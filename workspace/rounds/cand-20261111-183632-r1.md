# 第 56 轮（承接第 55 轮语义-接触接地；本轮灵感：「云边协同」×「手眼标定」）

> 第 55 轮把感知从“标签”推进到“可执行接触约束”，但留下一个未言明的前提：**像素到接触点的几何映射 `T_ce` 被当作真值**。本轮灵感直指这个前提：手眼标定不是一次性外参，而是云边异步、时变、弱可观测的潜变量；它的误差经杠杆臂放大后，恰好吃掉第 55 轮的语义边界裕度与全身生存核裕度。核心矛盾：**H24**：角标定误差 `δθ` 在接触点 `p` 上产生 `δθ×||p||` 量级的位置误差，同一 `δθ` 对近端夹爪无伤，对远端足端支撑面却会整体平移支撑多边形；**H25**：云端标定全局准但陈旧，边端标定新鲜但局部弱可观测，朴素切换会造成 `T` 的跳变，进而让接触集与生存核不连续塌缩；**H26**：降低标定不确定性需要激励运动，而激励运动本身受全身可行性与接触约束限制，标定与控制因此耦合。

## 0. 直觉与动机

**灵感 1（手眼标定 → 不是外参，而是接触几何的信任根）**
直觉：若 `T_ce` 偏了 1°，夹爪近处只差毫米，但全身机器人足端在 0.8 m 杠杆臂上就差厘米级；支撑多边形被整体平移/旋转，全身控制器却仍以为站在原处。因此手眼标定必须进入控制的第一性约束，而不是感知模块的调试参数。第 55 轮的 `C^+(Σ)` 与 `K(Σ)` 都建立在“接触点坐标是真的”之上，本轮要把这个“真”换成“带证书的近似真”。

**灵感 2（云边协同 → 标定的“精度-新鲜度”双时间尺度）**
直觉：云端有跨会话大数据，能解全局 `AX=XB`、辨识安装偏差与相机内参；边端有当前关节编码器、力/触觉与视觉伺服，能捕捉热漂移、振动与碰撞后的微小偏移，但看不到全局尺度，且平移-旋转弱可观测。正确做法不是二选一，而是把两者作为带时间戳与协方差的“标定证据”做信息融合，并对陈旧证据做过程噪声膨胀。云端提供先验，边端提供条件修正。

**灵感 3（杠杆放大 → 接触相关的标定预算）**
直觉：标定误差不应只有一个全局阈值。定义每个接触点的杠杆臂 `r_p`，把 `Σ_T` 传播为接触点协方差 `Σ_p = J_p Σ_T J_p^T + Σ_kin + Σ_seg`；语义边界裕度必须与标定不确定椭球在同一法向上叠加，离末端越远、法向越敏感，所需裕度越大。近端夹爪与远端足端应拥有不同的标定预算。

**灵感 4（主动标定 → 标定动作也是受约束的动作）**
直觉：要降低手眼不确定性必须激励（旋转末端、观察固定标记、双臂互看），但激励本身可能破坏支撑或违反关节限位。因此提出 **安全主动标定**：在生存核内选信息增益最大的动作；若安全激励集为空，就退回保守保持并显式报告“标定饥饿”，而不是为了标定去冒险抖动。

**灵感 5（云边一致性 → 标定切换的连续性）**
直觉：云边融合最危险的时刻不是误差大，而是估计跳变。`T` 的阶跃会让接触集与 `K` 不连续变化，护盾可能从可行瞬间变为不可行。因此必须把 `||Log(T_{k+1}^{-1}T_k)||` 与接触集对称差作为硬约束，超限则保持/混合并膨胀协方差，宁可慢一点，也不让几何信任突变。

## 1. 形式化定义（增量：定义 127–133）

**定义 127（云边手眼标定状态）**
潜变量 `T(t)∈SE(3)` 为相机到末端/基座链中的待定变换。云端证据 `(T_c,Σ_c,t_c)`，边端证据 `(T_e,Σ_e,t_e)`，龄期 `τ=t-t_c`。陈旧的云端信息矩阵按过程噪声膨胀：
`Λ_c(τ)=(Σ_c+Q(τ))^{-1}`，`Λ_fuse=Λ_c(τ)+Σ_e^{-1}`，`Σ_fuse=Λ_fuse^{-1}`。
其中 `Q(τ)=diag(q_t τ, q_t τ, q_t τ, q_r τ, q_r τ, q_r τ)` 建模热漂移/振动；`T_fuse` 由 `SE(3)` 上的右扰动 IEKF 给出。该定义把“云端旧证据”与“边端新证据”放在同一信息度量下，而不是用启发式阈值切换。

**定义 128（标定-接触误差椭球）**
接触点 `p_c` 经运动学链映射到世界 `p_w=T_wb T_be T_ec p_c`。对 `T` 的右扰动 `ξ∈se(3)`，`p_w` 的雅可比 `J_p=[I, -[p_w]_×]`。接触协方差
`Σ_p = J_p Σ_fuse J_p^T + Σ_kin + Σ_seg`，
其中 `Σ_kin` 为关节/连杆误差，`Σ_seg` 为第 55 轮语义边界误差。沿接触约束法向 `n`（支撑法向或摩擦锥边界），标定敏感裕度定义为
`m_T(p)=β·sqrt(n^T Σ_p n)`，`β` 为风险分位数（如 2σ）。

**定义 129（标定感知接触集）**
在定义 121/123 的 `C^+(Σ)` 上叠加标定不确定：
`C_T(Σ,Σ_T) = {(p,c)∈C^+(Σ) | m_s(p) ≥ θ_m(κ,c) + m_T(p)}`。
即语义边界裕度与标定误差椭球共享同一预算，不能各算各的：几何偏了，语义再确定也不构成可接触证据。

**定义 130（标定-语义-全身生存核）**
`K(Σ,Σ_T) = {x | ∃u∈A_WB,λ: f(x,u,λ)=ẋ ∧ supp(λ)⊆C_T(Σ,Σ_T) ∧ x_{t+1}∈𝒳_safe}`。
与定义 122 相比，标定误差通过 `C_T` 收缩核。这一步把“手眼标定偏了”严格翻译成“可行动集塌了”，而不是两句独立的工程告警。

**定义 131（标定连续性约束）**
相邻时刻变换变化 `Δ_T(k)=||Log(T_{k+1}^{-1}T_k)||`；接触集对称差 `Δ_C(k)=|C_T(k+1) △ C_T(k)|`。要求 `Δ_T≤Δ_T^max` 且 `Δ_C≤Δ_C^max`；否则融合器执行 hold/blend，禁止把跳变直接送入护盾。连续性在这里不是平滑性偏好，而是生存核 Lipschitz 性的前提。

**定义 132（安全主动标定问题）**
激励动作 `u_cal` 的 Fisher 信息增益 `I(u_cal)=½ log det(Λ_T^+ / Λ_T)`（D-最优）。安全主动标定为
`u_cal* = argmax_u I(u) s.t. x_{t+1}∈K(Σ,Σ_T), supp(λ)⊆C_T, u∈A_safe`。
若可行集为空，返回 `CALIBRATION_HUNGRY` 并进入保守保持。标定因此不是控制之外的离线步骤，而是带安全证书的动作。

**定义 133（云边手眼标定证书）**
`J_T=(T_core,Σ_T,τ,obs_rank,Δ_T,ρ_cal,evidence)`：
- `T_core` 为核心工作空间内的标定变换，`Σ_T` 为其融合协方差；
- `τ` 为云端证据龄期，`obs_rank` 为可观测性秩（激励充分性）；
- `Δ_T` 为连续性实测量，`ρ_cal` 为标定鲁棒性谱（对标定扰动的可行性保持率）；
- `evidence` 含 NEES 一致性、残差门控与力/触觉对齐日志。
若 `NEES∈[χ²_{1-α}/d, χ²_α/d]`、`obs_rank≥6`、`τ≤τ_max`、`Δ_T≤Δ_T^max` 且 `ρ_cal≥ρ_min`，则标定可部署。

def cloud_edge_handeye(cloud_batch, edge_stream):
    T_c, S_c = robust_axxb(cloud_batch)        # 云端批量 AX=XB + 外点剔除

### IP-128 CUP（Calibration Uncertainty Propagation）

```python
def propagate_calibration(T, Sigma_T, contacts, kin_cov, seg_cov, beta):
    out = {}
    for p_c, n in contacts:
        J = contact_jacobian(T, p_c)           # [I, -[p_w]_x]
        Sigma_p = J @ Sigma_T @ J.T + kin_cov(p_c) + seg_cov(p_c)
        out[p_c] = beta * sqrt(n.T @ Sigma_p @ n)
    return out                                # 每个接触点的标定裕度 m_T(p)
```

### IP-129 CAS（Calibration-Aware Shield）

```python
def calibration_aware_shield(u_nom, x, K, C_T, T_fuse, Sigma_T, T_prev, W):
    m_T = propagate_calibration(T_fuse, Sigma_T, C_T, kin_cov, seg_cov, beta)
    C_safe = {p for p in C_T if m_s(p) >= theta_m(p) + m_T[p]}
    u = qp_solve(H=W, g=-W @ u_nom, constraints=[
        viability_constraint(x, u, K),
        contact_constraint(u, C_safe),
        continuity_constraint(T_prev, T_fuse, Delta_T_max),
        friction_cone_constraint(u, mu),
        joint_limit_constraint(u),
    ])
    if u is None:
        return safe_hold(x), 'calib_hold'
    return u, 'ok'
```

### IP-130 SAC（Safe Active Calibration）

```python
def safe_active_calibration(T, Sigma_T, K, candidates):
    best, best_gain = None, 0.0
    for u_cal in candidates:
        if not in_viability_kernel(next_state(u_cal), K):  # 先验安全筛
            continue
        gain = 0.5 * logdet(information_matrix(u_cal) / information_matrix(T))
        if gain > best_gain:
            best, best_gain = u_cal, gain
    if best is None:
        return None, 'CALIBRATION_HUNGRY'
    return best, best_gain
```

### IP-131 CCC（Cloud-Edge Calibration Consistency）

```python
def fuse_with_continuity(ev_c, ev_e, t, T_prev, params):
    S_c_tau = ev_c.Sigma + process_noise(t - ev_c.t)
    T_fuse, S_fuse = se3_information_fusion(ev_c.T, S_c_tau, ev_e.T, ev_e.Sigma)
    dT = se3_log(T_prev.inverse() @ T_fuse).norm()
    if dT > params.Delta_T_max:
        T_fuse = blend(T_prev, T_fuse, params.Delta_T_max / dT)
        S_fuse = S_fuse + params.jump_inflation * (dT - params.Delta_T_max) * I6
    return T_fuse, S_fuse, dT
```

### IP-132 CHC（Calibration Hand-Eye Certificate）

```python
def calibration_certificate(traj, ev, rho_cal, budgets):
    T_core = core_workspace_transform(traj, ev.T)
    Sigma_T = ev.Sigma
    if not nees_consistent(ev.residuals, Sigma_T):
        return ('reject', 'covariance_inconsistent')
    if observability_rank(ev.excitation) < 6:
        return ('reject', 'weak_observability')
    if ev.tau > budgets.tau_max:
        return ('reject', 'stale_cloud_evidence')
    if max_continuity_error(traj) > budgets.Delta_T_max:
        return ('reject', 'calibration_jump')
    if rho_cal < budgets.rho_min:
        return ('reject', 'calibration_robustness_fail')
    return ('ok', CalibCert(T_core, Sigma_T, ev.tau, rho_cal, ev.evidence))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| C2HE | 云端 O(N_b·iter·n²)；边端 O(1)/帧 | O(N_b) 云端 / O(1) 边端 | 外点剔除、IEKF 一致性 |
| CUP | O(|C|·(3×3)) | O(|C|) | 雅可比上界、协方差 sound |
| CAS | O(QP) 每次 | O(|A_WB|) | 接触集收缩、连续性约束 |
| SAC | O(|U_cal|·(QP+logdet)) | O(|U_cal|) | 先验安全筛、信息增益可计算 |
| CCC | O(1)/步 | O(1) | 时间戳对齐、混合有界 |
| CHC | O(|轨迹|·|C|) | O(|C|) | NEES 校准、可观测性判据 |

**引理 1（标定不确定性的单调收缩）**
若 `Σ_T` 是真实标定误差 `ξ` 的有效上界（即 `ξ^T Σ_T^{-1} ξ ≤ β²`），则 `C_T(Σ,Σ_T) ⊆ C^+(Σ)` 且 `K(Σ,Σ_T) ⊆ K(Σ)`。因为 `m_T(p)≥0`，`C_T` 只是在 `C^+` 上追加了法向裕度；接触集变小只会减少可行力分布，故生存核单调收缩。该引理保证：**标定不确定性不会凭空扩大可行域**，护盾因此天然保守。

**引理 2（语义-标定联合裕度）**
在 `Σ_seg` 与 `Σ_T` 独立且各自为 `1-α/2` 上界的条件下，由定义 128 的协方差相加，接触点沿 `n` 的真实偏移超过 `m_s+m_T` 的概率不超过 `α`。即语义边界与标定误差不能各自按 `α` 计账后再宣称联合安全，必须并成一个预算。

**正确性定理（Calibration-Grounded Whole-Body Safety）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** 云边标定融合的 `Σ_T` 经 NEES 校验且为真实误差上界；**(A34)** 云端证据龄期 `τ≤τ_max`，过程噪声模型覆盖漂移；**(A35)** 连续性约束 `Δ_T≤Δ_T^max` 在每一步成立，或融合器已执行保守混合；**(A36)** 激励的可观测性秩 `obs_rank≥6`，否则进入 `CALIBRATION_HUNGRY` 保守模式。则部署后单步安全概率：
```
P_safe ≥ 1 - P(||ξ|| > ε_T) - P(NEES inconsistent) - P(τ > τ_max)
          - P(Δ_T > Δ_T^max) - P(CALIBRATION_HUNGRY) - P(shield fallback fails)
```
关键：**标定协方差进证书、接触裕度按杠杆臂膨胀、云边切换保持连续、主动标定受生存核约束**。任何一层都不能把“云端说标定很准”当作“边端接触几何已证实”。

## 6. 本轮最大风险

**一句话**：把标定协方差写进护盾后，安全性从“相信分割”变成“相信 `Σ_T` 是诚实的上界”；若云端旧证据被低估、或云边融合在切换瞬间跳变，护盾会用一个自认为保守、实则错误的几何去膨胀/收缩接触裕度，让全身控制器把接触点放到系统性偏移的支撑面上——这类失败看起来像感知错误，本质却是标定不确定性未被如实记账，因此必须以 **NEES 一致性 + 连续性硬约束 + 安全主动标定** 三重护栏，宁可报告“标定饥饿”，绝不把陈旧的云端变换当作当前接触几何的已证实真值。

### IP-128 CUP：杠杆臂放大与法向裕度

```python
def propagate_calibration(T, Sigma_T, contacts, kin_cov, seg_cov, beta=2.0):
    margins = {}
    for p_c, n in contacts:
        p_w = T @ p_c
        J = np.hstack([np.eye(3), -skew(p_w)])
        Sigma_p = J @ Sigma_T @ J.T + kin_cov(p_c) + seg_cov(p_c)
        margins[p_c] = beta * np.sqrt(n.T @ Sigma_p @ n)
    return margins
```

### IP-130 SAC：安全主动标定

```python
def safe_active_calibration(T, Sigma_T, K, candidates, lambda_info=1.0):
    L0 = information_matrix(T, Sigma_T)
    best, best_gain = None, 0.0
    for u in candidates:
        x_next = next_state(u)
        if not in_viability_kernel(x_next, K):          # 安全先验筛
            continue
        L1 = L0 + lambda_info * fisher_information(u)
        gain = 0.5 * (np.linalg.slogdet(L1)[1] - np.linalg.slogdet(L0)[1])
        if gain > best_gain:
            best, best_gain = u, gain
    if best is None:
        return None, 'CALIBRATION_HUNGRY'
    return best, best_gain
```

### IP-131 CCC：云边连续融合

```python
def fuse_with_continuity(ev_c, ev_e, t, T_prev, params):
    S_c_tau = ev_c.Sigma + process_noise(t - ev_c.t, params)
    T_fuse, S_fuse = se3_information_fusion(ev_c.T, S_c_tau, ev_e.T, ev_e.Sigma)
    dT = se3_log(T_prev.inverse() @ T_fuse).norm()
    if dT > params.Delta_T_max:
        alpha = params.Delta_T_max / dT
        T_fuse = se3_interp(T_prev, T_fuse, alpha)
        S_fuse = S_fuse + params.jump_inflation * (dT - params.Delta_T_max) * I6
        flag = 'blended'
    else:
        flag = 'ok'
    return T_fuse, S_fuse, dT, flag
```

## 3. 几何放大推导与数值推演

**推导（杠杆放大）**：设标定旋转误差 `δθ` 与平移误差 `δt`，接触点相对标定参考点臂长 `r`。则
`δp ≈ δt + δθ × r`，故 `||δp|| ≤ ||δt|| + ||δθ||·r`。
沿支撑法向 `n` 的分量 `δp_n = n^T(δt + δθ×r)`。若 `Σ_T=diag(σ_t²I, σ_θ²I)`，则
`σ_{p,n}² ≈ σ_t² + σ_θ²·||r×n||²`，这正是 `Σ_p=J_pΣ_TJ_p^T` 的标量形式。关键结论：**标定预算必须按 `r×n` 缩放，不能用一个全局角阈值**。

**数值推演（单位：mm）**：取 `β=2`，`σ_t=1.0`，`σ_θ=0.3°=5.24e-3 rad`，语义裕度 `θ_m=10`。

| 场景 | 杠杆臂 `r` | `σ_θ·r` | `m_T≈2σ_{p,n}` | 与语义裕度合成后所需总裕度 |
|---|---|---|---|---|
| 近端夹爪 | 0.05 m | 0.26 | 0.52 | 10.5 |
| 手部远端接触 | 0.40 m | 2.10 | 4.20 | 14.2 |
| 足端支撑 | 0.80 m | 4.19 | 8.38 | 18.4 |

再加云端证据龄期 10 s、漂移 `0.01°/s`，则额外角误差 `0.1°`，在足端再增 `1.4 mm`。这说明：**同一套云边标定参数，对夹爪够用，对全身足端可能已经吃掉大半语义裕度**。

**引理（单调收缩）**：若 `Σ_T` 为真实标定误差上界，则 `C_T⊆C^+`、`K(Σ,Σ_T)⊆K(Σ)`。证明：由 `m_T≥0`，`C_T` 仅为 `C^+` 的子集；接触支撑集缩小不增加可行接触力集合，故生存核只减不增。该引理是护盾保守性的基础。

**定理（Calibration-Grounded Safety）**：在 (A29)–(A36) 下，
```
P_safe ≥ 1 - P(||ξ||>ε_T) - P(NEES inconsistent) - P(τ>τ_max)
          - P(Δ_T>Δ_T^max) - P(CALIBRATION_HUNGRY) - P(shield fallback fails)
```
证明要点：标定误差以概率 `1-P(||ξ||>ε_T)` 落在 `Σ_T` 椭球内；NEES 与龄期条件保证融合协方差未被低估；连续性条件保证 `K` 不跳变；`CALIBRATION_HUNGRY` 时进入保守保持，不执行未证实接触。由并集界即得。

## 7. 本轮最大风险

**一句话**：本轮把“几何信任”从静态外参升级为带协方差的云边时间序列，但整套证书的 soundness 取决于 `Σ_T` 是否诚实地上界真实标定误差、以及融合切换是否保持连续；一旦云端旧证据的漂移被低估，或切换瞬间的跳变绕过连续性护栏，护盾就会用错误的 `C_T` 与 `K(Σ,Σ_T)` 做出“自认为保守”的决策，让全身控制器把接触点放到系统性偏移的支撑面上——必须以 **NEES 在线校验 + 连续性硬约束 + 安全主动标定/标定饥饿回退** 三重护栏，宁可停机重标，绝不把云端“全局最优”当作边端“当前几何已证实”。
