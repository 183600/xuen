# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「机械臂」×「跨任务泛化」）

> R69 把「不确定」拆成 aleatoric 与 epistemic，并给 epistemic 配了一套主动交互：看、问、触。它的理论漂亮，但全部效率收益押在一个未经证明的前提上——**流模型给出的模态分布是可信的**。R69 自陈的最大风险正是「问错比不问更危险」。本轮要指出：这个风险的根源不只是「模态没校准」，而是 R69 的两个结构性盲点：
> - **没有身体**：动作被当作抽象轨迹，模态是否物理可执行完全由学习到的流密度决定，缺少一条任务无关、可独立验证的硬证据；
> - **没有任务身份**：每个 episode 被当作独立同分布，系统分不清「熟悉任务里的真歧义」与「从没见过的任务」，于是把「我不知道这是什么任务」误当成「我知道任务但选不准模态」，把本应用于探索的预算花在追问一个错误的问题上。
>
> 两个灵感正好补上：
> - **机械臂**：机械臂的身体（运动学链、关节限位、速度/力矩包络、自碰撞、可达域、接触锥）是一份**免费的、任务无关的、可验证的物理证书**。一个幻影模态如果违反身体约束，根本不需要问人，它物理上就不可能；
> - **跨任务泛化**：跨任务不是「一个大模型包打所有任务」，而是「**身体不变量共享 + 任务条件组合**」。同一台臂在不同任务间共享身体与技能骨架；任务只改变目标、物体、可供性、工具。跨任务经验因此可以成为一条**独立于流密度、独立于人类回答**的证据：这个歧义在 12 个相似任务里是怎么解的。
>
> 核心命题：**把「可信」拆成三层证据金字塔——先问身体允不允许（硬、零数据），再问跨任务经验支不支持（软、可迁移、带出处），最后才问人（交互、最贵、可被投毒）；任务身份不确定时，禁止用一次交互来「定案」，改用对任务后验的鲁棒策略。** 命名 **LIMB-RAS**（Limb-Invariant Morphology Binding — 身体不变量约束下的跨任务泛化与交互消歧闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这个动作在这个任务上成立，是身体允许、经验支持，还是只能去试**」。

## 0. 直觉与动机

**灵感 1（机械臂 → 身体是一份免费的、任务无关的证书）**
直觉：R69 用流模型判断「这个动作像不像策略会做的」，但「像」不等于「做得到」。机械臂的关节限位、速度/加速度/力矩包络、自碰撞、可达域、接触锥，是写进物理与结构里的硬约束。它们有三个宝贵性质：**不随任务变、不需要标注、可以独立验证**。因此一个被流模型采样出来的「幻影模态」，只要它让肘关节越限或让小臂穿过自己，就可以在进入任何学习校准之前被直接删除。这把 R69 的「先校准模态权重，再决定信不信」改成了「先把物理不可能的删掉，剩下的才需要校准」——从源头降低了对不可信模态分布的依赖。

**灵感 2（跨任务泛化 → 不变量与变量的正确切分）**
直觉：如果每学一个任务就重训一个策略，任务越多越难维护；如果强行用一个策略覆盖所有任务，任务差异会把共享部分也拖坏。正确的切分是：**身体与运动骨架是任务间的不变量，任务只决定目标、物体、可供性、工具与约束**。于是在「身体坐标系」里，抓、推、拧、插这些技能可以跨任务复用；任务适配器只需学一个低维残差。跨任务泛化不是「零样本魔法」，而是「**把已经付过学费的经验，在身体坐标系里搬到新任务**」。

**灵感 3（三层证据 → 用硬先验正面消解 R69 的幻影风险）**
直觉：R69 只有两条证据——流模型的模态权重、人类交互回答；两者都可能错，而且会互相强化。LIMB 增加两条正交通道：
- **物理可行性**（确定性、零数据、任务无关）：幻影模态通常物理不可行；
- **跨任务支持**（数据驱动、带任务相似度权重）：一个真实模态应当在相似任务里被反复成功使用，一个幻影模态不会。
只有当模态同时「身体允许、经验支持、局部自洽」时，才允许高置信执行；否则降级。**幻影必须同时骗过物理、跨任务历史与交互三条通道，难度呈乘法下降。**

**灵感 4（任务身份 → 「歧义」不等于「新颖」）**
直觉：R69 把两种完全不同的 epistemic 混成一个 U_epi：一种是「任务我认识，但两个动作都合理」（绕左还是绕右）；另一种是「我根本不确定这是什么任务」（这是抓取还是递送？这是工具还是障碍？）。前者可以用一次注视/探针/问句高效消解；后者**一次回答根本不足以确定任务身份**，强行追问会把「诚实的不知道」变成「基于错误任务假设的自信行动」。LIMB 必须先把 U_epi 拆成 U_epi_local 与 U_epi_task，再做路由：局部歧义去交互，任务新颖去检索/鲁棒探索/保守。

**灵感 5（负迁移 → R70 必须严格包含 R69）**
直觉：从别人（或别的任务）那里学错，比不学更危险。跨任务先验可能在 fleet/任务平均上正确、在当前任务上错误；更阴险的是，它有「出处」、可复现、还能通过同一套证书，因而比随机错误更难被审计。所以本轮的理论姿态与 R69 对 R68 完全一致：**跨任务先验只能在 R69 已认证的可执行模态集合内重排序/重加权，绝不能扩张动作集合、绝不能放松 λ；没有可用先验或迁移门不开时，逐指令退回 R69。** 这样新增的每一个模块都只可能改进效率，不可能单独削弱已认证的安全。

**灵感 6（工具/末端执行器变更 → 身体是版本化的）**
直觉：机械臂的身体不变量并非永恒：换夹爪、换工具、换相机外参，都会改变可达域、碰撞体与接触锥。因此「身体证书」必须带版本号；跨任务记忆必须记录它是在哪个身体版本下获得的。版本不匹配时，跨任务先验降权或作废，而不是悄悄沿用。这把「终身学习」从「一个不断变大的模型」变成「**一份可追溯的身体-技能账本**」。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（LIMB-RAS 总览）** LIMB-RAS = (FLUID-RAS†, BSI, TID, CSL, MCF, XTE, TNU, NTF, TNI)。五不变式：
(i) **实时零学习写操作**（继承 R69 定义 293-i）；
(ii) **身体可行性健全**：物理可行性算子只剪枝、不新增；被其判为不可行的模态不得执行；
(iii) **先验单调性**：跨任务先验只能在 R69 认证的可行模态集合内重排序/重加权，不得扩张动作集合、不得降低 λ_floor；
(iv) **任务新颖保守**：任务新颖度超过阈值时，禁用跨任务先验与「高置信单次追问」，退回 R69 保守或任务鲁棒策略；
(v) **证据正交**：物理可行性、跨任务支持、交互回答是三类不同证据；任一单源不得单独定案。

**定义 311（身体模式描述子 BSI）** B = (运动学链参数、关节限位 q^±、速度/加速度/力矩包络、自碰撞模型、可达域、接触/力锥、工具坐标系)。B 在任务间不变；工具坐标系与工具相关，记 B^{(ν)} 为第 ν 个身体版本。B 由硬件规格与标定得到，不在实时环内学习。

**定义 312（物理可行性算子与身体残差）** 对轨迹 ξ，定义约束函数 h_i(ξ|B) ≥ 0（关节限位、速度/加速度、力矩、自碰撞距离、可达性、接触锥）。带安全裕度 δ_B 的可行域 ℱ_B^δ = {ξ : h_i(ξ|B) ≥ δ_B}。算子 Φ_B(ξ) = (feasible, m_B, r_B)，其中 m_B = min_i h_i/scale_i 为归一化最小裕度，r_B = Σ_i max(0, δ_B − h_i)^2 为身体残差。**健全性要求（A99）**：真实可执行域 ⊆ ℱ_B^δ，即 Φ_B 判不可行 ⇒ 真实不可执行；因此剪枝不会误删可执行模态，漏网的幻影由后续认证兜底。

**定义 313（身体坐标与任务等变分解）** 任务动作在末端/物体坐标系中表示为 ξ_body = T_B^{-1}(a)（对基座位姿、视角、相机外参等群作用等变），任务残差 ξ_task 捕获目标/物体/可供性差异。策略分解为
π_θ(ξ | o, B, τ) = p_shared(ξ_body | B) · p_task(ξ_task | z_τ, B)，
其中 p_shared 跨任务共享，p_task 由任务嵌入 z_τ 调制。这是 LIMB 能「带着身体迁移」而不同时覆盖所有任务的结构前提。

**定义 314（组合技能库 CSL）** 记忆 M = {(k, z_τ^k, precond_k, skill_k, stats_k)}：第 k 条记录含任务原型、前置条件、身体坐标技能、成功/失败统计与身体版本号。检索相似度 sim(z_τ, z_τ^k) 在任务嵌入空间计算；技能可按序列/并行组合成新任务解。库只追加不可变快照与统计，不覆盖历史。

**定义 315（任务身份后验与新颖度）** 任务嵌入 z_τ = f_τ(o, instruction)。任务后验 q_k = softmax_k(sim(z_τ, z_τ^k)/T)。新颖度 ν = 1 − max_k q_k（或用任务嵌入密度/能量），并用**分裂共形预测**校准：在已知任务分布上，ν 超过阈值的新颖判定的误报率 ≤ α_nov。任务身份熵 H_τ = −Σ_k q_k log q_k 度量「像多个任务」的程度。要求把「局部歧义」与「任务新颖」分开路由。

**定义 316（跨任务支持分 XTE）** 对候选模态 m 与检索到的任务集 S_m = {k : 模态 m 在任务 k 上成功}，定义带迁移权重的对数贝叶斯因子
s_X(m) = Σ_{k∈S_m} w_k · log [p(success | m, k) / p(success | ¬m, k)]，
w_k 由任务相似度、机制偏移与身体版本匹配度决定，并做有效样本量折扣。s_X 不是「真理」，只是一条带出处的证据；高 s_X 单独不足以定案（定义 320）。

**定义 317（不确定性再分解与路由 TNU）** 在 R69 二分基础上进一步拆分：
U_ale = Σ_k ŵ_k tr(Σ_k)（模态内噪声，不可约）；
U_epi_local = H_mode · g(Δ_min)，仅在任务已知（ν 低）且模态通过 ℱ_B^δ 后计算（任务内可交互消解）；
U_epi_task = H_τ · κ(ν)（任务身份不确定，单次交互不可定案，需检索/鲁棒探索）；
U_transfer = E[不匹配风险 | 检索先验]（先验是否适用于当前任务，由 NTF 门控）。
路由：U_epi_local → MINT 交互；U_epi_task → 任务鲁棒策略或安全探索；U_transfer 超阈 → 禁用先验、退回 R69；U_ale → λ floor。总保守下界
λ ≥ λ_floor(U_ale + U_epi_local^{unresolved} + U_epi_task + U_transfer)，因此逐项不小于 R69 的合并下界。

**定义 318（身体条件流匹配策略 MCF）** 速度场 v_θ(x_s, s | o, z_τ, B)，其中动作块在身体坐标中表示。采样时对硬约束采用「拒绝 + 局部重采样」，对软约束（如力矩平滑）采用可微 QP/CBF 投影 Π_{ℱ_B^δ}；**硬约束不允许投影到边界骑线**，以免把不可行模态伪装成可行模态。条件编码仍复用 R69 MTM trunk；额外条件 (z_τ, B) 通过低秩适配注入，避免重训。

**定义 319（可行性门控模态剪枝）** K 个采样 {ξ^{(j)}} 经 Φ_B 过滤，删除不可行者并按权重重归一化：ŵ_k' ∝ ŵ_k · 1[模态 k 的代表样本可行]。若全部样本不可行，则判为「身体-策略失配」（流模型不可信或身体版本错），不做任何高置信执行，λ = 1（或 R69 最保守），并上报异常。

**定义 320（三层证据融合与证据纪律）** 模态后验
p(m | o) ∝ ŵ_m' · exp(β_B m_B(m)) · exp(β_X s_X(m)) · L_int(m)，
其中 L_int 为交互似然。融合纪律：
(i) 物理可行性是**必要条件**，不是充分条件；
(ii) 高置信执行需至少「物理可行 + 一条软证据（跨任务支持或交互一致）」；
(iii) 单次交互回答仍受 R69 的 k-正交证据纪律约束，且交互证据不能用于判定任务身份（定义 322）；
(iv) 模态权重需通过 R69 的 MCG 校准门；未过则禁用交叉熵式加权，只用硬过滤与保守退避。

**定义 321（迁移门与负迁移防火墙 NTF）** 迁移门 T_k = P(任务 k 的先验在当前任务上改进风险 | 特征)，用验证数据/安全策略改进（SPI）估计其**高置信下界** LCB(T_k)。门开条件：LCB(T_k) > 0、前置条件 precond_k(o) 成立、身体版本匹配、且安全影子评估（在同一 C-RAS-WM 上把采用先验的候选与 R69 基线比较）证明认证风险不增。任一条不满足 ⇒ 先验作废，逐指令退回 R69。

**定义 322（任务新颖感知交互与鲁棒选择 TNI）** 当 ν > τ_nov：
(i) 禁止把交互预算用于「选哪个模态」，因为任务身份未定；
(ii) 允许**任务辨识型交互**（问「目标是什么/要递给谁」），但其回答只更新任务后验 q，不直接选动作；
(iii) 在更新后的任务后验支撑集上，选**最坏情况风险最小**的物理可行模态：m* = argmin_m max_{τ∈supp(q)} R(ξ_m | τ)，并对 supp(q) 取 CVaR；若无模态在所有高概率任务下安全，则停止/保守，而不是赌一个任务。
当 ν ≤ τ_nov：仍按 R69 MINT 处理局部歧义。

**定义 323（跨任务分层校准 CTH）** 模态权重与 MCG 的 ECE 用分层贝叶斯/部分池化在相似任务间借力：当前任务权重向跨任务后验收缩，收缩强度由任务相似度与样本量决定。这样在单任务样本不足时降低方差，但相似度低时自动退回本任务。跨任务统计只作为先验，不替代本任务在线证据。

**定义 324（身体版本化与工具变更 BSV）** 身体版本 B^{(ν)} 记录工具坐标系、碰撞体、可达域、力矩包络。换工具/换末端时递增 ν，并使旧版本技能进入「待再验证」状态：可检索但迁移门默认关闭，必须经过少量在线验证或影子评估后才重新开启。证书中记录 body_schema_ver 与技能记忆的版本匹配情况。

**定义 325（证书 J_LIMB）** J_LIMB = (J_FLUID, body_schema_ver, feasibility_pass_rate, task_novelty, transfer_gate_margin, cross_task_support, negative_transfer_shadow, U_ale/U_epi_local/U_epi_task/U_transfer, limb_ver)。Valid ⇔ Valid(J_FLUID) ∧ 身体可行性审计通过 ∧ 新颖度处置合规 ∧ 迁移门要么通过要么被保守绕过 ∧ 证据纪律满足。

**定义 326（迁移审计与干扰集 AIC-LIMB）** VQAuditor-T 审计：技能是否被错误检索、任务标签是否被投毒、跨任务统计是否被污染、身体版本是否错配、先验是否越过安全影子。干扰集 ℰ_LIMB = ℰ_FLUID × ℰ_transfer × ℰ_body，其中 ℰ_transfer 含错误任务标签、陈旧技能、非 IID 任务记忆、检索投毒；ℰ_body 含身体模型误差、未建模工具、标定漂移。

**定义 327（新颖任务的安全探索预算）** 对 ν 高的任务，允许有限次「信息性探索动作」，但必须同时满足：在任务后验的高概率支撑集上风险 ≤ ε_task、位移/力/时间预算受限、且探索动作也过 C-RAS-WM 认证。探索的目标是降低 H_τ 或提高技能库覆盖，而不是赌某个模态。预算耗尽仍高 ν ⇒ 保守停止。

**定义 328（时序耦合与降级顺序）** 默认 K=1、N_step=2；仅当 mode_head 报局部歧义或身体残差异常时升 K=4。降级顺序固定：先关跨任务先验（最可疑的软证据），再关交互（次可疑），最后只剩身体硬过滤 + R69 保守。该顺序保证任何一环失败时，系统向「更少先验、更少交互、更保守」单调退化。

**假设 A99–A103（LIMB 的适用边界）** A99：身体模型误差 ≤ δ_B，且 ℱ_B^δ 是真实可执行域的外近似；A100：跨任务源有界相关 ρ<1，迁移权重可校准；A101：任务嵌入与新颖度经共形校准（已知任务误报 ≤ α_nov）；A102：迁移门的 LCB 在有限样本下有效；A103：模态权重经 MCG 校准，证据纪律与安全影子可执行。

```python
# IP-264 BSI：身体可行性硬过滤（零数据、任务无关）
class BodySchemaInvariant:
    def filter(self, samples, B, delta):
        kept, residuals = [], []
        for xi in samples:
            h = self.constraints(xi, B)          # 关节/速度/力矩/自碰撞/可达/接触
            if min(h) >= delta: kept.append(xi)  # 硬约束只剪枝，不投影越界
            residuals.append(sum(max(0, delta - v)**2 for v in h))
        return kept, residuals

# IP-265 TID：任务身份后验 + 共形校准的新颖度
def infer_task(o, instruction, library, alpha_nov):
    z_tau = task_encoder(o, instruction)
    q     = softmax(sim(z_tau, library.prototypes) / T)
    nu    = conformal_novelty(z_tau, library, alpha_nov)   # 误报 <= alpha_nov
    h_tau = entropy(q)
    return z_tau, q, nu, h_tau

# IP-267 MCF：身体条件流匹配（硬约束拒绝，软约束投影）
def sample_flow(o, z_tau, B, K):
    z  = mtm_trunk(o)
    xs = randn(K, D)
    for i in range(N_step):
        xs = xs + (1.0 / N_step) * velocity(xs, i / N_step, z, z_tau, B)
        xs = [reject_or_project(x, B) for x in xs]   # 硬约束拒绝，软约束 QP

# IP-268 XTE：跨任务支持（带迁移权重与有效样本量折扣）
def cross_task_support(modes, z_tau, library, B):

    for m in modes:
        S = [k for k in library.match(z_tau, m) if library.version_ok(k, B)]
        w = [transfer_weight(z_tau, k) for k in S]
        out[m] = sum(wk * log_lr(m, k) for wk, k in zip(w, S)) / max(1.0, ess(w))
    return out

# IP-269 TNU：不确定性再分解与路由
def decompose_route(samples, z_tau, q, nu, library):
    U_ale, U_local, modes = aud.decompose(samples)       # R69 模态内/间
    U_task = entropy(q) * novelty_factor(nu)
    U_transfer = transfer_uncertainty(z_tau, library)
    if nu > TAU_NOV:      route = 'task_robust'
    elif U_local > TAU_EPI: route = 'interact'
    elif U_transfer > TAU_TR: route = 'fallback_R69'
    else:                 route = 'prior_assisted'
    return U_ale, U_local, U_task, U_transfer, modes, route

# IP-270 NTF：负迁移防火墙（LCB + 安全影子）
def transfer_gate(z_tau, library, shadow, o, B):
    for k in library.match(z_tau):
        if not precond(k, o) or not version_match(k, B): continue
        lcb = spi_lower_confidence_bound(k, z_tau)
        if lcb <= 0: continue
        if not shadow.certified_non_worse(k, o): continue   # 同一 C-RAS-WM 复核
        return True, k
    return False, None

# IP-277 主闭环（继承 R69，只在证据层插入 LIMB）
def LIMB_RAS_round(M, obs, instruction):

    B    = M.bsi.schema()

        samples, z_tau, q, nu, M.csl)

    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))   # 单调 >= R69

    return k, lam, mode, (U_ale, U_local, U_task, U_transfer)
```

## 3. 推导

**引理 19（身体可行性剪枝的健全性）** 设身体模型误差有界 δ_B，且 Φ_B 使用裕度 δ_B 构造 ℱ_B^δ，使真实可执行域 ⊆ ℱ_B^δ（A99）。则被 Φ_B 删除的模态必然真实不可执行；剪枝不会降低真实可执行模态的召回率。若身体模型误差超界，则误删概率 ≤ η(δ_B)，且由定义 319 的全删检测与定义 328 的降级顺序兜底。系：**物理过滤把幻影模态率从「依赖流模型校准」降为「依赖硬件规格」，这是一条不需要数据的独立通道。**

**引理 20（跨任务支持的证据强度）** 对候选模态 m，若跨任务源满足有界相关 ρ<1、迁移权重校准、且每个源在「m 为真/为幻影」下的成功似然比为 LR_k，则后验对数几率移动为 Σ_k w_k log LR_k，有效样本量按 N_eff = (Σw)^2/Σw² 折扣。若 log LR_k ≥ ℓ > 0 且 N_eff ≥ n，则幻影模态后验上界 ≤ exp(−c·n·ℓ)（常数 c 由 ρ 决定）。系：**跨任务证据可以在不追问人类的情况下消解一部分局部歧义，但它只是似然，不是定案；且必须在迁移门内使用。**

**引理 21（跨任务泛化误差分解）** 在定义 313 的等变分解下，新任务 τ 上的期望风险满足
R_τ(π) ≤ R_shared + R_task-residual + R_transfer-mismatch，
其中 R_shared 随任务数量与多样性增加而下降（共享身体坐标技能），R_task-residual 需要当前任务数据，R_transfer-mismatch 正是负迁移项。负迁移发生的充要条件是 mismatch 项超过共享增益；NTF 的门控就是对该不等式右端的在线估计。系：**跨任务泛化不是免费的；它成立的精确条件是「迁移不匹配小于共享收益」，而不是「任务看起来相似」。**

**定理 18（LIMB 严格包含 R69）** 在 A99–A103（身体健全、任务嵌入共形校准、迁移门 LCB 有效、模态校准门存在、证据纪律满足）下，对任意状态：
(i) 若关闭跨任务先验（库空/门关/ν 高）且身体过滤非绑定时，LIMB 的指令与 λ 逐条等于 FLUID-RAS；
(ii) 若启用先验，先验只在 R69 认证的可行模态集合内重排序，不新增动作、不降低 λ；
(iii) 任务新颖时改用任务鲁棒/保守策略，λ 单调不低于 R69。
故 E[R_LIMB] ≤ E[R_R69]；R69 是 LIMB 在「无身体剪枝、无跨任务记忆」边界上的退化。安全侧不做任何让步，效率侧获得「物理先验 + 跨任务复用」的双重收益。

**定理 19（负迁移防火墙与无突变）** 若迁移门只接受 LCB(改进)>0、前置条件成立、身体版本匹配且安全影子认证非劣的先验，则采用先验导致认证风险上升的概率 ≤ δ_gate + δ_shadow；门失败时定义 328 的降级顺序使 λ 单调不降，控制连续，不产生换装/提交突变（继承 R69 定理 17 与 R68 定理 15）。因此 LIMB 的「学习」通道只能通过被门控的软先验影响模态排序，不能绕过任何已认证的安全层。

## 6. 本轮最大风险

**一句话**：LIMB 把「可信」从流模型转移到「身体 + 任务身份 + 跨任务先验」，但**身体可行只保证「做得到」，不保证「做对」；跨任务支持只保证「在别的任务上对过」，不保证「这个任务就是那个任务」**——一旦任务嵌入发生感知别名（perceptual aliasing），一个物理可行、跨任务支持良好、安全影子也挑不出毛病的动作，会被以完整证书「借」给错误的任务；LIMB 于是把 R69 的「问错」升级为「带着身体证书与经验背书、自信地做错」。

**次级风险与缓解**：
1. **身体模型误差/未建模工具** → 裕度 δ_B + 版本化 BSV + 定义 319 全删检测 + E308；
2. **跨任务负迁移/投毒** → NTF 的 LCB + 前置条件 + 安全影子 + ℰ_transfer 对抗训练 + E305/E311；
3. **任务新颖度误判** → 共形校准 ν + 高 ν 时禁用单次定案 + 任务鲁棒策略 + E303/E313；
4. **实时预算被碰撞检测击穿** → 胶囊体代理 + swept volume + 仅候选轨迹检查 + E310；
5. **技能库遗忘/膨胀** → 不可变快照 + 分层校准 + 检索预算 + E312。

**定义 316（跨任务支持）** `s_X(m)=Σ_{k∈S_m} w_k log LR_k`，`w_k` 由任务相似度、机制偏移、身体版本匹配决定，并做有效样本量折扣；它只是似然，不是定案。

**定义 317（不确定性再分解与路由）** `U_ale=Σŵ trΣ`；`U_epi_local=H_mode·g(Δ_min)`（任务已知）；`U_epi_task=H_τ·κ(ν)`；`U_transfer=E[不匹配风险]`。路由：local→交互；task→任务鲁棒/探索；transfer→关先验退 R69；ale→λ floor。总下界逐项不小于 R69。

**定义 318–319（MCF 与可行性剪枝）** 速度场条件 `(o,z_τ,B)`；硬约束拒绝+局部重采样，软约束 QP/CBF 投影；硬约束不允许边界骑线。采样经 `Φ_B` 过滤后重归一化；全不可行 ⇒ 身体-策略失配，λ=1 并上报。

**定义 320（三层证据与纪律）** 后验 `∝ ŵ'·exp(β_B m_B)·exp(β_X s_X)·L_int`；物理可行是必要条件；高置信执行需「物理 + 一条软证据」；交互仍守 k-正交；权重需过 MCG。

**定义 321（迁移门/负迁移防火墙）** 门开需 `LCB(T_k)>0`、前置条件成立、身体版本匹配、安全影子认证非劣；任一不满足即先验作废并逐指令退回 R69。

**定义 322（任务新颖感知交互）** `ν>τ_nov` 时禁止用交互「选模态」；只允许任务辨识型交互，回答仅更新 q；动作按 `argmin_m max_{τ∈supp(q)} R`（CVaR）选；无安全模态则停止。

**定义 323–324（分层校准与版本化）** 模态权重/ECE 在相似任务间部分池化，相似低时退回本任务；换工具递增身体版本，旧技能待再验证。

**定义 325–328（证书/审计/探索/降级）** J_LIMB 并入身体版本、可行率、新颖度、迁移门裕度、影子结果、四类 U；ℰ_LIMB 覆盖迁移与身体；新颖任务探索需风险 ≤ ε_task 且过认证；降级顺序固定为「关先验 → 关交互 → 只剩硬过滤 + R69 保守」。

## 3. 关键算法伪代码

```python
# IP-264 BSI：身体可行性硬过滤（零数据、任务无关）
class BodySchemaInvariant:
    def filter(self, samples, B, delta):
        kept, residuals = [], []
        for xi in samples:
            h = self.constraints(xi, B)           # 关节/速度/力矩/自碰撞/可达/接触
            if min(h) >= delta: kept.append(xi)   # 只剪枝；硬约束不投影越界
            residuals.append(sum(max(0, delta - v)**2 for v in h))
        return kept, residuals

# IP-265 TID：任务身份后验 + 共形新颖度
def infer_task(o, instruction, library, alpha_nov):
    z_tau = task_encoder(o, instruction)
    q     = softmax(sim(z_tau, library.prototypes) / T)
    nu    = conformal_novelty(z_tau, library, alpha_nov)
    return z_tau, q, nu, entropy(q)

# IP-267 MCF：身体条件流匹配（硬约束拒绝，软约束投影）
def sample_flow(o, z_tau, B, K):
    z, xs = mtm_trunk(o), randn(K, D)
    for i in range(N_step):
        xs = xs + (1.0 / N_step) * velocity(xs, i / N_step, z, z_tau, B)
        xs = [reject_or_project(x, B) for x in xs]
    return decode(xs)                              # ξ_body + ξ_task

# IP-268 XTE：跨任务支持（迁移权重 + 有效样本量折扣）
def cross_task_support(modes, z_tau, library, B):
    out = {}
    for m in modes:
        S = [k for k in library.match(z_tau, m) if library.version_ok(k, B)]
        w = [transfer_weight(z_tau, k) for k in S]
        out[m] = sum(wk * log_lr(m, k) for wk, k in zip(w, S)) / max(1.0, ess(w))
    return out

# IP-269 TNU：不确定性再分解与路由
def decompose_route(samples, z_tau, q, nu, library):
    U_ale, U_local, modes = aud.decompose(samples)
    U_task     = entropy(q) * novelty_factor(nu)
    U_transfer = transfer_uncertainty(z_tau, library)
    if nu > TAU_NOV:          route = 'task_robust'
    elif U_local > TAU_EPI:   route = 'interact'
    elif U_transfer > TAU_TR: route = 'fallback_R69'
    else:                     route = 'prior_assisted'
    return U_ale, U_local, U_task, U_transfer, modes, route

# IP-270 NTF：负迁移防火墙（LCB + 安全影子）
def transfer_gate(z_tau, library, shadow, o, B):
    for k in library.match(z_tau):
        if not precond(k, o) or not version_match(k, B): continue
        if spi_lower_confidence_bound(k, z_tau) <= 0:    continue
        if not shadow.certified_non_worse(k, o):         continue
        return True, k
    return False, None

# IP-277 主闭环（继承 R69，只在证据层插入 LIMB）
def LIMB_RAS_round(M, obs, instruction):
    z, o = M.mtm.forward(obs)
    B    = M.bsi.schema()
    c, U_cal, thr = M.cof.step(...)
    z_tau, q, nu, H_tau = M.tid.infer(o, instruction, M.csl)
    K = 1 if M.mcf.mode_head(z, z_tau) < TAU_MODE else 4
    samples = M.mcf.sample(o, z_tau, B, K)
    samples, r_B = M.bsi.filter(samples, B, delta_B)
    U_ale, U_local, U_task, U_transfer, modes, route = M.tnu.decompose_route(
        samples, z_tau, q, nu, M.csl)
    if not modes:
        return conservative_stop(r_B, 'body_policy_mismatch')
    s_X = M.xte.support(modes, z_tau, M.csl, B)
    use_prior, k_src = M.ntf.transfer_gate(z_tau, M.csl, M.shadow, o, B)
    if use_prior and route == 'prior_assisted':
        modes = M.xte.reweight(modes, s_X)           # 只重排序/重加权
    if route == 'task_robust':
        mode, g = M.tni.minimax_over_tasks(modes, q), None
    elif route == 'interact':
        g    = M.mint.choose_interaction(modes, o, M.budget)
        mode = M.select_mode(modes, U_local)
    else:
        g, mode = None, M.select_mode(modes, U_local + U_task + U_transfer)
    U_floor = U_ale + (U_local if g is None else 0.0) + U_task + (U_transfer if not use_prior else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))   # 单调 >= R69
    k = M.c_ras_wm.certified_prefix(mode.a, ..., wm_preds)
    if route == 'fallback_R69' or not use_prior:
        lam = max(lam, lam_floor(U_ale + U_local + U_task))
    M.vqa_t.submit_async(g, z_tau, nu, s_X, use_prior, k_src, r_B)
    return k, lam, mode, (U_ale, U_local, U_task, U_transfer)
```

## 4. 推导

**假设 A99–A103**：A99 身体模型误差 ≤ δ_B 且 `ℱ_B^δ` 外近似真实可执行域；A100 跨任务源有界相关 ρ<1、迁移权重可校准；A101 任务嵌入/新颖度经共形校准；A102 迁移门 LCB 在有限样本下有效；A103 模态权重经 MCG 校准且证据纪律/安全影子可执行。

**引理 19（身体剪枝健全性）** 若身体模型误差 ≤ δ_B 且 `ℱ_B^δ` 外近似真实可执行域（A99），则 Φ_B 删除的模态必真实不可执行，剪枝不降低可执行模态召回；误差超界时误删概率 ≤ η(δ_B)，由全删检测与降级顺序兜底。系：物理过滤把幻影率从「依赖流模型校准」降为「依赖硬件规格」，是零数据独立通道。

**引理 20（跨任务支持证据强度）** 有界相关 ρ<1、迁移权重校准下，后验对数几率移动为 `Σ w_k log LR_k`，有效样本量 `N_eff=(Σw)^2/Σw²`；若每源 `log LR_k ≥ ℓ>0`、`N_eff ≥ n`，则幻影模态后验 ≤ `exp(−c·n·ℓ)`。系：跨任务证据可替代一部分追问，但只是似然，且必须在迁移门内使用。

**引理 21（跨任务泛化误差分解）** 等变分解下，新任务风险 `R_τ ≤ R_shared + R_task-residual + R_transfer-mismatch`；负迁移发生的充要条件是 mismatch 超过共享增益。NTF 的门控就是对该不等式右端的在线估计。系：跨任务泛化不是免费的，成立条件是「迁移不匹配小于共享收益」。

**定理 18（LIMB 严格包含 R69）** 在 A99–A103 下：无先验/门关/ν 高且身体过滤非绑定时，LIMB 逐指令等于 FLUID-RAS；启用先验时只在 R69 已认证可行模态集合内重排序，不新增动作、不降 λ；任务新颖时改用鲁棒/保守策略，λ 单调不低于 R69。故 `E[R_LIMB] ≤ E[R_R69]`，R69 是 LIMB 在「无身体剪枝、无跨任务记忆」边界上的退化。

**定理 19（负迁移防火墙与无突变）** 迁移门只接受 LCB(改进)>0、前置条件成立、身体版本匹配且安全影子非劣的先验，则采用先验导致认证风险上升的概率 ≤ δ_gate+δ_shadow；门失败时降级顺序使 λ 单调不降，控制连续，继承 R69 定理 17 与 R68 定理 15 的无突变性。学习只能通过被门控的软先验影响模态排序，不能绕过安全层。

## 7. 本轮最大风险

**一句话**：LIMB 把「可信」从流模型转移到「身体 + 任务身份 + 跨任务先验」，但**身体可行只保证「做得到」，不保证「做对」；跨任务支持只保证「在别的任务上对过」，不保证「这个任务就是那个任务」**——一旦任务嵌入发生感知别名，一个物理可行、跨任务支持良好、安全影子也挑不出毛病的动作，会被以完整证书「借」给错误的任务；LIMB 于是把 R69 的「问错」升级为「带着身体证书与经验背书、自信地做错」。

**次级风险与缓解**：身体模型误差/未建模工具 → 裕度 δ_B + 版本化 BSV + 全删检测 + E308；跨任务负迁移/投毒 → NTF 的 LCB + 前置条件 + 安全影子 + ℰ_transfer 对抗训练 + E305/E311；任务新颖度误判 → 共形 ν + 高 ν 禁单次定案 + 任务鲁棒策略 + E303/E313；实时预算被碰撞检测击穿 → 胶囊体代理 + swept volume + 仅候选轨迹检查 + E310；技能库遗忘/膨胀 → 不可变快照 + 分层校准 + 检索预算 + E312。
