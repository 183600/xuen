# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS 具身计量审计」IP-287~294；灵感循环第 3 轮；本轮灵感：「真机评测」×「自监督学习」）

> R72 把 GAUGE 从「认知层」推进到「具身层」：用 **REG** 把三频分离变成 ROS 2 实时执行图与 RTA 时序定理，用 **IRL** 把意图 z 纳入联合后验，用 **DMEM** 把灵巧手接触不确定度拆成四分量，用 **EREFLEX/ERVOI** 统一三层反作用预算，用 **S2R-UQ** 把 sim2real 残差送进 WCET 与 λ_floor，最后用 **J_EMB** 盖章。R72 的哲学是「**先证明它应当安全，再上真机**」。
>
> 但 R72 有一个未言明的前提：**评测是可信的**。它假设我们能测出「风险界是否真的守住了」，能测出「意图识别是否真的校准」，能测出「λ_floor 是否真的覆盖实机分布」。然而在真机上：
> - **真机评测视角**：评测本身是一件**测量仪器**。它有小样本、非平稳硬件（温漂/磨损/电池/润滑）、不可复现的试验（物理世界不能 reset）、被安全层拦截而永远观测不到的失败（删失）、评测者自由度（改 reset 流程、挑种子、事后选窗口）、基准泄漏（在同一台机器上迭代到通过）。**「零失败」不等于「安全」**：n=30 次零失败，95% 上界约 9.5%；n=300 次零失败，上界才约 1%（引理 33）。R72 的证书没有任何统计功效字段——这是一个**认识论漏洞**，不是工程细节。
> - **自监督学习视角**：真机数据昂贵、标注更贵，SSL 是唯一能规模化利用遥操作日志/视频/触觉流的路径。但 SSL 的每一个「增广不变性」都是一条**安全断言**：对光照不变，等于断言光照与任务无关；对颜色不变，可能把「拿红色块」变成「拿任意块」；对触觉漂移不变，可能把「真实滑移」抹成「传感器噪声」。**不变性错一条，表征就会自信地抹掉一条安全信号**。更危险的是，SSL 的「一致性残差」常被当作不确定度，但分布外它可以**与真实误差反相关**（越自信越错），未经校准直接进 λ 会把风险缩放做反。
> - **闭环污染视角**：如果同一个 SSL 表征既用于训练策略、又用于定义 OOD、又用于评测分层，那么它会**自己定义什么算「分布内」、什么算「成功」**。这是一个自我指涉的认识论闭环：表征错了，训练、检测、评测会互相点头。
>
> 本轮两个灵感正好补两块：
> - **真机评测** → 把评测升级为**被计量的仪器**（EVAL-MET）：预注册、区组随机化、删失建模、anytime-valid 证据、稀有事件压力测试、锚定试验、密封留出集；把「安全主张」从点估计改成**带覆盖保证的上置信界（UCB）**。
> - **自监督学习** → 把 SSL 升级为**被审计的测量仪器**（SSL-LEDGER / SSL-PROBE）：每条不变性带因果正当性、有效域、追溯链；一致性残差经 conformal/分位数校准后才可进 λ；训练/评测/审计三套表征分离并做泄漏检测。
>
> 核心命题：**不再只问「我的系统在真机上安全吗」，而问「我用来证明它安全的那个评测，本身可信吗？我用来自监督的表征，有没有偷偷改写安全定义？」** 把 R72 的「部署证书」升级为 **FIELD-GAUGE-RAS**（Falsifiable, In-situ, Evidence-valid, Ledgered, Drift-aware GAUGE for RAS）——**可证伪的现场证据闭环**。

## 0. 直觉与动机

**灵感 1（真机评测 → 证书的效力取决于评测的功效，而不是证书的厚度）**
直觉：R72 的 J_EMB 有哈希、有 RTA 证明、有追溯链，看起来很硬。但「硬」的是**内部一致性**，不是**外部有效性**。如果评测只有 N=20 次试验、硬件在 24 小时内漂移了 8%、安全层拦截了最危险的 30% 试验，那么这份证书盖章的是一个**统计上不可识别**的主张。真机评测的第一性原理不是「跑更多实验」，而是：**先声明我要估什么（estimand）、我有多大功效（power）、我的失败被什么机制删失（censoring）、我的硬件是不是同一个东西（stationarity）**。
更尖锐地说：**「零失败」是最容易被误读的证据**。0/30 的 95% 上界是 9.5%，不是 0%；要在 95% 置信下声称失败率 <1%，至少需要约 300 次零失败（引理 33）。R72 的所有「零 hard safety violation」目标，如果没有 UCB，就只是**叙事**，不是**证据**。

**灵感 2（真机评测 → 安全层越有效，观测到的风险越偏低：删失偏差）**
直觉：我们造安全层是为了**阻止**危险动作。但一旦阻止，我们就在评测中**永远看不到**那些本会发生的失败。于是「上线后零事故」可能不是「系统安全」，而是「系统把危险试验都挡掉了，所以我们没机会观测到失败」。统计学上这是**右删失/截断**：观察到的风险 R_obs = E[Y·1[未被删失]] ≤ 真实风险 R_true。若不建模删失倾向 e(x)=P(未被删失|x)，直接拿观测失败率当真实失败率，会**系统性低估**风险。必须用 IPCW（逆删失概率加权）或显式的删失生成模型，并报告**正性假设**（ê(x)≥ε）与**有效样本量 ESS**。**安全层的功劳，恰恰是评测偏差的来源**——这是本轮最反直觉、也最重要的一点。

**灵感 3（真机评测 → 硬件漂移是混淆变量，不是噪声）**
直觉：今天上午的机器人和下午的机器人不是同一个系统：电机发热、减速器磨损、触觉零点漂移、电池电压下降、桌面摩擦变化。若你先跑基线 A 再跑方法 B，B 的「提升」可能只是**时间效应**。正确做法不是「多跑几遍」，而是**区组随机化 + 配对 + 顺序平衡（counterbalancing）**，并在每个区组内做**平稳性证书**（change-point test + 漂移上界）。把硬件隐状态 h_t 显式写进生成模型 y_t = f(x_t,a_t,h_t)+ε，才能把处理效应 τ 与漂移 Δh 分开。**在漂移的机器上做顺序 A/B，是最常见的「自信地测错」。**

**灵感 4（自监督学习 → 不变性就是安全断言，必须有因果账本）**
直觉：SSL 的核心动作是「让表征对某个变换不变」。这句话在统计上等价于宣称：**该变换是 nuisance，不是任务的因果父节点**。如果这个宣称错了——颜色对「拿红块」是任务相关的、纹理对「判断成熟度」是任务相关的、触觉漂移与「真实滑移」不可分——那么不变性会**主动删除安全信号**，而且删除得越干净，表征越「好」，下游越自信。所以每条增广/不变性都必须有一张**账本**：变换 f、宣称的 nuisance 关系、有效域 D_f、因果/干预检验、追溯链 τ_f。**没有账本的不变性 = 未申报的安全假设。** 这是把 SSL 从「表征学习技巧」提升为「计量对象」的关键。

**灵感 5（自监督学习 → 一致性残差可以是探针，但必须先校准，且可能反相关）**
直觉：多视图/多模态/多时间尺度的一致性残差 r_SSL 看起来像「免费的不确定度」：不一致 ⇒ 可能 OOD。但它是**未校准**的，而且分布外可能**反相关**：模型在错误的地方自信（representation collapse、shortcut learning），残差反而小。未经校准把 u_SSL 放进 λ 分母，会在最需要抬高 λ 的时候把它压低。正确做法：在**独立真机留出集**上做 conformal/分位数校准，报告**覆盖率**与**分层条件覆盖率**，并做「反相关检验」；并且规定 u_SSL 只能**单向抬高** λ，不能单独降低 λ（安全侧只增不减）。**免费的不确定度通常不是不确定度，是另一个自信偏差。**

**灵感 6（闭环污染 → 训练/评测/审计三套表征必须分离）**
直觉：如果评测用的表征与部署用的表征同源，评测就会「认识」自己的偏差。更隐蔽的是：用 SSL 表征做 OOD 检测，再用同一表征定义评测分层，于是「分布内」由系统自己定义。必须分离 z_train / z_eval / z_audit 三套表征（不同数据切分、不同随机种子、最好不同模型族），并做泄漏检测（membership inference、最近邻重叠、表征交换后的性能掉点）。引入**循环指数 CI**：评测表征质量与训练表征质量的相关性；CI 高 ⇒ 评测在为训练背书，而不是检验训练。

**灵感 7（证据有序 → 允许早停，但不允许事后挑窗口）**
直觉：真机试验贵，必须能早停。但「看到结果不错就停」会严重膨胀第一类错误。解法不是禁止早停，而是用 **anytime-valid 证据**：e-process / 置信序列（confidence sequence），在**任意停时**都保持 α 水平。把每一次「看」都记进证据账本，禁止事后选择窗口或指标。**可证伪性不是「做了假设检验」，而是「停时也合法」。**

## 1. 形式化定义（增量：定义 366–381）

**定义 366（FIELD-GAUGE-RAS 总览）** FIELD-GAUGE-RAS = (EVAL, DRIFT, CENSOR, POWER, ANCHOR, SSL-LEDGER, SSL-PROBE, SEAL-EVAL, GAUGE-RAS†)。六不变式：
(i) **评测先行**：任何 J_EMB 主张必须附带 J_EVAL（估计量、设计、功效、删失、漂移、泄漏）；缺一即证书无效；
(ii) **证据有序**：只有 anytime-valid 证据可触发「通过/不通过/继续」，禁止事后挑窗口；
(iii) **删失显式**：被安全层拦截的试验必须进入删失模型；观测失败率不得直接当作真实失败率；
(iv) **漂移可分**：评测必须区组随机化/配对/顺序平衡，使处理效应 τ 与硬件漂移 Δh 可分离；
(v) **自监督可审计**：每条 SSL 不变性必须有因果正当性、有效域、追溯链；探针必须校准且只单向抬高风险；
(vi) **严格退化**：EVAL 失效 ⇒ 只报保守 UCB 或「无结论」；SSL 失效 ⇒ 退化为监督/手工特征 + R72；CENSOR 失效 ⇒ 不得声称安全率；SEAL 失效 ⇒ 不得声称泛化；全失效 ⇒ R72/R71/R68。

**定义 367（评测协议 EP）** EP = (θ_eval, 𝒟, s, b, β, π_seq, n_max, prereg_hash)：
- θ_eval：估计量（如 P(failure)、E[completion time]、风险调整成功率）；
- 𝒟：设计（paired / blocked / factorial / crossover）；
- s：抽样与纳入/排除标准；
- b：盲法映射（评测者不知道条件身份）；
- β：功效目标与最小可检测效应 MDE；
- π_seq：序贯停止规则（anytime-valid）；
- prereg_hash：冻结分析计划的哈希。
**EP 有效 ⇔ prereg_hash 匹配 ∧ 设计在 MDE 处功效 ≥ 1−β ∧ 估计量与设计相容。**

**定义 368（评测不确定度预算）** 
u_eval² = u_samp² + u_nons² + u_hw² + u_human² + u_protocol² + u_leak²，
分别对应抽样、非平稳、硬件标定、人类/评测者、协议漂移、基准泄漏。每个分量带独立追溯链 τ_eval_i。**J_EVAL 必须附预算表；任一缺失即无效。** 评测不确定度不是用来「加个误差棒」，而是用来判断**主张的分辨率**：若效应量 < u_eval，则该主张不可识别。

**定义 369（硬件状态与非平稳性 DRIFT）** 隐硬件状态 h_t（温度、磨损、标定、电池、润滑）满足 h_{t+1} = h_t + η_t；观测 y_t = f(x_t, a_t, h_t) + ε_t。若处理分配 a_t 与 h_t 相关（顺序试验的典型情形），则朴素估计
E[Ŷ_B − Ŷ_A] = τ + E[h_B − h_A]，
偏差非零。**平稳性证书 S_eval**：区组内 change-point 检验 + 漂移上界 Lip(h)·diam(block) ≤ δ_h。设计采用**区组随机化 + 平衡配对 + 顺序平衡**，估计量在区组内条件化。

**定义 370（安全删失与 IPCW）** 安全包络 𝒮 删失动作 a∉𝒮。观测 O = Y·1[未被删失]。删失倾向 e(x)=P(未被删失|x)。在**可忽略删失**（给定 x 无未观测混淆）与**正性**（ê(x)≥ε>0）下，IPCW 估计
R̂_IPCW = (1/n) Σ_i 1[未被删失_i]·Y_i / ê(x_i)
无偏。删失证书 C_eval 报告：e-model、正性诊断、**有效样本量** ESS = (Σw_i)²/Σw_i²（w_i=1/ê(x_i)）。**ESS 过小 ⇒ 主张无效，而不是「继续算」。**

**定义 371（anytime-valid 证据 POWER）** 在 H₀ 下，非负 e-process (E_t) 满足 E_0=1 且为超鞅；当 E_t ≥ 1/α 时拒绝 H₀，该规则在**任意停时**保持水平 α。等价地，置信序列 (CS_t) 满足 P(∀t: θ∈CS_t) ≥ 1−α。**证据账本**记录每次查看的 t、统计量、决策；事后选窗口/换指标即失效。

**定义 372（稀有事件与自适应压力测试 RARE-AST）** 目标 p_fail 可能远小于 1/n。用 SSL 世界模型/生成模型给出提议分布 q，重要性采样估计
p̂ = (1/n) Σ 1[fail(x_i)]·p(x_i)/q(x_i)，
报告 ESS 与方差上界。自适应压力测试在**真实性预算** D(q‖p_data) ≤ ρ 下最大化估计失败概率，防止找到「对抗但物理上不可能」的失败。**ρ 是防止 AST 变成幻想生成的闸门。**

**定义 373（锚定试验 ANCHOR）** 取最小随机真机试验集 A（|A|=n_A），估计仿真/OPE 估计量的偏差 b̂ = mean_real(A) − mean_OPE(A) 及其不确定度 u_anchor。**禁止 OPE-only 认证**：J_EVAL 要求 n_A ≥ n_min 且 |b̂| ≤ b_max；偏差修正后报告
|R_true − R_OPE| ≤ |b̂| + u_anchor + (1−overlap)·B，
其中 overlap 为策略支撑重叠度，B 为结果上界（引理 38）。

**定义 374（SSL 不变性账本 SSL-LEDGER）** 增广族 𝒜={g_f}，g_f 变换因子 f。不变性主张 I_f: z(g_f(x))=z(x)。**Nuisance 主张** N_f: Y ⫫ f | Pa(Y)（在语境中 f 不是任务结果的因果父节点）。有效域 D_f：N_f 成立的语境集合。账本条目 L_f=(f, g_f, N_f, D_f, test_stat, effect/p, τ_f)。**I_f 仅在 D_f 上可采纳**；若在 D_f 外被使用，则为**不安全不变性**（可擦除安全信号，引理 36）。

**定义 375（SSL 一致性探针与校准 SSL-PROBE）** 对视图 v_1..v_k（增广/模态/时间尺度），探针残差 r_SSL(x)=disc(z(v_i(x)))。认知估计 u_SSL=C(r_SSL)，C 为在**独立真机留出集**上拟合的 conformal/分位数校准器。**覆盖保证**：在校准分布上 P(err ≤ u_SSL) ≥ 1−α；必须报告**分层条件覆盖率**与**反相关检验**（corr(r_SSL, err) 的符号与幅度）。**安全约束：u_SSL 只允许抬高 λ，单独不得降低 λ。**

**定义 376（表征来源分离与泄漏检测）** 三套表征：z_train（部署）、z_eval（评测分层/指标）、z_audit（独立审计）。要求 z_eval 与 z_train 使用不同数据切分/种子/（最好）模型族。泄漏检验：(a) membership inference；(b) 最近邻重叠率；(c) 表征交换后的性能掉点。**循环指数** CI = corr(quality(z_eval), quality(z_train))；CI 高 ⇒ 评测在为训练背书，J_SSL 降级。

**定义 377（密封评测与预注册 SEAL-EVAL）** 评测密钥 K 由独立进程持有；盲法映射隐藏条件身份；留出集覆盖未见机器人 R_hold、用户 U_hold、环境 E_hold；预注册哈希在试验前提交、分析代码冻结；最终指标**一次性开封**（one-shot unsealing）。在线只允许通过 anytime-valid 通道监控。**密封不是保密，而是防止评测反馈被用于拟合。**

**定义 378（评测证书 J_EVAL）** 
J_EVAL = (EP_hash, power_report, drift_report, censoring_report, anchor_report, evidence_ledger, leak_report, eval_uq_budget, sealer_sig)。
Valid ⇔ 预注册匹配 ∧ MDE 处功效达标 ∧ 漂移受控或区组化 ∧ 删失模型正性/ESS 达标 ∧ 锚定偏差有界 ∧ anytime-valid 证据通过 ∧ 泄漏低于阈值。**Valid(J_EVAL) ⇒ 所有主张以带覆盖的 UCB 表述，而非点估计。**

**定义 379（自监督证书 J_SSL）** 
J_SSL = (corpus_provenance, invariance_ledger, probe_calibration, coverage_report, circularity_index, ssl_ver)。
Valid ⇔ 每条不变性在其有效域上可采纳 ∧ 探针在独立真机分层上覆盖率 ≥ 1−α ∧ CI 低于阈值 ∧ 语料来源完整（含采集条件、硬件状态、去重/污染检测）。

**定义 380（FIELD 证书 J_FIELD）** 
J_FIELD = (J_EMB, J_EVAL, J_SSL, field_ver)。
Valid ⇔ 三者全有效 ∧ 风险/收益主张均以 UCB/置信序列表述 ∧ 未使用被删失样本的朴素频率。

**定义 381（威胁模型 AIC-FIELD）** ℰ_FIELD = ℰ_EMB × ℰ_eval × ℰ_ssl：

## 3. 推导

**引理 33（零失败不是安全：样本量给不出你想要的结论）** 设 n 次独立试验零失败，真实失败率 p 的 95% 精确上界（Clopper–Pearson）满足 p ≤ 1−0.05^{1/n} ≈ 3/n。n=30 ⇒ 9.5%；n=100 ⇒ 2.95%；n=300 ⇒ 0.99%。**系：任何「零 hard safety violation」主张必须附 n 与 UCB；没有 UCB 的「零失败」只是叙事。**

**引理 34（删失偏差与 IPCW 无偏性）** 观察风险 R_obs=E[Y·1[未被删失]] ≤ R_true，偏差 = E[Y·1[被删失]] ≥ 0。在可忽略删失与正性下，E[R̂_IPCW]=R_true，且 Var(R̂_IPCW) ∝ 1/ESS。**系：安全层拦下的恰好是最危险的样本，因此「上线零事故」不是安全的证据，而是删失的证据；不建模删失就报告失败率，是系统性低估。**

**引理 35（漂移混淆与区组化的偏差界）** 顺序 A→B 的朴素估计偏差为 E[h_B−h_A]。若 h 在区组内漂移 Lipschitz 且幅度 ≤ δ_h，则区组随机化 + 条件化后偏差 ≤ L_h·δ_h；顺序平衡消除一阶时间效应。**系：在发热/磨损的真实机器上做未随机化的 A/B，效应量若小于漂移幅度，符号都可能反。**

**引理 36（不安全不变性 ⇒ 风险界失效）** 若因子 f 在有效域 D 上是 Y 的因果父节点，却被声明为 nuisance 并强制 z(g_f(x))=z(x)，则存在 x,x' 使 z(x)=z(x') 但 R(x)≠R(x')。任何仅依赖 z 的风险预测器在该划分上的误差 ≥ 塌缩划分的 Bayes 误差，且不可由更多数据消除。形式化：若 I(Y; f | z) > 0，则 z 不是 Y 的充分统计量。**系：每条 SSL 不变性都是一条需要证明的安全断言；证书里没有「增广技巧」，只有「被采纳的因果假设」。**

**引理 37（SSL 探针的反相关风险）** 一致性残差 r_SSL 与真实误差 err 的相关符号在分布外不保证为正；在 shortcut/塌缩情形可为负。若未校准即用 u_SSL 降低 λ，则在高风险区可能出现 λ↓。Conformal 校准只给**边际**覆盖，不给条件覆盖；必须报告分层覆盖率并加**单向安全钳**（u_SSL 只能抬高 λ）。**系：「免费的 OOD 分数」在安全闭环里必须先被当成敌手，再被当成信号。**

**引理 38（锚定偏差界）** 对任意 OPE 估计，|R_true−R_OPE| ≤ |b̂|+u_anchor+(1−overlap)·B。当 overlap→0 时界发散，OPE-only 认证失效；n_A 个随机锚定试验把界拉回有限。**系：仿真/日志回放可以产生假设，但不能单独产生安全证书。**

**定理 27（FIELD 严格包含与主张保守性）** 在 A111–A116（EP 有效、漂移受控、删失可忽略且正性、SSL 账本有效、探针校准、锚定有界）下：FIELD 在组件失效时逐指令退化为 R72/R71/R68；且其报告的风险 UCB 以概率 ≥ 1−α 覆盖真实风险。**安全主张只会更保守，不会因为「评测更精致」而变得更激进。**

**定理 28（评测证书有效性 ⇒ 可证伪的效应主张）** 若 J_EVAL 有效，则在任意停时下，报告的效应/风险主张的第一类错误 ≤ α；且功效 ≥ 1−β 于声明的 MDE。**「无功效，无主张」：当效应量 < MDE 时，正确输出是「不可识别」，而不是「无显著差异 ⇒ 等价」。**

**定理 29（密封留出抑制评测过拟合）** 若开发者只通过 anytime-valid 验证通道获取反馈，最终指标在密封留出集（大小 n_seal）上一次性计算，则对可适应选择的假设类 ℋ，泛化间隙 ≤ O(√(log|ℋ|/n_seal))。**系：密封留出集是「评测过拟合」的唯一硬约束；预注册只约束分析自由度，不替代留出数据。**

**定理 30（SSL 账本 + 校准探针 ⇒ 表征不劣化）** 若每条不变性在其有效域上可采纳、探针覆盖率 ≥ 1−α，则 SSL 增强估计器的风险 UCB 不劣于同域非 SSL 估计器（至多差一个校准松弛）；仅当不变性确为 nuisance 时才严格更优。**系：SSL 带来的是「样本效率」，不是「安全豁免」；账本把这份效率变成可审计的。**

## 6. 本轮最大风险

**一句话**：FIELD-GAUGE-RAS 把安全从「相信部署证书」转移到「相信 **评测本身无偏**、相信 **删失可忽略**、相信 **SSL 不变性恰好没删掉安全信号**」——**如果安全层把最危险的失败都删失了，而删失倾向模型又建立在「可忽略」这个无法检验的假设上；如果硬件漂移与处理效应不可分，而区组化只在小样本上做做样子；如果 SSL 的一致性探针在分布外与误差反相关，而 conformal 校准只给了边际覆盖、分层覆盖率从未被检查——那么系统会拿着一份「预注册过、密封过、anytime-valid、带 UCB」的证书，报告一个统计上无可挑剔、物理上完全错误的安全率：它不是「不知道自己不知道」，而是「用正确的统计学证明了一个被删失和漂移偷偷改写过的世界」。**

次级风险与缓解：
1. **删失不可忽略** → 报告敏感性分析（不同 e-model、E-value 式界）；高危动作在仿真/HIL 中做**故障注入**补足，不把真机删失当安全。
2. **漂移被漏检** → 在线 change-point + 硬件状态探针；平稳性证书**定期失效**并强制重标定；区组大小按漂移上界自适应。
3. **SSL 探针反相关** → 单向安全钳（只能抬 λ）；分层覆盖率报告；用独立 z_audit 做反相关检验；失败即降级为监督特征。
4. **评测过拟合/密封泄漏** → 密封留出集 + 一次性开封 + 密钥隔离；泄漏检测（membership/最近邻/交换掉点）纳入 J_EVAL。
5. **稀有事件样本不足** → SSL 提议的 AST + 重要性采样 + 真实性预算；报告 ESS 与方差上界，ESS 不足则拒绝主张。
6. **锚定试验本身被挑樱桃** → 锚定试验也必须预注册 + 随机化 + 盲法；b̂ 与 u_anchor 一起报告。
7. **复杂度的元风险** → 评测协议本身的复杂度纳入审计；字段化 J_FIELD，每个 veto 一条可复算证明；限制 |𝒜|、|ℰ_eval| 条目数，避免「用复杂度掩盖不可识别」。

> - SSL 的每条增广不变性是否**删掉了安全信号**？一致性探针在 OOD 下是否与误差反相关？
> - 训练/评测/审计是否共用同一表征，形成**自我指涉的评测闭环**？
>
> 本轮两个灵感补齐：
> - **真机评测（EVAL）**：把评测升级为**被计量的仪器**——预注册、区组随机化、删失建模、anytime-valid 证据、稀有事件 AST、锚定试验、密封留出；安全主张从点估计改为**带覆盖保证的 UCB**（「无功效，无主张」）。
> - **自监督学习（SSL）**：把 SSL 升级为**被审计的测量仪器**——不变性因果账本、探针 conformal 校准与单向安全钳、训练/评测/审计三套表征分离与泄漏检测（「不变性即安全断言」）。
>
> 核心命题：**从「我的系统在真机上安全吗」进化为「我用来证明它安全的评测与表征，本身可信吗？」** ——**可证伪的现场证据闭环**。
>
> IP 编号：IP-295~304（共 10 个）。理论姿态延续 R71–R72：**新层是旧层的严格泛化，安全侧只增不减，退化链逐指令等价，且主张必须可证伪。**

## 2. 形式化定义（要点版）

**定义 366（FIELD 总览与六不变式）** 评测先行、证据有序、删失显式、漂移可分、自监督可审计、严格退化。**任何 J_EMB 主张缺 J_EVAL 即无效。**

**定义 367（评测协议 EP）** EP 有效 ⇔ 预注册哈希匹配 ∧ 设计在 MDE 处功效 ≥ 1−β ∧ 估计量与设计相容。

**定义 368（评测不确定度预算）** u_eval² 六分量；每个分量带追溯链；**效应量 < u_eval ⇒ 主张不可识别**（不是「无差异」）。

**定义 369（硬件状态与漂移）** y_t=f(x_t,a_t,h_t)+ε；顺序 A/B 的偏差 E[h_B−h_A]；区组随机化 + 平衡配对 + 顺序平衡；平稳性证书 S_eval 要求区组内漂移 ≤ δ_h。

**定义 370（安全删失与 IPCW）** 观测风险 ≤ 真实风险；可忽略删失 + 正性下 IPCW 无偏；报告 e-model、正性、ESS；**ESS 过小 ⇒ 主张无效**。

**定义 371（anytime-valid 证据）** e-process 在任意停时保持 α；证据账本记录每次查看；**事后挑窗口/换指标即失效**。

**定义 372（稀有事件 AST）** SSL 提议 q + 重要性采样 + 真实性预算；报告 ESS/方差上界；**防止 AST 生成物理上不可能的失败**。

**定义 373（锚定试验 ANCHOR）** 最小随机真机试验估 b̂ 与 u_anchor；**禁止 OPE-only 认证**；|R_true−R_OPE| ≤ |b̂|+u_anchor+(1−overlap)·B。

**定义 374（SSL 不变性账本）** I_f:z(g_f(x))=z(x)；N_f:Y⫫f|Pa(Y)；有效域 D_f；**I_f 仅在 D_f 上可采纳**，否则为不安全不变性。

**定义 375（SSL 探针与校准）** u_SSL=C(r_SSL)；覆盖率 ≥1−α；报告分层条件覆盖与反相关检验；**u_SSL 只允许抬高 λ，单独不得降低 λ**。

**定义 376（表征来源分离）** z_train/z_eval/z_audit 不同切分/种子/模型族；泄漏检验 membership/最近邻/交换掉点；循环指数 CI 高 ⇒ J_SSL 降级。

**定义 377（密封评测 SEAL-EVAL）** 密钥隔离、盲法、R_hold/U_hold/E_hold 留出、预注册提交、分析冻结、一次性开封；在线只走 anytime-valid 通道。

**定义 378（评测证书 J_EVAL）** Valid ⇔ 预注册匹配 ∧ 功效达标 ∧ 漂移受控/区组化 ∧ 删失正性/ESS 达标 ∧ 锚定偏差有界 ∧ anytime-valid 证据通过 ∧ 泄漏低于阈值。**Valid ⇒ 主张以 UCB/置信序列表述。**

**定义 379（自监督证书 J_SSL）** Valid ⇔ 每条不变性在有效域可采纳 ∧ 探针覆盖率达标 ∧ CI 低 ∧ 语料来源完整。

**定义 380（FIELD 证书 J_FIELD）** Valid ⇔ J_EMB ∧ J_EVAL ∧ J_SSL ∧ 未使用删失样本的朴素频率。

**定义 381（威胁模型 AIC-FIELD）** ℰ_eval={p-hacking、协议漂移、基准泄漏、评测过拟合、漂移伪装、删失操纵、稀有事件欠采样、锚定挑樱桃、盲法破坏}；ℰ_ssl={增广投毒、不安全不变性、探针反相关、表征塌缩、评测泄漏、语料污染、shortcut 注入}。

# IP-296 DRIFT-LEDGER：硬件状态、区组随机化、平稳性证书
class DriftLedger:
    def update(self, h_obs):
        self.h, self.cp = change_point(self.hist + [h_obs])
        return self.h
    def assign_block(self, x):
        return balanced_randomize(x, self.h)          # 区组内随机、顺序平衡
    def stationarity_cert(self):
        return self.cp is None and self.drift_ub <= DELTA_H

# IP-297 CENSOR-IPCW：删失倾向 + IPCW + ESS
class CensorIPCW:
    def fit(self, trials):
        self.e = fit_propensity(trials.x, trials.not_censored)
    def estimate(self, trials):
        w = 1.0 / self.e.predict(trials.x)
        r = np.mean(trials.y * trials.not_censored * w)
        ess = w.sum()**2 / (w**2).sum()
        return RiskEstimate(r=r, ess=ess)
    def certify(self):
        return self.e.min() >= EPS_POS and self.ess >= ESS_MIN

# IP-298 POWER-SEQ：anytime-valid e-process
class AnytimeEvidence:
    def __init__(self, alpha, n_max):
        self.alpha, self.n_max, self.E, self.ledger = alpha, n_max, 1.0, []
    def update(self, x):
        self.E *= self._likelihood_ratio(x)           # H1 vs H0
        self.ledger.append((len(self.ledger), self.E))
        return self.E
    def decision(self):
        if self.E >= 1/self.alpha: return 'REJECT'
        return 'ACCEPT_H0' if len(self.ledger) >= self.n_max else 'CONTINUE'

# IP-299 RARE-AST：SSL 提议 + 重要性采样 + 真实性预算
class RareEventAST:
    def __init__(self, ssl_world_model, rho):
        self.q, self.rho = ssl_world_model, rho
    def estimate(self, n):
        xs = self.q.sample(n)
        w = self.q.p_data(xs) / self.q.q(xs)
        p_hat, ess = np.mean(self.q.failure(xs) * w), ess_of(w)
        assert self.q.kl_to_data() <= self.rho    # 真实性预算
        return p_hat, ess

# IP-300 ANCHOR：锚定偏差修正（禁止 OPE-only）
def anchor_correct(ope, real_trials, budget):
    if len(real_trials) < N_MIN: return None
    b_hat = mean(real_trials.y) - mean(ope.on(real_trials))
    u_anchor = se(real_trials)
    return BiasCorrected(est=ope.value - b_hat,
                         bound=abs(b_hat) + u_anchor + (1-overlap)*B)

# IP-301 SSL-LEDGER：不变性因果审计
@dataclass
class InvarianceEntry:
    factor: str; transform: Callable; nuisance_claim: str
    domain: set; test_stat: float; p_or_effect: float; tau: bytes

class SSLLedger:
    def audit(self, factor, transform, causal_test, context):
        return InvarianceEntry(
            factor, transform, f"Y ⟂ {factor} | Pa(Y)",
            causal_test.domain, causal_test.stat, causal_test.p,
            hash_chain(causal_test))
    def admit(self, entry, context):
        return entry is not None and context in entry.domain

# IP-302 SSL-PROBE：一致性残差 + 校准 + 单向安全钳
class SSLProbe:
    def __init__(self, encoder, calibrator):
        self.z, self.C = encoder, calibrator
    def residual(self, views):
        return discrepancy([self.z(v) for v in views])
    def u(self, x):
        r = self.residual(views(x))
        u = self.C.quantile(r)                        # conformal 校准
        if self.C.anticorrelated(r): u = max(u, U_FLOOR)
        return u                                      # 只用于抬高 λ
    def risk_scale(self, lam_base, u_ssl):
        return max(lam_base, lam_base * (1 + u_ssl / LAM_SCALE))

# IP-303 FIELD 主闭环：评测即试验，试验即证据
def FIELD_round(M, policy, ep):
    h    = M.drift.update(M.h_obs())
    cond = M.drift.assign_block(M.context)           # 先看硬件，再分配
    a    = policy.act(M.obs)
    censored = not M.safety.allows(a)                # 安全包络删失
    y, x = (None, M.context) if censored else M.world.step(a)
    ev   = M.power.update((x, y, censored))          # anytime-valid
    M.censor.add(x, not censored, y)
    if M.clock.due_anchor():
        M.anchor = anchor_correct(M.ope, M.sample_real(N_ANCHOR), M.budget)
    u_ssl = M.probe.u(M.obs)
    lam   = M.probe.risk_scale(M.lam_base, u_ssl)    # 单向抬升
    return J_FIELD(M, ev, lam, M.censor.certify(), M.drift.stationarity_cert())

# IP-304 SEAL-EVAL：密封留出 + 一次性开封
def sealed_final_eval(M, policy, K):

    R_hold, U_hold, E_hold = K.unseal()
    trials = run_blinded(policy, R_hold, U_hold, E_hold)

## 4. 推导（要点版）

**引理 33（零失败不是安全）** 0/n 的 95% 上界 p ≤ 1−0.05^{1/n} ≈ 3/n：n=30 ⇒ 9.5%，n=100 ⇒ 2.95%，n=300 ⇒ 0.99%。**任何「零 hard safety violation」必须附 n 与 UCB。**

**引理 34（删失偏差与 IPCW）** R_obs=E[Y·1[未被删失]] ≤ R_true；可忽略 + 正性下 E[R̂_IPCW]=R_true；Var∝1/ESS。**安全层拦下的恰是最危险样本，所以「零事故」是删失证据，不是安全证据。**

**引理 35（漂移混淆）** 顺序 A/B 偏差 = E[h_B−h_A]；区组随机化 + 条件化把偏差压到 ≤L_h·δ_h；顺序平衡消一阶时间效应。**效应量小于漂移幅度时，符号都可能反。**

**引理 36（不安全不变性 ⇒ 风险界失效）** 若 f 是 Y 的因果父节点却被强制不变，则存在同表征不同风险的点；若 I(Y;f|z)>0，z 不是充分统计量，误差不可由更多数据消除。**每条 SSL 不变性都是需要证明的安全断言。**

**引理 37（探针反相关）** r_SSL 与 err 的相关符号在 OOD 不保证为正；未校准直接用会把 λ 做反；conformal 只给边际覆盖。**u_SSL 必须单向抬 λ，并报告分层覆盖。**

**引理 38（锚定偏差界）** |R_true−R_OPE| ≤ |b̂|+u_anchor+(1−overlap)·B；overlap→0 时界发散。**仿真/日志只产生假设，不单独产生安全证书。**

**定理 27（严格包含与主张保守性）** A111–A116 下 FIELD 逐指令退化为 R72/R71/R68；风险 UCB 以概率 ≥1−α 覆盖真值。

**定理 28（评测证书 ⇒ 可证伪主张）** J_EVAL 有效 ⇒ 任意停时下第一类错误 ≤α，MDE 处功效 ≥1−β。**无功效，无主张；效应 < MDE ⇒ 「不可识别」，不是「等价」。**

**定理 29（密封留出抑制评测过拟合）** 反馈只经 anytime-valid 通道，最终指标在 n_seal 密封集一次性计算 ⇒ 泛化间隙 ≤O(√(log|ℋ|/n_seal))。**预注册约束分析自由度，但不能替代留出数据。**

**定理 30（账本 + 校准探针 ⇒ 表征不劣化）** 有效域可采纳 + 覆盖率 ≥1−α ⇒ SSL 风险 UCB 不劣于同域非 SSL（差一校准松弛）；仅真 nuisance 时严格更优。**SSL 给样本效率，不给安全豁免。**

## 5. 数值示例（把「零失败」翻译成 UCB）

| 零失败次数 n | 95% 上界 1−0.05^{1/n} | 可支持的主张 |
|---|---|---|
| 10 | 25.9% | 仅「失败率 <26%」 |
| 30 | 9.5% | 仅「失败率 <9.5%」 |
| 100 | 2.95% | 仅「失败率 <3%」 |
| 300 | 0.99% | 可支持「<1%」（近似） |
| 1000 | 0.30% | 可支持「<0.5%」 |

**删失示例**：真实失败率 10%，安全层拦掉一半危险动作，朴素观测 5%；若 e(x) 可估且正性成立，IPCW 回到 10%，但 ESS 从 1000 降到约 500。**不报 ESS 的 IPCW 和朴素频率一样不可信。**

**漂移示例**：真实方法效应 +5%，一整天硬件漂移 +8%；先 A 后 B 的朴素估计 ≈ +13%（虚高），先 B 后 A ≈ −3%（符号反）。**区组化 + 每区组随机化后才回到 +5%±区组界。**

## 7. 本轮最大风险

**一句话**：FIELD-GAUGE-RAS 把安全从「相信部署证书」转移到「相信 **评测本身无偏**、相信 **删失可忽略**、相信 **SSL 不变性恰好没删掉安全信号**」——**如果安全层把最危险的失败都删失了，而删失倾向模型建立在无法检验的「可忽略」假设上；如果硬件漂移与处理效应不可分，区组化只在小样本上做样子；如果 SSL 一致性探针在 OOD 与误差反相关，而 conformal 只给边际覆盖、分层覆盖从未被检查——那么系统会拿着一份「预注册过、密封过、anytime-valid、带 UCB」的证书，报告一个统计上无可挑剔、物理上完全错误的安全率：它不是「不知道自己不知道」，而是「用正确的统计学证明了一个被删失和漂移偷偷改写过的世界」。**

次级风险与缓解：
1. **删失不可忽略** → 删失敏感性分析 + 仿真/HIL 故障注入补足；不把真机删失当安全。
2. **漂移漏检** → 在线 change-point + 硬件探针；平稳性证书定期失效并强制重标定；区组大小自适应。
3. **SSL 探针反相关** → 单向安全钳（只抬 λ）；分层覆盖率；独立 z_audit 做反相关检验；失败即降级。
4. **评测过拟合/密封泄漏** → 密封留出 + 一次性开封 + 密钥隔离；membership/最近邻/交换掉点纳入 J_EVAL。
5. **稀有事件样本不足** → SSL-AST + 重要性采样 + 真实性预算；ESS 不足则拒绝主张。
6. **锚定挑樱桃** → 锚定试验也预注册/随机/盲法；b̂ 与 u_anchor 一起报。
7. **复杂度元风险** → 评测协议复杂度纳入审计；限制 |𝒜|、|ℰ_eval|；每个 veto 一条可复算证明，避免「用复杂度掩盖不可识别」。
