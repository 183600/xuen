# 第 67 轮（承接第 66 轮「RAS 情绪驱动闭环」IP-224~233；灵感循环第 4 轮；本轮灵感：「同步定位与建图」×「力矩控制」）

> 第 65 轮 VISTA 解决了「哪一层坏了」（故障可归因），第 66 轮 RAS 把「被动故障响应」升级为「主动意图感知」（用面部表情捕获风险态度、用 `λ_risk` 缩放控制）。但两轮都有一个共同的盲点：**它们始终把「感知」与「执行」当作两个先后相接的环节**——先用外感信号（视觉、表情）估计状态，再决定动作。动作本身从不被当作「测量」。
>
> 本轮把镜头转向另一条主轴：
>
> **让机器人用自己的动作去「摸」自己的地图。** 同步定位与建图（SLAM）是「估计几何」，力矩控制是「调节接触」。传统上它们是两个时标、两个回路：SLAM 出地图 → 规划器 → 刚性/阻抗控制器。TANGO 把二者拧成一个**接触对偶控制**回路：力矩既是控制输出，也是射向 SDF 地图的「物理探针」；地图协方差既是估计结果，也是阻抗律的输入。
>
> 一句话命题：**SLAM 的不确定性决定「力矩该多硬」，力矩的残差决定「地图该多准」**。这是 Feldbaum 对偶控制（dual control：控制信号同时承担「调节」与「探测」）在接触物理中的落地。

## 0. 直觉与动机

**灵感 1（SLAM → 力矩控制：地图是柔顺的先验）**
直觉：今天 SLAM 与阻抗控制是解耦的——地图交给规划器，规划器交给一个「假装地图很准」的刚性控制器。可地图协方差其实精确地告诉了你「哪个方向不能硬」。如果某个表面的法向位置方差很大，控制器就该沿那个方向变软、并限制接触力；反之若地图很确定，就该变硬以提高任务精度。于是阻抗参数不应是手调常数，而应是**地图后验协方差的函数**：`K_n = K_0 / (1 + κ_M/κ_0)`，其中 `κ_M` 是法向位置方差。这把「地图不确定性」从纸面指标变成了可执行的控制律。

**灵感 2（力矩 → SLAM：接触是射入几何的探针）**
直觉：视觉只能看见「看得见的表面」；而力矩能感知「正在摸的表面」。末端力/力矩本质上是接触法向 × 穿透深度经雅可比投影后的结果——它等价于一条**触觉光线**：不是测「到表面的距离」，而是测「距离场在接触点的梯度 × 穿透量」。在抽屉内壁、物体底面、两指之间这些视觉被遮挡的区域，力矩是唯一可用的几何传感器。把力矩残差当作 SLAM 的新因子，就在视觉退化方向上重新注入了可观测量。

**灵感 3（主动耦合：安全的「力矩抖动」就是主动 SLAM）**
直觉：主动 SLAM 会移动相机以降低地图熵；TANGO 则施加**力锥内、位移受限的小幅力矩抖动**，用其反作用读出局部表面几何。抖动的选择遵循「单位任务扰动下信息增益最大」：`τ* = argmax [β·IG(M; τ) − J_task(τ) − λ·risk(τ)]`。这不是给控制加噪声，而是把「探测」正式写成控制目标的一项——即对偶控制里「caution vs probing」的权衡，只不过这里的试探信号是通过真实接触实现的。

**灵感 4（对偶残差归因：区分「我地图错了」与「有人推我」）**
直觉：经典 SLAM 的创新残差（位姿残差 `r_T`）在力矩空间有一个对偶（力残差 `r_τ`）。单看任一残差都分不清故障来源；但二者的**跨协方差** `Cov(r_T, r_τ)` 是独特指纹：
- 地图误差 → `r_T` 与 `r_τ` 沿同一接触子空间**相关**地出现；
- 外部扰动 → 只有 `r_τ`，`r_T ≈ 0`；
- 力矩传感器偏置 → `r_τ` 呈持续结构但 `r_T ≈ 0`；
- 定位漂移 → 只有 `r_T`。

这正是 VISTA「故障可归因」主题的物理延伸：VISTA 用外感残差归因，TANGO 增加了一条**可主动激励**的接触通道，使「地图 vs 外力 vs 偏置」从不可分变为可分。

**灵感 5（合流 → TANGO）**
`TANGO = (CSF, TSD, CMT, ATD, MAC, DRA, DCC, AIC-T)`：
1. **CSF Contact-SLAM Fusion**：位姿、SDF 地图、接触力旋量、接触模式进入同一个因子图；
2. **TSD Torque-SDF Dual**：建立「力矩 ↔ SDF」的桥接雅可比 `O_c`，量化接触可观测性；
3. **CMT Contact Mode Tracker**：以 FREE/STICK/SLIP 混合滤波跟踪接触模式；
4. **ATD Active Torque Discovery**：按信息增益选择安全探测力矩；
5. **MAC Map-Aware Compliance**：用地图协方差调制阻抗与力饱和；
6. **DRA Dual Residual Attribution**：对偶残差联合归因（承接 VISTA/RAS）；
7. **DCC Dual-Consistency Certificate**：输出 `J_TANGO` 证书；
8. **AIC-T**：干扰集扩到接触软材料、粘滑、形变与共因（质量/摩擦失配）。

## 1. 直觉之后：严谨定义（增量：定义 251–268）

- **定义 251（TANGO 总览）** `TANGO = (CSF, TSD, CMT, ATD, MAC, DRA, DCC, AIC-T)`。定位：把 SLAM 几何估计与力矩接触调节统一为「接触对偶控制」。不变式：语义流负责 SDF 更新、接触模式后验、信息增益规划与证书；实时流（≥1kHz）只做力矩前馈、阻抗执行、力锥投影与接触事件检测，**零地图写回**。
- **定义 252（联合状态）** `ξ_t = (T_t ∈ SE(3), M_t: ℝ³→ℝ, w_t ∈ ℝ⁶, c_t ∈ C)`：位姿、SDF 地图、末端力旋量、接触模式（每接触 `∈ {FREE, STICK, SLIP}`）。
- **定义 253（SDF 与接触投影）** 符号距离 `φ_M(x)`；接触候选 `C_t = {i : φ_M(T_t p_i) ≤ δ_reg}`；投影点 `p_i^⊥ = x − φ_M(x)∇φ_M(x)`；法向 `n_i = ∇φ_M(p_i^⊥)`；穿透 `δ_i = max(0, −φ_M(T_t p_i))`。
- **定义 254（接触力模型）** 罚函数接触 `f_i = (k_c δ_i + d_c δ̇_i) n_i + f_i^t`，摩擦锥 `|f_i^t| ≤ μ_i f_i^n`；总旋量 `w = Σ_i Ad^T_{T,p_i} f_i`。
- **定义 255（力矩观测模型）** `τ_meas = J^T(T, M, c) w + b_τ + ε_τ`，`b_τ` 含重力、摩擦与零偏，`J` 为接触雅可比。
- **定义 256（力矩–SDF 桥接雅可比）** `O_c = ∂τ/∂(T,M) = J^T (∂w/∂φ)(∂φ/∂(T,M)) + (∂J^T/∂(T,M)) w`。它把「地图/位姿不确定性」映射为「力矩变化」，其秩即**接触可观测性**。
- **定义 257（接触信息增益）** `G_c = O_c^T R_τ^{-1} O_c`；探测序列的信息增益 `IG = ½ log det(I + Σ_{ξ|t}^{1/2} G_c Σ_{ξ|t}^{1/2})`。接触未激活（`δ=0`）时 `O_c=0 ⇒ IG=0`。
- **定义 258（主动力矩探测）** `τ*_t = argmin_{τ∈U_safe} [ J_task(τ) − β_t·IG(τ|ξ_t) + λ_s·risk(τ) ]`，`U_safe = {τ: |τ|≤τ_max, 摩擦锥余量≥ε, 预测位移≤d_max}`；`β_t` 随地图收敛退火。
- **定义 259（接触模式混合滤波）** 信念 `b_t(c)`；转移：`STICK→SLIP` 当 `|f^t| > μ f^n − ε_slip`；`FREE→STICK` 于接触事件；`SLIP→STICK` 当相对速度 `< v_stick`。按模式条件似然做预测/更新。
- **定义 260（对偶残差）** 位姿残差 `r_T = T_t^meas ⊖ T_t^pred ∈ ℝ⁶`，力残差 `r_τ = τ_meas − τ_pred(M,T,c) ∈ ℝ^{6n}`；堆叠 `r = [r_T; r_τ]`。零假设下 `r ~ N(0, Σ_dual)`，其**非对角块** `C_TP = Cov(r_T, r_τ)` 是关键。
- **定义 261（对偶残差归因假设）** `H = {H0 正常, H_map 地图误差, H_ext 外力, H_τbias 力矩偏置, H_pose 定位漂移, H_calib 标定误差, H_common 共因}`。每个假设规定 `r` 的子空间结构（如 `H_ext: r_τ∈range(O_ext), r_T≈0`；`H_map: r_T,r_τ` 经 `O_c` 相关），后验 `∝ exp(−½ r^T Σ_H^{-1} r)P(H)`。
- **定义 262（地图感知阻抗）** 法向刚度 `K_n(κ_M)=K_0/(1+κ_M/κ_0)`，阻尼 `D_n=2ζ√(K_n m)`，切向同步缩放；`κ_M = n^T Σ_{x|t} n`；力饱和 `f_max(κ_M)=f_0+f_exp·min(1,κ_M/κ_0)`。高不确定 → 柔顺 + 有界探测力；低不确定 → 增硬以提精度。
- **定义 263（对偶一致性谓词）** `DualConsistent(ξ,z) ⇔` (1) 摩擦锥满足；(2) `r^T Σ_dual^{-1} r ≤ χ²_{6+6n,1−α}`；(3) SDF 一致：接触点距表面 `≤τ_geo` 且穿透 `∈[0,δ_max]`；(4) 接触模式后验熵 `≤ H_max`。
- **定义 264（J_TANGO 证书）** `J_TANGO=(J_slam, J_compliance, r_dual, attribution_posterior, tr(Σ_M), b(c), rank(O_c), IG_achieved, aic_t_ver)`；`Valid ⇔ DualConsistent ∧ J_slam.Valid ∧ K_n ≥ K_min`。
- **定义 265（AIC-T 干扰与共因）** `E_T = E_vision × E_contact × E_dynamics × E_common`，其中 `E_contact = {软材料, 粘滑, 形变, 接触丢失}`，`E_common = {质量/惯量失配 → 位姿与力矩残差相关, 摩擦失配 → 表观地图偏移}`。
- **定义 266（双频契约）** 语义流（10–50Hz）做 SDF 更新、接触后验、IG 规划、证书；实时流（≥1kHz）做前馈、阻抗、力锥投影、接触事件；**只有实时流碰执行器**，语义流只下发偏置与边界，绝不下发逐拍力。
- **定义 267（探测安全包络）** 预算 `B_τ`；`risk(τ)=` 越锥力 + 越限穿透 + 任务偏离；`β_t ≤ β_max·1[task_phase 允许]`。
- **定义 268（TANGO 轮次契约）** 输入 `obs`，输出 `(a*_t, τ_t, J_TANGO)`；优先级：安全（力锥/穿透）> 对偶一致 > 任务精度；不一致时回退到「先验地图 + 纯阻抗」的安全降级。

class TorqueSDFDual:                       # TSD
    def contact_wrench(self, T, M, c):
        w = zero6()
        for i, p in enumerate(c.points):
            phi = M.sdf(T @ p)
            if phi > 0:                    # 无接触
                continue
            n = M.normal(T @ p); delta = -phi
            f_n = c.k_c * delta + c.d_c * c.delta_dot[i]
            f = f_n * n + friction(c.mu, c.v_t[i])
            w = w + adjoint_T(T, p).T @ f
        return w

    def bridging_jacobian(self, T, M, c):
        return jacobian(self.contact_wrench, (T, M))   # O_c


class ContactModeTracker:                  # CMT
    def update(self, b_prev, tau, T, M):
        pred = predict_mode(b_prev, tau)
        lik  = mode_likelihood(tau, T, M)  # FREE / STICK / SLIP
        return normalize({m: pred[m] * lik[m] for m in MODES})


class ActiveTorqueDiscovery:               # ATD
    def choose(self, xi, Sigma, beta, envelope):
        best, best_obj = None, -inf
        for tau in candidate_probes(envelope):
            O_c = xi.torque_sdf.bridging_jacobian(xi.T, xi.M, xi.c)
            G   = O_c.T @ inv(R_tau) @ O_c
            ig  = 0.5 * logdet(I + sqrtm(Sigma) @ G @ sqrtm(Sigma))
            obj = -task_cost(tau) + beta * ig - lam_s * risk(tau)
            if envelope.safe(tau) and obj > best_obj:
                best, best_obj = tau, obj
        return best


def tango_round(M, obs):
    # --- 语义流（10–50Hz） ---
    T_pred = M.slam.predict(obs.imu, obs.wheel)
    b_c    = M.cmt.update(M.b_c, obs.tau, T_pred, M.M)
    T_hat, M.M = M.csf.optimize(T_pred, M.M, obs.img, obs.depth,
                                obs.tau, b_c)          # 联合因子图
    r_T, r_tau = M.slam.innovation(T_hat, obs.tau, M.M, b_c)
    post_H = M.dra.attribute(r_T, r_tau, M.Sigma_dual, M.M, b_c)
    O_c = M.tsd.bridging_jacobian(T_hat, M.M, b_c)
    kappa_M = normal_variance(M.Sigma_x, M.M, b_c)
    K_n = M.mac.stiffness(kappa_M)
    beta = M.atd.probe_gain(M.Sigma_x, post_H)
    tau_probe = M.atd.choose(State(T_hat, M.M, b_c), M.Sigma_x,
                             beta, M.envelope)
    J = M.dcc.certify(T_hat, M.M, r_T, r_tau, post_H, b_c, kappa_M)

    if not J.valid:
        return M.fallback_impedance(obs), J      # 安全降级

    # --- 实时流（≥1kHz） ---
    tau_cmd = M.imp.compute(T_hat, K_n, tau_probe)
    tau_cmd = M.cone.project(tau_cmd, b_c, M.envelope)
    return tau_cmd, J

## 3. 推导

**引理 11（接触信息增益的单调性与遮挡优势）** 对罚函数接触，`IG` 随穿透 `δ` 与法向刚度 `k_c` 单调增，FREE 时 `IG=0`；且在视觉不可观测子空间（`O_v` 的零空间）上，`rank(O_c)>0 ⇔ 接触法向在该子空间有分量`。故对遮挡几何，力矩严格优于视觉。
*证明要点*：`G_c=O_c^T R_τ^{-1}O_c ⪰ 0`，`det(I+Σ^{1/2}G_cΣ^{1/2})` 随 `k_cδ` 单调；在 `O_v` 零空间内 `O_v=0`，任何具该方向分量的接触都会提升秩。

**引理 12（地图误差与外力的可辨识性）** 从 `r=(r_T,r_τ)` 可辨识 `(δM, f_ext)` 当且仅当 `O_c` 在接触子空间上满列秩；否则 `δM` 与 `f_ext` 落同一力子空间而混淆。主动探测通过激励独立接触方向提升 `rank([O_c, O_ext])`。
*证明要点*：两个未知量对 `r_τ` 的贡献为 `O_cδM + O_ext f_ext`，可分离 ⇔ 联立矩阵满秩。

**定理 11（对偶一致性安全界）** 若 `DualConsistent` 以置信度 `1−α` 成立且 `K_n` 按定义 262 取值，则执行力旋量误差 `‖w−w*‖ ≤ √(λ_max(Σ_dual))·χ`、穿透 `≤δ_max` 均以概率 `≥1−α` 成立；因此在有效 `J_TANGO` 下执行的任务，其接触力被限定在证书力锥与几何包络内。

**定理 12（主动探测的样本复杂度）** 在安全包络下按贪心 IG 选探针，位姿-地图后验的微分熵满足 `H_{N+1} ≤ H_N − ½ log(1 + SNR·σ_c)`，`σ_c` 为 `Σ^{1/2}G_cΣ^{1/2}` 最小非零特征值；故置信椭球体积缩至 `γ` 需 `N = O((1/SNR)·log(1/γ))` 次有效接触，而视觉在遮挡方向秩亏、需无界样本。

## 6. 本轮最大风险

**一句话**：TANGO 的核心假设是「接触力矩是地图的可靠几何探针、且其似然模型足够准，使地图误差与外力可联合辨识」——但真实接触是软的、有摩擦滞回、会磨损与滑移，一旦接触模型失配，对偶残差就会把「我自己的地图误差」误判成「外部扰动」（或反之），而主动探测又会用更大的接触力放大这一失配，形成「模型误差 → 错误归因 → 更大探测力 → 更大模型误差」的自激闭环，可能既毁任务又磨损/损伤接触面。

## 2. 形式化定义（完整版）

**定义 251（TANGO 总览）** TANGO 把 SLAM 几何估计与力矩接触调节统一为「接触对偶控制」：
```
TANGO = (CSF, TSD, CMT, ATD, MAC, DRA, DCC, AIC-T)
```
不变式：语义流负责 SDF 更新、接触模式后验、信息增益规划与证书构建；实时流（≥1kHz）只做力矩前馈、阻抗执行、力锥投影、接触事件检测，**零地图写回**。

**定义 252（联合状态）**
```
ξ_t = (T_t ∈ SE(3), M_t: ℝ³→ℝ, w_t ∈ ℝ⁶, c_t ∈ C)
```
其中 `c_t` 为每接触模式，取值于 `{FREE, STICK, SLIP}`。

**定义 253（SDF 与接触投影）**
```
C_t = { i : φ_M(T_t p_i) ≤ δ_reg }
p_i^⊥ = x − φ_M(x)·∇φ_M(x),  n_i = ∇φ_M(p_i^⊥)
δ_i = max(0, −φ_M(T_t p_i))
```

**定义 254（接触力模型）**
```
f_i = (k_c δ_i + d_c δ̇_i) n_i + f_i^t,   |f_i^t| ≤ μ_i f_i^n
w = Σ_i Ad^T_{T,p_i} f_i
```

**定义 255（力矩观测模型）**
```
τ_meas = J^T(T, M, c) w + b_τ + ε_τ
```

**定义 256（力矩–SDF 桥接雅可比）**
```
O_c = ∂τ/∂(T,M) = J^T (∂w/∂φ)(∂φ/∂(T,M)) + (∂J^T/∂(T,M)) w
```

**定义 257（接触信息增益）**
```
G_c = O_c^T R_τ^{-1} O_c
IG  = ½ log det(I + Σ_{ξ|t}^{1/2} G_c Σ_{ξ|t}^{1/2})
```
接触未激活（`δ=0`）时 `O_c=0 ⇒ IG=0`。

**定义 258（主动力矩探测）**
```
τ*_t = argmin_{τ∈U_safe} [ J_task(τ) − β_t·IG(τ|ξ_t) + λ_s·risk(τ) ]
U_safe = { τ : |τ|≤τ_max, 摩擦锥余量≥ε, 预测位移≤d_max }
```
`β_t` 随地图收敛退火；`β_t→0` 即退化为纯任务控制。

**定义 259（接触模式混合滤波）** 信念 `b_t(c)`，转移由摩擦锥驱动：
```
STICK → SLIP  当 |f^t| > μ f^n − ε_slip
FREE  → STICK 于接触事件
SLIP  → STICK 当相对速度 < v_stick
b_t(c) ∝ p(τ_t | ξ_t, c) · Σ_{c'} P(c | c') b_{t-1}(c')
```

**定义 260（对偶残差）**
```
r_T = T_t^meas ⊖ T_t^pred ∈ ℝ⁶
r_τ = τ_meas − τ_pred(M,T,c) ∈ ℝ^{6n}
r = [r_T; r_τ] ~ N(0, Σ_dual),   C_TP = Cov(r_T, r_τ) ≠ 0
```

**定义 261（对偶残差归因假设）**
```
H = {H0 正常, H_map 地图误差, H_ext 外力, H_τbias 力矩偏置,
     H_pose 定位漂移, H_calib 标定误差, H_common 共因}
```
各假设规定 `r` 的子空间结构，例如：
- `H_ext`: `r_τ ∈ range(O_ext)`, `r_T ≈ 0`；
- `H_map`: `r_T, r_τ` 经 `O_c` 相关；
- `H_τbias`: `r_τ` 持续结构、`r_T ≈ 0`；
后验 `P(H|r) ∝ exp(−½ r^T Σ_H^{-1} r) P(H)`。

**定义 262（地图感知阻抗）**
```
K_n(κ_M) = K_0 / (1 + κ_M/κ_0)
D_n(κ_M) = 2ζ √(K_n m)
f_max(κ_M) = f_0 + f_exp · min(1, κ_M/κ_0)
κ_M = n^T Σ_{x|t} n
```

**定义 263（对偶一致性谓词）**
```
DualConsistent(ξ,z) ⇔
  (1) 摩擦锥满足：|f^t| ≤ μ f^n + ε
  (2) r^T Σ_dual^{-1} r ≤ χ²_{6+6n, 1−α}
  (3) SDF 一致：dist(p_i, surface) ≤ τ_geo 且 δ_i ∈ [0, δ_max]
  (4) 接触模式后验熵 H(b(c)) ≤ H_max
```

**定义 264（J_TANGO 证书）**
```
J_TANGO = (J_slam, J_compliance, r_dual, attribution_posterior,
           tr(Σ_M), b(c), rank(O_c), IG_achieved, aic_t_ver)
Valid ⇔ DualConsistent ∧ J_slam.Valid ∧ K_n ≥ K_min
```

**定义 265（AIC-T 干扰与共因）**
```
E_T = E_vision × E_contact × E_dynamics × E_common
E_contact = {软材料, 粘滑, 形变, 接触丢失}
E_common  = {质量/惯量失配 → 位姿与力矩残差相关,
             摩擦失配     → 表观地图偏移}
```

**定义 266（双频契约）** 语义流（10–50Hz）做 SDF 更新、接触后验、IG 规划、证书；实时流（≥1kHz）做前馈、阻抗、力锥投影、接触事件。只有实时流碰执行器；语义流只下发偏置与边界，绝不下发逐拍力。

**定义 267（探测安全包络）** 单回合探测预算 `B_τ`；
```
risk(τ) = 越锥力 + 越限穿透 + 任务偏离
β_t ≤ β_max · 1[task_phase 允许探测]
```

**定义 268（TANGO 轮次契约）** 输入 `obs = (imu, wheel, img, depth, τ, c_event)`，输出 `(a*_t, τ_t, J_TANGO)`。优先级：安全（力锥/穿透）> 对偶一致 > 任务精度；不一致时回退「先验地图 + 纯阻抗」的安全降级。

## 3. 关键算法伪代码

```python
# IP-235 TSD：力矩–SDF 桥接
class TorqueSDFDual:
    def contact_wrench(self, T, M, c):
        w = zero6()
        for i, p in enumerate(c.points):
            phi = M.sdf(T @ p)
            if phi > 0:
                continue
            n = M.normal(T @ p)
            delta = -phi
            f_n = c.k_c * delta + c.d_c * c.delta_dot[i]
            f = f_n * n + friction(c.mu, c.v_t[i])
            w = w + adjoint_T(T, p).T @ f
        return w

    def bridging_jacobian(self, T, M, c):
        return jacobian(self.contact_wrench, (T, M))   # O_c


# IP-234 CSF：联合因子图
class ContactSLAMFusion:
    def optimize(self, T_prev, M, img, depth, tau, b_c):
        factors = [
            prior(T_prev),
            visual_factor(img, T_hat, M),
            range_factor(depth, T_hat, M),
            torque_factor(tau, T_hat, M, b_c),   # 新增：力矩作为几何因子
        ]
        T_hat, M = solve(factors)
        return T_hat, M


# IP-236 CMT：接触模式混合滤波
class ContactModeTracker:
    def update(self, b_prev, tau, T, M):
        pred = predict_mode(b_prev, tau)
        lik  = mode_likelihood(tau, T, M)   # FREE / STICK / SLIP
        return normalize({m: pred[m] * lik[m] for m in MODES})


# IP-237 ATD：信息增益最优探测
class ActiveTorqueDiscovery:
    def choose(self, xi, Sigma, beta, envelope):
        best, best_obj = None, -inf
        for tau in candidate_probes(envelope):
            O_c = xi.tsd.bridging_jacobian(xi.T, xi.M, xi.c)
            G   = O_c.T @ inv(R_tau) @ O_c
            ig  = 0.5 * logdet(I + sqrtm(Sigma) @ G @ sqrtm(Sigma))
            obj = -task_cost(tau) + beta * ig - lam_s * risk(tau)
            if envelope.safe(tau) and obj > best_obj:
                best, best_obj = tau, obj
        return best


# IP-239 DRA：对偶残差归因
class DualResidualAttribution:
    def attribute(self, r_T, r_tau, Sigma_dual, M, b_c):
        r = concat(r_T, r_tau)
        post = {}
        for H, (subspace, Sigma_H) in hypotheses(Sigma_dual).items():
            r_H = project(r, subspace)
            post[H] = exp(-0.5 * r_H @ inv(Sigma_H) @ r_H) * prior[H]
        return normalize(post)


# IP-238 MAC：地图感知阻抗
class MapAwareCompliance:
    def stiffness(self, kappa_M):
        K_n = self.K0 / (1.0 + kappa_M / self.kappa0)
        return max(self.K_min, K_n)


# IP-240 DCC：对偶一致性证书
class DualConsistencyCertificate:
    def certify(self, T, M, r_T, r_tau, post_H, b_c, kappa_M):
        r = concat(r_T, r_tau)
        chi2 = r @ inv(self.Sigma_dual) @ r
        ok = (self.cone_ok(b_c) and
              chi2 <= self.chi2_thresh and
              self.sdf_ok(M, b_c) and
              entropy(b_c) <= self.H_max)
        return Cert(valid=ok, chi2=chi2, post=post_H,
                    kappa_M=kappa_M, rank_Oc=self.rank_Oc)


# IP-242 / IP-243 TANGO 轮次
def tango_round(M, obs):
    # --- 语义流（10–50Hz） ---
    T_pred = M.slam.predict(obs.imu, obs.wheel)
    b_c    = M.cmt.update(M.b_c, obs.tau, T_pred, M.M)
    T_hat, M.M = M.csf.optimize(T_pred, M.M, obs.img, obs.depth,
                                obs.tau, b_c)
    r_T, r_tau = M.slam.innovation(T_hat, obs.tau, M.M, b_c)
    post_H = M.dra.attribute(r_T, r_tau, M.Sigma_dual, M.M, b_c)
    kappa_M = normal_variance(M.Sigma_x, M.M, b_c)
    K_n = M.mac.stiffness(kappa_M)
    beta = M.atd.probe_gain(M.Sigma_x, post_H)
    tau_probe = M.atd.choose(State(T_hat, M.M, b_c), M.Sigma_x,
                             beta, M.envelope)
    J = M.dcc.certify(T_hat, M.M, r_T, r_tau, post_H, b_c, kappa_M)

    if not J.valid:
        return M.fallback_impedance(obs), J         # IP-243 安全降级

    # --- 实时流（≥1kHz） ---
    tau_cmd = M.imp.compute(T_hat, K_n, tau_probe)
    tau_cmd = M.cone.project(tau_cmd, b_c, M.envelope)
    return tau_cmd, J
```

## 4. 推导

**引理 11（接触信息增益的单调性与遮挡优势）** 对罚函数接触，`IG` 随穿透 `δ` 与法向刚度 `k_c` 单调增，FREE 时 `IG=0`；且在视觉不可观测子空间（`O_v` 的零空间）上，`rank(O_c)>0 ⇔ 接触法向在该子空间有分量`。因此对遮挡几何，力矩严格优于视觉。

*证明要点*：`G_c = O_c^T R_τ^{-1} O_c ⪰ 0`；`det(I + Σ^{1/2}G_cΣ^{1/2})` 随 `G_c` 单调，而 `G_c ∝ (k_c δ)²`；在 `O_v` 零空间内 `O_v=0`，任何具该方向法向分量的接触都提升 `rank`。∎

**引理 12（地图误差与外力的可辨识性）** 从 `r=(r_T,r_τ)` 可辨识 `(δM, f_ext)` 当且仅当 `O_c` 在接触子空间上满列秩；否则 `δM` 与 `f_ext` 落同一力子空间而混淆。主动探测通过激励独立接触方向提升 `rank([O_c, O_ext])`。

*证明要点*：二者对 `r_τ` 的贡献为 `O_c δM + O_ext f_ext`；可分离 ⇔ `[O_c, O_ext]` 满列秩。∎

**定理 11（对偶一致性安全界）** 若 `DualConsistent` 以置信度 `1−α` 成立且 `K_n` 按定义 262 取值，则执行力旋量误差 `‖w−w*‖ ≤ √(λ_max(Σ_dual))·χ`、穿透 `≤ δ_max` 均以概率 `≥1−α` 成立；因此在有效 `J_TANGO` 下执行的任务，其接触力被限定在证书力锥与几何包络内。

*证明要点*：由 `r^TΣ^{-1}r ≤ χ²` 得 `‖r‖ ≤ √(λ_max(Σ))·χ`；`r_τ` 有界 ⇒ `w` 有界；`K_n≥K_min` 保证不因过软而失控穿透，`f_max(κ_M)` 保证不因过硬而越锥。∎

**定理 12（主动探测的样本复杂度）** 在安全包络下按贪心 IG 选探针，位姿-地图后验的微分熵满足
```
H_{N+1} ≤ H_N − ½ log(1 + SNR·σ_c)
```
其中 `σ_c` 为 `Σ^{1/2}G_cΣ^{1/2}` 的最小非零特征值。故置信椭球体积缩至 `γ` 需 `N = O((1/SNR)·log(1/γ))` 次有效接触，而视觉在遮挡方向秩亏、需无界样本。

*证明要点*：贪心选择使每次探测沿当前最大不确定方向注入信息；线性高斯下熵减少量即 `½ log det(I + …)` 的最小特征贡献，取 `σ_c` 即得下界。∎

**定理 13（对偶归因的可分性，承接 VISTA）** 若 `C_TP ≠ 0`（即地图误差会经 `O_c` 同时引起位姿与力矩残差），则忽略跨块的独立检验（VISTA 式）将 `H_map` 与 `H_ext` 混淆的概率为 `1/2`；使用联合卡方与子空间投影可使二者后验可分，误归因率 ≤ `exp(−½‖r‖²_{Σ^{-1}})`。
*证明要点*：独立检验仅比较边缘似然，而 `C_TP` 携带的正是区分二者的联合信息；联合高斯下投影子空间的似然比给出指数界。∎

## 7. 本轮最大风险

**一句话**：TANGO 的核心假设是「接触力矩是地图的可靠几何探针、且其似然模型足够准，使地图误差与外力可联合辨识」——但真实接触是软的、有摩擦滞回、会磨损与滑移，一旦接触模型失配，对偶残差就会把「我自己的地图误差」误判成「外部扰动」（或反之），而主动探测又会用更大的接触力放大这一失配，形成「模型误差 → 错误归因 → 更大探测力 → 更大模型误差」的自激闭环，可能既毁任务又磨损/损伤接触面。

**次级风险与缓解**：
1. **探测安全性**：主动抖动可能越锥或过载 → 硬性 `U_safe` 投影 + 每回合预算 `B_τ`，实时流先投影后执行；
2. **接触模型失配（软材料/粘滑）**：对偶残差被模型误差主导 → 在线辨识 `k_c, μ`，并将模型不确定并入 `Σ_dual` 而非归为 `H_ext`；
3. **双频撕裂**：语义流滞后导致 `K_n` 在快接触中过时 → 实时流用当前 `τ` 做局部补正，语义流只调边界；
4. **接触模式抖动**：SLIP↔STICK 频繁切换 → 滞回阈值 + 模式后验熵触发降级；
5. **真机力矩噪声/标定**：`b_τ` 漂移被误判为外力 → 定期零位标定与重力补偿自检，纳入 `H_calib`；
6. **算力**：SDF 因子图与 IG 规划在嵌入式仍重 → 稀疏体素 + 局部滑窗建图，语义流降频到 10Hz。
