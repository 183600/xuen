# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 1 轮；本轮灵感：「四足机器人」×「传感器标定」）

> R69 学会了「去问」：把不确定性拆成 aleatoric / epistemic，用流匹配策略给出有形状的动作模态，再用注视、探针、提问去消解可约部分。但 R69 的整套推理有一个从未被检验的前提——**测量装置是静止的、已知的、外部的**。它假设传感器已经标定好，且标定不随动作变化；信息动作永远「向外」指（看世界、问人），而从不「向内」指（校准自己）。R68 补了计量层，却把标定当成一个由被动滤波器（COF）慢慢收敛的常量。
>
> 四足机器人把这个前提彻底推翻：
> - **标定不是常量，而是步态相位的函数。** 足端触地冲击、关节柔顺、机身弯扭、负载与温漂，使外参、时延、IMU 零偏、腿长/接触模型参数在不同相位下取不同值；某些参数只在触地瞬态可观测，某些只在机身偏航机动可观测，某些在任何匀速直行中都不可观测。
> - **机器人本身就是标定仪。** 足端接触是天然的**度量基准**（每一步都是一次已知位移的测量），落地冲击是天然的**激励源**，机身机动是可控的已知信号。四足不必依赖外部标定板，它可以「用自己的腿测自己的眼睛」。
> - **最危险的病不是噪声，而是混淆（confounding）。** 同一条残差既可能是标定错了，也可能是地形斜了、腿滑了、状态估歪了。R68 自陈的「缓变故障被标定吸收」只是这个混淆子空间的一个切片。四足上，**运动既产生标定误差、又掩盖标定误差、还是唯一能分离标定误差的手段**——三者纠缠成一个自指闭环。
>
> 核心命题：**把标定从「被动估计一个常量」升级为「在安全包络内主动设计实验、用步态激发并分离自身参数」；标定的可观测量是相位条件化的，其核心障碍是标定–世界混淆与「越不确定越不敢激发、越不激发越不确定」的自举困境。** 命名 **PACE-RAS**（Phase-Aware Calibration Excitation for Risk-Adaptive Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我能不能先把自己校准到足以安全地校准自己**」——标定不是一个状态，而是一种需要被安全地执行的能力。

## 0. 直觉与动机

**灵感 1（标定是相位的函数，不是常量）**
直觉：同一台四足，站立时、匀速直行时、急转时、单腿支撑时，相机–IMU 外参与 IMU 零偏的可观测性完全不同：站着不动测不出尺度，匀速直行测不出偏航外参，周期步态会把「腿长偏差」和「IMU 刻度因子」搅成同一个乘积。R68 的 COF 把标定写成 `ĉ_{t+1}=ĉ_t+K·r_res`，隐含「任何时刻都有信息」。真相是：**信息只在特定相位窗口出现**。因此标定估计器必须携带「本相位看过什么」的覆盖率账本，而不是一个无记忆的递推。

**灵感 2（四足自带标定仪：接触是尺、落地是锤）**
直觉：足端接触事件给出三样免费的东西：(a) **度量**——支撑相足端在世界中近似不动，相邻触地之间机身位移可由腿长学重建，是一条不依赖外部目标的里程计；(b) **激励**——触地冲击是宽带、可重复、可调相位的输入，恰好激发 IMU 偏置与外参的可辨识方向；(c) **参照**——把腿式里程计与视觉/激光里程计对齐，就能在无标定板情况下估外参与时延。手眼标定需要「手」动，四足标定需要「腿」动。

**灵感 3（混淆是核心病理，R68 的洞只是它的一个切片）**
直觉：设残差 r ≈ H δθ + J δw（δθ 标定误差，δw 世界/地形/状态误差）。只要存在方向 u 使 `H u` 能被 `J δw` 解释，该标定方向就**原理上不可辨识**。R68 的「缓变故障被标定吸收」正是「δθ 落在可被 δw 替代的零空间」的极端情形。只盯残差阈值永远分不清「标定错了」和「世界变了」；必须问一个**联合可辨识性**问题：这条轨迹到底能同时定出多少个方向。

**灵感 4（激发是动作，因此也受安全约束）**
直觉：既然标定只在特定相位可观测，机器人就该**主动选择步态去制造那些相位**——改变步频、步长、机身侧摆/偏航、落脚偏置、必要时停顿。这是标准的主动实验设计（optimal experiment design）。但它是**安全攸关动作**：标定越差，越需要激发；而标定越差，能安全激发的幅度越小、越容易跌倒。于是出现**自举困境**：`Σ_θ` 大 ⇒ 安全激发集小 ⇒ 信息增益小 ⇒ `Σ_θ` 降不下来。

**灵感 5（周期性 = 别名：四足特有的新故障模式）**
直觉：步态是周期信号。某个与步态锁相的标定误差（如左右腿不对称导致的周期零偏）会与真实的周期机身运动**同频**，在频谱上不可分——你以为是机身在做正弦摆动，其实是周期偏置在冒充。**看更久没用，因为它们是同一个频率。** 解法不是「看得更多」，而是「走得不那么周期」：用步频调制/多频步态把锁相误差与受控运动在频域上拆开。这把「激励的幅度」问题升级为「**激励的秩与频谱**」问题。

**灵感 6（自证偏误：用自己的运动证明一个错误模型）**
直觉：激发是「你设计、你执行、你观测、你解释」。若地形或对手能塑造激发的后果，机器人就能用一个错误标定**自洽地**解释自己的动作：斜坡被读成相机俯仰外参偏置，软地被读成腿长偏差。R69 的「问错比不问更危险」在这里变成「**激发错比不激发更危险**」——因为激发的收益延迟且不确定，而代价（跌倒、被欺骗）即时且致命。因此必须引入**预注册激发签名**与**独立度量参照**，禁止事后合理化。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（PACE-RAS 总览）** PACE-RAS = (CGM, CRE, OAM, CFX, EXD, SCG, RCC, RAS-WM‡)。四条不变式：
(i) 实时流零学习写操作（继承 R69 定义 293-i）；
(ii) **安全激发**：任何激发动作 u 必须属于当前标定不确定度下的认证可恢复集 `E_safe(Σ_θ)`，且激发与任务动作共用 C-RAS-WM 前缀认证；
(iii) **预注册**：激发执行前必须先提交其预期观测签名 `Sig(u)`，执行后只允许按该签名检验，禁止事后改写解释；
(iv) **不单次定案**：单次激发、单相位证据、单通道残差不得单独确定一个标定参数，需相位覆盖或独立度量参照佐证（继承 R69 定义 293-iii 的证据纪律）。

**定义 311（相位条件标定流形 CGM）** 标定状态 `θ(φ,ℓ) ∈ ℝ^{d_θ}`：外参、传感器时延、IMU 零偏与刻度、腿长/接触刚度/足端半径等，随步态相位 `φ ∈ [0,1)^4`（四腿各自相位）与负载/温度 `ℓ` 缓变。其演化建模为慢 SDE `dθ = A_ℓ(θ)dℓ + Σ^{1/2}dW`，并维护相位条件后验 `p(θ | φ, o_{1:t})`。**关键：θ 是流形上的轨迹，不是单点；R68 的 `c` 是它在「标定板静止、平台不动」下的退化纤维。**

**定义 312（接触参照账本 CRE）** 接触事件集 `E = {(t_k, foot_k, p_k, j_k, s_k)}`（时刻/足/落点/冲量/滑移标志）。支撑相足端速度为 0 的假设下，相邻触地间机身增量 `Δx_k = FK(θ)(q_{t_k}) − FK(θ)(q_{t_{k+1}})` 给出**接触参照里程计**及其协方差 `Σ_cre(θ,φ)`。CRE 是外部目标无关的度量基准：它把「腿」变成「尺」，用于与视觉/激光里程计做外参与时延的自标定。

**定义 313（相位可观测图 OAM）** 对相位 φ 与激发原语 u，线性化观测 `r = H(φ,u) δθ + J(φ,u) δw + n`。相位 Fisher 信息 `F(φ,u) = H^T Σ_n^{-1} H`；轨迹信息 `F_tr(u) = Σ_{φ∈Φ(u)} n(φ) F(φ,u)`（`n(φ)` 为访问次数，`Φ(u)` 为激发访问的相位集）。定义**相位覆盖率** `cov(u) = λ_min(F_tr(u))/λ_max(F_tr(u))` 与**相位零空间** `N(φ) = null(F(φ,u))`。可见性要求 `F_tr(u) ≻ 0`（在规范固定后），否则对应方向不可辨识。

**定义 314（标定–世界混淆子空间 CFX）** 联合参数 `η = (δθ, δw)`，联合 Fisher `F_η = [[H^TΣ_n^{-1}H, H^TΣ_n^{-1}J],[J^TΣ_n^{-1}H, J^TΣ_n^{-1}J]]`。混淆子空间
`C(u) = { u_θ : ∃ δw, H u_θ + J δw = 0 }`，
即可被世界/地形解释掉的标定方向。定义**混淆度** `κ(u) = max_{‖u_θ‖=1} min_{δw} ‖H u_θ + J δw‖_{Σ_n^{-1}} / ‖u_θ‖`（对偶形式：`κ` 为 Schur 补的最小特征值之逆的平方根）。`κ=0` 的方向**原理上不可分离**。残余归因：R68 的「标定吸收」⇔ `δθ ∈ C(u)` 且 `r_res≈0`。

**定义 315（激发动作空间 EXA）** 激发原语 `u = (f_step, ℓ_step, a_roll, a_pitch, a_yaw, b_foot, pause) ∈ 𝒰`：步频、步长、机身横滚/俯仰/偏航激励幅度、落脚偏置、停顿。一段激发是原语序列 `u_{1:T}`；它是**在安全包络内的系统辨识轨迹**，与任务动作共享同一低层控制器与认证前缀。四足的独特之处：`u` 同时是「走路的参数」与「实验的输入」。

**定义 316（安全激发集 SCG-envelope）** 设认证可恢复集 `R`（来自 R68 C-RAS-WM 的捕获/恢复判据）。对激发 `u` 与标定不确定椭球 `Σ_θ`，最坏状态 `x_wc(u, δθ) = max_{δθ∈Ell(Σ_θ)} x(u, δθ)`。
`E_safe(Σ_θ) = { u ∈ 𝒰 : x_wc(u, δθ) ∈ R, ∀δθ ∈ Ell(Σ_θ) 且跌倒风险 ≤ ε_fall }`。
**性质：`Σ_θ` 越大 ⇒ `E_safe` 越小**（激励越危险）；这直接产生自举困境（定义 320）。

**定义 317（激发设计 EXD）** 目标是**沿混淆方向获取信息**而非笼统降方差：
`u* = argmax_{u∈E_safe} [ I_C(u) − λ_c·c(u) ]`，
其中 `I_C(u) = log det(I + Σ_θ^{1/2} Π_C F_tr(u) Π_C Σ_θ^{1/2})`（`Π_C` 为混淆子空间投影），`c(u)` 为能耗/时间/社交与任务扰动成本；`I_C(u) ≤ c(u)` 则不激发、走 R68/R69 保守。注意：**激励的秩比幅度更值钱**——增加一个独立激发方向常比加大同一方向幅度更安全（见引理 20）。

**定义 318（自举调节器 SCG）** 激发幅度/频率调度 `a_t = g(Σ_θ)`，满足 `g` 对 `Σ_θ` 单调：不确定越大越小；仅当证书有效且 `E_safe(Σ_θ) ≠ ∅` 时允许扩张；一旦估计失效或证据冲突立即收缩。SCG 是**自指安全阀**：它保证「用当前（保守）标定去判断激发是否安全」，绝不拿一个未认证的标定去授权一次可能致命的激发。

**定义 319（步态别名指数 GAI）** 周期步态基频 `ω_g`，锁相标定误差谱 `P_θ(ω)` 与受控机身运动谱 `P_x(ω)` 的重叠
`GAI(u) = ∫ min(P_θ(ω), P_x(ω)) dω / ∫ P_x(ω) dω`。
`GAI→1` ⇒ 标定误差与真实运动同频不可分；去别名需步频调制（chirp/多频）使 `GAI` 降到阈值以下。**这是四足相对固定基座机器人独有的故障模式**：腿的周期性本身就是一种「看不见的假设」。

**定义 320（安全自举可行性判据）** 若 `∃ u ∈ E_safe(Σ_θ)` 使 `Π_C F_tr(u) Π_C ≻ 0`，称 `Σ_θ` **可安全自举**；否则称 **安全内不可辨识（unidentifiable-in-safety）**。后者只能：(a) 借助外部参照（人/标定板/第二机器人），(b) 退化为最坏情形保守步态，或 (c) 显式拒绝在精度不足时执行高风险任务。**这是本轮最重要的诚实边界：自标定不是永远可行的。**

**定义 321（接触参照外参自标定 RCC）** 以 CRE 的机身增量 `Δx_k` 与视觉里程计 `Δz_k` 做对齐，估计相机–IMU–腿的旋转 `R` 与时延 `τ_d`：
`min_{R,τ_d} Σ_k ‖Δx_k − R Δz_{k−τ_d}‖²_{Σ_k^{-1}}`。
可观测条件：轨迹需含非退化偏航机动（激励 `a_yaw`）与足端不滑；退化时该方向进入 `N(φ)`，不得用 R69 的似然通道替代（两通道可能同误）。

**定义 322（标定–世界联合推断与归因）** 维护联合后验 `p(θ,w | o)`，并用四通道证据做归因：R68 的 `r_res`、R69 的 `Δa`（行为似然差）、本轮新增 `r_leg = Δx_k − FK(θ)(q)`（接触参照残差）与 `cov(u_t)`（相位覆盖）。归因规则：若 `r_res↓ ∧ Δa↑`（R69 判据）且 `r_leg` 与 `cov` 在某方向持续为 0 ⇒ **该方向落在 `C(u)`，禁止归因于标定**，必须先激发扩容或转保守。**没有覆盖，就没有归因权。**

**定义 323（激发威胁模型 AIC-PACE）** `ℰ_PACE = ℰ_FLUID × ℰ_terrain × ℰ_excite`：
`ℰ_terrain`（地形塑形欺骗：斜坡/软地/镜面使激发残差伪装成外参偏差）、`ℰ_excite`（对抗步态扰动、接触事件重放/伪造、别名注入、预注册签名被事后篡改）。新增「**自证攻击**」：对手只塑造激发后果而不碰传感器，诱导机器人用自己的动作确认错误标定。

**定义 324（参与式审计 VQAuditor-P）** 审计对象：激发是否有预注册签名、相位覆盖是否支撑归因、`GAI` 是否越界、`E_safe` 判定是否用了保守 `Σ_θ`、是否存在「单次激发定案」、别名/混淆是否被漏判。结论回灌 AuditBuf，成为 `I_C/c` 与 `g(Σ_θ)` 的先验。

**定义 325（证书 J_PACE）** `J_PACE = (J_FLUID, phase_coverage, confound_leakage_κ, gait_alias_index, excitation_risk, prereg_hash, safe_bootstrap_flag, calib_drift_rate, pace_ver)`。Valid ⇔ `Valid(J_FLUID)` ∧ `κ ≤ τ_κ`（或已显式标注不可归因）∧ `GAI ≤ τ_alias`（或已去别名）∧ 激发风险 ≤ ε_fall ∧ 预注册未被篡改。

**定义 326（三级严格退化）** 正常 → PACE；若无需激发、标定冻结且相位覆盖充足 ⇒ 逐指令退化为 **FLUID（R69）**；若标定不可信 / 混淆不可分 / 别名越界 / 自举不可行 / 证据冲突 ⇒ 逐指令退化为 **CALM（R68）纯保守**（`λ` 取最坏标定下的 `λ_floor`，步态取最小激发保守步态）。`λ` 在退化链上单调不降，安全侧不做任何让步。**R68 是「永不激发」边界，R69 是「身体已标定且冻结」边界。**

## 2. 关键算法骨架

```python
# IP-264 CGM：相位条件标定流形（复用 R68 COF 的残差，但保留相位标签）
class PhaseCalibManifold:
    def __init__(self, cof, phase_encoder):
        self.cof, self.enc = cof, phase_encoder
        self.post = {}                       # phi_bin -> (mu, Sigma, n_vis)
    def update(self, phi, residual, H):
        k = self.enc.bin(phi)                # 相位分箱（接触/摆动/瞬态）
        mu, S, n = self.post.get(k, (self.cof.mu, self.cof.Sigma, 0))
        S = inv(inv(S) + H.T @ inv(self.cof.R) @ H)   # 只在本相位有信息时收缩
        mu = mu + S @ H.T @ inv(self.cof.R) @ residual
        self.post[k] = (mu, S, n + 1)        # n_vis 是相位覆盖账本

# IP-265/266 OAM+CRE：接触参照里程计与相位可观测图
def observability(phi_bins, gait_u, model):
    F_tr, cov = 0, {}
    for phi, n in phi_bins.visits(gait_u):
        H, J = model.jacobians(phi, gait_u)  # 标定/世界雅可比
        F = H.T @ inv(model.R) @ H
        F_tr += n * F
        cov[phi] = eigvalsh(F)               # 逐相位可观测谱
    return F_tr, coverage(F_tr), nullspace(F_tr), cov

# IP-267 CFX：标定-世界混淆子空间（Schur 补）
def confound(H, J, R):
    A = H.T @ inv(R) @ H
    B = H.T @ inv(R) @ J
    D = J.T @ inv(R) @ J
    S = A - B @ pinv(D) @ B.T                # 标定在扣除世界解释后的信息
    lam = eigvalsh(S)
    kappa = 1.0 / sqrt(max(lam[0], 1e-9))    # kappa 大 = 难归因
    return S, kappa, nullspace(S)

# IP-268/269 EXD+SCG：安全激发设计与自举调度
def design_excitation(Sigma_theta, F_cf, budget):
    best = None
    for u in gait_candidates():              # 步频/步长/横滚/偏航/落脚偏置
        if not c_ras_wm.recoverable(u, Sigma_theta):   # 定义 316 安全集
            continue
        F_tr, cov, null, _ = observability_for(u)
        I = logdet(I + sqrt(Sigma_theta) @ P_C(F_cf) @ F_tr @ P_C(F_cf) @ sqrt(Sigma_theta))
        score = I - cost(u, budget)
        if best is None or score > best.score: best = (u, score, cov, null)
    return best if best and best.score > 0 else None   # 无安全正收益 -> 保守

def de_alias(gait):
    # IP-273：若 GAI 越界，调制步频/步长（多频）打破锁相别名
    if gait_alias_index(gait) > TAU_ALIAS:
        gait = chirp_or_multifreq(gait)      # 预注册新签名后执行
    return gait

# IP-270/271 RCC + 证书：接触参照外参/时延自标定
def contact_referenced_extrinsic(E, visual_odom, R0, tau0):
    # 用足端接触增量 Δx_k 对齐视觉里程计，估 R, tau_d（定义 321）
    return solve_alignment([e.delta_x for e in E], visual_odom, R0, tau0)

# IP-274 主闭环（继承 R69，只在「标定」处插入 PACE 层）
def PACE_RAS_round(M, obs):
    z, o = M.mtm.forward(...)                        # R68/R69 一次前向
    phi   = M.phase.estimate(o)                      # 步态相位
    c, U_cal, thr = M.cof.step(...)                  # R68 标定
    M.cgm.update(phi, M.residual, M.H)               # 定义 311：相位条件更新
    # 1) 可观测性与混淆诊断（只在需要时算，廉价路径默认跳过）
    F_tr, cov, null, _ = M.oam.observability(M.cgm.phase_bins, M.last_gait)
    S, kappa, C = M.cfx.confound(M.H, M.J, M.residual_cov)
    # 2) 安全激发：仅在「有可约混淆」且「安全集内存在正收益方向」时
    u = None
    if kappa > TAU_KAPPA and not M.scg.pinned:

    if u is not None:

        else:
            u = None
    # 3) 去别名：周期步态若与锁相误差同频，先调制再归因
    M.last_gait = de_alias(M.last_gait) if u is None else u

    attributable = (kappa <= TAU_KAPPA) and (M.oam.coverage_ok())

        M.cgm.freeze_attribution()                   # 没有覆盖就没有归因权
    U_floor = M.cgm.worst_case_U() if not attributable else M.cgm.U()
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))       # R68 铁律兜底
    # 5) 安全动作（继承 R69 的流策略 / R68 的认证）
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if not attributable or M.scg.pinned:
        k = min(k, k_cons(lam))                      # 保守步态/最小前缀
    M.vqa_p.submit_async(u, Sig, kappa, cov, M.last_gait)
    return k, lam, u, (cov, kappa)
```

## 3. 推导

**引理 19（相位覆盖决定可辨识性）** 在标定线性化模型下，轨迹后验协方差 `Σ_θ^{-1} = Σ_θ,0^{-1} + F_tr(u)`。若 `F_tr(u)` 在方向 `v` 上为零（该方向从未被访问相位的 `H` 张成），则 `v^T Σ_θ v` 不随观测下降——**看得再久也不收敛**。故可辨识性的必要条件是相位覆盖 `cov(u) > 0` 且访问相位的 `H(φ)` 张成 `d_θ` 维（规范固定后）。系：R68 的 COF 在「单一匀速直行」下只能观测 `rank(F_tr)` 个方向，其余方向本质冻结，这解释了为何它的 `r_res` 会长期「看起来很好」。

**引理 20（激励的秩比幅度更值钱；混淆可被独立方向拆开）** 设两个激发原语给出约束 `c_1 δL − d_1 s = e_1` 与 `c_2 δL − d_2 s = e_2`（`δL` 腿长偏差、`s` IMU 刻度因子）。单步态仅给一条约束，`(δL,s)` 秩 1 不可辨识；两独立步态使秩升为 2，可辨识当且仅当 `c_1 d_2 − c_2 d_1 ≠ 0`。**若两个步态沿同一流形共变（只加大同向幅度），行列式≈0，仍然不可辨识。** 因此 `I_C(u)` 的增益主要来自**新增独立方向**（`a_yaw`、`b_foot` 等正交机动），而非放大已有方向；后者还更易越出 `E_safe`。这直接指导 EXD 在「幅度」与「秩」之间优先选秩。

**引理 21（步态别名不可由时间平均消除）** 设锁相标定误差 `δθ(t)=δθ(φ(t))` 为 `ω_g` 的周期函数，受控机身运动亦含 `ω_g` 分量。两者在 Fourier 域同为 `{kω_g}`，任意长度观测只能给出其和，无法分离（时间平均只降低噪声、不改变秩）。去别名需使受控运动含 `ω_g` 之外的分量（步频调制/多频步态），使 `GAI(u) ≤ τ_alias`；所需调制带宽正比于待分离参数对频率的敏感度。**这是四足专属：固定基座没有「腿的周期」这个隐变量。**

**定理 18（PACE 严格包含 R69 与 R68）** 在 A105–A110（标定线性化、`Σ_θ` 为保守上界、`E_safe` 判定正确、预注册完整、相位覆盖可测）下，PACE 在任意状态期望任务风险 ≤ FLUID（R69）≤ CALM（R68）。当「无需激发且标定冻结、覆盖充足」时 PACE 逐指令与 R69 相同；当「混淆不可分 / 别名越界 / 安全自举不可行 / 证据冲突」时逐指令退化为 R68 保守。**安全侧单调不降，效率侧通过 resolution + 自标定获得增益。** R68 = 永不激发边界；R69 = 已标定冻结边界。

**定理 19（安全自举与无新增跌倒）** 若 `Σ_θ` 是真实标定误差的保守上界，且激发 `u ∈ E_safe(Σ_θ)`（定义 316），则对任意 `δθ ∈ Ell(Σ_θ)`，激发轨迹的每一步都在认证可恢复集 `R` 内，故新增跌倒概率 ≤ ε_fall；且激发后 `Σ_θ' ≼ Σ_θ` ⇒ `E_safe(Σ_θ') ⊇ E_safe(Σ_θ)`（单调扩张），自举链是良基的。**但存在性不保证**：若 `E_safe(Σ_θ)` 内无任何正信息方向（定义 320 的「安全内不可辨识」），则自举不可能，必须转外部参照或保守。**能力有边界，不能靠意愿弥补。**

**定理 20（信息–风险前沿）** 定义风险预算 `ε_fall` 下可达信息率 `R_info(ε) = max_{u∈E_safe(ε)} I_C(u)/T(u)`。`R_info(ε)` 对 `ε` 单调不减，且存在拐点 `ε*`：`ε<ε*` 时增大预算几乎不增信息（秩瓶颈），`ε>ε*` 后才进入幅度增益区。故最优策略是先补**独立激发方向**（提升秩、低风险）再考虑加大幅度（高风险）；这把「标定要多大胆」变成一条可绘制的 Pareto 前沿。

## 6. 本轮最大风险

**一句话**：PACE-RAS 把「标定」从被动估计变成了**主动、自指、安全攸关的动作**，于是全部收益押在一个危险的时序不对称上——**激发的代价即时且致命（跌倒、被地形欺骗），收益延迟且不确定**；更糟的是，最需要激发的时候正是标定最差、`E_safe` 最小、也最容易被混淆与别名骗过的时候，系统可能用一个错误标定**自洽地证明自己是对的**（自证偏误），或困在「不敢激发 → 永远标不准 → 更不敢激发」的自举死亡螺旋里。**激发错，比不激发更危险。**

**次级风险与缓解**：
1. **安全集判定依赖 `Σ_θ` 是保守上界**——若后验过度自信，`E_safe` 被高估 → 定理 19 失效；用 MCG 式校准门 + 最坏情形膨胀，后验越界即冻结激发；
2. **地形塑形/自证攻击**（定义 323）→ 预注册签名 + 独立接触参照 + 多独立激发方向交叉检验，禁止单次激发定案；
3. **步态别名**——周期性把「腿的假设」藏进频谱 → GAI 门控 + 步频调制去别名，别名越界即冻结归因；
4. **自举不可行**（定义 320）→ 诚实拒绝 + 外部参照，绝不用「多激发几次」硬闯；
5. **实时预算被相位分箱/混淆诊断击穿** → 廉价路径默认跳过 OAM/CFX，仅在残差异常或 `κ` 预警时升级计算。

**定义 311（CGM）** `θ(φ,ℓ)` 随相位与负载/温度缓变，维护相位条件后验 `p(θ|φ,o)`；R68 的 `c` 是「平台静止、标定板在视野」下的退化纤维。

**定义 312（CRE）** 支撑相足端零速假设下，`Δx_k = FK(θ)(q_{t_k}) − FK(θ)(q_{t_{k+1}})` 给出外部目标无关的接触参照里程计。

**定义 313（OAM）** `r = H(φ,u)δθ + J(φ,u)δw + n`；`F_tr(u)=Σ_φ n(φ)F(φ,u)`；`cov(u)=λ_min/λ_max`；`F_tr≻0`（规范固定后）才可辨识。

**定义 314（CFX）** 联合 Fisher 的 Schur 补 `S = A − B D^{-1} B^T`；`C(u)={u_θ:∃δw, H u_θ+J δw=0}`；`κ` 为 `S` 最小特征值的倒数平方根。R68「标定吸收」⇔ `δθ∈C(u) ∧ r_res≈0`。

**定义 315（EXA）** 激发原语含步频/步长/横滚/俯仰/偏航/落脚偏置/停顿；激发即「安全包络内的系统辨识轨迹」，与任务动作共享低层控制器与认证前缀。

**定义 316（安全激发集）** `E_safe(Σ_θ)={u: x_wc(u,δθ)∈R, ∀δθ∈Ell(Σ_θ), 风险≤ε_fall}`；`Σ_θ` 越大，`E_safe` 越小（自举困境来源）。

**定义 317（EXD）** `u*=argmax_{u∈E_safe}[I_C(u)−λ_c c(u)]`，`I_C=logdet(I+Σ_θ^{1/2}Π_C F_tr Π_C Σ_θ^{1/2})`；`I_C≤c` 则不激发。**秩 > 幅度**（引理 20）。

**定义 318（SCG）** `a_t=g(Σ_θ)` 对不确定度单调收缩；仅证书有效且 `E_safe≠∅` 时扩张；用当前保守标定判断激发是否安全，绝不用未认证标定授权致命激发。

**定义 319（GAI）** `GAI(u)=∫min(P_θ,P_x)/∫P_x`；`GAI→1` ⇒ 锁相标定误差与真实运动同频不可分，需步频调制去别名（四足专属故障模式）。

**定义 320（安全自举可行性）** 存在 `u∈E_safe(Σ_θ)` 使 `Π_C F_tr(u)Π_C≻0` ⇒ 可安全自举；否则 **安全内不可辨识**，只能外部参照 / 最坏情形保守 / 显式拒绝高风险任务。

**定义 321（RCC）** `min_{R,τ_d} Σ_k‖Δx_k − R Δz_{k−τ_d}‖²_{Σ_k^{-1}}`；可观测需非退化偏航机动与足端不滑。

**定义 322（联合推断与归因）** 四通道 `(r_res, Δa, r_leg, cov)`；若某方向 `r_leg` 与 `cov` 持续为 0 ⇒ 该方向在 `C(u)`，禁止归因于标定，先激发扩容或转保守。**没有覆盖，就没有归因权。**

**定义 323（AIC-PACE）** `ℰ_PACE = ℰ_FLUID × ℰ_terrain × ℰ_excite`；含「自证攻击」：只塑造激发后果、不碰传感器，诱导机器人自证错误标定。

**定义 324（VQAuditor-P）** 审预注册、相位覆盖、GAI、`E_safe` 是否用保守 `Σ_θ`、单次定案、混淆漏判；结论回灌 AuditBuf。

**定义 325（J_PACE）** 见符号表；Valid ⇔ `Valid(J_FLUID) ∧ κ≤τ_κ（或标注不可归因） ∧ GAI≤τ_alias（或已去别名） ∧ 风险≤ε_fall ∧ 预注册未篡改`。

**定义 326（三级严格退化）** PACE →（无需激发且标定冻结、覆盖充足）FLUID →（不可信/不可分/别名/自举不可行/冲突）CALM 纯保守；`λ` 单调不降；R68=永不激发，R69=已标定冻结。

## 3. 关键算法伪代码

```python
# IP-264 CGM：相位条件标定（保留相位标签，覆盖率账本）
class PhaseCalibManifold:
    def update(self, phi, residual, H, R):
        k = self.enc.bin(phi)
        mu, S, n = self.post.get(k, (self.cof.mu, self.cof.Sigma, 0))
        S = inv(inv(S) + H.T @ inv(R) @ H)
        mu = mu + S @ H.T @ inv(R) @ residual
        self.post[k] = (mu, S, n + 1)            # n 即相位覆盖

# IP-265/266 OAM + CRE：相位可观测图与接触参照
def observability(phase_bins, gait_u, model):
    F_tr = 0
    for phi, n in phase_bins.visits(gait_u):
        H, J = model.jacobians(phi, gait_u)
        F_tr += n * (H.T @ inv(model.R) @ H)
    return F_tr, coverage(F_tr), nullspace(F_tr)

# IP-267 CFX：混淆子空间（Schur 补）
def confound(H, J, R):
    A = H.T @ inv(R) @ H; B = H.T @ inv(R) @ J; D = J.T @ inv(R) @ J
    S = A - B @ pinv(D) @ B.T                    # 扣除世界解释后的标定信息
    return S, 1.0 / sqrt(max(eigvalsh(S)[0], 1e-9)), nullspace(S)

# IP-268/269 EXD + SCG：安全激发设计（优先加秩）
def design_excitation(Sigma, S_cf, budget):
    best = None
    for u in gait_candidates():                  # 步频/步长/横滚/偏航/落脚偏置
        if not c_ras_wm.recoverable(u, Sigma):   # 定义 316
            continue
        F_tr, cov, null = observability_for(u)
        I = logdet(I + sqrt(Sigma) @ P_C(S_cf) @ F_tr @ P_C(S_cf) @ sqrt(Sigma))
        s = I - cost(u, budget)
        if best is None or s > best.s: best = (u, s, cov)
    return best if best and best.s > 0 else None # 无安全正收益 → 保守

# IP-273 GAI：步态别名 → 步频调制去别名
def de_alias(gait):
    if gait_alias_index(gait) > TAU_ALIAS:
        gait = chirp_or_multifreq(gait)          # 先预注册新签名再执行
    return gait

# IP-270 RCC：接触参照外参/时延自标定
def contact_referenced_extrinsic(E, vis_odom, R0, tau0):
    return solve_alignment([e.delta_x for e in E], vis_odom, R0, tau0)

# IP-274 主闭环（继承 R69，只在标定处插入 PACE）
def PACE_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    phi = M.phase.estimate(o); M.cgm.update(phi, M.residual, M.H, M.residual_cov)
    F_tr, cov, null = M.oam.observability(M.cgm.phase_bins, M.last_gait)
    S, kappa, C = M.cfx.confound(M.H, M.J, M.residual_cov)
    u = None
    if kappa > TAU_KAPPA and not M.scg.pinned:
        u = M.exd.design_excitation(M.cgm.Sigma, S, M.budget)
    if u is not None:
        Sig = M.exd.preregister_signature(u)
        if M.c_ras_wm.certify_excite(u, M.cgm.Sigma):
            M.exec_excite(u); M.cgm.observe_and_test(Sig)   # 只按预注册检验
        else:
            u = None
    M.last_gait = de_alias(M.last_gait) if u is None else u
    attributable = (kappa <= TAU_KAPPA) and M.oam.coverage_ok()
    if not attributable: M.cgm.freeze_attribution()
    U_floor = M.cgm.U() if attributable else M.cgm.worst_case_U()
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if not attributable or M.scg.pinned:
        k = min(k, k_cons(lam))                  # 保守步态/最小前缀
    M.vqa_p.submit_async(u, Sig, kappa, cov, M.last_gait)
    return k, lam, u, (cov, kappa)
```

## 4. 推导

**引理 19（相位覆盖决定可辨识性）** `Σ_θ^{-1}=Σ_θ,0^{-1}+F_tr(u)`。若 `F_tr(u) v=0`，则 `v^TΣ_θ v` 不随观测下降——**看得再久也不收敛**。可辨识的必要条件是访问相位的 `H(φ)` 张成 `d_θ` 维（规范固定后）。系：R68 的 COF 在单一匀速直行下只能观测 `rank(F_tr)` 个方向，其余方向本质冻结，这解释了 `r_res` 为何会长期「看起来很好」。

**引理 20（秩比幅度值钱；混淆可被独立方向拆开）** 两条激发约束 `c_1δL−d_1s=e_1`、`c_2δL−d_2s=e_2`。单步态秩 1 不可辨识；双独立步态秩 2 可辨识当且仅当 `c_1d_2−c_2d_1≠0`。若两激发沿同一流形共变（只加大同向幅度），行列式≈0，仍不可辨识。⇒ 信息增益主要来自**新增独立方向**（偏航、落脚偏置等正交机动），而非放大已有方向；后者更易越出 `E_safe`。

**引理 21（步态别名不可由时间平均消除）** 锁相误差 `δθ(φ(t))` 与受控机身运动同为 `{kω_g}` 谐波，任意长度观测只给其和，时间平均只降噪、不改秩。去别名需让受控运动含 `ω_g` 之外分量（步频调制/多频步态），使 `GAI≤τ_alias`；所需调制带宽正比于参数对频率的敏感度。四足专属：固定基座没有「腿的周期」这一隐变量。

**定理 18（PACE 严格包含 R69 与 R68）** 在 A105–A110 下，PACE 任意状态期望任务风险 ≤ FLUID（R69）≤ CALM（R68）。无需激发且标定冻结、覆盖充足时逐指令同 R69；混淆不可分/别名越界/自举不可行/证据冲突时逐指令退化为 R68 保守。安全侧单调不降，效率侧获 resolution + 自标定增益。

**定理 19（安全自举与无新增跌倒）** 若 `Σ_θ` 为真实误差保守上界且 `u∈E_safe(Σ_θ)`，则任意 `δθ∈Ell(Σ_θ)` 下激发轨迹每步在可恢复集 `R` 内，新增跌倒概率 ≤ ε_fall；且 `Σ_θ'≼Σ_θ ⇒ E_safe(Σ_θ')⊇E_safe(Σ_θ)`，自举链良基。**但存在性不保证**：`E_safe` 内无正信息方向（定义 320）时自举不可能，必须外部参照或保守——能力有边界，不能靠意愿弥补。

**定理 20（信息–风险前沿）** `R_info(ε)=max_{u∈E_safe(ε)} I_C(u)/T(u)` 对 `ε` 单调不减，且存在拐点 `ε*`：`ε<ε*` 时增大预算几乎不增信息（秩瓶颈），`ε>ε*` 后才进入幅度增益区。⇒ 最优策略是先补独立激发方向（提秩、低风险）再加大幅度（高风险），「标定要多大胆」由此成为可绘制的 Pareto 前沿。

## 7. 本轮最大风险

**一句话**：PACE-RAS 把标定从被动估计变成**主动、自指、安全攸关的动作**，全部收益押在一个危险的时序不对称上——**激发的代价即时且致命（跌倒、被地形欺骗），收益延迟且不确定**；最需要激发时恰是标定最差、`E_safe` 最小、最易被混淆/别名骗过时，系统可能用错误标定自洽地证明自己对（自证偏误），或困在「不敢激发 → 标不准 → 更不敢激发」的自举死亡螺旋。**激发错，比不激发更危险。**

**次级风险与缓解**：`Σ_θ` 过度自信使 `E_safe` 被高估（MCG 式校准门 + 最坏情形膨胀，越界即冻结激发）；地形塑形/自证攻击（预注册签名 + 独立接触参照 + 多独立激发方向交叉，禁止单次定案）；步态别名（GAI 门控 + 步频调制去别名，越界即冻结归因）；自举不可行（诚实拒绝 + 外部参照，绝不多激发几次硬闯）；实时预算被相位分箱/混淆诊断击穿（常规路径默认跳过 OAM/CFX，仅异常升级）。
