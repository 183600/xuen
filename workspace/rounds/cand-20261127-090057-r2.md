### 第 2 轮灵感驱动研究记录

**灵感词**：情感计算、记忆检索

**直觉与动机**：
现有 v25（SRC-USC）把机器人看作「无情绪、无记忆的即时认知体」：七证一体（结构-力学-语义-重构-协同）覆盖了物理、语义与群体维度，却默认「人」只是环境中的静态障碍物、「时间」只是可忽略的瞬时窗口。这留下两个未被证明的真空：（1）碰撞安全不等于心理安全——机器人无法证明自己在长期人机共处中不会诱发、放大或错误响应人的负面情绪（恐惧、焦虑、被冒犯）；（2）感知与规划越来越依赖检索历史经验，但机器人无法证明自己复用的经验此刻仍然成立——记忆会陈旧、互相矛盾、被投毒、泄露隐私。受「情感计算」启发，人的情感状态是可观测、可建模、可校准的决策变量，它把人从障碍物升格为证书链中的「活体传感器 + 活体约束」，将安全从「物理碰撞」扩展为「心理-信任安全」；受「记忆检索」启发，长程经验是证书的「时间副本」，它让已验证的证书可被检索复用、让验证成本随时间摊薄，却把「陈旧性、矛盾性、可污染性、隐私性」引入为新的拒证来源。核心洞见：**情感计算给出「人」这一维的实时边界，记忆检索给出「时间」这一维的可复用边界；安全因此从「一次性验证」升级为「情感闭环内的持续可信、可追溯、可撤销」。**

**形式化目标**：
1. 情感交互证书（AIC）：① 人类情感状态估计的 conformal 覆盖 ℙ(y_h ∈ C_aff(x_h)) ≥ 1-α_aff，且用单侧 Clopper–Pearson 下界而非点估计做有限样本校核；② 情感安全包络 D(π, ŝ_h) ≤ D_max，其中接近距离/接触力/速度的安全阈值随恐惧/应激自适应；③ 共情反馈闭环的离散控制屏障证书 B_aff(h_{t+1}) − (1−γ_aff)B_aff(h_t) ≥ −ε_aff，且共情耦合增益 κ_emp ≤ κ_max，保证（信任，唤醒）不进入恐慌/弃用区。
2. 记忆检索证书（MRC）：① 检索相关性 R@K ≥ r_min ∧ P@K ≥ p_min（conformal 下界）；② 时间一致性：检索记忆新鲜度 Δt ≤ τ_max 且检索集内无矛盾对 (v_a ⊥ v_b)；③ 隐私：记忆读写的 (ε_mem, δ_mem)-差分隐私预算与成员推断风险 γ_mia 上界；④ 证书重放可靠性：被复用证书的前置条件在当前上下文漂移 ‖φ(ctx_now) − φ(ctx_t)‖ ≤ ε_ctx 下仍成立。
3. 构建时间-情感统一准入门（TAU-USC）：SRC-USC ∪ AIC ∪ MRC 九证一体，Exec_v26 = Exec_v25 ∩ Fil_aff ∩ Fil_mem ⊆ Exec_v25。
4. 定义情感-记忆耦合风险：被检索到的「恐惧记忆」经指数倾斜放大当前情感先验，进而使行为过保守/激进形成正反馈；给出耦合增益上界与「情感-记忆解耦」切断条件。
5. 证明九位一体单调退化链在情感误估/情感 OOD/记忆陈旧/记忆投毒/隐私泄露/耦合溢出下的保持性。

# ============================================================
# IP-448 Affective Interaction Certificate (AIC) — 情感交互证书
# ============================================================
@dataclass
class AffectiveInteractionCertificate:
    """情感 conformal 覆盖 + 情感安全包络 + 共情反馈闭环稳定性"""
    alpha_aff: float = 0.05
    D_max: float = 0.30
    gamma_aff: float = 0.10          # 离散 CBF 衰减率
    eps_aff: float = 1e-3            # CBF 松弛
    kappa_max: float = 0.20          # 共情耦合增益上界
    n_mc: int = 64                   # 不适度期望的蒙特卡洛样本数
    delta_mc: float = 1e-3           # 蒙特卡洛置信水平
    # 情感-行为耦合核参数（恐惧↑ ⇒ 距离↑；应激↑ ⇒ 力↓；唤醒↑ ⇒ 速度↓）
    d0: float = 0.80
    beta_fear: float = 0.60
    F0: float = 20.0
    beta_force: float = 0.50
    v0: float = 1.00
    beta_speed: float = 0.60
    w_prox: float = 1.0
    w_force: float = 1e-2
    w_speed: float = 0.1
    T_low: float = 0.30
    A_high: float = 0.80
    calibrator: 'ConformalCalibrator' = None

    # ---- 恐惧/应激/唤醒自适应的安全阈值 ----
    def safe_distance(self, y_h: 'AffectState') -> float:
        return self.d0 + self.beta_fear * y_h.fear

    def safe_force(self, y_h: 'AffectState') -> float:
        return self.F0 * (1.0 - self.beta_force * y_h.stress)

    def safe_speed(self, y_h: 'AffectState') -> float:
        return self.v0 * (1.0 - self.beta_speed * y_h.arousal)

    # ---- (1) 情感覆盖：有限样本有效的 conformal 下界 ----
    def verify_affective_coverage(self, obs: Tensor, labels: Tensor) -> bool:
        """ℙ(y_h ∈ C_aff(x_h)) ≥ 1-α_aff，用单侧 Clopper–Pearson 下界做校核"""
        if self.calibrator is None:
            return False
        pred_sets = self.calibrator.predict(obs)          # [N, |𝒴|]
        covered = [labels[i].item() in pred_sets[i] for i in range(len(labels))]
        # 不能用点估计（小样本会高估覆盖），必须用置信下界
        return clopper_pearson_lower(sum(covered), len(covered)) >= 1 - self.alpha_aff

    # ---- (2) 情感安全包络：不适度期望 + 有界性修正 ----
    def verify_discomfort_envelope(self, plan: 'RobotPlan',
                                   belief: 'AffectBelief') -> bool:
        """D(π,ŝ_h)=E_{y~ŝ}[Σ_t w·φ] ≤ D_max；对 MC 估计做 Hoeffding 上修"""
        if not plan.human_pos_complete():
            return False
        samples = belief.sample(self.n_mc)                # [n_mc] AffectState
        D = 0.0
        d_max = 0.0
        for t in range(len(plan.trajectory)):
            for y_h in samples:
                dp = max(0.0, self.safe_distance(y_h) - plan.distance_to_human(t))
                dF = max(0.0, plan.contact_force[t] - self.safe_force(y_h))
                dv = max(0.0, plan.velocity[t] - self.safe_speed(y_h))
                d = self.w_prox * dp + self.w_force * dF + self.w_speed * dv
                D += d
                d_max = max(d_max, d)
        D /= (len(plan.trajectory) * self.n_mc)
        # Hoeffding：以 1-δ 置信，真实期望 ≤ 经验均值 + d_max·sqrt(log(1/δ)/(2 n_eff))
        n_eff = len(plan.trajectory) * self.n_mc
        D_upper = D + d_max * math.sqrt(math.log(1.0 / self.delta_mc) / (2 * n_eff))
        return D_upper <= self.D_max

    # ---- (3) 共情反馈闭环：离散控制屏障 + 耦合增益上界 ----
    def verify_contagion_stability(self, trust: Tensor, arousal: Tensor,
                                   robot_affect: Tensor) -> bool:
        """B_aff(h_{t+1}) ≥ (1-γ_aff)B_aff(h_t) - ε_aff，且 κ_emp ≤ κ_max"""
        if self._estimate_kappa(robot_affect, arousal) > self.kappa_max:
            return False
        for t in range(len(trust) - 1):
            B_t = min(trust[t].item() - self.T_low,
                      self.A_high - arousal[t].item())
            B_next = min(trust[t + 1].item() - self.T_low,
                         self.A_high - arousal[t + 1].item())
            if B_next < (1.0 - self.gamma_aff) * B_t - self.eps_aff:
                return False
        return True

    def verify_all(self, obs, labels, plan, belief,
                   trust, arousal, robot_affect) -> bool:
        return (self.verify_affective_coverage(obs, labels)
                and self.verify_discomfort_envelope(plan, belief)
                and self.verify_contagion_stability(trust, arousal, robot_affect))

    def _estimate_kappa(self, robot_affect: Tensor, arousal: Tensor) -> float:
        """共情增益：机器人情感表达与人的唤醒之间的线性耦合系数的上界"""
        if len(robot_affect) < 2:
            return 0.0
        X = robot_affect - robot_affect.mean()
        Y = arousal - arousal.mean()
        denom = torch.dot(X, X).item()
        if denom < 1e-8:
            return 0.0
        return abs(torch.dot(X, Y).item() / denom)

# IP-449 Memory Retrieval Certificate (MRC) — 记忆检索证书
# ============================================================
@dataclass
class MemoryRetrievalCertificate:
    """检索相关性 + 时间一致性 + 隐私预算 + 证书重放可靠性"""
    memory: 'MemoryStore'
    K: int = 5
    P_at_K: float = 0.90
    R_at_K: float = 0.95
    tau_max: float = 3600.0            # 秒
    dp_epsilon: float = 1.0
    dp_delta: float = 1e-5
    gamma_mia: float = 0.01
    eps_ctx: float = 0.10
    n_cal: int = 500                   # conformal 检索校准样本数
    provenance_required: bool = True

    # ---- 带隐私噪声的 top-K 检索 ----
    def retrieve(self, query: Tensor) -> list['MemoryEntry']:
        scores = self.memory.similarity(query)                 # [|ℳ|]
        scores = scores + self._dp_noise(scores.shape)         # 指数/高斯机制噪声
        idx = torch.topk(scores, self.K).indices
        return [self.memory[j] for j in idx]

    # ---- (1) 检索相关性：conformal 下界 ----
    def verify_relevance(self, queries, retrieved, ground_truth) -> bool:
        R = recall_at_k(retrieved, ground_truth, self.K)
        P = precision_at_k(retrieved, ground_truth, self.K)
        return (conformal_lower_bound(R, self.n_cal) >= self.R_at_K and
                conformal_lower_bound(P, self.n_cal) >= self.P_at_K)

    # ---- (2) 时间一致性：新鲜度 + 非矛盾 ----
    def verify_temporal_consistency(self, retrieved, t_now: float) -> bool:
        for m in retrieved:
            if t_now - m.timestamp > self.tau_max:
                return False
        for a, b in itertools.combinations(retrieved, 2):
            if contradicts(a.value, b.value):
                return False
        return True

    # ---- (3) 隐私：DP 会计 + 成员推断风险上界 ----
    def verify_privacy(self) -> bool:
        eps_total, delta_total = self.memory.accountant.get_privacy_spent()
        if eps_total > self.dp_epsilon or delta_total > self.dp_delta:
            return False
        return self.memory.mia_risk_upper_bound() <= self.gamma_mia

    # ---- (4) 证书重放可靠性：前提 ∧ 上下文漂移 ----
    def verify_replay_soundness(self, cert: 'Certificate', ctx_now: 'Context') -> bool:
        if not cert.precondition(ctx_now):
            return False
        drift = torch.norm(self.context_embed(ctx_now) - cert.context_embedding).item()
        return drift <= self.eps_ctx

    def verify_all(self, queries, retrieved, ground_truth,
                   t_now, replayed_certs, ctx_now) -> bool:
        ok = (self.verify_relevance(queries, retrieved, ground_truth)
              and self.verify_temporal_consistency(retrieved, t_now)
              and self.verify_privacy())
        if ok:
            ok = all(self.verify_replay_soundness(c, ctx_now) for c in replayed_certs)
        return ok

    def _dp_noise(self, shape) -> Tensor:
        """高斯机制：σ = Δ·sqrt(2 ln(1.25/δ))/ε（分布式聚合时按组合定理累计）"""
        sigma = self.memory.score_sensitivity * math.sqrt(
            2.0 * math.log(1.25 / self.dp_delta)) / self.dp_epsilon
        return torch.randn(shape) * sigma


# ============================================================
# IP-450 Temporal-Affective Unified Certificate (TAU-USC)
# ============================================================
@dataclass
class TemporalAffectiveUnifiedCertificate:
    """九证一体：SRC-USC ∧ AIC ∧ MRC，含情感-记忆解耦"""
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'
    aic: AffectiveInteractionCertificate
    mrc: MemoryRetrievalCertificate
    lambda_mem: float = 0.5       # 记忆→情感先验的耦合增益
    coup_max: float = 0.25        # 耦合增益上界

    def admits(self, multi_plan, sensor_data, gt_entities=None,
               queries=None, retrieved=None) -> tuple[bool, dict]:
        # 1) v25 的七证准入
        if not self.src_usc.admits(multi_plan, sensor_data,
                                   gt_entities, queries, retrieved):
            return False, {'failed': 'SRC-USC'}

        # 2) 情感交互证书
        aic_ok = self.aic.verify_all(
            sensor_data['affect_obs'], sensor_data['affect_labels'],
            multi_plan.human_plan, sensor_data['affect_belief'],
            sensor_data['trust'], sensor_data['arousal'],
            sensor_data['robot_affect'])
        if not aic_ok:
            return False, {'failed': 'AIC'}

        # 3) 记忆检索证书 + 情感-记忆耦合
        mrc_ok = self.mrc.verify_all(
            sensor_data['queries'], sensor_data['retrieved'],
            sensor_data['gt_memories'], sensor_data['t_now'],
            multi_plan.replayed_certs, sensor_data['ctx_now'])
        if not mrc_ok:
            return False, {'failed': 'MRC'}

        coup_ok, decoupled, belief_post = self.verify_coupling(
            sensor_data['affect_belief'], sensor_data['retrieved'],
            multi_plan.human_plan)
        if not coup_ok:
            return False, {'failed': 'AIC+memory coupling',
                           'decoupled': decoupled}

        return True, {'decoupled': decoupled, 'belief_post': belief_post}

    def verify_coupling(self, belief_prior, retrieved, plan):
        """情感-记忆耦合：记忆倾斜后的信念仍满足不适度包络，否则解耦"""
        tilt = sum(w * psi(m.value) for w, m in
                   zip(self._retrieval_weights(retrieved), retrieved))
        gain = self.lambda_mem * torch.norm(tilt, p=1).item()
        if gain <= self.coup_max:
            belief_post = apply_exponential_tilt(belief_prior, self.lambda_mem * tilt)
            decoupled = False
        else:
            belief_post = belief_prior      # 解耦：保留检索但不重加权情感
            decoupled = True
        # 无论是否解耦，都必须用实际使用的信念复核包络（见引理 15）
        ok = self.aic.verify_discomfort_envelope(plan, belief_post)
        return ok, decoupled, belief_post

    def _retrieval_weights(self, retrieved) -> list[float]:
        # 检索相关性权重（可由 MRC 的相似度归一化得到），满足 Σ w = 1
        scores = torch.tensor([m.relevance for m in retrieved])
        return (scores / scores.sum()).tolist()

        multi_plan = self._plan(sensor_data)
        # 4) 写回新经验（DP 预算内）
        if self._can_write(sensor_data):
            self.tau_usc.mrc.memory.append(self._experience(sensor_data, multi_plan))
        # 5) 九证准入
        admitted, info = self.tau_usc.admits(
            multi_plan, sensor_data,
            gt_entities=sensor_data.get('gt_entities'),
            queries=sensor_data.get('queries'),
            retrieved=retrieved)
        return admitted, info

    def _can_write(self, sensor_data) -> bool:
        eps_total, _ = self.tau_usc.mrc.memory.accountant.get_privacy_spent()
        return eps_total < self.tau_usc.mrc.dp_epsilon

    def _estimate_affect_belief(self, sensor_data) -> 'AffectBelief':
        # 融合多模态观测得到 y_h 的后验（贝叶斯/Kalman/深度集成均可）
        return affect_fusion(sensor_data['affect_obs'],
                             sensor_data['affect_history'])


# 辅助函数
def clopper_pearson_lower(k: int, n: int, conf: float = 0.95) -> float:
    """成功数 k / 试验数 n 的单侧 Clopper–Pearson 置信下界"""
    if n == 0:
        return 0.0
    from scipy.stats import beta
    return beta.ppf(1.0 - conf, k, n - k + 1) if k > 0 else 0.0

def conformal_lower_bound(metric: float, n_cal: int, alpha: float = 0.05) -> float:
    """基于校准集规模的分布无关下界：metric - sqrt(log(1/alpha)/(2 n_cal))"""
    return metric - math.sqrt(math.log(1.0 / alpha) / (2 * n_cal))

def recall_at_k(retrieved, ground_truth, K: int) -> float:
    hits = sum(1 for q, gt in zip(retrieved, ground_truth)
               if any(m in retrieved_q for m in gt) for retrieved_q in [q[:K]])
    return hits / max(len(ground_truth), 1)

def precision_at_k(retrieved, ground_truth, K: int) -> float:
    hits = 0
    total = 0
    for q, gt in zip(retrieved, ground_truth):
        topk = q[:K]
        hits += sum(1 for m in topk if m in gt)
        total += len(topk)
    return hits / max(total, 1)

def contradicts(v_a, v_b) -> bool:
    """两记忆值在同一前提上给出不相容结论（可扩展为时态/数值区间冲突）"""
    return v_a.premise == v_b.premise and v_a.conclusion != v_b.conclusion

def apply_exponential_tilt(belief: 'AffectBelief', s: Tensor) -> 'AffectBelief':
    """ŝ⁺(y) ∝ ŝ⁻(y)·exp(s(y))：记忆对情感先验的指数倾斜"""
    logits = belief.log_probs + s
    return AffectBelief(log_probs=torch.log_softmax(logits, dim=-1))

## 3. 正确性论证（增量）

### 引理 13（情感交互证书的覆盖-包络-闭环三重保证）
**陈述**：`AIC.verify_all(...) = True` ⟹ 同时满足：
(1) 情感覆盖：ℙ(y_h ∈ C_aff(x_h)) ≥ 1-α_aff；
(2) 不适度包络：以 1-δ_mc 置信，真实 D(π,ŝ_h) ≤ D_max；
(3) 共情闭环安全：κ_emp ≤ κ_max 且 ∀t，B_aff(h_{t+1}) ≥ (1-γ_aff)B_aff(h_t) − ε_aff，故 h_t 前向不变地留在 𝒮_aff 内。

**证明**：
1. 覆盖：`verify_affective_coverage` 不取经验点估计，而以单侧 Clopper–Pearson 下界校验。conformal prediction 的边际覆盖由可交换性保证；CP 下界是保守的有限样本修正，故实际覆盖不低于名义值。
2. 包络：每个不适度核 φ 为单侧 hinge、非负且有界（d ≤ d_max）。由 Hoeffding 不等式，n_eff 个 i.i.d. 样本的经验均值以 1−δ_mc 置信不高于真实期望 d_max·√(ln(1/δ_mc)/(2n_eff))；代码比较 D_upper ≤ D_max，故真实期望必 ≤ D_max。
3. 闭环：κ_emp 上界切断机器人情感表达对人唤醒的正反馈自激；离散 CBF 条件（Agrawal et al., 2017）保证 B_aff ≥ 0 的前向不变性，即 h_t ∈ 𝒮_aff。三者分别对应「状态可证、行为可证、闭环可证」，缺一不可。∎

### 引理 14（记忆检索证书的相关-时间-隐私-重放四重保证）
**陈述**：`MRC.verify_all(...) = True` ⟹ 同时满足：
(1) 检索相关：R@K ≥ r_min ∧ P@K ≥ p_min；
(2) 时间一致：∀m∈retrieved，t_now−t_m ≤ τ_max，且检索集内无矛盾对；
(3) 隐私：累计 (ε_mem, δ_mem)-DP，且成员推断 advantage ≤ γ_mia；
(4) 重放可靠：∀c∈replayed，Pre(c)(ctx_now) 成立且上下文漂移 ≤ ε_ctx。

**证明**：
1. 相关性：检索质量以校准集点数经分布无关下界修正，避免小样本高估；下界 ≥ 阈值才通过。
2. 时间一致性：新鲜度是逐元素硬约束；矛盾对检查排除「同一前提、不同结论」的记忆同时进入决策，防止证据集自相矛盾。
3. 隐私：检索加噪服从高斯/指数机制，组合定理给出总预算；成员推断风险由训练-测试损失差的经验上界估计并与 γ_mia 比较。
4. 重放：证书是谓词化的（Pre(c) 编码其成立所需上下文），要求谓词在当前上下文成立且嵌入漂移有界；两者共同排除「把旧证书套到已漂移的新场景」的偷换。∎

### 引理 15（情感-记忆耦合的包络保持与解耦阈值）
**陈述**：设基础不适度 d(π,y)∈[0,d_max]，记忆经指数倾斜 ŝ⁺ ∝ ŝ⁻·exp(s) 作用于情感先验，其中 s(y)=λ_mem·Σ_j w_j ψ_j(y)，极差 ≤ B。则
|D(π,ŝ⁺) − D(π,ŝ⁻)| ≤ d_max·B/4；
因此若 D(π,ŝ⁻) + d_max·B/4 ≤ D_max，则包络在倾斜后仍成立；否则执行解耦（λ_mem←0）并重新验证。

**证明**：由 Hoeffding 引理，取值于长度 B 区间的指数倾斜使 KL(ŝ⁺‖ŝ⁻) ≤ B²/8；再由 Pinsker 不等式 TV ≤ √(KL/2) ≤ B/4。因 |D⁺−D⁻| = |E_{ŝ⁺}[d]−E_{ŝ⁻}[d]| ≤ d_max·TV，得 |ΔD| ≤ d_max·B/4。于是当 D⁻ + d_max·B/4 ≤ D_max 时 D⁺ ≤ D_max。若超过，则令 λ_mem=0 使 s≡0、ŝ⁺=ŝ⁻，回到已通过包络的 D⁻，从而既保留记忆检索结果、又不让记忆污染情感决策。∎

**推论**：耦合增益上界可取 Coup_max = 4(D_max − D(π,ŝ⁻))/d_max；代码中再以 λ_mem‖tilt‖₁ 的保守代理做前置闸门，二者任一超限即解耦。

### 引理 16（九位一体单调退化链的时间-情感终局）
**陈述**：任意单点/组合失效下，`Exec_v26 ⊆ Exec_v25 ⊆ ... ⊆ Exec_v18` 恒成立。

**证明**：在引理 12 基础上增加三条退化路径（另加一条耦合路径）：
- 情感误估/OOD/覆盖失效 → `AIC.verify_all=false` → `TAU-USC` 拒证 → 退回 `Exec_v25`：关闭情感自适应，改用固定的保守接近/力/速度阈值（严格 ⊇ 原自适应可行域），人仍被当作加大的静态安全包络。
- 记忆陈旧/矛盾/投毒/隐私超预算 → `MRC.verify_all=false` → `TAU-USC` 拒证 → 退回 `Exec_v25`：禁用记忆复用与证书重放，全部从当前观测重新验证（等价于无记忆基线）。
- 重放漂移/前提失配 → 该重放证书作废并回退到在线重验，不降低 `Exec_v25`。
- 耦合溢出 → 解耦（λ_mem=0），情感包络回到基础信念下验证；由引理 15 仍属 `Exec_v25` 的可行子集。
- 组合失效：各退化映射均单调落入上一版执行集，取交集仍保持包含关系。∎

### 定理（TAU-USC 九证准入门的时间-情感完备性）
**陈述**：对任意多机-人机混合计划 Π，`TAU-USC.admits(Π)=True` ⟺ Π 同时满足：
(1) 物理接地安全（几何∧规范∧负信息∧能量∧差距），

(5) 结构应力/能量/可制造性三重达标，
(6) 力控无源性/带宽/稳定性三重达标，
(7) 轻量化刚度/质量/屈曲三重达标，
(8) 语义覆盖/几何一致/开放词汇检索三重达标，
(9) 重构动力学/接口/证书传递三重达标，

**证明**：直接由 `TAU-USC.admits` 的十二个连言条件与引理 1–3、5–7、9–11、13–15 可得。必要性：任一条件缺失即拒证，对应十二类风险之一未被缓解。充分性：十二条件全满足时，由引理 4、8、12、16 保证执行集单调链与统计覆盖，构成从单机物理到「人-机-时」闭环的完整证明。∎
