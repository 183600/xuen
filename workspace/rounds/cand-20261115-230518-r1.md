# 第 11 轮（新灵感循环第 2 轮；本轮灵感：「多机协作」×「语音合成」）
> **基线**：第 10 轮 MetricVoiceGauge-STF-NRB-LS（定义 540–548；引理 87–91；实验 E571–E590）。
> 本轮纪律：**开放世界信任 + 言行一致**。两个灵感合治 v10 的同一笔隐性债：v10 的证书与规范都默认"世界只有我一个行动者"，语音披露只是不透明旁路。多机协作把"他者"放进证书前提，而他人策略不可验证；语音合成把披露升级为可生成、可撒谎的一等社会动作。必须保持 v10 铁律：任一新模块失效 ⇒ 注入声明中立元，行为严格**等价**（STF/SDC/AC/ID/MW）或**安全支配、活性退化**（CTC/NRB）于 v10，而非行为漂移。

## 0. 直觉与动机

**灵感 1（多机协作 → 从"世界模型"到"承诺模型"）**
直觉：v10 最深的隐含前提不是 β 太小，而是"环境不会自己动"——F̂_q 建模的是静态世界加自身动力学，他者要么不存在，要么被平均成噪声。多机场景里，他者恰恰是最大扰动，而且他者本身也是会出证书的系统。试图建模"别人会怎么走"不可验证且组合爆炸；但**不建模其策略、只校验其承诺**是可行的：每台机器发布一条有界、且在自身动力学内可停住的**承诺管**（committed tube），本地证书只需对"新鲜且一致"的承诺管并集做净空认证。信任被拆成三个可测子命题——新鲜（在时间窗内）、一致（实测轨迹落在管里）、违背可 1 帧检出。这与 STF 是同一招：把不可证的强前提"他人守规矩"换成可测的弱前提"承诺或可检出违背"。核心创新：**协作管契约（Cooperative Tube Contract, CTC）**。配套把共享语义图升级为**只增不减的单调隔离合并**（远端更新先进隔离区，本地或第二方独立印证后才入信；投毒至多让机器人更保守，不能降低 β），规范表升级为**版本协商取交**。

**灵感 2（语音合成 → 从"披露发生了"到"所言即所行"）**
直觉：v10 的 NRB 要求"语音披露"，却把语音当作不透明副作用——只要喇叭响了就算合规。语音合成让它成为一等生成动作：可以流畅、可信、且**说谎**。关键一步不是让语音更自然，而是让它**只能说出证书蕴含的话**：从 Ĉ_coop 与台账 Λ 派生一个**许可命题集** L，TTS 前端只允许把 L 中的模板槽位实例化；任何需要证书外命题的表达都被拒绝并降级为最小脚本披露。于是"听者以为机器人要做的事"与"机器人被认证会做的事"在构造上相连（模听者的解释函数这一可测弱前提）。语音还让多机协作可被人类审计：CTC 的形式承诺与 SDC 的语音渲染是**同一承诺的两个视图**，双视图写入台账，离线可核对"说了什么 → 做了什么"。核心创新：**言行一致证书（Say-Do Certificate, SDC）** + **承诺台账（Commitment Ledger, CL）**。

**二者咬合**：CTC 出**形式社会承诺**（可被其它机器校验），SDC 出**人类可审计的语音影子**（可被听者核对），CL 把两者哈希绑定；三者的公共约束是——**社会通道只增不减保守性**：共享地图只许加障碍、语音只许说证书蕴含的话、通信失败只许退化为更保守的他者模型。这把 v10 的结构化信任证书 Ĉ⁺ 升级为**社会承诺证书 Ĉ_coop = (ĝ_min^coop, ê_max, γ̂_grasp, β_STF+β_comm, n_t, m_t)**。

## 1. 研究问题（轮次升级版）

- **Q1（承诺式协作）**：如何把"其他机器人"从不可建模扰动变为可校验的承诺管，使多机证书在"承诺被遵守或 1 帧内被检出"这一可测前提下安全；同时通信丢失时安全退化为最坏速度界障碍模型（不新增 v10 之外的物理行为）？
- **Q2（言行一致）**：如何把语音合成约束为"只表达证书蕴含命题"，使形式意义上的虚假承诺为零，并在语音失败/台账缺口时退化为 v10 的最小脚本披露（控制面无行为发散）？听者解释保真度如何被实验测量而非假定？
- **Q3（社会面单调性）**：共享语义图、规范表、承诺台账的跨机合并各需什么单调/隔离/协商规则，才能保证多机信息交换只会让系统更保守（或等价），绝不因一个恶意/故障同伴而降低证书余量？

## 2. 设计原则（在 P10–P15 基础上新增 P16–P18）

**P16 承诺可检律（Commitment-or-Detect, CTC）**
证书对他者的依赖只许建立在"可发布承诺 + 可 1 帧检出违背"上，不许建立在对他人策略的建模或善意假定上；无承诺的他者一律按最坏速度界处理；违背检出时必须由几何/速度约束（反应距离 d_react）保证可避让，否则拒绝发布该承诺管。

**P17 言行一致律（Say-Do Consistency, SDC）**
语音是受约束的社会动作：只能实例化证书与台账蕴含的许可命题；安全关键语句用中性陈述韵律；语音在审计面异步运行，绝不进入 50Hz 控制回路；语音失败 ⇒ 最小脚本披露 + 台账缺口语义。

**P18 社会面单调律（Social Monotonicity, SM）**
跨机共享只许增加保守性：地标只增不减、或只升创新度 ν；规范版本不一致取更严交集；任何来自单方的可能降保守更新先进隔离区，需 ≥c_corr 次独立印证；台账双视图哈希绑定，缺口即降级。

## 3. 与基线的接口（如何退化）

- CTC 失效/通信丢失/存在无承诺他者 ⇒ 他者按最坏速度界 v_max 膨胀为动态障碍、K_eff≤2（安全支配、活性退化；单机时与 v10 等价）；
- SDC/TTS 失效 ⇒ v10 原样最小语音披露（NRB 定义 546），控制面零发散；台账缺口 ⇒ 下块 Π_r（v10 原样）；
- 共享图更新不满足单调 ⇒ 丢弃该更新（本地图原样）；规范版本不一致 ⇒ N∩，不可协商则 Π_r；
- STF 失效 ⇒ K=1；NRB 失效 ⇒ Π_r；AC 失效 ⇒ K=1（v10 Level-3 原样）；ID 失效 ⇒ 全模块常开、归因冻结；MW 失效 ⇒ v9 手写网关；v8 失效 ⇒ 中立元注入 ⇒ v7 ⇒ v6。

## 4. 预期贡献

1. **承诺式多机证书**：把"他者不可建模"从安全前提中拆除——不建模策略只校验承诺，通信丢失安全退化为最坏速度界障碍，显著降低 v10 在多机下要么忽略他者（不安全）、要么全局膨胀 β（处处保守）的二难（引理 92–93、98）；
2. **言行一致的可审计语音**：许可命题集 + 受约束模板 + 声学回执 + 双视图台账，使形式虚假承诺为零、硬介入必披露、语音失败不触控制面（引理 94–95）；
3. **社会面单调机制**：共享图隔离合并、规范版本取交、台账哈希绑定，使一个恶意/故障同伴至多让系统更保守（引理 96–97）；
4. **E591–E610** 覆盖承诺兑现/违背、通信退化、投毒、版本协商、SDC 越权拦截、听者保真、声学失败、多机语音协商与联合压力。

## 5. 本轮最大风险

**一句话**：整套方案把"他人"从不可建模的扰动换成"可信任的承诺"，但承诺可以在制动距离内被策略性违背——1 帧检出不等于来得及避让；而 SDC 只保证"所言被证书蕴含"，不保证听者不越界解释，越流畅一致的语音越会放大人类对这台机器的过度信任，安全最终取决于他者的诚实与听者的解释，而这两者都不是证书能保证的。

**新增定义 549（承诺管）** Γ_i(t) = (R_i, H_i, v_i^max, p_i^*, e_i)。R_i ⊆ ℝ³×[t,t+H_i] 为扫掠管；发布前提：(i) 管在自身动力学内 **brake-closed**——管前界任一点在 v_i^max 下的制动距离不超过到前界的几何距离；(ii) 管 ⊆ 当前自证书的已认证走廊。二者缺一不得发布（P16）。承诺管是"我能保证不越出的区域"，不是"我计划走的轨迹"。

**新增定义 550（新鲜、一致、违背）** 对收到的 Γ_j：Fresh_j(t) ⇔ t ≤ t_j^pub + H_j ∧ e_j 最新；Consistent_j(t) ⇔ x_j(t) ∈ R_j(t)⊕δ_br。违背 breach_j ⇔ ¬Consistent_j ∨（到期未续）。τ_det ≤ 1 帧。新鲜度到期而未续，**按违背处理**（保守）。

**新增定义 551（社会净空与社会承诺证书）** 令 g_self = min_k F̂_q,clearance(k) − β_STF；
- 对 fresh∧consistent 的 j：g_j = min_k dist(path_k, R_j) − d_mutual；
- 对 unknown 的 j：g_j = min_k dist(path_k, x_j) − v_max^soc·τ_react − d_mutual（v_max^soc 为观测速度上界+不确定度）。
则 ĝ_min^coop = min(g_self, min_j g_j)。Ĉ_coop valid ⇔ ĝ_min^coop ≥ d_safe ∧ ê_max ≤ τ_eff ∧ γ̂_grasp valid ∧ n_t 全通过（或修复后重验）∧ freshness(G_LM) ≤ T_fresh ∧ U_t^sem ∧ m_t 全部 ∈ {fresh∧consistent, unknown}。注意：unknown 不使证书失效，而是以膨胀项计入；无可用膨胀界时退 K=1。

**新增定义 552（确定性让行与和解）** 智能体上的全序 ≺ 按 (稳定 ID, 纪元) 字典序。若两承诺管在 d_mutual 内冲突，低优先级者**只许收缩**（缩管或提前到 p_i^* 停）；静态全序 ⇒ 等待图无环；收缩单调 ⇒ 最高优先级者始终可行。拒绝让行者按"无承诺/违背"处理：安全性由定义 551 保住，活性不保证（引理 93）。

**新增定义 553（共享图溯源与单调隔离）** 远端更新 u=(op, ℓ, provenance, ts)。允许的远端 op 仅：`add_obstacle`（提高占用）、`raise_nu`（只升 ν）；禁止 `delete`/`lower_nu`/`shrink_obstacle`。允许的更新先入隔离区，凭 c_corr 次独立印证（本地检测或另一独立同伴）后方可入信。于是可信图 G_LM 在合并下**只增不减**，T 逐点不减 ⇒ β_STF 不减（引理 96）。删除仅在本地印证且满足 v10 剪枝不变量（ν̄≤τ_sem/2 ∨ 走廊外 ∨ stale）时允许。

**新增定义 554（许可命题集）** L(Ĉ_coop,Λ) 由证书与台账蕴含的命题组成，至少含：`clearance ≥ d_safe`、`horizon = H`、`norms_passed = n_t`、`abort_point = p*`、`restricted_mode ⇔ Π_r`、以及**全部 hard 介入**（完整性规则）。不含：对他人未来策略的断言（只能引用其已发布承诺）、证书外预测、无法核验的因果解释。

**新增定义 555（言行一致证书 SDC）** 语句 u 由模板 t 与槽位绑定生成，M(u) 为其命题集。SDC-valid(u) ⇔ M(u) ⊆ L(Ĉ_coop,Λ)。生成器只允许槽位取自 L；越权则输出 u_min。**完整性**：每个 hard 介入须在 D_disc=2s 内至少被一条语音覆盖；TTS 失败时 u_min 也算覆盖，但台账记 disclosure_degraded（不升级为 Π_r，除非同时硬介入未覆盖）。

**新增定义 556（语音动作契约）** κ_SDC = (D_tts^start ≤150ms, D_tts^total ≤2s, prosody ∈ {neutral_declarative}（hard 语句强制中性，禁煽动/夸大韵律）, M_tts ≤1.2MB INT8, E_tts ≤300mW 瞬态, 异步且永不阻塞控制)。声学回执：loopback 检测到 RMS≥rms_min 且时长>0 方记 `spoken`；否则 `disclosure_failed`。音量受 ν-QUIE 场景规范约束（夜间降额）。

**新增定义 557（承诺台账 CL）** 条目 = H(prev ‖ epoch ‖ Γ_i（或接收到的 Γ_j）‖ hash(M(u)) ‖ 模板 id ‖ 执行动作哈希 ‖ {spoken|failed|repaired|veto|breach} 标志)。append-only；每 C_w=64 块链头校验点（继承 v10 定义 548）。双视图：形式（Γ）与语音（u）；离线审计检查 `M(u) ⊆ L(已执行)`，即"说的 ⊆ 认证做的"。跨机条目附 provenance，冲突只记录不覆盖。

**新增定义 558（社会风险与 K_eff-v11）** σ_soc(t) = max_j clip(1 − d_j^clear/d_react, 0, 1)，j 遍历 fresh 承诺管与 unknown 他者。有效块长升级为：
```
K_eff(t) = 1                                   若 ¬U_t^sem ∨ Ĉ_coop 不可得 ∨ ∃ unknown ∈ d_react
         = 2                                   若 Π_r ∨ 通信降级（有他者但无新鲜承诺）
         = max(1, ⌊K_max·(1 − min(1, max(Δ_dom/τ_dom, sup_走廊 T/τ_sem, σ_soc/τ_soc)))⌋)   否则
```
三重门控取 max：语义领先、标量域偏移、社会风险任一越阈即收缩；σ_soc→1 时 K→1 退回逐步。

**新增定义 559（规范版本协商）** 握手交换 (version_hash, norm_ids)。版本不一致时运行 N∩ = {ν_j : 各同伴均颁布且取更严 sev}；若 version_hash 不匹配且交集低于法定数或含冲突修复算子 ⇒ Π_r。构造上 N∩ 的可行动作集 ⊆ 各同伴 N_i 的可行动作集。

**新增定义 560（无承诺他者膨胀与退化）** 对 unknown 的 j，以半径 r_j + v_max^soc·τ_react + d_mutual 的动态障碍纳入定义 551；若该膨胀在剩余时域内不可认证（ĝ_min^coop < d_safe），则拒块、退单步或安全停驻。单机时 Unknown=∅，定义 551 退化为 v10 定义 543，故与 v10 等价。

**新增定义 561（承诺摘要与带宽）** 承诺管以 (AABB, 时域, 速度界, 中止点, 纪元) 量化压缩 + 校验和上链；摘要只许**低估** R_i（宁小勿大），否则接收方按摘要外的观测重新膨胀。带宽预算 ≤2KB/管/次。

**新增定义 562（听者解释模型 I）** I: U→2^Prop 为听者从语句 u 实际形成的命题集。弱前提 A7：I(u) ⊆ M(u)（听者不越界解释）。A7 不可证，只能经 E599 人因实验估计；SDC 的正确性以 A7 为条件（引理 94），并明确列出"省略/语气/背景知识"三类残余。

## 2. 形式化定义（要点与升级）

**定义 543（结构化块证书）** 升级为定义 551 的 Ĉ_coop；v10 的 β_STF、n_t、新鲜度条件全部保留，新增 m_t 与 β_comm（承诺摘要量化/网络抖动的余量，经 E591 标定）。**定义 539（有效块长）** 升级为定义 558。δ_trigger 五条件的「Ĉ_t⁺ valid」升级为「Ĉ_coop valid」；块证书失效与单步条件同样触发 M₀ 硬检查（v10 引理 82+81 联合论证原样保持）。STF/NRB/LS 的定义与退化路径不变。

# IP-361 CooperativeTubeContract：承诺式多机协作（不建模他人策略，只校验承诺）
class CooperativeTubeContract:
    def __init__(self, self_id, v_max_self, v_max_soc,
                 H_c=0.5, d_mutual=0.25, tau_react=0.1, delta_br=0.05):
        self.id, self.v, self.v_soc = self_id, v_max_self, v_max_soc
        self.H, self.d_mut, self.tau_r, self.dbr = H_c, d_mutual, tau_react, delta_br
        self.peers, self.latest_epoch = {}, {}

    def d_react(self, self_speed):
        return self_speed * self.tau_r + brake_dist(self_speed) + self.d_mut

    def publish(self, plan, cert, t):
        tube = sweep(plan, self.H)                 # 定义 549
        if not brake_closed(tube, self.v):         # P16：(i) 自身动力学可停
            return None
        if not (tube <= cert.certified_corridor):  # P16：(ii) 管 ⊆ 已认证走廊
            return None
        return Commitment(self.id, tube, t, self.H, self.v,
                          plan.abort_point, plan.epoch)

    def ingest(self, recv, obs_pose, t):
        fresh = {}
        for j, g in recv.items():
            if t <= g.t_pub + g.H and g.epoch >= self.latest_epoch.get(j, -1):
                fresh[j] = g; self.latest_epoch[j] = g.epoch
        breached = [j for j, g in fresh.items()
                    if not g.region.contains(obs_pose(j), tol=self.dbr)]
        unknown = set(observed_agents(t)) - set(fresh)      # 定义 550/560
        return fresh, breached, unknown

    def social_clearance(self, pred, fresh, unknown):
        g = pred.min_clearance
        for j, g_j in fresh.items():
            g = min(g, pred.dist_to_tube(g_j.region) - self.d_mut)
        for j in unknown:
            g = min(g, pred.dist_to(observed_agents_pose(j))
                       - self.v_soc * self.tau_r - self.d_mut)
        return g                                           # 定义 551

    def reconcile(self, commits):
        # 定义 552：静态全序，低优先级只收缩；无环等待
        for a, b in pairs(commits):
            if conflict(a.region, b.region, self.d_mut):
                win, lose = (a, b) if (a.id, a.epoch) < (b.id, b.epoch) else (b, a)
                lose.region = shrink_to_yield(lose.region, win.region)
                if not brake_closed(lose.region, lose.v):
                    lose.abort_point = lose.p_star      # 退到本管中止点
        return commits

class SocietyMonotone:

# IP-354（升级）：社会承诺证书分块执行器
class SocialChunkCertifier(StructuredChunkCertifier):
    def generate_chunk(self, state, ctx, stf, nrb, ctc, sdc):
        K = self.effective_K_social(ctx.delta_dom, ctx.tau_dom,
                                    stf, ctc, ctx)            # 定义 558
        if K == 1:
            return self._single_step_fallback(state)
        best = None
        for cand in self.policy.sample_sequences(state, K, n=64):
            pred = self.Fq.rollout(state, cand)
            beta = self.beta_base + self.lam * stf.field_on_footprint(pred.corridor)
            g_soc = ctc.social_clearance(pred, ctx.fresh, ctx.unknown)
            g_min = min(pred.min_clearance - beta, g_soc)     # 定义 551
            e_max = pred.max_effort + beta + ctx.beta_comm
            if g_min < self.d_safe or e_max > state.tau_eff:
                continue
            pts = self._abort_points(state, cand, pred)
            if not pts:
                continue
            chunk = Chunk(cand, CertCoop(g_min, e_max, beta, ctx.m_t), pts)
            chunk, verdict = nrb.review_chunk(chunk, stf, ctx)
            if chunk is None:
                continue
            # 语音只做"说证书蕴含的话"；异步，不阻塞控制
            utter, state_u = sdc.verbalize(chunk.intent, chunk.cert, ctc.ledger)
            chunk.utterance = utter
            score = self.policy.score(chunk, pred)
            if best is None or score > best.score:
                best = chunk
        return best or self._single_step_fallback(state)

    def midchunk_guard(self, chunk, k_exec, live_obs, stf, nrb, ctc, sdc):
        """50Hz 社会五检 ≤0.5ms；返回 ('continue', k+1) 或 ('abort', p*)"""
        if not chunk.cert_still_valid(live_obs):                 # 检 1（v9 原检）
            return self._nearest_abort(chunk, k_exec)
        stop_inv = (live_obs.nearest_clearance
                    - self.d_brake(live_obs.speed) - self.d_safe)
        if stop_inv < chunk.remaining_len(k_exec):               # 检 2（v9 原检）
            return self._nearest_abort(chunk, k_exec)
        if stf.surprise_near(live_obs.pose) > stf.tau_sem:       # 检 3（v10）
            return self._nearest_abort(chunk, k_exec)
        if nrb.fast_norms(live_obs).violated:                    # 检 4（v10）
            return self._nearest_abort(chunk, k_exec)
        fresh, breached, unknown = ctc.ingest(live_obs.recv,
                                              live_obs.pose_of, live_obs.t)
        if breached or any(ctc.within(live_obs.pose, u, ctc.d_react(live_obs.speed))
                           for u in unknown):                    # 检 5（本轮）
            return self._nearest_abort(chunk, k_exec)
        return ('continue', k_exec + 1)

## 4. 推导

**引理 92（承诺或检出下的协作安全）** 设 (A4) 每条收到的承诺管在发布时 brake-closed；(A5) 每个 fresh 同伴要么遵守其管，要么违背在 τ_det ≤ 1 帧内被检出的概率 ≥ 1−ε_c；(A6) unknown 他者速度 ≤ v_max^soc；(B1) 反应距离满足 d_react ≥ v_self·τ_det + d_brake(v_self) + d_mutual。则按定义 551 认证的 Ĉ_coop 在时域 H 内无碰撞的概率 ≥ 1−ε_c−ε_b。证明分三支：同伴守管 ⇒ 净空对已知区域成立；同伴违背 ⇒ A5 在 τ_det 内检出，B1 保证自车在冲突前可停/绕；unknown ⇒ A6 膨胀球排除。对检出失败取并集界。注记：若 B1 不成立，任何证书都不能保证安全——这不是证明缺陷而是物理极限，故 P16 要求发布前即检查 B1，而不是假装能救。∎

**引理 93（和解无死锁、活性条件）** 静态全序 ≺ + 「低优先级只许收缩」⇒ 等待图无环；最高优先级者的管不受他人收缩影响，除非其自身不可行——由定义 549 发布前已保证可行，故其始终可进展；对优先级归纳得全体在合作假设下进展。拒绝让行者被定义 550 判为违背/无承诺，安全仍由引理 92 保住，活性不保证（诚实标注）。∎

**引理 94（SDC 形式健全与残余风险的三分解）** 设 (A7) 听者解释 I(u) ⊆ M(u)（定义 562，实验可估不可证）；(A8) M(u) ⊆ L(Ĉ_coop,Λ)（SDC 检查）。则 I(u) ⊆ L，而 L 由证书与台账蕴含 ⇒ 听者关于"认证计划"的信念被实际执行计划蕴含（在 v10 证书健全性前提下）。故**形式虚假承诺率 = 0**。残余风险严格分解为：(a) 解释越界（¬A7）；(b) 省略（未强制披露的软信息）；(c) 韵律/语用暗示。硬介入由定义 555 完整性规则强制覆盖，(b) 对 hard 类被消除，对 soft 类仍存。∎

**引理 95（语音控制面隔离）** TTS 异步运行于审计面，控制侧从不读取 TTS 状态；队列满即丢弃并记 disclosure_failed；故相同输入下执行轨迹与 v10 逐位相同，语音时延只影响披露时延不影响安全。声学失败按 P13 只写台账并在下一块触发 Π_r（若硬介入未覆盖），不改变当期控制。∎

**引理 96（共享图单调隔离与投毒上界）** 由定义 553，远端允许更新只增障碍或升 ν ⇒ T_merged(x) ≥ T_local(x) 逐点成立；β_STF 对 T 单调（v10 引理 88）⇒ β 不减。单方恶意更新在 c_corr−1 次独立印证前不能入信；即使入信，其效果也只可能抬高 β（更保守），不能降低证书余量。故投毒代价是**活性/可用性**（多绕路、多停），不是安全性。删除受本地印证 + v10 剪枝不变量双重约束。∎

**引理 97（规范协商支配）** 构造上 N∩ 中每条规范的严重度 ≥ 任一同伴版本中同名规范 ⇒ N∩ 可行动作集 ⊆ 每个 N_i 的可行动作集 ⊆ v10 单机 N 的可行动作集（取任一同伴为参照）。版本不可协商 ⇒ Π_r ⊆ N∩ ⊆ 每个 N_i。故多机规范协商不引入任何 v10 不允许的动作；不一致时只会更严。∎

**引理 98（相对 v10 的保守性局部化）** 单机时 Unknown=∅、无同伴 ⇒ 定义 551 逐项退化为 v10 定义 543，行为等价。多机时，若 v10 想要安全，只能全局膨胀 β 至最坏他者速度覆盖全域（处处保守，活性骤降）；若忽略他者则不安全。CTC 把膨胀限制在**实际承诺管**与**无承诺他者的反应球**内 ⇒ 对同一 ε，认证成功率（活性）不劣于全局膨胀，且安全性与引理 92 同阶。即：CTC 不是"更安全"，而是"同样的安全下把保守性放到该放的地方"。∎

## 8. 本轮最大风险

**一句话**：整套方案把"他人"从不可建模的扰动换成"可信任的承诺"，但承诺可以在制动距离内被策略性违背——1 帧检出不等于来得及避让；而 SDC 只保证"所言被证书蕴含"，不保证听者不越界解释，越流畅一致的语音越会放大人类对这台机器的过度信任，安全最终取决于他者的诚实与听者的解释，而这两者都不是证书能保证的。
