# 第 58 轮（承接第 57 轮「少样本×多模态×个性化」IP-133~138；灵感循环第 1 轮（新周期）；本轮灵感：「场景泛化」×「演示数据」）

> 第 57 轮把证据质量交给一个从历史语料摊销出的元推断器，并自陈其最大风险：**"坏先验普遍"**——元语料若有系统性盲区（某类新材质、某种新耦合从未被探过），元模型会在 OOD 门学会识别的模式之外给出高度自信的错误后验，而 EV-xmodal 的一致加成与个性化授权加速会让这类错误更快进入承诺。根子在于：第 57 轮隐含假设 `z_r=(坡度/材质簇/季节)` 已抓住场景间所有该抓的差异——这个等价关系从未被检验。本轮两个灵感正面拆这个假设：**场景泛化**把"泛化"从模型的整体属性改写成**逐轴可证伪的部分函数**（泛化剖面 C/E/U，元先验只在已认证轴上实例化）；**演示数据**把演示从"一次标注"改写成**穿过状态-控制空间的覆盖凭证 + 探针提议分布**，并显式计量两种偏差（挑选偏差、反事实缺口）。合流命题：**泛化是被演示覆盖"贷"出来的，证伪就是违约**。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据承诺"升级为 **"泛化可证伪、覆盖可凭证、演示可审计的证据承诺"**。

核心矛盾：
- **H29（泛化 vs 轴假设）**：任何泛化声明都预设一个等价关系（哪些场景差异"无关紧要"）。第 57 轮把这个关系藏进 `z_r` 与元模型。若真正的风险轴未被命名，则"已认证泛化"是虚构——**轴集 A 本身就是一个未经检验的先验**。
- **H30（覆盖 vs 安全）**：覆盖说的是"我见过这一格"，安全说的是"我知道这一格在最坏容许扰动下会怎样"。演示覆盖是**标称的、on-policy 的**，高覆盖可以与大的反事实缺口并存。把两者混为一谈，就是第 58 轮版的"把置信当安全"。
- **H31（演示 vs 挑选/博弈）**：演示天然是选择性的（操作者决定给你看什么），一段被挑选的演示是"被当作证据出售的有偏样本"；更糟的是它可以被**舞台化**（只演平地、只演成功）。演示还可能泄漏的是习惯而非真值。故演示必须带出处、支撑匹配与反事实缺口，且不能单独授权不可逆接触。

## 0. 直觉与动机

**灵感 1（场景泛化 → 逐轴泛化剖面，而非一个全局元先验）**
直觉：泛化不是"模型好"这种整体属性，而是"**沿某个方向上，不同场景的差异不影响结论**"这种逐轴命题。像方言互通：你能听懂的不是"所有语言"，而是和你共享音系的那一族。机器人说"我在新场地也能干"时，真正该问的是：它凭什么认为这两个场地的差异无关紧要？本轮把这个"凭什么"变成可检验的东西：轴集 A（地形几何/材质簇/光照/载荷/速度域/季节……），每条轴给一个状态 C（已认证：该轴敏感性上界 ≤ s_a）/ E（外推：有弱证据、部分池化）/ U（未知：无证据、退回共形带）。**元先验只允许在 C 轴子向量上实例化**——泛化从"模型的属性"变成"逐轴可证伪的部分函数"。第 57 轮的语料盲区由此从"隐藏风险"变成"账本上一行 U"。

**灵感 2（演示数据 → 覆盖凭证 + 提议分布，而非真值标注）**
直觉：演示不是一次标注，而是一根**穿过状态-控制空间的管子**：它证明"沿这条轨迹存在可行控制"，一次覆盖一整片状态-控制邻域——比单点标签值钱。但它也比标签危险：①操作者只演示他想给你看的（**挑选偏差**，可被舞台化）；②演示的是标称轨迹（**反事实缺口**：ε 扰动后会发生什么，演示没说）；③演示把一个坏习惯拍得很自信（**策略泄漏 ≠ 正确性证明**）。所以演示的正确用法是双重的：**覆盖凭证**（"这一格被安全穿越过"）+ **探针提议分布**（"该优先去哪一格补探针"）。同一段演示重复五遍，仍然只覆盖同一条管子——这是对第 57 轮"同一模态问五遍"的升级版批评。

**灵感 3（合流 → 泛化账本：借与违约）**
直觉：场景泛化给"轴"，演示数据给"轴上的覆盖凭证"。合起来是一个比第 57 轮更诚实的经济学：**泛化是被演示覆盖"贷"出来的，证伪就是违约**。覆盖账本逐轴记录"借了多少、哪里违约"；任何证伪事件全局降级该轴并回溯撤销依赖它的覆盖。而唯一诚实的"未知未知"处理，是**未知轴发现**：不宣称覆盖了它，只检测"你的本体论不完整"——残差聚类若不能被现有轴解释，就开一条新轴并全局保守化。这也让第 57 轮的"事后证伪回溯"从模态可靠性推广到**场景轴与覆盖凭证**。

**灵感 4（PCE++ → 探询预算由覆盖边界与反事实缺口驱动）**
直觉：VOI 改为"缩短覆盖边界 / 降低 CF-gap / 认证最弱轴"的期望收益；演示用于给探针**热启动选址**；新增动作 **主动演示请求（Active Demo Request）**——让操作者演示难区（成本=人的时间，收益=覆盖增加），但请求来的演示仍须过 DEM 门、仍不得单独授权不可逆接触，且须与主动探针交叉验证（防舞台化）。进入未覆盖 cell 自动加宽、降档、绕行。四个安全通道不变：更准或更保守；但新增一个**显式残差 δ_axis**（未知轴逃逸）。

**灵感 5（与第 57 轮的接口）**
MFSL → **MFSL-G**（只在 C 轴摊销，E 部分池化，U 切共形带）；FSE → **FSE++**（新增 EV-demo 与覆盖门）；PCE+ → **PCE++**；`J_p` → **`J_q`**（加入泛化剖面、覆盖凭证、演示出处、CF-gap、账本）。OOD 判据也从原始特征密度改为"不变特征 + 逐轴残差"：一个场景可以密度上分布内，却在演示覆盖上未覆盖（别的任务见过）——两者都要，缺一不可。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（场景族分解与泛化剖面 SFD）** 场景空间 𝒮，描述子 z=(z^inv,z^nui)，风险相关轴集 A={a_1..a_m}，场景族 F⊆𝒮。泛化剖面 G_F:A→{C,E,U}：轴 a 认证为 C ⇔ 存在演示/探针证据集 D_a 使"仅沿 a 改变场景时响应差 ≤ s_a"以置信 1−α_a 成立（分层不变性检验或逐轴共形带宽 ≤ w_a）；E ⇔ 弱证据未达阈值；U ⇔ 无证据。元先验仅在 C 子向量上实例化 q_φ(θ|o,z_C)；E 用分层部分池化；U 强制共形带。**轴集 A 本身可被 GDL 扩充，但只能增加、不能删除。**

**定义 140（演示覆盖凭证 DCC）** 演示 d=(τ_d=(x_{0:T},u_{0:T}), c_d, o_d, y_d, prov_d)，场景格 c_d、操作者 o_d（可靠性取第 57 轮 PTM 的 w_h）、结果 y_d∈{succ,fail}、出处 prov_d。对声明扰动预算 ε 与度量 G，状态-控制管 T_ε(τ_d)={∪_t {(x,u):‖(x,u)−(x_t,u_t)‖_G≤ε}}。点覆盖密度 κ_ε(x,u)=max_d [w_{o_d}·e^{−λ age_d}·1{(x,u)∈T_ε(τ_d)}·1{y_d=succ}]。区域覆盖 Cov_ε(R|F)=μ(R)^{−1}∫_R κ_ε；缺口 Gap_ε(R)=1−Cov_ε。失败的演示**不产生负覆盖**，而是进入危险集 H_ε(R)（失败证据，永不清除）。**非声明**：x∉∪T_ε ⇒ unknown，不得推断为 safe；凭证只在声明支撑集与声明 ε 下有效。

**定义 141（场景泛化推断 SGI，含测试时自适应护栏）** 目标区域 r 的覆盖度 κ_r=Cov_ε(r)、相关轴认证比 c_r=|C∩A_rel|/|A_rel|、反事实缺口 γ_r（定义 143）。泛化声明强度 G(r)=g(κ_r,c_r,1−γ_r/γ_max)∈[0,1]，单调增于覆盖与认证轴比、减于 CF-gap；仅当 G(r)≥G_0 时作为证据权重入账。后验 b_r=(1−π_r)·Σ_d α_d(r)m_d+π_r·b_prior，π_r=1−G(r) 为"退向宽先验"的质量，α_d∝κ_ε·sim。测试时自适应（TTA）获准条件：更新 u_t 必须落在**保守锥**内——要么后验宽度不降，要么调度风险 R(π) 不增；否则拒绝并记 **adaptation conflict**（该冲突本身是分布漂移的弱证据，喂给 GDL）。

**定义 142（演示证据门 DEM 与反挑选）** EV-demo 支持接触 c ⇔ ①c 的状态-控制邻域 ⊆ T_ε(τ_d)；②场景格在 C 轴上匹配、在 E 轴上容差内；③出处可验且操作者授权满足 PTM；④**支撑匹配**：部署分布 p_deploy 与演示分布 p_demo 的密度比有界（重要性权重 ≤ W_sup）或两样本检验不拒绝，否则仅当部署被限制在演示支撑集内才可用；⑤CF-gap γ_r≤γ_0；⑥演示熵 H(p_demo)≥H_min（反"只演一格"）。EV-demo 至多替代一次 **L1** 佐证，**不得进入不可逆接触的必要证据集**（与 EV-xmodal 同级的隔离）。`主动演示请求`所得演示同样受此门约束，且须与主动探针结果一致才升为证据。

**定义 143（反事实缺口 CFG）** γ_ε(R)=sup_{‖δ‖_G≤ε}[risk(τ+δ;R)−risk(τ;R)]_+，或分布形态的 sup_δ JS(p(·|τ),p(·|τ+δ))。可证上界用局部 Lipschitz 代理 γ≤L_loc·ε，并要求 γ 进 P_fail。**覆盖凭证证明标称安全，CF-gap 证明"离最坏扰动还有多远"**；两者缺一不可。

**定义 144（泛化亏损账本 GDL 与未知轴发现）** 账本 ℒ_F 逐轴记状态、支撑证据、上次证伪时间，逐格记覆盖、CF-gap、依赖映射 Dep(cell,a)。证伪事件 ℱ=(F,a,残差签名,t)：①G_F(a)←U；②依赖 a 的覆盖全部按 Dep 回溯撤销（乘性衰减至 0），相关 EV-demo/EV-probe 失效直到重新演示并通过回归测试；③升级需新鲜证据 + 测试时"假认证率不升"的回归门。**未知轴发现**：证伪残差若聚类后不能被现有 A 解释（似然比/方差分解显著），开新轴 a_new 置 U，对族 F 全体 G(r) 乘保守因子 β<1，强制非参回退——**不宣称覆盖，只承认本体论不完整**。单调性：无新鲜证据不得上调任何状态。

## 2. 关键算法伪代码（完整版见产物区）

```python
def generalize_and_gate(M, r, demo_lib):              # IP-139/140/141 合流
    prof = scene_profile(M, r)                          # G_F: A -> {C,E,U}
    kappa, gap = coverage(r, demo_lib, eps=EPS, axis=prof.certified)
    gamma = cf_gap(r, demo_lib, eps=EPS)                # IP-143
    G = claim_strength(kappa, prof, gamma)              # 0..1
    if prof.has_unknown_relevant or G < G_0:
        return Inf(cls='BELT', belt=conformal_belt(M, r)), G, gamma
    return Inf(cls='SGI', post=mixture(M, r, kappa), G=G), G, gamma

def demo_evidence_gate(d, c, prof, persona, ledger):    # IP-142
    ok = (c.nbr in tube(d, EPS) and cell_match(prof, d) and
          prov_ok(d) and persona[d.op].auth >= 'A1' and
          support_match(d, deploy_stats) and cf_gap(c) <= GAMMA_0 and
          entropy_ok(d))
    return 'EV-demo' if ok and c.level == 'L1' else 'reject'

def gdl_falsify(ledger, F, axis, resid):                # IP-144
    ledger.demote(F, axis)                              # 单调降级 + 回溯撤销
    if unexplained(resid, ledger.axes(F)):
        a_new = open_axis(resid); ledger.freeze(F, beta=BETA)
    return ledger
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| SFD | O(\|A\|·N_demo) 建族；O(\|A\|) 查询 | O(\|A\|) | 认证诚实、U 轴禁用摊销先验 |
| DCC | O(log N_demo+k) 查询；O(1) 摊还更新 | O(N_demo·d) | 覆盖只在声明 ε/支撑集有效、失败留痕 |
| SGI | O(d·\|neighbors\|) | O(d) | π_r=1−G 单调、TTA 只加宽 |
| DEM | O(k_nbr+1) | O(1) | 支撑匹配、仅限 L1、反挑选 |
| GDL | O(1) 证伪 + O(受影响格) 撤销 | O(\|A\|+\|cells\|) | 单调降级、未知轴保守 |
| PCE++ | O(\|CP\|·k_p·(C_VOI+d+\|A\|)) | O(\|V\|+\|A\|+\|cells\|) | 覆盖边界导向、有限终止 |

**正确性定理（GCDS 概要）**：在 A37–A40 上加 (A41) 覆盖凭证诚实（声明 ε 与支撑集、失败留痕、密度比有界）；(A42) 泛化剖面诚实（C 轴不变性检验水平 α_a、元先验仅用 C 轴、U 轴走共形）；(A43) 演示出处与支撑匹配诚实、EV-demo 仅限 L1 且不单独授权不可逆接触；(A44) CF-gap 是声明 ε 下的有效上界、GDL 单调且未知轴发现保守。则：(i) 承诺失效率 ≤ δ_f+ε_meta·1[ID∩C]+δ_ood·α_conf+γ_ε(r)+δ_demo·1[L1]；(ii) 交互单调性再次强化：泛化与演示只能经"覆盖支撑内提高证据权重"或"更保守（加宽/降档/绕行）"影响系统，TTA 不能收窄后验；(iii) PCE++ 在 k_probes+k_cons+k_demo 内终止；(iv) 部署界显式含**未被任何证书界住的 δ_axis**（未知轴逃逸）。

## 6. 本轮最大风险

**一句话**：本轮把第 57 轮"语料盲区"从隐藏风险改造成显式的场景轴账本，但账本只能记录**已被命名的**轴——演示覆盖凭证会在未命名的风险轴上签发虚假的安心，而未知轴发现本质上是事后检测、无法事前预防，因此 `δ_axis` 是本方案唯一不被任何证书界住的残差。

## 2. 关键算法伪代码

### IP-139 SFD（场景族分解与泛化剖面）

```python
def scene_profile(M, r, A):
    prof = {}
    for a in A:
        # 仅沿 a 改变场景的对照对，检验响应差上界
        pairs = heldout_pairs(M.demos, axis=a, same_other_axes=True)
        sens  = max(resp_distance(M, z1, z2) for z1, z2 in pairs) \
                if pairs else float('inf')
        if len(pairs) >= n_min and sens <= s_a:
            prof[a] = 'C'                      # 已认证：可实例化元先验
        elif pairs:
            prof[a] = 'E'                      # 弱证据：分层部分池化
        else:
            prof[a] = 'U'                      # 无证据：禁用摊销，切共形带
    return Prof(prof, A=A, certified={a for a in A if prof[a] == 'C'})
```

### IP-140 DCC（演示覆盖凭证）

```python
def coverage_certificate(demos, R, eps, axis_set, supp):
    # 只统计声明支撑集 supp 内的格，且只对声明轴集认证
    cells = dice(R, eps=eps)
    if not covers_support(cells, supp):        # 越出支撑集 → 整段作废
        return Cov(0.0, gap=1.0, valid=False)
    for d in demos:
        if d.y != 'succ':
            hazard.add(tube(d, eps)); continue  # 失败留痕，不产生负覆盖
        for (x, u) in sample(tube(d, eps), cells):
            kappa[x, u] = max(kappa[x, u],
                              d.w_h * exp(-LAM * age(d)) * in_supp(x, u))
    cov = integral(kappa, R) / measure(R)
    gap = 1 - cov
    return Cov(cov, gap, hazard=hazard, eps=eps, axes=axis_set)
```

### IP-141 SGI（场景泛化推断 + TTA 保守锥）

```python
def scene_generalize(M, r, demos):
    prof  = scene_profile(M, r, A)
    cert  = coverage_certificate(demos, r, EPS, prof.certified, supp)
    gamma = cf_gap(r, demos, EPS)              # IP-143
    G     = claim_strength(cert.cov, prof, gamma)   # 单调：cov↑, cert↑, gamma↓
    if prof.has_unknown_relevant() or G < G_0:
        return Inf(cls='BELT', belt=conformal_belt(M, r)), G, gamma
    mix = (1 - (1-G)) * weighted_models(demos, r, cert) + (1-G) * wide_prior(M, r)
    return Inf(cls='SGI', post=mix, G=G), G, gamma

def tta_guard(post_old, post_new, R_old, R_new):
    wider  = width(post_new) >= width(post_old)
    safer  = R_new <= R_old + 1e-9
    if not (wider or safer):                    # 非保守更新一律拒绝
        gdl_note_adaptation_conflict()
        return post_old
    return post_new
```

### IP-143 CFG（反事实缺口）

```python
def cf_gap(r, demos, eps):
    # 可证上界：局部 Lipschitz 代理 + 扰动集合经验 sup
    L = local_lipschitz(r, demos)
    bound = L * eps
    emp = max(risk_ratio(tau, perturb(tau, eps)) for tau in demos if in_region(tau, r))
    return max(bound, emp)                    # 进 P_fail，取保守值
```

### IP-144 GDL（泛化亏损账本 + 未知轴发现）

```python
def gdl_update(ledger, F, event):
    if event.kind == 'falsify':
        a = event.axis
        ledger.set(F, a, 'U')                              # 单调降级
        for cell in ledger.cells_depending_on(F, a):
            ledger.retract_coverage(cell)                  # 回溯撤销
        ledger.invalidate_evidence(F, a)                   # 相关 EV 失效
    elif event.kind == 'confirm':
        if ledger.regression_ok(F, event):
            ledger.maybe_promote(F, event)                 # 有界、需回归门
    if unexplained(event.residual, ledger.axes(F)):        # 本体论不完整
        a_new = ledger.open_axis(F, event.residual)
        ledger.freeze(F, beta=BETA)                        # β<1 全局保守化
        force_nonparametric_belt(F)
    return ledger
```

### IP-138+ PCE++（覆盖导向探询 + 演示热启动 + 主动演示请求）

```python
def probe_commit_evolve_pp(x0, M, task, budget, consent, personas, demos):
    route = plan_on_scene_profile(M, task, risk_model)     # 优先已覆盖走廊
    sched, log = [], []
    for cp in route.checkpoints:
        inf, G, gamma = scene_generalize(M, cp.region, demos)
        M.b[cp.region] = inf.post if inf.cls == 'SGI' else worst_in(inf.belt)
        sigma = foothold_schedule(x0, cp, M); R = schedule_risk(sigma, M)
        while select_gait(R) == 'halt' and budget.probes_left > 0:
            cands = admissible_probes(cp, M, F_abs)
            if not cands:
                if budget.demo_left > 0 and G < G_DEMO_REQ:
                    M, ok = active_demo_request(cp, M, personas.active, budget)
                    if ok: budget.spend_demo(); continue
                break
            p = argmax(cands, key=lambda q: voi_pp(q, M, inf, G, gamma) - cost(q))
            if voi_pp(p, M, inf, G, gamma) < theta_voi: break
            M, _, D = xmodal_fuse(M, cp.region, execute_probe(p, cap=F_abs))
            if D > theta_D and 'consensus' not in cp.done:
                M, _, D = xmodal_fuse(M, cp.region,
                                      execute_probe(most_disagreeing(cp), cap=F_abs))
                cp.done.add('consensus')
            if coverage_boundary(cp, M) or gamma > GAMMA_WIDEN:
                widen_and_downshift(M, cp)                 # 未覆盖自动保守
            sigma = reselect_footholds(x0, cp, M); R = schedule_risk(sigma, M)
            budget.spend(p)
        g = select_gait(R); lv = contact_level(cp)
        ev = tag_evidence_q(sigma, M, lv)
        if g != 'halt' and fse_pp_gate(core_contact(cp), M, personas, demos)[0] == 'ok':
            sched.append(commit(sigma, g)); log.append(ev); continue
        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, M)) != 'halt': route = alt; continue
        return negotiate_or_stop(cp, M, sigma, R, consent,
                                 tau_int=tau_int(personas.active.auth))
    return sched, log, M

def voi_pp(q, M, inf, G, gamma):
    # 价值 = 缩小覆盖边界 / 降低 CF-gap / 认证最弱相关轴
    return (w1 * expected_coverage_gain(q) + w2 * expected_cf_gap_reduction(q)
            + w3 * expected_axis_certification(q) - w4 * (1 - G) * risk(q))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SFD | O(\|A\|·N_demo) 建族；O(\|A\|) 查询 | O(\|A\|) | 认证诚实、U 轴禁摊销（A42） |
| DCC | O(log N_demo+k) 查询；O(1) 摊还更新 | O(N_demo·d) | 只覆盖声明 ε/支撑集，失败留痕（A41） |
| SGI | O(d·\|nbr\|) | O(d) | π_r=1−G 单调、TTA 只加宽（A41/A44） |
| DEM | O(k_nbr) | O(1) | 支撑匹配、反挑选、仅限 L1（A43） |
| CFG | O(\|demos\|) 经验 + O(d) 代理 | O(d) | ε 上界进 P_fail（A44） |
| GDL | O(1) 证伪 + O(受影响格) 撤销 | O(\|A\|+\|cells\|) | 单调降级、未知轴保守（A44） |
| PCE++ | O(\|CP\|·(k_p+k_c+k_d)·(C_VOI+d+\|A\|)) | O(\|V\|+\|A\|+\|cells\|) | 覆盖导向、有限终止 |

**正确性定理（Generalization-Covered Demonstration Soundness, GCDS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 覆盖凭证诚实：覆盖只在声明扰动预算 ε、声明支撑集 supp、声明轴集 A 下成立，失败演示留痕，部署/演示密度比有界（`W_sup`）；**(A42)** 泛化剖面诚实：C 轴通过水平 α_a 的不变性检验，元先验仅在 C 轴子向量实例化，E 轴部分池化，U 轴走共形带；**(A43)** 演示出处可验、支撑匹配检验有效、覆盖熵 ≥H_min，EV-demo 仅限 L1 且不进入不可逆接触必要证据集；**(A44)** CF-gap 是声明 ε 下的有效风险上界，GDL 更新单调（证伪只降不升、再认证过回归门），未知轴发现保守（未解释残差即冻结并全局保守化）。则：

1. **承诺健全性**：`P(fail) ≤ δ_f + ε_meta(k)·1[ID∩C] + δ_ood·α_conf + γ_ε(r) + δ_demo·1[L1]`。
2. **单调性再次强化**：泛化与演示只能经 (a) 覆盖支撑内提高证据权重，或 (b) 更保守的动作参数（加宽/降档/绕行/更短 τ_int）影响系统；TTA 落在保守锥外即拒绝并记录 adaptation conflict，不存在收窄后验的升险路径。
3. **终止性**：演示请求 ≤k_demo、共识探针 ≤k_cons，每次探针要么覆盖新格、要么把 γ 降至 γ−Δ，否则停；PCE++ 终止于 {承诺, 绕行, L2 协商, 安全停}。
4. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k)·1[ID∩C] + δ_ood·α_conf + γ_ε(r) + δ_demo·1[L1])
             − P(𝓜 陈旧未检出) − P(护盾回退失败) − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
             − δ_axis
```

关键：**泛化只在已认证的轴上成立**（把第 57 轮的隐藏等价关系暴露成可证伪命题）；**覆盖只证明标称安全、CF-gap 才证明最坏扰动安全**（两者缺一不可）；**演示是覆盖凭证与提议分布，不是真值**（出处+支撑匹配+覆盖熵+仅限 L1 四重隔离）；**账本单调、未知轴保守**。而 `δ_axis` 是唯一不被任何证书界住的项——它诚实地标记"你的轴集可能不完备"。

## 6. 本轮最大风险

**一句话**：本轮把第 57 轮的"语料盲区"从隐藏风险改造成显式的场景轴账本，但账本只能记录**已被命名的**轴——演示覆盖凭证会在未命名的风险轴上签发虚假的安心；未知轴发现本质上是事后检测、无法事前预防，因此 `δ_axis` 是本方案唯一不被任何证书界住的残差；必须以"覆盖只作凭证不作真值、CF-gap 强制进 P_fail、演示仅限 L1、账本单调降级、未知轴即冻结回退"五重护栏，宁可退回又宽又慢的非参区间，也绝不把"演示过"说成"安全"。
