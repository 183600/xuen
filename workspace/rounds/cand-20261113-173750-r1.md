# 第 1 轮（灵感循环第 1 轮；本轮灵感：「数字孪生」×「事件相机」）

> 立题：数字孪生擅长回答“如果我这样做，世界会怎样”，却不知道自己什么时候已经错了；事件相机擅长回答“世界刚刚在哪里、何时变了”，却不知道静止的世界长什么样。本轮把二者组合成一个**可被实时证伪的孪生**：不是让事件相机去“融合修正”孪生，而是让孪生先预言自己的事件签名，再用事件流检验它。核心命题是：
>
> **孪生提供可反事实的假设，事件相机提供微秒级、HDR 的时间戳证据；信任不是标量，而是由事件可观测子空间决定的方向性椭球——没有回声的方向，不得发安全证书。**

## 0. 直觉与动机

**灵感 1（数字孪生 = 可反事实的“影子”，但影子会撒谎）**
直觉：数字孪生 = 实时同步的虚拟副本（状态估计 + 物理模型 + 渲染/几何），它最大的价值不是“看起来像”，而是能在真实执行之前**反事实地跑一遍**：如果这样抓、这样插、这样压，接触会不会发生在预测的位置，滑移会不会出现，形变会不会超限。对接触丰富的操作，这比纯反应式控制强得多。但必须诚实：孪生的误差是**结构化的**（sim-to-real gap、接触模型错、标定漂移、时延），不是零均值噪声；更危险的是，孪生永远能给出一个自信的未来，它**不知道自己正在错**。所以本轮的第一原则不是“把孪生做得更真”，而是“**让孪生在实时可被证伪**”。

**灵感 2（事件相机 = 只报告“变化”的微秒级证人）**
直觉：事件相机不对固定帧率采样，而是每个像素在亮度对数变化超过阈值 C 时异步发出一个带微秒时间戳、带极性的事件。它有三个近乎“作弊”的优点：微秒级延迟、>120dB 高动态范围、无运动模糊；也有三个致命的限制：没有绝对亮度、静止/无纹理处几乎无事件、事件只在有相对运动时出现。换句话说，事件相机不告诉你“那里有什么”，只告诉你“**什么时候、在哪里、以什么极性发生了变化**”。这恰好是检验孪生预言所需要的：一个预言本质上就是“在某个时刻、某个位置、某个方向会发生某个变化”。

**灵感 3（互补不是相加，而是互证）**
直觉：孪生看得见静态结构与语义，却看不见实时真值；事件相机看得见实时变化，却看不见静态结构。最自然的组合不是后期融合两路特征，而是构造一个**预测—检验闭环**：孪生用几何/物理渲染出“如果我是对的，事件流应该长什么样”，事件相机返回带时间戳的残差。孪生提供假设，事件流提供判决。这样，事件相机不需要重建整幅图像，孪生也不需要假装自己是真值，二者都只做自己最擅长的事。

**灵感 4（信任是有方向的：事件可观测子空间）**
直觉：并非所有孪生误差都会被事件看见。相机沿一条直边运动时，沿边方向的位移不产生事件（孔径问题）；静止场景更是完全不产生事件。因此事件对孪生的“证伪能力”有一个**零空间**。把信任压缩成一个标量（甚至一个各向同性的球）在数学上是错的；正确的对象是**方向性信任椭球**：在事件可观测方向上被证书覆盖，在零空间方向上保持先验不确定度，必须显式标注“不可观测”，而不是偷偷当作“没问题”。

**灵感 5（用主动微激发打破沉默）**
直觉：没有事件时，无法区分三种情况：(i) 孪生正确且场景静止；(ii) 物体无纹理/被遮挡/透明度高；(iii) 事件传感器坏了。沉默本身是多义的。解决办法不是等它动，而是**主动制造一个已知的、极小的、任务无关的激发**——微幅摆动、微旋转、结构光/亮度心跳——然后看事件流是否给出预期的回声。已知输入下的沉默是传感器故障的证据；已知输入下的回声则能缩小零空间。这把事件相机从“被动证人”变成“主动审问者”。

**灵感 6（合流 → ECHO：Event-Certified Hybrid Observer）**
ECHO 的闭环：孪生反事实推演（DTE）→ 预测事件签名（ESP）→ 运动补偿事件对齐与事件时间残差（ETA）→ 残差场（ERF）→ 事件可观测子空间与方向性信任椭球（EOS/TTE）→ 结构化故障归因（ECA）→ 不可观测时主动事件激发（AEP）→ 事件认证执行前缀（ECP）→ 异步早停。它与此前“多传感器谁更可信”的思路不同：**这里不问“该信谁”，而问“孪生在哪个方向、哪个时间窗内能被事件证据支持”**。一句话概括 ECHO：**孪生先说“将会发生什么”，事件相机回答“真的发生了吗、何时、在哪个方向”；没有回声的地方，不许发证书。**

## 1. 形式化定义（定义 1–14）

- **定义 1（事件流与时间表面）**：事件流 E_{[t_0,t]}={(t_i,x_i,p_i)}_{i=1}^{N(t)}，其中 t_i 为微秒时间戳，x_i∈Ω⊂ℝ²，p_i∈{+1,−1}。定义像素时间表面 T_t(x)=t−t_last(x)（或带符号的时间表面），ROI 事件率 λ(t,R)=N(t,R)/(|R|Δt)。事件流是“变化的时间戳集合”，不是强度图像。
- **定义 2（事件生成模型）**：令 L(x,t)=log I(x,t)。当 |L(x,t)−L(x,t_last)|≥C 时像素 x 发事件。对图像运动速度 u(x,t)，事件率近似 λ(x,t)≈|∇L(x,t)·u(x,t)|/C。该式把“孪生预测的运动”与“事件率/事件时刻”连接起来，是全部残差的物理基础。
- **定义 3（数字孪生与事件签名预测）**：孪生 M=(f,h,θ,Σ_θ)，状态 z_t（物体/末端位姿、速度、接触状态、材料参数），动力学 z_{t+τ}=f(z_t,u_t;θ)+w。给定候选动作块 u_{t:t+H}，孪生反事实 rollout 得 ẑ_{t+τ|t}，并由几何/反射率/相机运动预测事件率场 λ̂(x,t+τ) 与预测时间表面 T̂(x)。事件签名预测不要求像素级完美重建，只要求预测**边缘运动的方向与时刻**。
- **定义 4（运动补偿事件对齐与事件时间残差）**：对候选孪生轨迹 ξ，把事件按时间 warping 到参考时刻：x_i′=W(x_i,t_i;ξ)，构造 warped event image I_W(x;ξ)=Σ_i p_i δ(x−x_i′)。对齐分数 S(ξ)=Var(I_W)（或负熵/对比度）。定义轨迹级残差 e_e(ξ)=S(ξ*)−S(ξ_twin)，其中 ξ*=argmax_{‖ξ−ξ_twin‖≤ρ}S(ξ)；以及像素级事件时间残差 r_i=t_i−t̂(x_i;ξ_twin)。e_e 度量“用孪生轨迹解释事件流，比用附近最佳轨迹解释差多少”。
- **定义 5（事件可观测子空间）**：在 ξ_twin 处线性化 I_W(ξ)≈I_W(ξ_0)+J_e δξ，事件噪声协方差 Σ_e（含泊松/折射噪声）。事件 Fisher/Hessian H_e=J_eᵀΣ_e⁻¹J_e。可观测子空间 O=range(H_e)，零空间 N=ker(H_e)，可观测秩 r_e=rank(H_e)。沿方向 v 的孪生误差可检测性由 vᵀH_e v 给出；v∈N 时事件对该方向**原则上无信息**。
- **定义 6（方向性孪生信任椭球 TTE）**：孪生误差 δ=ξ_true−ξ_twin。在标定集上用事件残差做 split-conformal，得阈值 q_e(α)。定义 TTE：T_t(α)={δ: δᵀH_eδ≤q_e(α)}，并在 N 上叠加先验/其他传感器的保守椭球。对任务方向 v（例如末端沿法向的位移、接触力的切向分量），仅当 v∈O 且 vᵀH_ev≥κ_min 时才称“该方向被事件认证”。TTE 是**椭球**，不是球；“不可观测”必须显式传播到证书。
- **定义 7（事件时间接触/滑移检测）**：接触起始时刻 τ̂_c 定义为接触 ROI R_c 内事件率首次超过基线 kσ 且极性与预测法向运动一致的时刻；滑移起始由事件流切向位移/散度的突变给出。由事件生成模型，时间估计的 Cramér–Rao 下界 Var(τ̂_c)≥σ_e²/(Nκ²)，其中 N 为 ROI 事件数、κ 为事件率的时间斜率。高动态范围下帧相机饱和，而事件相机仍保留 κ，因此高速/强反光场景的时间证据更锐利。
- **定义 8（故障假设与结构化归因 ECA）**：ℋ={H0 健康, H_model 孪生模型错, H_calib 标定/外参/尺度漂移, H_sync 时间戳/时延错位, H_event 事件传感器故障/噪声, H_illum 全局光照/闪烁, H_common 共因失效（透明/遮挡/反光同时骗过孪生与事件）}。把残差场结构化分解为 r_e(x,t)≈Φ_sync(t)θ_sync+Φ_calib(x)θ_calib+Φ_model(x,t)θ_model+Φ_illum(t)θ_illum+ε；不同故障对应不同支撑/时间结构：全局平移→H_sync，随速度增长的平滑空间残差→H_calib，仅在接触时刻/接触点出现→H_model，事件率塌缩/盐椒噪声→H_event，全图同时同极性爆发→H_illum。归因后验 P(H|r_e)∝p(r_e|H)P(H)，熵高则判 ambiguous。
- **定义 9（主动事件激发 AEP）**：当事件支持不足（低纹理、静止、孔径、零空间大）时，选择安全微激发 u_ex（微幅摆动/微旋转/结构光心跳）：
  u_ex*=argmax_{u∈U_safe} log det(H_e(u)+εI)，s.t. 任务误差≤ε_task、力≤f_safe、可逆。
  其作用是 (i) 用已知输入的回声缩小零空间；(ii) 用“激发后仍无事件”判 H_event（心跳测试）；(iii) 为方向性信任椭球补充秩。易损/高精度任务优先选择视觉/光照激发而非接触激发。
- **定义 10（事件认证执行前缀 ECP）**：给定动作块 A_{t:t+H}、TTE 与故障后验，选择最小 k*≤min(H,m)（m 为不可逆视界），使得对每个可能故障假设、每个 s≤k*，任务风险方向均被 TTE 覆盖或由保守先验界定，且预测安全裕度≥0。执行 k* 步后强制重规划；事件监控器以异步方式在残差越界时立即中止（微秒级中断），而不是等到块边界。
- **定义 11（ECHO 证书 J_echo）**：J_echo=(J_base, twin_version, event_calib_ver, sync_offset, r_e, observability_rank, tte_params, fault_posterior, fault_entropy, k*, null_directions, aep_heartbeat_ok, common_cause_flag)。Valid(J_echo) ⇔ J_base 有效 ∧ 动作风险方向均被 TTE 覆盖或已执行 AEP ∧ r_e≤q_e(α) ∧ k*≥1 ∧ 零空间方向已显式标注并保守处理 ∧ 时间同步在界内。
- **定义 12（ECHO 闭环算子）**：慢回路（语义/模型流）：孪生状态更新→反事实 rollout→事件签名预测→结构化归因→AEP 规划→TTE/证书构建；快回路（事件/实时流）：事件摄取→运动补偿→残差/对齐→异步早停→前缀派发。不变式：**孪生渲染、故障归因、AEP 规划、证书只在慢回路；快回路只做事件对齐、残差计算、早停与执行，零学习写操作。**
- **定义 13（共因失效与互补性）**：设孪生失效事件 F_M 与事件传感器失效事件 F_E。互补性不是假设独立，而是显式建模耦合：P(F_M∧F_E)=P(F_M)P(F_E)+Δ_common，Δ_common 由同一反射率/几何/光照模型导致。ECHO 在 H_common 下不要求归因正确，只要求判 ambiguous 并退化为保守控制。
- **定义 14（沉默证据与心跳）**：对已知激发 u_ex，若预期事件签名 Ê(u_ex) 未出现，则似然比 Λ(silence|u_ex)=p(no event|H_event)/p(no event|H0) 用于判定传感器故障；若未激发且无事件，则只能输出 `event_unobservable`，禁止将其解释为“孪生正确”。

## 2. 关键算法骨架

```python
# 慢回路：孪生反事实 + 事件签名预测 + 归因 + 证书
def echo_slow_loop(M, obs, A):
    z_hat = M.twin.update(obs)                         # 状态估计
    rollout = M.twin.counterfactual(z_hat, A, H=M.H)   # 反事实未来
    ev_sig = M.esp.predict(rollout)                     # lambda_hat, T_hat
    warped = M.eta.warp(obs.events, rollout.traj)       # 运动补偿
    r_e, H_e = M.eta.residual_and_hessian(warped, ev_sig)
    O, N = observable_subspace(H_e)                     # 可观测/零空间
    post, ambiguous = M.eca.attribute(r_e, warped, H_e)
    if rank(H_e) < M.r_min or ambiguous:
        u_ex = M.aep.choose(H_e, post, M.f_safe)       # 微激发/心跳
        if u_ex is not None: M.execute_safe_excitation(u_ex)
    tte = M.tte.calibrate(H_e, r_e, alpha=M.alpha)
    k_star = M.ecp.certified_prefix(A, tte, post, M.m, M.alpha_chunk)
    return tte, post, k_star, ev_sig

# 快回路：事件流对齐 + 异步早停 + 前缀执行
def echo_fast_loop(M, A, k_star, tte):
    for s, a in enumerate(A[:k_star]):
        dispatch(a)
        e = M.eta.async_residual()                      # 微秒级
        if e > tte.threshold or M.eca.cusum_alarm():
            abort(a); return 'replan'
    return 'prefix_done'
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 1（事件可观测性与 CRB）**：若事件残差线性化成立，则 H_e=J_eᵀΣ_e⁻¹J_e；沿 v∈O 的误差估计方差下界为 vᵀH_e⁺v，v∈ker(H_e) 时无下界。因此事件只能认证 O 内的方向，不能认证 N。
- **引理 2（沉默的多义性）**：在窗口 W 内无事件时，任何满足 J_eδ=0（或低于事件阈值）的孪生误差 δ 与 δ=0 在事件似然下不可分；零事件的后验在 N 上保持先验方差。故“无事件”不能被解释为“孪生正确”，只能解释为“该方向不可观测”。
- **定理 1（方向性信任的覆盖）**：在事件残差可交换、conformal 校准有效的条件下，对 v∈O，P[|vᵀδ|>√(q_e(α)·vᵀH_e⁺v)]≤α。对 v∈N，H_e⁺v=0 但事件对该方向无信息，证书必须标注 `unobservable` 并用先验/其他传感器兜底；不得给出与 O 内相同的置信度。
- **定理 2（事件认证前缀的安全性）**：若 k*≤m、动作的全部风险方向均被 TTE 覆盖或保守先验界定、事件监控以延迟 Δ_e 中止，则单块越界概率 ≤ α_chunk+δ_fault+δ_sync+P(silent)+P(common)。其中 P(silent) 由 AEP 心跳控制；若未执行 AEP 且事件支持不足，则证书无效。**块承诺不放大风险，前提是沉默被当作不可观测而不是默许。**
- **推论（事件 vs 帧的时延优势）**：帧方法在曝光/运动模糊/饱和下损失时间信息，检测延迟下界约为 max(T_exp, 模糊核/速度)；事件方法的延迟约为 C/(|∇L·u|)，只依赖对比度斜率与阈值，HDR 下仍成立。因此在高速接触与强反光场景，事件时间证据能把“块级反应”压到“微秒级反应”。
- **命题（AEP 的信息增益）**：在线性高斯近似下，信任椭球体积 ∝ det(H_e)^{-1/2}。D-最优激发最大化 log det(H_e(u)+εI)，在能量约束下单调减小椭球体积；若激发方向在 N 上有非零投影，则 H_e 的秩增加，零空间收缩。因此 AEP 不是“多动一下”，而是**可证明地制造可观测性**。

## 5. 本轮最大风险

**一句话**：ECHO 的全部证书都依赖“事件流对孪生误差有足够可观测性”这一前提，而事件相机在静止、无纹理、遮挡、透明、低对比度或传感器失效时恰好会陷入沉默——**系统最容易把“没有回声”误读为“孪生正确”，从而在证据最稀薄的地方给出最高置信度的安全证书**；这是本轮方向性信任与认证前缀论证共同依赖的隐藏假设，也是必须用 AEP 心跳和显式 `unobservable` 标记正面防守的地方。

> 本轮新开一条“数字孪生 × 事件相机”的研究线。核心不是把事件相机当作第五个融合模态，而是把它当作**孪生的实时证伪器**：孪生先反事实地预言“事件应该在哪里、何时、以什么极性发生”，事件相机返回微秒级、HDR 的时间戳证据；二者的差异被分解为可归因的故障，并把“信任”从标量升级为**由事件可观测子空间决定的方向性椭球**。一句话：**没有回声的方向，不得发安全证书。**
>

## 2. 形式化定义（完整版）

**定义 1（事件流与时间表面）** 事件相机在像素 x∈Ω⊂ℝ² 上，当对数亮度变化超过阈值 C 时异步发出事件 (t_i,x_i,p_i)，p_i∈{+1,−1} 为极性。事件流 E_{[t_0,t]}={(t_i,x_i,p_i)}_{i=1}^{N(t)} 是一个带微秒时间戳的稀疏集合，不是强度帧。时间表面 T_t(x)=t−t_last(x) 记录每个像素上一次事件到当前的时间；ROI R 的事件率 λ(t,R)=N(t,R)/(|R|Δt)。**事件流只编码变化，不编码绝对亮度或静止纹理。**

**定义 2（事件生成模型）** 令 L(x,t)=log I(x,t)。像素 x 在 |L(x,t)−L(x,t_last)|≥C 时触发事件。对图像运动速度 u(x,t)（px/s），事件率近似为
λ(x,t) ≈ |∇L(x,t)·u(x,t)| / C。
该式是 ECHO 的物理桥梁：孪生预测 u，事件流测量 λ；若孪生正确，预测事件率/事件时刻应与实测一致。高动态范围下 L 不被截断，C 固定，因此事件率在强反光/低照度下仍保持可用的时间斜率。

**定义 3（数字孪生与反事实 rollout）** 孪生 M=(f,h,θ,Σ_θ)，状态 z_t 包含物体/末端 6D 位姿、线/角速度、接触状态、材料参数（刚度、阻尼、摩擦）。动力学与观测：
z_{t+τ}=f(z_t,u_{t:t+τ};θ)+w_t，y_t=h(z_t;θ)+v_t。
给定候选动作块 A_t=(a_t,…,a_{t+H−1})，反事实 rollout 得 ẑ_{t+τ|t}=f^τ(z_t,A_t;θ)。孪生的用途不是“给出真值”，而是**生成可检验的未来假设**。孪生必须带版本号与参数不确定度 Σ_θ，证书只对当前版本有效。

**定义 4（事件签名预测 ESP）** 由 ẑ_{t+τ|t} 与场景几何/反射率，计算预测图像运动 û(x,t+τ) 与预测事件率
λ̂(x,t+τ)=|∇L̂(x,t+τ)·û(x,t+τ)|/C。
预测时间表面 T̂(x) 由沿预测运动的首达时间给出。ESP 不要求神经渲染的像素级精度，只要求**边缘运动方向与事件时刻**足够准；对纹理缺失区域，ESP 输出“低置信/无事件预期”，而不是强行预测。预测事件签名 Ê(u) 用于与实测事件流做对齐和残差。

**定义 5（运动补偿事件对齐 ETA）** 对候选孪生轨迹 ξ，把事件 i 按时间 warping 到参考时刻 t_r：
x_i′=W(x_i,t_i;ξ)，I_W(x;ξ)=Σ_i p_i δ(x−x_i′)。
对齐分数 S(ξ)=Var(I_W(x;ξ))（等价地可用负熵或梯度能量）。若 ξ 正确，warped events 应聚成锐利边缘；若 ξ 有误，最佳对齐会落在附近 ξ*。定义轨迹级残差
e_e(ξ)=S(ξ*)−S(ξ_twin)，ξ*=argmax_{‖ξ−ξ_twin‖≤ρ}S(ξ)。
同时定义像素级事件时间残差 r_i=t_i−t̂(x_i;ξ_twin)，聚合成残差场 r_e(x,t)。e_e 回答“孪生轨迹能否解释事件流”，r_e 回答“在何处、何时解释得不好”。

**定义 6（事件可观测子空间 EOS）** 在 ξ_twin 处线性化 I_W(ξ)≈I_W(ξ_0)+J_eδξ，事件噪声协方差 Σ_e（含泊松散粒噪声、折射/读出噪声）。事件 Fisher 信息
H_e=J_eᵀΣ_e⁻¹J_e。
可观测子空间 O=range(H_e)，零空间 N=ker(H_e)，可观测秩 r_e_rank=rank(H_e)。对方向 v∈O，事件对 vᵀδ 的估计方差下界为 vᵀH_e⁺v；对 v∈N，事件**原则上无信息**。零空间的几何来源包括：静止场景、无纹理区域、孔径问题（沿直边运动）、遮挡、事件阈值以下的微小运动。**不可观测不是“没有误差”，而是“误差不可被该证据检验”。**

**定义 7（方向性孪生信任椭球 TTE）** 令 δ=ξ_true−ξ_twin。用标定集上的事件残差做 split-conformal，得 q_e(α)。定义
TTE_t(α)={δ: δᵀH_eδ≤q_e(α)}，
并在 N 上叠加先验/其他传感器（力觉、本体感觉）的保守椭球。对任务风险方向 v（例如末端沿接触法向的位移、切向滑移、形变方向），仅当 v∈O 且 vᵀH_ev≥κ_min 时称“该方向被事件认证”。方向性覆盖界为
|vᵀδ| ≤ sqrt(q_e(α)·vᵀH_e⁺v)，v∈O。
TTE 是椭球而非球：沿可观测方向紧、沿零空间方向松；证书必须把 `null_directions` 显式传给规划器与安全壳。

**定义 8（事件时间接触/滑移检测）** 接触起始 τ̂_c 定义为接触 ROI R_c 内事件率首次超过基线 kσ、且事件极性与预测法向运动一致的时刻。滑移起始由事件流切向位移/流场散度的突变给出；由于事件时间戳不受曝光限制，滑移的“第一帧”不再是帧周期，而是事件时刻。由定义 2，时间估计的 Cramér–Rao 下界
Var(τ̂_c) ≥ σ_e²/(Nκ²)，
N 为 ROI 事件数、κ=∂λ/∂t 为事件率时间斜率。该式说明：**决定时间精度的是事件数与对比度斜率，而不是帧率或曝光。**

**定义 9（结构化故障归因 ECA）** 故障假设
ℋ={H0 健康, H_model 孪生模型错（接触/摩擦/未建模动力学）, H_calib 外参/内参/尺度漂移, H_sync 时间戳偏移/通信时延, H_event 事件传感器故障/噪声, H_illum 全局光照/闪烁, H_common 共因失效（透明/遮挡/反光同时骗过孪生与事件）}。
把残差场结构化分解：
r_e(x,t) ≈ Φ_sync(t)θ_sync + Φ_calib(x)θ_calib + Φ_model(x,t)θ_model + Φ_illum(t)θ_illum + ε。
各故障的时间/空间支撑不同：
- H_sync：全局时间平移，warping 最优解 τ*≠0，残差与像素/接触无关；
- H_calib：随运动速度增长的平滑空间残差，边缘处梯度一致；
- H_model：残差只在接触时刻、接触点邻域出现，非接触段正常；
- H_event：事件率塌缩、盐椒噪声、极性偏置，warping 分数整体下降；
- H_illum：全图同时、同极性爆发，事件率与图像运动不相关；
- H_common：残差同时出现在孪生模型敏感区与事件可观测区，且两者失效方向一致，判 ambiguous。
后验 P(H|r_e)∝p(r_e|H)P(H)；若 max_H P(H|r_e)<1−δ_fi 或熵 H(P)>H_max，输出 ambiguous，不做定向处置。

**定义 10（主动事件激发 AEP）** 当事件支持不足（低纹理、静止、孔径、零空间大、残差不可解释）时，选择安全微激发 u_ex：
u_ex*=argmax_{u∈U_safe} log det(H_e(u)+εI)，
s.t. 任务误差≤ε_task，接触力≤f_safe，运动可逆且不进入不可逆状态。
U_safe 包含：微幅摆动（dither）、微旋转、结构光/亮度心跳、非接触视觉扫视。对易损/高精度任务，优先使用非接触或光照激发。AEP 有三重作用：
(i) 用已知输入的回声增加 H_e 的秩、缩小零空间；
(ii) 用“激发后仍无预期事件”判 H_event（心跳测试）；
(iii) 为 TTE 补充方向性证据。**AEP 不是“多动一下”，而是可证明地制造可观测性。**

**定义 11（事件认证执行前缀 ECP）** 给定动作块 A_{t:t+H}、TTE、故障后验与任务风险方向集 V_risk。选择最小 k*≤min(H,m)，m 为不可逆视界（由力限、停止距离、接触几何决定），使得
∀s≤k*，∀H∈supp_δ(post)，∀v∈V_risk：v 被 TTE 覆盖，或由保守先验界定，且预测安全裕度 ρ_safe(s)≥0。
执行 k* 步后强制重规划；事件监控器以异步方式在 r_e>q_e(α) 或 CUSUM 报警时立即中止，延迟 Δ_e 为事件处理延迟（目标 <100µs），而不是块边界。**长孪生前瞻、短事件执行。**

**定义 12（ECHO 证书 J_echo）**
J_echo=(J_base, twin_version, event_calib_ver, sync_offset, r_e, observability_rank, tte_params, fault_posterior, fault_entropy, k*, null_directions, aep_heartbeat_ok, common_cause_flag)。
Valid(J_echo) ⇔
1. Valid(J_base)；
2. 动作风险方向 V_risk 均被 TTE 覆盖，或已执行 AEP 并重新认证；
3. r_e≤q_e(α) 且 sync_offset 在界内；
4. k*≥1 且 k*≤m；
5. `null_directions` 已显式标注，且零空间方向由保守先验/其他传感器兜底；
6. 若事件支持不足且未执行 AEP，则 `aep_heartbeat_ok=False`，证书无效；
7. `common_cause_flag=True` 时不得声称归因确定，只允许安全降级。
审计链回答四个问题：孪生在哪个方向被事件支持？哪个方向不可观测？若不可观测，做了什么激发？为什么只执行 k* 步？

**定义 13（ECHO 闭环算子）** 慢回路（语义/模型流，10–100Hz）：
[孪生状态更新→反事实 rollout→ESP 事件签名预测→ETA 对齐/残差→EOS/TTE→ECA 归因→AEP 规划→ECP/CSP 规划→J_echo 构建→更新保守先验]。
快回路（事件/实时流，事件驱动）：
[事件摄取→运动补偿→r_e 计算→CUSUM/早停→前缀派发→中止/继续]。
不变式：**孪生渲染、故障归因、AEP 规划、证书只在慢回路；快回路只做事件对齐、残差、早停与执行，零学习写操作。**

**定义 14（共因失效与沉默证据）** 设 F_M 为孪生失效、F_E 为事件传感器失效。显式建模
P(F_M∧F_E)=P(F_M)P(F_E)+Δ_common，
Δ_common 来自共享的反射率/几何/光照模型（透明、镜面、强反光、遮挡）。ECHO 不假设独立；在 H_common 下只要求判 ambiguous 并安全降级。对已知激发 u_ex，若预期事件签名 Ê(u_ex) 未出现，定义沉默似然比
Λ(silence|u_ex)=p(no event|H_event)/p(no event|H0)；
Λ 高则判传感器故障。无激发且无事件时，只能输出 `event_unobservable`，**禁止解释为“孪生正确”。**

### IP-002 ESP：事件签名预测

```python
class EventSignaturePredictor:
    """由孪生 rollout 预测事件率场/时间表面；不要求像素级重建。"""
    def predict(self, rollout, scene, camera, C=0.15):
        # rollout.poses[t], rollout.vel[t], scene.reflectance/edges
        lam_hat, T_hat = {}, {}
        for t in rollout.times:
            u_hat = project_image_velocity(scene, camera, rollout.poses[t],
                                           rollout.vel[t])          # 图像运动
            grad_L = scene.log_gradient(camera, rollout.poses[t])    # 边缘梯度
            lam = np.abs(grad_L * u_hat) / C                         # 定义 2
            lam_hat[t] = lam
            T_hat[t] = first_arrival_time(lam, scene, camera)       # 首达时间
        return {'lam': lam_hat, 'T': T_hat,
                'confidence': edge_confidence(scene, camera)}
```

### IP-003 ETA：运动补偿对齐与残差

```python
class EventTimeAligner:
    """把事件按孪生轨迹 warping，输出对齐间隙与 Hessian。"""
    def warp(self, events, traj, t_ref):
        xs = [W(e.x, e.t, traj) for e in events]        # 定义 5
        return WarpedEvents(xs, events.p, t_ref)

    def residual_and_hessian(self, warped, ev_sig, eps=1e-3):
        xis0 = traj.params
        S0 = alignment_score(warped, xis0)               # Var(I_W)
        # 在附近做小范围搜索/梯度上升找最佳对齐
        xi_star = maximize_score(warped, xis0, radius=RHO)
        S_star = alignment_score(warped, xi_star)
        e_e = S_star - S0                                # 轨迹级残差
        J_e = numerical_jacobian(alignment_score, warped, xis0, eps)
        Sigma_e = event_noise_cov(events)                # 泊松+读出
        H_e = J_e.T @ np.linalg.pinv(Sigma_e) @ J_e      # 定义 6
        r_e = time_residual_field(events, ev_sig)        # 像素级残差场
        return e_e, r_e, H_e, J_e, xi_star
```

### IP-004 EOS/TTE：可观测子空间与方向性信任

```python
def eigen_observability(H_e, kappa_min=1e-6):
    w, V = np.linalg.eigh(0.5 * (H_e + H_e.T))
    keep = w > kappa_min * max(w.max(), 1e-12)
    O = V[:, keep]
    N = V[:, ~keep]                                     # 零空间方向
    return {'rank': int(keep.sum()), 'O': O, 'N': N, 'eig': w}

def calibrate_tte(H_e, calib_residuals, alpha=0.05):
    # split-conformal：非一致性分数 = sqrt(delta^T H_e delta)
    scores = np.array([np.sqrt(d @ H_e @ d) for d in calib_residuals])
    n = len(scores)
    q = np.quantile(scores, min(1.0, np.ceil((n + 1) * (1 - alpha)) / n))
    return {'q': float(q), 'H_e': H_e,
            'bound': lambda v: np.sqrt(q * v @ np.linalg.pinv(H_e) @ v)
                               if v in_range(H_e) else np.inf}
```

```python
class EventCertifiedAttribution:
    HYP = ('H0', 'H_model', 'H_calib', 'H_sync',
           'H_event', 'H_illum', 'H_common')

    def features(self, r_e, H_e, warped, ev_sig):

            'calib_growth': regress_residual_vs_speed(r_e, warped),
            'contact_local': contact_roi_energy(r_e) / total_energy(r_e),
            'event_rate_ratio': observed_rate(warped) / predicted_rate(ev_sig),
            'polarity_bias': polarity_imbalance(warped),
            'global_burst': global_simultaneity(warped),
            'rank': eigen_observability(H_e)['rank'],
        }

    def attribute(self, r_e, H_e, warped, ev_sig, delta_fi=0.15):
        f = self.features(r_e, H_e, warped, ev_sig)
        logp = {h: np.log(self.lik[h](f) + 1e-12) + np.log(self.prior[h])
                for h in self.HYP}
        z = np.array(list(logp.values())); z -= z.max()
        post = {h: float(np.exp(v) / np.exp(z).sum()) for h, v in logp.items()}
        h_star = max(post, key=post.get)
        H_ent = -sum(p * np.log(p + 1e-12) for p in post.values())
        ambiguous = (post[h_star] < 1 - delta_fi) or (H_ent > H_MAX)
        return post, h_star, ambiguous
```

### IP-006 AEP：主动事件激发

```python
class ActiveEventProbe:
    EXCITATIONS = ('dither_x', 'dither_y', 'micro_rotate',
                   'structured_light', 'brightness_heartbeat', 'visual_sweep')

    def choose(self, H_e, post, f_safe, fragile, energy_budget):
        if not any_events_or_rank_deficient(H_e):
            # 先用非接触心跳，区分“静止”与“传感器死”
            return 'brightness_heartbeat' if not fragile else 'visual_sweep'
        best, best_gain = None, -np.inf
        for u in self.EXCITATIONS:
            if not self.safe(u, f_safe, fragile):
                continue
            H_new = self.predicted_fisher(H_e, u)
            gain = np.log(np.linalg.det(H_new + EPS * np.eye(len(H_new)))
                          / np.linalg.det(H_e + EPS * np.eye(len(H_e))))
            if gain > best_gain:
                best, best_gain = u, gain
        return best if best_gain > DELTA_INFO else None
```

### IP-007 ECP：事件认证执行前缀

```python
class EventCertifiedPrefix:
    def certified_prefix(self, A, tte, post, V_risk, m, alpha_chunk):
        support = {h: p for h, p in post.items() if p >= DELTA_SUPP}
        for k in range(1, min(len(A), m) + 1):
            ok = True
            for h in support:
                for s in range(k):
                    if predicted_margin(A[s], h) < 0:
                        ok = False; break
                if not ok: break
            for v in V_risk:
                if not tte_covers(tte, v):          # 零空间/未认证方向
                    ok = False; break
            if not ok or violation_prob(A[:k], support) > alpha_chunk:
                return max(0, k - 1)
        return min(len(A), m)

    def monitor(self, tte):
        r_e = acquire_event_residual()              # 微秒级
        return AbortFlag(abort=(r_e > tte['q']) or cusum_alarm(r_e))
```

### IP-009 ECHO 闭环算子

```python
def ECHO_round(M, obs, task):
    events, img, depth, force = obs.events, obs.img, obs.depth, obs.force
    # ———— 慢回路 ————
    z_hat = M.twin.estimate_state(img, depth, force)          # 孪生状态
    A = M.planner.propose_chunk(z_hat, task, H=M.H)           # 候选动作块
    rollout = M.twin.counterfactual(z_hat, A, M.H)            # 反事实未来
    ev_sig = M.esp.predict(rollout, M.scene, M.camera)        # 事件签名
    warped = M.eta.warp(events, rollout.traj, t_ref=obs.t)    # 事件对齐
    e_e, r_e, H_e, _, _ = M.eta.residual_and_hessian(warped, ev_sig)
    eos = eigen_observability(H_e)
    post, h_star, ambiguous = M.eca.attribute(r_e, H_e, warped, ev_sig)
    # 不可观测 / 归因模糊 / 传感器疑似故障 → AEP
    if eos['rank'] < M.r_min or ambiguous:
        u_ex = M.aep.choose(H_e, post, M.f_safe, M.fragile, M.energy_budget)
        if u_ex is not None:
            M.execute_safe_excitation(u_ex)
            events = obs.events_after(M.excitation_window)
            warped = M.eta.warp(events, rollout.traj, t_ref=obs.t)
            e_e, r_e, H_e, _, _ = M.eta.residual_and_hessian(warped, ev_sig)
            eos = eigen_observability(H_e)
            post, h_star, ambiguous = M.eca.attribute(r_e, H_e, warped, ev_sig)
    tte = calibrate_tte(H_e, M.calib_residuals, M.alpha)
    k_star = M.ecp.certified_prefix(A, tte, post, M.V_risk, M.m, M.alpha_chunk)
    heartbeat_ok = M.ehc.check(events, ev_sig, u_ex)
    # ———— 快回路 ————
    status = M.ecp.execute_prefix(A, k_star, tte)
    # ———— 证书 ————
    J = build_j_echo(
        base=M.j_base, twin_version=M.twin.version,
        event_calib_ver=M.camera.calib_ver, sync_offset=M.eta.sync,
        r_e=float(e_e), observability_rank=eos['rank'],
        tte_params=tte, fault_posterior=post,
        fault_entropy=entropy(post), k_star=k_star,
        null_directions=eos['N'], aep_heartbeat_ok=heartbeat_ok,
        common_cause_flag=has_common_cause(post, events))
    return M, status, J
```

## 4. 推导

**引理 1（事件可观测性与 CRB）** 在定义 5–6 的线性化下，I_W(ξ)≈I_W(ξ_0)+J_eδξ，δξ∼N(0,Σ_ξ)。事件观测的 Fisher 信息为 H_e=J_eᵀΣ_e⁻¹J_e；对任意方向 v∈range(H_e)，误差 vᵀδ 的 Cramér–Rao 下界为
Var(vᵀδ) ≥ vᵀH_e⁺v。
若 v∈ker(H_e)，则事件似然对 vᵀδ 不变，下界为无穷（无信息）。证明：对 δ 的线性高斯模型，后验协方差为 H_e⁺；投影到 v 即得。零空间由事件生成模型的退化导致（静止、无纹理、孔径、遮挡），不是数值问题。∎

**引理 2（沉默的多义性）** 设窗口 W 内观测到零事件。对任意 δ 满足 J_eδ=0（或 |J_eδ| 低于事件阈值 C），事件似然 p(0 events|δ)=p(0 events|0)，故后验在零空间 N 上不更新。于是“无事件”无法区分 H0 与 H_event/H_occlusion/无纹理，也无法证明孪生在该方向正确。形式化地，零事件证据只降低 O 内方差，对 N 的方差不变。∎

**定理 1（方向性信任覆盖）** 在事件残差可交换、split-conformal 校准有效的条件下，对 δ=ξ_true−ξ_twin 有 P[δᵀH_eδ≤q_e(α)]≥1−α。对任意 v∈range(H_e)，由 H_e 内积的 Cauchy–Schwarz：
|vᵀδ| ≤ sqrt(vᵀH_e⁺v) · sqrt(δᵀH_eδ) ≤ sqrt(q_e(α)·vᵀH_e⁺v)。
因此对每个被认证方向 v，证书以 ≥1−α 覆盖其误差。对 v∈ker(H_e)，上式不适用，且由引理 2 事件不提供信息；证书必须置 `null_directions`，不得用同一 q_e 宣称安全。∎

**定理 2（事件认证前缀的安全性）** 设 k*≤m，且对每个 s≤k*、每个后验支持集内的故障假设 H，动作风险方向 V_risk 均被 TTE 覆盖或由保守先验界定，预测安全裕度≥0。事件监控以延迟 Δ_e 中止，同步误差界为 δ_sync，视觉/事件 conformal 覆盖为 1−α。则由联合界，单块越界概率
P[unsafe] ≤ α_chunk + δ_fault + δ_sync + P(silent) + P(common)。
其中 δ_fault 为后验支持集外的故障质量，P(silent) 为“事件支持不足且未执行 AEP”的概率，P(common) 为共因失效率。若未执行 AEP 且 eos.rank<r_min，则证书无效（定义 12 第 6 条），因此 P(silent) 被 AEP 心跳显式控制。由于 k*≤m，即使故障在块首发生，中止/重规划也发生在越过不可逆点之前。∎

**命题 1（事件 vs 帧的时延优势）** 帧方法的时间信息受曝光 T_exp 与运动模糊核长度 b 限制，检测延迟下界约为 max(T_exp, b/|u|)；在高动态范围下帧像素饱和，边缘对比度 ∇L 被截断，进一步增大延迟。事件方法的延迟由事件阈值与对比度斜率决定：τ_det≈C/(|∇L·u|)，只依赖局部对比度与运动速度，不依赖曝光；HDR 下 L 不饱和，故在强反光/低照度/高速场景中 τ_det 可低至微秒量级。∎

**命题 2（AEP 的信息增益与秩提升）** 在线性高斯近似下，TTE 体积 ∝ det(H_e)^{-1/2}。给定激发 u，若 H_e(u)=H_e+ΔH(u) 且 ΔH(u)≽0，则 log det(H_e(u)+εI) 单调不减，体积单调不增。若激发方向在零空间 N 上的投影非零，则 ΔH 在 N 上引入正特征值，rank(H_e) 增加，零空间收缩。因此 D-最优激发在能量约束下最大化体积缩减；AEP 是“制造可观测性”的可证明手段。∎

**命题 3（互补性的显式界）** 设孪生单独失效概率 p_M、事件单独失效概率 p_E、共因失效增量 Δ_common。ECHO 的“同时未被检出”概率为
p_M p_E + Δ_common（在给定事件可观测性条件下）。
当 Δ_common 大（透明/镜面/强反光）时，独立性假设失效，ECHO 不声称归因正确，而要求 H_common 判 ambiguous 并退化为保守控制；这使系统的安全性不依赖于“两模态独立”这一不成立的假设。∎

## 7. 已知风险

**一句话**：ECHO 的全部证书依赖“事件流对孪生误差有足够可观测性”，而事件相机在静止、无纹理、遮挡、透明、低对比度或传感器失效时恰好沉默——**系统最容易把“没有回声”误读为“孪生正确”，在证据最稀薄的地方给出最高置信度的安全证书**；这是本轮方向性信任与认证前缀论证共同依赖的隐藏假设。

**次级风险与缓解**：
1. **沉默被误读为一致**：用 `event_unobservable` 显式标记 + AEP 心跳；未激发且无事件时证书无效，绝不默认通过。
2. **孪生与事件共因失效**：透明/镜面/强反光同时破坏反射率模型与事件生成；CCA 显式建模 Δ_common，共因下只承诺安全降级（H_common→ambiguous）。
3. **事件相机无绝对亮度/静态纹理**：ESP 在无纹理区输出低置信，孪生补静态结构，但证书必须在这些区域降权；不能把孪生的静态几何当作事件已验证。
4. **时间同步误差**：微秒级优势会被毫秒级同步误差吃掉；E1 专门标定 sync_offset，证书携带该值，超界即判 H_sync 并重标定。
5. **事件率依赖运动**：慢速/微动任务事件稀疏，CRB 变差；AEP 可增加运动但受任务误差约束，需在“可观测性—任务扰动”间权衡。
6. **H_e 估计的线性化误差**：大位移/遮挡/非刚性形变下线性化失效；用多尺度 warping、鲁棒损失和局部重线性化，并把线性化残差计入 q_e。
7. **AEP 的安全边界**：微激发也可能触碰易损物体或激发不可逆过程；AEP 只允许在 U_safe 内，优先非接触/光照，且必须可逆。
8. **归因假设集有限**：未知故障落入最近假设；用后验熵/ambiguous 阈值拒绝归因，并持续扩充故障库。
