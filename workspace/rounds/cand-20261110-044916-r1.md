# 第 41 轮 · 双灵感落地 v8：力矩见证证书 × 序贯真机审计 × 证书跨域标定（四层架构 v6）

> 承接第 40 轮（v17：可认证流匹配执行 × 度量语义几何锚定 × 证书驱动课程引擎，四层架构 v5）。本轮灵感词「真机评测、力矩传感」把证书体系从「仿真里自洽」推进到「在金属上可证伪」：用关节力矩作为证书的**物理见证通道**，用 anytime-valid 序贯检验把昂贵真机评测变成**最小试次的证伪审判**，用分布无关的跨域标定把仿真证书**带误差棒地搬到真机**。

## 0. 直觉与动机

**灵感 1（真机评测 → 证书必须可证伪，而非仅可声明）**：第 40 轮把证书做成了「活文档」，但活性只发生在仿真与 Registry 之间：E67-E72 全是离线/仿真门槛，证书从未在真机上接受过审判。真机评测的真正困难不是「跑一遍」，而是：a) 试次昂贵（时间、磨损、人力、安全）；b) 危险（违约可能砸机伤人）；c) 统计上容易「看到不好就停」的偷看偏差（peeking bias）。因此真机评测的正确形态不是固定 N 次跑分，而是**在安全包络内的序贯证伪**：每跑一次都在更新「证书违约率」的 anytime-valid 证据，证据足够强就提前终止。这把评测从「费用中心」变成证书生命周期的**审判环节**。

**灵感 2（力矩传感 → 证书的第一个物理见证器）**：证书承诺的是边界（‖w_ext‖≤w_max、h_min、τ_max），而关节力矩传感器是这些边界在真机上**唯一可高频直接测量**的物理量。动量观测器把 τ_m 变成外力矩估计 r(t)，其误差有严格的一阶低通界 δ_obs=‖K_o⁻¹‖·sup|τ̇_ext|。于是「证书是否成立」第一次有了逐毫秒的物理见证：r(t) 越界即证书被物理证伪（或在统计意义上被质疑）。力矩还通过 Δx ≤ ½‖M⁻¹‖(‖r‖+δ)H² 把「力」误差传播成「几何」误差，直接接上第 40 轮的 h_min 与 ValidRegion。

**灵感 3（耦合 → 证书 = 假设 + 见证规约 + 审判协议）**：把两者相乘，证书对象升级为三元组：可证伪假设（本体的边界）、见证规约（用哪些传感器、以何统计量、以何置信度见证）、审判协议（序贯检验 + 安全采样 + 停止规则）。仿真证书经**力矩残差**做分布无关标定后迁到真机（带误差棒），再由**序贯审计**决定续期/吊销。至此证书闭环真正落地到金属：仿真认证 → 力矩标定 → 序贯真机审判 → 重颁/吊销。

## 1. 形式化定义

**定义 27（力矩见证证书 TWC）**：机器人 n_j 关节，τ_m 为力矩测量。广义动量 p=M(q)q̇，动量观测器
r(t) = K_o[ p(t) − ∫₀ᵗ (τ_m + Cᵀ(q,q̇)q̇ − g(q) + r(s)) ds − p(0) ], K_o ≻ 0。
误差动力学 ṙ = K_o(τ_ext − r)，故 r(t)=∫₀ᵗ K_o e^{−K_o(t−s)} τ_ext(s) ds，且
‖r(t) − τ_ext(t)‖ ≤ ‖K_o⁻¹‖ · sup_s‖τ̇_ext(s)‖ ≜ δ_obs。
证书若承诺接触旋量 ‖w_ext‖ ≤ w_max，则见证谓词
W(t) = [ ‖r(t)‖ ≤ ‖Jᵀ(q)‖ w_max + δ_obs + δ_noise ]。
TWC = (δ_obs, K_o, w_max, W, 见证规约)。W 为假 ⟹ 证书被物理证伪（需区分「证书错」与「模型错」，见 §5）。

**定义 28（力矩到几何的误差传播）**：在预测时域 H 内，力矩残差导致的状态偏差上界
Δx(H) ≤ ½ ‖M⁻¹‖ (‖r‖_∞ + δ_obs) H²。
故真机安全裕度 h_min^real ≥ h_min^sim − Δx(H) − B_t（B_t 为 IP-49 漂移球），ValidRegion 相应收缩。

**定义 29（序贯真机审计 SRRA）**：每次真机试验 i 在 ValidRegion 内、经力矩 CBF 保护运行，记违约 X_i = 1[∃t: ¬W(t)]。H₀: p=P(X=1) ≤ p₀（证书成立），H₁: p>p₀。混合似然比 e-过程
E_t = ∫_{p₁∈(p₀,1]} (p₁/p₀)^{S_t} ((1−p₁)/(1−p₀))^{t−S_t} π(dp₁), S_t=ΣX_i。
H₀ 下 E_t 为非负鞅，由 Ville 不等式 P_{H₀}(∃t: E_t ≥ 1/α) ≤ α —— **任意偷看、任意停止都保持 I 类错误**。审判规则：E_t ≥ 1/α 即吊销/重颁；证据不足则继续；预算耗尽输出「未证伪」而非「证明」。试验选择复用 IP-50 的赤字 D 但以真机实测边际计算，且只在 h_min^real>0 内采样（安全采样）。

**定义 30（证书跨域标定 SCT）**：在安全区采 n 次真机标定，得分 s_i = sup_t‖r_i(t)‖ / (‖Jᵀ‖ w_max^sim)，取 (1−δ) 分位分布无关上界
ĝ_τ = Q̂_{1−δ}(s_{1:n}) + √(ln(1/δ′)/(2n))，其中 DKW 给 P(sup|F_n−F|>ε) ≤ 2e^{−2nε²}，
则 P(现实 (1−δ) 分位 ≤ ĝ_τ) ≥ 1−δ′。迁移映射：w_max^real = max(ρ_DR, ĝ_τ)·w_max^sim，h_min^real 按定义 28 膨胀，δ_τ^real = δ_τ^sim·ĝ_τ。**边界**：力矩见证只覆盖力/接触/几何维（w_max、h_min、μ_max），不覆盖速度场光滑性 L_v/κ —— 后者仍取仿真值×鲁棒安全系数，并在证书中显式标注「部分见证」。

## 2. 三大产出设计

### 2.1 IP-51 TORQUE-WITNESS-CERT（力矩见证证书）
1. 高频（1kHz）动量观测器估计 τ_ext，配摩擦/未建模动力学在线辨识（RLS）以压缩 δ_obs。
2. 见证谓词 W(t) 与「越界分级」（瞬时过冲 vs 持续越界），避免噪声触发假证伪。
3. 力矩 CBF：h_τ = τ_max − ‖r‖ − δ_obs，与 IP-49 几何 CBF 组成 QP，力矩优先级更高（安全兜底）。
4. 误差传播（定义 28）把力矩残差注入 h_min 与 ValidRegion，形成「力—几何」联合有效区。
5. 见证规约写入契约：{传感器、采样率、K_o、δ_obs、δ_noise、判定窗}，可复现。

### 2.2 IP-52 SEQUENTIAL-REAL-ROBOT-AUDIT（序贯真机审计）
1. e-过程（定义 29）+ Ville 保证 anytime-valid；支持分批、可中断、可偷看。
2. 安全试验采样：只在 h_min^real>0 ∧ 力矩 CBF 可行内选择；近边界最大化信息（复用 IP-50 赤字带）。
3. 停止规则：证伪 / 预算耗尽 / 证据饱和三态；输出「吊销、续期、未决」而非二元通过。
4. 与 IP-50 共用 D(τ)，但边际 m_i 全部改为真机实测（λ̂、ĥ_min、‖r‖̂、B̂_t）。
5. 审计日志进 Registry，作为证书续期的唯一合法证据来源。

### 2.3 IP-53 SIM2REAL-CERT-TRANSFER（证书跨域标定）
1. 域随机化（DR）给先验上界 ρ_DR；力矩残差给后验检验 —— DR 是否真的覆盖现实。
2. DKW / split-conformal 给分布无关 (1−δ) 迁移因子 ĝ_τ（定义 30）。
3. 迁移后自动「重颁」CertBundle，并把「哪些维被力矩见证、哪些仍靠仿真」写成 provenance。
4. 若 ĝ_τ 超出 ρ_DR 的容忍带 → 判 DR 失配，触发重训练/扩 DR，而非强行放宽证书。

## 2. 关键算法

### IP-51 力矩见证证书（伪代码）
```
def momentum_observer(tau_m, q, dq, M, C, g, K_o, r_prev, p_prev, dt):
    p = M(q) @ dq
    integrand = tau_m + C.T @ dq - g + r_prev
    r = K_o * (p - (integral_prev + integrand*dt) - p_0)
    return r, p, integral_prev + integrand*dt

def torque_witness(r, J, w_max, delta_obs, delta_noise):
    bound = norm(J.T) * w_max + delta_obs + delta_noise
    if norm(r) > bound:
        return VIOLATION if persistent(r, window=50ms) else TRANSIENT
    return OK

def torque_cbf(r, tau_max, delta_obs, alpha):
    h = tau_max - norm(r) - delta_obs
    return QP(tau_ref, subject_to=d_dt_h >= -alpha*h)   # 与几何 CBF 联合求解

def force_to_geometry(delta_obs, r_inf, M_inv, H):
    return 0.5 * norm(M_inv) * (r_inf + delta_obs) * H**2   # Δx(H)
```

### IP-52 序贯真机审计（伪代码）
```
def e_process(X_history, p0, prior_grid):
    S = sum(X_history); t = len(X_history)
    return sum(pri**S * (1-pri)**(t-S) / (p0**S * (1-p0)**(t-S))
               for pri in prior_grid) / len(prior_grid)

def sequential_audit(policy, p0, alpha, beta, budget):
    X = []; E = 1.0
    while len(X) < budget:
        tau = select_safe_trial(policy, ValidRegion, torquecbf=True)
        x = rollout_real(tau, policy, witness=torque_witness)
        X.append(1 if x.violated else 0)
        E = e_process(X, p0, prior_grid)
        if E >= 1/alpha: return REVOKE, X          # 证书被证伪
        if len(X) >= budget: return UNDECIDED, X   # 未证伪 ≠ 证明
    return UNDECIDED, X
```

### IP-53 证书跨域标定（伪代码）
```
def transfer_certificate(scores, w_max_sim, delta_sim, rho_DR, delta=0.05, dprime=0.01):
    n = len(scores)
    q_hat = empirical_quantile(scores, 1-delta)
    g_hat = q_hat + sqrt(log(1/dprime) / (2*n))     # DKW 分布无关上界
    w_max_real   = max(rho_DR, g_hat) * w_max_sim
    delta_real   = g_hat * delta_sim
    if g_hat > rho_DR * (1 + tol_DR):
        flag = DR_MISMATCH                            # 触发扩 DR，而非放宽证书
    provenance = {"w_max": "torque-witnessed", "h_min": "torque+geom", "L_v": "sim-only"}
    return CertBundle(w_max_real, delta_real, g_hat), provenance, flag
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 正确性保证 |
|---|---|---|
| 动量观测器 | O(n_j³)（M,C,g 计算）+ O(n_j) 积分，1kHz 可实时 | **定理**：‖r−τ_ext‖≤δ_obs（一阶低通） |
| 力矩见证 | O(n_j) 每次判定 | W 为假 ⟹ 证书在该时刻被物理证伪 |
| 力矩 CBF | 小规模 QP O(n_u³) | h_τ>0 ⟹ 力矩不越界（离散时间需 margin） |
| 力→几何传播 | O(n_j³)，H 步一次 | **定理**：Δx(H)≤½‖M⁻¹‖(‖r‖∞+δ_obs)H² |
| e-过程 | O(K)（K=先验网格，K≈64） | **定理**：Ville，P_{H₀}(∃t:E_t≥1/α)≤α |
| 序贯审计 | 期望试次 ≈ SPRT，比固定 N 省 ≥40% | anytime-valid，容忍偷看/提前停止 |
| 跨域标定 | O(n log n) 排序 | **定理**：DKW 覆盖 ≥1−δ′（分布无关） |

| 力矩模型误差（摩擦/未建模）淹没违约信号 → 见证无功效或假吊销 | 高 | 在线 RLS 辨识摩擦；越界分级+判定窗；E73 第一守门 |
| 「证书错」与「模型错」混淆，误吊销正确策略 | 高 | 双假设诊断（力矩残差 vs 状态残差）；未决态而非二元判决 |
| 间隙/接触冲击使 r(t) 瞬态巨大 | 中 | 瞬态/持续分级，冲击窗口豁免计入 |
| 安全采样过保守 → 审计覆盖不足 | 中 | 赤字带主动采样 + 分阶段放宽预算 |
| 力矩只覆盖部分证书维 → 产生「已见证」假安全感 | 中 | provenance 强制标注，L_v/κ 明示「仅仿真」 |
| DKW/共形在非平稳（磨损）下失效 | 中 | 滑动窗口重标定 + 变更点检测触发重采 |

## 6. 本轮最大风险

**一句话**：整套「力矩见证」的功效完全取决于力矩模型保真度——若摩擦、未建模动力学、标定漂移使 δ_obs 比真实违约信号还大，见证要么宽到无法证伪（证书永远续期）、要么被模型误差淹没而假吊销频发（证书永远吊销），「在金属上可证伪」将退化为「在金属上自欺」，故 E73/E75 是本轮成败判据。
