# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「指令泛化」×「传感器标定」）

> R69 教会系统「问」：把不确定性拆成 aleatoric 与 epistemic，用流匹配策略显式表示多模态，用主动交互（看/问/触）消解歧义，并用流似然给标定层做第二意见。但它仍埋着一个未经检验的**本体论假设**：系统知道自己正在解哪道题。指令被当成一条无损、已接地的任务描述；标定被当成一个与语义无关的坐标修正。于是 R69 的「问」只在世界侧成立——一旦错的是**题面**（paraphrase、量词、方位、否定、组合），它会非常努力地把一道错的题做对，并在这个过程中把标定层调去配合这个误解。
>
> 本轮两个灵感恰好是同一枚硬币的两面：
> - **传感器标定**是「同一物理量在不同坐标/工况下必须读出同一值」——观测侧的 nuisance 不变性，且有计量学意义上的**溯源**（traceability）；
> - **指令泛化**是「同一意图在不同措辞/语言/语序下必须产生同一行为」——语义侧的 nuisance 不变性，同样需要**溯源**（这条指令到底被谁、按什么标准认定为这个意思）。
>
> 核心命题：**指令泛化与传感器标定在数学上是同一类对象——nuisance 群作用下的不变量；正因如此，它们可以互相冒充、彼此抵消，形成闭环数据上的「规范简并」（gauge degeneracy）：把传感器坐标系旋转 δ，同时把指令里的「左/右」解释反向 δ，行为完全不变。系统会得到一个自洽但错误的解。R70 的中心任务不是让泛化更强、标定更准，而是让两者「可辨识」（identifiable）：用帧混合的锚集与已知答案挑战打破联合规范，用「一次只动一个」的规范锁阻止共同适应，并在混淆不可解时拒绝适应、退回保守。** 命名 **GIGA-RAS**（Gauge-Identifiable GenerAlization：规范可辨识的指令泛化与标定解耦闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我做的，是不是你让我做的那件事？我看到的和听到的，是不是同一个世界？**」

## 0. 直觉与动机

**贯穿例子（先记住它，后面所有形式化都在解释它）**
机械臂要给「左边的人」递一杯咖啡。相机外参装反，图像左右镜像；同时用户按自己的视角把「左边」说成机器人的「右边」。两个错误恰好抵消：机器人每次都把杯子递到用户真正想要的那一侧，成功率 100%。任何只看任务成功率的评估都会给它满分——**它把一道理解错了的题，在一个标反了的世界里，做对了**。系统因此「证明」了标定正确、语义接地正确。打破这个自洽谎言，靠的不是更多成功的递杯，而是引入一个正交参照：一个只依赖身份、不依赖左右的任务（「递给戴红帽子的人」）去测语义，一个只依赖绝对几何、指令已认证无歧义的任务（「移到标定板前 10cm」）去测标定。

**灵感 1（指令泛化 = 语义的「该不变的不变，该敏感的更敏感」）**
直觉：好的指令泛化不是「对什么措辞都点头」。它要求两条同时成立：换一种说法（paraphrase、翻译、语序、省略）行为不变；只改一个语义要素（否定、量词、方位、实体、时序）行为必须变。只满足前者的是「什么都答应」的坍缩策略——对所有指令输出同一个动作，paraphrase 不变性满分，却根本没在解题。这与标定仪器完全同构：一个永远读 0 的传感器「重复性」完美，却毫无分辨率。泛化的正确度量因此是**双侧**的：不变性误差 J_inv 与最小对偶敏感性 J_sen，缺一不可。

**灵感 2（传感器标定 = 观测的规范变换 + 溯源）**
直觉：标定本质上是给观测选一张「坐标卡」（chart）。换安装角、换温度、换批次，物理量没变，读数变了；标定的工作是找一个变换把 nuisance 消掉，让不变量显形。但计量学还有一条被 R66–R69 弱化的铁律：**没有标准就没有标定**。标定值只有相对于一个可溯源的标准（fiducial、已知量块、计量链）才有意义；脱离标准的「自标定」可以完美解释任何残差。R70 把这条铁律搬到语义侧。

**灵感 3（真正的洞见：两者是同一群作用，因此可以互相冒充）**
直觉：设观测侧的规范变换为 g_S，指令侧的释义变换为 g_L。系统实际输出的是两者的**复合** B(ℓ,o) = π(· | G_θ(ℓ), C_κ(o))。若存在非平凡的联合变换 (g_L,g_S) 使所有支撑内 (ℓ,o) 上 B 都不变，那么闭环数据**根本无法分辨**是标定偏了还是指令被换了意思——因为只有复合量可见。这就是规范简并。R69 的 FMA 似然恰好是复合行为 B 的函数，因此在这种抵消下**结构性失明**：它能看见「行为变了」，却无法归因到 ℓ 还是 o。

**灵感 4（更多数据救不了混淆，只有锚能）**
直觉：如果简并方向落在数据支撑集内，再多同分布样本也只是在同一条平坦方向上滑得更远；损失面在该方向上的曲率是 0，梯度法不提供任何信息。打破简并必须改变**支撑集**：引入与两侧互不相关的外部参照。计量学的答案是标准件与挑战测试；语义学的答案是「经独立认证的指令—行为对」。所以本轮的关键资源不是算力，而是**锚**（anchor），以及锚的**帧混合性**（既含帧不变任务，也含帧协变任务）。

**灵感 5（「一次只动一个」：规范锁）**
直觉：联合适应是灾难的配方。正确做法是把 (θ,κ) 的适应做成**交替的单边适应**：动指令接地说时冻结标定，动标定时冻结接地说；切换必须通过被冻结一侧的已知答案挑战。这在数值上等价于强制选取一个规范（gauge fixing），并且每次只释放一个自由度。它把「自洽但错误」的联合漂移降级为「可检测的单侧误差」。

**灵感 6（主动澄清也要被溯源）**
直觉：R69 已经会问「世界是哪一种」；R70 要问「你要的是哪一件事」。但语义提问更容易诱导：选项顺序、预设（「是不是又坏了？」）、权威口吻都会把答案推向提问者的先验。因此 ACI 必须继承 R69 的非诱导与证据纪律，并且只把澄清结果当作**语义侧证据**，不允许它反过来悄悄重标定传感器——否则系统会用它自己问出来的答案去「证明」自己的坐标系是对的。

## 1. 形式化定义（增量：定义 310–329）

先固定贯穿全轮的假设，避免把结论建立在隐含前提上：

- **A99（任务可分解）** 真实行为可分解为 π(a | ψ, ξ)，其中 ψ = G\*(ℓ) 是意图规范，ξ = C\*(o) 是标定后的物理量；θ、κ 分别逼近 G\*、C\*。
- **A100（双侧群结构）** 释义群 G_L 在单位元局部连通，由保持语义的生成元 ℰ_G 生成；语义改变的最小编辑 E 是另一组方向，E ∩ Lie(G_L) = {0}。
- **A101（光滑与激励）** 行为 B 对 (θ,κ) 二次连续可微；锚集 Jacobian 可定义（覆盖条件见定义 321）。
- **A102（锚独立）** 锚标签的生成过程不包含当前 θ、κ，且带出处签名。
- **A103（密度 Lipschitz）** 继承 R69 的 A98：流策略密度对条件 Lipschitz，常数有界。

**定义 310（GIGA-RAS 总览）** GIGA-RAS = (SGR, IGR, ICS, ACI, GCL, AIC-GIGA, J_GIGA)。四条不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **规范锁**：同一适应窗口内，语义接地参数 θ 与标定参数 κ 至多一个处于 live（可更新），另一个必须冻结并带版本号；禁止联合适应；
(iii) **语义溯源**：任何 θ 更新必须在与更新目标独立的锚集 𝒜 上验证（A102），且不得提高锚集上的误差；
(iv) **保守包含**：U_sem 未消解或 U_conf 超阈时，风险缩放退化为 R69、再退化为 R68，安全侧只紧不松。

**定义 311（指令空间、释义群与最小对偶编辑）** 指令 ℓ ∈ ℒ。允许的释义群 G_L 由保持语义的编辑生成：同义替换、语序、冗余/省略、礼貌层级、跨语言翻译。商空间 ℒ/G_L 的每个元素是一个「说法类」。语义改变的最小编辑算子 e_i ∈ E（否定插入、量词替换、方位/介词互换、实体替换、时序倒置、作用域改变）不属于 G_L。**关键区分**：G_L 定义「应当不变」的方向，E 定义「必须敏感」的方向。

**定义 312（任务规范与语义接地）** 意图 ψ ∈ Ψ 是任务规范 ψ = (𝒢, 𝒞, φ_succ, τ_term)：目标集、约束集、成功谓词、终止条件。接地映射 G_θ: ℒ × 𝒪_ctx → Δ(Ψ)（上下文可含指代对象、对话历史、示教）。语义不确定性 U_sem = H(ψ | ℓ, o)。

**定义 313（标定作为规范变换与抵消对）** 标定映射 C_κ: 𝒪_raw → 𝒪_cal，κ 位于局部李群坐标。传感器帧变换 g_S 满足 C_κ(g_S·o) = C_{g_S κ}(o)（等变）。若存在从释义到坐标的对应 ρ，使对所有 (ℓ,o) 有 B(g_L ℓ, o) = B(ℓ, ρ(g_L)^{-1} o)，则称 (g_L, ρ(g_L)) 是一个**抵消对**——此时改变说法与改变坐标在行为上不可分辨。

**定义 314（规范稳定子、可辨识性与混淆维数）** Stab(θ,κ; ℬ) = {(g_L,g_S) ∈ G_L×G_S : B(g_L ℓ, g_S o) = B(ℓ,o)，∀(ℓ,o) ∈ ℬ}。若 Stab 在单位元邻域内平凡（维数 0），称 (θ,κ) 在电池 ℬ 上**可辨识**；否则称存在**规范简并**，d_conf = dim Stab 为混淆维数。**可辨识性是电池的性质，不是参数的性质**：换电池（改支撑集）才能改变它。

**定义 315（语义雅可比与双侧泛化证书）** 对 g ∈ Lie(G_L) 与 e_i ∈ E，令 d_B 为行为散度（动作分布 Wasserstein 或任务规范距离）：
J_inv = E_{ℓ,g} d_B(B(ℓ,o), B(e^{g}ℓ,o))；
J_sen,i = E_ℓ d_B(B(ℓ,o), B(e_i ℓ,o))。
语义泛化证书成立 ⇔ J_inv ≤ ε_inv ∧ min_i J_sen,i ≥ δ_sen。**第一式拒绝「过度敏感/脆性」，第二式拒绝「语义坍缩」**；单侧指标都有平凡欺骗解（见引理 22）。

**定义 316（组合同态与组合泛化）** 指令代数 (ℒ, ⊕)（并列、条件、时序组合）与任务代数 (Ψ, ⊗)。组合泛化度量
J_hom = E_{ℓ1,ℓ2} d_Ψ(G_θ(ℓ1⊕ℓ2), G_θ(ℓ1) ⊗ G_θ(ℓ2))。
J_hom 小 ⇔ 接地映射近似为代数同态 ⇒ 对训练中未出现的组合仍可预测。必须区分**已知原语的组合**（应泛化）与**未知原语**（应触发 ACI/拒答，而不是套用同态）。

**定义 317（标定–指令混淆分数）** 设观测到行为变化 ΔB = B_obs − B_{θ,κ}。分别求单侧最小解释
u_L = argmin_{δθ} ‖δθ‖ s.t. B_{θ+δθ,κ} = B_obs，u_S = argmin_{δκ} ‖δκ‖ s.t. B_{θ,κ+δκ} = B_obs。
定义 ρ_conf = exp(−|log‖u_L‖ − log‖u_S‖|) ∈ [0,1]：两侧能以可比代价解释同一行为变化时 ρ_conf→1。工程上由 ICS 电池的选择性差（定义 318）与规范交互项 I_gauge（定义 320）联合估计，避免在线求逆。

**定义 318（可分离性电池 ICS）**
- ℬ_inv：成功谓词对传感器帧**不变**的任务（停、等、保持直立、「它是红色吗」、计数、按身份指认）。在标定健康时，其误差选择性指向接地/能力。
- ℬ_cov：指令经认证无歧义、但成功依赖度量几何的任务（到已知 fiducial、插入深度 d、与目标对齐、沿桌面坐标走 10cm）。在接地健康时，其误差选择性指向标定。
- ℬ_cross：同义不同措辞的成对指令，跨两类任务各跑一遍。
判决表：ℬ_inv 高 / ℬ_cov 低 ⇒ 接地疑；ℬ_inv 低 / ℬ_cov 高 ⇒ 标定疑；两者同高 ⇒ 联合疑/混淆，进 LOCK_BOTH；两者低 ⇒ 通过。

**定义 319（干预式规范探针 / 已知答案挑战 KAC）**
(a) **释义挑战**：施加经认证的 g ∈ G_L，行为应不变；若变 ⇒ 接地对 nuisance 过敏。
(b) **标定挑战**：施加已知偏移 δκ（人为旋转外参 ε、加已知偏置），行为应按几何**精确**变化；几乎不变 ⇒ 标定层把真实偏差吸收掉了（R68 风险的镜像）；变化过大 ⇒ 欠校正。
(c) **语义挑战**：施加已知 e_i，行为应按语义精确变化；不变 ⇒ 语义坍缩。
KAC 是自检，不需外部标注，但需要**已知的扰动源**由独立硬件/流程提供——这一点是后面最大风险的伏笔。

**定义 320（因子化似然与规范交互项）** 设策略/流模型的对数似然 s(ℓ,o) = −log p(a | ℓ,o)。取参考观测 o₀ 与参考指令 ℓ₀：
s_L = s(ℓ,o₀)，s_O = s(ℓ₀,o)，s_X = s(ℓ,o)。
定义**规范交互项** I_gauge = s_L + s_O − s_X。若语义与几何可加分离，I_gauge 对 (ℓ,o) 近似常数；若模型用观测去「解释」指令（或反过来），I_gauge 随配对显著变化。**I_gauge 不是联合规范的函数**，因此能看见 R69 的 FMA 看不见的抵消。配对置换检验：把 (ℓ_i,o_j) 错配，若似然不显著下降 ⇒ 表征纠缠。

**定义 321（锚集、帧混合与可辨识覆盖）** 锚集 𝒜 = {(ℓ_k,o_k,y_k)}，y_k 为独立权威认证的结果（人、已知 fiducial、仿真真值残差），生成过程不含当前 θ、κ（A102）。**溯源性**：θ/κ 的每次更新都必须在 𝒜 上验证。**覆盖条件**：J_𝒜 = ∂B|_𝒜/∂(θ,κ) 列满秩（持续激励）。在 A101 下，若 𝒜 只含 ℬ_cov 且指令已认证，则 ∂B/∂θ ≡ 0，θ 不可辨识；只含 ℬ_inv 则 ∂B/∂κ ≡ 0。故锚必须**帧混合**。

**定义 322（规范锁 GCL 与切换契约）** 三模式：
- LOCK_CAL：κ 冻结于 κ\*，只更新 θ；
- LOCK_G：θ 冻结于 θ\*，只更新 κ；
- LOCK_BOTH：两者都不更新，只推理（默认/可疑态）。
切换契约：LOCK_CAL → LOCK_G 必须 (1) 在 ℬ_cov 上确认接地健康；(2) 通过释义挑战；(3) 通过 KAC(b) 的欠/过校正检查；反向对称。任一侧 KAC 失败或 ρ_conf > τ_conf ⇒ 立即进入 LOCK_BOTH，并把相关指令标记 **unverified**。

**定义 323（主动语义澄清 ACI）** 语义假设集 ℋ_sem = supp G_θ(ℓ)。澄清动作 q ∈ 𝒬（最小对偶问句、反事实复述、指认、演示、可执行探针——例如先小幅朝 A 移动看是否被纠正）。选择
q\* = argmax_q [VoI_sem(q) − c(q)]，VoI_sem(q) = H(ψ|ℓ,o) − E_{y_q}[H(ψ|ℓ,o,y_q)]，
约束：(i) 继承 R69 的交互预算与 C-RAS-WM 认证；(ii) **非诱导**：选项框架对称、无预设、无韵律/权威偏置，bias(q) ≤ τ_bias；(iii) **证据纪律**：澄清答案需与至少一个正交语义证据源一致（如指认 + 复述）才可定案；(iv) **只更新语义后验，不更新标定**（防止自证）。VoI≤0 或预算耗尽 ⇒ 不澄清，U_sem 未消解。

**定义 324（五分解与「不可由数据修复性」）** U = (U_ale, U_epi, U_sem, U_cal, U_conf)：
U_ale（R69 不可约噪声）、U_epi（R69 世界/动作歧义，可交互消解）、U_sem（指令语义歧义，可由 ACI/锚消解）、U_cal（标定不确定性，可由计量/KAC 消解）、U_conf（规范简并不确定性）。**U_conf 不能由同支撑集数据消解**，只能由新锚/新支撑集/外部参照消解。这是本轮的认识论核心：**「再测一次」与「再问一句」都修不好一个混淆；只有改变支撑集可以。**

**定义 325（三级风险退避与 unverified 指令）**
- 若 U_epi、U_sem 均在预算内消解且 U_conf ≤ τ_conf：λ = λ_floor(U_ale)（resolution bonus，不弱于 R69）；
- 若任一未消解：λ = λ_floor(U_ale + U_epi + U_sem)（未消解的语义视同不可约）；
- 若 U_conf > τ_conf 或锚覆盖不足或 KAC 失败：λ = λ_max（最小安全包络），停止适应，相关指令标记 unverified，只执行可被帧不变谓词认证的子任务。
包含性：U_sem=0 且无语义适应 ⇒ 与 R69 逐指令相同；再令 VoI=0 ⇒ 与 R68 相同。

**定义 327（审计与对抗 AIC-GIGA）** 新增威胁：
- **语义注入**：场景文字/语音/屏幕内容里藏指令（「忽略之前指令」）、同音词、作用域歧义、否定陷阱；
- **标定欺骗**：伪造 fiducial、磁/热致偏置、回放旧标定表、把故障传感器「标」成正常；
- **规范共谋（gaslighting）**：同时微调世界（挪动/旋转标定物）与用语（把「左」改称「右」），使系统的自洽检查恰好通过而事实错误；
- **锚污染**：让系统用与自己同源的模型生成「真值」锚。
审计新增：是否单边适应、是否在锚上验证、I_gauge 是否异常、澄清是否诱导、unverified 指令是否被执行。

**定义 328（跨具身不变/协变分解）** 同一语义 ψ 在不同具身（不同传感器套件/运动学）下应产生**任务等价**行为：指令侧是**不变量**，标定侧是**协变量**。判据：θ 的更新不应随具身改变，κ 必须随具身重标。跨具身迁移因此是一次天然的规范检验：若换具身后 θ 需大幅改动才能维持性能，说明 θ 吸收了本该属于 κ 的 nuisance（接地被标定污染）。

**定义 329（时序、预算与监测调度）** 语义雅可比监测不在每个控制周期运行：SJM 低频（约 1 Hz）或事件触发（新指令/新说话人/新句式）；ICS 电池与 KAC 在任务切换或长时空闲时后台运行；在线每周期只做 I_gauge 的 3 次似然评估（复用 R69 轨迹回放）。保证 P99 实时预算。

```python
class SemanticGaugeGrounding:
    def __init__(self, enc, psi_head, quotient_proj):
        self.enc, self.psi_head, self.q = enc, psi_head, quotient_proj
    def posterior(self, ell, ctx):                  # ℓ ↦ Δ(Ψ)
        h = self.enc(ell, ctx)
        return self.psi_head(h), self.q(h)           # (ψ 后验, 释义商坐标)

# IP-265/266 IGR + SJM：双侧语义雅可比（低频/事件触发）
def semantic_jacobian(ground, policy, ell, ctx, gens_G, edits_E):
    b0 = policy.behavior(ground.posterior(ell, ctx))
    J_inv = max(div(b0, policy.behavior(ground.posterior(g(ell), ctx)))
                for g in gens_G)                      # 该不变
    J_sen = min(div(b0, policy.behavior(ground.posterior(e(ell), ctx)))
                for e in edits_E)                     # 必须变
    return J_inv, J_sen                              # J_inv≤ε ∧ J_sen≥δ

# IP-267 ICS：帧不变 / 帧协变电池 → 选择性判决
def separability_verdict(battery_inv, battery_cov):

    if e_inv > T and e_cov < T:  return "GROUNDING_SUSPECT"
    if e_inv < T and e_cov > T:  return "CALIBRATION_SUSPECT"
    if e_inv > T and e_cov > T:  return "CONFOUNDED"
    return "HEALTHY"

# IP-268 GCL：一次只动一个

            if verdict == "GROUNDING_SUSPECT" or not kac.paraphrase_ok:
                return self.to("LOCK_BOTH")
            return self                               # κ 冻结，只更新 θ
        if self.mode == "LOCK_G":
            if verdict == "CALIBRATION_SUSPECT" or not kac.calibration_ok:
                return self.to("LOCK_BOTH")
            return self
        return self                                   # LOCK_BOTH：只推理

# IP-270 DFL：因子化似然 + 规范交互项（补 R69 FMA 的规范盲）
def gauge_interaction(score, ell, o, ell0, o0):
    s_L = score(ell, o0); s_O = score(ell0, o); s_X = score(ell, o)
    return s_L + s_O - s_X                            # 显著变化 ⇒ 语义/几何纠缠

# IP-271 KAC：已知答案挑战（自检，不需外部标注）
def known_answer_challenge(cal, ground, policy, o, ell):
    b  = policy.behavior(ground.posterior(ell, o), cal(o))
    dk = cal.challenge_offset()                       # 已知外参扰动
    b2 = policy.behavior(ground.posterior(ell, o), cal(o, dk))
    cal_ok = match(b2, predict_geometric(b, dk))      # 过/欠校正都抓
    g  = paraphrase(ell)                              # 认证释义
    b3 = policy.behavior(ground.posterior(g, o), cal(o))
    sem_ok = match(b3, b)                             # 应不变
    return cal_ok, sem_ok
```

## 3. 推导

**引理 19（规范简并下联合适应不可辨识）** 设行为只通过 B(ℓ,o) 被观测。若在 (θ\*,κ\*) 邻域内存在非零切向量 (δθ,δκ) 使 dB = 0 对所有支撑内 (ℓ,o) 成立，则任何仅依赖 B 的损失 L 沿该方向平坦（∇L·(δθ,δκ)=0，且该方向二阶导为 0）。因此 (i) 联合梯度适应不能分辨 (δθ,0) 与 (0,δκ)；(ii) 增加同支撑集数据不改变该零空间（核与数据无关）；(iii) 系统沿核漂移，得到自洽但错误的解。系：**R69 的 FMA 是 B 的函数；在模型已学到联合对称的极限下它对抵消严格不变，在未学到时也只能看见行为变化而无法归因**——这正是需要 I_gauge 的原因。

**引理 20（帧混合锚 ⇒ 可辨识）** 若锚集行为雅可比 J_𝒜 = ∂B|_𝒜/∂(θ,κ) 列满秩，则由隐函数定理 (θ,κ) 在 𝒜 上局部可辨识，规范稳定子平凡。进一步：若 𝒜 只含 ℬ_cov 且其指令已认证无歧义，则 ∂B/∂θ ≡ 0，θ 不可辨识；只含 ℬ_inv 则 ∂B/∂κ ≡ 0。故覆盖条件可操作化为 **rank(J_𝒜) = dim θ + dim κ**，且锚必须帧混合。

**引理 21（规范交互项是混淆的可观测判据）** 在 A99 与 A103 下，若接地与标定独立，则 s(ℓ,o) 近似可加，I_gauge 对 (ℓ,o) 近似常数；若存在抵消对（定义 313）或表征纠缠，则 I_gauge 随配对显著变化。由于 I_gauge 在非平凡 (g_L,g_S) 下取值改变，它不是联合规范不变量，故能穿透 R69 FMA 的盲区。可用配对置换检验给出无分布显著性。

**引理 22（语义坍缩的判别）** 常数接地映射 G(ℓ)=ψ₀ 使 J_inv=0 但 J_sen=0，被敏感性下界排除；对一切编辑都大幅改变行为的「脆性」映射可通过 J_sen 但不满足 J_inv。故双侧证书是语义泛化的**非退化**判据；任何单侧指标都存在平凡欺骗解。

**定理 18（GIGA 严格包含 R69 与 R68）** 当 U_sem=0 且 GCL=LOCK_BOTH（不做语义适应），GIGA 的世界侧路径与 R69 逐指令相同；当进一步 VoI=0 时与 R68 相同。并且对任意状态，GIGA 的 λ_floor 不小于 R69 的对应值（U_sem ≥ 0 只可能抬高下界），风险 ≤ R69。安全侧不做让步，效率侧仅在语义可辨识且消解成功时获得 resolution bonus。

**定理 19（规范锁的单调性与收敛）** 在 GCL 下每次更新只动一侧、另一侧冻结，且仅在锚集误差下降且 KAC 通过时接受。因此锚集误差序列单调不增；若锚覆盖（引理 20）成立，序列收敛到可辨识点。若锚被污染或不覆盖，ρ_conf 触发 LOCK_BOTH，系统**停止适应而非继续漂移**——失败模式是「停住并报警」，不是「自信地错下去」。

**定理 20（语义澄清的收益与安全）** 在 A95′（最小对偶可分性 δ_sen ≥ 3σ_sem）下，ACI 的期望任务成功率增益 ≥ c·δ_sen·(1−e^{−ΔH_sem})；当 VoI_sem ≤ c(q)、bias(q) > τ_bias 或证据纪律不满足时不做澄清，行为与 R69 相同。信息动作的物理安全由 R69 定理 17 继承（C-RAS-WM 认证 + 无突变）。

## 6. 本轮最大风险

**一句话**：GIGA-RAS 的全部可辨识性押在「锚集独立且未被污染」这一前提上——**若锚由与系统同源的模型自标注、或与接地/标定共享同一套传感器与语言先验，那么规范没有被打破，只是被固定到一个自洽的错误值上**；系统会拿到一张形式合法、指标漂亮的证书，却在一个错误的世界里稳定地做着错误的任务。**错误的锚比没有锚更危险：它把「诚实的歧义」升级为「被认证的谎言」。**

**次级风险与缓解**：
1. **KAC 的扰动源被模型吸收**（挑战本身被适应）→ 扰动源由独立硬件产生、挑战序列保密、以随机化顺序注入；
2. **语义电池泄漏**（评测句进入训练）→ 锚集与评测集分离、按句式族留出、定期轮换；
3. **澄清诱导**（选项/预设/韵律偏置）→ 非诱导约束 bias(q) ≤ τ_bias + 对称框架 + 人工审计；
4. **实时预算被 3 次似然击穿**→ 共享回放轨迹 + 低频调度 + K=1 默认路径；
5. **跨具身时 θ 吸收 κ**→ 定义 328 的天然规范检验，θ 漂移超阈即触发 LOCK_BOTH 并重标。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** 继承实时零学习写；规范锁（θ、κ 至多一个 live）；语义溯源（θ 更新须在独立锚集验证且误差不升）；保守包含（U_sem/U_conf 触发退化到 R69/R68）。

**定义 311–312（释义群与语义接地）** G_L = 同义/语序/省略/翻译等保义编辑；E = 否定/量词/方位/实体/时序/作用域等改义编辑。ψ 为任务规范；U_sem = H(ψ|ℓ,o)。

**定义 313–314（规范变换与可辨识）** 标定是坐标卡；抵消对 (g_L, ρ(g_L)) 使 B(g_L ℓ,o)=B(ℓ,ρ(g_L)^{-1}o)。Stab 平凡 ⇔ 可辨识；可辨识性属于电池而非参数。

**定义 315–316（语义雅可比与组合同态）** 证书 ⇔ `J_inv≤ε_inv ∧ min_i J_sen,i≥δ_sen`；`J_hom` 度量 `G(ℓ1⊕ℓ2)` 与 `G(ℓ1)⊗G(ℓ2)` 的距离，区分已知原语组合与未知原语。

**定义 317（混淆分数）** 单侧最小解释 u_L、u_S 的可比性，ρ_conf→1 表示强混淆；工程上用 ICS 选择性与 I_gauge 估计。

**定义 318（可分离性电池）** ℬ_inv（帧不变：停/等/保持直立/颜色/计数/身份）测接地；ℬ_cov（帧协变且指令认证：fiducial/插入深度/对齐/坐标位移）测标定；ℬ_cross 做同义复述。判决表把「谁在漂」变成可观测。

**定义 319（已知答案挑战 KAC）** 释义挑战应不变；标定挑战（已知 δκ）应按几何精确变化（不变=吸收，过变=欠校正）；语义挑战（已知 e_i）应按语义精确变化（不变=坍缩）。

**定义 320（因子化似然与规范交互项）** `s_L=s(ℓ,o₀)`、`s_O=s(ℓ₀,o)`、`s_X=s(ℓ,o)`；`I_gauge=s_L+s_O−s_X`。可加分离时近常数；纠缠时随配对显著变化。配对置换检验：错配似然不显著下降 ⇒ 表征纠缠。

**定义 321（锚集与覆盖）** 锚 `(ℓ_k,o_k,y_k)` 由独立权威产生、带出处签名；覆盖条件 `rank(∂B|_𝒜/∂(θ,κ))=dimθ+dimκ`。只含单一电池的锚必有一侧不可辨识 ⇒ 锚必须帧混合。

**定义 322（规范锁）** LOCK_CAL（κ 冻结，更新 θ）/ LOCK_G（θ 冻结，更新 κ）/ LOCK_BOTH（只推理）。切换须通过被冻结侧的释义/标定挑战；KAC 失败或 ρ_conf 超阈 ⇒ LOCK_BOTH + unverified。

**定义 323（语义澄清 ACI）** `q*=argmax[VoI_sem−c]`，s.t. R69 预算与 C-RAS-WM 认证、非诱导 `bias(q)≤τ_bias`、k 个正交语义证据一致、只更新语义后验不更新标定。VoI≤0 则不澄清。

**定义 324–325（五分解与三级退避）** U_conf **不可由同支撑集数据消解**。消解成功 `λ=λ_floor(U_ale)`；未消解 `λ=λ_floor(U_ale+U_epi+U_sem)`；混淆/锚不足/KAC 失败 `λ=λ_max` 且指令 unverified。

**定义 326–329（证书/对抗/跨具身/时序）** J_GIGA 含双侧雅可比、ECE_sem、ρ_conf、I_gauge、锚秩、双版本、gcl_mode、KAC；AIC-GIGA 增语义注入、标定欺骗、gaslighting、锚污染；跨具身判据 θ 不变、κ 协变；SJM 低频、ICS/KAC 后台、在线仅 3 次似然。

## 3. 关键算法伪代码

```python
# IP-264 SGR：语义规范接地（复用 R69 指令编码器）
class SemanticGaugeGrounding:
    def posterior(self, ell, ctx):
        h = self.enc(ell, ctx)
        return self.psi_head(h), self.q(h)          # (ψ 后验, 释义商坐标)

# IP-265/266 IGR+SJM：双侧语义雅可比
def semantic_jacobian(ground, policy, ell, ctx, gens_G, edits_E):
    b0 = policy.behavior(ground.posterior(ell, ctx))
    J_inv = max(div(b0, policy.behavior(ground.posterior(g(ell), ctx))) for g in gens_G)
    J_sen = min(div(b0, policy.behavior(ground.posterior(e(ell), ctx))) for e in edits_E)
    return J_inv, J_sen                            # J_inv≤ε ∧ J_sen≥δ，拒绝坍缩

# IP-267 ICS：帧不变/帧协变电池 → 选择性判决
def separability_verdict(battery_inv, battery_cov):
    e_inv, e_cov = eval(battery_inv), eval(battery_cov)
    if e_inv > T and e_cov < T:  return "GROUNDING_SUSPECT"
    if e_inv < T and e_cov > T:  return "CALIBRATION_SUSPECT"
    if e_inv > T and e_cov > T:  return "CONFOUNDED"
    return "HEALTHY"

# IP-268 GCL：一次只动一个
class GaugeCouplingLock:
    def step(self, verdict, kac):
        if self.mode == "LOCK_CAL":
            if verdict == "GROUNDING_SUSPECT" or not kac.paraphrase_ok:
                return self.to("LOCK_BOTH")
            return self                            # κ 冻结，只更新 θ
        if self.mode == "LOCK_G":
            if verdict == "CALIBRATION_SUSPECT" or not kac.calibration_ok:
                return self.to("LOCK_BOTH")
            return self
        return self                                # LOCK_BOTH：只推理

# IP-270 DFL：规范交互项（补 R69 FMA 的规范盲）
def gauge_interaction(score, ell, o, ell0, o0):
    return score(ell, o0) + score(ell0, o) - score(ell, o)

# IP-271 KAC：已知答案挑战
def known_answer_challenge(cal, ground, policy, o, ell):
    b  = policy.behavior(ground.posterior(ell, o), cal(o))
    dk = cal.challenge_offset()
    b2 = policy.behavior(ground.posterior(ell, o), cal(o, dk))
    cal_ok = match(b2, predict_geometric(b, dk))  # 过/欠校正都抓
    b3 = policy.behavior(ground.posterior(paraphrase(ell), o), cal(o))
    sem_ok = match(b3, b)                         # 应不变
    return cal_ok, sem_ok

# IP-276 主闭环（继承 R69）
def GIGA_RAS_round(M, obs, ell):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    psi, q = M.sgr.posterior(ell, obs.ctx)
    U_sem, J_inv, J_sen = M.sjm.update(psi, q, ell)
    verdict = M.ics.cached_verdict()
    I_g   = M.dfl.gauge_interaction(M.score, ell, o, M.ell0, M.o0)
    rho_c = M.conf.score(verdict, I_g, J_inv, J_sen)
    cal_ok, sem_ok = M.kac.cached()
    M.gcl.step(verdict, KAC(cal_ok, sem_ok))
    if rho_c > TAU_CONF or not M.anchor.covers():
        M.gcl.to("LOCK_BOTH"); psi = M.sgr.conservative_posterior(ell)
        U_sem = max(U_sem, U_unresolved)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    if U_sem > TAU_SEM and rho_c <= TAU_CONF and M.gcl.semantic_live():
        q_star = M.aci.choose(psi, obs, M.budget)     # 非诱导 + 预算 + 认证
        if q_star is not None:
            psi, U_sem = M.aci.update(psi, M.aci.execute(q_star),
                                      discipline='k_orthogonal')
    U_floor = U_ale + (U_epi if not resolved_world else 0.0) \
                    + (U_sem if not resolved_sem  else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if rho_c > TAU_CONF or not cal_ok or not sem_ok:
        lam, mode, k = lam_max, M.select_safest(modes), k_min
    else:
        mode = select_mode(modes, U_epi, lam)
        k = M.c_ras_wm.certified_prefix(...)
    M.vqa_g.submit(gcl_mode=M.gcl.mode, rho=rho_c, I_g=I_g,
                   jac=(J_inv, J_sen), anchors=M.anchor.versions())
    return k, lam, mode, (U_ale, U_epi, U_sem, U_conf=rho_c)
```

## 4. 推导

**引理 19（规范简并下联合适应不可辨识）** 若存在非零 (δθ,δκ) 使 dB=0 对所有支撑内 (ℓ,o) 成立，仅依赖 B 的损失沿该方向平坦。故联合梯度适应不能分辨 (δθ,0) 与 (0,δκ)；增加同支撑集数据不改变零空间；系统沿核漂移得到自洽错误解。系：R69 的 FMA 是 B 的函数，对抵消结构性失明。

**引理 20（帧混合锚 ⇒ 可辨识）** 锚行为雅可比列满秩时，隐函数定理给出局部可辨识、Stab 平凡。只含 ℬ_cov（指令认证）则 ∂B/∂θ≡0，θ 不可辨识；只含 ℬ_inv 则 ∂B/∂κ≡0。故 `rank(J_𝒜)=dimθ+dimκ` 是覆盖的可操作判据，锚必须帧混合。

**引理 21（I_gauge 是混淆判据）** 接地与标定独立时似然近似可加、I_gauge 近常数；存在抵消对或表征纠缠时随配对显著变化。I_gauge 不是联合规范不变量，故能穿透 FMA 盲区；配对置换检验给出无分布显著性。

**引理 22（语义坍缩判别）** 常数映射 J_inv=0 但 J_sen=0；脆性映射 J_sen 大但 J_inv 不达标。双侧证书是语义泛化的非退化判据。

**定理 18（严格包含）** U_sem=0 且 LOCK_BOTH ⇒ 与 R69 逐指令一致；再 VoI=0 ⇒ 与 R68 一致。λ_floor 因 U_sem≥0 只增不减，风险 ≤ R69。

**定理 19（锁的单调性与收敛）** 单边更新 + 锚误差下降 + KAC 通过 ⇒ 锚集误差单调不增；覆盖成立则收敛到可辨识点；锚污染/不覆盖 ⇒ ρ_conf 触发 LOCK_BOTH，停止适应而非漂移。

**定理 20（语义澄清的收益与安全）** A95′（δ_sen≥3σ_sem）下增益 ≥ `c·δ_sen·(1−e^{−ΔH_sem})`；VoI≤成本/诱导/证据不足时不澄清，行为同 R69；物理安全继承 R69 定理 17。

## 7. 本轮最大风险

**一句话**：GIGA-RAS 的全部可辨识性押在「锚集独立且未被污染」上——**若锚由与系统同源的模型自标注、或共享同一套传感器与语言先验，规范没有被打破，只是被固定到一个自洽的错误值上**；系统会拿到形式合法、指标漂亮的证书，却在一个错误的世界里稳定地做着错误的任务。**错误的锚比没有锚更危险：它把「诚实的歧义」升级为「被认证的谎言」。**

**次级风险与缓解**：KAC 扰动源被适应（独立硬件 + 保密随机序列）；语义电池泄漏（锚/评测分离、句式族留出、轮换）；澄清诱导（对称框架 + bias 阈值 + 人工审计）；3 次似然击穿预算（共享回放 + 低频调度 + K=1 默认）；跨具身 θ 吸收 κ（定义 328 检验，漂移超阈即 LOCK_BOTH 重标）。
