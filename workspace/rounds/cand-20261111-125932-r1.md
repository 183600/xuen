# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「最小可行产品」×「原型验证」）

> 第 54 轮已把技能组合从“能力匹配”推进为 **动作-鲁棒性双证书 J**，并用 SCOM/CEC/AEC 把组合、云边映射与对齐误差纳入可判定框架。但体系越完整，越暴露一个悖论：**证书声明的是“全动作空间 soundness”，而人类真正能验证的永远只是一个很小的动作子集**。本轮以「最小可行产品」和「原型验证」为反向压力，提出 **最小可证书核心 MCC、最小可证伪原型 MFP、原型保真度预算 SFB 与 MVP 证书 MVPC**，把研究范式从“把证书做得更全”转为“用最小原型最快击穿证书”。核心矛盾：H22：证书的 soundness 依赖 A26–A28（剖面完备、γ_ce Lipschitz、Explain 收敛），但这些假设在部署前几乎无法被全空间验证，形成**证书-证据鸿沟**；H23：若原型验证只追求“能跑通”的正向 demo，就会退化为 **validation theater / 古德哈特效应**——原型越简单越容易通过，却越不代表性。

## 0. 直觉与动机

**灵感 1（从“完整证书”到“最小可证书核心”）**
直觉：`J` 不必在 `A_core` 的每个动作上验证。若动作剖面 `α_S` 与鲁棒性谱 `ρ` 对动作是 Lipschitz 的，那么只需验证一个 **ε-网 `A_min`**，其 δ-邻域覆盖整个 `A_core`，就能用 Lipschitz 常数把 `A_min` 上的安全裕度外推到全空间。这正是 MVP 思想：**不是做完整产品，而是做能承载关键假设的最小切片**。`A_min` 越小，单位实验成本换来的证据密度越高。

**灵感 2（从“验证”到“证伪”：最小可证伪原型）**
直觉：原型的目的不是证明方案对，而是**尽快找到一个能让 `J` 崩塌的动作见证 `w`**。给定证书的每个假设（剖面完备性、γ_ce 单调性、Explain 收敛性），构造一个最小实验 `MFP`，其动作配置使 `J` 的预测裕度最小、环境扰动最大。若 `MFP` 都不能证伪，才暂时接受；这把“原型验证”定义为**主动的、对抗性的反例搜索**，而不是被动的 demo 展示。

**灵感 3（原型不是部署：显式建模保真度差距）**
直觉：机器人/边端原型与真实部署之间存在域差。若把原型通过率直接当成部署通过率，就是把 `δ_gap` 当 0。正确做法是：用**配对原型-部署实验 + conformal 上界**估计 `δ_gap`，并在证书迁移时显式扣除预算：`risk_deploy ≤ risk_proto + δ_gap`。MVP 的价值不在“便宜”，而在“差距可量化”。

**灵感 4（把 MVP 当作证书的编译目标）**
直觉：与其手工决定验证多少，不如让一个 **certificate→prototype 编译器** 自动产出 `M = compile(J)`：`A_min`（最小核心）、`W`（证伪见证集）、`δ_gap`（保真预算）、`β_cov`（失败模式覆盖率）。只有当 `β_cov ≥ β_min` 且 `δ_gap ≤ Θ_g` 时，才允许把原型证据升级为部署证书。MVP 因此成为证书体系的**最小可执行语义**。

**灵感 5（负结果优先的原型流水线）**
直觉：一次原型验证最有价值的产出不是“成功率 92%”，而是 **“被证伪的假设清单 + 仍未覆盖的失败模式”**。把 `β_cov` 提升为一等指标，迫使每轮原型主动寻找自己覆盖不到的失败模式，避免只在已知坑里反复自证。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（最小可证书核心 MCC）**
给定证书 `J`、核心动作集 `A_core` 与度量 `d_A`，称 `A_min ⊆ A_core` 为 `(ε, L)`-最小可证书核心，若：
```
(1) 覆盖：∀a∈A_core, ∃a'∈A_min, d_A(a,a') ≤ ε        （ε-网）
(2) 最小性：A_min = argmin |A| s.t. (1) 且 margin_J(a') ≥ m0 ∀a'∈A_min
(3) 外推：若 margin 为 L-Lipschitz，则 ∀a∈A_core, margin_J(a) ≥ m0 - L·ε
```
`A_min` 就是“能承载全局结论的最小实验切片”。

**定义 122（可证伪见证 Falsification Witness）**
见证 `w = (a, d, θ_env)` 由动作 `a`、鲁棒性维度 `d`、环境扰动参数 `θ_env` 组成。若 `margin_J(w) < 0`，则 `w` 证伪 `J`。见证价值定义为
```
V(w) = P_fail(w) / cost(w)      （单位实验成本的反例概率）
```
`W* = TopK_w V(w)` 为高价值见证集。

**定义 123（最小可证伪原型 MFP）**
`MFP = (A_min, W*, sim_conf, B)`，其中 `A_min` 来自定义 121，`W*` 为定义 122 的见证集，`sim_conf` 为仿真/硬件配置，`B` 为实验预算。`MFP` 的构造目标是
```
maximize  E[ I(∃w∈W*: J(w) 被证伪) ]
subject to cost(MFP) ≤ B,  A_min 为 (ε,L)-MCC
```
即：在预算内最大化“击穿证书”的期望，而不是最大化“演示成功”的期望。

**定义 124（原型-部署保真差距）**
```
δ_gap = sup_{a∈A_core} | risk_proto(a) - risk_deploy(a) |
```
用配对实验样本 `{(risk_proto^i, risk_deploy^i)}` 的 conformal 分位数给出上界 `δ̂_gap`，置信度 `1-α`。

**定义 125（MVP 证书）**
```
M = (J, A_min, W*, δ̂_gap, β_cov, evidence)
```
其中 `β_cov = |F_covered ∩ F_known| / |F_known| + λ·novelty`，`F_known` 为失败模式本体中的已知集合，`novelty` 为原型新发现的失败模式占比。可部署判据：
```
dom_J(T)=in ∧ δ̂_gap ≤ Θ_g ∧ β_cov ≥ β_min ∧ W* 未被证伪
```

**定义 126（失败模式覆盖率 FCR）**
`β_cov` 如定义 125；其补 `1-β_cov` 直接进入风险上界，度量“证书的测试充分性”，与 `ρ`（鲁棒性）、`α_S`（动作覆盖）正交。

## 2. 关键算法 伪代码

### IP-121 MCC（Minimal Certifiable Core）

```python
def minimal_certifiable_core(J, A_core, eps, L, theta_cov):
    # 贪心 ε-网：每次选能最大化未覆盖体积/成本 的动作
    A_min, covered = set(), set()
    while coverage(A_min, A_core, eps) < theta_cov:
        best, best_gain = None, -1
        for a in A_core - A_min:
            gain = uncovered_volume(a, A_core, covered, eps) / probe_cost(J, a)
            if gain > best_gain:
                best, best_gain = a, gain
        A_min.add(best)
        covered |= ball(best, eps)
    # 用 margin 与 Lipschitz 常数做外推自检
    assert all(margin(J, a) >= margin_min for a in A_min)
    return A_min, covered, L * eps
```

### IP-122 FWS（Falsification Witness Search）

```python
def witness_search(J, A_min, explain_roots, budget):
    # 以第 54 轮 Explain 根因为热启动，贝叶斯优化最大化 V(w)
    W, model = [], init_surrogate(explain_roots)
    while budget.remaining() > 0:
        w = model.propose_max_value()               # 兼顾探索/利用
        result = run_prototype(J, w)                # 最小原型执行
        budget.consume(result.cost)
        if margin(J, w) < 0:
            W.append((w, result))
            model.update(w, result, failed=True)
        else:
            model.update(w, result, failed=False)
    return W, model.posterior()
```

### IP-123 PVR（Prototype Validation Runner）

```python
def prototype_validate(J, MFP, alpha=0.05):
    W, post = witness_search(J, MFP.A_min, J.explain_roots, MFP.B)
    if W:
        return ('refuted', W, post)                 # 证伪优先，立即回传
    # 顺序检验（e-value / SPRT）累积“未被证伪”的证据
    e_value = sequential_evidence(post, MFP.A_min)
    if e_value > 1/alpha:
        return ('provisional_accept', MFP.A_min, e_value)
    return ('inconclusive', post)
```

### IP-124 SFB（Sim-to-Real Fidelity Budget）

```python
def fidelity_budget(proto_samples, deploy_samples, alpha=0.05):
    diffs = [abs(rp - rd) for rp, rd in zip(proto_samples, deploy_samples)]
    delta_hat = conformal_quantile(diffs, 1 - alpha)   # 分布无关上界
    return delta_hat, {'n': len(diffs), 'alpha': alpha}
```

### IP-125 MVPC（Minimum Viable Product Certificate Compiler）

```python
def compile_mvp_certificate(J, A_core, budget, beta_min, theta_g):
    A_min, _, eps_margin = minimal_certifiable_core(J, A_core, eps, L)
    MFP = MFP(A_min, W_star=topk_witness(J, A_min), B=budget)
    status, evidence = prototype_validate(J, MFP)
    if status == 'refuted':
        return ('reject', evidence)                  # 原型即证伪，不进部署
    delta_hat, _ = fidelity_budget(MFP.proto_samples, MFP.deploy_samples)
    beta_cov = failure_coverage(MFP, known=J.failure_ontology)
    if delta_hat > theta_g or beta_cov < beta_min:
        return ('insufficient_evidence', delta_hat, beta_cov)
    return ('ok', MVPCert(J, A_min, evidence.W, delta_hat, beta_cov))
```

### IP-126 CECP（Contrapositive Explain Coupling，与第 54 轮 Explain 联动）

```python
def refutation_to_repair(refuted_witnesses, J):
    # 把原型证伪的见证翻译为证书修补：缩小 A_core / 收紧 ρ_min / 重剖分 α_S
    repairs = []
    for w in refuted_witnesses:
        root = explain_failure(run_prototype(J, w), J.sim)
        repairs.append(plan_repair(root, w))
    return merge_repairs(repairs, priority='min_cost_first')
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| MCC | O(|A_core|²·|ε-net|)（可子模加速） | O(|A_min|) | ε-网覆盖半径、margin 单调 |
| FWS | O(B·(|T_surr|+c_probe)) | O(B) | 代理模型校准、见证独立同分布 |
| PVR | O(B + |A_min|) | O(B) | 顺序检验有效、α 控制 |
| SFB | O(n) | O(n) | 配对可交换性、conformal 覆盖 |
| MVPC | O(MCC + FWS + SFB) | O(|A_min|+B) | 组合门禁 sound |

**正确性定理（MVP Validation Soundness with Fidelity Budget）**
假设第 54 轮 (A26)–(A28) 成立，并新增：**(A29)** `A_min` 是 `A_core` 的 ε-网；**(A30)** 证书裕度对动作 `d_A` 为 L-Lipschitz；**(A31)** 见证搜索对价值 ≥ `ε_w` 的反例有检出概率 ≥ `1-δ_w`；**(A32)** conformal 上界 `δ̂_gap` 以概率 `1-α` 覆盖真实 `δ_gap`。
则部署失败概率满足
```
P_deploy_fail ≤ L·ε + (1-β_cov)·P_unknown + δ̂_gap + δ_w + α
```
关键：**ε-网把局部证据外推到全局**，**见证搜索把“证明”换成“未能否证”**，**conformal 预算显式吸收仿真-现实差距**，三者共同把第 54 轮的全空间声明降级为有预算的可检验声明。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| `A_min` 非 ε-网导致外推失效 | 高 | 分层留出动作层 + 实测 Lipschitz 常数 + 覆盖审计 |
| 见证搜索过拟合阈值（只找已知坑） | 高 | 独立留出见证 + 主动分布漂移 + 红队注入 |
| `δ_gap` 被系统性低估 | 高 | 配对实验 + conformal + 部署后在线回滚 |
| MVP 被当成最终产品（古德哈特） | 中 | 证书升级门禁 + 失败模式清单 + 定期全量抽检 |
| `β_cov` 度量主观 | 中 | 标准化失败模式本体 + 双人标注一致性 |

## 6. 本轮最大风险

**一句话**：MVP 把证书从“全空间声明”压缩为“最小核心 + 见证集”，其最大风险是 **用一个小而容易通过的原型制造出全局 soundness 的错觉**（验证剧场 / 古德哈特效应）——一旦 `A_min` 不是 ε-网、见证搜索只在已知失败模式内自证、且 `δ_gap` 被系统性低估，MVP 证书就会在部署分布漂移时集体失效；因此必须以 **留出动作层 + 独立见证 + 保真度 conformal 上界** 三重外部校验，把 MVP 定位为证伪工具而非证明工具。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（MCC×FWS×PVR×SFB×MVPC×CECP）

| MCC | O(|A_core|²·|A_min|)（子模贪心可近最优） | O(|A_min|) | ε-网覆盖 ≥ 95%，外推 `L·ε` |
| FWS | O(B·(|T_surr|+c_probe)) | O(B) | 见证价值排序 sound、独立留出 |
| PVR | O(B+|A_min|) | O(B) | e-value 有效、`α` 控制 |
| SFB | O(n) | O(n) | conformal 覆盖 `1-α`（可交换性） |
| MVPC | O(MCC+FWS+SFB) | O(|A_min|+B) | 门禁组合 sound |
| CECP | O(|W|·(|A|+c_exp)) | O(|W|) | 修补可追溯、最小成本优先 |

**正确性定理（MVP Validation Soundness with Fidelity Budget）**
假设第 54 轮 (A26)–(A28) 成立，并新增 **(A29)** `A_min` 为 `A_core` 的 ε-网；**(A30)** 裕度对 `d_A` 为 L-Lipschitz；**(A31)** 见证搜索对价值 ≥ `ε_w` 的反例检出概率 ≥ `1-δ_w`；**(A32)** conformal 上界以概率 `1-α` 覆盖真实 `δ_gap`。则
```
P_deploy_fail ≤ L·ε + (1-β_cov)·P_unknown + δ̂_gap + δ_w + α
```
关键：**局部最小证据经 ε-网 + Lipschitz 外推**，**“证明”被替换为“在预算内未能否证”**，**仿真-现实差距由 conformal 预算显式承担**。

- **对第 54 轮**：`J` 的 soundness 假设 A26–A28 由 MVP 层**逐条转成可证伪命题**，由 FWS/PVR 检验；

- **对 MVP 语义**：`M` 是证书的最小可执行语义，任何证书若无法编译出 `M`，即视为不可验证。

## 6. 本轮最大风险

**一句话**：MVP 把证书从“全空间声明”压缩为“最小核心 + 见证集”，其最大风险是 **用一个小而容易通过的原型制造出全局 soundness 的错觉**（验证剧场 / 古德哈特效应）——一旦 `A_min` 不是 ε-网、见证搜索只在已知失败模式内自证、且 `δ_gap` 被系统性低估，MVP 证书就会在部署分布漂移时集体失效；因此必须以 **留出动作层 + 独立见证 + 保真度 conformal 上界** 三重外部校验，把 MVP 定位为证伪工具而非证明工具。
