# 第 58 轮（承接第 57 轮「少样本×多模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「决策规划」×「手眼标定」）

> 第 57 轮把"证据说可信"推进到少样本可校准、跨模态可对账、个性化有界，但它仍隐含一个最强的"静止假设"：**地图坐标系与本体/执行坐标系之间的外参是已知且正确的**。所有证据都写在地图系，所有动作都落在本体系，而二者之间的变换被当作常识而非被检查的变量。**手眼标定**恰好刺穿这个假设：一个错误的外参会让全部观测与动作**自洽地整体偏移**——地图里每一步都落在"你以为的位置"，客观世界却系统性错位；更糟的是，第 57 轮引以为傲的跨模态对账，如果两个模态都经由同一个错误外参表达，它们会**同错同对**，"跨模态一致"退化为共模假一致。**决策规划**补上另一半：标定不是一次性的离线工序，而是一个有成本、有风险、其价值取决于当前决策的在线动作；只有当真值改变决策时，标定才值得做；而标定动作本身又要靠"当前可信坐标系"来保证安全——这是一个必须被显式打破的鸡生蛋。本轮把外参从"常量"变成**带版本、带漂移、带可信集的一等状态**，把"标定"从"前置作业"变成**与规划同台竞争预算的决策**，把"承诺"从"证据足够"升级为**"证据在可信坐标系内、且其坐标系版本一致"**。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"建立在可证对齐、版本一致坐标系上的证据说可信"**。

核心矛盾：
- **H32（自洽偏差 vs 可证伪）**：错误外参制造的是一种"自洽的错"——单次观测永远无法证伪，因为观测与动作共用同一套偏差；只有跨坐标系残差（接触 vs 视觉 vs 独立基准）、运动激励带来的可辨识性、以及时间漂移的不连续，才能把"自洽"变成"可证伪"。
- **H33（标定精度 vs 决策代价）**：外参可以标得很准，但代价是停机、专门动作与节拍；固定精度阈值要么在无关时刻过度标定（浪费），要么在关键时刻带病决策（欠标）。精度应随决策灵敏度自适应，而不是随日历自适应。
- **H34（标定即行动 vs 行动即标定）**：标定动作本身是物理动作，有风险、占预算，且需要"当前可信坐标系"来保证它安全；而"当前可信坐标系"又只能靠标定获得——不打破这个循环，标定要么不敢做，要么在错误坐标系里越标越自信。

## 0. 直觉与动机

**灵感 1（手眼标定 → 外参是一等状态，且会漂移）**
直觉：经典手眼标定解 `AX = XB`，求的是"眼睛看到的"到"手能做的"之间那个固定变换。它默认两件事：标定是一次性的、外参是常量。真实部署里这两件事都不成立——热胀冷缩、振动、负载形变、足端磨损、相机支架微动，都会让 `X` 缓慢漂移。于是真正的问题不是"如何把 `X` 标得更准"，而是"**如何在 `X` 已经不真的时候仍然不做不可逆的错事**"。做法是把 `X` 升级为状态 `C=(T,Σ,v)`：`T` 是外参估计，`Σ` 是其不确定度，`v` 是版本；再维护一个**可信集** `𝒞_α`——"真外参有 1−α 概率落在里面"。承诺只在"对 `𝒞_α` 中所有外参都安全"时给出，而不是只在"对点估计 `T` 安全"时给出。

**灵感 2（手眼标定 → 接触残差是天然的在线标定信号）**
直觉：机器人不必专门停机去标定。每一次落足/触探都是一次"手"的位姿测量；地图/视觉对同一位置有"眼"的预测；二者的残差就是一条标定观测。关键洞察是：**这只有在残差跨坐标系时才提供信息**——如果残差仍用同一个错误外参算出来，它永远是零，自洽地骗过你。所以自标定必须锚在一个"不经过待标定通道"的独立参考上（另一模态的几何基准、已验证锚点、外部基准），并监控**可辨识性**：接触点共线、法向单一、运动多样性不足时，某些方向的外参根本不可观测，此时可信集不得在该方向收缩。

**灵感 3（决策规划 → 标定的价值由决策决定，标定动作本身要被规划）**
直觉：标定不是越准越好，而是"够用就好"——够不够用取决于当前计划对外参有多敏感。如果一条宽支撑、对称落足的路径对 `T` 的小扰动不敏感，那么此刻花预算标定就是浪费；如果一条贴边路径的可行性完全取决于几毫米的外参，那么此刻不标定就是在赌。于是引入**决策条件标定价值 CVOI**：只有当"标定带来的决策改进"超过"标定成本 + 标定动作自身风险"时才标定。更进一步，标定动作本身必须在当前可信集下**可证安全且可卸载**（安全激励 / safe excitation）——用已验证的锚撑住，再做一个非退化但风险有界的激励动作。这就是用规划来打破 H34 的循环：**先做"在当前不确定下仍安全"的标定，而不是"标完才安全"的标定。**

**灵感 4（合流 → 标定感知规划 + 标定血缘）**
直觉：规划不能再在点估计坐标系里画一条线，而要在**可信集**上做鲁棒规划：把落足可行域按外参不确定度膨胀，在 `𝒞_α` 上取 minimax/satisficing，优先选择"标定不变量"（对称、宽支撑、对平移/旋转不敏感）的计划。与此同时，标定会更新，更新会**追溯性地改变旧证据的含义**：昨天"这里可承重"的证据，在地图系里是 (x,y)，外参一变，它对应的物理位置就变了。因此每条证据必须携带**标定版本与坐标敏感度**，标定更新时做**回溯重投影**：重投影后仍成立才保留，越出有效域就失效并降权；承诺证书要求参与证据的坐标系版本一致，或净重投影误差在容差内。

**灵感 5（证据门与算子 → 第六类证据 EV-calib 与标定-规划联合循环）**
直觉：本轮不增加"更多证据类"来堆安全，而是加一个**坐标系维度的证据类 EV-calib**：来自可辨识、独立参考、残差在可信集内的接触/几何证据。不可逆接触的必要证据集新增硬条件"坐标一致"——再强的裕度、再一致的跨模态，只要坐标系版本对不上，都不算数。算子 `CPE` 在每个检查点先读标定状态与决策灵敏度，必要时做安全激励标定并触发重投影，再在更新后的可信集上做标定感知规划与证据门校验；所有新机制仍只经"坐标系更准（含更保守的膨胀）"或"动作更保守（降档/绕行/弃权）"两个安全通道起作用，延续交互单调性。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（标定信念状态 CBS）** 外参变量 `T ∈ SE(3)`（地图/感知系 M ← 本体/执行系 B），标定状态 `C_t=(T_t,P_t,v_t,𝒞_t^α)`。漂移模型 `T_{t+1}=T_t·Exp(ξ_t)`，`ξ_t~f_drift(thermal,vibration,load,wear;θ_d)`，过程噪声协方差 `Q_d`（重尾，允许未建模阶跃）。可信集 `𝒞_t^α={T:(T⊖T_t)^T P_t^{-1}(T⊖T_t)≤χ²_{6,1−α}}`，`⊖` 为 SE(3) 对数映射；版本 `v_t` 单调不减。硬约束：标定证据不得只来自"经过 `T` 的自洽观测"，必须含至少一个**不经待标定通道**的独立参考通道（记 `indep_ref`）。

**定义 140（接触自标定 CHE 与可辨识性）** 第 `i` 个接触事件给出约束 `z_i=h_i(T)+ε_i`（接触点在本体系的位姿 vs 地图预测的残差，点-面/点-点形式），`ε_i~𝒩(0,R_i)`。信息矩阵 `J=Σ_i(∂h_i/∂T)^T R_i^{-1}(∂h_i/∂T)`。**可辨识条件**：`λ_min(J)≥λ_min^*` 且 `κ(J)≤κ_max`（否则沿零空间 `N(J)` 的方向不可观测）。在线更新：`P_t^-=P_{t−1}+Q_d`；`P_t^+` 由残差信息增量得到；对零空间方向强制保留（不收缩）即 `P_t^+ ← P_t^+ + Π_{N(J)}P_t^-`。可辨识性监控器在退化时把相应方向的可信集**加宽而非收紧**。

**定义 141（标定感知规划 CAP）** 给定名义计划 `π` 与可信集 `𝒞_t^α`，定义标定鲁棒安全值 `V_C(π)=min_{T∈𝒞_t^α} V(π;T)`。`C-safe(π) ⇔ V_C(π)≤δ_f` 且 `∀T∈𝒞_t^α` 约束满足。规划器取 `argmax_π V_C(π) s.t. C-safe(π)`，可等价实现为：按 `P_t` 的几何不确定度**膨胀地图/可行域**，并对计划施加"标定不变量"偏好（对称落足、宽支撑多边形、对 `T` 的平移/旋转梯度小）。`C-safe` 是承诺的必要条件，不是充分条件（仍需证据门）。

**定义 142（决策条件标定价值 DCV 与安全激励）** 标定动作 `a_cal`（激励轨迹/接触探测）必须：(i) 在当前 `𝒞_t^α` 下 `C-safe`；(ii) 可卸载/可回退；(iii) 非退化（预期新增信息 `λ_min(J(a_cal))≥λ_min^*`）。其价值
`CVOI(a_cal)=E_{z}[V_C^{post}(π*)]−V_C^{pre}(π*)−cost(a_cal)−risk(a_cal)`。
决策灵敏度 `S(π*)=‖∂V/∂T‖·σ_T`。仅当 `S(π*)≥S_min`（决策相关）且 `CVOI(a_cal)≥θ_cv` 时执行标定；否则在膨胀可信集上继续规划/承诺。新部署、大漂移事件、可辨识性告警时强制标定（预热）。

**定义 143（标定血缘与回溯重投影 CLA）** 每条证据 `e` 携带标定版本 `v(e)` 与坐标敏感度 `s_e=‖∂claim(e)/∂T‖`。标定更新 `δT=T_new⊖T_old` 时：`e'=T_new T_old^{-1}·e`；若重投影后 `e` 的声明越出自身有效域（裕度变号、置信区间不再覆盖、支撑多边形翻转），则标记 `invalid` 并降权；若 `‖δT‖≤τ_drift` 且不影响声明，则保留但血缘降级（权重乘 `η(v)`）。证据门新增 **EV-calib**：来自 `indep_ref` 且残差落在 `𝒞_t^α` 内的接触/几何证据；**坐标一致门**：参与不可逆接触承诺的全部证据须 `v(e)` 一致，或净重投影误差 `≤τ_rep`。

**定义 144（标定-规划联合算子 CPE）** 每检查点：①读 `C_t,𝒞_t^α`；②若 `S(π*)≥S_min` 且存在 `CVOI≥θ_cv` 的安全激励：执行 `a_cal`（预算 `k_cal`），更新 `C_t`，触发 CLA 重投影；③在更新后的可信集上做 CAP 规划/复核；④证据门（含 EV-calib 与坐标一致门）通过才承诺；⑤否则走探询/绕行/降档/L2 协商/安全停。预算 `k_probes+k_cons+k_cal`。证书 `J_a=J_p⊕(T_t,P_t,𝒞_t^α,v_cal,κ(J),calib_log,excitation_log,CVOI_log,reproj_log,drift_log,indep_ref)`。

## 2. 关键算法伪代码（完整版见产物区）

```python
def calib_belief_update(C, obs, drift):            # IP-139/140: 漂移 + 可辨识更新
    C.P = C.P + drift.Q(C.t, thermal, vib, load)   # 重尾过程噪声（含阶跃）
    J, indep = contact_info(obs)                   # 接触残差信息 + 独立性标记
    if not indep: return C, 'need_independent_ref'
    if lambda_min(J) < lam_star:                   # 退化：零空间不收缩
        C.P = C.P + project_nullspace(J, C.P)
        C.flag = 'unidentifiable'
    else:
        C = bayes_update(C, residual(obs), J)
        C.flag = 'identified'
    C.v += 1; return C, C.flag

def calibrate_aware_plan(pi, C):                   # IP-141: 可信集上鲁棒规划
    if not C_safe(pi, C.credible_set): return None  # 对点估计安全不够
    return argmax(pi_cands, key=lambda p: V_min(p, C.credible_set))

def safe_excitation(C, budget):                    # IP-142: 安全激励
    cands = [a for a in motions(C)
             if C_safe(a, C.credible_set) and unloadable(a)
             and expect_info(a) >= lam_star]
    return max(cands, key=lambda a: CVOI(a, C) - cost(a) - risk(a)) \
           if cands and CVOI(...) >= theta_cv else None

def reproject_evidence(M, dT, tau_rep):            # IP-143: 血缘回溯
    for e in M.evidence:
        e2 = dT * e
        if out_of_domain(e2) and sensitivity(e) * norm(dT) > tau_rep:
            M.invalidate(e); audit.log(('reproj_invalid', e.id))
        else:
            M.reweight(e, eta(e.version))
    M.bump()

def calibrate_plan_execute(x0, M, task, budget, C):  # IP-144: CPE
    for cp in plan_on_map(M, task).checkpoints:
        pi = pick_plan(cp, M)
        if decision_sensitive(pi, C) and (a := safe_excitation(C, budget)):
            C, _ = calib_belief_update(C, execute(a), drift); reproject_evidence(M, dT, tau_rep)
            budget.spend(a)
        pi = calibrate_aware_plan(pi, C)            # 可信集上复核
        ev = tag_evidence(cp, M, C, level=contact_level(cp))
        if pi and alignment_gate(ev, C) and evidence_gate(ev):
            commit(pi); continue
        return reroute_or_stop(cp, M, C, budget)
    return 'done'
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| CBS | O(1)/漂移步 | O(1) | 漂移模型诚实、可信集覆盖 ≥1−α_cal |
| CHE | O(N_c·d_h²)/更新 + O(d_h³) 特征分解 | O(d_h²) | 独立参考、可辨识性监控、零空间不收缩 |
| CAP | O(\|π\|·C_V) 可信集满意性检查 | O(\|π\|) | 在可信集全域而非点估计上验证 |
| DCV | O(\|A_cal\|·(C_V+E[I])) | O(\|A_cal\|) | CVOI 诚实、安全激励可卸载 |
| CLA | O(\|𝓜_ev\|·s_e) | O(\|𝓜_ev\|) | 版本/敏感度完备、重投影健全 |
| CPE | O(\|CP\|·(k_p+k_c+k_cal)·(C_VOI+C_V+d_h³)) | O(\|V\|+\|𝓜_ev\|) | 预算终止、坐标一致门 |

**正确性定理（Calibration-Sound Planning, CSP 概要）**：在 A33–A40 上加 **(A41)** 漂移模型与可信集：`P(T_t∈𝒞_t^α)≥1−α_cal`，漂移重尾诚实、大阶跃可被变化检测捕获；**(A42)** 可辨识性监控：可辨识方向才收缩，退化方向零空间保留，信息矩阵估计诚实；**(A43)** 安全激励：每个 `a_cal` 在当前可信集下 C-safe 且可卸载，CVOI 估计诚实；**(A44)** 标定血缘：每条参与承诺的证据携带版本与敏感度，重投影健全（误差 ≤τ_rep），`indep_ref` 独立于待标定通道。则：
(i) **标定健全性**：若 `π` 在 `𝒞_t^α` 上 C-safe，则真实外参落在集内时执行必安全；因外参导致的承诺失效率 ≤ `α_cal + τ_rep 项 + δ_f`。
(ii) **无自证漂移**：标定更新只能经"可信集收缩（附诚实覆盖）"或"旧证据失效/降权"改变系统；可行性只有在**可辨识且独立参考**带来的认证信息增益下才可扩张，且扩张量受测量信息界约束，不能被自洽残差单独扩张。
(iii) **单调性**：标定只经 (a) 坐标系更准（含更保守膨胀）或 (b) 动作更保守（降档/绕行/弃权）影响承诺；不改变决策规则本体。
(iv) **终止性**：每检查点标定动作 ≤ `k_cal`，CPE 在 `k_probes+k_cons+k_cal` 内终止于 {承诺, 绕行, L2 协商, 安全停}。
(v) **部署界**：`P_safe ≥ 1 − Σ_cp(δ_f+ε_meta+δ_probe+ε_h+δ_ood·α_conf+δ_xm·1[L1]+α_cal) − P(𝓜 陈旧未检出) − P(标定血缘漏检) − P(安全激励失效)`。

## 5. 风险与缓解

| 安全激励本身把系统推入风险 | 高 | 仅在当前可信集 C-safe 且可卸载的动作中选、锚优先、预算有界 |
| 标定更新导致旧证据大面积失效（可用性崩塌） | 中 | 重投影保留、血缘降级而非全删、τ_rep 容差与分版本证书 |
| 可信集膨胀过度 → 过度保守/绕行 | 中 | CVOI 触发标定以主动收缩、决策不变量计划降低灵敏度 |
| 标定/重投影时延进入控制回路 | 中低 | 增量滤波、特征分解增量、可退回点估计+硬膨胀的慢路径 |

## 6. 本轮最大风险

**一句话**：本轮把安全的赌注押在"可信集真的覆盖真实外参"上，而接触自标定的残差与跨模态对账**都在同一个外参 `T` 里计算**——一旦漂移是未建模的（例如一次未被 `f_drift` 捕获的支架微动），残差会自洽为零、可信集会在错误坐标系里不断收缩，CAP 便用"在错误坐标系内可证安全"的证书给出系统性的错误承诺，且越标定越自信；必须以不经 `T` 的独立参考、重尾漂移与变化检测、以及"认证信息增益才可扩张可行性"三条硬规则，确保标定只能让坐标系更可信，绝不能让一个自洽的幻觉获得承诺权。

### IP-140 CHE（接触自标定与可辨识性）

```python
def contact_info(obs):
    rows, indep = [], True
    for o in obs.contacts:
        p_b = o.body_pose; p_m = map_predict(o.region)
        rows.append(jacobian_h(p_b, p_m))          # ∂h/∂T
        indep = indep and o.reference != 'via_T'   # 必须有不经 T 的参考
    J = sum(A.T @ inv(o.R) @ A for A, o in zip(rows, obs.contacts))
    return J, indep

def che_update(C, obs):
    if not obs.has_indep_ref: return C, 'need_independent_ref'
    J, indep = contact_info(obs)
    lam = eigvalsh(J)
    if lam.min() < lam_star or cond(J) > kappa_max:   # 退化：不可辨识
        C.P = C.P + nullspace_inflate(J, C.P)          # 零空间保留/加宽
        C.v += 1; return C, 'unidentifiable'
    C = gaussian_update_se3(C, obs.residual, J)        # 可辨识方向才收缩
    C.v += 1; C.flag = 'identified'
    return C, 'identified'
```

def decision_sensitivity(pi, C):

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CBS | O(1)/漂移步 + O(1) 变化检测 | O(1) | 覆盖契约 ≥1−α_cal、重尾诚实（A41） |
| CHE | O(N_c·d_h²) 组装 + O(d_h³) 分解/更新 | O(d_h²) | 独立参考、可辨识监控、零空间不收缩（A42） |
| CAP | O(\|π\|·C_V) 可信集极值采样 | O(\|π\|) | 在可信集全域验证、膨胀单调（A41/A43） |
| DCV | O(\|A_cal\|·(C_V+E[I])) | O(\|A_cal\|) | CVOI 诚实、激励 C-safe 可卸载（A43） |
| CLA | O(\|𝓜_ev\|·s_e) 重投影 | O(\|𝓜_ev\|) | 版本/敏感度完备、重投影误差 ≤τ_rep（A44） |
| CPE | O(\|CP\|·(k_p+k_c+k_cal)·(C_VOI+C_V+d_h³)) | O(\|V\|+\|𝓜_ev\|) | 预算终止、坐标一致门、四态完备 |

**正确性定理（Calibration-Sound Planning, CSP）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 标定信念与可信集：`P(T_t∈𝒞_t^α)≥1−α_cal`，漂移模型重尾且未建模阶跃可被变化检测捕获；**(A42)** 可辨识性监控：仅可辨识方向收缩、退化方向零空间保留，`J` 与 `κ` 估计诚实；**(A43)** 安全激励：每个 `a_cal` 在当前可信集下 C-safe 且可卸载、提供 ≥`λ_min^*` 预期信息，CVOI 估计诚实；**(A44)** 标定血缘：参与承诺的证据携带版本与敏感度，重投影健全（误差 ≤τ_rep），`indep_ref` 不经待标定通道。则：

1. **标定健全性**：若计划在 `𝒞_t^α` 上 C-safe，则当真实外参落在集内时执行必安全；因外参导致的承诺失效率 ≤ `α_cal + τ_rep + δ_f`。
2. **无自证漂移**：标定更新只经"可辨识且独立参考的认证信息增益（可信集沿可观测方向收缩）"或"旧证据失效/降权"改变系统；自洽残差（经 `T` 计算的残差）不得单独使可信集收缩，故不存在"越标越自信的自洽幻觉"通道。
3. **单调性**：标定只经 (a) 坐标系更准（含不可辨识时的强制加宽）或 (b) 动作更保守（膨胀、降档、绕行、弃权）影响承诺；不改变决策规则本体与全局硬界。
4. **终止性**：每检查点安全激励 ≤`k_cal`，CPE 在 `k_probes+k_cons+k_cal` 内终止于 {承诺, 绕行, L2 协商, 安全停}。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1] + α_cal)
             − P(𝓜 陈旧未检出) − P(标定血缘漏检) − P(安全激励失效) − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
```

关键：**标定给精度、可信集给保底**（安全不押在点估计 `T` 上）；**接触自标定只在独立参考下给信息，退化只加宽不收紧**（打破自证漂移）；**安全激励用"当前不确定下仍安全"的动作换"未来更小的不确定"**（用规划打破 H34 的鸡生蛋）；**血缘/重投影把"坐标系版本"变成承诺的硬门**（外参一变，旧证据必须重新过堂）。

云边协议 CEB++ → **CEB#**：云端可下发**漂移模型参数与独立参考基准**，但**基准本身也要过隔离区**——先在边端以影子模式对既有证据做"重投影一致性回归"（覆盖不降 ∧ 可辨识告警不误报 ∧ 假承诺不升）通过后才接管可信集；边端回传标定残差、退化事件与重投影失效样本，作为云端的漂移建模与可辨识语料。第 57 轮"一切判定器走隔离"在本轮推广为"**连坐标系判定器也走隔离**"。

## 7. 本轮最大风险

**一句话**：本轮把安全的赌注押在"可信集真的覆盖真实外参"上，而接触自标定与跨模态对账**都在同一个外参 `T` 里计算**——一旦漂移是未建模的（一次未被 `f_drift` 捕获的支架微动或足端塑性变形），残差会自洽为零、可信集在错误坐标系里持续收缩，CAP 便用"在错误坐标系内可证安全"的证书给出系统性错误承诺，且越标定越自信；必须以不经 `T` 的独立参考、重尾漂移与变化检测、以及"认证信息增益才可扩张可行性"三条硬规则，确保标定只能让坐标系更可信，绝不能让自洽幻觉获得承诺权。
