# 第 43 轮（新循环第 3 轮） · Norm-ZeroShot：把「社会规范理解」编译成可组合契约、用「零样本泛化」把证书从检索插值升级为结构外推（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR 的 Sim-Cert-RAG 飞轮）。第 42 轮自陈最大风险是「仿真偏差累积 + 检索幻觉」：CKB 靠相似度检索，只能做**参数级插值**，一旦任务/环境在结构上新颖（组合未见、规范未见过），检索到的高相似模板会「自信地错」。本轮两个灵感词正面拆解这条失效链：**社会规范理解**把「安全」从纯物理碰撞扩展到**规范合规**（近体距离、让行、右侧通行、排队、轮次），并要求机器人理解**语境与角色**；**零样本泛化**提供方法论解药——不靠「见过相似的」，而靠「从已证原语按文法组合、由契约类型检查保证 soundness」，实现**结构级外推**。二者耦合出一个新证书范式：**规范 = 契约里的保证子句，零样本 = 契约的组合推导**；检索只负责参数迁移，结构新颖性交给组合证明。

## 0. 直觉与动机

**灵感 1（社会规范理解 → 安全的第二维：规范场与语境落地）**：第 42 轮的安全证书全是物理的（CBF 边际、碰撞距离、保持时间）。但真实部署里，机器人「不撞人」却「贴脸穿行、挡路、逆着人流、抢行」仍会被判失败——**社会不可接受 ≠ 物理不安全**。直觉是给机器人一副「规范眼镜」：把社会规范表示成**随语境/角色激活的约束场**——在走廊、电梯、斑马线、门口，对不同角色（行人、轮椅、儿童、工作人员），规范的**硬/软强度**不同。硬规范（法律/安全）必须恒满足，软规范（礼让、靠右、不挡道）允许在**违规预算**内权衡。规范冲突（效率 vs 礼让）用**规范格**的优先序消解。更关键：规范是**文化参数化**的（右侧通行 vs 左侧），这为灵感 2 的「零样本规范迁移」埋下伏笔。

**灵感 2（零样本泛化 → 从「检索相似」到「组合证明」的证书代数）**：第 42 轮 CKB 的本质是**案例推理/插值**：新任务 φ,ψ → 检索近邻 → 合并模板 → 差集补全。这在**参数邻近**时高效且 sound（有覆盖假设），但在**结构新颖**时没有 soundness 保证——这正是「检索幻觉」。零样本泛化的直觉完全不同：如果一个任务能由**已知原语按文法组合**得到，且每个原语带**假设-保证契约 (A,G)**，那么只要组合时前一个的保证能**推出**后一个的假设（G₁ ⟹ A₂），整段程序就**由构造而 sound**——不需要见过这个组合，不需要新数据，也不需要仿真重跑。这把验证变成**类型检查**（program : certificate），把任务程序变成**证明项**。无法静态消解的假设变成**残差义务 R(p)**，下推给运行时监控器。于是「零样本」不是「模型猜得好」，而是「证明系统在结构空间里外推」。

**灵感 3（二者耦合 → 规范模式迁移 + 检索/组合分工门）**：社会规范天然是「模式」而非「实例」：`靠右通行` 是**规范模式**，其文化参数（右/左）可替换，而不变式（「向迎面来车相反一侧超越」）保持不变。于是**零样本规范泛化 = 规范模式的参数重实例化 + 不变式保持验证**。同时，规范理解给零样本组合补上了**保证子句**：组合契约不仅要 G₁⟹A₂，还要**规范一致**（无硬规范冲突）。最后，把第 42 轮的风险显式制度化成一个**分工门**：按**结构距离 d_struct** 与**参数距离 d_param** 决定走 RAG（插值）还是 ZCC（组合外推）还是 SCV（冷启动仿真）。这样「检索幻觉」不再是隐患，而是被分诊规则挡在门外。

**耦合升级**：社会规范理解 = ZCC 的**新保证维度 + 规范模式库**；零样本泛化 = 把 CKB 从「模板仓库」升级为「契约 + 文法」的**证明引擎**；分工门 = 第 42 轮检索风险的**显式证伪器**。证书由此从 **Sim→RAG→Edge** 飞轮，进化为 **Norm→Contract→Compose→Edge** 的可证明外推体系，物理与社会两条主线在同一契约代数下统一。

## 1. 形式化定义（增量：定义 38–44）

**定义 38（社会规范单元与 deontic-STL）**：社会规范 `n = (ctx_n, ρ_n, φ_n, str_n, w_n)`，其中 `ctx_n: C×R → {0,1}` 是语境-角色适用谓词（C=地点类型/时间/人群密度，R=角色），`ρ_n` 是规范指向与参照的角色绑定（如「机器人让行人」），`φ_n` 是 deontic-STL 公式（O 义务 / F 禁止 / P 允许）定义在联合轨迹 `ξ=(x_robot, {x_human})` 上，`str_n ∈ {hard, injunctive, descriptive}` 是道义强度，`w_n≥0` 是违规严重度权重。语境 `c` 由语义图 + 社会感知（VLM 角色/群体/场景识别）给出。

**定义 39（规范格与冲突消解）**：适用集 `N(c,r) = {n : ctx_n(c,r)=1}`。强度序 `hard ≻ injunctive ≻ descriptive` 构成偏序，`(N, ⊑, ⊓, ⊔)` 为规范格，`⊑` 表「更强/更严」。**冲突消解是词典序的**：① hard 规范取合取（全部必须恒成立）；② injunctive 规范用**加权违规预算** `Σ w_n·V_n ≤ B`，优先级由格序决定；③ descriptive 规范仅作**人类行为预测先验**，不进入约束。若 hard 之间冲突（罕见），触发规范仲裁并上报人类（不可自动放行）。

**定义 40（社会证书与松弛 CBF）**：社会证书 `C_soc = (N_hard, N_soft, B, π_resolve)`。对 hard 规范，用 CBF 式屏障 `h_n(x) ≥ 0`（如近体距离 `h = d(x,P) − d_min`）；对 soft 规范，用**松弛 CBF** `h_n(x)+ε_n ≥ 0, ε_n ≥ 0`，在线最小化 `Σ w_n ε_n` 并累计 `∫ε_n ≤ B`。定义**社会边际** `m_soc = min_{n∈N_hard} h_n(x)`（归一化）。**社会安全** = 所有 hard 恒满足 ∧ 软违规预算未超支 ∧ 冲突已按 π_resolve 消解。

**定义 41（技能文法与假设-保证契约）**：技能文法 `G=(S,A,R,s0)`，产生式产出任务程序 `p`（序列 `;`、并行 `‖`、条件、循环）。每个原语技能 `s` 带假设-保证契约 `(A_s, G_s, N_s)`：`A_s` 是执行前对环境/前态的假设（STL），`G_s` 是后态保证 + 不变式，`N_s` 是此技能引入/满足的规范子句。**组合 soundness 条件**：`s1;s2` 合法当 `G_{s1} ⟹ A_{s2}`；`s1‖s2` 合法当假设相容且 `N_{s1} ⊎ N_{s2}` 无 hard 冲突。契约可**细化**（`G` 更强、`A` 更弱）。

**定义 42（零样本证书组合与残差义务）**：任务程序 `p` 由 `G` 导出。**类型检查**尽最大努力静态证明全部组合边条件；无法静态消解的假设构成**残差义务** `R(p)`。零样本证书 `C_zs(p) = (Π(p), R(p))`，`Π(p)` 是静态证明项（契约组合的证明树）。**定理（组合外推 soundness）**：若 `Π(p)` 的类型检查通过，且运行时对 `R(p)` 的每个义务由监控器保证成立，则 `p` 满足其组合契约（含物理 + 规范保证）；**该结论不依赖 KB 中存在相似任务**，故为结构意义的 zero-shot。定义**结构新颖度** `nov(p) = 1 − max_{p_i∈KB} sim_tree(p, p_i)`（推导树相似度）。

**定义 43（结构距离与检索/组合分工门）**：`d_struct(p, KB)` = 推导树到最近 KB 推导的归一化编辑距离；`d_param = dist(φ,ψ)` 嵌入距离。**分诊门** `Gate`：
- `d_struct ≤ ε_s` 且 `d_param ≤ ε_p` → **RAG**（插值；仅在覆盖假设下 sound，须附差集审计）；
- `d_struct > ε_s` 且 `p` 用已知原语可通过类型检查 → **ZCC**（组合外推；由定理 42 sound）；
- 存在未知原语 → **SCV**（仿真/人工冷启动，产出新原语或新规范模式）。

**命题**：`Gate` 把「检索幻觉」限制在 `d_struct ≤ ε_s` 的邻域内；结构新颖任务永远不被静默交给检索。

**定义 44（规范模式迁移与零样本规范泛化）**：规范模式 `Σ = (ψ[θ], I_Σ, Θ)`，`ψ[θ]` 是带文化/语境参数 `θ∈Θ` 的 deontic-STL 模板（如通行侧参数），`I_Σ` 是**不变式**（跨参数必须保持的语义，如「超越时与被超越者保持最小侧向净空且不阻断对向流」）。**零样本规范迁移**：对新语境参数 `θ'`，实例化 `Σ(θ')` 并验证 `I_Σ` 保持；若保持则规范语义可迁移，否则降级为待学习（入 SCV）。**命题**：`I_Σ` 保持 ⟹ 迁移后的规范在 `θ'` 下与原规范**同构**（相同的 O/F/P 结构）。

## 2. 产出设计（新增 IP-57/58/59 + 升级 IP-51/52/53/49/50/45/47/55/56）

### 2.1 IP-57 SOCIAL-NORM-CERTIFIER（SNC 社会规范证书器）
1. **规范落地**：社会感知（VLM + 语义图）输出 `(c, r, {x_human})` → 规范模式库匹配 → 实例化 `N(c,r)` → 冲突消解 → 硬/软约束流。
2. **规范模式库**：按「地点类型×角色×文化参数」组织的 deontic-STL 模板，每模板带不变式 `I_Σ` 与适用域标注；支持迁移验证。
3. **松弛 CBF + dSTL 编译**：硬规范编译为 CBF 约束（进入 IP-39 规划），软规范编译为 dSTL 监控器（进入 CMC/IP-53）。
4. **规范证书对象**：输出 `C_soc`，并入 IP-51 转移守卫与运行时监控；规范违规作为**新型反例**回灌飞轮。

### 2.2 IP-58 ZERO-SHOT-CERT-COMPOSER（ZCC 零样本证书组合器）
1. **技能文法与契约库**：从既有技能/乘积模板（IP-47）抽取 `(A,G,N)` 契约，建立文法与可组合索引。
2. **契约类型检查器**：把任务程序 `p` 解析为推导树，逐边检查 `G₁⟹A₂`、假设相容、规范无硬冲突；用 SMT/区间算术/抽象解释混合判定。
3. **残差义务抽取与下推**：静态不可判定的假设 → `R(p)` → 生成运行时监控器（复用 IP-56 L1 INT8 / LCS），实现「能证则证、不能证则监」。
4. **证明项与证书签发**：产出 `Π(p)`（可审计证明树）+ `C_zs(p)`，与 IP-55 版本化溯源对齐；证明失败时给出最小反例骨架供人工/SCV。

### 2.3 IP-59 NORM-SIM（社会规范仿真器，扩展 IP-54）
1. **社会智能体与规范场景**：Isaac Sim 中注入人群（ORCA/社会力）+ 规范行为（让行、排队、靠侧），随机化文化参数 θ 与场景类型。
2. **规范压力测试**：专门生成「规范冲突/边界」场景（狭窄走廊会车、电梯满员、斑马线抢行），测 `C_soc` 的硬违规率与软预算。
3. **规范反例归因**：违规轨迹 → 归因为「语境误判/角色误判/模式迁移失败/冲突消解错误」，回灌 CKB 与 SNC。
4. **规范模式挖掘**：从大规模人类轨迹中归纳候选规范模式与不变式，供人工确认后入模式库。

## 5. 本轮最大风险

**一句话**：社会规范是**开放纹理（open-textured）且文化歧义**的，任何有限的 deontic-STL/规范模式库都只能覆盖「规范显式化」的子集——一旦机器人把**未形式化的规范**当作不存在，或把「模式匹配成功」误当成「规范理解正确」，系统会**物理安全却社会冒犯**，且零样本组合的「由构造 sound」只在**契约模型正确**这一前提下成立；因此 E90（组合 soundness）与 E92（分工门零误判）是红线，且必须保留「规范不可消解即上报人类」的硬出口。

# 第 43 轮产物 · 创新点清单 v20：Norm-ZeroShot（SNC × ZCC × NORM-SIM）× 契约代数外推（四层架构 v8）

> 承接第 42 轮产物 v19。本轮**增量插入** IP-57/58/59，并升级 IP-51/52/53/49/50/45/47/55/56；不推倒既有层级。核心是把 v19 的「检索插值」扩展为「检索插值 + 契约组合外推」双引擎，并把「安全」从物理扩展到社会规范，两条线共享契约代数。

## 2. 关键算法（伪代码）

### IP-57 SNC：规范落地、冲突消解与社会证书
```
def ground_social_norms(context, roles, humans, norm_patterns):
    N = []
    for pat in norm_patterns.match(context, roles):   # 模式库匹配
        n = pat.instantiate(context, roles)            # 实例化 ctx/ρ/φ
        if n.ctx(context, roles): N.append(n)
    return resolve_conflicts(N)                         # 规范格消解

def resolve_conflicts(N):
    hard = [n for n in N if n.str == 'hard']
    soft = [n for n in N if n.str == 'injunctive']
    desc = [n for n in N if n.str == 'descriptive']
    # hard 取合取；若 hard 之间矛盾 → 上报，不自动放行
    if has_contradiction(hard):
        return SocialCert(escalate=True, hard=hard, soft=soft)
    # soft 按格序 + 权重排序，形成加权预算约束
    soft.sort(key=lambda n: (-n.priority, -n.w))
    return SocialCert(hard=hard, soft=soft, descriptive=desc,
                      budget=B_default, pi='lexicographic')

def social_cbf_constraint(C_soc, x, humans):
    # 硬规范 → CBF 约束；软规范 → 松弛变量
    A_h, b_h = [], []
    for n in C_soc.hard:
        h = n.barrier(x, humans)          # 如 d(x,P)-d_min
        A_h.append(h); b_h.append(0.0)
    slack_terms = [(n.w, n.barrier(x, humans)) for n in C_soc.soft]
    return A_h, b_h, slack_terms            # 交给 IP-39 规划做 min Σ w·ε
```

### IP-58 ZCC：契约类型检查与零样本证书
```
def zero_shot_compose(task_program, grammar, contracts):
    tree = grammar.derive(task_program)         # 推导树
    obligations, proof = [], []
    for edge in tree.edges:                     # 逐组合边
        s1, s2, mode = edge.left, edge.right, edge.mode
        if mode == 'seq':
            # sound iff G_s1 ⟹ A_s2
            ok, residue = implies(contracts[s1].G, contracts[s2].A)
            if not ok:
                if residue is None:
                    return ProofFailure(edge, 'assumption_unprovable')
                obligations.append(residue)      # 下推为运行时义务
            # 规范子句一致：无 hard 冲突
            if conflicts_hard(contracts[s1].N, contracts[s2].N):
                return ProofFailure(edge, 'norm_conflict')
        elif mode == 'par':
            if not compatible(contracts[s1].A, contracts[s2].A):
                return ProofFailure(edge, 'assumption_incompatible')
        proof.append((edge, mode, ok))
    C_zs = ZeroShotCertificate(proof=ProofTree(proof), residual=obligations)
    return C_zs

def dispatch_gate(task_program, KB, grammar, contracts, eps_s, eps_p):
    d_struct = struct_distance(grammar.derive(task_program), KB.derivations)
    d_param = param_distance(task_program.phi, task_program.psi)
    if d_struct <= eps_s and d_param <= eps_p:
        return 'RAG'                             # 插值，需差集审计
    if all_primitives_known(task_program, grammar, contracts):
        return 'ZCC'                             # 组合外推，由构造 sound
    return 'SCV'                                 # 冷启动仿真/人工
```

```
def social_pressure_test(C_soc, scene_gen, D_culture, N_traj=2000):
    results = []
    for _ in range(N_traj):
        scene = scene_gen.sample()                # 走廊/电梯/斑马线/门口
        theta = D_culture.sample()                # 文化参数
        humans = spawn_social_agents(scene, theta, policy='norm_compliant')
        traj = rollout(scene, humans, C_soc)
        results.append(evaluate(traj, C_soc))
    return aggregate(results)                     # 硬违规率/软预算/冲突事件

def attribute_norm_violation(traj, C_soc):
    labels = []
    if traj.ctx_est != traj.ctx_true: labels.append('context_misgrounded')
    if traj.role_est != traj.role_true: labels.append('role_misgrounded')
    if not invariant_preserved(traj, C_soc.schema): labels.append('norm_transfer_fail')
    if traj.conflict_resolution != 'lexicographic': labels.append('conflict_resolution_error')
    return {'traj': traj, 'labels': labels, 'root_cause': majority_vote(labels)}
```

```
def car_deontic_guard(e, x, cert_obj, C_soc):
    m_phys = cert_obj.m_lo[e]
    m_soc = social_margin(C_soc, x)               # 硬规范最小屏障
```

## 6. 本轮最大风险

**一句话**：社会规范是**开放纹理且文化歧义**的，任何有限的 deontic-STL/规范模式库都只能覆盖「规范显式化」的子集——一旦机器人把**未形式化的规范**当作不存在，或把「模式匹配成功」误当成「规范理解正确」，系统会**物理安全却社会冒犯**，且零样本组合的「由构造 sound」只在**契约模型正确**这一前提下成立；因此 E90（组合 soundness）与 E92（分工门零误判）是红线，且必须保留「规范不可消解即上报人类」的硬出口。
