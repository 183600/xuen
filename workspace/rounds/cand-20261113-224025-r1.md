# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「常识推理」×「数据采集」）

> R69 把不确定性一分为二，用「流匹配多模态策略 + 主动交互」去消解 epistemic 歧义，并留下一条对偶通道 (r_res, Δa) 盯防缓变故障。但它仍有两个盲区：
> 1. **它只会消解「已表示」的歧义。** 当策略只有**一个**模态、且这个模态置信很高时，H_mode≈0、U_epi≈0，R69 会给一个很松的 λ——恰恰在「自信地错」的时刻，它对危险最不设防。真正的问题不是「两个模态选哪个」，而是「**我的概念空间本身是不是错了**」（把电梯门当成可穿越的空隙、把人的后退当成邀请、把反光当成水面）。这类**本体论不确定性（ontological uncertainty）**无法靠多采样或追问同一套概念消解。
> 2. **它不积累知识。** 交互答案只用在本回合，问完即弃；系统永远不知道自己反复错在哪，也永远不知道该收集什么数据。数据采集在 R66–R69 里是「假定的、免费的、干净的」——而真实世界里数据是一个**有成本、有偏、可被投毒、涉及隐私与同意**的动作。
>
> 本轮两个灵感正好是彼此的镜像：
> - **常识推理**给出一个**不依赖策略自身假设空间**的独立先验——它能在模型最自信时说出「这不合常理」，从而成为**唯一能触到未知未知（unknown unknowns）的通道**；但常识粗糙、有文化/情境偏差、会幻觉，只能当「提议者」，绝不能当「裁决者」。
> - **数据采集**给出**唯一能扩张假设空间、纠正常识**的手段——但采集不是被动记录，而是一个有 value-of-information 的动作；**最该采集的地方，正是独立先验与模型发生分歧的「惊讶前沿」**。
>
> 核心命题：**在 R69 的 (aleatoric, epistemic) 之外加入第三种不确定性 U_sem（本体论/概念缺失），用「常识先验」检测它、用「预算化的稀有事件数据采集」在离线侧消解它，并用「来源追踪、校准门、自采比例上限、延迟写入」四条纪律防止数据回路把系统变成偏见的放大器或自我确认的回音室。**
> 命名 **CURATE-RAS**（Commonsense-grounded Uncertainty-triggered Rare-event Acquisition & Trustworthy Experience）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**什么才值得记住，而我的常识还不知道什么**」——常识是最廉价的期望，数据是最昂贵的证据；没有常识不知道该采什么，没有数据不知道常识错在哪。

## 0. 直觉与动机

**灵感 1（常识推理 → 一个不看模型脸色的独立先验）**
直觉：R68/R69 的所有异常信号都来自模型自己——残差、似然、模态熵。一个自洽但错误的世界模型可以在这些通道上全部「表现良好」，这正是「自信地错」。常识推理提供的是**外部锚点**：物体不会穿墙、满杯倾斜会洒、人后退通常不是邀请、反光不是地面。它不需要模型相信某个假设，只需要判断「这个（观测，动作，预测结果）合不合常理」。于是它能在 H_mode≈0 时依然报警——这是 aleatoric/epistemic 之外的第三个维度。

**灵感 2（数据采集 → 一个带成本、带偏、带伦理的动作）**
直觉：主动学习里最经典的失败是「在错误模型上做不确定性采样」——模型越错越自信，于是越不去采。用**独立的常识先验**做采集触发器，等于给不确定性采样换了一个不共享错误模式的裁判。数据价值也不该是「对参数的信息量」，而应是「**对安全决策的风险降低 / 单位成本**」：一条数据只有在你真的会因为它改变某个危险决策时才值钱。且采集天然带选择偏置——只采「惊讶样本」会让数据集失去真实基率，必须配背景采样与逆概率加权。

**灵感 3（对偶 → 常识是期望，数据是证据）**
直觉：常识先验给「应该发生什么」，数据给「实际发生了什么」。没有常识，你不知道哪里值得看（只能采到分布头部）；没有数据，你不知道常识哪里错了（只能活在自己的成见里）。二者构成一个闭环：**常识 → 惊讶 → 采集 → 审计 → 蒸馏/扩充概念 → 更准的常识**。这不是又加一层黑箱，而是给已有闭环补上「先验—证据」的呼吸。

**灵感 4（第三种不确定性 → U_sem 不可在回合内消解）**
直觉：U_ale 是噪声（再多数据也不减），U_epi 是已表示模态间歧义（问一句/采一点就能减），U_sem 是**概念缺失或错配**（「我根本没有这个词来描述眼前发生的事」）。关键区别：U_sem 在回合内**不可能**被消解，因为消解它需要改表征/改概念，而实时流禁止学习写操作。所以回合内的正确姿态是：**把 U_sem 当作不可约，保守兜底；把它记下来，交给离线数据回路去扩张概念**。这是对 R69「可约就交互」的一个必要限制——有些不确定性，这一秒就是解不了。

**灵感 5（数据是双刃剑 → 反馈坍塌与偏见放大）**
直觉：一旦系统能自己决定采什么、并用采来的数据训练自己，就有两个新 failure：(a) **回音室**——只采常识认为奇怪的东西，于是永远发现不了常识想象不到的未知；(b) **偏见放大**——常识在某个文化/情境下是错的，采集预算就系统性地偏向那个错误，数据又强化常识，形成自我确认的飞轮。再叠加投毒、隐私、同意。所以本轮必须同时交付：常识校准门、来源追踪、自采数据比例上限、上下文分层配额、延迟写入，以及「常识只提议不裁决」的纪律。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（CURATE-RAS 总览）** CURATE-RAS = (CSG, ODD, DVA, ARC, DCG, VQAuditor-D, RAS-WM‡)。四条不变式：
(i) **延迟写入**：数据回路不得写任何实时模块；当前回合只用冻结权重（继承 R68 定义 276-i、R69 定义 293-i）；
(ii) **常识只提议不裁决**：CS 只能触发「采集 / 保守兜底 / 查询慢 oracle」，绝不允许仅凭 CS 放行一个动作；动作安全仍由 C-RAS-WM 认证；
(iii) **本体论保守**：回合内不可消解的 U_sem 视同不可约，进入 λ floor；
(iv) **数据纪律**：来源可溯、常识校准、自采比例 ≤ α_max、上下文分层、隐私/同意可审计。

**定义 311（常识谓词空间与接地）** 谓词集 𝒫 = 𝒫_phys ∪ 𝒫_aff ∪ 𝒫_soc ∪ 𝒫_temp（物理 / 可供性 / 社会规范 / 时序因果）。对（观测 o，动作 a，预测结果 ŝ'）有真值 p*(o,a,ŝ') ∈ {0,1}。快速评论家 c_φ 输出 |𝒫| 维概率（蒸馏自慢 oracle）；慢 oracle O_ψ（冻结 VLM/LLM + 符号检查器）按预算查询。接地损失 L_CS = Σ_p BCE(c_φ, p*) + λ_s·一致性(c_φ, O_ψ)。

**定义 312（常识残差与惊讶）** 常识合理性 π_cs(o,a,ŝ') = Π_{p∈𝒫_req} c_φ(p)^{w_p}（或校准 log-odds 均值）；常识惊讶 S_cs = −log π_cs。评论家 epistemic 用集成方差 Var_cs 表示——**连常识自己都不确定时，不许它触发高成本采集**。

**定义 313（双通道惊讶四象限）** 模型惊讶 S_wm = −log p_θ(ŝ'|o,a)（R67 WM）；常识惊讶 S_cs。四象限：
- Q1（S_wm↑, S_cs↑）：真新颖 → 数据价值最高；
- Q2（S_wm↑, S_cs↓）：模型覆盖缺口但常识熟悉 → 可能重复/可蒸馏，采集优先级低；
- Q3（S_wm↓, S_cs↑）：**自信的胡话** → 最危险，立即安全兜底 + 采集；
- Q4（S_wm↓, S_cs↓）：正常。
R68/R69 主要看 Q1 一侧；**Q3 对它们完全隐形**。

**定义 314（本体论不确定性 U_sem）** 设模型类闭包为 ℳ、真实过程为 P*。U_sem = D_f(P*‖ℳ) 中**无法在 ℳ 支持内被似然识别**的部分。可操作代理：U_sem = E[ max(0, S_cs − τ_cs)·1{S_wm < τ_wm} ] + β·Var_cs。语义：模型很自信、常识很惊讶——差别不在「哪个模态」，而在「有没有这个概念」。

**定义 315（三分解与通道）** U = (U_ale, U_epi, U_sem)。通道：U_ale → R68 λ floor；U_epi → R69 交互消解；U_sem → 实时保守 + 离线扩张。三者不简单相加；回合内 U_sem 不可约。

**定义 316（数据价值 VoD）** 对数据 d（带上下文的事件/转移），VoD(d) = [E_{θ~post}R(θ) − E_{θ~post|d}R(θ)] / c(d)，其中 R 是**决策风险泛函**（安全边界违规率、稀有事件漏检率），非全参数似然。c(d) 含存储/标注/遥操作/同意成本。只在 d 会改变某个危险决策时才计值。

**定义 317（覆盖与子模性）** 覆盖 F(S) = Σ_{x∈𝒳} w(x)·max_{d∈S} sim(x,d)。采集目标 G(S) = Σ_{d∈S} VoD(d) − ρ·冗余(S) + η·F(S)。在 A99（sim 有界、边际递减）下 G 单调子模 ⇒ 贪心 ≥ (1−1/e)OPT。

**定义 318（稀有事件采集器 ARC）** 触发：Q3 ∨ U_sem > τ_sem ∨ 审计请求，且预算未超。选择：S* = greedy(G)。双轨：**锐采**（高保真、全来源、危险稀有事件）与**广采**（覆盖、低成本、含背景样本）。强制**背景/负样本配额**与逆概率加权，抵消惊讶采样带来的选择偏置。

**定义 319（延迟写入不变式）** 采集异步、离策略、带来源标签；实时模块只读冻结权重；任何训练/蒸馏离线、经 DCG 与证书版本化，可回滚。⇒ 采集不能改变当前安全包络。

**定义 320（常识校准与情境）** CS 先验以情境 κ（文化、场所、用户）为条件；校准误差 ECE_cs。若 ECE_cs > τ_cs 或 κ 为 OOD ⇒ 常识只能提议、不能单独触发高成本采集，必须 oracle 复核（常识校准门 CCG）。

**定义 321（数据策展门 DCG）** 来源校验、投毒过滤、自采比例 α ≤ α_max、留出人类/物理真值、上下文分层配额、隐私脱敏与同意标记。任一项不过 ⇒ 该批数据不得进入离线训练。

**定义 322（常识蒸馏与概念扩张）** 离线用 oracle 对「分歧样本」标注，蒸馏进 c_φ；用被 curated 的数据更新谓词/概念本体，版本化并保留回滚。**回写只发生离线**，实时流不感知。

**定义 323（参与式数据审计 VQAuditor-D）** 审计「采了什么、为什么采、是否公平、是否越权」：来源、覆盖、上下文分层、自采比、同意/隐私、常识是否单独定案。结论回灌 ARC 的成本先验。

**定义 324（采集威胁模型 ℰ_collect）** 投毒演示、貌似合理的错误人类示范、利用文化刻板印象的常识对抗、隐私外泄、反馈坍塌、oracle 幻觉。并入 AIC：ℰ_CURATE = ℰ_FLUID × ℰ_collect。

**定义 325（证书 J_CURATE）** J_CURATE = (J_FLUID, ECE_cs, U_sem_before/after, VoD_sum, coverage, provenance_hash, self_data_ratio, consent_flags, curate_ver)。Valid ⇔ Valid(J_FLUID) ∧ ECE_cs ≤ τ_cs ∧ DCG 通过 ∧ 延迟写入成立。

**定义 326（三级保守退避）** 可消解 epi → R69 resolution bonus；U_sem 超阈 / CCG 关闭 / 疑似投毒 → λ = λ_floor(U_ale + U_epi + U_sem)（回合内 U_sem 视同不可约）；默认边界逐指令退化为 R69/R68。安全侧永不弱于前序。

## 2. 关键算法骨架

```python
# IP-264 CSG：常识接地（快速评论家 + 级联慢 oracle，只在常识自己含糊时才问）
class CommonsenseGrounder:
    def __init__(self, critic, oracle, budget):
        self.c_phi, self.O, self.budget = critic, oracle, budget

    def score(self, o, a, s_hat):
        p   = self.c_phi(ground(o), a, s_hat)          # |P| 维谓词概率
        var = self.c_phi.ensemble_var()
        if var > TAU_VAR and self.budget.allow(o.context):
            p = 0.5 * p + 0.5 * self.O.query(ground(o), a, s_hat, o.context)
        pi = calibrated_plausibility(p, o.context)      # 情境条件校准
        return pi, var, p

    def distill(self, curated_pairs):                   # 仅离线；不写实时流
        self.c_phi.fit(curated_pairs, labels=self.O.batch(curated_pairs))

# IP-265 ODD：双通道惊讶四象限 + 三分解（ale / epi / sem）
def decompose3(samples, o, a, s_hat, csg, wm):
    U_ale, U_epi, modes, _ = fluid_decompose(samples, o)   # 继承 R69
    S_wm = -wm.log_prob(s_hat, o, a)
    pi, var, _ = csg.score(o, a, s_hat)
    S_cs = -log(pi)
    quad = quadrant(S_wm, S_cs)                          # Q1..Q4
    U_sem = max(0.0, S_cs - TAU_CS) * float(S_wm < TAU_WM) + BETA * var
    return U_ale, U_epi, U_sem, quad, modes

# IP-266 DVA：决策相关数据价值（不是全参数似然）
def data_value(d, post, decision_risk, cost):
    r_before = expected_risk(post, decision_risk)
    r_after  = expected_risk(posterior_update(post, d), decision_risk)
    return max(0.0, r_before - r_after) / cost(d)

# IP-267 ARC：稀有事件采集（贪心 + 背景配额 + 情境分层）
def acquire(candidates, quad, U_sem, budget, context):
    if not (quad == 'Q3' or U_sem > TAU_SEM or budget.audit_request):
        return []
    cand  = [d for d in candidates if provenance_ok(d)]
    chosen = []
    while budget.remaining() and cand:
        d = max(cand, key=lambda x: marginal_gain(chosen + [x]) / x.cost)
        chosen.append(d); cand.remove(d)                 # 子模贪心 (1-1/e)
    chosen += background_sample(rate=rho_bg)             # 抵消惊讶采样偏置
    return stratify_by_context(chosen, quota=context_quota)  # 防偏见放大

# IP-269 DCG：数据策展门（投毒 / 自采比 / 同意 / 留出真值）
def curation_gate(batch):
    if not provenance_ok(batch):                 return None
    if self_data_ratio(batch) > ALPHA_MAX:       return None
    if not consent_and_privacy_ok(batch):        return None
    if not poison_filter(batch):                 return None
    return batch.debias_with_ips_weights()       # 逆概率加权去选择偏置

# IP-274 主闭环（继承 R69，仅在实时侧加「常识保守通道」与异步采集）
def CURATE_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)      # R68
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4                    # R69
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    # 1) 常识独立通道：模型再自信也会被它质疑
    pi, var, _ = M.csg.score(o, M.last_action, M.last_wm_pred)
    S_wm = -M.wm.log_prob(M.last_wm_pred, o, M.last_action); S_cs = -log(pi)
    quad = quadrant(S_wm, S_cs)
    U_sem = max(0.0, S_cs - TAU_CS) * float(S_wm < TAU_WM) + BETA * var
    sem_alarm = (quad == 'Q3') or (U_sem > TAU_SEM)
    # 2) R69 交互（只处理已表示歧义）
    g = (M.mint.choose_interaction(modes, o, M.budget)
         if (U_epi > TAU_EPI and not sem_alarm) else None)
    U_epi_after = M.cia.update_belief(modes, M.cia.execute(g)) if g else U_epi
    # 3) 三级退避：U_sem 回合内不可约 → 保守；采集仅异步提交（延迟写入）
    U_floor = U_ale + (0.0 if g else U_epi_after) + (U_sem if sem_alarm else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if sem_alarm: lam = max(lam, LAM_SEM)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    if sem_alarm:
        M.arc.submit_async(o, M.last_action, M.last_wm_pred, quad, U_sem)  # 不写实时流
    mode = select_mode(modes, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_d.submit_async(quad, U_sem, g, lam)
    return k, lam, mode, (U_ale, U_epi_after, U_sem)

# 离线（不在实时环内）：采集 → 策展 → 审计 → 蒸馏 / 概念扩张 → 版本化回滚点
def CURATE_offline(M, stream_batch):
    S = M.arc.select(stream_batch)
    S = curation_gate(S)
    if S is None: return
    M.csg.distill(S)                    # oracle 标注分歧样本 → 快速评论家
    M.ontology.expand(S.new_predicates())  # 概念扩张，版本化
    M.vqa_d.audit(S); M.cert.bump(curate_ver='v+1')
```

## 3. 推导

**假设 A99**（覆盖函数 sim 有界、边际递减）；**A100**（常识对稀有事件的召回 r_cs > 0，且有可测误报率 f）；**A101**（延迟写入 + 证书版本化 + 可回滚）。

**引理 19（常识触发采样的稀有事件样本效率）** 稀有事件基率 ε，常识触发召回 r_cs、误报 f，则达到同一检出置信所需样本比 N_cs/N_rand ≈ [ε + (1−ε)f] / (ε·r_cs)（重要性采样的富集比）。当 r_cs > f 时 N_cs < N_rand，增益约 1/r_cs。系：**常识的价值不在「准」，而在「相对随机采样把稀有事件富集了多少」**；若 r_cs ≤ f，常识采集还不如随机——所以必须先测 r_cs（E301），而不是假设它有用。

**引理 20（数据选择子模贪心界）** 在定义 317 / A99 下，G 单调子模，贪心 S_g 满足 G(S_g) ≥ (1−1/e)·G(S*)；覆盖项使长尾不被 VoD 头部垄断。系：数据价值可离线批量计算，不占实时预算；「该采什么」是一个可证明的近似优化问题，而非拍脑袋。

**引理 21（反馈坍塌上界）** 设每轮训练中自采数据比例 α，若来源门失效且无留出真值，稀有事件率估计按 ε̂_{t+1} = (1−α)ε* + α·ε̂_t 递归——均值收敛但**方差按 1/(1−α) 放大**，且概念覆盖单调收缩（mode collapse）。取 α ≤ α_max 且强制人类/物理留出比例 ≥ 1−α_max，则偏差与覆盖损失 ≤ O(α_max/(1−α_max))。系：α_max 是「学习速度 vs 自我中毒」的硬旋钮，不能由模型自己调。

**引理 22（常识门控的偏见放大）** 若常识在情境群组 g 上的错误率差为 Δ_cs(g)，且采集预算按 S_cs 分配，则群体表示差距满足 d_{t+1}(g) ≥ (1 + Δ_cs(g)·B_t)·d_t(g)；除非采用上下文分层配额 q_g ∝ 基率。系：**用未校准的常识分配采集预算，会把数据偏置写进权重**——这不是隐私问题，而是安全问题：某些群体会永远落在「常识别扭」的盲区里。

**定理 18（CURATE 严格包含 R69/R68）** 当 S_cs ≤ τ_cs、U_sem ≤ τ_sem、CCG 关闭或 α_max = 0 时，CURATE 的实时指令与 R69 逐条相同；否则仅通过 λ 增大与「触发离线采集」改变行为，安全侧不弱于 R69。故 R69/R68 是「无常识信号、无采集预算」的边界，CURATE 是其严格泛化。

**定理 19（数据路径与实时安全解耦）** 在延迟写入（定义 319）下，采集 / 蒸馏 / 概念扩张均不改变当前回合权重与动作；离线更新经 DCG 与证书版本化、可回滚 ⇒ 控制连续、无突变；回合内 U_sem 视为不可约 ⇒ λ 关于不确定性单调不降。

## 6. 本轮最大风险

**一句话**：CURATE 全部的安全性押在「常识先验既信息丰富又足够校准」上——但常识是**有偏的镜子**：一旦它在某些情境/群体上系统性出错，惊讶驱动的采集就会只朝它指的方向看、只采回能强化它的证据，系统于是**永远发现不了常识想象不到的未知**（它本想抓的 unknown unknowns），反而把「自信的错」训练成「有数据背书的错」——**用数据给自己的偏见盖章，比 R69 的「问错」更危险，因为它会一直错下去**。

**次级风险与缓解**：
1. **偏见放大 / 回音室** → 上下文分层配额 + 背景采样 + 逆概率加权 + 引理 22 监控（E307/E313）；
2. **反馈坍塌 / 自采中毒** → 自采比 α_max 硬上限 + 人类/物理留出真值 + DCG（引理 21，E309）；
3. **常识校准失效** → CCG 门控，ECE_cs 越界即只允许「提议 + oracle 复核」，不许单独触发高成本采集（E306）；
4. **投毒演示** → 来源追踪 + 投毒过滤 + k 源一致（继承 R69 引理 18，E308）；
5. **隐私与同意** → 默认不采集可识别信息，脱敏与同意标记进入 J_CURATE（E315）；
6. **实时预算** → 快速评论家复用 trunk、oracle 级联、采集全异步（定理 19）。

# IP-264 CSG：常识接地（快速评论家 + 级联 oracle）
class CommonsenseGrounder:
    def score(self, o, a, s_hat):
        p, var = self.c_phi(ground(o), a, s_hat), self.c_phi.ensemble_var()
        if var > TAU_VAR and self.budget.allow(o.context):
            p = 0.5*p + 0.5*self.O.query(ground(o), a, s_hat, o.context)
        return calibrated_plausibility(p, o.context), var      # (pi_cs, Var_cs)

    def distill(self, curated_pairs):                          # 仅离线
        self.c_phi.fit(curated_pairs, labels=self.O.batch(curated_pairs))

# IP-265 ODD：四象限 + 三分解
def decompose3(samples, o, a, s_hat, csg, wm):
    U_ale, U_epi, modes, _ = fluid_decompose(samples, o)       # 继承 R69
    S_wm = -wm.log_prob(s_hat, o, a)
    pi, var = csg.score(o, a, s_hat); S_cs = -log(pi)
    quad  = quadrant(S_wm, S_cs)                               # Q1..Q4
    U_sem = max(0.0, S_cs - TAU_CS) * float(S_wm < TAU_WM) + BETA*var
    return U_ale, U_epi, U_sem, quad, modes

# IP-266 DVA：决策相关数据价值
def data_value(d, post, decision_risk, cost):
    return max(0.0, expected_risk(post, decision_risk)
                    - expected_risk(posterior_update(post, d), decision_risk)) / cost(d)

# IP-267 ARC：子模贪心 + 背景配额 + 情境分层
def acquire(candidates, quad, U_sem, budget):
    if not (quad == 'Q3' or U_sem > TAU_SEM or budget.audit_request): return []
    cand, chosen = [d for d in candidates if provenance_ok(d)], []
    while budget.remaining() and cand:
        d = max(cand, key=lambda x: marginal_gain(chosen+[x]) / x.cost)
        chosen.append(d); cand.remove(d)                       # (1-1/e)
    chosen += background_sample(rate=rho_bg)                   # 去选择偏置
    return stratify_by_context(chosen, quota=context_quota)    # 防偏见放大

            and self_data_ratio(batch) <= ALPHA_MAX and poison_filter(batch)):
        return None
    return batch.debias_with_ips_weights()

## 4. 推导

**引理 19（常识触发采样的稀有事件效率）** 基率 ε、常识召回 r_cs、误报 f 时，`N_cs/N_rand ≈ [ε+(1−ε)f]/(ε·r_cs)`；仅当 `r_cs > f` 时优于随机，增益约 `1/r_cs`。系：常识的价值是「富集比」，不是「准确率」，必须先测 r_cs。

**引理 20（数据选择子模贪心界）** A99 下 `G` 单调子模 ⇒ 贪心 `G(S_g) ≥ (1−1/e)G(S*)`；覆盖项保护长尾不被 VoD 头部垄断。系：「采什么」是可证明的近似优化，且离线计算，不占实时预算。

**引理 21（反馈坍塌上界）** 自采比 α、无留出真值时 `ε̂_{t+1}=(1−α)ε*+αε̂_t`：均值收敛但方差放大 `1/(1−α)`，概念覆盖单调收缩；取 `α≤α_max` 且人类/物理留出 `≥1−α_max`，偏差与覆盖损失 `≤O(α_max/(1−α_max))`。系：α_max 是「学习速度 vs 自我中毒」硬旋钮。

**引理 22（常识门控的偏见放大）** 常识在群组 g 上错误率差 `Δ_cs(g)`、按 S_cs 分配预算时 `d_{t+1}(g) ≥ (1+Δ_cs(g)B_t)d_t(g)`；除非上下文分层配额 `q_g∝基率`。系：未校准常识分配采集预算 = 把偏见写进权重（安全问题，非仅隐私）。

**定理 18（CURATE 严格包含 R69/R68）** `S_cs≤τ_cs`、`U_sem≤τ_sem`、CCG 关闭或 `α_max=0` 时实时指令与 R69 逐条相同；否则只经 λ 与「异步采集」改变行为，安全侧不弱于 R69。

**定理 19（数据路径与实时安全解耦）** 延迟写入下采集/蒸馏/概念扩张不改变当前权重与动作；离线更新经 DCG 与证书版本化可回滚 ⇒ 控制连续无突变；回合内 U_sem 不可约 ⇒ λ 单调不降。

## 7. 本轮最大风险

**一句话**：CURATE 的安全性押在「常识先验既信息丰富又足够校准」上——但常识是**有偏的镜子**：一旦它在某些情境/群体上系统性出错，惊讶驱动的采集就只朝它指的方向看、只采回强化它的证据，系统于是**永远发现不了常识想象不到的未知**（它本想抓的 unknown unknowns），反而把「自信的错」训练成「有数据背书的错」——**用数据给自己的偏见盖章，比 R69 的「问错」更危险，因为它会一直错下去**。

**次级风险与缓解**：偏见放大/回音室（上下文分层配额 + 背景采样 + 逆概率加权 + 引理 22，E307/E313）；反馈坍塌/自采中毒（α_max 硬上限 + 人类/物理留出 + DCG，引理 21，E309）；常识校准失效（CCG 只提议 + oracle 复核，E306）；投毒演示（来源追踪 + 投毒过滤 + R69 的 k 源一致，E308）；隐私与同意（默认不采可识别信息，脱敏入 J_CURATE，E315）；实时预算（评论家复用 trunk、oracle 级联、采集全异步，定理 19）。
