# 第 44 轮（灵感驱动循环第 1 轮）· Wrist-Flow-Cert × Flow-Cert-Sampler：把手上的相机变成接触级证书传感器，把流匹配策略变成可微证书生成器（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形边际覆盖被欺骗 + 多用户契约空集」，但它仍压着两个未言明的单点假设：**(H1) 证书感知默认在接触处仍由外部全局传感器（LiDAR/外部相机）提供**——接触区的自遮挡、微小间隙、滑移与形变被当作环境噪声，没有独立的接触级证据；**(H2) 流匹配只是执行器，生成与认证分离**——先采样再拒绝/接受，认证只看数值积分误差，不看生成分布是否在支撑内、也不看采样过程能否被约束引导。本轮灵感词「腕部相机」「流匹配策略」精确命中这两个假设：**腕部相机**是唯一贴着接触点、且自运动完全已知的传感器，能把「已知自运动」变成免费参考信号，用视觉流残差给出接触级证书；**流匹配策略**的 ODE 是可微程序，能同时提供密度、支撑、约束梯度与时间重参数化，使认证从「生成后」前移到「生成中」。二者耦合处出现本轮真正的新问题：**腕部相机最需要工作的快速接触时刻，恰是运动模糊最严重、证书最不可靠的时刻**——这不是工程细节，而是一条「速度-可观测性守恒」，必须用证书感知的时间重参数化正面处理。

## 0. 直觉与动机

**灵感 1（腕部相机 → 接触级证书传感器，自运动是免费参考）**：腕部相机装在末端执行器上，视场小、贴得近，能看到夹爪—物体界面的滑移、挤压、形变与遮挡，这些是外部全局相机与 LiDAR 都看不见的。直觉上它的自运动是负担；但正因为相机刚体运动由本体感知与动作精确已知，**预期光流可以解析计算**：给定深度与相机 twist，刚性场景的像面流是已知的。于是实际流减去预期流得到的残差，不再是无意义的噪声，而是「接触模型是否成立」的证据：刚性抓取应无残差，滑移会留下与滑移速度成比例的残差，形变会留下非刚体分量，遮挡会留下前后向流不一致。一句话：**眼睛长在手上，所以它知道自己「应该看到什么」，惊讶本身就是信号。** 但必须诚实：沿等照度线方向的滑移处于孔径盲区，因此 WFC 只能做「单向一致性检测」，不能宣称「无残差即无滑移」。

**灵感 2（流匹配策略 → 可微证书生成器，认证前移到生成中）**：v20 的 IP-48 认证的是数值积分误差（L_v、κ、ε_ode、N*），默认生成与认证分离：先采样动作块，再交给下游 CBF/几何证书拒绝。这浪费了流匹配最重要的结构——速度场是可微的。可微带来三件事：**(a) 密度**：若速度场 Lipschitz 且 ODE 流可逆，瞬时变量替换给出 log p(a) 的沿轨迹积分，可构造成证书化下界；**(b) 支撑**：用共形分位数把「低密度」变成分布无关的动作集合，替代拍脑袋阈值；**(c) 梯度**：把 CBF 约束投影到速度场，使采样**在生成时就满足动作空间硬约束**，而不是生成后再拒绝。一句话：**流匹配不是采样器，是可微证书生成器；检查程序，而不是只检查输出。** 注意一个陷阱：投影改变了速度场，密度证书必须沿**投影后的**流重新积分散度，否则证书对象错位。

**灵感 3（耦合 → 双流一致性 + 速度-可观测性守恒）**：流匹配给出动作块，动作块经运动学与场景模型给出**预期腕部光流**；腕部相机给出**实测光流**；二者的残差把「策略—本体—接触」三者绑成一条可在线检验的链。这条链的最大张力是：腕部相机最需要在快速接触时工作，而运动模糊随速度增长，高速时残差噪声最大、可观测性最差；流匹配越快，这个矛盾越尖锐。因此本轮不把速度当外部给定，而把**执行时序当作证书变量**：流匹配给出几何路径，按腕部相机的可观测性上限对接触段做时间重参数化（放慢但不改路径），并在需要时用暖启动流匹配做 C1 连续重规划。一句话：**不能让证书在最危险的接触瞬间最自信。**

**耦合升级**：WFC（腕部流证书）把接触级证据送进 CAR 守卫；FCS（流证书采样器）把密度、支撑、CBF 投影与时间重参数化编进 IP-48；FCV（流接触验证器）在仿真里注入滑移、模糊、无纹理、标定漂移与自遮挡，把反例回灌 CKB 与 SCV。四层架构由 v8 的「人格契约 + 并发证书」升级为 v9 的「人格契约 + 并发证书 + 接触级双流证书」。

## 1. 形式化定义（增量：定义 44–50）

**定义 44（腕部视觉-运动学流模型）**：腕部相机与末端执行器外参 T_CE、内参 K 已知。像素 u 处实测光流为 ω_t(u)∈R²，深度 d_t(u) 由腕部深度/RGB-D 给出，相机 twist ξ_t=(v_t,ω_t) 由本体感知与动作给定。刚性场景下的**预期光流** ω̂_t(u)=J_flow(u,d_t(u))·ξ_t，其中 J_flow 为像面雅可比。若物体以相对 twist Δξ_t 运动（滑移）或发生非刚体形变，则残差 r_t(u)=ω_t(u)−ω̂_t(u)−ω_def(u)，ω_def 为形变/接触模型项（刚性抓取取 0，可形变物体用学习模型或上界）。可靠像素掩码 M_t 由前后向流一致性、光度残差与深度有效性共同给出。

**定义 45（腕部流残差证书 WFC 与检出力）**：归一化残差 ρ_t²=(1/|M_t|)Σ_{u∈M_t} r_t(u)^TΣ_t(u)^{-1}r_t(u)。WFC 有效当且仅当 (i) ρ_t≤ε_ρ，其中 ε_ρ=sqrt(χ²_{2|M_t|}(1−δ)/|M_t|) 由噪声协方差与置信度 δ 给出；(ii) 覆盖率 |M_t|/|Ω|≥ν；(iii) 标定自检通过。**接触裕度** m_wfc=ε_ρ−ρ_t。**检出力命题**：对滑移引起的流偏 δω，若其在图像梯度法向的可观测投影满足 ‖P_obs δω‖_{Σ^{-1}}≥ε_ρ+z_{1−β}/sqrt(|M_t|)，则以至少 1−β 的概率被检出；其中 P_obs=I−gg^T/‖g‖²，g 为图像梯度。**盲区声明**：沿等照度线方向的滑移不可观测（孔径问题），故 WFC 只能作为**单向一致性证据与降级触发器**，绝不可作为「无滑移」的安全证明。**使用原则（刷新不扩张）**：WFC 只允许刷新已有全局证书的租约，守卫 margin 取 m←min(m_global,m_wfc)；任何扩张仍须走 v20 定义 39 的三重闸门。

**定义 46（流匹配的可微密度证书与共形支撑）**：流匹配 ODE 为 dx/ds=v_θ(x,s;c)，x(0)~p_0，x(1)~p_1（动作块 a=x(1)）。若 v_θ 全局 Lipschitz 且 ODE 流映射为微分同胚，则 log p_1(a)=log p_0(x_0)−∫_0^1 ∇·v_θ(x_s,s)ds。**证书化下界** log p_lo(a)=log p_0(x_0)−D̂−ε_div，D̂ 为散度积分的数值估计（动作维不高时用 d 次 JVP 精确求迹；高维时用 Hutchinson 并以次高斯集中不等式给 ε_div），ε_div 同时含积分器误差与估计误差。**共形支撑**：在按接触相位（Mondrian）分层的校准集上取非一致性分数 s_i=−log p_lo(a_i)，阈值为 q=⌈(n+1)(1−α)⌉/n 经验分位，A_α={a:−log p_lo(a)≤q}；在分层内可交换性下 P(a∈A_α)≥1−α。**安全候选集** = A_α∩C_global∩Π_u∩{h≥0}；空集则协商或安全停机。

**定义 47（证书引导的流采样 CGFS）**：设动作块空间上可微约束 h(a)≥0（关节限位、预测自碰撞、接触力上界等）。每个 ODE 步用最小范数修正把速度投影到 CBF 可行方向：v_proj=v−ReLU(−(∇h·v+γh))/‖∇h‖²·∇h；多约束用 QP。**投影密度一致性**：密度证书必须沿 v_proj 重新积分散度，即 log p_1^proj(a)=log p_0(x_0)−∫∇·v_proj ds；否则证书描述的是未投影分布，对象错位。**离散保持命题**：若 h(a_0)≥0、步长 η 满足离散 CBF 条件 h(a_{k+1})≥(1−γη)h(a_k)，则投影采样的整条动作块满足 h≥0。**范围声明**：该命题认证的是**动作空间硬约束**（生成时即满足）；任务空间安全仍由下游 CAR/几何证书在闭环中认证，二者不可互相替代。

**定义 48（运动模糊、证书有效期与速度-可观测性守恒）**：曝光 t_exp、像面速度 s=‖v_cam‖ 下，模糊长度约 b=s·t_exp，光流噪声协方差近似 Σ_t=Σ_0+(b²/12)·I（含离焦项则为上界）。因此 ε_ρ 随 s 单调增。定义**证书速度上限** v_cert=max{s:ε_ρ(s)≤ε_max∧覆盖率≥ν}；当 s>v_cert 时 WFC 租约强制失效，不得用于守卫。**证书感知时间重参数化**：设流匹配给出几何路径 a(τ)，执行时刻 t 满足 dt/dτ=σ(τ)>0，则执行速度按 1/σ 缩放。取 σ(τ)=min(1, v_cert/‖da/dτ‖) 可在接触段自动放慢而**不改变几何路径**，故路径上的 CBF/几何裕度不变；但必须另证速度/力矩/加速度可行性与任务时序 SLA。**守恒命题（非正式）**：不存在同时最大化执行速度与腕部可观测性的无约束解；证书感知调度的本质是在 v_cert 约束下重分配时间。

**定义 49（暖启动流匹配与原子化交接）**：重规划时用 p_0=N(a_prev,σ_w²I) 替代标准高斯先验（暖启动），使新 ODE 从当前动作附近出发，降低积分步数并保持连续性；暖启动流的密度仍按定义 46 沿其自身速度场认证。**交接不变式**：在切换时刻 t*，若旧计划与新计划均满足 C_u∩Π_u，且 ‖a_old(t*)−a_new(t*)‖≤δ_h，且 δ_h 小于当前守卫裕度，则直接切换不新增违例；否则在重叠窗内做**经认证的凸插值**（仅当安全集沿插值路径连通时），并在执行前完成新计划证书，禁止「先切后证」。**定理（原子交接）**：若切换只在新证书就绪后发生、且交接点满足上述不变式，则任意切换点的证书不变式保持。

**定义 50（接触可观测性与主动视点选择）**：令接触参数 θ_c（滑移速度、接触点、摩擦锥裕度等），残差 r=∂r/∂θ_c·θ_c+noise，Fisher 信息 F=Σ_{u∈M_t}J_r(u)^TΣ_t(u)^{-1}J_r(u)，定义可观测性 obs=λ_min(F)。主动视点问题：在 C_u∩Π_u 与任务进度约束下选择臂位姿/分支，使 obs 最大。**与投机分支的接口**：IP-58 的分支评分由 score(β) 升级为 score(β)+λ_obs·obs(β)，仅在任务收益不下降超过 ε_task 时启用，防止为了看清楚而牺牲任务。**命题（可观测性下界）**：若 obs≥obs_min，则滑移参数的最小可检测幅度随 obs_min^{-1/2} 下降；这是 E95 盲区实验的理论依据。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 WRIST-FLOW-CERT (WFC)：腕部流证书
1. **自运动补偿**：本体 twist + 深度 → 解析预期光流；前后向流一致性 + 光度/深度掩码。
2. **残差证书**：ρ_t、ε_ρ、覆盖率、标定自检；输出接触裕度 m_wfc 与接触事件（滑移/形变/遮挡/标定漂移）分类。
3. **单向使用纪律**：WFC 只能刷新租约、参与 min 守卫，不得扩张安全域；孔径盲区与运动模糊触发时自动失效。
4. **可观测性估计**：在线估计 Fisher 信息与 v_cert，向 FCS 提供速度上限、向投机选择提供 obs 评分。

### 2.2 IP-61 FLOW-CERT-SAMPLER (FCS)：流证书采样器
1. **可微密度证书**：沿（投影后）速度场积分散度，输出 log p_lo 与 ε_div；按接触相位做 Mondrian 共形支撑 A_α。
2. **CBF 引导采样**：每步最小范数投影，生成即满足动作空间硬约束；投影后重算密度，保证证书对象一致。
3. **证书感知时间重参数化**：用 v_cert 对接触段放慢，路径不变；校验速度/力矩/加速度可行性与 SLA。
4. **暖启动连续重规划**：以当前动作为先验中心，降低步数与交接跳变；配合原子交接不变式。

### 2.3 IP-62 FLOW-CONTACT-VALIDATOR (FCV)：流接触验证器
1. **双流一致性仿真**：渲染腕部相机（含运动模糊、镜面、无纹理、自遮挡），注入滑移/形变/标定漂移，检验 WFC 检出力与盲区。
2. **密度/支撑覆盖审计**：按接触相位统计 A_α 的条件覆盖率、投影前后分布偏移、ε_div 紧致性。
3. **速度-可观测性压力测试**：扫描执行速度与曝光，验证 v_cert 边界与时间重参数化的安全/时序曲线。
4. **交接与长时程**：暖启动重规划的交点连续性、原子切换、100h 接触事件回放，反例回灌 CKB/SCV。

## 3. 四层架构 v9

```
L0: 腕部相机驱动(全局快门/频闪) + 硬件光流 + 与本体/动作的硬时间同步
L1: TRI-FUSE(INT8) + IP-49 LIO → C_ms + B_t + 全局几何证书
    腕部流补偿(IP-60) → m_wfc + 接触事件 + v_cert + obs
L2: CTC + VLM + IP-35 仲裁 → R_φ(w) 分支池(b 候选, 并行投机)
    IP-61 FCS：密度 log p_lo / 共形支撑 A_α / CBF 投影 / 时间重参数化
L3: IP-51 CAR(margin=min(查表, 租约, persona, m_wfc)) ← IP-58 CCR(租约表 + RG + 混合关键级)
    → IP-47 RG 接口 + 暖启动交接 → IP-39 规划(CBF margin) → IP-45 总线
    → IP-48+FCS 认证流匹配执行 → IP-53 CMC(最高关键级监控)
L4: IP-57 PCE + IP-55 CKB(含腕部/接触指纹) ← IP-62 FCV(双流/模糊/滑移/交接) + IP-54 SCV
    → IP-44 蒸馏 + IP-50 课程(含模糊/盲区难度) → RCA 重颁 → 契约热更新
运行期：腕部高频流残差 → 刷新接触租约(仅刷新不扩张) → 残差/模糊超限 → 暖启动重规划
        → 新证书就绪后原子交接 → 过载走 HI 模式(砍投机, 保 WFC 与安全监控)
```

## 2. 关键算法（伪代码）

### IP-60 WFC：自运动补偿、残差证书、速度上限与可观测性
```
def wrist_flow_cert(img_prev, img_cur, depth, xi, delta=0.01):
    flow_fwd  = optical_flow(img_prev, img_cur)
    flow_bwd  = optical_flow(img_cur, img_prev)
    M         = consistency_mask(flow_fwd, flow_bwd, depth) & photometric_mask(...)
    omega_hat = image_jacobian(depth) @ xi            # 已知自运动的预期光流
    r         = flow_fwd - omega_hat - deform_model(depth)
    rho       = sqrt(mean_mahalanobis(r[M], Sigma))
    eps_rho   = sqrt(chi2_quantile(2*count(M), 1-delta) / count(M))
    m_wfc     = eps_rho - rho
    valid     = (rho <= eps_rho) and (count(M)/count(Omega) >= nu) and calib_ok()
    event     = classify_contact_event(r, M)          # slip / deform / occl / drift
    return WFC(valid, m_wfc, event, coverage=count(M)/count(Omega))

def cert_speed_limit(sigma0, exposure, eps_max, nu):
    # 模糊长度 b = s*t_exp，噪声协方差随 b^2/12 增长；求满足阈值与覆盖的最大速度
    return max{ s > 0 : eps_rho(s, exposure) <= eps_max and coverage(s) >= nu }

def observability(fisher_jacobians, M):
    F = sum(J(u).T @ inv(Sigma(u)) @ J(u) for u in M)
    return lambda_min(F)                               # 供 FCS/投机评分使用
```
**纪律**：`valid` 只允许 `lease.refresh("wrist")` 与 `guard_margin = min(global, persona, m_wfc)`；任何 `valid` 都不得用于放宽任何全局阈值或扩张 C_u。

### IP-61 FCS：密度、共形支撑、CBF 投影与时间重参数化
```
def certified_density(v_theta, a, cond, num_probes=None):
    x0   = invert_flow(v_theta, a, cond)               # 若流可逆；否则用轨迹重放
    D, e = divergence_integral(v_theta_for_projection, a, cond, num_probes)
    return log_p0(x0) - D - e                          # e 含积分误差 + 估计误差

def conformal_support(calib_scores, alpha):
    q = quantile(calib_scores, ceil((n+1)*(1-alpha))/n) # 分层(接触相位)各算各的
    return lambda a: (-log_p_lo(a) <= q)

def cbf_project(v, h, grad_h, gamma):
    denom = dot(grad_h, grad_h)
    if denom == 0: return v
    violation = -(dot(grad_h, v) + gamma*h)
    return v - (max(0.0, violation)/denom) * grad_h

def flow_cert_sample(v_theta, cond, h, C_u, alpha, v_cert):
    x = prior_sample(cond)                              # 暖启动: N(a_prev, sigma_w^2 I)
    for s in linspace(0, 1, N_star):
        v  = v_theta(x, s, cond)
        v  = cbf_project(v, h(x), grad(h, x), gamma)    # 生成时满足动作空间约束
        x  = integrator_step(x, v, s)                   # 沿投影后流前进
    a = x
    if not in_support(a, alpha): return None            # 共形支撑外 -> 拒绝/重采样
    if not subset(a, intersect(C_u, persona)): return None
    return TimeParam(a, sigma=min(1.0, v_cert/||path_speed(a)||)), certified_density(v_theta, a, cond)
```
**注意**：`certified_density` 的散度积分必须使用**投影后**的速度场；否则密度证书描述的是未投影分布，对象错位。

def atomic_handoff(old_plan, new_plan, t_star, margin_slack):

def certificate_aware_timing(path, v_cert, robot_limits):
    sigma = lambda tau: min(1.0, v_cert / max(norm(path.velocity(tau)), eps))
    traj  = reparameterize(path, sigma)
    return traj if feasible_velocity_torque(traj, robot_limits) else slow_down(path)

def select_with_observability(branches, C_global, persona, lam_obs, eps_task):
    cands = [(b, certify_branch(b)) for b in branches]
    cands = [(b,c) for b,c in cands if c.valid and subset(c.admissible, C_global & persona)]
    if not cands: return negotiate_or_safestop()
    base = max(cands, key=lambda bc: score(bc[0]))
    look = max(cands, key=lambda bc: score(bc[0]) + lam_obs*obs(bc[0]))
    return look if score(look[0]) >= score(base[0]) - eps_task else base

| 局部深度与外参误差反而放大接触级误差 | 中 | 外参在线自检；局部漂移界与全局求交取保守；E95 标定漂移测试 |

| 时间重参数化破坏节拍/力矩可行性 | 中 | 路径不变 + 单独可行性检查；不可行则整体减速而非改路径 |

## 6. 本轮最大风险

**一句话**：腕部相机的刚性/朗伯/亮度恒定/标定准确假设，恰好在接触处被形变、镜面、自遮挡与运动模糊同时破坏，而流匹配越快这些失效越严重——若把 WFC 当成「新鲜的安全证明」而不是「单向一致性证据」，它就会在本轮最需要保守的接触瞬间把陈旧租约洗成新鲜，制造静默不安全；因此 E95（检出力/盲区）与 E97（超速必失效）必须设为红线，且默认永远保留「全局几何证书 + 串行安全监控」这条不依赖腕部相机的底线。
