## 0. 直觉与动机

**灵感 1（上下文理解 → 情境是许可推理的粗粒化，而非又一路传感器）**
直觉：v23 的证书是"情境盲"的。同一几何构型，在"医院走廊急救""仓库交接""夜间厨房"里被签发同一张证书；可人站在那里，可能是在等待交接、可能是在挡路、也可能跌倒了需要帮助。上下文理解要补的不是再挂一个传感器，而是推断**潜在情境类型 c**，由它决定三件事：(a) 哪些规范适用（DCL 规则选择）；(b) 人下一步可能做什么（意图先验）；(c) 哪些证据此刻相关（注意/显著性）。反直觉点：**上下文的价值不在"信息量"，而在"它是可能世界空间的一个划分（partition）"——一个好的情境必须同时满足可辨识（有界误差）、规范可分辨（不同情境导出不同可执行集）、且在规划时域内稳定（不抖动）**。于是把情境形式化为带偏序 ⊑ 的粗粒化，用 conformal 情境集 Γ_c 给出 ≥1-α_c 覆盖；**歧义时取交集（保守），只有 Γ_c 收缩为单点且稳定驻留时才允许"花掉"特异性**。这与 v21 的 AbsCert 同构：AbsCert 赎回自由空间，SCC 赎回"情境不确定性保证金"。

**灵感 2（人机交互 → 人的心智模型是受控对象的一部分）**
直觉：v23 把"人"当障碍物或规范对象，但 HCI 的基本事实是：**人依据对机器人的信念行动，而非机器人的真实状态**。机器人安全但"出人意料"时，人会因误判而走进危险（机器人突然倒车，人以为它要继续前进）。同时交互是**混合主动（mixed-initiative）**的：人可提议、打断、接管。于是安全必须包含两件事：**可读性/可解释性（legibility）**——人能在预测时域内推断机器人意图；**交接安全（handover safety）**——接管请求后有限时间内系统可进入安全态。反直觉点：**可读性不是 UX 装饰，而是可执行集上的一个约束**：若计划在人预测时域内不可读，人最可能的反应会破坏安全裕度；故把"人的反应分布"写进安全约束，取最坏反应（或 CVaR）下的联合安全。更进一步，**可读性通过降低人的反应不确定性，反过来"赎回"一部分人-机安全裕度 δ_h**——这是 HCI 侧与 AbsCert 同构的赎回机制。

**二者如何统一**
统一为 **v23 之上的"情境-交互"层（SIL）**：SCC 回答"此刻是哪种情境、我有多确定"；CCNR 把情境编译为规范细化（歧义→交集，确定→细化）；CGC/LRC 回答"人和我对情境/意图的共同基础够不够、我的计划可不可读"；MIHC 回答"若要接管/打断，是否仍在安全回手集内"。共享状态 ζ_ce 扩展为 **ζ_sil = ζ_ce ∪ (Γ_c, dwell_c, b_h, g_t, L_t, H_safe, mi_state)**。统一准入门 **HPC-E++ = (HPC-E, CESC, FSVC, IPAttest, SCC∧CGC∧LRC∧MIHC) 五证一体**；任一缺失即退回 v23 的情境盲保守默认。安全不变量升级为：**几何执行集永不放大（Geo_v24 = Geo_v23）；SIL 只赎回 v23 显式预留的"情境/人反应保证金"，且赎回量有显式上界**；失效时 `Exec_v24^fail ⊆ Exec_v23 ⊆ Exec_v22 ⊆ …`。

## 2. 设计原则（在 P37–P42 基础上新增 P43–P46）

**P43 情境粗粒化律（Context Coarsening）**
情境空间 C 是可能世界的一个划分，带特异性偏序 ⊑。可执行集在情境歧义下取**交集**：`A_ctx(h_t) = ⋂_{c∈Γ_c(h_t)} A(c)`；仅当 `Γ_c` 为单点、覆盖 ≥1-α_c 且驻留 `dwell ≥ T_ctx` 时，才允许细化为 `A(c*)`。情境切换只在计划边界或重新认证后发生；`Γ_c` 失效即回退情境盲默认 `A_⊥ = ⋂_{c∈C} A(c)`（即 v23 默认）。故情境层只可能"有条件地赎回"它自己预留的保证金，几何执行集不变。

**P44 共同基础可赎回律（Common Ground Redemption）**
共同基础只赎回**有界**的人-反应保证金：`δ_h^cg = max(δ_h^min, δ_h^worst - κ·I_t(b_h;b_r))`，其中 `I_t` 为互信息、`δ_h^min` 为几何地板。赎回立即生效、立即撤销：一旦检测到"惊讶"（人反应与预测分布的总变差 > τ_surprise）或 `g_t < g_min`，立刻回到 `δ_h^worst` 并重规划。CGC 失效 ⇒ 不赎回 ⇒ `⊆ Exec_v23`。

**P45 可读性即约束律（Legibility-as-Constraint）**
有人在共享区时，可读性是**硬约束**：`L(π) = -log P_h(goal(π)|π) ≤ H_max`，且信号满足 Gricean manner 上界 `H(σ) ≤ H_sig`；无人在场时退化为软目标。可读性约束只收缩计划集；它通过降低人的反应熵来**单调地**缩小 `δ_h^cg`，绝不放大几何域。不可读的计划宁可换一条可读的，也不靠"更快/更响"去补偿。

**P46 混合主动交接律（Mixed-Initiative Handover）**
人的主动（急停、拉拽、语音停止）具有最高优先级，机器人不得以任何证书覆盖。机器人发起的交接/接管必须从安全回手集 `H_safe(θ)` 内发起，且存在 ≤ `T_ho` 的安全停止/交还路径；`H_safe` 是 v23 几何/能量证书下的受控不变集。协商状态机 `mi_state ∈ {ROBOT, HUMAN, NEGOTIATE, SAFE_STOP}` 必须无静默死锁：协商超时 → SAFE_STOP + 可读解释；冲突消解取"人优先 + 最保守"。

## 3. 与基线的接口（如何退化）

- SCC 失效（情境集为空/覆盖不足/抖动）⇒ 回退 `A_⊥`（情境盲 v23 默认）⇒ `⊆ v23`；
- CCNR 失效（规则库或情境映射崩溃）⇒ 不细化，只保留情境不变规则 ⇒ `⊆ v23`；
- CGC 失效（共同基础不足/惊讶检测触发）⇒ 不赎回，`δ_h = δ_h^worst` ⇒ `⊆ v23`；
- LRC 失效（无可读计划/信号不可解释）⇒ 换可读计划或降速/停止，不放大 ⇒ `⊆ v23`；
- MIHC 失效（不在 H_safe/接管超时）⇒ 立即安全停止并交还，禁止自主交互 ⇒ `⊆ v23`；
- 全部失效 ⇒ 完全回退 v23 ⇒ `Exec_v24^fail ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`。
- **安全继承**：SIL 只赎回 v23 预留的保证金且赎回量有界、可撤销；几何/能量/云边/IP 四层证书完全不动。任何失效都向更保守方向退化，且 `Geo_v24 = Geo_v23`。

## 4. 预期贡献

1. **情境即粗粒化**：首次把"上下文理解"形式化为带偏序的规范可分辨划分 + conformal 情境集，给出"歧义取交、单点细化、稳定才花"的保守推理协议；
2. **共同基础证书**：把人的心智模型纳入受控对象，给出 g_t 的 conformal 估计与"有界、可撤销"的人-反应保证金赎回，使 HCI 的可读性从 UX 指标升级为安全约束；
3. **可读性即约束**：给出 `L(π) ≤ H_max` 的硬约束与 Gricean manner 界，证明它只收缩计划集并单调降低人-反应熵；
4. **混合主动交接证书**：在 v23 证书上定义安全回手集 H_safe 与接管时延界 T_ho，给出人优先、无静默死锁的协商状态机；

6. **封堵交互侧同构风险**：用惊讶检测 + 撤销机制 + 独立证据，防止"共同基础幻觉"把安全押在错误的人模型上。

## 5. 本轮最大风险

**一句话**：CGC/LRC 依赖的人反应模型 `P_h` 与共同基础估计 `g_t` 本身就是从有限、带文化/个体偏差的数据里学出来的；若模型对某类人（儿童、听障、恐慌、非母语、恶意）系统性失真，机器人会拿到一张"可读且共同基础充分"的**假证书**，赎回本不该赎回的人-反应保证金——即"共同基础幻觉"：它比 v23 的"缺席幻觉"更隐蔽，因为它借"交互"之名把对人的错误假设写进了安全裕度。

## 1. 关键算法骨架（在 IP-431–439 骨架上扩展）

```python
# ============================================================
# IP-440 Situated Context Certificate (SCC) — 情境证书
# ============================================================
@dataclass(frozen=True)
class ContextCertificate:
    Gamma_c: frozenset          # conformal 情境集
    posterior: dict             # 归一化情境后验
    alpha_c: float
    dwell: float                # 模态情境连续驻留时长
    t_stamp: float

    def coverage_ok(self) -> bool:
        return sum(self.posterior[c] for c in self.Gamma_c) >= 1.0 - self.alpha_c

    def stable(self, T_ctx: float) -> bool:
        return self.dwell >= T_ctx

    def singleton(self) -> bool:
        return len(self.Gamma_c) == 1

    def modal(self) -> str:
        return max(self.Gamma_c, key=lambda c: self.posterior[c])


class SituatedContextEstimator:
    """conformal 情境估计：非一致性分数 + 分位数 → 情境集；带驻留滞回。"""
    def __init__(self, context_model, calibrator, alpha_c=0.05, T_ctx=1.5):
        self.model = context_model
        self.calibrator = calibrator
        self.alpha_c = alpha_c
        self.T_ctx = T_ctx
        self._modal_run_start = None
        self._last_modal = None

    def update(self, h_t) -> ContextCertificate:
        scores = self.model.nonconformity(h_t)          # {c: s_c}
        q = self.calibrator.quantile(self.alpha_c)      # 校准分位数
        Gamma = frozenset(c for c, s in scores.items() if s <= q)
        if not Gamma:                                   # 空集 → 全情境（最保守）
            Gamma = frozenset(scores)
        post = normalize({c: -s for c, s in scores.items()})
        modal = max(Gamma, key=lambda c: post[c])
        now = time.now()
        if modal != self._last_modal:                   # 模态切换 → 重置驻留
            self._modal_run_start = now
            self._last_modal = modal
        dwell = now - (self._modal_run_start or now)
        return ContextCertificate(Gamma, post, self.alpha_c, dwell, now)


# ============================================================
# IP-444 Context-Conditioned Norm Refinement (CCNR) — 规范细化
# ============================================================
class ContextConditionedNorms:
    """把情境编译为 DCL 规则子集；歧义取交，单点且稳定才细化。"""
    def __init__(self, rule_db, T_ctx=1.5):
        self.rule_db = rule_db
        self.T_ctx = T_ctx

    def admissible(self, plan, ctx: Optional[ContextCertificate]) -> bool:
        if ctx is None or not ctx.coverage_ok():
            return self.rule_db.admits_all_contexts(plan)      # A_⊥ = v23 默认
        if ctx.singleton() and ctx.stable(self.T_ctx):
            return self.rule_db.admits(plan, ctx.modal())      # 认证细化
        return all(self.rule_db.admits(plan, c) for c in ctx.Gamma_c)  # 歧义取交

    def redeem_region(self, ctx) -> set:
        """返回相对 A_⊥ 的赎回集，仅用于审计；不得触碰几何域。"""
        if not (ctx and ctx.singleton() and ctx.stable(self.T_ctx)):
            return set()
        return self.rule_db.diff_region(ctx.modal())           # 只读，供 SET 记录


# ============================================================
# IP-441 Common Ground Certificate (CGC) — 共同基础证书
# ============================================================
class HumanResponseModel:
    """P_h(a_h | π, b_h, c)；由交互日志学习，conformal 校准。"""
    def __init__(self, predictor, calibrator, alpha_h=0.01):
        self.predictor = predictor
        self.calibrator = calibrator
        self.alpha_h = alpha_h

    def distribution(self, plan, b_h, c=None):
        return self.predictor.softmax(plan, b_h, c)

    def cvar_safety(self, plan, dist, alpha):
        """最坏 (1-alpha) 尾部的人-反应联合安全裕度。"""
        vals = sorted(self.predictor.safety_margin(plan, a_h) for a_h in dist)
        k = max(1, int(math.ceil(alpha * len(vals))))
        return sum(vals[:k]) / k

    def surprise(self, observed_response, predicted_dist):
        return total_variation(observed_response, predicted_dist)


class CommonGroundCertificate:
    def __init__(self, response_model, g_min=0.8, delta_worst=0.5,
                 delta_min=0.05, kappa=0.3, tau_surprise=0.3, alpha_h=0.01):
        self.response_model = response_model
        self.g_min = g_min
        self.delta_worst = delta_worst
        self.delta_min = delta_min
        self.kappa = kappa
        self.tau_surprise = tau_surprise
        self.alpha_h = alpha_h

    def mutual_information(self, b_h, b_r):
        return max(0.0, entropy(b_h) - conditional_entropy(b_h, b_r))

    def redeemed_margin(self, b_h, b_r) -> float:
        I = self.mutual_information(b_h, b_r)
        return max(self.delta_min, self.delta_worst - self.kappa * I)

    def certify(self, plan, b_h, b_r, geo_clearance):
        g = 1.0 - total_variation(b_h, b_r)
        if g < self.g_min:
            return False, self.delta_worst
        dist = self.response_model.distribution(plan, b_h)
        if self.response_model.cvar_safety(plan, dist, self.alpha_h) < 0:
            return False, self.delta_worst
        delta = self.redeemed_margin(b_h, b_r)
        if geo_clearance < delta:                 # 赎回不得越过几何地板
            return False, self.delta_worst
        return True, delta

    def revoke_if_surprised(self, observed, predicted) -> bool:
        return self.response_model.surprise(observed, predicted) > self.tau_surprise


# ============================================================
# IP-442 Legibility–Readability Certificate (LRC) — 可读性证书
# ============================================================
class LegibilityCertificate:
    def __init__(self, human_model, H_max=1.0, H_sig=1.0, horizon=2.0):
        self.human_model = human_model
        self.H_max = H_max
        self.H_sig = H_sig
        self.horizon = horizon

    def legibility(self, plan) -> float:
        p = self.human_model.infer_goal_prob(plan.goal, plan, horizon=self.horizon)
        return -math.log(p + 1e-12)

    def admits(self, plan, signal, humans_present: bool) -> bool:
        if not humans_present:                    # 无人在场退化为软目标
            return True
        return (self.legibility(plan) <= self.H_max
                and self.human_model.signal_entropy(signal) <= self.H_sig)

    def repair(self, plan, alternatives):
        """从备选计划中选可读性最小且仍安全的替代；无解则返回 None。"""
        ok = [p for p in alternatives if self.legibility(p) <= self.H_max]
        return min(ok, key=self.legibility) if ok else None

# IP-443 Mixed-Initiative Handover Certificate (MIHC) — 交接证书
# ============================================================
class MixedInitiativeHandover:
    def __init__(self, geo_cert, dynamics, T_ho=0.5, dt=0.02):
        self.geo_cert = geo_cert
        self.dynamics = dynamics
        self.T_ho = T_ho
        self.dt = dt
        self.H_safe = self.safe_handback_set()

    def safe_handback_set(self):
        """受控不变集：存在 ≤T_ho 的安全停止/交还路径。"""
        return backward_reachable_safe_set(
            self.geo_cert, self.dynamics, horizon=int(self.T_ho / self.dt))

    def admit(self, state, mi_state, human_estop: bool) -> bool:
        if human_estop:
            return False                    # 人主动最高优先级，机器人让位
        if mi_state == "HUMAN":
            return True                     # 机器人只做辅助/制动
        if mi_state == "ROBOT":
            return state in self.H_safe
        if mi_state == "NEGOTIATE":
            return state in self.H_safe and self._no_deadlock(state)
        return mi_state == "SAFE_STOP"

    def _no_deadlock(self, state) -> bool:
        """协商超时即转 SAFE_STOP，避免双向礼让死锁。"""
        return self.negotiation_elapsed < self.T_ho

class SituatedExplanationTrace:

# ============================================================
# IP-445 HPC-E++ / Situated Interaction Gate (SIG) — 五证准入门
# ============================================================
@dataclass
class HPCEPlusPlus:
    hpc_e_plus: HPCEPlus
    scc: SituatedContextEstimator
    ccnr: ContextConditionedNorms
    cgc: CommonGroundCertificate
    lrc: LegibilityCertificate
    mihc: MixedInitiativeHandover
    trace: SituatedExplanationTrace

    def admits(self, plan, obs, humans_present, b_h, b_r, signal,
               mi_state, human_estop, modules):
        # 1) v23 基础四证：物理-规范-云边-少样本-IP
        if not self.hpc_e_plus.admits(plan, obs.x, obs.v, obs.z,
                                      obs.E_res, obs.margin_req, modules):
            return False

        # 2) 情境 + 规范细化（歧义取交，单点稳定才细化）
        ctx = self.scc.update(obs.history)
        if not self.ccnr.admissible(plan, ctx):
            self.trace.record("REJECT_CTX", obs, ctx, self.cgc.delta_worst, mi_state)
            return False

        # 3) 共同基础 / 可读性（有人在共享区才强制）
        delta = self.cgc.delta_worst
        if humans_present:
            ok, delta = self.cgc.certify(plan, b_h, b_r, obs.geo_clearance)
            if not ok or not self.lrc.admits(plan, signal, humans_present):
                self.trace.record("REJECT_CG", obs, ctx, self.cgc.delta_worst, mi_state)
                return False

        # 4) 混合主动交接（人优先、无静默死锁）
        if not self.mihc.admit(obs.state, mi_state, human_estop):
            self.trace.record("REJECT_MIHC", obs, ctx, delta, mi_state)
            return False

        self.trace.record("ADMIT", obs, ctx, delta, mi_state)
        return True


# ============================================================
# 端到端：v23 流水线 → SIL 五证准入
# ============================================================
class SituatedInteractionPipeline:
    def __init__(self, config: dict):
        self.base = PerceptionComplianceEnergyPipeline(config)   # v23
        self.scc = SituatedContextEstimator(config['ctx_model'],
                                            config['ctx_calibrator'])
        self.ccnr = ContextConditionedNorms(config['rule_db'])
        self.cgc = CommonGroundCertificate(config['response_model'])
        self.lrc = LegibilityCertificate(config['human_model'])
        self.mihc = MixedInitiativeHandover(config['geo_cert'], config['dynamics'])
        self.trace = SituatedExplanationTrace()
        self.gate = HPCEPlusPlus(
            hpc_e_plus=self.base.hpc_e_plus, scc=self.scc, ccnr=self.ccnr,
            cgc=self.cgc, lrc=self.lrc, mihc=self.mihc, trace=self.trace)

    def step(self, sensor_data, human_state, cloud_update=None):
        # 1) v23 感知/证书/共识/云边（不变）
        admitted_v23, info = self.base.step(sensor_data, cloud_update)
        if not admitted_v23:
            return False, info

        # 2) SIL 五证准入
        plan = info['plan']
        obs = build_observation(sensor_data, info)
        admitted = self.gate.admits(
            plan, obs,
            humans_present=human_state.present,
            b_h=human_state.belief, b_r=human_state.robot_belief,
            signal=human_state.signal,
            mi_state=human_state.mi_state,
            human_estop=human_state.estop,
            modules=self.base._modules_in_plan(plan),
        )

        # 3) 惊讶检测 → 立即撤销赎回并重规划
        if human_state.observed_response is not None:
            if self.cgc.revoke_if_surprised(
                    human_state.observed_response,
                    self.cgc.response_model.distribution(plan, human_state.belief)):
                self.cgc.delta_min = self.cgc.delta_worst   # 本周期撤销赎回
                admitted = False

        info.update({'sil_admitted': admitted,
                     'context': self.scc.update(obs.history).Gamma_c,
                     'explanation': self.trace.human_readable()})
        return admitted, info
```

## 3. 正确性论证

### 引理 1（情境交集的可执行性）
**陈述**：若 `Γ_c(h_t)` 满足 `P(c* ∈ Γ_c) ≥ 1-α_c`，且 `A_ctx = ⋂_{c∈Γ_c} A(c)`，则对任意 `π ∈ A_ctx`，以概率 ≥1-α_c 有 `π ∈ A(c*)`，即在真实情境下可执行。

**证明**：由覆盖性，事件 `c* ∈ Γ_c` 概率 ≥1-α_c；在此事件下，因 `A_ctx ⊆ A(c*)`（交集是每个成员集的子集），故 `π ∈ A_ctx ⇒ π ∈ A(c*)`。∎

### 引理 2（情境驻留滞回抑制抖动）
**陈述**：以 `T_ctx` 为模态驻留阈值，情境细化只在 `dwell ≥ T_ctx` 时发生，故情境细化的切换频率 ≤ `1/T_ctx`；在计划执行期内若不允许中途切换，则单个计划始终在单一情境版本下被认证。

**证明**：每次细化前必须积累 `T_ctx` 的连续驻留；模态一变即重置计时，故两次细化间隔 ≥ `T_ctx`。计划边界切换规则进一步保证认证与执行使用同一情境版本。∎

### 引理 3（共同基础赎回有界且可撤销）
**陈述**：`δ_h^cg ∈ [δ_h^min, δ_h^worst]`；若 `geo_clearance ≥ δ_h^cg` 且人反应模型在置信 1-α_h 下正确，则赎回后的联合人-机碰撞概率 ≤ α_h + α_c；惊讶检测触发时赎回立即撤销。

**证明**：由 `redeemed_margin` 的 `max/min` 夹逼得区间；CVaR 约束保证最坏 `α_h` 尾部的人-反应安全裕度 ≥0；情境覆盖贡献 `α_c`。撤销条款把 `δ_h` 重置为 `δ_h^worst`，故赎回不具持续性。∎

### 引理 4（可读性只收缩且单调增益）
**陈述**：加入 `L(π) ≤ H_max` 与 `H(σ) ≤ H_sig` 后计划集只减不增；可读性提高（`L` 降低）使人的反应熵下降，从而互信息 `I_t` 不减、`δ_h^cg` 不增（安全裕度更大），且 `Geo_v24 = Geo_v23`。

**证明**：约束是合取，故计划集单调收缩。反应熵下降 ⇒ `I_t = H(b_h) - H(b_h|b_r)` 增大（在 `H(b_h)` 不变时）⇒ `δ_h^worst - κ·I_t` 不增，取 `max` 后仍不增。几何域由 v23 证书独立给出，SIL 不修改。∎

### 引理 5（安全回手集的人优先与无死锁）
**陈述**：若 `H_safe` 是 v23 几何/能量证书下的受控不变集，则从任意 `s ∈ H_safe` 出发，存在 ≤`T_ho` 的安全停止/交还路径；`human_estop` 时机器人必让位；`NEGOTIATE` 超时转 `SAFE_STOP`，故无静默死锁。

**证明**：受控不变集定义保证对最坏有界人输入存在安全控制序列在 `T_ho` 内到达停止/交还；`admit` 在 `human_estop` 时返回 False（让位），在 `NEGOTIATE` 超过 `T_ho` 时 `_no_deadlock` 为 False（升级 SAFE_STOP）。∎

### 引理 6（失效单调回退链）
**陈述**：任意单点/组合失效下，`Exec_v24^fail ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`，且 `Geo_v24 = Geo_v23`。

**证明**：
- SCC 失效 → `ctx=None` 或 `coverage_ok=False` → `A_⊥`（v23 默认）→ 子集；
- CGC 失效 → `delta=δ_h^worst`，不赎回 → 子集；
- LRC 失效 → 无可读计划 → 拒绝/换计划/停止 → 子集；
- MIHC 失效 → 拒绝自主交互，安全停止 → 子集；
- 组合失效取交，单调性保持。∎

### 定理（HPC-E++ 五证准入门的情境-交互完备性）
**陈述**：对任意计划 π，`HPCEPlusPlus.admits(π) = True` ⟺ π 同时满足：
(1) v23 物理-规范-云边-少样本-IP 四证；
(2) 情境证书覆盖且规范可执行（歧义取交 / 单点稳定细化）；
(3) 人在场时共同基础与可读性达标，且赎回量不越几何地板；
(4) 混合主动交接处于安全回手集且人优先、无死锁。

**证明**：直接由 `admits` 的四个连言条件与引理 1–6 可得。必要性：任一条件缺失即拒证，对应情境误判/共同基础失真/不可读/交接失稳中的一类。充分性：四条件满足时，由引理 1–6 得可执行性、赎回有界性与失效单调回退，构成闭环。∎
