# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~302；灵感循环新一轮；本轮灵感：「场景理解」×「双臂协作」）

> R73 把信任从「全系统审计」下沉为「证据契约的组合代数」（MMS/DPEM/CCA/ΣREFLEX/CPB），并证明了热替换与零级联。但它有三个**粒度与耦合层面**的结构盲区，恰好被本轮两个灵感击中：
> - **证据粒度是「观测」而非「对象」**：R73 的不确定度是标量/向量（深度六分量、接触四分量），CCA 在**数值**上传播。但场景理解的基本单位不是像素，而是**对象假设**——存在性、关联（哪块观测属于哪个对象）、位姿、开放世界类别、可供性、对象间关系。关联歧义不是「再加一个方差」，而是**组合爆炸的离散不确定性**；CCA 没有类型去承载它，PAR 的一致性审计也只是成对标量残差，无法表达场景图的**关系一致性**（支撑、包含、接触、可达）。
> - **耦合被当作风险，而非结构**：R73 把「两模块通过共享物理过程隐性耦合」列为第 5 号次级风险，用「怀疑相关时禁用 PAR 缩窄」兜底。但双臂协作里，两臂共享同一个场景、同一盏灯、同一条标定链——耦合不是例外，而是任务的**全部内容**。若共享隐变量不被显式表示，系统只能在「虚假独立（错误缩窄）」与「一律保守（放弃协作）」之间二选一。
> - **证据生成在「干预」之下，校准却在「观测」之下**：一只臂的动作会改变场景（抓取、推、遮挡），另一只臂的观测是 **do(a) 之后的证据**，与校准集的观测分布不再可交换。R73 的 conformal 覆盖率在干预下失效；而**交接**正是最强的干预时刻，也是跌落风险最高的时刻。
>
> 本轮直觉一句话：**像素不会协作，对象才会。** 双臂协作的真正单位不是「两个传感器」或「两只手」，而是**共享的场景对象**。要让两臂共享一个世界，必须先显式表示**共享隐变量**、审计**条件独立**、并在**干预 regime** 下重新校准。于是把 MODGAUGE-RAS 推进为 **COOPSCENE-RAS**（COOPerative SCENE-evidence metrology with GAUGE audits）——**共享场景的协作证据计量**。

## 0. 直觉与动机

**灵感 1（场景理解 → 从「像素证据」到「对象-关系证据」）**
直觉：人看一张桌子，不会先得到一张深度图再取平均；他得到的是「这里有杯子、杯子在桌上、杯柄朝我」。场景理解输出的是**结构化假设**：对象是否存在、每块观测归属哪个对象、对象位姿与范围、类别（开放世界，允许 unknown）、可供性（可抓/可放/可支撑）、对象间关系。这些量里，**存在**与**关联**是离散、组合、非高斯的——把它们压成一个标量 u，等于把「我可能把盐罐看成了胡椒罐」误写成「距离多差 2cm」。所以核心不是加一个物体检测器，而是给场景假设定义**风险向量** R_scene =（漏检率，虚检率，关联错误率，位姿误差，关系违背率），并用分布无关风险控制（RCPS）逐项校准。**场景理解的困难不是感知精度，而是离散假设的可证伪性与风险可分配性。**

**灵感 2（双臂协作 → 共享隐变量把「隐性耦合」变成一等公民）**
直觉：两台相机看同一个杯子，它们并不独立：同一物体、同一光照、同一条标定链。若把两路证据当独立并联，会**过度自信**；若一律取 max，则放弃协作收益。正确对象是**条件独立**：E_A ⟂ E_B | S_scene。于是 CCA 需要新算子 **COND-PAR**：只有当「共享隐变量 S 被认证为充分」且「条件相关性低于门槛」时才允许缩窄；否则退回保守 max。一个反直觉点：条件化可能因 explaining-away 而**增大**方差，所以融合必须把 S 的后验不确定性一起积分（全方差公式），而不是把 Ŝ 当已知量代入。这把 R73 的风险 #5 从「审计注意事项」升级为**可注册、可检验、可证书化的图节点**。

**灵感 3（双臂协作 → 干预证据与交接否决）**
直觉：左手抓起杯子后，右手相机看到的是**被左手改变过的世界**。这不是同分布的新样本，而是 do(grasp) 下的证据，顺序 conformal 的交换性被破坏。解决方案不是「多采点数据」，而是**按 regime 校准**：regime r =（干预类型 a，上下文），只在同一 regime 内要求可交换；并维护一个**已认证干预包络** ℰ_int，包络外一律回退到保守界。交接是这套机制最尖锐的实例：两只手必须在同一个对象假设上达成一致才能松手，否则就是跌落。HOV 把「场景一致」变成**非补偿否决门**：两臂的对象后验若不在条件 conformal 集内一致，就拒绝交接、原地消歧，而不是赌一把。

**灵感 4（双臂协作 → 协作反作用通道 L5/L6）**
直觉：R73 的 χ_R 说「我的动作如何调制我自己的噪声」。双臂多了两条通道：**χ_vis**（另一只臂的动作改变我的可见性/遮挡 → 调制关联不确定度与漏检率）与 **χ_world**（我的动作改变共享场景状态 → 调制对象先验与可供性）。反作用从「自我反作用」升级为「**他者反作用 + 世界反作用**」。协作主动感知因此有严格形式：一臂按住物体、另一臂移开遮挡物再观察，联合信息增益 IG(S_scene; y_A,y_B | a) 必须扣除冗余（交互信息 II 可为负）；次模性给出有限停止与 1−1/e 保证。

**灵感 5（场景理解的威胁面 → 共同幻觉）**
直觉：双臂最危险的不是「一只臂错」，而是「两只臂因共享同一错误来源而一起错」：透明/镜面物体让两台同型号深度相机同时失效；伪造支撑关系让两臂都认为「可以放」；关联诱饵让两臂都把 A 认成 B。它们的**一致**会被 COND-PAR 误读为「独立证据互相验证」。所以必须引入**证据来源独立性**（provenance 而非统计相关）与**物理一致性否决**（穿模、无支撑、物体瞬移），并坚持 R71/R73 的「单源不定案」。**一致不等于正确；共享来源的一致只是共享的幻觉。**

## 1. 形式化定义（增量：定义 383–398）

**定义 383（COOPSCENE-RAS 总览与六不变式）** COOPSCENE-RAS = (SGC, SLC, COND-PAR, ICP, CCR, HOV, CSU, MODGAUGE-RAS†)。六不变式：
(i) **契约完整性**（继承）：无完整契约不入图、不参与组合；
(ii) **组合单调性**（扩展）：SER/PAR/VETO/COND-PAR 全部经 CCA† 校验，缩窄仅在审计通过时发生，无「凭空变好」路径；
(iii) **反作用通道完备**（扩展）：除 χ_R 外，跨臂耦合必须声明 χ_vis 与 χ_world；
(iv) **主张绑定**（扩展）：组件 ∈ {C1…C6, 工程附件}，附件不入核心认证路径；
(v) **严格退化链**（扩展）：共享隐变量不可识别 ⇒ COND-PAR 退化为 R73 保守 PAR；交接关闭 ⇒ 退化为单臂 MODGAUGE；
(vi) **共享场景一致性**（新增）：任一跨臂证据组合必须声明 d-分离该耦合的共享隐变量 S；未声明耦合的跨臂 PAR **禁止缩窄**。

**定义 384（场景图证据 SGE）** 场景假设 G_t = (O_t, R_t, S_t)：
- O_t = {o_i} 为对象节点，o_i = (e_i, ξ_i, B_i, c_i, A_i, τ_i)：存在后验 e_i ∈ [0,1]、位姿分布 ξ_i ∈ SE(3)、占据/范围 B_i、开放集类别 c_i ∈ 𝒞 ∪ {unknown}、可供性集合 A_i、来源追溯 τ_i；
- R_t = {(o_i, o_j, r, p_ij) : r ∈ 𝓡}，𝓡 = {support, contain, contact, reachable, occludes, relative-pose}，p_ij 为校准置信，且每条边带物理约束谓词；
- S_t 为共享隐变量（物体身份、光照、标定链、动力学、任务阶段）；
- 场景证据是**集合值对象**，携带关联划分 π（哪组观测归哪个对象），而非单点估计。

**定义 385（对象证据 OEV 与关联不确定度）** 臂 k 的对象证据 E_o^k = (e_o, α_o, ξ_o, Σ_ξ, B_o, c_o, A_o, τ_o)：
- α_o 为观测子集上的**关联后验**（划分 π 上的分布），关联熵 H_assoc(o) = H(α_o) 是一等不确定度分量；
- 场景不确定度**不是标量**，而是风险向量 R_scene = (P_miss, P_false, P_assoc_err, E‖Σ_ξ‖, P_relation_violation)；
- 对象级校准采用分布无关风险控制（RCPS）而非仅边际覆盖率：给定校准集与目标风险 β，选阈值 λ̂ 使经验风险以高概率 ≤ β。

**定义 386（场景证据契约 SGC）** SGC = (EC, L_scene, R_target, S_ref, ρ_open, assoc_model, rel_schema)：
- L_scene：场景损失泛函（漏检/虚检/关联/关系各自的代价）；
- R_target：场景风险预算向量（如 P_miss ≤ β_miss、P_assoc_err ≤ β_assoc）；
- S_ref：该模块声明依赖的共享隐变量引用；
- ρ_open：开放世界弃权策略（unknown 类别不产生可供性断言）；
- assoc_model：关联模型（Hungarian / 概率关联 / 多假设跟踪）；
- rel_schema：合法关系模式与物理约束（反穿模、支撑存在性）。
输出类型 T_out = SceneHypothesis；SGC 是 EC 的**结构化扩展**，EC 是 SGC 在 |O|=1 且关系为空时的特例。

**定义 387（共享隐变量契约 SLC）** 共享隐变量集合 S = {S_j}，每个 S_j 声明：
- scope(S_j)：被 S_j d-分离的模块对集合；
- id(S_j) ∈ {observed, inferred, unidentifiable}：可识别性状态；
- π_S：条件独立审计协议（held-out 条件残差检验 + conformal 条件集）；
- sensitivity：S 后验对融合结果的一阶敏感度上界。
MReg 升级为**隐变量增广 DAG** MReg^S：跨臂边必须标注「由哪个 S 分离」。

**定义 388（条件并联 COND-PAR）** 对证据 E_A、E_B 与共享隐变量 S，A ⊕_S B 的规则：
1. **充分性审计**：在 held-out 上检验 E_A ⟂ E_B | S（条件残差落入 conformal 条件集），且 S 的声明 scope 覆盖该边；
2. **条件相关门槛**：|ρ_{AB|S}| < ρ_max；
3. **全方差融合**：u_out² = E_S[u_fuse²(Ŝ)] + Var_S(∂u_fuse/∂S)（S 不确定性不得被静默丢弃）；
4. 审计失败或 S 不可识别 ⇒ u_out = max(u_A, u_B)，并置否决指示 `SHARED_LATENT_UNRESOLVED`；
5. 攻击语义：跨臂「过于一致」但 provenance 同源 ⇒ 触发 I⊥（共同幻觉），而非缩窄。

**定义 389（干预 regime 与 do-conformal）** 动作 a 视为对共享世界 S 的干预 do(a)。do(a) 之后产生的证据 y 属于 regime r = (a, context)。**已认证干预包络** ℰ_int 是满足以下条件的 regime 集合：(i) 校准支撑非空（同一 regime 内可交换）；(ii) 因果机制在包络内不变（假设 A115：物体的物理响应不随干预类型改变）。
- 在 ℰ_int 内：do-conformal 保证**按 regime 条件**的覆盖率；
- 在 ℰ_int 外：不得使用缩窄后的不确定度，回退到 do-free 保守上界。

**定义 390（regime 覆盖检验）** 对每个 regime 维护顺序 e-value / martingale 检验：若同一 regime 内经验误覆盖持续超出 α + 置信带宽，则拒绝交换性，标记该 regime 为 shifted，触发重校准或回退。检验的假警报率由 e-process 控制，不依赖分布假设。

**定义 391（协作反作用通道 CCR：L5/L6）** 联合动作 a = (a_A, a_B)。每个臂 i 的通道 χ_coop^i = (χ_vis^i, χ_world^i)：
- χ_vis^i：他臂动作 → 本臂遮挡/可见性 → 调制 (u_assoc, P_miss, u_edge)；
- χ_world：任一臂动作 → 共享对象状态 → 调制对象位姿先验、可供性与关系合法性。
联合预算 c_coop = Σ_i (c_vis^i + c_world^i) − Redundancy(II)，其中 II 为交互信息，II<0 表示两臂信息冗余。联合稳态集 Ω_coop = Ω_safe ∩ Ω_mutual-visibility ∩ Ω_arm-separation ∩ Ω_object-stability。任一层越界即拒绝该联合动作（非补偿）。

**定义 392（协作信息增益与次模性）** 联合信息增益 IG(S_scene; y_A, y_B | a) = H(S_scene) − H(S_scene | y_A, y_B, a)。交互信息 II = IG_joint − IG_A − IG_B（可正可负）。若 IG 在候选动作集上是**次模**的且成本模块正，则贪心协作主动感知有有限停止 n* 与 1−1/e 近似保证；若 II 显著为负（强冗余），必须重新分配角色（一臂保持、另一臂探索）而非继续叠加观测。

**定义 393（交接否决 HOV）** 交接时刻 t_h 的许可条件（全部满足才允许松手）：
(i) 两臂对象后验在**条件 conformal 集**内一致（条件于共享 S）；
(ii) 对象位姿不确定度 ≤ τ_pose；
(iii) 两臂抓取可供性集合交集非空；
(iv) 当前 regime ∈ ℰ_int，且该 regime 覆盖检验通过。
任一失败 ⇒ VETO（非补偿）：保持夹持、执行消歧动作，而不是降低门槛。

**定义 394（协作证书 J_COOP）** J_COOP = ⊗_{arm∈{A,B}} J_MOD(arm) ⊗ J_SLC(共享隐变量充分性) ⊗ J_ICP(regime 覆盖) ⊗ J_HOV(交接门) ⊗ J_comp(MReg^S)。
组合校验：跨臂边均有 S 声明、S 充分性证书有效、regime 覆盖通过、交接门可判定、联合反作用预算闭合、provenance 独立性检查通过。Valid(J_COOP) ⇒ Valid(J_MOD(A)) ∧ Valid(J_MOD(B)) ∧ 协作安全界（定理 31）。

**定义 395（协作场景理解规划 CSU）** 联合动作
a* = argmax_a [ IG(S_scene; y_A,y_B | a) − λ_s·E[u_scene^{next}(a)] − c_coop(a) ]
s.t. Ω_coop、两臂 REG 联合时序契约、HOV 可满足。**关键**：IG 与 u_scene^{next} 由 χ_vis/χ_world 的解析/半解析模型给出，避免联合传感器 rollout；角色（保持/探索/交接）作为动作的一部分被优化。

**定义 396（场景威胁面 AIC-SCENE）** ℰ_scene = {透明/镜面共同致盲、支撑关系伪造、关联诱饵、场景图投毒（假关系边）、遮挡攻击、同源传感器协同欺骗、物体瞬移（物理不可能）}。防线：provenance 独立性 + 物理一致性 VETO + 条件独立审计 + 单源不定案 + 关系边 `P_relation_violation` 硬门。

**定义 397（场景级 stub 与退化链）** 降级顺序（安全侧只增不减）：
完整 COOPSCENE → **关系 stub**（保留对象集，冻结/清空关系边）→ **单臂场景**（他臂证据变 stub，COND-PAR 关闭）→ **R73 度量证据**（退化为逐模态标量 u）→ R72/R71/R68。
任一降级必须保持 MReg^S 图连通与既有否决语义；stub 不产生关联证据、不参与 COND-PAR 缩窄。

**定义 398（场景复杂度与通信上限）** |O| ≤ 32、|R| ≤ 128、|S| ≤ 8、关联假设 top-K ≤ 8、场景图深度 ≤ 3、跨臂消息类型 ≤ 12、通信预算 ≤ B_comm——全部为 MReg^S 的**可审计图/消息性质**，部署期与运行时增量校验。

## 2. 关键算法骨架

```python
# IP-303 SGC：场景证据契约 + 对象/关系证据
@dataclass(frozen=True)
class SceneContract:
    ec: EvidenceContract                      # R73 基础契约（类型/预算/域/否决/追溯）
    risk_target: Dict[str, float]             # {P_miss, P_false, P_assoc_err, P_rel}
    s_ref: FrozenSet[str]                     # 依赖的共享隐变量
    assoc_model: str                          # hungarian | prob | mht
    rel_schema: RelationSchema                # 合法关系 + 物理约束
    open_world: bool                          # 允许 unknown 弃权

# IP-304 OEV：对象证据（存在/关联/位姿/可供性）
@dataclass
class ObjectEvidence:
    e: float                                  # 存在后验
    alpha: Distribution                       # 关联后验（划分上的分布）
    xi: SE3Distribution; B: Occupancy
    cls: str; afford: FrozenSet[str]
    tau: Provenance                           # 来源追溯（含传感器指纹）
    def risk(self):                           # 风险向量，非标量
        return SceneRisk(P_miss=1-self.e, P_assoc_err=entropy(self.alpha),
                         pose=norm(self.xi.cov), rel=0.0)

# IP-305 SLC + COND-PAR：共享隐变量条件并联
def cond_par(a_ev, b_ev, shared, audit):
    if not audit.sufficient(shared, a_ev, b_ev):          # E_A ⟂ E_B | S ?
        return conservative(a_ev, b_ev, flag='SHARED_LATENT_UNRESOLVED')
    if not audit.cond_conformal(a_ev, b_ev, shared):       # 条件残差在集内？
        return conservative(a_ev, b_ev, flag='COND_AUDIT_FAIL')
    if audit.provenance_same_source(a_ev, b_ev):           # 共同幻觉闸门
        return veto(a_ev, b_ev, 'COMMON_HALLUCINATION')
    rho = audit.cond_corr(a_ev, b_ev, shared)
    if abs(rho) >= RHO_MAX:
        return conservative(a_ev, b_ev, flag='COND_CORR_HIGH')
    fused = fuse(a_ev, b_ev, rho)
    return total_variance(fused, shared)                   # 积分 S 的不确定性

# IP-306 ICP：干预 regime 下的 do-conformal
class RegimeConformal:
    def calibrate(self, regime, calib_set): self.sets[regime] = build(calib_set)
    def cover(self, regime, r):
        if regime not in self.envelope: return self.conservative_bound(r)
        if self.e_test(regime).shifted: return self.conservative_bound(r)
        return self.sets[regime].covers(r)

# IP-307 CCR：协作双通道反作用步进
def coop_reflex_step(arms, a_joint, state, budget):
    total = 0.0
    for i in arms:
        chi_vis, chi_world = arms[i].ec.chi_coop(a_joint)
        c_vis = arms[i].reflex_vis(state[i], chi_vis)      # 遮挡/可见性代价
        c_world = arms[i].reflex_world(state, chi_world)   # 共享世界状态代价
        if not (arms[i].safe_set & chi_vis.safe & chi_world.safe):
            return None, total
        total += c_vis + c_world
    total -= budget.redundancy_discount(state)             # 信息冗余折扣（II<0）
    if budget.spent + total > budget.B_coop: return None, total
    return update_state(state, a_joint), total

# IP-308 HOV：交接否决门
def handover_gate(obj_A, obj_B, S, regime, calib):
    if S.id == 'unidentifiable': return False, 'S_UNRESOLVED'
    if not calib.cond_conformal(obj_A, obj_B, S): return False, 'SCENE_DISAGREE'
    if obj_A.pose_unc > TAU_POSE or obj_B.pose_unc > TAU_POSE: return False, 'POSE_UNC'
    if not (obj_A.afford & obj_B.afford): return False, 'NO_COMMON_AFFORDANCE'
    if regime not in calib.envelope: return False, 'REGIME_UNSUPPORTED'
    return True, 'OK'

# IP-309 J_COOP：协作证书
def J_COOP(arms, mreg_s, slc, icp, hov):
    return (J_MOD(arms['A']) & J_MOD(arms['B']) & slc.valid()
            & icp.covers_all_regimes() & hov.decidable() & mreg_s.audit())

# IP-310 CSU：协作场景理解规划
def cooperative_scene_plan(scene, arms, slc, budget):
    def J(a):
        ig = joint_info_gain(scene, arms, a)               # 含交互信息 II
        u_next = sum(m.ec.chi_coop(a).expected_scene_u(scene) for m in arms)
        return ig - LAM_S * u_next - coop_reflex_cost(arms, a)
    return optimize_joint_under_reg(J, union_action_space(arms), horizon=0.5)

# IP-311 COOPSCENE 主闭环（双域/单域混合，跨臂全经契约）
def COOPSCENE_round(M, obsA, obsB, tacA, tacB, depthA, depthB):
    # 感知域（双 100Hz）
    g_A = M.sgcA.update(depthA, obsA, M.shared)            # 场景图 A
    g_B = M.sgcB.update(depthB, obsB, M.shared)            # 场景图 B
    if g_A.assoc_unresolved: g_A = relations_stub(g_A)      # 关系 stub（定义 397）
    # 场景融合（计量域 50Hz）
    if M.clock.due_metric():
        G = M.fuse.cond_par(g_A, g_B, M.shared, M.audit)    # COND-PAR
        s_post = M.slc.update(M.shared, G)                  # 共享隐变量后验
        a_star = cooperative_scene_plan(G, M.arms, M.slc, M.budget)  # CSU
        ok, why = handover_gate(G.obj('A'), G.obj('B'), s_post, M.regime, M.icp)
        if M.intent_handover and not ok: M.arms.hold(why)   # HOV 非补偿
        s2, cost = coop_reflex_step(M.arms, a_star, M.state, M.budget)
        if s2 is not None: M.execute(a_star, s2)
        M.icp.test_regime(M.regime)                         # regime 漂移检验
        M.snapshot.write(G, s_post, a_star, M.regime)
    # 控制域（双 1kHz，继承 R73 三域时序隔离）
    snap = M.snapshot.read_latest()
    kA, kB = M.ctrl.compose(snap, M.arms)                   # 臂-臂避碰 + 证据风险 λ
    return kA, kB, J_COOP(M.arms, M.mreg_s, M.slc, M.icp, M.hov)
```

## 3. 推导

**引理 38（对象级风险的分布无关控制）** 设校准/测试对象级样本可交换，RCPS 以校准集选阈值 λ̂ 使经验风险 ≤ β 的概率 ≥ 1−δ。场景风险是向量，同时对 M 项风险控制需并集界（或对联合风险单调函数做单次控制）；因此 SGC 的 R_target 必须是**联合可校准**的，不能把五项独立校准后相乘声称联合保证。系：**场景风险不能用单标量 u 表达——这是 SGC 存在的理由。**

**引理 39（条件并联缩窄的合法性）** 若 E_A ⟂ E_B | S 且 S 被认证充分，则条件融合的覆盖率在 S 的每个取值上成立；由全方差公式，u_out² = E_S[u_fuse²] + Var_S(∂u_fuse/∂S) ≥ E_S[u_fuse²]，把 Ŝ 当已知量会**系统性低估**。故 COND-PAR 的缩窄是合法的，但必须显式积分 S 的不确定性；S 不可识别时任何缩窄都不合法。系：**条件独立不是免费缩窄，必须为「不知道 S」付费。**

**引理 40（隐藏耦合的覆盖亏损可检出）** 若真实结构为 E_A ← S → E_B 而审计按边际独立处理，则融合方差低估量是 S 诱导的边际相关的单调函数，覆盖率亏损下界由该相关与融合权重决定；把 S 显式入图后，条件残差不再携带该相关，审计能将其与真实独立区分。系：**R73 风险 #5 从「无法检测的隐耦合」变成「可注册、可检验的显节点」。**

**引理 41（干预 regime 的覆盖迁移）** 在已认证包络 ℰ_int 内，若机制不变（A115）且 regime 校准支撑非空，则 do-conformal 覆盖率按 regime 条件成立；跨 regime 迁移的附加亏损 ≤ ε_regime(支持距离)。包络外无保证，必须回退保守上界。系：**「交接前先问：这个干预 regime 校准过吗？」是可证伪的安全检查。**

**引理 42（协作主动感知的有限停止）** 若联合信息增益对动作集次模、成本模块正且边际成本有正下界，则贪心协作主动感知有限停止 n*，且停止时增益 ≥ (1−1/e)·OPT；若交互信息 II < 0 导致有效增益递减过快，则重分配角色可恢复次模性。系：**两臂不是「越多观测越好」，冗余必须被预算显式扣除。**

**引理 43（交接安全界）** 在 HOV 全条件满足时，交接跌落概率 ≤ 由条件 conformal 与位姿阈值联合校准的风险上界；任一条件失败即 VETO（非补偿），因此不存在「场景歧义下仍松手」的执行路径。系：**交接安全不是调参，而是一个可判定的门。**

**引理 44（场景降级的零级联）** 关系 stub 清除关系边但不产生对象证据，单臂 stub 不参与 COND-PAR，故降级不污染他臂的对象后验；由 R73 引理 35（同契约实现）与定理 29，逐指令退化为少结构版本且安全侧只增不减。系：**场景结构可以丢，但丢弃是显式、单调、可审计的。**

**定理 30（COOPSCENE 严格包含 MODGAUGE）** 当 (i) |O|=1 且关系集为空、(ii) 共享隐变量集 S=∅、(iii) regime 集仅含空干预、(iv) 交接关闭（单臂），COOPSCENE 的 SGC 退化为 EC、COND-PAR 退化为 PAR、CCR 退化为 χ_R、HOV 恒真、J_COOP 退化为 J_MOD。由引理 44 与 R73 定理 27–29，逐指令等于 R73，再退化等于 R72/R71/R68。**安全单调不减。**

**定理 31（协作证书有效性 ⇒ 双机安全界）** 在 A114（共享隐变量充分性：所声明 S 确实 d-分离跨臂耦合）与 A115（机制在 ℰ_int 内不变）下，Valid(J_COOP) ⇒ 两臂各自 J_MOD 有效 ∧ 跨臂条件独立已认证 ∧ regime 覆盖成立 ∧ 交接门可判定 ∧ 联合预算闭合 ⇒ (臂-臂碰撞 + 交接跌落 + 场景灾难性误判) 的联合风险 ≤ ε_coop。**证明重量落在 A114/A115 与 provenance 独立性上——即「共享的 S 是否真的是那个 S」。**

**定理 32（无免费协作：条件组合单调性）** 对 COND-PAR：u_out ≥ max(u_A,u_B) 当 S 不可识别或条件审计失败；即使在最有利条件下，缩窄量受条件覆盖率 (1−α) 与 S 的后验熵约束，且不得低于路径上所有输入贡献的单调函数。⇒ 不存在「两臂一致就凭空变好」的路径。系：**协作的收益来自「解释掉共享隐变量后剩余的独立信息」，不是来自「多了一个投票者」。**

**定理 33（不可识别共享隐变量的安全退化）** 若 id(S)=unidentifiable 或充分性证书失效，则 COND-PAR 强制退化为 R73 保守 PAR，J_COOP 的对应跨臂边降级为「无缩窄」；由定理 30，系统仍满足 MODGAUGE 的全部安全性质。⇒ **不可识别不是错误，而是安全回退。**

## 6. 本轮最大风险

**一句话**：COOPSCENE 把「共享」变成一等公民，却把安全的证明负担压在「**共享隐变量 S 的可识别性与充分性**」上——如果 S 未被正确识别（两臂的环境隐变量根本不是同一组，或 S 只是一个统计拟合），或者两臂通过同一物理来源（同型号相机、同一光源、同一标定链）产生**共同幻觉**，那么 COND-PAR 会把「共享的错误」认证为「条件独立的一致证据」，do-conformal 又会在未覆盖的干预 regime 中给出虚假覆盖率；系统会以两份互相印证的证书、一条一致的场景图、一份完整的审计日志，**协同地把同一个错误世界执行下去**——单臂时是「自信地错」，双臂时是「**一致地、可复现地、经过交叉验证地错**」。

次级风险与缓解：
1. **S 不可识别/误设** → 多候选 S 并存 + 可证伪检验（E399/E400）+ 不可识别即强制回退保守 max（定理 33），绝不默认缩窄。
2. **开放世界对象风险控制失效** → unknown 类别弃权（ρ_open）+ 联合风险单次校准（引理 38）+ 高风险对象人工确认，不把弃权当失败。
3. **关联组合爆炸** → top-K 关联 + |O|/|R| 上限（定义 398）+ 增量关联；超限触发关系 stub。
4. **干预包络过窄导致协作退化为单臂** → 在线安全扩展包络（受 RTA 与 HOV 约束），包络外保守回退；报告「协作可用率」而非隐藏退化。
5. **交接门过保守导致任务停滞** → 用**消歧动作**（移遮挡/轻触/换视角）而不是降低门槛；停滞率作为预注册指标。
6. **通信丢失/带宽不足** → 有损消息融合 + conformal 降级到独立保守模式；消息丢失率进证书校验。
7. **共同幻觉/对抗场景** → provenance 独立性（传感器指纹/标定链/光源 ID）+ 物理一致性 VETO + 单源不定案；一致性与独立性分开审计。
8. **C4–C6 主张过拟合** → 预注册 + 密封保持集 SEAL-COOP + 三方复现（E412）；只认预注册指标，组合收益单独归因。

## 2. 形式化定义（要点版）

**定义 383（总览与六不变式）** 契约完整性 / 组合单调性（含 COND-PAR）/ 反作用通道完备（含 χ_vis/χ_world）/ 主张绑定 C1–C6 / 严格退化链 / **共享场景一致性**（跨臂组合必须声明 d-分离 S，否则禁止缩窄）。

**定义 384（SGE）** `G_t=(O_t,R_t,S_t)`；对象为集合值假设；关系带物理约束谓词；场景证据携带关联划分 π。

**定义 385（OEV）** 对象证据含存在、关联、位姿、可供性、provenance；关联熵 `H_assoc` 与风险向量 `R_scene` 为一等量，不可压成标量 u。

**定义 386（SGC）** 在 EC 上追加场景损失 `L_scene`、风险预算 `R_target`、共享隐变量引用 `S_ref`、开放世界弃权 `ρ_open`、关联模型与关系模式；EC 为其单对象、零关系特例。

**定义 387（SLC）** 每个共享隐变量声明 scope / 可识别性 / 审计协议 / 敏感度；MReg 升级为 MReg^S，跨臂边必须标注分离它的 S。

**定义 388（COND-PAR）** 五步：充分性审计 → 条件相关门槛 → 全方差融合 → 失败回退 `max` + `SHARED_LATENT_UNRESOLVED` → 同源「过于一致」触发共同幻觉否决。

**定义 389（do-regime）** 动作即对共享世界的干预；do-conformal 只在同一 regime 内要求可交换；包络 ℰ_int 内保证条件覆盖，包络外回退 do-free 保守界。

**定义 390（regime 覆盖检验）** 顺序 e-value / martingale 检验交换性；误覆盖持续超 `α+带宽` ⇒ 标记 shifted，触发重校准/回退。

**定义 391（CCR）** `χ_coop^i=(χ_vis^i, χ_world^i)`；联合预算扣冗余；`Ω_coop = Ω_safe ∩ Ω_mutual-visibility ∩ Ω_arm-separation ∩ Ω_object-stability`；越界非补偿拒绝。

**定义 392（协作信息与次模性）** `IG` 对动作次模 + 正成本 ⇒ 有限停止与 1−1/e；`II<0`（强冗余）⇒ 重分配角色（保持/探索）而非叠加观测。

**定义 393（HOV）** 交接仅在四条件全满足时允许松手，任一失败即保持夹持并消歧，不降门槛。

**定义 394（J_COOP）** 组合校验：跨臂边均有 S 声明；S 充分性证书有效；regime 覆盖；交接门可判定；联合预算闭合；provenance 独立性通过。

**定义 395（CSU）** `a* = argmax IG − λ_s·E[u_scene^next] − c_coop`，受 Ω_coop、两臂 REG 联合时序、HOV 约束；角色（保持/探索/交接）进入动作空间。

**定义 396（AIC-SCENE）** 共同致盲 / 伪支撑 / 关联诱饵 / 场景图投毒 / 遮挡攻击 / 同源协同欺骗 / 物理不可能；防线：provenance 独立性 + 物理一致性 VETO + 条件审计 + 单源不定案。

**定义 397（场景 stub 与退化链）** 完整 → 关系 stub → 单臂场景 → R73 度量证据 → R72/R71/R68；stub 不产生关联证据、不参与 COND-PAR，安全侧只增不减。

**定义 398（复杂度与通信上限）** `|O|≤32, |R|≤128, |S|≤8, top-K≤8, 图深≤3, 消息类型≤12, B_comm`；均为可审计图/消息性质。

## 3. 关键算法伪代码

```python
# IP-303/304：场景证据契约 + 对象证据（风险向量而非标量）
@dataclass(frozen=True)
class SceneContract:
    ec: EvidenceContract                      # R73 基础契约
    risk_target: Dict[str, float]             # P_miss/P_false/P_assoc_err/P_rel
    s_ref: FrozenSet[str]                     # 共享隐变量引用
    assoc_model: str                          # hungarian | prob | mht
    rel_schema: RelationSchema                # 关系模式 + 物理约束
    open_world: bool

@dataclass
class ObjectEvidence:
    e: float; alpha: Distribution             # 存在后验 / 关联后验
    xi: SE3Distribution; B: Occupancy
    cls: str; afford: FrozenSet[str]; tau: Provenance
    def risk(self):
        return SceneRisk(P_miss=1-self.e, P_false=self.e*(1-self.prec),
                         P_assoc_err=entropy(self.alpha),
                         pose=norm(self.xi.cov), rel=0.0)

# IP-305/306：共享隐变量条件并联（COND-PAR）
def cond_par(a_ev, b_ev, shared, audit):
    if not audit.sufficient(shared, a_ev, b_ev):        # E_A ⟂ E_B | S ?
        return conservative(a_ev, b_ev, 'SHARED_LATENT_UNRESOLVED')
    if not audit.cond_conformal(a_ev, b_ev, shared):     # 条件残差在集内？
        return conservative(a_ev, b_ev, 'COND_AUDIT_FAIL')
    if audit.same_provenance(a_ev, b_ev):               # 共同幻觉闸门
        return veto(a_ev, b_ev, 'COMMON_HALLUCINATION')
    rho = audit.cond_corr(a_ev, b_ev, shared)
    if abs(rho) >= RHO_MAX:
        return conservative(a_ev, b_ev, 'COND_CORR_HIGH')
    return total_variance(fuse(a_ev, b_ev, rho), shared)  # 积分 S 的后验不确定性

# IP-307：干预 regime 下的 do-conformal
class RegimeConformal:
    def cover(self, regime, r):
        if regime not in self.envelope: return self.conservative_bound(r)
        if self.e_test(regime).shifted:  return self.conservative_bound(r)
        return self.sets[regime].covers(r)

# IP-308：协作双通道反作用
def coop_reflex_step(arms, a_joint, state, budget):
    total = 0.0
    for i in arms:
        chi_vis, chi_world = arms[i].ec.chi_coop(a_joint)
        c = arms[i].reflex_vis(state[i], chi_vis) + arms[i].reflex_world(state, chi_world)
        if not (arms[i].safe_set & chi_vis.safe & chi_world.safe): return None, total
        total += c
    total -= budget.redundancy_discount(state)            # 扣除信息冗余 II<0
    if budget.spent + total > budget.B_coop: return None, total
    return update_state(state, a_joint), total

# IP-309：交接否决门
def handover_gate(obj_A, obj_B, S, regime, calib):
    if S.id == 'unidentifiable': return False, 'S_UNRESOLVED'
    if not calib.cond_conformal(obj_A, obj_B, S): return False, 'SCENE_DISAGREE'
    if obj_A.pose_unc > TAU_POSE or obj_B.pose_unc > TAU_POSE: return False, 'POSE_UNC'
    if not (obj_A.afford & obj_B.afford): return False, 'NO_COMMON_AFFORDANCE'
    if regime not in calib.envelope: return False, 'REGIME_UNSUPPORTED'
    return True, 'OK'

# IP-310/311：协作证书 + 协作场景理解规划 + 主闭环
def J_COOP(arms, mreg_s, slc, icp, hov):
    return (J_MOD(arms['A']) & J_MOD(arms['B']) & slc.valid()
            & icp.covers_all_regimes() & hov.decidable() & mreg_s.audit())

def cooperative_scene_plan(scene, arms, budget):
    def J(a):
        ig = joint_info_gain(scene, arms, a)               # 含交互信息 II
        u_next = sum(m.ec.chi_coop(a).expected_scene_u(scene) for m in arms)
        return ig - LAM_S * u_next - coop_reflex_cost(arms, a)
    return optimize_joint_under_reg(J, union_action_space(arms), horizon=0.5)

def COOPSCENE_round(M, obsA, obsB, depthA, depthB):
    g_A = M.sgcA.update(depthA, obsA, M.shared)
    g_B = M.sgcB.update(depthB, obsB, M.shared)
    if g_A.assoc_unresolved: g_A = relations_stub(g_A)
    if M.clock.due_metric():
        G = M.fuse.cond_par(g_A, g_B, M.shared, M.audit)
        s_post = M.slc.update(M.shared, G)
        a_star = cooperative_scene_plan(G, M.arms, M.budget)
        ok, why = handover_gate(G.obj('A'), G.obj('B'), s_post, M.regime, M.icp)
        if M.intent_handover and not ok: M.arms.hold(why)   # HOV 非补偿
        s2, cost = coop_reflex_step(M.arms, a_star, M.state, M.budget)
        if s2 is not None: M.execute(a_star, s2)
        M.icp.test_regime(M.regime)
        M.snapshot.write(G, s_post, a_star, M.regime)
    snap = M.snapshot.read_latest()
    kA, kB = M.ctrl.compose(snap, M.arms)                   # 臂-臂避碰 + 证据风险 λ
    return kA, kB, J_COOP(M.arms, M.mreg_s, M.slc, M.icp, M.hov)
```

## 4. 推导（引理 38–44，定理 30–33）

**引理 38（对象级风险的分布无关控制）** 可交换校准 + RCPS 选阈值，使经验风险 ≤ β 的概率 ≥ 1−δ；场景风险是向量，多项联合控制必须用并集界或对联合风险做单次控制，不能独立校准后相乘。系：**场景风险不可能压成单个 u。**

**引理 39（条件并联缩窄合法性）** `E_A ⟂ E_B | S` 且 S 充分 ⇒ 条件覆盖率逐 S 成立；全方差公式给出 `u_out² = E_S[u_fuse²] + Var_S(∂u_fuse/∂S) ≥ E_S[u_fuse²]`，把 Ŝ 当已知量会系统性低估。系：**条件独立不是免费缩窄，必须为「不知道 S」付费。**

**引理 40（隐藏耦合覆盖亏损可检出）** 真结构 `E_A ← S → E_B` 被按边际独立融合时，方差低估量是 S 诱导边际相关的单调函数；把 S 显式入图后条件残差不再含该相关，审计可区分真假独立。系：**R73 风险 #5 从「无法检测」变为「可注册可检验」。**

**引理 41（干预 regime 覆盖迁移）** 包络 ℰ_int 内机制不变（A115）且支撑非空 ⇒ do-conformal 按 regime 条件覆盖；跨 regime 亏损 ≤ ε_regime(支持距离)；包络外无保证，必须回退。系：**「交接前先问该 regime 校准过吗」是可证伪检查。**

**引理 42（协作主动感知有限停止）** 联合 IG 次模 + 正成本 ⇒ 贪心有限停止 n* 且增益 ≥ (1−1/e)OPT；`II<0` 过强时重分配角色恢复次模性。系：**两臂不是观测越多越好，冗余必须显式扣预算。**

**引理 43（交接安全界）** HOV 全条件满足 ⇒ 跌落概率 ≤ 由条件 conformal 与位姿阈值联合校准的上界；任一失败即 VETO，不存在「歧义下松手」的执行路径。

**引理 44（场景降级零级联）** 关系 stub 清关系不产生对象证据、单臂 stub 不参与 COND-PAR ⇒ 不污染他臂后验；由 R73 引理 35 与定理 29 逐指令退化，安全侧只增不减。

**定理 30（COOPSCENE 严格包含 MODGAUGE）** `|O|=1, R=∅, S=∅, regime={空干预}, 交接关闭` ⇒ SGC→EC、COND-PAR→PAR、CCR→χ_R、HOV 恒真、J_COOP→J_MOD；逐指令等于 R73，再退化等于 R72/R71/R68。**安全单调不减。**

**定理 31（协作证书有效性 ⇒ 双机安全界）** 在 A114（S 充分性）与 A115（包络内机制不变）下，Valid(J_COOP) ⇒ 两臂 J_MOD 有效 ∧ 跨臂条件独立已认证 ∧ regime 覆盖 ∧ 交接门可判定 ∧ 联合预算闭合 ⇒ (臂-臂碰撞 + 交接跌落 + 场景灾难误判) 联合风险 ≤ ε_coop。**证明重量在 A114/A115 与 provenance 独立性：即「共享的 S 是否真的是那个 S」。**

**定理 32（无免费协作：条件组合单调性）** S 不可识别或审计失败 ⇒ `u_out ≥ max(u_A,u_B)`；即使最有利，缩窄量受条件覆盖率与 S 后验熵约束，且不低于路径输入的单调函数。不存在「两臂一致就凭空变好」的路径。

**定理 33（不可识别共享隐变量的安全退化）** `id(S)=unidentifiable` 或充分性证书失效 ⇒ COND-PAR 强制退化为 R73 保守 PAR，对应跨臂边降级为无缩窄；由定理 30 仍满足 MODGAUGE 全部安全性质。**不可识别不是错误，而是安全回退。**

## 8. 本轮最大风险

**一句话**：COOPSCENE 把「共享」变成一等公民，却把安全的证明负担压在「**共享隐变量 S 的可识别性与充分性**」上——如果 S 未被正确识别（两臂的环境隐变量根本不是同一组，或 S 只是一个统计拟合），或者两臂通过同一物理来源（同型号相机、同一光源、同一标定链）产生**共同幻觉**，那么 COND-PAR 会把「共享的错误」认证为「条件独立的一致证据」，do-conformal 又会在未覆盖的干预 regime 中给出虚假覆盖率；系统会以两份互相印证的证书、一条一致的场景图、一份完整的审计日志，**协同地把同一个错误世界执行下去**——单臂时是「自信地错」，双臂时是「**一致地、可复现地、经过交叉验证地错**」。

次级风险与缓解：
1. **S 不可识别/误设** → 多候选 S + 可证伪检验（E399/E400）+ 不可识别强制回退（定理 33）。
2. **开放世界风险控制失效** → unknown 弃权 + 联合风险单次校准（引理 38）+ 高风险人工确认。
3. **关联组合爆炸** → top-K + 图上限（定义 398）+ 增量关联；超限触发关系 stub。
4. **干预包络过窄** → 在线安全扩展（受 RTA/HOV 约束）+ 包络外保守回退，报告协作可用率。
5. **交接门过保守致停滞** → 用消歧动作而非降门槛；停滞率作预注册指标。
6. **通信丢失/带宽** → 有损融合 + conformal 降级到独立保守；丢包率进证书校验。
7. **共同幻觉/对抗** → provenance 独立性 + 物理一致性 VETO + 单源不定案。
8. **C4–C6 过拟合** → 预注册 + SEAL-COOP + 三方复现（E412）；只认预注册指标。
