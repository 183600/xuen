### 第 1 轮灵感驱动研究记录（承接 CADVS v30）

**灵感词**：意图识别、个性化交互

**直觉与动机**：

CADVS 已经把「安全 / 可行」做成了十二证 + 时序监控，但它默认了一个隐含前提：**控制目标 z 是已知且中性的**。真实人机系统里，证书只能证明「这个动作不会越过安全边界」，不能证明「这个动作是用户此刻真正想要的」。把意图识别与个性化交互引入后，问题从「如何在安全集内执行」变成「如何在意图不确定性与用户差异下，选择正确的安全集与正确的交互方式」。

1. **意图识别不是分类，而是带覆盖保证的隐状态估计**。语言、手势、注视、遥操作、历史偏好只是证据 E_t；真实意图 z =（目标 g，风格 ψ，约束 c）不可直接观测。分类器输出一个标签不够，必须输出后验 q_t(z)、校准的 credible set C_δ、可辨识性（Fisher 信息 / 有效秩）、OOD 分数与时效窗口。理由：**高置信错误比低置信正确更危险**；只有集合级证书才能把「识别错误」转成「保守控制 / 主动询问」，而不是静默执行错目标。

2. **个性化不是放宽安全，而是在证书内的偏好选择**。操作者的「快一点 / 靠近一点 / 少解释」只应改变安全集内部的代价排序、控制权分配和解释粒度，不能改变硬安全边界。把用户画像 u 作为先验，用 KL 信任域约束个性化策略 π_φ 相对群体策略 π_0 的偏移；否则个性化会退化成「回音室 + 安全侵蚀」。

3. **交互本身是一个带成本的控制动作**。澄清问题、预览、要求示范都会消耗注意力，并可能反过来改变人的意图。只在「意图不确定性对当前决策的风险有实质影响」时询问，即 VoI(q) = 期望风险降低 − λ·认知成本 > 0；把「问不问 / 问什么 / 何时问」纳入闭环，而不是固定频率确认。

**关键洞见**：安全证书与意图证书是两把不同的钥匙——安全证书回答「能不能做」，意图证书回答「该不该做 / 为谁做 / 怎么做」。HICAS 采用**双钥匙 + 鲁棒集合 + 有界个性化**：意图只负责在安全包络内选目标与风格，个性化只在信任域内改偏好，交互只在信息价值为正时发生。这样意图错误最多导致「保守 / 询问 / 回退」，而不会导致「平稳地执行错误目标」。

**形式化目标（增量）**：
1. 定义意图证书 IC_t = (q_t, C_δ, ĥ_t, m_t, ECE_t, I_F,t, OOD_t, τ_ttl, prov)，其中 C_δ 用 split conformal 给出 (1−δ) 覆盖。
2. 定义意图鲁棒安全集 S(C_δ) = S_CADVS ∩ ⋂_{z∈C_δ} S_z，控制器对 C_δ 内所有意图满足约束。
3. 定义个性化信任域：D_KL(π_φ(·|x,z) ‖ π_0(·|x,z)) ≤ ε(x,z)，且 π_φ 的输出必须经安全过滤器投影。
4. 定义控制权分配 α_t 与澄清策略 q* = argmax_{q∈Q} [ΔR_t(q) − λκ(q)]，带查询预算 B 与疲劳惩罚。
5. 证明：在 conformal 覆盖与安全过滤成立时，Exec_HICAS ⊆ Exec_CADVS，真实意图违例概率 ≤ δ + ε_CADVS；个性化相对群体策略的性能偏差 ≤ L√(ε/2)（有界代价 L），因此只有超过该界的偏好收益才可信。
6. 实验验证：相较 CADVS，预期任务成功率 +15~25%、偏好满足度 +30%，安全违例不增加；消融显示无信任域个性化使违例 >2×，无 VoI 澄清使询问次数 +40%。

**本轮最大风险**：**意图的「自信地错」与个性化的回音室耦合**——在分布外，conformal 的边际覆盖可能失效，识别器仍给出小而错的 C_δ；个性化又依据这个错误意图不断强化偏好，系统会以合法证书、平滑交互执行错误目标，而且越用越「顺手」，比显式不确定 / 拒绝更危险。

## 0. 定位与新增模块（在 IP-473~477 / CADVS v30 基础上扩展到 HICAS v31）

**直觉先行**：CADVS 的证书回答「动作是否安全」，HICAS 增加第二把钥匙回答「动作是否属于此刻这个人真正想要的目标与风格」。关键设计不是把意图识别做得更准，而是让系统在**意图可能错**时仍然安全：意图表示为带覆盖保证的集合，而非单点标签；个性化被限制在安全包络内的偏好选择；交互被建模为带认知成本的信息获取动作。形式化上，HICAS = CADVS ∪ MICK ∪ PIPG ∪ IRSAM ∪ VoICS ∪ PDPM，目标 `Exec_HICAS ⊆ Exec_CADVS`，即**个性化与意图层只能收缩/重排安全动作，不能扩张硬安全边界**。

| 编号 | 名称 | 类型 | 关键改进（相对 CADVS v30） |
|---|---|---|---|
| IP-478 | Multimodal Intent Certificate Kernel (MICK) | 意图证书层 | 多模态后验 + split conformal credible set + 可辨识性 / OOD / 时效；意图不再是标签而是可消费证书 |
| IP-479 | Personalized Interaction Profile Governor (PIPG) | 个性化治理 | 用户画像作为先验；逐状态 KL 信任域投影；控制权 α 与解释粒度个性化；反回音室探索；画像本地化 |
| IP-480 | Intent-Robust Shared-Autonomy MPC (IRSAM) | 鲁棒规划层 | 对 C_δ 内所有意图做场景鲁棒 MPC；目标代价按 q_t 期望；不可行时询问/安全保持而非硬执行 |
| IP-481 | Value-of-Information Clarification Scheduler (VoICS) | 主动交互层 | 以期望决策风险降低 / 认知成本选择澄清问题；查询预算 + 疲劳 + 反应性意图建模 |

**运行时集成**：在 RCANG 的 7 节点图上新增 3 个节点——`IntentNode`（10–30Hz，发布 `/cert/intent`）、`ProfileNode`（与置信/风险相关的低频更新，发布 `/cert/profile`）、`ClarifyNode`（事件驱动，发布 `/interaction/query`）。意图层与控制层**异步**：控制环 200–500Hz 继续消费 CADVS 证书；意图证书带 TTL，过期则进入 `SAFE_HOLD / ASK`，不允许用陈旧意图直接驱动高频控制。

## 2. 关键算法骨架

### IP-478 Multimodal Intent Certificate Kernel (MICK)

```python
@dataclass(frozen=True)
class Intent:
    goal: str                 # 例如 'fetch_cup' / 'handover' / 'guide_to_door'
    style: tuple[tuple[str, float], ...] = ()        # (('speed', 0.8), ('force_max', 12.0), ...)
    constraints: tuple[tuple[str, str], ...] = ()    # (('contact', 'palm_only'), ...)

@dataclass
class IntentCertificate:
    q: dict[Intent, float]
    credible_set: list[Intent]
    delta: float
    entropy: float            # 归一化
    margin: float
    ece: float
    fisher_trace: float
    ood: float
    t_stamp: float
    ttl: float
    provenance: str           # 模型版本 + 校准集 ID + 模态可用性

    def fresh(self, t_now: float) -> bool:
        return (t_now - self.t_stamp) <= self.ttl

@dataclass
class MultimodalIntentCertificateKernel:
    """MICK：多模态后验 → conformal 集合 → 意图证书；不在本模块做控制决策"""
    delta: float = 0.10
    ttl: float = 0.150
    min_fisher: float = 0.25
    max_ood: float = 0.30
    h_max: float = 0.65
    margin_min: float = 0.15
    max_set_size: int = 5

    def __post_init__(self):
        self.encoder = MultimodalEncoder()       # 语言/手势/注视/遥操作/示范
        self.temperature = nn.Parameter(torch.ones(()))
        self.conformal_qhat = None               # 校准集上的 (1-δ) 分位数
        self.prev_q = None
        self.change_detector = KLChangeDetector()

    def infer(self, evidence: Evidence, t_now: float) -> IntentCertificate:
        logits = self.encoder(evidence) / self.temperature.clamp_min(1e-3)
        q = softmax(logits)
        # 1) split conformal：非一致性分数越低越可能属于真实意图
        scores = {z: 1.0 - q[z] for z in q}      # 可用 APS / RAPS 替代
        qhat = (self.conformal_qhat if self.conformal_qhat is not None
                else self._top_k_quantile(scores, self.delta))
        C = [z for z, s in scores.items() if s <= qhat]
        if not C:                                 # 空集：退回 top-1 并标记低置信
            C = [max(q, key=q.get)]
        if len(C) > self.max_set_size:            # 效率保护：保留后验最高的 max_set_size 个
            C = sorted(C, key=q.get, reverse=True)[:self.max_set_size]
        # 2) 可辨识性：后验对意图嵌入的敏感度（Fisher 迹）
        fisher = self._fisher_trace(logits, q)
        # 3) 时序一致性：意图突变检测；突变时缩短 TTL 并扩大 δ
        drift = self.change_detector.update(q, self.prev_q)
        ttl = self.ttl if drift < 0.2 else max(0.05, self.ttl * 0.5)
        self.prev_q = q
        # 4) 诊断量
        p = torch.tensor(list(q.values()))
        entropy = float(-(p * p.clamp_min(1e-9).log()).sum() / math.log(len(q)))
        top2 = torch.topk(p, k=min(2, len(p))).values
        margin = float(top2[0] - top2[1]) if len(top2) > 1 else 1.0
        return IntentCertificate(
            q=q, credible_set=C, delta=self.delta,
            entropy=entropy, margin=margin,
            ece=self._online_ece(), fisher_trace=fisher,
            ood=self._ood_score(evidence), t_stamp=t_now, ttl=ttl,
            provenance=self._provenance(evidence),
        )

    def gate(self, ic: IntentCertificate) -> tuple[str, str]:
        """返回 ('RUN'|'ASK'|'SAFE_HOLD', reason)"""
        if not ic.fresh(time.time()):
            return 'SAFE_HOLD', 'intent_stale'
        if ic.ood > self.max_ood:
            return 'ASK', 'ood'
        if ic.entropy > self.h_max or ic.margin < self.margin_min:
            return 'ASK', 'ambiguous'
        if ic.fisher_trace < self.min_fisher:
            return 'ASK', 'unidentifiable'
        return 'RUN', 'ok'

    def cert_payload(self, ic: IntentCertificate) -> CertMsg:
        return CertMsg(
            cid='kc_intent_valid',
            payload={'credible_set': [asdict(z) for z in ic.credible_set],
                     'entropy': ic.entropy, 'margin': ic.margin,
                     'fisher': ic.fisher_trace, 'ood': ic.ood,
                     'delta': ic.delta, 'ttl': ic.ttl, 'prov': ic.provenance},
            t=ic.t_stamp, delta_t_val=ic.ttl, src='intent_node')
```

**设计要点**：
- conformal 的覆盖保证依赖**可交换性**；在线部署用 weighted/online conformal 维护 `qhat`，并在 PDPM 告警时主动放大 `delta`（宁可多问，不可自信地错）。
- `C_δ` 不是「最可能的几个意图」，而是「在 (1−δ) 频率下包含真实意图的集合」；空集/过小集合是告警信号，不是自信信号。
- `I_F,t` 与 `OOD_t` 把「模型不确定」与「数据不熟悉」分开：前者可通过询问降低，后者应直接降权/扩大集合。

### IP-479 Personalized Interaction Profile Governor (PIPG)

```python
@dataclass
class OperatorProfile:
    uid: str
    theta: np.ndarray          # 偏好嵌入（速度/距离/解释深度/主动性）
    competence: float          # 0..1，在线估计
    trust: float               # 0..1，自报 + 行为校准
    risk_tolerance: float      # 仅在认证安全边界内生效
    communication: str         # 'terse' | 'verbose' | 'visual'
    version: int = 0
    local_only: bool = True    # 画像不出设备；日志差分隐私

@dataclass
class PersonalizedInteractionProfileGovernor:
    eps_base: float = 0.05
    alpha_min: float = 0.25
    alpha_max: float = 0.95
    exploration: float = 0.05

    def personalize(self, x, z, q, profile: OperatorProfile) -> Policy:
        logits_0 = self.population_policy.logits(x, z)
        logits_phi = self.preference_head(x, z, profile.theta)
        eps = self.eps_base * (1.0 - self.risk(x, z))   # 风险越高，信任域越窄
        logits_phi = self.project_kl_ball(logits_phi, logits_0, eps)
        return Policy(logits=logits_phi, eps=eps)

    def project_kl_ball(self, logits_phi, logits_0, eps):
        """在 logits 空间插值 π_τ = softmax(logits_0 + τ·Δ)；
        τ=0 时 KL=0，二分 τ 使 KL(π_τ‖π_0) ≤ eps。"""
        delta = logits_phi - logits_0
        lo, hi = 0.0, 1.0
        for _ in range(20):
            mid = (lo + hi) / 2
            if kl_divergence(softmax(logits_0 + mid * delta), softmax(logits_0)) <= eps:
                lo = mid
            else:
                hi = mid
        return logits_0 + lo * delta

    def authority(self, ic: IntentCertificate, risk: float,
                  workload: float, profile: OperatorProfile) -> float:
        """α=1 全自主；α=0 全人类。风险/疲劳/低能力时让渡控制权。"""
        x = np.array([ic.margin, 1 - ic.ood, ic.fisher_trace,
                      1 - risk, profile.competence, profile.trust,
                      1 - workload])
        w = np.array([1.2, 1.0, 0.6, 1.8, 0.8, 0.5, 0.7])
        alpha = 1.0 / (1.0 + np.exp(-(w @ x - 2.0)))
        # 反回音室：低风险时保留少量探索，避免偏好锁死
        if risk < 0.2 and random.random() < self.exploration:
            alpha = min(alpha, 0.7)
        return float(np.clip(alpha, self.alpha_min, self.alpha_max))

    def explanation_depth(self, ic, profile) -> int:
        base = 1 if profile.communication == 'terse' else 3
        uncertainty = max(ic.entropy, 1 - ic.margin, ic.ood)
        return int(np.clip(base + round(4 * uncertainty), 1, 6))

    def update(self, profile: OperatorProfile, feedback: Feedback):
        """带信任域的画像更新；不是无约束 RLHF。"""
        grad = self.preference_grad(profile, feedback)
        candidate = profile.theta + 0.1 * grad + 0.01 * np.random.randn(*profile.theta.shape)
        profile.theta = self.project_to_profile_ball(candidate, self.population_mean)
        profile.competence = np.clip(profile.competence + 0.05 * feedback.success - 0.02 * feedback.override, 0, 1)
        profile.version += 1
        return profile
```

**设计要点**：
- 个性化只改变**安全集内部的排序**；硬安全由 IRSAM 的约束和 CADVS 安全过滤器共同保证。
- `risk_tolerance` 不能映射为「越过证书」；最多映射为「在证书给定的速度/距离区间内取更激进的值」。
- 探索率用于打破回音室：用户反复选择同一风格时，系统仍偶尔展示不同但安全的方案，避免偏好被自身推荐塑造成「伪偏好」。

### IP-480 Intent-Robust Shared-Autonomy MPC (IRSAM)

```python
@dataclass
class IRSAM:
    horizon: int = 20
    dt: float = 0.02
    n_scenarios: int = 24
    lambda_style: float = 0.3
    lambda_authority: float = 0.1

    def solve(self, x0, ic: IntentCertificate, profile: OperatorProfile,
              human_cmd, cert_agg) -> Plan | Infeasible:
        # 1) 从 q_t 采样场景，并强制包含 C_δ 中每个离散意图（若有）
        scenarios = self.sample_scenarios(ic.q, ic.credible_set, self.n_scenarios)
        # 2) 目标：期望任务代价 + 风格代价（个性化只进代价，不进硬约束）
        def objective(traj, u_seq):
            task = sum(expectation_over(ic.q, lambda z: self.task_cost(traj, z))
                       for _ in range(self.horizon))
            style = sum(self.style_cost(u, z, profile.theta) for u, z in zip(u_seq, scenarios))
            return task + self.lambda_style * style
        # 3) 约束：对 C_δ 中所有场景（场景近似）都满足任务谓词与安全约束
        constraints = []
        for z in scenarios:
            constraints += [
                lambda x, u, z=z: self.task_predicate(x, z) >= 0,
                lambda x, u, z=z: self.control_barrier(x, u, z) >= 0,
                lambda x, u, z=z: self.dynamics_residual(x, u, z) <= self.tol,
            ]
        plan = self.scenario_mpc(x0, objective, constraints,
                                 horizon=self.horizon, n_scenarios=len(scenarios))
        if plan is None:
            return Infeasible(reason='intent_robust_infeasible',
                              suggested_query=self.which_constraint_is_tight(scenarios))
        # 4) 控制权融合：α 由 PIPG 给出；人类输入也经同一安全过滤器
        alpha = self.pipg.authority(ic, risk=self.risk(x0, cert_agg),
                                    workload=self.workload, profile=profile)
        u_nom = alpha * plan.u[0] + (1 - alpha) * human_cmd.u
        u_safe = self.safety_filter.project(u_nom, x0, cert_agg, ic.credible_set)
        if u_safe is None:
            return Infeasible(reason='safety_filter_infeasible')
        return Plan(u=u_safe, horizon=plan, alpha=alpha, intent=ic)
```

**场景近似说明**：若 `Z` 离散且 `|C_δ|` 小，直接枚举 `C_δ`；若连续，则从 `q_t` 截断到 `C_δ` 后采样，并用 scenario optimization 的样本复杂度选择 `n_scenarios`。工程上把 `C_δ` 的离散支撑、最坏场景和 `q_t` 高密度场景混合采样，避免只采到后验中心而漏掉尾部意图。

**安全过滤器**：`u_safe = argmin_u ‖u − u_nom‖² s.t. x_{k+1}=f(x_k,u), h(x_k,u,z) ≥ 0, ∀z∈C_δ`；若不可行，则**不输出激进动作**，转入 `ASK` 或 `SAFE_HOLD`。这一步是 `Exec_HICAS ⊆ Exec_CADVS` 的算法锚点。

### IP-481 Value-of-Information Clarification Scheduler (VoICS)

```python
@dataclass
class QueryCandidate:
    kind: str                 # 'confirm_goal' | 'ask_preference' | 'show_preview' | 'request_demo'
    cost: float               # 认知成本 κ(q)
    response_model: Callable   # p(y | q, z, profile)（含反应性：询问会改变意图）
    partition: Callable        # 该查询对 C_δ 的区分能力（用于最小充分询问）

@dataclass
class VoICS:
    budget: int = 2
    tau: float = 0.05          # 净收益阈值
    lam: float = 1.0           # 初始认知成本权重
    refractory: int = 3        # 询问后至少保持的步数

    def select(self, ic: IntentCertificate, state, risk_fn,
               profile: OperatorProfile, fatigue: float) -> QueryCandidate | None:
        if self.used >= self.budget or self.cooldown > 0:
            return None
        lam = self.lam * (1.0 + fatigue)   # 疲劳时更不愿打扰
        best, best_net = None, -float('inf')
        for q in self.candidates():
            # 期望风险降低：R(q) - E_y R(q_y)
            R_before = self.decision_risk(ic.q, state, risk_fn)
            R_after = 0.0
            for y, p_y in q.response_model(ic.q, profile):
                q_y = self.bayes_update(ic.q, q, y)
                R_after += p_y * self.decision_risk(q_y, state, risk_fn)
            voi = R_before - R_after
            # 只问「能改变动作」的问题：若所有候选动作风险相同，VoI≈0
            net = voi - lam * q.cost
            if net > best_net and self.is_minimal_sufficient(q, ic.credible_set):
                best, best_net = q, net
        if best is not None and best_net > self.tau:
            self.used += 1
            self.cooldown = self.refractory
            return best
        return None

    def is_minimal_sufficient(self, q, C) -> bool:
        """优先选择能把 C 切成两个非空、且风险差异显著子集的查询；
        避免'为了确认而确认'的无效问题。"""
        parts = q.partition(C)
        return len(parts) >= 2 and all(parts) and self.risk_gap(parts) > self.tau
```

**设计要点**：
- 询问不是免费的标签获取，而是**决策风险的一阶下降**；如果问完不改变动作，VoI 为 0，不应问。
- 询问本身会改变人的意图（例如「你要 A 还是 B？」会诱导选择），因此 `response_model` 必须包含反应性项，不能把人的回答当作独立同分布标签。
- 用滚动时域而非一次性规划：多步查询价值通常非子模，贪心不保证全局最优；每步重算 VoI 更稳健。

### IP-482 Personalization Drift & Poisoning Monitor (PDPM)

```python
@dataclass
class PersonalizationDriftMonitor:
    h_d: float = 5.0
    k: float = 0.5
    window: int = 200

    def __post_init__(self):
        self.cusum = 0.0
        self.snapshot = None
        self.alarm = False

    def update(self, ic: IntentCertificate, profile: OperatorProfile,
               override: bool, inconsistency: float, task_failure: bool) -> str:
        # 无真实 z*，用可观测代理：人工接管、重复询问、任务失败、行为似然
        behavior_nll = -self.behavior_loglik(profile, ic)       # 偏好模型对后续动作的惊讶
        calib_proxy = 1.0 if (ic.margin < 0.1 or ic.ood > 0.3) else 0.0
        e = (0.8 * calib_proxy + 0.7 * float(override) +
             0.8 * max(0.0, behavior_nll - 0.693) + 0.6 * inconsistency +
             0.5 * float(task_failure))
        self.cusum = max(0.0, self.cusum + e - self.k)
        if self.cusum > self.h_d and not self.alarm:
            self.alarm = True
            return self.on_alarm()
        return 'OK'

    def on_alarm(self) -> str:
        """分级响应：先冻结画像与扩集，再回滚到稳定快照，最后人工审计。"""
        self.freeze_profile = True
        self.inflate_delta = True          # 下一次 MICK 使用更大 δ
        self.rollback_to_last_snapshot()
        return 'DRIFT_ALARM'
```

**设计要点**：
- 漂移检测不能依赖真实意图标签；使用**人工接管、重复确认、任务失败、后续动作似然**作为弱监督代理。
- 告警不是「重启一切」，而是分级：冻结画像 → 扩大意图集合 → 回滚到上一个稳定快照 → 请求人工审计；避免因一次误报破坏用户体验。

### HICAS 统一执行流（异步双环）

```python
def hicas_step(robot_state, sensor_data, human_cmd, profile, t_now):
    """
    快环：CADVS 安全证书 (200–500Hz)
    慢环：MICK 意图证书 (10–30Hz) + VoICS 澄清 (事件驱动)
    """
    # 0) 安全钥匙：沿用 CADVS 聚合证书
    cert_agg = wait_for_topic('/cert/aggregated', timeout=0.005)
    if cert_agg is None or not cert_agg.all_passed:
        return fallback_to_teacher(robot_state, sensor_data, reason='cert_agg_fail')

    # 1) 意图钥匙：必须新鲜；过期时不允许用旧意图驱动控制
    ic = intent_bus.latest()
    if ic is None or not ic.fresh(t_now):
        return ControlOutput(np.zeros(6), path='safe_hold',
                             certs=cert_agg, reason='intent_stale')

    # 2) 意图门控：不确定/不可辨识/OOD 时先问，不猜
    gate, reason = mick.gate(ic)
    if gate == 'ASK':
        query = voics.select(ic, robot_state, risk_fn=cadvs_risk,
                             profile=profile, fatigue=profile.workload)
        if query is not None:
            return ControlOutput(np.zeros(6), path='ask',
                                 certs=cert_agg, query=query, reason=reason)
        # 无法询问：用保守中性先验，扩大 δ 后进入鲁棒规划
        ic = mick.conservative_fallback(ic, inflate=0.15)

    # 3) 意图鲁棒规划 + 个性化代价
    plan = irsam.solve(robot_state, ic, profile, human_cmd, cert_agg)
    if isinstance(plan, Infeasible):
        return ControlOutput(np.zeros(6), path='safe_hold',
                             certs=cert_agg, reason=plan.reason)

    # 4) 漂移监控（在后台消费，不阻塞控制）
    drift = pdpm.update(ic, profile, override=human_cmd.override,
                        inconsistency=human_cmd.inconsistency,
                        task_failure=robot_state.task_failed)
    if drift == 'DRIFT_ALARM':
        return ControlOutput(np.zeros(6), path='rollback',
                             certs=cert_agg, reason='drift')

    # 5) 输出已经是经安全过滤器投影的动作
    return ControlOutput(plan.u, path='hicas',
                         certs=cert_agg, intent_cert=ic,
                         alpha=plan.alpha)
```

## 4. 正确性论证（增量更新）

### 定义 1（意图证书的覆盖有效性）

设校准集与在线样本可交换，非一致性分数 `s(z; E)` 在 calibration set 上取经验 (1−δ) 分位数 `q̂`，构造 `C_δ(E) = {z : s(z;E) ≤ q̂}`。若测试样本与校准集可交换，则
`P(z* ∈ C_δ(E)) ≥ 1 − δ`。
这是 split conformal 的直接结论；`ECE_t` 只是诊断量，不是覆盖保证的来源。

### 引理 32（意图鲁棒集合的覆盖安全性）

**陈述**：若 `C_δ(E_t)` 以概率 ≥ 1−δ 覆盖真实意图 `z*`，且控制器 `u_t` 对 `∀z ∈ C_δ(E_t)` 满足约束 `φ_z(x_t,u_t) ≥ 0`，则
`P(φ_{z*}(x_t,u_t) ≥ 0) ≥ 1 − δ`。

**证明**：事件 `{φ_{z*} < 0}` 蕴含 `z* ∉ C_δ`（因为若 `z* ∈ C_δ`，鲁棒约束保证 `φ_{z*} ≥ 0`）。故其概率不超过 `P(z* ∉ C_δ) ≤ δ`。∎

**工程含义**：不需要相信单点意图分类；只需要相信「集合覆盖」与「集合内鲁棒可行」。代价是保守性：`C_δ` 越大，`S(C_δ)` 越小，越可能不可行，此时必须询问/回退而非硬执行。

### 引理 33（个性化信任域的安全与性能界）

**陈述**：设 `π_0` 为 CADVS 群体策略，`π_φ` 为个性化策略，且对任意 `(x,z)` 有 `D_KL(π_φ(·|x,z) ‖ π_0(·|x,z)) ≤ ε`。若执行前经安全过滤器 `Proj_{S(C_δ)}`，则：
(i) `Exec(π_φ) ⊆ Exec_CADVS`；
(ii) 对任意有界代价 `c ∈ [0,L]`，`|J(π_φ) − J(π_0)| ≤ L√(ε/2)`。

**证明**：(i) 安全过滤器把所有动作投影到 `S(C_δ) ⊆ S_CADVS`，与策略无关。(ii) 由 Pinsker 不等式，`TV(π_φ, π_0) ≤ √(ε/2)`；对偶表示 `|E_{π_φ}c − E_{π_0}c| ≤ L·TV`，得证。∎

**工程含义**：个性化只能在已证明安全的动作集内改变选择；其收益必须超过 `L√(ε/2)` 的统计界，否则不能宣称「个性化有效」。这也是我们拒绝无约束 RLHF 式个性化的形式理由。

### 引理 34（澄清信息的非负价值与短视最优）

**陈述**：给定后验 `q` 与决策损失 `ℓ(a,z)`，定义 `R(q) = min_a E_{z~q} ℓ(a,z)`。对任意查询 `q` 及其观测 `Y`，令 `R̄(q) = E_{Y|q} R(q_Y)`，则 `R̄(q) ≤ R(q)`。因此单步 VoI 非负；只在 `VoI(q) > λκ(q)` 时询问，则每次询问的期望决策损失不增。

**证明**：`R(q) = min_a E_Y E_{z|Y}ℓ(a,z) ≥ E_Y min_a E_{z|Y}ℓ(a,z) = R̄(q)`，其中不等号来自「先取期望再取最小 ≥ 先取最小再取期望」。∎

**限定**：多步查询因风险函数通常非子模，贪心不保证全局最优；HICAS 采用滚动时域重算，并接受「短视最优、长期近似」的工程折中。

### 命题 1（不可辨识意图的误差下界）

**陈述**：若对任意可用证据 `E`，两个意图 `z_1,z_2` 的观测分布满足 `D_KL(P(E|z_1) ‖ P(E|z_2)) ≤ ε`，则任何判别器的平均错误率至少为 `(1 − √(ε/2))/2`。

**证明**：由 Pinsker，`TV(P(E|z_1),P(E|z_2)) ≤ √(ε/2)`；由 Le Cam 两点下界，最小错误率 ≥ `(1 − TV)/2`。∎

**工程含义**：当证据本身不携带信息时，再强的模型也只能猜；唯一正确的动作是扩大 `C_δ`、主动询问或保守回退。这是 HICAS 把「可辨识性」写入意图证书、并在 `I_F,t` 过低时强制 ASK 的理论依据。

### 定理（HICAS 的双钥匙包含性与安全界）

**陈述**：在以下假设下：
(A5) `C_δ(E_t)` 对真实意图 `z*` 有 (1−δ) 覆盖（定义 1 的交换性成立）；
(A6) IRSAM 对 `C_δ` 内所有意图满足任务与安全约束，且输出经 `S_CADVS` 安全过滤器；
(A7) `π_φ` 满足逐状态 KL 信任域 `ε`；
(A8) CADVS 自身的安全违例概率 ≤ `ε_CADVS`。
则：
(i) `Exec_HICAS ⊆ Exec_CADVS`；
(ii) 由意图错误导致的真实目标违例概率 ≤ δ；
(iii) 总安全违例概率 ≤ δ + ε_CADVS（忽略过滤器数值误差与执行延迟）；
(iv) 个性化相对 `π_0` 的任意有界代价差异 ≤ `L√(ε/2)`。

**证明**：(i) 由 A6 的安全过滤器与集合包含关系；(ii) 由引理 32；(iii) 对两个违例事件取并集界；(iv) 由引理 33(ii)。∎

**诚实声明**：上述结论的关键弱点不在证明，而在假设：
- conformal 覆盖是**边际**的，不是条件于用户/场景的；分布漂移会破坏交换性，使实际覆盖低于 1−δ；
- 场景 MPC 是 `C_δ` 的采样近似，不是对连续集合的精确鲁棒保证；
- 安全过滤器本身有求解时间与数值误差，需要 TCVM 纳入证书时延预算；
- 若 `S(C_δ)` 频繁不可行，系统会退化为频繁询问/安全保持，安全性提高但可用性下降。

因此 HICAS 的贡献不是「消除意图错误」，而是把意图错误**转化为可观测、可回退、可询问的证书事件**。

| H5 漂移可检测 | 风格突变后 ≤ 8 episodes 告警；回滚后 ≤ 3 episodes 恢复；负迁移从 ~15% 降至 <5% | 代理信号不足或 CUSUM 阈值失配 |
| H6 消融可区分 | 无 KL 个性化违例 ≥ 2×；无 conformal 违例 ≥ 1.9×；无 VoI 询问 ≥ 2.2×；无 PDPM 负迁移 ≥ 12% | 各组件贡献不显著，需重新设计 |

**统计**：每个条件 ≥ 30 次独立运行（不同随机种子与 persona 顺序），报告均值 ± 95% CI；安全指标用 Wilson 区间；多重比较用 Holm–Bonferroni。**失败判据**：若未见 persona 的 conformal coverage < 85%，或鲁棒不可行率 > 20%，或个性化收益低于 `L√(ε/2)` 的统计界，则本轮核心假设被证伪，应回退到「意图无关 + 保守 CADVS」。

## 6. 已知风险与缓解（增量更新）

| 风险编号 | 描述 | 严重度 | 缓解措施 | 剩余风险 |
|---|---|---|---|---|
| R19–R32 | CADVS v30 全部既有风险 | — | 原样继承十二证、TCVM、MRCC、VLCK 等 | 不变 |
| R33 | **意图的自信地错**（分布外仍给出小而错的 `C_δ`，且边际覆盖失效） | **极高** | 1) split/online conformal + weighted conformal；2) OOD 与 Fisher 门控，低可辨识性强制 ASK；3) PDPM 告警即放大 δ；4) 鲁棒集合 + 安全过滤器；5) 关键任务要求人工确认 | 条件覆盖仍无保证；快速分布漂移下检测有滞后 |
| R34 | **个性化安全侵蚀**（偏好被误映射为放宽安全边界） | 高 | 1) 硬安全与偏好代价严格分层；2) 逐状态 KL 信任域；3) 所有动作经 `S_CADVS` 投影；4) `risk_tolerance` 只在证书区间内调参 | 过滤器求解误差、时延导致瞬时越界 |
| R35 | **回音室 / 偏好锁死**（系统只展示符合画像的方案，塑造伪偏好） | 高 | 1) 低风险时保留探索；2) 定期展示反事实/多样方案；3) 用户可一键重置画像；4) 审计画像对决策的影响 | 长期操纵难以在短实验中发现；需纵向研究 |
| R36 | **询问过载 / 确认疲劳**（VoI 阈值过低导致频繁打扰） | 中 | 1) VoI − λκ 净收益门控；2) 查询预算与 refractory；3) 疲劳感知的 λ 自适应；4) 紧急情况才允许超预算询问 | 高风险 + 高疲劳时仍可能打扰 |
| R37 | **反馈投毒 / 画像漂移**（恶意/不一致反馈污染画像） | 高 | 1) PDPM 多代理 CUSUM；2) provenance + 版本快照；3) 冻结/回滚/隔离；4) 人工审计与差分隐私日志 | 慢漂移可能绕过阈值；拜占庭用户需额外认证 |
| R38 | **意图-控制时标失配**（20Hz 意图证书驱动 200Hz 控制，快速变卦时陈旧） | 中 | 1) TTL + `SAFE_HOLD`；2) 意图突变检测缩短 TTL；3) 变卦时先限速/保持再重规划；4) 人类接管优先 | 突变发生在两个意图周期之间仍有短窗口 |
| R39 | **画像隐私泄露**（偏好/能力/健康相关行为可被推断） | 中 | 1) 画像本地存储、默认不上传；2) 差分隐私日志；3) 可删除/可退出；4) 只上传证书摘要而非原始画像 | 行为侧信道仍可能泄露部分偏好 |

## 7. 本轮最大风险（最终确认）

**一句话**：**意图识别的条件性失准与个性化的自我强化形成闭环**——在分布外，边际 conformal 覆盖仍可能让「小而错」的 `C_δ` 通过，个性化又依据错误意图持续优化偏好，最终系统会以完整证书和平滑交互稳定地执行错误目标，这是一种比不确定性显式拒绝更隐蔽的「语义层虚假安全感」。
