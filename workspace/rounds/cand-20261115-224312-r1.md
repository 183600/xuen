# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「差异化定位」×「轻量化设计」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**轻量证书 + 三值差分定位 + 逐周期重验证**。两个灵感直指 v9 的同一个病根：块证书的可靠性被两件"重"东西绑架——(a) 一个约 40MB 的冻结 LSTM 代理和它离线标定的全局常数 β；(b) 一个由 DA-ML 20 帧滑窗独占的二元信任门。前者让证书只能 5Hz 生成、生成后即冻结；后者让"域偏移"只有一个滞后且单一失效模式的观测通道。本轮把"重"从模型搬到假设：用局部仿射区间证书做 50Hz 可重算的 sound 界，用安全/危险原型的差分定位做与 DA-ML 异构的第二通道，并把"没见过"显式编码为第三值 Unknown。

## 0. 直觉与动机

**灵感 1（轻量化设计 → 轻量的是证书，不是模型）**
直觉：v9 的 β 是一个全局常数，等价于假设"前向模型在任何地方都错得一样多"。这在接触丰富的操作里显然不成立：自由空间很准，贴边/接触时误差突增。把模型做小（蒸馏 LSTM）只是省内存，不解决"β 在需要时失效"。真正的轻量化对象应是**不确定性的表示**：把"点预测 + 全局 β"换成"局部仿射模型 + 随状态变化的区间界"，其代价是 O(d²K) 的矩阵-区间传播，小到可以每个控制周期从当前实测状态重新算一遍。这样证书不再是"5Hz 生成时冻结的一张纸"，而是"50Hz 持续刷新的一个界"。轻量化在这里的含义是：假设更弱（局部误差 ρ_t 而非全局 β）、参数更少（A,B,c,ρ 而非整张网络）、可重算（anytime，粗界永远可用）。

**灵感 2（差异化定位 → 用安全/危险锚点做差分，而不是用单一阈值做绝对判断）**
直觉：v9 的信任域是 Δ_dom < τ_dom 的一维阈值。问题不是阈值选得不好，而是"域偏移"被压缩成一个标量，且这个标量只由 DA-ML 一个 20 帧滑窗产生。差分定位（differential positioning）的启发是：绝对坐标不可靠时，用已知基准站做差分修正。这里把"认证安全轨迹"与"近失/注入故障轨迹"做成两组原型锚点 Z⁺/Z⁻；当前状态嵌入 φ(s) 后，不回答"这是哪"，而回答"离危险锚更近还是离安全锚更近"，即差分裕度 m(s)=d⁻(s)−d⁺(s)。它天然是多场景的（不同原型对=不同失效模式），可路由到不同的局部专家与块长；更重要的是，它是与 DA-ML **异构**的通道：一个看分布散度、一个看几何邻近；一个 20 帧滑窗、一个每周期 O(|Z|d)。

**灵感 3（两个灵感的合流 → 三值定位 + 异构信任门）**
直觉：若只把 m(s) 当第二个阈值，仍会犯"离所有原型都远 = 安全"的错。开放世界里真正危险的是"没见过"：它到危险锚也远，到安全锚也远。所以定位必须是三值的：Safe / Unsafe / Unknown，且 Unknown 不是"噪声/弃权"，而是"无安全证据"，必须触发最保守策略（K_eff=1、强制全模块唤醒）。三值逻辑把 v9 的"安全/不安全"二值世界补上了"未知"这一格；异构信任门把语义（DP）、统计（DA-ML）、数值（AIC 宽度）三条不同失效模式的证据做 AND——任一要求保守，系统就保守。

## 1. 严谨定义（新增定义 540–548）

**定义 540（局部仿射代理 LAM, Local Affine Model）** 在状态 s_t 的邻域内，把前向指标动力学线性化为
```
x_{k+1} = A_t x_k + B_t a_k + c_t + η_k ,   ‖η_k‖_∞ ≤ ρ_t
```
A_t,B_t,c_t 由当前状态处的在线雅可比（或最后一层特征线性化）给出；ρ_t 由留出残差的分位数乘 1.2 安全系数在线估计。与 v9 的全局冻结 LSTM 不同，LAM 是**每周期在局部重新线性化**的：它不是"更准的模型"，而是"可以随状态移动的模型"；误差假设从全局常数 β 变成局部 ρ_t，后者可用一步预测残差在运行时持续校准。

**定义 541（仿射区间证书 AIC, Affine Interval Certificate）** 用区间/仿射算术沿 LAM 传播状态与指标区间，得到
```
g_k ∈ [g_k^L, g_k^U] ,   e_k ∈ [e_k^L, e_k^U]
```
证书在第 k 步有效 ⇔ g_k^L ≥ d_safe ∧ e_k^U ≤ τ_eff ∧ (γ_grasp 区间只含 valid)。证书宽度
```
w_t = max_{k≤K} (g_k^U − g_k^L)
```
AIC 是 **anytime sound** 的：维护松弛序列 I^(0) ⊇ I^(1) ⊇ …，I^(0) 用 d_safe 与最大速度给出解析粗界，恒为真值的过近似；预算内逐级收紧。任何时刻返回的都是 sound 上界（可能很宽）。

**定义 542（安全/危险原型字典 Prototype Dictionary）**
```
Z⁺ = {(z_i, cert_i)}  认证安全轨迹上采集的安全原型
Z⁻ = {z_j}            近失、注入故障、仿真对抗轨迹上的危险原型
```
嵌入 φ: S → R^d（d ≤ 32）由 PCA/随机投影得到，不用大网络。距离 d⁺(s)=min_i ‖φ(s)−z_i⁺‖，d⁻(s)=min_j ‖φ(s)−z_j⁻‖；覆盖度 c(s)=min(d⁺,d⁻)。

**定义 543（三值差分定位 TDP, Tri-valued Differential Positioning）**
```
pos(s) = Safe     ⇔ m(s) ≥ m_min ∧ c(s) ≤ r_cov
       = Unsafe   ⇔ m(s) ≤ −m_min
       = Unknown  ⇔ 其余（含 c(s) > r_cov 的覆盖不足）
m(s) = d⁻(s) − d⁺(s)
```
"差分"在于：绝对距离不可比，用"到安全锚"与"到危险锚"的差来定位；"差异化"在于：不同原型对对应不同场景/失效模式，可路由到不同专家与块长。输出同时携带 m(s)、c(s)、最近原型 id，供解释与日志审计。

**定义 544（异构信任门 HTG, Heterogeneous Trust Gate）**
```
U_t ⇔ pos_t = Safe ∧ Δ_dom(t) < τ_dom ∧ w_t ≤ w_max
```
三条通道分别代表语义（原型几何）、统计（分布散度）、数值（区间宽度），失效模式不同。任一不满足 ⇒ K_eff ← 1；pos_t = Unknown ⇒ 额外强制全模块唤醒。**保守方向是 AND**：只有三通道都给"安全证据"时才允许长块。

**定义 545（场景差异化专家路由 DER, Differentiated Expert Routing）** 每个安全原型 z_i⁺ 绑定一个局部专家 E_i=(A_i,B_i,c_i,ρ_i)。当前取 top-2 专家，预测区间取并：
```
I(s) = I_1 ∪ I_2 ⊕ D_switch
```
若 m(s) < m_switch 则冻结当前专家（不切换），并额外膨胀 D_switch；m_switch>0 与保持周期 H_sw 共同抑制切换抖振。开放安全区 → 长 K；靠近危险原型 → 短 K 与更保守的专家。

**定义 546（逐周期重验证 PVR, Per-cycle Revalidation）** 每个控制周期 t，用当前实测状态 s_t 对剩余动作前缀 a^{k_exec:K} 重新传播 AIC，得到 [g]_{t:K}。若存在 k 使 g_k^L < d_safe 或 w_t > w_max，则本周期末即置 K_eff←1 并切换到 ≤k_exec 的最近中止点。代价 O(d²(K−k_exec))。这把 v9 的"生成时冻结证书"变成"执行时持续证书"。

**定义 547（轻量守卫 LDG，可选）** 把 v9 的中块守卫（证书失效检测 + 停车不变式）蒸馏为深度 2 决策树，附认证误差上界 ε_g；若 ε_g > ε_budget 或输入落在树的支持域外，退回精确守卫。其证书记录在契约表中，不改变语义。

**定义 548（退化与中立元 Neutral Elements）**
```
DP  不可用 ⇒ v^⊥ = Safe（空证据）      ⇒ HTG 逐位退化为 v9 的 Δ_dom/risk 二值门
LIC 不可用 ⇒ 回退 v9 的 β 块证书 + 5Hz 生成（逐位等价）
DER 不可用 ⇒ 单一 v9 前向模型；K_eff 按 v9 定义 539
PVR 不可用 ⇒ 回退 v9 生成时冻结证书
LDG 不可用 ⇒ 精确守卫（语义不变）
```
关键区分：DP **不可用**（注入中性 Safe）是退化，严格等价 v9；DP **可用但输出 Unknown** 是比 v9 更保守的主动判据，不得被当作噪声忽略。

## 2. 研究问题（轮次升级版）

- **Q1（轻量证书的 soundness 边界）**：局部仿射误差界 ρ_t 在接触非线性下如何在线校准？区间传播的包裹效应（wrapping effect）随 K 增长多快，何时应主动收缩 K 而非继续细化？
- **Q2（三值定位的开放世界安全）**：如何标定 r_cov 与 m_min，使 Unknown 既不漏报（假安全）又不淹没系统（效率悬崖）？覆盖不足能否被"主动探针"（有界探索）降低？
- **Q3（异构通道的独立性）**：DP、DA-ML、AIC 三通道的失效何时相关？AND 门的保守性收益是否值得其 liveness 代价？相关性必须实测而不能假设。

## 3. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 轻量区间证书律（LIC）** 块证书必须是"每周期可从实测状态重算"的区间界，而非生成时冻结的点证书；误差假设局部化（ρ_t）；宽度进入信任门；预算不足时返回更宽的 sound 界，而不是返回未经验证的点值。

**P14 三值差分定位律（TDP）** 状态定位取值于 {Safe, Unsafe, Unknown}；Unknown 表示"无安全证据"，触发最保守（K_eff=1 + 全唤醒）；只有 Safe 才允许长块。DP 失效注入中性 Safe 以严格退回 v9，但不得把 Unknown 当噪声。

**P15 逐周期重验证律（PVR）** 证书不跨周期继承信任：每周期用实测状态对剩余前缀重传播；中块违反在当前周期末即被发现，检测延迟从 v9 的 ≤(K−1)Δt 降到 ≤Δt + δ_sensor。

## 4. 与基线的接口（如何退化）

- LIC 失效 / 预算不足 ⇒ 回退 v9 的 β 块证书与 5Hz 生成，等价 v9 决策语义；
- DP 失效 ⇒ 注入 v^⊥=Safe（空证据），HTG 退化为 v9 二值门，逐位等价 v9；DP 正常但 Unknown ⇒ Level-0 保守态（比 v9 更严，非退化）；
- DER 失效 ⇒ 单一 v9 前向模型，K_eff 按 v9 定义 539；
- PVR 失效 ⇒ 回退 v9 生成时证书；
- v9 的 AC/MW/ID 失效 ⇒ 按 v9 五级链继续退化（AC→K=1；MW→手写网关；ID→全模块常开）；
- 全部失效 ⇒ 完整退回 MetricVoiceGauge-OTL-GC-ER v7，再退回 v6。

## 5. 预期贡献

1. **可重算区间证书**：把块证书从"5Hz 冻结点证书 + 全局 β"升级为"50Hz 局部仿射区间证书"，给出 soundness 与包裹效应的显式界，模型权重从约 40MB 降到 <100KB 参数；
2. **三值差分定位**：开放世界中显式建模"未知"，用安全/危险原型锚点构造与 DA-ML 异构的快速域偏移通道，并给出覆盖-精度风险曲线；
3. **逐周期重验证**：把 v9 最危险的"20 帧检测滞后 × 200ms 块"乘积拆成"1 周期重验证 × 剩余前缀"，从机制上消除滞后窗口（但不消除模型设定错误，见风险）；
4. **实验 E571–E590**：覆盖区间含真率、重验证时延、三值校准、通道相关性、接触最坏情况、效率悬崖与端到端任务。

## 6. 本轮最大风险

**一句话**：三值差分定位把"没见过"判为 Unknown 并强制 K_eff=1，这在开放家庭场景里可能长期触发——轻量证书省下的算力被保守性一次性吃回，系统安全却退化成 v8 的逐步模式，形成"安全但不再轻"的效率悬崖。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-LDP**（Metric Voice Gauge with Lightweight interval certificates & Differential Positioning）

> 背景：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮灵感：「差异化定位」×「轻量化设计」
> **继承纪律**：MetricVoiceGauge 九不变式（CVC-闭环、SpatialCert、RT-CVC、FaultCert、PrimitiveGraph、严格退化链、OTL、GCT、ER）全部保留；v8 的 DA-ML/SPR/Cal 与 v9 的 AC/MW/ID 原样继承。新组件一律为**可选增强**：任一环节不可用 ⇒ 注入中立元，严格等价退回 v9（吸收退回 v8），而非行为漂移。

## 0. 核心 IP 设计

| 编号 | 名称 | 类型 | 关键改进（相对 MetricVoiceGauge-ACMD v9） |
|---|---|---|---|
| IP-340–356 | v8/v9 全部模块 | 继承 | 语义不变；AC 的块生成与证书改由 LIC 提供（IP-357），退化链改由 HTG 融合（IP-359） |
| IP-357 | LightweightIntervalCertifier 轻量区间证书器 | 新增核心模块 | 局部仿射 LAM + 仿射算术；**每周期**对剩余前缀重传播；输出 [g^L,g^U] 与宽度 w；取代约 40MB LSTM 与全局常数 β |
| IP-358 | DifferentialPositioner 三值差分定位器 | 新增核心模块 | 32 维轻量嵌入 φ；安全 Z⁺/危险 Z⁻ 原型锚点；差分裕度 m=d⁻−d⁺、覆盖 c=min；输出 Safe/Unsafe/Unknown |
| IP-359 | HeterogeneousTrustRouter 异构信任路由器 | 新增集成模块 | 融合 pos、Δ_dom、w 的 AND 门；Unknown⇒K_eff=1+全唤醒；top-2 专家路由与差异化 K_eff |

**退化链声明（v10 契约化六级，新增 Level-0 保守态）：**
- Level-0（主动保守，非退化）：DP 正常但 pos=Unknown ⇒ K_eff←1、全模块强制唤醒、LIC 用最宽 sound 界；行为比 v9 更保守，但仍在安全集内；
- Level-1：AIC 证书失效或 Δ_dom ≥ τ_dom 或 w > w_max ⇒ K_eff←1，逐步执行，等价 v9 决策粒度；
- Level-2：LIC 不可用 ⇒ 回退 v9 的 β 块证书 + 5Hz 冻结生成；PVR 不可用 ⇒ 回退生成时证书；
- Level-3：DP 不可用 ⇒ 注入 v^⊥=Safe（空证据），HTG 逐位退化为 v9 二值门；
- Level-4：DER 不可用 ⇒ 单一 v9 前向模型；ID 失效 ⇒ 全模块 active、归因冻结，等价 v9 全模块常开；
- Level-5：v9 的 MW 失效 ⇒ 切回 v8 手写网关；v8 的 DA/SPR/Cal 失效 ⇒ 中立元注入（Δ_dom≡0 / risk_SLAM≡0 / sensor_weight≡1），等价 v7；
- Level-6：全失效 ⇒ 完整退回 MetricVoiceGauge-OTL-GC-ER v7，再退回 v6。

## 1. 符号体系增量（定义 540–548）

| 符号 | 含义 |

| LAM_t=(A_t,B_t,c_t,ρ_t) | 状态 s_t 处的局部仿射动力学与局部误差上界 |
| [g_k^L,g_k^U], [e_k^L,e_k^U] | 第 k 步 clearance / effort 的 sound 区间 |
| w_t = max_k (g_k^U−g_k^L) | 证书宽度：区间不确定性的可计算度量 |
| φ: S→R^d, d≤32 | 轻量状态嵌入（PCA/随机投影） |
| Z⁺, Z⁻ | 安全原型 / 危险原型锚点集合 |
| d⁺(s), d⁻(s) | 到最近安全/危险原型的嵌入距离 |
| m(s)=d⁻(s)−d⁺(s) | 差分裕度：正=偏安全，负=偏危险 |
| c(s)=min(d⁺,d⁻) | 覆盖度：到最近任意原型的距离 |
| pos(s)∈{Safe,Unsafe,Unknown} | 三值差分定位 |
| r_cov, m_min, m_switch | 覆盖半径、定位裕度阈、专家切换裕度 |
| U_t | 异构信任门：pos=Safe ∧ Δ_dom<τ_dom ∧ w_t≤w_max |
| w_max | 证书宽度上限，超过即收缩块长 |

**定义 540（局部仿射代理 LAM）** 见想法区。要点：线性化点每周期更新；ρ_t 由一步预测残差的滑动分位数 ×1.2 给出；不是全局模型，不承诺跨域一致。

**定义 541（仿射区间证书 AIC）** 见想法区。区间传播规则：
```
[X+Y] = [X^L+Y^L, X^U+Y^U]
[M·X] = [min(MX^L,MX^U), max(MX^L,MX^U)]   （逐行取端点）
X_{k+1} = A_t·X_k + B_t·a_k + c_t ⊕ [−ρ_t,ρ_t]
```
证书有效 ⇔ 每步 g_k^L≥d_safe ∧ e_k^U≤τ_eff ∧ γ 区间≡valid。anytime 细化：先粗解析界，再按预算加高阶项/更细分段；任何时刻的结果都是 sound 过近似。

**定义 542（原型字典）** 见想法区。Z⁺ 只收认证安全轨迹；Z⁻ 收近失/注入故障/仿真对抗。原型数量 |Z|≈200，单原型存 32 维向量 + 指标证书，总内存 <1MB。

**定义 543（三值差分定位 TDP）** 见想法区。三值映射的几何直觉：Safe 需要"既在覆盖内、又明确偏安全"；Unsafe 只需"明确偏危险"；其余一律 Unknown。Unknown 是安全侧默认值，不是低置信度的 Safe。

**定义 544（异构信任门 HTG）** 见想法区。注意 AND 的保守方向：三通道中任一给不出安全证据就收缩；不做加权平均，避免"两个说安全抵消一个说危险"。

**定义 545（场景差异化专家路由 DER）** 见想法区。top-2 并集 + 切换裕度 + 保持周期 H_sw=10；m(s)<m_switch 时冻结专家并膨胀 D_switch，抑制边界抖振。

**定义 546（逐周期重验证 PVR）** 见想法区。重验证只覆盖剩余前缀，已执行步不计；若 k_exec 已越过最近中止点，则只允许安全停驻。

**定义 547（轻量守卫 LDG，可选）** 深度 2 决策树，输出 {continue, abort}；附认证误差 ε_g。ε_g>ε_budget 或输入越界 ⇒ 精确守卫。LDG 不改变 abort 的语义，只改变判定路径的成本。

# IP-357 LightweightIntervalCertifier：轻量区间证书器
class Interval:
    def __init__(self, lo, hi): self.lo, self.hi = lo, hi
    def __matmul__(self, M):                    # 逐行端点
        lo = M @ self.lo; hi = M @ self.hi
        return Interval(np.minimum(lo, hi), np.maximum(lo, hi))
    def inflate(self, r): return Interval(self.lo - r, self.hi + r)

class LightweightIntervalCertifier:
    def __init__(self, d=12, d_safe=0.15, w_max=0.10, k_safety=1.2):
        self.d, self.d_safe, self.w_max = d, d_safe, w_max
        self.k_safety = k_safety

    def linearize(self, s):                     # 每周期调用，O(d·n_x)
        A, B, c = self.local_jacobian(s)        # 解析/自动微分/有限差分
        rho = self.k_safety * self.residual_quantile(s)   # 一步残差分位数
        return LAM(A, B, c, rho)

    def rollout_interval(self, s, actions, tau_eff):
        lam = self.linearize(s)
        X = Interval(s, s)                      # 初始区间（可含状态估计协方差）
        gL, gU, fails = [], [], []
        for k, a in enumerate(actions):
            X = (lam.A @ X) + lam.B @ a + lam.c
            X = X.inflate(lam.rho)              # 误差球膨胀
            g = self.clearance_map(X)           # 区间到指标的 Lipschitz 映射
            e = self.effort_map(X)
            gL.append(g.lo); gU.append(g.hi)
            if g.lo < self.d_safe or e.hi > tau_eff:
                fails.append(k)
        w = max(hi - lo for lo, hi in zip(gL, gU))
        return Cert(valid=not fails, gL=min(gL), w=w,
                    fail_k=(fails[0] if fails else None))


# IP-358 DifferentialPositioner：三值差分定位器
class DifferentialPositioner:
    def __init__(self, embed, Z_plus, Z_minus, m_min=0.10, r_cov=1.5):
        self.phi, self.Zp, self.Zm = embed, Z_plus, Z_minus
        self.m_min, self.r_cov = m_min, r_cov

    def position(self, s):
        p = self.phi(s)                          # 32 维，O(d)
        dp = min(np.linalg.norm(p - z) for z in self.Zp)
        dm = min(np.linalg.norm(p - z) for z in self.Zm)
        m, c = dm - dp, min(dp, dm)
        if m >= self.m_min and c <= self.r_cov:
            return Position('Safe', m, c)
        if m <= -self.m_min:
            return Position('Unsafe', m, c)
        return Position('Unknown', m, c)         # 覆盖不足或模棱两可


# IP-359 HeterogeneousTrustRouter：异构信任路由器
class HeterogeneousTrustRouter:
    def __init__(self, tau_dom, w_max, K_max=10, m_switch=0.15, H_sw=10):
        self.tau_dom, self.w_max = tau_dom, w_max
        self.K_max, self.m_switch, self.H_sw = K_max, m_switch, H_sw
        self.hold, self.cur_expert = 0, None

    def route(self, pos, delta_dom, w):
        if pos.label == 'Unsafe':
            return Trust('abort', K=1, wake_all=False)
        if pos.label == 'Unknown':
            return Trust('conservative', K=1, wake_all=True)
        if delta_dom >= self.tau_dom or w > self.w_max:
            return Trust('conservative', K=1, wake_all=False)
        shrink = (1 - min(1, delta_dom / self.tau_dom)) \
               * (1 - min(1, w / self.w_max))
        K = max(1, int(self.K_max * shrink))
        expert = self.pick_expert(pos)           # top-2 + m_switch + H_sw
        return Trust('normal', K=K, expert=expert)

## 4. 推导

**引理 87（AIC 可靠性 / soundness）** 设初始区间包含真实 s_t，且局部仿射误差在每个传播步满足 ‖η_k‖∞ ≤ ρ_t。则对任意 k≤K，真实 g_k ∈ [g_k^L,g_k^U]、e_k ∈ [e_k^L,e_k^U]。证明：对 k 归纳。基：X_0 ∋ s_t。步：真值 x_{k+1}=A x_k+B a_k+c+η_k；仿射算术对矩阵乘与加法的区间包含单调性给出 A·X_k+B a_k+c ∋ x_{k+1}−η_k；再用 [−ρ_t,ρ_t] 做 Minkowski 膨胀得 X_{k+1} ∋ x_{k+1}。指标映射 clearance/effort 对状态为 Lipschitz，区间映射保包含，故指标区间含真值。**推论**：g_k^L≥d_safe ⇒ 真实 g_k≥d_safe（保守有效）。∎

**引理 88（PVR 把滞后窗口从 KΔt 降到 Δt）** 定义证书年龄 age_t 为"自上次以实测状态重算以来的周期数"。v9 中 age_t ≤ K−1（生成时冻结），故对中块突变的检出延迟可达 (K−1)Δt=180ms（K=10）。v10 每周期对剩余前缀重算，age_t≡0；对任意"能被区间判据检出"的违反，PVR 在 t 周期末产生 fail_k，下一周期 K_eff=1 并切换中止点，延迟 ≤ Δt + δ_sensor。**边界**：本引理只保证"区间判据本身的及时性"；若 ρ_t 假设失效（模型设定错误），区间不再 sound，见第 8 节风险。∎

**引理 89（三值定位的保守性与 liveness 代价）** 由定义 543/544/545，pos=Unsafe ⇒ router 输出 abort；pos=Unknown ⇒ conservative(K=1, wake_all=True)；只有 Safe 且另两通道通过才进入 normal。故在 Unknown 上不存在 K>1 的执行，也不存在 dormant 模块。Liveness：E[K_eff] ≤ K_max·P(Safe)·E[shrink | Safe]；当 P(Safe)→0，系统退化为 v8 逐步模式。这是显式的效率-安全权衡，不是隐藏缺陷。∎

**引理 90（异构 AND 门的失效概率界）** 设三通道的"假安全"事件为 F_sem（DP）、F_stat（DA-ML）、F_num（AIC 宽度）。若三者相互独立，P(F_sem∧F_stat∧F_num)=∏P(F) ≤ min P(F)；若完全相关，P(∧F)=min P(F)。故 AND 门不劣于任一单通道，但只有在通道独立时才获得乘积收益。三通道使用不同信号（几何邻近、分布散度、区间宽度），**没有代数上的相互蕴含**；经验相关性必须由 E576 实测，不能假设。∎

**引理 91（专家并集 soundness 与切换无抖振）** 若真实局部动力学属于 top-2 专家之一的 validity region，则由引理 87 逐专家区间 sound，并集单调包含真值集，故 I_1∪I_2⊕D_switch sound。切换需 m(s)≥m_switch 且保持 H_sw=10 周期才生效；m_switch>0 与 H_sw 给出相邻切换间隔下界，有限时间切换次数有限，故无 Zeno 抖振。∎

**引理 92（预算与 WCET）** LIC 每周期 O(d²K)：d=12,K=10 的矩阵-区间传播 ≈0.3ms（嵌入式 ARM）。DP O(|Z|d)：|Z|=200,d=32 ⇒ ≈0.2ms。5Hz 生成 64 候选 × O(d²K) ≈3ms/次，摊销 0.3ms/cycle。PVR 已含在 LIC 的每周期调用中。HTR O(1)。典型决策 ≤7ms，p99 ≤20ms；峰值从 v9 的 12ms 单次 LSTM rollout 降到 3ms 仿射 rollout；模型权重从约 40MB 降到 <100KB 参数 + <1MB 原型表。∎
