# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「迁移学习」×「任务分解」）

> R69 教会闭环「问」，但它同时有一处**浪费**与一处**傲慢**。浪费：每个 episode 都把每类歧义当成第一次见，重新采样 K 次、重新算 VoI；人类不会——「他指的是哪个杯子」这种歧义见过一次就沉淀成解题习惯。傲慢：它把整个任务当成一团歧义，用单一全局 `H_mode` 决定该不该问；真实歧义是**局部**的——早餐任务里「用哪个鸡蛋」有歧义，「烧水」毫无歧义，把单位时间唯一一次提问预算花在全局熵最大的地方，常常花在无关处。
>
> 本轮两个灵感正好补这两块：
> - **迁移学习**：解题知识（哪类歧义、用什么信息动作、值多少、多可靠）是可跨任务迁移的资产；把它显式化为「解题卡」，检索—适配—门禁，而不是每次从零采样。
> - **任务分解**：把任务分解成偏序子任务图，把歧义钉在具体子任务节点上，用**关键性（下游影响）**而非局部熵来给交互预算定价。
>
> 二者不是并列的两招，而是**对偶**：分解定义了迁移的**单元**（子任务是技能/选项的自然粒度），迁移为每个单元**填充**先验（把冷启动 VoI 变成热启动 VoI）。核心命题：**先分解、再按子任务检索可迁移解题卡、只在信任门放行时用迁移知识加权交互预算；对迁移或分解的任何怀疑都退回 R69，R69 再退回 R68。** 命名 **STRATA-RAS**（SubTask Resolution Allocation with Trust-bounded Analogy transfer，子任务级、信任有界的类比迁移消歧闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这份解题知识从哪来、搬到新任务还可信吗**」。R69 的风险是「问错」，R70 的风险是「搬错」——搬错更隐蔽，因为它带着完整的出处与校准凭证。

## 0. 直觉与动机

**灵感 1（迁移学习 → 解题知识是一种可迁移资产）**
直觉：R69 的 VoI 是**在线、从零**估的：采 K 个流样本、聚模态、算模态熵，再除成本。可「怎么消解某类歧义」是跨 episode、跨任务反复出现的稳定技能——「指一下」「问一句是左边还是右边」「先摸一下确认材质」。把它丢掉，等于让系统永远当新手。迁移学习给了正确抽象：把「歧义签名 → 信息动作 + 价值/成本/可靠度」做成**解题卡**（resolution card），跨任务检索与轻量适配。收益有两层：样本效率（新任务不必再采 K=4 才敢判断）与校准（历史成功/失败直接修正 VoI 的先验）。但迁移在安全系统里是双刃剑：**负迁移**——在源任务有效、在目标任务无效甚至有害的知识——会把「不知道」伪装成「知道」。所以迁移必须带一个可验证的信任门，而不是无条件复用。

**灵感 2（任务分解 → 歧义是局部的，预算要看关键性）**
直觉：把一个任务看成单一歧义团是错的。做早餐可分解为 [取食材 → 预热 → 烹饪 → 装盘]：取食材处「用哪个鸡蛋/哪盒奶」高度歧义，预热几乎无歧义；装盘处「用哪个盘子」有歧义。全局 `H_mode` 会被高熵但**低关键性**的子任务支配（比如「用哪个盘子」熵很大但选错几乎无代价），而把唯一一次提问浪费在无关处。正确做法：分解成偏序 DAG，把歧义位点定位到节点，用**关键性 c(v)=下游影响链**给 VoI 加权。关键性加权把「哪里模糊」变成「哪里模糊且会改变结局」——这才是值得问的地方。

**灵感 3（对偶：分解定义单元，迁移填充单元）**
直觉：这两个词不是两件事。技能/选项（options）之所以能迁移，正因为它对应可复用的**子任务**；子任务之所以可分解，正因为它的解题方式有稳定的、可被历史证据支持的先验。于是：**任务分解提供迁移的粒度与地址，迁移学习提供每个粒度的先验与置信**。分离地看，分解只是层级规划、迁移只是参数复用；合起来才得到「按子任务检索历史解题经验、用关键性分配预算」的闭环。这是本轮最重要的结构性洞见，也是命名取「Strata（层）」的原因：任务被切成层，经验在层间迁移。

**灵感 4（负迁移与错误分解 → 比 R69 更隐蔽的风险）**
直觉：R69 的最大风险是「问错」，一个错误提问至少发生在眼前、可被审计看到。R70 引入了两种新的、**事后更难发现**的错误：(a) **负迁移**——新厨房和旧厨房外观几乎一样（签名距离小、出处完整、行为散度也不高），但刀具锋利度、容器容量、人的习惯不同，旧解题卡在这里是错的；系统却因「看起来像」而自信地跳过该问的问题，或问错问题。(b) **错误分解**——把本有强耦合的两个子任务当成独立，导致「局部已消歧」在全局其实没解决（例如「取鸡蛋」的模态改变了「烹饪」的可行性）。二者的共同点是：**错误带着完整的凭证**。所以 R70 必须把审计对象从「这次问得对不对」升级为「这份知识搬得对不对、这块任务切得对不对」。

**灵感 5（严格继承 → R70 = 空库 + 不分解 = R69）**
直觉：R69 确立的理论姿态是「新层必须是旧层的严格泛化」，R70 继续沿用并把它变成一条**安全链**：空解题库、或 TCG 全禁（信任=0）、或 SDG 退化为单节点时，STRATA 每轮逐指令等于 FLUID（R69）；FLUID 在 VoI≤成本时逐指令等于 CALM（R68）。于是 R70 ⊆ R69 ⊆ R68（风险不增），效率侧才获得「迁移加速 + 关键性聚焦」的 bonus。另一个可复用的正面接口：R69 的 FMA 似然通道本来用于「标定是否骗我」，其本质是**行为自洽度**；同一条通道可直接当**域探测器**（用源域策略给目标域动作打分，系统性偏移即域漂移）。这让「迁移是否骗我」与「标定是否骗我」共用一条不可被表面相似性伪造的证据。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（STRATA-RAS 总览）** STRATA-RAS = (SDG, RKT, HVA, TCG, MRB, RAS-WM‡)，其中 PRQ（出处/隔离/回滚）与 DVA（分解审计）为完整性支撑子系统。四条不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i / R69 定义 293-i；解题卡的写入只发生在离线或任务间）；
(ii) **交互预算硬约束**（继承 R69 定义 293-ii；单位时间信息动作 ≤1 次的节流不变）；
(iii) **证据纪律**（继承 R69 定义 293-iii）；
(iv) **迁移安全锚**：迁移来的知识只允许在**已认证**包络内放松保守性；对迁移有效性或分解有效性的任何怀疑 ⇒ λ 单调不降地退回 R69，再退回 R68。即安全链 R70 ⊆ R69 ⊆ R68（物理风险不增）。

**定义 311（子任务分解图 SDG）** 任务 τ 分解为偏序 DAG `G_τ=(V,E,ℓ)`：节点 v∈V 为子任务（带前置/后置条件、局部状态域 Ω_v、完成判据），边表示偏序依赖，`ℓ(v)∈{AND,OR}` 标注组合语义。**分解有效** ⇔ (a) 覆盖 `∪Ω_v` 覆盖任务状态轨迹；(b) 偏序无环；(c) 细化可重构：按 ℓ 组合 G_τ 可恢复 τ 的可行性条件；(d) 耦合有界：`∀(u,v)∈E, κ_uv ≤ κ_max`。分解器不要求最优，只要求**可审计**（定义 321）；无法有效分解时退化为单节点（=R69）。

**定义 312（歧义位点与关键性）** 节点 v 的歧义位点 `A_v = {s∈Ω_v : U_epi(s) > τ_epi}`（U_epi 继承 R69 定义 297）；歧义质量 `m(v)=μ(A_v)/μ(Ω_v)`。关键性 `c(v)=Σ_{w∈desc(v)∪{v}} s_{v→w}`，`s_{v→w}` 为「在 v 处选错模态」对 w 期望损失的敏感度（沿名义计划线性化）。**关键性加权歧义** `= c(v)·m(v)·ρ_v`，`ρ_v` 为 R69 的可解性 `g(Δ_min)`。直白：只有「会改变下游结局」的歧义才值得花预算。

**定义 313（解题卡与知识库 RKT）** 解题卡 `ρ=(σ_ρ, g_ρ, V̂_ρ, ĉ_ρ, r̂_ρ, prov_ρ, 𝔡_ρ, n_ρ)`：`σ_ρ` 歧义签名（歧义类型 + 局部上下文的紧凑嵌入），`g_ρ∈𝒜_info` 信息动作原型，`V̂_ρ` 期望 VoI，`ĉ_ρ` 成本，`r̂_ρ` 可靠度，`prov_ρ` 出处链，`𝔡_ρ` 源域嵌入，`n_ρ` 使用/成功计数。知识库 `ℒ={ρ_i}`，按签名度量 `d_σ` 检索 top-k，轻量适配 `A(ρ,σ_v)→ρ_v`（仿射校正 + 可靠度重标定，非全量重训）。

**定义 314（领域距离）** 源域 S 与目标域 T 的歧义分布距离 `d_𝔇(S,T)=W_1(p_σ^S,p_σ^T)+λ_c·W_1(p_z^S,p_z^T)`，`p_σ` 为歧义签名分布，`p_z` 为共享上下文分布；在线用有限样本得 `d̂_𝔇`。

**定义 315（行为散度 / 流式域探测器 FDD）** 复用 R69 的 FMA 似然通道，定义 `d_beh(S,T)=|E_S[−log p_{θ_S}(ξ|o)] − E_T[−log p_{θ_S}(ξ|o)]|`：用**源域策略**给目标域动作打分，分数系统性偏移即说明目标域行为不在源分布主脊上。`d_beh` 是 `d_𝔇` 中不需要目标标签的在线观测量，且**不能被签名相似度伪造**——这正是对 R69 风险的多一维正面回应。

**定义 316（迁移标定门 TCG）** 解题卡 ρ 在目标节点 v 的信任分 `T(ρ;v)=φ(σ 匹配度, d̂_𝔇, d_beh, prov 完整性, 在线成功率)∈[0,1]`。三级门：`T≥τ_hi` ⇒ **全信**（可单独授权交互、参与预算分配）；`τ_lo≤T<τ_hi` ⇒ **仅顾问**（可给先验均值、降采样量，但不得单独授权交互，须与冷启动样本或第二个正交来源一致）；`T<τ_lo` ⇒ **禁用**（视为空库，退回 R69 冷启动）。TCG 是 R69 MCG 的跨域版本：MCG 管「模态权重在域内是否校准」，TCG 管「解题知识跨域是否仍校准」。

**定义 317（层级 VoI 与加性分解）** 在 A99（给定 z_0 与 G_τ，子任务歧义条件独立、耦合 ≤κ_max）下，节点 v 处信息动作 g 的边际价值 `VoI_v(g)=c(v)·[H(M_v|o)−E_{y~p(·|g,o)}H(M_v|o,y)]`，等价地（接 R69 引理 16 的误差形式）`VoI_v ≥ c(v)·Δ_min,v·(1−e^{−ΔH_v})`，全局再加 `O(κ_max·|E|)` 的耦合项。全局 VoI 不再用单一 `H_mode`，而是 `Σ_v VoI_v` 减去各自成本；R69 的全局 VoI 是「所有关键性相等、单节点分解」的特例。

**定义 318（预算分配 HVA）** 给定跨 episode 的交互预算 B（次数/位移/社交成本，仍受单位时间 ≤1 约束）与 SDG 上的优先级约束（祖先未消歧时后代的「已解决」不可信），选交互集 S 与动作 `{g_v}`：`max_{S,{g_v}} Σ_{v∈S}[VoI_v(g_v)−c(g_v)]`，s.t. 预算、优先级、每个 (a,g) 过 C-RAS-WM 认证。树/链上是带优先级的树背包，DP `O(|V|·B/δ)`；一般 DAG 在树宽 tw 上 `O(2^tw·|V|·B/δ)`，生产中用宽界近似并回退「按 VoI/成本比 + 关键性」贪心。注意：HVA 分配的是**跨子任务/跨 episode 的长期预算**，不突破 R69 的单步节流。

**定义 319（元解题赌博机 MRB）** 新域中 TCG 只给信任分而不保证真值，是否信任某张卡是一个**带安全约束的 bandit**：臂 `a=(v,ρ)` 或「冷启动」，回报 = 实测 `[VoI−成本]`，约束 = 认证与失败代价。用保守 UCB：先以冷启动/顾问模式收集证据，成功一次才允许信任分上移一档；只用**下置信界**决定是否放松 λ（悲观主义）。迁移提供先验均值（加速），分解提供臂结构与跨子任务共享（分层 bandit）。冷启动永不被禁用 ⇒ 即使全库不可信，系统仍等价 R69。

**定义 320（负迁移界与可信迁移包络）** 设解析损失对 (σ,z) 为 L-Lipschitz、适配残差 `r_adapt`，则 `reg_T(ρ) ≤ reg_S(ρ)+L·d_𝔇(S,T)+r_adapt`（引理 20）。TCG 用可计算的 `d̂_𝔇、d_beh` 估计该上界，仅当上界可验证地 `≤ ε_tr` 时给「全信」。**可信迁移包络** `= {ρ : 上界 ≤ ε_tr 且 prov 完整}`；包络外只能作顾问或禁用。

**定义 321（分解有效性审计 DVA）** 在线比较每个子任务的预测结局（前置满足、模式、局部代价）与实测结局，得分解残差 `δ_decomp`；若 `δ_decomp>τ_decomp`（暗示错误独立性 / 漏耦合 / 错误切分），触发**边界安全的重分解**：只在子任务边界（可暂停点）重规划，旧卡与新分解的对应关系失效、相关信任分清零。审计结论回灌 AuditBuf 以学习分解先验，但不进实时写路径。

**定义 322（迁移投毒威胁模型 ℰ_xfer）** 跨任务供应链攻击：源任务被投毒 → 错误解题卡流入库；出处伪造；陈旧卡（源域曾有效、现已漂移）；重放缓冲污染；「看似合理」的对抗签名（让 σ 匹配但 g 有害）。并入 AIC：`ℰ_STRATA = ℰ_FLUID × ℰ_xfer`，其中 ℰ_FLUID 已含 ℰ_poison（R69 定义 304）。

**定义 323（出处账本与隔离/回滚 PRQ）** 每张卡带哈希链出处（源任务、episode、贡献者、时间、校验），库按源任务可**隔离**（新卡试用期不得驱动全信交互，只能顾问/冷启动对照）与**回滚**（撤销某源/某时段的全部贡献）。**跨源佐证**：同类歧义的解题卡需 ≥2 个独立源任务一致才可升为全信——这是 R69「k 个正交证据」纪律在**知识来源层**的镜像。

**定义 324（证书 J_STRATA）** `J_STRATA=(J_FLUID, decomposition_hash, sdg_validity, skill_provenance_root, transfer_trust_scores, negative_transfer_bound, hva_allocation_hash, meta_bandit_regret, strata_ver)`。Valid ⇔ Valid(J_FLUID) ∧ sdg_validity ∧ 出处完整 ∧ 无隔离/回滚中的卡被全信使用 ∧ 迁移安全锚（定义 310-iv）满足。

**定义 325（分级保守退避）** 设 `U_epi` 为 R69 的全局可约不确定性，`U_epi^decomp` 为按 SDG 分配后的可约部分，`T_v` 为所用卡信任分：
- 全信且双源佐证：`λ=λ_floor(U_ale)`（与 R69 最优情形相同）；
- 顾问/部分信任：`λ=λ_floor(U_ale + (1−T_v)·U_epi^decomp)`（插值）；
- 禁用/分解无效/出处可疑/回滚中：`λ=λ_floor(U_ale + U_epi^decomp) = R69 全保守`。
因 λ_floor 单调，`T_v∈[0,1]` 使 R70 始终位于 R69 的两极之间，且在 `T_v=0` 或空库时**逐指令等于 R69**。

**定义 326（时序耦合与自适应）** 分解只在任务开始或子任务边界做（低频，`O(|V|)`），迁移检索走缓存；单位时间仍 ≤1 次信息动作（R69 节流不变）；TCG 的 `n_ρ` 证据按贝叶斯更新，成功才允许信任上移一档（悲观升级）；`d_beh` 连续 m 次超阈 ⇒ 冻结全信迁移、进入冷启动对照。

**定义 327（与 R69 的接口）** R69 输出 `(U_ale,U_epi,modes)`；STRATA 在 `U_epi>τ_epi` 后插入三层：S1 分解定位 → S2 迁移检索/门禁 → S3 层级预算；输出仍是 `(U_ale, 残余 U_epi, 选中模态)`，对 R69 下游（λ_floor、select_mode、C-RAS-WM、审计）**零改接口**。这保证工程上可「加壳」而非重写。

## 2. 关键算法骨架

```python
# IP-264 SDG：可审计的任务分解（无效即退化单节点 = R69）
def decompose(task_spec, z0):
    G = planner.task_graph(task_spec)              # AND/OR 偏序 + 完成判据
    for v in G.nodes: v.omega = local_state_region(v)
    return G if validate(G) else single_node(task_spec)

# IP-265 ALC：歧义定位 + 关键性
def ambiguity_loci(G, policy):
    for v in G.nodes:
        A_v = {s for s in v.omega if policy.U_epi(s) > TAU_EPI}
        v.m = mass(A_v) / mass(v.omega)
        v.c = downstream_sensitivity(v, G)         # 定义 312
    return G

# IP-266 RKT：检索—适配（离线/任务间写入）
def retrieve(sigma_v, library, k=3):
    return [adapt(r, sigma_v) for r in library.topk(sigma_v, d_sigma, k)]

# IP-267/268 TCG：三级信任（签名 + 域距离 + 行为散度 + 出处）
def trust(card, v, dom):
    if not provenance.verify(card.prov): return 0.0
    dD  = dom.domain_distance(card.src, v)         # 定义 314
    dbe = dom.flow_divergence(card.src, v)         # 定义 315，复用 FMA
    s   = card.n_success / max(card.n_use, 1)
    return phi(card.sigma_match, dD, dbe, s)       # ∈[0,1]

# IP-269 HVA：关键性加权、带优先级的树背包
def allocate(G, cards, budget):
    items = []
    for v in G.nodes:
        rho = best_above_advisory(cards[v])        # 禁用卡不参与
        voi = v.c * entropy_drop_prior(rho, v)     # 定义 317
        items.append((v, rho, voi - cost(rho)))
    return precedence_knapsack(items, G.edges, budget)   # 祖先优先

# IP-270/271 MRB + NTG：悲观探索与负迁移守卫
def resolve(v, rho, T, budget):
    if T >= TAU_HI:
        return execute_certified(rho.g, v)         # 全信
    cold = cold_start_interact(v)                  # = R69 MINT
    if T >= TAU_LO and corroborate(rho, cold):     # 顾问：需正交一致
        return blend(rho, cold)
    return cold                                    # 禁用/不一致 → R69

# IP-276 主闭环（R69 加壳；无歧义时完全等价 R69）
def STRATA_RAS_round(M, obs, task):
    z, o = M.mtm.forward(obs)
    U_ale, U_epi, modes = M.fluid_step(o, z)       # R69 一次前向
    if U_epi <= TAU_EPI:
        return M.fluid_act(modes, U_ale, U_epi)
    G = decompose(task, z) if M.sdg.can(task) else single_node(task)
    G = ambiguity_loci(G, M.policy)
    cards = {v: retrieve(v.sigma, M.rkt) for v in G.ambiguous()}

    plan  = M.hva.allocate(G, cards, M.budget)
    U_epi_d = distribute_epi(U_epi, G, plan)       # 按关键性/可解性分到节点
    for v, rho in plan:
        act = M.mrb.resolve(v, rho, T[v], M.budget)
        U_epi_d[v] = M.cia.update_belief(U_epi_d[v], act)
    T_used = min((T[v] for v, _ in plan if T[v] >= TAU_HI), default=0.0)
    lam = max(M.efs.risk_scale(...),
              lam_floor(U_ale + (1.0 - T_used) * sum(U_epi_d.values())))
    if M.dva.residual(G) > TAU_DECOMP or M.tcg.frozen():   # 分解/迁移异常
        lam = max(lam, lam_floor(U_ale + U_epi))           # 退回 R69 全保守
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ...)
    mode = select_mode(modes, sum(U_epi_d.values()), lam)
    M.vqa.submit_async(G, plan, T, lam)            # 审分解/迁移/交互
    return k, lam, mode, (U_ale, sum(U_epi_d.values()))
```

## 3. 推导

**引理 19（关键性加权 VoI 的加性分解）** 设 A99 成立：给定 (z_0,G_τ)，模态身份 {M_v} 条件独立；任务损失 `L=Σ_v L_v + Σ_{(u,v)∈E} κ_uv·ΔL_uv`，`κ_uv≤κ_max` 且 ΔL 有界。对节点 v，令信息动作 g 使 `H(M_v|o)` 降 `ΔH_v`，可分性满足 R69 的 A95。则
`VoI_v(g) ≥ c(v)·Δ_min,v·(1−e^{−ΔH_v})`，且 `Σ_v VoI_v = VoI_global + O(κ_max·|E|)`。
要点：条件独立使信息增益可逐节点相加；关键性 `c(v)` 把「局部熵下降」换算为「全局期望损失下降」。系：**高熵但低关键性的歧义不该问**；这与 R69「可分才可问」并列，构成「值钱才问」的第二把尺。

**引理 20（迁移遗憾界）** 设解析损失泛函对 (σ,z) 为 L-Lipschitz，源/目标歧义分布 Wasserstein-1 距离 `d_𝔇(S,T)`，适配残差 `r_adapt`，则对任意解题卡 ρ：
`reg_T(ρ) ≤ reg_S(ρ) + L·d_𝔇(S,T) + r_adapt`。
证略（域适应泛化界的标准形式：目标风险 ≤ 源风险 + 分布散度项 + 理想联合假设残差；此处以 W_1 与 Lipschitz 常数给出可计算上界）。系：TCG 只要能用 `d̂_𝔇、d_beh` 把右端压到 `ε_tr` 以下，就得到**可验证的**「迁移不致大错」证书；这也说明为何只看签名相似度不够——它漏掉了 `d_beh` 这一项。

**引理 21（负迁移的安全不放大）** 设所有被执行的动作（任务动作与信息动作）都必须通过 C-RAS-WM 认证（R68/R69，A100：认证可靠），则不论迁移质量如何，
`R_safe(STRATA) ≤ max{ R_safe(R69), ε_cert } = R_safe(R69)`。
直觉：负迁移只能改变「在哪个子任务、选哪个**已认证**动作、要不要问」，不能把未认证动作放进执行集；最坏情况是漏问/问错/选了次优但已认证的动作——损失的是**效率**（由引理 20 界定），不是**物理安全**。系：R70 的风险形态是「白问/漏问」，而非「越界」。

**引理 22（分解误差的预算错配界）** 若真实存在被遗漏的耦合 κ>0 或错误切分，使加性假设偏差 `δ_decomp=|V_true−V_additive|`，则按加性 VoI 分配相对真最优的次优性
`≤ (|V|+1)·δ_decomp + B·δ_g`（`δ_g` 为成本离散化误差）。
系：DVA 通过「预测结局 vs 实测结局」估计 `δ_decomp`，超阈即重分解；只要审计足够灵敏，错配被限制在常数倍分解残差内。

**定理 18（层级分配支配整体分配）** 在 A99 下，对关键性加权目标，HVA 的预算分配所得期望收益 ≥ R69 式整体分配；等号成立当且仅当所有分歧义节点关键性相同（单一歧义团）。直白：只要歧义分布在**关键性不同**的子任务上，先分解、再把预算投到高关键性处严格更好；整体分配会被高熵低关键性的子任务浪费预算。

**定理 19（STRATA 严格包含 FLUID 与 CALM）** 当 `|ℒ|=0`、或 TCG 全禁（`T_v=0`）、或 SDG 退化为单节点时，STRATA 每轮输出**逐指令等于** FLUID（R69）；进一步，当 FLUID 因 `VoI≤成本` 退回 CALM 时，STRATA 也退回 CALM。故能力上 `STRATA ⊇ FLUID ⊇ CALM`，风险上 `R70 ⊆ R69 ⊆ R68`；效率侧获得「迁移加速 + 关键性聚焦」双重 bonus。

**定理 20（跨任务交互安全与无突变）** 迁移只在「已认证的信息动作 × 已定位的子任务」上改变选择；分解/重分解只发生在子任务边界（可暂停点，属安全集）；负迁移、TCG 冻结、隔离/回滚时 λ 单调不降地退回 R69；R68 的换装不变式（定理 15）保持 ⇒ 控制连续、无突变、无越界。

## 6. 本轮最大风险

**一句话**：STRATA-RAS 的全部效率收益押在「我能判断这份迁移知识在新任务上还可信」这一前提上——而 **TCG 本质上是拿源域训练出的判据去裁决目标域，最危险的负迁移恰恰是「表面相似、关键处不同」**（外观相同的厨房，但刀具锋利度、容器容量、人的习惯不同：签名距离小、出处完整、行为散度也可能不高），于是门禁放行，系统用一张过时的解题卡自信地跳过该问的问题或问错问题；再叠加错误分解把唯一一次交互预算投到低关键性子任务，R70 就把 R69 的「诚实的不知道」升级为「有理有据的搬错」——**搬错比不问更难被审计发现，因为它带着完整的出处与校准凭证；TCG 本身成了新的、必须被信任的单点。**

**次级风险与缓解**：
1. **错误分解 / 假独立性**（把耦合子任务当独立）→ DVA 审计 `δ_decomp` + 只在边界重分解 + 引理 22 错配界；
2. **迁移投毒 / 出处伪造**（跨任务供应链）→ 哈希链出处 + 隔离试用 + 回滚 + 跨源 ≥2 佐证（定义 323）；
3. **陈旧卡 / 概念漂移**（源域曾对、现已错）→ `d_beh` 连续超阈即冻结全信迁移（定义 326）+ MRB 悲观升级；
4. **冷启动退化**（全库不可信 → 退回 R69，R70 失去意义）→ 把「可迁移但未验证」降级为顾问而非禁用，用分类器分层保留部分加速；
5. **实时开销**（分解/检索/出处校验）→ 低频分解 + 缓存 + 哈希摊销，P99 预算表兜底。

**定义 317–318（层级 VoI 与 HVA）** `VoI_v=c(v)·[H(M_v|o)−E H(M_v|o,y)]`；`max Σ[VoI_v−c]` s.t. 预算、优先级、认证；树背包 DP，DAG 宽界近似 + 贪心回退。分配的是长期预算，不破单步节流。

**定义 321–323（DVA / 威胁 / PRQ）** `δ_decomp` 超阈 ⇒ 边界安全重分解；`ℰ_STRATA=ℰ_FLUID×ℰ_xfer`；哈希链出处 + 隔离试用 + 回滚 + 跨源 ≥2 佐证。

**定义 324–325（证书与分级退避）** `J_STRATA` 并入分解哈希、出处根、信任分、负迁移界；`λ=λ_floor(U_ale+(1−T)U_epi^decomp)`，T=0 逐指令 = R69。

**定义 326–327（时序与接口）** 分解低频、检索缓存、节流不变、悲观升级、`d_beh` 超阈冻结全信迁移；对 R69 下游**零改接口**，可加壳。

## 3. 关键算法伪代码

```python
# IP-264/265 分解 + 歧义定位（无效即单节点 = R69）
def decompose_and_locate(task, policy):
    G = planner.task_graph(task)
    if not validate(G): return [single_node(task)]
    for v in G.nodes:
        v.m = mass(ambiguous(v.omega, policy)) / mass(v.omega)
        v.c = downstream_sensitivity(v, G)          # 定义 312
    return G

# IP-266/267/268 检索 + 三级信任
def load_cards(G, library, dom):
    cards, trust = {}, {}
    for v in G.ambiguous():
        rho = adapt(library.topk(v.sigma, d_sigma, 3)[0], v.sigma)
        cards[v] = rho
        trust[v] = 0.0 if not provenance.verify(rho.prov) else phi(
            rho.sigma_match, dom.domain_distance(rho.src, v),
            dom.flow_divergence(rho.src, v), rho.n_success / max(rho.n_use, 1))
    return cards, trust

# IP-269 层级预算：关键性加权、祖先优先
def allocate(G, cards, trust, budget):
    items = [(v, cards[v], v.c * entropy_drop_prior(cards[v], v) - cost(cards[v]))
             for v in G.ambiguous() if trust[v] >= TAU_LO]
    return precedence_knapsack(items, G.edges, budget)

# IP-270/271 悲观解析：全信 / 顾问对照 / 退回 R69 冷启动
def resolve(v, rho, T):
    cold = cold_start_interact(v)                   # = R69 MINT
    if T >= TAU_HI: return execute_certified(rho.g, v)
    if T >= TAU_LO and corroborate(rho, cold): return blend(rho, cold)
    return cold                                     # 禁用/不一致

# IP-276 主闭环（无歧义完全等价 R69）
def STRATA_RAS_round(M, obs, task):
    z, o = M.mtm.forward(obs)
    U_ale, U_epi, modes = M.fluid_step(o, z)
    if U_epi <= TAU_EPI: return M.fluid_act(modes, U_ale, U_epi)
    G = decompose_and_locate(task, M.policy)
    cards, T = load_cards(G, M.rkt, M.dom)
    plan = M.hva.allocate(G, cards, T, M.budget)
    U_epi_d = distribute_epi(U_epi, G, plan)
    for v, rho in plan:
        U_epi_d[v] = M.cia.update_belief(U_epi_d[v], M.mrb.resolve(v, rho, T[v]))
    T_used = min((T[v] for v, _ in plan if T[v] >= TAU_HI), default=0.0)
    lam = max(M.efs.risk_scale(...),
              lam_floor(U_ale + (1 - T_used) * sum(U_epi_d.values())))
    if M.dva.residual(G) > TAU_DECOMP or M.tcg.frozen():
        lam = max(lam, lam_floor(U_ale + U_epi))    # 退回 R69 全保守
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ...)
    mode = select_mode(modes, sum(U_epi_d.values()), lam)
    M.vqa.submit_async(G, plan, T, lam)
    return k, lam, mode, (U_ale, sum(U_epi_d.values()))
```

## 4. 推导

**引理 19（关键性加权 VoI 加性分解）** A99（子任务歧义条件独立、耦合 ≤κ_max）下，`VoI_v ≥ c(v)·Δ_min,v·(1−e^{−ΔH_v})`，且 `Σ_v VoI_v = VoI_global + O(κ_max|E|)`。系：高熵低关键性歧义不该问——这是「值钱才问」，与 R69「可分才可问」并列。

**引理 20（迁移遗憾界）** 解析损失对 (σ,z) 为 L-Lipschitz、适配残差 r_adapt，则 `reg_T(ρ) ≤ reg_S(ρ)+L·d_𝔇(S,T)+r_adapt`。系：TCG 用可计算 `d̂_𝔇、d_beh` 给出可验证「不致大错」证书；只比签名相似会漏掉 d_beh 项。

**引理 21（负迁移的安全不放大）** 所有执行动作过 C-RAS-WM 认证（A100），则 `R_safe(STRATA) ≤ R_safe(R69)`。负迁移只能改变「在哪个子任务、选哪个已认证动作、要不要问」，最坏损效率（引理 20），不破物理安全。系：R70 的风险形态是「白问/漏问」而非「越界」。

**引理 22（分解误差预算错配界）** 加性偏差 `δ_decomp` 导致的次优性 `≤(|V|+1)·δ_decomp+B·δ_g`。系：DVA 估 δ_decomp，超阈重分解，错配受限于常数倍残差。

**定理 18（层级支配整体）** A99 下 HVA 期望收益 ≥ R69 整体分配；等号当且仅当所有分歧义节点关键性相同。系：歧义分布在关键性不同的节点上时，先分解再投预算严格更优。

**定理 19（STRATA 严格包含 FLUID/CALM）** 空库、TCG 全禁或 SDG 单节点 ⇒ 逐指令 = FLUID；FLUID 退回 CALM 时亦退回 CALM。故 `STRATA ⊇ FLUID ⊇ CALM`，风险 `R70 ⊆ R69 ⊆ R68`。

**定理 20（跨任务安全与无突变）** 迁移只改「已认证信息动作 × 已定位子任务」的选择；重分解只在子任务边界（安全集内）；负迁移/冻结/隔离/回滚时 λ 单调不降退回 R69；R68 换装不变式保持 ⇒ 控制连续、无突变、无越界。

## 7. 本轮最大风险

**一句话**：全部效率收益押在「我能判断这份迁移知识在新任务上还可信」上——但 TCG 是拿源域判据去裁决目标域，**最危险的负迁移是「表面相似、关键处不同」**（签名距离小、出处完整、行为散度也不高），门禁放行后系统用陈旧解题卡自信地漏问/问错，再叠加错误分解把唯一预算投错地方；R70 于是把 R69 的「诚实的不知道」升级为「有理有据的搬错」——**搬错比不问更难被审计，因为它带着完整的出处与校准凭证；TCG 本身成了新的、必须被信任的单点。**

**次级风险与缓解**：错误分解/假独立性（DVA + 边界重分解 + 引理 22）；迁移投毒/出处伪造（PRQ 哈希链 + 隔离 + 回滚 + 跨源 ≥2 佐证）；陈旧卡/概念漂移（d_beh 超阈冻结全信迁移 + 悲观升级）；冷启动退化（把「可迁移未验证」降为顾问而非禁用）；实时开销（低频分解 + 缓存 + 哈希摊销）。
