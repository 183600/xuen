## 0. 直觉与动机

**灵感 1（因果推理 → 从"关联证据"到"可识别因果证据"）**

直觉（先给图景）：前四轮我们一直在给证据加盖封印——类型、误差界、负信息、义务、意图、云边一致、少样本覆盖、专利。但所有封印都是**关联性的（associational）**：conformal 覆盖率是边缘分布上的平均承诺，CFC+++ 的"模态数 ≥ 2"只是"看起来独立"的代理，AbsCert 的 κ_c 是数据集平均的召回率。关联证据有两类致命混淆：

- **共因混淆（common cause）**：三个摄像头"一致地"没看见人，未必是三者独立地都没看见，而可能是同一块反光板、同一版固件、同一批训练数据偏差造成的**同一次显影**。"众口铄金"在这里恰恰是**众口一病**——计票数越多，错得越理直气壮。
- **观测/干预混淆（observation vs intervention）**：检测器"没响"（观测 `D=0`）不等于"把人放进去它也不会响"（反事实 `do(H=1)`）。v23 的缺席证书把两者当成一回事，全部可靠性押在一个平均召回假设 `κ_c` 上——这正是 v23 亲口点名的"合规的缺席幻觉"。

严谨定义（骨架，细节见产物区）：
- **因果证据图 CEG**：设因果 DAG `G=(V,E)`，节点含潜在在场 `H`、混杂 `C={L 光照, O 遮挡, T 训练分布, S_h 传感器健康, Fw 固件}`、各模态检测事件 `D_m`。两票证据 `D_i, D_j` 构成**独立佐证**当且仅当在给定已观测混杂 `C_obs` 下 **d-分离**：`D_i ⫫ D_j | C_obs`。定义**有效独立票数** `N_ind` 为证据节点中最大两两 d-分离集合的势（"因果独立集"）。CFC+++ 的"模态数 ≥ 2"升级为 **`N_ind ≥ M_min`**：共因票在计数与结构上坍缩成一票。
- **反事实缺席证书 CxAC**：AbsCert 的合法陈述不是"观测到 `D=0`"，而是干预陈述 `P(D=1 | do(H=1,R)) ≥ κ_c^cause(R)`。定义缺席置信上界
  `Bound_abs(R) = (1-κ_c^cause(R))·π_R^max / (1 - κ_c^cause(R)·π_R^max)`，
  仅当 `Bound_abs(R) ≤ ε_abs` 才签发。若 `κ_c^cause` 不可识别，依次用：(i) **受控干预校准**（让受试者按协议进入 R，覆盖儿童/轮椅/蹲姿/逆光）；(ii) 运行时**主动反事实探针**（微动视角/结构光闪光，制造实验性变异以打断"缺席 vs 失明"混杂）；(iii) **部分识别与敏感性**（Manski 界 + Γ 敏感性，`κ_c^cause ≥ κ_c^obs/Γ`）。探针不可行或界不够窄 ⇒ **拒绝签发**，退回"全域假设有人"。

关键反直觉点：**因果层不是给系统"增加能力"，而是给已有证据"打折"**——d-分离只会减少有效票，反事实只会作废缺席证书，敏感性只会收窄可宣称的召回。因此它天然**安全单调**：`Exec_v24 ⊆ Exec_v23`，而不是又一次"能力叠加"。

**灵感 2（研究空白 → 把"贡献"变成可审计、可证伪的对象）**

直觉：v20→v23 是一条模块膨胀曲线（IP-420→IP-439）。每轮都声称"首次/新增/封堵风险"，却**没有一个机制能回答"这到底是补了一个真洞，还是给旧风险换了个名字"**。研究空白（research gap）在论文里通常只是引言里的一句话；我们要把它变成**一等公民、可版本化、可证伪、可反换名审计的证书对象**。三条机制：

- **空白图谱 GANL**：登记每个空白 `g_i = (陈述, 现有工作为何没补, 闭合实验, 通过判据, 关联模块, 状态)`。每个模块上线前必须声明它闭合哪个 `g_i`，并交付**闭合实验（falsifier）**，而不是一段叙事。
- **空白闭合证书 GCC**：模块"可部署"当且仅当 `∃g_i: m ∈ closes(g_i)` 且 `closure_test(g_i)` 已执行且通过；测试失败 ⇒ 贡献降级为"猜想"，模块回退 v23 或停用（安全中性）。
- **反换名审计 ARA**：把贡献陈述规范化成（问题, 机制, 保证类型, 失效模式）四元组的规范形，用等价关系 `≈_claim` 检查新 `g_i` 是否只是某个已闭合空白的**同义改写**；若是 ⇒ 拒绝新颖性声明。并维护**空白债务账本 `gap_debt`**：显式列出我们故意不补的洞（研究边界），把"本轮最大风险"直接挂账到某个未闭合空白。

关键反直觉点：**"研究空白"不是写作技巧，而是安全/合规证书的元层**——它约束的不是机器人能做什么，而是**我们凭什么声称系统更安全**。一个未被闭合实验支撑的"安全性提升"，在审计意义上等价于一个未经测试的模块。

**三者（v23 + 因果 + 空白）如何统一**

统一为 **v23 之上的"因果-空白层"**：CEG/CIQ 回答"证据是否独立"，CxAC/CSPI/ACPP 回答"缺席是否反事实成立"，GANL/GCRA 回答"贡献是否真的补了洞"。共享状态 `ζ_causal = ζ_ce ∪ (G, κ_cause, Γ, N_ind, G_atlas, gap_debt)`。统一准入门 **HPC-E++ = (HPC-E+, CEG-quorum, CxAC, CSPI, GCC)** 五证一体：几何 ∧ 规范 ∧ 负信息 ∧ 能量 ∧ 云边 ∧ **因果独立 ∧ 反事实缺席 ∧ 敏感性达标 ∧ 空白闭合**。任一缺失 → 回退 v23（再退 v22…v18）。CFC+++ 升级为 **CFC++++（Causal-Identified Quorum）**：仲裁从"模态数 ≥ 2"改为"**`N_ind ≥ 2` 且计数 ≥ N-F**"，并用共因等价类做**因果版 NMS** 去重。

## 2. 设计原则（在 P34–P42 基础上新增 P43–P45）

**P43 因果独立证据律（Causal Evidence Independence）**
仲裁只计入**因果独立**的证据：`N_ind = ω(Ev, C_obs) ≥ M_min`，其中 `ω(·)` 为证据节点在给定 `C_obs` 下的最大两两 d-分离集合。共因证据按 `common_cause_class(Ev, C_obs)` 合并为等价类，每类只计一票（因果 NMS）。未知/未建模的混杂一律**按未阻断处理**（保守地判为相关），故 `Fil_caus` 只可能减少通过项。任何 CEG 失效（DAG 版本缺失/结构不可信）⇒ `N_ind := 1`，CFC++++ 退回 CFC+++ 的 `CI` 行为。

**P44 反事实缺席律（Counterfactual Absence）**
缺席证书只在**干预陈述**成立时签发：`Bound_abs(R) ≤ ε_abs`，其中 `κ_c^cause(R)` 必须来自受控干预校准/主动探针/带 Γ 界的部分识别之一，且 `π_R^max` 取可采纳先验的上确界；同时手势通道无在场证据（沿用 v23 的在场翻转）。若 `κ_c^cause` 不可识别、`Γ` 无正当性、探针不可行、或 `Bound_abs > ε_abs` ⇒ **拒绝签发**，该区域退回"假设有人"（v21 规则）。因此 CxAC 只作废 v23 的缺席证书，从不新增自由空间。

**P45 空白可证伪律（Gap Falsifiability）**
每个新模块必须绑定一个已登记空白 `g_i` 并附带闭合实验；(i) 闭合实验未执行/未通过 ⇒ 模块不得部署，回退其 v23 前身；(ii) `≈_claim` 判定新空白与已闭合空白等价 ⇒ 新颖性声明被降级，且该模块按"未声明空白"处理，同样回退；(iii) 任何被闭合实验**证伪**的旧声明 ⇒ 立即停用对应模块（更保守）。空白治理只做"回退/停用"，永不放行 v23 之外的计划，故 `Fil_gap` 安全中性。

## 3. 与基线的接口（如何退化）

- **CEG 失效**（DAG 不可信/版本不符）⇒ `N_ind:=1` ⇒ CFC++++ 退回 CFC+++（等价 v23）；
- **CxAC 失效**（校准缺失/探针不可行/Γ 无界）⇒ 缺席证书全拒 ⇒ 全域"假设有人"（比 v23 更保守，沿用 v21 的人距上限）；
- **CSPI 失效**（样本不足、界发散）⇒ `Bound_abs:=1` ⇒ 同 CxAC 失效；
- **ACPP 失效**（能量/安全包络不允许探针）⇒ 不做探针，用 CSPI 现有界判定；界不够则拒签；
- **GANL/GCRA 失效**（空白图谱损坏/审计器崩溃）⇒ 仅允许 v23 已部署模块，新模块一律不部署 ⇒ `Exec_v24 = Exec_v23`；
- **全部失效** ⇒ 完全回退 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ … ⊆ Exec_v18`（延续引理 162）。
- **安全继承**：CEG 只减票、CxAC 只作废缺席证书、CSPI 只收窄召回、空白治理只回退/停用；任意失效都向更保守方向退化。CEG/CxAC 以事件方式接入 v23 的 APS 新鲜度阶梯，控制路径仅做 O(1) 的"证书是否有效"查询。

## 5. 本轮最大风险

**一句话**：因果层的全部效力都押在**因果图 `G` 的正确性**与**敏感性参数 `Γ` 的下界**上——若 `G` 漏掉一个真实共因，或 `Γ` 低估了未测混杂的强度，则"因果独立"的仲裁与"反事实缺席"的证书会**形式成立、事实为假**，机器人将带着一张**带证明的因果盲区**撞上没被看见的人；这比 v23 的关联幻觉更危险，因为它现在多了一层看起来无懈可击的形式论证。

    EVIDENCE = "evidence"    # D_m
    VOTE = "vote"            # V_m（可观测的检测结论）


@dataclass
class CausalEvidenceGraph:
    """因果证据图：用 d-分离代替"模态数"，用共因等价类做因果 NMS。"""
    nodes: dict[str, NodeKind]
    edges: list[tuple[str, str]]                 # (parent, child)
    latent: set[str] = field(default_factory=set)   # 不可观测节点（含 H）

    def __post_init__(self):
        self.parents: dict[str, set[str]] = {n: set() for n in self.nodes}
        self.children: dict[str, set[str]] = {n: set() for n in self.nodes}
        for u, v in self.edges:
            self.parents[v].add(u)
            self.children[u].add(v)

    # ---- 基础图操作 -------------------------------------------------
    def ancestors(self, S: Iterable[str]) -> set[str]:
        seen, stack = set(), list(S)
        while stack:
            x = stack.pop()
            if x in seen:
                continue
            seen.add(x)
            stack.extend(self.parents[x])
        return seen

    def _ancestral_subgraph(self, keep: set[str]) -> set[str]:
        # keep 的祖先闭包；只保留在闭包内的边
        anc = self.ancestors(keep)
        return anc

    def _moral_adj(self, subset: set[str]) -> dict[str, set[str]]:
        """祖先子图 + 道德化：把每个节点的父节点两两相连。"""
        adj = {n: set() for n in subset}
        for v in subset:
            for u in self.parents[v] & subset:
                adj[u].add(v)
                adj[v].add(u)
            ps = sorted(self.parents[v] & subset)
            for a, b in combinations(ps, 2):            # 道德化
                adj[a].add(b)
                adj[b].add(a)
        return adj

    @staticmethod
    def _reachable(adj, src, blocked, dst=None) -> bool:
        seen, stack = set(), [src]
        while stack:
            x = stack.pop()
            if x in seen:
                continue
            seen.add(x)
            if dst is not None and x == dst:
                return True
            for y in adj.get(x, ()):
                if y not in blocked and y not in seen:
                    stack.append(y)
        return dst is None and bool(seen - {src})

    def d_separated(self, a: str, b: str, C_obs: Iterable[str]) -> bool:
        """Bayes-ball 等价实现：祖先子图 + 道德化 + 去掉 C_obs 后判连通。"""
        C = set(C_obs)
        keep = self.ancestors({a, b} | C)            # a,b,C 的祖先闭包
        adj = self._moral_adj(keep)
        return not self._reachable(adj, a, blocked=C, dst=b)

    def common_cause_class(self, evidence: list[str],
                           C_obs: Iterable[str]) -> dict[str, int]:
        """共因等价类：共享未阻断共同祖先的证据并成一类（并查集）。"""
        C = set(C_obs)
        parent = {e: e for e in evidence}

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(x, y):
            parent[find(x)] = find(y)

        # 两两检查：若 d-分离不成立（相关），且存在未阻断共同祖先，则并类
        for a, b in combinations(evidence, 2):
            if self.d_separated(a, b, C):
                continue
            anc_a, anc_b = self.ancestors({a}) - {a}, self.ancestors({b}) - {b}
            for c in anc_a & anc_b:
                if c in C:                            # 已调整的共同祖先
                    continue
                if self.parents.get(c) is not None:   # c 是真实（未阻断）共因
                    union(a, b)
                    break
        cls = {}
        for e in evidence:
            r = find(e)
            cls.setdefault(r, len(cls))
        return {e: cls[find(e)] for e in evidence}

    def max_independent_set(self, evidence: list[str],
                            C_obs: Iterable[str]) -> int:
        """N_ind：证据节点中两两 d-分离的最大集合的势。

        线上证据数 k≤8：O(k^3) 的极大团搜索；k>12 时退化为贪心（保守下界
        也够用，因为 N_ind 只用于"是否 ≥ M_min"的门槛判断）。"""
        C = set(C_obs)
        n = len(evidence)
        indep = [[False] * n for _ in range(n)]
        for i in range(n):
            indep[i][i] = True
            for j in range(i + 1, n):
                ok = self.d_separated(evidence[i], evidence[j], C)
                indep[i][j] = indep[j][i] = ok

        if n <= 12:
            best = 1
            # 精确最大团（Bron–Kerbosch，节点极少）
            def bk(R: set[int], P: set[int], X: set[int]):
                nonlocal best
                if not P and not X:
                    best = max(best, len(R))
                    return
                for v in list(P):
                    bk(R | {v},
                       {u for u in P if indep[v][u]},
                       {u for u in X if indep[v][u]})
                    P.discard(v)
                    X.add(v)
            bk(set(), set(range(n)), set())
            return best

        order = sorted(range(n), key=lambda i: -sum(indep[i]))
        chosen = []
        for i in order:
            if all(indep[i][j] for j in chosen):
                chosen.append(i)
        return max(1, len(chosen))

class CausalIdentifiedConsensus:
    """CFC++++：在 CFC+++ 的计数/层级/云边/IP 一致性之上，再加因果独立性。"""

    def __init__(self, base_cfc_plusplus, ceg: CausalEvidenceGraph,
                 m_min_ind: int = 2):
        self.base = base_cfc_plusplus
        self.ceg = ceg
        self.m_min_ind = m_min_ind

    def consensus_round(self, C_obs: Iterable[str]) -> dict:
        base_results = self.base.consensus_round()          # CFC+++ 原判定
        results = {}
        for key, verdict in base_results.items():
            if verdict == "CI":
                results[key] = "CI"
                continue
            votes = self.base.votes[key]
            ev = self._evidence_nodes(votes)
            try:
                classes = self.ceg.common_cause_class(ev, C_obs)
                n_ind = self.ceg.max_independent_set(ev, C_obs)
            except Exception:
                # 因果图不可信：按未阻断处理，退回 CFC+++ 的等价行为
                n_ind = 1

            dedup = self._dedup_by_class(votes, classes) if n_ind >= 1 else votes
            count_ok = len(dedup) >= self.base.N - self.base.F
            ind_ok = n_ind >= self.m_min_ind

            # 注意：这是"与"条件，故只可能比 CFC+++ 更严
            results[key] = (self.base._majority_with_outlier_filter(dedup)
                            if (count_ok and ind_ok) else "CI")
        return results

    def _evidence_nodes(self, votes: dict) -> list[str]:
        # 票 → 证据节点（vote 节点与其对应 evidence 节点同 id 前缀）
        return [f"E_{v.evidence_id}" for v in votes.values()]

    def _dedup_by_class(self, votes: dict, classes: dict[str, int]) -> dict:
        ev_to_vote = {f"E_{v.evidence_id}": k for k, v in votes.items()}
        rep = {}
        for ev, cls in classes.items():
            if cls not in rep:                 # 每类只保留一票
                rep[cls] = ev_to_vote[ev]
        return {k: votes[k] for k in rep.values()}

import math
from statistics import NormalDist


class CausalSensitivityModule:
    def __init__(self, delta_fp: float = 1e-3,
                 gamma_default: float = 2.0,
                 alpha_ci: float = 0.01):
        self.delta_fp = delta_fp
        self.gamma_default = gamma_default
        self.alpha_ci = alpha_ci
        self.D = {}                      # region -> list[bool] 受控干预检出记录
        self.gamma = {}                  # region -> Γ（先验；负对照可收紧）
        self.version = 0

    # ---- 受控干预校准 ------------------------------------------------
    def add_interventional_trials(self, region: str, hits: list[bool]):
        self.D.setdefault(region, []).extend(hits)
        self.version += 1

    def observed_recall(self, region: str) -> float:
        xs = self.D.get(region, [])
        if not xs:
            return 0.0                   # 无受控样本 => 召回视为 0（最保守）
        return sum(xs) / len(xs)

    def clopper_pearson_lower(self, hits: int, n: int, alpha: float) -> float:
        """二项比例的单侧 (1-alpha) 下界（用 Beta 分位数；此处给正态近似兜底）。"""
        if n == 0:
            return 0.0
        p = hits / n
        z = NormalDist().inv_cdf(1 - alpha)
        # Wilson 下界（保守且数值稳定）
        denom = 1 + z * z / n
        centre = p + z * z / (2 * n)
        rad = z * math.sqrt(p * (1 - p) / n + z * z / (4 * n * n))
        return max(0.0, (centre - rad) / denom)

    def gamma_corrected_recall(self, region: str) -> float:
        """Γ 敏感性：未测混杂最多把检出风险比压低 Γ 倍。"""
        xs = self.D.get(region, [])
        g = self.gamma.get(region, self.gamma_default)
        if not xs:
            return 0.0
        lo = self.clopper_pearson_lower(sum(xs), len(xs), self.alpha_ci)
        return lo / max(g, 1.0)

    # ---- 负对照收紧 Γ -------------------------------------------------
    def calibrate_gamma_with_negative_controls(self, region: str,
                                               nc_false_positive_rate: float):
        """负对照：已知无人的区域若仍报检出，说明存在"空背景假阳"通路；
        用它约束未测混杂强度上界（越大越保守）。"""
        g = max(self.gamma.get(region, 1.0),
                (1.0 + nc_false_positive_rate) * self.gamma_default)
        self.gamma[region] = g

    # ---- Manski 部分识别（无受控样本时的兜底） ------------------------
    @staticmethod
    def manski_causal_rate_bounds(p_det_and_present: float,
                                  p_present: float) -> tuple[float, float]:
        """P(D=1|do(H=1)) 的部分识别区间。

        X=H（是否有人），Y=D（是否检出）。观测只能给联合 P(D=1,H=1)，
        反事实项不可识别，故 b ∈ [P(D=1,H=1), P(D=1,H=1)+P(H=0)]。
        AbsCert 必须取左端点（保守下界）。"""
        lo = max(0.0, p_det_and_present)
        hi = min(1.0, p_det_and_present + (1.0 - p_present))
        return lo, hi

@dataclass
class AbsenceCertificate:
    region: str
    kappa_cause: float
    prior_max: float
    bound_abs: float
    eps_abs: float
    gamma: float
    probe_log: list
    assumptions: list[str]

    def valid(self) -> bool:
        return (self.bound_abs <= self.eps_abs
                and len(self.assumptions) == 0)   # 无可疑假设才有效


class CounterfactualAbsenceCertifier:
    def __init__(self, cspi: CausalSensitivityModule,
                 acpp: "ActiveProbePlanner",
                 gesture_channel,
                 ceg: CausalEvidenceGraph,
                 eps_abs: float = 1e-4):
        self.cspi = cspi
        self.acpp = acpp
        self.gesture = gesture_channel
        self.ceg = ceg
        self.eps_abs = eps_abs

    @staticmethod
    def bound_abs(kappa: float, prior: float) -> float:
        kappa = min(max(kappa, 0.0), 1.0 - 1e-12)
        prior = min(max(prior, 0.0), 1.0)
        return (1.0 - kappa) * prior / (1.0 - kappa * prior)

    def prior_max(self, region: str, class_id: str) -> float:
        # 区域先验上确界：无任何负信息时为 1（最保守）；
        # 有活动/声音/历史线索时由外源证据下调，但永不取 0。
        try:
            p = self.gesture.presence_prior_upper(region)
            return min(1.0, max(p, 0.0))
        except Exception:
            return 1.0

    def certify(self, region: str, detections, sensor_data: dict,
                class_id: str = "person"):
        # (0) 手势在场翻转：绝对优先（沿用 v23）
        try:
            if self.gesture.present_evidence(region):
                return None                       # 拒签，翻转为"有人"
        except Exception:
            return None                           # 手势通道失效 => 保守拒签

        # (1) 区域内不得已有检测
        if any(det.overlaps(region) for det in detections):
            return None

        # (2) 干预召回 + Γ 敏感性的保守下界
        k_obs = self.cspi.observed_recall(region)
        if k_obs <= 0.0:
            # 无受控干预样本：试 Manski 兜底；取左端点，通常不足 => 拒签
            return None
        k_cause = self.cspi.gamma_corrected_recall(region)
        pi = self.prior_max(region, class_id)
        bound = self.bound_abs(k_cause, pi)
        probe_log = []

        # (3) 若界不够窄，且探针可行 => 用主动干预收紧识别
        if bound > self.eps_abs and self.acpp.can_probe(region, sensor_data):
            try:
                hits = self.acpp.probe(region, sensor_data)
                self.cspi.add_interventional_trials(region, hits)
                probe_log = list(hits)
                k_cause = self.cspi.gamma_corrected_recall(region)
                bound = self.bound_abs(k_cause, pi)
            except Exception:
                return None                       # 探针失败 => 拒签

        # (4) 判定
        if bound <= self.eps_abs:
            assumptions = []
            if region not in self.cspi.gamma:
                assumptions.append("gamma_default_unverified")   # 记录可疑假设
            if pi < 1.0:
                assumptions.append("prior_narrowed_by_external_cue")
            return AbsenceCertificate(region, k_cause, pi, bound,
                                      self.eps_abs,
                                      self.cspi.gamma.get(region,
                                                         self.cspi.gamma_default),
                                      probe_log, assumptions)
        return None                               # 拒签 => 全域假设有人

class ActiveProbePlanner:
    def __init__(self, safe_envelope, energy_ledger, budget_joules: float = 5.0):
        self.safe_envelope = safe_envelope      # 必须是 v23 的 Exec_v23 包络
        self.energy = energy_ledger             # 计入 PGEV 的 E_res
        self.budget = budget_joules

    def can_probe(self, region: str, sensor_data: dict) -> bool:
        if self.budget <= 0:
            return False
        probe_plan = self._candidate(region)
        # 关键约束：探针本身也必须是 v23 已认证安全的计划
        if not self.safe_envelope.admits(probe_plan):
            return False
        return self.energy.E_res(sensor_data) >= self._cost(probe_plan)

    def _candidate(self, region: str):
        # 候选干预：微动视角 / 结构光闪烁 / 短暂照明变化；实现略
        return ProbePlan(region=region, kind="micro_pan", delta_joules=0.05)

    def _cost(self, plan) -> float:
        return plan.delta_joules

    def probe(self, region: str, sensor_data: dict) -> list[bool]:
        # 在若干候选干预中选期望信息增益最大者，执行并回收"是否检出"
        cands = [self._candidate(region)]
        best, best_ig = None, -1.0
        for a in cands:
            ig = self._expected_info_gain(a, sensor_data)
            if ig > best_ig and self._cost(a) <= self.budget:
                best, best_ig = a, ig
        if best is None:
            raise RuntimeError("no feasible probe")
        self.budget -= self._cost(best)
        return self._execute(best, sensor_data)

    def _expected_info_gain(self, plan, sensor_data) -> float:
        # I(κ; D | do(a)) 的蒙特卡洛近似；实现略
        return 1.0

    def _execute(self, plan, sensor_data) -> list[bool]:
        # 执行探针并记录剂量-反应；实现略
        return []

class ResearchGap:
    gid: str
    statement: str
    prior_art_why_not: str
    closure_test: str

    status: str = "open"                 # open/testing/closed/falsified

class ClaimCanonicalizer:
    """把贡献声明规范化并判定等价：先精确集合相等，再（可选）嵌入相似 + 人工裁决。"""

    SYNONYMS = {
        "absence": "negative_evidence",
        "negative": "negative_evidence",
        "permission": "unlock",
        "unlock": "unlock",
        "causal": "causal",
        "deconfound": "causal",
    }

    def canonicalize(self, statement: str) -> frozenset:
        import re
        toks = re.findall(r"[a-zA-Z_]+", statement.lower())
        toks = [self.SYNONYMS.get(t, t) for t in toks]
        return frozenset(t for t in toks if len(t) > 2)

    def equivalent(self, a: frozenset, b: frozenset,
                   emb_cos=None, thr: float = 0.9) -> bool:
        if a == b:
            return True
        if emb_cos is not None and emb_cos(a, b) >= thr:
            return True                     # 需人工裁决后落账
        return False


class GapAtlas:
    def __init__(self, canon: ClaimCanonicalizer):
        self.canon = canon
        self.gaps: dict[str, ResearchGap] = {}
        self.version = 0

    def register(self, g: ResearchGap) -> None:
        # 反换名：与任一已登记空白等价 => 拒绝新颖性声明
        for other in self.gaps.values():
            if self.canon.equivalent(other.canon, g.canon):
                raise ValueError(
                    f"relabel detected: {g.gid} ≈ {other.gid}；拒绝新颖性声明")
        g.canon = g.canon or self.canon.canonicalize(g.statement)
        self.gaps[g.gid] = g
        self.version += 1

    def run_closure(self, gid: str, experiment) -> bool:
        g = self.gaps[gid]
        g.status = "testing"
        try:
            ok = bool(experiment())          # 闭合实验（falsifier）
        except Exception:
            g.status = "falsified"
            return False
        g.status = "closed" if ok else "falsified"
        return ok

    def module_deployable(self, module: str, is_new_claim: bool) -> bool:
        if not is_new_claim:                 # v23 既有模块，无需新闭合实验
            return True
        return any(g.status == "closed" and module in g.modules
                   for g in self.gaps.values())

    def gap_debt(self) -> list[ResearchGap]:
        return [g for g in self.gaps.values()
                if g.status in ("open", "testing")]


class GapClosureRelabelingAuditor:
    def __init__(self, atlas: GapAtlas):
        self.atlas = atlas

    def audit(self, module: str, declared_gids: list[str]) -> bool:
        if not declared_gids:
            return False                     # 新模块必须声明闭合的空白
        for gid in declared_gids:
            g = self.atlas.gaps.get(gid)
            if g is None or g.status != "closed" or module not in g.modules:
                return False
        return True

@dataclass
class HPCECausalGapGate:
    hpc_e_plus: "HPCEPlus"                    # v23 四证门
    ceg: CausalEvidenceGraph
    ciq: CausalIdentifiedConsensus
    cxac: CounterfactualAbsenceCertifier
    cspi: CausalSensitivityModule
    gap_atlas: GapAtlas
    gc_auditor: GapClosureRelabelingAuditor

    def admits(self, plan, x, v, z, E_res, margin_req, modules,
               obs, region: str, C_obs) -> bool:
        # 1) v23 四证门
        if not self.hpc_e_plus.admits(plan, x, v, z, E_res,
                                      margin_req, modules):
            return False

        # 2) 因果独立仲裁（CFC++++ 已在调用方完成；此处复核门槛）
        try:
            ev = obs.evidence_nodes()
            if self.ceg.max_independent_set(ev, C_obs) < self.ciq.m_min_ind:
                return False
        except Exception:
            return False                       # 因果图不可信 => 拒

        # 3) 反事实缺席（若计划依赖"该区域无人"）
        if self._requires_absence(plan, region):
            cert = self.cxac.certify(region, obs.detections, obs.sensor_data)
            if cert is None or not cert.valid():
                return False

        # 4) 敏感性/部分识别（Γ 有据、样本达标）
        if not self.cspi.D.get(region):
            return False

        # 5) 空白闭合审计（仅对新 v24 模块强制）
        for m in modules:
            is_new = m.startswith("v24_")
            if not self.gap_atlas.module_deployable(m, is_new):
                return False
        for m, gids in obs.declared_gaps.items():
            if m.startswith("v24_") and not self.gc_auditor.audit(m, gids):
                return False

        return True

    @staticmethod
    def _requires_absence(plan, region: str) -> bool:
        return region in plan.assumed_empty_regions

    def step(self, sensor_data: dict) -> tuple[bool, dict]:

        if not ok23:
            return False, {"reason": "v23_gate", **info23}

        C_obs = sensor_data.get("C_obs", {"L", "O", "T", "S_h", "Fw"})

            info23["modules"], obs, sensor_data["region"], C_obs)
        return admitted, {
            "consensus": consensus,
            "n_ind": self.ceg.max_independent_set(obs.evidence_nodes(), C_obs),
            "gap_debt": [g.gid for g in self.atlas.gap_debt()],

## 3. 正确性论证

### 引理 5（因果独立仲裁只会收缩执行集）
**陈述**：对任意票集，`N_ind ≤ M`（模态数），且 CFC++++ 的通过条件包含 CFC+++ 的全部条件并额外要求 `N_ind ≥ M_min`，故 `Exec_with_CFC++++ ⊆ Exec_with_CFC+++`。

**证明**：
1. CFC++++ 的实现先调用 `base.consensus_round()`（CFC+++），凡 base 判 `CI` 者直接 `CI`；只在 base 通过时追加 `N_ind ≥ M_min` 与共因去重。因此通过集合是 base 通过集合的子集（连言只增不减）。
2. `N_ind` 是证据节点中两两 d-分离集合的势，必然 ≤ 证据总数 `M`；若模态两两独立则取等，若存在共因则严格 `< M`。故门槛 `N_ind ≥ M_min` 至少不弱于 `M ≥ M_min`。
3. 共因去重（每等价类计一票）只会减少计数，不会增加。
4. 任一 CEG 异常被 `except` 捕获并置 `n_ind=1`，结果退回 base 行为，仍是子集。
∎

**推论（封死"众口一病"）**：若全部模态共享一个未进入 `C_obs` 的共同祖先 `c`（同一反光板/固件/训练偏差），则任意两票在给定 `C_obs` 下均不 d-分离，`N_ind=1 < M_min`，仲裁返回 `CI`，不签发 SAFE——共因伪共识在结构上被阻断。

### 引理 6（反事实缺席的上界与失效安全）
**陈述**：设区域 `R` 内 `κ := P(D=1|do(H=1,R)) = κ_c^cause`、`P(H=1) ≤ π := π_R^max`、假阳性 `P(D=1|H=0)=f ≥ 0`。则在观测到 `D=0` 时
`P(H=1|D=0) ≤ Bound_abs(R) = (1-κ)π / (1-κπ)`；
若 `Bound_abs > ε_abs`，或 `κ` 不可识别，或手势有在场证据，则证书**拒签**，系统退回"假设有人"，执行集只收缩。

**证明**：
1. 由贝叶斯公式
   `P(H=1|D=0) = (1-κ)π / [ (1-κ)π + (1-f)(1-π) ]`。
2. 因 `1-f ≤ 1`，分母 `≤ (1-κ)π + (1-π) = 1 - κπ`；又分子 `≥0`，故
   `P(H=1|D=0) ≤ (1-κ)π / (1-κπ) = Bound_abs(R)`。取 `f=0` 得到的是保守（最大）上界，故成立。
3. 若 `κ` 由受控干预校准得到并经 Γ 修正 `κ_cause ≥ κ_obs/Γ`，则代回的 `Bound_abs` 是真实上界的进一步上界；若无法给出合法 `κ_cause`（无受控样本、`Γ` 无据、探针失败），证书构造上返回 `None`。
4. 拒签后由 P44 退回 v21 的"全域假设有人"规则，该规则本就 ∈ `Exec_v23`，故执行集单调不增。
5. 边界一致性：`π=1` 时 `Bound_abs = (1-κ)/(1-κ) = 1 > ε_abs`，必然拒签——自动退化为"覆盖区外一律保守"，与 v21 规则吻合。
∎

### 引理 7（空白治理安全中性）
**陈述**：`Fil_gap`（GCC/GCRA）只能把新模块回退到其 v23 前身或停用，永不放行 v23 之外的计划；因此 `Exec_v24 ⊆ Exec_v23` 与空白治理无关地成立。

**证明**：
1. 新模块 `m`（前缀 `v24_`）部署必须 `∃g: status=closed ∧ m ∈ g.modules`；失败时按接口约定回退 `m` 的 v23 前身 `m⁻`，而 `m⁻ ∈ Exec_v23`。
2. `≈_claim` 判定为换名 ⇒ 视为"未声明空白"⇒ 同样回退 `m⁻`。
3. 闭合实验**证伪**旧声明 ⇒ 停用对应模块，只会更保守。
4. 上述三种处理都不引入新自由空间；v23 既有模块（`is_new_claim=False`）直接通过，保持 v23 行为。
∎

### 引理 8（因果-空白层单调退化链）
**陈述**：任意单点或组合失效下，`Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18` 恒成立。

**证明**：
- `Exec_v24 = Exec_v23 ∩ Fil_caus ∩ Fil_cf ∩ Fil_gap`，按定义是交集，天然 ⊆ `Exec_v23`。
- CEG 失效 ⇒ `n_ind=1` ⇒ CFC++++ 退回 CFC+++（等价 v23）。
- CxAC/CSPI/ACPP 任一失效 ⇒ 缺席证书拒签 ⇒ 全域假设有人（比 v23 更保守，仍 ⊆ v23）。
- GANL/GCRA 失效 ⇒ 新模块不部署 ⇒ 等于 v23。
- 组合失效取交集，单调性由交集保持；后半段 `v23⊆v22⊆…` 由 v23 的引理 4 继承。
∎

### 定理（HPC-E++ 五证一体的安全-因果-科研诚信完备性）
**陈述**：对任意计划 `π`，`HPCECausalGapGate.admits(π)=True` 当且仅当同时满足：
(1) v23 四证（物理接地 ∧ 云边一致 ∧ 少样本覆盖 ∧ 专利完备）；
(2) 因果独立票数 `N_ind ≥ M_min`（独立佐证）；
(3) 若 π 依赖某区域无人，则该区域反事实缺席证书有效（`Bound_abs ≤ ε_abs`，手势无在场）；
(4) 敏感性/部分识别样本达标且 `Γ` 有据；
(5) 所有新模块的空白闭合实验通过且无换名。

**证明**：`admits` 是上述五项连言（含 `_requires_absence` 条件分支与 `except→False`）。必要性：任一为假即返回 `False`。充分性：五项同真时，由引理 5 保证独立仲裁不比 v23 弱、引理 6 保证缺席陈述反事实成立、引理 7 保证空白治理不越权、引理 8 保证执行集单调链；合起来给出"证据独立 ∧ 缺席反事实 ∧ 贡献可证伪"的闭环。
∎
