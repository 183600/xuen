# 第 62 轮（承接第 61 轮「具身语义进化闭环」ESEC；灵感循环第 8 轮；本轮灵感：「微调」×「力控」）

> 第 61 轮构建了「具身语义进化闭环」：USR 打通场景/意图/阻抗/证据的向量空间，MEL 提供零样本物理先验，DMS 实现多轮接地，SRT-Dual 解耦语义与实时，PCE+++++ 六维兜底。但**四个更深的局限**暴露出来：
> 1. **MEL 是「冻结的旁观者」**：第 61 轮只提了 LoRA 微调，却没有在线微调闭环。部署后模型不再从真实接触中学习，sim2real gap 无法收敛；零样本先验一旦系统性偏差（如普遍低估摩擦），就会永久偏差。
> 2. **USR/Π 是「静态投影」**：对齐损失用 Adam 在线更新，却缺乏稳定性与遗忘防护。投影头随新场景漂移时，旧场景表征被覆盖（灾难性遗忘），语义-控制一致性无法长期保持。
> 3. **力控是「隐式的」**：第 61 轮只输出阻抗 K（刚度/阻尼），没有显式接触力跟踪闭环。φ_phys 推断摩擦/刚度，却没有用实测力反馈校正；面对未知接触刚度、时变负载，稳态力误差无法消除。
> 4. **快慢耦合是「开环的」**：SRT-Dual 把语义流与实时流分开，但语义先验如何安全影响力控、力控残差如何反哺语义，只是单向「锚点投影」，没有双向、带稳定性的适应闭环。微调与力控一旦同时在线，可能互相激发振荡。

## 0. 直觉与动机

**灵感 1（「微调」的双关 → 双尺度微调 DFT）**
直觉：「微调」在机器学习里是 fine-tuning（LoRA/Adapter），在控制里是 fine adjustment（增益/设定点微调）。这不是巧合——两者都是「在已有结构上做小幅度、受约束的修正」。关键洞见：构建 **双尺度微调（Dual Fine-Tuning, DFT）**：慢尺度（~1-10Hz）对 MEL 做参数高效微调，快尺度（~100Hz-1kHz）对力控制器做增益与设定点微调；两者共享同一个「微调预算」与同一个「微调安全壳」。微调不再是模型的独角戏，而是「语义参数 + 控制参数」的联合小幅修正。

**灵感 2（力是语义与现实的接触面 → 力残差学习信号 FRLS）**
直觉：视觉告诉你「这是什么」，力告诉你「它到底有多硬、多滑」。力残差 r_f = F_measured − F_desired 是唯一同时包含「模型预测误差」与「控制跟踪误差」的物理量。关键洞见：把 r_f 分解为偶然残差 r_al（接触噪声、未建模高频）、认知残差 r_ep（物理属性先验错误）、控制残差 r_ctrl（增益不匹配）；r_al 交给鲁棒/自适应力控快速抑制，r_ep 交给 MEL 慢速微调，r_ctrl 交给增益调度——**同一个力残差，三个成分，两个时间尺度，各取所需**。

**灵感 3（无源性能量罐 → 保无源微调 PPA）**
直觉：力控最怕「向系统注入能量」导致接触振荡；在线微调最怕「参数漂移」导致闭环失稳。两者可被同一个物理约束统一：**无源性（passivity）**。关键洞见：设置「能量罐」E_tank，力控自适应的每一步、模型微调的每一次参数更新都必须「从罐中取能量」；当 E_tank 低于阈值时冻结对应层级的自适应，退化为固定增益的保守控制——**适应必须「自付能量」，不允许凭空产生能量**。

**灵感 4（约束流形 → 力条件适应流形 FCAM）**
直觉：不是所有参数方向都值得调。有的方向改变接触力（力敏感），有的方向只改变语义表征（力不敏感）。关键洞见：在参数空间中定义 **力条件适应流形 M_adapt**：只允许沿「力敏感 ∧ 无源保持 ∧ 信赖域内」的方向微调；用 Fisher 信息/力灵敏度选方向，用 LoRA 低秩压维度，用 EWC 锚定旧任务。微调从「自由梯度下降」升级为「流形上的受约束投影」。

**灵感 5（学会微调 → 力知情元学习 FIML）**
直觉：若每遇新场景都从零微调，太慢。元学习可「学会如何快速微调」。关键洞见：用 **力知情元学习（FIML）** 学习初始化 θ_meta，使面对新接触任务时仅需 k 步力残差梯度即可把力跟踪误差降到阈值以下；元目标直接是「k 步后的力跟踪误差」，而非普通任务损失。

**灵感 6（三流架构 → SRT-Tri 语义-适应-实时）**
直觉：第 61 轮是「语义流 vs 实时流」双流，但适应发生在两者之间，需要独立时间尺度。关键洞见：插入 **适应流（Adaptation Lane, ~100Hz-1kHz）**：语义流输出「适应超参数」（信赖域半径、力敏感掩码、元初始化），适应流执行力控增益微调与接触刚度在线辨识，实时流执行固定结构的力/阻抗内环。三流以「最新值语义 + 能量罐闸门」解耦，任一上游超时则下游冻结在上一有效参数。

**总纲**：把「微调」与「力控」合成一个闭环——**力残差是学习信号，微调是被无源性约束的小步修正，力控是承载微调的快速执行面**。一句话：**在接触面上学习，在能量罐里适应。**

## 1. 形式化定义（增量：定义 173–184）

**定义 173（双尺度微调 DFT）** DFT = (Θ_slow, Θ_fast, ρ, C_couple, τ_sep)。其中：
- **慢尺度参数**：Θ_slow = (θ_mel^LoRA, θ_Π)，MEL 的低秩适配器与 USR 投影头，更新频率 ~1-10Hz
- **快尺度参数**：Θ_fast = (K_p, K_d, F_d, k̂_e, δ_ff)，力控刚度/阻尼/力设定点/接触刚度估计/前馈，更新频率 ~100Hz-1kHz
- **超参数映射**：ρ: Θ_slow → Θ_fast，把信赖域半径、力敏感掩码、元先验映射为快尺度初值与边界
- **双向耦合**：C_couple = (C_{f→s}: 力残差统计 → 微调损失；C_{s→f}: 适应超参数 → 力控边界)
- **时间尺度分离**：τ_sep = τ_slow/τ_fast ≥ 100，奇异摄动小参数 ε = τ_fast/τ_slow ≤ 0.01

**定义 174（力残差分解 FRD）** 力残差 r_f(t) = F_m(t) − F_d(t)，分解为：
```
r_f(t) = r_al(t) + r_ep(t) + r_ctrl(t)
r_al  : 偶然残差（接触噪声、未建模高频、传感器噪声）——不可通过学习消除
r_ep  : 认知残差（φ_phys 系统性错误导致的低频稳态偏差）——可由 MEL 微调消除
r_ctrl: 控制残差（增益不匹配导致的瞬态误差）——可由力控自适应消除
```
分离方法：
```
r_al   = HPF(r_f)                                   # 高频零均值成分
r_ep   = LPF(r_f) − r_ctrl^ss                       # 低频稳态偏置扣除控制稳态残差
r_ctrl = C(s)·(K_p^nom − K_p(t))·δ(t)               # 由增益失配模型估计的瞬态成分
```
可辨识性条件：在接触过程中注入小幅多频探测（dither），保证 r_ep 与 r_ctrl 在频域可分离。

**定义 175（保无源适应 PPA / 能量罐）** 能量罐 E_tank(t) ≥ 0，动态：
```
dE_tank/dt = P_in(t) − P_adapt(t) − P_diss(t)
P_in     : 接触中可回收功率（仅在 |r_f| 小且接触稳定时充能）
P_adapt  : 自适应/微调消耗功率 = |Δθ^T ∂V/∂θ| / τ_adapt
P_diss   : 无源耗散（阻尼、摩擦），恒 ≥ 0
```
闸门规则：
- 力控更新允许 ⇔ E_tank ≥ E_min^fast
- 微调更新允许 ⇔ E_tank ≥ E_min^slow（E_min^slow ≫ E_min^fast）
- E_tank < E_min^slow：冻结 LoRA 更新，仅保留力控自适应
- E_tank < E_min^fast：冻结一切自适应，回退固定保守增益 (K_p^0, K_d^0)
无源保持条件：闭环存储函数 V(x) 满足 V̇ ≤ r_f^T ẋ − P_adapt，即自适应不增加系统总能量。

**定义 176（力条件适应流形 FCAM）** 参数空间中的可安全微调子集：
```
M_adapt = { (Δθ_slow, Δθ_fast) :
            ‖Δθ_slow‖_F ≤ ε_trust(t),
            Δθ_fast ∈ K_passive,
            s_l ≥ s_min  (l ∈ 被更新层),
            E_tank ≥ E_min^slow }
s_l = ‖∂F̂/∂θ_l‖                       # 层 l 的力灵敏度
K_passive = { (K_p,K_d) : K_p ≥ 0, K_d ≥ 2√(M_d K_p)·ζ_min }   # 无源增益集
```
微调投影：Δθ* = Proj_{M_adapt}(−η ∇L_ft)，先沿力敏感方向选层，再低秩压缩，最后信赖域裁剪。

**定义 177（安全信赖域微调 STFT）** LoRA 更新 ΔW = (α/r) B A，A∈ℝ^{r×d_in}, B∈ℝ^{d_out×r}，r ≪ min(d_in,d_out)。损失：
```
L_ft = ‖r_ep‖²_Σ + λ_ewc Σ_i F_i (θ_i − θ_i^*)² + λ_trust ‖B A‖²_F
```
约束：
```
‖B A‖_F ≤ ε_trust(t),   ε_trust(t) = ε_0 · min(1, E_tank/E_min^slow)
仅更新力敏感 top-k 层（按 s_l 排序，k = B_ft.top_k）
EWC 权重 F_i：旧任务 Fisher 信息对角近似
```

**定义 178（增益调度自适应力控 GSAIC）** 接触模型 F_m = k_e·δ + b_e·δ̇ + F_bias，k_e 未知且慢时变。带遗忘因子的递推最小二乘（RLS）在线辨识：
```
P(t+1) = (1/λ_rls)·(P(t) − P(t)²δ² / (λ_rls + P(t)δ²))
k̂_e(t+1) = k̂_e(t) + P(t+1)·δ·(F_m − k̂_e(t)·δ)
μ(t) = μ_0 · σ(E_tank)                       # 能量罐调制辨识步长
```
力设定点微调与前馈：
```
δ_r(t) = F_d / k̂_e(t) + δ_ff(t)
δ_ff(t) = −b̂_e·δ̇/k̂_e(t) + F_bias/k̂_e(t)
```
增益调度：
```
K_p(t) = clip(K_p^0 · k̂_e(t)/k_e^nom, K_p^min, K_p^max)
K_d(t) = clip(K_d^0 · sqrt(k̂_e(t)/k_e^nom), K_d^min, K_d^max)
```
接触稳定判据（临界阻尼下限）：K_d ≥ 2√(M_d K_p)·ζ_min，ζ_min 默认 0.7。

**定义 179（回放与抗遗忘缓冲 RAFB）** 优先经验回放：
```
D_rep = { (φ_phys, contact_ctx, r_f, task_id) }
优先级 p_i ∝ |r_ep,i|² + ε_rep
微调 mini-batch：50% 当前接触 + 50% 回放（按优先级采样）
EWC 权重：F_i ← F_i + (∂log p(y|x,θ)/∂θ_i)²，按任务累积
遗忘度量：FM = (1/|D_old|) Σ_{(x,y)∈D_old} |F̂_new(x) − F̂_old(x)|
```

**定义 180（力知情元学习 FIML）** 元参数 θ_meta，任务分布 p(T) 为不同材质/几何/负载的接触任务：
```
内循环（k 步，仅力残差损失）：
  θ'_0 = θ_meta
  θ'_{j+1} = θ'_j − α ∇_θ L_ft(θ'_j; D_T^support),  j=0..k−1
外循环：
  θ_meta ← θ_meta − β ∇_{θ_meta} Σ_T L_ft(θ'_k; D_T^query)
元目标：min_θmeta E_T[ ‖r_f(θ'_k)‖² ]，目标 k ≤ 10 步内 ‖r_f‖ < τ_ft（默认 0.5N）
```

**定义 181（适应预算 PCE++++++）** 在六维认知-语义预算上再增适应维度：
```
B_adapt = (B_ft, B_fc, B_tank, B_replay)
B_ft     = (LoRA_rank, Trust_radius, Update_freq, EWC_lambda, Top_k)
B_fc     = (Adapt_gain, Gain_bounds, Ident_rate, RLS_forget)
B_tank   = (E_capacity, E_min_fast, E_min_slow, Recharge_rate)
B_replay = (Buffer_size, Replay_ratio, Priority_power, Forget_tol)
cost_adapt = λ_ft·(Update_iters/Max_iters + ‖Δθ‖/ε_trust)
           + λ_fc·(Adapt_rate/Adapt_max)
           + λ_tank·(1 − E_tank/E_capacity)
           + λ_rep·(Replay_size/Buffer_max)
```
降级策略：
- B_ft 耗尽 → 冻结 LoRA，仅保留元先验 θ_meta
- B_fc 耗尽 → 固定保守增益 (K_p^0, K_d^0)
- B_tank 耗尽 → 全局冻结自适应（最高安全级）
- B_replay 耗尽 → 禁止在线微调（只允许元先验前向，避免遗忘）

**定义 182（适应证书 J_adapt）** 把「这次适应是否安全」变成可验证证书：
```
J_adapt = (Δθ_norm, E_tank, r_f_rmse, FM_forget, passivity_margin,
           meta_steps, anchor_version, ft_layer_mask_hash)
Valid(J_adapt) ⇔ Δθ_norm ≤ ε_trust ∧ E_tank ≥ E_min^slow
              ∧ r_f_rmse ≤ τ_force ∧ FM_forget ≤ τ_forget
              ∧ passivity_margin ≥ 0
J_adapt_exec = (J_sem_exec, J_adapt)   # 并入第 61 轮语义-执行联合证书
```

**定义 183（力条件语义锚点 FCSA）** 升级第 61 轮语义锚点，加入力残差与适应状态：
```
Anchor_t^force = (scene_emb, intent_emb, phys_prior, r_f_emb,
                  adapt_state, U_mel, version, timestamp, checksum)
r_f_emb     = E_force(频域特征(r_f), 统计特征(r_f))      # 力残差嵌入
adapt_state = (k̂_e, Δθ_norm, E_tank, meta_steps, ft_mask_hash)
```
三流共享同一锚点但各取字段：实时流只读 K 先验与 δ_r；适应流读 k̂_e 初值、增益边界、E_tank；语义流读 r_f_emb 与 U_mel。

**定义 184（自适应力-具身闭环 AFEC）** AFEC = (Lane_S ∘ Lane_A ∘ Lane_R, PPA, J_adapt_exec)。三流：
```
Lane_S (~1-10Hz)  语义流：MEL.infer → DMS → STFT/LoRA 微调 → USR/FCSA 写入
Lane_A (~100Hz-1kHz) 适应流：GSAIC 增益微调 + k̂_e 辨识 + FRD 分解 + RAFB 入缓冲
Lane_R (~1-10kHz) 实时流：固定结构力/阻抗内环，消费 Lane_A 的 K(t)、δ_r(t)
耦合：Lane_S → Lane_A 写超参数；Lane_A → Lane_S 写 r_ep 统计；PPA 统一闸门
```

### IP-183/186/187 DFT + FCAM + STFT（双尺度微调）

```python
class DualScaleFineTuner:
    def __init__(self, mel, usr, budget, energy_tank, d_us=256, lora_rank=8):
        self.mel = mel
        self.usr = usr
        self.budget = budget
        self.tank = energy_tank
        self.lora_rank = lora_rank
        self.ewc = EWCRegularizer()
        self.replay = ReplayForgettingBuffer(capacity=5000)
        self.force_sensitivity = {}  # layer -> s_l

    def estimate_force_sensitivity(self, batch):
        for name, p in self.mel.named_lora_parameters():
            g = torch.autograd.grad(self._force_loss(batch), p, retain_graph=True)[0]
            self.force_sensitivity[name] = g.norm().item()
        return self.force_sensitivity

    def select_force_relevant_layers(self, top_k=4):
        ranked = sorted(self.force_sensitivity.items(), key=lambda kv: -kv[1])
        return {name for name, _ in ranked[:top_k]}

    def _force_loss(self, batch):
        phi_phys, z_scene, _, U = self.mel.infer(*batch.obs)
        F_pred = self._contact_model(phi_phys, batch.delta, batch.delta_dot)
        r_ep = batch.F_measured - F_pred
        return (r_ep ** 2).mean()

    def project_to_manifold(self, grads, trust_radius):
        # 1) 力敏感层掩码
        mask = self.select_force_relevant_layers(self.budget.B_ft.top_k)
        # 2) LoRA 低秩已在结构上保证；3) 信赖域裁剪
        norm = torch.sqrt(sum(g.norm() ** 2 for n, g in grads.items() if n in mask))
        scale = min(1.0, trust_radius / (norm + 1e-8))
        return {n: g * scale for n, g in grads.items() if n in mask}

    def slow_step(self, batch, anchor_version):
        if not self.tank.allow_slow():
            return None  # 能量不足，冻结微调
        eps_trust = self.budget.B_ft.trust_radius * min(
            1.0, self.tank.E / self.tank.E_min_slow)
        loss = self._force_loss(batch) + self.ewc.penalty() + self._replay_loss()
        grads = torch.autograd.grad(loss, self._lora_params(), create_graph=False)
        gmap = {n: g for n, g in zip(self._lora_names(), grads)}
        gmap = self.project_to_manifold(gmap, eps_trust)
        self._apply_grads(gmap)
        self.ewc.update_fisher(batch)
        self.replay.push(batch)
        J = AdaptationCertificate.from_step(
            delta_norm=self._grad_norm(gmap), E_tank=self.tank.E,
            r_f_rmse=batch.r_f_rmse, FM=self.replay.forgetting_metric(),
            passivity_margin=self.tank.margin(), anchor_version=anchor_version)
        return J if J.valid() else self._rollback()
```

### IP-184 FRD（力残差分解）

```python
class ForceResidualDecomposer:
    def __init__(self, fs=1000, fc_split=5.0):
        self.hpf = HighPass(fc_split, fs)
        self.lpf = LowPass(fc_split, fs)
        self.gain_mismatch_model = GainMismatchModel()

    def decompose(self, F_m, F_d, delta, delta_dot, K_p_nom, K_p):
        r_f = F_m - F_d
        r_al = self.hpf(r_f)
        r_ctrl = self.gain_mismatch_model(delta, delta_dot, K_p_nom, K_p)
        r_ep = self.lpf(r_f) - self.gain_mismatch_model.steady_state()
        return ForceResidual(r_al=r_al, r_ep=r_ep, r_ctrl=r_ctrl, total=r_f)
```

### IP-185 PPA（能量罐与无源闸门）

```python
class PassivityEnergyTank:
    def __init__(self, capacity=1.0, e_min_fast=0.1, e_min_slow=0.3,
                 recharge_rate=0.2, dissipate_rate=0.05):
        self.E = capacity * 0.5
        self.E_cap = capacity
        self.E_min_fast = e_min_fast
        self.E_min_slow = e_min_slow
        self.recharge_rate = recharge_rate
        self.dissipate_rate = dissipate_rate

    def step(self, p_in, p_adapt):
        self.E += (p_in - p_adapt - self.dissipate_rate) * self.dt
        self.E = max(0.0, min(self.E_cap, self.E))
        return self.E

    def allow_fast(self):
        return self.E >= self.E_min_fast

    def allow_slow(self):
        return self.E >= self.E_min_slow

    def margin(self):
        return self.E - self.E_min_fast
```

### IP-188 GSAIC（自适应力控）

```python
class GainScheduledAdaptiveForceController:
    def __init__(self, K_p0=500.0, K_d0=30.0, M_d=1.0, zeta_min=0.7,
                 rls_forget=0.995, mu0=0.05):
        self.K_p0, self.K_d0, self.M_d = K_p0, K_d0, M_d
        self.zeta_min = zeta_min
        self.lam = rls_forget
        self.mu0 = mu0
        self.k_hat = 1000.0
        self.P = 1.0

    def update_stiffness(self, delta, F_m, E_tank):
        mu = self.mu0 * (E_tank / (E_tank + 1.0))
        self.P = (1 / self.lam) * (self.P - (self.P ** 2 * delta ** 2) /
                                   (self.lam + self.P * delta ** 2))
        self.k_hat += mu * self.P * delta * (F_m - self.k_hat * delta)
        return self.k_hat

    def schedule_gains(self, k_nom):
        K_p = np.clip(self.K_p0 * self.k_hat / k_nom, 0.2 * self.K_p0, 3.0 * self.K_p0)
        K_d = np.clip(self.K_d0 * np.sqrt(self.k_hat / k_nom),
                      0.2 * self.K_d0, 3.0 * self.K_d0)
        K_d = max(K_d, 2 * np.sqrt(self.M_d * K_p) * self.zeta_min)
        return K_p, K_d

    def force_setpoint(self, F_d, delta_dot, b_hat=0.0, F_bias=0.0):
        delta_r = F_d / max(self.k_hat, 1e-6)
        delta_ff = (-b_hat * delta_dot + F_bias) / max(self.k_hat, 1e-6)
        return delta_r + delta_ff
```

```python
class ReplayForgettingBuffer:
    def __init__(self, capacity=5000, replay_ratio=0.5, forget_tol=0.1):
        self.buf = deque(maxlen=capacity)
        self.replay_ratio = replay_ratio
        self.forget_tol = forget_tol
        self.old_force_predictions = {}

    def push(self, batch):
        priority = (batch.r_ep ** 2).mean().item() + 1e-6
        self.buf.append((priority, batch))

    def sample(self, n):
        priorities = np.array([p for p, _ in self.buf]) ** 0.6
        idx = np.random.choice(len(self.buf), size=n, p=priorities / priorities.sum())
        return [self.buf[i][1] for i in idx]

    def forgetting_metric(self):
        return np.mean([abs(self.old_force_predictions[k] - v)
                        for k, v in self._current_predictions().items()] or [0.0])


class ForceInformedMetaLearner:
    def __init__(self, model, inner_lr=1e-3, meta_lr=1e-4, k_steps=10):
        self.model = model
        self.alpha = inner_lr
        self.beta = meta_lr
        self.k = k_steps

    def inner_adapt(self, support, theta=None):
        theta = theta or self.model.meta_params()
        for _ in range(self.k):
            loss = self._force_loss(support, theta)
            theta = [p - self.alpha * g for p, g in
                     zip(theta, torch.autograd.grad(loss, theta))]
        return theta

    def meta_step(self, task_batch):
        meta_grads = []
        for support, query in task_batch:
            theta_prime = self.inner_adapt(support)
            loss_q = self._force_loss(query, theta_prime)
            meta_grads.append(torch.autograd.grad(loss_q, self.model.meta_params()))
        self._apply_meta_update(meta_grads, self.beta)
```

```python
class AdaptiveForceEmbodiedLoop:
    def __init__(self, mel, dms, usr, eeis, ertc, budget, tank):
        self.mel, self.dms, self.usr = mel, dms, usr
        self.eeis, self.ertc, self.budget = eeis, ertc, budget
        self.tank = tank
        self.frd = ForceResidualDecomposer()
        self.gsaic = GainScheduledAdaptiveForceController()
        self.ft = DualScaleFineTuner(mel, usr, budget, tank)
        self.replay = ReplayForgettingBuffer()
        self.fcsa = ForceConditionedAnchor()

    def lane_semantic(self, obs, utterance):
        phi_phys, z_scene, pi_intact, U = self.mel.infer(*obs)
        a_diag, C_pending, b_intent = self.dms.step(U)
        anchor = self.fcsa.commit(z_scene, b_intent, phi_phys, U)
        return anchor, a_diag

    def lane_adaptation(self, anchor, F_m, F_d, delta, delta_dot):
        if not self.tank.allow_fast():
            return self.gsaic.freeze()
        r = self.frd.decompose(F_m, F_d, delta, delta_dot,
                               self.gsaic.K_p0, self.gsaic.K_p)
        self.gsaic.update_stiffness(delta, F_m, self.tank.E)
        K_p, K_d = self.gsaic.schedule_gains(self.gsaic.k_hat)
        delta_r = self.gsaic.force_setpoint(F_d, delta_dot)
        self.replay.push(ContactBatch(anchor.phys_prior, r.r_ep, F_m, delta))
        return K_p, K_d, delta_r, r.r_ep

    def lane_realtime(self, K_p, K_d, delta_r, F_d):
        tau = self.eeis.compile_force(K_p, K_d, delta_r, F_d)
        return self.ertc.dispatch_torque(tau)

    def step(self, obs, utterance, F_m, F_d, delta, delta_dot):
        anchor, a_diag = self.lane_semantic(obs, utterance)
        K_p, K_d, delta_r, r_ep = self.lane_adaptation(
            anchor, F_m, F_d, delta, delta_dot)
        tau = self.lane_realtime(K_p, K_d, delta_r, F_d)
        if self.tank.allow_slow() and self.budget.ft_available():
            J = self.ft.slow_step(ContactBatch(obs, r_ep, delta, delta_dot), anchor.version)
            if J and not J.valid():
                self.tank.freeze_all()
        return tau, J
```

```python
class DualScaleFineTuner:
    def __init__(self, mel, usr, budget, tank, lora_rank=8):
        self.mel, self.usr, self.budget, self.tank = mel, usr, budget, tank
        self.lora_rank = lora_rank
        self.ewc = EWCRegularizer()
        self.replay = ReplayForgettingBuffer(capacity=5000)
        self.sensitivity = {}

    def estimate_sensitivity(self, batch):
        for name, p in self.mel.named_lora_parameters():
            g = torch.autograd.grad(self._force_loss(batch), p, retain_graph=True)[0]
            self.sensitivity[name] = g.norm().item()

    def project(self, grads, trust_radius):
        topk = set(sorted(self.sensitivity, key=self.sensitivity.get,
                          reverse=True)[:self.budget.B_ft.top_k])
        norm = torch.sqrt(sum(g.norm()**2 for n, g in grads.items() if n in topk))
        scale = min(1.0, trust_radius / (norm + 1e-8))
        return {n: g * scale for n, g in grads.items() if n in topk}

    def slow_step(self, batch, anchor_version):
        if not self.tank.allow_slow():
            return None
        eps = self.budget.B_ft.trust_radius * min(1.0, self.tank.E / self.tank.E_min_slow)
        loss = self._force_loss(batch) + self.ewc.penalty() + self._replay_loss()
        grads = dict(zip(self._lora_names(),
                         torch.autograd.grad(loss, self._lora_params())))
        g = self.project(grads, eps)
        self._apply(g)
        self.ewc.update_fisher(batch)
        self.replay.push(batch)
        J = AdaptationCertificate(self._grad_norm(g), self.tank.E, batch.r_f_rmse,
                                  self.replay.forgetting_metric(), self.tank.margin(),
                                  anchor_version)
        return J if J.valid() else self._rollback()
```

```python
class GainScheduledAdaptiveForceController:
    def __init__(self, K_p0=500., K_d0=30., M_d=1., zeta_min=0.7, lam=0.995, mu0=0.05):
        self.K_p0, self.K_d0, self.M_d = K_p0, K_d0, M_d
        self.zeta_min, self.lam, self.mu0 = zeta_min, lam, mu0
        self.k_hat, self.P = 1000.0, 1.0

    def update_stiffness(self, delta, F_m, E_tank):
        mu = self.mu0 * (E_tank / (E_tank + 1.0))
        self.P = (1/self.lam) * (self.P - self.P**2 * delta**2 /
                                 (self.lam + self.P * delta**2))
        self.k_hat += mu * self.P * delta * (F_m - self.k_hat * delta)
        return self.k_hat

    def schedule(self, k_nom):
        K_p = np.clip(self.K_p0 * self.k_hat / k_nom, 0.2*self.K_p0, 3*self.K_p0)
        K_d = np.clip(self.K_d0 * np.sqrt(self.k_hat / k_nom), 0.2*self.K_d0, 3*self.K_d0)
        K_d = max(K_d, 2*np.sqrt(self.M_d*K_p)*self.zeta_min)
        return K_p, K_d

    def setpoint(self, F_d, delta_dot, b_hat=0., F_bias=0.):
        return (F_d + (-b_hat*delta_dot + F_bias)) / max(self.k_hat, 1e-6)
```

```python
class ReplayForgettingBuffer:
    def __init__(self, capacity=5000, forget_tol=0.1):
        self.buf = deque(maxlen=capacity)
        self.forget_tol = forget_tol

    def push(self, batch):
        self.buf.append(((batch.r_ep**2).mean().item() + 1e-6, batch))

    def sample(self, n):
        p = np.array([x[0] for x in self.buf]) ** 0.6
        idx = np.random.choice(len(self.buf), n, p=p / p.sum())
        return [self.buf[i][1] for i in idx]

    def forgetting_metric(self):
        return float(np.mean([abs(a - b) for a, b in self._old_vs_new()] or [0.0]))


class ForceInformedMetaLearner:
    def __init__(self, model, alpha=1e-3, beta=1e-4, k=10):
        self.model, self.alpha, self.beta, self.k = model, alpha, beta, k

    def inner(self, support, theta):
        for _ in range(self.k):
            loss = self._force_loss(support, theta)
            theta = [p - self.alpha*g for p, g in
                     zip(theta, torch.autograd.grad(loss, theta))]
        return theta

    def meta_step(self, tasks):
        grads = []
        for sup, qry in tasks:
            theta_p = self.inner(sup, self.model.meta_params())
            grads.append(torch.autograd.grad(self._force_loss(qry, theta_p),
                                             self.model.meta_params()))
        self._apply_meta(grads, self.beta)
```

```python
class AdaptiveForceEmbodiedLoop:
    def __init__(self, mel, dms, usr, eeis, ertc, budget, tank):
        self.mel, self.dms, self.usr = mel, dms, usr
        self.eeis, self.ertc, self.budget, self.tank = eeis, ertc, budget, tank
        self.frd = ForceResidualDecomposer()
        self.gsaic = GainScheduledAdaptiveForceController()
        self.ft = DualScaleFineTuner(mel, usr, budget, tank)
        self.replay = ReplayForgettingBuffer()
        self.anchor = ForceConditionedAnchor()

    def lane_semantic(self, obs, utterance):
        phi, z, pi, U = self.mel.infer(*obs)
        a, C_pending, b = self.dms.step(U)
        return self.anchor.commit(z, b, phi, U), a

    def lane_adaptation(self, anc, F_m, F_d, delta, delta_dot):
        if not self.tank.allow_fast():
            return self.gsaic.freeze()
        r = self.frd.decompose(F_m, F_d, delta, delta_dot,
                               self.gsaic.K_p0, self.gsaic.K_p)
        self.gsaic.update_stiffness(delta, F_m, self.tank.E)
        K_p, K_d = self.gsaic.schedule(self.gsaic.k_hat)
        delta_r = self.gsaic.setpoint(F_d, delta_dot)
        self.replay.push(ContactBatch(anc.phys_prior, r.r_ep, F_m, delta))
        return K_p, K_d, delta_r, r.r_ep

    def lane_realtime(self, K_p, K_d, delta_r, F_d):
        return self.ertc.dispatch_torque(
            self.eeis.compile_force(K_p, K_d, delta_r, F_d))

    def step(self, obs, utt, F_m, F_d, delta, delta_dot):
        anc, a = self.lane_semantic(obs, utt)
        K_p, K_d, dr, r_ep = self.lane_adaptation(anc, F_m, F_d, delta, delta_dot)
        tau = self.lane_realtime(K_p, K_d, dr, F_d)
        J = None
        if self.tank.allow_slow() and self.budget.ft_available():
            J = self.ft.slow_step(ContactBatch(obs, r_ep, delta, delta_dot), anc.version)
            if J and not J.valid():
                self.tank.freeze_all()
        return tau, J
```

6. **快速适应**：FIML 新任务 k 步后力误差 ≤ τ_ft。
