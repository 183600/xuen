# 第 55 轮（承接第 54 轮 v16++ / v31；灵感循环第 1 轮；本轮灵感：「伦理与合规」×「记忆检索」）

> 第 54 轮把技能组合升级为 **动作-鲁棒性双证书** 与云边协同闭环。本轮把镜头从“能不能做”转向“**该不该做、凭什么做、做完还算不算数**”：系统记忆是相似性驱动的检索，而伦理合规是规范性、非单调、可审计的。核心矛盾：**H22「相似 ≠ 适用」**——语义近邻常不是规范上适用的先例/条款；**H23「记忆单调累积 vs 规范非单调撤证」**——被遗忘权、撤回同意、法规更新会追溯性使旧结论失效，而检索式记忆默认只增不减。本轮提出 **NMR-CC（Normative Memory Retrieval & Compliance Certificate）**：先适用性门控、再证据可审计、再非单调撤证、最后伦理否决式部署。

## 0. 直觉与动机

**灵感 1（检索是“像不像”，合规是“适不适用” → 相似-适用鸿沟）**
直觉：向量检索回答“这段记忆和查询有多像”，合规判断却问“这条规则/先例在这个辖区、这个时间、这份授权下是否适用”。二者只在统计上相关，并非同一谓词。把 top-k 相似记忆直接当依据，会产生 **合规幻觉（compliance hallucination）**：用一条语义相近但越权/过期/异地/未授权的先例为行为背书。RAG 的“检索到即引用”在此危险，因为**引用不等于适用**。
严谨化：每条记忆附带规范元数据 `μ=(scope,t_valid,consent,jurisdiction,authority,provenance)`；检索必须先过 **适用性门控** `app(m,q)≥θ_app`，再谈相关性。把 **相似-适用鸿沟** 定义为 `δ_sa = P(app=0 | sim≥θ_sim)`。

**灵感 2（合规必须是可审计的证据链，而非一个分数）**
直觉：合规结论要能被监管者/人类复核——“依据哪些条款、哪些先例、哪些反例、缺口在哪”。所以检索产物不应只是 top-k 文档，而是一张 **支持/攻击/缺口** 的证据 DAG。
严谨化：合规证书 `C_eth=(Γ,support,attack,gap,prov_dag)`，支持与攻击均挂到可追溯的 provenance 节点；`gap` 显式记录未被覆盖的规范义务。gap 未闭合则只能出“条件合规/待证”，不得出“合规”。

**灵感 3（记忆会变，规范会追溯 → 非单调撤证）**
直觉：新法规、判决翻转、用户撤回同意、被遗忘权生效，都会让过去签发的合规证书失效。检索系统默认 append-only，合规系统必须支持 **撤证与重证**，且要在监管窗口内完成。
严谨化：建 **记忆-证书依赖图** `D_M`，边表示证书对记忆条目的支持依赖；失效事件 `e` 触发依赖闭包 `Δ(e)` 的撤证，重证时间 `τ_revoke` 必须 ≤ 监管窗口 `τ_reg`；`stale` 证书不得复用。

**灵感 4（被遗忘权 → 检索路径不可残留）**
直觉：删除一条记忆不等于它检索不到：embedding、摘要、微调权重、缓存、交叉引用都可能残留。合规删除要求 **不可恢复性**，而不是数据库行删除。
严谨化：定义 **遗忘算子** `Erase(m)` 与 **残留恢复度** `Res(m)=max over probes recover(m)`；要求 `Res(m)≤ε_res`，覆盖向量、摘要、引用与缓存多个通道。

**灵感 5（伦理是门，不是权重 → 否决式部署）**
直觉：鲁棒性可用概率容忍，伦理/合规不能用期望值抵消——“95% 合规”不是合规。伦理维度应作为 **硬门控/字典序约束**，不能与成功率加权求和。
严谨化：部署判定改为字典序 `deploy = (E_ok) ∧ (A_ok) ∧ (ρ_ok)`，其中 `E_ok` 一票否决；`ρ` 只在 `E_ok ∧ A_ok` 内被优化。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（规范性记忆条目）**
记忆条目 `m=(c, e, μ)`，`c` 为内容，`e` 为嵌入，`μ=(scope, t_valid=[t_0,t_1], consent, jurisdiction, authority, provenance)` 为规范元数据。检索键 `k(m)=(e, μ)`，即“向量 + 规范标签”联合键。`μ` 任一必需字段缺失即标记 `undefined`，不得参与合规结论。

**定义 122（适用性门控检索）**
对查询 `q`（含适用域 `S_q`、时刻 `t_q`、辖区 `j_q`、授权上下文 `auth_q`），适用性
```
app(m,q) = 1[scope(m) ∩ S_q ≠ ∅] · 1[t_q ∈ t_valid(m)] · 1[consent(m,q)=ok] · 1[jurisdiction(m)=j_q] · 1[μ(m)≠undefined]
```
门控检索集 `R_θ(q) = { m : app(m,q) ≥ θ_app }`，再在 `R_θ(q)` 内按 `sim(e_m,e_q) ≥ θ_sim` 排序取 top-k。**顺序不可交换**：先门控、后排序。

**定义 123（相似-适用鸿沟与合规幻觉率）**
相似-适用鸿沟 `δ_sa = P(app=0 | sim ≥ θ_sim)`；合规幻觉率 `halluc = P(引用 m | app(m,q)=0)`。`δ_sa` 是本轮的核心可测量量，而非普通召回率。

**定义 124（合规证据证书）**
`C_eth=(Γ, support, attack, gap, prov_dag)`：`Γ` 为适用规范来源集；`support`/`attack` 为证据边；`gap` 为未闭合义务集；`prov_dag` 为溯源有向无环图。判定
```
E_ok(C_eth) = 1  ⟺  gap=∅ ∧ acyclic(prov_dag) ∧ ∀(m,r)∈support∪attack: app(m,q)=1 ∧ has_provenance(m,r)
```

**定义 125（非单调撤证）**
依赖图 `D_M=(V_M ⊎ V_C, E_dep)`，`V_M` 记忆、`V_C` 证书，边 `m → C` 表示证书 `C` 依赖 `m`。失效事件 `e=(m,reason)`；撤证闭包 `Δ(e)={C : C ⇝ m}`；撤证时效 `τ_revoke(e)=max_{C∈Δ(e)} recompute_time(C)`。要求 `τ_revoke ≤ τ_reg`，撤证后 `state(C)=stale`。

**定义 126（遗忘合规与伦理否决联合证书）**
`E_cert=(C_eth, Res, erase_log, δ_sa, τ_revoke)`；联合证书 `J_eth=(E_cert, ρ, A_cert)`（`ρ` 承接第 53/54 轮鲁棒性谱，`A_cert` 承接动作占用证书）。部署判定
```
deploy(J_eth, q) = E_ok(C_eth) ∧ (∀m∈Erased: Res(m) ≤ ε_res) ∧ (δ_sa ≤ Θ_sa) ∧ (τ_revoke ≤ τ_reg)
                   ∧ A_ok(A_cert) ∧ ρ_ok(ρ)
```
伦理项为 **硬约束**，不参与加权；`ρ` 只是在可行域内被优化。

## 2. 关键算法 伪代码

### IP-121 NMG（Normative Memory Gating）

```python
def normative_retrieve(q, mem, theta_app=1.0, theta_sim=0.8, k=10):
    gate = [m for m in mem if applicability(m, q) >= theta_app]
    ranked = sorted(gate, key=lambda m: cosine(m.emb, q.emb), reverse=True)
    retrieved = [m for m in ranked if cosine(m.emb, q.emb) >= theta_sim][:k]
    delta_sa = empirical_sa_gap(mem, q, theta_sim)   # 相似但不适用的条件概率
    return retrieved, delta_sa

def applicability(m, q):
    if m.mu is UNDEFINED: return 0.0
    return float(scope_overlap(m.mu.scope, q.scope)
                 and (m.mu.t_valid[0] <= q.t <= m.mu.t_valid[1])
                 and consent_ok(m.mu.consent, q.auth)
                 and m.mu.jurisdiction == q.jurisdiction)
```

### IP-122 CEB（Compliance Evidence Builder）

```python
def build_compliance_evidence(q, retrieved, rules):
    G, support, attack, gap = ProvDAG(), [], [], []
    for m in retrieved:
        for r in applicable_rules(m, q, rules):     # 只取 app=1 的规则
            G.add_source(m, r)
            (support if entails(r, q.obligation) else attack).append((m, r))
    for o in q.obligations:
        if not any(covers(r, o) for _, r in support):
            gap.append(o)                            # 缺口显式化
    return CertEth(G, support, attack, gap,
                   ok=not gap and G.is_acyclic())
```

### IP-123 NMR（Non-Monotonic Revocation）

```python
def revoke(event, D_M, certs, tau_reg):
    affected = dependency_closure(D_M, event.memory)
    t_revoke = 0.0
    for c in affected:
        mark_stale(c)
        t0 = now(); y = recompute(c, updated_memory=event); t_revoke = max(t_revoke, now() - t0)
        if y.ok: mark_fresh(y)                       # 重证成功才恢复可用
    return RevocationReport(affected, t_revoke, ok=(t_revoke <= tau_reg))
```

### IP-124 FCR（Forgetting-Compliant Retrieval）

```python
def forgetting_compliant_erase(m, store, probes, eps_res=1e-3):
    store.delete_record(m)
    store.drop_embeddings(m)                         # 向量通道
    regenerate_summaries(m)                          # 摘要通道
    invalidate_cache_and_xrefs(m)                    # 缓存/交叉引用通道
    return residual_recoverability(store, m, probes) <= eps_res
```

### IP-125 EVC（Ethical Veto Certificate）

```python
def ethical_veto(cert_eth, rho, a_cert, theta_sa, eps_res, tau_reg):
    if cert_eth.gap:                 return ('reject', 'normative_gap', cert_eth.gap)
    if not cert_eth.prov_acyclic():  return ('reject', 'provenance_cycle')
    if cert_eth.delta_sa > theta_sa: return ('reject', 'similarity_applicability_gap')
    if not cert_eth.erase_ok(eps_res): return ('reject', 'residual_memory')
    if cert_eth.tau_revoke > tau_reg: return ('reject', 'stale_after_revoke')
    if not (a_cert.ok and rho_ok(rho)): return ('reject', 'capability_or_robustness')
    return ('ok', JointEth(cert_eth, rho, a_cert))
```

### IP-126 EMC（Ethical-Memory Composite Certificate）

```python
def composite_certify(q, retrieved, rules, erased, D_M, rho, a_cert, budgets):
    C = build_compliance_evidence(q, retrieved, rules)
    rev = revoke_all_pending(D_M, budgets.tau_reg)    # 先结清历史 stale
    if not rev.ok:                    return ('reject', 'revocation_lag', rev)
    for m in erased:
        if residual_recoverability(store, m, probes) > budgets.eps_res:
            return ('reject', 'residual_memory', m)
    if C.delta_sa > budgets.theta_sa: return ('reject', 'sa_gap', C.delta_sa)
    return ethical_veto(C, rho, a_cert, budgets.theta_sa, budgets.eps_res, budgets.tau_reg)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| NMG | O(|M|·d + |M| log |M|) | O(|M|) | 门控先于排序、μ 缺失即拒 |
| CEB | O(|R_θ|·|rules|·|Ob|) | O(|V|+|E|) | gap 显式、provenance 无环 |
| NMR | O(|Δ(e)|·cost_recompute) | O(|D_M|) | 撤证闭包完整、τ_revoke≤τ_reg |
| FCR | O(|M|·|probes|) | O(1) 额外 | 多通道删除、残留可测 |
| EVC | O(1)（证书已建） | O(1) | 字典序否决、硬约束 |

**正确性定理（Normative Retrieval Compliance Soundness）**
承接第 54 轮 (A26)–(A28)；新增 **(A29)** 规范元数据 `μ` 完整可信（scope/validity/consent/jurisdiction 无缺失）；**(A30)** 证据 DAG 的 provenance 不可伪造且可追溯；**(A31)** 撤证闭包计算完整且 `τ_revoke≤τ_reg`；**(A32)** 遗忘后残留恢复度 `Res≤ε_res`。
则对任意查询 `q`：
```
P(false-allow) ≤ P(δ_sa > Θ_sa) + P(μ undefined) + P(provenance forged) + P(stale reused)
E_ok(C_eth) ⇒ 合规结论有据可查，且不因记忆单调累积而保留失效结论
¬E_ok ⇒ deploy=0（伦理硬约束不被 ρ 的高成功率抵消）
```
关键：**先门控后检索**压缩相似-适用鸿沟；**gap 显式化**阻断“无证据即合规”；**撤证闭包**保证非单调一致性；**残留恢复测试**保证遗忘真实生效；**字典序否决**保证伦理不可被权衡掉。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 规范元数据缺失/错误 → 虚假适用 | 高 | schema 校验 + 缺失即拒绝 + 法务抽检 |
| 记忆投毒 / 检索污染 | 高 | provenance 签名 + 来源信誉 + 对抗检索测试 |
| 遗忘残留（embedding/摘要/缓存） | 高 | 多通道删除 + 成员推断红队 + 定期重训 |
| 过度门控导致效用坍塌 | 中 | 分层阈值 + 条件合规 + 人工升级通道 |
| 辖区/同意语义歧义 | 高 | 形式化政策本体 + 法务对齐 + 冲突显式化 |

## 6. 本轮最大风险

**一句话**：规范性记忆检索把“检索到”升级为“可适用、可审计、可撤证、可遗忘”的合规证据，但其 soundness **三重依赖规范元数据的完整可信、provenance 不可伪造、以及遗忘残留的彻底清除**；一旦元数据缺失被当作适用、或被投毒记忆伪造 provenance，系统会以“有据可查”的姿态输出系统性越权合规——这种失败比普通幻觉更危险，因为它披着审计合法性的外衣，故必须以 **缺失即拒绝 + 签名溯源 + 成员推断红队** 三重护栏，宁可拒答/拒部署，绝不把“检索到的相似”当作“规范上的适用”。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-EthiMem（NMG×CEB×NMR×FCR×EVC×EMC）

> 承接第 54 轮产物 v31。本轮在“动作-鲁棒性双证书 + 云边协同”之上，增加 **规范性记忆检索与合规证据** 层，把记忆从“相似召回”升级为“适用门控 + 可审计证据 + 非单调撤证 + 可遗忘”的合规基础设施：
> - **NMG（Normative Memory Gating）**：规范元数据 `μ` 与适用性门控 `app(m,q)`，先门控后检索；
> - **CEB（Compliance Evidence Builder）**：合规证据 DAG 与证书 `C_eth`，显式记录支持/攻击/缺口；
> - **NMR（Non-Monotonic Revocation）**：记忆-证书依赖图上的撤证闭包与重证时效；
> - **FCR（Forgetting-Compliant Retrieval）**：被遗忘权的多通道删除与残留恢复测试；
> - **EVC（Ethical Veto Certificate）**：伦理字典序否决，不被鲁棒性成功率抵消；
> - **EMC（Ethical-Memory Composite Certificate）**：`J_eth=(E_cert,ρ,A_cert)` 联合证书。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-110/118/120 以纳入规范-记忆维度。

```python
        t0 = now(); y = recompute(c, updated_memory=event)
        t_revoke = max(t_revoke, now() - t0)
        if y.ok: mark_fresh(y)
    return RevocationReport(affected, t_revoke, ok=(t_revoke <= tau_reg))
```

```python
def ethical_veto(cert_eth, rho, a_cert, theta_sa, eps_res, tau_reg):
    if cert_eth.gap:                  return ('reject', 'normative_gap', cert_eth.gap)
    if not cert_eth.prov_acyclic():   return ('reject', 'provenance_cycle')

    if not cert_eth.erase_ok(eps_res): return ('reject', 'residual_memory')
    if cert_eth.tau_revoke > tau_reg: return ('reject', 'stale_after_revoke')

    return ('ok', JointEth(cert_eth, rho, a_cert))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| NMG | O(|M|·d + |M| log |M|) | O(|M|) | 门控先于排序、μ 缺失即拒 |
| CEB | O(|R_θ|·|rules|·|Ob|) | O(|V|+|E|) | gap 显式、provenance 无环 |
| NMR | O(|Δ(e)|·cost_recompute) | O(|D_M|) | 撤证闭包完整、τ_revoke≤τ_reg |
| FCR | O(|M|·|probes|) | O(1) 额外 | 多通道删除、残留可测 |
| EVC/EMC | O(1) / O(|Δ(e)|) | O(1)/O(|D_M|) | 字典序否决、硬约束 |

**正确性定理（Normative Retrieval Compliance Soundness）**
承接第 54 轮 (A26)–(A28)；新增 **(A29)** 规范元数据 `μ` 完整可信；**(A30)** provenance 不可伪造且可追溯；**(A31)** 撤证闭包完整、`τ_revoke≤τ_reg`；**(A32)** 遗忘后 `Res≤ε_res`。
则对任意查询 `q`：
```
P(false-allow) ≤ P(δ_sa > Θ_sa) + P(μ undefined) + P(provenance forged) + P(stale reused)
E_ok(C_eth) ⇒ 合规结论有据可查，且不因记忆单调累积而保留失效结论
¬E_ok ⇒ deploy=0（伦理硬约束不被 ρ 的高成功率抵消）
```
关键：**先门控后检索**、**gap 显式化**、**撤证闭包**、**残留恢复测试**、**字典序否决**。

## 5. 本轮最大风险

**一句话**：规范性记忆检索把“检索到”升级为“可适用、可审计、可撤证、可遗忘”的合规证据，但其 soundness **三重依赖规范元数据的完整可信、provenance 不可伪造、以及遗忘残留的彻底清除**；一旦元数据缺失被当作适用、或被投毒记忆伪造 provenance，系统会以“有据可查”的姿态输出系统性越权合规——这种失败比普通幻觉更危险，因为它披着审计合法性的外衣，故必须以 **缺失即拒绝 + 签名溯源 + 成员推断红队** 三重护栏，宁可拒答/拒部署，绝不把“检索到的相似”当作“规范上的适用”。
