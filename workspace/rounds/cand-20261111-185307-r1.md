# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「交互设计」×「数据集」）

> 第 54 轮把技能组合升级为动作-鲁棒性双证书（ρ、α_S、J），但所有证书的"证据"仍被当作理所当然——仿佛 ρ、α_S 是从真空里仿真出来的。本轮把镜头拉回证据的生产端：**证书的合法性最终由数据集支撑，而数据集由人—机交互生产**。核心矛盾：H22 证书-数据脱钩——证书从不记录"自己由哪份数据、多高覆盖、多强漂移支撑"，数据一更新证书就静默过期；H23 交互设计缺位——采集被当成一次性演示，交互协议本身没有被当作可优化、可度量人类成本的数据生产函数，导致高成本、低覆盖，且人看不懂解释也无法有效纠错。

## 0. 直觉与动机

**灵感 1（数据集 = 证书的证据账本，不是训练燃料）**
直觉：过去把 D 当"喂给模型的原料"。反过来看：每个证书声明 φ（例如"S 在动作区 R 上 ρ≥ρ_min"）都必须绑定一份数据集 D 与支撑度 `supp(D,φ)`。证书不再是二值结论，而是 `(φ, D_id, supp, drift, provenance)`。**没有数据出处的证书不可部署**——这把"可解释"从"解释模型"推进到"解释证据"。

**灵感 2（交互设计 = 数据生产函数，按证据缺口定向采集）**
直觉：采集不该平均用力。先算 **证据缺口** `gap(φ)=φ 的未支撑区域`，再按缺口选择交互协议 μ（演示 / 纠错 / 偏好比较 / 主动询问），目标是 **单位人类成本下的证据增益最大** `max E[Δsupp]/E[cost_human]`。这是主动学习，但目标函数里第一次显式出现"人"。

**灵感 3（交互即标注：把部署时的接管变成弱标签）**
直觉：部署时人的接管、纠正、否决，是最贵、也最贴近真实分布的标签。把交互轨迹 `τ=(s_t,a_t,e_t,h_t)` 结构化落库——状态、系统动作、展示给人的解释 e_t、人的反应 h_t——直接回填 α_S/ρ 的欠采样区。**解释不是交互的终点，而是采集的探针**。

**灵感 4（证书-数据依赖图：数据一变，证书必须级联失效）**
直觉：证书有向无环地依赖数据集。D 版本更新（增删改 + 分布漂移）时，依赖它的证书必须重验，其下游证书级联失效。禁止"旧证书 + 新数据"的静默组合——**数据漂移是第 54 轮动作漂移的上游母体**。

**灵感 5（解释也是交互设计问题：理解度证书）**
直觉：Explain 面向的不只是云端重规划器，更是人。定义解释理解度 `q=(理解准确率, 可操作性, 信任校准)`：人能否找到根因、能否据此行动、置信是否与真实 ρ 校准。**说不清楚的解释等于没有证据**，把 q 纳入证书链。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（交互轨迹）**
交互轨迹 `τ = ⟨(s_t,a_t,e_t,h_t)⟩_{t=1}^{T}`，其中 `s_t` 为状态，`a_t` 为系统动作，`e_t` 为呈现给人类的解释，`h_t ∈ {none, correct, takeover, veto, query}` 为人的反应。人类交互成本
```
cost_h(τ) = Σ_t ( c_read·|e_t| + c_act·1[h_t≠none] + c_lat·latency_t )
```

**定义 122（数据集证据契约）**
数据集 `D = (X, Y, π, Tr, prov)`：样本 X、标签 Y、采样策略 π、交互轨迹 Tr、出处 prov（采集者、时间、同意、版本）。对证书声明 φ，定义
```
supp(D, φ) = cover_π(φ) · reliab(Y)            # 覆盖 × 标注可靠度
drift(D, φ) = D_KL( p_D(·|φ.region) ‖ p_ref(·|φ.region) )
```
称 D 对 φ **D-有效** 当且仅当 `supp(D,φ) ≥ θ_ev ∧ drift(D,φ) ≤ δ_ev`。

**定义 123（证书-数据依赖图）**
`G_CD = (C ∪ Dset, E_dep)`，边 `(c,D)` 表示证书 c 依赖数据集 D。c **证据有效** 当且仅当 `∀D ∈ dep(c): D 对 c.claim 是 D-有效的`。数据更新 `ΔD` 触发级联失效
```
invalid(ΔD) = closure_{dependents}( { c : ΔD ∩ dep(c) ≠ ∅ } )
```

**定义 124（证据缺口）**
`gap(φ) = φ.region \ covered(D_support)`，优先级 `prio(φ) = risk(φ) · uncertainty(φ)`。总缺口 `G = { (φ, gap(φ), prio(φ)) }`。

**定义 125（交互采集策略）**
采集策略 `μ : G → Π`，Π 为交互协议集合。收益与成本
```
Gain(μ) = E[ supp(D ∪ τ_μ, φ) - supp(D, φ) ]
Cost(μ) = E[ cost_h(τ_μ) ]
μ* = argmax_{μ} Σ Gain(μ)/Cost(μ)   s.t.  Σ Cost(μ) ≤ B_h
```
**可判定采集条件**：`Gain(μ)/Cost(μ) ≥ θ_eig`，否则该缺口转入保守回退（拒绝宣称该证书）。

**定义 126（解释理解证书）**
`q = (acc, act, cal)`：`acc` 为人根因判断正确率，`act` 为人据此成功行动的比例，`cal` 为信任校准（期望校准误差 ECE）。解释证书 `E_cert = (e, q, evidence)`。若 `acc ≥ θ_acc ∧ act ≥ θ_act ∧ cal ≤ θ_cal`，则称该解释**人类合格**。

## 2. 关键算法 伪代码

### IP-121 IDC（Interaction-Driven Collection）

```python
def interaction_driven_collection(certs, datasets, human_budget, theta_eig):
    gaps = []
    for c in certs:
        if dataset_support(c, datasets) < c.theta_ev:
            gaps.append(EvidenceGap(c.claim, uncovered(c, datasets),
                                    risk(c) * uncertainty(c)))
    gaps.sort(key=lambda g: g.prio, reverse=True)
    plan, spent = [], 0.0
    for g in gaps:
        best = None
        for proto in protocols_for(g):            # demo / correct / prefer / query
            gain = expected_evidence_gain(proto, g)
            cost = expected_human_cost(proto, g)
            if gain / max(cost, 1e-9) >= theta_eig:
                if best is None or gain / cost > best.eff:
                    best = Choice(proto, gain, cost, gain / cost)
        if best is None or spent + best.cost > human_budget:
            continue
        trials = run_protocol(best.proto, g, gain_target=1 - g.theta_ev)
        D_new = trace_to_dataset(trials)          # 交互轨迹 → 结构化样本
        plan.append((g, best.proto, D_new))
        spent += best.cost
    return plan, spent
```

### IP-122 DEC（Dataset Evidence Contract）

```python
def dataset_evidence_contract(D, claim, theta_ev, delta_ev):
    support = coverage_ratio(D, claim.region) * annotation_reliability(D)
    drift = distribution_shift(D, claim.region)   # MMD / KL vs reference
    prov = Provenance(D.pi, D.traces, D.consent, D.semver)
    sound = support >= theta_ev and drift <= delta_ev
    return DatasetEvidence(D.id, claim, support, drift, prov, sound)
```

### IP-123 CDC（Certificate-Data Consistency）

```python
def certificate_data_consistency(cert_graph, D_old, D_new):
    delta = dataset_delta(D_old, D_new)           # 增删改 + 分布漂移
    invalid, frontier = set(), [c for c in cert_graph
                                 if delta.overlaps(c.data_deps)]
    while frontier:
        c = frontier.pop()
        if c in invalid:
            continue
        ev = dataset_evidence_contract(D_new, c.claim, c.theta_ev, c.delta_ev)
        if not ev.sound:
            invalid.add(c)
            frontier += cert_graph.dependents(c)  # 下游级联失效
    return invalid, topo_order(invalid)
```

### IP-124 HCE（Human Comprehension Evaluation）

```python
def human_comprehension(explain_cert, humans, theta_acc, theta_act, theta_cal):
    acc, act, conf = [], [], []
    for h in humans:
        e = render_for(explain_cert, h)           # 分层解释：根因 / 证据 / 可选动作
        pred = h.predict_root_cause(e)
        acc.append(pred == explain_cert.root_cause)
        act.append(h.can_act(e))
        conf.append((h.confidence(e), explain_cert.rho))
    cal = ece(conf)                               # 期望校准误差
    q = (mean(acc), mean(act), cal)
    ok = q[0] >= theta_acc and q[1] >= theta_act and q[2] <= theta_cal
    return ComprehensionCert(explain_cert, q, ok)
```

### IP-125 DGL（Dataset Governance Loop）

```python
def dataset_governance(versions, cert_graph, deploy_policy):
    for D in versions:
        if not D.consent or not provenance_complete(D):
            quarantine(D)                          # 出处/同意不全 → 隔离
    head = versions.head
    invalid, order = certificate_data_consistency(cert_graph, head.parent, head)
    for c in order:
        if c in invalid:
            c.mark_stale()
    blocking = [c for c in invalid if c.deployed]
    if blocking:
        deploy_policy.rollback(blocking, to_version=head.parent)
    return DatasetLedger(head, invalid, blocking)
```

### IP-126 IEQ（Interaction Efficiency Quotient）

```python
def interaction_efficiency(plan, human_minutes):
    gain = sum(expected_evidence_gain(p.proto, p.gap) for p in plan)
    return gain / max(human_minutes, 1e-9)       # 证据增益 / 人分钟
```

**正确性定理（Evidence-Grounded Certificate Soundness）**
承接第 54 轮 (A22)–(A28)，新增：**(A29)** `supp(D,φ)` 经独立审计校准（估计无偏）；**(A30)** 漂移检测器的漏报率 ≤ β_D；**(A31)** HCE 的人类样本对目标用户分布有代表性。
则部署成功概率
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - β_D - P(supp<θ_ev) - P(q<q_min)
```
关键：**证书先验数据支撑**，**数据变更触发级联失效**，**解释先验人类合格**。

| 风险 | 等级 | 缓解 |
|---|---|---|
| 支撑度 supp 自评偏差（自证清白） | 高 | 独立审计集 + 红队反例 + 双盲标注 |

## 6. 本轮最大风险

**一句话**：把数据集升格为证书的证据账本、把交互设计升格为数据生产函数，能让"可解释"从模型层下沉到证据层，但其 soundness **三重依赖支撑度自评的诚实、漂移检测的低漏报、以及人类理解度实验的代表性**；一旦 supp 自证清白、或漂移在长尾动作区漏检，系统会拿着一份看似完备、实则陈旧的证据账本，给出一张"人类看不懂、数据撑不住"的合法证书——这是比动作错位更隐蔽的失败，必须以**独立审计 + 多检测器漂移 + 双通道解释**三重护栏，宁可不发证书，绝不发一张自己给自己背书的证书。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（IDC×DEC×CDC×HCE×DGL×IEQ）

> 承接第 54 轮产物 v31。本轮在动作-鲁棒性双证书体系**之下**新增一个 **证据-交互层（EIL, Evidence & Interaction Layer）**，回答"证书凭什么成立、由谁生产、人是否看得懂"：
> - **IDC（Interaction-Driven Collection）**：按证据缺口定向设计交互采集，最大化单位人类成本的证据增益；
> - **DEC（Dataset Evidence Contract）**：数据集从"训练燃料"升级为证书的"证据账本"；
> - **CDC（Certificate-Data Consistency）**：数据版本变更触发证书依赖图级联失效；

> - **DGL（Dataset Governance Loop）**：出处/同意/漂移/回滚的数据治理闭环；
> - **IEQ（Interaction Efficiency Quotient）**：证据增益/人分钟的统一效率口径。

**正确性定理（Evidence-Grounded Certificate Soundness）**
承接第 54 轮 (A22)–(A28)，新增：**(A29)** `supp(D,φ)` 经独立审计校准；**(A30)** 漂移检测器漏报率 ≤ β_D；**(A31)** HCE 人类样本对目标用户分布有代表性。
则部署成功概率
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - β_D - P(supp<θ_ev) - P(q<q_min)
```
关键：**证书先验数据支撑**，**数据变更触发级联失效**，**解释先验人类合格**。

## 6. 本轮最大风险

**一句话**：把数据集升格为证书的证据账本、把交互设计升格为数据生产函数，能让"可解释"从模型层下沉到证据层，但其 soundness **三重依赖支撑度自评的诚实、漂移检测的低漏报、以及人类理解度实验的代表性**；一旦 supp 自证清白、或漂移在长尾动作区漏检，系统会拿着一份看似完备、实则陈旧的证据账本，给出一张"人类看不懂、数据撑不住"的合法证书——这是比动作错位更隐蔽的失败，必须以**独立审计 + 多检测器漂移 + 双通道解释**三重护栏，宁可不发证书，绝不发一张自己给自己背书的证书。
