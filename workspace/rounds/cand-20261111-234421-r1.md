# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「实时推理」×「伦理审查」）

> 第 54 轮已把技能组合推进为「动作空间剖面 + 云边协同 + 动作-鲁棒性联合证书」。本轮直面 **推理的实时性** 与 **伦理的可审查性** 这对结构性张力：H22：第 54 轮的联合证书 `J` 是离线/批式验证产物，一旦推理进入毫秒级控制回路，完整证书来不及算，只能拿到被截断的"部分证书"，其 soundness 随截止时间退化；H23：伦理审查本质是慢速、可争议、需人类审议的过程，而实时推理要求在线自主动作，二者时间尺度错位——把伦理压缩成一个在线布尔判定，极可能只是"伦理洗白"。

## 0. 直觉与动机

**灵感 1（实时推理 → 任意时间证书）**
直觉：证书不应是"全有或全无"的终态对象，而应是一条随时间单调精化的过程。多给 20ms，系统就多认证一块动作区域；到截止时刻无论如何交出一个"已认证子域 + 未决边界"的**诚实**证书。关键不是"算完了没有"，而是"任何时刻交出的部分证书都 sound"，即 soundness 在时间前缀上保序、认证域单调增长。

**灵感 2（实时推理 → 认证动作单元与摊销验证）**
直觉：第 54 轮的动作剖面 `α_S` 已把动作空间网格化。既然如此，就把动作空间 **离线切分为认证单元**（cell），每格预存一份联合证书、硬约束预检状态、剩余有效期 TTL 与边界裕度。线上只做 O(1) 查表 + 边界残差 + 新鲜度检查，把昂贵验证摊销到离线。**实时性来自"查表"，可靠性来自"边界裕度 + TTL"**。

**灵感 3（伦理审查 → 硬约束/软约束二分与运行时监视器）**
直觉：伦理不是一个标量。至少分两类：硬约束 `H`（禁止伤害、权限边界、不可逆动作的强制审批）可形式化为过去时安全时序逻辑，能在 O(1) 增量内实时监视；软约束 `S`（公平、尊严、情境恰当性、利益相关者同意）本质需要权衡与审议，不能诚实地说"在线判定"。因此运行时伦理监视器只对 `H` 给出 permit/deny，对 `S` 只给 "triggered/pending"，**绝不伪装成布尔裁决**。

**灵感 4（伦理审查 → 伦理债与延迟契约）**
直觉：实时系统不可能等所有 `S` 审议完。那就把它想成一张"伦理信用卡"：在时间压力下执行动作，同时记一笔 **伦理债** `d_e`（未决软约束 × 动作风险），进入待偿还队列。契约规定债务上限 `Θ_debt`、可延迟审议窗口 `τ_eth`、以及债务超限时的保守降级动作。这样"来不及审"不再被隐藏，而是被显式计量、可审计、可追偿。

**灵感 5（伦理审查 → 可争议性必须预付留证）**
直觉：事后被质疑时，系统必须在有界时间内回答"为什么这么做"。但实时推理当下不留证，事后就无法重建。因此 **可争议性必须在推理时预付**：每个动作落一条反事实账本（k-best 备选、所用证书、伦理状态、债务、降级路径）。可争议性 = 在 `τ_contest` 内可复原的 **因果-证书-伦理** 三元解释。

**灵感 6（统一：从"证书即对象"到"证书即过程"）**
直觉：把第 54 轮的 `J` 升级为 **带时标、残差与账本引用的证书过程** `J^E(t)`：在 `ρ、A_cert、γ_ce、δ_a` 之外，再加 `H_status、debt、TTL、Explain、ledger_ref`。部署判据从"存在一个证书"变为"在截止时刻存在 sound、未过期、债务未超限、且降级路径可执行的证书"。

## 1. 形式化定义（增量：定义 121–129）

**定义 121（任意时间证书）**
设联合证书空间为 `𝕁`，任务动作域为 `R*`，截止时间为 `T`。任意时间证书是映射 `A: [0,T] → 𝕁 ∪ {⊥}`，满足：
1. **前缀 soundness**：若 `A(t) ≠ ⊥`，则它对其声称的动作域 `R(t)` 是 sound 的（`R(t)` 内每个动作的 `ρ、A_cert、γ_ce、δ_a` 均满足定义 115–120）；
2. **单调精化**：`t₁ ≤ t₂ ⇒ R(t₁) ⊆ R(t₂)`；
3. **截止终止**：`A` 必须在 `T` 内返回，允许返回 `⊥`（未决）。
**验证性能剖面** `v_A(t) = μ(R(t)) / μ(R*)`（`μ` 为动作域测度）。称 `A` 为 `(ε_v, τ_c)`-可用，若 `v_A(τ_c) ≥ ε_v` 且 `τ_c ≤ T`。

**定义 122（证书新鲜度与过期风险）**
证书 `J` 带 TTL `τ_TTL`，签名时刻 `t_sign`。在时刻 `t` 的新鲜度 `fresh(J,t) = exp(-(t - t_sign)/τ_TTL)`，过期风险 `r_stale(J,t) = 1 - fresh(J,t)`。线上使用过期证书的风险必须计入部署上界，而非忽略。

**定义 123（伦理规约的硬/软二分）**
伦理规约 `E = (H, S, Θ_debt, τ_eth)`：
- 硬约束 `H = {h₁,…,h_m}`，每条是**可判定的过去时安全性质**（past-time safety MTL），`h: Trace → {sat, viol, unknown}`；
- 软约束 `S = {s₁,…,s_n}`，每条有触发谓词 `trig_s`、权重 `w_s`、决议状态 `res_s ∈ {none, pending, resolved}`；
- `Θ_debt` 债务上限，`τ_eth` 可延迟审议窗口。
对轨迹 `σ`，**硬伦理可容许** `Adm_H(σ)=1 ⇔ ∀h∈H: h(σ) ≠ viol`。

**定义 124（运行时伦理监视器）**
`M_E` 以 O(1) 增量方式消费 `(a_t, ctx_t)`，输出 `status ∈ {permit, deny, undecided, escalate}`：
- 仅当 `∀h∈H: h=sat` 且无 pending 软约束时 `permit`；
- 仅当存在 `h=viol` 时 `deny`（**保守性**：只在确定违规时拒绝）；
- 存在 triggered 未决软约束时 `undecided`（并累债）；
- `debt > Θ_debt` 时 `escalate`。
监视器误差 `ε_mon = P(确定违规被漏报) + P(permit 了实际违规动作)`。

**定义 125（伦理债）**
对轨迹 `σ`：
```
debt(σ) = Σ_t w_{s(t)} · risk(a_t, ctx_t) · 1[status_t ∈ {undecided, escalate} ∧ res_{s(t)} ∉ resolved]
```
债务只能由**离线审议回执** `repay(s, verdict, ts)` 减记；`debt_ratio = debt / Θ_debt`。

**定义 126（实时-伦理延迟契约）**
`C_ert = (T_rt, τ_eth, fallback, Θ_debt, escalation_channel)`：`T_rt` 为实时推理截止，`τ_eth ≤ T_rt` 为在线伦理判定预算，`fallback: Context → A_safe` 为未决时的保守子策略。若 `M_E` 在 `τ_eth` 内未决，则执行 `fallback` 并记债，**不得**以"默认允许"越过。原则：**不确定即降级，而非不确定即放行**。

**定义 127（认证动作单元）**
离线把动作域切分为 `𝒞 = {c}`，每单元 `c = (R_c, J_c, H_c, τ_TTL, m_c)`：动作子域、联合证书、硬约束预检状态、有效期、边界裕度。线上准入：
```
admit(a,ctx,t)=permit ⇔ a∈R_c ∧ fresh(J_c,t)≥φ_fresh ∧ boundary_margin(a,c)≥m_c ∧ H_c=pass
```
否则 `undecided`，转入任意时间补证或升级；单元外风险由边界裕度控制，摊销复杂度 O(1)。

**定义 128（可争议契约）**
`C_contest = (τ_contest, ledger, format)`：`ledger` 保存每个已执行动作的 `(J^E, k-best 反事实备选, H 状态, debt, Explain, fallback_used)`。**可争议性**要求：对任一动作，在 `τ_contest` 内可复原三元解释 `(cause, certificate, ethics)`，且与当时实际所用证书**一致**（一致性 sound）。

**定义 129（伦理-鲁棒性联合证书过程）**
`J^E(t) = (ρ, A_cert, γ_ce, δ_a, H_status, debt, τ_TTL, Explain, ledger_ref)`。部署判据升级为：
```
deploy(a,ctx,t) ⇔ Adm_H ∧ H_status=pass ∧ δ_a<Θ_a ∧ debt≤Θ_debt
                  ∧ fresh(J,t)≥φ_fresh ∧ boundary_ok ∧ fallback_available(ctx)
```
第 54 轮的 `dom_J(T)=in` 在此被替换为"**截止时刻仍 sound 且新鲜、且降级可执行**"。

## 2. 关键算法 伪代码

### IP-121 AVC（Anytime Verification Certificate）

```python
def anytime_certify(task, deadline, tau_step):
    t0 = now()
    R = empty_region()                 # 已 sound 认证的动作域
    cert = NullJointCert()
    frontier = [initial_region(task)]  # 由粗到细
    while now() - t0 < deadline:
        r = frontier.pop_min(upper_bound)          # 优先最可能高收益区域
        step = verify_region(r)                    # sound 证书或 None
        if step is not None:
            cert = meet_sound(cert, step)          # 只做合取，保持前缀 sound
            R = R ∪ r                              # 认证域单调增长
        else:
            frontier.extend(split(r))              # 未决则细分
        if now() - t0 + est_next(frontier) > deadline - tau_step:
            break
    status = 'complete' if not frontier else 'partial'
    return AnytimeCert(region=R, cert=cert, status=status,
                       v=measure(R) / measure(task.domain))
```

### IP-122 REM（Runtime Ethical Monitor）

```python
def monitor_step(state, a, ctx, E):
    state = state.extend(a, ctx)
    for h in E.H:                          # 硬约束：增量 O(1)
        v = h.eval_incremental(state)
        if v == 'viol':
            return Deny(h, state)          # 只报确定违规
    for s in E.S:                          # 软约束：只标记+累债，不在线裁决
        if s.trig(state) and s.res != 'resolved':
            state.pending.add(s)
            state.debt += s.w * risk(a, ctx)
    if state.debt > E.Theta_debt:
        return Escalate('debt_exceeded', state)
    if state.pending:
        return Undecided(state.pending, state)
    return Permit(state)
```

### IP-123 CAC（Certified Action Cell）

```python
def cell_admit(a, ctx, index, now_t, phi_fresh):
    c = index.lookup(a, ctx)                  # O(1)：动作哈希 + 上下文分桶
    if c is None:                        return Undecided('no_cell')
    if freshness(c.J, now_t) < phi_fresh:return Stale(c)
    if boundary_margin(a, c) < c.m_c:    return Undecided('boundary')
    if c.H_status != 'pass':             return Deny('hard_constraint')
    return Permit(c.J)
```

### IP-124 EDC（Ethical Debt Contract）

```python
def deadline_admit(a, ctx, E, index, contract):
    st = monitor_step(contract.state, a, ctx, E)
    if st.status == 'deny':      return Reject(st)
    if st.status == 'escalate':  return Fallback(contract.fallback(ctx), st)
    cell = cell_admit(a, ctx, index, now(), contract.phi_fresh)
    if cell.status == 'permit' and st.status == 'permit':
        return Admit(cell.J, st)
    # 未决：在 τ_eth 内尝试补证/审议，超时则保守降级并记债
    extra = try_verify_within(a, ctx, contract.tau_eth)
    if extra is not None:
        return Admit(extra, st)
    fb = contract.fallback(ctx)
    record_debt(a, st, fb, contract)          # 显式记账，不隐藏
    return Fallback(fb, st)
```

### IP-125 CSC（Contestability Certificate）

```python
def contest(action_id, tau_contest):
    rec = ledger.get(action_id)
    if rec is None:
        return ('missing_ledger',)            # 违反预付留证假设
    pack = ContestPack(
        cause    = Explain(rec.trace),        # 复用第 53 轮反向解释
        cert     = rec.J,                     # 当时实际所用证书
        ethics   = (rec.H_status, rec.pending, rec.debt),
        alts     = rec.kbest_alternatives,    # 推理时预付的反事实
        fallback = rec.fallback_used,
    )
    return ('ok', pack) if elapsed_since(action_id) <= tau_contest else ('timeout', pack)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| AVC | ≤ T 内任意中断，O(Σ verify) | O(认证域) | 前缀 sound + 认证域单调 |
| REM | O(|H|+|S|)/步，增量摊还 O(1) | O(|H|+|S|+|pending|) | 只在确定违规时 deny |
| CAC | 线上 O(1)，离线 O(|𝒞|·|A|) | O(|𝒞|) | 边界裕度 + TTL 保守 |
| EDC | O(1) + τ_eth 有界 | O(debt 账本) | 未决必须降级，债务有上限 |
| CSC | O(|trace|) 重放，受 τ_contest 约束 | O(k·|已执行动作|) | 账本完备、解释与证书一致 |

**正确性定理（Deadline-Aware Ethical-Robustness Soundness）**
承接第 54 轮 (A26)–(A28)；新增 **(A29)** 任意时间证书在全时间前缀 sound 且 `v_A(τ_c) ≥ ε_v`；**(A30)** 运行时监视器对 `H` 的误判率 ≤ `ε_mon`，且软约束只以债务形式外化、未被伪装成 permit；**(A31)** 反事实账本满足完备性（每个已执行动作都有 k-best 备选与所用证书记录）。则对任意截止 `T`：
```
P(violation) ≤ Σ_d (1-ρ_min(d)) + β_E + P(δ_a>Θ_a)
             + ε_mon + P(debt>Θ_debt) + (1-ε_v) + ε_residual
```
其中 `ε_residual` 为**伦理残余**——软约束与情境意义中无法被 `E` 形式化的部分。前六项可工程化压低；**`ε_residual` 不能**，它不是实现缺陷，而是"伦理不可完全形式化"的结构性下界。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| `ε_residual` 被忽略 → 伦理洗白 | 高 | 残余项写入证书 + 外部伦理委员会抽样审计 + 禁止把 `H=pass` 宣称"伦理通过" |
| 软约束债务无限累积 | 高 | 债务上限 + 硬性降级 + 债务 SLA + 定期强制清偿 |
| 监视器漏报/误报 | 中 | 形式化合成 `H` + 模糊测试 + 保守 deny 偏置 |
| 认证单元过期/分布漂移 | 高 | TTL + 新鲜度阈值 + 漂移检测触发重认证 |
| 反事实账本隐私泄露 | 中 | 最小化记录 + 加密 + 保留期 + 访问审计 |
| 任意时间证书被"截断即部署"滥用 | 高 | 最低覆盖门槛 `ε_v` + 未决强制 fallback |

## 6. 本轮最大风险

**一句话**：本轮把伦理审查压缩为"可实时判定的硬约束 + 可计量的伦理债"，最大风险是 **伦理残余 `ε_residual` 被工程指标系统性遮蔽**——一旦 `H=pass`、`debt≤Θ_debt`、证书新鲜被默认等同于"伦理已通过"，实时压力便会持续把决策推向可机器检查的伦理子集，而真正需要审议的软约束被债务化、债务又被 KPI 化，最终形成合规外观下的伦理洗白；故必须把残余项作为**不可归零的外部审计项**写进证书，而非塞进成功率公式。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（AVC×REM×CAC×EDC×CSC）

> 承接第 54 轮产物 v31。本轮在动作-鲁棒性联合证书之上，加入 **实时证书过程** 与 **可审计伦理层**，把"证书即对象"升级为"证书即过程"：

| `A(t)` / `R(t)` | 任意时间证书 / 其时刻 t 已 sound 认证的动作域 |
| `v_A(t)` | 验证性能剖面 `μ(R(t))/μ(R*)` |
| `fresh(J,t)` | 证书新鲜度 `exp(-(t-t_sign)/τ_TTL)` |
| `E=(H,S,Θ_debt,τ_eth)` | 伦理规约：硬约束 / 软约束 / 债务上限 / 审议窗口 |
| `Adm_H(σ)` | 硬伦理可容许（无确定违规） |
| `M_E` / `ε_mon` | 运行时伦理监视器 / 其漏报+误报率 |
| `debt(σ)` | 伦理债（未决软约束 × 动作风险） |
| `C_ert` | 实时-伦理延迟契约 |
| `𝒞={c}` / `m_c` | 认证动作单元集合 / 单元边界裕度 |
| `C_contest` / `ledger` | 可争议契约 / 反事实账本 |
| `J^E=(ρ,A_cert,γ_ce,δ_a,H_status,debt,TTL,Explain,ledger_ref)` | 伦理-鲁棒性联合证书过程 |
| `ε_residual` | 伦理残余（不可形式化下界，**不可归零**） |

## 2. 关键算法 伪代码

### IP-121 AVC

```python
def anytime_certify(task, deadline, tau_step):
    t0 = now()
    R = empty_region()
    cert = NullJointCert()
    frontier = [initial_region(task)]
    while now() - t0 < deadline:
        r = frontier.pop_min(upper_bound)
        step = verify_region(r)
        if step is not None:
            cert = meet_sound(cert, step)
            R = R ∪ r
        else:
            frontier.extend(split(r))
        if now() - t0 + est_next(frontier) > deadline - tau_step:
            break
    return AnytimeCert(region=R, cert=cert,
                       status=('complete' if not frontier else 'partial'),
                       v=measure(R) / measure(task.domain))
```

### IP-122 REM

```python
def monitor_step(state, a, ctx, E):
    state = state.extend(a, ctx)
    for h in E.H:
        if h.eval_incremental(state) == 'viol':
            return Deny(h, state)                 # 只报确定违规
    for s in E.S:
        if s.trig(state) and s.res != 'resolved':
            state.pending.add(s)
            state.debt += s.w * risk(a, ctx)
    if state.debt > E.Theta_debt:
        return Escalate('debt_exceeded', state)
    if state.pending:
        return Undecided(state.pending, state)
    return Permit(state)
```

### IP-123 CAC

```python
def cell_admit(a, ctx, index, now_t, phi_fresh):
    c = index.lookup(a, ctx)
    if c is None:                         return Undecided('no_cell')
    if freshness(c.J, now_t) < phi_fresh: return Stale(c)
    if boundary_margin(a, c) < c.m_c:     return Undecided('boundary')
    if c.H_status != 'pass':              return Deny('hard_constraint')
    return Permit(c.J)
```

### IP-124 EDC

```python
def deadline_admit(a, ctx, E, index, contract):
    st = monitor_step(contract.state, a, ctx, E)
    if st.status == 'deny':     return Reject(st)
    if st.status == 'escalate': return Fallback(contract.fallback(ctx), st)
    cell = cell_admit(a, ctx, index, now(), contract.phi_fresh)
    if cell.status == 'permit' and st.status == 'permit':
        return Admit(cell.J, st)
    extra = try_verify_within(a, ctx, contract.tau_eth)
    if extra is not None:
        return Admit(extra, st)
    fb = contract.fallback(ctx)
    record_debt(a, st, fb, contract)
    return Fallback(fb, st)
```

### IP-125 CSC

```python
def contest(action_id, tau_contest):
    rec = ledger.get(action_id)
    if rec is None: return ('missing_ledger',)
    pack = ContestPack(
        cause    = Explain(rec.trace),
        cert     = rec.J,
        ethics   = (rec.H_status, rec.pending, rec.debt),
        alts     = rec.kbest_alternatives,
        fallback = rec.fallback_used,
    )
    return ('ok', pack) if elapsed_since(action_id) <= tau_contest else ('timeout', pack)
```

### IP-126 ERJ（部署判定）

```python
def deploy_check(a, ctx, t, J_E, contract):
    if not implies_hard_constraints(ctx, J_E.H_status): return Reject('H')
    if J_E.delta_a >= Theta_a:                          return Reject('delta_a')
    if J_E.debt > contract.Theta_debt:                  return Reject('debt')
    if freshness(J_E, t) < contract.phi_fresh:          return Reject('stale')
    if not boundary_ok(a, J_E):                         return Reject('boundary')
    if not contract.fallback_available(ctx):            return Reject('no_fallback')
    return Admit(J_E)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| AVC | ≤ T 任意中断，O(Σ verify) | O(认证域) | 前缀 sound + 认证域单调 |
| REM | O(|H|+|S|)/步，增量摊还 O(1) | O(|H|+|S|+|pending|) | 仅确定违规时 deny |
| CAC | 线上 O(1)，离线 O(|𝒞|·|A|) | O(|𝒞|) | 边界裕度 + TTL 保守 |
| EDC | O(1)+τ_eth 有界 | O(debt 账本) | 未决强制降级，债务有上限 |
| CSC | O(|trace|) 重放，受 τ_contest 约束 | O(k·|已执行动作|) | 账本完备、解释与证书一致 |

**正确性定理（Deadline-Aware Ethical-Robustness Soundness）**
承接第 54 轮 (A26)–(A28)；**(A29)** 任意时间证书全前缀 sound 且 `v_A(τ_c) ≥ ε_v`；**(A30)** 运行时监视器对 `H` 误判率 ≤ `ε_mon`，软约束只以债务外化、不伪装为 permit；**(A31)** 反事实账本完备。则对任意截止 `T`：
```
P(violation) ≤ Σ_d (1-ρ_min(d)) + β_E + P(δ_a>Θ_a)
             + ε_mon + P(debt>Θ_debt) + (1-ε_v) + ε_residual
```
关键：前六项可工程化压低，`ε_residual` 是"伦理不可完全形式化"的**结构性下界**，只能外部审计与制度性披露，不能被工程优化掉。

## 6. 本轮最大风险

**一句话**：本轮把伦理审查压缩为"可实时判定的硬约束 + 可计量的伦理债"，最大风险是 **伦理残余 `ε_residual` 被工程指标系统性遮蔽**——一旦 `H=pass`、`debt≤Θ_debt`、证书新鲜被默认等同于"伦理已通过"，实时压力便会持续把决策推向可机器检查的伦理子集，而真正需要审议的软约束被债务化、债务又被 KPI 化，最终形成合规外观下的伦理洗白；故必须把残余项作为**不可归零的外部审计项**写进证书，而非塞进成功率公式。
