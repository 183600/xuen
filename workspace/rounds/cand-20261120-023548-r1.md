# 第 2 轮（UniBot 线 · 承接第 1 轮 UniBot-SAGE；本轮灵感：「数据集」×「力矩传感」）

> **轮次口径说明**：任务模板把本次标为「灵感循环第 1 轮」，而状态文件里已存在 UniBot 线的第 1 轮（SAGE 奠基版）。为不制造编号断裂，本文称本轮为 **UniBot 线第 2 轮**：第 1 轮的 IP-01…IP-08、定义 U1–U12、引理 L1–L7、实验 E601–E618 **全部保留**；本轮新增 **IP-09…IP-16、定义 U13–U24、引理 L8–L15、实验 E619–E638**。本轮不是推倒重来，而是**直接修补第 1 轮登记的最大风险**（抓握伪标签在未见物品上漂移）。

## 0. 情报核实（检索日期 2026-11-20；本轮新增一手核实）

本轮围绕两个灵感词重新核对官方数据与接口，得到一条会改变研究路线的**否定性事实**：

1. **公开数据集没有力矩/力/触觉/速度通道**。以 `unitreerobotics/G1_Dex1_PlugInEthernet` 的 `meta/info.json` 为样本（`codebase_version=v3.0`，1009 episodes / 496,037 frames / 30 fps / 4 路 480×640 AV1），其 `features` 只含：
   - 观测：`left/right_arm`(7)、`left/right_gripper`(1)、`lower_body`(15)、`left/right_leg`(6)、`left/right_ee_pose_gripper_base`(6)、`left/right_ee_pose_gripper_torso`(6)、`state_torso`(6)、`state_d435`(6)、`waist_state_joint`(3)、`recomputed_ee_valid`(1)；
   - 动作：同构的目标关节/目标 EE 位姿/`pivot`(7)/`base_command`(4)/`gripper_controls`(4) 等；
   - 以及 `timestamp/frame_index/episode_index/index/task_index`。
   **没有 `torque`、`effort`、`velocity`、`force`、`tactile` 字段，也没有 `success/reward/done` 字段。**
2. **评测观测目录同样没有力矩与速度**（官方 README §2）：只有 4 路图像、双臂位置、EE 位姿、抓手开合、`lower_body`、语言指令。动作是**目标位置**（joint 或 ee，二选一）。
3. **但数据集同时记录了“下发的目标”和“测到的状态”**：`action.*` 与 `observation.state.*` 在 30 Hz 下成对存在。这是本轮最重要的可利用结构：**它不是力矩，却是力矩在闭环里的“影子”。**
4. **`obs_delta_indices` 支持时序叠帧**（如 `[-4,-2,0]`），因此部署端可以有限差分出速度/加速度；我们自己也完整掌握已下发的动作历史。
5. **数据集只有成功遥操演示**，没有失败样本。失败相关信息只能以“成功轨迹中的微滑移 / 短暂失接触 / 重抓”形式**潜伏**在数据里。
6. **32 个任务名已核实**（HF collection），其中 `PlugInEthernet`、`PlugCharger`、`Unlock`、`ArrangeTestTubes`、`ZipUp`、`RemovePinnedNote`、`PourOutMedicine`、`SyringeWaterTransfer` 等正是接触最丰富的插入/旋转/细操作任务，与第 1 轮从 teaser 榜看到的“断在最后一环”同向。
7. **相机内参/外参可用**（`info.json` 的 `camera_params`，头双目已校正），腕部可做度量级相对位移估计，这给“滑移”提供了第二路几何证据。
8. **G1 硬件有力矩传感，但接口不暴露**；且我们不掌握评测端内环的具体形式（PD？阻抗？是否插值/平滑？循环延迟多少？）。这一点必须当作**未知量**处理，而不是当作已知。

**由此得到的路线级结论**：若把“力矩传感”理解成“读取力矩”，本轮立刻死路；但把它理解成**“从命令-测量残差中重建一个虚拟力矩/接触信号”**，则它同时满足：(a) 数据集里有原料，(b) 部署端可在线计算，(c) 不越出官方声明接口（合规）。这正是本轮的全部赌注。

## 1. 直觉解释（先直觉，再严谨定义）

### 灵感 1 ·「数据集」不是训练素材，而是一台大家忘了读的传感器

第一性原理：遥操数据集的每一帧都是一对 `(下发的目标 q*, 测到的状态 q)`，这是一次**闭环控制的输入输出样本**。控制器为了对抗重力、摩擦、接触，必须持续输出“努力”；当内环是位置跟踪时，**目标与实测之间的差，就是这份努力的可观测投影**。所以：

- 数据集不只是“示教动作的录像”，它还是一份**被动的力/接触日志**，只是没人去解调；
- 数据集没有失败样本，但**成功里藏着微失败**（夹住又滑、插入前撞、重抓），这些恰恰是第 1 轮最缺的负例；
- 32 个任务一任务一数据集，**任务标签是免费的、无歧义的**；真正会变的是**接触工况**（自由/接触/滑移/卡死），所以“数据集”的正解不是再堆数据增强，而是**按接触工况重新切分与重加权**。

一句话：把数据集从“素材堆”升级为“实验仪器”。

### 灵感 2 ·「力矩传感」→ 没有传感器，就重建一个“虚拟力矩”

第一性原理：关节力矩不是一个独立于控制的量，它正是控制器为维持/改变运动所施加的量。准静态下，对关节 `j` 写控制律（位置内环 + 重力补偿）：

```
τ_ctrl,j = Kp_j (q*_j − q_j) + Kd_j (q̇*_j − q̇_j) + g_j(q) + τ_ext,j
```

平衡时 `q̈≈q̇≈0`，理想重力补偿抵消 `g`，于是

```
τ_ext,j  ≈  Kp_j (q_j − q*_j)        （符号随约定）
```

也就是说：**跟踪残差 `r = q* − q` 与外部力矩同向、单调，比例因子是 1/Kp**。我们不知道 `Kp`、不知道延迟 δ、不知道评测端是否插值，但：

- **做“有没有接触/接触何时开始”的检测**，只需要一个逐关节标准化的统计量，绝对增益可以被消掉（引理 L9）；
- **做相位切分**，只需要接触分数的上升沿、持续段与高频振荡模式（引理 L11）；
- **做绝对牛顿数**才需要标定，而我们**不声称**能得到绝对力矩。

所以“力矩传感”在本轮被严格降级为一个**计算传感器（computational sensor）**：用命令-测量残差重建**相对力矩/接触强度**，并明确标注其可辨识边界（原则 P8）。这是诚实的版本，也是唯一能用公开数据做出来的版本。

### 合成：VTT（Virtual Torque Tomography，虚拟力矩层析）

把两个灵感拧成一条链：

```
数据集 → 用(q*,q)成对残差重建虚拟力矩 τ̂ → 在每条 episode 上做接触相位层析
      → 得到 32 任务的「接触图谱」→ 反向清洗/重加权训练数据
      → 部署端用同一估计器做接触/滑移门控 + 插入柔顺
      → 把 τ̂ 作为特权教师，蒸馏进视觉-本体潜变量以覆盖不可见接触
```

与第 1 轮的区别：第 1 轮的 IP-02 只能从“腕部视觉 + 抓手标量 + EE 速度”**猜**抓握；本轮加入了一条**有机械语义的物理通道**，它既在数据里、又能在部署端算出来。第 1 轮最大的风险是“抓握伪标签在未见物品上漂移”，而 VTT 的接触标签来自控制残差而不是视觉伪标，**恰好是对该风险的正面修补**。

## 2. 瓶颈重述：为什么是现在

1. **数据侧**：32 个数据集全是成功演示，没有负例；但“成功里的微失败”未被利用。接触工况的分布偏移（不是外观偏移）可能是泛化失败的主因，而没人按接触工况做 OOD 切分。
2. **策略侧**：最难的任务全是接触丰富型（插入/旋转/细操作）。这类任务的失败不是“看不见”，而是“力/对齐状态不可见”。VTT 把这一类隐状态显式化。
3. **接口侧**：官方明确不暴露力矩，却鼓励“动作良构、延迟稳定”。VTT 只用声明内数据，不越线；而其输出还能反过来做**物理一致性自审**（动作是否产生合理的接触谱），提升可信度。
4. **方法侧**：无传感器力估计（momentum observer / disturbance observer）在机器人学里是成熟工具，但**几乎无人把它当作“数据集审计 + VLA 部署”的跨轮研究仪器**。这就是本轮的跨学科接口：把经典控制里的可观测量，接到具身基础模型的数据与推理管线上。

## 3. 研究问题（Q6–Q11，承接 Q1–Q5）

- **Q6（可辨识性）**：在增益 `Kp/Kd`、循环延迟 δ、重力补偿残差、评测端插值全部未知的条件下，`(q*, q)` 残差能否给出**单调且可校准**的接触强度？其失效边界（高速、强平滑、力矩内环）在哪里？
- **Q7（相位可识别性）**：能否仅用 VTT + 抓手 + EE 速度，把 episode 切成 `free/approach/contact/lift/transport/align/insert/release/slip`，并以此替代第 1 轮 IP-06 里昂贵的 VLM 伪标，从而给六因子分解提供**物理标签**？
- **Q8（数据价值）**：按接触图谱做清洗（幽灵成功、近重复）与重加权（稀有接触工况上采样），是否比外观域随机化更能提升 OOD 成功率？
- **Q9（在线门控）**：部署端用自己下发的动作与实测状态算 VTT，能否以**高精度低召回**检出滑移/失接触，从而修正 IP-02 的不对称误判？
- **Q10（柔顺插入）**：在只有“位置目标”的 API 下，能否用 VTT 触发“降刚度 + 平面搜索 + 卡死回退”，把插入/旋转类任务从“硬怼”变成“找孔”？
- **Q11（部署可行性）**：同一估计器在数据集与评测端的语义是否同构？能否用**被动系统辨识**（不加激励）估出延迟与相对增益，从而在不触发“不规则交互”告警的前提下完成在线校准？

## 4. 设计原则（在 P1–P6 基础上新增）

- **P1 单一计分货币**（保留）：一切必须能落到终态成功率。
- **P2 隐状态显式化**（保留并升级）：抓握/接触/滑移/卡死都要成为**带置信度的隐变量**；本轮进一步要求它们有机械解释。
- **P3 技能组合而非参数堆叠**（保留）。
- **P4 推理期吸收偏移**（保留）。
- **P5 合规优先于最优**（保留）：只用声明内观测；不读评测侧私有信息；不注入可能被判“不规则交互”的激励信号（故主动探针降为 P2，首选被动辨识）。
- **P6 单模型、单 checkpoint、单 API**（保留）。
- **P7 物理一致优先于黑箱拟合**：每个接触标签都要能写成“力/力矩/运动学”的因果解释；学到的检测器只是加速器，不是证据本身。
- **P8 不虚构传感器**：全文只称“虚拟力矩/接触分数”，并显式报告可辨识边界与失效案例；绝不把相对量包装成绝对牛顿。
- **P9 数据-部署同构**：数据集上的 VTT 与部署端的 VTT 必须是同一段代码、同一套语义，只是标定参数不同；否则离线标签无法迁移。

## 6. 与第 1 轮的严格接口（不推倒，只加固）

- **IP-02 GraspVerify**：保留视觉三信号，新增 VTT 作为**第四路物理证据**；介入准则从“视觉置信度”升级为“视觉 + 接触残差 + 滑移几何”的合取，目标是把第 1 轮担心的假阳性压到 ≤1%。
- **IP-03 ChunkStitch**：接触相位决定 chunk 长度（插入相位更短），VTT 提供相位切换信号。
- **IP-06 六因子代理评测**：`P(reach)·P(grasp)·P(transport)·P(align)·P(insert)·P(release)` 的每个因子都可以由 VTT 相位自动给出，减少 VLM 打标成本与噪声。
- **IP-01 SkillToken-MoE**：接触图谱可作为“阶段 token”的监督信号，让专家划分对齐接触相位，而不是只按任务切。

## 7. 本轮最大风险（一句话）

**整个方案押在“评测端的跟踪残差主要由接触/负载决定”这一条机械假设上；若评测端实际使用力矩/阻抗内环、重平滑或强插值，残差会被环路动力学而非接触主导，VTT 会给出看起来物理上很可信、实际上系统性错误的接触标签与在线门控——这是“越有道理越危险”的失败模式。**

## 8. 下一轮迭代计划（深化与修剪）

- **先做“证伪”再做大**：E619–E623 是生死线——若自由空间残差不能被压到噪声级、或接触相位与人工标注一致性 <0.6，则**立刻砍掉 IP-12/IP-13/IP-14**，只保留 IP-10/IP-11 作为离线数据审计，且不使用其在线门控。
- **同构性优先**：E627 必须先证明“数据集上的 VTT”和“部署端的 VTT”可通过一个单调变换对齐；否则不做任何跨端阈值迁移。
- **深化**：把接触 HMM 从“手工状态机”升级为“任务语法约束的切换系统”（例如插入任务强制 `approach→contact→search→insert→release`），并让 IP-01 的阶段 token 直接复用该后验。
- **保留项**：IP-09（一切的地基）、IP-10（数据侧公共品）、IP-15（合规与语义校准）在任何情况下不砍。

## 0. 本轮结论摘要

**一句话路线**：官方数据集**没有力矩通道，却成对记录了“目标动作”和“实测状态”**——这使力矩可以作为一个**可重建的影子**被解调出来。我们据此提出 **VTT**：用命令-测量残差重建逐关节虚拟力矩，离线层析 32 个数据集的接触相位（ContactAtlas），在线做接触/滑移门控（TorqueLens），并用接触触发的柔顺搜索与特权蒸馏去攻插入/旋转类任务。

**为什么这条路线值得做（三条依据，均为已核实的结构性事实）**：

| 事实 | 含义 | 推出的设计 |
|---|---|---|
| 公开数据集与评测接口**均无力矩/力/速度/触觉** | “力矩传感”不能读，只能重建 | IP-09：虚拟力矩，而非真实力矩 |
| 数据集**同时**有 `action.*`（目标）与 `observation.state.*`（实测） | 闭环残差 `r=q*−q` 是一份被忽略的力日志 | IP-09/12：数据-部署同构的接触分数 |
| 32 个数据集全是**成功演示**，无失败/奖励字段 | 负例只能从成功轨迹里的微滑移/失接触挖掘 | IP-10/11：接触图谱 + 数据清洗 |

**合规红线（P5 不变）**：只用声明内观测；不注入易被判定为“不规则交互”的激励（主动探针降为 P2，默认被动辨识）；不把相对量包装成绝对力矩（P8）。

## 1. 创新点清单总表（本轮新增）

## 2. 创新点详述

### IP-09 · VTT 虚拟力矩层析（P0）

- **直觉**：机器人“用多大力”写在它的跟踪误差里。位置内环越硬，误差越小但比例关系越稳定；我们不需要知道硬度，只需要知道“误差什么时候异常变大且持续”。
- **两种实现（由易到难）**：
  1. **准静态残差（主用）**：`r_t = q*_{t−δ} − q_t`；逐关节、按速度分箱做稳健中心/尺度标准化，得接触分数 `s_t = Σ_j z_{t,j}²`。
  2. **动量观测器（备用，需 G1 URDF）**：`p = M(q)q̇`，`τ̂_ext = K_o (p − ∫(τ + Cᵀq̇ − g + τ̂_ext)dt)`。用于动态段与高速段，补上准静态模型的盲区。
- **必须显式处理的四个未知量**：①内环增益 `Kp,Kd`；②循环延迟 `δ`；③重力补偿残差与摩擦；④评测端插值/平滑。策略是：δ 用互相关估（IP-15），增益用逐关节标准化消掉，重力/摩擦吸收进自由空间基线，插值用速度分箱 + 自由段在线校准兜底。
- **与现有方案的差异**：现有 VLA 把接触当作视觉问题或直接忽略；无传感器力估计是经典控制工具，但**没人把它接到“官方数据集审计 + 远程部署 VLA”的链路上**。本 IP 的贡献是“把数据集当仪器”。
- **落地步骤**：①解码一对 `(action,state)` 并对齐时间轴；②估 δ；③自由段拟合速度分箱的稳健基线；④算 `s_t` 与 `τ̂_t`；⑤在人工标注的少量片段上验证 onset；⑥输出每 episode 的接触序列。
- **风险**：高速段被未建模速度耦合污染（§6 已量化）；强平滑/力矩内环使残差不再反映接触（§10 风险登记）。

### IP-10 · ContactAtlas 接触相位图谱（P0）

- **直觉**：一条操作轨迹就是一段“接触语法”：先自由接近，再接触，再抬起/搬运，再对准/插入，最后释放。语法可以从物理信号里读出来，不必让 VLM 逐帧猜。
- **定义**：在图谱中，任务 `k` 的相位集合 `M = {free, approach, contact, lift, transport, align, insert, release, slip}`；每条 episode 用**任务语法约束的切换 HMM**做 Viterbi 解码。发射特征 = `(s_t, |v_ee|, ġ_t, σ_slip)`；转移矩阵由任务语法给先验（如插入任务禁止 `free→insert`）。
- **产出**：①每任务各相位的时长/接触强度/振荡频率分布；②每个因子的经验成功率（直接喂给第 1 轮 IP-06 的六因子分解）；③异常 episode 列表（见 IP-11）。
- **与现有方案的差异**：第 1 轮用 VLM 伪标，贵且在未见物品上会漂；本 IP 用物理信号 + 任务语法，**标注成本近零**，且标签可解释。
- **风险**：某些释放动作的接触变化弱（轻物体），相位边界模糊 → 用滞回 + 最小驻留时间（hysteresis + min-dwell）约束，并保留 VLM 作为仲裁。

### IP-11 · DataForge 数据清洗与接触重加权（P1）

- **直觉**：32 个数据集全是“成功”的，但成功与成功不同：有的干净利落，有的颤颤巍巍、滑了两次才夹住。后者对失败恢复最有价值，却在均匀采样里被稀释。
- **四类数据价值信号**：
  1. **幽灵成功**：抓握相位内接触分数始终低于阈值，但 episode 被记为成功 → 可能是“推/拨完成”或标注宽松；保留但打标，避免污染“抓握”标签。
  2. **近失败/微滑移**：成功轨迹中出现短暂 `s` 跌落 + 物体相对位移 → 高价值恢复样本。
  3. **近重复**：接触签名 DTW 距离 < ε 的 episode → 下采样，降低过拟合。
  4. **稀有接触工况**：签名密度低（如高摩擦卡死、斜面插入）→ 上采样。
- **重加权**：`w_i ∝ 1/(\hat p(signature_i) + λ)`，并给出 OOD 重加权偏差界（引理 L14）。
- **风险**：重加权会放大遥操抖动/坏样本 → 必须与“动作平滑度/接触一致性”双重门槛联用。

### IP-12 · TorqueLens 在线接触/滑移门控（P0）

- **直觉**：第 1 轮的 GraspVerify 是“看 + 猜”；本轮加一根“物理探针”：如果夹住了，搬运时接触残差应持续、物体相对腕部应静止；如果滑了，物体在腕部画面里动、夹爪命令没变、残差会突变。三件事同时成立才介入——这就是高精度低召回。
- **与 IP-02 的关系**：把介入准则从 `g_t < τ_conf` 升级为合取：
  `intervene = (p_vis < τ_v) ∧ (s_t < τ_s) ∧ (σ_slip > τ_g) ∧ n_retry < 3`。
  其中 `p_vis` 是第 1 轮视觉抓握概率；`s_t` 是 VTT 接触分数；`σ_slip` 是腕部物体相对位移速率。任一不确定即**不介入**（保守）。
- **在线校准**：用 IP-15 估 δ；用 episode 起始自由段在线更新 `(μ,Σ)`；若自由段太短或运动太剧烈，**关闭 VTT 门控**并退回 IP-02。
- **风险**：评测端“重置/平滑”导致首帧残差异常 → 用 3 帧中值 + 上限截断，且把“异常首帧”计入审计而非触发动作。

### IP-13 · ContactCompliance 接触触发柔顺与搜索（P1）

- **直觉**：插入失败常不是“位置不对”，而是“太硬、太快、不知道已经撞上了”。人类插钥匙会边轻推边微调；机器人也应如此。
- **位置 API 下的实现（无需力矩指令）**：
  - 检测到 `insert/align` 相位且 `s_t > τ_c` 时，把每步位置增量乘以 `α_t ∈ (0.4, 0.8]`（虚拟降刚度）；
  - 在垂直于插入轴的平面内叠加**衰减的螺旋/Lissajous 搜索**：`Δp_⊥ = a_t [cos(2πft), sin(2πft)]`，`a_t = a_0 e^{−t/T}`；
  - 若 `s_t > τ_max`（疑似卡死），**先回退 2–5 mm 再带横向偏移重试**，而不是继续加力；
  - 参数 `a_0, f, T, α` 由 ContactAtlas 的相位统计初始化，再真机 A/B 微调。
- **与第 1 轮 IP-03 的协同**：插入相位用短 chunk（高频反馈），搜索动作在 chunk 边界缝合，避免搜索本身制造 jerk。
- **风险**：搜索可能碰倒周边物体（5 类泛化里的干扰物场景）→ 限制搜索幅度、加“禁区”与单物体优先；失败即回退到直线插入。

### IP-14 · TorquePrivileged 特权蒸馏（P1）

- **直觉**：VTT 是训练期的“特权教师”，但部署时若接触不可见/残差不可靠，学生还得靠视觉。把 τ̂ 蒸馏进视觉-本体潜变量，相当于让模型“看见力”。
- **做法**：冻结主干，加一个接触潜变量 `z_c` 与辅助头；`L_aux = −I(z_c; τ̂)` 的对比/回归近似 + 相位分类；策略头同时条件于 `z_c`。部署时若 VTT 可靠就用 VTT，否则用 `z_c`（门控融合）。
- **可辨识边界（引理 L13）**：若物体在腕部画面被完全遮挡或刚性固定，视觉里没有接触信息，`z_c` 不可能凭空恢复——此时必须回退 VTT 或纯保守策略。**不承诺“无传感器也能感知一切”。**
- **风险**：蒸馏把 VTT 的错误也学进去 → 只用“VTT 高置信且自由段校准通过”的样本作教师。

### IP-15 · PassiveLoopID 被动环路辨识（P1）

- **直觉**：我们不知道评测端的内环，但**自然运动本身就是一次宽带激励**。用自然数据做系统辨识，比注入探针更合规。
- **做法**：对每关节拟合 ARX/低阶传递函数 `q_t = f(q_{t−1..}, q*_{t−δ..})`；用 `q*` 与 `q` 的互相关峰估 δ；用频域幅相估相对 `Kp/Kd`；跨任务/跨端口检查稳定性。**不注入任何额外信号**。
- **主动探针（降为 P2）**：仅在自由相位、低速、低幅（≤0.5°）、带 taper 的前提下，才考虑小幅多正弦；默认关闭，且必须先获合规确认。
- **风险**：自然数据激励不足（某些任务几乎静止）→ 用多任务池化 + 分层估计，估不出就标记 `unidentified` 并关闭 VTT 门控。

### IP-16 · PhysAudit 物理一致性自审（P2）

- **直觉**：官方会看“延迟波动、动作统计规律性”。与其被动挨审，不如主动交一份“物理体检报告”：动作是否产生合理接触谱、jerk 是否在数据分布内、chunk 边界是否连续、各端口残差是否同分布。
- **产出**：延迟 p50/p99、jerk 直方图、接触谱覆盖率、`degraded` 次数、跨端口 KS 检验。
- **风险**：过度限幅/平滑压低成功率 → 只做“报告与告警”，不自动改写动作（与第 1 轮 IP-08 的教训一致）。

## 3. 符号与定义（U13–U24）

| 符号 | 含义 |
|---|---|
| `q*_t` | 第 t 步下发的目标关节位置（来自 `action.*` 或我们自己的历史） |
| `q_t` | 第 t 步实测关节位置（来自 `observation.state.*`） |
| `r_t` | 命令-测量残差 `q*_{t−δ} − q_t` |
| `τ̂_t` | 虚拟力矩（相对量，非绝对牛顿） |
| `s_t` | 接触分数（逐关节标准化残差的平方和） |
| `m_t` | 接触相位状态 |
| `σ_slip,t` | 滑移证据（物体在腕部系的相对位移速率） |
| `A_k` | 任务 k 的 ContactAtlas |
| `α_t, a_t` | 虚拟柔顺增益与搜索幅度 |
| `δ, Ĝ` | 环路延迟与相对增益估计 |
| `z_c` | 视觉-本体接触潜变量 |
| `w_i` | 第 i 条 episode 的数据价值权重 |
| `Φ` | 物理一致性指数 |

**定义 U13（命令-测量残差）** `r_t = q*_{t−δ} − q_t ∈ R^14`（双臂各 7 维）；`δ` 由 IP-15 估计，缺省为 1 帧。

**定义 U14（虚拟力矩）** 准静态下 `τ̂_t = K̂_p ⊙ r_t`，其中 `K̂_p` 只用于给相对量一个有物理量纲的叙述；**所有检测与门控只用 `s_t`，不用 `τ̂_t` 的绝对值**（P8）。

**定义 U15（接触分数）** `s_t = Σ_j z_{t,j}²`，`z_{t,j} = (r_{t,j} − μ_j(v_t)) / σ_j(v_t)`，`(μ_j,σ_j)` 为按速度分箱的自由空间稳健中心/尺度。

**定义 U16（接触相位）** `m_t ∈ M = {free, approach, contact, lift, transport, align, insert, release, slip}`。

**定义 U17（语法约束切换 HMM）** `P(m_t | m_{t−1}) = A_{m_{t−1},m_t}·1[(m_{t−1},m_t) ∈ G_k]`，`G_k` 为任务 k 的合法转移集；发射 `P(x_t | m_t)` 用高斯/混合模型，`x_t=(s_t, |v_ee,t|, ġ_t, σ_slip,t)`。

**定义 U18（ContactAtlas）** `A_k = {π_k, A_k, {μ_{k,m},Σ_{k,m}}, Dur_{k,m}, Spec_{k,m}}`，`Spec` 为插入相位的高频接触振荡谱。

**定义 U19（滑移证据）** `σ_slip,t = ||Δ p_o^{gripper}(t)|| / Δt · 1[|Δg*_t| < ε_g]`，`p_o^{gripper}` 为腕部系下目标物体关键点。

**定义 U20（虚拟柔顺）** 位置增量调制 `Δq^cmd_t = α_t Δq^policy_t + Δq^search_t`，`Δq^search_t` 为垂直于插入轴的衰减搜索项。

**定义 U21（被动辨识）** `δ̂ = argmax_δ corr(q*_{t−δ}, q_t)`；`Ĝ_j(ω) = \hat q_j(ω)/\hat q*_j(ω)` 在自然激励频段上的幅相。

**定义 U22（特权蒸馏）** `L_aux = −Σ_t log exp(sim(z_{c,t}, e(τ̂_t))/κ) / Σ_{t'} exp(sim(z_{c,t}, e(τ̂_{t'}))/κ)`。

**定义 U23（数据价值权重）** `w_i = [1/(\hat p(sig_i)+λ)] · 1[clean_i]`，`clean_i` 通过动作平滑度 + 接触一致性双门槛。

**定义 U24（物理一致性指数）** `Φ = w_1·(jerk 分位) + w_2·(接触谱覆盖率) + w_3·(跨端口残差 KS) + w_4·(降级率)`，用于 IP-16 报告。

## 4. 引理与推导（L8–L15）

**引理 L8（准静态残差–力矩关系）** 设关节 j 的位置内环为 `τ_ctrl,j = Kp_j(q*_j−q_j) + Kd_j(q̇*_j−q̇_j) + g_j(q) + τ_f,j`，动力学 `M q̈ + C q̇ + g = τ_ctrl + τ_ext`。在准静态 `q̈≈q̇≈0` 且重力补偿近似理想时，`τ_ext,j ≈ Kp_j(q_j − q*_j)`。因此 `r_j = q*_j−q_j` 与 `τ_ext,j` **反号同幅值缩放**，是单调代理。∎

**引理 L9（免标定接触检测）** 自由空间下 `r_j ~ N(μ_j(v), σ_j²(v))`（条件于速度）。令 `z_j=(r_j−μ_j)/σ_j`，则 `s=Σ z_j² ~ χ²_K`（K 为关节数）。取阈值 `τ = χ²_{K,1−α}`，则自由空间假阳性率 ≤ α，**与 `Kp_j, σ_j` 的具体值无关**；外部力矩只改变非中心参数。故不需要绝对增益即可控制 FPR。∎

**引理 L10（滑移可识别性）** 设 `p_o^{g}(t)` 为目标物体在夹爪系的质心。刚性抓握 ⇒ `p_o^g` 常数；滑移 ⇒ `||Δp_o^g||>ε` 且 `|Δg*|<ε_g`（命令未变）。若腕部相机可见物体，则 `Δp_o^g` 可直接测；若不可见，则滑移在视觉上不可辨识，只能由 `s_t` 的负载突变间接提示。故滑移检测是“视觉 + VTT”的合取，不是单通道。∎

**引理 L11（相位可识别性）** 定义事件：接触起始 = `s` 上穿 `τ_c` 且持续 ≥n 帧；抬起 = 接触保持且 `v_ee,z>v_0`；搬运 = 接触保持且 `|v_ee|>v_t`；对准 = 接触间歇且 `|v_ee|` 低；插入 = 接触持续、`|v_ee|` 低且 `s` 含 `f>f_0` 的高频分量；释放 = `g*` 增大且 `s` 下穿 `τ_c`。若各信号的信噪比使上述区间可分，则相位序列可辨识。故六因子标签可由本体 + VTT 独立于视觉获得。∎

**引理 L12（柔顺降低卡死概率的条件）** 一维轴孔装配中，设横向错位 `e ~ N(0,σ_e²)`、间隙 `c`、插入速度 `v`。当 `e>c` 时接触力随插入深度上升直至卡死。若搜索幅度 `a ≥ 2σ_e` 覆盖错位分布的主要质量，且插入步长满足 `v·Δt < c/2`（在接触被检测到之前不越界），则单次尝试的卡死概率严格小于无搜索的直线插入。故“先找孔、再进给”有机械优势。∎

**引理 L13（特权蒸馏的信息上界）** 对任意学生潜变量 `z_c=f(o_vis,o_prop)`，有 `I(τ̂; z_c) ≤ I(τ̂; o_vis,o_prop)`。若接触在视觉中不可观测（完全遮挡/刚性固定），则 `I(τ̂;o_vis)≈0`，蒸馏无法恢复接触；因此 `z_c` 与 VTT 必须**门控互补**，不能互相替代。∎

**引理 L14（接触重加权的偏差界）** 设训练/目标分布的接触签名密度为 `p_tr(s), p_ood(s)`，取 `w(s)=p_ood(s)/p_tr(s)` 时重要性加权风险对 OOD 无偏；用估计 `ŵ` 时，风险偏差 ≤ `2L·TV(p_tr,p_ood)·E|ŵ−w|`（L 为损失上界，TV 为全变差）。故签名估计误差会线性传导，需对 `ŵ` 做截断。∎

**引理 L15（数据-部署同构）** 若数据集与部署端使用同一估计器 `D(·)`，且延迟/增益差异可被一个**逐关节单调变换**吸收，则离线接触分数与在线接触分数在分位数意义下对齐，阈值可只用一个每任务校准常数迁移。若评测端引入时变插值/平滑，则变换随时间变化，阈值不可直接迁移——此时必须用 IP-15 在线重估，否则 VTT 门控应关闭。∎

# ===== IP-09 + IP-15：虚拟力矩 / 接触分数（数据集与部署端同一段代码）=====
import numpy as np

class VTT:
    """Virtual Torque Tomography: command-measurement residual -> contact score."""
    def __init__(self, speed_bins=(0, .05, .15, .3, .6, 2.0), delay=1):
        self.bins = np.asarray(speed_bins, float)
        self.delay = delay                 # δ̂ from IP-15
        self.base = {}                     # per speed-bin robust (mu, sd)

    def fit_free(self, q_cmd, q_meas):
        """Only free-space segments. q_cmd/q_meas: [T,14]."""
        r = q_cmd[:-self.delay] - q_meas[self.delay:]
        v = np.abs(np.gradient(q_meas, axis=0))[self.delay:]
        speed = np.linalg.norm(v[:, [0, 7]], axis=1)   # coarse whole-arm speed
        for lo, hi in zip(self.bins[:-1], self.bins[1:]):
            m = (speed >= lo) & (speed < hi)
            if m.sum() < 30:
                continue
            mu = np.median(r[m], axis=0)
            sd = 1.4826 * np.median(np.abs(r[m] - mu), axis=0)
            self.base[(lo, hi)] = (mu, np.maximum(sd, 1e-8))

    def score(self, q_cmd_hist, q_meas_hist, v_now):
        """Online: returns contact score s_t and robust z."""
        b = self._bin(v_now)
        mu, sd = self.base.get(b, self.base.get(self.bins[:2].tolist() and None) or (0, 1))
        r = q_cmd_hist[-1 - self.delay] - q_meas_hist[-1]
        z = (r - mu) / sd
        z = np.clip(z, -8, 8)              # guard against evaluator reset spikes
        return float(z @ z), z

    def _bin(self, v):
        for lo, hi in zip(self.bins[:-1], self.bins[1:]):
            if lo <= v < hi:
                return (lo, hi)
        return (self.bins[-2], self.bins[-1])

## 6. 合成数据自检（**synthetic，仅验证统计命题，不是 UniBot 实测**）

为避免“纸上物理”，本轮用 7 关节准静态 PD 模型做了一次自洽性检查：`r = τ_ext/Kp + c·v + bias + ε`，`Kp` 逐关节对数正态（未知）、`ε` 逐关节异方差、`c` 为未建模速度耦合。标定只用近静止自由段，阈值取自由分数 95 分位。

**结果 1（引理 L9：免标定检测可行）**

| 外部力矩（作用于 2 个关节） | 免标定 TPR @ 5% FPR | 已知真实尺度（oracle）TPR |
|---|---|---|
| 0.2 N·m | 0.092 | 0.181 |
| 0.5 N·m | 0.445 | 0.578 |
| 1.0 N·m | 0.989 | 0.996 |
| 2.0 N·m | 1.000 | 1.000 |

实测 FPR = 0.050（目标 0.05）。含义：**在准静态、低噪声段，逐关节标准化确实能在不知道增益的情况下控制假阳性**；这也说明小力矩（<0.5 N·m）本就难检，不能承诺。

**结果 2（最大风险的量化：速度污染）** 若只用“静止自由段”标定，而不按速度分层：

| 自由空间速度 | FPR |
|---|---|
| 0.02 rad/s | 0.052 |
| 0.10 rad/s | 0.059 |
| 0.25 rad/s | 0.114 |
| 0.50 rad/s | 0.418 |
| 1.00 rad/s | 0.984 |

含义：未建模的速度耦合会把“快速自由运动”误判为接触。**这正是本方案最大的现实风险，而不是假想。**

**结果 3（缓解：速度分箱标定）** 按速度分箱重估基线后：

| 自由空间速度 | FPR（分层） |
|---|---|
| 0.02 | 0.051 |
| 0.10 | 0.053 |
| 0.25 | 0.055 |
| 0.50 | 0.044 |
| 1.00 | 0.193 |

含义：分层标定把可用区间扩到约 0.5 rad/s，但高速端仍崩（末箱过粗、二阶动态未建模）。**因此设计上必须在高速运输相位关闭/降权 VTT，或切换到动量观测器。** 这不是调参能完全消除的，必须写进退化链。

> 复现说明：上述为 20,000 次/条件的合成实验，`numpy` 随机种子固定；脚本仅依赖 numpy。它**不**声明 UniBot 数据的任何统计性质。
