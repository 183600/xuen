# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配×主动交互不确定性二分闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「记忆检索」×「UniBot-V1」）

> R69 让闭环第一次学会「问」：把 epistemic 歧义交给看、问、触，用 VoI 判断值不值得问。但它隐含了一个从未言明的前提——**每一道歧义都是新鲜的，必须当场获取新信息才能解决**。现实里大量歧义早已被解过：同一个杯子滑不滑、同一个人说「等等」是什么意思、同一扇门在什么角度会卡住、同一类工件的抓取该用哪种姿态。对这类**重复出现的歧义**，每次重新观测、重新提问，是在为同一道题反复付费。系统缺的不是「再问一次」，而是「**记起上一次**」。
>
> 更关键的是，R69 把消歧手段局限在「即时获取信息」这一条通道。但人类消歧有三条本质不同的通道：**问**（获取新证据）、**忆**（调取已有经验）、**学**（把经验固化成技能）。R69 只实现了第一条；本轮补上第二条，并把它与第一条、第三条放进同一个决策框架里比较。`记忆检索` 给出的正是这条通道的机制；`UniBot-V1` 给出的则是它最有价值的部署形态——一个统一具身平台上，**跨任务、跨实例、跨本体**的经验库。
>
> 核心命题：**记忆检索是「第三类认知动作」——零交互成本、零参数写入，但它是一次「现在像过去」的赌注。因此检索必须带适用性证书（过去的假设现在是否仍成立）、必须被反驳检索挑战（有没有同样相似却相反的先例）、必须遵守「记忆是先验不是证据」（不得把风险压到当前观测允许的下界以下）；一旦证书不过、被污染或存在未消解的相似反例，就退化为 R69/R68。** 命名 **RECALL-RAS**（Retrieval-Enhanced Certified Adaptive Long-term Loop）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这件事我是不是见过，见过的还作数吗**」——不确定性不一定要求新证据，也可以是一次被认证的回忆；但**回忆错了，比不问更持久**。

## 0. 直觉与动机

**灵感 1（记忆检索 = 第三条消歧通道「忆」，与「问」「学」并列）**
直觉：R69 的 VoI 问的是「再观测一次能降多少熵」，它把「获取新信息」当成唯一的消歧手段。但人类面对熟悉的歧义时，第一反应往往不是问，而是**回想**：这个杯子我拿过，是滑的；这个人上次说「等等」是想让我停；这个抽屉要先往上提一点再拉。回忆的成本几乎是零——不打扰任何人、不移动任何关节、不改变任何一个参数，只是在经验库里做一次模式补全（pattern completion）。它天然适合**高频、低单次信息、但历史上出现过**的歧义。R69 的「问」适合低频高信息的情形；慢环的「学」适合高频但**从未见过、问也问不出**的系统性歧义；而「忆」恰好卡在两者之间：**见过，但还没被固化进参数**。

**灵感 2（检索是一个赌注：retrieve–reuse–revise–retain）**
直觉：检索便宜，是因为它押注「现在像过去」。经典案例推理（CBR）把这件事拆成四步：检索（retrieve）、复用（reuse）、修正（revise）、保留（retain）。R69 与慢环学习各自只做了其中一半：R69 会「问」却不「记」，慢环会「记」进参数却不先「查」。真正危险的是第二步——**复用**：如果检索到的先例来自一个动力学已经变化的世界（地面变滑、负载变重、用户换了人），直接复用就是把旧答案盖在新问题上。所以检索必须自带一个**适用性证书**：先例成立所依赖的前提，在当前是否还能被独立证据确认。检索的相似度只回答「像不像」，适用性证书才回答「能不能用」。

**灵感 3（UniBot-V1 = 记忆的规模效应，也是错误的超级传播）**
直觉：`UniBot-V1` 作为统一具身平台/基础模型，意味着记忆不再属于单台机器：一个实例在某个任务里学到的先例，可以被同型号、乃至跨本体（不同臂长、不同夹爪、不同底盘）的其他实例检索。这是记忆最大的价值——**经验复用把单机试错变成群体先验**。但它同时把单次错误放大成系统性偏差：一次被污染或被误标的记忆，会被所有检索到它的实例反复复用，成为跨越整个机队的「**记忆超级传播者**」。单次谎言只骗一次，坏记忆会骗很多次、骗很多台、还可能被写进下一轮审计的「历史正确」。规模效应与超级传播是同一枚硬币的两面，必须同时设计。

**灵感 4（统一认知动作：问 / 忆 / 学 / 退；R69 与慢环学习都是边界）**
直觉：R69 的「问」和慢环的「学」不应是两套并列系统，而应是同一个**认知动作空间**里成本不同的选项：问（信息动作，有交互成本与安全风险）、忆（检索动作，有误用风险）、学（写动作，有遗忘风险与停机成本）、退（R68 保守，零收益零新风险）。用一个统一价值 Q(a_epi) = 期望可约损失下降 − 成本 − 风险 来比较，就能得到清晰的分工：**低频高信息 → 问；高频且见过 → 忆；高频且没见过/记不住 → 学；不可信、不可认证、且有未消解反例 → 退**。而且这条路保持了前几轮最重要的理论姿态：R69 是「忆与学的成本 = ∞」的边界，慢环学习是「忆的成本 = ∞」的边界，R68 是「三者都被禁用」的边界。**新层必须是旧层的严格泛化，而不是并列替代。**

**灵感 5（记忆是先验不是证据：防止自证与过度自信）**
直觉：检索到「上次这样做成功了」，会强烈地改变后验，但它**没有产生任何新的观测**。如果允许记忆把风险缩放 λ 一路压到很低，系统就会陷入自我确认（echo chamber）：策略按记忆行动、观测到符合记忆的结果（因为行动本身就是照记忆做的）、再把这次结果写回记忆。危险在于，记忆只是先验；真正的安全下界必须由**当前观测**决定。因此本轮立一条硬约束：**记忆可以重加权、可以选模态，但不能把 λ 压到「当前观测允许的下界」以下，也不能凭空生成一个当前观测未认证的动作模态**。记忆降低的是「犹豫」，不是「证据」。

**灵感 6（新攻击面：记忆投毒、陈旧记忆、跨本体负迁移、检索对抗）**
直觉：既然消歧可以靠「忆」，攻击者就有了新目标。地上倒一桶油让旧记忆过时（陈旧）；往经验库里注入一条「这个负载可以抓」的假先例（投毒）；用跨本体记忆中「别的手能抓住」来误导当前较弱的手（负迁移）；甚至专门构造一个与坏先例最相似的当前情境（检索对抗），让「最相似」恰好等于「最不该用」。最阴险的是，**记忆既是触发器也是裁判**：检索相似度决定要不要用记忆，而审计又拿记忆当历史正确。所以必须交付：多源来源链、反驳检索、跨本体迁移证书、以及「证书不得只依赖被检索的记忆自证」的独立性约束。否则 RECALL 不是更聪明的消歧，而是给错误装了一条**会被全机队复用的永久通道**。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（RECALL-RAS 总览）** RECALL-RAS = (EMR, ACG, EAS, XMR, PCM, RAS-WM†)。四不变式：
(i) **快环零写、记忆只读**（继承 R68 定义 276-i）：实时闭环不写参数、不写记忆，记忆写入只在慢环；
(ii) **记忆写受控**：慢环 append-only、哈希链、结局验证、可回滚审计（定义 321）；
(iii) **记忆是先验不是证据**：检索最多重加权已有认证模态、不得新建动作模态、不得把 λ 压到当前观测允许下界以下（定义 322）；
(iv) **不可自证**：任何适用性/污染证书都不得只依赖被检验的记忆或检索相似度，须含至少一个机制独立的证据源（定义 314、320）。

**定义 311（情景记忆记录）** 一条记忆 m = (κ, φ, m_mode, g*, y, prov, t, ω, e)：
- κ ∈ ℝ^{d_κ}：**本体不变**的情境键（对象类别/可供性/几何关系/任务阶段的嵌入 + 语义地图锚点），显式剥离只与具体本体相关的量（臂长、关节角绝对值）；
- φ：歧义/模态描述（U_epi 的模态原型与可分性）；
- m_mode：当时被选中的模态；g*：当时采取的消歧/任务动作；
- y：结局（成功/失败/代价/人类反馈），**独立于使用该记忆的策略**采集；
- prov：来源链（实例 id、数据源、父记忆哈希）；t：时间戳；ω ∈ [0,1]：经校准的可信权重；e：本体标识与迁移元数据。

**定义 312（记忆检索 EMR）** 当前查询 q = Φ_inv(o_t)（与 κ 同一本体不变空间）。检索分数
s(m | q) = sim(q, κ_m) · ω_m · decay(t − t_m) · appl(m, o_t)，
其中 sim 为归一化相似度，decay 为陈旧衰减，appl ∈ {0,1} 为定义 314 的适用性指示。返回 top-N。**相似度只用于排序，不用于授权**。

**定义 313（检索可信度与校准）** 每条记忆的 ω 与其检索置信度需经校准：在留出集上定义检索校准误差 ECE_ret = Σ_b |B_b|/n · |acc(B_b) − conf(B_b)|，其中 acc 为「被检索且复用后确实正确」的频率，conf 为检索置信度。ECE_ret > τ_ret ⇒ 该区域禁用「忆」通道，退回 R69（定义 315）。

**定义 314（适用性证书 ACG）** 先例 m 的前提集 P(m)（同一物体类别、同一动力学区间、地图区域未变、分布偏移 ≤ δ、无碰撞/磨损告警等）必须在当前被**至少两个机制独立**的证据源确认（如：几何视觉、力觉探针、语义地图一致性、流似然残差）。证书
ACG(m, o_t) = 1[∀p ∈ P(m): verified_p(o_t) ≥ 2 独立源]。
ACG = 0 时记忆降级为 **advisory-only（仅提示，不参与 λ 缩放、不参与模态决策）**。

**定义 315（统一认知动作与价值）** 认知动作 a_epi ∈ {ask, recall, learn, retreat}。统一价值
Q(a_epi) = E[ΔL_reducible | a_epi] − c(a_epi) − r(a_epi)，
其中 ΔL_reducible 是该动作后**可约**（epistemic）损失的期望下降，c 为交互/检索/算力/停机成本，r 为误用/安全/遗忘风险。每轮取 a*_epi = argmax Q；若 max Q ≤ 0 → retreat（R68）。**分工定理**：低重访频率且查询信息量高 ⇒ ask；高重访频率、存在高相似且 ACG=1 的先例 ⇒ recall；高重访、无可用先例或系统性失配 ⇒ learn；证书不过/MCS 不足/存在未消解反例 ⇒ retreat。

**定义 316（检索价值 VoR 与三路边界）** VoR(m) = E[ΔL_epi | reuse(m)] − c_ret − r_mis(m)。设某类歧义的重访率为 π_R，问一次的期望成本为 c_ask，先例的适用概率为 α、误用损失为 L_mis、残余误差为 ε_res，则
**recall 优于 ask ⇔ π_R · c_ask > c_ret + (1−α)·L_mis + π_R · ε_res**。
系：**记忆只在「反复出现 + 先例仍适用」时才比问更值钱**；一次性歧义仍应去问，绝不为省一次交互而动用可能有毒的记忆。

**定义 317（跨本体记忆路由 XMR）** 记忆在 UniBot-V1 机队内共享，但跨本体复用需**迁移证书** TC(m, e_tgt)：源本体 e_src 与目标 e_tgt 在运动学可达域、关节限位、末端刚度、负载能力上的相容性 ≥ τ_comp，且在留出的跨本体验证集上迁移增益 > 0（无负迁移）。不满足则记忆仅在本体内可见，或按定义 318 作为「反例」使用。**负迁移是跨本体记忆的第一风险，优先于收益。**

**定义 318（反驳检索与证伪 CRF）** 在采纳 top-1 之前，检索 top-k 中与当前情境同样相似的反例集 ℛ⁻（导致失败或相反模态的记忆）。若正例与反例的校准相似度差 Δs < τ_s，则判为**未消解歧义**，不得用记忆定案；此时可转 ask，或保持 R68 保守。原则：**不能被反驳的先例，不可信**。

**定义 319（记忆投毒干扰集 ℰ_mem）** 注入假先例（数据投毒）、陈旧但高置信的记忆、跨本体污染（别的手能抓）、检索对抗（构造一个与坏先例最相似的当前状态）、共谋式「历史改写」。并入 AIC：ℰ_RECALL = ℰ_FLUID × ℰ_mem（沿用 R69 的 ℰ_FLUID，新增记忆攻击面）。

**定义 320（来源与污染监控 PCM）** 维护每条记忆的 provenance 链与写入分布。检测「相关注入」：同一来源/同一时间窗/同一模板的批量记忆若在检索中同时被激活，判为可疑簇并隔离（quarantine），该区域「忆」通道降权。污染嫌疑 > τ_poison ⇒ 禁用 recall，转 ask/retreat。

**定义 321（记忆写纪律 MWD）** 快环不写。慢环写入满足：append-only 日志、哈希链、**结局验证独立于使用该记忆的策略**（由未使用该先例的对照/外部反馈确认），去重与冲突标记，且写入本身可回滚（标记失效而非物理删除，保留审计）。这与 R68 的零写、慢环的受控写一脉相承：**写记忆不是漂移，而是一次可审计的账本追加**。

**定义 322（检索参与的风险缩放 RCD）** 设当前观测给出的未消解 epistemic 为 U_epi。若 recall 采纳且 ACG=1、CRF 无未消解反例、PCM 未告警：λ = λ_floor(U_ale + U_epi^res)，其中 U_epi^res 为记忆消解后的**残余** epistemic（记忆是软证据，残余永不置零）；否则 λ = λ_floor(U_ale + U_epi)（回 R69/R68）。且无论如何
**λ ≥ λ_obs_floor**，其中 λ_obs_floor 由当前观测的认证下界给出。⇒ 记忆只能降低「犹豫」，不能降低「证据强度」。

**定义 323（证书 J_RECALL）** J_RECALL = (J_FLUID, ECE_ret, ACG_hash, CRF_result, prov_chain_hash, XMR_transfer_cert, poison_score, recall_ver)。Valid ⇔ Valid(J_FLUID) ∧ ECE_ret ≤ τ_ret ∧ ACG=1 ∧ CRF 无争用 ∧ PCM 未越界 ∧ 跨本体 TC 通过（如跨本体）。

**定义 324（检索预算与延迟）** 记忆库规模随时间增长，检索用近似最近邻（HNSW/IVF），top-N 常数（N ≤ 8）；写入与索引更新只在慢环。快环检索 P99 预算 < 0.3ms。记忆哈希链与审计异步。

**定义 325（非平稳与遗忘）** 每条记忆有半衰期 T½(κ)：decay(t) = 2^{−(t−t_m)/T½}。半衰期内若 ACG 反复失败，记忆被降权或标记失效；失效记忆保留在账本但不参与检索（软删除）。遗忘是**可审计的失效**，不是静默覆盖。

**定义 326（记忆—学习闭环与反自证）** recall 的成功/失败结局（独立验证）成为新记忆；recall 反复失败 ⇒ 触发 VoR 下降、上调 learn 或 ask；learn 产生的行为改变需重新生成检索键（避免用旧键检索到已被参数吸收的行为）。**反自证约束**：用于验证记忆的结局不得由「按该记忆行动」本身单独产生，须有独立通道（外部反馈、对照探针、物理不变量）。

## 2. 关键算法骨架

```python
# IP-264 EMR：情景记忆检索（本体不变键 + 校准 + 陈旧衰减）
class EpisodicMemory:
    def __init__(self, index, calib, half_life):
        self.index, self.calib, self.T12 = index, calib, half_life

    def retrieve(self, o_t, N=8):
        q = embed_invariant(o_t)                       # 剥离本体相关量
        cands = self.index.ann(q, N * 4)               # 近似最近邻
        scored = [(m, self.calib.score(q, m) * decay(m.t, self.T12))
                  for m in cands]
        return sorted(scored, key=lambda z: -z[1])[:N] # 仅排序，不授权

    def counter_retrieve(self, q, N=8):                # IP-267 反驳检索
        return self.index.ann(q, N, filter='negative') # 失败/相反模态先例

    def write(self, m):                                # IP-270 慢环、append-only
        m.prov = hash_chain(m)                         # 哈希链
        self.index.append(m)                           # 快环不可达

# IP-265 ACG：适用性证书（≥2 机制独立源）
def applicability_cert(m, o_t, sources):
    ok = [src.verify(p, o_t) for p in m.preconditions
          for src in sources if src.mechanism_independent(m)]
    return all(sum(ok_p) >= 2 for ok_p in group_by_precondition(ok))

# IP-266 EAS：问 / 忆 / 学 / 退 的统一选择
def choose_epistemic_action(o_t, U_epi, mem, budget):
    cands = {}
    cands['ask']    = mint.value(o_t, U_epi, budget)   # R69 VoI
    for m, s in mem.retrieve(o_t):
        if applicability_cert(m, o_t, SRC) and not mem.crf_contested(m, o_t):
            cands['recall'] = max(cands.get('recall', -inf),
                                  vor(m, s, U_epi) - c_ret - r_mis(m))
    cands['learn']  = atl.value(o_t, U_epi)            # 慢环 VoL（若有）
    cands['retreat'] = 0.0                             # R68 保守基准
    return argmax(cands), cands                         # max<=0 → retreat

# IP-274 主闭环（继承 R69，仅在不确定性处置处插入「忆」）
def RECALL_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_cal)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    act, q = M.eas.choose_epistemic_action(o, U_epi, M.mem, M.budget)
    if act == 'recall' and not slow:
        m = q.best; U_epi = M.mem.apply_prior(modes, m)     # 软证据，残余不置零
        assert M.mem.acg(m, o) and not M.mem.crf_contested(m, o)
    elif act == 'ask' and not slow:
        g = M.mint.choose_interaction(modes, o, M.budget)
        if g: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    elif act == 'learn':
        M.atlas.enqueue_slow(M.mem.drift_region(o), U_epi)  # 慢环，异步
    # 记忆只能降犹豫，不降证据：λ 有观测下界
    U_floor = U_ale + (U_epi if act not in ('recall', 'ask') else U_epi)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor), M.obs_floor(o))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H),
                                    ..., wm_preds)
    if slow: lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, U_cal))
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_r.submit_async(act, m if act == 'recall' else None, U_epi, a_hat)
    return k, lam, mode, (U_ale, U_epi)
```

## 3. 推导

**引理 19（检索价值的分界）** 设某类歧义的重访率 π_R、单次询问成本 c_ask、检索成本 c_ret、先例适用概率 α、误用损失 L_mis、残余误差 ε_res。则记忆检索的长期期望成本低于直接询问当且仅当
π_R·c_ask > c_ret + (1−α)·L_mis + π_R·ε_res。
证明要点：每单位时间，ask 重复支付 π_R·c_ask；recall 支付一次固定检索成本，但以 (1−α) 概率误用并付出 L_mis，且残余 ε_res 仍然存在。取期望并令 recall ≤ ask 即得。系：**先例越不可靠（α↓）或误用越贵（L_mis↑），越应去问；只有当 α 足够高、且歧义确实高频时，忆才成立。** 这就是「记忆只在反复出现时值钱」的定量形式。

**引理 20（跨本体负迁移上界）** 设源/目标本体在末端可达域与刚度上的差异度 d_e（归一化），技能对本体参数的 Lipschitz 常数为 L_e，先例残余误差为 ξ。则跨本体复用的一次性性能损失 ≤ L_e·d_e + ξ。故迁移证书只需保证 d_e ≤ (ε_tol − ξ)/L_e。系：**跨本体记忆必须带「差异预算」，不能只比任务语义相似度**；语义再像，本体差太远，复用就是负迁移。

**引理 21（记忆投毒的超传播与反驳上界）** 单条被污染先例若不经验证被复用 K 次，错误被采纳至少 1 次，且由于记忆复用，危害按 K 放大（超级传播）。若要求 κ 个机制独立源验证（错误相关 ρ<1）并做反驳检索（正反例相似度差 Δs ≥ τ_s），则一次污染被采纳的概率 ≤ δ_m·ρ^{κ−1}·q_CRF + ε_σ，其中 q_CRF 为反驳检索漏检率。系：**记忆投毒比单次撒谎更危险（K 倍复用），但反驳检索与多源验证能把它压回可控**；单源记忆永远不得单独定案。

**定理 18（RECALL 严格包含 R69 与慢环学习）** 在 A99–A102 下，统一认知动作策略在任意状态上的期望风险 ≤ R69（禁用忆/学）；当 VoR ≤ 0 或 ACG=0 或 CRF 争用或 PCM 告警时，逐指令退化为 R69；当 VoR ≤ 0 且 VoI ≤ 0 时，逐指令退化为 R68。若慢环学习也被启用，R69 是「忆/学成本 = ∞」的边界，慢环是「忆成本 = ∞」的边界。⇒ 安全侧永不弱于前层，效率侧获得 **retrieval bonus**（用旧经验省下新交互）。

**定理 19（记忆不引入安全突变）** 检索只对已认证模态重加权、不新建动作模态；λ 受当前观测下界 λ_obs_floor 约束；跨本体复用须过 TC；故记忆改变的是「在已安全集合内选哪个」，不改变安全包络。结合 R68 换装不变式 ⇒ 控制连续、无突变。**记忆是选票，不是新候选人。**

## 6. 本轮最大风险

**一句话**：RECALL-RAS 的全部收益押在「**相似即可适用**」这一前提上——检索相似度只说明「像」，不说明「仍然成立」；一旦相似度被分布漂移、跨本体差异或对抗构造愚弄，系统会**自信地复用一个不再适用的先例**，而由于 `UniBot-V1` 的记忆是跨实例共享的，这条错误先例会被整个机队反复检索、反复复用、并被审计当作「历史正确」——**记错，比不问更持久，也比一次撒谎传播得更远**。

**次级风险与缓解**：
1. **记忆投毒/超级传播** → 多源独立验证（ACG ≥2 源）+ 反驳检索 CRF + PCM 相关注入检测 + 引理 21 上界；
2. **跨本体负迁移** → 迁移证书 TC（差异预算 d_e ≤ (ε−ξ)/L_e）+ 定义 317 + E308；
3. **陈旧记忆被当现行证据** → 半衰期 decay + ACG 反复失败即降权/软删除 + 定义 325；
4. **自证回声室** → 结局验证独立于使用记忆的策略 + λ 观测下界 λ_obs_floor + 定义 322/326；
5. **检索击穿实时预算** → ANN top-N + 索引只在慢环重构 + E313；
6. **UniBot-V1 异构性导致键空间失配** → 本体不变键 κ + 显式剥离本体相关量 + 跨本体验证集。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** 快环零写/记忆只读；记忆写慢环受控（append-only + 哈希链 + 结局验证）；记忆是先验不是证据（不新建模态、不压破 λ_obs_floor）；证书不可自证（≥1 独立证据源）。

**定义 311–313（记录 / 检索 / 校准）** 记忆键剥离本体相关量；检索分数 `sim·ω·decay·appl`，相似度只排序；检索置信度须校准，`ECE_ret > τ_ret` 即禁用忆。

**定义 314（ACG）** 先例前提集 P 由 ≥2 机制独立源确认；不通过则记忆降级 advisory-only，不参与 λ 与模态决策。

**定义 317（XMR）** 跨本体复用须过 TC：运动学/刚度/负载相容且跨本体验证增益 > 0；否则仅本体内可见或作反例。负迁移优先于收益。

**定义 318（CRF）** 采纳前检索同样相似的反例；正反例相似度差 `Δs<τ_s` 判未消解，不得用记忆定案。不能被反驳的先例不可信。

**定义 319–320（攻击面 / PCM）** `ℰ_RECALL=ℰ_FLUID×ℰ_mem`；provenance 链 + 相关注入检测 + 隔离，`poison_score>τ_poison` 禁用忆。

**定义 322（RCD）** 有效记忆消解时 `λ=λ_floor(U_ale+U_epi^res)`（残余不置零）；否则 `λ=λ_floor(U_ale+U_epi)`；始终 `λ ≥ λ_obs_floor`。**记忆降犹豫，不降证据强度。**

**定义 323–325（证书 / 预算 / 遗忘）** J_RECALL 并入 ECE_ret、ACG、CRF、prov、XMR、poison；ANN top-8，快环检索 <0.3ms；半衰期 `decay=2^{−(t−t_m)/T½}`，ACG 反复失败即降权/软删除。

## 3. 关键算法伪代码

```python
# IP-264 EMR：情景记忆检索（本体不变键 + 校准 + 陈旧衰减）
class EpisodicMemory:
    def retrieve(self, o_t, N=8):
        q = embed_invariant(o_t)                        # 剥离本体相关量
        cands = self.index.ann(q, N * 4)
        scored = [(m, self.calib.score(q, m) * decay(m.t, self.T12))
                  for m in cands]
        return sorted(scored, key=lambda z: -z[1])[:N]  # 仅排序，不授权

    def counter_retrieve(self, q, N=8):                 # IP-267 反驳检索
        return self.index.ann(q, N, filter='negative')

    def write(self, m):                                 # IP-270 慢环 append-only
        m.prov = hash_chain(m); self.index.append(m)    # 快环不可达

# IP-265 ACG：适用性证书（≥2 机制独立源）
def applicability_cert(m, o_t, sources):
    return all(sum(src.verify(p, o_t) for src in sources
                   if src.mechanism_independent(m)) >= 2
               for p in m.preconditions)

# IP-266 EAS：问 / 忆 / 学 / 退 统一选择
def choose_epistemic_action(o_t, U_epi, mem, budget):
    cands = {'ask': mint.value(o_t, U_epi, budget),
             'retreat': 0.0}
    for m, s in mem.retrieve(o_t):
        if applicability_cert(m, o_t, SRC) and not mem.crf_contested(m, o_t):
            cands['recall'] = max(cands.get('recall', -inf),
                                  vor(m, s, U_epi) - c_ret - r_mis(m))
    cands['learn'] = atl.value(o_t, U_epi)              # 慢环 VoL（若有）
    return argmax(cands), cands                          # max<=0 → retreat

    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_cal)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    act, q = M.eas.choose_epistemic_action(o, U_epi, M.mem, M.budget)
    if act == 'recall' and not slow:
        U_epi = M.mem.apply_prior(modes, q.best)        # 软证据，残余不置零
    elif act == 'ask' and not slow:
        g = M.mint.choose_interaction(modes, o, M.budget)
        if g: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    elif act == 'learn':
        M.atlas.enqueue_slow(M.mem.drift_region(o), U_epi)   # 慢环异步
    U_floor = U_ale + U_epi
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor), M.obs_floor(o))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H),
                                    ..., wm_preds)
    if slow: lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, U_cal))
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_r.submit_async(act, q.best if act == 'recall' else None, U_epi, a_hat)
    return k, lam, mode, (U_ale, U_epi)
```

## 4. 推导

**引理 19（检索价值分界）** 重访率 π_R、询问成本 c_ask、检索成本 c_ret、先例适用概率 α、误用损失 L_mis、残余误差 ε_res，则
`recall 长期成本 < ask ⇔ π_R·c_ask > c_ret + (1−α)·L_mis + π_R·ε_res`。
系：记忆只在「反复出现 + 先例仍适用」时比问更值钱；一次性歧义应去问。

**引理 20（跨本体负迁移上界）** 本体差异度 d_e、技能对本体的 Lipschitz 常数 L_e、先例残余 ξ，则一次性性能损失 ≤ `L_e·d_e + ξ`，迁移证书只需 `d_e ≤ (ε_tol−ξ)/L_e`。系：语义再像，本体差太远也不能复用。

**引理 21（记忆投毒的超传播与反驳上界）** 单条坏先例复用 K 次则危害按 K 放大；若 κ 源独立验证（相关 ρ<1）且反驳检索漏检 q_CRF，则采纳概率 ≤ `δ_m·ρ^{κ−1}·q_CRF + ε_σ`。系：记忆投毒比单次撒谎更危险（K 倍复用），多源 + CRF 把它压回可控；单源记忆不得单独定案。

**定理 18（RECALL 严格包含 R69 与慢环学习）** A99–A102 下，统一认知动作策略期望风险 ≤ R69；当 `VoR≤0 ∨ ACG=0 ∨ CRF 争用 ∨ PCM 告警` 时逐指令退化为 R69；当 `VoR≤0 ∧ VoI≤0` 时退化为 R68；慢环学习启用时 R69 是「忆/学成本=∞」的边界。安全不让步，效率获 retrieval bonus。

**定理 19（记忆不引入安全突变）** 检索只重加权已认证模态、不新建模态；λ 受 `λ_obs_floor` 约束；跨本体须过 TC；结合 R68 换装不变式 ⇒ 控制连续、无突变。记忆是选票，不是新候选人。

## 7. 本轮最大风险

**一句话**：RECALL-RAS 的全部收益押在「**相似即可适用**」这一前提上——检索相似度只说明「像」，不说明「仍然成立」；一旦相似度被分布漂移、跨本体差异或对抗构造愚弄，系统会自信地复用一个不再适用的先例；而由于 `UniBot-V1` 的记忆跨实例共享，这条错误先例会被整个机队反复检索、反复复用、并被审计当作「历史正确」——**记错，比不问更持久，也比一次撒谎传播得更远**。

**次级风险与缓解**：记忆投毒/超级传播（多源 ACG + CRF + PCM + 引理 21）；跨本体负迁移（TC 差异预算 + E308）；陈旧记忆（半衰期 + 软删除 + E310）；自证回声室（独立结局验证 + λ_obs_floor + 定义 322/326）；检索击穿实时预算（ANN top-8 + 慢环索引重构 + E313）；异构键空间失配（本体不变键 κ + 跨本体验证集）。
