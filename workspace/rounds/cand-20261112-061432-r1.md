# 第 58 轮（承接第 57 轮「少样本元推断×跨模态对账×个性化有界信任」IP-133~138；新灵感循环第 1 轮；本轮灵感：「传感器融合」×「用户需求分析」）

> 第 57 轮把安全的赌注从"模型置信"换到"证据质量"，并用元先验、跨模态对账、个性化信任为证据补上校准与纵深。但它仍默认两件事：**世界的关键性质是可被现有传感器分辨的**（多模态分歧只是噪声/欺骗，加证据终会收敛），**任务目标是对的**（证据门只回答"能不能做"，不回答"该不该做"）。这两条默认在真实部署里最脆：一个"低摩擦浅坡"与"高摩擦陡坡"可能产生几乎相同的滑移读数，融合得越漂亮，越是在把一个结构上不可分辨的量估计得很精确；而用户往往说不清自己真正要什么，说出的需求还可能互相冲突、随时间漂移、甚至被系统的提问方式塑造。本轮两个灵感各拆一条默认：**传感器融合**从"把多路读数平均得更准"升级为"先问这套传感器能否分辨与决策相关的差异"——任务相关可辨识性证书、主动激励与决策充分性；**用户需求分析**从"执行一份给定规格"升级为"在线反演一个可校准、可冲突、可开放世界的需求后验"——陈述/显示/验证三层需求、判别性提问与需求覆盖证书。两者在 **任务相关可观测性**处汇合：一个传感器差异只有在能改变需求相关决策时才值得融合；一个需求只有在系统可观测且可验证的范围内才可被承诺。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"差异可辨识、需求可反演、证据因果新鲜、来源有效独立的承诺说可信"**。

核心矛盾：
- **H29（融合精度 vs 可辨识性）**：传感器融合能压低方差，却压不掉结构性歧义；当两个不同的世界在整套传感器下观测等价时，再多样本、再好的融合器只会给出同一个错误的"高置信均值"。主动激励可以打破等价，但激励本身是动作、要花安全裕度与时间，且并非所有歧义都可安全激励。
- **H30（需求的可说性 vs 可验证性）**：用户说出的需求往往不完整、互相冲突、且部分连用户自己也不知道；显示偏好会被系统自身的行为塑形，事后验证又稀疏而延迟。于是"需求"没有廉价真值，却极易被系统用来给已经想做的动作背书——需求分析可能退化为需求剧场。
- **H31（时序异质 vs 承诺不可逆）**：不同传感器的采样率、延迟、时钟域与有效期不同；在墙钟时刻 t 融合，可能把"此刻的视觉"与"接触前的力"混在一起。更严重的是，迟到证据可以推翻已做出的不可逆承诺，而"多模态"也未必独立——共享上游模型、标定基准或物理欺骗会让多路证据同错。

## 0. 直觉与动机

**灵感 1（传感器融合 → 先可辨识，后融合）**
直觉：把传感器融合想成"给世界做选择题"。若两个候选世界在整套传感器上产生同一份答卷，那么融合算法无论多先进都无法把它们分开；它只能把同一个歧义平均得更光滑。传统做法用后验方差衡量"知道多少"，但低方差只说明"所有传感器都在重复同一句话"，不说明"这句话足以区分会改变决策的差异"。因此本轮把可辨识性提到融合之前：先计算**需求相关泛函 φ(θ)**（例如可通行性、接触风险、所需抓持力）在观测等价类内的取值范围；范围窄到不足以改变最优动作，才叫**决策充分可辨识**。对不可辨识方向，要么做**可撤回的主动激励**（换视角/换接触点/轻压再撤）提高观测矩阵秩，要么诚实地把等价类交给保守动作或人，而不是伪造精度。

**灵感 2（用户需求分析 → 需求是后验，不是文档）**
直觉：需求分析在传统工程里像"开工前填一张表"，但在具身系统里，需求是**在互动中逐步长出来的隐变量**。用户可能只说得清硬约束（"别碰倒杯子"），说不清软偏好（"别太慢，也别太莽"）；他会在看到机器人行为后才意识到自己还在意什么。于是把需求建成结构化假设 N=(硬约束,软效用,验收容差,开放世界标记) 上的校准后验，并把证据分三层：**陈述需求**（用户说的）、**显示需求**（用户在具体选择中暴露的）、**验证需求**（事后结果是否被接受）。提问不再是"把表填满"，而是选**最能改变动作的判别性问题**；未覆盖或冲突的需求必须显式暴露，而不是用默认值悄悄补齐。

**灵感 3（两灵感合流 → 任务相关可观测性）**
直觉：传感器融合与需求分析其实共用一句话——**"你在意的差异，我看得见吗？"** 看得见却不在意，是浪费融合；在意却看不见，是空头承诺。把二者合成一个判据：证据对当前需求**充分**，当且仅当所有与观测一致的潜在世界，在**已反演的需求模型**下会导出同一个 δ-最优动作（或风险差 ≤δ）。这使系统可以明确说出三类"不知道"：世界不可辨识（传感器不够/歧义）、需求不可辨识（没问对/用户也没想清）、二者耦合不可辨识（某个需求维度恰好对应一个观测盲区）。三种不知道对应三种保守出口，而不是三种自信解释。

**灵感 4（时序与溯源 → 融合的"何时"与"从哪来"）**
直觉：融合不仅在"哪个模态"上做账，还要在"事件时间"与"证据家谱"上做账。每条证据带事件时间区间、摄入时间、有效期与来源链；承诺只能使用**事件时间已越过水位线**且相对物理过程时间尺度仍新鲜的那部分证据，否则先等、先加宽或退到可撤回层。另一点更隐蔽：两个模态标签不同，不代表误差独立；若它们共享同一个上游模型、同一次标定或同一个物理欺骗源，它们就是**同一条证据被抄了两遍**。溯源图让"有效独立证据数"可计算，从而把第 57 轮 EV-xmodal 的"声明独立"升级为"审计独立"。

**灵感 5（PCE+++ → 六门承诺与统一保守出口）**
直觉：把第 57 轮的探-诺-演+扩成"先诊断再行动"的六门：物理证据门（能不能踩）、可辨识门（看不看得清）、需求门（该不该做、为谁做）、时序门（证据是否新鲜到能支撑这次不可逆）、溯源门（证据是否真的独立）、同意门（人是否授权）。任一门不过，按**信息获取成本从低到高、动作风险从高到低**的顺序退：可撤回激励 → 判别性提问 → 绕行 → 降档/降承诺级别 → L2 协商 → 安全停。新增的两种"探针"（激励探针、需求提问）都必须有预算上限与速率上限，且永远不能直接产生不可逆承诺。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（任务相关可辨识性 TRI 与可辨识证书）** 设世界隐状态 θ、传感器观测模型 o_m=h_m(θ)+ε_m、需求相关泛函 φ(θ)（可通行性/风险/所需力等，向量）。证据 o 的 ε-可信集 E_ε(o)={θ : log p(o|θ) ≥ sup_θ log p(o|θ) − ε}。称 φ 在 o 上 **(δ_id, ε)-可辨识**当且仅当 diam(φ(E_ε(o)))≤δ_id；称对需求模型 N 与动作集 𝒜 **决策充分可辨识**当且仅当
∀θ,θ'∈E_ε(o)：argmin_{a∈𝒜} Risk(a;θ,N) 的 δ_id-最优解集相同（或风险差 ≤δ_id）。
局部用 Fisher 信息 I(θ)=Σ_m J_m^T Σ_m^{-1} J_m 诊断：若存在方向 v 使 v^T I(θ)v≤ε_I 且 (∂φ/∂θ)v≠0，则 φ 在该方向**结构不可辨识**，增加同类样本无效，只能换观测几何（激励）或承认歧义。可辨识证书 IdCert=(S_id,S_null,[φ_lo,φ_hi],δ_id,A_exc,exc_safe)，其中 S_null 为零空间方向、A_exc 为允许的可撤回激励集、exc_safe 表示是否存在不进入不可逆集的激励。**不可逆承诺要求 δ_id≤δ_id^max 且 S_null 方向对 φ 无投影；仅局部线性证书不得用于 L2。**

**定义 140（需求隐变量分析 NLA）** 需求结构 N=(C,U,A,O)：硬约束 C（必须满足）、软效用 U（权重 w）、验收容差 A、开放世界标记 O（尚未被反演/验证的需求维度）。需求后验 p_t(N|h_t) 由陈述/显示/验证三类证据融合，校准契约 ECE_N≤ε_N。需求覆盖 RC(N)=min_{d∈D} conf(维度 d 已被充分反演且验证)，未覆盖维度必须显式标为 open 而非赋默认权重。判别性提问策略：
q* = argmax_{q∈Q_nd} VOI_N(q) − cost(q)，VOI_N(q)=E_o[H(p(N))−H(p(N)|o)]，
Q_nd 为**非操纵性提问集**（不得泄露系统偏好答案、不得为实现授权扩张服务），且每检查点提问数 ≤k_ask、速率 ≤r_ask。若 max VOI_N<θ_ask 或预算耗尽，则转保守默认；若出现验收失败但 N 未预测到，标记**需求惊奇**并把新维度加入 O。

**定义 141（需求-约束可追溯对齐 RCT）** 追溯图 𝒯：需求维度 → 操作约束 → 证据类 → 验收测试。代理缺口 gap(n)=|观测到的约束满足度 − 验证到的需求满足度|；需求冲突集 Conf={C_i,C_j : 不存在 a 同时满足二者容差}；不可满足/冲突必须经显式权衡同意 Π_tradeoff，不得由系统自行降权。**非操纵条件**：系统的提问与建议策略的优化目标不得包含自身授权/收益项；对任意 q∈Q_nd，授权扩张只能来自显式人工事件 e_grant。RCT 通过 ⇔ 动作 a 可追溯到已反演且覆盖的需求维度、无未处理冲突、代理缺口 ≤θ_gap。

**定义 142（时序因果融合 TCF）** 证据 e=(o_m,[t_e^-,t_e^+],a_e,TTL_e,src)，事件时间区间、摄入时间、有效期与来源。传感器时钟偏移有界；水位线 W(t)=min_m W_m(t)（各传感器已保证收到的最晚事件时间）。**因果融合**只使用 t_e^+≤W(t) 的证据；对未覆盖的隐变量按缺失证据加宽。设物理过程时间常数 τ_p(φ)，有效年龄 a_eff(e,t)=(t−t_e^-)/τ_p。承诺 a 必须满足：a_eff≤1 且水位线覆盖接触事件区间；否则只能等待、按时间折扣加宽，或退到 L1 可撤回层。迟到证据若与已承诺决策矛盾，须在 τ_rev 内进入**事后回溯审计**，记录 J_n 修订并在安全相关时执行安全停/恢复。**事后健全性**：承诺后矛盾未被 τ_rev 内收容的概率 ≤δ_rev。

**定义 143（溯源图融合与有效独立性 PGF）** 溯源有向图 G_p：节点为原始传感流、标定版本、模型版本、标注者、融合算子，边表示"被用于"。证据 e_i,e_j **溯源不相交**当且仅当其源节点 d-分离且无共同祖先；否则共同祖先集 CC(e_i,e_j) 给出误差相关上界 ρ̄(CC)。有效独立证据数
n_eff = (Σ_i w_i)^2 / (Σ_i Σ_j ρ_ij w_i w_j)，ρ_ii=1，ρ_ij≤ρ̄(CC(e_i,e_j))。
EV-xmodal 的独立性判据升级为：溯源不相交 ∧ n_eff≥2 ∧ 无未缓解共因；仅模态标签不同但共享上游模型/标定/欺骗源时视为**一条证据**。共因预警：若新证据的 CC 非空且 ρ̄ 超阈，则强制降权并触发物理共因测试。

**定义 144（需求条件化承诺 NCC 与证书 J_n）** 动作 a 在检查点被接纳 ⇔ 六门全过：
(1) 物理门：FSE(a) 通过（第 57 轮，含 J_p）；
(2) 可辨识门：TRI 对 a 的需求相关 φ **决策充分可辨识**，或 a 仅为可撤回动作且已按 IdCert 加宽；
(3) 需求门：RCT(a) 通过，且不存在关键 open 需求被默认补齐；
(4) 时序门：TCF 满足 a_eff≤1 且水位线覆盖，或 a 降级为可撤回；
(5) 溯源门：PGF 判定证据有效独立（或已按共因降权后仍过门）；
(6) 同意门：第 57 轮同意阶梯 + 权衡同意 Π_tradeoff（若存在需求冲突）。
证书 J_n=(J_p, IdCert, RC/需求日志, TimeCert, ProvCert, excitation_log, ask_log, Π_tradeoff)，继承 J_p 全检。**保守出口顺序**（信息成本升序/动作风险降序）：可撤回激励 → 判别性提问 → 绕行 → 降档/降承诺级 → L2 协商 → 安全停；每检查点 k_exc+k_ask 有界。

## 2. 关键算法伪代码（完整版见产物区）

```python
def id_certificate(M, r, need, obs):                 # IP-139
    E = credible_set(obs, eps=EPS_ID)               # 观测等价类
    lo, hi = minmax_phi(E); null = nullspace_fisher(M, r, phi=need.phi)
    safe_exc = [e for e in excitations(r) if e.reversible and e.not_in_X_irr]
    return IdCert(S_id=hi-lo > DELTA_ID, S_null=null,
                  interval=(lo, hi), A_exc=safe_exc, exc_safe=bool(safe_exc))

def need_update(pN, h, need_model):                  # IP-140/141
    pN = need_model.calibrate(need_model.posterior(h))
    if surprise(h): pN = need_model.open_world(pN, h)     # 验收失败→开放维度
    q = argmax(admissible_questions(pN), key=voi_need)
    if voi_need(q) >= THETA_ASK and rate_ok(): return pN, ask(q)
    return pN, None

def causal_fuse(M, r, e, t):                         # IP-142
    if e.t_plus > watermark(t): return M, 'wait_or_widen'
    age = (t - e.t_minus) / tau_p(phi_of(r))
    w = rho(M, e) * exp(-max(0.0, age - 1.0))        # 过期即降权/加宽
    M.b[r][e.mod] = bayes_update(M.b[r][e.mod], e.like, w=w)
    return M, 'ok'

def provenance_gate(es, Gp):                         # IP-143
    neff = effective_independence(es, Gp)
    cc   = common_cause_set(es, Gp)
    return neff >= 2 and not unresolved_cc(cc), neff, cc

def need_conditioned_commit(cp, M, N, t):            # IP-144 / PCE+++
    a = argmax(feasible(cp), key=expected_need_utility)
    if not fse_ok(a, M):              return fallback(cp, 'physical')
    idc = id_certificate(M, cp.r, N, M.obs[cp.r])
    if not decision_sufficient(idc, N, a): return fallback(cp, 'ambiguity')
    if not rct_ok(a, N):              return fallback(cp, 'need')
    if not tcf_ok(a, M, t):           return fallback(cp, 'stale')
    ok, neff, cc = provenance_gate(evidence(a), M.Gp)
    if not ok:                        return fallback(cp, 'common_cause')
    if not consent_ok(a, N):          return fallback(cp, 'consent')
    return commit(a, Jn(M, idc, N, t, neff, cc))
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| TRI | O(d_θ³ + \|E\|·d_φ) | O(d_θ²) | 证书区间保守、零空间完整 |
| NLA | O(\|𝒩\|·d_N + Q·C_VOI) | O(\|𝒩\|+H_need) | 校准诚实、非操纵提问集 |
| RCT | O(\|D\|·\|C\|) | O(\|𝒯\|) | 追溯完整、冲突不被静默降权 |
| TCF | O(1)/证据；O(\|e\|)回溯 | O(\|e\|·d_b) | 水位线完整、τ_p 估计保守 |
| PGF | O(\|G_p\|+\|E\|²) | O(\|G_p\|+\|E\|²) | 溯源完备、共因相关上界有效 |
| NCC | O(\|CP\|·(k_p+k_c+k_e+k_a)·C) | O(\|V\|+\|σ\|) | 六门偏序、k_e+k_a 终止 |

**正确性定理（Identifiable-Need-Causal Soundness, INCS 概要）**：在 A33–A40 上加 **(A41)** 可辨识证书诚实（未声明可辨识时真值落在区间内，概率 ≥1−δ_id；不可逆承诺不使用仅局部证书）；**(A42)** 需求后验校准 ECE_N≤ε_N、覆盖审计诚实、提问集非操纵且预算有界；**(A43)** 时序模型诚实（时钟偏移界、τ_p 保守、水位线完备、回溯在 τ_rev 内）；**(A44)** 溯源图对共享来源完备、共因相关上界 ρ̄ 有效；**(A45)** 新机制只经"加宽信念/增加约束/删除证据/收紧动作参数"影响系统，主动激励与提问不得直接承诺。则：
(i) 承诺失效概率 ≤ δ_f+ε_meta(k)+δ_probe+ε_h+δ_ood·α_conf+δ_xm+δ_id+ε_N+δ_stale+δ_cc；
(ii) 交互单调性扩展：可辨识门只会缩窄可承诺集或触发保守出口；需求门只会增加约束；时序门只会删除不新鲜证据；溯源门只会合并证据（降低 n_eff），不存在"更懂就更大胆"的通道；
(iii) PCE+++ 在 k_probes+k_cons+k_exc+k_ask 内终止于 {承诺, 绕行, L2 协商, 安全停}。

## 4. 实验设计 E177–E181

| 实验 | 指标 | 目标 |

### IP-139 TRI（任务相关可辨识性与可辨识证书）

```python
def profile_credible_set(M, r, obs, eps_id):
    # 用剖面似然在有界网格上取保守可信集，避免局部线性化直接用于 L2
    best = max(profile_loglik(theta, obs, M) for theta in grid(r))
    return [theta for theta in grid(r)
            if profile_loglik(theta, obs, M) >= best - eps_id]

def fisher_null_directions(M, r, phi_theta, eps_I):
    I = sum(J(m).T @ inv(Sigma(m)) @ J(m) for m in M.modalities(r))
    vals, vecs = eigh(I)
    return [v for lam, v in zip(vals, vecs.T)
            if lam <= eps_I and norm(project(phi_theta, v)) > EPS_PHI]

def id_certificate(M, r, N, obs):
    E = profile_credible_set(M, r, obs, EPS_ID)
    lo, hi = interval_hull([N.phi(theta) for theta in E])
    null = fisher_null_directions(M, r, N.phi_grad, EPS_I)
    exc = [e for e in reversible_excitations(r, M)
           if e in admissible_actions(r) and not enters_X_irr(e)]
    return IdCert(S_id=(hi - lo), S_null=null, interval=(lo, hi),
                  A_exc=exc, exc_safe=bool(exc), E_sample=E)

def decision_sufficient(idc, N, a, delta_id):
    if idc.width > delta_id:                    return False   # 精度不足
    if any(abs(project(idc.phi_grad, v)) > EPS_PHI
           for v in idc.S_null):                return False   # 结构歧义
    # 决策充分：等价类内 δ-最优动作集一致
    opts = [delta_optimal_actions(theta, N, delta_id) for theta in idc.E_sample]
    return all(o == opts[0] for o in opts)

def active_excitation(cp, M, idc, budget):
    if not idc.exc_safe or budget.exc_left <= 0: return None
    cands = [e for e in idc.A_exc if info_gain_rank(e) > 0]
    if not cands: return None
    e = max(cands, key=lambda x: info_gain_rank(x) / cost(x))
    return e if info_gain_rank(e) >= THETA_EXC else None
```

```python
def rct_check(a, N, trace, consents):
    dims = trace.requirements(a)
    if not dims:                                   return ('reject', 'no_trace')
    crit = [d for d in dims if d.critical]
    if any(d.open and not d.verified for d in crit):
        return ('reject', 'open_critical_need')    # 不用默认值补齐关键需求
    if conflict_set(dims, a):
        if not consents.tradeoff_for(a): 
            return ('reject', 'need_conflict')
    if max(proxy_gap(d, a) for d in dims) > THETA_GAP:
        return ('reject', 'proxy_gap')
    if manipulative(a, N, trace):
        return ('reject', 'manipulation')          # 动作反过来塑造需求以扩权
    return ('ok', RC(dims, trace))

def manipulative(a, N, trace):
    # 非操纵条件：系统选择动作/提问的目标中不得含自身授权收益；
    # 且动作不得通过改变用户信息状态来使授权更易发生
    return trace.objective_contains('authority') \
        or causes_authority_gain_via(a, N)
```

### IP-142 TCF（时序因果融合与迟到证据回溯）

```python
def watermark(sensors, t):
    return min(s.latest_contiguous_event_time for s in sensors)

def causal_fuse(M, r, e, t, phi):
    W = watermark(M.sensors, t)
    if e.t_plus > W:
        return M, 'wait_or_widen'                  # 不用未过水位线的证据
    age = (t - e.t_minus) / tau_p(phi, r)
    w = rho(M, e) * exp(-max(0.0, age - 1.0))      # 过期按过程尺度降权
    M.b[r][e.mod] = bayes_update(M.b[r][e.mod], e.like, w=w)
    if age <= 1.0:
        M.fresh[r].add(e.id)
    return M, 'ok'

def tcf_gate(a, M, t, phi):
    es = evidence_for(a, M)
    if any(e.t_plus > watermark(M.sensors, t) for e in es):
        return False, 'not_causally_available'
    if max((t - e.t_minus) / tau_p(phi, a.region) for e in es) > 1.0:
        return False, 'stale_for_process'
    return True, 'ok'

def on_late_evidence(M, e, committed, t):
    if committed and contradicts(e, committed):
        audit.retro(committed.id, e, t)            # 记录 J_n 修订
        if safety_relevant(committed):
            safe_stop_or_recover(committed)        # 在 τ_rev 内收容
        M.ver.bump(committed.region)
```

### IP-143 PGF（溯源图融合与有效独立性）

```python
def build_provenance(log):
    G = DiGraph()
    for e in log:
        G.add_edge(e.raw_sensor, e)
        G.add_edge(e.calibration_version, e)
        if e.model_version: G.add_edge(e.model_version, e)
        if e.annotator:     G.add_edge(e.annotator, e)
    return G

def effective_independence(es, G, w):
    rho = {}
    for i, j in combinations(range(len(es)), 2):
        cc = ancestors(G, es[i].src) & ancestors(G, es[j].src)
        rho[i, j] = rho_bar(cc) if cc else 0.0     # 共享祖先 → 相关上界
    denom = sum(w[i] * w[j] * rho.get((i, j), 0.0)
                for i in range(len(es)) for j in range(len(es))
                if i != j) + sum(x * x for x in w)
    neff = (sum(w) ** 2) / max(denom, EPS)
    return neff, rho

def pfg_gate(es, G):
    neff, rho = effective_independence(es, G, [1.0] * len(es))
    cc = shared_causes(es, G)
    if neff < 2.0:                       return False, 'same_evidence_twice'
    if any(r > RHO_MAX for r in rho.values()):
        return False, 'unresolved_common_cause'
    return True, 'ok'

def xmodal_evidence_p(b_r, D, es, G, level):
    if level != 'L1' or D > THETA_D:     return None
    if not agreeing_pair(b_r):           return None
    ok, why = pfg_gate(es, G)            # 独立性由溯源审计，不由模态标签声明
    return 'EV-xmodal' if ok else None
```

### IP-144 NCC（需求条件化承诺 / PCE+++）

```python
def need_conditioned_commit(cp, M, N, t, budget):
    a = argmax(feasible(cp), key=lambda x: expected_need_utility(x, N))
    if not fse_ok(a, M):                          # 第 57 轮物理证据门
        return fallback(cp, M, N, 'physical')
    idc = id_certificate(M, cp.r, N, M.obs[cp.r])
    if not decision_sufficient(idc, N, a, delta_id):
        e = active_excitation(cp, M, idc, budget)  # 先试可撤回激励
        if e: return ('excite', e)
        return fallback(cp, M, N, 'ambiguity')
    if not rct_check(a, N, M.trace, M.consents)[0] == 'ok':
        q = select_need_question(N, budget)        # 再问判别性问题
        if q: return ('ask', q)
        return fallback(cp, M, N, 'need')
    if not tcf_gate(a, M, t, N.phi)[0]:
        return fallback(cp, M, N, 'stale')
    ok, why = pfg_gate(evidence_for(a, M), M.Gp)
    if not ok:
        return fallback(cp, M, N, why)
    if not consent_ok(a, N):                      # 第 57 轮同意阶梯 + 权衡同意
        return fallback(cp, M, N, 'consent')
    return ('commit', commit(a, Jn(M, idc, N, t, why)))

def fallback(cp, M, N, reason):
    # 统一保守出口：信息成本升序、动作风险降序；不制造新的升险通道
    if can_reroute(cp, M, N):   return ('reroute', reroute(cp, M, N))
    if can_degrade(cp, M):      return ('degrade', degrade(cp, M))
    if may_negotiate(cp, N):    return ('negotiate', negotiate(cp, N))
    return ('safe_stop', cp)

def pce_plus_plus_plus(x0, M, task, N, budget, consent):
    route = plan_on_map(M, task, N.phi)
    for cp in route.checkpoints:
        step = need_conditioned_commit(cp, M, N, now(), budget)
        if step[0] in ('excite', 'ask'):
            M = execute_information_action(step[1], M)  # 只获取信息，不承诺
            budget.spend(step[0]); continue
        if step[0] == 'commit':
            route.advance(cp); continue
        if step[0] == 'reroute':
            route = step[1]; continue
        if step[0] in ('degrade', 'negotiate'):
            return merge_round57_operator(cp, step, M, consent)
        return step                                   # safe_stop
    return route, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TRI | O(d_θ³+\|E\|·d_φ) | O(d_θ²+\|E\|) | 证书区间保守、零空间完整、L2 不用局部证书（A41） |
| NLA | O(\|𝒩\|·d_N+Q·C_VOI) | O(\|𝒩\|+H_need) | 校准 ECE_N≤ε_N、非操纵提问、预算有界（A42） |
| RCT | O(\|D\|·\|C\|) | O(\|𝒯\|) | 追溯完整、冲突不静默降权、非操纵（A42） |
| TCF | O(1)/证据；O(\|e\|)回溯 | O(\|e\|·d_b) | 水位线完备、τ_p 保守、回溯 τ_rev（A43） |
| PGF | O(\|G_p\|+\|E\|²) | O(\|G_p\|+\|E\|²) | 溯源完备、相关上界有效、共因不静默（A44） |
| NCC | O(\|CP\|·(k_p+k_c+k_e+k_a)·C) | O(\|V\|+\|σ\|) | 六门偏序、k_e+k_a 终止、保守出口（A45） |

**正确性定理（Identifiable-Need-Causal Soundness, INCS）**
假设 A22–A40 成立；**(A41)** 可辨识证书诚实：未声明可辨识时真值落在 [φ_lo,φ_hi] 内概率 ≥1−δ_id，零空间报告完整，不可逆承诺不使用仅局部证书；**(A42)** 需求后验校准 ECE_N≤ε_N，覆盖审计诚实，提问集 Q_nd 非操纵且 k_ask/r_ask 有界；**(A43)** 时钟偏移界、τ_p 保守估计、水位线完备，迟到证据在 τ_rev 内收容；**(A44)** 溯源图对共享来源完备，ρ̄ 为有效相关上界；**(A45)** 主动激励/提问只获取信息、不直接承诺，且激励 ∈G_adm 非破坏；所有新机制只经"加宽信念/增加约束/删除证据/收紧参数"影响承诺。则：

1. **承诺健全性（对检查点取联合界）**：
```
P(fail) ≤ δ_f + ε_meta(k) + δ_probe + ε_h(w_max)
          + δ_ood·α_conf + δ_xm + δ_id + ε_N + δ_stale + δ_cc
```
其中 δ_id 为可辨识证书假阳性界，ε_N 为需求后验校准误差，δ_stale 为时效性失效界，δ_cc 为共因漏检界。

2. **交互单调性扩展**：TRI 只能缩窄可承诺集或触发激励/保守出口；NLA/RCT 只能增加或暴露约束，不能用推断扩大授权；TCF 只能删除不新鲜证据；PGF 只能合并证据、降低 n_eff，不能把一条证据拆成两条。因此不存在"传感器更多/更懂用户 ⇒ 更大胆"的升险通道；唯一扩张通道仍是显式人工授权 e_grant。

3. **终止性**：每检查点主动激励 ≤k_exc、需求提问 ≤k_ask，物理探针与共识探针沿用第 57 轮上界，PCE+++ 在 k_probes+k_cons+k_exc+k_ask 内终止于 {承诺, 绕行, L2 协商, 安全停}。

4. **部署界**：
```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm
                   + δ_id + ε_N + δ_stale + δ_cc)
             − P(𝓜 陈旧未检出) − P(护盾回退失败) − P(证书审计失效)
```

关键：**可辨识性把"精度"与"可分"解耦**（低方差不再等于可承诺）；**需求证书把"做对"从"做得像"里拆出来**（满足规格不等于满足需求）；**时序水位线把"知道"与"当时知道"解耦**；**溯源 n_eff 把"多模态"与"多证据"解耦**。四个解耦全部只让系统更保守或更诚实，不提供任何升险捷径。

## 6. 本轮最大风险

**一句话**：本轮把"该做什么"的判定权交给一个从有限互动中反演的需求后验，风险从第 57 轮的"坏先验普遍"变成"**需求僭越**"——系统可以物理上完全健全、证据上完全可辨识，却高效而自信地满足一个它自己误读或编造的需求，而需求覆盖证书与可辨识证书会把这种自洽误读包装成"合规"；必须以开放世界标记、事后需求验证、非操纵性提问与保守默认四重护栏，宁可承认"我不知道你想要什么"并停下，也不用人造需求为不可逆动作背书。
