# 第 4 轮（灵感循环第 4 轮；本轮灵感：「小样本学习」×「专利布局」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架继续原样继承。
> 本轮纪律：**增量升级 + 严格退化 + 主张级可审计**。小样本能力是增强项、不是依赖项；专利布局是设计期约束、不是运行时依赖。

## 0. 直觉与动机

**灵感 1（小样本学习 → 稀有盲区的 k-shot 修复，而不是等够样本）**
直觉：InstructGauge 的 SC-Cal 把修复能力绑定在「每个指令 stratum 至少 n_min 个校准样本」上。但真实部署里最值钱的恰恰是**稀有盲区**——新出现的材质、没见过的几何、换了传感器批次。它们永远等不到 n_min 个同层样本。小样本学习的启示不是「省样本」这个口号，而是：不要从零估计每个新任务，而要**元学习一个「修复先验」**，让新盲区只需 k≪n_min 个回执即可条件化。真正困难的假设是**把可交换性从「样本级」抬到「任务级」**——只有任务级可交换，跨任务共享先验才合法；把不同类任务硬混在一起共享，就是负迁移的温床。

**灵感 2（专利布局 → 把创新组织成可防御的权利要求格，而不是一张功能清单）**
直觉：一个能跑的系统和一个「站得住」的发明是两回事。专利布局的思维方式是：把技术特征拆成**独立权利要求 + 从属权利要求**的偏序格，每条独立权利要求都要有清晰的**现有技术增量**与**设计绕道阻力**。这对研究设计是健康压力：它强迫我们回答「别人换个实现还能不能达到同样效果」「这个增益到底是结构性的还是实现偶然的」。因此本轮把专利布局从“事后写材料”前移为**设计期的可测约束**：每个核心模块必须映射到特征-权利要求，并用对抗式「替代实现」实验测量其绕道阻力。

**灵感 3（耦合 → 元先验是数据资产，权利要求必须同时覆盖过程与装置）**
直觉：小样本模块真正难被复制的是**情节任务语料库 + 任务一致性门 + 元训练过程**，而不是那个 adapter 网络本身；只写装置权利要求，会被「换个 backbone、重训一遍」绕开。反过来，专利布局要求的「可分解性」会迫使小样本模块与校准模块解耦，从而天然限制负迁移的传播半径。二者耦合出一个双赢但危险的结构：**过程权利要求保护数据资产，装置权利要求保护运行时闭环；而语料库一旦构造有偏，过程与装置会同时失效**——所以必须显式建模语料泄漏与支持集投毒。

## 1. 研究问题（本轮要回答什么）

- **Q1（k-shot 的安全覆盖）**：在只有 k≪n_min 个有效回执时，能否给出**任务级**可解释、可验证的覆盖保证，而不是把「小样本」当成就地免责？
- **Q2（负迁移的检测与弃权）**：元先验在真正的分布外盲区上会不会自信地犯错？如何用任务一致性门在**执行前**判 OOD 并一键退回全局校准？
- **Q3（可防御性可测吗）**：能否把「专利布局」形式化为特征-权利要求格 + 设计绕道阻力，并证明「主张覆盖率」不会超过「证据覆盖率」？

## 2. 四条设计原则（正式化见产物区定义 448–466）

**P1 任务级可交换 + 显式弃权（Task-level Exchangeability + Abstention）**
元训练/元测试按**任务**而非样本切分；k-shot 覆盖只在任务级可交换假设下成立，一旦任务一致性分数低于阈值就弃权并回退全局。直观：先验可以借，但借用的合法性必须被检验，不能默认。

**P2 过程-装置双层权利要求（Process + Apparatus Claims）**
每个核心创新同时产出「装置权利要求（模块/闭环）」与「过程权利要求（数据构造/训练/审计流程）」；过程权利要求保护数据资产，装置权利要求保护运行时闭环。二者由同一份 ClaimPortfolioCert 绑定证据。

**P3 设计绕道可测（Design-Around as Measurable）**
每条独立权利要求都要过一个「替代实现能否达成同一行为」的对抗测试；绕道成功率高于阈值 ⇒ 降级为从属权利要求或并回主权利要求。直观：不能被证伪的设计，不算独立创新。

**P4 主张 ≤ 证据（Claim ≤ Evidence）**
运行时对外声明的每一条能力主张必须绑定回执与块证书；组合审计只做文书降级，**绝不改写数值路径**。直观：专利叙事不能反向污染系统行为。

## 3. 与基线的接口（如何退化）

- 元任务数不足 / TCG 判 OOD / 支持集过小 ⇒ 回退 SC-Cal 分层共形（InstructGauge）⇒ 再回退 BP-Cal（ToolGauge）；
- 支持集投毒检测触发 ⇒ 丢弃 k-shot 估计，只保留 TCV 有效回执的保守后验；
- 权利要求映射失败 / DAR 不达标 ⇒ 只降级文书（从属/合并），**不改变运行时数值路径**；
- InstructGauge 失效 ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE 原样。
**不变量**：P 阶段（组合审计）是纯投影，剥离它不改变任何数值行为。

## 4. 预期贡献

1. 一个**任务级可交换**的小样本元修复器 + 任务一致性门，使稀有盲区在 k≈2–5 个回执内可修复，且 OOD 时零误用；
2. 一个**支持集鲁棒聚合**与**情节语料泄漏控制**协议，使小样本增益可归因、不可被投毒放大；
3. 一个**特征-权利要求格**与**设计绕道审计**，把「可防御性」变成可测量、可预注册的指标；
4. 一条可证伪路径：E457–E472 覆盖 k-shot 覆盖、负迁移、语料泄漏、投毒、权利要求覆盖与 50Hz 时序保全。

## 5. 本轮最大风险

**一句话**：元先验在**真正未见的盲区**上可能以很高置信度产生系统性错误修复（负迁移），而「专利布局」精心构造的可防御叙事会进一步**放大这种错误的可信度外观**——缓解只能依赖任务级切分、TCG 执行前弃权、支持集鲁棒聚合与 DAR 对抗审计，并用 E457/E458/E459/E461/E470 主动证伪。

## 2. 形式化定义（要点）

**定义 448（情节修复任务 τ）** `τ = (S_τ, Q_τ, d_τ, κ_τ)`，`S_τ` 为支持集，每个回执必须通过 TCV（定义 418）且签名有效；`Q_τ` 为目标盲区单元；`d_τ` 为任务描述符（材质类、几何类、传感器模态、光照域）；`κ_τ` 为指令层（定义 438）。记 `k = |S_τ|`。

**定义 449（元分布与任务级切分）** 元训练集 `D_meta^tr = {τ_m}~𝒯_tr`、元测试 `D_meta^te ~ 𝒯_te`。切分条件是**任务级不相交**：`∀τ∈D_meta^te, ∀τ'∈D_meta^tr: sig(τ) ≠ sig(τ')` 且描述符簇不重叠。这比样本级切分强：它避免“同一物理盲区不同帧”造成的乐观偏差。

**定义 450（任务编码器 ψ）** `ψ: (2^{Receipt} × D_desc) → ℝ^{d_τ}` 对 `S_τ` 置换不变（DeepSets/注意力池化），使得支持集顺序不改变嵌入。

**定义 451（FS-Box 元适配器）** 元参数 `θ`，内环 `θ_τ = θ − η∇_θ L_{S_τ}(θ)`，后验 `q_{θ_τ}(u_s)`。元目标
`min_θ E_{τ~𝒯}[ L_{Q_τ}(q_{θ_τ}) ] + β_KL·KL(q_θ‖p_phys)`
继承定义 420，但把「摊销单前向」扩展为「摊销先验 + k 步内环」。物理先验 `p_phys` 仍作正则，避免退化成纯统计拟合。

**定义 452（k-shot 任务级覆盖）** 非一致性分数 `E_τ = |u* − û_τ| / ŝ_τ`。在**任务级可交换**且任务内支持/查询可交换的假设下，Jackknife+/CV+ 型元共形给出
`P(u* ∈ C_τ) ≥ 1 − α − ε_k`, `ε_k = O(√(log(1/δ)/k))`。
该保证是**有条件的**：任务级可交换一旦被漂移破坏，覆盖退回 `1−α−2η`（η 为任务分布 TV 漂移）；因此覆盖与 TCG 必须同时报告，禁止只报点估计。

**定义 453（TCG 任务一致性门）** `ρ(τ) = −log p_θ(z_τ) − λ·disagree(S_τ, Q_τ)`，阈值 `ρ_*` 由元校准集上的共形分位给出。若 `ρ(τ) < ρ_*` ⇒ **弃权**，回退全局/分层校准。直观：先判“这个任务像不像我元训练过的任务族”，再决定借不借先验。

**定义 454（负迁移与安全选择）** `NT(τ) = R_few(τ) − R_glob(τ)`。选择规则：仅当 `ρ(τ) ≥ ρ_*` 且 `k ≥ k_min` 时启用 few-shot 输出，否则用全局输出。由「选择后风险控制」可得 `R_selected ≤ min(R_few, R_glob) + margin`（高概率），margin 由独立验证回执估计。

**定义 455（RSR 支持集鲁棒聚合）** 对支持残差做中位数-of-means：分块求均值再取中位数。若投毒比例 `< 1/2 − ε`，估计误差 `O(√(log(1/δ)/k) + ε)`，击穿点 `β_bd = 1/2`。任何未过 TCV/签名的回执在聚合前即被剔除。

**定义 456（情节语料与泄漏守卫）** `G_meta` 按因子 `(材质, 几何, 模态, 光照)` 生成任务，并记录 `sig(τ)`（因子哈希 + 物理参数区间）。守卫：`sig` 去重、任务级切分、查询不得进入元训练、生成参数写入 provenance 日志。**过程权利要求保护的就是这套可复现的语料构造流程**（定义 463）。

**定义 457（特征-权利要求格）** 技术特征 `F = {f_1…f_n}`（如“任务级切分”“内环 k-shot”“TCG 弃权”“中位数-of-means”“8C 的 P 阶段”）。权利要求 `c = (F_c, R_c, type)`，`F_c ⊆ F`，`R_c` 为特征间关系约束，`type ∈ {independent, dependent}`。`ℒ = (C_ind, C_dep, ≤)`。

**定义 458（独立/从属偏序）** `c' ≤ c` 当且仅当 `F_{c'} ⊇ F_c`（从属权利要求通过加特征而变窄）；独立权利要求两两不可比。独立性要求 `c` 不被任何 `c' < c` 蕴含。

**定义 459（现有技术增量 δ_pa）** `δ_pa(c) = min_{p∈PA} dist(F_c, F_p)`。`δ_pa(c) > δ_min` 且未被 `p` 完全预期（anticipation）才计入新颖性。`dist` 用特征集合的加权 Jaccard/关系编辑距离，权重可预注册。

**定义 460（设计绕道阻力 DA）** `DA(c) = max_{a∈Alt(c)} success(a ⊨ ⟦c⟧ ∧ F_a ∩ F_c = ∅)`：替代实现 `a` 在不使用 `c` 的特征时仍达成 `c` 语义的成功率。要求 `DA(c) ≤ ν`。`Alt(c)` 是**有限枚举**的替代实现集合，因此 DA 只在枚举范围内有效（引理 65 明确此局限）。

**定义 461（主张覆盖 vs 证据覆盖）** 对行为集 `B`，`cov_claim(B) = |{b : ∃ c∈C_ind, b∈⟦c⟧}| / |B|`；`cov_evid(B)` 为能绑定有效回执+块证书的行为比例。目标定理：`cov_claim(B) ≤ cov_evid(B)`。

**定义 462（权利要求-证据绑定 CEB）** 每条权利要求 `c` 绑定 `(receipt_ids, chunk_cert_ids, meta_task_provenance)`；无法绑定的主张在序列化时剥离（纯投影，沿用定义 441/423）。

**定义 463（ClaimPortfolioCert）** `ClaimPortfolioCert = (ℒ, {δ_pa(c)}, {DA(c)}, evidence_index, process_claims, sigs)`，使审计者可沿「权利要求→特征→模块→实验→回执」五级证据链复现。

**定义 464（8C 闭环）** `I → H → C → E(chunk) → C(calibrate) → V → U → P`。P 阶段：组合审计（DA/δ_pa/覆盖率）与主张绑定。P 全异步、纯投影。

**定义 465（组合审计门 P-gate 与降级规则）** 若 `DA(c) > ν` 或 `δ_pa(c) ≤ δ_min` 或 `cov_claim > cov_evid` ⇒ 将 `c` 降级为 dependent 或并入父权利要求；**不修改任何运行时参数**。

**定义 466（运行时主张守卫 ClaimGuard）** 系统只允许对外声明 `ClaimPortfolioCert.ℒ` 中已入册、且当次运行有证据绑定的主张；出现未覆盖行为 ⇒ 标记 `UNCOVERED` 并触发重新审计，而不是自动生成新主张。

## 3. 关键算法骨架

# IP-328 FS-Box：情节元训练 + 内环 k-shot 适配
class FSBox:
    def meta_train(self, corpus, steps):
        for _ in range(steps):
            taus = sample_tasks(corpus, meta_batch)     # 任务级采样，非样本级
            loss = 0.0
            for tau in taus:
                z = psi(tau.S, tau.d)                    # 置换不变
                theta_tau = self.inner_adapt(theta, tau.S)  # k 步内环
                loss += self.query_loss(theta_tau, z, tau.Q)
                loss += BETA_KL * kl(self.q(theta), self.p_phys)
            theta = adam_step(theta, grad(loss))
        return theta

    def inner_adapt(self, theta, support):
        theta_t = theta
        for _ in range(self.inner_steps):
            theta_t = theta_t - ETA * grad(support_loss(theta_t, support))
        return theta_t

# IP-329 TCG：执行前一致性门
class TCG:
    def score(self, tau):
        z = psi(tau.S, tau.d)
        return -log_prob(self.meta_prior, z) - LAM * disagree(tau.S, tau.Q)

    def accept(self, tau, rho_star):
        return self.score(tau) >= rho_star          # 否则弃权 → 全局校准

# IP-331 RSR：中位数-of-means 支持聚合（抗投毒）
def robust_aggregate(support, k_chunks=5):
    support = [r for r in support if tcv_valid(r) and verify_sig(r)]
    if len(support) < K_MIN: return None            # 退化
    chunks = split(support, k_chunks)
    means = [mean_residual(ch) for ch in chunks if ch]
    return median(means)                             # 击穿点 1/2

# IP-330 MetaCorpus：因子化生成 + 泄漏守卫
class MetaCorpus:
    def build(self, factors, n_tasks):
        tasks, seen = [], set()
        for _ in range(n_tasks):
            tau = self.generate(sample_factors(factors))
            if sig(tau) in seen: continue            # 任务签名去重
            seen.add(sig(tau)); tasks.append(tau)
        return task_level_split(tasks)               # 𝒯_tr / 𝒯_te 任务级不相交

# IP-332 CPC：特征 → 权利要求格
class CPC:
    def build(self, modules, prior_art):
        features = extract_features(modules)          # F
        ind = [claim_of(m) for m in modules if m.core]  # 独立权利要求
        dep = [d for d in derive_dependents(ind)]        # 从属权利要求
        for c in ind + dep:
            c.delta_pa = min(dist(c.F, p.F) for p in prior_art)
        return ClaimLattice(ind, dep, order_by_inclusion)

# IP-333 DAR：设计绕道审计
class DAR:
    def audit(self, claim, alt_impls):
        hits = [a for a in alt_impls
                if reaches_semantics(a, claim) and a.F.isdisjoint(claim.F)]
        return max((self.success_rate(a) for a in hits), default=0.0)

# IP-334 8C 闭环（P 阶段纯投影）
def claimgauge_8c(M, s, ell):
    ok = instructgauge_7c(M, s, ell)                 # 前 7C 完全不变
    if not ok: return False
    tau = M.metacorpus.task_for(s)
    if M.tcg.accept(tau, M.rho_star) and len(tau.S) >= K_MIN:
        support = M.rsr.robust_aggregate(tau.S)      # 抗投毒
        if support is None: return instructgauge_fallback(M, s)
        mu, Sig = M.fsbox.adapt_and_calibrate(support, tau.Q)
        if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):
            return instructgauge_fallback(M, s)       # 负迁移兜底
        M.apcal.replace_last(mu, Sig)
    cert = M.cpc.build(M.modules, M.prior_art)
    for c in cert.claims:
        if not M.dar.audit(c, M.alt_impls) <= NU:
            cert.demote(c)                            # 仅降级文书
    bind_claim_evidence(cert, M.receipts, tau)        # CEB
    M.claimguard.register(cert)                       # 运行时只声明入册主张
    return True

# IP-335 主闭环（50Hz 路径不变）
def ClaimGauge_round(M, obs, audio, tac, depth, det, ell=None):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s)
            submit_async(claimgauge_8c, M, s, ell)
    return InstructGauge_round(M, obs, audio, tac, depth, det, ell)

## 4. 推导

**引理 59（任务级元共形覆盖）** 设任务 `τ ~ 𝒯` 可交换，非一致性分数任务内有界且满足 CV+ 条件，则 `P(u* ∈ C_τ) ≥ 1 − α − ε_k`，`ε_k = O(√(log(1/δ)/k))`；若任务分布漂移 `TV(𝒯_te, 𝒯_tr) = η`，则降级为 `≥ 1 − α − 2η − ε_k`。
*证明骨架*：在任务内用留一/Jackknife+ 构造 k 个校准残差，标准 CV+ 给出 `1−2α` 型有限样本界；对任务级再套一层可交换性，漂移项由 Pinsker 不等式把 TV 转成 KL 计入。

**引理 60（负迁移安全选择）** 若 TCG 的门限 `ρ_*` 由元校准集共形给出，且选择规则为「过门用 few-shot，否则用全局」，则以概率 `≥1−δ`：`R_selected ≤ min(R_few, R_glob) + O(√(log(1/δ)/N_val))`；特别地，弃权分支**恰好等于**全局校准风险（无额外损失）。
*证明骨架*：把选择视为在两个候选预测器上的带弃权选择；在独立验证集上做一致收敛，弃权分支退化为固定全局预测器，其风险由 InstructGauge 引理 55 保证。

**引理 61（k-shot 样本复杂度的先验加速）** 若元先验精度为 `σ_meta⁻²`、单回执噪声方差 `σ_obs²`，后验 `σ_post² = (σ_meta⁻² + k·σ_obs⁻²)⁻¹`，则达到目标精度 `ε` 只需
`k ≥ σ_obs²(ε⁻² − σ_meta⁻²)`。
对比定义 426 的 `n ≥ σ_obs²(ε⁻² − σ_0⁻²)`：元先验把冷启动方差 `σ_0²` 替换为更小的 `σ_meta²`，这正是 k≪n_min 的定量来源；若 `σ_meta² ≥ ε²` 则不等式无解，必须弃权——与 TCG 语义一致。

**引理 62（支持集投毒鲁棒性）** 若有效回执比例 `> 1/2 + ε`，RSR 的中位数-of-means 估计满足 `‖μ̂ − μ‖ ≤ O(√(log(1/δ)/k) + ε)`；击穿点 `β_bd = 1/2`。
*证明骨架*：分块均值在 `> 1/2` 诚实块下，中位数落在诚实均值区间内；块内亚高斯集中给出偏差项。

**引理 63（语料泄漏与乐观偏差界）** 在任务级不相交切分与签名去重下，元测试超额风险的乐观偏差 `≤ O(1/√M) + O(overlap(𝒯_tr, 𝒯_te))`；若 `overlap = 0`，则偏差只随元任务数 `M` 衰减。
*证明骨架*：对任务做经验过程一致收敛；签名去重消去样本级相关，剩余项由描述符簇重叠度量控制。

**引理 64（主张覆盖 ≤ 证据覆盖）** 若 `ClaimGuard` 只放行已入册且当次有证据绑定的主张，且 `CEB` 为纯投影，则对任意行为集 `B`：`cov_claim(B) ≤ cov_evid(B)`。
*证明骨架*：反证。若存在 `b` 被主张覆盖却无证据，则 `b` 对应的主张必然缺 `(receipt, chunk_cert)` 绑定，会在 CEB 序列化时被剥离，与“已入册可声明”矛盾。投影不改变数值路径，故此不等式是关于**声明**而非**行为**的，恰好是专利叙事不越界的保证。

**引理 65（DAR 的可证伪性与开放世界局限）** DAR 给出的 `DA(c) ≤ ν` 只对枚举集合 `Alt(c)` 成立；存在未枚举替代实现时，真实绕道阻力可能更高。故 `DA` 是**下界性质的上界估计**，其可信度随 `|Alt|` 与替代实现的覆盖度单调上升；本方案**不声称**开放世界下的绝对可防御性。
*证明骨架*：有限枚举上的 max 只覆盖被枚举者；对未枚举者取补集即得反例，说明该界不可推广为全称命题。这是主动写进判据的局限。

**引理 66（8C 等价性与实时保全）** P 阶段全异步、纯投影，且热替换仍只发生在 `q_quiesce`（定义 439）；故未涉及子图的逐指令等价性回到引理 57 → 49 → 44，主循环新增周期 `< 0.2ms`，继承引理 50/58 的硬实时结论。
*证明骨架*：P 的输入是已完成的 `(receipts, H, C)`，输出只写 `ClaimPortfolioCert`，不写 `(μ, Σ, EC)`；投影可交换地作用于声明层。

## 8. 本轮最大风险
