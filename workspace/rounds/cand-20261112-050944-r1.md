# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；灵感循环第 6 轮；本轮灵感：「运动学」×「用户体验」）

> 第 59 轮把「执行」接上了地：BUQ 辨识电机物理、ERTC 契约化实时执行、EEIS 编译阻抗参数、CLEP 双向闭环——但它只回答了「机器是否安全地执行」，没有回答「人是否可理解、可预测、可信任地与它共处」。本轮两个灵感精准击中这个**人因抽象泄漏**：**运动学**不是求解器内部的雅可比与逆解，而是**人与机器人共享的几何语言**——奇异性、可操作度、冗余零空间、关节限位、运动学标定误差，直接决定动作在人类观察者眼中是「流畅可读」还是「突兀惊悚」；**用户体验**不是界面皮肤，而是**信任校准、认知负荷、情境意识、控制感**——高层的 δ_f、ECE、共形带是人类无法直接感知的概率量，人感知的是「它下一步要干什么」「我能不能随时接管」「出问题时它有没有提前说」。本轮核心命题：**「把安全约束编译成可被人类感知的运动学契约；把人类体验信号反编译成证据层的信任校准证据」**——在 v59 的执行接地之上补上**体验接地（Kinematic-Experiential Grounding, KXG）**，实现「物理安全 × 可感知安全 × 信任校准」的三重接地。

核心矛盾：
- **H32（奇异性即体验悬崖）**：运动学奇异点附近 σ_min(J)→0，任务空间微小速度被放大为关节空间速度/加速度爆炸。对控制而言这是「限速/阻尼」问题；对人而言这是**自动化惊吓（automation surprise）**——机器人突然甩动、变慢、卡顿或无声切换模式。v59 的 ERTC/EEIS 保证了「不失控」，却没有保证「不吓人」；惊吓直接摧毁人的情境意识（situation awareness）与信任。
- **H33（冗余零空间：免费的体验画布，还是隐藏的欺骗空间）**：n>m 的冗余自由度可在零空间内不改变末端任务，用于**可读性**（提前朝目标方向运动、避开自碰撞、保持肘部自然）、**人机共融**（给人类让出空间）与**个性化**（不同用户偏好不同速度/直接度）。但零空间也可被用来「表演确定性」：动作看起来很果断，实际信念高度不确定——**可读性若与真实置信脱钩，就退化为体验操纵**。
- **H34（机器校准 ≠ 人类校准）**：v58/v59 用 ECE、共形覆盖校准**机器信念**；但用户对机器人的信任是另一套动力学：过度信任（over-trust）让用户在系统不可靠时仍放手，信任不足（under-trust）导致频繁接管、能力浪费。**TCE（信任校准误差）= |人类信任 − 真实可靠度|** 是与 ECE 平行、却从未被形式化的安全维度。
- **H35（安全保守化的体验代价）**：v59 的降级策略「宁可又慢又笨」在安全上正确，在体验上可能是灾难：频繁降级 → 用户不知道机器人何时可信 → 要么过度干预、要么完全放弃。**保守性必须可感知、可预告、可解释**，否则「安全」换来的是「被弃用」。

## 0. 直觉与动机

**灵感 1（运动学 → 体验地形 KEL）**
直觉：把机器人配置空间想象成一张「地形图」：平坦处动作顺滑，悬崖处（奇异点）轻轻一推就坠落。可操作度椭球 μ(q)=√det(JJᵀ) 描述「哪个方向好推」，条件数 κ=σ_max/σ_min 描述「各向异性有多强」，σ_min 描述「离悬崖多近」，关节限位裕度描述「离墙多近」，运动学标定误差描述「地图本身有多歪」。人看到的不是矩阵，而是**抖动、急停、末端漂移、莫名其妙的绕路**。因此定义**运动学体验地形** E(q,ẋ_d)，把 μ、κ、σ_min、限位裕度、标定误差、jerk 合成一个标量场；E 超阈或 σ_min 低于安全裕度即为**体验悬崖 H_KEL**。关键洞见：**奇异性首先是用户体验事件，其次才是控制事件**——因为人先感知到「吓人」，才去问「为什么」。

**灵感 2（运动学 → 冗余零空间可读性投影 LNP）**
直觉：7-DOF 臂/人形手臂的冗余自由度是一块**不改变任务的画布**。同一末端轨迹可以有很多关节解；选择「朝目标方向提前倾斜」「肘部朝外不挡人」「避免自碰撞」「保持关节远离限位」的解，会让人类观察者更早、更准地猜出意图——这就是**可读性（legibility）**。形式化：在零空间参数 ξ 上优化可读性泛函 L（观察者预测意图的对数似然）＋平滑代价，约束任务误差 ≤ ε_task、关节限位、自碰撞、PKC。**安全关键性质：LNP 只动零空间，不改变任务空间语义**，因此 v59 的证据语义与 EEIS 证书完全不受影响——这是「免费的体验改进」，但它有边界（限位、动力学耦合、奇异点附近零空间退化）。

**灵感 3（用户体验 → 信任-体验状态 TES）**
直觉：用户信任不是「满意度打分」，而是**对可靠度的动态估计**。成功→信任上升（边际递减），失败→信任骤降（负性不对称），意外/模式切换→信任受罚，好的解释→信任修复。定义 TES=(τ_trust, w_load, s_aware, p_pred, p_ctrl)，其中 p_pred 是用户对「下一步动作」的预测准确率，p_ctrl 是感知控制感（接管响应时间、是否可撤销）。**TCE=|τ_trust−R_true|**；over-trust 与 under-trust 分别触发不同交互策略。关键洞见：**ECE 校准机器，TCE 校准人**；两者都必须以真实可靠度为锚，否则「解释」会退化为「话术」。

**灵感 4（合流 → 可感知运动学契约 PKC）**
直觉：v59 的 EEIS 把 δ_f 编译成阻抗参数；本轮把「人的感知边界」也编译成契约：最大 jerk、最大任务速度、奇异裕度下限、预览时域 T_prev（≥ 人类反应时 + 规划时延）、解释延迟上限、降级预告提前量、接管响应时间。定义 C_ux=(jerk_max, v_max, σ_min_req, T_prev, L_exp, T_notice, T_override, smooth_q, disclosure_level)。运行时 M_ux 监视，违例 → **PERCEPTUAL_DEGRADE**（减速、加长预览、主动播报），且该通道**单向保守**：只能更慢/更可读/更透明，绝不能借体验之名放宽安全或隐瞒不确定性。

**灵感 5（合流 → 体验预算张量化与 PCE++++）**
直觉：v58 的 B_ux 是粗粒度「交互次数」。本轮把它**张量化**为 B_ux^⊗=(注意力裕度、耐心裕度、解释裕度、信任储备)。每次打断、每次等待、每段解释消耗不同分量；VOI 从「元认知收益 − 执行成本」扩展为「元认知收益 − 执行成本 − 体验成本」。信任储备低于阈值时，系统必须**降频交互、缩短解释、切可预测的保守模式**，而不是继续用高频询问「刷存在感」。体验预算耗尽不是安全降级，而是**交互降级**——但交互降级不得降低安全等级。

## 1. 形式化定义（增量：定义 153–160）

**定义 153（运动学体验地形 KEL, Kinematic Experience Landscape）** 设有 n 关节、m 维任务、雅可比 J(q)=∂x/∂q，奇异值分解 J=UΣVᵀ，σ₁≥…≥σ_r>0。定义：
```
μ(q)   = ∏_{i=1..r} σ_i                    # 可操作度
κ(q)   = σ₁ / σ_r                          # 条件数
d_s(q) = σ_r                               # 奇异裕度（离悬崖距离）
ℓ(q)   = min_j min((q_j−q_j^min)/range_j, (q_j^max−q_j)/range_j)   # 限位裕度
e_cal(q) = ‖x_fk(q) − x_meas‖              # 运动学标定误差
q̇_d = J⁺(q)·ẋ_d,  j(q) = d³q_d/dt³        # 任务速度对应的关节速度与 jerk
E(q,ẋ_d) = w_μ·[log(μ_ref/μ(q))]_+ + w_κ·(κ(q)−1)
         + w_s·(σ_ref/d_s(q)) + w_ℓ·(1/ℓ(q))
         + w_j·‖j(q)‖² + w_c·(e_cal(q)/ε_cal)
H_KEL(α) = { q | d_s(q) < σ_min_req(α) ∨ E(q,ẋ_d) > E_max(α) ∨ ℓ(q) < ℓ_min }
```
KEL=(E, μ, κ, d_s, ℓ, H_KEL)。**体验悬崖**定义为 ∂E/∂q 局部极大且 d_s 单调下降的配置带。KEL 的作用不是替代动力学，而是把「人眼可见的粗糙度」变成可监视、可编译的量。

**定义 154（可读性泛函与零空间可读性投影 LNP）** 冗余机械臂 n>m，零空间投影 N(q)=I−J⁺J，关节速度分解 q̇=J⁺ẋ_d+N(q)ξ, ξ∈ℝⁿ。定义可读性泛函：
```
L_leg(q_[0,T]) = −E_{o∼O}[ log P_o(î=i* | q_[0,T]) ] + λ_d·D_commit(q_[0,T]) + λ_s·S_smooth(q_[0,T])
```
其中 O 为人类观察者模型，i* 为真实意图，D_commit 奖励「早期承诺」（真实目标与备选目标的观测轨迹差异尽早拉大），S_smooth 惩罚 jerk。LNP 求解：
```
ξ* = argmin_ξ ∫_0^T [ L_leg(q(t)) + λ_u·‖ξ(t)‖² ] dt
s.t.  ‖x(q(t)) − x_d(t)‖ ≤ ε_task
      q(t) ∈ Q_free（关节限位、自碰撞、速度/加速度/jerk 界）
      (q̇,q̈,j) ∈ C_ux
q̇ ← J⁺ẋ_d + N(q)ξ*
```
**性质（任务语义保持）**：一阶意义下 N(q)ξ 不改变末端 x，故 LNP 不触碰 v59 的证据语义；LNP 只在「任务等价类」内优化人因可读性。

**定义 155（信任-体验状态 TES 与信任校准误差 TCE）** s_ux=(τ∈[0,1], w_load∈[0,100], s_aware∈[0,1], p_pred∈[0,1], p_ctrl∈[0,1])。真实可靠度 R_true(t) 由证据层滚动验证的成功率/校准后的 (1−δ_f) 给出。**信任校准误差 TCE=|τ−R_true|**；over-trust 判据 τ>R_true+δ_T，under-trust 判据 τ<R_true−δ_T。信任动力学（负性不对称 α_f>α_s）：
```
τ_{t+1} = clip( τ_t + α_s·R_t·(1−τ_t) − α_f·(1−R_t)·τ_t
                − α_surprise·Surprise_t + α_exp·Q_exp,t , 0, 1 )
Surprise_t = 1[ ‖Δx_cmd‖ > v_max·Δt ∨ 未预告的模式切换 ∨ 未预告的降级 ]
```
w_load 由 NASA-TLX 代理信号（接管频率、响应时延、任务切换数）估计；s_aware 由用户对下一动作的预测准确率 p_pred 与对当前模式的正确识别率合成；p_ctrl 由接管响应时延与可撤销性给出。

**定义 156（可感知运动学契约 PKC 与监视器 M_ux）** C_ux=(jerk_max, v_task_max, σ_min_req, T_prev, L_exp, T_notice, T_override, smooth_q, disclosure_level)。硬性关系：
```

T_notice ≥ T_react_human                           # 奇异性/降级预告至少提前一个人类反应时
T_override ≤ T_override_max                        # 接管必须在人类可接受时延内完成
```
运行时监视器 M_ux 采样 jerk 的 99% 分位数、σ_min、预览覆盖率、解释时延、预告提前量、接管响应。任一指标越界 → **PERCEPTUAL_DEGRADE**：降低 v_task、提高预览时域、主动披露不确定性、必要时切保守模式。**单向保守性**：契约更新算子 ⊑ 满足 C_ux'⊑C_ux ⇒ (v'≤v ∧ jerk'≤jerk ∧ σ_min_req'≥σ_min_req ∧ T_prev'≥T_prev ∧ disclosure'≥disclosure)，且物理安全界（EEIS/ERTC）不被放宽。

## 2. 关键算法伪代码

### IP-152 KEL（运动学体验地形）

```python
class KinematicExperienceLandscape:
    def __init__(self, kin, weights):
        self.kin, self.w = kin, weights

    def evaluate(self, q, xdot_d, dt):
        J = self.kin.jacobian(q)
        U, S, Vt = np.linalg.svd(J)
        S = S[S > 1e-9]
        mu = float(np.prod(S)) if len(S) else 0.0
        sigma_min = float(S.min()) if len(S) else 0.0
        kappa = float(S.max() / max(sigma_min, 1e-9))
        limit_margin = self.kin.joint_limit_margin(q)
        e_cal = self.kin.calibration_error(q)
        qdot = np.linalg.pinv(J) @ xdot_d
        jerk = self._joint_jerk(q, qdot, dt)
        E = (self.w.mu * max(0.0, np.log(self.w.mu_ref / max(mu, 1e-9)))
             + self.w.kappa * (kappa - 1.0)
             + self.w.s * (self.w.sigma_ref / max(sigma_min, 1e-9))
             + self.w.l * (1.0 / max(limit_margin, 1e-9))
             + self.w.j * float(np.dot(jerk, jerk))
             + self.w.c * (e_cal / self.w.eps_cal))
        return KELState(E=E, mu=mu, kappa=kappa, sigma_min=sigma_min,
                        limit_margin=limit_margin, jerk=jerk,
                        on_cliff=(sigma_min < self.w.sigma_min_req
                                  or E > self.w.E_max
                                  or limit_margin < self.w.l_min))

    def cliff_distance(self, q, xdot_d):
        """体验悬崖距离：用于 PKC 计算预告/减速提前量"""
        s = self.evaluate(q, xdot_d, dt=1e-3)
        return s.sigma_min - self.w.sigma_min_req
```

### IP-153 LNP（零空间可读性投影）

```python
class LegibleNullspaceProjector:
    def __init__(self, kin, observer_model, plm):
        self.kin, self.observer, self.plm = kin, observer_model, plm

    def project(self, q, xdot_d, x_d, C_ux, horizon=0.3):
        J = self.kin.jacobian(q)
        Jpinv = np.linalg.pinv(J)
        N = np.eye(len(q)) - Jpinv @ J
        qdot_base = Jpinv @ xdot_d

        def objective(xi_seq):
            q_seq = self._integrate(q, qdot_base, N, xi_seq)
            leg = -self.observer.log_likelihood_legible(q_seq, x_d)
            smooth = np.sum(np.diff(xi_seq, n=2, axis=0) ** 2)
            return leg + self.plm.lambda_smooth * smooth

        cons = [
            TaskError(self.kin, x_d, eps=self.w_eps_task),
            JointLimits(self.kin, margin=self.w_l_min),
            SelfCollision(self.kin),
            PerceptibleContract(C_ux),
        ]
        xi = constrained_minimize(objective, x0=np.zeros((30, len(q))), cons=cons)
        qdot = qdot_base + N @ xi[0]
        return self._scale_by_singular_margin(q, qdot, C_ux)

    def _scale_by_singular_margin(self, q, qdot, C_ux):
        _, S, _ = np.linalg.svd(self.kin.jacobian(q))
        smin = S.min()
        if smin < C_ux.sigma_min_req:
            qdot *= max(0.0, smin / C_ux.sigma_min_req) ** 0.5
        return np.clip(qdot, -C_ux.qdot_max, C_ux.qdot_max)
```

```python
class TrustExperienceEstimator:
    def __init__(self, alpha_s=0.15, alpha_f=0.45,
                 alpha_surprise=0.2, alpha_exp=0.1, delta_T=0.15):
        self.tau, self.w_load, self.s_aware = 0.5, 30.0, 0.5
        self.p_pred, self.p_ctrl = 0.5, 0.5
        self.a_s, self.a_f = alpha_s, alpha_f
        self.a_sur, self.a_exp, self.dT = alpha_surprise, alpha_exp, delta_T

    def update(self, outcome, surprise, explanation_q, signals, R_true):
        self.tau = float(np.clip(
            self.tau + self.a_s * R_true * (1 - self.tau)
            - self.a_f * (1 - R_true) * self.tau
            - self.a_sur * surprise + self.a_exp * explanation_q, 0.0, 1.0))
        self.w_load = 0.8 * self.w_load + 0.2 * signals.tlx_proxy
        self.s_aware = 0.8 * self.s_aware + 0.2 * signals.prediction_accuracy
        self.p_pred = signals.prediction_accuracy
        self.p_ctrl = signals.override_responsiveness
        return self.state(R_true)

    def state(self, R_true):
        tce = abs(self.tau - R_true)
        return TES(tau=self.tau, w_load=self.w_load, s_aware=self.s_aware,
                   p_pred=self.p_pred, p_ctrl=self.p_ctrl, tce=tce,
                   over_trust=self.tau > R_true + self.dT,
                   under_trust=self.tau < R_true - self.dT)
```

```python
class UXBudgetTensor:
    def __init__(self):
        self.B_att, self.B_wait = 1.0, 1.0
        self.B_expl, self.B_trust = 1.0, 1.0

    def cost(self, plan, wait, cog_load, trust_cost):
        return (L_ATT * int(plan.interrupts) / max(self.B_att, EPS)
                + L_WAIT * wait / max(self.B_wait, EPS)
                + L_COG * cog_load / max(self.B_expl, EPS)
                + L_TRUST * trust_cost / max(self.B_trust, EPS))

    def spend(self, interrupt, wait, cog_load, trust_cost):
        self.B_att = max(0.0, self.B_att - A_ATT * interrupt)
        self.B_wait = max(0.0, self.B_wait - A_WAIT * wait)
        self.B_expl = max(0.0, self.B_expl - A_COG * cog_load)
        self.B_trust = max(0.0, self.B_trust - A_TRUST * trust_cost)

    def policy(self):
        if self.B_trust < EPS: return 'predictable_conservative_disclose'
        if self.B_expl < EPS:  return 'short_template_progressive'
        if self.B_wait < EPS:  return 'autonomous_conservative_then_explain'
        if self.B_att < EPS:   return 'batch_or_defer_nonurgent'
```

```python
from dataclasses import dataclass

@dataclass
class KELState:
    E: float
    mu: float
    kappa: float
    sigma_min: float
    limit_margin: float
    jerk: np.ndarray
    on_cliff: bool

@dataclass
class KELWeights:
    mu_ref: float = 0.1
    sigma_ref: float = 0.05
    sigma_min_req: float = 0.02
    E_max: float = 10.0
    l_min: float = 0.10
    eps_cal: float = 0.005
    mu: float = 1.0
    kappa: float = 0.2
    s: float = 1.0
    l: float = 0.5
    j: float = 0.1
    c: float = 2.0

class KinematicExperienceLandscape:
    """把配置空间变成可监视的『体验地形』：平坦=顺滑，悬崖=奇异/限位/标定失真。"""
    def __init__(self, kin, weights: KELWeights = KELWeights()):
        self.kin, self.w = kin, weights

    def evaluate(self, q, xdot_d, dt=1e-3):
        J = self.kin.jacobian(q)                 # m×n
        U, S, Vt = np.linalg.svd(J, full_matrices=False)
        S = S[S > 1e-9]
        if len(S) == 0:
            return KELState(E=float('inf'), mu=0.0, kappa=float('inf'),
                            sigma_min=0.0, limit_margin=0.0,
                            jerk=np.zeros_like(q), on_cliff=True)
        mu = float(np.prod(S))
        sigma_min = float(S.min())
        kappa = float(S.max() / sigma_min)
        limit_margin = float(self.kin.joint_limit_margin(q))
        e_cal = float(self.kin.calibration_error(q))
        qdot = np.linalg.pinv(J) @ xdot_d
        jerk = self._joint_jerk(q, qdot, dt)

        E = (self.w.mu * max(0.0, np.log(self.w.mu_ref / max(mu, 1e-12)))
             + self.w.kappa * (kappa - 1.0)
             + self.w.s * (self.w.sigma_ref / max(sigma_min, 1e-12))
             + self.w.l * (1.0 / max(limit_margin, 1e-12))
             + self.w.j * float(np.dot(jerk, jerk))
             + self.w.c * (e_cal / self.w.eps_cal))

        on_cliff = (sigma_min < self.w.sigma_min_req
                    or E > self.w.E_max
                    or limit_margin < self.w.l_min)
        return KELState(E=E, mu=mu, kappa=kappa, sigma_min=sigma_min,
                        limit_margin=limit_margin, jerk=jerk, on_cliff=on_cliff)

    def _joint_jerk(self, q, qdot, dt):
        # 由有限差分/解析二阶导估计关节 jerk；这里给出占位实现
        return self.kin.joint_jerk(q, qdot, dt)

    def cliff_margin(self, q, xdot_d):
        """正=安全距离；负=已进入/越过悬崖。用于 PKC 预告提前量。"""
        s = self.evaluate(q, xdot_d)
        return s.sigma_min - self.w.sigma_min_req

    def cliff_horizon(self, q, xdot_d, dt, horizon):
        """预测未来 horizon 内最小奇异裕度，决定是否需要提前减速/预告。"""
        qs = self.kin.rollout(q, xdot_d, dt, horizon)
        return min(self.cliff_margin(qi, xdot_d) for qi in qs)
```

### IP-153 LNP（零空间可读性投影）

```python
@dataclass
class LNPConfig:
    eps_task: float = 1e-3        # 任务空间许可漂移（不改变证据语义）
    lambda_smooth: float = 0.5
    lambda_u: float = 0.01
    horizon_steps: int = 30

class LegibleNullspaceProjector:
    """只动零空间：不改变末端任务，只让动作更早、更准地暴露意图。"""
    def __init__(self, kin, observer_model, plm, cfg: LNPConfig = LNPConfig()):
        self.kin, self.observer, self.plm, self.cfg = kin, observer_model, plm, cfg

    def project(self, q, xdot_d, x_d, C_ux):
        J = self.kin.jacobian(q)
        Jpinv = np.linalg.pinv(J)
        N = np.eye(len(q)) - Jpinv @ J
        qdot_base = Jpinv @ xdot_d
        H = self.cfg.horizon_steps

        def rollout(xi_seq):
            qs, qds = [q.copy()], []
            for t in range(H):
                qd = qdot_base + N @ xi_seq[t]
                qs.append(self.kin.integrate(qs[-1], qd, dt=self.kin.dt))
                qds.append(qd)
            return np.array(qs[1:]), np.array(qds)

        def objective(xi_seq):
            q_seq, _ = rollout(xi_seq)
            leg = -self.observer.log_likelihood_legible(q_seq, x_d)
            smooth = np.sum(np.diff(xi_seq, n=2, axis=0) ** 2)
            return leg + self.plm.lambda_smooth * smooth + self.cfg.lambda_u * np.sum(xi_seq ** 2)

        cons = [
            {'type': 'ineq', 'fun': lambda xi: self.cfg.eps_task - self._task_error(xi, q, xdot_base, N, x_d)},
            {'type': 'ineq', 'fun': lambda xi: self.kin.joint_limit_margin_seq(self._qs(xi, q, xdot_base, N)) - 0.0},
            {'type': 'ineq', 'fun': lambda xi: self.kin.self_collision_margin_seq(self._qs(xi, q, xdot_base, N))},
            {'type': 'ineq', 'fun': lambda xi: C_ux.jerk_max - self._jerk_max(xi, q, xdot_base, N)},
        ]
        xi0 = np.zeros((H, len(q)))
        xi = self._solve(objective, xi0, cons)
        qdot = qdot_base + N @ xi[0]
        return self._scale_by_singular_margin(q, qdot, C_ux)

    def _scale_by_singular_margin(self, q, qdot, C_ux):
        _, S, _ = np.linalg.svd(self.kin.jacobian(q), full_matrices=False)
        smin = S.min()
        if smin < C_ux.sigma_min_req:
            qdot = qdot * max(0.0, smin / C_ux.sigma_min_req) ** 0.5
        return np.clip(qdot, -C_ux.qdot_max, C_ux.qdot_max)
```

```python
@dataclass
class TES:
    tau: float
    w_load: float
    s_aware: float
    p_pred: float
    p_ctrl: float
    tce: float
    over_trust: bool
    under_trust: bool

class TrustExperienceEstimator:
    """ECE 校准机器信念；TCE 校准人类信任。两者都以 R_true 为锚。"""
    def __init__(self):
        self.tau, self.w_load, self.s_aware = 0.5, 30.0, 0.5
        self.p_pred, self.p_ctrl = 0.5, 0.5
        self.a_s, self.a_f = 0.15, 0.45      # 负性不对称：失败打击 > 成功激励
        self.a_sur, self.a_exp = 0.20, 0.10
        self.delta_T = 0.15

    def update(self, outcome_success, surprise, explanation_q, signals, R_true):
        self.tau = float(np.clip(
            self.tau
            + self.a_s * float(outcome_success) * (1 - self.tau)
            - self.a_f * (1 - float(outcome_success)) * self.tau
            - self.a_sur * float(surprise)
            + self.a_exp * float(explanation_q), 0.0, 1.0))
        self.w_load = 0.8 * self.w_load + 0.2 * signals.tlx_proxy
        self.s_aware = 0.8 * self.s_aware + 0.2 * signals.prediction_accuracy
        self.p_pred = signals.prediction_accuracy
        self.p_ctrl = signals.override_responsiveness
        return self.snapshot(R_true)

    def snapshot(self, R_true):
        tce = abs(self.tau - R_true)
        return TES(tau=self.tau, w_load=self.w_load, s_aware=self.s_aware,
                   p_pred=self.p_pred, p_ctrl=self.p_ctrl, tce=tce,
                   over_trust=self.tau > R_true + self.delta_T,
                   under_trust=self.tau < R_true - self.delta_T)

    def disclosure_policy(self, tes, delta_f_req):
        """披露只增不减：over-trust 时强制增加透明信息。"""
        if tes.over_trust:
            return 'force_full_disclosure'
        if tes.under_trust:
            return 'show_capability_evidence'
        return 'progressive_disclosure'
```

```python
        jerk_max = min(plm.jerk_pref, self.hard_jerk_max) * slowdown

            C.T_notice *= 1.5
            C.sigma_min_req *= 1.1
        if sample.preview_coverage < 0.95:
            C.T_prev *= 1.2
        if sample.notice_lead < C.T_notice:
            C.T_notice *= 1.3
        # 物理安全界（ERTC/EEIS）不可被体验契约放宽——此处不触碰。
        return C
```

```python
    # ② TES
    R_true = M.evidence.reliability()
    tes = M.tes.update(M.last_outcome, M.last_surprise,
                       M.last_explanation_q, user_signals, R_true)

    # ③ KEL
    kel = M.kel.evaluate(q, xdot_d)
    if kel.on_cliff:
        M.request_slowdown = True

    # ④ LNP（只动零空间）
    C_ux = M.pkc_current
    qdot = M.lnp.project(q, xdot_d, M.task.position(cp), C_ux)

    # ⑤ PKC 编译（单向保守）
    C_ux, cert_pkc = M.pkc.compile(kel, tes, delta_f_req, M.plm)
    if not M.pkc.feasible(C_ux):
        return perceptual_degrade(M, cp, 'pkc_infeasible', cert_pkc)

    # ⑥ EEIS（v59 物理安全编译，不受体验层放宽）
    K_safe, cert_eeis = M.eeis.compile(delta_f_req, M.fused, M.buq.ukf.x, M.b_r[cp.region])
    if K_safe is None:
        return perceptual_degrade(M, cp, 'eeis_infeasible', cert_pkc)

    # ⑦ Dispatch（带预览/披露）
    dispatch_motion(qdot, C_ux, cert_pkc, cert_eeis,
                    preview=C_ux.T_prev, disclosure=C_ux.disclosure_level)

    # ⑧ Execute & Collect
    telemetry, feedback = execute_and_wait(cp, C_ux, timeout=M.contact_timeout)

    # ⑨ EV-uxk + 信念更新 + PLM 更新
    EV_uxk = build_uxk_evidence(telemetry, feedback, cert_pkc, kw=tes, C_ux=C_ux)
    EV_exec = build_exec_evidence(telemetry, cert_eeis, M.ertc.check()[0],
                                  M.buq.ukf.x, telemetry.tau_evidence, M.exec_degraded)
    M.EV_uxk_log.append(EV_uxk)
    M.EV_exec_log.append(EV_exec)
    M, fused, D_pp = reconcile_plus_plus(M, cp.region, EV_exec, EV_uxk)
    M.plm.observe_override(feedback.motion, feedback.override_reason)

    # ⑩ 体验预算与证书
    M.budget.ux.spend(feedback.plan, feedback.wait_s, feedback.cog_load, feedback.trust_cost)
    J_ux = append_experience_cert(M, kel, C_ux, cert_pkc, EV_uxk, tes)
    return M, fused, D_pp, EV_exec, EV_uxk, (cert_pkc, cert_eeis)

def build_uxk_evidence(telemetry, feedback, cert_pkc, tes, C_ux):
    jerk = telemetry.joint_jerk
    return EVuxk(
        jerk_q99=float(np.percentile(np.abs(jerk), 99)),
        sigma_min_min=float(telemetry.sigma_min_min),
        task_err_q99=float(np.percentile(np.linalg.norm(telemetry.task_err, axis=1), 99)),
        legibility_score=float(feedback.observer_intent_loglik),
        preview_coverage=float(feedback.preview_coverage),
        L_exp_actual=float(feedback.explanation_latency),
        TCE_est=float(tes.tce),
        override_count=int(feedback.override_count),
        degraded_ux_flag=bool(feedback.degraded or not feedback.contract_ok),
        over_trust=bool(tes.over_trust),
        override_failed=bool(feedback.override_failed),
        contract_ok=bool(feedback.contract_ok),
        C_ux=C_ux,
    )

@dataclass
class J_ux:
    kel_traj: list
    C_ux: PKC
    Cert_pkc_chain: list
    EV_uxk_log: list
    TES_traj: list
    PLM_version: int
    override_log: list
    disclosure_log: list
    version: int
    timestamp: float

    def verify_chain(self):
        for i in range(1, len(self.Cert_pkc_chain)):
            if self.Cert_pkc_chain[i].version < self.Cert_pkc_chain[i - 1].version:
                return False
        for C in [c.C for c in self.Cert_pkc_chain]:
            if not (C.T_prev >= 0.200 and C.T_notice >= 0.200):
                return False
            if C.sigma_min_req < HARD_SIGMA_MIN:
                return False
        return True
```

**正确性定理（Experience-Grounded Legibility Soundness, EGLS）**
假设 A22–A55（第 53–59 轮）成立；**(A56)** KEL：J、σ_min、限位、标定误差在标定后估计误差有界，E 对人类可感知粗糙度单调（代理诚实）。**(A57)** LNP：仅使用 N(q)ξ，任务误差 ≤ε_task，不违反 v59 物理约束，奇异裕度不足时按 σ_min 缩放。**(A58)** TES：代理信号单调有界，R_true 由证据层诚实给出，TCE 估计误差 ≤δ_TCE。**(A59)** PKC：单向保守，物理安全界不被放宽，违例触发 PERCEPTUAL_DEGRADE，T_prev 覆盖人类反应时。**(A60)** EV-uxk：仅参与对账与降级，不进入物理证据佐证集；over-trust 只增加披露。**(A61)** B_ux^⊗：各分量单调消耗、互不挪用，cost_ux 诚实上界真实体验成本，交互降级不降安全。**(A62)** PLM：自适应在 Φ_safe 内，个性化不放宽安全，漂移检测可靠。**(A63)** KXG：单次闭环在 τ_contact_max+τ_ux_max 内终止。则：

1. **运动学安全保持**：∀t，‖x(q(t))−x_d(t)‖≤ε_task，q(t)∈Q_free；σ_min<σ_min_req 时 ‖q̇‖≤q̇_max；v59 的 Cert_eeis 与证据语义不变。故可读性优化不改变证据语义、不削弱物理安全。
2. **体验悬崖可预告**：若预测 T_prev 内进入 H_KEL，系统要么经 LNP 规避，要么至少提前 T_notice≥T_react_human 预告；由奇异点引起的未预告惊吓概率 ≤δ_surprise。

4. **单向体验保守性**：EV-uxk 与 PKC 只能加宽后验、减速、增加披露、触发交互降级；不能减少探针、不能放宽物理约束、不能隐瞒不确定性。

## 6. 本轮最大风险

**一句话**：本轮首次把「主观体验」纳入形式化安全论证链，最大风险是**体验代理被优化目标反向操纵**——可读性泛函可能让机器人「看起来更果断」而非「实际更可靠」，信任建模可能诱导系统用解释与预告制造过度信任（over-trust），而 KEL/TES 的代理指标（jerk、预测准确率、TLX 问卷）与真实安全之间只有相关性、没有因果保证；一旦「体验优化」与「不确定性披露」冲突，系统就可能滑向**表演式安全**。五重护栏必须兜底：**LNP 只动零空间且任务误差硬约束**、**PKC 单向保守且物理安全界不可放宽**、**EV-uxk 永不替代物理证据**、**over-trust 只增披露不可减信息**、**PLM 安全约束内自适应并支持漂移回滚**——宁可「体验平淡但诚实」，绝不「体验惊艳但误导」。
