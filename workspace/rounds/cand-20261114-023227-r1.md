# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「惯性测量单元」×「安全性」）

> R69 把不确定性一分为二（aleatoric 收紧、epistemic 去问），并让「看/问/触」成为可认证、可审计的信息动作。它的安全论证建立在一个从未被质疑的前提上：**安全是可预测的**。C-RAS-WM 用学到的世界模型认证未来前缀；FMA 用策略自身的似然做「第二意见」。但这两条通道都活在模型内部——世界模型可能错，而策略似然更是**自指**的（它用策略定义的「正常」去检验策略）。当模型自信地错时，「安全认证」和「第二意见」会一起自信地错。
>
> 本轮两个灵感正好从外部钉进来：
> - **惯性测量单元（IMU）** 是高频率（~1kHz）、本体感受、受物理定律约束的通道。它测的不是「我预测身体会怎样」，而是「身体**实际**怎样」：加速度、角速度、角加速度、冲击。它位于执行之后、伤害之前，是天然的**安全见证者（witness）**，且独立于视觉、地图、LLM 和策略似然。
> - **安全性** 不只是「预测无伤害」，而是「**见证无伤害 + 事后可归因**」。一个安全证书若不能在被认证事件发生时仍然存活、且在事件后仍能被独立复核，它就只是承诺，不是收据。
>
> 核心命题：**在 R69 的「预测安全」之外，加一层「惯性见证安全」：用 IMU 的实测运动直接检验物理安全包络，并把「动态/执行模型失配」确立为第三条不确定性通道 U_dyn（既非 aleatoric 噪声、也非 epistemic 歧义，问不出来、只能靠独立物理见证）；只有当惯性见证有效时，R69 的 resolution bonus（消歧后放宽 λ）才被允许花出去；见证缺失/陈旧/完整性受损/接近包络时，单调退回 R69 的保守策略，绝不更激进。** 命名 **AEGIS-RAS**（Acceleration-Envelope Governed Inertial Safety：以实测加速度包络为盾的风险自适应闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我的身体真的照做了吗？此刻它安全吗？**」——预测是承诺，惯性是收据。

## 0. 直觉与动机

**灵感 1（IMU → 安全需要「收据」，而不只是「承诺」）**
直觉：R68/R69 的安全是**预测式**的——它们回答「按模型推演，未来 H 步内会不会出事」。但安全最终是关于**身体实际经历了什么**：一次碰撞、一次打滑、一次关节超速、一次失去平衡。IMU 恰好直接测量这些量，而且它在因果链上位于「执行器动作」之后、「不可逆伤害」之前。把 IMU 当作安全见证者，等于把安全论证从「我相信模型」改成「我测到了身体仍在安全包络内」。更关键的是，IMU 不依赖策略似然，因此不会和策略一起被同一个幻觉说服——这是对 R69 自指性的正面修补。

**灵感 2（偏置与漂移 → 见证者自己也会错，而且会被它所见证的事件破坏）**
直觉：IMU 有偏置、尺度因子、轴间失准、重力对齐误差、温度漂移；更糟的是，**一次硬冲击会改变偏置**——事故本身会污染那个用来判定事故是否安全的传感器。于是「安全性」在本轮还包含一个新问题：**见证的完整性（attestation integrity）**。这不是追问「是绕左还是绕右」能解决的 epistemic，也不是多测几次能平均掉的 aleatoric，而是「此刻这把尺子还能不能信」。它只能靠物理冗余与不变量（重力一致性、静止检测、双 IMU 校验、冲击锁定）来回答。

**灵感 3（第三通道 → R69 的「第二意见」其实还不够独立）**
直觉：R69 的 Δa（动作在策略密度下的似然）确实不会被外感受标定吸收，但它仍由策略定义「什么叫正常」。若策略在偏置观测上自信地生成一个「它觉得很正常」的动作，Δa 可能不升。IMU 残差 r_imu = 实测运动 − 本体/执行器模型预测，检查的是**牛顿-欧拉意义上的自洽**，没有学到的先验。于是形成三通道：r_res 测「传感器自洽」，Δa 测「行为自洽」，r_imu 测「物理自洽」。一个纯信息层面的故障若没有真正改变身体运动，就无法骗过 r_imu；而一旦它真的改变了身体运动，它就已经是物理安全事件，必须被见证。

**灵感 4（高频率 → 时间完整性也是安全性）**
直觉：真实事故常常不是「算错了」，而是「算晚了」：感知丢帧、策略排队、流采样/LLM 解码超时、执行器延迟。R69 为了消歧会多采样 K 次、回放 Hutchinson 似然、再调冻结 LLM 生成问句，这些都要时间。IMU 是 1kHz 心跳，可以给出**新鲜度与时间预算**：从当前状态到安全包络边界还剩多少时间（time-to-harm），感知-策略-执行总延迟必须小于它的一部分。超了就转「纯惯性安全停」，不拿时间去赌信息。

**灵感 5（见证必要但不充分 → 新的威胁模型）**
直觉：IMU 只看动力学，不看语义。**以极平稳的方式驶下悬崖，在惯性意义上是「安全」的**；慢慢把手伸进危险区，jerk 也可能很小。更恶意地，MEMS IMU 可被声学/共振注入欺骗，冲击可改写偏置，历史也可被重放。因此 AEGIS 必须显式承认：惯性见证是**必要的物理底线**，不是语义安全的充分条件；必须与 R69 的语义安全融合，并新增 ℰ_impact、ℰ_spoof、ℰ_gentle（动力学温柔但语义危险）三类干扰。

**灵感 6（严格姿态 → 常态恒等 + 危险区硬下限）**
直觉：AEGIS 不该破坏 R69 已经赢得的效率。做法是让惯性下限**在常态下不激活**：当实测运动离包络边界有足够裕度时，λ_AEGIS 逐指令等于 λ_R69；只有当裕度收缩、见证失效或接近包络时，才抬高 λ 或触发安全停。于是 AEGIS 是 R69 的「常态恒等 + 危险区安全支配」封装：安全侧永不弱于 R69，常态效率不受损；禁用见证时整体退化为 R69。这与本系列一贯姿态一致——新层必须包含旧层，安全侧不做任何让步。

## 1. 形式化定义（增量：定义 310–323）

**定义 310（AEGIS-RAS 总览）** AEGIS-RAS = (IWM, ISA, ADC, ATI, TIB, TCO, RAS-WM§)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i：只更新图/状态与证书，不更新网络权重）；
(ii) **见证独立**：见证路径只允许使用原始 IMU、刚体/执行器运动学模型与独立标定，**不得使用策略似然或学到的世界模型**作为其判据来源；
(iii) **安全单调**：见证缺失、陈旧、完整性降级或越界时，λ_AEGIS ≥ λ_R69，只收紧不放松；任何「放宽」只能来自 R69 已经给出的 resolution bonus，且须经见证门控；
(iv) **先归因后追溯**：任何对历史证书的撤销/收紧都必须带归因证据，且单调有界，禁止静默改写过去。

**定义 311（惯性安全包络 ISE）** 实测本体运动 `y_t = (a_t, ω_t, α_t, j_t)`（比力/加速度、角速度、角加速度、jerk），经抗混叠低通后使用。安全集
`S = { |a| ≤ a_max(m_payload), |ω| ≤ ω_max, |α| ≤ α_max, |j| ≤ j_max, ∫|a|dt ≤ J_max }`，
阈值来自伤害/失稳模型（人体损伤阈值或机械结构/倾覆阈值），离线认证并**版本化**。归一化裕度
`h(y) = min{ (a_max−|a|)/a_max, (ω_max−|ω|)/ω_max, (α_max−|α|)/α_max, (j_max−|j|)/j_max }`。
见证 `w_t = 1` 当且仅当 `h(y_{t−T:t}) ≥ m > 0` 且按实测 jerk 外推一步仍有 `h ≥ 0`。

**定义 312（惯性见证残差 IWR）** 本体/执行器预测器 `B(a_cmd, x) → ŷ`，残差 `r_imu = y_meas − ŷ`。按结构可观测性分解为四个正交子空间：执行器故障 `P_act`、外部扰动/碰撞 `P_dist`、打滑/接触丢失 `P_slip`、传感器故障/偏置跳变 `P_sensor`；`r_imu = Σ_P P r_imu`，各分量给归因似然（定义 318）。

**定义 313（三通道不确定性）** 不确定性不再是二分而是三分：
`U_ale`（模态内噪声，不可约 → R68/69 的 λ_floor）；
`U_epi`（模态间歧义，可约 → R69 的主动交互）；
`U_dyn = E[‖r_imu‖ | 归因后验]`（模型/执行失配，**既问不出也平均不掉** → 惯性见证与退避）。
三者语义不同，不做标量加和；只有 `U_ale` 与未消解 `U_epi` 进入 R69 的 λ，`U_dyn` 进入见证/安全停通道。直觉：噪声是「抖动」，歧义是「不知道选哪个」，失配是「身体没照做」。

**定义 314（安全见证证书 SAC）** `J_AEGIS = (J_FLUID, w_attest, h_min, TTH, integrity_state, attribution_posterior, latency_slack, imu_cal_hash, aegis_ver)`。
`Valid ⇔ Valid(J_FLUID) ∧ witness_fresh ∧ integrity_state = ok ∧ latency_slack ≥ 0 ∧ h_min ≥ 0`。证书显式记录「本次安全是由预测还是由见证支撑」，审计不得把二者混同。

**定义 315（resolution bonus 的见证门控 RBG）** 设 R69 输出为 `λ_R69`（消解成功时仅用 `λ_floor(U_ale)`，失败时用 `λ_floor(U_ale+U_epi)`）。AEGIS 取
```
λ_AEGIS = λ_R69                                  若 w=1 且 h_min ≥ m+δ（常态）
         = max(λ_R69, λ_floor(U_ale+U_epi))       若 w=0 或完整性降级（撤销 bonus）
         = max(λ_R69, λ_ISE(h_min))               若 m ≤ h_min < m+δ（接近包络，渐紧）
         = 1（安全停）                             若 h_min < m 或见证无效且 TTH 不足
```
其中 `λ_ISE(h)` 随 `h↓m` 单调升向 1。要点：**bonus 只能在「身体已被见证仍在安全区」时花**。

**定义 316（见证完整性 ATI）** `integrity_state ∈ {ok, degraded, invalid}`，由四项联合判定：(a) 静止/重力一致性（静止时 |a|≈g 且 ω≈0）；(b) 冗余 IMU / 异构惯性（陀螺与加计的物理一致性）奇偶校验；(c) 温度-偏置模型外推残差；(d) **冲击锁定**：当 `∫|a|dt > J_lock` 时冻结偏置估计并置 `degraded`，直到静止复核或独立参考确认。任一 invalid ⇒ `w=0`。

**定义 317（时间完整性预算 TIB）** `TTH(x)` 为在当前状态以最大允许制动/姿态恢复能力到达包络边界的剩余时间。总延迟 `L = L_perc + L_policy + L_flow + L_LLM + L_act`。要求 `L ≤ ρ·TTH`（ρ<1）。IMU 心跳提供 `L_perc` 与时间戳单调性；若超预算，跳过 R69 的 K 采样/似然回放/LLM 问句，转纯惯性安全停（定义 321）。

**定义 318（归因与追溯信任 ADC）** 当 `‖r_imu‖ > τ_imu`，在原因集 `C = {policy, actuator, disturbance, sensor}` 上求后验 `p(C | r_imu, context)`。处置：`policy`/`actuator` ⇒ 在视界 `H_r` 内**追溯撤销**近期 resolution bonus 并提高 λ；`disturbance` ⇒ 临时提高 λ、记录事件；`sensor` ⇒ 置见证 invalid，退回 R69 保守并按定义 316 处理。撤销次数有界、方向单调（只收紧不放松），保证控制连续。

**定义 319（三通道反吸收 TCO）** 联合统计量 `z = (r_res, Δa, r_imu)`。判别命题：若一个故障被 COF 标定吸收（`r_res≈0`）且不引起行为异常（`Δa` 小），则它要么没有真正改变身体运动（此时物理上无害），要么必然产生 `‖r_imu‖ ≥ c‖δ_actual‖ − ν`（A99：执行器/刚体模型 Lipschitz）。因此**纯信息层面的隐形故障无法同时做到「有害且不可见」**；剩下能藏住的是「动力学温柔但语义危险」的 ℰ_gentle，必须交给 R69 语义层，不能由 IMU 单独裁定。

**定义 320（信息动作的惯性门控 IAG）** R69 的信息动作 g 先过 C-RAS-WM 认证；AEGIS 额外要求 g 执行期间 `h(y) ≥ m_g` 且 `TTH ≥ L_g`。若交互进行中裕度跌破门限，立即中止 g，`U_epi` 视为未消解，退回 R69 保守。安全性含义：**一个会牺牲平衡的问句，不值得问**。

**定义 321（惯性最小风险条件 MRC）** 当见证 invalid 或 `h_min < m` 且 TTH 不足时，进入惯性安全停：在本体/包络约束内以受限 jerk 减速、维持姿态、冻结任务动作与信息动作，只保留见证与日志。退出必须由独立的完整性复核（静止重力一致性/冗余校验/温度模型）触发，不能由策略自己宣布恢复。

**定义 322（标定与证书版本化）** IMU 标定（偏置、尺度、失准、重力方向）以哈希版本化；`aegis_ver` 绑定策略版本、包络阈值版本、标定哈希与见证算法版本。任一版本不匹配即证书失效。冲击锁定期间禁止热更新标定。

**定义 323（威胁模型 ℰ_AEGIS）** `ℰ_AEGIS = ℰ_FLUID × ℰ_impact × ℰ_spoof × ℰ_gentle`：ℰ_impact 为冲击诱发的偏置/尺度跳变；ℰ_spoof 为声学/共振注入、重放、MEMS 欺骗；ℰ_gentle 为动力学平滑但语义危险（缓入危险区、温柔碰撞、慢速失稳）。并入 AIC；明确记录「IMU 对 ℰ_gentle 不可观测」。

## 2. 关键算法骨架

```python
# IP-264 IWM：惯性见证监视器（1kHz，只读原始 IMU，不碰策略）
class InertialWitnessMonitor:
    def __init__(self, envelope, margin=m, buf=deque(maxlen=W)):
        self.env, self.m, self.buf = envelope, margin, buf
    def update(self, imu_sample, dt):
        y = anti_alias(imu_sample)                     # (a, ω, α, j)
        self.buf.append(y)
        h = self.env.normalized_margin(y)              # 定义 311
        return h, (h >= self.m and self.env.one_step_ok(y, dt))

# IP-265 ISA + IP-267 ATI：见证与完整性（独立于策略/世界模型）
def attest(imon, imu, cal, redundant, temp):
    h, ok = imon.update(imu, dt)
    integrity = check_gravity(imu, cal) and parity(redundant) \
                and temp_bias_ok(imu, temp, cal) and not impact_locked(imu)
    w = int(ok and h >= MARGIN and integrity)
    return Attestation(w=w, h_min=h, integrity=integrity, t=imu.t)

# IP-266 ADC：本体模型残差 → 归因 → 追溯信任
def inertia_residual(a_cmd, x, y_meas, B):
    r = y_meas - B(a_cmd, x)                           # 定义 312
    proj = {k: P[k] @ r for k in ("act", "dist", "slip", "sensor")}
    post = attribution_posterior(proj, context=x)      # 定义 318
    return r, proj, post

# IP-268 TIB：时间完整性预算
def temporal_budget(x, latency):
    tth = min_time_to_envelope(x, env)                 # 定义 317
    return (latency.total <= RHO * tth), tth

# IP-269 TCO：三通道反吸收（R69 的 r_res/Δa + 本轮 r_imu）
def triple_check(r_res, delta_a, r_imu, tau):
    z = (r_res, delta_a, norm(r_imu))
    # 标定吸收但要害故障必须落进“物理异常”象限
    return classify_quadrant(z, tau)                   # 定义 319

# IP-273 AEGIS 主闭环：R69 之上只加“见证门控 + 单调退避”
def AEGIS_RAS_round(M, obs, imu):
    # 0) 先做见证与时间预算，必要时根本不进入 R69 的重计算
    att = attest(M.iwm, imu, M.cal, M.redundant, M.temp)
    time_ok, tth = temporal_budget(M.x, M.latency)
    if not time_ok or not att.w:
        return M.mrc.safe_stop(M.x, att)               # 定义 321，跳过 K 采样/LLM

    # 1) 正常执行 R69（其内部仍做 aleatoric/epistemic 二分与交互）
    k69, lam69, mode, (U_ale, U_epi) = M.fluid.round(obs)
    r, proj, post = inertia_residual(M.last_cmd, M.x, imu.y, M.B)
    r_res, delta_a = M.last_r_res, M.last_delta_a
    quad = triple_check(r_res, delta_a, r, M.tau)

    # 2) 归因：身体没照做/被撞/传感器坏 → 追溯撤销 bonus
    if norm(r) > M.tau_imu:
        cause = argmax(post)
        if cause in ("policy", "actuator"):
            M.trust.retro_revoke(H_r=M.H_r)            # 定义 318，单调
        elif cause == "sensor":
            att = att._replace(w=0, integrity="invalid")

    # 3) 见证门控：常态恒等，危险区硬下限，越界安全停
    lam = lam69
    if not att.w:
        lam = max(lam69, M.lam_floor(U_ale + U_epi))   # 撤销 resolution bonus
    elif att.h_min < M.m + M.delta:
        lam = max(lam69, M.lam_ise(att.h_min))
    if att.h_min < M.m:
        return M.mrc.safe_stop(M.x, att)

    # 4) 信息动作若正在执行，裕度一掉就中止
    if M.info_action_active and not M.iag.allow(att, M.info_action):
        M.abort_info_action()                          # U_epi 视为未消解

    # 5) 执行 + 证书 + 审计（记录“本次安全由见证支撑”）
    k = M.c_ras_wm.certified_prefix(M.ach.propose(M.x, M.vista.H), ..., M.wm_preds)
    tail = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqauditor_a.submit_async(att, r, post, quad, lam, lam69)
    return k, lam, mode, (U_ale, U_epi, U_dyn=norm(r))
```

## 3. 推导

**引理 19（见证式安全的模型无关性）** 设包络阈值经离线认证、传感器噪声满足 `|y_meas − y_true| ≤ ν`，且 `h(y_meas) ≥ m` 时真实运动仍有 `h(y_true) ≥ 0`（取 `m ≥ ν` 的归一化裕度）。则「见证有效 ⇒ 真实伤害代理量 ≤ ε_safe」的结论**不依赖策略/世界模型是否正确**，只依赖物理测量与阈值认证。要点：这是 R68/R69 安全论证的结构性补强——安全性第一次有了不经过学习模型的证据链。

**引理 20（三通道反吸收）** 沿用 R69 引理 17 的设定。设故障引起的真实本体运动偏差为 `δ_actual`，执行器/刚体模型满足 A99（Lipschitz 常数 `L_B`、噪声 `ν`）。则 `‖r_imu‖ ≥ L_B‖δ_actual‖ − ν`。因此：(a) 若 `δ_actual≈0`（纯信息故障、身体没变），r_imu 不可见，但此时物理伤害代理量也为 0；(b) 若故障真能致害，则必产生可被 r_imu 见证的动力学偏差，除非它落在「动力学温柔」的 ℰ_gentle 子空间。故 `(r_res, Δa, r_imu)` 三通道把「隐形且有害」压缩到 ℰ_gentle，而 ℰ_gentle 必须由 R69 语义层负责——**IMU 不声称能看见语义**。

**引理 21（时间完整性）** 若 `L ≤ ρ·TTH`（ρ<1）、包络制动能力满足 jerk/加速度上限，且感知时间戳单调，则在见证到越界倾向后，系统可在 `TTH` 内进入定义 321 的安全停；越界概率 ≤ `ε_noise + ε_ts`。系：R69 的 K 采样与 LLM 问句必须服从同一时间预算，否则「为了更确定而花掉安全余量」得不偿失。

**定理 18（AEGIS 对 R69 的常态恒等与安全支配）** 在 A99 与包络认证下：
(i) **常态恒等**：当 `w=1` 且 `h_min ≥ m+δ` 时，`λ_AEGIS = λ_R69`，动作、信息动作与证书的语义分支逐指令相同；
(ii) **安全支配**：任意状态下 `P_AEGIS(包络越界) ≤ P_R69(包络越界)`，且 `λ_AEGIS ≥ λ_R69`；
(iii) **退化边界**：禁用见证（`w≡1` 视作无约束）时 AEGIS 逐指令等于 R69。
故 R69 是 AEGIS 在「无物理见证」边界上的退化，AEGIS 是 R69 的「常态恒等 + 危险区硬下限」保守封装：安全不让步，常态效率不变，只在物理风险升高时更保守。

**定理 19（见证完整性与欺骗上界）** (a) 单 IMU 且可被任意欺骗时，不存在可靠的见证（不可能性：攻击者可伪造任意 `y`）。(b) 设 k 个异构惯性/接触证据源，欺骗相关性 ρ<1，且静止重力一致性、冲击锁定独立生效，则虚假见证率 ≤ `ρ^{k−1} + ε_cal + ε_temp`；要伪造一致的「重力 + 运动学 + 接触」签名，攻击者必须**物理地**驱动身体，而这本身会被见证，故 ℰ_spoof 不能无代价地变成 ℰ_gentle。(c) 冲击后偏置跳变使见证降级，定义 316 的冲击锁定把「事故后误判为安全」的概率压到 `ε_cal` 量级，代价是事故后短暂更保守。

**引理 22（追溯撤销的单调性与连续性）** 定义 318 的撤销只提高 λ，且在 `H_r` 内至多一次；撤销与 R69 的 λ_floor 复合后仍为单调不减的分段常值/连续函数，因此不引入控制突变；MRC 的进入/退出由独立完整性事件驱动，形成有限状态机，无抖动（附加滞回带 `δ_h`）。

## 6. 本轮最大风险

**一句话**：惯性见证只能证明「动得温柔」，不能证明「动得对」——把安全性等同于加速度/ jerk 包络，会让系统以极其平稳的姿态驶入语义危险（ℰ_gentle）；而当冲击恰好改写了 IMU 偏置时，**见证者本身会在事故后失效**，若冲击锁定与冗余校验不独立，AEGIS 会把「传感器坏了」误读成「身体安全了」——**见证错了，比没有见证更危险**。

**次级风险与缓解**：
1. **ℰ_gentle（动力学平滑但语义危险）** → 明确声明 IMU 非充分条件，必须与 R69 语义安全/世界模型融合，E308 专门量化；
2. **见证欺骗（ℰ_spoof）** → k 个异构证据源 + 静止重力一致性 + 冲击锁定的独立组合，定理 19 上界 + E303；
3. **冲击诱发的偏置跳变** → 定义 316 冲击锁定 + 冗余奇偶 + 温度模型，宁可短暂更保守；
4. **阈值认证错误（包络本身错）** → 包络阈值版本化、离线认证 + E315 HIL 复核，证书显式绑定 `aegis_ver`；
5. **过度保守导致任务失败** → 常态恒等（定理 18-i）+ 只在危险区收紧 + E306/E307 量化误停成本。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** `AEGIS = (IWM, ISA, ADC, ATI, TIB, TCO, RAS-WM§)`；零学习写操作；**见证独立**（只允许原始 IMU + 刚体/执行器模型 + 独立标定，不得用策略似然或世界模型）；**安全单调**（缺失/陈旧/降级/越界时 `λ_AEGIS ≥ λ_R69`）；**先归因后追溯**（撤销需证据、单调有界）。

**定义 311（惯性安全包络 ISE）** `S = {|a|≤a_max, |ω|≤ω_max, |α|≤α_max, |j|≤j_max, ∫|a|dt≤J_max}`，阈值来自伤害/失稳模型并版本化；`h(y)` 为归一化最小裕度；`w_t=1 ⇔ h(y_{t−T:t})≥m 且一步外推 h≥0`。

**定义 312（惯性见证残差 IWR）** `r_imu = y_meas − B(a_cmd,x)`；按可观测性分解为执行器/扰动/打滑/传感器四子空间，供归因使用。

**定义 313（三通道不确定性）** `U_ale`（噪声→λ_floor）、`U_epi`（歧义→交互）、`U_dyn=E[‖r_imu‖|归因]`（失配→见证/退避）。语义不同，不做标量加和；`U_dyn` 不驱动交互（问不出物理失配），只驱动见证与退避。

**定义 314（安全见证证书 SAC）** `J_AEGIS = (J_FLUID, w_attest, h_min, TTH, integrity_state, attribution_posterior, latency_slack, imu_cal_hash, aegis_ver)`；`Valid ⇔ Valid(J_FLUID) ∧ fresh ∧ integrity=ok ∧ latency_slack≥0 ∧ h_min≥0`；显式记录「本次安全由预测还是见证支撑」。

**定义 315（resolution bonus 见证门控 RBG）** 常态（`w=1 ∧ h_min≥m+δ`）`λ_AEGIS=λ_R69`；`w=0`/降级 `λ=max(λ_R69, λ_floor(U_ale+U_epi))`（撤销 bonus）；`m≤h_min<m+δ` 取 `max(λ_R69, λ_ISE(h_min))`；`h_min<m`/见证无效且 TTH 不足 `λ=1`（安全停）。bonus 只能在「身体被见证仍在安全区」时花。

**定义 316（见证完整性 ATI）** 四项联合：静止/重力一致性、冗余/异构惯性奇偶、温度-偏置模型、**冲击锁定**（`∫|a|dt>J_lock` ⇒ 冻结偏置、置 degraded，直到静止复核）。任一 invalid ⇒ `w=0`。

**定义 317（时间完整性预算 TIB）** `TTH(x)` 为到包络边界的最大允许机动时间；要求 `L ≤ ρ·TTH`；超预算跳过 K 采样/Hutchinson/LLM，转惯性安全停。

**定义 318（归因与追溯信任 ADC）** `‖r_imu‖>τ_imu` 时对 `C={policy,actuator,disturbance,sensor}` 求后验；policy/actuator ⇒ 视界 `H_r` 内追溯撤销 bonus 并提高 λ；disturbance ⇒ 临时提高 λ 并记录；sensor ⇒ 见证 invalid、退回 R69 保守。撤销有界、单调，保证连续。

**定义 319（三通道反吸收 TCO）** `z=(r_res,Δa,r_imu)`；若故障被标定吸收且行为异常小，则要么身体运动未变（物理无害），要么 `‖r_imu‖ ≥ L_B‖δ_actual‖−ν`（A99）。故「隐形且有害」被压缩到 ℰ_gentle，交由 R69 语义层。

**定义 320（信息动作惯性门控 IAG）** g 先过 C-RAS-WM；执行期间额外要求 `h(y)≥m_g` 且 `TTH≥L_g`，跌破即中止、`U_epi` 视为未消解、退回 R69 保守。

**定义 321（惯性最小风险条件 MRC）** 见证 invalid 或 `h_min<m` 且 TTH 不足时，受限 jerk 减速、维持姿态、冻结任务/信息动作，仅保留见证与日志；退出由独立完整性复核触发，不能由策略自行宣布恢复。

**定义 322（标定与证书版本化）** 偏置/尺度/失准/重力哈希版本化；`aegis_ver` 绑定策略、阈值、标定与见证算法版本；不匹配即证书失效；冲击锁定期间禁止热更新标定。

**定义 323（威胁模型 ℰ_AEGIS）** `ℰ_FLUID × ℰ_impact × ℰ_spoof × ℰ_gentle`：冲击偏置跳变、声学/共振注入与重放、动力学平滑但语义危险；显式记录「IMU 对 ℰ_gentle 不可观测」。

```python
                 and temp_bias_ok(imu, temp, cal) and not impact_locked(imu))
    return Attestation(w=int(ok and h >= MARGIN and integrity),
                       h_min=h, integrity=integrity, t=imu.t)

# IP-266：本体模型残差 → 归因
def inertia_residual(a_cmd, x, y_meas, B):
    r = y_meas - B(a_cmd, x)                       # 定义 312
    proj = {k: P[k] @ r for k in ("act", "dist", "slip", "sensor")}
    return r, proj, attribution_posterior(proj, x) # 定义 318

# IP-268：时间完整性预算
def temporal_budget(x, latency):
    tth = min_time_to_envelope(x, env)             # 定义 317
    return latency.total <= RHO * tth, tth

# IP-273：AEGIS 主闭环（R69 之上只加见证门控 + 单调退避）
def AEGIS_RAS_round(M, obs, imu):
    att = attest(M.iwm, imu, M.cal, M.redundant, M.temp)
    time_ok, tth = temporal_budget(M.x, M.latency)
    if not time_ok or not att.w:
        return M.mrc.safe_stop(M.x, att)            # 定义 321：跳过 K 采样/LLM

    k69, lam69, mode, (U_ale, U_epi) = M.fluid.round(obs)   # R69 原样执行
    r, proj, post = inertia_residual(M.last_cmd, M.x, imu.y, M.B)
    if norm(r) > M.tau_imu:                         # 定义 318 归因 + 追溯
        c = argmax(post)
        if c in ("policy", "actuator"): M.trust.retro_revoke(H_r=M.H_r)
        elif c == "sensor":             att = att._replace(w=0, integrity="invalid")

    lam = lam69                                     # 定义 315：常态恒等
    if not att.w:      lam = max(lam69, M.lam_floor(U_ale + U_epi))
    elif att.h_min < M.m + M.delta: lam = max(lam69, M.lam_ise(att.h_min))
    if att.h_min < M.m: return M.mrc.safe_stop(M.x, att)

    if M.info_action_active and not M.iag.allow(att, M.info_action):
        M.abort_info_action()                       # 定义 320；U_epi 未消解

    k = M.c_ras_wm.certified_prefix(M.ach.propose(M.x, M.vista.H), ..., M.wm_preds)
    tail = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqauditor_a.submit_async(att, r, post, lam, lam69)    # IP-272 审计
    return k, lam, mode, (U_ale, U_epi, U_dyn=norm(r))
```

## 4. 推导

**引理 19（见证式安全的模型无关性）** 包络阈值经离线认证、`|y_meas−y_true|≤ν`，取归一化裕度 `m≥ν`，则「见证有效 ⇒ 真实伤害代理量 ≤ ε_safe」**不依赖策略/世界模型是否正确**，只依赖物理测量与阈值认证。这是 R68/R69 安全论证的结构性补强：安全性第一次拥有不经过学习模型的证据链。

**引理 20（三通道反吸收）** 设故障引起的真实本体运动偏差为 `δ_actual`，`B` 满足 A99（Lipschitz `L_B`、噪声 `ν`），则 `‖r_imu‖ ≥ L_B‖δ_actual‖−ν`。(a) 若 `δ_actual≈0`（纯信息故障），r_imu 不可见但物理伤害代理量也为 0；(b) 若故障真能致害，必产生可被见证的动力学偏差，除非落在 ℰ_gentle。故 `(r_res, Δa, r_imu)` 把「隐形且有害」压缩到 ℰ_gentle，由 R69 语义层负责；**IMU 不声称能看见语义**。

**引理 21（时间完整性）** 若 `L≤ρ·TTH`、包络制动满足 jerk/加速度上限、时间戳单调，则见证到越界倾向后可在 `TTH` 内进入定义 321 安全停；越界概率 ≤ `ε_noise+ε_ts`。系：R69 的 K 采样与 LLM 问句必须服从同一时间预算。

**定理 18（AEGIS 对 R69 的常态恒等与安全支配）** 在 A99 与包络认证下：(i) 常态（`w=1 ∧ h_min≥m+δ`）`λ_AEGIS=λ_R69`，动作/信息动作/证书语义分支逐指令相同；(ii) 任意状态 `P_AEGIS(包络越界) ≤ P_R69(包络越界)` 且 `λ_AEGIS ≥ λ_R69`；(iii) 禁用见证时逐指令等于 R69。故 R69 是 AEGIS 在「无物理见证」边界的退化；AEGIS 是 R69 的「常态恒等 + 危险区硬下限」保守封装。

**定理 19（见证完整性与欺骗上界）** (a) 单 IMU 可被任意欺骗时不存在可靠见证（不可能性）。(b) k 个异构惯性/接触源、欺骗相关 ρ<1，且重力一致性与冲击锁定独立生效，则虚假见证率 ≤ `ρ^{k−1}+ε_cal+ε_temp`；伪造一致签名须物理驱动身体，而这本身被见证。(c) 冲击后偏置跳变由定义 316 冲击锁定降级，把「事故后误判为安全」压到 `ε_cal` 量级，代价是事故后短暂更保守。

**引理 22（追溯撤销单调、连续）** 定义 318 的撤销只提高 λ、`H_r` 内至多一次；与 λ_floor 复合后为单调不减的分段常值/连续函数，不引入突变；MRC 进入/退出由独立完整性事件驱动并带滞回 `δ_h`，无抖动。

## 7. 本轮最大风险

**一句话**：惯性见证只能证明「动得温柔」，不能证明「动得对」——把安全性等同于加速度/jerk 包络，会让系统以极其平稳的姿态驶入语义危险（ℰ_gentle）；而当冲击恰好改写 IMU 偏置时，**见证者本身会在事故后失效**，若冲击锁定与冗余校验不独立，AEGIS 会把「传感器坏了」误读成「身体安全了」——**见证错了，比没有见证更危险**。

**次级风险与缓解**：ℰ_gentle（IMU 非充分条件 → 必须与 R69 语义安全融合 + E308）；见证欺骗（k 异构源 + 重力一致性 + 冲击锁定 + 定理 19 + E303）；冲击诱发偏置跳变（定义 316 冲击锁定 + 冗余奇偶 + 温度模型，宁可短暂更保守）；包络阈值本身错（版本化 + 离线认证 + E315 HIL，证书绑定 `aegis_ver`）；过度保守（定理 18-i 常态恒等 + 仅危险区收紧 + E306/E307 量化误停成本）。
