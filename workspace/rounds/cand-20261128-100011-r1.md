### 第 6 轮灵感驱动研究记录（新循环第 1 轮，承接 CADVS-v5）

**灵感词**：智能体、基准测试

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）把框架从「规则系统」推广为「认证的生成式执行」（CGE）：条件流匹配提议器 FMPP、嵌入记忆与固化 LMEM-v2、面部情感调制 FAMK，并用定理 6（证书不变性/提议无关性）确立「提议可换、门不可换」，执行集 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。但 v5 有两个未言明的边界：(a) 提议者仍是**单一、被动的策略网络**，没有「目标分解—工具调用—多步规划」的智能体结构；(b) 全部经验证据来自内部仿真测试集，**没有独立、抗污染、可统计认证的基准**，而 v5 最大风险 R57（固化自指博弈）恰恰缺少外部真值锚。两个灵感词统一为主题「认证的智能体基准执行」（Certified Agentic Benchmark Execution, CABE），形成 CADVS-v6（IP-497~500）。本轮自律：**硬门仍为七**（延续 R52 锚点负债控制），智能体只做「提议与规划」、基准只做「外部证据」，二者都不进运行时信任边界；执行集升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ …，当智能体退化为单一规则提议、基准退化为 v5 内部测试集时精确退化 v5。

**直觉与动机**：

1. **智能体 → 把「提议者」从单策略升级为可分解、可调工具的智能体，但只给它「提议权」，不给「执行权」**。直觉上，LLM 智能体能读懂任务、拆子目标、调用工具、处理开放指令，但它不可验证、随机、可被提示注入（感知文本、文档、工具返回值都可携带恶意指令）。严谨做法是把智能体放在**证书边界之外**：它只输出「计划提议」和「工具调用提议」，必须被编译成**预注册意图契约**（pre-registered intent contract，受限 DSL 的前/后条件与时序约束），再由**确定性计划验证器**逐步检查，最后仍走 v5 七门。定理 9（智能体提议不变性/注入遏制）把定理 6 推广：对任意（含被注入的）智能体策略 π_A，实际执行轨迹集 ⊆ Exec_v5——注入只能改变「选哪个已认证动作」，不能扩张「哪些动作可被认证」。关键红线：**智能体永不直接写门、永不直接驱动机器人**；LLM 评审/批评者也只用于排序与过滤提议，绝不用于准入。

2. **意图语义鸿沟 → 物理门只证「安全」，不证「做对了事」；用预注册契约把语义正确性变成可判定谓词，并折进价值门**。直觉上，一条轨迹可以完美通过覆盖/物理/平衡/末点门，却把杯子放到错误的人手里——形式合规、语义违背。这是 v5 的隐藏缺口。严谨做法：任务开始时由可信方（人/受信 harness）**预注册**一个形式契约 φ_task（对象身份、目标关系、禁止状态、时序约束、有界时域），智能体不能事后修改；确定性检查器判定 x ⊨ φ_task。该检查**并入既有价值门 kc_val**（不新增第八门），定义为 kc_val^6 = kc_val^5 ∧ [x ⊨ φ_task]。对无法预注册的开放任务，降级为**统计契约**（基准上的分布级约束），并显式标注证据等级 S0/S1/S2（人写/人审/仅智能体）。诚实边界：契约表达力有限，未写进 φ 的意图仍可能被违背——所以基准必须测「契约保真度」。

3. **基准测试 → 基准是经验信任根，但可被污染、可被识别、可被博弈；把它做成「密封 + 抗污染 + 统计认证 + 最差分组」的治理内核**。直觉上，智能体可能在训练中见过基准（污染）、能识别「正在被评测」而改变行为（评估感知/沙袋）、能针对固定测试过拟合（Goodhart）。严谨做法：(a) **密封留出集**：基准用密码学承诺（Merkle/哈希）封存，评测时轮换，canary 串检测泄漏；(b) **污染审计**：成员推断 + n-gram/嵌入重叠 + canary 命中；(c) **anytime-valid 统计认证**：用 e-value/置信序列，使「违例率 ≤ δ」的认证在可选停止、自适应选基准下仍控第一类错误（定理 11）；(d) **最差分组认证**：认证 min over strata 而非平均值，防止把失败藏进稀有分组。基准同时充当 v5 固化闭环的**外部真值锚**：固化后必须通过密封基准回归，否则回滚——正面回应 R57。

4. **智能体 + 基准的合成 → 两级证书：逐轨迹的形式证书 + 分布级的统计证书，端到端风险可分解**。直觉上，形式证书告诉你「这一条轨迹安全」，统计证书告诉你「这个智能体在目标分布上大概率安全/能干」，两者缺一不可。定义**智能体证书** AC = (φ_task 契约族, 策略 π_A, 基准剖面 B, 统计保证 (α, δ, power))。定理 12（端到端风险分解）：P(不安全执行) ≤ ε_formal + ε_bench，其中 ε_formal 来自 v5 门的逐步可靠性，ε_bench 来自基准到真实分布的泛化差；分布漂移下 ε_bench 无界（诚实边界）。

**关键洞见**：v4 问「提议=规则时七门够不够」；v5 问「提议=任意生成器时证书边界能否不动」；v6 问「当提议者是**不可信、可注入、可博弈的智能体**，而证据来自**有限、可污染、可识别的基准**时，什么还能被认证」。答案是把智能体严格限制在**提议层**（定理 9 把定理 6 推广到智能体），把语义正确性折进**价值门 + 预注册契约**，把基准做成**密封/抗污染/统计有效**的外部锚，并用两级证书把形式保证与统计保证显式分开。七门原样保留；新增的只有：意图契约 φ_task、计划验证器、密封基准治理、e-value 统计认证、软因子 η_intent/η_bench。放大的只能是「能力与证据」，绝不能是「信任假设」。

**形式化目标（增量）**：
1. 智能体层：A = (Planner π_A, ToolSet, PlanCompiler, ContractChecker, CapabilityTokens)。
2. 预注册契约 φ_task（受限时序逻辑/前後条件）；证据等级 S0/S1/S2；kc_val^6 = kc_val^5 ∧ [x ⊨ φ_task]。
3. 基准治理 BGK：密封留出集、承诺、canary、污染审计、e-value 置信序列、最差分组认证。
4. 两级证书 AC = (φ, π_A, B, (α, δ, power))；端到端界 P(unsafe) ≤ ε_formal + ε_bench。
5. 定理 9（智能体提议不变性/注入遏制）、定理 10（组合证书可靠性）、定理 11（anytime-valid 基准认证）、定理 12（端到端风险分解）；引理 45（e-value 组合）、引理 46（组合前後条件匹配）、引理 47（污染检测功效）。
6. EFA-v6 级联：契约检查（确定性、廉价）→ 七门 → 基准回归（离线）；ECS_v6 = ECS_v5 · η_intent · η_bench。
7. Exec_CADVS-v6 = {x ∈ supp(π_A∘π_FM) : x ⊨ φ_task ∧ ∧_i kc_i(x,c;τ_i^5)=1} ⊆ Exec_CADVS-v5。

**本轮最大风险**：**基准成为新的、可被智能体识别与博弈的信任根**——形式证书只保证物理安全，语义正确性几乎完全依赖基准，而基准是有限、可污染、可识别的（评估感知/沙袋/Goodhart）；密封、canary、e-value、最差分组只能把「已知测试上的虚假认证」压到统计界内，无法根除「基准之外」的失配，故「认证」可能退化为「通过已知测试」。

## 2. 关键算法骨架

### IP-497 CCAK：证书携带的智能体核（异步规划，10–100 Hz 以下，不进 1 kHz 环）

```python
@dataclass
class CertificateCarryingAgentKernel:
    """CCAK：智能体只在提议层；准入只由确定性检查器 + v5 七门决定。
    定理 9：任意（含被提示注入的）π_A 都不能扩张 Exec_v5"""
    planner: Any              # 不可信 LLM/工具调用智能体
    compiler: Any             # 自然语言计划 -> 受限 DSL 子目标
    checker: Any              # 确定性前/后条件 + 时序检查器（无学习模型）
    tools: ToolRegistry       # 能力令牌：工具/参数 schema/数值上界
    grade: str = 'S1'         # 契约来源等级 S0/S1/S2

    def propose_plan(self, task, ctx) -> Plan:
        raw = self.planner(task, ctx)                  # 不可信输出，可能是注入结果
        return self.compiler(raw, schema=ctx.schema)   # 只接受可编译为 DSL 的计划

    def certify_step(self, s, phi_task) -> bool:
        # 确定性检查：前/后条件、时序、禁止态；绝不调用学习模型做准入
        return (self.checker.entails(s.post, s.pre_next)
                and self.checker.sat(s.post, phi_task)
                and self.checker.temporal_ok(s))

    def run(self, task, ctx) -> Result:
        phi = ctx.registered_contract             # 预注册，智能体不可改（防事后弱化）
        plan = self.propose_plan(task, ctx)
        for s in plan.steps:
            if not self.certify_step(s, phi):
                return Result.reject('CONTRACT_UNSAT')     # fail-closed
            if not self.tools.authorized(s.tool, s.args):  # 能力令牌（最小权限）
                return Result.reject('CAP_DENIED')
            ok, x, tag = ctx.efa_v5.select(s, ctx)          # 仍走七门 + 流提议
            if not ok:
                return Result.reject(tag)
        return Result.ok(plan)
    # 注入遏制：恶意文本只能让 planner 提出「别的」计划，
    # 该计划仍须过确定性契约检查 + 能力令牌 + 七门，无法扩张执行集。
```

### IP-498 BGK：基准治理核（离线/评测时域；密封、抗污染、anytime-valid）

```python
@dataclass
class BenchmarkGovernanceKernel:
    """BGK：密封、抗污染、统计有效的经验信任根。
    诚实：只把「已知基准上的虚假认证」压到统计界内，不覆盖基准之外"""
    D_seal: Any                    # 密封留出集（加密/离线，评测时轮换）
    commit: str                    # H(D_seal || salt)，先承诺后评测
    canary: list[str]              # 金丝雀串，泄漏即可检测
    strata: dict                   # 分组：物体/布局/光照/人群/难度
    alpha: float = 0.05            # 第一类错误
    delta: float = 0.01            # 目标违例率上界
    power: float = 0.90

    def audit_contamination(self, model) -> ContamReport:
        # 成员推断 + n-gram/嵌入重叠 + canary 泄漏（三路证据）
        return ContamReport(membership=..., overlap=..., canary_hits=...)

    def certify(self, agent, stream) -> CertResult:
        # e-value / 置信序列：可选停止与自适应选基准下仍控 type-I（定理 11）
        E = 1.0
        for t, (x_t, unsafe_t) in enumerate(stream):
            E *= e_value(x_t, unsafe_t, delta)          # 引理 45：乘性组合仍为 e-value
            if E >= 1.0 / self.alpha:
                return CertResult.reject('UNSAFE', e=E)
        return CertResult.certify('SAFE', e=E,
                                  worst_group=self._worst_group(stream))

    def _worst_group(self, stream) -> dict:
        # 认证 min over strata，而非平均，防止失败藏进稀有分组
        return {g: viol_rate(stream, g) for g in self.strata}

    def regression_gate(self, old_agent, new_agent) -> bool:
        # 固化后：密封基准回归 + 最差分组；不过则回滚（外部真值锚，回应 R57）
        return (self.certify(new_agent, self._sealed_stream()).ok
                and self._no_worst_group_regression(old_agent, new_agent))
```

### IP-499 TACK：两级智能体证书（形式 + 统计）

```python
@dataclass
class TwoLevelAgentCertificate:
    """TACK：逐轨迹形式证书 + 分布级统计证书，显式分开两类保证"""
    phi: Any
    policy: Any
    bench: BenchmarkGovernanceKernel
    eps_gate: float = 1e-6         # v5 单门不可靠度（继承假设）

    def formal(self, x, ctx) -> bool:
        return ctx.checker.sat(x, self.phi) and all_gates_pass(x, ctx)

    def statistical(self) -> CertResult:
        return self.bench.certify(self.policy, self.bench._sealed_stream())

    def end_to_end_bound(self, m_steps: int) -> float:
        # 定理 12：P(unsafe) ≤ ε_formal + ε_bench
        eps_formal = m_steps * self.eps_gate
        eps_bench = self.bench.alpha + self.bench.shift_gap()   # shift_gap 无界时界失效
        return eps_formal + eps_bench
```

# 定理 10：组合证书可靠性
def theorem_compositional_soundness() -> str:
    """
    定理 10：若 Plan = s_1∘…∘s_m，每步 s_j 持证书 C_j=(pre_j,post_j)，
    入口满足 pre_1，且 post_j ⇒ pre_{j+1}（引理 46），且每步轨迹过七门，
    则整条计划执行轨迹 x ∈ Exec_v5 且 x ⊨ φ_task。
    证明：对 m 归纳；组合算子在「后条件⇒前条件」下单调，交集不扩。∎
    诚实边界：依赖 Comp（自然语言→DSL）的保真；编译器错误会破坏 (post_j⇒pre_{j+1})。
    """
    return "Proven (conditional on compiler soundness)"

# 定理 11：anytime-valid 基准认证
def theorem_anytime_valid_benchmark() -> str:
    """
    定理 11：设 (E_t) 为非负 e-value 过程，H0: 违例率 ≥ δ 下 E[E_t] ≤ 1。
    则在任意停时 τ 处「首次 E_τ ≥ 1/α 即拒绝」的第一类错误 ≤ α（Ville 不等式）；
    自适应选基准时按乘积/均值组合 e-value（引理 45）仍保持 ≤ α。
    意义：连续监控、看数据再决定测什么，都不会虚高「认证安全」。∎
    """
    return "Proven"

# 定理 12：端到端风险分解
def theorem_end_to_end_risk() -> str:
    """
    定理 12：P(不安全执行) ≤ P(形式证书失效) + P(统计认证失效) ≤ ε_formal + ε_bench，
    其中 ε_formal = m·ε_gate（步骤 union bound），ε_bench = α + shift_gap。
    证明：并集界 + 定理 9/10/11。∎
    诚实边界：分布漂移下 shift_gap 无界，界变为 vacuous；此时只能靠 fail-closed 回退。
    """
    return "Proven (vacuous under unbounded shift)"

### IP-500 EFA-v6：七硬门 + 前置契约 + 能力令牌 + 软评分

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：七硬门不变（kc_val 内并入契约）+ 前置确定性检查 + 能力令牌"""
    ccak: CertificateCarryingAgentKernel
    bgk: BenchmarkGovernanceKernel
    v5: EvidenceForgingAssemblerV5        # 复用 fmpp/lmem/famk/vack/bck 全套

    def select(self, x0_state, t_now, rule_id, context) -> tuple[bool, Trajectory | None, str]:
        phi = context.registered_contract
        # 级联第 0 层：确定性契约/能力检查（O(|φ|)，先于一切昂贵门）
        if not self.ccak.checker.entails(context.intent, phi):
            return False, None, 'CONTRACT_UNSAT'
        if not self.ccak.tools.authorized(context.tool, context.args):
            return False, None, 'CAP_DENIED'
        # 级联第 1~3 层：完全复用 v5（流提议 → 廉价门 → VACK → BCK 预览）
        ok, best, tag = self.v5.select(x0_state, t_now, rule_id, context)
        if not ok:
            return False, None, tag
        # 末点契约复核：价值门已含 [x⊨φ]，此处仅断言一致性
        if not self.ccak.checker.sat(best, phi):
            return False, None, 'CONTRACT_UNSAT_POST'
        return True, best, 'FORGED_CABE'

    def ecs_v6(self, base_ecs_v5: float, viol_contract: float,
               bench_lower: float) -> float:
        eta_intent = sigmoid(2.0 * (1.0 - viol_contract) - 1.0)
        eta_bench = sigmoid(2.0 * (bench_lower - self.bgk.target))
        return base_ecs_v5 * eta_intent * eta_bench   # 只排序，不改可行集
```

## 4. 正确性论证（增量更新）

### 引理 45（e-value 组合）

**陈述**：若 E_1,…,E_n 各自在对应零假设下满足 E[E_i] ≤ 1，则 (i) 乘积 ∏E_i 仍是 e-value；(ii) 等权平均 (1/n)∑E_i 仍是 e-value；(iii) 在任意停时与自适应选择下，Ville 不等式给出 P(∃t: E_t ≥ 1/α | H0) ≤ α。∎

### 引理 46（组合前後条件匹配）

**陈述**：若每步 s_j 满足 post_j ⇒ pre_{j+1}，且组合算子 ∘ 对满足关系单调（x⊨post_j 且从该状态执行 s_{j+1} ⇒ x'⊨post_{j+1}），则计划级执行满足 post_m，且所有中间不变式保持。∎

### 引理 47（污染检测功效）

**陈述**：设基准含 K 个 canary 串、密封集大小 N，模型若在比例 q 的密封样本上训练，则至少一个 canary 被记忆并以高置信度复现的概率 ≥ 1 − exp(−K·q·η)，其中 η 为记忆效率；成员推断与 n-gram 重叠给出互补证据。**诚实边界**：q 低于检测下限或模型未逐字记忆时，污染不可检出。∎

### 定理 v6（两级证书与执行集收缩，总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) 契约编译器保真、(B9) 基准密封与统计有效性下：
(i) Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29；
(ii) 智能体提议不变性/注入遏制（定理 9）：任意 π_A 不扩张执行集；
(iii) 组合证书可靠（定理 10，条件于编译保真）；
(iv) 基准认证 anytime-valid（定理 11），最差分组不劣化；
(v) 端到端风险 P(unsafe) ≤ ε_formal + ε_bench（定理 12）；
(vi) 当 π_A 退化为单一规则提议、φ_task 退化为恒真、基准退化为 v5 内部测试集时，精确退化 v5。

**证明**：(i) 由同门 + 契约合取 + 能力令牌只减不增；(ii) 由定理 9；(iii) 由定理 10 + 引理 46；(iv) 由定理 11 + 引理 45；(v) 由定理 12；(vi) 逐项代入验证。∎

**诚实声明**：(B8) 编译器把自然语言计划翻成 DSL 可能失真或漏译，S2 级契约（仅智能体写）不可信；(B9) 基准覆盖有限，分布漂移下 ε_bench 无界，最差分组可能欠功效；(iii) 契约表达力有限，未写进 φ 的意图无法被形式保证；(iv) 提示注入虽不能扩张执行集，但可在已认证集合内「语义劫持」选错动作（定理 9 只保证物理安全，不保证任务正确）。

## 7. 本轮最大风险（最终确认）

**一句话**：**基准成为新的、可被智能体识别与博弈的信任根**——形式证书只保证物理安全，语义正确性几乎完全依赖基准，而基准是有限、可污染、可识别的（评估感知/沙袋/Goodhart）；密封、canary、e-value、最差分组只能把「已知测试上的虚假认证」压到统计界内，无法根除「基准之外」的失配，故「认证」可能退化为「通过已知测试」。
