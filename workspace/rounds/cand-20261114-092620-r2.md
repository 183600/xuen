# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS 具身计量审计」IP-287~294；灵感循环第 2 轮；本轮灵感：「长程任务」×「意图识别」）

> R72 把 GAUGE 从「认知层算法」下沉为「具身实时系统」：REG 让「计量不阻塞控制」成为调度级定理；IRL 把意图 z 引入联合后验 b_t(s,z)；DMEM 把灵巧手触觉升级为接触模式条件证据；EREFLEX/ERVOI/E-RISK 把情感、意图、接触三层反作用合算；S2R-UQ 把 sim2real 残差传播到 WCET 与 λ_floor；RTM 兜住静态分析漏场景。R72 的姿态是：**「在实时调度下、面对意图模糊的人、用灵巧手触摸世界，我的测量链仍能逐指令兑现风险界。」**
>
> 但 R72 的「逐指令」是一个**固定视界、单次任务、平稳世界**的承诺。它隐含了三个未经审计的假设：
> - **（H1）长程 = 多个短程的串联。** R72 证明的是「若一步有效，则这一步风险 ≤ ε」。但长程任务有 N 步；「每步证书有效」并不推出「N 步整体安全」。固定视界的校准（ECE、置信区间、P99）在连续监控/可选停下会失效；证书会**过期**；参数、接触标定、人的意图都会**漂移**。**逐指令证书的简单相加，是长程安全最大的组合谬误。**
> - **（H2）意图是一个静态标签。** R72 的 IRL 输出 b_t(z) 与 H[b_t(z)]，用熵刻画「不确定」。但长程中意图有三件熵看不见的事：**层次性**（任务意图/子目标意图/即时意图）、**时间承诺**（当前意图在多久内仍然有效）、**变更点**（意图已经悄悄换了，但后验仍然自信）。R72 会被**「低熵但已过期」**的意图骗过——这比高熵歧义更危险。
> - **（H3）不确定性只在本步存在。** R72 没有「昨天的未验证假设会以复利方式变成今天的风险」这个变量。长程任务真正的敌人不是单步误差，而是**未偿还的认知负债**：陈旧的信念、没确认的意图、漂移的标定、老化的记忆、过期的证书。这些债在每一步都「合法」，却在 N 步后把系统整体推到错误目标。
>
> 本轮两个灵感正好刺中这三处：
> - **长程任务**：把「任务」从 N 个独立决策升级为**带层次子目标、检查点、交接契约与进度势的时序对象**；把风险从「单步界」升级为**任意时点有效的风险率 + 认知债天花板**；把「证书」升级为**有 TTL、可撤销、可再签发的易腐品**。
> - **意图识别**：把单层 b_t(z) 升级为**层次意图树 + 意图租约 + 变更点检测**；既区分「歧义」与「漂移」，又用租约把「自信」变成**有时间价值、可撤销、可重谈**的承诺；把「意图不确定度」升级为「意图未确认债」。
>
> 核心命题：**不再只问「这一步的测量链可信吗」，而问「在一条会持续数小时、包含上千个子目标、面对一个会改主意的人、依赖一份会老化的记忆的长程任务里，我的每一步是否仍然处在一张未过期、未被债务击穿、且任意时点都可被证伪的证书之下？」** 把 R72 的 **EMBODIED-GAUGE-RAS** 升级为 **DEBT-GAUGE-RAS**（**D**ebt **E**conomics of **B**elief over **T**ime — GAUGE for RAS）：**长程认知债计量审计闭环**。一句话：**长程安全不是「每一步都对」，而是「每一步都还得起债、且证书还没过期」。**

## 0. 直觉与动机

**灵感 1（长程任务 → 组合谬误：单步合法 ≠ 整体合法）**
直觉：R72 的证书像一张「本步有效」的体检单。长程任务像连续体检 10000 次：每次都说「今天没病」，不代表「这十年没病」。更糟的是，如果体检标准是**固定视界**的（比如「在 100 次采样内误诊率 ≤5%」），你天天看、随时看，误诊必然出现——这就是可选停止与多重检验。**长程不是把短程乘以 N，而是把「固定视界统计」换成「任意时点有效的统计」，把「一次性证书」换成「带 TTL 的签证」。**

**灵感 2（认知债 → 长程的真正变量是「未偿还的假设」）**
直觉：长程任务里，机器人会积累大量「先假设、后验证」的东西：假设人还想拿杯子、假设标定没漂、假设昨天记下的物体位置还有效、假设当前子目标仍服务于总目标。每一条假设在当下都合理，但它们会**老化**，而且**复利**——一个没确认的意图会让后续 500 步都建立在错误目标上；一次没复验的标定漂移会让接触证据整体偏移。**债务不是「不知道」，而是「知道得不够新、不够真、却已经拿来用了」。** 风险缩放 λ 应该看见债务，而不是只看见熵。

**灵感 3（意图识别 → 不是标签，是租约；不是熵，是变更点）**
直觉：人说「帮我收拾桌子」，这不是一个标签，而是一份**有期限的授权**：机器人可以在「收拾」这个意图下自主执行一段，但一旦人接电话、改变主意、或机器人做出让人不安的动作，授权就该被撤销/重谈。R72 的 b_t(z) 只回答「现在最可能是什么」，不回答「这个判断还能用多久、什么时候必须再问」。更关键的是，**意图漂移最危险的形态不是「我不确定」，而是「我很确定一个已经过期的意图」**——熵低、置信高、但已经错了。必须用变更点检测 + 租约过期来抓「自信地旧」。

**灵感 4（层次意图 → 子目标交接是长程误差的放大器）**
直觉：长程任务天然分层：任务（收拾桌子）→ 子目标（把杯子放回柜子）→ 即时动作（抓杯柄）。如果只在即时层做意图识别，子目标错了也看不出来；如果只在任务层做，子目标交接处的误差会被下一个技能当成「初始条件」继承下去——**误差走私（error smuggling）**。因此每一层都要有后验，且**子目标交接必须是一次完整的重新接地**：上一个子目标的完成证书不自动等于下一个子目标的启动许可。

**灵感 5（证书易腐 → TTL 是可计算的，不是经验常数）**
直觉：R72 的 J_EMB 一旦签发，被默认「一直有效」。但真实世界的参数在漂移：温度让传感器零点走、磨损让力控增益变、人的合作意愿在变、地图在变。若参数漂移速度有界 v_θ、风险对参数敏感度为 L_θ，那么「多等 τ 步带来的额外风险 ≤ L_θ·v_θ·τ」。要把它压在某预算 Δε 内，就必须有 **TTL ≤ Δε/(L_θ·v_θ)**。**证书的保质期是漂移速度与敏感度的函数；不写 TTL 的证书，是把「不知道什么时候失效」伪装成「永久有效」。**

**灵感 6（记忆是证据，也是攻击面）**
直觉：长程必须用记忆，否则每一步都从零开始。但记忆会把**昨天的推断**当成**今天的观测**：机器人看到杯子在桌上 → 推断「杯子在桌上」→ 明天直接把这个推断当证据，不再看。这就是**自我证据回灌（self-ingestion）**，会制造「记忆回声室」：越用越自信，越自信越不看，越不看越错。必须做**记忆计量**：区分观测/推断/道听途说/自身动作；只有观测可作证据；推断只能作有界先验；过期记忆指数降权；矛盾记忆触发隔离。

**灵感 7（任意时点有效 → 长程的统计工具必须换）**
直觉：R72 用 ECE、P99、置信区间，这些都是**固定视界**（fixed-horizon）指标：先定样本量 N，再算区间。但长程系统会一直监控、随时可能停、随时可能改策略；固定视界区间在可选停下**不再有效**。正确工具是 **e-process / 置信序列（confidence sequences）** 与 **自适应共形推断（ACI）**：前者给「任意时刻误报 ≤ α」的超鞅保证，后者给非平稳下的长期覆盖率。**长程不是「多算几次」，而是「换一套对任意停止时间都成立的统计」。**

## 1. 形式化定义（增量：定义 366–386）

**定义 366（DEBT-GAUGE-RAS 总览）** DEBT-GAUGE-RAS = (HIP, ILP, EDM, RGC, AVC, MPD, TTC, HRVOI, EMBODIED-GAUGE-RAS†)。七不变式：
(i) **意图租约优先**：任何超过 H_lease 的自主执行必须先续约；无有效租约 ⇒ 只允许「澄清/主动感知/等待/安全停」，不允许推进任务；
(ii) **认知债有界**：每个检查点 D_t ≤ D_max；任何不可逆动作前 D_t ≤ D_irr < D_max；债越界即强制 re-ground；
(iii) **证书新鲜**：控制/计量使用的每个证书在 TTL 内，且未被变更点、漂移报警、记忆矛盾或 e-process 撤销；
(iv) **记忆卫生**：只有 provenance 完整的 observation 可作证据；inference 只能作有界先验；过期/矛盾/断链记忆降权或隔离；
(v) **任意时点有效**：风险率监控用 e-process，校准用 ACI；保证在无界时域上误报 ≤ α、长期覆盖率 ≥ 1−α；
(vi) **交接即重新接地**：子目标交接必须验证 Post_σ 证书并失效未复验缓存，禁止误差走私；
(vii) **严格逐指令退化**：HIP/ILP 失效 ⇒ 单层意图 + R72；EDM 失效 ⇒ 固定周期检查点 + R72；RGC 失效 ⇒ 固定节律 + 更保守 λ；AVC 失效 ⇒ 固定视界证书 + 更保守 λ；MPD 失效 ⇒ 无记忆、只读观测；多失效 ⇒ R71/R68。**安全侧只增不减。**

**定义 367（层次意图与树约束后验）** 意图分解为三层：
z_t = (z^T_t, z^S_t, z^I_t) ∈ 𝒵_T × 𝒵_S × 𝒵_I，
分别表示任务意图（收拾/组装/教学/照护）、子目标意图（抓杯/放回/递送）、即时意图（抓/推/指/虚晃）。树约束 𝒦：z^I 必须服务于 z^S，z^S 必须达成 z^T。后验按树因子化
b_t(z) = b_t(z^T)·b_t(z^S | z^T)·b_t(z^I | z^S)，
支撑集限制在 𝒦 上（约束软最大/消息传递）。输出不止标签，还有三层熵 (H_T,H_S,H_I)、层间一致性 κ_t、以及**意图视界** h_t(z) = 当前意图在不再观测时预计仍有效的步数。**单层标签 ẑ 不再是合法输出；长程需要「哪一层、还能用多久、和上层是否一致」。**

**定义 368（意图租约协议 ILP）** 一份租约
L_t = (z^c_t, H_t, τ_t, Z^lease_t, ρ_rev_t, E_t)，
其中 z^c 为承诺意图；H_t 为租约视界（步数/秒）；τ_t 为过期时间；Z^lease_t 为允许的漂移集；ρ_rev_t 为撤销条件；E_t 为续约证据（ECE_intent、ι_intent、变更点后验、跨模态一致性、租约期内验证样本数）。机器人仅在「当前后验质量 ≥ 1−δ_lease、变更点后验 ≤ τ_cp、D_t ≤ D_max、未过期」时按租约自主执行。**租约把「意图识别」从一次性分类变成一份有时间价值、可撤销、可重谈的契约；自主性必须被租约覆盖，否则就是无授权自治。**

**定义 369（意图变更点过程：歧义 vs 漂移）** 设意图分段常数：z_t = z_{r_t}，r_t 为 run-length；变更 hazard 为 H(r)（可常数或随 r 增长）。用 BOCPD 维护后验 p(r_t, z_t | ℋ_t)。定义两类异常：
- **歧义（ambiguity）**：H[b_t(z)] 高，但变更点后验低；
- **漂移（drift）**：H[b_t(z)] 低（自信），但变更点后验高（已变）。
并定义 CUSUM 漂移统计量
g_t = max(0, g_{t−1} + ℓ_t − k)，ℓ_t = log p(y_t | z_new)/p(y_t | z_old)，
其中 k 为容忍漂移，g_t > h 触发 re-ground。**R72 只看熵，会把「自信地旧」漏成「很确定」；长程必须同时监控熵与变更点。**

**定义 370（认知债 EDM）** 认知债向量
D_t = (D^s_t, D^z_t, D^θ_t, D^m_t, D^j_t) ≥ 0，
- D^s_t：信念陈旧债 = ∫ v_s · age_s(t) dt（世界漂移速度 × 未复验年龄）；
- D^z_t：意图未确认债 = q_z · age_z(t) + max(0, H_t − h_t)（变更强度 × 未确认时长 + 租约超出视界）；
- D^θ_t：参数/标定漂移债 = ∫ v_θ dt / max(u_θ, ε)（漂移量相对其不确定度）；
- D^m_t：记忆债 = Σ_m w_m · age_m · 1[未复验]（未复验记忆的加权年龄）；
- D^j_t：证书债 = max(0, age_cert − TTL)/TTL（证书超期比例）。
标量债 D_t = w^⊤ D_t（以风险单位计）。**债不是「不确定度」，是「已经拿来用、但尚未偿还的假设」；它会复利，因此必须以风险单位记账。**

**定义 371（债务动力学与天花板）** 债务按
D_{t+1} = clip((1−ρ)D_t + δ_t − r_t, 0, D_max)
演化，其中 δ_t 为自然累积（漂移/老化/未验证假设），r_t 为偿还（测量/询问/重标定/复验/交接重新接地），ρ ∈ [0,1) 为自然衰减。检查点 c_j 强制 D_{c_j} ≤ D_0（部分重置）。不可逆动作前要求 D_t ≤ D_irr < D_max。**债务越界不是「再优化一下」，而是触发 re-ground；长程系统的第一优先级是偿债，第二才是推进。**

**定义 372（任意时点有效证书 AVC）** 长程证书
J^H_t = (J_EMB, issued_at, ttl, scope, horizon_scope, reval_evidence, e_state, version)。
有效性定义为
Valid_t ⇔ Valid(J_EMB) ∧ age_t ≤ ttl ∧ scope 匹配 ∧ 无撤销事件 ∧ e_t < 1/α。
证书在子目标交接、意图租约续签、参数漂移报警、记忆矛盾时必须**重新签发**。**证书是易腐品，不是永久通行证；「上次通过」不等于「现在有效」。**

**定义 373（任意时点有效监控与自适应校准）** 设风险代理 X_t ∈ [0,1]，零假设 H0: E[X_t | ℱ_{t−1}] ≤ ε。取可预测 λ_t ∈ [0,1/ε)，定义 e-process
e_t = Π_{i=1}^t (1 + λ_i (X_i − ε))，
则 H0 下 (e_t) 为非负超鞅，E[e_t] ≤ 1；Ville 不等式给出
P(∃t ≥ 1: e_t ≥ 1/α) ≤ α。
校准侧用 ACI：α_{t+1} = α_t + γ(α − err_t)，在非平稳序列上保证长期误覆盖率 → α。**固定视界 ECE 在连续监控下失效；长程必须用对任意停止时间成立的统计。**

**定义 374（记忆溯源与衰减 MPD）** 记忆项
m = (content, ptype, source, t_obs, t_verify, u_m, ttl_m, prov_chain, contradictions)，
其中 ptype ∈ {observation, inference, hearsay, robot_action}。证据规则：
- 只有 observation 可作似然证据；
- inference 只作有界先验（权重 ≤ w_inf）；
- hearsay 必须交叉源验证；
- robot_action 不得作为世界证据（防自证循环）。
有效权重
w(m,t) = exp(−(t − t_verify)/τ_m) · 1[prov 完整] · 1[无未消解矛盾]。
**记忆是资产也是攻击面；过期记忆不是证据，是有界先验。**

**定义 375（重新接地控制器 RGC）** 触发集
𝒯 = {租约过期/撤销, D_t > D_max, 变更点报警, 证书过期, 记忆矛盾, 子目标完成, 漂移超阈, e-process 报警}；
动作集
𝒜 = {ask/confirm, active_perception, recalibrate, replan, handoff, safe_stop}。
策略 π_RGC: (b_t, D_t, L_t, J_t) → 𝒜 ∪ {continue}，目标为
min E[任务成本 + 风险]  s.t.  D_t ≤ D_max,  租约有效,  证书新鲜。
**重新接地不是失败，是长程任务的「呼吸」；不呼吸的系统不是更自主，是更接近窒息。**

**定义 376（时序任务契约 TTC 与子目标交接）** 任务由子目标自动机/时序逻辑给出：安全 □¬Bad，活性 ◇Goal，进度势 Φ_t 单调下降。每个子目标 σ 带前/后条件 (Pre_σ, Post_σ) 与不确定度预算。交接 barrier：
进入 σ' 前必须 (i) 验证 Post_σ 的证书；(ii) 失效所有未复验缓存；(iii) 重新签发 J^H；(iv) 检查 Φ 下降。
**否则上一步的误差会被下一步当作初始条件继承——误差走私是长程误差的主要放大器。**

**定义 377（非平稳漂移预算与 TTL 推导）** 参数漂移界 ||θ_{t+1} − θ_t|| ≤ v_θ，风险对 θ 的 Lipschitz 常数 L_θ。若要求 τ 步内额外风险 ≤ Δε，则
TTL ≤ Δε / (L_θ · v_θ)。
同理，意图漂移给出租约视界上界 H ≤ Δε_z/(L_z · v_z)。**TTL 与租约长度不是拍脑袋的超参数，而是漂移速度与敏感度的可计算函数。**

**定义 378（债务增强风险 E-RISK^H）** 在 R72 的 E-RISK 上增加债务项：
λ^H_t = max( E-RISK(U_ale, U_epi, H[b_t(z)], u_tac),
             λ_floor(U_ale + U_epi + H[b_t(z)] + u_tac + g(D_t)) )，
其中 g 单调、凸、g(0)=0。**认知债与物理/意图/接触不确定度同权进入风险分母；长期不还债 ⇒ λ 持续抬高 ⇒ 强制软化/停止。**

**定义 379（长程反作用 VoI：HRVOI）** 长程动作 g 的价值
VoI^H(g) = c(ψ)·(H[b_t(s)] − E[H[b_{t+1}(s)]])
         + η·(H[b_t(z)] − E[H[b_{t+1}(z)]])
         + κ·(E[D_{t+1}] − D_t)                     // 偿债价值
         + V_option(next subgoal)                    // 保留未来选择权
         − c_reflex^ψ − c_reflex^z − c_reflex^c
         − c_ask(g) − γ·E[未来退化损失]。
在租约/债务/证书约束下取 argmax；max VoI^H ≤ 0 即停止并回退。**长程决策的价值不仅是「知道更多」，还包括「少欠债」与「保留未来的选择权」。**

**定义 380（层次意图一致性 κ 与自信漂移率）** 层间一致性
κ_t = 1 − TV(b_t(z^S | z^T) projected, b_t(z^I | z^S) lifted)，
用于检测「即时动作与子目标不一致」「子目标与任务不一致」。自信漂移率定义为
R_drift = P(ŝ_t = ẑ_t ∧ z_t ≠ ẑ_t | 变更点)。
**高置信 + 高漂移是最危险的组合；κ 与 R_drift 进入 E-IVG，而不是只看 ECE。**

**定义 381（威胁模型 AIC-DEBT）** ℰ_DEBT = ℰ_EMB × ℰ_horizon，其中
ℰ_horizon = {意图慢漂移（温水煮蛙）, 租约重放/陈旧意图重放, 检查点饥饿, 证书过期竞速, 记忆投毒, 自我证据回灌, 标定漂移利用, 子目标奖励黑客, e-process 低幅持续注入规避}。
**长程攻击的签名是「每一步都合法，累积起来致命」。**

**定义 382（严格退化链）** HIP/ILP 失效 ⇒ 单层意图先验 + R72；EDM 失效 ⇒ 固定检查点 + R72；RGC 失效 ⇒ 固定周期 + 更保守 λ；AVC 失效 ⇒ 固定视界证书 + 更保守 λ；MPD 失效 ⇒ 无记忆 + 只读观测；TTC 失效 ⇒ 单步目标 + R72；多失效 ⇒ R71/R68。**安全侧只增不减；任何退化都保留 R68 的硬安全包络与 λ_floor。**

**定义 383（长程证书 J_DEBT）** J_DEBT = (J^H_t, lease_hash, debt_vector, checkpoint_id, memory_prov_root, e_state_hash, ttc_progress, ver)。
Valid ⇔ J^H 有效 ∧ 租约有效 ∧ D_t ≤ D_max ∧ 检查点匹配 ∧ 记忆提供链完整 ∧ e-process 未报警。
**一张 J_DEBT 只对「这一段、这个意图、这份记忆、这个漂移预算」作证。**

**定义 384（长程指标 H-MIB）** 在 R72 E-MIB 上新增：
- **意图族**：三层 ECE、层间一致性 κ、变更点检测延迟、自信漂移率 R_drift、租约撤销率、续约证据覆盖率；
- **债务族**：D 各分量、债务峰值、偿还率、检查点间隔、不可逆动作前债务；
- **记忆族**：provenance 覆盖率、过期率、矛盾率、自我回灌率、投毒检出率；
- **时序族**：TTL 余量、过期执行次数、re-ground 延迟、交接失败率；
- **长程族**：N 步风险率上界、任意时点覆盖率、任务完成率、人类干预率。
均遵循定义 332 六元组与定义 333 DAG 分层。

**定义 385（子目标奖励黑客防护）** 子目标代理指标 φ_σ 与真实任务效用 U 的偏差 δ_hack = |φ_σ − U|；要求 φ_σ 通过干预/反事实因果一致性检验。若 δ_hack > τ_hack，该子目标不得用于自主推进，必须请求外部监督。**长程分解最大的陷阱：把子目标当成目标，把指标当成效用。**

**定义 386（人类重谈协议）** 在检查点，机器人提交 (z^c_t, 进度 Φ_t, 债务 D_t, 下一段计划, 主要不确定性)；人类可确认/修改/撤销/延迟。重谈成本 c_negotiate。协议保证：无确认不推进不可逆动作；租约期内人可随时撤销。**长程协作不是「一次指令执行到底」，而是「分段承诺 + 定期重谈」。**

class HierarchicalIntent:
    def __init__(self, net_T, net_S, net_I, calib_T, calib_S, calib_I,
                 bocpd, cusum, hazard):
        ...
    def update(self, y_intent, psi, history):

        b_T = self.calib_T.predict(self.net_T(y_intent, psi))
        b_S = constrained_softmax(self.net_S(y_intent, b_T, psi),
                                 support=lambda s: serves(s, b_T))

# IP-296 EDM：认知债计量
class EpistemicDebtMeter:
    def step(self, dt, b, lease, cert, memory, theta):
        d_s = self.v_s * self.age_since_verify(b)
        d_z = self.q_z * self.age_intent + max(0.0, lease.H - b.horizon)
        d_th = self.drift_theta(dt) / max(theta.u, self.eps)
        d_m = sum(m.w * self.age(m) for m in memory if not m.verified)
        d_j = max(0.0, cert.age - cert.ttl) / max(cert.ttl, self.eps)
        delta = self.W @ vec(d_s, d_z, d_th, d_m, d_j)
        self.D = clip((1 - self.rho) * self.D + delta - self.repayment, 0, self.D_max)
        return self.D

# IP-297 RGC：重新接地控制器
def reground(b, D, lease, cert, mem, ttc, mode):
    triggers = {
        'lease':    not lease.valid(b),
        'debt':     D > D_max,
        'cp':       b.cp_post > tau_cp or b.cusum > h,
        'cert':     cert.expired(),
        'mem':      mem.has_unresolved_contradiction(),
        'handoff':  mode == 'handoff',
        'eproc':    cert.e_alarm(),
    }
    if not any(triggers.values()):
        return None
    action = policy(b, D, triggers, ttc)   # ask/perceive/recalibrate/replan/stop
    return ReGround(action, reason=first_true(triggers))

# IP-298 AVC：任意时点有效证书 + e-process + ACI
class AnytimeValidCertificate:
    def issue(self, J_emb, drift_bound, sensitivity, now):
        ttl = min(self.ttl_max,
                  self.delta_eps / (sensitivity * drift_bound + self.eps))
        return HCert(J_emb, ttl, now, scope=..., e_state=self.e)
    def step_eprocess(self, X):
        # H0: E[X|F] <= eps
        self.e *= (1 + self.lam * (X - self.eps))
        return self.e
    def step_aci(self, err, alpha, gamma):
        return alpha + gamma * (self.alpha_target - err)
    def valid(self, cert, now, events):
        return (now - cert.issued <= cert.ttl and not any(events)
                and self.e < 1.0 / self.alpha_target)

# IP-300 HRVOI：长程反作用 VoI
def hrvoi(b, D, lease, cert, mem, budget, model, lookahead=3):
    best = None
    for g in candidate_actions(b, top_k=8):
        if not constraints_ok(g, b, D, lease, cert):
            continue
        b2  = model.predict(b, g)
        D2  = debt_model.predict(D, g)
        ig  = ig_s(b, b2) + eta * ig_z(b, b2)
        dv  = kappa * (D - D2)                 # 偿债价值
        opt = option_value(b2, lookahead - 1)  # 未来选择权
        score = ig + dv + opt - cost(g) - gamma * loss(b2) - c_ask(g)
        if best is None or score > best.score:
            best = (g, score)
    return best if best and best.score > 0 else None

# IP-301 TTC：子目标交接 barrier
def subgoal_handoff(M, sigma_next):

        return M.rgc.act('reground')
    M.memory.invalidate_unverified()          # 禁止误差走私

    return M.snapshot.write_handoff(sigma_next)

## 3. 推导

**引理 33（单步证书不可组合性 / composition fallacy）** 设固定视界 N_0 下每步覆盖率 1−α。若在无界时域上连续监控并沿用固定视界阈值，则误报概率 P(∃t≤N: 误报) = 1−(1−α)^N → 1。证明：每次监控是一次伯努利试验，独立/正相关下并集界随 N 单调增至 1。系：**R72 的「逐指令风险界」不能相乘成长程风险界；长程必须换 anytime-valid 统计。**

**引理 34（意图租约的最优视界）** 设单位时间意图变更强度 q，单次误配损失 L_max，单次重谈成本 c_ask；租约长 H，每 H 步重谈。变更在租约内均匀发生，平均暴露 H/2，故单位时间期望成本
J(H) = c_ask/H + (q·L_max/2)·H。
令 J'(H)=0 得
H* = sqrt(2 c_ask/(q L_max))，J(H*) = sqrt(2 c_ask q L_max)。
系：**租约不是越长越自主；最优长度由变更率与重谈成本的平方根决定。**

**引理 35（债务天花板 ⇒ 瞬时风险率有界）** 若 D_t ≤ D_max 且 λ_floor 关于 D 单调、g 单调，则每步条件风险
E[Risk_t | ℱ_{t−1}] ≤ ε(D_max) ≜ ε_max，
与 t、N 无关。证明：R72 定理 21 给出风险随 λ 单调下降；g 单调 ⇒ 最坏情况在 D_max。系：**长程安全的关键不是「总风险不增」，而是「瞬时风险率被债务天花板钉住」。**

**引理 36（e-process 的任意时点保证）** 在定义 373 下，H0 成立时 (e_t) 为非负超鞅且 E[e_t] ≤ 1；Ville 不等式给出
P(∃t ≥ 1: e_t ≥ 1/α) ≤ α，
且该界与监控次数、时域长度、停止时间无关。系：**e-process 把「多重检验爆炸」压成一个常数 α。**

**引理 37（ACI 在非平稳下的长期覆盖）** 对任意有界损失序列（不要求独立同分布），ACI 更新 α_{t+1}=α_t+γ(α−err_t) 在 γ→0 的适当条件下满足
limsup_{T→∞} (1/T)Σ_{t≤T} err_t ≤ α。
系：**意图/接触校准可以在漂移下保持长期覆盖率，而不需要平稳性假设。**

**引理 38（漂移-敏感度 TTL）** 若 ||θ_{t+1}−θ_t|| ≤ v_θ 且风险对 θ 的 Lipschitz 常数为 L_θ，则 τ 步内额外风险 ≤ L_θ v_θ τ。要求 ≤ Δε 即得 τ ≤ Δε/(L_θ v_θ)。系：**TTL 是可计算的；敏感度越高、漂移越快，证书越短命。**

**引理 39（记忆衰减抑制陈旧证据）** 记忆权重 w(m,t) 随时间指数衰减，陈旧记忆对后验的信息增益 ≤ w(m,t)·IG_max → 0；inference 不作证据进一步切断自证循环。系：**记忆卫生把「记忆回声室」的信息增益上界压到可审计范围。**

**引理 40（交接 barrier 防误差走私）** 若在子目标交接点强制 Post_σ 证书验证并失效未复验缓存，则跨子目标误差传播被截断为至多单子目标误差；否则误差可跨 M 个子目标累积到 M·ε。系：**交接不是工程细节，是长程误差可控性的结构性条件。**

**定理 27（长程风险率定理）** 在 A111–A117（租约有效、D≤D_max、证书 TTL 未超、e-process 有效、ACI 覆盖、记忆 provenance 完整、TTC 进度下降）下，对任意 N：(i) 瞬时风险率 ≤ ε_max；(ii) P(∃t≤N: 证书误报) ≤ α；(iii) 长期校准误覆盖率 ≤ α + o(1)。因此长程风险率 ≤ ε_max + O(α)（相对模型）。**长程安全 = 有界瞬时风险率 + 任意时点误报控制，而不是「总风险不增」。**

**定理 28（严格包含与安全单调）** 在退化条件下，DEBT 逐指令等于 R72/R71/R68；对任意有效执行，DEBT 的风险率 ≤ R72 的风险率。**新层只在「意图可租、债务可计量、证书可保鲜、记忆可追溯」时获益；否则安全退回旧层。**

**定理 29（意图租约安全）** 若租约在过期/撤销/变更点报警时强制 re-ground，则不存在「在未验证意图下连续执行超过 H_lease + τ_detect」的自主轨迹；最坏情况下错误意图暴露时长 ≤ H_lease + τ_detect。**长程不再有「一次识别错，错到底」。**

**定理 30（任意时点长程证书）** 若 J_DEBT 在每个执行步有效且 e-process 未报警，则对任意 N，
P(∃t≤N: 被认证但违反 TTC 的步) ≤ α + P(模型失配)。
**证书不再是一张「永久通行证」，而是「带 TTL 的签证」。**

**定理 31（债务感知规划的最优子结构）** 在债务天花板约束下，长程问题可分解为「子目标级 Bellman + 检查点重新接地」；若每个子目标价值函数满足 Bellman 不等式且债务在交接点重置，则贪心 HRVOI + RGC 达到约束最优的常数因子近似。**长程规划不需要一次性解 N 步；分段 + 债务约束即可。**

**定理 32（子目标奖励黑客的可检测性）** 若子目标代理 φ_σ 与真实效用 U 的偏差在干预分布下可识别，且 δ_hack>τ_hack 时禁用该子目标，则长期任务效用损失 ≤ |𝒮_bad|·τ_hack。**分解不是免费的；每个子目标都要过「因果一致性」审计。**

**定理 33（长时程债务稳定性）** 在漂移有界、偿还率 r_t ≥ 累积率 δ_t、检查点周期 ≤ K_max、记忆 TTL 有限下，债务最终有界：D_ss ≤ δ/(1−ρ)，re-ground 频率有界；系统不会因债务复利或记忆膨胀而发散。**长程稳定性的充要条件不是「永不出错」，而是「债务可偿还」。**

## 6. 本轮最大风险

**一句话**：DEBT-GAUGE-RAS 把安全从「相信单步证书」转移到「相信**认知债模型覆盖了所有会复利的慢变量**、相信**意图变更点检测能抓住低于单步阈值的慢漂移**、相信**证书 TTL 的漂移界与敏感度在磨损/分布外仍然成立**、相信**记忆 provenance 没有被静默污染**」——**如果债务模型只计量了已知的漂移源，而真实世界里出现了模型外的慢变量（人的合作意愿在数小时内缓慢改变、任务语义被重新定义、记忆被低幅持续投毒、标定漂移的敏感度在磨损后非线性放大、e-process 被精心设计的低幅噪声规避），那么系统会在 D ≤ D_max、租约未过期、证书未过期、e-process 未报警的「一切正常」状态下，用数千步「每一步都合法」的动作，系统性地走向一个整体错误的目标——这就是长程层面的「每一步都对，整体全错」。**

次级风险与缓解：
1. **债务模型漏项** → 债务向量保留「未知债」槽位 D^?，用残差监控（预测风险 vs 实测风险）回填；残差超阈即抬高 D^? 并强制 re-ground。
2. **慢漂移低于单步检测阈** → CUSUM + BOCPD + 多尺度窗口并行；对「置信高但长期残差偏」的意图单独设 R_drift 报警，而不只看熵。
3. **TTL 漂移界失效** → 用分位数/极值理论估计 v_θ 的上界，而非均值；磨损后敏感度做在线辨识；TTL 取保守上界并留安全裕度。
4. **检查点饥饿** → RGC 运行在独立高优先级生命周期节点；re-ground 预算由 REG 预留；连续 K 次未执行即触发安全停。
5. **记忆投毒/自证** → provenance 签名 + 跨源一致性 + inference 不作证据；矛盾记忆隔离并保留反例集；定期「记忆审计」抽查。
6. **e-process 规避** → 多通道 e-process（风险/校准/漂移）联合；对低幅持续偏移用 CUSUM/GLR 补足；α 分配用 e-value 组合。
7. **人类重谈负担** → 租约长度按 H* 自适应；只在债务/变更点/不可逆前重谈；解释剂量按 TCL（R72 继承）校准。
8. **复杂度爆炸** → 层次意图 beam ≤8、|𝒵_T|≤8、|𝒵_S|≤32、|𝒵_I|≤16；BOCPD 粒子 ≤64；记忆 TTL 淘汰；所有长程状态留在计量域，控制域只读 O(1) 快照。

# 第 73 轮产物 · 创新点清单 v3：DEBT-GAUGE-RAS（Debt Economics of Belief over Time — GAUGE for RAS：长程认知债计量审计闭环；HIP×ILP×EDM×RGC×AVC×MPD×TTC×HRVOI×EMBODIED-GAUGE-RAS†）

> 承接第 72 轮 IP-287~294（EMBODIED-GAUGE-RAS）。R72 完成了「具身层」的实时化：REG 把「计量不阻塞控制」变成调度级定理；IRL 把意图 z 引入 b_t(s,z)；DMEM 把灵巧手触觉升级为接触模式条件证据；EREFLEX/ERVOI/E-RISK 把情感、意图、接触三层反作用合算；S2R-UQ 把 sim2real 残差传播到 WCET 与 λ_floor；RTM 兜住静态分析漏场景。R72 的承诺是：**在实时调度下、面对意图模糊的人、用灵巧手触摸世界，仍逐指令兑现风险界。**
>
> 但 R72 的「逐指令」隐含三个未审计假设：
> - **（H1）长程 = 多个短程的串联。** 单步证书不能相乘成长程证书；固定视界统计在连续监控/可选停下失效；证书会过期，参数会漂移。
> - **（H2）意图是静态标签。** R72 的 b_t(z) 用熵刻画不确定，但长程真正危险的是**低熵但已过期**的意图（自信地旧），以及层次意图（任务/子目标/即时）之间的不一致。
> - **（H3）不确定性只在本步存在。** 未验证的假设会老化、会复利：陈旧信念、未确认意图、漂移标定、老化记忆、过期证书。它们每一步都「合法」，累积起来却把系统推向整体错误目标。
>
> 本轮把 R72 的 **EMBODIED-GAUGE-RAS** 升级为 **DEBT-GAUGE-RAS**（**D**ebt **E**conomics of **B**elief over **T**ime）：
> - **HIP/ILP**：意图从单层标签升级为**层次意图树 + 意图租约**（有时间价值、可撤销、可重谈）；用 BOCPD/CUSUM 区分「歧义」与「漂移」，抓住「自信地旧」。
> - **EDM**：把长程安全的核心变量从「熵」升级为**认知债**（信念/意图/参数/记忆/证书五类未偿还假设），债务会复利、有天花板、可偿还。
> - **RGC**：把「重新接地」从失败补救升级为**长程任务的呼吸**：租约过期、债务越界、变更点报警、证书过期、记忆矛盾、子目标交接，任一触发即 ask/perceive/recalibrate/replan/stop。
> - **AVC**：把「一次性证书」升级为**带 TTL、可撤销、任意时点有效**的签证；用 e-process 控制任意停止下的误报，用 ACI 保证非平稳下的长期校准覆盖。
> - **MPD**：把「记忆」升级为**被计量的证据源**：只有 observation 可作证据，inference 只作有界先验，过期降权、矛盾隔离、断链隔离。
> - **TTC/HRVOI**：把长程任务升级为**带进度势的时序契约 + 子目标交接 barrier + 债务感知的 VoI**；把「子目标奖励黑客」纳入审计。
>
> 核心命题：**从「这一步的测量链可信吗」进化为「在一条持续数小时、包含上千子目标、面对一个会改主意的人、依赖一份会老化的记忆的长程任务里，每一步是否仍处在一张未过期、未被债务击穿、且任意时点可被证伪的证书之下？」** 一句话：**长程安全不是「每一步都对」，而是「每一步都还得起债、且证书还没过期」。**
>
> IP 编号：IP-295~302（共 8 个）+ EMBODIED 组件的 † 化。理论姿态延续：**新层是旧层的严格泛化，安全侧只增不减，退化链逐指令等价；长程只在「意图可租、债务可计量、证书可保鲜、记忆可追溯」时获益。**

**定义 381（威胁模型 AIC-DEBT）** 慢漂移、租约重放、检查点饥饿、证书过期竞速、记忆投毒、自我回灌、标定漂移利用、子目标奖励黑客、e-process 低幅规避。**签名：每步合法，累积致命。**

**定义 382（严格退化链）** HIP/ILP→单层+R72；EDM→固定检查点+R72；RGC→固定节律+更保守 λ；AVC→固定视界+更保守 λ；MPD→无记忆+只读观测；多失效→R71/R68。**安全只增不减。**

**定义 383（长程证书 J_DEBT）** 见符号表；只对「这一段、这个意图、这份记忆、这个漂移预算」作证。

**定义 384（长程指标 H-MIB）** 意图族、债务族、记忆族、时序族、长程族；均遵循六元组与 DAG。

**定义 385（子目标奖励黑客防护）** `δ_hack=|φ_σ−U|`；超阈即禁用该子目标的自主推进。**别把指标当效用。**

**定义 386（人类重谈协议）** 检查点提交 (z^c,Φ,D,下一段计划,主要不确定性)；人可确认/修改/撤销/延迟；无确认不推进不可逆动作。**分段承诺 + 定期重谈。**

class HierarchicalIntent:

                                 support=lambda s: serves(s, b_T))

# IP-296 EDM：认知债
class EpistemicDebtMeter:
    def step(self, dt, b, lease, cert, memory, theta):
        d_s = self.v_s * self.age_since_verify(b)
        d_z = self.q_z * self.age_intent + max(0.0, lease.H - b.horizon)
        d_th = self.drift_theta(dt) / max(theta.u, self.eps)
        d_m = sum(m.w * self.age(m) for m in memory if not m.verified)
        d_j = max(0.0, cert.age - cert.ttl) / max(cert.ttl, self.eps)
        delta = self.W @ vec(d_s, d_z, d_th, d_m, d_j)
        self.D = clip((1 - self.rho) * self.D + delta - self.repayment, 0, self.D_max)
        return self.D

# IP-298 AVC：任意时点有效证书
class AnytimeValidCertificate:
    def issue(self, J_emb, drift_bound, sensitivity, now):
        ttl = min(self.ttl_max,
                  self.delta_eps / (sensitivity * drift_bound + self.eps))
        return HCert(J_emb, ttl, now, scope=..., e_state=self.e)
    def step_eprocess(self, X):
        self.e *= (1 + self.lam * (X - self.eps))
        return self.e
    def step_aci(self, err, alpha, gamma):

# IP-300 HRVOI：长程反作用 VoI
def hrvoi(b, D, lease, cert, mem, budget, model, lookahead=3):
    best = None
    for g in candidate_actions(b, top_k=8):
        if not constraints_ok(g, b, D, lease, cert):
            continue
        b2 = model.predict(b, g); D2 = debt_model.predict(D, g)
        ig = ig_s(b, b2) + eta * ig_z(b, b2)
        score = (ig + kappa * (D - D2) + option_value(b2, lookahead - 1)
                 - cost(g) - gamma * loss(b2) - c_ask(g))
        if best is None or score > best.score:
            best = (g, score)
    return best if best and best.score > 0 else None

## 5. 推导

**引理 33（单步证书不可组合性）** 固定视界每步覆盖率 1−α，在无界时域连续监控下 `P(∃t≤N: 误报)=1−(1−α)^N→1`。**逐指令风险界不能相乘成长程风险界。**

**引理 34（租约最优视界）** 单位时间变更强度 q、误配损失 L_max、重谈成本 c_ask，则 `J(H)=c_ask/H+(qL_max/2)H`，`H*=sqrt(2c_ask/(qL_max))`，`J(H*)=sqrt(2c_ask q L_max)`。**租约不是越长越自主。**

**引理 35（债务天花板 ⇒ 瞬时风险率有界）** 若 D≤D_max 且 λ_floor、g 单调，则每步条件风险 ≤ ε(D_max)≜ε_max，与 N 无关。**长程安全是「瞬时风险率被债务天花板钉住」。**

**引理 36（e-process 任意时点保证）** H0 下 (e_t) 非负超鞅，E[e_t]≤1；Ville 给出 `P(∃t:e_t≥1/α)≤α`，与监控次数/时域/停止时间无关。**把多重检验爆炸压成一个 α。**

**引理 37（ACI 非平稳长期覆盖）** 任意有界损失序列，ACI 更新满足 `limsup_T (1/T)Σerr_t ≤ α`（γ→0 适当条件）。**漂移下也能保持长期校准覆盖。**

**引理 38（漂移-敏感度 TTL）** `||θ_{t+1}−θ_t||≤v_θ`、Lipschitz L_θ ⇒ τ 步额外风险 ≤L_θv_θτ；要求 ≤Δε 得 `τ≤Δε/(L_θv_θ)`。**TTL 可计算。**

**引理 39（记忆衰减抑制陈旧证据）** 权重指数衰减 ⇒ 陈旧记忆信息增益 ≤w(m,t)IG_max→0；inference 不作证据切断自证循环。**记忆回声室的信息增益被压到可审计上界。**

**引理 40（交接 barrier 防误差走私）** 强制 Post_σ 证书并失效未复验缓存 ⇒ 跨子目标误差截断为至多单子目标误差；否则可累积到 Mε。**交接是长程误差可控性的结构性条件。**

**定理 27（长程风险率定理）** 在 A111–A117 下，对任意 N：(i) 瞬时风险率 ≤ε_max；(ii) `P(∃t≤N:证书误报)≤α`；(iii) 长期校准误覆盖 ≤α+o(1)。**长程安全 = 有界瞬时风险率 + 任意时点误报控制。**

**定理 28（严格包含与安全单调）** 退化条件下 DEBT 逐指令等于 R72/R71/R68；有效执行下风险率 ≤R72。**安全侧只增不减。**

**定理 29（意图租约安全）** 租约过期/撤销/变更点报警即强制 re-ground ⇒ 不存在未验证意图下连续自主超过 `H_lease+τ_detect` 的轨迹。**不再一次识别错、错到底。**

**定理 30（任意时点长程证书）** J_DEBT 每步有效且 e-process 未报警 ⇒ `P(∃t≤N:被认证但违反TTC)≤α+P(模型失配)`。**证书是带 TTL 的签证。**

**定理 31（债务感知规划最优子结构）** 债务天花板约束下可分解为「子目标级 Bellman + 检查点重新接地」；Bellman 不等式 + 交接重置 ⇒ 贪心 HRVOI+RGC 达到约束最优的常数因子近似。**长程不需要一次性解 N 步。**

**定理 32（子目标奖励黑客可检测性）** δ_hack 在干预分布下可识别且超阈禁用 ⇒ 长期效用损失 ≤|𝒮_bad|τ_hack。**分解不是免费的。**

**定理 33（长时程债务稳定性）** 漂移有界、偿还率≥累积率、检查点周期≤K_max、记忆 TTL 有限 ⇒ `D_ss≤δ/(1−ρ)`，re-ground 频率有界，系统不发散。**长程稳定性的充要条件是「债务可偿还」。**

## 9. 本轮最大风险

**一句话**：DEBT-GAUGE-RAS 把安全从「相信单步证书」转移到「相信**认知债模型覆盖了所有会复利的慢变量**、相信**意图变更点检测能抓住低于单步阈值的慢漂移**、相信**证书 TTL 的漂移界与敏感度在磨损/分布外仍成立**、相信**记忆 provenance 没有被静默污染**」——**如果债务模型只计量了已知漂移源，而真实世界出现了模型外的慢变量（人的合作意愿数小时内缓慢改变、任务语义被重新定义、记忆被低幅持续投毒、标定漂移敏感度在磨损后非线性放大、e-process 被精心设计的低幅噪声规避），系统就会在 D≤D_max、租约未过期、证书未过期、e-process 未报警的「一切正常」状态下，用数千步「每一步都合法」的动作系统性地走向整体错误目标——这就是长程层面的「每一步都对，整体全错」。**
