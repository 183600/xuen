# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim++；灵感循环第 1 轮；本轮灵感：「数据集构建」×「情感语音」）

> 第 54 轮把证书从技能推到动作空间与云边映射，但整条证书链仍有一个从未被审计的根：**训练数据**。本轮把信任链继续下推，提出「数据根信任（Data Root of Trust）」；并以**情感语音**作为最严苛的压力测试——情感标签本质上是多标注者的分布而非客观真值，且情感在部署时又是**安全上下文**而非普通特征。核心矛盾：H22：数据集规模大 ≠ 证书所需覆盖，情感语音的标注熵与说话人/文化偏置会让“数据覆盖”退化为“数据幻觉”；H23：标注期使用的情感空间与部署期门控技能的情感空间若不同构，数据集证书无法传递到第 54 轮的动作-鲁棒性联合证书 `J`。

## 0. 直觉与动机

**灵感 1（情感是分布，不是标签 → 软标签流形）**
直觉：一段语音的“愤怒”不是一个 0/1 标签，而是一群标注者在 VAD（valence-arousal-dominance）+ 强度轴上的投票分布。强行多数投票会把“高分歧样本”压成伪真值，而这类样本恰恰在部署时最危险。应把标注保留为 `p_x(e)`，用标注熵 `H(x)` 衡量其可证程度：低熵样本进入“可证核心” `D_core`，高熵样本进入“探针缓冲” `D_probe`。这与第 54 轮的 `A_core / A_buffer` 形成同构——**证书只建立在核心上，探索只发生在缓冲里**。

**灵感 2（数据集是覆盖对象，不是样本集合 → 覆盖证书）**
直觉：第 54 轮的技能有动作占用 `α_S`，那么数据也应有在 `情感 E × 上下文 C × 动作 A × 鲁棒维 𝔇` 上的占用 `κ_D`。问“这个数据集够不够？”应变成问“`κ_D` 是否覆盖任务需求区域 `R_T`？”。覆盖是**相对任务**定义的，而不是绝对样本量；十万条中性朗读语音对“识别用户痛苦并触发安抚技能”这件事的覆盖可能接近零。

**灵感 3（反事实孪生 → 把情感与内容解耦）**
直觉：情感语音数据最大的混杂是“情绪”与“说了什么 / 谁在说”。用音色转换与韵律移植构造孪生对 `(x, x')`：固定内容只变情感、固定情感只变内容，并附**不变性证书**（情感维变化 ≥ r，内容/说话人变化 ≤ ε）。只有经过这种因子解耦的覆盖，才能在因果上归因于情感维度，而不是词汇或说话人。

**灵感 4（数据构建是逆问题 → 需求驱动的主动补采）**
直觉：传统流程是“先采再测”，我们反过来：从任务证书的需求区域 `R_T` 出发，求一个在标注预算下最大化覆盖增益的数据集。覆盖增益近似子模，贪心即可带 `1-1/e` 近似保证。第 54 轮的 `Explain` 反向解释回传正好告诉我们“下一个缺口在情感-动作空间的哪里”，于是形成 **部署失败 → 解释 → 补采 → 重证** 的数据飞轮。

**灵感 5（情感既是标签又是护栏 → 情感-动作条件证书）**
直觉：部署时“用户哭泣”不是普通特征，而是约束：它应当**门控**可用技能。把 `α_S` 扩展为 `α_{S|e}`，并加入情感单调/安全约束（如高唤醒负性情感不得触发高唤醒大幅动作）。关键要求：标注期情感空间与部署期门控情感空间必须**同构**（同一编码器/本体 + 同构检验），否则数据证书与部署证书各说各话，`J_D` 不成立。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（情感流形与软标签）**
情感空间 `E = V × A_r × D_v × I`（valence、arousal、dominance、intensity）。语音样本 `x` 的标注集 `𝒜(x)` 给出软标签 `p_x ∈ Δ(E)`，标注熵
```
H(x) = -Σ_{e∈E} p_x(e) log p_x(e)
```
数据集平均标注熵 `H̄_D = (1/|D|) Σ_x H(x)`。软标签校准误差记为 `β_cal`。

**定义 122（情感-动作条件剖面）**
技能 `S` 在情感上下文 `e` 下对动作 `a` 的占用为 `α_{S|e}(a) ∈ [0,1]`，满足 `α_{S|e=∅}(a) = α_S(a)`（退化到第 54 轮定义 115）。情感可采纳动作集
```
A_adm(e) = { a ∈ A | α_{S|e}(a) ≥ θ_cov ∧ safe(e,a) }
```
其中 `safe(e,a)` 为情感-动作安全谓词（例：`distress → 禁止高冲击/高速度动作`）。

**定义 123（数据集覆盖剖面与核心/探针划分）**
数据集 `D = {(x_i, p_i, c_i, a_i, d_i, prov_i)}`。覆盖剖面 `κ_D : E×C×A×𝔇 → [0,1]` 为局部核密度经归一化后的占用。任务 `T` 的需求区域 `R_T ⊆ E×C×A×𝔇` 由 `α_{S|e}` 与需声明的鲁棒维集合共同给出。**覆盖缺口**
```
Gap(D,T) = 1 - vol(R_T ∩ supp_θ(κ_D)) / vol(R_T)
```
划分 `D = D_core ⊎ D_probe`：`D_core = {x | H(x) ≤ H_max}` 承担证书；`D_probe = D \ D_core` 仅用于探索与主动补采。

**定义 124（反事实孪生与不变性半径）**
孪生对 `(x,x')` 若仅情感因子变化而内容/说话人保持，则记 `Δ_emo(x,x') ≥ r`、`Δ_content(x,x') ≤ ε`；反之亦然。不变性证书 `Inv_D = (r, ε, ρ_inv)`，其中 `ρ_inv` 为因子扰动下标签保持率。

**定义 125（数据集证书）**
```
D_cert = (κ_D, H̄_D, Inv_D, Prov_D, D_core, D_probe, δ_e, β_cal)
```
`Prov_D` 为带来源与同意状态的溯源图，`δ_e` 为覆盖估计的置信半径。部署可采纳当且仅当
```
Gap(D,T) ≤ θ_gap ∧ H̄_{D_core} ≤ H_max ∧ ρ_inv ≥ θ_inv ∧ β_cal ≤ θ_cal
```

**定义 126（数据条件鲁棒性与数据-技能联合证书）**
数据条件鲁棒性
```
ρ_{S|D}(d) = ρ_S(d) · 1[κ_D(·,d) ≥ θ_d]
```
即**没有覆盖的维度不允许声明鲁棒性**。联合证书 `J_D = (J, D_cert, ρ_{S|D}, Gap, iso)`，`iso` 为标注期与部署期情感空间的同构检验结果。若 `Gap > θ_gap` 或 `iso = fail`，触发主动补采 `ADC(R_T, D, Explain)` 或空间对齐。

## 2. 关键算法伪代码

### IP-121 EML（Emotion Manifold & soft Labels）

```python
def build_emotion_manifold(dataset, annotators, kernel='gaussian', H_MAX=0.5):
    soft = {}
    for x in dataset:
        votes = [a.label(x) for a in annotators[x.id]]
        p = kernel_density(votes, kernel=kernel, bandwidth='silverman')
        soft[x.id] = {'p': p, 'H': entropy(p), 'bin': calibration_bin(p)}
    H_bar = mean([v['H'] for v in soft.values()])
    D_core = [x for x in dataset if soft[x.id]['H'] <= H_MAX]
    D_probe = [x for x in dataset if soft[x.id]['H'] > H_MAX]
    return soft, H_bar, D_core, D_probe
```

### IP-122 DCC（Dataset Coverage Certificate）

```python
def coverage_profile(D, grid_E, grid_C, grid_A, dims, bw):
    kappa = zeros((len(grid_E), len(grid_C), len(grid_A), len(dims)))
    for x in D:
        for idx in neighbor_cells(x, grid_E, grid_C, grid_A, bw):
            kappa[idx] += kernel(x, bw)
    return normalize(kappa)

def coverage_gap(kappa, R_T, theta_cov=0.8, delta_e=0.05):
    covered = sum(1 for cell in R_T if kappa[cell] >= theta_cov)
    gap = 1.0 - covered / len(R_T)
    return gap, gap + delta_e          # 点估计 + 保守上界
```

### IP-123 CFT（Counterfactual Twin & invariance Test）

```python
def counterfactual_twins(x, converters, content_encoder, r_min, eps_max):
    twins = []
    for conv in converters:
        x_emo = conv.transfer_emotion(x, target=sample_other(x.emotion))
        x_cnt = conv.transfer_content(x, target=sample_other(x.content))
        twins.append((x_emo, x_cnt))
    inv = invariance_test(twins, content_encoder, r_min, eps_max)
    return twins, InvCert(r=inv.r, eps=inv.eps, rho_inv=inv.keep_rate)
```

### IP-124 ADC（Active Data Construction）

```python
def active_data_construction(D, R_T, budget, explain_channel, K=32):
    while coverage_gap(D, R_T)[1] > THETA_GAP and budget > 0:
        gap_cells = uncovered_cells(R_T, D)
        hint = explain_channel.next_missing_region()      # 来自第 54 轮 Explain
        candidates = query_pool(gap_cells | hint, k=K)
        # 覆盖增益近似子模：贪心 1-1/e
        x_star = max(candidates, key=lambda x: coverage_gain(D, x, R_T))
        D = D + [(x_star, annotate_soft(x_star))]
        budget -= cost(x_star)
    return D, build_dataset_certificate(D)
```

### IP-125 EAC（Emotion-Action Certificate / affective guardrail）

```python
def emotion_action_certify(alpha_S, e, theta_cov, safety):
    A_adm = [a for a in A if alpha_S.cond(e)[a] >= theta_cov]
    A_adm = [a for a in A_adm if safety.allow(e, a)]
    if not A_adm:
        return ('reject', 'no_admissible_action', e)
    if not monotone_safe(alpha_S, e, A_adm):   # 情感强度 -> 动作冲击 单调
        return ('reject', 'affective_nonmonotone', e)
    return ('ok', A_adm)
```

### IP-126 DGC（Data-Grounded Joint Certificate）

```python
def data_grounded_joint_certificate(skill_seq, D_cert, J, theta_gap, theta_d):
    if D_cert.gap > theta_gap:
        return ('reject', 'coverage_gap', D_cert.gap)
    if not representation_isomorphic(D_cert.encoder, J.encoder):
        return ('reject', 'emotion_space_mismatch')
    rho_D = {d: (J.rho[d] if D_cert.kappa_d(d) >= theta_d else 0.0)
             for d in J.rho}
    if not all(rho_D[d] >= J.rho_min[d] for d in rho_D):
        return ('reject', 'ungrounded_robustness', rho_D)
    return ('ok', JointCert_D(J, D_cert, rho_D))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| EML | O(\|D\|·\|𝒜\|·\|E\|) | O(\|D\|·\|E\|) | 软标签校准、熵估计无偏 |
| DCC | O(\|D\|·\|N_cell\|·\|𝔇\|) | O(\|E\|·\|C\|·\|A\|·\|𝔇\|) | 覆盖估计置信半径 δ_e |
| CFT | O(\|D\|·\|F\|·cost(convert)) | O(\|D\|·\|F\|) | 因子解耦、不变性可检验 |
| ADC | O(k·\|Cand\|·Δκ) | O(\|Cand\|) | 增益近似子模，贪心 1-1/e |
| EAC | O(\|E\|·\|A\|) | O(\|A\|) | 安全谓词 sound、单调约束 |
| DGC | O(\|S\|·\|A\| + \|D_cert\|) | O(\|A\|+\|𝔇\|) | 覆盖-鲁棒一致、空间同构 |

**定理（Data-Grounded Deployment Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 软标签校准 `β_cal ≤ θ_cal`；**(A30)** 反事实不变性在半径 `r` 内成立；**(A31)** 覆盖估计以置信半径 `δ_e` 成立且 `Gap(D,T) ≤ θ_gap`。则
```
P_success ≥ 1 - Σ_d (1 - ρ_{S|D}(d)) - β_E - P(δ_a > Θ_a)
            - (H̄_{D_core}/H_max)·β_H - Gap(D,T)·L_cov
```
其中 `L_cov` 为覆盖缺口的 Lipschitz 损失系数，`β_H` 为标注熵到下游损失的传导系数。关键结论：`ρ_{S|D}(d)=0` 当该维无数据覆盖，从而**杜绝“无数据鲁棒性”**；覆盖缺口以可加项直接进入失败概率下界，数据集证书不再是软性建议而是部署硬约束。

## 4. 实验设计 E162–E166

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 软标签校准 | ECE / 标注熵 vs 人类一致性 | ECE ≤ 0.08；高熵样本一致率显著低 |
| E163 覆盖缺口→成功率 | `Gap` 与下游技能成功率 | 缺口每 +0.1，成功率降幅可预测（R² ≥ 0.85） |
| E164 反事实不变性 | 情感/内容泄漏率、`ρ_inv` | 泄漏 ≤ 5%，`ρ_inv` ≥ 0.9 |
| E165 主动补采效率 | 关闭缺口所需样本数 | 较随机采样少 ≥ 30% |
| E166 情感护栏 | 违规率（distress→高冲击动作） | ≤ 1%，且无安全负迁移 |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 情感标注主观/文化偏置 | 高 | 软标签 + 校准 + 分层文化子集 + 标注者模型 |
| 高维覆盖估计维数灾难 | 高 | 因子化覆盖 + 核哈希/近邻 + 主动采样 + δ_e 保守膨胀 |
| 反事实转换伪影导致假不变 | 高 | 多转换器集成 + 人工抽检 + 不变性半径 + 反例回灌 |
| 主动补采确认偏误/自我强化 | 中 | 独立对抗池 + 探索配额 + 冻结审计集 |
| 情感语音隐私/声纹识别 | 高 | 知情同意 + 端侧特征 + 差分隐私 + 溯源可删除 |
| 标注期/部署期情感空间不同构 | 高 | 共享本体 + 同一编码器 + 同构检验 + 失败即拒部署 |

## 6. 本轮最大风险

**一句话**：把证书下推到“数据根”并以情感语音为压力测试，其 soundness 同时依赖**情感流形设定正确、覆盖估计可信、以及标注期与部署期情感空间同构**；一旦情感空间被错设或高维覆盖被高估，`D_cert` 就退化为“表面覆盖证书”，`ρ_{S|D}` 的下界变成空洞成立，故必须以**软标签校准 + 保守覆盖置信半径 + 同构检验**三重护栏，宁可直接拒绝部署，也绝不把“数据量很大”误当成“证书所需覆盖已满足”。

```python
    # 泄漏率高或不变性半径不达标 -> 该批数据不进入 D_core
    status = 'ok' if inv.keep_rate >= THETA_INV else 'quarantine'
    return twins, InvCert(r=inv.r, eps=inv.eps, rho_inv=inv.keep_rate), status
```

```python
def active_data_construction(D, R_T, budget, explain_channel, K=32):
    trace = []
```

```python
def emotion_action_certify(alpha_S, e, theta_cov, safety):
```

```python
def data_grounded_joint_certificate(skill_seq, D_cert, J, theta_gap, theta_d):
    if D_cert.gap + D_cert.delta_e > theta_gap:
        return ('reject', 'coverage_gap', D_cert.gap)
    if not representation_isomorphic(D_cert.encoder, J.encoder):

             for e in D_cert.required_emotions}
    if any(r[0] == 'reject' for r in E_adm.values()):
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| EML | O(\|D\|·\|𝒜\|·\|E\|) | O(\|D\|·\|E\|) | 软标签校准，熵估计无偏 |
| DCC | O(\|D\|·\|N_cell\|·\|𝔇\|) | O(\|E\|·\|C\|·\|A\|·\|𝔇\|) | 覆盖估计带置信半径 `δ_e` |
| CFT | O(\|D\|·\|F\|·cost(convert)) | O(\|D\|·\|F\|) | 因子解耦、不变性可检验 |
| ADC | O(k·\|Cand\|·Δκ) | O(\|Cand\|) | 增益近似子模，贪心 `1-1/e` |
| EAC | O(\|E\|·\|A\|) | O(\|A\|) | 安全谓词 sound、单调约束 |
| DGC | O(\|S\|·\|A\|+\|D_cert\|) | O(\|A\|+\|𝔇\|) | 覆盖-鲁棒一致、空间同构 |

**定理（Data-Grounded Deployment Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 软标签校准 `β_cal ≤ θ_cal`；**(A30)** 反事实不变性在半径 `r` 内成立；**(A31)** 覆盖估计以置信半径 `δ_e` 成立且 `Gap(D,T) ≤ θ_gap`。则
```
P_success ≥ 1 - Σ_d (1 - ρ_{S|D}(d)) - β_E - P(δ_a > Θ_a)
            - (H̄_{D_core}/H_max)·β_H - Gap(D,T)·L_cov - β_iso
```
其中 `L_cov` 为覆盖缺口的 Lipschitz 损失系数，`β_H` 为标注熵到下游损失的传导系数，`β_iso` 为情感空间非同构造成的残余误差（`iso=pass` 时置 0）。

**推论 1（无数据即无鲁棒）** 若某鲁棒维 `d` 的覆盖 `κ_D(d) < θ_d`，则 `ρ_{S|D}(d)=0`，第 54 轮的联合证书 `J` 在该维上自动失效。这为“鲁棒性声明”提供了可审计的数据前提。

**推论 2（覆盖缺口的可加惩罚）** 在 `L_cov` 有界下，覆盖缺口线性进入失败概率下界；因此“多采数据”不是目标，**把 `Gap` 压到 `θ_gap` 以下**才是目标，且 `D_probe` 不计入证书覆盖，避免用高熵数据虚增覆盖。

## 5. 实验设计与预期结果

| 实验 | 指标 | 目标 | 预期结果（相对基线） |
|---|---|---|---|
| E162 软标签校准 | ECE、高熵样本一致率 | ECE ≤ 0.08 | 软标签较多数投票 ECE 降 ≥ 40% |
| E163 覆盖缺口→成功率 | `Gap` vs 下游成功率 | R² ≥ 0.85 | 缺口 +0.1 对应成功率 −6%~−9% |
| E164 反事实不变性 | 情感/内容泄漏率、`ρ_inv` | 泄漏 ≤ 5%，`ρ_inv` ≥ 0.9 | 因子解耦后情感归因误差降 ≥ 35% |
| E165 主动补采效率 | 关闭缺口所需样本数 | 较随机少 ≥ 30% | Explain 引导较纯不确定性采样再少 ≥ 15% |
| E166 情感护栏 | 违规率 | ≤ 1% | 加入 `A_adm` 后安全违规降 ≥ 80%，任务完成率降 ≤ 3% |

**消融设计**：`D_cert` 的四个分量（覆盖、熵、不变性、校准）逐一移除，测量 E163/E166 的退化幅度，以验证“数据根信任”不是单一指标幻象。**关键对照**：大数据集（10× 样本但 `Gap` 高） vs 小数据集（1× 样本但 `Gap` 低），检验“覆盖优于规模”的核心主张。

## 6. 本轮最大风险

**一句话**：把证书下推到“数据根”并以情感语音为压力测试，其 soundness 同时依赖**情感流形设定正确、覆盖估计可信、以及标注期与部署期情感空间同构**；一旦情感空间被错设或高维覆盖被高估，`D_cert` 就退化为“表面覆盖证书”，`ρ_{S|D}` 的下界变成空洞成立，故必须以**软标签校准 + 保守覆盖置信半径 + 同构检验**三重护栏，宁可直接拒绝部署，也绝不把“数据量很大”误当成“证书所需覆盖已满足”。
