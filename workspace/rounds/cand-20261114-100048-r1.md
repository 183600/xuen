# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS 具身计量审计」IP-287~294；灵感循环第 1 轮；本轮灵感：「多传感器融合」×「UniBot世界挑战赛」）

> R72 把 GAUGE-RAS 从「认知层算法」下沉为「具身实时系统」：REG 调度契约、IRL 意图隐变量、DMEM 接触四分量、EREFLEX 三层反作用、S2R-UQ sim2real 桥接，并用三域分离保证「计量不阻塞控制」。但 R72 仍有两个隐含假设：
> - **融合假设**：视觉、语言、触觉、本体感觉等证据被逐条送进 BSE，仿佛「多一条证据 = 多一份独立信息」。它没有建模**共同模态误差**（同一光照、同一时钟、同一标定外参、同一网络、同一仿真器），也没有审计**融合算子本身**。当多传感器共享误差时，朴素独立融合会把同一个误差数很多遍，后验方差以 1/m 缩小，而真实误差有一个降不下去的地板——**融合幻觉**。
> - **评测假设**：J_EMB 是「自签证书」，只在部署分布上有效。UniBot 世界挑战赛式的评测使用**隐藏任务族、隐藏物体、跨本体、限时、真实世界决赛、外部评审、排行榜压力**。在验证集上盖章，不等于在隐藏测试集上安全；排行榜压力会诱发 **Goodhart**：优化指标而不是任务，优化证书而不是安全。
>
> 本轮两个灵感正好补两块：
> - **多传感器融合**：把「每条测量链的计量审计」升级为「**多条测量链在共享误差、异步延迟、外参偏差、传感器故障下融合后的计量审计**」。融合不是免费的加法，融合算子本身必须是一台被校准、被追溯、被非补偿性否决约束的测量仪器。
> - **UniBot世界挑战赛**：把「自签证书」升级为「**赛事有效证书**」——证书必须携带**评测感知有效域（EAVD）**、**密封审计**、**泛化界**、**抗 Goodhart 预算**、**跨本体迁移界**，并由**元证书**审计评测本身。
>
> 核心命题：**不再只问「我的测量链可信吗」，而问「我的多条测量链在共享误差下融合后还可信吗；以及在隐藏测试集、跨本体、排行榜压力下，我的可信度还成立吗？」** 把 R72 的 EMBODIED-GAUGE-RAS 升级为 **FUSE-GAUGE-RAS**（Fusion-metrologically-valid, Uncertainty-deduplicated, Sensor-health-audited, Evaluation-valid GAUGE for RAS）——**融合计量 × 赛事有效**的具身审计闭环。

## 0. 直觉与动机

**灵感 1（多传感器融合 → 冗余不等于独立，融合会制造虚假的确定性）**
直觉：假设两台相机看同一场景，曝光时间由同一个自动曝光算法控制，图像又经过同一个 ISP。它们的像素噪声或许独立，但「整体亮度偏暗 10%」这个误差是**共同模态**。再假设视觉、触觉、本体感觉都依赖同一个机器人时钟；一次时钟跳变会让所有时间戳同时偏，这不是三个独立故障，而是一个**共享故障**。若把它们当成独立证据做贝叶斯相乘，后验方差会以 1/m 缩小；但真实误差中有一部分是**降不下去的地板**。**精度（precision）不是准确度（accuracy）；冗余（redundancy）不是独立（independence）**。多传感器融合最大的危险不是「传感器太少」，而是「以为传感器很多所以不会错」。

**灵感 2（融合算子本身是测量仪器）**
直觉：R72 审计每条测量链，却把「融合」当成免费操作。融合算子有它自己的构造 φ_F（传感器图、相关组、时间对齐、外参变换）、估计器 m_F（信息滤波/CI/鲁棒融合）、不确定度预算 u_F、有效域 D_F、追溯链 τ_F、非补偿指标 I⊥_F。如果相关结构未声明、时间未对齐、外参有偏、融合器只在仿真里校准过，它输出的只是「看起来更小」的协方差，而不是更真的状态。**融合也要有计量证书；融合器的输出不是后验，而是「带审计协方差的融合测量」。**

**灵感 3（时间与空间是融合的隐藏维度）**
直觉：30Hz 视觉、200Hz 触觉、1kHz 控制。所谓「同一时刻」的状态，是插值/外推出来的。时间戳有不确定度，时钟有漂移，外参有标定误差，运动预测有模型误差。R72 的 E-RISK 把 U_ale、U_epi、H[b(z)]、u_tac 相加，却没有「时间错位」和「外参偏差」这两项——而它们恰是融合特有的**系统性**不确定度。**融合不是把 y 拼起来，而是把 (y, t, frame, health) 拼起来。**

**灵感 4（负信息与传感器健康：没读到不等于不存在）**
直觉：触觉没读到，可能是没接触，也可能是传感器坏了、被遮挡、量程饱和、采样丢了。视觉没看到障碍物，可能是没有障碍物，也可能是视野外、反光、被机械臂自己挡住。把「无事件」当成「无目标」的证据，是负信息的第一类错误；把「多传感器多数投票」当成故障检测，是第二类错误——**共同模态故障下，多数派会一起错**。需要显式的传感器健康状态机、共同模态事件检测、以及「关键传感器一票否决」。

**灵感 5（UniBot世界挑战赛 → 证书必须对隐藏测试集、跨本体、排行榜压力有效）**
直觉：R72 的 J_EMB 是「自签证书」：我在自己的测试集上审计自己。比赛用隐藏任务族、隐藏物体、不同机器人本体、限时、真实世界决赛和外部评审。你在验证集上盖章，不等于在隐藏测试集上安全。更麻烦的是，排行榜会改变研究者的行为：大家会优化「能上榜的指标」，而不是「能在世界里安全完成的任务」；会优化「证书看起来有效」，而不是「系统真的可信」。这就是 **Goodhart 的评测版**，也是比 R72「自信地错自己的可执行性」更深一层的 **meta-Goodhart：自信地错自己的可评估性**。**证书不是「我通过了我的测试」，而是「我在声明的分布上、经过独立密封审计、并且没有被评测本身欺骗」。**

**灵感 6（跨本体：gauge 可迁移性）**
直觉：UniBot 的「Uni」意味着多个本体。R72 的 S2R-UQ 是针对单本体的：仿真参数 → 实机参数。但比赛里可能是 Allegro 手、Shadow 手、LeapHand、不同臂长、不同相机外参、不同控制延迟。传感器图不同、相关组不同、关键传感器不同。只有存在 **gauge morphism**（保持传感器类型、坐标系、关键性、时序的图同构）时，融合标定才能迁移；否则必须重标定，或明确声明 OOD。**可迁移性不是「换个机器人还能跑」，而是「我能证明哪些参数在哪些本体间是同一 gauge」。**

**灵感 7（从「证据融合」到「融合的证据」）**
直觉：R72 的 BSE 把每条证据当独立观测；本轮要把「融合后的证据」本身当成一个**带来源、带相关结构、带健康状态、带时间年龄、带评测有效域的复合测量**。它有一个**有效信息量** I_eff，而不是简单地把每条证据的信息量相加。有效信息量会随传感器数量增加而**饱和**在共同模态地板；这个饱和点就是「再多传感器也买不到的安全」。**融合的收益有上限，融合的风险没有上限——除非你把共同模态显式建模。**

## 1. 形式化定义（增量：定义 366–385）

**定义 366（FUSE-GAUGE-RAS 总览与六不变式）**
FUSE-GAUGE-RAS = (SG, CAFM, F-GAUGE, T-FUSE, SHIELD, NEG-INFO, F-RISK, EAVD, CVC, XEMB, EMBODIED-GAUGE-RAS†)。六不变式：
(i) **融合有效性先于信息增益**：只有 F-GAUGE 有效、所有输入时间有效、关键传感器健康时，融合结果才可进入 BSE/风险缩放；
(ii) **相关诚实性**：共同模态误差必须被声明、估计或保守上界；未知相关默认使用保守融合（CI/CM-CI），**不得默认独立**；
(iii) **非补偿性关键性**：关键传感器组失效时，其他传感器的多数投票不能补偿；触发否决/降级；
(iv) **评测有界声明**：每一份证书必须携带 EAVD、密封审计、泛化界、跨本体迁移界；超出 EAVD 即证书退休；
(v) **严格逐指令退化链**：融合失效 ⇒ 单源最优 + R72；时间失效 ⇒ 冻结/预测 + R72；关键传感器丢失 ⇒ R68；评测失效 ⇒ 仅保留 R72 部署证书；
(vi) **安全单调**：融合/评测带来的任何效率收益，都不得把 λ 降到共同模态地板以下。

**定义 367（传感器图与融合追溯）**
传感器图 SG = (S, G, E_cross, E_group, κ, τ)：
- S = {s_i} 传感器集合，每个 s_i 带类型、坐标系、采样率、延迟、噪声模型、量程、失效模式；
- G = {g} **共同模态组**（同一标定外参、同一时钟、同一光照/ISP、同一网络/电源、同一仿真器、同一温度场等）；
- E_cross ⊆ S×S 跨模态一致性边；E_group ⊆ S×G 组成员边；
- κ: S → {vital, important, auxiliary} 关键性分类；
- τ: S → 追溯链（标定数据、外参版本、固件版本、时间同步源）。
**融合追溯** π_F 把每个融合分量映射到：源传感器、坐标变换、时间戳、相关组、健康状态、标定版本。**没有 π_F 的融合结果不得进入证书。**

**定义 368（共同模态误差分解）**
对传感器 i 的观测：
y_i = h_i(s, t_i) + e_i^ind + e_{g(i)}^cm + b_i + e_i^time + e_i^ext，
其中 e_i^ind ~ 𝒩(0, Σ_i^ind) 为条件独立误差；e_g^cm ~ 𝒩(0, Σ_g^cm) 为组 g 的共同模态误差；b_i 为确定性偏差，‖b_i‖ ≤ β_i；e_i^time 为时间错位误差；e_i^ext 为外参误差。于是
Σ_i = Σ_i^ind + Σ_{g(i)}^cm + Σ_i^time + Σ_i^ext。
**共同模态闭包**：若相关组可重叠，C(G) = Σ_{g∈G} Σ_g^cm · (1 + o_G)，其中 o_G ≥ 0 为重叠膨胀因子（保守处理重叠）。定义**共同模态占比** ρ_cm,i = tr(Σ_cm)/tr(Σ_i)，**有效独立度** r_i = tr(Σ_i^ind)/tr(Σ_i)。**ρ_cm,i 越大，增加同类传感器越没用。**

**定义 369（相关感知融合算子 CAFM 与有效信息）**
若分解已知，使用 **CM-IF（共同模态信息滤波）**：
Σ_ind = (Σ_i w_i (Σ_i^ind)^{-1})^{-1}，μ_ind = Σ_ind Σ_i w_i (Σ_i^ind)^{-1} y_i，
Σ_fused = Σ_ind + C(G)，μ_fused = μ_ind + δ_b，
其中 δ_b 为偏差补偿（未知时用 β 作为不确定度上界，不做点补偿）。
若相关结构未知，使用 **CM-CI（共同模态协方差交）**：
Σ_fused = CI({Σ_i^ind}) + C(G)，CI: Σ_CI^{-1} = Σ_i ω_i Σ_i^{-1}，Σ_i ω_i = 1，
ω 取最小化 det(Σ_CI) 或 trace(Σ_CI) 的解；CI 对任意未知相关都保持**一致性**（不低估）。
**有效信息**：
I_eff = ½ log det(Σ_prior)/det(Σ_fused)，
**冗余比** R_eff = I_eff / I_naive，**信息膨胀因子** κ = I_naive / I_eff ≥ 1，其中 I_naive 是假设独立、忽略共同模态时的信息量。**κ 是「你以为你赚到的信息」与「你实际赚到的信息」之比；κ 越大，融合幻觉越重。**

**定义 370（融合算子计量 F-GAUGE）**
F-GAUGE = (F, φ_F, m_F, u_F, D_F, τ_F, I⊥_F, π_F)：
- F 融合算子（CM-IF / CM-CI / 鲁棒融合）；φ_F 构造（传感器图、相关组、时间对齐、外参）；
- m_F 估计器；u_F 不确定度预算（含共同模态、时间、外参、标定、负信息）；
- D_F 有效域（传感器类型/速率/环境/相关结构/温度/负载）；
- τ_F 追溯链；I⊥_F 非补偿指标（关键性、健康、覆盖）；π_F 融合追溯。
**有效性条件**（全部满足才 Valid）：
(1) **校准**：融合后验的经验覆盖率与名义覆盖率误差 ≤ ε_cal（PIT/coverage 检验）；
(2) **不变性**：对传感器顺序、单位、坐标变换、时间基准的融合结果差异 ≤ ε_inv；
(3) **可追溯**：每个融合分量可复算到源证据与变换链；
(4) **保守性**：未知相关下 κ ≤ τ_κ 或使用 CI 保证；
(5) **时间有效**：所有输入年龄 ≤ τ_age、同步误差 ≤ τ_sync；
(6) **非补偿**：vital 组健康后验 ≥ τ_h，覆盖 ≥ τ_cov。
**融合计量指标**：ECE_fusion、coverage error、κ、ρ_cm、R_eff、AoI、外参误差、健康后验、负信息覆盖。

**定义 371（时间融合计量 T-FUSE）**
每个样本 i 有时间戳 t_i、时间戳不确定度 u_t^i、年龄 a_i(t) = t − t_i。时间错位协方差：
Σ_time^i(t) = J_i Σ_pred(t_i→t) J_i^T + (∂h_i/∂t)² (u_t^i)² + Σ_sync^i，
其中 Σ_pred 是从 t_i 预测到 t 的过程不确定度，Σ_sync 是时钟同步残差。融合快照的年龄 a_F = max_i a_i，时间有效性
ν_time = 1[∀i: a_i ≤ τ_age ∧ u_t^i ≤ τ_sync ∧ 时间戳单调]。
控制域只读年龄 ≤ τ_ctrl 的快照；若 a_F > τ_ctrl，则用运动模型外推，并按速度上界 v_max 膨胀：
u_time = √(λ_max(Σ_time^F)) + v_max · a_F。
**时间不是融合的元数据，而是融合不确定度的一等公民。**

**定义 372（负信息与检测覆盖 NEG-INFO）**
对传感器 i，检测事件 z_i ∈ {0,1}，检测概率 p_d,i = P(z=1 | 目标存在)，虚警率 p_f,i = P(z=1 | 目标不存在)。缺席 z=0 的似然比
LR_absent = (1 − p_d,i)/(1 − p_f,i)。
若 p_d,i 未知，取**最保守** p_d,i = 0 ⇒ LR_absent = 1（缺席不提供任何「不存在」证据）。对状态 x 定义覆盖概率 c_i(x) ∈ [0,1]（视野/遮挡/量程/接触可达性）；有效缺席似然用 p_d,i · c_i(x)。定义**负信息不确定度**
u_neg = 1 − min_i p_d,i · c_i(x)，
以及**覆盖空洞** Ω = {x: max_i p_d,i c_i(x) < τ_cov}。**在 Ω 内，「没读到」不得被解释为「不存在」。**

**定义 373（传感器健康状态机 SHIELD）**
每个传感器 i 的健康状态 h_i ∈ {healthy, degraded, suspect, failed, spoofed, unknown}。健康证据：
残差 r_i = y_i − h_i(ŝ)、归一化新息平方 NIS、跨模态一致性、时间一致性、标定漂移、温度、电流、丢包率、时间戳单调性、共同模态组内相关。
健康后验 b(h_i) 由 HMM/证据融合在线更新；**共同模态事件** e_cm：同一组内 ≥2 个传感器在统计显著时间内同时退化。**完整性风险** r_int,i = P(h_i ≠ healthy | evidence)。vital 传感器在 b(h_i = healthy) < τ_h 时判为失效。
**关键点**：多数投票在共同模态故障下会集体错；SHIELD 必须检测「大家一起坏」的模式，而不是只做单传感器异常检测。

**定义 374（非补偿性融合否决）**
关键性分类：vital（安全关键、无可替代观测）、important（可降级替代）、auxiliary（可丢弃）。对 vital 组 g，若
b(h_g = healthy) < τ_h 或覆盖 < τ_cov，
则融合被**否决**：不存在有限权重能让其他传感器「补偿」这个观测缺口。记否决谓词 V_g。任一 V_g 为真 ⇒ 触发 R68 或任务级停止；对 important 组，允许用剩余传感器融合，但必须显式记录**覆盖空洞** Ω 并抬高 λ；对 auxiliary 组，可直接丢弃。
**非补偿性的形式化直觉**：如果安全约束依赖的状态分量只被 vital 组观测，那么其他传感器对该分量的条件信息为零；贝叶斯后验不会因为「多数票」而变准，只会因为「虚假共识」而变自信。

**定义 375（融合感知风险缩放 F-RISK）**
令 U_eff 为相关感知融合后的物理/意图/接触不确定度（对 R72 的 U_ale、U_epi、H[b(z)]、u_tac 做**相关感知合成**，而不是朴素相加）：
U_eff = U_ale ⊕_ρ U_epi ⊕_ρ H[b(z)] ⊕_ρ u_tac，
其中 ⊕_ρ(a,b) = √(a² + b² + 2ρab)，ρ 由融合追溯 π_F 中的共享证据估计；无估计时取 ρ = 1 的保守上界。
再计入融合特有项：
U_total = U_eff + U_cm + U_time + U_ext + U_neg，
其中 U_cm 为共同模态/偏差界，U_time 为时间错位，U_ext 为外参误差，U_neg 为负信息覆盖缺口。风险缩放：
λ = max( risk_scale(U_total),
         λ_floor(U_total),
         λ_cm_floor(U_cm + β_cm) )。
**关键**：融合可以降低 U_eff，但**不能降低 U_cm**；因此 λ 有一个与传感器数量无关的共同模态地板。vital 否决时 λ = λ_max 或停止。**多传感器买不到共同模态之外的安全。**

**定义 376（评测感知有效域 EAVD）**
EAVD = (P_task, P_obj, P_env, P_emb, P_adv, Π_eval, T_budget, δ_conf)：
- P_task/P_obj/P_env/P_emb 分别为任务族、物体族、环境族、本体族分布；
- P_adv 为对抗/扰动族；Π_eval 为评测协议（指标、任务顺序、时限、随机化、隐藏集承诺、评分规则）；
- T_budget 为时间/算力预算；δ_conf 为置信水平。
若部署分布 D 与 EAVD 的差异 d(P_D, P_EAVD) ≤ ε，则称 D 被 EAVD 覆盖。**证书只在 EAVD 内有效；EAVD 之外的「安全」不是安全，是未声明。**

**定义 377（赛事有效证书 CVC）**
J_CVC = (J_EMB, EAVD, h(Π_eval), sealed_audit_proof, gen_bound, AGB_state, xemb_bound, meta_cert, ttl)。
Valid ⇔
(i) J_EMB 在 EAVD 上有效；
(ii) 密封审计通过（n_sealed 个隐藏样本，泛化界成立）；
(iii) AGB 未耗尽；
(iv) 对声明的本体族，XEMB 迁移间隙 ≤ τ_trans；
(v) META-CERT 通过；
(vi) 未过期、未检测到分布漂移。
**证书退休**：一旦在线漂移检测器、赛事反馈或密封审计触发，J_CVC 立即失效并降级；不允许「拿旧证书解释新分布」。

**定义 378（抗 Goodhart 预算 AGB）**
令 m 为被优化的指标，u 为真实任务效用。**Goodhart 间隙**
Γ = (R_val − R_sealed)/σ_sealed（标准化），
其中 R_sealed 是密封审计风险的无偏估计。**优化压力** P_opt = 候选策略选择次数 / 有效样本量。AGB 是对 P_opt × Γ 的预算；当 Γ > τ_Γ 或 AGB 耗尽时，证书失效，必须开启**新的密封集**，而不是继续在同一密封集上刷分。
配套机制：**预注册**（指标/假设在评测前固定）、**随机化协议**（任务顺序/种子/初始状态）、**多重比较校正**、**密封集一次性使用**。**在有限密封集上无界优化，必然过拟合；这不是道德问题，是选择偏差的数学后果。**

**定义 379（元证书 META-CERT）**
META-CERT 审计评测本身，输出 (audit_passed, audit_trace, residual_risk)：
- **泄漏**：隐藏集是否进入训练/标定/模型选择；
- **污染**：测试数据是否进入标定或超参搜索；
- **樱桃采摘**：是否只报告有利种子/任务；
- **仿真器漏洞**：是否利用物理引擎/渲染器 bug 走捷径（因果归因 + 反事实测试）；
- **评测器 bug**：独立重实现/差分测试；
- **对抗测试**：红队任务是否覆盖声明分布。
**谁审计审计者？** 独立密封审计 + 密码学承诺 + 预注册 + 红队。**没有 META-CERT 的 CVC，只是「自签证书的排行榜版」。**

**定义 380（跨本体计量 XEMB）**
本体 A 的传感器图 SG_A、运动学、动力学、执行器延迟；本体 B 类似。迁移算子 T_{A→B}: θ_A → θ_B 用于标定/融合参数。**gauge morphism** φ: SG_A → SG_B 保持传感器类型、坐标系、关键性、时序。若 φ 存在，迁移间隙
u_trans = ‖T_{A→B}(θ_A) − θ_B*‖_Σ + ε_φ + ε_cal，
其中 θ_B* 为真实标定，ε_φ 为图同构误差，ε_cal 为残余标定误差。若 φ 不存在，u_trans = ∞（不可迁移）。EAVD 必须包含 P_emb；隐藏本体超出覆盖 ⇒ 重标定或降级。
定义**本体不变性间隙** ι_xemb，类比 R71 的 gauge 不变性间隙：同一任务在 A/B 上融合后验的差异，不应超过 u_trans 允许的范围。

**定义 381（融合指标扩展 F-MIB）**
在 R72 E-MIB 基础上新增：
- **融合族**：ECE_fusion、coverage error、PIT 偏差、κ、ρ_cm、R_eff、冗余饱和点；
- **时间族**：AoI P99、时间戳误差、同步漂移、年龄违规率；
- **空间族**：外参误差、重投影误差、坐标一致性；
- **健康族**：故障检出率/延迟、虚警率、共同模态事件检出、欺骗检出；
- **负信息族**：检测覆盖、缺席似然校准、遮挡假阴性；
- **评测族**：Γ、泛化界宽度、AGB 余额、证书 TTL、迁移间隙、META-CERT 残余风险。
所有指标同遵循 R71 定义 332 六元组（φ, m, u, D, τ, I⊥）与定义 333 DAG 分层。

**定义 382（融合 IVG 扩展 F-IVG）**
失效条件：
- **融合**：ECE_fusion > τ_ece、κ > τ_κ、ρ_cm > τ_ρ、R_eff < τ_R、coverage error > τ_cov；
- **时间**：a_F > τ_age、同步误差 > τ_sync、年龄违规率 > τ_age_rate；
- **空间**：外参误差 > τ_ext、坐标不一致 > τ_frame；
- **健康**：vital 传感器不健康、共同模态事件、欺骗检出；
- **负信息**：覆盖 < τ_neg、缺席校准误差 > τ_null；
- **评测**：Γ > τ_Γ、AGB 耗尽、漂移检测、迁移间隙 > τ_trans、META-CERT 失败。
任一成立 ⇒ 相关模块失效，按定义 383 降级。

**定义 383（严格退化包含链）**
- 全有效 ⇒ FUSE-GAUGE-RAS 完整形态；
- 融合 gauge 失效 ⇒ **单源最优 + R72**（禁止静默融合），λ 按单源不确定度膨胀；
- 时间失效 ⇒ **冻结最后有效快照 + 运动预测 + R72**；年龄 > τ_max ⇒ R68；
- vital 传感器丢失 ⇒ 需要该模态的任务 **R68**；其余任务 R72；
- 评测失效 ⇒ **CVC 退休**，只保留 R72 部署证书，不得声称赛事有效；
- 跨本体 OOD ⇒ XEMB 重标定，或降级为 R72 的逐本体 S2R；
- 全失效 ⇒ R68。
**安全侧只增不减：任何退化都保留 R68 的硬安全包络与 λ_floor。**

**定义 384（威胁模型 AIC-FUSE / AIC-UNIBOT）**
ℰ_FUSE = ℰ_EMB × ℰ_fusion × ℰ_eval × ℰ_xemb：
- ℰ_fusion = {共同模态误差注入、相关结构误设、时间戳欺骗、外参标定投毒、单传感器欺骗/丢包、负信息利用（用遮挡制造「不存在」）、融合顺序攻击、标定漂移/磨损}；
- ℰ_eval = {基准过拟合、验证集泄漏、樱桃采摘、仿真器漏洞、评测器 bug、隐藏分布漂移、排行榜博弈、证书表演、meta-Goodhart（优化证书本身）}；
- ℰ_xemb = {本体不匹配、传感器图不匹配、执行器延迟不匹配、迁移标定投毒}。
**新威胁的核心不是「某传感器坏了」，而是「所有传感器一起坏，且坏得一致」。**

**定义 385（融合平面与版本化快照）**
融合平面是横切三域的逻辑层：它运行在**计量域**（软实时、可抢占），消费感知域的异步证据，输出**版本化融合快照**：
Snapshot = (version, t_fuse, b_t(s,z), Σ_fused, u_breakdown, health, F-GAUGE_hash, age, EAVD_id)。
控制域只读版本化快照，**绝不调用融合、绝不等待融合**。这保持 R72 定理 25 的非阻塞性，并把融合延迟隔离在计量域预算内。**融合平面可以有延迟，但控制域不能因融合而抖动。**

# IP-295 CAFM：共同模态误差分解 + 相关感知融合
@dataclass
class SensorSample:
    y: np.ndarray; t: float; u_t: float
    Sigma_ind: np.ndarray; cm_group: str
    frame: str; health: HealthPosterior

class CommonModeFusion:
    def __init__(self, groups, bias_bound, ci_solver):
        self.groups, self.beta, self.ci = groups, bias_bound, ci_solver
    def fuse(self, samples):
        # 1) 只融合条件独立部分
        Lambdas = [w * inv(s.Sigma_ind) for s, w in zip(samples, self.weights(samples))]
        Sigma_ind = inv(sum(Lambdas))
        mu_ind = Sigma_ind @ sum(L @ s.y for L, s in zip(Lambdas, samples))
        # 2) 共同模态只加一次（按组闭包，重叠时保守膨胀）
        Sigma_cm = common_mode_closure(self.groups, samples)
        Sigma_fused = Sigma_ind + Sigma_cm + self.beta.cov()
        # 3) 有效信息与冗余比
        I_eff = 0.5 * logdet(self.Sigma_prior) - 0.5 * logdet(Sigma_fused)
        I_naive = 0.5 * logdet(self.Sigma_prior) - 0.5 * logdet(Sigma_ind)
        return FusedEvidence(mu_ind, Sigma_fused, I_eff,
                             R_eff=I_eff / I_naive, kappa=I_naive / I_eff,
                             rho_cm=trace(Sigma_cm) / trace(Sigma_fused),
                             provenance=build_provenance(samples))

    if max(s.age for s in inputs) > TAU_AGE: return INVALID("stale")

    return VALID(F.provenance, F.u_breakdown)

# IP-297 T-FUSE：时间错位与年龄感知
def temporal_fuse(samples, t_now, motion_model, v_max):
    for s in samples:
        s.Sigma_time = (jac(s) @ motion_model.cov(s.t, t_now) @ jac(s).T
                        + outer(dh_dt(s), dh_dt(s)) * s.u_t**2
                        + s.Sigma_sync)
    a_F = max(t_now - s.t for s in samples)
    u_time = sqrt(max_eig(sum(s.Sigma_time for s in samples))) + v_max * a_F
    nu_time = all((t_now - s.t <= TAU_AGE) and (s.u_t <= TAU_SYNC) for s in samples)
    return TemporalEvidence(a_F=a_F, u_time=u_time, nu_time=nu_time)

# IP-299 NEG-INFO：缺席证据与检测覆盖
def null_likelihood(pd, pf, coverage, observed_absent):

## 3. 推导

**引理 33（共同模态冗余饱和）** 在定义 368–369 下，设组 g 内有 m 个传感器，独立部分方差一致为 Σ_ind，共同模态为 Σ_cm。CM-IF 的融合协方差
Σ_fused(m) = Σ_ind/m + Σ_cm。
当 m → ∞ 时 Σ_fused → Σ_cm，有效信息 I_eff(m) → ½ log det(Σ_prior)/det(Σ_cm)，**饱和**。而朴素独立融合给出 Σ_naive(m) = Σ_ind/m → 0，信息量无界增长。系：**多传感器的收益上限由共同模态地板决定；忽略共同模态会得到「无限信息」的幻觉。**

**引理 34（朴素融合的过度自信下界）** 若真实协方差为 Σ_true = Σ_ind + Σ_cm，而算法用 Σ_naive = Σ_ind，则
λ_max(Σ_true) ≥ λ_max(Σ_cm)，
且信息膨胀因子
κ = I_naive/I_eff = ½ log det(Σ_prior)/det(Σ_ind) ÷ ½ log det(Σ_prior)/det(Σ_ind+Σ_cm) ≥ 1。
特别地，当 Σ_cm 占主导时，κ → ∞。风险缩放若用 U_eff = √λ_max(Σ_naive) 而忽略 U_cm，则 λ 被系统性低估至少 λ_cm_floor(U_cm) 的差距。系：**「融合后不确定度更小」不是好消息，除非你能证明共同模态也一起变小。**

**引理 35（时间年龄 ⇒ 证据失效）** 设过程噪声正定，预测协方差 Σ_pred(Δt) 随 Δt 单调增长。若样本年龄 a > τ_age 而算法仍按 a=0 使用，则实际状态误差协方差至少为 Σ_time(a) = JΣ_pred(a)J^T + (∂h/∂t)²u_t²，其迹严格大于新鲜样本。忽略该项会使 λ 低估；按定义 371 的 u_time 膨胀 λ，可恢复保守性。系：**「同一时刻」是融合的第一谎言；时间错位是融合特有的系统误差。**

**引理 36（负信息的保守性）** 对任意 p_d ∈ [0,1]、p_f ∈ [0,1]，缺席似然比 LR_absent = (1−p_d)/(1−p_f) ≤ 1/(1−p_f)。若 p_d 未知而取最保守 p_d=0，则 LR_absent = 1，缺席不改变后验。因此：**把「没读到」当成「不存在」的任何非保守解释，都会在 p_d<1 时产生假阴性；覆盖空洞 Ω 内的缺席必须视为无信息。** 系：比赛隐藏物体/遮挡场景是负信息的天然攻击面。

**引理 37（有限密封集上的选择偏差）** 设密封集大小 n，候选策略数 M，风险估计的尾部有界。则选择验证风险最小的策略，其真实风险与密封风险的差距至少以
Ω(√(log M / n))
的速率增长（标准 uniform convergence/selection bound）。因此在同一密封集上无界优化必然过拟合；AGB 与一次性密封集不是保守主义，而是选择偏差的必要对冲。系：**排行榜上的「进步」可能只是对密封集的记忆。**

**引理 38（跨本体迁移间隙）** 若存在 gauge morphism φ: SG_A → SG_B 且 T_{A→B} 关于 θ 是 L-Lipschitz，则
u_trans ≤ L‖θ_A − θ_B*‖ + ε_φ + ε_cal。
若 φ 不存在，则不存在仅依赖 A 的有限迁移界；任何「零样本跨本体」声明都必须被限制在已声明的 gauge 同构族内。系：**UniBot 的「Uni」不是免费的；它是需要被证明的 gauge 等价类。**

**定理 27（FUSE-GAUGE 严格包含与安全单调）** 在假设 A111–A116 下：FUSE-GAUGE 在定义 383 的退化条件下逐指令等于 R72/R68；且对任意有效执行，其风险界 ≤ R72 的风险界。**安全单调不减；效率收益只在「融合有效、时间有效、关键传感器健康、EAVD 覆盖」时获得。**

**定理 28（CVC 有效 ⇒ 赛事风险有界）** 若 J_CVC 有效，则在 EAVD 覆盖的分布上，真实风险 ≤ 密封审计风险 + 泛化项 + 漂移项 + 迁移项，且证书退休机制保证超出 EAVD 后不再作安全声明。**证明重量落在「密封审计无污染、EAVD 真实覆盖、META-CERT 独立」上——这三者任一失效，CVC 退化为自签证书。**

**定理 29（融合的无免费午餐）** 不存在一个融合算子，在未知相关结构下同时满足：(i) 对任意相关都优于最优单源；(ii) 永不过度自信。CM-IF 在已知分解下最优；CI 在未知相关下保守；二者之间必须选择「假设」或「保守」。系：**任何声称「既更准又更敢」的融合器，都在某个相关结构下失效；问题不是会不会，而是你是否声明了那个结构。**

**定理 30（融合平面非阻塞）** 融合平面运行在计量域，控制域只读版本化快照、不等待、不调用融合。由定义 385 的单向快照协议，控制环 WCET 与融合负载无关；融合延迟只影响快照年龄，由 T-FUSE 的年龄膨胀进入 λ，而不会造成控制抖动。**融合可以有延迟，但控制不能因融合而失稳。**

## 6. 本轮最大风险

**一句话**：FUSE-GAUGE-RAS 把安全从「相信测量链审计」转移到「相信 **共同模态分解覆盖了所有共享误差源**、相信 **密封审计与 EAVD 真的代表隐藏测试集**、相信 **排行榜压力没有把证书变成优化目标**」——如果存在一个未被声明的共同模态（例如全场统一的光照突变、网络级时钟跳变、工厂预置的标定表被污染、仿真器的一个全局渲染 bug），CAFM 会给出一个「相关感知但相关组漏了一个」的过度自信融合；如果 UniBot 的隐藏任务族/本体族超出 EAVD，而密封集又被反复用于调参、META-CERT 未能检出泄漏，系统就会拿着一份「所有指标都在有效域内、所有审计都通过」的赛事有效证书，在决赛现场把人撞伤、把物体捏碎，赛后审计发现「证书确实有效，只是有效域声明错了」——这就是**meta-Goodhart 层面的「自信地错自己的可评估性」**。

次级风险与缓解：
1. **共同模态漏项** → 相关组红队枚举 + 运行时共同模态监测（组内残差相关突变）+ 未知相关默认 CI 保守兜底。
2. **EAVD 声明过宽** → 预注册任务/本体/环境族；密封集一次性；在线漂移检测触发证书退休。
3. **密封集泄漏/污染** → META-CERT 独立重实现、密码学承诺、训练/测试隔离审计、差分测试。
4. **排行榜过拟合** → AGB + 新鲜密封集 + 多种子/多任务报告 + 选择偏差界。
5. **跨本体迁移幻觉** → 仅声明 gauge 同构族；非同构本体强制重标定或 OOD 降级。
6. **融合平面拖慢计量域** → 融合平面软实时预算、控制域只读快照、融合降级为单源。
7. **复杂度爆炸** → 模块上限：|S|≤32、|G|≤8、|E_cross|≤64、|EAVD|≤6 族；每个 veto 一条可复算证明；复杂度纳入审计指标。

**本方案当前的最大风险：如果「共同模态相关组」与「评测有效域」这两个声明本身错了，那么 FUSE-GAUGE-RAS 会用一套更精致、更可审计、更能在排行榜上自证的流程，系统性地放大同一个错误——它不是不知道自己在融合，而是不知道自己漏掉了哪个共享误差源。**

## 2. 形式化定义（要点版）

**定义 366（总览与六不变式）** 融合有效性先于信息增益；相关诚实性；非补偿性关键性；评测有界声明；严格逐指令退化；安全单调（λ 不低于共同模态地板）。

**定义 367（传感器图与融合追溯）** SG 记录传感器、共同模态组、跨模态一致性、关键性、追溯链；π_F 把每个融合分量映射到源/变换/时间/相关组/健康/标定版本；无 π_F 不得进证书。

**定义 368（共同模态误差分解）** y_i = h_i(s,t_i)+e_i^ind+e_{g(i)}^cm+b_i+e_i^time+e_i^ext；Σ_i=Σ_i^ind+Σ_g^cm+Σ_i^time+Σ_i^ext；C(G)=Σ_g Σ_g^cm(1+o_G)。**共同模态只加一次，不随传感器数量增长。**

**定义 369（CAFM 与有效信息）** CM-IF：Σ_ind=(Σ_i w_i(Σ_i^ind)^{-1})^{-1}，Σ_fused=Σ_ind+C(G)；未知相关用 CM-CI。I_eff=½log det(Σ_prior)/det(Σ_fused)，R_eff=I_eff/I_naive，κ=I_naive/I_eff≥1。**κ 度量融合幻觉。**

**定义 370（F-GAUGE）** 融合算子六元组 + 追溯；六项检查：校准、不变性、可追溯、保守性、时间有效、非补偿。指标：ECE_fusion、coverage error、κ、ρ_cm、R_eff、AoI、外参误差、健康后验、负信息覆盖。

**定义 371（T-FUSE）** 时间戳不确定度 u_t、年龄 a_i、预测协方差 Σ_pred、同步残差 Σ_sync；u_time 随年龄与 v_max 增长；a_F>τ_ctrl ⇒ 外推 + λ 膨胀；a_F>τ_max ⇒ 停用该证据。

**定义 372（NEG-INFO）** 缺席似然比 LR_absent=(1−p_d)/(1−p_f)；p_d 未知取 p_d=0 ⇒ LR=1（无信息）；覆盖空洞 Ω={x:max_i p_d,i c_i(x)<τ_cov}；**Ω 内「没读到」≠「不存在」。**

**定义 373（SHIELD）** 健康状态机 + 残差/NIS/跨模态/时间/漂移/温度/电流/丢包/时间戳/组内相关证据；共同模态事件 e_cm：同组≥2 传感器同时退化；完整性风险 r_int；vital 健康后验 <τ_h 判失效。

**定义 374（非补偿性融合否决）** vital 组失效 ⇒ 否决，其他传感器不能补偿；important 组失效 ⇒ 允许融合但记录覆盖空洞 Ω 并抬 λ；auxiliary 可丢弃。**多数票不能替代对关键状态分量的观测。**

**定义 375（F-RISK）** U_eff=相关感知合成；U_total=U_eff+U_cm+U_time+U_ext+U_neg；λ=max(risk_scale(U_total),λ_floor(U_total),λ_cm_floor(U_cm+β_cm))；vital 否决 ⇒ λ_max/停止。**融合可降 U_eff，不可降 U_cm。**

**定义 376（EAVD）** 任务/物体/环境/本体/对抗族 + 评测协议 + 预算 + 置信；部署分布覆盖检查 d(P_D,P_EAVD)≤ε；EAVD 之外的安全是未声明。

**定义 377（CVC）** J_CVC 九元组；Valid ⇔ J_EMB 在 EAVD 有效 ∧ 密封审计通过 ∧ AGB 未耗尽 ∧ 迁移间隙≤τ_trans ∧ META-CERT 通过 ∧ 未过期/未漂移；**证书退休**：旧证书不得解释新分布。

**定义 378（AGB）** Γ=(R_val−R_sealed)/σ_sealed；P_opt=selections/n_sealed；AGB 预算 P_opt×Γ；Γ>τ_Γ 或预算耗尽 ⇒ 失效，必须开新密封集；配套预注册/随机化/多重比较校正/一次性密封集。

**定义 379（META-CERT）** 审计泄漏/污染/樱桃采摘/仿真器漏洞/评测器 bug/对抗覆盖；输出 (audit_passed,audit_trace,residual_risk)；**没有 META-CERT 的 CVC 只是排行榜版自签证书。**

**定义 380（XEMB）** gauge morphism φ 保持传感器类型/坐标系/关键性/时序；迁移间隙 u_trans；非同构 ⇒ u_trans=∞；EAVD 含 P_emb；本体不变性间隙 ι_xemb。

**定义 381（F-MIB）** 新增融合族（ECE_fusion/coverage/κ/ρ_cm/R_eff/饱和点）、时间族（AoI/时间戳/同步/年龄违规）、空间族（外参/重投影/坐标一致）、健康族（故障/共同模态/欺骗）、负信息族（覆盖/缺席校准/遮挡假阴性）、评测族（Γ/泛化界/AGB/TTL/迁移/元证书）。

**定义 382（F-IVG）** 融合/时间/空间/健康/负信息/评测六类失效条件；任一成立 ⇒ 按定义 383 降级。

**定义 383（严格退化链）** 全有效⇒FUSE-GAUGE；融合失效⇒单源最优+R72；时间失效⇒冻结/预测+R72；vital 丢失⇒R68 或 R72；评测失效⇒CVC 退休仅 R72；迁移 OOD⇒重标定/R72；全失效⇒R68。**安全侧只增不减。**

**定义 384（威胁模型）** ℰ_FUSE=ℰ_EMB×ℰ_fusion×ℰ_eval×ℰ_xemb；新增共同模态注入、相关误设、时间戳欺骗、外参投毒、单源欺骗、负信息利用、融合顺序攻击、基准过拟合、泄漏、采摘、仿真器漏洞、排行榜博弈、meta-Goodhart、本体/图/延迟不匹配。

**定义 385（融合平面与版本化快照）** 融合平面横切三域，运行在计量域；输出 (version,t_fuse,b_t,Σ_fused,u_breakdown,health,F-GAUGE_hash,age,EAVD_id)；控制域只读、不等待、不调用融合。**融合可有延迟，控制不能因融合而抖动。**

# IP-295 CAFM：共同模态分解 + 相关感知融合
class CommonModeFusion:
    def fuse(self, samples):
        Lambdas = [w * inv(s.Sigma_ind) for s, w in zip(samples, self.weights(samples))]
        Sigma_ind = inv(sum(Lambdas))
        mu_ind = Sigma_ind @ sum(L @ s.y for L, s in zip(Lambdas, samples))
        Sigma_cm = common_mode_closure(self.groups, samples)   # 每组只加一次
        Sigma_fused = Sigma_ind + Sigma_cm + self.beta.cov()
        I_eff = 0.5 * logdet(self.Sigma_prior) - 0.5 * logdet(Sigma_fused)
        I_naive = 0.5 * logdet(self.Sigma_prior) - 0.5 * logdet(Sigma_ind)
        return FusedEvidence(mu_ind, Sigma_fused, I_eff,
                             R_eff=I_eff / I_naive, kappa=I_naive / I_eff,
                             rho_cm=trace(Sigma_cm) / trace(Sigma_fused),
                             provenance=build_provenance(samples))

# IP-296 F-GAUGE：融合算子计量检查
def fuse_gauge_check(F, D_F, inputs):
    if not calibrated(F, D_F): return INVALID("calibration")
    if not invariant(F, inputs): return INVALID("invariance")
    if not traceable(F, inputs): return INVALID("traceability")
    if F.kappa > TAU_KAPPA and not F.conservative: return INVALID("overconfidence")
    if max(s.age for s in inputs) > TAU_AGE: return INVALID("stale")
    if any(vital_unhealthy(s) for s in inputs): return INVALID("critical")
    return VALID(F.provenance, F.u_breakdown)

# IP-297 T-FUSE：时间错位与年龄感知
def temporal_fuse(samples, t_now, motion_model, v_max):
    for s in samples:
        s.Sigma_time = (jac(s) @ motion_model.cov(s.t, t_now) @ jac(s).T
                        + outer(dh_dt(s), dh_dt(s)) * s.u_t**2 + s.Sigma_sync)
    a_F = max(t_now - s.t for s in samples)
    u_time = sqrt(max_eig(sum(s.Sigma_time for s in samples))) + v_max * a_F
    nu_time = all((t_now - s.t <= TAU_AGE) and (s.u_t <= TAU_SYNC) for s in samples)
    return TemporalEvidence(a_F=a_F, u_time=u_time, nu_time=nu_time)

def null_likelihood(pd, pf, coverage, observed_absent):
    if observed_absent is None: return 1.0        # 未知，保守无信息
    pd_eff = pd * coverage
    if pd_eff is None: return 1.0                 # p_d 未知，保守
    return (1 - pd_eff) / (1 - pf)

def fusion_risk_scale(U_ale, U_epi, H_z, u_tac, snap, params):
    U_eff = corr_aware_compose(U_ale, U_epi, H_z, u_tac, snap.corr)
    U_total = U_eff + snap.U_cm + snap.U_time + snap.U_ext + snap.U_neg
    lam = max(params.lam_base * (1 + U_total / params.lam_scale),
              params.lam_floor * (1 + U_total),
              params.lam_cm_floor * (1 + snap.U_cm + snap.beta_cm))
    if snap.vital_veto:
        return params.lam_max, VETO
    return lam, OK

## 4. 推导

**引理 33（共同模态冗余饱和）** Σ_fused(m)=Σ_ind/m+Σ_cm → Σ_cm（m→∞），I_eff 饱和；朴素融合 Σ_naive=Σ_ind/m→0，信息无界增长。**多传感器收益上限由共同模态地板决定。**

**引理 34（朴素融合过度自信下界）** 真实 Σ_true=Σ_ind+Σ_cm，若用 Σ_ind，则 λ_max(Σ_true)≥λ_max(Σ_cm)，κ≥1；Σ_cm 主导时 κ→∞。用 U_eff 忽略 U_cm 会系统性低估 λ。**「融合后不确定度更小」不是好消息，除非共同模态也变小。**

**引理 35（时间年龄⇒证据失效）** 过程噪声正定 ⇒ Σ_pred(Δt) 单调增长；忽略 a_F 会低估 λ；u_time 膨胀可恢复保守性。**「同一时刻」是融合的第一谎言。**

**引理 36（负信息保守性）** LR_absent=(1−p_d)/(1−p_f)≤1/(1−p_f)；p_d 未知取 0 ⇒ LR=1。非保守解释在 p_d<1 时产生假阴性；Ω 内缺席视为无信息。**隐藏物体/遮挡是负信息的天然攻击面。**

**引理 37（有限密封集选择偏差）** 密封集 n、候选 M，选择最小验证风险的策略，真实与密封风险差距至少 Ω(√(log M/n))。同一密封集无界优化必然过拟合；AGB+一次性密封集是必要对冲。**排行榜上的进步可能只是对密封集的记忆。**

**引理 38（跨本体迁移间隙）** 存在 gauge morphism 且 T_{A→B} L-Lipschitz ⇒ u_trans≤L‖θ_A−θ_B*‖+ε_φ+ε_cal；无 φ ⇒ 无有限迁移界。**UniBot 的「Uni」不是免费的，是需要证明的 gauge 等价类。**

**定理 27（FUSE-GAUGE 严格包含与安全单调）** 在 A111–A116 下，FUSE-GAUGE 在定义 383 退化条件下逐指令等于 R72/R68；任意有效执行风险界 ≤ R72。**安全单调不减，效率只在融合/时间/健康/EAVD 全有效时获益。**

**定理 28（CVC 有效⇒赛事风险有界）** J_CVC 有效 ⇒ 在 EAVD 覆盖分布上，真实风险 ≤ 密封审计风险+泛化项+漂移项+迁移项；证书退休保证超出 EAVD 后不再作安全声明。**证明重量在密封审计无污染、EAVD 真覆盖、META-CERT 独立。**

**定理 29（融合的无免费午餐）** 不存在融合算子，在未知相关下同时「优于最优单源」且「永不过度自信」。CM-IF 在已知分解下最优，CI 在未知相关下保守；必须选「假设」或「保守」。**任何声称既更准又更敢的融合器，都在某个相关结构下失效。**

**定理 30（融合平面非阻塞）** 融合平面在计量域，控制域只读版本化快照、不等待、不调用融合；控制 WCET 与融合负载无关；融合延迟只影响快照年龄并由 T-FUSE 进入 λ。**融合可以有延迟，控制不能因融合而失稳。**

## 7. 本轮最大风险

**一句话**：FUSE-GAUGE-RAS 把安全从「相信测量链审计」转移到「相信 **共同模态分解覆盖了所有共享误差源**、相信 **密封审计与 EAVD 真的代表隐藏测试集**、相信 **排行榜压力没有把证书变成优化目标**」——如果存在一个未被声明的共同模态（全场统一光照突变、网络级时钟跳变、工厂预置标定表污染、仿真器全局渲染 bug），CAFM 会给出「相关感知但相关组漏了一个」的过度自信融合；如果 UniBot 隐藏任务族/本体族超出 EAVD，而密封集又被反复用于调参、META-CERT 未检出泄漏，系统就会拿着一份「所有指标都在有效域内、所有审计都通过」的赛事有效证书，在决赛现场把人撞伤、把物体捏碎，赛后审计发现「证书确实有效，只是有效域声明错了」——这就是**meta-Goodhart 层面的「自信地错自己的可评估性」**。

**本方案当前的最大风险：如果「共同模态相关组」与「评测有效域」这两个声明本身错了，那么 FUSE-GAUGE-RAS 会用一套更精致、更可审计、更能在排行榜上自证的流程，系统性地放大同一个错误——它不是不知道自己在融合，而是不知道自己漏掉了哪个共享误差源。**
