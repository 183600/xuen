# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「研究空白」×「续航能力」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**可计算的无知 + 不可挪用的能量**。v9 已把"算力"变成块级预算、把"失效"变成中立元，但仍有两个未言明前提：(a) 系统只回答"当前是否安全 / 分布是否偏移"，从不回答"我不知道什么、哪块空白值得花能量去填"；(b) 所有预算都是周期内的 20ms 算力，从未把整场任务的**剩余续航**当作与安全并列的硬约束。两个灵感分别补齐"认知盲区"与"能量边界"，并要求新模块失效时注入**能量-认知中立元**，严格退回 v9 的"只利用、不探索"。

## 0. 直觉与动机

**灵感 1（研究空白 → 把"无知"变成可计算、可登记、可定价的状态）**
直觉：一位严谨研究者的标志不是"知道更多"，而是"清楚自己不知道什么，并且不把没验证过的当成已验证"。v9 的 DA-ML 只输出一个标量 Δ_dom：它告诉你"分布变了"，却不告诉你"变到哪、那里被探过没有、探一次值不值"。核心创新：**研究空白图谱（EpistemicGapMap, EGM）**——在状态-动作空间 X×A 上维护空白密度 G(x,a)，由三源融合：集成模型分歧（模型不确定性）、覆盖密度（新奇度）、**主张-证据缺口**（v9 ID 的消融证据与系统对外主张之差）。配套**研究空白登记簿（NegativeSpaceLedger, NSL）**：显式持久化"探过但无信息""结构上不可达"的负空间，既防止重复烧能量，也防止把"没探"包装成"已覆盖"。这是把学术意义上的 research gap 变成一个在线可观测量——**双重语义**：既指本工作在 v1–v9 中遗漏的文献空白（从未把无知与续航形式化），也指系统运行时的认识论盲区。

**灵感 2（续航能力 → 能量作为硬约束，而非事后统计）**
直觉：v9 的分块执行把算力利用率降到 ~0.3，但整机能量仍被当作"跑得动就行"的软约束。真正的续航能力要求：**任何时刻都为返航 / 安全停驻预留能量，且这笔储备永远不许被探索或性能优化挪用**。核心创新：**续航证书（EnduranceCertificate, EC）**与**续航不变式**：E_rem − Ê_probe − Ê_return ≥ E_reserve + margin，其中 Ê 由保守能量前向模型估计并带误差上界。这把 v9 的停车不变式从"距离域"对偶到"能量域"，使"能回来"成为可证明性质，而不是操作员的经验判断。

**灵感 3（研究空白 × 续航能力 → 空白-续航分配）**
直觉：探索未知是耗电的；续航有限时，"先探哪块空白"本质是一个带硬预算约束的有限时域信息采集问题。核心创新：**空白-续航分配器（GapEnduranceAllocator, GEA）**：在宏观节拍上，以单位能量期望信息增益 IG/cost 为序，解一个带安全可行域约束的预算化次模背包。关键安全设计：**探索不是新控制器，而是对 v9 分块证书执行器（AC）候选采样分布的偏置**——所有探索动作仍必须通过同一块证书与中止点集，因此探索永远被 v9 的安全屏蔽包裹。低电量 / 空白不可约 / 探索超配额时，注入**能量-认知中立元 e^⊥**（Ê=0、G 不更新、探索关闭），行为严格退回 v9 的"只利用"策略。于是形成一条**续航-认知退化链**：能量越少，系统越像 v9；能量耗尽只保留安全停驻。

## 1. 研究问题（轮次升级版）

- **Q1（无知的度量）**：如何在只有在线观测、无真实标签的条件下，构造**校准的**空白密度 G，使"G 高 ⇒ 该处确有可被信息降低的模型误差"，且不被偶然噪声（aleatoric）或传感器故障污染？
- **Q2（续航的可证明性）**：如何让续航证书在能量模型误差与执行抖动下仍保守成立，并使"探索预算"与"返航储备"在代数上不可混用？
- **Q3（探索-安全的复合）**：空白驱动的探索如何被 v9 的 M₀ / SpatialCert / AC 中止点 / ER 完整屏蔽，使任何被接受的探索都可回退，且 GEA 失效时严格退回 v9？
- **Q4（负空间诚实性）**：如何让系统对外主张的能力不超过登记簿中已验证的证据，并在"结构上不可达"的空白上明确说"不知道"而非"已覆盖"？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 空白可计算律（Computable Ignorance, EGM）**
无知必须是带证据的在线状态量，而非隐喻：G(x,a) 由集成分歧、覆盖密度、主张-证据缺口三源构成；只有同时满足"可约、可达、可安全探"的单元才进入探索候选；aleatoric 噪声与故障经重复试验判别后隔离（quarantine），不消耗探索预算。

**P14 续航不可挪用律（Non-fungible Endurance, EC）**
E_reserve 是硬下界，任何策略、任何优化、任何探索都不得动用；每周期检查 E_rem ≥ E_safe_stop(s) + E_reserve；探索预算 E_expl 显式扣除 Ê_return 与 E_reserve，并在代数上与 v9 的 20ms 算力预算分离，二者不可互相借贷。

**P15 探索受屏蔽律（Safety-Shielded Exploration, GEA）**
探索只允许改变 AC 的候选采样权重，不允许绕过块证书：每个探索块必须通过 Ĉ_t 有效、P_t 非空、M₀ 硬检查与 EC；任一失败即放弃该提案并记入 NSL；EGM / NSL / GEA / EC 任一失效即注入 e^⊥，严格等价 v9。

## 3. 与基线的接口（如何退化）

- EGM / NSL 失效 ⇒ G≡0、不产生探索提案，AC 采样恢复正常，等价 v9（无探索）；
- GEA 失效 ⇒ 无提案被选中，等价 v9；
- EC 软失效（能量模型残差超阈但返航估计仍可用）⇒ EFSM 进入 conservative，关闭探索、保留 v9 任务路径；
- EC 硬失效（续航不变式受威胁 / 返航估计不可信）⇒ EFSM 进入 return / safe_stop，放弃任务、能量最优返航；
- EFSM 进入 conservative / return / safe_stop ⇒ 探索关闭，v9 主闭环不变；
- v9 的 MW / AC / ID / DA / SPR / Cal 任一失效 ⇒ 继续沿 v9 的契约中立元链退化到 v8 / v7 / v6；
- 全部失效 ⇒ 安全停驻（速度衰减到 0），仅保留最小感知与断联心跳。

## 4. 预期贡献

1. **可计算的研究空白**：EGM + NSL 把"我不知道什么"变成带 LCB-IG 与负结果的在线状态，附"结构不可达空白"的显式登记；
2. **能量域的停车不变式**：续航证书把"能回来"从经验保障升级为可证明性质（引理 87），并与 v9 的距离域中止点解耦；
3. **带安全屏蔽的探索分配**：探索只重加权 AC 候选、不改变安全可行集，预算化次模背包给出可证明近似（引理 89–90）；
4. **续航-认知-安全三者的显式权衡**：实验 E571–E590 覆盖空白校准、能量模型失配、负空间审计、低电退化与端到端任务。

## 5. 本轮最大风险

**一句话**：用有限续航去填研究空白，最大的风险是——空白图谱把不可约的偶然噪声或传感器故障误判为"可填的空白"，而续航证书又建立在乐观的能量模型上，于是系统会把本应留给返航的电量烧在零信息回报的探索上，在真正需要返航时才发现"能回来"从未被证明。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-GEM**（Gap-aware Endurance Management = 研究空白图谱 × 续航证书 × 空白-续航分配）

> **背景**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> **本轮灵感**：「研究空白」×「续航能力」
> **继承纪律**：MetricVoiceGauge 九不变式（CVC-闭环、SpatialCert、RT-CVC、FaultCert、PrimitiveGraph、严格退化链、OTL、GCT、ER）与 v9 的分块证书执行 / 契约中间件 / 创新蒸馏全部保留。新组件一律为**可选增强**：任一环节不可用 ⇒ 注入能量-认知中立元 e^⊥，严格等价退回 v9 的"只利用、不探索"（引理 91），而非行为漂移。

## 研究空白声明（本轮元层贡献）

v1–v9 反复回答两个问题："当前是否安全？""模块是否失效？" 但它们共享两个未言明假设：

1. **无知的缺席**：DA-ML 只给标量 Δ_dom（分布变了），ID 只给标量 c_m（模块贡献），没有任何状态量刻画"哪块状态-动作区域没被验证过、探一次能换回多少可约误差"。文献中的 research gap 是离线叙事，v1–v9 从未把它在线化、可计算化。
2. **能量的缺席**：所有预算都是周期内 20ms 算力（v9 引理 86），整场任务的续航只在实验里被统计（E560 总功耗 ≤25W），从未进入安全论证。于是"安全"与"能回来"是两套互不相干的论证。

本轮把这两个空白同时补上：用 **EGM + NSL** 让无知可计算且不夸大，用 **EC + 续航不变式** 让返航能量不可挪用，再用 **GEA + 探索屏蔽** 把"用有限续航填空白"约束在 v9 的安全可行集内。

- **Level-0 normal**：EGM / NSL / EC / GEA / EFSM 全部在线，探索按预算开启；
- **Level-1 EGM / NSL 失效** ⇒ G≡0，无探索提案，AC 采样均匀化，等价 v9；
- **Level-2 GEA 失效** ⇒ 无提案被选中，等价 v9；
- **Level-3 EC 软失效**（能量模型残差超阈）⇒ EFSM=conservative，关闭探索，保留 v9 任务路径；
- **Level-4 EC 硬失效 / EFSM=return** ⇒ 放弃任务，能量最优返航；无法返航则 safe_stop；

## 1. 符号体系增量（定义 540–549）

| 符号 | 含义 |
|---|---|
| G_t(x,a) ∈ [0,1] | 研究空白密度（定义 540） |
| H_ens, ρ_cov, M_claim | 集成分歧、覆盖密度、主张-证据缺口（三源） |
| 𝒢_t = {c} | 研究空白图谱：离散单元集合（定义 541） |
| st_c ∈ {unknown, null, informative, quarantined} | 空白单元四态（定义 541） |
| π_p = (R_p, w_p, H_p) | 探索提案：目标区域、AC 采样偏置权重、步数视界（定义 542） |
| EC = (E_rem, Ê_probe, Ê_ret, E_reserve, margin, valid) | 续航证书（定义 543） |
| E_expl | 本次宏观节拍可用于探索的能量上界（定义 545） |
| α | 任务总能量中允许用于探索的比例（默认 0.15） |
| EFSM ∈ {normal, conservative, return, safe_stop} | 续航模式（定义 546） |
| ℒ | 研究空白登记簿条目集合（定义 547） |
| ÎG_lcb(R) | 信息增益的保守下置信界（定义 548） |
| e^⊥ | 能量-认知中立元：Ê=0、ΔG=0、探索关闭（定义 549） |

**新增定义 540（研究空白密度 EpistemicGapDensity）** 对状态-动作点 (x,a)：
```
G_t(x,a) = clip( w_u · H_ens(x,a)/H_max
               + w_c · (1 − ρ_cov(x,a))
               + w_v · M_claim(x,a), 0, 1 )
```
其中 H_ens 为集成前向模型/策略的预测分歧（互信息或方差迹），ρ_cov ∈ [0,1] 为局部覆盖密度（对已访问状态的核密度归一），M_claim ∈ [0,1] 为"对外主张能力 − NSL 已验证能力"的局部缺口（定义 547）。默认 w=(0.45, 0.30, 0.25)。三项均为在线可观测量；G 高**不**直接等于可探索——还须经定义 548 的可约性判别。

**新增定义 541（研究空白图谱 EpistemicGapMap, EGM）** 自适应分辨率的哈希网格 𝒢_t，每单元 c 存 (G, n_visit, last_probe, ÎG_lcb, Ê_probe, st_c)。四态迁移：
- `unknown → informative`：探针后 H_ens 显著下降（≥ δ_H）且 NSL 记为 informative；
- `unknown → null`：探针后 H_ens 不降（< δ_H）但未被判为噪声；
- `unknown → quarantined`：重复试验判别为 aleatoric（见定义 548）或结构不可达；
- `informative/null → unknown`：G 因新观测重新升高超过 τ_gap 时重开（有限寿命 TTL 防陈旧）。
`quarantined` 单元永不进入探索候选，但保留在图中供审计（"我们明确知道这里学不到东西"）。

**新增定义 542（探索提案 ProbeProposal）** π_p = (R_p ⊆ X×A, w_p ∈ [0, w_max], H_p ≤ K_max·B)，其中 w_p 是注入 AC 采样分布的偏置权重，H_p 为探索视界，B 为块数上界。提案**不是动作序列**，而是"把 AC 的候选采样向 R_p 倾斜"的请求；最终动作仍由 AC 生成并通过 Ĉ_t 与 P_t 校验。

**新增定义 543（续航证书 EnduranceCertificate, EC）** 保守能量前向模型 F_E 对块 ζ 给出 (μ_E, σ_E)，取 Ê = μ_E + k_E·σ_E（k_E=2）。证书：
```
valid ⇔ E_rem − Ê_probe − Ê_ret ≥ E_reserve + margin
        ∧ E_rem ≥ Ê_safe_stop(s_t) + E_reserve
```
Ê_ret 为从当前状态到最近安全航点/停驻区的保守能耗，Ê_safe_stop 为最小 jerk 停驻能耗。margin ≥ 能量模型残差上界 δ_E（在线监控：|E_true − μ_E| 的滑窗分位数超阈即 EC 软失效）。E_reserve 是**硬下界**，不随任务收益、探索收益或竞争分数调整。

**新增定义 544（续航不变式 EnduranceInvariant）** 对任意时刻 t：
```
E_rem(t) ≥ E_safe_stop(s_t) + E_reserve
```
以 50Hz 硬检查执行（与 v9 的 M₀ 同优先级，优先于一切任务逻辑）。破坏即无条件 safe_stop；任何探索 / 性能请求不得绕过。该不变式是 v9 停车不变式 d_stop(p) 在能量域的严格对偶：一个保证"停得下"，一个保证"回得来"。

**新增定义 545（空白-续航分配器 GapEnduranceAllocator, GEA）** 每 T_alloc=1s 的宏观节拍，给定可行提案集 F_t（须 EC 有效且 ES 可屏蔽）：
```
E_expl = min( E_rem − Ê_ret − E_reserve − margin,  α·E_mission − E_spent )
maximize  Σ_{p∈S} ÎG_lcb(R_p)
s.t.      Σ_{p∈S} Ê_probe(p) ≤ E_expl,  |S| ≤ k_max,  S ⊆ F_t
```
以 ÎG_lcb/Ê 贪心求解。ÎG 对目标区域次模时可证明常数近似（引理 89）；所有成本用保守上界 Ê，故预算约束不会被突破。

**新增定义 546（续航模式状态机 EnduranceFSM, EFSM）** 令 E_need = Ê_ret + E_reserve：
- `normal`：E_rem ≥ E_need + E_expl_min（有余量探索）；
- `conservative`：E_need ≤ E_rem < E_need + E_expl_min（只利用、不探索，v9 路径）；
- `return`：E_rem < E_need + margin（放弃任务、能量最优返航）；
- `safe_stop`：定义 544 受威胁或返航不可信（最小能耗停驻）。
迁移带迟滞（relaxation 余量 h，防止在阈值附近抖振）；只有 `normal` 允许探索；进入 `conservative` 及以下即注入 e^⊥。

**新增定义 547（研究空白登记簿 NegativeSpaceLedger, NSL）** 持久化条目 ℓ=(区域, 探针摘要, 结果 ∈ {informative, null, unreachable, fault}, ΔG, 置信度, 时间戳, 证据指纹)。两条职责：
1. **反重复**：`null` / `unreachable` 条目降低对应区域 G（但保留可见性），避免把续航反复烧在同一空白上；
2. **反夸大**：对外能力主张必须引用 ℓ 中的 informative 证据；无证据主张使 M_claim 升高，即"没验证过的地方被标成更空白"，从机制上惩罚过度声称。`unreachable` 是显式的"结构空白"（本体限制导致），不是失败。

**新增定义 548（信息增益的保守估计与噪声判别）** 对区域 R：
```
ÎG_hat(R) = H_before(R) − E_{p∼π_R}[H_after(R)]          （集成/粒子估计）
ÎG_lcb(R) = max(0, ÎG_hat(R) − κ·σ_IG(R))                 （保守下界）
```
可约性判别（区分 epistemic 与 aleatoric）：对同一区域做**重复试验**（两次独立探针或同一状态重复观测），若 H_ens 高但重复观测的经验方差同样高且不随样本下降 ⇒ 判为 aleatoric / 故障，置 `quarantined`；若分歧可被新样本压低 ⇒ epistemic，置 `informative`。分配只用 ÎG_lcb，故"不确定自己是否学到"的探针不会被高估。

**新增定义 549（能量-认知中立元与退化 Energy-Cognitive Neutral Element, e^⊥）** e^⊥ 是探索组合的恒等元：加入 e^⊥ 探针满足 Ê=0、ΔG=0、Δ状态=0、ΔNSL=0。对任一 v10 新模块 m，注入 e^⊥ 后其端口读数与 v9 对应端口逐位一致：
```
E_total = E_v9(1 + 0·e^⊥) = E_v9,     G_effective = 0,     探索集合 = ∅
```
故 Level-1/2/3 退化在行为上严格等价 v9；与 v9 已有的 v^⊥ 退化链可交换复合（引理 91）。

## 2. 形式化定义（要点与升级）

**定义 493 / 495 / 521 / 524（六层指标、MetaWeight、DA-OTL）** 继承 v9 全部不变。
**升级定义 496（软证书，v10）** 五条件 δ_trigger 不变，另加探索门控：
```
δ_trigger = σ<τ_safe ∧ γ_grasp valid ∧ Δ_dom<τ_dom ∧ risk_SLAM<τ_SLAM ∧ Ĉ_t valid
            ∧ (EFSM = normal ⇒ EC valid)
```
注意：探索只在 `normal` 且 EC 有效时被允许；但 **v9 任务路径在 conservative 下照常运行**，探索门控不改变 v9 的安全触发条件。
**升级定义 531（软硬约束衔接）** M₀ 判据新增能量硬入口：定义 544 破坏 ⇒ 立即 safe_stop，优先于 AC 中止点选择与任何探索。
**升级定义 539（有效块长门控）** K_eff 另受续航门控：`EFSM ≠ normal ⇒ K_eff 不含探索偏置`，即退回 v9 的 Δ_dom/risk_SLAM 门控；探索偏置不改变 K_eff 上限。

# IP-357 EpistemicGapMap：研究空白图谱
class EpistemicGapMap:
    def __init__(self, ensembler, cov_kde, w=(0.45, 0.30, 0.25),
                 cell=0.05, tau_gap=0.6, delta_H=0.05):
        self.ens, self.cov, self.w = ensembler, cov_kde, w
        self.cell_size, self.tau_gap, self.delta_H = cell, tau_gap, delta_H
        self.cells = {}                         # cell -> GapCell

    def _cell(self, x, a):
        key = (tuple((x // self.cell_size).astype(int)), tuple(a))
        return self.cells.setdefault(key, GapCell())

    def update(self, x, a, claim_gap):
        c = self._cell(x, a)
        H = self.ens.disagreement(x, a)                  # 集成分歧
        rho = self.cov.density(x, a)                     # 覆盖密度
        G = clip(self.w[0]*H/self.ens.H_max
                 + self.w[1]*(1.0-rho)
                 + self.w[2]*claim_gap, 0.0, 1.0)         # 定义 540
        c.G = 0.9*c.G + 0.1*G
        c.n_visit += 1
        if c.G < self.tau_gap and c.state != 'quarantined':
            c.state = 'unknown'

    def top_proposals(self, k_max, energy_scale):
        cands = [c for c in self.cells.values()
                 if c.state == 'unknown' and c.G >= self.tau_gap]
        cands.sort(key=lambda c: lcb_ig(c) / energy_scale(c),
                   reverse=True)                          # 定义 545 的序
        return cands[:k_max]


# IP-358 NegativeSpaceLedger：研究空白登记簿
class NegativeSpaceLedger:
    def __init__(self):
        self.entries = []

    def record(self, region, probe_id, outcome, delta_G, conf, evidence):
        assert outcome in ('informative', 'null', 'unreachable', 'fault')
        self.entries.append(LedgerEntry(region, probe_id, outcome,
                                        delta_G, conf, evidence, now()))

    def claim_gap(self, region):
        """主张缺少 informative 证据 ⇒ M_claim 升高（定义 547）。"""
        ev = [e for e in self.entries if overlaps(e.region, region)]
        return 1.0 if not any(e.outcome == 'informative' for e in ev) else 0.0

    def mark(self, cell, outcome):
        cell.state = {'informative': 'informative',
                      'null': 'null',
                      'unreachable': 'quarantined',
                      'fault': 'quarantined'}[outcome]


# IP-359 EnduranceCertifier：续航证书器
class EnduranceCertifier:
    def __init__(self, energy_model, reserve, margin, k_sigma=2.0):
        self.FE, self.reserve, self.margin = energy_model, reserve, margin
        self.k = k_sigma
        self.residual_q = RunningQuantile(0.99)          # 在线残差监控

    def est(self, s, chunk):
        mu, sd = self.FE.predict(s, chunk)
        return mu + self.k*sd                           # 保守上界 Ê
    def e_ret(self, s):   return self.FE.return_to_safe(s)
    def e_stop(self, s):  return self.FE.safe_stop(s)

    def certify(self, s, chunk):
        E_probe, E_ret = self.est(s, chunk), self.e_ret(s)
        ok = (s.energy - E_probe - E_ret
              >= self.reserve + self.margin)            # 定义 543
        ok = ok and (s.energy >= self.e_stop(s) + self.reserve)
        return Cert(ok, E_probe, E_ret,
                    s.energy - E_probe - E_ret - self.reserve)

    def observe(self, s, chunk, E_true):
        self.residual_q.update(abs(E_true - self.FE.mean(s, chunk)))
        return self.residual_q.value <= self.margin    # 超阈 ⇒ EC 软失效


# IP-360 GapEnduranceAllocator：空白-续航分配器
class GapEnduranceAllocator:
    def __init__(self, egm, nsl, ec, alpha=0.15, k_max=3):
        self.egm, self.nsl, self.ec = egm, nsl, ec
        self.alpha, self.k_max = alpha, k_max
        self.spent = 0.0

    def select(self, s, mission_energy, efsm, shield):
        if efsm.mode != 'normal':
            return []                                   # 只利用 = v9（定义 546）
        E_expl = min(s.energy - self.ec.e_ret(s) - self.ec.reserve
                     - self.ec.margin,
                     self.alpha*mission_energy - self.spent)   # 定义 545
        cands = []
        for c in self.egm.top_proposals(self.k_max*3, lambda c: c.E_probe):
            p = Probe(c.region, w=min(1.0, c.G), H=...)
            if not self.ec.certify(s, p).valid:
                self.nsl.record(c.region, p.id, 'unreachable', 0, 1, 'EC')
                continue
            if not shield.feasible(p):                  # v9 证书/中止点不可达
                self.nsl.record(c.region, p.id, 'unreachable', 0, 1, 'shield')
                continue
            cands.append((p, lcb_ig(c), self.ec.est(s, p)))
        chosen, used = [], 0.0
        for p, ig, cost in sorted(cands, key=lambda t: t[1]/t[2], reverse=True):
            if used + cost <= E_expl and len(chosen) < self.k_max:   # 次模背包贪心
                chosen.append(p); used += cost
        self.spent += used
        return chosen


# IP-361 EnduranceFSM：续航模式状态机
class EnduranceFSM:
    def __init__(self, ec, e_expl_min, hysteresis):
        self.ec, self.e_min, self.h = ec, e_expl_min, hysteresis
        self.mode = 'normal'

    def step(self, s):
        need = self.ec.e_ret(s) + self.ec.reserve
        if self.mode in ('normal', 'conservative'):
            if s.energy < need + self.h:            self.mode = 'return'
            elif s.energy < need + self.e_min + self.h: self.mode = 'conservative'
            else:                                    self.mode = 'normal'
        elif self.mode == 'return':
            if s.energy < self.ec.e_stop(s) + self.ec.reserve + self.h:
                self.mode = 'safe_stop'
            elif s.energy > need + self.e_min + 2*self.h:
                self.mode = 'normal'
        return self.mode


# IP-362 ExplorationShield：探索只重加权 AC 候选，不改变可行集
class ExplorationShield:
    def __init__(self, ac):
        self.ac = ac
    def feasible(self, probe):
        return self.ac.has_certified_candidate(probe.region, probe.H)
    def bias(self, chunk, probe):                       # 注入 AC 采样分布
        return self.ac.sampling_weight(chunk) * (1 + probe.w)

## 4. 推导

**引理 87（续航不变式的归纳保持与可返航性）** 设在 t₀ 有 E_rem ≥ E_safe_stop + E_reserve，且能量模型满足真值误差上界 |E_true − μ_E| ≤ k_E σ_E + δ_E，证书 margin ≥ δ_E。则对任意被接受的动作 / 块，t₀ 之后不变式仍成立；且当 EFSM 进入 return 时必存在能量最优返航轨迹。证明：对单步动作，接受条件给出 E_rem' = E_rem − E_true ≥ E_rem − (μ_E + k_E σ_E) − δ_E ≥ E_rem − Ê − δ_E；由 Ê 的构造与 margin 定义，EC 有效 ⇒ E_rem' ≥ Ê_ret + E_reserve ≥ E_safe_stop + E_reserve（返航能耗不小于最小停驻能耗）。对时间归纳即得不变式；EFSM 的 return 触发阈值含 margin，故触发时 E_rem ≥ Ê_ret + E_reserve，返航轨迹存在。∎

**引理 88（空白的校准与"不夸大"诚实性）** 在集成模型校准假设下，LCB-IG 满足 P(ÎG_lcb(R) ≤ IG_true(R)) ≥ 1−δ；重复试验判别把 aleatoric / 故障单元的误纳率压到 δ 以下。因此 `unknown` 且 ÎG_lcb>0 的单元以 1−δ 置信包含可约的 epistemic 空白；`quarantined` 单元不会被计入可探索收益；NSL 的 claim_gap 使无 informative 证据的区域 M_claim 升高。性质是**可靠但不完备**：可能漏掉部分空白（假阴性），但不会系统性伪造可填空白（假阳性受 δ 约束），也不会把"没探过"声称为"已覆盖"。∎

**引理 89（GEA 的近似最优与预算安全）** 设 ÎG 对提案集合次模、成本可加。GEA 的 IG/cost 贪心给出 S 满足 Σ_{p∈S} Ê ≤ E_expl，且 Σ ÎG(S) ≥ ρ·OPT，其中一般背包下 ρ ≥ (1−1/e)/2，所有候选成本相同时退化为经典 (1−1/e)；若预算充足，Sviridenko 枚举可提升至 (1−1/e)。预算安全由所有成本取保守上界 Ê 直接得到；探索实际能耗 ≤ E_expl ≤ E_rem − Ê_ret − E_reserve − margin，故返航储备不被触碰。∎

**引理 90（探索-安全屏蔽与 v9 不变式传递）** 探索动作集合是 AC 在偏置采样下产出的**证书有效块**的子集：每个块都满足 Ĉ_t 有效、P_t 非空、M₀ 硬检查与 v9 的 ER/5 维风险约束。故任一被执行的探索块都属于 v9 的安全可行集，v9 引理 80–86 对全部时刻 t 成立，与探索是否开启无关。若探索偏置导致无证书有效候选，则提案被拒并记入 NSL，v9 继续正常执行。∎

**引理 91（退化等价与有界探索开销）** 对 EGM / NSL / GEA / EC / EFSM 任一注入 e^⊥，均有 G_effective≡0 或探索集合=∅ 且 Ê_expl=0，故 E_total = E_v9、动作序列与 v9 逐位一致（定义 549），即 Level-1/2/3 严格等价 v9。探索开启时，任务能量被探索占用不超过 α·E_mission（定义 545 的硬截断），故任务可用能量 ≥ (1−α)·E_mission；任务进展损失以 α 为界，不随探索次数无界增长。e^⊥ 与 v9 的 v^⊥ 可交换复合：先注入 v^⊥ 再注入 e^⊥ = 先 e^⊥ 再 v^⊥ = v9。∎

**引理 92（探索终止 / 无能量饿死）** 设总空白量有界，每个 informative 探针使对应单元 ÎG_lcb 至少下降 δ>0，且 null / unreachable 单元被置为 `null` / `quarantined`（不再进入候选）；重开需 G 超过 τ_gap 且受 TTL 限制。则 informative 探针次数 ≤ G_total/δ，null 探针次数 ≤ |𝒢|，探索总能耗 ≤ (G_total/δ + |𝒢|)·Ê_max；探索在有限能量内终止，不会以"永远差一点"的方式耗光续航。∎

## 8. 本轮最大风险

**一句话**：用有限续航去填研究空白，最大的风险是——空白图谱把不可约的偶然噪声或传感器故障误判为"可填的空白"，而续航证书又建立在乐观的能量模型上，于是系统会把本应留给返航的电量烧在零信息回报的探索上，在真正需要返航时才发现"能回来"从未被证明。
