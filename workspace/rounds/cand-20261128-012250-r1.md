### 第 1 轮灵感驱动研究记录（新循环；继承 CADVS-v4）

**灵感词**：轻量化设计、指标体系

**继承关系**：第 4 轮 CADVS-v4（IP-489~492）在 v3 五锚点（3DCF / MSRG / HICK / EEK / LTEM + FFA）之上追加价值锚 VACK 与平衡锚 BCK，形成七硬门 kc_evidence_forged_v4 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem ∧ kc_val ∧ kc_bal，fail-closed；软评分 ECS_v4 = ECS_v3 · η_val · η_bal；执行集 Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。v4 的最大遗留风险是 VACK/BCK 的计算开销可能击穿 1 kHz 控制环。本轮不推翻 v4，而是用「轻量化设计」把「同样的证据」压缩到「更少的算力」，用「指标体系」把「证据质量」变成可度量、可审计、可防博弈的对象，形成 CADVS-v5（IP-493~496）。执行集升级为 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **轻量化设计不是「降低证据标准」，而是「降低单位证据的算力」**。v4 的 VACK（偏好模型推理，10–50 ms）与 BCK（全身动力学 + 接触锥 QP，1–5 ms）本质上是在控制环里做「昂贵的真理查询」。轻量化的正确姿势不是删掉硬门，而是给每个昂贵证书配一个**保守的、可证明的廉价代理**，只在代理无法判定时才回退到昂贵教师。三条机制互补：
   (a) **保守编译**：用蒸馏/查表/量化得到代理 g_i，并用保形预测（conformal prediction）校准出**单侧下界**，使 g_i 以高概率不超过教师 f_i；于是 g_i ≥ τ_i ⇒ f_i ≥ τ_i，代理通过集是教师通过集的子集，安全不被交易掉。
   (b) **任意时间级联（anytime cascade）**：从极便宜的粗界开始，逐级加细；任一时刻只要「下界 ≥ 阈值」即可安全接受，「上界 < 阈值」即可安全拒绝；预算耗尽仍无法判定则 fail-closed 拒绝。**决策永远可靠，只有完备率随预算下降**。
   (c) **事件触发 + 证书管道**：在参考状态 x_ref 处算一次证书，利用 f_i 的李普希茨常数 L_i 构造认证管道半径 r_i = (g_i(x_ref) − τ_i)/L_i；只要状态仍在管道内且未过期，就复用缓存证书。这把「每周期都算」变成「出管道才算」，算力随状态稳定性自适应。
   关键点：每一条捷径都带一个数学不变式；轻量化是证书的**精化（refinement）**，不是弱化。

2. **指标体系：从「宣称可信」到「可度量、可审计、可防博弈」**。v1~v4 一直在堆锚点，却没有回答「我们凭什么说系统更可信」。本轮建立分层证据指标体系 EIS：顶层安全维度采用**非补偿（non-compensatory）**聚合（min / 字典序 / 否决），软维度采用**加权几何平均**（对数线性）；这正好解释了 ECS 的乘性形式——它天然对「任一因子为零」不可补偿，且对子指标的尺度缩放保持排序不变。更重要的是引入**元指标**：校准误差 ECE、分布漂移、以及 Goodhart 风险 G_risk（代理指标与真实目标的偏离 + 审计覆盖率缺口）。指标体系必须把「指标本身是否被博弈」也当作一等公民，否则越优化越偏离。

3. **预算-证据 Pareto 前沿**。给定控制环预算 B（如 1 ms），把「证据质量」Q = (soundness, coverage, timeliness, calibration) 与「算力」C 放在同一坐标系，定义证据-算力 Pareto 前沿；调度器 BACS 在每周期选一个可行工作点。安全不靠「永远算完」，而靠「算不完就安全回退」：调度不可行 ⇒ 进入 S_stop / 软化阻抗，而不是带着未认证规则继续跑。

**关键洞见**：v4 回答「需要哪些证据」；v5 回答「每单位证据要花多少算力，以及证据质量如何被度量与防伪」。轻量证书把「计算可行性」变成「安全保证的一部分」，指标体系把「可信」从口号变成可反驳的测量命题。由于 kc_i^light ⇒ kc_i（高概率）且额外要求新鲜性与预算可行，八硬门版本仍只缩不涨：Exec_CADVS-v5 ⊆ Exec_CADVS-v4。

**形式化目标（增量）**：
1. 定义轻量证书 LCT_i = (g_i, x_ref, t_ref, r_i, T_i, δ_i, c_i) 与轻量硬门 kc_i^light = (g_i(x_ref) ≥ τ_i) ∧ d(x,x_ref) ≤ r_i ∧ (t−t_ref) ≤ T_i；证明 kc_i^light ⇒ kc_i（以概率 ≥ 1−δ_i）。
2. 定义保守编译器 LCC：保形单侧下界 + 蒸馏/查表/量化 + 李普希茨管道 + 任意时间级联；证明 anytime 决策的可靠性与预算-完备率单调性。
3. 定义证据指标体系 EIS = (V, ≼, φ, w, A, G_risk)：分层、归一化、非补偿顶层、几何软聚合、Goodhart 元指标；证明非补偿性、尺度不变性，并给出「指标不可完备性（Goodhart 不可能）命题」。
4. 定义预算感知证书调度器 BACS：在 Σc_i ≤ B 与最坏新鲜度约束下选择「新鲜计算 / 管道复用 / 回退」，不可行即 fail-closed。
5. 定义 EFA-v5：八硬门 kc_evidence_forged_v5 = kc_evidence_forged_v4 ∧ kc_fresh，其中每个 kc_i 以 kc_i^light 实现；软评分 ECS_v5 = ECS_v4 · η_fresh（η_fresh = 1 − staleness/T_max）。
6. 定义 Exec_CADVS-v5 ⊆ Exec_CADVS-v4：轻量代理只做保守替换，kc_fresh 只加不减，故嵌套严格成立。
7. 给出实验：同一安全水平下算力/延迟/能耗下降，以及轻量化带来的 FRR/覆盖率代价与指标体系的可审计性。

**本轮最大风险**：**轻量证书的保守性依赖保形可交换性与李普希茨界，一旦在线分布漂移使这些假设失效，代理会从「保守下界」静默变成「乐观估计」，在预算调度器的掩护下放行不安全执行——即用可计算的指标体系换来了不可验证的安全假象。**

### IP-493 LCC：轻量证书编译器（离线编译 + 在线管道检查）

```python
@dataclass
class LightCertificate:
    g_ref: float          # 代理在参考点的评分 g_i(x_ref)
    x_ref: np.ndarray
    t_ref: float
    r: float              # 认证管道半径 r_i = (g_ref - tau)/L
    T: float              # 新鲜度时域
    delta: float          # 保形误覆盖率
    cost: float

@dataclass
class LightweightCertificateCompiler:
    """LCC：把教师 f_i 编译为保守代理 g_i；输出可复用、可证明的 LCT"""
    tau: float
    lip: float                     # 李普希茨常数上界 L_i（离线估计 + 安全放大）
    delta: float = 0.01            # 保形误覆盖率
    calib_scores: list[float] = field(default_factory=list)  # 保形校准残差 f-g

    def conformal_lower(self, g_hat: float) -> float:
        # 保形分位数：以 1-delta 概率保证 g <= f
        q = np.quantile(self.calib_scores, 1.0 - self.delta, method="higher")
        return g_hat - q

    def compile(self, x_ref: np.ndarray, t_ref: float) -> LightCertificate:
        g_hat = self.surrogate(x_ref)            # 蒸馏/查表/量化代理
        g = self.conformal_lower(g_hat)          # 单侧保守下界
        r = max(0.0, (g - self.tau) / self.lip)  # 管道半径
        return LightCertificate(g, x_ref, t_ref, r, self.T, self.delta, self.cost)

    def kc_light(self, lct: LightCertificate, x: np.ndarray, t: float) -> bool:
        """轻量硬门：代理达标 ∧ 状态在认证管道内 ∧ 证书未过期"""
        return (lct.g_ref >= self.tau
                and np.linalg.norm(x - lct.x_ref) <= lct.r
                and (t - lct.t_ref) <= lct.T)

    def anytime_decide(self, x, budget: float) -> tuple[bool, bool]:
        """任意时间级联：返回 (已判定?, 接受?)。预算耗尽未判定 ⇒ (False, False) fail-closed"""
        spent = 0.0
        for k, (lower, upper, cost) in enumerate(self.cascade(x)):
            if spent + cost > budget:
                return False, False            # 预算耗尽，保守拒绝
            spent += cost
            if lower >= self.tau:
                return True, True              # 下界过阈，安全接受
            if upper < self.tau:
                return True, False             # 上界低于阈，安全拒绝
        return False, False

    def surrogate(self, x) -> float: ...       # 蒸馏/查表/量化代理
    def cascade(self, x): ...                  # 由粗到细的 (L_k, U_k, c_k) 序列
```

            return 0.0

### IP-495 BACS：预算感知证书调度器（控制环内，O(n log n)，n=8）

```python
@dataclass
class BudgetAwareCertificateScheduler:
    """BACS：在预算 B 与新鲜度约束下，为每个硬门选择 FRESH/TUBE/FALLBACK"""
    budget: float = 1e-3
    max_staleness: dict[str, float] = field(default_factory=dict)

    def schedule(self, gates, now: float) -> dict[str, str]:
        # 1) 先验：管道有效且未过期的门 → TUBE（零算力）
        plan = {}
        pending = []
        for g in gates:
            if g.tube_valid(now) and g.fresh(now):
                plan[g.name] = "TUBE"
            else:
                pending.append(g)
        # 2) 剩余门按「风险 × 陈旧度 / 代价」排序（EDF + 风险优先级）
        pending.sort(key=lambda g: -(g.risk * g.staleness(now) / max(g.cost, 1e-9)))
        # 3) 贪心装入预算；装不下的门 → FALLBACK（触发安全回退）
        spent = 0.0
        for g in pending:
            if spent + g.cost <= self.budget:
                plan[g.name] = "FRESH"
                spent += g.cost
            else:
                plan[g.name] = "FALLBACK"
        return plan

    def kc_budget(self, plan) -> bool:
        """预算可行且无门处于 FALLBACK 才算通过；否则整体 fail-closed"""
        return all(v != "FALLBACK" for v in plan.values())
```

### IP-496 EFA-v5：八硬门 + 软评分 + 轻量证据铸造流水线

```python
@dataclass
class EvidenceForgingAssemblerV5:
    """EFA-v5：轻量八硬门 fail-closed；ECS_v5 = ECS_v4 · η_fresh"""
    lcc: LightweightCertificateCompiler
    eis: EvidenceIndicatorSystem
    bacs: BudgetAwareCertificateScheduler
    v4: EvidenceForgingAssemblerV4
    T_max: float = 0.05

    def hard_gate(self, x, t_now, lcts: dict[str, LightCertificate],
                  plan: dict[str, str]) -> tuple[bool, str]:
        # 0) 预算可行门：任一 FALLBACK 即安全回退
        if not self.bacs.kc_budget(plan):
            return False, "BUDGET_INFEASIBLE"
        # 1) 新鲜度门：所有缓存证书未过期
        if not all((t_now - l.t_ref) <= l.T for l in lcts.values()):
            return False, "CERT_STALE"
        # 2) 七个轻量硬门（保守代理 ⇒ 教师语义）
        for name, lct in lcts.items():
            if plan[name] == "FRESH":
                ok = self.lcc.kc_light(lct, x, t_now)
            else:  # TUBE：管道有效即复用
                ok = (lct.g_ref >= self.lcc.tau
                      and np.linalg.norm(x - lct.x_ref) <= lct.r)
            if not ok:
                return False, f"{name.upper()}_UNPROVEN"
        return True, "FORGED_LIGHT"

    def ecs_v5(self, base_ecs_v4: float, max_staleness: float) -> float:
        eta_fresh = max(0.0, 1.0 - max_staleness / self.T_max)
        return base_ecs_v4 * eta_fresh
```

### 集成流水线（v4 → v5）

```
离线编译（一次性/慢时域）：
  教师 f_i（VACK/BCK/EEK/…）──▶ 蒸馏/量化/查表 ──▶ 代理 g_i
  ──▶ 保形校准（留出集）──▶ 分位数 q_i、δ_i
  ──▶ 李普希茨估计（区间上界）──▶ L_i
  ──▶ 编译 LCT_i 模板

在线慢时域（秒级，漂移监测）：
  EIS 审计 ──▶ ECE / D_drift / G_risk
  ├─ 漂移超阈 ⇒ 触发重校准（保形分位数 + L_i）或回退教师
  └─ 指标被博弈 ⇒ 轮换隐藏审计集、加严否决维度

控制环（1 kHz，预算 B）：
  BACS.schedule(gates, now)
  ├─ TUBE：O(d) 管道检查，零重算
  ├─ FRESH：运行轻量代理 / 任意时间级联
  └─ FALLBACK：安全回退（S_stop / 软化阻抗 / 教师慢路径）
  EFA-v5.hard_gate(plan, lcts)
  ├─ BUDGET_INFEASIBLE → S_stop（fail-closed）
  ├─ CERT_STALE        → 强制重算或安全回退
  └─ *_UNPROVEN        → 对应 v4 回退策略
```

## 4. 正确性论证（增量更新）

### 引理 43（轻量证书的保守性与管道不变式）

**陈述**：设教师 f_i、阈值 τ_i；代理 g_i 满足保形单侧下界 P(g_i(x) ≤ f_i(x)) ≥ 1−δ_i；f_i 为 L_i-李普希茨。令 g = g_i(x_ref)，r = max(0,(g−τ_i)/L_i)。若 kc_i^light(x,t) 成立，即 g ≥ τ_i、d(x,x_ref) ≤ r、t−t_ref ≤ T_i，则以概率 ≥ 1−δ_i 有 f_i(x) ≥ τ_i（即 kc_i 成立）。

**证明**：由李普希茨性，f_i(x) ≥ f_i(x_ref) − L_i d(x,x_ref) ≥ f_i(x_ref) − L_i r。由保形下界，f_i(x_ref) ≥ g（概率 ≥ 1−δ_i）。故 f_i(x) ≥ g − L_i r = g − (g−τ_i) = τ_i。∎

**工程含义**：管道复用不是「拍脑袋缓存」，而是带李普希茨认证的安全捷径；r 随代理裕度 g−τ_i 自适应，越接近阈值管道越窄，自动趋近逐周期重算。

### 引理 44（任意时间级联的预算-完备性）

**陈述**：设级联第 k 级给出下界 L_k ≤ f_i ≤ U_k，且 L_0 ≤ L_1 ≤ …、U_0 ≥ U_1 ≥ …，累计代价 c_(k) 递增。决策规则：L_k ≥ τ_i 则接受，U_k < τ_i 则拒绝，否则继续；预算耗尽未判定则拒绝。则：(i) 任何已做出的决策都与教师判定一致；(ii) 判定概率（完备率）随预算单调不减；(iii) 预算为零时退化为纯 fail-closed。

**证明**：(i) 接受时 f_i ≥ L_k ≥ τ_i；拒绝时 f_i ≤ U_k < τ_i。(ii) 增加预算只可能多执行若干级，已判定结果不变，未判定集合只减不增。(iii) 无级可执行，直接拒绝。∎

**工程含义**：轻量化把「实时性 vs 安全」的硬冲突转化为「实时性 vs 覆盖率」的软权衡——安全永不妥协，只牺牲接受率。

### 引理 45（指标体系的非补偿性与尺度不变性）

**陈述**：设 EIS 顶层否决聚合 A_veto = min_{v∈V_veto} φ_v，软聚合 A_soft = ∏_j φ_j^{w_j}（Σw_j=1），总分 A = A_veto · A_soft。则：(i) A 对每个 φ 单调不减；(ii) 任一否决指标为 0 ⇒ A=0（非补偿）；(iii) 若 φ_j' = c_j φ_j（c_j>0），则 A' = (∏ c_j^{w_j}) A，排序不变（尺度不变）；(iv) ECS 的乘性形式 ECS_v4 = ECS_v3·η_val·η_bal 正是 A_soft 的特例（对数线性）。

**证明**：(i)(ii) 由 min 与幂函数的单调性；(iii) 直接代入；(iv) 取对数即加权和。∎

**工程含义**：硬门是「非补偿否决」，软评分是「可补偿但零点吸收」；这为「为什么安全不能用加权和平均掉」提供了指标理论依据。

### 命题 1（指标不可完备性 / Goodhart 不可能定理）

**陈述**：设 I: Π→[0,1] 为任意由 m 个可测特征计算的有限指标体系，T: Π→[0,1] 为真实目标。若策略空间 Π 足够丰富（存在在未测维度上任意取值的策略），则对任意 ε>0，存在策略 π 使 I(π) ≥ 1−ε 而 T(π) ≤ ε。

**证明（构造）**：取 I-最优策略 π0 的可测特征向量；构造 π 使其 m 个可测特征与 π0 相同，但在某个未被 I 测量的有害维度上取最差值。由于 I 只依赖 m 个特征，I(π)=I(π0) ≥ 1−ε；而 T(π) ≤ ε。∎

**推论**：不存在对所有目标都「忠实」的有限指标体系；指标优化的安全性只能相对于**审计覆盖的维度**成立。因此 EIS 必须包含元指标 G_risk，并用隐藏审计、轮换指标、限制优化压力来界定威胁模型，而不是宣称「指标即真理」。

### 引理 46（Goodhart 风险的审计估计误差）

**陈述**：若真实目标 T ∈ [0,1]，独立审计样本 n 个，则经验 G_risk 的估计误差以概率 ≥ 1−δ 不超过 √(log(2/δ)/(2n))。

**证明**：Hoeffding 不等式直接给出。∎

**工程含义**：G_risk 可报告置信区间；审计样本不足时，指标体系的结论必须降级为「不可判定」，不得当作安全证据。

### 定理 v5（执行集收缩、预算安全与指标非补偿）

**陈述**：在以下假设下：(C1) 每个代理 g_i 满足保形单侧下界（误覆盖 δ_i）；(C2) 李普希茨上界 L_i 有效；(C3) 新鲜度时域 T_i 被遵守；(C4) BACS 对任何不可行调度执行 fail-closed 回退；(C5) 继承 v4 的 (B1)~(B6)。则：
(i) Exec_CADVS-v5 ⊆ Exec_CADVS-v4，且若 kc_fresh 非恒真则严格 ⊂；
(ii) 以概率 ≥ 1−Σ_i δ_i，不存在因轻量编译而放行的不安全执行；
(iii) 任意时间级联的已判定决策与教师一致，完备率随预算单调；
(iv) EIS 满足非补偿性与尺度不变性；G_risk 的估计误差由引理 46 界；指标不可完备性（命题 1）界定了任何安全声明的审计边界。

**证明**：(i) 每个 kc_i^light ⇒ kc_i（引理 43），且 v5 额外合取 kc_fresh 与 kc_budget，故执行集只缩不涨；严格性由存在「教师通过但缓存过期/管道失效」的路径保证。(ii) 对七门用联合界 Σδ_i。(iii) 引理 44。(iv) 引理 45、46 与命题 1。∎

**诚实声明**：轻量化不是免费午餐——它把安全保证从「确定性」降为「高概率 + 假设成立」，并以 FRR/覆盖率为代价。若分布漂移破坏保形可交换性，或 L_i 被低估，则引理 43 失效，且失效是**静默的**（代理仍输出看似合理的分数）。这是本轮最需要防守的边界。

## 5. 实验设计与初步结果（仿真，单机 v5；舰队/实机列入后续轮次）

### 5.1 实验设计

- **平台**：MuJoCo 3.x + MJX + 实机 Panda（后续）；算力剖析在 Jetson Orin / 桌面 CPU / FPGA 查表三种后端。
- **对照**：v4-full；v5-light（完整）；消融 A1（无保形裕度，朴素蒸馏）、A2（无管道，逐周期重算）、A3（无新鲜度门）、A4（无 BACS，固定轮询）、A5（EIS 改为加权和，补偿式）、A6（无隐藏审计，仅用公开指标）。
- **协议**：
  (a) 算力压测：1 kHz 控制环，统计延迟 P50/P99/P99.9、丢帧率、教师调用比例、能耗；
  (b) 安全等价性：同一场景下 v4 与 v5 的接受集差异，验证 FAR 不升、测量 FRR/覆盖率代价；
  (c) 分布漂移：光照、载荷、摩擦、传感器老化；测保形覆盖率是否跌破 1−δ，触发重校准的频率；
  (d) 指标博弈：让优化器直接最大化 EIS 公开指标（含 A5 补偿式对照），测真实安全退化与 G_risk 检出率；
  (e) 管道有效性：测实际状态轨迹落在认证管道内的比例与平均管道寿命。
- **指标**：FAR、FRR、覆盖率、任务成功率、延迟分位数、丢帧率、教师调用比例、能耗、ECE、D_drift、G_risk、ECS_v5 与失败 AUC、Pareto 超体积。

## 7. 本轮最大风险（最终确认）

**一句话**：**轻量证书的保守性依赖保形可交换性与李普希茨界，一旦在线分布漂移使这些假设失效，代理会从「保守下界」静默变成「乐观估计」，在预算调度器的掩护下放行不安全执行——即用可计算的指标体系换来了不可验证的安全假象。**
