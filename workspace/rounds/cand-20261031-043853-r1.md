# 第 1 轮（新循环，承接第 12 轮）· CAST：把动作空间当作待标定的度量

> 检索/复核日期：**2026-10-31（UTC）**。赛事身份不变：宇树 **UniBot 世界挑战赛**（unibot.unitree.com），G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API。本轮是新循环第 1 轮，承接第 10 轮 FACT-VLA、第 11 轮 GEO-RESIDUAL、第 12 轮 CHUNK-SERVO。三个灵感词是「动作空间」「虚实迁移」「状态估计」。本轮不推倒 CHUNK-SERVO，而是补它最弱的一个隐含假设：**伺服律把动作空间当成各向同性、时不变、已知的欧氏空间。**

## 0. 直觉：最后 3 厘米不是“看不清”，而是“动不准”

CHUNK-SERVO 已经把反馈周期从 1 s 压到 167 ms 执行块。它解决的是“什么时候看世界”，但没有解决“看到之后，这一厘米的修正到底该发多大”。它的伺服律可以写成：

```text
a_cmd = a_ff + clip(K_p e + K_d ė, ±δ_p, ±δ_r)
```

这里藏了四个假设：

1. **各向同性**：x 方向 1 cm 的指令和 y 方向 1 cm 的指令产生同样的运动；
2. **时不变**：自由空间和接触段的动作增益一样；
3. **已知锚点**：VLA 的相对动作、API 的绝对 EE 位姿、夹爪 TCP 三者没有系统性偏移；
4. **状态已知**：目标位姿、接触模式、滑移、外部扰动都能从四路 RGB + 本体里可靠读出来。

真实机器人上，这四条没有一条严格成立：

- **接触段是各向异性的**。沿插入轴推 1 cm，可能只进 0.15 cm；横向 1 cm 仍然接近 1 cm。固定增益要么在法向“顶住”产生大力，要么为了顶住而把增益调大，结果横向过冲。
- **接近奇异/关节限位时是病态的**。某些方向的等效增益很小，逆解会把指令放大，噪声也被放大。
- **TCP / 手眼外参有偏**。VLA 的相对动作以训练时的 EE 帧为锚点，挑战赛 API 的 `*_ee_pose_gripper_base` 以另一套 TCP 为锚点；差 1 cm 的平移或 2° 的旋转，足以让“最后 3 厘米”变成“最后 3 厘米 + 固定偏差”。
- **延迟让修正作用在旧状态上**。5 步块 + RTT 端到端 200–320 ms；如果还用当前帧的误差直接算增益，等于在开环系统里加了一个相位滞后。
- **接触/滑移/人为编辑会切换模式**。同一个固定增益不可能同时适合自由接近、接触保持、滑移重抓和被人移动目标后的重定位。

所以本轮的核心判断是：

> **视觉伺服算对了“往哪走”，但用错了“走多快、走多大”。缺的不是方向，是动作空间的度量（metric）和它的不确定性。**

而度量的参数——接触模式、目标位姿、动作增益、TCP、延迟——全都是**潜变量**。这就是「状态估计」的位置：不是再估一个 6D 物体位姿，而是把**动作空间本身**也放进状态向量里，和接触模式一起估。数字孪生则是「虚实迁移」的位置：它不是用来训第二个策略，而是用来给这个度量一个**标定过的先验**和**可验证的信赖域**。

一句话：**别假设动作空间，估计动作空间。**

## 1. CHUNK-SERVO 留下的五个缺口

| CHUNK-SERVO 的假设 | 真机现实 | 失败形态 | CAST 的补法 |
|---|---|---|---|
| 动作增益各向同性 | 接触法向增益可降到 0.1–0.3，切向仍接近 1 | 法向顶死/大力，切向过冲 | 任务相关度量 `M_t = J_taskᵀ W J_task + λI`；低增益方向自动降权 |
| 动作增益时不变 | 自由/接触/滑移/对齐后增益不同 | 固定增益在模式切换时振荡或停滞 | 接触模式 IMM + 模式条件动作模型 `A_t` |
| TCP/锚点已知 | VLA 训练帧、API EE 帧、夹爪 TCP 可能差 1 cm/2° | 系统性偏差，伺服越修越偏 | 离线手眼/TCP 标定 + 在线 TCP 残差估计 |
| 状态已知 | 目标被挡、透明、反光、被人移动 | 错误目标/错误法向 | 目标位姿 EKF + 置信度 + 回退 |
| 延迟已知/可忽略 | RTT 10–150 ms，控制频率未写死 | 相位滞后、超调 | 用估计的 `A_t` 做 Smith 预测；增益按延迟降档 |
| 仿真只调增益 | sim-to-real gap 未知 | 真机换机器人就崩 | 系统辨识 + 场景验证 + 每机器人微探针 |

这五个缺口里，前两个是**动作空间几何**，第三、四个是**状态估计**，第五个是**虚实迁移**。三个灵感词不是硬凑的，它们正好对应 CHUNK-SERVO 没有形式化的三层。

## 2. 形式化对象（先给定义，再给算法）

### 2.1 有效动作模型

设任务相关状态为 `x_t ∈ R^n`（默认是 EE 的 6D 误差 twist，或任务相关子空间），策略下发的动作为 `a_t ∈ R^m`（挑战赛 `ee` 模式下是 2×6 EE + 2 gripper + 7 pivot；CAST 只改双臂 EE 子空间）。真实机器人在一个执行块内的响应写成：

```math
x_{t+1} = x_t + A_t\,\delta a_t + c_t + w_t,\qquad
w_t \sim \mathcal N(0,\Sigma_w),
```

其中：

- `A_t ∈ R^{n×m}` 是**有效动作雅可比**，不是 URDF 的几何雅可比；它把内部 IK、关节柔顺、接触约束、控制器跟踪误差全都吸收进去；
- `c_t` 是零指令漂移/偏置；
- `δa_t` 是相对标称动作的修正；
- `A_t` 是**模式相关**的：`A_t = A_free + Σ_m 1[m_t=m] ΔA_m`。

这个模型的关键不是“线性”，而是“**A_t 是待估状态，不是常数**”。在一个 167 ms 的执行块内做局部线性化是合理的；跨模式不行，所以模式必须显式估计。

### 2.2 潜状态与信念

定义潜状态：

```math
z_t = \big(T^{\text{target}}_t,\; m_t,\; G_t,\; \delta T^{\text{tool}}_t,\; s_t,\; \tau_t\big),
```

- `T_target`：受器/目标在 base 系的位姿，或任务相关局部坐标系；
- `m_t ∈ {free, approach, contact, grasp, slip, external}`：接触/交互模式；
- `G_t`：动作增益的低维参数（各向异性缩放 + 小旋转 + 法向标量增益）；
- `δT_tool`：TCP/工具偏移；
- `s_t`：滑移量/滑移概率；
- `τ_t`：等效延迟。

信念 `b_t(z_t) = p(z_t | y_{1:t}, a_{1:t})`，其中观测 `y_t` 包括四路 RGB、双臂 EE 位姿、关节、夹爪、下身体。因子化近似：

```math
b_t(z_t) \approx b_t(m_t)\; b_t(T^{\text{target}}_t)\; b_t(G_t,\delta T^{\text{tool}}_t,\tau_t \mid m_t).
```

- 离散模式用 IMM（交互多模型）；
- 位姿用 SE(3) 上的 EKF/UKF；
- 增益/TCP/延迟用带先验的 Kalman/RLS，且只估**可辨识的低维子空间**；
- 协方差 `Σ_t` 传播到任务误差 `Σ_e`，再决定信赖域半径。

### 2.3 任务相关度量

不是所有 6D 误差都值得修。对插入任务，绕插入轴的 yaw 通常无关；对挂杯，钩平面的法向最重要；对叠碗，竖直轴和横向偏移最重要。用演示关键帧/受器几何定义任务帧 `J_task`（把 EE twist 映射到任务相关特征），定义：

```math
M_t = J_{\text{task}}^{\top} W J_{\text{task}} + \lambda I.
```

解释：

- `A_tᵀ W A_t` 大的方向，是“动作能有效改变任务”的方向，应该允许更大的修正；
- `A_tᵀ W A_t` 小的方向，是“推了也不动/病态”的方向，应该被度量惩罚；
- `λI` 是 Tikhonov 阻尼，保证 QP 严格凸、逆解有界；
- `J_task` 把无关自由度（例如圆柱插入的 yaw）投影掉，避免伺服和 VLA 抢控制权。

这就是「动作空间」这个词最实在的落点：**动作空间不是 6 个数字，而是一个带任务几何的黎曼度量。**

### 2.4 CAST-QP

给定 VLA 的标称动作 `a_ff`、任务误差 `e_t`、估计的 `Â_t` 和度量 `M_t`，每个 5 步执行块解一个小 QP：

```math
\begin{aligned}
\delta a_t^\star = \arg\min_{\delta a}\quad
& \| \hat A_t\,\delta a - e_t \|_W^2
+ \mu \| \delta a - \delta a_{ff} \|_{M_t}^2 \\
\text{s.t.}\quad
& \| \delta a \|_{M_t} \le \rho_t, \\
& \delta a \in \mathcal C(m_t,b_t),
\end{aligned}
```

- `ρ_t` 是信赖域半径，来自虚实标定的先验 + 在线协方差；
- `C(m_t,b_t)` 是模式约束：接触段法向缩幅、滑移段切向冻结、外部编辑段保持、关节/速度/工作空间限幅；
- `δa_ff` 是 VLA 计划相对标称的偏差（通常为 0；如果 VLA 的 30 步计划本身有速度剖面，则用它做前馈）。

闭式解（忽略信赖域和模式约束时）：

```math
\delta a^\star =
\big(\hat A_t^{\top} W \hat A_t + \mu M_t\big)^{-1}
\big(\hat A_t^{\top} W e_t + \mu M_t \delta a_{ff}\big).
```

信赖域用缩放投影：若 `||δa||_M > ρ`，令 `δa ← δa · ρ / ||δa||_M`。模式约束用方向分解：`δa = δa_n + δa_t`，法向乘 `κ_n(m_t)`，切向保留或冻结。

### 2.5 机会约束版本（严谨版）

`Â_t` 有协方差 `Σ_A`。与其拍一个 `ρ`，不如要求“以至少 `1-δ` 的概率，修正后的任务误差不超过 `ε`”：

```math
\Pr_{\hat A_t \sim b_t}\left(
\| \hat A_t\,\delta a - e_t \|_W \le \varepsilon
\right) \ge 1-\delta.
```

在高斯近似下，用 Cantelli/三角不等式得到一个可实现的 SOCP 形式：

```math
\| \hat A_t\,\delta a - e_t \|_W
+ \kappa_\delta \sqrt{\delta a^{\top} \Sigma_A \delta a}
\le \varepsilon,
\qquad
\kappa_\delta = \sqrt{\frac{1-\delta}{\delta}}.
```

这比固定半径更有原则：**动作模型越不确定，允许的修正越小**；不确定的方向自动被收缩。工程上可以先用 QP + 半径近似，等 G0/G2 过了再上 SOCP。

### 2.6 虚实迁移的角色

数字孪生只做三件事：

1. **系统辨识**：相机外参/焦距尺度、腕部安装、TCP、关节柔顺、延迟、接触摩擦/刚度；给出 `A_0`、`Σ_A`、`c_0`、`τ_0`。
2. **信赖域综合**：在 G1 URDF + Dex1 + 三个任务族（peg-in-hole / hang-stack / zip-unlock）上做域随机化，用场景优化或留出场景验证选 `(λ, μ, ρ_0, K_p, K_d)`；目标是**稳定域和约束满足**，不是“仿真成功率最高”。
3. **压测**：位置偏移、遮挡、背景、目标移动、人手进入、光照；测检测延迟、恢复率、超调、p99。

不做：在仿真里训 6B 策略；不用仿真成功率预测真机；不做 sim-to-real RL；不把仿真当第二个模型。

## 3. 为什么这不是第二个学习模型

CAST 的所有在线模块都是**确定性/贝叶斯控制器**：

- 动作模型是局部线性模型 + Kalman/RLS，不是神经网络；
- 状态估计是 IMM/EKF/UKF，不是学习策略；
- 信赖域是 QP/SOCP，不是学习残差；
- 数字孪生只在离线做系统辨识和参数验证，不参与在线决策；
- 唯一的可学习模型仍是官方 WLA/VLA。

这和 MPC 里的“内部模型”、Kalman filter 里的“过程模型”是同一类东西：**控制器需要模型，不等于又加载了一个策略**。合规上按第 12 轮的 C2（确定性控制器）走，提交材料写清楚每个模块没有可训练权重、没有在评测数据上更新。

## 4. 三个灵感词怎么落到可计算对象

| 灵感词 | 本轮的可计算对象 | 不做什么 |
|---|---|---|
| **动作空间** | 有效动作模型 `A_t`、任务相关度量 `M_t`、信赖域 `B_ρ`、EE/joint 双空间适配、任务相关子空间 `J_task` | 不学新策略；不把 6D 全空间都当同等重要；不盲目切 `control_space` |
| **虚实迁移** | 系统辨识 `A_0, Σ_A, τ_0, δT_tool`；场景验证的 `ρ_0`；sim-to-real gap 预算；每机器人微探针 | 不在仿真训策略；不用仿真成功率当结论；不做 sim-to-real RL |
| **状态估计** | 目标位姿 EKF、接触/滑移 IMM、动作增益 Kalman/RLS、TCP/延迟估计、协方差传播 | 不做 6D 物体位姿网络；不假设力/触觉（API 没有）；不在不可辨识时硬估全矩阵 |

## 5. 什么会证伪这个想法

我把证伪条件先写下来，避免事后讲故事：

1. **动作空间其实是各向同性且稳定的**：如果 32 任务、多台 G1 上 `A_t` 的任务相关奇异值谱很平、接触段增益下降 <20%，CAST 退化为 CHUNK-SERVO，没有增益。
2. **闭环不可辨识**：如果内部控制器、接触和延迟把 `A_t` 与反馈混淆，前 10 步估不准任务相关增益（>10% 误差），信赖域可能比固定增益更糟。本轮合成实验已经看到这个负结果的苗头（见产物区 §7.3）。
3. **模式估计太慢/太噪**：如果接触/滑移检测延迟 >200 ms 或误报 >10%，模式条件增益会频繁切错，反而不如固定增益。
4. **sim-to-real gap 超过预算**：如果 TCP/柔顺/延迟在不同机器人之间差异大于标定范围，先验 `A_0` 无意义；只能靠在线估计，而在线估计又受第 2 条限制。
5. **收益只在安全不在成功率**：如果 CAST 只降低法向指令/力代理，不提高成功率，那么它的价值是“更安全/更可复现”，不是“更高分”；竞赛策略要按这个真实收益重新分配工程。

预注册的通过标准（产物区 G0–G8）：

- G0：动作模型可辨识（任务相关增益误差 ≤10%，TCP ≤5 mm/1°，延迟 ≤30 ms）；
- G1：状态估计（目标位姿 ≤5 mm/2°，模式准确率 ≥85%，滑移延迟 ≤100 ms）；
- G2：仿真信赖域（0–150 ms 延迟、载荷/摩擦/相机随机化下稳定，留出场景违规率 ≤1%）；
- G3：真机单任务 A/B（≥3/5 任务 +10pp，或法向指令代理 −20% 且成功率不回归；FoldTowel 不回归 >5pp）；
- G4：人为干扰恢复（检测 ≤200 ms，仿真恢复 ≥70%）；
- G5：延迟/算力（p99 ≤150 ms，每端口 <1 CPU 核）；
- G6：32 任务 N 端口干跑（隔离、reset、内存）；
- G7：消融支持因果（度量 > 恒等度量；信赖域 > 硬 clip；状态估计 > 固定模式；预测 > 无预测）；
- G8：合规审计（无第二模型、无评测数据泄漏、可复现）。

任何一条不过，就按产物区的失败动作回退，不烧正式 320 trials。

## 6. 一句话押注

**把动作空间从固定坐标系升级为待估计的度量：虚实标定给先验，本体/视觉残差在线估计接触模式与动作增益，任务相关度量与信赖域约束伺服修正——在不新增学习模型的前提下，让 CHUNK-SERVO 的最后 3 厘米既准又稳。**

**当前方案最大的风险是：闭环中动作模型不可辨识——内部控制器、接触和延迟会把 `A_t` 与反馈混淆；若 G0 不能在 8–12 个安全微探针或前 10 步内把任务相关增益估到 10% 以内，CAST 的信赖域可能比固定增益更糟。**

# 第 1 轮产物 · CAST 技术报告

> 检索/复核日期：**2026-10-31（UTC）**。对象：宇树 **UniBot 世界挑战赛**（G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API）。本报告是第 1 轮（新循环）想法区「CAST」的工程化产物；承接第 10 轮 FACT-VLA、第 11 轮 GEO-RESIDUAL、第 12 轮 CHUNK-SERVO。本轮沿用第 12 轮已核实的官方/数据/API 事实；新增经典控制、状态估计与场景优化文献；新增一个合成数值实验，用来检验控制律和暴露辨识风险。**合成实验不代表真机结果。**

## 0. 结论与边界

### 0.1 一句话结论

CHUNK-SERVO 把反馈周期从 1 s 压到 167 ms，但它的伺服律仍假设动作空间各向同性、时不变、已知；CAST 把**有效动作模型 `A_t`** 和**接触模式 `m_t`** 一起放进状态向量，用虚实标定给先验、用本体/视觉残差在线更新、用任务相关度量 `M_t` 和信赖域 `ρ_t` 约束修正——目标不是“更准的感知”，而是“更准的动作尺度”。

### 0.2 证据等级

| 等级 | 含义 | 本报告中的例子 |
|---|---|---|
| A | 官方文档、提交模板、数据集元数据、排行榜 JSON 直接核实 | 规则、API、33,276 eps、WLA `chunk_size=30`、榜单 29.7% |
| B | 我们在公开数据/网页上做的分析，可复现 | 榜单 `step~success` 回归、跨模型任务相关、每任务平均时长 |
| C | 设计假设，需 G0–G8 验证 | 接触法向增益 0.1–0.3、TCP 偏差 1 cm/2°、`ρ` 的可迁移性 |
| D | 本轮合成数值实验，只验证数学性质，不代表真机 | 2D 延迟/接触/信赖域实验、闭环 RLS 负结果 |

### 0.3 本轮新增的关键判断

1. **动作空间是度量，不是坐标。** 同样的 6D 误差，在不同方向、不同接触模式下的“代价”不同；固定增益等价于假设度量是单位阵。
2. **状态估计必须包含动作模型。** 只估目标位姿不够；接触模式、动作增益、TCP、延迟都是影响控制律的潜变量。
3. **虚实迁移的正确用法是“标定 + 验证”，不是“训策略”。** 数字孪生给 `A_0, Σ_A, τ_0, ρ_0`；场景验证给概率性保证；真机靠在线低维自适应。
4. **闭环辨识是最大瓶颈。** 本轮合成实验显示：小修正下的全矩阵 RLS 会被内部控制器/接触混淆，4 个 3 mm 探针也不够；因此 CAST 的第一道门是 G0，不是控制律。
5. **CAST 的第一收益可能是安全/可复现，不一定是成功率。** 在合成实验里，带标定模型的 CAST 与“恒等模型 + 预测”成功率接近，但接触法向指令显著更低；竞赛策略要按真实收益分配工程。

### 0.4 本轮不做什么

- 不从零训 VLA/World Model；官方 WLA 已开源 6B 基座。
- 不做完整 sim-to-real 策略训练；数字孪生只做系统辨识、信赖域综合、压测。
- 不做第二个学习模型/残差策略；CAST 是确定性/贝叶斯控制器。
- 不做 6D 物体位姿网络；用目标位姿 EKF + 任务帧 + 局部特征。
- 不做力/触觉闭环；API 没有。
- 不做 30 Hz 广域网伺服；沿用 5 步块/双频。
- 不把合成 2D 结果外推到真机；G3 之前不提交 CAST 版本。
- 不把预览榜单的任务排名当实测难度；只当先验。

### 2.2 有效动作模型

真实执行可写成：

```math
x_{t+1} = f(x_t, a_t; \theta_t) + w_t,
```

其中 `θ_t` 包含关节柔顺、摩擦、接触、延迟、TCP。在一个执行块内局部线性化：

```math
x_{t+1} = x_t + A_t\,\delta a_t + c_t + w_t,
\qquad
A_t = \left.\frac{\partial f}{\partial a}\right|_{(x_t,a_t;\theta_t)}.
```

模式分解：

```math
A_t = A_{\text{free}} + \sum_{m\in\mathcal M} \mathbf 1[m_t=m]\,\Delta A_m.
```

低维参数化（避免全矩阵不可辨识）。在任务相关方阵子空间（`n=m=6`）可用：

```math
A_t = R_t\,\mathrm{diag}(g_{1,t},\dots,g_{n,t})\,R_t^{\top},
```

更保守、也是默认的“任务相关 + 法向标量”：

```math
A_t = A_0 + u_n\,(g_{n,t}-g_{n,0})\,u_n^{\top},
```

其中 `u_n` 是接触法向（由目标几何/任务帧给出），`g_n` 是法向有效增益。默认只估 `g_n` 和一个全局尺度，不估 6×12 全矩阵。

### 2.3 联合状态–动作模型估计

目标后验：

```math
p(z_t,A_t \mid y_{1:t},a_{1:t})
\propto
p(y_t\mid z_t,A_t)
\int p(z_t\mid z_{t-1},a_{t-1},A_{t-1})
p(A_t\mid A_{t-1})
p(z_{t-1},A_{t-1}\mid y_{1:t-1}) .
```

因子化：

```math
b_t(z_t,A_t)
\approx
b_t(m_t)\;
b_t(T^{\text{target}}_t)\;
b_t(G_t,\delta T^{\text{tool}}_t,\tau_t\mid m_t).
```

- `m_t`：IMM，离散马尔可夫链；
- `T_target`：SE(3) EKF/UKF；
- `G_t, δT_tool, τ_t`：带 sim 先验的 Kalman/RLS，只更新可辨识子空间；
- `A_t`：由 `G_t` 和模式条件模型重建。

**可辨识性条件**：回归矩阵 `Φ_t = [a_{t-1},...,a_{t-L}]` 在任务相关方向上满秩，且信噪比足够。若不满秩，保持先验、放大 `Σ_A`、收缩 `ρ_t`；不硬估。VLA 的 30 步 plan 可作为**外生工具变量**，因为 plan 不依赖当前测量噪声；用它做 IV 可以减轻闭环反馈带来的偏差。

### 2.4 任务相关度量

由演示关键帧/受器几何定义任务帧 `J_task: R^6 → R^r`（把 EE twist 映射到 `r` 个任务相关特征；默认 `r≤6`）：

```math
M_t = J_{\text{task}}^{\top} W J_{\text{task}} + \lambda I.
```

- `W` 是 `r×r` 任务特征权重（例如插入任务：横向 x/y 和 tilt 权重大，yaw 权重 0）；
- `λ` 是 Tikhonov 阻尼；
- 度量同时出现在目标函数和信赖域里，保证“重要的方向允许修，病态的方向不许修”。

### 2.5 CAST-QP

```math
\begin{aligned}
\delta a_t^\star = \arg\min_{\delta a}\quad
& \| \hat A_t\,\delta a - e_t \|_W^2
+ \mu \| \delta a - \delta a_{ff} \|_{M_t}^2 \\
\text{s.t.}\quad
& \| \delta a \|_{M_t} \le \rho_t, \\
& \delta a \in \mathcal C(m_t,b_t).
\end{aligned}
```

闭式解（忽略约束）：

```math
\delta a^\star =
\big(\hat A_t^{\top} W \hat A_t + \mu M_t\big)^{-1}
\big(\hat A_t^{\top} W e_t + \mu M_t \delta a_{ff}\big).
```

信赖域投影：

```math
\text{if } \|\delta a^\star\|_{M_t} > \rho_t:\quad
\delta a^\star \leftarrow \delta a^\star\,\frac{\rho_t}{\|\delta a^\star\|_{M_t}}.
```

模式约束 `C(m_t,b_t)`：

| 模式 | 约束 |
|---|---|
| free | 全 6D；`ρ_t = ρ_0` |
| approach | 全 6D；`ρ_t = 0.7ρ_0`；速度限幅 |
| contact | `δa_n ← κ_n δa_n`，`κ_n∈[0.3,0.5]`；`δa_t` 保留；`ρ_t = 0.5ρ_0` |
| grasp | 法向冻结；切向小步；夹爪保持 |
| slip | 切向冻结；先重抓/加大夹持；`ρ_t = 0.2ρ_0` |
| external | 保持；重定位；不执行大修正 |

### 2.6 机会约束版本

`Â_t` 有协方差 `Σ_A`。要求：

```math
\Pr_{\hat A_t \sim b_t}\left(
\| \hat A_t\,\delta a - e_t \|_W \le \varepsilon
\right) \ge 1-\delta.
```

Chebyshev/三角不等式给一个可实现且保守的 SOCP：

```math
\| \hat A_t\,\delta a - e_t \|_W
+ \kappa_\delta \sqrt{\delta a^{\top} \Sigma_A \delta a}
\le \varepsilon,
\qquad
\kappa_\delta = \frac{1}{\sqrt{\delta}}.
```

`κ_δ=1/√δ` 是 Chebyshev 界，对任意零均值、协方差 `Σ_A` 的分布成立；若假设高斯，可用卡方分位数收紧。

工程上先做 QP + 半径投影；G0/G2 过了再上 SOCP。SOCP 的维度 `m≤12`，单次求解 <1 ms。

### 2.7 假设

- **A1（局部线性）**：在一个 5 步块/167 ms 内，`A_t` 近似常数；跨模式不成立，故模式显式估计。
- **A2（模式马尔可夫）**：`m_t` 按稀疏转移矩阵切换；每个块最多切换一次。
- **A3（目标可观测）**：目标可见时 `T_target` 可估；不可见时回退先验/VLA。
- **A4（VLA 是标称）**：`a_ff` 是语义意图，不是硬约束；CAST 可在信赖域内修正。
- **A5（无力量测）**：接触/滑移只能从运动残差、视觉、夹爪状态推断；不声称力控。
- **A6（单模型）**：CAST 不含可训练权重；仿真只离线用。

### 3.1 端口拓扑

```text
                    ┌─────────────────────────────────────┐
                    │  Evaluator (N ports 8765..8765+N-1) │
                    └──────────────┬──────────────────────┘
                                   │ websocket: obs / action chunk
                                   ▼
                    ┌─────────────────────────────────────┐
                    │  Per-port PolicyService (CPU)       │
                    │  ├─ state estimator (IMM/EKF)       │
                    │  ├─ action-model estimator (K/RLS)  │
                    │  ├─ goal retrieval (demo library)   │
                    │  ├─ CAST-QP / trust region          │
                    │  ├─ plan cache + Smith predictor    │
                    │  └─ action adapter (WLA 54D → API)  │
                    └──────────────┬──────────────────────┘
                                   │ async, batched
                                   ▼
                    ┌─────────────────────────────────────┐
```

- 每个端口独立 `reset()`、独立信念、独立 plan cache、独立动作模型；共享只读演示库和 VLA 权重。
- 状态估计/CAST 是 CPU 线程；VLA 请求异步、可批处理；VLA 永远不阻塞 `get_action`（冷启动除外）。
- 模型权重只有一份；CAST 不加载第二个模型。

### 3.2 动作空间的三层映射

```text
VLA 语义动作空间 (54D, 相对 EE)
        │ compose + adapter
        ▼
挑战赛 API 动作空间 (ee 21D / joint 14D, 绝对目标)
        │ 任务相关投影 J_task
        ▼
CAST 度量空间 (3–6D twist + gripper)
        │ CAST-QP + 信赖域
        ▼
修正后的 API 动作
```

- **第一层**：VLA 的 54D 是训练时的语义动作空间；adapter 负责 compose 到 base 系绝对目标。
- **第二层**：API 的 `ee`/`joint` 是执行动作空间；CAST 对两者都适用：
  - `ee`：`A_t` 是“EE 指令 → EE 运动”的有效雅可比；
  - `joint`：`A_t = J(q) B`，`J(q)` 是几何雅可比，`B` 是关节到任务空间的等效增益；度量变成 `JᵀWJ + λI`，可在零空间做姿态正则。
- **第三层**：CAST 只在任务相关子空间里修正；无关自由度交给 VLA/内部控制器。

## 4. 状态估计

### 4.1 目标位姿与任务帧

- **头双目**：已校正，基线 58.2526 mm，`fx≈282`；ROI 内 SGBM/块匹配 → 视差 → 深度；平面/圆/线/ICP 拟合受器位姿。
- **腕部**：无内参；一次性棋盘格标定，或用 D435 先验 + 头双目深度兜底；2D 特征只做 IBVS/粗对齐。
- **演示先验**：`T_target→ee*` 来自成功演示关键帧；提供相对目标，不提供绝对位姿。
- **融合**：SE(3) EKF；测量协方差由重投影误差、ROI 有效像素、视差置信度估计。
- **任务帧**：由受器几何（孔轴、平面法向、钩平面）和演示接近方向定义 `J_task`；置信度低时退化为全 6D + 大 `λ`。

### 4.2 接触/滑移/编辑模式

IMM 模式与观测特征：

| 模式 | 运动残差 `r_t = Δx_t - Â_t δa_t` | 视觉/夹爪特征 | 典型动作 |
|---|---|---|---|
| free | 小，白噪声 | 目标远，夹爪空/持物 | PBVS，正常增益 |
| approach | 小，可能有减速 | 目标进入腕部视野 | PBVS+IBVS，降速 |
| contact | 沿法向被压缩/反向 | `d_t` 小，表面可见 | 法向缩幅，切向保留 |
| grasp | 小，物体随夹爪 | 夹爪闭合，物体随动 | 搬运，正常闭环 |
| slip | 切向残差大，物体相对夹爪动 | 物体在腕部图中滑动 | 冻结切向，重抓 |
| external | 残差无法被 static/grasp 解释 | 人手/目标移动 | 停 → 重定位 → 重规划 |

似然：

```math
\ell_t(m) = -\frac12 r_t^{\top}\Sigma_r^{-1}r_t
- \frac12 \log|\Sigma_r|
+ \log p(\text{visual features}\mid m).
```

转移矩阵稀疏，带最小驻留时间/迟滞，避免每块抖动。模式后验 `b_t(m)` 直接进入 `C(m_t,b_t)` 和 `ρ_t`。

### 4.3 动作增益、TCP、延迟

- **离线先验**：数字孪生 + 真实演示拟合 `A_0, Σ_A, δT_tool, τ_0`。
- **每机器人微探针**：在自由空间执行 8–12 个 2–3 mm 的安全正交微动（x/y/z/roll/pitch），测响应；带正则的最小二乘拟合 `A_0` 和 `δT_tool`；用互相关/时间戳估 `τ`。耗时 267–400 ms，可放在每个 episode 开始或每机器人一次。
- **在线低维更新**：只估 `g_n`（法向标量）和一个全局尺度；用 Kalman/RLS，带 sim 先验和遗忘因子；协方差 `Σ_A` 随 excitation 更新。
- **工具变量**：用 VLA plan 的 `a_ff` 作为 IV，减轻闭环反馈偏差；若 IV 与指令相关性弱，退回先验。
- **不可辨识处理**：若回归矩阵条件数 > 阈值或 excitation 不足，冻结 `Â_t`、放大 `Σ_A`、收缩 `ρ_t`；不输出大修正。

### 4.4 不确定性传播

任务误差协方差近似：

```math
\Sigma_e \approx J_z \Sigma_z J_z^{\top} + \Sigma_{\text{model}}.
```

信赖域半径：

```math
\rho_t = \rho_0\,
\sqrt{\frac{\sigma_{\text{ref}}^2}{\sigma_{\text{ref}}^2 + \mathrm{tr}(\Sigma_e)}}
\cdot
\min\left(1,\frac{\tau_{\text{ref}}}{\tau_t}\right).
```

- `ρ_0` 来自虚实场景验证；`σ_ref, τ_ref` 是标定常数（参考不确定度/参考延迟）；
- 不确定/延迟大 → `ρ_t` 收缩；
- 若 `ρ_t < ρ_min`，关闭 CAST，回退 CHUNK-SERVO/VLA。

### 5.3 信赖域综合与概率保证

**候选选择**：在训练场景集上网格/随机搜索 `(λ, μ, ρ_0, K_p, K_d, κ_n)`，约束：

```math
\begin{aligned}
&\text{spectral radius of closed loop} \le 1-\gamma_{\min},\\
&\text{steady-state error} \le e_{\max},\\
&\text{overshoot} \le o_{\max},\\
&\text{normal command proxy} \le f_{\max},\\
&\text{latency margin} \ge m_{\min}.
\end{aligned}
```

**验证**：在**独立留出**的 N 个场景上评估；若候选在留出集上零违规，则真实（仿真分布下）违规概率的保守上界为：

```math
\Pr[\text{violation}] \le 1-\beta^{1/N}
\approx \frac{\ln(1/\beta)}{N}.
```

取 `N=1000, β=0.05`，上界约 **0.3%**。这个界只要求 i.i.d. 场景和“候选在验证前固定”，不要求凸性；比场景优化定理更轻，但只给验证保证，不给最优性。

**凸情形**：若固定模式、线性化约束，可用 Campi–Garatti 场景优化：`N ≥ (2/α)(ln(1/β)+d)` 给出 `Pr[violation] ≤ α`（置信度 `1-β`）。CAST 的完整问题含模式切换，不满足凸性；因此默认用“训练选择 + 留出验证”的二段式。

**重要边界**：以上保证是**对仿真参数分布**的，不是对真机。真机可能在分布外；所以需要在线自适应、保守回退和 G3 真机门。

## 6. 算法

### 6.1 主循环伪代码

```python
class CASTPolicy:
    def reset(self):
        self.plan = None
        self.plan_idx = 0
        self.future = None
        self.t = 0
        self.belief = init_belief_from_sim_prior()
        self.A_hat = self.belief.A0
        self.Sigma_A = self.belief.Sigma_A0
        self.probe_done = False
        self.mode = "free"
        self.queue = deque(maxlen=self.latency_estimate)
        self.prev_obs = None

    def get_action(self, obs):
        self._maybe_probe(obs)          # 8-12 步安全微探针，仅自由空间
        self._update_belief(obs)        # IMM + EKF + 低维增益 KF
        self._maybe_request_plan(obs)   # 异步 VLA，不阻塞

        if self.plan is None:
            self.plan = self.vla.predict(obs)   # 冷启动同步
            self.plan_idx = 0

        a_ff = self.plan[self.plan_idx:self.plan_idx + self.H_c]
        if self._cast_enabled():
            a_cmd = self._cast(obs, a_ff)
        else:
            a_cmd = a_ff

        self.plan_idx += self.H_c
        if self.plan_idx >= len(self.plan):
            self.plan_idx = 0
            self.plan = None
        self.t += 1
        return self.adapter.to_api(a_cmd, obs, self.token)
```

### 6.2 CAST 子过程

```python
def _cast(self, obs, a_ff):
    # 1) 目标与任务帧
    T_target, Sigma_T = self.belief.target_pose(obs)
    J_task = task_frame(T_target, self.task_id)
    W = task_weights(self.task_id)

    # 2) 模式后验
    m_post = self.belief.mode_posterior(obs, self.A_hat)

    # 3) 任务误差（预测到动作生效时刻）
    x_now = ee_pose(obs)
    x_pred = self._predict(x_now, self.queue, self.A_hat)
    T_des = T_target @ self.goal_relative
    e = se3_log(inv(x_pred) @ T_des)

    # 4) 度量与信赖域
    M = J_task.T @ W @ J_task + self.lam * np.eye(6)
    rho = self._trust_radius(Sigma_T, self.Sigma_A, self.latency)

    # 5) 模式约束
    e_task = project(e, J_task)          # r 维
    A_task = J_task @ self.A_hat         # r×6（默认 A_hat 在 6D 任务子空间）
    delta = solve_damped(A_task, e_task, M, self.mu)
    delta = apply_mode_constraints(delta, m_post, self.belief.contact_normal)

    # 6) 信赖域投影
    n_m = sqrt(delta @ M @ delta)
    if n_m > rho:
        delta *= rho / n_m

    # 7) 前馈 + 反馈
    a_cmd = compose(a_ff, delta)
    return clip_safety(a_cmd, obs)
```

### 6.3 状态/动作模型更新

```python
def _update_belief(self, obs):
    # 目标位姿 EKF
    self.belief.update_target(obs, self.Sigma_T)

    # 运动残差（last_action 是已实际执行的动作，不是排队中的命令）
    dx = ee_delta(obs, self.prev_obs)
    r = dx - self.A_hat @ self.last_action

    # IMM 模式更新
    self.belief.update_mode(r, obs, self.belief.contact_normal)

    # 低维动作增益 KF（只在 excitation 足够时更新）
    phi = self._excitation_projection(self.last_action)
    if abs(phi) > self.phi_min and self.belief.free_space():
        self.g_n, self.Sigma_g = kalman_update(
            self.g_n, self.Sigma_g, phi, self._normal_residual(r),
            q=self.q_g, r=self.r_g)
        self.A_hat = self._rebuild_A(self.g_n)
        self.Sigma_A = self._rebuild_Sigma(self.Sigma_g)
    else:
        self.Sigma_A *= self.inflation
```

### 6.4 回退与安全

```python
def _cast_enabled(self):
    return (self.belief.confidence > self.theta_conf
            and self.rho > self.rho_min
            and self.mode not in ("external",)
            and not self.safety_watchdog.triggered)

def _fallback(self, a_ff):
    if self.safety_watchdog.triggered:
        return hold_position()
    return a_ff   # CHUNK-SERVO / VLA 开环
```

规则：

- 任何异常 → 返回上一组合法 chunk 或安全 hold；绝不返回 NaN/错误形状。
- 模式后验熵高 → 用 worst-case 度量 `max_m M_t(m)`、最小 `ρ`。
- `edit_score` 高 → 停、重定位、重规划。
- 连续 3 块 `||δa||` 接近 `ρ` 且误差不降 → 判定模型/目标异常，回退。

## 7. 正确性论证

### 7.1 引理 1（标称收缩）

把误差写成 `x_{t+1} = x_t - A δa_t + w_t`（`x_t` 是“目标减当前”的误差）。CAST 的闭式解为：

```math
\delta a_t = B x_t,\qquad
B = \big(\hat A^{\top}W\hat A + \mu M\big)^{-1}\hat A^{\top}W.
```

当 `Â=A`、`M=AᵀWA+λI`：

```math
x_{t+1} = (I - AB)x_t + w_t.
```

在 `W=I`、`A` 的奇异值 `σ_i` 上，第 `i` 个方向的收缩因子为：

```math
\gamma_i =
\frac{\mu(\sigma_i^2+\lambda)}
{(1+\mu)\sigma_i^2+\mu\lambda}.
```

数值（`μ=0.3, λ=0.12`）：

| `σ_i` | 固定增益 `K=0.7` 的 `|1-Kσ_i|` | CAST `γ_i` |
|---:|---:|---:|
| 1.00 | 0.300 | 0.251 |
| 0.60 | 0.580 | 0.286 |
| 0.30 | 0.790 | 0.412 |
| 0.15 | 0.895 | 0.655 |
| 0.05 | 0.965 | 0.936 |

解释：

- 对低增益方向，CAST 的收缩因子显著小于固定增益；固定增益在 `σ=0.15` 时几乎不收敛（0.895），CAST 仍有 0.655。
- 对 `σ→0`，CAST 也趋于 1；这是**不可控方向**，度量/信赖域会把它收缩，而不是硬逆。
- 这就是“动作空间度量”带来的定量差别。

### 7.2 引理 2（模型误差下的有界性）

设 `||A-Â|| ≤ ε`。则：

```math
\|x_{t+1}\|
\le
\|I-AB\|\,\|x_t\|
+ \|(A-\hat A)B\|\,\|x_t\|
+ w_{\max}
+ \varepsilon\|\delta a_{ff}\|.
```

记 `γ = ||I-AB||`、`β = ||B||`。若 `γ + εβ ≤ γ_bar < 1`，则误差收敛到不变集：

```math
\Omega =
\left\{
x:\|x\|
\le
\frac{w_{\max}+\varepsilon\|\delta a_{ff}\|}{1-\gamma-\varepsilon\beta}
\right\}.
```

**证明**：三角不等式 + 归纳；每一步把 `x_{t+1}` 的范数用 `x_t` 的范数界住，得到几何级数。`δa_ff` 是 VLA 前馈偏差；若为 0，则只剩 `w_max`。信赖域 `||δa||_M ≤ ρ` 把模型误差对状态的影响限制在 `ερ` 量级；因此 `ρ` 不是拍脑袋，而是**线性化有效域**。

**推论 1（信赖域有效性）**：若线性化误差随半径增长，`ε(ρ)ρ ≤ δ_x`，则选择 `ρ ≤ ρ_valid` 可保证不变集在容差内。G2 要测的就是 `ε(ρ)` 曲线。

### 7.3 命题 1（慢切换稳定性）

每个模式 `m` 有自己的 `A_m, M_m, ρ_m`。若：

1. 模式后验在切换后 `H_c` 步内置信度 > 阈值；
2. 切换驻留时间 ≥ `H_c`；
3. 切换瞬间用 worst-case 度量 `max_m M_m` 和 `min_m ρ_m`；

则切换系统在慢切换意义下稳定；否则用保守模式（最小 `ρ`、最大 `λ`）覆盖。严格的共同 Lyapunov 函数需要额外假设（例如各模式闭环矩阵的联合谱半径 <1），本报告不声称一般性定理；这是 G2 要验证的工程条件。

### 7.4 命题 2（留出验证的概率保证）

**命题**：设候选 `θ` 在验证前固定；验证场景 `ξ_1,...,ξ_N` i.i.d. 来自仿真参数分布 `P_Ξ`；若 `θ` 在 N 个场景上零违规，则：

```math
\Pr_{\xi\sim P_\Xi}[\text{violation}(\theta,\xi)]
\le 1-\beta^{1/N}
```

以至少 `1-β` 的置信度成立。

**证明**：若真实违规概率为 `p`，则 N 个场景全不违规的概率为 `(1-p)^N`；令 `(1-p)^N ≤ β`，解出 `p ≥ 1-β^{1/N}` 作为上界。标准二项尾界。

**边界**：这是对 `P_Ξ` 的保证，不是对真机；`P_Ξ` 由域随机化范围决定。若真机在 `P_Ξ` 支撑外，保证失效；所以需要 G0 真机标定、在线自适应、保守回退。

### 7.5 局限

- 局部线性只在 167 ms/5 步内成立；接触非线性/变形物体可能破坏。
- 高斯/IMM 近似不是精确后验；模式误判会传播。
- 闭环辨识的可辨识性没有一般保证；本轮合成实验已经暴露负结果。
- 场景验证只覆盖仿真分布；sim-to-real gap 是独立风险。
- 没有力/触觉，接触力只能用指令/残差代理，不能声称力控。

### 8.3 合成数值实验（本轮新增，D 级）

- 自由空间有效动作：`A_free = R(20°) diag(1, 0.6) R(20°)ᵀ`。
- 接触未对齐：`A_contact = R(20°) diag(1, 0.15) R(20°)ᵀ`；对齐后恢复 `diag(1,1)`。
- 过程/测量噪声 `0.15 mm`；延迟 0/1/2 步；200 次蒙特卡洛。
- 安全故障模型：接触段法向指令 `>6 mm` 连续 3 步 → 故障（模拟机器人保护/力超限）。
- 控制器：
  - `fixed`：CHUNK-SERVO 风格 `K=0.7`，无预测；
  - `fixed_pred`：恒等模型 + Smith 预测；
  - `cast_known`：真实 `A` + 度量 + 信赖域 + 预测（“标定好了”的上界，测控制律）；
  - `naive_inverse`：真实 `A` 直接逆，无信赖域（不安全对照）；
  - `cast_probe`：4 个 3 mm 探针 + RLS（负结果）。

**结果（20° 旋转，200 trials）**：

| 延迟 | 控制器 | 成功率 | 故障率 | 终误差 mm | 收敛步 | 接触法向指令 max mm | mean mm |
|---:|---|---:|---:|---:|---:|---:|---:|
| 0 | fixed | 1.000 | 0.000 | 0.24 | 25.2 | 12.83 | 0.96 |
| 0 | fixed_pred | 1.000 | 0.000 | 0.24 | 25.2 | 12.83 | 0.96 |
| 0 | cast_known | 1.000 | 0.000 | 0.24 | 25.4 | 12.37 | 0.55 |
| 0 | naive_inverse | 0.015 | 0.985 | 9.20 | 79.2 | 13.20 | 13.01 |
| 1 | fixed | 0.990 | 0.000 | 0.39 | 31.0 | 13.03 | 0.88 |
| 1 | fixed_pred | 1.000 | 0.000 | 0.30 | 27.1 | 5.73 | 0.72 |
| 1 | cast_known | 1.000 | 0.000 | 0.30 | 26.5 | 4.81 | 0.39 |
| 1 | naive_inverse | 0.035 | 0.965 | 6.43 | 78.2 | 13.05 | 12.58 |
| 2 | fixed | 0.155 | 0.025 | 3.76 | 80.0 | 12.86 | 4.00 |
| 2 | fixed_pred | 0.995 | 0.000 | 0.36 | 30.5 | 3.21 | 0.60 |
| 2 | cast_known | 0.995 | 0.000 | 0.36 | 27.6 | 1.74 | 0.34 |
| 2 | naive_inverse | 0.070 | 0.925 | 5.97 | 76.2 | 12.95 | 8.72 |

**读法**：

1. **延迟是主导因素**：2 步延迟下固定增益成功率 15.5%；加预测后 99.5%。CAST 必须先有预测，再谈度量。
2. **标定模型带来安全边际**：`cast_known` 与 `fixed_pred` 成功率接近，但接触法向指令 max 从 12.83→12.37（−4%）、13.03→4.81（−63%）、12.86→1.74（−86%）；mean 也显著更低。合成任务里“成功”不难，难的是**不顶着接触走**；这与“最后 3 厘米”的真实痛点一致。
3. **直接逆低增益方向是危险的**：`naive_inverse` 故障率 92.5–98.5%；信赖域/阻尼不是可选项。
4. **4 个 3 mm 探针不够**：`cast_probe` 在延迟 0 时成功率 0.995，但法向指令 max 15.88 mm（比固定增益更差）；延迟 2 时成功率 0.850、max 12.62 mm。原因见下一条。
5. **全矩阵闭环 RLS 不可辨识**：在 20° 旋转、小修正的闭环数据上，`A_hat` 的 Frobenius 误差在前 20 步维持约 **0.8**；100 次试验中接触模式检测触发 **0/100**。内部控制器/接触/延迟把 `A_t` 与反馈混淆，RLS 学到的是闭环响应，不是有效动作模型。

**结论**：CAST 的第一道门不是 QP，而是 **G0 可辨识性**。在 G0 不过之前，不能用全矩阵 RLS；应使用“sim 先验 + 法向标量 + 微探针/IV”，并把 `Σ_A` 保守化。

## 9. 竞赛策略

### 9.1 任务分层

- **A 档：CAST 优先（接触/插入/挂/叠/拉链/锁/拧）**：HangCup、DisconnectEthernet、ToolboxStorage、PlugCharger、Unlock、ArrangeTestTubes、OpenPillBottle、OrganizeStationery、PackBag、ZipUp、PaperCupStacking、StoreRacket、StackCups、PlugInEthernet、StackBowls、StoreEarphones、PackPhone、OrganizePencilCase、SyringeWaterTransfer。
- **B 档：CHUNK-SERVO/VLA 优先（语义/变形/动态）**：FruitCollection、PackDoll、FruitSorting、ColorArrangement、PlacePhotoFrame、OrganizeBookshelf、PickOutBatteries、OrganizeTools、FoldTowel、ArrangePlates、SpellRobot、ConveyorSorting、RemovePinnedNote。
- **C 档：观察**：单任务通道里 `p_t` 接近 0 且失败在早期感知/抓取的任务；不投 CAST。

优先级：

```text
priority_t = q_t * Δ_t / cost_t
```

- `q_t`：失败发生在最后 3 厘米的比例（先验，单任务通道后更新）；
- `Δ_t`：CAST 条件增益（成功率或法向指令代理）；
- `cost_t`：目标库/标定/调参成本。

先做 A 档中 `q_t` 最高、`cost_t` 最低的 3–5 个任务；不要一次铺 19 个。

### 9.2 单任务通道协议

1. 选 5 个代表任务（见 §8.5）。
2. 每任务 5 次 A/B：CHUNK-SERVO vs CAST；同初始条件。
3. 先固定 `H_c=5`；通过后扫 `H_c∈{3,5,8}`。
4. 记录成功率、步骤分、耗时、p99、法向指令代理、故障/安全事件。
5. 通过标准见 §8.5；否则不提交 CAST。
6. 最后才跑 32×10 正式评测。

### 9.3 提交节奏与预算

| 阶段 | 时间 | 交付 | 退出条件 |
|---|---:|---|---|
| P0 基线/接口 | 1 周 | WLA + API adapter；token/`pivot` 验证；chunk 30 基线 | 单任务通道 1 任务跑通 |
| P1 标定/微探针 | 2 周 | 相机/TCP/延迟；微探针；`A_0, Σ_A` | G0 |
| P2 状态估计 | 2 周 | 目标位姿/模式/增益；离线回放 | G1 |
| P3 CAST/仿真 | 2 周 | QP/SOCP；预测；场景验证 | G2/G4 |
| P4 真机单任务 | 2 周 | 5 任务 A/B | G3/G5 |
| P5 全量干跑/提交 | 1–2 周 | N 端口；32×10 干跑；提交包 | G6/G7/G8 |

**算力**：1×24 GB GPU（WLA 微调/推理）；可选 1×40/80 GB 多端口；16–32 CPU 核；存储 1–2 TB（只缓存关键帧/ROI 可 <100 GB）。

**人员**：1 人视觉/几何/标定；1 人 WLA/部署；1 人评测/统计/策略；可兼职；总计 8–10 周。

### 9.4 收益算术（诚实版）

- A 档 19 任务各 +5pp → 全局 +3.0pp；各 +10pp → +5.9pp。
- 若 CAST 只在 10 个任务生效，+3.1pp。
- 人为干扰轴 +10pp → +2pp。
- 若 CAST 主要降低法向指令而不涨成功率，全局成功率收益接近 0；价值是**更少故障/更可复现/更安全**，以及为后续学习型改进提供数据。
- 320 trials 下 `p≈0.25` 的 SE≈2.4pp；配对设计更低，但不要用 +1–2pp 做结论。

## 10. 风险与合规

### 10.1 风险表

| 风险 | 影响 | 缓解 |
|---|---|---|
| **闭环动作模型不可辨识** | 信赖域比固定增益更糟 | G0 先验/微探针/IV；只估低维增益；协方差保守化；不过门回退 |
| 内部控制器混淆 | RLS 学到闭环响应而非 plant | 用 VLA plan 做 IV；自由空间探针；模式条件模型 |
| 接触模式误判 | 法向/切向约束切错 | IMM + 迟滞 + 最小驻留；高熵用 worst-case |
| sim-to-real gap | 先验 `A_0` 失效 | 域随机化 + 真机标定 + 在线自适应 + 回退 |
| 延迟估计误差 | 预测相位错 | 时间戳/互相关；降增益；加 chunk |
| 每机器人差异 | 同一先验不适用 | 每机器人微探针；per-port 状态 |
| 透明/反光/变形 | 位姿/特征失败 | 只对刚体任务启用 CAST；腕部 2D + 回退 |
| 安全 | 大修正/碰撞 | 信赖域、限幅、限速、watchdog、hold |
| 单模型解释 | 被判定为第二模型 | C2 合规说明；无可训练权重；审计清单 |
| 评测噪声 | 假阳性 | 配对 A/B、bootstrap、预注册；320 trials SE≈2.4pp |
| 数据泄漏 | 离线指标虚高 | 按 session/机器人/物体/背景分组；测试集不参与标定 |
| `pivot` 语义不一致 | 动作被拒/机器人不动 | 先用 `example_env.py`/单任务通道验证；零 pivot 回退 |
| 提交次数限制 | 无法多次 A/B | 邮件确认；单任务通道先验证；一次提交则保守 |

### 10.2 合规模式

| 模式 | 做法 | 风险 | 建议 |
|---|---|---|---|
| C1 离线标注 | GEO-RESIDUAL 只离线生成相位/接触标签；线上只有 VLA | 最低 | 保守首选 |
| C2 确定性控制器 | CAST 是几何/控制/贝叶斯估计，无可训练权重；VLA 是唯一学习模型 | 低；需说明 | **主推** |
| C3 同 checkpoint 特征 | 目标描述子用 VLA 同一 checkpoint 的 encoder | 低–中；需说明 | 需要强描述子时用 |

**禁止**：加载第二个学习策略/残差网络/独立视觉编码器做在线决策；在评测数据上更新任何权重；把仿真策略当第二个模型。

### 10.3 合规审计清单

- [ ] 在线模块无可训练参数；所有更新是 Kalman/RLS/几何。
- [ ] 仿真只离线使用；标定数据与评测数据按 session/机器人隔离。
- [ ] 提交材料列出每个模块的输入/输出/更新规则。
- [ ] 目标库/演示库只读；N 端口共享不串状态。
- [ ] 失败回退到 CHUNK-SERVO/VLA，不返回非法动作。
- [ ] 安全限幅/限速/watchdog 可独立审计。

### 10.4 最大风险

**闭环中动作模型不可辨识**：内部控制器、接触和延迟会把 `A_t` 与反馈混淆；本轮合成实验已经看到全矩阵 RLS 的负结果。若 G0 不能在 8–12 个安全微探针或前 10 步内把任务相关增益估到 10% 以内，CAST 的信赖域可能比固定增益更糟；此时必须退化为“sim 先验 + 法向标量 + 固定增益”，而不是硬上全矩阵。
