## 1. 直觉与动机（两个灵感的碰撞）

**灵感 1（数据集 → 数据不是一袋帧，而是一部有章节、有走位的书）**
直觉：过去两轮我们把数据当 i.i.d. 样本：32k eps 均匀/按样本数混采、按 eps 质量加权。但一条示教是**有时间相位、有空间关系**的轨迹；「episode 数」只是这本书的册数，不是可读页数。证据是 F20：HangCup 平均 186 帧、ZipUp 平均 424 帧，按 eps 数采样会让 ZipUp 的运输段过度代表 HangCup 的抓取段；而数据集里根本没有章节标签（无 subtask 标注）——章节要我们自己切。于是「数据集」这个灵感的第一层是：**把扁平 episodes 重构成按（任务×物体×布局×相位）索引的时空段库**，并由此得到三个此前没有的能力：(a) **覆盖诊断**——覆盖张量的空格 = 可预测的弱项；(b) **相位均衡采样**——不再被长运输段和长任务淹没；(c) **相位级复用**——检索/缝合/合成都在段粒度发生，而不是整条 eps 粒度。核心反直觉点：**数据量的瓶颈不是「多少条」，而是「哪些格子里没有」；110 语料的价值不在多，而在补空格。**

**灵感 2（时空推理 → 策略缺一个时钟和一张关系图）**
直觉：当前 VLA 每步看图像+语言出动作，隐式地编码时间与空间，但没有显式的「我现在在任务的哪一相位」和「目标物相对夹爪/容器的空间关系是什么」。而失败往往不是「不会动」，而是**相位错位**（该对齐时还在接近、该松手时还在夹）或**空间关系违反**（偏了几厘米、朝向差 30°）。时空推理给两件东西：(a) **时间侧**：一个从观测历史（`obs_delta_indices` 支持任意负偏移历史栈，F18）预测相位/进度的轻量时钟，用于检测停滞/回退并调度 chunk；(b) **空间侧**：一张以夹爪、目标物、容器、干扰物为节点、以 near/above/aligned/inside/contact 为边的关系图，离线用于给数据建索引，在线只在高风险接触任务上做低频一致性校验。核心反直觉点：**时空推理不必上世界模型（I7）——一个相位时钟加一张关系图索引，就能吃到大部分「该什么时候、往哪动」的收益，且不超 66ms 预算。**

**两者统一（闭环）**：数据集提供**时空监督与索引**（相位伪标签、关系图、覆盖张量），时空推理提供**读索引的时钟与校验器**（相位后验、进度、关系一致性）；校验器发现异常又触发 I5 合成「偏离→修正」段，回到数据集。上一轮的结论是「胜负手在数据引擎」；本轮把这句话精确化为：**胜负手在数据引擎的索引结构——从「更多数据」升级为「结构化覆盖」。**

## 2. 严谨定义

- **轨迹/示教**：τ_i = {(o_{i,t}, a_{i,t})}_{t=1}^{T_i}，o 含多视角 RGB 与本体状态 s_t，ℓ_i 为任务标签。
- **相位切分**：相位是控制 regime 的极大稳定区间。取低维签名 z_t = [‖Δq_t‖, Δgripper_t, ‖v_ee,t‖, jerk_t, …]，用变点检测（PELT/二分分割）得切点；对跨 eps 的段做聚类得相位原型 κ∈K（无需人工命名；命名仅供可读性）。记 φ(t)=κ。
- **空间关系图**：G_t=(V_t,E_t)，V=目标物∪容器∪夹爪∪干扰物，E 上的谓词 r∈R={near, above, aligned, inside, contact, supported}；离线由特权 EE pose（F21）+ 开放词汇检测/跟踪计算，在线由检测+几何（接口若给本体状态则用 FK）估计。
- **时空段**：σ=(i,[b,e),κ,G_b,G_e,h_b,A_{b:e})，h_b 为关键帧嵌入，A 为动作 chunk。
- **时空段库（ST-Index）**：D_ST = {σ}，索引键=(任务族, 物体类, 布局分箱, 相位 κ, 关系签名)。
- **覆盖张量**：C[t,o,l,κ] = 落入该格的段数（或帧数）；**考纲目标质量** μ[t,o,l,κ] 由 I1 考纲卡（公开评测条件）给出，是「评测会以多大概率/多大计分权重落在该格」的估计。
- **边际覆盖增益**（数据价值的形式化）：Δ(σ) = Σ_{c∈cells(σ)} μ(c)·[1/((1+C(c))(2+C(c)))]；它等价于凹覆盖函数 Σ_c μ(c)(1−1/(1+C(c))) 的一阶增量，是次模的，体现「越空的格子边际价值越高」。
- **时空一致性分数**：给定历史 H_t，相位后验 p_t=f_φ(H_t)、进度 r_t∈[0,1]；异常分 A_t = w1·1[停滞/回退] + w2·(1−sim(Ĝ_t, G_t^perc))。在线只在接触族低频计算。

## 3. 对 v1.1 的增量修订

- **P9（新增，数据结构缺失）**：数据集无相位/子任务标注（F20），导致采样与检索都在错误的粒度上进行；「按 eps 均匀」同时浪费在长运输段和重复标称帧上。
- **P10（新增，特权信息落差）**：离线有 EE pose 等特权状态（F21），评测观测未必有；任何用特权信息造的标签必须验证「视觉可推断性」，否则是离线自嗨。
- **P2/P5 修订**：泛化缺口与时间压力都可部分归因于「相位错位」，而非纯视觉泛化；步骤分本质是相位里程碑的达成率。
- **P8 修订**：示教质量不只是「好坏」，还有「覆盖冗余」——大量重复的标称运输段是另一种低质数据。
- **Q9（ST-Index 有效性）**：无监督相位切分能否跨任务稳定复现物理相位？相位/关系索引是否与真实失败模式相关？
- **Q10（覆盖→增益）**：在固定算力下，边际覆盖采样是否优于质量/均匀采样？离线覆盖增益能否预测真机增益？
- **Q11（时钟可靠性）**：视觉-only 相位/进度头的精度是否足以触发恢复而不误报？关系校验器的成本-收益如何？

## 4. 设计原则（新增 PR6）

- **PR6 结构化覆盖律**：数据的价值 = 它在评测相关时空格子上贡献的边际覆盖，而非条数或帧数。任何采样/合成/检索决策都要能指出它填补了哪个格子。
- PR1–PR5 保留。

# UniBot-V1 参赛创新点清单（第 2 轮 v1.2 · 结构化覆盖版）

> 检索日期：2026-11-26（第 1 轮）、2026-11-27（第 2 轮）；来源见 §7。承接 v1.1：新增 I10/I11，深化 I1/I2/I5/I9，I3/I4/I6/I8 微调，I7 归档。清单只增改不重置。

## 0. 创新点清单（每点：动机 / 与现有方案差异 / 技术可行性 / 所需资源 / 落地步骤 / 风险）

### I10 ST-Index 时空分段数据集 ★★★★★（新）
- **动机**：数据集无相位/子任务标注（F20），扁平 eps 被当 i.i.d. 采样；HangCup 平均 186 帧、ZipUp 平均 424 帧（F20），按 eps 采样会让长任务的运输段过度代表短任务的抓取段。数据价值应按「评测相关时空格子的边际覆盖」计量（PR6），而不是条数。
- **与现有方案差异**：直接 SFT 队伍按 eps 均匀采样；v1.1 的 I2 已做「质量加权 + 孪生权重」，但仍在整条 eps 粒度。I10 把数据重构成段库，使采样/检索/合成/诊断都发生在（相位×关系）粒度，并给出可量化的覆盖缺口。
- **技术可行性**：高。全离线，不需要新模型：变点检测 + 段聚类 + 开放词汇检测/跟踪 + 特权 EE pose（F21）+ 少量人工抽检。
- **所需资源**：关键帧嵌入 1×GPU 日；切分/关系图 CPU 2–3 日；索引与嵌入存储约 20–50GB（不复制原始视频）；工程 1–2 人周。
- **落地步骤**：①schema adapter（F22：v3.0 具名字段 ↔ 16 维扁平，统一到 16 关节 + FK 得 EE pose）；②每任务 PELT 切分 + 段聚类，5% 样本用 VLM 关键帧描述人工抽检；③关系图（夹爪系/世界系谓词）；④覆盖张量 C 与考纲目标 μ（复用 I1 考纲卡）；⑤输出 top-gap 清单给 I1/I2，段索引给 I9/I5。
- **风险**：切分误差与关系图噪声污染下游——缓解：只用段做「软索引」（检索/采样权重），不做硬标签；切分稳定性用 split-half ARI 门禁（见 §2 E1）。μ 是公开考纲的估计而非真实评测分布——这是本轮最大风险，见 §6。

### I11 时空相位时钟 + 一致性校验 ★★★★（新）
- **动机**：失败常是相位错位/空间关系违反，而非「不会动」；步骤分是里程碑达成率（F17），需要显式时间抽象。策略本身没有时钟。
- **与现有方案差异**：v1.1 的 I5 进度头只做离线监督；I11 把它变成在线组件：视觉-only 相位/进度头 + 停滞/回退检测 + 接触族低频关系校验，直接驱动 I4 的 chunk 调度与 I5 的恢复触发。
- **技术可行性**：中-高。冻结视觉编码器 + 小 transformer 头，用 I10 伪标签训练；关系校验复用开放词汇检测，只在 6–8 个接触任务上低频运行。
- **所需资源**：训练 1×GPU 日；时钟推理 <5ms/步；关系校验约 10ms/次、每 2 个 chunk 一次；总 p99 仍目标 <40ms（F12 的 66ms 预算内）。
- **落地步骤**：①用 I10 段标签生成相位/进度监督；②训练时钟头（输入 `obs_delta_indices` 历史栈，F18）；③离线测相位 top-1、进度 MAE、停滞检测 ROC；④接 I4 chunk 调度；⑤接触族接关系校验，滞回 2 次后触发 I3/I5。
- **风险**：伪标签噪声导致误报恢复，反而伤标称成功率——缓解：滞回 + 代价敏感阈值 + 「先只在接触相位启用」；特权信息落差（P10）——缓解：训练只用视觉可推断的标签，EE pose 仅用于造标签、不进入在线输入。

### I1 v3 考纲校准五轴增广引擎 ★★★★★
- v1.1 的考纲卡继续用，但**升级为覆盖目标 μ**：每张卡给出该任务在（物体类×布局×外观×干扰×位置）上的评测质量分布；增广采样从「按卡随机」改为「按覆盖空格优先」。
- 新增剂量判据：单位算力带来的覆盖增益（Δ覆盖/GPU 时），而不是盲目加剂量；保留「不可行动作占比>5% 降级为平移不变增广」的 L0 判据。
- 与 I10 的关系：I10 输出 top-gap 清单，I1 只补这些格子，避免增广预算撒胡椒面。

### I2 v3 数据引擎 3.0：结构化覆盖共训 ★★★★★
- 在 v1.1（孪生语料 + loader 加权 patch + 质量加权）之上加三件事：
  1. **schema adapter**：挑战集 v3.0 具名字段与 110 语料扁平 16 维统一（F22），单测「同一物理轨迹两种 schema 映射误差 < 阈值」。
  2. **覆盖感知采样**：段级权重 ∝ 边际覆盖增益 Δ(σ)（见 §1.1/§1.2），替代按样本数混采；保留族级上限防止稀有噪声过采样。
  3. **相位均衡**：每个 batch 内各相位有最低配额，避免长运输段主导梯度。
- 官方 loader 的 weight 不生效（F11）仍需 patch；现在是两级采样（数据集级 × 段级）。

### I5 v3 非标称示教合成 + 得分点对齐恢复 ★★★★
- 在 v1.1（扰动重放/跨段缝合/世界模型续写/得分点过滤）之上：
  1. **相位边界重组**：只在相位边界缝合（A 的接近段 + B 的抓取段 + C 的运输段），且边界关系图兼容（图编辑距离 < δ）、相位顺序合法——比随机跨段缝合物理上更可信。
  2. **关系一致扰动**：物体位姿扰动后必须仍落在覆盖张量的有效格（I10 检查），避免生成物理不可行/评测分布外的「假偏离」。
  3. **停滞触发合成**：I11 在线检测到的停滞/回退状态，回灌成新的「偏离→修正」种子（离线后处理，不在评测时学习）。
- 得分点里程碑检测器不变，但里程碑与相位时钟对齐（同一套时间轴）。

### I9 v2 reset 期相位级检索 ★★★★
- v1.1 是整条 eps 最近邻；v2 改为**相位级**：查询 =(物体嵌入, 关系签名, 当前相位)，按相位分别检索「最像物体的抓取段/对齐段/放置段」，先验只注入当前相位相关的参数（gripper 开度、接近高度/朝向、技能模式）。
- 好处：避免整条 eps 的先验在错误相位上误导；未见物品轴仍靠「同类物体怎么抓」的类比。
- 关系签名作为检索键的一部分，使「同物体不同布局」也能被区分；距离阈值按相位分别标定。

### I3/I4/I6/I7/I8 微调
- **I3 v2**：关系校验器在接触相位检测到关系违反时触发伺服；I3'（训练时辅助监督）降级预案保留。
- **I4 v2**：chunk 长度由相位决定——接近/运输长（8–16），抓取/对齐/插入短（2–6），参照 F12 的 horizon 16；人手干预检测不变。
- **I6**：把时钟（<5ms/步）与关系校验（约 10ms/2 chunk，仅接触族）纳入 p99 预算；复用官方 model_server（F12）。
- **I7**：在线前瞻正式归档；WMA-0 仅作为 I5 的离线合成数据源，不再进关键路径。
- **I8 v3**：注册表新增「覆盖增益预测 vs 真机增益」「时钟可靠性 vs 恢复收益」两类对齐点；消融按 §2 扩展。

```python
def marginal_gain(seg, C, mu):
    cells = occupancy(seg)                       # 该段落入的所有 (task,obj,layout,phase)
    return sum(mu[c] * (1.0 / ((1 + C[c]) * (2 + C[c]))) for c in cells)
```

### 1.2 覆盖感知采样器（I2 v3）

```python
class CoverageAwareSampler:
    def __init__(self, index, C, mu, alpha=1.0, cap=5.0, floor=0.05):
        self.seg_w = {s.id: min(cap, max(floor, marginal_gain(s, C, mu) ** alpha))
                      for s in index.segments}
        self.phase_min = 0.05                    # 每相位最低配额

    def episode_weight(self, ep):
        return sum(self.seg_w[s.id] for s in ep.segments) / len(ep.segments)

    def sample_batch(self, n):
        batch = weighted_sample(self.seg_w, n)   # 段级采样，再取所属 eps
        return enforce_phase_quota(batch, self.phase_min)  # 相位均衡
```

### 1.4 相位时钟与异常检测（I11）

```python
class SpatioTemporalClock:
    def __init__(self, encoder, head, window=8, m=3, eps=0.02):
        self.encoder, self.head = encoder, head           # 冻结编码器 + 小头
        self.window, self.m, self.eps = window, m, eps
        self.r_hist, self.last_phase = [], None

    def update(self, obs_hist):                           # obs_delta_indices 历史栈（F18）
        f = self.encoder(obs_hist[-self.window:])
        logits, r = self.head(f)
        self.p_phase = softmax(logits)
        self.r_hist.append(float(r))
        self.last_phase = int(self.p_phase.argmax())
        return self.p_phase, r

    def anomaly(self, hold_phases):
        if len(self.r_hist) < self.m or self.last_phase in hold_phases:
            return False
        stall   = (self.r_hist[-1] - self.r_hist[-self.m]) < self.eps
        regress = self.last_phase in BACKWARD_OF.get(self.prev_phase, set())
        self.prev_phase = self.last_phase
        return stall or regress                          # 滞回由调用方做 2 次确认

def chunk_len(kappa):
    return {"approach": 12, "transport": 16, "pregrasp": 6, "grasp": 4,
            "align": 3, "insert": 3, "release": 3, "retract": 10}.get(kappa, 8)
```

```python
def maybe_recover(obs, clock, policy, contact_task):
```

## 2. 实验设计（分级消融 v3）

| 级别 | 内容 | 通道/成本 | 通过判据 |
|---|---|---|---|
| L0-E1 | 相位切分稳定性：split-half ARI、5% 样本 VLM/人工抽检 | 离线免费 | ARI > 0.6，抽检一致率 > 0.7 |
| L0-E2 | 覆盖采样 vs 质量采样 vs 均匀采样（同算力、留出任务） | 离线 | Δprog 覆盖 > 质量 > 均匀，覆盖−均匀 ≥ +2% 绝对，且无任务退步 >1% |
| L0-E3 | 时钟：相位 top-1、进度 MAE、停滞检测 ROC | 离线 | top-1 > 0.7，MAE < 0.1，AUC > 0.8，误报 <5% |
| L0-E4 | 关系图谓词 F1（接触族） | 离线 | F1 > 0.7 |
| L0-E5 | 无害性：I9 v2/I11 在标称场景 Δprog ≥ 0 | 离线 | 标称不退步 |
| L1 | 2^(4-1) 部分析因：{覆盖采样, 相位均衡, 时钟调度, 关系校验} | 离线 + 少量真机 | 主效应显著的 ≤3 个组合进 L2 |
| L2 | top 组合真机确认：≥2 任务 × 各 2 次 | 单任务通道 | 成功率/步骤分增益 ≥ 离线预测的 50% |
| 门禁 | PR4：run_client 全流程 + p99 + 动作健康度 | 本地 stub | 0 拒绝动作，p99 < 40ms |
