# 第 63 轮（承接第 62 轮「ROSE 鲁棒在线场景进化闭环」IP-183~192；灵感循环 II 第 2 轮；本轮灵感：「谐波减速器」×「避障控制」）

> 第 62 轮 ROSE 补齐了在线学习（OLP 遗憾界）、鲁棒编译（WCV/RSC）、场景银行（SBR/SHC）与对话屏蔽（Shield）。但回看整条链，有一个从未被检验的隐含假设：**「K_safe 被派发，关节就会忠实地走到指令位置」**。第 62 轮的 WCV 是在「指令/期望位姿空间」里做安全编译，RSC 校准的是外力矩残差；而真实机器人最后一段传动是**谐波减速器**——一个具有周期性运动学误差、回差/迟滞与非线性扭转柔度的**带记忆非理想传动**。避障控制恰恰对「真实末端到底在哪、下一步会到哪」最敏感。本轮把避障从「点估计 + 固定安全系数」升级为「传动误差感知的集合式鲁棒安全」，为前两轮的语义-学习闭环补上「机械接地」。

## 0. 直觉与动机

**灵感 1（谐波减速器 → 被忽略的机械层）**
直觉：谐波减速器的输出角不是输入角的线性缩放。柔轮弹性变形 + 椭圆波发生器 + 齿啮合，产生三类结构化偏差：①随输出角周期变化的**运动学误差** e(q)（编码器可直接观测、可学习，频谱由减速比与齿数决定）；②零/低力矩附近的**回差（lost motion）**，使输出在一个宽度 2δ 的死区内「不确定」，且方向反转时先不动、后跳变；③随载荷非线性变化的**扭转柔度** d=τ/K_t(τ)。三者叠加：真实位姿 p_true = FK(q_cmd + e + d + h)，而前 62 轮全部在 p_cmd 上论证安全。**关键洞见：谐波误差不是随机噪声，而是结构化的、可辨识的、且必须被安全论证显式覆盖的集合；把它当噪声抹平，等于把安全裕度建立在未建模动力学之上。**

**灵感 2（避障控制 → 从点到管）**
直觉：避障的本质是「真实占据集合与障碍集合不相交」。若真实位姿只能确定在一个集合 P_t 内（由传动误差集经 Jacobian 映到笛卡尔），安全条件就不是「点 p_cmd 不碰」，而是「**整个不确定管 P_t 不碰**」。把 P_t 建成 **zonotope**（中心 + 生成元）：线性映射闭包、支撑函数 O(G)、Minkowski 和高效——为 1kHz 安全滤波提供可实时计算的鲁棒裕度。避障由此从「点预测 + 固定安全距离」变为「集合传播 + 方向感知的支撑裕度」。

**灵感 3（迟滞 = 有记忆的状态）**
直觉：回差不是随机误差，而是有内部状态的方向依赖现象。给定指令轨迹和 δ，play 算子的内部状态 z 递推确定，且严格满足 |q_cmd − z| ≤ δ。但 δ 未知、可能左右不对称、且随磨损变化——因此需要一个**迟滞状态估计器 HSE** 在线辨识分支 σ 与死区宽度 (δ⁻,δ⁺)，并把「分支判错」的后果显式计入安全集（而不是假定分支已知）。

**灵感 4（磨损 → 非平稳误差集）**
直觉：柔轮疲劳、润滑退化、齿面磨损让 δ 缓慢增大，运动学误差谱也会漂移。第 62 轮 RSC 已示范「残差驱动球半径」；本轮把同构思想平移到运动学层：**运动学残差自校准**——用编码器残差辨识 e、δ、K_t，用后验方差/Page-Hinkley 检测漂移；漂移时**只膨胀安全集、不赌模型**。「不确定就收紧护栏」是跨轮不变的安全哲学。

**灵感 5（合流 → HERO：谐波误差感知的鲁棒避障闭环）**
直觉：TEL 学误差场，HSE 定迟滞分支，PUT 把联合误差集映成笛卡尔 zonotope，CCE 把「反应距离 + 刹车距离 + 回差 + 柔度 + 运动学误差」合成为齿轮感知的最小净空，RCBF 在该净空下做鲁棒安全滤波，WDD 盯住非平稳，HFF 只在**性能**上做前馈补偿（安全永不依赖补偿成功）。这是对 ROSE 的机械接地：**学习可以不准，安全集必须覆盖；控制可以保守，认证必须可审计。**

## 1. 形式化定义（增量：定义 185–195）

- **定义 185（HERO 闭环）**：HERO = (TEL, HSE, PUT, CCE, RCBF, HFF, WDD, AGS, J_hero)，挂在 ROSE 的 K_safe 派发层与末端执行之间，不推翻任何既有接口。
- **定义 186（传动误差场 TEL）**：q_j^act = q_j^cmd + e_j(q_j^cmd) + d_j(τ_j) + h_j；e_j = φ_j(q)^Tθ_j（傅里叶/齿啮合谐波基），d_j = ψ_j(τ)^Tη_j（奇次柔度）；θ,η 用带遗忘 RLS 在线更新，后验协方差 P_t 经 φ^T P φ 给出预测方差。
- **定义 187（迟滞状态 HSE）**：play 算子 z_t = max(x_t−δ, min(x_t+δ, z_{t−1}))，严格 |x_t−z_t|≤δ；分支 σ_t = sign(x_t−z_t)；δ 左右不对称 (δ⁻,δ⁺)，由 HSE 在线估计并给出分支置信度。
- **定义 188（位姿不确定管 PUT）**：关节误差集 Z_t = ĉ_t ⊕ Σ_j ε_j e_j[−1,1]（中心含 ê+d̂，逐关节标量半径 ε_j = δ_j + k_σ σ_j + |∂d_j/∂τ_j|Δτ_j）；笛卡尔管 P_t = p_c ⊕ J Z_t ⊕ ℬ(ρ₂)，ρ₂ = ½ L_H ‖Δ‖²_max。
- **定义 189（齿轮感知净空 CCE）**：d_req(v,τ) = vT_react + v²/(2a_max) + δ_hys + δ_comp(τ_max) + e_max + r_rob；安全裕度随速度/载荷实时变化，取代固定系数。
- **定义 190（鲁棒 CBF 避障滤波 RCBF）**：h_rob = dist(p_c,𝒪) − r_rob − σ_{P_t−p_c}(n)，n 为指向最近障碍的单位向量，σ 为支撑函数；QP：u* = argmin‖u−u_nom‖² s.t. ḣ_rob + α(h_rob) ≥ 0。
- **定义 191（迟滞前馈 HFF）**：u_ff = H_{δ̂}⁻¹(q_des)（逆 play），仅用于减小跟踪误差、提升任务性能；安全论证**不读取** u_ff。
- **定义 192（磨损漂移 WDD）**：残差 ρ_t = q_meas − q̂_pred；Page-Hinkley g_t = max(0, g_{t−1}+ρ_t−ν)，g_t>λ ⇒ 触发 δ 膨胀 + 停更 + 激励性复标定。
- **定义 193（自适应齿轮安全 AGS）**：安全模式阶梯 {nominal, inflated, conservative, stop}，由（WDD 报警、管覆盖后验、PE 条件数、RCBF 可行性）触发；与 ROSE 的 OCB 硬下界互锁，老虎机不得突破安全阶梯。
- **定义 194（齿轮证书 J_hero）**：J_hero = (J_rose, θ̂版本, δ̂±, P_t 生成元哈希, 覆盖率估计, RCBF 可行性, mode)；Valid ⇔ Valid(J_rose) ∧ 管覆盖 ≥1−α ∧ RCBF QP 可行 ∧ mode ≤ inflated（除非显式停机）。
- **定义 195（HERO 闭环算子）**：语义流（10–100Hz）执行 [残差提取 → TEL/HSE 更新 → PUT 构建 → WDD/AGS 决策 → 证书构建]；实时流（1–10kHz）执行 [读锚点与参数快照 → PUT 前向 → 支撑函数 → RCBF-QP → 派发]，**零学习写操作**。

## 2. 关键算法骨架

```python
# —— 语义流（10–100Hz）：学误差、定分支、校准集合 ——
θ_j, η_j ← RLS(φ_j(q_cmd), ψ_j(τ), resid_j; λ_forget)      # TEL
δ⁻, δ⁺, z, conf ← HSE.update(q_cmd, q_meas, τ)              # play 反演 + 分支
Z_t ← build_zonotope(ê, d̂, δ̂, k_σ·σ_pred, |∂d/∂τ|·Δτ)     # PUT（关节空间）
g_t ← WDD.push(q_meas − q̂_pred);  mode ← AGS.decide(g_t, PE_cond, cover)
# —— 实时流（1–10kHz）：集合式安全，无学习写 ——
P_t = p_c ⊕ J·Z_t ⊕ ball(ρ₂)                               # 笛卡尔不确定管
h_rob = dist(p_c, O) − r_rob − support(P_t − p_c, n)       # 方向感知裕度
u* = QP(u_nom, s.t. ḣ_rob + α·h_rob ≥ 0, u ∈ 𝒰)            # RCBF 安全滤波
if infeasible: brake(); mode ← stop                        # 硬兜底
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 1（play 精确界）**：play 算子对任意输入轨迹恒满足 |x_t−z_t| ≤ δ，故回差对位置的贡献是一个宽度 2δ 的**有界区间**，而非无界噪声或需要概率假设的扰动。
- **引理 2（zonotope 映射 + 二阶余项）**：p(q_c+Δ) = p_c + JΔ + ½ΔᵀHΔ + O(‖Δ‖³)；J Z_t 仍是 zonotope，Hessian 谱范数给出确定性余项球 ℬ(ρ₂)。
- **引理 3（管覆盖）**：若 TEL 后验以概率 ≥1−α₁ 覆盖 e、d，HSE 以 ≥1−α₂ 覆盖 δ 与分支，则 p_true ∈ P_t 的概率 ≥ 1−α₁−α₂。
- **定理 1（鲁棒无碰撞）**：若 RCBF 保持 h_rob ≥ 0 且 p_true ∈ P_t，则 dist(p_true,𝒪) ≥ r_rob > 0——避障成为「集合不相交」的机制保证，不依赖误差被消除。
- **命题（净空充分性）**：CCE 的 d_req 是「反应 + 制动 + 回差 + 柔度 + 运动学误差」的确定性上界，故以 d_req 为裕度的 RCBF 在最大速度/载荷下仍不穿透。
- **命题（HFF 安全无关）**：安全滤波只消费 P_t 与障碍几何，u_ff 只进入 u_nom；逆 play 失败仅损失跟踪性能，不改变 h_rob ≥ 0 的认证条件。
- **实时性**：支撑函数 O(G)（G≈关节数），CBF-QP 变量 ≤12、约束 ≤障碍数+1；语义流承担全部学习，实时路径保持 ≤1ms。

## 2. 形式化定义（完整版）

**定义 185（HERO 闭环）** HERO 是挂在 ROSE 派发层与末端执行之间的机械接地闭环：语义流从编码器/力矩残差中在线辨识谐波传动模型并维护误差集合；实时流只读取参数快照，把误差集合传播为笛卡尔不确定管，并用鲁棒 CBF 做安全滤波。不变式：**全部学习只发生在语义流；实时路径零学习写操作；安全认证只依赖集合覆盖，不依赖点估计精度。**

**定义 186（传动误差场 TEL）** 第 j 关节的实际输出
`q_j^act = q_j^cmd + e_j(q_j^cmd) + d_j(τ_j) + h_j`。
运动学误差用已知频率基展开：`e_j(q) = Σ_{k∈𝒦_j}[a_{jk}cos(kq) + b_{jk}sin(kq)] + c_j`，其中 `𝒦_j` 由减速比 N_j 与齿数决定（含输出基频 1×、椭圆波发生器 2×、齿啮合 N_j×）。柔度用奇次多项式 `d_j(τ)=κ_{j1}τ+κ_{j3}τ³`。参数向量 `θ_j,η_j` 用带遗忘因子 λ_f 的递推最小二乘更新：
`θ̂_t = θ̂_{t−1} + P_t φ_t(y_t − φ_tᵀθ̂_{t−1})`，`P_t = (P_{t−1} − P_{t−1}φ_tφ_tᵀP_{t−1}/(λ_f+φ_tᵀP_{t−1}φ_t))/λ_f`。
预测方差 `σ_j² = σ_ε²(1 + φ_jᵀ P φ_j)`，直接进入 PUT 的误差半径。

**定义 187（迟滞状态 HSE）** 迟滞用 play（backlash）算子建模：`z_t = max(x_t−δ, min(x_t+δ, z_{t−1}))`，其中 x_t 为去除确定性误差后的指令增量；严格有 `z_t ∈ [x_t−δ, x_t+δ]`。分支 `σ_t = sign(x_t−z_t)`。左右不对称时采用广义 play：`z_t = clamp(x_t, z_{t−1}−δ^{σ}, z_{t−1}+δ^{σ})`，`δ^{σ}` 按运动方向切换。HSE 维护 (δ̂⁻,δ̂⁺, z_t) 与分支置信度 `conf_t`（由可观测性/信噪比给出）。回差位移 `h_j = x_j − z_j`，其绝对值上界即 δ^σ。

**定义 188（位姿不确定管 PUT）** 关节空间误差集取 zonotope
`Z_t = ĉ_t ⊕ Σ_j ε_j e_j[−1,1]`，
`ĉ_t = ê(q_cmd) + d̂(τ̂)`，`ε_j = δ̂_j + k_σ·σ_j^pred + |∂d_j/∂τ_j|·Δτ_j`（k_σ=3 覆盖 99.7% 后验；Δτ_j 为载荷不确定带）。笛卡尔映射用一阶 Taylor + 确定性二阶余项：
`p(q_c+Δ) = p_c + J(q_c)Δ + ½ΔᵀHΔ + O(‖Δ‖³)`，
`P_t = p_c ⊕ J Z_t ⊕ ℬ(ρ₂)`，`ρ₂ = ½·L_H·ε_max²`，`L_H = sup_{‖Δ‖≤ε_max}‖H(q_c+Δ)‖₂`（区间算术或采样上界）。`J Z_t` 仍是 zonotope（中心 Jĉ，生成元 J e_j ε_j）。

**定义 189（齿轮感知净空 CCE）** 沿接近方向所需最小净空
`d_req(v,τ) = v·T_react + v²/(2a_max) + δ_hys + δ_comp(τ_max) + e_max + r_rob`
其中 `δ_hys = max(δ̂⁻,δ̂⁺)`，`δ_comp(τ_max)=κ₁τ_max+κ₃τ_max³`，`e_max = max_q|ê(q)|`，T_react 为感知-决策延迟，a_max 为可用减速度，r_rob 为固定鲁棒缓冲（取机身半径与最小工艺间隙）。`r_rob` 在 RCBF 中替换为 `r_robot + d_req`，使安全裕度随速度/载荷动态变化，而非固定系数。

**定义 190（鲁棒 CBF 避障滤波 RCBF）** 设障碍集合 𝒪，`h(x)=dist(x,𝒪)−r_robot` 为 1-Lipschitz 符号距离。定义方向感知鲁棒 barrier：
`h_rob(x_t) = dist(p_c,𝒪) − r_robot − d_req(v,τ) − σ_{P_t−p_c}(n)`，
其中 n 为从 p_c 指向最近障碍点的单位向量，`σ_{P−p_c}(n)=Σ_i|⟨J g_i,n⟩|+ρ₂` 为相对管在 n 方向的最大投影。安全滤波为
`u* = argmin_{u∈𝒰} ‖u−u_nom‖²_W  s.t.  L_f h_rob + L_g h_rob·u + α(h_rob) ≥ 0`，
离散实现用 `h_rob(x_{t+1}) ≥ (1−γ)h_rob(x_t)`。**QP 不可行 ⇒ 立即执行最大制动并令 AGS=stop**——可行性失败本身就是安全信号。

**定义 191（迟滞前馈 HFF）** `u_ff = H_{δ̂}⁻¹(q_des)` 为 play 算子的逆：给定期望输出序列，反解需要的指令增量。逆在不连续点/反转点附近非唯一，故在 `|σ_t|` 翻转窗口内关闭 HFF（滑模式门控）。**HFF 只进入 u_nom，不进入 h_rob 的任何一项**，因此逆模型错误不会削弱安全保证，只会降低跟踪性能。

**定义 192（磨损漂移 WDD）** 残差 `ρ_t = q_meas − q̂_pred(θ̂,η̂,δ̂)`。Page-Hinkley 统计量 `g_t = max(0, g_{t−1} + ρ_t − ν)`（双侧各一套），报警条件 `g_t > λ`。同时监控 `δ̂` 的慢漂与 RLS 信息矩阵的 PE 条件数 κ_PE。报警后：`Z_t` 按 Δδ_alarm 膨胀、冻结参数自适应、调度一段「激励性复标定」（在自由空间做多方向、带载的小幅往返，覆盖各傅里叶模态），并令 AGS 升一级。

**定义 193（自适应齿轮安全 AGS）** 四级阶梯与转移规则：

| 模式 | 触发 | 行为 |
|---|---|---|
| nominal | 覆盖 ≥1−α，κ_PE 正常，QP 可行 | 正常 RCBF，HFF 开启 |
| inflated | 覆盖边缘 / 轻微漂移 / 分支置信度下降 | Z_t 膨胀 k_infl 倍，HFF 关闭 |
| conservative | PE 差 / 管覆盖后验 < 阈值 / 多次报警 | 净空 ×k_cons，速度上限降低，仅 nominal 避障 |
| stop | RCBF QP 不可行 / 严重漂移 / 传感器失效 | 最大制动，拒绝新运动指令 |

AGS 与 ROSE 的 OCB 互锁：OCB 选择 MEL/对齐臂时不得突破 AGS 的降级阶梯（延续第 62 轮「硬降级规则为安全下界」）。

**定义 194（齿轮证书 J_hero）**
`J_hero = (J_rose, θ̂_ver, δ̂±, hash(P_t), cover, qp_feasible, mode)`。
验证规则：
`Valid(J_hero) ⇔ Valid(J_rose) ∧ cover ≥ 1−α ∧ qp_feasible ∧ mode ≤ inflated`
（`mode=conservative` 仅允许降速任务，`stop` 仅允许制动）。审计链：θ̂_ver 与 hash(P_t) 使「谁在何时改了误差模型/误差集合」可回放，延续第 62 轮 shield_hash / adapter_ver 的可追溯原则。

**定义 195（HERO 闭环算子）** 见 IP-202 伪代码。语义流执行 [残差提取 → TEL 更新 → HSE 更新 → PUT 构建 → WDD/AGS 决策 → J_hero 提交]；实时流执行 [读参数快照与锚点 → PUT 前向 → 支撑函数 → RCBF-QP → 派发]。所有写操作在语义流；实时流只做只读快照与 QP。

### IP-193 TEL（传动误差在线学习）

```python
class TransmissionErrorLearner:
    """傅里叶/齿啮合基 + 奇次柔度，带遗忘 RLS。仅语义流更新。"""
    def __init__(self, n_joint, ratio, teeth, K=6, lam=0.995, sigma_eps=1e-3):
        self.n, self.N, self.teeth = n_joint, ratio, teeth
        self.K, self.lam, self.sigma_eps = K, lam, sigma_eps
        self.theta = [np.zeros(2*K+1) for _ in range(n_joint)]     # e 参数
        self.eta   = [np.zeros(2) for _ in range(n_joint)]         # [k1,k3]
        self.P     = [1e3*np.eye(2*K+1) for _ in range(n_joint)]
        self.eta_P = [1e3*np.eye(2) for _ in range(n_joint)]

    def phi(self, q, j):
        # 频率集：输出1×,2× + 齿啮合 N×,2N× + 高次谐波
        ks = [1, 2, self.N[j], 2*self.N[j]] + list(range(3, 3+self.K))[:max(0,self.K-4)]
        feats = [1.0]
        for k in ks[:self.K]:
            feats += [np.cos(k*q), np.sin(k*q)]
        return np.array(feats)

    def psi(self, tau):
        return np.array([tau, tau**3])

    def update(self, q_cmd, q_meas, tau, h_hat):
        y = q_meas - q_cmd - h_hat                          # 待解释的确定性误差
        for j in range(self.n):
            phi = self.phi(q_cmd[j], j)                      # 运动学部分
            # 先扣柔度再看残差：交替最小二乘的一步
            y_e = y[j] - psi(tau[j]) @ self.eta[j]
            Kp, P = self.theta[j], self.P[j]
            denom = self.lam + phi @ P @ phi
            gain = (P @ phi) / denom
            Kp += gain * (y_e - phi @ Kp)
            P = (P - np.outer(gain, phi @ P)) / self.lam
            self.theta[j], self.P[j] = Kp, P
            # 柔度
            y_d = y[j] - phi @ Kp
            ps, Pe = psi(tau[j]), self.eta_P[j]
            den = self.lam + ps @ Pe @ ps
            ge = (Pe @ ps) / den
            self.eta[j] += ge * (y_d - ps @ self.eta[j])
            self.eta_P[j] = (Pe - np.outer(ge, ps @ Pe)) / self.lam
        return self.predict_var(q_cmd)

    def predict_var(self, q_cmd):
        out = []
        for j in range(self.n):
            phi = self.phi(q_cmd[j], j)
            var = self.sigma_eps**2 * (1 + phi @ self.P[j] @ phi)
            out.append(3.0*np.sqrt(max(var, 1e-12)))         # k_sigma = 3
        return np.array(out)
```

### IP-194 HSE（迟滞状态估计）

```python
class HysteresisStateEstimator:
    """play 算子 + 左右死区在线估计 + 分支置信度。"""
    def __init__(self, n_joint, delta0=0.002, delta_max=0.02, lr=1e-4):
        self.n = n_joint
        self.delta = np.full((n_joint, 2), delta0)           # [δ⁻, δ⁺]
        self.z = np.zeros(n_joint)
        self.x_prev = np.zeros(n_joint)
        self.delta_max, self.lr = delta_max, lr

    def update(self, x, q_meas_resid, tau):
        # x: 去除确定性误差后的指令增量；q_meas_resid: 实测残差
        conf = np.ones(self.n)
        for j in range(self.n):
            d = self.delta[j, 1] if x[j] >= self.x_prev[j] else self.delta[j, 0]
            z_new = np.clip(x[j], self.z[j] - d, self.z[j] + d)
            # clamp(x, z-δ, z+δ) 等价于 play；|x - z_new| <= d
            err = q_meas_resid[j] - (x[j] - z_new)
            # 用残差符号与大小调死区（保守：只允许缓慢增大，快速缩小）
            if err > 0:   self.delta[j, 1] = min(self.delta_max, self.delta[j, 1] + self.lr*err)
            elif err < 0: self.delta[j, 0] = min(self.delta_max, self.delta[j, 0] - self.lr*err)
            self.z[j] = z_new
            # 分支置信度：x-z 越接近 0 或越接近 δ，分支越模糊
            margin = abs(x[j] - z_new) / max(d, 1e-9)
            conf[j] = min(1.0, margin)                       # 0=完全不可辨,1=清晰
            self.x_prev[j] = x[j]
        return self.delta, self.z, conf

    def bounds(self):
        return self.delta[:, 0].copy(), self.delta[:, 1].copy()
```

### IP-195 PUT（位姿不确定管）

```python
class PoseUncertaintyTube:
    def __init__(self, n_joint, H_norm=1.0):
        self.n, self.L_H = n_joint, H_norm

    def build_joint_zonotope(self, e_hat, d_hat, delta, sigma_pred, dtau, dD_tau):
        # 逐关节标量半径；生成元沿关节轴
        eps = delta.max(axis=1) + sigma_pred + np.abs(dD_tau) * dtau
        center = e_hat + d_hat
        return center, eps                                  # Z = center + diag(eps)[-1,1]^n

    def to_cartesian(self, p_c, J, center, eps):
        c_j = J @ center
        gens = J * eps[None, :]                             # 每列一个生成元
        eps_max = np.linalg.norm(eps)
        rho2 = 0.5 * self.L_H * eps_max**2
        return p_c + c_j, gens, rho2

    def support(self, gens, rho2, n):
        # support of Σ_i g_i[-1,1] + B(rho2) along unit n
        return np.sum(np.abs(gens.T @ n)) + rho2
```

### IP-196 CCE + IP-197 RCBF（净空与安全滤波）

```python
def clearance_envelope(v, tau_max, kappa, delta_hys, e_max,
                       T_react=0.05, a_max=5.0, r_rob=0.02):
    braking = v * T_react + v**2 / (2.0 * a_max)
    comp = kappa[0]*tau_max + kappa[1]*tau_max**3
    return braking + delta_hys + comp + e_max + r_rob

def robust_cbf_qp(u_nom, p_c, J, gens, rho2, obstacles,
                  epsilon, alpha=2.0, r_robot=0.05, v=0.0, tau_max=0.0,
                  kappa=(0.0,0.0), delta_hys=0.0, e_max=0.0):
    # 1) 最近障碍与方向
    d_min, n_dir = nearest_obstacle(p_c, obstacles)
    d_req = clearance_envelope(v, tau_max, kappa, delta_hys, e_max, r_rob=r_robot)
    # 2) 方向感知支撑
    support = np.sum(np.abs(gens.T @ n_dir)) + rho2
    h_rob = d_min - d_req - support
    if h_rob < 0:
        return 'BRAKE', h_rob                            # 已进入危险管，硬停
    # 3) 离散 CBF-QP
    A, b = cbf_linearization(p_c, n_dir, u_nom, h_rob, alpha, epsilon)
    u = solve_qp(np.eye(epsilon.shape[0]), u_nom, A, b)
    if u is None:
        return 'BRAKE', h_rob                            # 不可行=安全信号
    return u, h_rob
```

### IP-198 HFF（迟滞前馈）

```python
def inverse_play(q_des, delta, z0, gate):
    """逆 play；反转窗口内关闭，避免非唯一解放大噪声。"""
    if not gate:
        return q_des                                    # 直通：安全不依赖它
    x = np.empty_like(q_des)
    z = z0
    for t, qd in enumerate(q_des):
        lo, hi = z - delta, z + delta
        x[t] = np.clip(qd, lo, hi) if t == 0 else qd     # 简化逆
        z = np.clip(x[t], z - delta, z + delta)
    return x
```

class WearDriftDetector:
    def __init__(self, nu=0.0, lam=0.05, delta_alarm=0.002):
        self.g_pos = self.g_neg = 0.0
        self.nu, self.lam, self.delta_alarm = nu, lam, delta_alarm

    def push(self, resid):
        self.g_pos = max(0.0, self.g_pos + resid - self.nu)
        self.g_neg = max(0.0, self.g_neg - resid - self.nu)
        alarm = max(self.g_pos, self.g_neg) > self.lam
        return alarm, self.delta_alarm

    def reset(self):
        self.g_pos = self.g_neg = 0.0

def HERO_step(M, q_cmd, q_meas, tau, obstacles):
    # ———— 语义流（10–100Hz）：全部学习与证书 ————
    h_hat = M.hse.z - M.hse.x_prev                       # 当前回差位移估计
    sigma_pred = M.tel.update(q_cmd, q_meas, tau, h_hat) # TEL

    e_hat = M.tel.predict(q_cmd); d_hat = M.tel.compliance(tau)

        e_hat, d_hat, delta, sigma_pred, M.tau_band, M.dD_tau)

        eps = eps * INFLATE[mode]                         # 只膨胀，不赌模型
    M.snapshot = (center, eps, mode)                      # 原子发布

    # ———— 实时流（1–10kHz）：只读快照，零学习写 ————

                             delta_hys=delta.max(), e_max=np.abs(e_hat).max())
    M.qp_feasible = (u != 'BRAKE')
    if u == 'BRAKE': u = M.brake()
    M.cover = M.coverage_monitor.update(q_meas, pc_shift, gens, rho2)

                           hash_tube(gens), M.cover, M.qp_feasible, mode)

## 4. 推导

**引理 1（play 精确界）** 归纳。基例由初始化保证 |x₀−z₀|≤δ。设 |x_{t−1}−z_{t−1}|≤δ。令 `z_t = max(x_t−δ, min(x_t+δ, z_{t−1}))`。因为 `min(x_t+δ,z_{t−1}) ≤ x_t+δ` 且 `max(x_t−δ,·) ≥ x_t−δ`，故 `z_t ∈ [x_t−δ, x_t+δ]`，即 `|x_t−z_t|≤δ`。对广义 play 与左右不对称 δ^σ 同理逐分支成立。∎
**意义**：回差对位置的贡献是一个宽度 2δ 的**确定性区间**，无需概率模型——这正是构造 zonotope 生成元的合法性来源。

**引理 2（zonotope 映射 + 二阶余项）** 由 `p(q+Δ) = p(q)+JΔ+R(Δ)`，`R(Δ)=½ΔᵀH(q+ξΔ)Δ`。故 `‖R(Δ)‖₂ ≤ ½‖H‖₂‖Δ‖² ≤ ½L_H‖Δ‖² = ρ₂`（对 `‖Δ‖≤ε_max`）。`J Z_t = Jĉ ⊕ Σ_j(J e_j ε_j)[−1,1]` 仍是 zonotope（仿射映射保 zonotope）。故 `p_true ∈ p_c ⊕ J Z_t ⊕ ℬ(ρ₂) = P_t`。∎
**支撑函数**：`σ_{P_t−p_c}(n) = Σ_j|⟨J e_j ε_j,n⟩| + ρ₂ = Σ_j ε_j|⟨J e_j,n⟩| + ρ₂`，逐项 O(1)，合计 O(n)。

**引理 3（管覆盖）** 设 TEL 后验满足 `P[∀j |e_true,j−ê_j| ≤ k_σ σ_j^pred] ≥ 1−α₁`（高斯后验或次高斯尾界），HSE 满足 `P[δ_true,j ∈ [δ̂_j⁻−Δ, δ̂_j⁺+Δ]] ≥ 1−α₂`；载荷 `|τ_j|≤τ_max` 为确定性界，柔度误差 `|d_true−d̂| ≤ |∂d/∂τ|Δτ` 由中值定理给出。并集界：`P[Δ_true ∈ Z_t] ≥ 1−α₁−α₂`。再由引理 2，`P[p_true ∈ P_t] ≥ 1−α₁−α₂`。令 α=α₁+α₂。∎

**定理 1（鲁棒无碰撞）** 设 `p_true ∈ P_t`，且 RCBF 在全部时刻保持 `h_rob ≥ 0`。取 n 为从 p_c 指向 𝒪 最近点的单位向量。对任意 `p ∈ P_t`，`⟨p−p_c, n⟩ ≤ σ_{P_t−p_c}(n)`，故 `dist(p,𝒪) ≥ dist(p_c,𝒪) − σ_{P_t−p_c}(n) ≥ r_robot + d_req > 0`。因此真实末端与障碍不相交。若覆盖仅以概率 1−α 成立，则碰撞概率 ≤ α。∎
**注**：这是「集合不相交」的机制保证；误差被覆盖而非被消除，与第 62 轮引理 2（偏差免疫）同构。

**命题（净空充分性）** 在一个反应周期 T_r 内末端沿接近方向的位移不超过 v·T_r（速度界），制动阶段位移不超过 v²/(2a_max)（匀减速运动学上界）；传动附加位移由引理 1 与柔度上界限制在 δ_hys+δ_comp(τ_max)，运动学误差限制在 e_max。四项之和 d_req 是「为停下并保持不穿透」所需净空的确定性上界。以 d_req 作为 h_rob 的固定项，故在最大速度/载荷下仍不穿透。∎

**命题（HFF 安全无关）** h_rob 仅依赖 (dist, r_robot, d_req, P_t)，其中 P_t 由 TEL/HSE/WDD 与观测数据构成，不读取 u_ff。因此 HFF 的逆模型误差只改变 u_nom 与跟踪性能，`h_rob ≥ 0` 的认证条件不变。即使逆 play 在反转点发散或门控关闭，安全滤波仍以集合覆盖兜底。∎

**命题（PE 与辨识）** RLS 在持续激励 `Σ_{i=t−W}^{t} φ_iφ_iᵀ ⪰ c I` 下指数收敛到真参数；无 PE 时 P_t 膨胀，`σ_j^pred` 增大，经引理 3 使 Z_t 膨胀——**辨识退化被自动转写为保守安全集**，而非静默的错误置信。κ_PE 因此既是诊断量，也是 AGS 的输入。∎

**命题（WDD 检测延迟）** 对残差均值由 ν₀ 跳变到 ν₁ 的 Page-Hinkley 检验，在给定误报率 α_fa 下平均检测延迟 `E[τ] ≳ log(1/α_fa)/KL(ν₁‖ν₀)`（标准 CUSUM/PH 结论）。λ 按 α_fa 标定，故磨损检出时间随偏差幅度对数下降；小幅慢漂由 δ̂ 的慢积分与 κ_PE 兜底。∎

**正确性定理（HERO-Safe）** 假设第 62 轮 A61–A76 及：
- **(A77)** 持续激励：存在窗口 W 使 `Σφφᵀ ⪰ cI`，或当不满足时 κ_PE 检出并驱动 AGS 保守化。
- **(A78)** play 模型结构误差有界：真实迟滞与理想 play 的偏差 ≤ Δ_struct，且 Δ_struct 计入 ε_j。
- **(A79)** 雅可比在管半径内非奇异，`‖J‖₂` 与 `L_H` 有可计算上界。
- **(A80)** 感知-决策延迟 ≤ T_react，制动减速度可达 a_max。
- **(A81)** 障碍几何可观测，最近点距离计算误差 ≤ Δ_obs 并计入 r_rob。

则：
1. **鲁棒无碰撞**：`P[p_true ∈ P_t] ≥ 1−α` 且 RCBF 保持 `h_rob≥0` ⇒ 碰撞概率 ≤ α（定理 1）。
2. **误差可学**：有 PE 时 TEL 收敛；无 PE 时 `σ_j^pred` 增大使安全集自动膨胀（命题 PE）。
3. **安全与补偿解耦**：HFF 失败不影响安全认证（命题 HFF）。
4. **磨损可察**：WDD 检出后只膨胀不赌模型，AGS 单调降级。
5. **可审计**：J_hero 记录参数版本、死区、管生成元哈希、覆盖率、QP 可行性与模式，实现「谁改了误差模型」的回放。
6. **实时性不变**：语义流承担全部学习写，实时流 ≤1ms、零学习写（继承 A75）。

## 7. 已知风险

**一句话**：HSE/TEL 的核心参数（迟滞死区 δ、误差场的未激励模态）只在「方向反转 + 有载」时可观，而一个工作良好的避障控制器恰恰倾向平滑、少反转、避接触——**安全行为本身压制了辨识所需的信息**；一旦在低激励下 δ 被低估，PUT 欠膨胀，RCBF 便在「纸面安全」中放行一次真实穿透，这是本轮全部安全论证共同依赖的单点假设（A77）。

**次级风险与缓解**：
1. **接触柔度正反馈**：接触力使关节偏转 → 穿透增大 → 接触力增大（正反馈），可能吞噬净空。缓解：CCE 显式计入 τ_max 下的柔度；接触阶段改用接触力测量更新 τ；必要时以接触阻抗上限钳制。
2. **线性化失效**：接近奇异位形或大 Δ 时一阶 Jacobian + 二阶球不够。缓解：区间 FK 兜底、按 ‖J‖ 条件数降速、在奇异邻域改用保守包络。
3. **play 模型失配**：真实迟滞可能是率相关/Preisach 型。缓解：A78 的结构误差计入 ε_j；用非参数残差包络随数据膨胀；E216 专门检验。
4. **多关节误差累积与保守性**：zonotope 的生成元相加使管偏保守，尤其多关节同向误差。缓解：利用关节误差相关性（同批磨损）做低秩生成元，牺牲少量保守性换取通过性；或用精确集近似。
5. **WDD 误报**：负载/温度变化被误判为磨损。缓解：把温度与负载作为回归量分离工况效应；双侧 PH + 多尺度窗口。
6. **标定激励与任务冲突**：避障任务不鼓励激励性运动。缓解：在自由空间/空闲时段做机会式激励；无法激励时停在 conservative，不冒险声称 nominal。
7. **感知延迟超界**：T_react 被低估时 CCE 失效。缓解：在线测量感知-决策延迟并反馈到 d_req；超过阈值即降级。

**与 ROSE 的接口**：J_hero 内嵌 J_rose；AGS 阶梯对 OCB 构成硬下界；TEL/HSE 的参数快照与 RSC 的球半径共享「语义流写、实时流读」的原子发布机制。HERO 不改变 ROSE 的在线学习/场景银行逻辑，只在其安全出口处增加机械层覆盖——**学习越激进，越需要这一层把「可能的不准」变成「可证的保守」**。
