### 第 1 轮灵感驱动研究记录（新循环）

**灵感词**：差异化定位、机器人操作系统

**直觉与动机**：

上一轮的 CADVS 已经把证书链铺进了 ROS2 节点图，但定位环节仍保留了一个隐含的「同质化假设」：DLC 对所有机器人、所有任务阶段都使用同一套「取 λ_max 最小源」的融合规则。这在实验室可行，在异构集群里会失效——室外巡检机器人靠 RTK，室内仓储机器人靠 UWB，崎岖地形的腿式机器人更信腿式里程计与 VIO。把「差异化定位」拆成两层来读，恰好同时击中两个要害：

1. **差分定位（differential）**：用基准站/相邻节点做差分，消除共模误差。CADVS 的 DLC 只做了「多源选优」，没有把「差分基准本身的可信度」当成一等公民——基准漂移时，所有差分结果会一起偏，而 λ_max 可能仍然很小，形成「虚假可信」。
2. **差异化定位（differentiated）**：每台机器人、每个任务阶段拥有自己的「定位画像」（用哪些模态、怎么融合、用什么证书方言、什么 QoS），而不是一套规则打天下。差异化提升适应性，但立刻引入「证书方言不可通约」的问题：A 用 RTK 证书、B 用 UWB 证书，谁更可信？怎么比较？

**机器人操作系统**在这里不只是运行时容器，而是「定位画像」的调度平面：ROS2 lifecycle 节点天然适合做可热插拔的定位模态；DDS QoS 决定不同画像的通信契约（RTK 低频可靠 vs VIO 高频尽力）；composition + 零拷贝把画像切换的代价压到可接受范围。于是「差异化定位 × ROS」不是两个词的拼接，而是一个具体架构：**可热插拔的定位画像 + 跨画像的证书汇率 + 参考画像共识**。

**关键洞见**：差异化与可比较性是一对根本张力。若允许每个画像用自己的不确定性度量，则不存在既「对所有画像都诚实」又「误差任意小」的统一规范化——这是一个可证明的权衡（下文的「无免费差异化」定理）。工程出路不是消除差异，而是**局部差异化、全局可比较**：本地控制用差异化画像（高频、贴任务），跨机共识只在所有机器人都能实例化的「影子参考画像 P_0」上进行（低频、同方言）。差异化留在边缘，可比性锚在共识层。

**形式化目标（增量）**：
1. 定义定位画像 P=(M, Φ, C, Q, T) 与画像间差异化散度 D(P_i,P_j)。
2. 定义规范化不确定度映射 cu_P(u)=ρ_P·u+b_P（汇率 ρ_P、偏置 b_P），以及影子参考画像 P_0。
3. 证明「差异化—可比较性权衡」：若要求 cu_i 与 cu_j 在同一物理状态下一致，则规范化误差 ε_can ≥ D/2（无免费差异化）。
4. 定义画像切换守卫 PSIG（最小驻留 + 迟滞 + PPC 有效窗），保证 Exec_DPB ⊆ Exec_CADVS。
5. 证明参考画像共识下的可用性增益 A_pos(DPB) ≥ max_P A_pos(P)，并给出 3 机异构实验验证设计：可用性提升 ≥15%、切换振荡 <0.5Hz、包含性 100% 保持、规范化误差 ≤ ε_can。

**本轮最大风险**：**差异化定位诱发「证书语义碎片化 + 定位唯我论」**——每台机器人用自己画像的证书自证可信，而汇率 ρ_P 随工况漂移，跨机一致性在全局层面失效；系统在本地「全部通过」，在集群层面却已悄悄分叉。

### IP-478 Differentiated Positioning Broker (DPB)

```python
# cadvs_dpb/dpb_node.py
from dataclasses import dataclass
from rclpy.lifecycle import LifecycleNode, TransitionCallbackReturn

@dataclass(frozen=True)
class PositioningProfile:
    pid: str
    modalities: frozenset[str]        # {'rtk','uwb','vio','leg_odom','wheel_odom'}
    fusion: str                       # 'min_lambda' | 'cov_intersection' | 'factor_graph'
    cert_schema: str                  # 方言标识，如 'dlc_v1'
    qos: str                          # QoS 注册表键
    phases: frozenset[str]            # {'transit','docking','manipulation','rough'}
    rho: float = 1.0                  # 到参考画像的汇率（先验）
    b: float = 0.0                    # 汇率偏置
    eps_can: float = 0.0              # 规范化误差界
    recent_unc: float = 1.0           # 最近一次局部不确定度（运行时刷新）

class DifferentiatedPositioningBroker(LifecycleNode):
    """IP-478：定位画像的注册、选择、热切换与 PPC 发布"""

    def __init__(self):
        super().__init__('dpb')
        self.registry: dict[str, PositioningProfile] = {}
        self.active: PositioningProfile | None = None
        self.active_since = 0.0
        self.guard = ProfileSwitchInvarianceGuard()
        self.cue = CanonicalUncertaintyExchange()
        self.shadow: PositioningProfile | None = None      # P_0
        self.lambda_cu, self.lambda_switch = 1.0, 0.1

    def on_configure(self, state):
        cfg = self._load_yaml('positioning_profiles.yaml')
        for item in cfg['profiles']:
            self.registry[item['pid']] = PositioningProfile(**item)
        self.shadow = self.registry[cfg['reference_profile']]
        self._activate_modalities(self.shadow.modalities, rate_hz=10)  # 影子常驻低频
        return TransitionCallbackReturn.SUCCESS

    def on_activate(self, state):
        self.active = self._default_profile()
        self.active_since = self._now()
        self._activate_modalities(self.active.modalities, rate_hz=200)
        return TransitionCallbackReturn.SUCCESS

    def select_profile(self, phase: str, health: dict[str, float]) -> PositioningProfile:
        """按阶段 + 可用性 + 规范化不确定度打分；返回最优候选（可能是当前画像）"""
        best, best_score = self.active, float('-inf')
        for p in self.registry.values():
            if phase not in p.phases:
                continue
            a = self._availability(p, health)                       # ∈[0,1]
            cu = self.cue.canonical(p, p.recent_unc)
            score = a - self.lambda_cu * cu - self.lambda_switch * self._divergence(self.active, p)
            if score > best_score:
                best, best_score = p, score
        return best

    def try_switch(self, target: PositioningProfile, t_now: float) -> SwitchCert:
        if target.pid == self.active.pid:
            return SwitchCert(ok=True, switched=False)
        ok = self.guard.admit(self.active, target, self.active_since, t_now,
                              self.cue, self.shadow)
        if not ok:
            return SwitchCert(ok=False, switched=False, reason='guard_reject')
        # ROS2 lifecycle 热切换：先加后减，避免定位空窗
        added = target.modalities - self.active.modalities
        removed = self.active.modalities - target.modalities
        self._activate_modalities(added, rate_hz=200)
        if not self._wait_healthy(added, timeout=0.100):
            self._deactivate_modalities(added)
            return SwitchCert(ok=False, switched=False, reason='new_modality_unhealthy')
        self._deactivate_modalities(removed)
        old, self.active = self.active, target
        self.active_since = t_now
        return SwitchCert(ok=True, switched=True, frm=old.pid, to=target.pid,
                          t_switch=t_now, ppc=self.publish_ppc())
```

### IP-479 Positioning Profile Certificate (PPC)

```python
@dataclass
class PositioningProfileCertificate:
    """IP-479：画像级证书——回答『当前凭什么定位』，并声明其可比性"""
    pid: str
    modalities: tuple[str, ...]
    fusion: str
    rho: float
    b: float
    canonical_unc: float       # cu_P(u_now)
    eps_can: float
    t_gen: float
    window: float
    shadow_unc: float          # 同一时刻影子参考画像的不确定度

    def valid(self, t_now: float) -> bool:
        return (t_now - self.t_gen) < self.window

    def comparable_to_reference(self, delta: float = 0.05) -> bool:
        # |cu_P − shadow_unc| / shadow_unc ≤ delta
        denom = max(abs(self.shadow_unc), 1e-9)
        return abs(self.canonical_unc - self.shadow_unc) <= delta * denom

    def to_msg(self) -> dict:
        return {
            'cert_id': 'ppc', 'src_node': 'dpb', 't_stamp': self.t_gen,
            'validity_window': self.window,
            'payload': {
                'pid': self.pid, 'modalities': list(self.modalities),
                'fusion': self.fusion, 'rho': self.rho, 'b': self.b,
                'cu': self.canonical_unc, 'eps_can': self.eps_can,
                'shadow_unc': self.shadow_unc,
            },
        }
```

### IP-480 Canonical Uncertainty Exchange (CUE)

```python
class CanonicalUncertaintyExchange:
    """IP-480：画像不确定度 → 参考画像不确定度的汇率标定与折算"""

    def __init__(self, huber_delta: float = 1.0, max_eps: float = 0.15):
        self.calib: dict[str, tuple[float, float]] = {}   # pid -> (rho, b)
        self.huber_delta = huber_delta
        self.max_eps = max_eps

    def fit(self, pid: str, u_local: np.ndarray, u_ref: np.ndarray):
        """共观测窗口内的成对样本做 Huber 仿射回归 u_ref ≈ rho*u_local + b"""
        rho, b, eps = robust_affine_fit(u_local, u_ref, self.huber_delta)
        self.calib[pid] = (rho, b)
        return rho, b, eps

    def canonical(self, p: PositioningProfile, u_local: float) -> float:
        rho, b = self.calib.get(p.pid, (p.rho, p.b))
        return rho * u_local + b

    def is_trustworthy(self, p: PositioningProfile) -> bool:
        """汇率漂移或规范化误差超界 → 该画像不得进入共识（但可本地使用）"""
        rho, b = self.calib.get(p.pid, (p.rho, p.b))
        return abs(rho - p.rho) <= self.max_eps and abs(b - p.b) <= self.max_eps
```

### IP-481 Profile-Switch Invariance Guard (PSIG)

```python
class ProfileSwitchInvarianceGuard:
    """IP-481：画像切换守卫——最小驻留 + 迟滞 + 影子有效窗"""

    def __init__(self, H_min: float = 0.5, H_hys: float = 1.15,
                 shadow_window: float = 0.2):
        self.H_min = H_min
        self.H_hys = H_hys
        self.shadow_window = shadow_window

    def admit(self, old, new, old_since: float, t_now: float,
              cue: CanonicalUncertaintyExchange, shadow) -> bool:
        if t_now - old_since < self.H_min:
            return False                                  # 防抖：最小驻留
        cu_old = cue.canonical(old, old.recent_unc)
        cu_new = cue.canonical(new, new.recent_unc)
        if not (cu_new * self.H_hys <= cu_old):
            return False                                  # 迟滞：必须显著更优
        if not cue.is_trustworthy(new):
            return False                                  # 汇率不可信 → 禁止切换
        # 切换全过程影子参考画像必须可用，保证共识不断线
        return bool(shadow.available and shadow.age < self.shadow_window)
```

### IP-482 Reference-Profile Consensus Layer (RPCL)

```python
class ReferenceProfileConsensus:
    """IP-482：只在影子参考画像 P_0 方言上做跨机一致性检查"""

    def __init__(self, gamma_consist: float = 0.05):
        self.gamma_consist = gamma_consist
        self.peer_shadow: dict[str, ShadowState] = {}

    def on_peer_shadow(self, pid: str, state: ShadowState):
        self.peer_shadow[pid] = state

    def check(self, local_shadow: ShadowState) -> tuple[bool, list[str]]:
        violations = []
        for pid, peer in self.peer_shadow.items():
            if not peer.fresh():
                continue
            err = np.linalg.norm(local_shadow.pose - peer.pose - peer.delta_rel)
            if err > self.gamma_consist:
                violations.append(f'{pid}: pose_err={err:.3f} > {self.gamma_consist}')
        return len(violations) == 0, violations
```

### DPB 单步执行流

```python
def dpb_step(robot_state, sensor_data, phase: str) -> ControlOutput:
    """差异化定位单步：影子共识锚点 + 画像选择/切换 + CADVS 证书消费"""
    # 1) 影子参考画像常驻，产出共识锚点（低频，永远同方言）
    shadow_cert = dpb.shadow_step(sensor_data)
    if not shadow_cert.valid:
        return fallback_to_teacher(robot_state, sensor_data, reason='shadow_unavailable')

    # 2) 差异化画像选择与受守卫切换
    target = dpb.select_profile(phase, sensor_data.health)
    dpb.try_switch(target, t_now=sensor_data.t)        # 被拒则沿用当前画像

    # 3) 当前画像产出 PPC + 定位证书
    ppc = dpb.publish_ppc()
    loc_cert = dpb.active_step(sensor_data)
    if not ppc.valid(t_now=sensor_data.t):
        return fallback_to_teacher(robot_state, sensor_data, reason='ppc_expired')
    if not ppc.comparable_to_reference():
        return fallback_to_teacher(robot_state, sensor_data, reason='ppc_not_comparable')

    # 4) 复用 CADVS 单步：仅把定位证书源替换为当前画像
    return cadvs_step(robot_state, sensor_data, loc_cert=loc_cert, ppc=ppc)
```

## 4. 正确性论证（增量更新）

### 定义 1（定位画像与差异化散度）

设画像 P_i 对同一物理状态 x 给出局部不确定度 u_i(x)（m）。定义差异化散度
D(P_i,P_j) = sup_x |u_i(x) − u_j(x)| / u_ref，
其中 u_ref 为参考尺度。D 度量两画像在「同一现实」上给出不同不确定性判断的最大归一化分歧。

### 引理 32（汇率一致性的误差传递）

**陈述**：若对每个画像 P 与状态 x，规范化映射满足 |cu_P(u_P(x)) − u*(x)| ≤ ε_can（u* 为参考画像下的真实规范化不确定度），则同一状态上两画像的规范化结果之差满足 |cu_i(u_i(x)) − cu_j(u_j(x))| ≤ 2ε_can。

**证明**：由三角不等式，
|cu_i(u_i) − cu_j(u_j)| ≤ |cu_i(u_i) − u*| + |u* − cu_j(u_j)| ≤ ε_can + ε_can = 2ε_can。∎

**工程含义**：跨画像比较的误差上界完全由规范化误差界 ε_can 决定；只要 PPC 如实声明 ε_can，比较结论就带可验证误差条。

### 定理 33（差异化—可比较性权衡 / 无免费差异化）

**陈述**：若要求规范化「一致」，即 ∀P,Q,x：cu_P(u_P(x)) = cu_Q(u_Q(x)) =: c(x)（同一共同货币），则规范化误差
ε_can := max_{P,x} |c(x) − u_P(x)| ≥ (1/2)·D(P_i,P_j)·u_ref
对任意一对使 D 取上确界的画像成立。特别地，ε_can = 0 迫使 D = 0（无差异化）。

**证明**：取达到 sup 的状态 x 与画像对 (P_i,P_j)，记 a = u_i(x)、b = u_j(x)，则 |a−b| ≥ D·u_ref。c(x) 是实轴上一点，它到 a、b 中较远者的距离 ≥ |a−b|/2 ≥ D·u_ref/2，故 max(|c−a|,|c−b|) ≥ D·u_ref/2。对全部画像取最大即得 ε_can ≥ D·u_ref/2。若 ε_can=0，则 |a−b|≤0，故 D=0。∎

**推论（设计原则）**：不存在「既高度差异化、又零误差可比较」的免费午餐。CADVS-DPB 的出路是把「一致性」的适用范围从「所有画像两两之间」收缩到「参考画像 P_0 与自身」——在 P_0 上 D=0，ε_can 可任意小；其余画像只需向 P_0 报备 ε_can 并按 PPC 门控。这就是「局部差异化、全局可比较」。

### 引理 34（画像切换的执行集不变性）

**陈述**：若 PSIG 仅在 (i) 驻留时间 ≥ H_min、(ii) cu_new·H_hys ≤ cu_old、(iii) new 汇率可信、(iv) 影子参考画像有效 时放行切换，且 PPC 门控要求 cu_P ≤ λ_thresh，则 Exec_DPB ⊆ Exec_CADVS，且单位时间内切换次数有限（无 Zeno 行为）。

**证明**：
- 执行集：DPB 单步最终调用 cadvs_step，仅替换定位证书源。PPC 门控 cu_P ≤ λ_thresh 经单调仿射映射（ρ_P>0）对应到参考画像的 DLC 门控 λ_max(Σ_rel) < λ_thresh，至少与 CADVS 同等严格；cert_agg.all_passed、教师路径、回退路径均原样复用。故每一步仍落在 Exec_CADVS。
- 无 Zeno：每次成功切换后驻留 ≥ H_min，故任意时间区间内切换次数 ≤ ⌈Δt/H_min⌉ + 1，有限。∎

### 定理 35（参考画像共识下的可用性增益）

**陈述**：设各画像在阶段 phase 的可用性为 A_pos(P,phase)。RPCL 让本地控制取 argmax_P A_pos(P,phase)，而共识恒用 P_0。则对每个阶段
A_pos(DPB, phase) ≥ max_P A_pos(P, phase) ≥ A_pos(single, phase)，
当且仅当存在单一画像在所有阶段均最优时取等号；若画像在阶段间互补（各自在某阶段最优），则严格改进。

**证明**：DPB 的选择打分以可用性为主项（λ_cu、λ_switch 仅作惩罚），在候选集合内取得 argmax，故 A_pos(DPB) ≥ max_P A_pos(P)；单画像基线只能取固定 P，故 max_P ≥ A_pos(single)。RPCL 恒用 P_0，使共识可用性与本地画像解耦，不引入额外可用性损失。互补情形下 argmax 随阶段变化，严格优于任一固定画像。∎

**诚实声明**：定理 35 的增益是「证书门控下的尽力增益」：若某阶段最优画像的 cu 超过 λ_thresh，PSIG 会拒绝切换并回退到 P_0，此时增益为零但不损失安全性。真正的风险不在增益公式，而在 ε_can 的在线估计是否诚实（见 R33/R35）。

### 实验设计（验证方案）

| 场景 | 模态可用性 | 基线 | 本方案 | 主指标 |
|---|---|---|---|---|
| 室内外切换 | 室外 RTK 好、室内 UWB 好、VIO 恒有 | v30 DLC 单画像 | DPB 差异化画像 | A_pos、切换次数 |
| 崎岖地形 | leg_odom 强、RTK 间歇 | 固定 VIO+RTK | DPB 选 leg_odom 画像 | 定位漂移、任务成功率 |

**消融**：去掉 CUE（直接比较原始 u）、去掉 PSIG（无迟滞）、去掉影子参考画像（用各自画像做共识）。预期：去掉 CUE/影子后跨机一致性误报显著上升；去掉 PSIG 后切换振荡 > 2Hz。**预期结果**：A_pos 提升 15–25%，切换振荡 < 0.5Hz，Exec 包含性 100% 保持，跨机一致性误差 ≤ γ_consist，规范化误差 ≤ 声明 ε_can。

## 6. 本轮最大风险（最终确认）

**一句话**：**差异化与可比较性的根本张力**——差异化定位让每台机器人获得贴合自身任务的定位能力，但定理 33 表明「高度差异化」与「低误差可比较」不可兼得；一旦 CUE 的汇率在工况漂移中失真、或影子参考画像 P_0 被同一物理扰动同时击穿，系统会陷入「每台机器人本地全部通过、集群共识却已悄然分叉」的定位唯我论，这比单机定位失败更危险，因为它以「分布式一致性已满足」的假象掩盖了集体失准。
