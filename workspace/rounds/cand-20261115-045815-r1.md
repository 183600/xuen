# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「具身智能大模型」×「多任务学习」）

> R69 把不确定性一分为二（aleatoric / epistemic），并给系统装上了嘴巴和眼睛：能问、能看、能摸。但它有一个从未被检验的前提——**系统始终知道自己正在做哪一个任务**。这个前提在单任务闭环里成立，在「具身智能大模型」里恰恰不成立：一个共享参数的基础模型要同时覆盖几十上百个任务，动作分布本质上是**任务条件分布**，而「我在哪个任务里」本身是一个隐变量。R69 的流似然 FMA 因此被两件事同时污染：
> (a) **稀有任务税**：池化似然把「这个任务罕见」误算成「行为异常」；
> (b) **歧义松弛**：池化似然在任务后验弥散时会偏低，低似然被误读成「安全」。
> 更麻烦的是「多任务学习」的固有代价：**负迁移**让每个任务的真实能力并不均匀，一个全局校准的置信度不是能力的充分统计量；而**组合泛化**——基础模型最大的红利——恰恰是逐任务证书覆盖不到的接缝盲区。
>
> 核心命题：**把「任务」提升为一等公民——先估任务身份，再用任务条件似然做故障诊断，用能力/干扰证书刻画「我这一招到底有多可信」，用组合 DAG 判断「没练过的任务组合」能不能信；所有任务级信号默认只增加保守，任何放松都必须由 k+1 个正交证据的任务证书来「挣得」。** 命名 **FACET-RAS**（Foundation-model Adaptive Competence and task-Evidence Tracing）——大模型像一颗多切面的宝石，每个任务是一个切面：必须知道自己正在看哪一面，以及那一面切得有多好。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我到底在做哪个任务、我这套本事在哪个任务上可信**」——不确定性有第三个轴：任务的轴。

## 0. 直觉与动机

**灵感 1（具身智能大模型 → 似然是任务条件的，不是边缘的）**
直觉：一个基础模型的动作密度不是一个 p(ξ|o)，而是一族 {p(ξ|o,τ)} 的混合。观测和指令只能给出任务后验 p(τ|o,q)，给不出任务本身。R69 的 FMA 直接在池化密度上取负对数，等于把「任务先验」偷偷算进了「行为异常」。同一个动作，在常见任务里正常，在稀有任务里被误报；同一处异常，在常见任务里被稀释，在罕见任务里被放大。**池化似然不是「行为异常」的充分统计量。**

**灵感 2（多任务学习 → 能力是任务相关的，且会被别的任务拖累）**
直觉：联合训练不是把 N 个单任务模型装进一个盒子；参数共享会互相拉扯。任务 j 的梯度若与任务 τ 反向，任务 τ 的能力就会下降——这就是负迁移。于是「模型有多自信」与「模型在这个任务上有多能干」是两件事。需要一个**能力证书**（每任务的分层 held-out 风险）和一个**干扰矩阵**（任务两两之间的迁移税），把「我知道」与「我能做」分开。更妙的是，干扰矩阵还能反过来指导架构：κ 高的任务应被分到不同专家（冲突驱动容量分配），而不是硬塞进同一组参数。

**灵感 3（任务是最便宜也最昂贵的消歧）**
直觉：问一句「你是要我把杯子递给你，还是放到桌上？」，一次就能同时消掉整条轨迹上每一步的动作歧义；而 R69 的动作级提问只消掉一步。任务级 VoI 是**按时间摊销**的，所以往往更划算。但反过来，任务选错的代价也沿整条轨迹摊销——**问对一次收益约 H 倍，问错一次损失也约 H 倍**。因此任务级证据纪律必须比动作级更严一档，而不是更松。

**灵感 4（组合是基础模型的红利，也是证书的盲区）**
直觉：多任务学习最大的卖点是「没练过的组合也能做」——把已会技能拼起来。但每个技能的证书只覆盖它自己的前提分布；两个都安全的技能，接缝处可能不安全（杯子递到一半再放到桌上，中间那段没人练过）。所以「零件都合格」推不出「整机合格」。必须显式检查**接缝覆盖**，未覆盖就回退。

**灵感 5（新攻击面：任务欺骗）**
直觉：R69 防的是「回答骗我」；R70 要防「任务骗我」。一句恶意或错误的指令可以把系统路由到一个高能力但完全不匹配当前场景的任务专家；此时策略似然可能很高（因为动作确实像那个任务），池化异常分也可能很低。**错误的自信比诚实的犹豫更危险。** 所以路由不能只听指令，必须与观测证据（可供性、物体状态、人的姿态）交叉验证。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（FACET-RAS 总览与四不变式）** FACET-RAS = (TIE, XAM, CIC, ROUTE, COMPOSE, MINT-T, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **任务条件证据**：任何似然/异常判断必须以任务后验为条件；禁止用池化似然单独下结论；
(iii) **任务级证据纪律**：任务路由/再路由至少需要 k+1 个正交证据源（比 R69 的动作级 k 多一档）；单条指令只是「提案」，不是「判决」；
(iv) **单调保守**：任务级新信号（U_task、U_transfer、a_fault）默认只进入收紧项；任何放松必须由带版本号的 k+1 证据任务证书显式抵扣，且抵扣量有上界。

**定义 311（任务库与任务条件策略）** 任务库 𝒯={τ_1..τ_N}，每个任务有指令模板、技能集、成功谓词。共享 trunk Φ 给出 z_t=Φ(o_t,q)；任务条件流场 v_θ(x_s,s|z_t,τ)，混合策略 π_θ(ξ|o,q)=Σ_τ p(τ|o,q)π_θ(ξ|o,τ)。单任务参数用轻量 adapter 承载，避免全参数共享把任务绑死。

**定义 312（任务身份后验 TIE）** p(τ|o,q) ∝ p(τ)·p(q|τ)·p(o|τ)·p(h_t|τ)，其中 h_t 为交互历史。输出 H_task=H(p(τ|o,q))、Δ_task=p_(1)−p_(2)（后验间距）、route-observation 一致性 c_ro = agreement(argmax_τ p(o|τ), argmax_τ p(q|τ))。TIE 温度在 held-out 上校准，报告 ECE_task。

**定义 313（任务条件流似然与归一化异常）** a_τ(ξ,o)=−log p_θ(ξ|o,τ)。每个任务在 held-out 上估计 (μ_τ,σ_τ)。归一化任务异常 ã_τ=max(0,(a_τ−μ_τ)/σ_τ)。这是「行为在自己的任务里有多反常」，与任务有多罕见无关。

**定义 314（池化似然的两种偏差）** a_marg=−log Σ_τ p(τ|o)p_θ(ξ|o,τ)。
- **稀有任务税**：在 A99（动作支撑近似不相交，ξ 落在 τ* 的高密度区）下，a_marg = a_{τ*} − log p(τ*|o) + O(ε)。即池化分 = 真实任务内异常 + 任务意外度 s_task=−log p(τ*|o)。
- **歧义松弛**：在 A99′（密度绝对连续、支撑重叠）下，由 Jensen，a_marg ≤ Σ_τ p(τ|o)a_τ；任务后验越弥散，池化似然越「乐观」。
⇒ 池化分在两端都不可识别：罕见任务假警报，歧义任务漏警报。故 FMA 必须任务条件化。

**定义 315（故障分与任务解释分）** a_fault = Σ_τ p(τ|o)ã_τ（任务归一化、后验加权）；a_explained = max(0, ã_marg − a_fault) 为「可被任务罕见/歧义解释」的部分。只有 a_fault 进入故障证据；a_explained 只用于诊断与提问方向（定义 321）。

**定义 316（能力证书 CIC）** 每任务 τ 记录：μ_τ、σ_τ（似然基线）、r_τ（held-out 成功率）、ece_τ（置信校准）、cov_τ（训练覆盖）、ver_τ（证书版本）。能力分 comp_τ = r_τ·(1−ece_τ)·cov_τ，三者均在离线窗口测量；运行时只读。

**定义 317（干扰矩阵与迁移税）** 训练窗口记录任务对 (j,τ) 的梯度冲突 κ_{j→τ}=max(0,−⟨g_j,g_τ⟩/‖g_τ‖²) 与数据权重 w_j。累计迁移税 T_τ=Σ_{j≠τ}w_jκ_{j→τ}。若某共享层上 T_τ 超阈值，触发**冲突驱动容量分配 CDEA**：在该层分裂出任务组专属专家，把 κ 高的任务分开；这是把引理 20 的界变成架构决策，而非只做事后告警。

**定义 318（风险路由器 ROUTE）** 输入 (p(τ|o,q), comp, T, c_ro, a_fault)，输出三档：
- **专家路由**：Δ_task ≥ δ、comp_τ ≥ c_min、T_τ ≤ T_max、c_ro 一致；
- **通才路由**：任务后验弥散或专家能力不足，改用池化策略并禁止任务级放松；
- **保守路由**：c_ro 不一致、T_τ 越界、组合未覆盖或证书过期，回 R68 全保守。
路由带滞回（hysteresis），防止任务抖动。

**定义 319（技能 DAG 与接缝）** 技能库 S，每个技能 s 有前提 Pre(s)、效果 Eff(s)。组合任务 = DAG 上的一条路径/子图 (s_1..s_L)。接缝 seam_i=(Eff(s_i),Pre(s_{i+1}))；接缝「被覆盖」当且仅当该状态转移在训练共现支撑内，或由 WM 认证可达。

**定义 320（组合覆盖与接缝风险）** 覆盖率 Cov_comp=(#覆盖接缝)/(L−1)；未覆盖接缝的风险 R_seam 由接缝分类器给出（输入两侧技能与中间状态）。若 Cov_comp<1，组合视为未认证；任一时序跳变、力突变或不可逆状态转移 ⇒ 直接回 R68。

**定义 321（任务级摊销 VoI，MINT-T）** 候选信息动作 g（问任务、看场景、做低代价探针）：
VoI_task(g)=Σ_{h=1}^{H}γ^{h−1}[H(M_h|o)−E_{y~p(·|g,o)}H(M_h|o,y)]−c(g)。
任务级问题能同时降低未来 H 步的动作模态熵；决策 g*=argmax[VoI_task−c]，并要求其摊销风险 Σ_hγ^{h−1}risk_h(g) ≤ ε_int。VoI_task≤c 时退化为 R69 的动作级 MINT。

**定义 322（任务欺骗与路由-观测一致性）** 任务欺骗：指令/上下文使 argmax p(q|τ) ≠ argmax p(o|τ)，从而路由到高能力但错误的专家。防线：c_ro 必须一致；任务级证据需 k_task=k+1 个正交源（指令、可供性、交互确认、历史），欺骗相关 ρ<1。单条指令永远不得单独定案（继承并强化 R69 定义 293-iii）。

**定义 323（不确定性四分解）**
U_ale=Σ_k ŵ_k trΣ_k（模态内噪声，继承 R69）；
U_epi=H_mode·g(Δ_min)（动作模态间可约歧义，继承 R69）；
U_task=H_task·h(Δ_task)（任务身份歧义，新）；
U_transfer=Σ_τ p(τ|o)max(0, comp_τ^single−comp_τ^joint)（负迁移导致的能力缺口，新）。
四者语义不同，分通道进入定义 324；不做简单加和。

**定义 324（三级保守退避）**
- **L0（任务已认证）**：λ=λ_floor(U_ale)，获得 task resolution bonus（比 R69 更不保守，但不低于 λ_floor(U_ale)）；
- **L1（任务未消解/歧义/未覆盖）**：λ=λ_floor(U_ale+U_epi+U_task+U_transfer+c_a·a_fault)；
- **L2（任务欺骗可疑/路由不一致/证书过期/干扰越界）**：λ=λ_floor(U_ale+U_epi+U_task^max+U_transfer+c_a·a_fault)，并叠加 R68 的最大收缩与 k_cal_shrink。
单调性：任一任务级信号只会抬高 λ；降低 λ 只能由 L0 证书按定义 310-iv 抵扣。

**定义 325（遗忘监控与证书再签发）** 离线更新后，在 anchor 任务集上重测 (r_τ,σ_τ,ece_τ)；若某任务 r_τ 下降超过 δ_forget 或 ECE 越界，则冻结该任务为「待复健」，运行时不授予 L0。证书带 ver_τ 与全局 bank_hash；运行时不写学习参数，只读证书。

**定义 326（证书 J_FACET）** J_FACET = (J_FLUID, task_posterior_ece, route_hash, comp_table_hash, interference_hash, cov_comp, a_fault_p95, U_task_before/after, bank_ver)。Valid ⇔ Valid(J_FLUID) ∧ ECE_task ≤ τ_task ∧ 路由证据纪律满足 ∧ 组合覆盖满足（或已回退） ∧ 证书未过期。

**定义 327（AIC-FACET 干扰集）** ℰ_FACET = ℰ_FLUID × ℰ_task × ℰ_mtl。ℰ_task={任务欺骗、任务坍缩（新任务被硬塞进最近任务）、路由振荡、任务后验投毒}；ℰ_mtl={负迁移突增、组合接缝失败、离线更新后遗忘、任务先验漂移}。

**定义 328（自适应任务采样与计算预算）** 常规路径只算 top-1 任务条件流（复用 R69 FMP）；仅当 Δ_task<δ 或 c_ro 不一致时算 top-2/3；仅当 COMPOSE 触发时做 DAG 检查。CDEA 只在离线窗口执行，保证 P99 实时预算。

# IP-264 TIE：任务身份后验（复用 trunk，零重复编码）
class TaskIdentityEstimator:
    def __init__(self, trunk, task_head, calib_T):
        self.trunk, self.head, self.T = trunk, task_head, calib_T
    def posterior(self, o, q, h):
        z = self.trunk(o, q)
        logits = self.head(z, h) / self.T          # 温度校准
        p = softmax(logits)
        return p, entropy(p), margin(p), route_consistency(p, o, q)

# IP-265 XAM：任务条件似然 + 池化偏差分解
def task_anomaly(fmp, xi, o, p_tau, topk=1):
    taus = topk_tasks(p_tau, topk)
    a_tau = {t: -fmp.log_likelihood(xi, o, task=t) for t in taus}
    a_norm = {t: max(0.0, (a_tau[t]-MU[t]) / SIGMA[t]) for t in taus}
    a_fault = sum(p_tau[t]*a_norm[t] for t in taus)
    a_marg  = -fmp.log_marginal_likelihood(xi, o, p_tau)      # 池化
    a_expl  = max(0.0, zscore(a_marg, MU_MARG, SIGMA_MARG) - a_fault)
    return a_fault, a_expl, a_tau

# IP-266 CIC：能力 + 干扰证书（离线测量，运行时只读）
def competence(task):
    return R[task] * (1 - ECE[task]) * COV[task]
def transfer_tax(task, weights):
    return sum(weights[j]*KAPPA[j][task] for j in tasks if j != task)

# IP-267 ROUTE：三档风险路由（带滞回）
def route(p_tau, cert, c_ro, prev=None):
    tau = argmax(p_tau)
    if c_ro != 'consistent' or cert.expired(tau):
        return 'conservative', None
    if margin(p_tau) >= DELTA and cert.comp[tau] >= C_MIN and cert.tax(tau) <= T_MAX:
        return 'specialist', tau
    if prev == 'specialist' and margin(p_tau) >= DELTA*HYST:
        return 'specialist', tau                 # 滞回，避免抖动
    return 'generalist', None

# IP-268 COMPOSE：技能 DAG 与接缝覆盖
def compose(task, skill_dag, seam_model):
    plan = shortest_path(skill_dag, task.init, task.goal)
    if plan is None: return None, (0.0, float('inf'))
    covered = [seam_model.covered(Eff(a), Pre(b)) for a, b in pairwise(plan)]
    cov = sum(covered) / max(1, len(covered))
    seam_risk = sum(seam_model.risk(a, b) for a, b, c in zip(plan, plan[1:], covered) if not c)
    return plan, (cov, seam_risk)

# IP-269 MINT-T：任务级摊销 VoI
def choose_task_interaction(p_tau, o, H, budget):
    best = None
    for g in task_info_candidates(p_tau, o):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o): continue
        voi = sum(GAMMA**h * (H_mode(h) - E_H_mode(h, g)) for h in range(H))
        score = voi - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None      # 退化为 R69 MINT

# IP-274 FACET 主闭环（继承 R69，在路由与异常处插入任务层）
def FACET_round(M, obs, q):
    z, o = M.mtm.forward(obs, q); c, U_cal, thr = M.cof.step(...)
    # 1) 任务身份
    p_tau, H_t, d_t, c_ro = M.tie.posterior(o, q, M.history)
    U_task = H_t * h(d_t)
    # 2) 组合检查（仅组合任务）
    plan, (cov, seam_risk) = M.compose.check(q, M.skill_dag, M.seam)
    composition_ok = (cov == 1.0 and seam_risk <= SEAM_MAX)
    # 3) 路由
    level, tau = M.route(p_tau, M.cert, c_ro)
    if not composition_ok: level = 'conservative'
    # 4) 任务条件异常（常规只算 top-1）
    a_fault, a_expl, _ = M.xam.task_anomaly(
        M.fmp, M.last_action, o, p_tau,
        topk=(1 if level == 'specialist' else 2))
    # 5) 任务级交互（仅 L1 且非欺骗可疑）
    g = (M.mint_t.choose_task_interaction(p_tau, o, M.vista.H, M.budget)
         if (level == 'generalist' and U_task > TAU_TASK and c_ro == 'consistent')
         else None)
    if g is not None:
        ans = M.cia.execute(g)                    # k+1 正交证据
        p_tau, H_t, d_t, c_ro = M.tie.update(p_tau, ans)
        U_task = H_t * h(d_t)
    # 6) 不确定性四分解 + 迁移税
    samples = M.fmp.sample(o, K=(1 if level == 'specialist' else 4), task=tau)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    U_transfer = sum(p_tau[t]*max(0.0, M.cert.comp_single[t]-M.cert.comp_joint[t])
                     for t in p_tau)
    # 7) 三级退避（单调保守）
    if level == 'specialist' and d_t >= DELTA and M.cert.valid(tau):
        lam = max(M.efs.risk_scale(...), lam_floor(U_ale))
    else:
        extra = U_ale + U_epi + U_task + U_transfer + C_A*a_fault
        lam = max(M.efs.risk_scale(...), lam_floor(extra))
        if level == 'conservative':
            lam = max(lam, 0.8)
    # 8) 执行 + 审计 + 证书
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_mode(modes, U_epi, lam)
    tau_cmd = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_t.submit_async(p_tau, g, a_fault, a_expl, cov, level)
    return k, lam, mode, (U_ale, U_epi, U_task, U_transfer)
```

## 3. 推导

**引理 19（池化似然的不可识别性）** 在 A99 下，a_marg = a_{τ*} − log p(τ*|o) + O(ε)：池化异常 = 任务内异常 + 任务意外度。系 (i) 稀有任务即使行为正常也会越过 FMA 阈值（假警报）；系 (ii) 常见任务会稀释真实异常，若再叠加任务欺骗，池化分可能被压低（漏警报）。在 A99′ 下，Jensen 给出 a_marg ≤ Σ_τ p(τ|o)a_τ，任务越歧义池化分越乐观。故**池化似然既不充分也不必要**，FMA 必须条件化并按任务归一化（定义 313–315）。

**引理 20（负迁移的干扰税）** 设联合更新 g=Σ_j w_j g_j，任务 τ 的损失 L_τ 光滑。一阶展开 ΔL_τ=−η⟨g,g_τ⟩+O(η²)，其中 ⟨g,g_τ⟩=w_τ‖g_τ‖²+Σ_{j≠τ}w_j⟨g_j,g_τ⟩。定义 κ_{j→τ}=max(0,−⟨g_j,g_τ⟩/‖g_τ‖²)，则单步超额损失 ≤ η‖g_τ‖²Σ_{j≠τ}w_jκ_{j→τ}+O(η²)。系：T_τ 可作为「联合训练相对单任务」的能力缺口先验；κ 高的任务应被 CDEA 分到不同专家（定义 317）。注意这是局部线性界，最终以 held-out 能力证书为准（定义 316）。

**引理 21（组合接缝不可由零件证书推出）** 若组合 (s_1..s_L) 的每个接缝都被覆盖，则组合风险 ≤ Σ_i R(s_i)+Σ_i R_seam,i；若存在未覆盖接缝，则零件证书对该组合无约束力（反例：两个各自安全的技能在中间状态产生力突变或不可逆转移）。系：Cov_comp<1 时必须回退，不能把「每个技能都认证过」当作「整条组合已认证」。

**引理 22（任务级 VoI 的摊销界）** 若任务身份 τ 在 H 步内不变，且每步动作模态熵的条件降低量相同，则 VoI_task(g)=(Σ_{h=1}^{H}γ^{h−1})·ΔH_task−c(g)，约为单步动作级 VoI 的 (1−γ^H)/(1−γ) 倍；但任务选错的期望损失同样被放大同倍。故任务级决策应在「摊销收益 vs 摊销风险」上做，且证据门槛提高一档（定义 322）。

**定理 18（FACET 对 FLUID/R68 的安全泛化）** 在 A99–A101 下：
(i) **退化**：当 N=1 或任务后验退化为 δ_τ、κ=0、无组合时，FACET 逐指令退化为 FLUID-RAS；再关闭交互与任务歧义时退化为 R68。
(ii) **安全下界**：任意状态 λ_FACET ≥ λ_floor(U_ale)=R69 的最松下界；未获任务证书时，FACET 的保守项是 FLUID 保守项的单调扩展（额外加上 U_task、U_transfer、a_fault），故不弱于 FLUID。
(iii) **放松**：L0 需要 k+1 正交任务证据（比 FLUID 的 k 更严），且放松只把任务级项清零，不清零动作级项。因此放松是「用更严的证据换同一下界」，不是无条件更松。**安全靠证据挣得，不靠重新解释似然。**

**定理 19（任务欺骗上界与摊销代价）** 单指令路由在欺骗率 δ_q 下错误任务率 ≥ δ_q；采用 k_task=k+1 个欺骗相关 ρ<1 的正交源，错误率 ≤ δ_q·ρ^{k}+ε_σ。若错误路由持续 H 步，期望损失按引理 22 放大 (1−γ^H)/(1−γ) 倍；因此任务级证据门槛必须比动作级高一档，且 L2 不得授予任何 task bonus。

## 6. 本轮最大风险

**一句话**：FACET-RAS 把安全押在「任务身份证书 + 能力/干扰证书」上——**若任务库覆盖不全、证书过期，或干扰矩阵因部署先验漂移而失真，系统就会把一个错误但「高能力」的任务专家路由成 L0，并用 k+1 证据的仪式把这次错误洗成一枚合法证书；任务级放松的摊销收益越大，被洗白的错误也沿整条轨迹传播得越远**——**选错任务，比不会做任务更危险。**

**次级风险与缓解**：
1. **开放集新任务被硬塞进最近任务（任务坍缩）** → 开放集检测 + 未覆盖即保守 + E308；
2. **组合接缝未覆盖** → Cov_comp 门控 + 接缝 WM 认证 + 引理 21；
3. **任务欺骗/指令投毒** → 路由-观测一致性 + k_task=k+1 + E303；
4. **负迁移估计只是局部线性先验** → 以 held-out 能力证书为准 + CDEA 离线分裂 + E304；
5. **离线更新后遗忘** → anchor 再认证 + 证书版本 + 冻结 L0 + E309；
6. **任务级提问疲劳** → 摊销 VoI + 预算 + 滞回 + E306。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** FACET-RAS = (TIE,XAM,CIC,ROUTE,COMPOSE,MINT-T,RAS-WM†)。四不变式：实时零学习写；**任务条件证据**（禁止池化似然单独定案）；**任务级证据纪律**（k+1 正交源，单指令只是提案）；**单调保守**（任务级信号只加不减，放松必须由带版本号的证书抵扣）。

**定义 311–312（任务库与 TIE）** 任务条件流场 `v_θ(x_s,s|z_t,τ)`，混合策略 `π_θ(ξ|o,q)=Σ_τ p(τ|o,q)π_θ(ξ|o,τ)`；`p(τ|o,q) ∝ p(τ)p(q|τ)p(o|τ)p(h_t|τ)`，输出 `H_task, Δ_task, c_ro`。

**定义 313–315（任务条件异常与池化偏差）** `a_τ=−log p(ξ|o,τ)`，`ã_τ` 归一化。池化 `a_marg` 在支撑近似不相交时等于 `a_{τ*} − log p(τ*|o)`（稀有任务税）；在支撑重叠时 Jensen 给出 `a_marg ≤ Σ p_τ a_τ`（歧义松弛）。故 `a_fault=Σp_τã_τ` 才是故障证据，`a_explained=max(0,ã_marg−a_fault)` 只用于诊断与提问方向。

**定义 316–317（能力与干扰）** `comp_τ=r_τ(1−ece_τ)cov_τ`；`κ_{j→τ}=max(0,−⟨g_j,g_τ⟩/‖g_τ‖²)`，`T_τ=Σ_{j≠τ}w_jκ_{j→τ}`。`T_τ` 越界触发 CDEA，把冲突任务分到不同专家。

**定义 318（ROUTE）** 专家路由需 `Δ_task≥δ ∧ comp_τ≥c_min ∧ T_τ≤T_max ∧ c_ro=consistent`；否则通才路由；欺骗可疑/证书过期/组合未覆盖 → 保守路由；带滞回防抖。

**定义 319–320（组合）** 技能 DAG 的接缝 `seam_i=(Eff(s_i),Pre(s_{i+1}))`；`Cov_comp` 为覆盖接缝占比；未覆盖接缝给出 `R_seam`；`Cov_comp<1` 即未认证，任一时序/力/可逆性违约直接回 R68。

**定义 321–322（MINT-T 与任务欺骗）** `VoI_task(g)=Σ_hγ^{h−1}[H(M_h|o)−E H(M_h|o,y)]−c(g)`；任务级问题按 H 步摊销。任务欺骗 = 指令后验与观测后验的 argmax 不一致；防线是 `c_ro` 一致 + `k_task=k+1` 正交源，单指令不得定案。

**定义 323–324（四分解与三级退避）** `U_ale`（模态内噪声）、`U_epi`（动作歧义）、`U_task=H_task·h(Δ_task)`（任务歧义）、`U_transfer=Σp_τ max(0,comp_τ^single−comp_τ^joint)`（负迁移缺口）。L0：`λ=λ_floor(U_ale)`（需 k+1 任务证书）；L1：`λ=λ_floor(U_ale+U_epi+U_task+U_transfer+c_a·a_fault)`；L2：L1 且 `U_task^max` + R68 最大收缩。信号只加不减。

**定义 325–328（再认证/证书/干扰/预算）** 离线更新后在 anchor 集重测，遗忘任务冻结 L0；`J_FACET=(J_FLUID, ECE_task, route_hash, comp_table_hash, interference_hash, cov_comp, a_fault_p95, bank_ver)`；`ℰ_FACET=ℰ_FLUID×ℰ_task×ℰ_mtl`；常规只算 top-1 任务条件流，歧义升 top-2/3，组合才跑 DAG。

def tie_posterior(o, q, h):
    z = trunk(o, q); p = softmax(task_head(z, h) / calib_T)
    return p, entropy(p), margin(p), route_consistency(p, o, q)

# IP-265 XAM：任务条件异常 + 池化偏差分解
def task_anomaly(fmp, xi, o, p_tau, topk=1):
    taus = topk_tasks(p_tau, topk)
    a    = {t: -fmp.log_likelihood(xi, o, task=t) for t in taus}
    a_n  = {t: max(0.0, (a[t]-MU[t])/SIGMA[t]) for t in taus}
    a_fault = sum(p_tau[t]*a_n[t] for t in taus)
    a_marg  = -fmp.log_marginal_likelihood(xi, o, p_tau)
    a_expl  = max(0.0, zscore(a_marg, MU_MARG, SIGMA_MARG) - a_fault)
    return a_fault, a_expl, a

# IP-268 COMPOSE：技能 DAG 与接缝
def compose(task, dag, seam):
    plan = shortest_path(dag, task.init, task.goal)
    if plan is None: return None, (0.0, float('inf'))
    cov = [seam.covered(Eff(a), Pre(b)) for a, b in pairwise(plan)]
    ratio = sum(cov) / max(1, len(cov))
    seam_risk = sum(seam.risk(a, b) for a, b, c in zip(plan, plan[1:], cov) if not c)
    return plan, (ratio, seam_risk)

        score = sum(GAMMA**h * (H_mode(h) - E_H_mode(h, g)) for h in range(H)) - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None      # 退化为 R69 MINT

# IP-274 FACET 主闭环
def FACET_round(M, obs, q):
    z, o = M.mtm.forward(obs, q); M.cof.step(...)
    p_tau, H_t, d_t, c_ro = M.tie.posterior(o, q, M.history)
    U_task = H_t * h(d_t)
    plan, (cov, seam_risk) = M.compose.check(q, M.skill_dag, M.seam)
    level, tau = M.route(p_tau, M.cert, c_ro)
    if cov < 1.0 or seam_risk > SEAM_MAX: level = 'conservative'
    a_fault, a_expl, _ = M.xam.task_anomaly(
        M.fmp, M.last_action, o, p_tau, topk=(1 if level == 'specialist' else 2))
    g = (M.mint_t.choose_task_interaction(p_tau, o, M.vista.H, M.budget)
         if (level == 'generalist' and U_task > TAU_TASK and c_ro == 'consistent')
         else None)
    if g is not None:
        p_tau, H_t, d_t, c_ro = M.tie.update(p_tau, M.cia.execute(g))
        U_task = H_t * h(d_t)
    samples = M.fmp.sample(o, K=(1 if level == 'specialist' else 4), task=tau)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    U_transfer = sum(p_tau[t]*max(0.0, M.cert.comp_single[t]-M.cert.comp_joint[t])
                     for t in p_tau)
    if level == 'specialist' and d_t >= DELTA and M.cert.valid(tau):
        lam = max(M.efs.risk_scale(...), lam_floor(U_ale))          # L0
    else:
        extra = U_ale + U_epi + U_task + U_transfer + C_A*a_fault
        lam = max(M.efs.risk_scale(...), lam_floor(extra))          # L1
        if level == 'conservative': lam = max(lam, 0.8)             # L2
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_mode(modes, U_epi, lam)
    tau_cmd = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_t.submit_async(p_tau, g, a_fault, a_expl, cov, level)
    return k, lam, mode, (U_ale, U_epi, U_task, U_transfer)
```

## 4. 推导

**引理 19（池化似然的不可识别性）** A99（动作支撑近似不相交）下 `a_marg = a_{τ*} − log p(τ*|o) + O(ε)`：池化分 = 任务内异常 + 任务意外度。系 (i) 稀有任务假警报；系 (ii) 常见任务稀释真实异常，叠加任务欺骗时可漏警报。A99′（支撑重叠）下 Jensen 给出 `a_marg ≤ Σ p_τ a_τ`：任务越歧义池化分越乐观。故池化似然既不充分也不必要。

**引理 20（负迁移的干扰税）** 联合更新 `g=Σ_j w_j g_j`，光滑 `L_τ` 的一阶展开给出单步超额损失 `≤ η‖g_τ‖²Σ_{j≠τ}w_jκ_{j→τ}+O(η²)`，其中 `κ_{j→τ}=max(0,−⟨g_j,g_τ⟩/‖g_τ‖²)`。系：T_τ 是能力缺口先验；κ 高的任务应由 CDEA 分到不同专家；最终以 held-out 能力证书为准。

**引理 21（组合接缝不可由零件证书推出）** 所有接缝覆盖时组合风险 `≤Σ_i R(s_i)+Σ_i R_seam,i`；任一接缝未覆盖时零件证书对组合无约束力。系：`Cov_comp<1` 必须回退。

**引理 22（任务级 VoI 的摊销界）** 若 τ 在 H 步内不变且每步熵降相同，则 `VoI_task` 约为单步动作级 VoI 的 `(1−γ^H)/(1−γ)` 倍；任务选错的损失同倍放大。故要按摊销收益/风险决策，且证据门槛提高一档。

**定理 18（FACET 对 FLUID/R68 的安全泛化）** (i) N=1 或后验退化为 δ_τ、κ=0、无组合时逐指令退化为 FLUID；再关闭交互与任务歧义退化为 R68。(ii) 任意状态 `λ_FACET ≥ λ_floor(U_ale)`（R69 最松下界）；未获任务证书时保守项是 FLUID 的单调扩展，故不弱于 FLUID。(iii) L0 需 k+1 正交任务证据，且只清零任务级项、不清零动作级项——用更严的证据换同一下界。**安全靠证据挣得，不靠重新解释似然。**

**定理 19（任务欺骗上界与摊销代价）** 单指令路由在欺骗率 δ_q 下错误率 ≥ δ_q；`k_task=k+1` 个欺骗相关 ρ<1 的正交源使错误率 `≤δ_q·ρ^k+ε_σ`。错误路由持续 H 步时损失按引理 22 放大，故任务级门槛高一档，L2 不授 task bonus。

## 7. 本轮最大风险

**一句话**：FACET-RAS 把安全押在「任务身份证书 + 能力/干扰证书」上——**若任务库覆盖不全、证书过期，或干扰矩阵因部署先验漂移而失真，系统就会把一个错误但「高能力」的任务专家路由成 L0，并用 k+1 证据的仪式把这次错误洗成一枚合法证书；任务级放松的摊销收益越大，被洗白的错误也沿整条轨迹传播得越远**——**选错任务，比不会做任务更危险。**

**次级风险与缓解**：开放集新任务坍缩（开放集检测 + 未覆盖即保守 + E308）；组合接缝未覆盖（Cov_comp 门控 + 接缝 WM 认证 + 引理 21）；任务欺骗/指令投毒（路由-观测一致性 + k_task=k+1 + E303）；负迁移估计只是局部线性先验（以 held-out 能力证书为准 + CDEA 离线分裂 + E304）；离线更新后遗忘（anchor 再认证 + 证书版本 + 冻结 L0 + E309）；任务级提问疲劳（摊销 VoI + 预算 + 滞回 + E306）。
