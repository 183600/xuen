## 2. 关键算法骨架

### IP-497 DWK：演示见证核（离线建图 + 固化准入，O(log N_D) 检索）

```python
@dataclass
class DemonstrationWitnessKernel:
    """DWK：演示方案作为外部见证。
    红线：演示只做固化准入与覆盖判定，不直接当策略目标，不改在线门"""
    emb_w: Any                    # 任务相关嵌入（物体/抓取类型/接触签名）
    atlas: Any                    # 见证图册：c_h -> ξ_h（FAISS + 区间树）
    eps_W: float = 0.15           # 见证邻域半径
    rho_min: float = 0.30         # 允许固化的最小覆盖率
    delta: float = 0.05           # 覆盖率置信下界的失败概率

    def witness_set(self, c) -> list[Witness]:
        return self.atlas.query(self.emb_w(c), radius=self.eps_W)

    def witness_consistent(self, e) -> bool:
        if not self.witness_set(e.c_ctx):          # 无正见证：拒绝
            return False
        if independent_audit_flags(e):             # 负向见证：拒绝
            return False
        return True

    def coverage_lb(self, region) -> float:
        """保守下界：DP 直方图 + 置信下界，绝不用点估计冒充覆盖率"""
        return clopper_pearson_lb(self.atlas.hist(region), delta=self.delta)

    def gate_for_consolidation(self, e) -> bool:
        # v5 准入 ∧ 见证一致性：外部接地的唯一入口
        return (e.forged and e.outcome_ok and e.human_audit
                and self.witness_consistent(e))

    def allow_region(self, region) -> bool:
        return self.coverage_lb(region) >= self.rho_min   # 未见证区禁固化
```

```python
        """min_t (μ f_n − |f_t|)/f_ref，沿轨迹逐接触点取最小"""
        ...

    def worst_case_cone(self, contact, Sigma_p, mu) -> bool:
        """位姿不确定椭球内最坏情形下 wrench cone 是否仍非空（引理 46）"""
        ...

    def kc_grasp(self, x, c) -> tuple[bool, dict]:
        eps_fc = self.force_closure_margin(x.contact, x.wrench, c.mu)
        sm = self.slip_margin(x.contact, x.wrench, c.mu)
        wc = self.worst_case_cone(x.contact, c.Sigma_p, c.mu)

        return ok, {'eps_fc': eps_fc, 'slip_margin': sm}

        # 合取细化：只在原门上「与」一个可测物理谓词，绝不替换/放松
        return (lambda x, c: kc_physics_v5(x, c) and self.kc_grasp(x, c)[0],
                lambda x, c: kc_balance_v5(x, c) and self.kc_grasp(x, c)[0])
```

### IP-499 EFA-v6 / 演示方案装配器（在线准入，七门逐字继承 + CCT 输出）

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：在线七门与 v5 逐字相同，末尾追加抓取子证书与演示方案输出"""
    fmpp: FlowMatchingProposalPolicyKernel
    lmem: LongTermMemoryEmbeddingConsolidation
    famk: FacialAffectModulationKernel
    gsck: GraspSubCertificateKernel
    dwk: DemonstrationWitnessKernel
    v5: EvidenceForgingAssemblerV5

    def select(self, x0_state, t_now, rule_id, context):
        s_emo = self.famk.observe(context.face, t_now)
        gamma = self.famk.gamma(s_emo)                 # γ_emo ≥ 1
        c = build_ctx(context, s_emo, self.lmem)
        witnesses = self.dwk.witness_set(c)            # 检索演示见证 token
        c = c.with_witnesses(witnesses)

        # 未见证区：仅收紧，不放宽（定理 12）
        if not self.dwk.allow_region(region_of(c)):
            gamma = {i: gamma[i] * GAMMA_CONS for i in gamma}   # γ_cons ≥ 1

        cands = self.fmpp.propose(c, self.fmpp.K)
        # 第 1 层：v5 廉价门（coverage/physics/memory/novelty）
        surv = [x for x in cands if self._cheap_gates(x, gamma)]
        # 第 1.5 层：抓取子证书（廉价可算部分）
        surv = [x for x in surv if self.gsck.kc_grasp(x, c)[0]]
        if not surv:
            return self._fallback_rule_proposal(gamma)     # fail-closed 回退 v5 规则
        # 第 2 层：VACK 仅评 ≤3 幸存者（与 v5 相同）
        surv.sort(key=self._prefilter_score, reverse=True)
        finals = [x for x in surv[:3] if self.v5.vack.kc_val(
            self.v5.vack.evaluate(x, c, t_now), tau=gamma['val'] * TAU_VAL5)]
        # 第 3 层：BCK 轨迹预览（事件触发 QP + 缓存证书）
        ok = [x for x in finals if self._bck_preview(x, gamma)]
        if not ok:
            return False, None, 'ALL_CANDIDATES_REJECTED', None
        best = max(ok, key=certified_margin)
        plan = self.assemble_cct(best, c, witnesses)   # 演示方案（可读证书）
        return True, best, 'FORGED_DWCG', plan

    def assemble_cct(self, x, c, witnesses) -> CertificateCarryingTrace:
        """把证书翻译成可回放的演示方案：每步记录门触发、边际、见证引用"""
        return CertificateCarryingTrace(
            trajectory=x, gate_margins=x.margins,
            witnesses=[w.id for w in witnesses],
            replay_checks=x.replay_checks)   # 人可逐步重放并核对门状态
```

```python
# 定理 9：见证锚定下的自指增益上界与相变
def theorem_witness_anchored_gain() -> str:
    """
    假设 (W1) 演示见证与 θ_FM 独立采集；(W2) 覆盖率 ρ_W ≥ ρ_min；
    (W3) 见证一致性误判率 ≤ δ_W；(W4) KL(π_new‖π_old) ≤ ε_KL。
    记训练经验分布 p_S = ρ_W p_W + (1−ρ_W) p_self。则每轮自指增益
        g ≤ (1−ρ_W)(1+δ_W) + sqrt(ε_KL/2)。
    故当 ρ_W > ρ_crit := 1 − (1 − g_target − sqrt(ε_KL/2))/(1+δ_W) 时，
    g ≤ g_target < 1，固化映射在 TV 距离下为压缩映射，回路有唯一有界不动点。
    证明：TV(p_S,p_W) ≤ (1−ρ_W)+ρ_W δ_W ≤ (1−ρ_W)(1+δ_W)；

    三角不等式 + Banach 压缩不动点。∎
```

## 4. 正确性论证（增量更新）

### 引理 45（见证覆盖率的保守下界）

**陈述**：设某区域直方图有 n 个样本、m 个落在见证邻域内，则覆盖率 ρ_W 的 Clopper–Pearson 下界 ρ̂_W^LB 满足 P(ρ̂_W^LB ≤ ρ_W) ≥ 1−δ。DWK 只用下界做固化准入，因此覆盖率误判只会导致「少固化」而非「多固化」。∎

**工程含义**：覆盖不足时系统自动退回 v5 保守模式，错误方向是 fail-closed。

### 引理 46（滑移边际对位姿不确定性的单调性）

**陈述**：接触力/力矩对物体位姿连续且 Lipschitz；设位姿扰动被半径 r(Σ_p)=delta_p·sqrt(λ_max(Σ_p)) 的椭球覆盖，则最坏滑移边际 slip_margin^worst(r) 关于 r 单调不增。故以 worst-case 锥非空 + slip_margin^worst ≥ ξ_slip 作为判据是保守的（真实边际不低于判据）。∎

### 定理 9（见证锚定下的自指增益上界与相变）

**陈述**：在 (W1)~(W4) 下，每轮自指增益 g ≤ (1−ρ_W)(1+δ_W) + sqrt(ε_KL/2)。当 ρ_W > ρ_crit 时 g < 1，固化映射为 TV 压缩映射，回路收敛到唯一有界不动点；当 ρ_W < ρ_crit 时自指项主导，固化可能沿自铸证方向漂移。

**证明**：见 IP-500 伪代码注释。核心是把经验分布分解为见证支撑部分与自生成部分，见证部分被外部 p_W 锚住，自生成部分占比 ≤ 1−ρ_W 且受 KL 约束；TV 三角不等式 + Pinsker + Banach。∎

**诚实边界**：这是**分布层面**的界，不保证「意图」一致；δ_W 是经验估计；ρ_crit 依赖 g_target 与 ε_KL 的取值，工程上需保守设定。

### 定理 10（抓取子证书细化不增门且保持嵌套）

**陈述与证明**：见 IP-500。合取细化只删点；七锚集合不变。∎

### 定理 11（演示验收假接受界）

**陈述与证明**：见 IP-500。Hoeffding 界给出学习过程准入的统计保证；不进入在线执行集。∎

### 定理 12（未见证区 fail-closed）

**陈述与证明**：见 IP-500。未见证区既禁固化又只收紧阈值，故执行集只会更小。∎

### 定理 v6（总装：外部接地的执行集收缩）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) 见证独立性、(B9) 覆盖率下界正确 下：
(i) Exec_v6 ⊆ Exec_v5 ⊆ … ⊆ Exec_v29（抓取细化 + 未见证区收紧）；
(ii) 在线七门与 v5 逐字相同，证书不变性（v5 定理 6）保持；
(iii) 固化自指增益由定理 9 界住，ρ_W > ρ_crit 时回路收敛；
(iv) 抓取子证书只细化 kc_physics/kc_balance，不新增锚（定理 10）；
(v) DAT 以 Hoeffding 界控制学习过程假接受（定理 11）；
(vi) 未见证区 fail-closed（定理 12）。

**证明**：逐条由定理 9~12 与 v5 定理 5~8 组合。∎

**诚实声明**：(a) 定理 9 只约束分布漂移，不约束意图；「贴近演示」是必要非充分条件，存在「像演示但违背意图」的对抗性通过空间；(b) 见证独立性 (B8) 是假设而非保证——若演示与证书机器同源，外部锚退化为名义外部；(c) 覆盖率下界依赖区域划分与 DP 直方图，区域划分本身可被博弈；(d) 抓取子证书依赖位姿不确定性 Σ_p 的校准，触觉缺失时 worst-case 估计可能过保守或漏检；(e) 七门完备性继承 v5 的 (B4) 加性价值假设，未解决。

### 第 6 轮灵感驱动研究记录

**灵感词**：演示方案、机械臂抓取

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）把 v4 的离散规则提议升级为条件流匹配、把被动记忆升级为「检索 + 固化」、把人因锚升级为「意图 + 情感调制」，并用定理 5~8 证明「换提议不换门」的证书不变性，执行集 Exec_v5 ⊆ Exec_v4 ⊆ … ⊆ Exec_v29。但 v5 自己标注的最大风险 R57 尚未偿还：**记忆固化是自指回路**——策略在自己铸证的片段上训练，缺乏外部真值，可能学会博弈门（形式合规、实质违背）。本轮两个灵感词恰好从「外部真值」与「落地任务」两侧补这个洞：

- **演示方案** → 人类演示是独立于证书机器的外部信号。但直接模仿（行为克隆）会引入稀疏、次优、甚至违反硬门的新问题。本轮把演示从「策略目标」改造成「**外部见证（witness）**」：演示只用于给固化片段做外部背书、给提议分布划出「已见证区域」、并给每个已认证抓取生成可回放的**演示方案**。注意「演示方案」在本轮是双向的：**输入端**是采集协议产出的演示见证集，**输出端**是系统交付给人的可读证书载体。
- **机械臂抓取** → 抓取是把七门落到物理世界的最小完整任务：它同时触发覆盖（可抓性/预抓取位姿）、物理（力闭合/摩擦锥）、平衡（接触稳定/滑移）、末点（落点）与价值（损坏/人因）。本轮不新增硬门（延续 v5 的七门自律），而是把抓取约束实现为现有物理门与平衡门内部的**抓取子证书**。

统一主题：**演示见证的认证抓取（Demonstration-Witnessed Certified Grasping, DWCG）**，形成 CADVS-v6（IP-497~500）。执行集嵌套升级为 Exec_v6 ⊆ Exec_v5 ⊆ … ⊆ Exec_v29；七门数量仍为七。

**直觉与动机**：

1. **演示方案 → 用外部见证给自指回路装「接地线」**。v5 的固化只问「这段经验是否已铸证且结局成功」，但铸证与结局都由同一套价值模型判定，等于自己给自己发证书。人类演示提供了一条**不经过 θ_FM 与 VACK 的外部通道**：如果一段自铸证片段在任务相关度量上远离任何成功演示，或落在独立审计判为博弈的负向见证附近，则它不能进入固化。形式上引入见证映射 W_ε(c) 与见证一致性谓词，把固化准入从 `forged ∧ outcome_ok ∧ human_audit` 收紧为 `forged ∧ outcome_ok ∧ human_audit ∧ witness_consistent`。关键不是「学演示」，而是「**用演示当尺子**」——演示可以稀疏、次优、甚至违反门（只取其中成功的物理片段作正见证），它只需要比证书机器更独立。

2. **机械臂抓取 → 抓取子证书把抽象门落到可测物理量，且不增门**。抓取的核心失效模式是力闭合不足、摩擦锥越界、位姿不确定导致滑移、接触点退化。本轮定义抓取子证书 kc_grasp = (ε_fc ≥ ε_fc^min) ∧ (slip_margin ≥ ξ_slip) ∧ (位姿不确定下的 worst-case wrench cone 非空)，并把它作为 kc_physics 与 kc_balance 的**合取细化**嵌入既有门：kc_physics^v6 = kc_physics^v5 ∧ kc_grasp^phys，kc_balance^v6 = kc_balance^v5 ∧ kc_grasp^bal。因为只是合取加项，执行集只缩不涨（定理 10），锚点集合不变（抓取是实例化不是新锚），正面维持 v5 对 R52 锚点维护负债的承诺。

3. **演示方案 → 证书的可读载体（legibility）**。一个标量证书对人不透明，无法审计。本轮要求每个被采纳的抓取都产出一份**演示方案**：可回放的（状态, 动作, 接触, 证书注解）轨迹，人可在仿真或实机上逐步重放，并看到每一步触发了哪一门、边际多少、引用了哪条人类演示作为见证。这把「证书」从机器内部谓词变成人可检验的见证，也为定理 11 的演示验收测试（DAT）提供输入：新固化策略上线前必须在固定演示方案集上回放，门一致率与见证一致率达标才放行。注意：DAT 是**学习过程的准入门**，不是在线执行集的新门，因而不破坏「在线七门冻结」红线。

**关键洞见**：v4 问「提议 = 规则时七门够不够」；v5 问「提议 = 任意生成器时证书边界是否不变」；v6 问「**当学习本身会反噬证书时，如何用外部见证把学习锚住**」。答案不是加门，而是给固化加两道离线约束：(a) 只吃有见证的片段（外部接地）；(b) 只在见证覆盖足够的区域固化，未见证区 fail-closed 退回 v5 保守模式。在线执行谓词逐字继承 v5，故 Exec_v6 ⊆ Exec_v5 由「抓取子证书细化 + 保守回退」双重保证。

**形式化目标（增量）**：

1. 演示方案协议：D = {(ξ_h, o_h, meta_h)}_{h=1}^{N_D}，ξ_h=(s_{0:T}, a_{0:T}, contact_{0:T})，o_h ∈ {success, fail}，采集与 θ_FM 独立（预采集或独立操作员）。
2. 见证映射与一致性：d_W(c, c_h) 为任务相关度量（物体位姿/几何 + 抓取类型 + 接触签名）；W_ε(c) = {h : d_W(c, c_h) ≤ ε_W}；witness_consistent(e) = 1[W_ε(c_e) ≠ ∅ ∧ 无负向见证]。
3. 抓取子证书：kc_grasp = kc_fc ∧ kc_slip ∧ kc_unc，作为 kc_physics/kc_balance 的合取细化，不新增顶层门。
4. 定理 9（见证锚定下的自指增益上界/相变）、定理 10（抓取子证书细化不增门且保持嵌套）、定理 11（演示验收假接受界）、定理 12（未见证区 fail-closed）；引理 45（见证覆盖的保守下界）、引理 46（滑移边际对位姿不确定性的单调性）。
5. 演示方案装配：对每个采纳抓取输出可回放 CCT（certificate-carrying trace），含每步门触发、边际与见证引用。
6. Exec_v6 = {x ∈ supp(π_θ^FM) : ∧_i kc_i^v5(x; τ^5)=1 ∧ kc_grasp(x)=1}，未见证区再 ∩ 保守阈值集（γ_cons·τ^5）；故 Exec_v6 ⊆ Exec_v5。

**本轮最大风险**：**见证外部性的假象**——若演示由同一仿真器、同一价值标注团队产生，且「见证一致性」只用轨迹邻近度这一代理，则所谓外部锚只是名义外部；策略可能学会「贴近演示但违背意图」的对抗性通过，覆盖率也可能在无见证区被高估，使自指回路以更隐蔽的形式复发。

| kc_i(x) ∈ {0,1} | 七硬门布尔谓词：kc_3DCF, kc_MSRG, kc_HICK, kc_EEK, kc_LTEM, kc_VACK, kc_BCK |
| σ_speech ∈ [0,1] | 语音识别置信度 |

### IP-496 EFA-v5：七硬门 + 调制阈值 + 级联采样选证

```python
@dataclass
class EvidenceForgingAssemblerV5:
    """EFA-v5：七硬门不变（阈值可调制、只紧不松）+ 级联采样选证"""
    fmpp: FlowMatchingProposalPolicyKernel
    lmem: LongTermMemoryEmbeddingConsolidation
    famk: FacialAffectModulationKernel
    v4: EvidenceForgingAssemblerV4        # 复用 scf/msrg/hic/eek/vack/bck 全套

    def select(self, x0_state, t_now, rule_id, context) -> tuple[bool, Trajectory | None, str]:
        s_emo = self.famk.observe(context.face, t_now)
        gamma = self.famk.gamma(s_emo)                   # 全 1.0 = 精确退化 v4
        c = build_ctx(context, s_emo, self.lmem)         # 含 Top-k 记忆 token
        cands = self.fmpp.propose(c, self.fmpp.K)        # K=8，~5–20 ms，异步准入时域
        # 级联第 1 层：廉价门（coverage/physics/memory/novelty，O(1)~O(log|M|)）
        surv = [x for x in cands if self._cheap_gates(x, gamma)]
        if not surv:
            return self._fallback_rule_proposal(gamma)   # fail-closed：回退 v4 规则提议
        # 级联第 2 层：VACK 仅评估 ≤3 幸存者（~50 ms 级，异步；预筛省 ~60% 昂贵调用）
        surv.sort(key=lambda x: self._prefilter_score(x), reverse=True)
        finals = []
        for x in surv[:3]:
            vac = self.v4.vack.evaluate(x, context_with(s_emo), t_now)
            if self.v4.vack.kc_val(vac, tau=gamma['val'] * TAU_VAL4):
                finals.append(x)
        # 级联第 3 层：BCK 轨迹预览（事件触发 QP + 缓存证书内插）
        ok = [x for x in finals if self._bck_preview(x, gamma)]
        if not ok:
            return False, None, 'ALL_CANDIDATES_REJECTED'
        best = max(ok, key=certified_margin)             # 通过者中取边际最大者
        return True, best, 'FORGED_CGE'

    def ecs_v5(self, ..., n_flow: float, s_emo: SHomo | None) -> float:
        eta_flow = sigmoid(n_flow_to_ll(n_flow) - b_flow)
        eta_emo = (1.0 - self.famk.lam_emo * s_emo.p_distress
                   if s_emo is not None and s_emo.sigma <= self.famk.sigma_max else 1.0)
        return self.v4.ecs_v4(...) * eta_flow * eta_emo
```

```
  固化（小时级）：铸证片段 ──▶ 证书过滤 ──▶ DP-SGD + KL 正则 + 失败回放 ──▶ θ_FM 更新
       ──▶ 回归门测试 + 红队对抗集 ──▶ 通过才上线（回滚 = 旧 θ_FM）
  边际蒸馏：BCK 离线可行/不可行轨迹采样 ──▶ FMPP 可行性先验头
  联邦：Δ_i(轨迹嵌入原型/情绪分位数, DP) ──▶ 安全聚合 ──▶ FedAvg ──▶ Φ_global
       ──▶ 下发：流先验原型、Γ_3D/Θ_domain/λ_vec^0 校准、ε_emo 参数

在线准入（异步，秒级）：
  FAMK.observe (10–30 Hz, 端侧) ──▶ γ(ŝ_emo) 预计算
  FMPP.propose (K=8) ──▶ 廉价门筛（含 n_flow 新颇度）
       ├─ 全灭 ──▶ fail-closed 回退 v4 规则提议
       └─ 幸存 ≤3 ──▶ VACK（调制 τ_val）──▶ BCK 预览 ──▶ 取边际最大者

在线控制环（目标 < 0.6 ms）：
  每周期：EEK(kc_ee) + BCK（事件触发：接触状态未变 → 缓存证书 + 解析边际内插，O(1)）
  证书消费：τ^5 = γ·τ^4 每周期预计算；消费缓存的候选证书
```
