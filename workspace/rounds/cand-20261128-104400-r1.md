### 第 6 轮灵感驱动研究记录

**灵感词**：真实世界泛化、移动底盘

**继承关系**：第 5 轮 CADVS-v5（IP-493~496，CGE）把提议升级为条件流匹配 π_θ^FM、记忆升级为 LMEM-v2 固化闭环、人因升级为 FAMK 情感阈值调制 γ_i≥1，并以定理 5/6/7/8 保证「换提议不换门、调制只紧、固化有界、七锚完备」，执行集 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。但 v5 的全部保证都**以「模型正确」与「分布内」为隐含前提**：实验仍在 MuJoCo 单机、底盘固定。两个灵感词恰好戳中这两个前提：(a) **真实世界泛化**——sim-to-real 的模型误差与非平稳分布漂移会让门分数 s_i 本身失真，v5 的「OOD 由回退兜底」只是把问题推给回退；(b) **移动底盘**——底盘进入决策变量后，支撑多边形动态化、定位漂移、轮滑、非完整约束同时出现，且「fail-closed 返回空动作」在移动中本身就是不安全动作。本轮不新增硬门（延续 R52 锚点负债控制），走「阈值校准 + 流形提升 + 回退认证」三条非侵入路径，形成 CADVS-v6（IP-497~500），主题「世界锚定的可迁移认证执行」（World-Grounded Transferable Certified Execution, WG-TCE）。执行集在固定底盘子空间上升级为 Exec_CADVS-v6|_{base-locked} ⊆ Exec_CADVS-v5，移动维度是**保守提升**而非放宽。

**直觉与动机**：

1. **真实世界泛化 → 把「模型给的门分数」换成「带校准误差界的门分数」，用保形校准给分布无关的覆盖率**。直觉：仿真里门分数被当成"真值"，真实世界里它只是"带偏差的估计"；与其假装模型对，不如显式估计模型偏多少，并把这个偏差加进阈值。严谨：引入世界锚定迁移核 WGTK。对每个门 i，用真实/高保真校准集的非一致性残差 R_i = s_i^real − s_i^model 做分裂保形校准，取 δ_i 为第 ⌈(n+1)(1−α_i)⌉ 个残差分位数，则 P(s_i^real ≥ s_i^model − δ_i) ≥ 1−α_i（**仅需可交换性**），再用 Bonferroni α_i = α/7 控族错误率；阈值升为 τ_i^6 = τ_i^5 + δ_i（只紧不松）。同时用 Lipschitz 界把"世界系证书"迁移到"体系证书"：位姿误差 ≤ ρ ⇒ 分数偏移 ≤ L_i·ρ（定理 14），使证书可跨坐标系、跨标定版本复用。关键：这是**分布无关**（distribution-free）而非"分布内"的保证——但代价是必须明示可交换性假设，并配漂移检测器；检测到非交换（p<α_shift）就判迁移失效，转 CSFK。

2. **移动底盘 → 不改门，改门的定义域：把七门从「固定基座」提升到「整身流形」，支撑多边形做不确定性腐蚀**。直觉：底盘一动，平衡不再是"桌面上的 ZMP"，而是"轮地支撑多边形随位姿与地形变化、且定位本身有误差"；覆盖与末点也不再是世界系固定点，而是"轮滑可达集"。严谨：引入移动底盘认证核 MBCK。配置流形 q=(q_base∈SE(2), q_arm)；支撑多边形 P(q_base, terrain) 取轮地接触凸包；在定位误差 ‖δp‖≤ρ、地形倾角 ≤φ 下取**鲁棒支撑多边形** P⊖B(ρ_eff)，ρ_eff=ρ+h·tanφ（h 为质心高），要求鲁棒 ZMP 到边界距离 ≥ 安全边际（定理 16 给出充分性）。覆盖/末点门在"轮滑可达集" R = T_nom ⊕ B(σ_s·T) 上做鲁棒可达性判定，并校验差速/曲率约束可行性。关键：这只是把既有门的定义域从固定基座流形提升到整身流形并腐蚀阈值，**谓词集合不变**；底盘锁死、ρ=0、σ_s=0 时精确退化为 v5。

3. **移动 + 真实世界 → fail-closed 必须从「返回空动作」升级为「返回已认证的安全停机/撤退」**。直觉：固定基座拒绝一个动作等于不动，是安全的；移动底盘在 1 m/s 上拒绝一个动作，机器人仍在滑行，空动作本身就是不安全动作。严谨：引入认证安全回退核 CSFK。把 fail-closed 的语义从 ⊥（无动作）改为一组**自身也被七门认证**的回退机动 {SAFE_STOP, SAFE_RETREAT, SAFE_LOCK}，其制动轨迹必须落在同一执行集内；停机距离按 d_stop ≤ v²/(2a_min)+v·τ_react+σ_s·T_brake+m_d 上界预留走廊。**定理 17（回退闭包）**：若回退机动经同一门集合认证且停机走廊无碰，则"拒绝→回退"的复合在系统层面仍保持 fail-closed——拒绝不会把系统带入未认证状态。无可用认证回退时（例如漂移已使当前状态在安全包络外）退化为硬急停 + 人机接管 + 报警，这是残余风险。

**关键洞见**：v4 问「规则提议时七门够不够」，v5 问「生成提议+记忆+情感时证书边界变不变」，v6 问「**当模型会错、世界会变、机器人会动时，证书凭什么还成立、拒绝之后靠什么才安全**」。v6 的三件事都是**元层**：WGTK 校准门的分数而不改门，MBCK 提升门的定义域而不加门，CSFK 认证回退而不放松门。七硬门 kc_evidence_forged_v5 原样复用，新增的只有误差界 δ、整身流形提升、鲁棒回退。当 δ=0、底盘锁死、回退退化为空动作时，系统精确退化为 v5。

**形式化目标（增量）**：
1. WGTK：校准残差 R_i、保形分位 δ_i（Bonferroni α/7）、τ_i^6=τ_i^5+δ_i、Lipschitz 迁移界 L_i·ρ、漂移检测与迁移失效判定。
2. MBCK：整身流形 q、鲁棒支撑多边形 P⊖B(ρ_eff)、鲁棒 ZMP 充分条件、轮滑可达集 R、非完整可行性校验、固定基座精确退化。
3. CSFK：回退机动集、制动走廊与停机距离界、回退自认证、回退闭包、无解时急停+接管。
4. 定理 14（世界锚定/证书迁移界）、定理 15（保形安全边际）、定理 16（移动底盘保守提升）、定理 17（回退闭包）、定理 18（七锚完备性在迁移/移动/回退下保持）；引理 47（保形分位有限样本界）、引理 48（鲁棒 ZMP 腐蚀充分性）。
5. EFA-v6：七硬门 + 校准阈值 + 整身鲁棒门 + 认证回退；ECS_v6 = ECS_v5 · η_transfer · η_mobile。
6. Exec_CADVS-v6 = {x ∈ 整身流形 : ∧_i kc_i(x,c; τ_i^5+δ_i)=1 ∧ 鲁棒 ZMP ∧ 非完整可行}；固定底盘子空间上 Exec_v6|_lock ⊆ Exec_v5。

**本轮最大风险**：**可交换性破缺下的「伪分布无关」保证**——保形校准的 1−α 覆盖率只在可交换性成立时有效，而移动底盘在闭环中主动改变数据分布、真实世界的非平稳漂移又让校准集与部署分布不可交换，于是 α 保证会静默失效，系统却仍以「分布无关」自我背书；这把 v5 明示的「OOD 无界」变成了被形式保证掩盖的盲区，更危险；漂移检测 + 回退 + 周期重标定只能缓解，无法根除。

## 2. 关键算法骨架

### IP-497 WGTK：世界锚定迁移与保形校准核（离线校准 + 在线 1–10 Hz 监测）

```python
@dataclass
class WorldGroundedTransferKernel:
    """WGTK：把模型门分数校准为带误差界的真实分数。
    定理 15：保形覆盖 1−α 仅需可交换性；非交换 → 迁移失效 → CSFK。
    红线：δ_i ≥ 0，阈值只升不降；漂移检测只触发回退/重标定，绝不放松门。"""
    calib: list                    # [(x, c, s_model[7], s_real[7])]，真实/高保真
    alpha: float = 0.05            # 族错误率，Bonferroni 分到 7 门
    L: np.ndarray = None           # 各门对位姿的 Lipschitz 常数 L_i
    shift_detector: Any = None
    alpha_shift: float = 0.05

    def calibrate(self) -> np.ndarray:
        deltas = []
        for i in range(7):
            R = sorted(sr[i] - sm[i] for (_, _, sm, sr) in self.calib)
            k = math.ceil((len(R) + 1) * (1 - self.alpha / 7))
            deltas.append(R[min(k, len(R)) - 1])          # 上分位数（引理 47）
        return np.maximum(0.0, np.asarray(deltas))         # δ_i ≥ 0

    def transfer(self, delta: np.ndarray, rho: float) -> np.ndarray:
        """世界系证书 → 体系证书：位姿误差 ρ 最多使分数偏移 L_i·ρ（定理 14）"""
        return delta + self.L * rho

    def shift_ok(self, batch) -> bool:
        p = self.shift_detector.p_value(batch)             # MMD/密度比/残差漂移
        return p >= self.alpha_shift                       # False ⇒ 非交换 ⇒ CSFK

    def thresholds(self, rho: float) -> np.ndarray:
        return TAU_V5 + self.transfer(self.calibrate(), rho)   # 只升不降
```

### IP-499 CSFK：认证安全回退核（事件触发，1–10 Hz）

```python
@dataclass
class CertifiedSafeFallbackKernel:
    """CSFK：fail-closed 的语义升级为「认证回退」。
    定理 17：回退机动经同一门集合认证 ⇒ 拒绝→回退仍保持 fail-closed。"""
    gates: Any                     # 复用 MBCK+WGTK+EFA-v5 七门
    a_min: float = 1.5             # 最小保证减速度
    tau_react: float = 0.1
    m_d: float = 0.05

    def stopping_corridor(self, x, v) -> Corridor:
        d = v * v / (2 * self.a_min) + v * self.tau_react + self.sigma_s * T_brake + self.m_d
        return corridor_along(x.base_path, d)

    def fallback(self, x, v, gamma) -> Maneuver:
        for m in (SAFE_STOP, SAFE_RETREAT, SAFE_LOCK):
            traj = m.plan(x, v)
            if self.gates.certify_all(traj, gamma) and free(self.stopping_corridor(traj, v)):
                return m                                   # 回退自身已认证
        return EMERGENCY_STOP + HANDOVER + ALERT           # 残余风险，显式越界
```

# 定理 15：保形安全边际（分布无关覆盖）
def theorem_conformal_margin() -> str:
    """

### IP-500 EFA-v6：七硬门 + 校准阈值 + 整身鲁棒门 + 认证回退

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：七硬门不变；校准/整身/回退为只紧元层。"""
    v5: EvidenceForgingAssemblerV5
    wgtk: WorldGroundedTransferKernel
    mbck: MobileBaseCertificationKernel
    csfk: CertifiedSafeFallbackKernel

    def select(self, x0_state, t_now, rule_id, context):
        # 0) 漂移检测：非交换 → 迁移失效，直接走认证回退
        if not self.wgtk.shift_ok(context.batch):
            return self.csfk.fallback(x0_state, context.v, gamma=INF_TIGHTEN), 'SHIFT_DETECTED'
        # 1) 校准阈值 + 整身鲁棒门（只紧）
        tau6 = self.wgtk.thresholds(context.rho)                 # τ^5 + δ，只升
        gamma = combine(self.v5.famk.gamma(context.s_emo),
                        self.wgtk.transfer(np.zeros(7), context.rho))
        # 2) 整身流形上的七门（覆盖/平衡/末点用鲁棒版本；其余同 v5）
        ok, best, reason = self.v5.select(x0_state, t_now, rule_id,
                                          context_with(gamma, tau6, lift=True))
        if ok and self.mbck.nonholonomic_ok(best):
            return True, best, 'FORGED_WGTCE'
        # 3) 拒绝 → 认证回退（不是空动作）
        return self.csfk.fallback(x0_state, context.v, gamma), 'CERTIFIED_FALLBACK'

    def ecs_v6(self, v5_terms, delta_bar: float, rho_bar: float) -> float:
        eta_transfer = 1.0 - 0.5 * min(delta_bar, 1.0)
        eta_mobile = 1.0 - 0.5 * min(rho_bar, 1.0)
        return self.v5.ecs_v5(**v5_terms) * eta_transfer * eta_mobile
```

## 4. 正确性论证（增量更新）

### 引理 47（保形分位的有限样本覆盖）

**陈述**：设 (Z_1,…,Z_{n+1}) 可交换，非一致性分数 R_i = R(Z_i)，δ 为前 n 个分数排序后第 ⌈(n+1)(1−α)⌉ 个。则 P(R_{n+1} ≤ δ) ≥ 1−α。∎

**诚实边界**：仅边际覆盖；对条件覆盖无保证。**可交换性**是全部保证的支点——时间相关、反馈闭环、非平稳漂移都会破坏它。

### 引理 48（鲁棒 ZMP 腐蚀充分性）

**陈述**：设真实支撑多边形 P 与名义 P̂ 满足 Hausdorff 距离 ≤ ρ_eff，ZMP 投影对位姿 1-Lipschitz。若 d_zmp(P̂⊖B(ρ_eff)) ≥ m_d，则真实 ZMP 落在 P 内且到边界 ≥ m_d。证明：腐蚀定义 + 三角不等式。∎

**诚实边界**：准静态假设；动态步态、腾空、急加减速下需捕获点/动量方法，本引理不覆盖。

### 定理 v6（世界锚定、整身提升与回退闭包，总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) 校准集与部署分布可交换、(B9) 地形倾角/轮滑/定位误差有界下：
(i) 固定底盘子空间上 Exec_CADVS-v6|_lock ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29（δ≥0 + 腐蚀 + 同门）；
(ii) 分布无关覆盖：七门联合真实违约率 ≤ α（定理 15，Bonferroni），执行集随 α 单调；
(iii) 证书迁移：世界系→体系边际税 ≤ L_i·ρ（定理 14）；
(iv) 整身保守提升：鲁棒 ZMP/轮滑可达 ⇒ 有界不确定性下不倾覆、可达（定理 16）；锁死底盘精确退化 v5；
(v) 回退闭包：拒绝→认证回退不越出执行集（定理 17）；
(vi) 七锚完备性保持（定理 18）。

**证明**：(i) 由 δ≥0、腐蚀只缩、谓词不变；(ii) 引理 47 + Bonferroni；(iii) 定理 14；(iv) 引理 48 + 可达集膨胀；(v) 定理 17；(vi) 定理 18。∎

**诚实声明**：(B8) 可交换性是**强假设**，真实非平稳部署几乎必然违反，此时 (ii) 静默失效——这是本轮最大风险；(B9) 准静态，不覆盖动态步态；(iii) 迁移税随 ρ 线性增长，大漂移下执行集可能塌缩至空，只能靠重定位/重标定恢复；(v) 回退闭包以"存在认证回退"为条件，状态已在包络外时无解；(vi) 加性价值假设 (B4) 继承自 v4，未解决。

## 7. 本轮最大风险（最终确认）

**一句话**：**可交换性破缺下的「伪分布无关」保证**——保形校准的 1−α 覆盖率只在可交换性成立时有效，而移动底盘在闭环中主动改变数据分布、真实世界的非平稳漂移又让校准集与部署分布不可交换，于是 α 保证会静默失效，系统却仍以「分布无关」自我背书；这把 v5 明示的「OOD 无界」变成了被形式保证掩盖的盲区，更危险；漂移检测 + 回退 + 周期重标定只能缓解，无法根除。
