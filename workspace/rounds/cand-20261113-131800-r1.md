# 第 66 轮（跨轮承接第 65 轮「VISTA 故障可归因闭环」IP-214~223；「技术融合 × 协同控制」灵感循环第 1 轮；本轮灵感：「技术融合」×「协同控制」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述最大风险已经暴露了要害：**故障被强行塞进有限假设集、且视觉与几何共享共因失效源时，归因会错，而系统因为『已经归因』反而更自信地继续执行。** 本轮不修补 FIR 的假设集，而是换一个更根本的提问：第 65 轮始终是**单机、单认证器、单故障**。COVENANT 问：**当安全不再由一台机器的一个模型保证，而由多种异构技术、多台机器互相作保时，谁为谁的假设负责、违约时如何协同降级？** 本轮核心命题是：
>
> **把「单机可归因」升级为「多机可协同、异构技术可证」：安全不是某一种技术的结论，而是一本『假设账本』上的多方契约——每种技术为某些假设作证、同时监控别人的假设；任一假设失守，必须有一个『不依赖该假设本身』的独立监控者在不可逆点前发现它，并在协同层完成契约修复。技术融合提供失效模式互补，协同控制提供互相作保，二者共享同一本账。**

## 0. 直觉与动机

**灵感 1（技术融合 → 安全技术的失效模式互补，而不是能力叠加）**
直觉：每一种安全技术都有**结构性盲区**——CBF/QP 可证但依赖模型正确；学习世界模型表达强但分布外脆弱；conformal 分布无关却只承诺边际覆盖、漂移即失准；shield 需要抽象、抽象错则失效；VISTA 能归因却假设故障在有限集且相互独立。把这些技术"投票/取平均"是错的：它们往往在同一批样本上一起对、一起错，平均只会稀释证据。融合的正确姿势是**让 A 的假设由 B 的监控来担保**：A 用模型，B 就监控"模型是否还行"；B 用学习，C 就监控"是否分布外"。融合的全部价值来自**失效模式互补**，全部风险来自**共模相关**。

**灵感 2（协同控制 → 多机安全本质是「互相作保」的契约）**
直觉：多机同场时，每个 agent 的安全集依赖别人未来怎么动。常规做法是各自膨胀、假设对方"理性/守规"；真正可靠的安全是**契约**：i 向 j 承诺"我保持在 G_i 内"，j 据此把 i 当作**有界扰动**纳入自己的安全屏障。VISTA 的故障归因改变的不是某个球，而是**某条承诺的可信度**：j 不能再假设 i 会守约，必须重算安全集、或退出契约。因此协同控制的本质是**契约的建立、监控、违约检测与重协商**，而不是一个静态的分布式 QP。

**灵感 3（两灵感合流 → 假设账本让「融合」与「协同」共用同一个形式对象）**
直觉：技术融合是"一个 agent 内、多种技术为同一组假设作保"；协同控制是"多个 agent 为彼此的承诺作保"。二者其实是**同一本假设账本的两个层级**：单机层是「技术 × 假设」，团队层是「agent × 承诺」。于是只需一种形式对象——**带监控者指针和独立性标签的假设账本**——就能同时表达两层。安全 = 账本良基（没有"无人独立监控"的假设）+ 契约兼容 + 违约在放弃视界内被修复。这让"融合"与"协同"不再是两个拼贴的模块，而是一个算子的两个投影。

**灵感 4（多机是多样性探针，但一致性不能伪造独立性）**
直觉：第 65 轮单机归因的最大盲区是共模故障。多机似乎带来"多数投票"这一免费解药，但必须诚实：**若多机共享同款相机、同款模型、同一时钟，它们会一致地错**，此时一致（零分歧）恰恰是危险信号而非信任信号。故多机提供的是**多样性红利**，不是冗余红利：独立时，分歧能定位局部异构故障；共模时，一致性完全无法识别谎言。独立性能否被利用，取决于**结构独立性是否被建立并可被检验**——这就是"多样性探针"：主动扰动其中一个 agent 的输入，看团队后验是否随之改变，没变就说明它们其实耦合在一起。

**灵感 5（VISTA 组件原位升级 → COVENANT）**
- **VISTA → VISTA-M**：从单机语义/实时流扩为「单机流 ∘ 团队协同流」，团队层只做契约协商与协同归因，不侵入实时环。
- **FIR → CFA（协同故障归因）**：单机后验改为对数意见池融合；**分歧定位局部故障**，**多样性探针暴露共模**。
- **CSC → CSC-C（契约感知的认证前缀）**：认证前缀除力/滑移约束外，还需满足"放弃视界 τ_r ≤ 不可逆视界 m"，否则预先降级。
- **RSC-V → RSC-C**：把"归因定向球"升级为"契约信任半径 r_j^C"，只对**被怀疑违约的邻居**收紧。
- **WCV-V → WCV-C**：搜索域改为**联合安全集**（自身证书 ∩ 邻居契约的下界）。
- **AIC-V → AIC-C**：干扰集增共模故障、拜占庭 agent、协同时序错位/通信延迟。
- **J_vista → J_cov**：证书增 assumption_ledger_hash、contract_version_vector、trust_radius_vector、common_mode_margin、repair_epoch。

## 1. 形式化定义（增量：定义 233–244）

- **定义 233（COVENANT 闭环）**：COVENANT = (VISTA-M, 𝕋, 𝕃, ⊔, ℂ, CR, CFA, DTP, DCBF, AIC-C, J_cov)。定位：VISTA 的"多机 × 多技术"升级。不变式：**实时流只做本地见证执行、监控触发与安全回退；账本构建、融合、契约协商、协同归因、多样性探针、证书只在语义流/团队低频线程，零学习写操作。**
- **定义 234（异构见证与不可比性）**：安全技术 t∈𝕋 产出见证 w_t=(S_t,A_t,φ_t)：S_t⊆𝕏 为声称安全集，A_t 为其健全所依赖的假设集，φ_t 为实时可判的监控谓词（A_t 失效时可被检出）。**不可比**：不存在 t,t' 使得 A_t⊆A_{t'} 且 S_t⊇S_{t'}——无单一见证支配其余，故单技术不可能健全覆盖全部假设。
- **定义 235（假设账本与良基监控）**：账本 𝕃 = {(a, Supp(a), Mon(a), ρ(a))}：每个假设 a 有支持者（依赖 a 的技术/契约）、监控者（能检出 ¬a 的见证）、独立性标签 ρ(a)（与该假设共享的共模源集合）。监控图 G_𝕃：a → t' 当 t'∈Mon(a)。**良基** ⇔ 存在分配 μ 使假设可线性排序 a_1,…,a_n，且每个 a_i 的监控者 t'(a_i) 的假设 ⊆ {a_1,…,a_{i−1}} ∪ Phys（Phys 为物理不变量）。即：没有任何假设只能由"自己也假设它"的见证来监控。
- **定义 236（融合算子 ⊔、共模割与伪融合）**：fuse(w_1..w_k)=(S_⊔, A_⊔, μ)，S_⊔=⋂_t S_t，A_⊔=⋃_t A_t，μ 为良基监控分配。**共模割** C：存在单一失效源 s（同款相机/时钟/通信/供电），当 s 失效时 Mon(a) 对全部 a∈C 同时失效的集合。共模裕度 κ_cm=1−max_C P(s_C 失效)。若账本"看似良基"但所有分配都被同一共模割击穿，称**伪融合**（pseudo-fusion）。
- **定义 237（协同安全契约与兼容性）**：agent i 的契约 C_i=(A_i,G_i)：A_i 是对邻居的假设，G_i 是自身保证（保持在安全集内）。团队契约 C=⊗_i C_i；**兼容** ⇔ (⋀_i G_i) ⇒ (⋀_i A_i)。联合安全集 S^⊗={x : ∀i, x_i∈S_i^{G_i}}。
- **定义 238（契约信任半径与违约余量）**：CFA 给出 agent j 的故障后验 P_j(H) 与熵 H_j。定义违约度 ε_j = (1−P_j(H0))·D_max + λ·H_j，信任半径 r_j^C = g(ε_j)（需保持的最小间距/扰动上界）。对未被归因的邻居取 ε_j=ε_0（默认先验）；对被归因者 ε_j 上升、r_j^C 收紧。
- **定义 239（契约修复 CR 与放弃视界）**：CR 三步——(i) **加固**：收紧自身 G_i（降速/增裕度）；(ii) **放宽**：按 r_j^C 扩大对邻居扰动的鲁棒集（收缩联合安全集）；(iii) **退出**：安全停/柔顺退避。修复按字典序最小化（先安全违规概率，再任务损失）。**放弃视界 τ_r** = 通信延迟 + 协商计算 + 停止距离所需时间；要求 τ_r ≤ min_i m_i（各机不可逆视界），否则必须**预先降级**而非事后修复。
- **定义 240（协同故障归因 CFA）**：各机本地后验 P_i(H)；独立性加权对数意见池 log P_team(H) ∝ Σ_i w_i log P_i(H)，w_i 按 AIC-C 估得的独立度下调相关机。分歧度 D_dis = max_{i,j} KL(P_i‖P_j)：**高分歧 ⇒ 局部异构故障可被定位**；**零分歧并不等于健康**（见定义 241）。
- **定义 241（多样性测试 DTP 与结构独立性）**：对 agent i 的观测注入已知小干预 δ（如微动视差/主动打光/注入已知扰动），测团队后验变化 ΔP_team(δ)。若 ΔP_team 显著小于独立假设下的预测（传递被衰减），判为**伪独立/共模耦合**；此时把融合降级为"单技术 + 默认最坏扰动"，不把独立性计入安全裕度。独立度证书独立于"一致性"：**一致性只有在独立性被外部建立时才可被采信**。
- **定义 242（分布式安全屏障 DCBF）**：团队屏障 h(x_team)（如最小间距、力限、关节限的合成）；每 agent 解本地 QP：min ‖u_i−u_i^nom‖² s.t. L_f h_i + L_g h_i u_i + Σ_{j≠i} ι_{ij}(r_j^C) ≥ −α h_i。若所有本地 QP 可行，则联合不变式 h≥0 保持；不可行则该 agent 触发 CR 的"退出"分支。
- **定义 243（融合-协同时序耦合）**：修复必须在放弃视界内完成，且 VISTA 的"长预测、短执行"前缀 k* 还要满足 k*·Δt ≤ τ_r；即**协同不能拖慢单机的不可逆点承诺**。违反则预降级并写入 J_cov。
- **定义 244（COVENANT 证书 J_cov）**：J_cov=(J_vista, assumption_ledger_hash, well_founded, contract_version_vector, compatible, trust_radius_vector, common_mode_margin, diversity_test_stat, repair_epoch, aic_c_ver)。Valid ⇔ Valid(J_vista) ∧ well_founded ∧ compatible ∧ τ_r≤min_i m_i ∧ (伪融合 ⇒ 已降级为单技术最坏扰动) ∧ 共模裕度≥κ_min。

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（良基账本 ⇒ 融合见证健全）**：若账本良基（定义 235）且监控延迟 ℓ_mon 小于剩余安全视界、共模裕度 κ_cm>0，则任一无物理担保的假设失效都会被一个"不依赖该假设自身"的监控者在越界前检出，融合见证健全。这是把"多技术"从并列堆叠变成**归纳可证**的监控链。
- **引理 10（契约兼容 + DCBF ⇒ 联合不变式）**：若团队契约兼容且每 agent 的本地 DCBF-QP 可行，则联合安全集 S^⊗ 前向不变；信任半径 r_j^C 越大，联合集越小、越保守但越安全。
- **定理 9（COVENANT 端到端协同安全）**：在良基账本、兼容契约、τ_r≤min m_i 下，团队越界概率 ≤ Σ(conformal α) + Σ(归因错误率) + (1−κ_cm) + P(τ_r 超时)，且只对**被归因违约**的邻居收紧信任半径。
- **定理 10（共模可检测性的边界）**：仅凭 agent 间一致性/分歧无法检测共模故障——若共模源使所有 agent 的后验更新相同，则团队后验退化为单机后验、分歧恒为 0；对抗共模只有两种力量：**结构性异构**（不同物理通道/模型族/时钟）与**主动多样性探针**（外生干预打破对称）。故"多机投票"不构成安全裕度，独立度必须被外部建立。
- **命题（融合的收益-风险权衡）**：融合的可安全运行域 F_⊔ 相对单技术并集 ⋃_t F_t 的扩张量由**互补盲区覆盖率**决定；当共模源 c 失效时 F_⊔ 收缩为 ⋂_{t:c∈ρ(t)} F_t。净收益为正 ⇔ 互补覆盖增益 > 共模暴露损失。
- **实时性**：本地 DCBF-QP 与监控触发留在实时环（<0.1ms + 既有 VISTA 2.5ms）；账本、融合、契约、CFA、DTP 全在团队低频线程，目标团队周期 ≤20ms。

## 5. 本轮最大风险

**一句话**：COVENANT 的全部健全性都压在"假设账本能被良基监控、且共模割可被结构性排除"之上；但账本构建、监控分配、契约协商与协同归因本身都跑在同一套感知/时钟/通信基质上——当真正致命的共模故障恰好发生在这层基质时，所有"独立监控者"一起失效、所有 agent 一起同意一个错误归因，系统会因"账本显示良基、契约显示兼容"而给出比单机 VISTA **更自信**的错误证书：技术融合与协同控制可能不是在消除单点故障，而是在更高层制造了一个被形式化外衣掩盖的**共模单点故障**。

## 2. 形式化定义（完整版）

**定义 233（COVENANT 闭环）** COVENANT 是 VISTA 的"多机 × 多技术"升级：保留第 65 轮"语义流 ∘ 实时流"骨架，在其上增加**团队协同流**（ALG 账本构建、FW 融合、CFA 协同归因、DTP 多样性探针、CN 契约协商、DCBF 耦合），并原位升级 CSC→CSC-C、RSC-V/WCV-V→RSC-C/WCV-C、AIC-V→AIC-C、J_vista→J_cov。不变式：**实时路径只做本地见证执行、监控触发与安全回退；账本、融合、契约协商、协同归因、多样性探针、证书只发生在语义流/团队低频线程，零学习写操作。**

**定义 234（异构见证与不可比性）** 安全技术 t∈𝕋 产出见证 w_t=(S_t,A_t,φ_t)：S_t⊆𝕏 为声称安全集，A_t 为其健全所依赖的假设集，φ_t 为实时可判的监控谓词（A_t 失效时 φ_t 触发）。称 w_t 与 w_{t'} **不可比**，若不存在支配关系 A_t⊆A_{t'} ∧ S_t⊇S_{t'}。不可比性的意义：没有任何单一技术能同时拥有最弱的假设与最大的安全集，故单技术健全覆盖不足，必须融合。

**定义 235（假设账本与良基监控）** 账本 𝕃 = {(a, Supp(a), Mon(a), ρ(a))}。监控图 G_𝕃 有边 a→t' 当 t'∈Mon(a) 且 t' 能实时判 φ_{t'} 以检出 ¬a。**良基（well-founded）** ⇔ 存在监控分配 μ 与假设的线性序 a_1,…,a_n，使得每个 a_i 的监控者 t'(a_i) 所依赖的假设
A_{t'(a_i)} ⊆ {a_1,…,a_{i−1}} ∪ Phys。
直观：监控链必须**归纳地**收敛到物理不变量，不能循环担保（"我相信你，因为你相信我相信你"）。若某假设只能由"自身也假设它"的见证监控，则账本在该假设上**不良基**，融合对该假设无效。

**定义 236（融合算子 ⊔、共模割与伪融合）** fuse(w_1,…,w_k)=(S_⊔,A_⊔,μ)，其中 S_⊔=⋂_t S_t、A_⊔=⋃_t A_t、μ 为良基分配。**共模割** C⊆A_⊔：存在单一失效源 s∈ρ(a)（同款相机、时钟、通信、供电、同一世界模型）使 {t' : t'∈Mon(a), a∈C} 全部同时失效。**共模裕度** κ_cm=1−max_C P(s_C 失效)。若账本"看似良基"但每一次良基分配都被同一共模割击穿，称**伪融合**（pseudo-fusion）：形式上有监控者，实际上监控者与被监控者同生共死。伪融合必须在 J_cov 中标出并降级。

**定义 237（协同安全契约与兼容性）** agent i 的契约 C_i=(A_i,G_i)：A_i 是对邻居行为的假设（如"j 保持间距 ≥ d_j"），G_i 是自身保证（保持在 S_i^{G_i} 内）。团队契约 C=⊗_i C_i。**兼容** ⇔
(⋀_i G_i) ⇒ (⋀_i A_i)。
即"所有保证合起来"能推出"所有假设"。联合安全集 S^⊗={x : ∀i, x_i∈S_i^{G_i}}。不兼容的契约意味着存在一个 agent 的假设无法由他人保证兑现，必须重协商。

**定义 238（契约信任半径与违约余量）** CFA 给出 agent j 的故障后验 P_j(H) 与熵 H_j（定义 240）。违约度
ε_j=(1−P_j(H0))·D_max + λ·H_j，
信任半径 r_j^C=g(ε_j)（需相对 j 保持的最小间距/把 j 视为的有界扰动上界）。未归因邻居取 ε_j=ε_0（默认先验）；被归因违约者 ε_j 上升、r_j^C 收紧。与第 65 轮 r_geo/r_force/r_model 的差别：这里膨胀的不是"我对世界的认识"，而是"我对邻居守约的信心"。

**定义 239（契约修复 CR 与放弃视界）** CR 在检测到归因违约或监控触发时执行三步：
1. **加固**：收紧自身 G_i（降速、增裕度、缩小步长）；
2. **放宽**：按 r_j^C 扩大对邻居扰动的鲁棒集（收缩联合安全集 S^⊗）；
3. **退出**：安全停/柔顺退避，撤销契约并进入 `safe_hold`。
修复按字典序最小化 (P[安全违规], 任务损失) 选分支。**放弃视界** τ_r=通信延迟+协商计算+停止距离所需时间；硬约束 τ_r≤min_i m_i（各机不可逆视界）。若无法满足，必须在动作执行前**预先降级**（不进入高承诺块），而不是等违约发生后补救。

**定义 240（协同故障归因 CFA）** 各机本地后验 P_i(H)。**对数意见池**：
log P_team(H) ∝ Σ_i w_i log P_i(H)，
w_i 为按 AIC-C 估得的独立度权重（相关机降权、拜占庭机可置零）。**分歧度**
D_dis=max_{i,j} KL(P_i‖P_j)。
高分歧 ⇒ 局部异构故障可被定位（多数一致、少数异常即嫌疑）；但**零分歧不等于健康**——若共模源使全体后验同向偏移，则分歧为 0 而结论错误，需由定义 241 处理。

**定义 241（多样性测试 DTP 与结构独立性）** 对 agent i 的观测通道注入已知小干预 δ（微动视差、主动打光、注入已知扰动、切换一套异构传感器），测量团队后验变化
ΔP_team(δ)=D_KL(P_team(·|δ) ‖ P_team(·))。
在**结构独立**假设下，δ 只应影响 agent i 的证据，团队后验变化有可预测量级 Δ_ind；若实测 ΔP_team(δ) ≪ Δ_ind（传递被衰减/被吸收），判为**伪独立/共模耦合**：多个 agent 实际上共享了同一个错误源。判为伪独立时，融合降级为"单技术 + 默认最坏扰动"，**不把独立性计入安全裕度**。核心立场：**一致性只有在独立性被外部建立时才可被采信；多机投票本身不构成安全裕度。**

**定义 242（分布式安全屏障 DCBF）** 团队屏障 h(x_team)（最小间距、力限、关节限的合成）。每 agent 解本地 QP：
u_i* = argmin ‖u_i−u_i^nom‖²
s.t. L_f h_i + L_g h_i u_i + Σ_{j≠i} ι_{ij}(r_j^C) ≥ −α h_i，
其中 ι_{ij}(r_j^C) 为契约耦合项（邻居在信任半径内可施加的最坏影响）。若所有本地 QP 可行，则联合不变式 h(x_team)≥0 保持；若某 agent 不可行，触发 CR 的"退出"分支。r_j^C 越大（越不信任 j），耦合项越保守，可行域越小。

**定义 243（融合-协同时序耦合）** 修复必须在放弃视界内完成，且 VISTA 的认证前缀还要满足协同时序约束：
k*·Δt ≤ τ_r ≤ min_i m_i。
即**协同不得拖慢单机的不可逆点承诺**：若团队协商所需时间超过某机不可逆视界，该机必须预降级（k* 截断、进入安全块），并把 `repair_epoch` 与 `tau_r` 写入 J_cov。这把第 65 轮"长预测、短执行"从单机时间约束升级为**团队时间约束**。

**定义 244（COVENANT 证书 J_cov）** J_cov=(J_vista, assumption_ledger_hash, well_founded, contract_version_vector, compatible, trust_radius_vector, common_mode_margin, diversity_test_stat, repair_epoch, aic_c_ver)。验证规则：
Valid(J_cov) ⇔ Valid(J_vista)
∧ well_founded(𝕃, μ)
∧ compatible(⊗_i C_i)
∧ (τ_r ≤ min_i m_i)
∧ (pseudo_fusion ⇒ 已降级为单技术最坏扰动)
∧ (pseudo_independence ⇒ 未把独立性计入裕度)
∧ κ_cm ≥ κ_min
∧ aic_c_ver 为当前版本。
审计链新增：为什么信这个监控者（账本 μ）、为什么收紧对这个邻居的信任（r_j^C）、融合是否伪融合（κ_cm）、独立度是否被探针证伪（ΔP_team）。

### IP-224/225 假设账本与融合见证

```python
class AssumptionLedger:
    """统一表达『技术融合』(技术×假设) 与『协同控制』(agent×承诺)。"""
    def __init__(self):
        self.assumptions = {}      # a -> {'supp': set, 'mon': set, 'rho': set}

    def register_witness(self, tech, w):
        for a in w.A:              # 技术 tech 依赖的假设
            self.assumptions.setdefault(a, {'supp': set(), 'mon': set(), 'rho': set()})
            self.assumptions[a]['supp'].add(tech)
            self.assumptions[a]['rho'] |= w.common_mode_sources(a)
        for a in w.monitors:       # 技术 tech 能监控的假设
            self.assumptions.setdefault(a, {'supp': set(), 'mon': set(), 'rho': set()})
            self.assumptions[a]['mon'].add(tech)

    def well_founded(self, mu):
        # 假设线性排序：每个假设由『不依赖其后继』的技术监控，最终落到 Phys
        order, remaining = [], set(self.assumptions)
        tech_assumes = {t: set(a for a, v in self.assumptions.items() if t in v['supp'])
                        for t in ALL_TECHS}
        while remaining:
            picked = None
            for a in list(remaining):
                mon = mu.get(a, self.assumptions[a]['mon'])
                if any(tech_assumes.get(t, set()) <= set(order) | PHYS for t in mon):
                    picked = a; break
            if picked is None:
                return False, order        # 剩余假设构成循环担保
            order.append(picked); remaining.discard(picked)
        return True, order

    def allocate_monitors(self):
        # 加权集合覆盖：优先选『不共享共模源』的监控者，最大化独立性
        return greedy_cover(self.assumptions, weight=lambda a, t: 1.0 - cm_overlap(a, t))

    def common_mode_margin(self, cuts):
        return 1.0 - max((cm_fail_prob(C) for C in cuts), default=0.0)


def fuse(witnesses, ledger):
    S = intersect(w.S for w in witnesses)
    A = union(w.A for w in witnesses)
    mu = ledger.allocate_monitors()
    ok, order = ledger.well_founded(mu)
    kappa_cm = ledger.common_mode_margin(ledger.cuts())
    pseudo = ok and kappa_cm < KAPPA_MIN      # 看似良基却被同一共模割击穿
    return Fused(S, A, mu, well_founded=ok, kappa_cm=kappa_cm,
                 pseudo_fusion=pseudo, order=order)
```

### IP-227/228 协同归因与多样性探针

```python
class CooperativeAttribution:
    def fuse(self, posts, weights):
        logp = {h: sum(w * np.log(p[h] + 1e-12)
                       for w, p in zip(weights, posts))
                for h in HYP}
        z = normalize_logp(logp)
        return softmax(z)

    def disagreement(self, posts):
        return max(kl(p, q) for p in posts for q in posts)

    def localize(self, posts):
        # 与团队后验最不一致的机为局部故障嫌疑
        team = self.fuse(posts, [1.0] * len(posts))
        return int(np.argmin([np.exp(-kl(p, team)) for p in posts]))

    def diversity_test(self, team, inject, observe, delta):
        # 注入已知干预，比较实际后验变化与独立预测
        base = observe(team)
        pert = observe(inject(team, delta))
        dp = kl(pert, base)
        return {'stat': float(dp), 'pseudo_independence': dp < BETA * dp_independent(delta)}
```

### IP-226 契约协商与修复

class ContractNegotiator:
    def compatible(self, contracts):
        # 所有保证的合取是否推出所有假设
        return implies(all_G(contracts), all_A(contracts))

    def repair(self, contracts, posts, tau_r):
        plans = []
        for mode in ('harden', 'relax', 'retreat'):     # 加固/放宽/退出
            C = apply_repair(contracts, posts, mode)
            plans.append((violation_prob(C), task_loss(C), C))
        plans.sort(key=lambda z: (z[0], z[1]))          # 字典序
        return plans[0][2]

    def pre_downgrade(self, m_min):
        # 放弃视界无法满足时，动作前预先降级，而非事后补救
        return {'k_cap': max(1, m_min - 1), 'safe_block': True}
```

def certified_prefix(self, A, post_team, m, tau_r, alpha_chunk):

def COVENANT_round(M, team_obs, goal):

    post_team = M.cfa.fuse(posts, weights)
    div = M.cfa.disagreement(posts)
    faulty = M.cfa.localize(posts) if div > TAU_DIS else None
    if not M.dtp.passes(team, delta=PROBE_DELTA):
        weights = [1.0] * N                            # 伪独立：独立性不计裕度
    # —— 信任半径 + 契约兼容 + 时序约束 ——
    r_C = {j: trust_radius(eps(post_team, j)) for j in range(N)}
    C = M.cn.compose(r_C)
    if not M.cn.compatible(C):
        C = M.cn.repair(C, posts, TAU_R)
    tau_r = estimate_renunciation_horizon(C)
    if tau_r > min(M[i].m for i in range(N)):
        return pre_downgrade(M, tau_r)                 # 动作前降级
    # —— 执行：契约前缀 + 本地 DCBF ——
    k_star = M.csc_c.certified_prefix(goal.A, post_team, min_m, tau_r, ALPHA)
    out = {i: realtime_step_covenant(i, team_state, r_C, goal, k_star) for i in range(N)}
    # —— 证书 ——
    J = build_j_cov(M, fused, post_team, C, r_C, tau_r, aic_c_ver=AIC_C_VERSION)
    return out, J
```

## 4. 推导

**引理 9（良基账本 ⇒ 融合见证健全）** 设账本良基（定义 235），即存在假设线性序 a_1,…,a_n 与监控分配 μ，使监控 a_i 的技术 t'(a_i) 仅依赖 {a_1,…,a_{i−1}}∪Phys。对序数归纳：基准 a_1 的监控者只依赖物理不变量，其 φ 触发器可靠；归纳步：假设 a_1..a_{i−1} 的失效都能被可靠检出，则监控 a_i 的技术 t'(a_i) 在其自身假设成立的前提下可靠，故 a_i 失效也可被检出。设监控延迟 ℓ_mon 小于剩余安全视界 τ_safe，则任一失效都在越界前被接住。若共模裕度 κ_cm>0，则监控者与被监控者不共享全部失效模式，上述"可靠"不因共模而退化为空。∎
**注**：良基性排除了"循环担保"，这正是单机 VISTA 隐含假设（"视觉与几何独立"）缺失的证明义务。

**引理 10（契约兼容 + DCBF ⇒ 联合不变式）** 若团队契约兼容（定义 237），则对任意可行本地 QP 解 u_i，Σ_i (L_f h_i + L_g h_i u_i + ι_{ij}) ≥ −α Σ_i h_i。因兼容性保证每个 A_i 被 ⋀G_j 兑现，耦合项 ι_{ij}(r_j^C) 覆盖邻居在信任半径内的最坏行为，故 h 的 Lie 导数沿团队闭环满足 ḣ ≥ −α h，前向不变。r_j^C 越大，ι_{ij} 越保守，可行域 Σ 越小；单调性由此得。∎

**定理 9（COVENANT 端到端协同安全）** 在良基账本、兼容契约、τ_r≤min_i m_i 下，团队越界概率
P[越界] ≤ Σ_t α_t (conformal) + Σ_i P[归因错误_i] + (1−κ_cm) + P[τ_r 超时] + α_chunk。
各项独立贡献：conformal 失准（定义 218）、CFA 归因错误（第 65 轮 FIR + 意见池）、共模割击穿（定义 236）、协同时序超时（定义 239）、块级前缀风险（CSC-C）。且处置只对**被归因违约**的邻居收紧 r_j^C，其余邻居维持 ε_0，避免第 65 轮"总膨胀同一个球"在多机上的过度保守。∎

**定理 10（共模可检测性的边界）** 设共模源 s 使所有 agent 的局部观测似然同向偏移，即 P_i(·|s)=P_j(·|s)（对全部 i,j 的假设检验统计量相同）。则：
1. **分歧失效**：D_dis=max_{i,j} KL(P_i‖P_j)=0，任何仅基于"一致性/分歧"的检测器对 s 的检验功效为 0——一致的谎言无法由一致性识破。
2. **独立性的两条外生来源**：(a) **结构性异构**——不同物理通道（视觉/触觉/本体感觉/外部追踪）、不同模型族、不同时钟，使 s 无法同时作用；(b) **主动多样性探针 DTP**——注入 δ 打破对称，若 ΔP_team(δ) 被异常衰减则暴露耦合。
3. **安全含义**：κ_cm 不能由"多机投票"推出，只能由结构性异构的**先验暴露模型**或 DTP 的**后验证伪**给出。若 κ_cm<κ_min 或 DTP 判伪独立，则独立性不得计入安全裕度，融合退化为单技术最坏扰动。∎

**命题（融合的收益-风险权衡）** 设单技术 t 的可安全运行域 F_t={x : A_t∧x∈S_t}∪{x : ¬A_t 但 ℓ_t 内可回退到安全集}。融合后
F_⊔={x : ∃良基分配 μ，使每个未成立的假设都被独立监控者在停止距离内发现}。
则 F_⊔ ⊇ ⋃_t F_t，扩张量 = **互补盲区覆盖率**（A 的盲区被 B 的监控接住的部分）。当共模源 c 失效时
F_⊔(c)=⋂_{t : c∈ρ(t)} F_t，
即所有"看似独立"的技术一起退化。故融合净收益
Δ = Vol(互补盲区覆盖) − Vol(共模暴露损失)，
存在一个技术数量拐点 N*：超过 N* 后新增技术的共模暴露增长快于互补覆盖，融合反而更危险。这为 E247 提供了可证伪预测。∎

**命题（放弃视界与安全退化）** 若 τ_r>min_i m_i，则存在故障在协商完成前越过 agent i 不可逆点的正概率，安全退化界不闭合。缓解只能来自**预降级**：在进入高承诺块前把 k* 截断至 ⌊(m_i−τ_r)/Δt⌋，把"事后修复"变成"事前留白"。这量化了协同的代价：协同越慢，单机越只能短执行。∎

## 7. 已知风险

**一句话**：COVENANT 的全部健全性都压在"假设账本能被良基监控、且共模割可被结构性排除"之上；但账本构建、监控分配、契约协商与协同归因本身都跑在同一套感知/时钟/通信基质上——当真正致命的共模故障恰好发生在这层基质时，所有"独立监控者"一起失效、所有 agent 一起同意一个错误归因，系统会因"账本显示良基、契约显示兼容"而给出比单机 VISTA **更自信**的错误证书：技术融合与协同控制可能不是在消除单点故障，而是在更高层制造了一个被形式化外衣掩盖的**共模单点故障**（A94 隐藏假设）。

**次级风险与缓解**：
1. **共模不可被一致性检测**（定理 10）：缓解：结构性异构（不同物理通道/模型族/时钟）+ DTP 主动证伪；伪独立时禁止把独立性计入裕度；κ_cm 低于阈值时降级为单技术最坏扰动。
2. **良基性判定的计算复杂度**：假设数大时线性序搜索可能组合爆炸；缓解：按共模源分块、只对 top-|A| 关键假设做良基检查、其余按最坏联合处理。
3. **契约协商的拜占庭/理性 agent**：邻居可能虚报保证；缓解：AIC-C 注入拜占庭、契约绑定可验证证据（J_cov 哈希）、失约即收紧信任半径。
4. **DTP 探针本身的伤害/扰动**：主动干预可能影响任务；缓解：只在低风险自由空间/零力窗注入 δ，探针力/位移设上界，易损场景改用被动异构观测。
5. **放弃视界估计误差**：τ_r 依赖通信/停止距离模型，估错则预降级不足；缓解：在线测通信 RTT、保守取停止距离上界、τ_r 预留安全系数。
6. **团队周期挤占语义流预算**：账本/融合/CFA/CN 达 20ms；缓解：增量更新账本、事件触发融合、共模源分块并行。
7. **信任半径与任务效率冲突**：过度收紧导致团队寸步难行；缓解：r_j^C 只在被归因违约时上升、修复成功后按证据回落至 ε_0，避免永久保守。
8. **异构技术的语义/接口不统一**：不同技术的 S_t、A_t 难以比较与合成；缓解：统一见证接口 (S,A,φ,ρ)、离线适配层、只要求"可监控"而非"可微"。
