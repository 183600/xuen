# 第 47 轮（承接第 46 轮 v23；本轮灵感：关节驱动 × 成功率） · Actuation-Grounded Success Certificate：关节可执行性证书驱动的感知-驱动成功率联合优化（v11）

> 承接第 46 轮 v23 Memory-Safety-Voice。v10 把“感知是否可信”升级为能量-上下文-深度联合调度，v23 把“交互是否安全”升级为记忆-语音-绑定闭环，但二者共享隐含假设 **H5：姿态证书 P_t 有效 ⇒ 任务能成功执行**。在 UniBot 上这不成立：P_t 只保证“目标估得准”，不保证“关节在力矩饱和、速度上限、热降额、回差与负载下能把末端送进容差”。于是“感知很确定”的动作可能因驱动能力不足而失败，而“感知稍差但驱动冗余大”的动作成功率反而更高。本轮两个灵感词精确命中 H5：**关节驱动**把姿态证书向下接到逆动力学与执行器物理约束，给出可执行性证书 A_t；**成功率**迫使系统从二值 fail-closed 升级为可校准的成功概率，并区分“安全放弃”与“不安全失效”。二者耦合出核心问题：**在能量租约、姿态证书、驱动租约三者之间，如何做以成功率为目标的联合预算分配；当驱动误差主导时，继续买感知是浪费，而盲目降额又可能错过可完成任务**。

## 0. 直觉与动机

**灵感 1（关节驱动 → 可执行性证书 A_t）**
直觉：感知回答“目标在哪”，驱动回答“够不够得着、来不来得及、会不会过热”。给定目标动作 a（目标位姿、期望力、速度剖面），逆动力学得到所需关节力矩轨迹 τ_req(t) 与速度轨迹 q̇_req(t)。执行器有硬约束：|τ_i|≤τ_i^max·κ_i(T_i)、|q̇_i|≤q̇_i^max·κ_i(T_i)，其中 κ_i(T_i) 是随结温下降的热降额系数。定义归一化裕度 μ_a（所有关节、整个时间窗上的最小相对余量）。μ_a<0 意味着无论 P_t 多窄都无法执行，必须降速、减载、改路径或安全放弃。回差、关节柔顺与模型误差则额外贡献末端执行误差上界 e_act。三者合成 **A_t=(μ_a,e_act,ℓ_a)**，与 P_t 并列为根信任证书的一维。

**灵感 2（成功率 → 双阈值而非二值）**
直觉：失败不该只有一种。第一类是 **safe-abort**：系统识别到不可执行/低成功概率后安全停止或回撤，只损失任务成功率；第二类是 **unsafe**：碰撞、失稳、损伤，损失安全性。把成功事件 S_t 定义为“末端误差≤ε_s 且无碰撞”，目标从“保证不失败”改为
max P(S_t) s.t. P(U_t)≤ε_u，
其中 U_t 是不可逆不安全事件。这把 v10/v23 的单一 fail-closed 显式升级为“成功率受控的 fail-safe”：安全约束守 ε_u，成功率是优化目标而非硬约束。

**灵感 3（耦合 → 感知-驱动边际预算分配）**
直觉：有效误差不是只有感知项。令
e_total = rad(P_t) ⊕ e_act(A_t) ⊕ e_ctrl（⊕ 为三角不等式的保守上界和）。
成功概率近似随 (ε_s - e_total) 单调。对感知半径与对驱动裕度求边际，二者之比约为
Γ = (∂Ŝ/∂(-rad)) / (∂Ŝ/∂μ_a) = 1 / (∂e_act/∂μ_a)。
**关键结论**：当 e_act 主导（热降额、大回差、重载）时，缩小 rad(P_t) 的成功率边际增益被压制，继续开深度相机、加算力几乎买不到成功率；此时预算应投向恢复驱动能力（降速、冷却、减载、换抓取点）。反之，当驱动裕度充足、e_act≈常数时，深度感知的边际成功增益才高。这就是“感知-驱动联合预算”的判据，也把上一轮的能量-上下文-深度调度自然接上关节物理。

**架构升级（v10/v23 → v11）**
根信任证书扩展为 J'_t=(P_t, A_t, ℓ_p, ℓ_e, ℓ_a, m_t, Ŝ_t)，新增驱动租约 ℓ_a（热、力矩、占空比）。ECPS 的效用从“证书宽度缩减/能耗”改为“期望成功率增益/能耗”；PSE 用 e_total 汇总感知与驱动误差；MVR 记忆键加入负载/温度/回差/速度，避免“感知上下文相同但驱动上下文不同”的错误复用；SAB 的绑定函数加入 μ_a 惩罚；CAR 守卫加入 success-risk 约束与 safe-abort 语义；CCA 新增关节饱和、回差漂移、热降额、负载突变红队。

## 1. 形式化定义（增量：定义 59–64）

**定义 59（关节驱动模型与驱动租约）**
关节动力学
τ = M(q)q̈ + C(q,q̇)q̇ + g(q) + f_fric(q̇) + f_back(q)。
执行器约束与热降额：
|τ_i|≤τ_i^max·κ_i(T_i), |q̇_i|≤q̇_i^max·κ_i(T_i), |q̈_i|≤q̈_i^max,
κ_i(T)=clip((T_th,i-T_i)/(T_th,i-T_0,i),0,1),
热状态 Ṫ_i=α_iP_i-β_i(T_i-T_env)，P_i∝|τ_i q̇_i|（铜损+机械功）。
驱动租约 ℓ_a=(T_i,τ^max,κ,duty_i,τ_th,λ_a)。剩余热预算
R_i(t)=T_th,i-T_i-λ_a(t-τ_a)，ℓ_a 有效 iff R_i(t)≥0 且 duty_i≤duty_i^max。

**定义 60（可执行性证书 A_t）**
动作 a=(x*,F*,s)，s 为速度剖面。逆动力学得 τ_req(t)、q̇_req(t)。归一化裕度
μ_a = min_{i,t} { 1-|τ_req,i(t)|/(τ_i^maxκ_i(T_i)), 1-|q̇_req,i(t)|/(q̇_i^maxκ_i(T_i)) }。
执行误差上界
e_act = ||J(q)||·b_max/2 + ||J(q)K^{-1}J(q)^T||·||F*|| + e_model，
其中 b_max 为关节回差，K 为关节刚度，e_model 为未建模动力学残差。
A_t=(μ_a,e_act,ℓ_a)。**A_t 有效 iff μ_a≥0 且 ℓ_a 有效**；否则该动作不可执行。

**定义 61（成功事件、可校准成功率与失败分层）**
S_t = { ||x_T-x*||≤ε_s } ∧ { no-collision }。
U_t = 不可逆不安全事件（碰撞/失稳/损伤）。
样本空间三分：P(S)+P(abort)+P(U)=1（abort 为安全放弃）。
成功率估计 Ŝ_t = Cal(f(P_t,A_t,c_t))，要求在独立审计集 D_cal 上
|(1/n)Σ 1[S_i] - Ŝ_i| ≤ δ_cal 且 ECE ≤ δ_ece。
注意 P(S) 与 P(U) 不互补：中间是 abort，这正是双阈值与二值 fail-closed 的本质区别。

**定义 62（有效误差预算与边际成功增益）**
e_total = rad(P_t) ⊕ e_act(A_t) ⊕ e_ctrl，⊕ 取保守上界和。
Ŝ ≈ F_S(ε_s - e_total)，F_S 为误差分布 CDF。边际：
∂Ŝ/∂(-rad)=f_S(ε_s-e_total)，
∂Ŝ/∂μ_a=f_S(ε_s-e_total)·(-∂e_act/∂μ_a)，
故感知-驱动边际替代比 Γ=1/(∂e_act/∂μ_a)。
**预算规则**：若 e_act/rad(P_t)≫1，则 ∂Ŝ/∂(-rad) 被压缩，调度器应优先提升 μ_a（降额阶梯），而非增加感知模态；反之优先感知。

**定义 63（成功率-安全联合证书）**
J'_t=(P_t,A_t,ℓ_p,ℓ_e,ℓ_a,m_t,Ŝ_t)。**联合 soundness**：
(1) P(x_t∈P_t | ω_t,m_t,ℓ_e 有效)≥1-α_p；
(2) P(U_t | J'_t)≤ε_u；
(3) |Ŝ_t-P(S_t|·)|≤δ_cal；
(4) ℓ_e、ℓ_a 均有效。
**失败分层**：A_t 失效 → 输出 safe-abort（不作动/回撤），不得记为 unsafe；仅当 μ_a≥0 且证书有效仍发生 U_t 才计入安全违例。

**定义 64（驱动可行的成功率调度）**
π(a,m | c,ω,B,T)=argmax_{a∈A_feas,m∈M} E[Ŝ(a,m)]
s.t. P(U)≤ε_u, E(t)≥E_min, μ_a≥0, ℓ_a 有效。
可行动作由**降额阶梯**给出：
a^(0)=全速全载，a^(1)=速度×0.7，a^(2)=负载×0.7，a^(3)=重规划抓取/路径，a^(4)=safe-abort。
选满足 μ_a≥0 且 Ŝ≥θ_s 的最低降额档，避免过度降额损失成功机会。若无任何档位满足，则 safe-abort（而非 unsafe）。

## 2. 与既有框架的耦合升级

- **ECPS（IP-63）**：U(m)=E[ΔŜ(m)]/(P_m+c_a·ActCost(a))，加入驱动成本项；当 Γ 显示驱动主导时自动转向降额而非深度。
- **PSE（IP-60）**：rad(P_t) 与 e_act 汇总为 e_total，半径查表保留模态条件化。
- **DCL（IP-61）**：采集任务记录驱动上下文（负载、温度、回差、速度）与成功/abort/unsafe 标签，用于成功率校准。
- **CCA（IP-62）**：新增关节饱和、回差漂移、热降额曲线偏移、负载突变、末端柔顺参数漂移红队。
- **CAR（IP-51）**：守卫从 E≥E_min 扩展为 E≥E_min ∧ μ_a≥0 ∧ Ŝ≥θ_s ∧ P(U)≤ε_u，并显式输出 safe-abort。
- **MVR（IP-66）**：记忆键加入 (payload,T,backlash,speed)，仅在驱动上下文也接近时复用；历史 unsafe 记忆永久屏蔽，abort 记忆降权。
- **SAB（IP-68）**：绑定函数 B 增加 μ_a 惩罚项，不可执行指令直接进入安全队列而非执行。

## 3. 算法直觉（一个控制周期）

1. 读取 P_t、能量租约 ℓ_e、驱动租约 ℓ_a、当前负载与结温；
2. 对每个候选模态 m 与降额档 a^(r) 计算 A_t 与 e_total；
3. 用校准器给出 Ŝ 与 unsafe 风险上界；
4. 以 ΔŜ/成本 选 (m,a^*)；若驱动主导（Γ 小且 e_act/rad≫1），跳过开深度、优先降额；
5. 若 Ŝ<θ_s 或 P(U)>ε_u → safe-abort；若仅能量/驱动租约失效 → 级联失效并回退保守档。

## 4. 本轮最大风险

**一句话**：成功率校准器在重载/高温等稀有尾态上可能过度自信，给出偏高的 Ŝ 而实际 unsafe 风险同时上升，若此时又用“abort 不算失败”的语义把近失事件吸收掉，系统会用“看起来更高的成功率”掩盖驱动能力的真实退化；因此必须在独立驱动红队集上做尾部校准，对 μ_a 接近 0 的样本强制保守降额，并禁止在 ℓ_a 临界时复用记忆。

## 2. 关键算法伪代码

### IP-69 JAC
```
def joint_actuation_cert(q, dq, a, P_t, T, lease_a, model):
    q_traj = plan_cartesian(q, dq, a)              # 逆运动学 + 速度剖面
    tau_req, dq_req = inverse_dynamics(model, q_traj)
    kappa = clip((T_th - T) / (T_th - T_0), 0, 1)
    mu = INF
    for i, t in enumerate(horizon):
        mu = min(mu,
                 1 - abs(tau_req[i,t]) / (tau_max[i] * kappa[i]),
                 1 - abs(dq_req[i,t])  / (dq_max[i]  * kappa[i]))
    J = jacobian(q)
    e_act = norm(J) * b_max / 2 \
            + norm(J @ inv(K) @ J.T) * norm(a.F) \
            + e_model
    valid = (mu >= 0) and lease_a.valid(t + a.duration)
    return ActuationCert(mu, e_act, valid, tau_req)

def actuation_error_sensitivity(A):
    # ∂e_act/∂μ_a 的数值估计：μ_a 越小，柔顺/回差补偿越难
    return (A.e_act - A.e_act_at_full_margin) / max(A.mu, EPS)
```

### IP-70 SRC
```
def success_probability(P_t, A_t, c_t, cal):
    e_total = P_t.radius + A_t.e_act + e_ctrl
    z = (eps_s - e_total) / sigma_s(c_t)
    raw = cal.base_model(z, c_t)          # 逻辑回归 / 保序回归
    s_hat = cal.conformal_clip(raw)       # 保证覆盖率 δ_cal
    return s_hat

def unsafe_risk(A_t, c_t, cal_u):
    # 尾部单独建模，不与 success 互补
    return cal_u.tail_model(A_t.mu, A_t.e_act, c_t)

def calibrated_execute_gate(P_t, A_t, c_t, theta_s, eps_u):
    s_hat = success_probability(P_t, A_t, c_t, cal_s)
    u_hat = unsafe_risk(A_t, c_t, cal_u)
    if u_hat > eps_u:
        return 'safe-abort', 'unsafe-risk'
    if s_hat < theta_s:
        return 'safe-abort', 'low-success'
    return 'execute', s_hat
```

### IP-71 ASM（在 MVR 之上加驱动上下文）
```
def asm_lookup(v_t, c_t, B_t, T, payload, backlash, M):
    best, best_d = None, INF
    for rec in M:
        d = cosine_dist(encode(v_t), encode(rec.c)) \
            + lambda_b * max(0, B_t - rec.B) \
            + lambda_t * abs(T - rec.T) \
            + lambda_p * abs(payload - rec.payload) \
            + lambda_k * abs(backlash - rec.backlash)
        if rec.outcome == 'unsafe':
            continue                       # 永久屏蔽
        if rec.outcome == 'abort':
            d += lambda_abort               # 降权
        if d < best_d:
            best, best_d = rec, d
    return (best, best_d) if best_d < tau_hit else (None, best_d)
```

### IP-64/63 驱动可行的成功率调度（含降额阶梯）
```
def derating_ladder(a, P_t):
    return [a,
            a.with_speed(0.7),
            a.with_payload(0.7),
            replan_grasp(a, P_t),
            ABORT]

def actuation_aware_schedule(c_t, omega_t, B_t, T, P_t, v_t, M):
    best = None
    for m in M:
        if not energy_lease_valid(m, B_t):
            continue
        for r, a in enumerate(derating_ladder(plan(v_t, P_t), P_t)):
            if a is ABORT:
                continue
            A = joint_actuation_cert(..., a, P_t, T, lease_a, model)
            if not A.valid:
                continue
            s_hat = success_probability(P_t, A, c_t, cal_s)
            if unsafe_risk(A, c_t, cal_u) > eps_u:
                continue
            gain = s_hat - S_prev
            cost = P_m[m] + c_a * actuation_cost(a)
            U = gain / cost
            if best is None or U > best.U:
                best = Candidate(m, a, A, s_hat, U, r)
            if r > 0 and best and best.s_hat >= theta_s:
                break                      # 最低满足档，避免过度降额
    if best is None or best.s_hat < theta_s:
        return ABORT, 'no-feasible'
    return best.m, best.a, best.s_hat
```

### 全局决策 Π'（融合记忆/实时/安全队列）
```
def global_decision(c_t, omega_t, B_t, T, payload, v_t, M, Q_safe):
    if Q_safe and not empty(Q_safe):
        cmd = pop(Q_safe)
        m, a, s_hat = actuation_aware_schedule(..., cmd.v, ...)
        return m, a, 'execute_from_queue'

    mem, d = asm_lookup(v_t, c_t, B_t, T, payload, backlash, M)
    if mem is not None and lease_valid(mem.lease_e, mem.lease_a):
        P = pose_certify(mem)
        A = joint_actuation_cert(..., mem.a, P, T, lease_a, model)
        gate, why = calibrated_execute_gate(P, A, c_t, theta_s, eps_u)
        return mem.m, mem.a, gate if gate != 'execute' else 'memory'

    m, a, s_hat = actuation_aware_schedule(c_t, omega_t, B_t, T, P_t, v_t, M)
    if a is ABORT:
        return None, None, 'safe-abort'
    gate, why = calibrated_execute_gate(pose_certify(m, a), A, c_t, theta_s, eps_u)
    if gate != 'execute':
        push(Q_safe, (v_t, why))
        return m, a, 'queued'
    return m, a, 'realtime'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| JAC 可执行性证书 | O(nH) 逆动力学（n≤7，H 时间窗） | O(nH) | μ_a≥0 且 ℓ_a 有效 ⇒ 力矩/速度/热约束在窗内可满足 |
| SRC 成功率校准 | O(1) 在线；O(|D_cal|) 离线 | O(|D_cal|) | 覆盖率偏差≤δ_cal、ECE≤δ_ece ⇒ Ŝ 校准 |
| ASM 记忆检索 | O(|M|·d) | O(|M|·d) | 驱动上下文接近才复用；unsafe 记忆屏蔽 |
| 降额调度 | O(|M|·|D|·nH) | O(1) | 取最低可行档；无可行档 ⇒ safe-abort |
| 全局 Π' | O(|M|·|D|·nH) | O(|Q|) | 记忆/实时/队列三路均有 safe-abort 出口 |

**正确性定理（成功率-安全联合）**
设 J'_t=(P_t,A_t,ℓ_p,ℓ_e,ℓ_a,m_t,Ŝ_t) 有效，且 SRC 在审计集上满足校准界 δ_cal、unsafe 尾模型满足 P(U|·)≤ε_u。则：
(i) 若 μ_a≥0 且两租约有效，执行命令满足关节力矩/速度/热约束；
(ii) 任务失败被严格分层：μ_a<0 或 Ŝ<θ_s 的路径只产生 safe-abort，不进入 U_t；
(iii) 对任意被执行的命令，|Ŝ_t-P(S_t|·)|≤δ_cal 且 P(U_t|·)≤ε_u；
(iv) 姿态证书单独有效不是执行的充分条件——必须同时通过 A_t 与 success gate，故 v10/v23 的“感知有效即可执行”错误不会发生。
证明要点：由定义 59–60 的约束收紧得 (i)；由定义 64 的降额阶梯与 abort 出口得 (ii)；由定义 61 的校准与 ε_u 约束得 (iii)；(iv) 由 Π' 的顺序门控直接得到。

## 4. 实验设计 E115–E120

| 实验 | 指标 | 门槛 |
|---|---|---|
| E115 JAC 可执行性准确性 | μ_a 预测误差；false-feasible 率 | 误差≤10%；false-feasible≤1% |
| E116 成功率校准 | ECE；覆盖率偏差；abort/unsafe 分离度 | ECE≤0.03；覆盖率±2%；分离度≥0.9 |
| E117 感知-驱动边际分配 | 热降额下“开深度” vs “降额”的成功率/能耗 | 降额策略成功率≥开深度基线，能耗低≥15% |
| E118 safe-abort 与 unsafe 隔离 | unsafe 事件数；abort 率 | 100h 内 unsafe=0；abort≤3% |
| E119 负载/回差漂移鲁棒性 | 成功率退化；Γ 估计偏差 | 退化≤5%；Γ 偏差≤15% |
| E120 100h 感知-驱动闭环 | 任务成功率；记忆覆盖；级联失效次数 | 成功率≥92%；覆盖≥60%；级联失效=0 |

**回退策略**：E115 false-feasible>3% → 将 μ_a 安全边距整体收紧 20%，并在 μ_a<0.2 时禁止全速档；E116 ECE>0.05 → 关闭记忆复用并退回固定保守阈值 + 强制降额；E118 出现任一 unsafe → 禁用语音快速路径，所有高风险动作要求二次确认并强制 a^(1) 档；E117 显示驱动主导却被误判为感知主导 → 用 Γ 的保守下界做硬门控。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 成功率尾态过度自信（重载/高温） | 高 | 独立驱动红队集尾部校准；μ_a 接近 0 时强制保守降额 |
| abort 语义掩盖近失事件 | 高 | abort 单独记账并计入 DCL；近失样本强制回灌审计 |
| 热模型/回差参数随磨损漂移 | 高 | 在线辨识 κ(T) 与 b_max；E119 定期漂移检测 |
| 记忆复用跨驱动上下文误配 | 中 | ASM 键加负载/温度/回差/速度；unsafe 永久屏蔽 |
| 降额过度导致成功率下降 | 中 | 取最低满足档；θ_s 自适应但不低于任务下限 |
| 校准集与部署分布偏移 | 中 | 共形在线更新 + 覆盖率监控告警 |

## 6. 本轮最大风险

**一句话**：成功率校准器在重载/高温等稀有尾态上可能过度自信，给出偏高的 Ŝ 而实际 unsafe 风险同时上升，若再用“abort 不算失败”的语义吸收近失事件，系统就会用“看起来更高的成功率”掩盖关节驱动能力的真实退化；因此必须做尾部校准、对 μ_a 临界样本强制降额，并在 ℓ_a 临界时禁止记忆复用。
