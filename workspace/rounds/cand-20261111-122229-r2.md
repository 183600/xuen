# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「实时推理」×「传感器标定」）

> 第 54 轮把技能组合升级为动作空间剖面 + 组合图 + 云边协同 + 联合证书 `J`，但仍隐含一个静态假设：**标定参数 θ 与观测算子 h 不随时间变化，证书一经签发便永久有效**。本轮聚焦 **证书的时间维度**：实时推理的截止期与传感器标定的漂移共同使任何证书都具有"保质期"。核心矛盾：H22：证书在标定锚点 `t_C` 处成立，但实时推理消费的是越来越旧的观测，证书随 `t - t_C` 增大而**静默失效**；H23：为满足推理截止期而跳过的标定刷新会累积 **标定债务 β**，使第 54 轮的鲁棒性谱 ρ 与动作占用证书 `A_cert` 发生系统性偏移。

## 0. 直觉与动机

**灵感 1（标定不是一个参数，而是一条漂移轨迹）**
直觉：真实传感器的标定 θ 从来不是常量。温漂、机械磨损、结构振动、镜头污染让 `θ(t)` 缓慢游走。第 54 轮的证书都建立在"观测算子 `h(·;θ)` 正确"之上；一旦 θ 漂移，动作剖面 `α_S`、动作兼容性 `compat`、云边映射 `γ_ce` 全部随之偏移。于是证书不应是布尔值，而应是 **带时间戳 `t_C`、锚点 `θ̂_C`、有效期 `τ_val`、漂移率 `drift_C` 的时变谓词**：`C` 在 `[t_C, t_C+τ_val]` 内 sound，越过即 **过期（stale）**。这把"证书"从静态承诺变成会腐烂的承诺。

**灵感 2（实时推理 = anytime 证书）**
直觉：实时推理不可能等后验完全收敛，必须在截止期 D 前停机。Anytime 推理给出证书序列 `C(τ)`，质量 `q(τ)` 随已用算力 τ 单调上升；关键不是"最终解多好"，而是 **任意时刻停机，给出的证书只承诺当前 q(τ) 的保证且仍然 sound**。于是"实时"不再是外挂的工程约束，而是内嵌进证书语义：`C_τ` 的保证与 τ 绑定。这与第 54 轮的 `ρ` 相容——只是 `ρ` 现在有了一个"计算量-质量"的横轴。

**灵感 3（标定-推理联合调度与标定债务）**
直觉：一个截止期 D 内，时间既可用于推理也可用于标定刷新，二者零和竞争：多算推理 → 证书质量高但观测更陈旧；多刷标定 → 观测更准但推理更浅。若为赶 D 反复跳过刷新，就累积 **标定债务 β(t)**——一种与"技术债"同构的按时增长的负债。债务越大，标定漂移包络越宽、证书有效期 `τ_val` 越短。调度目标变为：在 `τ_I + τ_K ≤ D` 且 `β ≤ β_max` 下最大化有效证书质量。这把第 54 轮的组合规划扩展为 **时间预算下的证书质量优化**。

**灵感 4（时变组合：技能组合的有效期是交叠后的最小值）**
直觉：第 54 轮组合图的边 `compat(S_i,S_j)` 是静态 Jaccard。但两个技能的动作交叠区会随标定漂移移动，原本 0.9 的兼容可能在 5 秒后跌到 0.6。因此组合边必须附带 **时间证书** `(t_anchor, τ_val, drift)`，整个组合的有效期是 `min_i τ_val(S_i)` 再减去转换耗时之和。若执行时长超过组合有效期，必须在途中 **重锚（recalibrate）** 或切成更短的子组合；否则"组合前缀兼容、组合后段错位"。

**灵感 5（云边时间分层：云做新鲜标定+重推理，边做实时轻推理+降级）**
直觉：云端算力大、可做高保真标定与重推理，但回传延迟 `L_cloud` 高；边端必须在 D 内响应。于是第 54 轮的 `γ_ce` 升级为 **时间感知映射**：云端周期性下发新鲜标定锚点 `θ̂_cloud` 与重推理证书，边端用 anytime 轻推理 + 过期证书的**保守降级执行**（缩小 `A_core`、提高 ρ_min、退回安全动作）。云边契约新增 **时效证书 `D_cert`**，显式声明 D、边端有效期 `τ_val^e`、云端锚点延迟 `L_cloud`、降级策略 `Π_fallback` 与风险上界 `ε_D`。部署条件是"边端撑得到下一个云端锚点，或降级路径足够安全"。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（标定状态与漂移包络）**
标定状态 `θ(t) ∈ Θ`，满足漂移包络
```
||θ(t+Δ) - θ(t)|| ≤ δ_θ·Δ + σ_θ·√Δ
```
（`δ_θ` 为有界漂移率，`σ_θ√Δ` 为扩散/冲击项）。观测 `x_t = h(s; θ(t)) + ε_t`。最近锚点估计为 `θ̂(t)`，**标定残差** `r_cal(t) = ||θ(t) - θ̂(t)||`。观测可信域 `B_obs(t) = {x : ||x - h(s;θ̂)|| ≤ g(r_cal(t)) + ν}`，其中 `g(·)` 为标定残差到观测偏差的 Lipschitz 传播函数。

**定义 122（时变证书与有效期）**
证书 `C` 附带 `(t_C, θ̂_C, τ_val(C), drift_C, evidence)`。有效期
```
τ_val(C; t_C) = sup{ Δ ≥ 0 : risk(C | θ(t), ||θ(t)-θ̂_C|| ≤ δ_θ Δ + σ_θ√Δ) ≤ ε_C }
```
称 `C` 在时刻 t **有效** 当且仅当 `t ∈ [t_C, t_C + τ_val(C)]` 且 `r_cal(t) ≤ r_max`；否则 **过期（stale）**。**时变 soundness**：若 `t` 在有效期内，则 `C` 所承诺的保证成立。证书从 `(payload)` 升级为 `(payload, t_C, θ̂_C, τ_val, drift)`。

**定义 123（Anytime 推理证书）**
实时推理算法在已用时间 τ 输出 `C_τ`，质量函数 `q(τ)` 非减，`q(0)=q_min`，`q(D_max)=q_max`。**任意时刻 soundness**：
```
∀ τ ≤ D : Pr[fail | C_τ] ≤ 1 - q(τ)
```
截止期可行当且仅当 `∃ τ ≤ D, q(τ) ≥ q_req`。定义**证书质量剖面** `q_C(t) = q(τ_I(t)) · 1[t - t_C ≤ τ_val]`，把"算力"和"新鲜度"合成同一条质量曲线。

**定义 124（标定债务与联合调度）**
离散标定债务：跳过刷新时 `β ← min(β_max, β + α·Δt)`，刷新成功时 `β ← (1-η)·β`。联合调度 `π = (τ_I, τ_K)`，约束
```
τ_I + τ_K ≤ D，  β(t) ≤ β_max
```
目标 `max_π  q(τ_I) - λ·β(π) - μ·P(stale)`。有效漂移包络随债务放宽：`δ_θ(β) = δ_θ^0 (1 + κβ)`，即"欠的标定债越多，证书腐烂越快"。

**定义 125（时变技能组合）**
组合边证书扩展为
```
C_comp^time = (A_overlap, ρ_comp, γ_ce, t_anchor, τ_val_comp)
τ_val_comp = min_i τ_val(S_i) - Σ_{edges} c_trans
```
若任务执行时长 `T_exec > τ_val_comp`，则组合必须**中途重锚**：`reanchor(C_comp^time, t')` 或退化为更短子组合序列。组合可行性条件在定义 116 基础上增加 `T_exec ≤ τ_val_comp`。

**定义 126（云边时效契约 / Deadline Certificate）**
```
D_cert = (D, τ_val^e, L_cloud, Π_fallback, ε_D)
```
- `D`：边端实时推理截止期；
- `τ_val^e`：边端当前证书有效期；
- `L_cloud`：云端新鲜标定锚点/重推理证书的到达延迟上界；
- `Π_fallback`：过期时的保守降级策略（收缩 `A_core`、抬高 `ρ_min`、退回安全动作）；
- `ε_D`：允许的时效失效风险上界。

**部署条件**：`τ_val^e ≥ D - L_cloud`（边端能撑到下一个云端锚点），或 `risk(Π_fallback) ≤ ε_D`（降级足够安全）。

## 2. 关键算法 伪代码

### IP-121 CST（Calibration State Tracking）

```python
def update_calibration(theta_hat, t_prev, t_now, anchors, delta_theta, sigma_theta):
    dt = t_now - t_prev
    # 先按漂移包络膨胀不确定度，再用新锚点收缩
    r = theta_hat.radius + delta_theta*dt + sigma_theta*math.sqrt(dt)
    for a in anchors:
        if a.timestamp > t_prev:
            theta_hat = kalman_update(theta_hat, a, r)
            r = theta_hat.radius
    return CalState(theta_hat, t_now, r)

def drift_residual(cs, theta_true):
    return norm(cs.theta_hat.mu - theta_true)   # 用于在线校准包络
```

### IP-122 TTL（Temporal Certificate Lifecycle）

```python
def validity_horizon(cert, risk_fn, eps, delta_theta, sigma_theta, dt_grid):
    for dt in dt_grid:                      # 由细到粗扫描
        bound = delta_theta*dt + sigma_theta*math.sqrt(dt)
        if risk_fn(cert, bound) > eps:
            return dt                        # 首个越界点即有效期上界
    return max(dt_grid)

def check_certificate(cert, t_now, r_cal, r_max):
    if t_now - cert.t_C > cert.tau_val:
        return ('stale', 'ttl_exhausted')
    if r_cal > r_max:
        return ('stale', 'calibration_residual')
    return ('valid', cert.payload)
```

### IP-123 AIC（Anytime Inference Certificate）

```python
def anytime_infer(observations, deadline, q_req, cert_builder):
    t0 = now()
    cert = cert_builder(observations)       # q_min 的保守证书
    while True:
        tau = now() - t0
        if tau >= deadline:
            break
        if cert.q >= q_req and tau >= cert.tau_needed:
            break                            # 达到要求即可提前停机
        cert = refine(cert, observations)    # 每步提升 q(tau)，保持 sound
    return cert                              # 承诺与已用算力一致的保证
```

### IP-124 CIS（Calibration-Inference Scheduler）

```python
def schedule_within_deadline(D, beta, q_curve, cal_gain, lam, mu, kappa):
    best = None
    for tau_K in time_slices(D):             # 标定预算
        tau_I = D - tau_K
        beta_next = max(0.0, beta - cal_gain(tau_K))
        delta_eff = delta_theta0 * (1 + kappa*beta_next)
        q = q_curve(tau_I)
        p_stale = stale_probability(tau_I, delta_eff, tau_K)
        score = q - lam*beta_next - mu*p_stale
        if score > best.score:
            best = Schedule(tau_I, tau_K, beta_next, q, p_stale)
    return best
```

### IP-125 TSC（Time-aware Skill Composition）

```python
def time_aware_plan(G, task, D, mach_exec):
    path = a_star(G, start='root', goal=task, heuristic=cost_align_time)
    t_anchor = now()
    tau_val = min(node.tau_val for node in path)
    for (u, v) in path_edges(path):
        tau_val -= u.c_trans
    if tau_val <= 0:
        return ('reject', 'composition_expires_before_start')
    if mach_exec(path) <= tau_val:
        return ('ok', path, tau_val)
    # 执行中途必然过期：插入重锚点或切短子组合
    return ('needs_reanchor', plan_reanchor_points(path, tau_val))
```

### IP-126 DCC（Deadline Cloud-Edge Contract）

```python
def deadline_contract(D, ttl_edge, L_cloud, fallback, eps_D):
    if ttl_edge >= D - L_cloud:
        return ('ok', CertPolicy('hold', D, ttl_edge, L_cloud))
    if risk(fallback) <= eps_D:
        return ('ok', CertPolicy('fallback', D, ttl_edge, L_cloud, fallback))
    exp = Explain('deadline_uncoverable', {'D':D,'ttl':ttl_edge,'L':L_cloud})
    return ('reject', exp)                   # 请求云端缩短 L 或边端加密标定
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CST | O(|anchors|·|Θ|) | O(|Θ|) | 漂移包络保守、锚点更新单调收缩 |
| TTL | O(|dt_grid|·|𝔇_ρ|) | O(|𝔇_ρ|) | risk 关于 Δ 单调，首越界即上界 |
| AIC | O(τ_max/Δτ·|π|) | O(|C|) | 每步 refine 保持 anytime sound |
| CIS | O(D/Δτ·|𝔇|) | O(1) | 目标函数对 τ_K 单峰（拟凹假设） |
| TSC | O(|V| log|V| + |E|) | O(|V|+|E|) | τ_val 沿路径单调不增 |
| DCC | O(1) | O(1) | 时效覆盖条件可判定 |

**正确性定理（Temporal Soundness of Real-time Composition）**
假设第 54 轮 (A22)–(A28) 成立；新增：
**(A29)** 真实漂移满足定义 121 包络且 `δ_θ(β)` 对 β 单调不减；
**(A30)** anytime 质量函数 `q(τ)` 关于 τ 非减，且每个停机点 `C_τ` 满足 anytime soundness；
**(A31)** 组合有效期按 `min(τ_val) - Σ c_trans` 计算，重锚延迟可忽略或计入预算；
**(A32)** 降级策略 `Π_fallback` 的失效概率可上界 `ε_fallback`。

则对任意 `t ∈ [t_C, t_C + τ_val_comp]`，部署成功概率满足
```
P_success(t) ≥ 1 - Σ_d (1 - ρ_min(d)) - β_E - P(δ_a > Θ_a) - P(compat < θ_a)
                 - (1 - q(τ_I)) - P(stale | t) - P(deadline_miss)
```
其中 `P(stale|t)` 由 `t - t_C > τ_val` 或 `r_cal > r_max` 触发；若 `D_cert` 走 fallback 分支，则用 `ε_fallback` 替换 `P(deadline_miss)`。**核心**：证书的每个保证都带上"在什么时刻之前、用多少算力换来的"两个前缀，静态 soundness 成为时变 soundness 的边界情形（`τ_val=∞, τ_I=∞`）。

## 4. 实验设计 E162–E166

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 标定漂移估计 | `r_cal(t)` 与真实漂移的 MAE / 包络覆盖率 | MAE ≤ 0.02，包络覆盖率 ≥ 98% |
| E163 过期检测 | stale 检测 precision / recall / 提前量 | F1 ≥ 0.92，平均提前 ≥ 1.5s |
| E164 anytime 质量剖面 | `q(τ)` 曲线与停机质量 vs 截止期 | 任意 τ 处 soundness 违约率 ≤ 1% |
| E165 联合调度收益 | 固定对半分配 vs CIS 的证书质量 | 质量提升 ≥ 10%，债务 ≤ β_max |
| E166 时效契约部署 | D_cert vs 静态证书的部署成功率 | 提升 ≥ 15%，fallback 触发可解释 |

**消融**：去掉 TTL（证书永久有效）应出现"过期证书被当有效执行"的系统性失败；去掉 anytime（固定算力）应在紧截止期显著掉成功率；去掉 CIS（固定时间分配）应显现高债务下的有效期塌缩。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 漂移包络被非平稳冲击击穿 | 高 | 在线残差监测 + 保守包络膨胀 + 硬性 TTL 熔断 |
| anytime 质量曲线离线拟合失真 | 高 | 在线自校准 q(τ) + 分位数保证替代均值估计 |
| 标定债务与有效期耦合被低估 | 高 | 将 β 纳入证书字段 + 债务上限硬约束 |
| 频繁重锚导致任务抖动 | 中 | 重锚点预规划 + hysteresis + 子组合缓存 |
| 云边时效契约时钟不同步 | 中 | 逻辑时钟/单调时钟 + 锚点版本号 + 安全降级 |
| 降级策略本身不安全 | 高 | fallback 证书独立验证 + 影子执行比对 |

## 6. 本轮最大风险

**一句话**：时变证书把"证书会腐烂"和"实时只能给 anytime 保证"这两件事显式化，理论上让第 54 轮的双证书首次具备时间语义，但其 soundness 完全依赖**漂移包络 `δ_θ(Δ)` 与 anytime 质量曲线 `q(τ)` 的离线拟合准确**；真实世界的非平稳冲击（温变、碰撞、镜头污染）会瞬时突破包络，使 `τ_val` 被系统性高估，边端把本应过期的证书当作有效继续执行，制造"证书还有效"的时效性假象并放大负迁移——因此必须以 **在线漂移残差监测 + 保守包络膨胀 + 硬性 TTL 熔断 + fallback 影子验证** 四重护栏，宁可提前降级，绝不把"新鲜度假设"当作部署前提。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（CST×TTL×AIC×CIS×TSC×DCC）

> 承接第 54 轮产物 v31。本轮在动作-鲁棒性双证书体系之上，增加 **证书的时间维度** 六大算子：
> - **CST（Calibration State Tracking）**：把标定建模为带漂移包络的时变状态 `θ(t)`；
> - **TTL（Temporal Certificate Lifecycle）**：给证书附 `(t_C, θ̂_C, τ_val, drift)`，显式过期；
> - **AIC（Anytime Inference Certificate）**：任意时刻停机仍 sound 的实时推理证书；
> - **CIS（Calibration-Inference Scheduler）**：截止期 D 内标定与推理的时间预算分配 + 标定债务 β；
> - **TSC（Time-aware Skill Composition）**：组合边带时效，组合有效期 = `min τ_val - Σ c_trans`；
> - **DCC（Deadline Cloud-Edge Contract）**：云边时效契约 `D_cert` 与保守降级。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/117/118/120 以纳入时间维度。

```python
def update_calibration(theta_hat, t_prev, t_now, anchors, delta_theta, sigma_theta):
```

### IP-122 TTL

```python
def validity_horizon(cert, risk_fn, eps, delta_theta, sigma_theta, dt_grid):
    for dt in dt_grid:
        bound = delta_theta*dt + sigma_theta*math.sqrt(dt)
        if risk_fn(cert, bound) > eps:
            return dt
    return max(dt_grid)

def check_certificate(cert, t_now, r_cal, r_max):
```

### IP-123 AIC

```python
def anytime_infer(observations, deadline, q_req, cert_builder):
    t0 = now()
    cert = cert_builder(observations)
    while True:
        tau = now() - t0
        if tau >= deadline or (cert.q >= q_req and tau >= cert.tau_needed):
            break
        cert = refine(cert, observations)
    return cert
```

### IP-124 CIS

```python
def schedule_within_deadline(D, beta, q_curve, cal_gain, lam, mu, kappa):
    best = None
    for tau_K in time_slices(D):
        tau_I = D - tau_K
        beta_next = max(0.0, beta - cal_gain(tau_K))
        delta_eff = delta_theta0 * (1 + kappa*beta_next)
        q = q_curve(tau_I)
        p_stale = stale_probability(tau_I, delta_eff, tau_K)
        score = q - lam*beta_next - mu*p_stale
        if score > best.score:
            best = Schedule(tau_I, tau_K, beta_next, q, p_stale)
    return best
```

### IP-125 TSC

```python
def time_aware_plan(G, task, D, mach_exec):
    path = a_star(G, start='root', goal=task, heuristic=cost_align_time)
    tau_val = min(node.tau_val for node in path)
    for (u, v) in path_edges(path):
        tau_val -= u.c_trans
    if tau_val <= 0:
        return ('reject', 'composition_expires_before_start')
    if mach_exec(path) <= tau_val:
        return ('ok', path, tau_val)
    return ('needs_reanchor', plan_reanchor_points(path, tau_val))
```

### IP-126 DCC

```python
def deadline_contract(D, ttl_edge, L_cloud, fallback, eps_D):
    if ttl_edge >= D - L_cloud:
        return ('ok', CertPolicy('hold', D, ttl_edge, L_cloud))
    if risk(fallback) <= eps_D:
        return ('ok', CertPolicy('fallback', D, ttl_edge, L_cloud, fallback))
    exp = Explain('deadline_uncoverable', {'D':D,'ttl':ttl_edge,'L':L_cloud})
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CST | O(|anchors|·|Θ| + |Θ|) | O(|Θ|) | 漂移包络保守，锚点更新单调收缩 |
| TTL | O(|dt_grid|·|𝔇_ρ|) | O(|𝔇_ρ|) | risk 关于 Δ 单调，首越界即上界 |
| AIC | O((τ_max/Δτ)·|π|) | O(|C|) | 每步 refine 保持 anytime sound |
| CIS | O((D/Δτ)·|𝔇|) | O(1) | 目标拟凹，网格最优逼近 |
| TSC | O(|V| log|V| + |E|) | O(|V|+|E|) | τ_val 沿路径单调不增 |
| DCC | O(1) | O(1) | 时效覆盖条件可判定 |

**正确性定理（Temporal Soundness of Real-time Composition）**
假设第 54 轮 (A22)–(A28) 成立；新增：
**(A29)** 真实漂移满足定义 121 包络且 `δ_θ(β)` 对 β 单调不减；
**(A30)** `q(τ)` 非减，每个停机点 `C_τ` 满足 anytime soundness；
**(A31)** 组合有效期按 `min(τ_val) - Σ c_trans` 计算，重锚延迟计入预算；
**(A32)** fallback 失效概率上界 `ε_fallback`。

则对任意 `t ∈ [t_C, t_C + τ_val_comp]`：
```
P_success(t) ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a) - P(compat<θ_a)
                 - (1-q(τ_I)) - P(stale|t) - P(deadline_miss)
```
走 fallback 分支时以 `ε_fallback` 替换 `P(deadline_miss)`。静态证书是 `τ_val=∞, τ_I=∞` 的退化特例，因此 v31 的所有结论被 v32 包含而非推翻。

## 5. 本轮最大风险

**一句话**：时变证书把"证书会腐烂"和"实时只能给 anytime 保证"显式化，理论上让第 54 轮的双证书首次具备时间语义，但其 soundness 完全依赖**漂移包络 `δ_θ(Δ)` 与 anytime 质量曲线 `q(τ)` 的离线拟合准确**；真实世界的非平稳冲击（温变、碰撞、镜头污染）会瞬时突破包络，使 `τ_val` 被系统性高估，边端把本应过期的证书当作有效继续执行，制造"证书还有效"的时效性假象并放大负迁移——因此必须以 **在线漂移残差监测 + 保守包络膨胀 + 硬性 TTL 熔断 + fallback 影子验证** 四重护栏，宁可提前降级，绝不把"新鲜度假设"当作部署前提。
