# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配主动消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「避障控制」×「快速原型」）

> R69 把「不确定性」拆成 aleatoric 与 epistemic，用「看/问/触」去消解后者，并给出一条漂亮的安全姿态：新层必须是旧层的严格退化。但它默认了一件极其关键的事——**安全约束本身是已知的**。它消解的是「我该选哪个动作」（参数/模态歧义），而不是「什么才算一次违规、这个从没见过的东西属于哪类物理对象」（模型形式 / 规约歧义）。真实避障恰恰死在后者：训练分布里没有的障碍、看不出材质的物体、会让路也可能突然扑过来的人。
>
> 本轮两个灵感正好对准这个缺口：
> - **避障控制**提醒我们，安全性从来不是「选对动作」的函数，而是「对安全集/规约的正确刻画」的函数；未知障碍首先污染的是**安全集**，不是动作分布。
> - **快速原型**给出人类对付「没有模型」的标准动作：先做一个便宜、粗糙、随时可扔的原型，在安全沙盒里试，试对了再上，试错了就扔——**原型的作用不是替代证明，而是让你在拥有证明之前先获得信息**。
>
> 核心命题：**当不确定性从「参数」升级为「模型形式/规约」时，采样固定策略无法消解它；必须现场合成（prototype）一个候选模型/约束，在孪生沙盒里相对比较（test），再通过一个可证明保守的安全内核（verified Safe Kernel）的一步可恢复性过滤后有限授权（promote），并在证据失效时自动退役（retire）。** 命名 **SKETCH-RAS**（Safe-Kernel-Escorted Twin-Checked Handoff；sketch 兼指「草图原型」与「画给人类看的失败草图」）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这个我从没见过的东西，按什么规则才算安全？我能不能先画个草图给你看**」——原型不是要交付的答案，而是一个可测试、可展示、可随时作废的问题。

## 0. 直觉与动机

**灵感 1（避障控制 → 未知障碍首先污染的是安全集，而不是动作分布）**
直觉：R69 面对岔路会「先停下看清」。但如果路上倒着一架没见过的梯子、一只可能咬人的狗、一个软塌塌的纸箱，问题不是「绕左还是绕右」这种动作层面的多峰，而是**我根本不知道把它的哪部分当作不可穿越、把多大的接触力当作碰撞、它会不会动**。也就是说，被未知污染的是**安全集 S 与违规谓词 Violate(·)** 本身。在错误的安全集上做再精确的动作优化，只是高效地驶向错误。避障控制的正统答案（CBF / 可达性 / 速度障碍）都以「障碍模型已知」为前提；一旦模型形式未知，这些方法连求解器都写不出来。

**灵感 2（快速原型 → 在拥有证明之前，先用原型换取信息）**
直觉：人类遇到没见过的障碍不会原地推导偏微分方程，而是**先做个粗糙原型**：伸脚试探、用手比划、拿根棍子戳一下，或者干脆「我演示给你看我要怎么过」。原型的关键不是正确，而是**便宜、可弃、可测试**。这把 R69 的「信息动作」再推进一步：R69 的信息动作是在**已有模型内**选一个观测去降低后验熵；R70 的信息动作是**造一个模型出来**，它在被证明之前只能待在沙盒里。于是「快速原型」不是工程上的偷懒，而是一种**认识论策略**：先造一个可能错的东西，让错误尽早、便宜、安全地暴露。

**灵感 3（二分升级 → 参数不确定性 vs 模型形式不确定性）**
直觉：R69 的 U_epi = H_mode·g(Δ_min) 度量的是「在固定模型类内，我该选哪个模态」。但「这团东西是刚体、可推动、可压缩、还是活的」不是同一个模型类里的几个参数，而是**几个不同的物理模型**。对固定策略再怎么采样，也采不出一个它从未表示的模型形式——这是 **model-form / structural uncertainty**，只能靠**合成新假设 + 测试**来降低，不能靠**采样旧假设**来降低。这是本轮必须新开一层的形式化理由：R69 的后验更新是把质量在既有模态间重新分配；R70 的原型是**往假设空间里新增一个模态**。

**灵感 4（对偶 → 控制器 vs 规约：真正致命的是画错的失败判据）**
直觉：绝大多数「快速原型」都在原型**控制器**（怎么绕）。但避障真正会死人的地方是**规约**：什么算碰撞？擦到灌木算不算？人后退一步算不算「已避让」？把一个可压缩纸箱当成实心墙会不会造成不必要的死锁？因此本轮把原型对象一分为二：**行为原型**（候选控制器）与**规约原型**（候选失败谓词/安全集）。并且给出一个反直觉但重要的操作：**把规约原型直接画给人类看**——在孪生里渲染一段「我打算这样过」的慢放幽灵轨迹，让人类只做一个极低带宽的判断（同意/否决/指一下该改哪），而不是回答「这是什么材质」这种高维、易撒谎、易幻觉的问题。**原型即问题（Prototype-as-Question）**：以示代问，用一段可证伪的草图替代一句抽象的提问。

**灵感 5（安全姿态 → 绝不让原型拥有安全授权）**
直觉：快速原型最大的诱惑是「twin 里跑通了就上」。这等于把安全性押在孪生与真实的一致性上，而孪生恰恰是最容易过拟合、最容易和真实共享盲区的东西。本轮采用 Simplex / runtime-assurance 的姿态：真实系统里永远有一个**已被验证的、极度保守的 Safe Kernel**（把一切未知都当硬障碍、必要时停），原型只能在**一步可恢复集**内取得授权，且任何时刻最多一个控制器掌权（单授权不变式）。孪生测试只用于**选择**（selection），安全内核的可恢复性过滤才用于**认证**（certification）。这条分工是本轮的核心：**测试只决定「值不值得试」，内核才决定「能不能做」**。于是原型再错，最坏只是慢；不可能不安全。代价也很诚实：**安全不等于活性**——见本轮最大风险。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（SKETCH-RAS 总览与三不变式）** SKETCH-RAS = (OCD, SPP, PAP, TTT, SKS, PRQ, PLR, PCO, DCD, RAS-WM††)。三不变式：
(i) **实时流零学习写**（继承定义 276-i）；原型合成只写隔离的、带版本的 *prototype buffer*，绝不写已验证基线或部署权重；
(ii) **单授权不变式**：任意时刻恰有一个控制器掌权——要么 Safe Kernel，要么被内核护送的已提升原型；禁止混合（禁止「两个半对的政策」相加）；
(iii) **爆炸半径有界**：原型可以错，但其授权被 Safe Kernel 的一步可恢复集界定；越界动作被否决，内核在 Δt_handoff 内重新掌权。

**定义 311（障碍响应类与类条件模型）** κ ∈ 𝒦 = {刚性静止, 被动可动, 可变形, 主动体, 脆弱/未知}。每类诱导一个接触/响应模型 F_κ 与一族允许的障碍函数 ℬ_κ（刚性→硬约束 CBF；可动→含动量传递；可变形→力限接触 CBF；主动体→责任敏感/博弈式；脆弱→最大裕度且禁触）。真实类 κ* 潜藏。

**定义 312（结构不确定性）** 记 U_struct = H(κ | o)（模型类的后验熵），与 R69 的 U_epi = H(M|o)（类内模态熵）区分。关键性质：**对固定策略 π_θ 采样不改变 U_struct**，因为 κ 的支撑不在 π_θ 的参数化里；降低 U_struct 的唯一途径是「合成新假设（原型）」或「获取关于 κ 的观测（探测/人类判断）」。

**定义 313（屏蔽式物理探测 SPP）** 探测 g_probe 施加受控扰动并观测响应 y（接触后位移、形变、反作用），仅在 Safe Kernel 执行且保留可恢复性的**中止包络**内允许。探测选择 g* = argmax_g I(κ; y | g) − c(g)，s.t. risk(g) ≤ ε_probe、预算未超。**关键：探针由内核代执行，原型不得亲手去碰**——你只能在安全之内学习未知。

**定义 314（原型 PAP）** 给定类假设 κ 与局部地图，合成候选避障器 π̂_κ（类条件 CBF-QP 或短视域 MPC），过程**随时可中断（anytime）**、≤ N_iter / T_synth，返回「当前最好」而非收敛解。原型是 sketch 质量：允许错，准入门槛是测试，不是正确性。

**定义 315（孪生集合与鲁棒测试锦标赛 TTT）** 孪生集合 𝒯 = {T_1..T_m}，显式包含 held-out 与对抗扰动孪生。候选（含 Safe Kernel 作对照）在 𝒯 上滚动 H 步。选择按**最坏孪生**排序：π̂* = argmax_{π̂} min_{T∈𝒯} score(π̂,T)，且仅在「相对 Safe Kernel 的进度增益 > δ 且最坏碰撞风险不增」时入选。**TTT 只产出选择，不产出安全证明。**

**定义 316（Safe Kernel 与一步可恢复集）** π_K 为在不变安全集 S_K 上已验证的保守控制器（一切已感知占据与未知均视为硬障碍、速度有界）。定义一步可恢复集 ℛ(s) = { s' : 从 s' 出发，π_K 在最坏允许扰动下仍可把系统保持在 S_K }。ℛ 由**内核的 sound 过近似模型**计算，与被测原型的模型无关。

**定义 317（可恢复性过滤 / 授权门槛）** 原型在 s 处取得授权的充要条件：s' = Pred_sound(s, u_proto) ∈ ℛ(s)，其中 Pred_sound 用内核的 sound 模型。任何未经此过滤的原型动作不得执行。

**定义 318（Simplex 切换与单授权握手）** 授权在 Kernel 与原型间切换须满足：类后验足够自信（或原型对 κ 后验鲁棒）、TTT 以裕度胜出、定义 317 过滤通过；违例/超时/退役时在 Δt_handoff ≤ 一个控制周期内切回，并做**无扰切换**（保持 R68/R69 的控制连续性不变式）。

**定义 319（新颖性门控）** 廉价 novelty_head(o) 判断障碍是否落在已知类/已知库内；绝大多数障碍是已知的（此时 SKETCH 逐指令退化为 FLUID）。只有门控开启才进入原型路径，保证常态开销不变。

**定义 320（原型即问题 PRQ）** 当物理探测不可行（脆弱/主动/人类）或人类在环时，把候选原型在孪生中渲染为一段 H 步的**反事实幽灵回放**（可 AR 叠加/慢放），向人类索取最低带宽判断：同意 / 否决 / 指一下应改之处。答案并入假设分布，遵守 R69 定义 293-iii 的证据纪律（单次判断不单独定案）。**收益**：一问的比特数由「行为差异」承载，远高于「请描述其材质」，且不诱导、可证伪。

**定义 321（原型生命周期与临时证书）** 每个被提升原型携带 J_PROTO = (κ 假设, 证据集, TTT 统计, 可恢复裕度, 到期时间, 监控谓词, 库来源)。生命周期：probe → prototype → test → **promote（有限授权）** → **retire（证据失效即退役）**。退役后归档（物理可弃，认知不可弃），供审计与检索。

**定义 322（类一致性监控 / 原型腐化检测）** 在假设 F_κ 下计算响应残差 r_κ = ‖y_obs − F_κ(u_probe)‖，用 CUSUM/GLR 检测分布漂移；触发即退役。这是 R69 FMA 的「对象侧」镜像：FMA 测行为是否自洽，这里测**对象是否还是假设的那个对象**。

**定义 323（原型库检索 PLR）** 用类别/几何/响应特征做相似检索，命中则「检索 + 微调」，miss 则从头合成——把「快速」落实为**摊销**（T_retrieval+T_adapt ≪ T_synth）。库只提供**提议**，绝不提供授权；检索式原型必须额外过对抗孪生，以防**库同质化**（见引理 21）。

**定义 324（未解结构的保守闭包与死锁检测）** κ 后验不可分且无探测/无人可问时，采用**类别的并集障碍 / 最大保守类（脆弱/未知）**，即 robust closure；若连该闭包都无可行动作（ℛ(s)=∅ 或所有候选被否），DCD 报**死锁**并升级（请求人类/请求让行/最小风险停车），绝不假装有解。

**定义 325（证书 J_SKETCH）** J_SKETCH = (J_FLUID, κ 后验与校准 ECE_κ, prototype_id/hash, TTT 最坏分, 可恢复裕度 ρ_rec, 生命周期状态, PLR 溯源, 死锁标志)。Valid ⇔ Valid(J_FLUID) ∧ 内核未失效 ∧ 监控未触发 ∧ 单授权不变式成立。

**定义 326（离线毕业）** 某原型在足够多真实遭遇中被验证通过后，可由**离线**认证流程「毕业」为正式安全层组件；实时流永不写入，库是二者之间的桥。这使「快速原型」与「慢速认证」在同一系统里共存：现场造得快，上线取得慢。

```python
# IP-266 PAP：anytime 原型合成（类条件 CBF-QP；随时可截断，返回 best-so-far）
def synthesize(kappa, local_map, u_nom, budget):
    h  = fit_barrier_family(kappa, local_map)     # 从 B_kappa 中选一族
    pi = CBFQP(h, u_nom)                          # min ||u-u_nom||^2 s.t. CBF
    for _ in range(budget.iter):                  # 每步都可被 deadline 打断
        h  = refine(h, kappa)                     # 用已有探测/感知证据
        pi = CBFQP(h, u_nom)                      # 单调 best-so-far
    return pi                                     # sketch 质量：未授权！

# IP-267 TTT：鲁棒孪生锦标赛（只做选择，不做证明）
def tournament(cands, twins, kernel, H):
    best = None
    for pi in cands + [kernel]:
        scores = [rollout(pi, T, H) for T in twins]        # 含对抗/held-out
        worst  = min(scores, key=lambda s: s.safety_margin)
        if dominates(pi, kernel, scores) and margin_ok(worst):
            best = better(best, pi, worst)                 # 以最坏情形排序
    return best                                            # None => 无候选

# IP-268 SKS：唯一的安全授权（硬实时关键路径）
def simplex_step(s, proto, kernel, kernel_model):
    u_k = kernel(s)
    if proto is None: return u_k, "KERNEL"
    u_p = proto(s)
    s_next = sound_predict(s, u_p, kernel_model)           # 内核的 sound 过近似
    if s_next in recoverable_set(s, kernel) and monitor_ok():
        return u_p, "PROTOTYPE"                            # 内核下一步仍可兜底
    return u_k, "KERNEL"                                   # 否决，内核立即掌权

# IP-269 PRQ：把原型变成问题（以示代问）
def prototype_as_question(proto, twin, human):
    ghost   = twin.rollout(proto, H=1.0)                   # 反事实幽灵回放
    verdict = human.judge(ghost, opts=["ok", "veto", "point"])
    return adapt_or_retire(proto, verdict)                 # 单次不单独定案

# IP-275 主闭环（安全在关键路径，原型在旁路）
def SKETCH_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    kappa, conf = M.ocd.infer(o)
    if not M.novelty.gate(kappa, conf):                    # 已知障碍
        return M.fluid_round(...)                          # 逐指令退化为 FLUID/R68
    # 1) 最便宜的信息优先：能在安全内探测就探测
    if M.spp.affordable(kappa) and not M.spp.risky(kappa):
        kappa = M.ocd.update(kappa, M.spp.probe(kappa, shield=M.sks.kernel))
    # 2) 库检索摊销 or 从头 anytime 合成（旁路线程，硬 deadline）
    base  = M.plr.retrieve(kappa) or M.pap.synthesize(kappa, o, M.budget)
    cands = M.pap.variants(base, kappa)
    # 3) 孪生锦标赛：选择，不是证明
    proto = M.ttt.tournament(cands, M.twin, M.sks.kernel, H=M.H)
    if proto is None:                                      # 无可信候选
        if M.prq.human_available():
            proto = M.prq.ask(base or M.sks.kernel, M.twin, M.human)
        else:                                              # 保守闭包 / 死锁升级
            return M.dcd.conservative_closure(o, M.sks.kernel)
    # 4) 唯一的授权点：一步可恢复性过滤（安全性只在这里被签发）
    u, src = M.sks.simplex_step(o, proto, M.sks.kernel, M.kernel_model)
    # 5) 生命周期：腐化监控 → 退役；参与式审计；证书
    M.pco.update(proto, o, M.dcd.consistency_residual())
    M.vqa_p.submit_async(kappa, proto, src, M.pco.state)
    return u, src, M.pco.cert()
```

## 3. 推导

**引理 19（屏蔽探测的可识别性与其失效边界）** 设 κ 先验 p，响应分布类间分离 Δ_resp、类内噪声 σ_resp。屏蔽探测把探测动作限制在保留可恢复性的子集内（定义 313），故其**风险 ≤ ε_probe 由构造保证**；但其**信息增益**只在 Δ_resp ≳ σ_resp 时为正。推论：对脆弱/主动类，因允许接触力→0，Δ_resp→0，物理探测的可识别性→0——**此时探测不是危险就是无用，必须改用 PRQ（以示代问）或不接触观察**。这解释了定义 313→320 的模态阶梯：信息获取的模态由「该类允许的接触强度」决定，而不是由「我想知道多少」决定。

**引理 20（原型债：孪生误差只进效率通道，不进安全通道）** 设孪生集合 𝒯 与真实响应过程在测试视域内的失配为 ε_twin。则 TTT 选出的原型相对真实最优的**性能遗憾**为 O(ε_twin·H·L)（L 为 Lipschitz 常数），但其在真实系统里造成的**安全违规 = 0**，只要：(a) 定义 317 的可恢复性过滤使用内核的 sound 过近似；(b) 握手机制满足 Δt_handoff ≤ 一个控制周期。证明要点：授权只依赖 sound 模型与 ℛ，与原型自身模型和孪生误差无关；孪生误差只能让「选择」变差，不能伪造「可恢复性」。**这是定理 18 的量化补充，也是本轮「测试 selects / 内核 certifies」分工的形式化。**

**引理 21（库检索的摊销收益与同质化污染）** 库规模 n、相似阈值 τ 下，命中率随 n 上升，命中时合成成本由 T_synth 降为 T_retr+T_adapt；但若孪生与被检索案例共享盲区，**误命中**（相似度假阳）可同时骗过 TTT，使全库在同类盲区上**同质化失败**（「一个 bug 复制 n 份」）。因此检索式原型必须：(i) 额外过对抗/held-out 孪生；(ii) 保留溯源多样性（禁止单一案例支配）；(iii) 在 J_PROTO 中记录库来源，便于审计回溯。

**命题 1（活性不可保证）** 定理 18 只保证安全，不保证前进。当 ℛ(s)=∅ 或所有候选被否决、且无人类/无让行时，系统可被证明安全地**永远停住**。故在未知/对抗障碍下，「安全」与「活性」可能互斥；活性必须由原型/PRQ/让行**购买**，不存在无条件的活性保证。把这一点写进定理而不是藏起来，是本轮对 R69「问错比不问更危险」的对称诚实（这里是「只保安全会变成只保不动」）。

**定理 18（条件安全：安全性独立于原型正确性）** 在 A101（π_K 在 S_K 上验证；sound 过近似；Δt_handoff ≤ 一个控制周期）下，对**任意**原型序列（含对抗错误、幻觉类、被投毒的孪生、腐化后未及时退役），闭环状态始终留在 S_K 内。证明：对步数归纳。每一步要么不经原型（内核动作，S_K 不变式保持），要么经定义 317 过滤，使后继 s'∈ℛ(s)；由 ℛ 定义，内核可从 s' 继续把系统保持在 S_K；退役/切回是 fail-safe 的。故安全是**监督器的不变式**，不是原型的属性。

**定理 19（SKETCH 严格包含 FLUID，FLUID 严格包含 R68）** 当新颖性门控关闭（κ 已知/在分布）或未提升任何原型时，授权恒为 FLUID，行为逐指令相同；当提升原型时，期望**任务性能**不低于 FLUID（消解了结构不确定性）而 S_K 不变式仍保持。故包含链 R68 ⊂ FLUID ⊂ SKETCH：R68 是「不交互且最大保守」边界，FLUID 是「模型已知、仅模态歧义」边界，SKETCH 是「模型形式未知」的一般情形。

## 6. 本轮最大风险

**一句话**：SKETCH-RAS 把安全性完全外包给一个「把未知都当硬障碍」的已验证 Safe Kernel，但这恰恰意味着——**当未知障碍真的把它围死时，这个 kernel 可能根本没有可行动作，于是「可证明安全」退化成「可证明永远停着」；而唯一能救活性的快速原型，又必须在 twin 里被信任才敢提升，twin 越像真机越容易被同一个盲区骗过，系统越试越自信——最大风险是安全与活性在未知障碍前不可兼得，而系统会为了守住前者那纸证明而牺牲后者，且自己并不察觉。**

**次级风险与缓解**：
1. **内核 sound 性被破坏**（感知欺骗/未建模作用力使过近似不再 sound）→ 内核模型在线监测 + 保守闭包 + 定义 325 证书内核失效即否；
2. **孪生同质化/原型债**（引理 20–21）→ 对抗/held-out 孪生 + 库溯源多样性 + E304/E307；
3. **原型腐化未及时退役**（对象已变但证书还在）→ 定义 322 CUSUM/GLR + E310；
4. **PRQ 被社交工程/幻觉利用**（展示的幽灵本身误导人）→ 单次判断不定案 + R69 证据纪律 + E308 诱导性评估；
5. **死锁与过度保守**（命题 1）→ DCD 显式死锁检测与升级（让行/求助/最小风险停车），绝不把「不动」伪装成「安全」。

```python
    base  = M.plr.retrieve(kappa) or M.pap.synthesize(kappa, o, M.budget)
    proto = M.ttt.tournament(M.pap.variants(base, kappa), M.twin, M.sks.kernel, M.H)
    if proto is None:
        if M.prq.human_available():
            proto = M.prq.ask(base or M.sks.kernel, M.twin, M.human)
        else:
            return M.dcd.conservative_closure(o, M.sks.kernel)
    u, src = M.sks.simplex_step(o, proto, M.sks.kernel, M.kernel_model)
    M.pco.update(proto, o, M.dcd.consistency_residual())
    M.vqa_p.submit_async(kappa, proto, src, M.pco.state)
    return u, src, M.pco.cert()
```

## 4. 推导

**引理 19（屏蔽探测的可识别性与失效边界）** 屏蔽探测把动作限制在保留可恢复性的子集内，风险 ≤ ε_probe 由构造保证；但信息增益只在 Δ_resp ≳ σ_resp 时为正。脆弱/主动类允许接触力→0 使 Δ_resp→0，探测要么危险要么无用，须改用 PRQ 或不接触观察。信息模态由「该类允许的接触强度」而非「我想知道多少」决定。

**引理 20（原型债：孪生误差只进效率通道）** 设 𝒯 与真实在测试视域内失配为 ε_twin，则选中原型相对真实最优的性能遗憾为 O(ε_twin·H·L)，但真实安全违规 = 0，只要 (a) 可恢复性过滤用内核 sound 过近似；(b) Δt_handoff ≤ 一周期。孪生误差只能让「选择」变差，不能伪造「可恢复性」——测试 selects，内核 certifies。

**引理 21（库检索的摊销收益与同质化污染）** 命中率随库规模 n 上升，命中时合成成本由 T_synth 降为 T_retr+T_adapt；但若孪生与被检索案例共享盲区，相似度假阳可同时骗过 TTT，使全库在同类盲区上「一个 bug 复制 n 份」。故检索式原型须额外过对抗/held-out 孪生、保留溯源多样性、并在 J_PROTO 记录来源。

**命题 1（活性不可保证）** 定理 18 只保安全不保前进；当 ℛ(s)=∅、所有候选被否且无人类/无让行时，系统可被证明安全地永远停住。活性必须由原型/PRQ/让行购买，不存在无条件活性保证——「只保安全会变成只保不动」。

**定理 18（条件安全：安全性独立于原型正确性）** 在 A101（π_K 在 S_K 上验证；sound 过近似；Δt_handoff ≤ 一周期）下，对任意原型序列（含对抗错误、幻觉类、被投毒孪生、腐化未退役），闭环始终留在 S_K。证明：对步数归纳；每步或内核动作（不变式保持），或经可恢复性过滤使后继 ∈ℛ(s)，由 ℛ 定义内核可从其后继续守 S_K；退役/切回 fail-safe。故安全是监督器不变式，不是原型属性。

**定理 19（SKETCH 严格包含 FLUID，FLUID 严格包含 R68）** 新颖性门控关闭或未提升原型时授权恒为 FLUID、行为逐指令相同；提升原型时期望任务性能不低于 FLUID 且 S_K 不变式保持。包含链 R68 ⊂ FLUID ⊂ SKETCH 成立。

## 5. 复杂度分析

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| novelty_head 门控 | < 0.05ms | <1MB | 定义 319 |
| OCD 类后验推断 | < 0.2ms | O(\|𝒦\|) | 定义 311–312 |
| SPP 探测规划（执行另计） | < 0.1ms | O(1) | 定义 313 |
| PAP anytime 合成（旁路） | ≤ 8ms（可截断） | 24MB | 定义 314 |
| TTT 锦标赛（K≤8×M≤6×H，旁路） | ≤ 15ms | O(K·M·H) | 定义 315 |
| **SKS 可恢复性过滤（硬实时）** | **< 0.1ms** | O(1) | 定义 316–317、定理 18 |
| PRQ 人类判断 | 100ms–s（异步） | — | 定义 320 |

**架构要点**：安全在关键路径，原型在旁路；原型超时只失效率、不失安全——这正是「快速原型」在硬实时系统中可行的原因。

## 7. 本轮最大风险

**一句话**：SKETCH-RAS 把安全性完全外包给一个「把未知都当硬障碍」的已验证 Safe Kernel，但这恰恰意味着——**当未知障碍真的把它围死时，这个 kernel 可能根本没有可行动作，于是「可证明安全」退化成「可证明永远停着」；而唯一能救活性的快速原型，又必须在 twin 里被信任才敢提升，twin 越像真机越容易被同一个盲区骗过，系统越试越自信——最大风险是安全与活性在未知障碍前不可兼得，而系统会为了守住前者那纸证明而牺牲后者，且自己并不察觉。**

**次级风险与缓解**：内核 sound 性被破坏（在线监测内核模型 + 保守闭包 + 证书内核失效即否）；孪生同质化/原型债（对抗/held-out 孪生 + 库溯源多样性 + E304/E307）；原型腐化未及时退役（CUSUM/GLR + E310）；PRQ 被社交工程/幻觉利用（单次判断不定案 + R69 证据纪律 + E308）；死锁与过度保守（DCD 显式死锁检测与升级：让行/求助/最小风险停车，绝不把「不动」伪装成「安全」）。
