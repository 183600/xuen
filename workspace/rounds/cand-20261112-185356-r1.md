# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 7 轮；本轮灵感：「自主导航」×「扩散策略」）

> 第 60 轮的 SGEC 把「执行层→证据层」升级为「认知驱动的场景-执行闭环」：SSM 场景先验、CIEC 意图锁定、EPIR 因果隔离、SERC 闭环。但它本质上仍是一个**判别式、单峰**的决策栈：
> 1. **单峰决策的多模态坍缩**：SERC 在场景-约束交集里 `argmin` 选一个 K，遇到「路口左/右/直行」这类**多同伦类**导航问题时，单峰策略会把多个可行模式**平均**成一条撞墙轨迹——这正是行为克隆的经典失败模式（mode averaging）。
> 2. **提案与认证的割裂**：前 60 轮的 EEIS/ERTC/SIC 是「认证器」，但**没有生成器**——它只能否决候选，不能主动生成多样化候选；候选由上层规划器给定，探索能力受限。
> 3. **实时性与最优性的硬冲突**：导航要求 10–50ms 级重规划，而高保真采样/优化昂贵；前几轮的 PCE 只管执行/认知，未覆盖「生成式采样」这一新算力黑洞。
> 4. **云-边分裂下的时间失效**：若扩散采样在云端 GPU、投影认证在边端，**一个 500ms 前采出的轨迹可能已因场景变化而失效**——第 60 轮的 EPIR 只保证因果顺序，不保证**时间有效性**。

## 0. 直觉与动机

**灵感 1（自主导航 → 扩散导航先验 DNP）**
直觉：导航的本质不是「找一条路」，而是「在多个同伦类里保持分布」。路口左转/右转/直行是三个**拓扑不同**的模式，用一条平均轨迹去拟合它们必然穿墙。扩散模型天生是**多峰生成器**：从纯噪声逐步去噪，可以采样出属于不同同伦类的轨迹。把导航策略建模为条件扩散 `ε_θ(x_t,t,c)`，条件 c = (场景语义 z、目标 g、代价地图 C_map、意图 I)。**关键洞见：去噪过程本身就是「由粗到细的规划」**——早期步骤决定走哪个同伦类（拓扑），后期步骤决定具体避障（几何）。

**灵感 2（扩散策略 → 认证去噪 CDC + 安全投影 SPD）**
直觉：扩散策略表达力强但**没有硬安全保证**，采样是随机的，可能撞墙。传统做法是「先采样后拒绝」（rejection sampling），但拒绝率极高、极慢。**关键洞见：把认证嵌进去噪循环**——每一步先用「可达管 T_t(x̂₀,ρ_t)」粗检（早期 ρ_t 大、检查便宜），再用控制障碍函数 CBF-QP 把预测的干净样本**投影**回安全集 `Proj_{C_safe}`（后期 ρ_t 小、检查精确）。由于 ρ_t 随 ᾱ_t→1 单调收缩，认证天然是**由粗到细**的，计算量与风险自适应。
但投影会引入**分布偏置**（projection bias）：投影后的样本不再服从原扩散分布。用「镜像/反射扩散」或投影分数修正 `∇log Z` 来补偿，否则会系统性偏向安全集边界。

**灵感 3（扩散策略 × 意图 → 意图引导的模式选择 IGM）**
直觉：第 60 轮的 CIEC 把意图硬锁成约束，是「单峰思维」。扩散策略下，意图应做**模式选择器**而非约束锁：一句「绕开人群」不是把速度锁死，而是把概率质量重新分配到「远离人群的同伦类」。用 classifier-free guidance：`ε̃ = ε_θ(c_∅) + w(I)·(ε_θ(c_I) − ε_θ(c_∅))`。**关键洞见：guidance 尺度 w 是双刃剑**——w 太大模式坍缩到单一同伦类（失去多模态），w 太小意图被忽略。需要「意图一致性概率」`P(ϕ(I)(x₀)) ≥ 1−δ` 的**可验证**校准，并按同伦类**分别认证、分别选择**，绝不跨类平均。

**灵感 4（自主导航 × 扩散 → 风险自适应去噪预算 RADB）**
直觉：扩散采样是算力黑洞（N 步 × M 样本 × 网络前向）。导航中大部分时间在开阔走廊（低风险），少数时间在窄道/人群（高风险）。**关键洞见：去噪步数与风险成正比**——低风险用 N_min 步粗采，高风险用 N_max 步 + 多样本 + 投影；一旦 top-M 样本全部带裕度认证，立即早停。这把第 60 轮的认知预算扩展出第五维 `B_diff`。

**灵感 5（合流 → 扩散-证据闭环 DECL + 时间有效性证书 TVC）**
直觉：执行产生的 EV-exec 是**免费的在线监督信号**。用回放缓冲更新扩散提案（score distillation / 轻量适配器），但**只更新提案、永不更新安全过滤器**——认证器是「宪法」，提案是「政策」。同时，云-边分裂下必须给每条轨迹发「时间有效性证书」：轨迹产出时刻 τ_s + 有效视界 τ_valid(v, κ_scene)，超时或场景跃迁即判失效，回退几何规划器。

**灵感 6（总纲：把「生成」和「认证」解耦再耦合）**
前 60 轮造的是「刹车与仪表盘」，本轮造的是「想象力」。扩散负责**生成多模态候选**，接地层负责**认证与投影**。二者不是简单的串联（先采样后拒绝），而是**在去噪过程中交替耦合**：生成一步 → 认证一步 → 投影一步。由此得到一个可证明的「安全生成」范式：**提案可以天马行空，但落在执行器上的每一条轨迹都必须穿过认证器**。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（扩散导航先验 DNP）** 导航轨迹空间 X = ℝ^{H×d}（H 个路点，每点 d 维位置+速度）。条件去噪扩散模型：
- **前向过程**：q(x_t|x_{t−1}) = N(x_t; √(1−β_t)·x_{t−1}, β_t I)，ᾱ_t = ∏_{s≤t}(1−β_s)
- **反向过程**：p_θ(x_{t−1}|x_t,c) = N(x_{t−1}; μ_θ(x_t,t,c), Σ_θ(x_t,t,c))，其中
  μ_θ = (1/√(1−β_t))·(x_t − (β_t/√(1−ᾱ_t))·ε_θ(x_t,t,c))
- **条件**：c = (z_scene, g, C_map, I)，z_scene 取自定义 153 的 SSM，I 取自定义 154 的 CIEC
- **先验**：π_diff(x₀|c) 为反向过程的推前分布（pushforward）。π_diff 允许在**同伦类集合 H = {[γ₁],…,[γ_K]}** 上多峰。

**定义 162（认证去噪级联 CDC）** 在去噪步 t，由当前噪声样本估计干净样本：
- x̂₀^{(t)} = (x_t − √(1−ᾱ_t)·ε_θ(x_t,t,c)) / √(ᾱ_t)
- **可达管**：T_t = x̂₀^{(t)} ⊕ B_{ρ_t}，其中 ρ_t = σ_ε·√((1−ᾱ_t)/ᾱ_t) + ρ_model（随 ᾱ_t→1 单调收缩到 ρ_model）
- **认证函数**：Cert_t(x̂₀) = 1 ⇔ T_t ∩ O = ∅ ∧ x̂₀ ∈ D_feas ∧ clearance(x̂₀) ≥ 0
- **由粗到细**：早期用膨胀障碍 O ⊕ B_{ρ_t} 做粗检（空间哈希，O(1) 查询）；后期 ρ_t 收紧做精检。Cert_t 单调细化：Cert_{t−1} ⇒ Cert_t（在模型 Lipschitz 假设下）。

**定义 163（安全投影扩散 SPD）** 安全集 C_safe = {x | h_j(x) ≥ 0, j=1..q} ∩ C_ERTC（C_ERTC 为定义 154 的实时契约）。投影算子：
- Proj_{C_safe}(x) = argmin_{y∈C_safe} ‖y − x‖²_W（W 为度量，按航向/速度各向异性加权）
- **投影去噪步**（DDIM 形式，避免直接投影噪声）：
  x̂₀ ← Proj_{C_safe}(x̂₀)；ε_safe = (x_t − √(ᾱ_t)·x̂₀)/√(1−ᾱ_t)；x_{t−1} = √(ᾱ_{t−1})·x̂₀ + √(1−ᾱ_{t−1})·ε_safe + σ_t z
- **投影调度** S_proj ⊆ {0..N−1}：仅在高风险步与末步投影，平衡 QP 开销与安全；末步 t=0 必投影
- **偏置修正**：投影链的平稳分布偏离 π_diff，需加修正项 s_corr = ∇log Z_t（或镜像映射），否则样本系统性贴边

**定义 164（意图引导模式选择 IGM）** 给定意图 I 与同伦类 H：
- **CFG 引导**：ε̃ = ε_θ(x_t,t,c_∅) + w(I)·(ε_θ(x_t,t,c_I) − ε_θ(x_t,t,c_∅))
- **意图一致性**：κ_intent(I,x₀) = 1[ϕ(I)(x₀) 成立]，要求 P_{x₀~π_diff}(κ_intent=1) ≥ 1−δ_intent
- **模式选择**：m* = argmin_{m∈H: Cert(m)=1 ∧ κ_intent(m)=1} J(m)，其中 J(m) 为路径代价 + 风险积分
- **禁止跨类平均**：不同同伦类的轨迹算术平均无拓扑意义（可能穿墙），因此按类分别采样、分别认证、按类选代表

**定义 165（风险自适应去噪预算 RADB）** 风险 r ∈ [0,1] 由 SIC（定义 158）+ 最小净空裕度 + 场景跃迁率 κ_scene 合成：
- N(r) = N_min + ⌊(N_max−N_min)·σ(α(r−r₀))⌋，M(r) = M_min + ⌊(M_max−M_min)·r⌋
- **早停**：若 top-M 样本全部 Cert=1 且净空裕度 ≥ ε_m，立即停止去噪
- **预算**：B_diff = (ΣN, ΣM, Q_proj, E_guidance)；单调消耗，任一耗尽即降级

**定义 166（时间有效性证书 TVC）** 轨迹证书 TVC = (τ_s, τ_valid, h_traj, sig)：
- τ_valid = min(τ_max, c_clear/(v_max+ε_v))·1/(1+κ_scene)
- **有效性判定**：Valid(t_exec) ⇔ (t_exec − τ_s ≤ τ_valid) ∧ (κ_scene < θ_scene) ∧ (seq 与定义 155 的 EPIR 期望序号一致)
- **失效处理**：超时或场景跃迁 → 丢弃该样本并触发重规划；连续失效 → 回退几何规划器

**定义 167（扩散-证据闭环 DECL）** 回放缓冲 R ← R ∪ {(c, x₀^exec, e_t)}，e_t 为定义 156 的 EV-exec。提案更新：
- θ_{k+1} = argmin_θ E_{(c,x,e)~R}[L_diff(θ;c,x)] + λ_trust·KL(π_θ ‖ π_{θ_k})
- **冻结约束**：C_safe、ERTC、Proj 永不更新（认证器是宪法）；只更新提案 θ
- **信任域**：KL ≤ ε_trust 防止灾难性漂移；更新频率受 B_diff 约束，低风险期才允许离线更新

**定义 168（PCE+++++ 五维预算耦合）** B_all = (B_scene, B_intent, B_ros, B_exec, B_diff)。价值-成本：
```
voi_diff(π) = VOI_meta_pessimistic(π) − cost_cog(π) − cost_exec(π) − cost_diff(π)
cost_diff = λ_step·ΣN + λ_sample·ΣM + λ_proj·Q_proj + λ_stale·P(stale)
```
降级链：B_diff 耗尽 → 几何规划器（A*/D* Lite + 认证净空）；Proj 不可行 → 蠕行/停车；B_scene 耗尽 → 通用场景先验；B_intent 耗尽 → 默认约束；B_ros 异常 → 本地闭环。

## 2. 关键算法伪代码

### IP-161/162/163 扩散导航器（认证 + 投影 + 自适应）

```python
class DiffusionNavigator:
    def __init__(self, denoiser, certifier, projector, scheduler):
        self.eps = denoiser            # ε_θ(x_t, t, c)
        self.cert = certifier          # CDC
        self.proj = projector          # SPD (CBF-QP)
        self.sched = scheduler         # RADB
        self.S_proj = {0, 5, 10}       # 投影步（末步必含）

    def plan(self, c, risk):
        N, M = self.sched.alloc(risk)
        x = torch.randn(M, H, d)
        for t in reversed(range(N)):
            eps = self.eps(x, t, c)
            x0 = (x - sqrt(1 - abar[t]) * eps) / sqrt(abar[t])
            if t in self.S_proj or t == 0:
                x0 = self.proj.project(x0, c)          # CBF-QP, batched
            eps_safe = (x - sqrt(abar[t]) * x0) / sqrt(1 - abar[t])
            x = sqrt(abar[t-1]) * x0 + sqrt(1 - abar[t-1]) * eps_safe
            if t > 0:
                x = x + sigma[t] * torch.randn_like(x)
            if t % self.cert_every == 0:
                rho = sigma_eps * sqrt((1 - abar[t]) / abar[t]) + rho_model
                mask = self.cert.certify(x0, rho, c)
                if mask.sum() == 0:
                    return ("FALLBACK", None)          # 全灭 → 几何规划
                x, x0 = x[mask], x0[mask]
                if self.cert.all_margin_ok(x0, eps_m) and t <= N - 3:
                    break                              # RADB 早停
        return self.select_modes(x0, c.intent)         # IGM
```

### IP-163 安全投影器（CBF-QP）

```python
def project(self, x0, c):
    out = x0.clone()
    for k in range(H):
        y = x0[:, k, :]
        # min ||u - y||^2_W  s.t.  h_j(u) >= 0  (线性化 CBF 约束)
        u = qp_solve(H=W, f=-W @ y.T,
                     A=-grad_h(y), b=h(y),
                     warm_start=self.prev_u.get(k))
        if u is None:                              # QP 不可行
            u = creep_toward_safe(y, c)            # 蠕行/停车
        out[:, k, :] = u
        self.prev_u[k] = u
    return out
```

### IP-164 意图引导模式选择

```python
def select_modes(self, x0, intent):
    groups = defaultdict(list)
    for traj in x0:
        if not self.cert.certify(traj[None], 0.0, None)[0]:
            continue
        if not intent_ok(traj, intent):            # κ_intent
            continue
        groups[homotopy_class(traj)].append(traj)  # 按同伦类分组
    best = {}
    for m, trajs in groups.items():
        best[m] = min(trajs, key=path_cost_J)      # 类内选代表
    return best                                    # 多类并存，绝不平均
```

### IP-165 风险自适应调度

```python
def alloc(self, risk):
    N = int(N_min + (N_max - N_min) * sigmoid(alpha * (risk - r0)))
    M = int(M_min + (M_max - M_min) * risk)
    return N, M

def risk_of(self, sic, margin, kappa_scene):
    return clip(0.5*(1 - sic.scene_conf) + 0.3*(1 - margin/margin_max)
                + 0.2*kappa_scene, 0, 1)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DNP | O(N·M·d²) 前向 | O(M·H·d) | 多同伦类覆盖（熵 ≥ H_min） |
| CDC | O(N·M·H)（空间哈希） | O(H) | 管认证 sound w.p. ≥ 1−α |
| SPD | O(Q·q³) QP（warm start O(Q·q)） | O(q²) | C_safe 控制不变 ⇒ 投影链不变 |
| IGM | O(K·M·H) | O(K·M) | 意图一致性 ≥ 1−δ_intent |
| RADB | 自适应降 N、M | O(1) | 预算单调、早停不损认证 |
| TVC | O(1) | O(1) | 零陈旧执行 |
| DECL | O(|R|·d²) 离线 | O(|R|) | 信任域内稳定 |

**正确性定理（SGEC+）**：
假设 A66–A70 成立：**(A66)** 去噪器 ε_θ 满足 L-Lipschitz，score 误差 ≤ δ_score，且管半径 ρ_t 以概率 1−α 上界真实干净样本偏差；**(A67)** C_safe 控制不变且 Proj 非扩张；**(A68)** 意图映射 ϕ 是 sound 的（约束蕴含），CFG 尺度经校准；**(A69)** 场景跃迁由 κ_scene 在 τ_valid 内检出，EPIR 因果序成立；**(A70)** 提案更新的信任域保证 π_θ 距认证分布 ≤ ε_trust。则：
1. **安全性**：每条下发轨迹落入 C_safe，概率 ≥ 1−α（由 A66、A67）。
2. **意图性**：采样轨迹满足意图约束，概率 ≥ 1−δ_intent（由 A68）。
3. **时效性**：陈旧轨迹不进入执行器；一旦失效必触发重规划或回退（由 A69）。
4. **活性/可达性**：若存在可行同伦类且 π_diff 对其质量 ≥ p_min，则模式选择以 ≥ 1−(1−p_min)^M 概率找到它。
5. **预算安全**：B_all 任一维耗尽，触发对应降级，绝不空转。

## 5. 本轮最大风险

**一句话**：扩散提案的安全证书完全依赖「管半径 ρ_t 的上界」与「CBF 模型」的保真度——若模型在未见场景中 OOD、低估去噪不确定性（ρ_t 过小）而 QP 投影又恰好可行，系统会执行一条「认证通过但实际撞墙」的轨迹，这是比「认证失败」更危险的**假阴性安全**；必须以 EV-exec 分布漂移 D⁺ 检测 OOD、以 ρ_model 保守膨胀、并以几何规划器的硬净空作为最后一道不可学习的护栏。

## 2. 关键算法伪代码

### IP-161/162/163 扩散导航器（认证 + 投影 + 自适应）

```python
class DiffusionNavigator:
    def __init__(self, denoiser, certifier, projector, scheduler):
        self.eps = denoiser            # ε_θ(x_t, t, c)
        self.cert = certifier          # CDC
        self.proj = projector          # SPD (CBF-QP)
        self.sched = scheduler         # RADB
        self.S_proj = {0, 5, 10}       # 末步必投影

    def plan(self, c, risk):
        N, M = self.sched.alloc(risk)
        x = torch.randn(M, H, d)
        for t in reversed(range(N)):
            eps = self.eps(x, t, c)
            x0 = (x - sqrt(1 - abar[t]) * eps) / sqrt(abar[t])
            if t in self.S_proj or t == 0:
                x0 = self.proj.project(x0, c)          # CBF-QP, batched
            eps_safe = (x - sqrt(abar[t]) * x0) / sqrt(1 - abar[t])
            x = sqrt(abar[t-1]) * x0 + sqrt(1 - abar[t-1]) * eps_safe
            if t > 0:
                x = x + sigma[t] * torch.randn_like(x)
            if t % self.cert_every == 0:
                rho = sigma_eps * sqrt((1 - abar[t]) / abar[t]) + rho_model
                mask = self.cert.certify(x0, rho, c)
                if mask.sum() == 0:
                    return ("FALLBACK", None)          # 全灭 → 几何规划
                x, x0 = x[mask], x0[mask]
                if self.cert.all_margin_ok(x0, eps_m) and t <= N - 3:
                    break                              # RADB 早停
        return self.select_modes(x0, c.intent)         # IGM
```

### IP-162 认证去噪级联

```python
def certify(self, x0, rho, c):
    ok = torch.ones(x0.shape[0], dtype=torch.bool)
    for k in range(H):
        tube = inflate(x0[:, k, :], rho)               # 粗检：膨胀障碍
        ok &= ~intersects(tube, c.C_map.obstacles)     # 空间哈希 O(1)
    ok &= feasible_dynamics(x0)                        # 动力学可行
    ok &= clearance(x0, c.C_map) >= 0                  # 精检：净空
    return ok

def all_margin_ok(self, x0, eps_m):
    return clearance(x0, self.last_map).min() >= eps_m
```

### IP-163 安全投影器（CBF-QP）

```python
def project(self, x0, c):
    out = x0.clone()
    for k in range(H):
        y = x0[:, k, :]
        u = qp_solve(H=W, f=-W @ y.T,
                     A=-grad_h(y), b=h(y),
                     warm_start=self.prev_u.get(k))
        if u is None:
            u = creep_toward_safe(y, c)                # 蠕行/停车
        out[:, k, :] = u
        self.prev_u[k] = u
    return out
```

### IP-164 意图引导模式选择

```python
def select_modes(self, x0, intent):
    groups = defaultdict(list)
    for traj in x0:
        if not self.cert.certify(traj[None], 0.0, None)[0]:
            continue
        if not intent_ok(traj, intent):                # κ_intent
            continue
        groups[homotopy_class(traj)].append(traj)      # 按同伦类分组
    return {m: min(ts, key=path_cost_J) for m, ts in groups.items()}
```

### IP-165 风险自适应调度

```python
def alloc(self, risk):
    N = int(N_min + (N_max - N_min) * sigmoid(alpha * (risk - r0)))
    M = int(M_min + (M_max - M_min) * risk)
    return N, M

def risk_of(self, sic, margin, kappa_scene):
    return clip(0.5*(1 - sic.scene_conf) + 0.3*(1 - margin/margin_max)
                + 0.2*kappa_scene, 0, 1)
```

def update_proposal(theta, replay, lam_trust, lr):
    loss = 0.0

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| DNP | O(N·M·d²) 前向 | O(M·H·d) | 同伦覆盖熵 ≥ H_min |
| CDC | O(N·M·H)（哈希） | O(H) | 认证 sound w.p. ≥ 1−α |
| SPD | O(Q·q³)（warm start O(Q·q)） | O(q²) | C_safe 不变 ⇒ 投影链不变 |
| IGM | O(K·M·H) | O(K·M) | 意图一致性 ≥ 1−δ_intent |
| RADB | 自适应降 N、M | O(1) | 早停不损认证 |
| TVC | O(1) | O(1) | 零陈旧执行 |
| DECL | O(\|R\|·d²) 离线 | O(\|R\|) | 信任域内稳定 |

**正确性定理（SGEC+）**：若 A66–A70 成立——(A66) ε_θ 满足 L-Lipschitz 且 ρ_t 以 1−α 上界真实偏差；(A67) C_safe 控制不变且 Proj 非扩张；(A68) 意图映射 sound 且 CFG 校准；(A69) κ_scene 在 τ_valid 内检出跃迁且 EPIR 因果序成立；(A70) 提案更新 KL ≤ ε_trust——则：
1. 安全性：下发轨迹落入 C_safe 的概率 ≥ 1−α。
2. 意图性：采样轨迹满足意图约束的概率 ≥ 1−δ_intent。
3. 时效性：陈旧轨迹不进入执行器。
4. 活性：若可行同伦类质量 ≥ p_min，模式选择以 ≥ 1−(1−p_min)^M 找到它。
5. 预算安全：任一 B_all 维耗尽即触发对应降级。

## 5. 本轮最大风险

**一句话**：扩散提案的安全证书完全依赖「管半径 ρ_t 的上界」与「CBF 模型」的保真度——若模型在未见场景中 OOD、低估去噪不确定性（ρ_t 过小）而 QP 投影又恰好可行，系统会执行一条「认证通过但实际撞墙」的轨迹，这是比「认证失败」更危险的**假阴性安全**；必须以 EV-exec 分布漂移 D⁺ 检测 OOD、以 ρ_model 保守膨胀、并以几何规划器的硬净空作为最后一道不可学习的护栏。
