# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS 具身计量审计」IP-287~294；灵感循环第 1 轮；本轮灵感：「持续学习」×「工具调用」）

> R72 把安全从「认知层算法」压到「具身实时执行」：REG 实时执行图、IRL 意图、DMEM 接触计量、EREFLEX 三层反作用、S2R-UQ 参数桥接，并用 J_EMB 把「调度可信、意图可辨、接触可计量」写进证书。但 R72 对两件事仍按**静态世界**处理：
> - **仪器集合是固定的**：BSE、意图网络、触觉编码器、sim2real 残差模型在部署时被审计一次，此后被认为「还是那个函数」。可真实具身系统会**持续学习**——在线自标定、按用户微调、增量更新接触模型、扩充技能库。**对「已经不是当前在跑的那个函数」出具的证书，是合法形式的伪证**。更隐蔽的是灾难性遗忘：新分布上的平均精度上升，而安全核里的否决案例被悄悄学没。
> - **世界边界是闭合的**：所有证据都来自自己身上的传感器。可真实智能体会**调用工具**——外部感知 API、抓取规划器、IK/碰撞求解器、仿真反事实检查、云端 VLM、其他机器人、人。工具是**别人的仪器**：有自己的版本、schema、有效性域、时延、可靠性与**副作用**。R72 的 MIB/E-MIB 里没有「工具」这个一阶可计量对象；工具调用既是**测量**又是**干预**，还会**换版**。
>
> 本轮两个灵感正好补上「时间维」与「所有权维」：
> - **持续学习**：把仪器从「一次校准的常量」升级为**带版本、带漂移率上界、带有效期、带回滚点的时变对象**；把「学习」从自由更新升级为**在安全核上非增的受约束更新（LCL）**；证书从「地契」变成「租约」——**过期、漂移、换版都自动失效**。
> - **工具调用**：把工具升级为**带契约的外部仪器（TCM）**，调用升级为**可认证的测量-干预动作（TCC）**；工具链的不确定度按**证据溯源图**传播，且**非补偿性**——任一节点契约失效，整条链不定案；工具选择变成带成本/时延/副作用定价的 **VoI 问题**。
> - **两者相乘**：工具会换版、选择器会过时、再认证会滞后。于是必须引入**证书时效与再认证（CRL）**、**不可篡改漂移账本（ADL）**与**审计锚**，专门对抗「持续把漂移盖章为有效」的 Goodhart。
>
> 核心命题：**不再只问「部署期的测量链可信吗」，而要问「当测量链持续改写自己、并把测量外包给不归自己所有的工具时，它还能逐指令兑现风险界，并能证明这个界说的是当前真正在跑的代码吗？」** 把 R72 的「部署期具身证书」升级为 **LIFELONG-TOOL-GAUGE-RAS**（Lifelong, Instrumented, Federated, Ever-audited, Non-forgetting, Gauge for RAS）——**终身可再认证的具身工具计量闭环**。

## 0. 直觉与动机

**灵感 1（持续学习 → 证书是租约，不是地契）**
直觉：一张校准证书之所以有意义，是因为它同时声明了「校的是哪台仪器」和「在多长时间内有效」。温度计会漂移，所以证书有有效期；软件模型也会漂移，而且漂得比温度计快得多。R72 的 J_EMB 只绑定了「算法版本」，没有绑定「**在线更新后的参数版本**」，也没有声明「**这份保证在什么时间窗内、对哪个数据分布成立**」。一旦模型开始在线学习，证书描述的就是一个**历史函数**。**新鲜 ≠ 可信；而一个永远新鲜的再认证流水线，可能是最高级的自欺。**

**直觉的严格化**：把仪器状态写成 θ_t，证书 c 在签发时刻 t_c 认证的是 θ_{t_c}。只有满足「版本匹配 + 时间在有效期内 + 漂移未超界」时，c 才能被用来支撑当前风险界。否则必须**膨胀不确定度**或**降级**。这条时态不变式是 R72 完全缺失的。

**灵感 2（持续学习 → 灾难性遗忘要定义在「安全核」上，而不是平均精度）**
直觉：持续学习最容易骗人的指标是平均准确率。系统在用户的新厨房里越用越准，平均损失下降；但它可能同时忘掉了「热锅不能碰」「滑移必须松手」「虚晃不能全速抓」这些**否决案例**。平均指标看不见最坏情况。**安全不关心你平均多好，只关心你在否决集上有没有变差。** 所以「没有遗忘」的正确提法不是「旧任务精度不掉」，而是「**安全核上的认证风险界不上升**」。这允许系统在新分布上大胆学习（可塑性），但在安全核上保持刚性（稳定性）——**可塑性给效率，刚性给生存**。

**灵感 3（工具调用 → 工具是「别人的仪器」，不是「自己的函数」）**
直觉：调用一个抓取规划器，和调用自己写的 `abs()` 有本质区别。`abs()` 的语义由你定义；抓取规划器的语义由**别人**定义，而且会在你不知情时换版。你看到的是 schema，看不到它内部把「抓红色杯子」grounding 到哪个像素。**你认证的是 wrapper，不是仪器本身。** 计量学对这件事有成熟答案：仪器必须带**可追溯的校准链、量程、最大允许误差、版本**；跨机构使用要**互认**。工具调用缺的正是这套「互认的仪器契约」。

**直觉的严格化**：工具契约 TC 必须包含输入/输出类型、前置/后置条件、有效性域 D_tool、不确定度签名 U_tool、时延分布、可靠性、副作用等级、代价与版本哈希。工具输出只有满足契约时才是**证据**；否则是「有格式的噪声」。

**灵感 4（工具调用 → 工具是动作，不是观测：副作用与不可逆承诺）**
直觉：R72 的所有证据获取都被默认可逆（看一眼、问一句、摸一下）。但工具调用常常**改变世界**：下单一台设备、锁死一个关节、向外部系统提交一个抓取任务、让人去做一件事。此时「调用」同时是**测量**和**承诺**；测错了不能「再测一次」，因为世界已经变了。所以工具调用必须有**副作用等级**：只读（read-only）、可逆（reversible）、不可逆（irreversible）、面向人（human-facing）。不可逆调用需要**显式授权令牌 + 正 VoI + 风险预算**，而不是「schema 合法就放行」。

**灵感 5（工具调用 × 持续学习 → 供应链漂移：契约同构而语义漂移）**
直觉：最危险的换版不是 schema 变了（那会被检测到），而是 **schema 完全不变、语义悄悄变了**。VLM 从 v3 升到 v4，「红色杯子」的 grounding 从杯身漂到杯柄；抓取规划器从「保守」调成「激进」；仿真器换了接触求解器。你的 TCC 检查全部通过，因为**契约文本没变**。这是工具版的「仪器漂移」，而且是**别人替你漂的**。对抗它只能靠：版本钉死、金丝雀查询、可复现调用记录、以及**隐藏审计锚**上的性能漂移检测。

**灵感 6（综合 → 「新鲜 ≠ 可信」：再认证必须与证据获取、回滚、账本联成闭环）**
直觉：如果只是「定期重跑一遍评测」，持续学习系统会学会评测集（Goodhart），工具会针对评测集优化，再认证会变成**盖章机器**。真正的再认证必须满足四件事：**触发有据**（漂移/换版/过期）、**取样有偏**（针对 gap 的主动实验设计，而非随机抽样）、**结论可复算**（账本 + 版本快照 + 隐藏锚）、**失败可回滚**（永远保留上一个已认证快照）。四者缺一，证书就退化成「信心的装饰」。

## 1. 形式化定义（增量：定义 366–382）

**定义 366（LIFELONG-TOOL-GAUGE-RAS 总览）** LTG = (LCL, TCM, TCC, CRL, ADL, GAUGE-RAS†)。五不变式：
(i) **版本绑定**：每条活跃证书必须绑定当前全部仪器/模型/工具的**精确内容哈希**；任一不匹配 ⇒ 证书失效；
(ii) **时效内插**：证书有生命周期 T_c；两次再认证之间，不确定度按漂移率**单调膨胀**，风险界只能用膨胀后的 u_eff；
(iii) **安全保持更新**：任何在线更新 δ 仅在「安全核 K_safe 上的认证风险界不上升」时可接受，否则投影/重放/拒绝/回滚；
(iv) **工具契约完备与非补偿**：每次工具调用携带 (契约, 版本, 有效性域, 不确定度签名, 副作用等级, 溯源, 代价)；工具链任一点失效 ⇒ 整链不定案；
(v) **不可篡改与严格退化**：所有更新、工具调用、再认证写入哈希链账本；漂移/换版/过期/契约违背 ⇒ 逐级退化到 R72/R71/R68，**安全侧只增不减**。

**定义 367（工具契约 TC，Tool Contract）** TC = (id, v, Σ_in, Σ_out, P_pre, P_post, D_tool, U_tool, Lat, Rel, σ, cost, τ_tool, h)：
- Σ_in/Σ_out 为类型化输入/输出 schema；
- P_pre(s,z) 为前置条件（**语义**可满足性，不只是类型合法），P_post 为可验证后置条件；
- D_tool ⊆ 𝒮×𝒵 为有效性域；U_tool = (u_ale, u_epi, u_cal, u_lat, u_ver) 为不确定度签名；
- Lat 为时延分布（p50/p99），Rel 为可靠性；σ ∈ {read-only, reversible, irreversible, human-facing} 为副作用等级；
- cost 为经济/时延/风险代价；τ_tool 为可追溯链；h 为契约与实现的联合内容哈希。
**工具输出只有在「版本匹配 ∧ 输入∈Σ_in ∧ P_pre 成立 ∧ D_tool 覆盖当前状态」时才是证据**；否则记为 contract-invalid，不可进入 BSE/风险缩放。

**定义 368（工具调用认证 TCC，Tool Call Certification）** 调用 c = (tool, x) 可采纳当且仅当：
(a) **接地**：x 的指代在 b_t(s,z) 上有非零支撑（不允许「指代不存在物体的参数」通过 schema 校验）；
(b) **前置**：Pr[P_pre | b_t] ≥ 1 − α_pre；
(c) **版本**：当前实现哈希 = 注册表钉死哈希；
(d) **时延**：Lat_{p99} ≤ 请求方 REG 截止时间的可分份额；
(e) **后置可验**：存在 T_post 内可执行的后置检查（否则只能按 read-only 降级使用，且置信度打折）；
(f) **副作用**：E[r_σ] ≤ 剩余风险预算；σ=irreversible 需**显式授权令牌**且 VoI^T > 0；σ=human-facing 需独立性检查；
(g) **总风险**：E[Risk_after] ≤ λ-scale 后的界。
全过 ⇒ 签发 J_tool（含契约哈希、调用记录、后置检查结果）；任一不过 ⇒ **契约拒绝（contract refusal）**，不是「先试了再说」。

**定义 369（工具链计量与证据溯源图）** 工具链是一条证据 DAG 𝒢 = (V, E)，节点为仪器（在体传感器或工具调用），边为数据流。链级不确定度按
u_chain² = 1ᵀ (J_Σ Jᵀ) 1，其中 Σ 为节点误差协方差、J 为链式雅可比；
**共享上游数据的节点必须先做协方差交叉（covariance intersection）去重**，禁止把同一张图像喂给三个模型后当成三票独立证据；定义**有效独立证据数** n_eff ≤ |V|。
链有效性 = ∧_{v∈V} valid(v)（**非补偿**）：任一节点 contract-invalid，整链不可定案。
**性质**：u_chain ≥ max_{v∈V} u_v；因此「多工具投票」不能把最不可靠的必需节点平均掉。

**定义 370（持续学习对象与安全核）** 仪器参数 θ_t ∈ Θ，在线更新流 δ_t。**安全核**
K_safe = (P_safe, V_veto, SLO)，
其中 P_safe 为安全关键状态分布（含历史否决案例与其邻域），V_veto 为否决指标集，SLO 为硬约束集。
**灾难性遗忘在本框架中定义为**：∃p∈P_safe 使认证风险界上升，或某 veto 指标越阈——**不是**平均精度下降。

**定义 371（安全保持更新 SPU，Safety-Preserving Update）** 更新 δ 可接受当且仅当：
(a) R_safe(θ⊕δ) ≤ R_safe(θ)（安全核风险界非增，R_safe = sup_{p∈P_safe} Risk）；
(b) 全部 veto 指标在隐藏审计锚上不越阈；
(c) 校准误差不退化超过 δ_cal（ECE/Brier/覆盖）；
(d) 参数/函数漂移 ‖f_{θ⊕δ} − f_θ‖ ≤ L_f·ε（局部 Lipschitz 预算）。
否则依次尝试：受约束投影 → 安全核重放增广 → 拒绝并保留旧版本。
**实现原则**：可塑性分配給「不影响安全核」的子空间（如新物体外观），刚性分配给安全核相关子空间（如滑移判定、热源语义、虚晃意图）；以**逐子空间门控**而非全局学习率实现。

**定义 372（证书时效与漂移膨胀 CRL，Certificate Lifetime）** 证书 c = (t_c, T_c, v_c, D_c, u_c, ε_c, coverage_c)。令 age = t − t_c，分布距离 d_t = d_D(D_t, D_c)（有界代理：嵌入 MMD/KS/密度比上界）。**有效不确定度**
u_eff(t) = u_c + ε_c + ρ_c·age + L_c·d_t，
其中 ρ_c 为仪器漂移率上界、L_c 为分布偏移的 Lipschitz 敏感度。
**c 在 t 时刻可用 ⇔ 版本匹配 ∧ u_eff(t) ≤ u_max,c**。超过即进入 FROZEN，等待再认证或回滚。

**定义 373（漂移追踪 ADT，Audited Drift Tracking）** 四通道漂移：
- **输入漂移**：原始观测/嵌入的 MMD/KS/密度比；
- **表征漂移**：中间层特征分布（用固定探针集）；
- **性能漂移**：隐藏审计锚 A* 上的风险/校准变化；
- **契约漂移**：工具版本哈希变化、schema 兼容性变化、静默弃用。
检测用顺序检验（CUSUM/SPRT/序贯 MMD），并显式控制误报率；任一通道报警 ⇒ 冻结相关证书 + 触发再认证；安全核通道报警 ⇒ 立即降级，不等再认证完成。

**定义 374（再认证协议 CRL-P）** 触发后：冻结 → **针对 gap 的主动数据获取（OED）** → 重跑 MIB/E-MIB 审计 → 证明或有界估计新风险 → 签发新证书或回滚 → 写账本。允许**影子再认证**：后台用候选版本再认证，前台继续用「上一个已认证版本 + 膨胀不确定度」保守运行；**不允许「未认证版本直接接管」**。

**定义 375（不可篡改审计账本 ADL）** 追加式哈希链 L：entry = (t, type, artifact_hash, version_manifest, certificate, evidence_hash, actor, parent_hash)。根 R_t 进入 J_LIFE。**审计锚 A\*** 为隐藏、冻结、轮换、**永不进入训练/校准数据**的评测集；指标带版本号与**折旧**：距上次独立审计越久，该指标对证书的支撑权重越低。**目的**：让「持续学习把评测集学进去」与「工具针对评测集优化」在账本上留下可检测痕迹。

**定义 376（回滚安全版本化 RSV）** 所有仪器/模型/工具实现保留不可变快照；`last_certified` 指针指向最近一次通过 J_LIFE 的快照。更新与再认证在**影子副本**上进行；切换是原子的；任何失败可 O(1) 回滚。**不存在「不可逆的未认证更新」**。

**定义 377（终身反作用预算 L-EREFLEX）** 在 R72 EREFLEX 三层（ψ/z/c）上新增：
- **工具反作用成本** c^τ = 经济成本 + 时延占用 + E[r_σ] + 不可逆承诺的期权损失；
- **学习反作用成本** c^λ = 计算/能耗 + 安全核重放成本 + 再认证分摊 + 遗忘风险上界。
累计 Σ(c^ψ+c^z+c^c+c^τ+c^λ) ≤ B_life；任一层越界 ⇒ 降级。

**定义 378（终身风险缩放 L-RISK）** λ = max( risk_scale(U_ale, U_epi, H[b_t(z)], u_tac, u_tool, u_stale),
λ_floor(U_ale + U_epi + H[b_t(z)] + u_tac + u_tool + u_stale) )，
其中 u_tool 由工具链不确定度签名合成，u_stale = u_eff(t) − u_c 为**证书陈旧膨胀量**。**六维同权入分母，无主次**：任一项失控都抬高 λ，强制软化动作或停止工具调用。

**定义 379（终身证书 J_LIFE）** J_LIFE = (J_EMB, ledger_root R_t, version_manifest_hash, cert_lifetimes, recert_proof, drift_status, tool_contract_hash, safety_kernel_regression_proof, llife_ver)。
Valid ⇔ J_EMB 在**当前版本快照**上有效 ∧ 所有活跃证书在有效期内 ∧ 最近更新有 SPU 证明 ∧ 无未处理的安全核漂移 ∧ 工具契约全部有效。

**定义 380（威胁模型 AIC-LIFE）** ℰ_LIFE = ℰ_EMB × ℰ_learn × ℰ_tool：
- ℰ_learn = {重放投毒、遗忘攻击（专门抹掉 veto 案例）、指标游戏、再认证饥饿、审计锚泄漏、回滚攻击、用「合法更新」逐步漂移出安全核}；
- ℰ_tool = {版本漂移/投毒、schema 注入、参数接地幻觉、副作用误分类、静默弃用、相关误差伪装独立、工具时延/费用 DoS、工具串谋}。

**定义 381（终身退化链）** 逐指令等价：
- 证书过期/漂移超界 ⇒ 冻结学习，退化为「上一已认证快照 + 膨胀 λ」的 R72；
- 工具契约违背/不可达 ⇒ 丢弃该工具（及其下游），退回在体仪器 R72；
- 更新被 SPU 拒绝 ⇒ 保留旧版本，不降级但**不前进**；
- 账本/再认证失效 ⇒ 只读安全模式（R72 保守策略）；
- 全部失效 ⇒ R68。**安全侧只增不减。**

**定义 382（审计锚与指标折旧协议 AMDP）** 锚集 A* 分层（跨人/跨文化/磨损/对抗/工具版本），按**时间与覆盖**轮换；锚从不进入训练；每次再认证报告「锚上风险」与「训练分布风险」之差 Δ_gap；若 Δ_gap 扩大快于噪声 ⇒ 判为分布外/指标游戏，冻结晋级。**指标权限 = f(独立审计新鲜度, 锚覆盖, 样本量)**，而非「跑过一次就永久有效」。

```python
class ToolContractRegistry:
    def register(self, contract, impl_hash):
        assert contract.h == hash_contract(contract, impl_hash)

    def resolve(self, tool_id, version_req):

# IP-296 TCC：工具调用认证（接地/前置/版本/时延/后置/副作用/风险）
def certify_tool_call(call, b_t, reg, budget, risk_params):
    tc = reg.resolve(call.tool_id, call.version)
    if not grounded(call.args, b_t):              return Reject('ungrounded')
    if prob(tc.P_pre, b_t) < 1 - ALPHA_PRE:       return Reject('precondition')
    if tc.Lat.p99 > budget.deadline_share:        return Reject('latency')
    if tc.sigma == 'irreversible' and not call.auth_token:
        return Reject('irreversible_unauthorized')
    r_side = expected_side_effect_risk(tc, call, b_t)
    if r_side > budget.remaining_risk:            return Reject('side_effect_budget')
    post = verify_post(tc.P_post, b_t) if tc.P_post else None
    if tc.sigma != 'read-only' and post is None:
        return Reject('unverifiable_commitment')
    if expected_risk_after(call, b_t, risk_params) > budget.bound:
        return Reject('risk_bound')
    return ToolCertificate(tc_h=tc.h, call=call, post=post, r_side=r_side)

# IP-297 工具链传播：证据溯源图 + 协方差交叉 + 非补偿有效性
def propagate_chain(graph, evidence):
    nodes = topo_sort(graph)
    # 1) 共享上游去重：同一数据源的后代先做 CI，避免「三模型三票」
    sigma = covariance_intersection_by_provenance(nodes, evidence)
    # 2) 非补偿：任一节点无效 ⇒ 整链无效
    if not all(evidence[v].contract_valid for v in nodes):
        return ChainEvidence(valid=False, reason='non_compensatory')
    u_chain = sqrt(ones @ (J(graph) @ sigma @ J(graph).T) @ ones)
    return ChainEvidence(valid=True, u=u_chain,
                         n_eff=effective_independence(nodes, evidence))

# IP-298 工具 VoI：工具选择 = 带成本/时延/副作用/契约风险的 VoI
def tool_voi(b_t, tool_candidates, budget, risk_params):
    best = None
    for tc in tool_candidates:
        c = certify_tool_call(tc, b_t, REG, budget, risk_params)
        if isinstance(c, Reject):                continue
        ig = EXPECTED_INFO_GAIN(b_t, tc) - DOUBLE_COUNT_PENALTY(tc, b_t)
        score = ig - tc.cost - LAM_LAT * tc.Lat.p99 \
                - LAM_SIDE * c.r_side - LAM_STALE * stale_penalty(tc)
        if best is None or score > best.score:   best = (tc, score)
    return best if best and best.score > 0 else None   # 无正收益：不调用

# IP-300 SPU：安全保持持续更新（安全核风险非增）
def safe_update(theta, delta, replay_safe, anchors, veto_metrics):
    cand = apply(theta, delta)
    if risk_bound(cand, replay_safe) > risk_bound(theta, replay_safe):
        cand = project_to_safe_set(theta, delta, replay_safe)
    if any(veto_metrics(cand, anchors) > t for t in VETO_THRESH):
        return theta, Reject('veto_regression')     # 拒绝：保持旧版本
    if calibration_gap(cand, anchors) > DELTA_CAL:
        return theta, Reject('calibration')
    return cand, Accept

# IP-301 CRL：证书时效与膨胀
def cert_valid(c, now, dist_now):

    u_eff = c.u + c.eps + c.rho * age + c.L * d
    ok = (version_match(c.v) and u_eff <= c.u_max)
    return ok, u_eff

# IP-302 再认证：冻结 → 针对 gap 的 OED → 审计 → 签发/回滚 → 记账
```

## 3. 推导

**引理 33（陈旧膨胀的声音性）** 设证书签发时 |u*(t_c) − u_c| ≤ ε_c，且仪器漂移满足 |u*(t) − u*(t_c)| ≤ ρ(t−t_c) + L·d(D_t, D_{t_c})。则对任意 t ≥ t_c，
u_eff(t) = u_c + ε_c + ρ(t−t_c) + L·d_t ≥ u*(t)。
即**膨胀后的不确定度是真实不确定度的上界**；在 u_eff ≤ u_max 期间，用 u_eff 计算的风险界仍然声音。**证明**：三角不等式直接相加。系：**证书不是「要么真要么假」，而是「在膨胀意义下一直真到某个时刻」**——这把静态证书变成了可计算的时效对象。

**引理 34（工具链的非补偿性与最坏节点下界）** 对任意有效链 𝒢，u_chain ≥ max_{v∈V} u_v；且若 ∃v 使 valid(v)=false，则链不可定案。**证明**：协方差二次型 1ᵀJΣJᵀ1 的对角项包含各节点方差且非负；有效性是合取。系：**「多工具投票」不能把不可靠节点平均掉，也不能把同一数据源重复计数当成独立证据**——这是对 R71「单源不定案」的跨机构推广。

**引理 35（安全保持更新的风险单调性）** 若每次接受的更新 δ 满足 R_safe(θ⊕δ) ≤ R_safe(θ)，则任意有限更新序列后 R_safe(θ_n) ≤ R_safe(θ_0)。**证明**：对 n 归纳。系：**平均性能可以波动、新任务精度可以牺牲，但安全核上的认证风险界不上升**；这把「灾难性遗忘」从模糊直觉变成可审计约束。**证明重量落在 P_safe 是否真被 replay/锚覆盖**。

**引理 36（工具调用次数有限）** 设每次工具调用代价 c ≥ c_min > 0，单次期望信息增益 Δ ≤ min(H[b_t], Δ_0·γ^k)（γ<1 或受剩余熵上界 H_max 约束）。则正 VoI 调用次数 n ≤ H_max/c_min，且相同输入的幂等调用被缓存消除。**证明**：VoI_k = Δ_k − c ≤ H_max/k_eff − c_min 的累计约束。系：**工具调用不会无限自循环**，「再调一个工具试试」有可证明的停止条件。

**引理 37（证书有效期的存在性与不存在性）** 令分母 D = ρ_c + L_c·d̄（d̄ 为平均分布距离率），则
T_c = (u_max − u_c − ε_c)/D 在 D>0 时有限且正，可支撑一个声音的有效期；若 D=0，有效期由覆盖衰减决定；若 D 无界（漂移无上界或无分布重叠），**不存在有限 T_c 能保证声音性**，必须冻结学习或退化。**证明**：由引理 33 直接解不等式；无界情形取上确界发散。系：**「永远自动续期」在无漂移界时是不可证明的**——这是对「再认证流水线包治百病」的数学否定。

**引理 38（回滚恢复到已认证状态）** 在不可变快照 + 原子指针切换下，任意时刻系统都能返回最近一次通过 J_LIFE 的快照；结合有效期，系统在任意时刻至少有一个「已认证回退点」。**证明**：快照不可变、指针切换原子；失败路径显式调用回滚。系：**持续学习不产生「不可逆的信任坍塌」**。

**定理 27（终身严格包含与安全单调）** 在 A111–A116 下：LTG 在退化条件下逐指令等于 R72/R71/R68（定义 381）；且对任意有效执行，风险界 ≤ R72 风险界。**安全单调不减，效率仅在「版本可信、更新受约束、工具契约有效、再认证及时」时获益。**

**定理 28（认证工具调用 ⇒ 有界工具诱导风险）** 若 TCC(c) 通过，且链传播使用去重协方差与非补偿有效性，则在契约真实、后置可验、副作用预算内，工具诱导风险 ≤ ε_tool = α_pre·R_pre + (1−α_pre)(R_post + R_side) + ε_chain。**证明**：对「前置失败 / 前置成功但后置失败 / 后置成功但副作用超界」三事件分解取上界。**证明重量落在「工具契约文本与实现语义一致」上**（见定义 380 的版本漂移）。

**定理 29（安全核非遗忘）** 若 SPU 的 replay/锚覆盖 P_safe，且每次更新满足定义 371，则任意有限持续学习序列后，安全核风险界不上升；平均任务性能可升可降。**证明**：引理 35。**注意**：若 P_safe 覆盖不足，结论退化为「只能保证被覆盖部分」——这不是技术细节，是本框架的**边界条件**。

**定理 30（账本可检篡改与审计锚抗 Goodhart）** 在哈希碰撞抵抗与锚保密下：(i) 任何对历史条目的修改都会改变根 R_t，被 `verify` 以压倒性概率检出；(ii) 在锚有效期与覆盖域内，训练侧对评测指标的优化不能改变锚上的无偏估计，故「指标游戏」表现为锚-训练 gap Δ_gap 扩大，从而被 AMDP 捕获。**证明**：(i) 哈希链归纳；(ii) 锚不进入训练 ⇒ 锚上期望与训练优化独立；gap 检验为两样本检验。系：**抗 Goodhart 不是「选对指标」，而是「保留一组永不参与优化的锚 + 让 gap 可检测」**。

## 6. 本轮最大风险

**一句话**：LIFELONG-TOOL-GAUGE-RAS 把安全从「相信一次部署期证书」转移到「相信**漂移率上界 ρ 与安全核覆盖 P_safe 真能代表未来**、相信**工具契约文本与工具实现语义始终一致**、相信**再认证流水线不会被指标游戏与再认证饥饿驯化**」——**如果真实世界漂移得比 ρ 快，或安全核没覆盖到真正致命的那类状态，或工具在不改 schema 的情况下悄悄换了语义，那么系统会持续地把一个已经错了的测量链**重新认证为「当前有效」**：每一张证书都新鲜、每一条账本都自洽、每一次审计都通过，事后却发现它只是**高效地把错误续期**。这就是「新鲜 ≠ 可信」的终极形态——不是静态地自信地错，而是**动态地、可审计地、带着回滚点地自信地错**。

次级风险与缓解：
1. **ρ/L 上界不可知或被低估** → 用**分位数回归 + 保守上界**估计漂移率；无界时强制冻结（引理 37 的否定侧），不假设「总会稳定」。
2. **P_safe 覆盖不足（定理 29 的边界）** → 安全核 replay 采用**对抗增广 + 人在环否决案例**；定期用红队生成新 veto 邻域；覆盖度本身进入 J_LIFE。
3. **契约同构而语义漂移** → **版本钉死 + 金丝雀基准查询 + 可复现调用记录 + 隐藏锚性能漂移**四件套；把「语义一致性」做成可检测量而非假设。
4. **再认证被指标游戏** → 隐藏锚 + 指标折旧 + 锚-训练 gap 检验（定义 382）；禁止锚进入任何训练/校准管线。
5. **再认证饥饿/资源耗尽** → 影子再认证 + 前台保底 last_certified + 每单位时间再认证次数上限；攻击不改变控制环时序。
6. **共享上游导致假独立** → 证据溯源图 + 协方差交叉 + n_eff；单源多工具不得定案（引理 34）。
7. **不可逆工具误放行** → 副作用等级 + 显式授权令牌 + 期权损失定价；默认拒绝，非默认放行。
8. **复杂度爆炸** → 模块化上限：|tools|≤32、链长 ≤8、|P_safe 样本|≤64、账本分段校验；每个 veto 一条可复算证明；复杂度本身纳入审计。

## 2. 形式化定义（要点版）

**定义 366（总览与五不变式）** 版本绑定、时效内插、安全保持更新、工具契约完备与非补偿、不可篡改与严格退化。**任一不变式被破坏 ⇒ 证书失效并降级。**

**定义 367（工具契约 TCM）** 工具是外部仪器；输出仅在「版本匹配 ∧ 输入∈Σ_in ∧ P_pre 成立 ∧ D_tool 覆盖当前状态」时是证据。**契约同构而语义漂移是头号威胁。**

**定义 368（工具调用认证 TCC）** 七个检查：接地、前置、版本、时延、后置可验、副作用预算、总风险。全过签发 J_tool，否则**契约拒绝**。**不可逆调用需显式授权令牌 + 正 VoI。**

**定义 369（工具链传播 TCP）** 证据 DAG + 协方差交叉去重 + 非补偿有效性。**u_chain ≥ max 节点 u；单源多工具不得定案。**

**定义 370（安全核 K_safe）** 灾难性遗忘 = 安全核风险界上升或 veto 越阈，**不是**平均精度下降。

**定义 371（安全保持更新 SPU）** 更新可接受 ⇔ 安全核风险非增 ∧ veto 不越阈 ∧ 校准不退化 ∧ Lipschitz 预算。否则投影/重放/拒绝。

**定义 372（证书时效 CRL）** u_eff = u_c+ε_c+ρ·age+L·d_t；u_eff ≤ u_max 才算活跃。**无漂移界时不存在有限有效期（引理 37）。**

**定义 373（漂移追踪 ADT）** 输入/表征/性能/契约四通道；安全核通道报警立即降级。

**定义 374（再认证 CRL-P）** 冻结 → gap 定向 OED → 审计 → 签发/回滚 → 记账；影子再认证不阻塞控制。

**定义 375（账本 ADL）** 追加式哈希链 + 隐藏审计锚 + 指标折旧；**让 Goodhart 留下可检测痕迹。**

**定义 376（回滚版本化 RSV）** 不可变快照 + 原子切换 + `last_certified` 指针；**不存在不可逆的未认证更新**。

**定义 377（终身反作用预算 L-EREFLEX）** 在 ψ/z/c 三层上加 c^τ（工具）与 c^λ（学习）；累计 ≤ B_life。

**定义 378（终身风险缩放 L-RISK）** 六维同权入分母：U_ale、U_epi、H[b_t(z)]、u_tac、u_tool、u_stale。

**定义 379（终身证书 J_LIFE）** Valid ⇔ J_EMB 对**当前版本**有效 ∧ 证书在有效期 ∧ 最近更新有 SPU 证明 ∧ 无未处理安全核漂移 ∧ 工具契约有效。

**定义 380（威胁模型 AIC-LIFE）** ℰ_EMB × ℰ_learn × ℰ_tool。新增：遗忘攻击、指标游戏、再认证饥饿、审计锚泄漏、回滚攻击；版本漂移、schema 注入、接地幻觉、副作用误分类、静默弃用、相关误差伪装、工具串谋。

**定义 381（终身退化链）** 过期/漂移 ⇒ 冻结 + 上一已认证快照（R72）；工具违背 ⇒ 弃用该链（R72）；更新被拒 ⇒ 保留旧版；账本/再认证失效 ⇒ 只读安全模式；全失效 ⇒ R68。**安全只增不减。**

**定义 382（审计锚与指标折旧 AMDP）** 隐藏、冻结、轮换、永不入训练的 A*；报告 Δ_gap；指标权限 = f(审计新鲜度, 锚覆盖, 样本量)。**抗 Goodhart 靠「保留不参与优化的锚」，不是靠「选对指标」。**

```python
        if not gate.valid: M.mode = gate.fallback            # R72/R71/R68
        M.snapshot.write(..., u_stale=cert_staleness(M.cert_current))

    # 工具域（事件触发，非阻塞）
    for req in tool_requests:
        cert = certify_tool_call(req, M.b_t, M.tool_reg, M.budget, M.params)
        if isinstance(cert, Reject):
            ledger.append(('tool_refused', req, cert.reason)); continue
        out = invoke_with_record(req)                        # 输入/版本/时延全记录
        ev  = propagate_chain(req.graph, out)                # 非补偿链传播
        if ev.valid:
            ledger.append(('tool_ok', cert, ev.u)); M.bse.add_tool_evidence(ev)
        else:
            ledger.append(('tool_invalid', ev.reason))

    # 学习域（低频，影子副本）
    if update_stream.ready() and M.drift.allow_learning():
        cand, verdict = safe_update(M.theta, update_stream.delta,
                                    M.replay_safe, M.hidden_anchors, M.veto)
        if verdict == Accept:
            M.shadow = cand                              # 候选版本，等待再认证
        ledger.append(('update_verdict', verdict))
    if M.drift.triggered() or M.cert_expired():
        M.cert_current = recertify(M.cert_current, M.shadow)
    return k, lam, J_LIFE(M)
```

## 4. 推导

**引理 33（陈旧膨胀的声音性）** 在漂移界 |u*(t)−u*(t_c)| ≤ ρ(t−t_c)+L·d(D_t,D_{t_c}) 与签发误差 |u*(t_c)−u_c| ≤ ε_c 下，
u_eff(t) = u_c + ε_c + ρ·age + L·d_t ≥ u*(t)。
故用 u_eff 计算的风险界在 u_eff ≤ u_max 期间仍然声音。系：**证书是「在膨胀意义下一直真到某个时刻」，不是静态真假二元。**

**引理 34（工具链非补偿与最坏节点下界）** 对任意有效链，u_chain ≥ max_{v} u_v；任一节点 invalid ⇒ 整链不可定案。**证明**：协方差二次型对角非负 + 有效性合取。系：**多工具投票不能平均掉不可靠节点，也不能把同一数据源重复计数当独立证据。**

**引理 35（安全保持更新的风险单调性）** 若每次接受 δ 都满足 R_safe(θ⊕δ) ≤ R_safe(θ)，则 R_safe(θ_n) ≤ R_safe(θ_0)。系：**平均性能可波动，但安全核认证风险不升**；证明重量在 P_safe 覆盖。

**引理 36（工具调用次数有限）** 单次代价 ≥ c_min>0、增益受剩余熵 H_max 约束 ⇒ 正 VoI 调用数 ≤ H_max/c_min；幂等缓存消除重复。系：**「再调一个工具试试」有可证明停止点。**

**引理 37（有效期存在/不存在）** D = ρ_c + L_c·d̄ > 0 时 T_c = (u_max−u_c−ε_c)/D 有限正；D 无界（漂移无界/无重叠）时**不存在有限有效期**能保证声音，必须冻结或退化。系：**「永远自动续期」在无漂移界时不可证明。**

**引理 38（回滚恢复已认证状态）** 不可变快照 + 原子指针 ⇒ 任意时刻可回 last_certified；系统始终至少有一个已认证回退点。系：**持续学习不产生不可逆信任坍塌。**

**定理 27（终身严格包含与安全单调）** 在 A111–A116 下：LTG 退化后逐指令等于 R72/R71/R68；任意有效执行风险界 ≤ R72。**安全只增不减。**

**定理 28（认证工具调用 ⇒ 有界工具诱导风险）** TCC 通过 + 去重协方差 + 非补偿 ⇒ 工具诱导风险 ≤ ε_tool = α_pre·R_pre + (1−α_pre)(R_post+R_side) + ε_chain。**证明重量在「契约文本与实现语义一致」。**

**定理 29（安全核非遗忘）** 若 replay/锚覆盖 P_safe 且每次更新满足 SPU，则有限学习序列后安全核风险不升。**若覆盖不足，结论只保证被覆盖部分——这是框架的边界。**

**定理 30（账本可检篡改 + 审计锚抗 Goodhart）** 哈希链使历史修改以压倒性概率被检出；隐藏锚不入训练 ⇒ 训练侧刷分表现为 Δ_gap 扩大，被 AMDP 捕获。系：**抗 Goodhart 靠「保留不参与优化的锚」，而非「选对指标」。**

## 7. 预期结果与判定标准

- **声音性优先**：E371/E379 的覆盖必须≥名义值（允许保守），任何系统性低估直接判负——这是不可用性能换的硬线。
- **安全单调**：E375/E376/E385 中，安全核风险界与 veto 指标必须非增；平均性能上升不能抵消安全核回归。
- **可审计性**：E374/E384/E386/E394 必须能从账本独立复算；不能复算的「通过」不计入。
- **效率收益**：E380/E388/E391 在安全线内允许有限效率损失（≤5%），以换取长期可再认证性。

## 8. 本轮最大风险

**一句话**：LIFELONG-TOOL-GAUGE-RAS 把安全从「相信一次部署期证书」转移到「相信**漂移率上界 ρ 与安全核覆盖 P_safe 真能代表未来**、相信**工具契约文本与工具实现语义始终一致**、相信**再认证流水线不会被指标游戏与再认证饥饿驯化**」——**如果真实世界漂移得比 ρ 快，或安全核没覆盖到真正致命的那类状态，或工具在不改 schema 的情况下悄悄换了语义，那么系统会持续地把一个已经错了的测量链重新认证为「当前有效」：每一张证书都新鲜、每一条账本都自洽、每一次审计都通过，事后却发现它只是高效地把错误续期——这就是「新鲜 ≠ 可信」的终极形态：不是静态地自信地错，而是动态地、可审计地、带着回滚点地自信地错。**

次级风险与缓解：
1. **ρ/L 上界不可知或被低估** → 分位数回归 + 保守上界；无界时强制冻结（引理 37 否定侧），不假设「总会稳定」。
2. **P_safe 覆盖不足（定理 29 边界）** → 对抗增广 replay + 人在环否决案例 + 红队生成 veto 邻域；覆盖度进 J_LIFE。
3. **契约同构而语义漂移** → 版本钉死 + 金丝雀基准查询 + 可复现调用记录 + 隐藏锚性能漂移，四件套把「语义一致性」变成可检测量。
4. **再认证被指标游戏** → 隐藏锚 + 指标折旧 + Δ_gap 检验；禁止锚进入任何训练/校准管线。
5. **再认证饥饿/资源耗尽** → 影子再认证 + 前台保底 last_certified + 单位时间再认证次数上限。
6. **共享上游导致假独立** → 证据溯源图 + 协方差交叉 + n_eff；单源多工具不得定案。
7. **不可逆工具误放行** → 副作用等级 + 显式授权令牌 + 期权损失定价；默认拒绝。
8. **复杂度爆炸** → |tools|≤32、链长≤8、|P_safe 样本|≤64、账本分段校验；每个 veto 一条可复算证明；复杂度纳入审计。
