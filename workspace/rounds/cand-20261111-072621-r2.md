# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；新灵感循环第 1 轮；本轮灵感：「电池管理」×「模型蒸馏」） · CellCert-Distill：双电池证书管理——把鲁棒性当作可老化容量，把蒸馏当作带内阻的容量搬迁

> 第 54 轮把技能组合推进到「动作剖面 α_S + 组合图 G_S + 云边映射 γ_ce + 联合证书 J」。但 J 仍隐含两个「理想电源」假设：**H29：证书一旦签发就保持满容量**，部署时长、适配次数、温度与负载都不会改变它的 worst-case 承诺；**H30：蒸馏只是把大模型变小**，不会改变鲁棒性结构。真实系统里，证书会像电池一样随使用、适配与蒸馏循环而老化；边缘 student 更会出现「标称容量高、内阻大」的虚标现象。本轮把 **物理电池 β 与证书电池 κ 并列管理**：能量约束动作可行域，证书健康约束鲁棒性承诺；蒸馏则是把 teacher 的证书容量搬迁到 student 的**有损传输**。

## 0. 直觉与动机

**灵感 1（证书是电池，不是开关）**
直觉：第 54 轮的 `J` 被当作布尔证书使用：通过就满血，不通过就拒绝。但鲁棒性裕度 `ρ_d - ρ_min(d)` 更像电量：会被执行、适配、蒸馏与分布漂移逐步消耗，还会因不可逆老化而永久缩容。于是证书应同时有 **电量 CSoC（当前可交付裕度）** 与 **健康度 CSoH（不可逆老化后的最大容量）**，部署决策必须同时看两者——高电量、低健康的证书会在任务中途快速衰减，比低电量、高健康的证书更危险。

**灵感 2（内阻：worst-case 的电压骤降）**
直觉：电池标称电压高不代表带载能力强；内阻大的电池一加负载就骤降。证书同理：一个 student 在平均精度上与 teacher 几乎一致，但遇到对抗扰动、低电量降频或分布外输入时，鲁棒性可能瞬间跌到阈值以下。因此必须引入 **证书内阻 `R_cert`**，并用负载测试测量：`ρ_eff(ℓ) = ρ - R_cert·ℓ`。只看空载（nominal benchmark）的证书，等于只看开路电压。

**灵感 3（蒸馏是容量搬迁，不是无损复制）**
直觉：云端 teacher 的证书 `J_T` 搬到边端 student 时，会发生逐维度的**容量衰减 `Δ_cap`**。常规蒸馏最小化平均输出差异，恰好会牺牲尾部维度：mean loss 很小，worst-case margin 却掉得很快。正确的蒸馏目标是 **最差维度优先的尾部蒸馏**，并附带「可搬迁容量预算」：搬不动的鲁棒性维度必须显式留在云端，不能假装学生也拥有。

**灵感 4（双电池耦合：能量与可信度一起放电）**
直觉：物理电量低时，系统倾向选更省电但更保守的技能，动作覆盖变窄，证书裕度随之下降；边端过热降频时，只能运行更小的 student，`R_cert` 上升。也就是说，**物理电池的放电曲线与证书电池的放电曲线是相关的**。分开管理会低估联合失效概率；必须联合估计 `(β_t, κ_t)` 并共享温度、功率与分布漂移这些耦合变量。

**灵感 5（cell balancing → 证书维度均衡）**
直觉：电池包最怕某一节电芯先耗尽；证书最怕某一个鲁棒性维度先跌破阈值。与其平均地「充电」，不如把证据预算集中投给最弱维度，做 max-min 均衡：`max min_d m_d`。这把主动测试从「多采点数据」变成「按维度缺口定向补证」，也为云边回传提供了明确的预算分配信号。

**灵感 6（BMS 可观测性 → 证书电量不能直接测量）**
直觉：真实 BMS 的 SoC 是隐变量，只能靠库仑计数与锚点校准估计，误差会漂移。证书电量同样不可直接观测：它依赖对部署分布的假设、负载测试的覆盖与蒸馏迁移误差。因此必须跟踪估计漂移 `δ_est`，在漂移超限、周期到期或分布漂移超半径时触发**锚点重校准**；否则系统会带着「虚高电量」继续放行。

**灵感 7（从证书到生命周期 → 认证是一次充电，寿命是多次循环）**
直觉：部署不是一次性认证，而是反复的「蒸馏—适配—执行—回收」循环。每次循环都会消耗循环寿命。系统必须在签发证书时就预测 **剩余使用寿命 RUL**，并保证 `RUL ≥ 任务规划视野`；否则应在任务前安排重认证，而不是在任务中 fail-closed。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（物理电池状态与技能能量剖面）**
物理电池状态 `β_t = (SoC_t, SoH_t, T_t, R_int,t)`，其中 `SoC∈[0,1]`、`SoH∈(0,1]`、`T` 为温度、`R_int` 为内阻。技能 `S` 的能量剖面 `e_S : A → ℝ_{≥0}`（单次执行焦耳数），功率包络 `P_S : A → ℝ_{≥0}`。可用能量与功率上限随温度与健康度退化：
```
E_avail(t) = η(T_t) · (SoC_t - SoC_floor) · C_nom · SoH_t
P_max(t)   = P_nom · κ_T(T_t) · κ_H(SoH_t),   κ_T,κ_H ∈ (0,1]
```
动作 `a` 物理可行当且仅当 `P_S(a) ≤ P_max(t)` 且 `e_S(a) ≤ E_avail(t) - E_reserve`。

**定义 122（证书电量、证书健康度与容量）**
证书 `J` 的鲁棒性维度谱为 `ρ_d`，阈值为 `ρ_min(d)`。定义逐维裕度与容量：
```
m_d(J) = clip( (ρ_d - ρ_min(d)) / (1 - ρ_min(d)), 0, 1 )
Cap_now(J) = Σ_d w_d · m_d(J)
CSoC(J) = Cap_now(J) / Cap_max(J)          # 当前可交付比例
CSoH(J) = Cap_max(J) / Cap_0(J)            # 不可逆老化后的最大容量比
```
其中 `Cap_max` 是当前健康状态下、经补证后可达到的最大容量，`Cap_0` 是最初认证容量。部署要求 `CSoC ≥ CSoC_min` 且 `CSoH ≥ CSoH_min`；只有其中一个达标不足以放行。

**定义 123（证书内阻与负载跌落模型）**
设负载等级 `ℓ ≥ 0`（扰动幅度、分布移位、降频与热应力的合成标量），逐维观测裕度满足
```
ρ_obs,d(ℓ) = ρ_d - R_cert,d · ℓ + ε_d,     ε_d 为零均值有界噪声
ρ_eff,d(ℓ) = ρ_d - R̂_cert,d · ℓ
```
`R_cert,d ≥ 0` 为证书内阻，`R̂_cert,d` 为其置信上界。证书在负载 `ℓ_deploy` 下有效当且仅当
```
∀d:  ρ_eff,d(ℓ_deploy) ≥ ρ_min(d)  ∧  R̂_cert,d ≤ R_cert,max
```
高标称 `ρ_d` 但高 `R_cert,d` 的证书会在真实负载下「电压骤降」，这正是蒸馏虚标的主要形态。

**定义 124（证书蒸馏传输算子与容量衰减）**
蒸馏传输算子
```
D_λ : (π_T, J_T, D_k, λ) → (π_S, J_S)
```
其中 `π_T,π_S` 为 teacher/student 策略，`D_k` 为适配数据，`λ` 为容量预算与逐维权重。逐维传输保真度与容量衰减定义为
```
F_d = 1 - max(0, ρ_T,d - ρ_S,d)
Δ_cap = Σ_d w_d · max(0, ρ_T,d - ρ_S,d)
```
**证书保持蒸馏**要求：`Δ_cap ≤ Θ_cap`、`R̂_cert,S ≤ Θ_R`、且 `∀d: ρ_S,d ≥ ρ_min(d)`。注意 `Δ_cap` 是尾部/最差维度的损失，不是平均精度损失；平均精度可升、`Δ_cap` 仍可超预算。

**定义 125（双电池联合可行组合）**
组合路径 `P = ⟨S_1,...,S_k; a_1,...,a_k⟩`，总能耗
```
E(P) = Σ_i e_{S_i}(a_i) + Σ_i e_trans(S_i,S_{i+1})
```
`P` 可行当且仅当同时满足：
```
(i)   E(P) + E_reserve ≤ E_avail(t)
(ii)  max_i P_{S_i}(a_i) ≤ P_max(t)
(iii) ∀d: ρ_eff,d(P, ℓ_deploy) ≥ ρ_min(d)
(iv)  CSoC(J_P) ≥ CSoC_min ∧ CSoH(J_P) ≥ CSoH_min
(v)   T(t+Δ) ≤ T_max
```
记可行域为 `𝔽(β_t, κ_t)`；`E_reserve` 必须覆盖**安全中止 + 返航/回充**，而不是只覆盖当前任务。

**定义 126（证书电芯均衡）**
逐维电量 `m_d`，证据预算 `B`，单位裕度补证成本 `c_d`。均衡算子
```
Balance(J,B):  max_{Δm}  min_d (m_d + Δm_d)
              s.t.       Σ_d c_d·Δm_d ≤ B,  0 ≤ Δm_d ≤ 1 - m_d
```
即把有限证据优先投给最弱维度（等价于电池包的 max-min 电芯均衡），而不是平均加证。均衡后的证书 `J^bal` 应满足 `min_d m_d(J^bal) ≥ min_d m_d(J)`。

**定义 127（证书循环寿命与剩余使用寿命）**
循环计数 `n`（每次蒸馏、适配、重认证、深度放电各计一次）。容量老化模型
```
Cap_max(n) = Cap_0 · (1 - α·n^z - β_cycle·D̄)
R̂_cert(n) = R_0 + r_1·n + r_2·D̄
```
其中 `D̄` 为平均放电深度。寿命终止（EoL）条件：`Cap_max(n) < Cap_EoL` 或 `R̂_cert(n) > R_EoL`。剩余使用寿命
```
RUL(J) = min{ n' ≥ n : Cap_max(n') < Cap_EoL } - n
```
部署前必须验证 `RUL(J) ≥ H_plan`（任务规划视野），否则先重认证或缩小任务。

**定义 128（证书 BMS 可观测性与锚点重校准）**
真实 `CSoC` 不可直接观测。估计值 `ĈSoC` 由证据库仑计数、负载测试与老化模型联合得到，估计漂移
```
δ_est(t) = | ĈSoC(t) - CSoC(t) |
```
漂移随部署时长、循环数与分布移位增长。触发锚点重校准的条件为
```
δ_est > δ_max  ∨  n - n_anchor ≥ N_anchor  ∨  d_Ξ(ξ_deploy, ξ_anchor) > ε_anchor
```
重校准使用高成本验证探针，更新 `R̂_cert`、`Δ_cap` 与老化参数。未完成重校准且 `δ_est > δ_max` 时，系统必须 fail-closed 或降级到已验证的保守子集。

## 2. 关键算法 伪代码

### IP-121 CBS（Certificate Battery State Estimator）

```python
def estimate_dual_battery(beta_prev, cycles, evidence, load_log, thermal_log):
    beta = update_physical_battery(beta_prev, cycles, thermal_log)
    cap0 = certificate_initial_capacity(evidence)
    cap_max = cap0 * (1 - alpha * cycles.n**z - beta_cycle * cycles.D_bar)
    m = {d: margin(evidence.rho[d], RHO_MIN[d]) for d in DIMS}
    cap_now = sum(W[d] * m[d] for d in DIMS)
    csoc = cap_now / cap_max if cap_max > 0 else 0.0
    csoh = cap_max / cap0 if cap0 > 0 else 0.0
    r_hat = {d: ucb_internal_resistance(load_log, d) for d in DIMS}
    delta_est = abs(csoc - evidence.csoc_anchor) + drift_model(cycles, thermal_log)
    return BetaState(beta, csoc, csoh, r_hat, delta_est, cap_max)
```

### IP-122 CPT（Certificate-Preserving Distillation Transport）

```python
def distill_with_certificate(teacher, J_T, data, budget):
    student = init_student(teacher, budget)
    student = train_tail_weighted(
        student, teacher, data,
        loss = mean_kl(student, teacher)
             + lambda_tail * worst_dimension_loss(student, teacher, J_T)
             + lambda_margin * margin_regression(student, J_T))
    J_S = measure_certificate(student, probes=data.stress_probes)
    delta_cap = sum(W[d] * max(0.0, J_T.rho[d] - J_S.rho[d]) for d in DIMS)
    r_hat = load_test_internal_resistance(student, data.load_ladder)
    if delta_cap > THETA_CAP or any(J_S.rho[d] < RHO_MIN[d] for d in DIMS):
        return ('reject', 'capacity_fade', delta_cap)
    if max(r_hat.values()) > THETA_R:
        return ('reject', 'internal_resistance', r_hat)
    return ('ok', student, J_S, TransportCert(delta_cap, r_hat, J_T.version, J_S.version))
```

### IP-123 LDT（Load-Test Falsification）

```python
def load_test_internal_resistance(student, load_ladder, alpha=0.05):
    r_hat = {}
    for d in DIMS:
        pts = []
        for ell in load_ladder:
            rho_obs = stress_eval(student, d, ell)      # 最坏情形探针
            pts.append((ell, rho_obs))
        slope = robust_upper_slope(pts, alpha)          # 保守斜率上界
        r_hat[d] = max(0.0, -slope)                     # 负载越大裕度掉得越快
    return r_hat
```

### IP-124 ECR（Energy-Certificate Routing）

```python
def energy_certificate_route(G_S, task, beta, kappa):
    def edge_cost(u, v):
        return (w_e * energy_cost(u, v, beta)
                + w_r * margin_loss(u, v, kappa)
                + w_t * thermal_cost(u, v, beta)
                + w_i * kappa.r_hat[v] * load_estimate(task))
    path = a_star(G_S, start=task.start, goal=task.goal, cost=edge_cost)
    E = total_energy(path)
    if E + E_reserve(path, beta) > E_avail(beta):
        return ('reject', 'energy_shortfall', E)
    if not all(rho_eff(path, d, load_estimate(task)) >= RHO_MIN[d] for d in DIMS):
        return ('reject', 'certificate_sag', path)
    if min_margin(path) < CSOC_MIN or csoh(path) < CSOH_MIN:
        return ('reject', 'certificate_low', path)
    return ('ok', path, JointBudget(E, E_reserve, margin_path(path)))
```

### IP-125 CBB（Certificate Battery Balancing）

```python
def balance_certificate(J, evidence_budget, cost):
    order = sorted(DIMS, key=lambda d: margin(J, d))   # 最弱维度优先
    delta = {d: 0.0 for d in DIMS}
    for d in order:
        need = 1.0 - margin(J, d) - delta[d]
        take = min(need, evidence_budget / max(cost[d], 1e-9))
        delta[d] += take
        evidence_budget -= cost[d] * take
        if evidence_budget <= 0:
            break
    return apply_evidence(J, delta), evidence_budget
```

### IP-126 CLM（Certificate Lifecycle Manager）

```python
def lifecycle_gate(J, cycles, mission_horizon):
    rul = remaining_useful_life(cycles)
    if rul < mission_horizon:
        return ('recertify_now', rul)
    if J.delta_est > DELTA_MAX or cycles.since_anchor >= N_ANCHOR:
        J = anchor_recalibrate(J)
        if J.delta_est > DELTA_MAX:
            return ('fail_closed', 'unobservable_certificate')
    if J.csoh < CSOH_MIN or J.r_hat_max > R_CERT_MAX:
        return ('recertify', 'eol_approaching')
    return ('deploy', J)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CBS | `O(|𝔇_ρ| + |L| log |L|)` | `O(|𝔇_ρ|+|L|)` | 负载上界 UCB、漂移可观测 |
| CPT | `O(E_distill + |L|·|𝔇_ρ|)` | `O(|π_S|+|𝔇_ρ|)` | 尾部损失、逐维容量预算 |
| LDT | `O(|L|·|𝔇_ρ|)` | `O(|L|)` | 负载阶梯覆盖真实负载谱 |
| ECR | `O(|V| log |V| + |E|)` | `O(|V|+|E|)` | 能量预留闭合、裕度单调 |
| CBB | `O(|𝔇_ρ| log |𝔇_ρ|)` | `O(|𝔇_ρ|)` | max-min 均衡、成本可加 |
| CLM | `O(|𝔇_ρ|)` | `O(1)` | 老化模型校准、锚点及时 |

**正确性定理（Distilled Energy-Aware Composition Soundness）**
假设第 54 轮 (A26)–(A28) 成立，并新增：
**(A29)** 物理电池模型与能量剖面经标定，`E_avail` 取下界；
**(A30)** 负载测试的斜率上界 `R̂_cert,d` 以置信度 `1-α` 覆盖真实 `R_cert,d`；
**(A31)** 蒸馏容量衰减满足 `Δ_cap ≤ Θ_cap` 且逐维均被负载测试复核；
**(A32)** 证书电量估计漂移 `δ_est ≤ δ_max`，锚点重校准在 `N_anchor` 内完成；
**(A33)** 热模型与降频曲线取保守包络。
则对任意满足 `P ∈ 𝔽(β_t,κ_t)` 的部署路径，任务成功概率满足
```
P_success(P) ≥ 1 - Σ_d (1 - ρ_eff,d(ℓ_deploy))
              - P(E_shortfall) - P(T > T_max)
              - P(Δ_cap > Θ_cap) - P(R_cert > R̂_cert)
              - P(δ_est > δ_max) - β_E
```
关键：**能量可行只是必要条件，证书电量与内阻必须同时过载测试**；**蒸馏只可在容量预算内搬迁，不能把未测试维度默认视为安全**；**证书电量必须锚点重校准，不能靠库仑计数无限外推**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 负载阶梯未覆盖真实负载谱，`R_cert` 外推失真 | 高 | 负载谱分层采样 + UCB + 超预算一律拒绝 |
| `CSoC` 估计与策略共享盲区，漂移在分布外突增 | 高 | 独立锚点探针 + 联合估计 + 漂移超限 fail-closed |
| 蒸馏只测平均值，漏掉尾部鲁棒性维度 | 高 | 逐维容量预算 + worst-case 探针 + 未测维度默认不认证 |
| 能量预留过于保守，任务可用性下降 | 中 | 按返航/中止成本自适应预留 + 任务前预算规划 |
| 老化模型与真实循环寿命失配 | 中 | 在线辨识 `α,z,r_1,r_2` + 早期重认证 |
| 热-算力-证书三者耦合导致级联降级 | 高 | 热降频曲线入证书模型 + 温度触发保守子集 |

## 6. 本轮最大风险

**一句话**：把证书类比为电池很有解释力，但最大的风险是**负载测试覆盖不到真实部署的负载谱，而 `CSoC` 估计器又与策略共享同一组分布假设**；此时一个「高电量、高健康度」的证书仍可能在能量紧张、热降频与分布外扰动同时到来时发生相关崩塌，因此必须坚持 **负载测试驱动 + UCB 内阻上界 + 锚点重校准 + 未测维度默认不认证**，宁可保守拒绝，也不把空载电压当作带载能力。

### IP-121 CBS（Certificate Battery State）

```python
def margin(rho_d, rho_min_d):
    return clip((rho_d - rho_min_d) / (1.0 - rho_min_d), 0.0, 1.0)

def update_physical_battery(beta_prev, cycles, thermal_log):
    T = thermal_model(beta_prev.T, cycles.load_profile)
    soh = max(0.0, beta_prev.soh - fade_physical(cycles, T))
    r_int = r_int_prev + aging_r(cycles, T)
    return BetaState(soC=beta_prev.soC, soH=soh, T=T, R_int=r_int)

def estimate_dual_battery(beta_prev, cycles, J_evidence, load_log, thermal_log):
    beta = update_physical_battery(beta_prev, cycles, thermal_log)
    cap0 = J_evidence.cap0
    cap_max = cap0 * (1.0 - alpha * cycles.n**z - beta_cycle * cycles.D_bar)
    m = {d: margin(J_evidence.rho[d], RHO_MIN[d]) for d in DIMS}
    cap_now = sum(W[d] * m[d] for d in DIMS)
    csoc = safe_div(cap_now, cap_max)
    csoh = safe_div(cap_max, cap0)
    r_hat = {d: ucb_resistance(load_log, d, level=0.95) for d in DIMS}
    drift = workload_drift(cycles, thermal_log) + |csoc - J_evidence.csoc_anchor|
    return CertBattery(beta, csoc, csoh, r_hat, drift, cap_max)
```

### IP-122 CPT（Certificate-Preserving distillation Transport）

```python
def distill_transport(teacher, J_T, data, budget):
    S = init_student(teacher, budget)
    S = train(
        S, data,
        loss = kl(S, teacher)
             + LAMBDA_TAIL * worst_dimension_loss(S, teacher, J_T, DIMS)
             + LAMBDA_MARGIN * margin_regression(S, J_T, data.stress_probes))
    J_S = certify(S, data.stress_probes)
    delta_cap = sum(W[d] * max(0.0, J_T.rho[d] - J_S.rho[d]) for d in DIMS)
    r_hat = load_test_internal_resistance(S, data.load_ladder)
    if delta_cap > THETA_CAP:
        return Reject('capacity_fade', delta_cap)
    if any(J_S.rho[d] < RHO_MIN[d] for d in DIMS):
        return Reject('dimension_below_threshold', J_S.rho)
    if max(r_hat.values()) > THETA_R:
        return Reject('internal_resistance', r_hat)
    return Ok(S, J_S, TransportCert(delta_cap, r_hat, J_T.version, J_S.version))
```

### IP-123 LDT（Load-test Falsification）

```python
def load_test_internal_resistance(student, load_ladder, alpha=0.05):
    r_hat = {}
    for d in DIMS:
        xs, ys = [], []
        for ell in load_ladder:
            rho_obs = stress_eval(student, d, ell)   # 对抗/降频/分布外联合探针
            xs.append(ell); ys.append(rho_obs)
        slope_ub = robust_upper_slope(xs, ys, alpha)
        r_hat[d] = max(0.0, -slope_ub)
    return r_hat

def load_test_gate(J_S, r_hat, ell_deploy):
    for d in DIMS:
        if J_S.rho[d] - r_hat[d] * ell_deploy < RHO_MIN[d]:
            return Reject('certificate_sag', d,
                          J_S.rho[d] - r_hat[d] * ell_deploy, RHO_MIN[d])
    return Ok('load_test_passed')
```

### IP-124 ECR（Energy-Certificate Routing）

```python
def energy_certificate_route(G_S, task, beta, kappa):
    ell = load_estimate(task, beta, kappa)
    def edge_cost(u, v):
        return (W_E * energy_cost(u, v, beta)
                + W_R * margin_loss(u, v, kappa)
                + W_T * thermal_cost(u, v, beta)
                + W_I * kappa.r_hat[v] * ell)
    path = a_star(G_S, task.start, task.goal, heuristic=edge_cost)
    E = total_energy(path) + transition_energy(path)
    E_res = abort_energy(path) + return_energy(path, beta) + SAFETY_MARGIN
    if E + E_res > E_avail(beta):
        return Reject('energy_shortfall', E, E_res, E_avail(beta))
    if max(power(path)) > P_max(beta):
        return Reject('power_limit', max(power(path)), P_max(beta))
    rho_path = compose_effective_robustness(path, kappa.r_hat, ell)
    if any(rho_path[d] < RHO_MIN[d] for d in DIMS):
        return Reject('certificate_sag', rho_path)
    J_P = compose_certificate(path, kappa)
    if J_P.csoc < CSOC_MIN or J_P.csoh < CSOH_MIN:
        return Reject('certificate_low', J_P.csoc, J_P.csoh)
    if thermal_projection(beta, path) > T_MAX:
        return Reject('thermal_budget', thermal_projection(beta, path))
    return Ok(path, JointBudget(E, E_res, rho_path, J_P))
```

### IP-125 CBB（Certificate Battery Balancing）

```python
def balance_certificate(J, budget, unit_cost):
    delta = {d: 0.0 for d in DIMS}
    for d in sorted(DIMS, key=lambda x: margin(J, x)):
        need = 1.0 - margin(J, d) - delta[d]
        take = min(need, budget / max(unit_cost[d], EPS))
        delta[d] = take
        budget -= unit_cost[d] * take
        if budget <= EPS:
            break
    J_bal = apply_evidence(J, delta)
    assert min(margin(J_bal, d) for d in DIMS) >= min(margin(J, d) for d in DIMS)
    return J_bal, budget

def targeted_probe_policy(J, probe_pool, budget):
    # 选择“单位成本提升最弱维度 min-margin”的探针子集
    return greedy_max_min_cover(probe_pool, J, budget, cost=lambda p: p.cost)
```

def lifecycle_gate(J, cycles, mission_horizon):
    rul = remaining_useful_life(cycles)   # 由 Cap_max(n), R_hat(n) 预测
    if rul < mission_horizon:

                   or cycles.scene_shift > EPS_ANCHOR)

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CBS | `O(|𝔇_ρ|+|L| log|L|)` | `O(|𝔇_ρ|+|L|)` | 内阻 UCB 覆盖、漂移有界 |
| CPT | `O(E_distill+|L|·|𝔇_ρ|)` | `O(|π_S|+|𝔇_ρ|)` | 尾部损失 + 逐维容量预算 |
| LDT | `O(|L|·|𝔇_ρ|)` | `O(|L|)` | 负载谱覆盖、斜率保守 |
| ECR | `O(|V| log|V|+|E|)` | `O(|V|+|E|)` | 能量预留闭合、裕度单调衰减 |
| CBB | `O(|𝔇_ρ| log|𝔇_ρ|)` | `O(|𝔇_ρ|)` | max-min 不减、成本可加 |
| CLM | `O(|𝔇_ρ|)` | `O(1)` | 老化模型校准、锚点及时 |

**正确性定理（Distilled Energy-Aware Composition Soundness）**
假设第 54 轮 (A26)–(A28) 成立，并新增：
**(A29)** 物理电池模型与能量剖面经标定，`E_avail` 与 `P_max` 取保守下界；
**(A30)** 负载测试的逐维斜率上界 `R̂_cert,d` 以置信度 `1-α` 覆盖真实 `R_cert,d`；
**(A31)** 蒸馏满足 `Δ_cap ≤ Θ_cap`，且每个维度都经过负载测试复核；
**(A32)** `δ_est ≤ δ_max`，锚点重校准在 `N_anchor` 内完成；
**(A33)** 热模型与降频曲线取保守包络。
则对任意 `P ∈ 𝔽(β_t,κ_t)`：
```
P_success(P) ≥ 1 - Σ_d (1 - ρ_eff,d(ℓ_deploy))
              - P(E_shortfall) - P(T > T_max)
              - P(Δ_cap > Θ_cap) - P(R_cert > R̂_cert)
              - P(δ_est > δ_max) - β_E
```
证明要点：
1. 由 (A29)，能量与功率约束是真实可用资源的保守下界，`E_shortfall` 只会被高估。
2. 由 (A30)，`ρ_eff,d = ρ_d - R̂_cert,d·ℓ` 是真实带载裕度的下界；ECR 的 (iii) 因此保证每个维度真实裕度不低于阈值。
3. 由 (A31)，student 证书的逐维容量衰减被显式预算约束，未通过负载测试的维度不得进入 `J_S`。
4. 由 (A32)，`CSoC` 的估计误差在部署期间有界；超过界即 fail-closed，不会用虚高电量继续放行。
5. 由 (A33)，热约束是保守的，`T > T_max` 事件被纳入失败预算。
6. 其余项承接第 54 轮的动作错位与 Explain 回传误差。

**关键不对称**：蒸馏只允许在**容量预算内**近似 teacher 的搜索/策略；证书求值、负载测试与 fail-closed 保护**不允许被蒸馏**。学生误差只损失可用性，不损失 soundness。
