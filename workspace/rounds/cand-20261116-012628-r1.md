# 第 12 轮（新灵感循环第 1 轮；本轮灵感：「多传感器融合」×「场景驱动创新」）
> **基线**：第 11 轮 MetricVoiceGauge-GSCF-SRA-JSSE（定义 549–561；引理 92–96；实验 E591–E610）。
> 本轮纪律：**交集取证 + 场景受权 + 格上退化**。三个词分别治理 v11 的三种残余债：**单证人债**（几何一致性只走深度/点云一条通道，透明、反光、强遮挡使其虚假低——上轮自认最大风险，或与对抗同源而虚假高）、**常数债**（γ_min、τ_sem、λ、β 是跨场景全局常数，易场景过保守、难场景欠保守，且“调参”无证据边界）、**阶梯债**（退化链是九个平铺 Level，无法表达“深度坏了但 IMU/力觉/轮速仍足证”，多重同时失效只能急停）。铁律不变：任一新模块失效 ⇒ 注入声明中立元，行为严格**等价**（对 MMEF/SCC）或**支配**（对 FHA）于 v11；正常时也只允许在**有覆盖合同**的场景内收紧余量，绝不凭空扩权。

## 0. 直觉与动机

**灵感 1（多传感器融合 → 从单证人残差到交集取证）**
直觉：v11 的 γ_ℓ 是“一条证据通道给出的残差”，它把两件事混为一谈——**物体真的变了**，还是**这条通道坏了**（透明/反光/遮挡使深度失效）。多传感器融合的正确形态不是加权平均（平均在源矛盾时会造出谁都不支持的折中值，恰好把故障抹平），而是**交集取证**：每个源携带标定置信区间，只有在区间彼此相容时才取交集、收紧误差界；交为空即**冲突**，而冲突是安全信号，不是需要被平滑掉的噪声。核心创新：**多模态证据融合（MultiModalEvidenceFusion, MMEF）**——有效见证集 W_ℓ + 区间交集算子 ⊞ + 冲突统计 κ_ℓ；无冲突时融合半径 rad^⊞≤min_i ε_i（**不比最好单源更宽**，因此不会引入新保守税），有冲突时 γ^⊞=0 并切保守剖面。这正面拆除 v11 的“单通道虚假低”风险：一条坏通道会被“不相容”暴露为冲突，而不是把 γ 拖低；同时也正面识别“全体一致地假”（共同模式失效）——若源共享标定偏差，κ 会虚假地小，这是本轮必须显式承认的边界。

**灵感 2（场景驱动创新 → 场景卡即受权证书，不是特权）**
直觉：v11 用一套全局常数覆盖所有场景，本质是“用最坏场景的余量给最好场景付税”；而真正的场景创新应是**参数随场景、但权力受证据约束**。核心创新：**场景条件证书（ScenarioConditionedCertificate, SCC）**——场景卡 s=(σ_s, π_s, C_s, B_s) 是**声明式数据**：可测签名 σ_s、证书参数剖面 π_s、**覆盖合同** C_s（在该场景分布上误差被 β_s 覆盖的概率 ≥1−ε_s）、**证据预算** B_s（标定/测试/内存/算力）。运行时识别器只做一件事：在**已离线认证的场景库**里选择；识别置信不足、签名越界、或与融合证据冲突 ⇒ 落到未知场景最保守剖面 π_⊥。关键纪律 **P17 场景只降不升律**：运行时永远不能创建或激活新场景，新场景只能被“提名为候选卡”写入台账、待离线认证；因此场景创新发生在实验台上，不发生在控制回路里。

**灵感 3（“场景 × 融合”咬合 → 退化格取代退化阶梯）**
直觉：多源融合真正的红利不是更准，而是**多重失效下仍有可证退化路径**——深度失效时，IMU+轮速+力/触觉+关节编码器仍可支撑关节空间包络与更小 K，而不必直接急停。v11 的九个平铺 Level 表达不了这种偏序。核心创新：**融合健康仲裁器（FusionHealthArbiter, FHA）+ 退化格 D=(2^E,⊆)**：失效集合 F 映射到“仍满足覆盖合同的最大剖面” π*(F)=⊓{π_s}，失效越多，meet 越保守（P18 单调律）；只有 meet 落到 ⊥（无任何可证剖面）才急停。这把 v11“三重守护同时失效只能急停”的悬崖，改成“可证的逐级收权”。

三者咬合：MMEF 出**相容性证据**（谁可信、何处冲突），SCC 出**受权场景剖面**（在该场景能收紧到多紧），FHA 出**失效偏序下的最大可证剖面**——共同把 v11 的 Ĉ_t⁺⁺ 升级为**取证-受权证书 Ĉ_t^{*} = (ĝ_min, ê_max, γ̂_grasp, β_MMEF, n_t, n_t^reason, Q_abort, ŝ, π_ŝ, κ, n_t^scen)**。

## 1. 研究问题（轮次升级版）

- **Q1（交集取证）**：如何用异构源的标定置信集做**交集**而非平均，使无冲突时融合半径 rad^⊞≤min_i ε_i（不引入新保守税）、透明/反光/动态导致的单通道虚假低被冲突或剔除抑制（虚假低率 ↓≥90%），且冲突误报率 ≤ε_conf=1%？
- **Q2（场景受权）**：如何把证书参数形式化为场景卡数据 + 覆盖合同 + 证据预算，使认识场景内余量收紧（β ↓≥20%）而覆盖率 ≥99%，未知/歧义/迁移场景落到 π_⊥，且运行时不可能自授权新场景？
- **Q3（格上退化）**：如何用退化格为每个传感器/模块失效集合选出最大可证剖面，使多重同时失效下优雅退化率 ↑、急停仅在 ⊥ 发生，且物理行为始终 ⊆ v11 可行集（支配性）？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 融合冲突即收缩律（Fusion-Conflict-Shrink, MMEF）**
异构源只许在置信集**非空交集**下收紧误差界；交为空或 κ>κ_max 时**禁止平均、禁止取中位数**，必须把冲突作为异常/场景歧义触发收缩。融合的独立性假设被违反（共同模式失效）时，其结论自动失效并回退 v11 单通道 + Δ_dom 标量门控。

**P17 场景只降不升律（Scenario-Monotone-Authority, SCC）**
场景识别只能从**离线认证且版本锁定**的场景库中选择剖面；运行时不得创建、激活或放松场景。识别置信不足、签名越界、融合冲突 ⇒ π_⊥（对所有 π_s 最保守）。任何新场景只能以“候选卡”入台账，须离线补证据预算后方可入网。

**P18 退化格单调律（Degradation-Lattice-Monotone, FHA）**
同时失效按格 meet 处理：F₁⊆F₂ ⇒ π*(F₂) ⊑ π*(F₁)（权力不增）；存在可证剖面即优雅退化，仅当 meet=⊥ 才急停；投影/仲裁只剪枝不生成新命令。

## 3. 与基线的接口（如何退化）

- MMEF 失效（见证不足 |W_ℓ|<2 / 标定过期 / 时钟失步）⇒ γ^⊞←γ_GSCF、rad^⊞←0、κ 不参与：等价 v11 GSCF 行为（单通道、承认其风险）；
- SCC 失效（识别器超时/OOD 拒识/场景库不可用）⇒ π←π_⊥，且 π_⊥ 比 v11 全局剖面**更保守或相等**：支配 v11；
- FHA 失效（仲裁超时/格映射损坏）⇒ 回落 v11 九级平铺退化链：等价 v11；
- GSCF 失效 ⇒ v11 Level-1（γ≡1、ν̂←ν、β←β_STF）；SRA 失效 ⇒ n^reason 全 0、K_eff←2；JSSE 失效 ⇒ 关节级急停保持（v6）；其余沿 v11 → v10 → … 链。
- 安全守卫 MMEF/SCC/FHA 一律 φ^elig=false 永不消融；仅“场景卡离线构建/融合权重离线标定”可蒸馏。

## 4. 预期贡献

1. **交集取证证书**：以“相容才收紧、冲突即收缩”替代单通道残差与朴素平均，几何虚假低率 ↓≥90%、β 在相容场景 ↓20–40%，同时把“平均掩盖故障”这一类经典失效显式排除（引理 97–98）；
2. **可受权场景创新**：场景卡 = 签名 + 剖面 + 覆盖合同 + 证据预算，运行时只降不升；未知/歧义场景保守回落（引理 99）；
3. **格上优雅退化**：多重同时失效下按 meet 逐级收权，急停从“常态兜底”变为“仅在 ⊥”的最后手段（引理 100）；
4. **E611–E630** 覆盖源标定、冲突阈值、透明/动态/遮挡、共同模式欺骗、场景覆盖与误分类、迁移、格退化、长跑与竞赛。

## 5. 本轮最大风险

**一句话**：MMEF 的可靠性建立在“源间误差独立且各自已标定”之上，而真实系统常共享标定偏差、共视退化或可被**相干欺骗**（同一物理伪造同时骗过深度与语义），此时 κ 虚假地小、融合界虚假地紧；更危险的是 SCC 的识别器可能**高置信地把分布外/对抗输入判成一个更宽松的已认证场景**，于是一切检查都“在库内、无冲突”地通过，证书对**错误的场景**严格保守而对真实场景失效——这是比 v11 单通道虚假低更隐蔽的失效，因为系统有了“看起来可审计”的场景卡作背书。

| π*(F) | 退化格 meet：失效集 F 下仍满足覆盖合同的最大剖面，π*(F)=⊓{π_s : s 可证且 F 下证据仍覆盖 σ_s} |
| Ĉ_t^{*} | 取证-受权块证书 (ĝ_min, ê_max, γ̂_grasp, β_MMEF, n_t, n_t^reason, Q_abort, ŝ, π_ŝ, κ_Φ, n_t^scen) |

**新增定义 562（异构见证与标定误差模型）** 每个地标 ℓ 的可测几何量 x_ℓ（相对位姿、深度、触点位移、关节反力一致性等），源 i 给出估计 x̂_{i,ℓ} 与残差 r_{i,ℓ}=‖x̂_{i,ℓ}−x^ref_ℓ‖，并携带标定置信半径 ε_i、失效概率 δ_i、标定域 D_i 与有效谓词 Val_i，满足：在 D_i∧Val_i 下 P(r_{i,ℓ}≤ε_i)≥1−δ_i。**ε_i、δ_i、D_i 均来自 E611 标定，不是手调常数**；换传感器需重标定并更新场景卡证据预算 B_s。

**新增定义 563（有效见证集）** W_ℓ(t) = {i∈E | Val_i(ℓ,t)=1 ∧ fresh_i≤T_fresh,i ∧ ctx∈D_i}。被排除的源只允许**加宽**融合界（保守），绝不允许被静默当作“一致见证”参与收紧。

**新增定义 564（交集融合算子 ⊞）** 对 i∈W_ℓ，置 I_{i,ℓ}=[r_{i,ℓ}−ε_i, r_{i,ℓ}+ε_i]。定义
```
I_sep^⊞ = [l^⊞, u^⊞],  l^⊞ = max_{i∈W}(r_{i,ℓ}−ε_i),  u^⊞ = min_{i∈W}(r_{i,ℓ}+ε_i)
I^⊞_ℓ = I_sep^⊞  若 l^⊞ ≤ u^⊞；否则 I^⊞_ℓ = ∅
r^⊞_ℓ = (l^⊞+u^⊞)/2,  rad^⊞_ℓ = (u^⊞−l^⊞)/2   （非空时）
```
**关键纪律：用交不用加权平均。** 平均在源矛盾时给出一个谁都不支持的“折中残差”，可把故障抹成正常；交集只在**所有见证都支持**的区域内收紧，因而天然排除该类失效。

**新增定义 565（冲突统计与阈值）** 当 I^⊞=∅ 或近空时，定义
```
κ_ℓ = [l^⊞ − u^⊞]_+ / (Σ_{i∈W} ε_i + ε_0)
```
κ_ℓ>κ_max ⇒ **冲突事件**。κ_max 由 E611 在“所有源有效且同分布”的零假设下标定，使误报率 ≤ε_conf=1%；ε_0 为防止分母为零的标定小量。冲突不是噪声，是**显式异常 / 场景歧义**，进入守卫与台账。

**新增定义 566（融合几何一致性）** 无冲突时 γ^⊞_ℓ = exp(−r^⊞_ℓ/τ_geo)，且 rad^⊞_ℓ 计入余量；冲突时 γ^⊞_ℓ=0（**声明异常**，而非“低置信地正常”）。联合创新度沿用 v11：ν̂_ℓ=max(ν_ℓ, 1−γ^⊞_ℓ)。由此，v11 中“一条通道坏了把 γ 拖低”或“一条通道被伪造把 γ 抬高”都被结构性改写：前者以冲突暴露，后者需同时骗过全部见证（见引理 101 的条件）。

**新增定义 567（融合信任场与 β_MMEF）** Γ^⊞ 为 γ̄^⊞ 的核加权场（同 T/Γ 的核与 5 帧 EMA）。融合余量：
```
β_MMEF(ζ,t) = β_base + λ·sup_{x∈Φ(ζ)} max(T(x,t), 1−Γ^⊞(x,t))
                     + λ_r·sup_{x∈Φ(ζ)} rad^⊞(x,t)
                     + λ_κ·1[Φ(ζ) 内存在冲突地标]
```
其中 rad^⊞(x) 为 rad^⊞_ℓ 的同核场。**若源相容**，rad^⊞_ℓ≤min_{i∈W}ε_i（交集是每个区间的子集），故 β_MMEF 相对“最好的单源”不会更保守；若源不相容，冲突项与 γ^⊞=0 双重抬高余量，永不更松。

**新增定义 568（场景卡）** 场景卡为声明式数据
```
s = (σ_s, π_s, C_s, B_s)
σ_s : 可测签名（光照分位、动态目标数、材质类别、遮挡比、人密度、传感器健康模式等）
π_s : (K_max,s, τ_sem,s, γ_min,s, λ_s, β_base,s, w_{i,s}, 守卫阈值)
C_s : 覆盖合同 —— 在 P_s 上 P(sup‖F̂_q−F‖ ≤ β_MMEF(π_s)) ≥ 1−ε_s（目标 ε_s≤1%）
B_s : 证据预算 —— 标定集规模、场景测试覆盖率、内存 M_s、能耗 E_s、时延预算
```
场景库 S 为版本化、哈希链锁定的只读数据；|S|≤64。**场景卡不是配置开关，是携带证明义务的证书数据**：改 π_s 必须重跑 C_s 覆盖，否则卡片作废。

**新增定义 569（场景识别与受权）** 识别器 R 输出 (ŝ,p̂,margin)。受权条件：
```
n_t^scen = 1  ⇔  ŝ∈S ∧ p̂≥τ_sc ∧ margin≥m_min ∧ π_ŝ 版本与台账锁一致
```
margin 为与次优场景的可分裕度。n_t^scen=0 ⇒ 场景未知/歧义 ⇒ π←π_⊥。**P17**：R 只能**选择** S 中剖面，不能修改 π、不能新增 s；R 的“候选新场景”只写台账不入控制。

**新增定义 570（未知场景保守剖面）** π_⊥ =(K_max=1, τ_sem=inf_s τ_sem,s, γ_min=sup_s γ_min,s, β_base=sup_s β_base,s, w=最保守源权)。定义偏序 π_a ⊑ π_b ⇔ A(π_a)⊆A(π_b)（π_a 不更宽松）。则 π_⊥ ⊑ π_s 对一切 s 成立，且 π_⊥ ⊑ v11 全局剖面。**任何识别失败都落到 π_⊥，故行为支配于 v11**（引理 99）。

**新增定义 571（场景迁移守卫）** 场景切换（ŝ 变化或 p̂ 跌破 τ_sc 或 margin<m_min）视为**安全相关事件**：50Hz 守卫检 6b 失败；若发生在中块，立即切最近 Q_abort 并置块失效，下一 5Hz 周期以 π_ŝ 重新生成。设滞回 h_sc 抑制抖动：只有连续 l≥2 个周期一致且 δp̂≥h_sc 才确认切换；抖动次数入台账。

**新增定义 572（退化格）** D=(2^E,⊆) 为失效集合的布尔格。对 F∈2^E，定义
```
π*(F) = ⊓ { π_s : s∈S 且 F 下仍存在源集覆盖 σ_s 且 C_s 可证 }
```
⊓ 取更保守者（K 更小、τ_sem 更严、γ_min 更高、β_base 更大）。**单调性（P18）**：F₁⊆F₂ ⇒ π*(F₂)⊑π*(F₁)。F=E（全失效）⇒ π*(E)=⊥（急停保持，v6）。

**新增定义 573（融合健康仲裁器 FHA）** 维护失效位图、W_ℓ、κ、源健康度；每 5Hz 块边界计算 π*(F) 并交给 AC/守卫；每 1kHz 只做 O(1) 位图健康检查。FHA **只选择剖面、只剪枝命令**，不生成新任务/关节命令。FHA 失效 ⇒ 回落 v11 九级平铺退化链。

**新增定义 574（场景卡证据预算与不可自授权）** 每张 s 绑定 B_s；部署期静态校验 Σ_s M_s ≤ RAM_scen、Σ_s E_s ≤ E_scen，且 C_s 需 ≥N_s 个独立评测片段。运行期 S 只读、版本哈希写入台账；**新场景从提出到活化必须在离线环节完成认证**，运行期任何“学习到的新场景”只能是候选记录（不参与控制）。

**新增定义 575（六检守卫）** 50Hz 守卫在 v11 五检基础上增两检，合称六检：(i) 证书有效；(ii) 停车不变式；(iii) 语义创新度 sup ν̄≤τ_sem；(iv) 快规范；(v) 几何一致性 inf γ̄≥γ_min；(vi-a) **融合无冲突** κ_Φ≤κ_max；(vi-b) **场景受权** n_t^scen=1 且 π_ŝ 与当前一致。任一失败 ⇒ 切最近中止点 p* 对应 q_abort，JSSE 接管。总预算 ≤0.8ms（v11 为 0.6ms，新增 ≤0.2ms）。

**新增定义 576（台账扩展）** Λ 新增记录：每次融合的见证集 W_ℓ 与 rad^⊞、每次冲突事件 κ_ℓ、场景判定 (ŝ,p̂,margin) 与切换、退化格选择 π*(F) 及失效位图、场景卡/合同版本哈希。哈希链 κ_h=256 不变；缺口触发 π_⊥（沿用 v10 台账缺口律）。

```python
# IP-365 MultiModalEvidenceFusion：交集取证（不平均）
class MultiModalEvidenceFusion:
    def __init__(self, sources, eps, delta, kappa_max, tau_geo=0.05,
                 lam=0.5, lam_r=1.0, lam_kappa=2.0, ema=0.2):
        self.sources, self.eps, self.delta = sources, eps, delta
        self.kappa_max, self.tau_geo = kappa_max, tau_geo
        self.lam, self.lam_r, self.lam_kappa, self.ema = lam, lam_r, lam_kappa, ema

    def witness_set(self, ell, t, ctx):
        return [i for i in self.sources
                if self.sources[i].valid(ell, t)          # Val_i
                and self.sources[i].fresh(t) <= self.sources[i].T_fresh
                and ctx in self.sources[i].domain]        # D_i

    def fuse(self, ell, t, ctx):
        W = self.witness_set(ell, t, ctx)
        if len(W) < 2:                                   # 单证人 ⇒ 不融合
            return None                                  # 调用方回退 γ_GSCF
        lo = max(self.sources[i].residual(ell) - self.eps[i] for i in W)
        hi = min(self.sources[i].residual(ell) + self.eps[i] for i in W)
        if lo <= hi:
            r = 0.5 * (lo + hi)
            rad = 0.5 * (hi - lo)                        # ≤ min_i eps_i
            gamma = math.exp(-r / self.tau_geo)
            ell.gamma_hat = self.ema * gamma + (1 - self.ema) * ell.gamma_hat
            ell.rad_hat = self.ema * rad + (1 - self.ema) * ell.rad_hat
            ell.kappa = 0.0
            ell.conflict = False
        else:
            ell.gamma_hat = 0.0                          # 冲突 ⇒ 显式异常
            ell.kappa = (lo - hi) / (sum(self.eps[i] for i in W) + 1e-9)
            ell.conflict = True
        ell.nu_hat = max(ell.nu_bar, 1 - ell.gamma_hat)
        return W, ell.kappa, ell.conflict

    def field_on_footprint(self, path):
        sup_T = max((self.stf.T(x) for x in path.corridor_samples()), default=0.0)
        sup_G = max((1 - self.Gamma(x) for x in path.corridor_samples()), default=0.0)
        sup_r = max((self.Rad(x) for x in path.corridor_samples()), default=0.0)
        has_conflict = any(ell.conflict for ell in self.stf.map.landmarks_in(path))
        return (sup_T, sup_G, sup_r, has_conflict)

    def beta(self, path):
        sup_T, sup_G, sup_r, conflict = self.field_on_footprint(path)
        return (self.beta_base + self.lam * max(sup_T, sup_G)
                + self.lam_r * sup_r
                + self.lam_kappa * (1.0 if conflict else 0.0))


# IP-366 ScenarioConditionedCertificate：场景卡即受权数据
class ScenarioConditionedCertificate:
    def __init__(self, library, recognizer, tau_sc=0.8, m_min=0.15,
                 h_sc=0.05, confirm_len=2):
        self.library = library          # 只读、版本哈希锁定，|S|≤64
        self.recognizer = recognizer    # 轻量分类器，输出 (s_hat, p_hat, margin)
        self.tau_sc, self.m_min = tau_sc, m_min
        self.h_sc, self.confirm_len = h_sc, confirm_len
        self.current, self.pending_n = None, 0

    def authorize(self, fused_evidence, ctx):
        s_hat, p_hat, margin = self.recognizer(fused_evidence, ctx)
        ok = (s_hat in self.library
              and p_hat >= self.tau_sc
              and margin >= self.m_min
              and self.library.version_ok(s_hat, ctx))
        if not ok:
            return self.library.pi_bottom, dict(n_scen=0, s_hat=s_hat,
                                                p_hat=p_hat, margin=margin)
        return self.library.profile(s_hat), dict(n_scen=1, s_hat=s_hat,
                                                 p_hat=p_hat, margin=margin)

    def transition_guard(self, s_hat, p_hat, margin):
        if self.current is None:
            self.current, self.pending_n = s_hat, 0
            return False
        changed = (s_hat != self.current or p_hat < self.tau_sc
                   or margin < self.m_min)
        self.pending_n = self.pending_n + 1 if changed else 0
        confirmed = changed and self.pending_n >= self.confirm_len
        if confirmed:
            self.current, self.pending_n = s_hat, 0
        return confirmed            # 确认迁移 ⇒ 中块立即中止并重生成


# IP-367 FusionHealthArbiter：退化格 meet，选最大可证剖面
class FusionHealthArbiter:
    def __init__(self, sources, library, v11_ladder):
        self.sources, self.library = sources, library
        self.v11_ladder = v11_ladder
        self.failed = set()

    def update_health(self, health_bits):          # 1kHz：O(|E|)
        self.failed = {i for i, ok in health_bits.items() if not ok}

    def select_profile(self):                      # 5Hz：格 meet
        if not self.healthy():
            return self.v11_ladder.fallback()      # FHA 失效 ⇒ 等价 v11
        it = iter(self.library.certified_under(self.failed))
        best = None
        for pi in it:
            best = pi if best is None else meet_conservative(best, pi)
        return best if best is not None else BOTTOM   # 仅 ⊥ 才急停


# IP-354（升级）：六检守卫 + 取证-受权证书
class EvidenceCertifiedChunker(TriGuardChunkCertifier):
    def __init__(self, *a, mmef=None, scc=None, fha=None, **kw):
        super().__init__(*a, **kw)
        self.mmef, self.scc, self.fha = mmef, scc, fha

    def generate_chunk(self, state, ctx, stf, gscf, sra, nrb):
        pi, scen_info = self.scc.authorize(ctx.fused_evidence, ctx)
        self.fha.update_health(ctx.sensor_health)
        pi = meet_conservative(pi, self.fha.select_profile())
        K = self.effective_K(ctx.delta_dom, pi.tau_dom,
                             trust_ok=stf.trust_ok(ctx) and gscf.geo_ok(ctx),
                             conflict_ok=self._conflict_ok(ctx),
                             scen_ok=scen_info["n_scen"] == 1,
                             pi=pi)
        if K == 1:
            return self._single_step_fallback(state)
        best = None
        for cand in self.policy.sample_sequences(state, K, n=64):
            pred = self.Fq.rollout(state, cand)
            beta = pi.beta_base + self.mmef.beta(pred.corridor)
            g_min = pred.min_clearance - beta
            e_max = pred.max_effort + beta
            if g_min < self.d_safe or e_max > state.tau_eff:
                continue
            pts = self._abort_points(state, cand, pred)
            if not pts:
                continue
            cert = EvidenceCert(g_min, e_max, beta, pts,
                                s_hat=scen_info["s_hat"],
                                pi=pi, kappa=ctx.kappa_Phi,
                                n_scen=scen_info["n_scen"])
            chunk = Chunk(cand, cert, pts)
            chunk, _ = nrb.review_chunk(chunk, stf, ctx)
            if chunk is None:
                continue
            n_reason, _ = sra.reason_on_chunk(chunk, stf, gscf, ctx)
            chunk.cert.n_reason = n_reason
            if not (all(n_reason) and chunk.cert.valid):
                continue
            chunk.cert.Q_abort = {p: self.jsse.map_abort(p) for p in pts}
            score = self.policy.score(chunk, pred)
            best = chunk if best is None or score > best.score else best
        return best or self._single_step_fallback(state)

    def midchunk_guard(self, chunk, k_exec, live_obs, stf, gscf, nrb, jsse,
                       mmef, scc, fha):
        """50Hz 六检 ≤0.8ms"""
        if not chunk.cert_still_valid(live_obs):
            return self._abort_to_jsse(chunk, k_exec, jsse)
        stop_inv = (live_obs.nearest_clearance
                    - self.d_brake(live_obs.speed) - self.d_safe)
        if stop_inv < chunk.remaining_len(k_exec):
            return self._abort_to_jsse(chunk, k_exec, jsse)
        if stf.surprise_near(live_obs.pose) > stf.tau_sem:
            return self._abort_to_jsse(chunk, k_exec, jsse)
        if nrb.fast_norms(live_obs).violated:
            return self._abort_to_jsse(chunk, k_exec, jsse)
        if not gscf.geo_ok_near(live_obs.pose):
            return self._abort_to_jsse(chunk, k_exec, jsse)
        if live_obs.kappa_Phi > self.kappa_max:            # 检 6a：冲突
            return self._abort_to_jsse(chunk, k_exec, jsse)
        pi, info = scc.authorize(live_obs.fused_evidence, live_obs.ctx)
        if info["n_scen"] == 0 or scc.transition_guard(
                info["s_hat"], info["p_hat"], info["margin"]):
            return self._abort_to_jsse(chunk, k_exec, jsse)  # 检 6b：场景
        fha.update_health(live_obs.sensor_health)
        if meet_conservative(pi, fha.select_profile()) != pi:
            return self._abort_to_jsse(chunk, k_exec, jsse)  # 权力须下降
        return ('continue', k_exec + 1)

    if verdict == 'abort':
        jsse.execute_abort_trajectory(next_target)
        current_chunk = None
    else:
        q_cmd = jsse.project(current_chunk.joint_actions[k_exec])
        execute_joint(q_cmd)
    C, spatial_cert, claims, metrics, rewards = M.inherited_v11_path(ctx)
    distiller.step(cycle_idx, ctx)
    return C, spatial_cert, claims, metrics, rewards
```

## 4. 推导

**引理 97（交集融合的可靠性与收紧性）**
设 W_ℓ 中源各自满足定义 562 的标定界，且**相互独立**（关键前提 A1）。则当 I^⊞_ℓ≠∅ 时：
(a) 真实残差 r*_ℓ∈I^⊞_ℓ 以概率 ≥1−Σ_{i∈W}δ_i（Bonferroni 并集界）；
(b) rad^⊞_ℓ ≤ min_{i∈W} ε_i（交集是每个区间的子集）；
(c) 因此融合不会比“最好的单源”更保守，且当源充分相容时严格更紧（rad^⊞ 可远小于 min ε_i）。
证明：(a) 每个事件 r*∈I_i 失败概率 ≤δ_i，并集界；(b) I^⊞⊆I_i 对一切 i，区间长度 ≤2ε_i；(c) 由 (b) 及 rad^⊞ 随区间收缩单调。∎
**推论**：β_MMEF 的 rad 项 ≤ λ_r·min_i ε_i，故相对“只信最好单源”的 v11 变体不引入新保守税；源越多且越一致，界越紧。

**引理 98（冲突即收缩的安全性；排除朴素融合失效）**
若 κ_ℓ>κ_max 或 I^⊞=∅，MMEF **不产生融合界**，而是置 γ^⊞_ℓ=0、β 增 λ_κ，并触发 π←π_⊥ 或中止；故：
(i) 单源故障或源间矛盾**只能使系统更保守**，不能借平均把故障抹平；
(ii) 物理行为 ⊆ v11 冲突前可行集（支配性）；
(iii) 冲突是**可审计的显式事件**（入台账 Λ），而非被平滑掉的噪声。
证明：(i) 冲突路径无更紧的 β、K 不增；(ii) 由定义 570 与守卫 6a；(iii) 由定义 576。∎
**对抗推论**：攻击者若只伪造一个源，必与其余源产生冲突；若要避免冲突，必须**同时**伪造足够多独立源（见引理 101 的条件）。这恰是把 v11 的“单通道可被穿透”改成“多通道必须被同时穿透”。

**引理 99（场景受权与保守回落的支配性）**
(i) 若 n_t^scen=1，则 Ĉ_t^{*} 使用 π_ŝ 且其覆盖合同 C_ŝ 保证场景内误差覆盖 ≥1−ε_ŝ；因此**只有被离线证明过的场景**才可能获得比 v11 更紧的余量。
(ii) 若 n_t^scen=0（识别失败、OOD 拒识、版本不符、迁移未确认），则 π←π_⊥，且 π_⊥⊑π_s 对一切 s、π_⊥⊑π_v11；因此行为 ⊆ v11 可行集（支配性）。
(iii) P17 保证 R 无法创建场景或修改 π：运行时对场景库只读、版本哈希校验；候选场景只写台账。
证明：(i) 由定义 568–569 的合同蕴含；(ii) 由定义 570 的构造与偏序传递；(iii) 由定义 574 的只读/版本锁定与台账只记不控。∎

**引理 100（退化格单调性与多重失效优雅退化）**
设 F₁⊆F₂ 为失效集合。则
(a) π*(F₂)⊑π*(F₁)（失效更多，权力不增）；
(b) 若存在 s 使 C_s 在 F₂ 下仍可证，则 π*(F₂)≠⊥，系统**优雅退化**而非立即急停；
(c) π*(F)=⊥ ⇔ 无任何场景/剖面在 F 下可证；此时进入关节级急停保持（v6，引理 95）。
证明：(a) 由 meet 的定义集合随 F 增大而缩小，meet 只会更保守；(b) 由构造直接；(c) 由 ⊥ 的定义。∎
**对 v11 的改进**：v11 在 GSCF/SRA/JSSE 同时失效时只能急停；v12 只要 IMU/轮速/力觉/编码器仍能支撑某个认证剖面（例如 π_⊥ 或“低动态/低人密度”场景），即可在**更小 K、更严阈值**下降级运行，且全程受交授权约束。

**引理 101（综合保守性与其成立条件）**
在下列前提下：
- (A1) **源独立性**：W_ℓ 中源的误差不共享同一未建模偏差；
- (A2) **标定有效性**：各源在 D_i∧Val_i 下满足定义 562，且标定漂移被 E628 检出；
- (A3) **冲突阈值标定**：κ_max 使零假设误报 ≤ε_conf；
- (A4) **场景覆盖**：每个场景卡 C_s 在其 P_s 上成立（≥1−ε_s），识别器在闭合场景集上“高置信错误”率 ≤ε_sc；
- (A5) v11 的 A1–A4 与引理 94–96 仍成立；
则任一中块危险事件被捕获的概率
```
≥ 1 − (Σ_i δ_i + ε_conf + ε_sc + ε_sra + ε_jsse + ε_β)
```
其中显著类 ≤1 帧（ν/κ 触发），非显著类由 β_MMEF 覆盖；且物理行为在失效路径上支配于 v11。
证明：对融合失效、冲突误报、场景误分类、SRA、JSSE、β 覆盖六个事件取并集界；各路径的“捕获或覆盖”由引理 97–100 与 v11 引理 96 拼接。∎
**必须直说的边界**：(A1) 与 (A4) 是**条件而非定理**——共同模式失效（共享标定偏差、共视退化、相干物理伪造）会同时使 κ 虚假小、融合界虚假紧；(A4) 的 ε_sc 只在**闭合场景集**上有标定意义，对开放世界/对抗输入无先验保证。这正是本轮最大风险，也是 E614/E622 要量化而非回避的部分。

## 8. 本轮最大风险

**一句话**：MMEF 的安全性完全条件于“源误差独立且各自已标定”（A1/A2），SCC 的安全性完全条件于“识别器高置信错误率 ≤ε_sc 且场景集闭合”（A4）——而真实部署中二者恰恰同源脆弱：共享标定偏差、共视退化或相干物理伪造会让 κ 虚假地小、融合界虚假地紧；更致命的是识别器可能高置信地把开放世界/对抗输入判进一个**更宽松的已认证场景**，此时“在库内、无冲突、可审计”的表象同时成立，证书对错误场景严格、对真实场景失效，比 v11 的单通道虚假低更难被发现。
