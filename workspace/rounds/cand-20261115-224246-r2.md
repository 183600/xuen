# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「碰撞避免」×「数据集构建」）

> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**几何硬安全 + 数据信任**。v9 的最大风险是“安全被抵押给前向模型”：块证书以信任域内 ‖F̂−F‖≤β 为前提，而 Δ_dom 的滑窗滞后恰发生在模型最不可靠的时刻。v10 用碰撞避免把硬安全从预测器手里拿回来，用数据集构建把 β 从常数变成带覆盖保证的分位数；两者都必须可退化回 v9（BCF 恒等过滤、CCB 取 β_0）。

## 0. 直觉与动机

**灵感 1（碰撞避免 → 几何硬安全过滤）**
直觉：与其问“模型预测我会不会撞”，不如问“在当前状态与有界执行能力下，哪些动作在几何上不可能撞”。碰撞锥/速度障碍把“会撞的速度”画成一个锥；控制屏障函数把“离障碍还有多少安全余量”写成一个标量 h≥0。关键：二者只用实测几何与已知运动学，不信任学习到的前向模型。v9 的 AC 守卫在 Δ_dom 滞后时可能迟到；v10 在 AC 之后加一道**不可绕过的 BCF**：若名义动作破坏离散屏障条件，就把它投影到最近的安全动作；无安全动作则立即紧急制动。安全不再由 β 购买，而由几何强制。
严谨定义：h(s)=min_o(dist(p,O_o)−d_safe)，鲁棒余量 m 吸收测量/扰动/离散化误差，h̃=h−m/γ；A_safe(t)={a : h̃(f(s,a)+w) ≥ (1−γ)h̃(s), ∀w∈W}，a*=Proj_{A_safe}(a_nom)；A_safe=∅ ⇒ a*=a_brake 并报 ICS（inevitable collision state）。多机时用责任份额 ρ_ij+ρ_ji=1 的互惠屏障，避免“我等你、你等我”的双停死锁。

**灵感 2（数据集构建 → 覆盖导向的保形语料）**
直觉：β 不该是拍脑袋的常数，也不该只在“信任域内”口头成立；它应是数据给的、带有限样本保证的分位数。但数据集不是越大越好：要在风险边界附近有足够的“近失 witness”，并且要能说清“哪些场景单元有资格发证书、哪些没有”。v10 构建**反事实近失语料 CCB**：覆盖导向采样场景空间 S（几何×动力学×Δ_dom×risk_SLAM×噪声），在近失边界主动采样并做反事实增广；用分组（Mondrian）保形校准给出每单元 β_k，满足单元内 P(|F̂−F|≤β_k)≥1−α_k；覆盖不足的单元直接 β_k=∞（拒绝发证，K_eff=1）。这把 v9 的全局 β 变成“空间索引的信任地图”。
严谨定义：单元 C_k，校准分数 s_i=|F̂(x_i)−F(x_i)|，β_k=Q_{⌈(n_k+1)(1−α_k)⌉}({s_i}_{i∈C_k})；n_k<n_min ⇒ β_k=∞。证书只在有覆盖的单元内有效——**无数据，不信任**。

**灵感 3（两者合流 → 安全与信任解耦）**
直觉：碰撞避免负责“即使预测错也不撞”，数据集负责“预测错多少有数据兜底”。二者正交：BCF 的保证不依赖 β；CCB 的保证不依赖几何安全。合流后，v9 的“分块执行在最需要安全时暴露最不可靠证书”被拆成两个可独立审计的命题：硬安全由 BCF 的鲁棒前向不变性保证；软证书由 CCB 的覆盖-保形保证背书。剩余风险被诚实地转移到“感知是否看见障碍”与“部署分布是否与语料可交换”。

## 1. 研究问题（轮次升级版）

- **Q1（几何硬安全）**：在测量误差、执行扰动与离散化下，BCF 能否保证安全集前向不变？最小侵入投影的偏差是否有界、是否无抖振？BCF 能否让 K_eff 与安全解耦（块可以长，安全仍逐步强制）？
- **Q2（覆盖-保形证书）**：如何构造覆盖导向的近失语料，使分组保形 β_k 在场景单元内达到有限样本条件覆盖？覆盖缺口如何被可靠检测并转化为 K_eff=1？
- **Q3（组合与退化）**：BCF/CCB 与 v9 的 AC/MW/ID 如何组合而不产生“过滤器否决风暴”？禁用任一模块是否逐位退回 v9？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 几何安全优先律（Geometry-First Safety, BCF）**
碰撞安全只能由实测几何 + 有界可达集/离散屏障条件强制，禁止由学习预测器“认证”；前向模型只负责软指标（努力、抓取、舒适）与性能。BCF 位于 AC 中块守卫之后、执行器之前，是最后一道不可绕过关卡，φ^elig=false。

**P14 覆盖应得证书律（Coverage-Earned Certificate, CCB）**
保形证书只在有足够校准覆盖的场景单元内有效；覆盖缺口 ⇒ β=∞ / K_eff=1。证书的信任来自数据集覆盖，而非模型自信；覆盖图与数据集卡是一等公民。

**P15 责任分摊律（Reciprocal Responsibility, RRA）**
多机安全通过显式责任份额 ρ_ij+ρ_ji=1 的互惠屏障实现；契约表携带 ρ；分配器失效 ⇒ ρ=1（各自全责），保守但安全。

## 3. 与基线的接口（如何退化）

- CCB 失效/无覆盖 ⇒ β←β_0（v9 常数）；覆盖缺口 ⇒ β=∞、K_eff=1（保守单步 + BCF）；
- BCF 未部署/显式禁用 ⇒ 恒等过滤，退回 v9 AC 中块守卫（预测依赖，风险升级告警）；BCF 运行期超时/异常 ⇒ 紧急制动 a^⊥（fail-safe），不回退到预测路径；
- RRA 失效 ⇒ ρ=1（各自全责）；
- v9 的 AC/MW/ID 失效 ⇒ 按 v9 链逐级退化（AC→K_eff=1、MW→v8 网关、ID→全 active）；v8 的 DA/SPR/Cal 失效 ⇒ 中立元注入退回 v7；全失效 ⇒ v6。

## 4. 预期贡献

1. **几何硬安全过滤**：把碰撞安全从“预测器证书”解耦为“实测几何 + 屏障不变式”，给出与 β 无关的鲁棒前向不变性；
2. **覆盖导向的保形语料**：β 从全局常数升级为按场景单元的空间索引分位数，附覆盖缺口拒绝律、数据集卡与漂移重标定；
3. **安全-信任正交分解**：v9 的单一风险被拆成两个可独立验证的命题，并保留严格退化链（引理 90）；
4. **互惠多机屏障**：责任份额使多机共享契约表时仍可证无碰撞；E571–E590 覆盖不变性、最小侵入、保形覆盖、遮挡与对抗感知、端到端。

## 5. 本轮最大风险

**一句话**：BCF 的“模型无关”只对“已看见的障碍”成立——遮挡、透明物或突然闯入者使 O(t) 不完备时，碰撞锥被系统性低估，而 CCB 又无法为传感器从未观测到的状态提供覆盖，于是“几何安全”与“数据信任”在最危险的盲区同时失效。

## 1. 符号体系增量（定义 540–547）

| 符号 | 含义 |
|---|---|
| h(s), h̃(s) | 屏障函数与鲁棒屏障：h=min_o(dist(p,O_o)−d_safe)，h̃=h−m/γ |
| m | 鲁棒余量：吸收测量误差 ε_m、速度误差 ε_v、扰动 w_max、离散化 Δ |
| γ ∈ (0,1) | 屏障收缩率；h̃ 每步至少按 (1−γ) 收缩 |
| A_safe(t) | 可行动作集：{a : h̃(f(s,a)+w) ≥ (1−γ)h̃(s), ∀w∈W} |
| a^⊥ | 紧急制动动作（最大减速度），BCF 的 fail-safe 吸收元 |
| ICS | 不可避免碰撞状态（A_safe=∅ 或制动距离不足） |
| ρ_ij | 机器人 i 在 pair (i,j) 中的责任份额，ρ_ij+ρ_ji=1 |
| S, C_k, n_k | 场景空间、覆盖网单元、单元校准样本数 |
| β_k, α_k | 单元 k 的保形误差上界与误覆盖率 |
| n_min | 单元发证所需最小校准样本数 |
| w_i | 近失 witness：反事实增广得到的最小间隙动作及其误差 |

**新增定义 540（碰撞锥与有界可达集 CollisionCone/ReachableSet）** 设机器人状态 s=(p,v)，动作 a∈A，步长 Δ，扰动 w∈W 满足 ‖w‖≤w_max；障碍 o 的位置 p_o、速度 v_o、加速度上界 a_o,max，测量误差 ‖p̂_o−p_o‖≤ε_m、‖v̂_o−v_o‖≤ε_v。一步可达集与膨胀障碍：
```
R(s,a,Δ) = { f(s,a,Δ) + w : w ∈ W }
O^⊕(t) = O(t) ⊕ B( ε_m + ε_v·Δ + ½·a_o,max·Δ² + w_max·Δ )
```
碰撞锥 CC(s,o) = { a : R(s,a,Δ) ∩ O_o^⊕ ≠ ∅ }；A_safe = A \ ⋃_o CC(s,o)。多步安全性由定义 541 的屏障条件递归保证，而非把一步锥简单连乘。

**新增定义 541（离散控制屏障证书 DiscreteCBF）** h(s)=min_o(dist(p,O_o^⊕)−d_safe)，鲁棒余量 m = w_max·Δ + 2ε_m + ε_v·Δ + ½·a_o,max·Δ²（按 L_h=1 的欧氏距离取），h̃=h−m/γ。安全集 C_γ={s : h̃(s)≥0}。屏障条件：
```
h̃( f(s,a) + w ) ≥ (1−γ)·h̃(s),   ∀w∈W
```
W 用凸外包或 worst-case 采样保守化。BCF 只使用实测几何与已知运动学，不调用 F̂；φ^elig=false，ID 永不消融。

**新增定义 542（最小侵入安全过滤与干预预算 MinimumInterventionFilter）**
```
a* = argmin_{a∈A_safe} (a−a_nom)^T Q (a−a_nom) + λ‖a‖²
```
若 a_nom∈A_safe 则 a*=a_nom；若 A_safe=∅ 则 a*=a_brake、置 ICS 锁存，直到 h̃(s)≥h_rearm 且持续 T_rearm 步才重新武装。BCF 干预是正常安全行为，不计入 MW 故障 strike；仅当滑窗干预率 > ρ_max 或 ICS 触发时上报“重规划/重标定”事件，避免“过滤器否决风暴”被误判为模块退化。

**新增定义 543（责任份额与互惠屏障 ReciprocalResponsibility）** 对 pair (i,j) 定义 h_ij=dist(p_i,p_j)−r_i−r_j−d_safe，份额 ρ_ij∈[0,1]，ρ_ij+ρ_ji=1。机器人 i 只对自己运动造成的 h 下降负责：
```
h̃_ij(s_i^{k+1}, ŝ_j^{k+1}) ≥ (1−ρ_ij·γ)·h̃_ij(s_i^k, s_j^k)
```
其中 ŝ_j 为通信/预测的 j 状态；无通信时用 j 的可达集上界，等价 ρ_ij=1。优先级 π 来自契约表，用于打破对称死锁（低优先级让行）。

**新增定义 544（场景空间与覆盖网 ScenarioSpace/CoverageNet）** S = G×D×X_dom×X_slam×N（几何、动力学、域偏移、SLAM 风险、噪声）。用自适应 ε-net/KD-tree 把 S 划为单元 C_k；覆盖度 cov(C_k)=n_k/n_min，风险权重 r_k 取单元内近失率或 h 的低分位。覆盖证书 = 所有高风险单元满足 cov(C_k)≥1；覆盖图随数据集版本冻结、随部署漂移重算。

**新增定义 545（反事实近失语料 CounterfactualNearMissCorpus）** D={(ξ_i, a_i^{1:K}, y_i, e_i, w_i)}。对每个近失样本，在动作邻域内重采样求最小间隙动作，保留 Pareto 前沿作为 witness w_i；e_i 为 witness 处的前向模型误差 |F̂−F|。样本携带场景 id、传感器噪声种子、时间戳与来源，禁止帧级泄漏（训练/校准/测试按场景划分）。

**新增定义 546（分组保形校准 MondrianConformal）** 对单元 C_k 的校准分数 s_i=max_metric |F̂(x_i)−F(x_i)|，取
```
β_k = Q_{⌈(n_k+1)(1−α_k)⌉}( {s_i}_{i∈C_k} )
```
其中 Q 为经验分位数；n_k<n_min 或单元未映射 ⇒ β_k=∞。按 Δ_dom 分箱与几何分箱做 Mondrian 分组，使覆盖近似条件于域偏移；漂移检测器触发时重标定。

**新增定义 547（覆盖缺口拒绝律 CoverageGapRejection）** 若 β_k=∞ 或单元未覆盖，则 AC 强制 K_eff=1、只允许 BCF 过滤后的单步动作，并记录“coverage_gap”事件、请求主动采样；这不是静默回退，而是可审计的安全拒绝。覆盖缺口事件率是数据集治理的一等指标。

## 2. 形式化定义（要点与升级）

- **定义 493/495/521/524** 继承 v9 不变。
- **升级定义 533′（块证书，v10）** 全局 β 替换为 β_{k(t)}（定义 546）；证书有效 ⇔ β_{k(t)}<∞ ∧ ĝ_min ≥ d_safe ∧ ê_max ≤ τ_eff ∧ γ̂_grasp valid。硬间隙不再由证书单独背书——即使 Ĉ 因模型误差失效，BCF 仍逐步强制 h̃≥0。

    def _inflate(self, obs, dt):
        r = (self.eps_m + self.eps_v*dt
             + 0.5*max(o.a_max for o in obs)*dt*dt + self.w_max*dt)
        return [o.inflate(r) for o in obs]

    def _h(self, s, obs):
        return min(dist(s.p, o.p) - o.r - self.d_safe for o in obs)

    def filter(self, s, a_nom, obs, dt):
        obs_inf = self._inflate(obs, dt)
        m = self.w_max*dt + 2*self.eps_m
        h_tilde = self._h(s, obs_inf) - m/self.gamma
        A_safe = self._safe_actions(s, obs_inf, h_tilde, dt)  # 线性化 QP / 凸外包
        if not A_safe:
            self.ics_latch = True
            return self.a_brake(s), 'ICS'
        a_star = argmin_qp(a_nom, A_safe, Q)
        self.intervention_rate.update(not close(a_star, a_nom))
        return a_star, 'OK'

# IP-359 ReciprocalResponsibilityAllocator
class ReciprocalResponsibilityAllocator:
    def __init__(self, contracts):
        self.contracts = contracts

    def shares(self, i, j):
        rho = 0.5  # 默认对称；按优先级/敏捷度/契约表调整
        return rho, 1 - rho

    def reciprocal_filter(self, bcf, s_i, a_i, neighbors):
        a = a_i
        for j, sj in neighbors:
            rho_ij, _ = self.shares(i, j)
            a = bcf.filter_pair(s_i, a, sj, rho_ij)      # 定义 543
        return a

## 4. 推导

**引理 87（BCF 鲁棒前向不变性，安全与 β 解耦）** 设初始 s_0∈C_γ（h̃(s_0)≥0），测量误差 ≤ε_m、速度误差 ≤ε_v、扰动 ‖w‖≤w_max、障碍加速度 ≤a_o,max，h 的 Lipschitz 常数 L_h=1。BCF 用膨胀障碍 O^⊕ 计算 h̃，并对所有 w∈W（或 W 的凸外包）强制 h̃(s_{k+1})≥(1−γ)h̃(s_k)。则 ∀k，h(s_k)≥m/γ>0，即与真实障碍 O 无碰撞，且该结论不依赖 F̂ 与 β。证明：O^⊕ 的膨胀半径覆盖一步内障碍与自车的不确定位移，故真实 h ≥ ĥ + m；又 h̃=ĥ−m/γ，得 h ≥ h̃ + m/γ。对屏障条件归纳得 h̃(s_k) ≥ (1−γ)^k h̃(s_0) ≥ 0。于是 h(s_k) ≥ m/γ > 0。∎

**引理 88（最小侵入、偏差有界与无抖振）** 若 a_nom∈A_safe，QP 解 a*=a_nom，零干预；若不在，a* 是 a_nom 在 A_safe 上的 Q-范数投影，偏差 ≤ dist_Q(a_nom,A_safe)。在线性化一步动力学与椭球扰动下 A_safe 为凸集，QP 唯一且投影非扩张；A_safe 非空时 a* 对 a_nom 连续，无高频切换。A_safe 空时锁存 ICS 并以 T_rearm 步与 h_rearm>m/γ 的滞回重新武装，故每 episode 的 ICS 切换次数有限；干预率监控把连续干预转为重规划事件而非模块故障。∎

**引理 89（保形覆盖与覆盖缺口）** 在单元 C_k 内样本可交换，分数 s_i=max_metric|F̂−F|，β_k 取 ⌈(n_k+1)(1−α_k)⌉ 阶统计量，则新样本满足 P(s_new≤β_k)≥1−α_k（split conformal）。对高风险单元集合 K 同时要求覆盖，由联合界得 P(∀k∈K: s_new≤β_k)≥1−Σ_{k∈K}α_k。若 n_k<n_min 或单元未映射，置 β_k=∞，则 AC 强制 K_eff=1；此时不发软证书，但 BCF 仍保证硬安全（引理 87）。∎

**引理 90（组合退化与 v9 等价）** 令 BCF 为恒等过滤（a*=a_nom）、CCB 返回 β_0、RRA 返回 ρ=1，则主闭环的取值与调用顺序逐位等于 v9（AC/MW/ID 不变），故 v9 是 v10 的退化实例。BCF 的 φ^elig=false，ID 永不使其 dormant。唯一非恒等失效是 BCF 运行期异常 ⇒ a_brake：这是有意的 fail-safe 吸收元，因为把安全过滤失效当恒等会直接取消 P13；因此 v10 的退化格包含 v9 子格，并保留 v9→v8→v7→v6 链。∎

**引理 91（互惠多机安全与死锁）** 对 pair (i,j)，若双方各自只对自身运动造成的 h_ij 下降负责，且份额满足 ρ_ij+ρ_ji=1，则在忽略二阶耦合项时 h̃_ij 的组合收缩率 ≤γ，故 h_ij≥0 前向不变；二阶项由膨胀余量 m 吸收。若 ρ 分配对称且双方同时让行，可能双停；优先级 π 打破对称（低优先级 ρ 更大），使至少一方有通行义务；若分配器失效 ρ=1，双方各自按对方可达集上界保守估计，安全但可能死锁，由进度监控升级到中央仲裁。∎

## 8. 本轮最大风险

**一句话**：BCF 的“模型无关”只对“已看见的障碍”成立——遮挡、透明物或突然闯入者使 O(t) 不完备时，碰撞锥被系统性低估，而 CCB 又无法为传感器从未观测到的状态提供覆盖，于是“几何安全”与“数据信任”在最危险的盲区同时失效。
