# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「仿真训练」×「双足机器人」）

> 第 54 轮把技能组合建立在动作空间剖面 α_S、组合图 G_S、云边映射 γ_ce 与联合证书 J 之上。但 α_S 默认动作是"静态可达点"，把 **接触相** 抹平；证书也默认"仿真结论可直接外推"，把 **训练证据边界** 忽视。双足机器人恰恰是欠驱动、接触相切换的混合动力学系统，仿真训练结论在真实触地处最易失效。核心矛盾：H22：同一关节动作在不同接触相下动力学语义不同，跨相组合证书在相切换点虚假成立；H23：仿真训练只保证训练分布 D_train 内的结论，部署落到域外时云端"可部署"承诺系统性失效。

## 0. 直觉与动机

**灵感 1（仿真训练 ≠ 学会，而是"证据覆盖域 + 现实差距场"）**
直觉：仿真训练产出的不是"技能已掌握"的布尔标签，而是一张覆盖 D_train 的 **证据地图**：在哪些 (动作, 相位) 上做过多少次 rollout、结论有多可信。部署时先要问：任务轨迹 Γ_T 是否落在证据覆盖域内？域外的仿真结论不可外推。再要问：即使被覆盖，sim 与 real 的动力学差多大？用一个 **现实差距场 g(a,φ)** 显式刻画，而不是靠平均成功率掩盖。
严谨：定义 121（证据谱）与 124（差距场/可迁移域）。

**灵感 2（双足机器人 → 动作空间必须显式加"接触相"维度）**
直觉：双足是欠驱动混合系统，flight / 左支撑 / 右支撑 / 双支撑 的动力学完全不同；同一"抬腿"指令在不同相下或保持平衡、或直接摔倒。第 54 轮的 α_S(a) 把相位抹平，恰好把最危险的相切换点藏了起来。应把动作空间升维为 A×Φ，让每个技能携带 **混合自动机 H_S**，把相切换写成带 guard 的离散迁移。
严谨：定义 122（接触相空间与混合动作）。

**灵感 3（相依赖鲁棒性 → ρ 再加一维相位，并锚定 Poincaré 截面）**
直觉：双足平衡的鲁棒性不是常数，而是随步态周期起伏：支撑中期稳、触地瞬间脆。第 53 轮的 ρ(d) 应扩展为 ρ^Φ(d,φ)；而相切换的临界点正是 Poincaré 截面，返回映射 P 的谱半径 κ<1 才是步态可复现的硬条件。这把"鲁棒"从逐点判据升级为 **极限环轨道稳定性**。
严谨：定义 123、125。

**灵感 4（组合的相转换预算 → 组合边要过"相位闸门"）**
直觉：两技能动作重叠再多，若 S1 结束在 ST_L、S2 要求起于 FL，且无法在 τ_φ 内合法过渡，则组合仍不可行。组合图 G_S 的边应增加 **相位可达性** 与 **相位转换预算**，证书记录重叠区上的差距场上界与 Poincaré 收缩率。
严谨：定义 126 + IP-126 PASCOM。

**灵感 5（仿真训练-部署闭环 → 把真实触地反例回灌重训）**
直觉：边端每一次真实触地都是一次"差距采样"。把 (a,φ,Δf) 反例沿第 54 轮 Explain 反向信道回传，云端更新 g 场与 D_trans，并据此 **主动补采域外点**，让"仿真训练"由一次性离线过程变成"训练-部署-反例-重采样"的闭环。
严谨：与定义 118 的 Explain_loop 及 IP-125 联动。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（仿真训练证据谱）**
技能 S 的证据谱 `E_sim(S) = (D_train, Ĉ, N, ĝ)`：`D_train ⊆ A×Φ` 为训练覆盖集，`Ĉ: 2^{A×Φ}→[0,1]` 为覆盖置信度，`N(a,φ)` 为采样次数，`ĝ` 为差距估计器。任务域 U 上的覆盖度 `cov_sim(S,U) = vol(U ∩ D_train) / vol(U)`；仅当 `cov_sim ≥ θ_cov` 且 `N ≥ N_min` 时，S 在 U 上的仿真结论可外推。

**定义 122（接触相空间与混合动作）**
接触相 `Φ = {FL, ST_L, ST_R, DS}`（flight / 左支撑 / 右支撑 / 双支撑），混合动作空间 `A_Φ = A × Φ`。技能 S 为混合自动机 `H_S = (Φ_S, →_S, Inv_S, G_S, R_S)`：`Φ_S ⊆ Φ`，迁移 `→_S` 带守卫 `G(a,φ)` 与重置 `R`。相兼容 `compat_Φ(S_i,S_j) = 1` 当且仅当存在 `φ_i ∈ Φ_{S_i}, φ_j ∈ Φ_{S_j}` 与长度 ≤ τ_φ 的合法迁移路径 `φ_i →* φ_j`。

**定义 123（相依赖鲁棒性谱）**
`ρ^Φ_S: 𝔇 × Φ → [0,1]`，`ρ^Φ_S(d,φ)` 为技能 S 在维度 d、接触相 φ 下的鲁棒度；相切换鲁棒性 `ρ^sw_S(φ→φ') = 1 - P(fail | φ→φ')`。技能鲁棒度取最脆点：`ρ^Φ_S = min_{d,φ} ρ^Φ_S(d,φ) ∧ min ρ^sw_S`。

**定义 124（现实差距场与可迁移域）**
`g: A×Φ → ℝ_{≥0}`，`g(a,φ) = || f_real(a,φ) - f_sim(a,φ) ||`。可迁移域 `D_trans(γ) = {(a,φ) | g(a,φ) ≤ γ}`。**证书只在 D_trans 内 sound**：`Γ_T ⊆ D_trans(γ)` 是任何部署证书的前置条件。

**定义 125（步态极限环与 Poincaré 稳定性）**
周期步态在 Poincaré 截面 `Σ_φ` 上诱导返回映射 `P_φ: Σ_φ → Σ_φ`。轨道稳定当且仅当 Jacobian 谱半径 `κ = ρ(∂P_φ/∂x) < 1`；收缩率 κ 越小，步到步扰动衰减越快。

**定义 126（仿真训练-接触相联合证书 S2R-J）**
`J_s2r = (E_sim, α^Φ_S, ρ^Φ_S, ĝ, κ_P, δ_gap, evidence)`。可部署当且仅当
```
Γ_T ⊆ D_trans(γ) ∧ cov_sim(Γ_T) ≥ θ_cov ∧ ρ^Φ_S ≥ ρ_min ∧ κ_P < 1 ∧ δ_gap ≤ Θ_gap
```
其中 `δ_gap = sup_{Γ_T} ĝ - g ≥ 0` 为差距估计的保守余量（要求 ĝ 为上界）。

## 2. 关键算法 伪代码

### IP-121 STC（Sim Training Coverage）

```python
def train_coverage(skill, phi_set, sampler, budget, gap_estimator):
    D, frontier = [], init_frontier(phi_set)
    while budget > 0:
        a, phi = active_select(frontier, gap_estimator)   # 差距高/覆盖低优先
        traj = sampler.rollout(skill, a, phi, domain_rand=True)
        D.append((a, phi, traj))
        frontier.update(a, phi, traj)
        budget -= traj.cost
    C_hat = conformal_coverage(D, phi_set)
    return EvidenceSpectrum(D, C_hat, counts(D), gap_estimator)
```

### IP-122 PPA（Phase Profile Automaton）

```python
def build_phase_automaton(skill, contact_stream):
    phases = detect_phases(contact_stream)              # FL/ST_L/ST_R/DS
    H = HybridAutomaton(phases)
    for phi, nxt in consecutive_with_events(contact_stream):
        guard = fit_guard(phi, nxt, contact_stream)
        reset = fit_reset(phi, nxt)
        H.add_transition(phi, nxt, guard, reset)
    return H

def phase_reachable(H, phi_i, phi_j, tau_phi):
    path = shortest_path(H.transitions, phi_i, phi_j)
    return path is not None and len(path) <= tau_phi
```

### IP-123 PSR（Poincaré Stability & Robustness）

```python
def poincare_cert(skill, phi, Sigma):
    P = estimate_return_map(skill, phi, Sigma)
    J = jacobian(P, Sigma.anchor)
    kappa = spectral_radius(J)
    rho_phi = min(robustness_spectrum(skill, d, phi) for d in DIMS)
    rho_sw = 1 - failure_rate(skill, phi)
    rho_min = min(rho_phi, rho_sw)
    return PoincareCert(kappa, rho_min, stable=(kappa < 1.0))
```

### IP-124 GFE（Gap Field Estimation）

```python
def estimate_gap_field(skill, feedback):
    residual = [(a, phi, f_real - f_sim(skill, a, phi))
                for (a, phi, f_real) in feedback]
    gp = GPRegressor(kernel=contact_kernel)      # 以接触相为分段核
    gp.fit(residual)
    def g_upper(a, phi):
        mu, sd = gp.predict(a, phi)
        return mu + beta * sd                    # 保守上界
    D_trans = {(a, phi) for (a, phi) in grid(skill.A, PHI)
               if g_upper(a, phi) <= gamma}
    return g_upper, D_trans
```

### IP-125 S2RC（Sim2Real Certifier）

```python
def s2r_certificate(skill_seq, Gamma_T, gamma, rho_min, Theta_gap):
    E = union_evidence([s.E_sim for s in skill_seq])
    g_upper, D_trans = estimate_gap_field_chain(skill_seq)
    if not subset(Gamma_T, D_trans):        return reject('out_of_coverage')
    if coverage(E, Gamma_T) < theta_cov:    return reject('evidence_insufficient')
    rho_phi = min(s.rho_phi[d, phi] for s in skill_seq
                  for d in DIMS for phi in s.phases)
    if rho_phi < rho_min:                   return reject('robustness_fail')
    kappa = max(poincare_kappa(s, phi) for s in skill_seq for phi in s.phases)
    if kappa >= 1.0:                        return reject('gait_unstable')
    delta_gap = conservative_margin(g_upper, Gamma_T)
    if delta_gap > Theta_gap:               return reject('gap_budget')
    return ok(JointCertS2R(E, rho_phi, g_upper, kappa, delta_gap, Gamma_T))
```

### IP-126 PASCOM（Phase-Aware Skill Composition）

```python
def phase_aware_composition(skills, H, theta_a, theta_phi, tau_phi):
    G = DiGraph()
    for i, s1 in skills:
        for j, s2 in skills:
            if i == j: continue
            a_ov = jaccard(s1.alpha, s2.alpha)
            ph_ok = any(phase_reachable(H[i], p1, p2, tau_phi)
                        for p1 in H[i].exit_phases
                        for p2 in H[j].entry_phases)
            if a_ov >= theta_a and ph_ok:
                g_ub = max(g_upper(p) for p in overlap(s1, s2))
                kappa = max(poincare_kappa(s1), poincare_kappa(s2))
                G.add_edge(i, j, compat=a_ov, phase_ok=ph_ok,
                           gap_ub=g_ub, kappa=kappa,
                           cost=cost_align(s1, s2) + w_phi * tau_phi_path)
    return G
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| STC | O(B·(T_rollout + |Φ|)) | O(|D_train|) | 覆盖置信度校准、主动采样无偏 |
| PPA | O(|contact_stream|·|Φ|²) | O(|Φ|²) | 相位检测 F1、guard sound |
| PSR | O(|Σ|³ + N·|Σ|²) | O(|Σ|²) | 返回映射可微、κ 为上界 |
| GFE | O(N³)（GP 拟合） | O(N²) | 差距上界保守、核分段合理 |
| S2RC | O(|Γ_T|·(N+|Φ|)) | O(|Γ_T|) | Γ_T⊆D_trans、余量非负 |
| PASCOM | O(|S|²·|Φ|²) | O(|S|²) | 相位可达完备、预算闭合 |

**正确性定理（Phase-Aware Sim2Real Soundness）**
假设第 54 轮 (A22)-(A28) 成立；**(A29)** `ĝ` 是 g 的校准保守上界（`ĝ ≥ g` w.p. ≥ 1-α）；**(A30)** 接触相检测 F1 ≥ 1-ε_φ，相迁移有限且无 Zeno；**(A31)** Poincaré 返回映射可微，κ<1；**(A32)** 边端反例回传延迟 ≤ τ_loop 且采样无偏。
则
```
P_success ≥ 1 - P(Γ_T ⊄ D_trans(γ)) - P(δ_gap > Θ_gap)
            - Σ_{d,φ}(1 - ρ^Φ_min(d,φ)) - P(κ ≥ 1) - ε_φ - β_E
```
关键：**先验限制在可迁移域**（而非全空间）、**相切换可判定**、**极限环收缩**，三者缺一则证书不 sound。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 差距场外推失真（域外过于乐观） | 高 | conformal 上界 + 域外拒答 + 主动补采 |
| 接触相检测误判/延迟 | 高 | 多模态融合（IMU+足端力+视觉）+ 迟滞 |
| Poincaré 映射高维不可微 | 中 | 数据驱动谱估计 + Lyapunov 证书 |
| 仿真训练过拟合特定地形 | 高 | 地形课程 + 域随机化 + 真实反例回灌 |
| 相位转换预算过保守致组合失败 | 中 | 分层松弛 + 相转换缓存 |

## 6. 本轮最大风险

**一句话**：把仿真训练与双足接触相引入证书体系，使"可部署"从动作可达升级为"证据覆盖 + 差距有界 + 极限环收缩"的联合判定，但其 soundness **同时押注差距上界 ĝ 的校准保守性、接触相检测的实时准确、以及 Poincaré 收缩率在真实接触扰动下的保持**；一旦 ĝ 在域外过度乐观、或触地瞬间被误判为支撑相，证书就会在真实双足最脆的相切换点系统性放行，故必须以 **域外拒答 + 相检测置信门控 + 真实反例回灌重训** 三重护栏，宁可在域外保守停机，也绝不把"仿真里学会的步态"直接当作真实可部署的承诺。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim-S2R（STC×PPA×PSR×GFE×S2RC×PASCOM）

> 承接第 54 轮产物 v31。本轮在动作-协同层之上增加 **仿真训练证据化、双足接触相混合动力学、现实差距场** 三大算子，把"可部署"从动作可达升级为"证据覆盖 + 差距有界 + 极限环收缩"的联合判定：
> - **STC（Sim Training Coverage）**：把仿真训练产出建模为证据谱 `E_sim` 与覆盖度 `cov_sim`；
> - **PPA（Phase Profile Automaton）**：为双足技能建立接触相混合自动机 `H_S`，动作空间升维为 `A×Φ`；
> - **PSR（Poincaré Stability & Robustness）**：以返回映射谱半径 κ 与相依赖鲁棒谱 `ρ^Φ` 判定步态轨道稳定；
> - **GFE（Gap Field Estimator）**：用保守上界 `ĝ` 估计现实差距场并圈定可迁移域 `D_trans`；
> - **S2RC（Sim2Real Certifier）**：输出仿真训练-接触相联合证书 `J_s2r`；
> - **PASCOM（Phase-Aware Skill Composition）**：在组合图上增加"相位闸门"与相转换预算。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/116/118 以纳入接触相与差距场维度。

def s2r_certificate(skill_seq, Gamma_T, gamma, rho_min, Theta_gap):
    E = union_evidence([s.E_sim for s in skill_seq])
    g_upper, D_trans = estimate_gap_field_chain(skill_seq)
    if not subset(Gamma_T, D_trans):        return reject('out_of_coverage')
    if coverage(E, Gamma_T) < theta_cov:    return reject('evidence_insufficient')
    rho_phi = min(s.rho_phi[d, phi] for s in skill_seq
                  for d in DIMS for phi in s.phases)
    if rho_phi < rho_min:                   return reject('robustness_fail')
    kappa = max(poincare_kappa(s, phi) for s in skill_seq for phi in s.phases)
    if kappa >= 1.0:                        return reject('gait_unstable')
    delta_gap = conservative_margin(g_upper, Gamma_T)
    if delta_gap > Theta_gap:               return reject('gap_budget')
    return ok(JointCertS2R(E, rho_phi, g_upper, kappa, delta_gap, Gamma_T))

### IP-126 PASCOM

```python
def phase_aware_composition(skills, H, theta_a, theta_phi, tau_phi):
    G = DiGraph()
    for i, s1 in skills:
        for j, s2 in skills:
            if i == j: continue
            a_ov = jaccard(s1.alpha, s2.alpha)
            ph_ok = any(phase_reachable(H[i], p1, p2, tau_phi)
                        for p1 in H[i].exit_phases
                        for p2 in H[j].entry_phases)
            if a_ov >= theta_a and ph_ok:
                G.add_edge(i, j, compat=a_ov, phase_ok=ph_ok,
                           gap_ub=max(g_upper(p) for p in overlap(s1, s2)),
                           kappa=max(poincare_kappa(s1), poincare_kappa(s2)),
                           cost=cost_align(s1, s2) + w_phi * tau_phi_path)
    return G
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| STC | O(B·(T_rollout + |Φ|)) | O(|D_train|) | 覆盖置信度校准、主动采样无偏 |
| PPA | O(|contact|·|Φ|²) | O(|Φ|²) | 相位检测 F1、guard sound |
| PSR | O(|Σ|³ + N·|Σ|²) | O(|Σ|²) | 返回映射可微、κ 为上界 |
| GFE | O(N³) | O(N²) | 差距上界保守、核分段合理 |
| S2RC | O(|Γ_T|·(N+|Φ|)) | O(|Γ_T|) | Γ_T⊆D_trans、余量非负 |
| PASCOM | O(|S|²·|Φ|²) | O(|S|²) | 相位可达完备、预算闭合 |

**正确性定理（Phase-Aware Sim2Real Soundness）**
假设第 54 轮 (A22)-(A28) 成立；**(A29)** `ĝ` 是 g 的校准保守上界（`ĝ ≥ g` w.p. ≥ 1-α）；**(A30)** 接触相检测 F1 ≥ 1-ε_φ，相迁移有限且无 Zeno；**(A31)** Poincaré 返回映射可微，κ<1；**(A32)** 边端反例回传延迟 ≤ τ_loop 且采样无偏。
则部署成功概率：
```
P_success ≥ 1 - P(Γ_T ⊄ D_trans(γ)) - P(δ_gap > Θ_gap)
            - Σ_{d,φ}(1 - ρ^Φ_min(d,φ)) - P(κ ≥ 1) - ε_φ - β_E
```
关键：**证书先验限制在可迁移域**、**相切换可判定**、**极限环收缩**，三者缺一则证书不 sound。

## 5. 本轮最大风险

**一句话**：把仿真训练与双足接触相引入证书体系，使"可部署"从动作可达升级为"证据覆盖 + 差距有界 + 极限环收缩"的联合判定，但其 soundness **同时押注差距上界 ĝ 的校准保守性、接触相检测的实时准确、以及 Poincaré 收缩率在真实接触扰动下的保持**；一旦 ĝ 在域外过度乐观、或触地瞬间被误判为支撑相，证书就会在真实双足最脆的相切换点系统性放行，故必须以 **域外拒答 + 相检测置信门控 + 真实反例回灌重训** 三重护栏，宁可在域外保守停机，也绝不把"仿真里学会的步态"直接当作真实可部署的承诺。
