# 第 10 轮（承接 v9；本轮灵感：「材料选型」×「抓取规划」）

> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 493–539；引理 69–86；实验 E531–E570）。
> **本轮纪律**：**把证书钉在物理上**。v9 的抓取安全最终落在两个无量纲假设上：γ_grasp 是一个模型标签，「信任域内前向模型误差 ≤ β」是一个未含接触物理的统计量。材料选型攻击前者（抓取有效性由摩擦、柔顺、脆性决定），抓取规划攻击后者（几何与力闭合必须在参数不确定下成立）。本轮把 Ĉ_t 中的 γ_grasp 替换为**材料可信集上的稳健 ε-力闭合证书**，并把 v9 的「恒等元退化」升级为「保守顶退化」：失效方向一律指向更大的材料不确定性，而不是更乐观的默认值。

## 0. 直觉与动机

**灵感 1（材料选型 → 材料属性是一等安全参数）**
直觉：抓一个玻璃杯和一个金属罐，几何完全一样，安全边界却不同：摩擦系数决定摩擦锥半角，柔顺决定接触压力分布与位姿误差，脆性决定最大法向力。把材料当"上下文/域"是不够的；材料参数必须进入证书本身。核心创新：**材料可信集估计器（MaterialCredalEstimator, MCE）**：不再输出"玻璃/金属"标签或点估计 μ̂，而是输出与全部视觉-触觉-听觉证据一致的**可信集 C_t ⊆ M**（属性区间/集合），并显式维护"不知道"元素 ⊤。安全判定只消费 C_t 的最坏点。这样"材料选错"不会变成一次乐观的抓取，而是变成一次更保守甚至拒绝的抓取。

**灵感 2（抓取规划 → 稳健力闭合而不是分类标签）**
直觉：抓取规划的核心不是"预测成功"，而是**力闭合**：接触力能否张成包含任意外力的力旋量锥。给定摩擦系数 μ，摩擦锥半角 θ=arctan μ；μ 的不确定性直接收缩可行抓取集。核心创新：**稳健抓取证书规划器（GraspCertificatePlanner, GCP）**：在 C_t 上取最坏摩擦 μ_min 计算 ε-力闭合质量 ε_C(g)=min_{m∈C} ε(g,m)，并同时给出法向力上界（脆性）与 caging 备份。证书 Ĝ=(g, ε_C, F_n 区间, 滑移裕度, 阶段中止集)。μ_min 与 ε 的单调关系（引理 87–89）使无穷多个材料假设坍缩为若干端点，证书仍可 5Hz 计算。

**灵感 3（耦合 → 材料选型与抓取规划是同一个混合整数稳健优化）**
直觉：材料选型不只是"识别物体"，还是"选哪只夹爪/哪种指尖材料"这一离散执行决策；抓取规划是连续几何决策。二者不能串行流水线：选一只高摩擦软指尖会抬高 μ_eff，却牺牲位姿精度与力控带宽；选硬指尖反之。核心创新：把二者写成**联合选型**：在夹爪目录 P_cat 与抓取空间 G(x) 上最大化最坏情况 ε_C 减去换爪/位姿代价，约束为脆性力上界与阶段中止可用性（定义 543）。这一个公式同时解释了"为什么某些材料需要专用指尖"和"为什么未知材料应该退回 caging/双手"。

**灵感 4（退化方向 → 从代数恒等到保守单调）**
直觉（本轮最重要的一步批判）：v9 说"模块失效就注入中立元 v^⊥，逐位等价 v8"。这对**可观测行为**成立，但对**安全证书**不成立：Δ_dom≡0 或 μ←默认值是"回到基线"，而基线默认值未必是当前物体族的**最坏情况**。材料是第一个暴露该裂缝的变量——把摩擦注入一个中性默认值可能比真实摩擦更乐观。核心创新：**保守顶退化（Conservative-Top Degradation, CTD）**：在新模块的失效语义里区分"行为等价"与"安全反单调"；材料与抓取类模块失效一律映射到可信格顶 ⊤=M_cat（最大无知），由引理 87 保证证书只会收缩、不会膨胀。v9 的恒等退化保留给那些 v8 已证明保守的模块。

## 1. 研究问题（轮次升级版）

- **Q1（材料可信集与证书反单调）**：如何用有限、有界误差的多模态证据维护材料可信集，使"失效/未知 → ⊤"在证书上严格单调保守？端点充分性在什么假设下成立？
- **Q2（联合选型的可解性与稳定性）**：材料/指尖的离散选择与抓取的连续规划如何联合求解，既保持 5Hz 块生成预算，又不在换爪上产生抖振？
- **Q3（抓取阶段的安全与退化）**：抓取块如何划分阶段并给出阶段特定的中止动作？在材料先验被触觉改写（甚至重置为 ⊤）时，如何保证中块中止仍满足脆性与停车/支撑不变式？在已知材料域上如何逐位复现 v9，在未知域上如何只做安全收窄？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P16）

**P13 材料可信集律（Material Credal Set, MCE）**
材料不是标签而是安全参数向量 m=(μ_s,μ_k,κ_c,ρ,p_frag,τ_therm)。估计器输出可信集 C_t（属性盒/集合），而非点估计；维护知识格 (2^M, ⊆, ∪, ∩, ⊥, ⊤)，⊤=M_cat 表示最大无知。安全证书只消费 C_t 的最坏点；未知物体、证据冲突、估计器失效一律置 ⊤。可信更新须满足：在证据误差界内，真值始终被 C_t 包含。

**P14 稳健抓取证书律（Robust Grasp Certificate, GCP）**
抓取 g 的有效性由最坏材料下的 ε-力闭合质量 ε_C(g)=min_{m∈C} ε(g,m) 定义，而非模型标签 γ_grasp。证书同时携带脆性力上界 F_frag(C)=min_{m∈C} p_frag(m)·A_contact 与 caging 备份；三者任一不满足即拒绝该抓取。证书在块边界计算，中块只做廉价复核。

**P15 联合选型与阶段中止律（Joint Selection & Phase Abort, JSA）**
指尖/夹爪材料选择 p∈P_cat 与抓取几何 g∈G(x) 联合求解：max_{p,g} ε_C(g;p) − λ_c·c_pad(p) − λ_pose·e_pose(g,p)，受 ε_C≥ε_min、F_n≤F_frag(C)、换爪预算与 caging 约束。抓取块按 approach/close/lift/transport 分阶段，每个中止点绑定阶段特定的安全动作（后退/松开/下放/笼持），且安全动作力界服从 F_frag(C)。换爪只在块边界发生并带滞回。

**P16 保守顶退化律（Conservative-Top Degradation, CTD）**
新增模块的失效映射必须落在保守格的上方：材料/触觉/抓取模块失效 ⇒ C←⊤（或保持原 C），证书只会收缩。区分两种退化语义：(a) **行为等价退化**——v8 已证明保守的模块（DA/SPR/Cal 等）仍注入 v9 中立元，逐位退回 v9；(b) **安全收窄退化**——材料/抓取模块的新增保证不被 v8 覆盖，失效时只能回到更小的认证抓取集，不许回到更乐观的默认值。已知材料域上 v10 逐位复现 v9；未知材料域上 v10 的认证集 ⊆ v9 可接受集。

## 3. 与基线的接口（如何退化）

- MCE 超时/不可用/检测到目录外材料 ⇒ C_t←⊤；ε_⊤ 收缩；若 ε_⊤<ε_min ⇒ 仅 caging/双手/求人，K_eff^g←1；
- TSO 超时 ⇒ 保持 C_t 不更新、关闭滑移预警，但仍由 ε_C 与 AC 守卫兜底（不扩大证书）；
- GCP 超时/无可行抓取 ⇒ 退回 v9 AC 的单步 + v9 γ_grasp（仅已知材料域；未知域退回 caging）；
- MGL 不可用 ⇒ 用目录类级保守包络并标记 uncalibrated；未知类直接 ⊤；
- MW/ID/AC 失效 ⇒ 按 v9 五级链退化；
- 已知材料域全失效 ⇒ 逐位等价 v9（引理 93a）；未知材料域 ⇒ 认证集 ⊆ v9 可接受集（安全收窄，引理 93b）；
- 全部失效 ⇒ v9→v8→v7→v6。

## 4. 预期贡献

1. **材料可信集 + 稳健力闭合证书**：把 γ_grasp 从无量纲标签升级为有物理量纲、可审计的最坏情况界，且证书对材料不确定性反单调（引理 87–89）；
2. **材料-夹爪-抓取联合选型**：一个混合整数稳健优化统一"识别材料"与"选指尖/生成抓取"，避免感知-规划串行流水线的接口失配；
3. **保守顶退化**：指出并修补 v9 中立元退化在安全语义上的裂缝，给出行为等价 vs 安全收窄的双轨退化定理（引理 93）；
4. **触觉闭环材料可信更新**：滑移/无滑移观测作为摩擦上下界，带不一致检测与 ⊤ 重置，使"抓取过程中才发现选错材料"成为可安全处理的事件（引理 90）；
5. 实验 E571–E590 覆盖材料误判、目录外、湿滑、脆性、滑移预警、换爪稳定、已知域等价与端到端任务。

## 5. 本轮最大风险

**一句话**：我们把"保守"定义为"材料目录 M_cat 内的最坏情况"，但若真实材料落在目录外（湿滑涂层、内部液体晃动、未知复合材料），⊤ 并不包含真值，稳健证书就不再稳健——本轮只是把 v9 的"乐观假设"从模型标签搬到了"目录完备性"上。

**新增定义 540（材料属性空间与可信格 Material Credal Set）** 材料属性 m=(μ_s,μ_k,κ_c,ρ,p_frag,τ_therm)∈M⊆ℝ⁶；对物体 o，C_o(t)⊆M 为与截至 t 的全部证据相容的属性集合。知识格取 (2^M,⊆,∪,∩,⊥,⊤)：C₁⪯_K C₂ ⇔ C₁⊇C₂（越大的集合越无知），⊔=∪（合并独立证据源的保守上界），⊓=∩（同时采信两源），⊥={m}（完全已知），⊤=M_cat（全材料目录）。工程实现用属性盒 C=∏_i[l_i,u_i]；非盒情形用盒外包 C⊆□(C)，保守性由引理 87 保持。未知物体、目录外检测、估计器失效均置 C_0=⊤。

**新增定义 541（有界误差证据与可信更新 Credal Update）** 传感器证据 y_t=h(m)+e_t，误差界 ‖e_t‖≤δ_t（δ_t 由账本 L 在离线标定，带时间衰减）。观测相容集 O_t={m:‖h(m)−y_t‖≤δ_t}。更新：
```
C_{t+1} = C_t ⊓ O_t        若 C_t ⊓ O_t ≠ ∅ 且一致性检查通过
        = ⊤                 否则（证据冲突 / 传感器故障 / 未知类）
```
两类特殊观测由 TSO 提供：无滑移于切向比 r ⇒ O⁺={m: μ_s(m) ≥ r−δ_s}；滑移起始于 r ⇒ O⁻={m: μ_s(m) ≤ r+δ_s}。可证：当误差界有效时，真值 m* ∈ C_t 对所有 t 成立；重置到 ⊤ 只会扩大集合，故保持包含性（引理 90）。

**新增定义 542（稳健 ε-力闭合证书 Robust Grasp Certificate）** 给定抓取 g=(K,F_n,p) 与材料 m，有效摩擦 μ_eff(m,p)=min(μ_obj(m), μ_pad(p))（Coulomb 接触；柔顺 κ_c 通过接触面积/压力分布修正，见定义 543）。力旋量锥
```
W(g,m) = { Σ_{i∈K} (f_i, p_i × f_i) : f_i ∈ Cone(n_i, μ_eff(m,p)), ‖f_i‖ ≤ F_n }
```
ε(g,m)=max{r : B_r(0) ⊆ W(g,m)/L_o}（L_o 为物体力旋量尺度）。稳健证书
```
ε_C(g) = min_{m∈C} ε(g,m),    F_frag(C) = min_{m∈C} p_frag(m)·A_contact(K)
```
抓取被认证 ⇔ ε_C(g) ≥ ε_min ∧ F_n ≤ F_frag(C) ∧ caging(g) ≠ ∅。证书 Ĝ=(g,ε_C,[F_n^min,F_n^max],s_m,C.id,P^g)，其中 C.id 记录产生该证书的可信集版本，供事后审计。

**新增定义 543（材料-指尖-抓取联合选型 Joint Material-Pad-Grasp Selection）** 指尖/夹爪 p∈P_cat，抓取 g∈G(x)。联合稳健优化：
```
(p*,g*) = argmax_{p∈P_cat, g∈G(x)}  ε_{C}(g;p) − λ_c·c_pad(p) − λ_pose·e_pose(g,p)
          s.t.  ε_C(g;p) ≥ ε_min,
                F_n(g) ≤ F_frag(C),
                τ_change(p) ≤ B_grasp,
                caging(g) ≠ ∅.
```
离散选择只在块边界发生；换爪采用滞回：仅当新方案 ε 改善 > h_pad 才切换，且每块至多一次。Ashby 式选型指数作为同分裁决：I(p)=μ_eff^wc(p)·A_contact/(F_n^wc·e_pose(p))；在 Pareto 前沿上按 I 降序取首个可行解。柔顺 κ_c 进入两项：抬高有效接触面积（增益）与增大位姿误差/力控滞后（代价），故不是单调偏好。

**新增定义 544（抓取阶段与阶段化中止集 Grasp-Phase Abort Set）** 抓取块 ζ^g=(a^{1:K},Ĝ,P^g) 的阶段划分 Π={approach,close,lift,transport}。中止点 p∈P^g 绑定阶段安全动作：
```
σ_approach = 沿预抓取方向后退至 clearance ≥ d_safe
σ_close    = 松开至 F_n=0 并后退；力不超过 F_frag(C)
σ_lift     = 下放至支撑面并松开；竖直速度指数衰减
σ_transport= 笼持/就地放置；保持 caging 约束
```
对每个 p，存在阶段 π(p) 使 σ_{π(p)} 的停车/支撑不变式成立：
```
dist(s_p, O) − |traj_{p:K}| ≥ d_brake^π(v_p) + d_safe  (approach/transport)
F_n(p) ≤ F_frag(C)  ∧  support(s_p)       (close/lift)
```
抓取块仅当 P^g≠∅ 时被接受；"无点可退"只允许发生在 K=1 的 v9 单步回退。

**新增定义 545（材料-抓取联合信任门 Joint Trust Gate）** 抓取信任
```
U^g_t = { Δ_dom<τ_dom ∧ risk_SLAM<τ_SLAM ∧ ρ_ε≥1 ∧ s_m>s_warn ∧ material_sound }
```
其中 material_sound 表示 C_t 未被置 ⊤ 且未标记 uncalibrated。有效抓取块长
```
K_eff^g(t) = 1                                            若 ¬U^g_t
           = min( K_eff^{v9}(t), K_g(ε_C) )                否则
K_g(ε) = clamp( ⌊K_max·(ε−ε_min)/(ε_ref−ε_min)⌋, 1, K_max )
```
K_g 单调不减于 ε_C：材料越不确定，抓取块越短；证书裕度不足时退化为单步抓取-复核。

**新增定义 546（触觉滑移预警与可信收缩 Tactile Slip Observer）** 触觉量：法向力 f_n、切向力 f_t、微振动能量、接触面积变化率。滑移裕度
```
s_m(t) = 1 − ‖f_t‖ / ( μ_min(C_t)·max(f_n, f_ε) )
```
摩擦下界 μ_min(C_t) 取 C_t 的 μ 下端点。滑移起始检测（切向比趋近 1 且微振动/面积突变）时，切向比 r=‖f_t‖/f_n 给出 O⁻；否则若无滑移且 f_n 足够大，给出 O⁺。若 s_m<s_warn 或更新后 ρ_ε<1，立即触发 `abort` 到最近阶段中止点；若观测与 C_t 冲突（C_t⊓O=∅），置 C←⊤ 并强制 abort + regrasp（不可继续用已污染的先验）。

**新增定义 547（材料-抓取证据账本 Material-Grasp Ledger）** 追加式记录
```
L ∋ (object_class, C_class, p, g, ε_C, F_n, outcome, δ_s, contact_law_id, ts)
```
用途：(i) 为已知类提供保守类级包络 C_class（作为 C_0 的先验）；(ii) 离线标定 δ_s、接触律与 pad 的 μ_pad；(iii) 目录外检测（object_class 的证据与所有 C_class 交集为空 ⇒ OOD）；(iv) 审计。L 不得把未知类强行归入已知类；未知类只能从 ⊤ 出发。

**新增定义 548（保守顶退化格 Conservative-Top Degradation）** 配置空间按证书保守性排序：c₁ ⪯_S c₂ ⇔ ε(c₁) ≥ ε(c₂)（c₁ 更保守则其认证集更小）。失效映射 f 满足单调性：若模块 M 失效，f(C) ⪰_S C，即证书不膨胀、认证集不收窄。双轨语义：
- **轨道 A（行为等价）**：v8 已证明保守的模块（DA/SPR/Cal、MW、ID、AC 调度），失效注入 v9 中立元，日志逐位等价 v9；
- **轨道 B（安全收窄）**：材料/触觉/抓取模块，失效置 ⊤ 或保持原 C，v10 认证集 ⊆ v9 可接受集。
已知材料域（L 覆盖且 OOD=false）上，类级包络使轨道 A 与轨道 B 在抓取判定上重合 ⇒ 逐位等价 v9（引理 93a）。未知域上只保证包含关系（引理 93b）。

**新增定义 549（材料-抓取审计协议 Material-Grasp Audit, MGA）** 离线/红队套件：(a) 已知类材料误标（玻璃↔金属）；(b) 目录外材料（湿滑涂层、装液容器、复合材料）；(c) 脆性（蛋壳/陶瓷）与可变形（织物/面包）；(d) 触觉故障（偏置/卡死/延迟）；(e) 对抗视觉（贴纸伪装摩擦）；(f) 换爪抖动；(g) 长跑磨损/湿度漂移。指标：认证抓取成功率、滑移率、压碎率、保守误拒率、OOD 检出率、已知域 v9 日志等价率、端到端任务分。MGA 不参与在线决策。

δ_trigger = { σ<τ_safe ∧ γ_grasp^rob valid ∧ Δ_dom<τ_dom ∧ risk_SLAM<τ_SLAM ∧ Ĉ_t valid }

# ---------- 基础容器 ----------
@dataclass(frozen=True)
class Interval:
    lo: float; hi: float
    def intersect(self, o):
        lo, hi = max(self.lo, o.lo), min(self.hi, o.hi)
        return None if lo > hi else Interval(lo, hi)

@dataclass(frozen=True)
class MaterialCredalSet:
    mu:   Interval   # [mu_lo, mu_hi]
    comp: Interval   # contact compliance
    frag: Interval   # max pressure; safety uses frag.lo
    mass: Interval
    unknown: bool = False
    sound:   bool = True

    @staticmethod
    def top():       # 最大无知 = 全目录外包（定义 540）
        return MaterialCredalSet(Interval(0.05, 1.2), Interval(0.0, 1e-2),
                                 Interval(1.0, 1e9), Interval(0.0, 1e3),
                                 unknown=True, sound=False)

    def worst(self):  # 引理 87/88：安全只消费最坏点
        return Material(mu=self.mu.lo, compliance=self.comp.hi,
                        frag_max=self.frag.lo, mass=self.mass.hi)

    def observe_noslip(self, r, delta):      # O⁺ = {mu >= r-delta}
        mu = self.mu.intersect(Interval(r - delta, 1e9))
        return MaterialCredalSet.top() if mu is None else replace(
            self, mu=mu, sound=True)

    def observe_slip(self, r, delta):        # O⁻ = {mu <= r+delta}
        mu = self.mu.intersect(Interval(0.0, r + delta))
        return MaterialCredalSet.top() if mu is None else replace(
            self, mu=mu, sound=True)

class MaterialCredalEstimator:

        self.L, self.perceive, self.delta = ledger, perceiver, delta_fn

    def init_for(self, obs):

        if cls is None or self.L.is_ood(cls, obs):
            return MaterialCredalSet.top()             # 目录外 → ⊤
        return self.L.class_envelope(cls)              # 已知类保守包络

    def update(self, obs, C_prev):
        y = self.perceive.material_evidence(obs)       # 视觉/音频/深度

        C = self._intersect(C_prev, O)

# ---------- IP-358 GraspCertificatePlanner ----------
@dataclass
class GraspCert:
    grasp: object; eps: float; f_min: float; f_max: float
    slip_margin: float; cset_id: int; abort_points: list

class GraspCertificatePlanner:
    def __init__(self, eps_min=0.15, lam_c=0.2, lam_p=0.3, h_pad=0.02,
                 k_max=10, eps_ref=0.6, d_safe=0.15):
        self.eps_min, self.lam_c, self.lam_p = eps_min, lam_c, lam_p
        self.h_pad, self.k_max, self.eps_ref, self.d_safe = (
            h_pad, k_max, eps_ref, d_safe)

    def robust_eps(self, g, C, pad):
        m = C.worst()                                  # 引理 88 端点充分性
        mu = min(m.mu, pad.mu)                         # Coulomb 有效摩擦
        W = self.wrench_cone(g.contacts, mu, pad.compliance)
        return self.eps_quality(W, g.scale)

    def plan(self, pc, C, pad_catalog, budget_ms, current_pad):
        best = None
        for pad in pad_catalog:
            if pad.changeover_ms > budget_ms:
                continue
            if current_pad and pad != current_pad and self._no_switch_gain(
                    best, pad, C, current_pad):        # 滞回（引理 91）
                continue
            for g in self.sample_grasps(pc, n=64):
                eps = self.robust_eps(g, C, pad)
                fmax = min(C.worst().frag_max, pad.f_max)
                if eps < self.eps_min or g.f_n > fmax:
                    continue
                if not self.has_caging_backup(g, C):
                    continue
                pts = self.phase_abort_points(g, C)    # 定义 544
                if not pts:
                    continue
                score = (eps - self.lam_c * pad.cost
                         - self.lam_p * self.pose_error(g, pad))
                if best is None or score > best.score:
                    best = Candidate(g, pad, eps, fmax, pts, score)
        if best is None:
            return self.degrade(pc, C)                 # 定义 548：未知→caging
        return GraspCert(best.g, best.eps, 0.0, best.fmax,
                         slip_margin=1.0, cset_id=id(C),
                         abort_points=best.pts)

    def phase_abort_points(self, g, C):
        pts = []
        for p in range(1, len(g.actions)):
            pi = g.phase_at(p)
            if pi in ("approach", "transport"):
                margin = (g.clearance[p]
                          - g.brake(pi, g.speed[p]) - self.d_safe)
                if margin >= g.remaining_len(p):
                    pts.append((p, pi))
            else:                                       # close / lift
                if g.f_n[p] <= C.worst().frag_max and g.has_support(p):
                    pts.append((p, pi))
        return pts

    def k_grasp(self, eps):
        ratio = (eps - self.eps_min) / max(self.eps_ref - self.eps_min, 1e-6)
        return max(1, min(self.k_max, int(self.k_max * ratio)))

class TactileSlipObserver:
    def __init__(self, s_warn=0.15, delta_s=0.03, eps_f=1e-6):
        self.s_warn, self.delta_s, self.eps_f = s_warn, delta_s, eps_f

    def update(self, tactile, C):
        f_n = max(tactile.f_n, self.eps_f)
        r = tactile.f_t / f_n
        sm = 1.0 - r / max(C.mu.lo, 1e-3)              # 定义 546 滑移裕度

            return ("abort_regrasp" if sm < self.s_warn or not C2.sound
                    else "hold"), C2, sm
        C2 = C.observe_noslip(r, self.delta_s)          # 无滑移 → O⁺
        return ("abort" if sm < self.s_warn else "continue"), C2, sm

## 4. 推导

**引理 87（可信集单调与证书反单调）** 设 C₁⊆C₂。则对任意抓取 g，ε_{C₁}(g)=min_{m∈C₁}ε(g,m) ≥ min_{m∈C₂}ε(g,m)=ε_{C₂}(g)，且 F_frag(C₁) ≥ F_frag(C₂)。故 C 变大（更无知）只会让证书更保守；失效映射 C↦⊤ 不可能提高认证裕度。证明：有限集上的 min 对集合包含反单调。∎

**引理 88（端点充分性）** 若 C 为盒 ∏[l_i,u_i]，且 ε(g,m) 对 μ 单调不减、对 p_frag 单调不减、对 κ_c 与质量按已知单调方向（柔顺过大降位姿精度、质量过大升所需力），则 min_{m∈C}ε(g,m) 在盒的某个顶点取得；对摩擦项即 μ_min=l_μ。证明：单调函数在多维盒上的最小值在支配最坏点的顶点取得；必要时用 ε 的拟凸性取极值点。故稳健证书每次只需 O(2^d) 次 ε 评估，d≤4 时 ≤16 次。∎

**引理 89（稳健力闭合可靠性）** 若 ε_C(g)≥ε_min 且 F_n≤F_frag(C)，则对每个 m∈C，g 在 m 下是 ε_min-力闭合且法向力不超脆性上限；准静态下不发生宏观滑移。若中块触觉把 C 更新为 C'（C'⊆C 或 C'=⊤），则 ε_{C'}≤ε_C；当 ρ_ε<1 时定义 545 强制 K_eff^g=1 或 abort，故安全不变式不被破坏。证明：ε 定义给出力旋量球包含，摩擦锥由 μ_eff≥μ_min 保证；C' 变大由引理 87 得证书收缩；abort 由定义 544 保证可停驻。∎

**引理 90（触觉有界误差更新的可靠性）** 设真值 m*∈C_t 且触觉误差满足 |e_s|≤δ_s。无滑移于切向比 r 推出 μ*(m*)≥r−δ_s，故 m*∈O⁺；滑移起始于 r 推出 μ*≤r+δ_s，故 m*∈O⁻。若 C_t⊓O≠∅，则 m*∈C_t⊓O；若为空，说明先验或误差界被违反，置 ⊤ 必包含 m*。因此只要 δ_s 是真实误差上界，C_t 始终是 m* 的可靠外包；滑移裕度 s_m 用 μ_min(C_t) 计算，故不会高估可承受切向力。∎

**引理 91（联合选型稳定性 / 无 Zeno）** 换爪仅在块边界发生，且需 ε 改善 > h_pad 并受 B_grasp 约束；每块至多一次切换。故切换次数 ≤ ⌊T/h_chunk⌋，不产生 Zeno 抖振；若预算耗尽则保持当前指尖，证书按当前 p 重算。证明：切换事件被块边界离散化并加滞回，相邻事件间隔 ≥ 一个块周期。∎

**引理 92（抓取阶段中止安全性）** 若 P^g≠∅，任一中止点 p 绑定阶段安全动作 σ_{π(p)}。对 approach/transport，定义 544 的停车不变式保证刹停后距障碍 ≥d_safe；对 close/lift，F_n≤F_frag(C) 且存在支撑/下放路径，故不会压碎或跌落。中块材料更新只改变 C 与 ε_C，不改变 σ 的阶段定义；若更新使 ρ_ε<1，则 abort 到最近 p，结论仍成立。∎

**引理 93（保守顶退化与 v9 双轨关系，升级引理 83）**
(a) **已知材料域**：若 L 对每个类提供保守类级包络 C_class，且 v9 的 γ_grasp 判定在 C_class 下等价于 ε_{C_class}≥ε_min ∧ F_n≤F_frag(C_class)（由 E580 逐位校验），则 MCE/GCP 失效并回退该类包络与 v9 AC 时，日志逐位等价 v9。
(b) **未知/目录外域**：C=⊤，认证集 {g:ε_⊤(g)≥ε_min, F_n≤F_frag(⊤)} ⊆ {g:γ_grasp^{v9}(g)=valid}（在 v9 可接受集上取更严约束），故只发生安全收窄；若 ε_⊤ 无可行解则返回 caging/双手/求人。
(c) **端到端**：任一 v10 状态或属于 (a) 的 v9 等价路径，或属于 (b) 的稳健证书路径；M₀ 只消费 ε_C 与 F_frag(C)（升级定义 531），故 v8/v9 的九不变式与安全引理原样传递。唯一新增前提是 C=⊤⊆M_cat 包含真实材料——即本轮最大风险。∎

**推论 94（材料不确定下的安全-可用性权衡）** 由引理 87 与定义 545，K_eff^g 随 ε_C 单调减、随 ρ_ε 增；因此材料不确定性以"块长/抓取模式"为代价换取安全，而不是以"证书放宽"为代价。该权衡可通过 ε_min 与 K_g 的斜率在 E572/E582 上显式测量。∎

## 8. 本轮最大风险

**一句话**：我们把"保守"定义为"材料目录 M_cat 内的最坏情况"，但若真实材料落在目录外（湿滑涂层、内部液体晃动、未知复合材料），⊤ 并不包含真值，稳健证书就不再稳健——本轮只是把 v9 的"乐观假设"从模型标签搬到了"目录完备性"上。
