# 第 15 轮（新灵感循环第 1 轮；本轮灵感：「伦理审查」×「模型量化」）

> **基线**：第 14 轮 MetricVoiceGauge-NCD-HUTDH（定义 595–606；引理 113–124；实验 E647–E660）。
> 本轮纪律：**审查即消除 + 量化即扰动 + 审查部署工件同一性**。不推倒 v14：v13 的 AIO/CPD/DDL/RTCR、v14 的 HBR/UCCI/PAA 与 MetricVoiceGauge 九不变式全部保留。三个新组件——ERC（伦理审查证书）、QGC（量化间隙证书）、EQC（伦理—量化耦合器）——一律以**中立元**接入，失效即严格退回 v14（引理 133），再沿 v14 退化链退回 v13/v12/v11/v10/v9/v8/v7/v6。本轮只做三件事：把"伦理审查"从一次性部署盖章改写为**逐动作、可撤销、可审计的红线证书**；把"模型量化"从精度压缩改写为**证书边界的有界扰动 + 量化税**；把二者合成同一条纪律——**只认证你真正部署的那个工件**。

## 0. 直觉与动机

**灵感 1（伦理审查 → 从盖章到红线圈、灰区与可撤销账本）**
直觉：今天的伦理审查几乎是一次性 IRB 盖章：委员会审查论文、数据与"预期用途"，通过后系统上线，之后一切交给运行时安全证书。这留下三个结构性缝隙。第一，**开放世界问题**：不可能穷举所有"被允许的动作"，但可以相对稳定地列出"绝对不许做的事"。第二，**审查—执行缝隙**：审查针对的是受控实验里的模型与分布，部署却在漂移、被压缩、被用户改写。第三，**伦理不是单一标量**：多元价值无法被一个 reward 排序，审查真正能提供的不是"善的答案"，而是**程序保证**——红线、可争辩、可追溯、可撤销。于是核心创新：**伦理审查证书（Ethics Review Certificate, ERC）**，把审查结果写成一个运行时谓词包络 `E_τ`：绝对红线 `F_abs`（任何时刻、任何时间压力、任何用户偏好都不得越过）、可审查红线 `F_rev`（默认禁止，仅在带约束授权的有效期内允许）、灰区 `G`（需逐动作人类签核）、以及撤销纪元 `τ` 与只增不改的审查账本。关键反直觉点：**伦理许可应当是"减法"而不是"加法"**——不认证"哪些动作允许"，而认证"哪些动作绝对禁止，其余必须落在已审查包络内"。减法天然单调：新增红线或撤销授权只会缩小执行集，永远不会凭空放大授权。

**灵感 2（模型量化 → 量化是证书边界的有界扰动，而精度不是安全度量）**
直觉：量化被当成"免费加速"：INT8 掉点不到 1%，于是默认可以上线。但安全关键系统的正确量纲不是平均精度，而是**薄边界上的判决**。权重量化是对参数的有界扰动 `‖W_Q − W‖ ≤ ε_Q`；若证书余量函数 `m_W(x,a)` 对参数 L-Lipschitz，则 `|m_{W_Q} − m_W| ≤ L·ε_Q`。这个界允许我们把量化误差写进证书：量化学生必须把阈值抬高 `U_q(x)`，即只在 `m_{S_Q}(x,a) ≥ θ + U_q(x)` 时放行，于是 `Acc_{S_Q} ⊆ Acc_S ⊆ Acc_T`——**量化只弱不强**，与 v13 的蒸馏纪律同构。更重要的是，量化会**按输入、按群体地系统性偏移**：某些低精度激活区间、某些少数群体样本恰好处在红线上，平均精度完全看不出来。因此量化间隙必须逐输入计算（用区间界传播/CROWN 求更紧的 `U_q(x)`），而不是全局一个数。核心创新：**量化间隙证书（Quantization Gap Certificate, QGC）+ 量化税**。量化买来速度，代价是更保守的阈值、更高的假拒绝和更小的有效安全余量。

**灵感 3（伦理审查×模型量化 → 只审查你真正部署的工件）**
直觉：最危险的不是"没审查"，而是"审查了另一个模型"。伦理委员会审的是 float32 教师、受控校准集；上线的是 INT4 学生、共享骨干多出口、还带用户偏好位移。两者在平均行为上可以几乎一样，却在红线附近不同——这正是 v13 DGC 警告过的"薄边界"，只不过这次薄边界同时是**安全边界**与**伦理边界**。所以两条纪律必须合并：**审查对象同一律（review the deployed artifact）**。第一，伦理证书必须绑定部署工件的哈希（权重精度、校准集、配置、代码版本）；改精度、改校准、改蒸馏目标即失效，需重审或塌缩。第二，红线圈定义在**语义动作**上，但量化改变的是**策略选择**；因此需要**红线邻域行为等价证书**：在红线边界 ρ-邻域内，量化策略必须不比已审策略更冒险，否则触发 **Q-escape**，把该决定升级到全精度教师或人工签核。第三，量化税与审查预算都是稀缺货币：量化误差吃掉安全余量，灰区签核吃掉人的注意力 `B_review`，二者**不可互相冲抵**。核心创新：**伦理—量化耦合器（Ethics-Quantization Coupler, EQC）**。它把"审查—量化—部署"从流水线上三个独立图章，变成一个必须同时成立的**不动点**：只部署被审查的工件，只审查可被证书支撑的行为。

**三者如何统一**
统一为 **v14 安全/实时层之上的许可与保真层**：v14 回答"在毫秒预算内能安全实现多少、由哪个学生实现"（`Exec_v14`），v15 回答"这些可实现的决策里，哪些落在已审查的伦理包络内、且在量化后仍然成立"（`Exec_v15`）。ERC 是**单调消除算子**（只删不加），QGC 是**有界扰动证书**（只加税不加权），EQC 是**绑定与升级算子**（把部署工件与审查工件对齐，并把越界决定升级）。共享状态 `ζ_eth = (E_τ, F_abs, F_rev, G, τ, artifact_id, W_Q, U_q(x), B_review, mode)`。**ERC 回答"什么绝对不能做"，QGC 回答"量化后还能证到什么"，EQC 回答"我审查的到底是不是我正在跑的东西"**。三者不是三个合规补丁，而是"红线—扰动—同一性"的许可链。

## 1. 研究问题（本轮升级版）

- **Q1（审查的可执行语义）**：如何把伦理审查编码成运行时证书，使"红线绝对、灰区可争辩、授权可撤销"同时成立？红线圈的加法与执行集的减法如何保持单调与组合一致？多元价值下如何避免把伦理压成单一 reward 而仍保持运行时判定不矛盾？
- **Q2（量化的可证边界）**：如何给出逐输入、可计算的量化间隙 `U_q(x)`，使 `Acc_{S_Q}⊆Acc_S⊆Acc_T` 在 INT4/INT8、权重量化与激活量化下都成立？量化误差与 DGC 的蒸馏间隙、TGC 的迁移间隙如何相加而不互相掩盖？群体性偏移如何被逐群体共形界覆盖？
- **Q3（审查与量化的耦合）**：如何定义并检验"审查对象同一性"？红线邻域的行为等价证书需要多宽的 ρ、多紧的界？Q-escape 何时优于直接回退、何时只是无谓的人工负担？审查注意力 `B_review` 如何与实时预算 `B_time` 联合调度而不互相挪用？
- **Q4（与 v14 的兼容与活性）**：伦理包络会不会把可行集删空、导致频繁 `a_ask^eth`？量化税会不会让学生阶梯塌到第 0 档？新增模块能否守住 50Hz/p99≤22ms，并严格退回 v14？审查账本与撤销通道本身能否被攻击或伪造？

## 2. 设计原则（在 P22–P24 基础上新增 P25–P27）

**P25 审查即消除律（Review Eliminates, Never Grants）**
伦理审查只能缩小执行集，不能新增授权：`Exec_v15⊆Exec_v14`。绝对红线 `F_abs` 不可被时间压力、安全收益、用户偏好 `α_user`、蒸馏速度或量化节省覆盖；灰区 `G` 必须由显式人类签核放行，不得用模型置信度替代。任何"综合伦理分数"只能用于排序，不能把红线变成软约束。

**P26 量化即扰动律（Quantization is Bounded Perturbation）**
任何精度降低都必须携带量化间隙证书 `U_q(x)`；量化后的学生、验证器与证书网络都必须满足单侧包含 `Acc_{S_Q}⊆Acc_S`，未经认证的量化模型不得出现在安全关键路径上。量化误差必须显式加入余量、写入风险账本，绝不能被"平均精度不变"吸收。量化只能买速度，不能买权限。

**P27 审查对象同一律（Review the Deployed Artifact）**
伦理证书绑定到部署工件的哈希与版本；精度、校准集、蒸馏目标、代码或值模型任一改变即失效，触发重审、Q-escape 或塌缩。对 float 教师的审查结论不能自动授权量化部署；只有当红线邻域行为等价证书成立时，审查才可被"迁移"到量化工件，否则必须重新审查。

## 3. 与基线的接口（如何退化）

- ERC 失效 ⇒ 注入 `E_τ≡⊤`：伦理包络不删除任何动作，无红线拦截、无灰区签核、无撤销通道，**等价 v14 执行路径**；
- QGC 失效 ⇒ 令 `U_q≡0` 且强制**反量化到全精度**（或禁用一切量化学生/量化验证器），只走 v14 全精度路径，**等价 v14（无量化）**；
- EQC 失效 ⇒ 无工件绑定与红线邻域等价检查，量化模型仅作 v14 事后预筛且必须全精度复核，**等价 v14 + 全精度复核**；
- 三者全失效 ⇒ MetricVoiceGauge-NCD-HUTDH v14，再沿 v14 退化链退回 v13/v12/v11/v10/v9/v8/v7/v6；
- **安全继承**：ERC 只做交集、QGC 只抬高阈值、EQC 只做升级或拒绝。三端口互不相交，均不能新增授权、不能放宽 v14 任何证书阈值；`Exec_v15⊆Exec_v14` 由引理 125 保证。

## 4. 预期贡献

1. **伦理审查的运行时证书化**：把"部署前盖章"改写为红线圈 + 灰区 + 可撤销账本的逐动作谓词，用"负认证"绕开开放世界许可枚举，填补审查与执行之间的结构性缝隙；
2. **量化间隙证书与量化税**：把模型量化从经验精度指标改写为证书边界上的有界扰动，给出逐输入 `U_q(x)` 与单侧包含证明，并显式计量量化带来的活动性损失；
3. **审查—量化不动点**：提出"只审查你部署的工件"的绑定原则与红线邻域行为等价证书，用 Q-escape 把"审查了错模型"的风险变成可调度的升级率；
4. **语义层—许可层分离**：v14 管"来得及做什么"，v15 管"被允许做什么、量化后还证不证得住"，用 `Exec_v15⊆Exec_v14` 把加速、安全与伦理许可解耦；E661–E680 覆盖红线有效性、量化单侧包含、群体偏移、工件同一性、审查预算与端到端消融。

## 5. 本轮最大风险

**一句话**：ERC 认证的是"程序与红线"而非"善本身"，QGC 认证的是"相对全精度学生不更冒险"而非"绝对正确"——当红线圈本身编码了有偏的价值排序、而量化误差又恰好集中在某个未被校准覆盖的少数群体上时，系统会在"已审查、已量化、按时、单侧包含、可追溯"的全套证书之下，稳定地、可复现地产生一个**程序完全合规却伦理上错误**的决定。

**定义 607（伦理许可包络与红线圈 Ethics Envelope & Red Lines）**
对动作空间 `A`，定义
```
E_τ(x) = { a∈A :
             a ∉ F_abs(x)
           ∧ ( a ∉ F_rev(x)  ∨  Auth_τ(x,a)=1 )
           ∧ ( a ∉ G(x)      ∨  Sign_τ(x,a)=1 ) } .
```
其中 `F_abs` 为**绝对红线**（永久禁止），`F_rev` 为**可审查红线**（默认禁止、带约束授权可放行），`G` 为**灰区**（须逐动作签核），`A\（F_abs∪F_rev∪G）` 为已审查白区（直接允许但记账）。伦理审查的产物不是"允许列表"，而是 `(F_abs,F_rev,G,Auth_τ,Sign_τ,τ)`。v15 执行集定义为
```
Exec_v15(x) = Exec_v14(x) ∩ E_τ(x) ∩ Acc_{S_Q}(θ+U_q(x)) .
```

**定义 608（灰区人工授权与审查预算 Gray-Zone Authorization & Review Budget）**
设人类审查注意力以速率 `B_review` 提供，审查队列 `Q_rev` 按优先级服务：`F_abs` 触发**零等待即时否决**（不进队列，直接停/柔顺/回退）；`G` 触发 `a_ask^eth` 入队，等待签核 `Sign_τ`；`F_rev` 需带约束授权，代理人可在预授权范围内答复。若在时限 `h` 内未获签核，唯一允许动作是认证回退，**不得执行"待审"动作**。定义有限审查预算下的伦理残差上界 `ε_eth(B_review)`：单位时间内未在期限前解决、只能回退的灰区决定比例。审查注意力与计算预算**不可互换**：`B_review` 不能由更多 GPU 或更低量化精度购买。

**定义 609（审查账本、工件绑定与撤销 Review Ledger, Binding & Revocation）**
审查账本为只增序列
```
L = { (artifact_id, scope, decision, evidence, τ, expires) } ,
artifact_id = H(W_Q, calib_set, config, code_hash) .
```
证书 `C_eth` 有效当且仅当
```
C_eth.artifact_id = H(当前部署工件)  ∧  τ_now ≤ C_eth.expires  ∧  ¬Revoked(C_eth, τ_now) .
```
`Revoke(τ')` 以 `τ'>τ` 追加，旧证书立即失效；陈旧证书只能触发 `S_0` 回退与重审，不能继续授权。账本哈希链保证撤销与授权不可被静默改写。

**定义 610（量化扰动与量化间隙 Quantization Perturbation & Gap）**
设量化映射 `W_Q=Q(W)`，参数扰动 `ε_Q=‖W_Q−W‖`。对证书余量 `m_W(x,a)` 定义逐输入量化间隙
```
U_q(x) = U_w(x) + U_act(x) + U_round ,
U_w(x)    = sup_{W'∈B(W_Q,ε_Q)} | m_{W'}(x,·) − m_{W_Q}(x,·) | ,
```
`U_act` 为激活量化引入的传播误差，`U_round` 为舍入/溢出项。`U_w` 用区间界传播（IBP）或 CROWN 的线性松弛逐输入求上界；`U_act` 按层 Lipschitz 复合。定义量化税：安全余量必须被同一 `U_q(x)` 抵消。并定义群体修正 `U_q^{(g)}(x)`：对每个受保护群体 `g` 单独校准共形分位，取 `U_q^{(g)}=U_q+Δ_g`，`Δ_g` 为群体尾部分位差，防止系统性偏移被总量平均掩盖。

**定义 611（量化证书包含 Quantized Certification Containment）**
设 v13 蒸馏间隙为 `U_d`，用户阈值 `θ_{S,user}`。量化学生 `S_Q` 的放行集定义为
```
Acc_{S_Q} = { a : m_{S_Q}(x,a) ≥ θ_{S,user} + U_d + U_q(x) } .
```
则要求
```
Acc_{S_Q}(θ_{S,user}+U_d+U_q) ⊆ Acc_S(θ_{S,user}+U_d)
                              ⊆ Acc_T(0) .
```
即量化只允许在 `U_d` 之上再叠加 `U_q` 的**单侧收缩**；任何试图用"平均精度不变"抵消 `U_q` 的部署都被视为证书失效。

**定义 612（审查对象同一性 Reviewed-Artifact Identity）**
对任意审查决定 `C_eth(W)` 与量化工件 `W_Q=Q(W)`：
```

```
`Δ_eth` 是两工件在伦理相关判决上的行为差（见定义 613）。因此 v15 要求伦理证书绑定 `artifact_id`，并规定部署顺序为 **教师 → 学生 → 量化 → 量化证书 → 对量化工件审查 → 部署**；先审 float 再量化属于**跨工件授权**，必须补充行为等价证书，否则证书无效。

**定义 613（红线邻域与行为等价证书 Red-Line Neighborhood & Behavioral Equivalence）**
以红线余量 `r_W(x,a)` 定义 ρ-邻域
```
N_ρ(F) = { (x,a) : |r_W(x,a)| ≤ ρ } .
```
行为等价证书要求：对一切 `(x,a)∈N_ρ(F)`，量化工件满足
```
r_{W_Q}(x,a) ≥ r_W(x,a) − U_q^F(x)  且  r_{W_Q}(x,a) ≥ ρ

r_{W_Q}(x,a) < ρ + U_q^F(x)          ⟹  触发 Q-escape（全精度复核或人工签核）.
```
`U_q^F` 是红线余量函数自身的量化间隙（逐群体校准）。该证书保证：只要自动放行，则真实（全精度）判决仍严格在红线外至少 ρ，量化不会把任何动作"推进"红线。

# IP-378 EthicsReviewCertificate：运行时伦理包络 + 账本 + 撤销
class EthicsReviewCertificate:
    def __init__(self, redlines_abs, redlines_rev, gray, ledger, review_budget):
        self.F_abs = redlines_abs      # 绝对红线谓词
        self.F_rev = redlines_rev      # 可审查红线谓词
        self.G = gray                  # 灰区谓词
        self.ledger = ledger           # 哈希链账本
        self.B_review = review_budget  # 注意力预算

    def envelope(self, x, a, tau):
        if self.F_abs(x, a):
            return "veto"                      # 零等待，不进队列
        if self.F_rev(x, a) and not self.ledger.auth_valid(tau, x, a):
            return "deny"                      # 默认禁止，除非带约束授权
        if self.G(x, a) and not self.ledger.sign_valid(tau, x, a):
            return "ask_eth"                   # 灰区：入队人工签核
        return "allow"

    def has_redline_risk(self, x, candidate_set):
        return any(self.F_abs(x, a) for a in candidate_set)

    def revoke(self, artifact_id, epoch):
        self.ledger.append(("revoke", artifact_id, epoch))   # 只增不改

    def certificate_valid(self, artifact_id, tau_now):
        return self.ledger.bound_and_unrevoked(artifact_id, tau_now)


# IP-379 QuantizationGapCertificate：逐输入量化间隙
class QuantizationGapCertificate:
    def __init__(self, margin_fn, eps_Q, ibp_bounds, group_calib):
        self.m = margin_fn             # 量化余量网络
        self.eps_Q = eps_Q             # 参数扰动上界
        self.ibp = ibp_bounds          # IBP/CROWN 逐输入界表
        self.group_calib = group_calib # 逐群体共形尾部分位

    def gap(self, x, group=None):
        u_w = self.ibp.weight_radius(x, self.eps_Q)      # 权重量化项
        u_act = self.ibp.activation_radius(x)            # 激活量化项
        u_round = self.ibp.rounding_bound(x)             # 舍入/溢出项
        u = u_w + u_act + u_round
        if group is not None:
            u += self.group_calib.tail_slack(group)      # 群体修正 Δ_g
        return u

    def threshold(self, theta_user, U_d, x, group=None):
        return theta_user + U_d + self.gap(x, group)     # 量化税：只抬不放

    def redline_gap(self, x, group=None):
        return self.gap(x, group)                        # r_W 的量化间隙


# IP-380 EthicsQuantizationCoupler：工件绑定 + 红线邻域 + Q-escape
class EthicsQuantizationCoupler:
    def __init__(self, erc, qgc, teacher_full, artifact_id, rho):
        self.erc, self.qgc, self.teacher = erc, qgc, teacher_full
        self.artifact_id = artifact_id
        self.rho = rho

    def gate(self, x, a, tau, student_Q, group=None):
        if not self.erc.certificate_valid(self.artifact_id, tau):
            return "stale"                       # 证书绑定失效：回退 + 重审
        verdict = self.erc.envelope(x, a, tau)
        if verdict in ("veto", "deny", "ask_eth"):
            return verdict
        r_q = student_Q.redline_margin(x, a)
        u_f = self.qgc.redline_gap(x, group)
        if r_q < self.rho + u_f:                 # 红线邻域内不再自动放行
            return "q_escape"                    # 全精度复核/人工签核
        if student_Q.margin(x, a) < self.qgc.threshold(
                self.theta_user, self.U_d, x, group):
            return "teacher_or_fallback"         # 量化学生未认证：回到教师
        return "allow"

    def q_escape(self, x, a, tau):
        if self.teacher.redline_margin(x, a) >= self.rho:
            return self.teacher.verify(x, a)     # 全精度教师复核
        return "fallback"                        # 复核也不足：认证回退

## 4. 推导

**引理 125（审查单调消除）** 对任意审查纪元 `τ`，`Exec_v15(x)=Exec_v14(x)∩E_τ(x)∩Acc_{S_Q}`，故 `Exec_v15⊆Exec_v14`。若新审查纪元 `τ'` 更严格（`E_{τ'}⊆E_τ`），则 `Exec_v15^{τ'}⊆Exec_v15^{τ}`。证明：交集对集合包含单调；`E_τ` 只由红线并集与授权/签核谓词定义，新增约束只能删去元素。∎ 推论：**伦理审查在代数上是一个纯删除算子**，它不可能与 v14 的加速算子"合谋"放大授权。

**引理 126（红线不可覆盖与组合交换性）** 设 `O∈{AIO,CPD,DDL,RTCR,HBR,UCCI,PAA}` 为 v14 中任一不新增授权的算子，则 `O(Exec_v14)∩E_τ = O(Exec_v14∩E_τ)`；因此任何调用顺序下，`F_abs` 都不可能被重建。证明：由 v14 引理 117 知 `O` 的输出仍是 `Exec_v14` 的子集，故两侧都等于 `O(Exec_v14)∩E_τ`；`E_τ` 的补集包含 `F_abs`，与 `O` 的输出取交后 `F_abs` 仍被删除。交换性来自交集的可交换性。∎ 推论：**"时间太紧所以走快档"不能成为越过红线的理由**，因为 RTCR 再快也只能落在 `E_τ` 内。

**引理 127（量化间隙的单侧包含）** 设 `m_{S_Q}` 为量化学生余量，`U_q(x)` 满足 `m_S(x,a) ≥ m_{S_Q}(x,a)−U_q(x)`（定义 610 的逐输入界）。若 `a∈Acc_{S_Q}`，即 `m_{S_Q}(x,a) ≥ θ_{S,user}+U_d+U_q(x)`，则 `m_S(x,a) ≥ θ_{S,user}+U_d`，故 `a∈Acc_S`；再由 v13 引理 114 得 `Acc_S⊆Acc_T`。因此 `Acc_{S_Q}⊆Acc_S⊆Acc_T`。证明：代入不等式链；`U_d` 吸收学生—教师间隙，`U_q` 吸收量化—全精度间隙，两者相加正是阈值税。∎ 推论：**量化只买速度，代价是阈值抬高、假拒绝增加**；平均精度下降不是判据，`U_q` 的逐输入上界才是判据。

**引理 128（联合间隙可加界）** 记 `Δ_tr=J_real(T)−J_sim(T)`、`Δ_dis=J_real(S)−J_real(T)`、`Δ_q=J_real(S_Q)−J_real(S)`。则
```
J_real(S_Q) − J_sim(T) = Δ_tr + Δ_dis + Δ_q ≤ U_gap + U_dis + U_q   （w.h.p.）
```
若再叠加伦理残差与交互项：
```
R_total ≤ U_gap + U_dis + U_q + U_eth + I_cross + δ_approx ,
P(违反) ≤ α_gap + α_dis + α_q + α_eth .
```
证明：代数展开三项；`Δ_tr`/`Δ_dis` 由 v13 引理 114/121，`Δ_q` 由定义 610 与引理 127；四项各自以 `1−α` 成立，用并集界合并。∎ 推论：**量化间隙不能拿迁移或蒸馏预算冲抵**，`B_total` 必须对建模误差与量化误差同时留量；新场景中三类间隙可能同向偏低。

**引理 129（审查对象同一性）** 存在教师 `W`、量化映射 `Q` 与输入 `x`，使 `C_eth(W)` 成立而 `C_eth(Q(W))` 不成立。构造：令 `x*` 位于某红线边界 `r_W(x*)=0` 的极小邻域内，量化把 `r_{Q(W)}(x*)` 推入负侧；则 float 教师不触发红线、量化部署触发红线。证明：量化误差在边界处不可约（定义 610 的 `U_q` 在该点达到下界），故 `r` 的符号可翻转；因此以 float 工件为对象的审查结论不能自动迁移。∎ 推论：**"先审 float 再量化上线"是跨工件授权**，必须有定义 613 的行为等价证书或重审，否则 v15 拒绝部署。

**引理 130（红线邻域行为等价的保守性）** 若 EQC 仅在 `r_{W_Q}(x,a) ≥ ρ+U_q^F(x)` 时自动放行，则任一自动放行的动作满足 `r_W(x,a) ≥ r_{W_Q}(x,a)−U_q^F(x) ≥ ρ > 0`，即真实（全精度）策略严格在红线外；若 `r_{W_Q}<ρ+U_q^F`，Q-escape 使用全精度教师复核或人工签核，其结果至少与直接回退一样保守。证明：第一个不等式由定义 610 的量化界给出；第二段由 Q-escape 路径只做更严格检查给出。∎ 推论：**Q-escape 不是性能损失，而是把"审查了错模型"的风险转成显式的升级率**；该升级率可预算、可观测、可调 ρ。

**引理 131（审查预算下的活性）** 设红线事件不进队列（零等待否决），灰区到达率 `λ_G`，服务率 `B_review`，时限 `h`。若 `λ_G<B_review`，则系统稳定；未在 `h` 内解决的灰区比例满足 `P(unresolved) ≤ (λ_G/B_review)·exp(−(B_review−λ_G)h)`（M/M/1 尾界）。任何未解决灰区只回退、不挂起执行。证明：标准排队尾界 + 定义 608 的"超时只回退"规则。∎ 推论：**伦理审查有吞吐上限**；`B_review` 不足时，系统会以更高假拒绝/回退换取合规，而不是偷偷用模型置信度替代人工签核。

**引理 132（撤销一致性）** 账本只增不改、纪元单调，`Revoke(τ')` 使一切 `τ≤τ'` 的旧证书失效。故撤销后 `E_τ` 单调收缩，`Exec_v15` 不增；陈旧证书只能触发 `S_0` 回退。证明：由定义 609 的有效性条件与纪元单调性直接得到。∎ 推论：**撤销是安全单向阀**；它可能降低活动性，但绝不可能恢复一个已被撤销的授权。

**引理 133（中立元退化等价 v14）** 注入定义 617 的中立元：`E_τ≡⊤`、`U_q≡0` 且强制全精度、EQC 为恒等。则 `Exec_v15=Exec_v14∩A∩(全精度学生集)=Exec_v14`；主闭环调用序列与 v14 逐位一致，再沿 v14 链退回 v13/v12/…/v6。证明：逐端口代入定义 617，并用 v14 引理 118 的边界条件核对；四端口互不相交且中立元不改变 v14 任何证书检查。∎

**引理 134（预算守恒与漂移下联合塌缩）** 新增在线成本上界：ERC 谓词查询与红线检查 ≤0.15ms；QGC 逐输入间隙查表 ≤0.1ms（IBP 界预计算）；EQC 工件哈希与邻域检查 ≤0.05ms；RBC 入队 ≤0.02ms；DGC 查表 ≤0.05ms。总决策 p99 仍 ≤22ms，50Hz 保持；离线量化校准、IBP 界表与伦理重审不在关键路径。漂移或工件变更触发时，强制反量化 + Q-escape + 重审，物理硬违规概率不高于 v14 对应回退；活动性损失满足
```
P(无可执行认证动作) ≤ P(drift) + P(artifact mismatch) + P(DGC/QGC 失效|drift) + P(a_ask^eth 预算耗尽) .
```
证明：逐项代入复杂度表并做静态 EDF 校验 `ΣŴ_m≤B_dec`；漂移时禁用一切量化高档与未绑定证书，只剩全精度 `S_0` 与人工回退，故安全性与 v14 回退同阶；活动性损失按四个互斥事件取并集界。∎ 推论：**漂移不是用更低精度去赌，而是用最保守的全精度回退去买重审时间**。

## 8. 已知风险与失效模式

1. **红线定义的道德风险**：红线圈本身可能编码有偏价值排序或遗漏新型伤害；系统会把"审查过的错误"稳定复现。缓解：多元审查委员会、红线可争辩与定期重审、外部红队、把"未覆盖伤害"设为独立失败类别而非平均指标。

2. **审查对象漂移**：部署后模型、校准集、代码或值模型变化，而证书未失效。缓解：工件哈希强绑定、TTL、运行时完整性校验、任何变更强制重审或塌缩。

3. **量化间隙被低估**：IBP/CROWN 界过松或激活量化尾部未覆盖，`U_q` 低估导致单侧包含失效。缓解：逐群体共形修正、EVT 尾部、对抗量化测试、保留额外 `B_quant` 余量、必要时降低精度激进度。

4. **群体性偏移被总量掩盖**：总体 `U_q` 合格但少数群体红线邻域偏移更大。缓解：逐群体 `U_q^{(g)}`、群体误判率差预注册、按最差群体部署。

5. **审查预算耗尽导致活性塌缩**：灰区过多或人工注意力不足时频繁回退。缓解：缩小灰区、把稳定灰区升级为红线/白区、增加 `B_review`、优化队列优先级、明确"回退是合规结果"。

6. **Q-escape 成为无限等待**：全精度复核或人工签核不可用，系统停在回退。缓解：Q-escape 设置硬时限、超时即回退、把升级率计入预算、保留零学习回退 `S_0`。

7. **量化学生与教师共享骨干的相关失效**：量化缺陷同时击穿所有档位。缓解：异构骨干、全精度影子抽查、关键路径保留非量化出口、故障注入。

8. **审查账本/撤销通道被攻击**：伪造授权、回滚纪元、删除撤销记录。缓解：哈希链/签名、只增审计日志、纪元单调、独立审计、离线根信任。

9. **伦理与安全的耦合误判**：把物理安全当伦理全部，忽略隐私、自主性、分配正义。缓解：分离伦理维度、程序保证优先、把不可量化的价值冲突交给人类签核而非模型打分。

10. **四类预算联合低估**：新场景同时触发迁移、蒸馏、量化与审查残差，四者同向偏低。缓解：定义 616 的联合下界、联合三角界、任一残差失效即最低档/`a_ask^eth`。

## 9. 本轮最大风险

**一句话**：v15 能证明"没有执行红线、量化没有新增授权、审查账本完整、工件哈希一致"，但它不能证明"红线圈是对的"——当红线圈本身有偏、而量化误差又集中在未覆盖的少数群体上时，系统会在全套可审计、可追溯、单侧包含的证书之下，稳定复现一个**程序完全合规却伦理上错误**的决定。
