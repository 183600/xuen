# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim++；灵感循环第 6 轮；本轮灵感：「专利布局」×「创新点挖掘」）

> 第 54 轮把系统推进到"动作-鲁棒性双证书"，并沉淀了 IP-001~IP-120 的技术特征清单。本轮不再增加执行层能力，而追问一个更上游的问题：**这些特征里哪些真正构成可专利的创新点？如何把它们组织成能覆盖设计空间、抗无效、可规避的专利组合？** 核心矛盾：H22：技术特征清单是"平铺累积"的，而专利布局要求"有偏序、有作用域、有冗余"的权利要求结构，二者之间缺少可计算映射；H23：人工罗列创新点只能发现"单点改进"，无法识别"组合才出现、拆开就消失"的协同型创新，也无法给出新颖性/创造性的判定边界，于是清单越堆越长、可专利性越稀薄。

## 0. 直觉与动机

**灵感 1（技术特征格 → 权利要求就是特征子集）**
直觉：把每个 IP 拆成原子技术特征 f（如"动作剖面 α_S"、"Lipschitz γ_ce"、"Explain 回传"）。一个权利要求不是一段文字，而是特征子集 F_c。实现 x 落入权利要求 c 的作用域，当且仅当 x 同时具备 F_c 中所有特征。于是"加特征 = 收窄范围"成为格上的单调运算：`F_c1 ⊆ F_c2 ⟺ scope(c2) ⊆ scope(c1)`。这把"独立权利要求/从属权利要求"变成可判定的格结构，也让"写宽了被驳回、写窄了被规避"成为可优化问题，而不是纯经验手艺。

**灵感 2（创新点 = 不可预期的组合效应，而非特征本身）**
直觉：单个特征多半已有先例；真正的创新点常常是"两个特征耦合后出现、单独使用时却不出现"的效应。例如"动作占用剖面"本身是描述，"Lipschitz 云边映射"本身是约束，但二者与"δ_a 预算否决"耦合后，才产生"云端承诺可被边端物理带宽否决"的新技术效果。用分区对照实验估计协同增益 `syn(c) = e(c) - max_partition Σ e(part)`，并且只接受置信下界超过阈值的组合，避免把噪声、过拟合或评测偏差包装成创造性。

**灵感 3（鲁棒专利布局 → 权利要求是设计空间上的纠错码）**
直觉：前 54 轮一直在做"系统鲁棒性"，本轮把鲁棒性迁移到**专利组合本身**。独立权利要求是码字，从属权利要求是冗余校验位；专利无效 = 擦除，竞争对手规避 = 对抗噪声。组合强度不看"有多少件专利"，而看**最小覆盖深度 d**：对威胁设计空间中的每个实现 t，至少有多少条彼此独立的权利要求覆盖它。无效掉 d-1 条，t 仍被覆盖。布局优化 = 在预算与有效性约束下同时最大化 d 与威胁覆盖。

**灵感 4（证据图谱 → 研究证据即专利支持）**
直觉：专利审查需要 enablement / support / 创造性证据；而前 54 轮恰好沉淀了"定义—算法—定理—实验—风险"五类证据。把每个特征绑定到证据节点，形成证据图谱；一个创新点只有证据完备度达标才"可申请"。这把"创新点挖掘"从灵感活动变成**可审计的证据挖掘**，也让实验结果直接变成申请文件的支持材料。

**灵感 5（FTO 规避闭环 → 规避设计反过来成为新创新点）**
直觉：对每件竞争专利 p 判定我方候选 c 是否落入 `scope(p)`；若落入，搜索最小新增特征 Δ，使 `scope(c∪Δ) ∩ scope(p)=∅` 且技术效果保留。规避解本身往往就是新的创新点，回流到特征格与组合中。对"我方不打算实施、但不想让对手占住"的特征组合，则做防御性公开，制造 prior art。布局因此是"申请—规避—公开"的三动作闭环。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（技术特征与特征格）**
原子特征集 `F = {f_1,...,f_n}`，每个特征 `f` 有实现域 `E(f) ⊆ U`（U 为设计空间）。特征表达式取合取范式；集合包含偏序 `⊆` 构成格 `𝔽 = (2^F, ⊆, ∪, ∩)`。若 `f' ⪯ f` 表示 `E(f') ⊆ E(f)`，则称 `f'` 是 `f` 的细化。

**定义 122（权利要求作用域与包容）**
权利要求 `c = (F_c, alt_c)`，`alt_c` 为可选替代组（OR）。作用域
```
scope(c) = ∩_{f∈F_c} E(f)                    （无替代）
scope(c) = ∪_{a∈alt_c} ∩_{f∈a} E(f)          （有替代）
```
包容关系 `c1 ⊑ c2 ⟺ scope(c1) ⊆ scope(c2)`。若 `F_c1 ⊆ F_c2` 且无替代，则 `c2 ⊑ c1`：特征越多，范围越窄。

**定义 123（新颖性边距）**
先验技术集合 `𝒫`，每件先验 p 亦表示为特征集 `F_p`。新颖性边距
```
δ_nov(c) = min_{p∈𝒫} d_J(F_c, F_p),   d_J(A,B) = 1 - |A∩B| / |A∪B|
```
`c` 相对 `𝒫` 新颖当且仅当 `δ_nov(c) ≥ θ_nov`。若 `𝒫` 只是真实先验的 `ε`-完备子集，则结论带 `ε` 风险（定理 T5）。

**定义 124（协同增益 / 非显而易见性）**
技术效果 `effect(·)` 为基准协议下的向量（成功率、鲁棒性、时延），标量化记为 `e(·)`。对特征集 c 的所有真划分 `Π(c)`：
```
syn(c) = e(c) - max_{π∈Π(c)} Σ_{b∈π} e(b)
```
只接受**置信下界** `LCB_α(syn(c)) ≥ θ_syn` 的组合作为创造性候选；不可构造的子集用带不确定度的代理模型估计，不满足 LCB 则不主张。

**定义 125（创新点与有效性证书）**
创新点 `ι = (c, δ_nov, syn_LCB, V_cert)`，其中 `V_cert = (E_def, E_alg, E_thm, E_exp, E_risk)` 为五类证据的完备度向量。`ι` 可申请当且仅当
```
δ_nov ≥ θ_nov  ∧  LCB_α(syn) ≥ θ_syn  ∧  min(V_cert) ≥ θ_e
```

**定义 126（组合覆盖深度 / 抗无效性）**
威胁设计空间 `T ⊆ U`。组合 `S = {c_1,...,c_k}`，对 `t∈T` 记 `cov_S(t) = {c∈S | t∈scope(c)}`。最小覆盖深度
```
d(S) = min_{t∈T} |cov_S(t)|
```
`S` 为 d-抗无效，当且仅当任意少于 d 条权利要求被无效，都不能使任一 `t∈T` 失去覆盖。

**定义 127（鲁棒专利布局问题）**
给定候选创新点池 `C`、预算 B、有效性阈值：
```
max_{S⊆C}  V(S) = λ1·cover(S,T) + λ2·d(S) + λ3·white(S) - λ4·red(S)
s.t.  |S| ≤ B,  ∀c∈S: ι_c 有效,  ∀c,c'∈S: ¬(c ⊑ c' ∧ 冗余)
```
其中 `cover(S,T)=|(∪_{c∈S} scope(c)) ∩ T|`，`white(S)` 为白空间覆盖，`red(S)` 为作用域冗余。

**定义 128（规避算子与防御性公开）**
对竞争专利 p 与我方候选 c，若 `scope(c) ∩ scope(p) ≠ ∅`，规避算子
```
Δ* = argmin_{Δ⊆F, Δ∩F_c=∅} cost(Δ)
s.t.  scope(c∪Δ) ∩ scope(p) = ∅  ∧  e(c∪Δ) ≥ (1-ε)·e(c)
```
防御性公开集合 `D` 的目标是最大化 `prior(D)`，即用公开内容压缩对手可主张的新颖空间。

## 2. 关键算法 伪代码

### IP-121 FLA（Feature Lattice Abstraction）

```python
def build_feature_lattice(ips, evidence_graph):
    F, E = {}, {}
    for ip in ips:
        for f in decompose(ip):            # 定义/算法/定理/实验 -> 原子特征
            F[f.id] = f
            E[f.id] = feature_extension(f, evidence_graph)   # E(f) ⊆ U
    lattice = Lattice(F, order=lambda a,b: E[a] <= E[b])
    return lattice, E

def claim_scope(F_c, E, alt=None):
    if alt is None:
        return reduce(intersection, (E[f] for f in F_c), U)
    return union(*(reduce(intersection, (E[f] for f in a), U) for a in alt))
```

### IP-122 INM（Innovation Mining）

```python
def mine_innovations(lattice, prior, benchmark, alpha=0.05, k=50):
    candidates = []
    for c in beam_search(lattice, order='by_support', beam=256):
        if not realizable(c):                       # 未实现组合用代理模型
            if optimistic_novelty(c, prior) < theta_nov:
                continue                            # 安全剪枝
            e_c, lcb_syn = surrogate_effect(c, benchmark, alpha)
        else:
            dnov = novelty_margin(c, prior)
            e_c, lcb_syn = partition_contrast(c, benchmark, alpha)
            if dnov < theta_nov:
                continue
        if lcb_syn >= theta_syn:
            candidates.append(Innovation(c, dnov, lcb_syn, evidence(c)))
    return top_k(candidates, score=lambda i: i.dnov * i.lcb_syn, k=k)
```
`optimistic_novelty` 利用 Jaccard 距离是度量这一事实给出上界：`δ_nov(c') ≤ δ_nov(c) + d_J(F_c, F_c')`，用于格搜索剪枝。

### IP-123 RPL（Robust Patent Layout）

```python
def robust_layout(candidates, threat_space, budget, lambdas):
    S = greedy(lambda c: marginal_V(c, S, threat_space, lambdas),
               candidates, budget)                 # 覆盖子模，贪心可行解
    model = MILP()                                 # 小规模精确补正
    x = model.binary_var_dict(candidates, name='x')
    z = model.integer_var(lb=0, name='d')          # 最小覆盖深度
    for t in threat_space:
        model.add_constraint(z <= sum(x[c] for c in candidates if t in scope(c)))
    model.maximize(sum(cover_term(c)*x[c] for c in candidates) + lambdas[1]*z
                   - redundancy_term(x))
    model.add_constraint(sum(x[c] for c in candidates) <= budget)
    return solve_with_validity_pruning(model, candidates)
```

### IP-124 CVC（Claim Validity Certificate）

```python
def validity_certificate(claim, evidence_graph, prior):
    ev = {k: evidence_graph.completeness(claim, k)
          for k in ('def','alg','thm','exp','risk')}
    dnov = novelty_margin(claim, prior)
    syn = partition_contrast_lcb(claim, evidence_graph.benchmark)
    ok = dnov >= theta_nov and syn >= theta_syn and min(ev.values()) >= theta_e
    return ValidityCert(ok, dnov, syn, ev,
                        counterexamples=evidence_graph.counterexamples(claim))
```

### IP-125 FDA（FTO Design-Around）

```python
def design_around(c, competitor_claim, effect_fn, eps):
    if not (scope(c) & scope(competitor_claim)):
        return ('clear', c)
    for delta in ascending_by_cost(powerset(feature_universe - F_c)):
        c2 = c | delta
        if not (scope(c2) & scope(competitor_claim)) \
           and effect_fn(c2) >= (1-eps)*effect_fn(c) \
           and novelty_margin(c2, prior) >= theta_nov:
            return ('design_around', c2, delta)
    return ('blocked', c)
```

### IP-126 PPM（Patent Portfolio Map / Claim Ladder）

```python
def claim_ladder(family, prior, theta_nov):
    c0 = broadest_claim(family, prior, theta_nov)   # 满足新颖性的最宽特征集
    ladder = [c0]
    for f in ordered_refinements(family):
        c = ladder[-1] | {f}
        if validity_certificate(c, evidence, prior).ok:
            ladder.append(c)                        # 无效时的回落层
    return ladder      # scope(c0) ⊇ scope(c1) ⊇ ... ⊇ scope(ck)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| FLA | O(|IP|·|F|·|U|) | 剪枝后 O(|F|²) | 特征分解完备、E(f) 可判定 |
| INM | O(beam·|F|·|Π|·T_bench) | O(beam·|F|) | LCB 控制 FDR、剪枝上界 sound |
| RPL | 贪心 O(|C|·B·|T|)；MILP 指数（小规模） | O(|C|·|T|) | 覆盖子模、深度约束可线性化 |
| CVC | O(|C|·|F|·|𝒫|) | O(|F|) | 证据五元组完备、反例可追溯 |
| FDA | O(2^{|F\F_c|})，剪枝后 O(|C|·|F|) | O(|C|) | 规避后效果保留与新颖性双约束 |
| PPM | O(|family|·|F|·|𝒫|) | O(|F|) | 阶梯单调收窄、每层可独立成立 |

**定理 T5（新颖性完备性风险界）**
若真实先验集合 `𝒫*` 被注册表 `𝒫` 以 Hausdorff 距离 `ε` 覆盖（`∀p*∈𝒫*, ∃p∈𝒫: d_J(F_{p*},F_p) ≤ ε`），则 `δ_nov^{𝒫*}(c) ≥ δ_nov^{𝒫}(c) - ε`。因此以 `θ_nov` 判定时，最坏漏检风险不超过 `ε`；**先验注册表不完备是新颖性误判的第一来源**。

**定理 T6（协同发现的错误发现率控制）**
在 (A29) 效果估计无偏、噪声次高斯、各划分检验经 Bonferroni 校正的假设下，`LCB_α(syn) ≥ θ_syn` 的判定把族错误率控制在 `α`。即：不能保证"所有真创新点都被发现"，但能保证"宣称的协同创新点很少是噪声"。

**定理 T7（覆盖子模性与布局近似）**
`cover(S,T)` 关于 S 单调子模；当把深度下界 `d(S) ≥ d0` 作为可行性约束时，带基数预算的布局可用贪心获得 `(1-1/e)` 的覆盖近似（深度约束通过分层展开 `Σ_k 1[∀t: cov(t)≥k]` 转化为若干覆盖层）。但 `d(S)` 本身是模块函数的最小值、并非子模，故**联合目标不保证贪心最优**，需 MILP 或局部搜索补正。

| 风险 | 等级 | 缓解 |

## 6. 本轮最大风险

**一句话**：本轮把"专利布局"形式化为特征格上的覆盖-抗无效优化，逻辑上自洽，但整套结论的地基是**特征分解与先验注册表**这两个人为产物；一旦特征粒度切错或先验检索漏检，优化器只会把"虚假新颖性"包装成高覆盖、高深度的漂亮组合，故必须以 **双标注特征词典 + ε-完备先验审计 + 独立复现的协同实验** 作为不可省略的前置门禁，宁可少报创新点，也不把检索盲区当成专利空白。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim+++×（FLA×INM×RPL×CVC×FDA×PPM）——从技术清单到鲁棒专利布局

| `𝔽 = (2^F, ⊆, ∪, ∩)` | 技术特征格 |
| `c = (F_c, alt_c)` | 权利要求：特征合取 + 可选替代组 |
| `scope(c)` | 权利要求覆盖的实现集合 |
| `c1 ⊑ c2` | 包容关系：`scope(c1) ⊆ scope(c2)` |
| `δ_nov(c)` | 对先验集合 `𝒫` 的新颖性边距 |
| `syn(c)` | 协同增益（非显而易见性代理量） |
| `V_cert` | 五元证据完备度向量 |
| `ι = (c,δ_nov,syn_LCB,V_cert)` | 创新点 |
| `d(S)` | 组合最小覆盖深度（抗无效性） |
| `Δ*` | 最小规避特征集 |
| `L` | 权利要求阶梯 `(c0,...,ck)` |

## 2. 关键算法 伪代码

### IP-121 FLA

```python
def build_feature_lattice(ips, evidence_graph):
    F, E = {}, {}
    for ip in ips:
        for f in decompose(ip):
            F[f.id] = f
            E[f.id] = feature_extension(f, evidence_graph)   # E(f) ⊆ U
    return Lattice(F, order=lambda a,b: E[a] <= E[b]), E

def subsumes(c1, c2, E):
    return claim_scope(c1.F, E) <= claim_scope(c2.F, E)      # c1 ⊑ c2
```

### IP-122 INM

```python
def mine_innovations(lattice, prior, benchmark, alpha=0.05, k=50):
    out = []
    for c in beam_search(lattice, order='by_support', beam=256):
        if realizable(c):
            dnov = novelty_margin(c, prior)
            lcb = partition_contrast_lcb(c, benchmark, alpha)
        else:
            if optimistic_novelty(c, prior) < theta_nov:     # Jaccard 度量上界
                continue
            dnov = optimistic_novelty(c, prior)
            lcb = surrogate_effect_lcb(c, benchmark, alpha)
        if dnov >= theta_nov and lcb >= theta_syn:
            out.append(Innovation(c, dnov, lcb, evidence(c)))
    return top_k(out, score=lambda i: i.dnov * i.syn_lcb, k=k)
```

### IP-123 RPL

```python
def robust_layout(candidates, threat_space, budget, lam):
    S = greedy(lambda c: marginal_V(c, S, threat_space, lam), candidates, budget)
    m = MILP()
    x = m.binary_var_dict(candidates, name='x')
    z = m.integer_var(lb=0, name='d')
    for t in threat_space:
        m.add_constraint(z <= sum(x[c] for c in candidates if t in scope(c)))
    m.maximize(sum(cover_gain(c)*x[c] for c in candidates) + lam[1]*z
               - redundant_cost(x))
    m.add_constraint(sum(x[c] for c in candidates) <= budget)
    return solve_with_validity_pruning(m, candidates)
```

### IP-124 CVC

```python
def validity_certificate(claim, evidence_graph, prior):
    ev = {k: evidence_graph.completeness(claim, k)
          for k in ('def','alg','thm','exp','risk')}
    dnov = novelty_margin(claim, prior)
    syn = partition_contrast_lcb(claim, evidence_graph.benchmark)
    ok = dnov >= theta_nov and syn >= theta_syn and min(ev.values()) >= theta_e
    return ValidityCert(ok, dnov, syn, ev,
                        counterexamples=evidence_graph.counterexamples(claim))
```

### IP-125 FDA

```python
def design_around(c, competitor, effect_fn, eps):
    if not (scope(c) & scope(competitor)):
        return ('clear', c)
    for delta in ascending_by_cost(powerset(feature_universe - c.F)):
        c2 = c | delta
        if not (scope(c2) & scope(competitor)) \
           and effect_fn(c2) >= (1-eps)*effect_fn(c) \
           and novelty_margin(c2, prior) >= theta_nov:
            return ('design_around', c2, delta)
    return ('blocked', c)
```

### IP-126 PPM

```python
def claim_ladder(family, prior, evidence):
    c0 = broadest_claim(family, prior, theta_nov)
    ladder = [c0]
    for f in ordered_refinements(family):
        c = ladder[-1] | {f}
        if validity_certificate(c, evidence, prior).ok:
            ladder.append(c)
    return ladder          # scope(c0) ⊇ scope(c1) ⊇ ... ⊇ scope(ck)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| FLA | O(|IP|·|F|·|U|) | O(|F|²)（剪枝后） | 特征分解完备、E(f) 可判定 |
| INM | O(beam·|F|·|Π|·T_bench) | O(beam·|F|) | LCB 控制族错误率、上界剪枝 sound |
| RPL | 贪心 O(|C|·B·|T|)；MILP 指数 | O(|C|·|T|) | 覆盖子模；深度线性化精确 |
| CVC | O(|C|·|F|·|𝒫|) | O(|F|) | 五元证据完备、反例可追溯 |
| FDA | 最坏 O(2^{|F\F_c|})，剪枝后 O(|C|·|F|) | O(|C|) | 规避与效果保留双约束 |
| PPM | O(|family|·|F|·|𝒫|) | O(|F|) | 阶梯单调收窄、每层独立成立 |

**定理 T5（新颖性完备性风险界）**
`𝒫*` 被注册表 `𝒫` 以 Hausdorff 距离 `ε` 覆盖时，`δ_nov^{𝒫*}(c) ≥ δ_nov^{𝒫}(c) - ε`。故以 `θ_nov` 判定时，最坏漏检风险 ≤ `ε`。工程含义：**专利检索的 ε 必须显式记录在 CVC 中，不能只报一个 δ_nov 数值**。

**定理 T6（协同发现 FDR 控制）**
在 (A29) 无偏估计、次高斯噪声、Bonferroni 校正下，`LCB_α(syn) ≥ θ_syn` 的宣称把族错误率控制在 `α`：不保证召回所有真创新点，但保证宣称的协同创新点很少是噪声。

**定理 T7（覆盖子模性与布局近似）**
`cover(S,T)` 单调子模；固定深度下界时，基数预算布局的覆盖项可获 `(1-1/e)` 贪心近似。但 `d(S)` 是模块函数的最小值、非子模，联合目标需 MILP 或局部搜索补正。**不可把 `(1-1/e)` 的结论错误扩展到深度项**。

**P1 权利要求阶梯（抗无效回落示例）**

```
c0 = {α_S 动作剖面, ρ 鲁棒性谱, 联合部署判定}        最宽，覆盖 T 最大，d 贡献大
c1 = c0 ∪ {γ_ce 云边映射}                           回落 1
c2 = c1 ∪ {Lipschitz L<1 约束}                      回落 2
c3 = c2 ∪ {Explain 反向解释回传与重剖分}             回落 3
c4 = c3 ∪ {δ_a 动作对齐预算否决}                     最稳但最窄
```

覆盖深度是**威胁相关**的：落入 `c4` 的威胁实现有 `d=5`；只落入 `c0\c1` 的实现只有 `d=1`。因此布局报告必须给出 `d(t)` 分布，而非单一 `d` 值。P5 的方法层因涉及抽象规则与智力活动，在 CN/US 均存在客体风险，故转为防御性公开，用 `prior(D)` 阻断对手对"协同挖掘/鲁棒布局"方法论的主张，同时保留实现细节作为商业秘密。

其中新增：
- `claim_id` 该能力所归属的权利要求族与层级；

- `d` 该实现对应的覆盖深度；
- `V_cert` 证据完备度向量。

## 6. 本轮最大风险

**一句话**：本轮把"专利布局"形式化为特征格上的覆盖-抗无效优化，逻辑上自洽，但整套结论的地基是**特征分解与先验注册表**这两个人为产物；一旦特征粒度切错或先验检索漏检，优化器只会把"虚假新颖性"包装成高覆盖、高深度的漂亮组合，故必须以 **双标注特征词典 + ε-完备先验审计 + 独立复现的协同实验** 作为不可省略的前置门禁，宁可少报创新点，也不把检索盲区当成专利空白。
