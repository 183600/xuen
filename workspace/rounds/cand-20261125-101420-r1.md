> **基线**：MetricVoiceGauge-NCD-HUTDH-v23+IP-436–439（云边证书链 CESC / 少样本证书 FSVC / 知识产权认证 IPAM 与 HPC-E+ 四证门；其上承 v22 的分层 PGEV / ACSC / DCSC、v21 的 SDC / CAC / DCL / GIC、v20 的 PCA / CTS / CFC / HPC 与 v19 / v18 / v17 全线）。
> 本轮纪律：**不推倒 v23**。CESC / FSVC / IPAM / HPC-E+ 全部保留，v20–v22 全部保留。本轮只做一件事：把整套"证书体系"从**未经检验的安全断言**升级为**可证伪、可跨站复核的科学假说体系**——用云边异构性作为证伪的实验仪器，把"研究空白"从一句口头自省变成一个可记账、可定价、可调度的对象。安全链只收紧不放松：`Exec_v24 = Exec_v23 ∩ Fil_fals_hard ⊆ Exec_v23`。

## 0. 直觉与动机

**灵感 1（研究空白 → 证书不是证明，而是待检验的假说）**
直觉：v18→v23 一路加证书、加谓词、加门，却从未被真正追问：这些证书赖以成立的每一个**经验谓词**——召回下界 κ_c、定位误差界 ε_loc、conformal 1−α 覆盖、原型漂移 Δ_proto、专利覆盖 100%、臂配空间能耗上界——究竟有哪几个被真实部署数据检验过？我们造了一座"验证"的巴别塔，却没有一层是"可证伪"的。研究空白不是"缺一个模块"，而是**声称的保证与已检验的保证之间的缺口**。本轮第一个反直觉点：**不是所有空白都值得填——空白的价值取决于它是否会翻转一个执行决策**。因此研究空白应当被"记账、定价、调度"，而不是被无差别地"消除"；把有限实验预算花在"即使不确定性消除、行为也不变"的空白上，是最昂贵的浪费。

**灵感 2（云端协同 → 异构站点是天然的对照实验，也是证伪的仪器）**
直觉：v23 的 CESC 把云边协同当成**版本同步管道**（云端下发 → 双轨并行 → 原子切换 → 回滚）。但云边协同更珍贵的性质是**分布异构**：不同站点、不同人群、不同光照、不同硬件，本身就是一组天然的非 i.i.d. 对照实验。若某个假设只在总部机房成立、到了边缘现场就失效，那正是"研究空白"的活体标本。本轮第二个反直觉点：**云边不该只"同步"，更该"互相证伪"**——云用自身先验去证伪边端的过拟合，边端用当下真实去证伪云的陈旧先验；而两者证据的代价**不对称**（云的反例便宜但滞后，边的安全事件昂贵但即时）。因此不能简单投票取多数，必须用一种**可组合、且不依赖独立同分布假设**的证据度量。恰好，e 值（e-value）满足我们全部要求：单个站点给出合法的 e 值，跨站用**算术平均**聚合仍合法（Markov 不等式只用到期望线性），且天然支持任意停时（Ville 不等式）。这把"众口铄金"式的共识从"计数多数"升级为"统计证据"。

**统一：给每张证书配一张"影子证书"**
把 v23 的每张证书 c 配一张**证伪证书 FCert(c)**：记录它的经验谓词、声称等级、证据日志与**明确的证伪条件**；用**联邦 e 值协议 FEFP**把各站点证据在云端无独立性假设地聚合；用**研究空白账本 RGL**统一记账 `G(c) = 声称 − 已验证`；用**价值信息调度 AGES**决定下一次实验花在哪。安全语义保持不变：硬谓词（κ_c、ε_loc 等安全攸关者）被证伪时**撤销**其依赖证书并退到 v23 的保守模式；软谓词（专利覆盖、原型漂移等审计项）被证伪时只降级为 *provisional* 并留证，**绝不触发 SafeStop、也绝不被伪装成已验证**。新准入门 **HPC-F** 只是 HPC-E+ 之上的一个额外合取项，故安全继承方向不变。

## 1. 研究问题（轮次升级版）

- **Q12（研究空白的可比度量）**：如何定义一个跨异质谓词类型（召回率、conformal 覆盖率、专利覆盖率、原型漂移、能量界）都可比的空白量 `G(c) ∈ [0,1]`，使其具备"声称 − 已验证"的语义、且能被 anytime-valid 置信序列无偏记账？不同量纲的谓词能否统一折算为"**决策翻转概率**"这一公共货币？

- **Q13（联邦证据的可组合性）**：在站点间存在任意（含对抗性）相关、样本量不等、且允许自适应停采样的条件下，如何聚合逐站 e 值使"全站点满足假设"这一交集的零假设仍被严格控制？平均 e 值、e-BH 多重检验与"单点针尖"定位之间如何权衡检测功效与定位精度？协议版本不一致（度量定义/采样框/α 不同）导致的"**不可比证据**"如何被识别而非被静默平均？

- **Q14（主动证伪与古德哈特防线）**：如何调度下一批实验（站点 × 切片 × K-shot × 协议）以最大化"单位成本价值信息" `VoI/cost`？在自适应选样下，e 值/置信序列的合法性如何保持（预注册承诺、可选停时下的 e-process、留出集稀释）？如何避免"**挑软柿子证伪**"——只在容易的问题上刷"存活"，而人形盲区永远不被采样？

- **Q15（负结果的审计与激励）**：如何让"负结果/被证伪"成为一等公民（不可篡改、跨机构可比、可被第三方复核）？在 CESC 的版本五元组上如何扩展出证据版本与协议版本，使不同批次的证伪判定在同一条 Merkle 审计链上可追溯、可复现、不可事后挑选？

## 2. 设计原则（在 P34–P42 基础上新增 P43–P46）

**P43 证伪优先于验证律（Falsification-before-Verification）**
凡证书 c 依赖的经验谓词 p，必须登记：声称等级 `1−α_c`、证据日志 `E_p`、**显式证伪条件** `φ_p`（何种观测将推翻它）、以及依赖图 `deps(c) ⊆ P`。证书只能主张**已挣得**的等级：`ClaimedLevel(c) ≤ LCB_{1−β}(metric_c | E_c)`；未挣得的部分计入研究空白 `G(c)` 并标记 provisional。**没有证据不等于没有风险，也不等于有风险**：未检验谓词默认沿用 v23 行为（不阻塞活性），只有**被证伪**才撤销。

**P44 联邦证据可组合律（Federated Evidence Composability）**
跨站聚合必须在不假设 i.i.d. 的前提下保持统计合法性，故采用 e 值**算术平均**（而非 pooled 频率或多数票）：`e_agg = (1/S) Σ_s e_s`。它对"所有站点均满足"的交集零假设有效，无论站点间如何相关。逐站 e 值另经 **e-BH** 做 FDR 控制以定位违规站点。**协议不可比**（`v_test` 不同）时禁止跨站平均，降级为逐站判定并记 `unresolved`，绝不静默混合。

**P45 认知失效与安全失效分离律（Epistemic–Safety Failure Separation）**
被证伪的**硬谓词**（κ_c、ε_loc、臂能量界）→ 撤销依赖证书 → 退回 v23 保守模式（`⊆` 保持）；被证伪的**软谓词**（专利覆盖、原型漂移）→ 仅降级 provisional + 留证 + 上报，不改变执行域。**认知失败绝不触发 SafeStop（避免"狼来了"式过度保守与活性坍缩）；安全失败绝不被标成 provisional 而掩盖（避免"静默降级"）。** 两类失败在账本上使用不同颜色、不同升级路径、不同审计人。

**P46 空白预算的价值优先律（Gap-Budget Value Priority）**
实验预算按 `VoI/cost` 贪心分配，其中 `VoI(g)` 是"解决空白 g 后执行决策的期望改变量（含安全与活性）"。**优先填会翻转决策的空白，而非不确定性最大的空白**；对已通过 K 次独立验证的谓词上调信任，对从未检验的谓词永不标"已验证"。负结果与正结果同等入账、同等保留。

## 3. 与基线的接口（如何退化）

- **FEFP 失效**（e 值引擎崩溃 / 协议不可比）⇒ 不做任何跨站断言，逐站保留 v23 行为并标 provisional ⇒ **等价 v23**（不会更不安全）；
- **硬谓词被证伪** ⇒ 撤销 SDC/CAC/ACSC/DCSC 中依赖该谓词的证书 ⇒ 退回 v23 的保守收缩 ⇒ `Exec_v24 ⊆ Exec_v23`；
- **软谓词被证伪** ⇒ 只标 provisional + 审计上报，执行域不变 ⇒ 仍是 v23 的子集（相等）；
- **云断联** ⇒ 复用 CESC `OfflineMode`：冻结 e 值聚合与协议版本，逐站本地证书继续签发，证据入本地账本待重连补交 ⇒ 子集；
- **AGES 无预算/无站点可采** ⇒ 冻结当前账本，`G` 只增不减（不确定性只会累积），所有未验证主张保持 provisional ⇒ 子集；
- **全线失效** ⇒ 完全回退 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ … ⊆ Exec_v18`。
- **关键点**：FCert 不增加任何自由空间，只可能**撤销**证书或**降低**主张等级；初装时"未检验"不阻塞活性，因此不会出现"没证据就停机"的活性归零；随着证据累积，`G` 单调收窄——**这是一个随时间变好的证书体系，而不是一个一次性通过的证书体系**。

## 4. 预期贡献

1. **研究空白的可计算化**：首次把"研究空白"定义为证书上的"声称 − 已验证"差量 `G(c)`，给出 anytime-valid 的记账与跨异质谓词的"决策翻转概率"公共货币；
2. **联邦 e 值证伪协议**：给出不依赖 i.i.d. 的跨站证据聚合（平均 e 值 + e-BH 定位 + 协议不可比检测），证明在站点强相关下仍严格控制"全站点满足"的交集零假设——恰好补上 v23 的 FSVC 用 Hoeffding 池化**默认独立性**这一隐藏裂缝；
3. **证伪证书与语义-规范-能量证书的对偶**：每张安全/合规/能量证书都获得一张可审计的证伪影子证书，构造成"安全子集不变 + 认知空白单调收窄"的双链结构；
4. **认知失效与安全失效的分离语义**：给出"撤销 / 降级 / 不阻塞"三档的严格退化规则，既防"狼来了"式活性坍缩，也防"静默降级"式掩盖；
5. **主动证伪调度**：以 `VoI/cost` 取代"最大不确定性"，把实验预算配置到会翻转决策的空白上，并给出古德哈特防线（预注册 + 可选停时下合法的 e-process + 留出集）；
6. **实验证据**：用跨站相关模拟证明朴素池化在站点相关时第一类错误从 0.05 膨胀到 0.197，而联邦 e 值平均稳定在 ≤0.05 且对 1/8 站点违规保持满功效。

## 5. 本轮最大风险

**一句话**：证伪层层层自指——若"检验哪些谓词、取什么 α、切哪些数据"都由被审计方自己决定，则联邦 e 值只会为"被问到的问题"负责，系统可以在一连串容易的问题上稳稳"存活"，而真正的研究空白（人形盲区）从未被采样；我们得到的不是安全，而是一张**合规的统计不在场证明**。

## 1. 关键算法骨架

```python
# ============================================================
# IP-440 Research-Gap Ledger (RGL) — 研究空白账本
# ============================================================
@dataclass
class EmpiricalPredicate:
    pid: str
    metric: str                 # 'recall_lb' | 'conformal_cov' | 'ip_cover' | 'proto_drift' | 'arm_energy'
    claimed: float              # 1 - alpha_c
    falsify_cond: str           # phi_p：何种观测推翻它
    deps: set[str]              # 依赖此谓词的证书 id
    is_hard: bool               # 硬谓词 -> 证伪即撤销；软谓词 -> 仅 provisional
    evidence: list = field(default_factory=list)   # [(t, value, site, witness?)]
    protocol_hash: str = ""

class ResearchGapLedger:
    def __init__(self, beta: float = 0.05):
        self.preds: dict[str, EmpiricalPredicate] = {}
        self.beta = beta
        self.merkle = MerkleLog()          # 追加式、可签名、不可篡改

    def register(self, p: EmpiricalPredicate):
        assert p.protocol_hash, "谓词必须携带协议指纹，否则证据不可比"
        self.preds[p.pid] = p
        self.merkle.append({"op": "register", "pid": p.pid, "proto": p.protocol_hash})

    def validated_level(self, pid: str) -> float:
        """LCB_{1-beta}(metric | evidence)：由同一 e-process 反演。"""
        p = self.preds[pid]
        if not p.evidence:
            return 0.0                      # 无证据 => 已验证等级为 0（空白=全额声称）
        cs = e_process_confidence_sequence(p.evidence, p.metric, beta=self.beta)
        return cs.lower

    def gap(self, cert_id: str) -> float:
        """证书的研究空白 G(c) = max(0, 声称 - 已验证)。"""
        dep = [p for p in self.preds.values() if cert_id in p.deps]
        if not dep:
            return 0.0
        # 证书整体等级取依赖谓词中最弱环（交）
        return max(max(0.0, p.claimed - self.validated_level(p.pid)) for p in dep)

    def record_witness(self, w: "Witness"):
        self.merkle.append({"op": "witness", "w": w.payload_hash, "site": w.site,
                            "t": w.t})
        self.preds[w.pred_id].evidence.append((w.t, 0.0, w.site, w))

    def downgrade(self, cert_id: str, to: str):
        """硬失败 -> revoke；软失败 -> provisional。二者颜色/升级路径不同。"""
        self.merkle.append({"op": "verdict", "cert": cert_id, "to": to})


# ============================================================
# IP-441 Federated E-Value Falsification Protocol (FEFP)
# ============================================================
class FederatedEValue:
    """
    逐站 e 值：测试 H0: metric >= 1-alpha_c （即"假设满足"），
    用 p1 (> p0) 的似然比构造。对复合零假设 p <= p0 亦合法（引理 2）。
    """
    def __init__(self, alpha: float = 0.05):
        self.alpha = alpha

    def site_evalue_recall(self, misses: int, n: int,
                           p0: float, p1: float) -> float:
        # p0 = 1 - kappa_c（声称的漏检率上界），p1 > p0（备择漏检率）
        assert 0 < p0 < p1 < 1
        log_e = (misses * math.log(p1 / p0)
                 + (n - misses) * math.log((1 - p1) / (1 - p0)))
        return math.exp(min(log_e, 700.0))

    def aggregate(self, site_evals: dict[str, float],
                  site_proto: dict[str, str]) -> tuple[float, str]:
        """算术平均对任意相关合法；协议不可比则拒绝聚合（unresolved）。"""
        if len(set(site_proto.values())) != 1:
            return float("nan"), "unresolved_incommensurable_protocol"
        if not site_evals:
            return float("nan"), "no_evidence"
        e_agg = sum(site_evals.values()) / len(site_evals)
        return e_agg, ("falsified" if e_agg >= 1.0 / self.alpha else "survived")

    def localize_violators(self, site_evals: dict[str, float]) -> list[str]:
        """e-BH：对逐站 e 值做 FDR 控制，定位真正违规的站点（针尖检测）。"""
        return e_benjamini_hochberg(site_evals, q=self.alpha)


# ============================================================
# IP-442 Falsification Certificate (FCert)
# ============================================================
@dataclass
class FalsificationCertificate:
    pred_id: str
    version: tuple            # V+
    claim: float
    validated: float
    e_agg: float
    alpha: float
    verdict: str              # survived | falsified | provisional | unresolved
    witness_root: bytes
    horizon: float
    is_hard: bool

    def gap(self) -> float:
        return max(0.0, self.claim - self.validated)

    def gate_effect(self) -> str:
        """硬证伪 -> revoke；软证伪/未验证 -> provisional；否则 pass。"""
        if self.verdict == "falsified" and self.is_hard:
            return "revoke"
        if self.verdict in ("falsified", "provisional", "unresolved"):
            return "provisional"
        return "pass"


# ============================================================
# IP-444 Active Gap Experiment Scheduler (AGES)
# ============================================================
class ActiveGapScheduler:
    def __init__(self, ledger: ResearchGapLedger, budget_per_round: float):
        self.ledger = ledger
        self.budget = budget_per_round

    def value_of_information(self, pid: str) -> float:
        p = self.ledger.preds[pid]
        gap = max(0.0, p.claimed - self.ledger.validated_level(pid))
        p_gap = self._posterior_gap_prob(pid)      # P(空白为真 | E)
        delta = self._expected_decision_flip(pid)  # 解决后决策改变量（安全+活性）
        cost = self._experiment_cost(pid)
        return (p_gap * delta - cost) / max(gap, 1e-6)

    def schedule(self) -> list[str]:
        # 只调度"会翻转决策"的硬谓词 + 少量软谓词（探索）；按 VoI/cost 排序
        hard = [p.pid for p in self.ledger.preds.values() if p.is_hard]
        ranked = sorted(hard, key=self.value_of_information, reverse=True)
        return ranked[: self._n_within_budget()]

    def preregister(self, pid: str, protocol: "Protocol"):
        """预注册：协议在采数前锁定，避免事后挑 α / 挑切片（古德哈特防线）。"""
        self.ledger.preds[pid].protocol_hash = hash_protocol(protocol)
        self.ledger.merkle.append({"op": "prereg", "pid": pid,
                                   "proto": hash_protocol(protocol)})


# ============================================================
# IP-445 HPC-F — 证伪感知准入门（在 HPC-E+ 之上加一个合取项）
# ============================================================
@dataclass
class HPCF:
    hpc_e_plus: "HPCEPlus"
    ledger: ResearchGapLedger

    def admits(self, plan, x, v, z, E_res, margin_req, modules) -> tuple[bool, dict]:
        # 1. 先过 v23 的四证门（安全继承的基座）
        if not self.hpc_e_plus.admits(plan, x, v, z, E_res, margin_req, modules):
            return False, {"reason": "hpc_e_plus"}
        # 2. 硬谓词证伪 -> 撤销依赖证书 -> 保守回退（仍是 Exec_v23 的子集）
        hard_deps = self._hard_predicates_of(plan, modules)
        for pid in hard_deps:
            fc = self.ledger.fcert(pid)
            if fc.gate_effect() == "revoke":
                # 不触发 SafeStop；退回 v23 的保守参数（共享区限速等）
                return False, {"reason": "hard_pred_falsified", "pid": pid,
                               "fallback": "v23_conservative"}
        # 3. 未验证/软失败不阻塞，仅标记 provisional
        tags = [pid for pid in hard_deps
                if self.ledger.fcert(pid).gate_effect() == "provisional"]
        return True, {"provisional": tags, "gaps": self.ledger.gap_report()}

    def _hard_predicates_of(self, plan, modules):
        return [p.pid for p in self.ledger.preds.values()
                if p.is_hard and (p.deps & set(modules))]
```

## 3. 正确性论证

### 引理 1（平均 e 值在任意相关下的合法性）
**陈述**：若每个站点 `e_s` 满足 `E_{H₀}[e_s] ≤ 1`（H₀ 为该站假设成立），则 `e_agg=(1/S)Σ_s e_s` 满足 `E_{H₀}[e_agg] ≤ 1`，且 `P_{H₀}(e_agg ≥ 1/α) ≤ α`，**无论站点间如何相关**。
**证明**：由期望线性，`E[e_agg]=(1/S)Σ_s E[e_s] ≤ 1` 不依赖联合分布；再由 Markov 不等式 `P(e_agg ≥ 1/α) ≤ α·E[e_agg] ≤ α`。若各站维护 e-process（非负上鞅），平均仍是非负上鞅，Ville 不等式给出任意停时下的同样界。∎

### 引理 2（复合零假设下似然比 e 值的合法性）
**陈述**：设 `e(X)=(p₁/p₀)^X((1−p₁)/(1−p₀))^{n−X}`，`0<p₀<p₁<1`，则对任意 `p≤p₀`，`E_p[e] ≤ 1`。
**证明**：`E_p[e] = f(p)^n`，其中 `f(p)=(1−p)(1−p₁)/(1−p₀)+p·p₁/p₀`。`f(p₀)=1`，且 `f'(p)=p₁/p₀−(1−p₁)/(1−p₀)>0`（因 `p₁>p₀`）。故 `p≤p₀ ⇒ f(p)≤1 ⇒ E_p[e]≤1`。∎

### 引理 3（安全继承不被证伪层破坏）
**陈述**：任意硬/软谓词判定与任意组合失效下，`Exec_v24 ⊆ Exec_v23`。
**证明**：`HPCF.admits` 先要求 `hpc_e_plus.admits`（即 π∈Exec_v23），再无任何分支能"增加"一个不在 Exec_v23 的计划；硬证伪只 `return False`（保守回退），软失败只返回 tag 而不改变执行域。因此 `Exec_v24 = Exec_v23 ∩ Fil_fals_hard ⊆ Exec_v23`。∎

### 引理 4（空白记账的单调性与"无免费可信"）
**陈述**：(i) 证据只增时 `LCB_{1−β}` 单调不减，故 `G(c)` 单调不增；(ii) 若谓词从未被检验（`E=∅`），则 `validated=0`，`G(c)=claim`。
**证明**：(i) anytime-valid 置信序列在追加数据下界不降（e-process 反演的标准性质）；(ii) 直接由 `validated_level` 对空证据返回 0。∎
**推论**：**"未被证伪" ≠ "已被验证"**。系统不能凭"没测出问题"获得任何可信度；可信度只能由证据下界挣得——这正是把"证明"降格为"可证伪假说"的形式化后果。

### 定理（HPC-F 的健全性与认知-安全分离）
**陈述**：`HPCF.admits(π)=True` ⇒ (1) π∈Exec_v23；(2) π 依赖的所有硬谓词均未被证伪；(3) 软谓词失败/未验证以 provisional 标记但绝不阻塞。且任意认知失败都不会触发 SafeStop，任意安全失败都不会被标为 provisional。
**证明**：由 `admits` 的两步合取（引理 3）与 `gate_effect` 的值域划分（`revoke` 仅对硬谓词 falsified，`provisional` 对软/未验证，`pass` 对 survived）直接可得；SafeStop 只在 `hpc_e_plus` 的 v23 路径内触发，FCert 分支永不调用 SafeStop。∎

## 4. 实验：跨站点相关下的证伪校准（本轮已运行）

**假设场景**：κ_c=0.99（漏检率上界 `p₀=0.01`）。若各站点漏检率满足假设，则"全站点满足"为真；若部分站点存在系统盲区（`p=0.05`），则为研究空白。站点间通过共享环境冲击产生**正相关**（Gaussian copula，秩相关 ρ）。对比两种聚合：
- **朴素池化**（v23 FSVC 的 Hoeffding 池化隐含做法）：把 `S·n` 次检验当作 i.i.d.，用 `√(p₀(1−p₀)/(Sn))` 做 z 检验；
- **联邦 e 值平均**：逐站似然比 e 值（`p₁=0.05`）算术平均，`e_agg ≥ 1/α` 即证伪。

设置：`n=1500`/站，`α=0.05`，2000 次重复。

| 配置 | 朴素池化 第一类错误 | 联邦 e 值平均 第一类错误 |
|---|---|---|
| S=4, ρ=0.5 | 0.074 | 0.000 |
| S=8, ρ=0.5 | 0.070 | 0.000 |
| S=16, ρ=0.5 | 0.094 | 0.000 |
| S=8, ρ=0.0 | 0.054 | 0.000 |
| S=8, ρ=0.3 | 0.062 | 0.000 |
| S=8, ρ=0.6 | 0.100 | 0.000 |
| S=8, ρ=0.9 | **0.197** | **0.000** |

| 功效（S=8, ρ=0.5, 存在真实空白） | 朴素池化 | 联邦 e 值平均 |
|---|---|---|
| 40% 站点漏检率 5% | 1.000 | 1.000 |
| 仅 1/8 站点漏检率 5% | 1.000 | 1.000 |

**结论**：(1) 站点越相关，朴素池化的第一类错误越失控（0.054→0.197），即它会把"没超出 α 的随机波动"误报成证据、或更危险地**低估研究空白**；联邦 e 值平均在所有相关水平下稳定 ≤α。(2) 代价是保守：H₀ 下从不误报（0.000），真实空白存在时仍满功效——保守性换来的是**可审计的正确性**，而非牺牲检出。(3) 这恰好证明 v23 的 FSVC 用 Hoeffding 池化**默认了跨设备独立性**，该假设在车队部署中几乎必然被违反。

复现要点（伪代码）：

```python
# 相关均匀分布（copula），保证每站边际漏检率恰为 p0
Z = rng.standard_normal((1, n))
W = rho * Z + sqrt(1 - rho**2) * rng.standard_normal((S, n))
U = norm.cdf(W)                         # 每站 ~ U(0,1)，跨站相关
X = (U < np.where(viol, 0.05, p0)[:, None]).sum(axis=1)
naive_reject = (X.sum()/(S*n) - p0) / sqrt(p0*(1-p0)/(S*n)) > norm.ppf(1-alpha)
e_agg = np.mean((p1/p0)**X * ((1-p1)/(1-p0))**(n-X))
e_reject = e_agg >= 1/alpha
```
