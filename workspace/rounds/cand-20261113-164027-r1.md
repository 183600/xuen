# 第 66 轮（承接第 65 轮「VISTA 视觉知情安全时序归因」IP-214~223；灵感循环第 3 轮；本轮灵感：「视觉定位」×「中间件」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，但它自述的最大风险是系统性的：**归因建立在两个从未被检验的假设上——故障属于有限假设集 ℋ、且视觉与几何失效相互独立；真实故障常是未知类型的组合，透明/镜面/对抗 patch 又会让视觉与几何共享同一个分布外失效源，于是 FIR 把未知复合故障强行归入最近假设、只膨胀错误的球——第 64 轮的单点故障由此升级为「归因错误的复合故障」，而且系统因为「已经归因」而更自信地继续执行（A88）。** 本轮不叠加新模态、不扩充假设集，而是改造归因本身的**认识论形态**：第 65 轮问「哪类故障后验最高」，RELIC 问「**我到底能不能说清是谁坏了；说不清时，我凭什么继续动**」。本轮核心命题是：
>
> **把「故障归因」从一次性闭集分类，重写为一次带完整性监控的「故障空间视觉定位」：用中间件血缘把「独立性假设」换成可观测的共因图，用视觉定位的绑架检测/全局重定位/多假设/保护水平处理未知复合故障，并把「归因丢失（lost）」升格为一等安全状态——宁可停在原地，也不带着证书做错误承诺。**

## 0. 直觉与动机

**灵感 1（视觉定位 → 归因不是分类，而是定位；而分类器从不会「承认自己走丢」）**
直觉：视觉定位系统真正难的从来不是「算一个位姿」，而是**知道自己何时算错了**。它有三件 VISTA 完全没有的装备：(i) **绑架检测（kidnapped robot）**——新观测与当前位姿假设矛盾时，不会把新观测硬塞进旧假设，而是宣布「我丢了」并**全局重定位**；(ii) **多假设**——重复走廊/相似结构造成感知混叠，单峰滤波会锁死在错峰上，必须保留多峰；(iii) **完整性监控（RAIM / 解分离 / 保护水平）**——不只输出点估计，还输出「这个估计能错到什么程度」的上界，以及在证据不足以支撑该上界时发出 `integrity unavailable`。VISTA 的 FIR 恰恰是个**只会局部跟踪、从不承认走丢、也从不算保护水平**的分类器：它永远在 ℋ 里挑一个最近的，即使真故障根本不在 ℋ 里。RELIC 把归因搬到**连续故障空间**：故障参数 θ 是「位姿」，阶段签名 ρ 是「观测」，ℋ 是「地图」；于是「未知复合故障」就是「地图外的新地点」，正确反应是**重定位或宣布丢失**，而不是最近邻强配。

**灵感 2（视觉定位 → 地图会过期：故障图谱不是真值，而是可维护的图）**
直觉：视觉定位默认地图会变（家具移动、季节更替），所以有**地图维护、回环闭合、地图版本**。VISTA 却默认 ℋ 完备且平稳——这是把「离线故障注入得到的图」当成了真值。RELIC 把 ℋ 显式当作**故障图谱（fault atlas）**：它可能缺新故障、参数会漂移；新故障先以**开放集**方式落为「未知地标」，反复出现后（回环闭合）才在语义流里晋升进图谱并升版本。地图外 = 未知故障，必须可检测、可暂存、可维护——而不是被 nearest-neighbor 悄悄吞掉。

**灵感 3（中间件 → 独立性是图上的事实，不是统计上的假设）**
直觉：VISTA 的 A88 把「视觉与几何独立失效」当假设。但谁最清楚两路证据是不是同源？**中间件**。它持有数据血缘（哪个相机/驱动/标定表/模型权重/时钟产生了哪条消息）、QoS（deadline、丢包、liveness）、版本与时间戳。若视觉与力残差**共享上游生产者**（同一相机、同一标定、同一感知模型 checkpoint、同一时钟），它们就**在结构上不独立**——这不是待检验的统计假设，而是从血缘图直接可读的边。RELIC 用**共因图**把独立通道折叠成「虚拟传感器」，既修掉 A88，也让「同一 OOD 物体同时骗过几何与视觉」这种共因变得**可观测、可隔离**。此外中间件还带来两件基础设施：(i) **时间同步有效性**——VISTA 的三阶段签名要求跨流对齐，时钟偏斜/丢包会把同步故障伪装成物理故障，必须前置门控并单列 H_mw；(ii) **确定性录放**——可离线用扩展图谱做**反事实重定位**，让图谱维护与证书审计可复现。

**灵感 4（合流 → RELIC：Relocalization-Enabled fault Localization with Integrity & Common-cause）**
闭环：中间件**证据信封**（payload + 血缘 + 时间戳 + QoS + 版本）→ 证据有效性/时间同步门 → 故障空间多假设信念（滤波 + 分故障漂移模型）→ 完整性监控（NIS / 解分离 / 保护水平 AIR）→ 若 integrity 可用：定向处置 + 认证前缀；若 `attribution_lost`：**k\*=0 安全保持 + 全局重定位 / 开放集检测** → 共因图感知融合（折叠虚拟传感器）→ 安全时做**主动重定位探针**（目标从「减熵」改为「降低定位/保护水平」）→ 回环闭合 + 图谱升版 → 证书 J_relic 记录「为何信 / 为何停 / 地图版本 / 血缘哈希 / 保护水平」。

**灵感 5（对第 65 轮组件的原位升级）**
- **FIR → FIR-L**：ℋ 增 `H_mw`（中间件/时序/版本）与 `H_novel`（开放集）；输出从「后验 + argmax」变为「多假设信念 + 保护水平 + lost 标志」。
- **VCV → VCV-L**：视觉证据自带位姿协方差；`visual_unobservable` 升级为「定位退化域 + 保护水平」——不可观测时给的是「此处视觉不能为证」，而非「无接触」。
- **AFA → AFA-L**：探针目标从「故障假设熵」改为「降低故障空间定位不确定度 / 保护水平」；完整性不足时禁动物理探针，只允许 passive / visual 探针。
- **CSC → CSC-L**：认证前缀在**完整性可信集**上验证；`lost ⇒ k*=0` 安全保持，杜绝「带错误归因的块承诺」。
- **RSC-V → RSC-P**：沿被定位的故障流形膨胀，多假设时按定位协方差与共因类膨胀，而非单类定向。
- **WCV-V → WCV-P**：搜索域增「血缘一致故障流形」与图谱开放集，按信念边缘化而非 top-2。
- **CSP-V → CSP-P**：块边要求 `localized ∧ AIR≤ε`；`relocalize` / `safe_hold` 成为一等元技能。
- **AIC-V → AIC-P**：干扰集增中间件故障（时钟偏斜、丢包、版本漂移、血缘伪造）与开放集新故障；证书增 atlas_ver / provenance_hash / time_sync_ver。
- **OLP / DIR / SSB**：在线学习仍只在语义流；用录放做反事实归因，实时流零写。
- **J_vista → J_relic**：增 fault_protection_level、integrity_risk、attribution_lost、provenance_hash、common_cause_class、time_sync_ver、atlas_ver、novelty_score。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（RELIC 闭环）**：RELIC = (VISTA, MEE, TSE, CCG, FSB, AIM, GRL, ATL, CCF, ARP, CSC-L, FLC, J_relic)。定位：VISTA 的「归因形态」升级——从闭集分类改为带完整性监控的故障空间定位。不变式：**故障定位、完整性判定、全局重定位、图谱维护、共因图更新、证书构建只在语义流；实时流只做证据门控、信念预测步、保护水平计算与安全前缀执行，零学习写操作。**
- **定义 234（中间件证据信封 MEE）**：每条证据编码为 E=(m, π, t, τ, q, v)，其中 m 为 payload（如阶段签名分量），π∈2^V 为血缘根集合（相机/驱动/标定表/模型 checkpoint/时钟等上游节点），t 为时间戳，τ 为源时钟域，q 为 QoS 状态（deadline 余量、丢包、liveness），v 为版本（schema/模型/标定）。证据流由中间件在发布时自动附加，不可由消费者自报。
- **定义 235（证据有效性与时间同步门 TSE）**：给定证据 E 与判定阈值 (τ_s, τ_d, τ_q)，有效性谓词
  valid(E) = 1[ |skew(τ, τ_ref)| ≤ τ_s ∧ staleness(t) ≤ τ_d ∧ q.alive ∧ v = v_ref ]。
  无效证据不得进入阶段归因，只能进入 `H_mw` 的观测；跨流相位切割在任一路无效时退化为单流（力窗口）切割。
- **定义 236（共因图与有效独立性 CCG）**：共因图 G=(V,E) 为血缘 DAG。证据 e_i、e_j 的祖先集 A_i=anc(π_i)。若 A_i∩A_j≠∅，则二者**结构不独立**，其共因等价类为 G 上按共享祖先的连通分量。有效独立通道数 n_eff = 证据所用祖先子图的连通分量数。事故「同一 OOD 物体同时骗过视觉与几何」在此图中表现为二者共享一个上游节点（同一检测器/同一时钟）。
- **定义 237（故障空间与多假设信念 FSB）**：故障空间 Θ=⨆_{H∈ℋ}Θ_H ∪ Θ_∅，Θ_∅ 为开放集（图谱外）区域；每类 H 的参数 θ_H（如 F/T 偏置 b∈ℝ⁶、几何误差 δφ、接触模型参数、视觉扰动）。信念 b_t(θ) 为 Θ 上的混合分布（粒子/高斯混合），带均值与协方差；滤波含分故障漂移模型（偏置慢漂、几何准静态、模型参数阶跃）。
- **定义 238（故障空间观测模型与归一化创新）**：ρ_t = h(θ) + ε，ε 的协方差 Σ_ρ(π,t,q) 依赖血缘完整性与时间有效性（共享祖先或多通道相关时 Σ 非对角）。归一化创新 NIS_t(θ) = (ρ_t−h(θ))ᵀΣ_ρ⁻¹(ρ_t−h(θ))；对每个假设取边缘似然。
- **定义 239（解分离与故障保护水平 AIR）**：对假设对 (H_i,H_j) 定义解分离统计量 d_ij=‖x̂_i−x̂_j‖_Σ（x̂ 为由该假设导出的控制/膨胀决策）。解分离阈值 λ_ij 由 conformal 标定。故障保护水平
  PL = max_{H∈supp} sup_{θ,θ'∈Θ_H} L(θ,θ')，L 为「按 θ 处置、真值为 θ'」的安全损失；归因完整性风险 AIR = P_{θ∼b}[L>L_alert] + P_novel。若 AIR > ε_int 则完整性不可用。
- **定义 240（attribution_lost 与全局重定位 GRL）**：当（i）所有图谱内假设的 NIS 超过 conformal 门限，或（ii）最优与次优解分离 d_ij<λ 且 AIR>ε_int 时，置 `attribution_lost=True`；不在 ℋ 内强配，改为在 Θ 全空间（含 Θ_∅）上做全局重定位：θ* = argmax_θ b_global(θ)，并给出开放集新颖度 s_novel = 1 − F_atlas(NIS*)。若 s_novel>τ_novel 判为图谱外故障。
- **定义 241（故障图谱与开放集 ATL）**：故障图谱 Atlas=(ℋ, {p(ρ|H)}, ver) 由离线故障注入 + 真机标定构建；维护开放集密度 p_∅ 与候选队列。新故障先入候选（未知地标），达到重复性阈值 r_novel 后由语义流晋升并升 ver。**图谱不是真值，是有版本、会过期、需维护的先验。**
- **定义 242（共因感知融合 CCF）**：对每个共因等价类 C 折叠为一个虚拟观测 E_C（协方差按类内相关估计），类间按独立融合。融合后验
  P(H|ρ)=∫ p(ρ_C |H,θ) ∏_{C'≠C} p(ρ_{C'}|H,θ) b(θ)dθ，
  而非 ∏_i p(ρ_i|H) 的朴素独立乘积。n_eff<k 时置信度按 (k−n_eff) 折减。
- **定义 243（安全主动重定位探针 ARP）**：当 `localized`（AIR≤ε_int）且存在可安全激励时，选
  a*=argmax_a E[ΔPL(a) + λ·ΔH(b)]，s.t. 预测 f_n≤f_safe、形变≤ε_strain、证据有效性可维持。
  目标从 VISTA 的「降低假设熵」改为「降低定位不确定度与保护水平」；当 `attribution_lost` 时禁动物理探针（此时连安全激励都无可靠前提），只允许 passive / visual_probe。
- **定义 244（完整性认证前缀 CSC-L）**：对块 A_t 与前缀 k，在**完整性可信集** 𝒞={θ: L(θ,θ̂)≤PL 且 AIR≤ε_int} 上验证 ∀θ∈𝒞、∀s≤k：ρ_safe(s;θ)≥0；选最小 k 使 P[∃s≤k 越界]≤α_chunk。若 `attribution_lost` 或 AIR>ε_int，则 k*=0，转入 `safe_hold / relocalize`——**块承诺只在「说清楚谁坏了」之后才被签发**。
- **定义 245（故障回环闭合与图谱维护 FLC）**：跨 episode 若同一签名簇反复出现且参数一致（Mahalanobis 距离<τ_loop），闭合回环：共享隐故障参数、联合降方差，并在语义流中决定晋升/淘汰。回放（录放）用于反事实重定位与回环验证。
- **定义 246（RELIC 证书 J_relic）**：J_relic=(J_vista, fault_protection_level, integrity_risk, attribution_lost, provenance_hash, common_cause_class, time_sync_ver, atlas_ver, novelty_score, n_eff)。Valid ⇔ Valid(J_vista) ∧ (AIR≤ε_int ∨ attribution_lost) ∧ (localized ⇒ 一致处置) ∧ (lost ⇒ k*=0 ∧ safe_hold) ∧ 无效证据未被用于相位归因 ∧ atlas_ver 与 provenance_hash 可复算。
- **定义 247（风险预算与诚实性）**：定义归因诚实性 honest=1−P(误归因 ∧ 未宣告 lost)，可用性 avail=P(localized)。RELIC 明确呈现二者的 Pareto 前沿：收紧 ε_int 提升诚实性、降低可用性；目标是**不把可用性换成错误承诺**。
- **定义 248（RELIC 闭环算子）**：语义流 [LiDAR→LSF→USR/MEL→VPG→ACH→阶段切分→MEE/TSE→FSB→FIR-L→AIM→(localized? 定向处置 : GRL/ATL 开放集)→CCF→ARP→WCV-P→CSP-P→CSC-L→Shield→执行 k*→EV_exec→RSC-P→OLP→DIR→SSB→FLC→AIC-P]；实时流 [锚点读→信封校验/时间同步门→信念预测步→保护水平计算→CSC-L 早停→`lost ⇒ safe_hold`→前缀派发→J_relic 构建]。

## 2. 关键算法骨架

```python
# 故障空间定位 + 完整性监控 + 丢失即停（语义流为主，实时流只做预测与门控）
envs = middleware.collect_envelopes()                 # 每条证据带血缘/时间/QoS/版本
valid = [e for e in envs if time_sync_gate(e, tau_s, tau_d, tau_ref)]
b = fsb.predict(b_prev, dt)                            # 分故障漂移模型
b = fsb.update(b, valid)                               # NIS + 边缘似然，仅有效证据
nis_atlas, pl, air = aim.monitor(b, valid)             # 解分离 + 保护水平 + 完整性风险
if nis_atlas.all_exceed() or air > eps_int:
    b, s_novel = grl.relocalize(valid, atlas)          # 全局重定位 + 开放集
    if s_novel > tau_novel:
        atlas.enqueue_novel(valid); lost = True
    else:
        lost = True
else:
    lost = False
if not lost:
    h_star, theta = fsb.map(b)
    balls = rsc_p.inflate(h_star, b.cov, ccg)
    k_star = csc_l.certified_prefix(A, b, integrity_set(pl, air), m, alpha_chunk)
else:
    k_star = 0                                         # 一等安全状态：不动、重定位
if not lost and air <= eps_int:
    a = arp.choose_probe(b, pl, f_safe)                # 降低保护水平，而非仅降熵
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（完整性告警的可靠性）**：在图谱-标定集上残差可交换（A95）时，若所有图谱内假设的 NIS 均超过 conformal 门限，则真故障在 Θ_∅（图谱外）的概率 ≥1−α_int；反之图谱内故障触发 `lost` 的误报率 ≤α_int。因此 `attribution_lost` 不是「认输」，而是一个**有统计保证的一等信号**。
- **引理 10（共因折叠的置信度校正）**：若 k 条证据落入同一共因类（共享祖先），朴素独立融合的 log-odds 最多被高估 k/n_eff 倍；折叠为虚拟观测后后验校准，过度自信至少下降 (1−n_eff/k)。这直接消解 A88 的「共享 OOD 失效源」。
- **命题（时间同步是相位可辨识性的前提）**：时钟偏斜 |skew|>τ_s 时，跨流相位对齐矩阵 S 的对应块错位、SᵀΣ⁻¹S 近奇异，VISTA 引理 7 的三阶段可辨识性退化。故 TSE 是第 65 轮全部可辨识性论证的**前置条件**，H_mw 必须单列，不能被 FIR 误记为 S 或 M 故障。
- **定理 9（RELIC 端到端安全）**：在 A94–A99 下，Valid(J_relic) ⇒（localized ∧ AIR≤ε_int ∧ 只在被定位流形上膨胀 ∧ k*≥1 ∧ 前缀安全）∨（attribution_lost ∧ k*=0 ∧ safe_hold/relocalize）∧ 共因折叠正确 ∧ 无效证据不参与相位归因。即：**系统永不为一个它说不清的故障签发移动承诺**。
- **定理 10（开放集-可用性权衡）**：随证据与回放累积，持续静默强配未知故障的概率单调下降；但更紧 ε_int 提高 lost 率、降低可用性。给出诚实性-可用性 Pareto 界：不存在既 100% 可用又 100% 诚实的策略。

## 2. 形式化定义（完整版）

**定义 233（RELIC 闭环）** RELIC 是 VISTA 的「归因形态」升级：在 GRIP→VISTA 的「语义流 ∘ 实时流」骨架上，挂载 MEE（中间件证据信封）、TSE（时序/有效性门）、CCG（共因图）、FSB（故障空间信念）、AIM（完整性监控）、GRL（全局重定位）、ATL（故障图谱/开放集）、CCF（共因感知融合）、ARP（安全重定位探针）、CSC-L（完整性认证前缀）、FLC（回环闭合/图谱维护），并原位升级 RSC-V→RSC-P、WCV-V→WCV-P、CSP-V→CSP-P、AIC-V→AIC-P、J_vista→J_relic。不变式：**故障定位、完整性判定、全局重定位、图谱维护、共因图更新、证书构建只发生在语义流与低频线程；实时路径只做证据门控、信念预测步、保护水平计算、安全前缀执行与 `lost⇒safe_hold`，零学习写操作。**

**定义 234（中间件证据信封 MEE）** 每条证据 E=(m, π, t, τ, q, v)：m 为 payload（阶段签名分量、位姿、接触斑、低维形变嵌入等）；π∈2^V 为血缘根集合，节点包括相机、驱动、标定表、感知模型 checkpoint、时钟源、力传感器固件等；t 为时间戳，τ 为源时钟域（用于跨域换标）；q 为 QoS 状态（deadline 余量、丢包计数、liveness）；v 为版本三元组（message schema、模型、标定）。**信封由中间件在发布时自动附加并签名**，消费者不得自行填写血缘/时间/版本——否则完整性论证失去根基。

**定义 235（证据有效性与时间同步门 TSE）** 给定参考时钟域 τ_ref 与阈值 (τ_s,τ_d,τ_q)，
valid(E) = 1[ |skew(τ,τ_ref)| ≤ τ_s ∧ staleness(t) ≤ τ_d ∧ q.alive ∧ q.drop ≤ τ_q ∧ v = v_ref ]。
- skew 由中间件时间同步服务估计（PTP/chrony），保留估计协方差。
- 任一路证据无效时，跨流相位切割退化为单流（力窗口）切割，且该证据只可进入 `H_mw` 的观测，不得进入几何/力/模型/视觉假设的似然。
- **同步故障必须单列为 `H_mw`**：否则相位错位会被 FIR 误记为 H_geo 或 H_model。

**定义 236（共因图与有效独立性 CCG）** 共因图 G=(V,E_mw) 为血缘 DAG（节点=生产者，边=数据流）。证据 e_i 的祖先集 A_i=anc(π_i)。共因等价类为 G 上「祖先集相交」的连通分量：e_i ≁ e_j ⇔ A_i∩A_j=∅。有效独立通道数 n_eff = 证据祖先子图的连通分量数。事故「同一 OOD 物体同时骗过视觉与几何」在图上的表现是：视觉与力/几何证据共享同一上游检测器/相机/标定节点，因此它们**结构不独立**，不得按独立证据融合。

**定义 237（故障空间与多假设信念 FSB）** 故障空间 Θ=⨆_{H∈ℋ}Θ_H ∪ Θ_∅。ℋ={H0, H_geo, H_force, H_model, H_vis, H_policy, H_mw}，Θ_∅ 为图谱外开放集。每类参数 θ_H：F/T 偏置 b∈ℝ⁶、几何误差 δφ、接触模型参数（软接触刚度/阻尼/接触点歧义）、视觉扰动（位姿/检测偏差）、策略 OOD 幅度、中间件故障幅度（时钟偏斜量/版本偏移）。信念 b_t(θ) 为混合分布（粒子集或高斯混合），带均值与协方差 Σ_b。漂移模型按故障类分别设定：H_force 慢漂（随机游走）、H_geo 准静态、H_model 阶跃、H_vis 与扰动相关、H_mw 分段（同步丢失前后的阶跃）。

**定义 238（故障空间观测模型与归一化创新）** ρ_t = h(θ) + ε，ε∼𝒩(0, Σ_ρ(π,t,q))。Σ_ρ 依赖血缘完整性与时间有效性：共享祖先或多通道相关时 Σ_ρ 含非对角项（这正是朴素独立融合会忽略的部分）。归一化创新 NIS_t(θ)=(ρ_t−h(θ))ᵀΣ_ρ⁻¹(ρ_t−h(θ))；对每个假设取边缘似然 p(ρ_t|H)=∫ p(ρ_t|θ)b_H(θ)dθ（粒子/混合求和）。

**定义 239（解分离与故障保护水平 AIR）** 对假设对 (H_i,H_j)，解分离统计量 d_ij=‖x̂_i−x̂_j‖_{Σ_x}，其中 x̂_H 是由假设 H 导出的**实际决策**（应膨胀哪个球、哪条控制律、执行多长的前缀），而非仅参数估计。阈值 λ_ij 由标定集 conformal 确定。故障保护水平
PL = max_{H∈supp(b)} sup_{θ,θ'∈Θ_H} L(θ,θ')，
L 为「按 θ 处置、真值为 θ'」的安全损失（半径/力限/滑移/几何越界）。归因完整性风险
AIR = Σ_H b(H)·1[PL_H>L_alert] + P_novel。
若 AIR>ε_int，则判定「完整性不可用」。

**定义 240（attribution_lost 与全局重定位 GRL）** 当 (i) 所有图谱内假设的 NIS 均超过 conformal 门限 q_NIS(α_int)，或 (ii) 最优/次优解分离 d_ij<λ_ij 且 AIR>ε_int 时，置 `attribution_lost=True`。此时**不在 ℋ 内强配**，而在全空间 Θ（含 Θ_∅）上做全局重定位：
θ* = argmax_θ b_global(θ)，s_novel = 1 − F_atlas(NIS*_atlas)，
其中 F_atlas 为图谱内残差的经验分布。若 s_novel>τ_novel，判为**图谱外故障**并进入 `H_novel` 候选；否则在 Θ 内重定位到最近的**可信**假设，但只有在 AIR 回落到 ≤ε_int 后才解除 lost。

**定义 241（故障图谱与开放集 ATL）** Atlas=(ℋ, {p(ρ|H)}, ver)。由离线故障注入（仿真 + 真机标定台）构建，但**明确不是真值**：它有版本 ver、会过期、参数会漂移。维护开放集密度 p_∅ 与候选队列；新故障先作为「未知地标」入候选，达到重复阈值 r_novel（同签名簇跨 episode 出现次数）后由语义流晋升进图谱并升 ver。淘汰机制：长期不再被观测或被证伪的假设降权。

**定义 242（共因感知融合 CCF）** 对共因等价类 C，把类内证据折叠为虚拟观测 E_C，其协方差按类内实际相关结构估计（由 CCG 的共享祖先与标定残差相关共同给出），类间视为独立：
P(H|ρ) ∝ ∫ p(ρ_C|H,θ) · ∏_{C'≠C} p(ρ_{C'}|H,θ) · b(θ) dθ，
而非 ∏_i p(ρ_i|H) 的朴素独立乘积。当 n_eff<k 时，置信度按 (k−n_eff) 折减（等价于有效样本数下降）。这一条直接修掉 VISTA 的 A88。

**定义 243（安全主动重定位探针 ARP）** 探针集 A={press,rub,tap,lift,visual_probe,null_test,resync_probe}。当且仅当当前 `localized`（AIR≤ε_int）时，选择
a* = argmax_{a∈A} E[ ΔPL(a) + λ·ΔH(b) ]，
s.t. 预测 f_n≤f_safe(φ̂,f̂_vis)、预测形变≤ε_strain、证据有效性可维持、支持视觉早停。
目标从 VISTA 的「最大化故障假设互信息（降熵）」改为「**降低定位不确定度与保护水平**」——因为真正决定安全的是 PL/AIR 而非分类熵。当 `attribution_lost` 时，连「安全激励」的前提都不成立，**禁动物理探针**，只允许 passive 观测、`visual_probe`（主动视觉）与 `resync_probe`（重同步时钟/重连中间件）。

**定义 244（完整性认证前缀 CSC-L）** 对块 A_t 与前缀 k，在完整性可信集 𝒞={θ: L(θ,θ̂)≤PL ∧ AIR≤ε_int} 上验证：∀θ∈𝒞、∀s≤k，ρ_safe(s;θ)≥0（沿用 ρ_rob/ρ_slip/ρ_force，并在 H_force 下用偏置上界、H_mw 下用同步失效的保守界）。用 conformal 选最小 k 使
P[∃s≤k: 某通道越界] ≤ α_chunk。
若 `attribution_lost` 或 AIR>ε_int，则 **k\*=0**，转入 `safe_hold / relocalize`：保持姿态、力限回退到最保守值、等待重定位或人接管。**块承诺只在「说清楚谁坏了」之后才被签发。**

**定义 245（故障回环闭合与图谱维护 FLC）** 跨 episode 若同一签名簇反复出现、参数一致（Mahalanobis 距离<τ_loop），则闭合回环：共享隐故障参数、联合降方差，并由语义流决定晋升/淘汰。录放（确定性 replay）用于反事实重定位与回环验证：把记录的 E 流在新图谱版本下重放，检验归因是否改变、是否仍满足 AIR≤ε_int。

**定义 246（RELIC 证书 J_relic）** J_relic=(J_vista, fault_protection_level, integrity_risk, attribution_lost, provenance_hash, common_cause_class, time_sync_ver, atlas_ver, novelty_score, n_eff)。验证规则：
Valid(J_relic) ⇔ Valid(J_vista)
∧ (AIR≤ε_int ∨ attribution_lost)
∧ (localized ⇒ 定向处置与信念一致 ∧ k*≥1)
∧ (attribution_lost ⇒ k*=0 ∧ safe_hold/relocalize 已记录)
∧ (无效证据未参与相位归因，且已归入 H_mw)
∧ atlas_ver 与 provenance_hash 可由中间件日志复算。
审计链新增：为何信这个归因（PL/AIR）、为何停（lost）、证据来自哪些上游（血缘哈希）、图谱是哪一版、有无共因类。

**定义 247（风险预算与诚实性）** honest=1−P(误归因 ∧ 未宣告 lost)，avail=P(localized)。RELIC 明确呈现诚实性-可用性 Pareto 前沿：收紧 ε_int / τ_novel 提高 honest、降低 avail。设计目标不是最大化 avail，而是**在任何 avail 下都不把「错误归因」伪装成「可信结论」**。

**定义 248（RELIC 闭环算子）** 语义流：[LiDAR→LSF→USR/MEL→VPG→ACH→阶段切分→MEE/TSE→FSB 预测/更新→FIR-L→AIM(NIS/解分离/PL/AIR)→(localized? 定向处置 : GRL 全局重定位 + ATL 开放集)→CCF 共因折叠→ARP 安全重定位探针→WCV-P→CSP-P/TSL→CSC-L 完整性前缀→Shield→执行 k*→EV_exec→RSC-P→OLP→DIR→SSB→FLC 回环/图谱维护→AIC-P]。实时流：[锚点读→信封校验/时间同步门→信念预测步→保护水平计算→CSC-L 早停→`lost⇒safe_hold`→π_σ 前缀派发→J_relic 构建]。

## 3. 关键算法伪代码

### IP-224/225 MEE + TSE（中间件证据与门控）

```python
class EvidenceEnvelope:
    __slots__ = ("m", "provenance", "t", "clock_domain", "qos", "version")
    # 由中间件发布端构造并签名；消费者只读

def time_sync_gate(E, ref, tau_s, tau_d, tau_q, v_ref):
    skew, _ = middleware.clock.estimate_skew(E.clock_domain, ref)
    if abs(skew) > tau_s:                    return False, "skew"
    if middleware.staleness(E.t, ref) > tau_d: return False, "stale"
    if not E.qos.alive or E.qos.drop > tau_q:  return False, "qos"
    if E.version != v_ref:                     return False, "version"
    return True, "ok"

def split_valid(envs, ref):
    ok, bad = [], []
    for E in envs:
        v, _ = time_sync_gate(E, ref, TAU_S, TAU_D, TAU_Q, V_REF)
```

### IP-226/231 CCG + CCF（共因图与共因感知融合）

```python
class CommonCauseGraph:
    def __init__(self, lineage_dag):
        self.g = lineage_dag

    def ancestors(self, E):
        return self.g.ancestors(E.provenance)

    def equivalence_classes(self, envs):
        sets = [self.ancestors(E) for E in envs]
        cls, used = [], set()
        for i, ai in enumerate(sets):
            if i in used: continue
            comp, stack = set(), [i]
            while stack:
                k = stack.pop()
                if k in used: continue
                used.add(k); comp.add(k)
                for j, aj in enumerate(sets):
                    if j not in used and (sets[k] & aj):
                        stack.append(j)
            cls.append(comp)
        return cls

    def n_eff(self, envs):
        return len(self.equivalence_classes(envs))

def cc_aware_fusion(belief, envs, ccg):
    cls = ccg.equivalence_classes(envs)
    loglik = {}
    for H in belief.components:
        total = 0.0
        for comp in cls:
            virtual = collapse(comp, envs, H)      # 类内折叠，协方差含相关项
            total += log p_virtual(virtual | H, belief)
        loglik[H] = total
    return normalize(loglik)
```

## 4. 推导

**引理 9（完整性告警的可靠性）** 在图谱-标定集上残差可交换（A95）时，图谱内假设的 NIS 是 conformal 可校准的。若所有图谱内假设的 NIS 均超过 q_NIS(α_int)，则「真故障属于 Θ_∅」在置信水平 1−α_int 下成立（否则存在图谱内假设以 >1−α_int 概率产生该观测，与其分位定义矛盾）。反之，图谱内故障被误判 `lost` 的概率 ≤α_int。故 `attribution_lost` 是**有统计保证的一等信号**，而非工程上的「认输」。∎

**引理 10（共因折叠的置信度校正）** 设 k 条证据落入同一共因等价类，共享祖先 A。朴素独立融合假设 p(ρ_1..ρ_k|H)=∏_i p(ρ_i|H)，而真实联合在给定 A 下才条件独立：p(ρ_1..ρ_k|H)=∫_A ∏_i p(ρ_i|H,A)p(A)dA。由变分/协方差不等式，独立乘积的 KL 距离最多把 log-odds 放大 O(k/n_eff) 倍（有效独立观测仅 n_eff 个）。折叠为虚拟观测 E_C（协方差含类内相关项）后，后验与真实联合一致，过度自信至少降低 (1−n_eff/k)。这直接消解 A88：共享 OOD 失效源在共因图上显形后，不再被当作两票独立证据。∎

**命题（时间同步是相位可辨识性的前提）** VISTA 引理 7 依赖跨流相位对齐矩阵 S 的三块结构。若时钟偏斜 |skew|>τ_s，视觉与力/几何的相位标签错位，S 的对应块被置换/涂抹，SᵀΣ_ρ⁻¹S 近奇异，κ_fi→0，三阶段可辨识性退化。因此 TSE 是第 65 轮全部可辨识性论证的**前置条件**；同步故障必须单列 `H_mw`，不能计入 H_geo/H_model 的似然。∎

**定理 9（RELIC 端到端安全）** 在 A94–A99 下，Valid(J_relic) 蕴含：
1. **要么说清并安全动**：localized ∧ AIR≤ε_int ∧ 只在被定位流形上膨胀（RSC-P）∧ k*≥1 ∧ 前缀在完整性可信集 𝒞 上验证通过；
2. **要么说不清就停**：attribution_lost ⇒ k*=0 ∧ safe_hold/relocalize，且不以任何后验强配签发移动承诺；
3. **共因正确**：共因等价类折叠融合，n_eff<k 时置信度折减，不把共享失效源当独立证据；
4. **同步不作伪**：无效证据不参与相位归因，只归入 H_mw；
5. **可审计**：PL/AIR/lost/血缘哈希/图谱版本皆可由中间件日志复算。
即：**系统永不为一个它说不清的故障签发移动承诺；它要么带着保护水平动，要么停住重定位。** ∎

**定理 10（开放集-可用性权衡）** 设图谱外故障的签名单调远离图谱残差分布，则随证据数 n 与回放次数 m 增加，最佳图谱内 NIS 单调上升、s_novel 单调上升，持续静默强配的概率以 O(exp(−c·n)) 衰减。但收紧 ε_int 提高 `lost` 率、降低 avail；对任意策略存在 Pareto 界 honest(avail)，不存在既 avail=1 又 honest=1 的策略（图谱不完备且允许未知故障）。RELIC 的价值在于**显式暴露这条前沿**，而不是用一个点估计把它藏起来。∎

## 7. 已知风险

**一句话**：RELIC 的完整性保证等价于「中间件血缘图忠实反映依赖，且故障图谱的开放集密度可标定」；一旦血缘被**漏报或伪造**（一个未声明的共享依赖，或一块被污染的时钟），完整性监控会拿「一致却错误」的证据算出一个很小的保护水平，把第 65 轮的「静默误归因」升级为**「带证书的误归因」**——系统不仅更自信，审计链还看起来无懈可击（A94）。

**次级风险与缓解**：
1. **血缘图不完整/被伪造**：最致命。缓解：信封由中间件签名为不可抵赖；跨源核对（相机-驱动-标定版本三方一致）；对未声明共享做敏感性分析（删除一条血缘边后 AIR 是否跃升）；把「血缘完整性」本身纳入 AIC-P。
2. **保护水平 PL 的损失函数难定义**：L(θ,θ̂) 依赖任务与物理后果，可能被低估。缓解：多任务分层 L；用真实事故回放标定；PL 虚高率单独作为 E247 指标监测。
3. **lost 过多导致可用性崩塌**：图谱不全都判 lost，机器人「不敢动」。缓解：分层 lost（soft lost 只降速/降 k，hard lost 才 safe_hold）；图谱主动扩充；用 avail-honest Pareto 显式管理而非追求单点。
4. **开放集阈值 τ_novel 与误报的权衡**：太松→未知被当已知，太紧→已知被当未知。缓解：conformal 校准 + 依任务代价设定；E245 专测。
5. **共因图计算依赖中间件覆盖**：若某些证据绕过中间件（共享内存直传），血缘缺失。缓解：强制所有安全相关证据走信封化通道；绕过即判证据无效。
6. **回环闭合错误晋升**：错误的新故障被晋升进图谱会污染后续归因。缓解：晋升需多 episode 复现 + 反事实录放验证 + 可回滚版本。
7. **实时预算**：TSE + FSB 预测 + PL 计算逼近 3ms。缓解：PL 用查表/预编译；粒子数按 CPU 预算自适应；重定位/回环全留语义流。
8. **录放与现实的分布差**：录放假设中间件日志完整、时钟可重放。缓解：记录时钟调整事件；重放时注入已知偏斜做鲁棒性检查。
