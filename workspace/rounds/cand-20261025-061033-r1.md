# 第 8 轮（新循环第 1 轮）· PHANTOM TOUCH：触觉不在传感器里，在动作与感知的差里

> 检索/复核日期：**2026-10-25（UTC）**。赛事身份不变：用户所指是宇树科技的 **UniBot 世界挑战赛**（unibot.unitree.com），G1 + Dex1、32 项桌面任务、通才单模型赛道、选手自部署 + 官方远程真机 API 评测。状态文件已跨 7 轮；本轮按“新循环第 1 轮 / 总第 8 轮”继续，保留并修剪 I1–I13，不推倒重来。三个灵感词是「触觉感知」「传感器融合」「论文发表」。

我先钉住一个不舒服的事实：**挑战赛的 API 没有触觉、没有力/力矩、没有深度，Dex1-1 也没有触觉阵列。** 但榜单最差的 8 个任务几乎都是接触密集任务：Plug In Ethernet 17.7%、Unlock 20.1%、Open Pill Bottle 22.7%、Hang the Cup 23.0%、Pick Out Battery 23.3%、Zip Up 23.4%、Organize Stationery 22.5%、Spell robot 21.8%（8 模型均值，占位数据，仅作结构先验）[S6]。触觉的物理信息没有消失，它泄漏在四个地方：

1. **头戴双目视差**：`head_stereo_left/right` 是已校正的立体对，meta 里直接给了内参、R、T 和基线 58.25mm [S4]；近距离可算毫米级深度。
2. **腕部近景**：`cam_left_wrist/right_wrist` 在夹爪闭合时看得见接触面、间隙、遮挡、变形和滑移。
3. **夹爪开度与命令的差**：命令继续闭合、实际开度停住 = 夹到东西；命令打开、实际不动 = 粘连/卡住。
4. **EE/关节跟踪误差**：位置控制器下，外部接触力会让实际位姿落后于指令；把“落后”按速度归一化，就是接触/阻力的代理。

把这四个信号融合成 30Hz 的**接触状态**，用它门控动作块、触发主动微探、驱动恢复，并在 33k 演示上做“动作-观测差”的大规模自监督——这既是本轮的技术主线，也是一个可发表的论文故事：**Touch Without Sensors**。上一轮 PILOT-GPR 的评分步骤图/放置/少样本/产学研资产保留，但研究火力从“放置”进一步收窄到“接触”：**放置是闸门，接触是闸门前面那道最贵的门。**

## 0. 本轮先核实：触觉不在 API 里，但接触信息在别处

### 0.1 API 的传感器清单：没有触觉、没有力、没有深度

提交模板 README 的观测目录是权威的 [S5]：

| 键 | 形状 | 接触相关用途 |
|---|---|---|
| `cam_left_high` / `cam_right_high` | 480×640×3 | 已校正立体对；度量深度、物体/容器位姿、夹爪-物体间隙 |
| `cam_left_wrist` / `cam_right_wrist` | 480×640×3 | 近景接触面、间隙、遮挡、变形、滑移 |
| `left_arm` / `right_arm` | 7 | 关节位置；跟踪误差、速度/加加速度（差分）；接触力代理 |
| `left_ee_pose_gripper_base` / `right_ee_pose_gripper_base` | 6 | EE 位姿；笛卡尔跟踪误差、运动不一致 |
| `left_gripper` / `right_gripper` | 1 | 开度；堵转/夹持接触 |
| `lower_body` | 15 | 躯干姿态、稳定性 |
| `language` | str | 任务指令（episode 内不变） |

**没有** tactile、force/torque、depth、joint velocity/torque、gripper current。动作空间只有 joint 或 ee 二选一，外加夹爪和 pivot；`action_chunk_size` 在 metadata 里固定，evaluator 把整段 chunk 开环执行完才再次调用 `get_action` [S5]。这意味着：

```text
接触反应延迟 ≈ action_chunk_size / 30s
T_a=4 → 133ms；T_a=8 → 267ms；T_a=16 → 533ms
```

这是一个硬约束：**想做接触闭环，就不能用大 chunk；想用大 VLA，就买不到高频接触反应。** 本轮方案必须正面回答这个 trade-off（见 §3.4）。

Dex1-1 的产品页也确认了缺口与潜力 [S9]：90mm 行程、5–120N 可调夹持力、0.1mm 分辨率、0.24s 全行程闭合；电机本身以 1000Hz 反馈**角度、角速度、力矩、温度**，但挑战 API 只暴露夹爪开度。也就是说，**硬件能“感觉”，接口不给你；本方案按“接口最坏情况”设计，不依赖内部力矩。** 这反而让论文主张更干净：零额外硬件、零私有接口。

### 0.2 数据集里有“动作-观测差”：被忽略的接触标签矿

挑战数据集约 33k episodes / 169h / 30fps，32 个任务，四路相机，EE 位姿 base/torso 两套，动作流与观测流逐帧对齐 [S3][S4]。这不是普通的“图像-动作”数据集，它同时保留了**指令动作**和**实际状态**：遥操作者命令夹爪闭合、命令手臂向前，而机器人在接触时会出现堵转、跟踪滞后、视觉运动停止。**接触的标签就藏在这两个流的差里。**

我做了一个小规模试点（各下载一个 parquet 分片；不是全量）：

- HangCup：324 条 episode、63,999 帧；
- PlugInEthernet：291 条 episode、111,462 帧；
- 合计 175,461 帧。

三个发现：

1. **原始 `action - observation` 不能直接当接触信号。** 动作领先观测约 2 帧（夹爪最优 lag 1–2，手臂 lag 2–3）；命令以 0.5/帧的斜率变化时，原始差会被“斜坡滞后”主导，看起来一直有 0.5 的差，但并不是接触。
2. **把“命令速度接近零”的稳态段单独拿出来，夹爪堵转是干净的夹持接触信号。** 定义稳态差 `gap = action_gripper - obs_gripper`，在命令速度 <0.005 连续 ≥3 帧时统计：HangCup 右手 51.9% 的 episode 出现 `gap>0.1`（左手仅 1.2%，因为任务用右手抓杯柄）；PlugInEthernet 左手 96.6%、右手 90.0% 的 episode 出现 `gap>0.1`（双手分别抓网线/网口）。这是“夹到东西”的直接证据。
3. **EE 跟踪误差是互补的“环境接触”信号。** 做 2 帧滞后补偿、再按指令速度分桶归一化后，右手 EE 位置残差的 p95：HangCup 1.26cm vs PlugInEthernet 2.74cm；p99：2.0cm vs 7.1cm。插入/对准阶段明显更“顶”。但夹爪堵转与 EE 残差的相关性很弱（HangCup +0.10，PlugInEthernet −0.08），说明它们抓的是不同物理量：**夹爪堵转≈抓握接触，EE 残差≈环境阻力**，必须融合，不能二选一。

这组数字不是接触真值，只是伪标签试点；但它足以证明：**在没有任何触觉传感器的条件下，33k 演示里存在可挖的接触信号，而且必须先做滞后补偿和速度归一化。** 这本身就是一个可写的方法论点。

### 0.4 2026 的证据：触觉可以“离线学、在线不用”，但还没人在 32 任务通才赛上做“零硬件接触推理”

这一轮读到的 2026 论文，几乎把“无触觉部署”的可行性拆成了几条独立证据：

| 工作 | 时间 | 用了什么信号 | 部署时要触觉吗 | 关键结果 |
|---|---|---|---|---|

综合起来是三句话：

1. **接触信息确实值钱**：力/触觉在接触阶段能带来 10–40pp 的增益（DEFT-VLA、SimpleTouch、ILA、Visible Touch）。
2. **触觉可以不在推理时出现**：HapticVLA、MIM-VLA、AgenticTactileVLA、Blind Assembly 都证明了“训练时用、部署时不用”或“用本体/电机反馈替代”的可行性。
3. **但还没有一篇工作同时满足**：零额外硬件 + 无触觉训练数据 + 32 任务通才 + 5 个泛化轴 + 开环 chunk API。**这正是本轮的空白。**

### 0.5 三个灵感词，各自钉到本轮事实上

- **触觉感知** → 不是“再加一个触觉传感器”，而是**把接触当成一个可推断的物理状态**：接触存在、相位、稳定性、是否插到位、是否卡住。没有触觉硬件时，触觉感知退化为“接触推理”；这比“我们买不起触觉”更准确，也更有研究味道。
- **传感器融合** → 不是“多模态拼接”，而是**可靠性加权的融合**：双目在 1m 处深度误差 ~3cm、腕部在闭合时被遮挡、EE 残差在高速运动时被滞后主导、夹爪堵转只在稳态段可信。每个信号都有明确的失效条件，融合层必须知道“现在该信谁”。
- **论文发表** → 不是“赛后补一篇”，而是**用论文的 claim ladder 反向设计实验**：先证明接触状态可推断（离线），再证明它改善接触密集任务（下游），再证明它跨 5 轴泛化（挑战赛），最后给出与触觉上界的差距（诚实）。挑战赛的 32 任务/5 轴/真机评测，正好是论文最难得的 external validity。

### 0.6 本轮主判断

**挑战赛最贵的失败不是“抓不到”，而是“抓到了但接触没管好”：没夹稳、没对准、没插到位、没发现滑移、没在卡住时退回来。触觉硬件缺席并没有让这些信息消失，它把信息搬到了双目视差、腕部近景、夹爪堵转和 EE 跟踪误差里。把四个信号融合成 30Hz 接触状态，用它门控动作块、主动微探、接触触发恢复；先在 8 个接触密集任务上拿 +10pp，再把它写成“无触觉硬件的接触推理”论文。这是本轮最值得押注的方向。**

边界也要先说清楚：

- 不声称测量力的大小（没有标定就没有牛顿）；只声称接触状态/相位/稳定性/就位。
- 不声称替代触觉；透明、柔性、低力、静态接触会失效，要给出负结果和回退。
- 不新造一个 VLA；接触层挂在现有 PILOT-GPR/WLA 主干上，保持单模型。
- 不把占位榜当真实排名；所有下游收益以调试槽/计分跑为准。
- 外部数据/预训练/发表规则未读到（Feishu 需登录），默认保守。

## 1. 为什么接触状态是当前最锋利的切入点

### 1.1 失败模型：接触密集任务的“最后三厘米”

把最差任务按接触类型拆开：

| 任务 | 8 模型均值 | 接触难点 | 接触状态能做什么 |
|---|---:|---|---|
| Plug In Ethernet | 17.7% | 插头对准网口、插入到底、卡扣 | 先接触→慢速对准→到位停止；卡住→退回重试 |
| Unlock | 20.1% | 钥匙插入、转动、锁环翻转 | 插入到位检测；阻力突降=开锁；滑脱→重抓 |
| Open Pill Bottle | 22.7% | 瓶盖啮合、拧开 | 啮合检测；打滑→加压/重抓；拧开→停止 |
| Hang the Cup | 23.0% | 杯柄挂到钩上、释放 | 钩住检测；释放后稳定性校验；掉落→重挂 |
| Pick Out Battery | 23.3% | 夹取薄电池、避免夹到盒子 | 夹持接触 vs 盒壁接触区分；滑移→重夹 |
| Zip Up | 23.4% | 拉链啮合、拉合 | 啮合检测；空拉→回退重新啮合 |
| Organize Stationery | 22.5% | 多物体放入、合盖 | 放入到位；合盖阻力；掉落→重放 |
| Spell robot | 21.8% | 字母放置、板面接触 | 放置稳定；被碰倒→恢复 |

这些任务的共同点不是“力越大越好”，而是**在正确的时间知道“碰上了/夹住了/到位了/滑了/卡了”**。这正是接触状态的定义。

### 1.2 评分算术：接触状态同时影响成功闸门和步骤分

上一轮已经算过：32 个任务的终局步骤合计 1275/3200 = 39.8%，放置/插入/堆叠/闭合类步骤约 59.7%，且终局步骤是 32/32 任务的成功闸门 [S2]。接触状态对这两块都直接起作用：

```text
成功率 = P(所有步骤完成)                 # 接触失败 → 终局失败
步骤分 = Σ 步骤权重 × P(该步完成)        # 接触失败 → 当前步及后续步骤丢分
```

更关键的是**跨轴杠杆**：位置、干扰物、背景、未见物品、人为干扰五个轴里，接触物理不变；一个在背景轴换桌布后仍然成立的接触层，是**跨轴资产**，而不是单轴补丁。对比“再补一个背景数据集”，接触层的边际收益更高。

### 1.3 为什么不是“再做一个 VLA”

榜单头部已经是 MolmoAct2、WALL-OSS-0.5、DreamZero、Spirit-v1.5 这类强 VLA/世界模型；再训一个同构 VLA，边际创新很低，而且算力/数据不占优。接触状态是**表示层缺失**，不是**模型容量缺失**：

- 现有 VLA 的输入是 RGB + proprio + language；接触是隐变量，模型只能从像素里“猜”。
- 接触状态把隐变量显式化，给策略一个低维、可解释、可门控的信号。
- 它是**模型无关**的：可以挂在 WLA、π0.5、GR00T 上；论文的贡献不依赖某个底座。
- 它有**独立的评价指标**（接触 F1、预警提前量、校准），不只靠下游成功率讲故事。

### 1.4 论文的 claim ladder

论文不能一上来就说“我们解决了接触密集操作”。按可证伪性分四级：

| 级别 | claim | 实验 | 失败即回退 |
|---|---|---|---|
| C1 | 接触状态可从可用信号推断 | 离线帧级/事件级 F1、预警提前量、ECE | F1<0.65 → 只做异常检测 |
| C2 | 接触状态改善接触密集任务 | 8 任务 A/B，+10pp 目标 | <3pp → 回退到 SVL/异常预警 |
| C3 | 跨 5 轴泛化 | 位置/背景/干扰物/未见/人为 | 某轴回归 >2pp → 关闭该轴门控 |
| C4 | 接近触觉上界 | 仿真触觉/公开触觉数据对照 | 差距过大 → 诚实报告负结果 |

这个 ladder 让“论文发表”不是赛后装饰，而是**本轮实验设计的骨架**：每个组件都要能映射到 C1–C4 的一个可测命题。

## 2. 方案轮廓：PhantomTouch

```text
4×RGB（头双目 + 双腕）   关节/EE/夹爪   动作历史/相位
        │                    │              │
        ├─ 立体度量分支 ──────┤              │
        │  校正视差→深度→3D间隙/位姿         │
        ├─ 腕部近景分支 ──────┤              │
        │  夹爪/物体分割→光流→滑移/遮挡       │
        ├─ 本体分支 ──────────┤              │
        │  滞后补偿→速度归一化→EE残差/堵转    │
        └─ 动作分支 ──────────┘              │
                    │                        │
                    ▼                        ▼
        可靠性感知融合（可见度/信噪比/不确定度）
                    │
                    ▼
        接触状态：free / near / grasp / slip / seated / jam / dropped
         + 每指接触 + 相位 + 不确定度 + 128d contact token
                    │
        ┌───────────┼────────────┬─────────────┐
        ▼           ▼            ▼             ▼
   CGC 门控     AMP 主动微探   SVL+ 放置校验   NRB+ 接触恢复
   动作块速度    不确定时试探   释放后稳定性    滑/卡/掉触发
                    │
                    ▼
        GPR-VLA（唯一学习主干）：contact token 注入 action expert
```

一句话：**把“触觉”从一个传感器问题改写成一个状态估计问题；用双目/腕部/本体/动作四个弱信号，估计一个强状态；用这个状态去门控动作、主动试探、触发恢复。**

## 3. 数据与训练：从 33k 演示里“挖”接触

### 3.1 三步伪标签

```text
Step 1 滞后校准：对每个任务/机器人，用互相关估计 action→observation 的最优 lag（试点约 2 帧）
Step 2 稳态堵转：命令速度≈0 且持续 ≥3 帧时，gap = a_g - o_g；gap>0.1 → grasp_contact
Step 3 速度归一化残差：e = |o_ee(t+lag) - a_ee(t)|；按 |Δa_ee| 分桶取中位数；residual = e - median(e|speed)
        residual > τ_env → env_contact / insertion_resistance
```

再加上腕部光流：物体/夹爪的运动不一致 → slip；物体停止而夹爪继续 → 环境接触/卡住；释放后物体位移 → dropped。最后用 HMM/变点检测把帧级信号平滑成事件级相位，人工抽检 5% 校准阈值。

### 3.2 仿真特权教师 + 真实学生

- 在 Isaac Lab/MuJoCo 里用 G1 + Dex1 建 10–20 个接触密集任务，开接触力传感器；
- 教师看真实接触力/接触点/物体位姿，学生只看部署可得的 RGB/proprio/动作；
- 蒸馏教师的 contact token（不是力的大小），让学生在没有触觉的真实数据上也能预测；
- 仿真只用于**特权监督**，不把仿真图像当真实数据堆量；域随机化覆盖光照/背景/摩擦/物体尺寸。

### 3.3 自监督预训练

- 在 33k 演示上做 masked multimodal modeling：遮住一帧/一个模态，预测其 latent；
- 未来预测：从 t 前的视觉/本体预测 t+k 的 proprio/视觉变化，接触事件作为变化点；
- 跨模态对比：同一时刻的视觉/本体/动作互为正样本，不同时刻/任务为负样本；
- 用冻结的 WLA/DINOv2 视觉特征，只训接触头，控制算力。

### 3.4 避免循环与泄漏

- 伪标签来自动作-观测差，模型输入也含动作-观测差 → 容易“抄答案”；
- 解决：预测**未来**接触（t 前输入，t+1..t+3 标签）；跨任务留出；仿真/人工标签做外部验证；消融“去掉动作差输入”看是否还有增益。

## 5. 风险与合规（先立后破）

- **没有触觉真值**：接触状态是代理，不是力；用仿真/人工/公开数据三源校验，论文里明确“contact state, not force”.
- **透明/柔性/遮挡**：双目在透明物体上失效，腕部在闭合时被夹爪挡住；给出失效检测和回退（纯 SVL/异常预警）。
- **开环 chunk**：T_a 固定；接触反应受 133–533ms 限制；默认 T_a=4，接触段用保守速度，下一 chunk 再反应。
- **类别极不平衡**：接触帧只占 5–10%；用 focal loss/事件级采样/硬负例。
- **延迟**：6B VLA + 立体 + 接触头可能超 133ms；先做旁路轻量头，必要时蒸馏/ROI/降频。
- **外部数据/预训练/发表规则未读**：Feishu 需登录；默认只用官方数据+自采标签+仿真；邮件问询后再开。
- **单模型审计**：接触头属于唯一模型的一部分；确定性门控代码要披露；不引入第二个学习策略。
- **过度声称**：不写“触觉替代”；写“接触状态推理”；不写“通用接触理解”；写“本挑战赛 32 任务上的证据”。

## 1. 事实核对（本轮新增，全部一手；来源表见 §10）

### 1.1 传感器清单：接触信息从哪里来

| 观测 | 形状 | 直接给什么 | 接触用途 | 失效条件 |
|---|---|---|---|---|

| `lower_body` | 15 | 躯干/腿 | 稳定性、上身扰动 | 不是接触主信号 |
| `language` | str | 任务指令 | 相位/步骤先验 | episode 内不变 |

**没有**：tactile、force/torque、depth、joint velocity/torque、gripper current。

### 1.2 动作-观测差：被忽略的接触标签矿（本轮试点）

数据集同时保留**指令动作**和**实际状态**。这不是“图像-动作”数据集，而是“指令-响应”数据集。接触的物理签名就在两者的差里，但原始差被控制滞后和命令斜坡主导，必须做两步校正：

1. **滞后补偿**：互相关估计 action→observation 的最优 lag；试点中夹爪 lag 1–2 帧、手臂 lag 2–3 帧。
2. **稳态/速度归一化**：只在命令速度接近零时看夹爪堵转；只在相同指令速度桶内看 EE 残差。

试点（各一个 parquet 分片，非全量）：

| 任务 | 分片 episodes / frames | 稳态 `gap>0.1` 左 / 右 | 稳态 gap 中位数 左 / 右 | EE 残差 p95 左 / 右 | EE 残差 p99 左 / 右 |
|---|---:|---:|---:|---:|---:|
| HangCup | 324 / 63,999 | 1.2% / **51.9%** | 0.012 / **0.101** | 0.64cm / **1.26cm** | 1.25cm / **2.00cm** |
| PlugInEthernet | 291 / 111,462 | **96.6%** / **90.0%** | **0.132** / **0.119** | **1.50cm** / **2.74cm** | **4.76cm** / **7.06cm** |

定义：`gap = action_gripper - obs_gripper`；稳态 = 命令速度 <0.005 连续 ≥3 帧；EE 残差 = 2 帧滞后补偿后 `|obs_ee(t+2) - cmd_ee(t)|`，按指令速度分桶取中位数，`residual = error - median(error|speed)`，只统计速度 <1m/s 的帧。

三个结论：

- **夹爪堵转是干净的抓握接触信号**：HangCup 右手（抓杯柄）51.9% episode 出现稳态 gap>0.1；左手仅 1.2%（任务不用左手）。PlugInEthernet 双手都抓东西，90–97% episode 出现。
- **EE 残差是互补的环境接触信号**：PlugInEthernet 的 p95/p99 约为 HangCup 的 2–3.5 倍，符合“插入/对准更顶”的直觉。
- **两者相关性弱**（HangCup +0.10，PlugInEthernet −0.08）：一个测抓握，一个测环境阻力，必须融合。

**这是伪标签，不是接触真值。** 它的价值是证明信号存在、给出阈值/滞后/归一化的工程基线；真值要靠仿真特权教师 + 1k 人工标注 + 公开触觉数据对照。

### 1.3 双目标定与深度误差：头看全局，腕看最后三厘米

HangCup 的 `meta/info.json` 直接给出 `camera_params.head_stereo` [S4]：

```text
K_left  = [[282.369, 0, 311.525], [0, 282.752, 256.628], [0, 0, 1]]
K_right = [[281.874, 0, 329.958], [0, 282.319, 249.512], [0, 0, 1]]
R ≈ I (非对角 <0.008)
T = [-58.253, -0.168, 0.579] mm   # 基线 58.25mm
rectified = true
```

深度误差近似 `σ_Z = Z² / (f·b) · σ_d`，取 `f=282.4`、`b=0.05825m`、视差噪声 `σ_d=0.5px`（乐观下界）：

| 距离 Z | σ_Z（0.5px） | 用途 |
|---:|---:|---|
| 0.3m | 2.7mm | 近距对准/间隙 |
| 0.5m | 7.6mm | 抓取/放置接近 |
| 0.8m | 19.5mm | 粗略位姿 |
| 1.0m | 30.4mm | 全局场景，不够插入 |
| 1.5m | 68.4mm | 只能做语义/区域 |

结论：**头双目适合 0.3–0.5m 的度量接近与物体/容器位姿；最后厘米级插入必须靠腕部近景 + 主动微探 + 接触状态，而不是头双目深度。** 这直接决定了多尺度融合架构。

腕部彩色内参也在 meta 里（`wrist_left.color.camera_matrix` fx≈436.4、fy≈435.9、cx≈323.9、cy≈242.9），但**没有腕部到 EE 的外参** [S4]。需要：
- 从 G1 URDF/CAD 或手眼标定获得；或
- 先用图像空间伺服（不依赖度量外参），把腕部当“接触面观察器”，头双目当“全局度量器”；
- 调试槽里用标定板/已知物体做一次手眼标定，误差目标 <5mm/2°。

## 2. 问题定义：接触状态、可观测性与评价

### 2.1 接触状态 taxonomy

不做“力的大小回归”，做**离散状态 + 不确定度**，因为无触觉硬件时力不可标定，而状态可验证：

| 状态 | 定义 | 主要证据 | 下游动作 |
|---|---|---|---|
| `free` | 夹爪/物体与环境无接触 | 双目间隙 >阈值；EE 残差低；夹爪空闭 | 正常速度 |
| `near` | 预接触，间隙 <2–3cm | 双目/腕部间隙缩小；视觉接近 | 减速、准备伺服 |
| `grasp_contact` | 夹爪接触物体，尚未确认稳定 | 稳态夹爪堵转；腕部接触面 | 停止闭合、轻提验证 |
| `grasp_stable` | 物体随夹爪运动，无滑移 | 物体/夹爪光流一致；轻提后仍一致 | 可搬运 |
| `slip` | 物体相对夹爪运动 | 腕部光流不一致；物体位姿跳变 | 加压/重抓 |
| `env_contact` | 物体/夹爪接触环境（插入/放置） | EE 残差；物体停止而夹爪继续；视觉接触 | 慢速、对准、微探 |
| `seated` | 插入到底/放置稳定 | 残差突降/停止；视觉到位；释放后不动 | 停止推、释放 |
| `jam` | 卡住/过力/楔形 | 残差持续高；物体不动；夹爪堵转 | 退回、重对准 |
| `dropped` | 物体丢失 | 释放后物体位移；夹爪空；视觉掉落 | 重抓/恢复 |

每指接触是独立二值；`grasp_stable`/`slip` 是物体级；`seated`/`jam` 是任务级。输出还包括 `uncertainty`（evidential/ensemble）和 `contact_token`（128d）。

### 2.2 可观测性：什么时候接触“看得见”

把接触写成隐变量 `c_t`，可用观测 `o_t`（四路 RGB、proprio、动作历史）估计 `p(c_t | o_{≤t}, a_{<t})`。接触要可观测，至少需要一个签名：

1. **运动受阻**：夹爪命令继续、实际开度停住；EE 命令继续、实际位姿落后。
2. **视觉运动不一致**：夹爪/物体在动，接触面/环境不动；或物体相对夹爪滑。
3. **几何间隙闭合**：双目/腕部看到接触面距离→0。
4. **外观变化**：遮挡、变形、压痕、反光变化。

失效条件：
- 透明/反光物体：双目视差失败，腕部外观线索弱；
- 柔性物体：变形但无力突变，接触状态模糊；
- 静态轻接触：无运动激励，EE 残差小；
- 夹爪闭合遮挡：腕部看不到接触面；
- 高速运动：滞后误差主导，残差信噪比低。

**主动微探**就是为这些失效条件设计的：注入一个已知的小运动，让“接触”产生可观测的响应（物体是否随动、阻力是否突变、是否到位）。这把“被动看”变成“主动问”。

### 2.3 评价指标

| 层级 | 指标 | 目标 |
|---|---|---|
| 帧级 | macro-F1、每类 recall、混淆矩阵 | ≥0.75 |
| 事件级 | 事件召回/精确率（±3 帧容差）、预警提前量 | 召回 ≥0.80；提前 ≥3 帧 |
| 校准 | ECE、Brier、选择性风险 | ECE ≤0.10 |
| 下游 | 成功率、步骤分、接触子集增益、非接触回归 | +10pp / +3–5pp / ≤2pp |
| 系统 | `get_action` p50/p99、接触头延迟、chunk 反应延迟 | p99 <100ms（目标） |
| 主动 | 每次 probe 的增益、probe 次数/任务 | ≥5pp 歧义集；≤2 次/步 |

### 2.4 不声称什么

- 不声称测量牛顿/力矩；没有标定就没有力。
- 不声称替代触觉；透明/柔性/遮挡会失效，要报告负结果。
- 不声称通用接触理解；只声称本挑战赛 32 任务 + 仿真/公开数据上的证据。
- 不声称新 VLA；接触层是模型无关的表示/控制增强。
- 不依赖占位榜排名；所有收益以调试槽/计分跑/离线真值为准。

### 3.2 四个信号分支

#### 3.2.1 立体度量分支

- 输入：`head_stereo_left/right` 原始 480×640；已校正，直接做 SGBM/RAFT-Stereo/Fast-FoundationStereo [S28][S29]。
- ROI：以夹爪/目标检测框为中心裁剪（例如 256×256），只对接触相关区域做深度；背景不重建。
- 输出：
  - 夹爪两指到物体表面的最近距离 `d_gap`；
  - 物体/容器 6D 位姿（关键点 PnP 或 foundation pose）；
  - 插入轴对齐误差 `e_align`（角度 + 横向偏移）；
  - 深度置信度（有效视差比例、左右一致性）。
- 频率：10–15Hz（不必 30Hz）；只在 `near`/`env_contact` 阶段开；free 阶段降频。
- 失效检测：有效视差 <30%、左右重投影误差 >2px、透明/反光 → 降权/关闭。

#### 3.2.2 腕部近景分支

- 输入：`wrist_left/right` 480×640；ROI 在夹爪两指与物体之间。
- 特征：
  - 夹爪指面/物体分割（SAM2 或轻量分割）；
  - 光流（RAFT/稀疏 Lucas-Kanade）比较物体流 vs 夹爪流 → `slip_score`；
  - 间隙/遮挡/变形外观；
  - 释放后物体位移（帧差/光流）→ `drop_score`。
- 输出：`slip_score`、`contact_visual`、`seated_visual`、`occlusion_flag`。
- 频率：15–30Hz（光流可 10Hz + 插值）。
- 失效检测：夹爪遮挡 >50%、运动模糊、低纹理 → 降权。

#### 3.2.3 本体/跟踪误差分支

- 输入：关节位置、EE 位姿、夹爪开度、动作历史；`obs_delta_indices` 提供 0.2–0.5s 堆叠。
- 预处理：
  1. 估计并补偿 action→observation lag（在线互相关/固定校准）；
  2. 计算关节/EE 跟踪误差 `e_q`、`e_x`；
  3. 按指令速度分桶归一化：`r_x = |e_x| - median(|e_x| | speed)`；
  4. 夹爪稳态堵转 `gap = a_g - o_g`（命令速度≈0 时）；
  5. 差分得到速度/加加速度；低通滤波。
- 输出：`grasp_stall`、`env_residual`、`motion_energy`、`jerk`。
- 失效检测：高速（>1m/s）残差被滞后主导；关节角缠绕；控制器刚度变化 → 降权。

#### 3.2.4 动作/相位分支

- 输入：当前 SSG 步骤、动作 chunk、命令历史、probe 历史。
- 作用：**同样的观测在不同动作下含义不同**。例如夹爪开度 0.3 在“正在闭合”时可能是接触，在“保持打开”时不是；EE 残差在“主动推”时是接触，在“自由运动”时是滞后。
- 输出：`phase_prior`（approach/contact/insert/release）、`expected_contact`、`probe_flag`。
- 实现：SSG 步骤 one-hot + 命令统计 + 小 MLP；不需要大模型。

### 3.3 可靠性感知融合（RAF）

不是简单 concat，而是“每个模态先自评，再互评”：

```text
r_i = reliability_i(visibility, SNR, calibration, OOD)
h_i = encoder_i(x_i)
z   = CrossAttention(query=learned, keys=h_i, values=h_i, bias=log r_i)
c   = TemporalTransformer(z_{t-k:t})        # 0.5–1.5s
logits = heads(c)                            # contact/phase/slip/seated/jam
u   = evidential_uncertainty(logits)
```

- **可靠性输入**：双目有效视差比例、腕部遮挡比例、EE 速度、夹爪命令速度、视觉 OOD 分数、历史一致性。
- **融合方式**：early cross-attention + late gating；每个模态一个 expert，门控网络按可靠性加权；训练时 modality dropout（随机丢一路），避免推理时单路失效崩溃。
- **不确定性**：evidential head（Dirichlet）或 3-model ensemble；温度标定；`u > τ_probe` 触发 AMP。
- **时序**：因果 TCN/Transformer，窗口 0.5–1.5s；30Hz 输入，10–15Hz 视觉特征 + 30Hz proprio；状态平滑用滞回（hysteresis）避免抖动。
- **输出**：每类 logit、每指接触、`contact_token` 128d、`u`。

### 3.4 接触门控动作块（CGC）

**问题**：API 的 chunk 开环执行，接触反应延迟 = T_a/30s；T_a 固定。大 chunk 适合大 VLA，小 chunk 适合接触闭环。

| T_a | 反应延迟 | 30Hz 下等效重规划率 | 适用 | 风险 |
|---:|---:|---:|---|---|
| 1 | 33ms | 30Hz | 高精度插入 | 6B 模型推理可能更不上 |
| 2 | 67ms | 15Hz | 接触密集 | 推理压力大 |
| 4 | 133ms | 7.5Hz | **默认** | 可接受，需 <133ms 推理 |
| 8 | 267ms | 3.75Hz | 自由空间/长程 | 接触反应慢 |
| 16 | 533ms | 1.9Hz | 纯 VLA 基线 | 接触不可控 |

CGC 的做法：

1. **默认 T_a=4**；如果推理 p99 >100ms，退 T_a=8 并降低接触段速度。
2. **速度门控**：`free` 100%、`near` 50%、`grasp_contact` 20%、`env_contact` 10–20%、`seated` 0、`jam` 反向小步。
3. **chunk 形状**：在接触段生成“减速到零”的保守 chunk（即使开环，也不会猛冲）；下一 chunk 再根据新接触状态修正。
4. **不能早停**：evaluator 执行完整 chunk；不要假设可以在 chunk 中间打断。所有“接触即停”必须靠下一 chunk 或低层柔顺。
5. **低层柔顺**：如果 API/控制器支持阻抗/力矩限制，接触段用低刚度；如果不支持，用位置小步 + 速度限制。
6. **延迟预算**：视觉编码 20–30ms + 接触头 5–10ms + VLA 60–90ms + 通信 5–10ms ≈ 100–140ms；T_a=4 刚好卡线，需要实测/蒸馏/ROI。

### 3.5 主动微探（AMP）

触发条件：
- `u > τ_probe`（接触状态不确定）；
- `expected_contact` 但 `grasp_contact` 未出现（可能没夹到/物体太薄）；
- `env_contact` 持续但 `seated` 未出现（可能没对准/卡住）；
- `slip` 与 `grasp_stable` 置信度接近。

探针库（每个 0.2–0.5s，力度/位移限幅）：

| 探针 | 动作 | 观测 | 判定 |
|---|---|---|---|
| 微推 | 沿插入轴 +1–2mm | EE 残差、物体位移 | 阻力突增→接触；物体随动→未到位 |
| 微提 | 垂直 +1–2mm | 物体是否随夹爪 | 随动→夹稳；不随→滑/未夹 |
| 微摆 | 绕插入轴 ±1° | 横向力/视觉间隙 | 有间隙→对准；卡住→jam |
| 慢插 | 1mm 步进 | 残差/视觉/声音（无） | 残差降→seated；升→jam |
| 释放测试 | 开爪 1–2mm 再合 | 物体位移 | 位移→重抓；不动→稳定 |

策略：`argmax_a I(c; o | a)` 的近似——选最能区分两个候选状态的探针；规则版用决策树，学习版用小型策略。预算 ≤2 次/步，总时长受 Endurance Governor 约束。

### 3.6 与 PILOT-GPR 的接线

| 旧组件 | 新接线 |
|---|---|
| SSG | 每个评分步骤增加 `expected_contact`/`contact_phase` 谓词；步骤完成需接触状态匹配（例如“插入”需 `seated`） |
| PGL | 放置目标阶梯增加“接触面”层级：槽位→锚点→6D 位姿→接触面法向/插入轴 |
| OPT | 位姿迁移增加“插入前姿态”和“接触后微调”；用演示的接触段统计 τ |
| ICR | 检索键增加 contact phase/contact state；检索值增加接触段动作先验 |
| SVL | `stable` 从“位移<ε”升级为“位移<ε 且 contact state=seated/grasp_stable 且无 slip” |
| NRB | 触发从“谓词 1→0”扩展为“slip/jam/dropped”；恢复动作库增加退回/重对准/重抓 |
| AH-TP | 接触段时长监督；避免“碰一下就退”或“一直顶” |
| Endurance | probe/重试预算；180s 总时长守卫 |

```python
def contact_aware_place(step, obs, plan, budget=2):
    for attempt in range(budget + 1):
        # 1. 先看接触状态，决定接近方式
        c = cse(obs, action_history, phase=step)
        if c.state in ("free", "near"):
            speed = 0.5 if c.state == "near" else 1.0
            chunk = policy.act(obs, plan, contact=c, speed=speed)
        elif c.state == "grasp_contact":
            chunk = policy.act(obs, plan, contact=c, speed=0.2)
        elif c.state == "env_contact":
            chunk = policy.act(obs, plan, contact=c, speed=0.1)
        elif c.state == "seated":
            open_gripper(slow=True)
            if stable_after_release(obs, window=0.5):
                return True
            else:
                plan = revise(plan, obs, reason="drop")
                continue
        elif c.state == "jam":
            retreat(2.0)             # 2mm back-off
            plan = realign(plan, obs)
            continue

        send(chunk)

        # 2. 不确定 → 主动微探（在下一个 chunk 前）
        if c.uncertainty > TAU_PROBE:
            probe = select_probe(c, step)
            obs2 = execute_probe(probe)   # 0.2–0.5s
            c = cse(obs2, action_history, phase=step)
            if c.state == "seated":
                open_gripper(slow=True)
                if stable_after_release(obs2, window=0.5):
                    return True
    return False
```

## 4. 数据引擎：从 33k 演示里“挖”接触

### 4.1 伪标签流水线

```text
[1] 读 parquet（action + observation + episode/frame）
[2] 估计 lag：互相关/最小 MAE；按任务/机器人分组
[3] 夹爪：稳态段 gap = a_g - o_g；gap>0.1 且持续 ≥3 帧 → grasp_contact
[4] EE：e = |o_ee(t+lag) - a_ee(t)|；按 |Δa_ee| 分桶；residual = e - median(e|speed)
       residual > τ_env 且速度 <1m/s → env_contact
[5] 腕部：物体/夹爪光流；|flow_obj - flow_grip| > τ_slip → slip
       物体停止而夹爪继续 → env_contact/jam
       释放后位移 > τ_drop → dropped
[6] 事件平滑：HMM/变点检测；滞回阈值；最短事件长度 2 帧
[7] 人工抽检 5%（1k clips）；计算标注一致性；校准 τ
[8] 写回：帧级 + 事件级标签；训练/验证/测试按 episode 划分
```

阈值初值（需在验证集校准）：

| 信号 | 初值 | 说明 |
|---|---:|---|
| 夹爪稳态 gap | 0.1（开度单位） | HangCup 右手中位 0.101；PlugInEthernet 0.119–0.132 |
| 夹爪命令稳态 | |Δa_g| <0.005 连续 3 帧 | 避开斜坡滞后 |
| EE 残差 τ_env | p95（按任务） | HangCup ~1.3cm；PlugInEthernet ~2.7cm |
| 滑移 τ_slip | 2–3px/帧 | 腕部光流差；按物体尺度归一 |
| 掉落 τ_drop | 5mm/0.5s | 释放后物体位移 |

### 4.2 仿真特权教师

- 平台：Isaac Lab / MuJoCo；G1 + Dex1 模型；10–20 个接触密集任务（插头/网口、钥匙/锁、瓶盖、杯柄/钩、电池/盒、拉链、笔盒、叠碗）。
- 特权信号：接触力/接触点/物体位姿/摩擦/间隙；教师用这些信号训练（或直接作为 label）。
- 学生输入：渲染 RGB（四路）+ proprio + 动作；**不输入力/接触**。
- 蒸馏目标：
  - 教师的 contact token（128d）→ 学生回归/对比；
  - 教师的 contact state logits → 学生 CE；
  - 教师的未来接触预测 → 学生多 horizon 预测。
- 域随机化：光照、背景、桌面高度、摩擦、物体尺寸/颜色、相机噪声；避免学生学“仿真纹理”。
- 仿真只做特权监督，不把仿真图像当真实数据堆量；用 GF 软权重控制合成比例。

### 4.3 自监督预训练

- **掩码多模态建模**：随机遮住一帧/一路相机/一段 proprio，预测 latent；迫使模型学跨模态结构。
- **未来预测**：从 t 前 0.5s 预测 t+1..t+3 的 proprio/视觉 latent；接触事件是变化点。
- **跨模态对比**：同一时刻的视觉/本体/动作互为正样本；不同时刻/任务为负样本。
- **接触事件预测**：用伪标签做辅助 BCE，但**输入只看 t 前**，避免抄答案。
- 实现：冻结 WLA/DINOv2 视觉特征；训练 10–30M 接触头；500k 帧子集；8×H100 约 2–3 天。

### 4.4 人工标注与 UniBot-Contact

- 抽样：8 个接触密集任务 × 125 clips ≈ 1,000 clips；每 clip 2–5s。
- 标注：接触存在（每指）、phase、slip、seated、jam、dropped；事件起止帧；不确定度。
- 一致性：3 名标注者；Cohen's κ ≥0.8；分歧仲裁。
- 发布：`UniBot-Contact` 子集（标签 + 校准 + 划分 + 说明），Apache-2.0，附引用；不发布原始视频（原始数据已有 HF 链接）。
- 用途：离线评测、论文基准、社区复用；不进入提交训练（避免“自己标自己测”）。

### 4.5 避免循环/泄漏

| 风险 | 解决 |
|---|---|
| 伪标签来自动作-观测差，模型输入也含动作-观测差 | 预测未来；跨任务留出；消融去掉动作差 |
| 同一 episode 的相邻帧泄漏 | 按 episode 划分；时间切分 |
| 仿真教师信息泄漏到学生 | 学生输入严格裁剪；蒸馏只给 token/logits |
| 人工标注被用于调阈值又被用于测试 | 标注分 train/val/test；测试集冻结 |
| 任务/物体重叠 | 按任务/物体分组划分；报告跨任务结果 |

### 5.2 下游挑战赛

| 条件 | 策略 | 任务 | trials | 主要指标 |
|---|---|---|---:|---|
| A | PILOT-GPR 基线（无 CSE） | 32 | 10/任务 | 成功率/步骤分 |
| B | +CSE（只门控，不重训） | 32 | 10/任务 | 同上 |

- 统计：320 trials/条件，SE≈2.5pp；接触子集 80–160 trials，SE≈4–5.5pp；配对初始条件 + bootstrap 95% CI。
- 目标：C 相对 A，接触子集 +10pp（保守 +5pp），整体 +3–5pp，非接触回归 ≤2pp。
- 调试槽优先级：T26 Plug In Ethernet → T10 Plug Charger → T12 Unlock → T19 Zip Up → T01 HangCup → T14 PourOutMedicine。
- 计分跑：中期 1 次、终期 1 次；若只允许 1 次，终期唯一一次。

### 5.3 消融

| 消融 | 变量 | 预期 |
|---|---|---|
| 信号 | 去双目 / 去腕部 / 去 proprio / 去动作 | 每路都有贡献；双目对对准最大，腕部对滑移最大，proprio 对抓握最大 |
| 融合 | concat vs cross-attn vs reliability | reliability 在遮挡/高速下更稳 |
| 时序 | 窗口 0.2/0.5/1.0/1.5s | 0.5–1.0s 最佳 |
| CGC | T_a=2/4/8；速度门控 on/off | T_a=4 + 门控最佳 |
| AMP | on/off；预算 0/1/2 | +5pp 歧义集；预算 2 上限 |
| 标签 | 伪标签 vs 人工 vs 仿真 | 仿真+人工最佳；伪标签可扩展 |
| 不确定度 | 无/evidential/ensemble | 校准更好，probe 更准 |

### 5.4 5 轴泛化

| 轴 | 测试 | 接触层关注 |
|---|---|---|
| 位置 | 物体/容器平移 | 双目/腕部相对几何；不应依赖绝对坐标 |
| 干扰物 | 路径旁物体 | 接触状态应区分目标/干扰物 |
| 背景 | 桌布/光照 | 视觉特征应抗外观；接触物理不变 |
| 未见物品 | 新物体 | 接触状态应跨物体；报告失败 |
| 人为干扰 | 中途移动/撤销 | slip/dropped/恢复触发 |

指标：每轴接触 F1、下游成功率、相对基线的回归；某轴回归 >2pp → 关闭该轴门控。

### 5.5 触觉上界

三种对照（按合规性排序）：

1. **仿真触觉**：同一任务，教师用真实接触力，学生用可用信号；比较 contact F1 与下游成功率。
2. **公开触觉数据**：UniVTAC/NeoData 等（若规则允许）训练触觉教师，蒸馏到我们的学生；只用于论文对照，不并入提交。
3. **硬件上界**：Dex3-1 或外接触觉夹爪（若实验室有）；单独实验台，不上挑战赛。

目的不是“打败触觉”，而是回答：**无触觉接触推理离触觉上界有多远？在哪些任务上接近、哪些差？**

### 5.6 负结果与失效分析

- 透明物体（试管、瓶子）：双目失效，腕部反光；报告 F1 下降与回退。
- 柔性物体（毛巾、拉链）：接触状态模糊，力小；报告“状态不可辨识”。
- 夹爪遮挡：腕部看不到接触面；报告遮挡比例与性能。
- 静态轻接触：无运动激励；主动微探的增益。
- 高速运动：滞后主导；速度门控/降速的收益。
- 这些负结果不是失败，是论文“诚实边界”的一部分。

## 6. 论文计划

### 6.1 标题、摘要、贡献

**标题**：*PhantomTouch: Learning Contact-State Representations from Vision, Proprioception, and Action Tracking for Tactile-Free Manipulation.*

**摘要骨架**：接触密集操作通常依赖触觉/力传感器；但许多机器人（包括本挑战赛的 G1 + Dex1）没有这些传感器。我们证明，接触状态可以从部署时已有的信号中推断：已校正双目、腕部近景、关节/EE 跟踪误差、夹爪堵转，以及机器人自己的动作历史。我们提出 PhantomTouch：一个可靠性感知的多模态时序模型，学习接触状态（free/near/grasp/slip/seated/jam/dropped）与 128d contact token；token 注入 VLA 动作专家，门控动作块，并在不确定时主动微探。我们在 32 任务通才赛的 8 个接触密集任务上评估，报告 +Xpp 成功率；在仿真/公开触觉数据上给出与触觉上界的差距；并分析透明/柔性/遮挡下的失效条件。

**贡献**：

1. **问题与基准**：无触觉机器人的接触状态 taxonomy、可观测性条件、UniBot-Contact 标注子集与评价协议。
2. **方法**：可靠性感知的双目/腕部/本体/动作融合 + contact token + 主动微探；模型无关，可挂任意 VLA。
3. **真实结果**：32 任务通才赛接触密集子集增益、5 轴泛化、开环 chunk 延迟分析。
4. **诚实边界**：透明/柔性/遮挡/低力负结果，与触觉上界的差距。

| “占位榜不可信” | 不依赖排名；调试槽/计分跑；CI；预注册 |
| “安全/过力” | 位置小步 + 速度限制 + 探针限幅；不回归力；jam 退回 |
| “透明/柔性失败” | 明确负结果与回退；这是贡献的一部分 |

### 6.4 数据、代码、署名、合规

- 数据：官方 33k Apache-2.0；衍生标签/校准以 Apache-2.0 发布；不重分发原始视频，只给 HF 链接。
- 代码：训练/评测/标注工具赛后开源；提交权重按主办方规则。
- 署名：团队 + 合作者；CRediT；避免挂名；数据标注者致谢。
- 伦理：无个人数据；遥操作数据已脱敏；不训练人脸/语音。
- 合规：外部数据默认 OFF；论文/预印本先问；单模型审计披露接触头与确定性门控。

## 8. 创新点清单更新（持续迭代；动机/差异/可行性/资源/步骤/风险/状态）

> 状态：押注=本轮主线；保留=沿用；升级=旧点改造；降级=保留但非主回路；砍=不做。

### I14 PhantomTouch CSE 接触状态估计（新增，押注）
- 动机：API 无触觉，但最差任务都是接触密集；接触是隐变量，显式化后可直接门控。
- 差异：多阶段状态（free/near/grasp/slip/seated/jam/dropped）+ 每指 + 不确定度；不是二值接触检测。
- 可行性：四路信号 API 可得；试点已证明夹爪堵转/EE 残差可分离；轻量头可 30Hz。
- 资源：1k 人工标注 + 500k 帧自监督；8×H100 2–3 天；1 人 2 周。
- 步骤：滞后校准→伪标签→CSE v0→融合→门控→真机 A/B。
- 风险：透明/柔性失效；伪标签噪声；类别不平衡。→ 分桶回退 + 人工/仿真校验 + focal loss。

### I15 RAF 可靠性感知融合（新增，押注）
- 动机：双目在 1m 外误差 3cm、腕部被夹爪遮挡、EE 残差在高速时被滞后主导；简单 concat 会被最差模态拖垮。
- 差异：每模态自评 + 互评 + modality dropout + evidential 不确定度；按阶段门控。
- 可行性：可靠性特征都是现成统计量；cross-attention 轻量。
- 资源：与 CSE 同训练；无额外数据。
- 步骤：可靠性特征→cross-attn→dropout→校准→消融。
- 风险：可靠性估计本身出错；用合成遮挡/噪声训练 + 温度校准。

### I16 CGC 接触门控动作块（新增，押注）
- 动机：API chunk 开环，接触反应延迟 = T_a/30s；大 VLA 与小 chunk 矛盾。
- 差异：不是改 API，而是按接触状态设计 chunk 速度/形状；给出 T_a 延迟表与默认 4。
- 可行性：只改策略输出/控制层；不改 evaluator。
- 资源：延迟压测；无训练。
- 步骤：T_a 选择→速度门控→chunk 形状→低层柔顺→压测。
- 风险：T_a=4 推理超时；退 T_a=8 + 降速/蒸馏。

### I17 AMP 主动微探（新增，押注）
- 动机：静态轻接触/遮挡/透明下被动观测不可辨识；主动注入激励可让接触“可见”。
- 差异：把接触推理从被动分类变成主动感知；探针库 + 不确定度触发 + 预算。
- 可行性：微推/微提/微摆都在 API 动作空间内；0.2–0.5s/次。
- 资源：无额外数据；调试槽验证。
- 步骤：探针库→触发规则→观测响应→决策树→学习版。
- 风险：探针本身导致掉落/卡住；限幅/预算/安全守卫。

### I18 UniBot-Contact 标注子集（新增，论文资产）
- 动机：没有公开的接触状态标签；论文需要可复现基准。
- 差异：32 任务中的 8 个接触密集任务、1k clips、帧级+事件级、Apache-2.0。
- 可行性：伪标签 + 人工抽检；已有数据；标注成本可控。
- 资源：3 名标注者 × 2 周；仲裁。
- 步骤：抽样→标注手册→双盲标注→κ→发布→基准。
- 风险：标注主观性；用 κ/仲裁/负结果缓解。

### I19 论文计划（新增，流程）
- 动机：把“论文发表”从赛后装饰变成实验设计骨架。
- 差异：claim ladder C1–C4 + 目标会议 + 审稿人问题 + fallback。

- 风险：规则不允许/结果不足；fallback 到 benchmark/负结果。
