### 第 6 轮灵感驱动研究记录

**灵感词**：协同控制、参数高效微调

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）把提议从离散规则升级为条件流匹配（FMPP）、记忆升级为嵌入+固化（LMEM-v2）、人因升级为面部情感调制（FAMK），确立「任意生成器 + 认证边界」（CGE）与执行集嵌套 Exec_v5 ⊆ Exec_v4 ⊆ … ⊆ Exec_v29，并诚实标注最大风险 R57（固化自指博弈回路）。本轮两个灵感词恰好从两个方向正面拆解 R57，而不新增硬门：(a) **参数高效微调**把「全参数固化」替换为「低秩可插拔适配器」，让固化漂移第一次有显式、可计算的上界，并支持隔离/回滚/热插拔（把 R57 的「不可根除」降为「不可根除但可隔离」）；(b) **协同控制**把「单站自我铸证」升级为「多站交叉共证」，用异构验证者的法定人数（quorum）共识打断单智能体的自指回路。主题定为「协同认证的参数高效执行」（Cooperatively-Certified Parameter-Efficient Execution, CCPE），形成 CADVS-v6（IP-497~500）。自律不变：**硬门仍为七门**，执行集嵌套升级为 Exec_v6 ⊆ Exec_v5 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **参数高效微调 → 固化从「整模型重训」变成「低秩可插拔补丁」，漂移第一次有了显式上界**。v5 的固化 C_cons 只给出抽象的 KL(π_new‖π_old) ≤ ε_KL 约束——定理 7 的 (C2) 是**假设**，不是**构造**。改用低秩适配器 Δv_φ(x,t|c)（对每个线性层 W → W + BA，rank r ≪ d），冻结基座 v_{θ0} 只训练 φ：固化漂移现在由 ‖φ‖ 直接控制——速度场扰动经 Grönwall 放大后给出 W_2 上界（引理 45 / 定理 9），于是 ε_KL 从「事后检验」变成「训练时投影约束」。更关键的工程后果：适配器可**热插拔、按站/任务路由、出问题直接拔掉精确回退基座**（定理 11），把 R57 的「只能缓解不能根除」改写为「不能根除但可隔离 + 可回滚 + 漂移有界」。联邦只传适配器（MB 级而非 GB 级），通信开销大降（偿还 v5 的通信假设）。

2. **协同控制 → 单站自我铸证升级为多站交叉共证，用异构 quorum 打断自指**。R57 的病灶是「自己给自己发证」：策略在自己的铸证片段上学习，又只被自己的门检验，闭环里没有外部真值。协同控制给出结构性解法：一条候选轨迹的证书必须由 N 个**异构验证站**（不同几何标定/价值模型/本地适配器）中的至少 q 个独立共签，才算「协同认证」。只要诚实验证者存在、且 q 大于「可被博弈数 f + 诚实门洞重合度 d」，单个被自指回路污染的验证者无法独自凑出 quorum（定理 10）。异构性由 PEFT 提供：每站一个不同的低秩适配器 ⇒ 提议分布天然去相关；但**真正的安全保障来自门校准的异构**——不同站的门洞（假阴性区域）不重合，单站学会的博弈样本会被其他站的门拦下。这里必须诚实：若验证者共享同一基座、同一门代码、同一标定源，门洞高度相关（d 增大），quorum 只是「相关误差的多数表决」，会产生**虚假独立性**——这是本轮最大风险（R60）。

3. **协同控制（第二层）→ 现有多智能体安全工具（协同 CBF）并入既有物理门，不新增锚**。协同控制的标准安全证书是控制障碍函数（CBF）。把多机避碰/队形保持写成联合状态上的协同 CBF，作为既有「物理门」在多机域上的扩展（不是第八个门）。这样舰队的联合执行集仍是七门交集，只是物理门的定义域从单机轨迹扩到联合轨迹；完备性（v4 定理 4）不变（定理 12）。人机共享控制则落为「人类作为保守锚验证者」——一个 veto 优先、门族不同的特殊验证者，天然提供去相关检查。

**关键洞见**：v5 回答「提议任意化后证书边界如何不变」；v6 回答「当固化会自指博弈、且系统从单站走向舰队时，如何让证书边界不仅不变、还可隔离、可交叉验证」。七硬门 kc_evidence_forged_v4 原样复用；v6 只改两处非门机制：(a) 提议/记忆固化改走低秩适配器 Δv_φ（隔离 + 有界漂移）；(b) 准入增加一层**协同共证过滤器**（与本地 v5 门取交，只紧不松）。软评分 ECS_v6 = ECS_v5 · η_coop · η_adapt，其中 η_coop 反映 quorum 裕度、η_adapt 反映适配器漂移裕度。执行集 Exec_v6 = Exec_v5^{local} ∩ {协同 quorum 通过} ⊆ Exec_v5。

**形式化目标（增量）**：
1. 低秩适配器：v_θ(x,t|c) = v_{θ0}(x,t|c) + Σ_j w_j(x,c)·Δv_{φ_j}(x,t|c)，Δv_{φ_j} 由 LoRA 型 (B_jA_j) 实现，rank r，‖φ_j‖_F ≤ ρ_max；路由 w 取 top-1（硬路由）以避免适配器互相干扰。
2. 固化算子 C_cons^LR：只更新 φ，冻结 θ0 与全部门/τ^4；损失 L_FM + λ_rank‖φ‖² + KL(π_new‖π_old)；训练后用 W_2 证书（引理 45）验收，超界则投影回 ρ_max。
3. 协同共证：N 个验证者，每者本地门族 G_j（七门，异构标定）；候选 x 的协同证书 CC(x)=1[ |{j : ∧_i kc_i^{(j)}(x)=1}| ≥ q ]；人类锚验证者 veto 优先。
4. 定理 9（低秩固化漂移界 / ε_KL 构造化）、定理 10（协同共证健全性与自指打断）、定理 11（适配器隔离/回滚精确性）、定理 12（七锚完备性在协同/适配下保持）。
5. EFA-v6：本地 v5 级联 → 协同共证过滤器（异步、秒级）→ 取 quorum 裕度与边际联合最大者；控制环只消费已共签的缓存证书。
6. Exec_v6 = Exec_v5^{local} ∩ {x : CC(x)=1} ⊆ Exec_v5。

**本轮最大风险**：**协同共证的虚假独立性（common-mode 验证者失效）**——若各站共享同一基座、同一门代码与同一标定源，门洞高度相关（d 增大），quorum 退化为「相关误差的多数表决」，自指回路只是被分布式化而非被打断，反而因「看起来有多方背书」而制造更强的虚假安全感；PEFT 去相关与门族异构只能降低相关性，无法保证独立。

```python
    v5: EvidenceForgingAssemblerV5
    lrca: LowRankCertifiedAdapter
    ccck: CooperativeCertificateConsensusKernel
    cse: CooperativeSafetyEnvelope | None = None

    def select(self, x0_state, t_now, rule_id, context) -> tuple[bool, Trajectory | None, str]:
        adapter_id = self.lrca.router(context.site, context.task)   # top-1
        # 第 0 层：本地 v5 级联（含 FAMK γ、LMEM、FMPP、VACK、BCK）
        ok_local, x, why = self.v5.select(x0_state, t_now, rule_id, context,
                                          velocity=self.lrca.velocity,
                                          adapter_id=adapter_id)
        if not ok_local:
            return False, None, why
        if self.cse and not self.cse.physics_gate_multi(context.joint_state,
                                                        context.joint_vel):
            return False, None, 'CSE_REJECT'
        # 第 1 层：协同共证（异步、秒级；与控制环解耦）
        cert = self.ccck.co_sign(x, context)
        if not cert.ok:
            return False, None, 'COOP_QUORUM_FAILED'
        return True, x, 'FORGED_CCPE'

    def ecs_v6(self, ..., n_flow, s_emo, coop_margin, w2_drift) -> float:
        eta_coop = sigmoid((coop_margin) / self.T_coop)
        eta_adapt = exp(-w2_drift / self.lrca.w_max)
        return self.v5.ecs_v5(..., n_flow, s_emo) * eta_coop * eta_adapt
```

## 4. 正确性论证（增量更新）

### 引理 45（速度场扰动 → 轨迹与分布漂移界）

**陈述**：设速度场 u,w 关于 x 均 L-Lipschitz，φ_t^u, φ_t^w 为同初值 x_0 对应的流。则 ‖φ_1^u(x_0)−φ_1^w(x_0)‖ ≤ ∫_0^1 e^{L(1−s)}‖u_s−w_s‖_∞ ds，且 W_2(p_1^u,p_1^w) ≤ ∫_0^1 e^{L(1−s)}(E‖u_s−w_s‖²)^{1/2} ds。∎

**证明**：令 δ_t=φ_t^u−φ_t^w，则 dδ/dt = (u_t(φ_t^u)−u_t(φ_t^w)) + (u_t−w_t)(φ_t^w)。由 Lipschitz 得 d‖δ_t‖/dt ≤ L‖δ_t‖ + ‖u_t−w_t‖_∞，Grönwall 给出轨迹界；分布界由「同初值同噪声」的耦合构造与 φ_1 的 Lipschitz 性推得。∎

### 引理 46（quorum 计数 / 多样性可行性）

**陈述**：至多 f 个拜占庭验证者，且任意 ¬Safe x 至多被 d 个诚实验证者假接受。则 ¬Safe x 的批准者数 ≤ f+d；故 q > f+d ⇒ 任何 CC(x)=1 的 x 必 Safe。可行性要求 f+d < N 且 q ∈ (f+d, N]。∎

### 定理 9（低秩固化漂移界 / ε_KL 构造化）

**陈述**：sup‖Δv_φ‖ ≤ L_φ‖φ‖_F ≤ L_φ ρ_max ⇒ W_2(π_new,π_old) ≤ ((e^L−1)/L)·L_φ ρ_max。取 ρ_max ≤ w_max·L/((e^L−1)L_φ) 即 W_2 ≤ w_max。在 (B8) 密度绝对连续 + 小扩散 σ 下，KL ≤ (L_φ²ρ_max²)/(2σ²)，TV ≤ √(KL/2)。∎

**意义**：定理 7 的 (C2)（KL 有界）从「事后假设」变为「训练时投影 + 可计算 W_2 证书」，这是 v6 把 R57 从「不可根除」降为「可隔离 + 有界」的理论支点。

### 定理 10（协同共证健全性 / 自指打断）

**陈述**：设至多 f 个验证者被自指博弈（拜占庭），诚实族满足 Div(d)，且 q > f+d。则 CC(x)=1 ⇒ Safe(x)；单个被污染验证者的自指证书无法凑 quorum。∎

**证明**：由引理 46，¬Safe x 至多获 f+d < q 批准，与 CC(x)=1 矛盾。∎

**诚实边界**：Div(d) 是**假设**不是定理；门洞相关（d 大）会破坏它。若 d ≥ N−f，则 quorum 不可行，系统 fail-closed 停摆——安全但不可用（R60/R61）。

### 定理 11（适配器隔离 / 回滚精确性）

**陈述**：top-1 硬路由下任一时刻至多一个适配器激活；detach(φ) 后 v=v_{θ0}，π 与 Exec 集精确回到 v5；适配器之间无叠加干扰。∎

### 定理 12（七锚完备性保持）

**陈述**：CSE 是物理门在多机域的扩展（非新锚），LRCA/CCCK 是提议与认证层升级（非新锚）；锚集合不变 + 协同过滤器与适配只紧不松 ⇒ 覆盖链与完备性（v4 定理 4）保持。∎

### 定理 v6（执行集嵌套、构造化漂移与协同健全，总装）

**陈述**：在 v4 (B1)~(B6)、v5 (B7) 及新增 (B8)「密度绝对连续/小扩散」下：
(i) Exec_v6 = Exec_v5^{local} ∩ {CC=1} ⊆ Exec_v5 ⊆ … ⊆ Exec_v29；
(ii) 低秩固化 W_2 漂移 ≤ w_max（定理 9），ε_KL 构造化；
(iii) 协同共证在 Div(d) 且 q>f+d 下健全，单站自指无法凑 quorum（定理 10）；
(iv) 适配器可隔离、精确回滚、无干扰（定理 11）；
(v) 七锚完备性保持（定理 12）；
(vi) 多机协同 CBF 只收紧物理门，执行集进一步缩（CSE）。

**证明**：(i) 由「本地 v5 门 + 额外协同谓词取交」。(ii) 引理 45 + 定理 9。(iii) 引理 46 + 定理 10。(iv) 定理 11。(v) 定理 12。(vi) CBF 前向不变条件为附加合取项。∎

**诚实声明**：(i) Div(d) 是经验假设，common-mode 相关性无法从原理上排除；(ii) 若 d≥N−f 则协同不可行，只能停摆或退回单站 v5；(iii) 低秩容量与漂移存在权衡（r 太小欠拟合、太大漂移），ρ_max 需按任务标定；(iv) 适配器后门/投毒只能靠红队与异常范数检测，无先验根除保证；(v) 加性价值假设 (B4) 与 FER 校准 (B7) 限制原样继承。

## 5. 实验设计与初步结果（仿真，单机多站；实机/舰队留待第 7 轮）

## 7. 本轮最大风险（最终确认）

**一句话**：**协同共证的虚假独立性**——当各站共享同一基座、同一门代码与同一标定源时，门洞高度相关（d 增大），quorum 退化为「相关误差的多数表决」，自指回路只是被分布式化而非被打断，却因「多方背书」制造更强的虚假安全感；PEFT 去相关与门族异构只能降低相关性，无法保证独立。
