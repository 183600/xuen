# 第 2 轮（UniBot 线 · 第 2 轮；本轮灵感：「决策规划」×「运动控制」）

> **承接声明（不重新基线化）**：第 1 轮已建立 UniBot 线，编号继续有效并封存：定义 U1–U12、引理 L1–L7、实验 E601–E618、创新点 IP-01–IP-08。本轮新增定义 U13–U20、引理 L8–L12、实验 E619–E636；IP-02 / IP-03 / IP-06 保留并升级，其余 IP 状态不变。
> **数据纪律**：榜单数字仍来自 `unibot.unitree.com/leaderboard_data.json`（teaser / 占位表，检索 2026-11-17）。本轮尝试重新拉取该文件，站点当前返回 HTML 挑战页而非 JSON，**无法重算任务分组**；故文中"接触密集 / 搬运型"的分组只按任务名与第 1 轮已算出的任务均值作**弱证据**使用，分组重算列为 E619 的第一步。

## 0. 本轮一句话：从"看见抓握"到"学会在最后一毫米里做决定"

第 1 轮把失败归因于**抓握隐变量**。方向对，但只覆盖了失败链的前半段。重看最难 6 个任务——Plug In Ethernet(17.7)、Unlock(20.1)、Spell robot(21.8)、Organize Stationery(22.5)、Open Pill Bottle(22.7)、Pick Out Battery(23.3)——它们真正共享的不是"抓不住"，而是**接触密集的收尾**：对齐、接触、插入、旋转、释放。抓握只是入场券，"最后一毫米"才是主战场。

本轮两个灵感正好补上第 1 轮缺的两块：

- **「决策规划」**：策略不该是一根从观测直通动作的反射弧，而应是一个**带可验证阶段终止条件与失败恢复的选项规划器**（options / POMDP）。决定"此刻该推进、该搜、该退、该重抓"的，是计划层；VLA 只负责"在选定选项内怎么动"。
- **「运动控制」**：在没有力/触觉的接口下，用**跟踪误差当"力代理"、用参考轨迹整形当"柔顺"**，把最后一毫米做成一个可闭环、可搜索、可撤退的控制问题。

还有第 1 轮已经量出来、却没用上的一个自由度：**时间几乎免费**（任务内 corr(时长, 成功)=−0.011，计分无时间项）。这允许我们用"慢、稳、会搜索"换成功率——**只要不撞 episode 超时**。这是本轮的钥匙。

## 1. 直觉（先直觉，不写公式）

**1.1 「决策规划」的直觉：VLA 是反射，不是计划。**
人做插网线不会"一条轨迹打到底"：先靠近 → 碰到 → 手感不对就微抖/回退 → 找到孔 → 插入 → 松手。每一步都有一个**可判断的"成了没有"**，失败就**换策略**。而当前的 VLA 提交形态是"观测进、动作块出"，既没有显式的阶段成功判据，也没有失败后的选项切换，所以它在"前半程很顺、最后一毫米崩"这件事上系统性吃亏——它把一次本可搜索救回的失败，执行成了一次超时。决策规划层的价值不是"更聪明地选任务"，而是**把可恢复失败从不可恢复失败里分出来**。

**1.2 「运动控制」的直觉：没有力传感器，但有两个旋钮和一个"传感器"。**
接口只给位置/关节指令，不给力矩。于是：
- **旋钮 A（时间缩放/保护移动）**：越接近接触，参考速度越低；冲量≈动量变化，慢下来就软下来。
- **旋钮 B（参考形状）**：阿基米德螺线搜索、微抖动（dither）、斜向扫掠、先退后进——这些都是经典 peg-in-hole 的"盲搜"策略，天然不需要力反馈。
- **那个"传感器"**：**跟踪误差** `e = 指令位姿 − 实测位姿`。自由空间里 `e` 只是延迟/模型误差；一旦接触阻力上来、电机跟不上指令，`e` 会增大。这是位置控制接口下唯一近似的"力代理"。**它可不可信，取决于底层控制器的刚度与带宽**——这正是本轮必须先探测的语义（对应第 1 轮 Q5 的延续）。

**1.3 两者的接缝：可验证的终止谓词。**
计划层要离散的"阶段结束了吗"，控制层能给的是连续的"误差/接触概率"。**终止谓词**就是二者的接口：它由控制层计算（可测、可审计），由计划层消费（触发选项切换）。把这条缝做对，规划才不会"拍脑袋切阶段"，控制才不会"在错误的目标上精确"。

## 2. 严谨化：把两个灵感写成预算化 POMDP + Options

**2.1 任务作为 POMDP。**
`M = (S, A, O, T, Ω, R)`。隐状态 `s_t = (z_phase, g_t, κ_t, p_t)`：阶段、抓握信念 `g_t`（第 1 轮 U4）、接触信念 `κ_t`（本轮 U15）、进度 `p_t`。观测 `o_t` = 官方 `obs`（4 路相机、关节/EE/抓手/lower_body）。动作 `a` = 官方 action 块。奖励稀疏且只在终态：`R = 1` 当且仅当任务成功，否则 0（第 1 轮 L1：step_score 与 success 近共线，故只用终态成功）。

**2.2 选项（options）。**
一个选项 `ω = (I_ω, β_ω, π_ω, d_ω)`：起始集 `I_ω`、**验证型终止谓词** `β_ω`、选项内策略 `π_ω`（可调用 VLA 名义策略或运动原语）、期望时长 `d_ω`。选项库 `Ω = {approach, visual_align, guarded_insert, spiral_search, rotate_align, retreat, regrasp, place, release}`。这与经典 options / semi-MDP 同构（Sutton–Precup–Singh, 1999），区别在于 `β_ω` 必须**可测、可审计**，且大量选项是**无需训练的参考整形**。

**2.3 预算化选项值（本轮的核心方程）。**
剩余预算 `h`（步）。规划器每步解：

```
V(b, h) = max_{ω ∈ Ω(b)} [ p_ω(b) · V(b', h − d_ω)
                          + (1 − p_ω(b)) · V(b_recover, h − d_ω − d_retreat) ]
```

其中 `p_ω(b)` 是选项把信念推进到下一阶段的后验成功概率，可由代理数据 + 在线信念估计。终态奖励稀疏 ⇒ 这是一个**有限时域随机最短路**，状态空间小（阶段 9 × 接触/抓握离散档 × 预算桶），可精确反向归纳，也可用小型价值表拟合。**关键**：时间只通过 `h` 进入，不进入奖励——这就把"时间免费"写成了结构，而不是口号。

**2.4 接触观测器（力代理的可辨识条件，见 L9）。**
`κ_t = P(contact | e_{t-k:t}, u_{t-k:t}, v_ee,t, 腕部几何)`，`e = x_ref − x_obs`（须先做延迟对齐，否则延迟会伪装成接触）。它是对第 1 轮 `g_t` 的**对偶隐变量**：抓握回答"东西在不在手里"，接触回答"手/物碰到环境没有"。

**2.5 运动原语（参考整形，不改 checkpoint）。**
`guarded_move`（速度随 `κ` 递减）、`spiral_search`（覆盖有几何保证，见 L11）、`dither`、`retreat`、`time_scale`。它们只作用于 VLA 的名义参考轨迹，落在半径 `ρ` 的管状邻域内（见 L12）⇒ 仍是"单 checkpoint、单 API"（第 1 轮 P6），且把合规风险控制在"任务无关的原语选择"上，而非"按任务名硬编码分支"（P5 红线）。

**2.6 一句话的形式化。**
本轮把第 1 轮的"隐状态显式化"从 `g_t` 扩展到 `(g_t, κ_t)`，并把"策略"从一个映射升级为一个**在信念上做预算化选项规划、在选项内做安全运动控制的闭环**。

## 4. 研究问题（本轮）

- **Q6（接触可观测性）**：仅凭跟踪误差 + 抓手标量 + 腕部视觉，能否把"接触/卡阻"估成带校准的 `κ_t`？在什么控制器刚度/延迟条件下它**必然失效**？如何用一次零成本探测定界？
- **Q7（选项规划是否优于反射）**：带验证型终止与恢复的预算化选项规划，在接触密集任务上是否严格优于扁平 VLA？假终止（false termination）的代价函数是什么形状？
- **Q8（原语的边际贡献）**：保护移动 / 螺线搜索 / 抖动 / 撤退，哪一个在"不重训"的前提下贡献最大？它们与第 1 轮 IP-03 的自适应 chunk 是否冲突（短 chunk 才能局部闭环）？
- **Q9（时间预算的最优分配）**：既然速度无奖励，一个 episode 应把多少时间分给搜索/恢复？停止规则（何时放弃、何时继续搜）如何写成可预注册的形式？
- **Q10（控制语义）**：评测端是开环回放 chunk 还是闭环跟踪？控制频率/增益/延迟是多少？这决定参考整形是否有效，也决定 `e` 能否被对齐。

## 5. 设计原则（在 P1–P6 上追加）

- **P7 计划与执行分离**：计划层选选项（离散、可审计），控制层整形参考（连续、可回退），VLA 只做选项内名义策略。三者都不改 checkpoint。
- **P8 只相信可验证的终止**：`β_ω` 必须是可测谓词；置信度低时不切换（宁可不切，也不乱切）。所有切换写日志（接第 1 轮 IP-08）。
- **P9 用时间换可靠（在超时裕度内）**：搜索/慢速/撤退的预算上界由 `h − d0` 的裕度决定；任何原语不得导致超时率上升。
- **P10 接触安全优先**：接触后禁止"硬顶"；先减速、再撤退、再换搜索模式；单选项内最大力矩代理（跟踪误差）超限即停。

## 6. MVP v2 与严格退化链

**MVP v2 = E620（控制语义探测）+ IP-09（接触观测器）+ IP-10（选项规划器）+ IP-11（运动原语）+ 第 1 轮 IP-06（代理评测）+ VLA 基线。**
与第 1 轮相比：IP-02 的抓握信念并入统一信念 `b`；IP-03 的自适应 chunk 优先服务"接触相位需要短 chunk"（U8 复用）；IP-06 增加"接触事件"标注与 last-mile 子指标。

**退化链（任一层不可用 ⇒ 行为回退，不漂移）**：
- Level-0 `κ` 不可观测（E621 未过）⇒ 关闭接触闭环，只保留**盲式保护移动/慢速接近**（仍可用，因不依赖 `κ`）。
- Level-1 规划器不可用 ⇒ 退回"单一选项序列 + 末端规则"的脚本化短链（仍比纯 VLA 多恢复）。
- Level-2 原语不可用 ⇒ 退回第 1 轮 IP-03 的纯 chunk 缝合 + VLA。
- Level-3 代理评测失真 ⇒ 只保留机制正确性驱动的 IP-09/IP-10/IP-11，用真机 A/B 判方向（沿用第 1 轮剪枝预案）。
- Level-4 整条新链失效 ⇒ 退回**纯基线策略**（安全网永远保留）。

## 7. 预期贡献（可验收）

1. **接触可观测性的可证伪分析**：给出"跟踪误差当力代理"的可辨识条件 d′ 与失效边界，并用一次零成本探测定界——这本身就是全赛道的公共知识。
2. **一个训练免费的收尾控制器**：保护移动 + 螺线搜索 + 抖动 + 撤退，作为单 checkpoint 上的参考整形包装，量化其在插入/旋转任务上的增益。
3. **一个可审计的选项规划器**：把"阶段是否完成/是否该放弃"写成可测谓词与预算化价值，使失败可归因、可回放、可复现。
4. **时间-可靠性交换的定量曲线**：给出"搜索预算 vs 成功率"的拐点，把"时间免费"变成可执行的停止规则。
5. **与第 1 轮栈的无缝集成**：抓握信念 `g` 与接触信念 `κ` 共享同一 belief-state，IP-03 的缝合成为控制层的低层平滑器，IP-06 提供阶段级评测。

## 8. 下一轮计划（深化与修剪）

- **深化**：把 `β_ω` 从手工谓词升级为**校准的生存分析**（何时该判定"这个孔找不到/这个盖拧不开"），用生存模型给出放弃阈值；把 `V(b,h)` 从表格升级为小型价值网络，用代理评测的自博弈数据训练。
- **修剪预案**：若 E621 显示 `κ` 不可观测（d′ < 0.5），**整轮收缩为"盲式保护移动 + 螺线搜索 + 时间预算停止规则"**，砍掉接触闭环与依赖 `κ` 的规划分支；若 E620 显示评测端为纯开环回放，则所有原语退化为离线参考轨迹，规划层只保留"阶段级重规划"。
- **保留项**：E620（控制语义）、IP-11（原语，最不依赖模型）、IP-10 的终止谓词与审计（即使无 `κ` 也有价值）。

## 9. 本轮最大风险

**本轮最大风险：整条方案把"跟踪误差 = 接触力代理"当作唯一接触传感通道，而评测端底层控制语义（开环回放/闭环跟踪、刚度、延迟）尚未验证；若控制器过刚或延迟主导误差，则 `κ` 不可观测，规划器与柔顺原语会同时失去反馈，退化成只会"慢放"的开环播放器，白白吃掉超时裕度。**

## 0. 本轮结论摘要

**一句话路线**：把第 1 轮的"三层栈 + 工程层"升级为**一个闭环控制架构**——

```
观测 → 信念（z_phase, g_t, κ_t, p_t）
     → 规划（预算化 options：推进 / 对齐 / 保护插入 / 搜索 / 旋转对齐 / 撤退 / 重抓 / 释放）
     → 控制（VLA 名义动作 + 参考整形原语 + chunk 缝合）
     → 审计（终止谓词日志 / 接触日志 / 超时裕度）
```

**为什么第 2 轮必须补这一层（三条来自第 1 轮的可核实事实）**：

| 事实（第 1 轮） | 推论 | 本轮动作 |
|---|---|---|
| 最难 6 任务全是插入/旋转/细粒度摆放 | 断点不是"抓不住"，而是"接触中做不对" | 新增接触隐变量 `κ`（IP-09）与收尾原语（IP-11） |
| corr(时长, 成功)≈−0.011，计分无时间项 | 时间可在超时裕度内换可靠性 | 预算化规划（IP-10）+ 停止规则（E627） |
| 接口只给位置/关节指令与 EE 位姿，无力/触觉 | 力信息只能由跟踪误差/视觉间接推断 | 明确"力代理"并给出可辨识条件（L9） |

**合规红线不变**：单 checkpoint、单 API、不用评测侧私有信息、不做"读题即硬编码任务分支"。原语的触发依据是**信念 `κ/phase` 与可测谓词**，不是任务名。

## 3. 创新点详述

### IP-09 · ContactObserver 接触/卡阻信念（P0）

- **动机**：官方接口只给期望动作与实测状态，无力/触觉。经典机器人学里，接触力可由力矩/电流估计；这里没有电流，但**位置跟踪误差 `e = x_ref − x_obs` 在接触时会增大**——这是位置控制下"力的影子"。它同时受刚度、带宽、延迟污染，因此必须先做**可辨识性判断**，而不是直接上阈值。
- **与现有方案的差异**：现有 VLA 提交把 `e` 当作无意义噪声丢弃；我们把 `e` 变成一等观测，并与抓手标量、腕部"物体是否随臂移动"视觉信号融合成校准概率 `κ`。这和第 1 轮 `g` 形成对偶：`g` 管"手里有没有"，`κ` 管"外面碰没碰"。
- **技术可行性**：中。信号都在 `obs` 与自己的动作历史里；难点是**延迟对齐**（否则延迟会被误判成接触）与**自由空间基线 D0 的在线估计**。检测器本身很小（1D/2D 特征 + 小 MLP/CNN）。
- **关键设计**：
  1. **参考队列**：缓存最近 `W` 步下发的参考动作与时间戳/步号；按估计延迟 `Δ` 取出"本应到达"的参考 `x_ref(t−Δ)`。
  2. **自由空间基线**：只在 `|v_ref|` 高、抓手开合稳定、腕部无遮挡的片段更新 `D0`（均值/协方差）。
  3. **接触证据**：`z = (e − μ0)ᵀ Σ0⁻¹ (e − μ0)` 的马氏距离 + 视觉静止特征 + 抓手受力代理（闭合后仍下滑）。
  4. **校准**：输出概率并用可靠性图校准；不追求召回，追求"高精度触发保护"。
- **落地步骤**：① E620 探测控制语义与延迟；② 采集自由空间/已知接触（轻压桌面、堵住）各若干分钟；③ 拟合 `D0` 与检测器；④ 校准 + 阈值；⑤ 接入 IP-10。
- **风险**：见 L9。若控制器过刚或延迟主导，`κ` 不可观测 ⇒ 立刻降级为"盲式保护移动"（Level-0），不硬用。

### IP-10 · OptionPlanner 预算化选项规划（P0）

- **动机**：VLA 是反射，没有"阶段成功了吗/该不该放弃/失败了退回哪里"的显式结构。最后一毫米的失败大多**可恢复**（退一点重来、换个角度搜），但扁平策略把可恢复失败执行成超时。
- **与现有方案的差异**：不做"大模型规划器"（延迟不允许、且易被视为脚本/多模型）；做**小状态空间的预算化 semi-MDP**：阶段 × 信念档 × 预算桶，价值可用表/小网络，决策可审计。规划器只输出**选项**，不输出动作，动作仍由 VLA/原语产生。
- **技术可行性**：高–中。选项库小（9 个）；`β_ω` 是手工可测谓词（接触持续、跟踪误差超限、视觉对齐误差、时间耗尽）；价值初值可用规则 + 代理数据拟合。风险是假终止导致循环，用"最小驻留 + 最大重试 + 审计"兜底。
- **关键设计**：
  - **验证型终止**：`β` 必须是"k 帧持续满足 + 置信度门控"，避免单帧噪声触发。
  - **恢复选项**：进入条件是"已验证失败"，动作是"撤退到安全前态（离开接触、保持抓握）"，而非随机扰动。
  - **预算桶**：`h` 离散为若干桶；每选项带期望时长 `d_ω`；当 `h` 低于安全阈值时，规划器只允许"保守完成/释放"，禁止长搜索。
  - **停止规则**：当搜索选项的期望边际收益 < 继续的 hazard 时切换为"放弃该子目标并执行可成功的最短路径"（如放置已知可放的位置），保证 episode 内不空转。
- **落地步骤**：①定义 9 个选项与 `β`；②用代理数据标定 `p_ω` 与 `d_ω`；③离线反向归纳价值表；④真机/仿真闭环接 IP-11；⑤消融：有无恢复、有无预算、有无 `κ`。
- **风险**：假终止/循环吃预算（用 E629/E635 量化）；规划器过度规则化被视为脚本（坚持"任务无关 + 依据信念"）。

### IP-11 · MotionPrims 参考整形原语库（P0）

- **动机**：接触密集任务需要"慢、软、会搜、会退"的运动，而这些**不需要重训 VLA**。位置接口下可用参考轨迹整形近似柔顺：减速降冲量、搜索补偿位姿不确定、撤退解卡。
- **与现有方案的差异**：现有提交直接回放 VLA chunk；我们在 chunk 之上加一层**任务无关的参考整形**，并让自适应 chunk 在接触相位变短以支持局部闭环（复用 IP-03 U8）。
- **技术可行性**：高。全部是控制/几何代码，无新数据。
- **原语清单**：
  - `guarded_move(x_goal, v_max, κ, κ_stop)`：速度随 `κ` 线性/指数衰减，`κ ≥ κ_stop` 即停（保护移动）。
  - `spiral_search(center, r_max, pitch, v, κ)`：阿基米德螺线，`pitch ≤ 2·r_capture` 保证覆盖（L11）；接触即减速。
  - `dither(axis, amp, f, n)`：小幅周期性抖动，破坏静摩擦/帮助落入孔/槽。
  - `rotate_align(axis, ω, κ)`：小角度往复旋转，用于 Unlock/拧盖类（配合第 1 轮非抓取原语）。
  - `retreat(dir, dist, v)`：沿接触法向/来路撤退到安全距离，解除卡阻。
  - `time_scale(traj, s)`：`s<1` 放慢整段参考；与 `guarded_move` 组合。
- **落地步骤**：①实现原语 + 管状约束（L12）；②E620 验证控制语义后选择"闭环 `κ`"或"开环盲式"版本；③参数扫描（速度、pitch、幅度）；④与 IP-03 短 chunk 联调；⑤消融每个原语。
- **风险**：①评测端若自带平滑/开环回放，闭环原语效果打折 ⇒ 退化为开环版本；②整形过度偏离 VLA 分布（管半径 `ρ` 过大）⇒ 成功率反降（L12 的 `ρ` 扫描）；③搜索可能扰动邻近物体 ⇒ 仅在单目标/低拥挤场景启用，设禁区。

### 对 IP-02 / IP-03 / IP-06 的升级

- **IP-02**：`g_t` 与 `κ_t` 共享 belief-state；抓握判定仍"高精度低召回"，但恢复动作现在由 IP-10 统一调度（重抓 vs 撤退 vs 换原语），避免第 1 轮"重抓死循环"。
- **IP-03**：`T_a(z_phase)` 增加约束——`phase ∈ {align, contact, insert}` 时 `T_a ≤ 2`，让控制层有局部反馈机会；`transport` 保持长 chunk 降延迟。缝合仍是边界 C0/C1 平滑。
- **IP-06**：六因子分解细化为 `reach → grasp → transport → align → contact → insert → release`，其中 `contact` 是**事件**（首次稳定接触）而非独立成功因子；代理评测增加"接触事件时间戳"与"last-mile 停留时长"，用于训练/评估 IP-09/IP-10。

**定义 U13（信念状态）** `b_t = (z_phase, g_t, κ_t, p_t)`，`z_phase` 沿用 U3，`g_t` 沿用 U4，`κ_t` 见 U15，`p_t ∈ {0..1}` 为阶段内进度估计。
**定义 U14（跟踪误差）** `e_t = x_ref(t−Δ) − x_obs(t)`，`Δ` 为估计的参考-执行延迟；对齐错误会直接污染 `κ`（E623 专项）。
**定义 U15（接触信念）** `κ_t = σ(f_θ(e_{t-k:t}, u_{t-k:t}, v_ee,t, φ_vis,t))`，其中 `u` 为历史指令，`φ_vis` 为腕部"物体相对夹爪静止/随动"特征。
**定义 U16（选项）** `ω = (I_ω, β_ω, π_ω, d_ω)`；`I_ω` 为起始条件（可由 `b` 判定），`β_ω` 为终止谓词，`π_ω` 为选项内策略（VLA 名义或原语），`d_ω` 为期望时长。
**定义 U17（验证型终止）** `β_ω(b_{t-k:t}) = 1` 当且仅当连续 `k` 帧满足条件且置信度 > `τ_β`；任何单帧满足不触发。

```python
# ===== 统一策略服务 v2（仍是单 checkpoint / 单 API）=====
class UniBotSAGE2:
    def __init__(self, ckpt, H=..., margin=..., rho=...):
        self.model = load_single_checkpoint(ckpt)   # 第 1 轮主干 + 专家
        self.belief = BeliefState()                 # U13
        self.co = ContactObserver()                 # IP-09 / U15
        self.planner = OptionPlanner(H=H, margin=margin)  # IP-10 / U18
        self.prims = MotionPrims(rho=rho)           # IP-11 / U19,U20
        self.stitch = Stitcher()                    # 第 1 轮 IP-03 / U7
        self.audit = AuditLog()                     # 第 1 轮 IP-08
        self.ref_hist = RefQueue()                  # 供延迟对齐 U14
        self.sessions = {}                          # 每端口隔离

    def get_action(self, obs, port):
        s = self.sessions.setdefault(port, Session())
        self.belief.update_phase_grasp(obs)         # U3/U4 + IP-02
        kappa, e = self.co.step(obs, self.ref_hist) # IP-09
        self.belief.kappa = kappa

        w = self.planner.select(self.belief, s.h)   # IP-10: 选选项
        a_nom = self.model.act(obs, self.belief, w) # VLA 选项内名义动作
        a = self.prims.apply(w, a_nom, self.belief, obs)  # IP-11: 参考整形
        a = self.stitch(a, s.last_action)           # IP-03: 边界平滑
        a = self.audit.clamp_and_log(a, obs, w)     # 限幅 + 审计

        self.ref_hist.push(a, obs)                  # 供下一步算 e
        s.last_action = a[-1]
        s.h -= len(a)                               # 预算递减
        if self.planner.terminated(self.belief, obs, e):   # U17
            self.belief.on_option_end(w)
        return pack(a)
```

```python
# ===== IP-09：接触观测器（延迟对齐 + 自由空间基线 + 校准）=====
class ContactObserver:
    def __init__(self, dt=1/30.0, delay_est=0, calib=None):
        self.dt = dt
        self.Delta = delay_est
        self.mu0, self.Sigma0 = None, None      # 自由空间 e 的分布 D0
        self.calib = calib                      # 可靠性图/温度参数

    def step(self, obs, ref_hist):
        x_ref = ref_hist.at(t=obs.t, delay=self.Delta)   # U14，延迟对齐
        err = []
        for side in ("left", "right"):
            x_obs = obs[f"observation.state.{side}_ee_pose_gripper_base"][-1]
            err.append(x_ref[side] - x_obs)
        e = concat(err)

        # 自由空间基线：仅在"高速、无接触、腕部无遮挡"时更新
        if self._is_free_space(obs, e):
            self._update_D0(e)

        if self.mu0 is None:
            return 0.0, e                       # 冷启动：不触发保护

        z = mahalanobis(e, self.mu0, self.Sigma0)          # 接触证据
        z_vis = wrist_object_static(obs)                   # 视觉证据
        logit = self.net([z, z_vis,
                          obs["observation.state.left_gripper"][-1],
                          obs["observation.state.right_gripper"][-1],
                          ee_velocity(obs)])
        kappa = self.calib(temp=logit) if self.calib else sigmoid(logit)
        return float(kappa), e

    def _is_free_space(self, obs, e):
        return (ee_speed(obs) > 0.05) and (not wrist_occluded(obs))
```

```python
# ===== IP-10：预算化选项规划器（小状态空间，可反向归纳）=====
class OptionPlanner:
    SUCCESSOR = {
        "approach":      ["visual_align", "retreat"],
        "visual_align":  ["guarded_insert", "spiral_search", "retreat"],
        "guarded_insert":["insert", "retreat", "spiral_search"],
        "spiral_search": ["guarded_insert", "retreat"],
        "rotate_align":  ["insert", "retreat"],
        "retreat":       ["visual_align", "regrasp", "place"],
        "regrasp":       ["approach"],
        "place":         ["release"],
        "release":       [],
    }

    def __init__(self, H, margin, value_table=None):
        self.H, self.margin = H, margin
        self.V = value_table or self._rule_init()

    def select(self, b, h):
        cand = [w for w in self.SUCCESSOR
                if self._initiable(w, b) and self._fits(w, h)]
        if not cand:
            return "place" if b.g > 0.5 else "release"   # 安全最短路径
        return max(cand, key=lambda w: self._Q(b, w, h))

    def _Q(self, b, w, h):
        p = self._p_success(b, w)
        d = self._duration(b, w)
        h2 = h - d
        if h2 <= 0:
            return -1.0                       # 预算越界 = 失败
        succ = p * (1.0 if w == "release" else self._V(b_next(b, w), h2))
        fail = (1-p) * self._V(b_recover(b, w), h2 - self._duration(b, "retreat"))
        return succ + fail

    def terminated(self, b, obs, e):
        w = b.active_option
        return BETA[w](b, obs, e)             # U17：k 帧持续 + 置信门控
```

```python
# ===== IP-11：参考整形原语（不改 checkpoint，管状约束）=====
class MotionPrims:
    def __init__(self, rho, kappa_stop=0.7):
        self.rho, self.kappa_stop = rho, kappa_stop

    def apply(self, w, a_nom, b, obs):
        if w == "guarded_insert":
            a = self.guarded_move(a_nom, b.kappa)
        elif w == "spiral_search":
            a = self.spiral_search(a_nom, b.kappa)
        elif w == "retreat":
            a = self.retreat(a_nom, dist=0.02)
        elif w == "rotate_align":
            a = self.rotate_align(a_nom)
        else:
            a = a_nom
        return project_to_tube(a, a_nom, self.rho)    # L12：不越管

    def guarded_move(self, a, kappa):
        s = max(0.0, 1.0 - kappa / self.kappa_stop)   # 越像接触越慢
        return time_scale(a, s)

    def spiral_search(self, a, kappa, R=0.02, pitch=0.002):
        # pitch ≤ 2*r_capture；接触时自动降速（U19/U20）
        path = archimedean(R, pitch)
        return blend(a, path, kappa)

    def retreat(self, a, dist):
        return along_negative_contact_normal(a, dist)

    def time_scale(self, a, s):
        return resample(a, factor=s)                  # s<1 变慢，U19

    def rotate_align(self, a, amp=0.05):
        return a + small_oscillation(amp)
```

## 6. 推导（本轮新增 L8–L12）

**引理 L8（时间预算近自由）** 设剩余预算 `h` 步，基础完成需 `d0` 步，裕度 `M = h − d0`。某可靠性机制时长 `d`，自身带来的成功增量非负。若 `d ≤ M`，则该机制的超时概率为 0，其期望终态成功非降；故在 `M` 内"花时间"没有计分代价，唯一代价是超时。由第 1 轮事实（计分无时间项、corr(时长,成功)≈−0.011）⇒ 最优是用满 `M` 而非超过 `M`。∎

**引理 L9（接触可观测性条件）** 记自由空间跟踪误差 `e0 ~ D0(μ0,Σ0)`，接触附加扰动 `δ` 经控制器灵敏度 `S`（近似刚度的倒数）映射为 `S·δ`。可分性 `d′ = ‖μ1−μ0‖ / sqrt(½(σ1²+σ0²))`。当控制器刚度过高（`S→0`）或延迟未对齐使 `D0` 方差主导时，`d′→0`，接触不可从 `e` 辨识；仅当 `d′ ≥ 1` 时 `κ` 可用（E621 判定）。∎

**引理 L10（恢复占优）** 仅在**已验证失败**时进入恢复，假触发率 `α`，恢复成功率 `r`，撤退时长 `d_r`。相对"硬执行到底"的期望成功增量约为 `(1−α)·r − α·ℓ`，其中 `ℓ` 为误触发造成的额外损失系数。若 `r > α·ℓ/(1−α)` 且 `d_r ≤ M`（L8），则加入恢复选项的期望成功率不降。∎

**引理 L11（螺线搜索覆盖）** 平面阿基米德螺线径向间距 `p`，若目标"捕获半径" `r_capture ≥ p/2`，则搜索圆盘 `R` 内任意目标中心必被扫过；覆盖时间 `T ≈ πR²/(p·v)`。给定 `M`（L8），应选 `R,p,v` 使 `T ≤ M`，否则先扩大捕获半径（对准/视觉伺服）而非无限扩搜。∎

**引理 L12（参考整形的策略保持性）** 若原语只对 VLA 名义参考做时间缩放、限速、局部扰动，并投影到半径 `ρ` 的管 `‖a − a_nom‖ ≤ ρ`，则执行轨迹偏离名义轨迹至多 `ρ`（叠加跟踪误差），checkpoint 未变（满足 P5/P6）。整形能带来的收益随 `ρ` 先增后减：`ρ` 太小无法解卡，太大则离开 VLA 训练分布 ⇒ 存在最优 `ρ*`（E625/E626 扫描）。∎

## 12. 本轮最值得押注的点

**押注 IP-09 + IP-11 的"接触闭环"组合**：它不依赖重训、不新增模型，却直接作用在 teaser 榜与 RoboDojo 共同暴露的断点（对齐/插入/恢复）；先用 E620 花一次零成本探测把"跟踪误差能不能当力代理"这件事定死，再用 IP-11 的盲式原语做安全网，最后才让 IP-10 的规划器接管选项切换。这样即使 `κ` 不可观测，也仍有一套能涨点的收尾控制器，而不是把整轮赌在一个未验证的传感器上。

**本轮最大风险：整条方案把"跟踪误差 = 接触力代理"当作唯一接触传感通道，而评测端底层控制语义（开环回放/闭环跟踪、刚度、延迟）尚未验证；若控制器过刚或延迟主导误差，则 `κ` 不可观测，规划器与柔顺原语会同时失去反馈，退化成只会"慢放"的开环播放器，白白吃掉超时裕度。**
