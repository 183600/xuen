# 第 13 轮（新循环第 1 轮）· SILK：把 CHUNK-SERVO 的「几何点估计」升级为「自监督信念状态」

> 检索/复核日期：**2026-10-28（UTC）**。赛事身份不变：宇树 **UniBot 世界挑战赛**（unibot.unitree.com），G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API。沿用第 12 轮的状态文件，因此按总轮次编号；本轮是新灵感循环的第 1 轮，三个词是「**自监督学习**」「**闭环控制**」「**状态估计**」。本轮不推倒第 10 轮 FACT-VLA、第 11 轮 GEO-RESIDUAL、第 12 轮 CHUNK-SERVO，而是补上它们共同缺的一层：**带不确定性与延迟的信念状态**。VLA 仍是唯一策略模型；自监督观测器是同一 checkpoint 的辅助头（或离线 C1 回退）；控制器仍是确定性几何/控制律。

## 0. 直觉：最后 3 厘米的失败，往往不是「没看见」，而是「看错了还以为很确定」

第 12 轮把反馈周期从 1 s 降到了 167 ms，这是必要的，但不充分。因为 CHUNK-SERVO 的伺服输入是一个**点估计**：`T_base_target(t)`、腕部特征点、`e(t)`。它没有告诉你这个估计有多可靠，也没有告诉你这个估计对应的是不是 100 ms 前的世界。透明试管的边缘、反光杯口、被夹爪挡住的孔、拉链头的自遮挡、人手的突然进入，都会让几何管线给出一个**自信但错误**的位姿。此时 5 步闭环反而更危险：它以 167 ms 的周期、用错误的误差方向持续修正。

所以本轮的核心问题不是「如何更快地看」，而是：

> 机器人应该维护一个什么样的状态信念，才能知道「现在该不该信视觉」「该用多大力气修」「该不该先动一下来减少不确定性」？

三个灵感词正好对应三件事：

| 灵感词 | 本轮要回答的问题 | 落到 SILK 的部件 |
|---|---|---|
| **自监督学习** | 没有失败标签、没有力/触觉，如何从 33k 条成功演示里学出「正常应该发生什么」？ | 动作条件隐动力学、时序对比、跨视角预测；接触/滑移/人为编辑 = 预测残差（surprise） |
| **状态估计** | 如何把四路 RGB + 本体感受变成带协方差、带延迟的信念？ | 延迟增广隐卡尔曼滤波、鲁棒更新、保形（conformal）校准、度量锚定 |
| **闭环控制** | 如何用信念而不是点估计来决定修正量？ | 不确定性/延迟调度的增益、机会约束、安全对偶试探、接触段法向阻尼 |

一句话：**从「目标在哪」升级到「我有多确定目标在哪、这个确定性是否足以让我动手」。**

## 1. 为什么是现在：三个已经核实过的事实，指向同一个缺口

### 1.1 数据是「只有成功」的，自监督比监督更匹配

第 12 轮已核实：32 个 HF 数据集合计 **33,276 episodes / 18,282,246 frames / 169.28 h**，单任务 969–1,533 条，全部是成功演示。没有失败标签，没有接触/滑移标签，没有力/触觉。人工标注 18M 帧不现实，而且标注规范跨 32 个任务很难统一。

自监督在这里不是「因为时髦」，而是**唯一能规模化利用这 169 小时信号的方式**：

- 用「当前隐状态 + 未来动作」预测「未来隐状态」，学的是**动作条件动力学**；
- 用同一 episode 相邻帧做正样本、其他 episode/任务做负样本，学的是**任务相关且不塌缩的表示**；
- 用头部双目与腕部视角互相预测，学的是**跨视角几何**；
- 用逆动力学从相邻隐状态回归动作，学的是**可控自由度**；
- 成功数据只覆盖「正常流形」，所以接触、滑移、遮挡、人为编辑会表现为**动作条件预测残差**——不需要标签就能得到 surprise。

### 1.2 API 没有深度/力/触觉，接触状态只能「估计」

第 12 轮已核实：观测只有四路 RGB 480×640、双臂关节、EE 位姿、夹爪、下身体、语言；**没有 depth、camera_info、force/torque、tactile**；腕部相机**没有内参矩阵**；`action_chunk_size` 固定，chunk 内不重新看世界。

这意味着：

- 接触/滑移不能直接测，只能从「动作执行后，世界是否按预期变化」中间接估计；
- 腕部 2D 伺服缺少内参，必须先标定；而棋盘格标定在 32 任务、N 台机器人、远程评测的节奏下很脆弱；
- 单帧几何在透明/反光/遮挡下会失效，必须有**时序先验**和**不确定性**来兜底。

### 1.3 单模型规则堵死「第二个策略」，但没堵死「同一模型的辅助状态头」

规则仍然是：所有任务须基于**同一模型**，不得混合多个模型。第 12 轮把合规分成 C1/C2/C3：离线标注、确定性控制器、同一 checkpoint 特征。

SILK 的合规主张是：

- **主推 C3**：在官方 WLA 同一 checkpoint 上加一个自监督辅助头（观测器/动力学头），共享冻结的 VLM encoder；动作头仍是唯一策略头。推理时一次前向，既出 30 步 plan，也出隐状态与协方差。
- **回退 C1/C2**：如果官方模型服务器不暴露特征，就把自监督观测器**只在离线**训练，用它生成伪标签/校准阈值/协方差表；线上只跑确定性卡尔曼滤波 + 几何锚定 + 保形阈值。这样线上没有第二个学习模型。
- **绝不**：加载第二个学习策略、独立残差网络、独立视觉编码器做在线决策。

## 2. 诊断：CHUNK-SERVO 缺的不是频率，而是「信念」

把第 12 轮的 5 步伺服拆开，会看到三个隐性假设：

1. **点估计假设**：`T_base_target(t)` 是一个准确的点。实际它可能是 5 mm 错、2° 错，且没有任何置信度。伺服拿到它就直接算 `e(t)`。
2. **固定增益假设**：`K_p, K_d` 在仿真里调好，假设 RTT 和噪声不变。实际远程 RTT 可能 10–150 ms，透明物体的测量噪声可能突然放大 10 倍。
3. **被动感知假设**：机器人只根据当前图像修正，不会主动动一下来减少不确定性。可在接触前，**一个小幅、安全、信息量最大的试探**，往往比盲目多走 2 mm 更省时间。

这三个假设在「最后 3 厘米」同时失效。于是出现一种很典型的失败：

```text
几何管线：目标在 (x=+4mm, y=-2mm)     ← 实际是 (+1mm, +1mm)，透明边缘导致偏差
伺服：   每 167ms 向右下修 0.4mm
VLA：    继续执行插入意图
结果：   越修越偏，直到卡住/撞上/超时
```

如果系统知道「这个位姿的协方差很大」，它本可以：降增益、先做一次横向试探、或者把头双目切到另一个视角确认。SILK 要做的就是这件事。

## 3. 形式化：把最后 3 厘米写成带延迟的 POMDP

### 3.1 状态、观测、动作、信念

设第 `t` 个控制 tick：

- 观测 `o_t = (I_t^{LH}, I_t^{RH}, I_t^{LW}, I_t^{RW}, q_t, g_t)`，四路 RGB + 本体（EE 位姿、关节、夹爪）；
- 动作 `a_t ∈ R^{21}`（`ee` 模式：2×6 EE 绝对位姿 + 2×1 夹爪 + 7 pivot）；
- 任务相关状态 `x_t = (T^{base}_{ee}(t), T^{base}_{target}(t), \dot T, c_t, s_t)`，其中 `c_t` 是接触/滑移隐变量，`s_t` 是语义/相位；
- 观测延迟 `τ_t`（RTT + 推理 + 图像传输），离散化为 `d_t = round(τ_t f_c)`；
- 信念 `b_t = p(x_t | o_{0:t}, a_{0:t-1})`。

目标是求一个控制律 `π(a_t | b_t)`，在任务成功约束下最小化期望末态误差：

```math
\min_{\pi}\ \mathbb E\left[\|e_T\|^2 + \lambda \sum_t \mathbf 1[\text{unsafe}_t]\right],
\quad e_t = \log\!\left(T_{ee}(t)^{-1} T_{ee}^{d}(t)\right).
```

### 3.2 隐状态模型

用一个自监督观测器把高维观测压成隐状态 `z_t ∈ R^{d_z}`：

```math
y_t = E_\phi(o_t),\qquad
z_t = \mathrm{Pool}(y_t),\qquad
z_{t+1} \sim \mathcal N\!\left(A z_t + B a_t,\ Q\right),
```

其中 `E_φ` 是同一 VLA checkpoint 的视觉/状态 encoder（C3），或离线小 encoder（C1）。`A,B` 可以是从 `g_θ(z_t, a_{t:t+k})` 在当前位置的雅可比得到的局部线性化，也可以是一个轻量线性头。

**度量锚定**：纯自监督只能把状态恢复到可逆线性变换，不能恢复毫米尺度。因此用头部双目 + 已知 EE 位姿给出的几何估计 `x_t^{geo}` 作为**度量锚**：

```math
x_t^{geo} = \Pi_{\text{stereo}}(I_t^{LH}, I_t^{RH}, q_t),\qquad
x_t = D_\psi(z_t) \ \text{with covariance}\ \Sigma_t.
```

`D_ψ` 是一个小线性/MLP 解码器，用几何管线的自动估计作为伪标签训练；几何失效时（透明/反光/遮挡），`Σ_t` 必须相应放大，控制器自动降增益。**这是 SILK 与「再训一个位姿网络」的关键区别：不做第二个学习模型，只做同一表示上的度量读出。**

### 3.3 自监督目标

从成功演示中采样长度为 `T` 的片段，最小化：

```math
\mathcal L =
\lambda_{1}\mathcal L_{\text{tc}}
+\lambda_{2}\mathcal L_{\text{dyn}}
+\lambda_{3}\mathcal L_{\text{inv}}
+\lambda_{4}\mathcal L_{\text{cv}}
+\lambda_{5}\mathcal L_{\text{nll}}
+\lambda_{6}\mathcal L_{\text{reg}}.
```

- **时序对比** `L_tc`：同一 episode 的 `(z_t, z_{t+Δ})` 为正，其他 episode/任务为负；InfoNCE 或 BYOL 形式。
- **动作条件预测** `L_dyn`：`||g_θ(z_t, a_{t:t+k}) - sg(z_{t+k})||^2`，`k ∈ {1,5,15}`；多 horizon 让模型同时学短期接触和中期任务进度。
- **逆动力学** `L_inv`：`||h_θ(z_t, z_{t+1}) - a_t||^2`；强迫隐状态保留可控自由度。
- **跨视角预测** `L_cv`：用头双目 + 外参预测腕部隐特征（或反之）；学习几何对应，也给腕部标定提供信号。
- **异方差 NLL** `L_nll`：`||r||^2/(2σ^2) + 0.5 log σ^2`；让观测器输出可校准的 `Σ_t`。
- **正则** `L_reg`：方差/协方差正则，防止表示塌缩。

只在成功数据上训练，**不学「失败」**；失败/接触/编辑通过 `L_dyn` 的残差（surprise）检测。这是「正常性建模」，不是「故障分类」。

### 3.4 延迟增广卡尔曼滤波

把延迟 `d` 显式放进状态：

```math
X_t = [z_t;\ z_{t-1};\ \dots;\ z_{t-d}],\qquad
X_{t+1} = F X_t + B a_t + w_t,\qquad
y_t^{meas} = H X_t + v_t,
```

其中 `H` 选出 `z_{t-d}`。标准预测/更新：

```math
X_{t|t-1} = F X_{t-1|t-1} + B a_{t-1},\quad
P_{t|t-1} = F P_{t-1|t-1} F^\top + Q,
```

```math
K_t = P_{t|t-1}H^\top(HP_{t|t-1}H^\top+R)^{-1},\quad
X_{t|t} = X_{t|t-1}+K_t(y_t^{meas}-HX_{t|t-1}),
```

```math
P_{t|t} = (I-K_tH)P_{t|t-1}.
```

延迟增广的状态空间与原系统等价；它把「100 ms 前的测量」变成对「当前状态」的带协方差估计，而不是把旧测量硬套到当前时刻。若 `d` 未知或时变，用时间戳缓冲 + 前向重传播；`Q` 按延迟估计误差膨胀。

### 3.5 保形 surprise 与鲁棒更新

在标定集上收集新息（innovation）的马氏距离：

```math
m_t^2 = (y_t-HX_{t|t-1})^\top S_t^{-1}(y_t-HX_{t|t-1}),\qquad S_t=HP_{t|t-1}H^\top+R.
```

用 split conformal 取 `q_{1-α}` 为 `m_t` 的 `⌈(n+1)(1-α)⌉/n` 分位数。则在新 episode 上，`m_t > q_{1-α}` 的误报率约 `α`（在可交换假设下）。当 `m_t > q`：

- 若残差方向与动作方向一致、且几何距离接近 0 → **接触**；
- 若残差在夹爪坐标系下与重力/切向一致、`r_grasp` 突变 → **滑移**；
- 若残差与动作无关、持续多帧 → **人为编辑/目标移动**；
- 若残差短暂、随视角变化 → **遮挡/反光**。

同时对 `R` 做鲁棒膨胀：`R_eff = R · max(1, m_t^2/q)`，避免滤波器被一个坏测量拉走。

### 3.6 机会约束与对偶试探

控制律仍是「VLA 前馈 + 伺服反馈」：

```math
a_{cmd} = a_{ff}\circ\exp(\Delta),\qquad
\Delta = \mathrm{clip}\!\left(K(\Sigma_t,\tau_t)\,e_t,\ \pm\delta_p,\ \pm\delta_r\right).
```

但增益不再固定：

```math
K(\Sigma_t,\tau_t) = \frac{K_0}{1+\beta\,\mathrm{tr}(\Sigma_t)/\sigma_0^2+\tau_t/\tau_0}.
```

更严格地，用机会约束：

```math
\mathbb P\left(\|e_{t+1}\|\le \varepsilon \mid b_t\right)\ge 1-\delta.
```

在高斯近似下，等价于

```math
\|e_t+\Delta\| + \sqrt{\chi^2_{n,1-\delta}\,\lambda_{\max}(\Sigma_t)} \le \varepsilon.
```

若不可行，就不硬修：保持、降速、或请求 VLA 重规划。

**安全对偶试探**：当任务相关方向的后验方差 `σ_t^2` 高于阈值、且夹爪离目标大于安全距离 `d_safe` 时，从一个小的确定性动作字典 `H` 中选一个试探 `η`：

```math
\eta^\star = \arg\max_{\eta\in H}\
\left[\tfrac12\log\det\!\left(I+\Sigma_t^{-1}J_\eta^\top R^{-1}J_\eta\right)
-\lambda\,\mathrm{cost}(\eta)\right],
```

约束 `||η|| ≤ 2 mm`、`||η_rot|| ≤ 0.01 rad`、接触段禁止、连续试探不超过 2 次。它只减少不确定性，不改变任务意图；这是「闭环控制」与「状态估计」真正耦合的地方——**控制动作本身也是信息动作**。

## 4. 算法步骤（SILK 全流程）

### 4.1 离线

1. **数据划分**：按 session/物体/背景分组，相邻帧不跨 split；每任务留出标定 episode。
2. **自监督预训练**：在 33k 成功演示上训练 `E_φ, g_θ, h_θ`；如果共享 VLA encoder，冻结 VLM，只训辅助头。
3. **度量锚定**：用头双目 + EE 位姿的几何估计训练 `D_ψ`；记录每类物体/阶段的残差分布。
4. **保形校准**：按任务族（刚体插入、悬挂、叠放、拉链/锁、变形）分别取 `q_{1-α}`；报告覆盖率与区间宽度。
5. **腕部自监督标定**：用已知 EE 运动 + 头双目特征轨迹，优化腕部内参/外参；输出协方差。
6. **目标库**：沿用第 12 轮 DG-KEYFRAME，给每个目标增加残差协方差与难度标签。

### 4.2 在线（每端口、每 tick）

```text
obs = receive()
y = E(obs)                              # 同一 checkpoint 辅助头
X, P = predict(X, P, last_action, tau)  # 延迟增广
if delayed_measurement_available:
    m2 = innovation(y_meas, X, P)
    P, X = robust_update(X, P, y_meas, m2, q)
    surprise = m2 > q
    mode = classify(surprise, geometry, gripper)
goal = retrieve(task, phase, obs)       # 第 12 轮目标库
e, Sigma_e = decode(X, P, goal)         # 度量锚定 + 协方差传播
if mode == CONTACT:
    e, Sigma_e = contact_damping(e, Sigma_e)
if should_probe(Sigma_e, d_t, mode):
    eta = select_probe(Sigma_e)         # 安全对偶试探
else:
    eta = 0
Delta = clip(K(Sigma_e, tau) @ e, limits) + eta
a_cmd = compose(vla_plan, Delta)
return chunk_5(a_cmd)
```

### 4.3 状态机

```text
INIT → PLAN → SERVO ⇄ CONTACT
                 │  ↑
                 ▼  │
               PROBE│
                 │  │
                 ▼  │
              RECOVER ┘
```

- `SERVO`：低 surprise、低协方差；正常 PBVS/IBVS。
- `CONTACT`：`d_t < d_c` 或 surprise 被动作解释；法向降增益、切向保留。
- `PROBE`：高协方差 + 安全距离；小幅信息动作；最多 2 次。
- `RECOVER`：高 surprise 且动作解释不了；停 → 重定位 → 重规划。
- 任意状态异常 → 安全 hold；绝不返回 NaN/错误形状。

## 5. 复杂度

| 部件 | 复杂度 | 30 Hz 下的量级 |
|---|---|---|
| 观测器辅助头 | `O(N_p d_z)`，共享 VLM 时只算头 | 5–15 ms（低分辨率四路） |
| 延迟增广 KF | `O((n(d+1))^3)`，`n=6,d≤10` | <1 ms CPU |
| 目标检索 | `O(\log N)` 近似 + top-k 重打分 | <5 ms |
| 控制器 | `O(n^3)` 机会约束 + 字典试探 | <1 ms |
| 每端口内存 | `X,P` + 目标缓存 | <1 MB + 共享只读目标库 |

训练侧：如果共享冻结 VLM encoder，只需训练 20–60M 参数的辅助头；单张 24 GB GPU、1–2 GPU 天可完成一个任务族的预训练。若使用离线小 encoder，训练成本略高，但线上不依赖官方特征接口。

## 6. 正确性论证（要点，完整版在产物区）

1. **延迟增广等价性**：把 `d` 步历史并入状态后，系统仍是 Markov 的；标准 KF 与「先更新旧时刻、再用已知动作前向传播」的全信息滤波等价。因此 SILK 不是启发式补延迟，而是对延迟系统的精确贝叶斯更新（在线性高斯假设下）。
2. **保形覆盖率**：在可交换假设下，`m_t > q_{1-α}` 的误报率 ≤ `α`，无需假设残差高斯。按任务族做 Mondrian conformal 可避免跨任务分布漂移。
3. **机会约束**：若 `e_t` 的后验近似为 `N(μ,Σ)`，则缩放后的 `Δ` 满足 `P(||e_{t+1}||≤ε) ≥ 1-δ`；这给出了「不确定时少修」的硬约束，而不是拍脑袋的增益。
4. **稳定性**：延迟闭环的特征方程为 `z^{d+1}-z^d+K H_c=0`；`d=1` 时稳定域 `0<KH_c<1`。SILK 通过前向预测把有效延迟从 `τ` 降到「延迟估计误差」，并用 `Σ` 调度增益，因此在 `τ` 变化时保持增益裕度。
5. **自监督的可辨识性**：逆动力学 + 多 horizon 预测识别可控子空间；时序对比防止塌缩；度量锚定解决尺度。这是**假设**，不是定理；G1 要用线性探针和位姿误差检验。
6. **单模型合规**：一个 checkpoint、一个策略头、一个辅助状态头；控制器是确定性几何/控制律。若官方不暴露特征，回退 C1：观测器只离线，线上只有确定性滤波器。

## 7. 与第 10/11/12 轮的关系：保留、升级、剪枝

**保留**：

- FACT-VLA：相位化 BC、CAC 柔顺执行、EGP 证据门控；
- GEO-RESIDUAL：动作条件化残差、米制表面距离、编辑检测；
- CHUNK-SERVO：30 步规划 + 5 步执行、演示相对目标、数字孪生标定、单任务通道。

**升级**：

- 点估计 → 信念：`T_base_target` 从点变成 `(μ,Σ)`；
- 固定增益 → 机会约束增益：`K(Σ,τ)`；
- 手工阈值 → 保形 surprise：接触/滑移/编辑共用一套校准过的残差；
- 被动伺服 → 安全对偶试探：控制动作同时是信息动作；
- 棋盘格标定 → 自监督时序标定：利用 169 h 演示的已知 EE 运动；
- 单帧几何 → 自监督动力学：成功数据学「正常」，残差学「异常」。

**剪枝**：

- 不做从零训 VLA/World Model；
- 不做完整 sim-to-real 策略训练；
- 不做第二个学习策略/残差网络；
- 不做 6D 物体位姿大网络；
- 不做力/触觉闭环（API 没有）；
- 不做 30 Hz 广域网高增益伺服；
- 不把预览榜单当难度表。

## 9. 竞赛策略：把工程投到「状态不确定性」最高的任务

第 12 轮的优先级是 `q_t × Δ_t / cost_t`；本轮加一个因子 `u_t`：

```text
priority_t = q_t × u_t × Δ_t / cost_t,
```

其中 `u_t` 是单任务通道中「失败前 0.5 s 内状态协方差/ surprise 处于高位的比例」。它把「最后 3 厘米失败」进一步分成两类：

- **几何可救**：目标可见、标定好、只是点估计噪声 → CHUNK-SERVO 已够；
- **估计可救**：透明/反光/遮挡/滑移/人为编辑导致信念错误 → SILK 的边际收益最高。

先验上，SILK 优先投：

- 透明/反光：ArrangeTestTubes、SyringeWaterTransfer、OpenPillBottle；
- 遮挡/自遮挡：ZipUp、Unlock、PlugInEthernet、ToolboxStorage；
- 接触/滑移：HangCup、StackBowls、PaperCupStacking、StoreRackets；
- 人为干扰轴（20% 权重）：surprise + 恢复。

变形/语义任务（FoldTowel、SpellRobot、ConveyorSorting）仍以 VLA 为主；SILK 只提供接触/滑移 surprise，不提供精确度量目标。

单任务通道协议不变：5 个代表任务、每任务 5 次 A/B、配对差值 + bootstrap 95% CI；至少 3/5 +10pp 才提交。区别是 A/B 从「servo off/on」变成「CHUNK-SERVO vs SILK」，并在高不确定性任务上分层。

## 10. 风险与一句话押注

| 风险 | 影响 | 缓解 |
|---|---|---|
| 自监督表示塌缩/走捷径 | 隐状态只编码背景/光照 | 跨视角、逆动力学、episode 负样本、有效秩监控 |
| 隐状态没有度量尺度 | 伺服方向对、幅度错 | 头双目 + EE 位姿锚定；协方差大时降增益 |
| 接触段线性高斯假设失效 | 滤波器发散/滞后 | 接触/非接触双模型；鲁棒膨胀；G3 真机验证 |
| 保形可交换性被违反 | 误报率超标 | 按任务族 Mondrian；在线更新阈值；报告覆盖率 |
| 官方不暴露 encoder 特征 | C3 不可行 | C1 离线观测器 + 确定性滤波器；不加载第二模型 |
| 在线自适应漂移 | 行为不可复现 | 默认关闭；只允许 LayerNorm/线性读出的小步更新 |
| 延迟非平稳 | 预测失准 | 时间戳缓冲；Q 膨胀；p99 监控；回退 chunk 8 |
| 试探动作影响任务 | 碰撞/超时 | 仅自由空间、≤2mm/0.01rad、最多 2 次、接触段禁止 |
| 评测噪声 | +1–2pp 假阳性 | 配对 A/B、bootstrap、重复实验；320 trials SE≈2.4pp |
| 数据泄漏 | 离线指标虚高 | 按 session/物体/背景分组；相邻帧不跨 split |

**一句话押注**：用 169 小时无标签成功演示训练一个与 VLA 同 checkpoint 的自监督隐状态观测器，用延迟增广卡尔曼把「100 ms 前的测量」变成「当前状态的信念」，用保形校准的 surprise 驱动有机会约束的 5 步伺服和安全试探——在不新增第二个策略模型的前提下，把最后 3 厘米从「自信的点估计闭环」升级为「知道自己有多不确定的信念闭环」。

**本轮最大风险**：自监督隐状态在接触瞬间既不可度量也不可校准，控制器却带着错误的置信度做闭环；因此 G1 的度量锚定与 G2 的保形校准是生死门，任一不过就退回 CHUNK-SERVO 的几何伺服。

### 1.2 第 12 轮留下的三个缺口（B）

2. **固定增益不随不确定性/延迟变化**：`K_p, K_d` 在仿真里调好，远程 RTT 和测量噪声一变就失稳或过慢。

- **A1（同一 checkpoint 可加辅助头）**：官方 WLA 的 VLM encoder 特征可被同一进程读取，或在提交包内可加载同一 checkpoint 并加辅助头；不引入第二个策略权重。

- **A3（几何锚定可得）**：头双目 + 已知 EE 位姿能在多数任务/阶段给出 5 mm/2° 量级的度量锚；透明/反光时锚定失效，但协方差会增大。
- **A4（局部线性高斯）**：最后 3 厘米的短时运动可用局部线性高斯模型近似；接触瞬间用双模型/鲁棒膨胀兜底。
- **A5（可交换性）**：同一任务族内的标定/测试 episode 近似可交换，保形覆盖率成立；跨任务用 Mondrian 分组。

## 2. 问题形式化

### 2.1 带延迟的 POMDP

设控制频率 `f_c`（默认 30 Hz），第 `t` 个 tick：

- 观测：`o_t = (I_t^{LH}, I_t^{RH}, I_t^{LW}, I_t^{RW}, q_t, g_t)`，其中 `q_t` 是双臂关节/EE 位姿/下身体，`g_t` 是夹爪；
- 动作：`a_t ∈ \mathcal A ⊂ \mathbb R^{21}`（2×6 EE 绝对位姿 + 2×1 夹爪 + 7 pivot）；
- 任务相关状态：

```math
x_t = \left(T^{b}_{ee}(t),\ T^{b}_{target}(t),\ \dot T^{b}_{ee}(t),\ c_t,\ s_t\right),
```

其中 `c_t` 是接触/滑移隐变量（连续），`s_t` 是语义/相位。

- 观测延迟 `τ_t`（RTT + 推理 + 图像传输），离散化 `d_t = round(τ_t f_c)`；
- 信念：

```math
b_t = p\left(x_t \mid o_{0:t-\tau_t},\ a_{0:t-1}\right).
```

目标是求控制律 `π(a_t | b_t)`：

```math
\min_{\pi}\ \mathbb E\left[\|e_T\|^2 + \lambda \sum_{t=0}^{T-1}\mathbf 1[\text{unsafe}_t]\right],
\qquad
e_t = \log\!\left(T_{ee}(t)^{-1}T_{ee}^{d}(t)\right)\in\mathbb R^6,
```

其中 `T_{ee}^{d}(t) = T_{target}(t)\,T_{target,ee}^{*}` 是演示检索给出的期望夹爪位姿。

### 2.2 两层状态估计

SILK 不把「隐状态」和「米制位姿」混为一谈，而是分两层：

```text
Layer 1（自监督）:  o_t ──E_φ──▶ z_t ──D_ψ──▶ (x_t^{SSL}, Σ_t^{SSL})
                              └──g_θ──▶ ẑ_{t+1} ──▶ latent surprise
Layer 2（贝叶斯滤波）: x_t^{SSL}, x_t^{geo} ──KF──▶ (μ_t, Σ_t)
```

- **Layer 1** 从无标签成功演示学习表示、动作条件动力学、度量读出和不确定性；
- **Layer 2** 把 Layer 1 的读出与几何管线 `x_t^{geo}` 融合，得到任务状态的均值和协方差；延迟在 Layer 2 显式增广。
- 这样，自监督不需要恢复绝对尺度（它做不到），尺度由几何锚定提供；几何失效时，Layer 1 的 `Σ^{SSL}` 和 Layer 2 的先验接管，控制器自动变保守。

### 2.3 自监督目标

从成功演示采样长度为 `T` 的片段 `(o_{0:T}, a_{0:T-1})`。定义：

```math
z_t = E_\phi(o_t),\qquad
\hat z_{t+k} = g_\theta(z_t, a_{t:t+k-1}),\qquad
\hat a_t = h_\theta(z_t, z_{t+1}).
```

总损失：

```math
\mathcal L =
\lambda_{tc}\mathcal L_{tc}
+\lambda_{dyn}\mathcal L_{dyn}
+\lambda_{inv}\mathcal L_{inv}
+\lambda_{cv}\mathcal L_{cv}
+\lambda_{nll}\mathcal L_{nll}
+\lambda_{reg}\mathcal L_{reg}.
```

各项定义：

```math
\mathcal L_{tc}
= -\log\frac{\exp\!\left(\mathrm{sim}(z_t,\bar z_{t+\Delta})/\kappa\right)}
{\sum_{j\in\mathcal N(t)}\exp\!\left(\mathrm{sim}(z_t,\bar z_j)/\kappa\right)},
```

其中 `\bar z` 是 stop-gradient/EMA target，`\mathcal N(t)` 包含同 episode 正样本与其他 episode/任务负样本。

```math
\mathcal L_{dyn}
= \sum_{k\in\{1,5,15\}}
\left\|g_\theta(z_t,a_{t:t+k-1})-\mathrm{sg}(z_{t+k})\right\|_2^2,
```

```math
\mathcal L_{inv}
= \left\|h_\theta(z_t,z_{t+1})-a_t\right\|_2^2,
```

```math
\mathcal L_{cv}
= \left\|\Pi_{\text{cross}}\!\left(z_t^{head},T_{head\to wrist}\right)-z_t^{wrist}\right\|_2^2
\quad\text{或 masked cross-view reconstruction},
```

```math
\mathcal L_{nll}
= \sum_t\left(\frac{\|z_{t+1}-\hat z_{t+1}\|_{\Sigma^{-1}}^2}{2}
+\frac12\log\det\Sigma_t\right),
```

```math
\mathcal L_{reg}
= \max(0,\ \gamma-\mathrm{std}(z))\ +\ \|\mathrm{Cov}(z)-I\|_F^2.
```

设计要点：

- **多 horizon**：`k=1` 学接触瞬态，`k=5` 学 167 ms 执行块，`k=15` 学半秒任务进度。
- **逆动力学**：防止隐状态只编码外观，强迫它保留可控自由度。
- **跨视角**：头双目与腕部的互相预测给几何对应，也为腕部标定提供信号。
- **异方差 NLL**：让 `Σ^{SSL}` 可校准；不是拍一个固定噪声。
- **只在成功数据上训练**：不学失败；失败/接触/编辑 = 预测残差。这是正常性建模，不是故障分类。

### 2.4 延迟增广卡尔曼滤波

令任务状态 `θ_t ∈ \mathbb R^n`（`n=12`：6D 位姿误差 + 6D 速度；接触标量可扩展到 `n=13`）。运动模型：

```math
\theta_{t+1} = F\theta_t + Ga_t + w_t,\qquad w_t\sim\mathcal N(0,Q),
```

其中 `F` 是常速度模型（EE 局部系），`G` 把动作映射到状态；接触时 `G` 的有效增益降低（柔顺）。

延迟 `d` 用状态增广：

```math
X_t = \begin{bmatrix}\theta_t\\ \theta_{t-1}\\ \vdots\\ \theta_{t-d}\end{bmatrix},
\qquad
X_{t+1} = F_aX_t + G_a a_t + w_t^a,
```

```math
F_a =
\begin{bmatrix}
F & 0 & \cdots & 0\\
I & 0 & \cdots & 0\\
0 & I & \cdots & 0\\
\vdots & & \ddots & \vdots\\
0 & \cdots & I & 0
\end{bmatrix},
\qquad
G_a = \begin{bmatrix}G\\0\\\vdots\\0\end{bmatrix}.
```

测量有两路：

```math
y_t^{SSL} = H_{SSL}X_t + v_t^{SSL},\qquad v_t^{SSL}\sim\mathcal N(0,R_t^{SSL}),
```

```math
y_t^{geo} = H_{geo}X_t + v_t^{geo},\qquad v_t^{geo}\sim\mathcal N(0,R_t^{geo}),
```

`H_{SSL}` 选出延迟 `d` 时刻的 SSL 读出，`H_{geo}` 选出几何读出。标准预测/更新：

```math
X_{t|t-1}=F_aX_{t-1|t-1}+G_a a_{t-1},\qquad
P_{t|t-1}=F_aP_{t-1|t-1}F_a^\top+Q_a,
```

```math
S_t=H P_{t|t-1}H^\top+R_t,\qquad
K_t=P_{t|t-1}H^\top S_t^{-1},
```

```math
X_{t|t}=X_{t|t-1}+K_t\left(y_t-HX_{t|t-1}\right),\qquad
P_{t|t}=(I-K_tH)P_{t|t-1}.
```

**等价性**：增广状态把延迟测量变成当前状态的一个分量；对线性高斯系统，上述滤波与「先更新旧时刻、再用已知动作前向传播」的全信息滤波等价。证明见 §11.1。

### 2.5 保形 surprise

Layer 1 的 latent 新息：

```math
r_t = z_t - g_\theta(z_{t-1},a_{t-1}),\qquad
m_t^{lat} = \sqrt{r_t^\top S_{z,t}^{-1}r_t},
```

Layer 2 的测量新息：

```math
\nu_t = y_t-HX_{t|t-1},\qquad
m_t^{KF} = \sqrt{\nu_t^\top S_t^{-1}\nu_t}.
```

在标定集上分别收集 `m_t^{lat}`、`m_t^{KF}`，用 split conformal 取 `q_{1-\alpha}`：

```math
q_{1-\alpha} = \mathrm{Quantile}_{\lceil(n+1)(1-\alpha)\rceil/n}\left(\{m_i\}_{i=1}^n\right).
```

于是 `m_t > q_{1-\alpha}` 的误报率约 `\alpha`（可交换假设）。按任务族做 Mondrian conformal：刚体插入、悬挂、叠放、拉链/锁、变形各自一个 `q`。

**分类规则**（确定性，不学第二个分类器）：

| 条件 | 判定 | 控制动作 |
|---|---|---|
| `m^{lat}` 大，残差方向与动作一致，`d_t` 接近 0 | 接触 | 法向降增益，切向保留 |
| `m^{lat}` 大，残差在夹爪系切向，`r_grasp` 突变 | 滑移 | 停止切向，增夹持，重抓 |
| `m^{lat}` 大，残差与动作无关，持续 >3 帧 | 人为编辑/目标移动 | 停 → 重定位 → 重规划 |
| `m^{KF}` 大，`m^{lat}` 正常，残差随视角变化 | 遮挡/反光/坏测量 | 鲁棒膨胀 `R`，降增益 |
| 两者都正常 | 正常 | 正常伺服 |

**鲁棒更新**：

```math
R_t^{eff} = R_t\cdot\max\left(1,\ \frac{(m_t^{KF})^2}{q_{1-\alpha}}\right),
```

或 Huber 权重 `w_t=\min(1,q/m_t^2)`。这样单个坏测量不会把滤波器拉走。

### 2.6 机会约束与增益调度

控制律：

```math
a_{cmd}=a_{ff}\circ\exp(\Delta),\qquad
\Delta=\mathrm{clip}\left(K(\Sigma_t,\tau_t)e_t,\ \pm\delta_p,\ \pm\delta_r\right).
```

其中 `a_{ff}` 是 VLA 的 30 步 plan 在当前 5 步块的相对动作，`e_t` 由信念均值解码。

**机会约束**：

```math
\mathbb P\left(\|e_{t+1}\|\le\varepsilon\mid b_t\right)\ge 1-\delta.
```

若 `e_{t+1}\approx e_t+\Delta+\epsilon`，`\epsilon\sim\mathcal N(0,\Sigma_t)`，则

```math
\|e_t+\Delta\|+\sqrt{\chi^2_{n,1-\delta}\,\lambda_{\max}(\Sigma_t)}\le\varepsilon.
```

实现时用保守近似 `\lambda_{\max}(\Sigma_t)\le\mathrm{tr}(\Sigma_t)`：

```math
\|\Delta\|\le \max\left(0,\ \varepsilon-\|e_t\|-\sqrt{\chi^2_{n,1-\delta}\mathrm{tr}(\Sigma_t)}\right).
```

若上界为 0，则不修：保持/降速/请求 VLA。**不确定时少修**不是拍脑袋，而是约束。

**增益调度**（工程近似）：

```math
K(\Sigma_t,\tau_t)=\frac{K_0}{1+\beta\,\mathrm{tr}(\Sigma_t)/\sigma_0^2+\tau_t/\tau_0},
```

取 `\beta\in[0.5,2]`，`\sigma_0` 是任务族的中位位置标准差，`\tau_0=50` ms；并设下限 `K\ge 0.25K_0`，避免完全不修。

### 2.7 安全对偶试探

当任务相关方向的后验方差高、且夹爪离目标大于安全距离时，控制动作可以同时是**信息动作**。定义有限试探字典：

```math
\mathcal H=\{\pm\eta_x,\pm\eta_y,\pm\eta_z,\pm\eta_{rx},\pm\eta_{ry}\},
\qquad
\|\eta\|\le 2\text{ mm},\ \|\eta_r\|\le 0.01\text{ rad}.
```

对每个 `\eta`，用局部线性化估计信息增益：

```math
I(\eta)\approx \frac12\log\det\left(I+\Sigma_t^{-1}J_\eta^\top R^{-1}J_\eta\right),
```

选择：

```math
\eta^\star=\arg\max_{\eta\in\mathcal H}
\left[I(\eta)-\lambda\,\mathrm{cost}(\eta)\right],
```

约束：

1. `d_t>d_{safe}`（自由空间，未接触）；
2. `\sigma_t>\sigma_{probe}`（确实不确定）；
3. 接触段、滑移、编辑、低延迟余量时禁止；
4. 连续试探 ≤2 次；每次后重新估计，若方差没降就停；
5. 试探不改变任务意图：`\eta` 加在 VLA 前馈的零空间/安全方向，或作为小幅偏移后回到原计划。

这是「闭环控制」与「状态估计」的耦合点：**为了看得更准而动，而不是为了动而动**。

### 3.1 进程/端口拓扑

                                   │ websocket: obs / action chunk

                    │  ├─ plan cache (30-step VLA plan)   │

### 3.3 状态机

```text
INIT ──first obs──▶ PLAN ──plan ready──▶ SERVO
  ▲                   ▲                    │
  │                   │                    ├─ d_t < d_c ──▶ CONTACT
  │                   │                    │                 │
  │                   │                    │                 └─ contact released ──▶ SERVO
  │                   │                    │
  │                   │                    ├─ σ_t > σ_probe & d_t > d_safe ──▶ PROBE
  │                   │                    │                                   │
  │                   └── replan ◀── RECOVER ◀── surprise > q ────────────────┘
  │                                      │
  └──────────────────────────────────────┘
任意状态 ──task success / max steps / unsafe──▶ DONE
```

- `SERVO`：低 surprise、低协方差；PBVS 主导，IBVS 辅助。
- `CONTACT`：`d_t < d_c` 或 surprise 被动作解释；法向增益 `0.3–0.5`、低通；切向保留。
- `PROBE`：高协方差 + 自由空间；小幅信息动作；最多 2 次。
- `RECOVER`：高 surprise 且动作解释不了；停 → 头双目重定位 → 目标可见则更新 goal，否则 VLA 重规划。
- `DONE`：清理状态，等待 `reset()`；绝不跨端口共享。

### 3.4 在线伪代码

```python
class SilkPolicy:
    def __init__(self, vla, observer, kf, goal_db, config):
        self.vla = vla
        self.obs = observer
        self.kf = kf
        self.goal_db = goal_db
        self.cfg = config
        self.reset()

    def reset(self):
        self.plan = None
        self.plan_idx = 0
        self.kf.reset()
        self.goal = None
        self.mode = "INIT"
        self.action_buf = []
        self.obs_buf = []
        self.probe_count = 0

    def get_action(self, obs, meta):
        self._check_token(meta)
        self._push_obs(obs)
        self._maybe_request_plan(obs)

        z, y_ssl, sigma_ssl = self.obs.encode(obs)       # Layer 1
        self.kf.predict(self.action_buf[-1] if self.action_buf else 0)
        m_lat = self.obs.surprise(z)
        if self._delayed_measurement_ready():
            y_meas = self._delayed_measurement()
            m_kf = self.kf.innovation(y_meas)
            self.kf.robust_update(y_meas, m_kf, self.cfg.q_kf)
        mystery = max(m_lat / self.cfg.q_lat, m_kf / self.cfg.q_kf)

        theta, Sigma = self.kf.belief()
        self.goal = self.goal_db.retrieve(obs, self.plan, self.goal)
        e, Sigma_e = self._decode_error(theta, Sigma, self.goal)

        self.mode = self._select_mode(mystery, e, Sigma_e, self.goal)
        if self.mode == "CONTACT":
            e, Sigma_e = self._contact_damping(e, Sigma_e)
        if self.mode == "PROBE" and self._probe_allowed(Sigma_e):
            eta = self._select_probe(Sigma_e)
            self.probe_count += 1
        else:
            eta = 0.0

        Delta = self._chance_clipped_gain(e, Sigma_e, self.cfg.tau)
        Delta = self._clip(Delta + eta, self.cfg.delta_p, self.cfg.delta_r)
        a_ff = self._next_plan_chunk()
        a_cmd = compose_relative(a_ff, Delta)
        self.action_buf.append(a_cmd)
        self.plan_idx += self.cfg.H_c
        if self.plan_idx >= len(self.plan or []):
            self._request_replan()
        return self._to_api(a_cmd, obs, self.cfg.token)

    def _select_mode(self, mystery, e, Sigma_e, goal):
        if mystery > self.cfg.q_edit and not self._explained_by_action():
            return "RECOVER"
        if self._contact_detected(e, Sigma_e):
            return "CONTACT"
        if self._probe_allowed(Sigma_e):
            return "PROBE"
        return "SERVO"
```

关键规则：

- VLA 永不阻塞 `get_action`（除冷启动）；plan 过期就用旧 plan + 信念伺服。
- 每个 chunk 只做一次滤波/伺服；异常 → 返回上一组合法 chunk 或安全 hold；绝不返回 NaN/错误形状。
- 所有阈值来自离线保形校准 + 单任务通道；不在正式评测里在线调参。

## 4. 自监督观测器

### 4.1 输入与编码器

- 四路 RGB 缩放到 240×320（头）和 160×160（腕）；`cam_right_high` 只用于双目/几何，不一定要进 VLA。
- 本体：EE 位姿（xyz+rpy → 旋转矩阵/rot6d）、关节、夹爪、下身体；语言用任务 embedding 或固定 prompt。
- 编码器选择：
  - **C3 主推**：复用 WLA 的 VLM encoder；对四路图做 token 化，加一个 4 层 cross-view fusion transformer（4×64 tokens），输出 `z_t`。辅助头 20–60M 参数；VLM 冻结。
  - **C1 回退**：独立小 ViT-S/CNN（5–15M），只在离线训练；线上只保留其输出的校准表/伪标签，不加载权重。
- 输出：
  - `z_t ∈ R^{256}`；
  - `D_ψ(z_t) = (x_t^{SSL}, \Sigma_t^{SSL})`；
  - `g_θ(z_t, a_{t:t+k})` 用于 surprise；
  - `h_θ(z_t,z_{t+1})` 用于逆动力学（仅训练）。

### 4.2 训练细节

| 项 | 设计 |
|---|---|
| 数据 | 33,276 episodes；按 session/物体/背景分组；相邻帧不跨 split |
| 片段 | 长度 32（约 1.07 s）；随机起点；每任务等比例采样 |
| 批大小 | 256 clips（C3 冻结 encoder 时可更大） |
| 增强 | 颜色抖动、模糊、cutout、帧 dropout、随机缩放/裁剪；**不做水平翻转**（破坏左右/几何） |
| 负样本 | 其他 episode/任务；同任务不同物体；避免只用同任务负样本 |
| 优化 | AdamW，lr 1e-4（头），cosine，warmup 5%；bf16 |
| 时长 | 单张 24 GB GPU，1–2 GPU 天/任务族；全 32 任务可共享 backbone |
| 监控 | 有效秩、特征方差、正/负余弦相似度、线性探针位姿误差、surprise AUROC |

**防塌缩**：

- 时序对比 + stop-gradient/EMA target；
- 逆动力学 + 多 horizon 预测提供非平凡监督；
- 方差/协方差正则；
- 每 epoch 计算有效秩 `\exp(\mathrm{entropy}(\lambda_i/\sum\lambda_i))`，低于阈值即报警；
- 线性探针：用冻结 `z_t` 预测 `T_target`/接触，若探针不升，说明表示没保住任务信息。

### 4.3 度量锚定

几何管线 `\Pi_{stereo}` 给出 `x_t^{geo}`：

```math
x_t^{geo} = \Pi_{stereo}\left(I_t^{LH}, I_t^{RH}, q_t\right),
```

其协方差 `R_t^{geo}` 由重投影误差、视差有效性、ROI 内点数估计：

```math
R_t^{geo} = J_\Pi\,\mathrm{Cov}(\text{reproj})\,J_\Pi^\top + \sigma_{cal}^2 I.
```

SSL 读出 `D_ψ(z_t)` 用几何估计做伪标签训练：

```math
\mathcal L_{anchor}
= \left\|D_\psi(z_t)-x_t^{geo}\right\|_{R_t^{geo}}^2
+ \frac12\log\det\Sigma_t^{SSL}.
```

注意：这不是「用第二个学习模型监督」，而是用**确定性几何管线**给同一表示提供度量锚；几何失效时 `R_t^{geo}` 很大，锚定自然变弱。

### 4.4 可选测试时自适应（默认关闭）

若新机器人/新相机导致表示漂移，可只更新 LayerNorm/线性读出的仿射参数，目标是最小化最近 `K=30` 帧的 latent 预测误差：

```math
\min_{\gamma,\beta}\ \sum_{i=t-K}^{t}\left\|z_i-g_\theta(z_{i-1},a_{i-1})\right\|^2,
```

约束 `\|\gamma-1\|_\infty\le0.1`、`\|\beta\|_\infty\le0.1`；不更新动作头；默认关闭，需 G7 合规确认。若官方认为在线更新也算模型变化，则完全禁用，只用离线校准。

## 5. 状态估计器

### 5.1 延迟增广 KF

实现细节：

- 状态 `θ_t = [e_t(6); \dot e_t(6)]`，`n=12`；接触标量可扩展到 `n=13`。
- `F`：常速度模型，`e_{t+1}=e_t+dt\,\dot e_t`，`\dot e_{t+1}=\dot e_t`；`G` 把 EE 动作映射到 `e` 的增量。
- `Q`：位置 `(0.1–0.5 mm)^2`，速度 `(1–5 mm/s)^2`；接触时位置 `Q` 放大 2–5 倍，反映未建模柔顺。
- `R^{SSL}`：来自 `Σ_t^{SSL}`；`R^{geo}`：来自重投影/视差。
- 延迟 `d`：状态增广；`d` 由时间戳估计，`d∈[0,10]`；若 `d` 变化，重建增广状态（用历史 buffer）。
- 数值：Joseph 形式更新 `P=(I-KH)P(I-KH)^\top+KRK^\top`；每 100 步检查对称正定；协方差用 Cholesky。
- 发散保护：若 `tr(P)` 超过阈值或新息连续 `>q`，重置滤波器到几何先验，并标记 `RECOVER`。

### 5.2 噪声估计

- `R^{SSL}`：异方差头输出 `\log\sigma^2`；用 NLL 训练；按任务族做温度缩放/保形校准。
- `R^{geo}`：重投影误差的鲁棒估计（MAD）；视差有效像素 <70% 时膨胀 4–10 倍；腕部无内参时只用头双目。
- `Q`：离线用演示的预测残差拟合；在线用新息的自协方差做小幅调整（限制在 0.5–2 倍）。
- 延迟不确定性：`Q += (0.5\,dt\,\dot e)(0.5\,dt\,\dot e)^\top`，反映 `d` 估计误差。

### 5.3 surprise 与接触/滑移

- `m^{lat}`：Layer 1 的预测残差；对接触/滑移/编辑最敏感。
- `m^{KF}`：Layer 2 的测量新息；对遮挡/反光/坏测量最敏感。
- 阈值：按任务族 Mondrian conformal；`α=0.05`（误报 5%）或 `α=0.01`（保守）。
- 分类：查表 §2.5；不做第二个学习分类器。
- 时间平滑：surprise 用 2–3 帧中值滤波，避免单帧噪声触发；编辑检测要求连续 3 帧超阈。
- 接触概率：`p_c = sigmoid(a_0 + a_1(d_c-d_t) + a_2 m^{lat} + a_3 r_{grasp})`；系数离线拟合，属于确定性控制器参数，不是学习模型。

### 5.4 协方差传播到任务空间

由 `θ_t` 到 `e_t` 的雅可比 `J_e`：

```math
\Sigma_t^e = J_e\,\Sigma_t\,J_e^\top.
```

机会约束用 `\Sigma_t^e` 的迹/最大特征值；增益调度用 `tr(\Sigma_t^e)`。若 `Σ` 很大但 `e` 很小，控制器仍会变保守——这是有意的：**不确定时不要因为「看起来快到了」就猛修**。

### 5.5 延迟估计

- 时间戳：每次 `get_action` 记录发送/接收时间；`τ_t = t_{recv}-t_{send}` 的 EMA。
- 图像时间戳不可得时，用动作-观测互相关：对最近 1 s 的动作范数与视觉残差做互相关，峰值为 `τ`。
- `d_t = round(τ_t f_c)`；`f_c` 未在 README 写死，必须单任务通道实测（默认 30 Hz）。
- 若 `τ_t` 抖动 >30 ms，`Q` 膨胀、增益降档、必要时回退 chunk 8–10。

## 6. 闭环控制器

### 6.1 前馈 + 反馈

```math
a_{cmd}=a_{ff}\circ\exp(\Delta),\qquad
\Delta=\mathrm{clip}\left(K(\Sigma_t,\tau_t)e_t,\ \pm\delta_p,\ \pm\delta_r\right).
```

- `a_{ff}` 来自 VLA 30 步 plan 的当前 5 步块；adapter 先 compose 成 base 系绝对位姿，再叠加 `\Delta`。
- `\Delta` 默认在 EE 局部系右乘；若用 base 系误差则左乘；全报告统一右乘，避免歧义。
- `δ_p=1` cm/块，`δ_r=0.05` rad/块；接触段 `δ_p` 降到 3 mm、`δ_r` 降到 0.02 rad。

### 6.2 增益调度

```math
K(\Sigma_t,\tau_t)=\frac{K_0}{1+\beta\,\mathrm{tr}(\Sigma_t^e)/\sigma_0^2+\tau_t/\tau_0},
```

- `K_0` 由仿真阶跃 + 真机小步辨识；`β=1` 起步；`σ_0` 取任务族中位位置标准差；`τ_0=50` ms。
- 下限 `0.25K_0`；上限 `1.5K_0`（低不确定、低延迟时可略激进）。
- 接触段：法向 `K_n=0.3K`，切向 `K_t=K`；法向一阶低通 `α=0.2`。
- 滑移：切向 `K_t=0`，夹持 +10–20%，重抓；恢复后 `K_t` 渐进恢复。

### 6.3 机会约束实现

```python
def chance_clipped_gain(e, Sigma_e, cfg):
    tr = np.trace(Sigma_e)
    radius = math.sqrt(chi2.ppf(1 - cfg.delta, df=6) * tr)
    budget = max(0.0, cfg.epsilon - np.linalg.norm(e) - radius)
    delta = cfg.K0 @ e
    if np.linalg.norm(delta) > budget:
        delta = delta * (budget / (np.linalg.norm(delta) + 1e-9))
    return clip(delta, cfg.delta_p, cfg.delta_r)
```

- `ε`：任务相关容差（插入 2–3 mm，悬挂 5 mm，叠放 3 mm）；由任务/阶段给定。
- 若 `budget=0`：不修，返回 `HOLD` 或降速；连续 3 块为 0 → `RECOVER`/重规划。
- 该实现是保守近似（用 `tr` 代替 `λ_max`），保证不低估不确定度。

### 6.4 安全对偶试探

- 触发：`σ_t>σ_probe`（如位置标准差 >1.5 mm）、`d_t>d_safe`（>1 cm）、`mode=SERVO`、`probe_count<2`。
- 字典：±x、±y、±z、±rx、±ry，幅度 1–2 mm / 0.005–0.01 rad；z 方向仅在插入轴不确定时用。
- 信息增益：局部线性化 `J_η`；若无法估计 `J_η`，用有限差分：执行 `η` 后比较 `tr(Σ)` 的下降。
- 成本：`cost(η)=||η||/η_max + 0.5*[接触风险] + 0.2*[时间]`；`λ` 由仿真扫。
- 安全：不接触、不靠近人、不靠近易碎物；超时/异常立即回退；试探后必须回到原 VLA 计划附近（零空间或小幅偏移）。
- 若 G3 显示试探无收益或超时增加，直接关闭（消融）。

### 6.5 接触/滑移/编辑

沿用第 11 轮信号，但阈值改为保形校准：

| 信号 | 判定 | 动作 |
|---|---|---|
| `d_t > d_far` | 自由接近 | PBVS，正常增益 |
| `d_far ≥ d_t > d_c` | 预接触 | PBVS + IBVS，降速 |
| `d_t ≤ d_c` | 接触 | 法向缩幅/低通，切向保留 |
| `r_grasp` 突变 | 滑移 | 停切向，增夹持，重抓 |
| `r_static` 大、`r_grasp` 小 | 已夹住 | 搬运，正常闭环 |
| `m^{lat}>q` 且动作解释不了 | 编辑 | 停 → 重定位 → 重规划 |
| `m^{KF}>q` 且 `m^{lat}` 正常 | 遮挡/反光 | 鲁棒膨胀 R，降增益 |
| `tr(P)` 超阈/连续新息 | 滤波发散 | 重置到几何先验，RECOVER |

## 7. 自监督腕部标定

腕部相机没有内参。用已知 EE 运动 + 头双目做自监督标定：

1. 在演示中选腕部与头部同时看到同一局部区域的时间窗；
2. 用头双目三角化 3D 点 `X_i`（或已知物体尺寸/平面）；
3. 在腕部图追踪对应特征 `u_i`；
4. 优化：

```math
\min_{K_w,T_w}\ \sum_i \rho\left(\left\|\pi(K_w,T_w,X_i)-u_i\right\|^2\right)
+\lambda_{reg}\left(\|K_w-K_w^0\|^2+\|T_w-T_w^0\|^2\right),
```

其中 `ρ` 是 Huber；`K_w^0,T_w^0` 是 D435 型号先验/URDF 安装先验。
5. 由 Hessian 得到参数协方差；重投影 >5 px 或协方差过大 → 不用腕部 IBVS，只用头双目 PBVS。
6. 每个机器人/每次换相机做一次；结果写入只读标定表。

这是「自监督」的另一种用法：不需要棋盘格/人工标签，用时序 + 跨视角一致性；但它是**离线标定**，不是在线学习模型。

## 8. 演示目标库（继承 CHUNK-SERVO）

### 8.1 离线

对每个任务/阶段/关键帧 `k`：

```text
T_base_target(k)  # 受器在 base 系
T_base_ee(k)      # 夹爪在 base 系
T_target_ee*(k) = inv(T_base_target(k)) @ T_base_ee(k)
I_wrist(k)        # 腕部目标图
d(k)              # 描述子（ORB/颜色/同 checkpoint 特征）
Σ_target(k)       # 目标位姿协方差/检索置信度
```

### 8.2 在线

```text
candidates = index.filter(task, phase)
candidates = candidates.rerank(pose_prior=T_target_ee_prior, top=50)
topk = candidates.topk(descriptor_distance, k=5)
goal = rerank(topk, pose_consistency, image_quality, phase, Σ_target)
if goal.confidence < θ_c:
    fallback: geometry-only / VLA open-loop
```

- 任务/阶段过滤优先于外观；避免「插网线」匹配到「拔网线」。
- 目标现在带协方差：`Σ_goal` 进入 `e_t` 的协方差传播；检索不确定时控制器自动保守。
- top-k 重打分包括：描述子距离、相对位姿一致性、目标图清晰度、相位置信度、标定协方差。
- 规模：A 档 19 任务约 19k episodes，每 episode 1–2 个关键帧 → 20–40k 目标；128×128 JPEG 5–10 KB → 200–400 MB；描述子 40–80 MB；索引 <100 MB；总 <1 GB，可随提交包分发或预加载。

## 11. 正确性论证

### 11.1 延迟增广 KF 的等价性

**命题 1**：对线性高斯系统 `θ_{t+1}=Fθ_t+Ga_t+w_t`，测量 `y_t=Hθ_{t-d}+v_t`，状态增广 `X_t=[θ_t;\dots;\theta_{t-d}]` 后的标准 KF，与「先对 `θ_{t-d}` 做测量更新、再用已知动作前向传播到 `t`」的全信息滤波，具有相同的后验均值与协方差。

**证明思路**：增广系统是 Markov 的；`H` 选出 `θ_{t-d}`；标准 KF 的更新等价于在增广联合高斯上做条件化。前向传播只使用已知动作，不引入新信息；因此两种计算是同一贝叶斯后验的两种结合律。∎

**推论**：CHUNK-SERVO 的「用旧测量直接算当前误差」是命题 1 的近似（忽略 `F`/`Q` 与交叉协方差）；SILK 用精确版本，因此在延迟下更稳。

### 11.2 保形覆盖率

**命题 2**（split conformal）：若标定残差 `m_1,\dots,m_n` 与测试残差 `m_{n+1}` 可交换，取 `q` 为 `\lceil(n+1)(1-\alpha)\rceil/n` 分位数，则

```math
\mathbb P\left(m_{n+1}\le q\right)\ge 1-\alpha.
```

**证明思路**：秩的均匀性；标准 split conformal 结论。∎

**注意**：跨任务/跨机器人不满足可交换；用 Mondrian（按任务族/机器人分组）分别校准，报告每组覆盖率。若组内样本少，用保守的 `q` 或层次模型。

### 11.3 机会约束缩放

**命题 3**：若 `e_{t+1}\sim\mathcal N(\mu,\Sigma)`，则

```math
\mathbb P\left(\|e_{t+1}\|\le\varepsilon\right)\ge 1-\delta
```

的一个充分条件是

```math
\|\mu\|+\sqrt{\chi^2_{n,1-\delta}\lambda_{\max}(\Sigma)}\le\varepsilon.
```

**证明思路**：`\|e\|^2` 是高斯二次型；`\|e\|^2\le r^2` 的概率由 `\chi^2_n` 分位数控制；用 `\|\mu\|` 的三角不等式与 `\lambda_{\max}` 放缩。∎

**实现**：用 `tr(\Sigma)` 代替 `\lambda_{\max}` 更保守；若约束不可行，则 `\Delta=0` 或降速；这保证「不确定时不猛修」。

### 11.4 稳定性

一阶离散延迟闭环：

```math
e_{k+1}=e_k-KH_c e_{k-d}.
```

特征方程：

```math
z^{d+1}-z^d+KH_c=0.
```

- `d=0`：`|1-KH_c|<1` → `0<KH_c<2`。
- `d=1`：`z^2-z+KH_c=0`；稳定域 `0<KH_c<1`；增益裕度约减半。
- `d=2`：稳定域更小；必须降增益/预测。
- SILK 用前向预测把有效 `d` 降到「延迟估计误差」；用 `K(\Sigma,\tau)` 在 `τ` 增大时降增益；因此稳定域随延迟移动，而不是固定增益硬扛。

**注意**：这是线性化分析；接触/柔顺/摩擦会改变有效增益，必须 G3 真机验证。

### 11.5 自监督的可辨识性（假设，不是定理）

- 逆动力学 `h(z_t,z_{t+1})≈a_t` 迫使 `z` 保留可控自由度；
- 多 horizon 预测迫使 `z` 保留任务相关动力学；
- 时序对比防止塌缩；
- 跨视角预测提供几何约束；
- 度量锚定 `D_ψ` 解决尺度。

但纯自监督仍可能保留任务无关因素（光照、背景）或丢失接触细节。G1 用线性探针/位姿误差/接触 AUROC 检验；不过门就退回几何点估计 + 手工阈值。

### 11.6 单模型合规

- 一个 checkpoint：VLM + 动作头 + 辅助观测头；辅助头不输出动作，只输出状态/协方差/surprise。
- 控制器：确定性几何/控制律；阈值来自保形校准，不是第二个学习策略。
- 若官方要求「模型只能有一个输出头」：回退 C1，观测器只离线；线上确定性 KF + 几何 + 标定表。
- 提交材料写清楚：辅助头的作用、无第二策略、控制器无学习权重；请求官方书面确认。

1. SSL 目标：full vs no `L_dyn` vs no `L_inv` vs no `L_cv` vs no `L_nll`。
2. 状态估计：KF vs 点估计；延迟增广 vs 无；鲁棒更新 vs 无。
3. 不确定性：固定增益 vs `K(Σ,τ)`；机会约束 vs 无。
4. surprise：保形阈值 vs 固定阈值；latent vs KF vs 两者。
5. 对偶试探：on/off；字典大小；安全距离。
6. 合规：C3 共享头 vs C1 离线观测器（性能/延迟/合规）。
7. 目标库：top-1 vs top-5 rerank；带/不带 `Σ_goal`。
8. 任务组合：`q×Δ/cost` vs `q×u×Δ/cost`。

## 13. 数值仿真结果（B 级，toy）

### 13.1 设置

为了在写代码前先验证「延迟增广 + 信念调度」是否值得做，搭了一个最小 1D 横向对齐 toy：

- 状态：`[p, v]`，`p` 是横向误差（mm），`v` 是速度（mm/s）；`dt=1/30 s`；
- 动力学：`p_{k+1}=p_k+dt v_k`，`v_{k+1}=a v_k+(1-a)u_k`，`a=e^{-dt/0.15}`；`u` 是速度指令，限幅 ±80 mm/s；
- 初始误差 `p_0~N(0,4 mm)`；`t=0.8 s` 时目标阶跃 +3 mm（模拟目标移动）；
- 测量：`y=p+noise`；标称 `σ=0.4 mm`；压力测试 `σ=1.5 mm` + 5% 的 +5 mm 离群点；
- 控制器：
  - **baseline**：用延迟 `d` 步的测量做有限差分 + EMA 速度估计，固定 `K_p=2.5,K_d=1.0`；
  - **KF**：延迟增广卡尔曼，固定同增益；
  - **SILK**：KF + `K(Σ)` 不确定性缩放（`var_ref=1 mm²`，地板 0.5）；
- 每场景 300 个 Monte Carlo episode，paired seeds；指标：末态误差、扰动后最大误差、调节时间、失败率（`max|p|>10 mm` 或 `final|p|>1 mm`）。

这是**控制/估计层的最小验证**，不是机器人仿真；它不能证明真机成功率，只用于检查延迟补偿是否方向正确。

### 13.2 结果：延迟补偿是主要收益

**标称噪声 `σ=0.4 mm`，无离群点**

| 控制器 | `d=0` 失败率 | `d=3` (100 ms) | `d=6` (200 ms) | `d=9` (300 ms) |
|---|---:|---:|---:|---:|
| baseline（延迟点估计） | 1.0% | 1.0% | **30.7%** | **65.3%** |
| KF（延迟增广） | 1.0% | 1.0% | **1.0%** | **1.0%** |
| SILK（KF+不确定性） | 1.0% | 1.0% | 1.0% | 1.0% |

末态误差（mm）：

| 控制器 | `d=0` | `d=3` | `d=6` | `d=9` |
|---|---:|---:|---:|---:|
| baseline | 0.190 | 0.240 | 0.875 | 1.526 |
| KF | 0.275 | 0.332 | 0.390 | 0.453 |
| SILK | 0.275 | 0.332 | 0.390 | 0.454 |

**压力测试 `σ=1.5 mm` + 5% +5 mm 离群点**

| 控制器 | `d=0` 失败率 | `d=6` 失败率 | `d=9` 失败率 |
|---|---:|---:|---:|
| baseline | 12.3% | 56.0% | 63.3% |
| KF | 1.0% | 1.3% | 3.7% |
| SILK | 1.0% | 1.3% | 4.3% |

**解读**：

- 在 `d=0..3`（0–100 ms），baseline 与 KF 都能稳定；KF 的调节时间更长（因为滤波平滑），但失败率相同。
- 在 `d=6..9`（200–300 ms），baseline 开始失稳；延迟增广 KF 把失败率从 30.7%/65.3% 降到 1.0%/1.0%，这是本轮最硬的数值证据。
- SILK 的不确定性缩放本 toy 中几乎不改变结果：因为标称 `Σ` 多数低于 `var_ref`，缩放没触发；压力测试中缩放只带来轻微差异（`d=9` 3.7%→4.3%）。**这说明本 toy 只验证了延迟估计，不足以验证接触段的不确定性调度**；后者必须靠接触/遮挡仿真和真机 G3/G4。
- `d=0` 时 KF 比 baseline 慢，是滤波平滑的代价；实际部署可在低延迟、低不确定时提高 `K_0` 或用 `K(Σ)` 的上限 `1.5K_0` 补偿。

### 13.3 结果：保形 surprise 可校准、可检测

固定 `d=3`，标称 `σ=0.4 mm`，标定 400 episodes（28,800 个新息），测试 200 episodes：

| 项 | 数值 |
|---|---:|
| `q_{0.95}` | 3.094 |
| `q_{0.99}` | 5.250 |
| 标称误报率（q95） | 5.3% |
| 标称误报率（q99） | 1.1% |
| 目标阶跃 +3 mm 检测率（200 ms 内） | 100% |
| 平均检测延迟 | 90.3 ms |

这说明：**不需要失败标签**，只用标定 episode 的新息分布，就能得到一个误报率可控、检测延迟 <100 ms 的 surprise 阈值。它可以直接驱动机器人的 `RECOVER`，也可以用来给 `R` 做鲁棒膨胀。

### 13.4 结果：鲁棒更新在坏测量下减少偏差

固定 `d=3`，在 `0.6–1.1 s` 注入 +8 mm 测量偏差（模拟反光/遮挡造成的持续坏测量），200 episodes：

| 更新方式 | 偏差期间最大 `|p|` | 偏差后最大 `|p|` | 末态 `|p|` |
|---|---:|---:|---:|
| 非鲁棒 KF | 3.160 mm | 3.965 mm | 0.664 mm |
| 鲁棒 KF（保形门控） | **1.904 mm** | 3.692 mm | 0.984 mm |

鲁棒门控把偏差期间的误差从 3.16 mm 降到 1.90 mm；代价是偏差后恢复略慢（末态 0.98 vs 0.66 mm）。这符合预期：门控拒绝坏测量，滤波器更多依赖模型，短期更稳、长期需要重新捕获。真机上应结合 `RECOVER` 重定位，而不是只靠滤波器。

### 13.5 局限

- 1D 线性高斯，不是接触/柔顺/摩擦；不能外推到 6D 位姿/透明物体。
- 未模拟 VLA 前馈、目标检索、腕部标定误差、图像噪声；这些会放大不确定性。
- 未验证对偶试探；它需要 2D/3D 仿真和真机安全测试。
- 增益未按控制器分别调优；绝对数值只用于相对比较。
- 结论只支持「延迟增广值得做」「保形 surprise 可校准」；不支持「SILK 一定涨点」。

## 14. 风险与合规

### 14.1 风险表

| 风险 | 影响 | 缓解 | 门 |
|---|---|---|---|
| 自监督表示塌缩/走捷径 | 隐状态只编码背景/光照 | 跨视角、逆动力学、episode 负样本、有效秩监控 | G1 |
| 隐状态没有度量尺度 | 伺服方向对、幅度错 | 头双目 + EE 位姿锚定；协方差大时降增益 | G1/G2 |
| 接触段线性高斯失效 | 滤波器发散/滞后 | 接触/非接触双模型；鲁棒膨胀；真机验证 | G3 |
| 保形可交换性违反 | 误报率超标 | Mondrian 按任务族/机器人；在线更新阈值；报告覆盖率 | G2 |
| 官方不暴露 encoder | C3 不可行 | C1 离线观测器 + 确定性 KF；不加载第二模型 | G7 |
| 在线自适应漂移 | 行为不可复现 | 默认关闭；只允许 LayerNorm/线性读出小步更新 | G7 |
| 延迟非平稳 | 预测失准 | 时间戳缓冲；Q 膨胀；p99 监控；回退 chunk 8 | G6 |
| 试探动作影响任务 | 碰撞/超时 | 仅自由空间、≤2 mm/0.01 rad、最多 2 次、接触段禁止 | G3/G5 |
| 目标检索 mismatch | 错误目标 | 任务/阶段过滤；top-k 重打分；协方差大回退 | G1 |
| 透明/反光/变形 | 深度/特征失败 | 不硬做 IBVS；用头双目/隐状态先验；协方差放大 | G0/G3 |
| 标定漂移/换机器人 | 残差变大 | 每机器人一次重标定；夹爪 PnP 自标定；误差大关伺服 | G0 |
| 评测噪声 | +1–2pp 假阳性 | 配对 A/B、bootstrap、重复实验；320 trials SE≈2.4pp | G4 |
| 数据泄漏 | 离线指标虚高 | 按 session/物体/背景分组；相邻帧不跨 split | G1 |
| 算力/延迟 | 30 Hz 跟不上 | 低分辨率；共享 encoder；辅助头 ≤10 ms；必要时 C1 | G6 |

### 14.2 合规论证

- **一个模型**：VLM + 动作头 + 辅助观测头，同一 checkpoint；辅助头不产生动作。
- **一个策略**：动作只来自 VLA plan + 确定性伺服；观测器不参与动作生成，只提供状态/协方差/surprise。
- **确定性控制器**：增益、机会约束、试探字典、阈值都是几何/控制/校准参数，不是学习策略。
- **回退**：若官方认为辅助头/在线更新不合规，切 C1：观测器只离线，线上确定性 KF + 几何 + 标定表；性能下降但合规。
- **材料**：提交时附「模型结构图、辅助头作用、无第二策略声明、控制器参数来源、官方确认邮件」。

### 14.3 本轮最大风险

**自监督隐状态在接触瞬间既不可度量也不可校准，控制器却带着错误的置信度做闭环；因此 G1 的度量锚定与 G2 的保形校准是生死门，任一不过就退回 CHUNK-SERVO 的几何伺服。**
