# 第 10 轮（新灵感循环第 1 轮；本轮灵感：「场景落地」×「比赛策略」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**落地即标定 + 策略即约束**。两个灵感分别治理 v9 的两个悬空假设：落地债（前向模型误差 β 靠离线标定，现场分布漂移后静默失效）与目标债（系统只优化"安全通过"，不回答"这场比赛该怎么赢"）。硬约束：通过**现场在线标定**替换固定 β、通过**策略-安全联合预算**把追分限制在安全包络内；任一策略/落地模块失效 ⇒ 注入中立元，严格退回 v9，绝不让策略成为安全的必要条件。

## 0. 直觉与动机

**灵感 1（场景落地 → 现场即标定）**
直觉：v9 的分块证书把安全性寄托在"信任域内前向模型误差 ≤ β"，但 β 是赛前标定的常数。真实赛场的光照、地面摩擦、传感器老化、电池电压跌落会让它悄悄失效——v9 自认的最大风险正是"Δ_dom 滑窗滞后，块证书在最需要安全时最不可靠"。落地的正确姿势不是"部署一个固定系统"，而是"部署一个会自我标定的系统"。核心创新 1：**现场残差监测器（FieldResidualMonitor, FRM）**：每步用真实观测与冻结前向模型的预测做残差，以共形预测（conformal prediction）维护误差上界 β̂(t)，直接替换 DA-ML 的滞后滑窗作为信任域判据；漂移由残差 CUSUM 触发窗口重置。核心创新 2：**场景部署编译器（ScenarioDeploymentCompiler, SDC）**：把抽象能力/契约表编译成某台机器人、某块场地的现场配置并签发**部署证书** d_cert。直觉：让系统在"最需要安全的时刻"用自己的现场数据说话，而不是拿赛前的一张纸。

**灵感 2（比赛策略 → 策略即约束优化）**
直觉：比赛不是"安全地做完所有事"，而是"在有限时间与风险下拿最高分"。策略本质是一个带机会约束的序贯决策：选任务组合、决定何时弃权、把安全裕度当作可交易的预算。核心创新 3：**比赛策略规划器（MatchStrategyPlanner, MSP）**：以"单位时间期望得分"为目标、以"整场安全违背概率 ≤ δ_match 且超时概率 ≤ ε_time"为硬约束，在线求任务组合与弃权阈值；用双阈迟滞避免任务切换抖动。关键纪律：策略只能在安全包络内交易，不能把 δ 当可无限放松的旋钮——**P14 策略不越安全包络律**。

**灵感 3（合流 → 策略-安全联合预算）**
直觉：落地给策略提供"可信的赔率"（真实 β̂ 与任务风险 ρ），策略给落地提供"该多保守"的目标函数。二者合成一个**联合预算**：安全裕度不是越保守越好，而是分配给"每单位安全投入能换回最多得分"的地方。这把 v9 的固定门控升级为**风险敏感的资源分配**：验证算力、块长 K_eff、消融回合都成为可被 λ（安全的影子价格）定价的资源。

## 1. 研究问题（轮次升级版）

- **Q1（现场标定）**：如何用在线残差给出前向模型误差的可证明上界 β̂(t)，并在分布漂移时快速收紧信任域？共形覆盖保证如何在"窗口内可交换、窗口间可漂移"的分段平稳假设下与 v9 引理 82 衔接？
- **Q2（策略可行性）**：在时间预算与安全机会约束下，任务组合与弃权策略的在线近似最优性界是什么？如何证明策略不会因局部得分诱导而逼近/穿越安全边界（P14）？
- **Q3（联合退化）**：SDC/MSP/FRM 任一失效时，如何注入中立元 → 退回 v9 的固定 β、固定任务序、全保守门控，且可观测日志能区分"策略主动保守"与"模块失效"？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 现场即标定律（Field-Calibrated Trust, FRM）**
信任域判据从 DA-ML 的固定滑窗升级为在线误差上界：β̂(t) = 残差窗口 W 的 (1−α) 共形分位（含有限样本校正）；CUSUM 检测到残差均值/方差漂移即重置窗口并收紧 β̂。K_eff 与 δ_trigger 使用 β̂(t) 而非 β_offline。

**P14 策略不越安全包络律（Strategy-Within-Envelope, MSP）**
策略输出 σ 必须先投影到可行集 F = {σ : Pr(safety violation) ≤ δ_match ∧ Pr(overtime) ≤ ε_time}，即 σ* = Π_F(σ_raw)。若投影导致期望得分下降超过 Δ_budget，则拒绝该策略并退回固定任务序（等价 v9 全任务顺序执行）。策略永远不参与安全门控；安全由 v9 引理链独立保证。

**P15 策略-安全联合预算律（Joint Strategy-Safety Budget, JS²）**
定义安全的影子价格 λ ≥ 0。任务 τ 的收益-风险比 g_τ = V_τ / (D_τ + λ·ρ_τ·B_match)。验证算力、块长、消融预算按 g_τ 的边际收益分配；λ 由机会约束的对偶（或二分搜索使风险恰约束紧）确定。λ→∞ 退化为纯安全（禁止任何高风险任务）；λ→0 退化为纯得分（但被 P14 投影挡住）。

## 3. 与基线的接口（如何退化）

- FRM 失效（残差窗口退化 / CUSUM 异常）⇒ β̂ ← β_offline，退回 v9 固定余量；
- SDC 失效 ⇒ 保守部署档（全模块 active、K_eff=1、不蒸馏），等价 v9 满安全模式；
- MSP 失效 ⇒ 固定任务序（v9 默认全任务顺序执行、不弃权），等价 v9 行为；
- 策略与安全解耦：任一策略模块失效时安全门控仍由 v9 的 DA/SPR/Cal/AC/MW 引理链独立保证；
- 全部失效 ⇒ 完整退回 MetricVoiceGauge-ACMD v9，再退回 v8/v7。
- **可区分性纪律**：每周期日志同时记录 `mode`（normal / conservative-by-policy / degraded-by-failure），"策略主动保守"不得被误记为"模块失效"，避免 v8 的虚假退化风暴以新形式复现。

## 4. 预期贡献

1. **现场即标定**：以共形预测 + CUSUM 把 v9 的固定 β 升级为有覆盖保证的在线 β̂(t)，直接封堵 v9 最大风险（滑窗滞后→证书过期）；
2. **比赛策略作为机会约束序贯决策**：任务组合、弃权阈值、时间预算统一建模，给出在线近似最优性界；
3. **策略-安全联合预算**：把安全裕度变成可定价资源，用影子价格 λ 在"追分"与"保守"之间做可解释的连续插值；
4. **双重退化纪律**：策略失效不影响安全、落地失效不影响基线，全部可观测、可区分、可逐位复现。

## 5. 本轮最大风险

**一句话**：策略层把"安全裕度"当作可交易预算，而得分与风险的相关性会被对手行为与环境非平稳地改写——若任务风险 ρ_τ 的在线估计滞后于真实变化，MSP 会在"看起来高性价比"的任务上系统性透支安全，即「策略在最想赢的时候最想突破包络」。

*策略层（追分侧）*
- Level-S1：MSP 失效 ⇒ 固定任务序（全任务顺序、不弃权），等价 v9；
- Level-S2：SDC 失效 ⇒ 保守部署档（全模块 active、K_eff=1、不蒸馏）；
- Level-S3：IP-360 失效 ⇒ λ ← ∞，纯安全分配，放弃策略性计算倾斜。

*安全层（继承 v9，独立于策略）*
- Level-1：AC 证书失效或信任域破坏 ⇒ K_eff ← 1；
- Level-2：MW 失效 ⇒ v8 手写网关路径；

## 1. 符号体系增量（定义 540–547）

**新增定义 540（部署清单与部署证书 DeploymentManifest & Certificate）**
部署清单 Δ=(R,S,A,C,Π)：机器人平台 R、传感器组 S、竞技场 A、能力集 C、运行剖面 Π（任务时长/人机交互频率/负载）。部署证书
```
d_cert = (res_cal, p99_lat, headroom_thermal, headroom_batt, envelope_safe, hash(cfg))
```
有效 ⇔ 每项均在现场阈内：max|res_cal| ≤ ε_cal、p99_lat ≤ WCET·1.1、热/电余量 ≥ 20%、envelope_safe 与 v9 定义 526–530 一致。d_cert 失效 ⇒ 强制保守部署档（Level-S2）。证书随配置哈希版本化，禁止"用 A 场地的证书跑 B 场地"。

**新增定义 541（现场残差 FieldResidual）**
```
r_t = y_t − F̂(s_{t−1}, a_{t−1}),   y_t ∈ ℝ^d 为真实软层指标
```
仅用真实可观测指标（间隙、力、抓取状态），不含真值不可得的量；缺失通道按中立元不进入残差集合，并在日志标记通道覆盖率。

**新增定义 542（在线误差上界 OnlineErrorBound）**
对每通道 j，在窗口 W_t 内取绝对残差 {|r_i^{(j)}|}，采用分割共形（split conformal）分位：
```
q_j(t) = Quantile_{⌈(n_t+1)(1−α)⌉/n_t}( {|r_i^{(j)}|}_{i∈W_t} )
β̂(t)  = max_j q_j(t) + c·sqrt(log(1/α')/(2 n_t))
```
c 为 Lipschitz/量纲常数。CUSUM 统计量 S_t = max(0, S_{t−1} + |r_t| − μ̂ − k) 超阈 h 即判定漂移：清空 W_t、将 β̂ 暂时置为 max(β_offline, 2β̂)、重标定 N_recal 步。α 为共形显著性（默认 0.01），保证边际覆盖 ≥ 1−α。

**新增定义 543（任务组合 TaskPortfolio）**
T={τ_i}，每任务 τ_i=(V_i, D_i, ρ_i, Pre_i, Post_i)：得分、时长分布（用中位数+尾部）、风险（执行期安全违背概率，由 β̂ 与场景难度映射）、前后置依赖。整场风险近似为任务风险的次可加上界：ρ(σ) ≤ Σ_{τ∈σ} ρ_τ（依赖边上的共同风险单列）。

**新增定义 544（策略证书 StrategyCertificate）**
```
Ŝ = (σ ⊆ T 满足依赖闭包, {θ_on, θ_off}, δ_match)
```
可行 ⇔
```
Pr(安全违背 | Ŝ) ≤ δ_match    （机会约束，用定义 543 上界 + Bernstein 修正）
Pr(总时长 > B_match | Ŝ) ≤ ε_time
```
目标：max_{Ŝ∈F} E[score(Ŝ)] / E[time(Ŝ)]（单位时间期望得分）。

**新增定义 545（机会约束安全包络 Chance-Constrained Envelope）**
F = { Ŝ : Pr(safety violation) ≤ δ_match ∧ Pr(overtime) ≤ ε_time }。Π_F 定义为：按 g_τ 从高到低贪心保留任务，直至风险/时间约束重新满足；若被删任务总得分损失 > Δ_budget 则拒绝并返回固定任务序。P14 要求：策略只可在 F 内选取，Π_F 是唯一的"入口闸"。

**新增定义 546（安全的影子价格与联合预算 Joint Budget）**
拉格朗日松弛 L(σ,λ)=E[score] − λ·(Pr(safety violation) − δ_match)。λ* 由二分搜索使风险约束恰紧（或对偶上升）。联合预算：把验证算力 c_ver、块长 K_eff、消融回合 r_abl 视为资源，按 ∂E[score]/∂resource 与 λ·∂risk/∂resource 的边际比分配。λ→∞ ⇒ 全部资源给安全，禁止高风险任务（Level-S3）。

**新增定义 547（承诺/弃权迟滞 Commitment-Abandon Hysteresis）**
任务 τ 在 t 时刻的期望边际得分 μ_τ(t)（用剩余时间、剩余风险预算、FRM 的 β̂ 更新）。状态机：
```
candidate → committed:  μ_τ ≥ θ_on 持续 H_c 周期
committed → abandoned:  μ_τ ≤ θ_off 持续 H_c 周期（θ_off < θ_on）
```
abandoned 任务当轮不再重入；若其依赖被满足且 μ 回升至 θ_on，需重新走 candidate。双阈保证切换间隔 ≥ H_c，杜绝任务层面 Zeno。

## 2. 形式化定义（要点与升级）

**定义 493–539** 全部继承（六层指标、MetaWeight/情感、DA-OTL、软证书、AC/MW/ID、K_eff 门控）。
**升级定义 496（软证书，v10）** δ_trigger 的第五条件由固定 β 改为 β̂(t)：
```
δ_trigger = {σ < τ_safe ∧ γ_grasp valid ∧ Δ_dom < τ_dom
             ∧ risk_SLAM < τ_SLAM ∧ Ĉ_t(β̂(t)) valid}
```
当 β̂ 因 CUSUM 漂移而临时放大时，块证书更易失效 ⇒ K_eff 自动收缩，形成"现场数据 → 更短块 → 更保守"的闭环。
**升级定义 531（软硬衔接）** M₀ 硬检查入口不变；新增策略层前置闸：MSP 只能平移"选哪个任务/何时弃权"，不能修改 M₀ 判据、d_safe、τ_dom、τ_SLAM。

## 3. 关键算法骨架

```python
# IP-359 FieldResidualMonitor：现场残差 → 共形误差上界
class FieldResidualMonitor:
    def __init__(self, forward_model, alpha=0.01, window=512,
                 cusum_k=0.5, cusum_h=5.0, beta_offline=0.02):
        self.F, self.alpha, self.window = forward_model, alpha, window
        self.k, self.h = cusum_k, cusum_h
        self.beta_offline = beta_offline
        self.res = defaultdict(deque)          # 每通道绝对残差
        self.cusum = defaultdict(float)
        self.settling = 0

    def update(self, s_prev, a_prev, y_true):
        y_hat = self.F.predict(s_prev, a_prev)
        for j in y_true.observed():            # 只用真实可观测通道
            r = abs(y_true[j] - y_hat[j])
            dq = self.res[j]; dq.append(r)
            if len(dq) > self.window: dq.popleft()
            mu = sum(dq) / len(dq)
            self.cusum[j] = max(0.0, self.cusum[j] + r - mu - self.k)
            if self.cusum[j] > self.h:         # 检测漂移 → 重标定
                dq.clear(); self.cusum[j] = 0.0
                self.settling = 50
        if self.settling: self.settling -= 1; return self.beta_offline
        beta = self.beta_offline
        for j, dq in self.res.items():
            n = len(dq)
            if n < 32: continue
            rank = math.ceil((n + 1) * (1 - self.alpha)) / n
            q = quantile(dq, min(1.0, rank))
            beta = max(beta, q + math.sqrt(math.log(1/self.alpha) / (2*n)))
        return beta                            # 供给 K_eff 与 δ_trigger

# IP-358 MatchStrategyPlanner：机会约束下的任务组合 + 迟滞弃权
class MatchStrategyPlanner:
    def __init__(self, portfolio, B_match, delta_match, eps_time,
                 theta_on=0.5, theta_off=0.3, H_c=10, delta_budget=0.15):
        self.P, self.B, self.delta, self.eps = portfolio, B_match, delta_match, eps_time
        self.on, self.off, self.Hc = theta_on, theta_off, H_c
        self.db = delta_budget
        self.count = defaultdict(int)
        self.state = {t: 'candidate' for t in portfolio}

    def _risk(self, sigma):
        return sum(self.P[t].rho for t in sigma)          # 次可加上界（定义 543）

    def _time(self, sigma):
        return sum(self.P[t].duration_p50 for t in sigma)

    def feasible(self, sigma):
        return (self._risk(sigma) <= self.delta
                and self._time(sigma) <= self.B * (1 - self.eps))

    def project(self, sigma, lam):
        """Π_F：按 g_τ 贪心保留，直到重新满足机会约束（定义 545）"""
        if self.feasible(sigma): return sigma
        g = {t: self.P[t].value / (self.P[t].duration_p50
              + lam * self.P[t].rho * self.B) for t in sigma}
        kept, base = [], sum(self.P[t].value for t in sigma)
        for t in sorted(sigma, key=g.get, reverse=True):
            cand = kept + [t]
            if self.feasible(cand): kept = cand
        if base - sum(self.P[t].value for t in kept) > self.db * base:
            return self.fixed_order()                      # 拒绝 → 等价 v9
        return kept

    def fixed_order(self):
        return [t for t in self.P if all(p in self.P for p in self.P[t].pre)]

    def plan(self, lam, beta_hat):
        for t in self.P:                                   # 用 β̂ 更新风险
            self.P[t].rho = self.P[t].risk_model(beta_hat)
        order = sorted(self.P, key=lambda t: self.P[t].value
                       / max(1e-6, self.P[t].duration_p50), reverse=True)
        return self.project(order, lam)

    def step(self, now, beta_hat):
        for t in self.P:
            mu = self.P[t].marginal_value(now, self.B, beta_hat)
            if self.state[t] == 'candidate' and mu >= self.on:
                self.count[t] += 1
                if self.count[t] >= self.Hc:
                    self.state[t] = 'committed'; self.count[t] = 0
            elif self.state[t] == 'committed' and mu <= self.off:
                self.count[t] += 1
                if self.count[t] >= self.Hc:
                    self.state[t] = 'abandoned'; self.count[t] = 0
        return {t: st for t, st in self.state.items() if st == 'committed'}
```

## 4. 推导

**引理 87（现场误差界的覆盖保证）** 设窗口 W_t 内各通道残差可交换、且 CUSUM 在分布漂移被检出的时延不超过 L_d 步。则对下一真实残差，Pr(|r_{t+1}| ≤ β̂(t)) ≥ 1−α − L_d·δ_drift。证明：分割共形预测在可交换性下给出边际覆盖 ≥ 1−α（含 (n+1)(1−α)/n 分位校正 + Bernstein 项吸收有限样本波动）；漂移未检出期间最多 L_d 步可能违反可交换性，按并集界扣减 L_d·δ_drift。于是 β̂(t) ≥ β_true 以概率 ≥ 1−α−L_d·δ_drift 成立，代入 v9 引理 82 即得块证书保守有效。∎

**引理 88（部署证书可靠性）** 若 d_cert 有效（标定残差 ≤ ε_cal、p99 延迟 ≤ 1.1·WCET、热/电余量 ≥ 20%、包络通过），则在定义 540 的运行剖面内，现场运行不越出 v9 安全包络；d_cert 失效 ⇒ SDC 强制保守档，K_eff=1、全模块 active，行为等价 v9 满安全模式（引理 91）。∎

**引理 89（策略近似最优性与可行性）** 任务组合在依赖 DAG 上为带机会约束的随机背包。按 g_τ=λ 定价后，用 LP 松弛给出上界 OPT_LP；Π_F 的贪心取整在基数约束/拟阵约束下满足 E[score] ≥ (1−1/e)·OPT_LP；机会约束用 ρ 的次可加上界 + Bernstein 修正保守化，故 Pr(violation) ≤ δ_match 成立。于是输出策略同时可行且近似最优；当近似损失 > Δ_budget 时直接拒绝（定义 545），退化为 v9 固定序。∎

**引理 90（任务无抖振）** 承诺/弃权各需 H_c 周期确认，θ_off<θ_on，且 abandoned 当轮不重入，故相邻任务状态迁移间隔 ≥ H_c 控制周期，有限时间迁移次数 ≤ ⌈B_match/(H_c·Δt)⌉，无 Zeno 抖振。∎

**引理 91（双层退化等价）** 策略层与安全层状态空间不相交：安全层仅读 β̂（FRM 失效时回落 β_offline），不读 σ/Ŝ；策略层失效只令 σ ← 固定任务序或 λ ← ∞，不触碰 M₀/AC/MW/ID/DA/SPR/Cal。故任一策略迁移下安全层行为与 v9 逐位一致；反向，安全层退化不影响策略的可行性判定（策略只做"更保守"的方向平移）。∎

**引理 92（策略不越安全包络）** P14 由两道闸保证：(i) 输出必经 Π_F，F 由 δ_match/ε_time 定义；(ii) M₀ 硬检查在合并执行前拥有绝对否决权，策略无权修改 d_safe/τ_dom/τ_SLAM。故对任意 MSP 输出 σ_raw，实际执行 σ*∈F，Pr(safety violation) ≤ δ_match，安全性不依赖策略的最优性。∎

**引理 93（联合预算守恒）** 设安全验证资源 c_ver 的边际风险下降为 −∂risk/∂c_ver，边际得分增量为 ∂score/∂c_ver。最优分配满足 ∂score/∂c_ver = λ·(−∂risk/∂c_ver)。当 λ 由对偶最优给出时，联合预算的分配是原机会约束问题的 KKT 点；λ→∞ 时 c_ver 全给安全，正对应 Level-S3。∎
