# 第 3 轮（灵感循环第 3 轮；本轮灵感：「数据集」×「动作空间」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E439）。
> 本轮纪律：**只换数据的产生方式与覆盖的度量方式，不改内核**——6C 闭环、MTC/TCV、AP-Cal、
> P-Quarantine、语言审计层与 MODGAUGE 五不变式全部保留；本轮把「回执袋」升级为**版本化计量数据集**，
> 把「预注册工具库」升级为**带可达性约束的动作空间**，并修复一个第 2 轮未意识到的统计缺陷。
>
> **基线审计先行（不追认空洞编号）**：
> 1. 第 2 轮产物头部声称实验增量 E426–E440，正文只定义到 E439，**E440 是空洞**；本轮从 **E441** 起，不替第 2 轮补写 E440。
> 2. **最严重（本轮起点）**：AP-Cal 隐含「回执 i.i.d./可交换」。但回执是**主动选择**出来的——增益注 β（定义 419）本身就是选择器。
>    于是数据集分布 p_D 由策略 π_data 决定，而非目标分布 p_target。这是**内生选择偏差**：越容易被看到的地方被探得越多，
>    校准因此**过度自信**；且同一策略使误差**跨盲区相关**，恰好放大第 2 轮已经担心的系统性污染。
> 3. 回执只是一个「袋」：无数据集版本、无溯源、无召回。工具事后被判缺陷时，无法回答「哪些热替换依赖了脏数据」。
> 4. 盲区被默认**可探**：没有「在当前动作空间内根本测不到」的概念，预算可能无限投入到不可达格子，或静默 stub。
> 5. 增益注 β 逐条计算，忽略**批次内相关性**：两探针测同一自由度时，联合信息增益远小于逐条之和（次模性），程序选择系统性高估。

认证覆盖永远不超过动作空间的信息闭包。

- **新增「数据集绑定不变式」**：任何热替换必须绑定 MD.hash；数值等价性断言只对同一 hash 成立；

## 0. 直觉与动机

**灵感 1（数据集 → 数据集不是被采集的，是被「演出来」的）**
直觉：具身计量里每一条数据都是一次动作的产物。于是「数据集」不是静态语料，而是 𝒜 在物理世界上的**轨道（orbit）**：
数据分布 p_D(s,a) 是策略 π_data 的函数，而非给定的。这一视角立刻暴露第 2 轮的隐藏假设——
对**主动选择的数据**使用 i.i.d. 校准，等价于「只在灯下找钥匙」却宣称整个房间都找过了。
数据集因此必须升级为一等对象：带 schema、版本哈希、溯源 DAG、许可与**召回**能力。
数据质量不是「多」，而是「覆盖了目标分布，且我们知道自己覆盖到哪」。

**灵感 2（动作空间 → 覆盖有硬天花板，诚实来自可达性）**
直觉：无论探测多聪明，能测到的格子只在动作空间的信息闭包内。动作空间（工具 × 参数包络 × 复合）
决定了一条**认知地平线**：地平线内可测量，地平线外只能靠先验外推。
第 2 轮把「测不到」和「没测」混为一谈。正确做法是把二者分开：对不可达格子，**显式记录不确定度下界与原因**，
永不热替换；当不可达格子太多时，把「扩展动作空间」本身当作一个**元动作**（加传感器、换视角、改参数化），
并核算其成本与覆盖增益。这同时给出一个反 Goodhart 的硬约束：覆盖不能凭空刷，只能靠可达动作或扩展动作空间换来。

**灵感 3（数据集 × 动作空间 → 覆盖-可达对偶与审计流）**
直觉：既然数据被策略内生地选择，唯一的诚实来源是**已知倾向的随机性**。
把一小部分预算（ε）用于均匀随机探针，得到一个**倾向已知、无偏的审计子集**：
共形校准、交叉验证、覆盖证书都只在审计子集上做分布无关声明，再按重要性权重迁移到目标分布。
这把「覆盖」从口号变成**可证伪的证书**，并给出对偶：**认证覆盖 ⊆ 可达覆盖**；
任何超出信息闭包的覆盖声明都只能来自先验，不来自测量——因此不随样本数增加而变可信。

## 1. 形式化定义（增量：定义 432–446）

**定义 432（计量数据集 MD 与版本）** 数据集 D = (id, ver, hash, parent, schema, {ρ_i}, prov, cov, lic)：
- **不可变**：新增产生 D' = D ⊕ Δ，ver+1，hash = H(ver, parent_hash, Δ)；
- schema：记录类型 (s, a, r, π_probe, ts, tool_ver, env_digest)；
- **数据集绑定**：EC 热替换必须记录 D.hash；数值等价性断言只对「同一 D.hash」成立。
修复第 2 轮「回执袋无身份」。

**定义 433（记录与溯源图）** 每条 ρ 挂到溯源 DAG：ρ → (tool_ver, calibration_cert, env_digest, π_probe)。
溯源支持反向查询：给定工具/校准证书 c，返回依赖它的记录集合 dep(c)。

**定义 434（探测动作空间 𝒜）** 𝒜 = {(t, θ) : t∈T₀, θ∈Θ_t} ∪ {a∘a'} ∪ {⊥ 被动观测}；
配度量 d_𝒜、包络约束、代价 c(a)、最坏时延 τ(a)。第 2 轮 T₀ 只是 𝒜 的原子层。

**定义 435（动作空间元操作与再认证）** 元动作 ρ = (expand, δ𝒜)，δ𝒜 ∈ {加工具, 换视角, 改参数化, 加传感器}；
代价 c_ρ、预期覆盖增益 ΔCov(ρ)。执行后 𝒜→𝒜'，**所有旧覆盖证书作废并重认证**（版本语义），
且必须通过安全契约（定义 430 PROBING 与力矩硬限的继承）。

**定义 436（探测可达性与信息闭包）** 盲区 s 在预算 B 下 δ-可达 ⇔ ∃ a_{1:k}∈𝒜^k，Σc ≤ B 且 Fisher 信息 I_s(a_{1:k}) ≥ δ。
信息闭包 Cl_δ(S₀) = 从当前已知状态 S₀ 出发 δ-可达的格子集合；**不可达 = 补集**（认知地平线之外）。

**定义 437（认知地平线与不确定度地板）** 对不可达格子维护 U_s = (σ_floor(s), 原因, 可扩展选项)；
σ_floor 由先验与物理包络给下界，**永不热替换**；下游依赖 s 的规划必须显式携带该下界或绕行。
这是对「诚实地不知道」的一等建模，而非静默 stub。

**定义 438（数据集构造策略与倾向）** π_data: ℋ → 一批动作；数据集由 p_D(·|π_data) 生成。
倾向 e(a|s) = P(a ∈ π_data(ℋ) | s)。**关键事实**：p_D ≠ p_target；目标量是 E_{p_target}[·]，
而校准拿到的样本来自 E_{p_D}[·]。

**定义 439（选择偏差感知校准 SB-Cal）**
后验 q_w(u_s) ∝ p_prior(u_s) · ∏_i [l(r_i|u_s)]^{w_i}，w_i = p_target(s_i,a_i)/p_D(s_i,a_i) = 1/e(a_i|s_i)。
- **有界 IPW**：w_i ← min(w_i, w_max)，控制方差；
- **ESS 门槛**：ESS = (Σw)²/Σw² ≥ n_min_eff，否则不校准、不替换；
- **先验夹紧继承**：Σ ≽ κ_phys·I。
- 若倾向模型不可信（π_data 不可测），SB-Cal 只能退回审计子集（定义 440）。

**定义 440（随机审计流 AuditStream）** 每次修复预算划出比例 ε 给**均匀随机动作**（已知倾向 e=1/|𝒜_stoch|）；
审计子集 A_aud 与策略子集 A_sel 分流。共形校准、交叉验证、覆盖证书的**分布无关**声明只在 A_aud 上做；
迁移到目标分布用重要性权重并报告 TV 界。审计种子公开、可复现（定义 444）。

**定义 441（覆盖证书 CoverageCert）** 三元组 (Cov_emp, Cov_reach, Cov_cert)：
- Cov_emp：有 ≥ n_min 条有效回执且后验 σ ≤ ε 的格子；
- Cov_reach = Cl_δ(S₀)：动作空间允许的格子上限；
- Cov_cert：在 A_aud 上以 1−α 共形下界认证、并投影到 Cov_reach 的集合。
**对偶约束**：Cov_cert ⊆ Cov_reach ∩ Cov_emp；Cov_emp 超出 Cov_reach 的部分只记「先验外推」，
**不得计入认证覆盖**，也不能作为热替换依据。

**定义 442（批次信息增益与次模批设计）** 对批次 A ⊆ 𝒜，联合信息增益 G(A) = I(u_s; {r_a}_{a∈A})。
在可观测性条件下 G 次模且单调；逐条 β 之和是边际上界，故第 2 轮逐条选择**系统性高估**。
批设计：argmax_{A: Σc ≤ B} G(A) − λ_c Σc；贪心给 (1−1/e) 近似（引理 54）。

**定义 443（数据集召回与爆炸半径）** 若工具/校准证书 c 事后失效，召回集 R = dep(c)；
受影响热替换 B = {swaps : D.hash 引用了 R 中的记录}。系统必须能按版本链**精确回退**到最近一张通过认证的 D.hash；
爆炸半径 |B| ≤ |R| 的溯源可达集。

**定义 444（离散化间隙与抖动探测）** 参数被网格化 ⇒ 网格之间存在未采样区域；定义离散化间隙 g_𝒜
与抖动探针（θ+δθ，固定种子）以给出间隙内覆盖的界。纯网格 = 可复现但可能错位；纯随机 = 无偏但不可复现；
审计流用**公开固定种子**平衡二者。

**定义 445（扩展退化链）** 认证覆盖不达标 / 审计流被预算挤占 / 动作空间不可扩展 ⇒ 退回 ToolGauge；
再失效 ⇒ LeanGauge ⇒ MODGAUGE。降级时**认证覆盖清零**（不得沿用未认证的旧证书），但已绑定的历史数据保留。

**定义 446（继承与编号约定）** 令 π_data 为 i.i.d.、ε=1、𝒜={被动观测}、w≡1 ⇒ OrbitGauge ≡ ToolGauge；
第 2 轮定义/引理在本轮参数化下成立为特例。E440 空洞不补，实验从 E441 起。

## 2. 关键算法骨架

```python
@dataclass(frozen=True)
class MD:                       # 定义 432：不可变 + 哈希链
    id: str; ver: int; hash: str; parent: str
    schema: str; records: tuple
    def extend(self, delta):
        return MD(self.id, self.ver + 1, H(self.hash, delta), self.hash,
                  self.schema, self.records + tuple(delta))

# IP-321 D-Set：版本化数据集构建 + 溯源
class DatasetBuilder:
    def __init__(self, pi): self.records, self.pi = [], pi
    def add(self, s, a, receipt):
        if not valid(receipt): return                  # 继承定义 417
        self.records.append(Record(s, a, receipt,
            propensity=self.pi.propensity(a, s),
            tool_ver=CUR_TOOL_VER, env_digest=env_digest()))
    def freeze(self): return MD(..., hash=H(self.records))

# IP-322 A-Box：可达性与信息闭包
class ActionSpace:
    def reachable(self, s, budget, delta):
        return any(fisher(s, seq) >= delta and cost(seq) <= budget
                   for seq in self.enumerate(s))
    def info_closure(self, S0, budget, delta):
        return {s for s in self.cells if self.reachable(s, budget, delta)}

# IP-323 SB-Cal：选择偏差感知校准
class SBCal:
    def calibrate(self, ds, s):
        rec = [r for r in ds.records if r.s == s]
        w = [min(1.0 / self.pi.propensity(r.a, r.s), W_MAX) for r in rec]
        if ess(w) < self.n_min_eff: return None        # 证据不足：拒绝替换
        mu, Sig = self.weighted_posterior(rec, w)
        return mu, clamp_min(Sig, KAPPA_PHYS)

# IP-324 AuditStream：已知倾向的随机审计
class AuditStream:
    def split(self, budget): return budget*(1-EPS), budget*EPS
    def sample(self, s, n, rng): return [uniform(self.A_stoch(s), rng) for _ in range(n)]

# IP-325 CoverageCert：覆盖-可达对偶证书
class CoverageCert:
    def certify(self, ds, aud, A, S0, budget):
        reach = A.info_closure(S0, budget, DELTA)
        emp   = {s for s in ds.cells()
                 if ds.n_valid(s) >= N_MIN and ds.sigma(s) <= EPS_S}
        cert  = conformal_lower(aud, alpha) & reach    # 只在审计集上做分布无关声明
        return Cert(emp=emp, reach=reach, cert=cert,
                    prior_only=emp - reach)             # 超可达：只算先验外推

# IP-326 6C 主闭环（数据集绑定 + 审计 + 认知地平线）
def orbitgauge_6c(M, s, budget):
    if not M.action_space.reachable(s, budget*(1-EPS), DELTA):
        M.horizon.add(s, sigma_floor=prior_floor(s)); return "horizon"
    b_sel, b_aud = M.audit.split(budget)
    H    = M.lbox.hypothesize(s, M.dataset.freeze().cell(s))   # H（继承）
    prog = M.tbox.select(H, M.action_space, M.tcv, b_sel)      # C（继承 + 批设计）
    rec  = M.tcv.execute(prog, M.env)                          # E（继承）
    rec += M.audit.execute_random(s, b_aud)                    # 审计流（无偏）
    ds   = M.dataset.extend(rec)                               # 版本 +1
    mu, Sig = M.sbcal.calibrate(ds, s)                         # SB-Cal
    if mu is None: return stub_and_red(s, "ess_low")
    if not M.apcal.cross_validate(mu, Sig, M.audit.cross(s)):  # V 只用审计回执
        return stub_and_red(s, "audit_failed")
    cert = M.cert.certify(ds, M.audit, M.action_space, M.S0, b_aud)
    if s not in cert.cert: return stub_and_red(s, "uncertified")
    ec = M.apcal.update_contract(M.dpe, mu, Sig, s, ds_hash=ds.hash)  # 数据集绑定
    if not contract_regression(ec): return stub_and_red(s, "regression")
    M.mreg.hot_replace(M.dpe, ec, ds_ref=ds.hash)
    M.dbox.update_from_posterior(s, mu, Sig)
    bind_claims(ec, H, prog, rec)                              # 定义 427（继承）
    return True

def OrbitGauge_round(M, obs, audio, tac, depth, det):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s); submit_async(orbitgauge_6c, M, s, M.budget_left(s))
    if M.horizon.too_large(): M.meta.expand_action_space()     # 元动作（定义 435）
    return MODGAUGE_round(M, obs, audio, tac, depth, det)      # 主控不变
```

## 3. 推导

**引理 51（内生选择偏差导致过度自信）** 设目标分布下的后验方差为 σ²_t，策略采样 p_D 下的朴素后验为 σ²_D。
当策略偏向低噪声/高可观测动作（增益注天然如此）时，在高信息区 p_D > p_target ⇒ w<1，
朴素校准把 w 当作 1 会**过计数**样本：Σ_i 1 > Σ_i w_i ⇒ 精度高估 ⇒ E[σ²_D] < σ²_t。
偏差随策略集中度单调增；有界 IPW 后验的方差上界 ∝ w_max²/ESS。
故：**不修正的选择偏差会把「只在能测的地方测过」伪装成「全都测过」**。
证明思路：重要性采样恒等式 + 后验精度分解 Σ^{-1} = Σ_0^{-1} + Σ_i w_i σ_i^{-2} + 截断权重偏差-方差权衡。

**引理 52（覆盖-可达对偶）** 对任何仅依赖测量的认证覆盖 Cov_cert：Cov_cert ⊆ Cl_δ(S₀)。
证明：认证一条记录需要一次有效回执，而有效回执要求一个 I≥δ 的可达动作序列；故认证格子 ∈ 信息闭包。
超出部分只能由先验外推支持，其可信度不随样本数增加而提高（只随先验正确性）。
**推论 52.1**：提高覆盖只有两条路——更多可达动作，或扩展动作空间；单纯增加样本只在高可达区域内有效。

**引理 53（审计流的分布无关覆盖）** 设审计子集 A_aud 由已知倾向的均匀随机动作产生，
则在 A_aud 上共形覆盖 P(h*∈H_s) ≥ 1−α（可交换性下）；迁移到 p_target 的覆盖 ≥ 1−α − TV(p_D^aud, p_target)
（或重要性加权下的有效 TV）。故 ε 给出显式的「诚实性-效率」曲线：ε↑ 声明更可信，选择效率↓。

**引理 54（批设计的次模近似）** 在可观测性拟阵条件下，高斯联合信息增益 G(A) = ½·logdet(I + Σ_0^{1/2} K_A Σ_0^{1/2})
次模且单调；预算约束下贪心解满足 G(A_greedy) ≥ (1−1/e)·G(A*)。
**系**：逐条 β 求和是上界，第 2 轮的选择高估量 = Σ_t β_t − G(A) ≥ 0，且随探针相关性增大而增大。

**引理 55（数据集召回的爆炸半径）** 工具/证书 c 事后失效时，召回集 R = dep(c)，
受影响热替换 B ⊆ {swaps : ds_hash 引用了 R}，|B| ≤ |R|；按版本链可精确回退到最近认证版本，
回退后系统在数值子图意义上等价于「该工具从未被使用」。故脏数据只沿溯源边传播，不会无限扩散。

**引理 56（时序与预算保持）** 审计流、SB-Cal、可达性分析全异步于 50Hz 路径之外；
50Hz 内联只增加 O(1) 哈希校验 < 0.1ms；ε·B 从修复预算中扣除，总预算不变，
故硬实时（继承引理 45/50）与预算不变式保持。

## 6. 本轮最大风险（一句话）

**一句话**：一旦「覆盖」被做成可认证指标，系统会遭受 **Goodhart 式审计套利**——策略倾向于在审计流容易通过、
动作空间边缘的格子上刷认证覆盖，而真正困难的格子（不可达或高噪声）被归入「认知地平线」后**合法地不再改进**；
认证覆盖率上升、真实任务成功率却停滞，而证书让这种停滞看起来是「已知且可控」的。
（E447/E449/E451 为证伪实验，审计种子公开与元扩展再认证为缓解。）

**次级风险与缓解**：
1. **倾向模型不可测/错设**（策略是学习出来的且会漂移）→ IPW 权重错误、ESS 低 → 强制降级到审计子集；E445。
2. **审计预算被挤占**（策略性 ε 缩水）→ ε 写进 TB-Contract 硬下限，不可由修复策略调整；E451。
3. **数据集召回风暴**（一个基础工具失效引发大面积回退）→ 版本链 + 爆炸半径界（引理 55）+ 分批重认证；E448。
4. **动作空间扩展的物理风险**（新增传感器/视角可能扰动）→ 元动作走 PROBING + 安全契约 + 人工审批；定义 435。
5. **离散化混叠**（网格间隙恰好躲过真值）→ 固定种子抖动探针 + 间隙界；定义 444、E450。
6. **溯源伪造**（伪造 env_digest 让脏数据看起来干净）→ 签名链继承定义 417 + 环境摘要绑定；E448。

## 2. 形式化定义（要点）

**定义 433（溯源）** 每条记录挂 (tool_ver, calibration_cert, env_digest, π_probe)；反向查询 dep(c)。
**定义 434（动作空间）** 𝒜 = 原子工具 × 参数包络 ∪ 复合 ∪ 被动观测；带度量/代价/时延。T₀ 只是原子层。

**定义 439（SB-Cal）** q_w ∝ p_prior · ∏ l(r_i|u_s)^{w_i}，w_i = 1/e(a_i|s_i) 截断到 w_max；ESS ≥ n_min_eff 才校准；Σ ≽ κ_phys·I。

```python
# IP-321 D-Set：不可变数据集 + 哈希链 + 溯源
@dataclass(frozen=True)
class MD:
    id: str; ver: int; hash: str; parent: str; schema: str; records: tuple
    def extend(self, delta):
        return MD(self.id, self.ver+1, H(self.hash, delta), self.hash,
                  self.schema, self.records + tuple(delta))

class DatasetBuilder:
    def __init__(self, pi): self.records, self.pi = [], pi
    def add(self, s, a, receipt):
        if not valid(receipt): return
        self.records.append(Record(s, a, receipt,
            propensity=self.pi.propensity(a, s),
            tool_ver=CUR_TOOL_VER, env_digest=env_digest()))
    def freeze(self): return MD(..., hash=H(self.records))

# IP-322 A-Box：可达性 / 信息闭包
class ActionSpace:
    def reachable(self, s, budget, delta):
        return any(fisher(s, seq) >= delta and cost(seq) <= budget
                   for seq in self.enumerate(s))
    def info_closure(self, S0, budget, delta):
        return {s for s in self.cells if self.reachable(s, budget, delta)}

# IP-323 SB-Cal：有界 IPW 后验 + ESS 门槛
class SBCal:
    def calibrate(self, ds, s):
        rec = [r for r in ds.records if r.s == s]
        w = [min(1.0/self.pi.propensity(r.a, r.s), W_MAX) for r in rec]
        if ess(w) < self.n_min_eff: return None
        return clamp_min(self.weighted_posterior(rec, w), KAPPA_PHYS)

# IP-324 AuditStream：已知倾向的随机探针
class AuditStream:
    def split(self, b): return b*(1-EPS), b*EPS
    def sample(self, s, n, rng): return [uniform(self.A_stoch(s), rng) for _ in range(n)]

# IP-325 CoverageCert：覆盖-可达对偶
class CoverageCert:
    def certify(self, ds, aud, A, S0, budget):
        reach = A.info_closure(S0, budget, DELTA)
        emp   = {s for s in ds.cells()
                 if ds.n_valid(s) >= N_MIN and ds.sigma(s) <= EPS_S}
        cert  = conformal_lower(aud, alpha) & reach
        return Cert(emp=emp, reach=reach, cert=cert, prior_only=emp-reach)

# IP-326 OrbitGauge 6C（数据集绑定 + 审计 + 地平线）
def orbitgauge_6c(M, s, budget):
    if not M.action_space.reachable(s, budget*(1-EPS), DELTA):
        M.horizon.add(s, sigma_floor=prior_floor(s)); return "horizon"
    b_sel, b_aud = M.audit.split(budget)
    H    = M.lbox.hypothesize(s, M.dataset.freeze().cell(s))   # H
    prog = M.tbox.select(H, M.action_space, M.tcv, b_sel)      # C
    rec  = M.tcv.execute(prog, M.env)                          # E
    rec += M.audit.execute_random(s, b_aud)                    # 无偏审计样本
    ds   = M.dataset.extend(rec)
    mu, Sig = M.sbcal.calibrate(ds, s)                         # SB-Cal
    if mu is None: return stub_and_red(s, "ess_low")
    if not M.apcal.cross_validate(mu, Sig, M.audit.cross(s)):  # V 仅用审计回执
        return stub_and_red(s, "audit_failed")
    cert = M.cert.certify(ds, M.audit, M.action_space, M.S0, b_aud)
    if s not in cert.cert: return stub_and_red(s, "uncertified")
    ec = M.apcal.update_contract(M.dpe, mu, Sig, s, ds_hash=ds.hash)
    if not contract_regression(ec): return stub_and_red(s, "regression")
    M.mreg.hot_replace(M.dpe, ec, ds_ref=ds.hash)
    M.dbox.update_from_posterior(s, mu, Sig)
    bind_claims(ec, H, prog, rec)                              # 继承定义 427
    return True

def OrbitGauge_round(M, obs, audio, tac, depth, det):

    if M.horizon.too_large(): M.meta.expand_action_space()
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 4. 推导

**引理 51（选择偏差 ⇒ 过度自信）** 高信息区 p_D>p_target ⇒ w<1；朴素校准取 w=1 过计数 ⇒ 精度高估 ⇒ σ²_D < σ²_t；
偏差随策略集中度单调增；有界 IPW 方差上界 ∝ w_max²/ESS；证明用重要性采样恒等式 + 后验精度分解。
**引理 52（覆盖-可达对偶）** Cov_cert ⊆ Cl_δ(S₀)：认证需要有效回执，回执需要 I≥δ 的可达动作；超出部分仅先验外推，样本再多也不增信。
推论 52.1：提高覆盖只有「更多可达动作」或「扩展动作空间」两条路。
**引理 53（审计流分布无关覆盖）** A_aud 上 P(h*∈H_s) ≥ 1−α；迁移到 p_target ≥ 1−α − TV(p_D^aud,p_target)；ε 勾勒诚实性-效率曲线。
**引理 54（次模批设计）** 高斯联合增益 ½·logdet(I+Σ_0^{1/2}K_AΣ_0^{1/2}) 次模；贪心 (1−1/e)；逐条高估量 = Σβ − G(A) ≥ 0。
**引理 55（召回爆炸半径）** |B| ≤ |dep(c)|；按版本链精确回退；脏数据只沿溯源边传播。
**引理 56（时序预算）** 50Hz 内联仅 +O(1) 哈希 < 0.1ms；审计预算从 TB-Contract 扣除；硬实时与预算不变式保持。

## 8. 本轮最大风险

**一句话**：把「覆盖」做成可认证指标后，系统会遭受 **Goodhart 式审计套利**——策略在审计流易过、动作空间边缘的格子上刷认证覆盖，
真正困难（不可达/高噪声）的格子被归入「认知地平线」后合法地不再改进；认证覆盖率上升而任务成功率停滞，
证书却让这种停滞显得「已知且可控」。以 E450（可刷性）、E444（证书泄漏）、E451（审计预算挤占）证伪，
以审计种子公开、ε 写入 TB-Contract 硬下限、元扩展再认证三重兜底。
