# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；新循环第 1 轮；本轮灵感：「数据增强」×「热管理」）

> R69 把不确定性拆成 aleatoric 与 epistemic，并让系统学会“问”。但它把两层地基当成了免费且恒定：
> - **数据地基**：模态分布是否可信，本质取决于训练分布是否覆盖了将要遇到的世界。R69 从不问“我的数据够不够？怎么补而不污染校准？”
> - **物理地基**：R69 的“实时 <2.6ms、K=4 消歧”被当成静态预算。但真实机器会发热——**热同时做两件事**：降频/降算力（K、N_step 被砍），以及让执行器降额、传感器产生慢偏置（植物与传感能力被砍）。
>
> 最阴险的是耦合：**热是“共因”**。它同时恶化植物与估计器。R69 最需要 K=4 消歧的时刻，恰是机器最热、算力最少的时刻；而热致传感偏置又长得像缓变故障，可能被 R68 的标定“解释掉”，或被 R69 的流似然误判。
>
> 本轮两个灵感正好补这两层地基：
> - **数据增强**：用热域随机化、降频推理轨迹、歧义回放来“补分布”——但增广会改变 aleatoric/epistemic 的统计、可能幻影出模态、也可能被投毒，所以必须**认证**（保真门 + 增广感知校准）。
> - **热管理**：把热状态当作一等公民——热感知策略、热-算-控调度、热安全包络；并在热压力下把“在线算消歧”换成“离线采数据”。
>
> 核心命题：**CALOR-RAS 在 FLUID 层之下再垫一层“可认证的数据增广 + 热-算-控调度”的地基层；正常温度且增广关闭时逐指令退化为 FLUID（再退化为 R68 边界），热压力下单调优雅降级，安全侧永不更差。** 命名 **CALOR-RAS**（Calibrated Augmentation & thermal-Load-aware Risk-adaptive System；CALOR＝热）。
>
> 一句话定位：R66 问“谁控制”，R67 问“未来怎样”，R68 问“我的测量还准吗”，R69 问“我该向谁求证”，R70 问“**我脚下的数据与物理地基，撑得住我的推理吗**”——不确定性不只在信念里，也在数据覆盖与散热余量里。

## 0. 直觉与动机

**灵感 1（数据增强 → 分布是可修补的，但补丁必须认证）**
直觉：R69 最大的隐忧是“流模型幻觉出不存在的模态”。根因往往不在模型本身，而在**训练分布没覆盖部署时遇到的状态**：没见过的热态、没见过的降频推理、没见过的歧义场景。数据增强是最直接的补丁——热域随机化让策略见过“又热又慢”的观测；降级模拟让估计器见过“K=1、量化、早停”的推理轨迹；歧义回放把在线撞到的多峰状态放大。但加强有三宗罪：一是**注入不真实模态**（幻影），二是**抹平真实模态**（覆盖丢失），三是**改变不确定性统计**——加噪声会让 U_ale 虚高、λ_floor 过度收紧、丢掉 resolution bonus；回放歧义会让 U_epi 虚高、诱发追问幻影。所以本轮的核心不是“增强”，而是**认证增强**：可达性支撑 + 分布保真 + 增广感知校准，三者缺一不可。

**灵感 2（热管理 → 算力和能力都是热的函数）**
直觉：热不是散热工程师的私事，而是控制回路里的**慢变量**。结温升高 → 芯片降频 → R69 的 K=4/Hutchinson 回放超时；电机升温 → 力矩降额 → 安全动作集收缩；传感器升温 → 零漂/灵敏度漂移 → 标定层接到一个“缓慢变脏”的输入。R69 把 K、N_step、实时预算当常数，等于假设“机器永远不热”。正确姿势是把热状态 θ_T 显式代入：策略条件化（TAP）、采样调度（TCC）、安全包络（TSE），以及热致偏差的可解释项（TDT）。

**灵感 3（耦合 → 热压力下，采数据比算消歧更划算）**
直觉：R69 的在线消歧要花算力，而算力在热压力下最贵。但“把撞到的歧义轨迹记下来、带去离线增广”几乎不花算力，只花存储。于是出现一个热感知的 value-of-information 权衡：**同样一笔热预算，是现在多采 4 个动作模态去问，还是现在只记一条高价值轨迹、让下一版模型少犯同样的错？** 定义热值信息比 TVoI，热压力越大越偏向采掘。这把“数据增强”从离线一次性工作，变成**闭环里的在线决策**（采什么、何时采），同时仍保持零在线学习写操作——线上只记录，训练在离线且版本锁定。

**灵感 4（新的辨识问题 → 热、漂移、故障三者互相冒充）**
直觉：R68 用 r_res 看传感器自洽，R69 用 Δa 看行为自洽。现在多了一条热通道 θ_T，但三者会互相冒充：热致偏置看着像缓变故障；真实故障可以被解释成“今天比较热”；甚至攻击者可以**主动加热机器**触发降频、顺带掩盖故障（热侧信道/热伪装）。所以要新增三分解 TDT：在热模型可辨识时把 Δa 拆成“热可解释分量 + 残差”，不可辨识时不允许猜，直接保守。这是对 R68 反吸收引理与 R69 对偶判据的**联合加固**。

**灵感 5（严格包含 → 地基层不能推翻上层，只能等价或收紧）**
直觉：R70 是“地基”，不是“新算法”。它只能做两件事：正常时**等价**（θ_T 正常、增广关闭 ⇒ 逐指令 = FLUID = R68 边界），异常时**单调收紧**（热越差、λ 越大、动作集越小、K 越少），绝不放松。这样每加一层不会新增一个需要独立信任的黑箱，而是把“信任”收敛为三条可审计证书：热余量、增广保真度、分解稳定性。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（CALOR-RAS 总览）** CALOR-RAS = (FLUID-RAS, THM, TCC, TSE, TAP, CAGE, AFD, AAC, DAQ, TVoI, TDT)。三不变式：
(i) **零在线学习写操作**（继承 R69 定义 293-i）：增广与校准只在离线进行且有版本号，线上只做推理、门控与记录；
(ii) **热安全包络硬约束**：任意 θ_T 下，认证动作集 ⊆ 热安全集 A_safe(θ_T)，且 P(T > T_crit) ≤ δ_T；
(iii) **增广可审计**：任何进入部署的增广流水线必须有 AFD 保真证书与 AAC 校准证书；未认证增广不得进入训练，也不得改变在线先验。

**定义 311（热状态与热余量）** 热状态 θ_T(t) = (T_junc, T_act, T_amb, T_batt, duty, coolant) ∈ Θ_T；热动力学 θ_T(t+1) = f_T(θ_T, u, load) + ε_T，观测有延迟 d_T。热余量 h_T = T_crit − max_i T_i；h_T < 0 为热越界。

**定义 312（算力供给函数）** 算力供给 C(θ_T) 关于温度单调不增，诱导延迟倍率 m(θ_T) ≥ 1 与可行采样集 𝒦(θ_T) = {(K, N_step) : latency(K,N_step)·m(θ_T) ≤ D}。热预算约束：单位步计算产热 q(K,N_step) ≤ h_T / τ_cool。

**定义 313（热致植物与传感退化）** 力矩上限 τ_max(θ_T) = τ_0·d(θ_T)，d ∈ [0,1] 单调不增；传感慢偏置 b_T(θ_T(t)) 及其变化率 ḃ_T。植物与观测模型显式条件化于 θ_T。

**定义 314（热感知策略 TAP）** 速度场 v_θ(x_s, s | o_t, θ_T) 与 mode_head(z_t, θ_T)；热嵌入经离线热残差适配器注入，不改主干权重（保持零在线写）。

**定义 315（热-算-控调度 TCC）** 每步选 (K, N_step, g)，在 deadline D、热预算 q ≤ h_T/τ_cool、K ≤ K_max(θ_T) 下最大化 E[安全裕度 + resolution] − λ_T·ΔT_rise；无可行解时返回 (1,1,None)。

**定义 316（热安全包络 TSE）** A_safe(θ_T) = {a : τ(a) ≤ τ_max(θ_T)，预测结温不越 T_crit（概率 ≥ 1−δ_T），传感器偏置在可观测域内}。C-RAS-WM† 的前缀认证必须在 A_safe(θ_T) 内完成。

**定义 317（认证增广算子 CAGE）** A_kernel = (A_thermal, A_throttle, A_replay, A_ambiguity)，分别做热域随机化、降频/量化推理模拟、高价值轨迹回放、歧义状态放大。每个算子的输出必须落在物理可达集 R_phys 内（防幻影），且不得删除参考分布中真实存在的模态（防覆盖丢失）。

**定义 318（增广保真证书 AFD）** D_fid(A_kernel) = MMD(D_aug, D_ref) + μ·mass(D_aug ∖ R_phys) + ν·mode_drop(D_aug, D_ref)。认证条件 D_fid ≤ ε_fid；越界则整条增广被拒。

**定义 319（增广感知校准 AAC）** 分层（按温度带/算力档/场景）重估模态权重与 ECE；要求分解稳定性 |U_ale^aug − U_ale^ref| ≤ L_A·D_fid、U_epi 同理。ECE 越界则该层禁用增广先验，退回未增广校准器。

**定义 320（歧义采掘 DAQ）** 在线对每条轨迹打分 harvest_score = Û_epi·w_thermal(θ_T)·novelty，超过阈值则连同 provenance（热状态、算力档、认证器版本、时间戳）写入采掘缓冲；离线回放增广。线上不训练、不回写权重。

**定义 321（热值信息比 TVoI）** TVoI(g) = VoI(g) / (c_compute(g)·m(θ_T) + c_thermal(g) + c_social(g))；采掘的 TVoI_h = 期望未来 U_epi 降幅 / 采掘成本。当热压力使 TVoI_h > TVoI(g*) 时，选采掘而非在线交互。

**定义 322（热-漂移-故障三分解 TDT）** 联合证据 (r_res, Δa, θ_T)。热可解释分量 Δa_T = J_flow·b_T(θ_T)，残差 Δa⊥ = Δa − Δa_T。可辨识条件：b_T 对 θ_T 的雅可比与故障方向不共线（秩条件）。满足则分三类（热偏置/真漂移/缓变故障）；不满足则标记 unknown 并强制保守。

**定义 323（增广投毒与热攻击 ℰ_CALOR）** 对抗增广（污染回放/伪造热日志）、伪相关增广、热侧信道（外部加热迫使降频以掩盖故障或降低认证）、热伪装（把故障伪装成热漂移）。ℰ_CALOR = ℰ_FLUID × ℰ_aug × ℰ_thermal。

**定义 324（证书 J_CALOR）** J_CALOR = (J_FLUID, thermal_margin h_T, afd_fid, decomp_stability, harvest_provenance_hash, derating_version, tcc_trace_hash, calor_ver)。Valid ⇔ Valid(J_FLUID) ∧ h_T ≥ 0 ∧ D_fid ≤ ε_fid ∧ 分解稳定 ∧ 无热越界。

**定义 325（热保守退避与优雅降级）** 四个热档：normal → FLUID；warm → K 降、λ↑、禁 Hutchinson 回放；hot → 禁在线交互、退 R68 保守、仅采掘；critical → 安全停机。λ 关于热压力单调不降；normal 档逐指令等于 FLUID。

**定义 326（离线增广与在线零写分离）** 增广、校准、热残差适配全部离线且版本锁定；在线只推理、门控、记录。证书中固定 aug_version 与 derating_version，确保“部署了什么”可复现、可审计。

# IP-264/265 THM + TCC：热余量与热-算-控调度
def thermal_budget(theta_T, deadline):
    head = T_crit - theta_T.T_max
    m    = latency_multiplier(theta_T)              # 越热越慢
    K_max = max(1, floor(K0 * head / head0))        # 热余量换采样数
    N_max = 2 if m < 1.5 else 1
    return head, m, K_max, N_max

def schedule_compute(theta_T, U_epi, deadline):
    head, m, K_max, N_max = thermal_budget(theta_T, deadline)
    for (K, N) in sorted(candidates(K_max, N_max), key=compute_cost):
        if latency(K, N) * m <= deadline and heat(K, N) <= head:
            return K, N
    return 1, 1                                     # 无可行解 → 最保守

# IP-268/269/270 CAGE + AFD + AAC（全部离线、版本化）
def certified_augment(D_ref, A_kernel):
    D_aug = apply(A_kernel, D_ref)                  # 热DR/降级模拟/采掘回放
    fid = (mmd(D_aug, D_ref)
           + mu * unreachable_mass(D_aug, R_phys)
           + nu * mode_drop(D_aug, D_ref))
    if fid > EPS_FID:
        return None, fid                            # 幻影/覆盖丢失 → 拒绝
    U_ale_cal, U_epi_cal, ece = recalibrate(D_aug, D_ref)
    if ece > TAU_ECE:
        return None, fid                            # 校准不可信 → 拒绝
    return Calibrator(A_kernel, U_ale_cal, U_epi_cal), fid

# IP-271/272 DAQ + TVoI：热压力下「采数据」优先于「算消歧」
def interact_or_harvest(modes, theta_T, budget):
    g = choose_interaction(modes, budget)           # R69 在线消歧
    if g is None:
        return None, None
    tvoi_i = voi(g) / compute_cost(g, theta_T)
    tvoi_h = future_voi(modes) / harvest_cost(modes)
    if tvoi_h > tvoi_i and is_thermal_stressed(theta_T):
        return None, harvest(modes)                 # 省算力，留数据给离线增广
    return g, None

# IP-273 TDT：热-漂移-故障三分解
def tri_decompose(r_res, da, theta_T, b_T):
    da_thermal = jac_flow @ b_T(theta_T)            # 热可解释分量
    resid      = da - da_thermal
    if not identifiable(theta_T):                   # 共线 → 不可分
        return 'unknown', LAM_SAFE
    if resid > TAU_FAULT:
        return 'slow_fault', LAM_SAFE
    if r_res < TAU_RES:
        return 'thermal_bias', LAM_WARM
    return 'drift', LAM_NORMAL

# IP-275 主闭环（外壳：先问地基，再问 FLUID）
def CALOR_RAS_round(M, obs):
    theta_T = M.thm.step(sensors)                   # 热状态+余量（延迟补偿）
    head, m, K_max, N_max = thermal_budget(theta_T, M.deadline)
    # 1) 热安全包络先收缩（能力降级）
    A_safe = M.tse.filter(M.ach.propose(...), theta_T)
    # 2) 热-算-控调度：热度决定还能不能消歧
    K, N = M.tcc.schedule(theta_T, M.last_U_epi, M.deadline)
    # 3) 热感知策略 + 增广感知校准
    z, o = M.mtm.forward(...)
    U_ale, U_epi, modes = M.aud.decompose(
        M.tap.sample(o, theta_T, K, N), z)
    U_ale, U_epi = M.aac.calibrate(U_ale, U_epi, theta_T)
    # 4) 热-漂移-故障三分解（R68/R69 两通道 + 热）
    kind, lam_t = M.tdt.decompose(M.last_r_res, M.fma.score(...), theta_T)
    # 5) 在线消歧 vs 离线采掘（热值信息比）
    g, harvested = M.tvoi.interact_or_harvest(modes, theta_T, M.budget)
    if g:
        U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    # 6) 风险缩放 + 热安全前缀
    lam = max(M.efs.risk_scale(...), lam_t,
              lam_floor(U_ale + (0.0 if g else U_epi)))
    k = M.c_ras_wm.certified_prefix(A_safe, ..., wm_preds)
    if kind in ('slow_fault', 'unknown') or head < 0:
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(...))  # 回最保守
    # 7) 采掘记录 + 热账本 + 证书
    M.daq.record(harvested, provenance=...)

## 3. 推导

**引理 19（热共因退化不是小扰动）** 设热致降额为 1−d(θ_T)、可采样数为 K_max(θ_T)。若不显式建模热，R69 名义风险界 R_nom 的违反量满足 ΔR ≥ L_d·(1−d(θ_T)) + L_s·(1/√K_max − 1/√K_0)，两项均为热压力的一阶项。要点：热盲不是可忽略扰动，恰好在最需要它时最大。系：必须把 θ_T 代入策略、调度与安全包络，否则 R69 的保证整体失效。

**引理 20（增广对不确定性分解的偏差界）** 对任何满足 AFD ≤ ε_fid 的增广核，|Û_ale − U_ale| ≤ L_ale·D_fid、|Û_epi − U_epi| ≤ L_epi·D_fid（Lipschitz 常数由轨迹聚类与协方差估计的稳定性给出）。系：热噪声增广抬 U_ale（λ 过紧、丢 resolution bonus），歧义回放抬 U_epi（诱发幻影追问）；故必须用 AAC 分层重校准，而不能把增广分布直接当在线先验。

**引理 21（热-漂移-故障可辨识性）** 令故障方向 v_f、热偏置雅可比方向 v_T = J_flow·∂b_T/∂θ_T。若 rank([v_f, v_T]) = 2（非共线）且热传感独立于被诊断传感器，则 (r_res, Δa, θ_T) 可分离三类；若共线或热传感与偏置同源，则不可辨识，任何“自信分类”都可能把故障洗成热漂移。⇒ 不可辨识时必须 unknown + 保守。

**引理 22（采掘价值的单调收益）** 对高 Û_epi 轨迹做覆盖性采掘并离线增广，在可达集覆盖度提升 Δc 下，未来 U_epi 期望降幅 ≥ c·Δc·(1−e^{−ΔH_replay})；且热压力使在线算力成本 m(θ_T) 上升时，采掘 TVoI 相对上升，存在热阈值 θ*_T 使采掘占优。⇒ “热时采数据”有信息论依据，不是权宜之计。

**定理 18（CALOR 严格包含 FLUID 与 R68）** 在 A99–A101 下：normal 档且增广关闭（或 AFD/AAC 认证通过）时，CALOR 逐指令等于 FLUID；热压力升高时 λ 单调不降、A_safe 单调收缩、K 单调不增；故任意状态期望风险 ≤ FLUID，安全侧永不更差。R70 是 R69 的“地基层”，不是并列替代。

**定理 19（热安全与无热失控）** 若 TCC 满足 q ≤ h_T/τ_cool 且 TSE 约束进入 certified_prefix，则 P(T > T_crit) ≤ δ_T；降级路径 normal→warm→hot→critical 单调，切换经 C-RAS-WM† 前缀认证与换装不变式（R68 定理 15），控制连续、无突变。

**定理 20（认证增广不放大 R69 风险）** 若 AFD ≤ ε_fid 且 AAC 各层 ECE ≤ τ_ece，则增广仅通过“校准后的先验”影响 U_ale/U_epi，其对 VoI 决策的偏差被 L·D_fid 界住；因此 R69“问错比不问更危险”的风险不被放大，反而因热/歧义覆盖提升而下降。若任一证书失效，则禁用增广、退回未增广 FLUID。

## 6. 本轮最大风险

**次级风险与缓解**：
1. **热模型失配**（未建模热源、执行器/芯片耦合）→ TSE 加保守裕度 + E311/E313 热态 OOD 检测 + 不可辨识即退最保守；

4. **热侧信道攻击**（外部加热迫使降频）→ 热账本交叉核验（负载-温度不一致检测）+ critical 停机；
5. **地基层被绕过**（直接改在线先验）→ 定义 326 离线/在线分离 + 证书固定 aug_version，部署可复现、可审计。

# IP-264/265 THM + TCC：热余量换算力
def thermal_budget(theta_T, deadline):
    head = T_crit - theta_T.T_max
    m    = latency_multiplier(theta_T)
    K_max = max(1, floor(K0 * head / head0))
    return head, m, K_max, (2 if m < 1.5 else 1)

def schedule_compute(theta_T, deadline):
    head, m, K_max, N_max = thermal_budget(theta_T, deadline)
    for K, N in sorted(candidates(K_max, N_max), key=compute_cost):
        if latency(K, N) * m <= deadline and heat(K, N) <= head:
            return K, N
    return 1, 1                                  # 无可行解 → 最保守

# IP-268/269/270 CAGE + AFD + AAC（离线、版本化）
def certified_augment(D_ref, A_kernel):

    fid = (mmd(D_aug, D_ref)
           + mu * unreachable_mass(D_aug, R_phys)
           + nu * mode_drop(D_aug, D_ref))
    if fid > EPS_FID: return None, fid
    U_ale_c, U_epi_c, ece = recalibrate(D_aug, D_ref)
    if ece > TAU_ECE: return None, fid
    return Calibrator(A_kernel, U_ale_c, U_epi_c), fid

    if (future_voi(modes) / harvest_cost(modes)
            > voi(g) / compute_cost(g, theta_T)) and is_thermal_stressed(theta_T):
        return None, harvest(modes)

def tri_decompose(r_res, da, theta_T, b_T):

## 4. 推导

**引理 19（热共因退化不是小扰动）** 热致降额 `1−d(θ_T)`、可采样数 `K_max` 造成名义风险界违反 `ΔR ≥ L_d(1−d(θ_T)) + L_s(1/√K_max − 1/√K_0)`，两项皆为一阶项；热盲恰在最需要时最大。⇒ 必须把 θ_T 代入策略/调度/包络。

**引理 20（增广分解偏差界）** `AFD≤ε_fid` ⇒ `|Û_ale−U_ale|≤L_ale·D_fid`、`|Û_epi−U_epi|≤L_epi·D_fid`。热噪声增广抬 U_ale（λ 过紧、丢 resolution bonus），歧义回放抬 U_epi（幻影追问）；必须 AAC 分层重校准，不能把增广分布直接当先验。

**引理 21（热-漂移-故障可辨识性）** 令 `v_f` 为故障方向、`v_T=J_flow·∂b_T/∂θ_T`。`rank([v_f,v_T])=2` 且热传感独立时可分三类；共线或同源则不可辨识，自信分类会把故障洗成热漂移。⇒ 不可辨识必须 unknown+保守。

**引理 22（采掘价值单调收益）** 覆盖性采掘使未来 `U_epi` 降幅 `≥ c·Δc·(1−e^{−ΔH_replay})`；热压力抬高在线算力成本 `m(θ_T)`，存在热阈值 `θ*_T` 使采掘 TVoI 占优。⇒ “热时采数据”有信息论依据。

**定理 18（CALOR 严格包含 FLUID 与 R68）** normal 且增广关闭/认证通过时逐指令等于 FLUID；热压力升高时 λ 单调不降、`A_safe` 单调收缩、K 单调不增；故期望风险 ≤ FLUID，安全侧永不更差。R70 是地基层，不推翻上层。

**定理 19（热安全与无热失控）** TCC 满足 `q≤h_T/τ_cool` 且 TSE 进入 certified_prefix ⇒ `P(T>T_crit)≤δ_T`；normal→warm→hot→critical 单调，切换经 C-RAS-WM† 认证与换装不变式，控制连续无突变。

**定理 20（认证增广不放大 R69 风险）** AFD 与 AAC 均通过时，增广只经“校准后先验”影响 U_ale/U_epi，偏差被 `L·D_fid` 界住，R69“问错比不问更危险”的风险不被放大；任一证书失效则禁用增广、退回未增广 FLUID。

## 7. 本轮最大风险

**一句话**：CALOR-RAS 的全部安全性押在“热模型与增广保真度可信”这一前提上——**一旦热模型漏掉一个未建模热源、或增广把幻影模态写进训练分布，TCC 就会在最热的时刻超支算力、TSE 给出乐观的力矩包络、AAC 把错误先验盖成“已认证”，把 R69 的“会提问”降级为“在错误的物理与数据地基上自信地提问”**。

**次级风险与缓解**：热模型失配（TSE 保守裕度 + 热态 OOD 检测 + 不可辨识退最保守）；增广幻影/覆盖丢失（AFD 可达性 + 模态保留 + 引理 20 界 + 失败即禁用）；增广投毒/热伪装（provenance 哈希 + 多源一致 + ℰ_aug 对抗训练 + 引理 21）；热侧信道（负载-温度一致性核验 + critical 停机）；地基层被绕过（离线/在线分离 + 证书固定 aug_version）。
