# 第 11 轮（新灵感循环第 3 轮；本轮灵感：「实例分割」×「动作分块」）
> **基线**：第 10 轮 MetricVoiceGauge-LRC（定义 540–549；引理 87–93；实验 E571–E590）。
> 本轮纪律：**实例优先 + 确定性分层 + 同境比较**。两个灵感各治 v10 的一处要害——「实例分割」治**盲聚合债**（v10 的 L0 用 `min_k min_o` 把全部障碍压成一个标量间隙，既丢身份也丢紧度），「动作分块」治**边界与赢家通吃债**（v10 在块边界硬切换、且用全局排行榜选唯一块）。仍以中立元退化链保证：TEE 失效退回 v10 winner-take-all，CSL 失效退回 v10 全局排行榜，OIS 失效退回 v10 球膨胀 L0，全失效退回 v10→v9→v8→v7→v6。

## 0. 直觉与动机

**灵感 1（实例分割 → 义务实例优先的硬界与归因）**
直觉：v10 的 L0 把世界看成一张均匀的「语义 stuff」图：计算 `ĝ⁰ = min_k min_o dist_lower(R_k, O ⊕ Ball(r_o))`。这在第一性原理上犯了两个错。其一，**紧度**：对所有障碍统一膨胀 `Ball(r_o)`，对细长/贴墙物体极其保守，把大量本可安全通过的块误拒，直接制造 v10 自陈的「L0 过松 → 长期回退 K=1」性能债。其二，**身份**：`min` 把「是谁在绑定」抹掉了；证书只回答「还差多少」，不回答「差在哪个实例、这个实例此刻可见还是被遮」。实例分割给的正是一张**可数 things + stuff** 的世界图：每个实例有 mask（形状）、稳定 id（身份）、amodal 包络（被遮时该占哪里）、可见性分割与遮蔽图。于是把标量间隙升级为**每实例间隙 + 绑定实例序列**：证书在每步对「绑定实例」做合取，mask 形状替代球膨胀带来紧度，amodal/遮蔽推理在遮挡下仍然保守，而 `b_k = argmin_o ĝ_{o,k}` 直接给出下游需要的**实例段标签**。核心创新：**实例分割硬界（InstanceMaskBound, IMB）** 与 **实例段证书**。

**灵感 2（动作分块 → 实例段一致的安全时序集成）**
直觉：v10 已有分块，但是「赢家通吃 + 硬边界」：块边界处新旧块可以突变（jerk/模式跳变），而块内开环执行会把前向模型误差一路累积。动作分块（action chunking）的第一性原理不是「预测更长」，而是**在边界处把重叠的多个预测融合**（temporal ensembling），用冗余对冲模型误差。但机器人不是 ACT 的模仿学习——我们不能直接把多条轨迹平均，那会破坏硬证书。破解的关键是**用实例段给融合上锁**：只有当若干候选块在同一前缀上**逐点绑定到同一实例、且彼此的实例间隙与动作都在容差内**（实例段一致），才允许把它们做加权集成；且只执行所有块都同意的**共识前缀**，前缀之外立即重规划。混合引入的偏差由运动学 Lipschitz 敏感度 `δ_Lip·ε_cons` 折算进证书裕度，从而**可证明**地仍落在安全走廊内。核心创新：**实例一致分块（InstanceConsistentChunker, ICC）** 与 **安全时序集成执行器（TemporalEnsembleExecutor, TEE）**。

**灵感 3（合成：实例分割 × 动作分块 → 同境比较，结构性消除虚假确定性）**
直觉：v10 自陈的最大风险是「排行榜的成对比较恰恰来自同一个可能失配的前向模型，可能把最不坏的候选一致地排到首位」。根因是排行榜在**不可比的语境之间**比较：块 A 此刻由近处行人绑定，块 B 由远端墙绑定，模型整体标定漂移会同时抬高一侧，使全局 argmax 稳定偏向「看起来都还行」的那类。实例分割让语境**可测**——每块有 per-step 绑定实例序列 `b_{1:K}`。于是规定：**统计比较（排行榜/集成）只在同一绑定上下文内进行，跨境决策交给模型无关的实例硬界**。这不是调参，而是**结构性**地堵死了「学习模型跨语境合谋」的通路——学习模型永远无法压过一条确定性的实例下界。同一张实例图还让退化归因从「模块级」细化到「实例级」：`c_{m,o}` 说明模块 m 在为哪个实例兜底，从而牺牲榜能保护「当前正在绑定或安全关键」的实例所依赖的模块。核心创新：**同境排行榜（ContextScopedLedger, CSL）** 与 **实例分割退化图（InstanceSegDegradationMap, ISDM）**。

## 1. 研究问题（轮次升级版）

- **Q1（实例硬界的紧度与确定性）**：如何构造每实例 mask/遮蔽感知的硬界，使熟悉域 L0 通过率显著高于 v10 的球膨胀、且在 ID 切换/合并/amodal 误判下仍保持**确定性保守**？地图/已知形状的确定性实例与学习分割器给出的统计实例如何**分层**——学习 mask 只许经共形 `δ_seg` 收紧、绝不许放宽确定性下界（max 聚合单调性）？
- **Q2（共识前缀集成的可证安全）**：在容差 `(ε_cons, ε_gap)` 与运动学 Lipschitz `δ_Lip` 下，重叠块的时序集成何时保持原证书骨架？可集成的块数上限是多少（裕度被 `δ_Lip·ε_cons` 吃掉之前）？相对 winner-take-all，块边界 jerk 与模式切换能否显著下降而不牺牲成功率？
- **Q3（同境比较与实例退化的等价性）**：上下文分桶的排行榜能否**可证**避免 v10 的跨境虚假确定性，同时保持每个上下文内 `O(d√(T_κ log T_κ))` 的次线性遗憾？实例分割的贡献下界 `c_{m,o}` 能否保持 v10 退化等价、且永不牺牲「当前绑定或安全关键」实例所依赖的模块？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 实例优先律（Instance-First Attribution）**
任何证书判定与退化判定都必须**点名绑定实例**：不接受/拒绝不得只给标量，必须给出 `b_k` 序列与逐实例间隙；退化必须给出「牺牲模块服务于哪个实例」。无实例标签的聚合结论只能作为诊断，不能作为执行依据。

**P17 分割确定性分层律（Segmentation-Determinism Stratification）**
确定性 L0 只允许使用地图/已知形状实例的精确 mask + 运动学包络；学习分割器的动态实例只能以共形半径 `δ_seg`（覆盖率 1−α）进入统计层。下界聚合取 max、上界取 min，故统计层**只能收紧、不能放宽**确定性层；任一分层不可用即回退到更硬的层，绝不允许「用学习 mask 放宽硬界」。

**P18 同境比较与共识律（Same-Context Comparison & Consensus）**
排行榜与集成只允许在**实例段一致**的块之间进行；跨上下文决策必须由模型无关的实例硬界决定，学习模型无权跨语境排序。集成只执行共识前缀，并强制证书裕度 ≥ `d_safe + δ_Lip·ε_cons`；共识前缀为空 ⇒ 退回 v10 winner-take-all。

## 3. 与基线的接口（如何退化）

- TEE 不可用 / 共识前缀为空 ⇒ 退回 v10 winner-take-all 选块（仍用 ISB 实例硬界）；
- CSL 失效（上下文不可读 / 分桶崩溃）⇒ 退回 v10 全局 RankLedger（仍用 ISB）；
- ISDM 失效 ⇒ 退回 v10 模块级牺牲榜（仍用实例硬界与同境比较）；
- OIS/BIA 失效（分割器崩溃 / 实例 id 不可用）⇒ 退回 v10 球膨胀 L0 + 标量 min（确定性仍在，仅失去紧度与身份）；
- 上述任一叠加 v10 内部失效 ⇒ 按 v10 七级链：LWC→v9 AC、RL→v9 绝对评分、LCC→v9 运行时 EDF+ID；
- v9 的 AC/MW/ID 失效 ⇒ v9 定义 536 注入中立元，退回 v8；
- 全部失效 ⇒ MetricVoiceGauge-ISAC v11 → LRC v10 → ACMD v9 → DA-SPR-Cal v8 → OTL-GC-ER v7 → v6。

## 4. 预期贡献

1. **实例分割硬界**：mask/遮蔽感知的每实例下界 + 绑定实例序列；熟悉域 L0 通过率相对 v10 球膨胀显著提升，陌生域保持确定性保守，并把「模型误差风险」进一步下沉到纯几何；
2. **实例一致的安全时序集成**：共识前缀 + Lipschitz 裕度，把动作分块的重叠融合**可证**地接入硬证书，块边界 jerk 与模式切换显著下降；
3. **同境比较**：从结构上消除 v10「跨语境合谋」的虚假确定性，跨境由模型无关下界裁决；退化归因细化到实例级；
4. **四账本闭环**：证书账本（实例/层级）、排序账本（同境）、退化账本（实例分割）、一致性账本（共识前缀）互相校验；E591–E610 覆盖紧度、遮蔽、身份、集成、同境、守卫、退化与端到端。

## 5. 本轮最大风险

**一句话**：本轮把 v10 的「前向模型误差」换成了「实例身份误差」——一旦分割器发生 ID 切换/实例合并，或 amodal 推理把被遮区域误判为空，遮蔽感知与同境比较会**一致地**把真实的绑定实例当成「已离开/已消除」，从而制造出比 v10 更危险的自信错误；而补救（身份不确定性膨胀 `δ_seg`）又会把好不容易收紧的 L0 重新放宽，抵消本轮全部紧度收益。

## 1. 符号体系增量（定义 550–560）

| 符号 | 含义 |
|---|---|
| 𝒪_t = 𝒯_t ⊔ 𝒮_t | 义务实例集：things（可数实例）与 stuff（语义区域）的 panoptic 分区 |
| id_o, M_o | 实例 o 的稳定身份与 mask（精确形状） |
| am(o), vis(o) | amodal 包络与可见区域，`hidden(o)=am(o)\vis(o)` |
| det(o) | 确定性标志：true 表示地图/已知形状实例，false 表示学习分割实例 |
| E_o | 实例保守包络（确定性：精确 mask；学习：可见/被遮分层共形膨胀） |
| ĝ_{o,k} | 实例 o 在第 k 步的间隙下界 |
| b_k = argmin_o ĝ_{o,k}, b_{1:K} | 第 k 步绑定实例、整块绑定实例序列（实例段标签） |
| ≐_seg | 实例段一致关系 |
| L_cons | 共识前缀长度 |
| ε_cons, ε_gap | 动作一致容差、实例间隙一致容差 |
| δ_Lip | 运动学 Lipschitz 敏感度（动作偏差 → 间隙变化上界） |
| δ_seg, ε_vis | 共形分割误差半径、可见区域测量误差 |
| κ = b_{1:K} | 同境上下文键 |
| c_{m,o} | 模块 m 对实例 o 的贡献下界 |

**新增定义 550（义务实例与 panoptic 分区）** 时刻 t 的义务实例集
```
𝒪_t = 𝒯_t ⊔ 𝒮_t
thing o ∈ 𝒯_t : (id_o, M_o, am(o), vis(o), det(o))
stuff s ∈ 𝒮_t : 地图/语义区域的精确 mask M_s（det=true）
```
`id_o` 由实例追踪（数据关联）维持；`det(o)=true` 仅指地图或已知形状实例，其 mask 视为精确（继承 v10「障碍地图无误」假设）；`det(o)=false` 的学习实例全部走共形层（定义 559）。

**新增定义 551（实例分割硬界 Instance-Mask Hard Bound）**
```
R_0 = {s},  R_k = R_{k-1} ⊕ [v_min,v_max]Δt ⊕ ½[a_min,a_max]Δt²
E_o = det(o) ? M_o : E_o^occ                      # 见定义 552
ĝ_{o,k}^{(0)} = dist_lower(R_k, E_o) − ε_ulp
ĝ_k^{(0)} = min_{o∈𝒪_t} ĝ_{o,k}^{(0)}
```
与 v10 的关键差异：用实例 mask `E_o` 取代对所有障碍统一的 `O ⊕ Ball(r_o)`。因 `M_o ⊆ O ⊕ Ball(r_o)`，对**子集**取 `dist_lower` 得到**更大**的下界（更紧），且只要 `E_o ⊇ 真实占据` 就仍保守。确定性实例精确、不含学习参数，故对域偏移**确定性不变**。

**新增定义 552（可见/被遮分层的遮蔽感知包络）**
```
E_o^occ = (vis(o) ⊕ Ball(ε_vis)) ∪ (hidden(o) ⊕ Ball(δ_seg)),   0 ≤ ε_vis ≤ δ_seg
```
可见部分由传感器直接观测，只需小测量误差 `ε_vis`；仅被遮部分需 amodal 的大误差 `δ_seg`。因真实占据 `⊆ vis(o)∪hidden(o)=am(o)`，且两部分误差分别被 `ε_vis`、`δ_seg` 覆盖，故 `E_o^occ ⊇ 真实占据`；又因可见部分不再享受全额 `δ_seg` 膨胀，比 `am(o)⊕Ball(δ_seg)` 更紧。`det(o)=true` 时 `E_o=M_o`（无膨胀）。

**新增定义 553（绑定实例序列 Binding-Instance Sequence）**
```
b_k = argmin_{o∈𝒪_t} ĝ_{o,k},   并列按 id_o 升序（确定性 tie-break）
b_{1:K} = (b_1, …, b_K)                                   # 实例段标签
```
块证书等价于 `∧_{k} [ ĝ_{b_k,k} ≥ d_safe ]`；与 v10 标量 `min` 数学等价但**保留身份**，供同境比较（定义 557）、实例段一致（定义 554）与实例退化（定义 558）使用。

**新增定义 554（实例段一致 Instance-Segment Consistency）** 两块 ζ^a, ζ^b 在前缀 ℓ 上实例段一致 `ζ^a ≐_seg ζ^b` 当且仅当
```
∀k ≤ ℓ:  b^a_k = b^b_k  ∧  |ĝ^a_{b_k,k} − ĝ^b_{b_k,k}| ≤ ε_gap  ∧  ‖a^a_k − a^b_k‖ ≤ ε_cons
```
即：逐点绑定到**同一实例**、该实例间隙估计一致、动作偏差受控。

**新增定义 555（共识前缀 Consensus Prefix）** 对候选集成 `ℰ={ζ^1,…,ζ^m}`，
```
L_cons = max{ ℓ : ∀ i,j∈ℰ,  ζ^i ≐_seg ζ^j on 1..ℓ }
```
`L_cons = 0` ⇒ 无共识，退回 v10 winner-take-all（Level-1 退化），绝不对不一致块做平均。

**新增定义 556（安全时序集成 Safe Temporal Ensembling）** 对 `k ≤ L_cons` 执行
```
w_i(k) = exp(−λ·age_i),   ā_k = Σ_i w_i(k)·a^i_k / Σ_i w_i(k)
准入裕度：Ĝ_{b_k,k} ≥ d_safe + δ_Lip·ε_cons
```
其中 `Ĝ_{b_k,k} = min_i ĝ^i_{b_k,k}`。混合只在前缀内、且证书以额外 Lipschitz 裕度收紧后放行（引理 97）。

**新增定义 557（同境排行榜 Context-Scoped RankLedger）** 以 `κ=b_{1:K}`（或滑动窗口哈希）对可行集分桶 `ℱ_t = ⊔_κ ℱ_κ`。仅对同桶候选做成对比较
```
∀i,j∈ℱ_κ:  y∼Bernoulli(σ(u_i−u_j)),  u_i=w_κᵀφ(ζ_i)
q_i = w_κᵀφ_i − β_t‖φ_i‖_{Σ_κ^{-1}},   β_t = z√(d·log(1+t_κ))
```
桶内沿用 v10 定义 543 的 `δ_rank` 迟滞；**跨桶只用模型无关 `ĝ` 直接裁决，不进入排行**。共同标定漂移 `c_κ` 在桶内成对差中抵消（BT 对公共平移不变），故桶内选择稳健；跨桶由硬界兜底。

**新增定义 558（实例分割贡献与退化图）**
```
c_{m,o} = 模块 m 对实例 o 的贡献下界（离线归因，写回 ID）
critical(o) = (o 为当前绑定实例) ∨ (φ_o^safe)
eligible(m) = ¬∃o: critical(o) ∧ (m∈serve(o))        # 服务关键实例的模块不可牺牲
≺_deg: 按 (Σ_o c_{m,o}, −Ŵ_m) 升序排列 eligible(m)，其余置尾
```
安全关键/当前绑定实例所依赖模块强制 `eligible=false` 且永在榜尾，继承 v10 的定义 545 资格约束。

**新增定义 559（共形分割误差半径 Conformal Segmentation Radius）** 在标定集上用非一致性得分（如 1−mask IoU / amodal 包络覆盖率）取 `1−α` 分位：
```
δ_seg = Quantile_{1−α}({ s(o_i) })      ⇒  P(真实占据 ⊆ E_o^occ) ≥ 1−α（可交换性下）
```
`δ_seg` 仅用于**学习实例**的膨胀，且下界聚合取 `max`，故统计层只能收紧、不能放宽确定性层。

**新增定义 560（实例漂移守卫 Instance-Drift Guard）** 50Hz 每拍做两件 O(#active) 检查：
```
(1) 新实例：∀o'∉cached.active, 若 dist_lower(p_t, E_{o'}) < d_safe + v_max·Δt ⇒ 作废当前块，回 5Hz
(2) id 失效：若 b_k 的 id_o 消失但对应 mask 能量未减 ⇒ 判为 ID 切换，δ_seg ← δ_seg + δ_switch，重新认证
```
不触碰前向模型，只做几何与 id 校验，代价 O(#active)。

class ObligationInstanceSegmenter:
    def __init__(self, tracker, conformal_radius):
        self.tracker, self.delta_seg = tracker, conformal_radius

                                   visible=m.exact_mask, det=True))

# IP-362/363 IMB + BIA：每实例硬界 + 绑定实例序列
class InstanceMaskBound:
    def __init__(self, kin, ulp=1e-6):
        self.kin, self.eps = kin, ulp

    def certify(self, state, actions):
        reach = {state.p}
        per_step = []                              # [(k, {o: gap})]
        for k, a in enumerate(actions):
            reach = self.kin.minkowski_step(reach, a, state.dt)
            gaps = {o.id: self.kin.dist_lower(reach, o.envelope()) - self.eps
                    for o in state.instances}
            per_step.append((k, gaps))
        bounds = [CertStep(k, gaps,
                           binding=min(gaps, key=lambda i: (gaps[i], i)))
                  for k, gaps in per_step]
        g_min = min(min(c.gaps.values()) for c in bounds)
        return InstanceCert(g_min, bounds, level=0)   # 保留每步绑定实例

    def refine(self, state, actions, cert):
        if cert.level == 0:                        # L1 残差：按实例收紧
            r = self.model.residual_bound(state, actions[0]) + state.beta
            return cert.tighten(-r)
        pred = self.model.rollout(state, actions)  # L2 v10 全 rollout
        return cert.replace_level2(pred, state.beta)


class BindingInstanceAttributor:
    @staticmethod
    def sequence(cert):                            # b_{1:K}
        return tuple(step.binding for step in cert.bounds)


# IP-364 ICC：实例段一致 + 共识前缀
def instance_segment_consistency(cert_a, cert_b, eps_gap, eps_cons, acts_a, acts_b):
    for sa, sb, aa, ab in zip(cert_a.bounds, cert_b.bounds, acts_a, acts_b):
        if sa.binding != sb.binding:                          return False
        if abs(sa.gaps[sa.binding] - sb.gaps[sb.binding]) > eps_gap:  return False
        if norm(aa - ab) > eps_cons:                          return False
    return True


def consensus_prefix(ensemble, eps_gap, eps_cons):
    L = min(len(e.cert.bounds) for e in ensemble)
    for k in range(L):
        ref = ensemble[0]
        for e in ensemble[1:]:
            if not step_consistent(ref, e, k, eps_gap, eps_cons):
                return k
    return L


# IP-365 TEE：安全时序集成，只执行共识前缀
class TemporalEnsembleExecutor:
    def __init__(self, lam=0.1, eps_cons=0.02, delta_lip=0.05):
        self.lam, self.eps_cons, self.delta_lip = lam, eps_cons, delta_lip

    def execute_prefix(self, ensemble, L, k_clock):
        acts = []
        for k in range(L):
            ws = [math.exp(-self.lam * (k_clock - e.t0 + k)) for e in ensemble]
            a = sum(w * e.actions[k] for w, e in zip(ws, ensemble)) / sum(ws)
            # 准入：以 Lipschitz 裕度收紧后的证书
            ghat = min(e.cert.gap_at(k, e.cert.binding_at(k)) for e in ensemble)
            if ghat < self.d_safe + self.delta_lip * self.eps_cons:
                return acts, "reject"              # 裕度不足 ⇒ 保守中止/回退
            acts.append(a)
        return acts, "ok"


# IP-366 CSL：同境排行榜（桶内比较，跨境由硬界裁决）
class ContextScopedLedger:
    def __init__(self, d=16, z=1.64, delta_rank=0.15, eta=0.08):
        self.ledgers = {}                           # κ -> (w, Σ, incumbent)
        self.z, self.delta_rank, self.eta = z, delta_rank, eta

    def select(self, feasible):
        best = None
        for kappa, bucket in group_by_context(feasible).items():
            led = self.ledgers.setdefault(kappa, _Ledger(d))
            sel = led.select_with_hysteresis(bucket, self.delta_rank)
            score = max(sel.cert.g_min for sel in [sel])  # 跨境用模型无关硬界
            if best is None or score > best[0]:
                best = (score, sel)
        return best[1]


# IP-367 ISDM：实例分割退化图

    def degrade_order(self, schedule, budget_remaining, instances, binding):

## 3. 推导

**引理 94（实例硬界的确定性与保守性）** 设确定性实例 `det(o)=true` 的 mask 精确且真实占据 `⊆ E_o=M_o`，运动学包络覆盖真实可达，则 ∀k：`R_k ⊇ 真实可达`，故 `ĝ_{o,k} = dist_lower(R_k,E_o) − ε_ulp ≤ 真实最小间隙`，`min_o` 后仍 ≤ 真实。该支路不含任何学习参数，对域偏移确定性不变。学习实例经定义 559 共形膨胀满足 `P(真实占据 ⊆ E_o^occ) ≥ 1−α`，仅提供统计保守。证明：`dist_lower` 对超集取下界；`ε_ulp ≥ 8 ULP` 覆盖 K 步浮点累计上界（同 v10 引理 87）；`det` 支路无学习量故不变。∎

**引理 95（相对球膨胀的紧度增益）** 记 v10 下界 `ĝ^{v10}_k = dist_lower(R_k, O⊕Ball(r_o))`，ISB 下界 `ĝ^{ISB}_{o,k} = dist_lower(R_k, M_o)`。因 `M_o ⊆ O⊕Ball(r_o)`，对子集取 `dist_lower` 得 `ĝ^{ISB}_{o,k} ≥ ĝ^{v10}_k`，且仍 `≤` 真实间隙（引理 94），故更紧且保守。对长宽比 ρ、膨胀半径 `r_o` 的细长实例，间隙增益随 `r_o` 与 ρ 增大；学习实例因可见部分仅用 `ε_vis < δ_seg` 膨胀，同样严格优于全额 `δ_seg`。紧度提升直接扩大 L0 可行集，缓解 v10 的「L0 过松 → K=1 回退」性能债。证明：距离函数对集合单调反变；分层膨胀半径不等式逐项成立。∎

**引理 96（分割确定性分层的单调收紧）** 设可用下界集合为 `{ĝ_det} ∪ {ĝ_stat}`，聚合 `G = max`。加入统计界只可能增大 G，绝不减小；移除统计界回退到 `G_det ≤ G`。故学习 mask 永远无法把确定性下界**放宽**（P17）。对安全关键实例，接受判据强制 `G_det ≥ d_safe`；非关键实例可按 `G ≥ d_safe` 且统计界覆盖率 `1−α` 接受（继承 v10 的统计接受语义）。证明：`max` 对集合扩张单调不减；移除元素给出更小值；接受判据按实例类别分派。∎

**引理 97（共识前缀集成的可证安全）** 设间隙对动作 `δ_Lip`-Lipschitz（由有界 v/a 包络与固定 Δt 保证）。若集成中各块均认证 `ĝ^i_{b_k,k} ≥ d_safe + δ_Lip·ε_cons`，且任意两块 `‖a^i_k − a^j_k‖ ≤ ε_cons`、绑定同一实例，则凸组合 `ā_k` 满足 `‖ā_k − a^i_k‖ ≤ ε_cons`，真实间隙
```
g(ā_k) ≥ g(a^i_k) − δ_Lip‖ā_k−a^i_k‖ ≥ ĝ^i_{b_k,k} − δ_Lip·ε_cons ≥ d_safe
```
故混合后仍安全；且 `L_cons` 有限保证在有限步后重规划（无开环失控）。证明：凸组合落在 `ε_cons` 球内；Lipschitz 给出间隙下界；认证裕度已预付 `δ_Lip·ε_cons`。∎

**引理 98（同境比较消除跨境虚假确定性与遗憾分解）** 桶内效用 `u_i = w_κᵀφ_i`，若存在桶内公共平移 `u_i → u_i + c_κ`，则成对差 `u_i−u_j` 不变，BT 似然与 argmax 不变，故桶内选择对公共标定漂移**不变**；跨桶决策使用模型无关 `ĝ` 而非学习排行，故 v10「单一全局排行榜跨语境合谋」的失效路径**不可达**。遗憾按桶分解：`Reg(T) ≤ Σ_κ O(d√(T_κ log T_κ)) + 0 ≤ O(d√(K T log T))`（Cauchy–Schwarz）。证明：BT 对公共平移不变；跨境由确定性下界裁决，学习模型无跨桶话语权；每桶标准 logistic bandit 椭圆置信集界求和。∎

**引理 99（实例漂移守卫的拍内完备性）** 守卫周期 `Δt=20ms`，最大位移 `≤ v_max·Δt`。若某实例能在一拍内使间隙跌破 `d_safe`，则当前必满足 `dist_lower(p_t,E_o) < d_safe + v_max·Δt`（三角不等式）；守卫按定义 560(1) 枚举所有满足该式的实例并核对其是否在 `cached.active`，任一缺席即作废整块。故在**检测覆盖**的前提下，拍内不会漏掉已探测实例。检测漏检是残余风险（见第 8 节）。证明：位移上界 + 三角不等式给出必要条件；穷举该必要集合并包含全部候选。∎

**引理 100（实例分割退化的等价与安全）** ISDM 仅重排 `eligible` 模块（`φ^elig=true`）；服务当前绑定或安全关键实例的模块被强制 `eligible=false` 且置尾，永不进入 `order`；注入值仍取自 v10 表 536。故当 ISDM 默认回退时与 v10 定义 545 逐位等价，且安全关键模块 0 被牺牲。证明：资格约束继承 v10 定义 545 与表 536；实例级保护是资格约束的加强而非放宽。∎

**引理 101（复杂度与预算可组合）** IMB 每步 `O(#active·d_s)`，实例追踪复用使 `#active` 有界，典型 `≤0.06ms`；共识前缀 `O(m·K)`，`m≤8`；CSL `O(Σ_κ n_κ d²)`；IDG `O(#active)`。故
```
B_cycle ≤ w_perc(2ms) + w(ℬ)/10 + w_guard(0.12ms) + w_ISB(0.06ms) + w_v10(4ms)
```
在 `ℬ=2` 时 `≤ 2 + 1.2 + 0.12 + 0.06 + 4 = 7.38ms`，50Hz（20ms）余量 `≥12.6ms`；与 v10 引理 92 可组合。∎

## 8. 本轮最大风险

**一句话**：本轮把 v10 的「前向模型误差」换成了「实例身份误差」——一旦分割器发生 ID 切换/实例合并，或 amodal 推理把被遮区域误判为空，遮蔽感知与同境比较会**一致地**把真实的绑定实例当成「已离开/已消除」，从而制造出比 v10 更危险的自信错误；而补救（身份不确定性膨胀 `δ_seg`）又会把好不容易收紧的 L0 重新放宽，抵消本轮全部紧度收益。
