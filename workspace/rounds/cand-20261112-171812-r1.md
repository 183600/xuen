# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 1 轮；本轮灵感：「指令泛化」×「多模态交互」）

> 第 60 轮实现了「认知驱动的场景-执行闭环」：SSM 场景语义建模、CIEC 认知意图约束、EPIR ROS 因果隔离、SERC 场景感知闭环、PCE++++ 四维认知预算，并以 SIC 三元校验与 CES 决策收口。但 **CIEC 的三个结构性局限**在本轮开始暴露：
> 1. **意图映射是闭集查表**：`I={'慢点','加紧','轻触','稳定','危险'}` 与 `ϕ_intent→constraint` 是硬编码字典。真实指令是**开放词表 + 组合式**的（「轻轻地把杯子挪到桌沿，别碰到旁边的水杯」包含 manner×object×relation×temporal 的未见组合），查表法对未见组合的泛化能力为零。
> 2. **意图证据是单模态符号**：CIEC 只吃一个 `intent` token，丢弃了指点手势、注视、力反馈示教、表情与韵律。指代（「那个」「这里」）无法仅凭文本消解；「轻一点」究竟是**限力**还是**降刚度**，也只有结合示教/手势才可确定。
> 3. **无泛化置信度、无拒识机制**：查表对分布内与分布外指令施加同样「自信」的约束——这恰是第 60 轮自己点名的最大风险。缺少「这条指令我到底懂不懂」的**保形（conformal）不确定性**与**拒识/澄清**能力。

## 0. 直觉与动机

**灵感 1（指令泛化 → 组合语义接地 CIG）**
直觉：泛化不来自「记住更多指令」，而来自「拆成更小的语义积木再重组」。把一条指令拆成 action×object×relation×manner×magnitude×temporal 六类原语，每个原语对应约束格上的一个算子；未见指令只要是「见过的积木的新拼法」，就能组合出正确约束。关键洞见：**约束天然构成一个格（lattice），组合就是格的 meet（收紧）**——「轻轻地」与「杯子易碎」不是两条规则相加，而是两次 meet 到同一个约束下界。

**灵感 2（多模态交互 → 多模态意图接地 MIG）**
直觉：人说话时手指、眼睛、身体从不闲着。语音给「语义」，手势/注视给「指代」，示教给「物理量级」，语气给「程度」。多模态接地 = 把指代表达绑定到感知实体（deixis resolution）+ 把各模态证据按可靠度做专家乘积融合。关键洞见：**指代消解本质是一个带多模态对齐分数的二部匹配问题**（匈牙利算法），而模态冲突（说「轻」但示教很重）是**必须先检出、再澄清**的一等公民，不能被加权平均悄悄吞掉。

**灵感 3（泛化安全 → 保形约束接地 CCG）**
直觉：泛化的反面是「自信地误解」。用保形预测给「指令→约束」映射戴上统计安全帽：在校准集上估计非一致性分数阈值 q̂，得到**约束预测集 C_α(x)**，保证真实约束以 1-α 的概率落在其中。当语义 OOD 距离或预测集直径过大（γ>τ_gap），不猜，而是**拒识/澄清**。关键洞见：**「我懂」应是一个可被统计证伪的断言**，而不是解析器的一句口头保证。

**灵感 4（主动澄清 → 有预算的澄清对话 ACD）**
直觉：不懂就问，但问要有价值、有上限。澄清 = 选一个使「真实约束」互信息最大的问题（确认/消歧/量化/换模态），受澄清预算约束；边际信息增益低于阈值即停，预算耗尽则回退保守约束并显式标注 `semantic_uncertainty`。

**灵感 5（合流 → 多模态指令接地闭环 MIGL）**
直觉：MIG 融合 → CIG 组合 → CCG 保形 → ACD 澄清 → CIEC 锁定 → SERC 执行 → EPIR 证据 → 回灌校准集。把第 60 轮「场景先验→执行」闭环的前端，接上一整套「指令理解→约束」的**可泛化、可拒识、可追溯**语义接地层。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（组合指令接地 CIG）** 设语义原语空间 𝒫 = 𝒜 × 𝒪_attr × ℛ × ℳ × 𝒢 × 𝒯，其中 𝒜 动作动词、𝒪_attr 带属性物体、ℛ 空间关系、ℳ 方式副词、𝒢 量级、𝒯 时序限定。组合解析器 `Parse: Σ* → SF(x) ∈ Tree(𝒫)` 将指令映射为带类型的语义树。约束空间 (𝒞, ⊑, ⊓, ⊔, ⊤, ⊥) 是 ERTC 契约域上的格，`⊑` 表示「更紧/更安全」。原语约束映射 `κ: 𝒫 → 𝒞` 需**单调**：`p ⊑_𝒫 p′ ⇒ κ(p) ⊑_𝒞 κ(p′)`。组合：
- 合取修饰：`C_comp(x) = ⊓_{p∈leaves(SF(x))} κ(p)`；
- 时序修饰：定义时间索引约束族 `{C_t}`，执行时按 t 顺序收紧。

**组合泛化能力**：只要 `leaves(SF(x)) ⊆ 𝒫_cov`（原子原语已覆盖、组合未见过），`C_comp(x)` 就有定义。**原语覆盖度** `cov(x)=|{p∈SF(x):p∈𝒫_cov}| / |SF(x)|`。

**定义 162（多模态意图接地 MIG）** 模态集 ℳ_m = {Speech, Gesture, Gaze, Haptic, Expression}。模态 m 给出证据 `e_m=(π_m(SF), ρ_m, τ_m)`，π_m 为语义树上分布，ρ_m∈[0,1] 可靠度，τ_m 时间戳。**专家乘积融合**：
`π_fused(SF) = (1/Z) · Π_m π_m(SF)^{ρ_m}`。
**指代接地**：指代表达集 ℰ_ref 与感知实体集 𝒪_det 的二部匹配，多模态对齐分数
`s(e,o)=λ_g·sim_g(gaze_ray,o)+λ_p·sim_p(point_ray,o)+λ_l·sim_l(emb(e),emb(o))`，
用匈牙利算法求 `M*=argmax Σ_{(e,o)∈M} s(e,o)`，并以 τ_match 过滤。
**冲突度量**：`conflict = max_{m,m′} JS(π_m ‖ π_m′)`（或 `D_KL(π_m ‖ π_fused)`）。

**定义 163（保形约束接地 CCG）** 校准集 `D_cal={(x_i,C_i*)}`，非一致性分数
`s(x,C)=d_𝒞(C,C*(x)) + λ_s·(1-cov(x))`。
保形阈值 `q̂_{1-α}` 为校准分数的 `⌈(n+1)(1-α)⌉/n` 分位数。约束预测集
`C_α(x) = { C∈𝒞_cand(x) : s(x,C) ≤ q̂_{1-α} }`。
**保形保证**（可交换性下）：`P(C*(x) ∈ C_α(x)) ≥ 1-α`。
**泛化间隙** `γ(x)=w_OOD·d_OOD(x)/d_ref + w_diam·diam(C_α(x))/diam_max`，其中 `d_OOD(x)=min_i d_SF(x,x_i)` 为语义分布外距离。
**拒识规则**：若 `γ(x)>τ_gap` 或 `C_α(x)=∅` ⇒ `ABSTAIN`（转 ACD）。

**定义 164（主动澄清对话 ACD）** 查询集 𝒬 = 𝒬_confirm ∪ 𝒬_disamb ∪ 𝒬_quantify ∪ 𝒬_modality（确认「你是指…吗」／消歧「哪一个」／量化「多轻，0–10」／换模态「请示范一下」）。选择规则：
`q* = argmax_{q∈𝒬} [ I(C; Ans(q) | π_fused) − λ_c·cost(q) ]`，
受澄清轮次预算 `B_clarify` 与响应时延 τ_response 约束。停止条件：边际互信息 < θ_ig 或轮次耗尽。
预算耗尽仍未收敛：输出 `C_cons = κ(most-likely primitive) ∩ C_safe_base`，并打标 `semantic_uncertainty=true`。

**定义 165（多模态指令接地闭环 MIGL）** 算子 `MIGL(M, instr_mm, scene, budget)`：
```
① MIG.fuse(instr_mm.evidence)       → π_fused, ref_bindings
② CIG.parse + ground(instr_mm.text) → SF, C_comp, cov
③ CCG.ground(SF, π_fused)           → C_α, γ, verdict
④ if γ>τ_gap ∨ conflict>τ_conflict ∨ C_α=∅:
       (C_intent, trace) ← ACD.run(π_fused)
   else:
       C_intent ← C_α ∩ C_comp
⑤ CIEC(60).receive(C_intent): ERTC.lock(C_intent)，记录 τ_response
⑥ SERC(60): SSM 场景先验 + C_intent → EEIS.compile → K_safe → execute → EV-exec
⑦ EPIR(60): 持久化 EV-exec，因果同步
⑧ Feedback: D_cal ← D_cal ∪ {(instr, 实测约束)}；按需更新 𝒫_cov
⑨ Return (C_intent, γ, ref_bindings, EV-exec, MAC)
```

**定义 166（语义预算 B_sem 与 PCE+++++）** `B_sem=(B_parse, B_ground, B_clarify, B_calib)`，与第 60 轮 `B_cog=(B_scene,B_intent,B_ros,B_exec)` 合并为 `B_all = B_cog ⊕ B_sem`。耗尽策略：
- `B_parse` 耗尽 ⇒ 退化为关键词匹配（degraded parse）；
- `B_ground` 耗尽 ⇒ 仅用语言 + 默认坐标（模态消融）；
- `B_clarify` 耗尽 ⇒ 保守约束 + `semantic_uncertainty` 标注；
- `B_calib` 耗尽 ⇒ 冻结 q̂ 并增大 τ_gap（更保守）。

**定义 167（语义-阻抗-置信度四元组 SIC+）** `SIC+ = (scene_conf, semantic_conf, K_certainty, execution_feasibility)`，其中
`semantic_conf = (1-γ)·max_{SF} π_fused(SF)`。
`SIC+_valid = scene_conf≥τ_scene ∧ semantic_conf≥τ_sem ∧ K_certainty≥τ_K ∧ execution_feasibility=true`。
更新：`semantic_conf ← semantic_conf·β + (1-β)·[1 − 1{EV-exec 与指令冲突}]`，β 为记忆系数。

**定义 168（多模态对齐证书 MAC）** `MAC=(provenance, alignment_edges, conformity, conflict_trace, clarification_trace)`。`provenance` 记录每个原语来自哪个模态、哪一帧；`alignment_edges` 为指代绑定；`conformity` 为 q̂ 下 `s(x,C_intent)`；与 EPIR 的 EV-exec 哈希链绑定，使「指令理解」也可追溯、可复现、可审计。

```python
class ConstraintLattice:
    TOP = Constraint(v_max=inf, F_max=inf, K_p=inf, K_d=0.0, eps_traj=inf)

    def meet(self, a, b):
        return Constraint(
            v_max=min(a.v_max, b.v_max), F_max=min(a.F_max, b.F_max),
            K_p=min(a.K_p, b.K_p), K_d=max(a.K_d, b.K_d),
            eps_traj=min(a.eps_traj, b.eps_traj))

    def leq(self, a, b):  # a ⊑ b : a 更紧/更安全
        return (a.v_max <= b.v_max and a.F_max <= b.F_max
                and a.K_p <= b.K_p and a.K_d >= b.K_d
                and a.eps_traj <= b.eps_traj)

KAPPA = {

class CompositionalInstructionGrounder:
    def __init__(self, kappa, lat):
        self.kappa, self.lat = kappa, lat
        self.parser = SemanticParser()      # typed seq2tree
        self.covered = set(kappa)

    def ground(self, x):
        sf = self.parser.parse(x)
        leaves = list(sf.leaves())
        C, unknown = self.lat.TOP, []
        for p in leaves:
            if p in self.kappa:
                C = self.lat.meet(C, self.kappa[p])
            else:
                unknown.append(p)
        cov = 1.0 - len(unknown) / max(1, len(leaves))
        return C, sf, cov, unknown
```

### IP-162 MIG（多模态意图接地）

```python
class MultimodalIntentGrounder:
    def __init__(self, lam=(0.4, 0.4, 0.2), tau_match=0.6):
        self.lam, self.tau_match = lam, tau_match

    def fuse(self, evidence):                      # evidence[m]=(logp, rho, t)
        scores = defaultdict(float)
        for m, (logp, rho, _t) in evidence.items():
            for sf, lp in logp.items():
                scores[sf] += rho * lp
        mx = max(scores.values())
        Z = sum(np.exp(v - mx) for v in scores.values())
        return {sf: np.exp(v - mx) / Z for sf, v in scores.items()}

    def conflict(self, evidence):
        ms = list(evidence)
        return max((js_div(evidence[a][0], evidence[b][0])
                    for i, a in enumerate(ms) for b in ms[i + 1:]), default=0.0)

    def ground_reference(self, refs, dets, gaze, point):
        S = np.zeros((len(refs), len(dets)))
        for i, e in enumerate(refs):
            for j, o in enumerate(dets):
                S[i, j] = (self.lam[0] * gaze_score(gaze, o)
                           + self.lam[1] * point_score(point, o)
                           + self.lam[2] * sem_sim(e, o))
        r, c = linear_sum_assignment(-S)           # 匈牙利算法
        return {refs[i]: dets[j] for i, j in zip(r, c) if S[i, j] >= self.tau_match}
```

### IP-163 CCG（保形约束接地）

```python
class ConformalConstraintGrounder:
    def __init__(self, alpha=0.1, tau_gap=1.0):
        self.alpha, self.tau_gap = alpha, tau_gap
        self.qhat, self.d_ref, self.diam_max = np.inf, 1.0, 1.0

    def calibrate(self, cal, score_fn):
        s = np.sort([score_fn(x, C) for x, C in cal])
        n = len(s)
        k = min(int(np.ceil((n + 1) * (1 - self.alpha))), n)
        self.qhat = s[k - 1]

    def ground(self, sf, pi, cands, ood_dist):
        C_alpha = {C for C in cands
                   if self.score(sf, C, pi, ood_dist) <= self.qhat}
        gamma = (ood_dist / self.d_ref
                 + self._diam(C_alpha) / self.diam_max)
        if not C_alpha or gamma > self.tau_gap:
            return C_alpha, gamma, 'ABSTAIN'
        return C_alpha, gamma, 'ACCEPT'
```

### IP-164 ACD（主动澄清对话）

```python
class ActiveClarificationDialogue:
    def __init__(self, budget=2, theta_ig=0.05, theta_ent=0.3):
        self.budget, self.theta_ig, self.theta_ent = budget, theta_ig, theta_ent

    def best_query(self, pi):
        best, best_gain = None, -np.inf
        for q in self.query_space(pi):
            gain = self.mutual_info(pi, q) - self.cost(q)
            if gain > best_gain:
                best, best_gain = q, gain
        return (best if best_gain > self.theta_ig else None), best_gain

    def run(self, pi, ask_fn):
        trace = []
        for _ in range(self.budget):
            q, _g = self.best_query(pi)
            if q is None:
                break
            ans = ask_fn(q)
            pi = self.bayes_update(pi, q, ans)
            trace.append((q, ans))
        if self.entropy(pi) > self.theta_ent:
            return self.conservative(pi), trace, 'semantic_uncertainty'
        return self.map_constraint(pi), trace, 'ok'
```

```python
def multimodal_instruction_grounding_loop(M, instr_mm, budget):
    fused = M.mig.fuse(instr_mm.evidence)
    refs  = M.mig.ground_reference(
        instr_mm.refs, M.detections, instr_mm.gaze, instr_mm.pointing)

    C_comp, sf, cov, unknown = M.cig.ground(instr_mm.text)

    cands = M.ccg.enumerate(sf, fused, M.eeis)
    C_alpha, gamma, verdict = M.ccg.ground(
        sf, fused, cands, ood_dist=M.mig.ood_distance(sf))
    conflict = M.mig.conflict(instr_mm.evidence)

    if verdict == 'ABSTAIN' or conflict > M.tau_conflict:
        C_intent, trace, status = M.acd.run(fused, instr_mm.ask)
    else:
        C_intent, trace, status = C_alpha & C_comp, [], 'ok'

    M.intent_ctrl.receive(C_intent, status)          # CIEC(60) 约束锁定
    M, fused_x, D_plus, EV_exec, cert = scenario_perception_evolution_loop(
        M, M.scene, C_intent, M.delta_f_req)         # SERC(60)

    mac = MAC(provenance=instr_mm.provenance, alignment=refs,
              conformity=M.ccg.score(sf, C_intent, fused, 0.0),
              conflict=conflict, clarification=trace)
    M.epir.append({**EV_exec.__dict__, 'mac_hash': mac.hash})

    M.calib_buffer.append((instr_mm, EV_exec.realized_constraint))
    if len(M.calib_buffer) >= M.calib_batch:
        M.ccg.calibrate(M.calib_buffer, M.ccg.score)
        M.calib_buffer.clear()
    return M, C_intent, gamma, mac, status
```

### IP-166 PCE+++++（语义预算耦合）

```python
class SemanticBudget:
    def __init__(self, parse_ops=200, ground_ops=400, clarify_turns=2, calib_ops=50):
        self.B_parse, self.B_ground = parse_ops, ground_ops
        self.B_clarify, self.B_calib = clarify_turns, calib_ops
        self.ops = defaultdict(int)

    def mode(self):
        if self.ops['parse'] >= self.B_parse:
            return 'keyword_only'
        if self.ops['ground'] >= self.B_ground:
            return 'language_only'
        if self.ops['clarify'] >= self.B_clarify:
            return 'conservative_labeled'
        if self.ops['calib'] >= self.B_calib:
            self.ccg.tau_gap *= 1.2
            return 'frozen_calibration'
        return 'normal'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CIG | O(|SF|) 次 meet | O(|κ|+|SF|) | 组合泛化误差 ≤ Σ 未覆盖原语权重；κ 单调保持 |
| MIG | O(M·|SF|) 融合 + O(n³) 匹配 | O(|SF|+n²) | 指代绑定准确率 ≥ δ_ref；融合熵 ≤ 最优单模态 |
| CCG | O(|𝒞cand|) 打分/更新 | O(n_cal) | 覆盖率 ≥ 1-α（可交换性下） |
| ACD | O(|𝒬|·|SF|) / 轮 | O(B_clarify) | 每次澄清后熵单调下降 |
| MIGL | O(闭环) | 复用 | SIC+ 四元校验通过，MAC 可追溯 |

**正确性定理（MIGS）**：
假设 A22–A65 及下列 A66–A71 成立：**(A66)** 组合解析器对语义树同态，且 κ 关于 `⊑` 单调。**(A67)** 各模态在给定真实意图下条件独立（专家乘积有效），且单模态分布已校准。**(A68)** 校准集与测试指令可交换（exchangeable），故保形覆盖成立。**(A69)** 指代匹配的实体对齐准确率 ≥ δ_ref。**(A70)** 澄清回答真实，且互信息估计无偏。**(A71)** 语义预算单调消耗，任一耗尽触发对应安全策略。

则：
1. **组合泛化正确性**：若 `leaves(SF(x)) ⊆ 𝒫_cov`，则 `C_comp(x)` 有定义且关于 `⊑` 单调；误差只由未覆盖原语决定，不随组合数量增长。
2. **多模态接地增益**：条件独立下 `H(π_fused) ≤ min_m H(π_m)`；指代绑定在 ζ 阈值下达到 δ_ref 对齐。
3. **保形安全**：`P(C*(x)∈C_α(x)) ≥ 1-α`；当 `γ>τ_gap` 时拒识，从而**不产生高置信的错误约束**。

```python
    TOP = Constraint(v_max=inf, F_max=inf, K_p=inf, K_d=0.0, eps_traj=inf)
    def meet(self, a, b):
        return Constraint(v_max=min(a.v_max, b.v_max), F_max=min(a.F_max, b.F_max),
                          K_p=min(a.K_p, b.K_p), K_d=max(a.K_d, b.K_d),

class CompositionalInstructionGrounder:
    def __init__(self, kappa, lat):
        self.kappa, self.lat = kappa, lat
        self.parser = SemanticParser()
    def ground(self, x):
        sf = self.parser.parse(x)
        C, unknown = self.lat.TOP, []
        leaves = list(sf.leaves())
        for p in leaves:
            if p in self.kappa:
                C = self.lat.meet(C, self.kappa[p])
            else:
                unknown.append(p)
        return C, sf, 1 - len(unknown) / max(1, len(leaves)), unknown
```

### IP-162 MIG（多模态意图接地）

```python
class MultimodalIntentGrounder:
    def fuse(self, evidence):
        scores = defaultdict(float)
        for m, (logp, rho, _t) in evidence.items():
            for sf, lp in logp.items():
                scores[sf] += rho * lp
        mx = max(scores.values())
        Z = sum(np.exp(v - mx) for v in scores.values())
        return {sf: np.exp(v - mx) / Z for sf, v in scores.items()}

    def ground_reference(self, refs, dets, gaze, point):
        S = np.zeros((len(refs), len(dets)))
        for i, e in enumerate(refs):
            for j, o in enumerate(dets):
                S[i, j] = (0.4 * gaze_score(gaze, o) + 0.4 * point_score(point, o)
                           + 0.2 * sem_sim(e, o))
        r, c = linear_sum_assignment(-S)
        return {refs[i]: dets[j] for i, j in zip(r, c) if S[i, j] >= 0.6}
```

### IP-163 CCG（保形约束接地）

```python
class ConformalConstraintGrounder:
    def __init__(self, alpha=0.1, tau_gap=1.0):
        self.alpha, self.tau_gap, self.qhat = alpha, tau_gap, np.inf
    def calibrate(self, cal, score_fn):
        s = np.sort([score_fn(x, C) for x, C in cal])
        n = len(s)
        self.qhat = s[min(int(np.ceil((n + 1) * (1 - self.alpha))), n) - 1]
    def ground(self, sf, pi, cands, ood_dist):
        C_alpha = {C for C in cands if self.score(sf, C, pi, ood_dist) <= self.qhat}
        gamma = ood_dist / self.d_ref + self._diam(C_alpha) / self.diam_max
        return C_alpha, gamma, ('ABSTAIN' if (not C_alpha or gamma > self.tau_gap)
                                else 'ACCEPT')
```
