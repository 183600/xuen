# 第 15 轮（新灵感循环起点；本轮灵感：「数据集」×「决策规划」）

> **基线**：第 14 轮 MetricVoiceGauge-NCD-HUTDHUP（定义 595–606；引理 122–124；实验 E647–E660）。
> 本轮纪律：**决策条件数据集 + 证书感知的数据获取规划 + 计划—反例闭环**。不推倒 v14：MetricVoiceGauge 九不变式、v13 的 AIO/CPD/DDL/RTCR、v14 的 HBR/UCCI/PAA 全部原样保留。三个新组件——DCG（决策条件数据集治理，含 DCC）、CAP（证书感知获取规划，含 IVC）、PCL（计划—反例闭环，含 PRC）——一律以**中立元**接入，失效即严格退回 v14（引理 131），再沿 v14→v13→…→v6 退化链退回。本轮只做三件事：把"数据集"从静态语料改写为**以决策为索引、带来源权重与覆盖证书的对象**；把"决策规划"从"在给定模型上选动作"改写为**物理动作与数据获取动作的联合规划**；把二者合成一条**数据只收紧、不放宽**的闭环。

## 0. 直觉与动机

**灵感 1（数据集 → 决策条件数据集与覆盖证书）**
直觉：v13/v14 的 TGC/DGC/UC 都默认校准集固定、独立同分布、能替任意候选计划作保。但在这套系统里，数据是被策略采出来的：保守策略只走到安全走廊，激进策略才进入薄接触区。用前者的数据给后者签证书，等于拿"没见过的区域"冒充"验证过的区域"。核心创新：**决策条件数据集（Decision-Centric Dataset, DCD）与决策条件覆盖证书（Decision-Conditional Coverage certificate, DCC）**。数据集的最小单位不再是 $(x,y)$，而是 $(x,\text{决策单元},\text{边界余量},\text{来源策略权重})$。DCC 只在"目标策略的访问分布被数据以有界密度比覆盖，且决策边界管状邻域有足够样本"时成立。关键反直觉点：**数据集的大小不重要，数据集与待认证决策的"支撑重叠"才重要**——一万条与目标计划无关的样本，抵不过目标边界上的十条反例。

**灵感 2（决策规划 → 把数据获取当作可执行动作）**
直觉：数据不是天上掉下来的，采集要花时间、要动机械臂、要进入本来可以绕开的区域。因此"要不要采这条数据"本身就是规划问题的一部分。核心创新：**证书感知获取规划（Certificate-Aware Acquisition Planning, CAP）与信息价值证书（Information Value Certificate, IVC）**。动作集扩张为 `A⁺ = A_phys ∪ A_probe`；probe 必须自己属于 `Exec_v14`（不得为了采集而进入未认证区域）、必须从同一 `B_time` 扣费、必须给出计划后悔下降的**保守下界** `IVC`，且 `IVC ≤ 0` 时禁止采集。再叠加一条强不变量：**数据只收紧，不放宽（Data Tightens, Never Widens）**——在线数据只能缩小授权集，任何扩大必须走离线再认证并留下留出锚点。于是"用数据买授权"被改写为"用预算买更小的不确定性，且只允许朝保守方向兑现"。

**灵感 3（数据集×决策规划 → 计划—反例闭环）**
直觉：普通主动学习最大化模型不确定性，但模型不确定的地方未必是**决策**不确定的地方。真正该采的是"差一点就被选中、且证书余量很薄"的边界状态。核心创新：**计划—反例闭环（Plan-Counterexample Loop, PCL）与计划后悔证书（Plan Regret Certificate, PRC）**。规划器先给出候选计划；反例算子在最接近决策翻转的边界上生成/检索状态，经教师或真值锚验证后入集；数据集只在决策边界上生长。评价从"样本量/损失"改为"计划后悔上界 `U_reg`"。为防止采样器—证书器—评估器共谋，锚点集与训练集强制不相交，并用重要性加权与影子数据集审计选择偏差。

**三者如何统一**
统一为 **v14 之上的"数据授权层"**：v14 回答"在时限内能实现多少已授权动作"（`Exec_v14`），v15 回答"要获得或维持这些授权，需要什么数据，且这份数据是否值得用安全预算去换"（`Exec_v15`）。DCG 把数据集变成决策索引的证书对象；CAP 把数据获取变成带信息价值证书的可执行动作；PCL 让数据在最该长的地方生长；三者共享状态 `ζ_data=(D,{w_i},DCC,Amb_D,IVC,B_data,anchor,mode)`。**DCG 回答"现有数据能替谁作保"，CAP 回答"该不该花预算去补哪块证据"，PCL 回答"补的证据是否真的改变决策"**。v14 的授权集在这里第一次成为**因变量**，而不再只是被查询的常量。

## 1. 研究问题（轮次升级版）

- **Q1（决策条件覆盖的可证语义）**：如何定义"数据集替某个决策作保"才使共形保证在策略诱导的选择偏差下仍 sound？密度比有界、有效样本量 `n_eff`、边界样本数 k 三者如何共同决定 DCC 的成立？支撑外无保证时，DCC 与 v14 的 TGC/UC 支撑条件如何合取而不互相掩盖？
- **Q2（获取规划的安全与价值）**：如何把 probe 纳入规划而不破坏 `Exec_v15⊆Exec_v14`？probe 自身的安全性、时间预算、`P^rt≠∅` 如何联合校验？IVC 如何给出分布无关的保守下界，使"以为有信息、其实白采"不消耗安全？在线单向收紧与离线再认证的边界如何定义，才既不发生活动性塌缩、也不发生静默扩权？
- **Q3（反例闭环的收益与自确认）**：以计划后悔而非模型精度为目标时，边界采样相对均匀采样能省多少样本？在近并列（near-tie）区域，最小可辨识后悔的下界是什么？当采样器、证书器、评估器共享同一偏差时，锚点、IPS 与影子数据集能否阻断自确认？不能时，系统应退化到哪一档？
- **Q4（与 v14 的兼容与活性）**：在线只收紧是否会把系统逐步逼到只剩 `a_ask` 的"保守死亡螺旋"？再认证锚点被污染时如何发现？新增的 DCG/CAP/PCL 能否守住 50Hz/p99≤22ms、`B_anchor` 不被挪用，并在任一端口失效时严格退回 v14？

## 2. 设计原则（在 P22–P24 基础上新增 P25–P27）

**P25 数据单向律（Data Tightens, Never Widens）**
在线获得的任何新样本只能收紧授权集：`Acc_{D'}(x)=Acc_D(x)∩Acc^{fresh}_{D'}(x)⊆Acc_D(x)`。任何扩大授权的行为必须经过离线再认证 `RECERT`，且必须通过**与训练集不相交的留出锚点**校验。禁止用在线数据直接放宽 TGC/DGC/UC/PRC 的任何阈值。

**P26 数据—动作不可分离律（Data-Action Non-Separability）**
数据获取是决策动作，不是免费的预处理。每个 probe 必须满足：`q∈Exec_v14`（不得为采集进入未认证区域）；`w(q)≤B_time−B_safe−w(π_after)`；采集后 `P^rt≠∅` 仍成立；`IVC(q)≥κ·cost(q)` 且 `IVC(q)≥0`。`B_data` 与 `B_transfer/B_distill`、`B_anchor` 互不冲抵。

**P27 决策中心评价律（Decision-Centric Evaluation）**
数据集价值以**计划后悔与证书判决变化**衡量，不以样本量、覆盖广度或训练损失衡量。每个样本必须携带来源策略、时间戳与决策单元标签；评价必须报告 `n_eff`、密度比上界 Λ 与 `P_tie`，否则视为无证书。

## 3. 与基线的接口（如何退化）

- DCG 失效 ⇒ 数据集退回固定 i.i.d. 语料：无来源权重、无决策单元索引，DCC 退化为 v14 全局共形，**等价 v14 数据路径**；
- CAP 失效 ⇒ 动作集退回 `A_phys`，无 probe、无 IVC，规划器只选物理动作，**等价 v14 决策规划**；
- PCL 失效 ⇒ 数据集离线固定，无边界反例生成，仅被动接收数据，**等价 v14 离线校准**；
- 三者全失效 ⇒ MetricVoiceGauge-NCD-HUTDHUP v14，再沿 v14 退化链退回 v13/v12/…/v6；
- **安全继承**：DCG 只签发"数据能替谁作保"，不新增授权；CAP 只在 `Exec_v14` 内选 probe 且信息价值持证；PCL 只生成待验证样本，入集仍受单向律约束。三端口互不相交，`Exec_v15⊆Exec_v14` 由引理 125 保证。

## 4. 预期贡献

1. **决策条件数据集与覆盖证书**：把"数据集"从静态语料改写为以决策为索引、带来源权重与边界覆盖的证书对象，给出策略诱导选择偏差下的共形有效性与 `n_eff`/Λ 条件，填补"离线数据不能免费为在线决策作保"的空白；
2. **证书感知的数据获取规划**：把数据获取纳入安全关键决策规划，probe 自身可执行、信息价值有保守下界、预算不可挪用，并给出"在线只收紧、离线才可扩权"的双模授权语义；
3. **计划—反例闭环与计划后悔证书**：以决策边界反例而非模型不确定性为采样目标，以 `U_reg` 而非损失为评价，给出近并列区域的可辨识下界与防自确认机制；
4. **数据—决策不可分离的负结果与实现层**：证明"固定数据集 + 决策规划"在近并列区域存在不可消除的后悔下界，明确"更多数据/更多 probe/更高后悔"三者必居其一；用 `Exec_v15⊆Exec_v14` 把数据授权与 v14 安全解耦；E661–E676 覆盖覆盖有效性、选择偏差、信息价值、单向更新、反例效率、漂移与端到端。

## 5. 本轮最大风险

**一句话**：数据与决策共适应的闭环会让覆盖证书自我确认——采样器只采证书器已经相信的区域，证书器又用这些样本证明自己正确，于是在"数据充分、密度比有界、预算守恒"的表象下，系统要么沿单向收紧退化成只会 `a_ask` 的保守死亡螺旋，要么在再认证时放行了一个被选择偏差掩盖、且教师与数据共同错判的计划。

> 背景：第 14 轮 MetricVoiceGauge-NCD-HUTDHUP（定义 595–606；引理 122–124；实验 E647–E660），其基线为 v13 MetricVoiceGauge-NCD-HUTD。

**定义 607（决策中心数据集 Decision-Centric Dataset）**
数据集是带来源与决策标签的样本族，而非全局语料：
```
D = { (x_i, a_i, y_i, w_i, b_i, t_i, cell_i) }_{i=1}^{n} ,   D_π = { i : b_i = π } ,
```
其中 `y_i∈{safe,unsafe}`（或证书边界余量），`w_i` 为行为策略 `b_i` 到目标策略的重要性权重，`cell_i` 为样本所属决策单元。对任意候选计划 π'，只有 `D` 中与 π' 的目标访问分布 `ν_{π'}` 支撑重叠的部分才可用于签发证书；数据集的"大小" `n` 与"可用有效量" `n_eff` 是两回事。

**定义 608（决策条件覆盖证书 DCC）**
对目标策略 π 与显著性 `α_s`，DCC 为三元组 `(ε,Λ,k)` 的合取：
```
DCC(D,π,α_s)=1  ⇔  P_{x~ν_π}[ dist(x, supp(D_π)) > ε ] ≤ α_s
                  ∧  ess sup_{x∈supp(ν_π)} dν_π/dμ_{D_π}(x) ≤ Λ < ∞
                  ∧  N_{ε}( D_π ∩ T_ε ) ≥ k ,
```
其中 `T_ε={x:|Δ(x)|≤ε}`，`μ_{D_π}` 为 `D_π` 的经验测度，`N_ε` 为 ε-覆盖样本数。**只有 `DCC(D,π)=1` 时，才允许把共形证书导出给 π**；否则必须返回"覆盖桥缺失"并降级为 probe 或 `a_ask`。DCC 是"数据能替谁作保"的唯一凭据。

**定义 609（策略感知有效样本量与密度比桥）**
对目标策略 π' 与行为策略 b：
```
w(x)=clip( dν_{π'}/dν_b (x), 0, Λ ) ,     n_eff = (Σ_i w_i)^2 / Σ_i w_i^2 .
```
`n_eff` 是 IPS 意义下的有效样本量。证书导出给 π' 的必要条件为 `n_eff ≥ n_min` 且 `Λ<∞`；若密度比无界或 `n_eff<n_min`，则视为**覆盖桥不存在**，不得用旧数据替新决策作保，只能经 CAP 采集支撑重叠样本或退回 `a_ask`。这直接阻断"保守数据替激进计划背书"的选择偏差。

**定义 610（数据获取动作与在线单向更新）**
动作集扩张为 `A⁺ = A_phys ∪ A_probe`。probe 写作 `q=(x, a_q, meas, budget)`，返回值 `z~Z(x,q)`。合取约束：
```
q ∈ Exec_v14(x)  ∧  w(q) ≤ B_time − B_safe − w(π_after)  ∧  P^rt ≠ ∅ 保持不变 .
```
在线更新 `D' = D ∪ {(x,z)}` 采用**单向收紧**：
```
Acc_{D'}(x) := Acc_D(x) ∩ Acc^{fresh}_{D'}(x) ⊆ Acc_D(x) .
```
即新数据只能让授权集变小或不变。任何扩大授权的更新必须走离线 `RECERT(D',anchor)`，且满足 `DCC(D',π',α_s)=1`、`anchor∩D'=∅`、锚点覆盖率 `≥1−α_a`。这一条与 P23 的"蒸馏只弱不强"同构，是数据侧的对应纪律。

**定义 611（信息价值证书 IVC）**
设 `U_reg(D)` 为定义 613 的计划后悔上界。probe q 的随机观测为 Z，定义
```
IVC(q;1−β) = LCB_{1−β}[ U_reg(D) − U_reg(D ∪ {(x,Z)}) ] ,
```
其中 `LCB` 由分裂校准/自助法在独立 probe 模拟集上估计，取保守下界。probe 仅在
```
IVC(q) ≥ 0   ∧   IVC(q) ≥ κ_data · cost(q)
```
时被允许；`IVC≤0` 时**禁止采集**（中立）。直觉：只有"能证明自己至少不会让后悔上界变差，且值得花预算"的数据才配被采。

**定义 612（证书感知获取规划目标）**
```
π_data(x) = argmax_{a∈A⁺} { value(a) + 1[a∈A_probe]·λ_I·IVC(a) − λ_c·cost(a) }
s.t.  a∈Exec_v14(x)                                   (物理动作)
      q∈Exec_v14(x) ∧ w(q)≤B_time−B_safe−w(π_after)   (probe 自身安全/时间)
      采集后 π_after∈Exec_v14 且 P^rt≠∅               (后续仍可执行)
      Acc 单向收紧（定义 610）
```
`λ_I` 是"信息价格"，`λ_c` 是"安全预算价格"。该目标是深度 1 的信息导向前瞻：先选 probe，再用观测后的最优物理动作收尾。因为 `IVC` 是保守下界且 `Acc` 只收紧，决策不会因"以为有信息"而越过 v14。

**定义 613（计划后悔证书 PRC）**
设 `J(π_D)` 为用数据集 D 选出的计划真实代价，`π*` 为最优计划：
```
Reg(D) = J(π*) − J(π_D) ≤ U_reg(D) := 2L·sqrt( (d_eff + log(1/δ)) / n_eff )
                                       + Δ_max · P_tie(D) + ε_plan ,
```
其中 `L` 为证书余量对数据的 Lipschitz 常数，`d_eff` 为决策边界有效维度，`P_tie(D)=P_{x~ν_π}(|Δ(x)|≤ε_tie ∧ Amb_D(x)≠{a*})` 为近并列且未被决定的概率，`ε_plan` 为有限前瞻/技能组合的逼近项。证书导出为 `(U_reg,δ)`；`U_reg > B_reg` 时计划不可执行。

**定义 614（计划—反例算子 PCL）**
```
CE(π,D) = argmax_{x∈X_cand}  1[ x∈T_{ε_tie} ] · m_min(x)^{-1} · ( Δ_max − |Δ(x)| ) ,
```
即优先挑"接近决策翻转且证书余量最小"的状态。每个反例必须经教师 anytime 或真值锚验证后才可入集，入集带 `b_i=π` 与 `cell_i`。离线目标：
```
min_{D'} U_reg(D')  s.t.  |D'| ≤ n_0 + B_pcl·r ,  D'⊇D ,  锚点不参与训练 .
```
PCL 只影响边界样本的**分布**，不改变证书规则本身。

**定义 615（三预算不可挪用 v15）**
```
B_total = B_transfer + B_distill + B_data          # 真实侧误差/成本可加
B_time  = B_safe + B_infer + B_acquire              # probe 与规划共享时间
B_data  = B_pcl + B_online ,      B_anchor ⊥ B_data # 锚点硬保留、不可挪用
```
`B_anchor` 与其余三类预算互不冲抵；`B_acquire` 只能来自 `B_infer` 的剩余切片，不得挤压 `B_safe`。任一预算耗尽时的唯一合法动作是沿 v14 阶梯更保守、触发 `a_ask` 或认证回退。

**定义 616（v15 执行集与共享状态）**
```
ζ_data = ( D, {w_i}, DCC, Amb_D, IVC, B_data, anchor, mode )

Exec_v15 = { a : a∈Exec_v14(x)
                 ∧ DCC(D,π_D,α_s)=1
                 ∧ U_reg(D) ≤ B_reg
                 ∧ Acc 与单向更新一致（定义 610）
                 ∧ P^rt≠∅ } .
```
`mode` 为 `plan`（纯物理规划）、`probe`（采集）、`shrink`（在线收紧）、`recert`（离线再认证）、`ask`（退回询问）。要求 `Exec_v15⊆Exec_v14`（引理 125）。

**定义 617（中立元表 v15 扩展）**

| 新组件 | v^⊥ | 等价退化点 |
|---|---|---|
| DCG | 固定 i.i.d. 数据集，无来源权重/决策索引，DCC→v14 全局共形 | Level-4（v14 数据路径） |
| CAP | 无 probe、无 IVC，动作集退回 `A_phys` | Level-3（v14 决策规划） |

**定义 618（数据—决策不可分离下界 Data–Decision Non-Separability）**
存在决策问题族（top-2 决策余量 `Δ`、边界有效维度 `d_eff`），使任何"先固定数据集、再对任意候选计划统一签发证书"的规划器，若其有效样本量为 `n_eff`，则计划后悔满足
```
E[Reg] ≥ Ω( min{ Δ , L·sqrt( (d_eff + log(1/δ)) / n_eff ) } ) .
```
若允许 probe，且 probe 产率至多 `r` 条/单位预算、在线数据预算为 `B_data`，则
```
n_eff ≤ n_0 + r·B_data    ⇒    E[Reg] ≥ Ω( min{ Δ , L·sqrt( (d_eff+log(1/δ)) / (n_0 + r·B_data) ) } ) .
```
证明：在近并列区域构造两个仅在 `T_ε` 上不同的决策问题（Le Cam 两点法），任何统一证书在样本量不足时必以常数概率选错，误差代价至少为 `Δ` 的常数倍；`n_eff` 上界由数据产率与预算给出。∎ 推论：**"更多数据、更多 probe、更高后悔"三者必居其一**；边界主动采样只能改变常数与把样本集中到 `T_ε`，不能突破 `1/sqrt(n_eff)` 速率。这正是"数据集 × 决策规划"不可分离的负结果。

**定义 619（来源账本与再认证锚）**
来源账本 `L = {(i, b_i, w_i, t_i, cell_i, verifier_i)}` 与锚点集 `anchor` 满足：
```
RECERT(D',anchor)=1  ⇔  DCC(D',π',α_s)=1 ∧ anchor∩D'=∅
                         ∧ 锚点覆盖率 ≥ 1−α_a ∧ 单向门控校验通过 .
```
锚点只能来自 v14 的独立真值通道（教师 anytime 验证 / 物理标定 / 人工确认），**不得由同一策略在同一循环中生成**；`B_anchor` 被硬保留，任何 probe 不得借用。这一条是阻断"采样器—证书器—评估器共谋"的结构性约束。

**定义 620（v15 数据授权策略 π_data 的语义保持）**
```
π_data(x; B, D, anchor) = argmax_{a∈A⁺} value(a)   s.t. 定义 612 的约束
                           ∧ a∈Acc_{D}(x) 或 a∈A_probe
                           ∧ 若 a∈A_phys 则 a∈Exec_v14(x)
```
并要求对所有 x、B、D：`π_data` 选出的物理动作属于 `Exec_v14(x)`；probe 只是"用已认证动作去换信息"，其本身不改变执行集。`mode=recert` 时 `π_data` 暂停物理执行，只做离线校验。

# IP-384 DecisionCentricDatasetGovernor：决策条件覆盖与来源账本
class DecisionCentricDatasetGovernor:
    def __init__(self, ledger, eps=0.05, Lambda=4.0, k=20, alpha_s=0.05):
        self.ledger = ledger            # DataProvenanceLedger
        self.eps, self.Lambda = eps, Lambda
        self.k, self.alpha_s = k, alpha_s

    def dcc(self, policy_id, visit_dist, delta_fn):
        D_pi = self.ledger.subset(policy_id)
        support_miss = self._mass_outside(D_pi, visit_dist, self.eps)
        Lam = self._density_ratio_bound(D_pi, visit_dist)      # clip 到 Infinity
        boundary = sum(1 for i in D_pi if abs(delta_fn(i)) <= self.eps)
        return (support_miss <= self.alpha_s
                and Lam <= self.Lambda
                and boundary >= self.k), (support_miss, Lam, boundary)

    def effective_n(self, target_id, behavior_id):
        ws = [self.ledger.weight(i, target_id, behavior_id) for i in self.ledger]
        s1 = sum(ws); s2 = sum(w * w for w in ws)
        return (s1 * s1 / s2) if s2 > 0 else 0.0


# IP-385 CertificateAwareAcquisitionPlanner：把数据获取当动作
class CertificateAwareAcquisitionPlanner:
    def __init__(self, dcg, ivc_table, kappa, lambda_I, lambda_c):
        self.dcg, self.ivc = dcg, ivc_table
        self.kappa, self.lamI, self.lamC = kappa, lambda_I, lambda_c

    def plan(self, x, A_phys, A_probe, B_time, B_safe, B_reg, pi_after_cost):
        candidates = []
        for a in A_phys:
            if self._certified_v14(x, a):
                candidates.append((self._value(a), a, None))
        for q in A_probe:
            if not self._probe_exec_v14(x, q):
                continue                         # probe 自身不安全：不可采
            if q.cost + pi_after_cost > B_time - B_safe:
                continue                         # 采完没时间收尾：不可采
            v = self.ivc.lower_bound(q, level=0.95)   # 计划后悔下降的保守下界
            if v < 0 or v < self.kappa * q.cost:
                continue                         # 无信息价值：中立，不采
            score = self.lamI * v - self.lamC * q.cost
            candidates.append((score, q, v))
        if not candidates:
            return None, "ask"
        score, action, ivc = max(candidates, key=lambda t: t[0])
        if action in A_probe:
            return action, "probe"
        return action, "plan"


# IP-388 MonotoneAuthorizationGate：在线只收紧，扩权必须再认证
class MonotoneAuthorizationGate:
    def __init__(self, anchor):
        self.anchor = anchor                    # 与训练集不相交

    def update_online(self, acc_old, acc_fresh):
        return acc_old & acc_fresh              # 交集：只会变小

    def recert(self, D_new, pi_new, dcc_ok, anchor_cover):
        if not dcc_ok:
            return False
        if self.anchor.intersects(D_new):
            return False                        # 锚点污染：拒绝再认证
        if anchor_cover < 1 - self.anchor.alpha_a:
            return False
        return True                             # 允许离线扩权（仍 ⊆ Exec_v14）


# IP-386 PlanCounterexampleLoop：在决策边界上生长数据
class PlanCounterexampleLoop:
    def __init__(self, verifier, budget_pcl, rate):
        self.verifier, self.B_pcl, self.rate = verifier, budget_pcl, rate

    def run(self, pi, D, X_cand, rounds):
        D_new = list(D)
        for _ in range(min(rounds, int(self.B_pcl * self.rate))):
            x = max(X_cand, key=lambda s: self._boundary_score(s, pi, D_new))
            if not self._in_tie_tube(x, pi):
                break
            z = self.verifier.verify(x)          # 教师 anytime / 真值锚
            if z is not None:
                D_new.append(z.with_provenance(pi))  # 带行为策略标签入集
        return D_new

    def _boundary_score(self, x, pi, D):
        d = abs(self._decision_margin(x, pi))
        m = self._certificate_margin(x, pi, D)
        return (1.0 / max(m, 1e-6)) * max(0.0, 1.0 - d)

## 4. 推导

**引理 125（单向更新安全性与 `Exec_v15⊆Exec_v14`）** 设在线更新满足 `Acc_{D'}=Acc_D∩Acc^{fresh}_{D'}`，离线扩权仅在 `RECERT(D',anchor)=1` 时发生且 `Acc^{recert}⊆Exec_v14`，probe 满足定义 610 的三条约束。则对任意更新序列与任意 x：
```
Acc_{D'}(x) ⊆ Acc_D(x) ⊆ Exec_v14(x)   （在线阶段）
Acc^{recert}(x) ⊆ Exec_v14(x)           （再认证阶段）
```
从而 `π_data(x)∈Exec_v15⊆Exec_v14`。证明：在线阶段由交集单调性直接得到；归纳到任意有限步仍保持。再认证阶段由 `RECERT` 的显式校验条件 `DCC=1 ∧ anchor∩D'=∅ ∧ 锚点覆盖` 与 v14 证书合取保证 `⊆Exec_v14`。probe 只产生新样本，不直接产动作，故不引入执行集外元素。∎ 推论：**数据获取不能绕过 v14；它只能让授权更小，或经独立锚点证明后恢复。**

**引理 126（DCC ⇒ 计划后悔上界）** 若 `DCC(D,π_D,α_s)=1`、证书余量 `m` 为 L-Lipschitz、共形覆盖为 `1−α`，则
```
Reg(D) ≤ 2L·sqrt((d_eff+log(1/δ))/n_eff) + Δ_max·P_tie(D) + ε_plan
```
以概率 `≥1−α−δ−α_s` 成立。证明：把状态分为"已决定非近并列"与"近并列/未决定"两类。前者由 DCC 的支撑与密度比条件把局部共形区间宽度控制在 `2L·sqrt((d_eff+log(1/δ))/n_eff)`，选错项的代价被该宽度吸收；后者无论选对选错，后悔不超过 `Δ_max`，其概率正是 `P_tie`。加上有限前瞻误差 `ε_plan`，并用并集界合并覆盖失败与支撑失败。∎ 推论：**降低后悔有两条正交路径**——提高 `n_eff`（数据/权重质量）或降低 `P_tie`（边界采样/更多档位），二者都不能靠"增大原始样本数 n"自动获得。

**引理 127（策略感知共形与 `n_eff`）** 设行为策略 b 产生数据，目标策略 π' 满足 `dν_{π'}/dν_b≤Λ`，权重按定义 609 截断。则重要性加权共形分位给出的覆盖为 `≥1−α−ε_shift(Λ,n_eff)`，其中 `ε_shift→0` 当 `n_eff→∞`。若 Λ 无界或 `n_eff<n_min`，则不存在分布无关正覆盖保证。证明：加权共形/协变量移位共形定理；截断引入的偏差由 `Λ` 控制，方差由 `n_eff` 控制。Λ 无界时构造反例（目标分布把质量放到数据支撑之外），覆盖可任意差。∎ 推论：**"数据替决策作保"是有方向性的**：π' 越接近行为策略、`n_eff` 越大，证书越有效；否则必须先 probe 建立覆盖桥。

**引理 128（IVC 的可靠性与 probe 无伤害）** 设 `IVC(q;1−β)` 是计划后悔下降的合法下界，probe `q∈Exec_v14`、预算与 `P^rt` 条件满足、更新为单向收紧。则：(i) 以概率 `≥1−β`，probe 后 `U_reg` 的下降不少于 `IVC(q)`；(ii) 任何 probe 决策都不会使执行集超出 `Exec_v14`；(iii) 若 `IVC(q)≤0`，不采集是弱最优且与 v14 等价。证明：(i) 由下界定义与分裂校准的有限样本修正；(ii) 由引理 125 的单向更新与 probe 可执行性；(iii) `IVC≤0` 时信息项不增加目标值，规划退化为纯 v14 物理动作选择。∎ 推论：**采集的安全性不依赖信息估计是否精确**——估计错只会让你少采或白采，不会让你越权。

**引理 129（反例闭环收益与不可突破的下界）** 记近并列管状邻域的质量为 `p_tie=P(T_{ε_tie})`。均匀被动采样在边界上的有效样本为 `n_eff·p_tie`；边界主动采样可把预算集中到 `T_ε`，使边界有效样本提升至 `n_eff`（最高），因此同预算下 `U_reg` 的常数项改善至多 `p_tie^{-1/2}`。但对任意数据集，仍满足定义 618 的下界
```
E[Reg] ≥ Ω( min{ Δ , L·sqrt((d_eff+log(1/δ))/n_eff) } ) .
```
证明：上界由引理 126；下界由 Le Cam 两点法在 `T_ε` 上构造不可区分问题，任何 `n_eff` 样本的检验错误率下界经 Pinsker/Fano 传导为后悔下界；主动采样改变样本在 `T_ε` 上的分布，只能改善常数，不能改变速率。∎ 推论：**反例闭环值得做，但它是"把好钢用在刀刃上"，不是"免费午餐"**；当 `p_tie` 极小时收益最大，当边界本身高维/复杂时 `d_eff` 主导，收益迅速衰减。

**引理 130（数据预算守恒与实时开销）** 在定义 615 下，`B_data=B_pcl+B_online` 与 `B_transfer/B_distill` 加性分离，`B_anchor` 硬保留。在线 probe 产率为 r 时 `n_eff≤n_0+r·B_online`，结合引理 129 得后悔下界。实时开销：来源账本查询 ≤0.1ms；DCC 统计 O(log n) ≤0.1ms；IVC 查表 ≤0.05ms；probe 规划 O(|A_probe|) ≤0.2ms；MAG 交集 O(|Acc|) ≤0.1ms；DVC O(1) ≤0.02ms。总决策 p99 仍 ≤22ms，50Hz 保持。证明：逐项代入复杂度表并做静态 EDF 校验 `ΣŴ_m≤B_dec`；`B_safe` 与 `B_anchor` 硬预留保证预算不被数据侧吃光。∎

**引理 131（中立元退化等价 v14）** 将定义 617 的五个中立元注入 DCG/CAP/PCL/MAG/DVC 端口，则数据集退化为固定 i.i.d. 语料、probe 集为空、反例生成停止、证书更新沿用 v14、覆盖永不过期；主闭环调用序列与 v14 逐位一致，再沿 v14 链退回 v13/…/v6。证明：逐端口代入定义 617，并用定义 595–606 的边界条件核对；五端口互不相交且中立元不改变 v14 任何证书检查。∎

## 8. 已知风险与失效模式

1. **策略诱导的选择偏差**：数据只来自已执行策略，目标策略的支撑可能根本未被覆盖。缓解：IPS/密度比桥、`n_eff` 硬门槛、无界 Λ 时拒绝签发、probe 优先补支撑。

2. **覆盖证书自确认**：采样器、证书器、评估器共享偏差时，DCC 会用自己采的样本证明自己对。缓解：锚点集强制不相交、影子数据集、`B_anchor` 硬保留、独立教师 anytime 抽查。

3. **单向收紧的保守死亡螺旋**：在线只收紧会导致授权集随时间单调缩小，最终频繁 `a_ask`。缓解：离线再认证复权、DVC 过期即显式降级而非静默、把活动性损失计入 `B_data` 预算并预注册。

4. **IVC 过度乐观**：校准 probe 模拟集太小或分布偏移时，`IVC` 高估信息价值，导致把预算花在无用 probe 上。缓解：分裂校准、保守下界、`κ_data` 余量、白采率在线监控，超阈值即停采。

5. **锚点污染/泄漏**：锚点与训练集交叉、或锚点本身由同一策略生成，再认证会放行错误扩权。缓解：锚点来源审计、时间/空间隔离、污染检测、`RECERT` 失败保持旧授权。

6. **在线数据投毒**：对抗样本可使单向更新把授权集"错误地收紧"到危险子集（活性攻击）或在再认证时欺骗覆盖。缓解：来源签名、异常检测、MAG 强制交集、锚点复验、投毒样本隔离。

7. **近并列病理**：`p_tie` 很大或 `Δ` 极小时，任何有限数据都无法决定，后悔下界主导。缓解：显式 `a_ask`、引入物理保守回退、放宽 `ε_tie` 并承认后悔、不要把不可辨识当成可学习。

8. **密度比无界**：目标策略进入数据未覆盖区域时 Λ 爆炸，共形保证失效。缓解：拒绝签发、probe 建桥、把"覆盖桥缺失"作为显式执行门。

9. **`B_anchor` 被预算压力挪用**：赶进度时把锚点预算花在 probe 上，导致再认证失去独立性。缓解：硬切片、静态 EDF 校验、`B_anchor` 独立计量、挪用即告警并退回 v14。

10. **数据—蒸馏—迁移三侧间隙同向偏低**：选择偏差、蒸馏间隙与迁移间隙在新场景中同时被低估。缓解：v14 的联合可加界（引理 121/124）保留，数据侧再加 IPS 修正与锚点审计；任一间隙失效即触发 `a_ask`/最低档。

11. **来源账本缺失/日志错误**：无 `b_i`、`w_i`、`t_i` 就无法做 IPS、时效与污染审计，DCC 退化为无根据的乐观声明。缓解：强制 schema、写入失败即拒签证书、离线对账、把无来源样本视为不可用。

## 9. 本轮最大风险

**一句话**：数据与决策共适应的闭环可能让覆盖证书自我确认——在"数据充分、密度比有界、预算守恒"的表象下，系统要么沿单向收紧退化成只会 `a_ask` 的保守死亡螺旋，要么在再认证时放行了一个被选择偏差掩盖、且采样器、证书器与锚点共同错判的计划。
