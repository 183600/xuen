## 1. 直觉与动机（两个灵感的碰撞）

**灵感 1（动态避障 → 这不是导航避障，而是「动作块盲区」里的时序鲁棒性问题）**

直觉：桌面操作没有大范围移动，真正的动态障碍是人的手、移动的干扰物、传送带上的物体。更关键的是：VLA 一次返回 `T_a` 步动作块，evaluator 顺序执行完才再次调用——在 `T_a/f` 秒内策略是「开环瞎子」。若照搬官方 16 步 @15Hz，盲区约 1.07s；人手穿过工作空间通常 0.3–0.8s。**等策略看见障碍，碰撞已经发生。** 所以动态避障的第一性原理不是「加一个避障模块」，而是「缩短盲区 + 提前预测」：要么把 `T_a` 降到 1–4 并承担更高推理频率，要么用历史栈估计速度、预测 TTC，在障碍进入工作空间前就把避让写进当前块。核心反直觉点：**在这个接口下，反应式避障基本不可行；可行的是预测式避障 + 提交期选择 chunk 长度。**

严谨定义：

- 策略 πθ 在决策时刻 `t_k = k·T_a/f` 观测 `o_{t_k−h:t_k}`，输出块 `A_k = (a_{t_k},…,a_{t_k+T_a−1})`，evaluator 开环执行。
- 动态扰动 `e(t)` 在 `t0` 出现，`TTC` 为到最近机器人连杆/夹爪的碰撞时间。
- 反应延迟 `Δ = T_a/f + L_detect + L_infer + L_net`；检测只能发生在决策时刻，故 `Δ ≥ T_a/f`。
- **可避让条件**：`TTC > Δ + ε`。定义可避让率 `A(π) = P(TTC > Δ)`。`T_a` 越大，`A` 越小。
- **动态泛化缺口** `G_dyn = E[score | 无动态扰动] − E[score | 有动态扰动]`。
- 目标：在延迟预算 `L_infer ≤ 1/f`（或分频推理）约束下，最大化 `E[score]` 对动态扰动分布的期望。

**灵感 2（真实世界泛化 → 泛化不是一条轴，而是一张「不变/等变/反应」矩阵）**

直觉：官方 5 轴 + 隐藏的跨机器人轴，要求的归纳偏置不同：背景/干扰物 → 不变性；位置 → 等变性；未见物品 → 语义类比；人为干扰/动态 → 反应性；跨机器人 → 标定不变性。用同一套「随机增广 + 平均 SFT」覆盖所有轴会互相打架：过度背景不变性可能抹掉任务相关线索；过度位置等变可能放大噪声。核心反直觉点：**真实世界泛化的正确单位不是「更多数据」，而是「每个轴一个正确的等变/不变性约束」；数据引擎要按轴配比，而不是按任务配比。**

严谨定义：

- 把评测分布写成混合 `P_eval = (1/5)Σ_a P_a`（每轴 2 次/任务），定义轴画像 `g(π) = (S_pos, S_dist, S_bg, S_unseen, S_human, S_robot)`。若各轴等权，总体分 `≈ (1/5)Σ_a S_a`。
- 定义最弱轴 `S_min = min_a S_a`、轴间方差 `Var_a(S_a)`。提出**轴条件风险** `CVaR_α(S_a)` 作为训练/选模目标，替代单一平均。
- 对每个轴定义变换群 `G_a` 与目标性质：不变 `f(g·o)=f(o)`（`g∈G_nuisance`）；等变 `f(g·o)=ρ(g)f(o)`（`g∈G_pose`）；反应 `f(o_{t−h:t}, e_{t−h:t})` 依赖时序。

**灵感 3（动态避障 × 真实世界泛化 → 用「安全预言机」造数据，而不是造模块）**

直觉：数据集全是成功、静态、标称；没有任何「人手来了怎么办」的示教。与其手工写避障控制器（引入新动作分布、且单模型边界存疑），不如用几何安全预言机在仿真/重放里生成「偏离→避让→恢复」的示教，把避障学进动作头。预言机只在训练期存在，推理期只有同一个 VLA + 风险辅助头。核心反直觉点：**避障能力应该从「合成失败示教」里长出来，而不是从推理期外挂模块里长出来；外挂模块越强，越可能违反单模型与延迟预算。**

严谨定义：

- 给定成功轨迹 `ξ=(s_t,a_t)`，在 `t0` 注入扰动得到 `ξ'`，用安全预言机 `Ω`（TTC/CBF/势场）生成避让动作 `a'_t`，并用状态空间最近邻从同任务其他成功轨迹拼接恢复后缀，得到合成示教 `ξ_syn=(s'_t,a'_t)`。
- 只有满足「避让后 `TTC>ε` 且最终达成下一得分点」的片段才入训。
- 合成示教有效性 `= 物理可行率 × 得分点达成率 × 与真实扰动分布的覆盖度`。

**三者统一**：动态避障给出「时间轴」这一缺失维度；真实世界泛化给出「轴条件归纳偏置」这一训练原则；合成示教给出「在不违反单模型/延迟约束下获得动态能力」的数据路径。本轮结论：**第 3 轮的胜负手从「数据量」转向「时间轴上的数据配比与 chunk 长度预算」——先把盲区缩短，再把避让学进块里。**

## 2. 对第 2 轮痛点的增量修订

- **P2（泛化缺口）**：从「5 轴静态校准」升级为「5 轴 + 跨本体 + 动态时间轴」的轴画像；动态轴是新的最大方差源。
- **P3（人为干扰）**：I4 的「自适应 chunk」在固定 `action_chunk_size` 下不可行（F21）；改为「提交期 chunk 长度预算 + 预测式风险门控 + 块内避让」。
- **P5（时间压力）**：动态扰动会放大超时；`T_a` 越小越安全但推理频率越高，需要显式延迟预算。
- **P7（先手窗口）**：跨机器人轴是多数队伍会忽略的隐藏轴，先做「本体归一化 + 相机随机化」可低成本拿分。
- **新增 P9（开环盲区）**：chunk 执行期间策略无法干预；这是动态避障的根本约束，也是本轮所有方案的可行性闸门。
- **新增 P10（动态数据稀缺）**：ConveyorSorting 仅 159 eps；动态示教必须合成/仿真补充。

## 3. 研究问题（本轮立项 Q9–Q11，Q1–Q8 保留）

- **Q9（延迟-反应权衡）**：在 `action_chunk_size` 固定、单步推理预算 B 下，`T_a` 与模型规模/分频推理如何联合优化，使动态扰动下期望得分最大？`T_a=1` 的慢-快异步策略是否可行且不触发延迟可信度惩罚？evaluator 实际是「整块执行」还是「逐步调用」？（这是本轮必须先确认的可行域边界。）
- **Q10（预测式避障的最小充分信号）**：仅用 4 路 RGB + 本体历史栈，能否在 TTC 前 0.3–0.5s 预测人手/移动物体侵入？风险头标签如何从安全预言机自动生成而不引入过多假阳性？
- **Q11（轴条件泛化）**：按轴配置不变/等变/反应约束，能否比均匀增广提升最弱轴与轴间方差？跨机器人标定轴能否用 reset 期少量自监督估计归一化？

## 6. 本轮最大风险

**一句话**：本轮方案的最大风险是——接口的开环 chunk 执行把动态避障压缩成「提交期 `T_a` 选择」问题：若 `T_a=1` 的推理频率过不了延迟可信度闸门，而大 `T_a` 又必然错过快速人手干扰，那么再好的预测与合成数据也只能覆盖慢扰动，动态轴收益存在硬上限；更糟的是，为降低碰撞而频繁 hold/retreat 会侵蚀标称任务的步骤分，而榜单按成功率优先，可能得不偿失。

# UniBot-V1 参赛创新点清单（第 3 轮 v1.2）

> 检索日期：2026-11-26（第 1 轮）、2026-11-27（第 2–3 轮）；来源见 §5。承接 v1.1：I1/I2/I4/I5/I6/I8/I9 深化，I10/I11 新增，I3 降级，I7 推理路径裁撤。清单只增改不重置。

## 0. 创新点清单（每点：动机 / 与现有方案差异 / 技术可行性 / 所需资源 / 落地步骤 / 风险）

### I4 v3 时间预算感知的 chunk 策略 + 预测式风险门控 ★★★★★

- **动机**：`action_chunk_size` 在 handshake 固定、action 形状严格校验（F21），chunk 一旦返回便开环执行；若照搬 16 步 @15Hz，盲区约 1.07s（F26），大于人手穿越工作空间的典型时间。动态避障的第一约束不是感知精度，而是「决策周期 vs TTC」。
- **与 v1.1 差异（重大修正）**：v1.1 的「运行期自适应 chunk」在当前接口下**不可行**，删除。改为三层：
  1. **提交期 `T_a` 预算**：在 `{1,2,4,8,16}` 中按延迟-反应联合目标选一个全局 `T_a`（伪代码 §1.1）；
  2. **运行期风险门控**：`get_action` 内计算风险/TTC，若超阈则对候选动作块重排、插入减速/保持/后退，并做**块末阻尼**（terminal damping），让下一块开始前速度已降低；
  3. **T_a=1 慢-快异步原型**（可选）：`T_a=1` 时每步调用；重 VLA 每 K 步后台更新一次潜计划，轻风险头每步修正；用双流/缓存隐藏延迟尖峰。
- **技术可行性**：高（T_a 扫描纯推理）；中（异步原型需工程）。
- **所需资源**：1×A100 推理；1 人周工程；无需重训即可先做 T_a 扫描。
- **落地步骤**：① 用单任务通道确认 evaluator 是「整块执行」还是「逐步调用」；② 测 `L_infer` 的 p50/p99；③ 在动态压力集上扫 `T_a × latency × TTC`；④ 选全局 `T_a`；⑤ 接风险门控与块末阻尼；⑥ L2 A/B（成功率、步骤分、碰撞率、p99）。
- **风险**：`T_a=1` 推理频率可能触发延迟可信度惩罚；hold/retreat 假阳性侵蚀步骤分；若 evaluator 实际逐步调用，则 `T_a` 论点需重估（先确认再放量）。

### I5 v3 动态扰动合成示教 + 得分点对齐恢复 ★★★★★

- **动机**：数据集全成功、全静态、标称；人为干扰轴（F22）与 ConveyorSorting 等动态任务（F24）缺「偏离→避让→恢复」示教。I5 v2 只做静态扰动重放/跨段缝合，未覆盖时间轴。
- **本轮深化（动态轴）**：在 v2 四条管线（扰动重放、跨段缝合、WMA 生成、得分点过滤）上新增**动态扰动合成**：
  1. **扰动库**：人手横穿、移动干扰物、物体被拨动、传送带速度突变；参数（速度、方向、进入角、遮挡时长）从考纲卡 + 任务 wiki 采样；
  2. **安全预言机**：仿真（Isaac Lab）中用 TTC/CBF/势场生成避让动作；真实数据中用「保持/后退/抬升」编辑动作 + 状态空间最近邻恢复后缀；
  3. **状态空间缝合**：以物体中心状态（不是像素）匹配同任务其他成功轨迹，拼接恢复后缀，保证动作来自真实分布；
  4. **双重过滤**：预言机验证无碰撞 + 官方得分点里程碑达成，才入训。
- **与现有方案差异**：v2 的恢复是静态偏离；v3 的恢复是时间轴上的避让 + 恢复；避让动作由预言机标注而非手工控制器，推理期不引入外挂模块。
- **技术可行性**：中-高。Tier 1（真实数据编辑 + 缝合）1 人周可出原型；Tier 2（Isaac Lab 动态场景）1×A100 3–5 天；Tier 3（WMA 视频生成）缓。
- **所需资源**：1×A100 仿真；1×24GB 训练；动态子集 ≈0.5TB。
- **落地步骤**：① 动态扰动库 schema；② ConveyorSorting + PlugInEthernet 两个试点；③ 预言机与缝合管线；④ 物理可行率/里程碑达成率抽检；⑤ LoRA 增量训练；⑥ L0 动态压力测试 → L2 单任务 A/B。
- **风险**：仿真-现实差距；预言机与真实人手运动分布失配；视频编辑产生物理不可行动作；合成数据污染标称行为（用低权重 + 家族级 L0 止损）。

### I10 预测性动态安全头（PDSH，新） ★★★★★

- **动机**：官方唯一显式动态轴是人为干扰（F22）；纯反应式策略受开环 chunk 限制（P9）。需要在障碍进入工作空间前预测 TTC，并把避让写进当前块。
- **核心设计**：
  1. **辅助头**：在 VLM/action expert 共享特征上接两个轻量头——风险头 `r_t=P(collision within H_r)`、TTC 回归头 `τ_t`；参数量 <1%；
  2. **训练标签**：仿真中用真实障碍/机器人轨迹算 TTC；真实数据用开放词汇检测 + 跟踪 + 本体正运动学估计；标称数据为负样本；用非对称损失惩罚漏检；
  3. **风险条件生成**：把 `(r_t, τ_t)` 编码为条件 token 注入 action expert，让模型自己生成减速/绕行/保持/后退，而不是外挂控制器；
  4. **推理门控**：`r_t > τ_hi` 或 `τ_t < Δ + margin` 时，采样 K 个候选块并用风险头重排；否则正常生成；**conformal 校准**阈值，控制标称集假阳性 hold <5%；
  5. **单模型合规**：风险头与动作头同属一个模型、一次前向/同一次 get_action，不是按任务切换的第二个模型。
- **与现有方案差异**：I4 的「人手检测」只是状态机触发；I10 把动态风险变成可微辅助任务 + 生成条件，能泛化到未见障碍轨迹。
- **技术可行性**：中。风险头训练 2 GPU 日；标签管线 1 人周；`T_a=1` 时风险头需 <10ms（可用小 backbone/蒸馏）。
- **所需资源**：1×24GB；跟踪/检测 CPU 或轻 GPU；1 人周。
- **落地步骤**：① 标签管线（仿真优先）；② 风险头离线训练与 ROC；③ 风险条件注入；④ conformal 阈值；⑤ 候选重排 + 块末阻尼；⑥ L0 动态压力 → L2 人为干扰抽测。
- **风险**：标签噪声与分布失配；假阳性 hold 伤步骤分；风险头自身延迟吃掉避让收益；对预言机过拟合。

### I11 跨本体标定归一化（CEN，新） ★★★★

- **核心设计**：
  1. **reset 后首个观测**（接口 `reset()` 无 obs，故在首次 `get_action`）估计标定 token：每 episode 本体统计（关节均值/方差、夹爪开度范围）+ 桌面平面/消失点/工作空间尺度 + 目标物体尺度；

- **所需资源**：1 人周；1×GPU；无需额外数据。
- **落地步骤**：① 标定 token schema；② 首帧估计器；③ 训练随机化；④ L0 相机/关节扰动测试；⑤ 有条件时真机双机器人抽测。

```python
def select_chunk_size(f_control, latency, dynamic_eps, budget_s):
    # latency: measured p50/p99 of get_action; dynamic_eps: (TTC, speed, angle) samples
    best = None
    for T in (1, 2, 4, 8, 16):
        blind    = T / f_control
        reaction = blind + latency.p99          # detection only at decision time
        avoidable = mean(ttc > reaction + EPS for ttc in dynamic_eps)
        timeout   = mean(reaction > budget_s)    # per-decision budget / task timeout proxy
        score     = avoidable - LAMBDA * timeout
        best = max(best, (score, T, blind, reaction, avoidable, timeout))
    return best                              # choose global T_a at submission time
```

### 1.3 风险条件动作头（I10）

```python
class PDSH(nn.Module):
    def forward(self, h):
        risk = torch.sigmoid(self.risk_mlp(h))          # P(collision within H_r)
        ttc  = F.softplus(self.ttc_mlp(h))              # seconds
        return risk, ttc

class TimeAwarePolicy:
    def get_action(self, obs):
        h = self.vlm(obs)
        risk, ttc = self.pdsh(h)
        cond = h + self.risk_embed(risk, ttc)           # 风险条件 token
        chunks = self.action_head.sample(cond, K=self.K)
        if risk > self.tau_hi or ttc < self.reaction_delay + MARGIN:
            chunks = self.rerank_by_risk(chunks, h)     # 选最安全的候选块
            chunks = self.terminal_damping(chunks)      # 块末降速，缩短下一盲区风险
        return chunks[0]
```

| L0-a | `T_a ∈ {1,2,4,8,16}` × latency `{0,20,40,80ms}` × TTC `{0.2,0.5,1.0,2.0s}` | 离线（免费） | 选出 `reaction < 0.5s` 且 timeout 风险可接受的 T_a |
| L0-b | 风险头 ROC/AUC、TTC 误差、标称集假阳性 hold 率 | 离线 | AUC ≥0.85；假阳性 hold <5% |
| L0-c | 动态合成示教：物理可行率、里程碑达成率、动作平滑度 | 离线 + 抽检 | 可行率 ≥90%、达成率 ≥80% |
| L0-d | 轴条件增广逐轴剂量-响应；最弱轴与轴间方差 | 离线（免费） | `S_min` +≥3pp，`Var` 下降 |
| L0-e | 跨本体扰动：相机 ±5°/焦距 ±5%/关节 ±2°/桌面 ±2cm | 离线 | 退化斜率降低 ≥30% |
| L1 | `{风险条件, 动态数据, 轴损失, T_a∈{2,4}}` 的 2^(4-1) 部分析因 | 离线 + 少量真机 | 主效应显著的 ≤3 组合进 L2 |
| L2 | 动态任务优先：ConveyorSorting、PlugInEthernet、PourOutMedicine、ZipUp；每任务 ≥2 次 | 单任务通道 | 成功率/步骤分不低于基线，碰撞率下降；p99 达标 |
| 门禁 | PR4：run_client 全流程 + p99 + 动作健康度 | 本地 stub | 0 拒绝动作；p99 < 40ms（或 T_a 预算内） |

**首批 L2 排队**：① I4 `T_a` 基线（动态压力）→ ② I10 风险门控 → ③ I5 动态合成数据 → ④ I11 跨本体抽测 → ⑤ I1/I8 轴条件增广。

## 4. 伦理合规 checklist（更新）

- [ ] **单模型边界**：I10 风险头是同一模型的辅助头，不按任务切换第二个模型；I11 标定 token 是推理期条件注入，零权重更新；I9 检索是推理期计算。以上均需向组委会书面确认（**新增确认项**）。
- [ ] **不做在线学习/适应**：所有 reset 期估计、风险条件、检索均为前向计算；不更新任何权重。
- [ ] **action_chunk_size 固定**：`T_a` 在提交时确定，运行期不改变形状；文档中明确。
- [ ] **人手安全**：hold/retreat/减速动作界内平滑，符合 PR3；不因避障做出突发大动作。
- [ ] **数据使用**：官方数据集（32 任务 + 110 语料 + DiverseManip + Sim）许可条款内使用；合成数据注明来源与生成方式；不使用评测数据。
- [ ] **动作健康度**：每次提交过 PR4（界内/平滑/统计正常）；延迟 p99 与 `T_a` 联动记录。
