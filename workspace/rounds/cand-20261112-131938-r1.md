# 第 58 轮（承接第 57 轮「元少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「持续学习」×「双臂协作」）

> 第 57 轮用元先验换效率、共形带给保底、跨模态给对账、个性化给有界信任，把"证据承诺"推到五层纵深。但它自陈的最大风险恰好指向两个被静态化处理的前提：**(a)** 元训练集 𝒟_meta 被当作冻结的历史语料，部署中每次新到访、每次事后判定都不回流——"坏先验普遍"不仅不会被纠正，反而会在同一盲区里被反复确认；安全框架只有"轮次"，没有"时间"。**(b)** 所有证据来自同一个身体：XMC 的四个模态共享同一控制器、同一标定、同一力路径，"跨模态"只是传感器层面的分工，不是物理层面的独立——一次共模标定漂移能让四个模态同时说假话。本轮两个灵感各补一条时间/身体维度的腿：**持续学习**让先验在部署生命期内可塑，但可塑性被证据门、回放、遗忘预算与冻结安全核约束——会学，但不许把安全边界学走；**双臂协作**把单一身体拆成两条半独立物理通道（锚定臂/探询臂），跨臂对账既能生产"物理冗余证据"，也首次暴露"共模一致"这一幻觉，并显式管理两臂共同适应的漂移。核心命题由"证据承诺"升级为 **"可塑而不遗忘、协作而不共谋的持续证据承诺"**（Continual Non-Forgetting, Cooperative Non-Colluding Evidence Commitment，LCCS）。

核心矛盾：
- **H29（可塑性 vs 稳定性：遗忘即失证）**：持续更新能以更低的悔值换取更准的先验，但也会覆盖掉让它保持安全的证伪记忆与 OOD 语料；一个"学会更快自信、却更慢学会自己错"的模型，是把围栏往后挪的模型——旧盲区被遗忘的那一刻，安全界悄悄收缩了。
- **H30（自学 vs 自证：反馈闭环）**：用自己的部署数据训练自己，会形成闭环：模型的选择决定了它能看到什么数据，未经验证的"成功"被当作真值回灌，置信度自我膨胀；这不是普通过拟合，而是"世界只剩模型已经相信的那部分"。
- **H31（双体独立 vs 共模：一致性可以是伪造的）**：两臂看着独立，却共享控制器/标定/供能/模型；共模误差能让两臂给出高度一致却同时错误的证据，而把相关证据重复计数比只用一条更危险。物理冗余若无独立性证书，只是把同一个错误问了两遍。
- **H32（分工 vs 耦合：锚定臂改变探询臂的物理）**：一臂探询、一臂锚定听起来像分工，但锚定臂的接触力/位姿会改变探询臂所测量的表面响应；角色分配还会被风险模型博弈（把困难探测推给"探询臂"），而两臂同时做不可逆接触会把风险集中成一次"联合承诺"。

## 0. 直觉与动机

**灵感 1（持续学习 → 可塑性挂在证据门后，遗忘必须有预算）**
直觉：安全的持续学习不是"允许模型一直更新"，而是"只允许被外部判定过的经验、以受控速率、更新到允许更新的那部分参数上"。把系统参数切成两块：**冻结安全核 Θ_safe**（决策规则、P_fail 界、证据门本体、授权硬界）与**可塑先验 Θ_pl**（区域信念、元先验、模态可靠性）。所有学习只投影进 Θ_pl；Θ_safe 只能由人审的版本升级触碰。经验分三态入台账：verified / falsified / unresolved——只有前两者能训练，unresolved 进隔离区等判定；回放按"证伪 × 近失 × 稀有 × 新近"加权，确保"自己错过的事"反复出现；学习率 η_t 随"离不可逆接触的距离"降低，探针与承诺之间设**学习冻结窗**；每次更新后在安全回归集 R_safe 上验收，性能不得低于上次认证检查点，否则回滚。学习被允许变准，但不被允许变松。

**灵感 2（双臂协作 → 物理冗余、锚定/探询分工、共模审计）**
直觉：双臂的价值不是"两个模态"的简单叠加，而是两个**有不同物理路径**的通道：不同接触点、不同标定纪元、不同力路径、尽量隔离的故障域。跨臂对账给出两种信息：**分歧即共模警报**（两臂看到的世界不一致，先别信任何一臂）；**一致即冗余证据**（仅在共模独立性证书成立且仅限非不可逆接触 L1 时，才可顶替一次佐证）。协作协议固定为 **anchor/probe**：锚定臂保持"冻结保守策略 + 稳定支撑"，探询臂做主动探测；锚定臂永远不参与学习，它是活的参照系。共享风险预算把两臂的失败概率与耦合风险合并计账；任一时刻至多一臂执行不可逆接触，除非两臂各有独立证据。

**灵感 3（持续学习 × 双臂 → 共同适应漂移与证据重复计数）**
直觉：单臂遗忘是"盲区固定、记忆流失"，双臂共学则是"盲区移动、两臂互相确认"。两条都在学的策略会朝彼此靠拢并共同漂移到一个自洽但错误的世界；共享经验若被两臂分别学习，等于把同一条证据计了两次，方差被人为压低。对策是三重的：台账全局唯一、证据复用只计一次；监控跨臂策略散度 δ_π（过低=同化成共模，过高=世界观矛盾），任一越界触发**独立性重置**（一臂切金丝雀冻结策略、外部锚定再标定）；金丝雀臂永不离线学习，作为对照真相。

**灵感 4（合流 → 证据门从五类到七类、安全核冻结、台账进证书）**
直觉：第 57 轮五类证据各得一个新维度：`EV-probe*` 增加"先验来自哪一版、可塑部分是否已回归验收"；新增 **EV-continual**（只来自台账中已验证/已证伪、且 K_cl 达标、且不在学习冻结窗的更新，且只能当佐证/先验，不能当不可逆接触主证据）与 **EV-dual**（跨臂一致，限 L1 ∧ 共模独立证书）。击穿安全 теперь要：元先验错 ∧ OOD 漏检 ∧ 跨模态无一致 ∧ 跨臂共模漏检 ∧ 遗忘回归失效 ∧ 无裕度 ∧ 人也错——纵深从五层到七层。证书从 J_p 扩为 **J_c**，把台账摘要、回放覆盖、遗忘余量、自训练比、锚定比、共模证书、角色日志、共适监控一起入证。

**灵感 5（PCEL → 承诺之后还有"学习义务"，但学习不能成为冒险的借口）**
直觉：把探-诺-演扩展为探-诺-演-**学**。每次承诺不是终点：外部判定回流台账、门控、回放、回归、必要时回滚，才是这一轮的闭环。VOI 里可以加入"未来训练价值"，但必须被折扣并与安全严格分离：训练价值只能为**非破坏性**探询提供额外动机，绝不能把一个原本 halt 的动作因为"能学到东西"而升级为可执行——学习只能让系统更愿意在安全阴影里多看，不能让系统更敢赌。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（持续证据台账 CEL）** 台账 ℒ_t={(e_i,τ_i,v_i,src_i,indep_i,h_i)}，判定 v_i∈{V(erified),F(alsified),U(nresolved)}。学习门 G_learn(e)=[v≠U]∧[src.external∨post_hoc_measured]∧[e∉quarantine]∧[reuse_count 全局唯一]。更新 θ_{t+1}=Proj_{Θ_pl}(θ_t−η_t∇L(Replay_p(ℒ_t)∪V_t))，其中 Θ_safe 冻结（决策规则/证据门/P_fail 界/授权硬界不参与梯度）；回放优先级 p_i∝recency×nearmiss×falsified×rarity。遗忘预算：对安全回归集 R_safe，Perf_{t+1}(R_safe)≥Perf_t(R_safe)−δ_forget，否则回滚至最近认证检查点 θ_cert。

**定义 140（稳定性-可塑性证书 SPC）** 学习率 η_t=η0·g(d_risk,backlog_U,margin_reg)，d_risk 为到最近不可逆接触的风险邻近度，g 单调不增；探针与承诺之间设学习冻结窗（禁止写 θ_pl，或提交前快照回滚校验）。证书 K_cl=(replay_cov, forget_margin, ρ_self=|self-trained|/|train|, α_anchor=|external V/F|/|train|, checkpoint_id)；未达标 ⇒ 不得产生 EV-continual，且回滚。

**定义 141（跨臂对账 XAR）** 臂集 𝒜={L,R}，分臂信念 b_r^a，可靠性 ρ_a。跨臂分歧 D_arm(r)=Σ_{a<a'}[TV(lbl^a,lbl^{a'})+|Q_μ^a(0.9)−Q_μ^{a'}(0.9)|/μ_scale]+内部力/位姿一致性违背。共模独立性证书 CM(r)=接触点分离 ∧ 标定纪元不同 ∧ 力路径不共享 ∧ 故障域隔离声明。规则：(R1) D_arm>θ_arm ⇒ 两臂均降权并加宽后验；(R2) EV-dual ⇔ D_arm≤θ_arm ∧ CM(r) ∧ level≤L1 ∧ 角色日志完整，仅可顶替一次 L1 佐证；(R3) 共享风险预算 risk_L+risk_R+coupling≤δ_f；除非两臂各有独立证据，任一时刻至多一臂做不可逆接触。

**定义 142（共同适应监控 CAM 与金丝雀臂）** δ_π(t)=divergence(π_L,π_R)，r_reuse=共享转移被重复计入学习的比例，共模漂移统计量。若 δ_π 低于 θ_collapse（同化→共模）或高于 θ_split（世界观矛盾），或 r_reuse>ρ_reuse_max，或共享先验漂移超界 ⇒ 触发独立性重置：一臂切入金丝雀冻结策略 π_canary（永不学习），外部锚定再标定，注入证伪回放入侵检验。

**定义 143（生命期证据门 LSE 与证书 J_c）** 证据类 EV-probe\*/visit/margin/xmodal/human/**continual**/**dual**。EV-continual ⇔ 来源∈ℒ_t 的 V/F ∧ K_cl 达标 ∧ 不在学习冻结窗 ∧ 仅作佐证/先验（不得进入不可逆接触必要证据集）。EV-dual ⇔ 定义 141 的 R2。J_c=(J_p, ledger_digest, K_cl, R_safe 结果, r_reuse, CM 证书, 角色日志, CAM 日志, θ_cert 版本)，继承 J_p 全检。

**定义 144（探-诺-演-学算子 PCEL）** 在 PCX 每检查点后插入"学"阶段：提交→外部判定→写台账→门控 G_learn→回放→R_safe 回归→（失败则回滚）。VOI 扩展 VOI_元悲观(π)+β_t·V_train(π)，但约束：V_train 只能为非破坏性（L0/L1）探询增加动机，且 argmax 结果不得使原本 halt 的动作变为可执行——`g'=halt ⇒ 任何 β_t 下仍 halt`。探尽→绕行→降档→L2 协商→安全停，四态不变。

## 2. 关键算法伪代码（完整版见产物区）

```python
def continual_learn(ledger, prior, regression):        # IP-139/140
    batch = replay(ledger, key=lambda e: recency*e.nearmiss*e.falsified*e.rarity)
    batch = [e for e in batch if learn_gate(e)]          # 只有 V/F 且外部锚定
    theta = project(theta_pl, grad_step(prior, batch, eta=eta_t(d_risk)))
    if perf(theta, regression.R_safe) < perf(theta_cert, regression.R_safe) - d_forget:
        return theta_cert, 'rollback'                    # 遗忘越界即回滚
    return theta, 'accepted'

def dual_arm_reconcile(M, r, b_L, b_R, cm):             # IP-141
    D = arm_divergence(b_L, b_R)
    if D > theta_arm:
        return widen(b_L), widen(b_R), 'common_mode_alarm'
    ev = 'EV-dual' if cm.certified() and level(r) <= 'L1' and role_log_ok() else None
    return fuse(b_L, b_R), ev, 'ok'

def co_adapt_monitor(pi_L, pi_R, ledger, r_reuse):       # IP-142
    if divergence(pi_L, pi_R) < theta_collapse or divergence(pi_L, pi_R) > theta_split \
       or r_reuse > rho_reuse_max:
        return independence_reset(canary=pi_canary, ledger=ledger)  # 一臂切冻结金丝雀
    return 'ok'
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| CEL | O(\|batch\|) 回放 / O(1) 追加 | O(\|ℒ\|) 版本化 | 只学 V/F、投影不进 Θ_safe、回滚完备 |
| SPC | O(\|R_safe\|)/验收 | O(\|R_safe\|) | 遗忘界、冻结窗、自训练比与锚定比 |
| XAR | O(\|𝒜\|²·d_b+\|𝒞\|) | O(\|V\|·\|𝒜\|·d_b) | 共模独立证书、证据只计一次、L1 限用 |
| CAM | O(H) 窗口 | O(H) | 同化/分裂双阈值、金丝雀不可学习 |
| LSE | O(\|σ\|) | O(\|σ\|) | 无证据类即拒、EV-continual 不得作主证据 |
| PCEL | O(\|CP\|·(k_p+k_c)·(C_VOI+d_φ)+\|ℒ\|·k_r) | O(\|V\|+\|σ\|+\|ℒ\|) | β_t 不改变 halt、终止性不变 |

**正确性定理（Lifelong Cooperative Calibrated Soundness, LCCS 概要）**：在 A37–A40 上加 (A41) 台账判定诚实且外部锚定比 ≥α_anchor；(A42) 遗忘预算与回归集有效、回滚原子；(A43) 共模独立性证书健全、证据全局只计一次；(A44) CAM 对同化/分裂的漏检 ≤δ_cam。则：(i) **学习单调性**：θ 更新被投影进 Θ_pl 且回滚保证 Perf(R_safe) 不降超 δ_forget，任何学习都不放宽证据门与 P_fail 界；(ii) **双体健全性**：EV-dual 贡献 ≤δ_dual·1[L1]·1[CM]，共模失败被隔离在 L1，且相关证据不重复计数；(iii) **遗忘有界**：Perf_t(R_safe) ≥ Perf_0(R_safe) − t·δ_forget，OOD 检出率不退化；(iv) **终止性**：PCEL 在 k_probes+k_cons 内终止于 {承诺, 绕行, L2 协商, 安全停}，β_t 不影响 halt；(v) 部署界在 CCPS 基础上减去遗忘/自证/共模/CAM 四项失败概率。

## 6. 本轮最大风险

**一句话**：持续学习把上一轮"冻结语料里的固定盲区"变成了"会移动、会自我确认的盲区"——系统把自己的未验证经验写回先验，而两臂共同适应又能让两条学习轨迹互相印证，使"遗忘了外部世界"这件事在系统内部看起来越来越一致、越来越自信；必须以冻结安全核、外部判定锚定、共模独立性证书与永不学习的金丝雀臂四重护栏，宁可学得慢、宁可不学，也绝不让学习把围栏一起搬走。

# 第 58 轮产物 · 创新点清单 v34：Lifelong-DualArm（持续证据台账×稳定性证书×跨臂对账×共适监控，CEL×SPC×XAR×CAM×LSE×PCEL）

> 承接第 57 轮 IP-133~138（MFSL/XMC/PTM/MXI/FSE/PCE+）、第 56 轮 IP-127~132（SMM/PCE/BVK/ISE/TAF/MEC）。本轮把"证据承诺"从一次性、单身体的静态框架，升级为 **"可塑而不遗忘、协作而不共谋的持续证据承诺"**：先验随生命期可塑但被证据门与遗忘预算约束，证据从单身体跨模态扩展到双身体跨臂对账，学习本身成为探-诺-演之后的第四阶段；第 57 轮"一切判定器走隔离"推广为"**一切学习走证据门 + 一切冗余过共模审计**"。

## 2. 关键算法伪代码

### IP-139 CEL（持续证据台账）

```python
def append_evidence(ledger, e, verdict, source):
    if e.uid in ledger.seen:                 # 全局唯一：跨臂/跨模态共享只计一次
        return ledger                        # 防止相关证据被重复训练
    ledger.seen.add(e.uid)
    ledger.add(E(e, t_now, verdict, source,
                 indep=source.independence_class(),
                 h=hardness(e)))             # near-miss / falsified / rare
    return ledger

def build_batch(ledger, k):
    cand = [e for e in ledger if e.v in ('V', 'F') and not e.quarantined]
    cand.sort(key=lambda e: e.recency * e.nearmiss * e.falsified * e.rarity,
              reverse=True)                  # 证伪/近失优先回放
    return cand[:k]
```

### IP-140 SPC（稳定性-可塑性证书 + 冻结安全核）

```python
def safe_learn(theta_pl, ledger, regression, risk_proximity, backlog):
    if in_learning_freeze_window():          # 探针—承诺之间禁止写入
        return theta_pl, 'frozen'
    eta = eta0 * g(risk_proximity, backlog, regression.margin)  # 越靠近不可逆越慢
    batch = build_batch(ledger, k_replay)
    cand = project_pl(theta_pl - eta * grad(theta_pl, batch))   # 只投影进 Θ_pl
    if perf(cand, regression.R_safe) < perf(theta_cert, regression.R_safe) - delta_forget:
        return theta_cert, 'rollback'        # 遗忘越界：原子回滚
    theta_cert = snapshot(cand)              # 认证检查点
    return cand, 'accepted'

def stability_plasticity_cert(ledger, regression, theta_cert):
    return K_cl(replay_cov=coverage(ledger, regression),
                forget_margin=perf(theta_cert, regression.R_safe) - perf_floor,
                self_ratio=self_trained_ratio(ledger),
                anchor_ratio=externally_verified_ratio(ledger),
                checkpoint_id=theta_cert.version)
```

### IP-141 XAR（跨臂对账 + 共模审计）

```python
def cross_arm_reconcile(M, r, arm_L, arm_R, cm_cert, role_log):
    D = arm_divergence(arm_L.b, arm_R.b) \
        + internal_force_violation(arm_L, arm_R)  # 内部力/位姿一致性
    if D > theta_arm:                             # R1: 分歧即共模警报
        M.b[r]['L'] = widen(M.b[r]['L'])
        M.b[r]['R'] = widen(M.b[r]['R'])
        return M, None, 'common_mode_alarm'
    fused = fuse(M.b[r]['L'], M.b[r]['R'], weights=[rho_L, rho_R])
    ev = None                                     # R2: 一致即证据，仅 L1 ∧ CM
    if cm_cert.certified(r) and level(r) <= 'L1' and role_log.complete():
        ev = 'EV-dual'
    risk = risk_L + risk_R + coupling_risk(fused) # R3: 共享风险预算
    assert not (irreversible(arm_L) and irreversible(arm_R)) or both_independent()
    return M, ev, ('ok' if risk <= delta_f else 'risk_over_budget')
```

### IP-142 CAM（共同适应监控 + 金丝雀臂）

```python
def co_adapt_monitor(pi_L, pi_R, ledger, r_reuse, shared_prior):
    d = divergence(pi_L, pi_R)
    if d < theta_collapse:                       # 同化 → 共模风险
        return independence_reset('collapse')
    if d > theta_split:                          # 分裂 → 世界观矛盾
        return independence_reset('split')
    if r_reuse > rho_reuse_max or drift(shared_prior) > theta_drift:
        return independence_reset('reuse_or_drift')   # 证据被重复计数/共同漂移
    return 'ok'

def independence_reset(reason):
    switch_arm('R', pi_canary)                   # 一臂切永不学习的金丝雀
    re_anchor_external()                         # 外部锚定再标定
    inject_falsification_replay()                # 注入证伪回放检验
    return 'reset', reason
```

```python
def lifelong_evidence_gate(c, M, persona, ood_reg, K_cl, cm_cert, role_log):
    if   c.ev == 'EV-probe*':
        ok = round57_probe_checks(c, M, ood_reg)
    elif c.ev == 'EV-continual':
        ok = (c.src in ('V', 'F') and K_cl.ok() and not in_learning_freeze_window()
              and not c.irreversible)            # 只能当佐证/先验
    elif c.ev == 'EV-dual':
        ok = c.level == 'L1' and cm_cert.certified(c.region) and role_log.complete()
    elif c.ev in ('EV-xmodal', 'EV-human', 'EV-visit', 'EV-margin'):
        ok = round57_gate(c, M, persona, ood_reg)
    else:
        return ('reject', 'no_evidence_class', c)
    if not ok: return ('reject', 'evidence_insufficient', c)
    if c.irreversible and c.ev in ('EV-dual', 'EV-continual'):
        return ('reject', 'lifelong_coop_not_primary', c)   # 硬禁令
    return ('ok', c)

def map_certificate_c(sched, log, M, ledger, K_cl, cm, cam, role_log):
    for c in contacts(sched):
        st = lifelong_evidence_gate(c, M, persona_of(c), ood_reg, K_cl, cm, role_log)
        if st[0] != 'ok': return st
    if not K_cl.ok():                          return ('reject', 'SPC_unmet')
    if cam.state != 'ok':                      return ('reject', 'co_adaptation_risk')
    if ledger.reuse_rate() > rho_reuse_max:    return ('reject', 'evidence_double_count')
    return ('ok', Jc(Jp(...), ledger.digest(), K_cl, R_safe_result,
                     ledger.reuse_rate(), cm.certificates(), role_log, cam.log))
```

### IP-144 PCEL（探-诺-演-学）

```python
def probe_commit_evolve_learn(x0, M, task, budget, consent, personas, ledger):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        inf = meta_few_shot_infer(M, cp.region, M.obs[cp.region], meta)  # 第 57 轮
        sigma, R = foothold_schedule(x0, cp, M), None
        while True:
            R = schedule_risk(sigma, M)
            if select_gait(R) != 'halt' or budget.probes_left == 0: break
            cands = admissible_probes(cp, M, F_abs)
            if not cands: break
            p = argmax(cands, key=lambda q: voi_meta_pessimistic(q, M, inf)
                       + beta_t * V_train(q, ledger) - cost(q))           # 学只加动机
            if voi_meta_pessimistic(p, M, inf) < theta_voi: break
            if V_train(p, ledger) > 0 and irreversible(p):
                continue                          # 学习动机不得制造不可逆冒险
            M, _, D = xmodal_fuse(M, cp.region, execute_probe(p, cap=F_abs))
            sigma = reselect_footholds(x0, cp, M); budget.spend(p)
        g = select_gait(R)
        if g != 'halt' and lifelong_evidence_gate(
                core_contact(cp), M, personas, ood_reg, K_cl, cm, role_log)[0] == 'ok':
            sched.append(commit(sigma, g)); log.append(tag_evidence(cp, M))
        else:
            alt = reroute(M, cp, risk_model)
            if alt and select_gait(schedule_risk(alt, M)) != 'halt': route = alt; continue
            return negotiate_or_stop(cp, M, sigma, R, consent,
                                     tau_int=tau_int(personas.active.auth))
    # 学阶段：提交之后才有资格学习
    for outcome in external_verdicts(sched):
        ledger = append_evidence(ledger, outcome.e, outcome.v, outcome.src)
        theta_cert_new, st = safe_learn(theta_pl, ledger, regression,
                                        proximity(M), ledger.backlog())
        co_adapt_monitor(pi_L, pi_R, ledger, ledger.reuse_rate(), shared_prior)
    return sched, log, M, ledger
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CEL | O(\|batch\|) 回放 / O(1) 追加 | O(\|ℒ\|) 版本化 | 只学 V/F、全局唯一去重、投影不进 Θ_safe（A41） |
| SPC | O(\|R_safe\|)/验收 | O(\|R_safe\|) | 遗忘界、学习冻结窗、锚定比/自训练比（A42） |
| XAR | O(\|𝒜\|²·d_b+\|𝒞\|) | O(\|V\|·\|𝒜\|·d_b) | 共模证书、EV-dual 限 L1、证据只计一次（A43） |
| CAM | O(H) | O(H) | 同化/分裂双阈值、金丝雀不可学习（A44） |
| LSE | O(\|σ\|) | O(\|σ\|) | 七类门、EV-continual 不得作主证据 |
| PCEL | O(\|CP\|·(k_p+k_c)·(C_VOI+d_φ)+\|ℒ\|·k_r) | O(\|V\|+\|σ\|+\|ℒ\|) | β_t 不改 halt、k_p+k_c 终止、四态完备 |

**正确性定理（Lifelong Cooperative Calibrated Soundness, LCCS）**
假设 A22–A32（第 53–55 轮）、A33–A36（第 56 轮）、A37–A40（第 57 轮）成立；**(A41)** 台账判定诚实、外部锚定比 ≥α_anchor、证据 uid 全局唯一；**(A42)** 安全回归集有效、遗忘预算 δ_forget、回滚原子且认证检查点可信；**(A43)** 共模独立性证书健全（接触点/标定纪元/力路径/故障域），相关证据不重复计数；**(A44)** CAM 对同化与分裂的漏检率 ≤δ_cam，金丝雀臂策略永不离线学习。则：

1. **学习单调性（不学走安全边界）**：所有梯度更新投影进 Θ_pl，Θ_safe（决策规则、证据门、P_fail 界、授权硬界）不变；回滚保证 Perf_t(R_safe) ≥ Perf_0(R_safe) − t·δ_forget，OOD 检出率不退化。故学习只能改善先验或效率，不能放宽承诺条件。
2. **双体健全性（协作不共谋）**：EV-dual 贡献 ≤ δ_dual·1[L1]·1[CM]；D_arm>θ_arm 时两臂均降权并加宽；证据 uid 唯一使相关经验不被重复计数，方差估计不被人为压低；共模失败被隔离在 L1，不进入不可逆接触必要证据集。
3. **自证有界**：ρ_self≤ρ_self_max、α_anchor≥α_anchor_min；U 状态证据永不训练，故部署反馈不能无限自我确认；α_anchor 不足时学习门直接拒学。
4. **共适可检**：δ_π 越界或 r_reuse 越界触发独立性重置，金丝雀臂提供外部对照；漏检概率 ≤δ_cam 并计入部署界。
5. **终止性**：β_t·V_train 只增动机不改 halt（`g=halt ⇒ 仍 halt`），PCEL 仍在 k_probes+k_cons 内终止于 {承诺, 绕行, L2 协商, 安全停}。
6. **部署界**：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf
                   + δ_xm·1[L1] + δ_dual·1[L1∧CM])
             − P(𝓜 陈旧未检出) − P(护盾回退失败)
             − P(遗忘回归失败) − P(自证闭环未被门控)
             − P(共模证书失效) − P(CAM 漏检)
```

关键：**学习给效率、冻结核给边界**（可塑与安全解耦，赌注不押在"模型会学对"上）；**冗余给信心、共模审计给否决权**（一致性只有在独立性成立时才是证据）；**金丝雀臂给外部真相**（总有一条永不离线的保守策略作为活参照）；三个新机制仍只经"信念更准（含回滚）"或"动作更保守（加宽/降档/停）"两个安全通道起作用。

## 6. 本轮最大风险

**一句话**：持续学习把上一轮"冻结语料里的固定盲区"变成了"会移动、会自我确认的盲区"——系统把自己的未验证经验写回先验，而两臂共同适应又能让两条学习轨迹互相印证，使"遗忘了外部世界"这件事在系统内部看起来越来越一致、越来越自信；必须以冻结安全核、外部判定锚定、共模独立性证书与永不学习的金丝雀臂四重护栏，宁可学得慢、宁可不学，也绝不让学习把围栏一起搬走。
