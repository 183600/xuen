# 第 41 轮 · 双灵感落地 v8：场景接地规范图谱 × 可审计伦理证书 × 伦理审查闭环（四层架构 v6）

> 承接第 40 轮（v17：可认证流匹配执行 × 度量语义几何锚定 × 证书驱动课程引擎，四层架构 v5；本循环第 2 轮）。灵感词「场景理解、伦理审查」补上第 40 轮证书体系仍缺的一维：**规范（norm）**。第 40 轮证明了动作「在几何与动力学意义上安全」，却没有回答「该动作在该场景中是否被允许」。本轮主张：伦理审查应与鲁棒性证书同构，成为「规范接地—规范证书—运行期审计—事件召回」的闭环；场景理解既是规范的接地传感器，又必须被伦理审查反向约束（目的绑定、数据最小化）。

## 0. 直觉与动机

**灵感 1（场景理解 → 规范的接地传感器）**：第 40 轮的证书回答「会不会撞」，不回答「该不该做」。安全是动力学命题，规范是语义命题：不得在私密空间拍摄、接触前须获同意、儿童须有监护人在场、不得进入他人财产——这些规范在抽象文本里都不可执行，必须先落到「谁在场、处于何种区域、关系是什么、是否同意」这些**场景谓词**上。于是场景理解成为规范的接地传感器，地面真值从第 40 轮的度量几何（点云、ESDF、漂移球）变成**类型化语义场景图**。但点估计在伦理上不可接受：漏检一个儿童、把私密区误判为公共区、把「未同意」读成「默许」，都是零容忍的安全关键假阴性。因此场景理解必须输出**校准解释集**（保形预测 + 在线 ACI），规范检查对解释集做**最坏情形**评估，而不是对最可能的单点标签评估——这是第 40 轮「漂移球内最坏情形」的语义版本。

**灵感 2（伦理审查 → 与 RCA 同构的治理闭环）**：若把伦理审查当成上线前一次性盖章，它必然退化为「伦理洗白」。本轮把它重构为与鲁棒性证书同构的运行期闭环：**规范图谱编纂（审查）→ 规范证书签发 → 运行期审计链 → 违规/近失触发召回与重审**。其中最关键、也最容易被回避的是**可编纂边界**：只有「可测量 ∧ 时域有界 ∧ 严重度有共识」的规范才允许机检，其余必须显式划入人类保留集并强制升级。证书必须自报边界与审查来源，否则「已认证」会制造对未编纂部分的虚假安全感。同时，伦理审查必须反向约束场景理解本身：目的绑定、数据最小化、原始可识别数据不出感知层——理解越深，越界能力越强，这是双用途问题的核心。

**三者的耦合（承接第 40 轮的三根支柱）**：第 40 轮的流匹配/几何/课程给出了「能」（capability），本轮补上「可」（permission）与「该」（obligation），并把二者做成**乘积证书**而非简单相加：执行前要求 `CertRobust.ValidRegion ∩ CertNorm.NormRegion ≠ ∅`，冲突时规范优先。场景理解供给规范接地，伦理审查约束场景理解，二者共用同一条证据与审计链。

## 1. 形式化定义

**定义 27（校准场景图与解释集）**：类型化场景图 $G=(O,R,Z,Ag)$，$O$ 为对象节点（类型、位姿、可见性），$R$ 为关系边（持有、靠近、监护、进入），$Z$ 为区域（私有/公共/危险），$Ag$ 为行为主体（角色：成人/儿童/未知）。场景理解器 $f_{scene}$ 输出点估计 $\hat G$ 与一致性打分 $s(G;I)$。给定校准集 $D_{cal}$，取分位 $q_\alpha$ 使 $P(s(G^*;I)\le q_\alpha)\ge 1-\alpha$，定义**校准解释集** $\hat G_\alpha=\{G:s(G;I)\le q_\alpha\}$。部署中用自适应保形推断（ACI）在线更新 $q_\alpha$ 以应对非平稳场景分布。

**定义 28（接地规范图谱）**：规范 $\nu=(id,m,\sigma,\psi,\tau,w,\rho)$，其中 $m\in\{O\text{ 义务},P\text{ 许可},F\text{ 禁止}\}$ 为道义模态；$\sigma$ 为场景模式（对 $G$ 的子图查询，决定适用性）；$\psi$ 为动作—场景时序约束（MITL 公式，原子命题取自场景谓词与动作谓词）；$\tau$ 为有界时域；$w$ 为严重度；$\rho$ 为审查来源（法规条款/内部政策/人工裁量记录）。规范图谱 $A=\{\nu_k\}$，接地为 $A(G)=\{\nu_k:G\models\sigma_k\}$。审查把 $A$ 划分为**可机检集** $A_{cert}$ 与**人类保留集** $A_{hum}$（见定义 30）。

**定义 29（伦理证书 CertNorm 与规范盾）**：对动作块轨迹 $\pi$ 与解释集 $\hat G_\alpha$，定义最坏情形违规

$$R_{eth}(\pi\mid \hat G_\alpha)=\max_{G\in\hat G_\alpha}\ \sum_{\nu\in A_{cert}(G)} w_\nu\cdot viol_\nu(\pi,G).$$

规范盾为约束投影 $\pi^\dagger=\arg\min_{\pi'\in\Pi}\|\pi'-\pi\|^2\ \text{s.t.}\ R_{eth}(\pi'\mid\hat G_\alpha)\le\varepsilon_{eth}$；若可行集为空则输出 $escalate$（升级人类），记为带成本 $c_{esc}$ 的零违规动作。$CertNorm=(A_{cert},\alpha,\varepsilon_{eth},c_{esc},audit\_root,expiry,provenance)$。组合：技能序列的规范证书按 $A_{cert}$ 并集与 $w$ 最大值合成；$O$ 与 $F$ 同时适用等冲突触发升级。

**定理（规范盾的条件可靠性）**：若 (i) 保形覆盖成立 $P(G^*\in\hat G_\alpha)\ge 1-\alpha$（ACI 在线维持），(ii) $A_{cert}$ 中规范的谓词均可由感知栈测量且时域有界，(iii) 盾按定义 29 接受 $\pi^\dagger$，则 $P(\pi^\dagger\ \text{违反}\ A_{cert}\ \text{中任一规范})\le \alpha+\delta_{aci}$，$\delta_{aci}$ 为 ACI 覆盖率漂移项。**该定理只保证对已编纂规范 $A_{cert}$ 的合规，不保证伦理正确**——后者由定义 30 的边界显式分离，这是本轮最重要的诚实声明。

**定义 30（审查边界、审计链与召回）**：可编纂边界 $\partial A=A_{cert}/A_{hum}$；$\nu\in A_{cert}$ 当且仅当 可测量 $\wedge$ 时域有界 $\wedge$ 严重度阈值经审查共识。审计链 $h_t=H(h_{t-1}\Vert I_t\Vert \hat G_{\alpha,t}\Vert A(G_t)\Vert CertNorm_t\Vert \pi_t\Vert d_t)$，$d_t$ 为人类裁决；要求任意执行动作可追溯到规范证书与审查来源。召回：给定违规规范 $\nu$，沿依赖图 $\nu\to\psi$ 的感知谓词 $\to f_{scene}$ 版本 $\to$ 技能契约 求可达集 $Recall(\nu)$，一次性吊销/冻结相关技能（与第 40 轮契约热更新同构）。

**定义 31（伦理课程赤字）**：$D_{eth}(\tau)=\sum_j v_j\cdot\max(0,1-m_j(\tau)/c_j)$，$m_j\in\{\text{predicate\_recall},R_{eth},\text{escalation\_rate},\text{audit\_coverage}\}$；近失事件（$0<R_{eth}\le\varepsilon_{eth}$ 或人类否决）作为高权重复现样本注入 IP-50，伦理审查的「判例」由此沉淀为课程。

## 2. 三大产出设计

### 2.1 IP-51 SCENE-GROUNDED-NORM-ATLAS（场景接地规范图谱）
1. 类型化场景图：VLM + 点云 + 多目标跟踪融合，输出对象/关系/区域/主体角色，并传播不确定性。
2. 校准解释集：保形预测给出 $\hat G_\alpha$，ACI 在线校正覆盖；对安全关键谓词（人/儿童/私有区/同意状态）采用**非对称代价**——宁可多报，召回优先。
3. 规范接地编译器：把审查模板（法规条款/内部政策/自然语言）编译为 $\sigma,\psi$ 的 MITL 模板，人工确认后入库；每条规范携带 provenance、版本与失效期。
4. 目的绑定感知：每个感知输出带 purpose tag；信息披露受用途格与最小化约束，原始可识别数据不出 L1，只向 L2/L3 暴露规范所需的抽象。

### 2.2 IP-52 NORM-CERTIFIED-SHIELD（规范盾 × 双证书）
1. 规范盾：在动作块解码处做约束投影（QP / 束搜索 / 分类器引导），运行期执行 MITL 检查；不可行即 escalate。
2. 非对称风险预算：$R_{eth}$ 取最坏情形或 CVaR；安全关键谓词的假阴性权重远高于假阳性。
3. 双证书：$CertBundle=(CertRobust,CertNorm)$，执行前要求 `ValidRegion ∩ NormRegion ≠ ∅`；冲突时规范优先（可做 > 能做）。
4. 与流匹配耦合：速度场条件增补规范上下文嵌入 $n=embed(A(G))$；盾作用于采样后的动作块，违规则在引导下有限步重采样，保持第 40 轮 $N^*$ 认证预算不被破坏。

### 2.3 IP-53 ETHICS-REVIEW-LOOP（伦理审查闭环）
1. 结构化审查模板 + 边界标注：每条规范标注 可机检/人类保留、证据要求、失效期、负责方。
2. 运行期审计链：动作—证据—解释集—证书—人类裁决全链哈希，支持事后取证与对账。
3. 升级与召回：escalate 路由到人工；违规/近失触发 $Recall(\nu)$ 并冻结相关契约，回归通过后解冻。
4. 判例课程：近失与人类否决进入 IP-50 第三轴；证书定期再审查（expiry 强制重颁）。

## 5. 本轮最大风险

**一句话**：最大风险是「伦理洗白/规范性幻觉」——证书只能覆盖可编纂的 $A_{cert}$，若场景理解在安全关键谓词上漏检（把儿童、私有区或同意状态判错），系统会以「已认证合规」的自信做出真实世界不道德的行为，且认证本身会给 $A_{hum}$ 部分带来虚假安全感；因此 E73（安全关键谓词高召回）与 E76（边界与红队）必须作为第一守门实验。

```
    G_hat = fuse_typed_graph(vlm(obs), pcd, tracker)      # O,R,Z,Ag
```

### IP-52 规范盾与双证书（伪代码）
```
def worst_viol(pi, G_set, A_cert):
    return max(sum_viol(pi, g, A_cert) for g in G_set)     # R_eth

def norm_shield(pi, G_set, A_cert, eps_eth):
    if worst_viol(pi, G_set, A_cert) <= eps_eth:
        return pi
    pi_star = project_to_safe(pi, lambda p: worst_viol(p, G_set, A_cert) <= eps_eth)
    return pi_star if pi_star is not None else ESCALATE(cost=c_esc)

def joint_gate(cert_robust, cert_norm):
    if not (cert_robust.valid and cert_norm.valid): return HALT
    region = cert_robust.ValidRegion & cert_norm.NormRegion
    return route(region) if region.nonempty() else HALT   # 规范优先于任务成功
```

```
    for skill in recall_dependency_graph(nu_violated):     # ν→谓词→f_scene→契约
        registry.revoke(skill)                             # 召回：冻结相关契约
    curriculum.inject_near_miss(nu_violated)               # IP-50 第三轴
    schedule_review(nu_violated)                           # 强制重审并更新 expiry
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 正确性保证 |
|---|---|---|
| 场景图融合 | O(N log N + E) | 类型化图 + 不确定性传播 |
| 保形解释集 / ACI | O(\|D_cal\|) 摊销，在线 O(1) | **定理**：P(G*∈Ĝ_α)≥1−α，ACI 维持漂移下覆盖 |
| 最坏违规 R_eth | O(\|Ĝ_α\|·\|A_cert\|·\|π\|)，束剪枝后部署级 | 最坏解释上界，安全关键假阴性权重最高 |
| 规范盾投影 | O(B·L) 束搜索 / 退化 QP | 可行则合规；不可行必 escalate（不静默放行） |
| 双证书路由 | O(\|V\|+\|E\|) | ValidRegion ∩ NormRegion 为空即熔断 |
| 审计链 | O(1)/动作，哈希追加 | 篡改可检出（哈希链），动作可追溯 |
| 召回 | O(\|V\|+\|E\|) BFS | 依赖图可达集一次吊销 |
| 组合规范 | O(\|V\|+\|E\|) | 道义类型检查 + 冲突触发升级 |

**定理（规范盾的条件可靠性，复述）**：在保形覆盖、谓词可测且时域有界、盾按定义 29 接受 $\pi^\dagger$ 三个前提下，$P(\pi^\dagger\ \text{违反}\ A_{cert})\le \alpha+\delta_{aci}$。该保证**仅覆盖 $A_{cert}$**；$A_{hum}$ 由升级机制与审计链兜底，不作形式化承诺。

## 4. 实验设计（E73-E78，硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E73 规范谓词接地 | 安全关键谓词召回/精确率（人/儿童/私有区/同意） | 召回≥99%，精确率≥90% |
| E74 解释集覆盖 | 实证覆盖 vs 名义 1−α（含光照/遮挡漂移） | 覆盖≥1−α−2%，平均集合规模≤K |
| E75 规范盾有效性 | 已编纂规范违规率 vs 无盾；任务成功率下降 | 违规<0.5%，成功率下降≤10% |
| E76 审查边界 | 人类保留案例正确升级率；红队未编纂规范检出 | 升级召回≥95%；伦理洗白 0 容忍 |
| E77 审计链 | 可追溯率、篡改检出、时延 | 100%/100%，开销<5ms |
| E78 端到端 + 伦理课程 | 部署期未编纂违规事件；近失/千任务 | 0；较固定课程下降≥40% |

失败即回退：E73/E75 不达标 → 回退 v17 + 静态许可清单 + 敏感区域远程遥操作，审计链转离线合规工具；E76 不达标则**禁止无人值守部署**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 伦理洗白：只认证可编纂子集，制造虚假安全感 | 高 | 证书自报边界 ∂A；A_hum 强制升级；E76 红队守门 |
| 场景关键谓词漏检（儿童/私有区/同意） | 高 | 非对称代价 + 高召回阈值 + 保形最坏情形；E73 第一守门 |
| 最坏解释集过保守 → 规范盾过度阻断/瘫痪 | 高 | ε_eth 风险预算 + escalate 作为合法零违规动作 + 集合剪枝；E74/E75 联合守门 |
| 保形覆盖在非平稳分布下失效 | 中 | ACI 在线校正 + 覆盖监控告警 + 定期重校准 |
| 规范冲突（O 与 F 同时适用） | 中 | 道义类型检查 + 冲突触发升级，不自动取舍 |
| 场景理解双用途/隐私越界 | 中 | 目的绑定 + 数据最小化 + 原始数据不出 L1 + 披露审计 |
| 审计链开销与存储爆炸 | 低 | 哈希链 + 分层归档 + 仅存证据摘要与指针 |

## 6. 本轮最大风险

**一句话**：最大风险是「伦理洗白/规范性幻觉」——证书只能覆盖可编纂的 $A_{cert}$，若场景理解在安全关键谓词上漏检，系统会以「已认证合规」的自信做出真实世界不道德的行为，并给 $A_{hum}$ 部分带来虚假安全感；故 E73（安全关键谓词高召回）与 E76（边界与红队）是本轮成败判据。
