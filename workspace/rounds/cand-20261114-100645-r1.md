# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「产学研合作」×「安全性」）

> R69 给闭环装上了一张嘴（看/问/触）和一份自签的证书 J_FLUID。但它有一个结构性盲点：**J_FLUID 是「自证」的**——由系统自己采信自己的模态校准、自己声明自己的安全，而且**不分地域**：它说「安全」，却从不说「在何种运行域、基于谁的证据、证据还有多新」。R69 自陈的最大风险（模态分布不可信 → 自信地问错）本质上不只是算法问题，而是一个**证据治理**问题：在真实世界里，没有任何单一机构有资格、也没有能力独自为具身系统签发安全声明。产业界握着部署遥测与真实故障，学术界握有形式化界与对抗生成，研究机构握着第三方基准与标定——三方**各自只看见一角，且互不完全信任**。
>
> 本轮两个灵感正好切开这个盲点：
> - **产学研合作** → 安全证据天然是**分布式、异构、不可直接合并**的；证书不该是一个标量，而应是一个**带运行域、带证据承诺、带签名法定人数、带溯源与撤销**的证明对象；
> - **安全性** → 安全不是全局真值，而是**有辖区（jurisdiction）的**：只在「被证据真正覆盖的运行域」内成立；域外不是「次安全」，而是「未认证」。
>
> 核心命题：**把 R69 的自签证书 J_FLUID 升级为「产学研联合签发、运行域受限、可组合、可撤销、随漂移衰减」的运行时可携带证明（proof-carrying certificate）；闭环只能在被联合证据覆盖的安全包络内行动，域外/过期/被撤销一律退化为 R68 最保守，绝不用「别处安全」冒充「此处安全」。** 命名 **PACT-RAS**（Proof-carrying, Attested, Composable Trust for Risk-Adaptive Systems）——产学研之间的一纸「安全契约」，由系统在运行中随身携带、逐指令校验。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**谁为这个答案担保、这份担保能走多远、何时失效**」——安全不是一个标量，而是一份有辖区、有期限、有署名、可被吊销的证明。

## 0. 直觉与动机

**灵感 1（产学研合作 → 证据是分布式的，证书不能自证）**
直觉：R69 的 J_FLUID 像一张自己给自己开的健康证明。可部署现场真正的问题是：这个模态校准是谁测的？在这片地面上测的吗？用了哪版模型？三个月前的结论今天还算数吗？产业界的现场遥测、学术界的对抗样本、研究机构的第三方基准，谁都不能单独回答。于是「证书」必须从「一个布尔 + 一堆指标」变成**一份可被多方独立核验的结构化声明**：它声明什么（claim）、在哪个运行域成立（domain）、凭什么（evidence commitment）、谁签名（quorum）、何时作废（epoch/expiry）、出问题找谁（provenance）。这也是产学研合作真正能落到技术上的形态：不是联合发论文，而是**联合签发一份机器可在运行时校验的安全证明**。

**灵感 2（安全性 → 安全有辖区，域外不是「更不安全」而是「未认证」）**
直觉：R68/R69 把安全当成一个全局标量：λ 越小越安全。但现实中的安全是**分区**的：实验室桌面上 99.9% 安全的策略，搬到工厂强反光地面、商场人流、雨雪户外，可能连 60% 都不到；没有哪份证据能跨越它没测过的域。所以正确的语义不是「整体安全度 = 0.97」，而是「在域 D₁ 内风险 ≤ ε₁（有证），在 D₂ 内 ≤ ε₂（有证），在 D₁∪D₂ 之外**没有证**」。域外必须被当成「未认证」而触发降级——这和 R69 的「不确定就收紧」在形式上相似，但在语义上更强：不是「我不确定」，而是「没有人对此负责」。

**灵感 3（合作 → 组合必须区分「与」和「或」，否则安全包络会被交集吃掉）**
直觉：如果每份证书都只能在其域内成立，那么把 n 份证书「同时要求成立」会让可用域收缩为交集，越合作、域越小——荒谬。正确的组合有两种：**合取**（同一动作同时依赖多条声明，风险按并集界相加）与**分片**（运行域被切成互斥小块，每块单独认证，风险取最大）。产学研合作要交付的，是一张**无缝铺满目标运行域的域拼图（tiling）**，而不是一叠互相缩窄的证书。铺不满的地方就是「无证区」，系统必须知道那里不能去。

**灵感 4（合作的反面 → 认知单一栽培，联合签字可能是同一个错误盖了三个章）**
直觉：三方都用同一个预训练 VLA 底座、同一个仿真器、同一批开源数据，那么它们的「独立验证」根本不独立；一个共同的缺陷会让三份证书同时通过。这时法定人数 k-of-n 是**幻觉**。安全论证的强度不取决于签名的数量，而取决于**证据来源的有效独立性**。这是本轮最锋利的一刀：**产学研合作最常见的失败不是没人签字，而是所有人签的是同一份偏见**。所以必须显式度量并惩罚证据相关性。

**灵感 5（安全性是时间的函数 → 证书会腐烂，需要漂移时钟与分级放行）**
直觉：昨天的证书不能证明今天的世界。R68 已经能估标定漂移、R69 已经能估行为似然异常——这些正好可以当作**证书的腐烂速率**：证据余量除以漂移速率，就是这张证书的剩余寿命。超过寿命就必须用新证据刷新（产业提供新遥测摘要、学界重算界、研究机构重跑基准），刷不出来就收缩辖区。于是「产学研合作」不是一次性签约，而是一个**以漂移为节拍的持续再认证循环**；部署也因此可以做成**分级放行**：先在最窄、证据最厚的域里开最低自主等级，随覆盖扩大逐级解锁，而不是一次性全开。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（PACT-RAS 总览）** PACT-RAS = (POM, DAT, CMP, PEL, QIS, BCP, TRL, FDC, CLG, PLB, PVA)，分别对应证书对象模型、域代数、组合引擎、隐私证据账本、法定人数/独立性评分、拜占庭签发、透明与撤销日志、新鲜度时钟、能力许可门、溯源归责、参与式审计。四不变式：
(i) **实时零学习写操作**（继承 R68 定义 276-i；证书校验只读）；
(ii) **域内行动律**：任何被执行的自主动作必须落在当前有效证书的覆盖域内，域外/过期/被撤销 ⇒ 回到 R68 最保守（λ_floor(U_ale+U_epi)，禁用交互）；
(iii) **证据不合并律**：来自不同主体的证据不得在未经独立性检验前被当作独立样本合并；相关性高时按有效样本数折算；
(iv) **可追溯律**：每个动作绑定其依赖的证书 ID 与日志根，撤销后仍可回溯定责。

**定义 311（安全声明与证书对象）** 运行域 D ⊆ 𝒳 是可描述的上下文子集（地形/光照/人流/语言分布/传感器健康/任务族）。安全声明 φ = (κ, H, ε, A) 表示「在假设 A 下，能力 κ 在时域 H 内的失效概率 ≤ ε」。证书 C = (id, φ, D, c_E, P_C, k, τ, T, h_sw, σ)，其中 c_E 为证据承诺（定义 314），P_C 为签发主体集，k 为阈值，τ 为签发时刻，T 为有效期，h_sw 为绑定的软件/权重哈希，σ 为阈值签名。

**定义 312（域代数与铺砌）** 域支持 ∩、∪、⊆、∂D（边界）与 dist(x,∂D)（边界裕度）。一组域 {D_i} 构成目标域 D 的 **ε-铺砌**，若 ∪D_i ⊇ D、内部两两不交（允许边界带 ℬ 重叠）、且 ∀i 风险界 ε_i ≤ ε_budget。覆盖裕度 m(x) = min_i dist(x, ∂D_i)/r_ref，r_ref 为归一化尺度；m<0 表示 x 落在所有证书域之外。

**定义 313（组合规则）** 
- **合取（AND）**：动作同时依赖 C₁…C_n ⇒ D_S = ∩D_i，ε_S = Σε_i + ε_assume（并集界）；用于同一决策的多重约束（碰撞 + 交互 + 语言）。
- **分片（OR / Tiling）**：x 落入互斥单元 D_i ⇒ ε_S = max_i ε_i + ε_boundary（在无证缝隙处 ε=∞）；用于跨场景的能力覆盖。
组合仅在「假设可放电（discharged）」时成立：C₁ 的保证须能推出 C₂ 的前提（assume-guarantee），否则 ε_assume 取未放电假设的上界。二者缺一不可：**合取保正确，分片保覆盖**。

**定义 314（隐私保全证据承诺）** 原始数据不出主体域：主体 p 发布 c_E = (MerkleRoot(证据集), 聚合统计量 \hatθ_p 及其差分隐私噪声, 覆盖抽样方案)。验证者通过（可选披露 + 随机抽检挑战 + 区间证明）核验 \hatθ_p 落在承诺内；不要求零知识证明完整的经验风险界（这是本轮明确的工程妥协，见第 6 节）。

**定义 315（法定人数与有效独立性）** 每位签发者在共享挑战集上给出对同一真值的误差指示 e_i∈{0,1}；定义主体间误差平均成对相关 ρ̄，设计效应 DE = 1+(n−1)ρ̄，**有效独立源数 n_eff = n/DE**。证书有效当且仅当 k ≤ n_eff，且签发者的模型血统/仿真器/数据源满足多样性约束（血统图最大公共子图规模 ≤ s_max）。ρ̄→1 时 n_eff→1：再多签名也只算一个。

**定义 316（拜占庭签发）** n 个主体中至多 f 个恶意/被攻陷；证书需 k ≥ 2f+1 个独立主体的阈值签名，且签名须绑定 h_sw（拒绝权重替换/回滚）、epoch（单调）、nonce（抗重放）。恶意主体可拒签/伪造/串谋，但不能在无 k 个有效独立签名时产出一张被网络接受的证书。

**定义 317（透明日志与撤销）** 证书与撤销均追加到只增（append-only）Merkle 日志 ℒ；撤销记录 r = (id, reason, epoch, σ)。撤销沿派生 DAG 做**污点传播**：C 被撤销 ⇒ 所有依赖 C 的派生证书与已放行许可证失效。撤销不可撤回（只可用新 epoch 重新签发）；客户端用包含证明校验「某证书自 epoch e 起未被撤销」。

**定义 318（新鲜度与漂移时钟）** 证书的认证余量 s_C = ε_C − \hat{risk}_C（证据上置信界与声明界之差）；漂移速率 \hat{d} 由 R68 标定漂移与 R69 FMA 异常率联合估计，安全缓冲 β>0。**有效寿命** T_C = s_C/(\hat{d}+β)，实际有效期取 min(T, T_C)。剩余寿命 R_C(t) = τ+T_C−t；R_C<0 ⇒ 视为过期。刷新即用新证据重算 s_C 与 T_C。

**定义 319（能力许可与分级放行）** 能力集 𝒦（交互 / 中速 / 高速 / 自主导航 / 力控接触…）。许可 L_κ(x,t) = 1 当且仅当存在有效证书集 S，其组合可推出 φ_κ、x∈覆盖域、且组合裕度 >0。自主等级 α(x,t) = max{α : 所有级别 ≤α 的能力均被许可}；最高等级受最弱一环约束。放行阶梯：从 α_min 起，随（覆盖面积 × 新鲜度）增长逐级解锁；任一证书失效则**单调回落**，不允许跳升。

**定义 320（在线覆盖监视器）** 每控制周期估计 x_t 与 m(x_t)；若 m<0（越界）或 R_C<0（过期）或 revoked（撤销）或 h_sw 不匹配，触发 **证书空洞（certificate gap）**：禁用越界能力、λ 取 R68 最保守、交互动作一律否决，并异步请求再认证。

**定义 321（溯源与事后归责）** 动作 a_t 的审计记录绑定 cert_ids(a_t)、日志根 root_t、覆盖率与新鲜度快照。事后若某证书被撤销，可精确回答「哪些已执行动作曾依赖它」——这是产学研责任划分的机器可读基础，也防止「出事后没人认账」。

**定义 322（PACT 威胁模型 ℰ_PACT）** ℰ_PACT = ℰ_FLUID × ℰ_byz × ℰ_supply × ℰ_stale，其中 ℰ_byz 为恶意签发/拒签/串谋，ℰ_supply 为底座模型/仿真器/数据供应链污染与版本回滚，ℰ_stale 为撤销抑制、日志分叉、过期证书重放。

**定义 323（证书 J_PACT）** J_PACT = (J_FLUID, cert_ids, coverage_margin, n_eff, k, freshness_R, log_root, epoch, pact_ver)。Valid ⇔ Valid(J_FLUID) ∧ 覆盖裕度>0 ∧ k≤n_eff ∧ 全部证书未过期/未撤销 ∧ 日志包含证明通过。

**定义 324（PACT-VQAuditor 与再认证循环）** 审计对象从「单次交互」上升到「跨主体的证据链」：抽样重放、跨机构红队、相关性审计、撤销时效审计。结论回灌三处：QIS 的相关性先验、FDC 的漂移速率、CLG 的放行阶梯。

## 3. 推导

**引理 19（组合可靠性）** 设证书 C_i 在 D_i 上给出 P(fail_i) ≤ ε_i，且各 fail_i 的联合失效被其并集覆盖。则合取组合在 ∩D_i 上 P(∨ fail_i) ≤ Σ ε_i；分片组合在 ε-铺砌上 P(fail) ≤ max_i ε_i + ε_boundary，其中 ε_boundary 由边界带 ℬ 的宽度与域内漂移率给出。要点：**合取让风险相加、域相交；分片让风险取最大、域相并**——只有分片能扩大可用包络，合取只会缩小它。

**引理 20（有效法定人数 / 认知单一栽培）** 设 n 个签发者的误差指示在共享挑战集上具有平均成对相关 ρ̄，则其均值的方差相对独立假设膨胀 DE = 1+(n−1)ρ̄ 倍，等价有效独立源数 n_eff = n/DE。若按独立假设计算的 k-of-n 置信水平为 1−δ，则真实置信水平不低于按 n_eff 重算者；当 ρ̄=1，n_eff=1，任何 k 都无法提供独立性。系：**证书的强度上界由证据多样性决定，而不是签名数量**；学界与产业若共用同一底座，其两票应折成一票。

**引理 21（漂移下的新鲜度）** 若真实风险以 \hat{d} 为界增长、认证余量为 s_C，则证书在 T_C=s_C/(\hat{d}+β) 后失效；在 [τ, τ+T_C] 内因漂移而误判安全的概率 ≤ exp(−2β²T_C)（Hoeffding 型）。系：刷新的必要频率 ∝ 漂移速率；慢变故障（R69 的 FMA 通道）会推高 \hat{d}，从而**自动缩短所有证书寿命**——R69 最担心的「被标定吸收的缓变故障」在这里第一次有了组织层面的后果：它会让整个安全证明提前过期。

**定理 18（PACT 对 FLUID-RAS 的安全侧严格包含）** 由于许可门只做**动作剔除**、不新增任何动作，且域外/过期/撤销时精确退化为 R68 最保守路径，故对任意状态 PACT 的瞬时风险 ≤ FLUID-RAS；当全部证书覆盖、新鲜、未被撤销且 n_eff≥k 时，许可门恒为真，PACT 与 FLUID-RAS **逐指令相同**。因此 PACT 不是又一层的替代，而是给 R69 加了一个**可被外部核验的包络**：安全侧不让步，代价只体现在域外能力的可用性上。

**定理 19（撤销完备性与有界陈旧）** 在同步撤销 gossip、Merkle 日志只增、epoch 单调、客户端校验包含证明的前提下，任何在 epoch e 之后提交的动作都不会许可证在 e 之前已被撤销的证书；在 gossip 延迟 Δ 的窗口内提交的动作可能短暂陈旧，但可被日志根回溯标记并追责。⇒ 不存在「永久幽灵许可」。

**推论（词典序安全）** 安全论证的剩余风险 = 证据相关性风险 + 域外渗漏风险 + 撤销延迟风险 + 组合假设未放电风险；其中相关性风险**不随签名数量下降**，是产学研合作架构的支配性风险项。

## 6. 本轮最大风险

**一句话**：PACT-RAS 把安全从「自我声明」升级为「联合证明」，但联合证明的强度被**证据相关性**锁死——若产学研三方共用同一底座模型、同一仿真器、同一批数据，n_eff 会坍缩到 1，一份带瑕疵的证书就能被「三票一致」盖章通过；此时系统拥有一份签名完备、日志透明、形式漂亮的安全证明，却只是**同一个偏见的三份复印件**——**证书剧场（certificate theater）比没有证书更危险，因为它把「未验证」伪装成了「已认证」。**

**次级风险与缓解**：
1. **域设计作弊**（把域切得极窄以获得低风险界，实际不可用）→ 要求覆盖面积/可用性与风险界同时报告，设最小可用域约束；
2. **撤销抑制/日志分叉** → 只增 Merkle 日志 + 阈值撤销 + epoch 单调 + 客户端包含证明（定义 316–317）；
3. **隐私-效用矛盾**（DP 噪声把界放宽到无意义）→ 分层披露 + 抽检挑战 + 以区间证明替代点估计；
4. **刷新负担导致「僵尸证书」** → 新鲜度时钟自动降级，宁可收缩辖区也不续用旧证；
5. **域边界抖动**（跨域来回切换引发控制抖动）→ 边界带 ℬ 迟滞 + 取相邻域的合取保守值。

## 4. 推导

**引理 19（组合可靠性）** 合取：∩D_i 上 P(∨fail_i) ≤ Σε_i；分片：ε-铺砌上 P(fail) ≤ max ε_i + ε_boundary。要点：合取使风险相加、域相交；分片使风险取最大、域相并——**只有分片扩大包络，合取只会缩小它**。

**引理 20（有效法定人数）** 平均成对相关 ρ̄ 使误差均值方差膨胀 DE=1+(n−1)ρ̄，有效独立源 n_eff=n/DE。ρ̄=1 ⇒ n_eff=1，任何 k 都不提供独立性。系：**证书强度由证据多样性决定，而非签名数量**。

**引理 21（漂移新鲜度）** 余量 s_C、漂移界 \hat d、缓冲 β ⇒ 寿命 T_C=s_C/(\hat d+β)；窗口内误判安全概率 ≤ exp(−2β²T_C)。系：R69 的 FMA 缓变故障会推高 \hat d，自动缩短所有证书寿命。

**定理 18（PACT 对 FLUID-RAS 严格包含）** 许可门只剔除动作、不新增动作；域外/过期/撤销精确退化为 R68 最保守 ⇒ 任意状态风险 ≤ FLUID-RAS；全域有证、新鲜、未撤销且 n_eff≥k 时与 FLUID-RAS 逐指令相同。

**定理 19（撤销完备与有界陈旧）** 只增 Merkle 日志 + 单调 epoch + 包含证明 ⇒ epoch e 后提交的动作不许可 e 前已撤销证书；gossip 延迟 Δ 内可短暂陈旧但可回溯定责，无永久幽灵许可。

**推论（词典序安全）** 剩余风险 = 证据相关性 + 域外渗漏 + 撤销延迟 + 组合假设未放电；其中相关性风险不随签名数量下降，是支配项。

## 5. 复杂度分析

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| 证书验签（2f+1） | 离线，<5ms | O(n) | 定义 316 |
| 覆盖/许可门（\|S\|≤8） | <0.05ms | O(\|S\|) | 定义 319–320 |
| 组合引擎（AND/OR） | <0.02ms | O(\|S\|) | 引理 19 |
| 新鲜度时钟 | <0.01ms | O(1) | 引理 21 |
| Merkle 包含证明 | O(log N)，异步 | O(log N) | 定义 317 |

## 7. 本轮最大风险

**一句话**：PACT-RAS 把安全从「自我声明」升级为「联合证明」，但联合证明的强度被**证据相关性**锁死——若产学研三方共用同一底座模型、同一仿真器、同一批数据，n_eff 会坍缩到 1，一份带瑕疵的证书就能被「三票一致」盖章通过；此时系统拥有一份签名完备、日志透明、形式漂亮的安全证明，却只是**同一个偏见的三份复印件**——**证书剧场（certificate theater）比没有证书更危险，因为它把「未验证」伪装成了「已认证」。**

**次级风险与缓解**：域设计作弊（同时报告覆盖面积与风险界，设最小可用域）；撤销抑制/日志分叉（只增 Merkle + 阈值撤销 + epoch 单调 + 包含证明）；隐私-效用矛盾（分层披露 + 抽检 + 区间证明）；僵尸证书（新鲜度时钟自动降级，宁可收缩辖区）；域边界抖动（边界带迟滞 + 相邻域合取保守值）。
