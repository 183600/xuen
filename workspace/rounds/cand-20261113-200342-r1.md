# 第 69 轮（承接第 68 轮「CALM-RAS 自标定风险自适应闭环」IP-243~252；新灵感循环第 1 轮；本轮灵感：「可用性评估」×「事件相机」）

> 第 68 轮把「标定」升为一等公民，换来一个漂亮却危险的信条：测量不可信时，一切都收紧。其自陈最大风险是「缓变故障被标定吸收」，而所有次级风险其实指向同一个更深的盲点：**系统只优化「机器是否违规」，从不优化「人是否还能正确地使用这台机器」**。当 U 升高，`λ_floor(U)` 把系统推向 0.8→1.0 的僵硬保守；一个不违规却让人无法完成任务的系统，会被人用最危险的方式「修复」——绕过、关掉、抢管。安全系统的头号失效模式不是突破包络，而是**被用户废弃**。
>
> 本轮两个灵感词恰好是一对：**可用性评估**给出「人是否还能用好」的度量与外环目标；**事件相机**给出微秒级、高动态、近似无纹理的观测底座，让可用性从离线问卷变成在线可观测量。合流后的核心命题：
>
> **把「可用性」升格为与风险并列的一等安全变量；用事件相机的跨参数化通道补上 CALM 的反吸收盲区；用双边策略替掉「一味收紧」——安全与可用不可兼得时，不是冻结，而是最优接管。EVA-RAS（Event-Vision, Usability-Aware RAS）。**
>
> 定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**当测量不准、机器被迫保守时，人还愿意、且能够安全地接住它吗**」。

## 0. 直觉与动机

**灵感 1（事件相机 → 一个参数化根本不同的独立证人）**
直觉：事件相机不拍「图像」，只输出「对数亮度变化超过阈值」的异步事件 `e_k=(x,y,t,p)`：时间戳微秒级、动态范围 120–140 dB、无运动模糊、稀疏且几乎不含纹理身份。它测的是**变化与时间**，不是**绝对亮度与曝光**。工程含义极强：帧相机的标定子空间含 `δ_exposure`，事件相机的标定子空间里**根本没有曝光维**；同理，「帧率/处理延迟增长」在帧通道里可被误当作物理时间同步漂移标定掉，而事件相机的微秒时间戳一眼拆穿。R68 的反吸收防线只有「带宽」一道；事件相机是第二道，且是**参数化正交**的一道。

**灵感 2（可用性评估 → 被忽视的最后一个安全变量）**
直觉：经典可用性评估（SUS、NASA-TLX、think-aloud、认知走查）衡量 effectiveness / efficiency / satisfaction；在人机共驾安全闭环里必须加第四维——**信任校准（trust calibration）**。人不是被动接受者：系统的每次保守收缩都是一个「信号」，人据此调整依赖、警惕与接管。过度保守 → 信任与依赖崩塌 → 绕过/关闭；过度激进 → 过度信任 → 闯入危险区。两种都是安全失效。**可用性不是体验指标，而是控制回路里的反馈量。**

**灵感 3（合流 → 事件流天然就是可用性观测器）**
直觉：可用性的关键量几乎都是**快时间尺度的人类行为**：操作启动时延、犹豫/停顿、手部微反转、急停伸手、接近-回避。这些用 30 fps 帧相机测不准（运动模糊 + 33ms 量化），用事件相机却是原生信号（μs、无模糊）；且事件流稀疏、无纹理，天然隐私友好——可部署进不能录脸的产线与医疗场景。于是「可用性评估」第一次能**在线、连续、隐私安全**地进入安全闭环，而非事后问卷。

**灵感 4（对症下药 R68 的两个真问题）**
- **缓变故障被吸收**：R68 只有「速率限制」防吸收，带宽内的慢故障天然被吃。引入事件通道后定义吸收残差 `Λ = r_e − J_e J_f⁺ r_f`；当故障方向落在帧标定的零空间、却在事件观测里留分量时，`E[Λ] ≠ 0`——**联合观测矩阵的秩提高了，慢故障重新可辨识**（引理 16）。这不是「多一个传感器」，而是「补一个秩」。
- **一味收紧的冻结失败**：`λ_floor(U)` 单调把 λ 推向 1。在人机共驾中，λ→1 使任务成功率崩塌、接管概率 `p_ov→1`，而接管风险 `R_ov` 常高于「适度保守的自主」风险 `R_auto`。于是总风险随保守度**先降后升**，存在内点最优 λ*（引理 17）。**正确动作不是无限收紧，而是在 U 越过 U* 时有序接管。**

**灵感 5（EVA-RAS 七组件）**
1. **EDM Event-Driven Metrology**：事件微秒时间基准 + 事件标定子空间 `C_e`，把 `r_sync` 升级到 μs，并作为与帧标定参数化正交的第二观测行；
2. **UOX Usability Observation eXtractor**：从事件流抽取 `u_t=(latency, hesitation, override-onset, min-distance, micro-reversal)`，隐私友好、μs 级；
3. **USB Usability-Safety Boundary**：定义可行域与 `λ_usable(U)`，把「安全要求的最保守」和「可用允许的最保守」摆到同一张 Pareto 图上；
4. **OHC Optimal Handoff Controller**：双边策略 `λ = min(λ_safety, λ_usable)`；二者不可同时满足时，按代价比较在 `U*` 处从「自主保守」切到「透明预备接管」，绝不做无声冻结；
5. **CRD Cross-parameterization Residual Disentangler**：用 `Λ` 统计量把「慢故障」从「慢漂移」里抠出来，专治 R68 原罪；
6. **TIL Trust-In-the-Loop**：信任动力学 `T_t` 在线估计与校准，把 `|T−T*|` 作为可用性损失项；
7. **EBA Event-Based Auditor**：用事件-帧语义差审计「交互崩溃」与被吸收故障；RAS-WM† / CALM† 继承核全保留。

一句话：R68 的失效是「标定越强、慢故障越隐形」；R69 的回答是「**再加一个不看曝光、只看时间与变化的证人；并且别把保守当安全，把能否被正确使用当安全**」。

## 1. 形式化定义（增量：定义 293–310）

**定义 293（EVA-RAS 总览）** `EVA-RAS = (EDM, UOX, USB, OHC, CRD, TIL, EBA, RAS-WM†, CALM†)`。继承 R68 三条不变式，新增三条：
(iv) **可用性非负**：`λ_applied ≤ λ_usable(U)`；若 `λ_safety > λ_usable`（安全与可用不可兼得）则必须进入 handoff 模式，**禁止静默冻结**；
(v) **事件通道参数化独立**：`C_e` 不含曝光与绝对光度；帧残差与事件残差在 CRD 之前**不得融合**（否则共模污染）；
(vi) **接管可解释**：每次 handoff 必须在 ≤ τ_warn 内输出「为什么、接下来谁负责、何时交还」三元组，供人校准信任。

**定义 294（事件观测模型与标定子空间）** 事件流 `E_{t0:t1}={e_k}`，`e_k=(x_k,y_k,t_k,p_k)`，触发条件
`|log I_p(t_k) − log I_p(t_k−Δ)| ≥ C_p`，`t_k` 精度 ~1 μs。
事件标定参数 `c^e = (Δt_sync^e, ξ^e, C_p, τ_ref, hotpix) ∈ C_e`，其中 `ξ^e` 为事件镜头畸变、`C_p` 为逐像素对比阈值、`τ_ref` 为不应期、`hotpix` 为热像素掩码。
**参数化不相交**：`C_e ∩ span{δ_exposure, δ_emo} = ∅`，即 `∂r_e/∂δ_exposure = 0`。联合标定状态 `c_t=(c^f_t, c^e_t)`，两子空间只在共享物理量（外参、时间）上相交。

**定义 295（跨模态联合观测与吸收残差）** 在工作点线性化：
`r_f = J_f δc + B_f f + n_f`，`r_e = J_e δc + B_e f + n_e`，
其中 `δc` 为标定误差、`f` 为真实故障。帧单独可吸收故障集 `A_f = {f : B_f f ∈ col(J_f)}`；联合可吸收集 `A_fe = {f : [B_f;B_e] f ∈ col([J_f;J_e])}`。定义**吸收残差**
`Λ = r_e − J_e J_f⁺ r_f = M_abs f + n_Λ`，`M_abs = B_e − J_e J_f⁺ B_f`。
若 `rank(M_abs|_F) = dim(F)`，则故障子空间 `F` 在联合观测下可辨识（引理 16）。

**定义 296（可用性观测向量）** 由事件 ROI 逐帧（1ms 累积窗）计算
`u_t = (L_t, H_t, O_t, D_t, R_t^rev, Ė_t)`：
- `L_t`：操作启动时延 = 机器人响应时刻 − 事件检测到人手运动起始时刻；
- `H_t`：犹豫度 = 手部轨迹停顿数 + 反转数（事件流重构）；
- `O_t`：接管起始 = 急停/摇杆 ROI 的事件密度突增（μs 级定位）；
- `D_t`：人-机最小距离（事件立体/已知工作空间几何）；
- `R_t^rev`：微反转率（犹豫的连续量）；
- `Ė_t`：事件率（注意力/运动强度代理）。
隐私性：事件仅含边缘与时间，不含纹理，重建攻击下身份可辨识度 `AUC_privacy ≤ 0.6`（E293 验证）。

**定义 297（可用性泛函与可行域）** 对策略 π：
`Q(π) = E[1{success}] − c_I·E[interaction cost] − c_T·E[|T − T*|]`，
其中 `T* = R_actual` 为「应然的信任水平」（校准目标）。安全约束 `R_total(π) ≤ ε`。**可用性-安全边界（USB）** 为 `(R_total, Q)` 的 Pareto 前沿；**可用允许的最保守度**
`λ_usable(U) = max{ λ : Q(λ,U) ≥ Q_min }`。
语义：λ 越大越保守，任务成功率与效率越低，故 `λ_usable` 是可用性给出的**上界**。

**定义 298（信任动力学）** `T_{t+1} = clip(T_t + α(1{outcome_t good} − T_t) − β·1{λ_t > λ_ref} + γ·transp_t, 0, 1)`，
`transp_t` 为解释透明度。信任误差 `e_T = |T_t − T*_t|`；欠信任 → 绕行/停用风险，过信任 → 危险区闯入风险，二者都计入 `AIC-EVA` 的 `ℰ_use`。

**定义 299（双边风险控制）** 总风险
`R_total(λ,U) = (1−p_ov(λ,U))·R_auto(λ,U) + p_ov(λ,U)·R_ov(U)`，
其中 `p_ov` 随 λ 单调增（越僵越容易被接管/绕过），`R_auto` 随 λ 单调减，`R_ov` 为接管后的人为风险。R68 的 `λ_safety` 只保证 `R_auto`；实际策略
`λ_applied = min(λ_safety(U), λ_usable(U))`。若内力要求 `λ_safety > λ_usable`，则可行域为空，**转 handoff**。

**定义 300（最优接管控制器 OHC）** 两动作代价：
`J_auto = R_auto(λ_safety,U) + c_task(1−Q_auto(λ_safety,U))`；
`J_handoff = R_ov(U, τ_warn) + c_switch + c_task(1−Q_handoff(τ_warn))`。
选择 `handoff ⇔ J_handoff < J_auto`；切换阈值 `U* = sup{U : J_auto(U) ≤ J_handoff(U)}`。事件通道把意图起始检测提前 `Δδ = δ_f − δ_e`（可达 20–30ms），`R_ov` 随 `τ_warn` 单调降，故 `U*` 被推后、接管成功率上升（定理 17）。

**定义 301（UOX 提取器）** 冻结骨干（不参与在线学习写操作，遵守 R68 不变式 i）：事件 → 1ms 体素 → 稀疏卷积/SNN → `u_t`。仅保留事件级特征，不缓存原始事件（隐私预算 `ε_priv`，E293 审计）。

**定义 302（CRD 缓变故障统计量）** 在线对 `Λ_t` 做白化 CUSUM：
`S_t = max(0, S_{t−1} + Λ_t^T Σ_Λ^{-1} Λ_t − κ)`，当 `S_t > h` 判 `H_sensor^trans`（真实故障），并强制 `λ ≥ 0.8`、冻结 COF 对该方向的吸收。κ、h 由 `A_f \ A_fe` 上的一类/二类错误率标定。

**定义 303（EBA 事件审计器）** 异步重放 `(E, frame, action)` 三元组，检测三类事件：交互崩溃（`u_t` 越过可用性阈值）、被吸收故障（`Λ` 事后显著）、解释失真（`transp_t` 与真实 `λ` 不符）。结论回灌 AuditBuf 并进入 CAC 第 2 关。

**定义 304（干扰集 AIC-EVA）** `ℰ_EVA = ℰ_CALM × ℰ_use × ℰ_evt`；
`ℰ_use = {可用性指标被 Goodhart 操纵、个体/文化差异、信任误估、任务定义漂移}`；
`ℰ_evt = {事件率饱和、热像素/背景噪声、时钟失步、隐私重建攻击、HDR 过曝段}`。

**定义 305（J_EVA 证书）** `J_EVA = (J_CALM, event_cal_hash, usability_vec, trust_cal_err, handoff_verdict, Λ_max, eva_ver)`。
`Valid ⇔ Valid(J_CALM) ∧ AUC_privacy ≤ 0.6 ∧ trust_cal_err ≤ τ_T ∧`（自主模式下 `λ_applied ≤ λ_usable`）`∧`（handoff 模式下三元组已交付）。

**定义 306（管线）** 离线：帧+事件联合标定 → 冻结 UOX 预训练（人类行为数据集，无在线标签）→ 可用性基线（SUS/TLX/信任量表）→ USB 标定 → 部署。
在线：事件 → UOX（μs）→ USB/OHC（每 10ms）→ 与 CALM 的 `λ_safety` 取 min；CRD 影子流持续算 `Λ`；EBA 异步审计；CAC 五关保留，新增第 6 关「可用性回归」。

**定义 307（μs 时间基准升级）** 用事件时间戳重估 `Δt_sync`：事件-力峰对齐残差 `r_sync^e` 分辨率 ~10 μs，较帧法（~16ms 量化）提升 3 个量级，直接改进 R68 定义 279 的 `r_sync`。

**定义 308（HDR 可用性覆盖）** 事件通道在 1–10⁵ lux 范围内保持可用；当帧通道因过曝/欠曝饱和时，`σ_stat` 与 `p_ov` 的估计改用事件分支，避免「帧瞎了就当静止」的伪静态误判。

**定义 309（可用性评估协议，离线锚）** 外侧以标准可用性方法锚定在线指标：SUS、NASA-TLX、信任量表（Jian 等）、think-aloud、认知走查；在线 `Q` 与离线量表做收敛效度检验（`r ≥ 0.7`），否则 UOX 权重回滚。

**定义 310（可解释接管三元组）** `H_t = (reason ∈ {unusable, unreliable, unsafe}, owner ∈ {human, auto}, eta)`；接管前 `τ_warn` 内推送；`eta` 为预计交还时间。信任校准依赖此三元组的准确率（E297）。

```python
# IP-253 EDM：事件微秒时间基准 + 事件标定（参数化独立）
class EventDrivenMetrology:
    def __init__(self, d_ce=7):
        self.c_e = np.zeros(d_ce)          # Δt_sync^e, ξ^e, C_p, τ_ref, ...
        self.last_t = 0                    # μs
    def residual_sync(self, E, force_peak_t_us):
        # 事件-力峰对齐：分辨率 ~10μs，替代 R68 的帧级 r_sync
        t_event = self.first_deformation_event_us(E)
        return (t_event - force_peak_t_us) - self.c_e[0]
    def event_row(self, E, r_f):           # 定义295：与帧标定正交的第二观测行
        J_e = self.jacobian_event(E)       # 对共享外参/时间有列，对曝光恒为 0
        return J_e, B_e_project(E)


# IP-254 UOX：事件可用性观测（隐私友好、μs 级）
class UsabilityObservationExtractor:
    def __init__(self, frozen_backbone, roi):
        self.backbone, self.roi = frozen_backbone, roi
    def observe(self, E_window):           # 1ms 窗，冻结骨干，无在线写
        v = self.backbone.sparse_forward(E_window, self.roi)
        L = v.response_ts - v.human_onset_ts
        H = v.pauses + v.reversals
        O = v.estop_density_spike          # 接管起始，μs 定位
        D = v.min_human_robot_distance
        return np.array([L, H, O, D, v.micro_reversal_rate, v.event_rate])


# IP-255/256 USB + OHC：双边策略与最优接管
class UsabilitySafetyBoundary:
    def lam_usable(self, U, Q_curve):      # 可用性允许的最保守度（上界）
        return max(l for l, q in Q_curve.items() if q >= Q_MIN)

class OptimalHandoffController:
    def decide(self, lam_safety, U, u_t, tau_warn):
        lam_u = self.usb.lam_usable(U, self.q_curve(u_t))
        if lam_safety <= lam_u:
            return {'mode': 'auto', 'lambda': lam_safety, 'explain': None}
        j_auto    = self.r_auto(lam_safety, U) + self.c_task * (1 - self.q_auto(lam_safety))
        j_handoff = self.r_ov(U, tau_warn) + self.c_switch + self.c_task * (1 - self.q_handoff(tau_warn))
        if j_handoff < j_auto:             # U 越过 U*
            return {'mode': 'handoff', 'lambda': lam_u,
                    'explain': self.triplet('unusable', 'human', self.eta(tau_warn))}
        return {'mode': 'auto', 'lambda': max(lam_safety, self.lam_floor(U)), 'explain': None}


# IP-257 CRD：跨参数化反吸收（专治 R68 慢故障盲区）
class CrossParameterizationDisentangler:
    def __init__(self, Sigma_Lambda, kappa, h):
        self.S, self.Sigma, self.kappa, self.h = 0.0, Sigma_Lambda, kappa, h
    def update(self, r_f, r_e, J_f, J_e, B_f, B_e):
        M_abs = B_e - J_e @ np.linalg.pinv(J_f) @ B_f
        Lam = r_e - J_e @ np.linalg.pinv(J_f) @ r_f
        self.S = max(0.0, self.S + Lam @ np.linalg.solve(self.Sigma, Lam) - self.kappa)
        if self.S > self.h:
            return 'H_sensor_trans', Lam, M_abs   # 强制 λ≥0.8、冻结吸收方向
        return 'absorb_ok', Lam, M_abs


# IP-259 EBA：事件可用性审计（异步）
class EventBasedAuditor:
    def audit(self, episode, u_th, lam_hist, Lam_hist):
        breakdown = any(u[1] > u_th['hesitation'] or u[2] > u_th['override'] for u in episode.u)
        absorbed  = Lam_hist.cusum_peak > u_th['lambda']
        distorted = max(abs(episode.transp - lam_hist)) > u_th['transp']
        return {'interaction_breakdown': breakdown, 'absorbed_slow_fault': absorbed,
                'explanation_distortion': distorted}

    # 1) 事件计量：μs 同步 + 正交观测行
    r_sync_e = M.edm.residual_sync(obs.events, obs.force_peak_t_us)
    J_e, B_e = M.edm.event_row(obs.events, M.calm.last_r_f)

    # 2) 事件可用性观测（1ms 窗，冻结骨干）
    u = M.uox.observe(obs.events_window)

    # 3) CRD：把「被 COF 吸收的慢故障」捞回来
    verdict, Lam, M_abs = M.crd.update(M.calm.last_r_f, r_sync_e,
                                       M.calm.J_f, J_e, M.calm.B_f, B_e)
    if verdict == 'H_sensor_trans':
        lam_safety = max(lam_safety, 0.8)          # 反吸收：只收紧，不吸收
        M.calm.freeze_direction(M_abs)

    # 4) 双边控制：安全 vs 可用
    tau_warn = M.uox.warning_window(u)             # 事件提前量 Δδ
    act = M.ohc.decide(lam_safety, U, u, tau_warn)

    # 5) 执行 + 可解释接管
    if act['mode'] == 'handoff':
        M.handoff.begin(act['explain'], tau_warn)  # 透明三元组，禁止静默冻结
        tau = M.pi_sigma.hold_safe()               # 平滑保持，不突变
    else:
        tau = M.pi_sigma.prefix_dispatch(
            M.calm.ach.propose(M.calm.x_prime, M.calm.vista.H)[:k]) * act['lambda']

    # 6) 影子/异步：EBA 审计 + 可用性回归关 + CAC
    M.eba.submit_async(obs.episode, u, lam_safety, Lam)
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit)   # 新增 usab_regression 关
    return k, act, u, (c, U), Lam
```

## 3. 推导

**引理 16（跨参数化反吸收）** 设故障子空间 `F` 满足 `rank(M_abs|_F)=dim(F)`，其中 `Λ = M_abs f + n_Λ`。则联合观测下 `f` 可辨识，且帧单独可吸收集与联合可吸收集满足 `A_fe ⊆ A_f`；当 `B_e` 在 `F` 上不被 `J_e J_f⁺ B_f` 抵消时 `A_fe ⊊ A_f`。**系 1**：R68 中 `A_f` 是全部慢故障可达集；EDM 把可辨识集扩大到 `A_f \ A_fe`，其体积即「补回的秩」。
**系 2（帧时延/失帧病例）** 帧处理延迟的线性增长在帧通道等价于 `Δt_sync` 漂移（可标定）；但事件微秒基准与帧时间戳的差是**单向**的，无法由任何共享 `δc` 同时解释，故进入 `A_f \ A_fe`，被 `Λ` 检出。

**引理 17（单边收紧的冻结失败）** 设 `R_auto` 对 λ 单调减且 `R_auto(1,U)=R_auto^min(U) ≥ 0`，`p_ov` 对 λ 单调增且 `p_ov(1,U)=1`，`R_ov(U) > R_auto^min(U)`。则
`R_total(1,U) = R_ov(U) > R_auto^min(U) = R_total` 的可行下界，故 λ=1 永非最优；存在内点 `λ*(U) < 1`。进一步若 `R_auto^min(U)` 随 U 上升而在某 `Ũ` 超过 `R_ov`，则对 `U > Ũ`，任何「自主收紧」都被接管/停机支配——**R68 的 λ_floor→1 在 U 大时严格劣于有序接管**。

**定理 16（EVA-RAS 风险-可用联合界）** 在 A87–A94 及 A95（事件标定独立性）、A96（人类行为平稳性）下：
1. `P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + α_evt`，其中 `α_evt` 由 `Λ` 检出率与 `AUC_privacy` 约束；
2. 自主模式：`λ_applied ≤ λ_usable(U) ⇒ Q ≥ Q_min`（可用性下界）；
3. `U > U* ⇒ handoff`，且接管窗口 `τ_warn ≥ τ_warn^min` 时 `R_ov` 相对无事件预警下降 `≥ 1 − exp(−Δδ/τ_h)`（τ_h 为人的准备时间常数）；
4. 慢故障：`f ∉ A_fe ⇒` 检出概率 `≥ 1 − β_CRD`，且一旦检出 `λ ≥ 0.8` 且该方向吸收被冻结（反吸收闭环）。

**定理 17（最优接管阈值与事件提前量）** 若 `J_auto(U)` 对 U 单调增、`J_handoff(U,τ_warn)` 对 U 单调不增且对 τ_warn 单调减，则 `U*` 存在；在 `τ_warn` 从 `τ_warn^frame` 提到 `τ_warn^frame + Δδ` 后 `U*` 单调后移，接管成功率单调升。与「全知 oracle」的遗憾 `Regret ≤ ∫_{U*}^{U*'} [J_auto − J_handoff]⁺ dP(U) + c_switch·P(误接管)`，`Δδ = 25ms` 时在 `τ_h = 150ms` 的典型人因模型下接管风险下降约 15%。

**引理 18（可用性指标的可操纵性）** 若 UOX 只优化代理 `u_t` 而不闭环锚定离线量表（定义 309），则存在行为策略使人偏好 `u_t` 单调下降而真实 `Q` 不变或下降（Goodhart）。故 `Q` 必须由 `(u_t, 离线 SUS/TLX/信任量表, 客观任务成功率)` 三源共同锚定，且 `J_EVA` 记录三源一致性。

**一句话**：EVA-RAS 把「测量不可信时谁负责」的答案交给了人类接管，同时用同一套事件相机去观测「人是否可用」——**若人在高压短窗口下接管失败，或可用性/信任信号本身被个体差异、文化偏差乃至恶意行为（Goodhart/信任操纵）带偏，系统就会从 CALM 那种「可审计的保守失败」退化为「不可审计的人机共同失败」**；而事件相机只提供 μs 的「变化见证」，并不提供人是否会做出正确决定的保证。

## 3. 关键算法伪代码

```python
# IP-253 EDM：事件微秒基准 + 与帧正交的第二观测行（无曝光维）
class EventDrivenMetrology:
    def residual_sync(self, E, force_peak_t_us):
        return (self.first_deformation_event_us(E) - force_peak_t_us) - self.c_e[0]  # ~10μs
    def event_row(self, E, r_f):
        J_e = self.jacobian_event(E)      # 对外参/时间有列，对 δ_exposure 恰为 0
        return J_e, self.B_e_project(E)

# IP-254 UOX：事件可用性观测（冻结骨干，隐私友好）
class UsabilityObservationExtractor:
    def observe(self, E_window):
        v = self.backbone.sparse_forward(E_window, self.roi)
        return np.array([v.response_ts - v.human_onset_ts,   # L
                         v.pauses + v.reversals,             # H
                         v.estop_density_spike,              # O（μs 定位）
                         v.min_human_robot_distance,         # D
                         v.micro_reversal_rate, v.event_rate])

# IP-257 CRD：跨参数化反吸收（专治 R68 慢故障盲区）
class CrossParameterizationDisentangler:
    def update(self, r_f, r_e, J_f, J_e, B_f, B_e):
        M_abs = B_e - J_e @ np.linalg.pinv(J_f) @ B_f
        Lam   = r_e - J_e @ np.linalg.pinv(J_f) @ r_f
        self.S = max(0.0, self.S + Lam @ np.linalg.solve(self.Sigma, Lam) - self.kappa)
        return ('H_sensor_trans', Lam, M_abs) if self.S > self.h else ('absorb_ok', Lam, M_abs)

# IP-255/256 USB + OHC：双边策略，可用性不可兼得则有序接管
class OptimalHandoffController:
    def decide(self, lam_safety, U, u, tau_warn):
        lam_u = self.usb.lam_usable(U, self.q_curve(u))
        if lam_safety <= lam_u:
            return {'mode': 'auto', 'lambda': lam_safety, 'explain': None}
        j_auto    = self.r_auto(lam_safety, U) + self.c_task*(1 - self.q_auto(lam_safety))
        j_handoff = self.r_ov(U, tau_warn) + self.c_switch + self.c_task*(1 - self.q_handoff(tau_warn))
        if j_handoff < j_auto:
            return {'mode': 'handoff', 'lambda': lam_u,
                    'explain': self.triplet('unusable', 'human', self.eta(tau_warn))}
        return {'mode': 'auto', 'lambda': max(lam_safety, self.lam_floor(U)), 'explain': None}

# IP-262 主闭环：CALM 的 λ_safety 外挂可用性双边层
def EVA_RAS_round(M, obs):
    k, lam_safety, joint_post, (c, U) = CALM_RAS_round(M.calm, obs)     # R68 继承
    r_sync_e = M.edm.residual_sync(obs.events, obs.force_peak_t_us)     # μs 同步
    J_e, B_e = M.edm.event_row(obs.events, M.calm.last_r_f)
    u = M.uox.observe(obs.events_window)                                # 可用性观测
    verdict, Lam, M_abs = M.crd.update(M.calm.last_r_f, r_sync_e,
                                       M.calm.J_f, J_e, M.calm.B_f, B_e)
    if verdict == 'H_sensor_trans':
        lam_safety = max(lam_safety, 0.8); M.calm.freeze_direction(M_abs) # 只收紧不吸收
    act = M.ohc.decide(lam_safety, U, u, M.uox.warning_window(u))       # 双边决策
    if act['mode'] == 'handoff':
        M.handoff.begin(act['explain'], M.uox.warning_window(u))        # 透明三元组
        tau = M.pi_sigma.hold_safe()                                    # 平滑，不突变
    else:
        tau = M.pi_sigma.prefix_dispatch(
            M.calm.ach.propose(M.calm.x_prime, M.calm.vista.H)[:k]) * act['lambda']
    M.eba.submit_async(obs.episode, u, lam_safety, Lam)
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit)              # 第六关可用性回归
    return k, act, u, (c, U), Lam
```

## 4. 推导

**引理 16（跨参数化反吸收）** `Λ=M_abs f+n`；若 `rank(M_abs|_F)=dim(F)` 则 `f` 在联合观测下可辨识；`A_fe⊆A_f`，当 `B_e` 在 `F` 上不被 `J_e J_f⁺ B_f` 抵消时 `A_fe⊊A_f`。**系 1**：事件补回的秩即 `A_f\A_fe`。**系 2**：帧处理延迟增长在帧通道可伪装成 `Δt_sync` 漂移被吸收，但事件-帧时间差单向，无法由共享 `δc` 同时解释，必落入 `A_f\A_fe`。

**引理 17（单边收紧的冻结失败）** `R_auto` 对 λ 单调减、`p_ov` 对 λ 单调增且 `p_ov(1)=1`、`R_ov>R_auto^min` ⇒ `R_total(1,U)=R_ov>R_auto^min`，λ=1 永非最优，存在内点 `λ*<1`；若 `R_auto^min(U)` 越过 `R_ov`，则对 `U>Ũ` 自主收紧被接管/停机支配——R68 的 `λ_floor→1` 严格劣于有序接管。

**定理 16（风险-可用联合界）** A87–A96 下：(1) 失败概率 ≤ R68 各项 + `α_evt`；(2) 自主模式 `λ_applied≤λ_usable ⇒ Q≥Q_min`；(3) `U>U* ⇒ handoff`，事件预警使 `R_ov` 降 `≥1−exp(−Δδ/τ_h)`；(4) `f∉A_fe ⇒` 检出 `≥1−β_CRD`，检出后 `λ≥0.8` 且该方向吸收冻结。

**定理 17（最优接管阈值）** `J_auto` 对 U 增、`J_handoff` 对 U 不增且对 τ_warn 减 ⇒ `U*` 存在；`τ_warn` 增加 `Δδ` 使 `U*` 后移、接管成功率升；相对 oracle 的遗憾 `Regret≤∫_{U*}^{U*'}[J_auto−J_handoff]⁺dP(U)+c_switch P(误接管)`；`Δδ=25ms, τ_h=150ms` 时接管风险约降 15%。

**引理 18（可用性可操纵性 / Goodhart）** 若只优化代理 `u_t` 而不以离线量表与客观成功率锚定（定义 309），存在行为策略使 `u_t` 单调变好而真实 `Q` 不升甚至降；故 `Q` 必须三源锚定（在线 `u_t` + SUS/TLX/信任量表 + 客观任务成功率），`J_EVA` 记录一致性。

## 7. 本轮最大风险

**一句话**：EVA-RAS 把「测量不可信时谁负责」的答案交给了人类接管，同时用同一套事件相机去观测「人是否可用」——**若人在高压短窗口下接管失败，或可用性/信任信号本身被个体差异、文化偏差乃至恶意行为（Goodhart/信任操纵）带偏，系统就会从 CALM 那种「可审计的保守失败」退化为「不可审计的人机共同失败」**；事件相机只提供 μs 的「变化见证」，并不提供人是否会做出正确决定的保证。

**次级风险与缓解**：Goodhart → `Q` 三源锚定 + J_EVA 记录一致性（引理 18）；个体差异 → 留一被试泛化与在线权重回滚（E299）；信任误估 → 三元组解释 + 信任校准误差入证书；事件饱和/热像素 → 事件率门控 + 热像素掩码 + 降级到帧分支；隐私重建 → 不缓存原始事件 + 隐私预算审计（E293）；接管本身成为最大风险 → `U*` 由代价比较决定而非默认接管，且保留「停机」作为第三动作。
