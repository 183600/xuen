# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；本轮灵感：「微调」×「联邦学习」）

> R69 让闭环学会了「问」，并把不确定性拆成 **aleatoric（噪声，收紧）** 与 **epistemic（歧义，去问）**。但它把「模态权重是否可信」只交给**本地** MCG 的 ECE 门控：而这份 ECE 是在**系统自己用 MINT 选出来的提问流**上估计的。MINT 又是用待校准的模态权重去选问题的——**校准数据由被校准对象自己挑选**。这是一个闭环里的自证（self-confirmation）：系统越只问容易的题，校准看起来越漂亮，越学不会问难题，最后可能在真正稀有的模态上「自信地不问」。R69 自陈的最大风险（模态权重不可信 → 追问幻影）并没有被消除，只是被本地 ECE 这道门**假装挡住了**。
>
> 本轮两个灵感正好补上两块缺失：
> - **联邦学习**提供「外部第二意见」：跨站点的独立经验可以作为本地先验的对照分布。但联邦不应是「平均一个大模型」，而应是**联邦标定**——只交换低维、可差分隐私的充分统计量，在本地做裁决。
> - **微调**提供「本地个性化」：方言、传感器、地方规范都要求本地适配；但微调的作用域必须被切干净——只允许改「怎么问、信哪个源」，永远不允许改「多慢、多安全」，而且只能在**带倾向得分的审计切片**上离线进行。
>
> 核心命题：**把「标定」从本地自证升级为「联邦举证 + 本地裁决 + 有界微调」；联邦只提供慢变、低维、可撤销的校准先验，本地只用信任域内的小适配器做个性化，安全地板与 C-RAS-WM 包络永远本地冻结、不可被联邦或微调下调；信任不足时逐级退回 R69 的本地 FLUID，再退回 R68 的纯保守。** 命名 **FED-TRACE**（Federated Trust-Region Adaptive Calibration for Epistemic resolution）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我该信谁的经验，谁又来校准我的校准**」——联邦不是免费的第二意见，它同时带来「多数抹平少数」与「伪造少数派」两种新失败。

## 0. 直觉与动机

**灵感 1（微调 → 校准必须可个性化，但绝不能在自证数据上）**
直觉：R69 的 MCG 用本地 ECE 门控 VoI，前提是本地校准数据能代表真实误差分布。可系统只在「自己问过」的样本上拿到标签；这些样本是 MINT 用**尚未可信的模态权重**挑出来的。于是校准误差被选择偏差系统性压低，微调再把它固化：越问简单题 → 校准越好看 → 越不问难题 → **认知懒惰闭环（epistemic laziness）**。微调本身不是错，错的是**数据来源**与**作用域**：只微调「怎么问/信哪个源」（信息动作头），不微调「多慢/多安全」（风险与安全参数）；只在独立审计切片上、带倾向校正地离线微调，绝不把实时提问流直接当训练集。

**灵感 2（联邦学习 → 给标定一个外部对照分布）**
直觉：R69 的最大风险是「模态分布不可信」。本地数据既少又自证，跨站点的独立经验天然是外部对照。但直接联邦平均一个大策略既贵又不安全：通信大、隐私差、非 IID 下会把本地稀有模态抹平。正确姿势是**联邦标定而非联邦模型**：站点只上传低维充分统计量（模态先验残差、共形分位数、分层覆盖计数、倾向日志哈希），聚合端做鲁棒分层聚合，本地端拿它当「第二意见」而不是「上级命令」。

**灵感 3（鲁棒 vs 少数 → 联邦标定的核心张力）**
直觉：拜占庭鲁棒聚合（中位数/截尾均值）天然会删掉少数——但稀有模态恰恰是少数，也恰恰是最需要被保留和追问的那部分（方言、罕见故障、特殊人群、极端天气）。「防投毒」和「防抹平」在同一个加权平均里不可兼得。解法不是更强的鲁棒统计，而是**分层 + 支持并集 + 根信任**：按 mode×scenario 分层聚合，权重用鲁棒估计，但模态的「存在性」用支持并集而不是平均权重；并明确一条「联邦标定三难」——没有外部根信任时，拜占庭鲁棒、稀有真模态保留、伪造模态拒绝三者不可兼得。

**灵感 4（微调 × 联邦 = 两时间尺度、两空间分解）**
直觉：联邦想共识，微调想偏离；直接耦合会得到两种坏结果——**共识坍缩**（全局先验淹没本地稀有特性）或**个性化漂移**（适配器过拟合本地偏差甚至投毒）。把两者放进不同变量、不同时间尺度：**全局慢变量**（先验/分位数，联邦轮）与**本地快变量**（低秩交互适配器，离线）解耦；**安全参数**作为第三个、不可训练的只读变量。于是新层严格泛化旧层：FTG 否决 → R69，本地校准也失效 → R68，安全侧永远不弱于 R68。

**灵感 5（新攻击面 → 被伪造的少数派与被抹掉的真模态）**
直觉：一旦系统「信联邦」，就有人伪造站点、伪造稀有模态、用 Sybil 凑够支持阈值；一旦系统「用微调适配」，就有后门适配器、奖励黑客、遗忘不彻底、成员推断。最危险的不再是「问错」，而是**信错群体后停止提问**：一个被伪造的少数派拿到 resolution bonus，系统反而更自信、更少交互。因此本轮必须同时交付：联邦信任门、无退化验收门、可撤销聚合、隐私预算，以及针对「自我确认」的显式检测。

## 1. 形式化定义（增量：定义 310–323）

**定义 310（FED-TRACE 总览）** FED-TRACE = (FCS, PCI, FCA, FedCP, FTG, TRFT, SNG, RAS-WM†)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）：聚合与微调都在离线/控制间隙完成；
(ii) **安全主权（local safety sovereignty）**：联邦聚合与任何微调都不得下调本地 λ_floor、不得放宽 C-RAS-WM 包络与信息动作认证阈值；安全参数在联邦中只读；
(iii) **举证隔离**：用于校准/微调的标签不得仅来自本系统自己选择的提问流，必须来自审计切片并做倾向校正，否则证据不足、U_fed 上调。

**定义 311（标定充分统计量 FCS）** 站点 k 上传 S_k = (Δŵ_k, q_k(α), κ_k, n_k, h_k)：Δŵ_k 为按 (mode, scenario) 分层的本地模态先验与上一轮全局先验的条件残差；q_k(α) 为分层共形分位数；κ_k 为分层覆盖计数；n_k 为有效样本数；h_k 为审计日志哈希（不上传原文）。要求 d_c ≪ d_model，且 S_k 满足 (ε_dp, δ)-DP（定义 320）。**不聚合全模型梯度**。

**定义 312（倾向校正标定 PCI）** MINT 以概率 π_k(g|o) = softmax((VoI(g)−c(g))/τ) 选信息动作，并记录该概率。定义倾向加权校准误差
ECE_IPS = Σ_b (n_b/N) · | Σ_{i∈b} w_i·1[ŷ_i≠y_i] − Σ_{i∈b} w_i·ŵ_i |，w_i = min(1/π_k(g_i|o_i), w_max)。
未加权 ECE 与总体 ECE 的偏差上界为 O(d_TV(q_query, q_audit))。定义**认知懒惰度** L_epi = 1 − E_{q_query}[VoI] / E_{q_unif}[VoI]；L_epi 越高，说明系统越只问容易的、校准越自证。

**定义 313（鲁棒分层聚合 FCA）** 在 Mondrian 单元 c=(mode, scenario) 上分别聚合，不做全局平均：权重/残差用坐标级 trimmed mean 或 median-of-means（去掉最高/最低 ⌊fN⌋ 个）；**存在性**用支持并集 supp^G(c) = {m : |{k : m∈supp_k(c)}| ≥ k_min}，而不是加权平均后取阈值；站点信任权重 u_k ∝ 1/(1+U_fed,k) 且乘审计通过率。输出全局先验 G = (w^G, q^G(α), supp^G)。

**定义 314（联邦共形与少数模态保护 FedCP）** 每个单元 c 用分层共形分位数 q^G_c(α)，使覆盖率 P(Y∈C) ≥ 1−α；模态 m 保留 iff 满足定义 313 的支持条件，或本地审计覆盖 ≥ 1−α 且 w_m ≥ w_min。定义**覆盖债** D_cov = Σ_c [ (1−α) − cover_c ]^+；D_cov > τ_cov ⇒ 该单元禁用 resolution bonus。少数模态即使权重很低，只要支持够就保留其「可被追问」资格，但**不自动获得高权重**。

**定义 315（联邦信任门 FTG 与 U_fed）**
U_fed,k = max_c [ d_TV(ŵ_k^c, w^{G,c}) + α_s·s_k + α_d·D_cov^c ]，
其中 s_k ∈ [0,1] 为拜占庭可疑分（本地-全局残差与邻站不一致度、审计失败率、提交统计量的时间突变）。FTG 通过 iff U_fed,k ≤ τ_fed ∧ f̂ ≤ f_max ∧ D_cov ≤ τ_cov（f̂ 为估计的可疑站点比例）。否则执行**本地否决（local veto）**：不用全局先验。

**定义 316（三通道不确定性与三级退避）** U = (U_ale, U_epi, U_fed)。U_ale、U_epi 继承 R69；U_fed 是「全局先验是否适用于本地」的**转移不确定性**（对校准来源的不确定性，不是对动作的不确定性）。三级：
- **L1 FED**：FTG 通过 → VoI 用全局先验，消解成功时 λ = λ_floor(U_ale)，获得 **federation bonus**；
- **L2 LOCAL**：FTG 否决 → 回到 R69 的本地先验，λ = λ_floor(U_ale + 未消解 U_epi)；
- **L3 CALM**：本地 ECE_IPS > τ_ece 或审计失败 → R68 纯保守，λ = λ_floor(U_ale + U_epi)。
安全侧单调：λ_L1 ≤ λ_L2 ≤ λ_L3，且 L3 与 R68 逐指令相同。

**定义 317（信任域微调 TRFT）** 本地只微调**交互策略适配器** Δθ（低秩 r，仅作用于信息动作头「问什么/信哪个源/如何加权证据」），
min_{Δθ} E_{D_aud}[ L_task^{DR}(θ+Δθ) ] + β·ECE_IPS(θ+Δθ) + μ·KL(π_{θ+Δθ}(g|·) ‖ π^G(g|·)) + (η/2)‖Δθ‖²，
s.t. ‖Δθ‖₂ ≤ ρ，且**安全参数集 Θ_safe 冻结**（λ_floor、C-RAS-WM 阈值、信息动作包络、证据纪律）。L_task^{DR} 为对记录行为策略 π_0 的双重稳健 off-policy 估计。两时间尺度：全局 G 每 T_g 更新，本地 Δθ 每 T_l 更新且 T_l ≪ T_g；**微调只在 D_aud 上离线进行**，实时流只消费适配器。

**定义 318（无退化验收门 SNG）** 新适配器只有在本地审计切片上通过三项单侧非劣性检验才上线：(i) 安全违规率不升（显著性 α_s）；(ii) ECE_IPS 不升且分层覆盖不降；(iii) 任务成功率不劣于 ε_noninferior。任一不过 ⇒ 进入 shadow 模式（只记录不执行）或拒绝。SNG 使微调**永远不能把 R69 的已认证行为变差**（no-regression）。

**定义 319（联邦遗忘与贡献撤销 FUL）** 任一站可请求删除其对 G 的贡献。FCA 为分位数/中位数维护可撤销充分统计；删除后重算 q^G 与 supp^G，并给出覆盖变化上界 |Δcover_c| ≤ Δ_ful；重签 J_FED。DP 机制需支持噪声重算或安全聚合下的贡献记账。

**定义 320（隐私与通信）** S_k 以 (ε_dp, δ)-DP 发布；本地交互日志与原始标签永不出域，只出哈希 h_k；每轮每站通信 ≤ B_c bits。关键设计：**隐私噪声只会抬高 U_fed 的下限，从而把系统推向更保守的 L2/L3，而不会以「信任」换精度**——隐私失败退化为安全，而不是退化为冒进。

**定义 321（证书 J_FED）** J_FED = (J_FLUID, U_fed, cover_min, D_cov, ECE_IPS, f̂, k_min, dp_ε, adapter_ver, sng_pass, ful_epoch, Θ_safe_hash, fed_ver)。Valid ⇔ Valid(J_FLUID) ∧ 覆盖 ≥ 1−α−τ_cov ∧ SNG 通过 ∧ f̂ ≤ f_max ∧ **Θ_safe_hash 与本地冻结值一致**。

**定义 322（威胁模型 AIC-FED）** ℰ_FED = ℰ_FLUID × ℰ_site × ℰ_privacy × ℰ_nonIID × ℰ_unlearn × ℰ_selftrain：拜占庭站点/投毒标定/伪造模态；成员推断与统计量泄露；分布漂移与多数抹平；删除不彻底；自我确认偏差与交互奖励黑客。

**定义 323（自我确认检测）** 记录查询分布 q_query 与审计分布 q_audit，计算 χ²(q_query‖q_audit) 与 L_epi。若 χ² > τ_χ 或 L_epi > τ_lazy，则禁止用提问流标签微调，并对该站点的 Δŵ_k 降权（U_fed 加惩罚）。这是对 R69「用自己问出来的数据校准自己」的直接封堵。

# IP-264/266 FCS + FCA：离线联邦轮，只聚合低维标定统计量
def federated_calibration_round(sites, G_prev, f_max, alpha):
    summaries = []
    for site in sites:
        S = site.compute_summary(G_prev, dp_eps=1.0)   # 分层残差/共形分位/覆盖/哈希
        S.suspicion = audit_suspicion(S, site.neighbors)  # 拜占庭可疑分
        summaries.append(S)
    cells = group_by_cell(summaries, key=('mode', 'scenario'))
    G = {}
    for c, Ss in cells.items():
        keep = trim_top_bottom(Ss, frac=f_max)          # 鲁棒权重/残差
        w_c  = median_of_means([S.dw for S in keep])    # 鲁棒先验
        G[c] = dict(w=w_c,
                    support=support_union(Ss, k_min=K_MIN),   # 存在性用并集，保少数
                    q=conformal_quantile(Ss, alpha),          # 分层覆盖
                    cover=coverage_counts(Ss))
    return G

    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)

    # (1) 联邦信任门：全局先验能不能用？

## 3. 推导

**引理 19（倾向校正的偏差界）** 设行为策略选择概率 π(g|o) ≥ π_min > 0 且权重截断 w ≤ w_max。则 ECE_IPS 是总体校准风险的相合估计；而未加权 ECE 的偏差满足 |ECE_unw − ECE_pop| ≤ 2·d_TV(q_query, q_audit)·C_res。要点：**只在自己爱问的样本上校准，会系统性低估误差**；R69 的本地 ECE 门控因此可能「门开着但闸是坏的」。系：必须有审计切片或显式倾向校正，否则 calibration 只是 query policy 的自画像。

**引理 20（鲁棒聚合与少数保留的张力）** 对 f 比例被腐蚀站点，trimmed mean 的估计误差 ≤ O(√(log d_c/n_eff) + f)（崩溃点 f < 1/2）；但同一规则下：真实模态若支持站点数 < k_min，其保留概率 → 0（无论权重多大）；伪造模态只要凑够 k_min 支持就会被保留。故**鲁棒性与稀有模态保留不能被同一个支持计数规则同时保证**。这把「多数抹平」与「伪造少数派」变成同一枚硬币的两面。

**引理 21（信任域微调的非劣性）** 在 SNG 单侧检验显著性 α_s、适配器半径 ‖Δθ‖ ≤ ρ 下，被接受适配器的本地校准退化超过 ε 的概率 ≤ α_s；且因 Θ_safe 冻结，安全包络变化恒为 0；策略漂移满足 ‖π_{θ+Δθ} − π_θ‖ ≤ L_π·ρ。要点：微调在**能力空间**上被限制为「怎么问」，在**安全空间**上被限制为「零变化」。

**引理 22（联邦共形覆盖）** 各 Mondrian 单元内若本地可交换，且至多 f 比例站点被腐蚀，分层共形 + 鲁棒顺序统计量的覆盖满足 cover_c ≥ 1 − α − f/(1−f) − D_cov,c。系：覆盖率不是靠「相信聚合端」得到的，而是靠每个单元自己的有限样本计数得到的；覆盖债直接进入证书与退避。

**定理 18（三级严格包含）** 在 A95–A101（继承 R69 的 A95–A98；A99：π ≥ π_min > 0；A100：U_fed ≤ τ_fed ⇒ 本地-全局校准差 ≤ ε_fed；A101：f ≤ f_max 且真实模态支持条件满足）下，任意状态 s 上
E[risk(FED-TRACE)] ≤ E[risk(R69 LOCAL)] ≤ E[risk(R68 CALM)]。
当 FTG 否决时，FED-TRACE 与 R69 **逐指令相同**；当本地 ECE_IPS 越界时，与 R68 **逐指令相同**。L1 的 federation bonus 只在覆盖达标且 SNG 通过时发放。故新层是旧层的严格泛化，安全侧不让步。

**定理 19（安全主权与无突变）** 联邦聚合与 TRFT 均不能修改 Θ_safe（J_FED 以 Θ_safe_hash 校验）；SNG 保证已认证行为不退化；信任下降时 λ 单调不降地退回 L2/L3。结合 R69 定理 17 的换装不变式 ⇒ 控制连续、无突变。隐私噪声只会抬高 U_fed、使系统更保守，绝不会通过「信任」降低安全。

**定理 20（联邦标定三难）** 不存在任何不依赖外部根信任的聚合规则 A，能同时保证：(a) f-拜占庭鲁棒（腐蚀比例 f 下误差有界）；(b) 保留所有支持数 < k_min 的真实模态；(c) 拒绝所有支持数 ≥ k_min 的伪造模态。证明要点：构造两个仅在一个模态的「真伪标签」上不同、而提交统计量完全一致的世界；A 无法区分二者，故必在 (b) 或 (c) 上失败。系：**支持度不是证据，只是共识**；必须引入本地审计、日志哈希、硬件/人工根信任或向人类升级，才能打破三难。这正是本轮把「证据纪律」升级为「来源纪律」的原因。

## 6. 本轮最大风险

**一句话**：FED-TRACE 的全部收益押在「联邦的标定来源既可信、又可代表本地」上——拜占庭鲁棒统计为了防投毒会抹掉稀有真模态，而支持度规则又会让足够多 Sybil 站点伪造的幻影模态获得 resolution bonus；一旦信错群体，系统会对一个被伪造或被抹平的先验**停止提问、加速执行**——**信错群体，比孤立更危险**。

1. **自我确认偏差被微调固化**（定义 312/323、PCI + 审计切片 + DR 估计，E301/E311）；

5. **隐私泄露 / 删除不彻底**（定义 319/320、DP 统计 + 可撤销聚合 + 哈希审计，E309/E310）。

## 2. 形式化定义（要点版）

**定义 310（总览与三不变式）** 实时零学习写；**安全主权**（联邦/微调不得下调 λ_floor、不得放宽 C-RAS-WM 与信息动作认证）；**举证隔离**（校准/微调标签不得仅来自自选提问流，须审计切片 + 倾向校正）。

**定义 311–312（FCS 与 PCI）** 只传分层低维统计量并 DP 发布；`ECE_IPS = Σ_b (n_b/N)|Σ w_i·1[err] − Σ w_i·ŵ_i|`，`w=min(1/π,w_max)`；未加权 ECE 偏差 `≤ 2·d_TV(q_query,q_audit)·C`；`L_epi = 1 − E_query[VoI]/E_unif[VoI]`。

**定义 313–314（FCA 与 FedCP）** 按 (mode, scenario) 分层：权重/残差 trimmed-mean 或 median-of-means；存在性 `supp^G={m:|{k:m∈supp_k}|≥k_min}`（并集，不用加权平均）；分层共形分位数保证 `cover_c ≥ 1−α−f/(1−f)−D_cov,c`；覆盖债超限即禁用 resolution bonus。

**定义 315–316（FTG 与三级退避）** `U_fed` 越界 / `f̂>f_max` / `D_cov>τ_cov` ⇒ 本地否决。L1 FED（FTG 通过，federation bonus）、L2 LOCAL（=R69）、L3 CALM（=R68）；`λ_L1 ≤ λ_L2 ≤ λ_L3`。

**定义 317–318（TRFT 与 SNG）** 目标 `DR任务损失 + β·ECE_IPS + μ·KL(·‖π^G) + (η/2)‖Δθ‖²`，`‖Δθ‖≤ρ`，`Θ_safe` 冻结；两时间尺度 `T_l ≪ T_g`；SNG 三项非劣性（安全/校准/任务）不过则 shadow/拒绝。

**定义 319–320（FUL 与隐私）** 可撤销充分统计 + 重算分位数 + 覆盖变化上界；`(ε_dp,δ)-DP`，日志不出域，仅出哈希；隐私噪声只抬高 U_fed（更保守）。

**定义 321–323（证书/威胁/自证检测）** `J_FED` 增加 U_fed、覆盖、ECE_IPS、f̂、Θ_safe_hash；`ℰ_FED = ℰ_FLUID × ℰ_site × ℰ_privacy × ℰ_nonIID × ℰ_unlearn × ℰ_selftrain`；`χ²(q_query‖q_audit)` 与 `L_epi` 超阈即禁止用提问流标签微调并降权该站先验。

## 4. 推导

**引理 19（倾向校正偏差界）** `π≥π_min>0` 时 ECE_IPS 相合；未加权 ECE 偏差 `≤ 2·d_TV(q_query,q_audit)·C_res`。故 R69 的本地 ECE 门控可能「门开着、闸是坏的」。

**引理 20（鲁棒 vs 少数）** f-腐蚀下 trimmed-mean 误差 `≤ O(√(log d_c/n_eff)+f)`（崩溃点 f<1/2）；但真实模态支持 `<k_min` 时保留概率→0，伪造模态支持 `≥k_min` 即被保留。鲁棒与保少数不可由同一支持计数规则同时保证。

**引理 21（微调非劣性）** SNG 显著性 α_s、半径 ρ 下，被接受适配器校准退化 `>ε` 的概率 `≤α_s`；`Θ_safe` 冻结使安全包络变化恒为 0；策略漂移 `≤L_π·ρ`。

**引理 22（联邦共形覆盖）** 单元内可交换、至多 f 站点被腐蚀时 `cover_c ≥ 1−α−f/(1−f)−D_cov,c`；覆盖靠有限样本计数而非「相信聚合端」。

**定理 18（三级严格包含）** A95–A101 下 `E[risk(FED)] ≤ E[risk(R69 LOCAL)] ≤ E[risk(R68 CALM)]`；FTG 否决时与 R69 逐指令相同，本地 ECE_IPS 越界时与 R68 逐指令相同；federation bonus 仅在覆盖达标且 SNG 通过时发放。

**定理 19（安全主权与无突变）** 联邦聚合与 TRFT 不能修改 Θ_safe（哈希校验）；SNG 保证已认证行为不退化；信任下降时 λ 单调不降；结合 R69 定理 17 ⇒ 控制连续、无突变。隐私噪声只抬高 U_fed，使系统更保守。

**定理 20（联邦标定三难）** 无外部根信任时，不存在聚合规则同时满足：(a) f-拜占庭鲁棒；(b) 保留所有支持 `<k_min` 的真实模态；(c) 拒绝所有支持 `≥k_min` 的伪造模态。证明：构造统计量相同、仅「真伪标签」不同的两个世界，规则无法区分。系：**支持度只是共识，不是证据**；须以本地审计、日志哈希、硬件/人工根信任打破三难——把「证据纪律」升级为「来源纪律」。

## 7. 本轮最大风险

**一句话**：FED-TRACE 的全部收益押在「联邦的标定来源既可信、又可代表本地」上——拜占庭鲁棒统计为了防投毒会抹掉稀有真模态，而支持度规则又会让足够多 Sybil 站点伪造的幻影模态获得 resolution bonus；一旦信错群体，系统会对一个被伪造或被抹平的先验**停止提问、加速执行**——**信错群体，比孤立更危险**。

**次级风险与缓解**：自我确认被微调固化（PCI + 审计切片 + DR，E301/E311）；伪造少数派/Sybil（k_min 支持 + 根信任 + VQAuditor-F，E305、定理 20）；稀有真模态被鲁棒统计抹掉（支持并集 + 覆盖债 + 本地否决，E304/E314）；微调后门/遗忘/奖励黑客（Θ_safe 冻结 + 低秩 + SNG，E306/E307）；隐私泄露/删除不彻底（DP + 可撤销聚合 + 哈希审计，E309/E310）。
