# 第 4 轮（灵感循环第 4 轮；本轮灵感：「域随机化」×「课程学习」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。域随机化沿「环境不确定性」轴升级契约校准；课程学习沿「任务顺序」轴升级盲区修复调度。二者都是增强项，不是依赖项。

## 0. 直觉与动机

**灵感 1（域随机化 → 把「一次标定」变成「一族标定」）**
直觉：盲区修复的契约（几何/传感器/模型）通常只在名义数字孪生 θ₀ 上标定。真实世界的光照、反射率、温度、传感器噪声、动力学都在变；把仿真「调得更真」是追不上的。域随机化的正确用法不是追求一个更真的点，而是把不确定性写成一个包络 `E_φ=(Θ_φ,P_φ,S_φ,w_φ)`，在包络上做分布鲁棒标定。但 DR 不是安全保证：它只把「点估计」换成「带支撑假设的分布估计」。如果真实 `θ*` 在包络外，鲁棒证书会静默失效。因此 DR 必须配一张**支撑覆盖证书（SCC）**：先证支撑，再谈鲁棒。

**灵感 2（课程学习 → 不要一上来修最难的盲区）**
直觉：盲区有难易。先用简单盲区获得干净回执，估出共享的噪声底与基础几何，再去修难盲区，可以显著降低难任务的样本复杂度。但课程学习有两个副作用：一是它破坏可交换性，使共形校准的覆盖率声明失效；二是调度器会「挑证据」——它决定自己看到什么，再用这些证据证明自己学得好。因此课程必须配**独立审计流、任意时间有效置信序列与反遗忘回放**；否则「课程」会变成「自证」。

**灵感 3（两者耦合 → 随机化课程，但必须强制前沿）**
直觉：DR 与 CL 的自然耦合是「由易到难地扩大随机化包络」：先在小包络里把契约调稳，再逐步扩大 `Θ_φ`。这正是课程域随机化（curriculum DR）。危险在于：调度器可以在简单包络里停留，用自己的审计证据证明自己鲁棒，而真实世界的难点在尚未探索的前沿或包络之外。解法不是取消课程，而是加三根结构支柱：**支撑证书**（包络外必须报警）、**独立审计**（调度器不能决定审计样本）、**强制前沿**（必须周期性尝试下一半径，失败则二分回退）。再把它们接进严格退化链。

## 1. 研究问题（本轮要回答什么）

- **Q1（DR 的迁移条件）**：域随机化能否把契约从单点标定升级为带迁移界的鲁棒标定？其充分条件是什么，何时必须回退名义标定？
- **Q2（课程的收益与边界）**：课程学习能否降低盲区修复的样本复杂度？正迁移与负迁移的判据是什么？
- **Q3（耦合的自证风险）**：随机化课程是否会产生「自证偏差 + 包络外推」？独立审计、任意时间有效界与强制前沿能否把它压回可证伪？

## 2. 设计原则（雏形，正式化见产物区定义 448–463）

**P1 支撑先于随机化（Support before Randomization）**
先签 SCC，再谈鲁棒性。`SCC=⊥`（真实分布与包络的 TV/似然比/支撑距离超阈）⇒ 关闭 DR，回退名义契约。DR 的迁移界只在支撑证书成立时有意义。

**P2 审计独立（Audit Independence）**
调度器只能看校准集，不能看审计集；覆盖率用任意时间有效置信序列报告，而不是事后点估计。课程不能用自己挑选的证据自证。

**P3 前沿强制（Forced Frontier）**
课程不能停在简单层。必须在 `T_frontier` 内尝试下一半径/下一难度；失败则二分回退。`T_frontier=∞` 时课程退化为无强制探索，自证风险不受控。

**P4 正迁移准入（Positive-Transfer Gate）**
只有 `κ_trans>0`、难任务样本复杂度严格下降、且回放遗忘 `F_k≤η_rep` 时才允许课程升级；否则回退 `π_unif`。

**P5 严格退化（Strict Degradation）**
任一新组件失效 ⇒ 退回 InstructGauge ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE。DR 与 CL 都是增强项，不是依赖项。

## 3. 与基线的接口（如何退化）

- `Θ_φ={θ₀}, P_φ=δ_{θ₀}, S_φ={θ₀}` ⇒ 名义 ToolGauge/InstructGauge 标定；
- `SCC=⊥` / 包络过宽 / 留出集退化 ⇒ 关闭 DR，用名义契约；
- `π_cl=π_unif` / `κ_trans≤0` / 审计覆盖失效 ⇒ 关闭课程，回退均匀调度；
- 回放遗忘超阈 ⇒ 冻结升级并用回放加权重校准；
- `T_frontier=∞` / 前沿失败 ⇒ 保持当前半径并告警；
- CurriDR 失效 ⇒ InstructGauge；InstructGauge 失效 ⇒ ToolGauge；ToolGauge 失效 ⇒ LeanGauge；LeanGauge 失效 ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个带**支撑覆盖证书**的域随机化鲁棒契约校准口径，把 sim-to-real 从「调参玄学」变成「有迁移界的分布鲁棒问题」；
2. 一个**课程调度 + 独立审计 + 反遗忘回放**的盲区修复顺序策略，把课程从「训练技巧」变成「可证伪的样本复杂度声明」；
3. 一个**强制前沿的随机化课程**机制，专门对抗「课程自证」与「包络外推」；
4. 一条完整可证伪路径：E457–E472 覆盖支撑检测、迁移界、角点保真、课程收益、负迁移、自适应覆盖、自证攻击、前沿探索、反遗忘、非平稳、端到端、消融、安全、时序与包络外极端。

## 5. 本轮最大风险

**一句话**：课程调度器与随机化包络共同决定了「系统看到的世界」，因此最大的风险不是单个组件失效，而是**自证偏差 + 包络外推**——系统可能在自己挑选的简单证据和自己定义的包络内证明自己鲁棒，而真实世界的 `θ*` 在包络之外或在前沿尚未探索的角点上；独立审计、任意时间有效界、强制前沿与 SCC 只能降低、不能消除这一残余风险。

## 2. 形式化定义（要点）

**定义 448（环境参数与随机化包络）** 设 `θ ∈ Θ ⊆ R^d` 为环境/扰动参数，真实环境参数 `θ*` 未知。随机化包络
`E_φ = (Θ_φ, P_φ, S_φ, w_φ)`，
其中 `Θ_φ ⊆ Θ` 为闭包络（盒/多面体/有限并），`P_φ` 为 `Θ_φ` 上的分布且满足 **密度下界** `inf_{θ∈Θ_φ} p_φ(θ) ≥ p_min > 0`（保证似然比可控），`S_φ ⊆ Θ_φ` 为有限角点集或 ε-网，`w_φ: Θ_φ→[0,1]` 为鲁棒聚合权重。名义环境对应 `E₀ = ({θ₀}, δ_{θ₀}, {θ₀}, 1)`。预算约束：`|S_φ| ≤ N_DR`、`d ≤ d_max`，超预算即拒绝包络。

**定义 449（数字孪生集成、鲁棒风险与 DRCert）** 记 `D_φ = {DPE(θ) : θ ∈ Θ_φ}`，损失 `ℓ(c;θ) ∈ [0,1]`。定义
`L_φ(c) = E_{θ~P_φ}[ℓ(c;θ)]`，
`CVaR_{α_rob}(c) = min_{η} { η + (1/α_rob) E_{θ~P_φ}[(ℓ(c;θ)−η)_+] }`，
`L_corner(c) = max_{θ∈S_φ} ℓ(c;θ)`。
`DRCert(c) = (φ, Θ_φ, L_φ(c), CVaR_{α_rob}(c), L_corner(c), heldout_real)`，其中 `heldout_real` 为留出真实回执上的损失（不参与校准）。

**定义 450（鲁棒契约校准 RCC）**
`c* = argmin_{c∈C} [ L_φ(c) + λ_rob·CVaR_{α_rob}(c) + λ_cplx·complexity(c) ]`
`s.t. shield(c)`、`L_corner(c) ≤ ε_corner`、`B_cur ≤ B_left`。
当 `E_φ=E₀` 且 `λ_rob=0` 时，RCC 逐项退化为名义 ToolGauge/InstructGauge 标定。RCC 只改契约参数，**不改变动作可行域**；安全盾仍由基线硬约束负责。

**定义 451（支撑覆盖证书 SCC）** `SCC = (d_sup, ρ_sup, Λ̂, β_sup)`，在独立真实回执 `R_real` 上计算：
1. 两样本差异 `d_sup(P̂_real, P_φ) ≤ τ_sup`；
2. 每个真实锚点的 k-NN 到 `Θ_φ` 的距离 `≤ ρ_sup`；
3. 包络内似然比上界 `Λ̂ ≤ Λ_max`（密度比估计并裁剪）。
任一失败 ⇒ `SCC = ⊥`，禁止使用 `DRCert` 的迁移界。`SCC` 只使用审计/真实回执，不使用课程调度器挑选的校准样本。

**定义 452（迁移界与 TV 缺口）** 记 `ε_TV = TV(P_real, P_φ)`、`β_out = P_real(Θ \ Θ_φ)`。若 `SCC` 成立，则对任意契约 `c`：
`|R_real(c) − R_φ(c)| ≤ 2 ε_TV`，
且当 `dP_real/dP_φ ≤ Λ` 于 `Θ_φ` 时，
`R_real(c) ≤ (1−β_out)·Λ·R_φ(c) + β_out`。
三元组 `(ε_TV, β_out, Λ)` 构成迁移证书字段；任一超阈即视为迁移界失效，必须回退名义契约。

**定义 453（课程、难度序与步调）** 课程含 `K` 个阶段，每阶段任务分布 `D_k`（盲区 + 包络 `E_{φ_k}`）。难度分
`d(s) = E_s[c_probe(s)] / E_s[ΔH_max(s)]`
（单位信息增益的探测成本）。要求 `D_1 ≼ D_2 ≼ ... ≼ D_K`，其中 `≼` 为「难度随机占优」偏序。步调 `ρ_k ∈ (0,1]` 为阶段 `k` 的任务占比，满足 `Σ_k ρ_k = 1`；`ρ_k` 不必单调，但必须覆盖每个阶段的最小暴露量 `n_min^cl`。

**定义 454（课程调度策略 π_cl）** `π_cl: H_t → (k, s)` 由历史 `H_t` 选阶段与任务，带 promotion/demotion：
- `promote(k→k+1)` 当 `L_aud(k) ≥ 1−α`、`ΔR_rob > 0`、`F_k ≤ η_rep`、`drift ≤ η_drift`；
- `demote(k→k−1)` 当 `L_aud(k) < 1−α−δ` 或发生安全违规。
`π_unif` 为均匀调度；`π_cl=π_unif` 即退化为 InstructGauge/ToolGauge 的任务顺序。

**定义 455（独立审计流与课程分层）** 每阶段维护互不相交的校准集 `C_cal^k` 与审计集 `A_k`；调度器只能读 `C_cal^k`，**不能读 `A_k`**。审计集按 `(课程阶段 k, 指令层 s)` 分层为 `A_{k,s}`；若 `|A_{k,s}| < n_min`，回退到阶段级或全局审计，覆盖率保证按 `−2η_global` 优雅降级而不是消失。

**定义 456（任意时间有效置信序列）** 对审计风险/覆盖 `R_{k,s}`，构造 `(L_t, U_t)` 使
`P(∀t ≥ 1 : R_{k,s} ∈ [L_t, U_t]) ≥ 1−α`。
例如按 `α/(t(t+1))` 分配 Hoeffding 界，或使用 betting/混合鞅置信序列。仅当 `L_t ≥ 1−α` 才 promotion；当 `U_t < 1−α−δ` 才 demote。该定义使覆盖率对可选停时与自适应调度稳健，是「课程不能自证」的统计基础。

**定义 457（反遗忘回放 ARB）** 回放缓冲 `B_rep` 用 reservoir sampling 从 `∪_{j≤k} A_j` 抽取 `m` 条。遗忘度量
`F_k = max_{j≤k} [ R_j(c_k) − R_j(c_j*) ]`，
其中 `c_j*` 为阶段 `j` 的最佳契约。更新约束 `F_k ≤ η_rep`；违反 ⇒ 冻结升级，并用回放加权损失重新校准。

**定义 458（前沿半径与强制探索 FEX）** 包络半径 `r_k`，真实最大安全半径
`r* = max{ r : R_real(c(r)) ≤ ε_safe }`。
强制规则：在 `T_frontier` 步内必须尝试 `r_{k+1} = min(r_k + Δr, R_max)`；失败则二分回退
`r_k ← (r_k + r_{k+1})/2`。每次前沿尝试必须含至少 `n_corner` 个角点/极端样本；`T_frontier=∞` 表示关闭强制探索，此时引理 64 不适用。

**定义 459（正迁移系数与课程样本复杂度）** 分层高斯模型：共享参数 `θ_s ~ N(0, τ²)`，任务观测 `y = θ_s + θ_k + ε`，`θ_k ~ N(0, σ_k²)`，`ε ~ N(0, σ_obs²)`。定义 `κ_trans ∈ [−1,1]` 为共享参数对难任务的方差解释比例。易任务 `n_e` 条后共享参数后验方差
`v_e = τ² σ_e² / (n_e σ_e² + τ²)`；
难任务达到误差 `ε` 所需样本
`n_h(ε) = O((v_e(1−κ_trans) + σ_h²) / ε²)`。
仅当 `κ_trans > 0` 且 `n_h` 较 `π_unif` 严格下降时才准入课程；`κ_trans≤0` 视为负迁移，回退 `π_unif`。

**定义 460（课程分层共形校准）** 在 InstructGauge 定义 438 的 `stratum(ι)` 上再乘课程阶段：`stratum″ = (k, stratum(ι))`；每层阈值 `q_{k,s}` 由 `C_cal^{k,s}` 的分位给出；低样本回退 `(k, GLOBAL)` 或 `(GLOBAL, s)`。课程与指令双重条件化都不假设可交换性，统一由定义 456 的独立审计流兜底。

**定义 461（CurriDR 预算准入）** `B_cur = c_dr + c_cl + c_audit + c_replay`；仅当 `B_cur ≤ B_left` 且 `c_dr/K + c_cl/T_cl + c_verify ≤ budget_slack` 时准入。包络规模超 `N_DR`、维度超 `d_max`、或课程阶段数超 `K_max` ⇒ 直接降级，不进入鲁棒校准。

**定义 462（CurriDR-9C 闭环）** 阶段序列
`I → H → C_cl → R → C_chunk → E → C_cvc → V → U`：
`I` 指令接地（继承 NLI-Box）、`H` 假设重排、`C_cl` 课程选任务/阶段、`R` 随机化包络与孪生集成、`C_chunk` 前缀封闭分块、`E` 执行、`C_cvc` 块有效性证书、`V` 校准/审计/回放验证、`U` 更新契约与记录证书。`C_cl` 与 `R` 均为异步钩子，不进入 50Hz 内联路径。

**定义 463（CurriDR 修复证书）** `RepairCert″(s) = (ι, C, ChunkCert, DRCert, CLCert, receipts, claims)`，其中
`CLCert = (k, π_cl, L_aud(k), F_k, r_k, frontier_age)`。
人类审计可沿「指令 → 块 → DR 包络 → 课程阶段 → 逐步回执 → 主张」六级证据链复现一次修复；`claims` 仍是纯投影（继承定义 441）。

## 3. 关键算法骨架

```python
# IP-328 DRE：域随机化包络（支撑、分布、角点、权重）
class DRE:
    def envelope(self, task, budget):
        theta = self.support(task)                  # Θ_φ: box / polytope / finite union
        corners = self.epsilon_net(theta, delta)    # S_φ；|S_φ| <= N_DR
        p_phi = self.mixture_uniform(theta)         # p_φ >= p_min > 0
        return Envelope(theta, p_phi, corners, w=self.robust_weights(theta))

    def nominal(self, task):
        return Envelope({self.theta0}, Delta(self.theta0), {self.theta0}, 1.0)

# IP-329 RCC：鲁棒契约校准（均值 + CVaR + 角点硬约束）
class RCC:
    def calibrate(self, env, receipts, budget):
        def score(c):
            L = mean(loss(c, th) for th in env.sample())
            cv = cvar_loss(c, env, alpha=ALPHA_ROB)
            worst = max(loss(c, th) for th in env.corners)
            return L + LAMBDA_ROB * cv + LAMBDA_CPLX * complexity(c), worst, L
        c, worst, L = argmin_verified(score, space=CONTRACTS, guard=shield)
        if worst > EPS_CORNER:
            return None                             # ⊥：退回名义契约
        return c, DRCert(env, L, cvar_loss(c, env), worst, self.heldout(c))

# IP-330 SCC：支撑覆盖证书（只读审计/真实回执）
class SCC:
    def certify(self, real, env):
        d  = two_sample_distance(real.sample(), env.sample())
        rho = max(knn_distance(x, env.theta) for x in real.anchors)
        lam = density_ratio_upper(real, env, clip=1e3)
        if d > TAU_SUP or rho > RHO_SUP or lam > LAMBDA_MAX:
            return None                             # ⊥：关闭 DR，迁移界作废
        return SupportCert(d, rho, lam, beta_out=estimate_out_mass(real, env))

# IP-331 CLS：课程调度（promotion / demotion / pacing）
class CLS:
    def next_task(self, history):
        k = history.stage
        if self.can_promote(k, history):
            k = min(k + 1, K_MAX)
        elif self.must_demote(k, history):
            k = max(k - 1, 1)
        s = sample_task(D[k], history, pace=RHO[k])
        return k, s

    def can_promote(self, k, h):
        return (h.audit_lower[k] >= 1 - ALPHA
                and h.delta_rob[k] > 0
                and h.forgetting[k] <= ETA_REP
                and h.drift[k] <= ETA_DRIFT)

# IP-332 CSA：独立审计流 + 任意时间有效置信序列
class CSA:
    def observe(self, k, s, receipt):
        if receipt.source == "audit":               # 调度器不可写
            self.A[(k, s)].append(receipt)
            self.cs[(k, s)].update(coverage(self.A[(k, s)]))

    def lower(self, k, s):
        if len(self.A[(k, s)]) < N_MIN:
            k, s = (k, GLOBAL) if len(self.A[(k, GLOBAL)]) >= N_MIN else (GLOBAL, s)
        return self.cs[(k, s)].lower()               # L_t，任意停时有效

# IP-333 ARB：反遗忘回放（reservoir + 遗忘约束）
class ARB:
    def forgetting(self, c_new, old):
        sample = self.reservoir.sample(M_REP)
        return max(risk(c_new, sample, j) - risk(old[j], sample, j)
                   for j in range(len(old)))

    def accept(self, c_new, old):
        return self.forgetting(c_new, old) <= ETA_REP

# IP-334 FEX：强制前沿探索 + 失败二分
class FEX:
    def next_radius(self, h):
        if h.steps_since_frontier >= T_FRONTIER:
            return min(h.r + DR_STEP, R_MAX)         # 强制尝试下一半径
        return h.r

    def on_failure(self, r, r_next):
        return (r + r_next) / 2                       # 二分回退

# IP-335 CurriDR-9C 闭环
def curridr_9c(M, s, ell):
    out  = M.nlib.ground(ell, M.scene, M.ontology)
    iota = out[0] if out else M.default_iota          # I
    H    = M.lbox.hypothesize(s, M.dbox.R[s], iota)   # H
    k, task = M.cls.next_task(M.history)              # C_cl
    if M.cls.fallback:
        k, task = 0, s                                # 退化 uniform
    env = M.dre.envelope(task, M.budget_left(s))      # R
    if M.scc.certify(M.audit_real, env) is None:
        env = M.dre.nominal(task)                     # ⊥ ⇒ 名义包络
    c = M.rcc.calibrate(env, M.receipts[k], M.budget_left(s))
    if c is None:
        c = M.nominal_contract(task)                  # ⊥ ⇒ 名义契约
    C = M.iac.plan_chunk(iota, H, M.tools, M.budget_left(s), M.drift_bound(s))
    if not M.tcv.verify(C.as_program(), M.budget_left(s))[0]:
        C = M.numeric_fallback(H)                     # C_chunk
    cert = M.cvc.commit(C, M.env, iota)               # E + C_cvc
    receipts = cert.receipts
    if len(receipts) < n_min(s):
        return stub_and_red(s, "insufficient")        # V
    if not M.arb.accept(c, M.old_contracts):
        return stub_and_red(s, "forgetting")          # V
    if M.csa.lower(k, stratum(iota)) < 1 - ALPHA:
        return stub_and_red(s, "audit")               # V
    new_ec = M.apcal.update_contract(M.dpe, c, receipts, s)
    if not contract_regression(new_ec):
        return stub_and_red(s, "regression")          # V
    M.mreg.hot_replace_at_quiescence(M.dpe, new_ec, cert.boundary)  # U
    M.history.record(k, task, cert, M.csa, M.arb, M.fex)
    return True

# IP-336 主闭环（50Hz 路径不变；仅替换异步 dispatch）
def CurriDR_round(M, obs, audio, tac, depth, det, ell=None):
    M.repair_dispatch = curridr_9c                     # 未设置即 InstructGauge 的 7C
    return InstructGauge_round(M, obs, audio, tac, depth, det, ell)
```

## 4. 推导

**引理 59（域随机化迁移界）** 设 `ℓ(c;θ) ∈ [0,1]`，`P_real` 为真实环境分布，`P_φ` 为随机化分布，`ε_TV = TV(P_real,P_φ)`。则对任意契约 `c`：
`|R_real(c) − R_φ(c)| ≤ 2 ε_TV`。
若 `P_real(Θ_φ) ≥ 1−β_out`，且 `dP_real/dP_φ ≤ Λ` 于 `Θ_φ`，则
`R_real(c) ≤ (1−β_out)·Λ·R_φ(c) + β_out`。
*证明骨架*：TV 定义给出有界函数期望差的上界 `2TV`；把 `R_real` 拆成包络内/外，包络内用似然比换测度，包络外因 `ℓ≤1` 直接界为 `β_out`。推论：`SCC=⊥` 时两界均不可用，DR 的「鲁棒」必须退回名义契约；DR 不是安全保证，只是带支撑假设的迁移声明。

**引理 60（角点集保真与 ε-网复杂度）** 设 `Θ_φ` 紧、`ℓ(c;·)` 为 `L`-Lipschitz、`S_φ` 为 `Θ_φ` 的 ε-网。则
`|max_{θ∈Θ_φ} ℓ(c;θ) − max_{θ∈S_φ} ℓ(c;θ)| ≤ L·ε`。
若 `Θ_φ` 为多面体且 `ℓ(c;·)` 凸，则最大值在顶点取得，取 `S_φ=vertices` 时误差为 0；若 `ℓ` 非凸/凹，则 ε-网只给可审计的下界与显式间隙。复杂度 `|S_φ| = O((R L/ε)^d)`；`d≤6` 可行，`d>d_max` 时改用随机多起点梯度上升的角点挖掘并报告经验间隙。*证明*：任意 `θ` 取最近网点的 Lipschitz 界；凸函数在多面体上的最大值在极点。推论：`L_corner` 是可审计的有限代理，间隙必须写入 `DRCert`，不能隐去。

**引理 61（课程样本复杂度与正迁移）** 在定义 459 的分层高斯模型下，易任务 `n_e` 条后共享参数后验方差 `v_e = τ²σ_e²/(n_eσ_e²+τ²)`。难任务达到 MSE `ε` 所需样本
`n_h(ε) = Θ((v_e(1−κ_trans)+σ_h²)/ε²)`。
故 `κ_trans>0` 时 `n_h` 随 `n_e` 单调下降；`κ_trans≤0` 时课程无收益甚至负迁移，应回退 `π_unif`。*证明*：高斯共轭给出后验方差；难任务的有效先验方差为 `v_e(1−κ_trans)+σ_h²`；标准参数估计 minimax 率给出样本复杂度。推论：课程准入必须在独立审计流上估计 `κ_trans`，不能假设「易⇒难」总是有益；E461 专测负迁移。

**引理 62（自适应采样下的任意时间有效覆盖）** 若审计集 `A_{k,s}` 与调度器所用 `C_cal^{k,s}` 不相交，且 `(L_t,U_t)` 满足 `P(∀t: R_{k,s} ∈ [L_t,U_t]) ≥ 1−α`，则对任意由 `π_cl` 诱导的停时 `τ`，
`P(R_{k,s} ∈ [L_τ,U_τ]) ≥ 1−α`；
若审计集被重复用于校准，则保证退化为 `1−α·#looks`（或必须做数据分割）。*证明*：任意时间有效性对停时封闭（optional stopping）；独立性保证审计样本分布不随调度器选择而变。推论：**课程不能用自己的校准集自证**；独立审计流是本轮结构设计的核心，E462/E463 专门证伪。

**引理 63（反遗忘回放界）** 设 `B_rep` 为过去各阶段审计集的 reservoir 样本（大小 `m`），遗忘度量 `F_k` 如定义 457。若在 `B_rep` 上 `F_k ≤ η_rep`，则以概率 `1−δ`
`F_k^true ≤ η_rep + O(√(log(1/δ)/m)·range)`。
*证明*：对每个阶段的风险差用 Hoeffding 不等式并取并集界；reservoir 给出无偏样本。推论：回放不消除遗忘，只把遗忘压到 `η_rep + 采样误差`；`η_rep` 必须与阶段数 `K` 联合设定，否则「反遗忘」只是换个地方遗忘。

**引理 64（强制前沿的停止误差）** 设真实最大安全半径 `r*`，风险关于 `r` 单调；每次前沿尝试的审计检验对坏契约的漏检概率 `≤ β_f`。采用几何扩张 + 失败二分，则认证半径 `r̂` 满足
`P(r̂ < r* − ε) ≤ β_f·O(log(R_max/ε))`，
尝试次数 `O(log(R_max/ε))`。*证明*：到 `r*` 前每次尝试是一次独立检验，漏检需连续发生；并集界给出上述概率；二分每步减半区间。推论：`T_frontier` 与 `β_f` 是「课程自证」风险的显式旋钮；`T_frontier=∞` 退化为无强制探索，本引理不成立。

**引理 65（严格退化等价）** 当 `Θ_φ={θ₀}`、`P_φ=δ_{θ₀}`、`S_φ={θ₀}`、`π_cl=π_unif`、`A_k=∅`（审计关闭）、`B_rep=∅`、`T_frontier=∞` 时，CurriDR-9C 与 InstructGauge-7C 逐指令等价；再令指令不可接地或分块退化，依次等价于 ToolGauge-6C、LeanGauge、MODGAUGE 原样。*证明*：逐项代入定义 448–462：DR 目标退化为名义损失，课程选择退化为均匀，SCC 与审计为空操作，9C 去掉 `C_cl` 与 `R` 两相后即 7C；`DRCert/CLCert` 字段均为纯投影。推论：新组件是增强项，不是依赖项。

**引理 66（决策开销与 50Hz 保全）** DR 集成的异步开销 `O(|S_φ|·d)` 每次校准；课程打分 `O(|B| log |B|)` 每阶段；审计更新 `O(log t)` 每条回执；回放 `O(m)` 每次更新；前沿尝试 `O(log(R_max/ε))` 次。主循环新增仅两个异步钩子的提交开销，实测 `<0.2ms`；热替换仍只在 `q_quiesce`，继承 InstructGauge 引理 57/58 与 ToolGauge 引理 50。*证明*：所有新增计算都在异步 worker，主路径只做一次 dispatch；关键路径长度与 `|S_φ|, m, K` 无关。推论：DR/CL 的规模只影响后台延迟，不影响 50Hz 硬实时。

| 安全（E469） | 违规 = 0，降级触发 100% | 视为设计级失败，关闭 DR/CL |
| 时序（E470） | 新增 < 0.2ms | 异步下沉或缩短 `N_DR/K_max` |
| 系统（E467/E471） | real 退化 ≤ 10% | 回退 InstructGauge / ToolGauge |

预期：E457/E459/E462/E463/E469/E472 为「结构/统计级」判据，应严格成立或给出显式间隙；E458/E460/E461/E464/E465/E471 为「效应量级」判据，按置信区间验收；E467 为「系统级」判据，报告相对基线效应量与 95% CI。

## 8. 本轮最大风险

**一句话**：`CLS` 与 `DRE` 共同决定了「系统看到的世界」——课程挑选证据、包络定义环境，因此最大的风险是**自证偏差 + 包络外推**：系统可能在自己挑选的简单证据和自己定义的包络内证明自己鲁棒，而真实 `θ*` 在包络之外或在前沿尚未探索的角点上；`SCC`、独立审计、任意时间有效界、强制前沿与严格退化只能降低、不能消除这一残余风险，必须以 E457/E462/E463/E464/E472 主动证伪。
