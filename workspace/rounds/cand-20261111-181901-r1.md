# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「分层规划」×「交互设计」）

> 第 54 轮把技能组合推进到动作-鲁棒性双证书（ACS/SCOM/CEC/AEC/JTC）。本轮引入两个新维度：**分层规划**（抽象-细化树与证书的跨层传递）与**交互设计**（把「人」提升为规划中的一等参与者）。核心矛盾：H22：高层计划的证书在低层细化时会因抽象鸿沟而失效，证书不能简单 copy 传递；H23：交互把人的意图、监督窗口与信任状态引入闭环，而人的意图不可观测且会漂移，机器人侧的「可读性/可撤销性」承诺与任务最优性相互拉扯。

## 0. 直觉与动机

**灵感 1（分层规划 → 计划是一棵带证书的抽象-细化树）**
直觉：真实长程任务不是一条扁平的最优路径，而是一棵计划树 𝒯：根是用户意图，中层是子目标/技能，叶是可执行动作。每一层都应带自己的证书，父层证书是子层证书的**抽象**（上投影），子层必须**细化**父层的承诺。证书传递不是复制，而是沿细化边做**保守投影**：`T_↑(C_child) ⊑ C_parent`。这把第 53/54 轮的鲁棒性与动作证书从「单层」拉升为「跨层可组合」。

**灵感 2（分层规划的经典陷阱 → 抽象鸿沟与反例引导的细化修正）**
直觉：抽象层为了可解性会抹掉几何、时序、资源细节；于是高层「可行」的计划在细化后可能不可行（downward refinement failure）。这不是 bug，而是抽象的本质代价。关键是把鸿沟**显式证书化**：`gap(v)=d(C(v), T_↑(⊔C_child))`，超过 ε_abs 就必须由低层反例驱动**抽象修正**，而不是整棵重规划。这与第 54 轮 Explain 回传天然对接：反例不只用来重选技能，更用来**收紧抽象**（CEGAR 式）。

**灵感 3（交互设计 → 人是规划中的一等参与者，不是环境扰动）**
直觉：交互设计最容易被误做成「加个界面/加句提示」。真正的一等公民是：**人也有自己的抽象层与意图**，并且能与系统同时提议、修改、否决。于是引入**双向动作空间**与**交互契约** `I=(O_r,O_h,W_sup,B_corr,Ξ)`：机器人承诺可读、可中断、可撤销、诚实报告置信；人承诺在监督窗口内监督、在纠错预算内纠正、不侵入安全区。契约不是礼貌规范，而是证书可部署性的一个合取项。

**灵感 4（交互设计 → 可读性/可预期性/可撤销性作为硬约束）**
直觉：一个计划「成功」不等于「可被接受」。人可以容忍偶尔失败，但难以容忍不可理解与不可挽回。于是把可读性 `leg`（观察前缀后对目标的推断集中度）、可预期性 `pred`（下一步动作与人类预期的偏差）、可撤销性 `rec`（回到安全可逆状态的最坏代价）纳入 `L_cert`，并要求它们在每一层都满足阈值。可撤销性尤其重要：它把「交互中的错误」从不可逆事故降级为可恢复的分支。

**灵感 5（混合主动 → 仲裁、交互预算与信任校准）**
直觉：交互不是「人下命令」或「机器全自动」的二选一，而是一个**混合主动**状态机：propose / confirm / intervene / abort。人和机器都可能发起。需要两个预算：**交互预算 β_int**（打扰次数/注意力）与**纠错预算 B_corr**；还需要一个随结果更新的**信任状态 σ_trust**，并显式证书化「过度信任风险」——过度信任（overtrust）在交互系统里和鲁棒性失败同样致命，因为它会让监督窗口事实上失效。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（分层计划树）**
分层计划树 `𝒯=(V,E,ℓ,ρ,C)`：`ℓ(v)∈{L_intent,L_task,L_motion}` 为抽象层，`C(v)` 为节点证书（承接第 53/54 轮 ρ 与 A_cert），分解边 `(v,{v_1..v_k})∈E` 表示 v 由子序列细化。根为意图节点 `v_root=L_intent`，叶为可执行动作。计划可行当且仅当 `∀ leaf, cover(...)=1` 且所有内部节点满足细化健全性（定义 122）。

**定义 122（细化健全性与证书传递）**
细化 `v ⇝ {v_1,...,v_k}` 带细化证书 `R=(pre,post,res,dl)`，健全当且仅当：
```
pre(v) ⇒ pre(v_1) ∧ post(v_k) ⇒ post(v) ∧ res(Σv_i) ≤ res(v) ∧ dl(Σv_i) ≤ dl(v)
```
证书抽象算子 `T_↑` 与具体化算子 `T_↓` 满足 Galois 连接 `α ⊣ γ`：`C_parent ⊒ T_↑(C_child)` 且 `T_↓(C_parent) ⊒ C_child`（保守过近似）。**证书传递 sound** 当且仅当 `⟦C_child⟧ ⊆ γ(⟦C_parent⟧)`。

**定义 123（抽象鸿沟）**
节点 v 的抽象鸿沟 `gap(v) = d( C(v), T_↑(⊔_{u∈child(v)} C(u)) )`。分层计划 `h-sound` 当且仅当 `∀v, gap(v) ≤ ε_abs` 且叶层可执行。鸿沟不是普通误差，而是**可诊断信号**：`gap` 大的节点优先触发抽象修正或反例采集。

**定义 124（交互契约）**
`I=(O_r,O_h,W_sup,B_corr,Ξ)`：
- `O_r`：机器人承诺 `{legible, interruptible, reversible, honest_confidence}`；
- `O_h`：人类承诺 `{supervise within W_sup, correct within B_corr, respect safety zone}`；
- `W_sup` 监督窗口（人可响应的时窗/注意力），`B_corr` 纠错预算（次数/时延）；
- `Ξ` 仲裁协议：`propose→confirm→execute | intervene→abort/replan | abort→safe_revert`。
契约满足当且仅当在人遵守 `W_sup,B_corr` 时，`O_r` 四项在每个执行前缀上成立。

**定义 125（可读性证书）**
`L_cert=(leg,pred,rec,τ_read)`：
- `leg = P(g* | 观察前缀 o_{1:t})` 的集中度（top-1 后验或负熵）；
- `pred = D_KL( P_h(a_{t+1}|o_{1:t}) ‖ π(a_{t+1}|o_{1:t}) )`；
- `rec`：从任意可达状态回到安全可逆集的最坏步数/时间；
- `τ_read`：人完成一次意图识别的时窗。
可部署条件：`leg≥θ_leg ∧ pred≤θ_pred ∧ rec≤τ_rec` 在每层均成立。

**定义 126（混合主动仲裁与信任校准）**
仲裁函数 `arb:(P_r,P_h,σ_trust,β_int)→{accept,confirm,ask,reject}`，其中 `P_r/P_h` 为机器/人提议。信任状态更新 `σ_trust' = clip(σ_trust + η·(outcome - E[outcome]), 0, 1)`。校准证书 `K_trust=(over,under,cal_err)`：`over` 为过度信任风险（声明置信 > 真实可靠度且人未监督），`under` 为欠信任成本，`cal_err` 为置信-可靠度校准误差。要求 `cal_err≤ε_cal` 且 `over=0` 时方可降低监督强度。

## 2. 关键算法 伪代码

### IP-121 HPT（Hierarchical Plan Tree）
```python
def build_plan_tree(intent, htn_lib, cert_lib, eps_abs):
    root = Node(level='intent', cert=cert_lib[intent])
    frontier = [root]
    while frontier:
        v = frontier.pop()
        if v.level == 'motion' or is_executable(v):
            continue
        subs = htn_lib.decompose(v)          # 子目标序列
        children = [Node(level=down(v.level), cert=cert_lib[s]) for s in subs]
        v.children = children; frontier += children
        if gap(v, children) > eps_abs:       # 早停，交反例引导修正
            v.needs_refine = True
    return root
```

### IP-122 ARC（Abstraction-Refinement Certificate）
```python
def certify_tree(root, T_up, eps_abs, eps_gap):
    order = postorder(root)
    for v in order:
        if not v.children:
            v.cert_ok = leaf_executable(v)
        else:
            agg = join([c.cert for c in v.children])
            v.cert_abs = T_up(agg)
            v.cert_ok  = leq(v.cert_abs, v.cert) and refinement_sound(v)
            v.gap      = dist(v.cert, v.cert_abs)
            if v.gap > eps_abs:
                v.cert_ok = False
                v.repair_hint = argmin_subtree(v.gap)   # CEGAR 修正锚点
    return root, all(node.cert_ok for node in order)
```

### IP-123 ICE（Interaction Contract Enforcement）
```python
def enforce_contract(tree, human, I):
    for prefix in execution_prefixes(tree):
        if not legible(prefix, human) and not within(human, I.W_sup):
            return ('violate', 'legibility', prefix)      # 契约破裂，降级
        if not interruptible(prefix) or not reversible(prefix):
            return ('violate', 'reversibility', prefix)
        if human.corrections > I.B_corr:
            return ('degrade', 'human_budget_exhausted')
    return ('ok', monitor_trust(human))
```

### IP-124 LGC（Legibility Certificate）
```python
def legibility_cert(tree, human_model, A):
    leg  = goal_posterior_concentration(tree, human_model)
    pred = kl_divergence(human_model.next_action(), tree.policy)
    rec  = worst_case_time_to_safe_revert(tree, A)
    ok = leg >= THETA_LEG and pred <= THETA_PRED and rec <= TAU_REC
    return L_cert(leg, pred, rec, tau_read=TAU_READ), ok
```

### IP-125 MIA（Mixed-Initiative Arbitration）
```python
def arbitrate(P_r, P_h, sigma, beta_int):
    if P_h is not None and conflicts(P_r, P_h):
        return 'confirm' if sigma < SIGMA_LOW else 'ask'
    if beta_int.exhausted():
        return 'accept' if P_r.risk <= RISK_MAX else 'reject'
    if P_r.risk > RISK_HIGH and sigma > SIGMA_HIGH:
        return 'confirm'          # 过度信任时强制确认
    return 'accept'
```

### IP-126 TCC（Trust Calibration Certificate）
```python
def trust_calibrate(sigma, declared, realized, human, W_MIN, EPS, EPS_CAL, ETA):
    cal_err = abs(declared - realized)
    over    = (declared > realized + EPS) and (human.supervision < W_MIN)
    sigma   = clip(sigma + ETA * (realized - declared), 0, 1)
    if over or cal_err > EPS_CAL:
        return ('recalibrate', K_trust(over=over, cal_err=cal_err), sigma)
    return ('ok', K_trust(over=False, cal_err=cal_err), sigma)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| HPT | O(|V|·b + |A|) | O(|V|) | 分解完备、叶可执行 |
| ARC | O(|V|·|C|) | O(|V|+|C|) | T_↑ 保守、细化健全 |
| ICE | O(|P|·|Ξ|) | O(|P|) | 契约四项逐前缀可判 |
| LGC | O(H·|A|) | O(H+|A|) | 人模型校准、可撤销集可达 |
| MIA | O(|Ξ|) | O(1) | 仲裁确定、预算单调 |
| TCC | O(1)/步 | O(1) | 校准误差有界、过度信任可检 |

**正确性定理（Hierarchical-Interaction Soundness）**
在 (A26)–(A28) 之上新增：**(A29)** `T_↑` 为保守过近似且细化健全；**(A30)** 人类在 `W_sup,B_corr` 内行动，契约 `I` 被遵守；**(A31)** 人模型校准误差 `ε_H ≤ ε_cal`；**(A32)** 叶层动作可达安全可逆集。
则对分层计划 `𝒯`：
```
P(success ∧ safe ∧ accepted) ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(gap>ε_abs)
                              - P(contract violated) - ε_H
```
其中 `accepted` 表示人未否决且信任未过度。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 抽象鸿沟在交互压力下放大 | 高 | 保守过近似 + CEGAR 修正 + gap 预算 |
| 人的意图漂移/不可观测 | 高 | 在线意图估计 + 可撤销优先 + 定期再确认 |
| 过度信任导致监督失效 | 高 | 信任校准证书 + 强制确认 + 能力自报告 |
| 交互预算耗尽导致体验崩塌 | 中 | 分级打扰策略 + 静默降级 + 事后解释 |
| 分层树规模爆炸 | 中 | 分支限界 + 证书缓存 + 抽象哈希 |
| 可读性优化牺牲任务最优性 | 中 | 可读性作为软约束 + Pareto 前沿选择 |

## 6. 本轮最大风险

**一句话**：分层规划让证书可跨层传递、交互设计让人成为一等参与者，但二者叠加产生了**双重抽象泄漏**——上层的抽象鸿沟与下层的人意图漂移会同时发生，而最危险的假设是把人的意图当成可形式化的静态契约；一旦人提前介入、疲劳或过度信任，最严谨的分层证书也会在交互中变成「合法的错误」，故必须以 **在线意图估计 + 可撤销性优先 + 显式信任校准 + 保守抽象** 四重护栏，宁可多问一次，绝不把人当成可证书化的确定性组件。

def arbitrate(P_r, P_h, sigma, beta_int):
    if P_h is not None and conflicts(P_r, P_h):
        return 'confirm' if sigma < SIGMA_LOW else 'ask'
    if beta_int.exhausted():
        return 'accept' if P_r.risk <= RISK_MAX else 'reject'
    if P_r.risk > RISK_HIGH and sigma > SIGMA_HIGH:

### IP-126 TCC

```python
def trust_calibrate(sigma, declared, realized, human, W_MIN, EPS, EPS_CAL, ETA):
    cal_err = abs(declared - realized)
    over    = (declared > realized + EPS) and (human.supervision < W_MIN)
    sigma   = clip(sigma + ETA * (realized - declared), 0, 1)
    if over or cal_err > EPS_CAL:
        return ('recalibrate', K_trust(over=over, cal_err=cal_err), sigma)
    return ('ok', K_trust(over=False, cal_err=cal_err), sigma)
```

## 5. 本轮最大风险

**一句话**：分层规划让证书可跨层传递、交互设计让人成为一等参与者，但二者叠加产生了**双重抽象泄漏**——上层的抽象鸿沟与下层的人意图漂移会同时发生，而最危险的假设是把人的意图当成可形式化的静态契约；一旦人提前介入、疲劳或过度信任，最严谨的分层证书也会在交互中变成「合法的错误」，故必须以 **在线意图估计 + 可撤销性优先 + 显式信任校准 + 保守抽象** 四重护栏，宁可多问一次，绝不把人当成可证书化的确定性组件。
