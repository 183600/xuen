# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「多模态大模型」×「因果推理」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**因果化信任域 + 多模态语义接地 + 严格隔离**。两个灵感共同治理 v9 最大的债：v9 的信任域 U_t 与块证书 Ĉ_t 都建立在**关联性**上——Δ_dom 是分布距离，F̂ 是关联预测。关联在分布内有效，在机制改变时失效，而机制改变恰恰是安全最关键的时刻。因果推理把「分布偏移」升级为「机制偏移 vs 滋扰偏移」的可识别分解；多模态大模型提供语义因果变量与候选图的先验。但 MLLM 高延迟、会幻觉、不可实时，因此必须**异步旁路 + 数据证伪 + 中立元退化**，任何一环不可用都严格退回 v9。

## 0. 直觉与动机

**灵感 1（因果推理 → 信任域的因果化）**
直觉：v9 问「当前观测离训练分布多远」（Δ_dom），但真正决定安全的是「我的动作对安全指标 M₀ 的因果效应是否变了」。灯变暗、纹理变化是滋扰偏移，P(M₀|do(a)) 不变，不该缩块；人从门后出现、地面变滑是机制偏移，P(M₀|do(a)) 变了，必须缩块。v9 用同一个标量 Δ_dom 把两者混为一谈：既会因无害外观变化误降级（算力浪费与抖动），又会因 Δ_dom 的 20 帧滑窗滞后而漏检真实机制偏移（v9 已声明的最大风险）。核心创新：**因果偏移判别器（CausalShiftDiscriminator, CSD）**，用 do-演算把 Δ_dom 分解为 Δ_mech（机制偏移）与滋扰残余，并用**因果支持度 CS**（positivity × 图置信 × 机制稳定）替代 Δ_dom 直接门控 K_eff 与 β。

**灵感 2（多模态大模型 → 语义因果接地，而非控制器）**
直觉：因果推断需要变量与因果图，而机器人在陌生家庭里恰恰不知道「哪些物体/人/意图是安全指标的原因」。MLLM 擅长从图像 + 语音 + 本体状态中提出语义变量（「半开的抽屉」「正在靠近的人」「湿滑地面」）与候选因果边。但 MLLM 延迟 0.2–2s、会编造边、输出不可微，绝不能进 50Hz 控制回路。核心创新：**多模态因果接地器（MultimodalCausalGrounder, MCG）**：1Hz 异步生成带类型的因果场景图候选 G^LLM（节点、边、自然语言理由、置信度），每条边必须通过日志上的条件独立性检验（e-value + e-BH 控制 FDR）才允许进入系统因果模型；图带版本与时效，超过 T_stale 置信度衰减到 0。**MLLM 只提议，数据才裁决（LLM proposes, data disposes）。**

**灵感 3（两者交汇 → 反事实块证书）**
直觉：v9 的块证书 Ĉ_t = F̂ 关联 rollout。因果化后可做**反事实 rollout**：在已识别 SCM 下对 do(a^{1:K}) 求最坏结构响应，并用分层 conformal 给出有限样本覆盖。核心创新：**反事实块证书器（CounterfactualChunkCertifier, CCC）**，是 IP-354 的升级：β 不再是常数 β₀，而是 β₀/CS（CS→0 时证书无解，自动退回 K=1）；证书按后门集分层校准，使覆盖保证从「同分布」扩展到「同因果层」。这直接回应 v9 风险：在机制偏移被 Δ_dom 发现之前，CS 已因 positivity 崩塌或机制不稳定而收缩骨架。

## 1. 研究问题（轮次升级版）

- **Q1（因果门控的可证优势）**：在什么图充分性假设下，因果支持门控在同等块长下的证书误差不劣于 v9 的 Δ_dom 门控，且对滋扰偏移的误降级与对机制偏移的漏检同时下降？
- **Q2（MLLM 隔离与幻觉治理）**：如何把高延迟、会幻觉、跨模态不一致的 MLLM 限制为「只提议变量与边」的先验，并以 anytime-valid CI 检验与时效衰减保证其不进入实时安全路径？
- **Q3（机制偏移下的证书覆盖）**：分层 conformal + 反事实 rollout 能否在机制偏移（而非仅协变量偏移）下维持 1−α 覆盖，或至少给出可检测的覆盖失效信号？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 因果支持域律（Causal-Support Domain, CMC）**
块证书有效当且仅当查询动作位于因果支持域：CS_t(a) ≥ τ_CS 且机制偏移 Δ_mech(t) < τ_mech。有效块长
```
K_eff = 1                                        若 Δ_mech ≥ τ_mech ∨ risk_SLAM ≥ τ_SLAM
      = max(1, ⌊K_max·CS_t·(1 − min(1, Δ_mech/τ_mech))⌋)   否则
```
证书余量 β(CS) = β₀ / max(CS, ε)，CS=1 时严格等于 v9 的 β₀。

**P14 多模态接地即先验律（LLM-Proposes-Data-Disposes, MCG）**
MLLM 的输出只允许是「候选」：候选节点、候选边、候选后门集与自然语言理由。每条边必须通过条件独立性检验的 e-value 并经 e-BH 过滤（FDR ≤ q）才可入图；MLLM 不得直接产生动作、阈值或安全结论。多模态不一致（视觉-语音-本体冲突）降低边置信，而非跨模态平均化抹平冲突。

**P15 因果降级同态律（Causal-Degradation Homomorphism, CSD）**
因果层的「中立元」不是零，而是 **v9 的观测算子**：MCG 失效 ⇒ G := ∅；CSD 失效 ⇒ (Δ_mech, CS) := (Δ_dom, 1)；CCC 失效 ⇒ β := β₀。三者同时失效时，v10 的门控、证书与主闭环**逐项退化为** v9 ACMD（不是行为相似，而是公式逐项相同）。

## 3. 与基线的接口（如何退化）

- MCG 失效 / 超时 / 图过期 ⇒ G^⊥=∅，后门集退化为空集，do-效应退化为条件期望，Δ_mech 退回 Δ_dom；
- CSD 失效 ⇒ Δ_mech := Δ_dom、CS := 1，β := β₀，严格等价 v9 的 AC 门控；
- CCC 失效 ⇒ 使用 v9 的 F̂ 关联 rollout + 常数 β₀；
- v9 的 AC/MW/ID 再失效 ⇒ 按 v9 五级链退回 v8/v7/v6；
- 全部失效 ⇒ 完整退回 MetricVoiceGauge-ACMD v9，再退回 v8 与更早基线。

## 4. 预期贡献

1. **因果信任域**：把「分布离得多远」升级为「机制变了没有」，给出滋扰/机制偏移的可识别分解与支持度门控；
2. **MLLM 的安全旁路范式**：高延迟大模型只做语义因果先验，CI 证伪 + FDR + 时效衰减三道闸，实时回路零阻塞、失效严格退化；
3. **反事实分层证书**：把块证书的覆盖保证从同分布推广到同因果层，并给出机制偏移下覆盖失效的可检测信号；
4. **因果自省**：用中介感知的因果归因升级 v9 的消融蒸馏，避免奖励「只影响滋扰」的模块。

## 5. 本轮最大风险

**一句话**：因果推断的可靠性以「因果图充分性（后门集无未观测混杂）」为前提，而 MLLM 的因果图恰在最陌生、最危险的场景里最可能漏掉关键混杂变量（被遮挡的人、反光地面、延迟出现的宠物）；一旦漏边，do-校正会给出自信但错误的「高因果支持」，反而放大 K_eff 并缩小 β——系统在最需要保守的时刻以最大块长执行最不可靠的证书，比 v9 的保守滞后更危险。

## 1. 符号体系增量（定义 540–549）

| 符号 | 含义 |

| Pa_m | 模块 m 的因果后门集（观测到的混杂变量集） |
| β(CS) | 支持度相关证书余量，β(1)=β₀ |
| α, T_stale | conformal 误覆盖水平、图时效上界 |
| ρ(τ) | 图新鲜度衰减：max(0, 1−τ/T_stale) |

**新增定义 540（类型化因果场景图 Typed Causal Scene Graph）** 一个 SCM 骨架 G_t=(V,E,θ)，V 为带类型与时空锚点的变量（物体 o、人 h、意图 ι、地面 g、机器人状态 S、动作 A、指标 M），E 为有向边且按时间展开后无环，θ 为机制参数。每条边 e 携带置信 γ_e∈[0,1] 与证据计数。G_t 由 G^LLM 经定义 541 的证伪过滤后得到。

**新增定义 541（边级证伪与 e-BH Edge Falsification）** 对候选边 e: X→Y，给定候选后门集 Z_e，检验 H_e: X ⫫ Y | Z_e。由日志流构造 anytime-valid e-value e_e（似然比/下注鞅），在水平 q 下用 e-BH 选取入图边：
```
E_admit = e-BH({e_e : e ∈ E_cand}, q)
```
未被拒绝独立性的边不得入图。MLLM 的置信 γ_e 只作为检验的先验权重，不能替代检验。

**新增定义 542（机制偏移 vs 滋扰偏移 Mechanism vs Nuisance Shift）** 源域 d_s、目标域 d_t。机制偏移
```
Δ_mech(t) = sup_{a ∈ A_feasible} | Ê_{d_t}[M₀ | do(a)] − Ê_{d_s}[M₀ | do(a)] |
```
其中 do-效应用后门调整估计：E[M₀|do(a)] = Σ_{z∈Pa(A)} E[M₀|a,z]·P(z)（或双稳健估计）。若对一切 a 有 P_t(M₀|do(a)) = P_s(M₀|do(a)) 而 P_t(V) ≠ P_s(V)，称纯滋扰偏移——它改变 P(V) 但不改变安全机制，不应缩块。若偏移作用于 M₀ 的祖先机制并改变 do-效应，称机制偏移，必须缩块。v9 的 Δ_dom 是两者的不可分混合。

**新增定义 543（因果支持度 Causal Support）**
```
CS_t(a) = clip( min{ O_t(a), Γ_t, 1 − Δ_mech(t)/τ_mech }, 0, 1 )
```
O_t(a) 为 positivity/重叠度（目标域中 do(a) 的倾向得分有效样本比 ess_t(a)/n_min，截断到 1）；Γ_t = ρ(t−t_G)·min_{e∈E} γ_e 为图置信（含时效衰减与多模态冲突惩罚）；第三项为机制稳定度。CS→0 表示该动作的因果效应不可识别或不可信。

**新增定义 544（因果门控有效块长 Causal-Gated Effective Chunk）**
```
K_eff(t) = 1                                                   若 Δ_mech(t) ≥ τ_mech ∨ risk_SLAM ≥ τ_SLAM
         = max(1, ⌊K_max·CS_t·(1 − min(1, Δ_mech(t)/τ_mech))⌋)  否则
```
令 CSD 中立：Δ_mech:=Δ_dom、CS:=1、τ_mech:=τ_dom，则此式逐项等于 v9 定义 539。滋扰偏移下 Δ_mech≈0、CS 高，故不误缩；机制偏移下 Δ_mech 抬升且 CS 下降，双重收缩。

**新增定义 545（反事实块证书与分层 conformal Counterfactual Chunk Certificate）** 对候选 a^{1:K}，在 G_t 上做结构反事实 rollout，并按后门集分层校准残差。对第 k 步与层 s=Pa(A_t)：
```
[L_k, U_k] = [ Q^{s}_{α/2}(M₀^{cf}_k),  Q^{s}_{1−α/2}(M₀^{cf}_k) ]
ĝ_min = min_{k≤K} (L_k − β(CS)),     ê_max = max_{k≤K} (U_k + β(CS))
```
证书有效 ⇔ ĝ_min ≥ d_safe ∧ ê_max ≤ τ_eff。层内交换性成立时，层内覆盖 ≥ 1−α；对 K 步取并集界得整体覆盖 ≥ 1−Kα。层级由 G_t 的 Pa(A_t) 给出，使保证从「同分布」变为「同因果层」。

**新增定义 546（支持度相关余量 Support-Dependent Margin）**
```
β(CS) = β₀ / max(CS, ε),   ε = 1e−3
```
β 关于 CS 单调不增，β(1)=β₀（v9 常数）；CS→0 时 β→∞，任何块都无法通过证书，自动 K_eff=1。β₀ 沿用 v9 E554 标定值。

**新增定义 547（图时效衰减与中立元 Graph Freshness & Neutral Element）** 图年龄 τ=t−t_G，ρ(τ)=max(0,1−τ/T_stale)，T_stale=2s。ρ 进入 Γ_t，故图过期只会降 CS、缩 K、放大 β。MCG 不可用或 G 为空时取 G^⊥=∅（无边、空后门集），此时 do-效应退化为观测条件期望，交由 Level-1/2 降级。

**新增定义 548（中介感知因果归因 Mediation-Aware Causal Attribution）** 对 φ^elig 模块 m，用 G_t 识别 m→Y 的中介集 Med(m)。定义总效应 TE_m = E[Y|do(m=on)] − E[Y|do(m=off)] 与直接效应 DE_m（固定 Med(m)）。ID 的贡献 c_m^cf 用 TE_m 判「是否值得算力」，用 DE_m 判「是否触及安全通路」：若 DE_m≈0 而 TE_m 高，说明模块只通过安全中介起作用，降级资格收紧。安全关键模块仍 φ^elig=false。

**新增定义 549（多模态冲突度 Multimodal Conflict）** 对节点/边 x，各模态证据给出后验 b_mod(x)，冲突度
```
δ_mm(x) = 1 − max_mod b_mod(x) + spread_mod b_mod(x)
```
γ_x ← γ_x·(1 − κ_c·δ_mm(x))。视觉-语音-本体冲突不被平均抹平，而是直接降低该边进入因果门的资格。

## 3. 关键算法骨架

```python
# IP-357 MultimodalCausalGrounder：异步、可证伪、带时效的语义因果先验
class MultimodalCausalGrounder:
    def __init__(self, mllm, ci_tester, q=0.1, T_stale=2.0, kappa_c=0.5,
                 min_edge_conf=0.2):
        self.mllm = mllm                 # 只提议，不裁决
        self.ci = ci_tester              # 日志上的 anytime-valid CI 检验
        self.q, self.T_stale = q, T_stale
        self.kappa_c, self.min_edge_conf = kappa_c, min_edge_conf
        self.G = TypedSCM.empty()        # G^⊥
        self.t_G = -1e9

    def update(self, obs_bundle, log_buffer, now):
        """非阻塞：主环只读 self.G；本函数在旁路线程 1Hz 调用"""
        proposal = self.mllm.propose_scene_graph(obs_bundle)     # 视觉+语音+本体
        candidates = []
        for e in proposal.edges:
            e.evalue = self.ci.e_value(log_buffer, e, cond=e.backdoor)
            e.gamma = self._fuse_modalities(e, proposal)          # 定义 549 冲突惩罚
            if e.gamma >= self.min_edge_conf:
                candidates.append(e)
        admitted = e_bh(candidates, q=self.q)                     # 定义 541，控 FDR
        self.G = TypedSCM(nodes=proposal.nodes, edges=admitted).fit(log_buffer)
        self.t_G = now
        return self.G

    def snapshot(self, now):
        """实时环唯一调用；O(|E|)，永不阻塞 GPU/网络"""
        rho = max(0.0, 1.0 - (now - self.t_G) / self.T_stale)
        if not self.G.edges or rho <= 0.0:
            return TypedSCM.empty()                               # 中立元 G^⊥
        return self.G.with_freshness(rho)


# IP-358 CausalShiftDiscriminator：把 Δ_dom 拆成机制/滋扰，并给因果支持
class CausalShiftDiscriminator:
    def __init__(self, estimator, tau_mech=0.15, tau_cs=0.2, eps=1e-3):
        self.est, self.tau_mech, self.tau_cs, self.eps = estimator, tau_mech, tau_cs, eps

    def decompose(self, G, source_data, target_data, actions):
        if G.is_empty:                                           # Level-1 降级
            return None, None
        eff_s = self.est.backdoor_do_effect(source_data, G, actions)   # Σ_z E[Z|a,z]P(z)
        eff_t = self.est.backdoor_do_effect(target_data, G, actions)
        delta_mech = max_abs(eff_t - eff_s)                      # 定义 542
        overlap = self.est.positivity_overlap(target_data, actions)    # ess/n_min
        graph_conf = G.min_edge_confidence()
        mech_stab = max(0.0, 1.0 - delta_mech / self.tau_mech)
        CS = clip(min(overlap, graph_conf, mech_stab), 0.0, 1.0) # 定义 543
        return delta_mech, CS

    def gate(self, delta_mech, CS, tau_dom, delta_dom, risk_slam, tau_slam, K_max):
        if delta_mech is None:                                   # CSD 失效 ⇒ v9 同态
            delta_mech, CS = delta_dom, 1.0
        if delta_mech >= self.tau_mech or risk_slam >= tau_slam:
            return 1
        return max(1, int(K_max * CS * (1.0 - min(1.0, delta_mech / self.tau_mech))))

    def margin(self, CS):
        return self.beta0 / max(CS, self.eps)                    # 定义 546


# IP-359 CounterfactualChunkCertifier：升级 v9 ActionChunkCertifier
class CounterfactualChunkCertifier(ActionChunkCertifier):
    def __init__(self, scm_rollout, conformal, beta0, alpha=0.05, **kw):
        super().__init__(**kw)
        self.cf, self.conformal, self.beta0, self.alpha = scm_rollout, conformal, beta0, alpha

    def generate_chunk(self, state, G, delta_mech, CS, K_max, tau_mech, risk_slam, tau_slam):
        K = self.csd.gate(delta_mech, CS, state.tau_dom, state.delta_dom,
                          risk_slam, tau_slam, K_max)
        if K == 1:
            return self._single_step_fallback(state)             # 等价 v8/v9 逐步
        beta = self.csd.margin(CS)                               # β(CS)=β₀/CS
        best = None
        for cand in self.policy.sample_sequences(state, K, n=64):
            cf = self.cf.rollout(G, state, cand, do=("A", cand))  # 反事实 rollout
            s = G.backdoor_stratum(state)                        # Pa(A_t) 层
            lo_q = self.conformal.quantile(s, self.alpha / 2)
            hi_q = self.conformal.quantile(s, 1 - self.alpha / 2)
            g_min = cf.min_clearance + lo_q - beta               # 定义 545
            e_max = cf.max_effort + hi_q + beta
            if g_min < self.d_safe or e_max > state.tau_eff:
                continue
            pts = self._abort_points(state, cand, cf)            # 定义 534 不变
            if not pts:
                continue
            score = self.policy.score(cand, cf)
            if best is None or score > best.score:
                best = Chunk(cand, Cert(g_min, e_max), pts, score)
        return best or self._single_step_fallback(state)


# IP-360 CausalInnovationDistiller：中介感知的因果归因（升级 v9 ID）
class CausalInnovationDistiller(InnovationDistiller):
    def attribute_causal(self, module, G, log_buffer, Y_metric, tau_de=0.02):
        if not self.contracts[module].distill_eligible:
            return float('inf')                                  # 安全模块不参与
        TE = self.est.total_effect(log_buffer, module, Y_metric, G)
        DE = self.est.direct_effect(log_buffer, module, Y_metric, G,
                                    mediators=G.mediators(module, Y_metric))
        if DE < tau_de and TE > 0:                               # 只影响中介 → 收紧资格
            self.contracts[module].distill_eligible = False
        self.ema[module] = clip(0.9 * self.ema.get(module, TE) + 0.1 * TE, 0, 1)
```

## 4. 推导

**引理 87（因果支持域下的反事实证书保守性）** 设 (A1) 图充分性：A 的合法后门集 Pa(A) 均被观测且入图；(A2) 校准层内 SCM 机制稳定；(A3) 层内交换性成立。则对任意 k≤K 与层 s，分层 conformal 给出 P(M₀_k ≥ L_k | s) ≥ 1−α/2；对 K 步取并集界得 P(∀k: M₀_k ≥ L_k) ≥ 1−Kα/2。故定义 545 的 ĝ_min 在信任域内保守有效。与 v9 相比，因 β(CS) ≥ β₀ 且额外取 SCM 最坏响应，v10 证书在同 K 下不更激进；CS=1、G 退化为 v9 时二者重合。∎

**引理 88（因果降级同态）** 逐项验证：(i) MCG 失效 ⇒ G=∅，Pa(A)=∅，do-效应退化为 E[M₀|A=a]，Δ_mech 由条件期望差定义；(ii) CSD 失效 ⇒ Δ_mech:=Δ_dom、CS:=1、τ_mech:=τ_dom，代入定义 544 得 v9 定义 539 的 K_eff；(iii) CCC 失效 ⇒ 定义 545 的 SCM rollout 换回 v9 的 F̂ rollout，β(1)=β₀。三项独立且可叠加，故全失效时门控、证书、主闭环与 v9 ACMD 公式逐项相同，日志逐位等价。∎

**引理 89（滋扰/机制分离性）** 在正确 G 下：(i) 若偏移为纯滋扰（定义 542），对一切 a 有 P_t(M₀|do(a))=P_s(M₀|do(a))，故 Δ_mech=0，K_eff 不被机制项收缩——相比 v9 的 Δ_dom 误降级严格减少；(ii) 若偏移作用于 M₀ 祖先机制且使某个可行动作的 do-效应改变 ≥δ，则 Δ_mech≥δ 触发门控；只要该 δ 在样本量下可估，检出不晚于 v9 的 Δ_dom 滑窗（后者需累积 20 帧）。故在 A1 下误降级与漏检同时弱改善。∎

**引理 90（幻觉 FDR 控制与时效安全）** 若每条边的 e-value 合法，e-BH 在任意依赖下控制 FDR ≤ q，故入图假边比例的期望 ≤ q（定义 541）。配合定义 547 的时效衰减，任一假边的影响窗口 ≤ T_stale：τ>T_stale 时 ρ=0 ⇒ Γ=0 ⇒ CS=0 ⇒ K_eff=1、β→∞，假边只能使系统更保守，不能使其更激进。该引理只给**长期与过期方向**的安全界，不保证 T_stale 窗口内假边的安全方向（见第 8 节风险）。∎

**引理 91（50Hz 隔离与无阻塞）** MCG 在旁路线程以 ≤1Hz 调用，主环仅执行 snapshot（O(|E|)，|E|≤512，≤0.05ms）；MLLM 的 0.2–2s 延迟完全被缓存隐藏。MLLM 卡死时 ρ 在 T_stale 内线性衰减到 0，CS→0、K→1、β→∞，控制回路保持 v9 的 ≤20ms 预算。故 v10 的最坏每周期成本 = v9 + O(|E|) ≤ 20ms，50Hz 守恒。∎

**引理 92（中介感知归因的一致性）** 若 G 包含 m 对 Y 的全部中介且无未观测混杂，则 g-formula 的总效应 TE_m 与直接效应 DE_m 估计一致；省略一个中介 Med₀ 会把部分间接效应并入直接效应，偏差上界为 |∂Y/∂Med₀|·|∂Med₀/∂m|。因此定义 548 用 TE 判算力资格、用 DE 判安全通路，并要求 G 的中介完备性由定义 541 的边检验与定义 549 的冲突惩罚共同保障；中介不完备时保守地把模块标记为 φ^elig=false。∎

## 8. 本轮最大风险

**一句话**：因果推断的可靠性以「因果图充分性（后门集无未观测混杂）」为前提，而 MLLM 的因果图恰在最陌生、最危险的场景里最可能漏掉关键混杂变量（被遮挡的人、反光地面、延迟出现的宠物）；一旦漏边，do-校正会给出自信但错误的「高因果支持」，反而放大 K_eff 并缩小 β——系统在最需要保守的时刻以最大块长执行最不可靠的证书，比 v9 的保守滞后更危险。
