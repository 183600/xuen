# 第 1 轮（灵感循环第 1 轮；本轮灵感：「跌倒恢复」×「行为树」）

> **基线**：承接产物区 v2 的 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440）。
> **本轮概念**：**RiseGauge**（Behavior-Tree Fall-Recovery Metrology）——把「修复闭环」本身建模为一次「跌倒恢复」，用契约标注的行为树替代线性 6C。
> 本轮纪律：先直觉后定义；每个新机制都必须能被证伪，并能退化回 ToolGauge。

## 0. 直觉：两个灵感其实在描述同一个「失效—恢复」结构

**灵感 1（跌倒恢复 → 修复不是继续修，而是先保护、再起身、再站稳、再回归）**

ToolGauge 的 6C 隐含假设：修复过程总是「可继续」的。交叉验证失败就重试，预算不足就降级，反作用通道保证不破坏数值路径。但真实失效更像跌倒：系统突然失去可信姿态——后验塌缩、契约回归失败、先验被 P-Quarantine 隔离——此时继续执行探测动作可能造成二次伤害。跌倒恢复的工程语言给出了一套顺序：

- **跌倒检测**：区分硬跌倒（立即触发）与软失稳（需连续确认，防误报）；
- **保护性姿态**：先收紧关节/冻结动作，避免二次伤害；
- **起身原语**：推起、翻滚、跪起、扶支撑点——每种原语有前条件、代价、风险、成功概率；
- **站稳验证**：不是「动作做完」就算恢复，而是「稳定窗口内不再跌倒」；
- **回归与防再跌**：迟滞回归、失败指纹、重复跌倒升级。

把 error contract 的失效类比为跌倒，修复闭环就从「线性重试」变成「有保护、有原语、有证书、有防复发的恢复控制」。

**灵感 2（行为树 → 反应式、可抢占、可组合的恢复控制）**

6C 是线性状态机：H→C→E→C→V→U。线性状态机的缺点是「跌倒」只能作为某个状态转移，优先级、抢占、重试、超时、并行监控都要手工编码，且难以证明「保护动作一定先于恢复动作」。行为树（BT）恰好提供：

- **Selector/Fallback**：恢复失败自动落到下一原语，最后落到安全 stub；
- **Sequence**：保护→诊断→选原语→执行→站稳→回归的强制顺序；
- **Decorator**：Retry、Timeout、Guard、Inverter，把「重试有界」「超时有界」「守卫优先」变成结构性质；
- **反应式抢占**：高优先级 FallGuard 可在任意 tick 中断低优先级 Nominal 子树；
- **可组合/可验证**：每个节点带契约（前条件、后条件、代价、风险、超时、副作用类），整棵树可以静态检查组合合法性。

**灵感 3（合流 → 两层同构的「反思式恢复」）**

对象层机器人跌倒恢复与元层契约跌倒恢复共享同一棵 BT 骨架：对象层的「跌倒」是元层的一个 failure fingerprint，元层的「保护性 posture」对应对象层的「收腿/护关节」。因此不需要两套机制，只需要一套 **契约标注行为树（CABT）**，在两个时间尺度上复用。这是本轮最核心的结构性想法：RiseGauge 不是给 6C 加一个 recovery 状态，而是把整个修复闭环重写成「可证明优先级」的恢复树。

## 1. 可检验假设

- **H1（保护安全）**：若 FallGuard 在派发 nominal 动作前被求值，且所有不可逆工具走 arm/commit 两阶段提交，则跌倒确认后不会发生任何 nominal 热替换或不可逆提交；保护性姿态本身零物理副作用。
- **H2（有界终止）**：在有限原语库、有界重试、有限超时、有限恢复预算下，恢复子树必然在有限时间内到达 StandSuccess 或 SafeStub，不存在无限「起身—再跌倒」循环。
- **H3（无抖振）**：在迟滞差 Δ_hys>0、跌倒确认窗口 c、站立窗口 W 下，fall→reenter 的切换次数有时间上界，不出现 Zeno 行为。
- **H4（恢复效率）**：按保守成功率下界 q⁻ 对原语排序 c/(q⁻)，在独立原语假设下最小化期望恢复代价；相比 6C 的固定重试，期望代价与 P99 恢复时延显著下降。
- **H5（严格退化）**：BT 运行时不可用、预算耗尽、原语库为空或全部被 ban 时，RiseGauge 与 ToolGauge 的数值行为/失败语义逐指令等价；RiseGauge 是增强层，不是新依赖。

## 2. 形式化草图（先给骨架，产物区给完整版）

**定义 A（跌倒谓词）** 硬跌倒 `Hard_s(t)` 立即触发：独立交叉验证失败、契约回归失败、P-Quarantine 触发、不可逆动作 commit 失败。软失稳 `Soft_s(t)` 需连续 c 个 tick 确认：姿态能量 `V_s(t)` 超阈、工具失败率超阈、后验方差膨胀。`Fall_s(t) = Hard_s(t) ∨ (Soft_s(t) 连续 c 次)`。

**定义 B（保护性姿态）** `Brace_s` 冻结 AP-Cal、取消并 void 在途工具、把 EC 夹紧到 `(μ_ref, max(Σ_s, κ_phys I)·σ_brace)`，关闭热替换。不可逆工具采用 arm/commit 两阶段；commit token 在 Fall flag 置位时立即失效。

**定义 C（恢复原语与程序）** 原语 `p = (Pre, Post, c, ρ, g, τ, Eff)`；恢复程序 `π = (p₁,…,p_L)`，`L ≤ L_rec`，`Σc ≤ B_rec`，`p ∉ P_ban(fp)`。选择用保守成功率下界 `q⁻_p` 排序 `c_p/q⁻_p`；有依赖（如必须先取得独立 anchor 才能 recalibrate）时走 DAG 最短路。

**定义 D（CABT）** 节点带契约；Selector/Sequence/Retry/Timeout/Guard/Parallel 有组合规则；tick 返回 S/F/R；ReactiveSelector 每次从高优先级重新 tick；halt 必须满足 SafeCancel。FallGuard 以最高优先级抢占 Nominal，恢复完成后才允许 U 阶段。

**定义 E（站立证书）** `Cert_s = (fp, π, r_⊥, witnesses, W)`；`r_⊥` 必须是未参与本轮校准的独立回执；cross_validate、contract regression、MODGAUGE 五不变式、W 窗口内 `Fall_s=0` 全部通过，才允许 Reenter 和热替换。

**定义 F（迟滞与防再跌）** `V_reenter < V_fall`，配合 c/W 窗口；同一 `fp` 在 `τ_fp` 内出现 ≥ q_ban 次则 ban 相关原语；stand 后 `τ_relapse` 内同 fp 再跌倒判为「假恢复」，提升 anchor 要求并下调 `q⁻`；原语耗尽则 stub+RED。

## 3. 与 ToolGauge 的差异（一句话版）

| 维度 | ToolGauge v2 | RiseGauge |
|---|---|---|
| 修复结构 | 线性 6C 状态机 | 反应式 CABT，FallGuard 最高优先级 |
| 失效处理 | 重试/降级 | 先 Brace 保护，再按原语库起身 |
| 恢复判据 | 交叉验证通过即热替换 | 独立 anchor + 稳定窗口的站立证书 |
| 重试 | 固定次数 | 有界 Retry + 超时 + 恢复预算 + banned 集 |
| 复发 | P-Quarantine 事后断路 | 失败指纹 + 迟滞 + 假恢复检测的事前防再跌 |
| 验证 | 6C 路径检查 | CABT 组合规则 + 有界模型检查 |
| 退化 | ToolGauge ⇐ LeanGauge ⇐ MODGAUGE | RiseGauge ⇐ ToolGauge ⇐ LeanGauge ⇐ MODGAUGE |

## 4. 证伪计划（什么会杀死这个想法）

1. 若 FallGuard 的误报率导致系统在正常漂移下频繁进入 Brace，恢复开销超过 6C 基线，则 H1/H4 不成立。
2. 若「假站立」无法被独立 anchor 检出（anchor 与校准共享同一失配先验），站立证书的假接受率不随 anchor 数指数下降，则 H1 的安全论证失效。
3. 若原语选择器在非独立、非平稳的成功率下长期选择错误原语，期望恢复代价高于「总是 reset prior」，则 H4 不成立。
4. 若 CABT 的静态组合规则过强，导致真实恢复策略无法表达（例如 Sequence 的后条件传播过严），工程上会退化成手写状态机，则「可验证性」只是装饰。
5. 若 50Hz 路径上 FallGuard 的原子读/指针交换在真实硬件上引入不可接受的抖动，或异步 Brace 的取消延迟超过安全界，则 H5 的硬实时论证不成立。

## 5. 本轮最大风险

**一句话**：RiseGauge 的最大风险是「假站立」——跌倒检测、恢复原语选择与站立证书共享同一个失配先验/特征管线时，恢复子树会系统性地把「未恢复」判成「已恢复」，而行为树的高优先级安全外观又让这种失败比 ToolGauge 的线性重试更难被外部审计发现。

## 2. 形式化定义（要点）

**定义 432（跌倒谓词）** 设盲区 `s` 的契约状态为 `z_s(t) = (μ_s, Σ_s, h_s, e_s)`，其中 `h_s` 为健康度、`e_s` 为独立残差向量。定义证据向量

`φ_s(t) = (1[|z_⊥| > ε_cross], 1[¬regress_s], 1[P-Quarantine_s], 1[logdet Σ_s > logdet Σ_max], 1[rate_fail_s > ρ_max])`。

`Hard_s(t) = φ_s,1 ∨ φ_s,2 ∨ φ_s,3`，`Soft_s(t) = φ_s,4 ∨ φ_s,5`；
`Fall_s(t) = Hard_s(t) ∨ (∧_{j=t-c_conf+1}^{t} Soft_s(j))`。
硬跌倒立即进入 Brace；软失稳需连续 `c_conf` 个 tick 确认，避免正常漂移误触发。

**定义 433（保护性姿态）** `Brace_s(C_s, I_s)` 接收当前契约与在途动作集 `I_s`，输出安全契约：

`C_s^safe = (μ_ref, max(Σ_s, κ_phys I)·σ_brace, mode=PROTECT, hot_replace=false)`，

并对每个 `a ∈ I_s` 调用 `a.cancel(); a.void_token()`。不可逆工具必须实现两阶段提交：`arm` 只准备不生效，`commit` 前检查 Fall flag；flag 置位则 token 立即失效。后条件：无新物理副作用、`C_s^safe ≽ C_s`（保守性单调）、任何 U 阶段热替换被门控。

**定义 434（姿态能量）** `V_s(t) = ||μ_s − μ_ref||²_{Σ_ref⁻¹} + λ_tr·max(0, tr(Σ_s)/tr(Σ_ref) − 1) + λ_z·z_⊥²`。`V_s` 在“回到参考姿态”时下降；阈值满足 `V_reenter < V_fall`。

**定义 435（恢复原语）** `p = (name, Pre_p, Post_p, c_p, ρ_p, g_p, τ_p, Eff_p)`：
`Pre_p(fp, z_s, B_rec, env)` 为前条件；`Post_p(z_s)` 为恢复后条件；`c_p` 为预算代价；`ρ_p` 为副作用风险等级；`g_p` 为预期增益（归一化成功概率）；`τ_p` 为最坏时延；`Eff_p` 为副作用描述（`none / cancel / probe / irreversible`）。保守成功率 `q⁻_p = BetaLower(α_p, β_p, δ)`，只用历史计数下界，不用点估计。

**定义 436（恢复程序与预算）** 程序 `π = (p_1,…,p_L)` 有效当且仅当：`L ≤ L_rec`；`Pre_{p_1}` 成立；`Post_{p_i} ⇒ Pre_{p_{i+1}}`；`Σ c_{p_i} ≤ B_rec`；`p_i ∉ P_ban(fp)`；不可逆原语的 `Eff` 不与并行监控冲突。安全关键盲区保留 `B_res`，不得被非关键恢复挪用。

**定义 437（行为树）** `BT = (N, root, rate, m)`；节点类型 `τ ∈ {Action, Condition, Sequence, Selector, ReactiveSelector, Parallel, Retry, Timeout, Guard, Inverter, SubTree}`；`m` 为记忆表（正在运行的子节点索引）。`tick(n, bb, m) → (Status, m')`，`Status ∈ {SUCCESS, FAILURE, RUNNING}`。

**定义 438（契约标注节点）** `n = (type, children, Pre, Post, c, ρ, τ, Eff)`。组合良构规则：
- Sequence：`Post(n_i) ⇒ Pre(n_{i+1})`，`Post = Post(n_last)`，`c = Σc_i`，`Eff` 不冲突；
- Selector：每个子节点带显式守卫 `G_i`，`Pre(n_i) = Pre(sel) ∧ G_i`；`Post = ∨ Post(n_i)`；守卫互斥或按优先级求值；
- Retry(k)：子动作必须幂等或带补偿（`Undo`），`Post = Post(child)`（仅成功时），`c ≤ k(c_child + overhead)`；
- Timeout(τ)：`τ > 0` 且子动作 `Eff` 可取消；
- Parallel：`Eff` 两两不冲突，成功/失败阈值显式；
- Guard(G, T)：`Pre = Pre(T) ∧ G`，`Post = G ∧ Post(T)`。

**定义 439（安全中止）** `halt(n)` 递归停止运行中的子节点，并对每个 Action 调用其 `cancel` 钩子。`SafeCancel(a)` 成立当且仅当 `cancel` 幂等、有界（≤ τ_cancel）、不产生不可逆副作用、不吞掉已提交回执。不可逆动作必须通过 `void_token` 使未提交的 commit token 失效。

**定义 440（FallGuard 与抢占）** `FallGuard = Guard(λbb. bb.fall_signal, RecoveryTree)`。根为 `ReactiveSelector([FallGuard, Nominal6C, SafeStub])`。每个 fast tick 从最高优先级开始重新求值；若低优先级子树处于 RUNNING 而高优先级返回 SUCCESS/RUNNING，则先 `halt(低优先级)`，再 tick 高优先级。`fall_signal` 是异步 FallBox 写入的原子标志，快路径只读不阻塞。

**定义 441（站立证书）** `Cert_s = (fp, π, r_⊥, witnesses, W)`。`r_⊥` 为独立 anchor 回执：来自未参与本轮校准的工具/通道，签名有效、`seq` 新鲜、与校准回执集不相交。验证谓词：

`StandVerify(s) = (B_anchor ≥ 1) ∧ cross_validate(μ_s, Σ_s, r_⊥) ≤ ε_cross ∧ regress_s ∧ IV_Contract ∧ IV_Monotone ∧ IV_Reaction ∧ IV_Claim ∧ (∀j∈[t−W+1,t]: Fall_s(j)=0) ∧ (V_s ≤ V_reenter)`。

全部通过才允许 `ReenterNominal` 与 U 阶段热替换；证书通过 ClaimReceipt 绑定语言主张，未绑定回执的主张在序列化时剥离（继承定义 423）。

**定义 442（迟滞回归）** 仅当 `V_s ≤ V_reenter` 连续 `W` 个 tick 且无新跌倒证据时回归 Nominal；`V_reenter < V_fall`，`Δ_hys = V_fall − V_reenter > 0`。迟滞窗口同时抑制「恢复—再跌倒」抖振。

**定义 443（失败指纹与防再跌）** `fp = H(failure_type, s, tool_id, sign(z_⊥), context_hash)`。`κ(fp, t)` 为窗口 `τ_fp` 内计数；`κ ≥ q_ban` 时将与该 fp 关联的原语加入 `P_ban`。若 stand 后 `τ_relapse` 内同 fp 再次跌倒，判为「假恢复」：提高 `B_anchor` 要求、下调相关原语 `q⁻`、记录到 SNC 失败指纹库 `F_*`。

**定义 444（升级梯）** `L_esc = (retry same → next primitive → rollback EC → reset prior (AP-Cal→BP-Cal) → stub + RED → human)`。每一级只能由显式守卫进入；`stub + RED` 为子图吸收态，不阻塞 50Hz 主路径，也不污染其他盲区。

**定义 445（严格退化链）** `RiseGauge ⇐ ToolGauge ⇐ LeanGauge ⇐ MODGAUGE`。BT 不可用/超预算 ⇒ 直接 `toolgauge_6c`；原语库空/全 ban ⇒ `stub_and_red`；FallBox 不可用 ⇒ 仅用 ToolGauge 的硬失败（交叉验证/回归）作为触发；anchor 不可得 ⇒ 不站立，stub。退化路径的数值行为必须逐指令等价。

**定义 446（双速率调度）** `Tick_fast` 在 50Hz 路径：只读 `FALL_FLAG`，命中则把指针交换到预计算的 `C_s^safe`；`Tick_slow` 在异步计量线程：执行 FallBox 轮询、Brace、Diagnose、恢复树、StandVerify。`Tick_fast` 的最坏开销 ≤ 0.01ms；`Brace` 的取消在异步线程有界完成（≤ τ_brace）。

**定义 447（审计与主张绑定）** 每次 tick 记录 `(tick_id, node_id, status, duration, receipts, fall_signal, cert_id)`；`Audit_BT` 可离线重放。恢复证书、原语 trace、anchor 回执与语言解说构成 `RepairCert`，语言主张必须引用有效回执，否则剥离；剥离是纯投影，不改变数值行为。

# IP-321 / 定义 432–433：跌倒检测 + 保护性姿态
class FallBox:
    def __init__(self, theta):
        self.eps_cross = theta.eps_cross
        self.V_fall = theta.V_fall
        self.c_conf = theta.c_conf
        self.sigma_brace = theta.sigma_brace
        self.rho_max = theta.rho_max
        self.soft_hist = deque(maxlen=self.c_conf)

    def poll(self, ec, r_indep, pquar, regress_ok):
        hard = (not regress_ok) or pquar.triggered() or (
            r_indep is not None and not self._cross_ok(ec, r_indep))
        soft = (self._posture_energy(ec) > self.V_fall
                or self._tool_fail_rate(ec) > self.rho_max)
        self.soft_hist.append(soft)
        soft_confirmed = (len(self.soft_hist) == self.c_conf
                          and all(self.soft_hist))
        return hard or soft_confirmed

    def brace(self, ec, inflight):
        for a in inflight:
            a.cancel()        # SafeCancel: 幂等、有界、无副作用
            a.void_token()    # 两阶段提交：未 commit 的 token 立即失效
        safe = ec.clamp(mu_ref=ec.mu_ref, kappa=KAPPA_PHYS,
                        inflate=self.sigma_brace)
        safe.mode = "PROTECT"
        safe.hot_replace = False
        return safe


# IP-323 / 定义 435–436：恢复原语库 + 保守选择
class RecoveryLib:
    def select(self, fp, ec, budget):
        cands = [p for p in self.primitives
                 if p.name not in self.banned[fp]
                 and p.Pre(fp, ec, budget, self.env)
                 and p.cost <= budget]
        if not cands:
            return None
        # 保守下界 q^- 排序；独立原语下的最优期望代价序
        cands.sort(key=lambda p: p.cost / max(p.q_lower, 1e-9))
        # 有依赖时（例如 anchor 必须先于 recalibrate）用 DAG 最短路
        return self.dag_shortest_path(cands, fp, ec, budget)

    def execute(self, prog, env, tcv):
        receipts = []
        for p in prog:
            if not tcv.pre(p, env.snapshot()):
                break
            r = tcv.invoke(p, env)          # arm -> commit 两阶段
            if r is None or not verify_sig(r):
                self.banned[p.name].add(p)
                continue
            receipts.append(r)
        return receipts


# IP-322 / 定义 437–440：CABT 运行时（节选）
class Node:
    def __init__(self, kind, children=(), pre=None, post=None,
                 cost=0.0, risk=0.0, timeout=None, effect="none"):
        self.kind, self.children = kind, list(children)
        self.pre, self.post = pre, post
        self.cost, self.risk = cost, risk
        self.timeout, self.effect = timeout, effect

    def tick(self, bb):
        if self.kind == "condition":
            return "SUCCESS" if self.pre(bb) else "FAILURE"
        if self.kind == "action":
            if not self.pre(bb): return "FAILURE"
            ok, r = self.run(bb)            # TCV 执行 + 契约后置校验
            if ok: bb.receipts.append(r)
            return "SUCCESS" if ok else "FAILURE"
        if self.kind == "sequence":
            for ch in self.children:
                st = ch.tick(bb)
                if st != "SUCCESS": return st
            return "SUCCESS"
        if self.kind == "reactive_selector":
            for ch in self.children:
                st = ch.tick(bb)
                if st in ("SUCCESS", "RUNNING"):
                    for other in self.children:
                        if other is not ch and other.status == "RUNNING":
                            other.halt()
                    return st
            return "FAILURE"
        # retry / timeout / guard / parallel 省略：见定义 438
        raise ValueError(self.kind)

    def halt(self):
        for ch in self.children:
            ch.halt()
        if self.kind == "action" and self.status == "RUNNING":
            self.cancel()                    # SafeCancel
            self.void_token()


# IP-326 / 定义 432–441：RBT 恢复闭环
def make_risegauge_tree(M):
    recovery = Node("sequence", [
        Node("action", pre=lambda bb: bb.fall, post=lambda bb: bb.braced,
             timeout=TAU_BRACE, effect="cancel", run=M.brace),
        Node("action", pre=lambda bb: bb.braced, post=lambda bb: bb.fp is not None,
             run=M.diagnose),
        Node("retry", [Node("sequence", [
            Node("action", pre=lambda bb: bb.fp is not None,
                 post=lambda bb: bb.prog is not None, run=M.select),
            Node("action", pre=lambda bb: bb.prog is not None,
                 post=lambda bb: bb.executed, run=M.execute),
            Node("condition", pre=M.stand_verify),
        ])], k=R_MAX),
        Node("action", pre=lambda bb: bb.standing,
             post=lambda bb: bb.reentered, run=M.reenter),
    ])
    return Node("reactive_selector", [
        Node("guard", [recovery], pre=lambda bb: bb.fall_signal),
        Node("subtree", [M.nominal_6c]),
        Node("action", pre=lambda bb: True, run=M.safe_stub),
    ])


# IP-328 / 定义 445–446：双速率主闭环
def risegauge_fast_tick(M, obs):
    if M.fall_flag.load():                   # 50Hz 只做原子读 + 指针交换
        M.dpe.set_contract(M.safe_ec)
    return MODGAUGE_fast_path(M, obs)


def risegauge_slow_tick(M):
    if M.fallbox.poll(M.dpe.ec, M.cross_receipt(), M.pquar, M.regress_ok):
        M.fall_flag.store(True)
    if not M.fall_flag.load():
        return M.nominal_6c()
    st = M.bt.tick(M.bb)                     # 异步恢复树

        M.fall_flag.store(False)
        M.dpe.set_contract(M.bb.safe_ec)
    return st

## 4. 推导

**引理 51（保护性姿态的零副作用与保守性）** 假设所有在途动作满足 `SafeCancel`、不可逆动作实现 arm/commit 两阶段提交，则 `Brace_s` 执行后：不产生新的物理副作用；`C_s^safe ≽ C_s`；MODGAUGE 五不变式保持；`hot_replace=false` 使 U 阶段不可达。
*证明*：`cancel` 幂等且无副作用，`void_token` 只使未提交 token 失效；TCV 将 void 回执丢弃；`σ_brace ≥ 1` 与 `κ_phys` 夹紧只会扩大置信域；`mode=PROTECT` 门控热替换。∎

**引理 52（抢占可靠性）** 若在 fast tick `t` 派发 nominal 动作之前已求值 `Fall_s(t)=1`，且 nominal 动作要么尚未派发、要么已派发但未 commit 且可取消，则在 `StandVerify` 成功之前不会发生 nominal 热替换或不可逆提交。
*证明*：ReactiveSelector 的优先级保证 FallGuard 先于 Nominal；安全中止在 tick 内完成；commit token 被 Fall flag 立即失效；U 阶段由站立证书门控。∎

**引理 53（恢复有界终止）** 在原语库有限、`R_max, L_rec, τ_max, B_rec` 有限且每次尝试代价 `c_p > 0` 时，恢复子树在

`T_max = τ_brace + (R_max + 1)·(L_rec·τ_max + τ_verify) + τ_reenter`

内终止于 `StandSuccess` 或 `SafeStub`。
*证明*：每个原语在 `τ_max` 内返回 SUCCESS/FAILURE/TIMEOUT；每次重试严格消耗重试计数与恢复预算；原语库有限且 banned 集只增不减；所有分支有限。∎

**引理 54（无抖振/驻留时间）** 设 `V_s` 每 tick 变化不超过 `L_V`。由于 `V_reenter < V_fall`，一次 fall→reenter 至少需要 `d = ⌈Δ_hys / L_V⌉` 个 tick 从 `V_reenter` 升到 `V_fall`；再叠加跌倒确认 `c_conf` 与站立窗口 `W`，任意两次 fall→reenter 之间至少相隔 `c_conf + W + d` 个 tick。因此在 `T` 个 tick 内切换次数 ≤ `⌊T/(c_conf+W+d)⌋ + 1`。
*证明*：反证；若两次切换间隔小于下界，则 `V_s` 必须在一个 tick 内跨越超过 `L_V` 的变化，矛盾。∎

**引理 55（恢复原语排序最优性）** 对相互独立、成功概率 `q_p` 与代价 `c_p` 的原语，按 `c_p/q_p` 非降序尝试，使首次成功前的期望代价最小。
*证明*：相邻交换。先 p 后 q 的期望代价为 `c_p + (1−q_p)c_q`；交换后差值为 `q_p c_q − q_q c_p`，故 p 应在前当且仅当 `c_p/q_p ≤ c_q/q_q`。∎

**引理 56（CABT 组合可靠性）** 若所有 Action 节点在运行时满足其契约，且树满足定义 438 的组合良构规则，则根节点返回 SUCCESS 蕴含 `Post(root)`；返回 FAILURE 蕴含回退后条件（stub 或升级）。
*证明*：对树结构归纳。Sequence 用后条件传播；Selector 用守卫划分与析取后条件；Retry 用幂等/补偿；Timeout 用可取消性；Guard 用前置强化。∎

**引理 57（严格退化等价）** BT 运行时被禁用/超预算时，RiseGauge 以相同输入调用 `toolgauge_6c`；原语库为空或全部被 ban 时，调用与 ToolGauge 相同的 `stub_and_red`；FallBox 不可用时只用硬失败触发。故退化路径的数值行为与失败语义与 ToolGauge 逐指令等价。
*证明*：按退化条件分情况，调用的是同一函数、同一输入、同一后置；新增分支只在增强路径可达。∎

**引理 58（时序保持）** 50Hz 快路径新增一个原子读与（跌倒时的）一次预计算契约指针交换，最坏 ≤ 0.01ms；FallBox/Brace/恢复树均在异步计量线程。即使异步 Brace 超过 `τ_brace`，快路径仍使用上一份已认证契约，且两阶段提交阻止未提交的不可逆动作，故 50Hz 硬实时预算不被破坏。
*证明*：快路径不分配内存、不做工具调用；指针交换为 O(1)；安全由引理 51/52 与 commit token 保证。∎

**引理 59（站立证书假接受界）** 若独立 anchor 回执与校准回执集统计独立，且标准化残差 `z_⊥` 满足 `σ_⊥`-亚高斯，则单 anchor 的假站立概率 ≤ `exp(−ε_cross²/(2σ_⊥²))`；`B_anchor` 个独立 anchor 时 ≤ `exp(−B_anchor·ε_cross²/(2σ_⊥²))`。若 anchor 与校准共享同一失配先验/特征管线，独立性假设失效，该界退化为空洞界——这正是本轮最大风险的数学位置。
*证明*：亚高斯尾界与独立性乘积；独立性失效时无法分解联合概率。∎

## 8. 本轮最大风险

**一句话**：RiseGauge 的最大风险是「假站立」——跌倒检测、恢复原语选择与站立证书共享同一个失配先验/特征管线时，恢复子树会系统性地把「未恢复」判成「已恢复」，而行为树的高优先级安全外观又让这种失败比 ToolGauge 的线性重试更难被外部审计发现；以 E448 的共享先验对抗组证伪、引理 59 的独立性假设审计、以及「双独立 anchor + 证书回执绑定」三重兜底。
