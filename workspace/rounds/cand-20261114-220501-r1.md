# 第 3 轮（灵感循环：本轮灵感「LoRA」×「大语言模型」；承接 ToolGauge 第 2 轮）

> **基线继承**：第 1 轮 **LeanGauge**（IP-310–314；定义 398–415；引理 42–45；E411–E425）
> → 第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；E426–E440）。
> 本轮纪律：在 ToolGauge 上做**结构性**改进，而不是继续堆模块。ToolGauge 已把「探测动作接口化」与
> 「先验质量可审计化」做完，但它自己承认的最大风险仍然成立：**摊销后验在预训练→部署偏移下产生跨盲区强相关偏差，
> 一次错误先验同时污染所有被热替换的子图**。本轮的靶心是把「共享即耦合」从结构上切断。
> MODGAUGE 五不变式保留；其中「组合单调性」升级为**条件组合单调性**（定义 440，含干扰证书）。

## 0. 一句话命题

把 ToolGauge 的「全量摊销后验 + 整子图热替换」升级为
「**冻结计量基座（F-Box）+ 每盲区秩预算低秩修复增量（R-Box）+ 干扰审计下的条件合并（X-Box）**」；
LLM 只做**结构提议**（改哪里、用多低秩、从适配器库借谁），**数值系数永远由带证书的求解器在回执上拟合**。

> **语言提议，求解器定权，干扰器否决。**

## 1. 映射（升级而非重写）

| 灵感 | 承接对象 | 升级为 | 一句话动机 |
|---|---|---|---|
| LoRA「冻结 + 低秩」 | AP-Cal 全量摊销后验；整子图热替换 | **F-Box 冻结基座 + R-Box 秩预算低秩修复增量** | 共享先验与局部修复解耦：错误被限制在一个低秩子空间内 |
| LoRA「可组合 / 可逆」 | 热替换不可逆；组合单调性靠测试兜底 | **X-Box 干扰审计 + 条件合并 + 精确回滚** | 低秩结构第一次让「局部误差局部化」有可计算证书 |
| LLM「上下文学习」 | VLA 三角色（假设 / 编程 / 解说） | **P-Box 上下文结构提议 + 自洽投票** | 少样本直接提议修复子空间，不重训、不进数值 |
| LLM「检索 / 推测解码」 | 逐盲区从零修复、无记忆 | **A-Lib 检索式热启动 + Spec-Repair 推测修复** | 复用历史修复，同时用强制验证阻断污染扩散 |

**核心命题**：ToolGauge 的问题不是「先验不够好」，而是「先验与修复共用同一组权重，于是无法区分共享知识与局部修正」。
RankGauge 把两者拆成**冻结基座 + 可插拔低秩增量**：基座提供跨盲区共享，增量只负责单盲区特化；
低秩使增量的容量、影响范围、回滚都变成可测、可证、可审计的量。

**不变式保持声明**：
- MODGAUGE 五不变式全部保留；「组合单调性」加强为**条件组合单调性**（定义 440）：任何已认证格子的裕度下降不得超过 δ_m；
- 「严格退化链」延长：RankGauge 失效（非局部可修 / 秩预算不足 / 干扰超限 / 检索污染 / LLM 不可用）
  ⇒ 退回 ToolGauge（完整 AP-Cal，无适配器）⇒ LeanGauge ⇒ MODGAUGE；
- 「语言不进入数值通道」保持：LLM 只输出结构提议，系数由求解器拟合（定义 438、444）。

## 2. 直觉

### 2.1 为什么是 LoRA（一）：低秩是「修复的容量旋钮」
ToolGauge 的 AP-Cal 用**同一张**预训练网络去适配所有盲区。这等价于假设「所有盲区的修正都落在同一个函数空间里」，
一旦某个盲区的真实修正与共享先验冲突，梯度会把冲突抹平成一个**对所有盲区都略错**的解——这正是「跨盲区强相关偏差」的力学来源。

LoRA 的做法给出另一种分解：$u_s = W_0 z_s + \alpha_s B_s A_s z_s$，$W_0$ 冻结共享，$B_sA_s$ 只服务盲区 $s$。
修复不再改写共享知识，只在其上加一个**秩为 $r_s$ 的局部扰动**。秩 $r_s$ 于是成为两个东西：
(a) **容量旋钮**——能表达多复杂的局部修正；(b) **审计单位**——这个修正至多占多少自由度、能影响哪些方向。

### 2.2 为什么是 LoRA（二）：可逆与可组合，正好补上「热替换」的两处软肋
第 2 轮的整子图热替换有两处结构性弱点：
1. **回滚只是近似**：新契约覆盖旧契约后，要回退只能靠保存旧快照，且浮点合并后不保证逐位一致；
2. **组合单调性靠回归测试**：多个修复叠加是否互相破坏，只能跑一遍测试，缺少**可计算的**先验判据。

低秩增量同时修两处：删除 $(A_s,B_s)$ 即精确恢复基座（只要不把增量折叠进 $W_0$，见引理 54）；
而两个增量是否互相干扰，可以由**敏感度子空间的重叠度**直接算出上界（定义 439、引理 52）。
这把「局部修复、误差局部化」从经验主张变成有证书的命题——**但前提是低秩方向真的正交，见 2.4**。

### 2.3 为什么是 LLM：它擅长提议「改哪里」，不擅长给出「改多少」
LLM 的上下文学习本质上是一种**免梯度、免训练的摊销提议器**：给它回执流、盲区语义、历史修复库元数据，
它能很快说出「这像镜面反射，应该动光照通道的低秩子空间，借库里第 17 号适配器做初值」。
这类**结构选择**正是数值求解器最难自己搜的部分（组合空间大、无梯度）。

但 LLM 对数值极不可信。于是分工必须硬性隔离：LLM 输出 `{support, rank, retrieved_ids, constraints, rationale}`，
**禁止输出进入契约的数值系数**；系数由最小二乘 / 经验贝叶斯求解器在有效回执上拟合，再穿过与 ToolGauge 同级的统计门。
自洽投票（采样 $k$ 条、对 support 逐维多数）压单次幻觉；检索提供热启动；推测式「草稿—验证」把昂贵拟合延后到必要时。

### 2.4 为什么不能迷信低秩：低秩 ≠ 因果局部（本轮最大风险）
一个 $r=1$ 的增量若指向全局最敏感的参数方向，照样能让所有格子同时漂移。
「低秩」只是**参数量**小，不是**影响范围**小。因此必须引入独立于低秩的**干扰度** $\rho(a,b)$（定义 439）
与**干扰回归**（定义 441）：低秩只是把「可能出错的方向」压到少数几个，真正保证局部性的是
「这些方向与本格以外格子的敏感子空间正交」。把低秩当安全证明，是本轮方案最危险的认知捷径。

### 2.5 检索是一把双刃剑
检索复用历史适配器，能把「每个盲区从零修复」变成「少样本热启动」，但也制造了一条**污染供应链**：
一个被投毒的适配器一旦进入库，会被后续许多盲区反复检索、反复热替换，形成比第 2 轮更强的**跨盲区相关污染**。
因此检索命中只能作为**初值**，必须通过签名、来源、强制验证三道关；验证失败一律隔离并告警（定义 445）。

## 3. 形式化定义（增量：定义 432–449）

**定义 432（冻结计量基座与适配位点）** 基座 $B_0 = \mathrm{MP\text{-}}\Phi_{\theta^*}$（第 2 轮定义 420）在部署期冻结，
$\theta^*$ 不可写。只允许在预注册**适配位点**（calibration head 的线性映射 $W_0\in\mathbb{R}^{d_u\times d_{in}}$，
以及可选的后验均值残差头）上做加法增量；其他任何写入视为违反不变式。

**定义 433（低秩修复增量 LRA）** 对盲区 $s$：$u_s = W_0 z_s + \alpha_s B_s A_s z_s$，
$A_s\in\mathbb{R}^{r_s\times d_{in}}$，$B_s\in\mathbb{R}^{d_u\times r_s}$，$\alpha_s=\alpha/r_s$。
初值 $B_sA_s=0$ ⇒ 适配器未启用时系统与基座逐位相同；删除 $(A_s,B_s)$ 精确恢复基座。

**定义 434（有效样本量与秩预算）** 回执流的信息矩阵 $I_s$（Fisher / 逆协方差加权）。
有效样本量 $n_{eff} = (\operatorname{tr} I_s)^2/\operatorname{tr}(I_s^2)$（对相关观测保守，恒有 $n_{eff}\le n$）。
秩预算
$$r_s^{max}=\max\Big\{r\le r_{cap}:\ C\,r\,(d_{in}+d_u)\log(2d/\delta)\le n_{eff}\,\varepsilon_{gen}^2\Big\}.$$
预算不足不是「多给点样本」的口号，而是一个显式的 `r_max` 上限。

**定义 435（秩-近似-泛化三元权衡）** 固定秩 $r$ 的修复误差满足
$$\mathrm{Err}_s(r)\le \mathrm{Err}_{base}(s)+\varepsilon_{approx}(h_s^*,r)+C\sqrt{\frac{r(d_{in}+d_u)\log(2d/\delta)}{n_{eff}}}.$$
第一项是冻结基座误差（不可在线消除）；第二项是低秩表达力不足（欠拟合）；第三项是估计方差。
最优秩由三者交点决定——**既不是秩越大越好，也不是越低秩越安全**。

**定义 436（非局部可修判定）** 若 $\inf_{r\le r_{cap}}\mathrm{Err}_s(r)>\varepsilon_{repair}$，则 $s$ 判为**非局部可修**：
不写适配器，转 `stub + RED`，并进入**离线**基座再预训练队列。这给 LoRA 一个诚实的失败出口。

**定义 437（适配器库与检索算子）** $\mathcal{L}=\{(\Delta_j,\text{meta}_j,\text{sig}_j,\text{prov}_j)\}$；
检索 $\mathrm{ret}(s,k)$ 按语义标签 $H_s$ 与数值签名（回执统计 + 敏感度指纹）距离取 top-$k$。
命中项只能作为**热启动初值**，必须通过定义 441 的强制验证才可合并。

**定义 438（上下文结构提议契约 CPC）** LLM 输入白名单：数值回执、$H_s$、库元数据（**不含原始权重**）。
输出 JSON 仅含 `{support, rank, retrieved_ids, constraints, rationale}`；**禁止输出进入契约的数值系数**。
采样 $k$ 条提议，对 support 逐维多数投票，rank 取分布中位数并夹到 $[0,r_s^{max}]$。

**定义 439（干扰度与正交证书）** 设 $P_b$ 为单元格 $b$ 在适配参数空间中的敏感子空间投影。
适配器 $a$ 对 $b$ 的干扰上界 $\mathrm{Inf}(a\to b)\le \|J_b\|\cdot\|B_aA_a\|_{op}\cdot\rho(a,b)$，其中
$$\rho(a,b)=\frac{\|P_b B_a\|_F}{\|B_a\|_F}\in[0,1].$$
**正交证书**：$\rho(a,b)\le\rho_{max}$（默认 0.05）方可共存；超限先做零空间投影 $B_a\leftarrow (I-P_b^\top P_b)B_a$（O-LoRA 式）后复算；
仍超限则拒绝该盲区修复。$\rho=0$ ⇒ 一阶干扰精确为零。

**定义 440（条件组合单调性）** 新增或合并适配器 $\Delta$ 后，对每个已认证单元格 $b$：
$$m_b' = m_b - \mathrm{Inf}(\Delta\to b) + \mathrm{gain}(\Delta\to b)\ \ge\ m_b-\delta_m$$
才允许提交；否则条件合并失败，回退「并行分路由」或 `stub`。
即：**允许局部变好，禁止任何已认证单元格变差超过 $\delta_m$**。

**定义 441（验证三重门）** V 阶段同时要求：① ToolGauge 的独立回执 $|z|\le\varepsilon_{cross}$；
② 秩-样本一致性（$n_{eff}$ 是否支撑所选 $r$）；③ 干扰回归套件（全部已认证单元格）。三门全过才允许合并。

**定义 442（推测修复 Spec-Repair）** 用检索到的 $\Delta_{draft}$ 作草稿，先在小型留出回执子集上做廉价验证；
通过则以草稿为初值做少量拟合（或直接用），否则回退完整秩拟合。接受判据与完整拟合同一统计水平。

**定义 443（精确回滚与退化链延长）** 适配器与基座分离存储，删除 $(A_s,B_s)$ 后重新由基座计算输出 ⇒ **逐位精确回滚**。
退化链：RankGauge 失败 ⇒ ToolGauge（完整 AP-Cal，无适配器）⇒ LeanGauge ⇒ MODGAUGE。低秩与检索均为增强项，不是依赖项。

**定义 444（语言无旁路 / 提议无伤害）** LLM 提议只能选择 support / rank / 检索初值 / 约束；
所有数值系数由求解器拟合且必须通过定义 441 三重门。错误提议的最坏后果是**被拒绝**，
不能把未认证数值写进契约（引理 55）。

**定义 445（适配器供应链安全）** 库中每个 $\Delta$ 带签名 $\text{sig}$、来源 $\text{prov}$、训练数据摘要；
合并前校验签名与来源；检索命中但验证失败 ⇒ 隔离并告警，并区分「检索到错的」与「库被投毒」。

**定义 446（基座漂移与秩饱和监控）** 统计连续修复的秩占用率 $r_s/r_s^{max}$ 与残差；
连续 $q$ 次饱和（$\ge 0.9$）且残差仍 $>\varepsilon_{repair}$ ⇒ 判定基座先验过时，触发**离线**再预训练（不在线改基座）。

**定义 447（修复证书的秩扩展）** `RepairCert` 增补：$r_s$、support、检索 provenance、正交证书 $\rho$ 表、
条件合并判据、回滚句柄。审计者可据此回答「改了哪里、改了多低秩、影响了谁、如何撤回」。

**定义 448（低秩局部性幻觉告警）** 显式记录：低秩是**容量**约束，不是**因果局部性**的充分条件；
秩 1 沿全局敏感方向的增量仍可污染全局。故定义 439 的正交证书与定义 441 的干扰回归是**必需**而非可选。

**定义 449（继承与退化特例）** 未重定义记号沿用定义 398–431；
令 $r_s=0$、$\mathcal{L}=\varnothing$、$\mathrm{LLM}=\varnothing$ ⇒ RankGauge ≡ ToolGauge；再令 $\mathrm{MP\text{-}}\Phi$ = 物理 GP ⇒ LeanGauge。

## 4. 算法骨架

```python
# IP-322 R-Box：秩预算低秩修复增量（LoRA on frozen metrology base）
class RankRepair:
    def fit(self, s, receipts, H, support, r):
        r = min(r, rank_budget(n_eff(receipts), d_in, d_u))   # 定义 434
        if r < r_min_required(s, receipts):                    # 定义 436
            return None, "non_local_repairable"
        A, B = init_lowrank(support, r)                        # 冻结基座上的零初值
        A, B = solve_ridge(receipts, A, B, frozen=W0)          # 系数由求解器定，非 LLM
        for b in certified_cells():                            # 定义 439 正交化
            B = (I - P_b.T @ P_b) @ B
        return LRA(A, B), "ok"

# IP-323 X-Box：干扰审计 + 条件合并
class XBox:
    def certify(self, new, certified):
        inf = {b: J_b_norm(new) * rho(new, b) for b in certified}   # 定义 439
        if any(v > rho_max for v in inf.values()):
            return False, "interference"
        return True, inf

    def conditional_merge(self, delta_set, margins):
        merged = sum_lora(delta_set)                           # rank <= sum r
        inf = self.certify(merged, margins.keys())
        if not inf[0]: return delta_set, "parallel_route"
        for b, m in margins.items():
            if m - inf[1][b] < m - DELTA_M:                    # 定义 440
                return delta_set, "parallel_route"
        return {merged}, "merged"

# IP-324 P-Box：LLM 上下文结构提议 + 自洽投票
class Proposer:
    def propose(self, receipts, H, library_meta):
        ctx = serialize_numeric(receipts, H, library_meta)     # 白名单，无自由文本
        samples = [self.llm(ctx) for _ in range(K_LLM)]        # 仅结构字段
        support = vote_support(samples)                        # 自洽
        rank = clamp(median_rank(samples), 0, rank_budget(...))
        return Proposal(support, rank, retrieve(library_meta, H))

# IP-325 Spec-Repair：草稿-验证式修复
class SpecRepair:
    def repair(self, s, receipts, H):
        prop = proposer.propose(receipts, H, lib.meta)
        draft = lib.load(prop.retrieved_ids)                   # 热启动
        if verify_cheap(draft, receipts.holdout):              # 定义 442
            return finetune(draft, receipts, prop, steps=SMALL)
        return RankRepair().fit(s, receipts, H, prop.support, prop.rank)

# IP-326 RankGauge-7S 闭环
def rankgauge_7s(M, s):
    H = M.lbox.hypothesize(s, M.dbox.R[s])                     # H
    prog = M.tbox.select(H, M.tools, M.tcv, M.budget_left(s))  # C
    receipts = M.tcv.execute(prog, M.env)                      # E
    if len(receipts) < n_min(s): return stub_and_red(s, "insufficient")
    prop = M.proposer.propose(receipts, H, M.lib.meta)         # P
    delta, why = M.specrepair.repair(s, receipts, H, prop)     # F（秩拟合）
    if delta is None: return stub_and_red(s, why)              # 非局部可修
    if not M.verify3(delta, receipts, M.certified):            # V（三重门）
        return stub_and_red(s, "verify_failed")
    ok, info = M.xbox.certify(delta, M.certified)              # I（干扰）
    if not ok: return stub_and_red(s, "interference")
    M.xbox.conditional_merge([delta], M.margins)               # M（条件合并）
    M.mreg.install_adapter(delta)                              # U（可精确回滚）
    M.dbox.update_from_posterior(s, *delta.predict())          # 继承第 2 轮修复
    bind_claims(delta.cert(H, prop))                           # 定义 447
    M.lib.add(delta, signed=True)                              # 定义 445
    M.pquar.record(delta.rank_ratio, delta.residual)           # 定义 446
    return True

# IP-327 主闭环：50Hz 路径不动；适配器推理为 O(r(d_in+d_u)) 的加性开销
def RankGauge_round(M, obs, audio, tac, depth, det):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s); submit_async(rankgauge_7s, M, s)
    if M.pquar.rank_saturated(): M.schedule_offline_retrain()  # 定义 446
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 5. 推导（引理 51–56）

**引理 51（秩预算泛化界）** 在定义 433–435 的设定下，对任意秩 $r\le r_{cap}$，以至少 $1-\delta$ 概率
$$\mathrm{Err}(\hat u_s)\le \mathrm{Err}_{base}(s)+\varepsilon_{approx}(h_s^*,r)+C\sqrt{\frac{r(d_{in}+d_u)\log(2d/\delta)}{n_{eff}}}.$$
*证明思路*：以低秩矩阵类的 Rademacher 复杂度 $\mathfrak{R}\lesssim\sqrt{r(d_{in}+d_u)/n_{eff}}$ 套标准泛化界，
再对基座误差与秩-$r$ 最佳近似误差做三角分解。

**引理 52（干扰可计算上界与正交零干扰）** $\mathrm{Inf}(a\to b)\le\|J_b\|_{op}\|B_aA_a\|_{op}\rho(a,b)$；
若 $P_bB_a=0$（即 $B_a$ 的列空间与 $b$ 的敏感子空间正交），则一阶干扰精确为 $0$。
*证明思路*：把 $b$ 的输出变化写成 $J_b P_b(B_aA_a)z$，对算子范数做次乘性分解，用 $\|P_bB_a\|_F$ 定义 $\rho$。

**引理 53（条件组合单调性保持）** 若每个新增适配器满足定义 440 的裕度判据且正交化后 $\rho\le\rho_{max}$，
则逐步合并后所有已认证单元格裕度不低于初始值减 $\delta_m$；MODGAUGE 组合单调性在容差 $\delta_m$ 内保持。
*证明思路*：对合并次数归纳，每步用引理 52 的干扰上界，裕度更新为 $m\leftarrow m-\mathrm{Inf}+\mathrm{gain}$。

**引理 54（精确回滚 ⇒ 严格退化链保持）** 只要增量不折叠进 $W_0$，删除适配器后系统输出与基座逐位相同，
故任何修复失败都能**精确**回退，严格退化链的每一级都成立。若为省推理成本把增量折叠进 $W_0$，
则回滚退化为减法、不保证逐位精确——因此折叠必须显式放弃「精确回滚」保证。
*证明思路*：基座输出每次都从冻结的 $W_0$ 重算，增量单独加；折叠路径失去这一性质。

**引理 55（提议无伤害）** 在定义 438 的白名单与 444 的数值隔离下，任意（含对抗性）LLM 提议，
其通过三重门的概率至多为认证水平 $\alpha_{cert}$，与提议内容无关；因此错误提议的最坏后果是被拒绝。
*注意*：若在同一条留出回执上反复试提议，会形成「分叉路径花园」式的多重检验；
需限定提议预算 $B_{LLM}$ 并用 Bonferroni / 保序检验校正（引理 55 的系）。

**引理 56（推测修复接受正确性与加速）** 草稿接受判据使用与完整拟合同水平的留出检验，
故被接受的草稿满足同一统计保证；期望成本 $c_{draft}+(1-p_{acc})c_{full}$，
当 $c_{draft}\ll c_{full}$ 且 $p_{acc}$ 不太低时加速比 $\ge 1$。

## 8. 本轮最大风险（一句话）

**一句话**：低秩是**容量**约束而非**因果局部性**的证明——一个秩为 1、却指向全局最敏感方向的修复增量，
仍能同时污染所有已认证格子；更糟的是，低秩 + 检索 + 自洽投票会让这种污染显得**格外结构化、格外可信**
（它既有证书、又能跨盲区复用），从而使「局部修复、误差局部化」的安全论证以更隐蔽的形式失效。

**次级风险与缓解**：
1. **低秩局部性幻觉** → 正交证书（定义 439）+ 干扰回归（定义 441）+ 显式告警（定义 448），低秩永远不单独作为安全证明；
2. **适配器供应链投毒** → 签名/来源/强制验证/隔离（定义 445），检索只作初值；
3. **检索造成新的跨盲区相关污染** → 每次合并前独立验证 + 库级溯源审计 + 定期全量重验；
4. **非局部可修被低秩强行掩盖** → 定义 436 的 $\inf_r\mathrm{Err}$ 判据与离线再训练出口；
5. **LLM 提议的隐藏多重检验** → 提议预算 $B_{LLM}$ + 保序检验/Bonferroni（引理 55 系）；
6. **合并牺牲精确回滚** → 折叠进 $W_0$ 必须显式放弃回滚保证（引理 54），默认保留分离存储；
7. **基座过时** → 秩饱和监控（定义 446）触发离线再预训练，绝不在线改基座。

## 2. 形式化定义（要点）

**定义 432（冻结基座与适配位点）** 部署期 $\theta^*$ 不可写；只允许在 calibration head 的 $W_0$ 与预注册残差头上做加法增量；其他写入违反不变式。
**定义 433（低秩修复增量）** $u_s=W_0z_s+\alpha_sB_sA_sz_s$，零初值 ⇒ 未适配时与基座逐位相同；删除即恢复。
**定义 434（秩预算）** $n_{eff}=(\operatorname{tr}I_s)^2/\operatorname{tr}(I_s^2)$；$r_s^{max}=\max\{r\le r_{cap}:Cr(d_{in}+d_u)\log(2d/\delta)\le n_{eff}\varepsilon_{gen}^2\}$。
**定义 435（三元权衡）** $\mathrm{Err}_s(r)\le \mathrm{Err}_{base}(s)+\varepsilon_{approx}(h_s^*,r)+C\sqrt{r(d_{in}+d_u)\log(2d/\delta)/n_{eff}}$；最优秩取三者交点。
**定义 436（非局部可修）** $\inf_{r\le r_{cap}}\mathrm{Err}_s(r)>\varepsilon_{repair}$ ⇒ 不写适配器，`stub+RED`，进离线再预训练队列。
**定义 437（适配器库与检索）** 库项含 $\Delta$、元数据、签名、来源；检索只作热启动初值，必须过验证。
**定义 438（结构提议契约）** 输入白名单（数值回执 / $H_s$ / 库元数据，无原始权重）；输出仅结构字段；$k$ 条自洽投票；rank 夹到 $[0,r_s^{max}]$。
**定义 439（干扰度与正交证书）** $\rho(a,b)=\|P_bB_a\|_F/\|B_a\|_F$；$\mathrm{Inf}(a\to b)\le\|J_b\|\|B_aA_a\|_{op}\rho(a,b)$；$\rho=0$ ⇒ 一阶干扰为零。
**定义 440（条件组合单调性）** $m_b'=m_b-\mathrm{Inf}(\Delta\to b)+\mathrm{gain}(\Delta\to b)\ge m_b-\delta_m$ 对所有已认证格子成立才可提交。
**定义 441（三重门）** 独立回执 $|z|\le\varepsilon_{cross}$ + 秩-样本一致性 + 干扰回归，三门全过才合并。
**定义 442（推测修复）** 检索草稿先做廉价留出验证；通过则小拟合，否则完整秩拟合；接受判据与完整拟合同级。
**定义 443（精确回滚与退化链）** 增量与基座分离存储，回滚由基座重算 ⇒ 逐位精确；失败逐级退回 ToolGauge / LeanGauge / MODGAUGE。
**定义 444（提议无伤害）** 语言只选结构；系数由求解器定且必须过三重门；错误提议最坏被拒绝。
**定义 445（供应链安全）** 库项签名 + 来源 + 数据摘要；合并前校验；验证失败的检索项隔离告警，区分「检索错误」与「投毒」。
**定义 446（基座漂移与秩饱和）** 连续 $q$ 次 $r_s/r_s^{max}\ge0.9$ 且残差 $>\varepsilon_{repair}$ ⇒ 离线再预训练，不在线改基座。
**定义 447（秩扩展证书）** `RepairCert`$^+$ 增补 rank/support/provenance/$\rho$ 表/合并判据/回滚句柄。
**定义 448（局部性幻觉告警）** 低秩是容量约束，不是因果局部性的充分条件；正交证书与干扰回归是必需项。
**定义 449（继承与退化特例）** $r_s=0,\mathcal{L}=\varnothing,\mathrm{LLM}=\varnothing$ ⇒ RankGauge ≡ ToolGauge；再令 MP-Φ = 物理 GP ⇒ LeanGauge。

## 3. 关键算法骨架

```python
# IP-322 R-Box：秩预算低秩修复
class RankRepair:
    def fit(self, s, receipts, H, support, r):
        r = min(r, rank_budget(n_eff(receipts), d_in, d_u))
        if r < r_min_required(s, receipts):
            return None, "non_local_repairable"            # 定义 436
        A, B = init_lowrank(support, r)                    # 零初值
        A, B = solve_ridge(receipts, A, B, frozen=W0)      # 数值由求解器定
        for b in certified_cells():
            B = (I - P_b.T @ P_b) @ B                      # 定义 439 正交化
        return LRA(A, B), "ok"

# IP-323 X-Box：干扰证书 + 条件合并
class XBox:
    def certify(self, new, certified):
        inf = {b: J_b_norm(new) * rho(new, b) for b in certified}
        return (all(v <= rho_max for v in inf.values()), inf)

    def conditional_merge(self, deltas, margins):
        merged = sum_lora(deltas)                          # rank <= sum r
        ok, inf = self.certify(merged, margins.keys())
        if not ok: return deltas, "parallel_route"
        if any(margins[b] - inf[b] < margins[b] - DELTA_M for b in margins):
            return deltas, "parallel_route"                # 定义 440
        return [merged], "merged"

# IP-324 P-Box：LLM 结构提议 + 自洽
class Proposer:
    def propose(self, receipts, H, library_meta):
        ctx = serialize_numeric(receipts, H, library_meta) # 白名单
        samples = [self.llm(ctx) for _ in range(K_LLM)]    # 仅结构字段
        return Proposal(support=vote_support(samples),
                        rank=clamp(median_rank(samples), 0, rank_budget(...)),
                        ids=retrieve(library_meta, H))

# IP-325 Spec-Repair：草稿-验证
class SpecRepair:
    def repair(self, s, receipts, H):
        prop = proposer.propose(receipts, H, lib.meta)
        draft = lib.load(prop.ids)
        if verify_cheap(draft, receipts.holdout):          # 定义 442
            return finetune(draft, receipts, prop, steps=SMALL), "ok"
        return RankRepair().fit(s, receipts, H, prop.support, prop.rank)

# IP-326 RankGauge-7S 闭环
def rankgauge_7s(M, s):
    H = M.lbox.hypothesize(s, M.dbox.R[s])                    # H
    prog = M.tbox.select(H, M.tools, M.tcv, M.budget_left(s)) # C
    receipts = M.tcv.execute(prog, M.env)                     # E
    if len(receipts) < n_min(s): return stub_and_red(s, "insufficient")
    prop = M.proposer.propose(receipts, H, M.lib.meta)        # P
    delta, why = M.specrepair.repair(s, receipts, H)          # F
    if delta is None: return stub_and_red(s, why)
    if not M.verify3(delta, receipts, M.certified):           # V
        return stub_and_red(s, "verify_failed")
    ok, info = M.xbox.certify(delta, M.certified)             # I
    if not ok: return stub_and_red(s, "interference")
    M.xbox.conditional_merge([delta], M.margins)              # 条件合并
    M.mreg.install_adapter(delta)                             # U（可精确回滚）
    M.dbox.update_from_posterior(s, *delta.predict())
    bind_claims(delta.cert(H, prop))                          # 定义 447
    M.lib.add(delta, signed=True)                             # 定义 445
    M.pquar.record(delta.rank_ratio, delta.residual)          # 定义 446
    return True

# IP-327 主闭环
def RankGauge_round(M, obs, audio, tac, depth, det):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s); submit_async(rankgauge_7s, M, s)
    if M.pquar.rank_saturated(): M.schedule_offline_retrain()
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 4. 推导

**引理 51（秩预算泛化界）** 对任意 $r\le r_{cap}$，以至少 $1-\delta$ 概率
$\mathrm{Err}(\hat u_s)\le \mathrm{Err}_{base}(s)+\varepsilon_{approx}(h_s^*,r)+C\sqrt{r(d_{in}+d_u)\log(2d/\delta)/n_{eff}}$。
*思路*：低秩矩阵类 Rademacher 复杂度 $\mathfrak{R}\lesssim\sqrt{r(d_{in}+d_u)/n_{eff}}$，套标准泛化界，再做三角分解。

**引理 52（干扰上界与正交零干扰）** $\mathrm{Inf}(a\to b)\le\|J_b\|_{op}\|B_aA_a\|_{op}\rho(a,b)$；若 $P_bB_a=0$ 则一阶干扰精确为 $0$。
*思路*：$b$ 的输出变化为 $J_bP_b(B_aA_a)z$，用算子范数次乘性与 $\rho$ 的定义。

**引理 53（条件组合单调性保持）** 若每个新增适配器满足定义 439–440，则逐步合并后所有已认证格子裕度不低于初始值减 $\delta_m$；MODGAUGE 组合单调性在容差内保持。
*思路*：对合并次数归纳，每步用引理 52 的干扰上界更新裕度。

**引理 54（精确回滚 ⇒ 严格退化链保持）** 只要增量不折叠进 $W_0$，删除后输出与基座逐位相同；折叠则回滚退化为减法、不保证逐位一致，因此折叠必须显式放弃该保证。
*思路*：基座每次由冻结 $W_0$ 重算，增量分离存储。

**引理 55（提议无伤害）** 在白名单与数值隔离下，任意（含对抗）LLM 提议通过三重门的概率至多 $\alpha_{cert}$，与提议内容无关，故最坏后果是被拒绝。
*系*：同一留出集上反复试提议会形成多重检验；限定 $B_{LLM}$ 并用 Bonferroni / 保序检验校正。

**引理 56（推测修复正确性与加速）** 接受判据与完整拟合同级，故被接受草稿满足同统计保证；期望成本 $c_{draft}+(1-p_{acc})c_{full}$，当 $c_{draft}\ll c_{full}$ 且 $p_{acc}$ 不太低时加速比 $\ge1$。

## 7. 与 ToolGauge 的差异与继承

- **继承**：D-Box 盲区判定（定义 398/399）、L-Box 语义假设与共形覆盖（422、425）、TCV 工具契约（416–418）、
  双层下注（419）、MP-Φ 摊销先验（420）、6C 的 H/C/E/V/U 骨架、P-Quarantine 思路、MODGAUGE 五不变式。
- **结构改动**：把「AP-Cal 就地改写共享先验 + 整子图热替换」改为「冻结基座 + 每盲区低秩增量 + 条件合并」。
- **加强的不变式**：组合单调性 → 条件组合单调性（含可计算干扰上界）；严格退化链新增「精确回滚」一级。
- **修复的第 2 轮缺陷**：跨盲区相关偏差、单回执验证过弱、$n_{min}$ 高斯假设、P-Quarantine 漏幅度、热替换回滚不精确、
  成本模型漏项，以及新增的检索污染攻击面（见 idea 区 §7 表）。
- **新增纪律**：语言只提议结构（定义 438/444）、低秩不单独作为局部性证明（定义 448）、
  折叠进基座即放弃精确回滚（引理 54）。

## 8. 本轮最大风险

**一句话**：低秩是**容量**约束而非**因果局部性**的证明——一个秩 1、却指向全局最敏感方向的修复增量，
仍能污染所有已认证格子；而低秩 + 检索 + 自洽投票会让这种污染显得格外结构化、格外可信
（有证书、可跨盲区复用），使「局部修复、误差局部化」的安全论证以更隐蔽的形式失效。
**兜底**：正交证书（定义 439）+ 干扰回归（定义 441）+ 显式告警（定义 448）+ 精确回滚（定义 443），
并以 E442/E443/E449/E456 作为证伪实验；低秩永远不单独作为安全证明。
