# 第 1 轮（新灵感循环第 1 轮；本轮灵感：「UniBot-V1」×「语义建图」；技术基线延续 v15）

> **基线**：第 13 轮 MetricVoiceGauge-NCD-HUTDH v15（技能扩散版：SCD/DSD/DCA/EDC，定义 607–626；引理 125–130；实验 E661–E670）。
> **本轮纪律**：**基座模型只作提案先验 + 语义地图是证书索引与定义域 + 语义证书运输只收缩、按运输间隙计费、失效即退回 v15**。不推倒 v15：v15 的 SCD/DSD/DCA/EDC、v13 的 AIO/CPD/DGC/DDL/RTCR、v12 的 USG/TGC/BAA/GAGP/UC、v11 的 HAS/HCC/HATD/HDT、v10 的 NGE/DSL/CC/CWM/CAE/NCP、v9 的 AC/MW/ID、v8 的 DA/SPR/Cal 与九不变式全部保留。六个新组件——SMC（语义地图证书）、UPG（UniBot 提案治理器）、SCT（语义证书运输）、SAM（语义别名监视器）、SMDL（语义退化阶梯）、LCR（语言—证书路由器）——一律以**收缩算子**接入：只收缩授权集、只增加支撑/时效/运输余量；失效即严格退回 v15（引理 140），再沿 v15→v14→…→v6 退化链退回。本轮只做三件事：把 UniBot-V1 从“决策者”降格为**不受信的提案者**、把语义地图从“几何地图的标签层”改写为**证书的索引与定义域**、把跨区域语义泛化改写为**带运输间隙证书的证书复用**。

## 0. 直觉与动机

**灵感 1（UniBot-V1 → 通用机器人基座模型是提案先验，不是安全证书）**
直觉：UniBot-V1 这类通用机器人基座模型最诱人的地方，是它能把自然语言、物体语义、技能先验和跨本体动作合到一个模型里，于是“看起来什么都会”。但它的“会”是**平均意义上的会**：它在训练分布内能给出语义上极其合理的动作，却在薄接触、重载、透明/反光物体、软体/可变形物体和新颖支撑面上没有任何逐实例保证。更隐蔽的是，基座模型的置信度与物理可行性几乎不相关——它可以非常自信地提议一个语义上正确、物理上却超出力矩/摩擦/工作空间的动作。核心创新：**把 UniBot-V1 严格降格为提案分布 `π_U(a,s,g,c|x,ℓ)`，只允许它给候选排序、提出“去查哪一片语义地图”的查询，绝不授权任何动作**。安全执行集由 v15 物理证书与语义地图证书的**取交**决定；换基座模型只改变效率，不改变安全集（引理 137）。反直觉点：**基座模型的泛化能力应当用于“更快找到已认证的动作”，而不是“认证更多动作”**；越强的模型越应该被用来节省查询预算，而不是被用来放宽证书。

**灵感 2（语义建图 → 语义地图是证书的索引，不是几何地图的注释）**
直觉：传统语义建图先建几何地图，再给格子贴“杯子/桌子/可抓取”的标签，规划器据此选目标。但对安全关键系统，标签不是“关于世界的描述”，而是**一条带支撑、带时效、带几何不确定性的谓词**：如果地图把一块反光区域误标为“可抓取”，那么基于该标签复用的证书会把一个未验证的动作放进执行集。更关键的是，语义地图天然会**在人类觉得“正常”的区域密集、在新颖/危险区域稀疏**，恰好把最需要证书的地方留成支撑空洞。核心创新：**证书索引语义地图（Certificate-Indexed Semantic Map）+ 语义接地证书（Semantic Grounding Certificate, SGC）**。每个地图单元不只存标签，还存：标签后验与不确定度、观测支撑与覆盖率、新鲜度、膨胀后的几何包络、以及一个**v15 证书句柄**（该单元内哪些技能/动作被物理证书覆盖）。单元只有在支撑足够、未过期、标签不确定度足够小、且证书句柄非空时才“有效”。反直觉点：**让语义地图更安全的方式不是让它更准，而是让它更诚实地标出“哪里没有支撑”**；空洞和别名区是一等公民，必须触发证书收缩或主动补证，而不是被平滑插值。

**灵感 3（UniBot × 语义建图 → 语义证书运输与提案—验证闭环）**
直觉：人类能在新房间里快速工作，是因为会把“杯子在桌边要小心”“拉开抽屉前先退半步”这类经验**按语义等价迁移**到新场景。我们想给这种迁移配一张“安全收据”：只有在语义抽象被认证为保持物理谓词时，才允许把源区域的证书运输到目标区域。核心创新：**语义证书运输（Semantic Certificate Transport, SCT）+ 运输间隙证书（Transport Gap Certificate, TGC-sem）+ 语义别名监视器（Semantic Aliasing Monitor, SAM）**。把语义地图按抽象 `α` 商成一个**运输图**；每条边带一个单侧间隙 `U_trans`，由标签差异、几何差异、能力（摩擦/质量/柔顺）差异和时效差异共同构成。只有当源证书余量 `m_c(a) ≥ U_trans(c→c')` 时才允许运输，且运输后的授权集只会变小。UniBot 负责提出“这两个区域在语义上是一类”的假设与查询顺序，SCT 负责验证并计费；验证失败就退回精确单元认证或几何-only 回退。反直觉点：**语义泛化不是免费的午餐，它是一笔按跳数计息的贷款**；运输间隙会沿路径累加（引理 134），因此必须周期性地重新锚定到真实观测，而不是无限复用。

**三者如何统一**
统一为 **v15 物理证书层之上的“语义接地层”**：v15 回答“在状态 x 下哪些动作被物理证书授权”（`Exec_v15`），v16 回答“在语义地图的哪一片区域、凭哪条运输路径、在多大的支撑/时效/别名风险下，这些授权才可被执行”（`Exec_v16`）。SMC 把语义地图变成证书索引；UPG 把 UniBot 变成不受信的提案者；SCT 把跨区域复用变成带间隙的单调收缩；SAM 在线检查支撑空洞、标签漂移与语义别名；SMDL/LCR 在风险升高时只向更保守档位塌缩并重排候选。共享状态 `ζ_sem=(level, U_trans^*, drift_sem, alias_risk, holes, refresh_age, B_sem, query_set)`。**SMC 回答“哪里被认证”，UPG 回答“先试哪个已认证候选”，SCT 回答“能不能把证书借过去”，SAM/SMDL 回答“借来的证书现在还作不作数”**。

## 1. 研究问题（轮次升级版）

- **Q1（语义接地证书的可证语义）**：如何定义“有效语义单元”，才能使标签错误、遮挡、反光/透明、可变形物体只导致假拒绝而绝不产生假接受？语义证书与 v15 的 GAGP/UC/TGC/四重证书如何合取而不重复计错？几何膨胀与标签不确定度应如何分工？
- **Q2（语义证书运输的 soundness 与紧致性）**：如何用共形方法给出单侧运输间隙 `U_trans`？标签差异、几何差异、能力差异、时效差异如何分解与合成？运输间隙沿路径如何复合、何时必须重新锚定？同标签不同能力的“语义别名”如何被显式计入而不是被标签一致性掩盖？
- **Q3（提案—验证路由的最优性）**：如何让 UniBot-V1 只在已认证集合内排序，从而“模型越强只越省查询”？语言歧义如何转化为证书查询而不是直接授权？查询/补证预算如何分配给“运输验证、支撑空洞探测、重新锚定”三者？
- **Q4（与 v15 的兼容与活性）**：语义地图查询 + 运输图最短路径能否守住 50Hz/p99≤22ms？SMC/SCT 的误差是否会与 v15 的 DCA/EDC 同向叠加？退化到第 0 档是否会清空可行集、导致频繁 `a_ask`？六个新组件全部失效时是否严格等价 v15？

## 2. 设计原则（在 P22–P24 基础上新增 P25–P27）

**P25 基座模型只提案不授权律（Foundation Model Proposes, Never Authorizes）**
任何基座模型输出（动作、技能、目标、区域对应）都只是提案分布 `π_U`。提案必须先经过 `Exec_v16` 的成员过滤，之后才允许用于排序或查询；`π_U` 的置信度不得进入任何证书阈值或安全判定。更换、升级、微调基座模型不得改变 `Exec_v16` 的安全语义，只能改变候选顺序与查询效率。

**P26 语义标签必须携带证据律（No Label Without Support）**
语义标签只有在同时满足支撑量、覆盖率、时效、标签不确定度、几何膨胀和 v15 证书句柄六项检查时才可作为证书索引。禁止“仅凭标签相似”把动作放入执行集；禁止对支撑空洞做平滑/插值；禁止把“同类别”当作“同能力”。语义地图必须把空洞、过期区和别名区显式暴露给下游，而不是用先验填平。

**P27 运输只收缩且必须重新锚定律（Transport Shrinks and Must Re-Anchor）**
语义证书运输只能产生源授权集的子集：`Acc_{c→c'}(U_trans) ⊆ Acc_c ⊆ Acc_v15`。运输间隙必须单侧、可复合、按跳数累加；超过 `K_max` 跳或累计间隙超过预算时必须重新观测/重新校准，禁止用环路或长链“重置”间隙。检测到支撑空洞、时效过期、标签漂移或能力别名时，必须沿 SMDL 向更保守档位塌缩，最坏退回 v15。

## 3. 与基线的接口（如何退化）

- **SMC 失效** ⇒ 语义地图退化为单一“全工作空间”单元且不带任何语义标签，只保留 v15 证书句柄，`Exec_v16=Exec_v15`，**等价 v15 几何路径**；
- **UPG 失效** ⇒ 忽略 UniBot 输出，在已认证集合内按固定顺序/均匀随机排序，安全集不变，**等价“v15 + 无语义提案”**；
- **SCT 失效** ⇒ `U_trans≡∞`，禁止任何跨单元运输，只允许精确单元认证，**等价“v15 + 离散语义重放”**；
- **SAM 失效** ⇒ 保守地视所有单元为潜在别名区，强制停在 `level≤1`，**等价“v15 + 精确单元 + 无运输”**；
- **SMDL 失效** ⇒ 只保留单一档位：精确单元 + 最保守技能，无阶梯、无塌缩，**等价“v15 + 单点语义锚”**；
- **LCR 失效** ⇒ 放弃语言→证书查询，改由 v15 静态调度器按固定顺序调用技能，**等价 v15 调度路径**；
- **六者全失效** ⇒ MetricVoiceGauge-NCD-HUTDH v15，再沿 v15→v14→v13→…→v6 退化链退回；
- **安全继承**：SMC 只做有效性过滤，UPG 只做已认证集合内排序，SCT 只做单侧收缩运输，SAM 只做降档触发，SMDL 只做单调退化，LCR 只做约束查询。六端口均不能新增授权或放宽任何 v15 阈值；`Exec_v16⊆Exec_v15` 由引理 131 保证，最坏退化由引理 140 保证。

## 4. 预期贡献

1. **提案—证书分离定理**：把 UniBot-V1 从“安全责任主体”降格为不受信提案者，证明安全执行集与基座模型无关，只与 v15 证书和语义接地证书有关；由此得到“换模型不需重认证安全、只影响效率”的工程结论；
2. **证书索引语义地图**：把语义建图从标签层改写为带支撑、时效、几何膨胀、能力句柄与别名风险的证书索引，使“地图哪里可信”成为可检查对象，而不是感知模块的内部副产品；
3. **语义证书运输与间隙计费**：给出跨区域复用证书的单侧间隙证书、三角复合与重新锚定预算，把“语义泛化”从定性能力变成可计量、可审计的安全贷款；
4. **语义退化阶梯与语言—证书路由**：在支撑空洞、时效过期、别名、漂移下单调塌缩，语言只产生证书查询、不产生授权；E671–E690 覆盖语义 soundness、运输 tightness、别名检测、空洞补证、跨本体迁移、实时性与端到端消融。

## 5. 本轮最大风险

**一句话**：语义地图与 UniBot-V1 共享同一套语义先验，当新颖物体的标签被二者“一致地”误判时，运输间隙会因校准集缺少该别名样本而被系统性低估，系统可能在“标签一致、证书已运输、每步都在支撑内”的表象下执行一个物理上从未被验证的动作——即**语义自洽的、运输可证的、却绝对错误的安全决定**。

## 0. 核心符号体系（定义 627–646）

| 符号 | 含义 |
|---|---|
| `M = {c_1,…,c_N}` | 证书索引语义地图；每个单元是一个带证据的语义区域 |
| `G_c ⊆ ℝ³` | 单元 `c` 的几何区域；`G_c^⊕ = G_c ⊕ B(0,δ_geo(c))` 为膨胀后的包络 |
| `p_c(y)` | 单元 `c` 在语义类别 `y∈Y` 上的标签后验分布 |
| `U_L(c)` | 标签不确定度，`U_L(c)=1−max_y p_c(y)` |
| `S_c, ρ_c, age_c` | 有效观测支撑量、覆盖率、距上次验证的时长 |
| `H_c` | v15 证书句柄：`H_c = {(s,a) : a 在 G_c^⊕ 上被 v15 物理证书覆盖}` |
| `Acc_c(x)` | 单元 `c` 内对 `G_c^⊕` 一致有效的动作集：`{a : inf_{p∈G_c^⊕} m_v15(a,p,x) ≥ 0}` |
| `GC(c)` | 语义接地证书，`GC(c)=(p_c,U_L(c),S_c,ρ_c,age_c,G_c^⊕,H_c,U_aff(c))` |

| `Exec_v16(x)` | 语义层可执行集：`{(c,a) : Valid(c), a∈Acc_c(x)∩Acc_v15(x)}` |
| `π_U(a,s,g,c|x,ℓ)` | UniBot-V1 的提案分布；只含未校准分数，不含任何证书语义 |
| `Prop(x,ℓ)` | 被治理后的提案集：`supp(π_U)∩Exec_v16(x)` |

| `G_tr=(M,E_tr)` | 语义运输图；边 `(c,c')` 存在当且仅当 `α(c)=α(c')` 且校准充分 |

| `Alias(c,c')` | 语义别名风险：标签相同但能力（质量/摩擦/柔顺）显著不同的概率上界 |
| `Q_ℓ, C_ℓ` | 语言指令 `ℓ` 的证书查询约束与满足约束的已认证候选集 |
| `SMDL = (L_0⊆…⊆L_m)` | 语义退化阶梯；`L_0` 为停/问或纯几何回退，`L_m` 为多跳运输 |
| `ζ_sem` | 语义共享状态：`(level, U_trans^*, drift_sem, alias_risk, holes, refresh_age, B_sem, query_set)` |
| `B_sem, K_max` | 语义风险预算与最大运输跳数；`K_max=⌊B_sem/ΔU⌋`，超过必须重新锚定 |

# IP-402 Semantic Map Certificate：把语义地图单元变成可检查的证书索引
class SemanticMapCertificate:
    def __init__(self, cells, v15_cert, n_min=30, rho_min=0.8,
                 T_fresh=120.0, eps_label=0.05, tau_alias=0.05):
        self.cells = cells
        self.v15 = v15_cert
        self.n_min, self.rho_min = n_min, rho_min
        self.T_fresh, self.eps_label = T_fresh, eps_label
        self.tau_alias = tau_alias

    def valid(self, c, now):
        # 六项证据检查 + 别名检查；任一失败即整单元无效
        if c.support < self.n_min:                 return False
        if c.coverage < self.rho_min:              return False
        if now - c.t_last > self.T_fresh:          return False
        if c.U_label > self.eps_label:             return False
        if c.hole or c.U_aff > self.tau_alias:     return False
        if not c.handles:                          return False
        # 句柄必须在膨胀几何上一致有效，而不是只在中心点有效
        return all(self.v15.margin(s, a, geom=c.G_inflated) >= 0
                   for (s, a) in c.handles)

    def authorized(self, c, x):
        if not self.valid(c, x.now):
            return set()
        return {a for (s, a) in c.handles
                if a in self.v15.authorized(s, x)
                and self.v15.margin(s, a, geom=c.G_inflated) >= 0}

    def executable_set(self, x):
        return {(c.id, a) for c in self.cells
                for a in self.authorized(c, x)}

    def holes(self, now):
        return {c.id for c in self.cells if not self.valid(c, now)}


# IP-403 UniBot Proposal Governor：先过滤、后排序；提案永不扩张授权
class UniBotProposalGovernor:
    def __init__(self, unibot, lam_progress=1.0, mu_risk=1.0):
        self.unibot = unibot
        self.lam, self.mu = lam_progress, mu_risk

    def govern(self, x, ell, exec_set):
        # 1. UniBot 只给“候选—分数”，分数不参与任何证书阈值
        scores = self.unibot.score_candidates(x, ell)
        # 2. 先过滤：不在 Exec_v16 中的提案直接丢弃
        certified = [(c, a) for (c, a) in exec_set if (c, a) in scores]
        if not certified:
            return None, "no_certified_proposal"
        # 3. 后排序：只在已认证集合内用提案分数、进度与风险做偏序
        def value(ca):
            c, a = ca
            return (scores[ca]
                    + self.lam * progress(c, a, x, ell)
                    - self.mu * risk(c, a, x))
        return max(certified, key=value), "ok"


# IP-404 Semantic Certificate Transport：单侧间隙、路径复合、只取子集
class SemanticCertificateTransport:
    def __init__(self, alpha=0.05, max_hops=4, min_pairs=20):
        self.alpha = alpha
        self.max_hops = max_hops
        self.min_pairs = min_pairs

    def edge_gap(self, c, cp, cal_pairs):
        # 校准对不足时禁止运输，而不是用先验猜一个间隙
        d = [p.d_phys for p in cal_pairs
             if p.src == c.id and p.dst == cp.id]
        if len(d) < self.min_pairs:
            return float("inf")
        return conformal_upper(d, 1 - self.alpha)

    def path_gap(self, c, cp, graph, cal_pairs):
        # Bellman-Ford 风格的最短间隙路径；跳数受限，防止长链无限借证
        dist = {c.id: 0.0}
        for _ in range(self.max_hops):
            updated = False
            for (u, v) in graph.edges:
                w = self.edge_gap(u, v, cal_pairs)
                if dist.get(u, float("inf")) + w < dist.get(v, float("inf")):
                    dist[v] = dist[u] + w
                    updated = True
            if not updated:
                break
        return dist.get(cp.id, float("inf"))

    def transport(self, c, cp, acc_c, margins, graph, cal_pairs):
        U = self.path_gap(c, cp, graph, cal_pairs)
        if U == float("inf"):
            return set(), U
        # 运输只删除“付不起间隙”的动作，绝不新增
        return {a for a in acc_c if margins[(c.id, a)] - U >= 0}, U


# IP-405 Semantic Aliasing Monitor：同标签不等于同能力
class SemanticAliasingMonitor:
    def __init__(self, tau_drift=0.1, tau_alias=0.05):
        self.tau_drift, self.tau_alias = tau_drift, tau_alias

    def check(self, c, x, map_cal):
        drift = map_cal.feature_distance(c, x)
        stale = (x.now - c.t_last) > c.T_fresh
        alias = c.U_aff                       # 能力差异的直接上界
        if drift > self.tau_drift or stale or alias > self.tau_alias:
            return "collapse"
        if c.hole or c.support < c.n_min or c.coverage < c.rho_min:
            return "hole"
        return "ok"


# IP-406 Semantic Degradation Ladder：只向更保守方向移动
class SemanticDegradationLadder:
    LEVELS = ["stop_or_ask", "exact_cell", "one_hop_transport",
              "multi_hop_transport"]

    def __init__(self, smc, sct, sam):
        self.smc, self.sct, self.sam = smc, sct, sam
        self.level = len(self.LEVELS) - 1

    def step(self, x, map_cal, current_cells):
        status = self.sam.check_current(current_cells, x, map_cal)
        if status == "collapse":
            self.level = 0
        elif status == "hole":
            self.level = max(0, self.level - 1)
        # 没有完整的重新观测/审计事件时，禁止升档
        return self.LEVELS[self.level]

    def authorized(self, x, map_cal, current_cells):
        lvl = self.step(x, map_cal, current_cells)
        if lvl == "stop_or_ask":
            return set()
        if lvl == "exact_cell":
            return self.smc.executable_set(x)
        if lvl == "one_hop_transport":
            return self._transport_closure(x, hops=1)
        return self._transport_closure(x, hops=self.sct.max_hops)


# IP-408 Semantic Support Prober：空洞处的最小代价补证
class SemanticSupportProber:
    def __init__(self, smc, cost_probe, cost_move, cost_ask):
        self.smc = smc
        self.c_probe, self.c_move, self.c_ask = cost_probe, cost_move, cost_ask

    def propose(self, holes, x, budget):
        options = []
        for h in holes:
            options.append(("probe", h, self.c_probe(h)))
            options.append(("retreat", h, self.c_move(h, x)))
            options.append(("ask", h, self.c_ask))
        feasible = [o for o in options if o[2] <= budget]
        if not feasible:
            return None
        return min(feasible, key=lambda o: o[2])


# IP-409 Semantic Transport Auditor：运输图不是一次性资产
class SemanticTransportAuditor:
    def __init__(self, min_pairs=20, max_cycle_gain=0.0):
        self.min_pairs, self.max_cycle_gain = min_pairs, max_cycle_gain

    def audit(self, graph, cal_pairs, alias_flags):
        bad_edges = set()
        for (u, v) in graph.edges:
            n = len([p for p in cal_pairs if p.src == u.id and p.dst == v.id])
            if n < self.min_pairs:
                bad_edges.add((u.id, v.id))     # 校准不足：禁用边
            if alias_flags.get((u.id, v.id), False):
                bad_edges.add((u.id, v.id))     # 别名污染：禁用边
        # 任何环路都不得“重置”间隙；检测到异常增益即整边禁用
        for cyc in graph.cycles():
            gain = sum(graph.edge_gap(e) for e in cyc)
            if gain <= self.max_cycle_gain:
                for e in cyc:
                    bad_edges.add((e[0].id, e[1].id))
        return bad_edges


# IP-407 Language–Certificate Router：语言只查询，不授权
class LanguageCertificateRouter:
    def __init__(self, smc, sct, ladder, governor):
        self.smc, self.sct = smc, sct
        self.ladder, self.governor = ladder, governor

    def route(self, ell, x, map_cal, current_cells):
        constraints = parse_language(ell)          # 类别、空间关系、目标谓词
        cells = [c for c in self.smc.cells
                 if satisfies(c, constraints)]
        exec_set = self.ladder.authorized(x, map_cal, current_cells)
        # 语言约束只做“筛选”，最终候选仍须同时属于语义证书与 v15 授权
        cands = [(c, a) for c in cells
                 for a in self.smc.authorized(c, x)
                 if (c.id, a) in exec_set]
        if not cands:
            return None, "ambiguous_or_uncertified"
        proposal, status = self.governor.govern(x, ell, cands)
        return proposal, status


# 主闭环集成：MetricVoiceGauge-NCD-HUTDH-v16（UniBot 语义接地版）
def metricvoicegauge_round_16_semantic_grounding(M, s, obs, sem_map=None,
                                                  unibot=None, ell=None, ...):
    # ---- v15 主路径原样保留（SCD/DSD/DCA/EDC + 继承路径）----
    results = middleware.run_cycle(runners={...}, ctx=ctx)
    nge.update_belief(obs)
    hcc.update_identification(obs.motor_enc, obs.joint_enc, obs.current)

    # ---- 1. 构造语义证书、运输图、别名监视与阶梯 ----
    smc = SemanticMapCertificate(sem_map.cells, ctx.v15_cert,
                                 n_min=ctx.n_min, rho_min=ctx.rho_min,
                                 T_fresh=ctx.T_fresh,
                                 eps_label=ctx.eps_label,
                                 tau_alias=ctx.tau_alias)
    sct = SemanticCertificateTransport(alpha=ctx.alpha_sem,
                                       max_hops=ctx.max_hops,
                                       min_pairs=ctx.min_pairs)
    sam = SemanticAliasingMonitor(tau_drift=ctx.tau_drift,
                                  tau_alias=ctx.tau_alias)
    ladder = SemanticDegradationLadder(smc, sct, sam)
    governor = UniBotProposalGovernor(unibot or ctx.unibot)
    router = LanguageCertificateRouter(smc, sct, ladder, governor)
    prober = SemanticSupportProber(smc, ctx.c_probe, ctx.c_move, ctx.c_ask)
    auditor = SemanticTransportAuditor(ctx.min_pairs)

    # ---- 2. 审计运输图：校准不足/别名污染/异常环路的边直接禁用 ----
    bad_edges = auditor.audit(sem_map.transport_graph, sem_map.cal_pairs,
                              sem_map.alias_flags)
    sem_map.transport_graph.disable(bad_edges)

    # ---- 3. 先由语义层给出“被认证的可执行集” ----
    current_cells = sem_map.cells_in_view(obs)
    exec_sem = ladder.authorized(obs, sem_map.calibration, current_cells)
    if not exec_sem:
        holes = smc.holes(obs.now)
        action = prober.propose(holes, obs, ctx.B_sem)
        if action is not None and action[0] == "probe":
            execute_probe(action[1])
            return M.inherited_v15_path(ctx)
        return M.strict_fallback_v15(obs)          # 第 0 档

    # ---- 4. UniBot 只在已认证集合内提案；提案失败不影响安全 ----
    proposal, status = router.route(ell or ctx.instruction, obs,
                                    sem_map.calibration, current_cells)
    if status != "ok":
        return M.strict_fallback_v15(obs)

    c_star, a_star = proposal

    # ---- 5. 执行前再做一次有效性/别名/新鲜度合取 ----
    if not smc.valid(c_star, obs.now):
        return M.strict_fallback_v15(obs)
    if sam.check(c_star, obs, sem_map.calibration) == "collapse":
        ladder.level = 0
        return M.strict_fallback_v15(obs)

    # ---- 6. 只执行取交后的动作；任何越界即退回 v15 ----
    skill_star = ctx.skill_of(a_star)
    if (a_star in ctx.v15.authorized(skill_star, obs)
            and (c_star.id, a_star) in exec_sem):
        execute(ctx.v15.refine(a_star, c_star.G_inflated), obs)
    else:
        return M.strict_fallback_v15(obs)

    # ---- 7. 低频重锚定 / 重新校准 / 运输图再审计 ----
    if cycle_idx % ctx.T_reanchor == 0:
        sem_map.refresh(new_obs_buffer)
        sct.recalibrate(sem_map.paired_regions)
        ctx.sem_audit = auditor.audit(sem_map.transport_graph,
                                      sem_map.cal_pairs,
                                      sem_map.alias_flags)
        if ctx.sem_audit:
            ladder.level = max(0, ladder.level - 1)   # 只能降档

    # ---- v15 继承路径 ----
    C, spatial_cert, claims, metrics, rewards = M.inherited_v15_path(ctx)
    return C, spatial_cert, claims, metrics, rewards

## 2. 推导（引理 131–140）

**引理 131（语义取交不扩张 v15 授权）**
对任意 `x`，`Exec_v16(x) ⊆ Exec_v15(x)`（投影到动作空间）。证明：由定义 634，`Exec_v16(x)={(c,a):Valid(c), a∈Acc_c(x)∩Acc_v15(x)}`；投影后每个 `a` 都满足 `a∈Acc_v15(x)`。∎ 推论：**v16 的所有语义能力都只能“在哪儿执行、先执行哪个”上做文章，不能改变“能执行什么”**；这是整个语义接地层的安全地基。

**引理 132（语义证书有效性蕴含 v15 物理可行性）**
设 `Valid(c)` 成立且 `(c,a)∈Exec_v16(x)`。则动作 `a` 在膨胀包络 `G_c^⊕` 上满足 v15 物理证书，风险不超过 v15 的 `α_v15`。证明：`Valid(c)` 要求 `c.handles` 中对应 `(s,a)` 在 `G_c^⊕` 上满足 `m_v15≥0`；定义 631 又要求 `Acc_c(x)` 是对 `G_c^⊕` 内所有点取一致下界，故几何/标签误差不能把某个未验证子区域“藏”进单元；`a∈Acc_v15` 给出动作维度的物理授权。标签不确定度只影响 `Valid(c)` 的通过与否，不参与物理余量的加法。∎ 推论：**语义错误只会导致假拒绝或单元失效，不能单独产生假接受**；语义层是门，不是物理证书的替代品。

**引理 133（运输间隙的单侧 soundness）**
设 `U_trans(c→c')` 是满足下式的单侧上界：对任意 `a∈Acc_c`，`m_{c'}(a) ≥ m_c(a) − U_trans(c→c')`。若 `a∈Acc_{c→c'}(U_trans)`，则 `m_{c'}(a) ≥ 0`，即 `a` 在目标单元 `c'` 中仍被 v15 物理证书覆盖。证明：由定义 640，`m_c(a) − U_trans ≥ 0`；代入单侧上界得 `m_{c'}(a) ≥ m_c(a) − U_trans ≥ 0`。∎ 推论：**运输只删除“付不起间隙”的动作，不会把源单元的动作原样搬到目标单元**；`Acc_{c→c'}(U) ⊆ Acc_c ⊆ Acc_v15`。

**引理 134（运输间隙的三角复合与单调性）**
对运输图上的任意路径 `c→c_1→…→c_k`，有
```
U_trans^*(c→c_k) ≤ Σ_{i=0}^{k−1} U_trans(c_i→c_{i+1}) ,
```
其中 `U_trans^*` 取所有路径的下确界。因此 `Acc_{c→c_k}(U_trans^*) ⊆ Acc_{c→c_{k−1}}(U_trans^*|_{k−1}) ⊆ … ⊆ Acc_c`。证明：`U_trans^*` 按路径和取下确界，三角不等式由“路径和”的定义直接得到；授权集对间隙单调不增（定义 640）。∎ 推论：**环路与长链不能“重置”或“充值”间隙**；借证是按跳数计息的，超过 `K_max` 必须重新锚定（引理 139）。

**引理 135（支撑空洞不可插值）**
设 `H` 为支撑空洞，`M_obs` 为 `H` 之外的全部观测。存在两个世界 `W_1,W_2`，它们在 `M_obs` 上完全一致但在 `H` 内能力不同；任何只依赖 `M_obs` 的估计器对 `W_1,W_2` 输出相同。因此若该估计器给 `H` 赋予正证书，必在其中一个世界中不安全。证明：构造 `W_1,W_2` 仅在 `H` 内的摩擦/质量/柔顺参数不同；所有外部观测相同，估计器无法区分。∎ 推论：**对空洞做平滑、插值或“按邻居推断”都没有有限风险保证**；只能主动补证或把空洞视为无效（触发 SMDL 降档）。

**引理 136（语义别名下界：同标签 ≠ 同能力）**
存在两个区域 `c,c'`，其标签分布完全相同（`p_c=p_{c'}`），但物理能力差异 `U_aff(c,c')>0`；任何忽略 `U_aff` 的运输都可能得到负的目标余量。证明：取两个同类但质量/摩擦/柔顺不同的物体，语义分类器输出相同分布；源证书在源物体上有效，在目标物体上因能力不同而失效。于是 `m_{c'}(a)=m_c(a)−U_aff < 0` 对某些 `a` 成立。∎ 推论：**“同一语义类”只是运输的必要条件，不是充分条件**；`U_trans` 必须显式包含能力差异项，或要求直接物理观测，不能用标签一致性替代。

**引理 137（提案不变性：换基座模型不改变安全集）**
`Exec_v16(x)` 的定义不依赖 `π_U`；UPG 的 `govern` 先做 `supp(π_U)∩Exec_v16` 过滤，再做偏序排序。故对任意两个提案分布 `π_U, π_U'`，可执行安全集相同；被执行的动作始终属于 `Exec_v16`。证明：过滤步骤只从 `Exec_v16` 中取子集，排序步骤不改变集合成员资格；主闭环第 6 步再次检查 `(c_star.id,a_star)∈exec_sem`。∎ 推论：**UniBot-V1 的升级/替换是安全中性的，只影响进度与查询效率**；这也给出一个可检验的预言：把 UniBot 换成随机提案器，安全违规率不应上升，只应看到完成率下降。

**引理 138（退化阶梯单调且无越级）**
设 `L_0⊆L_1⊆…⊆L_m` 为 SMDL 的嵌套授权档，且升档只允许在“完整重新观测 + 运输图再审计 + 别名检查通过”事件后发生。则在没有该事件时，`Exec_{L_k}(t+1) ⊆ Exec_{L_k}(t)`；监控触发时只能降到更低档。证明：`level` 的更新规则只有“保持/下降”；时间增长只增加 `age`、不增加支撑，故 `Valid` 单调不增；运输间隙不因等待而减小。升档被事件门控，排除越级。∎ 推论：**系统在单帧内不可能“越降越勇”**；最坏行为是 v15 精确单元或纯几何回退，而不是一个未验证的高档语义动作。

**引理 139（覆盖—运输—时效三难与重新锚定界）**
设 `m_min` 为源证书的最小可用余量，`ΔU` 为新颖单元每跳运输间隙的下界（`ΔU>0`），`K_max=⌊m_min/ΔU⌋`。则任何长度超过 `K_max` 的运输链授权为空；语义复用覆盖的单元数至多是以源单元为根、半径 `K_max` 跳的运输球。若要在不增加观测/校准的情况下扩大覆盖，只能增大每跳 `U_trans`（降低安全余量）或延长时间（增加 stale 风险）。证明：由引理 134，`k` 跳后累计间隙至少 `k·ΔU`；当 `k>K_max` 时 `m_min−k·ΔU<0`，授权集为空。覆盖上界由运输球的定义直接得到。∎ 推论：**语义泛化是一笔有预算的贷款**；`B_sem` 与 `T_reanchor` 是利率，必须显式计入任务预算，不能把“语义相似”当作无限额度的安全信用。

**引理 140（全失效严格退回 v15）**
若 SMC、UPG、SCT、SAM、SMDL、LCR 六个端口全部注入中立元——SMC 退化为覆盖全工作空间、只带 v15 句柄的单一单元；UPG 退化为均匀排序；SCT 的 `U_trans≡∞`（禁止跨单元运输）但对恒等边取 `0`；SAM 恒为 `ok`；SMDL 固定在 `exact_cell`；LCR 不加语义约束——则 `Exec_v16=Exec_v15`，主闭环等价于 `metricvoicegauge_round_15_skill_diffusion`。若语义地图本身无效，则第 3 步直接调用 `strict_fallback_v15`。证明：逐一代入中立元后，SMC 的 `Valid` 只剩 v15 句柄检查，`authorized` 退化为 `Acc_v15`；SCT 恒等运输不收缩；UPG 与 LCR 只重排不增删；SMDL 固定在精确单元；故执行集等于 v15。无效地图路径由主闭环第 3 步显式回退。∎ 推论：**v16 的每个语义端口都是可拔插的收缩算子；最坏情形严格等价 v15，不会因语义模块故障引入新授权。**

## 6. 已知风险与失效模式

1. **语义地图与 UniBot 的共同先验导致“一致地错”**：二者可能在同一新颖物体上给出相同错误标签，使别名监视器缺少反例。缓解：能力探针与物理校准独立于语义分类器；对低支撑/低覆盖率单元强制探测；保留几何-only 影子路径；对抗样本与跨分布测试。

2. **运输间隙低估**：校准对不足、区域对非交换、能力差异未被 `d_phys` 覆盖时，`U_trans` 可能偏小。缓解：校准对有最小样本要求，不足即 `U_trans=∞`；EVT 尾部分位；把能力差异单列为不可省略项；运输图审计禁用可疑边。

3. **支撑空洞被“平滑”掩盖**：地图模块可能对空洞做插值或先验填充。缓解：SMC 把 `Hole(M)` 显式暴露；主闭环在空洞处只允许补证/回退；禁止任何跨空洞运输；对空洞做定期审计。

4. **语义别名（同标签不同能力）**：同类物体在质量、摩擦、柔顺、温度上不同。缓解：`U_aff` 必须由直接物理证据给出；没有证据就禁止运输；别名监视器把 `U_aff>τ_alias` 的边全部禁用。

5. **语言歧义与越权**：语言指令可能指向多个物体/区域，或被误解析为未认证动作。缓解：LCR 只产生证书查询与多候选；歧义时 `a_ask`；语言解析结果必须再经 SMC 与 v15 双重取交。

6. **时效与地图老化**：物体移动、遮挡、光照变化使旧证书失效。缓解：`T_fresh` 与重观测预算；`age` 进入 `Valid`；SMDL 在过期时降档；长时任务定期重锚。

7. **跨本体迁移的隐性不匹配**：语义索引可复用，但物理证书（力矩、摩擦、工作空间）不可复用。缓解：CESB 强制物理证书重标定；语义运输边不自动继承；迁移后先做影子运行与审计。

8. **运输图环路与长链**：环路可能被误用来“重置”间隙，长链累积误差。缓解：引理 134 的路径和定义；STA 检测异常增益环路并禁用；`K_max` 与 `B_sem` 硬约束；周期重锚。

9. **实时性开销**：语义查询、路径间隙、别名检查可能挤占控制预算。缓解：单元/边预计算与缓存；`K_max≤4`；SMC 与 STA 的低频异步化；p99 压力测试与 watchdog。

10. **对抗/污染地图**：恶意或错误标注可让运输边指向不安全区域。缓解：STA 审计；多源标签一致性；对高影响边做人工/物理复核；污染检测触发全局降档。

11. **v15 与 v16 误差同向叠加**：DCA/EDC 的校准误差与 SMC/SCT 的语义误差可能同向，导致联合低估。缓解：所有不确定性取上界并加性预算；两套校准集独立；任一套失效即触发最低档；联合三角界审计。

12. **退化到第 0 档的活动性塌缩**：频繁空洞/别名/过期可能使系统长期停/问。缓解：SSP 最小代价补证；把补证成本计入任务预算；优先修复高价值单元；允许在安全前提下退到最近精确单元而非直接停。

## 7. 本轮最大风险

**一句话**：语义地图与 UniBot-V1 共享同一套语义先验，当新颖物体的标签被二者“一致地”误判时，运输间隙会因校准集缺少该别名样本而被系统性低估，系统可能在“标签一致、证书已运输、每步都在支撑内”的表象下执行一个物理上从未被验证的动作——即**语义自洽的、运输可证的、却绝对错误的安全决定**。
