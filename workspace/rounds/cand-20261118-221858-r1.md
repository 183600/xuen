# UniBot 线 · 迭代轮（承接第 1 轮 UniBot-SAGE；本轮灵感：「跨物体泛化」×「异常检测」）

> 说明：第 1 轮记录了 UniBot-SAGE 三层栈（抓握隐变量 / 技能路由 / 推理期适配）。本轮不改任务域与接口事实，只把研究焦点收敛到两个灵感词的交叉点：**未见物体上的失败，能否被"异常"这一信号提前捕获并触发恢复**。编号沿用并扩展：定义 U13–U24、引理 L8–L14、实验 E619–E640；IP-09 起为新增创新点。

## 0. 情报与事实基线（沿用第 1 轮，检索日期 2026-11-17）

- 任务事实（32 任务、G1+Dex1 单维夹爪、4 路相机、joint/ee 互斥、N 连续端口、评测端采集延迟与动作规律性）与数据集事实（32 份 LeRobot v3.0，≈32k eps / 169 h）不变，来源见第 1 轮 §10。
- 榜单仍为 teaser/占位表：只用作"任务面与接口规格说明书"，**不作为真机性能真值**。
- 本轮新增待核实项（下一轮务必补齐）：①官方"未见物品"泛化场景的判定口径（是留出物体实例还是留出类别）；②评测是否允许 episode 内"主动放弃并重试"；③恢复动作是否会被计为"不规则交互模式"。**未核实前，所有恢复策略默认"不引入外部分支、只重查当前观测再决策"。**

## 1. 直觉（先给画面，再给定义）

**灵感 A ·「跨物体泛化」：能跨物体迁移的不是"像什么"，而是"怎么动"。**
人拿起从未见过的杯子，并不依赖"这是某型号杯子"的记忆；他依赖的是**接触后物体的跟随方式**：夹住了会一起走，打滑会相对滑动，太宽合不拢，太薄会滑脱。也就是说，跨物体真正可迁移的不变量是**物体-夹爪的相对运动 / 接触动力学**，而不是外观纹理。外观是 nuisance variable，交互动力学才是 invariant。于是泛化的正解之一，是把策略与监控都重参数化到"物体相对、外观无关"的坐标系里。

**灵感 B ·「异常检测」：既然不能保证泛化正确，就要能立刻知道"现在不对劲"。**
对真正新奇的物体，任何先验都可能错。但错并不可怕，**错了还不知道**才可怕。若我们只从成功示范里学一个"正常交互流形"，那么一旦观测到的"指令→实际运动"关系偏离这个流形，就得到一个**当下可计算**的失配信号：夹爪闭合但物体不随动（抓空）、物体相对夹爪滑移（打滑）、关节跟踪误差突变（碰撞 / 卡滞）、画面分布远离训练支撑（新奇物体 / 背景）。异常检测把"无界的泛化问题"改写成"有界的监控问题"：不必保证先验对，只需保证**先验失效时能被看见**。

**合成：异常是跨物体泛化的安全阀。**
跨物体泛化负责"尽量做对"，异常检测负责"做错时尽早发现并换策略"。二者不是并列技巧，而是**同一个闭环的两端**：泛化给出前向猜测，异常给出对猜测的实时否决权。由此得到本轮主线 **ACG：Anomaly-gated Cross-object Generalization（以异常为门控的跨物体泛化）**：
**正常交互建模（成功数据）→ 多通道残差异常分数 → 门控（迟滞 / 驻留）→ 恢复或探索 → 回到泛化策略**，全程仍是一个 checkpoint、一个 API。

## 2. 瓶颈在哪里（把两个灵感落到可量化处）

沿用第 1 轮的量化结论，并明确本轮要新增测量的量：

1. **断点在最后一环**：最难任务集中在插入 / 旋转 / 细粒度摆放（Plug In Ethernet、Unlock、Spell robot…）⇒ 失败多为"接近成功后的接触失配"，正是残差异常最敏感的地方。
2. **泛化场景含"未见物品"**：这是跨物体泛化的直接考核轴；第 1 轮尚未系统测量"见过物体 vs 未见过物体"的成功率间隙 `Δ_gen`，本轮把它列为一等公民指标。
3. **失败样本天然稀缺且无标签**：真机失败少、标注贵 ⇒ 监控必须**只用成功数据训练**（残差式 / one-class），失败只在评测时出现（open-set）。
4. **干预成本不对称**：漏报（失败未察觉）→ 硬失败；误报（正常却干预）→ 可能打断一条本可成功的轨迹。⇒ 阈值必须按代价而非按 AUC 选。

（第 1 条为第 1 轮 teaser 证据；第 2–4 条为本轮设计前提，需 E619–E621 实测确认。）

## 3. 研究问题（本轮版）

- **Q6（可迁移的正常性）**：只用成功数据学到的"正常交互流形"，在**未见物体**上残差分布漂移多大？能否用物体相对表示把漂移压到阈值可控范围？
- **Q7（可控误报）**：能否用**一致性预测（conformal）**给出分布无关的误报率控制？跨物体（破坏可交换性）后该保证退化多少，如何用分组 / 在线校准补救？
- **Q8（代价最优门控）**：在"漏报 ≫ 误报"的不对称代价下，阈值、迟滞、驻留时间与恢复菜单应如何联合选择，使净成功率最大？
- **Q9（恢复的原语覆盖）**：对"抓空 / 打滑 / 错位 / 碰撞 / 新奇物体"五类异常，恢复原语（重抓 / 重对齐 / 后退 / 探索 / 重查观测）各自覆盖哪些、盲区在哪？
- **Q10（异常即技能）**：把异常类型作为额外 skill token 路由到恢复专家，是否比"统一恢复器"更优，且仍满足单 checkpoint 合规？

## 4. 设计原则（在第 1 轮 P1–P6 上增补）

- **P7 正常性只从成功学、失败只用于检验**：训练集不得含失败标签，避免"用测试分布造监控"的泄漏。
- **P8 物体身份是 nuisance**：监控输入优先用相对运动 / 接触量，外观只作辅助通道且需消融证明其非必需。
- **P9 先检测、后行动、可回退**：任何干预必须能一句话解释"哪个通道、超了多少阈"；干预失败要能回到"不干预"的安全路径。
- **P10 可证伪的跨物体声明**：所有"泛化提升"必须报告 seen/unseen 双指标与检测指标，禁止只报总体均值。
- **P11 不利用未核实语义**：恢复不得依赖评测端未声明的执行 / 重试语义（沿用第 1 轮 P5）。

## 5. MVP 与退化链

**MVP = 残差异常监控（运动学 + 抓握 / 接触两通道）+ conformal 阈值校准 + 门控恢复（重抓 / 重对齐 / 重查观测）+ 跨物体留出评测。**
（视觉新奇通道与异常类型路由为增强项，不阻塞 MVP。）

退化链：
- L0 监控不可用 ⇒ 纯基线开环；
- L1 校准失效（跨物体误报暴涨）⇒ 提高阈值 / 退回"仅高置信触发"，宁可少救不可乱救；
- L2 恢复专家不可用 ⇒ 仅"中断当前 chunk + 用当前观测重查一次策略"；
- L3 重查仍失败 ⇒ 安全保持 / 后退，交由基线继续；
- L4 整层失效 ⇒ 纯基线（永远保留可跑通的最小提交）。

## 6. 预期贡献（可验收）

1. **一个只用成功数据训练的多通道交互异常监控**，给出 seen/unseen 双域的检测 AUROC/AUPRC 与可靠性图。
2. **把"跨物体泛化"从口号变成可测的量**：定义并测量泛化间隙 `Δ_gen` 与"检测-恢复后残余失败率"，并报告误报代价。
3. **一套分布无关的误报控制及其在物体漂移下的退化曲线**（conformal + 分组校准），这是可复用的方法学产物。
4. **异常门控恢复的净收益曲线**（按代价扫描阈值），并给出"何时不该做异常检测"的否定性结论边界。
5. **跨物体留出评测协议**（物体实例 / 类别两级留出），补齐第 1 轮 IP-06 的 OOD 轴。

## 7. 本轮最大风险（一句话）

**整套方案押在"正常交互的残差分布在物体间近似不变"这一假设上；一旦未见物体造成的漂移超过阈值，conformal 的误报保证即失效，监控会在新奇物体上要么频繁误报、把本可成功的轨迹打断，要么彻底沉默、漏掉它本该捕获的失败——恰好在它被设计来解决的那根轴上失灵。**

## 8. 下一轮迭代计划

- **深化**：把"异常分数"升级为"带提前量的失效预测"（在失败显化前 k 步预警），研究预警提前量与误报的权衡。
- **深化**：把异常类型路由（Q10）与第 1 轮 IP-01 的技能路由合并为"状态条件化"的单一门控。
- **修剪预案**：若 E621 显示跨物体误报率无法压到可用区间（如召回 70% 时 FPR>15%），则**放弃统一阈值**，改为按任务簇 / 物体簇分组校准；若分组仍不可行，则把异常检测降级为"仅用于离线诊断"，不进入在线闭环。
- **保留项**：跨物体留出评测（信息价值最高）、成功-only 残差监控（机制正确）、conformal 校准（可证伪）。

# 迭代轮产物 · 创新点清单 v2（UniBot 线）：**UniBot-ACG**

> **ACG = Anomaly-gated Cross-object Generalization**（以异常为门控的跨物体泛化）。

## 0. 本轮结论摘要

**一句话路线**：把"跨物体泛化"重写成"物体相对表示 + 成功-only 正常性建模"，把"异常检测"重写成"conformal 可控误报的门控恢复"，二者组成 **ACG 闭环**；不失配时完全退化为基线策略。

**三条设计依据**：
1. 失败集中在最后一环且**无标签** ⇒ 成功-only 残差监控最契合（不需要失败样本，也无需像素级重建）。
2. **未见物品**是官方泛化轴 ⇒ 必须报告 seen/unseen 双指标与检测指标，否则任何"泛化提升"不可证伪。
3. 干预代价**不对称**（漏报 ≫ 误报）⇒ 阈值按代价选、用 conformal 控误报、用迟滞防抖。

**合规红线（沿用第 1 轮 P5 / P11）**：单一 checkpoint、单一 API；不读评测侧私有信息；不依赖未声明的重试 / 执行语义；恢复动作保持良构、不做脚本化"拟人噪声"。

## 2. 创新点详述

### IP-09 · NIM（Normal-Interaction Monitor）正常交互残差监控（P0）

- **直觉**：正常交互有结构——给定指令与当前观测，末端怎么动、夹爪闭合后物体怎么跟、关节是否跟得上，都有稳定关系。偏离这个关系就是异常。
- **与现有方案的差异**：常见异常检测在**像素/潜空间**做重建或密度估计，分数不可解释、对背景变化敏感；NIM 在**动作条件**下预测下一时刻的**关系量**（EE 位姿增量、关节增量、物体-夹爪相对位姿 / 速度、夹爪闭合、接触代理），残差按通道分解，直接对应物理失败类型，可解释、可门控。
- **技术可行性**：高。冻结主干特征 + 轻量 predictor（MLP / 小 Transformer），成功数据即可训练；无需失败标签。
- **所需资源**：官方 32 数据集（≈32k eps）；单卡数小时。
- **落地步骤**：①统一关系量提取（EE 位姿差分、腕部光流 / 分割质心、关节跟踪误差、夹爪闭合比）；②训练动作条件 predictor（输入观测历史 + action chunk，预测下一段关系量）；③按通道 robust z-score 标准化；④融合（学习权重或取 max）；⑤split-conformal 定阈；⑥通道消融（kin / grasp / rel / vis / act）。
- **风险**：关系量依赖可靠分割 / 光流；成功数据未覆盖的相位残差天然偏大 ⇒ 必须**按相位条件化**并报告分相位阈值。

### IP-10 · ORI（Object-Relative Invariant）物体相对不变表示（P0）

- **直觉**：能跨物体迁移的不是"它长什么样"，而是"它被夹住后怎么动"。
- **与现有方案的差异**：不追求"更强视觉编码"，而是**坐标系选择**：在腕部帧中定位夹爪与目标物体，计算相对位姿 / 相对运动 / 相对尺度 / 滑移量，作为监控与恢复的主输入；外观通道仅作辅助且可关闭。
- **技术可行性**：中–高。优先用现成分割器或数据中已知夹持点做弱监督；分割不稳时退化为"腕部 ROI + 背景减除 + 光流"版本。
- **所需资源**：小–中（分割 + 小网络）。
- **落地步骤**：①腕部相机自运动补偿；②夹爪 / 物体分割（弱监督或现成分割器）；③相对量计算；④用相对量重训 NIM；⑤外观通道开 / 关消融，报告 ΔAUROC 与跨物体 FPR；⑥在透明 / 反光 / 细长物体上记录退化。
- **风险**：分割恰在最难的透明 / 反光 / 细长物体上失败 ⇒ 必须有退化路径，并把这些样本单独报告，不能藏进均值。

### IP-11 · ARC（Anomaly-gated Recovery Controller）异常门控恢复（P0）

- **直觉**：检测若不能转成动作就无价值；但干预又要防止误伤，所以"先确认、再动手、可回退"。
- **与现有方案的差异**：把恢复做成**有限状态机 + 代价门控**：仅当异常持续 `d` 步且超阈值（迟滞）才触发；恢复菜单按异常类型选；每次恢复后强制"重新观测再决策"，并有总预算上限与冷却期。
- **技术可行性**：高（工程 + 小策略）。
- **所需资源**：小。
- **落地步骤**：①定义恢复原语 `R`（重抓 / 重对齐 / 后退 / 探索 / 重查 / 安全保持）；②门控逻辑（见 §4）；③按异常通道选原语；④恢复后重查 VLA（当前 obs、短 chunk）；⑤预算与回退；⑥代理评测 + 真机 A/B。
- **风险**：误报打断正常轨迹；恢复本身可能引入新异常 ⇒ 冷却期、单 episode 上限、以及"恢复到不干预"的安全网（退化链 L1–L4）。

### IP-12 · LOOX（Leave-One-Object-out cross-object bench）跨物体留出评测（P0）

- **直觉**：没有跨物体标尺，就无法证明泛化，也无法判断监控是否"只记住了见过的物体"。
- **与现有方案的差异**：第 1 轮 IP-06 做了 OOD 切分但未系统化到物体粒度；LOOX 规定**物体实例级**与**物体类别级**两种留出，统一输出 seen/unseen 双指标与检测指标。
- **技术可行性**：中（需物体标注：任务卡 + VLM 接地 + 人工抽检）。
- **落地步骤**：①每任务对象清单；②构建实例 / 类别留出；③定义指标：`Δ_gen`、AUROC_seen/unseen、FPR@Recall、残余失败率；④bootstrap CI；⑤作为所有 IP 的统一裁决器。
- **风险**：32 任务物体复用少，类别留出样本不足 ⇒ 以实例留出为主、类别留出为辅，并显式报告每组样本量。

### IP-13 · CACT（Conformal Adaptive Calibration under shift）漂移下校准（P1）

- **直觉**：阈值不能拍脑袋；分布无关的误报控制很香，但跨物体破坏可交换性，必须量化退化。
- **与现有方案的差异**：不是"训练一个阈值"，而是**校准协议**：split conformal 给边际 FPR 保证；再做分组（任务 / 物体簇）与在线（adaptive conformal inference）版本，量化保证退化。
- **落地步骤**：①留出校准集 `D_cal`；②split-conformal 分位数；③测 seen/unseen 的 FPR 膨胀；④分组 / 在线校准；⑤画"召回–FPR–代价"曲面。
- **风险**：分组后每组样本少导致分位数不稳；在线校准引入漂移 ⇒ 设更新速率上限与回退。

### IP-14 · AXS（Anomaly-conditioned Skill token）异常条件化技能 token（P2）

- **直觉**：抓空、打滑、错位需要不同恢复；统一恢复器是次优。
- **与现有方案的差异**：把异常类型 `z_anom` 作为 skill token 喂给第 1 轮 IP-01 的专家门控，路由到恢复专家；仍是单 checkpoint。
- **落地步骤**：①异常类型弱标（通道 argmax）；②训练恢复专家；③路由消融（oracle vs 实际）；④合规降级（单专家）。
- **风险**：合规（多专家是否算多模型）；恢复专家数据稀缺 ⇒ 先做 oracle 上界再决定是否投入。

## 3. 符号与定义（U13–U24）

| 符号 | 含义 |
|---|---|
| `M` | 正常交互流形 = 成功轨迹（状态-动作-关系量）分布的支撑 |
| `f_dyn` | 动作条件交互动力学模型 |
| `r_t` | 多通道残差向量 |
| `s_t` | 融合后的异常分数 |
| `q_{1-α}` | conformal 阈值（目标边际误报 α） |
| `d` | 门控驻留步数（迟滞） |
| `R` | 恢复原语库 |
| `φ_obj` | 物体相对不变表示 |
| `Δ_gen` | 跨物体泛化间隙 |
| `z_anom` | 异常类型 token |

**定义 U13（正常交互流形）** `M := supp(P(τ))`，`τ = (o_{0:T}, a_{0:T}, y_{0:T})` 只取成功示范；失败轨迹不在训练支撑内。
**定义 U14（交互动力学模型）** `f_dyn: (o_{t-k:t}, a_{t:t+H}) → ŷ_{t+1:t+H+1}`，`y` 为关系量（EE 位姿增量、关节增量、物体-夹爪相对位姿 / 速度、夹爪闭合、接触代理）。
**定义 U15（多通道残差）** `r_t = clip(|y_t − ŷ_t| / σ_ch)`，按通道做 robust 标准化；通道集 `ch ∈ {kin, grasp, rel, vis, act}`。
**定义 U16（异常分数）** `s_t = G(r_t)`，`G` 为学习融合或取 max；`s_t` 越大越异常。
**定义 U17（conformal 阈值）** 给定校准分数 `{s_i}`，`q = s_(⌈(n+1)(1−α)⌉)`；在线版按 ACI 更新 `α_t`。
**定义 U18（门控状态机）** 状态 `∈ {NORMAL, SUSPECT, RECOVER, COOLDOWN}`，转移由 `(s_t, d, cooldown, budget)` 决定。
**定义 U19（恢复原语库）** `R = {re-grasp, re-align, backoff, explore, re-query, hold-safe}`。
**定义 U20（物体相对表示）** `φ_obj(o)` 消除物体身份：相对位姿 / 速度 / 尺度 / 滑移，配合腕部自运动补偿。
**定义 U21（跨物体泛化间隙）** `Δ_gen = E[succ | seen] − E[succ | unseen]`。
**定义 U22（代价）** `C = c_fn·FN + c_fp·FP + c_rec·N_rec`，`c_fn ≫ c_fp`（漏报远贵于误报）。
**定义 U23（异常类型 token）** `z_anom ∈ {grasp_fail, slip, misalign, collision, novelty, none}`。
**定义 U24（校准 / 检验划分）** `D_cal`（成功、seen）与 `D_test`（含 unseen、含失败），二者严格不重叠。

## 4. 关键算法骨架

```python
# ===== IP-09 + IP-10：成功-only、动作条件的多通道残差监控 =====
class NIM:
    def __init__(self, dyn, scaler, q):
        self.dyn, self.scaler, self.q = dyn, scaler, q   # q 由 conformal 得到
    def relation(self, obs_hist):
        ee  = ee_pose(obs_hist)
        rel = wrist_relative_motion(obs_hist)            # 光流/分割质心 − 自运动
        return dict(
            ee_delta = d(ee),
            grip     = gripper_scalar(obs_hist),
            rel_pose = rel["pose"], rel_vel = rel["vel"],
            slip     = rel["slip"], joint_err = joint_track_err(obs_hist),
        )
    def score(self, obs_hist, action_chunk):
        y_hat = self.dyn(obs_hist, action_chunk)
        y_now = self.relation(obs_hist)
        r = {k: robust_z(y_now[k] - y_hat[k], self.scaler[k]) for k in y_now}
        return fuse(r)                                   # 学习融合或 max
    def type(self, r):                                   # 定义 U23，供 IP-14 用
        return argmax_channel(r)
    def anomalous(self, s):
        return s > self.q
```

```python
# ===== IP-13：split conformal（可交换下边际 FPR ≤ alpha）=====
def conformal_threshold(scores_cal, alpha):
    n = len(scores_cal)
    k = math.ceil((n + 1) * (1 - alpha))
    return sorted(scores_cal)[min(k, n) - 1]
```

```python
# ===== IP-11：迟滞 + 驻留 + 预算的恢复门控 =====
class Gate:
    def __init__(self, tau_hi, dwell=3, cooldown=15, budget=6):
        self.tau_hi, self.dwell, self.cooldown, self.budget = tau_hi, dwell, cooldown, budget
        self.state, self.cnt, self.cd, self.used = "NORMAL", 0, 0, 0
    def step(self, s, z_anom):
        self.cd = max(0, self.cd - 1)
        if self.state in ("NORMAL", "SUSPECT"):
            self.cnt = self.cnt + 1 if s > self.tau_hi else 0
            if self.cnt >= self.dwell and self.used < self.budget and self.cd == 0:
                self.state, self.used, self.cnt = "RECOVER", self.used + 1, 0
                return pick_primitive(z_anom)            # 见下
        elif self.state == "RECOVER":
            self.state, self.cd = "COOLDOWN", self.cooldown
        elif self.state == "COOLDOWN" and self.cd == 0:
            self.state = "NORMAL"
        return None                                      # None ⇒ 交给基线继续

def pick_primitive(z):
    return {
        "grasp_fail": "re-grasp",  "slip": "re-grasp",
        "misalign":   "re-align",  "collision": "backoff",
        "novelty":    "explore",   "none": "re-query",
    }[z]
```

```python
# ===== 每个 chunk 的统一调用（失配时覆盖，否则完全不动基线）=====
def get_action(self, obs):
    s = self.nim.score(obs.hist, a_prev_chunk)
    if s > self.q * self.soft_margin:
        z = self.nim.type(self.nim.last_residual)
        prim = self.gate.step(s, z)
        if prim is not None:
            self.audit.log(obs.t, s, z, prim)            # 可审计：哪个通道、超多少
            return self.recovery.act(prim, obs)          # 恢复后强制重查 obs
    return self.base_policy.act(obs)                     # 默认路径 = 纯基线
```

## 5. 推导（引理 L8–L14）

**引理 L8（split-conformal 的边际误报控制）** 若校准分数与检验分数可交换，则对 `s_test` 的 conformal p 值 `p_test` 有 `P(p_test ≤ α) ≤ α`，即 `FPR ≤ α`。证明：由可交换性，`s_test` 在 `n+1` 个分数中的秩均匀分布，`p_test ≤ α ⟺` 秩落在最大 `⌈(n+1)α⌉` 个位置之一，概率恰为 `⌈(n+1)α⌉/(n+1) ≤ α`。∎

**引理 L9（跨物体漂移下的保证退化）** 若 `D_cal` 与 `D_test` 的分数分布（在归一化后）1-Wasserstein 距离为 `δ`，且分数有界 / 比较函数 1-Lipschitz，则 `FPR_test ≤ α + δ`。⇒ 跨物体不是"保证失效"，而是"保证带一个可测的漂移项 δ"；分组校准（CACT）就是把 δ 从"跨所有物体"降到"组内"。∎

**引理 L10（检测-恢复的残余失败界）** 设基线跨物体失败率 `ε`，检测召回 `r_det`，恢复成功率 `r_rec`，误报率 `α`，误报致损（归一化）`c_fp`。则净失败率不超过
`ε·(1 − r_det·r_rec) + (1 − ε)·α·c_fp`。
净收益为正的充要条件约为 `r_det·r_rec·ε > (1 − ε)·α·c_fp`。⇒ 在 `ε` 小、`α` 不小、`c_fp` 非零时，"做异常检测"本身可能不划算——这正是本轮必须给出否定性边界的原因。∎

**引理 L11（不对称代价下的阈值选择）** 若 `c_fn/c_fp = λ ≫ 1`，则最小化 `λ·FNR(τ) + FPR(τ)` 的一阶条件为 `λ·f_FN(τ*) = f_FP(τ*)`；工程上取等价约束形式：在 `FPR(τ) ≤ α_budget` 下最大化 `Recall(τ)`。⇒ 阈值由代价与 FPR 预算共同决定，不由 AUC 决定。∎

**引理 L12（不变性可迁移的条件）** 若 `φ_obj` 对物体身份等变（换物体不改变相对量分布），且条件律 `P(y | a, φ_obj)` 在物体间不变，则 NIM 残差分布不变、阈值可跨物体复用；否则漂移由表示误差与条件分布差共同界定。⇒ 这是 ACG 的核心可证伪假设，必须由 E621/E622 检验，不能默认成立。∎

**引理 L13（迟滞抑制抖动）** 设正常态下 `s_t` 越阈近似独立、概率 `p`，驻留 `d` 步使误触发率降到约 `p^d`，代价是真实异常检测延迟 `d` 步。⇒ 当异常持续时间远大于 `d` 时净收益为正；`d` 需按 episode 步长扫描（E627）。∎

**引理 L14（异常类型路由的上界）** 令 `S[a, c]` 为"异常 `a` 用原语 `c` 的恢复成功率"，统一恢复器取列平均，oracle 路由取行最大，则路由增益 `= E_a[max_c S[a,c] − mean_c S[a,c]] ≥ 0`，与第 1 轮 IP-01 的 oracle 逻辑同构。⇒ 先测 `S` 再决定是否值得做 AXS。∎
