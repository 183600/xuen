# 第 13 轮（新循环第 1 轮）· E-PARITY：先证明基线是真的，再学末端技能

> 灵感词：**末端执行器控制**、**技能学习**、**基线复现**。
> 承接：第 10 轮 FACT-VLA、第 11 轮 GEO-RESIDUAL、第 12 轮 CHUNK-SERVO。本轮不推倒前 12 轮，而是补上它们共同缺的地基：**一个可证明的官方基线**；然后把「30 步规划 + 5 步伺服」升级为「技能化末端控制」。

## 0. 一句话

前 12 轮一直在往系统上加法；本轮先做减法：**用 parity 证书证明官方 WLA 到挑战赛 API 的动作语义是对的，再把 32 个任务分解成少量末端技能，用一个共享 checkpoint 的技能 token + 确定性末端原语执行，最后才用配对 A/B 判断技能层是否真的涨点。**

## 1. 直觉：三个灵感词其实是一个纠偏

### 1.1 末端执行器控制：真正的接口不是关节，是「绝对位姿」

挑战赛 API 的 `ee` 动作是**绝对目标位姿**（base 系 xyz+rpy）；官方 WLA 输出的是**相对当前 EE 的 xyz+rotvec**，且一个 30 步 chunk 共享 plan-time 锚点。这不是一个可以随手补的 adapter 细节，而是两种动作语义：

- 相对动作是「从锚点出发的增量」；
- 绝对动作是「每个时刻的目标位姿」；
- chunk 切片时，如果错误地在每个 5 步块重新锚定，后面的动作会整体漂移，漂移量等于已经执行过的位移。

前 12 轮的所有增益——伺服、相对目标、人为干扰恢复——都建立在这个映射正确的前提上。**如果映射错了，A/B 测到的是 adapter 的 bug，不是算法。** 所以本轮把末端执行器控制放在第一位：先把 `SE(3)` 的锚点、帧、rpy/rot6d、夹爪符号、`pivot` 语义、控制频率全部形式化，再谈技能。

### 1.2 技能学习：32 个任务不是 32 个映射，是少量接触技能的组合

33,276 条演示里，抓取、接近、对齐、插入、挂、拉链、倒、叠、释放这些技能反复出现。单体 30 步 BC 把技能边界糊在一个 chunk 里：模型在「还差 3 厘米」时仍然按平均轨迹走，接触事件发生时没有切换。技能学习的价值不是「多训几个策略」，而是：

- 把长程任务分解成**有前置/后置条件的技能**；
- 每个技能只学少量参数（目标位姿、接近方向、插入深度、搜索幅度、释放时机）；
- 技能之间用确定性契约衔接，失败可回退；
- 所有技能共享**同一个 checkpoint**，用 skill token 区分，不违反单模型。

### 1.3 基线复现：不是工程杂务，是算法的一部分

榜单 29.7% 是预览/合成数据，不能当 SOTA，也不能当难度表。唯一可信的基线是：**官方 WLA + 官方 API，在单任务不计分通道上重复测出来的分布**。如果这个基线没有被复现，后面所有 +5pp、+10pp 都不可解释。基线复现要回答四个问题：

1. 动作语义是否同构？（帧、锚点、符号、`pivot`、频率）
2. 模型输出是否可重放？（同一观测，动作误差）
3. 评测是否稳定？（两次 session 的成功率/延迟）
4. 负对照是否正常？（hold/random 是否真的接近 0）

这四个问题不过，技能层不启动。**这就是「基线复现」作为算法第一层的含义。**

## 2. 严谨定义

### 2.1 动作与观测

设 base 系为 `F_b`。单臂 EE 位姿 `T ∈ SE(3)`。挑战赛 `ee` 动作：

```math
a_t = (T_t^{L,\mathrm{cmd}}, T_t^{R,\mathrm{cmd}}, g_t^L, g_t^R, p_t)
\in \mathcal A = SE(3)^2 \times [0,1]^2 \times \mathcal P.
```

观测：

```math
o_t = (I_t^{LH}, I_t^{RH}, I_t^{LW}, I_t^{RW}, q_t, T_t^{L}, T_t^{R}, g_t, b_t, l).
```

其中 `l` 是语言指令，`b_t` 是下身体/腰部状态。动作是**绝对目标位姿**；模型内部可以用相对动作，但输出前必须 compose 到 base 系。

### 2.2 技能选项

定义技能词表 `Ω = {REACH, GRASP, ALIGN, INSERT, HANG, ZIP, POUR, STACK, RELEASE, RETRACT, RECOVER, HOLD}`。每个技能是一个 option：

```math
\omega = (I_\omega, \beta_\omega, P_\omega, \Theta_\omega),
```

- `I_ω ⊆ O`：启动条件；
- `β_ω: O → {0,1}`：终止条件；
- `P_ω: O × Θ_ω → A`：确定性末端原语；
- `Θ_ω ⊆ R^{d_θ}`：技能参数（目标相对位姿、接近方向、插入深度、搜索幅度、释放时机等）。

### 2.3 单模型约束

设 `f_φ` 是唯一的学习模型（官方 WLA checkpoint）。单模型约束：

```math
\forall o,l:\quad \pi(a \mid o,l) = F_\phi(o,l),
```

其中 `F_φ` 的所有可学习部分共享 `φ`；技能 token、门控、参数头都是 `f_φ` 的输出；`P_ω` 没有学习权重；演示库只存数据，不存策略参数。这样技能层不是第二个模型，而是同一个模型的条件化输出。

### 2.4 基线 parity

设 `P_ref` 是官方 server + 官方 example adapter 的参考管线，`P_ours` 是我们的适配器 + 同一 checkpoint `φ_0`。对重放集 `D_rep`：

```math
e_t = \|p_{\mathrm{ref}}(t)-p_{\mathrm{ours}}(t)\|_2
    + \lambda_r \|\mathrm{Log}(R_{\mathrm{ref}}(t)^\top R_{\mathrm{ours}}(t))\|_2.
```

Parity 证书：

```math
\mathrm{Parity}(D_{\mathrm{rep}},\varepsilon,\delta):
\max_t e_t \le \varepsilon
\quad\land\quad
\frac{1}{|D_{\mathrm{rep}}|}\sum_t \mathbf 1[e_t\le\varepsilon]\ge 1-\delta.
```

本轮默认 `ε = 1 mm + 0.5°`（真实重放），单元测试用更紧的数值容差；`δ = 0.01`。这不是「模型准确率」，而是「动作语义是否同构」的证书。

### 2.5 目标

```math
\max_\phi\ \mathbb E[\mathrm{success}]
\quad \text{s.t.}\quad
\text{single-model}(\phi),\ 
\mathrm{Parity}(P_0,\varepsilon,\delta),\ 
\text{safety}.
```

`P_0` 是基线臂；技能层只在基线的 A/B 对照成立后启动。

## 3. 方法：E-PARITY 四层

### 3.1 L0 复现层：先证明基线是真的

不把基线当「跑通就行」的工程，而是当算法对象。四件事：

1. **动作空间同构**：rpy↔rot6d、相对→绝对 compose、chunk 锚点、夹爪符号、`pivot` 语义、相机左右顺序、控制频率。
2. **Parity 测试 T1–T8**：合成相对动作、切片、边界连续性、夹爪方向、零 `pivot`、相机映射、reset 隔离、延迟。
3. **基线卡**：模型 commit/权重 hash、API 配置、chunk、resize、控制频率、5 任务 ×10 trials 的成功率/Wilson CI、p50/p99 延迟、timeout、负对照。
4. **失败分类**：固定方向漂移（帧错）、首块对后续漂移（锚点错）、抓取反向（符号错）、base 乱动（`pivot` 错）、第二 episode 继承状态（reset 泄漏）。

### 3.2 L1 技能层：SKILL-SEG + 末端原语

**离线分割**：用 `(v_EE, gripper, contact, d_t)` 检测候选边界；对每段拟合技能原语；用 DP 最小化「拟合残差 + 技能数惩罚 + 切换惩罚」：

```math
C[j] = \min_{i<j,\omega}\ C[i] + \mathrm{Fit}(i,j,\omega) + \lambda_\omega + \mu.
```

**参数化**：每个技能用少量参数描述。例如：

| 技能 | 关键参数 |
|---|---|
| REACH | 预抓取相对位姿、接近方向、速度 |
| GRASP | 夹爪宽度、闭合速度、滑移阈值 |
| ALIGN | 插入轴、横向增益、容差 |
| INSERT | 插入深度、搜索幅度/频率、法向柔顺 |
| HANG | 挂钩相对位姿、抬起方向、挂入深度 |
| ZIP | 拉链方向、拉力代理、拉动次数 |
| POUR | 倾斜轴、角度、持续时间 |
| STACK | 放置位姿、下落高度、释放时机 |
| RELEASE | 张开速度、撤离方向 |
| RECOVER | 停止、重定位、重规划 |

**契约**：每个技能有 `(Pre, Inv, Post)`。例如 INSERT：`Pre` 是已对齐且孔可见；`Inv` 是 EE 在插入轴附近、无过大横向力；`Post` 是插入深度达标。技能图保证 `Post_i ⊆ Pre_{i+1}`；不满足就回退 RECOVER 或基线。

### 3.3 L2 学习层：Gated Baseline Distillation

不是从零训技能策略，而是在官方 baseline 上做**门控蒸馏**：

```math
f_\phi(o,l) = (a_{\mathrm{base}}, \omega_{\mathrm{logits}}, \theta, c).
```

最终动作在 EE 切空间混合：

```math
T_{\mathrm{cmd}}
= T_{\mathrm{base}} \cdot \exp\!\big(c \cdot \mathrm{Log}(T_{\mathrm{base}}^{-1} T_{\mathrm{skill}})\big).
```

- `c=0`：逐字回到基线；
- `c=1`：完全走技能原语；
- 中间：平滑过渡，不会在 SE(3) 上做非法线性插值。

训练损失：

```math
\mathcal L
= \mathcal L_{\mathrm{action}}
+ \lambda_\omega \mathcal L_{\mathrm{skill}}
+ \lambda_\theta \mathcal L_{\mathrm{param}}
+ \lambda_c \mathcal L_{\mathrm{gate}}
+ \lambda_p \mathcal L_{\mathrm{parity}},
```

```math
\mathcal L_{\mathrm{parity}}
= (1-c_{\mathrm{label}})\,
\|a_{\mathrm{base}}-a_{\mathrm{base}}^{\pi_0}\|^2.
```

含义：**技能段学技能，非技能段蒸馏基线**。基线只在训练时做 teacher，在线不加载第二份模型；最终仍是一个 checkpoint。

### 3.4 L3 执行层：30 步规划 + 5 步伺服

保留第 12 轮 CHUNK-SERVO 的双频结构：

- VLA 每 30 步产出一个 plan；
- 每 5 步用腕部/头部视觉修正一次；
- 修正目标是演示检索的「受器→夹爪」相对位姿；
- 接触段法向缩幅、切向保留；
- 延迟用 RTT 测量 + 增益调度。

区别是：每个 5 步块现在属于一个技能，受技能契约保护；门控低时回退基线，而不是硬做伺服。

## 4. 算法步骤

### 4.1 离线

```text
1. 复现基线：T1–T8 → parity 证书 → 基线卡 → 负对照。
2. 分割演示：候选边界 + DP → 技能段。
3. 拟合参数：每段最小二乘 → 技能参数先验 N(θ̄_ω, Σ_ω)。
4. 门控蒸馏：冻结 VLM，训 action head + skill token + gate + param head。
5. 标定：头双目外参、腕部内参、RTT、伺服增益。
6. 离线验证：held-out session 的分割 F1、参数误差、parity 重放。
```

### 4.2 在线

```text
observe o_t
(a_base, ω, θ, c) = f_φ(o_t, l)
if c < c_min or not Pre_ω(o_t):
    return a_base
T_base  = compose(a_base, anchor)
T_skill = P_ω(θ)(o_t)
T_cmd   = T_base · exp(c · Log(T_base^{-1} T_skill))
T_cmd   = clip_rate_limit(T_cmd)
return 5-step chunk
```

### 4.3 异常

```text
if guard_fail or edit_score > θ_e:
    HOLD
    re-localize target
    if target visible: resume with conservative gain
    else: request VLA re-plan
    if retries > max: fail gracefully
```

## 6. 实验门

| 门 | 问题 | 通过标准 | 失败动作 |
|---|---|---|---|
| B0 | 动作语义是否同构？ | T1–T8 全过；重放 parity ≥99%，max ≤2ε | 停，修 adapter |
| B1 | 基线是否稳定？ | 5 任务 ×10 trials；两次 session 差异 ≤10pp；负对照≈0 | 停，查评测/重置 |
| B2 | 技能分割是否可信？ | held-out boundary F1 ≥0.75；参数误差 ≤5mm/2° | 改用手工阶段标签 |
| B3 | 仿真技能是否收敛？ | A 档技能成功率 ≥90%；目标位姿噪声下不崩 | 降增益/缩技能集 |
| B4 | 真机是否涨点？ | 10 任务 ×10 配对；≥6/10 任务 +10pp；无回归 >5pp | 不提交技能层 |
| B5 | 全量是否稳定？ | 32×10 干跑；端口隔离；p99 ≤150ms；内存不涨 | 回退基线 |

## 7. 风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| Parity 假阳性 | 基线是假的，所有增益是伪的 | 单任务通道、负对照、零 pivot 回退、行为检查 |
| 单模型解释 | 技能头/门控被判成多个模型 | 共享权重、一个 checkpoint、C1/C2/C3 合规模式 |
| 技能分割噪声 | 参数学错、契约错位 | held-out F1、置信度门控、低置信回退基线 |
| 原语失配 | 长尾物体失败 | 只对 A 档启用；失败回退 VLA |
| 评测噪声 | +1–2pp 假阳性 | 配对 A/B、bootstrap CI、预注册 |
| `pivot` 语义 | 动作被拒/机器人不动 | `example_env.py`、零 pivot 回退、单任务验证 |
| 算力/时间 | 技能层来不及 | 基线先锁；技能只投 A 档 |
| 安全 | 绝对位姿跳变 | 限幅/限速/工作空间/最大重试 |

## 8. 一句话押注与最大风险

**先把官方 WLA 的动作语义用 parity 证书钉死，再把 32 个任务分解成共享 checkpoint 的末端技能，用确定性原语执行、用门控蒸馏保留基线、用配对 A/B 只在基线为真时宣布涨点。**

**最大风险：parity 证书只能证明「我们以为的基线」是对的；如果评测端隐藏的控制频率或 `pivot` 语义与我们假设不同，基线就是海市蜃楼，后续所有技能增益都会变成 adapter 伪影。**

# 第 13 轮产物 · E-PARITY 技术报告

> 副标题：**End-effector, Parity-gated, Skill-parameterized control**（末端执行器、基线对齐、技能参数化控制）
> 日期：**2026-10-31（UTC）**。
> 证据说明：本轮不新增网页抓取；赛事/规则/API/数据事实沿用第 12 轮已核实的 A 级记录（检索日期 2026-10-28）。本轮新增的是算法设计与实验协议，默认 C 级，需 B0–B5、S0–S4 验证。对象仍是宇树 **UniBot 世界挑战赛**（G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API）。

## 0. 结论与边界

### 0.1 一句话结论

前 12 轮的主要风险不是「算法不够多」，而是「基线没有被证明」；E-PARITY 先用 parity 证书把官方 WLA 到挑战赛 API 的动作语义钉死，再用一个共享 checkpoint 的技能 token + 确定性末端原语 + 门控基线蒸馏，把 32 个任务分解成可复用、可回退、可测量的接触技能。

### 0.2 本轮增量

1. **基线复现层**：动作空间同构、T1–T8 单元/重放测试、parity 证书、基线卡、负对照、失败分类。
2. **技能层**：SKILL-SEG 分割、技能参数化、技能契约、技能图。
3. **学习层**：Gated Baseline Distillation；一个 checkpoint；基线只做 teacher，不做在线第二模型。
4. **执行层**：30 步规划 + 5 步伺服 + 相对目标 + 技能契约（承接第 12 轮 CHUNK-SERVO）。
5. **评测层**：基线优先的 B0–B5；10 任务 ×10 配对 A/B；统计功效与预注册。

### 0.3 本轮不做什么

- 不从零训 VLA/World Model；官方 WLA 6B 已开源。
- 不加载第二个学习策略/残差网络；技能头与基线共享 checkpoint。
- 不做 32 个任务各一个模型；技能词表共享。
- 不做 6D 物体位姿网络；用相对目标 + 局部特征。
- 不做力/触觉闭环；API 没有。
- 不把预览榜单当 SOTA/难度表；只当赛事方给的难度信号。
- 不做 30Hz 广域网伺服；用 5 步 chunk/双频。
- 不声称仿真成功率能预测真机；仿真只做稳定域和相对排序。

## 1. 事实基线与证据等级

### 1.1 沿用第 12 轮的 A 级事实

| 项 | 事实 | 对本轮的含义 |
|---|---|---|
| 任务 | 32 项桌面任务；10 次/任务；5 类泛化各 2 次；单次 180s | 320 trials；统计噪声约 2.4pp |
| 模型 | 所有任务须基于**同一模型**；模型类型不限 | 技能层必须共享一个 checkpoint |
| API 观测 | 四路 RGB 480×640；无 depth/camera_info/force/tactile | 只能做视觉 + 本体闭环 |
| API 动作 | `ee` 模式为**绝对目标位姿** xyz+rpy；`joint`/`ee` 互斥 | WLA 相对动作必须 compose 到绝对 |
| chunk | `action_chunk_size` 固定；index 0 先执行，其余顺序执行；chunk 内无新观测 | 反馈周期 = `H_c/f_c + τ` |
| 端口 | 从 8765 起 N 个连续端口；每端口独立；`reset()` 必须隔离 | 控制器必须 per-port，无全局状态 |
| 测试通道 | 不计分单任务测试通道 | 唯一敢做 A/B 的地方 |
| 数据 | 33,276 episodes / 18,282,246 frames / 169.28h / 30fps / 32 任务 | 足够做技能分割与参数先验 |
| 官方基座 | UnifoLM-WLA-1.0：6B、约 2,500h、64 任务、chunk 30、30Hz、4 步去噪、54D action、60D state、冻结 VLM、24GB 可微调 | 不从头训；做 action-head 微调 |
| 榜单 | 29.7% 等分数是预览/合成；`step~success` R²>0.999999；跨模型任务相关约 0.098；成功率非 1/10 整数倍 | 不能当 SOTA、难度表或失败分布 |

### 1.2 证据等级

| 等级 | 含义 | 本报告中的例子 |
|---|---|---|
| A | 官方文档、提交模板、数据集元数据、榜单 JSON 直接核实（沿用第 12 轮） | 规则、API、33,276 eps、WLA chunk 30 |
| B | 我们在公开数据/网页上做的分析，可复现 | 榜单 `step~success` 回归、任务相关 |
| C | 设计假设，需 B0–B5/S0–S4 验证 | parity 阈值、技能分割 F1、门控蒸馏增益 |

### 1.3 本轮的核心判断

1. **最大的混杂不是模型容量，而是动作语义。** 帧、锚点、rpy/rot6d、夹爪符号、`pivot`、控制频率任一处错位，都会产生固定方向漂移或 chunk 间漂移，量级可能大于技能层想争取的 +10pp。
2. **第二混杂是测量。** 320 trials 下 `p≈0.25` 的 SE≈2.42pp；5 任务 ×5 A/B 只有 25 对，无法分辨 +5pp。基线复现和技能 A/B 都必须配对、预注册、给 CI。
3. **第三混杂是技能纠缠。** 30 步 chunk 覆盖 1s，接触、插入、释放可能跨在同一个 chunk 里；单体 BC 学到的是技能的平均轨迹，不是技能切换。
4. **因此顺序必须是：基线 → 技能 → 伺服。** 不是「先做最炫的伺服，再补基线」；基线不真，伺服增益不可解释。


## 2. 问题形式化

### 2.1 动作、观测与 MDP

设 base 系为 `F_b`。单臂末端位姿 `T ∈ SE(3)`。挑战赛 `ee` 动作是绝对目标位姿：

```math
a_t = (T_t^{L,\mathrm{cmd}}, T_t^{R,\mathrm{cmd}}, g_t^L, g_t^R, p_t)
\in \mathcal A = SE(3)^2 \times [0,1]^2 \times \mathcal P,
```

其中 `g` 是夹爪开合，`p_t` 是 7 维 `pivot`（下身体/腰部目标）。观测：

```math
o_t = (I_t^{LH}, I_t^{RH}, I_t^{LW}, I_t^{RW}, q_t, T_t^{L}, T_t^{R}, g_t, b_t, l),
```

其中 `l` 是语言指令，`b_t` 是 `lower_body`。MDP 记为 `M = (O, A, P, R, γ)`，单次 episode 上限 180s，成功奖励 `R=1`，否则 0；排名先看成功率，再看待步骤分。

**关键接口事实**：模型内部可以用相对动作，但 API 只接受绝对目标位姿。因此必须定义 compose 算子：

```math
\mathrm{Compose}(a^{\mathrm{rel}}_{1:H}; T_0)
= \big(T_0 \exp(a^{\mathrm{rel}}_1), \ldots, T_0 \exp(a^{\mathrm{rel}}_H)\big),
```

其中 `T_0` 是 **plan-time** 的 EE 位姿，不是执行到第 `s` 步时的 EE 位姿。这个锚点不变量是第 4 节 parity 测试的核心。

### 2.2 技能选项

技能词表：

```math
\Omega = \{\mathrm{REACH}, \mathrm{GRASP}, \mathrm{ALIGN}, \mathrm{INSERT},
\mathrm{HANG}, \mathrm{ZIP}, \mathrm{POUR}, \mathrm{STACK},
\mathrm{RELEASE}, \mathrm{RETRACT}, \mathrm{RECOVER}, \mathrm{HOLD}\}.
```

每个技能是一个 option：

```math
\omega = (I_\omega, \beta_\omega, \mathrm{Prim}_\omega, \Theta_\omega),
```

- `I_ω ⊆ O`：启动条件（目标可见、已抓取、已对齐等）；
- `β_ω: O → {0,1}`：终止条件（到位、接触、滑移、超时等）；
- `Prim_ω: O × Θ_ω → A`：确定性末端原语；
- `Θ_ω ⊆ R^{d_θ}`：技能参数，例如目标相对位姿、接近方向、插入深度、搜索幅度、释放时机。

参数向量统一为 `θ ∈ R^{d_θ}`，`d_θ = 24`，每个技能用掩码选择自己关心的维度。这样模型只需要一个参数头，不需要每个技能一个网络。

### 2.3 单模型约束

设 `f_φ` 是唯一的学习模型（官方 WLA checkpoint）。单模型约束写成：

```math
\forall o,l:\quad \pi(a \mid o,l) = F_\phi(o,l),
```

其中：

1. `F_φ` 的所有可学习部分共享 `φ`；
2. 技能 token 嵌入 `E_ω` 是 `φ` 的一部分；
3. 门控 `c`、技能分类 `ω`、参数 `θ` 都是 `f_φ` 的输出；
4. 末端原语 `Prim_ω` 是解析控制器，没有学习权重；
5. 演示库只存目标图/相对位姿/参数统计，是数据资产，不是策略参数。

这不是「一个模型 + 一个残差策略」，而是「一个模型的条件化输出 + 一个确定性控制器」。如果官方对「模型」作最宽解释，走 §11.2 的 C1/C2/C3 合规模式。

### 2.4 基线 parity

设 `P_ref` 是官方 server + 官方 example adapter 的参考管线，`P_ours` 是我们的适配器 + 同一 checkpoint `φ_0`。对重放集 `D_rep = {o_{1:T}}`，定义逐帧动作误差：

```math
e_t = \|p_{\mathrm{ref}}(t)-p_{\mathrm{ours}}(t)\|_2
    + \lambda_r \|\mathrm{Log}(R_{\mathrm{ref}}(t)^\top R_{\mathrm{ours}}(t))\|_2,
```

其中 `λ_r` 把旋转误差换算成米（例如 `λ_r = 0.1 m/rad`，约 1°≈1.75mm）。Parity 证书：

```math
\mathrm{Parity}(D_{\mathrm{rep}},\varepsilon,\delta):
\max_t e_t \le \varepsilon
\quad\land\quad
\frac{1}{|D_{\mathrm{rep}}|}\sum_t \mathbf 1[e_t\le\varepsilon]\ge 1-\delta.
```

默认 `ε = 1mm + 0.5°`（按 `λ_r=0.1 m/rad` 折算约 1.87mm 的标量阈值），`δ = 0.01`；单元测试用更紧的数值容差（`1e-6`）。另外定义 chunk 边界连续性：

```math
j_k = \|p_{\mathrm{abs}}[k,H_c-1]-p_{\mathrm{abs}}[k+1,0]\|_2
\le v_{\max}\frac{H_c}{f_c}+\varepsilon.
```

如果 `j_k` 超界，说明切片时重新锚定了，或者时间戳错位。这是最容易漏、也最致命的 adapter bug。

### 2.5 优化目标

```math
\max_\phi\ \mathbb E[\mathrm{success}]
\quad \text{s.t.}\quad
\text{single-model}(\phi),\ 
\mathrm{Parity}(P_0,\varepsilon,\delta),\ 
\text{safety}.
```

`P_0` 是基线臂，不是最终策略。技能层只在基线 parity 通过后启动；最终策略 `π_φ` 允许偏离基线，但训练时有门控蒸馏把它拉回基线。

### 2.6 可辨识性条件

视觉伺服/技能原语只在以下条件同时满足时启用：

1. 目标/受器在头部双目或腕部视野内；
2. 深度/视差有效（双目 ROI 有效像素 ≥70%，或腕部特征 inlier ≥15）；
3. 相机标定误差在门限内（重投影 ≤5px）；
4. 目标相对位姿估计协方差低于阈值；
5. 任务/阶段属于刚体接触类（A 档）。

任一条不满足 → 回退基线动作或 PBVS 粗对齐；不硬做 IBVS。这条规则同时是技能契约的一部分。

## 4. 基线复现层：动作空间同构与 parity 证书

### 4.1 必须钉死的八个同构

1. **旋转表示**：挑战赛 `*_ee_pose_gripper_base` 是 xyz+rpy；第 12 轮核对 WLA server 的 `*_ee_6d` 是 xyz+rot6d（9D）。需要 `rpy ↔ rot6d` 双向转换，且约定 Euler 顺序（默认 `xyz`/roll-pitch-yaw，必须与官方示例一致）。
2. **相对→绝对**：WLA 输出相对 plan-time 当前 EE 的 xyz+rotvec；挑战赛要绝对 base 系位姿。`T_abs = T_anchor · exp(a_rel)`。
3. **锚点**：一个 30 步 chunk 的所有动作共享 plan-time 锚点；切片到 5 步时不能重新锚定到当前 EE。
4. **夹爪符号**：挑战赛 `[0,1]` 的方向（0=闭合还是张开）必须用示例/真机确认；WLA 的原始标量可能方向相反。
5. **`pivot` 语义**：挑战赛只写 “Lower-body / pivot target”，7 维顺序/符号未逐维定义；先用零 `pivot` 回退，再用 `example_env.py` 和单任务通道验证。
6. **相机映射**：`cam_left_high`/`cam_right_high`/`cam_left_wrist`/`cam_right_wrist` 的左右、上下、旋转必须用已知标记验证；腕部相机无内参，需要标定。
7. **控制频率**：README 未写死 30Hz；本轮假设 30Hz，但必须用时间戳/动作执行日志实测。
8. **reset 隔离**：N 个端口独立；`reset()` 必须清空 plan cache、技能状态、目标估计、滤波器、计数器。

### 4.2 T1–T8 测试

| 编号 | 测试 | 方法 | 通过标准 | 失败诊断 |
|---|---|---|---|---|
| T1 | rpy↔rot6d 往返 | 随机 10k 旋转，双向转换 | 最大测地误差 <1e-6 rad | Euler 顺序/归一化错 |
| T2 | compose 锚点 | 合成相对动作序列，参考实现 vs 我们的实现 | 最大位姿误差 <1e-6；重新锚定变体应显著失败 | 锚点/乘法顺序错 |
| T3 | chunk 切片连续性 | plan 30，执行 5；检查边界 `j_k` | `j_k ≤ v_max H_c/f_c + ε` | 切片重新锚定/时间戳错 |
| T4 | 夹爪符号 | 开/合指令，读回宽度 | 方向与示例一致 | 符号反了 |
| T5 | 零 `pivot` | 全程返回零 `pivot` | base/waist 静止；再小 `pivot` 仿真验证 | `pivot` 顺序/符号错 |
| T6 | 相机映射 | 四路相机放已知标记 | 左右/上下/旋转正确 | 相机索引/翻转错 |
| T7 | reset 隔离 | 两端口交错 reset/episode | 无状态泄漏；内存不涨 | 全局缓存/滤波器未清 |
| T8 | 延迟/时基 | 记录 `get_action` 时间戳与执行日志 | p50/p99 可解释；timeout 不升 | 图像编码/网络/队列阻塞 |

### 4.3 parity 证书流程

```text
1. 用官方 example_env / 回放数据构造 D_rep（至少 20 条轨迹，覆盖 5 个任务）。
2. 用同一 checkpoint φ0、同一图像预处理，分别跑 P_ref 和 P_ours。
3. 对齐时间戳，计算 e_t、max、分位数、chunk 边界 j_k。
4. 若 max e_t > 2ε 或 within-ε < 99%，按 T1–T8 逐项定位。
5. 通过后生成 parity 证书，写入基线卡。
```

### 4.5 负对照与方差

- **hold**：全程保持初始位姿；成功率应≈0。若明显>0，任务可能太容易或 evaluator 有自动完成逻辑。
- **random**：在安全工作空间内随机小动作；成功率应≈0。若>0，评测/动作语义有严重问题。
- **replay（仅仿真）**：回放演示动作；用于验证环境/动作语义，不用于真机分数。
- **两次 session**：同一 5 任务 ×10 trials 重复两次；若成功率差 >10pp 或延迟分布明显不同，先查评测稳定性，不进入技能层。

### 4.6 失败分类

| 编号 | 现象 | 最可能原因 | 修复 |
|---|---|---|---|
| F1 | 固定方向漂移 | 帧/坐标轴/TCP 偏移 | 重标定/换帧 |
| F2 | 首个 chunk 正常，后续漂移 | 切片重新锚定 | 固定 plan-time 锚点 |
| F3 | 抓取时开合反了 | 夹爪符号 | 翻转/查示例 |
| F4 | base 乱动或不动 | `pivot` 语义错 | 零 pivot 回退 |
| F5 | 超调/振荡 | 控制频率/延迟估计错 | 实测频率/降增益 |
| F6 | 第二 episode 继承第一 episode 状态 | reset 未隔离 | 清状态 |
| F7 | 左右相机内容互换 | 相机映射错 | 修索引/翻转 |
| F8 | 动作滞后、timeout | 网络/编码/队列 | 降分辨率/加 chunk |

### 4.7 伪代码

```python
def compose_chunk(anchor_T, rel_chunk):
    # rel_chunk: (H, 6) xyz + rotvec, relative to plan-time anchor
    return [anchor_T @ exp_se3(r) for r in rel_chunk]

def slice_chunk(plan_rel, anchor_T, start, H_c):
    # IMPORTANT: anchor_T is the plan-time anchor, NOT current EE
    return [anchor_T @ exp_se3(plan_rel[i]) for i in range(start, start + H_c)]

def parity_check(ref_traj, our_traj, eps_p, eps_r):
    errs = []
    for Tr, To in zip(ref_traj, our_traj):
        ep = norm(trans(Tr) - trans(To))
        er = norm(log_so3(Tr.R.T @ To.R))
        errs.append(ep + 0.1 * er)
    return max(errs), mean(e <= eps_p + 0.1 * eps_r for e in errs)
```

不是每个任务都需要全部技能；每个任务是一条技能序列（技能图），见 §5.4。

### 5.2 SKILL-SEG：演示分割

对每条演示 `{(o_t,a_t)}_{t=1}^T`：

**候选边界**：在以下信号上做 change-point 检测，得到候选边界集合 `B`（每 episode 约 10–30 个）：

- EE 线速度/角速度的局部极小；
- 夹爪状态跳变（开→合、合→开）；
- 接触指示 `d_t < d_c` 的上升沿/下降沿（第 11 轮 GEO-RESIDUAL）；
- 目标距离 `||T_ee - T_goal||` 的局部极小；
- 语言/阶段标签（第 10 轮 FACT-VLA）的切换点。

**分割目标**：对每个候选段 `[i,j]`、每个技能 `ω`，拟合参数 `θ`，定义

```math
\mathrm{Fit}(i,j,\omega)
= \min_{\theta\in\Theta_\omega}\sum_{t=i}^{j}
\big\|a_t - \mathrm{Prim}_\omega(\theta)(o_t)\big\|^2.
```

用动态规划求最小代价分割：

```math
C[j] = \min_{i<j,\ \omega}\ C[i] + \mathrm{Fit}(i,j,\omega)
+ \lambda_\omega + \mu,
```

其中 `λ_ω` 是技能复杂度惩罚，`μ` 是切换惩罚。回溯得到每条演示的技能序列与参数。

**为什么用 DP 而不是手工切**：手工切只能覆盖少量任务；DP 把「技能边界」和「技能参数」放在同一个目标里，且可以用 held-out session 检查 F1。它也不是万能：如果两个技能在原语空间里不可分，DP 会把它们合并；这时用 `λ_ω/μ` 调粒度，或回退手工标签。

### 5.3 末端原语

统一形式：给定起始 EE 位姿 `T_start`、目标 `T_goal = T_target · T_target_ee*`、参数 `θ`，相位 `s∈[0,1]`：

```math
T_{\mathrm{des}}(s)
= T_{\mathrm{start}}\exp\!\big(s\,\mathrm{Log}(T_{\mathrm{start}}^{-1}T_{\mathrm{goal}})\big)
\exp\!\big(\delta_\omega(s;\theta)\big),
```

其中 `δ_ω` 是技能特定的扰动/搜索项：

- INSERT：`δ` 含沿插入轴的推进 + 横向螺旋/锯齿搜索；法向柔顺、切向保留；
- HANG：`δ` 含挂钩的抬起/下压方向；
- ZIP：`δ` 含沿拉链方向的拉动与回程；
- POUR：`δ` 含绕倾斜轴的旋转；
- STACK：`δ` 含下落高度与释放时机；
- REACH/RELEASE/RETRACT：`δ=0` 或简单直线。

底层控制：

```math
v_c = K_p e + K_d \dot e + v_{ff},\qquad
e = \mathrm{Log}(T_{\mathrm{ee}}^{-1}T_{\mathrm{des}}),
```

`v_c` 限幅后转成绝对目标位姿；在 `ee` 模式下直接下发。接触段把 `K_p` 的法向分量降到 0.3–0.5 倍，切向保留；滑移/卡住时进入 RECOVER。

### 5.4 技能契约与技能图

每个技能有契约 `(Pre_ω, Inv_ω, Post_ω)`：

| 技能 | Pre | Inv | Post | 失败回退 |
|---|---|---|---|---|
| REACH | 目标可见、EE 在工作空间 | 不碰撞、误差单调下降 | 距预接触 <ε | 重定位/基线 |
| GRASP | 物体在夹爪内、宽度合适 | 夹持力代理稳定 | 物体随夹爪运动 | 重抓/基线 |
| ALIGN | 已抓取、目标可见 | 轴向误差 <ε、无过大横向力 | 对齐完成 | 搜索/重定位 |
| INSERT | 已对齐、孔可见 | 插入轴附近、深度单调 | 深度达标 | 退回/重试 |
| HANG | 挂钩对齐 | 不碰撞、姿态稳定 | 挂入且稳定 | 重挂/基线 |
| ZIP | 拉链头咬合 | 拉力代理在范围、无脱轨 | 拉合到位 | 重咬合 |
| POUR | 容器已抓、受器可见 | 不溢出、角度可控 | 倒出量达标 | 停止/基线 |
| STACK | 物体已抓、放置区可见 | 不碰撞、堆叠稳定 | 放置且稳定 | 重放/基线 |
| RELEASE | 已放置 | 物体不滑落 | 夹爪张开、撤离 | 重抓 |
| RETRACT | 夹爪已张开 | 不碰撞 | EE 离开接触区 | 停/基线 |
| RECOVER | 异常已检测 | 安全速度/工作空间 | 目标重定位或重规划 | 安全停 |

技能图是一个任务级有向图 `G_t = (Ω_t, E_t)`，边表示允许的技能转移；`Post_i ⊆ Pre_j` 才允许边 `i→j`。图是任务数据，不是学习模型。VLA 预测下一个技能，图做过滤；没有合法转移时进入 RECOVER。

### 5.5 技能 token 与门控

- 技能 token：`E_ω ∈ R^{d_e}`，加到 action head 的条件输入（或作为语言 prompt 的前缀）。`E_ω` 属于同一个 checkpoint。
- 技能分类：`p(ω|o,l) = softmax(g_φ(o,l))`。
- 参数头：`θ = h_φ(o,l, E_ω)`。
- 门控：`c = σ(q_φ(o,l, E_ω)) ∈ [0,1]`。

最终动作在切空间混合：

```math
T_{\mathrm{cmd}}
= T_{\mathrm{base}}\cdot
\exp\!\big(c\cdot \mathrm{Log}(T_{\mathrm{base}}^{-1}T_{\mathrm{skill}})\big).
```

如果 `c < c_min`（默认 0.5）或 `Pre_ω` 不满足，直接返回 `T_base`。这样即使技能头出错，也不会比基线更差；最坏情况是逐字回到基线。

### 5.6 相对目标检索（承接第 12 轮）

离线：对每个任务/技能关键帧，存

```math
T_{\mathrm{target}\to\mathrm{ee}}^*
= T_{\mathrm{base}\to\mathrm{target}}^{-1}
  T_{\mathrm{base}\to\mathrm{ee}},
```

以及腕部目标图 `I_wrist`、描述子 `d`、置信度。在线：

```math
T_{\mathrm{goal}}(t)
= T_{\mathrm{base}\to\mathrm{target}}(t)\,
  T_{\mathrm{target}\to\mathrm{ee}}^*.
```

检索时先按任务/技能过滤，再按描述子距离和相对位姿一致性重排 top-k；置信度低时回退到任务级固定相对目标，再低就回退基线。

### 5.7 技能层伪代码

```python
def skill_step(o, base_action, f_phi, library, task_graph):
    a_base, logits, theta, c = f_phi(o, o.language)
    omega = argmax(logits)
    if not task_graph.allowed(omega) or c < C_MIN:
        return a_base
    if not contract_pre(omega, o):
        return a_base

    T_target = localize_target(o)          # stereo / prior
    if T_target is None:
        return a_base
    T_star = library.retrieve(omega, o)    # T_target->ee*
    T_goal = T_target @ T_star
    T_skill = primitive(omega, o.T_ee, T_goal, theta)
    T_base = compose(a_base, o.anchor)
    T_cmd = T_base @ exp_se3(c * log_se3(inv(T_base) @ T_skill))
    return clip_rate_limit(T_cmd)
```


## 6. 学习层：Gated Baseline Distillation

### 6.1 核心思想

技能层不应该从零学一个 30 步策略，而应该在官方基线上做**有门控的增量**：

- 非技能段：蒸馏基线，保持原有能力；
- 技能段：学习技能 token、参数和末端原语；
- 门控 `c` 决定当前帧更信谁；
- 基线只在训练时做 teacher，在线不加载第二份模型。

这解决了两个问题：一是小数据微调容易把基线能力训坏；二是单模型规则下不能在线跑两个策略。

### 6.2 训练目标

设 `π_0` 是冻结的官方 WLA，`D` 是演示数据，`ω_t, θ_t, c_t^{label}` 来自 SKILL-SEG。模型输出 `(a_base, ω_logits, θ, c)`。最终动作为：

```math
a_{\mathrm{final}}
= \mathrm{Blend}\big(a_{\mathrm{base}},
\mathrm{Prim}_{\hat\omega}(\theta), c\big).
```

损失：

```math
\mathcal L
= \mathcal L_{\mathrm{action}}
+ \lambda_\omega \mathcal L_{\mathrm{skill}}
+ \lambda_\theta \mathcal L_{\mathrm{param}}
+ \lambda_c \mathcal L_{\mathrm{gate}}
+ \lambda_p \mathcal L_{\mathrm{parity}}
+ \lambda_s \mathcal L_{\mathrm{smooth}},
```

逐项：

```math
\mathcal L_{\mathrm{action}}
= \|a_{\mathrm{final}} - a^{\mathrm{demo}}\|^2,
```

```math
\mathcal L_{\mathrm{skill}}
= \mathrm{CE}(\omega_{\mathrm{logits}}, \omega^{\mathrm{label}}),
\qquad
\mathcal L_{\mathrm{param}}
= \|\theta - \theta^{\mathrm{label}}\|^2,
```

```math
\mathcal L_{\mathrm{gate}}
= \mathrm{BCE}(c, c^{\mathrm{label}}),
\qquad
\mathcal L_{\mathrm{parity}}
= (1-c^{\mathrm{label}})\,
\|a_{\mathrm{base}} - a_{\mathrm{base}}^{\pi_0}\|^2,
```

```math
\mathcal L_{\mathrm{smooth}}
= \|c_t - c_{t-1}\|^2.
```

默认权重：`λ_ω=0.1`、`λ_θ=0.1`、`λ_c=0.05`、`λ_p=0.5`（warmup 后线性降到 0.1）、`λ_s=0.01`。这些是起点，不是结论；在 held-out session 上调。

### 6.3 训练流程

| 阶段 | 做什么 | 冻结 | 目的 |
|---|---|---|---|
| P0 | 官方 WLA 基线 parity | 全部 | 证明动作语义 |
| P1 | 技能分割 + 参数拟合 | — | 生成标签与先验 |
| P2 | 冻结 VLM，训 action head + token + gate + param | VLM | 保留语义能力 |
| P3 | 高 parity 权重 warmup | VLM | 不把基线训坏 |
| P4 | parity 权重衰减，技能权重上升 | VLM | 学接触技能 |
| P5 | 接触段 hard-example mining | VLM | 提升最后 3cm |
| P6 | 阈值/增益标定 | 全部 | 稳定域 |

### 6.4 单模型合规模式

| 模式 | 做法 | 风险 | 建议 |
|---|---|---|---|
| C1 | 不加载技能头；基线 + 任务级固定原语参数 | 最低 | 保守提交 |
| C2 | 技能 token 作为语言 prompt；沿用原 action head；门控用确定性相位检测 | 低 | 默认 |
| C3 | 共享 skill head + gate + param head；一个 checkpoint | 低–中；需说明 | 性能优先 |
| 禁止 | 每个技能一个独立策略网络；独立视觉编码器；在线集成两个模型 | 高 | 不做 |

C2 的关键是：skill token 不引入新的可学习模块，只是把「当前技能」写进语言条件；门控用 `d_t`/夹爪状态/相位规则，不用学习。C3 的关键是：所有新参数都属于同一个 checkpoint，且共享主干，不是多个模型。

### 6.5 推理

```python
def infer(o, f_phi):
    a_base, logits, theta, c = f_phi(o, o.language)
    omega = argmax(logits)
    if c < C_MIN or not pre(omega, o):
        return a_base
    T_skill = primitive(omega, o.T_ee, goal(o, omega), theta)
    T_base = compose(a_base, o.anchor)
    T_cmd = T_base @ exp_se3(c * log_se3(inv(T_base) @ T_skill))
    return to_api(T_cmd, o)
```

## 7. 执行层：30 步规划 + 5 步伺服

### 7.1 双频结构

```text
VLA:   每 30 步产出一个 plan；后台线程；不阻塞 get_action
Servo: 每 5 步用最新腕部/头部图修正；返回 5 步 chunk
API:   action_chunk_size = 5
```

反馈周期：

```math
T_{\mathrm{fb}} \approx \frac{H_c}{f_c} + \tau.
```

| 场景 | `H_c` | `f_c` | `τ` | `T_fb` | 评价 |
|---|---:|---:|---:|---:|---|
| 官方默认 | 30 | 30 | 50ms | 1050ms | 接触段基本开环 |
| 本方案 | 5 | 30 | 50ms | 217ms | 可做 1–2 次修正 |
| 高延迟 | 5 | 30 | 150ms | 317ms | 降增益/只做 PBVS |
| 低频率 | 5 | 10 | 50ms | 550ms | 改 `H_c=3` 或回退基线 |

`H_c` 是提交前要扫的超参数，不是常数；按实测 `f_c` 和 `τ` 选。

### 7.2 PBVS/IBVS 与相对目标

- 远距离（>5cm）：PBVS，用头双目/局部 ICP 估计 `T_base_target`，误差 `e = Log(T_ee^{-1} T_goal)`。
- 近距离（<2cm）：IBVS，用腕部图像点/轮廓，`v = -λ L_s^+ (s-s*)`。
- 中间：按置信度加权。
- 接触段：法向 `Δ_n` 乘 0.3–0.5 并低通，切向 `Δ_t` 保留。
- 透明/反光/变形：降低 IBVS 权重，回退 PBVS/基线。

### 7.3 延迟补偿

- 用时间戳测 `τ`（图像采集→动作执行）。
- 增益调度：`K_eff = K_0 / (1 + τ/τ_0)`，`τ_0=50ms`。
- Smith/卡尔曼预测：`e_{t+τ} ≈ e_t + J_v v τ`。
- 若 `T_fb > 300ms`：关闭 IBVS，只做 PBVS 粗对齐 + 基线；不要在远程链路上追高增益。

### 7.4 安全与回退

- 每块最多 `1cm / 0.05rad` 的修正；绝对位姿限幅。
- 工作空间盒约束；速度/加速度限幅。
- 连续 3 块 `||Δ||` 超阈值 → 判定目标估计/标定异常，回退基线。
- 滑移/碰撞/编辑检测 → HOLD → RECOVER；最大重试次数后安全停。
- 任何异常都返回合法 chunk，绝不返回 NaN/错误形状。

### 7.5 执行伪代码

```python
def get_action(obs):
    tick(obs)
    maybe_request_plan(obs)          # async, non-blocking
    if plan is None:
        return safe_hold(obs)
    base_chunk = plan[plan_idx:plan_idx + H_c]
    cmd_chunk = []
    for k in range(H_c):
        a_base = base_chunk[k]
        a_final = skill_step(obs, a_base, f_phi, library, task_graph)
        cmd_chunk.append(a_final)
    plan_idx += H_c
    return adapter.to_api(cmd_chunk, obs)
```


## 8. 复杂度分析

### 8.1 符号与规模

| 符号 | 含义 | 规模 |
|---|---|---:|
| `N` | 演示 episode 数 | 33,276 |
| `T̄` | 平均帧数 | ≈549 |
| `K` | 技能词表大小 | 12 |
| `B` | 每 episode 候选边界数 | 10–30 |
| `d_θ` | 技能参数维度 | 24 |
| `M` | 目标库关键帧数 | ≈20k–40k |
| `H_p / H_c` | 规划/执行 chunk | 30 / 5 |
| `f_c` | 控制频率 | 假设 30Hz，待实测 |

### 8.2 离线

**分割**：候选边界检测 `O(N T̄)`；DP `O(N B^2 K)`。代入 `N=33,276, B=20, K=12`：

```math
O(N B^2 K) \approx 1.6\times 10^8
```

可在 CPU 上并行，几分钟到几十分钟量级。

**参数拟合**：每段最小二乘。用充分统计量后为

```math
O(N\bar T d_\theta + N_{\mathrm{seg}} d_\theta^3),
```

`N_seg≈5N`，`d_θ=24`，最坏约 `2×10^9` 次小矩阵运算；按 episode 并行可接受。若用闭式线性原语，成本更低。

**微调**：标准 transformer 训练 `O(E B L d_model^2)`，E 是 epoch，B 是 batch，L 是序列长度；只训 action head/projector/技能头，冻结 VLM。单张 24GB 可跑；不是本轮瓶颈。

### 8.3 在线

| 操作 | 复杂度 | 说明 |
|---|---|---|
| VLA forward | `O(L d_model^2)` | 每 30 步一次，摊到 6 次 `get_action` |
| 技能分类/参数/门控 | `O(d_model d_θ)` | 与 forward 共享 |
| 目标检索 | `O(log M)` | ANN 索引 |
| 原语一步 | `O(k^3)`，`k≤6` | 小矩阵伪逆/求逆 |
| 伺服一步 | `O(k^2)` | 特征/Jacobian |
| 每端口状态 | `O(1)` | plan cache、计数器、滤波器 |

端到端延迟主要由 VLA forward + 图像传输 + RTT 决定；技能层额外开销相对可忽略。目标是 `p99 ≤150ms`，否则加 chunk/降分辨率/关伺服。

### 8.4 内存与通信

- 模型：6B bf16 ≈12GB；共享一份。
- 目标库：20–40k 关键帧，128×128 JPEG 约 5–10KB/帧 → 200–400MB；描述子 40–80MB；索引 <100MB；总 <1GB。
- 每端口：plan cache 30×54 float、图像缓冲、状态机 → <10MB。
- 通信：4 路图缩放后 JPEG 几十 KB/次；chunk 5；payload 可控。

## 9. 正确性论证

### 9.1 引理 1（适配器 compose 同构）

设 plan-time 锚点为 `T_0`，相对动作 `r_1,...,r_H`。参考实现的绝对位姿为

```math
T_i = T_0 \exp(r_i),\quad i=1,\ldots,H.
```

若我们的适配器使用同一锚点和同一指数映射，则逐项相等。若在第 `s` 步重新锚定到当前 EE：

```math
T'_{s+j} = T_s \exp(r_{s+j})
= T_0 \exp(r_s)\exp(r_{s+j}),
```

与 `T_0 exp(r_{s+j})` 相差 `exp(r_s)` 的累积运动。因此，**切片必须保留 plan-time 锚点**；否则后续动作整体漂移，漂移量等于已执行位移。

*证明*：直接代入 SE(3) 乘法结合律；误差界为 `||Log(T_s^{-1}T_0)||`。∎

### 9.2 引理 2（分割的 MAP 最优性）

设 `C(σ)` 是 DP 目标，`σ*` 是真实分割。若存在 margin `δ>0` 使得对所有 `σ≠σ*` 有 `C(σ*) + δ < C(σ)`，则 DP 返回 `σ*`。证明：DP 枚举所有候选边界上的分段，取全局最小；`σ*` 是唯一最小，故返回它。∎

注意：这是**模型选择**保证，不是统计恢复保证；margin 不成立时，分割可能错。因此必须用 held-out boundary F1 评估，并用置信度门控回退。

### 9.3 引理 3（相对目标的坐标不变性）

定义误差

```math
e = \mathrm{Log}\big(T_{\mathrm{ee}}^{-1}
T_{\mathrm{target}}T_{\mathrm{target}\to\mathrm{ee}}^*\big).
```

若对 base 系做左乘 `G∈SE(3)`（即 `T_ee'=G T_ee`，`T_target'=G T_target`），则

```math
e' = \mathrm{Log}\big((G T_{\mathrm{ee}})^{-1}
(G T_{\mathrm{target}})T^*\big)
= \mathrm{Log}\big(T_{\mathrm{ee}}^{-1}T_{\mathrm{target}}T^*\big)
= e.
```

所以控制律只依赖相对位姿，不依赖绝对 base 坐标；换 base 系/重标定不需要重调增益。

若物体移动 `Δ`（`T_target'=Δ T_target`），期望位姿变为 `Δ T_goal`；控制器会把 EE 驱向新目标。这正是相对目标对位置/人为干扰的鲁棒性来源，但前提是 `T_target` 被重新估计；目标估计错，控制器会稳定地追错目标。∎

### 9.4 引理 4（技能契约组合）

设技能序列 `ω_1,...,ω_n`，每个技能有契约 `(Pre_i, Inv_i, Post_i)`。假设：

1. 控制器在 `Pre_i` 成立时维持 `Inv_i`；
2. 终止检测只在 `Post_i` 成立或 guard 触发时触发；
3. 技能图保证 `Post_i ⊆ Pre_{i+1}`。

则按序执行时，系统保持安全不变量；若未触发 guard，最终达到 `Post_n`；若触发 guard，进入 RECOVER/HOLD，且 HOLD 不产生运动。证明：对 `n` 归纳；基础情形由 `Pre_1`；归纳步由假设 3 和 2。∎

这是**设计时契约 + 运行时 guard**，不是形式化验证；感知误差和原语不收敛会破坏假设 1，所以需要置信度门控和回退。

### 9.5 引理 5（单模型合规）

按构造，在线策略为

```math
\pi(a|o,l)
= \mathrm{Blend}\big(f_\phi^{\mathrm{base}}(o,l),
\mathrm{Prim}_{\hat\omega}(h_\phi(o,l)), c_\phi(o,l)\big),
```

其中 `f_φ^base`、`h_φ`、`c_φ` 共享同一个 `φ`；`Prim` 无学习权重；目标库是数据。因此在线只有一个学习模型。∎

注意：这是**构造性合规**，不是官方裁定。若官方把技能头解释为独立模型，退回 C1/C2（§6.4）。

### 9.6 命题 6（测量有效性）

假设：

1. L2 已通过 parity 证书，L3/L4 使用同一适配器；
2. evaluator 在两个臂之间平稳（任务分布、初始条件、评分逻辑不变）；
3. 两臂配对/随机化，除技能层外无其他差异；
4. 成功率是 0/1，配对差值可观测。

则 `E[Y_on - Y_off] = p_on - p_off`，即技能层的平均处理效应。证明：由潜在结果框架，`Y_on - Y_off` 只归因于技能层；parity 保证适配器不是混杂，L3/L4 的差异只在技能层；平稳性保证期望不随时间漂移。∎

这是**因果识别**陈述，不是显著性声明；显著性仍需配对 bootstrap/McNemar 和预注册门槛。

### 9.7 局限

- 所有证明都条件于感知精度、原语收敛、evaluator 平稳等假设；这些没有被形式化验证。
- Parity 证书无法覆盖评测端未公开的语义（控制频率、`pivot` 细节、reset 协议）。
- 分割的 MAP 保证很弱；真实数据上 F1 可能不够。
- 技能契约是工程契约，不是定理；运行时 guard 是最后一道防线。
- 技能层的增益是任务相关的；不承诺全局 +10pp。


## 10. 实验设计与门

### 10.1 基线门 B0–B5

| 门 | 问题 | 设计 | 通过标准 | 失败动作 |
|---|---|---|---|---|
| B0 | 动作语义同构？ | T1–T8 + 重放 | 全过；parity ≥99%，max ≤2ε | 停，修 adapter |
| B1 | 基线能复现？ | 5 任务 ×10 trials ×2 sessions | 两次差异 ≤10pp；Wilson CI 合理 | 停，查评测/模型 |
| B2 | 负对照正常？ | hold/random/replay | hold≈0、random≈0 | 查任务/评测 |

| B4 | 基线卡冻结？ | 权重/commit/配置/结果 | 可重放 | 不进入技能层 |
| B5 | 安全基线锁定？ | 若允许多次提交，先交基线 | 锁定 tie-break | 只交一次则跳过 |

### 10.2 技能门 S0–S4

| 门 | 问题 | 设计 | 通过标准 | 失败动作 |
|---|---|---|---|---|
| S0 | 分割可信？ | 33k 演示，按 session/物体/背景划分 | boundary F1 ≥0.75；参数误差 ≤5mm/2° | 改手工标签/缩技能集 |
| S1 | 仿真收敛？ | peg/hang/zip 三族；噪声/延迟 | A 档技能 ≥90%；0–150ms 稳定 | 降增益/缩技能集 |

| S3 | 全量稳定？ | 32×10 干跑；N 端口 | 无串扰；内存不涨；p99 ≤150ms | 回退基线 |
| S4 | 消融支持因果？ | 见 §10.3 | 关键消融方向一致 | 保留有效部分 |

### 10.3 消融

1. **锚点修复 on/off**：off 时故意在每个 5 步块重新锚定；预期显著漂移/失败，用来证明 parity 层必要。
2. **技能 token on/off**：同 checkpoint，去掉 token；检验技能条件化是否真的有用。
3. **门控蒸馏 on/off**：去掉 `L_parity`；检验是否把基线训坏。
4. **解析原语 on/off**：纯学习 action head vs 学习参数 + 解析原语；检验接触精度来源。
5. **相对目标 vs 绝对目标**：同任务/同初始条件；检验位置/人为干扰。
6. **5 步 vs 30 步**：检验反馈周期。
7. **SKILL-SEG vs 手工阶段标签**：检验分割质量对最终成功率的影响。
8. **门控阈值 `c_min`**：0.3/0.5/0.7；检验回退率与增益的折中。

### 10.4 统计

- 320 trials、`p≈0.25`：`SE≈2.42pp`；不要把 +1–2pp 当结论。
- 10 任务 ×10 配对 = 100 对；若 discordant rate 20–30%，配对差值 SE≈4.5–5.5pp；+10pp 约 2σ，可检测但不算富裕。
- 5 任务 ×10 = 50 对；SE≈6.3pp，不足以分辨 +10pp 以下；只用于预实验。
- 每任务报 Wilson 95% CI；汇总报配对 bootstrap 95% CI；二分类用 McNemar。
- 预注册主任务/主指标/停止规则；多任务用 Holm/BH 控制多重比较。
- 不把榜单预览分数当外部效度；不拿它校准。

### 10.5 任务组合

沿用第 12 轮的 A/B/C 分档，但顺序改为「基线优先」：

```text
priority_t = q_t * Δ_t / cost_t
```

- `q_t`：失败发生在最后 3cm 的比例（先验，B1 后更新）；
- `Δ_t`：技能层条件增益（S2 后更新）；
- `cost_t`：目标库/标定/调参成本。

先做 A 档中 `q_t` 最高、`cost_t` 最低的 5–10 个任务；B 档保留基线；C 档只观察。不要一次铺 19 个。

## 11. 风险与合规

### 11.1 风险表

| 风险 | 影响 | 缓解 |
|---|---|---|
| Parity 假阳性 | 基线是假的，所有增益是伪的 | 单任务通道、负对照、零 pivot 回退、行为检查 |
| 单模型解释 | 技能头/门控被判成多个模型 | 共享权重、一个 checkpoint、C1/C2/C3 |
| 技能分割噪声 | 参数学错、契约错位 | held-out F1、置信度门控、手工回退 |
| 原语失配 | 长尾物体失败 | 只对 A 档启用；失败回退 VLA |
| 目标检索 mismatch | 错误目标 | 任务/技能过滤、top-k 重排、置信度回退 |
| 透明/反光/变形 | 深度/特征失败 | 只对刚体任务启用；腕部 2D + 基线兜底 |
| 标定漂移/换机器人 | 残差变大 | 每机器人重投影校准；误差大关伺服 |
| 人为干扰不在视野 | 漏检 | 本体/夹爪/任务状态兜底；不声称 100% |
| 评测噪声 | +1–2pp 假阳性 | 配对 A/B、bootstrap、预注册 |
| 时间/算力 | 技能层来不及 | 基线先锁；技能只投 A 档 |
| 安全 | 绝对位姿跳变/碰撞 | 限幅/限速/工作空间/最大重试 |

### 11.2 单模型合规

| 模式 | 做法 | 风险 | 建议 |
|---|---|---|---|
| C1 | 不加载技能头；基线 + 任务级固定原语参数 | 最低 | 保守首选 |
| C2 | 技能 token 作为语言 prompt；沿用原 action head；确定性门控 | 低 | 默认 |
| C3 | 共享 skill head + gate + param head；一个 checkpoint | 低–中；需说明 | 性能优先 |
| 禁止 | 每个技能一个独立策略网络；独立视觉编码器；在线集成两个模型 | 高 | 不做 |

提交材料要写清楚：唯一学习模型是 WLA checkpoint；技能 token/gate/param 是同一 checkpoint 的输出；末端原语是无学习权重的控制器；演示库是数据，不是策略；基线 teacher 只用于训练。

### 11.3 安全

- 绝对位姿每块最多 1cm/0.05rad 修正；速度/加速度限幅。
- 工作空间盒约束；碰撞/滑移/编辑检测即停。
- 最大重试次数；失败安全停，不返回非法动作。
- 多端口独立；reset 清空所有状态。

### 11.4 最大风险

**Parity 证书只能证明「我们以为的基线」是对的；如果评测端隐藏的控制频率或 `pivot` 语义与我们假设不同，基线就是海市蜃楼，后续所有技能增益都会变成 adapter 伪影。**


## 12. 与第 10–12 轮的关系

| 层 | 第 10 轮 FACT-VLA | 第 11 轮 GEO-RESIDUAL | 第 12 轮 CHUNK-SERVO | 本轮 E-PARITY |
|---|---|---|---|---|
| 观测 | 相位化 BC | 动作条件化残差/几何 | 双频观测 | 保留，作为技能分割信号 |
| 目标 | 相位标签 | 接触/编辑检测 | 演示检索相对目标 | 保留，升级为技能契约 |
| 动作 | CAC 柔顺 | 残差执行 | 30 步规划 + 5 步伺服 | 保留，加入技能原语 |
| 模型 | 单 VLA | 单 VLA + 几何 | 单 VLA + 确定性伺服 | 单 VLA + 技能 token + 原语 |
| 评测 | 设计门 | 离线/仿真 | 5 任务 ×5 A/B | 基线优先 10 任务 ×10 |
| 新增 | — | — | — | **parity 证书、SKILL-SEG、门控蒸馏** |

**保留**：FACT-VLA 的相位化 BC、CAC 柔顺执行、EGP 证据门控；GEO-RESIDUAL 的动作条件化残差、米制表面距离、编辑检测；CHUNK-SERVO 的 30/5 双频、相对目标、数字孪生、竞赛组合。

**升级**：观测层 → 技能层 → 测量层；单体 chunk → 技能 token + 原语；adapter 细节 → parity 证书；5×5 A/B → 10×10 配对。

**剪枝**：不重复造 VLA/World Model；不做逐任务策略；不做 6D 物体位姿网络；不做力/触觉；不做 30Hz 广域网伺服；不把榜单当难度表。

**本轮真正的新东西**：

1. 把「基线复现」从工程步骤提升为**可检查的 parity 证书**（T1–T8 + 重放 + 基线卡 + 负对照）。
2. 把「技能学习」做成**单 checkpoint 的技能 token + 解析末端原语 + 契约**，不是多个策略。
3. 把「门控基线蒸馏」作为训练目标：技能段学技能，非技能段蒸馏基线。
4. 把「测量有效性」写成命题：只有基线 parity 成立，配对 A/B 才能解释为技能层效应。
