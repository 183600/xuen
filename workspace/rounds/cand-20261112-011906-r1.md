# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 4 轮；本轮灵感：「数据集」×「位姿估计」）

> 第 57 轮把安全的赌注从"证据质量"推到"先验质量"——元先验给效率、共形给保底，并用跨模态对账与个性化信任状态机补上单模态共谋与人类博弈两条腿。但它的风险自陈留下了两个尚未命名的前提：**(a)** 元先验的一切本领都来自数据集 𝒟_meta，可这份数据集是"由被它治理的策略自己采集、自己打标"的——机器人只在"自己已经敢踩"的地方获得事后真值，于是数据集中系统性缺席的恰恰是最高风险的区域（幸存者偏差）；更糟的是，承诺后实测的标签被当初促成承诺的信念污染，形成"我信它安全→我去踩→我把踩过的记录当证据→更信它安全"的数据乱伦（data incest）。**(b)** 所有"区域 r 的证据"都偷偷假设了"我知道自己在哪"——位姿估计是证据地图未署名的守门人：位姿漂移会让两次重访共享同一误差，"跨到访一致"这一最强证据可被漂移伪造；也会让同一区域的证据写进两个地方，或把两个地方合并成一个。本轮两个灵感各补一条地基：**数据集**从"中性题库"变成"必须溯源的策略产物"——覆盖证书、选择倾向去偏、标签来源分级、审计留出集；**位姿估计**从"传感器噪声"变成"证据的坐标系"——位姿条件证据、位姿去相关证书、区域数据关联门。核心命题由"少样本可校准的证据说可信"升级为 **"出身可溯源、坐标可关联的证据说可信"**：没有出身证明与定位证明的证据，只是传闻。

核心矛盾：
- **H29（数据集 vs 先验）**：先验质量的上界由数据集覆盖与标签有效性决定；而数据集由被治理的策略主动采集，只在已敢触碰处有真值——最危险的区域恰恰无标签，且承诺后标签被信念污染，先验越自信越会污染自己的训练集。
- **H30（位姿 vs 证据）**：证据只有在"同一个地方"才可累积；位姿漂移让重访的独立性造假（伪一致）或让同一区域分裂（伪分歧），而第 56/57 轮的跨到访、跨模态证据都默认位姿正确。位姿误差不是可平均掉的独立噪声，而是共享的混杂变量。
- **H31（关联 vs 安全）**：数据关联（这是不是同一个区域）本身没有证据门；错误合并会用一个安全区的历史给危险区背书，错误分裂会让证据永远攒不够而退化为永久探询。

## 0. 直觉与动机

**灵感 1（数据集 → 谱系、覆盖与去偏）**
直觉：机器人部署生涯的元学习不是"老师给题库"，而是"学生自己出题、自己批卷、还专挑会做的题做"。数据集不是中性的，它是一份**政策遗迹**：采什么、在哪采、谁来标，全由当前策略决定。两条必须处理的病理——**幸存者偏差**（只在敢踩处有事后真值，最难的地方永远没有标签）与**数据乱伦**（标签来自被信念污染的承诺轨迹，反过来强化该信念）。对策不是"多采点"，而是让数据集**自证其出身**：每个样本带采集策略、选择倾向、标签来源等级、位姿不确定度；用逆倾向加权（IPW）把部署分布与数据集分布对齐；显式维护 visited⊇committed⊇labeled 三角，未标注的高风险分层就是**缺陷证书**；再留出永不训练的审计分层，并用"干预探针"打断自我强化回路。一句话：**先验可以摊销，但只能摊销有出身证明、覆盖到位的经验。**

**灵感 2（位姿估计 → 证据的坐标系与数据关联）**
直觉：地图里每个"这里"都藏着一个"我在哪"。位姿估计不是可以平均掉的独立噪声，而是**混杂变量**：同一漂移段内的两次观测共享位姿误差，它们"一致"其实只问了一遍；不同传感器若在各自坐标系里比较，位姿误差会制造伪分歧（假警报）或互相抵消（伪一致）。所以证据必须**带坐标系**：每条证据带位姿协方差与锚点，注册到区域时按空间重叠质量折损；跨到访/跨模态要主张"独立"，就必须先出**位姿去相关证书**（不同锚、回环闭合、绝对基准），否则共享误差的观测只算一个。更进一步，"这是不是同一个区域"本身要有**数据关联门**：关联后验分三态——合并 / 新建 / 幽灵区；幽灵态下两区并存、取风险并集、禁止跨区证据累积，先花位姿证据消歧，而不是急着合并省探针。

**灵感 3（合流 → 证据的"出身+定位"双证与第六类证据）**
直觉：数据集的错误与位姿的错误有同一个根——**数据关联**：标签写错了地方就是覆盖缺陷，证据写错了地方就是位姿漂移。于是本轮把第 57 轮的证据门从"五类+校准证书"升级为"**五类×双证+EV-pose**"：EV-probe\*/EV-visit/EV-xmodal 必须先过数据准入门（DPG）与区域关联门（RAG），再谈校准与独立；新增 **EV-pose**（回环/绝对锚/多假设一致）作为"坐标证据"，它能把相关观测升格为独立对，却永远不能把 L1 升格为 L2。击穿安全需要：先验错 ∧ 数据准入漏检 ∧ 关联错误 ∧ 无位姿证据 ∧ 无裕度 ∧ 人也错——纵深从五层继续加厚。

**灵感 4（PPX → 先修坐标，再花探针）**
直觉：当位姿不确定或关联歧义时，最该做的不是接触探针而是**位姿探针**——回环重观测、主动找绝对基准、多假设一致性检验。位姿未定就采接触数据，等于往错的格子里写证据；数据无权就调元先验，等于用没有出身证明的经验背书。PPX 把检查点第一件事从"元推断"改成"位姿-关联自检"，并新增第二条停止条件：坐标不明不累积证据。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（数据集谱系与覆盖 DPC）** 样本 s=(o,θ̂,r,z,π_col,t,u_pose,ℓ_src)，π_col 采集策略（诱导选择概率 e(s)=P(s∈𝒟|x)），ℓ_src∈{L0 事后实测,L1 主动探针,L2 承诺轨迹反推}。部署分布 Q 与数据分布 P_D 的倾向加权估计 Q̂(θ|x)=Σ_i w_i δ_{θ̂_i}，w_i=1/e(s_i)（重叠 e≥e_min 才可用）。覆盖函数 Cov(𝒟,w)=层 w 内有效样本数（有效=去重 ∧ ℓ_src∈{L0,L1} ∧ PIQ≥π_min；见定义 141）；覆盖证书 k_cov(w,δ_cov)=使分层风险估计偏差≤δ_cov 的最小有效样本数。三角审计 visited⊇committed⊇labeled 暴露缺陷；审计留出集 𝒟_audit 永不入训练。乱伦率 η_incest=|L2|/|𝒟|（按分层计）。

**定义 140（数据集-先验准入门 DPG）** 元先验 q_φ 对区域 r 可用 ⇔ (i) Cov(𝒟,w(r))≥k_cov(w(r),δ_cov)；(ii) η_incest(w(r))≤η_max；(iii) 倾向模型已声明且重叠 e(s)≥e_min（近邻层兜底）；(iv) 数据集偏移 DS(r)=TV(P̂_D(w(r)),Q(w(r)))≤θ_ds。任一不满足 ⇒ **数据无权**，r 即使观测看似 ID 也按 OOD 处理（退共形带/非参），先验无权不得承诺。DPG 是"数据出境签证"：没有它，第 57 轮的摊销后验不得进入 P_fail。

**定义 141（位姿条件证据 PCEv）** 证据 e 带位姿协方差 Σ_p(e)、锚点 a(e)（绝对锚 / 相对锚链 / 航迹推算）与年龄 age(e)。注册不确定度 Σ_e=Σ_p+Σ_r；空间重叠质量 Ω(e,r)=∫_r N(x;μ_e,Σ_e)dx；位姿信息质量 PIQ(e,r)=Ω(e,r)·(1−λ_drift(age,a))。有效证据要求 PIQ≥π_min。**位姿去相关**：同锚且未回环的两观测视为一个有效独立证据；有效独立数 n_eff=1+Σ_{(i,j)}ρ_dec(i,j)𝟙[去相关证书]，ρ_dec∈{0,1}。EV-pose ⇔ 回环闭合 ∨ 绝对基准固定 ∨ 位姿后验单峰且 tr(Σ_p)≤σ_p²；EV-pose 仅把相关观测升格为独立对，不改变接触等级、不替代 EV-probe 的校准证书。

**定义 142（区域数据关联门 RAG）** 观测 o 对已存区域的关联后验 p(H|o,𝓜)，H∈{同区域 r, 新区域, 歧义}。三态：p(同)≥θ_same⇒合并；p(同)≤θ_new⇒新建；否则 **幽灵区 g**。幽灵态规则：两区并存、风险取 max、禁止任何跨区证据累积与 EV-visit/EV-xmodal 计数，必须先花位姿证据（EV-pose）消歧；未过 RAG 的观测不得作为重访或独立证据。合并是升险操作，须有证据；分裂是保守操作，允许无证据发生。

**定义 143（出身-定位证据门 PSE 与证书 J_d）** 证据类 {EV-probe\*,EV-visit,EV-margin,EV-xmodal,EV-human,EV-pose}。EV-probe\*/EV-visit/EV-xmodal 额外须双证：provenance（覆盖/标签级/IPW/DPG 通过）∧ pose（PIQ≥π_min ∧ 关联态=merged）。不可逆接触还须关联态非幽灵且 (EV-pose ∨ PIQ≥π_irr)，且 EV-probe\* 的样本效率证书须在 DPG 通过的层内声明。J_d=(𝒟 谱系,倾向模型,覆盖图,标签级直方图,DS 日志,位姿协方差日志,关联日志,幽灵注册表,留出清单)；J_p 继承 J_m 并扩展为 J_p∧J_d。

**定义 144（位姿条件探-诺-演 PPX）** 每检查点：①位姿-关联自检 → (PIQ, 关联三态)；②DPG 决定元先验是否可用（无权则切共形带/非参）；③幽灵态优先发位姿探针（回环/绝对锚）消歧，而非接触探针（预算 k_g）；④其余继承 PCX（元推断/对账/承诺/绕行/协商）。终止于 {承诺, 绕行, L2 协商, 安全停, 位姿待定保守停}。

## 2. 关键算法伪代码（完整版见产物区）

```python
def dataset_admissible(D, r, meta, Q):            # IP-139/140
    w = stratum(r)
    if coverage(D, w) < k_cov(w, delta_cov): return False, 'coverage'
    if incest_rate(D, w) > eta_max:          return False, 'data_incest'
    if not overlap_ok(D.propensity, w):      return False, 'no_overlap'
    if dataset_shift(D, w, Q) > theta_ds:    return False, 'shift'
    return True, 'ok'

def pose_conditioned_update(M, r, e):             # IP-141
    piq = overlap_mass(e, r) * (1 - drift(e.age, e.anchor))
    if piq < pi_min: return M, 'pose_unusable'
    rho = decorrelation_cert(e, M.evidence[r])    # 同锚未回环 ⇒ 相关
    M.b[r] = bayes_update(M.b[r], e.like, w=rho * piq)
    return M, 'ok'

def associate(M, o):                              # IP-142 三态
    p = assoc_posterior(o, M)
    if p.same >= theta_same: return 'merge', argmax_region(p)
    if p.same <= theta_new:  return 'new', new_region(o)
    return 'ghost', spawn_ghost(o)                # 禁止跨区累积
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| DPC | O(\|𝒟\|) 离线 + O(1)/查询 | O(\|𝒟\|+\|W\|) | 倾向重叠、标签分级、留出隔离 |
| DPG | O(1)/区域 | O(\|W\|) | 数据无权即按 OOD（保守） |
| PCEv | O(\|e\|·d) | O(\|𝓜\|·d) | PIQ 诚实、去相关证书不可自授 |
| RAG | O(\|V\|·d) | O(\|V\|+\|G\|) | 歧义取幽灵、风险取并集 |
| PSE | O(\|σ\|+\|G\|) | O(\|σ\|) | 双证缺一即拒、EV-pose 不升级接触 |
| PPX | O(\|CP\|·(k_p+k_g)·(C_VOI+d)) | O(\|V\|+\|G\|) | 位姿未定不采接触、k_p+k_g 终止 |

**正确性定理（CCPS+ 概要）**：在 A33–A40 上加 (A41) 数据覆盖与倾向声明诚实、审计留出隔离、η_incest≤η_max；(A42) 位姿协方差与锚点声明诚实；(A43) 关联门三态保守且幽灵态禁止跨区累积；(A44) EV-pose 仅升格独立性、永不升级接触等级。则：(i) 先验错误贡献被 DPG 截断——仅在 Cov≥k_cov ∧ DS≤θ_ds 的层内以 ε_meta(k) 计入，缺陷层贡献 ≤δ_cov；(ii) 伪独立/伪重访贡献 ≤δ_pose+δ_assoc（幽灵态禁止累积，同锚观测只计一次）；(iii) 交互单调性保持：数据无权、坐标不明、关联歧义只会降低承诺概率或增加位姿探针，不存在升险路径；(iv) PPX 在 k_probes+k_g 内终止。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 元无知：覆盖/位姿证书本身被低估，"有证书的错误" | 高 | 保守上界估计 + 审计留出 + 第二意见传感器 + 证书权限硬顶（证书不得单独授权不可逆接触） |
| IPW/倾向模型错误或重叠不足 | 高 | 重叠检查 e≥e_min + 近邻层兜底 + 敏感性分析 + 无法校正则降权不承诺 |
| 幽灵区爆炸导致永久探询 | 中高 | 位姿探针预算 k_g + 保守合并（并入幽灵而非新建）+ 超预算转安全停 |
| 数据乱伦隐性回路 | 高 | 干预探针 + 时间滞后标签 + 留出分层 + 标签来源分级禁用 L2 入安全先验 |
| 位姿门拖慢控制回路 | 中 | 前向 O(d) + 预取 + 可退回第 57 轮路径（但降级为保守） |

## 6. 本轮最大风险

**一句话**：本轮把赌注推到"数据集的覆盖与位姿的关联"之后，安全就依赖"系统诚实地知道自己哪里没数据、且知道自己在哪"——但覆盖证书与位姿协方差本身是被估计的，存在"元无知（不知道自己的无知）"的盲区：一个只在自己敢踩处采样、又系统性低报位姿协方差的数据集，会让覆盖证书与关联证书双双"合格"，把错误洗成有证书的错误——证书本身成为新的橡皮章；必须以证书权限硬顶（证书不得单独授权不可逆接触）、审计留出与干预探针、位姿协方差保守上界三重护栏，宁可承认"我不知道自己不知道"，也不让一张自签的证书替代真实接触证据。

# 第 58 轮产物 · 创新点清单 v34：Provenance-Pose（数据集谱系×位姿条件证据×数据关联，DPC×DPG×PCEv×RAG×PSE×PPX）

> 承接第 57 轮 IP-133~138（MFSL/XMC/PTM/MXI/FSE/PCE+）与第 56 轮 IP-127~132（SMM/PCE/BVK/ISE/TAF/MEC）。第 57 轮把赌注从"证据质量"推到"先验质量"；本轮指出先验质量还压在两个未审计的地基上——**数据集是政策遗迹（幸存者偏差 + 数据乱伦）**，**位姿估计是证据的坐标系（漂移伪造独立性与区域身份）**。据此把部署命题升级为 **"出身可溯源、坐标可关联的证据承诺"**：先验必须持数据出境签证（DPG），证据必须持出身+定位双证（PSE），区域身份必须过数据关联门（RAG），位姿本身升级为可兑换独立性的第六类证据（EV-pose）。赌注链由"模型置信→证据质量→先验质量"继续下推为"**先验质量 ← 数据集质量 ← 数据关联质量**"。
> IP 编号：IP-139~IP-144（共 6 个），升级 IP-133/134/137/138 以纳入数据集准入与位姿条件。

## 0. 核心 IP 设计

### IP-139 DPC（数据集谱系与覆盖）

```python
def dataset_sample(o, theta_true, r, z, policy, t, pose_cov, src):
    return Sample(o=o, theta_hat=theta_true, r=r, z=z, pi_col=policy,
                  t=t, u_pose=pose_cov, l_src=src)      # L0/L1/L2

def update_coverage(D, w):
    valid = [s for s in D.by_stratum(w)
             if s.l_src in ('L0', 'L1') and piq_of(s) >= pi_min]
    D.Cov[w] = dedup_count(valid)
    D.eta_incest[w] = frac([s for s in D.by_stratum(w) if s.l_src == 'L2'])
    return D

def fit_propensity(D, policy_log):
    # e(x)=P(x 被采入 𝒟 | 部署分布)；只支持重叠区估计
    e = train_classifier(D.samples, policy_log)       # 采集=1/未采=0
    return e

def ipw_posterior(D, w, e, prior):
    S = D.by_stratum(w)
    if min(e(s.x) for s in S) < e_min:                 # 重叠不足
        return None, 'no_overlap'
    wts = [1.0 / e(s.x) for s in S]
    return weighted_posterior(S, wts, prior), 'ok'

def coverage_certificate(D, w, delta_cov):
    k = 1
    while stratified_risk_bound(D, w, k) > delta_cov:
        k += 1
    return k                                           # 声明所需的 k_cov
```

### IP-140 DPG（数据集-先验准入门）

```python
def dataset_prior_gate(D, r, meta, Q):
    w = stratum(r)
    if D.Cov[w] < D.k_cov[w]:                    return False, 'coverage'
    if D.eta_incest[w] > eta_max:               return False, 'data_incest'
    if not overlap_ok(D.propensity, w):         return False, 'no_overlap'
    if tv(P_hat(D, w), Q(w)) > theta_ds:        return False, 'dataset_shift'
    if w in D.audit_stack:                      return False, 'audit_holdout'
    return True, 'ok'

def meta_infer_gated(M, r, obs, meta, D, Q):
    ok, why = dataset_prior_gate(D, r, meta, Q)
    if not ok:                                   # 数据无权 ⇒ 视同 OOD
        return Inf(cls='OOD', reason=why,
                   belt=conformal_belt(meta.res, sim=ctx(r), alpha=alpha_conf))
    return meta_few_shot_infer(M, r, obs, meta)  # 第 57 轮路径（仅在有签证层）
```

### IP-141 PCEv（位姿条件证据与去相关）

```python
def pose_conditioned_update(M, r, e):
    Sigma_e = e.Sigma_p + M.Sigma[r]                  # 注册不确定度
    Omega = overlap_mass(M.region[r], e.mu, Sigma_e)  # ∫_r N(x; μ_e, Σ_e)
    piq = Omega * (1 - drift_penalty(e.age, e.anchor))
    if piq < pi_min:
        return M, 'pose_unusable'                     # 不可用，不写入信念
    corr = same_anchor(e, M.evidence[r]) and not has_loop_closure(e, M)
    w = piq * (independence_weight(corr))             # 相关 ⇒ 折为一次
    M.b[r] = bayes_update(M.b[r], e.like, w=w)
    M.evid_meta[r].append((e.anchor, e.Sigma_p, corr, e.t))
    return M, 'ok'

def pose_evidence(M, r, e_pair):
    # EV-pose：回环 / 绝对锚 / 单峰低协方差
    ok = loop_closure(e_pair) or absolute_anchor(e_pair) or \
         (is_unimodal(e_pair.pose_post) and trace(e_pair.Sigma_p) <= sigma_p2)
    if ok:
        M.rho_dec.add(pair_id(e_pair))                # 仅升格独立性
        M.audit.log(('EV-pose', r, pair_id(e_pair)))
    return 'EV-pose' if ok else None

def effective_independent_count(M, r):
    base = 1
    return base + sum(1 for pr in M.evidence[r] if pair_id(pr) in M.rho_dec)
```

### IP-142 RAG（区域数据关联门，三态）

```python
def region_associate(M, o):
    p_same = assoc_posterior(o, M)                    # 含位姿项
    if p_same >= theta_same:
        return 'merge', nearest_region(o, M)          # 升险操作：需证据
    if p_same <= theta_new:
        return 'new', create_region(o)
    g = spawn_ghost(o)                                # 歧义 ⇒ 幽灵
    M.ghost.add(g)
    return 'ghost', g

def ghost_commit_guard(M, region):
    # 幽灵态：两区并存、风险取并集、禁止跨区证据累积
    if region in M.ghost:
        return ('reject', 'association_ambiguous',
                max_risk(M.ghost_cluster(region)))
    return ('ok', region)

def resolve_ghost(M, g, pose_ev):
    if pose_ev == 'EV-pose' and assoc_entropy(M, g) < theta_H:
        M.merge_ghost(g)                              # 有证据才合并
    elif assoc_entropy(M, g) < theta_H:
        M.split_ghost(g)                              # 无证据则永久分开（保守）
    M.audit.log(('ghost_resolve', g, pose_ev))
```

### IP-144 PPX（位姿条件探-诺-演）

```python
def probe_commit_evolve_pose(x0, M, task, budget, consent, personas, D, Q):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        # ① 位姿-关联自检：先修坐标，再花探针
        st, reg = region_associate(M, latest_obs(cp))
        if st == 'ghost':
            for _ in range(budget.k_g):
                pev = execute_pose_probe(cp, reg)     # 回环/绝对锚
                resolve_ghost(M, reg, pose_evidence(M, cp.region, pev))
                if reg not in M.ghost: break
            if reg in M.ghost:
                return safe_stop(cp, 'association_ambiguous')  # 保守停
        # ② 数据准入决定先验是否可用
        inf = meta_infer_gated(M, cp.region, M.obs[cp.region], M.meta, D, Q)
        M.b[cp.region] = inf.post if inf.cls == 'ID' else worst_in(inf.belt)
        sigma = foothold_schedule(x0, cp, M); R = schedule_risk(sigma, M)
        # ③ 探针循环（继承 PCX，证据写入需过位姿条件）
        while select_gait(R) == 'halt' and budget.probes_left > 0:
            p = argmax(admissible_probes(cp, M, F_abs),
                       key=lambda q: voi_meta_pessimistic(q, M, inf) - cost(q))
            if voi_meta_pessimistic(p, M, inf) < theta_voi: break
            e = execute_probe(p, cap=F_abs)
            M, st = pose_conditioned_update(M, cp.region, e)
            if st != 'ok': break                      # 位姿不可用，不写信念
            M, _, Dx = xmodal_fuse(M, cp.region, e)
            budget.spend(p)
            sigma = reselect_footholds(x0, cp, M); R = schedule_risk(sigma, M)
        g = select_gait(R)
        lv = contact_level(cp)
        ev = tag_evidence_p(sigma, M, lv)
        if g != 'halt' and provenance_pose_gate(
                core_contact(cp), M, D, Q)[0] == 'ok':
            sched.append(commit(sigma, g)); log.append(ev); continue
        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, M)) != 'halt': route = alt; continue
        return negotiate_or_stop(cp, M, sigma, R, consent,
                                 tau_int=tau_int(personas.active.auth))
    return sched, log, M
```

```python
def meta_few_shot_infer_gated(M, r, obs, meta, D, Q):
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DPC | O(\|𝒟\|) 离线 + O(1)/查询 | O(\|𝒟\|+\|W\|) | 倾向重叠、标签分级、留出隔离（A41） |
| DPG | O(1)/区域 | O(\|W\|) | 数据无权即按 OOD（A41） |
| PCEv | O(\|e\|·d) | O(\|𝓜\|·d) | PIQ 诚实、去相关证书不可自授（A42） |
| RAG | O(\|V\|·d) | O(\|V\|+\|G\|) | 歧义取幽灵、风险取并集（A43） |
| PSE | O(\|σ\|+\|G\|) | O(\|σ\|) | 双证缺一即拒、EV-pose 不升级接触（A44） |
| PPX | O(\|CP\|·(k_p+k_g)·(C_VOI+d)+\|CP\|·A\*) | O(\|V\|+\|G\|) | 位姿未定不采接触、k_p+k_g 终止 |

**正确性定理（Provenance-Pose Soundness, PPS / CCPS+）**
假设 A22–A32（第 53–55 轮）、A33–A36（第 56 轮）、A37–A40（第 57 轮）成立；**(A41)** 数据集覆盖与倾向声明诚实：分层有效样本数、e(s)、ℓ_src 标注真实，审计留出集永不参与训练或先验选择，η_incest≤η_max；**(A42)** 位姿协方差与锚点声明诚实，PIQ 计算不低报不确定性，去相关证书不可由被评估方自授；**(A43)** 关联门三态保守：歧义一律进幽灵态且幽灵态禁止跨区证据累积；**(A44)** EV-pose 仅升格观测独立性，永不升级接触等级、永不替代 EV-probe\* 的校准证书。则：

1. **先验错误被数据签证截断**：ID 路径 P(fail) ≤ δ_f + ε_meta(k)·1[DPG pass] + δ_cov + δ_probe + ε_h(w_max)；DPG 未过的层只以共形带最坏值或非参区间进入 P_fail。
2. **伪独立/伪重访被坐标证书截断**：跨到访、跨模态贡献的上界由"同锚相关观测只计一次 + 幽灵态禁止累积"保证，额外失败贡献 ≤ δ_pose + δ_assoc；EV-pose 仅把相关对恢复为独立对，不放宽任何接触门槛。
3. **交互单调性保持**：数据无权 ⇒ 退共形/非参；坐标不明 ⇒ 位姿探针或保守停；关联歧义 ⇒ 幽灵并集风险。三者只会降低承诺概率或增加位姿探针，不存在升险路径。
4. **终止性**：每检查点位姿探针 ≤k_g，接触探针 ≤k_probes；PPX 在 k_probes+k_g 内终止于 {承诺, 绕行, L2 协商, 安全停, 位姿待定保守停}。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta·1[DPG] + δ_cov + δ_probe + ε_h
                   + δ_ood·α_conf + δ_xm·1[L1] + δ_pose + δ_assoc)
             − P(𝓜 陈旧未检出) − P(护盾回退失败)
             − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效) − P(证书自签未被审计发现)
```

关键：**效率来自元先验，但先验须持数据出境签证（DPG）；安全性来自共形与坐标证书，且证书权限封顶**（任何证书都不得单独授权不可逆接触）；**证据的独立性由位姿去相关来"挣"，不由模态自封**；**区域身份是升险操作，合并需证据、分裂默认保守**。赌注从"先验质量"继续下推，但下推的每一步都配一个不可自授的证件。

云边协议 CEB++ → **CEB+++**：云端不得直接下发"覆盖良好"的先验——元模型更新除第 57 轮的影子校准外，还须附带**数据谱系与覆盖审计**（分层样本来源、L2 占比、IPW 重叠、审计留出未泄漏），边端独立复核 DS 与覆盖后才允许该层元先验取得"数据签证"；边端回传位姿去相关证书与幽灵消歧结果，作为云端数据关联校准集。第 57 轮"一切判定器走隔离"在本轮细化为"**判定器与其数据签证分离审计**"——出题人、批卷人、签证官三者不得是同一方。

## 6. 本轮最大风险

**一句话**：本轮把赌注推到"数据集的覆盖与位姿的关联"之后，安全就依赖"系统诚实地知道自己哪里没数据、且知道自己在哪"——但覆盖证书与位姿协方差本身是被估计的，存在"元无知（不知道自己的无知）"的盲区：一个只在自己敢踩处采样、又系统性低报位姿协方差的数据集，会让覆盖证书与关联证书双双"合格"，把错误洗成有证书的错误——证书本身成为新的橡皮章；必须以证书权限硬顶（证书不得单独授权不可逆接触）、审计留出与干预探针、位姿协方差保守上界三重护栏，宁可承认"我不知道自己不知道"，也不让一张自签的证书替代真实接触证据。
