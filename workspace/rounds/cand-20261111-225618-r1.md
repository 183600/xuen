# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「意图理解」×「世界模型」）

> 第 54 轮把技能组合从"能力匹配"推进到"动作空间占用 + 云边协同"，并给出动作-鲁棒性联合证书 J。但整座大厦有两个未言明的地基：**任务意图 ι 被当作给定的任务串 T_desc，世界模型 M 被当作可信的仿真神谕**。本轮把这两个地基显式化、概率化、可证伪化。核心矛盾：H22：意图是部分可观测的潜变量，针对错误意图签发的证书在真实意图下可能灾难性失效；H23：所有动作剖面 α_S、鲁棒性谱 ρ、仿真证据都由世界模型 M 生成，若 M 存在系统偏差或被"模型利用"（model exploitation），证书就退化为自指循环。

## 0. 直觉与动机

**灵感 1（意图不是字符串，而是后验分布 → 歧义集）**
直觉：用户说"把杯子拿过来"时，"拿"的方式、目标杯、是否允许移动障碍物都未定。应把意图 ι 建成潜变量，由观测 o（指令、演示、场景、操作者纠正）经贝叶斯逆规划得到后验 `p(ι | o, M)`，并取 **ε-可信集 `I_ε`** 作为"当前无法排除的意图集合"。组合规划必须对 `I_ε` 中所有意图都不失败，而不是对某个点估计最优。这把第 54 轮的"任务动作序列 `A_T`"从确定集合升级为 **意图索引的族 `{A_T(ι)}`**。

**灵感 2（世界模型是证据源，也是误差源 → 可信度带）**
直觉：第 53–54 轮的动作剖面与鲁棒性谱，本质上都是"世界模型告诉我们"的结果。若 M 在某个 `(s,a)` 上偏差大，那么 `α_S(a)=1` 只是模型的一厢情愿。于是要把 M 的不符度 `δ_M` 作为一等公民：用保形预测（conformal prediction）在标定集上给出转移残差分位数，定义 **模型支持域 `supp_δ(M)`**；落在域外的动作不得签发证书。这把"仿真到现实"的鸿沟从一句免责声明，变成一个可检查的数值预算。

**灵感 3（意图与世界模型天然耦合 → 逆规划的对偶）**
直觉：意图推断用世界模型做似然 `p(o | ι, M)`，而世界模型的可信度又依赖意图所诱导的状态分布——二者是同一个推断问题的两面。若 M 有偏，`p(ι | o, M)` 也会有偏；反之若意图错，标定数据的状态分布也会错。因此需要 **联合接地（joint grounding）**，并显式度量"接地三元组" `Δ_g = (Δι, δ_M, δ_a)`，而不是分别承诺两个数。

**灵感 4（失效归因三分 → 意图错 / 模型错 / 技能弱）**
直觉：执行失败时，第 53 轮的 Explain 只会说"哪个动作/哪个维度坏了"，但更根本的三种原因是：真实意图不在 `I_ε` 内、状态动作落在模型支持域外、或意图与模型都对但技能/鲁棒性不足。解释器必须做 **因果三分**，否则会把"意图理解错误"误诊为"鲁棒性不足"，从而修错地方。三分归因决定了闭环该回传"重新问人"、"重新标定模型"还是"重新组合技能"。

**灵感 5（主动消歧与意图遗憾 → 从被动保守到主动求证）**
直觉：`I_ε` 过大时，一味保守会让系统瘫痪或频繁请求人类。更好的做法是选择 **信息增益最大且安全** 的探针动作，主动区分候选意图；若无法安全探针，再请求澄清。目标函数应从"最坏情况鲁棒"扩展为 **意图遗憾** `R(ι) = V(ι,P*) - V(ι,P)` 在 `I_ε` 上的最坏值，形成 **意图后验 → 歧义集 → 条件证书 → 主动探针 → 后验更新** 的闭环。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（意图后验与 ε-歧义集）**
意图空间 `𝕀`，观测 `o_{1:t}`（指令、演示、场景图、操作者纠正），世界模型 `M`。后验
```
p(ι | o_{1:t}, M) ∝ p(o_{1:t} | ι, M) · p(ι)
```
其中 `p(o_{1:t} | ι, M) = ∫ p(o | s) p(s | ι, M) ds`，`p(s | ι, M)` 由 M 在意图 ι 的最优策略 `π*_ι` 下滚出。给定保形非一致性分数 `s(ι,o)` 与标定集分位数 `q_{1-α_i}`，定义
```
I_ε(o) = { ι ∈ 𝕀 : s(ι,o) ≤ q_{1-α_i} }
```
满足 `P(ι* ∈ I_ε) ≥ 1-α_i`。**意图熵** `H(ι|o)` 度量歧义程度。

**定义 122（世界模型可信度与支持域）**
世界模型 `M : S×A → Δ(S)`。转移残差 `r(s,a) = d(s', M(·|s,a))`，`d` 为对状态敏感的度量（如任务相关加权 Wasserstein）。保形阈值
```
δ_M = Quantile_{1-α_m}({ r(s,a) : (s,a,s') ∈ D_cal })
supp_δ(M) = { (s,a) : r(s,a) ≤ δ_M }
```
模型可信证书 `W = (M, δ_M, supp_δ, coverage=1-α_m)`。**注意**：`δ_M` 的覆盖率成立依赖部署分布与标定集可交换。

**定义 123（意图-世界接地）**
接地 `g = (p(ι|o,M), W)`。`g` **可采纳** 当且仅当 `I_ε ≠ ∅` 且计划 P 的所有仿真证据轨迹满足 `(s,a) ∈ supp_δ(M)`。接地误差三元组
```
Δ_g = (Δι, δ_M, δ_a),  Δι = 1[ι* ∉ I_ε]
```
`Δ_g` 是可随证书传递的"认知误差"向量，与第 53 轮的 `ρ`（执行鲁棒性）正交。

**定义 124（意图条件联合证书）**
```
J_ι = ( p(ι|o,M), I_ε, δ_M, ρ_ι, A_cert, γ_ce, evidence )
```
可部署当且仅当
```
∀ ι' ∈ I_ε :  cover(S, A_T(ι')) ∧ min_d ρ_{ι'}(d) ≥ ρ_min
∧ δ_M ≤ Θ_M ∧ δ_a ≤ Θ_a
```
**最坏意图鲁棒性** `ρ^wc = min_{ι'∈I_ε} min_d ρ_{ι'}(d)`。只有 `ρ^wc ≥ ρ_min` 才签发。

**定义 125（三源失效归因）**
给定失败观测 `o_f` 与已有证据 `E`，假设空间 `H = {H_intent, H_model, H_skill}`：
- `H_intent`：`ι* ∉ I_ε`（计划优化了错误意图）；
- `H_model`：`(s,a) ∉ supp_δ(M)`（世界模型在失效点不可信）；
- `H_skill`：前两者成立，但 `ρ`/`α` 不足（真实技能或鲁棒性失败）。

归因 `ĥ = argmax_{h∈H} p(o_f | h, E) · p(h)`。三分要求 **互斥且完备**（在给定证据粒度下）。

**定义 126（主动意图消歧与意图遗憾）**
安全探针域 `A_safe ⊆ A_core`。探针 `a_q` 的期望信息增益
```
EIG(a_q) = I(ι ; o_{t+1} | o_{1:t}, a_q)
a_q* = argmax_{a_q ∈ A_safe} [ EIG(a_q) - λ_r · risk(a_q) ]
```
若 `EIG(a_q*) < e_min` 或 `|I_ε| > N_max` 或 `H(ι|o) > H_max`，则请求人类澄清。**意图遗憾** `R(ι) = V(ι,P*) - V(ι,P)`；组合目标为
```
min_P  max_{ι ∈ I_ε} R(ι)   s.t.  J_ι 可部署
```

## 2. 关键算法 伪代码

### IP-121 IIE（Intent Inference Engine）

```python
def infer_intent(observations, M, intent_space, prior, calib, alpha_i=0.05):
    post = {}
    for iota in intent_space:
        # 逆规划：在 M 下按意图 iota 的最优策略滚出轨迹，算观测似然
        post[iota] = prior[iota] * observation_likelihood(observations, iota, M)
    post = normalize(post)

    # 保形阈值：标定集上真实意图的排名/分数分位数，保证覆盖率 >= 1-alpha_i
    scores = [conformal_score(post, iota_true) for (iota_true, _) in calib]
    q = quantile(scores, 1.0 - alpha_i)
    I_eps = {iota for iota in intent_space if conformal_score(post, iota) <= q}
    return IntentBelief(post=post, I_eps=I_eps, entropy=entropy(post))
```

### IP-122 WMC（World Model Calibration）

```python
def calibrate_world_model(M, D_cal, alpha_m=0.05):
    residuals = []
    for (s, a, s_next) in D_cal:
        pred = M(s, a)                      # 分布
        residuals.append(task_weighted_distance(s_next, pred))
    delta_M = quantile(residuals, 1.0 - alpha_m)
    support = ConformalSupport(M, delta_M)
    # 漂移监测：滑动窗口残差分位数上升则降级
    drift = detect_shift(residuals_window())
    return WorldCred(M, delta_M, support, coverage=1-alpha_m, drift=drift)
```

### IP-123 ICC（Intent-Conditioned Certificate）

```python
def intent_conditioned_certify(plan, intent_belief, cred, gamma_ce,
                               rho_min, Theta_M, Theta_a):
    if cred.delta_M > Theta_M or cred.drift > drift_budget:
        return ('reject', 'world_model_untrusted', cred.delta_M)

    rho_wc = {}
    for iota in intent_belief.I_eps:
        A_T = task_actions(iota)
        for (sid, a_c) in plan:
            a_e = gamma_ce(a_c)
            s = skill_lib[sid]
            if not cover_check(s.alpha, A_T):
                return ('reject', 'intent_action_gap', iota, sid)
            if not cred.support.contains_plan_step(s, a_e):
                return ('reject', 'model_support_gap', iota, sid, a_e)
        rho_wc[iota] = compose_robustness_chain(plan, iota, K)

    worst = min(min(r.values()) for r in rho_wc.values())
    if worst < rho_min:
        return ('reject', 'intent_robustness_gap', worst)

    delta_a = max_alignment_error(gamma_ce, common_core(plan, intent_belief.I_eps))
    if delta_a > Theta_a:
        return ('reject', 'action_mismatch', delta_a)
    return ('ok', IntentCert(intent_belief.I_eps, cred, rho_wc, delta_a))
```

### IP-124 GCT（Grounding Consistency Triage）

```python
def triage_failure(o_f, intent_belief, cred, plan):
    in_intent = o_f.true_intent in intent_belief.I_eps
    in_support = cred.support.contains(o_f.state, o_f.action)

    hypotheses = {
        'intent': not in_intent,
        'model':  not in_support,
        'skill':  in_intent and in_support,   # 前两者排除后即为技能/鲁棒性
    }
    # 反事实重放：在每个假设下，失效是否"本可预测"
    logp = {}
    for h, active in hypotheses.items():
        if not active:
            logp[h] = -inf
            continue
        logp[h] = counterfactual_loglik(o_f, h, plan, intent_belief, cred) \
                  + log_prior[h]
    h_hat = argmax(logp)
    return GroundingExplanation(h_hat, softmax(logp),
                                recommended_action={
                                    'intent': 'ask_human / re-infer',
                                    'model':  'recalibrate / expand D_cal',
                                    'skill':  'recompose / raise rho_min'}[h_hat])
```

### IP-125 AIR（Active Intent Resolution）

```python
def active_intent_resolution(intent_belief, cred, skills, budget, lam_r):
    if intent_belief.entropy < H_max and len(intent_belief.I_eps) <= N_max:
        return ('plan', None)

    candidates = []
    for s in skills:
        for a in cred.support.intersect(s.alpha.core):   # 只探支持域内的核心动作
            a_c = gamma_ce.inverse(a)
            eig = mutual_information(intent_belief, a, cred)
            risk = transition_risk(s, a, cred)
            if is_reversible(s, a, cred):
                candidates.append((eig - lam_r * risk, eig, s, a, a_c))

    if not candidates:
        return ('ask_human', intent_belief.top_k(3))

    best = max(candidates, key=lambda x: x[0])
    if best[1] < e_min or budget.exhausted():
        return ('ask_human', intent_belief.top_k(3))
    return ('probe', best[2], best[3])      # 执行探针后更新后验
```

### IP-126 IWG（Intent-World Grounded Certificate）

```python
def issue_IWG(plan, observations, intent_belief, cred, gamma_ce, budgets):
    status, ic = intent_conditioned_certify(
        plan, intent_belief, cred, gamma_ce,
        budgets.rho_min, budgets.Theta_M, budgets.Theta_a)
    if status != 'ok':
        return ('reject', ic)

    J = JointCert(rho=ic.rho_wc, A_cert=ic.A_cert,
                  gamma_ce=gamma_ce, delta_a=ic.delta_a,
                  evidence=collect_evidence(plan, cred))

    # 接地三元组随证书一起传递；任何一项超预算则整体否决
    Delta_g = (delta_iota(intent_belief), cred.delta_M, ic.delta_a)
    if not grounding_budget_ok(Delta_g, budgets):
        return ('reject', 'grounding_budget_exceeded', Delta_g)

    return ('ok', IWGCert(intent=intent_belief, world=cred,
                          action=J, grounding=Delta_g,
                          validity_condition=f'coverage_i>={1-budgets.alpha_i},'
                                             f'coverage_m>={1-budgets.alpha_m}'))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| IIE | `O(|𝕀|·T·|S|)` / 更新 | `O(|𝕀|)` | 后验校准、保形覆盖率 |
| WMC | `O(|D_cal|)` 标定 + `O(1)` 查询 | `O(|D_cal|+|S|)` | 可交换性、残差度量 sound |
| ICC | `O(|I_ε|·|S|·|A| + |𝔇_ρ|)` | `O(|I_ε|·|A|)` | 最坏意图、预算闭合 |
| GCT | `O(|H|·|evidence|)` | `O(|H|)` | 三假设互斥完备 |
| AIR | `O(|A_safe|·|𝕀|·|S|)` | `O(|𝕀|)` | EIG 近似、安全域可逆 |
| IWG | 组合上界 | `O(|I_ε|·|A|+|D_cal|)` | 联合 sound、三元预算 |

**正确性定理（Intent-World Grounded Soundness）**
假设第 54 轮 (A26)–(A28) 成立，并新增：**(A29)** 意图后验保形校准，`P(ι* ∈ I_ε) ≥ 1-α_i`；**(A30)** 部署分布与标定集可交换，`δ_M` 覆盖率 `≥ 1-α_m`；**(A31)** 三源归因互斥完备，主动消歧在预算内收敛。则
```
P_success ≥ 1 - α_i - α_m - Σ_d (1 - ρ^wc(d)) - β_E - P(δ_a > Θ_a)
```
**关键**：证书不再对"意图正确、模型可信"做无条件承诺，而是把这两个前提变成显式的 `α_i`、`α_m` 预算。代价是：该式是**联合界**，对 `α_i` 与 `α_m` 的相关性不作任何处理——而二者恰恰通过逆规划强相关，这是本定理最大的诚实缺口（见第 5 节）。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 意图歧义集过大导致决策瘫痪 / 频繁打扰人类 | 高 | AIR 主动探针 + 澄清预算 + 默认保守意图回退 |
| 保形可交换性在非平稳世界失效，`δ_M` 虚假收窄 | 高 | 在线重标定 + 变点检测 + `δ_M` 漂移告警与证书降级 |
| **模型偏差与意图误判共振（共同盲区）** | 极高 | 独立外部锚点（人类/物理传感器）+ 对抗意图集 + 交叉验证 |
| 主动探针本身不可逆或诱发风险 | 高 | `A_safe ⊆ A_core` + 可逆性检查 + 人类否决通道 |
| 三源归因不完备（多因叠加、证据不足） | 中 | 允许混合归因 + 反事实重放 + 证据置信度标注 |
| 接地证书过于保守，可用性下降 | 中 | 分级证书 + 风险预算 `α_i/α_m` 自适应 |

## 6. 本轮最大风险

**一句话**：本轮把意图与世界模型从"隐含前提"提升为"显式预算"，但意图后验由世界模型做似然、模型可信度又由意图分布定标定集，二者构成一个**相互确认的闭环**；一旦二者共享同一系统性偏差，`I_ε` 会围绕错误意图收缩、`δ_M` 也会在该意图诱导的分布上虚假收窄，系统将签发一枚**自洽却错误**的"已接地"证书，且所有内部指标都显示健康——因此必须以 **独立于该闭环的外部锚点（人类澄清、物理传感、跨模型交叉验证）与对抗意图探针** 作为不可被世界模型解释掉的硬约束。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（IIE×WMC×ICC×GCT×AIR×IWG）

> 承接第 54 轮产物 v31。本轮在"动作-鲁棒性双证书"之上，补上两个此前被当作隐含前提的地基——**意图理解（Intent Understanding）** 与 **世界模型可信度（World Model Credibility）**，把证书从 `J` 升级为 **意图-世界联合接地的 `IWG`**：
> - **IIE（Intent Inference Engine）**：由观测经贝叶斯逆规划得到意图后验与 ε-歧义集 `I_ε`；
> - **WMC（World Model Calibration）**：用保形预测给出世界模型不符度 `δ_M` 与支持域 `supp_δ(M)`；
> - **ICC（Intent-Conditioned Certificate）**：对 `I_ε` 中最坏意图签发条件证书 `J_ι`；
> - **GCT（Grounding Consistency Triage）**：把失效三分归因为意图错 / 模型错 / 技能弱；
> - **AIR（Active Intent Resolution）**：用信息增益最大且可逆的安全探针主动消歧；
> - **IWG（Intent-World Grounded Certificate）**：接地三元组 `Δ_g=(Δι,δ_M,δ_a)` 随证书传递。
>

## 2. 关键算法 伪代码

### IP-121 IIE

```python
def infer_intent(observations, M, intent_space, prior, calib, alpha_i=0.05):
    post = normalize({
        iota: prior[iota] * observation_likelihood(observations, iota, M)
        for iota in intent_space
    })
    scores = [conformal_score(post, iota_true) for (iota_true, _) in calib]
    q = quantile(scores, 1.0 - alpha_i)
    I_eps = {iota for iota in intent_space if conformal_score(post, iota) <= q}
    return IntentBelief(post, I_eps, entropy(post))
```

### IP-122 WMC

```python
def calibrate_world_model(M, D_cal, alpha_m=0.05):
    residuals = [task_weighted_distance(s_next, M(s, a))
                 for (s, a, s_next) in D_cal]
    delta_M = quantile(residuals, 1.0 - alpha_m)
    support = ConformalSupport(M, delta_M)
    drift = detect_shift(residuals_window())
    return WorldCred(M, delta_M, support, coverage=1-alpha_m, drift=drift)
```

### IP-123 ICC

```python
def intent_conditioned_certify(plan, intent_belief, cred, gamma_ce,
                               rho_min, Theta_M, Theta_a):
    if cred.delta_M > Theta_M or cred.drift > drift_budget:
        return ('reject', 'world_model_untrusted', cred.delta_M)
    rho_wc = {}
    for iota in intent_belief.I_eps:
        A_T = task_actions(iota)
        for (sid, a_c) in plan:
            a_e = gamma_ce(a_c)
            s = skill_lib[sid]
            if not cover_check(s.alpha, A_T):
                return ('reject', 'intent_action_gap', iota, sid)
            if not cred.support.contains_plan_step(s, a_e):
                return ('reject', 'model_support_gap', iota, sid, a_e)
        rho_wc[iota] = compose_robustness_chain(plan, iota, K)
    worst = min(min(r.values()) for r in rho_wc.values())
    if worst < rho_min:
        return ('reject', 'intent_robustness_gap', worst)
    delta_a = max_alignment_error(gamma_ce,
                                  common_core(plan, intent_belief.I_eps))
    if delta_a > Theta_a:
        return ('reject', 'action_mismatch', delta_a)
    return ('ok', IntentCert(intent_belief.I_eps, cred, rho_wc, delta_a))
```

### IP-124 GCT

```python
def triage_failure(o_f, intent_belief, cred, plan):
    in_intent = o_f.true_intent in intent_belief.I_eps
    in_support = cred.support.contains(o_f.state, o_f.action)
    hypotheses = {
        'intent': not in_intent,
        'model':  not in_support,
        'skill':  in_intent and in_support,
    }
    logp = {}
    for h, active in hypotheses.items():
        logp[h] = (counterfactual_loglik(o_f, h, plan, intent_belief, cred)
                   + log_prior[h]) if active else -inf
    h_hat = argmax(logp)
    return GroundingExplanation(
        h_hat, softmax(logp),
        recommended_action={
            'intent': 'ask_human / re-infer',
            'model':  'recalibrate / expand D_cal',
            'skill':  'recompose / raise rho_min'}[h_hat])
```

### IP-125 AIR

```python
def active_intent_resolution(intent_belief, cred, skills, budget, lam_r):
    if intent_belief.entropy < H_max and len(intent_belief.I_eps) <= N_max:
        return ('plan', None)
    candidates = []
    for s in skills:
        for a in cred.support.intersect(s.alpha.core):
            eig = mutual_information(intent_belief, a, cred)
            risk = transition_risk(s, a, cred)
            if is_reversible(s, a, cred):
                candidates.append((eig - lam_r*risk, eig, s, a,
                                   gamma_ce.inverse(a)))
    if not candidates:
        return ('ask_human', intent_belief.top_k(3))
    best = max(candidates, key=lambda x: x[0])
    if best[1] < e_min or budget.exhausted():
        return ('ask_human', intent_belief.top_k(3))
    return ('probe', best[2], best[3])
```

### IP-126 IWG

```python
def issue_IWG(plan, observations, intent_belief, cred, gamma_ce, budgets):
    status, ic = intent_conditioned_certify(
        plan, intent_belief, cred, gamma_ce,
        budgets.rho_min, budgets.Theta_M, budgets.Theta_a)
    if status != 'ok':
        return ('reject', ic)
    J = JointCert(rho=ic.rho_wc, A_cert=ic.A_cert, gamma_ce=gamma_ce,
                  delta_a=ic.delta_a, evidence=collect_evidence(plan, cred))
    Delta_g = (delta_iota(intent_belief), cred.delta_M, ic.delta_a)
    if not grounding_budget_ok(Delta_g, budgets):
        return ('reject', 'grounding_budget_exceeded', Delta_g)
    return ('ok', IWGCert(intent=intent_belief, world=cred,
                          action=J, grounding=Delta_g))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| IIE | `O(|𝕀|·T·|S|)` | `O(|𝕀|)` | 后验保形覆盖 `≥1-α_i` |
| WMC | `O(|D_cal|)` 标定 + `O(1)` 查询 | `O(|D_cal|+|S|)` | 可交换性 + 残差度量 sound |
| ICC | `O(|I_ε|·|S|·|A|+|𝔇_ρ|)` | `O(|I_ε|·|A|)` | 最坏意图校验、预算闭合 |
| GCT | `O(|H|·|evidence|)` | `O(|H|)` | 三假设互斥完备 |
| AIR | `O(|A_safe|·|𝕀|·|S|)` | `O(|𝕀|)` | EIG 近似、探针可逆 |
| IWG | 组合上界 | `O(|I_ε|·|A|+|D_cal|)` | 联合 sound、三元预算 |

**正确性定理（Intent-World Grounded Soundness）**
假设第 54 轮 (A26)-(A28) 成立；**(A29)** `P(ι*∈I_ε) ≥ 1-α_i`（意图后验保形校准）；**(A30)** 部署分布与标定集可交换，`δ_M` 覆盖率 `≥1-α_m`；**(A31)** 三源归因互斥完备，主动消歧在预算内收敛。则
```
P_success ≥ 1 - α_i - α_m - Σ_d(1-ρ^wc(d)) - β_E - P(δ_a>Θ_a)
```
关键：**意图正确性是概率承诺而非事实**，**模型可信性是覆盖率承诺而非点保证**，二者以 `α_i/α_m` 的形式被计入失败预算，而不是被隐藏。

> 诚实说明：上式为联合界。`α_i` 与 `α_m` 实际通过逆规划强相关（模型偏差直接污染意图后验），联合界对相关性不作处理，因此偏保守且在共同偏差下会同时低估两者；这正是第 5 节"共同盲区"风险的数学来源。

## 6. 本轮最大风险

**一句话**：意图后验用世界模型做似然、模型可信度又由意图分布定标定集，二者构成**相互确认的闭环**；一旦共享同一系统性偏差，`I_ε` 会围绕错误意图收缩、`δ_M` 也会在该意图诱导的分布上虚假收窄，系统将签发一枚**自洽却错误**的"已接地"证书，且内部指标全部健康——故必须以 **独立外部锚点（人类澄清、物理传感、跨模型交叉验证）与对抗意图探针** 作为不可被世界模型解释掉的硬约束，宁可承认"未接地"，绝不把"意图与模型互相点头"当作部署依据。
