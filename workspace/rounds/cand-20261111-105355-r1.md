# 第 55 轮（承接第 54 轮 v16+++ GroundEdge-GenSim+++；新灵感周期第 1 轮；本轮灵感：「具身智能大模型」×「社会规范理解」）

> 第 54 轮已把技能组合抬升为「动作空间 α_S × 鲁棒性谱 ρ」的双证书体系（ACS/SCOM/CEC/AEC/JTC）。本轮把「社会规范」引入，但拒绝把它做成外挂安全过滤器：**规范是定义在动作空间与交互历史之上的一个场 ν**，与 α_S、ρ 共同构成三元证书。核心矛盾：H22：具身大模型的规范知识停留在“陈述层”（会说礼貌话），却在“动作层”无法落位（不知何时靠近、看向谁、以何节奏让位），存在陈述-动作鸿沟；H23：规范是上下文相关、多主体、文化可变的，任何全局规范分类器都不 sound；H24：检测规范违反 ≠ 生成规范行为，系统还缺“违规可解释 + 可修复”的闭环。

## 0. 直觉与动机

**灵感 1（规范场 → 规范不是离散标签，而是动作空间上的可微场）**
直觉：过去把规范当作 `is_violation ∈ {0,1}` 的分类问题，这是错误的抽象。规范更像重力：它在 `(上下文 c, 动作 a, 交互历史 h)` 上形成一个**规范场** `ν : C × A × H → [0,1]^k`，每个维度给出“该动作在该情境下有多得体”。动作空间因此不再只有一个可行域 `A`，而是被切出**规范可行域** `A^ν_θ(c,h) = {a | ν_j(a,c,h) ≥ θ_j, ∀j}`。这让第 54 轮的 α_S 有了社会语义：**技能覆盖动作 ≠ 该动作在社会上可接受**，两者是动作空间上的两个正交约束。

**灵感 2（陈述-动作鸿沟 → 区分“会说”与“会做”）**
直觉：具身大模型常能正确回答“应该先敲门吗？”，但其策略在实际状态分布下并不执行该判断。把“陈述规范” `ν_decl(c,a,h)`（模型被问询时给出的判断）与“动作规范” `ν_real(a,c,h)`（策略实际选择动作所隐含的判断）分开，定义**规范鸿沟** `Δ_g = E[|ν_decl - ν_real|]`。这给出一个可测、可诊断的新指标：一个模型可以规范考试满分却社交失礼，`Δ_g` 正是这种“知行不一”的度量。

**灵感 3（规范组合涌现 → 每个技能都礼貌，组合起来未必礼貌）**
直觉：第 54 轮已发现动作兼容不等于语义兼容；规范层面更严重。两次单独得体的动作，因**时序、距离累积、话语轮次、角色切换**而在组合后产生“涌现违规”。例如“靠近递物”与“凝视确认”各自合规，叠加后变成压迫性接近。因此规范不能在单技能上封闭检查，必须在**序列与多主体层**上做规范闭包，显式建模涌现项 `ε_emerge`。

**灵感 4（云边规范宪法 → 云端审议、边端护栏、歧义仲裁）**
直觉：大模型的规范推理强但慢、且云边动作粒度不同；边端需要毫秒级的社会物理护栏（个人空间、注视、让位时序、力/速度）。让云端产出**规范宪法** `K_n`（可审议、可解释、含文化上下文），再把它**编译**为边端的规范守卫 `g_edge`；高严重度、物理可执行、低延迟的规范下沉到边端否决，歧义或制度性规范上浮到云端。边端“先否决、再上浮、超时保守”，形成**云审议 - 边守卫 - 歧义仲裁 - 规范回写**的闭环。

**灵感 5（规范鲁棒谱与歧义延迟 → 不懂就问，而不是硬猜）**
直觉：规范在不同文化、具身形态、人群密度、角色关系下会漂移。把第 53 轮的鲁棒性谱扩展出**规范维** `ρ_norm`：规范合规性在分布漂移下保持多少。更重要的是：当规范后验的**歧义带** `ε_amb` 超阈值时，系统应**延迟决策**（最小冒犯动作、询问、让位），而不是用高置信度伪装确定性。这把“规范不可判定”从失败变成一等公民。

**灵感 6（规范修复与三元证书 → 违规不是终点，修复是能力）**
直觉：社交中违规不可避免，关键在**检测-解释-修复-记账**。定义**规范债务** `D_norm`：未修复的小违规累积会耗尽对方容忍度。系统需具备修复策略集 `Π_rep = {道歉, 解释, 退出, 让位, 询问, 补偿}` 与修复成功概率。最终把第 54 轮的 `J=(ρ,A_cert,γ_ce,δ_a)` 升级为**动作-鲁棒-规范三元证书** `J^+ = (ρ,A_cert,γ_ce,δ_a,ν,N_cert,ρ_norm,D_norm)`，让“能做人做的事”与“能在人面前得体地做”统一到同一张可验证证书里。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（规范上下文与交互历史）**
规范上下文 `c = (scene, agents, roles, relations, culture, task_phase, density)`；交互历史 `h = (a_{1:t}, u_{1:t})`，其中 `u` 为人类的社会信号（注视、退让、迟疑、言语）。规范只在 `(c,h)` 上定义，拒绝上下文无关的全局规范。

**定义 122（规范场与规范可行域）**
规范场 `ν : C × A × H → [0,1]^k`，`k` 个维度（安全、隐私、尊重/礼貌、公平、角色适切、轮次协同）。`ν_j=1` 表示该维度完全得体，`0` 表示严重违反。规范可行域
```
A^ν_θ(c,h) = { a ∈ A | ν_j(a,c,h) ≥ θ_j, ∀ j=1..k }
```
规范严重度 `σ(a,c,h) = Σ_j w_j·(1 - ν_j(a,c,h))`，规范风险 `R_norm = E[σ]`。

**定义 123（陈述-动作规范鸿沟）**
`ν_decl` 为模型被显式问询时给出的规范判断，`ν_real` 为由策略动作分布反推的隐含规范判断（例如用反事实接受率估计）。定义
```
Δ_g(c,h) = (1/k) Σ_j |ν_decl,j(a*,c,h) - ν_real,j(a*,c,h)|
```
其中 `a*` 为执行动作。`Δ_g` 大即“知行不一”。

**定义 124（规范组合与涌现违规）**
对技能序列 `S_1⊗...⊗S_n`，规范场满足**次可加闭包**
```
ν_{S_1⊗...⊗S_n}(c,h) ≥ min_i ν_{S_i}(c,h) - ε_emerge(S_1..S_n)
```
`ε_emerge ≥ 0` 捕捉时序/距离/话语/角色交互带来的额外违规。若 `min_i ν_{S_i} ≥ θ` 但 `ν_{⊗} < θ - δ`，称**涌现违规**。规范组合可判定当且仅当 `ν_{⊗} ≥ θ ∧ ε_emerge ≤ Ε`。

**定义 125（规范证书）**
```
N_cert = (ν, scope, ε_amb, σ_max, evidence, repair_policy)
```
- `scope`：规范有效域（文化、角色、场景的适用边界）；
- `ε_amb`：规范后验歧义带宽度（由 conformal / 贝叶斯可信集给出）；
- `σ_max`：证书范围内最大严重度；
- `evidence`：至少包含规范探针集、反事实仿真、争议样本；
- `repair_policy`：违规后的修复策略及其成功概率下界。
部署条件：`ν ≥ θ ∧ ε_amb ≤ Ε ∧ σ_max ≤ Σ ∧ repair_policy 可执行`。

**定义 126（云边规范宪法）**
规范宪法 `K_n = (N_cloud, G_edge, τ_norm, Arb)`：
- `N_cloud`：云端规范审议结果，含文化/制度/角色推理与解释；
- `G_edge = compile(N_cloud) = {g_i}`：编译后的边端规范守卫，`g_i : C×A×H → {pass, veto, escalate}`；
- `τ_norm`：歧义仲裁延迟预算；
- `Arb`：仲裁规则——边端 veto 优先于云端计划；`escalate` 在 `τ_norm` 内未决则回退到最小冒犯动作 `a^⊥`（冻结/让位/询问）。

**定义 127（规范鲁棒谱与规范迁移契约）**
规范鲁棒谱 `ρ_norm(d)` 度量在漂移维度 `d`（文化、具身形态、人群密度、角色、遮挡/光照、语言）下规范合规率的保持度。迁移契约
```
T_norm = (Inv, Var, β_adapt)  s.t.  ν_target ≥ ν_source - Δ_culture,  ∀ 维度 ∈ Inv
```
`Inv` 为跨域不变规范（如不得伤害），`Var` 为需本地适配的规范，`β_adapt` 为适配预算。禁止把 `Var` 当作 `Inv` 直接迁移。

**定义 128（动作-鲁棒-规范三元证书）**
```
J^+ = (ρ, A_cert, γ_ce, δ_a, ν, N_cert, ρ_norm, D_norm)
```
其中 `D_norm` 为规范债务（未修复违规的加权累积，`D_norm_{t+1} = λ·D_norm_t + σ_t·(1 - repair_success_t)`）。部署条件：第 54 轮条件全部成立，且 `N_cert` 可部署、`ρ_norm ≥ ρ_min`、`D_norm ≤ D_max`。

## 2. 关键算法 伪代码

### IP-121 NGP（Norm Grounding Probe）

```python
def norm_grounding_gap(policy, probes, judge):
    # probes: (c, h, a, intended_norm) 反事实规范探针集
    gaps = []
    for c, h, a, nu_decl in probes:
        # 陈述层：直接问询大模型
        nu_decl_pred = judge(policy.llm, c, h, a)
        # 动作层：策略在该情境下选择 a 的反事实概率
        p_a = policy.action_prob(a, c, h)
        nu_real = to_norm_scale(p_a, policy.action_dist(c, h))
        gaps.append(abs(nu_decl_pred - nu_real))
    return mean(gaps), bootstrap_ci(gaps)
```

### IP-122 NFC（Norm Field Calibration）

```python
def calibrate_norm_field(transitions, annotators, alpha=0.1):
    # 多标注者 + 上下文索引，学习后验而非点估计
    nu_model = ContextualNormRegressor(dims=K)
    nu_model.fit(transitions, annotators)
    calib = ConformalNormWrapper(nu_model, alpha=alpha)
    def nu(a, c, h):
        lo, hi = calib.interval(a, c, h)      # 规范歧义带
        return calib.point(a, c, h), (hi - lo)
    return nu   # 返回 (规范值, 歧义带)
```

### IP-123 NCC（Norm-Checked Composition）

```python
def norm_checked_composition(skill_seq, nu, h, theta, Emerge_budget):
    nu_seq = [nu(s, c, h) for s in skill_seq]
    base = elementwise_min([x.value for x in nu_seq])
    eps = estimate_emergent_violation(skill_seq, h, nu)   # 反事实联合仿真
    if any(base[j] < theta[j] for j in range(K)):
        return ('reject', 'segment_violation', base)
    if eps > Emerge_budget:
        return ('reject', 'emergent_violation', eps)
    if max(x.amb for x in nu_seq) > E_amb:
        return ('defer', 'ambiguous', suggest_min_offense(skill_seq, nu, h))
    return ('ok', base - eps)
```

### IP-124 CEN（Cloud-Edge Norm Constitution）

```python
def compile_norm_constitution(N_cloud):
    # 高严重度、物理可执行、低延迟规范下沉为边端守卫
    guards = []
    for norm in N_cloud.norms:
        if norm.severity >= SIGMA_EDGE and norm.physically_checkable \
           and norm.latency <= TAU_EDGE:
            guards.append(NormGuard(norm, check=compile_checker(norm)))
    return guards

def cloud_edge_decide(a, c, h, guards, cloud, tau_norm):
    for g in guards:                      # 边端毫秒级
        r = g.check(a, c, h)
        if r == 'veto':
            return ('veto', g.explain(), a_min_offense(c, h))
    if any(g.needs_context(c, h) for g in guards):
        ans = cloud.reason_norm(a, c, h, timeout=tau_norm)
        if ans is None:
            return ('fallback', 'timeout', a_min_offense(c, h))
        return ans
    return ('pass', None, a)
```

### IP-125 NRC（Norm Repair Controller）

```python
def norm_repair(social_signal, nu, D_norm, Pi_rep):
    breach = detect_breach(social_signal)           # 注视回避/后退/迟疑/言语
    if not breach: return D_norm, None
    sigma = nu.severity(social_signal.last_action)
    best, best_util = None, -inf
    for rep in Pi_rep:                              # 道歉/解释/退出/让位/询问/补偿
        p_ok = rep.success_prob(social_signal.context)
        util = p_ok * (1 - D_norm) - rep.cost - sigma
        if util > best_util:
            best, best_util = rep, util
    D_norm = LAMBDA * D_norm + sigma * (1 - best.success_prob())
    return D_norm, best
```

### IP-126 NTC（Norm Transfer Certificate）

```python
def norm_transfer_certificate(N_source, target_domain, beta_adapt):
    Inv, Var = N_source.split_invariant_variant(target_domain)
    violations = []
    for norm in Inv:
        if not holds(norm, target_domain):
            violations.append(('invariant_broken', norm))
    if violations:
        return ('reject', violations)
    adapted = {}
    for norm in Var:
        cost = adapt_cost(norm, target_domain)
        if cost > beta_adapt:
            return ('defer', 'adaptation_budget_exceeded', norm, cost)
        adapted[norm] = adapt(norm, target_domain)
    return ('ok', N_cert(merge(Inv, adapted), scope=target_domain))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| NGP | O(|P|·|A|·k) | O(|P|·k) | 探针覆盖陈述与动作两侧 |
| NFC | O(|D|·k + |D|log|D|) | O(|D|·k) | conformal 有效性、上下文分层 |
| NCC | O(|S|·|A|·k + |S|²·sim) | O(|S|·k) | 涌现项有界、阈值 sound |
| CEN | O(|G| + τ_norm·π_cloud) | O(|G|) | 守卫 sound、仲裁单调、超时回退 |
| NRC | O(|Π_rep|·k) | O(k) | 修复概率下界可估、债务收敛 |
| NTC | O(|N|·k) | O(|N|·k) | 不变量/变量划分正确、适配预算闭合 |

**正确性定理（Norm-Aware Embodied Deployment Soundness）**
承接第 54 轮 (A26)–(A28)；新增 **(A29)** 规范上下文覆盖 `P(c,h ∉ scope) ≤ β_C`；**(A30)** conformal 规范集具有边际覆盖 `≥ 1-α`；**(A31)** 边端守卫对高严重度规范 sound 且有 `τ_norm` 上界；**(A32)** 修复策略成功概率有可估下界 `p_rep`；**(A33)** 涌现违规满足 `ε_emerge ≤ Ε`。则部署期规范合规概率
```
P(compliant) ≥ 1 - β_C - α - P(ρ_norm < ρ_min) - P(ε_emerge > Ε)
                 - (1 - p_rep)·P(breach) - P(D_norm > D_max)
```
关键：**规范可行性先于动作可行性**，**歧义显式化而非掩盖**，**违规可修复且债务有界**。

## 6. 本轮最大风险

**一句话**：把社会规范做成动作空间上的规范场与三元证书，能把“会说规范”推进到“可验证地得体做事”，但其 soundness **根本依赖规范本身的上下文覆盖、标注者共识与文化不变量划分**；一旦规范场欠采样或把某一群体的规范误标为普适不变量，证书会以“数学上 sound”的姿态输出系统性文化偏差与排斥，故必须以 **多元规范建模 + 歧义显式延迟 + 可申诉修复** 为前置护栏，宁可承认“不知道是否得体”，也绝不把规范证书当作普适道德真值。

> 承接第 54 轮产物 v31。本轮在「动作空间 × 鲁棒性 × 云边协同」双证书体系之上，增加 **规范场、规范鸿沟、规范组合闭包、云边规范宪法、修复闭环、规范迁移** 六个算子，形成 **动作-鲁棒-规范三元证书**：

## 2. 关键算法 伪代码

### IP-121 NGP

```python
def norm_grounding_gap(policy, probes, judge):
    gaps = []
    for c, h, a, nu_decl in probes:
        nu_decl_pred = judge(policy.llm, c, h, a)          # 陈述层
        p_a = policy.action_prob(a, c, h)
        nu_real = to_norm_scale(p_a, policy.action_dist(c, h))  # 动作层
        gaps.append(abs(nu_decl_pred - nu_real))
    return mean(gaps), bootstrap_ci(gaps)

def diagnose_gap(policy, probes):
    # 定位鸿沟来源：感知缺失 / 动作不可达 / 规划未接地 / 权衡冲突
    causes = Counter()
    for c, h, a, _ in probes:
        if not policy.perceives(c, 'social_cues'): causes['perception'] += 1
        elif not policy.can_execute(a, c, h):      causes['affordance'] += 1
        elif not policy.selects(a, c, h):          causes['planning'] += 1
        else:                                      causes['tradeoff'] += 1
    return causes
```

### IP-122 NFC

```python
def calibrate_norm_field(transitions, annotators, alpha=0.1):
    nu_model = ContextualNormRegressor(dims=K)   # 上下文分层 + 多标注者
    nu_model.fit(transitions, annotators)
    calib = ConformalNormWrapper(nu_model, alpha=alpha)

    def nu(a, c, h):
        lo, hi = calib.interval(a, c, h)         # 规范歧义带
        return calib.point(a, c, h), (hi - lo)
    return nu

def min_offense_action(c, h, nu, A_cand):
    # 歧义时选择规范下界最高、严重度最低的动作
    scored = [(min(nu(a,c,h)[0]), -nu_severity(a,c,h), a) for a in A_cand]
    return max(scored)[2]
```

### IP-123 NCC

```python
def norm_checked_composition(skill_seq, nu, c, h, theta, E_amb, Emerge_budget):
    nu_seq = [nu(s, c, h) for s in skill_seq]
    base = elementwise_min([x[0] for x in nu_seq])
    amb = max(x[1] for x in nu_seq)
    eps = estimate_emergent_violation(skill_seq, c, h, nu)  # 反事实联合仿真
    if any(base[j] < theta[j] for j in range(K)):
        return ('reject', 'segment_violation', base)
    if eps > Emerge_budget:
        return ('reject', 'emergent_violation', eps)
    if amb > E_amb:
        return ('defer', 'ambiguous', min_offense_action(c, h, nu, feasible(skill_seq)))
    return ('ok', base - eps)
```

### IP-124 CEN

```python
def compile_norm_constitution(N_cloud):
    guards = []
    for norm in N_cloud.norms:
        if (norm.severity >= SIGMA_EDGE and norm.physically_checkable
                and norm.latency <= TAU_EDGE):
            guards.append(NormGuard(norm, check=compile_checker(norm)))
    return guards

def cloud_edge_decide(a, c, h, guards, cloud, tau_norm):
    for g in guards:                          # 边端毫秒级否决
        r = g.check(a, c, h)
        if r == 'veto':
            return ('veto', g.explain(), min_offense_action(c, h, g.nu, A))
    if any(g.needs_context(c, h) for g in guards):
        ans = cloud.reason_norm(a, c, h, timeout=tau_norm)
        if ans is None:
            return ('fallback', 'timeout', min_offense_action(c, h, g.nu, A))
        return ans
    return ('pass', None, a)
```

### IP-125 NRC

```python
def norm_repair(social_signal, nu, D_norm, Pi_rep):
    breach = detect_breach(social_signal)     # 注视回避/后退/迟疑/言语
    if not breach:
        return D_norm, None
    sigma = nu.severity(social_signal.last_action)
    best, best_util = None, -inf
    for rep in Pi_rep:                        # 道歉/解释/退出/让位/询问/补偿
        p_ok = rep.success_prob(social_signal.context)
        util = p_ok * (1 - D_norm) - rep.cost - sigma
        if util > best_util:
            best, best_util = rep, util
    D_norm = LAMBDA * D_norm + sigma * (1 - best.success_prob())
    return D_norm, best
```

### IP-126 NTC

```python
def norm_transfer_certificate(N_source, target_domain, beta_adapt):
    Inv, Var = N_source.split_invariant_variant(target_domain)
    broken = [n for n in Inv if not holds(n, target_domain)]
    if broken:
        return ('reject', 'invariant_broken', broken)
    adapted = {}
    for norm in Var:
        cost = adapt_cost(norm, target_domain)
        if cost > beta_adapt:
            return ('defer', 'adaptation_budget_exceeded', norm, cost)
        adapted[norm] = adapt(norm, target_domain)
    return ('ok', N_cert(merge(Inv, adapted), scope=target_domain))
```

def tri_joint_certificate(skill_seq, gamma_ce, nu, delta_a_budget, rho_min, D_norm):
    J = joint_certificate(skill_seq, gamma_ce, delta_a_budget, rho_min)  # 第 54 轮

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| NGP | O(|P|·|A|·k) | O(|P|·k) | 探针双侧覆盖，鸿沟可置信估计 |
| NFC | O(|D|·k + |D|log|D|) | O(|D|·k) | conformal 边际覆盖 ≥ 1-α |
| NCC | O(|S|·|A|·k + |S|²·sim) | O(|S|·k) | 涌现项有界，序列规范闭包 sound |
| CEN | O(|G| + τ_norm·π_cloud) | O(|G|) | 守卫 sound，仲裁单调，超时回退 |
| NRC | O(|Π_rep|·k) | O(k) | 修复概率下界可估，`D_norm` 收敛 |
| NTC | O(|N|·k) | O(|N|·k) | `Inv/Var` 划分正确，适配预算闭合 |

**正确性定理（Norm-Aware Embodied Deployment Soundness）**
承接第 54 轮 (A26)-(A28)；新增 **(A29)** 上下文覆盖 `P(c,h∉scope)≤β_C`；**(A30)** conformal 覆盖 `≥1-α`；**(A31)** 边端守卫对高严重度规范 sound 且延迟 `≤τ_norm`；**(A32)** 修复成功率下界 `p_rep`；**(A33)** `ε_emerge ≤ Ε`。则
```
P(compliant) ≥ 1 - β_C - α - P(ρ_norm < ρ_min) - P(ε_emerge > Ε)
                 - (1-p_rep)·P(breach) - P(D_norm > D_max)
```
关键：**规范可行性先于动作可行性**，**歧义显式化**，**违规可修复且债务有界**。

## 5. 本轮最大风险

**一句话**：把社会规范做成动作空间上的规范场与三元证书，能把“会说规范”推进到“可验证地得体做事”，但其 soundness **根本依赖规范本身的上下文覆盖、标注者共识与文化不变量划分**；一旦规范场欠采样或把某一群体的规范误标为普适不变量，证书会以“数学上 sound”的姿态输出系统性文化偏差与排斥，故必须以 **多元规范建模 + 歧义显式延迟 + 可申诉修复** 为前置护栏，宁可承认“不知道是否得体”，也绝不把规范证书当作普适道德真值。
