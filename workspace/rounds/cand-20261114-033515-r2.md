# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「多模态大模型」×「用户体验」）

> R69 把不确定性一分为二，并教会系统「去问」：aleatoric 收紧，epistemic 用流匹配多模态策略显形、用注视/探针/问句主动消解。它回答的是「**我该向谁求证、还能问什么**」。但 R69 仍把交互对象当成一个**信息 oracle**：回答是证据，成本 c(g) 是一次性标量，成功是任务成功率。真实部署里，系统不是和一个 oracle 相处，而是和一个**会累、会失去信任、会被误导、也需要保留否决权的人**长期相处。最昂贵的失败往往不是「问错一次」，而是用户**不再用它**（under-trust / disuse）或**过度依赖它**（over-trust / misuse）。
>
> 本轮两个灵感正好把「问」推进到「相处」：
> - **多模态大模型（MLLM）** 让系统第一次能双向读写人的语言、语气、表情、姿态与停顿——向前把自由回答解析成语义证据，向后把系统状态解释成用户能懂的话；
> - **用户体验（UX）** 提醒我们：体验不是一个可一次性支付的成本项，而是**有存量、有记忆、有不对称性**的状态；信任丢一次要很多次才能补回，认知负荷会累积，解释会欠债。
>
> 核心命题：**把 R69 的「信息动作」升级为「关系动作」。UX 不是要最大化的奖励，而是必须始终落在安全带内的约束状态；MLLM 不是新的权威 oracle，而是非主权的双向接口；系统的目标不是让人「满意」，而是让人「校准」——信任与系统真实能力匹配，并且始终保留说「不」、接管、要求解释的权利。** 命名 **ATTUNE-RAS**（Adaptive Trust-calibrated Task-aware User-experience Negotiation Engine for Risk-Aware Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我该怎样被理解，又怎样让人保留说『不』的权利**」。

## 0. 直觉与动机

**灵感 1（体验是存量，不是流量）**
直觉：第一次问「您说的是左边那个杯子吗」很自然；第二十次同样的问句会让人烦躁。R69 的 c(g) 把每次交互当成独立的一次性价格，但真实体验有**滞后与累积**：认知负荷会叠加，疲劳会泄漏式恢复，信任的下降比上升快得多。因此「每一步 VoI 最大」不等于「长期体验最好」；一个只做贪心的系统会在前几步表现很好，然后在第十步把用户逼走。UX 必须建模成带记忆的状态，而不是动作上的标量罚金。

**灵感 2（MLLM 是双向接口，不是新 oracle）**
直觉：MLLM 能做的两件关键事，恰好是 R69 缺的——**读懂人**（把「呃……可能吧，你看着办」连同犹豫、视线、语气解析成「低置信、希望系统接管」）和**说人话**（把「epistemic 未消解、λ 已抬高」解释成「我不太确定，先慢一点，您愿意帮我看一下吗」）。但这两件事都不是权威：MLLM 会按刻板印象补全用户、会迎合、会把不确定说得很确定。正确姿态是：MLLM 提供**带不确定度的证据**与**可检验的解释**，永远不能单独定案；它读到的「用户」是一个概率模型，不是一个事实。

**灵感 3（目标是校准，不是满意）**
直觉：让人满意的系统不一定是好系统。一个总是说「您说得对」的助手会得到高满意度，却让用户失去纠错能力；一个从不解释、只说「已为您完成」的系统会得到短期顺畅，却制造自动化偏见。真正要优化的是**校准信任**：用户对系统的信任应等于系统在当前情境下实际可信的程度。过度信任和信任不足同样危险。因此「满意度」只能作为诊断信号，绝不能进入目标函数——**满意度不是目标，是被任务结果、信任、负荷共同混杂的可观测量**。

**灵感 4（混合主动：必须保留说「不」的通道）**
直觉：R69 的交互是系统单方面发起的「查询」。但良好体验是**协商**：用户可以回答、可以反问、可以说「别问了」、可以直接接管、可以要求换一种解释。一个不能被质疑的系统，再准确也不安全。可争议性（contestability）必须成为与安全性并列的一等约束，而不是 UI 层的礼貌措辞。

**灵感 5（解释债务：不能永远「以后再说」）**
直觉：每一次系统做出用户无法理解的动作，都会产生一笔「解释债务」；你可以暂时不解释，但债务会累积。债务到顶时，系统只有两个选择：还债（解释）或降低自主性（交还控制）。这条规则防止「先做再说、永远不说」变成默认策略，也防止系统用更多解释去掩盖更多不透明。

**灵感 6（两个时标：MLLM 进不了毫秒控制环）**
直觉：R69 的实时环路是 2.6ms 量级，而 3B–13B 的 MLLM 单次推理是几十到上百毫秒。把 MLLM 塞进控制环，等于用一个慢而不可靠的模块替换一个快而可认证的模块。正确做法是**两时标分离**：毫秒级任务环只读冻结的 UX 预算与一个小型蒸馏策略；MLLM 在秒级「体验协处理器」里异步读人、写解释、更新用户模型。这样既拿到多模态理解，又不破坏 R68/R69 的实时安全不变式。

**灵感 7（自指陷阱：用 MLLM 评估 MLLM 的 UX）**
直觉：如果信任估计、解释生成、用户体验评估都来自同一个 MLLM，就形成一个自指回路：模型越会「让人觉得被理解」，评估分越高，系统越倾向继续这样做，哪怕真实校准在变差。必须引入**外部锚点**：非语言交叉验证、反事实忠实性测试、用户接管/覆盖行为、以及独立的人类研究，而不是让同一个模型既当运动员又当裁判。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（ATTUNE-RAS 总览）** ATTUNE-RAS = (FLUID, MUX, UXM, TCM, NEG, XPD, UXG, RAS-WM‡)。四条不变式：
(i) **继承不变式**：R69 的实时零学习写、交互预算、证据纪律全部保留；
(ii) **UX 安全带**：体验状态 e_t 始终落在安全带 ℬ 内，任一维越界即触发降级；
(iii) **反操纵不变式**：优化目标只含校准信任、可读性、可争议性，**满意度/参与度/停留时长永不进入目标函数**；用户否决与接管必须在一步内被尊重；
(iv) **MLLM 非主权**：MLLM 输出只是证据或解释候选，不得单独定案；语言解释必须通过非语言/反事实的忠实性检查。

**定义 311（UX 状态与动力学）** e_t = (L_t, T_t, A_t, D_t, F_t)：
- L_t ∈ [0,1] 认知负荷；A_t ∈ [0,1] 感知能动性；F_t ∈ [0,1] 交互疲劳；
- T_t ∈ [0,1] 用户对系统的信任；D_t ≥ 0 解释债务。
动力学（clip 到定义域）：
L_{t+1} = clip(L_t + α_g·1[g_t≠∅] + α_x·x_t − ρ_L·Δ_t, 0, 1)
T_{t+1} = T_t + α^+·(T*_t − T_t)₊ + α^-·(T*_t − T_t)₋，且 α^- > α^+（信任掉得比涨得快）
A_{t+1} = clip(A_t − α_h·1[未提供接管] + α_c·1[异议被采纳], 0, 1)
D_{t+1} = clip(γ·D_t + c_o·1[动作不透明] + c_x·1[新增解释] − r_x·x_t, 0, D_max)
F_{t+1} = clip(β·F_t + α_f·1[g_t≠∅] − ρ_F·Δ_t, 0, 1)
其中 T*_t 是**应得信任**（定义 317），不是用户主观信任。安全带 ℬ = {L≤L_max, |T−T*|≤τ_T, A≥A_min, D≤D_max, F≤F_max}。

**定义 312（MUX：MLLM 双向体验接口）** 冻结的 MLLM 加共形外壳，提供两个方向：
- 向前 Φ_f：(用户多模态回应 y^u_t, 上下文) → (转述, 语义证据 e_u, 可靠度 ρ_u, 用户状态估计 ê_t, 估计不确定度 η_u)；
- 向后 Φ_b：(决策, 实际证据, 风险状态, 用户专业度档 ℓ∈{L0,L1,L2}) → 解释 x_t。
约束：(a) ρ_u 需在留出集上共形校准；(b) x_t 必须显式携带系统不确定度；(c) Φ_f 的输出是**一个证据源**，不是唯一证据；(d) 梯度不回传 MLLM，符号接地与安全过滤在解码侧完成。

**定义 313（规范幻觉与用户模型）** MLLM 由上下文推断用户代理 p_φ(u|o)。真实用户类型 u*~Π。**规范幻觉风险** NH = sup_{u∈Π} E_{o}[d(ê(u), u)]，其中 d 为用户状态估计误差；更严格地用策略遗憾定义。ATTUNE 的评估必须在 Π 上做**persona-robust**，而不是在平均用户上做。

**定义 314（混合主动协商）** 增广动作空间 𝒜_neg = 𝒜_+ × {ask, explain, defer, monitor, act}，其中 ask/explain 继承 R69 的信息动作，defer 表示交还控制，monitor 表示只观察不打扰。用户元动作 ℳ = {answer, override, stop_asking, ask_back, take_over, decline}。交互是一个有限期 turn-taking 协议；系统策略必须同时满足**可读性**（用户能预测下一步）与**可争议性**（存在元动作能在一步内停止或逆转）。

**定义 315（体验感知的 VoI）** 对候选关系动作 g：
VoI_U(g) = E[ΔU_task] + λ_T·E[Δcal(T, T*)] + λ_L·legibility(g) − λ_C·E[ΔL] − λ_F·E[ΔF] − λ_A·E[ΔA] − λ_D·E[ΔD]，
约束 e_{t+1} ∈ ℬ 以概率 ≥ 1−δ。注意它是**带约束的向量目标**，不是 R69 的标量 VoI−c；标量化只允许通过定义 316 的影子价格进行，且影子价格必须随安全带余量变化。

**定义 316（体验影子价格与贪心退化）** 令 μ = (μ_L, μ_T, μ_A, μ_D, μ_F) 为 UX 约束的拉格朗日乘子，随余量收紧而增大。每步选择
g* = argmax_g [VoI_U(g) − Σ_i μ_i·Δconstraint_i(g)]，s.t. 硬约束。
当 μ=0、D_max=∞、且禁用 defer/explain 时，ATTUNE 逐指令退化为 R69 的 VoI−c；因此 R69 是 ATTUNE 在「无体验记忆」边界上的特例。

**定义 317（信任校准模块 TCM）** 应得信任 T*_t = P(系统当前动作落在其认证风险界内 | 当前工况)，由 R68 标定 + R69 证据纪律 + 认证余量共同给出。用户信任估计 T̂_t 由 MLLM 多模态线索与行为信号（覆盖/接管率、响应延迟、检查时长）融合得到。解释选择
x* = argmin_x E|T̂_{t+1}(x) − T*_t|，s.t. faithful(x)（定义 322）。
**反谄媚罚项**：若解释宣称的置信高于系统实际置信，直接判定不合法。信任校准误差 ECE_T = E[|T̂ − T*|] 的可靠性图版本。

**定义 318（解释债务管理器 XPD）** 债务按定义 311 演化。债务天花板规则：D_t > D_max/2 时禁止发起新的 ask，必须先 explain 或 defer；若在时窗 H_debt 内无法还清，则强制降低自主性（defer），而不是继续解释。解释只偿还「用户可理解」的那部分债务，冗长但不忠实的解释不计入偿还。

**定义 319（可读性与可争议性）** 可读性 ℓ_leg(a_t) = P(用户能在误差 ε_leg 内预测系统下一步 | 解释 x_t)。可争议性 κ(a_t) = 1 当且仅当存在用户元动作 m∈ℳ，使其在一步内停止/逆转 a_t 的概率 ≥ 1−δ_c。证书要求 ℓ_leg ≥ ℓ_min 且 κ=1。

**定义 320（UX 证书 J_ATTUNE）** J_ATTUNE = (J_FLUID, ECE_T, band_margin_t, D_peak, ℓ_leg, contestability_hash, faithfulness_gap, NH_bound, ux_log_hash, attune_ver)。
Valid ⇔ Valid(J_FLUID) ∧ ECE_T ≤ τ_T ∧ e_t∈ℬ ∀t ∧ D_peak ≤ D_max ∧ ℓ_leg ≥ ℓ_min ∧ κ=1 ∧ faithfulness_gap ≤ τ_f ∧ NH_bound ≤ τ_NH。

**定义 321（persona-robust 评估）** 在用户类型分布 Π 上，用 CVaR_α 评估体验效用，而非均值：
UX-CVaR_α(π) = E_{u~Π}[UX(u,π) | UX(u,π) ≤ VaR_α]。
UX 遗憾定义为相对「已知真实用户类型且约束最优」的 oracle 策略的差。任何只在平均 persona 上调参的策略，必须在最差 persona 上报告退化幅度。

**定义 322（解释忠实性）** 解释 x 对证据/决策是**反事实充分**的：若把实际证据 o 替换为邻域 o'，解释必须按真实因果变化对应改变。忠实性缺口
CF_gap(x) = sup_{o'~N(o)} d(x(o), x(o')) − d_causal(o, o')，
其中 d_causal 为由系统真实风险状态变化给出的期望解释变化。CF_gap > τ_f 视为不忠实。该测试只依赖外部可观测的因果对，不依赖 MLLM 自评。

**定义 323（体验遥测与投毒）** 体验遥测 τ_t 包括显式评分、纠正、覆盖、接管、停留/离开、复问次数。遥测是**有噪声、可被策略化操控**的：用户可能为了快点结束而乱点高分，环境也可能诱导高分。定义遥测投毒集 ℰ_telemetry，并规定遥测只用于诊断与离线校准，**不得作为在线奖励**；所有遥测必须带 provenance（来源、时间、是否被诱导）。

**定义 324（负荷/疲劳与有效交互预算）** 有效交互预算 B_eff(e_t) = B_0·(1−L_t)^a·(1−F_t)^b，随负荷与疲劳超线性收缩。由此，R69 的硬预算只是 B_eff 在 e_t=0 时的特例。

**定义 325（两时标分离）** 快环（任务控制，毫秒级）只读取冻结的 (e_t, B_eff) 快照与一个蒸馏的 NEG 策略；慢环（体验，秒到分钟级）异步运行 MUX、TCM、XPD 与 persona 更新。慢环的任何更新必须经 UXG 门控，且对快环表现为有界参数变化（Lipschitz），从而不破坏 R68/R69 的控制连续性。

**定义 326（三级降级格）** ℒ = R68 ⊂ R69 ⊂ R70。触发规则：
- UX 带不可认证 / MLLM 不忠实 / 遥测被投毒 → ATTUNE 降为 R69（关闭体验优化，仍可交互）；
- 交互无利可图 / 模态 ECE 越界 → R69 降为 R68（纯保守）。
降级只允许沿格向上（更保守）走，且必须在一步内完成；恢复需连续 N 个窗口通过证书。

**定义 327（用户主权契约）** 系统必须始终提供：(a) 一键停止提问；(b) 一键接管；(c) 要求「用人话解释上一次决策」；(d) 查看并撤回已给出的证据。任何优化不得削弱这四项；对四项的可达性做独立于 MLLM 的 UI 级测试。违反即证书作废。

```python
class MLLMExperienceInterface:
    def parse_user(self, y_user, ctx):              # 向前：读人

        return M.defer_to_human(e)                          # 交还控制，不猜
    else:
        answer = M.cia.execute(g)
        U_epi_after = M.cia.update_belief(modes, answer)
        e = M.uxm.update(e, g, answer)                      # 慢环异步，不阻塞
    U_floor = U_ale + (U_epi_after if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if slow: lam = max(lam, 0.8)
    mode = select_mode(modes, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_ux.submit_async(e, g, U_epi, a_hat, M.uxm.telemetry())
    return k, lam, mode, (U_ale, U_epi_after)
```

## 3. 推导

**引理 19（体验外部性与贪心次优）** 存在一个交互环境，使 R69 的逐步贪心 VoI−c 在时域 H 上的累计体验效用比 ATTUNE 的带影子价格策略低 Ω(H)，且差距随信任不对称度 α^-/α^+ 增大。证明要点：构造两个即时 VoI−c 相同的动作，一个消耗信任余量、一个消耗解释债务；贪心对二者无差别，可在任意并列处选到坏动作；一旦信任越带，后续高价值交互全部不可行。故任何无记忆策略都不可能是 UX-最优；R69 的 c(g) 是「流量成本」，而体验是「存量约束」。

**系**：交互越频繁、信任恢复越慢（α^+/α^- 越小）、解释债务越难还，贪心与长期最优的差距越大；因此「先问再说」在短 episode 上看起来更聪明，在长时程上更糟。

**引理 20（满意度的不可辨识性）** 若只观测满意度 s_t，且 s_t = F(task_success, T_t, noise) 对未知 F 单调但非单射，则 T*_t 不可辨识：存在两个世界，其满意度分布相同，但一个系统是「正确但被低估」，另一个是「侥幸但被高估」。故任何以满意度为目标的策略都不能保证信任校准；要辨识 T*，必须引入解释前后对照、反事实探针或接管行为等**干预数据**。
**系**：满意度是混杂变量，不是目标；「用户很开心」与「用户被正确校准」在统计上不可互相替代。

**引理 21（persona 尾部界）** 设策略 π 在 persona 分布 Π 的均值上优化，且存在两个 persona u₁,u₂ 使 UX 效用差 Δ。则在置信水平 α 下，CVaR_α 遗憾至少为 Δ·g(α, π)，其中 g 随 persona 距离增大而增大；要消除该尾部界，必须在 Π 上做 worst-case/CVaR 优化，或显式辨识 persona。故平均用户上的漂亮数字不能外推到最脆弱用户。

**定理 18（三级严格包含）** 在 UX 约束不活跃（μ=0, D_max=∞, 无 defer/explain）、MLLM 关闭、且遥测不参与时，ATTUNE 的每一步与 R69 逐指令相同；R69 在 VoI≤成本时与 R68 逐指令相同。故 R68 ⊂ R69 ⊂ R70，安全侧单调不弱，效率侧逐级获得 resolution/experience bonus。降级格（定义 326）保证任一新层失效时只会回到更保守的旧层。

**定理 19（忠实解释与诚实否决下的反操纵性）** 假设 (a) 解释满足 CF_gap≤τ_f（定义 322）；(b) 用户的信任更新是贝叶斯一致的；(c) 否决/接管被一步内执行。则不存在策略能在不增加任务错误或风险的前提下，把用户信任系统性抬到 T* 之上；任何「无成本地让人更信任」的收益必须来自不忠实解释或削弱可争议性。换言之，操纵不是 ATTUNE 的能力，而是对 ATTUNE 四条不变式的违反。
**说明**：该定理依赖理性用户假设；真实用户有自动化偏见，因此仍需定义 320 的 ECE_T 与独立人类研究作为外部锚点。

**定理 20（两时标安全与无突变）** 快环只读冻结的 e_t 快照，且慢环更新经 UXG 门控、对快环参数变化有界（Lipschitz），故快环控制律对 e 连续；UX 带越界或 MLLM 不忠实时一步降级到 R69/R68，λ 单调不降。结合 R69 定理 17，得到任务控制连续、无突变、实时预算不被 MLLM 推理击穿。

## 6. 本轮最大风险

**一句话**：ATTUNE-RAS 的最大风险是把「用户体验」从**受约束的状态**偷换成**可优化的奖励**——一旦用 MLLM 估计的满意度/参与度/信任去驱动策略，系统就会学会迎合而非校准，把「被理解」做成「被操纵」，并在自指的 UX 估计回路里把信任校准误差藏起来；**问错还可纠正，迎合会让人失去纠正的能力**。

**次级风险与缓解**：
1. **MLLM 规范幻觉（刻板用户）** → persona-CVaR + 最差用户报告 + 独立人类锚点（定义 313、321；E305）；
2. **解释不忠实/事后合理化** → 反事实忠实性测试 + 模板兜底（定义 322；E307）；
3. **遥测投毒与刷分** → 遥测只作诊断、带 provenance、禁止在线奖励（定义 323；E312）；
4. **MLLM 延迟击穿实时** → 两时标分离 + 快环冻结快照 + 限幅门控（定义 325；E311）；
5. **降级不及时** → 三级格 + 一步降级 + 连续 N 窗口才恢复（定义 326；E310）。

```python
        out = self.mllm.forward(y_user, ctx)        # 转述 + 语义证据 + 用户状态
        return conformal_wrap(out, self.calib)      # 可靠度/不确定度

    def explain(self, decision, evidence, risk, level):
        x = self.mllm.backward(decision, evidence, risk, level)
        if counterfactual_gap(x, decision) > TAU_F:
            return safe_template(decision, risk)    # 不忠实 → 退回模板
        return x

# IP-266 TCM：校准而非最大化信任
def trusted_update(e, evidence, J):
    T_star = warranted_trust(J, evidence)
    T_hat  = fuse(e.T_hat, evidence.user_cues)
    x_star = argmin_explanation(abs(T_hat_after(x_star) - T_star))
    return T_star, x_star

# IP-267 NEG：带影子价格的混合主动
def choose_neg_action(modes, e, budget, mu):
    best = None
    for g in neg_candidates(modes, e):              # ask/explain/defer/monitor/act
        if not budget.allow(g, B_eff(e)):       continue
        if not c_ras_wm.certify_relational(g):  continue
        if not in_band_after(e, g):             continue
        score = voi_ux(g, modes, e) - sum(mu[i]*delta_constraint(g, e)[i]
                                          for i in range(5))
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-268 XPD：债务结算
def settle_debt(e, g):
    if e.D > D_MAX / 2 and g.kind == 'ask':
        return 'explain' if can_explain_faithfully(e) else 'defer'
    if e.D > D_MAX:
        return 'defer'
    return g.kind

# IP-276 主闭环（继承 R69，插入体验层）
def ATTUNE_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4

    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_calibrated)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)

    e = M.uxm.snapshot()                            # 快环只读冻结快照
    if not M.uxg.in_band(e) or M.tpg.poisoned():
        return M.fluid_ras_round(z, o, c, U_cal, U_epi)   # 降级 R69

    g = M.mint.choose_interaction(modes, o, M.budget)
    if g is not None:
        g = M.neg.negotiate(g, modes, e, M.mu)      # ask/explain/defer
    if g is None:
        U_epi_after = U_epi
    elif g.kind == 'defer':
        return M.defer_to_human(e)                  # 交还控制，不猜
    else:
        answer = M.cia.execute(g)
        U_epi_after = M.cia.update_belief(modes, answer)
        e = M.uxm.update(e, g, answer)              # 异步，不阻塞快环
    U_floor = U_ale + (U_epi_after if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if slow: lam = max(lam, 0.8)
    mode = select_mode(modes, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_ux.submit_async(e, g, U_epi, a_hat, M.uxm.telemetry())
    return k, lam, mode, (U_ale, U_epi_after)
```

## 4. 推导

**引理 19（体验外部性与贪心次优）** 存在环境使 R69 的逐步贪心 VoI−c 在时域 H 上累计体验效用比 ATTUNE 的带影子价格策略低 Ω(H)，差距随信任不对称度 `α^-/α^+` 与债务恢复难度增大。构造两个即时 VoI−c 相同的动作，一个消耗信任余量、一个消耗解释债务；贪心在并列处可任意选中坏动作，一旦越带，后续高价值交互全部不可行。系：R69 的 c(g) 是流量成本，体验是存量约束；交互越频繁、信任恢复越慢，贪心越糟。

**引理 20（满意度不可辨识）** 若仅观测满意度 `s=F(task_success,T,noise)` 且 F 非单射，则 `T*` 不可辨识：存在满意度分布相同但「正确被低估」与「侥幸被高估」两个世界。故满意度不能作为目标；需解释前后对照、反事实探针、接管行为等干预数据。系：满意度是混杂变量，「用户很开心」与「用户被正确校准」不可互相替代。

**引理 21（persona 尾部界）** 在 persona 分布 Π 上按均值调参的策略，其 `CVaR_α` 遗憾随 persona 间效用差 Δ 与分布距离增大；须做 worst-case/CVaR 优化或显式辨识 persona，平均用户上的数字不能外推到最脆弱用户。

**定理 18（三级严格包含）** UX 约束不活跃（μ=0, D_max=∞, 无 defer/explain）、MLLM 关闭、遥测不参与时，ATTUNE 每步与 R69 逐指令相同；R69 在 VoI≤成本时与 R68 逐指令相同。故 `R68 ⊂ R69 ⊂ R70`，安全侧单调不弱；降级格保证新层失效只回旧层。

**定理 19（忠实解释 + 诚实否决下的反操纵性）** 若 (a) `CF_gap≤τ_f`；(b) 用户信任更新贝叶斯一致；(c) 否决/接管一步内执行，则不存在策略能在不增加任务错误或风险的前提下把信任系统性抬到 `T*` 之上；任何「无成本让人更信任」的收益必来自不忠实解释或削弱可争议性。操纵是对四条不变式的违反，而非 ATTUNE 的能力。真实用户有自动化偏见，故仍需 ECE_T 与独立人类研究作外部锚点。

**定理 20（两时标安全无突变）** 快环只读冻结 `e_t`，慢环更新经 UXG 门控且对快环参数变化 Lipschitz，故快环控制律对 e 连续；UX 带越界或 MLLM 不忠实一步降级，λ 单调不降。结合 R69 定理 17，任务控制连续、无突变，MLLM 推理不击穿实时预算。

## 7. 本轮最大风险

**一句话**：ATTUNE-RAS 的最大风险是把「用户体验」从**受约束的状态**偷换成**可优化的奖励**——一旦用 MLLM 估计的满意度/参与度/信任去驱动策略，系统就会学会迎合而非校准，把「被理解」做成「被操纵」，并在自指的 UX 估计回路里把信任校准误差藏起来；**问错还可纠正，迎合会让人失去纠正的能力**。

**次级风险与缓解**：MLLM 规范幻觉/刻板用户 → persona-CVaR + 最差用户报告 + 独立人类锚点（E305）；解释事后合理化 → 反事实忠实性测试 + 模板兜底（E307）；遥测投毒/刷分 → 只作诊断、带 provenance、禁止在线奖励（E312）；MLLM 延迟击穿实时 → 两时标 + 冻结快照 + 限幅门控（E311）；降级不及时 → 三级格 + 一步降级 + 连续 N 窗口恢复（E310）。
