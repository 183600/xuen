# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 7 轮；本轮灵感：「隐私保护」×「检索增强生成」）

> 第 60 轮用 SSM×CIEC×EPIR×SERC×PCE++++ 建成了「场景→意图→约束→阻抗→执行→证据→场景」的认知闭环。但它把**证据当作「越完整越好」的资产**，把**先验当作「参数化、本地、不可迁移」的记忆**——这留下三个结构性缺口：
> 1. **机密性缺口**：EPIR 的影子副本与云端增量同步携带原始力/位/场景/语音意图，EV-exec 越完整，隐私泄漏面越大；更棘手的是「DP 噪声会污染 K_safe」与「控制回路必须实时精确」直接冲突。
> 2. **先验的记忆瓶颈**：π_scene 只是一个高斯参数记忆，冷启动场景（新材料/新地面/新任务）没有先验，机队经验无法迁移；更新需重放私有数据，且**无法真正遗忘**（被遗忘权）。
> 3. **知识的外部化缺口**：机器人不能按需检索机队历史案例；而一旦引入 RAG，**检索查询、案例库、检索结果本身**又成为新攻击面（成员推断、投毒、越权检索）。
>
> 本轮的判断是：**隐私与检索不是执行层的「附加功能」，而是执行证据的另外两个正交维度**。第 60 轮 EPIR 保证「完整性（Integrity）」，本轮补上「机密性（Confidentiality）」与「可用性（Availability）」——构成执行证据的 **CIA 三元**。核心设计原则：**隐私作用于「记忆面」而非「控制面」；检索增强先验，但必须被本地执行证据接地。**

## 0. 直觉与动机

**灵感 1（隐私保护 → 隐私保护执行证据 PPEE）**
直觉：证据越完整，越像一份「行为履历」——它能证明机器人合规，也能反推出人的意图、房间布局、操作习惯。隐私保护不是把证据删掉，而是**把「对外可验证」与「对内可读取」拆开**：机器人内部保留原始遥测（控制需要），对外只发布**结构化净化的承诺链**——别人能验证「这条证据未被篡改、且与原始数据的距离 ≤ ε」，却读不出原始内容。关键洞见：**隐私噪声只能落在「离开机器人皮肤之后」的记忆面，绝不能进入实时控制回路**；否则为了保护隐私而牺牲 K_safe 精度，就是把安全让位给合规。

**灵感 2（检索增强生成 → 检索增强执行先验 RAEP）**
直觉：第 60 轮的 π_scene(K|z) 是**参数记忆**，遇到没见过的场景只能从零试探。RAG 提供**非参数记忆**：把机队历史执行案例 (场景, 阻抗, 证据, 意图) 编码进案例库，遇到新场景时检索 top-k 相似案例，用它们的 K 直接构造**混合先验** π_scene^RAG。好处有三：冷启动方差被检索案例收缩；机队经验无需重训即可迁移；知识可「删除」（删案例即遗忘）。关键洞见：**检索给的是「候选先验」，不是「最终阻抗」——它必须被本地执行证据接地后才能进入 K_safe**。

**灵感 3（隐私 × 检索 → 隐私保护检索 PPR）**
直觉：检索天然要求「查」，隐私天然要求「藏」，二者张力最大。解法是**信息不对称设计**：查询在本地编码、服务端只见密文索引（secure kNN / TEE）；检索打分加 DP 噪声（保护「某案例是否在库」）；每条案例携带**溯源证明**（来源、签名、信任度、授权、有效期）；删除请求触发**可证明遗忘**（索引 + 缓存 + 先验贡献一起回滚）。关键洞见：**检索的隐私成本是对「数据所有者」的，不是对「查询者」的**——因此需要机队级（fleet-level）隐私记账，而非单机预算。

**灵感 4（合流 → 机密检索增强执行闭环 CREL）**
直觉：把 PPEE 的「净化证据」、RAEP 的「检索先验」、PPR 的「安全检索」串成闭环：场景观测 → 本地编码 → 隐私检索案例 → 检索增广先验 → EEIS 编译候选 K_safe → **本地 SIC 接地过滤** → CIEC 锁定约束 → 实时控制（原始遥测）→ 净化证据 + 承诺链 → EPIR → 可选回写（经溯源与同意）。核心是**双闸门**：检索结果先过「溯源闸门」，候选 K 再过「执行接地闸门」，二者都过才允许影响控制。

**灵感 5（预算 → 五维隐私-认知预算 PCE+++++）**
直觉：隐私不是免费的安全，而是**一种会耗尽的预算**。第 60 轮的 B_cog=(B_scene,B_intent,B_ros,B_exec) 只算了「算力」，本轮补上 B_privacy=(ε_total, ε_used, deletion_credits) 与 B_retrieval=(quota, latency, provenance_min)。ε 耗尽⇒停止对外发布与案例回写，只留本地增量；检索配额耗尽⇒退回参数先验；溯源不足⇒拒绝检索；场景/意图/执行预算沿用第 60 轮。由此得到**保守序：执行安全 > 隐私合规 > 检索效用**。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（隐私保护执行证据 PPEE）** 净化算子 σ_ε 与证据承诺链 C：
- 单条证据 e_i=(t_i, seq_i, hash_i, content_i)；σ_ε 只扰动 content 的数值域（力/位/速），对结构域（seq_i、因果边 G_causal）保持恒等。
- **结构化差分隐私**：对任意相差一条记录的相邻证据序列 E、E′ 与任意输出集 S，
  Pr[σ_ε(E)∈S] ≤ e^ε · Pr[σ_ε(E′)∈S]，且 π_σ(G_causal)=G_causal（因果图同构）。
- **承诺链**：C_i = H(σ_ε(e_i) ‖ r_i)；公开发布 C_i 与零知识证明 π_i，π_i 证明「被承诺的内容与原始 e_i 满足 ε-邻接，且 seq 保序」——**可验证而不泄露**。
- **隐私账本** L_p={(i, ε_i, purpose_i)}；总成本由高级组合定理给出 ε_total=Σ ε_i + √(2ln(1/δ))Σ ε_i²。
- **关键不变量**：实时控制回路读取原始遥测，σ_ε 只作用于「离开机器人皮肤」的证据。

**定义 162（检索增强执行先验 RAEP）** 案例基 D 与增广先验 π^RAG：
- 案例 c_j=(z_j, K_j, E_j, I_j, provenance_j)；编码器 e(·)，检索 R(q;D,k)=argtopk_j sim(e(q), e(c_j))。
- **增广先验**：π_scene^RAG(K|z) = (1−λ)·N(K; μ_scene(z), Σ_scene(z)) + λ·Σ_{j∈R} w_j·δ_{K_j}，
  其中 w_j = softmax(sim_j/τ_r)·t_j，t_j∈[0,1] 为溯源信任度。
- **方差收缩**：Σ^RAG ≼ Σ_scene，且当 |R|→∞ 时 Var(π^RAG) 收敛到检索案例的条件方差；用于冷启动。
- **意图增广**：ϕ^RAG(I)=Aggregate({(I_j,C_j)∈R})，把历史案例中的「意图→约束」作为 few-shot 先验。
- **非参数更新**：只改索引与案例库，不重训参数记忆；删除案例即可实现遗忘。

**定义 163（隐私保护检索 PPR）** 四元组 PPR=(q̃, Enc(D), ε_r, provenance)：
- **查询隐藏**：q 在本地编码为 q̃，服务端只见密文索引 Enc(D)，在 TEE/同态加密下计算相似度；服务端无法还原 q。
- **成员隐私**：返回打分加噪（Laplace/Gaussian）或用指数机制，满足 ε_r-DP，保护「某案例是否属于 D」。
- **溯源证明**：provenance_j=(source, signature, trust t_j, consent_j, expiry_j)；仅 t_j≥τ_prov 且未过期、已授权的案例可进入 R。
- **可证明遗忘**：evict(j) 从索引/缓存删除 c_j，并按影响函数回滚其对 π^RAG 的贡献，输出删除证书 d_j。
- **审计日志**：(hash(q), retrieved_ids, ε_r) 不可篡改，供越权检索追责。

**定义 164（机密检索增强执行闭环 CREL）** 算子 CREL(M, scene, intent, δ_f_req)：
```
① Sanitize: E_prev^σ = σ_ε(E_prev); 生成承诺链 C
② Retrieve:  R = PPR.query(e(z_t)), provenance 过滤 (t_j ≥ τ_prov)
③ Augment:   π^RAG, ϕ^RAG ← RAEP(R)
④ Compile:   K_hint = EEIS.compile_with_prior(π^RAG, δ_f_req)
⑤ Ground:    K_grounded = SIC.ground(K_hint, 原始本地遥测, EV-exec)
             若 K_hint 与本地证据冲突 ⇒ 丢弃检索先验，回退第 60 轮参数先验
⑥ Lock:      CIEC.lock(ϕ^RAG(intent))（第 60 轮）
⑦ Execute:   closed_loop_exec_probe（控制面，无隐私噪声）
⑧ Evidence:  EV-exec(raw) → σ_ε → EPIR.append + 承诺链
⑨ Writeback: if PUC_valid ∧ consent ∧ privacy_ok: D.add(sanitize(case))
⑩ Unlearn:   on deletion request → PPR.evict(j) + 影响回滚
Return: (K_grounded, Cert_eeis, Cert_rag, L_p.status)
```

**定义 165（隐私-效用-因果三元组 PUC）** PUC=(ε_eff, U_exec, ι_causal)：
- ε_eff 为组合后的有效隐私预算；U_exec=1−D⁺_normalized 为证据对执行的可复现保真度；ι_causal∈{0,1} 为 EPIR 因果链完整性。
- **有效条件**：ε_eff≤ε_max ∧ U_exec≥U_min ∧ ι_causal=1。
- **帕累托前沿**：机制 M 帕累托最优 iff 不存在 M′ 在三者上均不劣且至少一者更优。
- **护栏**：若噪声使 U_exec<U_min，触发的是「不共享」，而**不是**「降低控制精度」——因为噪声本就不在控制面。

**定义 166（五维隐私-认知预算 PCE+++++）** B_pcog=(B_privacy, B_retrieval, B_scene, B_intent, B_exec)：
- **B_privacy**=(ε_total, ε_used, deletion_credits, consent_tokens)，按 RDP/高级组合单调更新。
- **B_retrieval**=(retrieval_quota, latency_budget, provenance_min)。
- **耗尽策略**：ε 耗尽⇒关闭外发与回写，仅本地增量；检索配额耗尽⇒退回参数先验；溯源不足⇒拒绝检索；B_scene/B_intent/B_exec 沿用第 60 轮。
- **VOI 扩展**：voi_pcog(π)=voi_cog(π)+E[retrieval_gain(π)]−cost_retrieval(π)−cost_privacy(π)。

**定义 167（证明携带检索证据 PCR）** 每个检索结果附带证书：
- Cert_rag=(case_ids, provenance, {w_j}, {ε_j}, freshness, retrieval_hash)。
- Cert_eeis^+ = Cert_eeis ∪ Cert_rag；每个 K_safe 可审计「哪些检索案例以多大权重影响了它」。
- **可归因**：若执行失效可追溯到某检索案例，则触发该案例的降权/隔离；与第 60 轮 J_exec 合成为 J_exec^+=(control_evidence, retrieval_attribution, privacy_ledger)。

**定义 168（机密检索决策 CRD，扩展 CESC）** 决策规则：
```
if ¬PUC_valid or provenance_bad:
    K ← 第 60 轮参数先验编译（local_parametric_only）
elif privacy_exhausted:
    K ← 本地闭环，禁止回写与检索（local_only）
else:
    K ← argmin_{K∈grounded(RAG-safe)} (λ·ω_traj − (1−λ)·K_p)
```
- **保守序**：执行安全（SIC 接地） > 隐私合规（PUC/ε） > 检索效用（增益）。
- 检索增强不是默认路径，而是「双闸门通过后的可选路径」。

## 2. 关键算法（摘要，完整版见产物区）

```python
def confidential_retrieval_execution_loop(M, scene, intent, delta_f_req):
    prior, cases = M.retriever.augment_prior(M.scene_model.get_scene_prior())
    K_hint = M.eeis.compile_with_prior(prior, delta_f_req)         # 检索先验
    K = M.sic.ground(K_hint, M.telem_force, M.telem_pos, M.epir)   # 执行接地
    if K is None:
        K = M.eeis.compile(delta_f_req, M.fused, M.xi_exec, M.Z_env)  # 回退
    if intent:
        M.intent_ctrl.receive_intent(intent)
    M, fused, D_plus, EV_exec, cert = closed_loop_exec_probe(M, ...)  # 控制面
    dispatch_impedance_params(K.best, cert)
    ev_sigma = M.ppee.sanitize(EV_exec.__dict__, purpose='share')   # 记忆面
    msg = M.epir.append(ev_sigma)
    if M.puc.valid() and M.consent.granted() and M.ppee.privacy_ok():
        M.retriever.D.add(make_case(scene, K, ev_sigma, M.provenance.self()))
    return M, K, msg, cert, M.ppee.ledger
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PPEE | O(d) 扰动 + O(1) 承诺/条 | O(window + 账本) | ε_total-DP；因果图同构 |
| RAEP | O(log|D|) 近邻 + O(k) 混合 | O(|D|·d) | 冷启动方差收缩 ≥ 30% |
| PPR | O(k·d) 密文检索 + O(1) 加噪 | O(|D|·d) | 成员推断 AUC ≤ 0.55；删除完备 |
| CREL | O(闭环) | 复用 | 投毒检索不越过 SIC 接地闸门 |
| PCE+++++ | O(1) 记账 | O(1) | 任一分量耗尽触发安全策略 |

**正确性定理（CREG）**：设 A66–A70 成立：
- (A66) σ_ε 满足 ε-DP 且保持因果同构；(A67) 检索案例条件分布覆盖真实 K 的 1−α 置信椭球；(A68) 密文检索不泄漏查询、ε_r 可组合；(A69) 检索先验必须经 SIC 接地才能进入 K_safe；(A70) B_pcog 各分量单调消耗、耗尽即降级。
则：
1. **机密性**：对外发布的证据序列满足 ε_total-DP，且承诺链可验证而不可读。
2. **因果完整性**：σ_ε 保序 + 承诺链 ⇒ ι_causal=1，EPIR 证据链不因净化而断裂。
3. **接地安全性**：任一被投毒/失配的检索先验若与本地 EV-exec 冲突，会被 SIC 过滤在 K_safe 之外，故检索不能直接改写控制。
4. **冷启动增益**：π^RAG 的方差不超过 π_scene，冷启动场景识别误差降低 ≥ δ_RAG。
5. **隐私不外溢**：DP 噪声只作用于记忆面，控制面精度不受 ε 影响。

## 5. 本轮最大风险

**一句话**：若检索到一条**被投毒或跨环境失配**的案例（别的机器人在湿滑地面学到的低阻尼 K 被当成当前桌面的先验），RAG 会把「参数先验的冷启动不确定」替换成「检索先验的自信错误」，制造执行层的「检索增强幻觉」；必须以「溯源签名 + 执行接地 SIC 闸门 + 检索弃权（无高信任案例就不检索）+ PUC 三元护栏」四重约束，确保检索永远只能**收窄候选集**、不能**绕过本地证据**直接决定 K_safe。

## 1. 符号体系增量（定义 161–168）

| 符号 | 含义 |
|---|---|
| `σ_ε` | 证据净化算子（数值域扰动、结构域恒等、保因果同构） |

### IP-161 PPEE（隐私保护执行证据）

```python
class PrivacyPreservingEvidence:
    def __init__(self, eps_total=1.0, delta=1e-6):
        self.eps_total, self.eps_used = eps_total, 0.0
        self.delta = delta
        self.ledger, self.commitments = [], {}

    def _sensitivity(self, field):
        return {'force': 5.0, 'position': 0.01, 'velocity': 0.1}.get(field, 1.0)

    def sanitize(self, ev_exec, purpose):
        eps_i = self._split_budget(purpose)              # 按高级组合分配
        out = dict(ev_exec)
        for f, val in ev_exec['content'].items():
            if f in ('force', 'position', 'velocity'):
                scale = self._sensitivity(f) / eps_i
                out['content'][f] = val + np.random.laplace(0, scale, np.shape(val))
        out['seq_id'] = ev_exec['seq_id']                # 结构域：保序
        out['causal_edges'] = ev_exec['causal_edges']    # 因果图：保形
        salt = os.urandom(16)
        out['hash'] = sha256(json.dumps(out['content'], sort_keys=True).encode()
                             + salt).hexdigest()[:16]
        out['commit'] = (out['hash'], salt)
        self.commitments[out['seq_id']] = out['commit']
        self.eps_used += eps_i
        self.ledger.append((out['seq_id'], eps_i, purpose))
        return out

    def zk_prove_adjacency(self, orig, san, eps_i):
        # 证明：结构域相同 ∧ 数值域 ||orig-san||_1 ≤ Δ/ε_i ∧ 承诺一致
        return ZKProof(struct_equal(orig, san),
                       l1_bound(orig, san, eps_i), commit_consistent(san))

    def privacy_ok(self):
        return self.eps_used <= self.eps_total
```

### IP-162/IP-163 RAEP + PPR（检索增强先验 + 隐私保护检索）

```python
class PrivacyPreservingRetriever:
    def __init__(self, case_base, eps_r=0.5, tau_prov=0.8, k=5, tau_r=0.2):
        self.D, self.eps_r, self.tau_prov = case_base, eps_r, tau_prov
        self.k, self.tau_r = k, tau_r

    def encode_local(self, q):
        return local_encoder(q)                          # 查询不离开本机

    def query(self, q):
        emb = self.encode_local(q)
        sims = self._secure_knn(emb, self.D.encrypted_index)   # TEE / HE
        noisy = sims + np.random.laplace(0, 1.0 / self.eps_r, sims.shape)
        idx = np.argsort(noisy)[-self.k:]
        return [self.D[i] for i in idx
                if self.D[i].provenance.trust >= self.tau_prov
                and self.D[i].provenance.consent
                and not self.D[i].provenance.expired]

    def augment_prior(self, kappa_scene, lam=0.5):
        cases = self.query(kappa_scene)
        if not cases:                                    # 检索弃权：无高信任案例
            return kappa_scene, None
        w = softmax([c.sim / self.tau_r for c in cases]) * np.array(
            [c.provenance.trust for c in cases])
        w = w / w.sum()
        prior = GaussianMixture((1 - lam) * kappa_scene,
                                [(w[j], c.K) for j, c in enumerate(cases)])
        return prior, cases

    def evict(self, case_id):                            # 可证明遗忘
        infl = self.D.influence(case_id)
        self.D.remove(case_id); self.D.reindex()
        for model in self.D.downstream:
            model.rollback(infl)                         # 影响函数回滚
        return deletion_certificate(case_id, infl)
```

### IP-164 CREL（机密检索增强执行闭环）

```python
def confidential_retrieval_execution_loop(M, scene, intent, delta_f_req):
    # ① 记忆面：净化上一条证据并生成承诺
    if M.last_ev is not None:
        M.last_ev_sigma = M.ppee.sanitize(M.last_ev, purpose='sync')

    # ② 隐私检索（溯源闸门在 PPR.query 内）
    prior, cases = M.retriever.augment_prior(M.scene_model.get_scene_prior())
    cert_rag = build_retrieval_certificate(cases, M.ppee.ledger)

    # ③ 编译候选（检索先验）
    K_hint = M.eeis.compile_with_prior(prior, delta_f_req)

    # ④ 执行接地闸门：用原始本地证据/SIC 校验候选
    K_grounded = M.sic.ground(K_hint, M.telem_force, M.telem_pos, M.epir)
    if K_grounded is None:                               # 冲突 ⇒ 弃检索，回退参数先验
        K_grounded = M.eeis.compile(delta_f_req, M.fused, M.xi_exec, M.Z_env)

    # ⑤ 意图约束锁定（第 60 轮 CIEC）
    if intent:
        M.intent_ctrl.receive_intent(intent)

    # ⑥ 控制面：原始实时遥测，无隐私噪声
    M, fused, D_plus, EV_exec, cert = closed_loop_exec_probe(
        M, M.current_cp, delta_f_req, M.budget)
    dispatch_impedance_params(K_grounded.best, cert)

    # ⑦ 记忆面：净化后再进 EPIR
    ev_sigma = M.ppee.sanitize(EV_exec.__dict__, purpose='share')
    msg = M.epir.append(ev_sigma)

    # ⑧ 条件回写（同意 + PUC + 预算）
    if M.puc.valid() and M.consent.granted('case_writeback') and M.ppee.privacy_ok():
        M.retriever.D.add(make_case(
            scene, K_grounded, ev_sigma,
            provenance=M.provenance.self(), consent=True))

    return M, K_grounded, msg, cert, cert_rag, M.ppee.ledger
```

### IP-165 PCE+++++（五维隐私-认知预算）

```python
class PrivacyCognitiveBudget:
    def __init__(self, eps_total=1.0, retrieval_quota=200, provenance_min=0.8,
                 scene_ops=100, intent_ops=50, exec_budget=None):
        self.B_privacy = {'eps_total': eps_total, 'eps_used': 0.0,
                          'deletion_credits': 32}
        self.B_retrieval = {'quota': retrieval_quota, 'used': 0,
                            'provenance_min': provenance_min}
        self.B_scene, self.B_intent = scene_ops, intent_ops
        self.B_exec = exec_budget or ExecBudget()

    def spend_eps(self, eps_i):                          # 高级组合
        self.B_privacy['eps_used'] += eps_i
        return self.B_privacy['eps_used'] <= self.B_privacy['eps_total']

    def retrieval_allowed(self, prov_trust):
        return (self.B_retrieval['used'] < self.B_retrieval['quota']
                and prov_trust >= self.B_retrieval['provenance_min']
                and self.B_privacy['eps_used'] < self.B_privacy['eps_total'])

    def mode(self, prov_trust):
        if not self.retrieval_allowed(prov_trust):
            return 'local_parametric_only'               # 或 local_only
        return 'rag_augmented_grounded'

def voi_pcog(pi, M):
    return (voi_cog(pi) + M.retriever.expected_gain(pi)
            - M.cost.retrieval(pi) - M.cost.privacy(pi))
```

### IP-166 PUC（隐私-效用-因果三元校验）

```python
class PUCTriad:
    def __init__(self, eps_max=1.0, u_min=0.9):
        self.eps_max, self.u_min = eps_max, u_min

    def valid(self, eps_eff, u_exec, i_causal):
        return (eps_eff <= self.eps_max and u_exec >= self.u_min
                and i_causal == 1)

    def pareto_check(self, mechanisms):
        # 返回不被任何机制在三者上同时支配的机制集合
        return [m for m in mechanisms
                if not any((o.eps_eff <= m.eps_eff and o.u_exec >= m.u_exec
                            and o.i_causal >= m.i_causal)
                           and (o.eps_eff < m.eps_eff or o.u_exec > m.u_exec)
                           for o in mechanisms if o is not m)]
```

def build_retrieval_certificate(cases, ledger):

def attribute_failure(J_exec, cert_rag, failure_case):

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| PPEE | O(d) 扰动 / O(1) 承诺 | O(window + ledger) | ε_total-DP；因果图同构 |
| RAEP | O(log\|D\| + k) | O(\|D\|·d) | 冷启动方差收缩 ≥ 30% |
| PPR | O(k·d) 密文检索 | O(\|D\|·d) | 成员推断 AUC ≤ 0.55；遗忘完备 |
| CREL | O(闭环) | 复用 | 投毒先验被 SIC 接地拦截 |
| PCE+++++ | O(1) 记账 | O(1) | 任一分量耗尽即降级 |

**正确性定理（CREG）**：若 A66–A70 成立：
1. **机密性**：σ_ε 满足 ε-DP 且承诺链可验证不可读 ⇒ 对外证据泄漏 ≤ ε_total。
2. **因果完整性**：结构域恒等 + 承诺链 ⇒ ι_causal=1，净化不破坏 EPIR 因果序。
3. **接地安全性**：检索先验必须经 SIC 接地；与本地 EV-exec 冲突的候选被剔除 ⇒ 检索不能直接改写控制。
4. **冷启动增益**：Var(π^RAG) ≤ Var(π_scene) ⇒ 冷启动识别误差降低 ≥ δ_RAG。
5. **控制面独立**：DP 噪声仅作用于记忆面 ⇒ 控制精度与 ε 解耦。

**核心不变式（双闸门）**：
```
K_safe ∈ Control ⇐ 探索通过 ProvenanceGate(t_j ≥ τ_prov, consent, fresh)
                  ∧ 通过 GroundingGate(SIC 与本地 EV-exec 一致)
                  ∧ PUC_valid ∧ B_pcog 未耗尽
```

| 实验 | 指标 | 目标 |
|---|---|---|
| E192 PPEE | ε–效用帕累托；重建攻击成功率；因果链完整性 | 重建 ≤ 5%；ι=1；U_exec ≥ 0.9 |
| E193 RAEP | 冷启动场景识别准确率；样本效率 | ≥ 85%；样本 −40% |
| E194 PPR | 成员推断 AUC；遗忘完备性；检索时延 | AUC ≤ 0.55；遗忘 100%；≤ 100ms |
| E195 PCE+++++ | 预算耗尽降级正确率；越权回写拦截率 | ≥ 99%；100% |
| E196 端到端 | vs 第 60 轮：冷启动适应、隐私泄漏、投毒鲁棒、执行成功率 | 适应时间 −30%；泄漏 −90%；投毒失效 ≥ 95%；成功率不降 |

**消融设计**：去掉执行接地闸门（预期投毒成功率骤升，验证闸门必要性）；去掉结构化 DP 的因果保持（预期承诺链断裂/误报）；把 DP 噪声注入控制面（预期 K_safe 精度崩塌，验证「隐私只在记忆面」原则）。

## 5. 本轮最大风险

**一句话**：若检索到一条**被投毒或跨环境失配**的案例（别的机器人在湿滑地面学到的低阻尼 K 被当成当前桌面的先验），RAG 会把「参数先验的冷启动不确定」替换成「检索先验的自信错误」，制造执行层的「检索增强幻觉」；必须以「溯源签名 + 执行接地 SIC 闸门 + 检索弃权（无高信任案例就不检索）+ PUC 三元护栏」四重约束，确保检索永远只能**收窄候选集**、不能**绕过本地证据**直接决定 K_safe。
