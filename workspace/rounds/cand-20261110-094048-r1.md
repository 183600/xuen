# 第 43 轮（新循环第 3 轮） · Affect-Cert Loop（ACL）：把「情感语音」升格为可证接口 —— 用深度学习的三把锁（Lipschitz 约束 / 共形校准 / 流匹配投影）给共情上保险（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR）。第 42 轮自陈最大风险是「仿真偏差 + 检索幻觉」导致证书在「自信满满」中静默失效。本轮灵感词「情感语音」「深度学习」把这条失效链推到**人机接口**这一层：情感语音是唯一同时**双向**（听懂人 + 说给人）的高带宽通道，深度学习是唯一能把这条通道做得自然的技术，但深度模型恰恰是**最不可证**的黑箱。本轮的立场是：**不把情感语音当 UI 装饰，而当安全关键接口**——用深度学习的三种可证化技术（Lipschitz 约束网络、共形预测/随机平滑、流匹配 + 凸投影）给「共情」上三把锁，并把第 42 轮已有的流匹配、蒸馏、Sim-Cert-RAG 飞轮原样复用为它们的工程底座。证书因此从「物理安全」扩展为「物理 + 社会」双证书。

## 0. 直觉与动机

**灵感 1（情感语音 → 一条双向的安全关键通道）**：过去两轮的「人」只作为环境扰动出现在 D_sim 里。情感语音的直觉是：人是**有内部状态的对手/伙伴**，其情感状态 a_t（效价 v、唤醒 r、支配 d）既被机器人的话改变，又反过来改变机器人该不该动。**输入侧**：语音里的韵律（F0 起伏、能量、语速、停顿、气声）是比文本更早、更密的「人是否恐惧/犹豫/愤怒」信号，应作为 CAR 的软模态守卫；**输出侧**：机器人自己的语气（安慰、紧迫、冷静）是控制量，说错语气在社交上是「二次伤害」。于是情感语音天然是「感知 → 决策 → 表达 → 再感知」的闭环，而不是一个识别任务。

**灵感 2（深度学习 → 自然与可证的张力，正是创新点所在）**：情感识别/合成的 SOTA 全是深度模型（自监督语音表征、大 TTS、世界模型），但它们只给点估计、无覆盖保证、且对说话人/文化/噪声严重 OOD。直觉上要做三件事：**(a) 给识别器套共形预测**，输出「带覆盖率的预测集」而非 softmax，让 CAR 能看到「我不确定」；**(b) 给情感世界模型套 Lipschitz 约束**（谱归一化/正交 RNN），使预测误差能区间传播，被 ACBF 做最坏情况检查；**(c) 给语音合成套认证韵律包络**，生成器（流匹配）自由发挥，投影层保证输出落在安全包络内。三把锁都不牺牲自然度，只是把「自由」限制在可证集合里。

**灵感 3（与既有架构的咬合 → 不新增一座孤岛）**：第 42 轮 IP-48「认证流匹配」原本给运动生成，**流匹配天然也生成语音韵律**，可升级为「运动 + 韵律」双用骨干；IP-43「韵律调度」正好升级为「由 ACBF 反解的包络调度器」；IP-44 蒸馏增加「保覆盖蒸馏」；IP-56 边缘运行时增加情感编码器 INT8 与情感查表分片；IP-54 SCV 在 Isaac Sim 里加「情感人类孪生体」做社交压力测试并产出情感反例；IP-55 CKB 增加情感场景指纹与「哪种语气在人身上有效且安全」的检索模板。证书飞轮的数据源从「物理轨迹」扩到「人机情感轨迹」。

**耦合升级**：识别（ACE）给世界模型（AWM）提供带集值的不确定初值，世界模型给合成（CAP）的包络反解提供安全裕度，合成又改变人的情感、回到识别——形成 **Perceive→Predict→Express→Perceive** 的情感内环，外环仍挂在 Sim-Cert-RAG 飞轮上。

## 1. 形式化定义（增量：定义 38–43）

**定义 38（情感状态与语音观测模型）**：人类情感状态 \(a_t=(v_t,r_t,d_t)\in\mathcal A=[-1,1]^3\)（效价/唤醒/支配）。语音观测 \(o_t=(x_t,\ell_t)\)，\(x_t\) 为波形，\(\ell_t\) 为文本/意图。深度编码器 \(E_\theta\)（自监督语音骨干 + 文本融合）输出 \(p_\theta(a_t\mid o_t)=\mathcal N(\mu_\theta(o_t),\sigma_\theta^2(o_t))\)。定义**情感边际** \(m_{aff}(a)=\min_{a^\ast\in\partial\mathcal A_{safe}}\|a-a^\ast\|\)，即以到安全情感集边界的距离作为「社会安全余量」。

**定义 39（共形情感证书）**：给定校准集 \(D_{cal}=\{(o_i,a_i)\}_{i=1}^n\)，归一化非一致性分数 \(s(o,a)=\|a-\mu_\theta(o)\|/\sigma_\theta(o)\)，阈值 \(\hat q\) 取 \(\lceil (n+1)(1-\alpha)\rceil/n\) 分位数。预测集 \(C_\alpha(o)=\{a:s(o,a)\le\hat q\}\)，在可交换性下保证 \(\mathbb P(a\in C_\alpha(o))\ge 1-\alpha\)。**时序相关/分布偏移**下用自适应共形（ACI）更新置信水平：\(\alpha_{t+1}=\mathrm{clip}(\alpha_t+\eta(\alpha-\mathbb 1[a_t\notin C_{\alpha_t}(o_t)]),[\alpha_{min},\alpha_{max}])\)，保证长期平均覆盖；并提供**块共形**（block-conformal）版本以应对回合内自相关。

**定义 40（情感控制屏障函数 ACBF）**：情感安全集 \(\mathcal A_{safe}=\{a:h_{aff}(a)\ge0\}\)，\(h_{aff}\) 可组合：\(h_{r}=r_{max}(c_t)-r\)（不过度唤醒）、\(h_{v}=v-v_{min}\)（不陷入强负面）、\(h_{truth}=\mathbf 1[\text{prosody}\sim\text{mode}]\)（不在 SafeStop 伪装平静）。机器人语音控制 \(u\)（韵律参数）须满足离散 ACBF：\(h_{aff}(a_{t+1})\ge(1-\gamma)h_{aff}(a_t)\)，其中 \(a_{t+1}=f_{aff}(a_t,u,c_t)\)，\(c_t\) 为机器人模式（Nominal/Degraded/SafeStop/Emergency）。Emergency 下允许 \(r\) 更高以传达紧迫，但硬上界 \(r\le r_{panic}\)。

**定义 41（认证情感韵律包络）**：韵律轨迹 \(\pi=\{(F0_t,E_t,\rho_t,\text{pause}_t)\}\)。模式相关包络 \(\mathcal E_{c}=\{\pi:A\pi\le b_c,\ |F0_{t+1}-F0_t|\le s_{max}\}\)，其构造使「凡 \(\pi\in\mathcal E_c\)，在 \(f_{aff}\) 驱动下 \(h_{aff}\ge0\)」。生成器 \(G_\psi\)（流匹配）以（语义、模式、包络）为条件生成 \(\pi^{gen}\)；**投影层** \(\Pi_{\mathcal E_c}(\pi^{gen})=\arg\min_{\pi\in\mathcal E_c}\|\pi-\pi^{gen}\|^2\) 保证 \(\pi\in\mathcal E_c\)。**命题**：若 \(f_{aff}\) 满足 Lipschitz \(L_{aff}\) 且预测误差 \(\le\varepsilon_{aff}\)，则把包络边界内缩 \(L_{aff}\varepsilon_{aff}\) 后，真实情感轨迹不越界。

**定义 42（Lipschitz 约束情感世界模型）**：\(f_{aff}:(a_t,u_t,c_t)\mapsto a_{t+1}\)，用谱归一化 + 正交约束保证全局 Lipschitz \(L_{aff}\le\bar L\)。训练损失 \(\mathcal L=\mathcal L_{pred}+\lambda\max(0,\mathrm{Lip}(f_{aff})-\bar L)\)。给出区间传播：若 \(a,a'\in B(a_0,\delta)\)，则 \(\|f_{aff}(a)-f_{aff}(a')\|\le\bar L\delta\)；预测误差 \(\varepsilon_{aff}\) 由验证集分位数或共形给出。ACBF 的可行性检查在**可达集** \(\mathrm{Reach}(a,u)=B(f_{aff}(a,u,c),\bar L\delta+\varepsilon_{aff})\) 上取最坏值。

**定义 43（情感增强知识库与检索）**：KB 记录扩展为 \((\phi,\psi,\psi_{aff},C,\Xi,\Pi)\)，新增 \(\psi_{aff}\)=情感场景指纹（说话人类型、情绪强度、文化/语言、噪声/信道）。检索器 \(R(\phi,\psi,\psi_{aff})=\mathrm{Top}\text{-}k(\mathrm{sim}_\phi\cdot\mathrm{sim}_\psi\cdot\mathrm{sim}_{aff})\)。RAG 合成同时迁移两类模板：**有效响应模板**（哪种语气在该人群上被验证有效）与**情感反例**（如「温柔语气在紧急场景被误读为不重视」）。合成成本 \(\propto|\Delta|\) 的性质保持。

## 2. 四大产出设计（新增 IP-57/58/59 + 升级 IP-39/43/44/45/48/50/51/52/54/55/56）

### 2.1 IP-57 AFFECT-CERT-ENCODER（ACE，情感识别 + 共形证书）
1. **骨干**：自监督语音表征（WavLM/HuBERT 类）→ 轻量跨模态融合（文本意图 + 韵律统计），输出 \((\mu,\sigma)\)；用随机平滑训练提升对信道噪声的认证鲁棒半径。
2. **共形层**：split-conformal 给出预测集；ACI 应对 Sim→Real 漂移；块共形应对一轮对话内的自相关。
3. **集值接口**：向 CAR/AWM 输出 `{point, set, radius, coverage}`，而非标量标签；不确定时主动「澄清提问」而非猜测。
4. **边缘化**：保覆盖蒸馏到 INT8（见 IP-44 升级），端侧 < 20ms/100ms 帧。

### 2.2 IP-58 CERT-AFFECT-PROSODY（CAP，认证情感语音合成）
1. **双用流匹配**：复用 IP-48 骨干，条件从运动换成（语义、模式、包络），输出韵律轨迹。
2. **包络投影**：逐拍凸 QP 投影（盒约束 + 斜率约束可闭式裁剪），保证 \(\pi\in\mathcal E_c\)；投影失真写进证书。
3. **真实性约束**：模式 ↔ 韵律的最小偏离（SafeStop 不得用「一切正常」语调），由 \(h_{truth}\) 强制。
4. **兜底韵律**：ACBF 不可行时退到「中性、低唤醒、慢速」安全默认韵律。

### 2.3 IP-59 AFFECT-WORLD-MODEL（AWM，Lipschitz 情感世界模型）
1. **Lipschitz 约束动力学**：谱归一化 MLP/正交 RNN，全局 \(\mathrm{Lip}\le\bar L\)，训练后做 Lipschitz 验证。
2. **可达集传播**：给 ACBF 提供最坏情况可行域；可行则输出语音控制 \(u\)，不可行则升级到澄清/停止。
3. **个体/文化条件**：以 \(\psi_{aff}\) 为条件输入，但条件变化受 Lipschitz 约束以限制外推风险。
4. **在线微调的安全边界**：TTA/持续学习只允许在「不影响已认证覆盖」的参数子空间内更新（见风险）。

## 5. 本轮最大风险

**一句话**：情感标签的主观性、文化相关性与交互时序自相关会击穿共形预测的可交换性假设——**机器人可能在数学上「覆盖有效」、在社交上「致命误读」**（把真实恐惧自信地判为平静，再用「安全」的平静语气回应），这是一种比第 42 轮「仿真偏差」更隐蔽的**情感幻觉失效**；因此 E87/E88（跨分布覆盖）与 E89（ACBF 实测）必须作为红线实验，且「不确定即澄清、不可行即中性兜底」必须是架构级强制路径。

### IP-57 ACE：共形情感证书 + ACI + 保覆盖蒸馏
```
def fit_affect_certificate(encoder, D_cal, alpha=0.1):
    scores = []
    for o, a in D_cal:
        mu, log_sigma = encoder(o)
        s = dist_A(a, mu) / exp(log_sigma)      # 归一化非一致性
        scores.append(s)
    n = len(scores)
    k = ceil((n + 1) * (1 - alpha))
    qhat = sorted(scores)[min(k, n) - 1]
    return qhat

def affect_certificate(encoder, o, qhat):
    mu, log_sigma = encoder(o)
    r = qhat * exp(log_sigma)
    return {'point': mu, 'set': Ball(mu, r), 'radius': r, 'coverage': 1 - alpha}

def aci_update(alpha_t, covered, alpha=0.1, eta=0.01, lo=1e-3, hi=0.5):
    # covered: a_t in C_{alpha_t}(o_t) ? 1 : 0
    return clip(alpha_t + eta * (alpha - (0.0 if covered else 1.0)), lo, hi)

def block_conformal_scores(episodes, block=10):
    # 回合内自相关：按块聚合非一致性，恢复近似可交换
    return [max_score(ep[i:i+block]) for ep in episodes
            for i in range(0, len(ep), block)]

def distill_coverage_preserving(teacher, student, D_cal, alpha):
    student = distill(teacher, student, D_cal, loss='kl')
    # 关键：在蒸馏后用校准集重标定阈值，恢复学生覆盖
    q_student = fit_affect_certificate(student, D_cal, alpha)
    assert empirical_coverage(student, D_cal, q_student) >= 1 - alpha - 0.01
    return student, q_student
```

### IP-58 CAP：双用流匹配 + 认证包络投影
```
def generate_prosody(flow_model, semantic, mode, envelope):
    pi_gen = flow_integrate(flow_model, cond=(semantic, mode))
    pi_safe = project_to_envelope(pi_gen, envelope)   # 凸 QP
    assert in_envelope(pi_safe, envelope)
    return pi_safe

def project_to_envelope(pi, env):
    # min ||p - p_gen||^2  s.t.  A p <= b (盒约束) 且 |p_{t+1}-p_t| <= s_max (斜率)
    p = pi.copy()
    for t in range(len(p)):
        p[t] = clip(p[t], env.lo, env.hi)             # 盒约束闭式
    for t in range(1, len(p)):                         # 斜率约束，两遍扫描
        p[t] = clip(p[t], p[t-1] - env.s_max, p[t-1] + env.s_max)
    return p

def envelope_from_acbf(f_aff, h_aff, mode, Lbar, eps_aff, gamma):
    # 在模式约束下反解允许的韵律盒（示意：二分搜索最宽可行盒）
    lo, hi = default_box(mode)
    lo, hi = shrink(lo, hi, Lbar * eps_aff)           # 安全内缩
    assert acbf_holds_for_all(f_aff, h_aff, (lo, hi), gamma)
    return Envelope(lo=lo, hi=hi, s_max=mode.slew)

def safe_default_prosody():
    return Prosody(f0=neutral_f0, energy=low, rate=slow, pause=long)  # ROM 常驻兜底
```

### IP-59 AWM：Lipschitz 世界模型 + 可达集 + ACBF 可行性
```
class LipschitzAffectDynamics(nn.Module):
    # 每层谱归一化（spectral norm<=1）+ 正交约束 → 全局 Lip(f) <= Lbar
    def forward(self, a, u, c, psi_aff): ...

def reachable_set(a, u, c, f_aff, Lbar, eps_aff, delta):
    center = f_aff(a, u, c)
    radius = Lbar * delta + eps_aff
    return Ball(center, radius)

def acbf_select(a, u_candidates, f_aff, h_aff, gamma, Lbar, eps_aff):
    for u in u_candidates:
        R = reachable_set(a, u, c, f_aff, Lbar, eps_aff, delta=0.0)
        if min_{a2 in R} h_aff(a2) >= (1 - gamma) * h_aff(a):
            return u
    return None   # 不可行 → 交给 IP-51 澄清 / SafeStop / 中性兜底

def verify_lipschitz(f_aff, grid, Lbar):
    # 采样网格上的经验 Lipschitz 验证 + 每层谱范数上界
    return empirical_lip(f_aff, grid) <= Lbar and layer_spectral_bound(f_aff) <= Lbar
```

```
# CAR：物理守卫 ∪ 情感守卫
def car_transition_guard(e, x, a_set, cert):
    phys_ok =  phys_margin(x) >= cert.theta[e]
    # 集值最坏情况：预测集的每个元素都必须在安全情感集内
    aff_ok  = all(h_aff(a) >= cert.theta_aff[e] for a in a_set.samples())

def rag_synthesize_with_affect(phi, psi, psi_aff, KB):
```

**关键命题（情感双证书）**：若 (i) 共形覆盖成立 \(a_t\in C_\alpha(o_t)\)（概率 \(\ge1-\alpha\)）；(ii) \(f_{aff}\) 满足 \(\mathrm{Lip}\le\bar L\) 且误差 \(\le\varepsilon_{aff}\)；(iii) 韵律 \(\pi\in\mathcal E_c\) 且包络已内缩 \(L_{aff}\varepsilon_{aff}\)，则真实情感轨迹以概率 \(\ge1-\alpha\) 满足 \(h_{aff}(a_{t+1})\ge(1-\gamma)h_{aff}(a_t)\)。三者缺一即触发「澄清/中性兜底」而非放行。

## 6. 本轮最大风险

**一句话**：情感标签的主观性、文化相关性与交互时序自相关会击穿共形预测的可交换性假设——**机器人可能在数学上「覆盖有效」、在社交上「致命误读」**（把真实恐惧自信地判为平静，再用「安全」的平静语气回应），这是一种比第 42 轮「仿真偏差」更隐蔽的**情感幻觉失效**；因此 E87/E88（跨分布覆盖）与 E89（ACBF 实测）必须作为红线实验，且「不确定即澄清、不可行即中性兜底」必须是架构级强制路径。
