# 第 66 轮（承接第 65 轮「VISTA 视觉知情安全时序归因」IP-214~223；灵感循环第 2 轮；本轮灵感：「数据采集」×「用户体验」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述的最大风险是整条链的隐藏假设 A88：**故障必须落在有限假设集 ℋ={H0,H_geo,H_force,H_model,H_vis,H_policy} 内，且视觉与几何的失效必须相互独立。** 真实故障常是未知类型的组合；透明/镜面/对抗 patch 又会让视觉与几何共享同一分布外失效源。于是 FIR 会把未知复合故障**强行塞进最近假设、只膨胀错误的球**，而系统还因为「已经归因」而更自信地继续执行。本轮不往 ℋ 里再加第 7 个假设，也不再多装一个传感器，而是把两个一直被视为「外生」的东西拉进闭环：**数据**与**人**。第 65 轮问「是哪一类已知故障」，ATTUNE 问：
>
> **「这个故障到底在不在我们的字典里？如果不在，值不值得、以什么代价、在什么时刻去采一次数据或问一次人，才能把它安全地变成已知——而这次询问会不会反而破坏人对系统的信任？」**
>
> 核心命题：**把「闭集、离线、独立故障归因」升级为「开集、主动采集、信任校准的人机协同归因」——未知故障必须能被诚实拒识；每一次数据采集都是一次带物理风险、注意力成本与信任后果的受控实验；用户体验（注意力/信任/负荷/可理解性）是安全预算的一部分，而不是事后包装。**

## 0. 直觉与动机

**灵感 1（数据采集 → 故障字典不是一个离线数据集，而是一个需要主动培育的活体）**
直觉：VISTA 的 `p(ρ|H)` 来自离线故障注入，隐含前提是「故障词表在部署前已经完备、且每个假设都有足够样本」。但真实部署里最贵的恰恰是长尾故障：每换一台机器人、一栋楼、一批物体，签名的分布就漂移，而现场每个新故障往往只有一两个例子。于是「数据采集」在这里不是「再多标一点数据」的同义词，而是**决定下一次采什么、向谁采、什么时候采、采完是否值得留**。数据有且仅有一个价值判据：**它能否降低「未知故障」的期望风险，而不是让已知类更准**。关键反转是——采集动作本身既可能是安全的探针，也可能是新的物理伤害源；主动采集会带来选择偏差（只在我们已经看得到的地方采），人类标签会带来噪声与迎合偏差。所以采集必须被当作**受控实验**：有假设、有预算、有停止条件、有可逆性。

**灵感 2（用户体验 → 人不是免费的 oracle，注意力、信任、认知负荷都是稀缺的安全资源）**
直觉：VISTA 把人当成「外部监督者」或最终兜底，这在工程上偷懒：人也会疲劳、会过度信任、会在错误时刻分心。用户体验不是界面美化，而是三个可度量的安全量：(i) **注意力预算**——打扰次数、打断时机、恢复成本；(ii) **信任校准**——人对机器可靠性的主观信任与真实可靠性之间的偏差，过度信任导致「橡皮图章」式放行（automation bias），信任不足导致无谓弃用；(iii) **可理解性**——解释是否让人形成正确的心智模型，而不是用置信度话术掩盖无知。**好的用户体验不是让人更信任机器人，而是让人的信任与机器人的真实可靠性对齐。** 必须诚实：信任不可直接观测、用户研究样本小、参与度指标可被操纵；因此用户模型只能作为**可撤销的先验**，绝不能当安全真值。

**灵感 3（两灵感合流 → ATTUNE：一次询问同时花掉「注意力」、买回「信息」）**
直觉：两条灵感其实是一枚硬币的两面。**每次向人求助，都是用人的注意力去换关于未知故障的信息；每次给出解释，都是用人的注意力去换信任校准。** 因此它们共享同一个预算、同一个最优停止问题、同一种「问多了反而更糟」的失效模式。闭环是：开集归因（OADR）发现「字典外」→ 成本感知查询（CAQ）在「自采集 / 问人 / 影子日志」之间做选择 → 安全可逆地执行 → 数据 provenance 与认证准入（DPC）决定是否把新故障写进字典 → 信任校准与最小充分解释（TCE/EXP）确保人形成正确心智模型 → 协同升级阶梯（HAI）决定自动驾驶到移交的分级 → 证书 J_attune。名字取「调音」之意：**系统与人的可靠性被持续调到同一根弦上**。

**灵感 4（关键反转：从「人纠正机器人」变成「机器人管理自己的无知」）**
直觉：第 64 轮把人当「几何真值」，第 65 轮把视觉当「第三条可错证据」，本轮把人也降格为**有噪声、有成本、会疲劳、可撤销的第四条可错证据**。既然可错，就必须像 VCV 的 `visual_unobservable` 一样，显式引入 `human_unavailable`、`human_unreliable`、`human_conflicted` 三种状态：**看不见不能当作不存在，人不回答也不能当作没问题，人回答得太快太顺也不能当作可信。** 机器人真正要管理的不是「人类知道什么」，而是「自己的字典边界在哪里、边界外的东西值不值得花人的注意力去命名」。

**灵感 5（VISTA 组件的原位升级）**
- **FIR → OADR**：闭集 softmax 升级为「已知子空间投影 + 正交新颖度 + conformal 拒识」，输出 `known / unknown / ambiguous` 三态，**未知不再被强行归类**。
- **APP/AFA → CAQ**：探针集从物理探针扩展到「问人/要示范/要偏好/影子日志」，目标从「故障互信息」升级为「单位综合成本的开集信息增益」。
- **RSC-V → RSC-U**：人类反馈只作为可撤销软先验，不许把任何球缩到证据下界以下；未知时联合膨胀并进入安全待机。
- **CSC → CSC-U**：认证前缀同时受不可逆视界 `m` 与**人类接管反应视界** `m_human` 约束；未知故障下 `k*=1` 或直接升级。
- **CSP-V → CSP-U**：规划器显式插入「采集/询问/移交」元技能，代价含期望人类注意力；每条块边必须存在安全停止点与移交点。
- **AIC-V → AIC-U**：干扰集增加人因对抗——疲劳、迎合、社会工程、解释注入、习惯化。
- **J_vista → J_attune**：证书增加 open-set p 值、unknown 标志、查询预算、信任校准、解释与数据 provenance 哈希。
- **新增 HUC / DPC / TCE / EXP / HAI**：用户模型、数据价值与认证准入、信任校准、最小充分解释、协同升级阶梯。

## 1. 形式化定义（增量：定义 233–249）

- **定义 233（ATTUNE 闭环）**：ATTUNE = (VISTA, OADR, HUC, CAQ, DPC, TCE, EXP, HAI, RSC-U, CSC-U, CSP-U, AIC-U, J_attune)。定位：VISTA 的「开集化 + 主动采集 + 人机信任校准」升级。不变式：**开集评分、用户模型推断、查询选择、解释生成、信任校准、数据准入与证书只在语义流；实时流只执行安全可逆的查询前缀、认证执行前缀、监控与人类否决，零学习写操作。**
- **定义 234（开集故障假设空间与三态拒识）**：`ℋ_open = ℋ_known ∪ {H_unk}`。对签名 ρ 定义新颖度 `ν(ρ) = ‖(I−P_𝒮)ρ‖²_{Σ_ρ⁻¹}`（`P_𝒮` 为已知故障子空间投影），并用标定集构造 conformal p 值 `p_unk(ρ)`。判定：若 `p_unk ≤ α_os` 且 `max_{H∈ℋ_known} P(H|ρ) ≥ 1−δ_fi` → `known(H*)`；若 `p_unk > α_os` → `unknown`；否则 `ambiguous`。阈值按代价敏感选取（漏拒未知的代价 ≫ 多问一次的代价）。
- **定义 235（已知故障子空间与可增长基）**：已知故障效应张成子空间 `𝒮 = span{B_1,…,B_K}`（可由低秩适配器方向或类协方差主方向构造）。加入新故障 `H_new` 必须使 `𝒮` 扩张且**旧类投影残差保持**（不遗忘约束 `‖(I−P_{𝒮'})ρ_old‖ ≤ (1+ε_forget)‖(I−P_𝒮)ρ_old‖`）。低秩不是装饰，而是可检验的结构先验：若扩张后残差谱不收敛，说明低秩假设失效，应退回联合保守而非继续拟合。
- **定义 236（用户模型 HUC）**：潜状态 `u_t = (τ_t 信任, w_t 负荷, c_t 能力, a_t 可用性)`，观测为交互事件 `o_t`（响应时延、修改率、否决、跳过解释、求助）。维护信念 `b_t(u)`。**可撤销性**：当 `H[b_t] > h_max` 或模型校验失败时，退回总体先验与无画像基线。能力 `c` 与信任 `τ` 必须分开：能力决定「问了有没有用」，信任决定「会不会盲从」。
- **定义 237（采集/查询动作集与三重成本）**：`Q = {self_probe, silent_log, label_query, demo_request, preference_query, confirm_query, veto_request}`。每个 `q` 带物理风险 `R_phys(q)`、注意力成本 `R_att(q)`、信任成本 `R_trust(q)`、时延 `Δt(q)`；查询必须满足 `f_n ≤ f_safe`、形变 `≤ ε_strain`、可逆、且有超时回退。**不可逆动作永远不允许作为采集动作。**
- **定义 238（成本感知查询 CAQ）**：`q* = argmax_{q∈Q} EIG(q; ℋ_open | b_t, ρ) / (λ_p R_phys + λ_a R_att + λ_t R_trust + λ_d Δt)`，s.t. 预算 `Σ cost ≤ B`、可用性 `a_t ≥ a_min`、安全与可逆约束。若最佳期望信息增益 `< δ_query`、或 `R_phys` 超限、或人不可用 → 降级为 `silent_log` 或 `null_test`，并显式标注 `collection_deferred`。这正是把「采集」从离线阶段变成在线决策。
- **定义 239（数据价值、provenance 与认证准入 DPC）**：每条数据 `d` 记 `prov(d) = (来源, 工况, 时间, 标定版本, 是否人标, 用户状态)`。价值 `v(d) = Δ(期望开集风险) / (采集成本 + 存储成本)`，用影响函数/近似 Shapley 估计。准入规则（定义 240）未通过前，数据只进隔离区 quarantine。支持**撤销**：若某来源被判定偏差/投毒，按 provenance 反查并回滚其影响。
- **定义 240（故障字典的认证准入）**：候选 `H_new` 转正需同时满足：(i) 跨会话复发 `≥ n_rec`；(ii) 与现有假设可区分（成对互信息/分离度 `≥ δ_sep`）；(iii) 存在保守缓解策略且其最坏代价有界；(iv) 通过人因/对抗验证；(v) 不破坏旧类（定义 235 的不遗忘界）。**生长不等于拟合：只让「能被安全处置」的新故障进入字典。**
- **定义 241（信任校准 TCE）**：真实可靠性 `R_true(t)`（滚动窗口内「适当依赖」比例），系统声明可靠性 `R_hat(t)`，人的信任 `τ_t`。校准误差 `CE = |τ_t − R_true(t)|`；过度信任（`τ ≫ R_true`）→ 橡皮图章风险；信任不足（`τ ≪ R_true`）→ 无谓弃用。干预集 `I={none, show_uncertainty, show_evidence, force_check, demo, request_handover}`，选择 `i* = argmin_i [E|τ_{t+1}−R_true| + λ_w·Δw_i]`。
- **定义 242（最小充分解释 EXP）**：解释内容 `e ∈ E` 包含「结论 + 关键证据 + 不确定性 + 数据来源 + 可撤销点」。目标 `min_e cost_cog(e)` s.t. `E[CE 降低] ≥ δ_exp`，并强制**反过度声明**：不得只给结论不给不确定性与 provenance；`overclaim(e)=1` 则证书非法。解释哈希进证书，保证「系统当时到底说了什么」可审计。
- **定义 243（协同升级阶梯 HAI）**：`L = {autonomous, notify, confirm, demo_request, shared_control, handover, safe_idle}`。转移由开集状态、信任校准、风险、可用性共同决定；**每次升级可逆**，人类否决在反应视界内始终有效；单位任务查询数有上界 `N_q`，防止「用提问把责任外包」。
- **定义 244（人类反应视界与 CSC-U）**：`m_human = v_max·(t_react + t_handover)`。认证前缀 `k* ≤ min(m, m_human)`。在 `unknown` 状态下，证书要求对 `H_unk` 做**联合最坏膨胀**而非单球膨胀；若无法在预算内认证 → `k*=1` 或 `safe_idle`，绝不「因为还没归因所以先按健康执行」。
- **定义 245（RSC-U 可撤销人类先验）**：`r_geo/r_force/r_model` 可被人反馈以权重 `w_h = f(τ_t, c_t)` 软更新，但**不得低于证据下界**；所有人类更新带版本号、可回滚。`H_unk` → 三球联合膨胀（`r=√(r_geo²+r_force²+r_model²)`）并降低 `k*`。人类反馈永远不能把未知变成已知——只有 DPC 准入可以。
- **定义 246（CSP-U 采集感知规划）**：在块级规划中加入信息型元技能 `{ask_label, request_demo, silent_observe, handover_point}`；块边代价 `= 执行代价 + λ_q E[注意力] + λ_risk·P(需升级)`；每条块边必须附带**安全停止点**与**移交点**。技能签名绑定 `(故障签名, 查询历史)`，查询历史异常即判 OOD。
- **定义 247（AIC-U 人因对抗认证）**：干扰集 `ℰ_U = ℰ_V × ℰ_human`，`ℰ_human` 含疲劳、迎合/讨好、恶意标签、社会工程、解释注入、习惯化、操作员缺席。`ρ_dir` 在最坏人因下重算；**共因**（同一场景同时拖慢感知、诱导错误标签、并让解释显得可信）显式建模。共因下不要求归因正确，只要求判 `unknown/ambiguous` 并安全升级。
- **定义 248（ATTUNE 证书 J_attune）**：`J_attune = (J_vista, open_set_pvalue, unknown_flag, query_budget_spent, trust_calibration, explanation_hash, human_provenance_hash, escalation_level, aic_u_ver)`。`Valid(J_attune) ⇔ Valid(J_vista) ∧ (unknown 已拒识并升级 ∨ 已认证归因) ∧ 查询预算未超 ∧ 解释未过度声明 ∧ 人类反馈 provenance 有效 ∧ (human_unavailable ⇒ 未以人类沉默否定故障) ∧ 安全网存在`。
- **定义 249（ATTUNE 闭环算子）**：语义流 `[LiDAR→LSF→USR/MEL→VPG→ACH→阶段签名→VCV→OADR 开集拒识→(known) FIR / (unknown) CAQ 选查询→安全查询→HUC 更新→DPC 准入→TCE/EXP→HAI 升级→WCV-V→CSP-U→CSC-U→AIC-U→J_attune]`；实时流 `[锚点读→残差采集→阶段判定→查询前缀/认证前缀执行→人类否决监听→早停→J_attune 构建]`。

## 2. 关键算法骨架

```python
# OADR：开集三态，不再强行最近邻
nu = novelty_energy(rho, basis_S, Sigma_rho)          # 字典外能量
p_unk = conformal_pvalue(nu, calib_novelty)           # 分布无关 p 值
if p_unk > alpha_os:
    state = 'unknown'                                 # 诚实拒识
elif max(known_post.values()) >= 1 - delta_fi:
    state = 'known'
else:
    state = 'ambiguous'

# CAQ：用人的注意力买信息，同时守住物理安全
best, best_score = None, -inf
for q in query_types(state, b_user, rho):
    if not safe_and_reversible(q, f_safe, eps_strain):   # 不可逆动作禁止作为采集
        continue
    eig = expected_open_set_info_gain(q, state, b_user, rho)
    cost = lam_p * phys_risk(q) + lam_a * attn_cost(q, b_user) \
         + lam_t * trust_cost(q, b_user) + lam_d * delay(q)
    if eig / (cost + 1e-9) > best_score:
        best, best_score = q, eig / (cost + 1e-9)
if best is None or best_score < delta_query or b_user.availability < a_min:
    best = 'silent_log'; note_collection_deferred()

# TCE + EXP：让信任与真实可靠性对齐，而不是追求“更信任”
ce = abs(tau - R_true)
if ce > ce_max:
    i = argmin_i(expected_calibration_error(tau, R_true, i)
                 + lam_w * workload_delta(i, b_user))
    e = select_minimal_sufficient_explanation(conclusion, evidence,
                                              uncertainty=True, provenance=True)
    if overclaim(e): reject_explanation(e)          # 不许只给结论不给不确定性
    present(e, intervention=i)

# HAI + CSC-U：升级阶梯与认证前缀
level = escalate(state, ce, risk, b_user.availability)
k_star = csc_u.certified_prefix(A, state, m, m_human, alpha_chunk)
if state == 'unknown' and not certifiable_under_unknown(A[:1]):
    level = 'safe_idle'; k_star = 0
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（开集拒识的有限样本保证）**：在可交换性下，conformal p 值给出 `P[把未知判成 known] ≤ α_os`；拒识功效由已知子空间与新颖方向的分离度 `κ_os` 决定。分布漂移破坏可交换性时退化为 anytime-valid e-value，保证随时间不虚警。
- **引理 10（查询的最优停止与预算界）**：期望信息增益随已采样本边际递减，成本随打扰次数递增，故 `EIG/cost` 单调下降，存在最优停止点；查询数上界 `N_q ≤ B/c_min`，且任何时刻可因 `a_t < a_min` 无条件降级为 `silent_log`。
- **引理 11（信任校准的有界收敛与不可辨识性）**：在用户模型可撤销、干预有界、`R_true` 可估计时，校准误差在平稳段以 `O(1/√n)` 收敛；但当人类反馈本身有偏（迎合/疲劳）时 `R_true` 不可辨识，只能给出最坏界而非点估计。
- **定理 9（ATTUNE 端到端）**：在 A94–A99 下，已知故障的处置不弱于 VISTA；未知故障以 `≥1−α_os` 被拒识并进入安全升级；人类反馈只经 DPC 认证准入才改变字典；`Valid(J_attune)` ⇒ 无强行归因 ∧ 查询在预算内 ∧ 解释未过度声明 ∧ 安全网存在。
- **定理 10（不劣于基线与人类失误下的有界遗憾）**：安全网 `V = max(V_ATTUNE, V_VISTA, V_no_human)` 保证协同不劣于任一基线；若人类反馈中恶意/错误比例为 `ε_h`，鲁棒聚合给出 `Risk ≤ Risk_VISTA + ε_h·L_h`，且撤销机制使恢复时间有界。
- **实时性**：开集评分、用户模型更新、查询选择、解释生成、信任校准全在语义流；实时流只增新颖度标量读取（`<0.05ms`）、否决监听（`<0.02ms`）、查询前缀派发与早停，目标仍 `≤2.5ms`。

## 5. 本轮最大风险

## 2. 形式化定义（完整版）

**定义 233（ATTUNE 闭环）** ATTUNE 是 VISTA 的「开集化 + 主动采集 + 人机信任校准」升级：在 VISTA 骨架上把 FIR 原位升级为 OADR，新增 HUC（用户模型）、CAQ（成本感知查询）、DPC（数据 provenance 与认证准入）、TCE（信任校准）、EXP（最小充分解释）、HAI（协同升级阶梯），并原位升级 RSC-V→RSC-U、CSC→CSC-U、CSP-V→CSP-U、AIC-V→AIC-U、J_vista→J_attune。不变式：**开集评分、用户模型推断、查询选择、解释生成、信任校准、数据准入与证书只在语义流；实时流只做残差采集、安全可逆的查询前缀、认证执行前缀、人类否决监听与早停，零学习写操作。**

**定义 234（开集故障假设空间与三态拒识）** 令 `ℋ_open = ℋ_known ∪ {H_unk}`，`ℋ_known = {H0,H_geo,H_force,H_model,H_vis,H_policy}`。用已知故障标定数据构造子空间 `𝒮`，定义新颖度

`ν(ρ) = ‖(I − P_𝒮) ρ‖²_{Σ_ρ⁻¹}`，

其中 `P_𝒮` 为到 `𝒮` 的正交投影。在独立标定集上取非一致性分数 `ν_i`，令 `p_unk(ρ) = (1 + #{i: ν_i ≥ ν(ρ)}) / (n+1)`。三态判定：

- `known(H*)`：`p_unk(ρ) > α_os` 且 `P(H*|ρ) ≥ 1−δ_fi`；
- `unknown`：`p_unk(ρ) ≤ α_os`；
- `ambiguous`：其余。

阈值 `α_os` **按代价敏感选取**：漏掉未知（把未知当已知继续执行）的损失远大于多一次查询的成本，故 `α_os` 取偏保守侧。`H_unk` 不参与 softmax 竞争，避免「最近邻强行归类」。

**定义 235（已知故障子空间与可增长基）** 已知故障效应张成 `𝒮 = span{B_1,…,B_K}`，`B_k` 可取低秩适配器方向、类协方差主方向或故障注入的判别方向。加入新故障 `H_new` 使 `𝒮' = span(𝒮, B_new)`，须满足不遗忘约束

`‖(I−P_{𝒮'}) ρ_old‖ ≤ (1+ε_forget)·‖(I−P_𝒮) ρ_old‖`，∀ 旧类样本 ρ_old。

低秩是可检验的结构先验：若扩张后正交残差谱不收敛（新增方向无法解释剩余能量），说明低秩假设失效，应退回联合保守膨胀，而不是继续拟合。

**定义 236（用户模型 HUC）** 潜状态 `u_t=(τ_t,w_t,c_t,a_t)`：`τ_t` 信任、`w_t` 认知负荷、`c_t` 领域能力、`a_t` 可用性（在场/分心/离线）。观测 `o_t` 包括响应时延、是否修改建议、否决率、跳过解释、主动求助。维护信念 `b_t(u)`（贝叶斯滤波或轻量粒子滤波）。**可撤销性**：若 `H[b_t] > h_max` 或离线校验失败，退回总体先验 `b_0` 与无画像基线。`c` 与 `τ` 必须分离：`c` 决定「问是否有效」，`τ` 决定「是否盲从」。用户模型的输出只进入查询/解释/升级决策，**不进入物理安全真值**。

**定义 237（采集/查询动作集与三重成本）** `Q={self_probe, silent_log, label_query, demo_request, preference_query, confirm_query, veto_request}`。每个 `q` 带：

- 物理风险 `R_phys(q)`：执行 q 期间的最大力/形变/越界概率；
- 注意力成本 `R_att(q)`：期望打断时长与恢复成本；
- 信任成本 `R_trust(q)`：过度询问或过度解释导致信任漂移的代价；
- 时延 `Δt(q)`。

查询必须满足 `f_n ≤ f_safe`、`strain ≤ ε_strain`、**可逆**、有超时回退。**不可逆动作永远不允许作为采集动作**——这是把「主动采集可能造成新伤害」显式排除。

**定义 238（成本感知查询 CAQ）** 给定开集状态与用户信念，选择

`q* = argmax_{q∈Q} EIG(q; ℋ_open | b_t, ρ) / (λ_p R_phys + λ_a R_att + λ_t R_trust + λ_d Δt)`，

s.t. `Σ_{已执行} cost ≤ B`、`a_t ≥ a_min`、安全与可逆约束。若最佳比值 `< δ_query`、或 `R_phys` 超限、或人不可用，则降级为 `silent_log` / `null_test`，并标注 `collection_deferred`。这把「数据采集」从离线数据工程变成在线、带预算、可解释的决策。

**定义 239（数据价值、provenance 与认证准入 DPC）** 每条数据 `d` 记录 `prov(d)=(source, condition, time, calib_ver, human_labeled, user_state)`。数据价值

`v(d) = Δ(期望开集风险) / (采集成本 + 存储成本)`，

用影响函数或近似 Shapley 估计。数据先进入隔离区 quarantine；支持按 provenance 反查与回滚（若某来源被判定偏差/投毒）。**数据进入系统不等于进入字典**。

**定义 240（故障字典的认证准入）** 候选 `H_new` 转正需同时满足：

1. 跨会话复发 `≥ n_rec`；
2. 与现有假设可区分：成对分离度/互信息 `≥ δ_sep`；
3. 存在保守缓解策略且最坏代价有界；
4. 通过人因与对抗验证（定义 247）；
5. 满足定义 235 的不遗忘界。

未满足者继续隔离，**不得**为了「覆盖更多情况」而放宽。核心原则：**只让「能被安全处置」的新故障进入字典。**

**定义 241（信任校准 TCE）** 真实可靠性 `R_true(t)` 为滚动窗口内「适当依赖」比例（人该接管时接管、该放行时放行），系统声明可靠性 `R_hat(t)`，人的信任 `τ_t`。校准误差 `CE=|τ_t−R_true(t)|`。过度信任 `τ≫R_true` → 橡皮图章；信任不足 `τ≪R_true` → 无谓弃用。干预集 `I={none, show_uncertainty, show_evidence, force_check, demo, request_handover}`，选择

`i* = argmin_{i∈I} [ E|τ_{t+1} − R_true| + λ_w·Δw_i ]`。

**定义 242（最小充分解释 EXP）** 解释内容 `e` 至少含：结论、关键证据、不确定性、数据 provenance、可撤销点。目标

`min_e cost_cog(e)` s.t. `E[CE 降低] ≥ δ_exp`，

并强制反过度声明：`overclaim(e)=1`（只给结论、隐藏不确定性或来源，或用置信度话术掩盖未知）则 `Valid(J_attune)=False`。解释哈希进证书，使「系统当时到底说了什么」可审计。

**定义 243（协同升级阶梯 HAI）** `L={autonomous, notify, confirm, demo_request, shared_control, handover, safe_idle}`。转移由 `(开集状态, CE, 风险, a_t)` 决定；每次升级可逆，人类否决在反应视界内始终有效；单位任务查询数 `≤ N_q`，防止「用提问把责任外包」。升级的单调性原则：**不确定时只允许向更保守方向升级，不允许因询问成功而越过证据直接降级。**

**定义 244（人类反应视界与 CSC-U）** `m_human = v_max·(t_react + t_handover)`。认证前缀 `k* ≤ min(m, m_human)`。在 `unknown` 状态下，证书要求对 `H_unk` 做**联合最坏膨胀**而非单球膨胀；若无法在预算内认证，则 `k*=1` 或 `safe_idle`。**绝不因为「还没归因」就先按健康执行。**

**定义 245（RSC-U 可撤销人类先验）** `r_geo/r_force/r_model` 可被人反馈以权重 `w_h=f(τ_t,c_t)` 软更新，但不得低于证据下界；所有人类更新带版本号、可回滚。`H_unk` 时三球联合膨胀 `r=√(r_geo²+r_force²+r_model²)` 并降低 `k*`。人类反馈不能把未知变成已知——只有 DPC 准入可以。

**定义 246（CSP-U 采集感知规划）** 在块级规划中加入信息型元技能 `{ask_label, request_demo, silent_observe, handover_point}`；块边代价为

`J_block = 执行代价 + λ_q E[注意力] + λ_risk·P(需升级)`，

每条块边必须附带安全停止点与移交点。技能签名绑定 `(故障签名, 查询历史)`；查询历史异常（例如从未查询却突然高置信）即判 OOD。

**定义 247（AIC-U 人因对抗认证）** `ℰ_U = ℰ_V × ℰ_human`，`ℰ_human` 含疲劳、迎合/讨好、恶意标签、社会工程、解释注入、习惯化、操作员缺席。`ρ_dir` 在最坏人因下重算；显式建模**共因**：同一场景同时拖慢感知、诱导错误标签、并让解释显得可信。共因下不要求归因正确，只要求判 `unknown/ambiguous` 并安全升级。

**定义 248（ATTUNE 证书 J_attune）** 

`J_attune = (J_vista, open_set_pvalue, unknown_flag, query_budget_spent, trust_calibration, explanation_hash, human_provenance_hash, escalation_level, aic_u_ver)`。

验证规则：

`Valid(J_attune) ⇔ Valid(J_vista)`
`∧ (unknown 已拒识并升级 ∨ 已认证归因)`
`∧ query_budget_spent ≤ B`
`∧ ¬overclaim(explanation)`
`∧ human_provenance_valid`
`∧ (human_unavailable ⇒ 未以人类沉默否定故障)`
`∧ safety_net_present`

### IP-224 OADR（开集归因与拒识）

```python
class OpenSetAttribution:
    """已知子空间投影 + 正交新颖度 + conformal p 值。未知不参与 softmax。"""
    def __init__(self, basis_S, Sigma_inv, calib_novelty, alpha_os=0.05,
                 delta_fi=0.15):
        self.P = projection(basis_S)          # 到已知故障子空间
        self.Si = Sigma_inv
        self.calib = np.sort(calib_novelty)
        self.alpha_os, self.delta_fi = alpha_os, delta_fi

    def novelty(self, rho):
        r = rho - self.P @ rho
        return float(r @ self.Si @ r)

    def p_value(self, rho):
        nu = self.novelty(rho)
        n = len(self.calib)
        ge = np.searchsorted(self.calib, nu, side='left')
        return (1 + (n - ge)) / (n + 1)

    def attribute(self, rho, known_lik, prior):
        p_unk = self.p_value(rho)
        logp = {h: np.log(known_lik[h](rho) + 1e-12) + np.log(prior[h])
                for h in known_lik}
        z = np.array(list(logp.values())); z -= z.max()
        post = {h: float(np.exp(v) / np.exp(z).sum()) for h, v in logp.items()}
        h_star = max(post, key=post.get)
        if p_unk <= self.alpha_os:
            return 'unknown', p_unk, post              # 诚实拒识
        if post[h_star] >= 1.0 - self.delta_fi:
            return 'known', p_unk, post
        return 'ambiguous', p_unk, post
```

### IP-226 CAQ（成本感知的主动采集）

```python
class CostAwareQuery:
    QUERIES = ('self_probe', 'silent_log', 'label_query', 'demo_request',
               'preference_query', 'confirm_query', 'veto_request')

    def choose(self, state, rho, b_user, budget_left, f_safe, eps_strain):
        best, best_ratio = None, -np.inf
        for q in self.QUERIES:
            if not self._safe_and_reversible(q, f_safe, eps_strain):
                continue                              # 不可逆动作禁止作为采集
            if self._cost(q, b_user).total > budget_left:
                continue
            if b_user.availability < A_MIN and q != 'silent_log':
                continue                              # 人不在就别问人
            eig = self._expected_open_set_info_gain(q, state, rho, b_user)
            cost = self._cost(q, b_user).total
            ratio = eig / (cost + 1e-9)
            if ratio > best_ratio:
                best, best_ratio = q, ratio
        if best is None or best_ratio < DELTA_QUERY:
            return 'silent_log', {'deferred': True, 'ratio': best_ratio}
        return best, {'deferred': False, 'ratio': best_ratio}

    def _cost(self, q, b_user):
        return Cost(phys=R_PHYS[q],
                    attn=ATTN[q] * (1 + b_user.workload),
                    trust=TRUST[q] * (1 + b_user.trust_miscal),
                    delay=DELAY[q])

    def _expected_open_set_info_gain(self, q, state, rho, b_user):
        # 对未知的 H_unk 与已知假设做期望后验熵下降；用用户能力 c 折扣
        post = self._predict_post(q, state, rho)
        return b_user.competence * (entropy(self.post0) - entropy(post))
```

## 4. 推导

**引理 9（开集拒识的有限样本保证）** 假设标定与测试样本可交换，`ν_i` 与 `ν(ρ)` 独立同分布。则 conformal p 值满足 `P[p_unk(ρ) ≤ α_os] ≤ α_os`，即**把真正未知的样本判成 `known` 的概率 ≤ α_os**（等价于在零假设「ρ 来自已知分布」下的第一类错误控制）。拒识功效（把真正的未知判为 unknown 的概率）由已知子空间与新颖方向的分离度 `κ_os = d(𝒮, span(B_new)) / σ_ρ` 控制：`κ_os` 越大，`ν(ρ_unk)` 越集中在标定分位数之上。若分布漂移破坏可交换性，改用 anytime-valid e-value：`E_t = ∏ exp(λ_t ν_t − ψ(λ_t))`，在任何停时 `P[∃t: E_t ≥ 1/α] ≤ α`，保证长期不虚警。∎

**引理 10（查询的最优停止与预算界）** 设第 m 次查询的期望信息增益 `g(m)` 关于 m 递减（信息饱和），成本 `c(m)` 关于 m 递增且凸（注意力疲劳）。则 `g(m)/c(m)` 单调下降，最优停止规则为「首次 `g(m)/c(m) < δ_query` 即停」。因每次查询成本 `≥ c_min`，查询总数 `N_q ≤ B/c_min`。又因 `a_t` 可随时降到 `a_min` 以下，CAQ 有降级出口 `silent_log`，故不存在「无限追问」或「追问致死」的路径。∎

**引理 11（信任校准的有界收敛与不可辨识性）** 在平稳段，若 `R_true` 可由滚动统计一致估计、干预有界、用户模型可撤销，则 `CE_t` 的滑动平均以 `O(1/√n)` 收敛到 0（标准随机逼近）。但当人类反馈本身有偏（系统性迎合或疲劳）时，观测模型 `p(o|u)` 与 `R_true` 不可同时辨识（观测等价类非单点），此时 `CE` 只能给最坏界 `|τ−R_true| ≤ |τ−R̂| + |R̂−R_true|`，后项需由独立审计（外部核验/离线复核）估计。**故 TCE 只能缩小可辨识的那部分误差，不能消灭系统性偏差。**∎

**定理 9（ATTUNE 端到端）** 在 A94–A99 下：

1. **已知故障不弱于 VISTA**：当 `state='known'` 时 OADR 退化为 VISTA 的 FIR 后验，处置规则相同；
2. **未知故障不再被强行归类**：由引理 9，`P[未知误判为 known] ≤ α_os`；被拒识者进入 `H_unk` 联合膨胀与 HAI 升级；
3. **采集受预算与安全约束**：CAQ 只在可逆动作集内选择，且引理 10 给出 `N_q` 上界；
4. **数据不直接改安全真值**：新故障只有过 DPC 认证准入（定义 240）才进入 `ℋ_known`，人类反馈只作可撤销软先验（定义 245）；
5. **协同不劣于基线**：安全网 `V = max(V_ATTUNE, V_VISTA, V_no_human)` 与 `safe_idle` 出口保证；
6. **证书六层链**：`Valid(J_attune)` 同时约束归因、开集、预算、解释、provenance 与升级等级。∎

**定理 10（人类失误下的有界遗憾）** 设人类反馈中以比例 `ε_h` 为恶意或系统性错误，其余为无偏。采用 provenance 分组 + 鲁棒聚合（截尾均值/中位数），则字典更新后的风险满足

`Risk ≤ Risk_VISTA + ε_h·L_h + O(1/√n)`，

其中 `L_h` 为单条错误反馈可造成的最大风险增量。由于每条更新带版本号且可按 provenance 回滚，恢复时间满足 `T_recover ≤ T_detect + T_rollback`，与数据量无关（版本化回滚为 O(1) 索引）。当 `ε_h → 0` 时退化为 VISTA 的风险。∎

**命题（用户体验作为安全约束，而非事后指标）** 若把 `R_att`、`R_trust`、`CE` 直接写入 `J_attune` 与 CAQ 目标，则「打扰过多导致疲劳」与「解释过度声明导致盲从」都会使证书非法，从而在**规划期**被排除，而不是在用户研究后才发现。这把 UX 从「评估指标」提升为「可行域约束」，与第 65 轮把 `visual_unobservable` 写入证书同构。∎

## 7. 已知风险

**一句话**：ATTUNE 把「人」从兜底变成闭环内的证据源与预算项，于是所有开集拒识、查询选择与信任校准都共同依赖一个更隐蔽的假设——**人至少在统计意义上是可校准、非对抗、且注意力成本可被正确估价的**；一旦操作员疲劳、迎合或遭遇社会工程，系统会把「问出来的错误标签」经 DPC 洗成「已知故障」，再用一份看起来很克制的解释去强化人的过度信任，形成**用采集数据自我确认、用解释包装无知的闭环**，此时「开集」反而比闭集更危险，因为它让人误以为系统已经知道自己不知道什么。

**次级风险与缓解**：

1. **开集拒识的功效依赖分离度 `κ_os`**：低秩假设失效或新颖方向与已知子空间近正交度低时，未知可能被误判为 known；缓解：分视界/分工况标定 `α_os`，`κ_os` 低于阈值时直接判 ambiguous，不追求高检出。
2. **conformal 的可交换性在漂移下失效**：缓解：anytime-valid e-value + 在线重校准 + 漂移检测；覆盖率下降即提高 `α_os`。
3. **用户模型不可辨识**：`τ`、`c`、`R_true` 可能观测等价；缓解：只把可辨识部分用于决策，其余退回总体先验；独立审计估计系统性偏差。
4. **主动采集的选择偏差**：只在「已看见」处采集，长尾可能永远不被覆盖；缓解：保持固定比例的影子/探索采集，记录覆盖度，对未覆盖区域标注 `unknown`。
5. **数据投毒与迎合偏差**：单条错误标签经字典转正可长期污染；缓解：provenance + 鲁棒聚合 + 认证准入 + 版本化回滚。
6. **解释操纵与过度声明**：解释本身可能是「社会工程」的入口；缓解：反过度声明硬约束、解释哈希审计、外部复核。
7. **查询预算与任务效率的张力**：保守预算可能导致系统频繁 `safe_idle`，实用性下降；缓解：按任务风险分级预算，显式报告「因预算放弃采集」的比例。
8. **实时预算**：实时流虽只增轻量项，但否决监听与查询前缀派发仍需硬实时；缓解：否决通道独立于语义流，看门狗兜底。
