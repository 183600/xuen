# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「平衡控制」×「数据集构建」）

> 第 54 轮把技能组合提升为动作-鲁棒性双证书。本轮追问一个被前几轮默认成立的前提：**平衡**。核心矛盾：H22：ρ 与 α_S 都把“不摔倒/不失稳”当作隐式背景条件，但平衡裕度在技能组合上是**非可加**的，两个各自稳定的技能拼接后可能因质心迁移、支撑多边形切换而出现“平衡侵蚀”；H23：动作剖面 α_S 的采样与数据集构建彼此脱节，数据集在平衡边界附近系统性欠采样，而失效恰恰集中在边界，于是证书在“幻影边界”上成立。

## 0. 直觉与动机

**灵感 1（平衡裕度场 → 把“不失稳”从布尔前提变为可微的场）**
直觉：技能 S 的每个动作 a 都有一个平衡裕度 `β_S(a)`（ZMP 到支撑多边形边界的有符号距离，或捕获点裕度）。之前 `α_S(a)∈[0,1]` 只回答“能不能做”，`β_S(a)` 回答“做完还能站多稳”。把 `β_S : A → ℝ∪{+∞}` 作为与 α_S 并列的第一性剖面：动作可行域应收缩为 `A_S^β = {a | α_S(a)≥θ_cov ∧ β_S(a) ≥ β_min}`。这把平衡从隐含假设变成显式约束。

**灵感 2（平衡侵蚀 → 组合的非可加失效模式）**
直觉：组合的平衡裕度不是 `min(β_i, β_j)`。质心迁移、支撑脚切换、手臂反作用都会产生交互项。定义平衡侵蚀 `Δβ_{ij}(a) = min(β_i(a),β_j(a)) - β_{i⊗j}(a)`。Δβ 可正可负（协同可增益），但负值意味着“单看都稳、合起来晃”。组合图 G_S 的每条边必须附 Δβ 预算，`sup_a Δβ_{ij}(a) > ε_bal` 直接否决。这把第 54 轮的 compat 从静态动作交集升级为**动态平衡守恒**。

**灵感 3（平衡分层数据集 → 数据集构建的第一次严谨化）**
直觉：均匀采样动作空间是低效的，因为失效集中在 `β≈β_min` 的边界层。构造 **平衡分层数据集** `D = ⋃_k D_k`，按 β 区间分层（安全层、边界层、近失效层、失效层），每层给足样本，并强制边界层过采样。数据集不再是一堆轨迹，而是**带平衡分层的证据结构**。

**灵感 4（分布平衡控制 → “平衡”的第二个含义）**
直觉：数据集的“平衡”不只是机器人平衡，也是**分布平衡**。把采样分布 q 当作控制量，目标是让最差平衡层的风险最小，同时不让 q 偏离先验 p0 太远：`min_q max_k R_k(q) s.t. KL(q||p0) ≤ ε`。这是分布鲁棒优化：既“平衡控制”了机器人，也“控制平衡”了数据。两层含义在此收敛为同一个算子。

**灵感 5（数据集覆盖证书 → 让数据成为证书的一部分）**
直觉：证书 J 里的 evidence 目前是散落的仿真反例。把它升级为 **数据集覆盖证书 `C_data = (D, {D_k}, cov, gap_2r, CE)`**：每个平衡层有覆盖率 cov_k，有边界反例 CE，有 sim2real 间隙上界 gap_2r。没有 C_data 的 J 不允许部署——**数据本身要被认证**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（平衡裕度场）**
动作空间 A 上的平衡裕度场 `β_S : A → ℝ ∪ {+∞}`，`β_S(a) = dist(ZMP(a), ∂P_support(a))`（支撑多边形边界有符号距离，多边形内为正）。**平衡可行域** `A_S^β = {a ∈ A | β_S(a) ≥ β_min}`。约定 `β=+∞` 表示该动作不改变支撑状态（如原地保持）。

**定义 122（平衡不变式与平衡侵蚀）**
组合 `S_i ⊗ S_j` 在动作 a 上满足平衡不变式当且仅当
`β_{i⊗j}(a) ≥ min(β_i(a), β_j(a)) - ε_bal`。
平衡侵蚀 `Δβ_{ij}(a) = min(β_i(a),β_j(a)) - β_{i⊗j}(a)`。第 54 轮组合可判定条件新增一项：`sup_{a∈A_core} Δβ_{ij}(a) ≤ ε_bal`。

**定义 123（平衡分层数据集）**
数据集 `D = ⋃_{k=0}^{3} D_k`，层由裕度划分：`D_0` 安全层 `β ≥ 2β_min`；`D_1` 边界层 `β_min ≤ β < 2β_min`；`D_2` 近失效层 `0 ≤ β < β_min`；`D_3` 失效层 `β < 0`。层权重 `w_k`，边界层强制 `|D_1| ≥ η·|D|`。

**定义 124（数据集覆盖证书）**
`C_data = (D, {D_k}, cov, gap_2r, CE)`：
- `cov_k = |{a ∈ A_core | ∃d∈D_k, ||a-a_d|| ≤ δ}| / |A_core|` 为第 k 层对核心动作域的 δ-覆盖；
- `gap_2r` 为 sim2real 间隙上界（由成对真实/仿真轨迹估计）；
- `CE` 为边界层反例集。
若 `min_k cov_k ≥ θ_data` 且 `gap_2r ≤ Θ_2r` 且 `CE ≠ ∅`，称 D 为 **平衡覆盖的**。

**定义 125（分布平衡控制）**
采样分布族 `Q = {q : D_KL(q||p0) ≤ ε}`。平衡控制目标
`q* = argmin_{q∈Q} max_k R_k(q)`，其中 `R_k(q) = E_{a~q|D_k}[ℓ(fail | a)]` 为层 k 的条件风险。对偶地，`q* ∝ p0 · exp(λ_k*/τ)`（层内指数倾斜），λ* 由最大层风险拉平（water-filling 对偶上升）。

**定义 126（平衡-数据联合证书 BJC）**
`J^β = (J, β, Δβ, C_data)`：
- J 为第 54 轮动作-鲁棒性联合证书；
- β 为平衡裕度场，Δβ 为组合平衡侵蚀上界；
- C_data 为数据集覆盖证书。
部署条件：`dom_J(T)=in ∧ δ_a<Θ_a ∧ sup Δβ ≤ ε_bal ∧ min_k cov_k ≥ θ_data ∧ gap_2r ≤ Θ_2r ∧ CE≠∅`。

## 2. 关键算法 伪代码

### IP-121 BCF（Balance Cost/Field）

```python
def balance_field(skill, A, sim, beta_min):
    beta = {}
    for a in A:
        zmp  = sim.zmp(skill, a)
        poly = sim.support_polygon(skill, a)
        beta[a] = signed_dist(zmp, poly)          # >0 稳定
    feasible = {a for a, b in beta.items() if b >= beta_min}
    return beta, feasible
```

### IP-122 BAL-DS（Balance-Aware Dataset Synthesis）

```python
def build_balanced_dataset(skills, A_core, sim, budget, theta_data, eta):
    D = {0: [], 1: [], 2: [], 3: []}
    for a in boundary_seed(A_core):                # 先播种边界
        b = sim.query_balance(a)
        D[stratum(b)].append((a, b))
    while used(D) < budget:
        k = argmax_stratum_uncertainty(D)          # 最不确定且覆盖最低的层
        a = acquisition(D, k, beta_surrogate(D))   # 不确定度 + 边界邻近 + 推扰
        b, fail = sim.rollout_with_push(a, push=red_team_push())
        D[stratum(b)].append((a, b, fail))
        if coverage(D, A_core) >= theta_data and len(D[1]) >= eta*len(D):
            break
    return D
```

### IP-123 BEC（Balance Erosion Check）

```python
def balance_erosion(si, sj, A_edge, beta, eps_bal):
    worst = 0.0
    for a in A_edge:
        b_i = sim.zmp(si, a)                       # 单技能裕度
        b_j = sim.zmp(sj, a)
        b_comp = sim.zmp_compose(si, sj, a)        # 组合裕度
        worst = max(worst, min(b_i, b_j) - b_comp)
    return ('ok' if worst <= eps_bal else 'reject', worst)
```

### IP-124 DCC（Dataset Coverage Certifier）

```python
def certify_dataset(D, A_core, delta, theta_data, theta_2r):
    cov = {k: covered(D[k], A_core, delta) for k in D}
    gap = estimate_sim2real_gap(D)                 # 成对真实/仿真
    CE  = [d for d in D[1] if d.fail]
    ok = (min(cov.values()) >= theta_data
          and gap <= theta_2r and len(CE) > 0)
    return ('ok' if ok else 'reject', DataCert(D, cov, gap, CE))
```

### IP-125 DBC（Distributional Balance Control）

```python
def balance_sampling(p0, strata, eps, lr=0.05, T=50):
    lam = {k: 0.0 for k in strata}
    q = dict(p0)
    for _ in range(T):
        R = {k: empirical_risk(q, k) for k in strata}
        k_max = argmax(R)
        for k in strata:                           # water-filling 对偶上升
            lam[k] += lr * (R[k] - R[k_max])
        q = normalize({a: p0[a] * exp(lam[stratum(a)]) for a in p0})
        q = kl_project(q, p0, eps)                 # 投影回 KL 球
    return q
```

### IP-126 BJC（Balance-Joint Certificate）

```python
def balance_joint_certificate(skill_seq, A_core, beta, eps_bal,
                              C_data, theta_data, theta_2r):
    if min(C_data.cov.values()) < theta_data or C_data.gap > theta_2r:
        return ('reject', 'data_not_covering', C_data)
    worst = max(balance_erosion(si, sj, A_core, beta, eps_bal)[1]
                for si, sj in pairs(skill_seq))
    if worst > eps_bal:
        return ('reject', 'balance_erosion', worst)
    J = joint_certificate(skill_seq, gamma_ce, delta_a_budget, rho_min)
    if J[0] != 'ok':
        return J
    return ('ok', JointCert_Beta(J[1], beta, worst, C_data))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| BCF | O(|A|·c_sim) | O(|A|) | ZMP/支撑多边形模型与接触模式一致 |
| BAL-DS | O(B·c_sim) | O(B) | 分层完备、边界层过采样 |
| BEC | O(|A_edge|·c_sim) | O(1) | 侵蚀 sup 可估、组合真值可查询 |
| DCC | O(Σ_k|D_k|·|A_core|) | O(|D|) | δ-覆盖可判定、gap_2r 可估 |
| DBC | O(T·|strata|·B) | O(B) | KL 投影收敛、对偶间隙有界 |

**正确性定理（Balance-Aware Composition Soundness）**
承接第 54 轮 (A26)–(A28)；新增 **(A29)** 平衡裕度场 β 在接触模式不变区间内 Lipschitz 连续、接触切换点单独标注；**(A30)** 数据集对每个平衡层的核心动作域 δ-覆盖，且 sim2real 间隙 `gap_2r` 有一致上界；**(A31)** 组合侵蚀 `Δβ` 可被边端仿真 sup 估计，估计误差 ≤ ε_est。
则部署后失稳概率
```
P_fall ≤ Σ_k w_k·(1-cov_k) + P(Δβ > ε_bal) + gap_2r + ε_est
```
即：**数据覆盖、平衡侵蚀、sim2real 间隙三者相加构成失稳上界**。当 `cov_k→1, gap_2r→0, Δβ≤ε_bal, ε_est→0` 时退化为第 54 轮结论。**推论（边界优先）**：在固定数据预算 B 下，若失效风险随 |β−β_min| 单调上升，则分层采样 q* 的失效发现率不低于均匀采样，且省下的预算可全部投入边界层。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| ZMP 模型在软接触/滑移下失真 | 高 | 力台/触觉真值校准 + 接触模式分层 + 滑移扰动 |
| 边界采样在真机上危险 | 高 | 仿真先行 + 安全吊装 + 渐进边界暴露 |
| 分布鲁棒目标过保守 | 中 | ε 自适应 + 分层拉平而非最坏层独大 |
| 平衡侵蚀不可组合（超加） | 中 | 三元组验证 + 局部线性化误差预算 |
| 数据集覆盖 ≠ 行为覆盖 | 中 | 动作-结果联合分层 + 反例驱动补充 |

## 6. 本轮最大风险

**一句话**：平衡裕度场与平衡分层数据集把“不失稳”从隐含前提变为可认证的显式约束，但其全部 soundness 依赖 **β 在接触模式切换处仍被正确估计**；一旦软接触、打滑或足底形变让仿真 ZMP 系统性偏离真值，数据集就会在一个“幻影边界”上做到漂亮的分层覆盖，证书认证的是一个不存在的安全边界，故必须以力台/触觉真值校准、接触模式显式分层与滑移红队扰动作为硬护栏，宁可把平衡边界估得保守，也绝不把“数据集看起来平衡”当作“机器人真的平衡”。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（BCF×BAL-DS×BEC×DCC×DBC×BJC）

> 承接第 54 轮产物 v31。本轮把被默认成立的“平衡”前提显式化，并第一次把 **数据集构建** 纳入证书体系：

```python
    if min(C_data.cov.values()) < theta_data or C_data.gap > theta_2r:
        return ('reject', 'data_not_covering', C_data)
    worst = max(balance_erosion(si, sj, A_core, beta, eps_bal)[1]
                for si, sj in pairs(skill_seq))
    if worst > eps_bal:
        return ('reject', 'balance_erosion', worst)
    J = joint_certificate(skill_seq, gamma_ce, delta_a_budget, rho_min)
    if J[0] != 'ok':
        return J
    return ('ok', JointCert_Beta(J[1], beta, worst, C_data))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| BCF | O(|A|·c_sim) | O(|A|) | 接触模式一致的分段 Lipschitz |
| BAL-DS | O(B·c_sim) | O(B) | 分层完备、边界层过采样 |
| BEC | O(|A_edge|·c_sim) | O(1) | 侵蚀 sup 可估、真值可查 |
| DCC | O(Σ_k|D_k|·|A_core|) | O(|D|) | δ-覆盖可判定、gap_2r 可估 |
| DBC | O(T·|strata|·B) | O(B) | KL 投影收敛、对偶间隙有界 |
| BJC | O(|S|·|A_core|·c_sim) | O(|A_core|) | 三层否决（数据/侵蚀/证书）顺序 sound |

**正确性定理（Balance-Aware Composition Soundness）**
承接第 54 轮 (A26)–(A28)；新增 **(A29)** β 在接触模式不变区间内分段 Lipschitz、切换点单独标注；**(A30)** 数据集对每层核心动作域 δ-覆盖且 `gap_2r` 有一致上界；**(A31)** `Δβ` 的边端 sup 估计误差 ≤ ε_est。则
```
P_fall ≤ Σ_k w_k·(1-cov_k) + P(Δβ > ε_bal) + gap_2r + ε_est
```
**推论 1（边界优先）**：若失效风险随 `|β−β_min|` 单调上升，固定预算下分层采样 q* 的失效发现率 ≥ 均匀采样；剩余预算全部投入 D_1 使 `P(Δβ>ε_bal)` 估计更紧。
**推论 2（数据即证据）**：`C_data` 不满足时，即使 ρ、α_S、γ_ce 全部达标，`J^β` 也拒绝部署——数据缺口不能由模型置信度填补。

## 6. 本轮最大风险

**一句话**：平衡裕度场与平衡分层数据集把“不失稳”从隐含前提变为可认证的显式约束，但其全部 soundness 依赖 **β 在接触模式切换处仍被正确估计**；一旦软接触、打滑或足底形变让仿真 ZMP 系统性偏离真值，数据集就会在一个“幻影边界”上做到漂亮的分层覆盖，证书认证的是一个不存在的安全边界，故必须以力台/触觉真值校准、接触模式显式分层与滑移红队扰动作为硬护栏，宁可把平衡边界估得保守，也绝不把“数据集看起来平衡”当作“机器人真的平衡”。
