# 第 45 轮（承接第 44 轮 v21；本轮灵感：本体感知 × ROS） · Proprio-Cert × Transport-Cert：把「本体感知」升为与姿态互补的根信任，把「ROS 传输/时钟」升为证书的因果契约（五层架构 v10）

> 承接第 44 轮 v21（Pose-Cert × Data-Cert）。v21 自陈最大风险是「审计集与采集策略不独立 → 覆盖自我确认（Goodhart）」，但它与整个 v21 证书栈还共享两个更底层的未言明假设：**(H4a) 外感知姿态是唯一的根信任，本体感觉只是运动提示**；**(H4b) 证书是一个「本地、原子」的对象——在某一时刻算出来，之后任何消费者只要拿到一个合法 TF 就等价于在用同一物理状态**。真实 UniBot 只有四路 RGB + 本体感觉（关节编码器、IMU、轮速、电机电流），没有深度/力/触觉，且运行在 ROS 上：TF2 是带时间缓存（`TimePointZero` 会静默取最新）、QoS `BEST_EFFORT` 会静默丢包、跨节点时钟会漂、节点会重启、外参/标定版本可能混用。于是出现 v21 完全没有覆盖的失效模式：**证书在生产端 sound，却在消费端静默不 sound**。两个灵感词精确命中 H4：**本体感知**迫使我们承认「身体」是第二个根——它对场景（透明/镜面/弱纹理）不敏感，但对滑移、柔性、背隙、标定漂移敏感，是外感知的姿态互补量；**ROS**迫使我们承认「传输与时间本身就是证明的一部分」——证书不是一张静态表，而是一个跨节点、跨时钟域、跨帧、跨 QoS 等级的分布式对象。二者耦合出本轮真正的新问题：**本体感知可以桥接外感知的空窗，但桥的合法性依赖 ROS 因果链；而本体感知的标定又来自外感知数据，标定误差是两路的共模项，会在融合时被重复计数或悄悄抵消，把 Goodhart 从「采集层」搬到了「标定根」。**

## 0. 直觉与动机

**灵感 1（本体感知 → 身体是第二个根，但它是「相对根 + 共模漂移」）**
直觉：外感知回答「我在世界的哪里」，本体感觉回答「我相对上一刻动了多少」。前者绝对但对场景敏感，后者对场景不敏感但只给增量、且误差沿路径累积。把本体证书写成增量集合 K_t = {ΔX : d(ΔX, ΔX̂_t) ≤ r_ψ}，其中 ψ 是本体可观测性分层（编码器分辨率、背隙、关节速度/加速度、力矩-电流残差、滑移指示、柔性/柔顺估计、IMU 偏置漂移、温度、轮径/外参标定年龄）。姿态沿运动链传播为 X_{t+Δ} ∈ X_t ∘ K_t。关键直觉：**本体误差不是「每步独立噪声」，而是「共模标定偏差 × 路径长度 + 独立噪声」**；若把共模项当独立项按步数开方，drift 会被低估一个数量级。因此本体证书的半径必须写成路径泛函，而不是时间的简单函数。

**灵感 2（ROS → 证书的 soundness 必须在消费端成立，传输/时钟是证明的一部分）**
直觉：v21 的租约只问「姿态多久没刷新」，却不问「这张证书是怎么到我手里的」。在 ROS 图里，一条安全消息可能：被 `BEST_EFFORT` 丢掉；被 DDS 重排/重复；时间戳来自另一个时钟域；TF 查询用了「最新」而不是「精确时刻」；外参标定版本与生产端不一致；节点重启后 epoch 变了但 seq 归零。任何一项都足以让「生产端 sound 的证书」在消费端对错状态使用。于是给每条证书加一枚**传输护照** T = (frame_chain, calib_version, clock_domain, t_stamp, t_recv, seq, epoch, qos_class, source_node)，并定义**消费端闸门**：帧链连通、外参版本精确匹配、精确时刻 TF 可查、时钟偏移 + 传输延迟 ≤ δ_sync、seq 单调且 epoch 未变、QoS 等级满足关键级、t_recv−t_stamp ≤ deadline。任一不满足即证书不可用，而不是「凑合用最新 TF」。

**灵感 3（耦合 → 桥接、共模融合与传输红队）**
直觉：外感知退化（透明/镜面/空洞/遮挡）时，本体感觉可以短期桥接姿态；但桥必须同时满足「本体证书有效」与「ROS 因果链有效」，且桥的漂移会随时间/路径增长，必须在租约内被外感知刷新。融合时最容易犯的错是「两路独立、取交集更紧」：**两路共享同一套外参/轮径/编码器标定，标定误差是共模的**；在标定集上两路都「覆盖很好」，部署时一起偏，交集看起来更紧却对真实姿态漏覆盖。正确做法不是假设独立，而是**在标定证书 C_cal 上做边缘化并集**：P_fuse = ⋃_{c∈C_cal} (P_ex(c) ∩ P_pr(c))，把共模项显式抬成半径；代价是可用性下降，必须用实验诚实度量。再往外一层，用 **ROS bag 回放 + 故障注入**（时钟跳变、丢包、重排、重启、陈旧 TF、标定版本混用）做传输红队，把「消费端覆盖」也纳入审计。

**耦合升级**：PSE（姿态证书）与新增 KCE（本体证书）在 C_cal（标定证书）上做共模感知融合，得到 P_fuse；新增 TCG（传输/时间证书守卫）在消费端把 P_fuse 的可用性绑定到 ROS 因果链；新增 CGA（证书图审计器）用 bag 回放与故障注入做端到端覆盖红队。四层架构由 v9 的「姿态根信任 + 校准数据治理」升级为 v10：底部加一层**分布式传输与时间底座**，根信任由「单根姿态」升级为「姿态 + 本体 + 标定 + 时钟 + 传输」的多根因果图。

## 1. 形式化定义（增量：定义 50–55）

**定义 50（本体感知运动学证书与分层）**
设本体可观测性分层 ψ_t = (n_enc, b_back, v_joint, a_joint, r_tau, s_slip, c_comp, β_imu, T_temp, a_calib) 为离散化条件向量（编码器有效位、背隙、关节速度/加速度、力矩-电流残差、滑移指示、柔顺估计、IMU 偏置漂移、温度、标定年龄）。本体增量证书 K_t ⊆ SE(3) 满足**条件覆盖**：
P(ΔX_t ∈ K_t | ψ_t = ψ) ≥ 1 − α_k, ∀ψ ∈ Ψ_obs。
构造：ΔX̂_t 由编码器 + IMU + 轮速的因子图/预积分给出；半径 r_ψ = Q_{1−α_k}(d(ΔX, ΔX̂) | ψ)。沿运动链组合：X_{t+Δ} ∈ X_t ∘ K_t（SE(3) 集合组合，非简单加法）。**路径漂移界**：
r_proprio(t) ≤ γ_cal·‖e_cal‖·ℓ_path(t) + Σ_k ε_indep(ψ_k) + β_bias·(t−τ_0) + ε_temp,
其中 ℓ_path 是累计路径长度，γ_cal 是共模放大系数（标定误差随路径线性放大），ε_indep 是独立噪声。**未观测层** ψ ∉ Ψ_obs、检测到滑移/柔顺模式、或标定年龄超界时不签发本体证书。

**定义 51（共享标定下的异构融合；反对朴素求交）**
设外感知证书 P_ex 与本体传播证书 P_pr 共享标定 nuisance e_cal（头部外参、轮径、编码器偏置、IMU 外参），标定证书 C_cal 满足 P(e_cal ∈ C_cal) ≥ 1 − α_c。**朴素求交 P_ex ∩ P_pr 不构成 sound 融合**：两路半径都是在「估计标定」上校准的，部署时若真值 c* 偏离，二者同向偏移；在标定集上覆盖率好看，部署上可同时漏掉真值。**共模感知融合规则**：
P_fuse = ⋃_{c∈C_cal} (P_ex(c) ∩ P_pr(c))。
**覆盖命题**：若 c* ∈ C_cal、X_t ∈ P_ex(c*)、X_t ∈ P_pr(c*)，则 X_t ∈ P_fuse；故
P(X_t ∈ P_fuse) ≥ 1 − α_c − α_p − α_k（并集界，不假设两路独立）。
**共模反重复计数命题**：若把 e_cal 当作每步独立噪声，drift 界低估因子可达 ℓ_path/√N；因此 KCE 的半径必须显式含 γ_cal·‖e_cal‖·ℓ_path 项，且 C_cal 必须作为独立根进入因果图。代价：P_fuse 比朴素交集宽，可用性损失必须实测（E104）。

**定义 52（ROS 传输与时间证书）**
每条证书携带传输护照 T = (frame_chain, calib_version, clock_domain, t_stamp, t_recv, seq, epoch, qos_class, source_node)。**有效性谓词** Valid(T, κ)（κ 为关键级）当且仅当：
1. frame_chain 连通，且每段外参版本 == calib_version（禁止混版）；
2. 精确时刻 t_stamp 的 TF 可查（禁止 `TimePointZero`/latest 回退），插值残差 ≤ ε_interp；
3. |clock_offset| + δ_queue + δ_interp ≤ δ_sync(κ)（同一 clock_domain 或有界同步）；
4. seq 在 epoch 内严格递增（重复/重排检出），epoch 与生产端一致（节点重启检出）；
5. qos_class ≥ required(κ)（安全关键必须 RELIABLE + deadline；BEST_EFFORT 仅允许非安全信息）；
6. t_recv − t_stamp ≤ deadline(κ)。
**传输 soundness 命题**：若 Valid(T,κ)，则消费端使用的证书对应 t_stamp 时刻的物理状态，误差被 δ_e2e 界住；若 ¬Valid(T,κ)，则证书必须不可用（fail-closed），不得降级为「用最新 TF 凑合」。

**定义 53（端到端时间膨胀与桥接窗口）**
定义 δ_e2e = |clock_offset| + δ_queue + δ_interp + δ_qos。消费端证书必须做**运动膨胀**：
P_consumed ⊇ P_fuse(t_stamp) ⊕ Ball(v_max·δ_e2e)（或等价地用租约 r(t_stamp)+v_max·δ_e2e）。
新鲜度判据：r_fuse(t_stamp) + v_max·δ_e2e ≤ r_max(θ, φ)。
**桥接窗口**：仅当 PSE 无新证书、KCE 有效、TCG 有效且 r_proprio(t) ≤ r_max 时，允许用本体桥接；一旦桥接累计路径 ℓ_path 或时长超界，或 C_cal 过期，立即 fail-closed。

**定义 54（证书因果图与多根信任）**
证书因果图 G = (V, E)，边类型 E_type ∈ {sensor, calib, clock, transport, pose, proprio}。根集合 R = {外感知姿态根, 本体根, 标定根, 时钟根, 传输根}。节点有效：
Valid(v) = local_check(v) ∧ ∀(u→v) Valid(u) ∧ edge_condition(u→v)。
其中 calib 边要求版本精确匹配、clock 边要求同一时钟域且在租约内、transport 边要求 Valid(T,κ)、pose/proprio 边要求集合组合有效。**级联命题**：任一 u ∈ R 失效 ⇒ 所有后代 v 失效（fail-closed），禁止「局部降级后继续用」。这严格推广定义 46 的单根姿态租约。

**定义 55（本体-传输覆盖驱动的采集与审计）**
数据护照扩展为 π_i = (…, ψ, τ, calib_role, clock_domain, bag_id, qos_events)。分层从单一 ω 扩展为三元 (ω, ψ, τ)，τ 是传输/时间故障类（丢包、重排、时钟跳变、重启、陈旧 TF、标定版本混用）。采集效用
U(ω,ψ,τ) = [Δgap·S_φ] / [cost + c_risk·Risk]，
在最坏三元层上取最大；审计独立性公理不变（A ⟂ (D_cal, π_acq)），并新增**回放确定性**：同一 bag 回放必须产生相同的 Valid/Invalid 判定（否则闸门本身不可审计）。投毒测试扩展为注入陈旧 TF/时钟跳变/标定版本提升，要求证书不静默接受。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-63 KIN-CERT-ENGINE（本体感知运动学证书引擎 KCE）
1. **本体分层 ψ**：编码器有效位/背隙/关节速度加速度/力矩-电流残差/滑移/柔顺/IMU 偏置/温度/标定年龄。
2. **增量证书与组合**：因子图/预积分给出 ΔX̂ 与协方差，按层共形半径 r_ψ；SE(3) 集合组合沿运动链传播。
3. **路径漂移界**：显式区分共模标定项 γ_cal·‖e_cal‖·ℓ_path 与独立项；输出桥接可用时长/路径上界。
4. **滑移/柔顺/背隙检测**：力矩-电流/轮速-编码器一致性残差触发本体降级；未观测层拒发证书。

### 2.2 IP-64 TRANSPORT-CERT-GUARD（传输/时间证书守卫 TCG）
1. **传输护照**：frame_chain/calib_version/clock_domain/t_stamp/t_recv/seq/epoch/qos_class/source_node。
2. **消费端闸门**：精确时刻 TF、版本匹配、时钟偏移界、seq/epoch、QoS 关键级、deadline；任一失败即 fail-closed。
3. **时间膨胀**：把 δ_e2e 转为运动膨胀 Ball(v_max·δ_e2e)，并入租约新鲜度判据。
4. **安全 QoS 契约**：安全关键话题强制 RELIABLE + deadline + 单调 seq；BEST_EFFORT 消息不得单独支撑安全谓词。

### 2.3 IP-65 CERT-GRAPH-AUDITOR（证书因果图审计器 CGA）
1. **多根因果图审计**：遍历 G，检查 calib/clock/transport 根是否有效；定位「生产端 sound、消费端 unsound」的断点。
2. **ROS bag 回放红队**：注入时钟跳变、丢包、重排、重复、节点重启、陈旧 TF、标定版本混用，验证消费端覆盖与 fail-closed。
3. **端到端覆盖审计**：在独立 bag 上估计消费端条件覆盖（按 ω×ψ×τ 分层），量化时间膨胀后的实际覆盖率。
4. **回放确定性与投毒**：同一 bag 判定可复现；注入错误标定/伪造护照/重放旧 epoch 必须检出并隔离。

## 3. 五层架构 v10

```
L0 分布式传输与时间底座（新）:
  ROS2/DDS QoS + TF2 时间缓存 + PTP/NTP/单调时钟 + node epoch + 标定版本管理
    → IP-64 TCG: 传输护照 → Valid(T,κ) → 时间膨胀 δ_e2e
    → IP-65 CGA: bag 回放 + 时钟/丢包/重排/重启/陈旧TF/混版 红队（只读）
    → 任一传输根失效 → 下游证书 fail-closed

根信任层（升级为多根）:
  IP-60 PSE(外感知姿态 P_ex, ω) + IP-63 KCE(本体增量 K, ψ) + C_cal(标定证书)
    → 定义 51 共模边缘化融合 P_fuse = ⋃_c (P_ex(c) ∩ P_pr(c))
    → 本体交叉校验/滑移/标定过期/未观测层 → 拒发或膨胀到 P_max

L1: 几何/物体 6D 位姿 → C_ms, B_t, L_m；人/多用户 → H_u
    └─ 以 P_fuse 为条件，引用 pose/proprio/calib/clock/transport 五个根
L2: CTC + VLM + IP-35 仲裁 → 分支池；检索键含 ω/ψ/calib_version
L3: IP-51 CAR(margin = min(查表, 租约衰减, persona 上限) − L_φ·rad(P_fuse) − L_φ·v_max·δ_e2e)
    → IP-49 几何 □ 提升 → IP-47 组合 → IP-39 规划
    → IP-45 总线(transport-cert/clock/epoch/calib/proprio) → IP-53 CMC 区间监控
L4: IP-61 DCL(三元层覆盖驱动采集 + 护照 + 分块加权共形)
    ← IP-62 CCA(外感知/采集覆盖红队) + IP-65 CGA(传输/时钟/因果图红队)
    → 重校准 r_ω/r_ψ/C_cal → 更新 P_fuse → IP-55 CKB + IP-54 SCV

## 5. 本轮最大风险

**一句话**：v10 把根信任从「姿态单根」扩成「姿态+本体+标定+时钟+传输」多根，但真实 ROS 图里这些根共享同一个时钟、同一套外参、同一条网络——一个未被检出的时钟跳变、标定版本混用或共模标定漂移，就可能让整个多根因果图「一致地错」，而定义 51 的标定边缘化又让证书显著变宽；因此 E104（共模融合 soundness）与 E105/E106（传输/时钟红线）必须设为不可回退的闸门，默认退回「单根姿态盒 + 精确时刻 + 安全停机」这条永不失 sound 的底线。

def make_token(msg, node, clock_domain, qos_class):
    return TransportToken(
        frame_chain = msg.header.frame_id_chain,
        calib_version = current_calib_version(msg.header.frame_id_chain),
        clock_domain = clock_domain,
        t_stamp = msg.header.stamp,

def validate_transport(T, kappa, tf_buffer, clock, node_epoch, required_qos):
    if not frames_connected(T.frame_chain):                  return False
    if not all(version_matches(f, T.calib_version) for f in T.frame_chain):
        return False                                          # 禁止混版
    tf = lookup_transform_exact(tf_buffer, T.frame_chain, T.t_stamp)
    if tf is None: return False                               # 禁止 latest 回退
    if tf.interp_residual > EPS_INTERP: return False
    delta = abs(clock.offset(T.clock_domain, clock.local_domain)) \
            + queue_delay(T) + tf.interp_residual
    if delta > delta_sync(kappa): return False
    if not seq_monotone(T): return False                      # 重复/重排
    if T.epoch != node_epoch: return False                    # 重启/旧 epoch
    if qos_rank(T.qos_class) < qos_rank(required_qos(kappa)): return False
    if T.t_recv - T.t_stamp > deadline(kappa): return False
    return True

def temporal_inflate(cert, delta_e2e, v_max):
    return cert.set + ball(v_max * delta_e2e)                 # 运动膨胀

def consumer_gate(cert, T, kappa, tf_buffer, clock, node_epoch):
    if not validate_transport(T, kappa, tf_buffer, clock, node_epoch,
                              required_qos(kappa)):
        return FailClosed('transport_invalid')                # 不凑合用最新 TF
    P = temporal_inflate(cert, delta_e2e(T, clock), v_max=kappa.v_max)
    if cert.r + kappa.v_max * delta_e2e(T, clock) > r_max(kappa):
        return FailClosed('temporal_stale')
    return P
```

def calibration_marginalized_fusion(P_ex, P_pr, C_cal):
    # 反对朴素求交：先对共享标定取并，再逐 c 求交
    return union_over(C_cal,

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 多根「一致地错」：共享时钟/外参/网络，单点共模故障穿透全图 | 高 | E104/E105/E106 红线；共模项显式建模；标定/时钟/传输作为独立根审计；fail-closed |
| 朴素求交导致部署漏覆盖（标定集好看、部署偏） | 高 | 定义 51 边缘化并集；E104 用朴素法做阳性对照，必须复现违例 |
| 共模 drift 被当独立噪声 → 桥接半径严重低估 | 高 | 路径泛函 r_proprio；γ_cal·‖e_cal‖·ℓ_path 显式项；E103/E107 红线 |
| TF latest 回退 / QoS 静默丢包 → 消费端用错状态 | 高 | TCG 精确时刻 + QoS 关键级 + deadline；E105 红线；禁止 best-effort 支撑安全谓词 |
| 融合过保守 → 几何/规划可用性崩塌 | 高 | 仅安全谓词用 P_fuse；可用性损失门槛（E104/E109）；自适应分层 |

## 6. 本轮最大风险

**一句话**：v10 把根信任从「姿态单根」扩成「姿态+本体+标定+时钟+传输」多根，但真实 ROS 图里这些根共享同一个时钟、同一套外参、同一条网络——一个未被检出的时钟跳变、标定版本混用或共模标定漂移，就可能让整个多根因果图「一致地错」，而定义 51 的标定边缘化又让证书显著变宽；因此 E104（共模融合 soundness）与 E105/E106（传输/时钟红线）必须设为不可回退的闸门，默认退回「单根姿态盒 + 精确时刻 + 安全停机」这条永不失 sound 的底线。
