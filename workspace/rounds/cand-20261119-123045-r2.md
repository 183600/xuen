# 第 14 轮（新灵感循环第 5 轮；本轮灵感：「数据标注」×「商业模式」）

> **基线**：第 13 轮 MetricVoiceGauge-NCD-HUTDH v15（IP-378–381；引理 125–130；实验 E661–E670）。
> 本轮纪律：**标注即证据 + 市场只买证据 + 尾部自融资 + 反 Goodhart**。不推倒 v15：SCD/DSD/DCA/EDC 与 v13 的 AIO/CPD/DDL/RTCR、v12 的 USG/TGC/BAA/GAGP/UC、v11/v10/v9/v8 全部保留。三个新端口——ACP（标注—证书生产函数）、BWC（预算化加权共形校准）、LCM（责任锚定证书市场）——加两个哨兵 ICL（激励相容标注审计）与 GCM（Goodhart 覆盖监视），一律以**中立元**接入，失效即严格退回 v15（引理 136），再沿 v15→v14→…→v8 退化链回退。本轮只做三件事：把"标注"从免费预处理改写为**证书的证据生产**、把"商业模式"从无关变现改写为**责任与证据成本的分摊机制**、把二者合成"标注预算→证书覆盖→定价/责任→再投资尾部标注"的自融资闭环。

## 0. 直觉与动机

**灵感 1（数据标注 → 标注是证书的铸币）**
直觉：v15 的证书全部建立在"校准集覆盖当前分布"之上，可校准集不是从天上掉下来的，是花钱标出来的。DCA 的 `ρ_cov`、SCD 的 `prob_lower`、EDC 的边界检查，本质上都在消费同一份被标注的数据；标注一旦稀疏，证书就退化为"在被标注到的地方有效"的局部真理。研究与工程习惯把标注当免费预处理，于是把最贵的部分——长尾、接触边界、危险样本——悄悄留给了部署时的漂移。核心创新：**标注—证书生产函数（Annotation–Certificate Production, ACP）**：把每个区域的标注量映射到该区域的证书余量与覆盖率，定义**单位标注的边际证书增益**。证书不再是"有/无"，而是"用多少标注买来的、在多宽的区域上有效的"。反直觉点：**应该按边际风险削减而非按模型误差来标注**——标一个模型已经会做、但证书不覆盖的样本，可能比标一个模型做错、却从不部署的样本更有价值。

**灵感 2（商业模式 → 商业模式是责任与证据的分摊机制）**
直觉：商业模式决定"谁付标注钱、谁担出错责"。纯利润最大化的标注分配天然偏向高频、可变现的场景，而长尾危险场景标注最贵、变现最弱——这恰好是证书最容易失守的地方。把商业模式当"事后变现"是错的；它其实是**证据生产的激励结构**。核心创新：**责任锚定证书市场（Liability-Anchored Certificate Market, LCM）**：证书按分级订阅出售，每一级价格 = 该级剩余风险的期望责任 + **尾部标注税 γ**；γ 专项补贴长尾标注，形成"卖得越多、尾部证据越厚"的自融资闭环。安全阈值不被市场改变，市场只改变证据预算与保守档位的选择——**只买证据，不买权限**。

**灵感 3（标注×商业 → 激励相容标注与 Goodhart 哨兵）**
直觉：只要标注者的报酬与其"产出"挂钩，标注就会被策略化：凑数量、挑容易的、边界含糊处给便宜标签。若覆盖率的统计口径又恰好是标注分布本身，那么"覆盖率"会被商业模式反向优化——标注越多、指标越好看，真实尾部反而越空。核心创新：**激励相容标注审计（Incentive-Compatible Labeling, ICL）+ Goodhart 覆盖哨兵（Goodhart Coverage Monitor, GCM）**：用适当支付规则与抽检使"如实且用力标注"成为占优策略；GCM 用部署分布 `p` 对标注分布 `q` 做重要性重加权与有效样本量 `n_eff` 监控，一旦 `q` 相对 `p` 出现系统性偏斜，就判定证书"在被优化的指标上成立、在真实分布上不成立"，强制塌缩到更保守档并追加尾部标注。

**三者如何统一**
统一为 **v15 之上的证据—经济层**：v15 回答"在给定校准集上哪些动作被证书允许"（`Exec_v15`），v16 回答"这些证书的支撑是用多少标注、由什么激励结构生产出来的，以及商业模式会不会悄悄掏空它"（`Exec_v16`）。ACP 管"标注买多少证书"，BWC 管"偏斜标注下证书还保什么"，LCM 管"谁付钱、谁担责、如何自融资地补尾部"，ICL/GCM 管"标注是否真实、指标是否被反向优化"。共享状态 `ζ_eco=(B_ann, q→p 权重 w, n_eff, ρ_R, γ, tier, ε_lab, GCM, liability)`。**ACP 回答"证据值多少钱"，LCM 回答"谁来买这份证据"，BWC/ICL/GCM 回答"这份证据还算不算数"**。

## 1. 严格定义（本轮核心对象的初版）

- **定义 631（标注—证书生产函数）**：对区域 `R⊆X`，记有效标注量 `n_R`、单位成本 `c_R`，证书余量 `m_R(n_R)` 关于 `n_R` 单调不减且凹，覆盖率 `ρ_R(n_R)`；称 `F_R(n)=(m_R(n), ρ_R(n))` 为区域 `R` 的生产函数，**单位成本的边际证书增益** `μ_R(n)=m'_R(n)/c_R`。
- **定义 632（部署—标注偏差）**：部署密度 `p`、标注密度 `q`，`w=p/q`（`q>0` 处），有效样本量 `n_eff=(Σw_i)^2/Σw_i^2`；区域覆盖缺口 `δ_R=∫_R p·1[x∉supp(q)]dx + TV(p_R,q_R)`。
- **定义 633（局部证书）**：`Acc_R(D_ann)={a : m_R(a) ≥ U_d + δ_R + ε_lab}`；未覆盖区域自动取最保守集合。
- **定义 634（责任锚定证书与定价）**：档位 `t` 的证书残余风险上界 `r_t`、单次事故期望损失 `L`、责任分摊 `λ∈[0,1]`，价格 `P_t = base_t + λ·r_t·L + γ_t`，其中 `γ_t` 为尾部标注税。
- **定义 635（自融资约束）**：若每期售出 `N_t` 张证书、尾部标注单价 `c_tail`、维持最坏区域覆盖 `ρ_min` 所需尾部标注数 `n_tail^min`，则要求 `Σ_t γ_t N_t ≥ c_tail·n_tail^min`。
- **定义 636（标注噪声间隙）**：真实标签分布与申报标签分布的 TV 距离经共形膨胀后的证书加项 `ε_lab`。
- **定义 637（激励相容标注机制）**：支付规则 `s(ℓ,audit)` 使标注者如实且用力报告的期望效用不低于任何策略性报告；剩余不可避免的噪声记为 `ε_lab`。
- **定义 638（Goodhart 覆盖统计量）**：`G=sup_R (ρ̂_q(R) − ρ_p(R))`，`gcm_alarm = 1[G>τ_G]`。

## 2. 研究问题（轮次升级版）

- **Q1（标注的可证生产）**：如何把"标注量→证书余量/覆盖率"建成可测量、可外推的生产函数？边际增益 `μ_R` 在异质区域上如何估计与校准？标注预算受限时，证书的**局部性定理**能否给出可执行的分配规则，而不是又一张全局平均指标？
- **Q2（偏斜标注下的有效性）**：当 `q≠p` 时，加权共形还能保什么？`n_eff` 降到多低时必须放弃加权、退回最保守档？`δ_R`、`ε_lab` 与 v15 的 `U_d/ρ_cov` 如何合成一个不重复计算的联合界？
- **Q3（商业模式与安全的耦合）**：如何设计定价与责任分摊，使"补尾部标注"成为卖方的**自融资最优反应**，而不是靠监管强加？责任上限、免赔额、分级订阅分别把风险推给了谁？市场机制会不会通过 `q` 的选择把证书"做账"？
- **Q4（激励与反 Goodhart）**：什么支付规则使如实用力标注占优？在有限抽检与有限预算下，租金—噪声前沿是什么？GCM 能否在证书被"优化"到失效前检出，并与 v15 的漂移检测正交而不互相掩盖？
- **Q5（兼容与活性）**：市场层是否可能放宽任何 v15 阈值？尾部税是否会把价格推高到市场崩溃、反而减少标注总量？反复塌缩是否让系统长期停在最低档（"安全的贫穷"）？

## 3. 设计原则（在 P22–P24 基础上新增 P25–P28）

**P25 标注即证据律（No Free Certificate）**
任何证书必须携带其支撑标注分布 `q`、有效样本量 `n_eff`、以及 `q` 对部署分布 `p` 的区域覆盖缺口 `δ_R`；无支撑区域的证书自动取最保守集合。禁止报告脱离 `q` 的"全局覆盖率"。

**P26 市场只买证据律（Market Buys Evidence, Never Permission）**
LCM 的价格、征费与档位选择只影响标注预算与保守档位，不得改变 v15 的任何阈值、证书判决或动作集合；恒有 `Acc_v16 ⊆ Acc_v15` 与 `Exec_v16 ⊆ Exec_v15`。

**P27 尾部自融资律（Tail Self-Financing）**
每张售出证书按剩余风险缴纳尾部标注税，税收入必须在预注册周期内足以维持最坏区域覆盖 `ρ_min`；否则禁止上架更高自主档，而不是先卖再补证据。

**P28 激励相容与反 Goodhart 律（Incentive-Compatible, Anti-Goodhart）**
标注支付规则须使如实用力为占优策略（或显式给出噪声上界 `ε_lab`）；覆盖统计必须在部署分布 `p` 上计算，禁止用标注分布 `q` 自证覆盖；`G>τ_G` 时强制降档并触发尾部补标。

## 4. 与基线的接口（如何退化）

- ACP 失效 ⇒ 固定均匀标注预算，`ρ_R` 退化为经验计数，**等价 v15 的 DCA 路径**；
- BWC 失效 ⇒ 在 `q` 上做无权共形并追加保守惩罚 `δ_R`，**等价 v15 校准路径**；
- LCM 失效 ⇒ 无定价/征税，预算外生固定，**等价 v15 商业无关路径**；
- ICL 失效 ⇒ 视标签为可信、`ε_lab≡0`，**等价 v15 对标注的隐含假设**；
- GCM 失效 ⇒ 关闭覆盖偏差检查，**等价 v15 的 EDC 漂移检查**；
- 五者全失效 ⇒ MetricVoiceGauge-NCD-HUTDH v15，再沿 v15→v14→v13→v12→…→v8 退化链回退；
- **安全继承**：ACP 只改预算、BWC 只收紧证书、LCM 只改定价与档位选择、ICL 只压低噪声、GCM 只触发降档。五端口均不能新增授权或放宽阈值；`Exec_v16⊆Exec_v15` 由引理 136 保证。

## 5. 预期贡献

1. **标注—证书生产函数**：把标注从"预处理成本"提升为"证书的可计量生产要素"，给出单位标注的边际证书增益与按边际风险分配的水位规则；
2. **预算化加权共形校准**：在标注分布与部署分布不一致、且标注预算有限时，给出显式含 `n_eff`、`δ_R`、`ε_lab` 的局部证书，而不是一张乐观的全局覆盖率；
3. **责任锚定证书市场**：把商业模式设计成"尾部标注自融资"的机制——只买证据、不买权限，使商业激励与安全证据同向，而不是相互抵消；
4. **激励相容与反 Goodhart 闭环**：用支付规则压低标注噪声，用部署分布上的覆盖哨兵阻止"覆盖率做账"，并给出端到端退化与活性分析；E671–E680 覆盖生产函数、加权校准、自融资、激励、Goodhart 攻击与端到端。

## 6. 本轮最大风险

**一句话**：商业模式会把"标注覆盖率"变成可优化的 KPI——便宜、常见地区的标注把 `ρ̂` 抬高，而真实部署分布下的尾部覆盖与 `n_eff` 并未改善，于是系统在"覆盖率达标、税收支平衡、证书全部有效"的表象下，执行了一个在安全关键长尾上从未被标注、从未被验证的决定。

## 1. 关键算法骨架

```python
# IP-402 Annotation–Certificate Planner：标注买证书
class AnnotationCertificatePlanner:
    def __init__(self, regions, cost_fn, margin_fn, coverage_fn, budget_ann):
        self.regions = regions            # [R_1, ..., R_m]
        self.cost = cost_fn               # R -> c_R
        self.margin = margin_fn           # (R, n) -> m_R(n)
        self.coverage = coverage_fn       # (R, n) -> rho_R(n)
        self.B = budget_ann

    def marginal_gain(self, R, n):
        # 单位成本的边际证书增益（数值差分 + 成本归一）
        h = max(1, int(0.05 * n))
        dm = self.margin(R, n + h) - self.margin(R, n)
        return dm / (h * self.cost(R))

    def allocate(self, rho_min, eps=1e-9):
        """水位分配：把预算花在 μ_R 最大且尚未达到 ρ_min 的区域。
        等价于 min Σ c_R n_R  s.t.  ρ_R(n_R) >= ρ_min 的 KKT 解。"""
        n = {R: 0 for R in self.regions}
        spent = 0.0
        while spent < self.B:
            active = [R for R in self.regions if self.coverage(R, n[R]) < rho_min]
            if not active:
                break
            R = max(active, key=lambda r: self.marginal_gain(r, max(1, n[r])))
            step_cost = self.cost(R)
            if spent + step_cost > self.B:
                break
            n[R] += 1
            spent += step_cost
        return {
            "n": n,
            "m": {R: self.margin(R, n[R]) for R in self.regions},
            "rho": {R: self.coverage(R, n[R]) for R in self.regions},
            "spent": spent,
            "unmet": [R for R in self.regions if self.coverage(R, n[R]) < rho_min],
        }


# IP-403 Budgeted Weighted Conformal：偏斜标注下的局部证书
class BudgetedWeightedConformal:
    def __init__(self, scores, weights, alpha_d=0.05, eps_lab=0.0):
        self.scores = scores              # 校准残差/边界分数
        self.w = weights                  # p(x)/q(x)
        self.alpha_d = alpha_d
        self.eps_lab = eps_lab            # 由 ICL 审计给出

    def effective_size(self):
        s, s2 = sum(self.w), sum(wi * wi for wi in self.w)
        return (s * s) / max(s2, 1e-12)

    def weighted_quantile(self, level):
        pairs = sorted(zip(self.scores, self.w), key=lambda t: t[0])
        total = sum(wi for _, wi in pairs)
        acc = 0.0
        for score, wi in pairs:
            acc += wi
            if acc >= level * total:
                return score
        return pairs[-1][0]

    def local_certificate(self, delta_R):
        n_eff = self.effective_size()
        # 有限样本膨胀：n_eff 越小，分位越保守
        level = min(1.0, (1 - self.alpha_d) * (1 + 1.0 / max(n_eff, 1.0)))
        U = self.weighted_quantile(level)
        # 联合保守加项：覆盖缺口 + 标注噪声（两者不相交，可加）
        U_sound = U + delta_R + self.eps_lab
        return {
            "U": U_sound,
            "n_eff": n_eff,
            "delta_R": delta_R,
            "eps_lab": self.eps_lab,
            "valid": n_eff >= 1.0 / self.alpha_d,
        }


# IP-404 Liability-Anchored Certificate Market：只买证据，不买权限
class LiabilityCertificateMarket:
    def __init__(self, tiers, loss_L, liability_share, c_tail, rho_min):
        self.tiers = tiers                # [{t, r_t, base_t, autonomy}]
        self.L = loss_L
        self.lam = liability_share
        self.c_tail = c_tail
        self.rho_min = rho_min

    def price(self, tier, gamma_t):
        # 责任溢价 + 尾部标注税；autonomy 只决定可选档，不改任何 v15 阈值
        return tier["base_t"] + self.lam * tier["r_t"] * self.L + gamma_t

    def required_tail_labels(self, n_tail_min_ratio, n_total):
        return int(self.rho_min * n_total * n_tail_min_ratio)

    def self_financing(self, mix, gamma):
        """mix: {tier_id: N_t}；返回 (可行?, 最小统一征税 γ*, 缺口)。"""
        revenue_levy = sum(gamma * N for N in mix.values())
        n_total = sum(mix.values())
        need = self.required_tail_labels(1.0, max(n_total, 1))
        cost_need = self.c_tail * need
        gamma_star = cost_need / max(n_total, 1)
        return revenue_levy >= cost_need, gamma_star, cost_need - revenue_levy

    def admissible_tier(self, buyer_budget, gamma):
        # 预算内允许的最高自主档；不允许超过 v15 授权
        ok = [t for t in self.tiers if self.price(t, gamma) <= buyer_budget]
        return max(ok, key=lambda t: t["autonomy"]) if ok else None


# IP-405 Incentive-Compatible Labeler：让如实用力成为占优策略
class IncentiveCompatibleLabeler:
    def __init__(self, audit_rate, kappa, eps0):
        self.audit_rate = audit_rate      # 抽检比例
        self.kappa = kappa                # 每单位租金的噪声下降率
        self.eps0 = eps0                  # 零租金时的噪声上界

    def payment(self, label, peer_agreement, audited_truth=None):
        # 适当评分 + 抽检罚则：如实报告最大化期望得分
        score = 1.0 - (label - peer_agreement) ** 2
        if audited_truth is not None:
            score += 1.0 - float(label != audited_truth)
            score -= 2.0 * float(label != audited_truth) * (1 - self.audit_rate)
        return score

    def noise_bound(self, rent_R):
        # 租金—噪声前沿：多付一元租金，残差噪声下降 kappa
        return max(0.0, self.eps0 - self.kappa * rent_R), rent_R


# IP-406 Goodhart Coverage Monitor：在部署分布上算覆盖
class GoodhartCoverageMonitor:
    def __init__(self, tau_G, alpha=0.05):
        self.tau_G = tau_G
        self.alpha = alpha
        self.p_hist = []

    def update(self, p_batch, q_support):
        self.p_hist.extend(p_batch)
        covered = sum(1 for x in self.p_hist if x in q_support)
        rho_p = covered / max(1, len(self.p_hist))
        # 标注侧覆盖率只在 q 上有定义，这里作为被优化的 KPI 传入
        return rho_p

    def statistic(self, rho_hat_q, rho_p):
        return max(0.0, rho_hat_q - rho_p)

    def check(self, rho_hat_q, rho_p, n_eff):
        G = self.statistic(rho_hat_q, rho_p)
        # 有效样本越少，阈值越保守（Bonferroni 风格膨胀）
        thr = self.tau_G + (1.0 / max(n_eff, 1.0)) ** 0.5
        return {"G": G, "alarm": G > thr, "force_collapse": G > thr, "thr": thr}

def metricvoicegauge_round_16_evidence_economy(M, s, obs, eco=None, ell=None, ...):

    results = middleware.run_cycle(runners={...}, ctx=ctx)
    nge.update_belief(obs)
    hcc.update_identification(obs.motor_enc, obs.joint_enc, obs.current)

    eco = eco or ctx.eco

        regions=eco.regions, cost_fn=eco.cost,
        margin_fn=eco.margin, coverage_fn=eco.coverage,

    plan = acp.allocate(rho_min=eco.rho_min)

    icl = IncentiveCompatibleLabeler(eco.audit_rate, eco.kappa, eco.eps0)
    eps_lab, rent = icl.noise_bound(eco.rent)
    eco.eps_lab = eps_lab

    # ---- BWC：偏斜标注下的局部证书 ----
    bwc = BudgetedWeightedConformal(
        scores=eco.cal_scores, weights=eco.importance_w,
        alpha_d=ctx.alpha_d, eps_lab=eps_lab)
    delta_R = eco.coverage_gap(obs)          # 由 ACP/EDC 提供的区域覆盖缺口
    cert = bwc.local_certificate(delta_R)
    if not cert["valid"]:
        # 有效样本不足：禁止使用加权证书，退回 v15 最保守档
        cert["U"] = float("inf")

    # ---- LCM：定价/征税，只改档位与预算 ----
    lcm = LiabilityCertificateMarket(
        tiers=eco.tiers, loss_L=eco.L,
        liability_share=eco.lam, c_tail=eco.c_tail,
        rho_min=eco.rho_min)
    feasible, gamma_star, gap = lcm.self_financing(eco.sales_mix, eco.gamma)
    if not feasible:
        # 未自融资：禁止上架更高自主档，把缺口写入补标预算
        eco.B_ann += max(0.0, gap)
        plan = acp.allocate(rho_min=eco.rho_min)

    # ---- GCM：反 Goodhart ----
    gcm = GoodhartCoverageMonitor(tau_G=eco.tau_G)
    rho_p = gcm.update(eco.p_batch, eco.q_support)
    g = gcm.check(rho_hat_q=plan["rho"].get("tail", 0.0),
                  rho_p=rho_p, n_eff=cert["n_eff"])

    # ---- 决策：证书 + v15 守卫共同放行 ----
    if g["force_collapse"]:
        eco.tier = 0                      # 安全塌缩到最保守档
        eco.B_ann += eco.tail_topup       # 触发尾部补标
        execute(eco.fallback(obs))
    else:
        tier = lcm.admissible_tier(eco.buyer_budget, eco.gamma)
        a_cert = eco.certified_action(obs, cert, tier) if tier else None
        if a_cert is not None and a_cert in ctx.v15_exec_set(obs):
            execute(a_cert)               # 市场只选档，不扩权
        else:
            execute(eco.fallback(obs))

    # ---- v15 守卫原样保留 ----
    verdict, k_next = chunk_guard(
        current_chunk, k_exec, live_obs, nge.b, hcc, ...)
    if verdict == 'abort':
        current_chunk.execute_transfer_safe_abort(k_next)
        current_chunk = None
    elif verdict == 'degrade':
        current_chunk = current_chunk.rung(0)
    elif verdict == 'recover':
        execute_recovery(nge.epistemic_recovery())
    else:
        execute(current_chunk.skills[k_next])

    # ---- 低频异步：重估生产函数、重定价、重审计 ----
    if cycle_idx % T_eco == 0:
        eco.refit_production(new_annotation_batch)
        eco.reprice(lcm, eps_lab=cert["eps_lab"])
        eco.B_ann += max(0.0, lcm.self_financing(eco.sales_mix, eco.gamma)[2])

    # ---- v15 继承路径 ----
    C, spatial_cert, claims, metrics, rewards = M.inherited_v15_path(ctx)
    return C, spatial_cert, claims, metrics, rewards
```

## 3. 推导

**引理 131（无免费证书：支撑局部性）** 设校准只用标注分布 `q`，其支撑为 `S_q=supp(q)`。则对任意区域 `R`，在 `p` 下的证书违规概率满足
```
P_p(违规 | x∈R) ≤ α + δ_R ,
```
其中 `δ_R = p(R∖S_q) + TV(p_R,q_R)`；在 `R∖S_q` 上不存在优于最坏先验的分布无关保证。证明：共形交换性只在 `supp(q)` 上成立；把 `p` 在 `R` 上的质量拆为"落在 `S_q` 内"与"落在 `S_q` 外"两部分，外部质量贡献 `p(R∖S_q)`，内部分布用 `TV` 控制与 `q_R` 的差异，三角不等式合并即得。外部无信息，故不可能有更优保证。∎ 推论：**证书是局部的、按预算生产的；全局平均覆盖率不能替代逐区域 `δ_R`**。

**引理 132（标注预算的水位分配与尾部欠覆盖）** 在预算 `B_ann` 下最小化 `Σ c_R n_R` 使 `ρ_R(n_R)≥ρ_min`（`ρ_R` 凹），KKT 条件为在活跃区域上 `m'_R(n_R)/c_R = λ`（边际证书增益相等）。若标注分配按边际收益 `v_R` 成比例（商业最优），且尾部 `v_tail` 低于均值 `v̄`，则尾部标注份额满足
```
n_tail / n̄ ≤ v_tail / v̄ ,
```
从而 `ρ_tail` 以至少 `1 − v_tail/v̄` 的比例落后。证明：KKT 给出水位等式；商业最优解是把预算投向 `v_R·ρ'_R` 更大的区域，尾部若 `v` 低则其边际收益排序靠后，由凹性知投入份额被压低；线性比例给出所述上界。∎ 推论：**利润最大化天然欠标尾部；尾部标注税是把 `v_tail` 人工抬回水位的唯一显式手段**。

**引理 133（偏斜标注下的乐观证书界）** 若用 `q` 上的无权共形代替 `w=p/q` 的加权共形，则 `p` 下的实际违规率至多被低估 `TV(p,q)`；当 `n_eff<1/α` 时，加权证书也不可显著优于 `q` 上的证书。形式化地，
```
风险_p(无权) ≥ α + max(0, TV(p,q) − α) ,
```
且在 `n_eff→1` 时 `U_sound` 的有限样本膨胀发散。证明：无权分位是 `q` 的分位；由 Le Cam 两分布耦合，用 `q` 判决在 `p` 上的错误率与 `TV` 线性相关；加权共形的方差随 `n_eff` 下降而放大，标准有效样本量下界给出膨胀项。∎ 推论：**商业模式只要改变 `q`，就能在不改任何阈值的情况下"合法地"放松真实保证**——这正是 GCM 必须存在的原因。

**引理 134（尾部标注税自融资条件）** 设每期售出 `N` 张证书、统一税 `γ`、尾部标注单价 `c_tail`、维持 `ρ_min` 需 `n_tail^min` 个尾部标签。则自融资可行当且仅当
```
γ ≥ γ* = c_tail · n_tail^min / N .
```
若按档位风险差定价 `γ_t = κ·(ρ_min−ρ_t)^+`，则所需销量满足 `N ≥ c_tail·n_tail^min / (κ·Σ_t (ρ_min−ρ_t)^+ N_t/N)`。证明：税收总额为 `γN`，成本为 `c_tail n_tail^min`，相除即得；分级情形按风险差加权求和。∎ 推论：**更高自主档必须支付更高尾部税；"先卖高自主、再补证据"在约束下不可行**。

**引理 135（激励相容的租金—噪声前沿）** 在标注者有私人努力成本、标签噪声随努力下降的委托—代理模型中，任何使如实用力成为占优策略的机制都必须支付信息租金 `rent`，且残差噪声满足
```
ε_lab ≥ max(0, ε_0 − κ·rent) ,
```
其中 `ε_0` 为零租金噪声、`κ>0` 为效率。因此不存在同时做到「零租金」与「零标注噪声」的机制。证明：由显示原理，占优策略要求支付对努力单调；激励相容约束的包络定理给出租金下界，努力越高租金越高；噪声关于努力单调递减，代入即得线性前沿。∎ 推论：**标注质量不是免费的，`ε_lab` 必须作为证书加项显式预算，而不是默认标签可信**。

**引理 136（市场中性：只买证据不买权限）** 设 v16 的动作集合为
```
Acc_v16(x) = Acc_v15(x) ∩ {a : m_R(a) ≥ U_sound(R)} ∩ Acc_tier(tier) ,
```
其中 `tier` 只由 `buyer_budget` 与 `gamma` 选择。则对任意 `x`、任意定价/征税/审计结果，`Acc_v16(x) ⊆ Acc_v15(x)`，故 `Exec_v16 ⊆ Exec_v15`。若 ACP/BWC/LCM/ICL/GCM 全部失效，则 `Acc_v16=Acc_v15`、`Exec_v16=Exec_v15`。证明：交集只可能缩小集合；失效时各加项取中性元（`δ_R=0, ε_lab=0, γ=0, tier=最高且不超 v15`），交集退化为 `Acc_v15`。∎ 推论：**商业模式再激进也无法买到 v15 之外的权限；它能买到的只有更快的档位与更厚的证据**。

**引理 137（Goodhart 检测的样本复杂度）** 若 `TV(p,q)≥ε`，则 GCM 在部署分布上累计 `m` 个样本后，以概率至少 `1−β` 使 `G>τ_G`，所需
```
m = O( (1/ε^2) · log(1/β) ) .
```
证明：`ρ̂_p−ρ̂_q` 的期望差由 `TV` 下界控制；用 Hoeffding/Bernstein 对两个经验覆盖率同时做双侧集中，取并集界并令其小于 `β` 解出 `m`。`n_eff` 折减等价于把有效样本数按 `q` 的集中度下调，阈值相应膨胀。∎ 推论：**尾部补标与 GCM 告警必须绑定同一个预算科目，否则告警只是噪声**。

**引理 138（证据—经济闭环的活性上界）** 记 `P_collapse` 为任一周期内因 `n_eff<1/α` 或 `G>τ_G` 触发塌缩的概率，则系统的认证可执行率满足
```
Act ≥ 1 − P_collapse − P(预算耗尽) − P(执照内无可行档) ,
```
且塌缩期内的活动性损失不超过 v15 在第 0 档的活动性。证明：三个失败事件覆盖所有无可执行认证动作的情形，取并集界；塌缩执行的正是 v15 的第 0 档回退，其安全性由 v15 引理 128 继承。∎ 推论：**"安全的贫穷"是真实失效模式——市场层若过度保守，会把系统长期锁在第 0 档**。

## 7. 已知风险与失效模式

1. **生产函数误设**：`m_R(n)` 的真实形状可能非凹或在稀疏区突变，水位分配会押错区域。缓解：非参数单调拟合 + 留出验证、保守下包络、按季度重估。
2. **覆盖率指标被 Goodhart 化**：只优化标注分布上的 `ρ̂_q` 会系统性地漏掉尾部。缓解：GCM 用部署分布 `p` 计算、分层报告、把尾部覆盖写入合同而非仅看均值。
3. **责任价格不可执行**：事故责任分摊 `λ`、责任上限与保险条款可能与实际法律不一致，`γ` 收不上来。缓解：把 `λ` 作为保守参数、优先用可执行的订阅费而非事后追偿、预留偿付准备金。
4. **有效样本量坍塌**：重要性权重方差大时 `n_eff` 骤降，加权证书失效。缓解：权重裁剪、分层抽样、`n_eff<1/α` 时强制退回 `q` 上证书并整体降档。
5. **标注激励的合谋**：同行一致性评分可被标注者串谋操纵。缓解：随机抽检真值、多来源交叉、异常一致性检测、审计预算独立。
6. **尾部税导致市场萎缩**：`γ` 过高使价格超出买方预算，销量下降反而减少标注总量。缓解：分级征税、需求弹性建模、设置价格上限与公共补贴，监控"安全的贫穷"。
7. **联合间隙重复计算或漏算**：`δ_R`、`ε_lab`、v15 的 `U_d/ρ_cov` 可能同向偏乐观而被重复打折。缓解：用引理 133 的非重叠分解、单侧加项、联合三角界审计。
8. **塌缩—补标振荡**：GCM 频繁告警导致系统在最高档与第 0 档间振荡，活动性差。缓解：滞回阈值、补标完成后才解锁、振荡计数器触发结构性重校准。
9. **标注分布漂移与部署分布漂移混淆**：两者同时变化时 `TV(p,q)` 无法可靠估计。缓解：双通道漂移检测、在 `p` 上直接留出评估、任一通道越界即降档。
10. **商业模式把责任外部化**：通过免责条款把风险转嫁给终端用户，机制表面自融资、实际无约束。缓解：把免责条款纳入 `λ` 审计、外部监管抽样、公开证书支撑的 `n_eff` 与 `δ_R`。

## 8. 本轮最大风险

**一句话**：商业模式会把"标注覆盖率"变成可优化的 KPI——便宜、常见地区的标注把 `ρ̂` 抬高，而真实部署分布下的尾部覆盖与 `n_eff` 并未改善，于是系统在"覆盖率达标、税收支平衡、证书全部有效"的表象下，执行了一个在安全关键长尾上从未被标注、从未被验证的决定。
