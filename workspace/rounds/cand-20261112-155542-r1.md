# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 1 轮；本轮灵感：「自主导航」×「UniBot-V1」）

> 第 60 轮的 SGEC 闭环把「场景落地」做成了「场景识别 → 阻抗先验 → 意图约束 → 执行证据」的**单点局部闭环**（SSM×CIEC×EPIR×SERC×PCE++++）。但它把「场景」建模为**孤立节点**，把「执行」建模为**平台无关的抽象**，把「证据」建模为**顺序正确的消息**。这留下三个未触及的硬缺口：
> 1. **「点」不是「路」**：SSM 能识别当前脚下是湿滑地面，却无法回答「从 A 到 B 的整条路是否可走」。自主导航的本体不是场景分类，而是**场景之间的可通行迁移**——边（edge）的几何可行性、执行接缝处的阻抗跳变、绕行代价全部缺失。所有局部节点 SIC_valid ≠ 全局路径可执行。
> 2. **「可编译」不等于「该具身可执行」**：第 60 轮的 `K_safe` 是平台无关的抽象结论；而 UniBot-V1 有具体的运动学极限、传感视场、算力与执行器阻抗包络。「EEIS 编译成功」只是说参数在安全集合里，并没说**这台身体**能把它走完。缺**平台能力包络**，也缺**跨具身归一化**（换一台 UniBot 变体，先验是否还成立？）。
> 3. **证据只保「顺序」不保「几何」**：EPIR 用 seq_id+SHA256 保证了消息因果，但导航证据的合法性依赖 **tf 链无环、时间一致、map_id 一致、回环漂移有界**。一条序号完美、哈希正确的消息，仍然可能因为坐标系跳变或地图漂移而是**几何错误**的——"证据链完整"≠"证据链正确"。

## 0. 直觉与动机

**灵感 1（自主导航 → 可导航场景图 NAG）**
直觉：导航不是"逐格移动"，而是"在场景图上选一条**可由本具身兑现**的迁移序列"。把第 60 轮的场景节点连成图：节点是场景区域及其阻抗先验，边是两场景之间的**可通行走廊**，边上带三类量——几何需求 r_e（坡高、坡角、通道宽度、摩擦下限）、可通行概率 p_traverse(e)、以及**执行接缝阻抗跳变 ΔK_e**。关键洞见：**一条路线的可行性是"边可行性之积"，而不是"节点安全性之并"**；真正让机器人卡死的是场景切换处（桌面→地毯的阻抗突变），而第 60 轮完全没建模接缝。

**灵感 2（UniBot-V1 → 平台能力包络 PCA）**
直觉：同一份规划，对不同身体的意义完全不同。给 UniBot-V1 建一个**能力包络** C_p = (运动学极限、传感视场、算力、执行器阻抗区间)。边的准入不再问"几何上是否连通"，而问"**需求 r_e 是否被 C_p 分量支配**"。关键洞见：**把"能不能走"从几何问题改写为"能力-需求支配问题"**——这使抽象规划第一次真正"接地"到具体具身。

**灵感 3（全局-局部一致性 GLC）**
直觉：第 60 轮的 SIC 只检查单个场景的「场景置信度 × 阻抗确定性 × 执行可行性」。但导航要的是**整链路一致**：每个节点的 K_i 必须在各自的局部可行为集 A_i 内，且相邻节点的 K 跳变不能超过执行器 slew 上限，否则再"安全"的两个节点连起来也会在接缝处震荡/失稳。关键洞见：**全局可行性 = Π(边通行概率) · Π(节点 SIC) · Π(接缝 slew 可行) · exp(−λ·漂移)**，任一项为 0 则整条路不可执行。

**灵感 4（ROS/tf → 拓扑坐标因果完整性 TFCI）**
直觉：EPIR 的因果图只连"消息→消息"，但导航证据的因果还包含"传感器系→基座系→地图系"的**变换链**。把 EPIR 升级为 TFCI：证据元组加入位姿 p、tf 链 τ、map_id；合法性 = seq 连续 ∧ 哈希一致 ∧ tf 无环且时间对齐 ∧ map_id 一致 ∧ 回环漂移 ≤ ε。关键洞见：**在因果图里加"坐标变换边"，并检测"帧跳变"与"地图漂移"**——导航的证据必须同时是"顺序正确"和"几何正确"的。

**灵感 5（目标意图 → 目标意图导航规划 GINP）**
直觉：第 60 轮的 CIEC 把"轻触/慢点"映射成局部阻抗约束，但"去充电站、避开人群、快点"是**目标级意图**，不是局部约束。把导航意图 G 拆成 (g_target 目标节点, soft_prefs 软偏好, hard_constraints 硬约束)，在 NAG 上解**约束最短路**。关键洞见：**意图既约束"去哪"也约束"怎么走"**——"去充电站"锁目标节点，"避开人群"抬高风险权重并禁用高密度边，"快点"抬高时间权重；且目标意图一旦受理即锁定路线子图，局部 CIEC 不得反客为主覆盖全局目标。

**灵感 6（合流 → 导航执行闭环 NEL）**
直觉：把 SERC 从"单点循环"升级为"路线循环"：全局规划 → 逐边执行 → 证据回传 → **失败即增量修复**。不是推翻重规划，而是把失败边标记、降低 p_traverse、只对受影响的后缀子图做 A*/D* 式修复。关键洞见：**导航的鲁棒性来自"修复"而非"预知"**——世界会变，重要的是局部失败能以 O(受影响子图) 的代价修复，而非全局重算。

**灵感 7（跨具身 → 能力归一化 CAN）**
直觉：UniBot-V1 只是一台具体身体；研究价值在于"能力相对"的表示。把边的需求 r_e 用能力包络 C_p 归一化成无量纲比率 ρ_e = ‖r_e / C_p‖（分量比的最大值）。ρ≤1 准入，(1,1+δ] 降级准入，>1+δ 禁行。关键洞见：**在 ρ-空间里学到的规划先验可跨具身迁移**——换一台 UniBot-V1' 只需重算 C_p' 与 ρ'，先验仍可复用。

**灵感 8（PCE+++++ → 导航认知预算 B_nav 与导航证书 J_nav）**
直觉：导航多出三笔开销——建图/回环（B_map）、全局规划（B_plan）、增量修复（B_replan），叠加第 60 轮的 B_cog。关键洞见：**导航需要一个"全程证书" J_nav**：它把整条路线的每节点 SIC、每边 p_traverse、TFCI 链合法性、GLC 值、预算账本封成一份可审计凭证——执行结束时不是"我觉得走完了"，而是"我有一份可核验的全程合规证明"。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（可导航场景图 NAG）** NAG = (V, E, W)。其中：
- **节点**：V = {v_i}，v_i = (z_i, R_i, μ_K^i, Σ_K^i)。z_i 为场景类型（沿用第 60 轮 SSM 的 Z_scene），R_i 为度量区域（占据栅格/多边形），(μ_K^i, Σ_K^i) 为该场景的阻抗先验参数。
- **边**：E = {(u, v)}，边 e = (u, v) 携带需求向量 r_e = (Δh, θ_slope, w_width, μ_fric, ΔK_seam)，分别为高差、坡角、通道宽度、摩擦下限、接缝阻抗跳变；以及可通行概率 p_traverse(e) 与代价 c_e。
- **权重**：W = (w_len, w_risk, w_energy, w_time)。
- **边代价**：c_e = w_len·len(e) + w_risk·(−log p_traverse(e)) + w_energy·E(e) + w_time·T(e)。
- **路线**：π = (v_0, e_1, v_1, …, e_n, v_n)，起始 v_0，终点 v_n = v_goal。
- **核心语义**：路线可行性不是 max 节点安全，而是 **Π_e p_traverse(e) · Π_i SIC_valid(v_i) · Π_i slew_feasible(K_i, K_{i−1})**。NAG 是 SSM 从「点识别」升级到「图规划」的载体。

**定义 162（平台能力包络 PCA）** 给定具身平台（本轮为 UniBot-V1，参数以能力包络抽象而非硬编码）：
- C_p = (K_kin, S_sensor, B_comp, M_act)，其中
  - K_kin = (v_max, ω_max, a_max, θ_max, w_min, μ_min)：运动学/地形极限；
  - S_sensor = (FOV, range, modalities)：传感视场、量程、模态集合；
  - B_comp = (TOPS, mem, latency_budget)：算力与延迟预算；
  - M_act = ([K_min, K_max], τ_act, slew_max)：执行器阻抗区间、力矩上下限、阻抗变化斜率上限。
- **能力支配关系**：边 e 准入当且仅当 r_e ⪯ C_p（按对应分量逐项支配），且 p_traverse(e) 的置信下界 ≥ θ_p。
- **降级准入**：若 r_e 仅在 (1, 1+δ] 倍率内越界，则标为 degraded，代价加罚 w_risk·log(1/δ)；否则禁行。

**定义 163（全局-局部一致性 GLC）** 给定路线 π 与节点阻抗序列 (K_0,…,K_n)：
- **局部可行为集**：A_i = { K | SIC_valid(v_i, K) }（SIC 沿用第 60 轮定义 158）。
- **接缝可行**：slew_feasible(K_i, K_{i−1}) = 1[‖K_i − K_{i−1}‖_∞ ≤ slew_max]。
- **全局一致度**：
  ```
  GLC(π, K) = Π_{e∈π} p_traverse(e) · Π_i SIC_valid(v_i, K_i) · Π_i slew_feasible(K_i, K_{i−1}) · exp(−λ_drift · drift(π))
  ```
- **判定**：GLC(π, K) ≥ θ_gl 且 ∀i: K_i ∈ A_i，才称路线 π 全局可执行。

**定义 164（拓扑坐标因果完整性 TFCI）** 导航证据 n = (t, seq, hash, p, τ, m)，其中 t 时间戳、seq 序列号、hash 内容哈希、p 位姿、τ = sensor→base→map 的 tf 变换链、m 地图 id。合法性：
```
TFCI_valid(n) = seq_continuous(n) ∧ hash_match(n) ∧ tf_acyclic(τ) ∧ |t(τ)−t| ≤ ε_t ∧ map_consistent(m) ∧ drift(p) ≤ ε_drift
```
- **帧跳变检测**：若 ‖p_t − p_{t−1}‖ > v_max·Δt + ε_jump，则标记 frame_jump，触发重定位；
- **地图漂移检测**：回环闭合误差 drift(p) > ε_drift 即判 map_drift，证据链作废并重建；
- **因果图扩展**：把 tf 变换作为因果图的"变换边"，检测变换环路与时间倒挂。

**定义 165（目标意图导航规划 GINP）** 导航意图 G = (g_target, soft_prefs, hard_constraints)：
- g_target ∈ V：目标节点（"去充电站"→ 充电节点）；
- soft_prefs：软偏好（"快点"→ w_time↑；"慢点"→ w_risk↑）；
- hard_constraints：硬约束（"避开人群"→ 禁用 crowd_density > θ_c 的边；"不许上楼梯"→ 禁用 θ_slope > θ_max 的边）。
- **规划问题**：
  ```
  π* = argmin_π Σ_{e∈π} c_e
       s.t. v_0 = 当前节点, v_n = g_target,
            ∀e: r_e ⪯ C_p, ∀e: e ∉ Forbidden(hard_constraints),
            GLC(π, K) ≥ θ_gl, K_i ∈ A_i, slew_feasible 逐接缝成立
  ```
- **意图锁定**：目标意图受理后，锁定路线子图 Sub(π*)；局部 CIEC 约束只能收窄 A_i，不得改变 g_target 或解除 hard_constraints。

**定义 166（导航执行闭环 NEL）** 算子 NEL(M, G):
```
① GINP: π* ← constrained_shortest_path(NAG, v0, G.g_target, C_p, G)
② 对 π* 逐边 e=(u,v) 执行：
   ③ PCA: if not admissible(r_e, C_p): mark(e); π* ← incremental_repair(π*, e); continue
   ④ SSM: z ← R_scene.update(obs); π_scene ← prior(z)
   ⑤ EEIS: K_i ← compile_with_scene_prior(π_scene, δ_f_req, A_i)   # 受 A_i 与 GLC 约束
   ⑥ Execute: telemetry ← wait_contact()
   ⑦ Evidence: n ← build_nav_evidence(telemetry, p, τ, m, seq, hash)
   ⑧ TFCI: if not TFCI_valid(n): relocalize / rebuild_map; goto ③
   ⑨ EV-exec ← build_exec_evidence(...); EPIR.append(EV-exec)
   ⑩ if exec_failure or D⁺ > τ_fail:
          NAG.update_edge(e, p_traverse ↓); π* ← incremental_repair(π*, e)
   return (π*, J_nav, reached)
```
- **增量修复**：仅对 e 的后缀子图做 A* 修复，复用未受影响部分的 g/h 值（D*/LPA* 思想）。

**定义 167（跨具身能力归一化 CAN）** 边的能力比率：
```
ρ_e = max_k ( r_e^(k) / C_p^(k) )      # 分量比的最大值，无量纲
```
- 准入：ρ_e ≤ 1；降级准入：1 < ρ_e ≤ 1+δ；禁行：ρ_e > 1+δ。
- **归一化表示**：把边的需求表示为能力空间中的点 ρ_e ∈ [0,∞)；规划先验 π_plan(ρ) 与具身解耦。
- **迁移定理（目标）**：若 π_plan 在 UniBot-V1 的 ρ-空间收敛，则换用 C_p' 时只需重算 ρ'_e = ‖r_e/C_p'‖，先验 π_plan 无需重训即可复用（要求 C_p 各分量可比且 δ 一致）。

**定义 168（导航认知预算 B_nav 与导航证书 J_nav）**
- **预算**：B_nav = (B_map, B_plan, B_replan, B_cog)
  - B_map：(建图更新频率, 回环闭合算力, 地图内存)；
  - B_plan：(全局规划算力, 最短路迭代上限)；
  - B_replan：(修复次数上限, 受影响子图规模上限)；
  - B_cog：第 60 轮的 B_scene/B_intent/B_ros/B_exec。
- **VOI 扩展**：
  ```
  voi_nav(π) = VOI_cog(π) − cost_map(π) − cost_plan(π) − cost_replan(π)
  ```
- **降级**：B_map 耗尽→用陈旧地图+保守边（禁用 degraded 边）；B_plan 耗尽→贪心 next-best-node；B_replan 耗尽→安全停靠/返航；B_cog 耗尽→第 60 轮既有降级。
- **导航证书 J_nav**：
  ```
  J_nav = (route_id, [(v_i, SIC_i)], [(e_j, p_traverse_j, ρ_j)], TFCI_chain_valid, GLC(π), budget_ledger)
  ```
  它是整条路线的可审计合规凭证：执行成功 = "J_nav 可核验"，而非"看起来走完了"。

### IP-161 NAG（可导航场景图构建/更新）

```python
class NavigableAffordanceGraph:
    def __init__(self):
        self.nodes = {}          # vid -> {scene, region, mu_K, Sigma_K, SIC}
        self.edges = {}          # (u,v) -> {r_e, p_traverse, n_trials, cost}

    def add_or_update_node(self, vid, scene, region, prior):
        self.nodes[vid] = {
            'scene': scene, 'region': region,
            'mu_K': prior['mu'], 'Sigma_K': prior['Sigma'],
            'SIC': prior.get('sic', 0.0)
        }

    def update_edge_stats(self, u, v, success, r_e):
        e = self.edges.setdefault((u, v), {'n_trials': 0, 'n_succ': 0, 'r_e': r_e})
        e['n_trials'] += 1
        e['n_succ'] += int(success)
        # Beta 后验均值 + 置信下界（保守）
        a, b = e['n_succ'] + 1, e['n_trials'] - e['n_succ'] + 1
        e['p_traverse'] = a / (a + b)
        e['p_lcb'] = beta_lcb(a, b, conf=0.95)
        return e

    def edge_cost(self, u, v, W):
        e = self.edges[(u, v)]
        return (W['len'] * e['r_e']['len']
                + W['risk'] * (-np.log(max(e['p_lcb'], 1e-6)))
                + W['energy'] * e.get('E', 0.0)
                + W['time'] * e.get('T', 0.0))
```

### IP-162 PCA（平台能力包络准入）

```python
class PlatformCapability:
    def __init__(self, kin, sensor, comp, act, delta=0.2):
        self.kin = kin      # v_max, omega_max, a_max, theta_max, w_min, mu_min
        self.sensor = sensor
        self.comp = comp
        self.act = act      # K_min, K_max, tau_act, slew_max
        self.delta = delta  # 降级准入容忍带

    def ratio(self, r_e) -> float:
        # 需求/能力的最大分量比（无量纲）
        ratios = [
            r_e['dh'] / self.kin['theta_max'],   # 或按地形换算
            r_e['theta_slope'] / self.kin['theta_max'],
            self.kin['w_min'] / max(r_e['w_width'], 1e-6),
            self.kin['mu_min'] / max(r_e['mu_fric'], 1e-6),
        ]
        return max(ratios)

    def admit(self, r_e) -> str:
        rho = self.ratio(r_e)
        if rho <= 1.0:
            return 'admit'
        if rho <= 1.0 + self.delta:
            return 'degraded'
        return 'reject'
```

### IP-163 GLC（全局-局部一致性校验）

```python
def global_local_consistency(path, K_seq, nag, pca, drift=0.0, lam_drift=1.0, theta_gl=0.5):
    prod = 1.0
    for i, vid in enumerate(path):
        sic = nag.nodes[vid]['SIC']
        prod *= (1.0 if sic >= 1e-9 else 0.0)
        if i > 0:
            u, v = path[i - 1], vid
            prod *= nag.edges[(u, v)]['p_lcb']
            if np.max(np.abs(np.asarray(K_seq[i]) - np.asarray(K_seq[i - 1]))) > pca.act['slew_max']:
                return 0.0                     # 接缝 slew 不可行
    prod *= np.exp(-lam_drift * drift)
    return prod if prod >= theta_gl else 0.0
```

### IP-164 TFCI（拓扑坐标因果完整性）

```python
class TFCIValidator:
    def __init__(self, eps_t=0.05, eps_drift=0.05, eps_jump=0.2, v_max=1.5):
        self.eps_t, self.eps_drift, self.eps_jump, self.v_max = eps_t, eps_drift, eps_jump, v_max
        self.last = None

    def validate(self, n):
        ok = (n['seq'] == (self.last['seq'] + 1 if self.last else n['seq']))
        ok &= hash_match(n) and not tf_has_cycle(n['tau'])
        ok &= abs(n['tau'].stamp - n['t']) <= self.eps_t
        ok &= (self.last is None or n['map_id'] == self.last['map_id'])
        ok &= n.get('drift', 0.0) <= self.eps_drift
        if self.last is not None:
            dt = max(n['t'] - self.last['t'], 1e-6)
            if np.linalg.norm(np.subtract(n['p'], self.last['p'])) > self.v_max * dt + self.eps_jump:
                ok = False
                n['flag'] = 'frame_jump'
        if not ok:
            n['flag'] = n.get('flag', 'cause_broken')
        self.last = n
        return ok
```

### IP-165 GINP（目标意图导航规划）

```python
def goal_intent_planning(nag, v0, G, pca, W):
    forbidden = set()
    for c in G.get('hard_constraints', []):
        if c['type'] == 'avoid_crowd':
            forbidden |= {e for e, ed in nag.edges.items()
                          if ed['r_e'].get('crowd', 0) > c['theta']}
        if c['type'] == 'no_stairs':
            forbidden |= {e for e, ed in nag.edges.items()
                          if ed['r_e']['theta_slope'] > c['theta']}
    W = dict(W)
```

1. **路线可执行性**：若 GLC(π*) ≥ θ_gl，则存在一条 K 序列使每节点落在 A_i、每接缝 slew 可行。
2. **证据几何正确性**：若 J_nav 中 TFCI_chain_valid，则执行证据链在顺序与坐标上均一致。
3. **修复最优性**：NEL 的增量修复返回受影响后缀上的代价最优解，且不劣于全量重规划。

### IP-161 NAG（可导航场景图）

```python
class NavigableAffordanceGraph:
    def __init__(self):
        self.nodes, self.edges = {}, {}

    def add_or_update_node(self, vid, scene, region, prior):
        self.nodes[vid] = {'scene': scene, 'region': region,
                           'mu_K': prior['mu'], 'Sigma_K': prior['Sigma'],
                           'SIC': prior.get('sic', 0.0)}

    def update_edge_stats(self, u, v, success, r_e):
        e = self.edges.setdefault((u, v), {'n_trials': 0, 'n_succ': 0, 'r_e': r_e})
        e['n_trials'] += 1; e['n_succ'] += int(success)
        a, b = e['n_succ'] + 1, e['n_trials'] - e['n_succ'] + 1
        e['p_traverse'] = a / (a + b)
        e['p_lcb'] = beta_lcb(a, b, conf=0.95)   # 保守下界
        return e

    def edge_cost(self, u, v, W):
        e = self.edges[(u, v)]
        return (W['len'] * e['r_e']['len']
                + W['risk'] * (-np.log(max(e['p_lcb'], 1e-6)))
                + W['energy'] * e.get('E', 0.0)
                + W['time'] * e.get('T', 0.0))
```

### IP-162 PCA（平台能力包络）

```python
class PlatformCapability:
    def __init__(self, kin, sensor, comp, act, delta=0.2):
        self.kin, self.sensor, self.comp, self.act = kin, sensor, comp, act
        self.delta = delta

    def ratio(self, r_e):
        return max(
            r_e['theta_slope'] / self.kin['theta_max'],
            self.kin['w_min'] / max(r_e['w_width'], 1e-6),
            self.kin['mu_min'] / max(r_e['mu_fric'], 1e-6),
        )

    def admit(self, r_e):
        rho = self.ratio(r_e)
        if rho <= 1.0:
            return 'admit'
        return 'degraded' if rho <= 1.0 + self.delta else 'reject'
```

### IP-163 GLC（全局-局部一致性）

```python
def global_local_consistency(path, K_seq, nag, pca, drift=0.0, lam_drift=1.0, theta_gl=0.5):
    prod = 1.0
    for i, vid in enumerate(path):
        if nag.nodes[vid]['SIC'] <= 0:
            return 0.0
        if i > 0:
            prod *= nag.edges[(path[i - 1], vid)]['p_lcb']
            if np.max(np.abs(np.asarray(K_seq[i]) - np.asarray(K_seq[i - 1]))) > pca.act['slew_max']:
                return 0.0
    prod *= np.exp(-lam_drift * drift)
    return prod if prod >= theta_gl else 0.0
```

### IP-164 TFCI（拓扑坐标因果完整性）

```python
class TFCIValidator:
    def __init__(self, eps_t=0.05, eps_drift=0.05, eps_jump=0.2, v_max=1.5):
        self.eps_t, self.eps_drift = eps_t, eps_drift
        self.eps_jump, self.v_max = eps_jump, v_max
        self.last = None

    def validate(self, n):
        ok = hash_match(n) and not tf_has_cycle(n['tau'])
        ok &= abs(n['tau'].stamp - n['t']) <= self.eps_t
        ok &= n.get('drift', 0.0) <= self.eps_drift
        if self.last is not None:
            ok &= (n['seq'] == self.last['seq'] + 1)
            ok &= (n['map_id'] == self.last['map_id'])
            dt = max(n['t'] - self.last['t'], 1e-6)
            if np.linalg.norm(np.subtract(n['p'], self.last['p'])) > self.v_max * dt + self.eps_jump:
                ok = False; n['flag'] = 'frame_jump'
        if not ok:
            n['flag'] = n.get('flag', 'cause_broken')
        self.last = n
        return ok
```

| E196 端到端 | vs 第 60 轮局部闭环：到达率、卡死率、证据完整率 | 到达 +20%；卡死 −50%；≥ 99.9% |

## 5. 本轮最大风险

**一句话**：NAG 的边统计来自极少量真实通行，p_traverse / r_e 极易标定失真；一旦一条"自信的错误边"通过了 PCA 准入并被 J_nav 盖章，整个框架会以"证书已签发"的形式放大这次失败——因此必须用「边概率置信下界而非点估计」「在线边重标定」「J_nav 在首个 GLC/TFCI 违约即作废」「degraded 边默认禁行」四重护栏，保证"证书"永远只是"当前证据下的条件合规"，绝不等于"绝对安全"。
