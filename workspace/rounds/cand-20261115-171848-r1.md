# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配策略 × 主动多模态交互的不确定性二分闭环」IP-253~263；本轮灵感：「移动底盘」×「步骤分」）

> R69 把不确定性一分为二——aleatoric 交给 λ_floor，epistemic 交给「看/问/触」的主动交互——并宣称这是对 R68 的严格泛化。但它悄悄依赖了两个从未被检验的前提：**(H1) 观察者站在一个已知、可信的参考系里**，所有观测共享同一个位姿，所以不确定性只存在于「世界是什么」（模态 M），不存在于「我在哪」；**(H2) 信用在终点结算**，一条轨迹由最终成功率打分，过程是否被认证无关紧要。
>
> 本轮两个灵感正好各自击穿一个前提：
> - **移动底盘**击穿 (H1)：底盘本身就是那个参考系，而它会漂。更致命的是，位姿误差是**共模**的——它同时偏置所有传感器、所有模态、所有交互回答。R69 的 VoI 在这个方向上是**恒等于零的**（同姿态再多看/多问，gauge 误差一分不减），可系统仍会自信地花预算去「看清楚」和「问一句」。于是 R69 在移动平台上会出现一种荒诞行为：**它拼命向一个站错位置的人求证，却从不想着走回去看一眼地标。**
> - **步骤分**击穿 (H2)：长时程移动任务里，一个错误交互（问错、被投毒）或一段漂移，会被后续的运气掩盖；只看终点，会把「侥幸成功」误认证为「可靠成功」。步骤分要求**逐步给信用、逐步要证据**——把「终点证书」变成「一步一证的账本」。
>
> 核心命题：**在「不确定性二分」之上再正交地拆出第三类——参考系（gauge）不确定性 U_gau，它是共模的，只能由「重定基」动作（回访地标、移动到新视点、机动增观测）消解，不能由同姿态的看/问/触消解；同时把终点证书替换为势函数化的「步骤信用账本」，预算按步做凹效用调度，并要求每步证据密验证。** 命名 **TREAD-RAS**（Terrain-Referenced, step-credited Embodied Active Disambiguation）。口号：**先定盘，再论事；一步一证。**（tread：既是轮胎与地面的接触足迹，也是「踏出的每一步」。）
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我站的地方对吗、这一步算数吗**」——风险自适应闭环第一次把**自己的立足点**和**过程的信用**放进同一个账本。

## 0. 直觉与动机

**灵感 1（移动底盘 → 参考系是可漂移的潜变量，且是共模的）**
直觉：坐在轮式底盘上的多模态系统，最先坏掉的往往不是感知，而是「我在哪」。里程计会打滑，轮子会陷，地面会变形，机械臂一挥质心就偏，转弯时视野全变。更关键的是：位姿偏差是**共享偏差**，不像像素噪声那样各测各的、可以平均掉。它让所有观测一起偏移——你以为面前是「左边那扇门」，其实是右边那扇。R69 的模态分解会把这种偏移吸收成「语义歧义」，于是系统去追问、去凝视，而这全是白费：**共模误差在同姿态下不可观测。** 因此必须把参考系本身当作一个独立潜变量，并区分两类 epistemic：差分歧义（可问）与共模歧义（只能挪）。

**灵感 2（移动底盘 → 动作会消耗「定位资本」，任务与测量不再解耦）**
直觉：R68/R69 把测量当作外生的——标定漂了就去标定。但在移动底盘上，**是你自己的动作把标定搞坏的**：机械臂前伸改变质心→驱动轮法向力变→滑移率变→里程计漂；加速/振动→IMU 偏置与视觉模糊；原地急转→可观测特征变少。于是每个任务动作都在花一笔「参考系资本」。这引出一个 R69 没有的经济学：**不能把定位当成免费的后台服务，它是有预算、会被任务消耗的稀缺资源。** 你可以在必要时透支它换取进度，但必须在余额见底前回充（回访地标/机动重定基），否则整条轨迹的信用一起作废。

**灵感 3（步骤分 → 信用应逐步结算，且要用势函数防止跑偏）**
直觉：期末考只看总分，会奖励蒙对；步骤分奖励「过程正确」。长时程移动任务同理：只看终点，会把「侥幸穿过未认证区域后到达」当成满分。步骤分要求：每一步的子目标是否被**因果地**达成、证据是否**正交且新鲜**、这一步的残余风险记账。但步骤分有个众所周知的副作用——**Goodhart**：一旦系统发现「刷步骤分」比「真的完成任务」容易，它就会去刷。对策不是取消步骤分，而是让它**势函数化**（policy-invariant）：步骤分只做信用重分配，不改变最优任务策略，从而在理论上封住「为分数而分数」的捷径。

**灵感 4（步骤分 → 预算应按步做凹效用调度，而非近视地扑向当前最模糊处）**
直觉：R69 的 MINT 每一轮都盯着「当前歧义最大的地方」花预算，这是**近视**的。长时程里，后面某一步的边际收益可能远高于眼前。步骤分给出天然的信号：每步的边际信用增益 ΔS_i(b)。若它边际递减（越投入越不划算），那么全局最优就是**按步注水（water-filling）**：让所有有效步的「单位成本边际增益」相等。R69 恰好是 N=1 的近视特例；移动底盘把 N 拉大，调度就从「选一个交互」升级为「排一个预算表」。

**灵感 5（两者合流 → 信用账本必须为参考系留「托管余额」）**
直觉：把灵感 2 与 3 接起来，得到本轮最核心的物件：**带 gauge 托管的步骤信用账本**。每一步的信用 S_i 不仅记「任务进度 − 残余风险 − 未消解不确定性」，还记「参考系余额 K 是否低于下限」。当 K 见底，哪怕当前步骤分正高，系统也必须中断任务去 rebase——这叫「先定盘，再论事」。这样一来，安全不再是外挂的刹车，而是账本里一条**守恒约束**：参考系资本不能透支到无法回充。

**灵感 6（移动底盘 → 新的威胁：感知绑架与刷分）**
直觉：参考系一旦成为显式潜变量，就有了新的攻击面。攻击者不必骗你的分类器，只要让你**相信自己在别处**：伪造地标、注入里程计偏移、操纵地形诱发滑移。此时 R69 的所有证书都会在「错误的坐标系」里被盖成有效章——这是全链路污染。R70 必须交付：参考系反劫持锚（不经过可被同一通道篡改的独立源）、gauge/object 分解的似然第二意见、以及「步骤分刷分」这一新型 reward hacking 的对抗集。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（TREAD-RAS 总览）** TREAD-RAS = (GDM, GBO, SCL, VBS, PVC, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **参考系托管**：任一步任务动作的 gauge 消耗不得超过托管余额；余额低于 K_min 必须先执行重定基动作（定义 314–315）；
(iii) **步骤信用守恒与密验证**：Σ_i b_i ≤ B（交互/移动/社交预算守恒），且每一步证据必须独立认证（定义 318），终端成功不豁免中间步骤；
(iv) **参考系独立第二意见**：gauge 判定不得只依赖可被同一通道篡改的证据（继承并强化 R69 的 k-正交纪律）。

**定义 311（位姿潜变量与 gauge 零空间）** 底盘位姿 T_t ∈ SE(2)（或 SE(3)），世界结构 W，观测 o_t = h(T_t, W) + n_t。gauge 群 G 作用于 T_t，且 h 在 G 的轨道上不变（相对几何不变）。微分观测算子 J = ∂h/∂T 在 gauge 方向 ξ_g 上秩亏，定义 **gauge 零空间** 𝒩_g = {ξ : Jξ ≈ 0}。直观：沿 𝒩_g 挪动观察者，画面几乎不变 ⇒ 该方向不可观测。

**定义 312（三类不确定性，epistemic 沿可辨识性再分）** 保留 R69 的 U_ale（噪声，不可约）。把 epistemic 沿观测算子的两个子空间切开：
- **U_epi^diff**（差分歧义）：商空间 𝒯/𝒩_g 上的模态熵，可由同姿态的看/问/触消解（R69 的 MINT 处理的正是它）；
- **U_gau ≡ U_epi^com**（共模/参考系不确定性）：沿 𝒩_g 的后验熵，同姿态任何观测都不降，只有改变 𝒩_g 的重定基动作才降。
**关键盲区**：R69 的 VoI(M; g) 在 𝒩_g 方向上恒为 0，却仍会把共模误差当语义歧义去花预算——这是本轮要修的结构性错误。

**定义 313（gauge 动力学与动作-观测耦合）** T_{t+1} = T_t ⊕ (u_t + s_t)，u_t 为里程计增量，s_t 为滑移（重尾、非零均值）。滑移由地形 τ_t、载荷/质心 c_t、动作 a_t 共同决定：s_t ~ p(· | τ_t, c_t, a_t)。定义 **gauge 消耗率** C_g(a) = E[tr Cov(s_t | a)]/Δt。**耦合命题**：执行任务动作 a 改变质心与振动，因而改变 s_t 的方差——任务与测量不再解耦，动作会消耗定位资本。

**定义 314（gauge 托管账本）** gauge 资本 K_t ≥ 0，递推 K_{t+1} = K_t − C_g(a_t) + R_rebase(g_t) + η_t，η_t 为标定/学习注入的微小回充。K < K_min ⇒ 强制 rebase，即使当前步骤分正高。K_min 由「一次最坏 rebase 的往返成本」定义，保证永远留有回充能力。

**定义 315（重定基动作 / frame-breaking options, GBO）** 宏信息动作 g ∈ 𝒜_rebase ⊂ 𝒜_info：回访已知地标（loop closure）、移动到新视点（active relocalization）、原地机动（旋转/激励以增加可观测性）、地形接触探询。与 R69 的微观 g（gaze/probe/ask）本质不同：rebase **改变 𝒩_g 本身**（新位姿使 gauge 方向获得独立约束），故对 U_gau 的 VoI > 0。成本 c(g) = 距离/时间/风险，受非完整约束：不可直达方向需绕行，路径成本由运动学图给出。任 g 仍须过 C-RAS-WM 认证（继承 R69 定义 302）。

**定义 316（步骤划分与步骤分）** 将轨迹分为 N 个语义/几何步骤 {σ_i}（子目标段）。步骤分 S_i ∈ [0,1]：
S_i = w_p·Progress_i − w_r·Risk_i − w_u·U_i^res − w_g·[K_i < K_min]，
其中 Progress_i 为已认证子目标进度，Risk_i 为该步残余风险，U_i^res 为未消解不确定性惩罚，末项为 gauge 欠账罚。S_i 仅在证据链被认证（定义 318）时计入账本。

**定义 317（势函数化步骤分：只重分配信用，不改变最优策略）** 令 Φ(s) 为「距完成的期望认证进度」势函数，即时信用 r'_i = r_i + γΦ(s_{i+1}) − Φ(s_i)。当 S_i 由 Φ 的差分 + 认证指示生成时，步骤分是 **policy-invariant**（势函数塑造，Ng 1999）：不改变最优任务策略，只加速信用分配与早期干预。**若 S_i 脱离 Φ（例如加入纯终点奖励），Goodhart 风险回归**（定义 323）。

**定义 318（密验证 / 一步一证）** 每步证据 e_i 需同时满足：来源正交性（≥2 个独立通道）∧ **干预性**（子目标由该动作因果达成，而非侥幸——用反事实/随机化探针检验）∧ 时效性。证据链 𝔼 = (e_1,…,e_N) 可认证 ⇔ 每步 e_i 认证。定义 **反侥幸标记** L = 1，当且仅当终端成功但存在未认证步骤。

**定义 319（步骤预算调度 VBS）** 全局预算 B = (B_int, B_move, B_social) 守恒。给每步分配 b_i，Σ b_i ≤ B，最大化 Σ_i E[ΔS_i(b_i)] − λ_g·Σ_i C_g(a_i)；ΔS_i 边际递减 ⇒ 凹效用下按步注水最优：所有有效步满足 ∂ΔS_i/∂b_i = μ。**R69 是 N=1 的近视特例**：它把全部预算投给「当前最模糊」的一步，忽略了未来步的边际收益。

**定义 320（gauge 感知流似然第二意见，扩展 R69 FMA）** 把 R69 的 Δa 分解到 gauge/object 两个子空间：Δa = P_g Δa + P_⊥ Δa。P_g 大而 r_res 低 ⇒ 疑似 **gauge kidnapping**（位姿被劫持，全链路在错误坐标系里被认证）；P_⊥ 大 ⇒ 语义/物体级异常。判别统计量 ρ_kg = ‖P_g Δa‖ / (‖P_⊥ Δa‖ + ε)。

**定义 321（参考系锚定与反劫持）** 至少一个 gauge 证据源不经过可被同一攻击篡改的通道：短时惯性死推、地形接触、磁/天体罗盘、已知地标的独立测距。重定基必须**双源一致**（继承 R69 定义 293-ii 的正交证据纪律，但作用于参考系层）。

**定义 322（步骤信用证书 PVC）** J_TREAD = (J_FLUID, {S_i}, {e_i_hash}, K_min_margin, L_antiluck, ρ_kg, escrow_ledger_hash, tread_ver)。Valid ⇔ Valid(J_FLUID) ∧ 密验证通过 ∧ ∀i S_i ≥ s_min ∧ K_N ≥ K_min ∧ (¬L 或 L 被显式降级并标注)。

**定义 323（步骤分 Goodhart 防护）** (i) 势函数化保证 policy-invariance（定义 317）；(ii) 留出审计：VQAuditor-S 用独立复核重算 S_i，不复用被审计者的中间量；(iii) 对抗性刷分（故意走捷径刷终端、留未认证步骤）纳入 ℰ_gaming；(iv) **因果认证优先于结果认证**——结果相同但因果路径不同的步骤，信用不同。

**定义 324（移动底盘威胁模型 ℰ_chassis）** 感知绑架（伪造地标/GPS/里程计使底盘信以为在别处）、滑移注入（地形/负载操纵诱发系统性漂移）、非完整约束滥用（诱导系统做不可达或高成本的 rebase，耗尽预算）、步骤分刷分。并入 AIC：ℰ_TREAD = ℰ_FLUID × ℰ_chassis。

**定义 325（分级退化，严格包含 FLUID 与 R68）** 当 U_gau = 0（gauge 已知）且 N = 1（单步）时，TREAD 逐指令退化为 FLUID；当 K < K_min 时，TREAD 只多花一笔 rebase 预算，任务侧策略与 FLUID 一致 ⇒ 安全侧不弱于 FLUID。⇒ R68 ⊂ R69 ⊂ R70。

**定义 326（跨轮证书链）** 每个 J_TREAD 携带父证书哈希，形成可审计的「步骤账本链」，支持事后定位「哪一步错了、当时证据是什么、当时站在哪个参考系」。这是「步骤分」在安全审计上的直接兑现。

# IP-264 GDM：位姿/滑移潜变量 + 可观测性分析
class GaugeDriftModel:
    def predict(self, T, a, terrain, com):
        return T @ exp_se2(self.odom(a) + self.slip_sample(terrain, com, a))

    def gauge_nullspace(self, o):
        J = jacobian_obs(o)                     # ∂h/∂pose
        return null_space(J)                    # 𝒩_g：同姿态不可观测方向

    def gauge_cost(self, a):                    # 动作诱发的 gauge 消耗 C_g(a)
        return self.kappa * trace(self.slip_cov(a))

    def decompose(self, o, T, modes):
        Up, Nd = self.gauge_nullspace(o), self.object_subspace(o)
        U_gau  = entropy(project_posterior(modes, Up))
        U_diff = entropy(project_posterior(modes, Nd))
        return U_diff, U_gau

# IP-265 GBO：重定基动作（宏信息动作）候选与成本
def rebase_candidates(T, o, graph):
    cands = [loop_closure(T, graph), active_relocalize(o),
             rotate_in_place(T), contact_probe(o)]
    return [(g, kinematic_path_cost(T, g, graph)) for g in cands]

# IP-266 SCL：势函数化步骤分 + 密验证
def step_score(phi, s, s_next, prog, risk, u_res, k, k_min, certified):
    shaped  = phi(s_next) - phi(s)                     # policy-invariant
    dense   = prog - risk - u_res
    penalty = 0.0 if k >= k_min else 1.0
    s_i = clip(shaped + dense - penalty, 0.0, 1.0)
    return s_i if certified else 0.0                   # 未认证不计分

def certify_step(e):
    return (e.orthogonal_sources >= 2 and
            e.causal_intervention and            # 反事实/随机化检查
            e.fresh)

# IP-267 VBS：凹效用下的按步注水调度
def allocate_budget(step_marginals, B, lam_g, gauge_costs, quantum=1):
    b = [0]*len(step_marginals)
    while sum(b) < B:
        gains = [step_marginals(i, b[i]) - lam_g*gauge_costs[i]
                 for i in range(len(b))]
        i = argmax(gains)
        if gains[i] <= 0: break
        b[i] += quantum
    return b

# IP-269 G-FMA：gauge/object 分解的似然第二意见
def gauge_anomaly(policy, xi, o, o_cal, N_g):
    da = flow_loglik_diff(policy, xi, o, o_cal)        # R69 的 Δa
    pg = project(da, N_g)                              # 共模分量
    po = da - pg                                       # 差分量
    return pg, po, norm(pg) / (norm(po) + eps)

# IP-274 主闭环：先定盘，再论事；一步一证
def TREAD_RAS_round(M, obs, ledger):
    T_hat, k_bal = M.gdm.update(obs)
    U_diff, U_gau = M.gdm.decompose(obs, T_hat, M.last_modes)

    # 1) 参考系托管：余额见底必须先 rebase（即使牺牲当前步骤分）
    if k_bal < M.k_min:
        g = M.gbo.choose(rebase_candidates(T_hat, obs, M.graph), M.budget)
        g = M.gae.anchor_certify(g)                    # 双源一致 + 非可篡改锚
        T_hat, k_bal = M.gdm.rebase(g, obs); M.budget.spend(g)

    # 2) 差分歧义仍走 R69 的 MINT（看/问/触）
    g2 = M.mint.choose_interaction(M.last_modes, obs, M.budget) \
         if U_diff > TAU_DIFF else None

    # 3) 参考系独立第二意见：区分缓变漂移与感知绑架
    pg, po, rho = M.gfma.gauge_anomaly(M.fmp, M.last_action, obs, M.obs_cal, M.gdm.N_g)
    kidnapping = (rho > TAU_KG) and (M.last_r_res < TAU_RES)

    # 4) 步骤分（势函数化）+ 密验证
    certified = M.scl.certify_step(M.last_evidence)
    S = M.scl.score(M.phi, M.s_prev, M.s, M.progress, M.risk,
                    U_diff + U_gau, k_bal, M.k_min, certified)
    ledger.append(M.step_idx, S, M.last_evidence, T_hat, k_bal)

    # 5) 预算按步注水；未认证/欠账步优先补证
    b = M.vbs.allocate(ledger.marginals(), M.budget, M.lam_g,
                       [M.gdm.gauge_cost(a) for a in ledger.actions])

    # 6) 安全侧不变：λ floor 吃全部未消解量
    lam = max(M.efs.risk_scale(...),
              lam_floor(U_ale + U_diff + (U_gau if kidnapping else 0.0)))
    if kidnapping:
        lam = max(lam, 0.8)                            # 回 R68/FLUID 最保守
    kk = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)

    # 7) 证书 + 独立审计
    M.vqa_s.submit_async(ledger.tail(), rho, kidnapping)
    return M.pvc.emit(ledger, k_bal, rho, kidnapping), kk, lam
```

## 3. 推导

**引理 19（gauge 信息的零性：问不出你在哪）** 在固定位姿 T 下，任一观测对 gauge 方向 ξ_g 的 Fisher 信息为 0（因 Jξ_g ≈ 0），故任何同姿态微观信息动作 g（gaze/probe/ask）对 U_gau 的 VoI ≡ 0；只有使 ∂h/∂T 在 ξ_g 上满秩的重定基动作 g ∈ 𝒜_rebase 才使 VoI > 0。**系**：R69 的 MINT 在移动平台上会把预算系统性地投给「无效的看/问」，而永远不生成「走回去看」——这是结构性的，不是调参能修的。

**引理 20（动作-观测耦合的托管必要性）** 若任务动作 a 引起质心偏移 δc，则滑移方差增加量 ≥ c₀‖δc‖²，从而 gauge 资本按 C_g(a) ≥ c₀‖δc‖²/Δt 衰减。若系统不设 K_min 托管，则存在一条「贪进度」轨迹，每步 S_i 都高，但 K 在终点前跌破可回充阈值，导致最坏情况下一次 rebase 失败使整段轨迹的参考系信用归零。**系**：步骤分若不含 gauge 欠账罚（定义 316 末项），会系统性高估那些「烧定位换进度」的步骤。

**引理 21（步骤分的策略不变性与其失效边界）** 若 S_i 由势函数差分 r'_i = r_i + γΦ(s_{i+1}) − Φ(s_i) 生成，则对任意任务奖励 r，最优策略不变（Ng 1999）；因此步骤分只加速信用分配、不诱导偏离。**反之**，一旦 S_i 含不具势函数形式的终点项或与 Φ 不一致的塑形项，则存在任务奖励使最优策略被步骤分带偏（Goodhart 的构造性证明）。故定义 317 是「给步骤分」的安全前提，而非可选优化。

**引理 22（密验证的反侥幸性）** 设每步证据的误接受率 ≤ α，且「侥幸满分」必含至少一个未认证步骤。则稀疏终点证书的侥幸满分割度可达 1（存在对抗性运气路径），而密验证把「错误地给出满分」的概率压到 ≤ 1 − (1−α)^N ≈ Nα（union bound）；配合反事实干预检查（定义 318），可进一步排除「结果对但因果错」的路径。**系**：步骤分不是把证书变严（安全侧不变），而是把**信用归属**变准。

**定理 18（TREAD 严格包含 FLUID 与 R68）** 在 A99–A101（gauge 动力学有界、密验证误接受率有界、凹步骤效用）下：当 U_gau = 0 且 N = 1 时，TREAD 与 FLUID 逐指令相同；当 K < K_min 时，TREAD 只追加一笔受认证的 rebase，任务侧策略与 FLUID 一致。故任意状态下的期望风险 ≤ FLUID ≤ R68，安全侧不做让步，且在长时程上获得步骤调度与 resolution 的双重收益。

**定理 19（按步注水的最优性）** 若每步边际信用增益 ΔS_i'(b) 连续、严格递减且跨步可分离，则预算调度问题 max Σ_i ΔS_i(b_i) s.t. Σ b_i ≤ B 的 KKT 条件等价于「所有内点步的边际增益（扣除 gauge 成本）相等」，即注水解；贪心逐量子分配在量子→0 时收敛到该解。**系**：R69 的近视策略（只投当前最模糊步）是忽略未来步边际收益的特例，其与最优解的差距由跨步边际增益的离散度界定。

**定理 20（先定盘后论事的无突变安全）** 当 K < K_min 且存在可行 rebase 时，系统在执行 rebase 期间冻结任务动作的认证、λ 单调不降，控制连续；当 rebase 不可行/超时/被劫持时，系统退化为「只允许已被认证的安全包络内动作」，等价于 R68/FLUID 的纯保守路径。结合引理 19 与定义 321 的双源锚，gauge kidnapping 被检出时 λ 与 k 同步收紧，提交/换装不变式（R68 定理 15）保持 ⇒ 无突变。

# IP-264 GDM：位姿/滑移潜变量 + 可观测性
class GaugeDriftModel:
    def predict(self, T, a, terrain, com):
        return T @ exp_se2(self.odom(a) + self.slip_sample(terrain, com, a))
    def gauge_nullspace(self, o):                 # 定义 311
        return null_space(jacobian_obs(o))        # 𝒩_g
    def gauge_cost(self, a):                      # 定义 313
        return self.kappa * trace(self.slip_cov(a))
    def decompose(self, o, T, modes):             # 定义 312
        Up, Nd = self.gauge_nullspace(o), self.object_subspace(o)
        return entropy(project(modes, Nd)), entropy(project(modes, Up))

# IP-266 SCL：势函数化步骤分 + 密验证
def step_score(phi, s, s_next, prog, risk, u_res, k, k_min, certified):
    if not certified: return 0.0                  # 一步一证
    shaped  = phi(s_next) - phi(s)                # policy-invariant
    penalty = 0.0 if k >= k_min else 1.0          # gauge 欠账罚
    return clip(shaped + prog - risk - u_res - penalty, 0.0, 1.0)

def certify_step(e):
    return e.orthogonal_sources >= 2 and e.causal_intervention and e.fresh

# IP-267 VBS：按步注水（凹效用）
def allocate_budget(marginal_dS, B, lam_g, gauge_costs, quantum=1):
    b = [0]*len(gauge_costs)
    while sum(b) < B:
        gains = [marginal_dS(i, b[i]) - lam_g*gauge_costs[i] for i in range(len(b))]
        i = argmax(gains)
        if gains[i] <= 0: break
        b[i] += quantum
    return b

# IP-269 G-FMA：gauge/object 分解第二意见
def gauge_anomaly(policy, xi, o, o_cal, N_g):
    da = flow_loglik_diff(policy, xi, o, o_cal)   # R69 Δa
    pg = project(da, N_g); po = da - pg
    return pg, po, norm(pg) / (norm(po) + eps)    # ρ_kg

# IP-274 主闭环：先定盘，再论事；一步一证
def TREAD_RAS_round(M, obs, ledger):
    T_hat, k_bal = M.gdm.update(obs)
    U_diff, U_gau = M.gdm.decompose(obs, T_hat, M.last_modes)

    # 1) 参考系托管：余额见底先 rebase（即使牺牲当前步骤分）
    if k_bal < M.k_min:
        g = M.gbo.choose(rebase_candidates(T_hat, obs, M.graph), M.budget)
        g = M.gae.anchor_certify(g)                    # 双源一致 + 非可篡改锚
        T_hat, k_bal = M.gdm.rebase(g, obs); M.budget.spend(g)

    # 2) 差分歧义仍走 R69 的 MINT
    g2 = (M.mint.choose_interaction(M.last_modes, obs, M.budget)
          if U_diff > TAU_DIFF else None)

    # 3) gauge 感知第二意见
    pg, po, rho = M.gfma.gauge_anomaly(M.fmp, M.last_action,
                                       obs, M.obs_cal, M.gdm.N_g)
    kidnapping = (rho > TAU_KG) and (M.last_r_res < TAU_RES)

    # 4) 步骤分 + 密验证 + 记账
    certified = M.scl.certify_step(M.last_evidence)
    S = M.scl.score(M.phi, M.s_prev, M.s, M.progress, M.risk,
                    U_diff + U_gau, k_bal, M.k_min, certified)
    ledger.append(M.step_idx, S, M.last_evidence, T_hat, k_bal)

    # 5) 注水调度预算；未认证/欠账步优先补证
    b = M.vbs.allocate(ledger.marginals(), M.budget, M.lam_g,
                       [M.gdm.gauge_cost(a) for a in ledger.actions])

    # 6) 安全侧不变：λ floor 吃全部未消解量；绑架则回最保守
    lam = max(M.efs.risk_scale(...),
              lam_floor(U_ale + U_diff + (U_gau if kidnapping else 0.0)))
    if kidnapping: lam = max(lam, 0.8)
    kk = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)

    # 7) 独立审计 + 证书
    M.vqa_s.submit_async(ledger.tail(), rho, kidnapping)
    return M.pvc.emit(ledger, k_bal, rho, kidnapping), kk, lam
```

## 4. 推导

**引理 19（gauge 信息的零性）** 固定位姿下，同姿态微观信息动作对 U_gau 的 VoI ≡ 0（`Jξ_g≈0`）；只有改变 𝒩_g 的重定基动作才使 VoI>0。系：R69 的 MINT 在移动平台上必然「只问不走」，是结构性缺陷。

**引理 20（托管必要性）** 任务动作的质心偏移 δc 使滑移方差增加 ≥ `c₀‖δc‖²`，gauge 资本按 `C_g(a)≥c₀‖δc‖²/Δt` 衰减；无 K_min 托管时存在「每步都高但终点前无法回充」的贪心轨迹，最坏使整段参考系信用归零。

**引理 21（步骤分策略不变性与失效边界）** 势函数差分生成的 S_i 保持最优任务策略（Ng 1999）；含非势函数终点/塑形项时存在使最优策略被带偏的任务奖励（Goodhart 构造）。故势函数化是给步骤分的安全前提。

**引理 22（密验证反侥幸）** 每步误接受 ≤ α 时，稀疏终点证书的侥幸满分率可达 1（存对抗运气路径），密验证压到 `≤1−(1−α)^N≈Nα`；加干预检查可再排除「结果对、因果错」。系：步骤分不把证书变严，而是把信用归属变准。

**定理 18（严格包含 FLUID/R68）** A99–A101 下，`U_gau=0 ∧ N=1` 时 TREAD 与 FLUID 逐指令相同；`K<K_min` 时只追加一笔受认证 rebase，任务侧策略与 FLUID 一致 ⇒ 期望风险 ≤ FLUID ≤ R68，安全不让步、长时程获步骤调度与 resolution 双重收益。

**定理 19（注水最优性）** 凹且可分离的边际步骤增益下，预算调度的 KKT 等价于「内点步边际增益（扣 gauge 成本）相等」；量子化贪心在量子→0 收敛到注水解。R69 近视策略是忽略跨步收益的 N=1 特例，差距由跨步边际增益离散度界定。

**定理 20（先定盘后论事的无突变）** K<K_min 且 rebase 可行时冻结任务认证、λ 单调不降、控制连续；rebase 不可行/超时/被劫持时退化为仅安全包络内动作（等价 R68/FLUID 纯保守）。结合引理 19 与双源锚，绑架检出时 λ 与 k 同步收紧，提交/换装不变式保持 ⇒ 无突变。

## 7. 本轮最大风险

**一句话**：TREAD-RAS 的全部收益押在「gauge 子空间 𝒩_g 能被正确估计」这一前提上——**若共模/差分分解估计错了（把漂移误判为语义歧义，或反之），系统会把预算投到错误的一侧：要么反复去『重定基』一个其实只是语义模糊的问题、耗尽移动预算，要么把真实的定位劫持当成『再问一句就好』的语义问题，最后在错误的坐标系里把每一步都盖成『已认证』——步骤账本越完整，错误越可信。**

**次级风险与缓解**：动作诱发漂移建模误差（C_g 保守上界 + K_min 裕度）；感知绑架（G-FMA 投影 + 非可篡改双源锚 + λ/k 同步收紧）；步骤分 Goodhart（势函数 invariance + VQAuditor-S 独立复核 + ℰ_gaming 对抗）；注水调度被非凹效用破坏（分片凹化 + 一阶贪心近似界）；rebase 规划击穿实时预算（宏动作异步 10Hz + 紧急回退纯保守）。
