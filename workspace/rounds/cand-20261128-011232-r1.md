### 第 1 轮灵感驱动研究记录

**灵感词**：闭环控制、任务规划

**继承关系**：第 4 轮 CADVS-v4（IP-489~492）在 v3 五锚点（3DCF / MSRG / HICK / EEK / LTEM / FFA）之上追加价值锚 VACK（kc_val）与平衡锚 BCK（kc_bal），形成七硬门 kc_evidence_forged_v4 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem ∧ kc_val ∧ kc_bal，fail-closed；软评分 ECS_v4 = ECS_v3 · η_val · η_bal；执行集 Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ … ⊆ Exec_v29。本轮不推翻 v4，而是把「证书」从执行期的静态闸门升级为贯穿「规划—认证—执行—观测—反馈—重规划」的闭环信号，形成 CADVS-v5（IP-493~496），执行集升级为 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **闭环控制：把「证据铸造」从开环验证变成闭环受控系统**。v4 的证书只在规则准入/控制环被消费一次，执行结果并不回写证书、信任与规划——本质是「开环验证」：预测对了没人知道，预测错了也只在下一次失败时被动暴露。控制理论的基本教训是「开环观测器必然漂移」，证据系统同理。引入**证书残差** e = C_obs − C_pred（观测证书减预测证书），把它当作误差信号，构建**残余反馈控制器（RFC）**：用残差驱动规则信任 T_r、硬门阈值与规划参数的连续调整，并用输入-状态稳定（ISS）/压缩映射给出有界性保证。这样「证书」不再只是通过/拒绝的比特，而是带方向的反馈信号。

2. **任务规划：证书感知的任务与运动规划（certificate-aware TAMP）**。v4 的证书只作用于「已经选好的规则/轨迹」，规划器完全不知道证书的存在，于是常见「规划成功、执行被硬门拒绝」的空转。让规划器把每个动作的预测证书当作**可行性约束 + 代价项**：动作证书 C_i、序列组合 C(π) = ⋀_i C_i ∧ 前置链 ∧ 时序不变量、证书感知启发式 h_π（可采纳下界）。这是「plan with certificates」而非「plan then certify」：在搜索阶段就剪掉注定过不了硬门的计划。

3. **闭环任务规划：把规划层本身闭合起来**。定义「plan → certify(预测) → execute → observe(残差) → repair/replan」的规划层闭环。核心是**重规划监督器（RPS）**：事件触发（证书失效 / 残差超界 / 信任跌破 / 环境变化 / 证书过期），带**重规划预算**与**势函数 V 单调下降**条件，同时保证活性（不死锁、不无限抖动）与安全性（未认证不执行）。并以**三时间尺度分离**（快环 1 ms / 中环 10–100 ms / 慢环 0.1–10 s）把规划、VACK、FFA 移出快环，直接缓解 v4 遗留的实时性风险。

**关键洞见**：v4 回答「这条规则此刻是否可信」；v5 回答「这个计划能否被认证地执行，以及执行偏差如何反馈修正」。证书从「闸门（gate）」升级为「信号（signal）」，系统从「开环验证的自主栈」升级为「闭环受控的自主栈」。形式上升级为九硬门 kc_evidence_forged_v5 = kc_evidence_forged_v4 ∧ kc_plan（规划期）∧ kc_loop（执行期残差），fail-closed；软评分 ECS_v5 = ECS_v4 · η_plan · η_loop。特别强调：kc_plan 只是**前置剪枝**，绝不替代运行期硬门——安全性仍由 v4 的七硬门 + kc_loop 保证，因此不会出现「预测即放行」的漏洞。

**形式化目标（增量）**：
1. 定义计划 π = (a_1,…,a_n)、动作证书 C_i、计划证书 C(π) = ⋀_i C_i ∧ 前置链(post_i ⊨ pre_{i+1}) ∧ □ 不变量，及规划期硬门 kc_plan。
2. 定义证书残差 e_i = m^obs_i − m^pred_i、归一化残差 ρ_i = ‖e_i‖_∞，及执行期硬门 kc_loop = (ρ_i ≤ ρ_max ∧ 要求为正的观测边际仍为正)。
3. 定义证书感知启发式 h_π(s)（可采纳下界）与证书剪枝的 A*/HTN 搜索，证明剪枝不损失完备性（仅剪掉可证不可行的分支）。
4. 定义 RFC 的一阶滤波反馈律 T_{t+1} = (1−α)T_t + α·g(m^obs_t)（带死区与抗饱和），并证明 ISS/BIBO 有界性。
5. 定义 RPS 的事件触发集、重规划预算 B 与势函数 V，证明「有限次重规划内到达目标或安全停机」。
6. 定义三时间尺度调度与各层实时预算。
7. 定义 EFA-v5 九硬门与软评分 ECS_v5，及 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 的严格收缩。

**本轮最大风险**：闭环反馈的稳定性完全依赖「预测证书—观测证书」残差的可靠性；一旦模型失配产生系统性偏差，残差反馈会把规划器推向错误的重规划方向，引发振荡（thrashing）甚至安全违例。

## 2. 关键算法骨架

### IP-493 PCC：计划证书编译器与证书感知搜索（慢环，0.1–10 s）

```python
@dataclass
class PlanCertificateCompiler:
    """PCC：把动作预测证书组合为计划证书；证书感知启发式与剪枝；kc_plan 仅作前置剪枝"""
    cert_bus: CertificateBus          # 提供 MSRG/VACK/BCK 的预测证书
    rho_max: float = 0.15
    ttl: float = 2.0                  # 计划证书有效期（秒）

    def compile(self, plan: Plan, t_now: float) -> PlanCert:
        # 1) 逐动作取预测证书（provisional，不替代运行期硬门）
        certs = [self.cert_bus.predict(a) for a in plan.actions]
        # 2) 前置条件链：post_i 必须蕴含 pre_{i+1}
        for prev, nxt in zip(plan.actions, plan.actions[1:]):
            if not implies(prev.post, nxt.pre):
                return PlanCert.bottom(reason='PRECOND_CHAIN_BROKEN', t0=t_now)
        # 3) 时序组合：C(π) = ⋀_i □_[t_i,t_i+T_i] C_i ∧ □_[0,T_π] I
        C = CertCalc.TOP
        for c, a in zip(certs, plan.actions):
            if c == CertCalc.BOT:
                return PlanCert.bottom(reason='ACTION_UNCERTIFIED', t0=t_now)
            C = CertCalc.meet(C, CertCalc.always(c, a.T))
        C = CertCalc.meet(C, CertCalc.always(plan.invariant, plan.horizon))
        # 4) 证书裕度 → 计划软评分（不进入安全判定，仅排序）
        margin = min(self._action_margin(c) for c in certs)
        return PlanCert(C=C, margin=margin, actions=plan.actions,
                        t0=t_now, ttl=self.ttl, provisional=True)

    def kc_plan(self, pc: PlanCert, t_now: float) -> bool:
        """规划期硬门：只保证『该计划在预测模型下可铸造且未过期』"""
        return (pc.C != CertCalc.BOT
                and pc.provisional
                and (t_now - pc.t0) <= pc.ttl)

    def _action_margin(self, c) -> float: ...


def cert_aware_astar(start, goal, actions_fn, cert_bus, h_geo):
    """证书感知 A*：h_geo 可采纳；证书只用于剪掉『可证不可行』分支，保持完备性"""
    openq = [(h_geo(start), 0.0, start, [])]
    while openq:
        f, g, s, path = heappop(openq)
        if s == goal:
            return path
        for a in actions_fn(s):
            c = cert_bus.predict(a)
            if c == CertCalc.BOT:            # 证书剪枝：可证不可行
                continue
            if path and not implies(path[-1].post, a.pre):
                continue
            s2 = a.apply(s)
            g2 = g + a.cost
            # 关键：f 仍用可采纳 h_geo；证书裕度只作 tie-break，避免破坏可采纳性
            heappush(openq, (g2 + h_geo(s2), g2, s2, path + [a]))
    return None
```

### IP-494 RFC：残余反馈控制器（中环，10–100 ms）

```python
@dataclass
class ResidualFeedbackController:
    """RFC：证书残差 → 信任/阈值反馈；kc_loop 执行期残差硬门；带死区与抗饱和"""
    alpha: float = 0.2               # 0 < alpha < 1，压缩因子
    rho_max: float = 0.15
    deadband: float = 0.02
    tau_trust: float = 0.35

    def update(self, rule_id: str, m_pred: np.ndarray, m_obs: np.ndarray,
               trust: float) -> tuple[float, str]:
        e = np.asarray(m_obs) - np.asarray(m_pred)
        rho = float(np.max(np.abs(e)))
        if rho <= self.deadband:                      # 死区：抑制噪声抖动
            return trust, 'HOLD'
        g = self._target_trust(m_obs)                 # 观测边际 → 信任目标
        trust_new = (1.0 - self.alpha) * trust + self.alpha * g
        trust_new = float(np.clip(trust_new, 0.0, 1.0))   # 抗积分饱和
        return trust_new, ('REPLAN' if rho > self.rho_max else 'ADAPT')

    def kc_loop(self, m_pred: np.ndarray, m_obs: np.ndarray,
                required_positive: np.ndarray) -> bool:
        """残差在界内，且要求为正的观测边际未变号"""
        e = np.asarray(m_obs) - np.asarray(m_pred)
        rho = float(np.max(np.abs(e)))
        keep_positive = bool(np.all(np.asarray(m_obs)[required_positive] > 0.0))
        return (rho <= self.rho_max) and keep_positive

    def _target_trust(self, m_obs: np.ndarray) -> float:
        # g 单调、L-Lipschitz：例如 g = clip(min(m_obs), 0, 1)
        return float(np.clip(np.min(np.asarray(m_obs)), 0.0, 1.0))
```

### IP-495 RPS：重规划监督器（事件驱动，跨中/慢环）

```python
@dataclass
class ReplanningSupervisor:
    """RPS：事件触发 + 预算 + 势函数下降；优先局部修复，否则全局重规划，否则安全停机"""
    budget: int = 5
    lam: float = 0.5
    eps: float = 1e-3
    tau_trust: float = 0.35

    def supervise(self, plan, pc, residual_hist, env_changed, t_now) -> str:
        V = self._potential(plan, pc, residual_hist)
        triggers = {
            'CERT_FAIL':  pc.C == CertCalc.BOT,
            'RESIDUAL':   residual_hist.rho > self.rho_max,
            'TRUST_LOW':  residual_hist.trust < self.tau_trust,
            'ENV_CHANGE': env_changed,
            'STALE':      (t_now - pc.t0) > pc.ttl,
        }
        if not any(triggers.values()):
            return 'CONTINUE'
        if self.budget <= 0:
            return 'SAFE_STOP'                     # 活性保护：预算耗尽 → 安全停
        self.budget -= 1
        repaired = self.repair(plan, triggers)     # 局部修复优先
        if repaired is not None and self._potential(repaired, pc, residual_hist) < V - self.eps:
            return 'REPAIR'
        replanned = self.replan(plan.goal, pc)     # 全局重规划
        if replanned is not None and self._potential(replanned, pc, residual_hist) < V - self.eps:
            return 'REPLAN'
        return 'SAFE_STOP'                         # 无法改进则不冒险执行

    def _potential(self, plan, pc, h) -> float:
        return self._cost_to_go(plan) + self.lam * (h.rho + (1.0 - h.trust))
    def _cost_to_go(self, plan) -> float: ...
    def repair(self, plan, triggers): ...
    def replan(self, goal, pc): ...
```

### IP-496 EFA-v5：九硬门 + 软评分

```python
@dataclass
class EvidenceForgingAssemblerV5:
    """EFA-v5：九硬门 fail-closed；kc_plan 只前置剪枝，运行期安全仍由 v4 七门 + kc_loop 保证"""
    efa4: EvidenceForgingAssemblerV4
    pcc: PlanCertificateCompiler
    rfc: ResidualFeedbackController

    def hard_gate_v5(self, plan_cert: PlanCert, m_pred, m_obs, required_positive,
                     t_now: float, **v4_args) -> tuple[bool, str]:
        # 1) 运行期七硬门（安全性主体，语义不变）
        ok4, reason4 = self.efa4.hard_gate(**v4_args)
        if not ok4:
            return False, reason4
        # 2) 规划期前置剪枝（不替代运行期门）
        if not self.pcc.kc_plan(plan_cert, t_now):
            return False, 'PLAN_UNCERTIFIED'
        # 3) 执行期残差硬门（闭环一致性）
        if not self.rfc.kc_loop(m_pred, m_obs, required_positive):
            return False, 'LOOP_DIVERGED'
        return True, 'FORGED_V5'

    def ecs_v5(self, rho_bar: float, rho_max: float, ecs_v4: float) -> float:
        eta_plan = 1.0 / (1.0 + rho_bar / rho_max)      # ∈ (0,1]
        eta_loop = max(0.0, 1.0 - rho_bar / rho_max)    # ∈ [0,1]
        return ecs_v4 * eta_plan * eta_loop
```

### 集成流水线与三时间尺度（v4 → v5）

```
慢环 T_slow ∈ [0.1, 10] s（规划/联邦/价值，绝不在快环）：
  FFA：各站 Δ_i 增加『残差统计、重规划统计、信任校准』→ DP 扰动 → 安全聚合 → Φ_global
  VACK：evaluate 预测轨迹 → α_val^pred（供 PCC）
  PCC：证书感知 A*/HTN 搜索 → 计划 π + 计划证书 C(π) → kc_plan
       └─ 若 kc_plan 失败 → 换计划/放宽子目标/请求人类

中环 T_med ∈ [10, 100] ms（反馈与局部修复）：
  每动作结束/每 N 个周期：
    m_obs ← EEK/BCK/VACK 观测；m_pred ← 对应预测
    ρ = ‖m_obs − m_pred‖_∞
    RFC.update → T_r 更新；kc_loop 判定
    RPS.supervise → CONTINUE / REPAIR / REPLAN / SAFE_STOP
       ├─ CONTINUE  → 继续执行
       ├─ REPAIR    → 局部动作替换（保持 C(π)）
       ├─ REPLAN    → 回慢环 PCC 重规划（预算 B−1）
       └─ SAFE_STOP → 安全停机 + 教师介入

快环 T_fast = 1 ms（安全主体，v4 原样）：
  EEK → EEC → kc_ee
  BCK → BCC → kc_bal
  EFA-v5.hard_gate_v5(plan_cert 缓存, m_pred, m_obs, required_positive, …)
    ├─ HIC_STOP / COVERAGE_BLIND / PHYSICS_UNPROVEN / EE_UNPROVEN
    ├─ BALANCE_UNSTABLE / MEMORY_REJECT / VALUE_MISALIGNED
    ├─ PLAN_UNCERTIFIED → 冻结执行、回中环重规划
    └─ LOOP_DIVERGED    → 冻结执行、回中环修复
```

| PCC.compile | O(\|π\|·d_c + \|π\|) | O(\|π\|) | \|π\| 计划长度，d_c 证书维度 | 慢环，~1–50 ms |
| 证书感知 A*/HTN | O(b^d) 最坏 / 剪枝后 O(b_eff^d) | O(b·d) | b 分支因子 | 慢环，0.1–10 s |
| RFC.update | **O(d)** | O(d) | d 边际维度 | 中环，< 0.1 ms |
| kc_loop | **O(d)** | O(1) | — | < 0.01 ms |
| RPS.supervise | O(\|π\|) 修复 / O(b^d) 重规划 | O(\|π\|) | B 预算 | 事件驱动，中/慢环 |
| EFA-v5 硬门（增量） | **O(1)**（除 kc_plan 缓存查询） | O(1) | — | < 0.01 ms |

**通信开销**：计划证书 C(π) 仅慢环生成（低频，~0.5–2 KB）；残差统计 e/ρ 中环上报（~100 B/动作）；FFA Δ_i 增加残差/重规划统计（~1–2 KB/站点）；原始感知数据不离站。

**实时性缓解（相对 v4 的关键改进）**：
- **时间尺度分离**：PCC/VACK/FFA 全部移出快环，快环只做 O(1) 的硬门查询与 O(d) 残差计算，故 v4 的「VACK ~30 ms、BCK ~5 ms 挤进 1 ms」风险被结构性消除。
- 计划证书与信任均为**缓存查询**，快环不触发任何搜索或学习。
- 残差计算用增量式滑动窗口，避免每周期全量重算。

## 4. 正确性论证（增量更新）

### 引理 43（计划证书的可靠性与组合性——以及它的边界）

**陈述**：设每个动作的预测证书 C_i 在其预测模型 M̂ 下是可靠的（C_i = ⊤ ⇒ 在 M̂ 下动作满足硬门），且前置链 post_i ⊨ pre_{i+1} 成立、时序不变量 I 在 M̂ 下成立。则 kc_plan(π) 通过 ⇒ 在模型 M̂ 下整条计划可被铸造。**但 kc_plan 通过不蕴含真实系统下可执行**；后者必须由运行期 v4 七硬门与 kc_loop 逐动作保证。

**证明**：由组合定义 C(π) = ⋀_i C_i ∧ 前置链 ∧ □I；各 C_i 在 M̂ 下可靠 ⇒ 合取在 M̂ 下可靠；前置链保证动作可衔接；□I 保证时序不变量。故在 M̂ 下可铸造。真实系统与 M̂ 的差异由运行期门 + kc_loop 兜底，故 kc_plan 只能作**必要条件（前置剪枝）**，不能作充分条件。∎

**工程含义**：这是刻意的「安全解耦」——规划层负责效率与可行性预筛，执行层负责真实安全。避免「预测即放行」的致命错误。

### 引理 44（残差反馈的 ISS 稳定性）

**陈述**：信任反馈律 T_{t+1} = (1−α)T_t + α·g(m^obs_t)，α ∈ (0,1)，g 为 L-Lipschitz。设观测扰动 d_t 有界，即 ‖g(m^obs_t) − g(m^pred_t)‖ ≤ L‖d_t‖。则对任意初值 T_0，
‖T_t − T*‖ ≤ (1−α)^t ‖T_0 − T*‖ + L·sup_t‖d_t‖，
其中 T* 为无扰动不动点。即系统对扰动输入-状态稳定（ISS），稳态误差被 L·sup‖d‖ 界定。

**证明**：令 T* = g(m^pred)（无扰动不动点）。展开 T_{t+1} − T* = (1−α)(T_t − T*) + α(g(m^obs_t) − g(m^pred_t))。取范数并用 Lipschitz：
‖T_{t+1}−T*‖ ≤ (1−α)‖T_t−T*‖ + αL‖d_t‖。递推展开得 ‖T_t−T*‖ ≤ (1−α)^t‖T_0−T*‖ + αL Σ_{k=0}^{t-1}(1−α)^{t−1−k}‖d_k‖ ≤ (1−α)^t‖T_0−T*‖ + L·sup‖d‖。∎

**工程含义**：α 越小越稳但适应越慢；α→1 适应快但放大噪声。死区进一步抑制小残差抖动；clip 抗饱和保证 T ∈ [0,1]。

### 引理 45（重规划的活性与安全）

**陈述**：设 (i) 每个重规划窗口内环境最终静止（eventually static）且存在可行计划；(ii) 每次 REPAIR/REPLAN 只在势函数下降 ≥ ε 时被采纳，否则 SAFE_STOP；(iii) 预算 B 有限。则 RPS 在至多 B 次重规划后，要么到达目标，要么 SAFE_STOP；不存在无限重规划循环；且任何未被 v4 七门 + kc_loop 认证的动作都不会被执行。

**证明**：(a) 有限性：每次非 SAFE_STOP 的重规划使 budget 减 1，故至多 B 次。(b) 无抖动：V 每次被采纳的重规划严格下降 ≥ ε，而 V 有下界（代价非负、ρ≥0、T≤1），故不能无限下降；结合预算有限，终止。(c) 安全：执行入口恒经过 hard_gate_v5，其第一段即 v4 七硬门；kc_plan 与 kc_loop 只增加合取项，故未认证动作不可执行。∎

**诚实边界**：引理 45 只保证「不无限抖动 + 安全停机」，**不保证在动态/对抗环境中一定到达目标**；到达目标需要 (i) 的最终静止与可行性假设，或额外的人类介入/放宽子目标。

### 定理 v5（闭环证书规划的收缩、稳定与安全）

**陈述**：在 (B1)~(B6)（继承 v4）及新增 (B7) 预测证书在模型 M̂ 下可靠、(B8) 残差有界、(B9) 重规划预算有限 下：
(i) Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29（严格收缩，因 kc_plan、kc_loop 均非恒真）；
(ii) 计划前置剪枝在 M̂ 下可靠且不损失完备性（引理 43）；
(iii) 信任反馈 ISS 有界（引理 44）；
(iv) 重规划有限且安全（引理 45）；
(v) 运行期安全语义不变：kc_plan 不替代运行期硬门，故 v5 的真实安全性 ≥ v4；
(vi) 快环实时性不被规划/价值计算侵蚀（三时间尺度分离）。

**证明**：(i) v5 在 v4 每条执行路径上追加 kc_plan（规划期）与 kc_loop（执行期）两个合取项，路径集只缩不涨；两门非恒真（存在被拒计划/残差超界轨迹），故严格。(ii) 由引理 43。(iii) 由引理 44。(iv) 由引理 45。(v) hard_gate_v5 先调用 efa4.hard_gate，kc_plan/kc_loop 仅追加约束，故不会放宽 v4 的拒绝。(vi) 由集成流水线的三时间尺度设计：快环仅 O(1)/O(d) 操作。∎

**诚实声明**：(B7) 在非结构化/开放世界中极强——预测证书依赖模型 M̂，而 M̂ 可能系统性偏差，此时 kc_plan 会误剪（把可行计划剪掉）或漏剪（放行预测可行但实际不可行的计划，但后者仍被运行期门拦住，不会造成安全问题，只造成空转）。(B8) 残差有界在接触突变/传感器失效时可能被违反。缓解：预测证书用集成模型 + 不确定度区间；残差门在异常时退化为「冻结执行 + 安全停」；重规划失败升级到人类。

## 5. 实验设计与初步结果（计划中，第 1~2 轮仿真/实机）

### 5.1 实验设计

- **平台**：MuJoCo 3.x + MJX（接触/操作）+ PyBullet（快速 TAMP 基准）+ PDDL/HTN 规划器 + N 台实机 Panda（舰队，N=3~5）。
- **任务**：长程操作（厨房备餐、积木堆叠、装配插孔），每任务 8~20 个动作，含前置依赖与资源约束。
- **对照**：v4（plan-then-certify，开环重规划）、v5（证书感知规划 + 闭环反馈）、消融 A1（去 kc_plan）、A2（去 kc_loop/RFC，仅静态重规划）、A3（去 RPS 势函数，纯阈值触发）、A4（RFC 用固定 α=1，无死区/抗饱和）。
- **扰动**：质量/摩擦 ±20% 模型误差；物体位姿偏移 1~5 cm；外部扰动冲量；人类偏好漂移（λ_vec 突变）；证书过期（TTL 缩短）。
- **指标**：任务成功率、执行期安全违例率、平均重规划次数、重规划抖动率（thrash/min）、规划-执行不一致率（预测可行但执行被拒）、makespan、ECS_v5 与失败 AUC、信任校准 ECE、快/中/慢环延迟 P99/P99.9、丢帧率。

## 7. 本轮最大风险（最终确认）

**一句话**：闭环反馈的稳定性完全依赖「预测证书—观测证书」残差的可靠性；一旦模型失配产生系统性偏差，残差反馈会把规划器推向错误的重规划方向，引发振荡（thrashing）甚至安全违例。
