# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环新周期第 1 轮；本轮灵感：「四足机器人」×「主动交互」）

> 第 60 轮用 SSM×CIEC×EPIR×SERC 把「执行层→证据层」升级为「认知驱动的场景-执行闭环」。但把它放到**四足机器人**身上，会暴露三个在固定基座假设下被隐藏的裂缝：
> 1. **浮动基座失配**：SSM/EEIS/ERTC 编译出的 K_safe 本质是「末端阻抗」，隐含基座不动；四足是浮动基座、欠驱动、接触点随步态切换——一组在机械臂上安全的 K_safe，可能把支撑多边形内的 CoM 推出边界，直接摔倒。
> 2. **认知仍是被动**：SSM 只被动观测、CIEC 只被动接收意图；当场景模糊（湿滑？地毯？）或意图含糊（「轻一点」到底多轻？）时，机器人不会**主动**去问、去试、去换视角——只能等下一次被动观测，错过最佳信息获取时机。
> 3. **交互是单向的**：第 60 轮的意图接地只有人→机，缺少机→人的确认、澄清、协商；信任、耐心、互动疲劳等社会成本没有进入预算，「问得太多」和「不问」都可能是失败。

## 0. 直觉与动机

**灵感 1（四足机器人 → 全身执行可行域 WBER）**
直觉：四足的「执行」不是末端动一下，而是**四条腿 + 一个漂浮的身体一起活下去**。机械臂可以靠固定基座「吸收」任意反力；四足不能——任何 K_safe 都要先回答「这条腿蹬下去，身体会不会翻」。关键洞见：**把阻抗编译从「末端空间」搬到「质心动力学 + 摩擦锥 + 支撑多边形」的联合可行域**：K_safe^WB = K_safe^scene ∩ WB(state)，其中 WB 由质心动力学、角动量、摩擦锥、捕获点共同定义。阻抗 K 通过接触雅可比 J 诱导接触力 f，于是「K 是否安全」变成「f 是否落在可行多面体内」——一个可在线求解的 QP/缩放问题。

**灵感 2（步态 → 步态-接触契约 GCC）**
直觉：四足的接触不是连续的，而是**按节拍切换的契约**：哪条腿何时抬、何时落、落点在哪。主动信息获取（用脚敲地面、试探边缘）必须在**支撑相窗口**内完成，且不能延误下一次触地。关键洞见：把 ERTC 的「实时契约」升级为**步态-接触契约 σ(t)**：任何主动探测动作 a_probe 必须满足「三腿支撑、探测时长落在支撑窗口、不推迟触地 deadline」，否则不可执行。

**灵感 3（主动交互 → VOI 驱动的主动交互算子 AIO）**
直觉：人面对不确定会「问一句、试一下、走近看」；机器人也应如此。关键洞见：**主动交互不是拍脑袋，而是有信息价值门槛的决策**：在 {问人、用脚探、换步态/视角、直接执行、放弃} 之间，用期望样本信息价值 EVSI 减去交互成本与失稳风险，只有净收益 > 0 才主动出手。这让「主动」有了可计算的边界，也与第 60 轮 PCE++++ 的 VOI 一脉相承。

**灵感 4（安全 → 主动交互安全包络 AISE）**
直觉：**主动交互本身可能成为事故源**——探地的那只脚一离地，支撑就从四条腿变三条腿；问人时若停在楼梯口，注意力被对话占用也可能摔。关键洞见：所有主动动作必须先过一道「安全包络」：支撑裕度、探测力上限、τ_abort 内可回退到三腿稳定站姿，缺一不可。

**灵感 5（信任 → 信任校准门控 TCG 与双向意图接地 BIG）**
直觉：人会烦。一直追问「这是湿的吗」的机器人会被关掉；从不确认的机器人则会自信地把地毯当湿滑面。关键洞见：把**信任/耐心建模为隐状态 b(trust)**，主动提问消耗「社会资本」；低信任时机器人应优先自探而非问人。同时，交互应是**双向**的：机器人带着 EV-exec 证据提出约束 C_proposed，人类确认/纠正，形成「提议—澄清—修复」的接地状态机。

**灵感 6（合流 → 四足主动交互闭环 LAIR）**
直觉：场景→不确定性→主动获取信息→全身可行阻抗→执行→证据→更新场景/信任，形成**会主动问、会安全试的四足执行闭环**。它不是「更聪明的规划器」，而是把「主动交互」做成执行接地层的一等公民：信息不足时先行动去获取信息，而不是带着不确定硬执行。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（全身执行可行域 WBER）** 给定浮动基座状态 x_b=(c, ċ, R, ω)、支撑腿集合 C、关节状态 q，全身执行可行域
```
WB(x_b, q) = { K | ∃ f = {f_i}_{i∈C} :
    m c̈ = Σ_i f_i + m g,                       (质心线动量)
    Ḣ = Σ_i (p_i − c) × f_i + Σ_i τ_i,          (绕质心角动量)
    f_i ∈ FC_i(μ_i) = { f | f_z ≥ 0, ‖f_xy‖ ≤ μ_i f_z },   (摩擦锥)
    J_c(q) q̇ + J̇_c q̇ = 0,                      (支撑腿不滑)
    c + ċ/ω_cp ∈ conv{ p_i : i ∈ C },            (捕获点/支撑多边形)
    τ_j ∈ [τ_j^min, τ_j^max], q̇_j ∈ [q̇_j^min, q̇_j^max]
}
```
阻抗经接触雅可比 J_c 诱导接触力：f = J_c^{-T} K Δx + D Δẋ。于是 K ∈ WB 等价于其诱导 f 落在上述线性约束多面体 P(x_b,q)={f | A f ≤ b} 内。定义
```
K_safe^WB = { K ∈ K_safe^scene | J_c^{-T} K Δx ∈ P(x_b,q) }.
```
当 K_safe^scene ∩ WB = ∅ 时返回 DEGRADE_BALANCE_SAFE（降低 α 缩放、增加支撑腿、或改成静态四腿站姿）。

**定义 162（步态-接触契约 GCC）** 接触调度 σ: ℝ → {S,W}^4，占空比 β = T_stance/T_cycle。探测动作 a_probe=(leg, τ_start, τ_dur, f_probe, p_target) 是 **GCC-可执行** 的当且仅当：
- **单腿探测**：探测期间 |{i : σ_i(t)=S}| ≥ 3（至少三腿支撑）；
- **窗口包含**：a_probe.τ_start ≥ t_stance_start 且 a_probe.τ_start+τ_dur ≤ t_stance_end(leg)；
- **不延误触地**：加入 a_probe 后，下一次计划触地时刻 t_td 的偏移 Δt_td ≤ ε_td；
- **载荷可承受**：f_probe ≤ f_load_max(剩余三腿)，且剩余腿的摩擦锥不越界。
记 GCC_adm(a, σ) ∈ {true,false}，并在 true 时返回预留的支撑窗口 W_probe。

**定义 163（主动交互算子 AIO）** 动作集
```
A = { ASK_HUMAN(q), SELF_PROBE(a_probe), REGAUGE(β', viewpoint), COMMIT(K), ABSTAIN }
```
动作 a 的期望样本信息价值（EVSI）为
```
EVSI(a) = E_{o∼P(·|a)}[ max_K E_{θ|o}[R(K,θ)] ] − max_K E_θ[R(K,θ)]
```
其中 θ=(scene, K*, intent) 为待辨识量，R 为下游执行回报（含 D⁺、跌落惩罚、证据质量）。AIO 选择
```
a* = argmax_{a∈A} { EVSI(a) − cost_int(a) − risk(a, x_b) }
s.t. AISE_safe(a, x_b) ∧ (a=SELF_PROBE ⇒ GCC_adm(a,σ))
```
仅当最优净收益 > 0 时执行主动动作，否则回退 COMMIT(K_conservative)。cost_int 计入算力、时间、社会成本。

**定义 164（主动交互安全包络 AISE）** 状态 x_b 下的可交互动作集
```
E_act(x_b) = { a | support_margin(after(a)) ≥ m_safe,
                   a.type=SELF_PROBE ⇒ f_probe ≤ f_probe_max ∧ |p_target−p_leg| ≤ l_reach,
                   abortable(a, τ_abort) = true }
```
abortable 指在 τ_abort 内能中止 a 并把支撑恢复为三腿稳定站姿；若任一条件不满足，a 被硬性剔除（不是软惩罚）。

**定义 165（信任校准门控 TCG）** 人类信任/耐心隐变量 τ_h，机器人维护后验 b(τ_h)（Beta 分布参数 (α,β)）。提问门控：
```
ASK_HUMAN 允许 ⇔ E_b[trust] ≥ τ_trust ∧ N_ask(t−Δ,t) < r_max
```
每次提问后按人类响应（快速/迟疑/拒绝/纠正）更新 (α,β)。当 E_b[trust] < τ_trust 时，AIO 的动作集退化为 {SELF_PROBE, REGAUGE, COMMIT, ABSTAIN}，即「少问、多试、保守做」。

**定义 166（双向意图接地 BIG）** 对话状态 D=(I_h, I_r, γ)，其中 I_h 为人类意图假设、I_r 为机器人解释、γ 为接地置信度。状态机：
```
提议 PROPOSE: I_r ← ϕ_intent→constraint(I_h)；向人类展示 C_proposed 与 EV-exec 证据
澄清 CLARIFY: 选择使 disagreement 期望下降最大的问题 q*；I_h ← update(I_h, reply)
修复 REPAIR: 若人类否定，调整 I_r 并重发 C_proposed
终止: disagreement(I_h,I_r) ≤ τ_ground 或达到最大轮次 → 锁定约束
```
接地成功率 g(D)=P(disagreement ≤ τ_ground)；未接地则走 CIEC 默认约束并标注低置信。

**定义 167（四足主动交互闭环 LAIR）** 算子 LAIR(M, delta_f_req)：
```
① SSM+: scene_belief ← SceneSemanticModel.update(proprio, extero)
② AIO:  a* ← argmax_{a∈A} EVSI(a) − cost_int(a) − risk(a)   （受 AISE/GCC/TCG 门控）
③ 若 a*=ASK_HUMAN: I ← BIG.ground(q, scene_belief); CIEC.receive_intent(I)
   若 a*=SELF_PROBE: 在 GCC 预留下执行探地；scene_belief ← assimilate(probe_evidence)
   若 a*=REGAUGE: 改变步态/视角重新观测
   若 a*∈{COMMIT,ABSTAIN}: 跳过主动动作
④ 场景先验 π_scene(K|z) → EEIS.compile_with_scene_prior → K_scene
⑤ WBER 投影: (K_wb, α) ← WB.project(K_scene, x_b, q)
   若 K_wb=∅: return DEGRADE_BALANCE_SAFE(M)
⑥ CLEP: 执行闭环得到 fused, D⁺, EV-exec, Cert
⑦ EPIR: S_shadow.append(EV-exec); 因果同步
⑧ 信念更新: scene_belief、trust_belief、K_cert ← EV-exec
⑨ return (scene_belief, K_wb, EV-exec, Cert, trust_belief)
```

**定义 168（主动交互预算 PCE+++++）** B_pia = (B_act, B_trust, B_gait, B_exec)：
- **B_act** = (N_probe_max, N_ask_max, Risk_budget)：主动动作次数与风险额度；
- **B_trust** = (α, β, r_max, τ_trust)：社会资本与提问速率上限；
- **B_gait** = (Support_margin_slack, Touchdown_slack, Gait_phase_budget)：步态稳定性与时序余量；
- **B_exec** = 第 59/60 轮原有执行预算。
```
voi_pia(π) = EVSI(π) − cost_int(π) − cost_cog(π) − cost_exec(π) − risk_balance(π)
```
降级链：B_act 耗尽 ⇒ 只允许 COMMIT/ABSTAIN；B_trust 低 ⇒ 只允许 SELF_PROBE/REGAUGE；B_gait 紧 ⇒ 禁止一切 SELF_PROBE（不许抬腿），仅 REGAUGE 或 COMMIT；B_exec 耗尽 ⇒ 第 59 轮原有降级。

### IP-161 WBER（全身执行可行域）

```python
class WholeBodyExecutionRegion:
    def __init__(self, robot, mu=0.8, m_safe=0.05):
        self.robot, self.mu, self.m_safe = robot, mu, m_safe

    def project(self, K_scene, x_b, q):
        A, b = self._linearized_constraints(x_b, q)      # 摩擦锥+角动量+扭矩+CP
        Jt = self._contact_jacobian_T(x_b, q)
        dx = self._task_displacement(x_b, q)
        # 最大安全缩放 α：使 α·Jt·K_scene·dx 落在多面体 A f <= b 内
        alpha = self._max_feasible_scaling(A, b, Jt @ K_scene @ dx)
        if alpha <= 0:
            return None, 0.0
        return K_scene.scale(alpha), alpha

    def _max_feasible_scaling(self, A, b, f_dir):
        bounds = [b[i] / (A[i] @ f_dir) for i in range(len(b))
                  if A[i] @ f_dir > 1e-9]
        return min(bounds) if bounds else 0.0
```

### IP-162 GCC（步态-接触契约）

```python
class GaitContactContract:
    def __init__(self, duty=0.6, min_stance=3, eps_td=0.02):
        self.duty, self.min_stance, self.eps_td = duty, min_stance, eps_td

    def admissible(self, probe, schedule):
        window = schedule.stance_window(probe.leg)
        if window is None:
            return False
        if not (window.start <= probe.t_start and
                probe.t_start + probe.duration <= window.end):
            return False
        if schedule.stance_count(probe.t_start) < self.min_stance:
            return False
        if schedule.touchdown_shift(probe) > self.eps_td:
            return False
        if probe.force > schedule.load_capacity(probe.leg):
            return False
        return True
```

### IP-163 AIO（主动交互算子）

```python
class ActiveInteractionOperator:
    def __init__(self, aise, gcc, tcg):
        self.aise, self.gcc, self.tcg = aise, gcc, tcg

    def choose(self, belief, state):
        best, best_score = None, 0.0
        for a in self._candidates(belief):
            if not self.aise.safe(a, state):
                continue
            if a.type == 'self_probe' and not self.gcc.admissible(a, state.schedule):
                continue
            if a.type == 'ask_human' and not self.tcg.allows_ask():
                continue
            score = (self._evsi(a, belief)
                     - self._cost(a)
                     - self._balance_risk(a, state))
            if score > best_score:
                best, best_score = a, score
        return best if best is not None else self._commit(belief)
```

### IP-164 AISE（主动交互安全包络）

```python
class ActiveInteractionSafetyEnvelope:
    def __init__(self, m_safe=0.05, f_probe_max=30.0, tau_abort=0.15):
        self.m_safe, self.f_probe_max, self.tau_abort = m_safe, f_probe_max, tau_abort

    def safe(self, action, state):
        if self._support_margin_after(action, state) < self.m_safe:
            return False
        if action.type == 'self_probe':
            if action.force > self.f_probe_max:
                return False
            if self._reach(action, state) > state.l_reach:
                return False
        return self._abortable(action, state, self.tau_abort)
```

### IP-166 BIG（双向意图接地）

```python
class BidirectionalIntentGrounding:
    def __init__(self, tau_ground=0.1, max_rounds=3):
        self.tau_ground, self.max_rounds = tau_ground, max_rounds

    def ground(self, initial_intent, scene_belief, exec_evidence):
        I_h = self._parse(initial_intent)
        I_r = self._infer(I_h, scene_belief)
        for _ in range(self.max_rounds):
            if self._disagreement(I_h, I_r) <= self.tau_ground:
                break
            q = self._select_clarification(I_h, I_r)
            reply = self._ask_human(q)
            I_h = self._update(I_h, reply)
            I_r = self._infer(I_h, scene_belief, exec_evidence)
        return I_r, self._disagreement(I_h, I_r) <= self.tau_ground
```

```python
def legged_active_interaction_loop(M, delta_f_req):
```

### IP-168 PCE+++++（主动交互预算）

```python
class ProactiveInteractionBudget:
    def __init__(self, probe_max=20, ask_max=10, r_max=0.2):
        self.B_act = {'probe': probe_max, 'ask': ask_max, 'risk': 1.0}
        self.trust = BetaBelief(alpha=5.0, beta=2.0)
        self.B_gait = {'support_slack': 0.05, 'td_slack': 0.02}
        self.r_max = r_max

    def allows(self, action):
        if action.type == 'self_probe':
            if self.B_act['probe'] <= 0 or self.B_gait['support_slack'] <= 0:
                return False
        if action.type == 'ask_human':
            if self.B_act['ask'] <= 0 or self.trust.mean() < 0.5:
                return False
        return True

    def spend(self, action, risk):
        self.B_act[action.type] -= 1
        self.B_act['risk'] -= risk
        if action.type == 'ask_human':
            self.trust.observe(response_quality=risk)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| WBER | O(n_c³) QP/周期（n_c≤4） | O(n_c²) | 投影后 f 满足摩擦锥与捕获点约束 |
| GCC | O(1) 判定/调度 | O(T_cycle) | 探测窗口合法、触地延误 ≤ ε_td |
| AIO | O(|A|) EVSI 近似 | O(|A|) | 仅执行净收益 > 0 的主动动作 |
| AISE | O(1) 检查 | O(1) | 不满足包络的动作被硬剔除 |
| BIG | O(max_rounds) | O(dialog) | disagreement 单调下降则有限轮终止 |
| LAIR | O(闭环) | 复用 | 全身可行 + 交互可回退 |

**假设 A66–A70**：**(A66)** 接触模型在单周期内可线性化且摩擦锥凸；**(A67)** GCC 调度器可在一个步态周期内完成相位重排；**(A68)** EVSI 可由后验采样近似，误差 ≤ δ_evsi；**(A69)** 人类对澄清问题的回答使 disagreement 期望不增；**(A70)** 主动动作在 τ_abort 内可中止并恢复三腿稳定支撑。

**命题 1（WBER 瞬时安全性）** 若 A66 成立且 K_safe^WB ≠ ∅，则 WBER 投影得到的 K 在本周期内诱导的接触力满足摩擦锥与捕获点约束，不发生支撑丢失。
**命题 2（GCC 可执行性）** 若存在 a_probe 满足 GCC 四条约束，则存在相位偏移使 a_probe 在支撑窗口内完成且 Δt_td ≤ ε_td（由 A67）。
**命题 3（AIO 触发合理性）** 在 A68 的近似下，AIO 输出为净收益最大的动作；若所有动作净收益 ≤ 0，则回退 COMMIT，故不会为「无价值信息」付出失稳代价。
**命题 4（BIG 终止性）** 若 A69 成立且 disagreement 有正下界 τ_ground，则对话在 max_rounds 内终止，且接地成功时约束一致。

## 2. 关键算法伪代码

### IP-161 WBER（全身执行可行域）

```python
class WholeBodyExecutionRegion:
    def __init__(self, robot, mu=0.8, m_safe=0.05):
        self.robot, self.mu, self.m_safe = robot, mu, m_safe

    def project(self, K_scene, x_b, q):
        A, b = self._linearized_constraints(x_b, q)      # 摩擦锥+角动量+扭矩+CP
        Jt = self._contact_jacobian_T(x_b, q)
        dx = self._task_displacement(x_b, q)
        alpha = self._max_feasible_scaling(A, b, Jt @ K_scene @ dx)
        if alpha <= 0:
            return None, 0.0
        return K_scene.scale(alpha), alpha

    def _max_feasible_scaling(self, A, b, f_dir):
        bounds = [b[i] / (A[i] @ f_dir) for i in range(len(b))
                  if A[i] @ f_dir > 1e-9]
        return min(bounds) if bounds else 0.0
```

### IP-162 GCC（步态-接触契约）

```python
class GaitContactContract:
    def __init__(self, duty=0.6, min_stance=3, eps_td=0.02):
        self.duty, self.min_stance, self.eps_td = duty, min_stance, eps_td

    def admissible(self, probe, schedule):
        window = schedule.stance_window(probe.leg)
        if window is None:
            return False
        if not (window.start <= probe.t_start and
                probe.t_start + probe.duration <= window.end):
            return False
        if schedule.stance_count(probe.t_start) < self.min_stance:
            return False
        if schedule.touchdown_shift(probe) > self.eps_td:
            return False
        if probe.force > schedule.load_capacity(probe.leg):
            return False
        return True
```

### IP-163 AIO（主动交互算子）

```python
class ActiveInteractionOperator:
    def __init__(self, aise, gcc, tcg):
        self.aise, self.gcc, self.tcg = aise, gcc, tcg

    def choose(self, belief, state):
        best, best_score = None, 0.0
        for a in self._candidates(belief):
            if not self.aise.safe(a, state):
                continue
            if a.type == 'self_probe' and not self.gcc.admissible(a, state.schedule):
                continue
            if a.type == 'ask_human' and not self.tcg.allows_ask():
                continue
            score = (self._evsi(a, belief)
                     - self._cost(a)
                     - self._balance_risk(a, state))
            if score > best_score:
                best, best_score = a, score
        return best if best is not None else self._commit(belief)
```

### IP-164 AISE（主动交互安全包络）

```python
class ActiveInteractionSafetyEnvelope:
    def __init__(self, m_safe=0.05, f_probe_max=30.0, tau_abort=0.15):
        self.m_safe, self.f_probe_max, self.tau_abort = m_safe, f_probe_max, tau_abort

    def safe(self, action, state):
        if self._support_margin_after(action, state) < self.m_safe:
            return False
        if action.type == 'self_probe':
            if action.force > self.f_probe_max:
                return False
            if self._reach(action, state) > state.l_reach:
                return False
        return self._abortable(action, state, self.tau_abort)
```

### IP-165 TCG（信任校准门控）

```python
class TrustCalibratedGating:
    def __init__(self, tau_trust=0.5, r_max=0.2):
        self.tau_trust, self.r_max = tau_trust, r_max
        self.alpha, self.beta = 5.0, 2.0      # Beta(α,β)
        self.ask_history = deque()

    def allows_ask(self):
        self._prune(self.ask_history, window=60.0)
        return (self.alpha / (self.alpha + self.beta) >= self.tau_trust
                and len(self.ask_history) < self.r_max * 60.0)

    def observe(self, grounded, response_time):
        if grounded and response_time < 2.0:
            self.alpha += 1.0
        else:
            self.beta += 1.0
        self.ask_history.append(time.time())
```

### IP-166 BIG（双向意图接地）

```python
class BidirectionalIntentGrounding:
    def __init__(self, tau_ground=0.1, max_rounds=3):
        self.tau_ground, self.max_rounds = tau_ground, max_rounds

    def ground(self, initial_intent, scene_belief, exec_evidence):
        I_h = self._parse(initial_intent)
        I_r = self._infer(I_h, scene_belief)
        for _ in range(self.max_rounds):
            if self._disagreement(I_h, I_r) <= self.tau_ground:
                break
            q = self._select_clarification(I_h, I_r)
            reply = self._ask_human(q)
            I_h = self._update(I_h, reply)
            I_r = self._infer(I_h, scene_belief, exec_evidence)
        return I_r, self._disagreement(I_h, I_r) <= self.tau_ground
```

```python
def legged_active_interaction_loop(M, delta_f_req):
```

### IP-168 PCE+++++（主动交互预算）

```python
class ProactiveInteractionBudget:
    def __init__(self, probe_max=20, ask_max=10, r_max=0.2):
        self.B_act = {'probe': probe_max, 'ask': ask_max, 'risk': 1.0}
        self.trust = BetaBelief(alpha=5.0, beta=2.0)
        self.B_gait = {'support_slack': 0.05, 'td_slack': 0.02}
        self.r_max = r_max

    def allows(self, action):
        if action.type == 'self_probe':
            if self.B_act['probe'] <= 0 or self.B_gait['support_slack'] <= 0:
                return False
        if action.type == 'ask_human':
            if self.B_act['ask'] <= 0 or self.trust.mean() < 0.5:
                return False
        return True

    def spend(self, action, risk):
        self.B_act[action.type] -= 1
        self.B_act['risk'] -= risk
        if action.type == 'ask_human':
            self.trust.observe(response_quality=risk)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| WBER | O(n_c³) QP / 周期（n_c≤4） | O(n_c²) | 投影后 f 满足摩擦锥与捕获点约束 |
| GCC | O(1) 判定 / 调度 | O(T_cycle) | 探测窗口合法、触地延误 ≤ ε_td |
| AIO | O(|A|) EVSI 近似 | O(|A|) | 仅执行净收益 > 0 的主动动作 |
| AISE | O(1) | O(1) | 越界动作硬剔除 |
| BIG | O(max_rounds) | O(dialog) | disagreement 单调降则有限轮终止 |
| LAIR | O(闭环) | 复用 | 全身可行 + 交互可回退 |

**假设 A66–A70**：**(A66)** 单周期接触模型可线性化、摩擦锥凸；**(A67)** 调度器可在一个步态周期内重排相位；**(A68)** EVSI 后验近似误差 ≤ δ_evsi；**(A69)** 澄清回答使 disagreement 期望不增；**(A70)** 主动动作 τ_abort 内可中止并恢复三腿支撑。

**正确性定理（LEAP）**：若 A66–A70 成立，则：
1. **全身安全性**：K_safe^WB ≠ ∅ ⇒ 投影阻抗诱导接触力满足摩擦锥与捕获点约束，本周期不支撑丢失（命题 1）。
2. **步态可执行性**：GCC_adm(a,σ)=true ⇒ 存在相位偏移使探测在支撑窗口完成且不延误触地（命题 2）。
3. **主动交互合理性**：AIO 仅执行净 EVSI > 0 且过 AISE/GCC/TCG 门控的动作；否则回退 COMMIT（命题 3）。
4. **接地终止性**：BIG 在 max_rounds 内终止，接地成功则人机约束一致（命题 4）。
5. **预算安全性**：B_act/B_trust/B_gait/B_exec 任一耗尽即触发对应降级链，最坏退化为静态四腿 COMMIT。

**降级链**：B_act 耗尽 ⇒ 仅 COMMIT/ABSTAIN；B_trust 低 ⇒ 仅 SELF_PROBE/REGAUGE；B_gait 紧 ⇒ 禁止抬腿 SELF_PROBE；B_exec 耗尽 ⇒ 回退第 59 轮降级。
