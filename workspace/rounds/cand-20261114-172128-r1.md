# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~302；新灵感循环第 1 轮；本轮灵感：「参数高效微调」×「人机交互」）

> R73 把证据计量做成可组合契约（MMS / DPEM / CCA / ΣREFLEX / CPB），并把系统安全的证明负担从「全系统审计」转移到「契约表达力」。R73 自陈的最大风险是：当真实噪声超出契约可表达空间时，系统会在一堆**类型正确、预算闭合、证书齐全**的模块图上，自信地组合出一个错误的世界。R74 追问：这个错误还可能从哪来？
>
> 答案是两个尚未被建模的**活体来源**：
> - **会持续变化的实现**：R73 的热替换定理（引理 35）假设「同契约实现」在部署前固定。但现代机器人技能靠 LoRA/Adapter/prefix 持续微调，行为在运行中缓慢漂移；参数增量**没有任何证书覆盖**，一次 adapter 合并就可能悄悄改掉安全相关行为。
> - **会学习、会信任、会被误导的人**：R73 的 ERVOI 把 human cost 当预算、把人反馈当标签。但人因证据质量是**机器人沟通动作的函数**（问得清不清楚、何时打断、是否披露不确定度），而人的信任又被机器人行为塑造——人类不是外生 oracle，而是闭环里的一个状态。
>
> 因此 R73 的三条隐含假设——**impl 静态、人类外生、证明开环**——在本轮全部失效。三个灵感正好补三块：
> - **参数高效微调 → DAC（Delta Adapter Contract）**：低秩增量 ΔW=BA 不是「新模型」，而是**可计量的行为位移**。给出包络证书（谱范数 × 输入界）、适配器组合代数 ALA，并把热替换从「逐指令等价」诚实弱化为「性质漂移 ≤ η_Δ」。
> - **人机交互 → HEM（Human Evidence Metrology）**：人类反馈是模式条件、可被沟通调制、且带**策略性**的证据。六分量（专长/负荷/信任/利害/可观测/沟通）+ 人类类型后验 b_t(θ_h)；新增第五反作用层 χ_H。
> - **两者合成 → TCL（Trust Calibration Loop）+ 闭环稳定性**：PEFT 是人类反馈的产物，人的信任是机器人行为的产物——这是一个闭环。R74 认证的对象从「模块」升为「环」：收缩性、信任-可靠性共校准、证据漂移有界。
>
> 核心命题：**不再问「证据能否成为契约」，而问「学习与交互能否成为可审计的闭环——使行为增量的安全性、人因证据的质量、以及人机信任的校准，在持续微调与交互中被证明有界？」** 把 MODGAUGE-RAS 重构为 **PACT-RAS**（Parameter-efficient Adapter Contracts with Trust-calibrated human evidence）——**可塑性与信任的契约代数**。

## 0. 直觉与动机

**灵感 1（PEFT → 低秩增量是「有界的行为位移」，不是「又一个新模型」）**
直觉：LoRA 的 ΔW=BA 只改低秩子空间，(IA)³/prefix/adapter 只改极少数参数。直觉上这像「换了个模型」，数学上却是一个**受控扰动**：单层输出位移 ‖ΔW x‖ ≤ σ_max(B)·σ_max(A)·‖x‖，多层沿 Lipschitz 常数复合。于是适配器应当携带一张**包络证书**，声明「在有效域 D 内，我的输出位移不超过 η_Δ」，而不是要求重跑全系统认证。这个视角的收益是双重的：(a) 认证成本从 O(全模型) 降到 O(r·d)；(b) 合并 adapter 的**干扰**（两个增量作用于同一奇异方向）可以被显式计量，而不是靠实验撞运气。代价是诚实的：PEFT 改变行为，所以不可能再有 R73 的「逐指令等价」，只能有「性质漂移 ≤ η_Δ」——这是从**精确保持**到**有界保持**的范式转变。

**灵感 2（人机交互 → 人是模式条件、可调制、带策略的证据源）**
直觉：把人当 oracle 是最危险的人因假设。人给出的标签、纠正、示范、接受/拒绝、干预，质量由六件事决定：**专长**（会不会）、**负荷**（累不累/赶不赶时间）、**信任校准**（过度信任就橡皮图章，信任不足就过度干预）、**利害**（有没有动机敷衍或作弊）、**可观测性**（从他的位置看不看得见关键状态）、**沟通质量**（机器人有没有把不确定度讲清楚）。这与 DPEM 的深度六分量**完全同构**：深度噪声依赖视角 v，人因噪声依赖沟通上下文 κ；深度有材质类别 m，人有类型 θ_h。但人比深度多一件事——**策略性**：人会学习机器人的怪癖、会因信任被塑造而改变行为。所以人因证据必须同时有 aleatoric 分量与 **strategic 类型后验**，且需要信任校准审计。把人类当「传感器」不是贬低人，而是承认人也有测量误差且必须被计量。

**灵感 3（合成 → 闭环：PEFT 是人的产物，信任是机器人的产物）**
直觉：两条灵感单独用都只是给 R73 打补丁。真正的结构性新问题是一个**环**：
人反馈 → 微调数据 → adapter 增量 → 机器人行为与沟通 → 人的信任与证据质量 → 人反馈。
这个环可以是良性的（信任校准、证据质量高），也可以是病理的：**过度信任 → 监督减少 → 数据变差 → adapter 退化 → 偶发失败 → 信任骤降 → 过度干预 → 中断成本爆炸**；或者**反馈回声室**（adapter 只学到一个有偏人类的偏好，并在同一沟通策略下自我强化）。R73 的 J_MOD 是开环的：认证每个模块与组合，但不认证这个环收不收敛。所以 R74 的新定理不是「模块安全」，而是「**环有界**」。

**灵感 4（可塑-可证权衡：没有免费的个性化）**
直觉：η_Δ 越大（个性化越强、越能适应新用户/新任务），可证安全域 D_cert 就必须越小，或者安全裕度必须越大。这不是工程缺陷，而是结构事实：一个行为可以任意漂移的系统，不可能在固定域上保持固定安全界。把它写成定理（定理 31），就得到一个可证伪的设计曲线：任何声称「无限个性化 + 零安全代价」的系统必然在某个 η 处违反其安全声明。

**灵感 5（沟通是安全执行器，不是 UX 装饰）**
直觉：如果过度信任会直接抬高风险，那么「解释不确定度、必要时故意暴露一次近失效、在降级时明确告知已切换自主」就不是界面问题，而是**控制动作**，要和 ψ/z/c/v 一样进入反作用预算。这把 HCI 从"事后可用性"提升到"在线安全回路"，也解释了为什么 R73 的 ERVOI 只算 human cost 是不够的：它计量了打断的代价，却没计量信任错配的**风险**。

## 1. 形式化定义（增量：定义 383–396）

**定义 383（PACT-RAS 总览与六不变式）** PACT-RAS = (MODGAUGE-RAS†, DAC, HEM, ALA, TCL, IECG, CPB†)。六不变式：
(i) **契约完整性**：模块、适配器、人因通道均须实例化契约（定义 367 / 384 / 386），缺一不入图；
(ii) **组合单调性**：证据经 CCA†、行为经 ALA 组合，二者均无「凭空变好」路径（引理 34 / 39）；
(iii) **反作用通道完备**：每个证据/行为/人因模块声明通道 χ_R / χ_Δ / χ_H（可为平凡），ΣREFLEX† 预算闭合；
(iv) **主张绑定**：每个组件 ∈ {C1,…,C5, 工程附件}（定义 391），附件不进核心认证路径；
(v) **严格退化链扩展**：模块/适配器/人因失效 ⇒ 各自 stub（定义 393），系统逐指令退化为少模态/少可塑版本；
(vi) **闭环有界性**（新增）：信任-可靠性共校准（定义 388）与闭环证据漂移（定义 389）在认证时域内有界——**这是本轮把「开环证书」升为「闭环证书」的唯一新公理**。

**定义 384（增量适配器契约 ΔC）** 一个参数高效适配器模块 ΔC = (EC, W₀_ref, (B, A), r, 𝒟, η_Δ, δ_forget, τ_prov)：
- EC：继承定义 367 的证据契约（类型/预算/域/否决/追溯/时序/密封引用）；
- W₀_ref：基础模型内容哈希（**包络只在同一基座下有效**，基座变则证书作废）；
- (B, A), r：低秩增量 ΔW = BA，rank(ΔW) ≤ r ≪ min(d_in, d_out)（同时覆盖 LoRA / adapter / (IA)³ / prefix 的线性化形式）；
- 𝒟：微调数据溯源（人员、会话、授权、用途、是否含敏感数据）——**没有溯源的增量不可入图**；
- η_Δ：**行为包络证书**，在有效域 D 内 sup_{x∈D} d_out(π_{W₀+ΔW}(·|x), π_{W₀}(·|x)) ≤ η_Δ（可用 KL / 动作 logits 位移 / 证据分布位移实例化）；
- δ_forget：基座任务保留界（灾难性遗忘上界）；
- τ_prov：溯源合并函数（供 J_MOD† 复算）。

**定义 385（适配器组合代数 ALA）** 三个算子及其包络规则：
- **MERGE（任务算术/并行合并）** ΔW₁ ⊕ ΔW₂ = ΔW₁ + ΔW₂。包络：η₁₂ ≤ η₁ + η₂ + I(ΔW₁, ΔW₂)，其中**干扰项** I = 两增量在同一奇异方向上的作用重叠所导致的额外损失上界；仅当 I ≤ I_max 且 δ_forget 未超预算才允许合并，否则退化为 SER 或 VETO。
- **SER（顺序组合）** f_Δ₁₂ = f_Δ₂ ∘ f_Δ₁。包络 η₁₂ ≤ L₁·η₂ + η₁（顺序不可交换，先低 L 后高 η 更安全）。
- **GATE（专家混合/路由）** 输出为凸组合 ⇒ η ≤ Σ w_i η_i；但要求路由器在 D 内可证（路由不把输入送出有效域，否则触发否决）。
- **否决**：任一适配器的包络越预算，或干扰项超限，或基座哈希不匹配 ⇒ 该组合整体否决（非补偿）。ALA 与 CCA 同型：**组合只增不减，缩窄只在可证条件下发生**。

**定义 386（人因证据计量 HEM）** 人类观测 y_h（标签/纠正/示范/接受-拒绝/自然语言/干预）。条件似然
p_h(y_h | s, ψ_h, κ, θ_h)，
其中 ψ_h 为人类认知状态，κ 为沟通上下文，θ_h 为人类类型。**六分量**：
u_h² = u_expertise²(ψ_h) + u_workload²(ψ_h) + u_trust²(e_trust) + u_stake²(θ_h) + u_observability²(s, κ) + u_communication²(κ)。
类型集 𝓗 = {expert-cooperative, novice-cooperative, inattentive, over-trusting, adversarial}；后验 b_t(θ_h) 由响应时延、与机器人历史一致性、纠正质量、跨会话稳定性在线推断（对应 DPEM 的材质后验）。有效域 D_h = {b_t(adversarial∨inattentive) < τ_h} ∧ u_workload < τ_load ∧ 人因数据授权有效。**每分量独立追溯链 τ_h,i**。

**定义 387（人因反作用通道 χ_H，第五反作用层 L5）** 沟通动作 g_c ∈ 𝒢_c（提问、解释、等待、交接、要求确认、请求示范、披露不确定度）。χ_H: 𝒢_c × (ψ_h, κ) → Θ_h′ × D_h′，声明沟通动作如何调制人因噪声参数与有效域：
- 提问 → 降低 u_observability，但抬高 u_workload（打断成本）；
- 解释/披露 → 降低 u_trust（校准过度信任），但消耗注意预算；
- 等待 → 降低 u_workload，但增加任务时延；
- 交接/请求示范 → 降低 u_expertise 依赖，但引入新的人类策略风险。
反作用成本 c_reflex^H = E[Δu_h | g_c] + λ_int·InterruptCost(g_c) + λ_trust·D_KL(b_t(θ_h) ‖ b_t′(θ_h))，并入 ΣREFLEX†。

**定义 388（信任校准环 TCL）** 信任 t_h 为隐状态，机器人估计 t̂_h；**适当信任** t*_h 应与系统认证可靠性 R_sys 匹配。校准误差 e_trust = |t̂_h − t*_h|。信任动力学：
t_h^{t+1} = t_h^t + α(observed outcome − t_h^t) + β·Comm(g_c) + ξ，
其中 Comm 为沟通注入（披露不确定度/展示近失效可下调过度信任，虚假承诺会抬升信任）。**信任-可靠性共校准不变式**：|E[t_h] − R_sys| ≤ ε_trust 在认证时域内成立；违反 ⇒ 触发校准沟通动作（定义 387），校准失败 ⇒ 人因通道 stub + 风险厌恶抬升 λ，并**显式告知已降级**（不得静默自主）。

**定义 389（闭环证据漂移与环增益）** 闭环状态 x_t = (b_t(s), b_t(θ_h), adapter 集, t_h)。环算子 F = 数据生成 ∘ 适配器训练 ∘ 行为/沟通 ∘ 人因反馈。**环增益**
ρ_loop = ‖∂x_{t+1}/∂x_t‖（谱半径）。闭环证据漂移 d_drift(T) = Σ_{t≤T} TV(p_evidence^predicted, p_evidence^realized)。**认证条件**：ρ_loop < 1 − δ 且 d_drift(T) ≤ Drift_max(T)。**反馈回声室**定义为 adapter 在无外生人类样本、且沟通策略固定时 b_t(θ_h) 的熵单调塌缩（后验过度自信）。

**定义 390（交互证据因果图 IECG）** 扩展 R73 的 ECG。节点 = {证据模块, 适配器, 人因状态, 沟通动作, 信任}；边 = 条件/调制依赖，标注是否消耗预算、是否带否决。R73 的 L3/L4 同构（动作→观测→噪声→估计→动作）在此扩展为 L5（沟通→人因噪声/信任→证据→行为→沟通）。**环检测**：IECG 中出现正反馈环且 ρ_loop ≥ 1 ⇒ 审计不通过；因果链断裂 ⇒ 安全拒绝（继承 R73 附录思想），而非仅不确定度累积。

**定义 391（主张-证明绑定扩展 CPB†）** 保留 C1/C2/C3，新增：
- **C4（增量可证 / Delta certifiability）**：低秩适配器包络证书在**校准质量与下游安全**上使持续微调可认证；相比「整模型重训 + 全系统重审」或「无包络热插拔」，认证成本大幅下降且安全漂移有界。绑定 (DAC, ALA) ← MB4 ← AB4 ← (包络紧度比, 热替换安全漂移, 认证成本比)。
- **C5（交互可校准 / Interaction calibratability）**：把人因证据六分量与信任校准显式建模并计入反作用预算，比「把人当 oracle」或「只优化 human cost」在**适当依赖率、过度信任致败率、干预成本**上显著更优，且闭环漂移有界。绑定 (HEM, TCL, IECG) ← MB5 ← AB5 ← (适当依赖率, over-trust 致败率, 环增益估计误差)。
非绑定组件 = 工程附件，不进 MReg、不进正文。

**定义 392（可塑-可证域 D_cert(η)）** 对契约声明安全界 ε_mod，可证运行域 D_cert(η_Δ) = {x ∈ D : margin(x) ≥ ε_mod + η_Δ}。**可塑-可证权衡**：η_Δ ↑ ⇒ D_cert 单调收缩（或 ε_mod 单调增大）。认证时必须**同时**声明 (η_Δ, D_cert)，只声明其一是无效证书。

**定义 393（模块/适配器/人因的 stub 语义扩展）** 适配器 stub：回退基座 W₀（ΔW=0），包络 η=0，继承基座证书；人因 stub：y_h=∅、u_h=∞、D_h=∅、I⊥=本通道全集、χ_H 平凡，同时抬升自治风险厌恶 λ 并**显式向人披露已切换自主**；与 R73 模块 stub 一致，stub 仍参与 MReg† 连通性校验。

**定义 394（认证成本扩展 CertCost†）** CertCost† = Σ_模块(SEAL + conformal) + Σ_适配器(基座复用 + 包络核验 O(r(d_in+d_out)) + 溯源审计) + 人因研究成本(SEAL-H 校准 + IRB) + 组合校验 + **闭环审计成本**。C4 可证伪形式：热替换 CertCost† 比 ≈ 适配器成本 / 全模型成本 > 10×；C5 的可证伪形式：人因建模使校正后的适当依赖率显著提升且研究成本可复现。

**定义 395（人因密封审计集 SEAL-H）** 预注册人类样本（分层：专长×负荷×信任倾向×是否对抗）、密封保持集、禁止被 adapter 训练数据污染；含**反事实子集**（同一状态、不同沟通动作）用于隔离 χ_H 与 TCL。没有外生人类样本的闭环审计视为无效（防回声室）。

**定义 396（复杂度结构上限扩展）** |V_M| ≤ 32（含适配器与人因通道）、组合深度 ≤ 5、|𝓗| ≤ 5、adapter 数 ≤ 16、rank ≤ 64、环长 ≤ 3、IECG 节点 ≤ 96——全部为 MReg†/IECG 的可审计图性质（部署期 + 运行时增量校验）。

## 2. 关键算法骨架

```python
# IP-303 DAC：增量适配器契约与包络证书（部署期 + 增量更新）
@dataclass(frozen=True)
class DeltaContract:
    ec: EvidenceContract                 # 继承 R73 契约
    base_hash: str                       # W0 内容哈希（基座变则作废）
    B: Tensor; A: Tensor; rank: int      # ΔW = B @ A
    provenance: Provenance               # 微调数据溯源（人/会话/授权/用途）
    eta_delta: float                     # 认证行为包络（定义 384）
    delta_forget: float                  # 基座任务保留界
    tau_prov: Callable                   # 溯源合并

def certify_delta(base, B, A, domain, input_bound):
    # 引理 38：输出位移上界 = σmax(B)·σmax(A)·‖x‖，多层复合 Lipschitz
    env = spectral_norm(B) * spectral_norm(A) * input_bound
    env = compose_lipschitz(base, env)            # 沿下游模块传播
    forget = heldout_base_loss_delta(base, B, A)  # δ_forget 经验核验
    return DeltaContract(..., eta_delta=env, delta_forget=forget)

# IP-304 ALA：适配器组合代数（对应 CCA 的 SER/PAR/VETO）
def compose_adapter(a, b, op):
    assert a.base_hash == b.base_hash             # 不同基座不可合并
    if op == 'MERGE':
        inter = interference(a.B, a.A, b.B, b.A)  # 同奇异方向作用重叠
        if inter > I_MAX: return SER(a, b)        # 干扰超限 → 降级顺序组合
        return Delta(eta=a.eta + b.eta + inter,
                     forget=max(a.delta_forget, b.delta_forget),
                     prov=a.tau_prov.merge(b.tau_prov))
    if op == 'SER':                               # 顺序：先低 L 后高 η 更安全
        return Delta(eta=a.L * b.eta + a.eta, ...)
    if op == 'GATE':                              # 路由须在域内可证
        assert router_certified(a, b)
        return Delta(eta=sum(w * e for w, e in zip(weights(a, b), (a.eta, b.eta))), ...)
    # VETO：任一越预算/断链 → 整体否决（非补偿）

# IP-305 HEM：人因证据计量（人因域，事件触发）
class HumanEvidenceMetrology:

# IP-306 TCL：信任校准环（计量域，低频）
def trust_calibration_step(t_hat, R_sys, b_theta, budget):
    e = t_hat - R_sys
    if abs(e) <= EPS_TRUST: return None, 0.0        # 已校准，不打扰
    if e > 0: g_c = 'disclose_uncertainty'          # 过度信任 → 披露/展示近失效
    else:     g_c = 'explain_reliability'           # 信任不足 → 解释可靠性
    cost = interrupt_cost(g_c) + trust_kl(b_theta, g_c)
    if budget.spent + cost > budget.B: return None, cost   # 非补偿拒绝
    return g_c, cost                                # 沟通 = 安全执行器（定义 388）

# IP-307 LoopAudit：闭环稳定性与回声室检测（计量域，低频）
def closed_loop_audit(history, adapter_set, b_theta):
    rho = estimate_loop_gain(history)               # ∂x_{t+1}/∂x_t 谱半径
    drift = evidence_drift(history)                 # TV 累积
    echo = posterior_entropy_collapsed(b_theta) and not has_exogenous_humans(history)
    stable = (rho < 1 - DELTA) and (drift <= Drift_max(history.t))
    return stable, dict(rho=rho, drift=drift, echo=echo)
```

## 3. 推导

**引理 38（增量包络的廉价比界）** 对线性层 y = W x + b，ΔW=BA，若 ‖x‖₂ ≤ X，则 ‖ΔW x‖₂ ≤ σ_max(B)σ_max(A)·X。多层网络利用各层 Lipschitz 常数复合（L_total = Π L_i）得到全局包络。⇒ 包络核验代价 O(r(d_in+d_out))，与基座规模无关。系：**持续微调的认证可以随参数增量走，而不必随模型规模走——这是 C4 的成本基础。**

**引理 39（适配器组合的单调包络）** MERGE：η₁₂ ≤ η₁+η₂+I，I≥0；SER：η₁₂ ≤ L₁η₂+η₁ ≥ η₁；GATE：凸组合不产生低于 min(ηᵢ) 的包络；VETO 只收缩有效域。⇒ 任何 ALA 组合路径的包络不低于其输入的单调组合，且缩窄仅在干扰可证、路由可证时发生。系：**行为组合与证据组合共享同一条「无认知免费午餐」原则（对照引理 34）。**

**引理 40（适配器热替换的有界保持）** 若 base_hash 不变、EC 相同、且 η_Δ ≤ ε_mod − ε_safety_reserve，则 R73 的全部系统级性质（退化链、风险单调、时序隔离、审计覆盖）在 D_cert(η_Δ) 内保持，且安全界至多漂移 η_Δ。η_Δ = 0 时逐指令退化为引理 35。系：**从「精确保持」到「有界保持」是 PEFT 时代热替换的唯一诚实形式。**

**引理 41（人因六分量的条件近正交性与策略分离）** 给定 (ψ_h, κ, θ_h)，六分量由不同机制产生（技能、认知资源、信任偏差、动机、视角、沟通保真），条件近似不相关；策略性由类型后验 b_t(θ_h) 单独承载。遗漏任一分量 ⇒ 系统性高估人类可靠性（与 R73 引理 33 同型，条件集扩为沟通上下文与人类类型）。系：**「人也是传感器」不是比喻，而是同一条计量公理的实例。**

**引理 42（人因证据的有效样本量衰减）** 设单次人类观测的 Fisher 信息为 I_h(θ)，则 I_h(θ | u_load, e_trust) ≤ I_max·(1 − u_load/u_max)·(1 − e_trust/e_max)。故 n 次反馈的有效样本量 n_eff ≈ n·I_h/I_max。⇒ 「人越多越好」不成立：高负荷+信任错配下，更多反馈可能只增加噪声而不增加信息。系：**忙碌/过度信任的人不是更多标签，而是更少信息。**

**引理 43（闭环有界性）** 若环增益 ρ_loop < 1−δ、信任更新为压缩映射（α<1 且 |β·Comm| 有界）、人因有效样本量有正下界（引理 42），则闭环存在不变集，且 d_drift(T) ≤ Drift_max(T) = d_0/(1−ρ_loop)。⇒ 「人在环」不自动安全，只有当环收缩时才安全。系：**这是把开环 J_MOD 升级为闭环证书的唯一数学支点。**

**定理 30（PACT 严格包含 MODGAUGE）** 令 ΔW=0（或 adapter stub）、人因通道为 u_h=0 的外生 oracle、e_trust=0、ρ_loop=0，则 PACT 逐指令等于 MODGAUGE-RAS（定义 366），再退化等于 R72/R71/R68。**安全单调不减；可塑性与信任校准只在证书满足时获益。**

**定理 31（可塑-可证权衡定理）** 对固定安全界 ε_mod 与固定契约，D_cert(η_Δ) 关于 η_Δ 单调不增；且不存在同时满足「η_Δ 任意大」与「D_cert = D（满域）」的证书。**证明**：由定义 392，margin(x) ≥ ε_mod + η_Δ；η_Δ 增大则满足该式的 x 集合收缩。⇒ **个性化/可塑性的代价必须显式写进证书，否则系统在 η_Δ 超过某阈值后即在「证书有效」下违反安全声明。** 这是本轮最核心的可证伪命题，直接对标 R73 的「组合无免费午餐」。

**定理 32（信任-可靠性共校准是安全的必要条件）** 若 E[t_h] − R_sys 持续 > ε_trust（过度信任）超过时域 T，则期望风险随时域单调上升（监督概率随信任上升而下降 ⇒ 有效否决概率下降）。⇒ 安全保持的交互系统必须主动把 |E[t_h] − R_sys| 约束在 ε_trust 内。系：**沟通是安全执行器，不是 UX 装饰——这把 HCI 纳入控制回路。**

**定理 33（闭环证伪性：反回声室）** 若 adapter 仅由同一人类类型分布、同一沟通策略下的反馈训练，且无外生人类样本（SEAL-H）与反事实审计，则 b_t(θ_h) 的熵单调塌缩（后验过度自信），引理 41 的条件正交性失效，闭环证据漂移无界。⇒ **闭环审计必须包含外生样本与反事实子集，否则「闭环稳定」是自我实现的假象。**

## 6. 本轮最大风险

**一句话**：PACT 的闭环证书建立在我们能够**认证「人的证据模型」与「信任动力学」**之上——但人是策略性、非平稳、且会被测量本身改变的（观察者效应/Goodhart）：一旦人类学会机器人会按 t̂_h 校准、或 adapter 与沟通策略共同把反馈分布塑造成自己想要的样子，闭环稳定性定理可能在一套数学上自洽、IECG 上无环、所有包络与共校准都「通过」的系统里，认证出一个**被交互本身不断改写的「人」**，于是系统会以最高置信度信任一份已经失效的人因契约。

次级风险与缓解：
1. **包络过松（尤其非线性/循环/下游放大）** → 分段 Lipschitz + 实测校准回写 η_Δ + 超界即 stub；只信实测核验的包络。
2. **低秩 ≠ 行为有界**（注意力/归一化/循环使 ΔW 扰动被放大）→ 端到端包络核验（引理 38 的多层复合）+ 基座哈希绑定 + 域硬边界。
3. **适配器合并干扰被低估** → 干扰项证书 I + 同奇异方向检测；不确定时禁用 MERGE，退 SER。
4. **信任测量效度（心理测量学）** → 多指标（行为依赖率/自报告/干预率）三角验证；只用行为指标进安全回路，自报告仅作辅助。
5. **人因研究成本与伦理** → SEAL-H 最小分层样本 + IRB + 预注册；C5 只认预注册指标，避免 p-hacking。
6. **回声室/自训练漂移** → 强制外生人类样本 + 反事实子集 + 环增益监控（定理 33）；漂移超界即冻结 adapter 更新。
7. **可塑-可证权衡被隐藏** → 证书必须同时声明 (η_Δ, D_cert)，禁止只报其一；E399 专测此反例。
8. **降级不透明导致信任崩塌** → 人因 stub 必须显式披露自主（定义 393），并把披露本身计入 χ_H 预算。

## 2. 形式化定义（要点版）

**定义 383（PACT-RAS 与六不变式）** 契约完整性 / 组合单调性 / 反作用通道完备（χ_R, χ_Δ, χ_H）/ 主张绑定 / 严格退化链 / **闭环有界性（新增）**。前五条是 R73 的继承，第六条是本轮唯一新公理。

**定义 384（ΔC 增量适配器契约）** 适配器 = (EC, 基座哈希, (B,A,r), 溯源 𝒟, η_Δ, δ_forget, τ_prov)。包络只在同一基座下有效；无溯源不可入图；η_Δ 由谱范数×输入界核验。

**定义 385（ALA 适配器组合代数）** MERGE：η≤η₁+η₂+I，I 超限则降 SER；SER：η≤L₁η₂+η₁（顺序不可交换）；GATE：凸组合且路由须域内可证；VETO：任一越界即否决（非补偿）。基座哈希不同不可合并。

**定义 386（HEM 人因证据计量）** p_h(y_h|s,ψ_h,κ,θ_h)；六分量各有追溯链；类型后验 b_t(θ_h) 在线推断；有效域 D_h；失效即人因 stub。

**定义 387（χ_H 第五反作用层）** 提问/解释/等待/交接/确认/示范各自调制 u_observability / u_workload / u_trust / u_expertise；成本 c_reflex^H 并入 ΣREFLEX†。

**定义 388（TCL 信任校准环）** 适当信任 t*_h=R_sys；共校准不变式 |E[t_h]−R_sys|≤ε_trust；违反触发校准沟通；校准失败 ⇒ 人因 stub + λ 抬升 + **显式披露自主**。

**定义 389（闭环证据漂移/环增益）** 状态含 b_t(s)、b_t(θ_h)、adapter 集、t_h；认证 ρ_loop<1−δ 且 d_drift(T)≤Drift_max(T)；反馈回声室 = 后验熵单调塌缩且无外生样本。

**定义 390（IECG 交互证据因果图）** 节点含证据/适配器/人因/沟通/信任；边带预算与否决标注；正反馈环且 ρ_loop≥1 ⇒ 审计不通过；断链 ⇒ 安全拒绝。

**定义 391（CPB† 主张绑定）** C1 物理感知证据计量 / C2 反作用预算组合 / C3 契约式模块化（继承）；**C4 增量可证**（DAC,ALA ← MB4 ← AB4 ← 包络紧度、热替换漂移、认证成本比）；**C5 交互可校准**（HEM,TCL,IECG ← MB5 ← AB5 ← 适当依赖率、over-trust 致败率、环增益误差）。非绑定=工程附件。

**定义 392（可塑-可证域）** D_cert(η_Δ) = {margin ≥ ε_mod + η_Δ}；证书必须同时声明 (η_Δ, D_cert)，只报其一无效。

**定义 393（stub 扩展）** 适配器 stub ⇒ 回退基座（η=0，继承基座证书）；人因 stub ⇒ y_h=∅, u_h=∞, D_h=∅, χ_H 平凡，且抬升 λ、**显式披露自主**；stub 仍参与 MReg† 连通校验。

**定义 394（CertCost†）** 模块 + 适配器(基座复用 + 包络 O(rd) + 溯源) + 人因(SEAL-H + IRB) + 组合 + 闭环审计。C4 可证伪：热替换 CertCost† 比 >10×。

**定义 395（SEAL-H）** 分层人类样本（专长×负荷×信任倾向×是否对抗）+ 密封保持集 + **反事实子集**（同状态不同沟通动作）；禁止被 adapter 训练污染。

**定义 396（复杂度结构上限）** |V_M|≤32、组合深度≤5、|𝓗|≤5、adapter 数≤16、rank≤64、环长≤3、IECG 节点≤96——MReg†/IECG 可审计图性质。

```python
# IP-303 DAC：增量适配器契约与包络证书
@dataclass(frozen=True)
class DeltaContract:
    ec: EvidenceContract
    base_hash: str; B: Tensor; A: Tensor; rank: int
    provenance: Provenance
    eta_delta: float; delta_forget: float
    tau_prov: Callable

def certify_delta(base, B, A, domain, input_bound):
    env = spectral_norm(B) * spectral_norm(A) * input_bound   # 引理 38
    env = compose_lipschitz(base, env)                        # 多层复合
    forget = heldout_base_loss_delta(base, B, A)
    return DeltaContract(..., eta_delta=env, delta_forget=forget)

# IP-304 ALA：适配器组合代数
def compose_adapter(a, b, op):
    assert a.base_hash == b.base_hash
    if op == 'MERGE':
        inter = interference(a.B, a.A, b.B, b.A)
        if inter > I_MAX: return SER(a, b)                    # 干扰超限降级
        return Delta(eta=a.eta + b.eta + inter,
                     forget=max(a.delta_forget, b.delta_forget),
                     prov=a.tau_prov.merge(b.tau_prov))
    if op == 'SER':
        return Delta(eta=a.L * b.eta + a.eta, ...)
    if op == 'GATE':
        assert router_certified(a, b)
        return Delta(eta=sum(w * e for w, e in zip(weights(a, b), (a.eta, b.eta))), ...)
    # VETO: any envelope breach / broken provenance => reject

# IP-305 HEM：人因证据计量
class HumanEvidenceMetrology:
    def update(self, y_h, session, comm_ctx, robot_state):
        theta_post = self.type_infer(y_h, session.history, comm_ctx)
        u_exp = self.calib.expertise(session.skill)
        u_load = self.calib.workload(session.latency, session.interrupts)
        u_tr  = self.calib.trust_error(session.trust_est, self.R_sys)
        u_st  = self.calib.stake(theta_post)
        u_obs = self.calib.observability(robot_state, comm_ctx)
        u_com = self.calib.communication(comm_ctx)
        valid = (theta_post['adversarial'].prob < TAU_ADV) and (u_load < TAU_LOAD)
        return HumanEvidence(lik=p_h(y_h, robot_state, comm_ctx, theta_post),
                             theta_post=theta_post, valid=valid,
                             u=norm6(u_exp, u_load, u_tr, u_st, u_obs, u_com),
                             chi_H=chi_human(comm_ctx))

# IP-306 TCL：信任校准环（沟通 = 安全执行器）
def trust_calibration_step(t_hat, R_sys, b_theta, budget):
    e = t_hat - R_sys
    if abs(e) <= EPS_TRUST: return None, 0.0
    g_c = 'disclose_uncertainty' if e > 0 else 'explain_reliability'
    cost = interrupt_cost(g_c) + trust_kl(b_theta, g_c)
    if budget.spent + cost > budget.B: return None, cost     # 非补偿拒绝
    return g_c, cost

# IP-307 LoopAudit：闭环稳定性与回声室
def closed_loop_audit(history, adapter_set, b_theta):
    rho = estimate_loop_gain(history)                        # 谱半径
    drift = evidence_drift(history)
    echo = posterior_entropy_collapsed(b_theta) and not has_exogenous_humans(history)
    stable = (rho < 1 - DELTA) and (drift <= Drift_max(history.t))
    return stable, dict(rho=rho, drift=drift, echo=echo)

# IP-308 PACT 主闭环
def PACT_round(M, obs, audio, tac_frame, depth_img, y_h, session):
    d_ev = M.dpe.update(depth_img, rgb, M.cam_state, M.motion, M.peers)
    t_ev = M.dmem.update(tac_frame, M.last_action)
    h_ev = M.hem.update(y_h, session, M.comm_ctx, M.last_state)
    if not h_ev.valid: h_ev = stub_human(M.hem)              # 定义 393

    if M.clock.due_metric():
        b_t = M.bse.step_full(..., d_ev=d_ev, t_ev=t_ev, h_ev=h_ev)
        cand = [a for a in M.adapters if M.mreg.delta_admissible(a, b_t.domain)]
        a_sel = min(cand, key=lambda a: a.eta_delta)         # 最保守优先
        pi = M.policy.with_delta(a_sel)
        g_c, c_h = trust_calibration_step(M.t_hat, M.R_sys, h_ev.theta_post, M.budget)
        g = M.ervoi.choose(b_t, ..., h_ev, M.budget)
        s2, cost = sigmareflex_step(M.mods, g, M.state, M.budget)
        h2, cost_h = human_reflex_step(M.hem, g_c, M.human_state, M.budget)
        if s2 is None or h2 is None: g = None                # 任一越界即拒绝
        M.loop_ok, M.loop_diag = closed_loop_audit(M.history, M.adapters,
                                                   h_ev.theta_post)
        if not M.loop_ok: M.risk_params.lam *= SAFETY_BUMP
        M.snapshot.write(b_t, h_ev, a_sel, g_c, M.loop_diag)
        M.mreg.audit(); M.iec.audit()
    snap = M.snapshot.read_latest()
    lam = embodied_risk_scale(snap.U_ale, snap.U_epi, snap.H_z,
                              max(snap.t_ev.u, snap.d_ev.u, snap.h_ev.u),
                              M.risk_params)
    A = M.ach.propose_ctrl(..., pvop_bias=snap.pvop)
    k = M.c_ras_wm.certified_prefix(A, lam)
    M.ctrl_out.publish(k, lam)
    return k, lam, J_MOD_dagger(M.mreg, M.adapters, M.hem)  # 组合 + 闭环证书
```

## 4. 推导

**引理 38（增量包络的廉价比界）** 线性层 ΔW=BA，‖x‖≤X ⇒ ‖ΔWx‖ ≤ σ_max(B)σ_max(A)X；多层用 Lipschitz 复合。包络核验 O(r(d_in+d_out))，与基座规模无关。系：**认证随增量走，不随模型规模走。**

**引理 39（适配器组合单调包络）** MERGE：η≤η₁+η₂+I（I≥0）；SER：η≤L₁η₂+η₁；GATE：凸组合不低于 min(ηᵢ) 下界；VETO 收缩域。⇒ 无「合并后更安全」路径。系：**行为组合与证据组合共享「无免费午餐」（对照引理 34）。**

**引理 40（适配器热替换有界保持）** base_hash 不变、EC 相同、η_Δ ≤ ε_mod−ε_reserve ⇒ R73 全部系统级性质在 D_cert 内保持，安全界至多漂移 η_Δ；η_Δ=0 退化为引理 35。系：**「有界保持」是 PEFT 时代热替换的唯一诚实形式。**

**引理 41（人因六分量条件近正交 + 策略分离）** 给定 (ψ_h,κ,θ_h)，六分量机制不同、条件近似不相关；策略性由 b_t(θ_h) 承载。遗漏 ⇒ 系统性高估人类可靠性。系：**「人也是传感器」是同一条计量公理的实例。**

**引理 42（人因有效样本量衰减）** I_h(θ|u_load,e_trust) ≤ I_max(1−u_load/u_max)(1−e_trust/e_max) ⇒ n_eff ≈ n·I_h/I_max。系：**高负荷/过度信任的人不是更多标签，而是更少信息。**

**引理 43（闭环有界性）** ρ_loop<1−δ、信任更新压缩、人因有效样本量有正下界 ⇒ 存在不变集，d_drift(T) ≤ d_0/(1−ρ_loop)。系：**这是把开环 J_MOD 升为闭环证书的数学支点。**

**定理 30（PACT 严格包含 MODGAUGE）** ΔW=0 + 人因 oracle（u_h=0,e_trust=0）+ ρ_loop=0 ⇒ 逐指令等于 MODGAUGE-RAS，再退化等于 R72/R71/R68。安全单调不减。

**定理 31（可塑-可证权衡）** D_cert(η_Δ) 关于 η_Δ 单调不增；不存在「η_Δ 任意大 且 D_cert=D」的证书。证明：margin(x) ≥ ε_mod+η_Δ 的满足集随 η 收缩。⇒ **个性化/可塑性的代价必须写进证书。** 本轮的「无免费午餐」主命题。

**定理 32（信任-可靠性共校准是安全必要条件）** 过度信任 |E[t_h]−R_sys|>ε_trust 持续 T 时，监督概率下降 ⇒ 有效否决概率下降 ⇒ 期望风险单调上升。⇒ 必须主动约束信任误差。系：**沟通是安全执行器。**

**定理 33（闭环证伪性：反回声室）** 若 adapter 仅由同一类型分布、同一沟通策略的反馈训练且无外生样本/反事实审计 ⇒ b_t(θ_h) 熵塌缩、引理 41 失效、漂移无界。⇒ **闭环审计必须含外生样本与反事实子集。**

## 8. 本轮最大风险

**一句话**：PACT 的闭环证书建立在我们能够认证「人的证据模型」与「信任动力学」之上——但人是策略性、非平稳、且会被测量本身改变的：一旦人类学会机器人会按 t̂_h 校准，或 adapter 与沟通策略共同把反馈分布塑造成自己想要的样子，闭环稳定性定理可能在一套数学上自洽、IECG 无环、所有包络与共校准都「通过」的系统里，认证出一个被交互本身不断改写的「人」——系统会以最高置信度信任一份已经失效的人因契约。

次级风险与缓解：
1. 包络过松（非线性/循环/下游放大）→ 分段 Lipschitz + 实测回写 η_Δ + 超界即 stub。
2. 低秩 ≠ 行为有界（注意力/归一化放大扰动）→ 端到端多层包络 + 基座哈希绑定 + 域硬边界。
3. 合并干扰低估 → 干扰证书 I + 同奇异方向检测；不确定即禁 MERGE 退 SER。
4. 信任测量效度 → 行为指标进安全回路，自报告仅辅助；多指标三角验证。
5. 人因研究成本/伦理 → SEAL-H 最小分层 + IRB + 预注册，只认预注册指标。
6. 回声室/自训练漂移 → 强制外生样本 + 反事实子集 + 环增益监控，超界冻结 adapter 更新。
7. 可塑-可证权衡被隐藏 → 证书必须同时声明 (η_Δ, D_cert)；E399 专测反例。
8. 降级不透明 → 人因 stub 显式披露自主，披露本身计入 χ_H 预算。
