# 第 2 轮迭代 · 分支 B（灵感循环：「开源生态」×「触觉感知」）—— 向开源生态借“皮肤”，把触觉蒸馏成可归因的接触事件

> **承接 v2，不推倒。** v2（Gazebo × 实时性 × 模块化）的旗舰是“检测进度被撤回 → 重做”，但它的判据是**视觉状态**：看到子目标从 `done` 退回 `undone`。视觉看到的是“结果”，看不到“接触过程”；而 `human_*` 的撤回恰恰是**接触事件的反向序列**——拧回、拉开、翻开、拿走、叠好后拿下第二个。等视觉确认“退回了”，往往已经浪费了一个动作块，甚至丢掉了前置步骤分。
>
> 本轮两个灵感词正好补上这个缺口：
> - **「触觉感知」**：官方接口没有触觉、没有力/力矩、没有深度，Dex1-1 也没有触觉阵列。但触觉信息没有消失，它泄漏在**双目视差、腕部近景、夹爪指令-开度差、EE 跟踪误差**里。更关键的是：触觉不是“一个力值”，而是**接触事件的语言**——`make / sustain / slip / break / reverse`。感知触觉，等于推断“现在处于哪种接触相位、接触发生在哪、是否稳定、进行到多深、是谁造成的”。
> - **「开源生态」**：触觉教师不在真机上，而在开源生态里——物理引擎的接触力/接触点、TACTO/TacSL/DiffTactile 的虚拟触觉、DIGIT/GelSight 触觉数据、Ego4D/EPIC-Kitchens 的人类手-物交互视频、OpenVLA/π0/GR00T/SmolVLA 的预训练权重、LeRobot/Isaac Lab 的工具链。开源生态既是“免费皮肤”，也是“供应链风险”：预训练污染、许可不兼容、多检查点拼装都可能让增益不可信或不合规。
>
> **一句话押注：用开源生态的“皮肤”做教师，蒸馏出无触觉、可归因、可校准的接触信念；用它把 v2 的“视觉撤回检测”升级为“接触事件反向检测”，并用开源生态审计保证增益可信。**

## 0. 直觉先行（30 秒版）

1. **最贵的失败不是“抓不到”，而是“接触没管好”。** 32 个任务里最难的一批——插网线（T26）、开锁（T12）、拧药瓶（T14）、拉拉链（T19）、叠毛巾（T16）、装手机（T29）、整理文具袋（T31）——共同点不是“力越大越好”，而是**在正确的时间知道“碰上了/夹住了/到位了/滑了/卡了/被谁动了”**。这恰好是“触觉感知”的定义，而不是“再加一个传感器”。
2. **接口没有触觉，但接触信息在四个地方泄漏。** 头戴双目是已校正的立体对，近距离可算毫米级深度；腕部相机在夹爪闭合时看得见接触面、间隙、遮挡和滑移；命令继续闭合而实际开度停住 = 夹到东西；位置控制器下实际位姿落后于指令 = 外部接触/阻力。四个信号各有明确失效条件，必须**可靠性加权融合**，不能二选一。
3. **“检测到撤回”不够，还要“归因”。** 同样是“进度被撤回”，机器人自己没夹稳、人类伸手把毛巾翻开、环境让碗滑落，最优响应完全不同：自己失败→重试/重抓；人类撤回→让行/重做/稳住；环境滑落→恢复/降速。v2 的“一律重做”会烧步骤分和延迟。**接触归因把“发生了什么”升级为“谁导致的、为什么”。**
4. **开源生态是唯一能提供“触觉教师”的地方。** 真机不能加传感器；但物理引擎知道每一次接触的力、接触点、接触对象和接触体（机器人/人/环境）；开源触觉模拟器能渲染虚拟触觉；开源人类视频能教“人手如何撤回一个已完成动作”。**用教师标签训练，用学生部署**，是唯一同时满足“无额外硬件 + 单模型 + 真机接口”的路线。

**边界（必须先说清楚）：**
- 不声称测量“牛顿力”。没有标定就没有力的大小；只声称**接触存在、相位、位置、稳定性、相对进度、归因**。
- 不声称“替代触觉”。透明、柔性、低力、静态接触、完全遮挡会失效；必须给出负结果和回退。
- 不声称开源模型“一定干净”。预训练污染、许可、版本漂移是**必须审计的风险**，不是脚注。
- 不声称仿真=真机。仿真教师只提供**结构/事件/归因**监督，成败与像素级接触仍需真机锚点校准。

## 2. 严谨定义：从“触觉信号”到“可归因接触事件”

### 2.1 定义 1（特权触觉 POMDP）

令任务为 POMDP `M = (S, A, O, T, R, γ)`。真实状态 `s_t ∈ S` 包含物体位姿、接触图、接触相位与任务阶段。可观测 `o_t = Ω(s_t) ∈ O` 只含 4 路 RGB、本体与语言；**特权触觉** `τ_t = Ω_τ(s_t) ∈ T` 只在训练/仿真中可得，包含接触力旋量、接触点、接触对象、接触体（机器人 link / 人手 / 环境）与穿透/滑移速度。

- 教师：`T_τ: S × T → Δ(C)`，把特权状态映射为接触状态分布。
- 学生：`S_θ: O^{t-H+1:t} → Δ(C)`，只吃可观测历史，输出接触状态信念。
- 策略：`π_φ: O^{t-H+1:t} → Δ(A)`，与学生**共享编码器**（单模型合规）。
- 蒸馏目标：

```text
L(θ) = E[ KL( T_τ(c | s, τ) || S_θ(c | o_{t-H+1:t}) ) ]
     + λ1 · CalibrationLoss(S_θ)
     + λ2 · GrammarConsistency(S_θ; G_g)
```

第三项把“接触相位必须沿着合法事件序列转移”作为结构先验，既提样本效率，也压掉不可能转移（例如无 `make` 直接 `sustain`）。

### 2.2 定义 2（接触状态）

接触状态是一个**因子化**变量，而不是单个标量：

```text
c_t = (e_t, φ_t, l_t, σ_t, d_t, ι_t)
```

- `e_t ∈ {0,1}`：是否存在接触（机器人-物体或物体-物体）。
- `φ_t ∈ Φ = {free, approach, make, sustain, slip, break, jam}`：接触相位。
- `l_t ∈ L`：接触位置/接触对（左/右夹爪面、指尖、物体表面、容器边缘）。
- `σ_t ∈ [0,1]`：抓握稳定性（未来 Δt 内不滑移的概率）。
- `d_t ∈ R≥0`：相对啮合/插入/折叠/拉链进度（不是牛顿力）。
- `ι_t ∈ {robot, human, environment, unknown}`：**接触归因**，即这次接触事件由谁造成。

`ι_t` 是本轮的关键增量：它把“触觉感知”从“检测到接触”推进到“接触的因果来源”。仿真教师可以精确给出 `ι_t`（接触体 ID），学生从视觉（人手检测、物体异常运动）与本体（非自身动作导致的位姿变化）中推断。

### 2.3 定义 3（接触事件语法）

对每个技能 `g`，定义**概率有限状态自动机**：

```text
G_g = (Q_g, Σ_g, δ_g, q_0, F_g, D_g)
```

- `Σ_g = {make, sustain, slip, break, depth+, depth−, reverse}` 是接触事件字母表；
- `δ_g: Q_g × Σ_g → Δ(Q_g)` 是带概率的转移；
- `D_g` 是每个状态的持续时间分布（用 HSMM/半马尔可夫处理时序不确定性）；
- `F_g ⊆ Q_g` 是完成态；`R_g ⊆ Q_g` 是**反向态**（撤回）。

一个计分步 `g` 的完成，不是“看到某个静态状态”，而是**自动机到达 `F_g`**；`regressed` 不是“视觉状态退回”，而是**到达 `R_g`，或 `sustain` 后出现反向 `break`/`depth−`**。用前向滤波维护相位后验：

```text
b_t(q) ∝ Σ_{q'} b_{t-1}(q') · P(q | q') · P(e_t | q)
```

判据：

```text
done      ⇔ b_t(F_g) > τ_done
regressed ⇔ b_t(R_g) > τ_rev  ∨  (b_t(sustain→break_reverse) > τ_rev)
fail      ⇔ b_t(jam) > τ_jam
ongoing   ⇔ otherwise
```

**示例（T19 ZipUp）：**
- 正向：`approach → make(track) → sustain(along track, depth+) → break(end)`。
- 反向：`make → sustain(reverse direction, depth−) → break(start)`。
- 归因：若反向事件伴随“人手进入画面 + 夹爪未动”，`ι=human`；若夹爪仍在拉但 `depth−`，`ι=robot`（打滑/脱轨）；若两者都无但物体下落，`ι=environment`。

### 2.4 定义 4（可辨识性与校准弃权）

接触状态**不是**从 `o_t` 完全可辨识的：遮挡、透明物体、小间隙、静态接触都会让视觉退化。定义 `ε`-可辨识：存在学生 `S` 使 `E[||S(o)-c||] ≤ ε`；一般情形不成立。因此学生必须输出**校准信念**，而不是硬标签。用 conformal prediction 构造接触集合：

```text
C_α(o_t) = { c : score(o_t, c) ≤ q_{1-α} }
```

并保证 `P(c_t ∈ C_α(o_t)) ≥ 1-α`（在可交换性假设下）。验证器只有在**反向集合与完成集合不相交**、且反向后验超过阈值时才触发 `regressed`；否则**弃权/主动微探**。这给“假撤回重做率”一个统计护栏。

### 2.5 定义 5（开源生态组合图与单模型合规）

把提交视为有向无环图 `G = (V, E)`：节点是数据、权重、代码、仿真场景；边是组合操作（微调、蒸馏、提示、调用）。定义：

- **单模型合规**：推理子图恰有**一个学习骨干**；其他学习节点要么已蒸馏进骨干，要么是与骨干共享参数的 PEFT 头；非学习确定性变换（归一化、几何、滤波）不受限。推理期调用外部 VLM/API 视为不合规。
- **可复现**：每个节点有固定版本/哈希/种子，评测可回放（硬件非确定性除外）。
- **许可兼容**：边标签满足许可证蕴含关系；GPL/AGPL 进入分发路径需隔离或替换。
- **污染风险** `ρ`：模型训练数据与评测分布的重叠风险。无法证明“无污染”，只能用 canary/改写/OOD 探针估计。

### 2.6 定义 6（生态组合选择）

给定候选骨干 `B={b_1..b_m}`、数据 `D`、仿真器 `S`、触觉资产 `T`，选择**一个**骨干与一组 PEFT 头，最大化：

```text
U = α·E[success] + β·E[step_score] − γ·E[latency] − δ·ρ_contam − ε·r_license
s.t.  memory ≤ M,  latency ≤ L,  single_model_compliant,  license_compatible
```

这把“开源生态”从购物清单变成**受约束的选择问题**：不是“用最大的模型”，而是“在合规/延迟/污染约束下选最合适的模型”。

## 3. 瓶颈假设（更新）

- **H1（最高杠杆）**：`human_*` 撤回是**接触事件的反向序列**；接触事件 + 归因比静态视觉状态更早、更准地检测撤回，尤其在遮挡/小物体/透明物体场景。
- **H2**：接触状态可从四个泄漏通道可靠推断；但必须**按失效条件加权**，否则“高速滞后”“纹理缺失”“自遮挡”会制造自信的错误。
- **H3**：开源生态能提供足够的特权触觉教师（仿真接触力 + 虚拟触觉 + 人类交互视频），把“无触觉部署”的差距压到可接受范围；但 sim-to-real 与跨具身域差是主要误差源。
- **H4**：接触相位驱动的**离线块长选择 + 块内安全尾段**能同时降低延迟方差与接触密集步的失败率；固定块长在“接近/自由”阶段浪费往返，在“接触/滑移”阶段反应太慢。
- **H5**：开源生态的“免费”有代价；不做污染/许可/版本审计的增益，可能在泛化轴或合规审查上归零。

## 4. 候选与合并 → v3 清单（详见产物区）

围绕两个词发散 10 个草案，合并后得到 v3：**新增 UIP-16~22**，保留 UIP-02′/05/08′/11/14，封存/合并 UIP-01′/09′/12/13/15。

- **旗舰 UIP-16 · TACIT**：触觉特权蒸馏 + 接触归因；无触觉部署、单骨干、可校准。
- **UIP-17 · CEG**：接触事件语法验证器；把 `regressed` 从“状态回退”升级为“反向事件序列”。
- **UIP-18 · OSP**：开源生态组合与审计；单模型合规图、许可账本、污染探针、可复现锁。
- **UIP-19 · HID**：人类干预检测器；用开源人类视频补 `human_*` 数据空白。
- **UIP-20 · TAD**：触觉增强数据工厂；仿真接触教师 + 虚拟触觉 + 反向撤回/恢复数据。
- **UIP-21 · CPS**：接触相位调度器；`T_a` 在 metadata 握手后不可改，因此按 `φ_t` 与不确定度**离线**选全局 `T_a`，并在块内设计相位条件化的安全尾段（保持/微退/停止）。
- **UIP-22 · CUG**：接触不确定度护栏；conformal 弃权 + 假撤回率控制 + 延迟预算。

**与 v2 的关系：** 01′/09′ 的“检测撤回→重做”被 17 吸收并升级；12 的“扰动-恢复数据工厂”被 20 吸收并加入接触标签；13 的“自适应块长”被 21 升级为“接触相位驱动”；15 的“可信度安全阀”被 22 升级为“校准不确定度驱动”。

## 5. 本轮最大风险

**一句话：把“接触信念”当成“接触真值”——在遮挡、透明、小间隙场景下，视觉蒸馏出的接触状态可能自信地错，进而触发假撤回重做，反而烧掉步骤分与延迟预算；因此必须让接触头输出校准信念、让验证器在不确定时弃权/微探，并保留真机锚点。**

## 1. 旗舰深潜：UIP-16 · TACIT（TActile-privileged Contact Inference & Transfer）

### 1.1 机制

TACIT 是一个**教师-学生**框架：

- **教师（只在训练/仿真中出现）**：物理引擎的接触力旋量、接触点、接触对象、接触体（机器人 link / 人手 / 环境）、穿透深度、滑移速度；可选叠加 TACTO/DiffTactile 的虚拟触觉图像。
- **学生（部署时）**：只吃 4 路 RGB + 本体 + 动作历史，输出因子化接触信念 `b(c_t)`，其中 `c_t = (e, φ, l, σ, d, ι)`。
- **共享骨干**：学生编码器与策略 `π_φ` 共享；接触头、技能头、策略头都是 PEFT 适配器/小头，满足**单模型合规**。
- **语法约束**：接触相位 `φ` 的转移受 UIP-17 的接触事件自动机约束，避免“无 `make` 直接 `sustain`”这类物理上不可能的预测。
- **归因**：`ι_t` 由教师精确标注（接触体 ID）；学生从“人手进入画面”“物体异常运动”“夹爪未动但物体动了”等线索推断。

### 1.2 教师信号从哪来（开源生态的四类资产）

| 教师信号 | 开源来源 | 提供什么标签 | 主要风险 |
|---|---|---|---|
| 物理接触真值 | Gazebo / Isaac Lab / MuJoCo / `unitree_ros` / `unitree_sim_isaaclab` | `e, φ, l, σ, d, ι` 的精确标签；接触体 ID | 仿真接触模型与真机差异 |
| 虚拟触觉图像 | TACTO（MIT）、DiffTactile（MIT）、TacSL、TacEx、Taccel | 触觉纹理/滑移/压力分布；用于预训练触觉编码器 | 渲染/材料/传感器模型域差 |
| 真实触觉数据 | DIGIT/GelSight/OmniTact 等公开触觉数据集 | 接触语义（滑移、纹理、压力） | 与 Dex1 平行夹爪形态不同 |
| 人类交互视频 | Ego4D、EPIC-Kitchens、Something-Something、HOI4D、Assembly101 | 人手-物体接触、撤回、放置的**语义先验** | 视角/域差；许可需核 |
| 真机弱标签 | UniBot 33k 数据集 | 夹爪指令-开度差、EE 跟踪误差、动作-观测滞后 | 伪标签，不是接触真值 |

**关键工程判断：不需要先造一个 GelSight 传感器。** 对 TACIT 的接触状态/归因而言，物理引擎的**接触力 + 接触点 + 接触体 ID**已经是足够的特权信号；虚拟触觉只在“预训练触觉编码器/跨具身迁移”时需要。这样把“触觉感知”从“传感器工程”降维成“接触监督学习”，成本低一个数量级。

### 1.3 学生架构

```text
RGB(4) ──► 视觉编码器（共享骨干，ViT/ResNet） ──┐
proprio + action history ──► 本体编码器（MLP/TCN） ──┤
language ──► 语言编码器（共享） ────────────────────┤
                                                   ▼
                                       时序融合（因果 Transformer/TCN）
                                                   │
                    ┌──────────────────────────────┼──────────────────────────────┐
                    ▼                              ▼                              ▼
            接触存在/相位头                  接触位置/进度头                 归因头
          (Dirichlet over Φ)              (Gaussian / quantile)        (Dirichlet over {R,H,E,?})
                    │                              │                              │
                    └──────────────► 校准层（temperature / conformal）◄────────────┘
                                                   ▼
                                         b(c_t) = (e, φ, l, σ, d, ι)
```

- 分类量（`e, φ, l, ι`）用 Dirichlet 证据头，输出均值与证据强度；连续量（`d`）用分位数/高斯头；`σ` 用 sigmoid + 校准。
- 时序融合使用**因果**结构，避免未来信息泄漏；训练时可用双向教师，部署时只用因果学生（teacher-student 不对称）。
- 缺失模态（某路相机被遮挡/丢帧）用 mask token + 可靠性权重处理，不让单路失效拖垮整体。

### 1.4 语法约束蒸馏

普通蒸馏只对齐逐帧标签，容易产生“相位抖动”。加入自动机约束：

```text
L_grammar = − Σ_t log Σ_{q_t} b_t(q_t) · P(e_t | q_t)
            s.t. q_t → q_{t+1} 必须属于 G_g 的合法转移
```

实现上可用一个可微的 HMM/CRF 层：学生输出每个相位的发射概率，前向算法在自动机上边缘化，反向传播梯度。这样即使教师标签有噪声，合法转移的先验也能稳定训练。

### 1.5 部署与单模型合规

- 教师、虚拟触觉、人类视频**只在离线训练**出现；推理图只有一条骨干 + 三个共享骨干的小头。
- 不调用外部 VLM/API；语言理解由共享骨干内的文本编码器完成。
- 接触头输出的是**信念**，不是动作；动作仍由策略头产生，接触信念只作为门控/仲裁输入。这样即使接触头退化，策略也不会直接崩溃（可回退到 v2 的视觉验证）。

### 1.6 与 v2 的差异

| 维度 | v2（RHPV-D / DCR-R） | v3（TACIT / CEG） |
|---|---|---|
| 撤回判据 | 视觉状态从 done 退回 undone | 接触事件反向序列（`sustain→break_reverse` / `depth−`） |
| 触觉 | 未使用 | 特权蒸馏，部署无触觉 |
| 归因 | 无 | `ι ∈ {robot, human, environment}` |
| 误判护栏 | 置信度阈值 + 最大重做次数 | conformal 弃权 + 假撤回率控制 + 语法约束 |
| 数据 | 视觉状态标签 | 接触/归因/事件标签（仿真教师） |

### 1.7 可行性、资源、风险

- **可行性：中高。** 教师信号来自现成物理引擎；学生只加小头；不需要新硬件。
- **资源：** 1 张推理卡部署；离线 1–4 张卡做教师数据生成/蒸馏；仿真 CPU/GPU 视场景而定。
- **风险：** 接触可辨识性（遮挡/透明/小间隙）、sim-to-real 接触模型差异、伪标签噪声。对应 UIP-22 的弃权/校准与 UIP-20 的域随机化。

## 2. 触觉的四个泄漏通道与可靠性融合

| 通道 | 观测/计算 | 能测什么 | 典型失效 | 融合用法 |
|---|---|---|---|---|
| 头戴双目视差 | `cam_left_high/right_high` 已校正立体对；SGBM/RAFT-Stereo/Fast-FoundationStereo 算深度 | 物体/容器/夹爪的度量深度、间隙、对准偏差 | 纹理缺失、透明/反光、远距离 | 提供 `l`（接触位置）与 `d`（插入深度）的几何先验；失效时降权 |
| 腕部近景 | `cam_left_wrist/right_wrist` 480×640 | 接触面、间隙、遮挡、变形、滑移 | 夹爪自遮挡、快速运动模糊 | 提供 `e/φ/slip` 的近距离证据；接触阶段保持高分辨率 |
| 夹爪指令-开度差 | `action.*_gripper` vs `observation.state.*_gripper` | 夹持接触/堵转（命令继续闭合但开度停住） | 斜坡滞后（命令变化时差被斜坡主导） | 只在**命令速度≈0 的稳态段**使用；提供 `e` 与 `σ` |
| EE 跟踪误差 | `action.*_ee_pose_gripper_base` vs `observation.state.*_ee_pose_gripper_base` | 外部接触/阻力/卡住 | 高速运动滞后、控制器饱和 | 做 2–3 帧滞后补偿 + 按指令速度归一化；提供 `jam/σ` |

**融合规则（可解释版）：**

```text
log b(c_t) = Σ_i w_i(o_t) · log p_i(c_t | channel_i) + log p_prior(c_t | language, skill)
w_i(o_t) = reliability_i(o_t) / temperature_i
```

`reliability_i` 由失效条件显式给出（例如：双目深度置信度、腕部遮挡比例、夹爪命令速度、EE 速度），再用一个小型门控网络学习残差。**不允许**把四个通道简单拼接后让大模型“自己学可靠性”——数据里没有足够多的失效样本，显式失效条件更稳。

**真机弱标签（无教师时）：**
- 夹爪稳态堵转 `gap = action_gripper − obs_gripper > δ` → 夹持接触正样本。
- EE 残差（滞后补偿 + 速度归一化）的尾部分位 → 环境接触/卡住候选。
- 动作领先观测 1–3 帧；必须先做滞后补偿，否则“斜坡滞后”会被误判为接触。
- 这些是**伪标签**，只用于预训练/校准，不作为最终真值。

## 3. UIP-17 · CEG（Contact-Event Grammar verifier）

### 3.1 自动机与判据

每个技能 `g` 一个概率自动机 `G_g = (Q_g, Σ_g, δ_g, q_0, F_g, D_g)`；`Σ_g = {make, sustain, slip, break, depth+, depth−, reverse}`。用半马尔可夫前向滤波维护相位后验 `b_t(q)`，并输出：

```text
done      ⇔ b_t(F_g) > τ_done
regressed ⇔ b_t(R_g) > τ_rev  ∨  b_t(sustain→break_reverse) > τ_rev
fail      ⇔ b_t(jam) > τ_jam
ongoing   ⇔ otherwise
```

### 3.2 归因条件化的仲裁表

| 推断事件 | 归因 `ι` | 最优响应 | 典型任务 |
|---|---|---|---|
| 反向 `depth−` / `break_reverse` | `robot` | 重试/重抓/加大啮合；检查是否打滑 | T19 拉链脱轨、T26 插头没插到底 |
| 反向 `depth−` / `break_reverse` | `human` | 让行/重做该子目标；不要盲目重复原动作 | T14 拧回、T16 翻开、T19 拉开、T27 拿下第二个 |
| 物体位姿突变 | `human` | 重新接地目标位姿；已完成步不重做 | T25 挪底座、T08 挪架子 |
| 物体掉落/滑移 | `environment` | 恢复/降速/重抓；保前置步骤分 | T27 碗滑落、T01 杯子掉落 |
| 物体消失/被拿走 | `human` | 保前置步骤分；尝试替代方案；不可硬刚 | T12 中途把锁拿走 |
| 接触持续但 `d` 不增 | `robot`/`environment` | 退回微探/换角度；避免长时间顶住 | T10 插头卡住、T31 拉链卡住 |

这张表把 v2 的“一律重做”拆成**六种响应**，直接对应不同失败模式；步骤分和延迟都会受益。

### 3.3 与 v2 的差异

v2 的 `regressed` 是**状态回退**；CEG 的 `regressed` 是**事件反向 + 归因**。前者要等视觉确认“退回了”，后者在 `sustain→break_reverse` 的瞬间就能触发；前者无法区分“自己失败/人类撤回/环境滑落”，后者可以。**这是本轮对旗舰的直接升级。**

## 4. UIP-18 · OSP（Open-Source Portfolio & Provenance audit）

### 4.1 为什么需要它

开源生态不是免费午餐：预训练污染、许可不兼容、版本漂移、多检查点拼装都可能让增益不可信或不合规。v2 已经担心“外部 VLM 可能被判非单模型”；本轮把担心变成**可执行的审计**。

### 4.2 组合图与单模型合规

```text
[UniBot 数据] ──fine-tune──► [骨干 B] ──► [策略头] ──► action
[仿真接触]   ──teacher────► [蒸馏]   ──► [接触头 ⊂ B] ──► contact belief
[人类视频]   ──pretrain───► [接触编码器 ⊂ B]
[开源模型]   ──init───────► [骨干 B]（只选一个）
```

- 推理子图恰有**一个学习骨干 B**；接触头/策略头/技能头都是共享 B 的 PEFT 头；教师/人类视频只在离线。
- 外部 VLM/API 调用 = 不合规；多骨干集成 = 不合规（除非规则明确允许）。
- 确定性模块（几何、滤波、自动机、conformal）不算“模型”，可自由组合。

### 4.3 审计清单（提交前必须全绿）

| 审计项 | 问题 | 证据 | 失败处理 |
|---|---|---|---|
| 许可账本 | 每个模型/数据/代码的许可证是否兼容？ | `provenance.yaml` + 许可证文本哈希 | 替换 GPL/AGPL/不明许可资产 |
| 单模型合规 | 推理图是否只有一个学习骨干？ | 组合图 + 推理进程快照 | 合并/蒸馏/删除多余骨干 |
| 污染探针 | 预训练是否见过评测任务？ | canary/改写/OOD/成员推断 | 降权/改用干净初始化/如实报告 |
| 版本锁 | 依赖/权重/数据是否可复现？ | commit/hash/容器 digest/种子 | 固定版本、容器化、锁定 HF revision |
| 供应链安全 | 权重是否 `safetensors`？是否有可疑 pickle？ | 文件格式/哈希/SBOM | 拒绝 pickle、重下来源、扫描 |
| 延迟/显存 | 是否满足 N 端口并发与可信度？ | 压测报告 | 量化/共享骨干/降分辨率 |

### 4.4 污染探针（可执行）

1. **指令改写**：同一任务用 5–10 种不同措辞；若模型只在原句上表现好，疑似记忆。
2. **物体/背景替换**：用未见物体/背景做 held-out；对比公开集与 held-out 的差距。
3. **Canary 组合**：把两个任务的子目标组合成新任务；污染模型往往“按旧任务走”。
4. **成员推断**：用损失/困惑度区分训练集与 held-out 片段（需谨慎解释）。
5. **时间切分**：若模型发布日期晚于数据集发布，仍不能证明见过；以行为探针为准。

### 4.5 生态组合选择

```text
maximize  U = α·E[success] + β·E[step_score] − γ·E[latency] − δ·ρ_contam − ε·r_license
s.t.      memory ≤ M, latency ≤ L, single_model_compliant, license_compatible
```

用一个小型 held-out 验证集（8 个代表任务 × 50 episodes）估计 `success/step_score`，用压测估计 `latency/memory`，用探针估计 `ρ_contam`。**离线选一个骨干，在线只跑一个模型**；这就是“开源生态”的正确用法。

### 4.6 生态资产表（节选）

| 资产 | 类型 | 许可（提交前需核） | 用途 | 主要风险 |
|---|---|---|---|---|
| UniBot 32 数据集 | 数据 | Apache-2.0 | 主训练/验证 | 只覆盖公开任务，泛化轴不足 |
| `unifolm-wla` WLA-1.0-Base | 模型 | Apache-2.0（需核） | 初始化/骨干候选 | 6B 显存/延迟 |
| OpenVLA / π0 / π0.5 / GR00T / SmolVLA / RDT-1B | 模型 | 各异（需逐一核） | 骨干候选 | 许可、污染、显存 |
| TACTO / DiffTactile | 仿真 | MIT | 虚拟触觉预训练 | 传感器/材料域差 |
| TacSL / TacEx / Taccel | 仿真 | 各异（需核） | 高通量触觉 | Isaac 依赖/许可 |
| LeRobot | 工具 | Apache-2.0 | 数据/训练/回放 | 版本漂移 |
| Ego4D / EPIC-Kitchens / HOI4D | 人类视频 | 研究许可（需核） | 人手干预预训练 | 许可、域差、隐私 |

### 4.7 “开放核心”策略

可以开源**审计工具 + 接触事件语法 + 数据 schema**（这些不泄露策略权重），但保留训练好的骨干/头。这样既建立生态可信度、方便复现，又不把竞争优势直接送人。对比赛评审而言，“可审计”本身就是可信度的一部分。

## 5. UIP-19 · HID（Human-Interaction Detector）

### 5.1 动机

公开机器人数据里**没有人类干扰**，但 `human_*` 是规则白纸黑字的最大得分缺口。开源生态里却有大量**人类手-物交互视频**：Ego4D、EPIC-Kitchens、Something-Something、HOI4D、Assembly101。它们不提供机器人动作，但提供**人手如何抓、拉、拧、翻、放回**的语义先验。HID 用这些视频预训练“人手接触/干预”检测器，再用仿真生成的人为干扰 + 真机弱标签微调。

### 5.2 机制

```text
开源人类视频 ──► 手部检测/姿态 + 物体分割 ──► 手-物接触事件（onset/offset/reverse）
             ──► 自监督掩码视频建模 + 对比学习 ──► 干预编码器
                                                     │
仿真人为干扰（TAD） ──► 域适配/微调 ──► 机器人相机上的干预检测
真机弱标签（物体异常运动/人手进入） ──► 校准
```

- **预训练目标**：手-物接触存在、接触起始/结束、物体状态变化、反向动作（拉→推、开→关、放→拿）。
- **域适配**：机器人相机是第三人称/腕部近景，人类视频多为第一人称；用外观随机化、视角变换、伪相机参数增强，减少域差。
- **输出**：`P(ι_t = human)` 与干预区间 `[t_on, t_off]`，作为 TACIT 归因头的先验/辅助监督。

### 5.3 与 TACIT 的关系

HID 不是独立模型：它的编码器蒸馏进共享骨干的归因头；推理时只保留一个轻量干预头。开源视频只在离线预训练出现，满足单模型合规。

### 5.4 风险

- 人类视频的“撤回”语义与机器人任务不完全一致（人手 vs 夹爪、物体尺度不同）。
- 许可/隐私：Ego4D 等有研究许可限制，需确认能否用于比赛提交。
- 域差可能大于收益；必须做消融（E204），不能假设“人类视频一定有用”。

## 6. UIP-20 · TAD（Tactile-Augmented Data factory）

### 6.1 机制

在 Gazebo/Isaac 里为每个任务建场景（G1 + Dex1 + 桌面资产 + 同名义相机位），并：

1. **挂虚拟接触传感器**：夹爪面/指尖的接触力旋量 + 接触点 + 接触对象 + 接触体 ID；可选 TACTO/DiffTactile 渲染触觉图像。
2. **脚本化人为干扰**：按 `human_*` 文本复现反向撤回（拧回、翻开、拉开、拿走、挪底座）、搬移、遮挡、递物、协助。
3. **让示范者恢复**：生成 `(干扰前 → 撤回 → 恢复)` 三元组，并标注接触事件序列与归因。
4. **域随机化**：光照、纹理、物体位姿、相机噪声、接触刚度/摩擦、干扰时机/速度/轨迹。
5. **真机弱标签校准**：用 UniBot 数据的夹爪堵转/EE 残差做弱监督，缩小 sim-to-real。

### 6.2 数据 schema

```text
episode = {
  obs: {rgb_high_l, rgb_high_r, rgb_wrist_l, rgb_wrist_r, proprio, language},
  contact: {e, phi, location, stability, depth, attribution},   # 教师标签
  events: [(t, event_type, object_id, source)],                  # 事件序列
  action: {arm, gripper, pivot},                                 # 机器人动作
  intervention: {type, t_on, t_off, object_id},                  # 人为干扰
  meta: {task, scene, randomization_seed, sim_version}
}
```

### 6.3 与 v2 DRF 的差异

v2 的 DRF 主要生成**视觉状态**的扰动-恢复数据；TAD 生成**接触事件 + 归因**标签，直接训练 TACIT/CEG。前者回答“看起来恢复了吗”，后者回答“接触事件是否反向、是谁造成的”。这是从“数据增强”到“监督信号增强”的升级。

### 6.4 风险

- 仿真干扰 ≠ 真机人为干扰的形态/时机；用随机化 + 真机锚点兜底。
- 虚拟触觉与 Dex1 平行夹爪形态不同；只用它预训练通用触觉编码器，不直接当 Dex1 触觉真值。
- 场景资产重建成本高；优先做 8 个接触密集任务（T05/T10/T12/T14/T16/T19/T26/T27），再扩展。

## 7. UIP-21 · CPS + UIP-22 · CUG（接触相位调度 + 不确定度护栏）

### 7.1 先修正一个接口误读

v2 的 UIP-13 假设“可以返回 ≤ `action_chunk_size` 步的块”。但 README §3 明确：`action_chunk_size = T_a`，每个动作数组形状是 `(T_a, …)`，评测端按 `T_a` 步整块执行。**metadata 握手后不能改 `T_a`，也不能在运行期返回更短的块。** 因此 CPS 不能“按相位动态改块长”，只能：

- **模式 A（推荐，简单）**：离线按任务接触密度选一个较小的全局 `T_a`（接触密集任务 2–4，自由搬运任务 6–8）。
- **模式 B（进阶）**：保留较大 `T_a`，但把块设计成**相位条件化的安全尾段**：前段执行当前意图，后段在预期接触/不确定时放入“保持/微退/停止”动作，降低开环执行的风险。
- **模式 C（组合）**：模式 A + 模式 B；用 UIP-22 的不确定度决定尾段策略。

### 7.2 相位-块长-尾段表

| 接触相位 `φ` | 不确定度 | 建议 `T_a`（离线） | 块内尾段 | 理由 |
|---|---|---|---|---|
| `free/approach` | 低 | 6–8 | 正常推进 | 少往返、低开销 |
| `make` | 中 | 3–4 | 最后 1 步减速/微探 | 对准阶段需要快反馈 |
| `sustain` | 低 | 3–6 | 保持当前速度 | 稳定接触，避免过度纠偏 |
| `slip/jam` | 高 | 2–3 | 微退/停止/重抓 | 防止越顶越深 |
| `break/reverse` | 高 | 2–3 | 重验证/让行 | 立即重观测 |

### 7.3 观测预算

`obs_delta_indices` 决定发送哪些键 + 堆叠几帧；每张图 = 一张 JPEG。接触密集任务要保腕部高分辨率，头双目可降采样：

| 键 | 堆叠 | resize | 理由 |
|---|---|---|---|
| `cam_left_wrist` / `cam_right_wrist` | `[0]` 或 `[-2,0]` | 480×640 | 接触近景最关键 |
| `cam_left_high` / `cam_right_high` | `[-2,0]` | 240×320 | 立体深度，降带宽 |
| `left_arm` / `right_arm` | `[-4,-2,0]` | 原生 | 本体动态 |
| `left_gripper` / `right_gripper` | `[-4,-2,0]` | 原生 | 堵转/接触 |
| `*_ee_pose_gripper_base` | `[-2,0]` | 原生 | 跟踪误差 |
| `lower_body` | `[0]` | 原生 | 可酌情删减 |
| `language` | `[0]` | — | 任务条件 |

### 7.4 CUG：校准弃权与假撤回率控制

```text
输入：接触信念 b(c_t)，conformal 集合 C_α(o_t)，历史重做次数 r，延迟预算 B
1. 若 C_α(o_t) 同时包含 done 与 reverse → 弃权，返回 ongoing（不触发重做）。
2. 若 b(reverse) > τ_rev 且 C_α(o_t) 不含 done：
     - 若 ι=human 且 r < r_max → 让行/重做，r += 1
     - 若 ι=robot 且 r < r_max → 重试/重抓，r += 1
     - 若 ι=environment → 恢复/降速
3. 若累计延迟 > B 或 r ≥ r_max → 放弃重做，保前置步骤分，继续/收尾。
4. 所有重做动作做形态平滑，避免“统计规律性异常”伤可信度。
```

**目标**：在 90% conformal 覆盖率下，把假撤回重做率压到 ≤5%，同时不显著增加超时率。

## 10. 资源、时间线与合规

### 10.1 粗排时间线

- **第 1–2 周**：确定数据 schema；标注 8 个接触密集任务的接触原语/事件/归因；跑通 UniBot 数据读取与动作-观测差伪标签。
- **第 3–5 周**：搭 TAD 仿真场景（T05/T10/T12/T14/T16/T19/T26/T27）；导出接触/归因标签；训练 TACIT 学生；E201/E203。
- **第 6–7 周**：CEG 自动机 + 归因仲裁；HID 人类视频预训练；E202/E204。
- **第 8 周**：CPS/CUG；观测预算压测；E206。
- **第 9 周**：OSP 审计（许可/污染/单模型/复现）；E207；预约真机做 E205/E208 锚点。

### 10.2 资源

- 推理：1 张卡（共享骨干 + PEFT 头）；N 端口并发用共享后端 + 每端口状态隔离。
- 离线：1–4 张卡做教师数据/蒸馏；仿真 CPU/GPU 视场景；存储 ~1–2 TB（数据集 + 仿真数据）。
- 人力：接触标注/仿真场景重建是主要瓶颈；优先做 8 个任务，不要一开始铺 32 个。

### 10.3 合规红线

- **单模型**：一个学习骨干；接触头/策略头/技能头共享；教师/人类视频只在离线。
- **接口**：动作形状严格 `(T_a, …)`；不返回短块；`meta.token` 每次携带；N 端口状态隔离。
- **许可**：建立 `provenance.yaml`；GPL/AGPL/不明许可资产不进入分发路径；权重用 `safetensors`。
- **污染**：如实报告探针结果；不把“公开集高分”包装成“泛化好”。
- **可信度**：延迟平滑、动作形态平滑、避免异常重试；CUG 的延迟预算要留余量。

## 11. 本轮最大风险 & 押注

**最大风险（一句话）：把“接触信念”当成“接触真值”——在遮挡、透明、小间隙场景下，视觉蒸馏出的接触状态可能自信地错，进而触发假撤回重做，反而烧掉步骤分与延迟预算；因此必须让接触头输出校准信念、让验证器在不确定时弃权/微探，并保留真机锚点。**

**→ 本轮最值得押注：UIP-16 TACIT × UIP-17 CEG × UIP-19 HID / UIP-20 TAD 组成的“可归因接触事件闭环”，由 UIP-18 OSP 做生态合规审计、UIP-21/22 做实时与不确定度护栏。** 它精确对准三件同时成立的事：规则里白纸黑字的人类撤回、公开数据完全空白的触觉/干扰监督、以及开源生态里现成可借的教师信号；而且完全落在选手 API 权限与离线算力之内。
