# 第 64 轮（承接第 63 轮「LIRO 几何-技能-干扰三层鲁棒操作闭环」IP-193~202；灵感循环 III 第 1 轮；本轮灵感：「行为树」×「运动规划」）

> 第 63 轮 LIRO 把单机操作补成了「LiDAR 几何先验 × 通用技能组合 × 四类干扰认证」的闭环，但它「技能层面规划 + 参数层面鲁棒展开」的主张下藏着一个**结构性断层**：
> 1. **开环序列没有反应式结构**：CSP 输出 τ=[σ_1,…,σ_H]，实时流只展开首技能 π_σ1，失败后靠语义流从头重规划，恢复策略是零散的 safe_idle / ask_clarify。执行期没有带条件的重试、兜底顺序与记忆，**恢复无结构、反应无上界**。
> 2. **符号层与几何层之间没有桥**：USL 的 pre/eff 是一阶逻辑谓词，𝒫_feas 只从 φ 球里采样并检查 ERTC，**从未验证「存在一条无碰撞、满足关节/动力学约束的运动」**。符号可行 ≠ 几何可行——窄通道、关节限位、动态障碍、抓取接近方向的碰撞，都会让 CSP 承诺的「可达/可抓」在运动层直接落空。LIRO 有任务层（USL/CSP）与控制层（WCV 阻抗），唯独缺了中间的**运动层**。
> 3. **不确定性只进了阻抗球，没进运动轨迹**：WCV-Geo 的 B(φ̂,r) 与 AIC 的干扰集认证的是「参数/观测鲁棒」，而规划器把标称路径当作可精确跟踪。证书证明的是「阻抗安全」，不是「轨迹安全」——扰动传播到状态空间后，路径可能已经蹭到障碍。
> 4. **计划失败不反哺计划结构**：SSB 只把险情写进场景参数与先验，从未改变「用什么结构去完成技能」，失败经验无法长成更好的执行树。

本轮因此不新增感知模态，而是给 LIRO 补上**「反应式执行结构」与「几何-动力学可行性」**这两块缺失的地基：用行为树把任务计划变成可验证、可恢复、可反应的控制结构；用运动规划把符号技能精化为带不确定性管（tube）的几何-动力学可行动作；两者在任务-运动桥（TAMP 抽象精化）处咬合——**行为树保证「结构可控」，运动规划保证「动作可达」，管道保证「跟踪不越界」**。

## 0. 直觉与动机

**灵感 1（行为树 → BCT：Behavior-tree Compiler，CSP→Certified BT）**
直觉：CSP 现在给的是一条「做 A 再做 B 再做 C」的直线，任何一步没成，整条线就断。行为树的本质恰恰是**把「顺序、兜底、重试、并行监护、条件守卫」显式写成树**：Sequence 节点在子节点返回 Failure 时立刻短路进兄弟 Fallback，Decorator 节点给叶子加重试/超时/优先级，Condition 叶子在每次 tick 重新评估世界。于是我们把 CSP 的技能序列**编译**成一棵带守卫的认证行为树 T_τ：每个技能 σ_i 变成 `Fallback(Sequence(pre_σi?, Do(σ_i), post_σi?), Recovery_i)`，外面再套一层 `Fallback(…, SafeIdle)`，并与一个**安全监护子树** `Parallel(Task, SafetyMonitor)` 并发运行。**关键洞见：计划不再是「一条要祈祷它别断的线」，而是「一棵断在哪都能退到已验证兜底的树」；反应时延从「语义流重规划（几十 ms）」降到「一次 tick（<0.1ms）」。**

**灵感 2（运动规划 → MPL + TMB：运动原语层 + 任务-运动桥）**
直觉：运动规划不是给阻抗控制「打下手」的路径生成器，而是**符号承诺的兑现器**。每个技能叶子 π_σ 背后接一个运动原语 m=(ξ 路径, s 时间律, u 前馈, Ω 不确定管)。TMB 做经典 TAMP 的**抽象精化**：符号层先在 USL 上规划（快），每展开一条符号边就用 MPL 验证其**几何可行性**——存在运动原语使 Ω(t) 全程落在 C_free 且满足动力学约束；不可行就生成一条**冲突子句**（这条符号转移被禁止）回到 CSP 重规划。**关键原则：符号层可以乐观，但精化必须保序——被删掉的边只能是几何真不可行的边，绝不能因为采样器一次没找到路就误杀可行动作。**

**灵感 3（运动规划 → RTF：Robust Tube Funnel，把不确定性管进轨迹）**
直觉：WCV-Geo 已经给了 φ 的球，AIC 给了干扰集，但它们停在「参数/观测」层面。运动层要问的是另一个问题：**在 φ 最坏取值 + 扰动 + 状态估计误差下，实际轨迹会不会跑出无碰撞走廊？** RTF 把这三个源传播成一条沿标称轨迹的状态误差管 Ω(t)=标称(t)⊕椭球(E(t),ρ(t))，ρ(t) 取 φ∈B∩𝒢、干扰∈ℰ、估计误差的最坏合成；规划器**只接受 Ω(t)∩障碍=∅ 且满足收缩/漏斗条件的原语**。这样证书第一次从「阻抗不会失稳」升级为「轨迹不会碰撞」。

**灵感 4（三灵感合流 → BATON：Behavior-tree-Assisted Task-motion OrchestratioN，行为树驱动的任务-运动接力闭环）**
直觉：接力棒（baton）是最好的比喻——**任务层把「要做什么 + 已验证的契约」这根棒交给运动层，运动层把「怎么走 + 走完的证据」交回任务层**。闭环：LiDAR/触觉 → LIRO 单机内环 → CSP 得符号计划 → BCT 编译为认证行为树 → TMB 逐边做几何精化（冲突子句回灌 CSP）→ MPL 生成运动原语 → RTF 验证不确定管 → 实时 tick/跟踪/监护 → 证据与失败签名回写 SSB/BTL → BTR 修复子树 → 重新 BTV 验证。**第 63 轮 LIRO 是「符号规划 + 参数鲁棒」，BATON 是「反应式结构 + 几何可行 + 轨迹可证」，且 BATON 不推翻 LIRO，只把它作为树里的执行内环。**

**灵感 5（LIRO 组件的原位升级）**
- **CSP → CSP-BT**：输出由「单条序列」升级为「带观测分支的条件计划」，条件分支天然编译成行为树的 Fallback；精化冲突子句进入符号约束集。
- **USL → USL-MP**：每个技能 σ 增加运动原语接口 `π^mp_σ(x',θ)→m`（路径+时间律+前馈+管），π_σ 仍是阻抗关键帧。技能 = 符号契约 + 运动兑现 + 阻抗执行三层。
- **Shield-Skill → Shield-BT**：前置条件凸投影升级为**并行安全监护节点**，具有抢占优先级；任何时刻监护 Failure 立即触发整树兜底，安全不依赖上游策略。
- **OLP-Geo → OLP-BT**：在线投影损失加入「恢复轨迹一致性」项——被 BTR 采纳的恢复动作也进入梯度，使基础策略少犯错。
- **SSB → SSB-Sig**：场景银行增记**失败签名** ψ=(技能, 失败模式, 局部几何, 阶段, 残差)，并与 BTL 行为树库互相索引。
- **OCB-Skill → OCB-BT**：预算臂空间增入运动规划模式 {full_KRRRT*, warm_start_TO, cached_primitive, straightline_tube, frozen}，EXP3 在「行为树执行模式 × 运动规划预算」联合调度。

## 1. 形式化定义（增量：定义 201–215）

- **定义 201（BATON 闭环）**：BATON = (LIRO, BCT, MPL, TMB, RTF, BTV, BCP, BTR, BTL, MPB, J_baton)。定位：LIRO 的「反应式执行 × 几何-动力学可行性 × 轨迹级不确定认证」升级，全部新组件挂在第 63 轮骨架上；不变式：**编译/规划/精化/验证/修复全部在语义流（10–100Hz），实时流（1–10kHz）只做 BT tick、原语跟踪、管成员检查与安全监护，且零学习写操作**。
- **定义 202（行为树 BT）**：T=(V,E,β,τ_0)，控制节点 {Seq, Fall, Par, Retry_k, Timeout_Δ}，叶子 {Act, Cond}；tick 返回 {Success, Failure, Running}。Seq 全成才成、一败即败；Fall 一成即成、全败才败；Par 按策略合并（本文用「监护 Failure 立即抢占」）；Retry_k 最多重试 k 次；Timeout_Δ 超时即 Failure。
- **定义 203（认证节点契约）**：每节点 n 带契约 K_n=(Pre_n, Post_n, Inv_n, Rely_n, Guar_n)。动作叶 Act(σ)：`Pre_n ⊇ pre_σ`、`Post_n ⊢ eff_σ`、`Inv_n` 全程不变；条件叶 Cond(c)：Success 时 `Post_n ⊢ c`，且**单侧保守**（不确定时返回 Failure，假阳性率 ≤ α_guard）。组合规则由子节点契约按 Seq/Fall/Par 推导（见 IP-208）。
- **定义 204（BCT：CSP→认证行为树编译）**：`compile(τ, θ, G) → T_τ`：按序为每个 σ_i 生成 `Fallback(Sequence(pre_σi?, Act(σ_i), post_σi?), Recovery_i)`，Recovery_i ∈ {Retry(σ_i), BTR 修复子树, SafeIdle}；整串外套 `Fallback(整个 Sequence, SafeIdle)`，并与 `SafetyMonitor` 组成 `Parallel(…, 抢占)`；末节点守卫目标 G。编译保持符号计划语义并增加运行时恢复。
- **定义 205（MPL：运动原语层）**：技能 σ 的运动原语 `m=(ξ, s, u, Ω, cost, cert)`，ξ:[0,T]→C_free 为路径，s 为时间律，u 为前馈控制，Ω 为不确定管。生成器 = 以 π_σ 的关键帧热启动的 kinodynamic RRT*（采样动力学可行轨迹）+ 轨迹优化（iLQR/TO，含关节限位/力矩/速度约束）。接口 `π^mp_σ(x',θ)→{m_1,…,m_K}`。
- **定义 206（TMB：任务-运动桥 / 几何可行性）**：技能在构型 x 下几何可行 `gf(σ,x) ⇔ ∃m: ξ(0)=x, ξ(T)∈Pre_geo(eff_σ), Ω(t)⊆C_free ∀t, u∈U`。符号抽象**保序**当且仅当 `Pre_geo(σ) ⊆ pre_σ`（几何可行蕴含符号谓词）。精化循环：若符号边 e=(σ_i→σ_{i+1}) 在 x 处不可行，则加入冲突子句 `¬e@x_context` 回灌 CSP 重规划；迭代上界 K_refine。
- **定义 207（RTF：鲁棒不确定管/漏斗）**：`Ω(t)=ξ(t)⊕ℰ(E(t), ρ(t))`，`ρ(t)=max_{φ∈B(φ̂,r)∩𝒢, η∈ℰ_AIC, e_est∈Δ_est} ‖δx(t;φ,η,e_est)‖`，由敏感度/区间算术传播。规划器仅接受 `Ω(t)∩O=∅` 且满足**漏斗收缩条件**（存在反馈使 Ω(t) 前向不变）的原语。跟踪律在标称前馈 u 外加 `K_tube(t)·(x−ξ(t))`。
- **定义 208（BTV：行为树组合验证）**：按结构归纳推导根契约：Act/Cond 取定义 203；Seq 的 Post=末子 Post、Inv=各子 Inv 合取；Fall 的 Post=各分支 Post 析取、Inv=各分支 Inv 合取；Par 取各子 Inv 合取并保证监护优先。验证目标：`Pre_root ∧ Inv_root` 在每次 tick 后归纳保持，且监护节点 Failure 优先于任务 Success。
- **定义 209（BCP：BT 引导的条件计划）**：CSP 输出条件计划树 π_cond（节点含观测守卫），`compile_cond(π_cond)→T`；分支守卫为单侧保守条件叶。遇到不确定观测（如「是否抓住」）默认走保守分支（重试/求助），而非乐观直行。
- **定义 210（BTR：行为树修复）**：失败签名 `ψ=(σ, mode, ctx_geo, phase, residual)`；修复算子 `O={retry_perturb, insert_recovery, reorder_fallback, substitute_skill, tighten_guard}`；用 BTL 案例匹配 + EXP3 选算子，生成补丁 patch，经 BTV 验证且**契约不弱化**才提交。
- **定义 211（BTL：行为树库）**：条目 `(ψ, patch, contract, success_stats, lineage)`，按失败签名相似度检索；与 USL（技能库）、SSB（场景库）三角索引——场景给上下文、技能给叶子、行为树给结构。
- **定义 212（MPB：运动规划预算 anytime 调度）**：臂 = 规划模式 {full_KRRRT*, warm_start_TO, cached_primitive, straightline_tube, frozen}；每语义步在截止时间内返回**当前最好可行原语**；超时未得则返回保守兜底（不声称不可行）。与 OCB-BT 联合做 EXP3。
- **定义 213（失败签名）**：`ψ=(σ, failure_mode ∈ {pre_violated, post_unreached, motion_infeasible, tube_violated, guard_uncertain, timeout}, ctx_geo, phase, residual)`；`ψ≡ψ'` 当且仅当技能、失败模式、局部几何指纹聚类一致，用于 BTL 检索与 SSB 归并。
- **定义 214（J_baton 扩展证书）**：`J_baton=(J_liro, bt_hash, bt_cert, mp_cert, tube_cert, refine_hash, repair_ver, mpb_stats)`。`Valid(J_baton) ⇔ Valid(J_liro) ∧ Valid(bt_cert) ∧ mp_cert(每条激活叶子有 Ω⊆C_free 的原语) ∧ tube_cert(跟踪不变式) ∧ 精化一致 ∧ repair_ver 新鲜`。
- **定义 215（实时/语义切分不变式）**：语义流做编译/规划/精化/验证/修复/学习；实时流做 `tick T_τ`（O(树深)）、`跟踪 ξ 当前段`（O(1)）、`Ω(t) 成员检查`（椭球二次型 O(1)）、`SafetyMonitor` 与兜底。实时路径 ≤ 2ms，零学习写操作（继承 A75/A82）。

## 2. 关键算法骨架（完整伪代码见产物区）

# —— 语义流（10–100Hz）——
tau, theta = csp.plan(goal, x_prime, phi_hat, r)          # 符号层（快、乐观）
T = bct.compile(tau, theta, goal)                         # CSP → 认证行为树
for edge in refine_edges(T):                              # TMB 任务-运动桥
    m, ok = mpl.plan_primitive(edge, x, phi_hat, r)       # KRRRT* + TO
    if not ok: csp.add_conflict_clause(edge); tau = csp.replan(); T = bct.compile(tau, theta, goal)
    tube_ok = rtf.certify(m, phi_hat, r)                  # 不确定管 ⊆ C_free
    if not tube_ok: m = mpl.tighten(m) or fallback
bt_cert = btv.verify(T, leaf_contracts)                   # 结构归纳 + rely-guarantee
# —— 实时流（1–10kHz，零学习写）——
status = T.tick(obs)                                      # 条件守卫 + 节点派发（<0.1ms）
if safety_monitor.triggered(): status = T.fallback()      # 监护抢占
u = track(primitive_ref, x) + tube_feedback(x)
if not in_tube(x, Omega): u = fallback()
# —— 失败反馈 ——
psi = failure_signature(status, obs); ssb.record(psi)
if psi.critical: T = btr.repair(T, psi); btl.store(...)   # 修复后必须重过 BTV

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 5（编译保持性与反应性）**：若叶契约成立，则从满足 pre_σ1 的状态出发，编译树 T_τ 要么执行 τ 到达 G，要么进入一个**已认证兜底**且维持 Inv；任意守卫被违反到触发兜底的反应时延 ≤ 1 个 tick。**计划不再依赖「一路成功」的善意假设。**
- **引理 6（精化保序与终止）**：若符号抽象保序（Pre_geo⊆pre）且冲突子句只删几何真不可行边，则 TMB 在有限转移集上 ≤ K_refine 次终止；存在几何可行计划时精化不会误删（概率 1 于采样完备极限），否则返回兜底而非伪可行计划。
- **定理 4（认证行为树安全性）**：若每叶满足定义 203 契约、组合规则可靠、监护优先，则结构归纳给出 `Pre_root∧Inv_root ⇒ 每次 tick 后 Inv_root 归纳保持`；特别地碰撞自由、力/速度硬限始终成立——**局部契约拼出整树不变式**。
- **定理 5（RTF 轨迹安全）**：若扰动/估计误差 ∈ Δ、φ∈B∩𝒢，且漏斗条件使 Ω(t) 前向不变、Ω(t)∩O=∅，则实际闭环轨迹 ∀t 落在 Ω(t) 内，故无碰撞；证书从参数级升级为轨迹级。
- **定理 6（BATON 端到端）**：`Valid(J_baton) ⇒` 安全（无碰撞/动力学可行）概率 ≥ 1−α_tube；任务成功率 ≥ 1−α_guard−α_budget（α_guard 守卫假阳性、α_budget 规划预算超时）；规划失败只降低任务成功率，**不降低安全性**（兜底）。
- **引理 7（修复不降级）**：BTR 仅提交通过 BTV 且契约不弱化的补丁，故 ∈ 修复不降低认证安全裕度；性能可能波动但安全单调不降。
- **实时性**：BT tick O(树深) + 跟踪 O(1) + 管检查 O(1)，新增 < 0.2ms，实时路径仍 ≤ 2ms（继承 A75/A82）。

## 2. 形式化定义（完整版）

**定义 201（BATON 闭环）** BATON 是 LIRO 的「反应式执行 × 几何/动力学可行性 × 轨迹级不确定认证」升级：在第 63 轮「语义流 ∘ 实时流」骨架上挂载 BCT（编译）、MPL（运动原语）、TMB（任务-运动桥）、RTF（不确定管）、BTV（结构验证）、BCP（条件计划）、BTR/BTL（修复与库）、MPB（预算调度），并原位升级 CSP→CSP-BT、USL→USL-MP、Shield-Skill→Shield-BT、OLP-Geo→OLP-BT、SSB→SSB-Sig、OCB-Skill→OCB-BT。不变式见定义 215。BATON 把 LIRO 视为树中的一个**执行内环**：树负责结构与恢复，内环负责单技能阻抗编译与干扰认证。

**定义 202（行为树 BT）** 行为树 `T=(V,E,β,τ_0)`，根 `τ_0`，子节点映射 β。控制节点：
- `Seq([c_1,…,c_k])`：顺序 tick，任一 `Failure` 立即返回 `Failure`，全 `Success` 才 `Success`，出现 `Running` 则 `Running`；
- `Fall([c_1,…,c_k])`：顺序 tick，任一 `Success` 立即 `Success`，全 `Failure` 才 `Failure`；
- `Par([c_1,…,c_k], policy)`：并发 tick，本文用 `policy=monitor_preempt`——监护子返回 `Failure` 时以最高优先级抢占其余子并返回 `Failure`；
- `Retry_k(c)`：子失败后重试至多 k 次；
- `Timeout_Δ(c)`：子运行超过 Δ 返回 `Failure`。
叶子：`Act(σ,θ)` 执行技能（或运动原语），`Cond(c)` 评估谓词（每 tick 重新评估，反应式）。记忆型 Sequence 可选（本框架默认反应式，避免陈旧记忆导致跳过失败守卫）。

**定义 203（认证节点契约）** 每节点 n 带契约 `K_n=(Pre_n, Post_n, Inv_n, Rely_n, Guar_n)`：
- 动作叶 `Act(σ,θ)`：`Pre_n ⊇ pre_σ`（进入时前置成立）、`Post_n ⊢ eff_σ`（Success 时后置成立）、`Inv_n` 全程保持（碰撞自由、关节/力/速度硬限、抓取稳定等）；`Rely_n` 为对环境与运动原语的假设，`Guar_n` 为对环境的承诺。
- 条件叶 `Cond(c)`：`Success ⇒ c`，且**单侧保守**——证据不足或冲突时返回 `Failure`（把不确定当作不成立），保证假阳性率 ≤ `α_guard`；这使失败分支只会多走恢复，不会误跳过守卫。
- `Retry/Timeout` 不改变子契约，仅改变尝试次数与时间窗；`Timeout` 的 `Post` 为空（只可能 Failure）。

**定义 204（BCT：CSP→认证行为树编译）** 给定带参数绑定的技能序列 `τ=[σ_1,…,σ_H]`、`θ=[θ_1,…,θ_H]` 与目标谓词 G：
```
compile(τ,θ,G) =
  Par( [ Seq( Fall_i for i=1..H ) , SafetyMonitor ],
       policy=monitor_preempt )
  Fall_i = Fall([ Seq([ Cond(pre_σi), Act(σ_i,θ_i), Cond(eff_σi) ]),
                  Recovery_i ])
  Recovery_i ∈ { Retry_k(Act(σ_i,θ_i)), RecoverySubtree(σ_i), SafeIdle }
  末尾追加 Cond(G)（目标守卫）
```
编译的语义：按序尝试每个技能的「前置成立 → 执行 → 后置成立」，任一步失败立即进入该技能的恢复子树；恢复耗尽则 SafeIdle（认证安全兜底）。SafetyMonitor 与任务并发，拥有抢占权。**编译不改变符号计划的成功路径，只把「失败即断线」变成「失败有结构恢复」。**

**定义 205（MPL：运动原语层）** 技能 σ 的运动原语 `m=(ξ, s, u, Ω, cost, cert)`：
- `ξ:[0,T]→C_free`：无碰撞路径（C-space）；
- `s:[0,T]→[0,1]`：时间律（时间最优或鲁棒裕度优先）；
- `u:[0,T]→U`：前馈控制（满足力矩/速度/加速度约束）；
- `Ω:[0,T]→2^C`：不确定管（定义 207）；
- `cost`：时间/能耗/风险加权；
- `cert`：区段可行性证书（动力学可行 + 管在自由空间）。
生成：以 π_σ 的阻抗关键帧投影出若干末端/关节种子 → 热启动 **kinodynamic RRT\***（在状态-控制空间采样、以动力学积分连接）→ 轨迹优化（iLQR/TO，硬约束关节限位、力矩、速度、接触力）→ 得到候选原语。接口 `π^mp_σ(x',θ)→{m_1,…,m_K}` 返回 K 个代价递增的候选，供 anytime 选择。

**定义 206（TMB：任务-运动桥 / 几何可行性）** 技能 σ 在构型 x 下几何可行：
`gf(σ,x) ⇔ ∃m: ξ(0)=x ∧ ξ(T)∈Pre_geo(eff_σ) ∧ Ω(t)⊆C_free ∀t ∧ u(t)∈U ∧ ξ 动力学可行`。
符号抽象**保序**当 `Pre_geo(σ) ⊆ pre_σ`（几何可行 ⇒ 符号前置成立）；\|反方向不要求\|（符号可乐观）。精化循环：
1. 符号层规划得 τ；
2. 对 τ 的每条符号边 e 调 MPL/RTF 检查 `gf`；
3. 若获得**可靠不可行证据**（如区间算术证明任何管都撞障、或可用走廊体积下界 < 管体积下界），加入冲突子句 `forbid(e, ctx)` 回灌 CSP 重规划；
4. 若只是采样超时/预算耗尽（unknown），**不写全局冲突子句**，仅把该边在该上下文标为「高风险」，局部降级到候选原语/恢复分支；
5. 迭代 ≤ K_refine。
**关键：只有可靠不可行才剪枝，超时只降级不误杀。**

**定义 207（RTF：鲁棒不确定管 / 漏斗）** `Ω(t)=ξ(t)⊕ℰ(E(t),ρ(t))`，其中 `E(t)` 为沿轨迹的敏感度/可达矩阵，管半径
`ρ(t)=max_{φ∈B(φ̂,r)∩𝒢(g), η∈ℰ_AIC, e_est∈Δ_est} ‖δx(t;φ,η,e_est)‖`。
`ρ(t)` 由三条支路合成：① 物体参数球 B(φ̂,r) 经接触动力学敏感度传播；② AIC 干扰集 ℰ 经闭环响应传播；③ 状态估计误差 `Δ_est`（来自 ARA 锚点新鲜度与传感噪声）。**漏斗条件**：存在反馈增益 `K_tube(t)` 与收缩度量 M(t)，使标称管前向不变，即 `x(t)∈Ω(t) ⇒ x(t+dt)∈Ω(t+dt)`。规划器仅接受 `Ω(t)∩O=∅`（O 为障碍）且漏斗条件成立的原语。跟踪律：`u = u_nom(t) + K_tube(t)(x−ξ(t))`。

**定义 208（BTV：行为树组合验证）** 按结构归纳推导根契约：
- `Act/Cond` 取定义 203；
- `Seq`: `Pre=Pre_{c1}`，`Post=Post_{ck}`，`Inv=⋀_j Inv_{cj}`，且要求 `Post_{cj} ⇒ Pre_{c(j+1)}`（链接条件）；
- `Fall`: `Pre=⋁_j Pre_{cj}`（至少一分支可入），`Post=⋁_j Post_{cj}`，`Inv=⋀_j Inv_{cj}`；
- `Par`: `Pre=⋀_j Pre_{cj}`，`Post=⋀_j Post_{cj}`，`Inv=⋀_j Inv_{cj}`，且监护节点 Failure 的抢占时延 ≤ 动作生效时延。
验证目标：`Pre_root ∧ Inv_root` 经任意 tick 后仍是 `Inv_root` 的归纳不变式；监护优先性成立（不存在「任务 Success 抢在监护 Failure 前提交」的执行序）。

**定义 209（BCP：BT 引导的条件计划）** CSP 输出条件计划 `π_cond`：节点形如 `(σ, guard, succ_branch, fail_branch)`，其中 guard 为一侧保守观测谓词（如「抓稳了？」）。编译 `compile_cond(π_cond)` 把分支变成行为树的 `Fall([Seq([Cond(guard), succ]), fail_branch])`。对不确定观测默认走 fail_branch（重试/求助），不乐观直行。这使 CSP 从「单条序列」升级为「带观测分支的反应式计划」。

**定义 210（BTR：行为树修复）** 失败签名 `ψ=(σ, mode, ctx_geo, phase, residual)`，mode ∈ {pre_violated, post_unreached, motion_infeasible, tube_violated, guard_uncertain, timeout}。修复算子：
1. `retry_perturb`：在 ψ 附近扰动 θ（抓取位姿/接近方向）后重试；
2. `insert_recovery`：在 Act 前插入恢复技能（后退、重新感知、重新对齐）；
3. `reorder_fallback`：交换同效分支优先级（如先顶抓后侧抓）；
4. `substitute_skill`：替换为后置条件相同的替代技能（来自 USL）；
5. `tighten_guard`：在进入危险上下文前加更严格的前置守卫，阻止重复触发。
选择：BTL 按 ψ 相似度检索历史补丁 + EXP3 探索算子。**约束**：补丁必须通过 BTV 且「契约不弱化」（新根契约 ⇒ 旧根契约，`Inv` 不缩水）才提交；否则回退原树（原树仍安全）。

**定义 211（BTL：行为树库）** `BTL = {(ψ, patch, contract, success_stats, lineage)}`；检索相似度 = 技能相同 + 失败模式相同 + 几何指纹距离 < τ_geo + 残差距离。与 USL（叶子技能）、SSB（场景与险情）三角索引：SSB 给上下文，USL 给替代叶子，BTL 给结构补丁。条目有淘汰：连续失败或长期未用则归档。

**定义 212（MPB：运动规划预算 anytime 调度）** 臂空间 = `{full_KRRRT*, warm_start_TO, cached_primitive, straightline_tube, frozen}` × 既有 OCB-BT 执行模式。每语义步在截止 `Δ_plan` 内运行 anytime 规划器，始终保留当前最好可行原语；超时未得则返回**保守兜底**（SafeIdle / 短程后退），且**不声称不可行**。奖励 `r_t = progress_t − κ·(compute_cost_t + risk_penalty_t + switch_penalty)`，EXP3 更新。

**定义 213（失败签名）** `ψ=(σ, mode, ctx_geo, phase, residual)`；`ψ≡ψ'` 当且仅当技能相同、失败模式相同、`ctx_geo` 的几何指纹（复用 SSB fp_cloud 局部块）距离 < τ_geo、残差归一化距离 < τ_res。等价类用于 BTL 检索、SSB 归并与 BTR 算子统计。

**定义 214（J_baton 扩展证书）** `J_baton=(J_liro, bt_hash, bt_cert, mp_cert, tube_cert, refine_hash, repair_ver, mpb_stats)`。
`Valid(J_baton) ⇔`
- `Valid(J_liro)`（第 63 轮证书）；
- `Valid(bt_cert)`（BTV 推导并验证根契约，含监护优先）；
- `mp_cert`：每条**激活**叶子都绑定了一个 `Ω(t)⊆C_free` 且动力学可行的原语；
- `tube_cert`：漏斗前向不变式成立，且 `ρ(t)` 覆盖 WCV/AIC/估计误差界；
- `refine_hash` 与当前符号抽象、冲突子句集一致；

**定义 215（实时/语义切分不变式）** 语义流（10–100Hz）执行：BCT 编译、BCP 条件规划、MPL 运动规划、TMB 精化、BTV 验证、BTR 修复、BTL/SSB 记账、DIR/AIC/OLP 学习。实时流（1–10kHz）执行：`T.tick(obs)`（条件检查 + 节点派发）、原语跟踪 `u_nom+K_tube(x−ξ)`、管成员检查（椭球二次型）、SafetyMonitor 与兜底。**实时路径零学习写操作，总新增 ≤ 2ms。**

## 3. 关键算法伪代码

### IP-204 BCT（CSP→认证行为树）

```python
class Seq:
    def __init__(self, children): self.children = children
    def tick(self, obs, bb):
        for c in self.children:
            st = c.tick(obs, bb)
            if st != 'Success': return st
        return 'Success'

class Fall:
    def __init__(self, children): self.children = children
    def tick(self, obs, bb):
        for c in self.children:
            if c.tick(obs, bb) == 'Success': return 'Success'
        return 'Failure'

class Par:
    def __init__(self, children, policy='monitor_preempt'):
        self.children, self.policy = children, policy
    def tick(self, obs, bb):
        statuses = [c.tick(obs, bb) for c in self.children]
        if self.policy == 'monitor_preempt' and statuses[-1] == 'Failure':
            return 'Failure'                      # 监护抢占
        return 'Success' if all(s == 'Success' for s in statuses) else 'Running'

class Retry:
    def __init__(self, child, k): self.child, self.k = child, k
    def tick(self, obs, bb):
        for _ in range(self.k + 1):
            if self.child.tick(obs, bb) == 'Success': return 'Success'
        return 'Failure'

class Cond:
    def __init__(self, pred): self.pred = pred
    def tick(self, obs, bb):
        # 单侧保守：证据不足 -> Failure（不跳过守卫）
        v, conf = self.pred.evaluate(obs, bb)
        return 'Success' if (v and conf >= CONF_MIN) else 'Failure'

class Act:
    def __init__(self, skill, theta, mpl): self.skill, self.theta, self.mpl = skill, theta, mpl
    def tick(self, obs, bb):
        if bb.current_primitive is None or bb.primitive_skill is not self.skill:
            bb.current_primitive = self.mpl.plan(self.skill, obs, self.theta)
        return self.skill.execute(obs, bb.current_primitive)   # Running/Success/Failure

class BCTCompiler:
    def __init__(self, mpl, k_retry=2):
        self.mpl, self.k_retry = mpl, k_retry

    def compile(self, tau, theta, goal):
        seq = []
        for sigma, th in zip(tau, theta):
            body = Seq([Cond(sigma.pre), Act(sigma, th, self.mpl), Cond(sigma.eff)])
            recovery = Fall([Retry(Act(sigma, th, self.mpl), self.k_retry),
                             SafeIdle()])
            seq.append(Fall([body, recovery]))
        seq.append(Cond(goal))
        return Par([Seq(seq), SafetyMonitor()], policy='monitor_preempt')

    def compile_cond(self, pi_cond):
        # (sigma, guard, succ_branch, fail_branch) -> Fall([Seq([Cond(guard), succ]), fail])
        return Fall([Seq([Cond(pi_cond.guard), self.compile(pi_cond.succ, pi_cond.theta, pi_cond.goal)]),
                     self.compile(pi_cond.fail, pi_cond.fail_theta, pi_cond.goal)])
```

class RobustTubeFunnel:
    def __init__(self, scene, aic, delta_est):
        self.scene, self.aic, self.delta_est = scene, aic, delta_est

    def tube(self, m, phi_hat, r):
        Omega = []
        for t in m.grid:
            rho_phi = propagate_param_ball(m, t, phi_hat, r)    # φ∈B∩𝒢 敏感度
            rho_aic = propagate_disturbance(m, t, self.aic.eps) # AIC 干扰集
            rho_est = self.delta_est                            # 估计误差
            rho = rho_phi + rho_aic + rho_est + SAFETY_MARGIN
            Omega.append(Ellipsoid(center=m.xi(t), radius=rho, E=m.sensitivity(t)))
        return Omega

    def certify(self, m, phi_hat, r):
        for t, om in zip(m.grid, m.Omega):
            if self.scene.collides(om): return False            # Ω(t) ∩ O = ∅
            if not self.contraction_ok(m, t): return False      # 漏斗前向不变
        return True

    def in_tube(self, x, om):
        d = x - om.center
        return float(d @ om.E @ d) <= om.radius ** 2            # O(1)

    def tracking(self, m, t, x):
        return m.u(t) + self.K_tube(t) @ (x - m.xi(t))

class TaskMotionBridge:
    def __init__(self, mpl, rtf, csp, max_refine=5):
        self.mpl, self.rtf, self.csp, self.max_refine = mpl, rtf, csp, max_refine

    def refine(self, tau, theta, x, x_prime, phi_hat, r):
        clauses = []
        for i, sigma in enumerate(tau):
            prims, found = self.mpl.plan(sigma, x, x_prime, theta[i], phi_hat, r,
                                         deadline=self.deadline)
            if not found:
                # 只有可靠不可行才剪枝；否则记 unknown 局部降级（不误杀）
                if self.sound_infeasible(sigma, x, phi_hat, r):
                    clauses.append(('forbid', (sigma, i), context(x)))
                else:
                    clauses.append(('unknown', (sigma, i), context(x)))
                continue
            x = prims[0].xi.end                                 # 前进到下一构型
        return clauses

    def sound_infeasible(self, sigma, x, phi_hat, r):
        # 区间算术/体积下界证明：任何满足 ρ 的管都撞障或超动力学限
        return interval_arithmetic_infeasible(sigma, x, phi_hat, r, self.scene)

    def solve(self, goal, x, x_prime, phi_hat, r):
        self.deadline = now() + DELTA_REFINE
        for k in range(self.max_refine):
            tau, theta = self.csp.plan(goal, x_prime, phi_hat, r)
            clauses = self.refine(tau, theta, x, x_prime, phi_hat, r)
            hard = [c for c in clauses if c[0] == 'forbid']
            if not hard: return tau, theta, clauses
            self.csp.add_clauses(hard)                          # 回灌符号约束
        return [SafeIdle()], [None], clauses                    # 兜底，不伪可行

### IP-208 BTV（行为树结构验证）

```python
def derive_contract(node):
    if isinstance(node, Act):
        return node.skill.contract                    # Pre⊇pre_σ, Post⊢eff_σ, Inv
    if isinstance(node, Cond):
        return Contract(Pre=TRUE, Post=node.pred, Inv=TRUE,
                        guard_onesided=True)
    if isinstance(node, Seq):
        cs = [derive_contract(c) for c in node.children]
        ok = all(implies(cs[j].Post, cs[j+1].Pre) for j in range(len(cs)-1))
        assert ok, 'sequence link violated'
        return Contract(Pre=cs[0].Pre, Post=cs[-1].Post,
                        Inv=all_and([c.Inv for c in cs]))
    if isinstance(node, Fall):
        cs = [derive_contract(c) for c in node.children]
        return Contract(Pre=any_or([c.Pre for c in cs]),
                        Post=any_or([c.Post for c in cs]),
                        Inv=all_and([c.Inv for c in cs]))
    if isinstance(node, Par):
        cs = [derive_contract(c) for c in node.children]
        return Contract(Pre=all_and([c.Pre for c in cs]),
                        Post=all_and([c.Post for c in cs]),
                        Inv=all_and([c.Inv for c in cs]),
                        monitor_preempt=True)
    if isinstance(node, (Retry, Timeout)):
        return derive_contract(node.child)

class BTV:
    def verify(self, T, leaf_contracts):
        for leaf in T.leaves():
            if not contract_implies(leaf.contract, leaf_contracts[leaf.id]):
                return CertResult(False, 'leaf_contract_mismatch', leaf.id)
        root = derive_contract(T.root)
        if not inductive_invariant(T, root.Inv):        # Pre∧Inv -> tick 后 Inv
            return CertResult(False, 'inv_not_inductive', None)
        if not monitor_priority_ok(T):                  # 监护先于任务提交
            return CertResult(False, 'monitor_priority', None)
        return CertResult(True, root, hash_tree(T))
```

    def update(self, idx, progress, compute_cost, risk, switched):

## 4. 推导

**引理 5（编译保持性与反应性）** 设叶契约（定义 203）成立，初始状态满足 `pre_σ1`。对编译树 `T_τ` 做结构归纳：
- `Fall_i` 的 `body=Seq(Cond(pre),Act,Cond(eff))`：`Cond(pre)` 为 Success 才进入 Act，Act 的契约保证 Success 时 `eff` 成立，随后 `Cond(eff)` 在同一 tick/紧邻 tick 校验；若任一守卫 Failure，`Fall_i` 立即转向 `Recovery_i`。
- 若所有 `Fall_i` 的 body 均 Success，则由 Seq 链接条件 `eff_σi ⇒ pre_σ{i+1}`（定义 208 检查）逐级推进，末守卫 G 成立，任务 Success。
- 若某技能恢复耗尽，进入 `SafeIdle`，其契约维持 `Inv`。
反应性：`Cond` 是叶子，每 tick 重评；`Fall` 短路时延为 O(1) 节点，故从守卫被违反到进入恢复 ≤ 1 个 tick。∎

**引理 6（精化保序与终止）** 抽象保序 `Pre_geo⊆pre` 下，若存在几何可行计划，则其每条符号边几何可行，`sound_infeasible` 返回 False，不会生成 `forbid` 子句；因此该计划不会被误删。冲突子句只在实际得到可靠不可行证据时加入，每条子句排除一个 `(边,上下文)`，有限抽象下至多 `K_refine` 次。采样超时仅标 `unknown` 并局部降级，不进入全局约束，故不会因超时误杀可行计划（代价是可能绕行或兜底）。在采样器概率完备极限（预算→∞）下，`unknown` 收敛为可靠判定。∎

**定理 4（认证行为树安全性）** 假设每个叶子满足其契约、组合规则（定义 208）可靠、监护节点在动作生效前可抢占。对树结构归纳证明 `Pre_root ∧ Inv_root ⇒ 每次 tick 后 Inv_root`：
- Act/Cond 由叶契约直接保持 `Inv`；
- Seq/Fall/Par 的 `Inv` 为子 `Inv` 的合取（定义 208），子保持则父保持；
- 监护 Failure 抢占保证危险动作不提交，故 `Inv`（碰撞自由、力/速度硬限）不被破坏。
因此根不变式归纳成立，特别地整棵树执行期间碰撞自由且满足动力学硬限。∎

**定理 5（RTF 轨迹安全）** 设实际扰动、参数偏差与估计误差落在 `Δ=ℰ_AIC×B(φ̂,r)×Δ_est` 内，且对每个 `t` 存在反馈 `K_tube(t)` 使 `Ω(t)` 关于标称场前向不变（漏斗条件）。由前向不变性，`x(0)∈Ω(0) ⇒ x(t)∈Ω(t) ∀t`。又规划器只接受 `Ω(t)∩O=∅`，故实际轨迹与障碍不相交，且 `u∈U` 保证动力学可行。将 `φ∈B∩𝒢` 的最坏情形吸收进 `ρ(t)`，结论对参数球内任意 `φ` 一致成立。∎

**定理 6（BATON 端到端）** 由定义 214，`Valid(J_baton)` 蕴含 `Valid(J_liro)`、`Valid(bt_cert)`、`mp_cert`、`tube_cert`。由定理 4 得结构安全（概率 1 于契约成立）；由定理 5 得轨迹安全（概率 1 于 Δ 覆盖，覆盖失败概率 ≤ `α_tube`）；BCP 守卫假阳性 ≤ `α_guard`，规划预算超时导致任务失败概率 ≤ `α_budget`。由联合界，`Valid(J_baton) ⇒` 安全概率 ≥ `1−α_tube`，任务成功率 ≥ `1−α_guard−α_budget`。规划失败只触发兜底，**不削弱安全性**（SafeIdle 契约维持 Inv）。∎

**引理 7（修复不降级）** BTR 仅提交满足 `BTV.verify` 且 `contract_nondecreasing(T,T2)`（新根契约蕴含旧根契约、`Inv` 不缩水）的补丁。由定理 4，`T2` 的不变式仍然归纳成立，故修复后认证安全裕度不下降；性能可能暂时下降，安全单调不降。∎

**引理 8（预算调度的 anytime 遗憾）** OCB-BT 在 K 臂上用 EXP3，伪遗憾 `≤ 2√(2KT log K)`；anytime 规划器在截止内单调改进（保留当前最好原语），故 `r_t` 非降。超时臂的奖励因 `compute_cost` 与 `risk` 被惩罚，EXP3 渐近避开；任务失败概率 `α_budget ≤ P(截止内无可行原语)`，且该事件只触发兜底。∎

## 8. 已知风险

**一句话**：行为树的组合正确性只对它**假定的叶子契约**成立——一旦学习型技能 π_σ 或运动原语在分布外几何/扰动下违反了其声明的 pre/eff 或管道前提，BTV 会把「未经充分验证的叶子」组合成「看起来经过验证的系统」，**结构可信被误当成组件可信，证书在最底层叶子处断裂**；而运动规划只具概率完备性（超时 ≠ 不可行）还会让 TMB 在「误杀可行计划」与「高估管道」之间二选一。

**次级风险与缓解**：
1. **叶子契约域外失效**（首要）：离线契约验证覆盖不到 OOD → 运行时用单侧保守守卫 + 管越界检测 + 定期留出集校验；一旦检测到叶子违约，**立即撤销该叶子的证书并降级到 SafeIdle**（fail-safe），同时把签名写入 BTL 触发修复。
2. **规划超时误判**：严格区分 `unknown` 与 `infeasible`，只有区间算术/体积下界等可靠证据才加冲突子句；`unknown` 只局部降级。缓解超时误杀，但可能绕路。
3. **接触丰富场景管道过保守**：接触动力学不确定使 `ρ(t)` 偏大，仿真中兜底率高达 44.7% → 引入接触感知漏斗（接触力锥内的局部收缩度量）与学习残差管道；保守兜底始终安全，只是效率损失。
4. **并行语义/监护时延**：监护必须在动作提交前生效 → 将动作切分为短原子片（≤1 tick）+ 提交屏障；对无法切分的长动作，限幅其单步位移并保证 `Inv` 单调。
5. **BTR 过拟合失败签名**：修复可能只记住表象 → BTL 条目需留出集验证 + 定期重新探索算子 + 失败签名做几何聚类而非原始残差。
6. **树规模与 tick 时延**：CSP 长计划会加深树 → 编译时限树深（≤12）与叶子数；超限则用编译期子树折叠（把纯序列段压成宏叶子）。
7. **抽象分类器域移**：pre/eff 谓词由学习分类器给出，可能不保序 → 仅将其作为**必要条件的保守近似**（宁严勿松），并用 TMB 的几何检查兜住符号层的乐观；符号层永不单独作为可行性证据。
