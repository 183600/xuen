### 第 6 轮灵感驱动研究记录

**灵感词**：故障诊断、语音合成

**继承关系**：第 5 轮 CADVS-v5（IP-493~496，CGE）把提议升级为条件流匹配 π_θ^FM、把记忆升级为 LMEM-v2 固化闭环、把人因升级为 FAMK 情感阈值调制 γ_i≥1，并以定理 5/6/7/8 保证「换提议不换门、调制只紧、固化有界、七锚完备」，执行集 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。但 v5 暴露两个尚未处理的结构性短板：(a) fail-closed 只会「拒绝」，不会「解释为什么拒绝」，也无法区分真不安全、传感器漂移、标定失效、门实现缺陷，导致误拒率与维护负债上升，且**证据本身是否可信从未被诊断**；(b) 人因通道是单向的——系统只看脸、人类既听不懂证书也无法安全地用语音介入，而语音与人脸都是可伪造的对抗面。两个灵感词统一为主题「可诊断的认证执行」（Diagnosable Certified Execution, DCE），形成 CADVS-v6（IP-497~500）。本轮自律：**硬门数量仍不增**（维持七门，延续 R52 锚点负债控制）；诊断与语音都做成**只读观测层 + 只紧通道**，绝不拥有放松门的权限，执行集嵌套升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **故障诊断 → 给证书系统装上「听诊器」，但听诊器不能改判**。直觉：v5 的七个门像七个只会喊「不行」的裁判；故障诊断让系统能说「是谁坏了、坏在哪、要不要修」，并把「喂给门的证据是否可信」本身纳入监测。严谨：引入证据完整性故障诊断核 EIFDK，对每条证据通道（力/位姿/接触/几何/记忆/价值）生成残差 r（门边际 m_i=s_i−τ_i 与解析冗余残差 e_j），构造故障签名矩阵 S∈{0,1}^{p×m}，用结构化残差做**可分离性判定**与**最小诊断**（冲突集的最小 hitting set，Reiter）。关键红线（**定理 9 诊断观测无害性**）：诊断算子只读残差、只输出信任状态，门谓词与阈值只允许被「收紧」；被诊断为故障的通道直接 fail-closed（门恒拒），绝不允许旁路或降阈。信任格 HEALTHY ≻ DEGRADED ≻ FAULTED 上执行集单调收缩，恢复只能靠**修复**（重标定/换传感器）恢复可用性，不能靠放宽门。

2. **语音合成 → 让证书「被听见」，并让语音介入「只紧不松」**。直觉：如果人听不懂系统为何拒绝，人因锚就是空转；让系统用语音把证书念出来，人就能参与诊断与恢复。但合成的语音必须「说的每句话都能在证书里找到依据」，否则解释本身就是新的幻觉源。严谨：证书落地语音器 CGSV——受限文法 + 蕴含校验，神经 TTS 只负责韵律渲染、不产生内容；每个断言必须由证书记录 Cert 蕴含（**定理 11 可听化忠实性**），合成语音打水印可溯源，韵律被约束为「安全一致」（危险时不得用安抚语调）。反向的语音通道 VIAK：说话人验证 + 反重放/反深度伪造（**把语音通道本身当作被诊断子系统**），语音指令只能触发「停止/减速/收紧」这类**只紧**动作，结构上不存在「语音放松安全门」的代码路径（**定理 12 语音 veto 单调与防伪造**）；副语言痛苦线索与 FER 融合，仍只收紧。

**关键洞见**：v4 回答「规则提议时七门够不够」，v5 回答「生成提议+记忆+情感时证书边界是否不变」，v6 回答「当证据本身可能坏、当人要通过可伪造的语音通道介入时，如何让认证边界既保持又变得**可诊断、可解释**」。诊断与语音都是**元层**：诊断是只读观测器，语音是只紧接口；七硬门 kc_evidence_forged_v5 原样复用，新增的只有信任状态、可听化忠实性、反伪造界。执行集 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 由「同门 + 诊断只紧 + 语音只紧」保证；当诊断恒判健康、语音关闭时精确退化为 v5。

**形式化目标（增量）**：
1. EIFDK：残差 r、故障签名矩阵 S、可诊断性判据（列可分离）、最小诊断 hitting set、信任格与 fail-closed 降级、恢复编排、诊断解释 Dx。
2. CGSV：证书记录 Cert → 断言集 P(Cert) → 受限文法句子 → 神经 TTS；蕴含校验 soundness；水印检测；安全一致韵律约束。
3. VIAK：语音指令 → ASR → 说话人验证 + 反伪造 → 只紧动作集 A_tighten；副语言痛苦与 FER 融合；无放松路径。
4. 定理 9（诊断观测无害/执行集单调）、定理 10（七门可诊断性判据）、定理 11（可听化忠实性）、定理 12（语音 veto 单调与防伪造）、定理 13（七锚完备性在诊断/语音元层下保持）。
5. EFA-v6：七硬门 + 信任门控 + 诊断解释 + 语音接口；ECS_v6 = ECS_v5 · η_diag · η_verbal。
6. Exec_CADVS-v6 = {x ∈ Exec_CADVS-v5 : trust(evidence) ≠ FAULTED ∧ 语音通道 bonafide} ⊆ Exec_CADVS-v5。

**本轮最大风险**：**诊断器自身漏诊（who watches the watchmen）**——证据完整性诊断成为新的单点失效：若传感器故障恰好落在诊断器的盲区（残差零空间），失真的证据会被当成健康证据送进门，fail-closed 在「诊断正确」这一前提被悄悄破坏后失效；语音可听化还可能制造「已解释 = 已安全」的信任错觉。只能靠多源冗余残差、诊断器自身的独立红队与周期性物理标定缓解，无法根除。

## 2. 关键算法骨架

### IP-497 EIFDK：证据完整性故障诊断核（准入/1–10 Hz，与 1 kHz 控制环解耦）

```python
@dataclass
class EvidenceIntegrityFaultDiagnosisKernel:
    """EIFDK：证据完整性故障诊断。
    定理 9（诊断观测无害）：诊断只读残差、只输出信任状态，绝不改判门。
    红线：FAULTED 通道 → 门恒拒（fail-closed），禁止旁路、禁止降阈。"""
    signature: np.ndarray        # S ∈ {0,1}^{p×m}，离线由结构可分离性设计得到
    eps: np.ndarray              # 各残差噪声阈 ε_j
    delta_max: float = 0.1

    def residuals(self, x, c, meas) -> np.ndarray:
        m = np.array([g.margin(x, c) for g in GATES])      # 门边际 m_i
        e = parity_residuals(meas)                          # 解析冗余 e_j
        return np.concatenate([m, e])

    def diagnose(self, r: np.ndarray) -> Diagnosis:
        alarm = np.abs(r) > self.eps                        # supp(r)
        cand = [i for i in range(1, self.m + 1)
                if self._consistent(self.signature[:, i], alarm)]
        conflicts = self._conflict_sets(alarm, self.signature)
        Dx = minimal_hitting_sets(conflicts)                 # Reiter 最小诊断
        trust = self._trust_from(Dx, cand, r)               # H / G / F
        return Diagnosis(trust=trust, Dx=Dx, explain=self._explain(Dx))

    def _trust_from(self, Dx, cand, r):
        # 单故障、可隔离且幅值显著 → FAULTED；多解不可隔离 → DEGRADED（收紧）
        if len(Dx) == 1 and self._isolable(Dx[0]):
            return {ch: 'F' for ch in self._affected_channels(Dx[0])}
        if len(Dx) >= 1:
            return {ch: 'G' for ch in self._affected_channels(Dx)}
        return {ch: 'H' for ch in self._all_channels()}

    def gate_multiplier(self, trust) -> dict:
        # HEALTHY→1；DEGRADED→1+δ（δ≤δ_max）；FAULTED→∞（门恒拒）
        return {i: (math.inf if trust[ch_i] == 'F'
                    else 1.0 + self.delta_max if trust[ch_i] == 'G'
                    else 1.0)
                for i, ch_i in GATE_CHANNEL.items()}
```

### IP-498 CGSV：证书落地语音器（准入/事件触发，10–30 Hz 渲染，与控制环解耦）

```python
@dataclass
class CertificateGroundedSpeechVerbalizer:
    """CGSV：证书落地语音。
    定理 11（可听化忠实性）：每句都由 Cert 蕴含；TTS 只渲染文本/韵律，不产生内容。"""
    grammar: Any                  # 受限文法：模板 + 闭词表 + 类型化槽位
    tts: Any                      # 神经 TTS（仅 prosody 可控，文本 token 冻结）
    watermark: Any

    def verbalize(self, cert: Certificate) -> Audio:
        facts = entailment_atoms(cert)             # P(Cert)：拒绝原因/故障 Dx/边际/建议
        plan = select_required(facts)              # 必报项：verdict + 主因 + 信任状态
        text = self.grammar.render(plan)           # 只允许 P(Cert) 中的原子
        assert self._entailed(text, cert)          # 蕴含校验（soundness 硬断言）
        prosody = safety_consistent_prosody(cert)  # 危险时禁止安抚/轻快语调
        audio = self.tts(text, prosody=prosody)    # 文本 token 序列不变
        return self.watermark(audio, w=SYNTH_MARK) # 合成语音可溯源
```

### IP-499 VIAK：语音介入认证核（端侧，10–30 Hz，与控制环解耦）

```python
@dataclass
class VoiceInterfaceAuthenticationKernel:
    """VIAK：语音介入。
    定理 12：语音只紧不松 + 反伪造；「语音放松安全门」不存在代码路径。
    语音通道本身是被诊断子系统（反重放/反深度伪造 = 通道故障诊断）。"""
    sv: Any                 # 说话人验证（注册声纹）
    anti_spoof: Any         # 反重放 / 反深度伪造（CQCC/相位/水印一致性）
    kappa_v: float = 0.5
    sigma_max: float = 0.25

    def handle(self, audio, s_face) -> Action:
        spk = self.sv.verify(audio)
        bona = self.anti_spoof(audio)
        if not spk.ok or not bona.ok:
            return Action.reject_and_alert()          # fail-closed，报警并记录 Dx
        intent = asr(audio)
        if intent in A_TIGHTEN:                        # 仅 STOP/SLOW/TIGHTEN/HANDOVER
            return Action.tighten(intent)
        return Action.reject_unsupported()             # 无放松路径（结构上不可能）

    def gamma_voice(self, s_voice, s_face) -> float:
        p = max(s_face.p_distress if s_face else 0.0,
                s_voice.p_distress if s_voice else 0.0)
        if s_voice and s_voice.sigma > self.sigma_max:
            p = s_face.p_distress if s_face else 0.0
        return 1.0 + self.kappa_v * p                  # ≥ 1 恒成立
```

### IP-491 扩展 CERTCALC-v6：新增定理 9~13（离线理论）

```python
# 定理 9：诊断观测无害性 / 执行集单调
def theorem_diagnosis_innocuousness() -> str:
    """
    定理 9：设诊断 D: r↦trust 是残差与故障模型的纯函数，且门阈值调制满足
    γ_i^diag ∈ [1,∞]，FAULTED 记为 γ=∞（门恒拒）。则
    (i) kc_i^{v6}(x) = kc_i^{v5}(x) ∧ 1[trust_i ≠ F]，τ_i^6 = γ_i^diag·τ_i^5 ≥ τ_i^5；
    (ii) Exec_v6 = {x∈Exec_v5 : ∀k trust_k≠F} ⊆ Exec_v5；
    (iii) D 不能把任一拒绝变为通过（诊断只出现在合取/单调阈值位置）。
    证明：(i) 构造；(ii) 由 γ≥1 各门通过集单调缩、再交信任门控；(iii) 反设需
    γ<1 或去掉合取项，均被构造排除。∎
    工程含义：诊断只增加「可用性修复」与「解释」，不增加「放行权」。
    """
    return "Proven"

# 定理 10：七门可诊断性判据
def theorem_diagnosability() -> str:
    """
    定理 10：在结构化残差 r=Sr·f+n（n 有界）下，故障集 F 可诊断当且仅当
    (D1) 可检测：∀i, S_{·i} ≠ 0；
    (D2) 可隔离：∀i≠j, S_{·i} ≠ S_{·j}；
    (D3) 加性故障需无成比例列（S_{·i} ∦ S_{·j}），否则仅可检测不可隔离。
    最小可检测幅值 f_min = 2ε/‖S_{·i}‖（ε 为残差噪声界）。
    证明：由奇偶空间结构化残差理论（Gertler）；列相等 ⇒ 存在不可区分故障对。∎
    诚实边界：D1~D3 是设计期条件，部署期 S 的失配会静默削弱可诊断性。
    """
    return "Proven (design-time); mismatch degrades silently"

# 定理 11：可听化忠实性
def theorem_verbalization_faithfulness() -> str:
    """
    定理 11：若文法 G_gram 的每条推导只使用 P(Cert) 中的原子，且 TTS 保持文本
    token 序列不变（仅改韵律），则输出语音 u 相对 Cert 是 sound 的：u 中每个
    可断言命题都被 Cert 蕴含；且水印检测漏检率 ≤ δ_w。
    证明：对文法推导做结构归纳（每个产生式右部原子 ∈ P(Cert)）；TTS 文本保持性
    保证内容不被篡改；水印由扩频检测错误界给出。∎
```

### IP-500 EFA-v6：七硬门 + 诊断信任门控 + 可听化 + 语音接口

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：七硬门不变；诊断/语音为只紧元层。"""
    v5: EvidenceForgingAssemblerV5
    eifdk: EvidenceIntegrityFaultDiagnosisKernel
    cgsv: CertificateGroundedSpeechVerbalizer
    viak: VoiceInterfaceAuthenticationKernel

    def select(self, x0_state, t_now, rule_id, context):
        # 1) 证据完整性诊断（只读）
        r = self.eifdk.residuals(None, context, context.measurements)
        dx = self.eifdk.diagnose(r)
        gamma_diag = self.eifdk.gate_multiplier(dx.trust)
        # 2) 语音介入（只紧；伪造即拒并报警）
        action = self.viak.handle(context.audio, context.s_emo)
        gamma_voice = self.viak.gamma_voice(context.s_voice, context.s_emo)
        if action.kind in ('STOP', 'HANDOVER'):
            cert = Cert(False, cause=action, dx=dx)
            self.cgsv.verbalize(cert)
            return False, None, action.kind
        # 3) 任一证据通道 FAULTED → fail-closed，且给出可听化解释
        if any(t == 'F' for t in dx.trust.values()):
            cert = Cert(False, cause='EVIDENCE_FAULT', dx=dx)
            self.cgsv.verbalize(cert)
            return False, None, 'EVIDENCE_FAULT'
        # 4) 交给 v5 内层（阈值叠加诊断/语音收紧，仍只紧）
        gamma = combine(gamma_diag, gamma_voice, self.v5.famk.gamma(context.s_emo))
        ok, best, reason = self.v5.select(x0_state, t_now, rule_id,
                                          context_with(gamma))
        self.cgsv.verbalize(Cert(ok, reason=reason, dx=dx))
        return ok, best, reason

    def ecs_v6(self, v5_terms, n_Dx: int, verbal_conf: float) -> float:
        eta_diag = 1.0 - 0.2 * min(n_Dx / 3.0, 1.0)
        eta_verbal = verbal_conf
        return self.v5.ecs_v5(**v5_terms) * eta_diag * eta_verbal
```

### 集成流水线（v5 → v6）

```
离线/设计期：
  故障签名设计：故障集 F × 残差集 → 结构化残差，满足 D1~D3（定理 10）
  语音器构建：证书 schema → 受限文法 G_gram + 断言模板 + 水印密钥（签名下发）
  反伪造训练：重放/深度伪造/对抗音频 → anti_spoof 检测器（含诊断器红队）
  诊断器红队：残差零空间攻击、慢漂移、共模故障 → 评估漏诊率

在线准入（异步，秒级）：
  EIFDK.residuals/diagnose (1–10 Hz) ──▶ trust, Dx
     ├─ 任一 FAULTED ──▶ fail-closed + CGSV 播报「哪个通道故障 + 建议」
     └─ HEALTHY/DEGRADED ──▶ γ_diag（只紧）
  VIAK.handle (10–30 Hz) ──▶ 只紧动作 / 拒绝伪造（报警 + Dx）
  EFA-v6 ──▶ v5 内层（七门 + γ 收紧）──▶ CGSV 播报证书（忠实、带水印）

在线控制环（目标 < 0.6 ms，继承 v5）：
  每周期：EEK + BCK（事件触发；触发条件新增「诊断状态变更」）
  消费预计算 γ = combine(γ_diag, γ_voice, γ_emo)；诊断/语音均不进入 1 kHz 环
```

## 3. 复杂度分析（增量更新）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 | 实时性指标 |
|---|---|---|---|---|

| VIAK.handle | O(f_audio) ASR+SV+反伪造 | O(1) | 10–30 Hz | ~5–20 ms，端侧 |
| γ 合成/ECS_v6 | O(1) | O(1) | — | < 0.01 ms |
| EFA-v6 硬门 | O(1)（阈值预计算） | O(1) | — | < 0.03 ms |

**通信开销**：诊断解释 Dx 与信任状态随证书落盘（~1 KB/事件，签名）；语音仅本地渲染或端侧播放；声纹/原始音频不出端，反伪造在端侧完成；水印密钥与文法由签名下发。跨站仅上报 DP 后的漏诊率/误诊率统计。

**实时性说明**：诊断与语音全部位于准入/事件时域，控制环只消费预计算 γ；诊断状态变更通过事件触发 BCK 重解，不引入周期性开销。**诊断不增加控制环延迟**。

## 4. 正确性论证（增量更新）

### 引理 45（残差噪声下的漏诊界）

**陈述**：设残差噪声 ‖n‖∞ ≤ ε，故障 f_i 的签名列范数 ‖S_{·i}‖₂，则幅值 ‖f_i‖₂ < 2ε/‖S_{·i}‖₂ 的故障以概率 1 不可检测（落在噪声球内）；对幅值 ≥ f_min 的故障，漏诊率 ≤ P(‖n‖∞ > ‖S_{·i}‖‖f_i‖/2) ≤ p·exp(−c·‖S_{·i}‖²‖f_i‖²/ε²)（Hoeffding/次高斯）。∎

**诚实边界**：该界只对**建模内**故障成立；未建模故障（签名外）可能落在残差零空间，漏诊率无界——这正是本轮最大风险的理论根源。

### 引理 46（合成语音水印漏检界）

**陈述**：扩频水印在加性噪声/重编码下，检测统计量服从高斯，漏检率 ≤ Q((μ_w − τ_w)/σ_w)；给定误报率 α，漏检率随水印能量 SNR 单调下降。∎

**诚实边界**：强去水印攻击（重合成、声码器再渲染）可显著抬高漏检率，水印只提供**溯源**而非**防伪**；防伪主力是 anti_spoof 检测器（经验界）。

### 定理 v6（诊断/语音元层的单调收缩与忠实性，总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) 诊断器对建模内故障满足 D1~D3、(B9) 语音器满足受限文法与文本保持性下：
(i) Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29（诊断只紧 + 语音只紧 + 同门）；
(ii) 诊断观测无害：D 不能把拒绝变通过（定理 9）；
(iii) 可诊断性：建模内故障可检测/可隔离当且仅当 D1~D3（定理 10），最小可检测幅值由引理 45 给出；
(iv) 可听化忠实：语音断言 sound，水印可溯源（定理 11 + 引理 46）；
(v) 语音 veto 单调且防伪造接受概率 ≤ FAR_v + (1−FAR_v)δ_w（定理 12）；
(vi) 七锚完备性保持（定理 13）。

**证明**：(i) 由定理 9（γ_diag≥1、FAULTED 恒拒）+ 定理 12（A⊆A_tighten）+ v5 嵌套；(ii) 定理 9(iii)；(iii) 定理 10 + 引理 45；(iv) 定理 11 + 引理 46；(v) 定理 12；(vi) 定理 13。∎

**诚实声明**：(B8) 只覆盖建模内故障，签名外/零空间故障漏诊无界；(B9) 忠实性不蕴含可理解性，韵律误导需靠「安全一致韵律」约束；(iii) 语音防伪是军备竞赛，FAR_v 随攻击演进漂移；(iv) 诊断器与反伪造器自身是新的单点失效（who watches the watchmen）；(v) 加性价值假设 (B4) 继承自 v4，未解决。

## 7. 本轮最大风险（最终确认）

**一句话**：**诊断器自身漏诊（who watches the watchmen）**——证据完整性诊断成为新的单点失效：若传感器故障恰好落在诊断器的残差零空间，失真的证据会被当成健康证据送进门，fail-closed 在「诊断正确」这一前提被悄悄破坏后失效；语音可听化还可能制造「已解释 = 已安全」的信任错觉。只能靠多源冗余残差、诊断器独立红队与周期性物理标定缓解，无法根除。
