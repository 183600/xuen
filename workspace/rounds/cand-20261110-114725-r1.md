# 第 43 轮（新循环第 3 轮） · 空间证书 × 参与式共创：把「位姿不确定性」与「用户经验」焊进证书飞轮（四层架构 v8）

> 承接第 42 轮 v19（Sim-Cert-RAG 飞轮）。第 42 轮自陈最大风险是「仿真偏差累积 + 检索幻觉」，本质是**证书的输入（状态与模板）都不可信**。本轮灵感词「SLAM」「用户共创」正好从两个方向补这层信任：**SLAM** 让证书意识到自己站在一个**会漂移、会重访、会变化的地图**上——状态不是一个点而是一个信念椭球，证书必须为位姿不确定性付费、随地图漂移过期、随回环重认证、随重访检索复用；**用户共创**让证书作者从少数专家扩展为**在环用户**——演示、自然语言约束、偏好、红队反例都能进入知识库，但必须穿过「非扩张信任格」与自动验证闸门。两者合成一个新对象：**参与式语义证书地图（PSCM）**——地图不只存几何，还存「谁在这里、因为什么、在什么信任等级下、认证到何时」的证书。SLAM 提供空间索引，用户共创填充语义经验，证书从「时间里的资产」升级为「空间里可被社区维护的公共资产」。

## 0. 直觉与动机

**灵感 1（SLAM → 证书的「位姿税」与「空间记忆」）**：前三轮所有证书都默认状态 `x` 已知，但机器人拿到的永远是估计 `x̂` 与协方差 `Σ`。直觉上，定位越不确定，安全边际越该被「打折」：真实状态可能落在可信椭球的任意角落，而边际是 Lipschitz 的，所以最坏边际约为 `m(x̂) − L_m·椭球半径`，这就是**位姿不确定性税 Δ_pose**。更关键的是 SLAM 的两个特有事件：**回环**（pose jump 会让证书瞬间失真，必须先冻结再重认证）与**重访**（同一地点再次到达，应直接取回上次在该地点验证过的局部证书，而不是重算——这把回环检测变成「空间检索」）。而**漂移**意味着离上次建图越远证书越不可信，需要一个**漂移前沿 d_frontier** 让证书随距离过期。SLAM 因此不只是定位模块，而是证书的**空间索引与失效时钟**。

**灵感 2（用户共创 → 证书的「参与式作者」与「非扩张闸门」）**：过去证书只能由专家离线撰写。用户共创的直觉是：真正懂场景的人是现场用户——他们能示范「这里要慢」，能说「别靠近楼梯」，能提供「上次打滑」的反例，能表达偏好（更保守/更快）。但用户输入**不可信、可能矛盾甚至恶意**。所以关键不是「让用户随便写」，而是设计一个**安全闸门**：用户贡献只能在**收缩/特化**方向改变证书，绝不能在未证明的情况下**放大**安全包络。形式化为**非扩张合并**：`Safe(C ⊕ u) ⊆ Safe(C)`。再叠加**演示→证书编译器（Demo2Cert）**与**自然语言约束解析**，用户不必懂形式化方法也能贡献可验证的证书片段。

**灵感 3（合成 → 参与式语义证书地图 PSCM）**：把两者焊在一起：SLAM 的地点识别与 CKB 的检索其实是同一件事的两面——**地点是空间指纹，任务是语义指纹**。于是定义地点证书 `c_p`：绑定一个地图锚点、一组语义风险标签、一组局部守卫/边际/保持时间，以及**来源与信任等级**。用户在一处标注「儿童出没」，该标注经 VLM 解析为语义风险场，经 SCV 验证为局部保守约束，再以地点证书落库；机器人重访该地点时，SLAM 地点识别直接命中 KB 取回证书，并按位姿税与漂移前沿修正。环境变了（家具挪动 = **空间漂移**），变更检测触发**再认证请求**，用户只需确认「是/否变化」，这就是人类在环的地图维护。证书由此成为**可被社区维护、可追溯、会过期的空间公共资产**。

**耦合升级**：SLAM 是证书的「空间坐标 + 失效时钟」，用户共创是证书的「来源 + 语义 + 信任」，SCV 是「验证闸门」，CKB 是「沉淀仓库」，ECR 是「边缘执行」。新飞轮：**位姿/漂移 → 空间检索 → 用户/专家模板 → 验证 → 地点证书 → 边缘执行 → 变更检测 → 再认证**。

## 1. 形式化定义（增量：定义 38–45）

先给直觉，再给定义：前四者解决「状态不确定」，中间两者解决「用户不可信」，最后两者把证书锚定到空间。

**定义 38（信念状态、可信集与位姿税）**：信念状态 `b_t = (x̂_t, Σ_t)`；`β`-可信集 `E_β(b) = {x : (x−x̂)^T Σ^{-1} (x−x̂) ≤ χ²_{d,β}}`。**信念边际** `m(b) = min_{x∈E_β(b)} m(x)`；**位姿不确定性税** `Δ_pose(b) = L_m·√(χ²_{d,β}·λ_max(Σ))`。**命题**：若边际 `m` 关于状态是 `L_m`-Lipschitz，则 `m(b) ≥ m(x̂) − Δ_pose(b)`，故守卫 `m(b) ≥ θ` 是 sound 的充分条件。

**定义 39（空间证书与漂移前沿）**：证书依赖地图 `M` 与 IP-49 的里程计漂移界 `B_t`。定义**漂移前沿** `d_frontier = (B_max − B_0)/κ`（`κ` 为漂移增长率上界），**空间证书** `C_p = (anchor p, M|_p, d_frontier, θ_p, L_m,p, trust, expiry)`。当 `B_t + κ·d_since_loop > B_max` 或距最近回环超过 `d_frontier`，`C_p` 自动降级为 `unverified`。

**定义 40（认证感知主动 SLAM）**：策略 `π` 选择视点/动作，目标 `J(π) = E[Σ_t φ(m(b_t)) − λ·cost]`，其中 `φ = 1[m(b_t) ≥ θ]`（可认证覆盖率）或 `min(m(b_t) − θ, 0)`（避免不可认证区）。与熵最大化主动 SLAM 的区别：**只为证书敏感区（守卫面附近、L_m 大、地图不确定）买信息**，其余区域不浪费探索预算。

**定义 41（共创信任格与非扩张合并）**：信任等级 `T = {E 专家认证, C 众包验证, U 用户建议, X 外部未审}`，序 `E ⊐ C ⊐ U ⊐ X`。合并算子 `⊕` 必须满足**非扩张性**：`Safe(C ⊕ u) ⊆ Safe(C)`；任何「扩大安全集」的贡献都不得经由合并进入，必须作为**新证书**走完整 SCV 认证。**命题**：若每次准入都通过非扩张闸门，则知识库任意前缀的证书集合对固定地图与分布仍 sound。

**定义 42（Demo2Cert：演示到证书编译）**：用户示范轨迹集 `D = {ξ_i}`。约束推断得候选不变式 `Inv_D` 与守卫 `g_D`；在 SCV 中做覆盖与反例搜索；通过后生成证书片段 `C_D = (Inv_D, g_D, θ_D, provenance=user, trust=U)`。准入条件：Sim 验证风险 `≤ ε_sim` 且非扩张检查通过。

**定义 43（自然语言约束与有界偏好场）**：用户语句 `ℓ` 经 VLM/LLM 解析为语义约束集 `K(ℓ)`（物体/区域/动作谓词），映射为语义风险场 `ρ_ℓ(x)` 与局部不变式。偏好场 `δ_p(x)` 满足 `|δ_p(x)| ≤ δ_max` 且仅作用于非关键区（`m(x̂) − θ ≥ δ_max`），硬安全包络 `θ` 不变。**命题**：有界偏好场在关键区被屏蔽，故其单独不可能造成硬安全违例。

**定义 44（参与式语义证书地图 PSCM）**：`PSCM : P → C_p ∪ ∅`，`P` 为地点集合。`c_p = (p, sem_labels, Inv_p, g_p, θ_p, L_m,p, provenance, trust, t_stamp, expiry)`。**空间检索** `R_place(z) = Top-k` over place-recognition embedding；命中后按位姿税与漂移前沿修正 `m(b)` 再判定。

**定义 45（空间漂移与再认证）**：变更统计量 `D_t = d(M_t, M_{t−Δ})`（占用/语义/拓扑差异）。若 `D_t > τ_space` 或重访配准残差超界，`c_p` 标记 `stale`，触发：(1) 冻结依赖 `c_p` 的守卫；(2) 用户一次确认（change? y/n）；(3) 若变，SCV 重跑局部证书并版本递增。**命题**：若变更漏检率 `≤ δ_s` 且再认证延迟 `≤ L`，则陈旧证书被使用的总时间 `≤ L + δ_s·T`。

## 2. 产出设计（增量 IP-57/58/59 + 升级 IP-49/51/52/54/55/56/50/45/47）

### 2.1 IP-57 SPATIAL-CERT-COUPLING（空间证书耦合 SCL）
1. **信念边际传播**：在 IP-53 区间电路之上接入 `Σ`，用 Lipschitz 税给出 `m(b)`；各向异性 `Σ` 用最大特征值/支撑函数，避免保守到不可用。
2. **回环连续性守卫**：检测 `pose jump > δ_jump` 时冻结受影响地点的守卫，重定位后先局部重认证再恢复 Nominal（证书连续性窗口）。
3. **漂移前沿与过期**：每个地点证书带 `expiry`，由 `B_t`、`d_since_loop`、`κ` 计算；过期触发检索刷新或降级。
4. **认证感知主动 SLAM**：效用 = 可认证覆盖率与回退风险；用边际敏感度加权 next-best-view，输出「已认证区域地图」与「待认证前沿」。

### 2.2 IP-58 PARTICIPATORY-CERT-STUDIO（参与式证书工坊 PCS）
1. **信任格与准入闸门**：`E/C/U/X` 四级；非扩张合并断言 `Safe(C_new) ⊆ Safe(C_old)`；放大必须走完整认证。
2. **Demo2Cert**：遥操作演示 → 约束推断（不变式/守卫）→ SCV 验证 → 准入；给出最小修复建议而非直接拒绝。
3. **自然语言约束解析**：VLM 将语句 grounding 到物体/区域/动作谓词，歧义时主动追问（主动共创），输出语义风险场。
4. **偏好场与多用户聚合**：有界偏移 `δ_max`；多用户用 Pareto/社会选择聚合，冲突取保守交集。
5. **防投毒审计**：来源图、独立冗余支撑、异常检测、专家抽检与「信任债务」预算；可疑贡献隔离沙箱。

### 2.3 IP-59 PARTICIPATORY-SEMANTIC-CERT-MAP（参与式语义证书地图 PSM）
1. **地点指纹**：地点识别嵌入 + 语义哈希，HNSW 空间索引，与 CKB 语义索引双路召回。
2. **地点证书检索与修正**：重访时取回 `c_p`，施加位姿税与漂移衰减后再判定；不命中则退化为在线证书。
3. **人类在环地图维护**：变更检测 → 一键确认 → 局部重认证 → 版本递增；只在确有漂移时打扰用户。
4. **语义风险场融合**：用户标注 + VLM 标签取保守上包络，形成有界 `ρ(x)`。

## 3. 四层架构 v8

```
L1: TRI-FUSE(INT8) + IP-49 LIO → x̂_t, Σ_t(位姿协方差), C_ms, B_t(漂移界)
    + IP-57 SCL: 位姿税 Δ_pose = L_m·r(Σ)、漂移前沿 d_frontier、回环连续性守卫
L2: CTC + VLM + IP-35 仲裁 → 语义观测 + IP-58 自然语言约束/偏好场
    + IP-59 PSM: 地点识别 ↔ CKB 空间索引，语义风险场 ρ(x)
L3: IP-51 CAR(信念守卫 m(b) ≥ θ, 信任门) ← IP-56 ECR(L0查表 + L1 INT8 + 漂移监控)
    → IP-57 认证感知主动SLAM / 回环/漂移重认证 → IP-39 规划(CBF margin=m(b))
    → IP-45 总线(共创/变更心跳) → IP-53 CMC(看门狗=L1 INT8)
L4: IP-55 CKB(任务×地点检索 + 信任格 + 模板合并) ← IP-54 SCV(用户红队 + Demo2Cert 验证)
    ← IP-58 PCS(信任闸门 + 偏好场 + 防投毒审计)
    ← IP-59 PSM(地点证书 + 人类确认地图维护)
    → IP-44 蒸馏(QAT→INT8) + IP-50 课程(用户共创课程) → RCA 重颁证书(版本+信任+有效期) → 契约热更新
运行期：位姿/地点查询(组合<10μs) + 信念边际 + L1 监控(100μs) + 漂移/变更监控
        → 本地重认证 或 飞轮触发 → Sim 重跑 → KB/地点证书更新 → 热更新下发
```

## 4. 实验设计（E87–E94 硬门槛，承接 E79–E86）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E87 信念空间边际有效性 | 真实误差落入 β-椭球比例；位姿税后违例率 | 覆盖 ≥ β−1pp；违例 = 0 |
| E88 认证感知主动 SLAM | 可认证面积/时间 vs 熵基线；不可认证状态占比 | 覆盖速度 ≥ 1.5x；不可认证 < 10% |
| E89 回环连续性 | 回环期间不安全事件；冻结→重认证恢复时间 | 0 起；< 2s |
| E90 Demo2Cert | 用户演示→通过率；误准入（验证放行的不安全证书）；编译时间 | 通过 ≥ 70%；误准入 0/100；< 10min |
| E91 非扩张/防投毒 | 注入 50 个恶意贡献：检测率；安全集被放大次数 | 检测 ≥ 95%；放大 = 0 |
| E92 偏好场 | 用户满意度；硬安全违例 | 满意度 ≥ 80%；违例 = 0 |
| E93 地点证书检索 | 地点识别召回；证书复用率；空间漂移检测延迟/误报 | 召回 ≥ 0.95；复用 ≥ 60%；< 1s；误报 < 5% |
| E94 长期共创现场 | 4 周 / 10 用户：专家验证负担降幅、证书贡献数、采纳率 | 负担降 ≥ 50%；贡献 ≥ 100；采纳 ≥ 60% |

回退：E87 位姿税过保守 → 自适应 `β` + 只在守卫附近用信念界，远处用名义界；E88 主动 SLAM 不收敛 → 退回均匀探索 + SafeStop 区域扩大；E90/E91 出现误准入或投毒 → **冻结用户共创通道**，回退纯专家证书；E93 漂移检测失效 → 缩短 `d_frontier` 并降低地点证书权重；E94 采纳率低 → 简化交互，仅保留「一键确认 + 演示」两条通道。

## 5. 本轮最大风险

**一句话**：本轮把证书同时绑到「会漂移的地图」和「不可信的用户」上，最致命的新失效链是**被投毒的空间记忆**——一条由恶意或错误贡献产生、却通过了看似保守的合并、又被地点识别反复命中的陈旧证书，会在环境已变后仍被当作已验证经验复用并扩散；因此 E91（非扩张/防投毒）与 E93（漂移失效）必须作为红线实验，任一不达标即冻结用户共创通道并回退到纯专家证书。

# 第 43 轮产物 · 创新点清单 v20：空间证书（SCL）× 参与式共创（PCS）× 参与式语义证书地图（PSM）（四层架构 v8）

> 承接第 42 轮产物 v19（Sim-Cert-RAG 飞轮）。本轮**增量插入** IP-57/58/59，并升级 IP-49/51/52/54/55/56/50/45/47；不推倒任何既有层级。核心是把 v19 的「仿真验证→知识沉淀→边缘低成本→持续进化」再叠加两维：**空间（SLAM 提供的位姿/地图/漂移）**与**来源（用户共创提供的语义/偏好/信任）**，使证书从「时间里的资产」变为「空间里可被社区维护的资产」。

## 2. 关键推导（命题与证明）

**命题 1（位姿税下界）**：若边际 `m` 关于状态是 `L_m`-Lipschitz，则 `m(b) ≥ m(x̂) − Δ_pose(b)`，其中 `Δ_pose(b) = L_m·√(χ²_{d,β}·λ_max(Σ))`。

*证明*：对任意 `x ∈ E_β(b)`，有 `‖x − x̂‖_Σ ≤ √χ²_{d,β}`，故欧氏距离上界 `‖x − x̂‖₂ = ‖Σ^{1/2}Σ^{-1/2}(x−x̂)‖₂ ≤ √(λ_max(Σ))·‖x−x̂‖_Σ ≤ √(χ²_{d,β}·λ_max(Σ))`。由 Lipschitz 得 `m(x) ≥ m(x̂) − L_m‖x−x̂‖₂ ≥ m(x̂) − Δ_pose(b)`。对 `E_β` 取下确界即得 `m(b) ≥ m(x̂) − Δ_pose(b)`。∎
*备注*：若 `Σ` 各向异性极强，可用支撑函数 `h_Σ(u) = √(uᵀΣu)` 在守卫法向 `u` 上取方向税，而非全用 `λ_max`，可显著降低保守度（缓解可用性崩塌）。

**命题 2（非扩张合并保 soundness）**：设初始证书 `C_0` sound。若每次准入更新 `u_k` 都满足 `Safe(C_{k+1}) ⊆ Safe(C_k)`，则任意前缀证书 `C_n` 仍 sound；若用户贡献要求扩大安全集，则只能作为新证书 `C*` 走完整 SCV 认证，认证通过后单独入 KB 而不与 `C_0` 合并。

*证明*：由非扩张性得集合链 `Safe(C_n) ⊆ … ⊆ Safe(C_1) ⊆ Safe(C_0)`，soundness 对子集遗传（在 `Safe(C_0)` 内不发生违例，故在更小的 `Safe(C_n)` 内也不发生）。扩大型贡献不进入该链，其正确性由 SCV 独立证明。∎

**命题 3（有界偏好场不破坏硬安全）**：设硬安全包络 `H = {x : m_nominal(x) ≥ θ}`。偏好偏移 `δ` 满足 `|δ| ≤ δ_max`，且仅在 `m_nominal(x) − θ ≥ δ_max` 的区域施加。则在该区域 `m_nominal(x) − (θ + δ) ≥ 0`，即偏好场单独不产生硬违例。

*证明*：施加区满足 `m_nominal − θ ≥ δ_max ≥ δ`，移项得 `m_nominal ≥ θ + δ`。由于 `δ ≤ δ_max` 且 `δ ≥ −δ_max`，阈值为 `θ + δ`，上式成立，故不新增违例。关键区 `m_nominal − θ < δ_max` 强制 `δ = 0`，硬包络不变。∎

**命题 4（漂移前沿过期保证）**：设漂移增长满足 `B_t ≤ B_0 + κ·d_since_loop`（`κ` 为 IP-49 给出的上界）。若证书在 `B_t + κ·d_since_loop > B_max` 时立即过期，则不存在「真实漂移已超预算但证书仍有效」的时间窗。

*证明*：过期条件使用 `B_pred = B_t + κ·d_since_loop`，而真实漂移 `B_real ≤ B_t + κ·d_since_loop = B_pred`。当 `B_real > B_max` 时必有 `B_pred > B_max`，已触发过期，故不会在超预算后继续使用该证书。∎
*前提*：`κ` 必须是有效上界；若 `κ` 被低估则命题失效，这正是 E87/E93 需要实测的原因。

**命题 5（地点证书检索的 soundness 条件）**：若 (a) 地点识别召回正确（误匹配概率 `≤ δ_place`），(b) 漂移在 `d_frontier` 内，(c) 使用信念边际 `m(b)` 判定，则依赖地点证书 `c_p` 的单次判定的违例概率 `≤ δ_place + δ_drift`，其中 `δ_drift` 为命题 4 的残余风险。

*证明*：正确识别 + 漂移有效 + 信念判定 sound（命题 1）三者同时成立时判定 sound；失败事件是三者并集的子集，由 union bound 得上界。故需通过语义哈希重排、多假设与不确定性门控压低 `δ_place`，并通过硬过期压低 `δ_drift`。∎

### IP-57 SCL：信念边际、回环守卫、漂移过期、认证感知主动 SLAM
```
def belief_margin(b, cert, beta=0.99):
    # b = (x_hat, Sigma)
    d = len(b.x_hat)
    r = sqrt(chi2_quantile(d, beta) * max_eigenvalue(b.Sigma))
    m_nom = cert.m_nominal(b.x_hat)
    return m_nom - cert.L_m * r, r          # m(b), Δ_pose

def car_guard_belief(e, b, cert_obj):
    m_b, tax = belief_margin(b, cert_obj)
    ok = m_b >= cert_obj.theta[e]
    return ok, m_b, tax

def loop_closure_guard(event, belief, place_certs):
    if event.is_loop_closure and event.pose_jump > DELTA_JUMP:
        affected = place_certs.in_range(event.pose_jump)
        freeze(affected)                          # 冻结受影响守卫
        b_new = relocalize(event)
        recert = [recertify(c, b_new.Sigma) for c in affected]
        return 'ReCertifying', recert
    return 'Continue', None

def cert_expiry(place_cert, B_t, dist_since_loop, kappa, B_max):
    B_pred = B_t + kappa * dist_since_loop
    if B_pred > B_max or place_cert.age > place_cert.TTL:
        return 'EXPIRED'
    return 'VALID'

def active_cert_slam(belief, frontier, cert_map, budget_views):
    # 只为证书敏感区买信息：敏感度 × 信息增益
    best, best_u = None, -inf
    for v in frontier_views(frontier, budget_views):
        sens = cert_sensitivity(v, cert_map)      # 守卫面附近 / L_m 大 / 地图不确定
        ig   = expected_information_gain(v, belief)
        u    = sens * ig
        if u > best_u: best, best_u = v, u
    return best
```

## 7. 本轮最大风险

**一句话**：本轮把证书同时绑到「会漂移的地图」和「不可信的用户」上，最致命的新失效链是**被投毒的空间记忆**——一条由恶意或错误贡献产生、却通过了看似保守的合并、又被地点识别反复命中的陈旧证书，会在环境已变后仍被当作已验证经验复用并扩散；因此 E91（非扩张/防投毒）与 E93（漂移失效）必须作为红线实验，任一不达标即冻结用户共创通道并回退到纯专家证书。
