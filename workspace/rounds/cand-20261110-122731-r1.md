# 第 44 轮（新循环第 4 轮） · Whole-Body-Cert × ROS-Cert-Bus：把「全身控制」与「ROS」纳入可验证证书闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形边际覆盖被欺骗 + 多用户契约求交为空」，但它仍压着两个更底层的单点假设：**(H3) 证书停在任务空间，默认「身体一定能实现」**——真正被执行的是冗余浮基全身系统的关节力矩与接触力，任务空间动作可行不等于存在满足动力学、摩擦锥、CoP/ZMP、关节/力矩/自碰撞约束的全身控制；**(H4) 证书运行时被当作单进程共享内存**——真实系统由 ROS2/DDS 多节点、多时钟、多 QoS 组成，消息会丢、会乱序、会过期，节点会崩溃重启，执行器回调会交错。本轮灵感词「全身控制」「ROS」精确命中这两个假设：**全身控制**迫使证书从「动作上的标量」下沉为「可行控制集上的鲁棒证书」，并让冗余从麻烦变成安全边际杠杆；**ROS** 迫使我们把「证书运输」本身纳入证书，把端到端时延、QoS 降级、节点失效与 fencing 变成可审计的 soundness 条件。二者耦合处是本轮真正的新问题：**执行器真正需要的不是「算出来的证书」，而是「在正确时刻送达、且在全身约束下仍可执行的那一份证书」**。

## 0. 直觉与动机

**灵感 1（全身控制 → 证书必须下沉到「可行控制集」，WBC 是最后一位认证者）**：直觉上，规划器说「手往左 10cm」只是任务参考；身体能不能做，要看在浮基动力学、接触、摩擦锥、ZMP、关节/力矩/自碰撞约束下是否存在一条可行控制。传统做法是「规划—WBC 执行—失败再说」，这把可行性当实现细节。我们反过来：**WBC 首先是一个认证器**——它在鲁棒层级 QP 里同时求控制与证书，输出可行控制集 U_cert、全身边际 m_wb、活跃约束集与接触模式 σ。任务参考只有被某个 u∈U_cert 抬升时才可下发。这样「能做」被严格定义为「在不确定集内存在满足全部硬约束且保留停止余量的全身控制」。这直接承接 v20 的 `C_u = C_global ∩ Π_u`：人格契约只能在**任务参考层**收缩，绝不允许放松全身硬约束。

**灵感 2（ROS → 没送达的证书不是证书，传输层必须被认证）**：直觉上，v20 的 rely-guarantee 把并发当成进程内线程交错；但 ROS2 里证书是消息，会经历序列化、DDS 发现、网络/共享内存、executor 调度、QoS 降级、节点崩溃。一个在规划器里 sound 的证书，若晚到 5ms 或来自旧 epoch，就不再 sound。因此引入**传输感知租约**：把端到端时延 D_max、时钟速率偏差 ρ_max、TTL、epoch/fencing、模型与标定哈希全部写进证书；证书话题强制 RELIABLE + KEEP_LAST(1) + DEADLINE + LIVELINESS，QoS 降级或 deadline 违约即失败关闭。**一句工程原则：安全关键路径要么不走网络，要么把网络的最坏行为算进证书。**

**灵感 3（耦合 → 执行时刻证书 ATC：三张证书的交集 + 冗余边际预算）**：WBC 的冗余是双刃剑：nullspace 可用于增大安全边际或完成次级任务，是「免费」的可用性杠杆；但它会改变未来状态，可能把今天的余量透支成明天的越界（margin laundering）。同时，接触是离散模式，异步接触检测又经 ROS2 延迟，切换必须对接触假设集鲁棒。于是把三者收束到**执行时刻证书** ATC = 全身可行集 ∩ 有效租约 ∩ 接触模式证书，且只在执行器节点做最终判定；冗余动作受 CBF + 停止余量预算约束，接触切换只在前后模式都持证时允许。**收缩（少动/保持）永远安全，冗余扩张与模式切换必须持证。**

**耦合升级**：WBCC（全身证书控制器）把任务参考编译成鲁棒 HQP + CBF 证书与接触切换守卫；CTL（证书传输层 / ROS2 证书总线）把租约、QoS、fencing、执行器隔离做成运行时契约；WRV（全身-ROS 验证器）在仿真与真机上注入全身约束故障、接触序列、QoS 降级、节点崩溃与时钟偏差，把反例回灌 CKB/SCV。四层架构由 v8 的「人格 + 并发证书层」升级为 v9 的「人格 + 并发 + 全身可行集 + 传输证书层」。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（全身层级证书与鲁棒可行控制集）**：设全身状态 x=(q,ν)（浮基位姿 + 关节），控制 u=(τ, λ_c, σ)，其中 τ 为关节力矩、λ_c 为接触力、σ 为接触调度。硬约束 H(x,u)≤0 至少包含：浮基动力学 M(q)ν̇+C(q,ν)ν+g(q)=S^Tτ+Σ_c J_c^Tλ_c；摩擦锥 λ_c∈FC(μ_c)；单边接触与支撑多边形 CoP/ZMP∈P(σ)；关节位置/速度/力矩界 q∈Q, ν∈V, τ∈T；自碰撞距离 d_ij(q)≥d_min；接触互补。给定不确定集 Δ（状态估计误差、负载/质心偏移、摩擦系数），**鲁棒可行控制集** U_cert(x,Δ,σ)={u : ∀δ∈Δ, ∃ν̇,λ_c 使 H(x+δ,u)≤−ε_rob，且层级任务 T_1≻…≻T_n 的每一级都达到其认证优先级余量}。全身边际 m_wb(x)=min_j slack_j/scale_j（活跃约束的最小归一化余量），证书 C_wb=(U_cert,m_wb,活跃集,σ,model_hash,τ_w)。**可靠性命题**：若 u_t∈U_cert 且 Δ 覆盖真实误差，则 x_{t+1} 仍在硬约束安全集内；任务参考 r 可下发当且仅当 ∃u∈U_cert 抬升 r。**推论**：任务空间可行但全身不可行的参考必须被拒绝或协商，不能交给执行器「尽力而为」。

**定义 45（认证空域杠杆与边际预算）**：取高层级任务的零空间 N(x)={δu : J_1 δ=0}（可推广到 HQP 已解层级的零空间）。对每个安全约束 j 定义 CBF h_j(x)≥0，其离散鲁棒条件为 h_j(x_{t+1}) ≥ (1−α_j)h_j(x_t)。δu∈N 可执行当且仅当 ∀j 满足该条件且保留**停止余量** h_j(x_{t+1})≥h_j^stop。**边际台账**：c_j(t)=Σ_{k≤t} max(0, h_j(x_k)−h_j(x_{k+1}))，要求 c_j(t)≤B_j 且 B_j<h_j^stop。**命题（不洗白余量）**：若每一步都满足鲁棒 CBF 与停止余量，则 h_j 前向不变；若再加预算 c_j≤B_j，则冗余次级任务无法通过「先透支、后承诺恢复」把系统推到停止余量之外。**推论**：空域杠杆只能花「盈余」，不能花「保命钱」。

**定义 46（接触模式切换证书）**：接触调度 σ∈Σ 是离散模式；接触检测经感知/传输后有不确定集 K̂（由有界误差或共形集合给出）。切换守卫 G(σ→σ') 成立当且仅当：(i) **切换就绪**——当前模式在 T_tr 内可到达一个对所有 k∈K̂ 都持证的切换就绪集 S_tr(σ')；(ii) **后继鲁棒可行**——∀k∈K̂，U_cert(x,k,σ')≠∅ 且含停止控制；(iii) **插值无碰**——切换期间的足端/接触力插值满足自碰撞与支撑约束；(iv) **腾空预算**——若 σ' 含腾空相，则时长≤T_air_max 且落点证书已签发。**定理（切换安全）**：若 G 成立且前后模式各自满足定义 44 的鲁棒不变条件，则在守卫窗口内任意时刻切换都保持鲁棒可行性；若 K̂ 中不存在公共可行的后继模式，则禁止切换，保持当前模式的安全保持或急停。**推论**：异步接触检测的延迟不是「噪声」，而是 K̂ 与 D_max 的一部分。

**定义 47（传输感知租约与端到端新鲜度）**：租约 ℓ=(m_wb, TTL, λ, D_max, ρ_max, κ, epoch, model_hash, calib_hash)。TTL 为发送端签发的有效期；D_max 为「测量→WBC 求解→序列化→DDS/共享内存→executor→执行器」的最坏剩余时延界；ρ_max 为发送/接收时钟速率偏差上界。接收端本地经过 Δt 后，**有效边际** m_eff=m_wb−λ·(Δt/(1−ρ_max)+D_max)，**有效剩余寿命** T_eff=TTL/(1+ρ_max)−Δt−D_max；仅当 m_eff≥θ、T_eff≥0、deadline/liveliness 满足、哈希匹配且 epoch 为当前值时才可用。取 λ=L_m·v_max（L_m 为全身边际对状态的 Lipschitz 常数）。**定理（端到端新鲜度 sound）**：若真实位移 ||x(t_a)−x(τ_w)||≤v_max(t_a−τ_w)、t_a−τ_w≤Δt/(1−ρ_max)+D_max，且 m_wb 在 τ_w 测量，则 m(x(t_a))≥m_eff，绝不误用陈旧边际。**注**：绝对时间戳只用于 epoch 排序，不用于新鲜度；新鲜度完全由本地单调时钟 + 时延界 + 速率偏差界给出，避免依赖全局时钟同步。

**定义 48（ROS2 证书消息契约、分布式依赖-保证与 fencing）**：证书消息 M=(cert_id, writer_id, epoch, model_hash, calib_hash, payload, TTL, qos_req, sig)。**消息契约**：证书/租约话题必须 RELIABLE、KEEP_LAST(1)、DEADLINE δ、LIVELINESS、VOLATILE；BEST_EFFORT、QoS 降级、deadline 违约、哈希不匹配均视为无效。**分布式 RG**：节点 N_i 声明写集 W_i（发布的临界变量）与读集 R_i；要求 (1) 非干扰：非安全节点的 W_i∩critical(I)=∅；(2) 临界读通信封闭：每个临界读在单一 writer 的 epoch 快照上完成，读后校验 epoch 未变（seqlock/版本号）；(3) 失效检测：节点崩溃/重启在 T_fail 内被发现，其租约全部作废。**fencing 定理**：若每个执行器组只接受来自最高 epoch 且签名有效的命令，epoch 在重启后持久单调，则陈旧 writer 与分裂脑 writer 均不能致动。**失败关闭**：证书缺失、QoS 不达标、epoch 回退、哈希不符 ⇒ 进入安全保持，而非沿用最后一条命令。

**定义 49（执行时刻证书 ATC 与组合定理）**：执行器在时刻 t_a 同时持有全身证书 C_wb、租约 ℓ、接触证书，定义
C_act(t_a)=U_cert(x̂,Σ_w,σ) ∩ LeaseSet(ℓ,t_a) ∩ ContactSet(σ,t_a)，
其中 LeaseSet 为满足定义 47 的 m_eff≥θ 的控制集合，ContactSet 为当前接触假设下仍持证的模式集合。执行器仅接受 u∈C_act；否则进入安全保持 u_hold（关节 PD 趋向认证姿态并维持当前接触）。**组合定理（端到端全身 soundness）**：若 (i) 定义 44 的 Δ 覆盖 [τ_w,t_a] 内真实误差，(ii) 定义 47 的 D_max/ρ_max 覆盖传输与时钟，(iii) 定义 46 的 K̂ 覆盖接触检测延迟，(iv) 零阶保持时长 T_hold≤T_eff 且包含停止余量，则对任意 t∈[t_a,t_a+T_hold]，真实全身状态保持在硬约束安全集内；反之任一证书失效都触发安全保持，绝不继续执行。**推论**：ATC 把 soundness 的责任放在「最后一个能看见执行器的节点」，因此规划器、WBC、传输层的任何单点故障都不能静默越界。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 WHOLE-BODY-CERT-CONTROLLER（全身证书控制器 WBCC）
1. **鲁棒层级 QP + 全身 CBF**：把任务栈（平衡、末端、姿态、次级任务）与硬约束（动力学、摩擦锥、CoP/ZMP、关节/力矩、自碰撞、接触互补）统一进带不确定集 Δ 的层级 QP；每步同时输出 u*、U_cert、m_wb、活跃集与优先级证书。
2. **空域杠杆与边际台账**：nullspace 优先用于抬高安全边际，其次服务次级任务；每方向必须通过所有 CBF 与停止余量；维护 c_j(t)≤B_j，禁止跨时透支。
3. **接触模式监督**：维护接触假设集 K̂、切换就绪集与落点证书；切换守卫失败时保持当前模式或安全保持，绝不「赌下一脚」。
4. **证书接口**：向 CTL 输出 (m_wb, 活跃集, σ, model_hash, τ_w) 与安全保持姿态；证书不是日志，而是执行许可。

### 2.2 IP-61 CERT-TRANSPORT-LAYER / ROS2 CERT-BUS（证书传输层 CTL）
1. **传输感知租约**：签发/校验 (TTL,D_max,ρ_max, λ, epoch, 哈希)；执行器用本地单调时钟做 ATC 终检，过期/超时即失败关闭。
2. **QoS 契约与生命周期**：证书话题强制 RELIABLE + KEEP_LAST(1) + DEADLINE + LIVELINESS + VOLATILE；订阅端显式校验 QoS 不低于契约；节点生命周期/崩溃触发租约作废。
3. **消息模式与 fencing**：cert_id/writer_id/epoch/model_hash/calib_hash/签名；每个执行器组单 writer，epoch 持久单调；陈旧/分裂脑命令拒收。
4. **执行器隔离与实时路径**：安全监控、WBC、证书处理分属独立 executor / 互斥回调组；临界快照用 seqlock；认证路径优先 intra-process/零拷贝共享内存，网络只承载非安全关键回传。

### 2.3 IP-62 WHOLE-BODY-ROS-VALIDATOR（全身-ROS 验证器 WRV）
1. **全身约束故障注入**：关节限位/力矩饱和、摩擦锥退化、CoP 越界、自碰撞、负载/质心突变、接触丢失。
2. **中间件故障注入**：QoS 降级、消息丢弃/乱序/延迟、节点崩溃/重启、DDS 发现延迟、executor 饥饿、时钟速率偏差。
3. **ATC 审计**：从证书签发到执行器接受的端到端链路，检出陈旧使用、epoch 回退、QoS 降级漏检、撕裂/丢失更新与静默续用。
4. **联合压力测试**：接触切换 × WBC 过载 × 传输抖动 × 人格/任务切换，输出 soundness 与可用性曲线。

## 3. 四层架构 v9

```
传输面: ROS2 CERT BUS (RELIABLE/KEEP_LAST1/DEADLINE/LIVELINESS/VOLATILE)
        + epoch/fencing + model/calib hash + 端到端时延审计；安全路径优先 intra-process/零拷贝
L0: RT 驱动(关节编码器/IMU/力觉/接触开关) —— 本地单调时钟，不依赖网络
L1: TRI-FUSE(INT8) + LIO + 接触/状态估计 → x, Σ, K̂(接触假设), 时间戳
L2: CTC + VLM + IP-35 仲裁 → 任务参考；IP-57 PCE 只参数化参考(速度/步长/风格)
L2.5: IP-60 WBCC(鲁棒层级 QP + 全身 CBF) → U_cert, m_wb, σ, 活跃集
      + 空域边际台账(停止余量) + 接触切换守卫
L3: IP-51 CAR(任务参考 × 全身可行集 × 传输租约) ← IP-58 CCR(传输感知租约 + 分布式 RG + 混合关键级)
    → IP-39 规划(CBF margin=min(查表, 租约衰减, 全身余量))
    → IP-53 CMC(关节/力矩/摩擦锥/CoP/自碰撞监控, 最高关键级, 独立 executor)
    → IP-45 证书总线 → IP-61 CTL 终检(ATC) → 执行器

### IP-60 WBCC：全身认证、空域预算与接触切换
```
def wbc_certify(x, tasks, sigma, Sigma_unc, params):
    # 1) 构造鲁棒层级 QP：硬约束 + 每级任务 + CBF + 停止余量
    qp = build_robust_hqp(x, tasks, sigma, Sigma_unc,
                          friction=True, cop=True, joint=True,
                          torque=True, self_collision=True, contact=True)
    sol = solve_hqp(qp, warm_start=True)
    if not sol.feasible:
        return Cert.INFEASIBLE            # 触发协商/接触切换/安全保持
    # 2) 全身证书：活跃约束的最小归一化余量
    slack = [constraint_slack(c, sol) for c in qp.active_constraints]
    m_wb  = min(slack) / scale(qp.active_constraints)
    U     = constraint_polytope(qp, sol, robust_eps=params.eps_rob)
    # 3) 空域：先抬 margin，再做次级任务，受停止余量约束
    u = allocate_nullspace(sol.u, qp.nullspace, qp.cbf, qp.budget)
    return Cert(U_cert=U, m_wb=m_wb, active=qp.active_set,
                sigma=sigma, model_hash=params.model_hash, tau_w=now())

def allocate_nullspace(u0, N, cbf, budget):
    # 每个候选 δu∈N 必须满足所有 CBF 与停止余量；预算不足则拒绝
    for delta in N.basis:
        if all(cbf.h_next(u0 + delta) >= cbf.alpha * cbf.h_now
               and cbf.h_next(u0 + delta) >= cbf.h_stop
               and budget.can_spend(delta) for cbf in cbf):
            u0 = u0 + project(delta, N)
    return u0                              # 只花盈余，不花保命钱

def contact_transition_guard(sigma, sigma_next, x, K_hat, cert):
    if not reachable_in(cert, S_tr(sigma_next), T_tr): return False
    if not all(robust_feasible(x, k, sigma_next) and has_stop(x, k)
               for k in K_hat):          return False           # 无公共可行后继
    if not collision_free_interpolation(x, sigma, sigma_next):  return False
    if has_aerial_phase(sigma_next) and not landing_cert(x, sigma_next): return False
    return True
```

### IP-61 CTL：租约签发、QoS 契约、fencing 与 ATC 终检

def issue_lease(cert, kappa, now, model_hash, calib_hash, epoch):
    lam  = L_m * v_max_bound(cert)                # 定义 47
    TTL  = min(lease_budget(cert), 1.0 / control_rate + D_max)
    return Lease(m=cert.m_wb, TTL=TTL, lam=lam,
                 D_max=measured_Dmax_p9999 + safety_margin,
                 rho_max=clock_rate_skew_bound,
                 kappa=kappa, epoch=epoch,
                 model_hash=model_hash, calib_hash=calib_hash)

def validate_lease(lease, theta, now_local, current_epoch):
    dt    = now_local - lease.t_recv
    m_eff = lease.m - lease.lam * (dt / (1 - lease.rho_max) + lease.D_max)
    T_eff = lease.TTL / (1 + lease.rho_max) - dt - lease.D_max
    return (m_eff >= theta and T_eff >= 0
            and lease.epoch == current_epoch
            and lease.qos_ok and lease.hash_ok)

def ros2_cert_publish(pub, msg, qos):
    # 证书话题禁用 BEST_EFFORT；QoS 降级/DEADLINE 违约 => 失败关闭
    assert qos.reliability == RELIABLE and qos.depth == 1
    assert qos.deadline is not None and qos.liveliness is not None
    pub.publish(sign(msg, writer_id, epoch))

def actuation_time_certificate(cert, lease, contact, u, now_local):
    # 最后一个看见执行器的节点做三证交集终检
    if not (u in cert.U_cert
            and validate_lease(lease, theta, now_local, cert.epoch)
            and contact.holds(contact.sigma, contact.K_hat)):
        return safe_hold(cert.hold_pose, keep_contact=True)
    return u

def safe_hold(hold_pose, keep_contact):
    # 关节 PD 趋向认证姿态并维持当前接触；不放松任何阈值
    return joint_pd(hold_pose.q, hold_pose.nu, keep_contact)
```

| model/calib 哈希不符（错误 URDF/标定）导致全身证书张冠李戴 | 中-高 | 证书绑定 model_hash/calib_hash；部署前全量回归；订阅端强制校验 |
| 认证路径依赖网络，单点延迟放大为全身越界 | 中 | intra-process/零拷贝优先；网络只承载非安全回传；默认单 RT 节点兜底 |

## 6. 本轮最大风险

**一句话**：全身鲁棒可行集与 ROS2 端到端时延界都是模型包络，一旦任一被低估，「冗余空域优化 + 传输抖动 + 接触切换」会在执行器处同时叠加成静默越界——因此 E95/E98/E99 必须设为红线实验，并默认回退到「单 RT 节点 + 关节空间安全保持 + 网络不进入安全回路」这条永不依赖中间件的底线。
