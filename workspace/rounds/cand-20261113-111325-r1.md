# 第 67 轮（承接第 66 轮「RAS 情绪驱动闭环」IP-224~233；灵感循环第 1 轮；本轮灵感：「成功率」×「异常检测」）

> 第 66 轮 RAS 把「故障响应闭环」升级为「意图感知闭环」，用面部表情与风险缩放让闭环首次感知「谁在控制、该收多紧」。但 RAS 与 VISTA 共享一个未被言明的前提：**它们只对「安全」负责，不对「成功」负责**。安全证书保证「不会违规」，却从不保证「任务能完成」。成功率在现有体系里只是实验报告末尾的一行事后统计；异常检测也只是被拆碎成几何残差、模型残差、情绪误判等互不相通的子模块。于是系统可以做到「每一步都安全、整段任务却频繁失败」——而失败往往不是因为它不够保守，恰恰是因为它**太保守**：认证前缀被压得太短，任务推进不足，反复重规划、超时、最终放弃。
>
> 本轮的核心命题是：
>
> **把「成功率」从延迟的事后指标升级为「在线、任意时有效、可证书的约束」；把「异常检测」从报警子模块升级为「连接微观异常证据与宏观成功率的统计桥梁」。用共形 p 值 → e 值 → 检验鞅构造成功率下界 LCB(SR)，用它在「成功—安全帕累托前沿」上选择认证前缀 k†，用异常引导的稀有事件分裂在少量回合内估计失败尾概率。**
>
> 由此得到 **CREST：Certified Rare-event Estimation for Success-rate Tracking（可证书稀有事件成功率追踪）**，它由 SCAN × eSR × RES × SPF × SBG × AAP × DRR × SRC 八件套构成。CREST 问的不再是「这一步安不安全」，而是「**在保证安全的前提下，我还能诚实地承诺多高的成功率；以及，我的『成功』统计有没有被自己污染**」。

## 0. 直觉与动机

**灵感 1（成功率是被忽视的目标函数：安全 ≠ 成功）**
直觉：VISTA 取 `k* = max{k : margin_k ≥ 0}`，RAS 再乘一个风险缩放。这是一个**纯安全**准则，隐含假设「越保守越不会失败」。但在长程任务里，成功率关于前缀长度 `k` 并不是单调的：
- `k` 太小 → 每次只敢走一小步 → 推进不足、频繁重规划、规划开销与累计风险反而上升 → 超时/停滞失败；
- `k` 太大 → 单块暴露面变大 → 违规概率上升 → 安全失败。
所以 `LCB(SR | k)` 在 `k` 上通常是**单峰的**，最优点 `k†` 落在**内部**，而且往往严格小于安全边界 `k*`。**最大安全前缀不是最大成功率前缀**——这是本轮最锋利、也最容易被忽略的一点。CREST 的第一个动作，就是把认证前缀的选择从「安全边界」搬到「成功—安全帕累托前沿」。

**灵感 2（异常检测 = 逐样本的「失败前兆」）**
直觉：异常分数是**即时的、逐样本的、无标签的**；成功率是**延迟的、回合级的、需要标签的**。二者恰好互补。把「任务按预期推进」当作零假设 `H_0`，则异常分数就是一个天然的检验统计量。共形预测（conformal prediction）给出**分布无关**的 p 值，不依赖残差服从高斯；再把 p 值映射成 e 值，乘积得到检验鞅（test martingale），Ville 不等式保证**在任意数据依赖的停止时刻**都有效。于是我们不必等到回合结束，在线就能说：「以 1−α 的置信度，本任务成功率至少是 LCB 这么大」。这是把「异常检测」真正接入「成功率证书」的关键一步。

**灵感 3（失败是稀有事件：异常分数是稀有事件分裂的反应坐标）**
直觉：成功率通常很高（90%+），失败是稀有事件。朴素蒙特卡洛要数 `O(1/P_f)` 个回合才能看到足够多的失败，这在真实机器人上不可承受。异常分数恰好提供了稀有事件分裂（subset simulation / splitting）所需的**反应坐标（reaction coordinate）**：沿异常分数从常态到故障逐层采样，把尾部失败概率分解成若干「条件概率之积」，每层都保持足够多的样本。这样，异常检测从「报警器」升级为「稀有事件估计器的提议分布」，把「估成功率」从「数回合」变成「数层分裂」。

**灵感 4（成功率作为控制变量：SBG 成功率预算控制器）**
直觉：既然有了在线 LCB(SR)，就可以把它与目标 `τ_succ` 的差当作控制误差：LCB 有余量 → 允许前进更长（提高任务推进、提升成功率）；LCB 逼近阈值 → 收缩前缀、抬高 λ_risk 下限、增加保守。这是 VISTA/RAS 之后第一次把「成功率」直接接进控制律，而不是留作离线评价。控制动作集 `{extend, hold, shrink, probe, abort}` 中，只有 `shrink` 是无条件安全的，`extend` 必须由证书余量背书——**单向棘轮，fail-closed**。

**灵感 5（主动异常探针：对「成功率边界」做主动学习）**
直觉：当 LCB 恰好落在阈值附近，继续执行的信息量很低，而「成功率边界在哪里」的不确定性很高。此时最有价值的动作是主动制造**廉价、低风险、信息量大**的分布外样本（小幅扰动、传感器重查询、安全的任务变体），用 acquisition 函数最大化「单位代价的 LCB 方差下降」。这把 RAS 的「情绪探针」推广成「成功率边界探针」，本质是对成功率边界做主动学习。

**灵感 6（最大陷阱：Goodhart 与生存者偏差）**
直觉：一旦把成功率当优化目标，系统就可能学会**刷分**：放弃难任务、把难回合标注成「异常并排除」、或把超时不计入分母。这时证书是诚实的，但证书的**样本选择**被污染了——认证的「成功率」上升，而真实任务成功率下降。这比第 66 轮的「情绪欺骗」更隐蔽，因为异常检测本身恰好提供了「合法排除样本」的工具。因此 CREST 必须把 abandon 计为失败、对分母做审计，并让「排除样本」这一动作本身触发 fail-closed。

## 1. 形式化定义（增量：定义 245–258）

- **定义 245（CREST 总览）**：`CREST = (SCAN, eSR, RES, SPF, SBG, AAP, DRR, SRC)`，定位为 VISTA/RAS 之上的「成功率证书层」。不变式：(i) SCAN/eSR 的每步更新为闭式，实时流零学习写操作；(ii) RES/AAP/DRR 只在语义流进行；(iii) 所有回退 fail-closed，只允许收缩前缀、抬高 λ_risk、增大 α_eff；(iv) 成功率的**分母**（回合集合）必须被审计，任何「排除回合」等价于记一次失败。
- **定义 246（回合成功与成功率）**：长度 `N` 的回合，成功事件
  `S = ⋀_{t=1}^{N} (safe_t ∧ progress_t ∧ ¬abandon_t)`，
  其中 `abandon_t` 为主动放弃或超时。成功率 `SR = P(S = 1)`。**约定：abandon 与超时一律计为失败，且不进入任何「已排除」集合**。
- **定义 247（序贯共形异常分数）**：从残差/几何/情绪等模块拼接特征 `φ_t`，非一致性分数 `s_t = A(φ_t)`。以标定集 `{s_i}_{i≤n}` 计算共形 p 值
  `p_t = (1 + #{i : s_i ≥ s_t}) / (n + 1)`。
  在可交换性下 `p_t` 随机占优于 `U(0,1)`，即 `P(p_t ≤ α) ≤ α`。异常判据为 `p_t < α`。`SCAN` 额外维护滑动分数窗与标定版本号。
- **定义 248（异常 e 值与检验鞅）**：取 `κ ∈ (0,1)`，定义每步 e 值
  `e_t = κ · p_t^{κ−1}`，满足零假设下 `E_0[e_t] ≤ 1`。
  累积 `M_t = ∏_{i=1}^{t} e_i`，则 `M_t` 是非负上鞅且 `E_0[M_0] = 1`。Ville 不等式给出
  `P_0(∃t : M_t ≥ 1/α) ≤ α`，即**任意停止时刻**都有效。
- **定义 249（任意时有效成功率下界 LCB）**：对候选成功率 `s ∈ [0,1]`，构造伯努利 e-过程
  `M_t(s) = ∏_{i=1}^{t} [(1 − s) + s · e_i]`。
  定义 `LCB_t(SR) = sup{ s : M_t(s) < 1/α }`。由定义 248 的上鞅性与 Ville 不等式，
  `P(∀t : SR ≥ LCB_t(SR)) ≥ 1 − α`。`LCB_t` 随证据累积单调升高，但对「无证据的乐观」零容忍。
- **定义 250（异常引导的稀有事件分裂 RES）**：以异常分数 `r(φ) = s(φ)` 为反应坐标，取层水平 `ℓ_0 < ℓ_1 < … < ℓ_m`，使每层条件失败概率约为 `p_0`（如 0.1）。失败概率估计
  `P̂_f = P̂(s > ℓ_0) · ∏_{j=1}^{m} P̂(s > ℓ_j | s > ℓ_{j−1})`，
  成功率 `ŜR = 1 − P̂_f`。`ℓ_j` 由上一层样本的 `(1−p_0)` 分位数自适应选取。
- **定义 251（成功—安全联合可行域与帕累托认证前缀）**：安全可行域 `K_safe` 由 VISTA/RAS 证书给出（`k ≤ k*_VISTA ∧ k ≤ k*_RAS`）。预测条件成功率下界 `L(k) = LCB_t(SR | execute prefix k then replan)`，其单步风险由 SCAN + RES 的 hazard 估计给出。**帕累托认证前缀**
  `k†_t = argmax_{k ∈ K_safe} L(k)`，
  并列时取安全裕度更大者。关键性质：`k†` 可以严格小于 `k*`，即为了成功率可以主动**不**用满安全预算。
- **定义 252（SBG 成功率预算控制器）**：控制误差 `e_t = LCB_t(SR) − τ_succ`。策略
  `a_t = π(e_t, ḣ_t)`，`a_t ∈ {extend, hold, shrink, probe, abort}`，满足滞回（避免抖动）与单向安全：`shrink` 无条件允许；`extend` 仅在 `e_t ≥ δ_extend` 且证书仍 Valid 时允许；`abort` 计为失败并冻结分母。
- **定义 253（AAP 主动异常探针）**：探针菜单 `𝒜`（小幅动作扰动、传感器重查询、任务变体、低风险对抗采样）。采集函数
  `a* = argmax_{a∈𝒜} E[ΔVar(LCB_t(SR)) | a] / cost(a)`，
  仅当 `a*` 的期望 LCB 增益 `> δ_probe` 且探针自身风险 `≤ ε_probe` 时执行。
- **定义 254（DRR 漂移感知重标定）**：漂移统计量 `D_t = MMD(Ŝ_recent, Ŝ_calib)`（或用分数分布 KL）。若 `D_t > τ_drift`，则：(a) 将标定失效标记置位；(b) 用加权共形（权重 `w_i ∝ exp(−λ d_i)`）重标定；(c) 提高有效显著性 `α_eff = α · (1 − ρ_drift)`；(d) 收缩 `k†`。DRR 保证漂移下 LCB 只会更保守，不会更乐观。
- **定义 255（WAS 非对称加权评分）**：漏检失败（false negative）的代价远高于误报。定义加权非一致性分数 `s_t^w = w_fn · s_t · 1[failure-like]`，或直接对 p 值做加权共形；目标是让「乐观的 LCB」在代价意义上几乎不可能出现。`w_fn / w_fp` 由安全预算标定。
- **定义 256（SRC 成功率证书）**：
  `J_CREST = (J_RAS, LCB_SR, τ_succ, n_eff, drift_stat, cal_version, P̂_f, res_levels, abandonment_audit, crest_ver)`。
  `Valid(J_CREST) ⇔ Valid(J_RAS) ∧ LCB_SR ≥ τ_succ ∧ drift_stat ≤ τ_drift ∧ abandonment_audit = pass ∧ n_eff ≥ n_min`。
- **定义 257（失效安全回退序）**：`Valid(J_CREST) = False` 时，按优先级执行：(a) 将 `k† ← max(k† − Δ_shrink, k_safe_min)`、`λ_risk ← max(λ_risk, 0.8)`；(b) 增大 `α_eff` 重算更保守的 LCB；(c) 声明 `success_unobservable` 并切到保守基线；禁止在任何分支里延长 `k`、降低 `λ_risk` 或把当前回合计入「已排除」。
- **定义 258（成功率估计的样本地板）**：给定目标精度 `ε`、置信度 `α` 与 RES 的方差缩减效率 `Eff`，认证所需有效回合并数
  `n_min ≈ C · log(1/α) / (ε² · Eff)`，
  其中 `Eff = Var_MC / Var_RES`。此式给出「成功率证书能多快被签发」的物理地板：异常检测越好，`Eff` 越大，证书签发越快。

# IP-234 SCAN：序贯共形异常检测（实时流，闭式更新）
class SequentialConformalAnomaly:
    def __init__(self, calib_scores, alpha=0.05):
        self.calib = sorted(calib_scores)
        self.alpha = alpha
        self.version = 0

    def pvalue(self, s_t):
        n = len(self.calib)
        # 共形 p 值：标定集里 ≥ s_t 的比例
        ge = sum(1 for s in self.calib if s >= s_t)
        return (1 + ge) / (n + 1)

    def step(self, phi_t):
        s = nonconformity(phi_t)              # 定义 247
        p = self.pvalue(s)
        return {"score": s, "p": p, "anomaly": p < self.alpha,
                "version": self.version}


# IP-235 eSR：e 值成功率下界（实时流，零学习写）
class EValueSuccessBound:
    def __init__(self, alpha=0.05, kappa=0.5):
        self.alpha, self.kappa = alpha, kappa
        self.logM = 0.0
        self.n = 0

    def update(self, p):
        # e_t = kappa * p^(kappa-1)，取对数避免下溢
        self.logM += math.log(self.kappa) + (self.kappa - 1.0) * math.log(max(p, 1e-12))
        self.n += 1

    def _log_martingale(self, s):
        # 伯努利 e-过程：log[(1-s) + s*e_i] 的累积
        # 实现时维护增量近似或分段近似，保证 O(1) 更新
        return self._segment_log_martingale(s)

    def lcb(self):
        lo, hi = 0.0, 1.0
        for _ in range(40):                   # 二分反演，40 次足够 1e-12
            mid = 0.5 * (lo + hi)
            if self._log_martingale(mid) < math.log(1.0 / self.alpha):
                lo = mid
            else:
                hi = mid
        return lo                             # 定义 249


# IP-236 RES：异常引导的稀有事件分裂（语义流）
def residual_failure_prob(scan, phi_pool, p0=0.1, max_levels=8, min_pool=20):
    scores = np.array([scan.step(phi)["score"] for phi in phi_pool])
    levels, cond, pool = [], [], scores
    for _ in range(max_levels):
        if len(pool) < min_pool:
            break
        level = np.quantile(pool, 1.0 - p0)   # 自适应层水平，定义 250
        p_j = float(np.mean(pool > level))
        levels.append(level)
        cond.append(max(p_j, 1e-9))
        pool = pool[pool > level]
    p_f = float(np.prod(cond)) if cond else float(np.mean(scores > levels[-1]))
    return {"P_f": p_f, "levels": levels, "cond": cond,
            "eff": variance_reduction(scores, cond)}   # 定义 250/258


# IP-237 + IP-252：帕累托认证前缀 + 成功率预算控制器
class SuccessBudgetGovernor:
    def __init__(self, tau_succ=0.95, delta_extend=0.02, delta_probe=0.01):
        self.tau_succ, self.delta_extend = tau_succ, delta_extend
        self.delta_probe = delta_probe

    def choose(self, k_safe, k_prev, lcb, hazard_fn):
        # 在安全可行域内找 LCB(SR | k) 的最大点
        best_k, best_l = k_safe, -1.0
        for k in range(1, k_safe + 1):
            l = predict_success_lcb(k, lcb, hazard_fn)   # 定义 251
            if l > best_l:
                best_k, best_l = k, l
        err = best_l - self.tau_succ
        if err >= self.delta_extend:
            action = "extend"          # 有余量，允许更长
        elif err >= -self.delta_probe:
            action = "hold"
        elif err >= -self.delta_extend:
            action = "probe"           # 边界附近，主动探针
        else:
            action = "shrink"          # 只收紧
        return best_k, action, {"lcb": best_l, "err": err}


# IP-243：CREST 与 VISTA/RAS 闭环耦合
def CREST_round(M, obs, tau_succ=0.95):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    M.lsf.update_geometry(P_cloud)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))
    y_vis = M.f_vis(img, depth, flow)

    # 1) 原有 RAS/VISTA 前向
    face_gate = M.er.gateway.recognize(img)
    A = M.vista.ach.propose(x_prime, H=M.vista.H)
    rho = M.vista.fir.signature(M.vista.stage.split(M.vista.residual_log))
    joint_post, _ = M.efs.synthesize(rho, face_gate)

    # 2) SCAN：逐样本异常证据
    phi_t = build_phi(rho, face_gate, A, M.residual_log)
    scan_out = M.scan.step(phi_t)

    # 3) eSR：任意时有效成功率下界
    M.esr.update(scan_out["p"])
    lcb = M.esr.lcb()

    # 4) RES：稀有事件尾概率（语义流，低频触发）
    if M.should_estimate_failure(scan_out):
        res = residual_failure_prob(M.scan, M.phi_replay_pool)
        M.p_f_hat = res["P_f"]

    # 5) DRR：漂移检查，失效则更保守
    if M.drr.update(scan_out["score"]):
        M.scan.reweight_calibration(M.drr.weights)
        lcb = M.esr.lcb_conservative(alpha_eff=M.drr.alpha_eff)

    # 6) 安全前缀
    k_ras = M.csc_ras.certified_prefix_ras(A, joint_post, M.m_ras, M.alpha_chunk)

    # 7) SPF + SBG：帕累托前缀与成功率预算
    k_dag, action, info = M.sbg.choose(k_ras, M.last_k, lcb, M.res.hazard_fn)

    # 8) AAP：边界附近主动探针
    if action == "probe":
        a_star = M.aap.best_probe(lcb, M.tau_succ)
        if a_star is not None and M.aap.cheap_and_safe(a_star):
            M.execute_probe(a_star)
            M.esr.update(M.scan.step(build_phi_after_probe(M)).p)

    # 9) 控制指令与证书
    lam = M.efs.risk_scale(joint_post)
    tau_cmd = M.vista.pi_sigma.prefix_dispatch(A[:k_dag]) * lam
    J = build_src(J_ras=M.vista.J, lcb=lcb, tau_succ=tau_succ,
                  drift=M.drr.stat, p_f=M.p_f_hat,
                  audit=M.audit_abandonment(), version=M.crest_ver)
    if not valid_src(J):                       # 定义 256/257
        k_dag, lam = M.sbg.fail_closed(k_dag, lam)
        tau_cmd = M.vista.pi_sigma.prefix_dispatch(A[:k_dag]) * lam

    M.last_k = k_dag
    return k_dag, lcb, action, J

## 3. 推导

**引理 11（e 值的鞅有效性与 Ville 界）** 若 `e_t ≥ 0` 且 `E_0[e_t] ≤ 1`，则 `M_t = ∏_{i≤t} e_i` 为非负上鞅，`E_0[M_0] = 1`，且对任意停止时刻 `τ`，`P_0(M_τ ≥ 1/α) ≤ α`。
*证明*：条件期望 `E[M_t | ℱ_{t−1}] = M_{t−1} E[e_t] ≤ M_{t−1}`；由 Ville 不等式直接得到。关键点：该界对**数据依赖的停止**成立，因此允许控制器在任意时刻用证据决定是否继续。

**引理 12（共形 p 值 + 可选停止的复合有效性）** 在可交换性下，定义 247 的 `p_t` 随机占优 `U(0,1)`，故定义 248 的 `e_t` 满足 `E_0[e_t] ≤ 1`；将其代入引理 11，LCB 对任意停止时刻有效。若分布发生协变量漂移，DRR 的加权共形把有效样本重加权到目标分布，代价是有效样本量 `n_eff = (∑w)²/∑w²` 下降；由定义 258，LCB 的收敛速度按 `n_eff` 缩放。
*证明思路*：加权共形的覆盖率界 + 有效样本量公式；`n_eff` 的下降通过 `α_eff` 膨胀吸收，保证「漂移只会更保守」。

**引理 13（RES 的方差缩减）** 设分裂层数 `m`、每层条件概率 `p_0`，则 RES 估计量的相对标准差约为 `√(m(1−p_0)/(n p_0)) / P_f`，而朴素 MC 为 `√((1−P_f)/(n P_f))`。故方差缩减效率 `Eff ≈ P_f^{-1} / (m/p_0)`（数量级），当 `P_f ≪ p_0/m` 时收益显著。
*证明思路*：条件概率之积的独立性近似 + 各层二项方差线性叠加；稀有事件下 `P_f` 指数小，分裂把指数代价转成线性代价。

**定理 11（成功率下界的任意时有效性）** 在定义 247–249 下，对任意（可随数据选择的）停止时刻 `τ`，
`P(SR ≥ LCB_τ(SR)) ≥ 1 − α`。
即「在线宣称的成功率下界」在整个任务生命周期内一致有效，不需要预先固定回合数。
*证明思路*：定义 249 的集合反演 + 引理 11/12；`LCB` 是 e-过程未拒绝区域的上确界，拒绝事件恰为 `{M_t(SR) ≥ 1/α}`。

**定理 12（成功—安全前沿的非退化性）** 设任务推进收益 `G(k)` 关于 `k` 凹增且有上界，单块违规风险 `H(k)` 关于 `k` 凸增，且 `LCB(SR|k) ≈ G(k) · exp(−∑_{s≤k} h_s)`。则：
1. `LCB(SR|k)` 在 `k` 上单峰，存在内部最优 `k†`；
2. 存在参数区间使 `k† < k*_VISTA`，即**最大安全前缀严格劣于成功率最优前缀**；
3. 在相同安全约束下，`k†` 的 `LCB(SR)` 不低于 `k*`，因为 `k*` 也在可行域内，`k†` 只是取了更优者。
*证明思路*：`log LCB = log G(k) − Λ(k)`，`log G` 凹、`Λ` 凸，故 `log LCB` 凹，一阶条件给内部最优；构造 `G` 在 `k*` 附近已饱和而 `H` 仍线性增长的例子即得 (2)。该定理说明 CREST 是 VISTA 的**严格精化**而非替代：安全不降，成功率升。

**定理 13（漂移与刷分下的单向保守性）** 在 DRR（定义 254）与回退序（定义 257）下，任何漂移检测或证书失效都只会使 `LCB` 不增、`k†` 不增、`λ_risk` 不减；且单位回合的成功/失败判定不可被「异常排除」改写。因此存在一个审计映射使认证 `LCB` 是真实成功率的**保守下界**（允许悲观、禁止乐观）。
*证明思路*：对回退序做单调性归纳；对「排除回合」的禁止由定义 246/257 的硬约束保证；对 Goodhart 的防护由分母审计（定义 256）保证。

**定理 14（成功率证书的样本地板）** 给定精度 `ε`、置信度 `α` 与稀有事件估计效率 `Eff`，任何达到 `P(|SR − ŜR| > ε) ≤ α` 的估计器所需有效回合数满足 `n ≥ C·log(1/α)/(ε²·Eff)`；因此 CREST 的证书签发速度受异常检测质量直接制约，而非仅受计算量制约。
*证明思路*： Hoeffding/ empirical-Bernstein 下界 + 定义 258 的方差缩减代入；信息论下界由 Bernoulli 参数估计的局部 minimax 风险给出。

## 6. 本轮最大风险

**一句话**：CREST 的全部可证性依赖「成功率的分母是被诚实观测的回合集合」以及「异常检测的标定分布覆盖部署分布」；一旦控制器学会把难回合标成异常并排除、或把放弃算作未发生，`LCB(SR)` 就会在证书完全 Valid 的情况下单调上升，而真实任务成功率下降——这是**成功率 Goodhart / 生存者偏差**，它比第 66 轮的情绪欺骗更危险，因为异常检测恰好为「合法地删样本」提供了工具，而证书本身不会报警。

**次级风险与缓解**：
1. **分母污染**：abandon/超时/异常排除一律计为失败，并做分母审计（定义 256）；
2. **共形可交换性失效**：DRR 加权共形 + 漂移触发时只增保守，禁止乐观重标定；
3. **稀有事件估计偏差**：RES 需报告层间条件概率与置信区间，偏差大时拒绝签发证书；
4. **eSR 收敛慢**：以 `κ` 与分段 e-过程调优，并在 `n_eff` 不足时显式输出「未认证」而非低值；
5. **探针成本与安全**：AAP 仅在 `ε_probe` 内执行，探针本身计入风险预算，不得绕过 fail-closed。

## 2. 形式化定义（完整版）

**定义 245（CREST 总览）**
```
CREST = (SCAN, eSR, RES, SPF, SBG, AAP, DRR, SRC)
```
不变式：SCAN/eSR 每步闭式更新，实时流零学习写；RES/AAP/DRR 只在语义流；所有回退 fail-closed（只收缩 `k`、抬高 `λ_risk`、增大 `α_eff`）；成功率的**分母**必须审计，任何「排除回合」等价于记一次失败。

**定义 246（回合成功与成功率）**
```
S = ⋀_{t=1}^{N} (safe_t ∧ progress_t ∧ ¬abandon_t),   SR = P(S=1)
```
约定：abandon、超时一律计为失败，且不得进入任何「已排除」集合。

**定义 247（序贯共形异常分数）**
```
s_t = A(φ_t),   p_t = (1 + #{i : s_i ≥ s_t}) / (n + 1)
```
在可交换性下 `p_t` 随机占优 `U(0,1)`；异常判据 `p_t < α`。SCAN 维护滑动分数窗与标定版本号。

**定义 248（异常 e 值与检验鞅）**
```
e_t = κ · p_t^{κ−1},  κ∈(0,1),   E_0[e_t] ≤ 1
M_t = ∏_{i=1}^{t} e_i,           E_0[M_0] = 1
```
`M_t` 为非负上鞅；Ville 不等式：`P_0(∃t: M_t ≥ 1/α) ≤ α`，对任意停止时刻成立。

**定义 249（任意时有效成功率下界）**
```
M_t(s) = ∏_{i=1}^{t} [(1−s) + s·e_i]
LCB_t(SR) = sup{ s : M_t(s) < 1/α }
```
由定义 248 得上鞅性，故 `P(∀t: SR ≥ LCB_t(SR)) ≥ 1−α`。

**定义 250（异常引导稀有事件分裂 RES）**
```
P̂_f = P̂(s>ℓ_0) · ∏_{j=1}^{m} P̂(s>ℓ_j | s>ℓ_{j−1})
```
层水平 `ℓ_j` 取上一层样本的 `(1−p_0)` 分位数自适应选取，使每层条件概率约为 `p_0`（如 0.1）。

**定义 251（成功—安全联合可行域与帕累托认证前缀）**
```
K_safe = {k : k ≤ k*_VISTA ∧ k ≤ k*_RAS}
k†_t = argmax_{k∈K_safe} LCB_t(SR | execute prefix k then replan)
```
并列时取安全裕度更大者。`k†` 可严格小于 `k*`——为成功率主动不花完安全预算。

**定义 252（SBG 成功率预算控制器）**
```
e_t^{ctrl} = LCB_t(SR) − τ_succ

```
带滞回避免抖动；`shrink` 无条件允许，`extend` 仅在 `e_t^{ctrl} ≥ δ_extend` 且证书 Valid 时允许；`abort` 计为失败并冻结分母。

a* = argmax_{a∈𝒜} E[ΔVar(LCB_t(SR)) | a] / cost(a)

仅当期望 LCB 增益 `> δ_probe` 且探针风险 `≤ ε_probe` 时执行。

D_t = MMD(Ŝ_recent, Ŝ_calib)   或   KL(Ŝ_recent ‖ Ŝ_calib)

若 `D_t > τ_drift`：置标定失效；加权共形重标定（`w_i ∝ exp(−λ d_i)`）；抬升 `α_eff = α(1−ρ_drift)`；收缩 `k†`。保证漂移下 LCB 只更保守。

**定义 255（WAS 非对称加权评分）**

异常检测越好（`Eff` 越大），成功率证书签发越快。

class SequentialConformalAnomaly:
    def __init__(self, calib_scores, alpha=0.05):
        self.calib = sorted(calib_scores); self.alpha = alpha; self.version = 0
    def pvalue(self, s_t):
        n = len(self.calib)
        return (1 + sum(1 for s in self.calib if s >= s_t)) / (n + 1)
    def step(self, phi_t):
        s = nonconformity(phi_t)
        p = self.pvalue(s)
        return {"score": s, "p": p, "anomaly": p < self.alpha, "version": self.version}

def residual_failure_prob(scan, phi_pool, p0=0.1, max_levels=8, min_pool=20):
    scores = np.array([scan.step(phi)["score"] for phi in phi_pool])
    levels, cond, pool = [], [], scores
    for _ in range(max_levels):
        if len(pool) < min_pool: break

        p_j = float(np.mean(pool > level))
        levels.append(level); cond.append(max(p_j,1e-9))
        pool = pool[pool > level]
    p_f = float(np.prod(cond)) if cond else float(np.mean(scores > levels[-1]))
    return {"P_f": p_f, "levels": levels, "cond": cond,
            "eff": variance_reduction(scores, cond)}

    def __init__(self, tau_succ=0.95, delta=0.02, delta_probe=0.01):
        self.tau_succ, self.delta, self.delta_probe = tau_succ, delta, delta_probe
    def choose(self, k_safe, lcb, hazard_fn):
        best_k, best_l = k_safe, -1.0
        for k in range(1, k_safe+1):
            l = predict_success_lcb(k, lcb, hazard_fn)
            if l > best_l: best_k, best_l = k, l
        err = best_l - self.tau_succ
        action = ("extend" if err >= self.delta else
                  "hold" if err >= -self.delta_probe else
                  "probe" if err >= -self.delta else "shrink")
        return best_k, action, {"lcb": best_l, "err": err}


# IP-243 CREST 闭环
def CREST_round(M, obs, tau_succ=0.95):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    M.lsf.update_geometry(P_cloud)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))
    y_vis = M.f_vis(img, depth, flow)

    face_gate = M.er.gateway.recognize(img)
    A = M.vista.ach.propose(x_prime, H=M.vista.H)
    rho = M.vista.fir.signature(M.vista.stage.split(M.vista.residual_log))
    joint_post, _ = M.efs.synthesize(rho, face_gate)

    phi_t = build_phi(rho, face_gate, A, M.residual_log)
    scan_out = M.scan.step(phi_t)
    M.esr.update(scan_out["p"])
    lcb = M.esr.lcb()

    if M.should_estimate_failure(scan_out):
        res = residual_failure_prob(M.scan, M.phi_replay_pool)
        M.p_f_hat = res["P_f"]

    if M.drr.update(scan_out["score"]):
        M.scan.reweight_calibration(M.drr.weights)
        lcb = M.esr.lcb_conservative(alpha_eff=M.drr.alpha_eff)

    k_ras = M.csc_ras.certified_prefix_ras(A, joint_post, M.m_ras, M.alpha_chunk)
    k_dag, action, info = M.sbg.choose(k_ras, lcb, M.res.hazard_fn)

    if action == "probe":
        a_star = M.aap.best_probe(lcb, tau_succ)
        if a_star is not None and M.aap.cheap_and_safe(a_star):
            M.execute_probe(a_star)
            M.esr.update(M.scan.step(build_phi_after_probe(M)).p)

    lam = M.efs.risk_scale(joint_post)
    tau_cmd = M.vista.pi_sigma.prefix_dispatch(A[:k_dag]) * lam
    J = build_src(J_ras=M.vista.J, lcb=lcb, tau_succ=tau_succ,
                  drift=M.drr.stat, p_f=M.p_f_hat,
                  audit=M.audit_abandonment(), version=M.crest_ver)
    if not valid_src(J):
        k_dag, lam = M.sbg.fail_closed(k_dag, lam)
        tau_cmd = M.vista.pi_sigma.prefix_dispatch(A[:k_dag]) * lam
    return k_dag, lcb, action, J

## 4. 推导

**引理 11（e 值鞅有效性）** 若 `e_t ≥ 0`、`E_0[e_t] ≤ 1`，则 `M_t=∏e_i` 为非负上鞅，且对任意停止时刻 `τ`，`P_0(M_τ ≥ 1/α) ≤ α`。
*证明*：`E[M_t|ℱ_{t−1}] ≤ M_{t−1}` + Ville 不等式；对数据依赖停止成立，故允许在线决策。

**引理 12（共形 + 可选停止的复合有效性）** 可交换性下 `p_t` 随机占优 `U(0,1)`，故 `E_0[e_t] ≤ 1`，代入引理 11 得 LCB 对任意停止时刻有效；协变量漂移下 DRR 加权共形把有效样本量降为 `n_eff=(∑w)²/∑w²`，用 `α_eff` 膨胀吸收，保证只更保守。

**引理 13（RES 方差缩减）** 层数 `m`、每层概率 `p_0` 时，RES 相对标准差 `≈ √(m(1−p_0)/(n p_0))/P_f`，朴素 MC 为 `√((1−P_f)/(nP_f))`；`Eff ≈ P_f^{-1}/(m/p_0)`，故 `P_f ≪ p_0/m` 时收益显著。

**定理 11（成功率下界的任意时有效性）** 在定义 247–249 下，对任意可随数据选择的停止 `τ`，`P(SR ≥ LCB_τ(SR)) ≥ 1−α`。
*证明*：集合反演 + 引理 11/12；拒绝事件恰为 `{M_t(SR) ≥ 1/α}`。

**定理 12（成功—安全前沿非退化性）** 设推进收益 `G(k)` 凹增、单块违规风险 `H(k)` 凸增、`LCB(SR|k) ≈ G(k)exp(−∑_{s≤k}h_s)`，则：(1) `LCB(SR|k)` 单峰，存在内部最优 `k†`；(2) 存在参数区间使 `k† < k*_VISTA`，即最大安全前缀严格劣于成功率最优前缀；(3) `k†` 的成功率不低于 `k*`（后者也在可行域内）。
*证明*：`log LCB = log G − Λ`，凹 − 凸 = 凹，一阶条件给内部最优；令 `G` 在 `k*` 附近饱和、`H` 仍线性增长即得 (2)。CREST 是 VISTA 的严格精化：安全不降、成功率升。

**定理 13（单向保守性）** 在 DRR 与回退序下，任何漂移检测或证书失效只会使 `LCB` 不增、`k†` 不增、`λ_risk` 不减；且单位回合判定不可被「异常排除」改写。故认证 LCB 是真实成功率的保守下界（允许悲观、禁止乐观）。
*证明*：对回退序做单调性归纳；排除禁令由定义 246/257 硬约束；Goodhart 防护由分母审计保证。

**定理 14（样本地板）** 给定 `ε, α, Eff`，任何满足 `P(|SR−ŜR|>ε) ≤ α` 的估计器需 `n ≥ C·log(1/α)/(ε²·Eff)`；证书签发速度受异常检测质量直接制约。
*证明*：Hoeffding/empirical-Bernstein 下界 + 定义 258 代入；局部 minimax 下界由 Bernoulli 参数估计给出。

## 6. 本轮最大风险

**一句话**：CREST 的全部可证性依赖「成功率的分母是被诚实观测的回合集合」与「异常检测的标定分布覆盖部署分布」；一旦控制器学会把难回合标成异常并排除、或把放弃算作未发生，`LCB(SR)` 就会在证书完全 Valid 的情况下单调上升，而真实任务成功率下降——这是**成功率 Goodhart / 生存者偏差**，比第 66 轮的情绪欺骗更危险，因为异常检测恰好为「合法地删样本」提供了工具，而证书本身不会报警。

**次级风险与缓解**：
1. **分母污染**：abandon/超时/异常排除一律计失败，并做分母审计；
2. **共形可交换性失效**：DRR 加权共形 + 漂移时只增保守，禁止乐观重标定；
3. **稀有事件估计偏差**：RES 报告层间条件概率与置信区间，偏差大时拒绝签发证书；
4. **eSR 收敛慢**：调 `κ` 与分段 e-过程，`n_eff` 不足时显式输出「未认证」；
5. **探针成本与安全**：AAP 仅在 `ε_probe` 内执行，探针计入风险预算，不绕过 fail-closed。
