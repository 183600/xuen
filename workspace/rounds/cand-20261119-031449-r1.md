# 第 1 轮（UniBot 线 · 本轮灵感：「时空推理」×「对比实验」）

> **连续性声明**：本线沿用上一轮 UniBot-SAGE 的工程骨架与四条硬结论（终态成功是唯一计分货币；跨任务专长准正交；断点在最后对齐/插入/释放；快没有红利），**不推倒重来**。本轮把研究重心换到两个新透镜：
> - **「时空推理」**负责“最后一厘米”的机制：显式预测夹爪—物体—目标的**相对**位姿轨迹，并用时序逻辑做一致性监控；
> - **「对比实验」**负责“在噪声里证明它有效”的方法：用配对/反事实对比把不可读的 1–3 分效应变成可检验的因果量。
>
> 编号继续累加：定义 **U13–U18**、引理 **L8–L12**、实验 **E619–E630**；上一轮 U1–U12 / L1–L7 / E601–E618 保留引用，不重复展开。情报基线沿用上一轮核实结果（检索日期 2026-11-17），本轮不新增对外事实断言。

## 0. 先给直觉：三个画面

**画面 1 · 最后失败的不是“看见”，而是“预见到”。**
插网线、拧瓶盖、把电池从槽里抠出来，失败点几乎都在最后几毫米。这类失败不是“识别不出物体”，而是“未来半秒里，夹爪、被夹物体、目标孔位三者的**相对位姿**会往哪走”没被显式预测。反应式 VLA 只能等偏差出现在像素里再纠正，而到那时机械上已经晚了。

**画面 2 · chunk 是“时间断片”，所以“异常”这个概念不存在。**
现有策略每 8–16 步独立出一块动作，块与块之间没有共享的时空假设。于是“抓住没有 / 滑没滑 / 对准没有”只散落在腕部像素的细微变化里；没有时序记忆，模型就没有“事情正在变坏”的表征，只会继续自信地错下去。**时空推理的第一性作用是给策略一个“可被违反的预期”**——有了预期，滑移、错位、空抓才成为可检测事件。

**画面 3 · 你无法在噪声里用绝对分数证明 1 分。**
真机时段稀缺、任务间方差大、官方榜单还是 `gen_leaderboard.py` 随机生成的 teaser。用绝对成功率调参 = 在噪声上挑最大值。真正能读出 1–3 分效应的唯一办法是**配对比较**：同一初始状态、同一随机数、只切换一个组件，看同一 episode 的差分。**对比实验不是“多做几组”，而是一种把方差消掉的估计器设计。**

**合成的一句话直觉**：把“最后一厘米”从“分类/回归”改写成「**在相对坐标系里预测未来、并比较多个未来**」，再用「**配对反事实**」去证明每个改动真的有用。前者提供候选，后者提供监督与判据。

## 1. 把直觉变成可检验的命题

### 1.1 「时空推理」的严格翻译

设交互在**末端执行器坐标系**中描述。定义相对状态

```
x_t = ( Δp_t , ΔR_t , g_t , σ_t )
```

其中 `Δp_t, ΔR_t` 是“目标关键点/抓取物体”相对于夹爪基座的平移与旋转（对插入类任务是孔位，对抓取类任务是物体质心与主轴），`g_t` 是 1 维夹爪开合，`σ_t` 是接触/滑移隐变量。选择相对坐标不是记号偏好：它把“绝对位置、背景、桌子高度”这些 OOD 变量**因子化掉**，是后面跨场景外推的前提（引理 L12）。

学一个**相对动力学模型（STRDM）**：

```
x̂_{t+1}, Σ̂_{t+1} = f_θ( x_{t-k:t} , a_{t:t+H} )
```

用官方 32 个数据集自监督训练（我们有完整动作、关节/EE 状态、四路相机；未来相对位姿由腕部帧几何 + 正运动学得到，接触/滑移由“夹爪闭合后物体是否随臂运动”间接标注）。它同时产出三样东西：

1. **候选未来的评分** `A_H(a_{t:t+H}) = P(终态成功 | x_t, a)`（U15）；
2. **时序创新残差** `e_t = d(x_t, x̂_t)`（U16），用于滑移/错位告警；
3. **时序逻辑鲁棒度**：把“先对齐再插入、夹紧后才能抬升、对准后不得有大幅相对横移”写成信号时序逻辑（STL）公式 `φ`，在线算鲁棒度 `ρ_φ`；`ρ_φ<0` 即已违反时序约束，必须介入。

**为什么这不是“再做一个世界模型”**：官方参考架构（UnifoLM-WMA）已把世界模型兼作仿真/策略增强。我们的差异是三点——(a) 只在**接触尺度的相对 SE(3)**上建模，而不是生成像素级未来；(b) 训练目标是**用于排序的判别目标**，不是重构；(c) 推理期作**chunk 选择器**而非训练期增广。它是挂在冻结主干上的小头，能在官方 <105 ms 量级的预算内跑（见 §7）。

### 1.2 「对比实验」的严格翻译

对任一组件 `π`（例如“开启 STRDM 选择器”），定义配对对比：

```
Δ_π = E_{s0 ~ D} [ Y(π_T | s0) − Y(π_C | s0) ]
```

其中 `π_T/π_C` 是同一初始状态 `s0`、同一随机数流下的治疗/对照，`Y∈{0,1}` 为终态成功。方差为

```
Var(Δ̂_π) = ( σ_T² + σ_C² − 2ρ σ_T σ_C ) / N
```

配对的价值全在 `ρ`：`s0` 相同、随机数相同、只切换一个组件时 `ρ` 通常远大于 0，所需样本量按 `(1−ρ)` 缩减（引理 L8）。这把“真机时段不够”从**不可解**变成**工程可解**。

更关键的是：**对比实验不只用于评估，还用于造训练信号**。在官方 episode 的分支点 `t`，从同一记录状态出发执行候选块 A 与 B，得到一对 (未来, 结果) 标签——这就是**反事实回放**。它给 STRDM 的排序头提供“同一状态下谁更好”的成对监督，而普通行为克隆只给“当时做了什么”。**时空推理产生候选空间，对比实验产生偏好信号**，这是本轮两个灵感真正的耦合点。

### 1.3 三个可反驳的预测（预注册）

- **H1（相对性）**：STRDM 在未见背景/未见位置上的相对位姿误差增长，显著小于同容量绝对坐标系基线。
- **H2（可选择性）**：在“最后对齐”相位的 K 个候选中择优，其增益大于在早期搬运相位择优；即时空推理的红利集中在接触附近。
- **H3（可测性）**：配对设计相对非配对设计，把检出 +2 分效应所需样本量至少降 3 倍（当 `ρ≥0.67`）。

## 2. 研究问题（本轮版）

- **Q6（相对动力学的 OOD 稳健性）**：相对坐标系是否真的把背景/位置偏移因子化掉？在留出物体、留出背景、留出位置上，误差增长曲线差多少？
- **Q7（候选比较的兑现率与上界）**：K 个候选块中择优，能把 oracle 上界兑现多少？K 增大时收益是否被 critic 误差与相关性吃掉？延迟预算内 K 最大多少？
- **Q8（时序异常的检出边界）**：给定滑移幅度与观测噪声，滑移检测的 AUROC、检出延迟（步）与误报率如何权衡？“只在违约时介入”能否保证不伤基线？
- **Q9（对比实验的分辨率）**：在真实 `ρ` 下，配对设计能可靠检出多小的 `Δ_π`？需要多少真机 episode/时段？哪些效应小到**不值得做**？
- **Q10（反事实回放的保真度）**：用模型/仿真产生的成对标签，在什么保真度阈值以上才优于纯真实标签？模型偏差会不会系统性地偏爱某类候选？

## 3. 设计原则（在上一轮 P1–P6 上新增）

- **P7 相对优先（relative-first）**：凡是能写在末端系里的量，绝不写成世界系。世界系只用于重定位与安全限位。
- **P8 比较优先（contrast-first）**：任何“变好了”的主张，必须给出**配对对比 + 置信区间 + 预注册门槛**；没有对照的绝对分数只能当轶事，不进结论。
- **P9 保守切换（conservative switching）**：选择器只有在“优于基线候选的边际 ≥ δ”时才切换，否则执行基线块；宁可少赚，不可把 critic 的错变成新的硬失败。
- **P10 可归因（attributable）**：每个介入（重抓/重对准/换块）都落一条带时间戳、相对状态、触发原因的事件日志，供六因子分解与审计复用。

## 5. MVP 与退化链

**MVP = IP-11（时序滑移/错位监控，实时） + IP-12（配对实验引擎，离线/本地） + IP-09 的最小 STRDM（只做短时相对位姿预测） + 基线 VLA。**
先做监控与评测，是因为它们**不依赖新数据、不改主干、且立刻能让后续每个改动可被分辨**；IP-10（候选选择）只有在 STRDM 精度与延迟都过关后才启用。

**严格退化链（任一层失效 ⇒ 行为回退，而非漂移）**：
- L0 STRDM 不可用 ⇒ 关闭 IP-10 选择器，执行基线块；
- L1 滑移监控置信度低 ⇒ 退化为“不干预”的开环执行（沿用上一轮高精度低召回准则）；
- L2 选择边际 `< δ` ⇒ 执行基线候选（P9）；
- L3 配对假设被破坏（串扰/共享状态）⇒ 该批数据作废，不用于任何结论；
- L4 整条链路失效 ⇒ 提交纯基线策略（永远保留一个能跑通、可信度合规的安全网）。

## 6. 预期贡献（可验收）

1. **一个相对坐标系的时空动力学头**，给出相对位姿预测误差随 horizon 的曲线，并在留出背景/位置上与绝对系基线做配对比较（H1）。
2. **一个“比较多个未来”的 chunk 选择器**，给出 K 与兑现率、延迟的关系，并证明在最后对齐相位收益最大（H2）。
3. **一个 STL 时序一致性监控器**，把“滑移/错位/空抓”从不可见变成带延迟上界的可检测事件（Q8）。
4. **一套配对/反事实实验协议**：功率表、预注册模板、串扰检查、配对 bootstrap；使 1–3 分效应第一次在本任务上**可判定**（H3）。
5. **把“通用能力”重新表述为可比较的未来**：不是“哪个模型更好”，而是“在同一状态下，哪个候选未来更接近成功”——这与上一轮“技能近正交”的发现互为表里。

## 7. 本轮最大风险

**一句话**：STRDM 的误差与基础策略的误差共享同一个视觉主干与同一批训练数据，二者**不是独立证据**——critic 很可能在最需要它的 OOD 场景里“自信地认同基线的错误”，于是“比较多个未来”退化成“把同一个偏见采样 K 次”，甚至因切换而低于基线。

## 0. 本轮结论摘要

**一句话路线**：在冻结的 VLA 主干上挂一个**相对坐标系时空动力学头（STRDM）**，用它并行推演 K 个候选动作块的未来，选“终态相对位姿最像成功”的那一条（并在边际不足时回退基线）；同时用 STRDM 的时序创新残差 + 时序逻辑鲁棒度做**滑移/错位监控**；最后用**配对/反事实实验引擎**让每个组件的因果效应在稀缺真机时段里变得可判定。

**三条定量锚（沿用上一轮 teaser 结构 + 本轮统计计算）**：

| 事实 | 数值 | 推出的设计 |
|---|---|---|
| 失败集中在插入/旋转/细粒度摆放（Plug In Ethernet 17.7、Unlock 20.1） | 断点在接触附近 | 时空推理的红利应集中在 align/insert 相位（H2） |
| 跨任务专长准正交（Kendall τ 均值 0.064），per-task oracle 比最好单模型 +4.26 | 候选空间真实存在 | 专家层提供**多样化候选**，critic 负责择优 |
| 单臂成功率 Bernoulli，p≈0.25，σ²=0.1875；检出错 Δ=0.05（5 分）在 α=.05/power=.8 下 | 非配对每臂 ≈1177 episodes；配对 ρ=0.8 时仅 ≈235 对 | 不做配对，真机时段根本不足以支撑任何结论（引理 L8） |

## 2. 创新点详述

### IP-09 · STRDM 相对时空动力学头（P0）

- **动机**：最后一厘米的失败是**相对运动预测**失败，而非识别失败。绝对世界模型把背景、位置、光照都卷进状态，恰是 OOD 偏移最大的维度；相对状态把这些因子化掉（引理 L12）。
- **与现有方案的差异**：官方 WMA 路线用世界模型做生成/仿真/策略增强；本方案只做**接触尺度、相对系、判别式**的小头：(a) 输入是短历史相对状态 + 候选动作块；(b) 输出是未来相对 SE(3) 与接触概率，不生成像素；(c) 只在推理期用于**排序与监控**，不碰主干权重。因此它能在 <105 ms 量级预算内与主干并行。
- **技术可行性**：高。官方数据含完整动作与关节/EE 状态，未来相对位姿可由 `ee_pose_gripper_base` + 正运动学 + 腕部帧几何得到；接触/滑移用“夹爪闭合后物体是否随臂运动”间接标注。网络为 Transformer/GRU 小头（≤10 M 参数）。
- **所需资源**：数据 = 官方 32 数据集（≈32k eps / 169 h）；算力 = 1–2×A100 × 1–2 天；接口 = 无新增字段（纯内部）。
- **落地步骤**：①统一切帧与坐标系（腕部系 → EE 系）；②自动生成相对位姿与接触/滑移标签，人工抽检 5%；③训练多 horizon 预测（0.25/0.5/1/2 s），用 NLL + 分位数校准；④留出物体/背景/位置做 OOD 误差曲线（E619/E625）；⑤蒸馏/量化到单次 rollout ≤8 ms。
- **风险**：腕部帧在遮挡/反光下几何不稳 ⇒ 用双目 + EE 运动先验融合；相对标签在“物体未被夹住”时无定义 ⇒ 用接触概率掩码，只在前置条件满足时算精度。

### IP-10 · CEC 反事实候选选择器（P0）

- **动机**：上一轮发现跨任务专长准正交、oracle +4.26，但“知道谁更强”需要能读出**当前状态**。CEC 把“模型选择”下沉到“**同一状态下的候选未来选择**”，绕开“如何预先判定任务归属”的难题。
- **与现有方案的差异**：常规做法是单块贪心或固定专家；我们做**块级反事实比较**：K 个候选来自专家层温度采样（保证多样性），STRDM 并行推演，评分 `A_H`；仅当最优候选比基线候选的边际 ≥ δ 才切换（P9），否则执行基线。
- **技术可行性**：中–高。K≤4 时可与主干并行，延迟可控；K 增大收益受 critic 误差与候选相关性限制（引理 L9）。
- **所需资源**：算力 = 推理时 K×STRDM（K=2–4 默认，K=8 仅离线）；数据 = 官方数据 + 反事实回放对（IP-12）；接口 = 无。
- **落地步骤**：①先固定 K=2、δ=0.1 做最小可用；②用反事实回放训练排序头（成对 ranking loss，而非逐点回归）；③在 align/insert 相位单独开启，其余相位关闭；④扫 δ 与 K（E620/E626）；⑤若延迟超预算，蒸馏成单次前向的“候选打分器”。
- **风险**：critic 错误与基线错误相关（本轮最大风险）⇒ 保守 δ + 只在最后相位开 + 每 episode 切换次数上限（≤5）+ A/A 自检。

### IP-11 · TSM 时序滑移/错位监控（P0）

- **动机**：接口只给 1 维夹爪标量与腕部像素，抓握/滑移是隐变量；上一轮把它做成二值判定，本轮升级为**时序状态机 + 可违反的预期**。
- **与现有方案的差异**：不只判“抓住没有”，而是判“**正在滑/正在歪/空抓**”：用 STRDM 的预测—观测创新残差（U16）与 STL 鲁棒度（相位顺序、夹紧才可抬升、对准后相对横移受限）联合告警；介入动作按违约类型路由到重抓/重对准/非抓取原语。
- **技术可行性**：高。纯统计版（无 STRDM）也能用“预测常数速度”做 baseline；有 STRDM 时残差更敏感。
- **所需资源**：在线 <3 ms（复用 IP-09 输出）；数据 = 官方数据 + 注入式合成滑移（用于校准）；接口 = 无。
- **落地步骤**：①定义相位自动机与 STL 公式；②用正常数据估创新协方差 Σ，设阈值 τ=c·√λ_max；③CUSUM 累积残差以降延迟；④在数据中注入已知滑移/错位，测 AUROC、延迟、ARL₀（E621/E628）；⑤高阈值、低召回，只在高置信违约时介入。
- **风险**：STL 约束过严会误报（把正常探索当违约）⇒ 约束只用“物理上必然”的条款；误报代价用 A/A 与在线回滚控制。

### IP-12 · PIEE 配对/干预实验引擎（P0）

- **动机**：真机时段稀缺、任务方差大、teaser 是随机占位表 ⇒ 绝对分数不可读。没有可判定的实验，所有组件都无法迭代。
- **与现有方案的差异**：不是“多跑几组取均值”，而是：(a) 同一初始状态、公共随机数的**配对**；(b) 单组件切换的**干预**对比；(c) **反事实回放**生成成对排序标签；(d) A/A 校准与串扰检查；(e) 预注册与序贯检验，禁止“看着结果改假设”。
- **技术可行性**：高（工程 + 统计）。
- **所需资源**：接口 = 官方 `run_client.py`/`run_server.py`；数据 = 官方 episode 回放；算力 = 小。
- **落地步骤**：①复刻评测闭环，验证 `reset()` 隔离与端口无串扰；②实现 matched-initial-state 采样与 CRN；③实现配对 bootstrap 与序贯 α-spending；④A/A 测试（治疗=对照）确认 `Δ̂≈0`；⑤输出功率表与预注册模板；⑥反事实回放分支与保真度评估（E623）。
- **风险**：官方评测端不允许我们控制初始状态（配对只适用于**我们自己的本地 A/B**，不能用于官方分数）⇒ 明确区分“开发期配对”与“提交期绝对分”，不把两者混为一谈（引理 L11 的适用范围）。

## 3. 符号与定义（U13–U18）

| 符号 | 含义 |
|---|---|
| `x_t` | 相对状态 `(Δp_t, ΔR_t, g_t, σ_t)`，均在 EE 系 |
| `f_θ` | STRDM：相对动力学 `x̂_{t+1}=f_θ(x_{t-k:t}, a_{t:t+H})` |
| `A_H` | 候选块 `a_{t:t+H}` 的终态对齐成功评分 |
| `e_t` | 时序创新残差（预测 vs 观测，Mahalanobis 距离） |
| `φ, ρ_φ` | STL 时序约束及其鲁棒度（<0 即违反） |
| `Δ_π` | 组件 `π` 的配对平均处理效应 |
| `ρ` | 配对臂之间的结果相关系数 |
| `δ` | 选择器切换的保守边际 |

**定义 U13（相对状态）** `x_t = (Δp_t, ΔR_t, g_t, σ_t)`：`Δp/ΔR` 为目标关键点（抓取相位取物体质心/主轴，插入相位取孔位）相对夹爪基座的位姿；`g∈[0,1]` 为夹爪开合；`σ∈[0,1]` 为接触/滑移隐变量。**相对优先**（P7）：所有建模与评分都在此系内完成。

**定义 U14（相对动力学）** `x̂_{t+1}, Σ̂_{t+1} = f_θ(x_{t-k:t}, a_{t:t+H})`；以教师强制 + 多步 rollout 训练，损失为 Gaussian NLL + 分位数校准项。

**定义 U15（终态对齐评分）** `A_H(a_{t:t+H}) = E[ Y | x_t, a_{t:t+H} ]`，由 `f_θ` 的终端相对位姿特征（位置误差、角度误差、接触概率、终端速度）过一个小分类头估计；输出经温度校准。

**定义 U16（时序创新与滑移告警）** `e_t = (x_t − x̂_t)ᵀ Σ̂_t^{-1} (x_t − x̂_t)`；CUSUM 统计量 `S_t = max(0, S_{t−1} + e_t − κ)`，`S_t>h` 触发滑移/错位告警；同时 `ρ_φ(x_{t-k:t})<0` 触发时序约束违约告警。

**定义 U17（配对对比）** `Δ̂_π = (1/N) Σ_{i=1}^N [ Y_i(π_T | s_i) − Y_i(π_C | s_i) ]`，其中 `s_i` 相同、随机数流相同（CRN），仅组件 `π` 开关不同；CI 用配对 bootstrap。

**定义 U18（反事实回放对）** 在记录 episode 的分支点 `t` 从同一状态执行候选 `a` 与 `a'`，得成对标签 `(x_t, a, a', y_a − y_{a'})`；排序损失 `L_rank = −log σ( (A(x_t,a) − A(x_t,a'))·sign(y_a − y_{a'}) )`。

```python
# ===== IP-09 + IP-10 + IP-11：推理期统一策略（单 checkpoint、单 API）=====
class STRIDEPolicy:
    def __init__(self, ckpt, K=2, delta=0.10, H=16):
        self.base = load_single_checkpoint(ckpt)   # 含上一轮专家层
        self.strdm = STRDMHead.from_pretrained(ckpt)  # 小头，与主干并行
        self.monitor = TemporalMonitor()           # IP-11
        self.stats = RobustStats()                 # 创新协方差在线估计
        self.K, self.delta, self.H = K, delta, H

    def get_action(self, obs, port):
        s = self.sessions[port]
        x = self.rel_state(obs)                    # U13（EE 系）
        zt, zp = self.task_phase(obs)              # 复用上一轮 U2/U3

        # 1) 候选未来：专家层温度采样 K 个块（含基线贪心块）
        cands = [self.base.act(obs, zt, zp, sample=(i > 0)) for i in range(self.K)]
        base_idx = 0

        # 2) 仅在“最后相位”开启比较（H2：红利集中在接触附近）
        if zp in FINAL_PHASES and self.strdm.ready and s.switches < 5:
            futures = [self.strdm.rollout(x, a, H=self.H) for a in cands]
            scores = [self.strdm.align_score(f) + LAM * stl_robust(f) for f in futures]
            best = int(np.argmax(scores))
            # 3) P9 保守切换：边际不足就执行基线
            if scores[best] - scores[base_idx] < self.delta:
                best = base_idx
            if best != base_idx:
                s.switches += 1
            a = cands[best]
        else:
            a = cands[base_idx]

        # 4) 时序监控：创新残差 / STL 违约 => 路由到恢复动作
        if self.monitor.alarm(x, self.strdm.last_pred, self.stats):
            a = self.recover(obs, reason=self.monitor.reason)   # 重抓/重对准/非抓取原语
        self.stats.update(x, self.strdm.last_pred)
        return self.pack(a, obs)

    def rel_state(self, obs):
        # 腕部帧 + ee_pose + gripper -> EE 系相对位姿；接触由闭环+随动估计
        return build_relative_state(obs)           # U13
```

# ===== IP-12：配对对比 + A/A 校准 =====
def paired_contrast(run_episode, pi_T, pi_C, n_pairs, seed0):
    deltas = []
    for i in range(n_pairs):
        s0  = sample_initial_state(seed0 + i)        # matched initial state
        rng = np.random.default_rng(seed0 + i)       # common random numbers
        yT  = run_episode(pi_T, s0, rng)             # 治疗臂
        yC  = run_episode(pi_C, s0, rng)             # 对照臂
        deltas.append(yT - yC)
    return mean_ci_bootstrap(deltas)                 # U17

def aa_calibration(run_episode, pi, n_pairs, seed0):
    # 治疗=对照：若 CI 不含 0，说明存在串扰/共享状态/漂移，整批作废
    lo, hi = paired_contrast(run_episode, pi, pi, n_pairs, seed0)
    return (lo <= 0.0 <= hi)

## 5. 推导（引理 L8–L12）

**引理 L8（配对方差缩减 ⇒ 稀缺时段下唯一可行的检验）**
设治疗/对照单臂方差为 `σ_T², σ_C²`，配对相关为 `ρ`，则
`Var(Δ̂) = (σ_T² + σ_C² − 2ρσ_Tσ_C)/N`；当 `σ_T=σ_C=σ` 时 `= 2σ²(1−ρ)/N`。
检出错 `Δ` 所需配对数 `N ≈ 7.849·2σ²(1−ρ)/Δ²`（α=0.05 双侧、power=0.8），而非配对每臂需 `n = N/(1−ρ)`。
⇒ 配对把 episode 预算按 `(1−ρ)` 缩减；`ρ=0.8` 时为 1/5。取 `p=0.25, σ²=0.1875` 得 §7 的功率表。∎

**引理 L9（候选选择的收益界与保守切换的安全性）**
设基线候选成功率 `p_b`，K 个候选若相互独立且单块成功率为 `p`，oracle 成功率 `1−(1−p)^K`；记实际达成 `p_sel`，则**兑现率** `= (p_sel − p_b)/(oracle − p_b)`。
若选择器只在评分边际 `≥δ` 时切换、且切换时的候选真实成功率以概率 `q` 不低于 `p_b`，则
`E[Y] ≥ p_b − (1−q)·Pr(switch)·Δ_max`。
⇒ 提高 `δ` 会降低 `Pr(switch)`，从而把“critic 犯错”的期望损失压到可控；这是 P9 的形式依据。候选相关性越高，oracle 上界越接近 `p`，K 的红利越小（故默认 K≤4）。∎

**引理 L10（滑移的检出延迟上界）**
若滑移未发生时创新 `e_t` 为平稳零均值序列，发生时每步均值上移 `μ>κ`；CUSUM 阈值 `h`，则平均检出延迟 `≤ h/(μ−κ)+1`；误报间隔 `ARL₀` 随 `h` 指数增长。
⇒ 给定允许延迟 `m` 步，应取 `h ≈ m(μ−κ)`；在官方 30 fps 下 5 步 ≈167 ms，仍在“最后一厘米”的可救窗口内。∎

**引理 L11（配对对比的可识别性与 A/A 判据）**
在一致性（同一 `s0` 的治疗定义明确）、无干扰（SUTVA：配对两臂不共享可变状态）、状态匹配三条下，`Δ̂_π` 识别平均处理效应。
本赛制的干扰源：共享后端隐状态、端口串扰、共享 RNG、热漂移。若 `reset()` 完整且会话隔离，则 SUTVA 成立；**A/A 检验**（治疗=对照）的 CI 覆盖 0 是可识别性的必要条件。
⇒ 官方评测由组织方控制初始状态，配对只用于**本地开发期 A/B**；提交期只能报告绝对分与置信区间，二者不可混用。∎

**引理 L12（相对坐标系的偏移因子化，条件性）**
若场景绝对状态可分解为 `x_abs = h(场景) ⊕ x_rel`，且模型只以 `x_rel` 为输入，则关于场景变量（背景、位置、桌高）的协变量偏移不改变模型输入的类条件分布。
现实中感知仍看到场景，故该结论是**近似**；H1/E625 正是对“近似是否足够好”的检验，而非先验保证。∎

## 7. 配对实验的统计设计（IP-12 核心产物）

**样本量直觉**：成功率是 Bernoulli，`p≈0.25`，`σ²=p(1−p)=0.1875`。α=0.05 双侧、power=0.8，`(z_{0.975}+z_{0.8})²≈7.849`。

所需**配对数 N**（总 episode ≈2N）：

| 可检出效应 Δ | ρ=0（配对失效） | ρ=0.5 | ρ=0.8 | ρ=0.95 |
|---|---|---|---|---|
| 2 分 | 7358 | 3679 | 1472 | 368 |
| 3 分 | 3270 | 1635 | 654 | 164 |
| 5 分 | 1177 | 589 | 236 | 59 |
| 10 分 | 294 | 147 | 59 | 15 |

**读法（本轮最重要的方法论结论）**：
- 若不做配对（或用 `ρ≈0` 的伪配对），要证明 +3 分需 ~3270 episodes/臂——真机时段下不可行；
- 若配对 `ρ=0.8`，只需 ~654 对（≈1308 episodes，含两臂），仍不小，但已进入“若干时段 + 回放”的可执行区间；
- 因此**本轮不追逐 1–2 分的榜单微调**，只追逐机制级、可配对验证的效应（滑移检出、对齐改善）；对 1 分以下的差别，明确宣布“本设计无权下结论”。

**执行纪律**：预注册假设 → 固定 `s0` 采样与 RNG → A/A 校准 → 主对比 → 配对 bootstrap CI → 序贯检验用 α-spending，禁止看结果改假设。

## 9. 风险登记册

| 风险 | 概率 | 影响 | 对冲 |
|---|---|---|---|
| **critic 与基线误差相关**（同一主干/数据） | 高 | 高（OOD 上“自信地重复错误”） | 保守 δ、仅最后相位开启、每 episode 切换上限、A/A + OOD 门控、失败即回退基线 |
| 相对标签在未夹住时无定义 | 中 | 中 | 接触概率掩码；只在前置条件满足时计损失 |
| 配对假设被串扰破坏 | 中 | 高（结论作废） | A/A 校准；端口隔离压测；作废不合格批次 |
| 官方评测无法配对 | 高（必然） | 中 | 明确配对仅用于本地；提交期用绝对分 + CI |
| K 推演超延迟预算 | 中 | 中 | K≤2 默认；蒸馏单前向；相位门控；早退 |
| STL 过严误报 | 中 | 中 | 只用物理必然约束；ARL₀ 校准；高阈值低召回 |
| 反事实回放偏差被学进 critic | 中 | 高 | 保真度门槛；真实标签为主、回放为辅；按相位报告 |
| 过度解读 teaser | 中 | 中 | 只作结构参考；一切结论以本地配对 + 真机 A/B 为准 |

**剪枝预案**：必保 IP-11（机制正确、可独立成立）与 IP-12（方法论基础设施）；IP-09 依 H1 决定是否保留完整形态；IP-10 依 E620/E626 决定是否上线；其余上一轮 P1/P2 项继续暂缓。

## 11. 本轮最值得押注的创新点（一句话）

**押注 IP-11（时序滑移/错位监控）：它不需要新数据、不改主干、不依赖 critic 的绝对精度，却直接命中“最后一厘米”的可救窗口——把“滑了/歪了/空抓”从不可见的隐变量变成带延迟上界的可检测事件；即使 IP-09/IP-10 全部失效，它也能独立成立并回退到安全基线。**

**本轮最大风险**：STRDM 的误差与基础策略共享同一视觉主干与训练分布，二者不是独立证据，critic 可能恰在最需要它的 OOD 场景里“自信地重复基线的错误”，使“比较多个未来”退化为“把同一个偏见采样 K 次”。
