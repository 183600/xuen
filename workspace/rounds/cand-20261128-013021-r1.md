### 第 5 轮灵感驱动研究记录

**灵感词**：目标检测、事件相机

**继承关系**：第 4 轮 CADVS-v4（IP-489~492）在五锚点基础上追加价值锚 VACK（kc_val）与平衡锚 BCK（kc_bal），形成七硬门 fail-closed 证据铸造框架与证书演算 CERTCALC，执行集 Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。本轮不推翻 v4，而是从「目标检测」「事件相机」两个灵感出发，补齐 v4 证据链中最容易被忽视的一环——**感知证据的语义接地与时间新鲜度**，形成 CADVS-v5（IP-493~496），执行集升级为 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ …。

**直觉与动机**：

1. **事件相机：把证书从「帧采样」升级为「连续时间证据」**。v1~v4 的所有证书都在离散帧/控制周期上铸造，存在帧间盲窗 Δt_frame（30 fps 约 33 ms，60 fps 约 16 ms）。快速操作时末端/目标在盲窗内可位移数厘米，导致「铸造时刻合法、执行时刻已过期」的陈旧证书——这是 v4 实时性风险之外的另一种隐性失效。事件相机以微秒级时间戳、>120 dB 高动态范围、无运动模糊输出异步事件流 E={(x_k,y_k,t_k,p_k)}，把证据的时间分辨率从「帧」推进到「事件」，并为 v4 CERTCALC 中的时序投影 □_T 提供可执行的操作语义：□_T kc 不再只是语法符号，而是「在 [0,T] 内每个事件时刻、且相邻证据间隔不超过 g_max 时 kc 恒成立」的可监控命题。

2. **目标检测：把「空间覆盖」升级为「语义接地 + 身份连续性」**。v4 的空间锚 3DCF 只回答「这块区域被观测到了吗」，不回答「观测到的到底是不是那个该操作的目标」。覆盖 ≠ 看对：对称物体、透明/反光物体、相似实例、快速运动与强光/弱光都会造成类别混淆、位姿歧义或身份切换（identity switch），而这些是静默失效——覆盖率与物理证书都可能通过，但操作对象从第一步就错了。引入事件驱动目标检测核 EODK，输出检测证书 DC = (cls, pose6d, conf, track_id, switch_prob, pose_amb, source, event_rate, t)，硬门 kc_det 同时约束置信度、身份连续性与位姿歧义边际。这不是再加一个「检测准确率指标」，而是把「被操作实例的身份」变成可被下游物理/价值/平衡锚共同引用的证据主键。

3. **三方交叉验证：事件流—运动学—帧检测的一致性**。事件相机提供逐像素亮度变化，可估计事件光流 u_ev；机器人正运动学 + 雅可比可预测期望光流 u_kin；帧检测提供低频语义锚点。三者应满足刚性运动一致性。若事件光流与运动学预测矛盾，则要么感知错了（错误检测/错误关联），要么物理模型错了（标定/动力学失配），两者都应拒绝。这把 v4 的感知锚与物理锚第一次真正闭环：**感知证据必须与物理证据自洽**，而不是各自独立地「都通过」。

**关键洞见**：v4 回答「覆盖/物理/人因/末点/记忆/价值/平衡」；v5 追问「看到的对象对不对（EODK，语义接地）」以及「看到的时刻是否新鲜且与物理运动自洽（ETCK，连续时间一致性）」。九硬门 kc_evidence_forged_v5 = kc_evidence_forged_v4 ∧ kc_det ∧ kc_tc，fail-closed；软评分 ECS_v5 = ECS_v4 · η_det · η_tc。理论上提出**连续时间证据铸造（CTEF）**：证书带显式有效期 τ_exp(v,a,δ_safe)，陈旧证书自动失效；事件流把 τ_exp 从帧级收紧到事件级，使 v4 的 □_T 第一次具备可判定的物理语义。

**形式化目标（增量）**：
1. 定义事件流 E 与时间表面 S(t)、事件率 r(t)；定义事件驱动目标检测证书 DC 与硬门 kc_det = (conf ≥ τ_det) ∧ (switch_prob ≤ τ_switch) ∧ (pose_amb ≥ τ_amb)。
2. 定义事件-运动学一致性证书 TCC = (ε_flow, ε_pose, hdr_margin, latency, t)；硬门 kc_tc = (ε_flow ≤ τ_flow) ∧ (ε_pose ≤ τ_pose) ∧ (latency ≤ τ_lat)。
3. 定义证书有效期 τ_exp(v_max, a_max, δ_safe) = min(τ_max, (−v+√(v²+2aδ))/a)，以及陈旧证书失效规则；证明帧采样管线在高速下可能放行不合法证书，事件驱动监控可收紧。
4. 定义连续时间监控器 Always(kc, E, t0, t1)，把 □_T 落地为事件间隔约束（证据空窗 > g_max 即拒绝），并给出检测延迟界。
5. 定义 EFA-v5 九硬门与软评分 ECS_v5 = ECS_v4 · η_det · η_tc，其中 η_det = conf，η_tc = clip(1 − ε_flow, 0, 1)。
6. 证明 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 且严格，并给出检测身份切换界与事件-运动学一致性界。
7. 定义静态盲区回退：事件率 r < r_min 时切帧检测，但把 source='frame' 与放大后的 τ_exp 写入 DC，保证诚实降级而非假装新鲜。

**本轮最大风险**：**事件相机对静态场景「无事件即无感知」的物理盲区**——当机器人与目标近乎静止时事件率趋零，事件检测器没有输入，语义锚反而失效；同时事件数据缺乏绝对亮度/颜色/纹理，事件目标检测的语义能力与成熟度远低于帧检测，混合融合又引入事件-帧标定与时间同步误差。若处理不当，v5 新增的两道硬门在慢速/静态操作中会退化为频繁回退甚至误拒，收益被抵消。

## 2. 关键算法骨架

### IP-493 EODK：事件目标检测核（跟踪时，事件路径 ~1–5 ms；静态回退帧 ~10–30 ms）

```python
@dataclass
class EventObjectDetectionKernel:
    """EODK：事件驱动异步检测 + 身份连续跟踪；kc_det 硬门"""
    tau_det: float = 0.70          # 置信度阈值
    tau_switch: float = 0.15       # 身份切换概率阈值
    tau_amb: float = 0.10          # 位姿歧义边际
    r_min: int = 5000              # 静态盲区回退事件率阈值 (ev/s)
    detector: Any = None           # 事件检测器（RVT/事件Transformer/脉冲网络）
    tracker: Any = None            # 异步关联 + 卡尔曼/粒子跟踪
    frame_detector: Any = None     # 帧检测器（回退）

    def detect(self, events: EventStream, frame: Optional[np.ndarray],
               t_now: float) -> DC:
        # 1) 事件驱动：只在事件到达时增量更新，稀疏计算
        if events.rate(t_now) >= self.r_min:
            surf = events.time_surface(t_now)
            dets = self.detector(surf)
            source = 'event'
            tau_exp_scale = 1.0
        else:
            # 2) 静态盲区诚实回退：无事件 → 帧检测，且放大有效期
            dets = self.frame_detector(frame) if frame is not None else []
            source = 'frame'
            tau_exp_scale = self.frame_staleness_scale   # 约 Δt_frame/τ_max
        # 3) 异步跟踪：关联 + 身份连续性统计
        trk = self.tracker.update(dets, events, t_now)
        return DC(cls=trk.cls, pose6d=trk.pose, conf=trk.conf,
                  track_id=trk.id, switch_prob=trk.switch_prob,
                  pose_amb=trk.pose_amb, source=source,
                  event_rate=events.rate(t_now), t=t_now,
                  tau_exp_scale=tau_exp_scale)

    def kc_det(self, dc: DC) -> bool:
        """引理 43：通过 ⟹ 检测实例身份在时窗内连续且位姿可分辨"""
        return (dc.conf >= self.tau_det
                and dc.switch_prob <= self.tau_switch
                and dc.pose_amb >= self.tau_amb)
```

### IP-494 ETCK：事件-运动学一致性核（控制环内，目标 < 0.5 ms）

```python
@dataclass
class EventTemporalConsistencyKernel:
    """ETCK：事件光流 vs 运动学预测光流 vs 帧检测位姿；kc_tc 硬门"""
    tau_flow: float = 0.20
    tau_pose: float = 0.02         # m / rad
    tau_lat: float = 0.005         # s
    max_iter: int = 3              # 对比度最大化迭代上限（早停）

    def verify(self, events: EventStream, dc: DC,
               qd: np.ndarray, J: np.ndarray, kin_pose: Pose,
               t_now: float) -> TCC:
        # 1) 事件光流：对比度最大化 / 时间表面梯度（仅活跃像素，O(N_ev)）
        u_ev = self._event_flow(events, t_now, iters=self.max_iter)
        # 2) 运动学预测光流：u_kin = J(q) q̇ 投影到像平面
        u_kin = self._project(J @ qd, dc.pose6d, self.camera_model)
        eps_flow = self._flow_residual(u_ev, u_kin)
        # 3) 位姿一致性：检测位姿 vs 运动学预测位姿
        eps_pose = self._pose_residual(dc.pose6d, kin_pose)
        # 4) 数据新鲜度：最后一个事件到现在的延迟
        lat = t_now - events.last_ts
        return TCC(eps_flow=eps_flow, eps_pose=eps_pose,
                   hdr_margin=events.hdr_margin, latency=lat, t=t_now)

    def kc_tc(self, tcc: TCC) -> bool:
        """引理 44：通过 ⟹ 感知运动与物理运动在阈值内自洽"""
        return (tcc.eps_flow <= self.tau_flow
                and tcc.eps_pose <= self.tau_pose
                and tcc.latency <= self.tau_lat)
```

### IP-495 CTEM：连续时间证据监控（把 □_T 落地；O(N_ev)）

```python
@dataclass
class ContinuousTimeEvidenceMonitor:
    """CTEM：在事件流上验证 Always(kc)；证书有效期与陈旧失效"""
    g_max: float = 0.005           # 最大证据空窗 (s)
    tau_max: float = 0.050         # 有效期上限 (s)

    def always(self, kc_fn, events: EventStream, t0: float, t1: float) -> bool:
        # 事件时刻逐点检查 + 空窗检查；空窗超 g_max 即不可证（fail-closed）
        last = t0
        for e in events.window(t0, t1):
            if e.t - last > self.g_max:
                return False
            if not kc_fn(e):
                return False
            last = e.t
        return (t1 - last) <= self.g_max

    def validity_horizon(self, v: float, a: float, delta_safe: float) -> float:
        # 位移 d(Δ)=vΔ+0.5aΔ² ≤ δ_safe 的最大 Δ
        if a <= 1e-9:
            delta = delta_safe / max(v, 1e-9)
        else:
            delta = (-v + math.sqrt(v * v + 2 * a * delta_safe)) / a
        return min(self.tau_max, delta)

    def admissible(self, cert_time: float, t_now: float,
                   v: float, a: float, delta_safe: float) -> bool:
        # 陈旧证书失效：超过有效期即拒绝（fail-closed）
        return (t_now - cert_time) <= self.validity_horizon(v, a, delta_safe)
```

### IP-496 EFA-v5：九硬门 + 软评分 + 证据铸造流水线 v5

```python
@dataclass
class EvidenceForgingAssemblerV5:
    """EFA-v5：九硬门 fail-closed；ECS_v5 = ECS_v4 · η_det · η_tc"""
    scf: SpatialCoverageFieldKernel
    msrg_cache: dict
    hic: HumanIntentCertificateKernel
    eek: EndEffectorFidelityKernel
    ltem: LongTermEpisodicMemory
    vack: ValueAlignmentCertificateKernel
    bck: BalanceControlKernel
    eodk: EventObjectDetectionKernel
    etck: EventTemporalConsistencyKernel
    ctem: ContinuousTimeEvidenceMonitor
    mu_S: float = 0.75
    w: tuple = (0.4, 0.4, 0.2)

    def hard_gate(self, x, t_now, rule_id, hic, eec: EEC, bcc: BCC,
                  dc: DC, tcc: TCC, object_class, geo_sig,
                  theta_domain_fp, traj, context) -> tuple[bool, str]:
        # 优先级：HIC veto 最高；其余八硬门并行评估，任一失败即拒
        if self.hic.veto_active(hic):            return False, 'HIC_STOP'
        if not self.scf.kc_coverage(x, t_now):   return False, 'COVERAGE_BLIND'
        if not self.eodk.kc_det(dc):             return False, 'DETECTION_UNGROUNDED'
        if not self.etck.kc_tc(tcc):             return False, 'TEMPORAL_INCONSISTENT'
        s2rc = self.msrg_cache.get(rule_id)
        if s2rc is None or s2rc.verdict != 'accept' or s2rc.mu_pass < self.mu_S:
            return False, 'PHYSICS_UNPROVEN'
        if not self.eek.kc_ee(eec):              return False, 'EE_UNPROVEN'
        if not self.bck.kc_bal(bcc):             return False, 'BALANCE_UNSTABLE'
        pass_mem, eta_mem, novelty = self.ltem.query(object_class, geo_sig, theta_domain_fp, rule_id)
        if not pass_mem:                         return False, 'MEMORY_REJECT'
        vac = self.vack.evaluate(traj, context, t_now)
        if not self.vack.kc_val(vac):            return False, 'VALUE_MISALIGNED'
        return True, 'FORGED' + ('|NOVELTY' if novelty else '')

    def ecs_v5(self, x, t_now, rule_id, A_att=0.0, eta_mem=0.5,
               eta_val=0.5, eta_bal=0.5, eta_det=0.5, eta_tc=0.5) -> float:
        base = (self.scf.gamma3d(x, t_now)**self.w[0]
                * getattr(self.msrg_cache.get(rule_id), 'mu_pass', 0.0)**self.w[1]
                * (1 + self.w[2]*A_att))
        return base * eta_mem * eta_val * eta_bal * eta_det * eta_tc
```

### 集成流水线（v4 → v5）

```
离线/慢时域（FFA + 价值/平衡/感知先验学习，不在控制环）：
  各站 i：本地 Δ_i (3DCF/SPRT/末端力/手势/价值偏好/平衡统计/事件检测类别/身份切换率)
       ──▶ DP 扰动 ──▶ 安全聚合 ──▶ 服务器 FedAvg ──▶ Φ_global
       ──▶ 下发：Γ_3D 先验、Θ_domain 校准、手势先验、价值 λ_vec^0、平衡 W^0/ZMP^0、
                  事件相机内参/噪声先验、检测类别先验

在线感知（事件驱动，~1–5 ms；静态回退帧）：
  EODK.detect(E, frame, t) ──▶ DC ──▶ kc_det
       └─ 静态盲区 r<r_min ──▶ 帧回退，source='frame'，放大 τ_exp
```

## 3. 复杂度分析（增量更新）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 | 实时性指标 |
|---|---|---|---|---|
| EODK 事件检测/跟踪 | O(N_ev + N_det·N_trk) 稀疏 | O(N_ev 窗口) | N_ev=事件数, N_det=检测数 | ~1–5 ms（GPU/轻量网络） |
| EODK 静态帧回退 | O(H·W) | O(H·W) | 仅在 r<r_min 时触发 | ~10–30 ms（静态/慢速，可容忍） |
| EODK kc_det | **O(1)** | O(1) | — | < 0.01 ms |
| ETCK 事件光流 | O(N_ev·max_iter) 稀疏，早停 | O(N_ev 窗口) | max_iter ≤ 3 | ~0.1–0.5 ms |
| ETCK kc_tc | **O(1)** | O(1) | — | < 0.01 ms |
| CTEM Always | O(N_ev 窗口) | O(1) | g_max=5 ms | < 0.1 ms |
| CTEM validity_horizon | **O(1)** | O(1) | — | < 0.001 ms |
| EFA-v5 硬门 | **O(1)** | O(1) | — | < 0.03 ms（不含观测） |
| 端到端在线增量（含 EODK/ETCK 观测） | ~1–6 ms | — | — | 事件路径可满足 1 kHz；帧回退路径不满足 |

**通信开销**：DC 证书仅跟踪/准入时产生（事件驱动，非固定频率）；TCC 每周期仅在异常时上报（正常时本地聚合为统计量），~200 B/异常；CTEM 只上传有效期违约计数；FFA Δ_i 扩充至 ~6–12 KB/站点；原始事件流不离站（只上传统计量与先验）。

**实时性缓解**：
- EODK 事件路径稀疏计算，只处理活跃像素；轻量检测器 + 跟踪复用上一帧特征。
- ETCK 光流只在小 ROI（检测框）内计算，迭代早停。
- 静态回退与 1 kHz 控制环解耦：帧检测异步在感知线程，控制环只读最近 DC 并检查其 τ_exp 是否过期。
- CTEM 的 g_max 与 τ_exp 由运动速度自适应：高速时收紧，低速时放宽。

## 4. 正确性论证（增量更新）

### 引理 43（检测身份切换界）

**陈述**：设正确目标与干扰实例的特征/位姿间隔为 Δ，单次关联的噪声标准差为 σ，单次误关联概率 p = Q(Δ/(2σ))（高斯尾）。在时窗 T_id 内共 n 次独立关联，kc_det 要求经验切换率 switch_prob ≤ τ_switch。则当 τ_switch > p 时，错误接受（真实切换率 > τ_switch 却通过）的概率 ≤ exp(−2n(τ_switch − p)²)。

**证明**：每次关联是独立的伯努利误关联，经验均值以 Hoeffding 不等式集中于 p；kc_det 通过意味着经验切换率 ≤ τ_switch，若真实切换率高于 τ_switch，则需经验值大幅低估，其概率由 Hoeffding 界给出。∎

**工程含义**：kc_det 不只是「置信度够高」，还要求「身份在时窗内连续」。延长 T_id 或增大实例间隔 Δ 都能指数级压低身份切换的误接受率。

### 引理 44（事件-运动学一致性界）

**陈述**：对刚性运动，事件光流满足 u_ev = u_kin + n，其中 ‖n‖ ≤ σ_ev + ε_model（事件噪声 + 模型误差）。若检测位姿误差为 δ_pose，则诱导的光流差异至少为 c·δ_pose/Δt（c 为投影常数）。kc_tc 通过（ε_flow ≤ τ_flow）即排除位姿误差 δ_pose > τ_flow·Δt/c 的错误检测，误接受概率 ≤ 1 − δ（由噪声尾界）。

**证明**：三角不等式 ‖u_ev − u_kin‖ ≥ ‖u_true − u_kin‖ − ‖n‖；当检测位姿偏离真实位姿 δ_pose，u_true 与 u_kin 的差异正比于 δ_pose/Δt；阈值 τ_flow 大于噪声界时，错误检测的残差以高概率超阈。∎

**工程含义**：这是「感知—物理」的交叉验证：错误检测、错误关联、标定漂移、动力学失配都会表现为事件光流与运动学预测的矛盾，从而被 kc_tc 统一拦截。

### 定理 5（证书时间有效性与陈旧性界）

**陈述**：设证书在 t 铸造，执行时刻 t′，末端/目标最大速度 v、加速度 a，安全裕度 δ_safe。则：
(i) 证书对 t′ 合法仅当 t′ − t ≤ τ_exp(v,a,δ_safe) = min(τ_max, (−v+√(v²+2aδ_safe))/a)（a=0 时为 δ_safe/v）。
(ii) 帧采样管线的证书最坏陈旧度为 Δt_frame（或 Δt_frame/2，取决于采样相位），若 v·Δt_frame > δ_safe，则存在执行使证书已陈旧却被接受。
(iii) 事件驱动 CTEM 在最大证据空窗 g_max ≤ τ_exp/κ 时提供连续时间可靠性：在有效期内要么证据被刷新、要么拒绝；检测延迟 ≤ g_max。

**证明**：(i) 由位移运动学 d(Δ)=vΔ+0.5aΔ² ≤ δ_safe 解出 Δ 上界。(ii) 帧采样只能保证在采样时刻合法，采样间隔内位移可达 v·Δt_frame，超过 δ_safe 即失效。(iii) CTEM 对每个事件时刻及空窗逐点验证，空窗超过 g_max 即 fail-closed；事件到达使刷新间隔以 1/r 量级逼近 0，故 t′ 的有效性可被连续证明。∎

**工程含义**：这把 v4 的实时性风险量化为「证书有效期」问题，并说明事件相机不是单纯提升精度，而是把「证据的新鲜度」变成可计算、可拒绝的一等公民。

### 定理 6（v5 执行集严格收缩与九锚点完备）

**陈述**：在 (B1)~(B6)（继承 v4）之外追加：(B7) 事件检测器在事件率 ≥ r_min 时校准可靠；(B8) 事件-帧时间同步误差 ≤ τ_sync。则：
(i) Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29（严格收缩）；
(ii) 身份切换误接受率由引理 43 界；
(iii) 感知-物理不一致通过率由引理 44 界；
(iv) 陈旧证书通过率由定理 5 界；
(v) 九锚点 {3DCF, MSRG, HICK, EEK, LTEM, VACK, BCK, EODK, ETCK} 互补完备：去 EODK 无法排除「覆盖正确但对象错误」，去 ETCK 无法排除「对象正确但证据陈旧/运动矛盾」；
(vi) 静态盲区（r<r_min）下 kc_det 的保证退化为帧检测保证，且 τ_exp 按 source='frame' 放大，故不假装新鲜。

**证明**：(i) v5 在 v4 每条执行路径上追加 kc_det（准入/跟踪）与 kc_tc（控制环内），只缩不涨；两硬门非恒真（构造误检/矛盾光流即拒）保证严格。(ii)(iii)(iv) 分由引理 43、44、定理 5。(v) 逐锚点构造反例（风险表 R53~R58）。(vi) 由 EODK 的 source 标记与 CTEM 的 τ_exp 放大规则直接得出。∎

**诚实声明**：(B7) 事件检测器的语义能力目前弱于帧检测，且在静态场景无事件输入，故 kc_det 的强保证只在「动态 + 事件率充足」时成立；(B8) 事件与帧的硬件同步误差、事件相机内参标定误差会直接进入 ε_flow。缓解：混合检测（事件为主、帧为辅）、在线时空标定、把 source 与 τ_exp_scale 写入证书以便下游按证据等级降级使用。

## 5. 实验设计与初步结果（计划中，第 5~6 轮实机）

### 5.1 实验设计

- **平台**：MuJoCo/MJX + v2e/ESIM 事件合成（仿真）+ N 台实机 Panda（N=3~5）+ 事件相机（Prophesee EVK4 / DVS346）+ 同轴 RGB + 人类偏好标注平台。
- **对照**：v4-full、v5-full、消融 A1（去 EODK，退化 3DCF 几何覆盖）、A2（去 ETCK，退化静态阈值）、A3（去 EODK+ETCK，纯 v4）、A4（事件检测仅用帧回退）、A5（事件光流替换为帧光流）。
- **协议**：
  (a) 高速抓取：末端速度 1–3 m/s，触发运动模糊，测帧检测失效而事件检测可用；
  (b) 极端光照：强反光/逆光（>120 dB 场景）与低照度（<1 lux）；
  (c) 语义混淆：对称/透明/相似实例，测身份切换；
  (d) 静态盲区：目标静止 2 s 以上，测事件率下降与回退率；
  (e) 感知-物理矛盾注入：故意错标定、错误检测，测 kc_tc 拦截率；
  (f) 陈旧性压测：不同速度下证书 P99 陈旧度、τ_exp 违约率；
  (g) 联邦异构：站点感知条件不同（光照/相机型号），测检测先验收敛与负迁移。
- **指标**：检测 mAP/召回、身份切换率、6D 位姿误差、事件-运动学残差分位数、陈旧证书率、静态回退率、任务成功率、安全违例率、ECS_v5 与失败 AUC、控制环延迟 P99/P99.9、丢帧率。

## 7. 本轮最大风险（最终确认）

**一句话**：**事件相机对静态场景「无事件即无感知」的物理盲区**——当机器人与目标近乎静止时事件率趋零，事件检测器没有输入，语义锚反而失效；同时事件数据缺乏绝对亮度/颜色/纹理，事件目标检测的语义能力与成熟度远低于帧检测，混合融合又引入事件-帧标定与时间同步误差。若处理不当，v5 新增的两道硬门在慢速/静态操作中会退化为频繁回退甚至误拒，收益被抵消。
