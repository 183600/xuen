# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 4 轮；本轮灵感：「LoRA」×「视觉语言动作模型」）

> 第 57 轮把安全的赌注从"证据质量"再往前推了一层——用跨区域摊销的元先验 q_φ + 共形保底 + 跨模态对账 + 个性化信任状态机，把"少样本可校准、跨模态可对账、个性化有界"写进了证据门；但它自己的风险自陈暴露了一个结构性缺陷：**所有安全都押在一个"整体式先验"上**——q_φ 是一个不可分解的黑箱，一旦它在某个方向系统性错误，OOD 门与共形带只能"整块退回"，无法指出"是哪一块先验错了"，于是坏先验会**普遍**污染，而不是局部污染。本轮两个灵感各给一刀：**LoRA** 把整体式先验拆成"冻结的语义底座 + 可组合的低秩适配器"，让先验**可分解、可归因、可拆卸、且容量有预算**——安全不再问"先验好不好"，而问"任何单一先验最多能污染多少维、能否被单独摘除"；**视觉语言动作模型（VLA）** 把语言提升为一等公民——它既是**可验证的任务契约**（自然语言指令解析为形式约束），又是**语义先验的来源**，但语义先验只提供"看起来像什么"，永不提供"概率是多少"。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"可组合、可归因、语言落地（且语义永不替代物理）的证据说可信"**。

核心矛盾：
- **H29（容量 vs 安全）**：低秩适配器用极小容量撬动巨大底座，效率极高；但秩 r 本身就是"可注入的自信维度"——r 越大越能拟合，也越能过拟合、越容易被污染；多个适配器叠加会互相干扰（composition interference），秩预算耗尽后必须驱逐，驱逐即遗忘。
- **H30（语言 vs 落地）**：VLA 的语言先验流畅、组合性强、能听懂"别踩看起来湿的东西"；但"说得对"不等于"做得对"，语言头与动作头共享同一底座时，二者**天然自洽**——自洽不等于正确，语义一致性若来自同一个模型，就不是证据而是回音。
- **H31（个性化 vs 容量授权）**：第 57 轮的个性化只参数化"佐证数量与时延"；一旦个性化升级为"给某人多少秩"，信任越高容量越大，被博弈时的污染面也越大——但可拆卸适配器同时提供了一种前几轮没有的**可逆性**：污染可以只摘一块，而不必回滚全局。

## 0. 直觉与动机

**灵感 1（LoRA → 冻结底座 + 可组合低秩适配，先验从"一个黑箱"变"一叠卡片"）**
直觉：第 57 轮的 q_φ 像一位通才老师，什么都懂一点，但你无法知道他哪句话是"通用常识"、哪句话是"在某块冰面上学到的偏见"。LoRA 的启发是：**别改老师本人（冻结底座 θ₀），只给每位学生发一叠小卡片（低秩适配器 ΔW_i=B_iA_i，秩 r_i）**，卡片可叠加、可单抽、可作废。于是先验被分解为"通用物理直觉（底座）+ 若干站点/季节/材质/操作者的专用偏移（适配器）"。三个安全红利随之而来：**(a) 容量预算**——r_i≤r_max 是"任何单一偏移最多能改多少维"的硬界，坏卡片改不动高维结构；**(b) 归因**——每条承诺可归因到"哪几张卡片贡献了多少"，证伪时只摘涉事卡片（unmerge），底座不动，从而把第 57 轮"坏先验普遍"降级为"坏卡片局部"；**(c) 组合可控**——适配器冲突度（interference）可测，冲突超阈即强制加宽或禁用，避免两张卡片相互放大错误。

**灵感 2（VLA 语言 → 可验证契约 + 语义先验，但语义永不冒充概率）**
直觉：语言是唯一能低成本表达"组合式约束"的接口——操作者一句"只在承重面上落脚、别碰看起来湿的区域"，就同时给了目标、禁忌与偏好。VLA 让语言与动作共享隐空间，于是指令可以被**解析成形式安全契约**（时序/几何约束），动作可被**逐条核对**。但这里必须划一条红线：VLA 输出的是**语义**（"这是干燥的、承重的"），不是**校准概率**。语义可以**提高警惕**（发现"看起来湿"就降档/绕行/发问），但绝不允许**降低警惕**（语义说"没事"不能替代物理探针）。我们把这条写成单向性：**语义只踩刹车，不踩油门**。

**灵感 3（VLA 语言 × 物理探针 → 语义-物理落地检查 SGC，专治语义过度自信）**
直觉：语言模型的自信是"措辞的自信"，不是"世界的自信"。要检验语义是否落地，必须拿它与一个**独立物理通道**对照：VLA 说"承重"，力探针测 F_bear；VLA 说"干燥"，摩擦探针测 μ。二者一致 → 语义可作 L1 的必要佐证；二者分歧 → 语义过度自信被捕获，强制加宽或转物理实证。关键设计是**独立性**：落地检查的物理通道必须与 VLA 语义头不共享底座，否则"语言头 + 动作头同源"会制造**同源共谋**——模型自己跟自己一致，检查退化为回音。

**灵感 4（LoRA × 个性化 → 容量即信任，但容量必须可审计、可撤销）**
直觉：第 57 轮的授权只决定"要不要多要一份佐证"；本轮把授权升级为"**能注入多大秩、能启用哪类适配器**"——A0 只能确认不能造卡片，A1 可注入低秩卡片，A2 可注入较高秩卡片；但每张卡片必须携带**出处（谁的数据、多少样本、held-out 校准）**，操作者一旦被降级，其卡片立即隔离并可回溯摘除。这让"信任"第一次与"模型容量"直接挂钩，也让"撤销信任"第一次等于"精确摘除影响"，而不必全局回滚。

**灵感 5（合流 → 证据门从五类到七类，安全从"整块退回"到"局部摘卡"）**
直觉：第 57 轮证据门 EV-probe*/visit/margin/xmodal/human 本轮再加两类：**EV-adapter**（承诺须由带秩预算/支撑集/校准声明的适配器背书）与 **EV-lingual/EV-ground**（语言契约符合性与语义-物理落地一致，均**仅限 L1 且仅作必要非充分条件**）。击穿安全从"元先验错 ∧ OOD 漏检 ∧ …"变成还要"**底座本身在高维方向系统性错 ∧ 低秩卡片无法纠正 ∧ 独立物理通道也同向错 ∧ 语言契约也误解析**"——纵深从五层到七层。同时承诺失败从"全局退回"细化为"**精确摘卡**"：可归因、可撤销、可重放。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（语义低秩适配 SLA）** 冻结底座 θ₀；适配器族 𝒜={A_i=(B_i,A_i,r_i,spt_i,ece_i,src_i)}，ΔW_i=B_iA_i∈ℝ^{d×r_i}·ℝ^{r_i×d}，秩预算 r_i≤r_max。组合参数 θ=θ₀+Σ_i α_iΔW_i，α_i∈[0,1] 为门控。**支撑证书** spt_i=（训练覆盖的区域/季节/材质簇、样本数 n_i、held-out ECE_i）；**可拆卸性**：unmerge(i) 精确恢复 θ₋ᵢ=θ−α_iΔW_i（底座不参与更新，无灾难性遗忘）。**干扰度** I(i,j)=‖ΔW_iΔW_j^⊤‖_F/(‖ΔW_i‖_F‖ΔW_j‖_F)；I(i,j)>θ_I ⇒ 两卡冲突，禁止同时以 α=1 激活（强制加宽或二选一）。归因：承诺 c 的先验贡献分解为 φ_c=Σ_i attr_i(c)，attr_i 可审计。

**定义 140（语言落地契约 LGC）** 指令 u 经约束语义解析器得 (𝒞,𝒜𝓂𝒷)：𝒞 为形式安全契约（时序/几何/语义约束集），𝒜𝓂𝒷 为歧义集（多种可行解析）。**解析健全性**：真实意图 ∈ 解析集 w.p. ≥1−δ_parse。若 |𝒜𝓂𝒷|>1 或 parse_conf<θ_pc ⇒ 不承诺，发**澄清探针**（向人发问或指向歧义对象）。动作 a 对契约 𝒞 的符合性 conf(a,𝒞)∈{pass,violate,unknown}；unknown 视同 violate（保守默认）。**语言不生成概率**：conf 只用于阻断，不用于放行不可逆接触。

**定义 141（语义-物理落地检查 SGC）** 语义预测 ŷ_sem(r)（VLA 语言/affordance 头）与独立物理后验 θ_phys(r)（探针实测 μ,k,F_bear）。**落地残差** G(r)=D(ŷ_sem(r), π(θ_phys(r)))，其中 π 把物理参数投影到语义标签空间（干燥/承重/可通行）。**语义-物理校准误差** SPCE=E[|P(sem=ŷ)−1[phys=ŷ]|]。三规则：(G1) G(r)>θ_G ⇒ 判语义过度自信，P_fail 以物理后验为准并加宽，语义不得作任何放行证据；(G2) G(r)≤θ_G ∧ SPCE≤ε_spce ⇒ 语义可作 **EV-ground**，仅限 L1 且仅作必要佐证；(G3) 独立性：θ_phys 通道与 VLA 语义头不共享底座参数（否则拒发 EV-ground，标记 `same_base_collusion`）。

**定义 142（容量审计个性化 CAP）** 升级第 57 轮 PTM：s_o=(cal,vig,auth) 之外，授权参数化**可注入秩上限** rank\*(auth)（A0=0/A1=r_low/A2=r_high≤r_max）与**可启用适配器族** fam\*(auth)。适配器出处 src_i 必须绑定操作者 op_i 与其 held-out 校准；op_i 降级 ⇒ 其全部适配器进入隔离区（α_i=0 且回溯标记由 attr_i 背书的承诺）。单向有界不变：升级需 n_verify≥N_up(A) ∧ cal≥θ_cal(A) ∧ 速率≤Δ_auth/T；降级实时；rank\* 与全局 r_max 均不可被个性化突破。

**定义 143（可组合适配器证据门 CAG 与证书 J_L）** 证据类 EV-probe\*/visit/margin/xmodal/human 继承第 57 轮，新增 **EV-adapter**（承诺由适配器背书且 r_i≤rank\*(auth) ∧ spt_i 覆盖该区域 ∧ ECE_i≤ε_adapter）与 **EV-lingual/EV-ground**（均限 L1、仅必要非充分）。不可逆接触必要证据集={EV-probe*∨EV-margin∨EV-adapter}∪佐证，**不含** EV-lingual/EV-ground/EV-xmodal。冲突检查：若涉事适配器间 I>θ_I 且未加宽 ⇒ 拒。J_L=(J_p 全量, adapter_registry, rank_budget_usage, attr_trace, contract_parse_log, ambiguity_log, grounding_residual_log, spce_log, provenance_log, collusion_flags)。

**定义 144（探-语言-组合算子 PLC / PCE++）** 每检查点：①语义推断（冻结底座 + 激活适配器，带秩预算）；②语言契约：解析 u→(𝒞,𝒜𝓂𝒷)，歧义即发澄清探针；③落地检查：G(r)>θ_G 或 same_base_collusion ⇒ 语义失权、转物理；④承诺 ⇔ ∃g:R≤δ_f(g) ∧ CAG 过；否则选 argmax_π[VOI_元悲观(π)−cost(π)]≥θ_voi，动作集新增**澄清探针**（问人）、**换卡探针**（切换适配器重估）、**落地探针**（物理验证语义声明）；探尽→绕行→降档→L2 协商或安全停。

## 2. 关键算法伪代码（完整版见产物区）

```python
def sla_forward(x, base, adapters, auth):          # IP-139/142: 容量受控组合
    active = [a for a in adapters if a.enabled and a.rank <= rank_star(auth)
              and not conflicts(a, active_set(adapters))]
    theta = base.theta0
    for a in active:
        theta = theta + a.alpha * (a.B @ a.A)      # 低秩叠加
    return theta(x), attr_trace(active)

def language_contract(u, parser):                  # IP-140: 歧义即问，不赌
    C, amb = parser.parse(u)                       # 约束集 + 歧义集
    if len(amb) > 1 or parser.conf(u) < theta_pc:
        return None, clarify_probe(amb)            # 发澄清探针
    return C, None

def grounding_check(sem, phys, independent):       # IP-141: 语义只踩刹车
    if not independent: return ('no_ev', 'same_base_collusion')
    G = D(sem.label, project(phys))
    if G > theta_G or spce(sem) > eps_spce:
        return ('widen_phys', 'semantic_overconfident')  # 语义失权
    return ('EV-ground', 'ok')                     # 仅 L1 必要佐证
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| SLA | O(Σ r_i·d)/前向；unmerge O(r_i·d) | O(Σ r_i·d) | 秩预算 r_max、支撑证书诚实、unmerge 精确 |
| LGC | O(parse(u)) | O(\|𝒞\|) | 解析健全性 ≥1−δ_parse、歧义即拒 |
| SGC | O(d_sem+d_phys) | O(1) | 物理通道独立、单向（只加宽） |
| CAP | O(1)+O(H_op) | O(\|op\|·\|𝒜\|) | rank\*≤r_max、出处可审计、降级即隔离 |
| CAG | O(\|σ\|·\|𝒜\|²) | O(\|σ\|) | 冲突即拒、语义类不进不可逆证据集 |
| PLC | O(\|CP\|·(k_p+k_c+k_cl)·(C_VOI+Σr_i d)) | O(\|V\|+\|𝒜\|) | 悲观 VOI、k_p+k_c+k_cl 终止 |

**正确性定理（Composable Grounded Soundness, CGS 概要）**：在 A37–A40 上加 (A41) 底座冻结且 unmerge 精确、r_i≤r_max、支撑证书与 ECE 声明诚实；(A42) 语言解析健全（真实意图入解析集 ≥1−δ_parse），歧义即拒；(A43) 落地检查物理通道与语义头不共享底座、单向加宽；(A44) 适配器出处审计完备、授权只动 rank\*/fam\* 且不破 r_max。则：(i) 可归因承诺失效率 ≤δ_f+ε_meta(k)+ε_adapter+δ_probe+ε_h，其中坏卡片贡献被 attr_i 局部化；(ii) 语义放行风险为零（EV-lingual/EV-ground 不进不可逆必要集且只加宽），同源共谋被 G3 硬禁；(iii) 交互单调性延续：适配器组合、语言、落地只经"信念更准（含加宽）"或"动作更保守"起作用；(iv) PLC 在 k_p+k_c+k_cl 内终止。

## 6. 本轮最大风险

**一句话**：本轮把安全建立在"冻结底座 + 低秩卡片可局部摘除"上，但底座是所有卡片、也是 VLA 语言头与动作头的**共同祖先**——若底座在某个高维方向上系统性错误，低秩卡片改不动它、语言头还会生成与错误动作**自洽**的合理说辞，于是"语义-物理落地"若不使用真正独立的物理通道就会退化成模型的自言自语；必须以"语义只踩刹车、物理才踩油门、独立通道才发 EV-ground"三重硬约束，把最深的赌注留给世界本身而不是任何一个模型。

## 2. 关键算法伪代码

### IP-139 SLA（语义低秩适配，容量受控且可拆卸）

```python
def sla_compose(x, base, adapters, auth, region):
    active = []
    for a in adapters:
        if not a.enabled: continue
        if a.rank > rank_star(auth): continue            # 授权容量硬界
        if not covers(a.spt, region): continue           # 支撑证书覆盖
        if any(interference(a, b) > theta_I for b in active):
            continue                                     # 冲突卡不同时满权
        active.append(a)
    theta = base.theta0
    for a in active:
        theta = theta + a.alpha * (a.B @ a.A)            # 低秩叠加，底座冻结
    return theta, AttrTrace(active)                      # 可归因

def sla_detach(base, adapters, i):                       # 精确摘卡
    adapters[i].enabled = False; adapters[i].alpha = 0.0
    return base.theta0 + sum(a.alpha*(a.B@a.A) for a in adapters if a.enabled)

def sla_certificate(a, region):
    return dict(rank=a.rank, n=a.spt.n, ece=a.ece,
                covers=bool(covers(a.spt, region)), src=a.src)
```

def semantic_physical_grounding(sem, phys, independent):
    if not independent:
        return ('no_ev', 'same_base_collusion')          # 同源共谋硬禁
    G = divergence(sem.label, project_to_semantics(phys)) # 落地残差

### IP-143 CAG（可组合适配器证据门 + 证书 J_L）

```python
def composable_evidence_gate(c, M, persona, adapters, ood_reg, contract, ground):
    if c.ev == 'EV-adapter':
        a = c.adapter
        ok = (a.rank <= rank_star(persona[c.op].auth)
              and covers(a.spt, c.region) and a.ece <= eps_adapter
              and not conflicting_active(a, adapters, theta_I))
    elif c.ev in ('EV-lingual', 'EV-ground'):
        ok = c.level == 'L1'                             # 仅非不可逆
        if c.ev == 'EV-lingual': ok &= (contract == 'pass')
        if c.ev == 'EV-ground':  ok &= (ground == 'EV-ground')
    elif c.ev == 'EV-probe*':
        ok = (c.inf.cls == 'ID' and c.inf.ece_k <= eps_meta(c.k)) or \
             (c.inf.cls == 'OOD' and c.region in ood_reg.certified)
    elif c.ev == 'EV-xmodal':
        ok = c.level == 'L1' and c.indep_declared and D(c.region) <= theta_D
    elif c.ev == 'EV-human':
        ok = persona[c.op].auth >= 'A1' and \
             c.corrob >= quarantine_exit(persona[c.op].auth)
    elif c.ev in ('EV-visit', 'EV-margin'):
        ok = round56_checks(c, M)
    else:
        return ('reject', 'no_evidence_class', c)
    if not ok: return ('reject', 'evidence_insufficient', c)
    if c.irreversible and c.ev in ('EV-xmodal', 'EV-lingual', 'EV-ground'):
        return ('reject', 'semantic_or_xmodal_on_irreversible', c)  # 硬禁令
    return ('ok', c)

def certificate_L(sched, log, M, adapter_reg, contract_log, ground_log,
                  spce_log, provenance_log, collusion_flags):
    for c in contacts(sched):
        st = composable_evidence_gate(c, M, persona_of(c), adapter_reg,
                                      ood_reg, contract_of(c), ground_of(c))
        if st[0] != 'ok': return st
    if min(x.K_margin for x in sched) < budgets.theta_K: return ('reject', 'K_margin')
    if rho_sem(sched, M) < budgets.rho_min:              return ('reject', 'rho_sem')
    if any(collusion_flags.values()):                    return ('reject', 'collusion')
    return ('ok', JL(core_contacts(sched), adapter_reg, rank_budget_usage,
                     attr_trace, contract_log, ambiguity_log,
                     ground_log, spce_log, provenance_log))
```

### IP-144 PLC（探-语言-组合算子，PCE++）

```python
def probe_language_compose(x0, M, task, budget, consent, personas, adapters):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        theta, attr = sla_compose(M.state(cp.region), base, adapters,
                                  personas.active.auth, cp.region)
        sem = semantic_head(theta, cp)                   # VLA 语义/affordance
        C, amb, pst = parse_instruction(cp.instruction, parser)
        if pst == 'clarify':                             # 歧义即问
            r = execute_probe(make_clarify_probe(amb, M), budget.k_cl)
            C, amb, pst = parse_instruction(r.answer, parser)
            if pst == 'clarify': return negotiate_or_stop(cp, M, None, None, consent)
        sigma = foothold_schedule(x0, cp, M); R = schedule_risk(sigma, M)
        while select_gait(R) == 'halt' and budget.probes_left > 0:
            cands = admissible_probes(cp, M, F_abs)
            if not cands: break
            p = argmax(cands, key=lambda q: voi_meta_pessimistic(q, M, sem) - cost(q))
            if voi_meta_pessimistic(p, M, sem) < theta_voi: break
            M, _, D = xmodal_fuse(M, cp.region, execute_probe(p, cap=F_abs))
            if D > theta_D and 'consensus' not in cp.done:
                p2 = most_disagreeing_modality_probe(M, cp.region)
                M, _, D = xmodal_fuse(M, cp.region, execute_probe(p2, cap=F_abs))
                cp.done.add('consensus')
            sigma = reselect_footholds(x0, cp, M); R = schedule_risk(sigma, M)
            budget.spend(p)
        g = select_gait(R)
        if g != 'halt':
            ground = semantic_physical_grounding(sem, M.phys[cp.region],
                                                 independent=independent_channel(cp))
            if ground[0] == 'widen_phys':
                M.b[cp.region] = widen_phys(M.b[cp.region], ground[1])
            contract = contract_check(commit_action(sigma, g), C)
            if contract == 'violate':
                alt = reroute(M, cp, risk_model)
                if alt: route = alt; continue
                return negotiate_or_stop(cp, M, sigma, R, consent)
            c = core_contact(cp)
            if composable_evidence_gate(c, M, personas, adapters,
                                        ood_reg, contract, ground[0])[0] == 'ok':
                sched.append(commit(sigma, g)); log.append(tag_evidence(c)); continue
        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, M)) != 'halt': route = alt; continue
        return negotiate_or_stop(cp, M, sigma, R, consent,
                                 tau_int=tau_int(personas.active.auth))
    return sched, log, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SLA | O(Σ r_i·d)/前向；unmerge O(r_i·d) | O(Σ r_i·d) | 秩预算、支撑证书诚实、unmerge 精确（A41） |
| LGC | O(parse(u)) | O(\|𝒞\|) | 解析健全 ≥1−δ_parse、歧义即拒（A42） |
| SGC | O(d_sem+d_phys) | O(1) | 物理通道独立、单向加宽（A43） |
| CAP | O(1)+O(H_op) | O(\|op\|·\|𝒜\|) | rank\*≤r_max、出处审计、降级即隔离（A44） |
| CAG | O(\|σ\|·\|𝒜\|²) | O(\|σ\|) | 冲突即拒、语义类不进不可逆证据集 |
| PLC | O(\|CP\|·(k_p+k_c+k_cl)·(C_VOI+Σr_i d)) | O(\|V\|+\|𝒜\|) | 悲观 VOI、k_p+k_c+k_cl 终止、四态完备 |

**正确性定理（Composable Grounded Soundness, CGS）**
假设 A22–A32（第 53–55 轮）、A33–A36（第 56 轮）、A37–A40（第 57 轮）成立；**(A41)** 底座冻结且 unmerge 精确，r_i≤r_max，适配器支撑证书与 held-out ECE 声明诚实；**(A42)** 语言解析健全：真实意图落入解析集 w.p. ≥1−δ_parse，歧义/低置信即拒并发澄清探针；**(A43)** 落地检查的物理通道与 VLA 语义头不共享底座参数，且语义只允许加宽不允许放行；**(A44)** 适配器出处审计完备，授权只参数化 rank\*/fam\*，降级即隔离，r_max 不可被个性化突破。则：

1. **可归因承诺健全性**：失效率 ≤ δ_f + ε_meta(k) + ε_adapter + δ_probe + ε_h(w_max)；任一张坏卡片对总风险的贡献被 attr_i 局部化，unmerge 后其余卡片不受污染（无灾难性遗忘，因底座冻结）。
2. **语义放行风险为零**：EV-lingual/EV-ground 不进入不可逆接触必要证据集；G3 硬禁同源共谋；语义一致只能使 P_fail 加宽或不变，绝不下调。
3. **交互单调性延续**：适配器组合、语言契约、落地检查只能经 (a) 校准信念更新（含强制加宽）或 (b) 更保守动作（澄清、换卡、降档、L2）影响系统，无升险路径。
4. **终止性**：每检查点澄清探针 ≤k_cl、共识探针 ≤k_cons，PLC 在 k_probes+k_cons+k_cl 内终止于 {承诺, 绕行, L2 协商, 安全停}。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + ε_adapter + δ_probe + ε_h
                  + δ_ood·α_conf + δ_xm·1[L1] + δ_parse)
             − P(底座高维系统性错误 ∧ 低秩不可纠)
             − P(𝓜 陈旧未检出) − P(护盾回退失败) − P(超时 ∧ 安全停失效)
```

关键：**低秩给效率、秩预算给容量上界、unmerge 给局部可逆**（安全不再押"先验好不好"，而押"任何单一先验最多能污染多少、能否单独摘除"）；**语言给组合式约束、语义永不冒充概率**（只踩刹车不踩油门）；**落地检查用独立物理通道**，把"模型跟自己一致"从证据降级为需要外部世界背书的必要佐证。

云边协议 CEB++ → **CEB+++**：云端可下发**适配器增量**（而非整模型），但**适配器也要过隔离区**——先影子模式运行，校验秩预算、支撑覆盖、ECE 不劣化、干扰度不超阈、且不得绕过独立物理落地检查；边端回传适配器归因残差、证伪事件与同源共谋标记，作为云端卡片的淘汰/重训依据。第 57 轮"一切判定器走隔离"在本轮细化为"**一切先验走容量预算与可拆卸隔离**"：任何先验（含云端下发的低秩卡片、VLA 语言先验）都必须声明容量、出处与可摘除性，否则不得进入承诺链。

## 6. 本轮最大风险

**一句话**：本轮把安全建立在"冻结底座 + 低秩卡片可局部摘除"上，但底座是所有卡片、也是 VLA 语言头与动作头的**共同祖先**——若底座在某个高维方向上系统性错误，低秩卡片改不动它、语言头还会生成与错误动作自洽的合理说辞，于是"语义-物理落地"若不使用真正独立的物理通道就会退化成模型的自言自语；必须以"语义只踩刹车、物理才踩油门、独立通道才发 EV-ground"三重硬约束，把最深的赌注留给世界本身而不是任何一个模型。
