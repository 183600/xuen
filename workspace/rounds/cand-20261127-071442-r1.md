### 第 2 轮灵感驱动研究记录

**灵感词**：放置、通用机器人

**直觉与动机**：
（1）「放置」是操作任务中唯一不可逆的承诺点：抓取可以微调、搬运可以重规划，但一旦松开夹爪，物体状态就交给环境与重力，证书从「可控状态」转为「已兑现承诺」。现有 v25 的七证体系（USMC+SMC+RMC+MCC）全部在松手前有效，却缺少「松手后仍在有界扰动下成立」的持久化保证。若无此保证，前置证书再完备，也可能在放置瞬间被支撑面摩擦、堆叠碰撞、软物体变形一次性推翻。
（2）「通用机器人」意味着单一本体/策略要覆盖开放任务分布，无法为每个任务预先枚举证书。因此正确性必须从「状态证书」上移为「技能契约代数」：只要每个技能附带前/后置条件证书，且组合规则保号，未知任务可由已证技能组合而成；组合不成立时必须输出「安全弃权（abstain）」而非冒险执行。通用性由此从「能力宣称」变成「可证覆盖 + 可证弃权」。
（3）跨学科洞见：放置 = 分布式事务的两阶段提交（prepare → commit，commit 后不可 abort）；通用能力 = 可组合契约的类型系统 + 覆盖率证明。证书中的风险 α、能量 E、承诺代价 C 在组合时是可累加/可相乘的资源，需要显式的「证书预算代数」，否则组合会静默超支。核心洞见：**放置是证书的「兑现边界」，通用性是可组合契约的「类型闭包」；通用机器人的安全性 = 技能组合闭包 ∩ 放置承诺持久性。**

**形式化目标**：
1. 定义放置承诺证书（PCC）：在松手前对后置状态给出「支撑稳定 / conformal 位姿 / 释放冲量 / 最坏返工代价」四重保证，并配单向 commit token，保证 commit 后无可 abort。
2. 定义通用技能证书（GSC）：技能 σ = (Pre, Eff, Cert, Emb, r_σ, α_σ, E_σ, C_σ) 的 assume-guarantee 契约，定义前向链接组合与 (α, E, C) 预算可加规则。
3. 定义本体迁移证书（ETC）：能力签名偏序 Φ_dst ⊒ Φ_src 与动力学间隙 ε_transfer，判定证过的技能能否迁移到新本体，且迁移后鲁棒半径不塌缩。
4. 定义放置-通用统一准入门（PG-USC）：SRC-USC ∪ PCC ∪ GSC ∪ ETC 十证一体，Exec_v26 = Exec_v25 ∩ Fil_place ∩ Fil_gen ∩ Fil_transfer ⊆ Exec_v25。
5. 证明技能组合的预算可加性与「证明或弃权」覆盖保证，以及单调退化链在放置失败 / 组合失配 / 迁移超差下的保持性。

```python
# ============================================================
# IP-448 Placement Commitment Certificate (PCC) — 放置承诺证书
# ============================================================
@dataclass
class PlacementCommitmentCertificate:
    """松手前的四重保证 + 单向 commit token（commit 后不可 abort）"""
    object_pose: Tensor                 # [7] 目标放置位姿 (p, quat)
    com_world: Tensor                   # [3] 物体质心（世界系）
    support_polygon: Tensor             # [K,2] 支撑多边形顶点（世界系投影）
    release_twist: Tensor               # [6] 释放瞬间物体速度旋量
    belief: 'PoseBelief'                # 位姿信念（含协方差/粒子）
    disturbance_set: 'BoundedSet'       # W：有界扰动凸多面体
    alpha_place: float = 0.05           # 位姿覆盖风险
    eps_p: float = 0.005                # 位置容差 (m)
    eps_R: float = 0.035                # 姿态容差 (rad)
    m_stab: float = 0.02                # 稳定裕度下界 (m)
    J_max: float = 0.5                  # 释放冲量上界 (N·s)
    B_commit: float = 0.1               # 承诺代价预算
    horizon: int = 50                   # 持久化时域

    # ---------- (a) 支撑与稳定 ----------
    def verify_support_stability(self) -> bool:
        """COM 投影在支撑多边形内且裕度 ≥ m_stab；W 下准静态可行"""
        proj = self.com_world[:2]
        margin = signed_distance_to_polygon(proj, self.support_polygon)
        if margin < self.m_stab:
            return False
        for w in self.disturbance_set.vertices():      # W 的顶点
            if not self._quasi_static_feasible(w):
                return False
        return True

    def _quasi_static_feasible(self, w: Tensor) -> bool:
        """W 扰动下存在满足摩擦锥的支撑反力（LP 可行性）"""
        G = self._friction_cone_matrix(self.support_polygon)  # 支撑点摩擦锥
        h = self._wrench_balance_rhs(self.com_world, w)        # 重力+扰动
        return lp_feasible(G, h)                               # 小规模 LP

    # ---------- (b) conformal 位姿精度 ----------
    def verify_pose_conformal(self) -> bool:
        """ℙ(‖p−p*‖≤ε_p ∧ ∠(R,R*)≤ε_R) ≥ 1−α_place"""
        samples = self.belief.sample(4096)
        ok = (samples[:, :3] - self.object_pose[:3]).norm(dim=1) <= self.eps_p
        ok &= rotation_angle(samples[:, 3:], self.object_pose[3:]) <= self.eps_R
        return ok.float().mean().item() >= 1.0 - self.alpha_place

    # ---------- (c) 释放冲量 ----------
    def verify_release_impulse(self) -> bool:
        """释放瞬间线冲量 ‖m·v‖ ≤ J_max，避免放置后弹跳/滑移"""
        return torch.norm(self.release_twist[:3]).item() <= self.J_max

    # ---------- (d) 承诺代价（不可逆性预算） ----------
    def verify_commitment_cost(self) -> bool:
        """commit 后 H 步内最坏返工代价 sup_{w∈W} cost ≤ B_commit"""
        worst = self._worst_case_rework(self.disturbance_set, self.horizon)
        return worst <= self.B_commit

    def _worst_case_rework(self, W, H) -> float:
        # 以支撑稳定 / 位姿偏移为状态，最坏扰动序列下的返工（重抓/扶正）代价
        return robust_dp_cost(
            x0=self._post_release_state(),
            disturbance_set=W,
            horizon=H,
            cost_fn=rework_cost,
            dynamics=quasi_static_dynamics,
        )

    def verify_all(self) -> bool:
        return (self.verify_support_stability()
                and self.verify_pose_conformal()
                and self.verify_release_impulse()
                and self.verify_commitment_cost())


class TwoPhasePlacementProtocol:
    """放置 = prepare→commit 两阶段；commit 为单向门"""
    def prepare(self, pcc: PlacementCommitmentCertificate,
                grasp_state: 'GraspState') -> Optional['CommitToken']:
        if not pcc.verify_all():
            return None
        return CommitToken(
            pcc_hash=structural_hash(pcc),
            snapshot=grasp_state.clone(),
            seal=True,
            t_issue=now(),
            ttl=0.2,                       # 200ms 内未 commit 即作废
        )

    def commit(self, token: Optional['CommitToken'],
               robot: 'Robot') -> bool:
        if token is None or token.stale() or not token.seal:
            return False
        if not robot.grasp_intact():       # 松手前最后一道物理自检
            return False
        robot.open_gripper()               # ← 不可逆点
        token.mark_committed()             # commit 后禁止 abort
        return True

# IP-449 Generalist Skill Certificate (GSC) — 通用技能证书
# ============================================================
@dataclass
class SkillCertificate:
    name: str
    pre: 'Predicate'                    # 前置条件
    eff: 'Predicate'                    # 后置条件（效果）
    cert: 'CertificateBundle'           # 该技能携带的 USMC/SMC/PCC 等证书
    emb: 'EmbodimentSignature'          # 适用本体能力签名
    robustness_radius: float = 0.02     # r_σ
    alpha: float = 0.01                 # α_σ
    energy: float = 0.1                 # E_σ（归一化）
    commit_cost: float = 0.0            # C_σ（含放置时 > 0）

@dataclass
class ComposedCertificate:
    plan: list[str]
    alpha: float
    energy: float
    commit_cost: float
    emb: 'EmbodimentSignature'
    robustness_radius: float

@dataclass
class GeneralistSkillCertificate:
    """技能库 + 组合闭包 + 证明或安全弃权"""
    library: dict[str, SkillCertificate]
    alpha_budget: float = 0.05
    energy_budget: float = 1.0
    commit_budget: float = 0.2
    max_depth: int = 8

    def compose(self, seq: list[str]) -> Optional[ComposedCertificate]:
        """前向链接：Eff_{σ_i} ⇒ Pre_{σ_{i+1}}；预算可加；鲁棒半径取 min"""
        if not seq or len(seq) > self.max_depth:
            return None
        acc = ComposedCertificate(seq[0], 0.0, 0.0, 0.0, None, float('inf'))
        prev_eff = None
        for name in seq:
            s = self.library.get(name)
            if s is None:
                return None
            if prev_eff is not None and not implies(prev_eff, s.pre):
                return None                        # 契约链断裂
            acc.alpha += s.alpha                   # union bound
            acc.energy += s.energy                 # 能量可加
            acc.commit_cost += s.commit_cost       # 承诺代价可加
            acc.emb = s.emb if acc.emb is None else meet_signature(acc.emb, s.emb)
            acc.robustness_radius = min(acc.robustness_radius,
                                        s.robustness_radius)
            prev_eff = s.eff
            if acc.alpha > self.alpha_budget:      # 预算超支即拒绝
                return None
            if acc.energy > self.energy_budget:
                return None
            if acc.commit_cost > self.commit_budget:
                return None
        return acc

    def certify_or_abstain(self, task: 'Task') -> tuple[bool, Union[ComposedCertificate, str]]:
        """在技能库里搜索满足任务的组合；找不到则安全弃权而非冒险"""
        plan = self.search_composition(task, max_depth=self.max_depth)
        if plan is None:
            return False, 'abstain'
        comp = self.compose(plan)
        if comp is None:
            return False, 'abstain'
        if not implies(comp_to_eff(comp), task.goal):   # 后置不覆盖目标
            return False, 'abstain'
        return True, comp

# IP-450 Embodiment Transfer Certificate (ETC) — 本体迁移证书
# ============================================================
@dataclass
class EmbodimentSignature:
    dof: int
    reach: float          # 工作空间半径 (m)
    payload: float        # 额定负载 (kg)
    force_bw: float       # 力控带宽 (Hz)
    sensors: frozenset    # {'rgbd','tactile','ft',...}
    friction: float       # 末端有效摩擦系数

    def __ge__(self, other: 'EmbodimentSignature') -> bool:
        """能力偏序：本签名不弱于 other"""
        return (self.dof >= other.dof
                and self.reach >= other.reach
                and self.payload >= other.payload
                and self.force_bw >= other.force_bw
                and self.sensors >= other.sensors
                and self.friction >= other.friction)

@dataclass
class EmbodimentTransferCertificate:
    src: EmbodimentSignature
    dst: EmbodimentSignature
    gap_estimator: 'DynamicsGapEstimator'
    eps_transfer: float = 0.03

    def verify(self, skill: SkillCertificate) -> bool:
        # (1) 目标本体能力必须覆盖源本体
        if not (self.dst >= self.src):
            return False
        # (2) 迁移间隙有界，且迁移后鲁棒半径不塌缩
        gap = self.gap_estimator.estimate(self.src, self.dst)
        if gap > self.eps_transfer:
            return False
        return skill.robustness_radius - gap >= 0.0

@dataclass
class PlaceGeneralistUnifiedCertificate:
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'   # v25 七证
    pcc: PlacementCommitmentCertificate
    gsc: GeneralistSkillCertificate
    etc: EmbodimentTransferCertificate

    def admits(self, multi_plan: 'MultiRobotPlan',
               sensor_data: dict) -> tuple[bool, dict]:
        # 1. v25 七证（单机 USMC + SMC + RMC + MCC）
        if not self.src_usc.admits(
            multi_plan, sensor_data,
            gt_entities=sensor_data.get('gt_entities'),
            queries=sensor_data.get('queries'),
            retrieved=sensor_data.get('retrieved'),
        ):
            return False, {'reason': 'SRC_USC_reject'}

        # 2. 通用技能组合闭包（证明或弃权）
        ok_gen, comp = self.gsc.certify_or_abstain(multi_plan.task)
        if not ok_gen:
            return False, {'reason': 'GSC_abstain'}

        # 3. 每个被组合技能在目标本体可迁移
        for name in comp.plan:
            if not self.etc.verify(self.gsc.library[name]):
                return False, {'reason': f'ETC_reject:{name}'}

        # 4. 若任务含放置，则放置承诺必须在松手前成立
        if multi_plan.has_placement:
            if not self.pcc.verify_all():
                return False, {'reason': 'PCC_reject'}
            token = TwoPhasePlacementProtocol().prepare(
                self.pcc, multi_plan.grasp_state)
            if token is None:
                return False, {'reason': 'PCC_prepare_fail'}
            multi_plan.commit_token = token

        return True, {
            'plan': comp.plan,
            'alpha': comp.alpha,
            'energy': comp.energy,
            'commit_cost': comp.commit_cost,
            'commit_token': getattr(multi_plan, 'commit_token', None),
        }

# ---------------- 辅助函数 ----------------
def signed_distance_to_polygon(p: Tensor, poly: Tensor) -> float:
    """点到凸多边形边界的有符号距离（内部为正）"""
    n = len(poly)
    d_min = float('inf')
    for i in range(n):
        a, b = poly[i], poly[(i + 1) % n]
        e = b - a
        nrm = torch.stack([-e[1], e[0]])
        nrm = nrm / (nrm.norm() + 1e-12)
        d = torch.dot(p - a, nrm)
        d_min = min(d_min, d.item())
    return d_min

def implies(pre: 'Predicate', post: 'Predicate') -> bool:
    """谓词蕴含：用 SMT/区间算术判定 pre ⊆ post"""
    return pre.implies(post)

def meet_signature(a: 'EmbodimentSignature',
                   b: 'EmbodimentSignature') -> 'EmbodimentSignature':
    """组合技能所需能力签名的下确界（逐维取弱）"""
    return EmbodimentSignature(
        dof=min(a.dof, b.dof),
        reach=min(a.reach, b.reach),
        payload=min(a.payload, b.payload),
        force_bw=min(a.force_bw, b.force_bw),
        sensors=a.sensors & b.sensors,
        friction=min(a.friction, b.friction),
    )

def rotation_angle(q1: Tensor, q2: Tensor) -> Tensor:
    """四元数姿态夹角"""
    dot = torch.abs(torch.sum(q1 * q2, dim=-1)).clamp(0, 1)
    return 2 * torch.acos(dot)
```

## 3. 正确性论证（增量）

### 引理 13（放置承诺证书的四重保证与单向性）
**陈述**：`PCC.verify_all() = True` ⟺ 放置后置状态同时满足：
(1) 支撑稳定：d_supp(COM,P_supp) ≥ m_stab 且 ∀w∈W 准静态力平衡可行；
(2) 位姿精度：ℙ(e_p≤ε_p ∧ e_R≤ε_R) ≥ 1−α_place；
(3) 释放温和：‖m·v‖ ≤ J_max；
(4) 承诺可承受：sup_{w∈W} rework_cost ≤ B_commit。
且 `prepare` 成功生成的 token 一旦 `commit`，协议不存在 abort 分支。

**证明**：
1. 稳定性由质心投影裕度与摩擦锥 LP 可行性直接给出：W 的顶点可行 ⇒ 凸组合可行（LP 可行域凸）。
2. 位姿覆盖率由信念采样的经验频率给出，样本量 4096 时与真值偏差由 DKW 不等式约束在 O(1/√S)，离线再用 conformal 校准消除有限样本偏差。
3. 冲量界保证释放瞬间不引入超过支撑可恢复范围的动量。
4. 承诺代价由鲁棒动态规划在 W 的最坏顶点序列上求上界，B_commit 是"不可逆后仍可接受"的预算。
5. 单向性由 `commit` 的控制流保证：唯一写操作 `open_gripper()` 之后无回滚路径，token 状态机 `sealed→committed` 无 `→aborted` 边。
∎

### 引理 14（技能组合的契约保号与预算可加）
**陈述**：若 σ_i 均满足 ⊨_ag {P_i} σ_i {Q_i}，且序列 seq 满足 Q_i⇒P_{i+1}，且 Σα_i≤α_budget、ΣE_i≤E_budget、ΣC_i≤C_budget，则 `compose(seq)` 返回的 ComposedCertificate 满足 ⊨_ag {P_1} seq {Q_n}，且其真实风险 ≤ Σα_i、真实能耗 ≤ ΣE_i、真实承诺代价 ≤ ΣC_i。

**证明**：
1. 契约链：前向链接由 `implies(prev_eff, s.pre)` 逐段检查，归纳得 {P_1} seq {Q_n}。
2. 风险：各技能失败事件取并集，P(∪A_i) ≤ ΣP(A_i) = Σα_i（union bound）；若需更紧可用 Rényi 散度或 DKW 联合界，作为后续优化。
3. 能量与承诺代价：两者均为非负可加量，沿执行序列累加即上界。
4. 鲁棒半径取 min 是保守但正确的：组合在每一步均需抵抗至少 min r_σ 的扰动。
5. 任一预算超支即返回 None，故返回的组合必然满足预算约束。
∎

### 引理 15（通用性的「证明或安全弃权」覆盖保证）
**陈述**：对任务分布 𝒯 上任意任务 τ，`GSC.certify_or_abstain(τ)` 的结果要么返回一个已证组合（可安全执行），要么返回 `abstain`（不执行且不产生未证行为）。因此在语义上不存在"执行了未获证计划"的路径。

**证明**：
1. 决策树只有两个出口：`compose` 返回非空且 `implies(eff, goal)` → 已证；其余所有分支（无组合、预算超支、目标不覆盖）→ abstain。
2. 执行层只消费 `admitted=True` 的计划（PG-USC `admits` 的返回值），abstain 路径不进入执行。
3. 故"执行未证行为"的状态不可达。
补充：覆盖质量由技能库对 𝒯 的可组合覆盖度度量，记 Cov(L,𝒯)=ℙ_τ(∃已证组合)；系统需报告 Cov 并在 Cov<1−δ 时显式告警，避免把"弃权"误当成"安全"。
∎

### 引理 16（本体迁移的能力偏序与鲁棒性保持）
**陈述**：若 `ETC.verify(σ)=True`，则 σ 在目标本体上的行为满足：能力需求被覆盖（Φ_dst⊒Φ_src），且迁移后鲁棒半径 r'_σ = r_σ − gap ≥ 0。

**证明**：
1. `Φ_dst⊒Φ_src` 逐维比较 DOF/工作空间/负载/力带宽/传感/摩擦，保证目标本体不缺少执行该技能所需的任何能力维度。
2. gap 为源-目标动力学差异的归一化上界（离线辨识 + 仿真-现实差校准）；若任务扰动幅度 ≤ r_σ−gap，则迁移后仍落在稳定域内。
3. r_σ−gap≥0 即迁移后仍保有非负鲁棒裕度，故原证书在新本体上有效。
∎

### 引理 17（十位一体单调退化链）
**陈述**：任意单点/组合失效下，`Exec_v26 ⊆ Exec_v25 ⊆ … ⊆ Exec_v18` 恒成立。

**证明**：由定义 `Exec_v26 = Exec_v25 ∩ {π: PCC ∧ GSC ∧ ETC}`，交集必然子集。再补三条退化路径的语义：
- 放置承诺失效（支撑/位姿/冲量/代价任一不过）→ `PCC.verify_all=false` → PG-USC 拒证 → 保持抓取、退回 Exec_v25（不松手，降级为悬停/重规划）。
- 组合闭包失效或预算超支 → `GSC.abstain` → 拒证 → 退回 Exec_v25 的单技能已证计划或遥操作（不做未证组合）。
- 迁移超差/能力签名不覆盖 → `ETC.verify=false` → 拒证 → 退回源本体技能库或原构型执行（不做未证迁移）。
- 组合失效取交集，单调性保持。
∎

### 定理（PG-USC 十证准入门的安全-合规-可部署-可保护-结构-语义-重构-协同-放置-通用完备性）
**陈述**：对任意多机计划 Π = {π_1..π_N}，`PG-USC.admits(Π)=True` ⟺ Π 同时满足：
(1)–(10) v25 的全部十项条件（物理接地、云边一致、少样本覆盖、专利保护、结构、力控、轻量化、语义、重构、协同）；
(11) 放置承诺：支撑稳定 ∧ conformal 位姿 ∧ 释放冲量 ∧ 承诺代价 ∧ 单向 commit；
(12) 通用组合：任务由已证技能前向链接组成且 (α,E,C) 预算不超支；
(13) 本体迁移：目标能力签名覆盖源签名且迁移间隙 ≤ ε_transfer、迁移后鲁棒半径非负。

**证明**：`admis` 的控制流是上述条件的合取；必要性由任一条件失败即返回 False 得；充分性由引理 4、8、12、13–17 得：v25 保证单机到群体的物理-语义闭环，PCC 保证不可逆点的持久安全，GSC 保证任意任务"证明或弃权"，ETC 保证跨本体不丢失保证，四者合取构成从"开放任务"到"不可逆放置"再到"跨本体部署"的完整闭环。
∎
