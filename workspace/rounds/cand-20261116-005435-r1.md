# 第 1 轮（新灵感循环第 1 轮；本轮灵感：「伦理与合规」×「课程学习」）

> **基线**：第 9 轮 MetricVoiceGauge-ACMD（v9；定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**合规不可中立化、课程晋升可证化、两链正交化**。v9 用中立元把「模块失效」变成「功能退化」，这套代数对性能模块成立，但对伦理/合规模块是**反向**的：约束失效不能注入恒等元（那等于解除约束），只能注入最保守元。更尖锐的是，v9 中 DA-ML 失效注入 Δ_dom≡0 会让 K_eff 变大——这是功能等价、却是规范 fail-open。故 v10 的核心不是再加一个模块，而是把 v9 的单一退化链拆成**功能链**与**规范链**，并让课程学习只沿「可证能力」方向扩张自主包络。

## 0. 直觉与动机

**灵感 1（伦理与合规 → 规范链与合规见证）**
直觉：v9 能证明「动作块在几何上安全」，却不能证明「这次决策在规范上被允许」——例如未经同意靠近人、超期保存可识别影像、在无人类监督时执行不可逆操作。合规不是又一层软指标，而是一组**硬约束 + 可审计见证**。核心创新：**规范契约核（NormativeContractKernel, NCK）**：把法规/伦理规则编译为确定性安全自动机 A_R，每个动作块携带合规证书 Ĉ^comp 与见证摘要；硬规则失败进入**限制模式**（只允许安全核 S_0），而不是继续跑 v9。关键理论点：**合规退化是单调收缩的，不是中立元恒等的**。

**灵感 2（伦理与合规 → 审计链与最小披露）**
直觉：合规不仅要「做对」，还要「可被外部复算」。核心创新：**合规见证与审计链（ComplianceWitnessAuditChain, CWAC）**：每条决策写入哈希链 (decision, witness, rule_version)，原始个人数据只保留最小摘要与 TTL；审计者用公开规则版本可离线复算。这让「解释权」从叙事变成可验证产物，也让隐私义务成为证书的一部分。

**灵感 3（课程学习 → 可证渐进自主）**
直觉：v9 的 K_max、速度、阈值都是人工设定的一次性常数，机器人要么一直保守、要么一直冒险。课程学习给出正确隐喻：**先在小自主包络内取得统计证据，再晋升到更大包络**。核心创新：**课程晋升调度器（CurriculumProgressionScheduler, CPS）**：课程层级 l 决定自主包络 E_l（任务集、K_max、速度、人类确认义务），晋升需同时满足「能力 e-过程」与「合规 e-过程」的 anytime-valid 证据，降级是单周期立即的。**晋升可证性条件**要求新包络下 v9 安全证书仍可构造，避免「靠运气成功」。

**灵感 4（课程学习 × 伦理 → 联合门控与对抗课程）**
直觉：能力晋升不能只看成功率，否则会奖励「钻规范空子」的策略。核心创新：**联合晋升门（JointPromotionGate, JPG）**：能力、合规、信任域三者取最小；并用**伦理对抗课程（EthicalAdversarialCurriculum, EAC）**按难度递增注入规范边界案例，把「红队」变成课程的一部分。

## 1. 研究问题（轮次升级版）

- **Q1（合规退化）**：如何定义规范格与限制性退化，使任何模块失效都只能收缩容许动作集，且不破坏 v9 功能等价？
- **Q2（审计可复算）**：如何让合规见证在隐私最小披露下可外部复算，并抵抗日志篡改？
- **Q3（课程可证晋升）**：如何在可选停时（optional stopping）下控制错误晋升率，并保证晋升后的安全证书仍可构造？
- **Q4（联合门控）**：能力晋升与合规约束如何组合，避免「高成功率但规范违规」的策略被晋升？

## 2. 设计原则（新增 P13–P16）

**P13 合规单调退化律（Restrictive Degradation）**
规范端口失效注入限制元 v^⊖，容许集 A_adm ← A_adm ∩ v^⊖；任何退化事件不得扩张容许集。安全核 S_0（安全停、后退、释放、求助、保持）恒被允许。

**P14 双格分离律（Double-Lattice Separation）**
功能端口用中立元 v^⊥（x ⊕ v^⊥ = x），规范端口用限制元 v^⊖（∩ 收缩）；两端口独立，禁止用功能中立元替代规范限制元。DA-ML/SPR 等功能端口的 Δ_dom≡0、risk_SLAM≡0 只用于功能等价，不得作为规范放行依据。

**P15 可证晋升律（Certified Progression）**
l→l+1 需能力 e-过程拒绝 H0（成功率≤p0）、合规 e-过程拒绝 H0（违规率≥δ0）、且新包络证书可行性成立；缺一不升。晋升证据来自带人类监督的**课程探针**，而非仅低层级回放。

**P16 非对称迟滞律（Asymmetric Hysteresis）**
晋升需连续 N_p 个合格窗口，降级单周期生效；硬违规、信任域破坏、审计链断裂直接回 l=0 并进入限制模式。

## 3. 与基线的接口（如何退化）

- NCK 失效/不可判定 ⇒ 限制模式 S_0（安全停/退/释放/求助），**不退回无约束 v9**；仅离线消融实验允许「功能等价」对照（E590）。
- CPS 失效 ⇒ 冻结当前层级、停止晋升；同层级功能行为逐位等价 v9（引理 92）。
- CWAC 失效 ⇒ 决策仍执行但标记「不可审计」，同时进入限制模式（合规不可在无见证下继续自主）。
- v9 AC/MW/ID/DA/SPR/Cal 失效 ⇒ 保持 v9 功能退化链；但规范链独立覆写：信任相关模块失效 ⇒ K_eff←1、l←0，而非 Δ_dom≡0 的放宽。
- 全部功能模块失效 ⇒ v9→v8→v7→v6 功能链；规范链独立保持 fail-closed。

**保守扩展关系（本轮对 v9 的核心修正）**：v10 不声称在所有故障下与 v9 逐位等价，而声称 (i) 全健康轨迹上输出相同；(ii) 任意轨迹上 A_adm^{v10} ⊆ A_adm^{v9}。即 v10 是 v9 的规范保守扩展，而非行为复制。这把「等价退化」升级为「只减不增的退化」。

## 4. 预期贡献

1. **规范格 + 限制性退化 + 双格分离**：首次把「安全退化」与「合规退化」的代数方向区分开，给出单调收缩定理（引理 88–89）与保守扩展关系（推论 89a）。
2. **可外部复算的合规见证与审计链**，隐私最小披露，规则版本可追溯。
3. **anytime-valid 课程晋升**：在可选停时下控制错误晋升率（引理 90），并用证书可行性把「能力」与「可证安全」绑定（引理 92）。
4. **联合门控与伦理对抗课程**：E571–E590 覆盖规则变异、退化单调、审计复算、隐私、晋升有效性、渐进自主与端到端任务。

## 5. 本轮最大风险

**一句话**：合规层若严格 fail-closed，会在算力/感知压力下频繁把机器人锁进安全核（可用性崩塌本身也是伦理失败）；而一旦为可用性允许「合规超时即中立元」，伦理保障就会在过载时被静默关闭——**最大的风险是把「合规」当成又一个可注入中立元的普通模块**。

# 第 1 轮产物 · 创新点清单 v10：**MetricVoiceGauge-NCCP**（Normative-Compliance & Certified-Curriculum Progression）

> 基线：第 9 轮 MetricVoiceGauge-ACMD（v9，定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮灵感：「伦理与合规」×「课程学习」。
> **继承纪律**：MetricVoiceGauge 九不变式、v9 的 AC/MW/ID 与 DA-ML/SPR/Cal 全部保留。新组件在**功能端口**上是可选增强（禁用后全健康轨迹等价 v9，引理 92）；但在**规范端口**上不是可选增强，而是独立的 fail-closed 链（P13/P14）。这是 v10 与 v9 的范式差异：**功能可以退回，规范只能收紧**。

**v10 双层退化链（功能链 + 规范链，正交）：**

- **规范链（fail-closed，永远在线）**
  - N-0：硬规则违规/不可判定 ⇒ S_0 限制模式 + 人类接管；不回 v9。
  - N-1：CWAC 断裂 ⇒ 决策降级为「不可审计」并同步进入 S_0。
  - N-2：规则版本不匹配/未认证 ⇒ 仅允许 S_0，直到加载已认证版本。
  - N-3：信任相关模块（DA-ML/SPR/Calib-FI）失效 ⇒ 规范端口注入「未知」而非 0：K_eff←1、l←0。
- **功能链（沿用 v9，允许中立元等价）**
  - F-1：AC 失效 ⇒ K_eff←1，逐步执行（v9 Level-1）。
  - F-2：MW 失效 ⇒ v8 手写网关路径（v9 Level-2）。
  - F-3：ID 失效 ⇒ 全模块 active、归因冻结（v9 Level-3）。
  - F-4：DA/SPR/Cal 功能端口失效 ⇒ Δ_dom≡0 / risk_SLAM≡0 / weight≡1，功能等价 v7。
  - F-5：全失效 ⇒ v9→v8→v7→v6。

> 关键：F-4 的中立元只作用于功能端口。规范端口对同一失效注入 v^⊖=「未知」，因此 v10 在 v9 会放宽的地方收紧。这就是「保守扩展」而非「逐位等价」。

**新增定义 540（规范规则集 Normative Rule Set）** R=(R_hard,R_soft)。硬规则 r 是事件迹 σ∈Σ* 上的安全性/共安全性属性，例如：非同意近距离接触禁止、可识别影像最小化与 TTL、不可逆操作需人类确认、声明必须带 grounding、人类 override 必须始终可达。软规则 r 赋予代价 c_r(σ)∈[0,1]，总代价须 ≤ B_eth。规则以内容寻址版本 ver_r 注册（IP-365）。

**新增定义 541（规范自动机 Normative Automaton）** 每条硬规则编译为确定性安全自动机 A_r；q_r^bad 为吸收态。规范状态 q_t 由事件流（感知事件、动作事件、声明事件、人类输入、时钟）驱动。迹合规 ⇔ q_t∉Bad_R 且软代价 ≤ B_eth。实现采用逐规则监视器：时间 O(|R_hard|)/事件，内存 O(Σ_r|Q_r|)。

**新增定义 542（合规见证与合规证书 Compliance Witness & Certificate）** 见证 w_t 绑定规则版本、最小证据摘要 h(e_t)、裁决与时间戳；证据按 IP-364 脱敏。块证书 Ĉ^comp_t 断言：沿预测块与所有候选中止点，q 不进入 Bad_R；块末未履行义务 O_{t+K} 均可由 S_0 中的动作履行或安全挂起；并附见证摘要。块合规可采纳 ⇔ 上述成立且 Ĉ^comp_t 在 v9 前向模型误差 β 下保守成立。

**新增定义 543（规范格与容许集 Normative Lattice）** 容许集 A_adm(s)={a∈A(s): ∀r∈R_hard, δ_R(q(s),a)∉Bad_R；软代价 ≤B_eth；O(s) 可履行}。以集合包含 ⊆ 为序，meet 为 ∩；规范 bottom 固定为 S_0（而非 ∅，以保证系统始终可安全停驻/求助）。设计校验：∀s, S_0⊆A_adm(s)（由 M₀ 硬检查与人类 override 可达性保证）。

**新增定义 544（限制性退化 Restrictive Degradation）** 对失效事件 f，限制元 v^⊖_f 是该失效下仍可证明合规的最大动作集，且 S_0⊆v^⊖_f。退化算子 D_f(A)=A∩v^⊖_f。例：同意监视器失效 ⇒ 禁用所有需要同意的接近/接触动作；隐私监视器失效 ⇒ 禁用采集与外传；规范核本身失效 ⇒ v^⊖=S_0。由定义立即得 D_f(A)⊆A。

**新增定义 545（双格分离 Double-Lattice Separation）** 功能格 (V,⊕,v^⊥) 与规范格 (2^A,∩,S_0) 独立。模块 m 同时导出功能输出 y_m∈V 与规范足迹 P_m⊆A；组合为 y=⊕_m y_m、A_adm=A_task∩⋂_m P_m。功能端口失效置 y_m←v^⊥；规范端口失效置 P_m←v^⊖_m。**非干扰条件**：y_m 不得参与 P_m 的计算（P_m 只由事件迹、规则版本与显式见证决定）。DA-ML 的 Δ_dom≡0 属功能端口，规范端口必须同时取 v^⊖=「未知」。

**新增定义 546（审计链 Audit Chain）** H_t=H(H_{t-1}‖h(d_t)‖h(w_t)‖ver_t‖t)，周期性把根签名/外锚定。审计者持有公开规则版本与日志，可离线重放 A_R 并核验 H 链。隐私：链上只存哈希与脱敏特征；原始证据按 TTL_r 加密保留，且用途 ρ_data 受规则约束；超期或撤同意即删除并记录删除见证。

**新增定义 547（课程层级与自主包络 Curriculum Level & Autonomy Envelope）** l∈{0,…,L}，E_l=(T_l,K_max(l),v_max(l),H_l,β_l,B_eth(l),ρ_data(l))。自主序：l≼l' 当且仅当 T_l⊆T_l'、K_max(l)≤K_max(l')、v_max(l)≤v_max(l')、H_l⊇H_l'（低层级要求更多人类确认），且安全间距 d_safe 不随层级放松。β_l 不要求单调，只要求按层标定并被晋升证据覆盖；若 β_l 无法覆盖该层误差，则该层晋升不可行。

**新增定义 548（晋升证书与 e-过程 Promotion Certificate）** 在带监督的课程探针上收集窗口结果 X_i（任务成功）与 Y_i（规范违规）。能力 e-过程 E^{suc}_n=∏_{i≤n}(1+λ_s(X_i−p0))，合规 e-过程 E^{comp}_n=∏_{i≤n}(1+λ_c(δ0−Y_i))，λ 取可行区间使其在各自零假设下为非负超鞅。晋升证书 Π_{l→l+1}=(E^{suc}_n≥1/α_p) ∧ (E^{comp}_n≥1/α_c) ∧ (n≥n_min) ∧ CertFeasible(l+1)，其中 CertFeasible 要求 v9 的 AC 证书、MW 预算与规范自动机在 E_{l+1} 上仍可构造。

**新增定义 549（联合门控与降级 Joint Gate）** l_t=min(l_t^CPS,l_t^trust)，l_t^trust=0 若 Δ_dom≥τ_dom∨risk_SLAM≥τ_SLAM∨校准失效，否则 L。晋升：连续 N_p 个窗口 Π 成立才 l←l+1。降级：软证据不足 l←max(0,l−1)；硬规范违规、审计链断裂、人类 override 失败 l←0 并进入 S_0。降级在同一控制周期生效。

# IP-357 NormativeContractKernel：规范契约核
class NormativeContractKernel:
    def __init__(self, rules, version, safe_core=S_0):
        self.rules = rules                    # R_hard + R_soft，绑定 ver_r
        self.version = version
        self.monitors = {r.id: make_monitor(r) for r in rules.hard}
        self.soft_pot = 0.0
        self.safe_core = safe_core

    def step(self, q_state, event):
        q = q_state
        for r in self.rules.hard:              # 逐规则，避免乘积爆炸
            q[r.id] = self.monitors[r.id].delta(q[r.id], event)
            if q[r.id] in self.monitors[r.id].bad:
                return q, self.safe_core        # 硬违规 ⇒ 立即限制
        self.soft_pot += self.rules.soft_cost(event)
        return q, None

    def admissible(self, q_state, state):
        A = state.action_space()
        if self.soft_pot > self.rules.B_eth:
            A = A & self.safe_core
        for r in self.rules.hard:
            if q_state[r.id] in self.monitors[r.id].bad:
                return self.safe_core
        return A & self._obligation_filter(q_state, state)

    def degrade(self, A, failure):
        # 定义 544：规范端口只做交集，绝不并集
        return A & self.rules.restrictive_set(failure)

        self.key = key

    def append(self, decision, witness):

            'rule': witness.rid, 'ver': witness.ver,

            'verdict': witness.verdict, 't': now(),
        }

# IP-359 CurriculumProgressionScheduler：课程晋升
class CurriculumProgressionScheduler:
    def __init__(self, L=5, p0=0.9, delta0=0.01, alpha_p=0.05,
                 alpha_c=0.05, N_p=3, n_min=30):
        self.l = 0
        self.esuc = 1.0
        self.ecomp = 1.0
        self.n = 0
        self.good_windows = 0
        self.L = L
        self.p0, self.delta0 = p0, delta0
        self.alpha_p, self.alpha_c = alpha_p, alpha_c
        self.N_p, self.n_min = N_p, n_min

    def observe(self, success, violation, lam_s, lam_c):
        self.n += 1
        self.esuc *= (1 + lam_s * (success - self.p0))
        self.ecomp *= (1 + lam_c * (self.delta0 - violation))
        ok = (self.esuc >= 1 / self.alpha_p
              and self.ecomp >= 1 / self.alpha_c
              and self.n >= self.n_min)
        self.good_windows = self.good_windows + 1 if ok else 0

    def try_promote(self, cert_feasible):
        # 定义 548/549：三条件 + 非对称迟滞
        if (self.l < self.L and self.good_windows >= self.N_p
                and cert_feasible(self.l + 1)):
            self.l += 1
            self._reset_evidence()
            return True
        return False

    def demote(self, severity):
        # 定义 549：单周期生效；硬违规直接回 0
        self.l = 0 if severity == 'hard' else max(0, self.l - 1)
        self._reset_evidence()

## 4. 推导

**引理 87（合规见证可靠性）** 设 A_R 正确编码 R_hard，见证 w 与事件迹一一绑定且哈希无碰撞。若所有硬规则监视器在迹 σ 上不进入坏态，则 σ 满足 R_hard。证明：A_r 为确定性安全自动机且坏态吸收；对 σ 逐事件归纳得 δ_R(q_0,σ)∉Bad_R，由编码正确性即得语义满足。∎

**引理 88（限制性退化的单调收缩）** 对任意失效序列 f_1,…,f_k，A_adm^{(k)}⊆A_adm^{(0)}；且若每个 v^⊖_{f_i}⊇S_0，则 S_0⊆A_adm^{(k)}。证明：由定义 544，每步为 A←A∩v^⊖，交集单调不增；S_0 对每步均被保留，故其始终在交集中。∎

**引理 89（双格非干扰）** 在非干扰条件下，任意功能端口替换 y_m←v^⊥ 都不改变 A_adm；反之，规范端口替换 P_m←v^⊖ 只会缩小 A_adm。证明：A_adm=A_task∩⋂P_m 只依赖 P_m；P_m 的计算不读 y_m（非干扰条件），故功能退化对 A_adm 无影响；P_m←P_m∩v^⊖ 使交集单调缩小。∎

**推论 89a（v9 保守扩展）** 全健康轨迹上 v10 与 v9 输出逐位相同；任意轨迹上 A_adm^{v10}⊆A_adm^{v9}，且在 DA-ML/SPR/Cal 失效时严格更小。证明：全健康时两端口取正常值，功能链与 v9 相同（v9 引理 83），规范链只做额外交集；失效时 v10 的规范端口取「未知」/S_0，而 v9 取中立元，后者不更保守。∎

**引理 90（anytime-valid 晋升的错误控制）** 在零假设 H0（成功率≤p0 或违规率≥δ0）下，任意可选停时策略的错误晋升概率 ≤ α_p+α_c。证明：E^{suc}、E^{comp} 在各自 H0 下为非负超鞅，初值 1；由 Ville 不等式 P(sup_n E_n≥1/α)≤α；晋升要求两过程同时越阈，故由并集界得 ≤α_p+α_c。∎

**引理 91（非对称迟滞无抖振）** 晋升需连续 N_p 个合格窗口，降级单周期生效，故任意「晋升—降级」循环至少持续 N_p 个窗口；在有限时间内迁移次数有限，且硬违规的降级延迟 ≤1 控制周期。证明：good_windows 计数在任一不合格窗口清零；降级不等待窗口。∎

**引理 92（课程晋升保持 v9 安全不变式）** 若 CertFeasible(l+1) 成立，则在 E_{l+1} 上 v9 引理 82–86 仍成立；CPS 只改变包络参数，不改变功能数据流。证明：CertFeasible 逐项要求 AC 块证书保守性（引理 82）、MW 预算（引理 86）、规范中止点（IP-363）；对 l 归纳即得。∎

**引理 93（审计可复算与篡改证据）** 在哈希抗碰撞与签名不可伪造假设下，(i) 审计者用公开 ver_r 重放 A_R 得到的裁决与日志见证一致；(ii) 任意修改日志必改变 H_t 根（概率可忽略），从而被检测；(iii) 链上仅含摘要与脱敏特征，不泄露原始个人数据。证明：(i) 确定性自动机 + 内容寻址版本；(ii) 哈希链碰撞归约；(iii) 由 IP-364 的构造与 TTL 策略直接得。∎
