# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「语言指令」×「力矩传感」）

> 第 54 轮已把技能组合建立在动作空间剖面 `α_S` 与云边联合证书 `J` 之上。本轮沿“语义—物理”方向继续下沉：**语言指令是离散符号，力矩传感是连续物理量，二者之间缺少可验证的接地**。核心矛盾：**H22**：语言谓词（“轻放”“旋紧”“插到底”）在力矩空间中没有唯一定义，同一指令可对应多组力矩策略，不同指令又可能共享力矩签名，形成**语义混叠**；**H23**：语言级证书只在符号层成立，一旦映射到带噪声、会温漂的力矩传感器，执行层可能违反力矩包络而语义层无从察觉。

## 0. 直觉与动机

**灵感 1（从标签到力矩语义区域）**
直觉：不要把“轻放”当成一个分类标签，而应把它看成**力矩签名空间里的一个区域**。一次技能执行产生力矩轨迹 `τ(t)`，提取签名 `Φ_τ = (τ_peak, τ_rms, j_peak, f_c, τ_ss, κ)`，则谓词 `p` 对应签名分布 `D_p`。接地置信度 `g(p,τ) = P(Φ_τ(τ) ∈ D_p)`。这把第 54 轮的动作占用 `α_S(a)` 从“动作可达”升级为“**力语义可达**”：`α_S` 只回答“这个动作能不能做”，而 `g(p,τ)` 回答“这个动作像不像用户说的那件事”。

**灵感 2（力矩签名谱 → 与鲁棒性谱并列的第二条谱）**
直觉：第 53 轮有鲁棒性维度谱 `ρ`，本轮引入**力矩签名谱** `σ_S`，其维度为峰值、均方根、jerk、谱质心、稳态保持力矩、接触刚度估计、滑移前后力矩差。技能 `S` 不再只有 `(ρ_S, α_S)`，而是 `(ρ_S, α_S, σ_S)`。语言接地就是在 `σ_S` 上做**带容差的区域覆盖判定**，与动作剖面形成“动作—力”双剖面。

**灵感 3（语言指令编译为力矩契约，而非直接生成轨迹）**
直觉：与其让模型直接输出轨迹，不如把祈使句编译成**可检验的约束契约**：力矩包络 `E_p(t) = [τ_min(t), τ_max(t)]`、阻抗参数 `Z_p = (K_p, D_p)`、终止条件 `stop_p`（如“力矩达到目标且变化率低于 ε”或“检测到咔哒瞬态”）。这样语言层只承诺“约束”，执行层保留策略自由度，证书只需验证“执行是否落在包络内 + 签名是否属于 `D_p`”，比端到端轨迹更容易做 soundness 论证。

**灵感 4（语义混叠与主动力矩探针）**
直觉：“轻放”之所以歧义，是因为不知道物体有多硬。人手会先**轻轻碰一下**估计刚度，再决定力度。于是把“试探”形式化为主动探针：`a* = argmax_a I(P; τ_a | h)`，在安全力矩包络 `τ_safe` 内选择信息增益最大的微小接触动作。探针把“语言歧义”转化为“物理可观测信息”，使接地从被动分类变为**主动辨识**。

**灵感 5（反向语言解释：力矩残差 → 可读诊断）**
直觉：执行后力矩残差 `Δτ = τ_exec - τ_ref` 不应只回传数值，而应映射为语言级诊断：“接触太硬（刚度高于预期 2.3 倍）”“未到位（保持力矩未达阈值）”“发生滑移（切向力矩突降）”。这把第 53/54 轮的反向解释通道从“根因动作 `a_e`”升级为**用户可读的语义反馈**，使用户能改写指令，形成“指令—力矩—语言诊断—改写”的闭环。

**灵感 6（从动作-鲁棒性金字塔到语义-力矩金字塔）**
直觉：在第 54 轮 `𝕃`（鲁棒性）与 `𝔸`（动作空间）之上叠加**语言-力矩层 `𝕋`**：`𝕋_0` 传感器物理极限与安全包络，`𝕋_1` 力矩签名谱，`𝕋_2` 语言-力矩接地关系，`𝕋_3` 指令-力矩契约与语言诊断。跨层证书需同时携带 `ρ`、`A_cert` 与新增的 `T_cert`，构成**动作-鲁棒性-力语义三证书体系**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（力矩签名与签名谱）**
一次执行产生力矩轨迹 `τ : [0,T] → ℝ^d`（关节力矩或接触力旋量）。特征映射
```
Φ_τ(τ) = (τ_peak, τ_rms, j_peak, f_c, τ_ss, κ, Δτ_slip)
```
其中 `τ_rms = sqrt(1/T ∫_0^T |τ(t)|² dt)`，`j_peak = max_t |dτ/dt|`，`f_c` 为功率谱质心，`τ_ss` 为稳态保持力矩，`κ` 为由 `dτ/dx` 估计的接触刚度，`Δτ_slip` 为滑移前后切向力矩差。技能 `S` 的**力矩签名谱** `σ_S` 为各维度的经验分布，签名集 `𝒯_S ⊆ ℝ^7`。

**定义 122（语言-力矩接地关系）**
设 `P` 为语言谓词集（“轻放”“旋紧至 N·m”“插到底”“缓慢接触”）。接地不是函数而是**关系** `G ⊆ P × 𝒯`，`G(p) = D_p` 为签名分布。接地置信度
```
g(p, τ) = P_{Φ ~ D_p}[ d(Φ_τ(τ), Φ) ≤ ε_g ]
```
允许 `|G(p)| > 1`（一义多力矩）与 `D_p ∩ D_q ≠ ∅`（多义同力矩），即显式承认多对多。

**定义 123（指令-力矩契约 ITC）**
编译映射 `comp : L → C_{p→τ}`，契约为
```
C_{p→τ} = (p, E_p, Z_p, stop_p, δ_τ, evidence)
```
- `E_p(t) = [τ_min(t), τ_max(t)]` 力矩包络；
- `Z_p = (K_p, D_p)` 目标阻抗；
- `stop_p` 终止谓词（到位/饱和/瞬态检测）；
- `δ_τ` 为允许的包络越界预算（如 `∫ 1[τ∉E_p] dt ≤ δ_τ`）；
- `evidence` 为谓词—包络标定记录。
**契约忠实**：若执行满足 `C_{p→τ}`，则 `g(p,τ) ≥ θ_g`。

**定义 124（语义-力矩歧义度）**
两谓词的签名混叠用 Bhattacharyya 系数度量：
```
amb(p,q) = BC(D_p, D_q) = ∫ sqrt(dD_p dD_q) ∈ [0,1]
Amb(p)   = max_{q≠p} amb(p,q)
```
执行后的后验歧义为 `H(P | Φ_τ, h)`（给定观测与历史时候选谓词的熵）。`Amb(p) > θ_amb` 时契约**不得直接部署**，必须消歧。

**定义 125（主动力矩探针）**
探针为一组受安全包络约束的微小接触动作 `A_probe ⊆ A`，满足 `|τ(a)| ≤ τ_safe`。探针选择为
```
a* = argmax_{a∈A_probe} IG(a) = H(P|h) - E_{τ_a}[ H(P | h, τ_a) ]
```
并要求 `IG(a*) ≥ ι_min`（信息增益正）且探针造成的位移/冲量低于安全阈值。

**定义 126（语言-力矩联合证书）**
联合证书
```
L = (p, G_p, C_{p→τ}, T_cert, J, verbal_evidence)
```
- `T_cert = (Φ_exec, g_exec, viol, δ_τ, β_τ)`：签名取证、接地置信度、包络越界量、容差、传感器偏置界；
- `J = (ρ, A_cert, γ_ce, δ_a, evidence)` 为第 54 轮联合证书；
- `verbal_evidence` 为力矩残差到语言诊断的映射记录（如“太硬/未到位/滑移”）。
若 `g_exec ≥ θ_g`、`viol ≤ δ_τ`、`Amb(p) ≤ θ_amb`（或已被探针消歧）、且 `J` 可部署，则 `L` 可部署。

## 2. 关键算法 伪代码

### IP-121 LTG（Language-Torque Grounding）

```python
def fit_grounding(predicate, demos, eps_g):
    feats = [torque_signature(tau) for tau in demos]      # 定义 121
    mu = mean(feats)
    sigma = cov(feats) + eps_g * I
    return GaussianSignature(mu, sigma, predicate)

def grounding_confidence(p, tau):
    phi = torque_signature(tau)
    return p.signature.membership(phi)                     # P[d(phi,Phi)<=eps_g]

def build_grounding_relation(P, demo_bank):
    return {p: fit_grounding(p, demo_bank[p], EPS_G) for p in P}
```

### IP-122 TSC（Torque Signature Certificate）

```python
def torque_certificate(p, tau_exec, C, beta_tau):
    phi   = torque_signature(tau_exec)
    g     = grounding_confidence(p, tau_exec)
    viol  = envelope_violation(tau_exec, C.E_p)
    ok    = (g >= THETA_G) and (viol <= C.delta_tau) and (beta_tau <= BETA_MAX)
    return T_Cert(phi, g, viol, C.delta_tau, beta_tau, ok)
```

### IP-123 ITC（Instruction-Torque Contract Compilation）

```python
def compile_instruction(utterance, ontology, torque_limits):
    p   = parse_predicate(utterance, ontology)            # 语言解析
    E_p = predicate_to_envelope(p, ontology)              # 谓词→包络
    Z_p = predicate_to_impedance(p, ontology)             # 刚/柔需求→K,D
    stop = predicate_to_stop_condition(p, ontology)       # 到位/瞬态
    C   = ITC(p, clip(E_p, torque_limits), Z_p, stop, DELTA_TAU)
    if not contract_grounded(C, ontology):                # 离线标定校验
        return ('reject', 'ungrounded_predicate', p)
    return ('ok', C)
```

### IP-124 ATP（Active Torque Probing）

```python
def disambiguate(p, P_candidates, history, safety):
    if Amb(p) <= THETA_AMB:
        return ('resolved', p)
    best, best_ig = None, -inf
    for a in safety.admissible_probes():                  # |tau| <= tau_safe
        ig = expected_information_gain(P_candidates, history, a)
        if ig > best_ig:
            best, best_ig = a, ig
    if best_ig < IOTA_MIN:
        return ('refuse', 'insufficient_information')     # 主动拒答
    tau_probe = execute(best)
    return ('probe', best, tau_probe, update_posterior(P_candidates, tau_probe))
```

### IP-125 LTR（Language-Torque Residual Explanation）

```python
def explain_torque_residual(tau_exec, tau_ref, C):
    dtau = tau_exec - tau_ref
    causes = []
    if contact_stiffness(tau_exec) > C.Z_p.K * K_TOL:
        causes.append('contact_too_stiff')
    if steady_state(tau_exec) < C.stop_p.target * STOP_TOL:
        causes.append('not_seated')
    if slip_detected(tau_exec):
        causes.append('slippage')
    if jerk_peak(tau_exec) > C.jerk_max:
        causes.append('motion_too_abrupt')
    return verbalize(causes, magnitudes(dtau), C.p)       # → 可读诊断
```

### IP-126 JLT（Joint Language-Torque Certificate）

```python
def joint_language_torque_certificate(p, tau_exec, C, J_prev, verbal, beta_tau):
    T = torque_certificate(p, tau_exec, C, beta_tau)
    if not T.ok:
        return ('reject', 'torque_violation', T, explain_torque_residual(tau_exec, C.ref, C))
    if Amb(p) > THETA_AMB:
        return ('reject', 'ambiguity', Amb(p), disambiguate(p, candidates(p), [], SAFETY))
    if not J_prev.deployable:
        return ('reject', 'joint_certificate_fail', J_prev)
    return ('ok', JointLangCert(p, C, T, J_prev, verbal))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| LTG | O(|P|·n·d²) 训练 | O(|P|·d²) | 签名充分统计、谓词可分 |
| TSC | O(T·d + |P|·d) | O(T) | 包络定义一致、偏置有界 |
| ITC | O(|utt|·d + |P|) | O(|P|) | 编译忠实、谓词已标定 |
| ATP | O(|A_probe|·T·|P|) | O(|P|+|A_probe|) | 探针安全、信息增益正 |
| LTR | O(|T_cert|·|P|) | O(|P|) | 残差—诊断映射可解释 |
| JLT | O(T·d + |P|·d²) | O(|P|·d²) | 三证书合取 sound |

**正确性定理（Language-Torque Grounding Soundness）**
承接第 54 轮假设 (A22)–(A28)，新增：
**(A29)** 力矩签名 `Φ_τ` 对谓词隶属是充分统计量，且不同谓词签名分布可分离；
**(A30)** 传感器偏置/温漂有界 `|bias| ≤ β_τ`，且按周期标定；
**(A31)** 编译映射 `comp` 忠实：满足 `C_{p→τ}` 的执行必有 `g(p,τ) ≥ 1-ε_c`；
**(A32)** 主动探针始终满足 `|τ| ≤ τ_safe` 且 `IG ≥ ι_min`。
则对可部署证书 `L`：
```
P(success | deploy L) ≥ 1 - Σ_d (1-ρ_min(d)) - P(Amb>θ_amb)
                        - P(viol>δ_τ) - β_τ - ε_c
```
关键：**力语义先经签名取证**，**歧义先经主动探针或拒答**，**力矩越界先于语言层否决**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 力矩传感器噪声、温漂、磨损导致签名漂移 | 高 | 在线偏置估计 + 周期标定 + 签名漂移告警 |
| 语言谓词长尾、力矩证据缺失 | 高 | 谓词本体白名单 + 未接地谓词主动拒答 |
| 签名不可辨识/多谓词混叠 | 高 | 主动探针 + 增加区分性力维度 + 拒答 |

| 主动探针本身不安全 | 中 | 硬力矩包络 + 冲量上限 + 人工确认高危探针 |
| 语言解析/编译幻觉 | 中 | 结构化谓词本体 + 契约形式校验 + 不可编译即拒 |

## 6. 本轮最大风险

**一句话**：语言-力矩接地把技能证书从“动作-鲁棒性”推进到“语义-物理”三证书，但其 soundness **三重依赖力矩签名可分离、传感器标定稳定、指令编译忠实**；一旦真实接触噪声、温漂与磨损使签名漂移，或长尾谓词根本没有力矩证据，系统就会产生“语义自信但物理越界”的**假接地**，故必须以 **在线标定 + 未接地即拒答 + 安全包络内的主动探针** 三重护栏，宁可承认“听不懂”，也绝不把力矩空间里的“像”当作语言语义的“是”。

### IP-121 LTG

```python
def torque_signature(tau, x=None):
    return dict(peak=absmax(tau), rms=rms(tau), jerk=maxabs(diff(tau)),
                spec=spectral_centroid(tau), ss=steady_state(tau),
                kappa=contact_stiffness(tau, x), slip=slip_drop(tau))

def fit_grounding(predicate, demos, eps_g):
    feats = [vectorize(torque_signature(t)) for t in demos]
    return GaussianSignature(mean(feats), cov(feats) + eps_g*I)

def build_grounding_relation(P, demo_bank, eps_g):
    return {p: fit_grounding(p, demo_bank[p], eps_g) for p in P}

def grounding_confidence(p, tau):
    return p.signature.membership(vectorize(torque_signature(tau)))
```

### IP-122 TSC

```python
def envelope_violation(tau, E, dt):
    return sum(max(0.0, E.min[i]-tau[i], tau[i]-E.max[i]) for i in range(len(tau))) * dt

def torque_certificate(p, tau_exec, C, beta_tau):
    phi  = torque_signature(tau_exec)
    g    = grounding_confidence(p, tau_exec)
    viol = envelope_violation(tau_exec, C.E_p, C.dt)
    ok   = (g >= THETA_G) and (viol <= C.delta_tau) and (beta_tau <= BETA_MAX)
    return T_Cert(phi, g, viol, C.delta_tau, beta_tau, ok)
```

### IP-124 ATP

```python
def expected_information_gain(cands, history, a):
    prior = entropy(posterior(cands, history))
    return prior - expected_entropy_after(cands, history, a)

def disambiguate(p, cands, history, safety):
    if Amb(p) <= THETA_AMB:
        return ('resolved', p)
    probes = [a for a in safety.admissible_probes() if maxabs(a.torque) <= TAU_SAFE]
    a_star = max(probes, key=lambda a: expected_information_gain(cands, history, a), default=None)
    if a_star is None or expected_information_gain(cands, history, a_star) < IOTA_MIN:
        return ('refuse', 'insufficient_information')
    tau = execute(a_star)
    return ('probe', a_star, tau, posterior(cands, history + [tau]))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| LTG | O(|P|·n·d²) | O(|P|·d²) | 签名充分统计、谓词可分 |
| TSC | O(T·d + |P|·d) | O(T) | 包络定义一致、偏置有界 |
| ITC | O(|utt|·d + |P|) | O(|P|) | 编译忠实、未接地即拒 |
| ATP | O(|A_probe|·T·|P|) | O(|P|+|A_probe|) | 探针安全、`IG≥ι_min` |
| LTR | O(|T_cert|·|P|) | O(|P|) | 残差—诊断映射可解释 |
| JLT | O(T·d + |P|·d²) | O(|P|·d²) | 三证书合取 sound |

**正确性定理（Language-Torque Grounding Soundness）**
承接 (A22)–(A28)，新增 **(A29)** `Φ_τ` 是谓词隶属的充分统计且签名分布可分离；**(A30)** 传感器偏置/温漂 `|bias|≤β_τ` 且周期标定；**(A31)** `comp` 忠实，满足 `C_{p→τ}` 的执行有 `g≥1-ε_c`；**(A32)** 探针满足 `|τ|≤τ_safe` 且 `IG≥ι_min`。则
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - P(Amb>θ_amb) - P(viol>δ_τ) - β_τ - ε_c
```
关键：**力语义先经签名取证**，**歧义先经探针或拒答**，**力矩越界先于语言层否决**。

## 6. 本轮最大风险

**一句话**：语言-力矩接地把技能证书从“动作-鲁棒性”推进到“语义-物理”三证书，但其 soundness **三重依赖力矩签名可分离、传感器标定稳定、指令编译忠实**；一旦真实接触噪声、温漂与磨损使签名漂移，或长尾谓词根本没有力矩证据，系统就会产生“语义自信但物理越界”的**假接地**，故必须以 **在线标定 + 未接地即拒答 + 安全包络内的主动探针** 三重护栏，宁可承认“听不懂”，也绝不把力矩空间里的“像”当作语言语义的“是”。
