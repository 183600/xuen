# 第 43 轮（新循环第 3 轮） · 鲁棒-SLAM-证书（RSC）：把「位姿与地图可信」从隐含假设升级为可证伪、可局部隔离的证书（四层架构 v8）

> 承接第 42 轮 v19（Sim-Cert-RAG 飞轮）。第 42 轮自陈最大风险是「仿真偏差累积 + 检索幻觉」。本轮灵感词「鲁棒性」「同步定位与建图 (SLAM)」击中了比这两条更深、被所有既有轮次默认掉的一个单点故障：**整条证书栈都建立在 SLAM 给出的位姿 x̂_t 与度量语义地图 C_ms 之上，唯独 SLAM 自己没有被认证**。几何证书的漂移界 B_t、CAR 的守卫、L0 查表的有效域，全都把「位姿/地图正确」当作公理。而 SLAM 的典型失效恰恰是**自信地错**——感知别名导致假回环污染整张地图、绑架/退化导致协方差假性收缩。鲁棒性给了我们三把尺子：击穿点（能容忍多少离群测量）、鲁棒半径（能容忍多大输入扰动）、污染隔离（坏点只让局部失效而非全局静默）。本轮把这三把尺子做成 SLAM 证书层，并让 v19 的飞轮对 SLAM 失效鲁棒。

## 0. 直觉与动机

**灵感 1（SLAM → 证书的地基，也是最大单点故障）**：v19 里 IP-49 几何证书写作「m(x) = d(x, ∂O) − L_m·B_t」，其中 B_t 被当作一个已知的漂移上界；L0 查表的有效域、CAR 的守卫阈值也都来自同一张地图。但 SLAM 是**感知与规划之间的信念引擎**：一次高置信的假回环，就能把两段本不相邻的轨迹焊死，整张 C_ms 随之平移；一次绑架（kidnapping），定位丢失却仍输出低方差位姿；一段长走廊/隧道，扫描匹配沿轴向退化，协方差却在错误方向上收缩。这些失效的共同点是**协方差不再可信**：传统 SLAM 报的 Σ_t 是不一致的（inconsistent），下游拿它算出的 B_t 必然过乐观。因此「先认证 SLAM，再谈其余」不是锦上添花，而是证书栈的**地基工程**。

**灵感 2（鲁棒性 → 从「平均正确」升级到「最坏情况不静默崩」）**：鲁棒统计的第一性概念是**击穿点**：在多少比例的任意离群测量下估计器仍可被证明正确。SLAM 天然有大量离群源（动态物体、感知别名、错误数据关联）。直觉方案是把后端从最小二乘换成 GNC-TLS/TEASER 这类鲁棒估计，并用 PCM（成对一致性最大化）把回环验证变成「最大一致团」问题——团的规模直接给出击穿点下界。第二把尺子是**鲁棒半径**：对输入扰动 ‖Δz‖≤ρ 时证书是否仍成立，可以用随机平滑（randomized smoothing）或局部 Lipschitz 界估出，等价于给证书量一个「护甲厚度」。第三把尺子是**共形预测**：与其假设误差服从某个高斯模型（模型误设正是 SLAM 自信错误的根源），不如用分割共形给出**分布无关**的漂移界 B_t，使 P(e_t ≤ B_t) ≥ 1−α。但共形只保证**边际（平均）覆盖**——这恰恰是下一节污染隔离要补的洞。

**灵感 3（污染隔离 → 鲁棒性不仅属于估计器，也属于证书系统本身）**：v19 的降级是全局的（Nominal / Degraded / SafeStop）。但对 SLAM 失效而言，全局熔断既过保守（一个角落的假回环把全场打成 SafeStop），又过危险（若不熔断，坏位姿会污染所有证书）。正确结构是**证书污染隔离**：把位姿图按鲁棒一致性切成可信连通分量，假回环所在子图只让 **Tube(坏子图)** 内的证书失效，其余区域保持 Nominal。这把「鲁棒」从估计器属性升级为**证书系统的拓扑属性**：失效有边界、有半径、可局部回滚。语义侧同理——对抗补丁/语义别名会让 VLM 自信误判（APC 用随机平滑 + 跨模态一致性给语义证书一个鲁棒半径）。

**耦合升级**：RSC 输出 S_t = (x̂_t, R_t, χ_t, ρ_t, f*_t, B_t)，其中 χ_t 是故障类型（Valid / Degenerate / Aliased / Kidnapped）。S_t 直接替换 IP-49 里「拍脑袋的 B_t」；IP-51 的守卫增加「χ_t=Valid 且鲁棒裕度 > 0」这一必要条件；IP-54 的域随机化新增 SLAM 故障注入菜单；IP-55 的指纹新增「退化签名」（如长走廊、玻璃幕墙、重复纹理）；IP-52 在查表前插入一个 5μs 的 T-2 SLAM 证书自检。飞轮因此从「仿真→知识→边缘」扩展为「感知→SLAM 证书→证书栈→回注仿真」的**带地基的飞轮**。

## 1. 形式化定义（增量：定义 38–44）

**定义 38（SLAM 证书）**：S_t = (x̂_t, R_t, χ_t, ρ_t, f*_t)，其中 x̂_t ∈ SE(3) 为位姿估计，R_t ⊆ SE(3) 为**认证误差区域**（椭球或区间盒），χ_t ∈ {Valid, Degenerate, Aliased, Kidnapped} 为故障标志，ρ_t∈[0,∞) 为鲁棒半径，f*_t∈[0,1] 为击穿点。**Sound 条件**：若 χ_t=Valid，则真位姿 x*_t ∈ R_t；且 P(χ_t=Valid ∧ x*_t ∉ R_t) ≤ δ_s。注意这里把「报错」与「报对」解耦——**允许诚实地说不知道，但禁止自信地说错**。

**定义 39（证书鲁棒半径）**：ρ_t(S) = sup{ ε ≥ 0 : ∀ 测量扰动 ‖Δz‖_∞ ≤ ε、污染比例 ≤ f，仍有 χ_t=Valid ∧ x*_t ∈ R_t }。直觉：证书的「护甲厚度」。若后端对测量是 L_z-Lipschitz 的，则 ρ_t ≥ (B_t − e_t)/L_z 给出一个可计算下界；随机平滑给出另一个概率化下界。

**定义 40（击穿点）**：f*(S) = sup{ f : 鲁棒后端在比例 f 的任意离群测量下仍恢复出一致内点集 |C_max| ≥ k_min }。用 PCM 最大团可给下界 f* ≥ 1 − k_min/|E_loop|。**(ρ_t, f*_t) 构成鲁棒剖面**：一个说「输入能坏多少」，一个说「数据能被污染多少」，两者缺一不可。

**定义 41（退化证书与零空间膨胀）**：局部可观测性由信息矩阵 H_t = JᵀΩJ 的谱给出。当 λ_min(H_t) < λ_deg 时，沿最小特征向量 v_min 方向不可观测（长走廊/隧道/玻璃幕墙的典型场景）。误差区域分解为 R_t = R_t^obs ⊕ R_t^null，其中 null 方向膨胀 B_null = σ_degen/√max(λ_min, ε)。**硬约束：禁止在退化方向收缩协方差**——这正是「自信地错」的数学根源，必须用退化证书显式放大。

**定义 42（共形化漂移界）**：给定校准集 {(x_i, e_i)}，取 B_t = Q_{1−α}({e_i})（协变量偏移时用加权共形）。提供分布无关边际覆盖 P(e_t ≤ B_t) ≥ 1−α。**并附加条件覆盖监控**：按环境指纹 ψ 分桶，若某桶经验覆盖 < 1−α−γ，则把该桶整体标记为证书失效。原因见风险节：边际覆盖可以在 99% 的同时恰好放过那个 1% 的灾难子域。

**定义 43（证书污染隔离）**：位姿图 G=(V,E)，污染边集 E_bad（假回环/动态关联）。鲁棒子图分割把 G 分为可信连通分量 {G_k}；证书 Cert(x) 仅在 x ∈ Tube(G_good) 内有效。定义污染扩散半径 r_cont = max_{e∈E_bad} dist(e, G_good) 与局部失效域 L_bad = Tube(G_bad)。系统仅在 L_bad 内降级，其余区域维持 Nominal——**失效有边界**。

**定义 44（鲁棒证书传播）**：几何证书边际 m(x) = d(x, ∂O) − L_m·(B_t ⊕ B_null)，共形漂移与退化膨胀共同进入 B_t。鲁棒性要求：若输入扰动 ≤ ρ_t，B_t 的增量 ≤ L_B·ρ_t，则证书仍 sound 当且仅当**鲁棒裕度** m(x) − L_m·L_B·ρ_t > 0。这把「鲁棒」从口号变成可在线计算的裕度，也让 CAR 的守卫能显式消费 ρ_t。

## 2. 产出设计（新增 IP-57/58/59 + 升级 IP-49/51/52/54/55/50/45）

### 2.1 IP-57 ROBUST-SLAM-CERT（RSC，鲁棒 SLAM 证书层）
1. **鲁棒后端**：GNC-TLS 替代最小二乘，逐级降权离群；回环用 TEASER 全局配准做初值 + PCM 最大团做一致性验证。
2. **击穿点估计**：f* = 1 − |C_max|/|E_loop| 作为下界；同时输出「次大团/最大团」比值作为别名风险指标（比值接近 1 说明存在两套自洽但互斥的解释，正是感知别名的信号）。
3. **退化检测**：解算 H_t 的谱，λ_min 低于阈值即标记 Degenerate，并沿 v_min 膨胀 R_t^null；保留「可观测子空间」的精确界，避免过度保守。
4. **共形漂移界**：滑窗校准集 + 分桶条件覆盖；B_t 随环境指纹自适应，而不是全局常数。
5. **绑架检测**：内点率/匹配得分骤降 + 多假设位姿的先验不一致触发 Kidnapped，立即收缩 R_t 为空并请求重定位。
6. **输出契约**：S_t 打包进 IP-45 的高频健康话题，字段含 χ_t、λ_min、f*、ρ_t、B_t、覆盖桶 ID。

### 2.2 IP-58 CERT-CONTAMINATION-GUARD（CCG，证书污染隔离）
1. **可信分量分割**：对位姿图做鲁棒连通分量分解（PCM 一致的边才连），得到 G_good 与 G_bad。
2. **失效域计算**：L_bad = Tube(G_bad)（按位姿不确定度膨胀的管道域）；r_cont 作为污染扩散半径上报。
3. **局部证书裁剪**：每个证书对象携带 scope；裁剪 scope ← scope \ L_bad，空则局部失效并触发该区域的重规划，而非全局 SafeStop。
4. **回滚与修复**：G_bad 进入「隔离区」，重定位/重观测修复后解除隔离，并记录一次污染事件入 CKB。

### 2.3 IP-59 ADVERSARIAL-PERCEPTION-CERT（APC，对抗感知证书）
1. **随机平滑鲁棒半径**：对输入加高斯噪声做多数投票，r = (σ/2)(Φ⁻¹(p_A) − Φ⁻¹(1−p_A)) 给出语义分类的 L2 鲁棒半径。
2. **跨模态/多视角一致性**：几何残差、语义标签、时序跟踪三方交叉验证，任一显著不一致则拒绝该语义证书。
3. **加权共形语义校准**：按场景指纹分桶校准语义误差，抑制「平均覆盖掩盖局部灾难」。
4. **注入 CKB**：对抗补丁/语义别名样本作为负例进入 Ξ，供下一轮先验与课程使用。

回退：E87 条件覆盖大面积不达标 → 放弃全局共形，退化为「按桶查表 + 手工安全裕度」；E88 别名检测不足 → 提高 k_min 并强制重定位，牺牲可用性换安全；E89 退化检测漏报 → 关闭全量协方差信任，分数阶地退化为 B_t = B_max 的保守常数；E91 鲁棒半径估计不可靠 → 只用击穿点 f* 做门控，ρ 不进守卫；E92 隔离失效 → 整体回退到 v19 全局降级（承认可用性损失）。

## 5. 本轮最大风险

**一句话**：共形漂移界只保证**边际（平均）覆盖**，而 SLAM 的致命失效（绑架、假回环）是**局部、集中**的——平均覆盖可以是 99%，却恰好放过那 1% 的灾难子域；若条件覆盖的分桶过粗、或鲁棒半径与退化膨胀被重复计数，证书仍会在「统计上合规」的假象下静默失效，因此 E87 的分桶条件覆盖与 E92 的污染隔离必须作为红线，任一桶覆盖不达标即把该桶整体降级为 SafeStop。

# 第 43 轮产物 · 创新点清单 v20：鲁棒-SLAM-证书（RSC × CCG × APC）× 证书栈的失效隔离（四层架构 v8）

> 承接第 42 轮产物 v19。本轮**增量插入** IP-57/58/59，并升级 IP-49/51/52/54/55/50/45/47；不推倒任何既有层级。核心是把 v19 隐含的公理「SLAM 位姿与地图可信」升级为**可证伪、带鲁棒剖面、可局部隔离**的证书，让整条证书栈对 SLAM 失效鲁棒。

## 0. 核心 IP 设计

| 编号 | 名称 | 类型 | 关键改进 |

## 2. 关键算法（伪代码）

### IP-57 RSC：鲁棒 SLAM 证书
```
def slam_certificate_step(z, graph, calib_by_env, alpha=0.01):
    # 1) 鲁棒后端：GNC-TLS 逐级降权，TEASER 全局初值
    X, inliers = gnc_tls_backend(graph, z, init=teaser(graph.loop_edges))
    # 2) 回环一致性 → 击穿点 + 别名风险
    loops = graph.loop_candidates()
    C_max = max_clique(pcm(loops, inlier_thresh), min_size=k_min)
    C_second = max_clique(pcm_excluding(loops, C_max))
    f_star = 1.0 - len(C_max) / max(1, len(loops))
    alias_risk = len(C_second) / max(1, len(C_max))   # 接近 1 ⇒ 两套自洽解释
    aliased = (len(C_max) < k_min) or (alias_risk > alias_ratio_max)
    # 3) 退化检测：信息矩阵谱 + 零空间膨胀
    H = build_information(graph, X, inliers)
    lam, V = eigh(H)
    degenerate = lam[0] < lambda_deg
    B_null = (sigma_degen / sqrt(max(lam[0], 1e-9))) * V[:, 0] if degenerate else 0.0
    # 4) 共形漂移界（分桶，防边际覆盖掩盖局部灾难）
    env_bucket = bucket_id(graph.env_fingerprint)
    e = residual_norms(X, graph, inliers)
    B_conf = weighted_conformal_quantile(calib_by_env[env_bucket], e, alpha)
    B_t = inflate(B_conf, B_null)          # 沿退化方向膨胀
    # 5) 绑架检测
    kidnap = (inlier_ratio(inliers) < r_min) or prior_inconsistent(X)
    # 6) 故障分类 + 鲁棒半径
    chi = 'Kidnapped' if kidnap else ('Aliased' if aliased else
          ('Degenerate' if degenerate else 'Valid'))
    rho = estimate_robust_radius(X, graph, B_t, L_z, inliers)
    R_t = error_region(B_t, B_null, chi)   # Kidnapped ⇒ 空/全空间，诚实说不知道
    return SLAMCert(X, R_t, chi, rho, f_star, B_t, lam[0], env_bucket)

def estimate_robust_radius(X, graph, B_t, L_z, inliers):
    # Lipschitz 下界：允许 B_t 被扰动撑大，直到刚好吃掉全部余量
    e_t = max_residual(X, graph, inliers)
    return max(0.0, (B_t - e_t) / max(1e-9, L_z))
```

### IP-58 CCG：证书污染隔离
```
def contamination_guard(graph, certs, lambda_deg):
    # 1) 鲁棒连通分量：仅保留 PCM 一致边
    comps = robust_components(graph, edge_ok=lambda e: e.pcm_consistent)
    good = max(comps, key=lambda c: support(c, certs))
    bad = graph.nodes - good.nodes
    # 2) 污染域与扩散半径
    L_bad = tube(bad, inflation=pose_uncertainty(bad))
    r_cont = max((dist(e, good) for e in graph.edges if e.bad), default=0.0)
    # 3) 局部裁剪：坏域只让局部证书失效
    for cert in certs:
        cert.scope = cert.scope.difference(L_bad)
        if cert.scope.is_empty():
            cert.invalidate(mode='local')        # 触发局部重规划，不全局熔断
    return certs, L_bad, r_cont, good

def repair_and_release(graph, isolated):
    if relocalize_success(graph, isolated):
        graph.merge(isolated); return True
    return False                                  # 继续隔离，记录污染事件入 CKB
```

### IP-59 APC：对抗感知证书
```
def adversarial_perception_cert(vlm, obs, calib_by_env, alpha=0.01, sigma=0.25):
    # 1) 随机平滑：加噪多数投票，给出 L2 鲁棒半径
    p_A = smoothed_confidence(vlm, obs, sigma)          # P(预测=A)
    radius = (sigma / 2.0) * (Phi_inv(p_A) - Phi_inv(1.0 - p_A))
    # 2) 跨模态/多视角一致性
    if not (geometric_consistent(obs) and temporal_consistent(obs)
            and cross_modal_consistent(obs)):
        return SemanticCert(radius=0.0, status='REJECT')
    # 3) 加权共形语义校准（分桶）
    b = bucket_id(obs.env_fingerprint)
    cov = weighted_conformal_coverage(calib_by_env[b], obs, alpha)
    status = 'VALID' if cov >= 1.0 - alpha else 'INVALID_BUCKET'
    return SemanticCert(radius, status=status, coverage=cov, bucket=b)
```

### IP-49/51/52 升级：证书栈消费 SLAM 证书
```
# IP-49：漂移界共形化 + 退化膨胀 + 鲁棒裕度
def geometric_margin(x, cert, S_t):
    B_t = inflate(S_t.B_t, S_t.B_null)
    m = dist(x, boundary_obstacle(x)) - L_m * B_t
    robust_margin = m - L_m * L_B * S_t.rho
    return m, robust_margin

# IP-51：守卫必须消费 χ 与鲁棒裕度
def car_transition_guard(e, x, cert_obj, S_t):
    if S_t.chi != 'Valid':                 return False   # 坏位姿禁止放行
    m, rm = geometric_margin(x, cert_obj, S_t)
    return (rm > 0.0) and (m >= cert_obj.alpha_e[e] * cert_obj.theta_sim[e])

# IP-52：T-2 档 SLAM 证书自检（5μs，先于 L0 查表）
def certify_light_v3(x, guards, S_t, budget_us=200):
    if S_t.chi != 'Valid' or S_t.lam_min < lambda_deg or S_t.bucket_ok is False:
        return local_degrade(x, S_t), -2          # T-2：局部降级
    b = cert_lookup_L0(x)                         # T-1：5μs
    if not undecided_guards(b, guards): return b, -1
    if budget_us < 110: return downgrade_monotone(b), -1
    status, margin = monitor_step_INT8(quantize_obs(x))  # T0：100μs
    b.m_lo = margin
    return (b, 0) if not undecided_guards(b, guards) else (downgrade_monotone(b), 0)
```

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 共形只保边际覆盖，局部灾难子域被平均掉 | 高 | 分桶条件覆盖监控 + 不达标桶整体 SafeStop；E87 红线 |
| 鲁棒半径与退化膨胀重复计数，导致双重保守或双重乐观 | 高 | ρ、B_null、B_conf 三者来源正交化；增益统一走定义 44 的鲁棒裕度，禁止在别处二次修正 |
| PCM 最大团在密集场景退化 | 中 | 限制 \|E_loop\|、用谱聚类预分组、超时降级为保守拒绝回环 |
| 污染切分误伤真实连通地图 | 中 | 分量合并需连续多帧支持；隔离可逆并记录审计；误隔离阈值加迟滞 |
| 分桶过细导致校准样本不足、覆盖估计噪声大 | 中 | 层级桶 + 最小样本数合并（不足则退到父桶）；共形分位数用有限样本修正 |
| 随机平滑半径对小 σ 过乐观 | 中 | σ 自适应 + 半径报告与实测偏差监控；不作为唯一依据，叠加跨模态一致性 |
| 退化谱在非欧/大场景数值不稳 | 低-中 | 归一化 H、双精度、特征对用 Lanczos；λ_min 只用于门控与膨胀方向 |

## 6. 本轮最大风险

**一句话**：共形漂移界只保证**边际（平均）覆盖**，而 SLAM 的致命失效（绑架、假回环）是**局部、集中**的——平均覆盖可以是 99%，却恰好放过那 1% 的灾难子域；若条件覆盖的分桶过粗、或鲁棒半径与退化膨胀被重复计数，证书仍会在「统计上合规」的假象下静默失效，因此 E87 的分桶条件覆盖与 E92 的污染隔离必须作为红线，任一桶覆盖不达标即把该桶整体降级为 SafeStop。
