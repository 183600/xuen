# 第 66 轮（承接第 65 轮「VISTA 视觉知情安全时序归因」IP-214~223；灵感循环第 1 轮；本轮灵感：「VLA」×「谐波减速器」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，用视觉、动作分块与主动判别探针把「谁坏了」从不可辨识变成可分离，并用「长预测、短执行」把块级承诺压回不可逆视界。它自述的最大风险仍然成立：**归因依赖「故障属于有限假设集、且视觉与几何失效相互独立」；真实故障常是未知复合类型，透明/镜面/对抗 patch 会让视觉与几何共享同一 OOD 失效源，FIR 于是把未知复合故障强行归入最近假设、只膨胀错误的球——第 64 轮的单点故障升级为「归因错误的复合故障」，且系统因「已经归因」更自信地继续执行（A88）。**
>
> 本轮不增加第六个学习模态，也不把故障库再扩一格，而是换一个更底层的提问：**VISTA 缺的究竟是一个更聪明的感知，还是一个与视觉/力觉失效结构不同的物理见证？** 谐波减速器恰好提供了后者——它不是理想 N:1 齿轮，而是一只带迟滞、回差、周期传动误差与热/磨损漂移的柔顺传动；电机端/关节端双编码器与电流给出的「兑现力矩」是一个**非学习的、带负载记忆的机械见证**。VLA 则提供另一件 VISTA 没有的东西：**语义意图**——它知道「现在是在轻轻放鸡蛋，还是在用力推箱子」，这能解释同样大小的力残差到底是不是故障，但 VLA 本身会幻觉、会 OOD、会被语言注入。
>
> 本轮核心命题：**把「故障可归因」升级为「语义意图 × 机械兑现」的双重接地：用 VLA 只生成可错的语言意图先验与语义-物理一致性证据，用谐波传动状态作为第三条非学习见证，分离「传感器偏了 / 传动没兑现 / 语义理解错了 / 共因失效」；并让语言只能改变先验、不能改变硬安全约束，使证书在 VLA 出错时仍可成立。**

## 0. 直觉与动机

**灵感 1（VLA → 语义意图是归因的先验，不是真值）**
直觉：VISTA 的 FIR 只看残差，不知道机器人「想做什么」。一个 8N 的法向力，在「擦桌子」里是正常接触，在「递鸡蛋」里是压碎前兆；一个零力残差，在「自由空间接近」里正常，在「已经该接触」的任务里则是漏接触。VLA（RT-2/OpenVLA/π0 一类）最擅长的正是把图像与语言映射成任务、目标、接触模式与力的语义（"gently", "press", "insert", "hand over"）。但 VLA 的短处同样清楚：没有度量精度、会幻觉目标、会误解模糊指令、会被提示词注入、输出动作块在动力学上可能不可行。因此 VLA 正确的角色是**意图先验生成器 + 语义-物理一致性证据源**，绝不是真值或安全控制器。语言可以把 P(H) 从均匀推向某个假设，但不能单独把不安全动作变成安全。

**灵感 2（谐波减速器 → 第三条非学习见证，且带负载记忆）**
直觉：VISTA 的视觉与 F/T 都是「电子/学习」通道，透明物体、镜面、对抗 patch、软接触模型错可能让它们共享同一个 OOD 源。谐波减速器不一样：它的误差是**机械的、确定性的、与负载历史相关的**——柔轮扭转刚度在低扭矩区软、高扭矩区硬，齿隙造成换向丢失运动，传动误差随波发生器角度准周期变化，摩擦随速度/温度漂移，磨损随累计载荷缓慢增长。双编码器（θ_m, θ_j）+ 电机电流 + 已辨识的传动模型，可以给出一个**与环境接触无关的兑现力矩估计** τ̂_ext，其失效结构与视觉/F/T 不同。更重要的是**迟滞环本身是负载历史的记忆**：当前 (τ, δ) 落在环的哪一支、传动误差的相位在何处，编码了最近经历了什么；重放旧动作块或时序错位很难同时伪造这份机械记忆。它不是真值，模型也会错，但它是**错误结构不同的第三条可错证据**——这正是 VISTA 的 A88 最缺的东西。

**灵感 3（VLA × 谐波减速器 → 语义-物理一致性）**
直觉：VLA 能说出「这一步应该是轻触、轴向插入、约 3N」，谐波传动能测出「实际兑现了多少力矩、在哪个方向、迟滞环走到哪一支」。把两者对齐，就得到一个 VISTA 没有的判据：**语义上应该发生的事，物理上是否真的发生了？** 若 VLA 说「轻轻夹鸡蛋」而传动侧看到高刚度、高力矩，可能是 VLA 认错物体（H_vla），也可能是物体比看上去硬（H_common/H_model），也可能是传动摩擦过大（H_trans）——单看一个通道不可分，但三者的**跨通道不一致模式**不同。反过来，语言也能帮助归因：指令说「用力压紧」，则大力残差不应被误判为 H_force。关键是让语言只进入先验与软约束，硬约束永远由物理量决定。

**灵感 4（合流 → HARMONIA：谐波驱动机械见证 × 语言意图归因闭环）**
闭环：VLA-LIP 把语言/图像编译成结构化意图 I（只作先验与期望签名）→ TSO 用双编码器/电流/温度估计兑现力矩、扭转、迟滞、摩擦与传动误差 → TSE 形成第三组残差证据 → L-FIR 在扩展假设集上做语言条件归因（语言 log-prior 有界裁剪）→ 归因模糊时 TAP 做安全的传动激励探针（换向/低速扫掠/载荷阶跃）→ SPC 检测语义-物理不一致 → MFC 用「兑现力」而非「指令力」认证块前缀 k*，并带传动健康租约 → HMP 用迟滞记忆检测重放/时序错位 → RSC-H/WCV-H/CSP-H/AIC-H 原位升级 → J_harmonia。VISTA 把接触层拆成「接触前/中/后」，HARMONIA 再往下拆一层：**在「动作被认证」与「动作被兑现」之间，插入一个可观测、可归因、带记忆的传动层；在「残差」与「故障」之间，插入一个语言意图先验。**

**灵感 5（VISTA 组件原位升级）**
- **FIR → L-FIR**：假设集增 H_trans（传动摩擦/背隙/迟滞/传动误差/热/磨损）与 H_vla（语义/指令/目标理解错），并显式保留 H_common（共因失效）；先验由 VLA 意图条件化，但 log-prior 裁剪到 ±γ_max。
- **APP/AFA → TAP**：探针集增安全传动激励（小幅换向、低速扫掠、载荷阶跃），目标从「故障假设互信息」扩展为「故障假设 + 传动参数可辨识性」的联合信息；易损物体优先 null_test / visual_probe / language clarification。
- **VCV/VPG**：保持，但新增「传动侧接触证据」作为交叉验证；视觉不可观测时不再只能靠 F/T，可由 τ̂_ext 兜底。
- **CSC → MFC**：认证前缀从「指令力」改为「兑现力」，增传动模型 conformal 误差 q_trans 与传动健康租约。
- **RSC-V → RSC-H**：增 r_trans、r_intent、r_common；只膨胀被归因者，传动故障不再被塞进 r_force。
- **WCV-V → WCV-H**：搜索域增传动可行集 𝒯 与意图一致集 ℐ；在传动参数后验上对兑现力取最坏。
- **CSP-V → CSP-H**：技能图增 verify_transmission / excite_transmission / ask_language / retreat；块边绑定传动签名与意图哈希。
- **AIC-V → AIC-H**：干扰集增传动故障（摩擦/背隙/迟滞/热/磨损）、语言对抗（误导指令/提示注入/目标替换）、重放与时序错位；共因故障只要求判 ambiguous 并安全降级。
- **J_vista → J_harmonia**：证书增 transmission_health、tau_ext、intent_hash、transmission_model_ver、actuation_lease、hmp_residual、common_mode_flag、language_influence_bound。

```python
# HARMONIA：语义意图 → 机械兑现 → 归因 → 兑现力认证前缀
def harmonize(M, obs):
    l, img, depth, q_m, q_j, tau_m, temp = obs
    # 1) VLA-LIP：只产生意图先验与期望签名
    I = M.vla.intent(l, img)                 # (task, force_semantics, fragility, ...)
    P_I, mu_I, Sig_I = M.lip.compile(I)
    # 2) TSO：机械见证
    ts = M.tso.observe(q_m, q_j, tau_m, temp)   # tau_ext, hyst, r_te, r_lost, Sigma_tau
    # 3) TSE + 扩展签名
    rho = M.tse.signature(M.vista.phases, ts, P_I)
    # 4) L-FIR：语言条件归因（先验已裁剪）
    post, h_star, ambiguous = M.lfir.attribute(rho, P_I, gamma_max)
    if ambiguous:
        a = M.tap.choose(post, M.tso.theta_hat, M.f_safe, I.fragile)
        if a is not None:
            M.execute_probe(a); rho = M.tse.signature(...); post, h_star, ambiguous = M.lfir.attribute(rho, P_I, gamma_max)
        else:
            M.ask_language(I)                # 澄清，不进入硬约束
    # 5) SPC：语义-物理一致性
    spc = M.spc.score(mu_I, Sig_I, M.tso.contact_signature())
    if spc > M.q_spc: rho['lang'] = spc      # 作为 H_vla/H_common 证据
    # 6) MFC：按兑现力认证前缀
    A = M.vista.ach.propose(obs, H=M.H)
    k_star = M.mfc.certified_prefix(A, post, M.tso, M.m, M.alpha_chunk)
    # 7) HMP：机械记忆溯源
    if M.hmp.residual(M.tso) > M.q_hmp: M.flag('temporal_provenance_fail')
    # 8) 执行 k* 步 + 早停 + 重归因；证书
    return M, build_j_harmonia(...)
```

```python
# L-FIR：裁剪语言先验后的故障后验
def attribute(self, rho, P_I, gamma_max):
    logp = {}
    for h in self.H:
        logp[h] = log_lik[h](rho) \
                  + clip(log(P_I[h]) - log(self.P0[h]), -gamma_max, gamma_max) \
                  + log(self.P0[h])
    post = softmax(logp)
    h_star = argmax(post)
    ambiguous = post[h_star] < 1 - self.delta_fi
    return post, h_star, ambiguous

# MFC：兑现力而非指令力的认证前缀
def certified_prefix(self, A, post, tso, m, alpha_chunk):
    support = {h: p for h, p in post.items() if p >= self.delta}
    top = sorted(support, key=support.get, reverse=True)[:2]
    for k in range(1, min(len(A), m) + 1):
        f_del = [tso.delivered_force(a) for a in A[:k]]   # f_cmd + e_trans, |e_trans|<=q_trans
        if not all(safety_margin(f, h) >= 0 for f in f_del for h in top):
            return k - 1
        if violation_prob(f_del, top, q_trans, tso.lease) > alpha_chunk:
            return k - 1
    return min(len(A), m)
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（机械见证打破共因退化）**：在传动模型条件独立于视觉/F/T 失效、线性化有效时，J_H=J_VISTA+J_trans；若 J_VISTA 在 H_force/H_geo 方向奇异，而 J_trans 在该方向有正投影，则 J_H≻0，κ_w 至少增加 λ_min(J_trans)。因此「F/T 偏 vs 几何幻觉」不再只能二选一；H_trans 也从 H_force 中分离。

## 2. 形式化定义（完整版）

**定义 233（HARMONIA 闭环）** HARMONIA 是在 VISTA 的「语义流 ∘ 实时流」骨架上挂载 VLA-LIP（语言意图先验）、TSO（传动状态观测）、TSE（传动签名证据）、L-FIR（语言条件归因）、SPC（语义-物理一致性）、TAP（传动感知探针）、MFC（机械可行性证书）、HMP（谐波记忆溯源），并原位升级 RSC-V→RSC-H、WCV-V→WCV-H、CSP-V→CSP-H、AIC-V→AIC-H、J_vista→J_harmonia。不变式：**VLA/语言模型只进先验与软约束；硬安全约束、认证前缀与安全包络只依赖物理量、传动模型与有界证书；世界模型推断、语言编译、归因、探针选择、证书构建只在语义流；实时流只做观测、阶段判定、前缀派发与早停，零学习写操作。**

**定义 234（VLA 意图对象与语言条件先验）** 设语言指令 ℓ、观测 o_t。VLA/多模态语言模型 f_int 输出结构化意图
I = (task, targets, contact_mode, force_semantics, fragility, expected_events, workspace, success)
其中 contact_mode ∈ {free, contact, insert, slide, grasp, handover, wipe, …}，force_semantics ∈ {gentle, moderate, firm, unknown}。由 I 生成语言先验
P_I(H) ∝ P_0(H) exp(γ_I(H))，Σ_H P_I(H)=1，
以及期望接触签名 (μ_I, Σ_I)（如预期法向力区间、接触时刻、切向/轴向力比、允许滑移）。**I 不是状态估计，也不进入硬约束；它只改变归因先验、探针选择与 SPC 的期望签名。** 若 I 含无法编译成可监控谓词的成分，则该成分被丢弃并记 `intent_partial`。

**定义 235（语言信任域）** 语言先验必须满足 |γ_I(H)| ≤ γ_max，γ_max 由离线语言可靠性标定（不同任务/模型可不同）。若意图熵 H(I) > τ_I、目标置信度低于阈值、或 I 与观测出现逻辑冲突，置 `intent_untrusted`，退回 P_0 并降低 w_lang。语言对任意两假设后验 log-odds 的影响至多 2γ_max：对 H1,H2，
|Δ log-odds| = |γ_I(H1) − γ_I(H2)| ≤ 2γ_max。
因此语言只能在物理证据的决策边界附近改变排序；当顶层两假设的物理似然比落在 e^{±2γ_max} 带内时，必须置 `intent_sensitive`，触发 TAP、语言澄清或保守联合膨胀，不得给出确定性归因。

**定义 236（谐波传动状态与模型）** 谐波减速器由波发生器、柔轮、刚轮组成，其非理想传动可写为
θ_j = θ_m/N − δ，
τ_j = K(δ, h; Θ) + f_fric(δ̇, z, T; Θ) + e_te(θ_m; Θ) + J_j q̈_j，
其中 δ 为扭转偏转与丢失运动的合成，h 为迟滞状态（如 Bouc–Wen/Preisach 状态），z 为摩擦状态（Stribeck/Coulomb + 黏性），T 为温度，e_te 为随波发生器角度准周期的传动误差（主导项为 θ_m 的基频及谐波），Θ 为传动参数（分段刚度 K_1<K_2、迟滞宽度、齿隙、传动误差傅里叶系数、热系数、效率）。外部力矩
τ_ext = τ_j − J_j q̈_j − τ_g，
其中 τ_g 为重力/科氏等已知项。模型在自由空间也应成立；接触只改变 τ_ext，而不应改变传动参数。

**定义 237（传动状态观测器 TSO）** TSO 以双编码器 (θ_m, θ_j)、电机电流（→ τ_m）、温度 T 与模型为输入，维护状态
x = [δ, δ̇, h, z, T]ᵀ，
用 EKF/UKF 或移动视界估计（MHE）更新；输出
TS = (τ̂_ext, ĥ, r_te, r_lost, r_therm, Σ_τ, witness_level)。
其中 r_te 为实测传动误差与模型预测之差，r_lost 为换向时丢失运动相对模型预测的残差，r_therm 为热模型残差。若只有电机端编码器，则 τ̂_ext 的可观测性显著下降，witness_level 降为 `current_model` 并放大 Σ_τ；若有关节力矩传感器，则升为 `torque_sensor`。**TSO 不是力矩真值，而是带模型误差与置信度的机械见证。**

**定义 238（传动签名证据 TSE）** 定义
ρ_trans = [r_τ, r_hyst, r_te, r_lost, r_therm]ᵀ，
其中
- r_τ = (τ_FT − τ̂_ext) / √(σ_FT² + σ_τ²) 为 F/T 与传动见证的标准化交叉残差；
- r_hyst 为实测迟滞环（τ–δ 轨迹）相对模型预测环的形状残差（面积、宽度、拐点）；
- r_te、r_lost、r_therm 如定义 237。
扩展签名 ρ_H = (ρ_vis, ρ_force, ρ_trans, ρ_chunk, ρ_lang)，其中 ρ_lang 由 SPC 与意图不确定性构成。TSE 的关键不是「传动残差大就是坏」，而是**不同故障在 ρ_trans 的不同分量上留下不同结构**：F/T 偏置主要抬升 r_τ；传动摩擦/背隙主要抬升 r_lost/r_te/r_hyst；接触模型错在 load 段抬升 ρ_force 与 ρ_trans 的联动；视觉错对 ρ_trans 几乎无影响。

**定义 239（扩展故障假设与 L-FIR）** 扩展假设集
ℋ_H = {H0 健康, H_geo 几何幻觉, H_force F/T 偏置/漂移/饱和, H_model 接触模型错, H_vis 视觉错, H_policy 块策略 OOD, H_trans 传动/驱动故障, H_vla 语义/指令/目标理解错, H_common 共因失效}。
语言条件后验
P(H|ρ_H, I) = p(ρ_H|H) P_I(H) / Σ_{H'} p(ρ_H|H') P_I(H')。
若 max_H P(H|ρ_H,I) ≥ 1−δ_fi 且无 `intent_sensitive`，则定向处置：
- **H_geo**：r_geo↑，要求 VCV 确实看到接触斑落点/法向不符。
- **H_force**：r_force↑，零力窗重标定，**不动 r_geo**。
- **H_model**：r_model↑，切柔顺、扩大接触模型不确定集。
- **H_vis**：w_vis↓，VCV 降权，退回 F/T + TSO。
- **H_policy**：H↓、k↓，强制重规划。
- **H_trans**：r_trans↑，切柔顺/降速，触发传动重辨识或 TAP；**不把传动误差记到 F/T 或几何头上**。
- **H_vla**：w_lang↓，请求澄清/重述，退回语言无关安全策略；**不因语言错误而膨胀物理球**。
- **H_common**：置 `common_mode_flag`，联合膨胀 r_geo/r_force/r_model/r_trans 并 safe_idle；**不强行归因**。
若 max_H P < 1−δ_fi 或 `intent_sensitive`，判 ambiguous，进入 TAP 或 ask_language。

**定义 240（见证多样性与共因退化）** 设扩展签名线性化 E[ρ_H|θ]=S_Hθ、ρ_H∼N(S_Hθ,Σ_H)，其中 θ 为各故障幅度。定义见证多样性
κ_w = λ_min(S_HᵀΣ_H⁻¹S_H) / λ_max(S_HᵀΣ_H⁻¹S_H)。
若存在非零方向 v 使 S_H v 只落在视觉/力觉子空间且传动分量近零，则称 v 为 witness_degenerate：此时「视觉+F/T 一致」并不能证明没有共因失效，系统必须判 ambiguous 或触发 TAP，而不得声称已分离。若传动误差与视觉/F/T 误差条件独立，则
J_H = J_VISTA + J_trans，λ_min(J_H) ≥ λ_min(J_VISTA) + λ_min(J_trans)。
特别地，若 J_VISTA 在 H_force/H_geo 的共因方向奇异，而该方向在 J_trans 上有正投影，则该方向首次变为可辨识。若条件独立不成立（例如温度同时影响 F/T 与传动摩擦），必须使用块协方差 Σ_H 并直接检查 S_HᵀΣ_H⁻¹S_H 的秩，**不能假设「多一个通道就一定独立」**。

**定义 241（语义-物理一致性 SPC）** 给定意图期望签名 (μ_I, Σ_I) 与实测接触签名 y_c（由 τ̂_ext、F/T、视觉接触斑/力比等构成），定义
s_spc = (y_c − μ_I)ᵀ Σ_I⁻¹ (y_c − μ_I)。
用 split-conformal 在标定集上取 q_spc(α)。若 s_spc > q_spc(α)，输出 `semantic_physical_mismatch`，作为 H_vla/H_policy/H_common 的证据。**SPC 不能单独判 H_vla**：物理上「物体比预期硬」也会造成不一致；必须结合 ρ_trans 与 ρ_force 才能区分「VLA 认错」与「物体/接触模型异常」。若无法区分，进入 TAP 或请求语言澄清。

**定义 242（传动感知主动探针 TAP）** 探针集
A_H = A_VISTA ∪ {dir_reverse（小幅换向）, slow_sweep（低速正反扫掠）, load_step（安全载荷阶跃）, zero_load_hold（零载保持/标定）}。
选择
a* = argmax_{a∈A_H} [ I(ℋ_H; ρ_H(a) | ρ_H) + λ_θ I(Θ; ρ_trans(a) | ·) ]，
s.t. 预测兑现力 ≤ f_safe(φ̂, f̂_vis)、预测迟滞/磨损增量 ≤ ε_wear、预测热升 ≤ ε_therm、支持早停；物体易损（f_safe < f_min_probe）时禁用所有接触探针，优先 `null_test`/`visual_probe`/`ask_language`。若边际信息 < δ_fi，放弃物理探针并保守降级。TAP 的目的不是「多摸几下」，而是**在安全预算内创造传动参数与故障假设的可辨识性**：换向暴露背隙/摩擦方向性，低速扫掠暴露 Stribeck/爬行，载荷阶跃暴露迟滞与刚度分段，零载保持暴露 F/T 偏置。

**定义 243（机械可行性证书 MFC 与传动租约）** 对动作块 A_t、执行前缀 k，在后验支持集 supp_δ(post)={H:P(H|ρ,I)≥δ} 上，用**兑现力**
f_del = f_cmd + e_trans，|e_trans| ≤ q_trans(α_trans)
（q_trans 为 split-conformal 传动模型误差上界）逐一验证 ρ_safe(f_del, H) ≥ 0。取最小 k 使
P[∃s≤k: 某通道越界] ≤ α_chunk，
且 k ≤ m（m 为不可逆视界）。输出 k*(A_t) 与最小兑现力裕度。传动健康租约
lease = (t_exp, ΔΘ_max, T_max)，
当 ||Θ̂(t) − Θ̂_0|| > ΔΘ_max、T > T_max 或 t > t_exp 时证书失效，必须重辨识（TAP/null_test）或保守回退。**MFC 认证的是世界实际收到的力，而不是策略以为发出的力。**

**定义 244（谐波记忆溯源 HMP）** 传动误差相位 φ=θ_m mod 2π 与迟滞状态 h 共同构成机械记忆。由模型滚动预测在给定动作块 A_t 下的流形
ℳ(A_t) = {(φ_s, h_s, τ̂_ext,s)}_{s≤k}。
定义 r_hmp = dist((φ_obs, ĥ_obs, τ̂_ext,obs), ℳ(A_t))。若块重放、时序错位、通信延迟或传感器丢帧导致相位跳变/迟滞状态偏离流形，r_hmp > q_hmp(α) 时触发 `temporal_provenance_fail`，拒绝该块并要求重规划。HMP 与 AIC-H 的 ℰ_time 共用证据；它检测的是**机械上不可能的时间旅行**，不是所有重放（若旧块恰好从同一机械状态开始，HMP 退化为普通时序检查）。

**定义 245（RSC-H / WCV-H）** 维护独立不确定半径 r_geo、r_force、r_model、r_trans、r_intent、r_common 与信任权重 w_vis、w_lang。RSC-H 只膨胀被归因者（定义 239），并按
r = √(r_geo² + r_force² + r_model² + r_trans² + r_intent² + r_common²)
融合进 WCV-H。搜索域
B(φ̂,r) ∩ 𝒢(g) ∩ K(μ̂) ∩ ℱ(f_lim) ∩ 𝒱 ∩ 𝒯(Θ̂,r_trans) ∩ ℐ(I,r_intent)，
其中 𝒯 为传动可行集（刚度/迟滞/背隙/热/磨损包络），ℐ 为意图一致集（软约束）。CVaR 尾部采样 n_worst=8，并在传动参数后验上对 f_del 取最坏；归因模糊时按后验加权做边缘化尾部；交集为空则回退 B(φ̂,r) 并置 `attribution_conflict=True`。**语言只影响 ℐ 与 P_I，不影响 ℱ 与 𝒯 的硬边界。**

**定义 246（CSP-H 块级技能规划）** 在 CSP 的层级 A* 上以块为边：每条块边需 Valid(J_harmonia) 且 k*≥1。TSL 技能 σ 绑定 (块签名, 传动签名, 意图哈希) 的联合分布 𝒟_σ；实际联合签名到 𝒟_σ 的 Mahalanobis 距离 > τ_chunk 即判 OOD，该技能不入图。规划器可插入 `verify_transmission`（零载/换向/扫掠辨识）、`excite_transmission`（TAP 激励）、`ask_language`（澄清）、`retreat`（safe_idle）。软约束代价增 λ_fi·H(P(H|ρ,I)) + λ_lease·1[lease 将过期] + λ_lang·u_intent。

**定义 247（AIC-H 语言/传动/时序对抗认证）** 干扰集
ℰ_H = ℰ_V × ℰ_trans × ℰ_lang，
其中 ℰ_trans 含摩擦/背隙/迟滞参数漂移、热、磨损、编码器丢帧；ℰ_lang 含误导指令、目标替换、提示注入、歧义省略；ℰ_common 含同一 OOD 物体同时骗过视觉与接触模型（如透明软壳、对抗纹理 + 异常刚度）。ρ_dir 在 ℰ_H 上重算（n_cert 128→160，其中 32 给传动/语言/共因）；J_dir 增 transmission_calib_ver、language_trust_ver、hmp_ver。**语言对抗下的验收标准不是「归因正确」，而是「硬约束不被突破、归因可判 ambiguous、系统安全降级」。**

**定义 248（J_harmonia 证书）**
J_harmonia = (J_vista, transmission_health, τ̂_ext, transmission_model_ver, intent_hash, language_influence_bound, actuation_lease, hmp_residual, common_mode_flag, witness_level)。
验证规则：
Valid(J_harmonia) ⇔ Valid(J_vista)
∧ witness_level ≥ w_min
∧ (max_H P(H|ρ,I) ≥ 1−δ_fi ∨ 已执行 TAP/ask_language)
∧ k* ≥ 1 ∧ lease 有效
∧ 语言仅经裁剪先验进入（|γ_I|≤γ_max）
∧ (witness_degenerate ⇒ 已判 ambiguous)
∧ (common_mode_flag ⇒ 已 safe_idle/联合膨胀)。
审计链新增：传动是否兑现（τ̂_ext 与 τ_FT）、语言影响了多少（language_influence_bound）、机械记忆是否一致（hmp_residual）、是否发生了共因退化（common_mode_flag）。

### IP-226 TSO（传动状态观测）

```python
class TransmissionStateObserver:
    """双编码器 + 电流 + 温度 + 谐波模型；输出兑现力矩与传动残差。"""
    def __init__(self, model, theta_hat, sigma, dt):
        self.model = model                 # K(delta,h;Theta), friction, e_te
        self.theta_hat = theta_hat
        self.x = np.zeros(5)               # [delta, delta_dot, h, z, T]
        self.P = np.eye(5)
        self.dt = dt

    def predict(self, tau_m, temp):
        x, P = self.model.f(self.x, tau_m, self.theta_hat, temp, self.dt)
        F = self.model.jacobian(self.x, tau_m, self.theta_hat, temp, self.dt)
        self.x, self.P = x, F @ self.P @ F.T + self.model.Q
        return self.x

    def update(self, q_m, q_j, tau_m, temp):
        self.predict(tau_m, temp)
        delta_meas = q_m / self.model.N - q_j
        H = np.zeros((2, 5)); H[0, 0] = 1.0; H[1, 4] = 1.0
        z = np.array([delta_meas, temp])
        y = z - H @ self.x
        S = H @ self.P @ H.T + self.model.R
        K = self.P @ H.T @ np.linalg.inv(S)
        self.x = self.x + K @ y
        self.P = (np.eye(5) - K @ H) @ self.P
        tau_ext = self.model.tau_ext(self.x, tau_m, self.theta_hat)
        return TransmissionState(
            tau_ext=tau_ext, h=self.x[2],
            r_te=self.model.te_residual(self.x, q_m),
            r_lost=self.model.lost_motion_residual(self.x, q_m),
            r_therm=self.model.thermal_residual(self.x, temp),
            Sigma_tau=self.model.tau_cov(self.P),
            witness_level=self.model.witness_level)

    def delivered_force(self, a):
        # 关节兑现力矩 -> 末端兑现力，叠加 conformal 传动误差 q_trans
        return self.model.ee_force(a, self.theta_hat, self.x, q=self.model.q_trans)
```

### IP-228 L-FIR（语言条件归因）

```python
class LanguageConditionedFaultIsolation:
    H = ('H0', 'H_geo', 'H_force', 'H_model', 'H_vis',
         'H_policy', 'H_trans', 'H_vla', 'H_common')

    def __init__(self, lik, P0, delta_fi=0.15, gamma_max=0.7):
        self.lik, self.P0 = lik, P0
        self.delta_fi, self.gamma_max = delta_fi, gamma_max

    def attribute(self, rho, P_I):
        logp = {}
        for h in self.H:
            prior = np.log(self.P0[h])
            lang = np.clip(np.log(P_I[h] + 1e-12) - prior,
                           -self.gamma_max, self.gamma_max)
            logp[h] = self.lik[h].logpdf(rho) + prior + lang
        post = softmax(logp)
        order = sorted(post, key=post.get, reverse=True)
        h_star = order[0]
        ambiguous = post[h_star] < 1.0 - self.delta_fi
        intent_sensitive = (np.log(post[order[0]] + 1e-12)
                            - np.log(post[order[1]] + 1e-12)) <= 2 * self.gamma_max
        return post, h_star, ambiguous, intent_sensitive

    def directed_demote(self, h_star, balls, w, H):
        if h_star == 'H_geo':
            balls['r_geo'] *= self.kappa_infl
        elif h_star == 'H_force':
            balls['r_force'] *= self.kappa_infl
            request_null_window_recalibration()
        elif h_star == 'H_model':
            balls['r_model'] *= self.kappa_infl
            switch_compliant_control()
        elif h_star == 'H_vis':
            w['vis'] *= self.kappa_vis
        elif h_star == 'H_policy':
            H = max(H_MIN, H // 2)
        elif h_star == 'H_trans':
            balls['r_trans'] *= self.kappa_infl
            switch_compliant_control(); request_transmission_reid()
        elif h_star == 'H_vla':
            w['lang'] *= self.kappa_lang
            request_clarification()
        elif h_star == 'H_common':
            for b in ('r_geo', 'r_force', 'r_model', 'r_trans'):
                balls[b] *= self.kappa_infl
            request_safe_idle()
        return balls, w, H
```

### IP-229 SPC（语义-物理一致性）

```python
class SemanticPhysicalConsistency:
    def __init__(self, q_spc):
        self.q_spc = q_spc

    def score(self, mu_I, Sigma_I, y_c):
        e = np.asarray(y_c) - np.asarray(mu_I)
        return float(e @ np.linalg.solve(Sigma_I, e))

    def verdict(self, s):
        return 'semantic_physical_mismatch' if s > self.q_spc else 'consistent'

    def evidence(self, s, post):
        # 只增加 H_vla/H_common 的相对证据，不直接判 H_vla
        return {'H_vla': np.log1p(s), 'H_common': 0.5 * np.log1p(s)}
```

```python
class MechanicalFeasibilityCertificate:
    def certified_prefix(self, A, post, tso, m, alpha_chunk, delta=0.05):
        support = {h: p for h, p in post.items() if p >= delta}
        top = sorted(support, key=support.get, reverse=True)[:2]
        k_best = 0
        for k in range(1, min(len(A), m) + 1):
            f_del = [tso.delivered_force(a) for a in A[:k]]

                break
            if not tso.lease_valid():

            k_best = k
        return k_best
```

```python
def HARMONIA_round(M, obs, delta_f_req):
    l, img, depth, q_m, q_j, tau_m, temp, P_cloud, W_meas, tactile = obs
    # ———— 语义流 ————

    # 2) TSO/TSE：机械见证

    post, h_star, ambiguous, intent_sensitive = M.lfir.attribute(rho, P_I)

                             I.fragile, M.lip.entropy(I))
        if a is not None:
            M.execute_probe(a); ts = M.tso.update(q_m, q_j, tau_m, temp)
            rho = M.tse.signature(M.vista.phases, ts, P_I, W_meas)
            post, h_star, ambiguous, intent_sensitive = M.lfir.attribute(rho, P_I)
        else:
            M.ask_language(I)

    s_spc = M.spc.score(mu_I, Sig_I, M.tso.contact_signature())
    if s_spc > M.q_spc:

            h_star, M.balls, {'vis': M.w_vis, 'lang': M.w_lang}, M.H)

    goal = M.dms.parse_goal((M.usr.U_ep, M.usr.U_al))

    if k_star < 1:

    hmp_ok = M.hmp.check(M.tso, A, k_star, M.q_hmp)
    if not hmp_ok:
        M.flag('temporal_provenance_fail')
        return M, None, M.j_harmonia_invalid('temporal_provenance_fail')
    # 8) 实时执行 k* 步 + 早停 + 重归因
    K_safe, EV_exec, cert_exec = realtime_step_harmonia(
        M, delta_f_req, tau, A, k_star, x_prime)
    # 9) 语义流更新
    M.olp.online_step(M.olp.fuse_evidence(x_prime, W_meas, tactile, post),
                      execution_loss_grad(K_safe, EV_exec, M.balls))
    M.rsc_h.update(EV_exec, W_meas, M.balls, post)
    M.aic_h.certify(tau, M.tso, post, P_I)
    return M, K_safe, build_j_harmonia(
        cert_exec, J_grip=M.j_grip, fault_posterior=post,
        transmission_health=M.tso.health(), tau_ext=M.tso.x,
        transmission_model_ver=M.tso.ver, intent_hash=hash(I),
        language_influence_bound=M.lip.bound(I),
        actuation_lease=M.tso.lease, hmp_residual=M.hmp.residual(M.tso, A, k_star),
        common_mode_flag=(h_star == 'H_common'),
        witness_level=M.tso.witness_level)
```

## 4. 推导

**引理 9（机械见证打破共因退化）** 设 VISTA 签名与传动签名分别为
ρ_V = S_V θ + ε_V，ε_V ∼ N(0, Σ_V)；
ρ_T = S_T θ + ε_T，ε_T ∼ N(0, Σ_T)，
且 ε_V ⊥ ε_T | θ（A95）。则 Fisher 信息
J_V = S_VᵀΣ_V⁻¹S_V，J_T = S_TᵀΣ_T⁻¹S_T，
合并后 J_H = J_V + J_T。由 Weyl 不等式，
λ_min(J_H) ≥ λ_min(J_V) + λ_min(J_T)。
若 J_V 在方向 v 上奇异（例如 H_force 与 H_geo 在视觉+F/T 下不可分，存在 v≠0 使 S_V v=0），而 vᵀJ_T v > 0（传动见证在该方向有非零敏感度），则 vᵀJ_H v > 0，该方向变为可辨识。更一般地，若 J_V 的零空间为 𝒩，且 J_T 在 𝒩 上正定，则 J_H ≻ 0。κ_w 的条件数改善需 λ_max(J_T) 有界；若 λ_max 增长过快，应改用 λ_min 或归一化裕度，而**不能仅凭「多一个通道」宣称条件数一定变好**。该引理的关键前提是**传动误差与视觉/F/T 误差不相关**；若温度/振动等同时影响两者，则必须用块协方差直接检验秩，见定义 240。∎

**引理 10（语言影响有界）** 由定义 234–235，
log(P_I(H1)/P_I(H2)) = log(P_0(H1)/P_0(H2)) + γ_I(H1) − γ_I(H2)，
故语言对先验 log-odds 的改变 ≤ 2γ_max。后验 log-odds 为
log(P(H1|ρ,I)/P(H2|ρ,I)) = log(P_I(H1)/P_I(H2)) + log(p(ρ|H1)/p(ρ|H2))。
因此若 |log(p(ρ|H1)/p(ρ|H2))| > 2γ_max，语言不能翻转两者的排序；若 ≤2γ_max，则置 `intent_sensitive`。在 `intent_sensitive` 时，系统不输出确定性归因，而触发 TAP/ask_language 或联合膨胀。由此，**错误或恶意语言最多把归因推到物理决策边界附近，不能单独把低似然假设变成高置信归因，也不能突破硬安全约束**（硬约束不含 I）。∎

**引理 11（兑现力前缀安全）** 设 k*≤m，lease 有效（Θ 在 ΔΘ_max 内），q_trans 以 ≥1−α_trans 覆盖传动模型误差，视觉 conformal 以 ≥1−α_vis 覆盖，块 conformal 预算 α_chunk，后验支持集覆盖 1−δ_fi。定义事件 E = {传动误差超出 q_trans} ∪ {视觉覆盖失败} ∪ {真实故障不在支持集} ∪ {块内某步越界}。由联合界，
P[E] ≤ α_trans + α_vis + δ_fi + α_chunk。
在 E 的补集上，MFC 已对每个支持集假设验证了前 k* 步的兑现力安全，且 k*≤m，故故障在块首激活时也能在越过不可逆点前停下。因此块承诺不引入超出单步安全的新风险。∎

**定理 9（HARMONIA 端到端语义-物理安全）** 在 A94–A99 下：
1. **语言不突破硬安全**：硬约束集 𝒞_hard 不含 I；任何 a∉𝒞_hard 无论语言如何都不能被 MFC 认证（定义 243、引理 10）。
2. **故障可分离性增强**：在 A95 与传动见证非退化时，J_H≻0；H_trans/H_force/H_geo 的可辨识裕度不低于 λ_min(J_VISTA)+λ_min(J_trans)（引理 9）。
3. **兑现安全**：Valid(J_harmonia) ⇒ 执行前缀的兑现力满足力/滑移/几何约束，概率至少 1−(α_chunk+δ_fi+α_vis+α_trans)（引理 11）。
4. **语义-物理一致性可检**：H_vla/H_common 引起超过 q_spc 的签名偏移时，SPC 以 ≥1−α 检出（定理 10）；不可检时不得声称语义正确。
5. **优雅降级**：VLA 失效/语言不可信 → w_lang↓、退回语言无关策略；F/T 失效 → TSO+视觉主导；视觉失效 → TSO+F/T；双编码器缺失 → witness_level↓、证书降级；传动模型漂移 → lease 失效、重辨识/保守回退；未知/共因故障 → ambiguous/ common_mode_flag + safe_idle。
6. **实时性**：语义流承担 VLA/归因/探针/证书；实时流只做 TSO/TSE/HMP 与派发，目标 ≤3.0ms（A99）。∎

**定理 10（语义-物理不一致的可检出性）** 设 H0 下 y_c ∼ N(μ_I, Σ_I)，s_spc ∼ χ²_d；在 H_vla/H_common 下 y_c = μ_I + Δ，s_spc ∼ χ²_d(λ)，非中心参数 λ = ΔᵀΣ_I⁻¹Δ。conformal 阈值 q_spc 控制 H0 误报 ≤α；检测概率 P_det = P(χ²_d(λ) > q_spc) 关于 λ 单调递增。因此语义-物理不一致的信噪比越高越可检。若 Δ 落在他物理上合理的签名流形内（例如 VLA 认错但物体恰好具有相似力签名），或 Σ_I 在该方向方差极大，则 λ 小、检测失败——这是 SPC 的结构性盲区，必须由 TAP/澄清/保守回退兜底。∎

**命题（机械记忆的重放检测）** 设迟滞状态估计误差 |ĥ−h|≤ε_h、传动误差相位估计误差 ≤ε_φ。若重放/错位使真实状态相对块 A_t 的预测流形 ℳ(A_t) 偏移 >2ε_h（或相位 >2ε_φ），则 r_hmp > q_hmp 的概率 →1，HMP 拒绝该块。若旧块恰好从同一 (φ,h) 状态开始且动作序列在机械上等价，则 ℳ 重合，HMP 无法区分——此时需要时间戳/随机 nonce/上层重规划器共同防护。∎

## 7. 已知风险

**次级风险与缓解**：
1. **传动模型误设（未建模连杆/基座/接触动力学）**：τ̂_ext 可能吸收非传动误差；缓解：在模型中加入连杆/基座项，使用关节端 IMU/力矩传感器交叉验证，q_trans 用真实台架 conformal 标定，超界即降级；**绝不把 τ̂_ext 当力矩真值**。
2. **双编码器不是所有关节都有**：单编码器下 TSO 可观测性差；缓解：witness_level 显式降级，使用关节力矩传感器或输出端 IMU；若都没有，HARMONIA 退化为 VISTA + 语言先验，证书明确标注 `witness_level=low`。
3. **语言先验系统性偏置**：即使有 γ_max，误导语言仍可在边界内推动归因；缓解：`intent_sensitive` 触发 TAP/澄清/联合膨胀；硬约束语言无关；语言信任权重按模型/任务标定；对提示注入做独立过滤器（但不作为安全唯一依赖）。
4. **VLA 幻觉落在物理签名流形内**：SPC 不可检；缓解：ask_language、任务级常识检查、保守回退；不因 SPC 通过就认为 VLA 正确。
5. **三通道共因失效**：透明/镜面 + 异常刚度 + F/T 饱和可能同时骗过三者；缓解：common_mode_flag + safe_idle + 联合膨胀；未来引入 IMU/本体感觉/关节温度等第四独立通道。
6. **HMP 依赖迟滞可观测性**：迟滞状态估计误差大时重放检测退化；缓解：只承诺「机械上明显不可能」的重放检测，结合时间戳/随机 nonce/上层重规划；不把 HMP 当唯一时序防护。
7. **VLA 延迟/异步**：VLA 可能在语义流之外运行，意图过期；缓解：意图带 lease 与哈希，过期即 `intent_stale`，退回语言无关策略；安全路径不等 VLA。
8. **标定负担与磨损漂移**：每关节 Θ 不同且随磨损变化；缓解：群体先验 + 在线辨识 + 安全激励 + lease；离线台架覆盖多温度/负载。
9. **实时预算**：TSO+TSE+HMP 增加约 0.6ms；缓解：与编码器读取/状态估计共享，ROI/事件触发，语义流卸载 VLA/归因/证书；目标 ≤3.0ms 并保留降级模式。
10. **实验外部效度**：谐波传动摩擦/迟滞的仿真到现实差距大；缓解：以真机台架为主、仿真为辅，报告每类故障的混淆矩阵与置信区间，不只报平均值。

**本轮最大风险（一句话）**：HARMONIA 的全部新增安全性都押在「传动模型足够准、且其误差与视觉/F/T 失效不相关」上；一旦未建模的连杆柔顺、基座运动或接触动力学被 τ̂_ext 吸收，模型会把机械误差伪装成外部接触，而 VLA 的语义先验又会把它解释成合理意图——系统于是以「物理+语义双重接地」的姿态比 VISTA 更自信地错，这是本轮最大的风险。
