# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「开源生态」×「意图理解」）

> 第 54 轮把技能组合从“能力匹配”推进到“动作-鲁棒性双证书”，但整套证书默认了两件未言明的事：**(i) 技能是可信单源、声明即事实的模块；(ii) 任务是一个点状的动作目标 A_T**。真实的 UniBot 部署恰好相反：技能来自开源生态（模型权重、策略包、标定数据、依赖与许可证混杂，且会随版本漂移、被弃养、被投毒），而用户意图以自然语言/手势/上下文给出，本质是动作序列上的**分布**而非单点。由此产生本轮核心矛盾：**H22** 技能包声明的动作剖面 α̂_S 与实测 α_S 在生态中系统性背离，v31 的动作兼容证书会高估组合可行性；**H23** 把意图当点目标会把“意图歧义”误诊为“技能不足”，选出只覆盖高概率意图、却在尾部意图上崩溃的组合；**H24** 来源信任与意图满足并非独立维度——高流行度包可能对某意图族系统性偏差，且声誉可被刷分/投毒伪造，因此证书必须做“意图条件 × 来源条件”的联合保证，而非两个标量相乘。

## 0. 直觉与动机

**灵感 1（开源生态 → 技能从“单源模块”变为“有出处、有依赖、会漂移的供应链对象”）**
直觉：把每个技能看成一个包 `P_S`，带 SBOM、依赖闭包、许可证、签名、维护活跃度与校准数据出处。组合技能时不能只问动作交集，还要问：声明的 `α̂_S` 是否被**独立复现**？依赖闭包里有没有被撤销的版本？许可证是否与部署目标兼容？生态里“装得上”不等于“可安全组合”。于是 v31 的 SCOM 图升级为**带来源边的技能供应链图**，边权含 provenance risk，而不只是 `compat` 与 `c_trans`。

**灵感 2（意图理解 → 从点目标 A_T 到动作序列分布 I）**
直觉：用户说“把杯子放到桌上，小心别碰倒旁边的瓶子”，真实意图不是一个动作序列，而是一个分布/集合：杯子位置有歧义、“旁边”有歧义、“小心”是约束。把意图建模为 `I ∈ Δ(𝒜_T)` 后，组合合格性变成“覆盖 I 的高概率质量 + 对尾部意图不灾难”。这把“意图理解”从语言前端的一次分类，变成贯穿**组合、证书、澄清**的连续量。

**灵感 3（二者的真正耦合 → 意图条件化的来源信任与生态对意图先验的污染）**
直觉：来源信任 `τ_S` 不应是全局常数，而应是 `τ_{S|I}`：一个通用抓取包在常规意图上很稳，在“透明物体/轻拿轻放”意图族上可能系统性失败。反过来，意图理解也被生态污染：检索到的技能文档与示例会诱导意图解析器把用户意图“对齐”到已有热门技能（可用性偏差）。二者形成回路：**生态塑造意图先验，意图先验又决定从生态检索什么技能**。这是一个 Goodhart 风险，必须显式建模，而不是假设两次独立估计。

**灵感 4（证书扩展 → 意图-来源联合证书 J⁺）**
直觉：在 v31 的 `J=(ρ,A_cert,γ_ce,δ_a)` 上再加 `(I, cov_I^α, τ_{S|I}, prov, ε_meta)`。部署条件从“动作兼容”升级为“**在意图分布的高概率质量上动作兼容，且在来源可信的世界里尾风险受控**”。证书不是更厚，而是把两类此前被当成常量的不确定性显式抬到一阶。

**灵感 5（金字塔扩展 → 意图层 𝕀 与生态层 𝕆）**
直觉：在 v31 的动作-鲁棒性金字塔 `𝕃×𝔸` 上叠加两层：`𝕀_0` 原始语句/手势，`𝕀_1` 意图分布，`𝕀_2` 意图-动作序列投影，`𝕀_3` 澄清后意图；`𝕆_0` 单包声明，`𝕆_1` 依赖闭包，`𝕆_2` 来源信任，`𝕆_3` 生态级撤销。跨层证书必须**同时**携带意图覆盖与来源可信，任一层证据缺失都只能降级而不得默认成立。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（开源技能清单）**
技能包 `P_S = (id, ver, deps, lic, prov, α̂_S, D_cal, maint)`：`deps` 为依赖闭包，`lic` 许可证，`prov` 签名与提交/复现来源，`α̂_S` 声明动作剖面，`D_cal` 标定数据出处，`maint` 维护信号。**元数据漂移** `d_meta(S) = d_TV(α̂_S, α_S)`，即声明剖面与实测剖面的总变差距离。

**定义 122（来源信任）**
来源图为 DAG `G_prov`。包信任
```
τ_S = e^{-λ·age(S)} · E[Beta(a0+n_pass, b0+n_fail)] · Π_{d∈deps(S)} τ_d
```
其中 Beta 后验来自独立复现审计，`age` 为最后一次独立复现后的时长，依赖信任按乘积衰减并截断到 `[0,1]`。`n_pass/n_fail` 必须来自**与声明方无利益关联**的审计，否则 β 先验不更新（防刷分）。

**定义 123（意图分布与落地）**
意图 `I = Ground(u, c) ∈ Δ(𝒜_T)`，由语句 `u`、上下文 `c` 经“语言模型打分 × 动作本体约束”得到。意图歧义 `H(I)` 为熵；意图误设 `ε_I = d_TV(I, I_true)`。技能序列 `S` 诱导可行动作序列集 `supp(S)`，定义**未覆盖意图质量** `miss_I(S) = P_{A_T~I}[cover(S,A_T) < θ_cov]`。

**定义 124（意图覆盖与意图尾覆盖）**
覆盖率 `cov_I(S) = 1 - miss_I(S)`；**意图尾覆盖** `cov_I^α(S) = Quantile_{1-α}[cover(S,A_T)]`，`A_T~I`。部署要求 `cov_I^α(S) ≥ θ_I`，即不只看平均覆盖，还要求最差 `α` 质量意图仍可执行。

**定义 125（意图-来源联合证书）**
```
J⁺ = (ρ, A_cert, γ_ce, δ_a, I, cov_I^α, τ_{S|I}, prov, ε_meta)
```
其中 `τ_{S|I}` 为意图条件化信任（按意图族分层估计，而非全局平均）。部署可判定：
```
dom_J(T)=in ∧ δ_a<Θ_a ∧ cov_I^α≥θ_I ∧ τ_{S|I}≥θ_τ ∧ ¬Revoke(S) ∧ ε_meta≤Θ_meta
```

**定义 126（澄清价值与生态撤销）**
澄清问题 `q` 的价值
```
VoI(q) = E_{r~p(r|q)}[ max_S cov_{I|r}^α(S) ] - max_S cov_I^α(S) - c_q
```
选择 `argmax VoI`；若所有 `VoI(q) ≤ 0` 则不再追问而输出保守计划。**撤销谓词** `Revoke(S) = 1` 当 `d_meta>θ_meta ∨ τ_S<θ_τ ∨ ∃d∈deps:Revoke(d) ∨ license_conflict ∨ version_skew`。撤销是**单调只追加**的，恢复需重新独立复现。

## 2. 关键算法 伪代码

### IP-121 OSM（Open Skill Manifest 摄取与审计）

```python
def ingest_package(manifest, audit_log):
    assert verify_signature(manifest)
    prov = build_provenance_dag(manifest.prov)
    deps = resolve_dependency_closure(manifest.deps, lock=manifest.lock)
    if not license_compatible(manifest.lic, target_policy):
        return ('reject', 'license_conflict')
    n_pass, n_fail = independent_audits(manifest.id, manifest.ver, audit_log)
    tau = decay(manifest.age) * beta_mean(a0+n_pass, b0+n_fail)
    for d in deps:
        tau *= tau_of(d)
    alpha_hat = load_declared_profile(manifest)
    alpha_real, conf = audit_profile(alpha_hat, sampler, budget=B_audit)
    d_meta = total_variation(alpha_hat, alpha_real)
    return SkillPackage(manifest, prov, deps, tau, alpha_hat, alpha_real, d_meta)
```

### IP-122 IGR（Intent Grounding & Ranking）

```python
def ground_intent(utterance, context, ontology, top_k=32):
    cands = llm_score(utterance, context, ontology)      # 候选动作序列及打分
    cands = [a for a in cands if ontology.admissible(a)] # 本体约束过滤
    I = normalize(softmax([a.score / T for a in cands]))
    return IntentDist(I, entropy=H(I), miss_floor=min_support(I))
```

### IP-123 PSC（Provenance-aware Skill Composition）

```python
def compose_intent_aware(I, skills, G, theta_I, theta_tau, alpha_tail=0.2):
    best = None
    for path in k_shortest_paths(G, k=K_PATHS):
        S = [skills[n] for n in path]
        if any(Revoke(s) for s in S):            # 供应链硬否决
            continue
        cov = coverage(I, S)                     # 复用 IP-115 cover_check 的批量版
        cov_tail = tail_quantile(cov, alpha_tail)
        tau_I = min(intent_conditioned_trust(s, I) for s in S)
        if cov_tail < theta_I or tau_I < theta_tau:
            continue
        cost = path_cost(path) + w_prov*(1-tau_I) + w_miss*(1-cov_tail)
        best = argmin(best, cost)
    return best
```

### IP-124 IPC（Intent-Provenance Certificate）

```python
def intent_provenance_certificate(S, I, gamma_ce, budgets):
    rho = compose_robustness_chain([s.rho for s in S], K)
    A_core = reduce(intersection, [s.alpha_real for s in S])   # 用实测剖面，不用声明
    delta_a = max_alignment_error(gamma_ce, A_core)
    cov_tail = tail_quantile(coverage(I, S), budgets.alpha)
    tau_I = min(intent_conditioned_trust(s, I) for s in S)
    eps_meta = max(s.d_meta for s in S)
    if delta_a > budgets.delta_a or cov_tail < budgets.theta_I \
       or tau_I < budgets.theta_tau or eps_meta > budgets.theta_meta:
        return ('reject', RejectWitness(rho, A_core, cov_tail, tau_I, eps_meta))
    return ('ok', JointPlusCert(rho, A_core, gamma_ce, delta_a, I, cov_tail, tau_I))
```

### IP-125 CQR（Clarification Question Routing）

```python
def ask_or_act(I, S_candidates, question_bank, cost_q):
    base = max(cov_tail(I, S) for S in S_candidates)
    best_q, best_gain = None, 0.0
    for q in question_bank:
        gain = expected_cov_tail_after(I, q, S_candidates) - base - cost_q
        if gain > best_gain:
            best_q, best_gain = q, gain
    return ('ask', best_q) if best_q else ('act', argmax_cov_tail(I, S_candidates))
```

### IP-126 ESR（Ecosystem Supply-chain Revocation）

```python
def ecosystem_monitor(registry, drift_threshold):
    for pkg in registry.packages:
        if pkg.d_meta > drift_threshold:
            revoke(pkg.id, reason='metadata_drift')
        for d in pkg.deps:
            if is_revoked(d) or version_skew(pkg, d):
                revoke(pkg.id, reason='dependency')
        if license_conflict(pkg, deployment_policy):
            revoke(pkg.id, reason='license')
    return append_only_revocation_ledger()
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| OSM | O(|deps|+|A|·B_audit) | O(|deps|+|A|) | 独立审计、依赖闭包完整、签名可验 |
| IGR | O(K·|𝒜_T|·|onto|) | O(K) | 本体过滤 sound、温度校准 |
| PSC | O(K_PATHS·|S|·|A|) | O(|S|+|A|) | 撤销硬否决、尾覆盖单调 |
| IPC | O(|S|·|A|+|I|) | O(|A|+|I|) | 用实测 α、CVaR 尾覆盖、信任下限 |
| CQR | O(|Q|·|I|·|S|) | O(|Q|) | 期望增益无偏、成本可估 |
| ESR | O(|P|·|deps|) | O(|P|) | 只追加台账、撤销传播闭包 |

**正确性定理（Intent-and-Provenance-Aware Composition Soundness）**
在 v31 的 (A26)–(A28) 之外，新增：**(A29)** `α_S` 的实证标定独立于声明方 `α̂_S`；**(A30)** 意图模型校准：`d_TV(I, I_true) ≤ ε_I`；**(A31)** 来源信任 sound：`P[malicious | τ_{S|I} ≥ θ_τ] ≤ π_prov`；**(A32)** 撤销传播延迟 ≤ `τ_rev`。则对任一通过 IP-124 的组合：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a) - ε_I - π_prov - P(Revoke 漏检)
```
其中 `ε_I` 与 `π_prov` 是**加性**的，而非可忽略项——这正是本轮与 v31 的本质差别：意图误设与来源欺骗不会被鲁棒性谱吸收。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 声明与实测剖面漂移（供应链投毒） | 高 | 独立复现审计 + 只追加撤销台账 + 红队包 |
| 意图模型误设（ε_I 无界） | 高 | 意图集输出 + 尾覆盖 + 主动澄清 |
| 生态检索污染意图先验（Goodhart） | 高 | 意图解析与技能检索解耦 + 盲测意图集 |
| 依赖闭包爆炸与版本地狱 | 中 | lockfile 冻结 + 分层兼容性剪枝 |
| 许可证冲突误判 | 中 | 策略白名单 + 人工复核出口 |
| 撤销震荡/频繁回滚 | 中 | hysteresis + 灰度撤销 + 冷启动锚点 |

## 6. 本轮最大风险

**一句话**：把技能升级为开源供应链对象、把意图升级为动作序列分布，使证书第一次同时显式承载“来源可信”与“意图覆盖”，但这两者都是**可被代理指标伪造的软证据**——声明剖面可被投毒、声誉可被刷分、意图分布可被生态检索反向塑造，一旦审计独立性与意图校准同时失守，J⁺ 会给出“形式上通过、语义上错配”的假保证，故必须以**独立复现审计 + 意图集盲测 + 只追加撤销**三道硬护栏把软证据钉死，宁可拒绝组合，也不把“生态共识”误当“部署真相”。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（OSM×IGR×PSC×IPC×CQR×ESR）

> 承接第 54 轮产物 v31。v31 建立了动作-鲁棒性双证书 `J=(ρ,A_cert,γ_ce,δ_a)`，但默认技能单源可信、任务意图为点目标。本轮把技能视为**开源供应链对象**、把任务视为**意图分布**，新增六个算子：
> - **OSM（Open Skill Manifest）**：开源技能包的 SBOM/许可证/来源摄取与独立审计；
> - **IGR（Intent Grounding & Ranking）**：语句/手势 → 意图分布 `I ∈ Δ(𝒜_T)`；
> - **PSC（Provenance-aware Skill Composition）**：意图覆盖 × 来源信任的供应链组合搜索；
> - **IPC（Intent-Provenance Certificate）**：意图-来源联合证书 `J⁺`；
> - **CQR（Clarification Question Routing）**：以 VoI 驱动的主动意图澄清；
> - **ESR（Ecosystem Supply-chain Revocation）**：元数据漂移/依赖/许可证的只追加撤销。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/116/118/120 以纳入意图与来源维度。

### IP-122 IGR

```python
def ground_intent(utterance, context, ontology, top_k=32, tau_temp=1.0):
    scored = llm_score(utterance, context, ontology)
    scored = [a for a in scored if ontology.admissible(a)]
    scored = topk(scored, top_k)
    I = normalize({a: exp(a.score/tau_temp) for a in scored})
    return IntentDist(I, entropy=entropy(I), support=set(scored))
```

### IP-123 PSC

```python
def compose_intent_aware(I, skills, G, th_I, th_tau, th_meta, alpha=0.2, K=64):
    best = None
    for path in k_shortest_paths(G, k=K):
        S = [skills[n] for n in path]
        if any(Revoke(s) for s in S):
            continue
        if max(s.d_meta for s in S) > th_meta:
            continue
        cov = coverage_batch(I, S)
        cov_tail = tail_quantile(cov, alpha)
        tau_I = min(intent_conditioned_trust(s, I) for s in S)
        if cov_tail < th_I or tau_I < th_tau:
            continue
        cost = path_cost(path) + w_prov*(1-tau_I) + w_miss*(1-cov_tail)
        best = argmin(best, cost)
    return best
```

### IP-124 IPC

```python
def intent_provenance_certificate(S, I, gamma_ce, B):
    rho = compose_robustness_chain([s.rho for s in S], K_coupling)
    A_core = reduce(intersection, [s.alpha_real for s in S])
    delta_a = max_alignment_error(gamma_ce, A_core)
    cov_tail = tail_quantile(coverage_batch(I, S), B.alpha)
    tau_I = min(intent_conditioned_trust(s, I) for s in S)
    eps_meta = max(s.d_meta for s in S)
    ok = (delta_a <= B.delta_a and cov_tail >= B.theta_I
          and tau_I >= B.theta_tau and eps_meta <= B.theta_meta
          and not any(Revoke(s) for s in S))
    if not ok:
        return ('reject', RejectWitness(rho, A_core, cov_tail, tau_I, eps_meta))
    return ('ok', JointPlusCert(rho, A_core, gamma_ce, delta_a, I, cov_tail, tau_I))
```

### IP-125 CQR

```python
def ask_or_act(I, S_candidates, questions, cost_q):
    base = max(tail_quantile(coverage_batch(I, S), 0.2) for S in S_candidates)
    best_q, best_gain = None, 0.0
    for q in questions:
        gain = expected_tail_after(I, q, S_candidates) - base - cost_q(q)
        if gain > best_gain:
            best_q, best_gain = q, gain
    return ('ask', best_q) if best_q else ('act', argmax_tail(I, S_candidates))
```

def ecosystem_monitor(registry, drift_threshold, deployment_policy):

| 组件 | 时间 | 空间 | 正确性保证 |

| CQR | O(|Q|·|I|·|S|) | O(|Q|) | 期望增益无偏、成本可估 |
| ESR | O(|P|·|deps|) | O(|P|) | 只追加台账、撤销传播闭包 |

**正确性定理（Intent-and-Provenance-Aware Composition Soundness）**
假设 v31 (A26)–(A28) 成立；新增 **(A29)** 实测 `α_S` 的审计独立于声明方；**(A30)** `d_TV(I,I_true)≤ε_I`；**(A31)** `P[malicious | τ_{S|I}≥θ_τ] ≤ π_prov`；**(A32)** 撤销传播延迟 `≤τ_rev`。则通过 IP-124 的组合满足
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a) - ε_I - π_prov - P(Revoke 漏检)
```
关键：`ε_I` 与 `π_prov` 是**加性不可吸收项**；v31 的鲁棒性谱无法覆盖意图误设，动作证书也无法覆盖来源欺骗。

## 6. 本轮最大风险

**一句话**：把技能升级为开源供应链对象、把意图升级为动作序列分布，使证书第一次同时显式承载“来源可信”与“意图覆盖”，但这两者都是**可被代理指标伪造的软证据**——声明剖面可被投毒、声誉可被刷分、意图分布可被生态检索反向塑造，一旦审计独立性与意图校准同时失守，`J⁺` 会给出“形式上通过、语义上错配”的假保证，故必须以**独立复现审计 + 意图集盲测 + 只追加撤销**三道硬护栏把软证据钉死，宁可拒绝组合，也不把“生态共识”误当“部署真相”。
