# 第 69 轮（承接第 68 轮「CALM-RAS 标定感知风险自适应闭环」IP-243~252；灵感循环第 2 轮；本轮灵感：「创新点提炼」×「触觉感知」）

> 第 68 轮 CALM-RAS 把标定升级为在线潜变量，却在自己的风险句里承认了范式的原罪：**所有参照都是内部的**——视觉对着力学校、力觉对着视觉校、模型对着模型校。于是落在标定带宽内的缓变故障会被「完美解释掉」，系统在「测量越来越准」的假象里失去检出能力。根因不是滤波器设计，而是**计量学的自指性（self-referential metrology）**：一个只有内部参照的标定系统，原则上无法区分「传感器漂了」与「世界变了」。
>
> 本轮灵感恰好给了两把互补的钥匙：
>
> - **触觉感知**：接触是机器人唯一「物理地碰到世界」的模态。滑移起始、碰撞、接触断裂、粘滞都是**物理分岔事件（physical bifurcation event）**，且可由与力通道物理异构的通道（高频振动、声发射、视觉位移、电机电流）独立确认。它们是**外部裁判（external oracle）**，不落在力/视觉的标定群内，因此不会被标定吸收。
> - **创新点提炼**：R65–R68 已积累 252 个 IP，生成速度远超验证速度。把「提炼」当作可形式化操作（保证格 + 最小描述长度 MDL），会发现一个**幽灵保证（phantom guarantee）**：R68 声称「慢故障不被吸收」，但该保证不由任何既有不变量生成——它依赖的是「频率分离」，而频率分离只是时间域性质，不是锚。提炼不只是记账，它是**缺口探测器**：它精确指出了缺的那块积木是「外部锚定」。
>
> 核心命题：**TACIT-RAS（Tactile-Anchor + Calibration-Identifiability disTillation）——用稀疏但因果接地的触觉事件作为外部锚，把标定更新硬约束在「锚可辨识子空间」内，不可辨识方向显式冻结并转保守；同时用保证格提炼把 252 个 IP 压成 6 条不变量，让「提炼」本身成为缺口探测与反通胀机制。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**我的标定凭什么可信**」——当参照全在系统内部时，只有物理接触能当外部裁判。

## 0. 直觉与动机

**灵感 1（触觉感知 → 接触事件是物理分岔，不是又一路传感器）**
直觉：不要再用「触觉也参与标定」这种同构思路——那只会把自指性再加深一层（又多一个可被标定的模态）。触觉的独特价值是**事件性**：滑移不是某个力的数值，而是「静摩擦锥被突破」这一刻的定性分岔；碰撞是动量交换的一刻；接触断裂是法向力归零的一刻。这些事件可以由与力通道**物理异构**的通道独立确认，因此提供了标定群之外的**外部标签**。用控制论的话说：R68 的残差全是「内部一致性残差」，而滑移事件是「外部可观测性残差」。结论：不要问「触觉能不能测得更准」，要问「触觉能不能在别人都自说自话时，说一句物理上不可辩驳的话」。

**灵感 2（触觉感知 → 锚定的是可辨识性的秩，不是精度）**
直觉：R68 的 U(ĉ)=tr(Σ) 只度量「标定不确定度」，却默认标定在**所有方向**上都在发生。真正关键的量是**可辨识性（identifiability）**：锚能观测到 c 的哪些方向？把锚雅可比 J_A 的行空间叫可辨识子空间 S_id，其零空间 S_ua 叫不可辨识子空间。R68 的 COF 在整个 c∈ℝ¹² 上自由更新，等于让慢故障在 S_ua 里被悄悄吸收；TACIT 只许在 S_id 更新，S_ua 显式冻结——**不是让标定更强，而是让标定更诚实**。这与 R68 的速率限制器正交：速率限制管「时间上不可吸收」，锚投影管「结构上不可吸收」，两者合起来才覆盖全空间。

**灵感 3（触觉感知 → 序锚与共模抵消）**
直觉：绝对阈值锚依赖已知摩擦系数/质量，工程上难得。退一步用**序锚（ordinal anchor）**：两指加载时谁先滑、两个接触点谁先断、碰撞与滑移谁先发生——这些**顺序**对共模增益/零偏不敏感（同一读出的公共误差同时作用于比较双方）。序锚辨识差分/相对参数，静态零读辨识公共偏移，二者互补。但序锚对共模方向天然失明——这恰好说明为什么单靠序锚不够：必须「静态锚（定偏移）+ 事件锚（定尺度/差分）+ 计量基准（定绝对尺度）」三件套才能张满 c。

**灵感 4（创新点提炼 → 保证格、幽灵保证与不变量基）**
直觉：把每个 IP 看成一条「机制 → 保证」的映射。252 个 IP 里大量是同一不变量的换装（R65 的收缩、R66 的遮挡保守、R67 的前瞻收缩、R68 的标定下限，其实是同一条「不确定只收紧」）。用保证格 + MDL 求最小生成基，得到 6 条不变量：I1 收缩单调性、I2 时间尺度分离、I3 外部锚定（缺）、I4 影子认证提交、I5 同源共模抵消、I6 归因顺序。提炼的副产品是**幽灵保证**：被某个 IP 声称却不由任何不变量生成的保证。R68 的「慢故障不被吸收」正是幽灵保证——它名义上由 I2 生成，但 I2 只是时间域分离，对 ω_f < ω_cal 无能为力。提炼精确指出：缺的是 I3，而触觉事件正好提供 I3。

**灵感 5（两灵感合流 → TACIT-RAS 六组件 + 一次自我瘦身）**
1. **TAC**：触觉锚事件通道（滑移/碰撞/断裂/粘滞），异构独立检测；
2. **OAR**：序锚 + 阈值锚残差，共模鲁棒；
3. **CIC**：标定可辨识性证书（J_A 的秩、S_id/S_ua、每方向证书）；
4. **COF†**：锚投影标定滤波——只更新 S_id，S_ua 冻结并抬不确定度；学习型 cal_head 降级为「提案」，必须有锚背书；
5. **CFA†**：锚条件归因——S_ua 上的慢故障显式升格为独立假设 H_slow，永不交给标定；
6. **CAC† + DIB/RDX**：把「锚一致性」「标定 canary」加进认证；DIB 提炼创新基、RDX 量化研究债。
同时做**一次自我瘦身**：把 R65–R68 的重复 IP 合并进 6 不变量，删去被覆盖的冗余主张（保留证据、删除重复主张），让创新点清单从 252 收敛到一个可审计的基。

## 1. 形式化定义（增量：定义 293–307）

**定义 293（TACIT-RAS 总览）** TACIT-RAS = (TAC, OAR, CIC, COF†, CFA†, CAC†, DIB, RDX, RAS-WM‡)。四条不变式：
(i) **实时流零学习写操作**（继承 R68，一切参数更新只在影子流、经认证原子换装）；
(ii) **锚优先**：任何标定更新必须落在锚可辨识子空间 S_id 内，S_ua 一律冻结；
(iii) **锚只收紧**：锚/事件证据只能抬高 λ_floor 或收缩 k，绝不放宽（I1 的强化）；
(iv) **锚可反驳**：锚自身健康度 h_A 是独立潜变量，h_A 低时锚降级为普通证据、退回 R68 保守行为，而不是盲信。

**定义 294（触觉锚事件）** ℰ_tac = {E_slip, E_impact, E_break, E_stick}，事件 e = (t_e, 类型, 确认通道集 C_e, 置信度)。E_slip：切向/法向力比逼近静摩擦锥 + 高频振动签名；E_impact：法向力峰 + 声发射；E_break：接触力过零 + 视觉/电容确认；E_stick：相对位移归零持续 τ_stick。**异构性条件 A95**：事件检测器不得使用被标定力通道的尺度/零偏参数。

**定义 295（锚残差：阈值锚 + 序锚）** 阈值锚残差 r^thr_e = g_e(ŷ, ĉ)（如滑移时刻的 F_t − μ̂F_n）；序锚残差 r^ord = Σ_{事件对} 1[order_pred ≠ order_obs]（顺序失配数）。总锚残差 r_A = (r^thr, r^ord)。与 R68 残差的关系：r_t 是内部一致性，r_A 是外部可观测性；拼成 r^+ = (r_t, r_A)。

**定义 296（标定可辨识性证书 CIC）** c ∈ ℝ^{d_c}（d_c=12）；锚雅可比 J_A = ∂r_A/∂c ∈ ℝ^{m_A×d_c}；S_id = rowspace(J_A)，S_ua = null(J_A)；锚覆盖率 ρ_A = rank(J_A)/d_c。每方向证书 cert_k ∈ {ANCHORED, WEAK, BLIND}，按 J_A 奇异值与该方向先验精度之比分类。CIC = (J_A, ρ_A, {cert_k}, S_ua 正交基)。**披露义务**：S_ua 非空必须写入证书并对外声明。

**定义 297（锚投影标定滤波 COF†）** 继承 R68 的 EKF，但更新加行空间投影：
`Δc = Π_{S_id} · K · (r^+ − h(ĉ))`，`Π_{S_id} = J_A^+ J_A`。
S_ua 分量不更新，Σ 在 S_ua 上只增不减（先验方差膨胀）⇒ U 自动升高。速率限制器保留（时间防线）+ 投影（结构防线）。学习型 cal_head 输出只作提案 c_prop：其 S_id 投影与锚一致才接受，S_ua 分量一律不采信。

**定义 298（锚条件归因 CFA†）** 假设空间扩为 {H_cal, H_sensor^trans, H_slow, H_world}。核心判据是**方向一致性**：
- p(r^+ | H_cal, ĉ)：内部残差与锚残差应**同时**小；
- p(r^+ | H_slow)：内部残差可被慢变量解释，但锚残差方向落在 S_id 且持续单侧偏置；
- **若内部说「标定好了」（r_t 小）而锚说「物理上不对」（r_A 大），判 H_slow/H_sensor^trans，绝不判 H_cal**；
- S_ua 上的残差不得判 H_cal（冻结即不解释）。

**定义 299（慢故障可检测性条件）** 故障签名 v_f = v_id ⊕ v_ua。可检测当且仅当 ‖v_id‖ ≥ τ_det（锚可判）；若 ‖v_ua‖ 主导，则不可由锚检测 ⇒ 进保守分支（λ ≥ 0.8、k 收缩、标定冻结），并记入**不可观测账本（unobservable ledger）**。

**定义 300（保证格与提炼 DIB）** IP i ↦ (M_i 机制, G_i 保证集)，G_i ⊆ 𝒢。覆盖 i ≼ j 若 G_i ⊆ G_j 且 M_i 可被 M_j 替换。提炼目标：
`min_{B ⊆ IP} Σ_{i∈B} MDL(i)  s.t.  cover(B) ⊇ ∪_i G_i`（允许松弛 ε）。
**幽灵保证**：g ∈ ∪G 但不被 B 中任何不变量生成；判定依据是 g 的证明依赖了「未锚定的分离性」或「未验证的学习模块」。DIB 输出：不变量基 {I1..I6}、吸收映射、幽灵保证清单、下一轮缺口。

**定义 301（研究债指数 RDX）** `RDX = (未验证 IP 数 × 平均存续轮数) / (被证伪或合并 IP 数 + 1) + w_g·#幽灵保证`。反通胀规则：每轮新增 IP 必须附带验证预算或合并动作，否则 RDX 单调上升。

**定义 302（CAC† 认证六关）** R68 五关 + 第 6 关 **锚一致性 / 标定 canary**：注入的慢故障 canary 不得被 COF† 在 S_id∪S_ua 上「标好」；S_ua 冻结后其残差必须仍超阈值；否则一票否决。

**定义 303（AIC-TACIT 干扰集）** ℰ_TACIT = ℰ_CALM × ℰ_anchor × ℰ_distill；ℰ_anchor = {锚退化、锚欺骗、锚稀疏冷启动、共模盲区}；ℰ_distill = {错误合并、覆盖漏检、幽灵保证残留}。

**定义 304（J_TACIT 证书）** J_TACIT = (J_CALM, anchor_health, ρ_A, cert_vec, S_ua_hash, distill_basis_hash, rdx, tacit_ver)。Valid ⇔ Valid(J_CALM) ∧ anchor_health > τ_h ∧ (S_ua = ∅ ∨ 保守分支已激活) ∧ 无未披露幽灵保证。

**定义 305（管线）** 离线：标定锚事件检测器 → 估计锚雅可比 J_A → 提取不变量基（DIB）。在线：TAC 异步检测 → OAR 计算 → COF† 锚投影更新 → CFA† → CAC† 六关 → 原子换装；每 N 轮跑一次 DIB/RDX 审计。

**定义 306（锚健康与反驳权）** 锚健康度 h_A ∈ [0,1] 由跨锚一致性（多触点/声学/电流）与已知基准回归给出。仅当 h_A > τ_h 时锚拥有「收紧权」；h_A ≤ τ_h 时锚降级为普通证据、退回 R68 保守行为（λ ≥ 0.8），**且不得因锚失效而放宽**。

**定义 307（交叉锚冗余）** 每个锚事件至少由两个物理异构通道确认（voting），单通道不得单独触发「标定可辨识升级」或「故障判定」；≥3 通道时允许 2-of-3。这是「谁来锚定锚」的第一道防线。

```python
# IP-253/254 TAC+OAR：触觉锚事件与锚残差（异步，独立通道）
class TactileAnchorChannel:
    CHANNELS = ('vibration', 'acoustic', 'visual_disp', 'motor_current')

    def detect(self, tactile, img, current):
        ev = []
        if slip_signature(tactile, self.CHANNELS):     # 静摩擦锥 + 振动
            ev.append(AnchorEvent('E_slip', t_now, quorum(self.CHANNELS)))
        if impact_signature(tactile, self.CHANNELS):
            ev.append(AnchorEvent('E_impact', t_now, quorum(self.CHANNELS)))
        if contact_break(tactile, img):
            ev.append(AnchorEvent('E_break', t_now, quorum(self.CHANNELS)))
        return ev

    def residuals(self, ev, c_hat):
        r_thr = [g_e(self.y, c_hat) for e in ev if e.type in ('E_slip','E_impact')]
        r_ord = self.ordinal_mismatch(ev, self.predicted_order(c_hat))
        return AnchorResidual(r_thr, r_ord)


# IP-255 CIC：可辨识性证书（J_A 的秩与 S_id/S_ua）
class CalibrationIdentifiabilityCertificate:
    def build(self, static_anchor, event_anchor, c_prior):
        J = jacobian(lambda c: anchor_map(c), c_prior)   # m_A x d_c
        U, sv, Vt = svd(J)
        rank = (sv > sv_floor).sum()
        S_id = Vt[:rank].T                               # 行空间基
        S_ua = Vt[rank:].T                               # 零空间基
        cert = classify(sv, c_prior.sigma)               # ANCHORED/WEAK/BLIND
        return CIC(J, rank / len(c_prior.mu), S_id, S_ua, cert)


# IP-256 COF†：锚投影标定滤波（时间防线 + 结构防线）
class AnchoredCalibrationFilter(CalibrationObservationFilter):
    def __init__(self, cic, **kw):
        super().__init__(**kw); self.cic = cic

    def step(self, anchor_res, r_internal, sigma_stat):
        self.predict()
        obs = concat([anchor_res.thr, anchor_res.ord, r_internal])
        H = self.cic.J
        K = self.S @ H.T @ inv(H @ self.S @ H.T + R)
        delta = K @ (obs - self.h(self.c))
        delta = self.cic.S_id @ (self.cic.S_id.T @ delta)   # 投影到 S_id
        self.c = self.c + delta
        self.rate_limit()                                   # R68 时间防线
        self.S = self.S + self.cic.S_ua @ self.cic.S_ua.T * sigma_ua # S_ua 冻结膨胀
        return self.c, trace(self.S)


# IP-257 CFA†：锚条件归因（内部小 + 锚大 ⇒ 慢故障，绝不判标定）
def anchor_conditioned_attribution(r_internal, r_anchor, c, U, cic):
    p_cal = gauss(r_internal, 0, R_i) * gauss(proj(r_anchor, cic.S_id), 0, R_a)
    p_trans = gauss(r_internal, 0, R_i) * heaviside_anchor(r_anchor, tau_a)
    p_slow = gauss(r_internal, 0, R_slow) * onesided(r_anchor, cic.S_id)
    p_world = gauss(r_internal, 0, R_world) * gauss(r_anchor, 0, R_a)
    post = normalize(dict(H_cal=p_cal, H_trans=p_trans, H_slow=p_slow, H_world=p_world))
    if norm(proj(r_anchor, cic.S_ua)) > tau_ua:       # 不可锚方向有残差
        post = conservative_branch(post)               # 不判 H_cal
    return post


# IP-259 DIB：创新点提炼（保证格 + MDL 最小基）
def distill(ip_ledger):
    order = topological_by_guarantee(ip_ledger)        # 保证格
    B = greedy_mdl_cover(order)                        # 最小描述长度覆盖
    phantom = [g for g in covered_goals(ip_ledger)
               if not generated_by(B, g)]
    return DistillationBasis(B, phantom, rdx(ip_ledger, B))


# IP-262 主闭环：TACIT round
def TACIT_round(M, obs):
    V, T, P, L, tac, img, cur, flow = obs
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))
    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)

    ev = M.tac.detect(tac, img, cur)                    # 1) 异步锚事件
    r_A = M.tac.residuals(ev, M.cof.c)                  # 2) 锚残差
    r = residuals(x_prime, o, M.wm_residual_cache)      #    内部残差
    c, U = M.cof.step(r_A, r, sigma_stat(M))            # 3) COF† 锚投影
    cic = M.cic.build(M.static_anchor, ev, c)           # 4) 可辨识性证书

    rho = M.fir_signature(z, M.residual_log)
    joint = M.cfa(r, r_A, c, U, cic)                    # 5) 锚条件归因
    lam = max(M.efs.risk_scale(joint),                    # 6) 风险缩放
              0.8 if (U > TAU_CAL or cic.has_blind or M.tac.h_A < TAU_H) else 0.6)
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, joint, min(M.vista.m, M.m_emo),
                                    M.alpha_chunk, M.wm_preds)
    if M.tac.h_A < TAU_H or cic.has_blind:              # 7) 锚不可信/盲区收缩
        k = min(k, k_anchor_shrink(A, cic))

    M.vqa_c.submit_async(M.wm_preds, {'anchor': r_A, 'cic': cic, 'joint': joint})
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit)  # 8) CAC† 六关
    return k, lam, joint, cic
```

## 3. 推导

**引理 16（仿射标定的锚可辨识三元组）** 设每接触通道 y = s·y* + b + ε。静态自由空间锚（y*=0）给出 b；滑移/碰撞事件在被独立通道确认的时刻满足 F_t* = μF_n*，给出尺度**比值** s_t/s_n；已知质量静载（F*=mg）给出**绝对尺度**。三者齐备 ⇒ (s,b) 可辨识，rank(J_A) 达满。**缺绝对尺度 ⇒ 公共尺度方向不可辨识（S_ua 至少 1 维）**——这正是比例型慢故障（增益老化）的盲区。

**引理 17（结构防线与时间防线正交，合起来覆盖慢故障）** R68 速率限制给出时间互补：ω_f ≥ 3ω_cal 的故障残余 ≥ (2/3)‖r_f‖（引理 13）。TACIT 锚投影给出结构互补：签名落在 S_id 的**任意带宽**故障（含 ω_f ≪ ω_cal）满足 ‖J_A v_f‖ ≥ τ_det，故可检出——检测依据是**结构矛盾**而非频率，与 ω_f/ω_cal 无关。两防线覆盖 S_id ∪ {ω_f ≥ 3ω_cal}；唯一不可覆盖区是 `S_ua ∩ {ω_f < 3ω_cal}`，其维数由 ρ_A 显式给出而非隐藏。

**引理 18（序锚的共模盲区 = 其鲁棒性的对偶）** 共享读出偏置 b₀（所有接触同加）在序比较中抵消，故 r^ord 对 b₀ 不敏感、rank(J_ord) ≤ d_c − 1，且 b₀ ∈ S_ua^ord。系：序锚必须与静态锚配对，否则公共/绝对方向永远不可辨识。序锚对共模的鲁棒性与对共模的失明是同一枚硬币的两面——这解释了为什么「静态锚 + 事件锚 + 计量基准」缺一不可。

**定理 16（TACIT 慢故障可检测性与零静默吸收）** 在 A92–A96 下：
1. 若故障签名在 S_id 上的分量 ≥ τ_det，则检出概率 ≥ 1 − β，**与 ω_f/ω_cal 无关**；
2. 若签名落入 S_ua，则 `P(被标定静默吸收) = 0`：COF† 冻结 S_ua，系统强制 λ ≥ 0.8 ∧ k 收缩 ∧ 不可观测账本记账；
3. 于是 R68 的「原罪」被一分为二：**可锚方向 → 可检测；不可锚方向 → 不吸收且显式保守**。幽灵保证被消除，或降级为「已披露的不可观测方向」；
4. 端到端风险界继承定理 14，新增 `α_anchor = P(锚伪事件) · P(未被子通道否决)`。

**定理 17（提炼可靠性与反通胀）** 若提炼基 B 覆盖保证并集且幽灵保证集为空，则删去 IP\B 不降低安全保证（至多 ε 松弛）。若幽灵保证非空，则对每个 g 必须显式降级或补充生成器。RDX 单调性：新增未验证 IP 使 RDX 上升，唯一合法下降操作是 DIB 的合并/证伪——**提炼是研究程序自身的负反馈控制器**。

**定理 18（锚失效的单调安全性）** 当 h_A ≤ τ_h 时锚失去收紧权，系统退回 R68 行为且 λ ≥ 0.8；故单纯的锚**退化**只会导致过度保守，不会导致过度放宽。系：唯一危险是「被欺骗且自报高 h_A 的锚」——这把风险从「锚可能坏」精确收窄为「锚健康度可能被伪造」。

## 6. 本轮最大风险

**一句话**：TACIT 把触觉锚抬成「外部裁判」，但**锚本身可能退化或被欺骗，而一个坏锚比没有锚更危险**——因为系统会以「物理上不可辩驳」的最高置信度信任它：伪造的滑移事件会把 COF† 在 S_id 内推向错误标定，使内部残差随之变小，CAC† 的 canary 若不覆盖该接触模式便放行，系统就在「有外部锚、所以更可信」的假象下**更自信地走向错误标定**；定理 18 只能保证「诚实退化的锚 → 保守」，无法保证「被伪造的高健康度锚 → 安全」，这是「谁来锚定锚」这一自指问题的残留。

**次级风险与缓解**：
1. **锚健康度被伪造** → 交叉锚冗余（定义 307）+ 硬件异构 + canary 慢故障注入 + 锚健康度纳入 J_TACIT 版本链；
2. **锚稀疏/冷启动** → S_id 不更新、U 升高、显式保守，绝不无锚更新；
3. **序锚共模盲区** → 必须与静态锚 + 计量基准配对（引理 16、18），盲区写入 CIC 披露；
4. **提炼错误合并** → DIB 只删「主张」不删「证据」，覆盖漏检进 ℰ_distill，RDX 记录债务；
5. **锚检测器自身训练漂移** → 锚检测器也纳入影子流与 CAC† 认证，禁止实时学习。

```python
        'H_trans': N(r_int, 0, R_i) * step(r_A, tau_a),
        'H_slow':  N(r_int, 0, R_slow) * onesided(r_A, cic.S_id),
        'H_world': N(r_int, 0, R_world) * N(r_A, 0, R_a),
    }
    if norm(proj(r_A, cic.S_ua)) > tau_ua:
        post = conservative_branch(post)               # 盲区残差：不判 H_cal
    return normalize(post)

# IP-259 DIB
def distill(ledger):
    order = topological_by_guarantee(ledger)
    B = greedy_mdl_cover(order)
    phantom = [g for g in goals(ledger) if not generated_by(B, g)]
    return Basis(B, phantom, rdx(ledger, B))

# IP-262 TACIT round
def TACIT_round(M, obs):
    V, T, P, L, tac, img, cur, flow = obs
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))
    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)
    ev = M.tac.detect(tac, img, cur)                   # 1) 异步锚事件
    r_A = M.tac.residuals(ev, M.cof.c)                 # 2) 外部锚残差
    r = residuals(x_prime, o, M.wm_residual_cache)
    c, U = M.cof.step(r_A, r, sigma_stat(M))           # 3) COF† 锚投影
    cic = M.cic.build(M.static_anchor, ev, c)          # 4) 可辨识性证书
    joint = M.cfa(r, r_A, c, U, cic)                   # 5) 锚条件归因
    lam = max(M.efs.risk_scale(joint),
              0.8 if (U > TAU_CAL or cic.has_blind or M.tac.h_A < TAU_H) else 0.6)
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, joint, min(M.vista.m, M.m_emo),
                                    M.alpha_chunk, M.wm_preds)
    if M.tac.h_A < TAU_H or cic.has_blind:             # 6) 盲区/锚弱 → 收缩
        k = min(k, k_anchor_shrink(A, cic))
    M.vqa_c.submit_async(M.wm_preds, {'anchor': r_A, 'cic': cic, 'joint': joint})
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit)  # 7) CAC† 六关
    return k, lam, joint, cic
```

## 5. 推导

**引理 16（仿射标定的锚可辨识三元组）** 静态零锚定偏移 b；滑移/碰撞事件定尺度比值；已知质量静载定绝对尺度。三者齐备 ⇒ 每通道 (s,b) 可辨识；缺绝对尺度 ⇒ 公共尺度方向不可辨识（S_ua ≥ 1 维），即比例型慢故障（增益老化）的盲区。

**引理 17（结构防线与时间防线正交）** R68 速率限制管 ω_f ≥ 3ω_cal（残余 ≥ 2/3，时间域）；TACIT 锚投影管签名落在 S_id 的**任意带宽**故障（结构矛盾，与 ω_f 无关）。两防线覆盖 `S_id ∪ {ω_f ≥ 3ω_cal}`；唯一盲区 `S_ua ∩ {ω_f < 3ω_cal}` 的维数由 ρ_A 显式给出。

**引理 18（序锚共模盲区 = 鲁棒性对偶）** 共享偏置 b₀ 在序比较中抵消 ⇒ rank(J_ord) ≤ d_c − 1 且 b₀ ∈ S_ua^ord。故序锚必须与静态锚 + 计量基准配对；其共模鲁棒性与共模失明是同一枚硬币两面。

**定理 16（慢故障可检测性与零静默吸收）** A92–A96 下：
1. 签名在 S_id 上的分量 ≥ τ_det ⇒ 检出概率 ≥ 1−β，**与 ω_f/ω_cal 无关**；
2. 签名落入 S_ua ⇒ `P(被静默吸收)=0`（冻结 + λ≥0.8 + k 收缩 + 记账）；
3. R68 原罪一分为二：可锚方向可检测，不可锚方向不吸收且显式保守；幽灵保证被消除或降级披露；
4. 端到端风险界继承定理 14，新增 `α_anchor = P(锚伪事件)·P(未被子通道否决)`。

**定理 17（提炼可靠性 / 反通胀）** 基 B 覆盖保证并集且无幽灵保证 ⇒ 删去 IP\B 不降低安全保证（≤ ε 松弛）；有幽灵保证则必须降级或补生成器。RDX 单调性：未验证新 IP 抬高 RDX，唯一合法下降操作是 DIB 合并/证伪。

**定理 18（锚失效的单调安全性）** h_A ≤ τ_h ⇒ 锚失去收紧权、退回 R68 且 λ≥0.8 ⇒ 诚实退化的锚只导致过度保守，不导致过度放宽。唯一危险是「被欺骗且自报高 h_A 的锚」。

## 8. 本轮最大风险

**一句话**：TACIT 把触觉锚抬成「外部裁判」，但**锚本身可能退化或被欺骗，而一个坏锚比没有锚更危险**——系统会以「物理上不可辩驳」的最高置信度信任它：伪造的滑移事件把 COF† 在 S_id 内推向错误标定，内部残差随之变小，CAC† 的 canary 若不覆盖该接触模式便放行，系统就在「有外部锚、所以更可信」的假象下**更自信地走向错误标定**；定理 18 只能保证「诚实退化的锚 → 保守」，无法保证「被伪造的高健康度锚 → 安全」，这是「谁来锚定锚」自指问题的残留。

**次级风险与缓解**：锚健康度被伪造（交叉锚冗余 + 硬件异构 + canary + J_TACIT 版本链）；锚稀疏冷启动（S_id 不更新、显式保守）；序锚共模盲区（必配静态锚 + 计量基准，盲区写入 CIC 披露）；提炼错误合并（只删主张不删证据，漏检进 ℰ_distill）；锚检测器自身漂移（同样走影子流 + CAC† 认证，禁止实时学习）。
