# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；本轮灵感：「机器人操作系统」×「视觉语言动作模型」）

> R69 让机器人学会「不确定就去问」：把不确定性拆成 aleatoric / epistemic，用流匹配多模态策略显式表示歧义，用注视/探针/问句主动消解。但 R69 与它之前所有轮次共享两个未言明的假设：
> 1. **闭环是一个整体**——一个 trunk、一个策略、一个实时回路、一张证书。真实机器人却是 ROS 式的**节点联邦**：不同厂商、不同时钟、不同 QoS、各自只看见图的一部分；消息会丢、会乱序、会过期，节点会重启、会升级。在联邦里，「我知道」通常只是「我基于一份**可能已经过期**的上游数据，做出了一个局部正确的判断」。
> 2. **语义是给定的**——任务目标、指代、谓词都已被正确接地。但 VLA 把开放词汇指令带进闭环时，**「把杯子放进水槽」这句话本身就可能被接错**：是哪个杯子？水槽还是洗碗机？模型可能幻觉出一个不存在的把手。R69 的 U_epi 只描述「动作有几种模态」，描述不了「目标本身指错了」。
>
> 本轮两个灵感正好补上这两块：
> - **机器人操作系统**给出一个「证书必须可组合、可过期、可追责」的运行时：assume-guarantee 契约、QoS、时钟、生命周期、版本、分布式审计。
> - **视觉语言动作模型**给出语义层的「意义租约（lease on meaning）」：VLA 不直接驱动执行器，而是输出一个**可验证、会过期、可被撤销**的任务契约，其动作头正是 R69 的流匹配策略。
>
> 核心命题：**把 R69 的「单点证书」升级为「分布式、带时限、按风险预算切分的契约组合」；语义层（VLA）与运行时层（ROS）不是两个系统，而是同一套契约代数的两个视图。没有一枚活的组合租约，就不允许任何执行。** 命名 **CONCERT-RAS**（**CON**tract-composed **CERT**ified semantic autonomy）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我凭什么信它、这份信任到什么时候失效、出了事该怪谁**」。

## 0. 直觉与动机

**灵感 1（ROS → 闭环其实是一个「证书联邦」，不是一台机器）**
直觉：R69 的 `J_FLUID` 是一张「我这个节点此刻安全」的证书。但执行器拿到的动作，是感知、VLA、规划、安全认证若干节点串起来的结果。任何上游节点迟到、丢包、用了旧标定、或悄悄升级了版本，下游都可能**对一份陈旧或错配的数据做出局部正确的判断**。ROS 的 assume-guarantee 契约语言正好把这件事说清楚：每个节点只承诺「若我的输入满足 A_v，则我的输出满足 G_v」。整条链的安全不是某一张证书，而是 **G_u ⇒ A_v 沿图逐边传递**的结果。联邦里没有全知节点，因此也**不可能**有「一个节点证明整条链安全」。

**灵感 2（ROS 的 QoS / 时钟 / 生命周期 → 证书必须是一张会过期的租约）**
直觉：R69 的证书没有时间戳，等价于假设世界静止。但机器人以速度 v 运动，任何「我看到了障碍物在 x」的断言，过 Δt 后有效位置已漂移 vΔt。ROS 的消息有 timestamp、deadline、liveliness，节点会 crash/restart。于是本轮最重要的一个「反 R69 事实」：**证书不是事实，是租约（lease）**——只在一个有限时间窗内、对一个特定版本、在时钟偏差可界定时成立。这把 R69 一个隐藏的静态世界假设，变成了显式的安全参数 τ。凡有 L>0 的漂移，R69 的 τ=∞ 证书在有限时间后**必然失效**。

**灵感 3（VLA → 语义是一层「意义租约」，而不是一条指令）**
直觉：端到端 VLA 直接把 (图像, 语言) 映射成动作：快、通用，但慢（5–10 Hz）、不透明、会幻觉，而且**语义错误与动作错误纠缠在一起，无法分别认证**。更好的切法是：VLA 只负责把语言指令编译成一个**可验证的语义契约** `C_sem=(φ, Γ, σ, U_sem, τ_sem)`，绝不直接输出执行器指令；低层动作由 R69 的流匹配策略（可视为 VLA 的动作头）生成，并继续接受 R69 的实时认证。语义层的每次输出都是一个**可撤销的租约**：世界变了、证据过期了、或权威变了，就必须重签。

**灵感 4（风险预算 → 端到端安全不能由单个节点独自证明）**
直觉：正确做法是**切分风险预算**：端到端允许风险 r_max 被分成各节点的 ρ_v，加上共同原因项 ρ_cc 与未建模项 ρ_unmod；每个节点只需、也只能证明自己的 r_v ≤ ρ_v。这把「谁来负责」变成一张账本：**安全是一个预算分配问题，不是一个全局证明问题**。代价是：任何节点的预算超支都必须显式上报并使组合证书失效——否则「每个节点都说自己没问题」恰恰是最危险的状态。

**灵感 5（新攻击面 → 语义注入、契约伪造、重放、共同原因）**
直觉：一旦引入 ROS 与 VLA，攻击面陡增：场景里的一块文字牌可能被 VLA 读成指令（提示注入）；被攻陷的节点可能发布一张「看起来很合理」的假证书；旧证书可能被重放；时钟可能被偏置让过期证据显得新鲜；多个「独立」传感器可能因同一物理原因一起失效。因此本轮必须同时交付：**权威（authority）与来源（provenance）**、**防重放/防伪造的证书账本**、**时钟偏差感知的租约**、**共同原因相关的预算上界**、以及**有序降级而非直接停机**的失效管理。否则 CONCERT 只是给 R69 的证书盖了一个「分布式」的橡皮图章。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（CONCERT-RAS 总览）** CONCERT-RAS = (SCL, SGV, AGN, CGL, LEASE, RBK, CFM, PROV, MTS, SID, RAS-WM‡)。三不变式：
(i) **实时回路零学习写操作**（继承 R69 定义 293-i）；
(ii) **无活租约不执行**：任一执行窗口 [t, t+H] 内，必须存在一个组合有效的租约集合覆盖所有涉及节点；否则只在已认证的降级档位上执行；
(iii) **预算健全**：每个节点实测风险 ≤ 其分配预算 ρ_v，且 r_e2e ≤ Σρ_v + ρ_cc + ρ_unmod；任一节点无法证明即触发组合失效。三者合起来把「安全」从一次性断言变成**持续可维持的运行时状态**。

**定义 311（计算图与节点）** G_t = (V_t, E_t)，节点 v = (π_v, K_v, ρ_v, c_v)，边 (u→v) 表示 u 的输出主题被 v 订阅。图随时间变化（生命周期迁移、重启、热升级）。节点可增删，**但增删本身是图变更事件**，必须走定义 315 的失效传播。

**定义 312（消息与来源）** m = (payload, t_gps, t_mono, qos, prov, h_K, nonce)。prov 为签名来源链，h_K 为发布时所用契约版本哈希，nonce 防重放；接收端对 prov 的每一跳验签，任一跳未认证即拒收。

**定义 313（A/G 契约）** K_v = (A_v, G_v)。A_v 是对输入流性质的谓词（新鲜度 ≤ τ_in、速率、QoS、标定版本、分布偏移界）；G_v 是对输出性质的谓词（误差界、延迟、校准不确定性、覆盖率）。节点「守约」⇔ 运行期间 A_v 恒真且 G_v 恒真。**注意：契约只承诺「条件成立时输出满足性质」，不对 A_v 本身的充分性负责**——这是本轮最大风险的根源（§6）。

**定义 314（组合有效性）** 对 S ⊆ V，`⊨_t ⊗_{v∈S} K_v` ⇔ 对每条边 (u→v)∈S，G_u ⇒ A_v 在当前窗口成立，且所有 c_v 在 t 处 live、版本一致。有效性沿图拓扑归纳判定；组合证书 `c_S` 是这棵证明树的根哈希。

**定义 315（证书图账本 CGL）** 证书以哈希链组织成 DAG；每条边记录 (evidence_hash, version, t_issue, nonce)。任何图变更（节点替换、版本升级、重标定）使所有后代证书**自动失效**（沿反向拓扑传播），必须重签或降级；这是对「静默升级 / 静默漂移」的正式防御。

**定义 316（证据租约 LEASE）** c = (P, h, t0, τ, k, sig)。在 t 处 live ⇔ `t0+δ ≤ t ≤ t0+τ−δ` ∧ `k = 当前版本` ∧ `sig 有效`（δ 为时钟偏差界）。租约声明的有效断言为 `P_t = P ± L_P·(t−t0)`，L_P 为该量的漂移界；要求 `P_t ⊆ 安全集`。**R69 的证书是 τ=∞ 的特例，仅当 L_P=0 时可靠。**

**定义 317（风险预算核 RBK）** 预算分配 ρ = {ρ_v} 满足 `Σρ_v ≤ ρ_total − ρ_cc − ρ_unmod`；节点以置信 1−δ 证明 `r_v ≤ ρ_v`；组合上界 `r_e2e ≤ Σρ_v + ρ_cc + ρ_unmod`。ρ_cc 由共同原因相关结构（credal 集 / copula 上界）给出：`ρ_cc = max_{S⊆V} corr_mass(S)`。预算可**动态回收**：某节点长期远低于预算则其份额可让渡，但回收本身需重签组合证书。

**定义 318（语义契约 SCL）** VLA: (ℓ, o_{t−h:t}) ↦ C_sem = (φ, Γ, σ, U_sem, τ_sem, k)。φ 为可验证时序谓词（STL/LTL 片段）；Γ = {(γ_i, e_i, s_i)} 为接地（符号、证据引用、校准支持度）；σ 为子目标骨架（只含符号子目标，不含执行器指令）；U_sem 为目标假设后验熵；τ_sem 为语义租约。**VLA 的输出不进入执行器，只进入契约层。**

**定义 319（语义不确定性）** `U_sem = U_sem^ref + U_sem^rel + U_sem^scope`：分别指代、谓词/关系、量词/时序辖域的歧义。它是 epistemic 的（可经澄清降低），除非指令本质欠定。U_sem 与 R69 的 U_epi 正交：**U_epi 是「同一目标下动作有几种模态」，U_sem 是「目标究竟是哪一个」**；二者不可加，走不同通道（定义 321 与 R69 定义 307）。

**定义 320（接地验证器 SGV）** 对 φ 中每个 γ：要求 `s_γ ≥ τ_g`（校准支持）且 `a_γ = 1`（物理可供性：可及、可抓、无碰撞路径）。`pass(C_sem) = ∧_γ [s_γ ≥ τ_g ∧ a_γ]`。任一失败 ⇒ U_sem 未消解，不许签语义租约。SGV 是「VLA 幻觉」与「执行器」之间唯一的闸门。

**定义 321（语义交互 SID）** 增广语义信息动作 `g_sem ∈ {ask_referent, ask_predicate, ask_demo, point}`；`VoI_sem(g) = H(G|o) − E[H(G|o,y)]`；选择 `argmax[VoI_sem − c_sem]`，s.t. 人类注意力预算、语义租约剩余时间 ≥ 期望澄清时长、且继承 R69「k 个正交证据一致」纪律。语义交互是慢速、社交成本高的动作，走独立预算与疲劳衰减；它是 R69 低层交互（注视/探针/问句软提示）的**上层版本**。

**定义 322（权威与来源 PROV）** 指令 ℓ 必须由持有 `task:set` 能力令牌的主体签名；场景内嵌文字的能力集为空（**文字是数据，永远不是命令**）；进入降级档位需 `safety:degrade`；改变风险预算需 `safety:budget`。消息来源链 prov 的每一跳都需可验证。权威构成一个格（authority lattice），契约协商只能请求受影响能力的权威。

**定义 323（时钟与时限）** 全局时间由 PTP 提供、偏差界 δ；本地单调计时器；租约在全局时间上按保守 δ 判定。失去同步 ⇒ τ 收缩到本地保守值并置 `degraded_time`；若 τ < τ_min ⇒ 直接进入降级档 R2。**时钟本身就是一条证据通道，也会被攻击。**

**定义 324（多时间尺度执行器 MTS）** 快环 `f_fast ≥ 300 Hz`（执行门 + R69 FLUID）、语义环 `f_sem ≈ 5–10 Hz`（VLA）、契约环 `f_ctr ≈ 1 Hz`（重签/审计）。要求 `τ_sem ≥ (1/f_sem + jitter)·κ`（κ 为安全系数）；快环**不得等待**语义刷新，只持有租约。R69 把三个时间尺度压进一个回路，是本轮要拆掉的最大工程假设。

**定义 325（降级阶梯 CFM）** R0 完整 CONCERT；R1 冻结最近有效语义租约、降速；R2 R69 局部保守（λ_floor、无语义层）；R3 最小风险停靠。定义**安全风险** `r_safe(R0) ≥ r_safe(R1) ≥ r_safe(R2) ≥ r_safe(R3)`（即越往下物理风险越低）与**任务风险** `r_task(R0) ≤ … ≤ r_task(R3)`（越往下越做不成事）；带迟滞 h 的单调转移，恢复需连续 k 个周期组合有效。**fail-operational，而非 fail-stop（除 R3）。**

**定义 326（证书 J_CONCERT 与归责）** `J_CONCERT = (⊕_v J_FLUID_v, h_G, {c_v}, budget_ledger, U_sem, U_time, U_comp, degrade_rung, prov_chain, concert_ver)`。Valid ⇔ 所有租约 live ∧ 组合有效 ∧ 预算健全 ∧ 来源已认证 ∧（U_sem 已消解或有界声明）。**归责集** B = 证据 DAG 中按拓扑顺序最早违反的 A_v 或 G_v 的节点集合（回放账本得到）；审计只回答「谁的假设先破」，不回答「谁的设计错」——后者是 §6 的未解问题。

# IP-264/268/269 快环：执行门 + R69 FLUID（只在出口加"组合租约门"）
def CONCERT_fast_round(M, obs):
    z, o = M.mtm.forward(obs)
    k, lam, mode, U = M.fluid.step(z, o)          # R69 FLUID 一步（含低层交互）
    t = M.clk.now()
    lease = M.cgl.live_composition(t)             # 增量 O(deg)，返回 (valid, blame, h_G)
    if not lease.valid:
        return M.cfm.degrade(lease.blame, t)      # 阶梯降级，绝不放行
    sem = M.scl.held_lease(t)                     # 只读，不阻塞
    if sem is None or sem.expired(t, M.clk.delta):
        return M.cfm.degrade({'sem'}, t)
    if not M.sgv.consistent(mode.a[:k], sem, o):  # 动作必须落在语义可行集内
        return M.cfm.degrade({'sgv'}, t)
    M.rbk.charge(mode, lam, U)                    # 超支即置组合失效
    return M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam

# IP-264/265/318/320 语义环：VLA -> 语义契约租约（低频、异步）
def CONCERT_semantic_round(M, instruction, obs_hist):
    if not M.prov.authorized(instruction, cap='task:set'):
        return None                               # 场景文字 / 未授权主体：直接拒绝
    C = M.vla.compile(instruction, obs_hist)      # -> (phi, Gamma, sigma, U_sem)
    if not M.sgv.pass_(C):                        # 接地 + 可供性验证
        g = M.sid.choose_semantic(C, obs_hist)    # ask_referent / point / demo
        if g is None: return M.cfm.degrade({'sem'}, M.clk.now())
        C = M.sid.update(C, M.sid.execute(g))     # 需 k>=2 正交证据一致
    return M.scl.sign(C, tau=M.mts.tau_sem, version=M.cgl.version)

# IP-267/314/315 契约环：图变更 -> 失效传播 -> 重签/降级
def CONCERT_contract_round(M):
    if M.cgl.changed():
        invalid = M.cgl.invalidate_descendants(M.cgl.diff())
        for v in invalid:
            if not M.agn.recertify(v):
                return M.cfm.degrade({v}, M.clk.now())
        M.cgl.commit(M.agn.compose())             # 重算组合有效性 + 根哈希
    M.auditor_d.async_replay(M.cgl)               # 防重放 / 伪造 / 预算洗白

# IP-270 降级阶梯：单调、带迟滞、fail-operational
def degrade(M, blame, t):
    r = min(M.cfm.rung + 1, 3)
    if not M.cfm.hysteresis_ok(r, t):
        return M.fluid.conservative_step()        # 保持当前档
    M.cfm.set(r, blame)
    if r == 3: return M.cfm.minimal_risk_stop()
    return M.fluid.conservative_step(lam_floor=max(M.lam_floor, 0.8))

# IP-268 租约有效性（时钟偏差感知 + 防重放）
def live(c, t, delta, version, seen):
    return (c.t0 + delta <= t <= c.t0 + c.tau - delta
            and c.k == version and verify_sig(c) and c.nonce not in seen)

## 3. 推导

**引理 19（陈旧性是一等风险）** 设状态满足 A99：`‖ẋ‖ ≤ L`。一条在 t0 处精度为 ε 的断言，在 t 处使用时有效误差 ≤ `ε + L(t−t0)`。故 R69 的 τ=∞ 证书**仅当 L=0 或允许误差无界时可靠**；任何有速度的机器人，其证书在 `τ* = (ε_max−ε)/L` 之后必然失效。系：给定安全阈值 ε_max，租约时域 `τ* = (ε_max-ε)/L` 是在安全约束下最大化可用性的选择——**τ 不是工程参数，而是由运动学决定的安全量**。

**引理 20（预算健全的组合界）** 若每个节点 `r_v ≤ ρ_v`、共同原因质量 `≤ ρ_cc`，则 `r_e2e ≤ Σρ_v + ρ_cc + ρ_unmod`。证明：对「任一节点在其预算内失效」做联合界，A/G 契约保证事件可组合；ρ_cc 吸收相关失效。系：**缩小任一 ρ_v 不会增大上界**，因此安全旋钮是单调的，可用性是它的价格；这就给出了「安全-可用性 Pareto 前沿」的严格坐标。

**引理 21（注入下的接地可靠性）** 若 (a) 支持度已校准（ECE ≤ τ_ece），(b) φ 中每个接地要求 k≥2 个正交证据一致（继承 R69 引理 18），(c) 权威排除场景文字，则「φ 指向不存在/错误指代」或「未授权指令被执行」的概率 ≤ `α = f(校准误差, 证据相关 ρ)`，与 R69 引理 18 同形。系：**语义攻击不引入新数学，它要么退化为接地失败（被 SGV 抓），要么退化为权威失败（被 PROV 拒）**。

**引理 22（阶梯单调性与活性）** 定义动作集 `A(R0) ⊇ A(R1) ⊇ A(R2) ⊇ A(R3)`；安全风险沿阶梯非增、任务风险非减。带迟滞 h 的转移使降级状态不产生极限环；若组合在连续 k 个周期有效，则恢复到上一档。故降级是**单调、可回放、无抖振**的，且每一次转移都是契约状态的确定性函数（审计可重放）。

**定理 18（CONCERT 严格包含 FLUID-RAS）** 在退化极限 `|V|=1、τ=∞（或 L=0）、U_sem=0、图不变` 下，组合恒有效、语义层为恒等，CONCERT 的执行门与策略**逐指令等于** FLUID-RAS。一般情形下：语义租约缺失时，CONCERT 的可执行集 ⊆ FLUID 的可执行集，且其回退档正是 FLUID 本身；语义租约有效且已验证时，CONCERT 可执行 FLUID 无法表示的开放词汇语义动作（得到 semantic resolution bonus）。因此新层在**表达力上严格更强、在认证动作集上保守细化**——安全侧不做任何让步。

**定理 19（联邦的 fail-closed 性）** 在不变式 (ii)(iii) 与已认证来源下，单个节点崩溃/陈旧/伪造/版本错配不能产生未认证执行：伪造证书被签名与哈希链拒绝，陈旧证书被租约拒绝，版本错配被 CGL 传播失效，未授权指令被 PROV 拒绝。残留风险仅来自 **A_v/G_v 本身的充分性**（定义 313 的告诫）。故：**实现级故障被 fail-closed，规范级缺陷不被覆盖**——这正好是 §6 的最大风险。

**定理 20（多时间尺度无抖振）** 若 λ 对租约年龄单调非减、阶梯带迟滞 h，则闭环降级状态无极限环；若 `τ_sem ≥ 1/f_sem + jitter`，语义刷新不会引发虚假降级；否则系统单调降到 R2 并停留至恢复条件，控制信号为有界变差的分段常值——**连续、无突变**（承接 R69 定理 17）。

## 6. 本轮最大风险

**一句话**：CONCERT 能证明的是「整条联邦遵守了它自己写下的契约」，而不是「这些契约足以覆盖真实世界的失效模式」——**一旦某个节点的 A_v/G_v 漏掉了真正的失效模式（尤其是跨节点的共同原因与 VLA 共享的语义盲区），每个节点都会诚实地证明自己达标，组合层再把一个规范错误洗成一张系统级「证书」；形式化认证于是成了「垃圾进、证明出」的放大器**。

**次级风险与缓解**：
1. **共同原因使联合界失效**（多传感器同源失效、多「独立」证据其实相关）→ ρ_cc 的 credal/copula 上界 + E306 对抗性相关注入；
2. **VLA 语义盲区是系统性的**（同一底座模型在所有节点犯同一种接地错误，破坏「正交证据」假设）→ 多模型/多模态接地 + 人类抽检 + E301/E310；
3. **降级阶梯本身不安全**（R2/R3 也是学出来的）→ 每档独立认证，R3 用非学习的最小风险控制器；
4. **时钟与同步是单点**（PTP 被攻陷则所有租约失效）→ 保守 δ + 单调本地计时 + E308；
5. **语义澄清的社交成本与疲劳**（无限问会耗尽人类注意力）→ SID 独立预算 + 疲劳衰减 + E310；
6. **证书账本膨胀**（长时程下 DAG 无界增长）→ 定期压缩/锚定 + 只保留安全相关后代。

def CONCERT_fast_round(M, obs):

def CONCERT_semantic_round(M, instruction, obs_hist):

def CONCERT_contract_round(M):

        for v in M.cgl.invalidate_descendants(M.cgl.diff()):

        M.cgl.commit(M.agn.compose())

def degrade(M, blame, t):

## 4. 推导

**引理 19（陈旧性一等风险）** 若 `‖ẋ‖≤L`，t0 处精度 ε 的断言在 t 处有效误差 ≤ `ε+L(t−t0)`。R69 的 τ=∞ 证书只在 `L=0` 时可靠；有速度系统的必失效时域 `τ*=(ε_max−ε)/L`。**τ 是由运动学决定的安全量，不是工程参数。**

**引理 20（预算健全组合界）** 各节点 `r_v≤ρ_v`、共同原因 `≤ρ_cc` ⇒ `r_e2e≤Σρ_v+ρ_cc+ρ_unmod`（联合界 + A/G 可组合性）。系：缩小任一预算不增大上界 ⇒ 安全旋钮单调，可用性是其价格，给出严格的安全-可用性 Pareto 坐标。

**引理 21（注入下接地可靠性）** 支持度校准（ECE≤τ_ece）+ 每接地 k≥2 正交证据 + 权威排除场景文字 ⇒ 错误指代/越权执行概率 ≤ `α=f(校准误差, ρ)`，与 R69 引理 18 同形。系：语义攻击不引入新数学，只退化为接地失败（SGV 抓）或权威失败（PROV 拒）。

**引理 22（阶梯单调与活性）** `A(R0)⊇A(R1)⊇A(R2)⊇A(R3)`，安全风险非增、任务风险非减；迟滞 h 消除极限环；连续 k 周期有效则恢复。降级单调、可回放、无抖振。

**定理 18（CONCERT 严格包含 FLUID-RAS）** 退化极限 `|V|=1, τ=∞, U_sem=0, 图不变` 下逐指令等于 FLUID-RAS；一般情形语义租约缺失时执行集 ⊆ FLUID 且回退档即 FLUID，租约有效时可执行 FLUID 无法表示的开放词汇动作。**表达力严格更强，认证动作集保守细化。**

**定理 19（联邦 fail-closed）** 不变式 (ii)(iii)+已认证来源下，单节点崩溃/陈旧/伪造/版本错配均不能产生未认证执行；残留风险仅来自 A_v/G_v 的**充分性**。实现级故障 fail-closed，规范级缺陷不被覆盖。

**定理 20（多时间尺度无抖振）** λ 对租约年龄单调非减 + 迟滞 h ⇒ 无极限环；`τ_sem≥1/f_sem+jitter` ⇒ 无虚假降级；否则单调降到 R2 并停留。控制信号为有界变差分段常值，连续无突变（承接 R69 定理 17）。

## 7. 本轮最大风险

**一句话**：CONCERT 能证明的是「整条联邦遵守了它自己写下的契约」，而不是「这些契约足以覆盖真实世界的失效模式」——**一旦某节点的 A_v/G_v 漏掉真正的失效模式（尤其跨节点共同原因与 VLA 共享的语义盲区），每个节点都会诚实地证明自己达标，组合层再把一个规范错误洗成一张系统级「证书」；形式化认证于是成了「垃圾进、证明出」的放大器**。

**次级风险与缓解**：共同原因使联合界失效（credal/copula 上界 + E306 相关注入）；VLA 语义盲区系统性共享（多模型/多模态接地 + 人类抽检 + E301/E310）；降级阶梯本身不安全（每档独立认证，R3 用非学习最小风险控制器）；时钟单点（保守 δ + 单调本地计时 + E308）；语义澄清疲劳（独立预算 + 衰减 + E310）；账本膨胀（定期压缩锚定）。
