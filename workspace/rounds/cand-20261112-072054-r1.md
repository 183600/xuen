# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；灵感循环第 6 轮；本轮灵感：「UniBot」×「数据标注」×「标注接地」）

> 第 59 轮把安全论证一路下沉到电流环、WCET 与阻抗参数，堵住了「执行器不是理想执行器」的抽象泄漏。但整条证据链仍有一个更深的隐含前提没有被审计：**所有证据最终都要落在「标签」上**——什么算「可抓取」、什么算「成功接触」、什么算「同一物体」、什么算「异常」，这些语义并非来自传感器，而来自**标注协议与标注者**。本轮两个灵感精准击中这一点：**UniBot** 代表跨具身通用机器人基础模型，它把同一套标签语义复用到形态、末端执行器、力限幅完全不同的本体上，而**标签语义是具身相对的**；**数据标注**代表标签的生产过程，它携带标注者偏差、协议歧义、主动采样偏差、自动标注幻觉与训练集污染。本轮核心命题：**「把标注从『数据属性』还原为『具身 × 协议 × 标注者的联合测度』；为标签建立可审计的来源链与语义契约，使证据层只在其语义有效域内使用标签」**——即从第 59 轮的**执行接地**推进到**语义接地**。

核心矛盾：
- **H32（标注即真理·标签噪声结构相关）**：第 53–59 轮的所有共形校准、证据门、ECE 界都默认训练/校准标签是「真值 + i.i.d. 噪声」。真实标注是**标注者 × 任务难度 × 协议版本**的结构化混淆：同一个标注者对「边缘可抓取」系统性偏保守，对某类材质系统性高估刚度；主动标注又让被标注样本**非随机**。此时共形校准集的条件覆盖率建立在错误标签上，ECE 的「自洽」只是**对错误标签的过拟合**。
- **H33（跨具身语义漂移·UniBot 标签不可通约）**：UniBot 共享表征让「抓取成功」这个标签从四足/夹爪/灵巧手之间迁移。但同一标签在不同本体上的**可行域不同**：夹爪的「可抓取」在吸盘上可能不成立，大行程机械臂的「可达」在小臂展本体上失效。若证据层直接复用源具身标签，后验会被**语义漂移**系统性带偏，且漂移不体现在任何传感器残差里——它藏在下游失败率里。
- **H34（标注预算与选择偏差·主动标注改变分布）**：标注不是免费的，证据层需要决定「标哪些样本」。按不确定性/信息增益主动选样会**改变标注分布**，使经验风险估计有偏；标注预算 B_ann 与探针/微调/解释/执行预算相互竞争。没有预算与选择机制的显式建模，「多用标签」既可能买来校准，也可能买来**确认偏误**。

## 0. 直觉与动机

**灵感 1（UniBot → 跨具身语义契约 UEC）**
直觉：UniBot 的价值不是「一个模型跑所有机器人」，而是「一份表征契约让标签可迁移」；但契约有**适用边界**。把标签 l 的语义写成**具身条件谓词** φ_l^e：在本体 e 的具身参数（运动学、末端几何、力上限、传感配置）下，存在一个可执行动作 a 使任务成功概率 ≥ 1−δ。「可抓取」不是物体的属性，而是 (物体, 末端, 力限幅, 姿态可达集) 的联合谓词。于是跨具身复用标签前必须先验证 **d_sem(φ_l^{e_src}, φ_l^{e_tgt}) ≤ ε_sem**：在共享特征支撑上两个谓词的**语义分歧**（成功率差的上确界 / 诱导分布 TV）。UEC 输出**可迁移标签集**与**必须重标注/重探针的标签集**；不可迁移时不允许 UniBot 用源标签「脑补」目标本体。

**灵感 2（数据标注 → 标注不确定性量化 LAQ 与主动标注 AAL）**
直觉：标签不是观测值，而是**标注者在其混淆矩阵下的一次含噪采样**。用分层 Dawid–Skene：每个标注者 a 有混淆张量 π_a[c,c']=P(输出 c' | 真类 c)；每个样本有难度先验；EM 同时估计真实标签后验、标注者可靠度与样本难度。把宏 F1 的「标注准确性」换成**逐标签后验 + 可靠性权重**，证据层收到的不是硬标签，而是**带来源的软标签似然**。校准集必须使用**去噪后验**而非原始标签，否则共形覆盖是对噪声的覆盖。主动标注则用 **VOI_ann**：在「信息增益 − λ·标注成本」下选样本，并**强制记录采样倾向 e(x)**，用逆倾向加权（IPS）修正选择偏差，用有效样本量 ESS 判断「这次标注到底买到了多少独立信息」。

**灵感 3（三灵感合流 → 标注接地层 AGL 与三向契约）**
直觉：第 59 轮是「证据层 ↔ 执行层」的双向契约；本轮补上第三条边——**语义层**。三向契约：**语义层**（标注协议/具身谓词）向证据层承诺「标签在何处有效」，证据层向执行层承诺「带证书的参数」，执行层把「真实成功/失败」回传为**再标注信号**。关键立场：**标注是元模态（meta-modality），不是第 6 个独立物理模态**。它不能像视觉/触觉那样为「同一事实」提供独立佐证，只能（i）修正先验与似然、（ii）加宽校准不确定性、（iii）触发重标注/重探针。否则「标注者同意标注者」会构成伪独立证据，重蹈第 59 轮明确禁止的 EV-exec 自证覆辙。

**灵感 4（PCE++++ → 五预算耦合）**
直觉：第 59 轮已有 B_probe/B_ft/B_ux/B_exec；本轮新增 **B_ann（标注预算：标注配额、标注者工时、一致性余量、污染扫描余量）**。VOI 计算里标注收益是「降低决策风险」，成本是「标注工时 + 一致性审计 + 潜在污染」。当 B_ann 耗尽，系统只能退向**自监督/自动标注 + 更宽共形带**，而不是假装标签变干净了。五预算严格隔离、单调消耗、互不挪用。

**灵感 5（XMC++ → 标注作为「元模态」的对账）**
直觉：跨模态对账现在要对账「标签语义」。定义**标注分歧** D_ann = 标注后验与融合后验的 TV + 标注者间不一致 κ 的补 + 语义漂移 d_sem。规则与 EV-exec 同构：**EV-ann 只能加宽后验、触发降级/重标注，绝不能减少探针或替代 EV-xmodal/EV-human 佐证**。

## 1. 形式化定义（增量：定义 153–160）

**定义 153（标注来源状态与结构化标签似然 LAQ）** 标注来源状态 λ_ann=(a, p, e, t, l, c, A)，其中 a=标注者 ID（人或模型）、p=协议版本、e=具身 ID、t=时戳、l=标签名、c=自报置信、A=歧义集合（允许的多个标签）。标注者混淆张量 π_a[c,c']=P(Y^a=c' | Y=c, e, p)，服从 Dirichlet 先验。结构化标签似然：
```
L_ann(y | θ, λ_ann) = π_a[θ, y] · 1[y ∈ A] / Z(A, θ)
```
其中 Z 为歧义集归一化。真实标签后验 q_i(c) ∝ P_prior(c) · Π_{a∈A_i} π_a[c, y_i^a]。去噪后的校准集为 {(x_i, q_i)}，共形分数按 q_i 加权。标注者可靠度 ρ_a = 1 − E_{c~q}[1 − π_a[c, argmax_{c'} π_a[c,c']]] 参与融合权重，但**不进入独立性声明**。

**定义 154（跨具身语义契约 UEC）** 对标签 l 与本体 e，定义语义谓词：
```
φ_l^e(o) = 1[ ∃ a ∈ A_e(o) : P(success(a,o,e) | ξ_exec) ≥ 1 − δ_sem ]
```
A_e(o) 为执行器 e 在物体 o 上的可达动作集（依赖运动学、末端几何、力上限）。跨具身语义漂移：
```
d_sem(φ_l^{e_s}, φ_l^{e_t}) = sup_{o∈Supp_shared} |φ_l^{e_s}(o) − φ_l^{e_t}(o)|
                             = sup_o |P(success|o,e_s) − P(success|o,e_t)|
```
（连续版本用诱导成功率分布的 TV；有限样本用 DKW 上界 + 共形校准给出 1−δ 置信上界。）迁移契约：
```
C_ue = (e_s, e_t, l, ε_sem, N_val, d̂_sem, δ, admissible)
admissible ⇔ d̂_sem + DKW(N_val, δ) ≤ ε_sem
```
仅 admissible 的 (l, e_s→e_t) 允许复用源标签；否则标签必须重标注或对目标具身重探针。契约随固件/末端/力限幅版本化，任一变化即失效。

**定义 155（主动标注与选择偏差 AAL）** 标注采样策略 π_ann(x) 给出倾向 e(x)=P(x 被选入标注集 | 历史)，**必须在选样时记录**。逆倾向风险估计：
```
R̂_IPS(θ) = (1/n) Σ_i 1[e(x_i)>0] / e(x_i) · ℓ(θ; x_i, q_i)
ESS = (Σ_i w_i)² / Σ_i w_i²,  w_i = 1/e(x_i)
```
主动标注选择：
```
voi_ann(x) = H(θ | D) − E_{y~L_ann(·|x)}[ H(θ | D ∪ {(x,y)}) ] − λ_ann · c_ann(x)
```
其中 c_ann 含标注者工时、审计与污染扫描成本。当 ESS < ESS_min 或 max_i w_i > w_max（倾向过小）时，估计不可信，必须回退到「随机抽样重标注」子集或加宽共形带。

**定义 156（标注证据 EV-ann 与元模态对账 XMC++）** 
```
EV-ann = (provenance_ok, κ_iaa, e_min, w_max, d_sem, contamination_rate,
          label_noise_est, ess, budget_age, degraded_flag)
```
κ_iaa = Fleiss κ（多名标注者）或与专家锚点的一致率。标注模态**不加入**物理模态集，而作为**元模态**：
```
ℳ^ann = ℳ⁺ ∪ {ann},  但 ann ∉ 佐证集
D_ann(r) = TV(q_ann(r), fused(r)) + (1−κ_iaa) + w_sem·d_sem(r)
```
规则：(R1++) D_ann>θ_D ⇒ 后验加宽并触发重标注/重探针；(R2++) EV-ann **不得**替代 EV-probe*/EV-xmodal/EV-human；(R3++) provenance_ok=false 或 contamination>θ_c ⇒ 该标签来源整体降权 ρ_ann→ρ_min 并回溯标记历史；(R4++) 主动标注倾向缺失 ⇒ 视同 provenance_ok=false。

**定义 157（标注预算 B_ann 与 PCE++++）**

```
B_ann = (label_quota, annotator_time_slack, iaa_slack, contamination_slack)
```

**定义 158（标注证书 J_ann 与 JCPS+++）**

### IP-152 LAQ（分层 Dawid–Skene 标注不确定性量化）

```python
class LabelAnnotationQuantifier:
    def __init__(self, n_classes, n_annotators, n_items, prior_strength=1.0):
        self.K = n_classes
        self.pi = np.full((n_annotators, n_classes, n_classes),
                          prior_strength / n_classes)   # 混淆张量
        self.difficulty = np.zeros(n_items)              # 样本难度
        self.q = np.full((n_items, n_classes), 1.0 / n_classes)

    def em_fit(self, annotations, max_iter=100, tol=1e-5):
        # annotations: list[(item, annotator, label)]
        for _ in range(max_iter):
            q_old = self.q.copy()
            self._e_step(annotations)
            self._m_step(annotations)
            if np.max(np.abs(self.q - q_old)) < tol:
                break
        return self.q

    def _e_step(self, ann):
        for i in range(len(self.q)):
            logp = np.log(self.prior + 1e-12) + self.difficulty[i]
            for (item, a, y) in ann:
                if item == i:
                    logp += np.log(self.pi[a][:, y] + 1e-12)
            self.q[i] = softmax(logp)

    def _m_step(self, ann):
        for (item, a, y) in ann:
            self.pi[a][:, y] += self.q[item]
        self.pi = self.pi / self.pi.sum(axis=2, keepdims=True)

    def structured_label_likelihood(self, item, y, a, ambiguity_set=None):
        if ambiguity_set and y not in ambiguity_set:
            return 0.0
        lik = self.pi[a][:, y].copy()
        if ambiguity_set:
            lik[[c for c in range(self.K) if c not in ambiguity_set]] = 0
            lik = lik / (lik.sum() + 1e-12)
        return lik   # 逐类别似然向量，供证据层替换硬标签

    def annotator_reliability(self, a):
        pred = self.pi[a].argmax(axis=1)
        return float(np.mean(self.pi[a][np.arange(self.K), pred]))

    def detect_contamination(self, y_obs, y_pred, z_embedding, alpha=0.01):
        # 用嵌入空间局部一致性 + 标签翻转率检测训练集污染
        local_flip = local_label_flip_rate(z_embedding, y_obs, y_pred)
        return local_flip > np.quantile(local_flip, 1 - alpha)
```

### IP-153 UEC（跨具身语义契约）

```python
class EmbodimentSemanticContract:
    def __init__(self, eps_sem, delta=0.01):
        self.eps_sem = eps_sem
        self.delta = delta
        self.contracts = {}

    def check(self, label, e_src, e_tgt, shared_support_eval):
        # shared_support_eval: [(object, success_src, success_tgt, n_trials)]
        diffs, ns = [], []
        for (o, p_s, p_t, n) in shared_support_eval:
            diffs.append(abs(p_s - p_t)); ns.append(n)
        d_hat = max(diffs) if diffs else 0.0
        # DKW 单侧上界（取各点最大样本量下的保守界）
        n_eff = max(1, min(ns)) if ns else 1
        dkw = np.sqrt(np.log(2.0 / self.delta) / (2.0 * n_eff))
        d_upper = min(1.0, d_hat + dkw)
        admissible = d_upper <= self.eps_sem
        C_ue = SemanticContract(
            label=label, e_src=e_src, e_tgt=e_tgt,
            eps_sem=self.eps_sem, N_val=len(shared_support_eval),
            d_sem_hat=d_hat, d_sem_upper=d_upper,
            delta=self.delta, admissible=admissible
        )
        self.contracts[(label, e_src, e_tgt)] = C_ue
        return C_ue

    def filter_labels(self, labels, e_target):
        ok, redo = [], []
        for l in labels:
            cs = [c for (ll, es, et), c in self.contracts.items()
                  if ll == l and et == e_target]
            (ok if cs and all(c.admissible for c in cs) else redo).append(l)
        return ok, redo   # 仅 ok 进入证据集；redo 入重标注/重探针队列
```

### IP-154 AAL（主动标注与选择偏差校正）

```python
class ActiveAnnotationLoop:
    def __init__(self, laq, budget_ann, ess_min=100, w_max=20.0):
        self.laq = laq
        self.B = budget_ann
        self.ess_min, self.w_max = ess_min, w_max
        self.propensity_log = []

    def select(self, candidates, model_entropy_fn, cost_fn):
        best, best_voi = None, -np.inf
        for x in candidates:
            h = model_entropy_fn(x)
            exp_h = expected_posterior_entropy(self.laq, x)   # E_y[H(θ|D∪{(x,y)})]
            voi = h - exp_h - LAMBDA_ANN * cost_fn(x)
            if voi > best_voi:
                best, best_voi = x, voi
        return best, best_voi

    def annotate(self, x, policy_prob, a, y):
        self.propensity_log.append((x, policy_prob, a, y))
        self.B.spend_one_label(cost_fn(x))
        return self.laq.structured_label_likelihood(x, y, a)

    def ips_risk(self, losses, propensities):
        w = np.array([1.0 / max(e, 1e-6) for e in propensities])
        ess = (w.sum() ** 2) / (w ** 2).sum()
        if ess < self.ess_min or w.max() > self.w_max:
            return None, ess, "selection_bias_unreliable"
        return float(np.mean(w * np.array(losses))), ess, "ok"

    def audit(self, losses, propensities):
        r, ess, status = self.ips_risk(losses, propensities)
        return AnnotationAudit(risk_ips=r, ess=ess, max_weight=max(propensities) and 1/min(propensities),
                               reliable=(status == "ok"))
```

### IP-155 XMC++（标注元模态对账）

```python
def reconcile_with_annotation(M, region, q_label, ev_ann, fused):
    # 标注只作为「先验/似然修正 + 加宽」，不进入独立佐证
    if not ev_ann.provenance_ok:
        fused = widen_posterior(fused, factor=GAMMA_WIDEN)
        return fused, float('inf')
    D_ann = tv_distance(q_label, fused.label_dist) \
            + (1.0 - ev_ann.kappa_iaa) \
            + W_SEM * ev_ann.d_sem
    if D_ann > THETA_D_ANN or ev_ann.contamination_rate > THETA_CONTAM:
        fused = widen_posterior(fused, factor=1.0 + D_ann)
        M.ood_reg.flag_semantic(region)
        M.reannotation_queue.push(region)
    # 注意：即使 D_ann 很小，也不减少探针/佐证需求（单向性）
    return fused, D_ann
```

假设 A22–A55（第 53–59 轮）成立；**(A56)** LAQ：标注者混淆张量可辨识（每类≥3 名冗余标注者或存在专家锚点）；EM 收敛到局部极大且真实标签在歧义集约束内；结构化似然诚实包含真实标签分布。**(A57)** UEC：共享特征支撑上的语义漂移估计 d̂_sem 是真实的 1−δ 上界（DKW + 共形）；契约仅在其版本内有效，固件/末端/力限幅变更即失效。**(A58)** AAL：每次选样都记录非零倾向 e(x)≥e_min 且 w_max 有界；IPS 估计无偏、ESS≥ESS_min 时方差可控；倾向缺失视同来源无效。**(A59)** XMC++：标注作为元模态，只允许加宽后验或触发重标注/降级，绝不减少探针/佐证需求。**(A60)** PCE++++：五预算单调消耗、互不挪用；B_ann 耗尽 ⇒ 保守降级而非伪造标签。则：

2. **去噪校准健全性**：使用 LAQ 软标签似然的校准集，其条件覆盖误差 ≤ 原始 ECE + δ_label(λ_ann)，其中 δ_label = O(标注噪声率 × 混淆矩阵条件数)；执行 OOD 与标注 OOD 分别触发共形保底带。

### IP-152 LAQ（分层 Dawid–Skene 标注不确定性量化）

```python
import numpy as np
from dataclasses import dataclass, field

@dataclass
class AnnotationAudit:
    risk_ips: float
    ess: float
    max_weight: float
    reliable: bool
    reasons: list = field(default_factory=list)

class LabelAnnotationQuantifier:
    def __init__(self, K, n_annotators, n_items, prior_strength=1.0):
        self.K = K
        self.prior = np.full(K, 1.0 / K)
        self.pi = np.full((n_annotators, K, K), prior_strength / K)
        self.difficulty = np.zeros(n_items)
        self.q = np.full((n_items, K), 1.0 / K)
        self.n_items = n_items

    def em_fit(self, annotations, max_iter=100, tol=1e-5):
        # annotations: [(item_id, annotator_id, label_id)]
        for it in range(max_iter):
            q_old = self.q.copy()
            self._e_step(annotations)
            self._m_step(annotations, n_annotators=self.pi.shape[0])
            if np.max(np.abs(self.q - q_old)) < tol:
                return {"q": self.q, "iters": it + 1, "converged": True}
        return {"q": self.q, "iters": max_iter, "converged": False}

    def _e_step(self, annotations):
        logp = np.tile(np.log(self.prior + 1e-12), (self.n_items, 1))
        logp += self.difficulty[:, None]
        for (i, a, y) in annotations:
            logp[i] += np.log(self.pi[a][:, y] + 1e-12)
        logp -= logp.max(axis=1, keepdims=True)
        self.q = np.exp(logp)
        self.q /= self.q.sum(axis=1, keepdims=True)

    def _m_step(self, annotations, n_annotators):
        counts = np.zeros_like(self.pi)
        for (i, a, y) in annotations:
            counts[a][:, y] += self.q[i]
        # Dirichlet 平滑，避免零概率与不可辨识
        self.pi = (counts + 1e-2) / (counts.sum(axis=2, keepdims=True) + 1e-2 * self.K)

    def structured_label_likelihood(self, item_id, y, annotator_id, ambiguity_set=None):
        lik = self.pi[annotator_id][:, y].copy()
        if ambiguity_set is not None:
            mask = np.zeros(self.K, dtype=bool)
            mask[list(ambiguity_set)] = True
            lik[~mask] = 0.0
            lik = lik / (lik.sum() + 1e-12)
        return lik   # 逐类别似然向量，供证据层替换硬标签

    def annotator_reliability(self, a):
        pred = self.pi[a].argmax(axis=1)
        return float(np.mean(self.pi[a][np.arange(self.K), pred]))

    def detect_contamination(self, y_obs, y_pred, z_embedding, alpha=0.01):
        # 嵌入空间近邻的标签翻转率：局部一致性越低越可能被污染
        flip = []
        for i in range(len(z_embedding)):
            nn = nearest_neighbors(z_embedding, i, k=10)
            flip.append(np.mean(y_obs[nn] != y_obs[i]))
        flip = np.asarray(flip)
        thr = np.quantile(flip, 1 - alpha)
        return {"rate": float(np.mean(flip > thr)), "threshold": float(thr), "flags": flip > thr}

    def denoised_calibration_set(self, items):
        # 校准集用软标签（q）与可靠性权重，而非硬标签
        return [(x, self.q[i], self.annotator_reliability(a))
                for (x, i, a) in items]
```

```python
@dataclass
class SemanticContract:
    label: str
    e_src: str
    e_tgt: str
    eps_sem: float
    N_val: int
    d_sem_hat: float
    d_sem_upper: float
    delta: float
    admissible: bool
    embodied_params_hash: int

class EmbodimentSemanticContract:
    def __init__(self, eps_sem, delta=0.01):
        self.eps_sem = eps_sem
        self.delta = delta
        self.contracts = {}

    def check(self, label, e_src, e_tgt, shared_support_eval):
        # shared_support_eval: [(object, p_success_src, p_success_tgt, n_trials)]
        diffs = [abs(ps - pt) for (_, ps, pt, _) in shared_support_eval]
        ns = [n for (_, _, _, n) in shared_support_eval]
        d_hat = max(diffs) if diffs else 0.0
        n_eff = max(1, min(ns)) if ns else 1
        dkw = np.sqrt(np.log(2.0 / self.delta) / (2.0 * n_eff))
        d_upper = min(1.0, d_hat + dkw)
        C = SemanticContract(
            label=label, e_src=e_src, e_tgt=e_tgt,
            eps_sem=self.eps_sem, N_val=len(shared_support_eval),
            d_sem_hat=d_hat, d_sem_upper=d_upper, delta=self.delta,
            admissible=(d_upper <= self.eps_sem),
            embodied_params_hash=hash((e_src, e_tgt, self.eps_sem))
        )
        self.contracts[(label, e_src, e_tgt)] = C
        return C

    def filter_labels(self, labels, e_target, embodied_params):
        ok, redo = [], []
        for l in labels:
            cs = [c for (ll, _, et), c in self.contracts.items()
                  if ll == l and et == e_target]
            valid = bool(cs) and all(
                c.admissible and c.embodied_params_hash == hash((c.e_src, c.e_tgt, c.eps_sem))
                for c in cs)
            (ok if valid else redo).append(l)
        return ok, redo   # redo 入重标注/重探针队列，绝不进入证据集

    def invalidate_on_change(self, e, changed_keys):
        # 末端/力限幅/运动学变更 ⇒ 相关契约立即失效
        for key in list(self.contracts):
            if e in key[1:] and changed_keys:
                self.contracts[key].admissible = False
```

```python
class ActiveAnnotationLoop:
    def __init__(self, laq, budget_ann, ess_min=100, w_max=20.0):
        self.laq = laq
        self.B = budget_ann
        self.ess_min, self.w_max = ess_min, w_max
        self.propensity_log = []

    def select(self, candidates, model_entropy_fn, expected_posterior_entropy_fn, cost_fn):
        best, best_voi = None, -np.inf
        for x in candidates:
            voi = (model_entropy_fn(x)
                   - expected_posterior_entropy_fn(x)
                   - LAMBDA_ANN * cost_fn(x))
            if voi > best_voi:
                best, best_voi = x, voi
        return best, best_voi

    def annotate(self, x, policy_prob, annotator_id, y, cost):
        if policy_prob <= 0:
            raise ValueError("missing_propensity_forbidden")
        self.propensity_log.append({
            "x": x, "e_x": policy_prob, "annotator": annotator_id, "y": y
        })
        self.B.spend_label(cost)
        return self.laq.structured_label_likelihood(x, y, annotator_id)

    def ips_risk(self, losses, propensities):
        w = np.array([1.0 / max(e, 1e-6) for e in propensities])
        ess = float((w.sum() ** 2) / max((w ** 2).sum(), 1e-12))
        if ess < self.ess_min:
            return None, ess, ["ess_below_min"]
        if w.max() > self.w_max:
            return None, ess, ["max_weight_exceeded"]
        return float(np.mean(w * np.asarray(losses))), ess, []

    def fallback_random_reannotation(self, pool, k):
        # 倾向过小/缺失时的唯一合法回退：随机抽样重标注，重算 e(x)
        return random.sample(pool, min(k, len(pool)))
```

**正确性定理（Annotation-Grounded Evidence Soundness, AGES）**
假设 A22–A55（第 53–59 轮）成立；**(A56)** LAQ：标注者混淆张量可辨识（每类≥3 名冗余标注者或存在专家锚点），EM 收敛且真实标签在歧义集约束内，结构化似然诚实包含真实标签分布。**(A57)** UEC：共享特征支撑上的语义漂移估计 d̂_sem 是真实漂移的 1−δ 上界（DKW+共形）；契约仅在其版本内有效，末端/力限幅/运动学变更即失效。**(A58)** AAL：每次选样记录非零倾向 e(x)≥e_min 且 w_max 有界；IPS 估计无偏、ESS≥ESS_min 时方差可控；倾向缺失视同来源无效。**(A59)** XMC++：标注作为元模态只允许加宽后验或触发重标注/降级，绝不减少探针/佐证需求。**(A60)** PCE++++：五预算单调消耗、互不挪用；B_ann 耗尽 ⇒ 保守降级而非伪造标签。则：

1. **语义有效性**：任一进入证据集的标签 l 必满足 d_sem(φ_l^{e_src}, φ_l^{e_tgt}) ≤ ε_sem（1−δ 置信）；否则只能作探索性先验，不得进入校准与证据门。
2. **去噪校准健全性**：使用 LAQ 软标签似然的校准集，其条件覆盖误差 ≤ 原始 ECE + δ_label(λ_ann)，δ_label = O(噪声率 × 混淆矩阵条件数)；标注 OOD 与执行 OOD 分别触发共形保底带，二者不互相掩盖。
3. **选择偏差可控**：ESS≥ESS_min 且 w_max≤W_max 时，IPS 风险估计无偏且置信区间有效；否则系统必须随机重标注或加宽共形带，不得用有偏估计下结论。
4. **跨具身迁移安全**：可迁移标签上的目标具身失败率 ≤ 源具身失败率 + ε_sem + DKW(N_val, δ)；不可迁移标签绝不进入证据集。
5. **标注单向性**：EV-ann 只能加宽后验/触发保守，不能替代任何物理模态佐证，也不能减少探针数；增加标注预算不改变该单向性。
6. **终止性**：AGCL 在 k_probes+k_cons+k_ft+k_ux+k_exec+k_ann 内终止于 {承诺(带 Cert_eeis+J_ann), 绕行, 降档, L2 协商, 安全停, 执行降级停, 语义降级停}。
7. **部署界**（检查点联合界，在 EGES 基础上追加标注四项）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                   + δ_ft·1[回滚窗口] + δ_kg·1[检索失败] + δ_ux·1[μ_mis>θ_mis]
                   + δ_exec·1[ξ_exec漂移] + δ_ξ_ood·1[执行OOD]
                   + δ_ertc·1[契约违例] + δ_eeis·1[μ分析漏报]
                   + δ_label·1[标注噪声] + ε_sem·1[跨具身迁移]
                   + δ_sel·1[ESS<ESS_min] + δ_contam·1[污染未检出])
         − P(𝒢 结构性错误未检出) − P(护盾回退失败) − P(τ_int 超时 ∧ 安全停失效) − P(固件回滚失败)
```

关键：**LAQ 把标签从真值降格为带混淆矩阵的似然**；**UEC 把 UniBot 的可迁移性变成可验证的语义契约**；**AAL 把标注预算变成带倾向日志的主动采样**；**XMC++ 把标注钉死为元模态**——只加宽、不作证；**PCE++++ 五预算耦合**让标注枯竭时系统变保守而非变自信；**J_ann/CEB+++++ 让每个标签可追溯到「谁、按什么协议、在哪个具身上、以多大置信、经什么选择机制产生」**。三条安全单向通道继续成立：**信念更准（去噪似然）、不确定性更大（语义漂移/选择偏差）、动作更保守（语义降级停）**。

## 6. 本轮最大风险

**一句话**：标注接地本身不可完全形式化——混淆张量可辨识性、共享特征支撑的选取、ε_sem 的设定、倾向模型的正确定性，任一项被违反都会把系统性语义偏差洗成「高置信去噪标签」，让系统**在语义上自信地错**；必须坚持「UEC 未过即出证据集、倾向缺失即来源无效、EV-ann 绝不佐证、预算耗尽即保守、隔离区留出具身切片」五重护栏，宁可把标签当噪声，不可把噪声当标签。
