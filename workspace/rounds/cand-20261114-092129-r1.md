# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS 具身计量审计」IP-287~294；灵感循环第 1 轮；本轮灵感：「人机交互」×「共享控制」）

> R72 把 GAUGE 从「认知层算法」下沉为「具身实时系统」：REG 把「计量不阻塞控制」变成调度级定理；IRL 把意图 z 引入联合后验 b_t(s,z)；DMEM 把灵巧手触觉升级为接触模式条件证据；EREFLEX/ERVOI/E-RISK 把情感、意图、接触三层反作用合算；S2R-UQ 把 sim2real 残差传播到 WCET 与 λ_floor。R72 的姿态是：**「在实时调度下，面对意图模糊的人、用灵巧手触摸世界，我的测量链仍能逐指令兑现风险界。」**
> 但 R72 仍然是一个**机器人主权（robot-sovereign）**系统：
> - **共享控制视角**：R72 的全部交互动作只有「调整 λ / 软化自己 / 提问」。但共享控制的真正动作空间是 **{保持权限、让渡权限、混合权限、协商权限、安全停}**。「软化」不等于「让渡」：当人比机器人更胜任时，正确的动作是把控制权交出去，而不是把机器人变得更慢；当机器人更胜任时，正确的动作是**接管并让人保持在环**，而不是继续问问题直到人烦。**λ 是风险增益，不是权限变量。**
> - **人机交互视角**：R72 的 ψ 只建模「你的话可不可信」，z 只建模「你想要什么」；它没有建模**「你信不信我（trust）、你还跟不跟得上（workload/SA）、你以为现在是谁在控制（mental model of authority）」**。而这三者恰恰是 HRI 的核心状态：过度信任 → 人停止监控 → 机器人的「自信地错」无人兜底；信任不足 → 人频繁接管 → 共享控制退化为手动，且接管本身引入人为错误；情境意识丢失 → 接管来不及。**人是会建模你的主体，不是被动证据源。**
> - **隐藏权限视角**：R72 的 λ_floor 安全滤波器会在人「控制」时静默改写人的指令。这在功能上正确，在**权限语义上危险**：人以为自己握着权限，实际执行的是滤波器裁剪后的动作 → **申报权限 ≠ 有效权限**。共享控制最经典的失败不是某一步算错，而是**「谁在开车」的共识在慢漂移中破裂**（mode confusion / silent autonomy / authority creep）。
>
> 本轮两个灵感正好补三块：
> - **共享控制**：把 λ 单方缩放升级为**权限仲裁 AAM + 联合权限模型 JAM**：α_t ∈ Δ 是显式的、按子任务分配的、带速率限制与接管截止时间的权限状态；权限分配受**非补偿性能力否决**与**接管可行性硬约束**。
> - **人机交互**：把「人」升级为**被计量的状态 h_t =（信任 τ、负荷 w、情境意识 SA、注意 attn、心理模型 m̂_h）**，建立**人因计量 HSM**、**共享情境意识 SCC**、**信任校准层 TCL**、**权限-责任账本 LEDGER**；信任不是越大越好，**校准（τ ≈ 机器人真实可靠度 R_r）才是目标**。
> - **联合审计**：R72 的单方证书 J_EMB 升级为**联合证书 J_SHARE**：机器人测量链有效 ∧ 人因状态可测 ∧ 权限分配可行 ∧ 共享情境一致 ∧ 透明诚实 ∧ 接管可行 ∧ 账本完整。任一失效即权限分配无效（非补偿性合取）。
>
> 核心命题：**不再只问「我的测量链可信吗」，也不再只问「我该多保守」，而问「在谁该握权限、人是否还跟得上、我们是否对『谁在控制』有同一个信念的前提下，这个团队还能逐指令兑现安全界吗？」** 把 R72 的「具身计量审计」推进为 **SHARED-GAUGE-RAS**（Shared-authority, Human-state-metrology, Arbitrated, Responsibility-explicit, Explainable, Deference-aware GAUGE for RAS）——**共权计量审计闭环**。

## 0. 直觉与动机

**灵感 1（共享控制 → 权限是所有权，不是增益）**
直觉：在共享控制里，λ 只在问「我该多小心」；α 在问「**谁的手在方向盘上**」。这两件事必须分开。机器人可以「很小心地全权控制」，也可以「很激进地把控制让给人」，还可以「两人按 0.6/0.4 混合」。R72 把所有情形压成一个 λ，等于假设「权限永远在机器人，人只是输入噪声」。这在人比机器人更懂当前情境时会直接错：老人想自己慢慢端杯子，机器人却因为测到意图模糊而把杯子抓得更紧、动作更慢——**正确的共享控制是松手让渡，而不是更保守地握着**。所以必须定义**权限状态 α_t、权限动作、权限转移语义、接管延迟、权限抖动约束**。

**灵感 2（人机交互 → 人也在估计你，信任/负荷/情境意识是状态变量）**
直觉：HRI 里最危险的不是机器人不知道世界，而是**人不知道机器人知道什么**。R72 的证书再完备，如果人过度信任它，人就会去刷手机；机器人一旦在 OOD 上「自信地错」，没有人会按急停。反过来，如果人完全不信任，机器人每次动作都被接管，共享控制退化成「昂贵的摇杆」。因此人因状态 must be metered：**信任 τ 是隐变量，不是自报数字**；**负荷 w 会被人机界面本身抬高**；**情境意识 SA 会因权限切换太快而丢失**。而且人因计量是**反身测量**：你显示什么，就会改变你测的那个状态（显示不确定性 → 改变信任 → 改变接管行为）。这是比 R72 的 ψ 更深的一层：ψ 是「人说的话可不可信」，h 是「人本身还是不是合格的共同控制者」。

**灵感 3（共享控制的隐藏权限 → 安全滤波器是未申报的驾驶员）**
直觉：假设人握着摇杆（α=0），机器人只做安全滤波。滤波器的输出 u = clip(u_h) 与人想要的 u_h 不同，但界面仍显示「人在控制」。此时**有效权限 α^eff > 0**，而**申报权限 α^decl = 0**。一次两次没关系，长期看这是**静默自治（silent autonomy）**：机器人实际上在开，人以为自己在开。等到需要人接管时，人的情境意识已经被剥夺。**因此：每一次滤波干预都必须被归因、记账、并在超阈时升级为显式协商；有效权限必须等于申报权限，否则 SCC 失效。** 这条不变式比「滤波器安全」更根本——**安全滤波器可以是安全的，同时是欺骗性的**。

**灵感 4（信任非单调 → 目标不是最大化信任，而是校准信任）**
直觉：HRI 论文常把「提升信任」当目标，这对安全系统是错的。团队失败概率 ≈ P(机器人失败 ∧ 人没接住)。人的接管概率随信任**下降**（越信越不监控）。所以当 τ > R_r（真实可靠度）时，继续抬信任只会拆掉备份。**存在一个最优信任 τ* ≈ R_r；过度信任与信任不足都增加团队损失。** 推论：机器人在**过度信任区**必须进入**守护模式（guardian mode）**——不是因为它不确定，而是因为**人不会再兜底**。这把 R72 的「不确定性 → 更保守」扩展成「**校准误差 → 更保守**」。

**灵感 5（接管是一个实时截止时间）**
直觉：R72 的 REG 只给控制环 1ms 截止时间。共享控制多了一个截止时间：**人从「以为自己在控制」到「真正接管」需要 T_take = 感知 + 决策 + 动作 + 通信延迟**。若机器人当前权限下的安全余量 m 只够撑 T_safe = m / v，则必须满足 **T_take ≤ T_safe**，否则要么提前让渡，要么降速买时间（v ≤ m / T_take）。所以**接管不是一个 UI 问题，是一个和 1kHz 控制环同构的硬实时可行性问题**。R72 的 REG 契约必须被扩展：**接管路径也是实时路径**。

**灵感 6（可问责 → 权限与信息必须可重放）**
直觉：共享控制出了事故，问题往往不是「哪个算法错了」，而是**「谁在什么时候有权、他知道什么、界面显示了什么、他有没有可能接管」**。这在法律/伦理上叫责任归属。R72 的 J_EMB 只证明机器人算法当时有效，无法回答这些问题。需要一个**权限-责任账本 LEDGER**：逐指令记录 α、α^eff、双方能力、人因状态、展示的解释、滤波干预、接管事件，哈希链式，作为 J_SHARE 的一部分，支持事后逐指令重放。**没有账本的共享控制，是不可审计的责任真空。**

**灵感 7（透明是最优剂量，不是越多越好）**
直觉：解释/不确定性显示会提高校准，但也会占用人的工作记忆。**校准增益对解释量是凹的，负荷成本是凸的**；因此存在有限最优解释量 e*，「什么都显示」会因过载反而降低团队表现。且解释必须**诚实（faithful）**：不能只挑对自己有利的证书片段，否则 TCL 就变成**信任操纵**而非信任校准。

## 1. 形式化定义（增量：定义 366–386）

**定义 366（SHARED-GAUGE-RAS 总览）** SHARED-GAUGE-RAS = (AAM, HSM, JAM, SCC, TCL, T-REFLEX, T-VoI, A-RISK, LEDGER, GAUGE-RAS†)。七不变式：
(i) **权限显式且守恒**：任意时刻、任意子任务 k，α_t[k] ∈ [0,1] 且人机份额相加为 1；每条控制指令必须可归因到某个权限持有者/混合比例，禁止「无主指令」；
(ii) **人因可测**：每个进入仲裁的人因分量携带计量六元组 (φ,m,u,D,τ,I⊥)；测量缺失/越域 ⇒ 不得静默假设「人状态良好」，必须降级为保守单方权限；
(iii) **非补偿性能力否决**：权限只能分配给能力下界达标（C_holder ≥ C_req(风险类)）的一方；机器人测量链有效不能补偿人因状态不可测，反之亦然；
(iv) **有效权限 = 申报权限**：α^eff（含安全滤波干预）与 α^decl 的偏差必须低于 ε_auth，且每次滤波干预入账；超阈即视为静默自治并升级协商；
(v) **接管可行**：当前权限分配的接管延迟 P99 ≤ 任务剩余安全时间 T_safe；不可行则提前让渡或降速买时间；
(vi) **联合证书非补偿**：J_SHARE 是合取，任一分量无效 ⇒ 权限分配无效；
(vii) **严格逐指令退化**：AAM 失效 ⇒ 固定权限 + R72；HSM 失效 ⇒ 最坏人因假设 + 守护模式；JAM 不可行 ⇒ 静态权限划分 + R72；SCC 失效 ⇒ 协商/安全停；TCL 不诚实 ⇒ 只显示审计过的证书位；全失效 ⇒ R68。**安全侧只增不减。**

**定义 367（权限状态、权限动作与混合控制）** 设子任务集 K。权限向量 α_t ∈ Δ^{K−1}，α_t[k] 为机器人在子任务 k 上的权限份额，人为 1−α_t[k]。权限动作
a_t^auth ∈ {RETAIN, YIELD, BLEND(α), REQUEST, SAFE_STOP}。
控制混合（以阻抗为例）：
u_t[k] = α_t[k]·u_r[k](λ_t) + (1−α_t[k])·u_h[k]，
Z_t[k] = α_t[k]·Z_r[k] + (1−α_t[k])·Z_h[k]（位控/力控按同一 α 混合）。
权限动力学：α_{t+1} = T^α(α_t, a_t^auth, C_r, C_h, R_task, h_t)，
带**速率限制** |α_{t+1}[k] − α_t[k]| ≤ ρ_max（紧急安全停除外）与**驻留时间** dwell_min。
**有效权限**：α_t^eff[k] = α_t[k] + (1−α_t[k])·𝟙[‖F_λ(u_h) − u_h‖ > 0]，其中 F_λ 为安全滤波。α^eff 必须入账（定义 376）。

**定义 368（人因计量 HSM）** 人因状态 h_t = (τ_h, w_h, SA_h, attn_h, m̂_h, γ_h)：
- τ_h：对机器人的信任隐变量（**不是自报分数**）；
- w_h：认知/操作负荷；SA_h：情境意识（SAGAT 式探针的可观测代理）；attn_h：注意/参与度；m̂_h：人对机器人能力/权限/计划的心理模型；γ_h：权限偏好（「我想自己来」/「你来」）。
观测流 y_h = (gaze, pupil, HRV, response_latency, override_events, sparse_self_report)。测量模型 p(y_h | h_t, context) 与外生噪声；HSM 输出 (ĥ_t, u_h, D_h, τ_h, I⊥)。
**信任校准误差** TCE = |τ_h − R_r|，其中 R_r 为机器人**已认证**的真实可靠度（只在 J_EMB 有效域内有定义）。
**反身性**：显示/解释 e_t 是作用于 h_t 的干预——p(h_{t+1} | h_t, e_t) ≠ p(h_{t+1} | h_t)。所以 HSM 的校准必须在**随机化显示策略**下评估，不能只用「自然日志」。

**定义 369（权限能力）** 对子任务 k 与风险类 r：
- 机器人能力 C_r[k] = LCB(competence | J_EMB, E-IVG 余量, ε_emb, 剩余安全裕度) ∈ [0,1]；
- 人类能力 C_h[k] = LCB(competence | ĥ_t, 技能先验, **控制带宽** 1/T_take, SA_h, attn_h) ∈ [0,1]；
- 风险类需求 C_req(r)（如高风险任务的 C_req 接近 1）。
**能力是下界，不是均值；是子任务级，不是全局级。** 全局平均能力会掩盖某个关键子任务的失效。

**定义 370（联合权限仲裁 JAM）** 选择 (a^auth, α) 最大化
J(α) = E[U_task] − λ_safe·Risk(α) − λ_w·HumanCost(α) − λ_ov·OverrideCost(α)，
s.t. **硬约束**：
(a) Risk(α) ≤ ε_req；
(b) T_take(α) ≤ T_safe(α)（定义 371/引理 36）；
(c) C_holder[k] ≥ C_req(r_k) 对每个 k（**非补偿性否决**）；
(d) w_h + Δw(e) ≤ w_max；
(e) |α_{t+1} − α_t| ≤ ρ_max 且驻留 ≥ dwell_min。
可行集为空 ⇒ SAFE_STOP 或 REQUEST（显式协商），**绝不放宽硬约束来「凑一个解」**。

**定义 371（共享情境意识 SCC 与模式混淆/权限冲突）** 四个共享维度：权限归属、当前子目标/计划、不确定性水平、下一接管线索。定义
D_SA = Σ_i w_i·d_i(m̂_h(i), actual_i)，
其中 d_i 为对应维度的可计算散度（权限用 |m̂_h(α) − α|，计划用轨迹/子目标距离，不确定性用显示区间与 J_SHARE 区间之差）。
**模式混淆** MC = |m̂_h(α) − α| + 𝟙[人像 α≈0 那样操作，而 α≈1] + 𝟙[界面显示的权限与实际不符]。
**权限冲突** AC = 𝟙[‖u_h − u_r‖ > τ_c] ∧ 𝟙[双方置信都高]。
D_SA > ε_SA ∨ MC > τ_MC ∨ AC ⇒ SCC 失效 ⇒ REQUEST（协商）或 SAFE_STOP，**绝不静默继续**。

**定义 372（信任校准层 TCL）** 机器人从解释库 ℰ 选择 e_t（证书摘要、不确定性区间、下一步意图、权限变更理由、置信区间）。目标：
e* = argmin_e E[(τ_h' − R_r)² | e, ĥ_t] + λ_w·Δw(e) + λ_c·cost(e)，
s.t. Δw(e) ≤ budget_w，且 **诚实不变式**：e 展示的可靠度区间必须是 J_SHARE 真实区间的**有效摘要**，不得选择性隐藏不利证书位、不得把 E-IVG 未过说成过。
**TCL 是对 τ 的干预，不是装饰**；它必须与 T-REFLEX 的 L0 层耦合（定义 373）。

**定义 373（团队反作用 T-REFLEX）** 五层反作用：
- **L0 信任**：τ_{t+1} = T^τ(τ_t, robot behavior, e_t, outcomes, failures)；成本
  c^τ = c^τ_over + c^τ_under = 𝟙[τ > R_r + δ]·E[漏检干预损失] + 𝟙[τ < R_r − δ]·(误接管成本 + 弃用损失)；
- **L1 情感 ψ**（R72）：成本 c^ψ；
- **L2 意图 z**（R72）：成本 c^z；
- **L3 接触 c**（R72）：成本 c^c；
- **L4 情境意识 SA**：SA_{t+1} = T^SA(SA_t, α 变化, e_t, 模式切换, 意外事件)；成本 c^SA = ΔSA 惩罚 + 权限切换导致的 SA 损失。
累计预算 c^τ + c^ψ + c^z + c^c + c^SA ≤ B_team_total。**关键：过度信任是成本，不是收益；信任项是双向的。** 任一层越界 ⇒ T-IVG 降级。

**定义 374（团队反作用 VoI：T-VoI）**
VoI^T(g, e) = c(ψ)·IG_s + η_z·IG_z + η_τ·[TCE(τ) − E_{e,g}[TCE(τ')]] + η_SA·[SA − E[SA']]
             − Σ_{i∈{ψ,z,c,τ,SA}} c_reflex^i(g, e)
             − λ_w·Δw(e) − λ_ov·OverrideCost(g) − γ·E[ΔLoss^{future}_{degraded}]。
动作 g 包括 **ASK / EXPLAIN / YIELD / RETAIN / TAKEBACK / BLEND / SAFE_STOP**——**解释与权限转移是带 VoI 的一等动作**。选择 (g*,e*) = argmax VoI^T，s.t. 团队安全包络与预算；max VoI^T ≤ 0 ⇒ 停止交互并回退。

**定义 375（权限感知风险缩放 A-RISK）**
λ_t = max( A_risk(U_ale, U_epi, H[b_t(z)], u_tac, **H[α]**, **TCE**, **D_SA**),
            λ_floor(U_ale + U_epi + H[b_t(z)] + u_tac + H[α] + TCE + D_SA) )。
解释：
- 机器人高权限时，机器人自身不确定度主导；
- **权限模糊 H[α] 是独立风险源**：不知道谁在控制时，双方可能同时行动（冲突）或同时不行动（真空）；
- **过度信任 TCE_+ 抬高 λ_floor**（守护模式）：人越不会兜底，机器人越要保守；
- 人类持权时，机器人退化为**守护滤波器**，干预阈值 θ_int 随 λ_floor 单调。
**没有「主/次不确定度」——权限、信任、情境意识与物理/意图/接触同权进入分母。**

**定义 376（权限-责任账本 LEDGER）** 仅追加、哈希链式条目：
(t, α_t, α_t^eff, a_t^auth, C_r, C_h, ĥ_t ± u_h, e_t(展示内容), 滤波干预 F_λ, 接管事件, 停权事件, J_SHARE 摘要)。
每条控制指令都能被重放为「谁有权、双方各自知道什么、界面显示了什么、接管是否可行」。**LEDGER 根哈希进入 J_SHARE。**

**定义 377（联合证书 J_SHARE）**
J_SHARE = (J_EMB, hsm_valid, jam_feasible_hash, scc_valid, tcl_faithful, takeover_proof, ledger_root, shared_ver)。
Valid ⇔ J_EMB 有效 ∧ 人因测量在有效域 ∧ 权限分配可行且能力否决满足 ∧ SCC 不变式成立 ∧ TCL 诚实 ∧ 接管可行性证明有效 ∧ 账本完整。
**合取，非补偿。** 「机器人证书很强」不能抵消「人因状态不可测」。

**定义 378（威胁模型 AIC-SHARE）** ℰ_SHARE = ℰ_EMB × ℰ_auth × ℰ_human × ℰ_ui：
- ℰ_auth：权限霸占（该让不让）、静默自治扩张、权限抖动、责任洗白（把机器人的选择记成人的选择）、接管陷阱（过晚请求接管）；
- ℰ_human：信任操纵（挑有利解释）、对抗性过度信任诱导、疲劳/过载利用、分心诱导、社交工程；
- ℰ_ui：不确定性显示造假、模式指示器欺骗、延迟隐藏、解释洪水（过载攻击）、警报疲劳。
R72 的威胁模型只覆盖「机器人测量链」；本轮必须覆盖「**团队认知界面**」。

**定义 379（严格退化链）**
- 全有效 ⇒ 完整共权（α 可连续混合）；
- AAM 失效（J_EMB 有效）⇒ R72 单方风险缩放 + 人类硬否决 + 守护滤波；
- AAM 有效、JAM 不可行 ⇒ 静态权限划分（高风险归人、低风险归机器人）+ R72；
- HSM 失效 ⇒ 假设最坏人因（低 SA、高负荷、过度信任）+ 守护模式 + 禁止向人让渡；
- SCC 失效 ⇒ 立即协商/安全停（共享情境破裂时不允许继续）；
- TCL 不诚实 ⇒ 只显示审计过的证书位（禁用劝说式解释）；
- 全失效 ⇒ R68。
**安全单调不减；任何退化都保留 R68 硬安全包络与人类不可剥夺的急停权。**

**定义 380（权限仲裁稳定性）** 权限切换采用**迟滞带 + 驻留时间 + 速率限制**：仅当新持有人的能力优势超过迟滞带 η_hys，或驻留时间到期且旧持有人能力下界跌破 C_req 时才切换。定义切换代价模型，要求单位时间切换次数 ≤ N_sw_max。**权限是控制变量，必须证明不抖。**

**定义 381（停止权不变式与隐藏权限）**
(i) **不可剥夺停止权**：无论 α 如何，人始终拥有一条独立于所有软件权限的硬件急停通道；软件 α 不得超过硬件否决。
(ii) **有效权限 = 申报权限**。安全滤波器 F_λ 的每次干预是**隐式权限获取**，必须入账；若单位时间干预率超过 τ_filt，则必须从「人在控制」显式切换为「机器人守护」，并告知人（否则即静默自治）。
(iii) **责任可归因**：账本必须能对每条指令唯一确定权限归属与信息集；不可归因即视为不安全配置。

**定义 382（团队指标扩展 MIB-T）** 在 R72 E-MIB 上新增：
- **权限族**：权限分配与 oracle 的一致率、模式混淆率、权限冲突率、静默自治率、接管延迟 P99、接管成功率、权限抖动率；
- **人因族**：TCE、过度/不足信任率、NASA-TLX、SAGAT 情境意识、干预率、依从/依赖率（complacency）；
- **团队族**：团队流畅度（空闲/并发时间）、完成时间、硬安全违规、恢复时间、责任可追溯覆盖率。
所有指标同遵循定义 332 六元组与 333 DAG 分层。

**定义 383（团队 IVG 扩展 T-IVG）** 失效条件：
- 人因：HSM 越域、TCE > τ_TCE、SA 赤字 > τ_SA、过度/不足信任超阈；
- 权限：接管延迟 P99 > T_safe、权限冲突/静默自治超阈、能力否决被触发、权限抖动超阈；
- 界面：TCL 诚实性违反、解释洪水导致 w_h 超预算；
- 机器人：继承 E-IVG 全部条件。
任一成立 ⇒ 对应模块降级（定义 379）。

**定义 384（权限-风险条件单调）** 若权限分配对每个子任务满足能力否决与接管可行，且共享情境一致，则团队风险界 ≤ 同一时刻 R72 单方风险界；若人因能力不达标却仍被授予权限，则团队风险可以**严格大于**单方风险（共享控制不是免费的安全增益）。**因此安全增益来自「有效分配」，不来自「有人在环」。**

**定义 385（有限停止与协商终止）** T-VoI 的交互/解释/协商动作边际成本有正下界，边际增益随轮次非增 ⇒ 存在有限 n* 停止交互；权限协商协议带最大轮数 R_max 与死锁打破规则（超时 ⇒ 安全停或默认最小风险权限），保证**不会无限「谁来开」**。

**定义 386（混合主动性协议）** 主动性令牌 token ∈ {HUMAN, ROBOT, JOINT}，随权限动作转移；令牌转移必须在账本中原子提交，且带超时。REQUEST 打开一个带截止时间的协商窗口；窗口内双方不得同时单方面改变 α。**协议层的互斥是避免权限冲突的结构性保证。**

# IP-295 AAM：权限仲裁（协调域 20–50Hz；控制域只读 α 快照）
@dataclass
class AuthorityState:
    alpha: Dict[str, float]      # subtask -> robot share in [0,1]
    action: str                  # RETAIN/YIELD/BLEND/REQUEST/SAFE_STOP
    since: float                 # dwell timer
    token: str                   # HUMAN/ROBOT/JOINT
    ledger_head: bytes

def arbitrate(st: AuthorityState, C_r, C_h, h_hat, risk_req, T_safe, params):
    cands = build_authority_candidates(st, params)          # 含 RETAIN/YIELD/BLEND/REQUEST
    feasible = []
    for a in cands:
        if not competence_veto(a, C_r, C_h, risk_req):       # 硬约束(c)
            continue
        if takeover_latency_p99(a, h_hat) > T_safe(a):       # 硬约束(b)
            continue
        if h_hat.workload + explanation_load(a) > params.w_max:
            continue
        if not rate_limit_ok(a, st.alpha, params):           # 硬约束(e)
            continue
        feasible.append(a)
    if not feasible:
        return SAFE_STOP(st.alpha) if not recoverable(st) else REQUEST(st)
    # 迟滞：除非能力优势超过带或驻留到期，否则不切
    return max(feasible, key=lambda a: team_utility(a)
               + hysteresis_bonus(a, st, params))

# IP-296 HSM：人因状态计量（感知/协调域；反身测量）
class HumanStateMetrology:
    def update(self, streams, context):
        tau   = self.trust_model.infer(streams, context)      # 隐变量后验
        wl    = self.workload_model.infer(streams)
        sa    = self.sa_model.infer(streams, context)
        attn  = self.attention_model.infer(streams)
        mhat  = self.mental_model.infer(streams, context)     # 人以为的权限/计划
        return HumanState(tau=tau, workload=wl, sa=sa, attention=attn,
                          mental=mhat, u=self.calib.uncertainty(),
                          valid=self.calib.in_domain(), tchain=self.calib.tchain)

# IP-297 JAM：联合权限模型（硬约束优化；不把安全折进软效用）
def joint_authority(C_r, C_h, risk_req, h, task, params):
    best, bestJ = None, -inf
    for alpha in authority_grid(task, params):
        if any(C_r[k] < risk_req[k] and alpha[k] > 0 for k in task.k):  # 非补偿否决
            continue
        if any(C_h[k] < risk_req[k] and alpha[k] < 1 for k in task.k):
            continue
        if takeover_latency(alpha, h) > task.T_safe:
            continue
        J = team_utility(alpha) - params.l_safe * risk(alpha) \
            - params.l_w * human_cost(alpha, h) - params.l_ov * override_cost(alpha)
        if J > bestJ: best, bestJ = alpha, J
    return best

# IP-298 SCC：共享情境意识 + 模式混淆 + 隐藏权限哨兵
def shared_sa_check(h, st, plan, displayed, filt):
    d_auth = abs(h.mental.alpha - st.alpha)
    d_plan = plan_divergence(h.mental.plan, plan)
    d_unc  = interval_gap(h.mental.reliability, displayed.reliability)
    D_sa   = W_AUTH*d_auth + W_PLAN*d_plan + W_UNC*d_unc
    silent = abs(effective_alpha(st, filt) - st.alpha)
    conflict = disagreement(h) and both_confident(h)
    if D_sa > TAU_SA or silent > TAU_AUTH or conflict:
        return SCCViolation(D_sa, silent, conflict,
                            action='NEGOTIATE' if recoverable(st) else 'SAFE_STOP')
    return SCCValid(D_sa)

# IP-299 TCL：信任校准（诚实解释 + 最优剂量）
def choose_transparency(cert, h, budget):
    best = None
    for e in explanation_library(cert):
        if not faithful(e, cert):          # 诚实不变式：不得选择性隐藏
            continue
        if workload_cost(e, h) > budget:
            continue
        gain = expected_tce_gain(h, e, cert.true_reliability)   # 对 τ 的干预收益
        cost = workload_cost(e, h) + display_cost(e)
        score = gain - LAM_W * cost
        if best is None or score > best.score:
            best = (e, score)
    return best

# IP-302 A-RISK：权限感知风险缩放（控制域，硬实时）
def authority_risk_scale(U_ale, U_epi, H_z, u_tac, H_alpha, TCE, D_sa, params):
    denom = U_ale + U_epi + H_z + u_tac + H_alpha + TCE + D_sa
    lam = max(params.lam_base * (1 + denom / params.lam_scale),
              params.lam_floor * (1 + denom))
    return lam

# IP-304 SHARED 主闭环（四域：控制/协调/计量/感知 + 硬件否决路径）
def SHARED_GAUGE_RAS_round(M, obs, audio, tac_frame, human_streams, human_cmd):
    # === 硬件否决路径（独立于所有软件，最高优先）===
    if M.estop.triggered():
        return M.estop.stop()

    snap = M.snapshot.read_latest()                  # 控制域只读
    # === 控制域（1kHz，硬实时）===
    u_r = M.ctrl.robot_policy(snap, lam=snap.lam)
    u   = blend(u_r, human_cmd, snap.alpha)          # 按申报权限混合
    u, filt = M.safety_filter(u, snap.lam_floor)     # 守护滤波（任何权限下常在）
    M.ctrl.publish(u)
    M.ledger.note_filter(filt)                       # 滤波干预必须入账
    M.cert_ctrl.write(alpha=snap.alpha, lam=snap.lam,
                      wcet=M.rtm.wcet_us(), breaker=M.breaker.status())

    # === 协调域（20–50Hz，软实时）===
    if M.clock.due_coord():
        h = M.hsm.update(human_streams, obs)
        C_r = M.jemb.competence()
        C_h = M.hsm.competence(h)
        st  = M.aam.arbitrate(M.auth, C_r, C_h, h, M.risk_req, M.t_safe)
        if st.action == 'SAFE_STOP':
            M.mode = 'SAFE_STOP'
        scc = M.scc.check(h, st, M.plan, M.displayed, M.filter_state)
        if not scc.valid:
            M.mode = 'NEGOTIATE'
        e = M.tcl.choose(M.cert, h, M.workload_budget)
        M.display.show(e)
        M.snapshot.write_authority(st.alpha, st.token)
        M.ledger.append(M.t, st, C_r, C_h, h, e, M.filter_state,
                        M.breaker.status())

    # === 计量域（50Hz，继承 R72）===
    if M.clock.due_metric():
        b_t_full = M.bse.step_full(M.b_prev, obs, M.last_action, M.last_g, M.last_y)
        z_dist, ece_z, iota_z = M.irl.update(M.y_intent_buf, M.psi_hat, b_t_full)
        gate = M.e_ivg.check(M.registry, b_t_full, z_dist, M.tac_ev, M.seal.latest)
        if not gate.valid:
            M.mode = gate.fallback
        M.snapshot.write(b_t_full, z_dist, gate, M.psi_hat, M.tac_ev)

    # === 感知域（Best-effort；继承 R72）===
    psi_hat, ece_aff = M.aura.update(audio)
    tac_ev = M.dmem.update(tac_frame, M.last_action)
    M.y_intent_buf.append(extract_intent_obs(obs, audio, M.last_action))

    # === 团队 VoI（事件触发；含解释/授权/协商）===
    if M.mode in ('FULL', 'NEGOTIATE') and (
            M.sa_deficit > TAU_SA or M.tce > TAU_TCE or entropy(b_t_full) > TAU_EPI):
        g = M.tvoi.choose(b_t_full, M.psi_hat, M.z_dist, M.tac_ev,
                          M.hsm.latest, M.auth, M.budget)
        if g:
            g.execute()
    return u, M.auth, J_SHARE(M)

## 3. 推导

**引理 33（权限模糊是独立风险源）** 设有效权限在两组策略 {π_r, π_h} 间未定，二者在状态 s 上的动作分歧为 d(s)=‖π_r(s)−π_h(s)‖。若冲突时双方同时施加动作，则最坏瞬时风险 ≥ R_max + κ·d(s)；若真空时双方都不动作，则任务失败风险 + 漏检风险。因此 E[Risk | α 不确定] > E[Risk | α 确定] 当且仅当 d>0 或存在真空。系：**H[α] 必须与物理不确定度同权进 λ；「不知道谁在开」本身就是风险。**

**引理 34（信任非单调与校准最优）** 设机器人真实可靠度 R_r，团队失败 ≈ P(robot fail)·(1 − p_int(τ)·p_succ(τ))，其中 p_int 随 τ 递减（越信越不监控），p_succ 在 τ > R_r 后递减（脱环导致接管质量下降），并存在信任不足的弃用/误接管成本 c_under(τ) 与过度信任的漏检成本 c_over(τ)。则团队损失 L(τ) 在 τ* ≈ R_r 处取极小，L 在 τ→0 与 τ→1 两端上升。**推论：以「最大化信任」为目标的 HRI 策略在安全关键系统中是错的；正确目标是 TCE 最小化。**

**引理 35（非补偿性能力否决的必要性）** 若权限分配允许用全局平均能力决定，则存在子任务 k 使 C_holder[k] < C_req(r_k) 而平均能力达标；此时该子任务的最坏风险不受其他子任务的高能力影响（风险按子任务取上界，不按平均）。故任何加权和仲裁都可能把关键子任务交给无资格方；只有**子任务级非补偿否决**能消除此类失效。系：**α 必须是子任务向量，不是全局标量。**

**引理 36（接管截止时间 ⇒ 速度上限）** 设机器人在权限 α 下距安全包络的剩余裕度为 m，最大速度为 v，人的接管延迟为 T_take（含感知、决策、动作、通信）。则接管可行 ⇔ v·T_take ≤ m。为使对 T_take 的 P99 保证成立，必须取 v ≤ m / T_take^{P99}。系：**接管与 1kHz 控制环同构，都是硬实时截止时间；共享控制必须把「人的反应时间」写进速度规划。**

**引理 37（权限抖动下界）** 设能力估计噪声方差 σ²，两持有人真实能力差 Δ，迟滞带 η_hys < Δ。朴素 argmax 的期望切换次数随 σ²/Δ² 上升；引入迟滞带与驻留时间后，单位时间切换次数 ≤ N_sw_max，且当 η_hys 在 [σ, Δ) 内时，稳态正确率损失 ≤ O(σ/Δ)。系：**权限必须是带滞回的控制量，否则仲裁器会变成振荡器。**

**引理 38（隐藏滤波 = 静默自治）** 若 F_λ 在 α^decl=0 时改变了人类指令（‖F_λ(u_h)−u_h‖>0），则实际执行的是 α^eff>0 的混合策略，而人被告知 α^decl=0。若该偏差持续且不入账，则人的情境意识按 T^SA 单调下降，接管延迟 T_take 单调上升；当能力失效需要接管时，T_take 可能超过 T_safe。系：**安全滤波器可以是安全的，同时是欺骗性的；必须把滤波干预当作权限事件审计。**

**引理 39（透明的最优剂量）** 设校准增益 g(e) 凹（边际递减）、负荷成本 c(e) 凸（超载后加速上升），则团队净收益 g(e)−c(e) 存在有限内点最优 e*；e>e* 时过度解释降低团队表现。系：**「显示全部不确定性」不是透明，是过载攻击的入口。**

**引理 40（联合证书的非补偿性）** J_SHARE 是合取式，任一分量失效即整体无效。故不存在权重 w 使「机器人证书强」补偿「人因不可测」或反之。系：**共享安全不能做加权平均，只能做与。**

**引理 41（协商终止）** 协商协议最大轮数 R_max 有限、每轮至少排除一个不可行动作或收紧一次权限可行集、超时进入默认最小风险权限/安全停；故协商必在有限轮内终止，且不会以「无权限」状态无限悬空。系：**「谁开」的争论本身必须是有截止时间的实时过程。**

**假设 A117–A123（共享层启用条件）**
- **A117 人因可测**：HSM 在部署分布内校准，TCE 有界，越域可检出；
- **A118 能力下界有效**：C_r/C_h 是真实能力的下界，C_req 覆盖任务风险类；
- **A119 接管可估**：T_take 的 P99 可估计，且 T_take ≤ T_safe 可在线检查；
- **A120 共享情境可观测**：SCC 对 m̂_h 的观测足以在 ε_SA 内检测模式混淆，α^eff 可计算；
- **A121 解释诚实**：解释库中每个 e 都是 J_SHARE 的有效摘要，审计集无选择偏差；
- **A122 协议良态**：迟滞/驻留/速率限制生效，协商有限且超时有默认最小风险权限；
- **A123 反作用良态**：τ/ψ/z/c/SA 的转移对动作 Lipschitz，团队预算有限。

**定理 27（共享严格包含与条件风险单调）** 在 A117–A123（人因校准有效、权限分配满足硬约束、SCC 成立、接管可行、TCL 诚实）下：SHARED 按定义 379 逐指令退化为 R72/R71/R68；且在有效分配下，团队风险界 ≤ R72 单方风险界（定义 384）。**注意这是条件定理：共享控制的优势来自「把权限交给更有资格的一方」，而不是「有人在环」这一事实本身。**

**定理 28（J_SHARE 有效 ⇒ 团队安全）** 通过 J_SHARE ⇒ (i) 机器人物理安全（J_EMB）；(ii) 每个子任务权限持有人能力下界达标（非补偿否决）；(iii) 接管延迟 P99 ≤ T_safe（接管可行）；(iv) 共享情境一致，无模式混淆/静默自治（SCC）；(v) 展示信息诚实且不过载（TCL）；(vi) 账本可逐指令归因。综上，团队物理与认知风险 ≤ ε_share（相对人因测量模型）。**证明重量落在「HSM 在分布内有效」与「SCC 真的覆盖了有效权限」上。**

**定理 29（权限过程稳定、协商终止、停权不变）** 由定义 380/385/386 与引理 37/41：权限切换次数有界、协商有限步终止、有效权限始终可归因，且硬件急停通道在任何 α 下保持可用。**共享控制不会因仲裁协议本身进入振荡、活锁或责任真空。**

**定理 30（可问责性）** 若 LEDGER 完整且 J_SHARE 有效，则对每条控制指令，存在唯一权限归属与信息集，事后可从账本重放重建「谁在何时有权、双方知道什么、界面显示了什么、接管是否可行」。**因此共享控制的责任归属是可审计的，而不是事后叙事。**

## 6. 本轮最大风险

**一句话**：SHARED-GAUGE-RAS 把安全从「相信机器人自己的测量链」转移到「相信 **人因计量 HSM 真的测准了信任/负荷/情境意识**、相信 **共享情境意识 SCC 真的覆盖了有效权限（包括安全滤波器的静默干预）**、相信 **权限协议在真实人类的时间尺度上不会振荡/悬空/责任洗白**」——**如果 HSM 在分布外（跨文化、疲劳、药物、对抗性过度信任）把「人已经脱环」误判成「人高度参与」，如果安全滤波器长期静默改写人的指令而账本只记录了申报权限，如果 TCL 为了「提升信任」选择性地展示有利证书——那么这个系统会用一套「每层都有证书、每次授权都有账本、每个指标都在有效域内」的共享控制，在真正需要人接管的那一刻发现：人以为自己在开车，机器人以为人在监控，账本显示双方都同意了，而车已经撞上去了。这就是共享控制层面的「自信地错自己的权限」。**

次级风险与缓解：
1. **HSM 是整条链最弱的一环** → 多模态交叉验证 + 生理/行为/自报三源分歧检测；越域即降级；绝不把单一自报当真相。
2. **静默自治/滤波隐藏** → 有效权限账本 + 滤波干预率阈值 + 强制显式模式切换；「滤波即权限事件」。
3. **过度信任的守护模式被误解为「机器人变笨」** → TCL 同步解释「因为你需要休息，我暂时更保守」，并把守护原因入账；解释必须诚实。
4. **权限抖动/协商活锁** → 迟滞 + 驻留 + 速率限制 + 最大协商轮数 + 死锁打破。
5. **TCL 退化为信任操纵** → 诚实不变式 + 独立审计的解释库 + 对抗性解释检测（E384）。
6. **人因传感器隐私/伦理** → 只保留任务必需的最小信号，原始生理数据不上行、仅保留审计所需摘要；账本脱敏。
7. **共享控制拖垮实时** → 权限仲裁/HSM 全部在协调域异步，控制域只读 α 与 λ；硬件否决路径独立。
8. **复杂度爆炸** → |K|≤8、|𝒜_auth|≤5、解释库 ≤16、账本按窗口压缩；复杂度本身纳入审计指标。

# 第 73 轮产物 · 创新点清单 v1：SHARED-GAUGE-RAS（Shared-authority, Human-state-metrology, Arbitrated, Responsibility-explicit, Explainable, Deference-aware GAUGE for RAS：共享权限 × 人因计量 × 联合仲裁 × 可问责 × 可解释的具身计量审计；AAM×HSM×JAM×SCC×TCL×T-REFLEX×T-VoI×A-RISK×LEDGER×GAUGE-RAS†）

> 承接第 72 轮 IP-287~294（EMBODIED-GAUGE-RAS）。R72 把「计量审计」下沉到 ROS 2 实时执行图、意图隐变量、灵巧接触计量、三层反作用与 sim2real 桥接，解决了「机器人自己的测量链在实时调度下是否可信」。
> 但 R72 是**机器人主权**的：交互动作只有「调 λ / 软化 / 提问」，人只是证据源与扰动源。它没有把三件共享控制/HRI 的核心事实写进证书：
> - **权限不是增益**：软化 ≠ 让渡；当人更胜任时应交权，当机器人更胜任时应接管并让人保持在环；权限必须是显式的、子任务级的、带接管截止时间的状态 α。
> - **人也是被测对象**：信任 τ、负荷 w、情境意识 SA、心理模型 m̂_h 是决定团队是否安全的隐状态；过度信任会拆掉人类备份，信任不足会让共享控制退化为手动；**目标是校准，不是最大化信任**。
> - **有效权限 ≠ 申报权限**：安全滤波器每一次静默干预都是一次隐式扩权（silent autonomy）；共享控制最经典的失效不是单步算错，而是「谁在开车」的共识慢漂移破裂。
>
> 本轮把 R72 推进为 **SHARED-GAUGE-RAS**：
> - **AAM/JAM**：把 λ 单方缩放升级为**子任务级权限仲裁**，带非补偿性能力否决、接管可行性硬约束、迟滞/驻留/速率限制；
> - **HSM/SCC/TCL**：把人因状态变成**被计量的测量链**，建立共享情境意识哨兵与信任校准层，透明解释只做「最优剂量 + 诚实摘要」；
> - **T-REFLEX/T-VoI/A-RISK**：把信任与情境意识作为反作用层合算预算，把 H[α]、TCE、SA 赤字与物理/意图/接触不确定度同权塞进风险分母；
> - **LEDGER/J_SHARE**：把单方证书升级为**联合证书 + 权限-责任账本**，支持逐指令责任重放。
>
> 核心命题：**从「我的测量链可信吗」到「在谁该握权限、人是否还跟得上、我们是否对『谁在控制』有同一个信念的前提下，这个团队还能逐指令兑现安全界吗？」** ——**共权计量审计闭环**。
>
> IP 编号：IP-295~304（共 10 个）+ R72 组件的 † 化。理论姿态延续：**新层是旧层的严格泛化，安全侧只增不减，退化链逐指令等价，且共享控制的增益只来自「有效分配」而非「有人在环」。**

## 2. 形式化定义（要点版）

**定义 366（总览与七不变式）** 权限显式且守恒、人因可测、非补偿能力否决、有效权限=申报权限、接管可行、联合证书非补偿、严格退化。**任何一条失效都触发降级，不允许用其他层的强度补偿。**

**定义 367（权限状态与混合）** α∈Δ；u = α·u_r(λ) + (1−α)·u_h；Z = α·Z_r + (1−α)·Z_h；α 带速率限制 ρ_max 与驻留 dwell_min。**α^eff 把安全滤波干预计入：α^eff = α + (1−α)·𝟙[F_λ 改动了人的指令]。**

**定义 368（HSM）** 人因状态六元组，信任为隐变量；每个分量带 (φ,m,u,D,τ,I⊥)。**反身性：p(h_{t+1}|h_t,e_t) ≠ p(h_{t+1}|h_t)；HSM 必须在随机化显示策略下校准。**

**定义 369（权限能力）** C_r 来自 J_EMB/E-IVG 下界；C_h 来自 ĥ、技能先验、控制带宽 1/T_take、SA、attn；C_req 按风险类。**能力是子任务级下界，不是全局均值。**

**定义 370（JAM）** 最大化团队效用，受硬约束：Risk≤ε_req、T_take≤T_safe、C_holder≥C_req（逐子任务）、w+Δw≤w_max、速率/驻留。**可行集空 ⇒ SAFE_STOP/REQUEST，绝不放宽硬约束。**

**定义 371（SCC）** 四维共享情境；D_SA、MC、AC；**静默自治 = |α^eff − α^decl| > ε_auth**。失效 ⇒ 协商/安全停。

**定义 372（TCL）** e* = argmin E[(τ'−R_r)²] + λ_w Δw + λ_c cost，s.t. Δw≤budget 且诚实摘要。**解释是干预，不是装饰；透明度有最优剂量。**

**定义 373（T-REFLEX）** 五层反作用与联合预算；c^τ = c^τ_over（漏检干预）+ c^τ_under（误接管/弃用）。**过度信任是成本，信任项双向。**

**定义 374（T-VoI）** 物理增益 + 意图增益 + 信任校准增益 + SA 增益 − 五层反作用 − 人负荷 − 接管/协商成本 − 远期损失。**ASK/EXPLAIN/YIELD/TAKEBACK/BLEND 都是带 VoI 的动作。**

**定义 375（A-RISK）** λ 分母加入 H[α]、TCE、D_SA；过度信任抬高 λ_floor（守护）；人类持权时机器人作为守护滤波，干预阈值 θ_int 随 λ_floor 单调。

**定义 376（LEDGER）** 仅追加哈希链：时间、α、α^eff、权限动作、双方能力、人因状态、展示内容、滤波干预、接管/停权事件。**逐指令可重放。**

**定义 377（J_SHARE）** 合取式联合证书；机器人强不能补偿人因不可测，反之亦然。

**定义 378（AIC-SHARE）** 在 ℰ_EMB 上增加 ℰ_auth（霸占/静默扩权/抖动/责任洗白/接管陷阱）、ℰ_human（信任操纵/过载利用/分心）、ℰ_ui（显示造假/延迟隐藏/解释洪水/警报疲劳）。

**定义 379（严格退化）** 全有效⇒共权；AAM 失效⇒R72+硬否决+守护；JAM 不可行⇒静态权限+R72；HSM 失效⇒最坏人因+守护+禁止让渡；SCC 失效⇒协商/安全停；TCL 不诚实⇒只显示审计位；全失效⇒R68。

**定义 380（仲裁稳定）** 迟滞带 + 驻留 + 速率限制；单位时间切换 ≤ N_sw_max。**权限是控制变量，必须证明不抖。**

**定义 381（停止权不变式 / 隐藏权限）** 人拥有独立硬件急停；软件 α 不得超过硬件否决；滤波干预即隐式扩权，必须入账并在超阈时显式切换模式；每条指令必须可唯一归因。

**定义 382（MIB-T）** 权限族（一致率、模式混淆、冲突、静默自治、接管 P99/成功率、抖动）、人因族（TCE、过度/不足信任、NASA-TLX、SAGAT、依从/依赖）、团队族（流畅度、完成时间、违规、恢复、可追溯覆盖率）。

**定义 383（T-IVG）** 人因/权限/界面/机器人四类失效条件，任一 ⇒ 定义 379 的对应降级。

**定义 384（条件风险单调）** 有效分配 ⇒ 团队风险 ≤ R72；无效分配（人不够格却被授权）⇒ 团队风险可严格大于单方风险。**共享控制不是免费安全增益。**

**定义 385（有限停止/协商终止）** T-VoI 边际成本有正下界、边际增益非增 ⇒ 有限 n* 停止；协商最大轮数 R_max + 超时默认最小风险权限/安全停。

**定义 386（混合主动性协议）** 主动性令牌 {HUMAN, ROBOT, JOINT} 原子转移；REQUEST 开带截止的协商窗口，窗口内禁止单方改 α。**协议层互斥是权限冲突的结构性防线。**

def arbitrate(st, C_r, C_h, h_hat, risk_req, T_safe, params):
    feasible = []
    for a in build_authority_candidates(st, params):
        if not competence_veto(a, C_r, C_h, risk_req):     # 非补偿硬约束
            continue
        if takeover_latency_p99(a, h_hat) > T_safe(a):     # 接管硬约束
            continue

            continue

            continue
        feasible.append(a)
    if not feasible:
        return SAFE_STOP(st.alpha) if not recoverable(st) else REQUEST(st)
    return max(feasible, key=lambda a: team_utility(a)
               + hysteresis_bonus(a, st, params))

class HumanStateMetrology:

# IP-297 JAM：硬约束联合权限
def joint_authority(C_r, C_h, risk_req, h, task, params):
    best, bestJ = None, -inf
    for alpha in authority_grid(task, params):
        if any(C_r[k] < risk_req[k] and alpha[k] > 0 for k in task.k):
            continue
        if any(C_h[k] < risk_req[k] and alpha[k] < 1 for k in task.k):
            continue
        if takeover_latency(alpha, h) > task.T_safe:
            continue
        J = (team_utility(alpha) - params.l_safe * risk(alpha)
             - params.l_w * human_cost(alpha, h)
             - params.l_ov * override_cost(alpha))
        if J > bestJ: best, bestJ = alpha, J
    return best

# IP-298 SCC：共享情境/模式混淆/静默自治
def shared_sa_check(h, st, plan, displayed, filt):
    d_auth = abs(h.mental.alpha - st.alpha)
    d_plan = plan_divergence(h.mental.plan, plan)
    d_unc  = interval_gap(h.mental.reliability, displayed.reliability)
    D_sa   = W_AUTH*d_auth + W_PLAN*d_plan + W_UNC*d_unc
    silent = abs(effective_alpha(st, filt) - st.alpha)
    conflict = disagreement(h) and both_confident(h)
    if D_sa > TAU_SA or silent > TAU_AUTH or conflict:
        return SCCViolation(D_sa, silent, conflict,
                            action='NEGOTIATE' if recoverable(st) else 'SAFE_STOP')
    return SCCValid(D_sa)

# IP-299 TCL：诚实解释 + 最优剂量
def choose_transparency(cert, h, budget):
    best = None
    for e in explanation_library(cert):
        if not faithful(e, cert):                 # 不得选择性隐藏不利证书位
            continue
        if workload_cost(e, h) > budget:
            continue
        gain = expected_tce_gain(h, e, cert.true_reliability)
        cost = workload_cost(e, h) + display_cost(e)
        score = gain - LAM_W * cost
        if best is None or score > best.score:
            best = (e, score)
    return best

# IP-302 A-RISK：权限感知风险缩放（控制域 <0.08ms）
def authority_risk_scale(U_ale, U_epi, H_z, u_tac, H_alpha, TCE, D_sa, params):
    denom = U_ale + U_epi + H_z + u_tac + H_alpha + TCE + D_sa
    return max(params.lam_base * (1 + denom / params.lam_scale),
               params.lam_floor * (1 + denom))

# IP-304 SHARED 主闭环（四域 + 独立硬件否决）
def SHARED_GAUGE_RAS_round(M, obs, audio, tac_frame, human_streams, human_cmd):
    if M.estop.triggered():
        return M.estop.stop()                         # 不可剥夺停止权

    u   = blend(u_r, human_cmd, snap.alpha)
    u, filt = M.safety_filter(u, snap.lam_floor)
    M.ctrl.publish(u)
    M.ledger.note_filter(filt)                        # 滤波即权限事件
    M.cert_ctrl.write(alpha=snap.alpha, lam=snap.lam,
                      wcet=M.rtm.wcet_us(), breaker=M.breaker.status())
    # 协调域 20–50Hz

        st = M.aam.arbitrate(M.auth, M.jemb.competence(), M.hsm.competence(h),
                             h, M.risk_req, M.t_safe)

        if not scc.valid: M.mode = 'NEGOTIATE'

    M.tac_ev = M.dmem.update(tac_frame, M.last_action)
    M.y_intent_buf.append(extract_intent_obs(obs, audio, M.last_action))

## 4. 推导

**引理 33（权限模糊是独立风险源）** 有效权限未定时，双方动作分歧 d>0 导致冲突风险，或双方都不动作导致真空/漏检。故 H[α] 与物理不确定度同权进 λ；「不知道谁在开」本身就是风险。系：权限模糊不能被机器人自身的高置信度补偿。

**引理 34（信任非单调，校准最优）** p_int 随 τ 递减（越信越不监控），p_succ 在 τ>R_r 后递减（脱环导致接管质量下降），加上弃用/误接管成本，团队损失 L(τ) 在 τ*≈R_r 取极小，两端上升。系：**以「最大化信任」为目标的 HRI 在安全关键系统中是错的；目标是 TCE 最小化。**

**引理 35（非补偿能力否决的必要性）** 全局平均能力会掩盖某子任务的 C_holder<C_req；风险按子任务上界而非平均合成，故加权和仲裁可把关键子任务交给无资格方。只有子任务级非补偿否决能消除此类失效。系：α 必须是向量。

**引理 36（接管截止时间 ⇒ 速度上限）** 接管可行 ⇔ v·T_take ≤ m；对 T_take 取 P99 得 v ≤ m/T_take^{P99}。系：**接管是硬实时截止时间，必须写进速度规划。**

**引理 37（权限抖动下界）** 能力估计噪声 σ²、真实差 Δ；朴素 argmax 的期望切换随 σ²/Δ² 上升；迟滞带 η_hys∈[σ,Δ) 把切换压到 ≤N_sw_max，正确率损失 ≤O(σ/Δ)。系：**权限是带滞回的控制量。**

**引理 38（隐藏滤波 = 静默自治）** α^decl=0 时 F_λ 改动 u_h ⇒ 实际执行 α^eff>0；持续且不入账 ⇒ SA 下降、T_take 上升；需要接管时可能 T_take>T_safe。系：**安全滤波器可以既安全又欺骗；滤波干预必须审计。**

**引理 39（透明最优剂量）** 校准增益凹、负荷成本凸 ⇒ 存在有限内点 e*；e>e* 降低团队表现。系：**「显示全部」是过载攻击入口。**

**引理 40（联合证书非补偿）** J_SHARE 是合取；不存在权重使机器人强补偿人因不可测。系：共享安全只能做「与」。

**引理 41（协商终止）** R_max 有限、每轮收紧可行集、超时默认最小风险权限/安全停 ⇒ 有限终止，无悬空权限。系：「谁开」的争论本身必须有截止时间。

**假设 A117–A123（共享层启用条件）**
- **A117 人因可测**：HSM 在部署分布内校准，TCE 有界，越域可检出；
- **A118 能力下界有效**：C_r/C_h 是真实能力的下界，C_req 覆盖任务风险类；
- **A119 接管可估**：T_take 的 P99 可估计，且 T_take ≤ T_safe 可在线检查；
- **A120 共享情境可观测**：SCC 对 m̂_h 的观测足以在 ε_SA 内检测模式混淆，α^eff 可计算；
- **A121 解释诚实**：解释库中每个 e 都是 J_SHARE 的有效摘要，审计集无选择偏差；
- **A122 协议良态**：迟滞/驻留/速率限制生效，协商有限且超时有默认最小风险权限；
- **A123 反作用良态**：τ/ψ/z/c/SA 的转移对动作 Lipschitz，团队预算有限。

**定理 27（共享严格包含与条件风险单调）** 在 A117–A123（人因校准有效、权限硬约束满足、SCC 成立、接管可行、TCL 诚实）下：按定义 379 逐指令退化为 R72/R71/R68；有效分配下团队风险 ≤ R72。**条件是本质的：共享控制的增益来自有效分配，不来自「有人在环」。**

**定理 28（J_SHARE 有效 ⇒ 团队安全）** J_SHARE ⇒ J_EMB 物理安全 + 逐子任务能力达标 + 接管可行 + 共享情境一致（无模式混淆/静默自治）+ 透明诚实不过载 + 账本可归因 ⇒ 团队风险 ≤ ε_share。**证明重量在 HSM 分布内有效与 SCC 覆盖有效权限。**

**定理 29（权限过程稳定、协商终止、停权不变）** 由定义 380/385/386 与引理 37/41：切换有界、协商有限终止、有效权限可归因、硬件急停始终可用。**共享控制不会因仲裁协议本身振荡、活锁或责任真空。**

**定理 30（可问责性）** LEDGER 完整且 J_SHARE 有效 ⇒ 每条指令存在唯一权限归属与信息集，事后可重放重建「谁有权、知道什么、显示了什么、接管是否可行」。**责任归属可审计，而非事后叙事。**

## 7. 本轮最大风险

**一句话**：SHARED-GAUGE-RAS 把安全从「相信机器人自己的测量链」转移到「相信 **人因计量 HSM 真的测准了信任/负荷/情境意识**、相信 **共享情境意识 SCC 真的覆盖了有效权限（包括安全滤波器的静默干预）**、相信 **权限协议在真实人类的时间尺度上不会振荡/悬空/责任洗白**」——**如果 HSM 在分布外（跨文化、疲劳、药物、对抗性过度信任）把「人已经脱环」误判成「人高度参与」，如果安全滤波器长期静默改写人的指令而账本只记录了申报权限，如果 TCL 为了「提升信任」选择性地展示有利证书——那么这个系统会用一套「每层都有证书、每次授权都有账本、每个指标都在有效域内」的共享控制，在真正需要人接管的那一刻发现：人以为自己在开车，机器人以为人在监控，账本显示双方都同意了，而车已经撞上去了。这就是共享控制层面的「自信地错自己的权限」。**

次级风险与缓解：
1. **HSM 是整条链最弱的一环** → 生理/行为/自报三源交叉验证 + 分歧检测；越域即降级；绝不把单一自报当真相。
2. **静默自治/滤波隐藏** → 有效权限账本 + 滤波干预率阈值 + 强制显式模式切换；「滤波即权限事件」。
3. **过度信任的守护被误解为「机器人变笨」** → TCL 同步诚实解释守护原因并入账。
4. **权限抖动/协商活锁** → 迟滞 + 驻留 + 速率限制 + R_max + 死锁打破。
5. **TCL 退化为信任操纵** → 诚实不变式 + 独立审计解释库 + 对抗性解释检测（E384）。
6. **人因传感器隐私/伦理** → 只保留任务必需的最小信号，原始生理数据不上行，账本脱敏。
7. **共享控制拖垮实时** → 权限/HSM 全部在协调域异步，控制域只读 α/λ；硬件否决独立。
8. **复杂度爆炸** → |K|≤8、|𝒜_auth|≤5、解释库 ≤16、账本窗口压缩；复杂度本身纳入审计。
