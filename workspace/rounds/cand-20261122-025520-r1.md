# 第 1 轮（新灵感循环第 1 轮；本轮灵感：「最小可行产品」×「避障控制」）

> **基线**：上一循环产出 MetricVoiceGauge-NCD-HUTDH-v20 + IP-420–424（感知层：PCA/CTS/CFC/HPC/CFCtrl）。v20 及更早的 v19（DCM/OGCC/CCV/DRS/OGC）、v17（CLP/S2C/HCG/PSV/APS/AMC）全部保留。
> 本轮纪律：**最小可行是证书的选择，不是安全的让步；避障是证书内的修复，不是证书外的逃逸**。本轮只做一件事：把 v20 的“全量感知碰撞证书”升级为“最小可行避障证书”，使机器人在动态障碍下既能反应式避障，又不越过已认证边界。

## 0. 直觉与动机

### 灵感 1（最小可行产品 → 证书的最小可行核，而非全量认证）

**直觉。** v20 的 HPC 试图一次把 `Θ_n^col(o)` 尽可能完整地认证出来：采样越密、Hull 越紧、盲区越小，证书越“好”。但工程上真正被执行的往往只是其中很小的一块参数域——当前任务只需要一条可行走廊。MVP 的教训不是“做得糙”，而是“先交付一个可验证的最小闭环，再按真实需求增量扩展”。把它翻译成证书语言：**不要先认证整个域、再从中挑一条路；而要先挑出任务必需的最小核，只认证这个核，其余全部标记为“延迟认证 (deferred)”而不是“不安全 (unsafe)”**。关键反直觉点：**“未认证”是一个独立状态，不等于“碰撞”**；最小核越小，认证越快、越容易审计，而安全性不下降，因为执行被严格限制在核内。

**严谨定义。** 给定任务需求 `R = (G_task, T_task, ε_risk)`（目标集、时限、风险上界）、v20 的碰撞证书域 `Θ_n^col(o)` 与闭环动力学 `x_{t+1}=f(x_t,u_t,d_t)`，定义**可行性核**
`Viable_R(Θ) = { x ∈ Θ : ∃π, 从 x 出发在 T_task 内到达 G_task 且全程留在 Θ }`。
**最小可行证书核**为
`Θ_mv = argmin_{Θ ⊆ Θ_n^col} Cost(Θ)  s.t.  Viable_R(Θ) ≠ ∅,  V_mv(Θ) ≥ V_min,  Θ 被 v20 证书认证`，
其中 `Cost(Θ)` 是认证成本（采样数、Hull 计算、时延的加权），`V_mv(Θ) = min_{x∈Viable_R(Θ)} h(x)` 是核内最坏安全裕度，`V_min` 是预注册的逃逸裕度下界。**延迟认证集** `D_def = Θ_n^col \ Θ_mv`。扩展算子 `Expand(Θ_mv, Δ)` 仅在 `Δ` 通过 v20 的 PCA/CFC 验证且 `Viable_R(Θ_mv ∪ Δ) ≠ ∅` 时被接受。为把参数域接到控制环，记 `X_mv = {x : proj_θ(x) ∈ Θ_mv}` 为核的状态提升；下文简写 `x ∈ Θ_mv`。执行不变式：**任何时刻 `x_t ∈ Θ_mv`，否则触发扩展或安全停，绝不进入 `D_def`**。

### 灵感 2（避障控制 → 保证书的安全滤波，而非覆盖证书的反应式逃逸）

**直觉。** 反应式避障（APF、VO、DWA、CBF）擅长“此刻别撞”，但它是局部、短视的：它不知道也不关心自己是否把机器人推出了 v20 的认证域。v20 说“θ 处安全”，避障说“现在必须往左”；如果二者冲突，工程上常见的做法是让避障覆盖证书——这在动态障碍下很有效，却让“认证通过”与“实际执行”之间出现一条无人审计的缝。我们的做法相反：**避障不是覆盖证书，而是在证书内做最小干预的修复**。给每个候选避障指令配一个**见证 (witness)**：执行后状态仍在 `Θ_mv` 或一个可证返回的**避障恢复管 (ART)** 内，且统一安全函数 `h` 不下降；在所有见证中选离标称指令最近的那个；若一个见证都没有，就**安全停**，而不是逃到证书外。关键反直觉点：**避障的目标不是“离障碍最远”，而是“在保持可返回的前提下偏离标称计划最小”**——后者才同时保住安全与活性。

**严谨定义。** 状态 `x_t=(q_t, \dot q_t)`，标称控制 `u_nom`，统一安全函数
`h(x) = min( c_col(x), c_lim(x), κ·c_sing(x) )`，
其中 `c_col` 为到障碍的带 margin 距离，`c_lim` 为关节限位裕度，`c_sing` 为奇异裕度。**可容许控制集**
`U_adm(x) = { u : x'=f(x,u) ∈ Θ_mv ∪ ART,  h(x') ≥ (1-α)h(x),  Rec(x') ≠ ⊥ }`，
**保证书避障滤波器**取
`u_safe = argmin_{u ∈ U_adm(x)} ||u - u_nom||²`；
若 `U_adm(x)=∅`，输出 `u_stop` 并进入 `SAFE_STOP`。**恢复管** `ART` 是满足如下条件的集合：`ART ⊆ Cert_v20`（`Cert_v20` 为 v20 的 CCV 逐点认证状态集，**没有 v20 点证书的状态不得进入 ART**），且存在返回策略 `Rec` 与时限 `T_avo`，使得 `∀x ∈ ART, ∀d∈D`，闭环在 `T_avo` 内回到 `Θ_mv`，且全程 `h ≥ 0`。

### 两条灵感如何统一

统一为 **v20 证书体系之上的最小可行避障层**：v20 回答“给定感知，节点 n 在参数 θ 下是否零碰撞”，v21 回答“在动态障碍下，为了完成任务，最少需要认证哪一块域，以及在这块域内如何反应式避障”。**MVCK 是选择侧**（从 v20 域中选出最小可行核，延迟其余部分），**CPAF 是修复侧**（在核与恢复管内做最小干预投影），**ART 是返回侧**（允许可证返回的短时逃逸），**ICL 是审计侧**（增量、回滚、失效），**VAC 是协调侧**（预算、时效、触发）。共享状态 `ζ_mv = (Θ_mv, D_def, h, ART, ledger, u_safe, τ_mv, budget, mode_mv)`。统一接口：**若 `x ∈ Θ_mv` 且 CPAF 找到见证，则执行 `u_safe`；若 `x ∉ Θ_mv`，先尝试增量扩展；扩展失败或无见证则安全停；任何情况下都不进入 `D_def`。**

## 1. 研究问题（轮次升级版）

- **Q1（最小可行核的最小性与保守性）**：如何定义 `Cost(Θ)` 与“最小”，才能既减少认证成本又不把逃逸空间切掉？`Viable_R(Θ)` 在连续状态/参数空间上如何可判定或可过近似？如何保证 `minimalize` 只删冗余、不删可行性，且 `V_mv ≥ V_min` 始终成立？
- **Q2（保证书避障的可行性与最小干预）**：如何保证 `U_adm(x)` 在正常工况下非空？`h` 的三个分量如何标定，使“碰撞、限位、奇异”不会互相淹没？最小干预投影在离散控制集上是否唯一，如何避免抖振与局部死锁？
- **Q3（恢复管的在线计算与保守性）**：`ART` 如何在 50Hz 控制环内在线计算/更新？如何用 Hamilton–Jacobi 可达性或 CBF 构造一个既保守又不至于“全不可返回”的管？`T_avo` 与 v20 的 `TTL` 如何对齐？
- **Q4（增量扩展、回滚与感知时效）**：何时触发 `Expand`？增量如何复用 v20 的 PCA/CFC 验证而不重新认证全域？感知 HPC 过期时，如何只失效依赖它的增量，而不是整块核？如何避免“扩展—失效—再扩展”的认证抖动？

## 2. 设计原则（在 P31–P33 基础上新增 P34–P36）

**P34 最小可行选择律（Minimum Viable Selection）**
`Θ_mv ⊆ Θ_n^col`，`D_def = Θ_n^col \ Θ_mv`；执行只允许在 `Θ_mv` 内，扩展只允许经 `Expand` 且通过 v20 验证。**“延迟认证”不是“不安全”**：`D_def` 既不被执行，也不被当作障碍；它只是一个待认证的保留区。MVCK 只能选择子集，不能扩张 v20 的域；`minimalize` 必须保留 `V_mv ≥ V_min` 的逃逸带。

**P35 避障保证书律（Certificate-Preserving Avoidance）**
每个被接受的避障指令必须有见证 `w=(u, x', Rec)`：`x' ∈ Θ_mv ∪ ART`、`h(x') ≥ (1-α)h(x)`、`Rec` 在 `T_avo` 内返回 `Θ_mv`，且 `ART ⊆ Cert_v20`。在所有见证中取 `||u-u_nom||` 最小者；无见证则安全停。**避障不得进入 `D_def`，也不得修改 v20 的证书本身**。

**P36 增量可回滚律（Incremental Rollback）**
每次 `Expand`/`Shrink` 都是一笔台账事务：`(pre_hash, post_hash, Δ, source, τ, verdict)`；验证失败或新鲜度过期时回滚到上一可行核。台账是哈希链，任何篡改可被机械检出；失效只传播到依赖该 `source` 的事务，不整链作废。

## 3. 与基线的接口（如何退化）

- MVCK 失效（最小化求解失败）⇒ 直接使用 v20 的完整 `Θ_n^col`，不做最小化；等价 v20（更大但安全）；
- CPAF 失效（无可行见证/求解超时）⇒ 执行 v20 认证的标称计划；若标称计划与动态障碍冲突则安全停，绝不逃逸；
- ART 失效（返回管不可计算）⇒ 禁止离开 `Θ_mv`，活性下降但安全；
- ICL 失效（台账损坏）⇒ 只读最后一笔已验证核，不再扩展；
- VAC 失效（协调器超时）⇒ 固定 TTL/预算，回退 v20 的 CFCtrl/APS；
- 五者全失效 ⇒ 完全回退 v20；
- **安全继承**：MVCK 只选子集、CPAF 只在 `Θ_mv ∪ ART` 内修复、ART 只允许 `Cert_v20` 内的可证返回、ICL 只回滚不扩张、VAC 只失效不新增，故 `Exec_v21 ⊆ Exec_v20` 由引理 162 保证。

## 4. 预期贡献

1. **最小可行证书核**：首次把 MVP 的“最小可验证闭环”翻译成碰撞证书语言，给出 `Θ_mv`、`D_def`、`Expand` 与“延迟≠不安全”的形式化，显著降低在线认证成本；
2. **保证书避障**：把反应式避障改写为带见证的最小干预安全滤波，给出 `U_adm`、`ART`、`Rec` 与无见证安全停，填上“避障覆盖证书”的审计缝；
3. **增量证书台账**：把核的每次扩展/收缩做成可回滚、可审计、按依赖失效的哈希链事务，支撑“认证即迭代”；
4. **安全-活性解耦**：MVCK 用“扩展”管活性，CPAF 用“投影”管安全，二者互不越权，避免全量认证的过度保守与纯反应式避障的证书失效；
5. **闭环继承**：`Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`，在动态障碍下保持 0 碰撞，同时把“安全停”率压到可接受范围。

## 5. 本轮最大风险

**一句话**：MVCK 的最小化与 CPAF 的局部贪心都是短视的——若最小核切得过小、恢复管又只覆盖局部，动态障碍会把状态推到核边界使 `U_adm(x)=∅`，系统进入“安全但永久冻结”的**活性陷阱**（可行性核为空，而非发生碰撞）。

```python
# IP-425 Minimum Viable Certificate Kernel
class MinimumViableCertificateKernel:
    def __init__(self, v20_hpc, cost_fn, escape_margin=0.15, v_min=0.05):
        self.hpc = v20_hpc
        self.cost_fn = cost_fn
        self.escape_margin = escape_margin
        self.v_min = v_min

    def build(self, node, obj, task_req, nominal_plan):
        theta_col = self.hpc.certified_domain(node, obj)       # v20: Θ_n^col
        seed = self.seed_from_plan(nominal_plan, theta_col)     # 任务走廊
        core = self.viability_closure(seed, theta_col, task_req)
        core = self.minimalize(core, task_req)                  # 只删冗余
        core = self.reserve_escape(core, theta_col)             # 保留逃逸带
        deferred = theta_col.difference(core)                   # D_def
        return MVKernel(core, deferred, self.cost_fn(core), task_req)

    def viability_closure(self, seed, theta_col, task_req):
        # 反向可达/受控不变闭包：保留“能回到目标且不越界”的状态
        core = seed.intersect(theta_col)
        while True:
            grow = self.predecessor(core).intersect(theta_col)
            grow = {x for x in grow if self.can_reach_goal(x, core, task_req)}
            if grow == core:
                return core
            core = grow

    def minimalize(self, core, task_req):
        # 贪心删除对 Viable_R 无贡献的单元；每次删除后重验可行性与逃逸裕度
        for cell in sorted(core.cells, key=self.cost_fn.desc):
            trial = core.remove(cell)
            if trial.viable(task_req) and trial.h_margin() >= self.v_min:
                core = trial
        return core

    def reserve_escape(self, core, theta_col):
        # 在核边界保留一条“可返回带”，防止 minimalize 把逃逸空间切光
        band = self.escape_band(core, theta_col, self.escape_margin)
        return core.union(band)

    def expand(self, kernel, delta, verifier, task_req):
        # 增量扩展：必须同时通过 v20 验证与可行性保持
        if not verifier.v20_safe(delta):            # 复用 v20 PCA/CFC/HPC
            return kernel, "V20_REJECT"
        trial = kernel.core.union(delta)
        if not trial.viable(task_req):
            return kernel, "VIABILITY_LOST"
        if trial.h_margin() < self.v_min:
            return kernel, "ESCAPE_MARGIN_LOST"
        return MVKernel(trial, kernel.deferred.difference(delta),
                        self.cost_fn(trial), task_req), "OK"
```

```python
# IP-426 Certificate-Preserving Avoidance Filter
class CertificatePreservingAvoidanceFilter:
    def __init__(self, f, h, art, alpha=0.3, du_max=0.2, tau_dwell=0.1):
        self.f, self.h, self.art = f, h, art
        self.alpha, self.du_max, self.tau_dwell = alpha, du_max, tau_dwell

    def filter(self, x, u_nom, kernel, last_u, last_switch_t, now):
        candidates = self.sample_controls(x, u_nom, self.du_max)
        witnesses = []
        for u in candidates:
            x_next = self.f(x, u)
            if not (kernel.contains(x_next) or self.art.contains(x_next)):
                continue
            if self.h(x_next) < (1 - self.alpha) * self.h(x):
                continue
            rec = self.art.return_policy(x_next)
            if rec is None:
                continue
            witnesses.append((u, x_next, rec))
        if not witnesses:
            return self.safe_stop(x), "SAFE_STOP"
        # 最小干预：离标称最近；同分时优先驻留时间长的方向，抑制抖振
        best = min(witnesses, key=lambda w: (norm(w[0] - u_nom),
                                             self.chatter_penalty(w[0], last_u)))
        if self.chatter_guard(best[0], last_u, last_switch_t, now):
            return last_u, "DWELL"
        return best[0], "OK"

    def safe_stop(self, x):
        # 安全停本身必须被认证：x ∈ Θ_mv ∪ ART 且 h(x) ≥ 0
        assert self.h(x) >= 0
        return zero_control(x)
```

```python
# IP-427 Avoidance Recovery Tube
class AvoidanceRecoveryTube:
    def __init__(self, f, h, kernel, dt=0.02, horizon=0.5):
        self.f, self.h, self.kernel = f, h, kernel
        self.dt, self.horizon = dt, horizon
        self.rec = {}

    def compute_local(self, x0):
        # 反向可达：能在 horizon 内回到 kernel 的状态集合（保守过近似）
        art = set()
        frontier = {x0}
        for _ in range(int(self.horizon / self.dt)):
            art |= frontier
            frontier = {x for x in self.pre(frontier)
                        if self.h(x) >= 0
                        and not self.kernel.contains(x)
                        and self.v20_point_certified(x)}   # ART ⊆ Cert_v20
        self.rec = self.return_policy_from(art)
        return ART(art, self.rec)

    def contains(self, x):
        return x in self.art

    def return_policy(self, x):
        return self.rec.get(x, None)   # 由反向可达过程缓存
```

```python
# IP-428 Incremental Certificate Ledger
class IncrementalCertificateLedger:
    def __init__(self):
        self.chain = []
        self.head = GENESIS

    def append(self, tx):
        tx.pre_hash = self.head
        tx.hash = H(tx.canonical())
        self.chain.append(tx)
        self.head = tx.hash
        return tx.hash

    def rollback(self, k):
        # 回到第 k 笔已验证事务；其后事务标记 STALE，不删除以便审计
        self.head = self.chain[k].hash
        for tx in self.chain[k + 1:]:
            tx.verdict = "STALE"
        return self.chain[k].kernel

    def invalidate_dependent(self, source, ttl, now):
        # 只失效依赖该 source 且超时的增量
        for tx in self.chain:
            if source in tx.sources and now - tx.tau > ttl:
                tx.verdict = "STALE"
        return self.last_viable_kernel()

    def verify(self):
        h = GENESIS
        for tx in self.chain:
            if tx.pre_hash != h or H(tx.canonical()) != tx.hash:
                return False
            h = tx.hash
        return True
```

```python
# IP-429 Viability-Avoidance Coordinator
class ViabilityAvoidanceCoordinator:
    def __init__(self, mvck, cpaf, art, ledger, v20_verifier,
                 ttl=0.5, budget_ms=8.0):
        self.mvck, self.cpaf, self.art = mvck, cpaf, art
        self.ledger, self.v20_verifier = ledger, v20_verifier
        self.ttl, self.budget_ms = ttl, budget_ms

    def tick(self, x, u_nom, kernel, now):
        # 1. 时效：只失效依赖 HPC 的增量，回退到最后可行核
        if now - kernel.tau > self.ttl:
            kernel = self.ledger.invalidate_dependent("HPC", self.ttl, now)

        # 2. 状态不在核内：尝试预算内的最小增量扩展
        if not kernel.contains(x):
            if self.budget_left(now) > 0:
                delta = self.local_delta(x)
                kernel, status = self.mvck.expand(
                    kernel, delta, self.v20_verifier, kernel.task_req)
                self.ledger.append(ICLTx(source="VAC", delta=delta,
                                         verdict=status, tau=now))
            if not kernel.contains(x):
                return self.cpaf.safe_stop(x), "OUT_OF_KERNEL"

        # 3. 核内：保证书避障滤波
        u_safe, status = self.cpaf.filter(x, u_nom, kernel,
                                          self.last_u, self.last_switch_t, now)
        self.ledger.append(ICLTx(source="CPAF", delta=None,
                                 verdict=status, tau=now))
        return u_safe, status

    def budget_left(self, now):
        return self.budget_ms - (now - self.tick_start) * 1000.0
```

## 3. 推导

**引理 157（最小可行选择保守性）** `Θ_mv ⊆ Θ_n^col`，且 `D_def = Θ_n^col \ Θ_mv` 永不执行；执行不变式保证 `x_t ∈ Θ_mv ∪ ART`。由于 `Θ_mv` 被 v20 认证、`ART ⊆ Cert_v20`，每个被执行状态都落在 v20 的认证集合内。故 `Exec_v21 ⊆ Exec_v20`。∎

**推论 157.1（延迟不等于不安全）** `D_def` 中可能存在真实障碍，也可能只是尚未认证；MVCK 既不把 `D_def` 当障碍（否则过度保守），也不把它当安全（否则越界）。它只承诺“不执行未认证区”。∎

**引理 158（避障保证书性）** 对 CPAF 接受的每个 `u`，见证保证 `x' ∈ Θ_mv ∪ ART` 且 `h(x') ≥ (1-α)h(x)`；若 `x' ∈ ART`，`Rec` 在 `T_avo` 内把状态送回 `Θ_mv` 且全程 `h ≥ 0`。对时间归纳：`x_0 ∈ Θ_mv`，每一步要么留在 `Θ_mv`，要么进入 `ART` 后按 `Rec` 返回；故所有状态都在认证集合内且 `h ≥ 0`，不会碰撞。∎

**引理 159（最小干预的局部最优性与活性条件）** `u_safe` 是 `U_adm(x)` 上严格凸二次目标（或有限候选集上）的最小元，故在局部是最小干预的。但最小干预是短视的：它不保证全局活性。若 `U_adm(x) ≠ ∅` 且 `V_mv ≥ V_min`，则下一步仍在可行性核内；若 `U_adm(x) = ∅`，安全停是唯一被认证的动作，系统可能死锁。故活性需要 `V_mv > 0` 与周期性 `Expand` 共同保证。∎

**引理 160（增量台账可审计与可回滚）** ICL 是哈希链：任一事务被篡改会改变其 `hash`，并使其后所有 `pre_hash` 校验失败，`verify()` 必然检出。`rollback(k)` 把 `head` 恢复到第 `k` 笔事务并把其后事务标记 `STALE`，故执行永远不会使用未验证的增量；回滚后的核与第 `k` 笔事务的 `post_hash` 一致。∎

**引理 161（时效协调的安全继承）** VAC 在 `now - τ_mv > ttl` 时只失效依赖 `HPC` 的增量，并回退到 `last_viable_kernel`；若不存在可行核，则回退 v20 的 `Θ_n^col` 或安全停。TTL 界定了核的最大年龄，故任一时刻 `Exec_v21(t) ⊆ Exec_v20(t)`。∎

**引理 162（v21 整体安全继承）** v21 由五个只做“限制/选择/修复/回滚/失效”的算子组成：MVCK 选子集、CPAF 在 `Θ_mv ∪ ART` 内投影、ART 只含 `Cert_v20` 的可返回状态、ICL 只回滚不扩张、VAC 只失效不新增。五者叠加不产生 `Θ_n^col` 之外的动作，故 `Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`。∎

## 7. 已知风险与失效模式

1. **最小化切掉逃逸空间**：`minimalize` 以体积/成本为目标，可能删除唯一的返回走廊，使 `Viable_R` 非空但 `U_adm` 在扰动下变空。缓解：`V_mv ≥ V_min` 硬约束、`reserve_escape` 保留边界带、死锁在线监测。
2. **可行性核的过近似误差**：`Viable_R` 在连续空间上用离散/可达性过近似，可能把不可返回状态误判为可返回（假阴性）。缓解：HJ 可达性、CBF 证书、保守离散化与误差界。
3. **ART 在线计算延迟**：高维状态空间上反向可达集计算昂贵，可能超过 50Hz 预算。缓解：局部 ART + 预计算缓存 + GPU；超时则禁用 ART，退回 `Θ_mv`。
4. **认证抖动（thrash）**：动态障碍使 HPC 频繁失效，VAC 反复扩展/回滚，导致控制不稳定。缓解：滞回、最小驻留时间、预算门控、按依赖增量失效。
5. **`h` 分量互相淹没**：`min` 结构下，碰撞距离很小会掩盖限位/奇异风险；或 `κ` 标定不当使奇异项主导。缓解：分层阈值、分量告警、保守标定与在线校准。
6. **最小干预的局部死锁**：最小干预是短视的，可能在凹形障碍前反复选择“最近但不可行”的方向。缓解：前瞻窗口、逃逸带、随机打破对称、必要时回退 v20 计划。
7. **台账膨胀与哈希链延迟**：长任务产生大量事务，链校验变慢。缓解：Merkle 批量提交、检查点裁剪、异步校验。
8. **与 v20 感知的语义错位**：`D_def` 中的真实障碍未被感知，但执行不进入 `D_def`，故安全；风险在于扩展时把未感知区域误认证。缓解：扩展必须复用 v20 PCA/CFC，且 `ART ⊆ Cert_v20` 逐点校验。

## 8. 本轮最大风险

**一句话**：MVCK 的最小化与 CPAF 的局部贪心都是短视的——若最小核切得过小、恢复管又只覆盖局部，动态障碍会把状态推到核边界使 `U_adm(x)=∅`，系统进入“安全但永久冻结”的**活性陷阱**（可行性核为空，而非发生碰撞）。
