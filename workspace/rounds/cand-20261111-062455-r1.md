# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「数据采集」×「力控」）

> 第 54 轮把技能从"能力"剖面化为"动作空间占用"，并给出云边动作对齐证书。本轮补上被动作空间刻意忽略的一维——**接触**：动作不只是位姿轨迹，还携带力/力矩（wrench）。于是动作空间从 `A=A_c×A_e` 扩展为 `A^F=A_c×A_e×W`，而力控证书的证据只能来自**数据采集**。核心矛盾：**H22 采集悖论**——要证明力控技能安全，必须有覆盖力空间的数据；但采集力数据本身要施加力，又必须先有力控安全保证，证据与前提互为条件。**H23 虚假认证**——采集数据的力空间覆盖度与证书声称的鲁棒域不一致，未被数据覆盖的力域被"顺带"认证。**H24 力残差不可归因**——力跟踪误差是接触模型、传感器偏置、柔顺参数、外扰的耦合，云端拿到标量误差无法决定"补采数据"还是"重剖分技能"。

## 0. 直觉与动机

**灵感 1（力是动作空间缺失的一维，不是后处理量）**
直觉：位姿控制假设"世界不反作用"，力控恰恰研究反作用。技能 `S` 的真实执行集不是动作点集，而是 `(a_c,a_e,w)` 三元组，其中 `w=(f,τ)∈W⊆ℝ⁶` 是接触 wrench。第 54 轮的 `α_S(a)` 只是在 `w=0` 切片上的投影；一旦接触，`α_S` 会随 `w` 收缩。把 `W` 提为一等维度后，"技能能做什么"变成一个**带力包络的可行性体**，而不是一张二维占用图。直觉上：会"抓"不等于会"轻拿轻放"，差别全在 `W` 的边界。

**灵感 2（力控剖面 = 可行 wrench 多面体 + 柔顺参数）**
直觉：力控技能的性格由两样东西决定——它能承受/施加多大的力（可行 wrench 集 `W_S`），以及它对外扰的"软硬"（阻抗 `Z_S=(K_p,K_d)`）。同一末端轨迹配不同 `Z_S`，接触稳定性天差地别。因此技能剖面应是 `β_S(a,w)` 加上稳定裕度，而不是单一占用度。

**灵感 3（数据不是免费的：采集即证据，且采集有风险）**
直觉：第 54 轮把"主动采样"当作缓解手段，却假设采样无代价。对力控而言，每一条力数据都是一次真实接触：可能划伤工件、过载关节、触发保护停机。所以数据采集应被视为**带风险预算的证据获取**：选择"最能消解证书不确定性"的接触去采，而不是穷举扫格点。数据覆盖证书 `D_cert` 应和技能证书 `Φ_S` 一样，是可审计的一等产物。

**灵感 4（采集悖论的解：安全包络的单调扩张）**
直觉：鸡生蛋问题不能靠"先随便采"解决，而要靠**保守起点 + 单调扩张**。先用零接触/微接触/被动观测得到一个必然安全的初始包络 `W_cert^0`（几乎不覆盖，但 sound）；每次只在 `W_cert^t ⊕ 裕度` 内、且有 backup 控制器可回退的位置采集；新数据通过留出验证后，才把 `W_cert^{t+1}` 扩到 `W_cert^t` 之外。证书只增不减、且每次扩张都有证据，这就把"采集"变成了一个**可证安全的不动点迭代**。直觉上像攀岩：每一步只抓已验证的支点，绳保（backup）永远在线。

**灵感 5（价值信息驱动的定向补采）**
直觉：不是所有未知都值得采。由力残差反向解释 `Explain_F` 定位不确定性最高、且对部署证书影响最大的力域子集，只在那一小块加密采集（局部加密而非全域扫描）。采集价值 = 证书熵的下降 /（风险 × 时间 × 负载代价）。这把"数据采集"从日志堆积变成**证书驱动的主动实验设计**。

**灵感 6（云边分工：云端要证据，边端只能在安全域内给证据）**
直觉：云端拥有全局任务与证书账本，可以提出"我需要 `W_r` 区域的数据"；边端拥有接触与安全监护，只能回答"在 `W_safe` 内我可以采，超出则拒绝并回传原因"。二者形成 `请求—安全过滤—采集—校准—回传—扩证` 的契约环，且**边端的安全否决权高于云端的采集请求**。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（力-动作联合空间）**
`A^F = A_c × A_e × W`，`W ⊆ ℝ⁶` 为接触 wrench 空间（力 `f` 与力矩 `τ`）。技能 `S` 的执行集 `E_S ⊆ A^F`；第 54 轮的 `A_S` 是 `E_S` 在 `W={0}` 上的切片。

**定义 122（力控剖面）**
技能 `S` 的力控剖面 `β_S : A^F → [0,1]`，且附带阻抗 `Z_S=(K_p,K_d)` 与可行 wrench 包络 `W_S(a_c,a_e)={w | β_S(a_c,a_e,w)≥θ_F}`。**力覆盖** `cover_F(S,A^F_T)=1` 当且仅当 `∀(a_c,a_e,w)∈A^F_T, β_S≥θ_F`。

**定义 123（接触稳定证书）**
接触稳定证书 `Φ_S=(W_safe, m_π, δ_F, evid)`：
- `W_safe ⊆ W_S` 为认证安全 wrench 多面体（含摩擦锥、关节力矩上限、工件承载约束）；
- `m_π > 0` 为无源性/接触稳定裕度（阻抗控制闭环的 passivity margin）；
- `δ_F` 为力跟踪容差；
- `evid` 为支撑该证书的采集证据索引（数据集哈希 + 校准记录）。
若 `m_π < m_min` 或 `W_safe=∅`，技能不得进入接触任务。

**定义 124（数据采集覆盖证书）**
`D_cert=(C_W, C_T, prov, δ_cal)`：`C_W∈[0,1]` 为已采集数据在 `W` 上的（体积/测度）覆盖率，`C_T` 为任务相关子域覆盖率，`prov` 为数据来源与采集条件（机型、传感器、夹具、环境）溯源，`δ_cal` 为标定误差上界。**覆盖缺口** `η_D = 1 - C_W|_{W_safe}`，只统计证书声称的安全域，防止"域外数据凑覆盖率"。

**定义 125（采集价值 / 证书信息增益）**
对候选接触 `e=(a_c,a_e,w)`，
```
VoI(e) = [H(Φ_S | D) - H(Φ_S | D∪{e})] / (r(e)·κ_load + c_time(e))
```
`H` 为证书参数（`W_safe` 边界、`m_π`、`δ_F`）的后验熵，`r(e)` 为采集风险（超载/滑移/损伤概率），`κ_load` 为风险当量。采集策略选 `argmax_e VoI(e) s.t. e 满足安全包络`。

**定义 126（安全采集包络与单调扩张不变式）**
采集时刻 `t` 的认证包络 `W_cert^t`。允许的探测集
```
P^t = { e | w(e) ∈ W_cert^t ⊕ κ·m_π , BackUpReachable(e, τ_b)=1 }
```
**单调扩张不变式**：仅当新数据 `D_new` 通过留出接触验证且 `W_safe^{new}` 的扩张部分有 `C_W≥θ_cov` 支撑时，才令 `W_cert^{t+1} ⊇ W_cert^t`；否则保持或收缩。任一探测触发力/位姿越界即 abort 并由 backup 控制器接管。

**定义 127（力残差反向解释）**
力残差 `r_F = f_meas - f_pred` 分解为
```
r_F ≈ e_c (接触模型误差) + e_s (传感器偏置/漂移) + e_k (柔顺参数失配) + e_d (外扰)
```
`Explain_F(r_F)` 输出 `(主导项, 置信度, 建议动作)`，建议动作 ∈ {`recollect(W_r)` 定向补采, `reprofile(ΔZ_S)` 重标柔顺, `recalibrate(sensor)` 重标定, `reject(domain)` 拒绝域}。

## 2. 关键算法 伪代码

### IP-121 FAP-F（Force Action Profiling）

```python
def force_action_profile(skill, A_c, A_e, probe_policy, W_grid):
    beta, W_S = {}, {}
    for (a_c, a_e) in product(A_c, A_e):
        w_safe = convex_hull([w for w in W_grid
                              if probe_policy.is_safe(skill, a_c, a_e, w)])
        for w in W_grid:
            beta[(a_c,a_e,w)] = probe_policy.estimate(skill, a_c, a_e, w)
        W_S[(a_c,a_e)] = w_safe
    return ForceProfile(beta, W_S, skill.Z)

def cover_F(beta, A_F_T, theta_F=0.8):
    return all(beta.get(a,0.0) >= theta_F for a in A_F_T)
```

### IP-122 CSC（Contact Stability Certificate）

```python
def contact_certificate(profile, dynamics_model, m_min, torque_limits):
    W_safe = profile.W_S ∩ friction_cone(dynamics_model.mu) \
                        ∩ joint_torque_polytope(torque_limits)
    m_pi = passivity_margin(profile.Z, dynamics_model)   # 下界估计
    if m_pi < m_min or is_empty(W_safe):
        return ('reject', 'unstable_contact', m_pi, W_safe)
    delta_F = estimate_force_tolerance(profile, dynamics_model)
    return ('ok', CertPhi(W_safe, m_pi, delta_F,
                          evid=profile.dataset_hash))
```

### IP-123 SAQ（Safe Active Acquisition）

```python
def safe_active_acquisition(skill, D, W_cert, budget, theta_cov, tau_b):
    while budget.remaining > 0:
        candidates = sample_wrench(skill, D)                 # 后验采样
        feasible = [e for e in candidates
                    if inside(e.w, dilate(W_cert, kappa)) 
                    and backup_reachable(e, tau_b)]
        if not feasible:
            break                                            # 安全域已采尽
        e_star = max(feasible, key=lambda e: expected_VoI(e, D, skill))
        if expected_VoI(e_star, D, skill) <= theta_voi:
            break
        with force_guard(skill, W_cert, e_star):
            f_meas, meta = execute_probe(skill, e_star)
        D = D.add(e_star, f_meas, meta)
        budget.charge(risk(e_star), time_of(e_star))
        if validation_pass(D, e_star):
            W_cert = expand_monotone(W_cert, e_star, D)
    return D, W_cert
```

### IP-124 DCC（Data Coverage Certificate）

```python
def data_coverage_certificate(D, W_claim, theta_cov, delta_cal_max):
    C_W = measure(D.covered ∩ W_claim) / measure(W_claim)
    C_T = task_weighted_coverage(D, W_claim)
    delta_cal = max(D.calibration_residuals)
    prov_ok = D.provenance.matches(sensor=fk_ft, fixture=fixture_id)
    if C_W < theta_cov or delta_cal > delta_cal_max or not prov_ok:
        return ('under_covered', C_W, delta_cal, D.provenance)
    return ('ok', DataCert(C_W, C_T, D.provenance, delta_cal))
```

### IP-125 FEX（Force Residual Explain）

```python
def explain_force_residual(r_F, contact_model, sensor_model, Z):
    components = {
        'e_c': residual_under(contact_model, r_F),
        'e_s': residual_under(sensor_model, r_F),
        'e_k': residual_under(Z, r_F),
        'e_d': r_F - sum_of_above,
    }
    lead = argmax(abs(components))                        # 需可辨识性假设 A32
    action = {
        'e_c': 'recollect', 'e_s': 'recalibrate',
        'e_k': 'reprofile', 'e_d': 'reject_or_buffer',
    }[lead]
    return ExplainF(lead, confidence(components), action)
```

### IP-126 FDC（Force Data Contract）

```python
def cloud_edge_force_contract(W_request, chain, W_cert, budget, tau_b):
    # 云端请求；边端拥有安全否决权
    W_granted = W_request ∩ W_cert
    if is_empty(W_granted):
        return ('deny', 'outside_safe_envelope', W_request)
    plan = safe_active_acquisition(chain, chain.D, W_granted, budget, tau_b)
    D_new, W_cert_new = plan
    return ('grant', D_new, data_coverage_certificate(D_new, W_granted),
            explain_summary(D_new), W_cert_new)
```

### IP-127 EBC（Epistemic Bootstrapping Certificate）

```python
def expand_monotone(W_cert, e, D, theta_cov):
    W_new = W_cert ∪ {e.w}
    if not heldout_validation(D, W_new):
        return W_cert
    if data_coverage_certificate(D, W_new).C_W < theta_cov:
        return W_cert
    if not safety_invariant(W_cert, W_new, D):
        return W_cert
    return W_new
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| FAP-F | O(\|A_c\|·\|A_e\|·\|W_grid\|·T_probe) | O(\|A^F\|) | 剖面采样完备、接触模型精度 |
| CSC | O(\|W_grid\|·d) | O(\|W\|) | 摩擦锥/力矩约束 sound、m_π 为下界 |
| SAQ | O(B·(N·\|D\| + T_probe)) | O(\|D\|) | 安全包络不变式、backup 可达 |
| DCC | O(\|D\|·d) | O(\|D\|) | 覆盖率口径一致、溯源可核验 |
| FEX | O(\|r_F\|·k) | O(k) | 残差可辨识（A32） |
| EBC | O(\|D_new\|·d) | O(\|W\|) | 扩张单调、留出验证无泄漏 |

**正确性定理（Force-Data-Certified Contact Soundness, FDCS）**
假设第 54 轮 (A26)–(A28) 成立；新增 **(A29)** 力控剖面由结构化探测校准且覆盖证书 `C_W` 本身经留出接触校准（覆盖率不虚高）；**(A30)** `m_π` 为无源性下界且保守；**(A31)** 安全采集不变式成立，backup 控制器在 `τ_b` 内可达；**(A32)** `r_F` 的分解在小变形、准静态近似下可辨识。则对声称域 `T`：
```
P_success(T) ≥ 1 - η_D - δ_cal - P(w ∉ W_safe) - Σ_d(1-ρ_min(d)) - β_E
P(unsafe during acquisition) ≤ ε_safe + P(backup latency > τ_b)
```
关键：**数据覆盖是证书的前提而非附属**，**安全包络先于采集而非后验**，**扩张单调保证证据不倒退**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 力空间覆盖率估计本身未校准（"覆盖假象"） | 高 | 留出接触验证 + 覆盖率置信下界 + 红队接触 |
| 接触模型/摩擦锥漂移导致 `W_safe` 过乐观 | 高 | 在线摩擦辨识 + 保守摩擦锥 + 滑移绊线 |
| 安全包络过保守 → 数据饥饿 | 中高 | 微接触/被动观测预热 + VoI 调度 + 主动扩证 |
| backup 控制器延迟超 `τ_b` | 高 | 硬实时看门狗 + 力矩硬限幅 + 机械柔顺兜底 |
| 力传感器漂移、溯源缺失 | 中 | 采集时内嵌标定、provenance 哈希、跨机交叉校验 |
| 残差不可辨识导致误补采 | 中 | 主动激励实验 + 可辨识性检查 + 拒绝归因 |

## 6. 本轮最大风险

**一句话**：把力控与数据采集耦合后，"安全"与"证据"互为前提，方案的全部 soundness 都压在**覆盖率估计的校准性**和**安全包络扩张的单调性**上；一旦覆盖率被域外数据或分布偏移虚高，系统就会在"看似已被数据认证"的力域里越界接触，而这类失败恰恰发生在采集悖论最脆弱的边界——故必须坚持**覆盖置信下界、安全否决权优先于采集请求、以及任何扩张都以留出接触验证为前提**，宁可证书更窄，也不让"数据覆盖"变成新的虚假认证来源。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-ForceSim（FAP-F×CSC×SAQ×DCC×FEX×FDC×EBC）

> 承接第 54 轮产物 v31。本轮在动作-鲁棒性双证书体系上补入**接触维度**与**证据维度**，把"技能能做什么"扩展为"技能能施加多大 wrench 且有何证据"：
> - **FAP-F（Force Action Profiling）**：力-动作联合空间 `A^F=A_c×A_e×W` 上的技能剖面 `β_S` 与可行 wrench 包络 `W_S`；
> - **CSC（Contact Stability Certificate）**：接触稳定证书 `Φ_S=(W_safe,m_π,δ_F,evid)`；
> - **SAQ（Safe Active Acquisition）**：安全包络内、以证书信息增益为目标的主动力数据采集；
> - **DCC（Data Coverage Certificate）**：力数据覆盖证书 `D_cert=(C_W,C_T,prov,δ_cal)`，区分"采到"与"证到"；
> - **FEX（Force Residual Explain）**：力残差四分解 `(e_c,e_s,e_k,e_d)` 与采集/重剖分/重标定决策；
> - **FDC（Force Data Contract）**：云端请求证据、边端安全否决的采集契约；
> - **EBC（Epistemic Bootstrapping Certificate）**：安全包络的单调扩张证书，破解采集悖论。

def force_action_profile(skill, A_c, A_e, probe_policy, W_grid):
    beta, W_S = {}, {}
    for (a_c, a_e) in product(A_c, A_e):
        safe_ws = [w for w in W_grid
                   if probe_policy.is_safe(skill, a_c, a_e, w)]
        W_S[(a_c,a_e)] = convex_hull(safe_ws)
        for w in W_grid:
            beta[(a_c,a_e,w)] = probe_policy.estimate(skill, a_c, a_e, w)
    return ForceProfile(beta, W_S, skill.Z, dataset=probe_policy.dataset)

def cover_F(beta, A_F_T, theta_F=0.8):
    return all(beta.get(a, 0.0) >= theta_F for a in A_F_T)

### IP-123 SAQ

```python
def safe_active_acquisition(skill, D, W_cert, budget, theta_cov, tau_b):
    while budget.remaining > 0:
        cand = posterior_sample_wrench(skill, D)
        feasible = [e for e in cand
                    if inside(e.w, dilate(W_cert, kappa))
                    and backup_reachable(e, tau_b)]
        if not feasible:
            break
        e_star = max(feasible, key=lambda e: expected_VoI(e, D, skill))
        if expected_VoI(e_star, D, skill) <= theta_voi:
            break
        with force_guard(skill, W_cert, e_star):
            f_meas, meta = execute_probe(skill, e_star)
        D = D.add(e_star, f_meas, meta)
        budget.charge(risk(e_star), time_of(e_star))
        if heldout_validation(D, e_star):
            W_cert = expand_monotone(W_cert, e_star, D, theta_cov)
    return D, W_cert
```

### IP-124 DCC

def data_coverage_certificate(D, W_claim, theta_cov, delta_cal_max):
    C_W = measure(D.covered & W_claim) / measure(W_claim)
    C_T = task_weighted_coverage(D, W_claim)
    delta_cal = max(D.calibration_residuals)
    prov_ok = D.provenance.matches(sensor='ft', fixture=D.fixture_id)
    if C_W < theta_cov or delta_cal > delta_cal_max or not prov_ok:

    return ('ok', DataCert(C_W, C_T, D.provenance, delta_cal))

### IP-125 FEX

```python
def explain_force_residual(r_F, contact_model, sensor_model, Z):
    comp = {
        'e_c': residual_under(contact_model, r_F),
        'e_s': residual_under(sensor_model, r_F),
        'e_k': residual_under(Z, r_F),
        'e_d': r_F - residual_under(contact_model, r_F)
                    - residual_under(sensor_model, r_F)
                    - residual_under(Z, r_F),
    }
    if not identifiable(comp):
        return ExplainF('ambiguous', 0.0, 'active_excitation')
    lead = max(comp, key=lambda k: abs(comp[k]))
    action = {'e_c': 'recollect', 'e_s': 'recalibrate',
              'e_k': 'reprofile', 'e_d': 'reject_or_buffer'}[lead]
    return ExplainF(lead, confidence(comp), action)
```

### IP-127 EBC

```python
def expand_monotone(W_cert, e, D, theta_cov):
    W_new = W_cert | {e.w}
    if not heldout_validation(D, W_new):
        return W_cert                       # 扩张失败：保持不变（绝不后退）
    if data_coverage_certificate(D, W_new).C_W < theta_cov:
        return W_cert
    if not safety_invariant(W_cert, W_new, D):
        return W_cert
    return W_new                            # 仅证书扩张时记录新证据
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| FAP-F | O(\|A_c\|·\|A_e\|·\|W_grid\|·T_probe) | O(\|A^F\|) | 剖面可判定，接触模型精度有界 |
| CSC | O(\|W_grid\|·d) | O(\|W\|) | `W_safe` sound，`m_π` 为保守下界 |
| SAQ | O(B·(N·\|D\|+T_probe)) | O(\|D\|) | 安全包络不变式 + backup 可达 |
| DCC | O(\|D\|·d) | O(\|D\|) | 覆盖口径一致、溯源可核验 |
| FEX | O(\|r_F\|·k) | O(k) | 残差可辨识（A32） |
| FDC | O(SAQ + 通信) | O(\|D_new\|) | 安全否决优先、契约单调 |
| EBC | O(\|D_new\|·d) | O(\|W\|) | 扩张单调、留出验证无泄漏 |

**正确性定理（Force-Data-Certified Contact Soundness, FDCS）**
假设第 54 轮 (A26)–(A28) 成立；新增 **(A29)** 覆盖证书 `C_W` 经留出接触校准（不虚高）；**(A30)** `m_π` 为无源性下界且保守；**(A31)** 安全采集不变式成立且 backup 在 `τ_b` 内可达；**(A32)** `r_F` 四分解在小变形准静态下可辨识。则对声称域 `T`：
```
P_success(T) ≥ 1 - η_D - δ_cal - P(w ∉ W_safe)
                 - Σ_d(1-ρ_min(d)) - β_E
P(unsafe during acquisition) ≤ ε_safe + P(backup latency > τ_b)
```
三条关键前提：**数据覆盖先于认证**、**安全包络先于采集**、**包络扩张单调且可审计**。

## 5. 本轮最大风险

**一句话**：把力控与数据采集耦合后，"安全"与"证据"互为前提，方案的全部 soundness 都压在**覆盖率估计的校准性**和**安全包络扩张的单调性**上；一旦覆盖率被域外数据或分布偏移虚高，系统就会在"看似已被数据认证"的力域里越界接触，而这类失败恰恰发生在采集悖论最脆弱的边界——故必须坚持**覆盖置信下界、安全否决权优先于采集请求、以及任何扩张都以留出接触验证为前提**，宁可证书更窄，也不让"数据覆盖"变成新的虚假认证来源。
