## 0. 情报核实（检索日期 2026-11-20；本轮新增一手核实）

本轮直接抓取了官方提交 README 与一个官方数据集卡，得到三条会改变研究路线的事实：

1. **评测动作目录里有 `action.pivot`（7 维，shared）**，官方描述为 "Lower-body / pivot target"；动作目录里**没有** `action.base_command`。观测目录只有 4 路图像、双臂位置、EE 位姿（base frame）、抓手开合、`lower_body`(15)、语言指令；**没有底盘位姿/速度、没有 torso/D435 位姿、没有力矩/力/触觉**。
2. **官方数据集的动作里同时有 `base_command`(4) 与 `pivot`(7)**：`base_command = (vx, vy, angle_z, height)`，`pivot = (vx, vy, angle_z, pivot_3, pivot_4, pivot_5, height)`。观测里有 `lower_body`(15) = 双腿 12 + 腰 3、`state_torso`(6)、`state_d435`(6)、以及 base/torso 两套 EE 位姿。

## 1. 直觉解释（先直觉，再严谨定义）

### 灵感 1 ·「移动底盘」→ 机器人可以"走到分布里去"，而不是"把分布学进网络里"

第一性原理：5 类泛化场景不是同一种东西。位置变化、遮挡、相机-物体相对位姿是**几何偏移**；背景/光照是**光度偏移**；未见物品是**语义偏移**；人为干扰是**动态偏移**。第 1 轮把它们统一压成一个上下文向量 c 去调制网络（IP-04），这是"把分布学进网络"。但几何偏移有一个别人没用上的出口：**机器人可以动**。`action.pivot` 给了平面速度、偏航、3 个 pivot 关节和高度——它可以在 episode 开始时把相机-物体相对位姿**主动搬到训练流形附近**，让策略看到一个"见过"的场景，而不是让网络去外推一个"没见过"的场景。

一句话：**Move the robot, not the model.** 这是把测试时分布偏移从"学习问题"改写成"控制问题"。

但这里有两个不显然的坑，也是本轮真正的研究内容：

- **底盘是盲的**：评测不发送底盘位姿。你命令走了 20 cm，实际走了多少、转了多少，只能估计。底盘运动是开环的，误差随路径长度累积。
- **底盘和手臂是耦合的**：EE 目标定义在 **base frame** 里。base 一动，世界系里的 EE 就跟着动。抓取/插入时随手动底盘，等于把物体从夹爪里拽走。所以底盘不是自由的"相机小车"，而是一个**冗余自由度**：必须在"不改变世界系 EE 任务"的零空间里动。

### 灵感 2 ·「场景泛化」→ 泛化不是一根标量，而是四种机制的组合

第一性原理：一个"泛化"分数背后至少有四种数学承诺，混在一起会互相抵消：

| 偏移类型 | 数学承诺 | 正确机制 | 底盘能帮多少 |
|---|---|---|---|
| 几何（位置/遮挡/相对位姿） | **等变性** `π(g·o)=g·π(o)` | 主动规范化：把 `g·o` 搬到训练流形；或学等变表征 | **强**（可直接改变相对位姿） |
| 光度（背景/纹理/光照） | **不变性** `π(o)=π(T o)` | 表征不变性 / 域随机化 / 测试时归一化 | 弱（只能换视角，换不掉背景） |
| 语义（未见物品） | **组合性/可供性** | 可供性抓取、非抓取原语、语言先验 | 很弱（看得更清≠会做） |
| 动态（人为干扰） | **鲁棒性/恢复** | 退让、重观测、重试、物理恢复原语 | 中（可退让/重新接近） |

由此得到本轮的关键量：**可规范化率 κ**——某条泛化轴造成的性能缺口，有多大比例能被底盘/视角运动消掉。κ 是一个**可测量的诊断量**，不是口号。它直接决定资源该投给"主动规范化"还是"语义/可供性"。

### 合成：SAGE-M = SAGE + Scene-Canonicalizing Whole-Body Control

在第 1 轮三层栈（接地/技能/适应）之上，本轮加一个**"场景规范化层"**，并把第 1 轮的适应层从"只调网络"扩展为"调网络 + 调身体"：

**诊断（IP-09：SceneShift Decomposer）→ 感知（IP-10：Blind Base State Estimator）→ 行动（IP-11：Canonical Null-Space Controller）→ 恢复（IP-12：Active Peek Recovery）→ 评测（IP-13：Scene Ladder）**，
外加**训练-部署对齐（IP-16）**、**底盘相位技能（IP-14）**、**底盘审计（IP-15）**。

核心一句：**用底盘把几何分布拉回训练流形；用零空间保证不破坏操作；用场景阶梯量化每条轴到底值不值得拉。**

## 2. 瓶颈在哪里（本轮对接口/数据的结构化分析）

| 观察 | 事实 | 对策略的含义 |
|---|---|---|
| 动作缺口 | 数据有 `base_command`(4)，评测只有 `pivot`(7) | 必须从 `base_command` 蒸馏/映射到 `pivot`；不能假设二者语义相同 |
| 观测缺口 | 数据有 `state_torso`/`state_d435`，评测不发 | 底盘位姿是隐变量；需要 BBSE（IP-10）与漂移监控 |
| 结构化部分可观测 | `lower_body` 含腰 3 关节；平面 (x,y,θ) 与 h 不含 | 腰部可闭环，平面底盘只能开环+视觉校正 |
| EE 在 base frame | base 动 ⇒ 世界系 EE 动 | 底盘运动必须走零空间或做手臂补偿（L9） |
| 底盘 7 维 | vx,vy,ω,3 pivot joints,h | 冗余度足够做"保持 EE + 改视角"的次级优化 |
| 4 路相机 + 30 fps | 头双目 + 双腕 | 可做轻量视觉里程计/相对位姿估计 |
| 5 轴泛化 | 几何/光度/语义/动态四类 | 不应一锅炖；κ 分轴测量（IP-09/IP-13） |
| 榜单 teaser | 无新数字 | 一切调参以本地 OOD + 真机 A/B 为准 |

**合成代理实验（显式假设，非真机；脚本见产物区 §10）**：
- 位置轴：物体横向偏移 σ 从 0.08→0.50 m，固定底盘成功率 0.914→0.340；主动规范化后 0.986→0.880。**几何可规范化率 κ≈0.82–0.96**。
- 语义缺口 δ_sem=0.6 时，同一主动规范化的绝对增益被压到 +0.16～+0.22（从 0.234→0.393、0.136→0.352）。**底盘买得到几何，买不到语义**。
- 底盘-手臂耦合：接触中若不做补偿，Δb=5 cm 时抓握保持率已降到 0.46，Δb=10 cm 降到 0.04；10% 残差补偿下 Δb=10 cm 仍有 0.97。**接触期必须冻结或补偿**。
- 主动"偷看"：抓握后验 q≈2/3（最犹豫）时收益最大 +0.14；q=0.05 或 0.95 时为负。**只在模糊带偷看**。

这三条把本轮的边界划清楚了：**主战场是位置/遮挡这类几何轴；语义轴仍归第 1 轮 IP-02；底盘运动必须过零空间与相位门控。**

## 3. 研究问题（轮次版）

## 4. 设计原则（新增 P7–P13，保留 P1–P6）

- **P7 先测量后移动**：E619/E620 未过门之前，不写任何依赖底盘的策略；所有底盘收益先当作假设。
- **P8 几何/语义分离**：底盘只负责几何轴；语义轴继续用 IP-02 的可供性/非抓取原语。禁止用"多动底盘"掩盖"不会做"。
- **P9 零空间优先**：底盘运动优先放在世界系 EE 任务的零空间；接触期 authority→0，除非补偿已验证。
- **P10 盲区保守**：无底盘位姿观测 ⇒ 运动预算有限、漂移监控、超限即冻结；宁可少动，不可乱动。
- **P11 单一计分货币**（承 P1）：每一次底盘运动都必须能写成"提升某任务终态成功率"的因果链；不能映射的一律降级。
- **P12 可退化**：pivot 不可用/不可靠 ⇒ 退回"手臂/腕部主动视角选择 + 第 1 轮上下文调制"；再退 ⇒ 纯基线。
- **P13 合规**：只用官方声明的观测/动作；单 checkpoint、单 API；训练期特权信息（`state_torso` 等）只用于蒸馏，部署期不得读取。

## 5. 最小可提交闭环（MVP）与退化链

**MVP = IP-09（诊断） + IP-10（盲底盘状态） + IP-11 的"接触前规范化"简化版 + IP-13（场景阶梯） + 第 1 轮基线。**
不在 MVP 里做：接触期零空间运动、主动偷看、底盘技能路由——它们依赖 E623/E624 的安全验证。

**退化链**：
- L0 `pivot` 是 no-op / 不被执行 ⇒ 退回手臂+腕部主动视角选择（仍可做几何规范化，但自由度小）。
- L1 底盘状态估计漂移过大 ⇒ 退回保守开环 + 短路径，只做 episode 开头的粗规范化。
- L2 零空间残差过大 ⇒ 接触期完全冻结底盘，只在 grasp 前动。
- L3 规范化无增益（κ 低）⇒ 退回第 1 轮 SAGE，把资源转给 IP-02/IP-01。
- L4 整条链路失效 ⇒ 提交纯基线（永远保留可跑通的最小提交）。

## 6. 预期贡献（可验收）

1. **把"泛化"拆成四种机制 + 一个可测的 κ**：给出 5 轴 × 6 失败因子的二维诊断矩阵，回答"哪条轴值得用底盘治、哪条轴必须靠语义"。
2. **盲底盘状态估计与 pivot 语义辨识**：用 32 个官方数据集做一步动力学辨识，给出 pivot 的单位/延迟/积分方式与可部署估计器（这是全赛道的公共品）。
3. **场景规范化的零空间控制**：把移动底盘从"被忽略的执行器"变成"世界系 EE 零空间里的主动感知自由度"，并给出接触期安全门控。
4. **主动偷看恢复**：用物理测试时计算（移动再看一眼）修补第 1 轮"抓握误判不对称"的最大风险。
5. **场景阶梯基准**：S0–S5 逐轴可控评测，测出每条泛化轴的边际效应与交互，供后续每轮排序。
6. **底盘可信度审计**：pivot 的 jerk/rate/chunk 连续性与延迟报告，对齐官方可信度口径。

## 7. 下一轮迭代计划

## 8. 本轮最大风险（结尾一句话）

**一句话**：本轮把赌注压在"`action.pivot` 在桌面评测里是一个真正可执行、可重复、可观测校正的移动自由度"上；如果它实际上只是保持平衡/固定姿态的通道，或者速度语义/延迟未知且无底盘位姿反馈，那么"主动规范化"就退化成手臂/腕部的被动视角选择，收益从几何级掉到边际级——所以 E619/E620 必须是本轮的第一道 go/no-go 门，过不了就立刻退回第 1 轮 SAGE，而不是继续在底盘上堆工程。

## 0. 本轮结论摘要

**一句话路线**：第 1 轮把泛化当成一根标量、把底盘当成常量；本轮把泛化拆成**几何/光度/语义/动态**四种机制，并把 `action.pivot` 这个被忽略的 7 维自由度变成**可控但不可观测的测试时分布旋钮**——用底盘把几何分布拉回训练流形，用**世界系 EE 零空间**保证不破坏操作，用**相位门控**保证接触期不乱动，用**场景阶梯**量化每条泛化轴到底值不值得拉。

| 合成：δ_sem=0.6 时绝对增益压到 +0.16～+0.22 | 底盘买不到语义 | 语义轴仍归 IP-02；禁止用底盘掩盖"不会做" |
| 合成：接触中 Δb=5 cm 不补偿，抓握保持率 0.46 | 底盘-手臂强耦合 | 接触期冻结或补偿 ⇒ L9/L13 相位门控 |

**合规红线（承 P5/P6/P13）**：单一 checkpoint、单一 API；只用官方声明观测/动作；训练期特权信息只做蒸馏，部署期不读；不做"读题硬编码"；底盘轨迹必须平滑、可审计，避免触发官方"动作统计规律性/不规则交互"的可信度审核。

## 2. 创新点详述

### IP-09 · SceneShift Decomposer（P0）

- **动机**：第 1 轮的 IP-06 六因子分解回答的是"**任务哪一环**失败"（reach/grasp/transport/align/insert/release）；本轮需要正交的第二维："**哪种分布偏移**导致失败"（几何/光度/语义/动态）。两者组成 5×6 矩阵，才能回答"这条轴该用底盘治、还是该用语义/不变性治"。
- **与现有方案的差异**：现有做法把 5 类泛化场景当成同一种"域随机化"；我们把它们拆成四种数学承诺（等变/不变/组合/鲁棒），并给每条轴一个**可测的 κ**。
- **技术可行性**：高。用官方 32 数据集做基底，叠加可控扰动（物体位姿、遮挡物、背景替换、留出物体实例、脚本化人干扰），每格 n≥200；κ 用"主动 vs 被动"的差值除以 S0→S_i 的缺口。
- **所需资源**：数据 = 官方 32 数据集；算力 = 中（渲染/增强 + 小评估器）；接口 = 无。
- **落地步骤**：①搭 S0–S5 阶梯；②每条轴单独加、再 2^k 组合；③对每格跑被动/主动两套策略；④输出 `M[failure_factor, shift_type]` 与 `κ_i`；⑤用 bootstrap 给 κ 置信区间。
- **风险**：①合成扰动与真机分布不符 ⇒ 用真机锚点（每轮 2–3 个时段）标定；②κ 的估计依赖主动策略本身 ⇒ 用**固定预算的 oracle 主动策略**（允许完美底盘位姿）作为上界，真实策略只兑现其中一部分。

### IP-10 · Blind Base State Estimator（P0）

- **动机**：评测不发送底盘位姿，但世界系 EE 控制、零空间投影、漂移监控都需要 `ξ=(x,y,θ,h)`。没有它，底盘运动就是开环赌博。
- **与现有方案的差异**：现有提交要么完全不用 pivot，要么把它当"保持姿态"的常量；我们把底盘位姿当成**和抓握一样的隐变量**，用本体感觉 + 视觉 + 动作历史估计。
- **技术可行性**：中–高。①先用 32 数据集做**一步动力学辨识**：比较"pivot 是速度/位置"的候选模型，拟合 `lower_body_{t+1}=f(lower_body_t,pivot_t)` 与 `state_torso_{t+1}=g(state_torso_t,pivot_t)`；②训练小估计器（GRU/TCN + 轻量视觉特征）预测 `state_torso`/`state_d435`；③用一致性残差做漂移监控。
- **所需资源**：数据 = 官方 32 数据集；算力 = 单卡数小时；接口 = 无（纯策略内部）。
- **落地步骤**：①E619 辨识 pivot 语义（速度/位置、单位、延迟、积分）；②E620 训练可部署估计器（只用声明观测）；③E626 拟合漂移 `ε(L)`；④设安全预算 `C_max`；⑤超限冻结底盘。
- **风险**：①视觉里程计被移动物体/背景变化干扰 ⇒ 以本体感觉为主、视觉为慢校正；②一步动力学在接触/打滑时失配 ⇒ 只在自由空间用模型，接触期冻结；③高度 h 可能不可观 ⇒ 先只估计平面 (x,y,θ)，h 保持常量。

### IP-11 · Canonical Null-Space Controller（P0）

- **动机**：底盘一动，世界系 EE 就动（EE 目标在 base frame）。抓取/插入时随手动底盘 = 把物体从夹爪里拽走。正确做法不是"不动底盘"，而是**在保持世界系 EE 的零空间里动底盘**——用冗余度换视角。
- **与现有方案的差异**：现有做法把 pivot 当平衡/固定姿态；我们把底盘+腰+臂看成一条**冗余运动链**，主任务是世界系 EE 位姿，次任务是场景规范化（降低 `G(b)`、提高可达性 `R(b)`），用零空间投影保证主任务不受影响。
- **技术可行性**：中。零空间 QP 是标准工具；难点在底盘位姿估计（IP-10）与 pivot 语义（E619）。MVP 先做**离散版**：episode 开头"走到规范化位姿 → 冻结 → 操作"；完整零空间版留到 P1。
- **所需资源**：算力 = 小（QP 在 CPU 上 <1 ms）；数据 = 无（用 IP-09 的阶梯做 A/B）；接口 = `action.pivot`。
- **落地步骤**：①E619 确认 pivot 可执行；②E621 训练/拟合规范化打分器 `G(b)` 与可达性 `R(b)`；③离散版：episode 开头选 `b*` 并走过去；④E623 验证零空间补偿残差；⑤完整版：把 `b*` 作为次级目标，QP 求 `u*`；⑥相位门控 `α(z_phase)`：approach/observe=1，transport=0.5，grasp/insert/release=0。
- **风险**：①pivot 是 no-op ⇒ 全部退化为手臂/腕部视角选择（L0 退化）；②零空间二阶残差在高速/大曲率下超限 ⇒ 限速 + 曲率约束（L13）；③底盘运动撞桌/失稳 ⇒ 控制屏障函数 + 保守包络；④规范化目标把机器人带到"看得清但够不到"的位姿 ⇒ 必须联合可达性 `R(b)`，不能只最小化 `G(b)`。

### IP-12 · Active Peek Recovery（P1）

- **动机**：第 1 轮最大风险是抓握误判不对称——漏判（以为抓住其实没有）会把可救的失败变成硬失败。盲目重抓可能越弄越糟；更聪明的做法是**移动再看一眼**：用底盘/腕部做一次小型"偷看"，把抓握隐变量 `g_t` 的置信度拉高，再决定继续/重抓/换非抓取原语。
- **与现有方案的差异**：现有做法要么开环执行、要么原地重抓；我们把"移动"当成**信息获取动作**，用信息价值（value of information）决定是否值得偷看。
- **技术可行性**：高（依赖第 1 轮 IP-02 的抓握判定器）。偷看候选：横向 ±5–10 cm、高度 ±2 cm、偏航 ±0.1 rad、腕部旋转 ±0.2 rad；用 IP-11 的零空间保持 EE 稳定。
- **所需资源**：算力 = 小；数据 = 官方数据 + 少量真机试错；接口 = 无。
- **落地步骤**：①定义模糊带 `[τ_low, τ_high]`；②训练"偷看可观测性"模型（给定当前 `g` 与候选视角，预测信息增益）；③E624 对比"偷看 vs 盲目重抓"；④限制触发相位（grasp/lift，绝不 insert）；⑤设最大偷看次数（≤3）。
- **风险**：①偷看本身扰动物体 ⇒ 只在低加速度、低接触力时做；②信息增益模型不准 ⇒ 用保守阈值，宁可不偷看；③偷看增加时间 ⇒ 用第 1 轮"时长与成功无关"的结论，时间不是主要成本，但仍设上限。

### IP-13 · Scene Ladder Benchmark（P0）

- **动机**：没有可控的逐轴评测，就无法知道"底盘到底值不值得做"。第 1 轮 IP-06 是任务因子分解；本轮加**偏移类型阶梯**。
- **与现有方案的差异**：现有评测多是"随机场景跑一遍"；我们做**单轴可控 + 组合**的阶梯，能测边际效应与交互。
- **技术可行性**：中–高。S0 规范场景；S1 位置；S2 + 干扰物/遮挡；S3 + 背景/光照；S4 + 未见物品（留出实例）；S5 + 人为干扰（脚本/真人）。每格 n≥200，复用第 1 轮 L7 的样本量论证。
- **所需资源**：数据 = 官方 32 数据集 + 渲染/增强；算力 = 中；接口 = 无。
- **落地步骤**：①定义每级的可复现扰动种子；②跑被动/主动两套；③算 κ 与 5×6 矩阵；④做 2^k 交互实验；⑤把结果作为后续 IP 的"边际收益排序器"。
- **风险**：①合成阶梯与真机相关性不足 ⇒ E601 式锚点标定；②未见物品的"留出"划分泄漏 ⇒ 按实例/类别严格分组；③人干扰不可复现 ⇒ 用脚本化轨迹 + 少量真人。

### IP-14 · Base-aware Skill Tokens（P1）

- **动机**：底盘运动引入了新的相位结构（approach/observe/manipulate/retreat/recover），第 1 轮的 `z_phase` 只覆盖操作相位。把 `z_base` 加进 skill token，让 MoE 在"移动专家"和"操作专家"之间路由，仍是单 checkpoint。
- **与现有方案的差异**：现有模型把底盘动作和手臂动作混在一个策略里；我们显式条件化，避免"移动时用操作先验、操作时用移动先验"的错配。
- **技术可行性**：中。数据里有 `base_command`/`pivot`，可自动打 `z_base` 标签；依赖 IP-01 的合规形态。
- **所需资源**：数据 = 官方 32 数据集；算力 = +20%；接口 = 无。
- **落地步骤**：①从 pivot 速度/高度与相位自动标 `z_base`；②扩展 U1 为 `π(a|o,ℓ,z_task,z_phase,z_base)`；③训练 + 路由消融；④准备"单专家 + token"降级形态。
- **风险**：①`z_base` 标签噪声 ⇒ 用速度阈值 + 人工抽检；②专家退化 ⇒ P3 约束"每专家至少服务 2 个任务"；③合规 ⇒ 先书面确认多专家。

### IP-15 · Pivot Audit & Credibility（P2）

- **动机**：官方明确会采集 per-step 延迟、波动、动作统计规律性并可能据此评估可信度。底盘轨迹是新的"动作规律性"来源，必须可审计。
- **与现有方案的差异**：多数提交只保证"能跑"；我们把 pivot 的平滑性、速率、chunk 连续性、漂移做成可导出报告。
- **技术可行性**：高（工程活）。
- **所需资源**：算力 = 极小；接口 = 官方 client。
- **落地步骤**：①pivot 的 jerk/rate 限幅；②chunk 边界的 C0/C1 缝合（扩展第 1 轮 IP-03）；③延迟/漂移埋点；④N 端口 × 8 h 并发压测；⑤导出报告。
- **风险**：①过度平滑降低响应 ⇒ 只作用在残差，不改均值；②"过于规律"被视为脚本化 ⇒ 保留策略固有随机性；③pivot 与手臂的 chunk 不同步 ⇒ 统一 chunk 时钟。

### IP-16 · Sim-to-Eval Base Alignment（P1）

- **动机**：训练数据有 `base_command`、`state_torso`、`state_d435`；评测只有 `pivot` 和精简观测。这个缺口会让"在数据上训得很好"的底盘策略在评测端直接失效。
- **与现有方案的差异**：现有做法通常忽略这个缺口，或假设 `base_command≈pivot`；我们显式建模两个缺口，用**特权信息蒸馏**补上。
- **技术可行性**：中–高。①动作侧：从数据学 `base_command → pivot` 的映射（或直接把 `base_command` 当特权标签，训练时用、部署时由策略自己产生 pivot）；②观测侧：训练时用 `state_torso`/`state_d435` 做教师，蒸馏到只用声明观测的学生（IP-10）；③域随机化背景/光照，让学生对评测分布稳健。
- **所需资源**：数据 = 官方 32 数据集；算力 = 单卡数小时；接口 = 无。
- **落地步骤**：①E619 同时辨识 `base_command` 与 `pivot` 的动力学；②训练特权教师；③蒸馏学生；④在留出任务上验证动作/观测对齐；⑤部署端只读声明观测。
- **风险**：①特权信息泄漏到部署端 ⇒ 代码级审计（只允许声明键）；②蒸馏学生容量不足 ⇒ 用轻量 GRU + 视觉特征；③`base_command` 与 `pivot` 语义不同 ⇒ 先做 E619，不假设。

## 3. 符号与定义（U13–U24）

| 符号 | 含义 |
|---|---|
| `ξ=(x,y,θ,h)` | 底盘平面位姿 + 高度（评测端不可直接观测） |
| `b=(vx,vy,ω,p3,p4,p5,h)` | `action.pivot` 的 7 维命令 |
| `o_b` | 命令底盘到 `b` 并稳定后的观测 |
| `φ(·)` | 冻结视觉编码器（DINOv2/CLIP 级） |
| `M_train` | 训练观测在 `φ` 空间的流形（经验分布） |
| `G(b;o)` | 规范化缺口：`o_b` 到 `M_train` 的距离 |
| `κ(Δ)` | 偏移 `Δ` 的可规范化率 ∈[0,1] |
| `R(b;o)` | 从 `b` 出发的可达/可抓性分数 |
| `J_w` | 世界系 EE 的全身体雅可比 |
| `N` | 零空间投影 `I - J_w^† J_w` |
| `α(z_phase)` | 相位门控的底盘 authority ∈[0,1] |
| `g_t` | 抓握概率（第 1 轮 U4） |
| `I(G;o_b)` | 关于抓握状态 `G` 的期望信息增益 |
| `S_i` | 场景阶梯第 i 级 |
| `z_base` | 底盘相位 token |
| `ε_t` | 底盘状态一致性残差（漂移监控） |

**定义 U13（场景偏移分解）** `Δ = (Δ_g, Δ_p, Δ_s, Δ_d)`，分别为几何、光度、语义、动态偏移。5 条官方泛化轴是这四类的混合：位置→`Δ_g`；干扰物/遮挡→`Δ_g+Δ_d`；背景/光照→`Δ_p`；未见物品→`Δ_s(+Δ_g)`；人为干扰→`Δ_d`。

**定义 U14（规范化算子）** `C_b: o ↦ o_b`：命令底盘到 `b`（一段短轨迹）并稳定后的观测。

**定义 U15（规范化缺口）** `G(b;o) = d( φ(C_b(o)), M_train )`，`d` 用 kNN 距离或马氏距离；越小越"在训练分布里"。

**定义 U16（可规范化率）** `κ(Δ) = clip( 1 - E_{o~Δ}[min_{b∈B_safe} G(b;o)] / E_{o~Δ}[G(b_0;o)], 0, 1 )`。若分母为 0 则 κ=0。操作版用成功率缺口：`κ_i = clip( (succ_active(S_i)-succ_passive(S_i)) / (succ(S_0)-succ_passive(S_i)), 0, 1 )`。

**定义 U17（盲底盘状态）** `ξ_t=(x_t,y_t,θ_t,h_t)`；估计器 `ξ̂_t = f_ξ(o_{0:t}, b_{0:t-1})`；漂移 `e_t = ξ_t - ξ̂_t`。

**定义 U18（全身体运动学）** `x_w = T(ξ) · x_b(q_arm, q_waist)`；`J_w = ∂x_w/∂[q_arm, q_waist, b]`；零空间 `N = I - J_w^† J_w`。

**定义 U19（规范化零空间目标）** `u* = argmin_{u} G(b+N_b u;o) + λ_r / R(b+N_b u;o) + λ_s||u||²`，s.t. `J_w N u = 0`，`h_j(b+N_b u) ≥ 0`，`||u|| ≤ u_max`。

**定义 U20（相位门控 authority）** `α(z_phase) ∈ [0,1]`；实际底盘命令 `ḃ = α·ḃ_canon + (1-α)·ḃ_hold`。建议：approach/observe=1；transport=0.5；grasp/insert/release=0。

**定义 U21（主动偷看）** `b_peek = argmax_{b∈B_peek} [ I(G; C_b(o)|h_t) - λ_c c(b) ]`；仅当增益>0 且 `g_t∈[τ_low,τ_high]` 时触发。

**定义 U22（底盘相位 token）** `z_base ∈ {approach, observe, manipulate, retreat, recover}`。

**定义 U23（场景阶梯）** `S0 ⊂ S1 ⊂ … ⊂ S5`，S0 规范，S1 位置，S2 +干扰物/遮挡，S3 +背景/光照，S4 +未见物品，S5 +人为干扰；`κ_i` 由 U16 的操作版给出。

**定义 U24（训练-部署底盘缺口）** `Δ_base = D( P_train(ξ, base_command, state_torso, state_d435), P_eval(o) )`。部署策略只允许读声明观测；训练期特权信号只用于蒸馏。

```python
# ===== SAGE-M 统一策略服务（仍是单 checkpoint、单 API）=====
class SAGEMPolicy:
    def __init__(self, ckpt):
        self.sage  = SAGEPolicy(ckpt)              # 第 1 轮基线
        self.bbse  = BlindBaseStateEstimator()     # IP-10
        self.cnsc  = CanonicalNullSpaceController()# IP-11
        self.peek  = ActivePeekRecovery()          # IP-12
        self.audit = PivotAudit()                  # IP-15
        self.sessions = {}

    @property
    def metadata(self):
        m = dict(self.sage.metadata)               # control_space / obs_delta_indices / token
        m["action_chunk_size"] = 8
        return m

    def reset(self, port):
        self.sessions[port] = Session()
        self.sage.reset(port); self.bbse.reset(port)

    def get_action(self, obs, port):
        s = self.sessions[port]
        # 1) 盲底盘状态 + 漂移
        xi_hat, drift = self.bbse.update(obs, s.last_pivot)
        # 2) 第 1 轮相位 / 抓握 / 技能
        phase = self.sage.phase(obs)
        g     = self.sage.grasp_prob(obs)
        # 3) authority：接触期冻结
        alpha = self.authority(phase, drift)
        # 4) 规范化（MVP 只在接触前）
        if phase in {APPROACH, OBSERVE} and alpha > 0:
            b_star = self.cnsc.target(obs, xi_hat)
            pivot  = self.cnsc.track(b_star, xi_hat, alpha)
        else:
            pivot  = s.last_pivot                  # freeze
        # 5) 主动偷看（模糊带）
        if self.peek.should(g, phase, s.n_retry):
            pivot = self.peek.action(obs, g, xi_hat, s.n_retry)
            s.n_retry += 1
        # 6) 手臂动作（第 1 轮 IP-01/02/03）
        a = self.sage.act(obs, phase, ...)
        # 7) pivot/arm 同步缝合 + 审计
        pivot = self.audit.clamp(pivot)
        out = self.sage.pack(a, pivot, obs)
        s.last_pivot = pivot[-1]
        return out

    def authority(self, phase, drift):
        if drift > DRIFT_MAX: return 0.0             # 盲区保守
        return {APPROACH:1.0, OBSERVE:1.0,
                TRANSPORT:0.5}.get(phase, 0.0)       # grasp/insert/release=0
```

```python
class BlindBaseStateEstimator:
    def __init__(self):

                          obs["ee_pose"], last_pivot)
        xi_pri = self.dyn.propagate(self.h, last_pivot)   # 死推
        xi_hat = self.net(torch.cat([z, xi_pri]))          # 学习校正
        self.h = xi_hat
        eps    = self.consistency(obs, xi_hat, last_pivot) # 漂移监控
        return xi_hat, eps
```

```python
# ===== IP-13：场景阶梯与 κ =====
def scene_ladder(policy_passive, policy_active, tasks):
    succ = {}
    for level in [S0, S1, S2, S3, S4, S5]:
        for task in tasks:
            succ[level, task, "p"] = evaluate(policy_passive, task, level)
            succ[level, task, "a"] = evaluate(policy_active,  task, level)
    kappa = {}
    for i in range(1, 6):

        gain = succ[S_i, :, "a"].mean() - succ[S_i, :, "p"].mean()
        kappa[i] = np.clip(gain / max(gap0, EPS), 0, 1)
```

## 5. 推导（引理 L8–L15）

**引理 L8（底盘只能买几何）** 设 `G(b)=G_g(b)+G_s+G_c(b)`，其中 `G_s` 为语义缺口（未见物品的身份/可供性），对 `b` 不变；`G_g(b)` 为几何缺口；`G_c` 为非负交叉项。则 `min_{b∈B_safe} G(b) ≥ G_s`，从而 `κ(Δ) ≤ 1 - G_s/G(b_0)`。∎
> 含义：未见物品的语义缺口不能靠"看得更清"消掉；底盘对 `Δ_s` 的 κ 上界由语义缺口决定。

**引理 L9（零空间一阶安全）** 世界系 EE 速度 `ẋ_w = J_w [q̇_arm; q̇_waist; ḃ]`。若 `[q̇_arm; q̇_waist; ḃ] = J_w^† ẋ_w* + N u`，则 `J_w N u = 0`，故一阶 `ẋ_w = ẋ_w*`。二阶残差 `≈ 0.5 [q̇]^T H [q̇] Δt`，界为 `L||q̇||² Δt`。∎
> 含义：零空间运动在**一阶**不破坏世界系 EE；接触期是否可用取决于二阶残差与曲率（L13）。

**引理 L10（盲底盘漂移界）** 无底盘位姿观测时，死推误差满足 `||e_t|| ≤ e_0 + c ∫_0^t ||ḃ|| ds`；若规范化路径长度为 `L`，则 `||e_t|| ≤ e_0 + cL`。因此 κ 应乘上折扣 `exp(-λ(e_0+cL))`。∎
> 含义：底盘运动预算 `C_max` 必须有限；长距离"走过去"不如短距离"挪一下"。

**引理 L11（偷看价值）** 关于抓握状态 `G` 的期望信息增益 `I(G;o_b)=H(G)-E[H(G|o_b)]`；偷看值得做当且仅当 `I(G;o_b) > c_peek/λ`，其中 `c_peek` 是时间/扰动成本，`λ` 是单位信息的成功价值。∎

**引理 L12（规范化价值上界）** `VAC = P(succ|active)-P(succ|passive) ≤ P(fail|Δ_g)·κ·(1-e_drift)`。∎
> 含义：若失败主要来自语义/接触而非几何，底盘收益必然小；这是可预注册的否证条件。

**引理 L13（相位-速度界）** 由 L9，二阶残差 `ε≈0.5 L ||ḃ||² Δt²`；给定允许残差 `ε`，`||ḃ|| ≤ sqrt(2ε/(L Δt²))`。∎
> 含义：接触期要么把 `α→0`，要么把速度压到该界以下；不能"边插边快速转身"。

**引理 L14（阶梯可识别性）** 单轴逐级加偏移时，各轴边际效应在无强交互假设下可识别；交互用 2^5 因子设计估计。每格 `n≥200` 时标准误 `≤0.04`（复用第 1 轮 L7 的样本量论证），足以稳定 top-1 轴排序。∎

**引理 L15（合规性）** `action.pivot` 是官方声明的 shared 动作键；IP-10/11/12 只读声明观测 + 自身动作历史；训练期 `state_torso`/`state_d435`/`base_command` 只做蒸馏，不进入部署路径；对外仍是单 checkpoint、单 `get_action`。故不违反单模型/单 API 规则。∎
