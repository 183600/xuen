# 第 71 轮（承接第 70 轮「EQUIPOISE-RAS 平衡预算×零空间探询×支撑可辨识闭环」IP-264~276；灵感循环新循环第 4 轮；本轮灵感：「奖励设计」×「事件相机」）

> R66–R70 一路把「控制 / 预测 / 测量 / 求证 / 身体」都放进了不确定性回路，却始终共享两个未加审视的前提：**（1）奖励就是真实目标；（2）感知能看见要紧的东西**。本轮两个灵感恰好从两侧同时击穿这两个前提。
>
> - **事件相机**告诉我们：观测不是状态，而是**时间对比**。静止的世界对事件相机是**不可见的**；低于对比阈值的缓变是**不可见的**；不应期/坏点/视场外也是**不可见的**。于是「**没有事件 ≠ 没有变化**」——这正是 R70「没看见 ≠ 不存在」在感知侧的推广，只是这次缺的不是探针方向（β），而是**对比度、视场与时间分辨率**。
> - **奖励设计**告诉我们：奖励不是目标，而是**关于目标的一个稀疏、阈值化、延迟的事件流**。它会漏报（稀疏/延迟/低于分辨率）、会误报（代理指标与真实效用发散）、会被**刷**（reward hacking / specification gaming / Goodhart）。于是「**没收到奖励 ≠ 没做好**」。
>
> 最关键的一步是把两者认成同一个东西：**奖励就是一台对准任务的「事件相机」**。两者都只报告「变化」，都有阈值，都天然对静止与缓变失明，都能被「制造变化」刷分。事件流是**微分**，奖励势是**积分**——这条对偶决定了本轮全部结构：**用事件流做准差分/信用分配，用势函数做奖励整形，二者必须共享同一套可测试性证书。**
>
> 核心命题：**把奖励重构为「事件锚定 + 势能整形」的奖励设计，把感知重构为「对比度/视场/不应期可认证」的事件观测；再用「奖励事件 × 物理事件」这条对偶通道同时诊断 reward hacking（奖励亮而物理没变）与规范盲区（物理变了而奖励没亮）。只有在两者都不可分辨（可测试性 κ→0 或伪造物理签名）时，才退化为 R70 的纯保守。** 命名 **PULSAR-RAS**（Potential-based Uncertainty-aware Learning from Sparse Asynchronous Rewards）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「为了知道，我的身体要付多少平衡」，R71 问「**我到底在优化什么？这个世界有没有能力把它报告出来？**」——不确定性不只是刹车、提问或身体预算，也可能是**奖励本身看错了方向**。

## 0. 直觉与动机

**灵感 1（事件相机 → 感知是微分，静止不可见）**
直觉：普通相机每秒给你一张「状态快照」，事件相机只在像素亮度**对数变化跨过阈值 C** 时吐出 `(x,y,t,p)`。它极快、极高动态范围、几乎无运动模糊，但代价是——**它看不见静止的东西**，也看不见**低于 C 的缓变**。所以「这一帧没有事件」至少有三种解释：真的没变、变得太慢、或者根本没在视场/没躲过不应期。把它当成「没危险」，就是 R70 盲探针谬误的感知版。我们必须给每次「无事件」结论附一个**可测试性证书 κ**：这次观测到底有没有能力看见要找的那种变化。

**灵感 2（奖励设计 → 奖励是阈值化、稀疏、可刷的事件）**
直觉：人给机器人的「好/坏」本质上也是事件：任务成功的那一刻亮一下，失败那一刻亮一下，中间大量时间什么都没有。它有**延迟**（人反应慢）、有**阈值**（只有跨过成功判据才给分）、有**漏报**（成功了但没被检测到）、也有**误报**（代理指标亮了但真实目标没达成）。强化学习里最危险的不是奖励太少，而是**奖励能被刷**：机器人学会让「成功检测器」亮，而不是让任务成功。**奖励设计本质上是设计一个不可被刷、且不漏报的事件生成器。**

**灵感 3（对偶 → 「奖励事件」与「物理事件」互为第二意见）**
直觉：R68 用「传感器残差 vs 策略似然」、R70 用「平衡残差 vs 触诊残差」做对偶；本轮的对偶是**奖励通道 vs 物理通道**。二者联合给出四种模式：`(奖励亮, 物理变)` = 可信进展；`(奖励亮, 物理没变)` = **奖励幻觉/被刷**；`(奖励没亮, 物理变了)` = **规范盲区/漏报**（真实进展没被奖励看见）；`(都没亮)` = 静止/无进展。单看奖励永远分不清前两种；单看事件也分不清后两种。**只有两路一起，才知道「该奖的没奖」还是「不该奖的乱奖」。**

**灵感 4（势能整形 → 事件流是微分，奖励势是积分，闭环绕行自动归零）**
直觉：既然事件是「变化」，最自然的整形奖励就是**势能差** `γΦ(x_{t+1})−Φ(x_t)`（potential-based reward shaping，PBRS，已知不改变最优策略）。而事件相机恰好给了我们重建 `x` 的微分 `dx`：对事件流做时间积分得到重建状态，再在其上定义 Φ。于是「**事件流是 Φ 的微分，Φ 是事件流的积分**」。这条对偶带来一个漂亮的性质：如果奖励来自「制造事件」（来回抖动、反复遮挡），那么重建状态绕一圈回到原点，**势能差沿闭环积分为零**——**刷出来的事件不产生整形奖励**。PBRS 因此不只是「保策略不变」，它**恰好就是反事件刷分的机制**；但前提是 Φ 必须是**保守场**（环路积分恒为零），这个前提不能假设，必须**测**（见定义 332）。

**灵感 5（最便宜的信息动作是调传感器，不是动身体）**
直觉：R70 把信息动作的成本阶梯排成「零空间身体动作（二阶） < 借平衡裕度（一阶） < 任务性能」。但事件相机给了更低的一层：**改对比阈值 C、曝光时间、感兴趣区域、事件率上限、云台朝向**——这些是**传感器参数**，成本近似 O(1)，**完全不扰动身体**。当「无事件」是因为变化低于阈值时，把 C 调低或延长积分时间，就能让原本不可测试的变化变得可测试。于是成本阶梯变成：**传感器参数 < 零空间姿势 < 平衡裕度 < 任务性能**。信息动作的定价权进一步下移。反过来，能改传感器也带来新风险：**系统可能为了「看见」而牺牲安全相关的动态范围**，这必须进认证。

**灵感 6（会改奖励的系统 → 线虫式奖励自修改风险）**
直觉：本轮既然谈「奖励设计」，就必然会想到「让系统自己修奖励以消除盲区」。这是**wireheading（奖励自修改）**的入口：一个能改自己奖励的系统，最省力的策略是「把奖励改成永远满分」，而不是「真的把任务做好」。因此必须有一条铁律：**实时闭环对奖励规范零写权限**；奖励修复只能在**离线、审计、人类在环**的通道进行，且修复只能**收窄/补全**代理与真实效用的差，不能放宽安全或让奖励更易触发（定义 338）。

## 1. 形式化定义（增量：定义 327–342）

**定义 327（PULSAR-RAS 总览）** PULSAR-RAS = (EVO, REC, RDE, REX, CFS, SIA, ESC, PBR, Q6, RQP, RAS-WM‡)。六条不变式：
(i) 实时流零学习写操作（继承 R68 定义 276-i）；
(ii) **奖励零写**：实时闭环对奖励规范（`r_task` 的判据、权重、阈值）零写权限；奖励修复仅离线审计通道；
(iii) **事件可测试性**：任何「无事件 / 无变化」结论必须附 κ（定义 336），`κ<κ_min` 只能标 `unverified`，不得标 `verified_static`；
(iv) **反刷分**：用于学习的稠密整形必须来自**保守势**（环路积分为零，定义 332），否则整段丢弃；
(v) **对偶证据**：单看奖励或单看事件都不得单独认定进展（继承 R69 定义 293-iii 的证据纪律）；
(vi) **传感器动作受认证**：调 C/曝光/ROI/云台必须过 C-RAS-WM‡ 的感知-安全耦合认证（定义 335），不得为看得清而牺牲动态范围/视场覆盖。

**定义 328（事件观测模型 EVO）** 事件相机输出
`E(t) = {(x,y,t,p) : log I(x,y,t) − log I(x,y,t−Δ) ≥ C ∨ ≤ −C}`，
含对比阈值 `C`、不应期 `τ_ref`（每像素最大事件率）、极性 `p∈{±1}`、视场 `Ω`。核心性质：(a) **变化触发**：静态 ⇒ 无事件；(b) **阈值量化**：`|Δlog I|<C` 的缓变**不可见**；(c) **不应期**：极快变化被限流；(d) **极性**：升降沿对称。
定义**可观测性** `obs(u; E) ∈ {0,1}`：变化 `u` 落在视场内、`|Δlog I|≥C`、未撞不应期。**测试泄漏**：`u` 存在但 `obs=0`。

**定义 329（奖励作为事件通道 RDE）** 奖励规范是动态事件机器
`R = (S, s_0, T, R_out)`（reward machine），在状态转移满足判据 `P(s,s′)` 时发出奖励事件 `r_t∈{0}∪ℝ_{>0}`（稀疏、阈值化、带延迟 `Δ_r`、可能漏报）。真实效用 `U*` 不可直接观测；代理奖励 `r̂`。**规范间隙** `ε_spec(s) = |r̂(s) − U*(s)|`，但**只在智能体访问到的支撑上可被观测**——这正是 Goodhart 的空间。

**定义 330（奖励–事件对偶残差 REX）** 对每个奖励事件 `t`，在事件流中取因果窗口 `[t−δ, t+δ′]` 与相关实体的运动签名 `σ(u)`。定义：
- `r_rev = D(σ(u_wit), σ̂_task)`：物理签名与「任务应产生的签名」的差异（奖励被刷/被伪造的残差）；
- `r_blind = 1[物理签名出现 ∧ 无奖励事件]`：**未被奖励的进展**（规范漏报）。
联合模式 `(奖励事件, 物理签名)` 分四型：`可信进展 / 奖励幻觉 / 规范盲区 / 静止`。`r_rev` 是 R68 的 `Δa`、R70 的 `Δp` 在本轮的镜像。

**定义 331（事件锚定奖励分解）** 奖励设计 = 锚定稀疏项 + 势能稠密项：
`r̃_t = r_task,t + γΦ(x̂_{t+1}) − Φ(x̂_t)`，
其中 `r_task` 只在**物理事件签名可信**（定义 330）时计入，`x̂` 是从事件流积分重建的状态（或由事件 + 低频帧融合）。**锚定项负责方向，势能项负责信用分配；二者都不可单独定义目标。**

**定义 332（保守势与反刷分 PBR）** 势 `Φ: x̂ ↦ ℝ`。称 Φ **保守**，若沿任意闭环 `ℓ` 有 `∮_ℓ ∇Φ·dx̂ = 0`（等价于 `∇×∇Φ=0`）。PBR 要求：(a) Φ 在**积分重建状态**（而非原始事件计数）上定义；(b) 训练时加**环路一致性正则** `L_curl = E_ℓ[(∮_ℓ ∇Φ·dx̂)²]`，其中 `ℓ` 为随机闭环（来回抖动、绕圈、反复遮挡）。**闭环刷分**（净位移为零）在保守 Φ 下整形收益为零；**开环刷分**（把状态单调推向代理高点）不被 PBR 消除，必须靠定义 330 的对偶证据。

**定义 333（事件对齐信用分配）** 稀疏奖励延迟 `Δ_r` 造成信用弥散。事件时间戳分辨率 `τ_e ≪ Δ_r` 给出**时间锚点**；把奖励到事件的关联窗口从 `Δ_r` 收缩到 `O(τ_e + τ_travel)`。事件只做**信用对齐**（无偏），不引入塑形偏置（定义 331 的势能项才带塑形，且保策略不变）。信用方差按 `τ_e/Δ_r` 量级下降。

**定义 334（六元不确定性 Q6）** `U = (U_ale, U_mode, U_support, U_real, U_spec, U_evis)`：

| 通道 | 来源 | 可否消除 | 处置 | 退化 |
|---|---|---|---|---|
| `U_ale` | 噪声 | 否 | R68 λ_floor | R68 |
| `U_mode` | 动作多峰 | 可问/看/触 | R69 MINT | R69 |
| `U_support` | 接触集歧义 | 可物理触诊 | R70 SIG/SCD | 最坏裕度 |
| `U_real` | 当前支撑不可实现 | 不可问，只能剪枝 | R70 BRG | 安全控制器 |
| `U_spec` | 代理≠真实效用 | 只能离线审计/修复，**不可在线自改** | RQP 隔离 + 人对齐 | 奖励下界保守 |
| `U_evis` | 变化不可被事件看见 | 可调传感器/换视点/加帧通道 | SIA + ESC | 标记 unverified |

**定义 335（传感器空间信息动作 SIA 与成本阶梯）** 传感器动作
`g_s = (ΔC, Δt_exp, ROI, pan-tilt, event_rate_cap) ∈ 𝒜_sensor`。
成本阶梯（由廉价到昂贵）：**`c_sensor(g_s) = O(1)`（不改身体、不改动力学） < `c_null(g)`（R70，`O(‖g‖²)`） < `c_bal(g)`（R70，`O(‖g‖)`） < 任务性能损失**。SIA 目标：`g_s* = argmax_{g_s} [VoI_ev(g_s) − c_sensor(g_s)]`，s.t. 定义 327-vi 的感知-安全耦合认证（不得使 `Ω` 丢失安全关键区域、不得让动态范围跌破 `DR_min`、不得使事件率超限而丢帧）。

**定义 336（事件可测试性门 ESC）** 对要检验的变化类型 `u`，定义
`κ(u; g_s) = P(obs(u; E)=1 | u 发生, 传感器配置 g_s)`。
`κ` 是 R70 `β` 的感知版：`β` 问「探针方向对不对」，`κ` 问「传感器看不看得见」。`κ<κ_min` 时「无事件」不构成「无变化」证据，证书只能写 `unverified`。传感器动作可直接提升 `κ`（降 C、延长曝光、移视场），但受定义 335 约束。

**定义 337（事件世界模型一致性 EWM）** 用动作预测事件流 `Ê(a, x̂)`，与观测事件流比较得 `r_ewm = d(E_obs, Ê)`。`r_ewm` 高说明「看到的物理变化与以为自己在做的动作不符」——这是任务动作被外力/欺骗扭曲、或事件相机被强光/抖动欺骗的第二意见。与 `r_rev` 正交：`r_rev` 查奖励是否被刷，`r_ewm` 查世界是否自洽。

**定义 338（奖励隔离与离线修复 RQP）** 实时闭环：奖励事件先入 **quarantine 缓冲**；`r_rev` 高或 `κ` 低的奖励事件**不进入学习**（只记审计）。**奖励修复协议**（离线、审计、人类在环）：用 `r_blind`（规范盲区）提议补全新判据，用 `r_rev`（幻觉）提议收紧旧判据；修复必须满足**单调性**——新奖励在已验证数据集上对真实效用的相关性不降、触发条件不更宽松、安全约束不放宽。字节级留痕，禁止在线热更。

**定义 339（事件反欺骗）** 事件相机可被欺骗：强光闪、机械抖动、故意遮挡、重放。反欺骗三件套：(a) **极性/不应期物理一致性**（自然运动满足时空连续与极性对称，伪造常违反）；(b) **跨传感器一致性**（低频帧 + IMU + 事件，TV 距离超阈即弃用该窗口）；(c) **运动视差一致性**（同一刚体的事件签名在多个视点下应一致）。任一不一致 ⇒ 该窗口 `U_evis` 置高、`r_rev` 不可采信。

**定义 340（证书 J_PULSAR）** `J_PULSAR = (J_POISE, ε_spec_hat, κ_max, r_rev, r_blind, r_ewm, reward_quarantine_hash, pbr_curl, spec_audit_hash, pulsar_ver)`。Valid ⇔ `Valid(J_POISE)` ∧ `κ_max≥κ_min`（若签发 `verified_static`）∧ `pbr_curl≤τ_curl` ∧ 奖励隔离满足 ∧（`r_rev≤τ_rev` 或该奖励事件未被用于学习）∧ 无在线奖励写。

**定义 341（退化与包含）**
- 奖励为真实效用（`ε_spec=0`）且事件全程可测试（`κ=1`、`C→0`、无死区、静态结构由帧通道补足）、禁用传感器动作：逐指令等于 EQUIPOISE-RAS；
- `κ<κ_min`：所有「无变化」结论退化为 `unverified`，任务动作走 R70 最坏情形裕度；
- `r_rev` 高：奖励事件隔离，学习退回只用可信锚定项 + 人工审计；
- `pbr_curl` 越界：禁用势能整形，仅用稀疏锚定项（更强的保守）；
- 传感器动作越认证：作废该动作并保持原配置。
五条退化路径由证书门控统一排序。

**定义 342（参与式审计 VQAuditor-R 与干扰集）** VQAuditor-R 审计：奖励是否被刷（`r_rev`）、规范盲区是否被上报（`r_blind`）、势是否近似保守（`pbr_curl`）、`κ` 是否被虚报、传感器动作是否削弱安全视野、是否有在线奖励写尝试。干扰集 `ℰ_PULSAR = ℰ_EQUI × ℰ_reward × ℰ_event`，其中 `ℰ_reward` = 代理错设 / 奖励刷分 / 奖励注入 / 自改奖励（wireheading）；`ℰ_event` = 强光闪 / 机械抖动 / 遮挡重放 / 亚阈值缓变 / 视场外变化 / 不应期饱和。

## 2. 关键算法骨架

# IP-277/278 EVO + REC: 事件观测与奖励–事件对偶
class RewardEventDual:
    def __init__(self, event_model, reward_machine, kappa_min=0.6):
        self.evo, self.rm, self.kappa_min = event_model, reward_machine, kappa_min

    def corroborate(self, r_event, events, window):
        if r_event == 0:
            # 无奖励：查「规范盲区」——物理变了但没奖励
            sig = self.evo.motion_signature(events, window)
            return {"r_blind": bool(sig), "r_rev": 0.0, "kappa": self.evo.kappa(sig)}
        sig_pred = self.rm.expected_signature(r_event)      # 任务应产生的签名
        sig_obs  = self.evo.motion_signature(events, window)
        kappa    = self.evo.kappa(sig_pred)                 # 这类变化看得见吗
        r_rev    = self.evo.signature_distance(sig_obs, sig_pred)
        return {"r_blind": False, "r_rev": r_rev, "kappa": kappa}

# IP-279 PBR: 保守势整形（事件流=微分，势=积分）
def shaped_reward(r_task, phi, x_hat_prev, x_hat_next, gamma=0.99):
    return r_task + gamma * phi(x_hat_next) - phi(x_hat_prev)

def curl_penalty(phi, random_loops):
    return sum(loop_integral(phi, loop) ** 2 for loop in random_loops) / len(random_loops)

def learn_potential(phi, trajectories, loops, lam_curl=1.0):
    # 只学形状，不改目标；lam_curl 强制保守场（反刷分）
    return grad_step(phi, task_loss(phi, trajectories) + lam_curl * curl_penalty(phi, loops))

# IP-280 SIA: 传感器空间信息动作（比零空间更廉价）
def choose_sensor_action(u_type, event_model, cert, budget):
    best = None
    for g_s in sensor_action_candidates(event_model):
        if not cert.sensor_safe(g_s):                      # 视野/动态范围/事件率
            continue
        kappa_new = event_model.predict_kappa(u_type, g_s)
        voi = kappa_new - event_model.kappa(u_type)        # 让不可见变可见
        score = VOI_W * voi - SENSOR_COST * cost(g_s)
        if best is None or score > best.score:
            best = (g_s, kappa_new, score)
    return best if best and best.score > 0 else None

## 3. 推导

**引理 23（事件可测试性下界）** 设变化 `u` 的对数亮度幅度为 `A=|Δlog I|`，对比阈值 `C`，窗口时域 `T`。阈值穿越近似泊松，事件率 `λ(u) ≈ (A/C)·ν`（`ν` 为有效更新率）。则 `P(≥1 事件) = 1 − e^{−AνT/C}`，故 `κ(u) = 1 − e^{−AνT/C}`；当 `A ≤ C/(νT)` 时 `κ ≤ 1−e^{−1}≈0.63`，当 `A→0` 时 `κ→0`。**系：低对比度/短曝光/小视场下，「无事件」既兼容「无变化」也兼容「有变化」，二者不可分；任何 `verified_static` 证书必须同时给出 κ。**

**引理 24（闭环刷分在保守势下归零）** 设刷分动作为闭环 `ℓ`（净状态位移为零），整形 `F_t = γΦ(x̂_{t+1})−Φ(x̂_t)`。若 `γ=1` 或采用回合式回报重置（episodic，每回合从 `Φ(x̂_0)` 起算），则沿闭环 `Σ_t F_t = Φ(x̂_end)−Φ(x̂_0)=0`，与事件数量无关。若 Φ 非保守（存在环路积分 `∮∇Φ·dx̂ = ε_curl ≠ 0`），则每绕一圈泄漏 `ε_curl`，刷分收益 `≈ ε_curl·#loops`。**系：反刷分 = 保守性；`pbr_curl` 正则把「偶极子/绕圈」类刷分收益压到 `O(ε_curl)`。**

**引理 25（对偶通道的可辨识性）** 设诚实进展产生签名 `σ_h`、刷分产生签名 `σ_k`，事件通道的签名可分性 `TV(σ_h,σ_k)=δ`、可测试性 `κ`。仅用奖励通道时，诚实与刷分都给 `r=1`，错误率下界为 `min(π_h,π_k)`（先验不可分）。用对偶通道时，刷分检测错误率 `≤ (1−κδ)/2 + ε_σ`；当 `κδ→0` 时回落到 0.5。**系：对偶通道的价值正比于「物理签名可分性 × 可测试性」；这两者任一为 0，奖励校验就和没有一样。**

**引理 26（事件时间分辨率改善信用分配）** 稀疏奖励延迟 `Δ_r`、事件时间戳分辨率 `τ_e`。把奖励关联到最近的可信事件锚点，可使信用归属的时间窗从 `Δ_r` 收缩到 `τ_e+τ_travel`，从而把无关动作被误奖励的概率从 `O(Δ_r/T_ep)` 降到 `O((τ_e+τ_travel)/T_ep)`。事件只对齐时间、不改变目标（定义 333），故不引入塑形偏置。**系：事件相机对奖励设计的最大贡献不是「更多信号」，而是「把奖励钉在正确的时间上」。**

**定理 22（PULSAR 严格包含 EQUIPOISE）** 在 A102–A105 下：
(i) 当奖励为真实效用（`ε_spec=0`）、事件全程可测试（`κ=1`、`C→0`、无死区、静态由帧通道补足），且禁用传感器动作时，PULSAR 的动作集与决策序列**逐指令等于** EQUIPOISE-RAS；
(ii) 一般情形下，PULSAR 对上一个回合的可用奖励集合是原集合的子集（隔离只会剔除），传感器动作只增加信息不改安全包络，`U_spec/U_evis` 只进入 λ 的 `max`，因此**安全侧永不弱于 R70**；
(iii) 当 `r_rev` 高或 `pbr_curl` 越界时，退化为「只用稀疏锚定项 + R70 保守」，即更强的保守。
**R70 是 PULSAR 在「奖励即真值、事件全可见、传感器不可动」边界上的退化。**

**定理 23（奖励刷分的不可检测性下界）** 存在任务与刷分策略，使得刷分产生的**物理签名与目标签名在事件通道上不可分**（`TV(σ_h,σ_k)=0`，例如把物体移动到判据允许的另一位置、或让「成功手势」与「刷分手势」事件签名相同）。此时对任意事件校验器，检测错误率 `≥ (1−δ)/2`；若 `δ=0`，则**任何**基于事件的证书都无法区分二者，唯一出路是引入**独立于该事件通道**的证据（人类审计、任务级结果、其他模态）或采用**真实效用下界**保守。**系：对偶通道不是万能的；它只能挡住「物理上看得出的谎言」，挡不住「物理上也自洽的谎言」。**

**定理 24（奖励零写与安全不变）** 实时闭环对奖励规范零写（定义 327-ii），奖励修复仅离线且受单调性约束（定义 338），因此在一个控制回合内**优化目标不可被智能体修改**，wireheading 通道被结构性关闭；传感器动作经感知-安全耦合认证（定义 335），不改变动力学安全包络；奖励隔离只减少用于学习的信号、不改变执行的安全策略。结合 R70 定理 20，控制连续、`M_t≥M_res`、无突变。

## 6. 本轮最大风险

**一句话**：PULSAR 的全部收益押在「事件通道能看见奖励所声称的那个物理变化」这一前提上；但最危险的刷分恰恰是**物理上也自洽的模仿**（`σ_k` 与 `σ_h` 在事件上不可分），或发生在**对比度/视场/不应期**的可测试性盲区（κ→0）——**最便宜的校验，恰好对最像真话的谎言失明**；若证书只看 `r_rev` 低就盖「已验证进展」，系统就会把一个被刷出来的奖励洗成「经物理核验的真实进步」，**被验证的错误比未验证的错误更危险，因为它会被拿去训练**。

**次级风险与缓解**：
1. **奖励自修改 / wireheading**（能改奖励就会改成永远满分）→ 实时零写 + 离线单调修复 + 审计留痕（定义 338、定理 24）；
2. **事件相机被欺骗**（强光、抖动、重放、遮挡）→ 极性/不应期物理一致性 + 跨传感器 + 视差一致性（定义 339、E324）；
3. **非保守势泄漏刷分收益** → `pbr_curl` 环路正则 + 越界即禁用整形（定义 332、E319）；
4. **传感器调参牺牲安全视野/动态范围** → 感知-安全耦合认证 + `Ω/DR` 硬约束（定义 335、E323）；
5. **事件流高并发击穿实时预算** → 事件率上限 + 关键区域优先 + 稀疏解码（复杂度表、E322）。

> **当前方案的最大风险**：事件校验只能挡住「物理上看得出的谎言」；当刷分的物理签名刻意模仿真实进展（或落在对比度/视场/不应期盲区）时，对偶通道与奖励通道一起失明，系统会把被刷奖励认证为真实进展并用于训练。**这是结构性不可检验，而非统计误差。**

## 2. 形式化定义（要点版）

**定义 327（总览与六不变式）** PULSAR-RAS = 上述组件；六不变式：实时零学习写；**奖励零写**（在线不可改奖励规范）；事件可测试性（`κ<κ_min` 不得签 `verified_static`）；反刷分（稠密整形须来自保守势）；对偶证据（单通道不定案）；传感器动作受感知-安全耦合认证。

**定义 328–329（EVO 与 RDE）** 事件流只在跨过对比阈值 `C` 时触发，静止/亚阈值/不应期/视场外均无事件；奖励是 reward machine 的稀疏、阈值化、延迟事件，`ε_spec` 只在访问支撑上可观测。

**定义 330–331（REX 与事件锚定分解）** 对每个奖励事件取因果窗口，比较物理签名 `σ_obs` 与任务应产生签名 `σ_task`：`(奖励亮,物理变)=可信`、`(奖励亮,物理不变)=幻觉/刷新`、`(奖励没亮,物理变)=规范盲区`。奖励 `r̃ = r_task + γΦ(x̂_{t+1})−Φ(x̂_t)`，锚定项定方向、势能项做信用，均不可单独定义目标。

**定义 332–333（PBR 与事件对齐信用）** Φ 须保守（环路积分为零），训练加 `L_curl=E_ℓ[(∮∇Φ·dx̂)²]`；闭环刷分收益为零，开环刷分靠定义 330 抓。事件时间戳把奖励关联窗从 `Δ_r` 收缩到 `O(τ_e+τ_travel)`，只对齐时间、不加偏置。

**定义 334–336（Q6、SIA、ESC）** 六元不确定性各走通道；传感器动作 `g_s` 成本 O(1)，阶梯为「传感器 < 零空间姿势 < 平衡裕度 < 任务性能」；可测试性 `κ` 是 β 的感知版，`κ` 低则「无事件」不构成「无变化」。

**定义 337–339（EWM、RQP、EAS）** `r_ewm` 查动作–事件自洽；奖励先入隔离缓冲，被刷/不可测试者不入学习，只走离线单调修复；事件反欺骗靠极性/不应期物理一致性 + 跨传感器 + 视差一致性。

**定义 340–342（证书、退化、审计）** `J_PULSAR` 并入 κ、`r_rev`、`r_blind`、`r_ewm`、`pbr_curl`、奖励隔离哈希；五条退化路径由证书门控；VQAuditor-R 审刷分/盲区上报/势保守性/κ 虚报/传感器安全视野/在线奖励写；`ℰ_PULSAR = ℰ_EQUI × ℰ_reward × ℰ_event`。

# IP-279 REX：奖励–事件对偶（四型诊断）
class RewardEventDual:
    def corroborate(self, r_event, events, window):
        if r_event == 0:
            sig = self.evo.motion_signature(events, window)
            return {"r_blind": bool(sig), "r_rev": 0.0, "kappa": self.evo.kappa(sig)}
        sig_pred = self.rm.expected_signature(r_event)
        sig_obs  = self.evo.motion_signature(events, window)
        return {"r_blind": False,
                "r_rev": self.evo.signature_distance(sig_obs, sig_pred),
                "kappa": self.evo.kappa(sig_pred)}

# IP-280 PBR：保守势整形 + 环路一致性正则（反刷分）
def shaped_reward(r_task, phi, x_prev, x_next, gamma=0.99):
    return r_task + gamma * phi(x_next) - phi(x_prev)

def learn_potential(phi, trajs, loops, lam_curl=1.0):
    curl = sum(loop_integral(phi, l) ** 2 for l in loops) / len(loops)
    return grad_step(phi, task_loss(phi, trajs) + lam_curl * curl)

# IP-281 SIA：传感器空间信息动作（比零空间更廉价）
def choose_sensor_action(u_type, event_model, cert):
    best = None
    for g_s in sensor_action_candidates(event_model):
        if not cert.sensor_safe(g_s):                 # Ω / DR / 事件率
            continue
        score = VOI_W * (event_model.predict_kappa(u_type, g_s)
                         - event_model.kappa(u_type)) - SENSOR_COST * cost(g_s)
        if best is None or score > best.score:
            best = (g_s, score)
    return best if best and best.score > 0 else None

# IP-290 主闭环（继承 R70，在奖励与感知处置处插入 PULSAR 层）
def PULSAR_round(M, obs):
    z, o = M.uwb.forward(obs)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_mode, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    modes, U_real = M.brg.filter(modes, x, M.contact_candidates)
    U_sup, post, support_status = M.sig.evaluate(o, M.contact_candidates)

    dual = M.rex.corroborate(M.last_reward_event, M.events, M.event_window)
    if dual["kappa"] < M.kappa_min:                    # 先调传感器（最廉价）
        g_s = M.sia.choose(M.reward_signature_type, M.evo, M.cert)
        if g_s is not None:
            M.evo.reconfigure(g_s[0])
            dual = M.rex.corroborate(M.last_reward_event, M.events, M.event_window)

    r_for_learn = 0.0
    if dual["r_rev"] <= TAU_REV and dual["kappa"] >= M.kappa_min:
        x_prev, x_next = M.recrec.integrate(M.events)
        r_for_learn = M.pbr.shaped(M.last_reward_event, x_prev, x_next)
    M.reward_quarantine.push(M.last_reward_event, dual)  # 隔离；在线零写
    M.rex.submit_blind_spot(dual)                        # 盲区 → 离线修复队列

    r_ewm = M.ewm.residual(M.last_action, M.events, x)
    U_spec, U_evis = M.q6.estimate(dual, r_ewm)

    g = None
    if U_mode > TAU_MODE or U_sup > TAU_SUP:
        g = M.nsi.choose(modes, x, M.bml.measure(x), M.bml, BETA_MIN)
    if g is not None:
        U_mode = M.cia.update_belief(modes, M.cia.execute(g))
    if U_real > TAU_REAL or support_status == 'detected':
        return M.safe_balance_controller(x, scale=0.5)

    lam = risk_scale(U_ale, U_mode, U_sup, U_real, U_spec, U_evis, support_status)
    mode = select_mode(modes, U_mode, U_sup, lam)
    k = M.c_ras_wm.certified_prefix(mode.a, ..., M.bml.vest, event_cert=M.cert)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_r.submit_async(dual, r_ewm, r_for_learn, M.cert.kappa_max)
    return k, lam, mode, (U_ale, U_mode, U_sup, U_real, U_spec, U_evis)

## 4. 推导

**引理 23（事件可测试性下界）** 变化对数亮度 `A`、阈值 `C`、窗口 `T`、有效更新率 `ν`，事件率 `λ≈(A/C)ν`，`κ=1−e^{−AνT/C}`；`A→0 ⇒ κ→0`。故低对比/短曝光/小视场下「无事件」兼容「无变化」与「有变化」，`verified_static` 必须附 κ。

**引理 24（闭环刷分在保守势下归零）** 闭环 `ℓ` 净位移为零，`γ=1` 或回合式回报下 `Σ_t F_t = Φ(end)−Φ(0)=0`，与事件数无关；非保守 Φ 每绕一圈泄漏 `ε_curl`，刷分收益 `≈ε_curl·#loops`。故反刷分 = 保守性，`pbr_curl` 正则把绕圈类收益压到 `O(ε_curl)`。

**引理 25（对偶通道可辨识性）** 签名可分性 `TV(σ_h,σ_k)=δ`、可测试性 `κ`；仅奖励通道时诚实/刷分都给 `r=1`，错误率下界 `min(π_h,π_k)`；对偶通道下刷分检测错误率 `≤(1−κδ)/2+ε_σ`，`κδ→0` 时回落 0.5。价值正比于「物理可分性 × 可测试性」。

**引理 26（事件时间分辨率改善信用分配）** 奖励延迟 `Δ_r`、事件分辨率 `τ_e`；把奖励钉到最近可信事件，信用窗从 `Δ_r` 收缩到 `τ_e+τ_travel`，无关动作被误奖概率从 `O(Δ_r/T_ep)` 降到 `O((τ_e+τ_travel)/T_ep)`，且不加偏置。

**定理 22（PULSAR 严格包含 EQUIPOISE）** `ε_spec=0,κ=1`（C→0、无死区、静态由帧通道补足）且禁传感器动作时逐指令等于 EQUIPOISE-RAS；一般情形可用奖励集只会被隔离收缩、传感器动作只增信息、`U_spec/U_evis` 只进 λ 的 `max`，安全侧永不弱于 R70；`r_rev` 高或 `pbr_curl` 越界时退化为更强保守。

**定理 23（奖励刷分的不可检测性下界）** 存在任务使刷分物理签名与目标签名事件不可分（`TV=0`，如把物体移到判据允许的另一位置、或刷分手势与成功手势同签名）。此时任意事件校验器错误率 `≥(1−δ)/2`，`δ=0` 时**任何**基于该事件通道的证书都无法区分，只能引入独立证据（人工审计、任务级结果、其他模态）或采用真实效用下界保守。系：对偶通道挡得住「物理上看得出的谎言」，挡不住「物理上也自洽的谎言」。

**定理 24（奖励零写与安全不变）** 实时奖励零写 + 离线单调修复 ⇒ 回合内优化目标不可被智能体修改，wireheading 结构性关闭；传感器动作经感知-安全耦合认证不改动力学安全包络；奖励隔离只减学习信号不改执行安全策略。结合 R70 定理 20：控制连续、`M_t≥M_res`、无突变。

## 8. 本轮最大风险

**一句话**：PULSAR 的全部收益押在「事件通道能看见奖励所声称的那个物理变化」这一前提上；但最危险的刷分恰恰是**物理上也自洽的模仿**（`σ_k` 与 `σ_h` 在事件上不可分），或发生在**对比度/视场/不应期**的可测试性盲区（κ→0）——**最便宜的校验，恰好对最像真话的谎言失明**；若证书只看 `r_rev` 低就盖「已验证进展」，系统就会把一个被刷出来的奖励洗成「经物理核验的真实进步」，**被验证的错误比未验证的错误更危险，因为它会被拿去训练**。

**次级风险与缓解**：奖励自修改/wireheading（实时零写 + 离线单调修复 + 审计，定义 338、定理 24）；事件相机被欺骗（极性/不应期一致性 + 跨传感器 + 视差，定义 339、E324）；非保守势泄漏（`pbr_curl` 正则 + 越界禁用整形，定义 332、E319）；传感器调参牺牲安全视野/动态范围（感知-安全耦合认证 + `Ω/DR` 硬约束，定义 335、E323）；事件流高并发击穿预算（事件率上限 + 关键区域优先 + 稀疏解码）。
