# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；新灵感循环第 1 轮／累计第 60 轮；本轮灵感：「成本控制」×「长期记忆」）

> 第 59 轮把安全论证链一路下沉到电流环：BUQ 在线辨识电机结构性不确定性、ERTC 把嵌入式时序变成硬契约、EEIS 把概率安全界编译成阻抗证书、CLEP 让执行实测成为第 5 个对账模态、PCE+++ 用四重预算约束探—诺—演。但它同时默默假设了两件从未被审视的事：**(i) 证据是免费且无限的**——每次探针、共形校准、μ 分析、证书签发、审计日志，都被当作不消耗算力/能量/存储/机时/人力的「空气」，VOI 只算信息收益不算总拥有成本；**(ii) 证据是无记忆的**——每一轮都从零重新获取，上一次探针、上一台机器、上一个场地、上一个月留下的经验既不复用也不折旧。本轮两个灵感精准击中这个真空：**成本控制**把「证据」拉进经济学，**长期记忆**把「证据」拉进时间。本轮核心命题：**把证据从一次性消耗品，升级为「会折旧、可复用、需付费维护的资本资产」——用长期记忆摊薄获取成本，用成本控制约束记忆膨胀与陈旧风险，实现「证据资产化」（Evidence-as-Capital）**：不是问「还能不能更安全」，而是问「这份安全值多少钱、由谁摊、能保多久、过期怎么办」。

核心矛盾：
- **H32（证据不是免费的·成本不可约）**：PCE+++ 的 B_probe/B_ft/B_ux/B_exec 都是「资源余量」，不是「钱/能量/机时/人力」。真实部署里，一次高保真触探的边际成本可能远超它降低的失效期望损失；如果 VOI 不扣除总拥有成本 TCO，系统会为了 10⁻⁵ 的风险下降烧掉整块电池。**安全验证本身可能比被验证的任务更贵**。
- **H33（记忆既是资产也是负债·陈旧性）**：长期记忆能省掉重复获取，但旧校准、旧证书、旧 KG 子图在分布漂移下会**静默失效**。共形覆盖在 TV 漂移 ε_TV 下最多衰减 ε_TV：一个标称 1−α 的保底带，重用时真实覆盖率可能只剩 1−α−ε_TV。**复用省下的每一分钱，可能是从安全边际里扣的**。反过来，过度遗忘会丢掉用高昂代价换来的经验，让系统「越用越笨」。
- **H34（成本与安全耦合·不可分治）**：把成本控制当成「省钱模块」、把安全当成「独立门」，必然出现「安全门通过但账已经破产」或「为了降本悄悄下调 δ 预算」。正确做法是**字典序**：安全可行性是硬约束（不可购买、不可挪用），在可行域内再最小化 TCO。**安全预留金 R_safe 永远不许被经济学优化动一分**。

## 0. 直觉与动机

**灵感 1（成本控制 → 证据经济学 TCO）**
直觉：证据不是「越多越好」，而是「**边际风险下降 / 边际成本**」的生意。把每类证据动作（探针、再校准、再验证、模型微调、人审、记忆整合、跨本体迁移）都挂上完整成本账：获取成本 c_acq、存储成本 c_store·保留时长、检索成本 c_ret·使用次数、再验证成本 c_reval、人力成本 c_human、能量/机时 c_energy，以及「不验证而失败」的期望损失 c_fail·δ。**证据总拥有成本** TCO(π)=Σ 各项。于是 PCE++++ 的 VOI 从「VOI_meta − cost_exec」升级为「VOI_meta − TCO」，且增加一条**硬底线**：无论多贵，安全关键证据（ERC 契约、共形保底带、稳定性证书、不可逆接触人审）都有不可削减的最低配置。

**灵感 2（长期记忆 → 证据资产账本 EAL）**
直觉：把证据当**资产**记账，而不是当**当轮临时变量**。每份证据是一个资产 a，带：覆盖域 C_a（它能支撑哪些状态×时间）、强度 s_a（覆盖水平/证书等级）、来源链 provenance（固件/模型/传感器/场地/日期）、签发时戳、**有效性谓词 V_a(x,t)**、**成本模型**、**保留等级**（临时/运营/审计/安全底线）。记忆不是「一个向量库」，而是**一本可审计的账本**：哪些资产在支撑当前的承诺、它们多老、还能保多久、续期要多少钱。跨会话/跨本体复用时，先查账本、再验有效性，而不是从零再探一遍。

**灵感 3（合流 → 折旧-失效与成本感知复用 CAER）**
直觉：资产会折旧。折旧速率由版本变更、世界漂移、环境偏移、硬件老化、模型换代共同决定——用**风险率 λ_a(t)** 与生存函数 S_a(t)=exp(−∫λ) 刻画；硬失效（固件/模型版本不匹配）立即作废。复用决策因此是一个**带风险的替换问题**：复用（便宜但风险随年龄涨）/ 再验证（中等成本，用少量标定样本重置风险）/ 再获取（最贵但最干净）/ 回退（放弃该检查点）。在风险可行域内最小化长期成本率，其最优解是**年龄阈值策略**（超过 τ* 或上下文距离超过 d* 就再验证）——这正是更新理论的经典结论，可形式化证明。

**灵感 4（记忆管理 → 整合与安全遗忘 MCF）**
直觉：长期记忆必须有预算（字节、检索延迟、整合算力），不能无限膨胀。整合把大量**情节记忆**压缩成**语义/程序记忆**（相似接触聚类→提炼成一条更宽覆盖的资产），遗忘删掉低价值密度资产。但遗忘是**危险操作**：删错一条证据可能制造「静默覆盖洞」。因此规定：① 安全底线与审计类资产在法定期限内**禁止删除**；② 删除前必须验证剩余资产仍覆盖运营包络，或该区域已被标记为「仅回退」；③ 整合产物若覆盖未被留出验证集认证，则视为**新资产**，必须重新验证；④ 所有删除留**墓碑（tombstone）**，保留来源哈希以便追溯与恢复。

**灵感 5（跨会话/跨本体 → 摊薄与共因风险 CSET）**
直觉：一次昂贵的电机参数辨识/共形校准，若能在同型号 N 台机器人间共享，单机成本降为约 1/N——这是长期记忆最大的经济价值。但共享引入**共因故障**：若这条资产本身错了，整个机队一起错。因此迁移必须过三道关：硬件/固件兼容性、上下文距离 d_ctx ≤ ε_transfer、以及**握手验证**（少量样本快速核验）。机队风险界必须显式加一项共因项 δ_common，并要求用**多样性验证**（不同来源/随机抽检）压制相关性，而不是简单除以 N。

**灵感 6（反照研究本身 → 架构成本审计）**
直觉：59 轮、151 个 IP、7 个层级，本身也需要「成本控制」。每个新增能力都应回答：**它相对已有能力带来的边际安全增量，是否配得上它的实现/验证/维护成本？** 引入「架构成本审计」：按「边际风险下降 / 边际复杂度」排序，识别并合并/降级「白住不付租金」的组件，防止研究本身陷入「越堆越安全」的幻觉。这不是删功能，而是让每一层都能出示自己的**成本-收益凭证**。

## 1. 形式化定义（增量：定义 153–160）

**定义 153（证据资产 Evidence Asset, EA）** 一个证据资产是一个七元组
```
a = (id, type, claim, C_a, s_a, P_a, t_a; V_a, cost_a, ret_a)
```
- `type ∈ {CAL(校准/共形集), CERT(证书), EPI(情节经验), SEM(语义/程序记忆), MODEL(微调权重/KG子图), TRUST(授权/同意/信任), AUDIT(审计记录)}`；
- `claim`：该资产所支撑的命题（如「区域 r 上后验 ECE ≤ ε」「阻抗证书在工况 w 下鲁棒稳定」）；
- `C_a ⊆ 𝒳×𝒯`：覆盖域（状态×时间）；
- `s_a`：强度（共形覆盖水平 1−α、证书等级、样本量）；
- `P_a`：来源链（固件/模型/传感器标定/场地/签发者/父资产）；
- `t_a`：签发时间；
- `V_a(x,t)`：有效性谓词，`V_a = context_compatible(x,C_a) ∧ version_match(P_a) ∧ ¬invalidated_a(t) ∧ age_a(t) ≤ horizon_a`；
- `cost_a = (c_acq, c_store, c_ret, c_reval, c_energy, c_human)`；
- `ret_a ∈ {EPHEMERAL, OPERATIONAL, AUDIT, SAFETY_FLOOR}`：保留等级，后两类受硬保留约束。
复用残留风险：`ρ_reuse(a,x,τ) = ρ_base(a,x) + Δ_drift(a,x,τ)`，其中 `ρ_base` 为签发时残余违约概率，`Δ_drift` 由定义 155 的漂移界给出且对 τ 单调不减。

**定义 154（证据资产账本 EAL）** EAL = `(L, idx, policy)`，L 为仅追加（append-only）的资产事件日志，idx 为按 `(type, coverage, provenance, version)` 建的多维索引，policy 为保留/删除/整合策略。资产生命周期状态机：
```
ISSUED → ACTIVE → {STALE(漂移超阈), QUARANTINED(冲突/证伪), REVALIDATING}
      → {RETIRED(被新资产取代), TOMBSTONED(安全删除)}   （AUDIT/SAFETY_FLOOR 禁止 TOMBSTONED）
```
不变量：**(I1)** 任一被用于承诺的资产必须 `V_a=true` 且状态 ∈ {ACTIVE}；**(I2)** 任一删除操作留下墓碑，墓碑保留 `id, P_a, 原因, 时间` 且可恢复；**(I3)** 不存在「静默覆盖洞」：运营包络内每个未被 ACTIVE 资产覆盖的区域，必须被显式标记为 `fallback-only`；**(I4)** 版本变更使相关资产原子性转入 STALE。

**定义 155（折旧-失效模型 ADI）** 风险率分解
```
λ_a(t) = λ_ver(t) + λ_drift(t) + λ_env(t) + λ_hw(t) + λ_model(t)
```
其中 λ_ver 为版本切换的阶跃（硬失效），λ_drift 由在线变点/漂移估计器给出，λ_env 由上下文距离给出，λ_hw 由执行状态 ξ_exec 漂移给出，λ_model 由策略/模型换代给出。生存函数 `S_a(t)=exp(−∫_0^t λ_a(s)ds)`，半衰期 `T_½=ln2/λ`（常风险近似）。**漂移-覆盖衰减引理**：若签发时校准分布 P 与当前部署分布 Q 满足 `TV(P,Q) ≤ ε_TV(τ)`，则强度为 1−α 的共形资产在 Q 下覆盖率 ≥ `1−α−ε_TV(τ)`（任取测试集，覆盖事件概率之差不超过两分布 TV 距离）。于是资产在风险预算 `δ_alloc` 下的**再验证触发时点**为
```
τ* = inf{ τ : ρ_base + ε_TV(τ) > δ_alloc }
```
`ε_TV(τ)` 由漂移估计器给出，并附带置信上界（高概率成立），保证触发器「不早于安全失效、不晚于必要」。

**定义 156（成本感知证据复用决策 CAER）** 在检查点 cp、风险预算 δ_f^req、资产候选集 A(cp) 下，为每个资产选一动作 `d_a ∈ {reuse, revalidate, reacquire, fallback}`，代价与风险：
```
cost(reuse)=c_ret(a)                     risk=ρ_reuse(a,cp,age)          # 便宜、风险随龄涨
cost(reval)=c_reval(a)+c_ret(a)          risk=ρ_base(a,cp)+ε_res(a,N_reval)  # 中价、重置风险
cost(reacq)=c_acq(a)                     risk=ρ_base(fresh)             # 最贵、最干净
cost(fallback)=c_fb(cp)                  risk=δ_fallback(≤δ_f^req)      # 放弃机会，保守
```
决策是**字典序最优化**：
```
(1) 可行性：Σ_{a∈A(cp)} risk(d_a) ≤ δ_f^req  ∧  c_total ≤ B  ∧  R_safe 未被挪用
(2) 则最小化 c_total = Σ cost(d_a) + c_fail·E[failure]
(3) 平局最大化安全裕度
若无可行解 ⇒ 返回 fallback（绝不「先复用再说」）。
```
**阈值最优性（更新理论）**：若风险率 λ 随龄单增、成本平稳、再验证将资产年龄重置为 0，则长期平均成本率 `(c_reval + M·c_reuse)/E[lifetime]` 的最优解是年龄阈值策略：`reuse 当 age ≤ T*，revalidate 当 age > T*`。CAER 的 τ*（定义 155）是该策略的安全可行版本。

**定义 157（记忆整合与安全遗忘 MCF）** 整合算子 `Cons: 2^A → 2^A` 把一组情节资产映射为一条（或少数）语义资产，满足：① 覆盖 `C_cons ⊇ ∪ C_a`（不缩覆盖）；② 强度由**留出验证集**重新认证，未认证则视为新资产；③ 成本严格下降 `Σ(c_store+c_ret) > c_store(cons)+c_ret(cons)`。遗忘是带约束的**预算最大覆盖**：
```
maximize  Σ_a v_a(τ)·x_a          # v_a = 保留资产带来的期望风险下降
s.t.      Σ_a (c_store(a)+c_ret(a))·x_a ≤ B_mem
          x_a=1 对 ret_a∈{AUDIT,SAFETY_FLOOR} 且未过法定期限      # 硬保留
          coverage(∪_{x_a=1} a) ⊇ envelope  ∨  未覆盖区标记 fallback-only   # 无静默洞
          x_a=0 对 consent 已撤销/隐私过期                          # 合规删除
```
该问题是带硬约束的预算最大覆盖，一般 NP-hard；贪心按价值密度 `v_a/(c_store+c_ret)` 选择，达到 `1−1/e` 近似，且硬约束优先。

**定义 158（跨会话/跨本体迁移 CSET）** 迁移谓词
```
Transfer(a: s→t) = hw_fw_compatible(s,t) ∧ d_ctx(C_s,C_t) ≤ ε_transfer
                   ∧ Handshake(a,t,N_hs)=pass
```
握手验证用少量样本 `N_hs` 对目标本体快速核验，成本 `c_hs ≈ (N_hs/N_acq)·c_acq ≪ c_acq`。机队摊薄：单机获取成本近似 `c_acq/N + c_hs`。**共因风险界**：若 N 台共享同一资产，机队失效概率 `P_fleet ≤ N·δ_ind + δ_common`，其中 δ_ind 为单机独立残余风险，δ_common 为资产本身的系统误差；要求 `δ_common ≤ δ_common^max`，否则强制**多样性配置**（≥2 条独立来源资产交叉验证）或禁止共享。

**定义 159（证据总拥有成本 ETCO 与安全预留金）** 
```
TCO(π) = c_acq + c_store·H + c_ret·U + c_reval·R + c_energy + c_human + c_fail·E[failure]
```
扩展预算 `B = (B_probe, B_ft, B_ux, B_exec, B_mem)`，其中 `B_mem=(storage_bytes, retrieval_latency, consolidation_compute)`，并引入**不可挪用安全预留金** `R_safe ⊆ B`（ERC 契约、共形保底带、稳定性证书、不可逆接触人审的固定成本）。预算约束变为 `可花费预算 = B − R_safe`。**成本感知 VOI**：`voi_tco(π) = VOI_meta_pessimistic(π) − TCO(π) − λ_cost·占用(π)`，且**先按 δ 可行性剪枝，再按 voi_tco 排序**。**架构成本审计**：对每个组件/IP 计算 `rent_i = Δrisk_reduction_i / Δcost_complexity_i`，`rent_i < θ_rent` 且存在等价替代 ⇒ 标记候选合并/降级（不自动删除，进入人工评审队列）。

**定义 160（PCE++++ / PCEM 记忆增强·成本受控闭环）** 算子
```
PCEM(M, task, B, consent):
  ① Retrieve: A(cp) ← EAL.query(region=cp, envelope=M)
  ② Depreciate: 对每个 a 计算 age、ε_TV(age)、ρ_reuse、V_a
  ③ Decide:    {d_a} ← CAER(A(cp), δ_f^req, B, R_safe)
               if 无可行解: return fallback/negotiate_or_stop
  ④ Act:       执行 revalidate/reacquire 的最小集合（握手/共形样本/探针）
  ⑤ Fuse:      M,fused,D⁺ ← XMC+(M, cp, 证据, EV-exec)   # 陈旧资产按 ρ_mem 降权
  ⑥ Issue:     产生新证据 → EAL.append(asset, provenance, cost, retention)
  ⑦ Consolidate/Forget: 若超 B_mem：MCF(A, B_mem, envelope, R_safe)
  ⑧ Account:   TCO 记账、更新 B、把 R_safe 与可花费预算分离
  ⑨ Share:     若 CSET 通过：机队摊薄/握手验证/共因风险检查
  ⑩ Return:    (M, fused, D⁺, decision_log, ledger_delta, cost_report)
```

## 2. 关键算法伪代码

### IP-152 EAL（证据资产账本）

```python
@dataclass
class EvidenceAsset:
    id: str
    type: str                      # CAL/CERT/EPI/SEM/MODEL/TRUST/AUDIT
    claim: str
    coverage: CoverageRegion       # C_a ⊆ X × T
    strength: float                # 1-α / cert level / sample-based
    provenance: ProvenanceChain    # firmware/model/sensor/site/issuer/parent
    issue_time: float
    retention: str                 # EPHEMERAL/OPERATIONAL/AUDIT/SAFETY_FLOOR
    cost: CostModel                # acq/store/ret/energy/human
    validity: ValidityModel        # horizon, version set, context set
    state: str = 'ACTIVE'

class EvidenceAssetLedger:
    def append(self, asset, *, parent=None, reason='issue'):
        self._check_provenance(asset)
        self.events.append(Event('append', asset.id, reason, parent, now()))
        self.idx.insert(asset)
        return asset.id

    def query(self, region, envelope):
        # 返回可能覆盖该区域的候选（后续由 CAER 精算风险）
        return [a for a in self.idx.candidates(region)
                if a.state in ('ACTIVE', 'STALE', 'QUARANTINED')]

    def invalidate_on_version(self, changed):
        # I4: 版本变更原子性置 STALE；SAFETY_FLOOR 需触发再验证而非删除
        for a in self.idx.touch(changed):
            self._transition(a, 'STALE', reason=f'version:{changed}')

    def tombstone(self, aid, reason):
        a = self.get(aid)
        assert a.retention not in ('AUDIT', 'SAFETY_FLOOR') or self._mandate_expired(a)
        self.events.append(Event('tombstone', aid, reason, a.provenance_hash, now()))

        return envelope - union(a.coverage for a in self.active()) - self.fallback_only
```

### IP-154 CAER（成本感知复用）

```python
class CostAwareEvidenceReuse:
    def __init__(self, ledger, depreciation, tco):
        self.eal, self.adi, self.tco = ledger, depreciation, tco

    def decide(self, cp, delta_f_req, budget, reserve):
        assets = self.eal.query(cp.region, cp.envelope)
        spendable = budget.remaining() - reserve.irreducible_cost(cp, assets)
        if spendable < 0:
            return self._fallback(cp, 'reserve_violation')

        options = []
        for a in assets:
            tau = now() - a.issue_time
            if not a.V(cp.x, now()):
                options.append(Option(a, 'reacquire', self._cost(a, 'reacquire'),
                                      self.adi.fresh_risk(a)))
                continue
            # 三个可行动作的 (cost, risk)
            options.append(Option(a, 'reuse', self._cost(a, 'reuse'),
                                  self.adi.residual_risk(a, cp.x, tau)))
            if tau > self.adi.revalidation_trigger(a, delta_f_req / max(len(assets),1)):
                options.append(Option(a, 'revalidate', self._cost(a, 'revalidate'),
                                      self.adi.reval_risk(a)))
            options.append(Option(a, 'reacquire', self._cost(a, 'reacquire'),
                                  self.adi.fresh_risk(a)))

        # 字典序：先可行性（Σrisk ≤ δ），再最小 TCO（贪心按 Δrisk/Δcost 边际）
        best = self._lexicographic_select(options, delta_f_req, spendable)
        if best is None:
            return self._fallback(cp, 'no_feasible_evidence')
        return DecisionSet(best, spendable=spendable)

    def _lexicographic_select(self, options, delta, spendable):
        feasible = [o for o in options if o.risk <= delta]
        if not feasible: return None
        # 每个资产先取最便宜风险可接受动作；若总风险超预算，按边际性价比升级
        chosen = self._greedy_min_cost_with_risk_budget(feasible, delta)
        if sum(o.cost for o in chosen) > spendable: return None
        return chosen
```

```python
class MemoryConsolidator:
    def __init__(self, ledger, validator):
        self.eal, self.validator = ledger, validator

    def consolidate(self, cluster):
        # 仅当留出验证集认证明整合资产覆盖不缩水、风险不升
        cand = distill(cluster)
        ok, strength = self.validator.certify(cand, heldout=cluster.heldout)
        if not ok:
            return [self.eal.append(cand, parent=[a.id for a in cluster])]  # 视为新资产
        parent = [a.id for a in cluster]
        for a in cluster:
            if a.retention in ('AUDIT', 'SAFETY_FLOOR'):
                continue        # 硬保留：整合不删除原件
            self.eal.tombstone(a.id, reason='consolidated')
        return [self.eal.append(cand.with_strength(strength), parent=parent)]

    def enforce_budget(self, envelope, B_mem):
        while self.eal.footprint() > B_mem:
            # 硬约束优先：先剔除可删的、非底线的、价值密度最低者
            removable = [a for a in self.eal.active()
                         if a.retention in ('EPHEMERAL', 'OPERATIONAL')
                         and self.eal.mandate_ok(a)]
            if not removable: break
            victim = min(removable, key=lambda a: self._value_density(a))
            self.eal.tombstone(victim.id, reason='budget_gc')
            # 删除后立即检查：不许出现静默覆盖洞
            holes = self.eal.coverage_holes(envelope)
            if holes:
                self.eal.mark_fallback_only(holes)   # 补偿：降级为仅保守回退
        self.eal.assert_no_silent_hole(envelope)

    def _value_density(self, a):
        return self._expected_risk_reduction(a) / (a.cost.store + a.cost.ret + 1e-9)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| EAL | 查询 O(log\|A\|+k)（多维索引）；追加 O(log\|A\|) | O(\|A\|) 事件+索引 | 来源链、版本原子失效、无静默洞、删除留墓碑 |
| ADI | O(1)/资产（常风险）/ O(log H) 触发（二分） | O(1)/资产 | 漂移界诚实 ⇒ 覆盖率 ≥1−α−ε_TV；触发 τ* 安全且不早于必要 |
| CAER | O(\|A(cp)\|·4) 选项 + 贪心 O(\|A\|log\|A\|) | O(\|A(cp)\|) | 字典序可行性；阈值策略在单增风险率下最优 |
| MCF | 贪心 O(\|A\|log\|A\|) | O(\|A\|) | 覆盖不缩水（或标记 fallback-only）；硬保留；1−1/e 近似 |
| CSET | O(N_hs)/迁移 | O(1)/资产 | 兼容+握手+共因界；多样性配置 |
| ETCO | O(1)/记账；审计 O(\|I\|log\|I\|) | O(\|I\|) | TCO 诚实上界；R_safe 不可挪用 |
| PCEM | O(\|CP\|·(\|A\|log\|A\| + N_hs + gate)) | 复用 EAL/第 59 轮结构 | 终止；每检查点安全可行或回退 |

**正确性定理（Cost-Bounded Memory-Grounded Soundness, CBMGS）**
设第 59 轮假设 A22–A55 成立，并新增：
**(A56)** EAL 诚实：每个资产的 claim 在签发时落在其认证覆盖内，provenance 不可篡改，版本失效原子传播。
**(A57)** 漂移界诚实：`ε_TV(τ)` 是高置信上界，故 `ρ_reuse ≥ 真实残留风险`。
**(A58)** 折旧单调：`Δ_drift(a,x,τ)` 对 τ 与上下文距离单调不减；再验证将风险重置到 ≤ 签发水平。
**(A59)** CAER 字典序：先检查风险可行性（含 R_safe 与 spendable），后优化 TCO；无可行解必回退，绝不静默复用。
**(A60)** 整合/遗忘健全：整合产物经留出验证认证，覆盖不缩水；删除前要么剩余覆盖仍覆盖运营包络，要么显式标记 fallback-only；AUDIT/SAFETY_FLOOR 在法定期限内不删。
**(A61)** 迁移健全：兼容性 + 上下文距离 + 握手验证通过；共因风险 `δ_common ≤ δ_common^max` 或强制多样性。
**(A62)** 合规：consent 撤销/隐私过期即删除，且删除有墓碑、可追溯。

则：
1. **记忆接地的安全健全性**：部署安全界在第 59 轮基础上增加陈旧项
   `P_safe ≥ 1 − Σ_cp (…第59轮各项… + δ_mem·1[复用陈旧] + δ_consol·1[整合] + δ_transfer·1[跨本体] + δ_common·1[共因])`，
   其中复用项的 `δ_mem ≤ ρ_base + ε_TV(τ)` 由 A57/A58 保证；再验证/再获取项在风险预算内被显式分配。
2. **无静默覆盖洞**：任意时刻，运营包络内每个区域要么被 ACTIVE 资产按 `≤δ_f^req` 覆盖，要么被显式标记 fallback-only；不存在「以为有证据、实则无证据」的区域（A60 + I3）。
3. **成本受控**：`TCO(π) ≤ B − R_safe`，且 `R_safe` 在所有决策中不被挪用；预算耗尽只能导向更保守（回退/降档/停），不能导向「降标准以省钱」。
4. **阈值最优性**：在单增风险率、平稳成本下，CAER 的年龄阈值策略最小化长期平均成本率，且其阈值不晚于安全失效点 τ*（A58）。
5. **摊薄正确性**：机队共享使单机获取成本约 `c_acq/N + c_hs`，但风险界必须计入 `δ_common`；当多样性不足时，共享被禁止（A61）。
6. **整合不增风险**：`Cons` 保持/扩大覆盖，强度经留出集认证；未认证产物按新资产处理，禁止「压缩即降风险」。
7. **终止性**：每次再验证/再获取消耗有限预算，fallback 直接终止；PCEM 在 `k_evidence + k_cons` 内终止于 {承诺, 回退, 降档, 协商, 安全停}。

**关键**：长期记忆把「反复为同一件事付钱」变成「一次获取、多次摊销」，但**摊销的每一期都要交『陈旧风险』的利息**；成本控制负责把这笔利息算清楚、并在违约前强制再验证或降级。安全预留金是这条经济链的**不可抵押资产**。

```python
@dataclass
class CostModel:
    acq: float; store: float; ret: float; reval: float
    energy: float = 0.0; human: float = 0.0

@dataclass
class ValidityModel:
    horizon: float
    versions: set                 # {firmware, model, sensor_calib, kg_version}
    context: ContextRegion

@dataclass
class EvidenceAsset:
    id: str
    type: str                     # CAL/CERT/EPI/SEM/MODEL/TRUST/AUDIT
    claim: str
    coverage: CoverageRegion
    strength: float
    provenance: ProvenanceChain
    issue_time: float
    retention: str
    cost: CostModel
    validity: ValidityModel
    state: str = 'ACTIVE'

    def V(self, x, t):
        return (self.coverage.contains(x)
                and self.validity.versions.issubset(current_versions())
                and self.state not in ('RETIRED', 'TOMBSTONED')
                and (t - self.issue_time) <= self.validity.horizon)

class EvidenceAssetLedger:
    def __init__(self):
        self.events = []                 # append-only
        self.idx = MultiIndex(['type', 'coverage', 'version', 'retention'])
        self.fallback_only = RegionSet()
        self.active_ids = set()

    def append(self, asset, parent=None, reason='issue'):
        assert verify_provenance(asset.provenance)
        asset.state = 'ACTIVE'
        self.events.append(Event('append', asset.id, reason, parent, now()))
        self.idx.insert(asset); self.active_ids.add(asset.id)
        return asset.id

    def query(self, region, envelope):
        return [a for a in self.idx.candidates(region)
                if a.state in ('ACTIVE', 'STALE', 'QUARANTINED')]

    def invalidate_on_version(self, changed):
        for a in self.idx.touch(changed):
            self._transition(a, 'STALE', f'version:{changed}')

    def tombstone(self, aid, reason):
        a = self.get(aid)
        if a.retention in ('AUDIT', 'SAFETY_FLOOR') and not mandate_expired(a):
            raise RetentionViolation(aid)
        self.events.append(Event('tombstone', aid, reason, a.provenance_hash, now()))
        self._transition(a, 'TOMBSTONED'); self.active_ids.discard(aid)

    def coverage_holes(self, envelope):
        covered = union(a.coverage for a in self.active())
        return envelope - covered - self.fallback_only

    def assert_no_silent_hole(self, envelope):
        holes = self.coverage_holes(envelope)
        if holes: raise CoverageHoleError(holes)

    def mark_fallback_only(self, holes, reason='deletion_compensation'):
        self.fallback_only |= holes
        self.events.append(Event('fallback_only', None, reason, None, now()))

    def footprint(self):
        return sum(a.cost.store for a in self.active())
```

### IP-153 ADI（折旧-失效模型）

```python
class AssetDepreciation:
    def __init__(self, drift_estimator, version_registry, exec_state, model_registry):
        self.drift, self.versions = drift_estimator, version_registry
        self.exec, self.models = exec_state, model_registry

    def hazard(self, a, t):
        return (self._ver_hazard(a) + self._drift_hazard(a, t)
                + self._env_hazard(a) + self._hw_hazard(a) + self._model_hazard(a))

    def survival(self, a, tau):
        return math.exp(-self._integrated_hazard(a, tau))

    def tv_drift_bound(self, a, tau, conf=0.95):
        # 在线漂移估计器返回 TV 距离的高置信上界（含估计误差）
        return self.drift.tv_upper(a.coverage, age=tau, conf=conf)

    def residual_risk(self, a, x, tau):
        return a.strength_to_risk(x) + self.tv_drift_bound(a, tau)

    def revalidation_trigger(self, a, delta_alloc):
        # 单调性保证二分有效：ρ_base + ε_TV(τ) 对 τ 不减
        lo, hi = 0.0, a.validity.horizon
        for _ in range(40):
            mid = 0.5 * (lo + hi)
            if a.strength_to_risk(None) + self.tv_drift_bound(a, mid) > delta_alloc:
                hi = mid
            else:
                lo = mid
        return hi
```

### IP-154 CAER（成本感知证据复用）

```python
@dataclass
class Option:
    asset: EvidenceAsset
    kind: str            # reuse/revalidate/reacquire/fallback
    cost: float
    risk: float

class CostAwareEvidenceReuse:
    def decide(self, cp, delta_f_req, budget, reserve):
        assets = self.eal.query(cp.region, cp.envelope)
        spendable = budget.remaining() - reserve.irreducible_cost(cp, assets)
        if spendable < 0:
            return None                       # 安全预留金优先，直接回退

        options = []
        n = max(len(assets), 1)
        for a in assets:
            tau = now() - a.issue_time
            if not a.V(cp.x, now()):
                options.append(Option(a, 'reacquire', cost(a, 'reacquire'), risk_fresh(a)))
                continue
            options.append(Option(a, 'reuse', cost(a, 'reuse'),
                                  self.adi.residual_risk(a, cp.x, tau)))
            if tau > self.adi.revalidation_trigger(a, delta_f_req / n):
                options.append(Option(a, 'revalidate', cost(a, 'revalidate'),
                                      self.adi.reval_risk(a)))
            options.append(Option(a, 'reacquire', cost(a, 'reacquire'), risk_fresh(a)))

        chosen = self._lexicographic_select(options, delta_f_req, spendable)
        if chosen is None:
            return None
        return DecisionSet(chosen, spendable)

    def _lexicographic_select(self, options, delta, spendable):
        # 步骤1：每个资产选满足其分摊风险的最小成本动作
        best_by_asset = {}
        for o in options:
            cur = best_by_asset.get(o.asset.id)
            if cur is None or (o.risk <= cur.risk and o.cost < cur.cost):
                best_by_asset[o.asset.id] = o
        chosen = list(best_by_asset.values())

        # 步骤2：若总风险超预算，按边际性价比 Δrisk/Δcost 升级动作
        while sum(o.risk for o in chosen) > delta:
            upgrades = []
            for o in chosen:
                for alt in options:
                    if (alt.asset.id == o.asset.id and alt.risk < o.risk
                            and alt.cost > o.cost):
                        upgrades.append(((o.risk - alt.risk) / (alt.cost - o.cost), o, alt))
            if not upgrades:
                return None
            _, old, new = max(upgrades, key=lambda u: u[0])
            chosen[chosen.index(old)] = new

        if sum(o.cost for o in chosen) > spendable:
            return None
        return chosen
```

### IP-155 MCF（记忆整合与安全遗忘）

```python
class MemoryConsolidator:
    def __init__(self, ledger, validator):
        self.eal, self.validator = ledger, validator

    def consolidate(self, cluster):
        cand = distill(cluster)                       # 情节→语义/程序
        ok, strength = self.validator.certify(cand, heldout=cluster.heldout)
        if not ok:
            # 未认证 ⇒ 视为新资产，必须重新验证，禁止「压缩即降风险」
            return [self.eal.append(cand, parent=[a.id for a in cluster],
                                    reason='unverified_consolidation')]
        for a in cluster:
            if a.retention in ('AUDIT', 'SAFETY_FLOOR'):
                continue                              # 原件硬保留
            self.eal.tombstone(a.id, reason='consolidated')
        return [self.eal.append(cand.with_strength(strength),
                                parent=[a.id for a in cluster], reason='consolidated')]

    def enforce_budget(self, envelope, B_mem):
        while self.eal.footprint() > B_mem:
            removable = [a for a in self.eal.active()
                         if a.retention in ('EPHEMERAL', 'OPERATIONAL')
                         and self.eal.mandate_ok(a)]
            if not removable:
                break                                  # 只剩硬保留，宁超预算也不违规
            victim = min(removable, key=self._value_density)
            self.eal.tombstone(victim.id, reason='budget_gc')
            holes = self.eal.coverage_holes(envelope)
            if holes:
                self.eal.mark_fallback_only(holes)     # 补偿：显式降级为仅回退
        self.eal.assert_no_silent_hole(envelope)

    def _value_density(self, a):
        # 价值密度 = 期望风险下降 / 单位存储+检索成本
        return self._expected_risk_reduction(a) / (a.cost.store + a.cost.ret + 1e-9)
```

```python
class SafetyReserve:
    def __init__(self, items):
        self.items = items            # 固定成本项，不可压缩
    def irreducible_cost(self, cp, assets):
        need = 0.0
        if cp.irreversible: need += self.items['human_audit']
        need += self.items['conformal_floor'] + self.items['erc_contract']
        if any(a.type == 'CERT' for a in assets): need += self.items['cert_reval_floor']
        return need

class EvidenceTCO:
    def tco(self, plan, expected_failure_prob):
        return (plan.c_acq + plan.c_store * plan.H + plan.c_ret * plan.U
                + plan.c_reval * plan.R + plan.c_energy + plan.c_human
                + self.c_fail * expected_failure_prob)

    def cost_aware_voi(self, probe, M, fused):
        return voi_meta_pessimistic(probe, M, fused) - self.tco(probe, probe.delta_f)

    def architecture_audit(self, components):
        # 边际风险下降 / 边际复杂度；低 rent 进入人工评审，不自动删除
        return sorted(((c.name, c.delta_risk_reduction / (c.delta_complexity + 1e-9))
                       for c in components), key=lambda kv: kv[1])
```

```python
def probe_commit_evolve_memory(M, task, B, reserve, consent):

def xmodal_fuse_mem(M, region, decision, rho_mem):

    for d in decision.reused:

                                          d.asset.as_likelihood(), w=w)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| EAL | 查询 O(log\|A\|+k)；追加 O(log\|A\|) | O(\|A\|) 事件+索引 | 来源链不可篡改、版本原子失效、无静默洞、删除留墓碑 |
| ADI | O(1)/资产（常风险）；O(log H) 触发（二分） | O(1)/资产 | 漂移界诚实 ⇒ 覆盖率 ≥1−α−ε_TV；τ* 安全且不早于必要 |
| CAER | O(\|A(cp)\|·4)+贪心 O(\|A\|log\|A\|) | O(\|A(cp)\|) | 字典序可行性；单增风险率下阈值策略最优 |
| MCF | 贪心 O(\|A\|log\|A\|) | O(\|A\|) | 覆盖不缩水或标记 fallback-only；硬保留；1−1/e 近似 |
| CSET | O(N_hs)/迁移 | O(1)/资产 | 兼容+握手+共因界；多样性兜底 |
| ETCO | O(1)/记账；审计 O(\|I\|log\|I\|) | O(\|I\|) | TCO 诚实上界；R_safe 不可挪用 |
| PCEM | O(\|CP\|·(\|A\|log\|A\|+N_hs+gate)) | 复用第 59 轮结构 | 终止；每检查点安全可行或回退 |
| J_mem | O(1)/接触追加 | O(接触数) | 账本/证书链版本单增、TCO 可对账、覆盖洞审计可复查 |

**正确性定理（Cost-Bounded Memory-Grounded Soundness, CBMGS）**
设第 59 轮假设 A22–A55 成立，并新增 A56–A62（EAL 诚实、漂移界诚实、折旧单调、CAER 字典序、整合/遗忘健全、迁移健全、合规删除）。则：

1. **记忆接地的安全健全性**：
```
P_safe ≥ 1 − Σ_cp ( δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                    + δ_ft·1[回滚窗口] + δ_kg·1[检索失败] + δ_ux·1[μ_mis>θ_mis]
                    + δ_exec·1[ξ_exec漂移] + δ_ξ_ood·1[执行OOD] + δ_ertc·1[契约违例] + δ_eeis·1[μ分析漏报]
                    + δ_mem·1[复用陈旧] + δ_consol·1[整合] + δ_transfer·1[跨本体] + δ_common·1[共因] )
         − P(𝒢结构性错误未检出) − P(护盾回退失败) − P(τ_int超时∧安全停失效) − P(固件回滚失败)
```
其中 `δ_mem ≤ ρ_base+ε_TV(τ)`（A57/A58），再验证/再获取项被显式分配进 δ 预算。
2. **无静默覆盖洞**：任意时刻运营包络内每个区域，要么被 ACTIVE 资产按 ≤δ_f^req 覆盖，要么显式标记 fallback-only（A60 + EAL 不变量 I3）。
3. **成本受控且安全预留不可挪用**：`TCO(π) ≤ B − R_safe`；预算耗尽只能导向更保守（回退/降档/停），不能导向「降低安全标准省钱」（A59 + A62）。
4. **阈值最优性**：单增风险率、平稳成本下，CAER 年龄阈值策略最小化长期平均成本率，且阈值不晚于安全失效点 τ*（更新理论 + A58）。
5. **整合不增风险**：`Cons` 覆盖不缩水、强度经留出认证；未认证产物按新资产处理，禁止「压缩即降风险」。
6. **摊薄与共因**：机队共享使单机获取成本约 `c_acq/N+c_hs`，但风险界计入 `δ_common`；多样性不足则禁止共享（A61）。
7. **终止性**：再验证/再获取消耗有限预算，fallback 直接终止；PCEM 于 `k_evidence+k_cons` 内终止于 {承诺, 回退, 降档, 协商, 安全停}。
