# 第 1 轮（本灵感循环第 1 轮；承接第 5 轮 CADVS-v5 基线；本轮灵感：「奖励设计」×「腕部相机」）

> **基线**：第 5 轮 CADVS-v5（IP-493~496；定义 2101–2240；定理 5–8；引理 43–44；风险 R53–R59）。CADVS-v4 / v29 的七硬门、证书演算与执行集嵌套链全部继承不变。
> **本轮纪律**：不推翻 v5，两条灵感各沿一条**非侵入**轴升级；硬门数量不增（仍七门），新增的只是「感知证据通道」与「排序契约」，二者都不进入信任边界；任一环节不可用必须**精确退化**为 v5。执行集升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29。

## 0. 直觉与动机

**灵感 1（腕部相机 → 从「被动全景感知」升级为「主动、可认证的近场取证」）**
直觉：现有覆盖门吃的是固定全局相机，而真正导致操作失败的是**接触区局部几何**——被夹爪/手指自遮挡、镜面反光、运动模糊。腕部相机贴得近、分辨率高，看起来是天然解药；但它窄视场、易自遮挡、易糊、手眼标定会漂。因此不能把腕部相机当成「更好的相机」，而要把它当成**可被审计的取景动作**：每次取景产出一张视角证书（遮挡率、模糊量、手眼标定残差、几何一致性、接触区覆盖增益），证书不过就不采信，退回 v5 全局视图。主动取景只允许**增加证据**，绝不允许**放松门**。

**灵感 2（奖励设计 → 从「标量价值分」升级为「只重排、不扩权的奖励契约」）**
直觉：v5 的价值门与 ECS 仍是学出来的标量，且可在线自适应，这正是 R57「固化自指博弈」的温床。奖励设计真正该问的不是「给多少分」，而是「奖励被允许改变什么」。答案：奖励只允许在**已认证执行集内重排候选**，永远不能改门、放松阈值或扩权。用「字典序契约（安全 ≻ 任务 ≻ 信息 ≻ 成本）+ 势函数塑形（策略不变）+ 反事实奖励审计（Goodhart 检测）」，把标量奖励的注入面压成一个可类型检查的**排序算子**。

**灵感 3（耦合 → 「看」与「偏好」必须结构解耦，否则互相放大）**
直觉：若让任务奖励去驱动取景，取景就会学会「挑一个让奖励好看的视角」——遮住失败、避开反光缺陷；若让取景结果直接进奖励，相机噪声就被「奖励化」。两者同源：**同一个传感器既是证据源、又是被奖励对象**。解法是「双奖励防火墙」：取景只优化**认证信息增益**（认知奖励），任务奖励既看不到也指挥不了取景；任务奖励只在认证证据上排序。由此得到本轮主定理：执行集对取景策略与奖励契约都**不具备扩权通道**——优化压力无法扩大信任边界。

## 1. 研究问题（本轮要回答什么）

- **Q1（腕部相机的安全性）**：腕部相机如何在**不扩大执行集**的前提下提升接触区覆盖？需要什么样的视角证书才能把「近场看得清」变成「可审计的证据」？
- **Q2（奖励的抗博弈性）**：奖励如何被设计成「只重排、不扩权」，并在 Goodhart/自指博弈下有可检验的失效开关？
- **Q3（感知–奖励的耦合）**：当取景与奖励都由学习得到时，如何证明二者不会联合放大误差或合谋「看起来合规、实质违背」？退化链是否精确？

## 2. 三条设计原则（正式化见产物区定义 2241–2298）

**P1 视角证据化（View-as-Evidence）**
腕部相机的每次取景是一个带证书的取证动作。覆盖门升级为 `kc_cov^v6 = kc_cov^v5 ∧ kc_view ∧ kc_local`，三项取**合取**，只紧不松；无相机/证书失效 ⇒ `kc_view≡1`，精确退回 v5 全局视图，禁用相机不能获得比 v5 更弱的保证。

**P2 奖励可采纳（Reward-Admissibility）**
奖励契约 `R_contract = ⟨r_safe, r_task, r_info, r_cost; ≻_lex⟩` 只在 `Exec_v6` 内排序：`argmax_{x∈Exec_v6} R_contract ⊆ Exec_v6`。塑形用势函数 `F=γΦ(s')−Φ(s)` 保证策略不变性；反事实审计失败即冻结塑形并回退 v5 的 `ECS_v5` 排序。奖励**不出现在执行集的定义里**。

**P3 证据–价值分离（Evidence-Value Firewall）**
认知奖励（取景）与任务奖励（动作）物理隔离：取景策略不得读任务价值模型，任务奖励不得指挥取景；所有证书带来源标签与签名（global / wrist / tactile / proprio），防火墙做污点传播检测。分离不是工程约定，而是定理 11 的前提。

## 3. 与基线的接口（如何精确退化）

- 无腕部相机 / 视角证书失效 / 标定漂移超阈 ⇒ `kc_view≡1`、`η_view=1`，等价 v5 全局视图；
- 奖励审计失败 / 契约越权 / 审计样本不足 ⇒ 冻结塑形与自适应，回退 `ECS_v5` 排序（执行集本就不含奖励，故 Exec 不变）；
- 取景预算耗尽且无有效视角证书 ⇒ 回退 v5；
- 防火墙检测到来源污染 ⇒ 关闭主动取景 + 回退 v5；
- 所有新组件失效 ⇒ CADVS-v5 ⇒ v4 ⇒ … ⇒ v29，严格链不变。

## 4. 预期贡献

1. **视角证书 + 主动取证**：把腕部相机从「更多像素」变成「可审计证据」，并在结构上保证不扩执行集（定理 9）。
2. **只重排奖励契约 + 势函数塑形 + 反事实审计**：给 R57 一个**结构性**（而非仅经验性）的缓解，把奖励从信任边界内移出（定理 10）。
3. **证据–价值分离定理 + 双奖励防火墙**：证明取景与奖励不能联合扩权或合谋，感知误差不能被奖励「洗白」（定理 11）。
4. **可证伪实验 E601–E616**：遮挡/反光/标定漂移/对抗取景/长程奖励机器/隐私审计，并显式包含「拆掉防火墙」的失效对照。

## 5. 本轮最大风险

**一句话**：**感知–奖励共谋**——腕部相机既是证据源又是被奖励对象，主动取景与奖励契约可在同一自认证回路上联合学会「看起来合规」而非「事实上正确」；视角证书本身也由同一传感器估计，存在循环论证，独立触觉/本体/全局视图交叉校验与随机审计视角只能检测、不能根除。

## 0. 增量定位与继承关系

v5 把「提议/记忆/人因」升级为生成式，但留下两个未被信任边界覆盖的输入面：(a) **感知**仍是被动全局视图，接触区证据不足；(b) **价值**仍是可在线自适应的标量，正是 R57 自指博弈的入口。本轮用两个灵感词各补一刀，并把二者**结构解耦**：

- 腕部相机 ⇒ **证据通道**升级：主动、近场、带证书；只加合取约束，不放松门。

### IP-497 ACVK：主动认证取景核（眼在手，10–30 Hz，与 1 kHz 控制环解耦）

```python
@dataclass
class ActiveCertifiedViewKernel:
    """ACVK：腕部相机主动取证 + 视角证书。
    P1：取景只能加合取证据，不能放松任何门（定理 9）"""
    cam: Any                       # 眼在手 RGB-D；内参/曝光/对焦可控
    hc: Any                        # 手眼标定 + 残差估计（独立基准：标定板/本体/IMU）
    B: int = 4                     # 每次准入取景预算
    o_max: float = 0.35
    b_max: float = 2.5             # px
    delta_max: float = 2.0         # mm
    c_min: float = 0.8
    tau_local: float = 0.85

    def cert(self, V, I, contact_region, cross_modal) -> ViewCert:
        # 遮挡/模糊/覆盖由腕部图估计；标定残差与几何一致性必须用
        # 独立于腕部相机的信号交叉校验（本体/IMU/全局视图/触觉）
        o = occlusion_ratio(I, contact_region)
        b = blur_estimate(I)
        dhc = self.hc.residual(I, cross_modal)          # 独立基准
        cg = geometric_consistency(I, cross_modal.global_view, cross_modal.tactile)
        dcov = certified_coverage_gain(I, contact_region)
        return ViewCert(dcov, o, b, dhc, cg)

    def kc_view(self, vc: ViewCert) -> bool:
        return (vc.o <= self.o_max and vc.b <= self.b_max
                and vc.dhc <= self.delta_max and vc.c_geo >= self.c_min)

    def select_views(self, state, contact_region, cross_modal) -> list[View]:
        """NBV 贪心：只最大化『认证覆盖增益』，不看任务奖励（防火墙保证）。
        g 单调子模 ⇒ 贪心 ≥ (1−1/e) 最优（引理 47）。"""
        S, views = 0.0, []
        for _ in range(self.B):
            cand = admissible_views(state, self.cam)     # 可达、无碰撞、不逆光
            scored = []
            for V in cand:
                vc = self.predict_cert(V, contact_region, cross_modal)
                if not self.kc_view(vc):                 # 预测证书不过 → 不取
                    continue
                scored.append((expected_gain(vc, S), V))
            if not scored:
                break
            gain, V = max(scored)
            views.append(V); S += gain
        return views                                  # 空 ⇒ EFA-v6 退回 v5

    def local_cov(self, x, views, cross_modal) -> float:
        return local_coverage(x, views, cross_modal)  # 供 kc_local
```

### IP-498 RDCK：奖励设计契约核（只重排；离线审计）

```python
@dataclass
class RewardDesignContractKernel:
    """RDCK：字典序契约 + 势函数塑形 + 反事实审计。
    P2：argmax R ⊆ Exec；奖励不出现在执行集定义里（定理 10）"""
    lex: tuple = ('safe', 'task', 'info', 'cost')
    phi: Any = None                # Φ：认证状态 → 势（可编译自奖励机器 RM）
    rm: Any = None                 # 奖励机器（长程任务规格）
    gamma: float = 0.99
    tau_G: float = 0.15
    kl_eps: float = 0.05
    frozen: bool = False

    def rank(self, cands: list, certs: dict, task) -> list:
        """只在调用方给定的 Exec 子集内排序；越界输入直接拒绝（类型级保证）。"""
        assert all(c.in_exec for c in certs.values())
        def key(x):
            c = certs[x]
            return (self.r_safe(c), self.r_task(x, c, task, self.rm),
                    self.r_info(c), -self.r_cost(x))
        return sorted(cands, key=key, reverse=True)   # 字典序：安全永远第一
```

### IP-499 EVF：证据–价值防火墙

```python
@dataclass
class EvidenceValueFirewall:
    """EVF：认知奖励（取景）与任务奖励（动作）物理隔离。
    证书带来源与签名；污点传播检测跨通道泄漏（定理 11 前提）。"""
    tainted: bool = False

    def epistemic_reward(self, vc: ViewCert, prov) -> float:
        assert prov.source in ('wrist', 'global', 'tactile', 'proprio')
        assert not prov.reads_task_value            # 取景不得读价值模型
        return vc.certified_info_gain               # 仅认证信息增益

    def task_reward(self, x, certs, prov) -> float:
        assert prov.controls_view is False          # 奖励不得指挥取景
        assert all(c.signed for c in certs.values())# 只用已签名的认证证据
        return self.rdck.score(x, certs)

    def check(self, certs) -> bool:
        # 任一证书来源污染/签名缺失/跨通道引用 ⇒ 关闭主动取景并回退 v5
        if any((not c.signed) or c.tainted for c in certs.values()):
            self.tainted = True
        return not self.tainted
```

### IP-500 EFA-v6：七硬门 + 视角合取 + 奖励仅重排

```python
@dataclass
class EvidenceForgingAssemblerV6:
    v5: EvidenceForgingAssemblerV5       # 七门 / FMPP / LMEM / FAMK 全套复用
    acvk: ActiveCertifiedViewKernel
    rdck: RewardDesignContractKernel
    evf: EvidenceValueFirewall

    def select(self, x0_state, t_now, rule_id, context):
        # 1) 主动取证（认知奖励；与任务奖励隔离）
        views = self.acvk.select_views(x0_state, context.contact_region, context.cross)
        vc = self.acvk.cert_for(views, x0_state, context.cross) if views else None
        if views and not self.acvk.kc_view(vc):
            return self.v5.select(x0_state, t_now, rule_id, context)  # fail-safe→v5
        if not self.evf.check(certs=[vc] if vc else []):
            return self.v5.select(x0_state, t_now, rule_id, context)  # 污染→v5
        # 2) 复用 v5 七门选证（Exec 由门定义，奖励尚未参与）
        ok, x, tag = self.v5.select(x0_state, t_now, rule_id, context)
        if not ok:
            return ok, x, tag
        # 3) 仅在 Exec 内用奖励契约重排；Exec 不变
        pool = self.v5.last_candidates
        certs = {c: self._cert(c, vc) for c in pool}
        ranked = self.rdck.rank(pool, certs, context.task)
        best = ranked[0]
        self.rdck.audit_async(context.audit_set)       # 异步；失败只回退排序
        return True, best, 'FORGED_CEV'

    def _cert(self, x, vc) -> Cert:
        # 汇总 v5 门证书 + 视角证书 + kc_local；全部带签名
        base = self.v5.gate_certs(x)
        local = self.acvk.local_cov(x, self.acvk.last_views, self._cross())
        return Cert(base=base, view=vc, kc_local=local >= self.acvk.tau_local,
                    signed=True)

    def ecs_v6(self, base_ecs_v5, vc, audit_G) -> float:
        eta_view = 1.0 if vc is None else sigmoid(vc.c_geo - self.acvk.c_min) * (1 - vc.o)
        eta_reward = 1.0 if audit_G is None else 1.0 - min(audit_G / self.rdck.tau_G, 1.0)
        return base_ecs_v5 * eta_view * eta_reward
```

### 集成流水线（v5 → v6）

```
在线准入（异步，秒级）：
  ACVK.select_views (B=4, 认知奖励，防火墙隔离) ──▶ cert_view
      ├─ 证书不过 / 预算耗尽 / 来源污染 ──▶ fail-safe 退回 v5 全局视图
      └─ 证书通过 ──▶ kc_view ∧ kc_local（合取）
  EFA-v5 七门选证（Exec_v5）──▶ Exec_v6 = Exec_v5 ∩ kc_view ∩ kc_local
  RDCK.rank（字典序 + 势函数）──▶ 仅重排 Exec_v6 内候选 ──▶ best
  RDCK.audit（异步）──▶ 超阈冻结，回退 ECS_v5 排序（Exec 不变）

在线控制环（目标仍 < 0.6 ms，v5 不变）：
  每周期只消费 v5 缓存证书 + 预计算阈值；取景/奖励全部在准入时域异步完成

离线/慢时域：
  奖励机器编译 + 契约标定；反事实审计留出集维护
  联邦：视角原型/证书统计/奖励超参（DP）──▶ 安全聚合 ──▶ Φ_global 下发
```

## 4. 正确性论证（增量更新）

### 引理 45（手眼标定误差到覆盖估计的传播界）

**陈述**：设手眼标定残差为 δ_hc，接触区尺度为 L，深度噪声为 ε_d，则认证覆盖增益的估计误差满足 |Δĉov − Δcov| ≤ L·δ_hc + ε_d。取 δ_max 即把覆盖误判压到 L·δ_max + ε_d 以内。∎

### 引理 46（奖励审计的 Goodhart 检测功效）

**陈述**：设留出审计集 n 条、代理–真值排序差 ≥ Δ，则反事实审计以概率 ≥ 1 − exp(−2nΔ²) 检出（Hoeffding）。故 τ_G 与 n 共同给出可调检测下界；检测不到的部分是定理 12 的诚实边界。∎

### 引理 47（NBV 子模贪心近似比）

**陈述**：若覆盖函数 g(S) 单调子模且证书有效视角集合非空，则预算 B 下的贪心取景满足 g(S_greedy) ≥ (1−1/e)·g(S*)。∎

### 定理 9（视角单调性 / 只紧不松）

**陈述**：`kc_cov^v6 = kc_cov^v5 ∧ kc_view ∧ kc_local` 为合取，故对任意取景配置 `Exec_v6 ⊆ Exec_v5`；无相机或证书失效时 `kc_view≡1`，且若同时无局部约束则精确退化 v5。禁用腕部相机不能获得比 v5 更弱的保证。∎

**证明**：合取只会缩小通过集；退化情形两额外项恒真。∎

### 定理 10（奖励可采纳 / 只重排不扩权）

**陈述**：若 R 仅在 `Exec_v6` 上定义、塑形为势函数形式 `F=γΦ(s')−Φ(s)`，则 (i) `argmax_{x∈Exec_v6} R ⊆ Exec_v6`；(ii) 塑形不改变最优策略（策略不变性）；(iii) `Exec_v6` 的定义中不含 R，故奖励的任何更新/博弈都不能扩大执行集。∎

**证明**：(i) 定义域封闭；(ii) Ng et al. 势函数定理；(iii) 执行集是门的谓词，R 只出现在 `Rank_v6`。∎

### 定理 11（证据–价值分离 / 无联合扩权）

**陈述**：在防火墙 EVF 生效（取景不读任务价值、奖励不指挥取景、证书签名且来源独立交叉校验）下，对任意取景策略 π_view 与任意奖励契约 R，`Exec_v6(π_view, R) ⊆ Exec_v5`，且 R 不出现在 `Exec_v6` 的定义中；因此取景误差不能被奖励「洗白」，奖励也不能请求放松门。二者只可能在排序层产生分歧，不可能在信任边界层合谋扩权。∎

**证明**：`Exec_v6` 由门与视角证书定义，R 不参与；视角项为合取（定理 9）；EVF 切断 π_view 对 R 的梯度/信息通道。∎

**诚实边界**：若视角证书本身错误（循环论证或交叉校验同源），则定理 11 的前提失效——这正是 R63。

### 定理 12（v6 总装：执行集收缩 + 精确退化 + 审计边界）

**陈述**：在 v5 假设 (B1)~(B7) 与新增 (B8) 交叉校验独立性下：
(i) `Exec_v6 ⊆ Exec_v5 ⊆ … ⊆ Exec_v29`；
(ii) 无相机/证书失效/防火墙污染 ⇒ 精确退化 v5；
(iii) 奖励只影响排序，不影响执行集；
(iv) 视角证书错误接受率由引理 45 与交叉校验覆盖度共同界定；
(v) Goodhart 检测功效由引理 46 界，未检出部分无结构根除保证；
(vi) NBV 覆盖效率由引理 47 的 (1−1/e) 下界。∎

**证明**：(i)(ii) 由定理 9；(iii) 由定理 10；(iv) 引理 45 + 独立性；(v) 引理 46；(vi) 引理 47。∎

**诚实声明**：(B8) 交叉校验若与腕部相机共享标定/时钟/几何先验，则独立性只是近似的，循环论证风险仍在；(ii) 奖励契约的字典序若被错误指定（安全项写错），系统会「安全地做错事」——这是规格负债而非博弈；(iii) 视角证书与奖励审计都只提供检测/回退，不提供根除。

## 7. 本轮最大风险（最终确认）
