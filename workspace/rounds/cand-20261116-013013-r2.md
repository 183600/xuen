# 第 12 轮（灵感循环第 2 轮；本轮灵感：「仿真到现实迁移」×「在线学习」）
> **基线**：第 11 轮 MetricVoiceGauge-GSCF-SRA-JSSE（定义 549–561；引理 92–96；实验 E591–E610）。
> 本轮纪律：**间隙可证 + 更新可证 + 覆盖可证**。两个灵感分别治理 v11 的三种债：**迁移债**（β_GSCF、γ_min、τ_sem、ε_fk 全在离线域标定，仿真/标定域与真实部署域之间的间隙从未进入证书——这正是 v11 自认的最大风险）、**适应债**（v10 起就有在线学习器 OTL，但更新无安全门，任何在线更新都可能悄悄作废 Ĉ⁺⁺）、**覆盖债**（"覆盖率 ≥99%"是事后经验统计，不是对未来的分布无关保证）。铁律不变：新模块失效 ⇒ 注入声明中立元，行为**等价**（SRGF/OCC）或**支配**（COAL）于 v11，绝不行为漂移。

## 0. 直觉与动机

**灵感 1（仿真到现实迁移 → 把"域"从假设变成可证余量）**
直觉：v11 的三重守护都踩在一个没说出来的前提上——"阈值在标定域成立，搬到真实域仍成立"。仿真给了我们一个可无限采样、可对抗注入、可反复标定的"先验世界"，但 sim 与 real 之间有一条**谁都没写进证书的缝**。仿真到现实迁移真正值钱的不是"把仿真调得更像"，而是**承认缝、并把缝做成一个可估计、可局部化、可入证书的场**。核心创新：**仿真-现实间隙场（SimToRealGapField, SRGF）**——用域随机化（DR）在参数分布 P_DR 上训练前向模型与阈值先验，用少量真实转移做系统辨识与 PAC 上界，得到**地标/区域局部化**的间隙估计 δ̂_SR(x)，把 v11 的三重余量升级为**四重余量** β_SR = β_OCC + λ·sup max(T,1−Γ) + λ_SR·sup δ̂_SR。理论关键一步（引理 97）：把真实误差**可加分解**为"仿真内误差 + 域间隙 + 自适应残差"，仿真内误差由 v11 证书管、间隙由 SRGF 管、自适应残差由在线学习管——每笔债都有主。更诚实的是引理 101：**未观测区域的间隙不可辨识**，SRGF 对"没去过的走廊"只许按先验宽度保守抬余量或收缩，不许假装知道。

**灵感 2（在线学习 → 让适应带上安全闸与后悔界）**
直觉：在线学习是唯一能让 δ̂_SR 随真实数据变小的东西，但它同时是证书最大的破坏者——一次"看起来更好"的更新可能把模型推向证书从未覆盖的分布。v11 的 OTL 是"学了再说"，v12 要改成"**先证再学**"。核心创新：**持证在线适应环（CertifiedOnlineAdaptationLoop, COAL）**：维护**现任模型**（已认证）与**候选模型**（在线更新）；候选在**影子模式**下只预测、不驱动执行；用共形 + 集中不等式给出候选/现任的**认证风险上界** R_cert，只有当候选的认证风险**不劣于**现任（留出 margin）才提交，否则**逐位回滚**到现任快照；变点检测（CUSUM/Page–Hinkley）一报警即**冻结学习 → 抬余量 → 收缩 K**。安全侧永远"只收紧、不放松"：所有守卫 φ^elig=false，学习不得触碰。理论上给出认证风险单调（引理 98）、检测延迟与误报界（引理 99）、后悔 O(√T) 与遗忘界（信赖域/EWC 约束参数漂移 ≤ρ）。

**灵感 3（在线学习 → 把经验覆盖率变成分布无关保证）**
直觉：v11 说"β_GSCF 覆盖 ≥99%"，那是**过去的频率**，不是**未来的保证**；分布一漂，99% 可以一夜变 80%。共形预测恰好把"点估计 + 经验阈值"变成"**带覆盖保证的集合**"，而自适应共形推断（ACI）在**非交换、漂移**序列上仍给**长期平均覆盖**界；再加权重共形，可把仿真分布当 proposal、真实分布当 target，在协变量偏移下修正覆盖。核心创新：**在线共形证书（OnlineConformalCertifier, OCC）**：用残差非一致性分数在线维护分位数 β_OCC，ACI 步长 γ 自动调 α_t（漂移时收紧），窗口覆盖一旦跌破 1−α−δ 即触发收缩；对 sim→real 用密度比加权共形，密度比超过 W_max 则退回 ACI。该模块把 v10/v11 反复出现的"经验标定阈值"从**风险**降级为**可审计、可证覆盖的估计**。

三者咬合：SRGF 给**可迁移先验与可局部化间隙**（真实误差里的"已知未知"），COAL 用真实数据**安全地**把间隙变小（"已知未知"→"已知已知"），OCC 给**未来覆盖的分布无关保证**（把"经验 99%"变"保证 1−α"）——共同把 v11 三重证书升级为**四重可迁移证书 Ĉ⁺⁺⁺ = (ĝ_min, ê_max, γ̂_grasp, β_SR, n_t, n_t^reason, Q_abort, δ̂_SR, α_t, lr_t)**。

## 1. 研究问题（轮次升级版）

- **Q1（迁移可证）**：如何把从未被证书覆盖的域间隙形式化为可局部化、可估计的 δ̂_SR，使真实误差上界 = 仿真误差 + 间隙 + 自适应残差，且对不可辨识区域强制保守（不把"仿真里没事"当作证明）？
- **Q2（更新可证）**：在线更新如何在"不劣化认证风险"的约束下进行，使安全性单调（认证风险非增）、变点即冻结、回滚逐位一致，且后悔 O(√T)、参数漂移/遗忘有界？
- **Q3（覆盖可证）**：如何用（加权）自适应共形把经验覆盖率升级为分布无关的长期覆盖保证，并在漂移/偏移下自动收紧而不长期冻结（失去适应性）？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 间隙入证律（Gap-in-Certificate, SRGF）**
任何来自仿真/离线标定的量（模型、β、γ_min、τ_sem、ε_fk）必须附带域间隙预算 δ̂_SR；未观测区域的间隙按先验最坏界 δ_prior 计入，禁止用"仿真中没见过问题"充当证明。

**P17 先证再学律（Certify-before-Learn, COAL）**
在线更新只许在候选的认证风险不劣于现任时提交；守卫不可学、不可松；变点即冻结；回滚必须逐位恢复已认证快照；学习收益必须用 regret 与参数漂移预算度量，而非仅用训练损失。

**P18 覆盖可证律（Coverage-Certified, OCC）**
凡以阈值形式进入证书的量，必须给出分布无关覆盖保证（或明确声明的漂移假设）；覆盖跌破预算时只许收缩，不许沿用旧的"经验 99%"。

## 3. 与基线的接口（如何退化）

- SRGF 失效（仿真器不可用 / DR 采样失败 / 真实辨识数据不足）⇒ δ̂_SR≡0、β_SR←β_GSCF：**逐项等价 v11**（失去间隙余量，退回 v11 隐含"同域"前提，但台账显式记录该前提已被降级）；
- COAL 失效（影子评估超时 / 认证风险不可算）⇒ **冻结在最近已认证快照**（等价 v11 静态模型），台账标记"学习停摆"；
- OCC 失效（共形更新超时 / 分数溢出）⇒ β_OCC←β_base 并加固定保守膨胀，等价 v11 固定 β 行为；
- 其余沿 v11 退化链（GSCF→SRA→JSSE→STF→NRB→AC→ID→MW→v8）。SRGF/COAL/OCC 与安全守卫一律 φ^elig=false 永不蒸馏，仅"间隙场维护/学习器"可蒸馏。

## 4. 预期贡献

1. **可迁移证书**：真实误差三分解 + 间隙场局部化 + 不可辨识下界，使"仿真里安全"第一次对"真实里安全"给出（有条件的）可证桥，而非默默假设同域（引理 97、101）；
2. **持证在线学习**：影子提交 + 认证风险单调 + 变点冻结 + 逐位回滚，学习不破安全（引理 98–99）；
3. **在线共形覆盖**：把经验阈值升级为分布无关长期覆盖保证，漂移下自适应收紧（引理 100）；
4. **E611–E630** 覆盖间隙标定、DR 覆盖、迁移证书、不可辨识区、更新安全、后悔、变点、回滚、遗忘、ACI 覆盖、对抗漂移、联合压测、退化链、预算、长跑、多机、投毒、竞赛。

## 5. 本轮最大风险

**一句话**：SRGF、COAL、OCC 三者都**用同一批真实数据既学习又认证**——共形的交换性/有界漂移假设，正是对抗反馈、协变量偏移或"学习本身改变了数据分布"（闭环）时最先破裂的东西；一旦间隙被低估、覆盖被高估，v12 会带着一枚比 v11 更"自信"的证书，漂进从未被真实数据覆盖的区域——而这恰恰是引理 101 已经警告的不可辨识区。

**新增定义 562（域随机化集成与仿真先验）** 在 θ~P_DR 上训练模型集成 {F̂_sim^θ}，取均值 F̂_sim=E_θ[F̂_sim^θ]，方差作为模型不确定性。**P_DR 的支撑必须覆盖部署域的可达参数区间**（E612 检验）；否则 SRGF 自动对支撑外状态使用 δ_prior。

**新增定义 563（域间隙函数与先验界）** δ_SR(x,u)=‖f_real(x,u)−E_θ[f_sim^θ(x,u)]‖。δ_prior 由 DR 支撑宽度 w_DR 与 Lipschitz 常数给出：δ_prior = L_f·w_DR + ε_sim，作为**未观测区的上界**；它不是经验阈值，而是最坏界（引理 101 说明该界不可被改进为更小）。

**新增定义 564（局部化间隙场与四重余量）** 每地标/区域维护 δ̄_ℓ = EMA_{5帧}(r_ℓ)，r_ℓ 为真实转移残差。δ̂_SR(x)=δ̄_ℓ（观测区）或 δ_prior（未观测区）。β_SR(ζ)=β_OCC + λ·sup_{Φ(ζ)} max(T,1−Γ) + λ_SR·sup_{Φ(ζ)} δ̂_SR。**单调性**：任一 δ̄_ℓ↑ 或 T↑ 或 Γ↓ ⇒ β_SR↑。

**新增定义 565（迁移信任域）** U^SR = (sup_{x∈走廊近邻} δ̂_SR(x) ≤ δ_max) ∧ OCC.coverage_ok() ∧ freshness(G_LM) ≤ T_fresh。U^SR 失效 ⇒ K_eff←1 或 Π_r（见定义 573 的六检）。

**新增定义 566（现任-候选双模型）** F̂_inc 为最近一次通过提交门的已认证模型；F̂_cand 由在线优化器在真实/影子数据上更新，**只产生预测，不驱动执行**（影子模式）。二者共享同一特征与安全壳。

**新增定义 567（认证风险上界）** R_cert(F̂;D)= (1/n)Σ loss(F̂;D_i) + Q_{1−α_t}(s_i) + C(n,δ)，其中 Q 为 OCC 在线共形分位，C 为集中项（Hoeffding：√(log(1/δ)/2n)）。R_cert 是**带高概率保证的风险上界**，非训练损失。

**新增定义 568（持证提交门与逐位回滚）** 提交门：若 R_cert(F̂_cand) ≤ R_cert(F̂_inc) − m_safe，则 F̂_inc←Snapshot(F̂_cand) 并记 lr_t=adapt；否则 F̂_cand←BitCopy(F̂_inc)（逐位恢复）、记 lr_t=rollback，本次更新不进入执行。**快照与回滚的位一致性由 E619 验证**。

**新增定义 569（变点检测与冻结）** CUSUM：g_t=max(0, g_{t−1}+s_t−ν)，ν 为期望残差。g_t>h_cp ⇒ lr_t=frozen，β 额外抬 δ_prior，K_eff 收缩，直到窗口残差回到基线并重新通过提交门。检测延迟与误报由引理 99 给出。

**新增定义 570（共形非一致性分数与加权共形）** s_t=‖x_{t+1}−F̂_inc(x_t,u_t)‖。sim→real 场景用密度比 W(x)=dP_real/dP_sim（训练判别器估计，截断 W_max）加权分位；W 截断误差 ε_W 进入覆盖界（引理 100）。

**新增定义 571（自适应共形水平 ACI）** err_t=1{s_t>β_OCC(t)}；α_{t+1}=clip(α_t+γ(α−err_t), α_min, α_max)。漂移使 err_t 升高 ⇒ α_t 升高 ⇒ 分位收紧 ⇒ β 增大（自动保守化）。

**新增定义 572（在线共形余量与覆盖预算）** β_OCC(t)=max(β_base, WeightedQuantile_{1−α_t}({(s_i,W_i)}_{窗口}))。窗口 W（默认 512）内误覆盖均值 > α+δ_cov ⇒ 触发 U^SR 失效与收缩。**β_OCC 只增不减地覆盖 β_base**，保证 OCC 失效退化时与 v11 一致。

**新增定义 573（四重证书）** Ĉ_t⁺⁺⁺=(ĝ_min,ê_max,γ̂_grasp,β_SR,n_t,n_t^reason,Q_abort,δ̂_SR,α_t,lr_t)。有效 ⇔ v11 定义 552 全部条件 ∧ U^SR ∧ δ̂_SR 已定义 ∧ lr_t≠rollback。升级定义 553：
```
K_eff(t) = 1                                若 ¬U_t^sem 或 ¬U_t^geo 或 ¬U_t^SR 或 Ĉ_t⁺⁺⁺ 不可得
         = 2                                若 NRB/SRA 失效 或 lr_t=frozen
         = max(1, ⌊K_max·(1 − min(1, max(Δ_dom/τ_dom, sup T/τ_sem, sup(1−Γ)/τ_sem, sup δ̂_SR/δ_max)))⌋)  否则
```

**新增定义 574（六检守卫）** 50Hz 六检（O(k),k≤8）：(i) 四重证书有效性；(ii) 停车不变量；(iii) 语义创新度 sup ν̄≤τ_sem；(iv) 快规范；(v) 几何一致性 inf γ̄≥γ_min；(vi) **迁移/覆盖：sup δ̂_SR≤δ_max ∧ OCC.coverage_ok() ∧ lr_t≠rollback**。任一失败 ⇒ 切最近中止点 p* 对应 q_abort，JSSE 接管。总预算 ≤0.7ms。

**新增定义 575（学习台账与退化）** Λ_L 在 v11 台账上扩展：H(prev‖t‖snapshot_id‖Δw‖R_cert_inc‖R_cert_cand‖decision‖lr_t)。缺口或哈希断裂 ⇒ 立即 lr_t=frozen、β 抬 δ_prior。台账与 v11 伦理台账同链或双链锚定。

**新增定义 576（漂移与遗忘预算）** 单次更新 ‖Δw‖≤ρ；累计漂移 ‖w_t−w_0‖≤B_w（EWC/信赖域保证）；累计后悔 B_regret(T)=O(√T)（凸损失）或 O(√T·d)（线性 bandit 类比）。越预算 ⇒ 冻结学习（不是越预算继续学）。

# IP-365 SimToRealGapField：仿真-现实间隙场
class SimToRealGapField:
    def __init__(self, sim_ensemble, dr_sampler, L_f, w_DR, eps_sim,
                 tau_gap=0.02, ema=0.2, h=0.5, δ_max=0.08):
        self.sim = sim_ensemble          # {F̂_sim^θ}, θ~P_DR
        self.dr = dr_sampler
        self.delta_prior = L_f * w_DR + eps_sim   # 未观测区最坏界（定义 563）
        self.delta_max = δ_max
        self.ema, self.h = ema, h
        self.map = LandmarkMap()         # 与 STF/GSCF 共用地标拓扑

    def fit_from_real(self, transitions):        # 离线 PAC 拟合（定义 563）
        emp = max(norm(t.x_next - self.sim.mean(t.x, t.u)) for t in transitions)
        n = len(transitions)
        conc = sqrt(log(1 / 0.01) / (2 * n))
        self.delta_pac = emp + conc                # 高概率间隙上界

    def update(self, x, u, x_next):              # 在线 O(k)，真实残差 → 局部场
        r = norm(x_next - self.sim.mean(x, u))
        ell = self.map.landmark_of(x)
        if ell is not None:
            ell.delta_bar = self.ema * r + (1 - self.ema) * ell.delta_bar
            ell.observed = True

    def delta_hat(self, x):                      # 观测区用局部值，未观测区用先验
        ell = self.map.nearest(x)
        if ell is not None and ell.observed:
            return max(ell.delta_bar, self.delta_pac)
        return self.delta_prior

    def field_on_footprint(self, path):          # sup over corridor（定义 564）
        return max(self.delta_hat(x) for x in path.corridor_samples())

    def transfer_ok(self, pose):
        return (self.field_on_footprint(pose.corridor) <= self.delta_max
                and self.map.fresh(T_fresh) and self.occ.coverage_ok())


# IP-366 CertifiedOnlineAdaptationLoop：持证在线适应环
class CertifiedOnlineAdaptationLoop:
    def __init__(self, inc_model, optimizer, occ, ledger, guards,
                 m_safe=0.01, rho=1e-3, h_cp=5.0, nu=0.0, ewc=0.1):
        self.inc = inc_model.snapshot()          # 已认证现任
        self.cand = inc_model.clone()
        self.opt, self.occ, self.ledger = optimizer, occ, ledger
        self.guards, self.m_safe, self.rho = guards, m_safe, rho
        self.h_cp, self.nu, self.ewc = h_cp, nu, ewc
        self.g, self.lr = 0.0, 'adapt'

    def cert_risk(self, model, batch):           # 定义 567
        emp = mean(model.loss(b) for b in batch)
        q = self.occ.quantile()                  # β_OCC
        conc = sqrt(log(1 / 0.01) / (2 * len(batch)))
        return emp + q + conc

    def change_point(self, residuals):           # 定义 569（CUSUM）
        for r in residuals:
            self.g = max(0.0, self.g + r - self.nu)
        return self.g > self.h_cp

    def step(self, batch, residuals):
        if self.lr == 'frozen':
            return self.inc
        if not self.guards.all_ok():             # 安全守卫只收紧
            self.lr = 'frozen'
            return self.inc
        # 信赖域 + EWC：候选参数漂移受控（定义 576）
        delta = self.opt.step(self.cand, batch)
        if norm(delta) > self.rho:
            delta = delta * (self.rho / norm(delta))
        self.cand.apply(delta)
        if self.change_point(residuals):
            self.lr = 'frozen'
            self.inc.inflate_beta(self.occ.quantile())
            self.ledger.append_update(self.inc.snapshot_id, delta, None, None, 'freeze')
            return self.inc
        r_inc = self.cert_risk(self.inc, batch)
        r_cand = self.cert_risk(self.cand, batch)
        if r_cand <= r_inc - self.m_safe:        # 持证提交门（定义 568）
            self.ledger.append_update(self.inc.snapshot_id, delta, r_inc, r_cand, 'accept')
            self.inc = self.cand.snapshot()
            self.lr = 'adapt'
        else:                                    # 逐位回滚
            self.cand = self.inc.bit_copy()
            self.ledger.append_update(self.inc.snapshot_id, delta, r_inc, r_cand, 'rollback')
            self.lr = 'rollback'
        return self.inc


# IP-367 OnlineConformalCertifier：在线共形证书
class OnlineConformalCertifier:
    def __init__(self, alpha=0.01, gamma=0.005, window=512, delta_cov=0.01,
                 W_max=10.0, beta_base=0.0):
        self.alpha_target, self.alpha = alpha, alpha
        self.gamma, self.window = gamma, window
        self.scores, self.errs = deque(maxlen=window), deque(maxlen=window)
        self.delta_cov, self.W_max, self.beta_base = delta_cov, W_max, beta_base

    def update(self, residual, weight=1.0):      # 定义 570–572
        self.scores.append((residual, min(weight, self.W_max)))
        beta = self.quantile()
        err = 1 if residual > beta else 0
        self.errs.append(err)
        # ACI：漂移 ⇒ α_t 升 ⇒ 分位收紧 ⇒ β 增
        self.alpha = clip(self.alpha + self.gamma * (self.alpha_target - err),
                          1e-4, 0.5)

    def quantile(self):                          # 加权分位，且 ≥β_base
        return max(self.beta_base,
                   weighted_quantile(sorted(self.scores), 1 - self.alpha))

    def coverage_ok(self):
        return (len(self.errs) < self.window
                or mean(self.errs) <= self.alpha_target + self.delta_cov)


# IP-354（升级）：四重守护证书分块执行器
class QuadGuardChunkCertifier(TriGuardChunkCertifier):
    def __init__(self, *a, srgf=None, coal=None, occ=None, **kw):
        super().__init__(*a, **kw)
        self.srgf, self.coal, self.occ = srgf, coal, occ

    def generate_chunk(self, state, ctx, stf, gscf, sra, nrb):
        K = self.effective_K_quad(ctx, stf, gscf, self.srgf)
        if K == 1:
            return self._single_step_fallback(state)
        best = None
        for cand in self.policy.sample_sequences(state, K, n=64):
            pred = self.Fq.rollout(state, cand)
            beta_sr = (self.occ.quantile()
                       + self.lam * gscf.field_on_footprint(pred.corridor)
                       + self.lam_sr * self.srgf.field_on_footprint(pred.corridor))
            g_min = pred.min_clearance - beta_sr
            e_max = pred.max_effort + beta_sr
            if g_min < self.d_safe or e_max > state.tau_eff:
                continue
            pts = self._abort_points(state, cand, pred)
            if not pts:
                continue
            cert = QuadCert(g_min, e_max, beta_sr,
                            delta_hat=self.srgf.field_on_footprint(pred.corridor),
                            alpha=self.occ.alpha, lr=self.coal.lr, pts=pts)
            chunk = Chunk(cand, cert, pts)
            chunk, _ = nrb.review_chunk(chunk, stf, ctx)
            if chunk is None:
                continue
            n_reason, _ = sra.reason_on_chunk(chunk, stf, gscf, ctx)
            chunk.cert.n_reason = n_reason
            if not all(n_reason):
                continue
            chunk.cert.Q_abort = {p: self.jsse.map_abort(p) for p in pts}
            score = self.policy.score(chunk, pred)
            if best is None or score > best.score:
                best = chunk
        return best or self._single_step_fallback(state)

    def midchunk_guard(self, chunk, k_exec, live_obs, stf, gscf, nrb, jsse):
        """50Hz 六检 ≤0.7ms"""
        if not chunk.cert_still_valid(live_obs):
            return self._abort_to_jsse(chunk, k_exec, jsse)
        stop_inv = (live_obs.nearest_clearance
                    - self.d_brake(live_obs.speed) - self.d_safe)
        if stop_inv < chunk.remaining_len(k_exec):
            return self._abort_to_jsse(chunk, k_exec, jsse)
        if stf.surprise_near(live_obs.pose) > stf.tau_sem:
            return self._abort_to_jsse(chunk, k_exec, jsse)
        if nrb.fast_norms(live_obs).violated:
            return self._abort_to_jsse(chunk, k_exec, jsse)
        if not gscf.geo_ok_near(live_obs.pose):
            return self._abort_to_jsse(chunk, k_exec, jsse)
        if not (self.srgf.transfer_ok(live_obs.pose)       # 检 6：迁移/覆盖
                and self.occ.coverage_ok()
                and self.coal.lr != 'rollback'):
            return self._abort_to_jsse(chunk, k_exec, jsse)
        return ('continue', k_exec + 1)

## 4. 推导

**引理 97（sim-to-real 误差三分解与证书桥）**
设 (A1) f_real 与 F̂_sim 均为 L-Lipschitz；(A2) 间隙 δ_SR(x,u) 由定义 563 给出，观测区由 δ̂_SR 以概率 ≥1−ε_gap 上界、未观测区取 δ_prior；(A3) 现任模型与仿真均值之差 e_adapt=‖F̂_inc−F̂_sim‖ 被 OCC 的 β_OCC 以高概率覆盖。则单步真实误差满足
‖F̂_inc(x,u)−f_real(x,u)‖ ≤ ‖F̂_sim−f_sim‖ + δ_SR(x,u) + e_adapt，
沿 H 步 rollout 以 L 复合，得到真实误差 ≤ 仿真内误差 + H·(δ_SR+e_adapt) + O(L^H)，被 β_SR 覆盖。**退化**：SRGF 失效（δ̂=0）且 OCC 失效（β_OCC=β_base）时，β_SR=β_GSCF，逐项回到 v11。∎

**引理 98（持证提交的认证风险单调性与逐位回滚）**
(i) 提交门仅在 R_cert(F̂_cand) ≤ R_cert(F̂_inc) − m_safe 时更新现任，故已接受更新的认证风险序列非增；(ii) 拒绝时 F̂_cand ← BitCopy(F̂_inc)，执行侧看到的模型与更新前逐位相同，故物理行为集合不因拒绝而改变（**支配性**：不会引入 v11 之外的新行为）；(iii) 信赖域 ‖Δw‖≤ρ 与 EWC 惩罚使累计漂移 ≤B_w，遗忘有界；(iv) 凸损失下在线梯度/镜像下降给出 B_regret(T)=O(√T)。故 COAL 只增加"更安全方向上的适应"，不增加新的物理行为集合；COAL 失效即冻结现任 ⇒ 等价 v11。∎

**引理 99（变点检测的及时冻结与误报界）**
CUSUM 在漂移幅度 κ 下的期望检测延迟 ≤ h_cp/κ（Page–Hinkley 经典界），无漂移时平均误报间隔 ≥ e^{h_cp}（ARL 界）。检测到 g_t>h_cp 即 lr_t=frozen、β 抬 δ_prior、K_eff 收缩，故危险窗口长度为检测延迟加冻结切换时延；该长度作为 ε_cp 项进入联合界（引理 102）。∎

**引理 100（在线共形覆盖与漂移下收缩）**
在分数有界、α_t 截断于 [α_min,α_max]、ACI 步长 γ 的条件下，长期平均误覆盖满足
(1/T)Σ err_t = α + O(1/(γT)) + O(γ)，
即覆盖可被 1/T 与 γ 控制（Gibbs–Candès 型结论）。若用密度比 W 加权且 W≤W_max，则目标域覆盖 ≥1−α−ε_W（ε_W 为密度比估计与截断误差，Tibshirani 型加权共形）；W 超界即退回 ACI。窗口误覆盖 >α+δ_cov ⇒ U^SR 失效 ⇒ 收缩。**故 β_OCC 把"经验 99%"升级为"可声明漂移假设下的分布无关覆盖"**。∎

**引理 101（未观测区域间隙不可辨识下界）**
设区域 R 上无任何真实转移。对任意仅依赖仿真与 P_DR 的估计器 δ̂，存在两个与仿真观测完全一致的现实环境，其间隙分别为 0 与 δ_prior（两环境在 P_DR 支撑内不可区分）。由两点下界（Le Cam），任意估计器在 R 上的最坏误差 ≥ δ_prior/2。**故证书在未观测区只能取 δ_prior 或收缩**，不能声称知道更小的间隙。这解释了为什么要"安全地主动探测"，也界定了 sim-to-real 的能力边界。∎

**引理 102（四重守护联合保守性与支配性）**
在引理 97–101 与 v11 引理 92–96 假设下，四重证书 Ĉ⁺⁺⁺ 以概率 ≥1−(ε_geo+ε_sra+ε_jsse+ε_gap+ε_gate+ε_cp+ε_W+ε_β) 捕获任一中块危险事件：显著语义/几何走 v11 检 3/5（≤1 帧），迁移/覆盖异常走检 6（≤1 帧），非显著误差由 β_OCC+β_SR 覆盖。物理行为：三新模块 inactive 时逐项等价 v11；active 时只接受认证风险非增的更新或更保守的收缩，故行为集合 ⊆ v11 可行集 ∪ "经证更安全"集合。∎

## 8. 本轮最大风险

**一句话**：SRGF、COAL、OCC 共用同一批真实数据**既学习又认证**——共形的交换性/有界漂移假设，恰好在对抗反馈、协变量偏移或闭环"学习改变数据分布"时最先破裂；一旦间隙被低估、覆盖被高估，v12 会带着一枚比 v11 更"自信"的证书漂进从未被真实数据覆盖的区域，而引理 101 已证明那里根本不可辨识——乐观的迁移证书比诚实的全局怀疑更危险。
