# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「用户测试」×「自监督学习」）

> 第 54 轮把技能组合与云边协同固化为动作空间剖面 α_S 与联合证书 J。但 J 的 soundness 全部来自「内部仿真 + 形式假设」：它能证明系统在模型内自洽，却回答不了两个外部问题——真实用户是否接受？表征是否真的抓住了动作因果？本轮引入两个外部性来源：**用户测试**（外部效度的稀疏金标准）与**自监督学习**（无标签交互数据的证据放大器）。核心矛盾：H22：SSL 表征可以高度自洽却与真实可控性/用户接受度脱钩（表征捷径）；H23：用户测试主观、非平稳、采样有偏，直接当证书会污染 soundness；H24：若用 SSL 选择用户测试样本、又用同一批用户测试校准 SSL 证书，会形成「证据回音室」。

## 0. 直觉与动机

**灵感 1（用户测试 = 外部效度校准器，而非终点验收）**
直觉：第 54 轮的证书 J 是「内部一致性证书」，只保证在仿真模型 𝔐 和假设 A22–A28 下成立。用户测试提供的是**模型外**的接受度样本 β_U。把用户测试从「最后打分」改为**校准集**：用 conformal 方法把「证书预测成功率 p_cert」映射到「用户接受率下界」，只有当用户接受下界 ≥ τ_u 且 ρ ≥ ρ_min 时才允许部署。这样用户测试不是主观加分项，而是**可统计校准的外部证据**。

**灵感 2（自监督学习 = 用无标签交互放大证据）**
直觉：动作剖面 α_S 若靠枚举 `can_execute(a_c,a_e)` 采样，成本 O(|A_c|·|A_e|·|S|)，且大量长尾动作永远采不到。自监督学习在无标签交互日志上训练**动作条件表征** z=f(o,a)（掩码轨迹重建 + 时序对比 + 逆动力学一致性），可以低成本估计「动作可控性剖面」 α̂_S 与新颖度 ν，把仿真查询减少一个量级。SSL 不是替代证书，而是**证书的证据引擎**。

**灵感 3（主动用户测试 = 在信息量最大的地方花人）**
直觉：用户测试昂贵且不可并行，不应随机抽。以 SSL 潜空间的不确定性 σ_α、conformal 区间宽度、OOD 新颖度 ν 为采集函数，主动选择「最能让证书变确定」的样本去问用户。这把用户测试预算 B_u 变成**信息增益预算**，形成 SSL 预训练 → 主动查询 → 用户标签 → 校准证书 → 再采样 的闭环。

**灵感 4（SSL 绊线 = 把「表征自信」与「真实可控」解耦）**
直觉：SSL 的预测误差低可能只是数据冗余大。必须加**干预式负对照**：动作打乱（action shuffle）、时间反转、跨本体替换；若表征在这些干预下仍「预测得好」，说明它学的是捷径而非动作因果。把干预一致性与潜空间 OOD 分数合成**绊线** ν_trip；一旦触发，证书失效并升级到人工/用户测试，而不是继续外推。

**灵感 5（证据金字塔：从内部证书到外部共识）**
直觉：第 54 轮的动作-鲁棒性金字塔 𝕃×𝔸 之上再加**证据层 𝔼**：𝔼_0 无标签交互日志，𝔼_1 SSL 表征与动作可控性，𝔼_2 主动用户测试样本，𝔼_3 校准后的用户接受证书。跨层传递的不是单一标量，而是「证书 + 校准映射 + 覆盖域 + 绊线状态」。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（用户测试证据）**
用户测试协议 π 在用户分层 U 与任务分层 T 的网格上采样，产生 `(u,t,o,a,r,y)`，其中 r∈{0,1} 为客观任务成败，y∈{accept,reject,pref} 为主观接受。用户测试证据 `E_U = (U_strata, T_cover, n_eff, κ, β_U)`，β_U(t) 为任务 t 的用户接受率，κ 为评分者一致性。**覆盖条件** `cov_U = |U_strata×T_cover 中有样本的格| / |U_strata×T_cover| ≥ θ_U`。

**定义 122（动作条件自监督表征）**
编码器 `f_θ: O×A→Z`，自监督损失 `L_ssl = L_mask + λ1 L_temp + λ2 L_inv + λ3 L_var`：
- `L_mask`：掩码轨迹重建；
- `L_temp`：时序对比（同一轨迹相邻步为正，跨轨迹为负）；
- `L_inv`：逆动力学 `â = h(z_t,z_{t+1})` 的一致性；
- `L_var`：防坍缩方差项。
假设在支撑集上 `||z(o,a)-z(o,a')|| ≤ L_z||a-a'||`。

**定义 123（自监督动作可控性剖面）**
`α̂_S(a) = E_{o∼D_S}[ φ(z(o,a), a) ]`，其中 φ 为前向可预测性与逆动力学一致性之积；附不确定度 `σ_α(a)`。与第 54 轮定义 115 的关系：`α̂_S` 是 `α_S` 的**低成本估计**，仅在 SSL 支撑域 `supp(D_S)` 内可信；域外必须回落到枚举采样或标记为未知。

**定义 124（用户-证书一致性校准）**
以用户测试为校准集，非一致性分数 `s = |p_cert - y|`，构造 conformal 区间 `[p_lo, p_hi]`，校准映射 `g: p_cert ↦ [p_lo,p_hi]`。**部署门**：
```
deploy ⟺ p_lo ≥ τ_u ∧ ρ_comp ≥ ρ_min ∧ ν_trip < Θ_ν
```
并定义证书-用户分歧 `Δ_cal = E[|p_cert - β_U|]`。若 `Δ_cal > Θ_cal`，证书进入「外部效度失败」状态而非静默通过。

**定义 125（自监督绊线）**
新颖度 `ν(o,a) = w_1·PE(o,a) + w_2·disagree(o,a) + w_3·(1 - inv_consistency)`，其中 PE 为预测误差、disagree 为集成分歧。**绊线** `ν_trip = sup_{a∈A_T} ν(o,a)`。域外质量 `m_OOD = P(ν > τ_ν)`。证书只在 `m_OOD ≤ Θ_OOD` 时有效。

**定义 126（主动用户测试查询）**
给定用户预算 `B_u`，查询选择
```
q* = argmax_{q∈Q} [ IG(q; p_cert) · 1(σ_α(q) > τ_σ) / cost(q) ]
```
并强制保留探索配额 `ε_u`：至少 ε_u·B_u 的样本来自非不确定性最高区域（防回音室）。

## 2. 关键算法 伪代码

### IP-121 USE（User Study Evidence）

```python
def collect_user_evidence(policy, U_strata, T_grid, budget, protocol):
    samples = []
    for (u, t) in stratified_sample(U_strata, T_grid, budget):
        r = protocol.run_task(u, t)            # 客观成败
        y = protocol.elicit_acceptance(u, t)   # 主观接受
        samples.append((u, t, r, y))
    E_U = Evidence(
        U_strata=U_strata,
        T_cover=coverage(T_grid, samples),
        n_eff=effective_n(samples),
        kappa=inter_rater(samples),
        beta_U=acceptance_rate(samples))
    return E_U
```

### IP-122 SRL（Self-Supervised Representation）

```python
def train_ssl(logs, theta):
    for batch in logs:                       # (o_t, a_t, o_{t+1}) 无标签
        z_t, z_n = f(batch.o_t), f(batch.o_next)
        loss = mask_loss(batch) \
             + theta.l1 * temporal_contrast(z_t, z_n) \
             + theta.l2 * inv_dynamics_consistency(z_t, z_n, batch.a) \
             + theta.l3 * variance_reg(z_t)
        loss.backward(); opt.step()
    return f

def controllability_profile(f, skill, A, D_S):
    alpha_hat, sigma = {}, {}
    for a in A:
        vals = [phi(f(o, a), a) for o in D_S]
        alpha_hat[a] = mean(vals)
        sigma[a] = std(vals) / sqrt(len(vals))
    return alpha_hat, sigma
```

### IP-123 SSP（Self-Supervised Profiling with fallback）

```python
def self_supervised_profile(skill, A, f, D_S, tau_sigma):
    alpha_hat, sigma = controllability_profile(f, skill, A, D_S)
    alpha = {}
    for a in A:
        if in_support(f, a, D_S) and sigma[a] <= tau_sigma:
            alpha[a] = alpha_hat[a]                  # 低成本估计
        else:
            alpha[a] = enumerate_execute(skill, a)   # 域外回落
    return alpha
```

### IP-124 UCL（User-Certificate Calibration）

```python
def calibrate_certificate(p_cert_calib, y_user_calib, alpha=0.1):
    scores = [abs(p - y) for p, y in zip(p_cert_calib, y_user_calib)]
    q = quantile(scores, 1 - alpha, method='higher')

    def gate(p_cert, rho_comp, nu_trip, tau_u, rho_min, Theta_nu):
        p_lo, p_hi = max(0, p_cert - q), min(1, p_cert + q)
        ok = (p_lo >= tau_u) \
             and (min(rho_comp.values()) >= rho_min) \
             and (nu_trip < Theta_nu)
        return ok, (p_lo, p_hi)
    return gate
```

### IP-125 SST（Self-Supervised Tripwire）

```python
def tripwire(f_ensemble, trajectory, tau_nu):
    nu = []
    for o, a in trajectory:
        pe = prediction_error(f_ensemble, o, a)
        dis = ensemble_disagreement(f_ensemble, o, a)
        inv = 1 - inverse_dynamics_consistency(f_ensemble, o, a)
        nu.append(w1 * pe + w2 * dis + w3 * inv)
    return max(nu), ood_mass(nu, tau_nu)
```

### IP-126 AUQ（Active User Query）

```python
def active_user_query(pool, p_cert, sigma_alpha, budget, eps_u):
    n_explore = int(eps_u * budget)
    exploit = sorted(
        pool, key=lambda q: -IG(q, p_cert) * sigma_alpha[q] / cost(q))
    explore = random_sample(pool, n_explore)
    return exploit[:budget - n_explore] + explore
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| USE | O(B_u·(τ_task+τ_elicit)) | O(B_u) | 分层覆盖、评分者一致性 |
| SRL | O(N_log·E·|Z|) 一次性预训练 | O(E·|Z|) | 动作条件、防坍缩、干预负对照 |
| SSP | O(|A|·|D_S|)，对比枚举 O(|A|·|S|·sim) | O(|A|) | 支撑域判定、域外回落 |
| UCL | O(n_calib log n_calib) | O(n_calib) | 可交换性、覆盖保证 |
| SST | O(|A_T|·E) | O(|A_T|) | 集成多样性、阈值校准 |
| AUQ | O(|pool| log |pool|) | O(|pool|) | 信息增益估计、探索配额 |

**正确性定理（Externally-Calibrated Evidence Soundness）**
在 (A26)–(A28) 之上追加：**(A29)** 用户测试校准集与部署分布可交换（或满足加权 conformal 的协变量偏移界）；**(A30)** SSL 支撑域外回落枚举采样，`supp(D_S)` 覆盖任务动作序列的比例 ≥ 1-ε_s；**(A31)** 绊线阈值 τ_ν 在校准集上满足误报 ≤ ε_ν。
则对部署策略：
```
P(user_accept ∧ spec_ok) ≥ 1 - α - ε_s - ε_ν - β_E - P(Δ_cal > Θ_cal)
```
关键：**用户标签外部校准**、**SSL 仅作域内插值**、**绊线阻断外推**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| SSL 表征捷径（自洽不因果） | 高 | 动作打乱/时间反转/跨本体负对照 + 干预一致性门 |
| 用户测试主观与采样偏差 | 高 | 预注册协议 + 分层抽样 + 评分者一致性 + held-out 人工审计 |
| 证书-用户分布偏移 | 高 | 加权 conformal + 分布漂移监测 + 门限自动收紧 |
| 主动查询回音室 | 高 | ε_u 探索配额 + 独立审计集 + 伪标签隔离 |
| 用户隐私与数据合规 | 中 | 端侧 SSL + 联邦/差分隐私 + 明示同意 |

## 6. 本轮最大风险

**一句话**：本轮用「用户测试校准 + 自监督证据放大」把内部证书升级为外部共识，但其 soundness 依赖 **SSL 表征的因果忠实性、用户校准集的可交换性、以及二者不共享同一选择偏差**；一旦 SSL 学到捷径且用户测试又只在 SSL「自信」的样本上采集，系统会得到一个内部覆盖率高、外部完全失效的「证据回音室」，因此必须以 **干预式负对照 + 分层 held-out 人工审计 + 独立探索配额** 作为不可协商的三角护栏，宁可承认证书「外部未知」，也不把统计自洽伪装成用户共识。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim-U（USE×SRL×SSP×UCL×SST×AUQ）

> 承接第 54 轮产物 v31。第 54 轮解决了「技能能否在动作空间与云边之间被组合/验证」，本轮解决「证书凭什么被真实用户与真实数据信任」。新增两个外部性来源与四个闭合算子：
> - **USE（User Study Evidence）**：把用户测试协议化为分层的、可统计的外部证据；
> - **SRL（Self-Supervised Representation Layer）**：无标签交互日志上的动作条件表征；
> - **SSP（Self-Supervised Skill Profiling）**：用 SSL 低成本估计动作剖面 α̂_S，并在域外回落枚举；
> - **UCL（User-Certificate Calibration）**：用 conformal 把内部证书校准为用户接受下界；
> - **SST（Self-Supervised Tripwire）**：以预测误差 + 集成分歧 + 干预一致性构成绊线；
> - **AUQ（Active User Query）**：在信息增益最大处花用户测试预算，并保留探索配额防回音室。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/117/118/120 以纳入外部证据与 SSL 维度。

```python
        pe = prediction_error(f_ensemble, o, a)
        dis = ensemble_disagreement(f_ensemble, o, a)
        inv = 1 - inverse_dynamics_consistency(f_ensemble, o, a)
        nu.append(w1 * pe + w2 * dis + w3 * inv)
    return max(nu), ood_mass(nu, tau_nu)
```

```python
def active_user_query(pool, p_cert, sigma_alpha, budget, eps_u):
    n_explore = int(eps_u * budget)
    exploit = sorted(
        pool, key=lambda q: -IG(q, p_cert) * sigma_alpha[q] / cost(q))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| USE | O(B_u·(τ_task+τ_elicit)) | O(B_u) | 分层覆盖 ≥ θ_U，κ 可报告 |
| SRL | O(N_log·E·|Z|) 一次性 | O(E·|Z|) | 动作条件、防坍缩、干预负对照通过 |
| SSP | O(|A|·|D_S|)（枚举基线 O(|A|·|S|·sim)） | O(|A|) | 支撑域内插值，域外回落 |
| UCL | O(n_calib log n_calib) | O(n_calib) | conformal 覆盖 ≥ 1-α |
| SST | O(|A_T|·E) | O(|A_T|) | 误报 ≤ ε_ν，OOD 质量可测 |
| AUQ | O(|pool| log |pool|) | O(|pool|) | 探索配额保证不塌缩 |

**正确性定理（Externally-Calibrated Evidence Soundness）**
在 (A26)–(A28) 成立的基础上追加：**(A29)** 用户校准集与部署分布可交换，或满足加权 conformal 的协变量偏移界；**(A30)** SSL 支撑域外回落枚举，`supp(D_S)` 覆盖任务动作序列比例 ≥ 1-ε_s；**(A31)** 绊线阈值满足误报 ≤ ε_ν。
则：
```
P(user_accept ∧ spec_ok) ≥ 1 - α - ε_s - ε_ν - β_E - P(Δ_cal > Θ_cal)
```
关键：**用户标签提供外部校准**，**SSL 只在域内插值**，**绊线阻断外推**，**探索配额切断选择偏差回路**。

## 6. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| SSL 表征捷径（自洽不因果） | 高 | 动作打乱/时间反转/跨本体负对照 + 干预一致性门 |
| 用户测试主观与采样偏差 | 高 | 预注册协议 + 分层抽样 + 评分者一致性 + held-out 人工审计 |
| 证书-用户分布偏移 | 高 | 加权 conformal + 分布漂移监测 + 门限自动收紧 |
| 主动查询回音室 | 高 | ε_u 探索配额 + 独立审计集 + 伪标签隔离 |
| 用户隐私与数据合规 | 中 | 端侧 SSL + 联邦/差分隐私 + 明示同意 |

## 7. 本轮最大风险

**一句话**：本轮用「用户测试校准 + 自监督证据放大」把内部证书升级为外部共识，但其 soundness 依赖 **SSL 表征的因果忠实性、用户校准集的可交换性、以及二者不共享同一选择偏差**；一旦 SSL 学到捷径且用户测试又只在 SSL「自信」的样本上采集，系统会得到一个内部覆盖率高、外部完全失效的「证据回音室」，因此必须以 **干预式负对照 + 分层 held-out 人工审计 + 独立探索配额** 作为不可协商的三角护栏，宁可承认证书「外部未知」，也不把统计自洽伪装成用户共识。
