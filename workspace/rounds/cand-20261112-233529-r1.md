# 第 63 轮（承接第 62 轮「ROSE」IP-183~192；灵感循环 II 第 2 轮；本轮灵感：「课程学习」×「低延迟推理」）

> 第 62 轮 ROSE 用「在线学习遗憾界 × Wasserstein-CVaR 鲁棒编译 × 场景银行遗憾课程」把 ESEC 静态闭环升级为动态闭环。但除 ROSE 自述的最大风险（RSC 球覆盖失效）之外，还暴露出**四个与「学什么 / 学多难 / 推多深」直接相关的结构性短板**：
> 1. **SHC 是「遗憾老虎机」而非「课程」**：它按簇遗憾分配预算（Hedge），却**没有难度度量、没有 pacing、没有易→难的样本序**。一个场景被反复采样只因为它「亏钱多」，而非因为它「此刻最可学」。极端时出现「难样本淹没」（hard-sample flooding）：模型还不会走就被迫跑，梯度方向互相抵消。
> 2. **低延迟与鲁棒性被硬耦合**：实时路径的 WCV 固定 `n_worst=16` 次物理编译 + CVaR 评估。球半径 r_t 因漂移膨胀时，这 16 次评估的**最坏时延不可控**——第 62 轮「≤1ms 契约」只是平均时延的胜利，p99 没有证书。
> 3. **学习率与回放是「无课程」的**：OLP 的 η_t = D/(G̃√t) 是时间调度而非难度调度；MEL-OA 回放按簇权重采样，容易在「险情尾部」系统性欠采样——而尾部恰是 CVaR 唯一关心、也是安全性唯一依赖的区域。
> 4. **J_rose 没有「延迟证书」**：它证明「安全」，却不证明「在 SLO 内安全」；无法回答「系统在 1ms 预算下是否仍满足 ρ_rob ≥ 0」。

## 0. 直觉与动机

**总直觉（两时间尺度解耦）**：课程学习想把算力花在「能力边界」（难而可学）上，低延迟推理想把算力花得越少越好（易则浅出）——直接相加会产生「**算力-难度反向拉扯**」。LADDER 的解法是把两条流在时间尺度上解耦：**学习算力只发生在语义流（离线于控制），推理算力只发生在实时流（在线于控制）**，二者只通过两个接口耦合：① 难度先验 d_t(s)（语义流产生，实时流据此选深度）；② 证书（实时流产生，语义流据此判断「学生」何时可被提拔）。课程不再只是「排数据」，而是「**排信任**」。

**灵感 1（课程学习 → DCL：难度度量 + 最近发展区 + 自步 pacing）**
直觉：真正的课程学习需要三件套——难度、发展区、节奏。定义可校准难度 d_t(s)=σ(α_u·U_ep+α_e·e_exec+α_n·novelty+α_g·Ĝ_c)。**最近发展区（ZPD）**不是固定区间，而是随「能力」λ_t 移动的窗口：只采样 d_t(s)∈[λ_t−δ, λ_t]，λ_t 由闭环 pacing 更新 λ_{t+1}=λ_t+γ(ĉ_t−c*)（ĉ_t 为成功率 EMA），使成功率稳定在 c*≈0.7——「可学但不轻松」。漂移触发时 λ 回退（re-warmup），而不是在旧课程上继续前进。

**灵感 2（课程学习 → PCR：带硬尾额度的课程回放）**
直觉：课程若只喂「刚好难」的样本，会患**尾部失忆**——最危险的稀有场景永远不在 ZPD 内。给回放加**硬尾额度**：每次适配 batch 至少 ρ_tail（如 20%）来自最高难度/CVaR 尾部，其余按课程权重 w_t(s) ∝ exp(−(d_t(s)−λ_t)²/2σ²)。课程负责「效率」，尾额度负责「保险」，二者正交、可分别证明。

**灵感 3（低延迟推理 → AIC：推理阶梯 + anytime 语义）**
直觉：把推理做成**阶梯** ℓ=0..3（缓存/代理 → 蒸馏 MEL+OLP → WCV 草案 → WCV 全量），每级有**认证成本 c_ℓ 与认证误差上界 ε_ℓ**（单调）。实时流在截止期内选**最深可行级**（just-enough inference）：ℓ*(t)=max{ℓ: c_ℓ ≤ τ_avail(t)}。任意时刻被打断，返回当前级的证书 (ℓ, ε_ℓ, latency)——这是 anytime 算法语义，把「必须算完」降级为「随时可交卷，且知道卷面误差上界」。

**灵感 4（低延迟推理 → SRC：带 Lipschitz 证书的投机鲁棒编译）**
直觉：ROSE 的 WCV 要 16 个最坏 φ 候选。但**鲁棒损失对 φ 是 Lipschitz 的**：sup_{φ∈B(φ̂,r)} CVaR_ε ℓ(K;φ) ≤ CVaR_ε ℓ(K;φ̂) + L_φ·r（CVaR 对损失变量本身 1-Lipschitz，复合后常数 L_φ）。于是先用**一次**点估计 + 廉价上界做「草案 + 验证」：若上界 ≤ ℓ_max 且 margin−L_m·r ≥ 0 则直接采纳（投机成功）；否则升级到全量 WCV。这是**声学的（sound）**投机——验证器绝不假接受，只可能假拒绝。平均只需 1~2 次编译，p99 由升级路径兜底。

**灵感 5（课程 × 低延迟 → PDD：渐进深度蒸馏，深路径当老师）**
直觉：把深 WCV 当 teacher、浅 surrogate 当 student，用课程管理「何时信任学生」：学生与 teacher 的**认证一致率** a_t 随部署增长；当 a_t ≥ 1−α 且尾额回放覆盖足够，**提拔**学生到更低延迟级；漂移使 a_t 下降则**降级**回 deep。延迟随能力**单调下降**，而不是靠手调阈值——「学会变快」本身是一条课程（self-distillation curriculum over inference depth）。

**灵感 6（合流 → LADDER：课程-延迟双阶梯闭环）**
三者咬合：DCL/PCR 回答「学什么、学多难」（语义流慢时间尺度）；AIC/SRC/PDD 回答「推多深、多快」（实时流快时间尺度）；LCR/PLC/DCC 提供「在 SLO 内且证书不倒」的调度与缓存。第 62 轮 ROSE 是「学习-鲁棒动态闭环」，LADDER 是「**课程-延迟双时间尺度闭环**」：难度上升 → 课程推进；延迟收紧 → 深度下探；两者只在证书边界处握手。

## 1. 形式化定义（增量：定义 185–196）

- **定义 185（LADDER 双阶梯框架）**：LADDER = (ROSE, DCL, AIC, SRC, LCR, PCR, PLC, DCC, CAL, J_ladder)。定位：ROSE 的「课程化 × 延迟化」升级，不改动任何既有接口。
- **定义 186（可校准难度与 ZPD）**：d_t(s)=clip(α_u·norm(U_ep)+α_e·norm(e_exec)+α_n·novelty+α_g·norm(Ĝ_c),0,1)，Σα=1；难度经保序回归校准使 d̂_t 单调逼近条件期望损失；ZPD_t=[λ_t−δ, λ_t]。
- **定义 187（自步课程 DCL）**：采样权重 w_t(s) ∝ exp(−(d_t(s)−λ_t)²/(2σ²))·𝟙[ZPD_t]；pacing λ_{t+1}=clip(λ_t+γ(ĉ_t−c*), λ_min, λ_max)；漂移（e_exec>τ_res 连续 W 步）触发 λ 回退。
- **定义 188（推理阶梯 AIC）**：级 ℓ∈{0,1,2,3}，认证成本 c_ℓ 单调不减、认证误差上界 ε_ℓ 单调不增；级 0 为 DCC 缓存/代理，级 3 为全量 WCV。
- **定义 189（anytime 路由 LCR）**：τ_avail(t)=(τ_SLO−τ_other(t))/load；ℓ*(t)=max{ℓ:c_ℓ≤τ_avail(t)}（无可行级则退级 0 保守）。输出延迟证书 (ℓ*, c_{ℓ*}, ε_{ℓ*}, r_t)。EDF 可行性：Σ WCET_i/period_i ≤ 1 且 deadline_i ≥ WCET_i。
- **定义 190（投机鲁棒编译 SRC）**：草案 K_d 用点估计；验证 V(K_d)=[CVaR_εℓ(K_d;φ̂)+L_φ·r_t ≤ ℓ_max] ∧ [margin(K_d,φ̂)−L_m·r_t ≥ 0]；V 真则采纳并出证书，否则升级全量 WCV。
- **定义 191（带尾额度的课程回放 PCR）**：p_t(s) ∝ (1−ρ_tail)·w_t(s) + ρ_tail·tailweight_t(s)，tailweight 依据 CVaR 尾部/失败计数；保证 batch 尾样本期望占比 ≥ ρ_tail。
- **定义 192（渐进延迟契约 PLC）**：τ_SLO(t)=max(τ_min, τ_init·γ^{⌊(t−t0)/T_phase⌋})，γ<1；**只收紧延迟**，安全域 𝒦、r_t、ℓ_max 不参与课程、永不放松。
- **定义 193（漂移补偿代理 DCC）**：级 0 输出 K_sur 仅在 age<τ_fresh 且 r_t≤r_cache 有效，否则失效并升级；误差界 ε_sur(t) ≤ ε_0 + L_s·r_t·(1+age/τ_fresh)。
- **定义 194（课程自适应学习率 CAL）**：η_{t,s} = (η_0/√(t+1))·(1+β_d·closeness(d_t(s),λ_t))，closeness∈[0,1]；步长比值 ∈[1,1+β_d]，遗憾仍 O(√T)。
- **定义 195（延迟-鲁棒证书 J_ladder）**：J_ladder = (J_rose, ℓ*, c_{ℓ*}, τ_SLO, a_t, d_t 版本, cache_ver)；Valid ⇔ Valid(J_rose) ∧ c_{ℓ*}≤τ_SLO ∧ ρ_rob≥0 ∧ (ℓ*>0 ∨ a_t≥1−α) ∧ cache_not_stale。
- **定义 196（LADDER 闭环算子）**：语义流（慢：难度估计→课程 pacing→PCR 回放→MEL-OA/OLP 更新→PDD 提拔/降级）∘ 实时流（快：LCR 选级→DCC/OLP/SRC/WCV→派发→延迟证书）。

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 1（廉价 sound 上界）**：CVaR_ε 对损失变量 1-Lipschitz（sup 范数），ℓ(K;·) 对 φ 为 L_φ-Lipschitz ⇒ sup_{φ∈B(φ̂,r)} CVaR_εℓ(K;φ) ≤ CVaR_εℓ(K;φ̂)+L_φ·r。故 SRC 验证器 **sound（无假接受）**，期望编译次数 = 1 + P(升级)。
- **引理 2（anytime 单调与 EDF）**：ε_ℓ 单调不增、c_ℓ 单调不减 ⇒ 任意中断点返回的 (ℓ,ε_ℓ) 是真误差合法上界；LCR 在 Σutil≤1 下 EDF 可调度（确定性 WCET），随机 WCET 由 Cantor 界控制违约概率。
- **定理 1（课程下遗憾不劣化）**：CAL 步长比值 ∈[1,1+β_d]，OGD 分析仅常数放大 ⇒ R_T ≤ (1+β_d)·D·G̃·√T；ZPD 采样降低有效梯度方差，经验收敛更快（E212）。
- **定理 2（尾部保持）**：PCR 硬尾额度使尾部簇每次适配采样概率 ≥ ρ_tail；遗忘界中尾项系数由 1 降为 (1−ρ_tail)，E216 校验尾部成功率保持 ≥95%。
- **定理 3（渐进深度安全）**：PDD 提拔需 a_t≥1−α 且 EMA≥τ_agree，降级由漂移触发；每级输出均携 sound 证书 ⇒ 任意时刻 ρ_rob≥0（机制保证，非假设）。
- **延迟-鲁棒 Pareto**：SRC 平均成本 = c_draft + p·(c_full+c_verify)，p 由 r_t 与 L_φ 决定；r_t→0 时 p→0（全投机），r_t 大/近边界时 p→1（退回 ROSE 全量）。两端都 sound，中间连续插值。

## 5. 本轮最大风险

**一句话**：低延迟快路径的「廉价鲁棒上界」依赖 Lipschitz 常数 L_φ（及安全裕度常数 L_m）的真实性——若 L_φ 由局部线性化低估（与 ROSE 的 J_φ 病态同源），SRC 会在 r_t 较大的漂移区间**假接受**，把「可证明的快速安全」偷换成「按平均情形校准的快速不安全」，而课程又恰好把难/尾部样本推向这些区间。

## 2. 形式化定义（完整版）

**定义 185（LADDER 双阶梯框架）** LADDER 是 ROSE 的课程化 × 延迟化升级：把「学什么/学多难」（DCL、PCR、CAL）放在语义流慢时间尺度，把「推多深/多快」（AIC、SRC、LCR、DCC）放在实时流快时间尺度，把「信任何时转移」（PDD）作为两者之间唯一的课程状态机。不变式：**学习写操作永不出现在实时路径；安全域永不参与课程**。

**定义 186（可校准难度与 ZPD）** 对场景 s，难度 `d_t(s)` 由四项归一化信号加权：认知不确定 `U_ep`、执行残差 `e_exec`、场景新颖度 `novelty`（到场景银行最近邻距离）、簇遗憾 `Ĝ_c`。以保序回归（isotonic regression）在线校准，使 `d̂_t` 对条件期望损失单调；ZPD 为 `[λ_t−δ, λ_t]`，δ=0.15。难度不是标签而是**可被证书校验的预测**（E211 用 Spearman ρ 校验）。

**定义 187（自步课程 DCL）** 采样权重 `w_t(s) ∝ exp(−(d_t(s)−λ_t)²/(2σ²))·𝟙[d_t(s)∈ZPD_t]`。Pacing 用闭环控制：`λ_{t+1}=clip(λ_t+γ(ĉ_t−c*), λ_min, λ_max)`，`ĉ_t` 为成功率 EMA，`c*=0.7`。漂移检测：若 `e_exec>τ_res` 连续 W=8 步，`λ ← λ_min+β_back(λ−λ_min)`（re-warmup），防止在已失效的旧课程上继续前进。

**定义 188（推理阶梯 AIC）** 四级：
- ℓ=0：DCC 缓存/代理查表（c₀ 最小，ε₀ 最大）；
- ℓ=1：蒸馏 MEL + OLP 前向；
- ℓ=2：WCV 草案（点估计 + SRC 验证）；
- ℓ=3：WCV 全量（`n_worst=16` 最坏 φ 候选，ε₃ 最小）。
认证成本 `c_ℓ` 单调不减、认证误差/鲁棒裕度规范 `ε_ℓ` 单调不增。阶梯保证：任一级输出都携带合法上界（见引理 2）。

**定义 189（anytime 路由 LCR）** 给定 `τ_avail(t)`，选 `ℓ*(t)=max{ℓ:c_ℓ≤τ_avail(t)}`；若无可行级，退回级 0 并标记 `conservative_fallback`（安全域收缩到 `K_BASELINE`）。EDF 可行性判据：`Σ_i WCET_i/period_i ≤ 1` 且每个 job 的 `deadline_i ≥ WCET_i`。随机 WCET 时以 Cantor 不等式给 deadline-miss 概率上界。

**定义 190（投机鲁棒编译 SRC）** 草案 `K_d = OLP.project(x)`（一次前向）。验证：
`V(K_d) = [CVaR_εℓ(K_d;φ̂) + L_φ·r_t ≤ ℓ_max] ∧ [margin(K_d,φ̂) − L_m·r_t ≥ 0]`。
`V` 真 ⇒ 采纳 `K_d` 并出证书（级 2）；`V` 假 ⇒ 升级 `wcv_compile` 全量（级 3）。**soundness**：由引理 1，`V` 通过蕴含真实鲁棒损失 ≤ ℓ_max 且真实裕度 ≥ 0，故无假接受；只有可能假拒绝（保守）。

**定义 191（带尾额度的课程回放 PCR）** 适配 batch 采样分布 `p_t(s) ∝ (1−ρ_tail)·w_t(s) + ρ_tail·tailweight_t(s)`，其中 `tailweight_t(s)` 按 CVaR 尾部排名与 `failure_count` 构造；硬约束：`k_tail=round(ρ_tail·k)` 个样本强制来自尾部。尾部额度是**硬保证**，不被课程权重稀释。

**定义 192（渐进延迟契约 PLC）** `τ_SLO(t)=max(τ_min, τ_init·γ^{⌊(t−t0)/T_phase⌋})`，γ=0.9，T_phase=500。**只收紧延迟维度**：安全域 𝒦、球半径 r_t、鲁棒损失阈值 ℓ_max 全程不参与课程、永不放松。这是「延迟课程」而非「安全课程」。

**定义 193（漂移补偿代理 DCC）** 级 0 缓存键为场景签名；命中条件 `age<τ_fresh ∧ r_t≤r_cache`。失效即升级。误差界 `ε_sur(t) ≤ ε_0 + L_s·r_t·(1+age/τ_fresh)`：漂移越大、锚点越旧，代理越不可信，误差界越宽——**用界而不是用阈值管理陈旧性**。

**定义 194（课程自适应学习率 CAL）** `η_{t,s}=(η_0/√(t+1))·(1+β_d·closeness)`，`closeness=max(0,1−|d_t(s)−λ_t|/δ)`。ZPD 内样本步长放大至多 `1+β_d`；比值有界，故 OGD 遗憾仅常数放大（定理 1）。

**定义 195（延迟-鲁棒证书 J_ladder）** `J_ladder=(J_rose, ℓ*, c_{ℓ*}, τ_SLO, a_t, d_ver, cache_ver)`。
`Valid(J_ladder) ⇔ Valid(J_rose) ∧ c_{ℓ*}≤τ_SLO ∧ ρ_rob≥0 ∧ (ℓ*>0 ∨ a_t≥1−α) ∧ cache_not_stale`。
新增字段使「本轮用了多深的推理、是否在 SLO 内、学生是否已被认证提拔、代理是否新鲜」全部可审计。

**定义 196（LADDER 闭环算子）** 见 IP-202 伪代码：语义流 `[难度估计 → pacing → PCR 采样 → MEL-OA/OLP 更新 → PDD 提拔/降级 → 银行/遗憾记账]`；实时流 `[LCR 选级 → DCC 命中/失效 → OLP 前向 → SRC 验证/升级 → 派发 → J_ladder]`。

### IP-193 DCL（难度课程阶梯）

```python
class DifficultyCurriculumLadder:
    def __init__(self, alpha=(.3,.3,.2,.2), lambda0=0.3, gamma=0.05,
                 c_star=0.7, delta=0.15, sigma=0.1, lambda_min=0.1,
                 lambda_max=0.95, drift_window=8, tau_res=RES_TAU,
                 beta_back=0.5):
        self.a = alpha; self.lam = lambda0; self.gamma = gamma
        self.c_star = c_star; self.delta = delta; self.sigma = sigma
        self.lmin, self.lmax = lambda_min, lambda_max
        self.drift_window = drift_window; self.tau_res = tau_res
        self.beta_back = beta_back; self.drift_cnt = 0

    def difficulty(self, U_ep, e_exec, novelty, Ghat_c):
        a0, a1, a2, a3 = self.a
        raw = (a0*norm(U_ep) + a1*norm(e_exec)
               + a2*novelty + a3*norm(Ghat_c))
        return float(np.clip(raw, 0.0, 1.0))     # 可再经保序回归校准 d_hat

    def weight(self, d):
        in_zpd = float(self.lam - self.delta <= d <= self.lam)
        return in_zpd * np.exp(-((d - self.lam)**2) / (2*self.sigma**2))

    def step(self, success_ema, e_exec):
        # 漂移 → 回退课程（re-warmup），而非在失效课程上前进
        self.drift_cnt = self.drift_cnt + 1 if e_exec > self.tau_res else 0
        if self.drift_cnt >= self.drift_window:
            self.lam = self.lmin + self.beta_back * (self.lam - self.lmin)
            self.drift_cnt = 0
        else:
            # 成功率高于目标 → 上调难度；低于 → 下调
            self.lam = float(np.clip(
                self.lam + self.gamma * (success_ema - self.c_star),
                self.lmin, self.lmax))
        return self.lam
```

    def __init__(self, cascade, tau_slo, tau_other=0.0, reserve_slack=0.15):
        self.cas = cascade; self.tau_slo = tau_slo
        self.tau_other = tau_other; self.reserve = reserve_slack

def cal_eta(eta0, t, d, lam, delta=0.15, beta_d=0.5):

## 4. 推导

**引理 1（廉价 sound 上界）** 设 φ↦ℓ(K;φ) 关于 φ 为 L_φ-Lipschitz。CVaR_ε 有对偶表示 `CVaR_ε(X)=max_{Q∈𝒬_ε} E_Q[X]`，𝒬_ε 为概率测度集。对任意 X,Y：`|CVaR_ε(X)−CVaR_ε(Y)| = |max_Q E_Q X − max_Q E_Q Y| ≤ max_Q E_Q|X−Y| ≤ ‖X−Y‖_∞`，故 CVaR 关于损失变量 1-Lipschitz（sup 范数）。于是对任意 φ∈B(φ̂,r)：
`CVaR_εℓ(K;φ) ≤ CVaR_εℓ(K;φ̂) + sup_ω|ℓ(K;φ,ω)−ℓ(K;φ̂,ω)| ≤ CVaR_εℓ(K;φ̂)+L_φ r`。
对 φ 取 sup 得 `sup_{φ∈B}CVaR_εℓ(K;φ) ≤ CVaR_εℓ(K;φ̂)+L_φ r`。∎
推论（SRC soundness）：若 `V(K_d)` 通过，则真实鲁棒损失 ≤ ℓ_max 且真实裕度 ≥ 0，故**无假接受**；期望编译次数 `E[N] = 1 + P(ub>ℓ_max ∨ margin_lb<0)`。

**引理 2（anytime 单调性与 EDF）** 因 `c_ℓ` 单调不减、`ε_ℓ` 单调不增，`ℓ*(t)` 是预算内最深级，其返回的 `(ℓ*,ε_{ℓ*})` 对真实误差是合法上界；任意中断点等价于更浅级，界仍成立（anytime 语义）。确定性 WCET 下，约束截止期任务的 EDF 可调度充要条件为 `Σ WCET_i/period_i ≤ 1` 且 `deadline_i ≥ WCET_i`；随机 WCET 时由 Cantor 不等式 `P(miss) ≤ exp(−2m(1−util)²)` 控制（m 为独立 job 数）。

**定理 1（课程下遗憾不劣化）** CAL 步长 `η_{t,s}=η_base(1+β_d·closeness) ∈ [η_base, (1+β_d)η_base]`。OGD 标准分析中梯度范数上界被放大至 `(1+β_d)G̃`；取 `η_t=D/((1+β_d)G̃√t)` 仍得
`R_T ≤ D·G̃(1+β_d)√T`。
即课程只放大常数、不改变 √T 率。另一方面 ZPD 采样使有效样本的梯度方差下降，收敛常数项改善（E212 实证）。∎

**定理 2（尾部保持）** PCR 以概率 ≥ ρ_tail 采样尾部样本。MEL-OA 的一步遗忘界中，尾部簇项系数由 1 降为 (1−ρ_tail)：
`ΔL_tail ≤ (η_adapt G²)/(2λ_F σ_min(F)) + (1−ρ_tail)·Δ_shift`。
EWC 项 `λ_F` 与尾额度 `ρ_tail` 正交叠加：前者压参数漂移，后者保样本覆盖。故尾部成功率得以保持（E216：≥95% vs 无尾额度 70%）。∎

**定理 3（渐进深度安全）** PDD 状态机仅在 `a_t≥1−α` 且 `agree_ema≥τ_agree` 时提拔，漂移 `drift>1.5r_ref` 时降级。每级输出都携带 sound 证书（级 2 为 SRC 上界，级 3 为全量 WCV）。提拔只是选择更浅的**已认证**级，不放松证书本身；降级只是回到更深级。故任意时刻 `ρ_rob≥0` 与 `c_{ℓ*}≤τ_SLO` 同时成立（机制保证，非假设）。∎

**命题（延迟-鲁棒 Pareto 插值）** SRC 平均成本 `E[c] = c_draft + p·(c_full+c_verify)`，其中 `p=P(升级)` 随 `r_t` 与 `L_φ` 单调增：`r_t→0` 时 `p→0`（全部投机成功，延迟逼近级 1/2）；`r_t` 大或接近安全边界时 `p→1`（退回 ROSE 全量）。两端均 sound，故 LADDER 在 ROSE（全量、慢、强）与纯投机（快、弱）之间给出**连续且可证的 Pareto 插值**。∎

- **(A78)** 难度校准：`d̂_t` 对条件期望损失保序（单调）且 Spearman ρ 有下界。
- **(A79)** 阶梯 WCET 估计 `c_ℓ` 为真实时延上界（由离线剖析 + 运行时监控共同维护）。
- **(A80)** PDD 一致率估计 `a_t` 为 PAC 估计（Hoeffding 型集中）。
- **(A81)** PCR 尾部采样器无偏（重要性加权），`tailweight_t` 良定义。
- **(A82)** 缓存失效原子；陈旧读不超过 `τ_fresh`（继承 A75）。

则：
1. **可证低延迟**：任意时刻 `c_{ℓ*}≤τ_SLO` 且输出携 sound 鲁棒证书；SRC 假接受率 = 0，平均编译次数 `1+P(升级)`，p99 由升级路径 + 预留 slack 兜底。
2. **课程有效且不破坏收敛**：ZPD+pacing 使难簇收敛更快（E212），OLP 遗憾仍 `O((1+β_d)√T)`。
3. **尾部不失忆**：PCR 硬尾额度使尾部簇采样 ≥ ρ_tail，尾部成功率保持 ≥95%。
4. **渐进深度安全**：PDD 只在认证一致时提拔、漂移时降级，任意时刻 `ρ_rob≥0`。
5. **延迟-鲁棒可插值**：SRC 在 ROSE 全量与纯投机之间连续插值，两端均 sound。
6. **审计完整**：J_ladder 使「推了多深、是否超 SLO、学生是否被认证、缓存是否新鲜」全部可回放审计。

## 7. 已知风险

**一句话**：低延迟快路径的「廉价鲁棒上界」依赖 Lipschitz 常数 `L_φ`（及安全裕度常数 `L_m`）的真实性——若 `L_φ` 由局部线性化低估（与 ROSE 的 `J_φ` 病态同源），SRC 会在 `r_t` 较大的漂移区间**假接受**，把「可证明的快速安全」偷换成「按平均情形校准的快速不安全」，而课程又恰好把难/尾部样本推向这些区间。

**次级风险与缓解**：
1. **L_φ 低估 / 强非线性**：用区间算术或对偶界给 `L_φ` 的可验证上界，并对证书做保守膨胀；E214 对抗球扫掠专测假接受。
2. **课程尾部饥饿（curriculum starvation）**：课程权重天然偏向 ZPD，尾部可能被长期排除 → PCR 硬尾额度 + 监控尾部成功率，低于阈值即提高 ρ_tail。
3. **难度度量过时**：漂移使 `d_t` 与真实损失脱钩 → 漂移触发 re-warmup + 周期保序重校准（E211 在线监控 ρ）。
4. **WCET 估计错误**：`c_ℓ` 低估导致超时 → 预留 slack + 运行时 p99 监控 + 超时强制降级级 0 保守。
5. **PDD 提拔过早**：学生可能在训练分布上"模仿"teacher 但在尾部不一致 → PAC 一致率 + 分布漂移检测 + 定期 teacher 全量复核。
6. **三重学习耦合（OLP + MEL-OA + PDD）**：三者同时更新可能互相追逐 → 奇偶步交替更新 + 关联锁 + 证书不通过即冻结提拔。
