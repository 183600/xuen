### 第 1 轮灵感驱动研究记录（新循环；继承 CADVS-v5）

**灵感词**：遥操作、柔顺控制

**继承关系**：承接上一循环第 5 轮 CADVS-v5（IP-493~496，认证生成式执行 CGE，Exec_v5 ⊆ Exec_v4 ⊆ … ⊆ Exec_v29）。v5 把提议从规则库升级为流匹配生成器、把记忆做成固化闭环、把人因升级为情感调制，但它的**被认证对象仍是一条离线轨迹** x=(pose_{0:T}, wrench_{0:T})。本轮两个灵感词暴露 v5 的**本体论缺陷**：在遥操作 + 接触任务中，wrench 不是可离线自由指定的变量，而是「阻抗参数 × 环境动力学」的涌现结果；同一条 pose 轨迹在不同环境刚度下产生完全不同的 wrench，因此对 wrench 轨迹逐点认证在接触场景下是**不 sound** 的（软环境过松、硬环境过紧）。同时遥操作的通信延迟会破坏无源性，v5 的 BCK 只做静态平衡/力矩锥检查，读不到「人—延迟—机器人—环境」闭环里的能量回流。据此提出 CADVS-v6「认证遥操作-柔顺执行」（Certified Teleoperation-Compliant Execution, CTCE）：核心是**把被认证对象从「轨迹」搬到「闭环能量/无源性证书」**，且**不新增硬门**（延续 R52 锚点维护自律）——物理门 kc_phys 重铸为鲁棒无源性证书、平衡门 kc_bal 重铸为能量罐/波变量预算、人因门 kc_hick 扩为无源性保序的权威混合，再加一个**跨门的时间有效性包装**（证书过期即 fail-closed）。执行集升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5。

**直觉与动机**：

1. **柔顺控制 → 认证对象从「轨迹」变成「阻抗律 + 能量预算」**。直觉：柔顺控制的本质是「让机器人顺着接触力走」，真正决定安全的是 K_d/D_d/M_d 与环境交互的**闭环能量流**，而不是某个预设 wrench。v5 对 wrench 逐点设门，在环境未知时既可能过松（软环境）也可能过紧（硬环境），这是结构性缺陷而非参数问题。v6 用端口哈密顿（port-Hamiltonian）统一描述：ẋ=(J−R)∇H+Gu+F_ext，阻抗律作为控制端口，环境不确定集 E 覆盖刚度/阻尼/接触位置。**定理 9（鲁棒无源性证书 soundness）**：若证书保证 ∀E∈E、∀t 能量罐 T(t)≥0 且耗散不等式成立，则闭环对人—机—环境整体 L2 稳定，且对 E 内任意环境成立——这是「对一整族环境一次认证」，而不是对名义环境认证。副产品 **定理 12（刚度/阻尼单调性）** 给出证书在 (K_d,D_d) 单调盒上的免费迁移：一个证书覆盖一族阻抗参数，避免逐点重算。

2. **遥操作 → 延迟把「稳定性」变成一等公民，能量罐/波变量成为硬预算**。直觉：遥操作里人是远端的、有延迟的控制器；恒定延迟可用波变量变换做到无源，但**时变延迟/抖动**必须靠能量罐或 TDPA 注入阻尼。v5 的 BCK 只检查瞬时力/力矩平衡，读不到「延迟导致能量回流」。v6 把 kc_bal 重铸为**能量罐预算门**：从人侧注入的能量必须先入罐，罐空即禁止会注入能量的动作（fail-closed）。**定理 10（证书时间有效性/新鲜度）** 把延迟与扰动变成证书的「保质期」：证书在 t0 有效不代表在 t0+τ 有效；门裕度 m_i=s_i−τ_i 在扰动下有 Lipschitz 漂移界 L_i，故有效视界 Δ_i=m_i/L_i，过期即重认证。这把「实时性」从工程指标升级为**可证明的安全性条件**，正面回应 v5 遗留的 R54/实时性负债。

3. **遥操作 + 柔顺 → 人机权威混合必须是无源保序的，否则共享控制本身成为攻击面**。直觉：遥操作天然是「人给一部分、自主给一部分」的共享控制；若用朴素的力/位凸组合混合两路指令，可能在接口处凭空注入能量——两路各自无源，混合后不无源。**定理 11（权威混合保序/不变性）**：只有能量域/波变量域的混合满足耗散不等式；力域凸组合可被构造出能量注入反例。因此 CABK 把人类权威 α 与自主权威 1−α 的混合限制在无源保序算子族内，且混合后证书边界与 α 无关（人只能在已认证集合内选择，不能把集合扩大）；可选的安全权威 β_safety≥1 只紧不松，与 v5 情感调制同构。人因门 HICK 由此从「意图 veto」升级为「意图 veto + 权威混合无源性」，仍是同一锚点。

**关键洞见**：v5 回答「提议可换成任意生成器时证书边界是否不变」；v6 回答「当被控对象是带延迟的人—机—环境闭环、执行器是柔顺阻抗时，证书到底应该认证什么」。答案：认证**能量/无源性**而非轨迹；证书是**带保质期的、对不确定环境族鲁棒的、在人机权威混合下保序的**。七硬门数量不变，但 kc_phys/kc_bal/kc_hick 三者被重铸到能量空间，另加跨门新鲜度包装 TVW（包装不是新锚点）。嵌套 Exec_v6 = {x^6 : π_v5(x^6)∈Exec_v5 ∧ kc_phys^PHCK=1 ∧ kc_bal^ETBK=1 ∧ ∧_i f_i>0} ⊆ Exec_v5 由「投影约束 + 只紧阈值 + 过期即拒」三重保证。

**形式化目标（增量）**：
1. 端口哈密顿闭环：ẋ=(J−R)∇H+Gu+F_ext；阻抗律 u=−(M_d ẍ+D_d ẋ+K_d(x−x_d))；环境族 E={K_e∈[K⁻,K⁺], D_e∈[D⁻,D⁺], x_c∈X_c}。
2. 能量罐：Ṫ=β(uᵀy)⁺−γ(uᵀy)⁻−P_diss，T≥0；波变量 u_w=(1/√2b)(F+bv)、v_w=(1/√2b)(F−bv)。
3. TVW：证书 c_i 携带有效期 Δ_i=m_i/L_i；新鲜度 f_i(t)=max(0,1−(t−t_i)/Δ_i)；f_i=0 ⇒ 该门 fail-closed。
4. CABK：权威混合算子 B_α 限定在无源保序族；能量域混合下 Exec_v6 与 α 无关（不变性），安全权威 β_safety≥1 只紧。
5. 定理 9（鲁棒无源 soundness）、定理 10（新鲜度视界）、定理 11（权威混合保序/不变）、定理 12（刚度单调证书迁移）、定理 13（七锚完备性保持）。
6. EFA-v6：先做能量可行性廉价预筛 → VACK → BCK 预览；ECS_v6=ECS_v5·η_pass·η_fresh。

**本轮最大风险**：**环境不确定集与延迟上界不可在线验证**——鲁棒无源性证书只相对于假设的 (E, τ_max) 成立，真实环境/延迟一旦越界，证书被静默作废，而能量罐耗尽会把失效放大成「冻结或瘫软」的突变，恰在最需要柔顺的接触瞬间最危险。

@dataclass
class EnergyTankWaveBudgetKernel:
    """ETBK：时变延迟下的无源能量预算；罐空即 fail-closed 禁止注入能量动作"""
    b: float = 100.0
    T0: float = 1.0
    Tmax: float = 2.0
    beta: float = 0.90            # 充电效率（<1 保证离散安全）
    gamma: float = 0.95           # 放电系数
    P_diss: float = 0.01          # 基础耗散

    def wave_encode(self, F, v):
        return (F + self.b*v)/sqrt(2*self.b), (F - self.b*v)/sqrt(2*self.b)

        power = float(u @ y)

### IP-499 TVW：证书时间有效性包装（跨门，O(1)/门）

```python
@dataclass
class TemporalValidityWrapper:
    """TVW：给每个门证书加保质期；过期视为失败（只紧），故嵌套保持。
    不新增门，只是所有门的统一后处理"""
    def wrap(self, gate_cert, margin, lipschitz_L, t_now) -> FreshCert:
        delta = margin / max(lipschitz_L, 1e-9)
        return FreshCert(cert=gate_cert, t_cert=t_now, horizon=delta)

    def valid(self, fc: FreshCert, t_now) -> bool:
        return fc.cert.ok and (t_now - fc.t_cert) < fc.horizon

    def freshness(self, fc: FreshCert, t_now) -> float:
        if fc.horizon <= 0: return 0.0
        return max(0.0, 1.0 - (t_now - fc.t_cert)/fc.horizon)
```

### IP-500 CABK：认证权威混合核（准入/人机接口，保序）

```python
@dataclass
class CertifiedAuthorityBlendingKernel:
    """CABK：人类权威 α 与自主 1-α 在波域/能量域混合，保序。
    定理 11：力域凸组合可注入能量；波域/能量域混合保持耗散不等式，
    且 Exec 与 α 无关——人只能在已认证集合内选择，不能扩大集合"""
    etbk: EnergyTankWaveBudgetKernel

    def blend(self, human_cmd, auto_cmd, alpha: float, tank: float, dt: float):
        hw = self.etbk.wave_encode(human_cmd.F, human_cmd.v)
        aw = self.etbk.wave_encode(auto_cmd.F, auto_cmd.v)
        w = tuple((1-alpha)*a + alpha*h for a, h in zip(aw, hw))  # 波域插值
        F, v = self._decode(w)
        T, ok = self.etbk.step(tank, F, v, dt)
        if not ok:
            F, v = self._damp(F, v)          # 罐空：只紧，裁剪为高阻尼保持
        return Control(F=F, v=v, tank=T, pass_ok=ok)

    def safety_authority(self, beta_safety: float, xi: float) -> float:
        """β_safety≥1 只紧：增大安全权威只会缩小可达能量，不放大"""
        return max(beta_safety, 1.0) * xi
```

### IP-501 EFA-v6：七硬门 + 能量预筛 + 新鲜度包装

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：七门数量不变（能量重铸）+ 证书新鲜度 + 级联采样"""
    fmpp: Any; lmem: Any; famk: Any
    phck: PortHamiltonianComplianceKernel
    etbk: EnergyTankWaveBudgetKernel
    cabk: CertifiedAuthorityBlendingKernel
    tvw: TemporalValidityWrapper
    v5: EvidenceForgingAssemblerV5

    def select(self, x0_state, t_now, rule_id, context) -> tuple[bool, Any, str]:
        gamma = self.famk.gamma(self.famk.observe(context.face, t_now))
        c = build_ctx_v6(context, self.lmem)             # 含 θ_imp/α/T0/τ̂
        cands = self.fmpp.propose(c, self.fmpp.K)        # K=8，异步准入
        # 级联第 1 层：能量可行性廉价预筛（PHCK 顶点界 + ETBK 罐）
        surv = []
        for x in cands:
            pc = self.phck.certify(x.theta_imp, x.pose, x.T0, c.tau_hat)
            if pc.ok and self.etbk.precheck(x.T0):
                surv.append((x, pc))
        if not surv:
            return self._fallback_rule_proposal(gamma)   # fail-closed 回退 v5 规则提议
        # 级联第 2 层：VACK 仅评 ≤3 幸存者
        surv.sort(key=lambda t: t[1].xi_pass, reverse=True)
        finals = []
        for x, pc in surv[:3]:
            vac = self.v5.vack.evaluate(project_v5(x), context_with(gamma), t_now)
            if self.v5.vack.kc_val(vac, tau=gamma['val'] * TAU_VAL4):
                finals.append((x, pc))
        # 级联第 3 层：BCK 预览 + TVW 新鲜度
        ok = []
        for x, pc in finals:
            fc = self.tvw.wrap(pc, pc.margin, pc.lipschitz_L, t_now)
            if self._bck_preview(project_v5(x), gamma) and self.tvw.valid(fc, t_now):
                ok.append((x, fc))
        if not ok:
            return False, None, 'ALL_CANDIDATES_REJECTED'
        best = max(ok, key=lambda t: t[0].certified_margin)   # 边际最大者
        return True, best[0], 'FORGED_CTCE'

    def ecs_v6(self, base_args, n_flow, s_emo, xi_pass, fresh) -> float:
        eta_pass = sigmoid((xi_pass - self.phck.xi_min) / 0.05)
        eta_fresh = fresh
        return self.v5.ecs_v5(base_args, n_flow, s_emo) * eta_pass * eta_fresh
```

## 4. 正确性论证（增量更新）

### 引理 45（能量罐离散化耗散界）

**陈述**：Euler 离散一步的数值能量误差 ≤ C·dt·‖uᵀy‖∞；当 β<1、γ<1 且 dt≤dt_max 时，离散罐在 power<0 段单调不增。**证明**：一步 Taylor 余项 + 充电效率折扣，取 C 为端口映射 Lipschitz 常数。∎

### 引理 46（波变量延迟无源性）

**陈述**：恒定延迟下波变量通道满足 ∫uᵀy dt ≤ ½‖w(0)‖²；时变延迟需 TDPA 补偿，补偿注入量有界且可被能量罐吸收。**证明**：波变量能量泛函沿通道守恒，延迟只平移不改变符号；时变项由 TDPA 阻尼界约束。∎

### 引理 47（门裕度漂移 Lipschitz 界）

**陈述**：扰动功率 ≤ P_max、延迟 ≤ τ_max 下，|ṁ_i| ≤ L_i = c_i·(P_max + ‖∂s_i/∂x‖·v_max)，故 Δ_i=m_i/L_i 内 m_i 不变号。**证明**：s_i 对状态 Lipschitz，状态变化率由功率界控制。∎

### 引理 48（环境族区间算术 soundness）

**陈述**：若 E 用区间/顶点表示且系统对 E 单调（或极值在顶点取到），顶点枚举给出 worst-case 的 sound 下界；非线性接触用保守包络。**证明**：区间算术包含性 + 顶点极值性。∎

### 定理 v6（鲁棒无源、时间有效、权威保序的嵌套，总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) 环境∈E、延迟≤τ_max 下：
(i) Exec_CADVS-v6 ⊆ Exec_CADVS-v5（投影约束 + 只紧阈值 + 过期即拒）⊆ … ⊆ Exec_v29；
(ii) 鲁棒无源：kc_pass 认证 ⇒ 对 E 内任意环境 L2 稳定（定理 9）；
(iii) 时间有效：只消费新鲜证书，视界外 fail-closed（定理 10）；
(iv) 权威保序/不变：波域混合下 Exec 与 α 无关，β_safety 只紧（定理 11）；
(v) 证书迁移：K_d↓/D_d↑ 单调盒免费迁移（定理 12）；
(vi) 七锚完备性保持（定理 13）。
**证明**：(i) 由 π_v5 + 只紧 + TVW；(ii) 定理 9；(iii) 引理 47 + 定理 10；(iv) 定理 11；(v) 定理 12；(vi) 定理 13。∎

**诚实声明**：(B8) 的环境族与延迟上界**不可在线验证**，鲁棒性只相对于假设成立；能量罐耗尽时系统会主动降级为高阻尼保持（可能「冻结」），这是安全但影响任务的突变；刚度迁移依赖过阻尼与单调性假设，欠阻尼/多接触模态下需逐点认证；接触摩擦/形变/粘滑使无源性证明可能失效，只能靠能量罐硬兜底与红队检测；加性价值假设 (B4) 继承自 v4，仍未解决。
