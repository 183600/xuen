# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「强化学习」×「技能学习」）

> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> **本轮纪律**：**护盾化探索 + 契约化技能 + 经验-证书对偶**。v9 把算力省下来了、把退化声明化了，但策略仍是冻结的、模块仍是手写的——系统有经验，却没有把经验变成能力的机制。强化学习提供"从经验改进决策"，技能学习提供"把长时程压成可复用单元"；本轮要回答的不是"能不能训一个更大的网络"，而是"怎样让学习发生在一条已经严格定义的安全退化链之内"，使一次更新、一个新技能、一次经验提升都可被证书审计。

## 0. 直觉与动机

**灵感 1（强化学习 → 护盾内的保守策略改进）**
直觉：RL 的威力来自试错，但机器人在真实世界没有试错的资格。常见的"先仿真再部署"在域偏移下会失效，而 DA-ML 恰好在测域偏移。我的关键选择是：**不让 RL 控制底层动作**，只让它在 v9 已经认证过的技能集合里做选择、排序与组合——把探索从"连续动作空间"搬到"离散技能空间"。再叠两层保险：(i) 由 M₀/SpatialCert/块证书/停车不变式构成的**硬护盾**把不可行技能的概率严格置零（不是加惩罚，而是投影）；(ii) 策略更新采用**安全策略改进（Safe Policy Improvement, SPI）**：只有候选策略的悲观回报下界不劣于行为策略、且软成本上界不超预算时才接受。直觉上，RL 不再"发明新动作"，而是"发现更好的技能调度"——这与 v9 的契约中间件同构，因而能共用同一张退化表。

**灵感 2（技能学习 → 带契约的 option）**
直觉：技能学习（option / skill discovery）把"走 20 步的抓取"压成一次决策，缩短信用分配链、复用经验、降低规划维度。但技能一旦学错，组合会放大错误：一个后置条件不成立的技能后面再接一个技能，就是一次无声的越界。所以我的核心主张是：**技能必须像中间件模块一样携带契约**——前置条件 Pre、后置条件 Post、过程不变式 Inv、最坏时长 D_max、失败概率上界 ε、中立回退 v^⊥。只有当"前一个技能的后置条件与不变式蕴含后一个技能的前置条件"时，才允许顺序组合（Hoare 式三段论）。技能因此不是"多学几个策略"，而是"在既有安全代数里增加可组合的证明单元"。

**灵感 3（经验 → 技能蒸馏与课程）**
直觉：v9 的 AC 已在 5Hz 产块、50Hz 执行，日志里天然有大量「信念-动作块-结果」轨迹。把这些轨迹里反复出现、终止条件稳定的片段**提升（promote）为技能候选**，用离线 RL/行为克隆训练，经影子验证与契约检查后才入册——技能库因此是随经验增长的活文档，而不是一次性写死的模块集合。同时用**能力（competence）置信下界**决定"何时敢调用"某个技能。这样"技能学习"与 v9 的"创新点蒸馏器"形成对偶：ID 决定"哪些模块值得算力"，ESD 决定"哪些经验值得成为技能"。

## 1. 研究问题（轮次升级版）

- **Q1（护盾下探索）**：如何把探索限制在安全可行核（viable kernel）内，使任何一次 RL 探索都不离开 M₀ 安全不变式？护盾的"可行"判断本身依赖前向模型，如何避免护盾被策略反向利用？
- **Q2（技能契约组合）**：在部分可观测与感知有界误差下，什么形式的 Pre/Post/Inv 契约能保证顺序组合的可靠性可传递（组合后失败概率只按联合界增长、时延可加）？
- **Q3（模型利用与奖励黑客）**：当 RL 优化器与证书共享同一个（可能失准的）模型时，如何用集合分歧、共形校准与悲观成本界，使策略无法系统性地钻证书的空子？
- **Q4（经验-证书对偶）**：技能提升判据如何同时约束复用价值、能力置信与安全契约，并保证"全部新组件关掉"时严格退化回 v9？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 护盾探索律（Shielded Exploration, SSP）**
策略只能在护盾集 Sh(b) 内取非零概率：π^Sh(ω|b) ∝ π(ω|b)·1[ω∈Sh(b)]。护盾是硬投影，不是软惩罚。Sh(b) 要求技能前置条件成立、能力置信下界达标、M₀ 预检通过、且其 v9 动作块存在满足停车不变式的中止点。**护盾不可被奖励信号覆盖**——RL 无权学习"打开护盾"。

**P14 技能契约组合律（Skill Contract Composition, CSL）**
技能 ω=(I_ω, π_ω, β_ω, C_ω, ρ_ω)，其中 C_ω=(Pre_ω, Post_ω, Inv_ω, D_ω^max, ε_ω, v_ω^⊥)。顺序组合 ω₁⊳ω₂ 有定义当且仅当 Post_{ω₁}∧Inv_{ω₁} ⇒ Pre_{ω₂}；组合契约按三段论导出，D 相加、ε 按联合界相加、v^⊥ 取后者（保证退化到 v9 单步块）。组合只在离线/入册期做静态检查，运行期不再拼装未知契约。

**P15 经验-证书对偶律（Experience-Certificate Duality, ESD）**
每条经验只有在能附带可验证证书时才可入册或部署。提升一个技能需同时满足：复用频次、终止稳定性、契约留出验证、覆盖新颖度、影子安全。没有证书的更新等价于"不更新"：策略冻结在 v9 行为策略 π_b，只影响调度、不影响安全。

## 3. 直觉如何落成严谨定义（预告）

- **技能 MDP**：把 POMDP 的信念空间 B 与技能库 Ω 组成约束技能 MDP，动作是"调用哪个 option"而非电机指令；
- **带契约技能**：C_ω 是 Hoare 三元组在部分可观测下的推广，可靠性定义为"前置成立 ⇒ 以 ≥1−ε 到达后置且全程不变式成立"；
- **护盾集与可行核**：Sh(b) 是安全动作集的保守内近似；存在可行核 V 使 b∈V ⇒ Sh(b)≠∅ 且后继仍以高概率留在 V，从而用归纳法把安全从单步推到整条轨迹；
- **安全策略改进**：用行为策略的重要性采样构造回报下界 J⁻ 与软成本上界 C⁺，接受规则同时约束回报、成本、KL 信任域与有效样本量（ESS）；
- **能力门控**：ρ_ω 用 Beta 后验，只有 LCB_δ(ρ_ω) ≥ ρ_min 才允许调用，失败概率由此获得有限样本界；
- **共形证书**：把 v9 固定余量 β 升级为共形分位数 q̂_{1−α}，在可交换假设下给出分布无关覆盖；域偏移时由 DA-ML 门控并切换到加权共形，避免"β 拍脑袋"；
- **提升判据**：Promote(σ) = 复用 ∧ 终止稳定 ∧ 契约留出验证 ∧ 新颖度 ∧ 影子安全，缺一不升。

## 4. 与 v9 基线的接口（如何退化）

- SSP 失效（更新被 SPI 拒绝 / 规划超时）⇒ 策略冻结为 π_b = π_v9，动作序列与 v9 逐位等价；
- CSL 失效（契约检查失败 / 技能库不可用）⇒ Ω 退化为 {primitive_chunk}，每个技能的中立元就是 v9 的单步块；
- ESD 失效（提升判据不满足）⇒ 技能库冻结、不入新技能，等价 v9 模块集合；
- v9 的 AC/MW/ID 任一失效 ⇒ 走 v9 原退化链到 v8；
- v8 的 DA/SPR/Cal 任一失效 ⇒ 中立元注入，等价 v7；全失效 ⇒ 完整退回 v6。

**关键纪律**：RL 与技能的任何更新都在**块边界屏障**处双缓冲换入，绝不在一个已认证动作块的中途换策略——否则"证书是对旧策略签发的、动作却由新策略执行"，证书立即失效。

## 5. 本轮最大风险

**一句话**：RL 的优化目标与安全证书共享同一个可被策略利用的前向模型，一旦技能策略学会把状态驱动到"集合内成员一致、但共同偏离真实动力学"的区域，护盾会给出虚假的安全证明——优化器不是在绕过护盾，而是在利用护盾模型的**相关误差**，使安全在最需要时被系统性地高估。

## 2. 形式化定义

**定义 540（约束技能 MDP）** 给定 POMDP 的信念空间 B 与技能库 Ω，定义
```
M_Ω = (B, Ω, P_Ω, r, c, γ),   c(b,ω) = (c_safe, c_effort, c_affect)
```
其中 P_Ω(b'|b,ω) 为在 b 启动技能 ω、按其终止条件 β_ω 停机后到达 b' 的迁移；r: B×Ω→ℝ 为任务奖励；c_safe 为硬安全成本（由护盾强制为 0），c_effort 与 c_affect 为软成本（努力超限、情感漂移）。策略 π: B→Δ(Ω)。硬安全不进 RL 的奖励，避免"用奖励买安全"。

**定义 541（带契约技能）** 技能
```
ω = (I_ω, π_ω, β_ω, C_ω, ρ_ω)
```
- I_ω ⊆ B：启动集；β_ω: B→{0,1}：终止条件；π_ω: B→Δ(A)：技能内底层策略；
- C_ω = (Pre_ω, Post_ω, Inv_ω, D_ω^max, ε_ω, v_ω^⊥)，Pre/Post/Inv 为信念谓词，D_ω^max 为最坏控制周期，ε_ω∈[0,1] 为失败概率上界；
- v_ω^⊥ = primitive_chunk：技能失效时回退到 v9 单步块（不是空动作），保证退化语义；
- ρ_ω ~ Beta(a_ω,b_ω)：能力后验，成功 +1、失败 +1。

**定义 542（契约可靠性）** 若对所有 b⊨Pre_ω，执行 ω 至 β_ω 或 D_ω^max 为止，有
```
Pr[b'⊨Post_ω ∧ Inv_ω  ∧  ∀t≤D: Inv_ω(b_t)] ≥ 1 − ε_ω
```
则称 ω 契约可靠，记 ⊨C_ω。部分可观测下所有谓词定义在信念 b 上，而不是隐藏状态 s 上；感知误差通过 Calib-FI 的误差界进入谓词的保守化。

**定义 543（技能顺序组合）** 若 Post_{ω₁}∧Inv_{ω₁} ⇒ Pre_{ω₂}，则 ω₁⊳ω₂ 有定义，且
```
C_{12} = (Pre_{ω₁}, Post_{ω₂}, Inv_{ω₁}∧Inv_{ω₂},
          D_{ω₁}^max + D_{ω₂}^max, min(1, ε_{ω₁}+ε_{ω₂}), v_{ω₂}^⊥)
```
采用**帧公理**：技能不修改其契约未声明的作用域之外的持久状态；跨技能共享状态必须显式写入双方 Inv。组合仅在入册/离线期计算，运行期只做 O(1) 的谓词求值。

**定义 544（护盾集）** 
```
Sh(b) = { ω∈Ω :
    b ⊨ Pre_ω                                   (前置成立)
  ∧ LCB_δ(ρ_ω) ≥ ρ_min                          (能力可信)
  ∧ M₀.precheck(b, π_ω) = pass                  (硬安全预检)
  ∧ b ⊨ Inv_ω                                   (不变式将成立)
  ∧ has_recoverable_abort(b, ω) = true }        (v9 停车不变式有解)
```
护盾投影：
```
π^Sh(ω|b) = π(ω|b)·1[ω∈Sh(b)] / Σ_{ω'∈Sh(b)} π(ω'|b)
```
若 Sh(b)=∅，强制调用 recovery 技能（安全停驻），该技能恒在库中且 φ^elig=false。**护盾不可学习、不可被奖励打开**：它没有可训练参数。

**定义 545（安全可行核）** V⊆B 为满足下式的最小集合：
```
b∈V ⇒ Sh(b)≠∅ ∧ ∃ω∈Sh(b): Pr[b'∈V | b,ω] ≥ 1 − ε_ω
```
V 用保守可达性分析离线计算（与 v9 的 SpatialCert 同源几何），运行期只做成员查询。V 是"允许探索的州"；V 外一律 recovery。

**定义 546（共形块证书，升级 v9 定义 533）** 用留出校准集 D_cal 计算非一致性分数 s_i=|F̂(s_i,a_i)−F(s_i,a_i)|，取
```
q̂_{1−α} = Quantile_{1−α}({s_i})
```
块证书余量 β ← q̂_{1−α}。在可交换假设下，P(s_new ≤ q̂_{1−α}) ≥ 1−α（分布无关）。域偏移时 DA-ML 触发加权共形（按似然比 w(x) 重加权），加权后覆盖要求 ∫w dP_target=1；若权重方差超阈值，则拒绝签发证书、K_eff←1。**这把 v9 的"β 拍脑袋"换成有限样本覆盖保证，但也把风险集中到可交换性本身。**

**定义 547（悲观回报与软成本上界）** 给定行为策略 π_b 的数据集 D={(b_i,ω_i,r_i,c_i)}，候选策略 π 的重要性权重 w_i=π(ω_i|b_i)/π_b(ω_i|b_i)，则
```
J⁻_π   = (Σ_i w_i r_i)/(Σ_i w_i) − Rad_r(n, δ)
C⁺_{π,k} = (Σ_i w_i c_{k,i})/(Σ_i w_i) + Rad_c(n, δ),  k∈{effort, affect}
```
Rad 采用经验 Bernstein 半径；权重裁剪 w_i ≤ w_max 控制方差。**有效样本量** ESS=(Σw_i)²/Σw_i²。

**定义 548（安全策略改进接受规则）** 候选策略 π_θ 仅在同时满足下列四式时被接受：
```
(1) J⁻_{π_θ} ≥ J⁻_{π_b} − ζ                     (不劣于行为策略)
(2) C⁺_{π_θ,k} ≤ B_k,  k∈{effort,affect}          (软成本不超预算)
(3) D_KL(π_b ‖ π_θ) ≤ δ_trust                     (信任域)
(4) ESS(w) ≥ n_min                                (覆盖充分)
```
否则保持 π_b。接受后的新策略写入影子缓冲，在下一个块边界原子换入（P16）。

**定义 549（技能提升判据）** 轨迹分段 σ 提升为技能候选当且仅当
```
Promote(σ) = Recur(σ) ≥ N_p                    (复用足够)
           ∧ TermStable(σ) = true                (终止谓词稳定)
           ∧ ContractHeldOut(σ) = true           (留出集上契约可靠，共形覆盖 ≥1−α)
           ∧ Novelty(σ) ≥ ν                       (覆盖新颖度，避免重复技能)
           ∧ ShadowSafe(σ) = true                 (影子模式无安全违背)
```
五项皆真才入册；任一项失败保持为原始轨迹，不改变运行策略。入册后先以 ρ_ω=Beta(1,1) 起步，LCB 未达 ρ_min 前不会被护盾选中——"可学"与"可用"解耦。

# ---------------- IP-358 ContractSkillLibrary：契约技能库 ----------------
@dataclass
class SkillContract:
    pre: Predicate; post: Predicate; inv: Predicate
    d_max: int; eps_fail: float; fallback: str = "primitive_chunk"

@dataclass
class Skill:
    name: str
    policy: Policy                 # π_ω
    terminate: Callable            # β_ω
    contract: SkillContract        # C_ω
    competence: BetaPosterior      # ρ_ω
    eligible: bool = True          # 与 v9 ID 的 φ^elig 同源

class ContractSkillLibrary:
    def __init__(self): self.skills = {}
    def admit(self, w):
        assert w.contract.fallback == "primitive_chunk"
        self.skills[w.name] = w

    def compose(self, w1, w2):
        if not implies(and_(w1.contract.post, w1.contract.inv), w2.contract.pre):
            raise CompositionRejected(f"{w1.name}>{w2.name}")
        return Skill(
            name=f"({w1.name}>{w2.name})",
            policy=Sequential(w1.policy, w2.policy),
            terminate=w2.terminate,
            contract=SkillContract(
                pre=w1.contract.pre,
                post=w2.contract.post,
                inv=and_(w1.contract.inv, w2.contract.inv),
                d_max=w1.contract.d_max + w2.contract.d_max,
                eps_fail=min(1.0, w1.contract.eps_fail + w2.contract.eps_fail)),
            competence=BetaPosterior.combine(w1.competence, w2.competence))


# ---------------- IP-357 ShieldedSkillPlanner：护盾内安全 RL ----------------
class Shield:
    def __init__(self, lib, m0, spatial_cert, rho_min=0.9, delta=0.05):
        self.lib, self.m0, self.cert = lib, m0, spatial_cert
        self.rho_min, self.delta = rho_min, delta

    def admissible(self, b):
        out = []
        for w in self.lib.skills.values():
            if not w.eligible: continue
            if not w.contract.pre(b): continue
            if w.competence.lcb(self.delta) < self.rho_min: continue
            if not self.m0.precheck(b, w.policy): continue
            if not w.contract.inv(b): continue
            if not self.cert.has_recoverable_abort(b, w): continue
            out.append(w.name)
        return out

class ShieldedSkillPlanner:
    def __init__(self, shield, policy_net, behavior, replay,
                 zeta=0.02, budgets=(0.8, 0.8), trust=0.05, n_min=200):
        self.shield, self.policy_net = shield, policy_net
        self.behavior = behavior          # 初始化 = v9 行为策略 π_b
        self.replay = replay
        self.zeta, self.budgets, self.trust, self.n_min = zeta, budgets, trust, n_min
        self.pending = None

    def act(self, b):
        allowed = self.shield.admissible(b)
        if not allowed:
            return "recovery"             # 安全停驻技能，恒可用
        logits = self.policy_net(b)
        return sample(mask_softmax(logits, allowed))

    def maybe_update(self):
        batch = self.replay.sample()
        if effective_sample_size(batch.weights, self.policy_net) < self.n_min:
            return                        # 覆盖不足：不签发证书
        J_lcb = pessimistic_return(batch, self.policy_net)
        C_ucb = optimistic_cost(batch, self.policy_net)
        if J_lcb < self.J_behavior_lcb - self.zeta: return
        if any(C_ucb[k] > self.budgets[k] for k in ("effort", "affect")): return
        if kl(self.policy_net, self.behavior) > self.trust: return
        self.pending = self.policy_net.train_step(batch)   # 影子权重，不生效

    def on_chunk_boundary(self):
        if self.pending is not None:      # P16：块边界原子换入
            self.behavior = self.policy_net
            self.policy_net = self.pending
            self.pending = None


# ---------------- IP-359 ExperienceSkillDistiller：经验技能蒸馏 ----------------
class ExperienceSkillDistiller:
    def __init__(self, lib, N_promo=30, nu_min=0.1, shadow_eps=20):
        self.lib, self.buckets = lib, defaultdict(list)
        self.N_promo, self.nu_min, self.shadow_eps = N_promo, nu_min, shadow_eps

    def observe(self, trace):
        for seg in segment_by_subgoal(trace):
            self.buckets[descriptor(seg)].append(seg)

    def promote(self):
        for key, segs in list(self.buckets.items()):
            if len(segs) < self.N_promo: continue
            if not termination_stable(segs): continue
            if coverage_novelty(key) < self.nu_min: continue
            cand = train_offline(segs)                 # BC / IQL / CQL
            if not heldout_contract_check(cand, alpha=0.05): continue
            if not shadow_safe(cand, episodes=self.shadow_eps): continue
            self.lib.admit(cand)                       # 通过才入册
            del self.buckets[key]


# ---------------- 主闭环：MetricVoiceGauge-SHARP ----------------
def metricvoicegauge_round_10(M, s, obs, ...):
    ctx = mw_default_ctx()

    # v9 感知链：MW 契约表（DA/SPR/Cal/OTL），超时即中立元
    results = middleware.run_cycle({
        'DA_ML': lambda c: domain_adapter.update_and_measure(obs),
        'SPR':   lambda c: slam_risk.compute(M.slam_backend.get_latest_state()),
        'CAL_FI':lambda c: calib_fi.get_weights_kappa(),
        'OTL':   lambda c: online_learner.update_and_thresholds(c),
    }, ctx)
    ctx.delta_dom = results['DA_ML']
    trust = ctx.delta_dom < M.tau_dom and ctx.risk_slam < M.tau_slam

    # SSP：护盾内技能选择；不可信域/超时 ⇒ v9 行为策略（Level-1）
    if current_skill is None or current_skill.terminate(ctx.belief):
        name = shielded_planner.act(ctx.belief) if trust else "primitive"
        current_skill = csl.skills.get(name, primitive_skill)

    # CSL：运行期只查前置与不变式；失败 ⇒ v^⊥=primitive_chunk（Level-2）
    if not (current_skill.contract.pre(ctx.belief)
            and current_skill.contract.inv(ctx.belief)):
        current_skill = primitive_skill

    # v9 AC：用技能策略产块；块证书/中止点/中块守卫语义不变
    if current_chunk is None or current_chunk.exhausted:
        current_chunk = chunker.generate_chunk(
            ctx.belief, ctx.delta_dom, M.tau_dom, trust,
            policy=current_skill.policy)
    verdict, k = chunker.midchunk_guard(current_chunk, k_exec, live_obs)

        current_chunk.execute_safe_stop_at(k)          # 定义 534
        current_chunk = None
        current_skill.competence.update(success=False) # ρ_ω 失败计数
    else:
        execute(current_chunk.actions[k])

    # v8 继承路径 + ID 归因 + ESD 入册
    out = M.inherited_v8_path(ctx)
    distiller.step(cycle_idx, ctx)
    esd.observe(trace_buffer.pop_ready())
    if cycle_idx % T_promote == 0:
        esd.promote()                                  # 失败即不入册（Level-3）
    if at_chunk_boundary():
        shielded_planner.on_chunk_boundary()           # P16 双缓冲换入
        shielded_planner.maybe_update()                # SPI 四条件
    return out

## 4. 推导

**引理 87（护盾可行性 ⇒ 轨迹安全）** 设 V 为定义 545 的可行核，b₀∈V，且每个技能的契约可靠（定义 542）。若策略满足 supp π(·|b)⊆Sh(b)，则对所有 t，b_t∈V，且 M₀ 安全不变式以概率 ≥1−Σ_t ε_{ω_t} 成立。证明：对 t 归纳。b₀∈V。若 b_t∈V，定义 545 给出 Sh(b_t)≠∅ 且所选 ω_t∈Sh(b_t) 的后继 b_{t+1}∈V 的概率 ≥1−ε_{ω_t}。契约可靠性同时保证过程不变式 Inv_{ω_t} 成立，而 M₀ 预检与 v9 块证书保证硬安全判据。对 t 用联合界即得。∎

**引理 88（技能契约组合的可靠性传递）** 若 ⊨C_{ω₁}、⊨C_{ω₂} 且 Post_{ω₁}∧Inv_{ω₁} ⇒ Pre_{ω₂}，则 ⊨C_{12}，其中 C_{12} 如定义 543。证明：从任意 b⊨Pre_{ω₁} 出发，ω₁ 以 ≥1−ε₁ 到达 b'⊨Post_{ω₁}∧Inv_{ω₁}，由蕴含得 b'⊨Pre_{ω₂}；再由 ω₂ 的契约以 ≥1−ε₂ 到达 b''⊨Post_{ω₂}∧Inv_{ω₂}。过程不变式由两段各自成立且 Inv₁∧Inv₂ 在段间保持（帧公理）。失败概率 ≤ ε₁+ε₂ 由联合界给出；时延为两段最坏时长之和。∎

**引理 89（安全策略改进的有限样本保证）** 设数据由 π_b 采样，候选 π_θ 的 ESS(w)≥n_min，且经验 Bernstein 半径按置信度 1−δ 构造。若定义 548 的四条件全满足，则以概率 ≥1−δ：
```
J(π_θ) ≥ J(π_b) − ζ − 2·Rad_r,     C_k(π_θ) ≤ B_k + 2·Rad_c,  k∈{effort,affect}
```
证明：J⁻ 与 C⁺ 分别是 J 与 C 的 1−δ/2 置信下/上界（经验 Bernstein）。接受条件 (1)(2) 把估计量夹在行为基线与预算之内；再由置信区间宽度得真实量最多偏移 2·Rad。覆盖条件 (4) 保证重要性权重方差有界，否则置信区间不成立（见引理 92）。KL 条件 (3) 限制候选与行为策略的偏离，控制重要性权重的指数增长。∎

**引理 90（能力门控的失败率界）** 若技能仅在 LCB_δ(ρ_ω)≥ρ_min 时被调用，则单次调用失败概率 ≤ 1−ρ_min + Rad_Beta(n_ω,δ)，其中 Rad_Beta 为 Beta 后验的置信宽度。组合技能的失败率按引理 88 的联合界相加。证明：由 Beta 后验的 Clopper–Pearson 下界，真成功率 ≥ LCB_δ 以概率 ≥1−δ；门控条件给出真成功率 ≥ ρ_min − Rad，故失败概率 ≤ 1−ρ_min+Rad。∎

**引理 91（v10 关闭新组件 ⇒ 严格退回 v9）** 令 SSP 关闭（π←π_b=π_v9，不更新）、CSL 关闭（Ω={primitive_chunk}）、ESD 关闭（不入册）。则对任意固定种子与输入序列，v10 主闭环产生的动作序列、块证书、退化日志与 v9 逐位一致；再叠加 v9 的 AC/MW/ID 关闭，逐级退回 v8→v7→v6。证明：关闭 SSP 后策略分布相同；关闭 CSL 后每个技能的 v^⊥ 均为 primitive_chunk，前置/不变式检查退化为恒真；关闭 ESD 后技能库不变；主闭环剩余路径与 v9 骨架逐语句对应。块边界双缓冲在关闭态无 pending，故无额外状态。归纳即得。∎

**引理 92（覆盖前提不可省）** 若 ESS(w)<n_min，则对任何候选 π_θ，定义 547 的置信区间宽度至少为 Δ(n_min,δ)；当偏离足够大时 J⁻_{π_θ} ≤ J⁻_{π_b}−ζ 恒不成立，接受规则 (1) 必然拒绝。即：**没有行为策略覆盖的地方，SPI 不签发任何改进证书**。证明：重要性权重方差随 TV(π_θ,π_b) 增大而无界增长，经验 Bernstein 半径随之增大；当半径超过 ζ 时，回报下界无法超过行为基线减 ζ。这是重要性采样估计的 minimax 下界（覆盖不足时不可估）。∎

**引理 93（模型利用上界与相关误差的残余风险）** 设证书模型集合 M_δ 以概率 ≥1−δ 覆盖真实模型 M*，集合直径 diam(M_δ)≤r_δ，成本对模型 Lipschitz 常数 L。则被护盾接受的动作，其真实软成本 ≤ B_k + L·r_δ（以概率 ≥1−δ）。若 M*∉M_δ，则无上界；此时集合成员的**成对分歧** u 可以很小却仍共同偏离真实模型——**相关误差不可由分歧审计发现**。证明：M*∈M_δ 时，悲观上界 max_{M_i∈M_δ} C_{M_i} 覆盖 C_{M*}；Lipschitz 给出直径界。M*∉M_δ 时，集合内一致性不排除共同偏差，分歧 u=0 也不提供信息。∎

**引理 94（时间抽象降低样本复杂度）** 设技能平均长度 K̄、原始折扣 γ，则技能级 MDP 的有效折扣 γ_Ω=γ^{K̄}。在表格型设定下，达到 ε-最优技能策略的样本复杂度为 Õ(|B||Ω|/(ε²(1−γ_Ω)²))。相对原始动作设定的缩减因子为 ((1−γ)/(1−γ_Ω))²。取 γ=0.99、K̄=10，γ_Ω≈0.904，缩减因子≈0.0109（理想化约 90×）。**净收益需扣除技能学习样本 N_learn**：当 N_flat/N_skill > 1 + N_learn/N_skill 时才真正划算。∎

## 8. 本轮最大风险

**一句话**：RL 的优化目标与安全证书共享同一个可被策略利用的前向模型，一旦技能策略学会把状态驱动到"集合内成员一致、但共同偏离真实动力学"的区域（相关误差而非可检测分歧），护盾会给出虚假的安全证明——优化器绕过护盾的方式不是打破它，而是让它相信一个错误的模型。
