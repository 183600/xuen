# 第 41 轮 · 双灵感落地 v8：证书化失败恢复 × 移动操作复合认证（四层架构 v6）

> 承接第 40 轮（v17：可认证流匹配执行 × 度量语义几何锚定 × 证书驱动课程引擎，四层架构 v5）。第 40 轮交出了「动作在几何/动力学意义上可证安全」的三根支柱，却把失败恢复留成 v16 的「服务化故障转移」（IP-38 保持），把移动操作简化为「规划器读 ESDF」。本轮灵感词「失败恢复、移动操作」直指这两个缺口：证书不应只在失败后被吊销，而应在失败前预警；移动操作的证书不能是「臂证书 + 底盘证书」的拼接，而必须是含耦合项的复合证书。

## 0. 直觉与动机

**灵感 1（失败恢复 → 证书裕度是先兆探针，恢复是受约束的契约重协商）**：第 40 轮把证书当成「安全证明」，只在违约后触发 RCA 重颁。但证书边际 m(t)=c−g(x(t)) 是一条随状态演化的时间序列；其下降速率可被动力学 Lipschitz 常数上界，于是「还剩多久违约」可以**被证明**而不是被**观察**。这把失败恢复从「事后抢救」移到「事前切换」：τ_v(x)=m(x)/(L·v_max) 是违约时间的保守下界，只要 τ_v > τ_switch+τ_reach 就有时间执行恢复。更关键的是，恢复动作本身也是控制行为，可能比原失败更危险（为了避障而急停反而导致底盘失稳）。因此恢复技能必须自带证书 CertRec，并满足：自身鲁棒证书成立、在当前 ValidRegion 内可执行、在预警预算内可达、恢复序列良基终止（不允许无限恢复循环）。失败不再是异常字符串，而是「哪一条契约的哪一项义务被违反」的类型化证据——与第 40 轮 C_ms 类型系统同构。

**灵感 2（移动操作 → 复合证书与「轨迹管」有效域）**：移动操作不是「底盘到点 + 机械臂抓取」两个独立问题。底盘运动通过惯性/雅可比耦合进入臂端执行误差，臂的反作用力又经质心进入底盘稳定性。把两本证书取 min 是不够的：必须显式给出耦合增益 γ 与小增益条件 κ_c=κ_a−γ·L_{b→a}>0，否则会出现「各自都认证、合起来失效」的经典盲区。此外，移动让 ValidRegion 从「当前点的区域」变成「沿规划底盘轨迹的管状区域」：激光覆盖与漂移球必须对整条轨迹管成立，而不能只对当前位姿成立。移动操作还有一类独有失败——基座放置不可达/不稳，这需要一个基座放置证书（可达集含不确定球、支撑多边形稳定裕度、ESDF 间距三者同时成立）。

**灵感 3（两者的耦合 → 恢复需要「可退守的有效域」，移动操作提供最丰富的失败分布）**：第 40 轮的熔断器只会「停」，但停在半路可能既不在有效域也不安全。移动操作恰好拥有「退守」这一物理自由度：当 ValidRegion 将失效（遮挡、几何退化、漂移膨胀）时，最优恢复往往不是原地停，而是退回到最近的可认证区域并重新放置基座。于是失败恢复与移动操作形成闭环：移动操作提供失败样本，证书裕度免费产生失败标签，恢复课程把这些样本转成恢复技能，恢复技能又要求一个「安全核（safe kernel）」不变量。三者的乘积约束是：执行前、执行中、恢复时都要同时满足 CertRobust ∧ CertMob ∧ CertRec。

## 1. 形式化定义

**定义 27（证书裕度过程与预警时域）**：设约束 g_i(x)≥0、阈值 c_i，裕度 m_i(x)=c_i−g_i(x)。沿闭环轨迹 x(t) 有 |d/dt g_i(x(t))| ≤ L_i·v_max，其中 L_i 为 g_i 沿系统动力学的 Lipschitz 常数，v_max 为执行速度上界。定义违约时间下界

τ_v,i(x) = m_i(x) / (L_i·v_max)（m_i>0），

以及系统预警时域 τ_warn(x)=min_i τ_v,i(x)。恢复就绪条件为 τ_warn(x) > τ_switch + τ_reach(x;g)，其中 τ_switch 为切换时延，τ_reach 为恢复技能 g 把状态带入其安全集的时间上界。预警触发即「预失败（pre-failure）」，区别于违约后的「已失败（post-failure）」。

**定义 28（恢复证书 CertRec 与良基终止）**：恢复技能 g 的证书定义为

CertRec(g) = {CertRobust(g), Pre_g, Post_g, E_g, τ_reach(g), r_g, depth_max}，

其中 Pre_g/Post_g 为 C_ms 前提/后置，E_g⊆{F1..F6} 为它能处理的失败类型集，r_g 为良基秩函数（取值于有限良序集，如剩余失败类型数或到有效域的距离）。恢复算子 R 在状态 x 与失败证据 e∈E 上选 g，要求

reach_g(x) ∧ τ_reach(g) ≤ τ_warn(x) − τ_switch ∧ r_g(Post_g(x)) < r_g(x)。

**定理（恢复终止性）**：若每次恢复都使 r 严格下降且 r 取值有限，则任意恢复序列长度 ≤ depth_max，不会出现「恢复触发新恢复」的无界循环；深度超过 depth_max 时强制升级（escalate）到人类/远程操作。

**定义 29（移动操作复合证书 CertMob）**：复合状态 s=(q_b,q_a)，复合流 ẋ_s=f_s(x_s,u)，其中底盘子系统 ẋ_b=f_b(x_b)+G(x_a)，臂子系统 ẋ_a=f_a(x_a,x_b)。以加权度量下的收缩性定义耦合证书：

κ_c = κ_a − γ·L_{b→a}，CertMob 成立 ⟺ κ_c>0 ∧ κ_b>0 ∧ BaseCert(p_b) 成立。

其中 κ_a、κ_b 为两子系统单向 Lipschitz 常数，γ 为底盘运动到臂端的耦合增益，L_{b→a} 为耦合通道 Lipschitz 常数（小增益条件）。基座放置证书 BaseCert(p_b) 要求

target ∈ Reach(p_b) ⊖ B_t（可达集在漂移球内仍含目标）∧ CoM_proj ∈ supp(p_b) ⊖ margin_stab ∧ h_ESDF(p_b) ≥ B_t + margin。

**定义 30（轨迹管有效域与退守策略）**：给定底盘规划轨迹 p_b(·):[0,T]→SE(2)，轨迹管 T_r={x: dist(x,p_b(t))≤r_tube(t)}。轨迹管有效域

ValidTube = { t : 激光覆盖(T_r(t)) ∧ sup_{x∈T_r(t)} B(x) ≤ B_cert }。

若某 t 处 ValidTube 失效，则启动退守策略 π_retreat：把状态带入安全核 K={x: CertRobust(x) ∧ CertMob(x) ∧ x∈ValidRegion} 的最大受控不变子集，且退守过程中 h_ESDF(x)≥B_t 恒成立。原熔断器由「停止」升级为「退守或停止，取可行且更安全者」。

**定义 31（失败恢复课程赤字）**：在第 40 轮 D(τ) 上增加恢复维度：

D_rec(τ)=Σ_j v_j·max(0,1−m_j(τ)/c_j)，m_j∈{detect_lead, recovery_success, 1−false_trigger, 1−recovery_cost, recovery_depth}。

近失（0<裕度≤ε）与恢复失败样本按证书赤字加权注入回放；失败标签由证书违约证据自动生成（自监督），无需人工标注。

## 2. 四大产出设计

### 2.1 IP-54 CERTIFIED-FAILURE-RECOVERY（证书化失败恢复）
1. 裕度监测器：在线估计 m_i 与 L_i（谱范数/有限差分上界），输出 τ_warn 与失败类型。
2. 类型化失败目录 F1–F6：F1 ODE 残差；F2 几何间距；F3 漂移界/有效域；F4 语义后置；F5 基座可达；F6 基座稳定。
3. 恢复技能库：每个恢复技能带 CertRec；恢复选择=约束优化 max P(success|e,g) s.t. reach ∧ budget ∧ rank-decrease。
4. 恢复即处理器（handler）：与 IP-47 效果类型绑定，见 2.4。
5. 运行期：预失败触发 → 选恢复 → 执行并复检 → 失败升级。

### 2.2 IP-55 MOBILE-MANIP-COMPOSITE-CERT（移动操作复合认证）
1. 复合流匹配：动作块=(底盘速度块, 臂关节块)，条件含基座位姿；复用 IP-48 认证但输出复合 κ_c。
2. 耦合增益估计：以轨迹回放拟合 γ、L_{b→a}，给 (1−δ) 上界；不满足 κ_c>0 时用时间缩放（臂动时底盘慢行）主动降 γ。
3. 基座放置证书 BaseCert：可达集、支撑多边形、ESDF 三合一，在线 QP 求候选放置。
4. 轨迹管有效域：沿规划轨迹滚动认证 ValidTube，出管即退守。
5. 联合规划：IP-39 增加「先放基座再规划臂」的耦合感知模式，代价含 BaseCert 可行性。

### 2.3 IP-56 RETREAT-TO-VALIDITY（退守有效域/认证降级）
1. 安全核 K 计算：CBF 不变集的采样近似 + Lipschitz 保守扩张；离线预计算，在线查表。
2. 退守策略库：退回最近有效位姿、降级到视觉-惯性放宽球、原地平衡优先姿态。
3. 熔断器四态：正常 / 预警 / 退守 / 停止，按可行性单调降级，禁止跳级。
4. 每次状态迁移写审计链，供 IP-53/课程回放（为未来轮次预留接口）。

### 2.4 IP-47/IP-50 升级：效果类型化任务代数 × 恢复课程
- IP-47：技能契约增加效果签名 E 与处理器 H_E；组合传播效果并强制类型检查「恢复处理器是否覆盖声明的失败集」，未定义恢复在编译期报错（把现场崩溃前移为类型错误）。
- IP-50：D_rec 纳入课程带；注入失败/近失/恢复场景；恢复深度轴（1→2→3）作为第四课程轴，量化 3 档防组合爆炸。
- IP-38：从「服务化故障转移」升级为「证书驱动恢复」，复用 IP-54 的 CertRec。

## 5. 本轮最大风险

**一句话**：本轮全部设计押在「耦合可分离」这一假设上——若底盘-臂耦合增益 γ 的认证上界过松、或小增益条件 κ_c>0 在真实移动操作中经常不成立，复合证书将退化为「谁都不敢动」的死锁，而恢复证书又可能因预警时域被 L_i 高估而永远来不及执行，最终把第 40 轮的「装饰性证书」问题升级成「装饰性恢复」。

## 2. 关键算法

### IP-54 证书化失败恢复（伪代码）
```
def margin_alarm(x, contracts):
    for g_i in constraints:
        m_i = c_i - g_i(x)
        L_i = lipschitz_upper(g_i, dynamics)      # 谱范数/有限差分上界
        tau_v = m_i / (L_i * v_max + eps)
    tau_warn = min(tau_v)
    e = classify_failure(x, contracts)            # F1..F6
    return tau_warn, e

def recover(x, e, tau_warn, G, depth, r_prev):
    if depth > depth_max: return escalate(x, e)
    feasible = [g for g in G if e in g.E and g.Pre(x)
                and reach_time(g, x) + tau_switch <= tau_warn
                and g.rank(Post(g, x)) < r_prev]
    if not feasible: return safe_stop_or_retreat(x)
    g  = argmax(feasible, key=P_success)
    x1 = certify_execute(g, x)                    # 复用 IP-48 认证流采样
    return recover(x1, classify_failure(x1), margin_alarm(x1)[0],
                   G, depth + 1, g.rank(x1))
```

### IP-55 移动操作复合认证（伪代码）

```
def composite_cert(v_theta, replay):
    kappa_a = lower_bound_one_sided_lip_arm(v_theta)
    kappa_b = lower_bound_one_sided_lip_base(v_theta)
    gamma, L_b2a = fit_coupling_upper(replay, delta=0.01)
    kappa_c = kappa_a - gamma * L_b2a

def base_placement_cert(p_b, target, B_t, esdf, support):
    ok_reach = target in reach_set(p_b).erode(B_t)
    ok_stab  = com_proj in support(p_b).erode(margin_stab)
    ok_clear = esdf.clearance(p_b) >= B_t + margin
    return ok_reach and ok_stab and ok_clear

def valid_tube(p_b_traj, T_r, B_cert):
    return [t for t in grid(T_r)
            if lidar_coverage(T_r(t)) and max_B(T_r(t)) <= B_cert]

def couple_aware_plan(task):
    p_b = argmin cost(p) s.t. base_placement_cert(p, ...)
    if not valid_tube(p_b): p_b = nearest_with_valid_tube(p_b)
    arm = plan_arm(p_b, task, guard=kappa_c)
    return p_b, arm
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 正确性保证 |
|---|---|---|
| 裕度预警 | O(\|constraints\|·d)/步，L_i 热启动 | **定理**：τ_v=m/(L·v_max) 为违约时间下界（Lipschitz 上界成立时） |
| 恢复选择 | O(\|G\|)，按 E 建索引后近 O(log\|G\|) | 约束优化：reach ∧ budget ∧ rank-decrease 同时成立才执行 |
| 恢复序列 | depth ≤ depth_max | **定理**：良基秩严格下降 ⟹ 终止，无恢复循环 |
| 复合认证 | 复用 IP-48 认证开销 + 耦合拟合 O(replay) | **定理**：κ_c>0 ⟹ 加权度量下复合系统收缩，跟踪误差指数收敛 |
| BaseCert | 可达集/支撑多边形 O(1) 查询 + QP | 三条件同时成立才是合法放置；任一违约禁止执行 |
| ValidTube | O(T·体素) 滚动 | 管上每点覆盖与漂移界成立，避免「当前有效、中途失效」 |
| 安全核 K | 离线采样 O(N·MC)，在线 O(1) 查表 | 采样近似 + Lipschitz 保守扩张 ⟹ K 内不变性近似可证 |
| 效果类型检查 | O(\|V\|+\|E\|) | 未覆盖失败集在编译期报错，恢复定义完备性前移 |
| 恢复课程 | O(6)/任务；带采样 O(1) | Robbins-Monro 收敛 + 赤字加权回放抑制遗忘 |

## 5. 风险与缓解

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 耦合证书过松 → κ_c≤0 频发，退化为「谁都不敢动」 | 高 | 仅认证耦合通道；时间缩放主动降 γ；E75 第一守门 |
| 预警时域被 L_i 高估 → 恢复总是来不及 | 高 | 在线估计 L_i + 保守 v_max + 提前量化档位；E73 守门 |
| 安全核 K 在杂乱/退化场景为空集 | 中 | 保守扩张 + 视觉惯性放宽球兜底；不可行即降级到停止 |
| 恢复振荡（A→B→A） | 中 | 良基秩 + 滞回 + depth_max 强制升级 |
| 恢复课程类别极不均衡/灾难遗忘 | 中 | 赤字加权回放 + 失败类型分层采样 |
| 效果类型随技能数组合爆炸 | 低 | 固定 F1–F6 目录，禁止自定义失败类型 |
| 复合动作块维度升高使流认证更松 | 中 | 仅认证执行头与耦合通道，主干经验值×安全系数 |

## 6. 本轮最大风险

**一句话**：本轮全部设计押在「耦合可分离」这一假设上——若底盘-臂耦合增益 γ 的认证上界过松、或小增益条件 κ_c>0 在真实移动操作中经常不成立，复合证书将退化为「谁都不敢动」的死锁，而恢复证书又可能因预警时域被 L_i 高估而永远来不及执行，最终把第 40 轮的「装饰性证书」问题升级成「装饰性恢复」。
