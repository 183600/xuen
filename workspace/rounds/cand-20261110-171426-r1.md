# 第 47 轮（承接第 46 轮 v23；本轮灵感：主动交互 × 迁移学习） · Active-Transfer：主动交互修复迁移鸿沟的跨域姿态证书守护（五层架构 v11）

> 承接第 46 轮 v23 Memory-Safety-Voice。v23 把记忆检索、语音指令与安全绑定接入能量-上下文-深度框架，但隐含假设 H5：系统的先验（记忆库、共形校准、模态效用）只来自**当前域**，且机器人只能**被动响应**已经到来的语音或环境变化。UniBot 一旦换房间、换物体集、换任务或换操作者，H5 立即破裂：源域记忆与校准被直接复用会产生负迁移，而最有价值的消歧信息（“这是玻璃杯吗”“请演示一次”）根本不在现有传感器里，必须**主动向人提问**才能获得。两个灵感词精确命中 H5：**主动交互**把“提问/请求演示/移动视点/物理探测”建模为带人力和能量成本、可计算信息增益的动作；**迁移学习**把跨域先验从免费资产重估为“有域差的负债”，其可信度必须被估计、膨胀与审计。二者耦合出新问题：**如何在有限的交互预算与能量租约下，主动选择最能缩小迁移证书宽度的交互，并在迁移性被高估或人类回答与先验冲突时，保证姿态证书不静默失效**。

## 0. 直觉与动机

**灵感 1（主动交互 → 把“提问”变成一等安全动作）**
直觉：当前机器人更像“哑巴执行器 + 被动听令”。很多不确定性（透明/镜面材质、未见过的抓取点、迁移后失效的深度先验）靠再多 RGB/深度帧也消不掉，但一句“这个能捏吗？”或一次人类演示就能消掉。于是把交互动作 q 与感知模态 m 并列建模：q 有信息增益 VoI、有人类注意力成本 c_h、有能量/时延成本，必须像模态调度一样在预算内择优。关键约束：**提问本身也必须安全**——机器人不能在姿态证书已失效时先做一个大动作去“问”，动作必须落在当前证书 P_t 内（no-motion-beyond-cert）。

**灵感 2（迁移学习 → 先验的可信度必须可被证伪）**
直觉：迁移学习让新域少采数据、快速适配，但源域共形半径在目标域可能过度乐观（负迁移/协变量偏移），这正是“静默失效”的温床。因此迁移性 τ 不能是固定超参，而必须在线估计（表征 MMD、源-目标分歧、目标审计覆盖率），并把 τ 直接写进证书半径的膨胀项 r_ω^{tr}=r_ω+c_τ(1-τ)/τ+Δ_0。当 τ<τ_min 时，源域证书作废，只能靠目标域校准或主动交互重建；且 τ 的上升必须由独立审计集放行，避免“越迁移越自信”的自证循环。

**灵感 3（耦合 → 主动迁移闭环：先验指路，交互补票）**
直觉：迁移先验告诉我们“哪里可能不可信”（高分歧区域），主动交互则在“最值钱的不确定处”补一个目标域标签。两者互为杠杆：没有迁移先验，提问空间太大、问题太贵；没有主动交互，迁移误差无法被证伪。闭环 = 迁移性估计 → 定位鸿沟 → 计算 VoI → 安全提问/演示 → 目标域校准更新 → 重新签发联合证书。

**耦合升级**：在 v10 四层上新增 **主动迁移层 ATL（Active Transfer Layer）**。根信任层新增**交互租约 ℓ_i** 与**迁移证书 τ**；L1 几何层使用迁移膨胀半径；L2 上下文预测器加域标签并输出“迁移可疑区”；L3 CAR 守卫新增 τ≥τ_min 与交互预算约束；L4 DCL 把主动交互获得的样本作为带护照的目标域数据。五层 v11：根信任（姿态/能量/交互/迁移四租约）、L1 几何、L2 上下文与迁移可疑度、L3 安全守卫、L4 主动数据采集。

## 1. 形式化定义（增量：定义 59–63）

**定义 59（迁移性与证书膨胀）**
源域 D_s、目标域 D_t，迁移性 τ(D_s→D_t)∈(0,1]，由表征 MMD、源-目标预测分歧与目标审计覆盖率联合估计。迁移姿态半径
r_ω^{tr} = r_ω + c_τ·(1-τ)/τ + Δ_0，
其中 Δ_0 为保守下限。若 τ<τ_min，源域证书作废，必须用目标域共形校准或主动交互重建。**迁移 soundness**：
P(X_t∈P_t^{tr} | τ≥τ_min, ℓ 有效) ≥ 1-α_p - δ_tr(τ)，
δ_tr 随 τ 单调递减，τ→1 时 δ_tr→0。

**定义 60（迁移-共形校准）**
目标域与源域密度比 w(x)=p_t(x)/p_s(x)（截断到 [0,W]）。加权共形分位数给出 C_α^{tr}，其覆盖率满足
P_t(X∈C_α^{tr}) ≥ 1-α - TV(p_s,p_t) - ε_W，
ε_W 为密度比截断误差。当 W 越界或 TV 过大时自动抬 α、膨胀半径，禁止直接复用源域分位数。

**定义 61（主动交互动作与信息价值）**
交互动作集 Q={ask_human, request_demo, viewpoint_change, self_probe, do_nothing}，每次产生观测 y_q。对潜在可观测层 ω 与迁移参数 θ 的信息价值
VoI(q)=E_{y_q}[H(ω,θ|X)-H(ω,θ|X,y_q)]·S_φ(ω) - λ_h c_h(q) - λ_e c_e(q) - λ_l c_l(q)，
c_h 为人类注意力/耐心成本，c_e 为能量，c_l 为时延，S_φ 为下游敏感度。仅当 VoI(q)>ε_v 且当前证书风险超阈值时才提问。

**定义 62（交互租约与安全查询策略）**
交互租约 ℓ_i=(B_h,P_i,τ_i,λ_h)，B_h 为剩余人类注意力预算。查询策略
π_q(c_t,ω_t,B_t,ℓ_i)=argmax_{q∈Q} VoI(q)
s.t. c_h(q)≤B_h，E(t+Δ|q)≥E_min，**动作安全约束**：执行 q 所需机体运动必须落在当前证书 P_t 内（no-motion-beyond-cert）。

**定义 63（主动迁移联合证书）**
J_t^{AT}=(P_t^{tr},ℓ_p,ℓ_e,ℓ_i,m_t,τ_t,q_t)。联合 soundness：
P(X_t∈P_t^{tr} | ω_t,m_t,τ_t≥τ_min,ℓ_p,ℓ_e,ℓ_i 有效) ≥ 1-α_p-δ_tr
且 q_t 满足动作安全约束。**冲突回退**：若人类回答/演示与迁移先验分歧 >θ_d，或 τ 跌破 τ_min，或 B_h 耗尽，则废除迁移证书，退保守姿态盒或 fail-closed。

## 2. 三大新增产出与既有 IP 升级

**IP-69 ATM（Active Transfer Monitor）**
- 在线迁移性估计：表征 MMD + 源-目标分歧 + 目标审计覆盖率
- 证书膨胀：把 τ 注入 r_ω^{tr}，对 τ 单调不增（τ 越小半径越大）
- 负迁移告警：分歧突增/覆盖率暴跌即触发 τ 下调与证书重签，且 τ 上升需独立审计放行

**IP-70 AXI（Active eXchange Interface）**
- VoI 计算器：对 Q 中每个动作估计信息增益与三类成本
- 安全查询门控：动作安全约束 + 交互租约 + 能量租约三重过滤
- 对话/演示模板：最小化人类负担的提问措辞、一次演示的槽位绑定

**IP-71 TC2（Transfer-Conformal Calibrator）**
- 密度比加权共形 + 截断误差补偿
- 目标域审计集小样本自适应 α 抬升
- 与 IP-64 深度分层校准联合：按模态组合分域校准

**IP-72 DTA（Demonstration Transfer Adapter，可选增量）**
- 人类单次演示→策略残差适配器，带安全滤波
- 演示护照：来源、置信、适用域标签

**既有 IP 升级**
IP-66 MVR：记忆加域标签，跨域检索必须经 τ 加权并受 ℓ_i 约束
IP-67 VAD：从单轮指令升级为“提问-回答”对话，槽位由答案更新
IP-68 SAB：把人类回答/演示纳入绑定函数 B，冲突即入安全队列
IP-62 CCA：新增迁移偏移红队、恶意/误导性回答注入测试
IP-51 CAR：守卫加入 τ≥τ_min 与交互预算耗尽判定
IP-45 总线：新增 transferability / interaction-lease / query-action / demo-passport 话题

## 3. 算法骨架

ATL 每控制周期：
1. 读 B_t, ℓ_e, ℓ_i, ℓ_p, c_t, ω_t, τ_t
2. ATM 更新 τ_t 并膨胀 r_ω^{tr}
3. 若 τ_t<τ_min 或证书风险高：AXI 对 Q 求 VoI
4. 过滤不满足动作安全/能量/人力预算的 q，选 q_t^*
5. 执行 q_t^*，把回答/演示写入目标域审计集，TC2 重校准
6. 重估 τ_t；若 τ 未上升则降级，禁止无审计的自我提升
7. PSE 用新半径签发 P_t^{tr}，CAR 用 J_t^{AT} 守卫；冲突/预算耗尽→fail-closed
所有交互动作与证书同源打护照，供 CCA 回放审计。

## 4. 本轮最大风险

**一句话**：迁移性估计 τ 本身可能被高估（尤其在目标退化层先验与源域相反时），而主动交互又可能因问题设计不当或人类给出错误/敷衍回答而把系统引向错误的“高置信”，最终让膨胀后的姿态证书仍不足以覆盖真实误差并静默失效；因此必须让 τ 只降不升地受审计集约束、把人类回答当作带噪声的弱标签、并在任何冲突或预算耗尽时 fail-closed。

## 2. 关键算法 伪代码

### IP-69 ATM
```
def estimate_transferability(src_emb, tgt_emb, audit, disagree_fn, coverage_fn,
                             lm=1.0, ld=1.0, lc=1.0):
    mmd = rbf_mmd(src_emb, tgt_emb)
    dis = disagree_fn(src_model, tgt_emb)
    cov = coverage_fn(audit)              # 目标审计集对源证书的覆盖率
    tau = exp(-(lm*mmd + ld*dis + lc*(1.0-cov)))
    return clip(tau, 1e-3, 1.0)

def inflate_radius(r, tau, c_tau=0.5, delta0=0.02, tau_min=0.4):
    r_tr = r + c_tau*(1.0-tau)/max(tau, 1e-3) + delta0
    valid = tau >= tau_min
    delta_tr = delta0*(1.0/max(tau, 1e-3) - 1.0)   # 覆盖率损失上界
    return r_tr, valid, delta_tr

def update_tau(tau_prev, tau_audit, audit_valid):
    # τ 下降立即生效；上升必须有独立审计集放行，防自证循环
    if tau_audit < tau_prev:
        return tau_audit
    return tau_audit if audit_valid else tau_prev
```

### IP-70 AXI
```
def voI(q, omega_belief, theta_belief, S_phi, costs):
    H0 = entropy(omega_belief) + entropy(theta_belief)
    exp_H1 = 0.0
    for y, p_y in predictive(q, omega_belief, theta_belief):
        post = bayes_update(omega_belief, theta_belief, y)
        exp_H1 += p_y * (entropy(post.omega) + entropy(post.theta))
    gain = (H0 - exp_H1) * S_phi
    return gain - costs.lam_h*q.c_h - costs.lam_e*q.c_e - costs.lam_l*q.c_l

def select_query(Q, cert, lease_i, lease_e, theta_risk, eps_v=0.05):
    best, best_v = None, eps_v
    for q in Q:
        if q.c_h > lease_i.B_h:                       continue
        if not energy_ok(lease_e, q, Delta, E_min):    continue
        if not motion_within_cert(q, cert):            continue  # 硬安全约束
        v = voI(q, ...)
        if v > best_v:
            best, best_v = q, v
    return best if (best is not None and risk(cert) > theta_risk) else None
```

### IP-71 TC2
```
def weighted_conformal(scores_tgt_audit, w, alpha, Wcap=5.0, delta0=0.02):
    w = clip(w, 0.0, Wcap)
    order = argsort(scores_tgt_audit)
    ws, ss = w[order], scores_tgt_audit[order]
    cum = cumsum(ws) / sum(ws)
    qhat = ss[min(searchsorted(cum, 1.0-alpha), len(ss)-1)]
    eps_W = max(0.0, 1.0 - sum(ws)/ (Wcap*len(ws)))   # 截断误差粗界
    return qhat + eps_W + delta0
```

### 全局 ATL 决策
```
def atl_step(c_t, omega_t, B_t, leases, tau_prev, Q, audit):
    tau = update_tau(tau_prev, estimate_transferability(...), audit.valid)
    r_tr, valid, delta_tr = inflate_radius(r_omega(omega_t), tau)
    P_t = issue_cert(r_tr)
    q = select_query(Q, P_t, leases.i, leases.e, theta_risk)
    y = None
    if q is not None:
        y = execute(q)                                   # 动作已受证书门控
        audit.add(y, passport={'src':D_s,'q':q,'tau':tau,'conf':y.conf})
        tc2.recalibrate(audit)
        tau = update_tau(tau, estimate_transferability(...), audit.valid)
        r_tr, valid, delta_tr = inflate_radius(r_omega(omega_t), tau)
        P_t = issue_cert(r_tr)
    if (not valid) or conflict(y, transfer_prior) > theta_d:
        return conservative_box(omega_t), 'degrade'
    if leases.i.B_h <= 0 and risk(P_t) > theta_risk:
        return 'fail-closed', 'interaction-budget'
    return P_t, 'active-transfer'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| ATM 迁移性估计 | O((n_s+n_t)·d + n_a) | O(n_a·d) | τ 下降即时生效，半径对 τ 单调有效 |
| AXI 查询选择 | O(\|Q\|·\|Y\|·H) | O(\|Y\|·d) | 三重门控保证查询动作不越证书 |
| TC2 加权共形 | O(n_a log n_a) | O(n_a) | 覆盖率 ≥1-α-TV-ε_W（截断补偿） |
| ATL 全局决策 | O(\|Q\|·\|Y\|H + n_a log n_a) | O(\|Q\|+\|Y\|) | τ/能量/交互三租约失效即回退 |

正确性定理：设迁移性估计满足 |τ̂-τ|≤ε_τ，加权共形的密度比截断误差为 ε_W，交互动作全部通过 no-motion-beyond-cert 过滤。若 τ̂≥τ_min 且审计有效，则 J_t^AT 的覆盖率满足
P(X_t∈P_t^tr) ≥ 1-α_p - δ_tr(τ̂) - L_τ·ε_τ - TV(p_s,p_t) - ε_W；
若 τ̂<τ_min、人类回答与先验分歧 >θ_d、或 B_h 耗尽且风险超阈，则系统退保守姿态盒或 fail-closed，不签发跨域证书。因此传输误差只会使证书变宽或系统降级，不会让 J_t^AT 在未审计的跨域先验上“假装有效”。

| E116 跨域证书覆盖率 | 新房间/新物体集实测覆盖率 | ≥ 1-α-δ_tr（如 0.95 目标下 ≥ 0.93） |
| E117 主动查询效率 | 每场景提问数、正 VoI 比、消歧成功率 | 提问 ≤ 3/场景；正 VoI ≥ 70%；成功率 ≥ 85% |
| E118 负迁移检出 | 检出召回、误报率、降级及时性 | 召回 ≥ 90%；误报 ≤ 5% |
| E119 交互负担与安全 | 提问/小时、NASA-TLX、越证书动作数 | 提问 ≤ 12/小时；TLX 不升 20%；越证书 0 次 |
| E120 100h 跨域闭环 | 新场景/任务/操作者下覆盖率、任务成功率、fail-closed 次数 | 覆盖 ≥ 97%；成功 ≥ 95%；非计划停机 0 起 |

回退策略：E115 ECE>0.15 或 τ 校准失败 → 关闭迁移复用，全部目标域重校准；E116 覆盖率不达标 → 提高 Δ_0 与 α、禁用 IP-72 演示迁移；E118 误报过高 → 缩短审计窗口、降 τ_min；E119 人类负担超标 → 优先改用 self_probe/viewpoint_change，仅在关键处 ask_human；E120 fail-closed 频繁 → 预置保守深度+停等策略并重新分配交互预算。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| τ 被高估（尤其退化层先验相反） | 高 | τ 上升需独立审计放行；δ_tr 显式入覆盖率界；τ_min 保守设定 |
| 人类回答错误/敷衍形成虚假高置信 | 高 | 回答按带噪声弱标签入库；与视觉/深度互检；分歧>θ_d 即降级 |
| 提问过多造成人类负担与任务中断 | 中 | 交互租约 B_h 硬预算；VoI 门槛；优先自探测/换视点 |
| 负迁移下证书静默变窄 | 高 | 半径只随 τ 下降而膨胀；负迁移告警冻结源域记忆 |
| 密度比截断导致覆盖率高估 | 中 | ε_W 补偿；W 越界自动抬 α；小样本保守分位 |
| 迁移与主动交互互相“自证” | 中 | 审计集与训练/查询集隔离；CCA 注入误导回答红队 |

## 6. 本轮最大风险

**一句话**：迁移性 τ 可能被高估、人类回答又可能是带噪声甚至敷衍的弱标签，两者叠加会让系统产生“虚假高置信”，使膨胀后的姿态证书仍不足以覆盖真实误差并静默失效；因此必须让 τ 的上升只由独立审计集放行、把人类回答当作弱标签并做视觉-深度互检，并在任何冲突或交互预算耗尽时 fail-closed。
