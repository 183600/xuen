# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感驱动研究循环第 2 轮；本轮灵感：「语义建图」×「闭环控制」）

> 第 54 轮把技能组合做成「动作空间剖面 α_S + 云边映射 γ_ce + 联合证书 J」的可判定路径。本轮补上其缺失的两层语义：**动作空间回答“能做什么动作”，语义地图回答“动作在环境语义上意味着什么”；闭环控制回答“做完后如何知道自己做对了”**。核心矛盾：H22——几何精确 ≠ 语义正确，只用几何误差闭环的系统会「精确地做错事」，而现有 ρ / A_cert / J 证书对此完全盲；H23——语义地图不是静态参考系，它会漂移与过时，若建图不进入控制闭环，则控制越稳、语义偏离越深。

## 0. 直觉与动机

**灵感 1（语义图作为控制参考系 → 目标从位姿提升为关系约束）**
直觉：任务目标天然是关系式的（“杯子在桌上”“门已关”“手持的是螺丝刀而非扳手”）。把目标表达为语义约束集 `G = {g_1,...,g_m}`，每个 `g_j` 是对象-关系-属性谓词，控制参考便从几何位姿 `x*` 升级为语义图 `G`。几何位姿只是语义目标的一个实现方式；同一语义目标可对应一族几何构型。这让控制器面向“任务意图”而非“指定坐标”。

**灵感 2（语义残差作为独立反馈通道 → 拒绝「精确地做错」）**
直觉：闭环控制不能只有几何残差 `e_geo`，必须有语义残差 `e_sem(t) = d_sem(M_t, G)`——由当前信念语义图与目标语义图的差分给出。控制器联合最小化 `e_geo` 与 `e_sem`；当 `e_sem` 超阈而 `e_geo` 很小，正是**语义错位**的典型信号（拿了错对象、放错关系），必须中止或重规划，而不是继续压几何误差。

**灵感 3（建图进闭环 → 感知-建图-控制三者收缩）**
直觉：语义地图版本 `M_t` 由控制动作产生的观测 `z_{t+1}` 更新，`M_{t+1}=U(M_t,z_{t+1},u_t)`；同时地图证书 `SMC` 的置信度/新鲜度反过来门控控制（`stale` 超阈则先重观测再动作）。于是形成 **建图→控制→观测→校图** 的闭环。可判定性条件：语义可观测（执行动作落在 `A_obs` 内）、闭环时延小于地图漂移时间常数、且语义误差在闭环下收缩。

**灵感 4（语义可观测性作为动作选择的一等约束）**
直觉：不是所有动作都能“看清”语义后果。抓取只看几何就无法确认抓的是不是目标类别；需要**主动消歧动作**（转视角、轻抬、触摸）。定义 `obs(a,Q)` 并据此裁剪动作空间：`A_obs(Q) = {a : obs(a,Q) ≥ θ_obs}`。这把第 54 轮的 `α_S` 动作剖面从“能否执行”升级为“执行后能否语义判定”，拒绝在不可观测动作上承诺语义证书。

**灵感 5（与鲁棒性/云边层的耦合 → 语义闭环联合证书）**
直觉：第 54 轮联合证书 `J` 只覆盖动作对齐与鲁棒性；本轮增补语义地图证书 `SMC` 与收缩证书 `(κ,δ)`，形成 `J_sem = (ρ, A_cert, γ_ce, δ_a, SMC, κ, δ, evidence)`。云端与边端还须校验**地图版本一致**（`ver` 哈希相同），否则粗规划基于的语义图与边端实际信念图不同，`γ_ce` 再精确也无意义。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（语义地图）**
语义地图 `M_t = (O_t, R_t, Λ_t, Σ_t, ver_t)`：
- `O_t`：对象实例集合，`o=(id, x_o, c_o)`，`x_o∈SE(3)`，`c_o` 为类别；
- `R_t ⊆ O_t×O_t×ℛ`：关系三元组（on / in / near / holding / occludes…）；
- `Λ_t : O_t×Attr → [0,1]`：属性/类别置信度；
- `Σ_t`：位姿与语义不确定度；
- `ver_t`：内容哈希版本。

语义距离 `d_sem(M,M') = α_o·d_obj + α_r·d_rel + α_a·d_attr ∈ [0,1]`，其中 `d_obj` 为匈牙利匹配后的对象位姿距离、`d_rel` 为关系图 `R` 的编辑距离、`d_attr` 为匹配对象属性置信度之差。

**定义 122（语义可观测性）**
对动作 `a`、任务查询集 `Q`（目标所需关系/属性），
```
obs(a,Q) = I(Q ; z_{t+1} | M_t, a) / H(Q) ∈ [0,1]
```
为归一化互信息，用重复 rollout 与标签扰动经验估计。**语义可观测动作集** `A_obs(Q;θ_obs) = {a∈A : obs(a,Q) ≥ θ_obs}`。只有当执行动作落在 `A_obs` 内，语义残差才可作为反馈使用。

**定义 123（语义残差）**
目标语义约束 `G={g_1..g_m}`，软满足度 `sat(g_j,M_t)∈[0,1]`（由 `Λ_t` 与 `R_t` 计算）。语义残差
```
e_sem(t) = [1 - sat(g_1,M_t), ..., 1 - sat(g_m,M_t)]，  ||e_sem||_1/m ∈ [0,1]
```
与第 54 轮几何残差 `e_geo` 并列，构成双通道反馈。

**定义 124（语义闭环系统）**
离散时间系统：
```
u_t = π(x_t, M_t, G)
x_{t+1} = f(x_t,u_t),   z_{t+1} = h(x_{t+1}) + η
M_{t+1} = U(M_t, z_{t+1}, u_t)
```
代价 `J = Σ_t [ e_geoᵀ Q e_geo + e_semᵀ R e_sem + u_tᵀ U u_t ]`。控制律 `π` 必须满足：`u_t` 的执行动作 ∈ `A_obs(Q;θ_obs)`，且 `M_t` 的 `SMC` 有效。

**定义 125（语义收缩性）**
闭环 `Φ` 在域 `D` 上称 `(κ,δ)`-语义收缩，若
```
∀M_t∈D:  d_sem(M_{t+1}, G) ≤ κ·d_sem(M_t, G) + δ,  0 ≤ κ < 1
```
则 `limsup_{t→∞} d_sem(M_t,G) ≤ δ/(1-κ)`。部署准入要求 `δ/(1-κ) ≤ Θ_sem`。

**定义 126（语义地图证书 SMC）**
```
SMC = (ver, cover, stale, prov, Δ_sem)
```
- `ver`：地图版本哈希；
- `cover`：任务相关区域被置信度 ≥ θ_cov 观测到的比例；
- `stale = now - last_validated`：距上次校验的时间；
- `prov`：支撑每条关键约束 `g_j` 的观测来源集合（可追溯）；
- `Δ_sem`：自上次校验以来的语义漂移上界。
`SMC` 有效 ⇔ `cover ≥ θ_cov ∧ stale ≤ Θ_stale ∧ Δ_sem ≤ Θ_drift ∧ ∀g_j∈G_crit: prov(g_j)≠∅`。

**定义 127（语义闭环联合证书）**
```
J_sem = (ρ, A_cert, γ_ce, δ_a, SMC, κ, δ, evidence)
```
在第 54 轮 `J` 上增补 `SMC` 与收缩常数 `(κ,δ)`。可部署 ⇔
```
dom_J(T)=in ∧ δ_a<Θ_a ∧ SMC valid ∧ κ<1 ∧ δ/(1-κ) ≤ Θ_sem ∧ ver_cloud = ver_edge
```
最后一项为云边语义图版本一致性；`evidence` 需含语义残差轨迹与关键约束的 provenance。

## 2. 关键算法 伪代码

### IP-121 SMM（Semantic Map Maintenance）

```python
def semantic_update(M, z, u, t):
    O_new = associate(M.O, z, gate=chi2_gate(M.Sigma))
    for o, z_o in O_new:
        M.pose[o]  = fuse_pose(M.pose[o], z_o)        # EKF / pose-graph
        M.attr[o]  = bayes_update(M.attr[o], z_o.labels)
    R_new = infer_relations(M.O, M.pose, M.attr)      # 几何+学习关系
    M.R   = reconcile(M.R, R_new, huber=True)         # 抑制单帧跳变
    drift = d_sem(M, M.last_validated)
    M.ver = content_hash(M.O, M.R, M.attr)
    return M, drift

def drift_gate(drift, Theta_drift):
    return drift > Theta_drift    # 触发重校验 / 降速 / 重观测
```

### IP-122 SOC（Semantic Observability Characterization）

```python
def semantic_observability(skill, Q, sampler, n=32, theta_obs=0.6):
    A_obs = {}
    for a in action_grid(skill):
        snaps = [sampler.rollout(skill, a).semantic_snapshot() for _ in range(n)]
        obs   = normalized_mutual_info(snaps, Q)      # 对标签扰动稳健估计
        A_obs[a] = obs
    return {a: o for a, o in A_obs.items() if o >= theta_obs}
```

### IP-123 SEC（Semantic Error Control）

```python
def semantic_control(x, M, G, rho_min, Theta_sem, Theta_stale):
    e_geo = geometric_error(x, G)
    e_sem = semantic_residual(M, G)
    if M.stale > Theta_stale or not map_certificate_valid(M):
        return ('hold', request_reobserve(G.critical))
    a = policy(x, M, G, e_geo, e_sem)
    if a not in A_obs(G.query):                       # 不可观测动作禁止承诺语义
        a = disambiguate(M, G)                        # 主动消歧（转视角/轻抬）
    if l1(e_sem)/len(e_sem) > Theta_sem:
        return ('abort_or_replan', explain_semantic(M, G))
    return ('act', a, e_sem)
```

### IP-124 SMC（Semantic Map Certificate）

```python
def semantic_map_certificate(M, task, now, COV, STALE, DRIFT):
    cover   = coverage(M, task.relevant_region)
    stale   = now - M.last_validated
    prov_ok = all(M.provenance.get(g) for g in task.critical_constraints)
    delta   = semantic_drift_bound(M)                 # SMM drift + 标签噪声上界
    ok = cover >= COV and stale <= STALE and prov_ok and delta <= DRIFT
    return SMC(M.ver, cover, stale, M.provenance, delta, ok)
```

### IP-125 SCC（Semantic Contraction Certificate）

```python
def contraction_certificate(traj_M, G, kappa_budget, delta_budget):
    ds = [d_sem(M, G) for M in traj_M]
    for t in range(len(ds) - 1):
        if ds[t+1] > kappa_budget * ds[t] + delta_budget:
            return ('reject', 'contraction_violated', t)
    return ('ok', fit_kappa(ds), fit_delta(ds))
```

### IP-126 SJC（Semantic Joint Certificate）

```python
def semantic_joint_certificate(J, SMC, traj_M, G, budgets):
    if not SMC.valid:                 return ('reject', 'map_certificate_invalid')
    if J.domain != 'in' or J.delta_a > budgets.a:
        return ('reject', 'action_mismatch', J.delta_a)
    status, kappa, delta = contraction_certificate(traj_M, G, budgets.k, budgets.d)
    if status != 'ok' or kappa >= 1 or delta/(1-kappa) > budgets.sem:
        return ('reject', 'non_contraction', kappa, delta)
    if SMC.ver != budgets.expected_ver:
        return ('reject', 'cloud_edge_version_mismatch', SMC.ver)
    return ('ok', J_sem(J.rho, J.A_cert, J.gamma_ce, J.delta_a, SMC, kappa, delta))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SMM | O(|O|+|R|·|O|) / 次更新 | O(|O|+|R|) | 关联门限保守、关系调和单调 |
| SOC | O(|A|·|Q|·n) | O(|A|·|Q|) | obs 估计无偏、θ_obs 校准 |
| SEC | O(T·(|O|+|R|)) | O(|O|+|R|) | 收缩 κ<1、门控无抖动 |
| SMC | O(|O|+|R|) | O(|O|+|R|) | cover/stale/prov 可核验 |
| SCC | O(T) | O(1) | 收缩常数在时域上成立 |
| SJC | O(|S|·|A|+|O|+|R|) | O(|O|+|R|+T) | 联合证书 sound、版本一致 |

**正确性定理（Semantic Closed-Loop Soundness）**
假设第 54 轮 (A22)–(A28) 成立；新增 **(A29)** 语义更新算子 `U` 对任务约束集 `G` 满足 `drift ≤ Θ_drift` 且关系调和单调（不虚假删除已满足约束）；**(A30)** 实际执行动作 ⊆ `A_obs(Q;θ_obs)`；**(A31)** 闭环时延 `τ_loop < τ_drift` 且闭环为 `(κ,δ)`-语义收缩。则
```
d_sem(M_t, G) ≤ κ^t · d_sem(M_0, G) + δ/(1-κ)
P_success ≥ 1 - [δ/(1-κ) + (1-cover) + P(stale>Θ_stale) + P(ver 失配)]
```
关键：**语义可观测是可反馈的前提，收缩性是可收敛的前提，版本一致是云边可协同的前提**——三者缺一则 `J_sem` 不成立。

## 4. 实验设计 E162–E166

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 语义漂移检测 | drift 检测 F1 / 误报率 | F1 ≥ 0.90，FP ≤ 5% |
| E163 语义可观测性校准 | `A_obs` 预测执行成功的 AUC / 覆盖率 | AUC ≥ 0.85，覆盖 ≥ 90% |
| E164 语义闭环收缩 | 实测 `κ̂`、稳态 `e_sem` | `κ̂ ≤ 0.8`，稳态 ≤ 0.10 |
| E165 “精确做错”率 | 语义错误率 vs 仅几何闭环 | 相对降低 ≥ 40% |
| E166 云边语义版本一致性 | 因 ver 失配导致的部署失败 | 降低 ≥ 30% |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 语义标签噪声制造虚假残差 | 高 | 置信度门控 + hysteresis + 标签校准 |
| 地图漂移快于闭环（τ_drift < τ_loop） | 高 | 在线估计 τ_drift + stale 回退重观测 |
| 语义可观测性欠采样导致虚假覆盖 | 高 | 主动消歧动作 + 主动采样 + 红队场景 |
| 云边语义本体/版本不一致 | 中 | 共享本体 + ver 哈希契约 + 版本失配拒绝部署 |
| 语义图差分超控制周期 | 中 | 增量图差分 + 关键约束优先计算 |

## 6. 本轮最大风险

**一句话**：语义闭环把控制从“几何准确”提升为“语义可判定”，但其 soundness **三重依赖语义可观测性的可靠校准、地图漂移慢于闭环时延、以及标签/本体的跨端一致**；一旦 `obs` 被高估或 `τ_drift` 被低估，控制器会在所有几何证书与鲁棒性证书全绿时“精确地做错事”，且错误被语义残差自身掩盖——故必须以 **主动消歧采样 + 漂移实时监测 + 版本一致性硬门控** 三重护栏，宁可停下来重观测，也绝不把“语义可观测的假象”当作闭环可收敛的前提。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-SemClose（SMM×SOC×SEC×SMC×SCC×SJC）

> 承接第 54 轮产物 v31。本轮在「动作空间剖面 + 云边协同」之上，增加 **语义建图进入控制闭环** 的算子族：

```python
    if l1(e_sem) / len(e_sem) > Theta_sem:
        return ('abort_or_replan', explain_semantic(M, G))
    return ('act', a, e_sem)
```

### IP-124 SMC

```python
def semantic_map_certificate(M, task, now, COV, STALE, DRIFT):
    cover = coverage(M, task.relevant_region)
    stale = now - M.last_validated
    prov_ok = all(M.provenance.get(g) for g in task.critical_constraints)
    delta = semantic_drift_bound(M)
    ok = cover >= COV and stale <= STALE and prov_ok and delta <= DRIFT
    return SMC(M.ver, cover, stale, M.provenance, delta, ok)
```

### IP-125 SCC

```python
def contraction_certificate(traj_M, G, kappa_budget, delta_budget):
    ds = [d_sem(M, G) for M in traj_M]
    for t in range(len(ds) - 1):
        if ds[t+1] > kappa_budget * ds[t] + delta_budget:
            return ('reject', 'contraction_violated', t)
    return ('ok', fit_kappa(ds), fit_delta(ds))
```

### IP-126 SJC

```python
def semantic_joint_certificate(J, SMC, traj_M, G, budgets):
    if not SMC.valid:
        return ('reject', 'map_certificate_invalid')
    if J.domain != 'in' or J.delta_a > budgets.a:
        return ('reject', 'action_mismatch', J.delta_a)
    status, kappa, delta = contraction_certificate(traj_M, G, budgets.k, budgets.d)
    if status != 'ok' or kappa >= 1 or delta / (1 - kappa) > budgets.sem:
        return ('reject', 'non_contraction', kappa, delta)
    if SMC.ver != budgets.expected_ver:
        return ('reject', 'cloud_edge_version_mismatch', SMC.ver)
    return ('ok', J_sem(J.rho, J.A_cert, J.gamma_ce, J.delta_a, SMC, kappa, delta))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SMM | O(|O|+|R|·|O|)/更新 | O(|O|+|R|) | 关联门限保守、关系调和单调 |
| SOC | O(|A|·|Q|·n) | O(|A|·|Q|) | obs 无偏估计、θ_obs 校准 |
| SEC | O(T·(|O|+|R|)) | O(|O|+|R|) | κ<1、门控无抖动 |
| SMC | O(|O|+|R|) | O(|O|+|R|) | cover/stale/prov 可核验 |
| SCC | O(T) | O(1) | 收缩常数时域成立 |
| SJC | O(|S|·|A|+|O|+|R|) | O(|O|+|R|+T) | 联合证书 sound、ver 一致 |

**正确性定理（Semantic Closed-Loop Soundness）**
第 54 轮 (A22)–(A28) 成立；**(A29)** `U` 对 `G` 满足 `drift ≤ Θ_drift` 且关系调和单调；**(A30)** 执行动作 ⊆ `A_obs(Q;θ_obs)`；**(A31)** `τ_loop < τ_drift` 且闭环 `(κ,δ)`-语义收缩。则
```
d_sem(M_t,G) ≤ κ^t·d_sem(M_0,G) + δ/(1-κ)
P_success ≥ 1 - [δ/(1-κ) + (1-cover) + P(stale>Θ_stale) + P(ver 失配)]
```
关键：**语义可观测可反馈、收缩性可收敛、版本一致可协同**。

## 5. 本轮最大风险

**一句话**：语义闭环把控制从“几何准确”提升为“语义可判定”，但其 soundness **三重依赖语义可观测性的可靠校准、地图漂移慢于闭环时延、以及标签/本体的跨端一致**；一旦 `obs` 被高估或 `τ_drift` 被低估，控制器会在所有几何证书与鲁棒性证书全绿时“精确地做错事”，且错误被语义残差自身掩盖——故必须以 **主动消歧采样 + 漂移实时监测 + 版本一致性硬门控** 三重护栏，宁可停下来重观测，也绝不把“语义可观测的假象”当作闭环可收敛的前提。
