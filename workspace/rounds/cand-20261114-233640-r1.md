# 第 3 轮（灵感循环第 3 轮；本轮灵感：「知识图谱」×「动力学」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440）。
> 本轮纪律：**在前人基础上改进，而不是推倒重来**——ToolGauge 的 6C 六段闭环、MTC/TCV 工具契约、
> MP-Φ/AP-Cal 摊销先验、P-Quarantine 断路器、MODGAUGE 五不变式与 4CV 骨架全部保留；
> 两条灵感分别沿「结构关系」与「时间演化」两轴升级，并审计并修复第 2 轮遗留的七处缺陷（见 §5）。

## 三位一体映射（升级而非重写）

**核心命题**：把 ToolGauge 的
「语义假设 → 契约化工具调用 → 摊销校准 → 交叉验证后局部热替换」
升级为
「**关系化假设 → 契约化工具调用 → 时变摊销滤波 → 溯源定界的失效与主动维护**」：
知识图谱负责**结构依赖**（根因共享、工具失败迁移、污染的精确影响域），
动力学负责**时间依赖**（参数漂移、盲区生灭与复发、证据老化、预测性调度）。
两者都是**带外元数据层**：数值真值仍由计量层独占，50Hz 路径与 MODGAUGE 五不变式原样保持。

**不变式保持声明**：
- MODGAUGE 五不变式全部保留；
- **组合单调性扩展**：图/时间层只做**删除性投影**（污染失效=回退到干净祖先，证据过期=降级主张），不得引入新的数值行为；同一契约版本内污点单调增长，重建版本开新谱系根；
- **主张绑定扩展**：语言主张不仅须引用有效回执，还须引用一条**时间一致、无环、未被污染**的溯源路径（定义 443）；否则剥离；
- **严格退化链延长**：ChronoGauge ⇒ ToolGauge（丢图/丢动力学，保留契约）⇒ LeanGauge（纯数值探测）⇒ MODGAUGE。图与动力学是增强项，不是依赖项。

## 0. 直觉与动机

**灵感 1（知识图谱 → 盲区不是孤岛，污染范围可被图精确圈定）**
直觉：第 2 轮里盲区是逐个 independent 修复的；虽然 AP-Cal 共享了先验，但**没有记录「谁影响了谁」**。
于是当 P-Quarantine 闻到先验偏差时，它只有两个极端选择：全信，或**全局暂停并回退所有人**——这恰好把
「局部修复、误差局部化」的安全论证反向牺牲掉了：一次可疑先验会让全系统的摊销能力瞬间归零。
知识图谱同时治两种病：
(a) **假设病**：共享材质/光照/工具失败指纹的盲区在图上成簇，多跳推理可把已确认根因迁移给新盲区，
省样本、少探测；
(b) **定界病**：若每个契约字段都写入连向「所用先验输出 / 假设 / 回执 / 父版本」的溯源边，那么
一个可疑先验的**伤害集**就等于图上的可达闭包。我们精确失效这个集合、保留其余健康子树——
「一次错误先验污染所有子图」从一句不可操作的风险，变成一个**有边界的、可证伪的集合**。
直觉一句话：**把风险的形容词，换成图的动词（reachability）。**

**灵感 2（动力学 → 世界在变，证据会过期，盲区会复发）**
直觉：第 2 轮默认世界准静态、数据可交换、修好即永久。现实里盲区是一个**种群**：
会**出生**（新遮挡、热漂移、材质变化）、**迁移**、**合并**（两个症状同一根因）、**分裂**、以及最要命的
**复发**（修好后又出现）。同时，一条回执的可用性随年龄衰减。动力学给出四件事：
(a) 每个盲区的风险/生存模型 → 预测「下一个最值得修的是谁」（主动维护、预算分配）；
(b) 契约参数随时间的随机过程（OU/AR(1)），摊销先验从「静态映射」变为「滤波/跟踪器」；
(c) 时变共形 / ACI → 漂移下仍有覆盖保证，而非只靠一个静态 SLA 阈值；
(d) 证据时效与合同寿命 → 「已修复」有半衰期，到期**软失效**（重评分），与污染的**硬失效**分离。
直觉一句话：**从「修一次」到「养一个会变化的盲区种群」。**

**灵感 3（合流 → 在时空因果图上闭环，7C）**
直觉：只有图没有动力学，是一张静态地图；只有动力学没有图，是逐节点跟踪却看不见共享根因。
二者合流后，C-STKG 是**共享底座**：H/C 阶段读图，U/W 阶段写图。闭环从 6C 变 7C，多出最后一步 **W（Weave，回写）**：
原子地写入溯源边、更新动力学状态、设置合同到期时间、刷新调度优先级、生成 RepairCert 的图切片。
失效不再是「暂停一切」，而是**图手术**：求闭包 →  tombstone 污染版本 → 回退干净祖先/ stub+RED → 仅重排这些盲区。
下游主张层只接受时间一致、无环、未污染的溯源路径；被污染路径上的主张在序列化时剥离。

## 1. 形式化定义（增量：定义 432–447）

**定义 432（时空因果知识图谱 C-STKG）** G_t = (V, E, τ_V, τ_E, W)：
- V 为类型化实体节点：区域 r、盲区 s、材质/模态 m、工具 t、假设 h、回执 ρ、契约版本 v（即 EC_v）、语言主张 c、失败模式 f、先验输出 π；
- E ⊆ V × R × V 为类型化有向边，关系集 R 见定义 433；W 为边权（因果支持度 / 对数几率）；
- τ_V: V → 2^T、τ_E: E → 2^T 给出**时间有效期**；时序查询 G_t 只保留在 t 有效的边；
- **溯源子图** G^prov ⊆ G 仅含 PROV_RELS = {influences, derivedFrom, supersedes, uses, cites}，其中 influences/derivedFrom/supersedes 构成 **DAG**（定义 443）。

**定义 433（本体 O_STKG，预注册）** 实体类型 + 关系签名与值域固定，禁止运行时自由扩张（防提示注入，扩展定义 429）：
- 空间：locatedIn(s,r)、adjacent(r,r′)、sharesMaterial(s,m)、sharesLighting(s,m)；
- 因果/证据：causes(f,s)、refines(h,h′)、supportedBy(h,ρ)、probes(t,s)、failedOn(t,f)、predicts(π,s)；
- 版本/溯源：uses(v,π)（契约版本用了哪个先验输出）、influences(π,v)、derivedFrom(v,v′)、cites(c,ρ)、invalidates(v′,v)、supersedes(v,v′)；
- 时序：before(x,y)、coincides(x,y)、recurs(s,s′)（复发）。

**定义 434（溯源谱系、污染闭包与两级粒度）**
- Lin(v) = 影响 v 数值字段的全部实体（先验节点、假设、回执、父版本）；
- 先验节点分**两级粒度**：π_local（某次上下文条件下的单次输出，连边到具体 v）与 π_root（共享权重，连边到**所有**使用 Dyn-Φ 的 v）。这显式建模「隐式全局耦合」：怀疑局部输出 ⇒ 闭包局部；怀疑共享权重 ⇒ 闭包=全局（正确退化为第 2 轮的全局暂停）；
- 对可疑集 X，**污染闭包** Closure_{G_t}(X) = 从 X 沿 PROV_RELS 在 t 有效边上可达的契约版本集合；
- 污点单调：版本内一旦被污染，其后续派生版本均污染；由**干净证据重建**的新版本开新谱系根，不继承污点。
- 可靠性/最小性见引理 51。

**定义 435（关系化多跳假设 KG-Hypo）** 推广定义 422：候选由 C-STKG 上**有界 k 跳**邻域 N_k(s) 生成：
Cand(s) = { h : h = 邻居 s′ 的已确认根因沿因果边迁移，且 h 至少有一条跨模态指纹边支撑 }；
打分融合 VLA 语义先验（第 2 轮）与图关系分数（如相邻已确认根因的贝叶斯对数几率）；
共形校准在关系特征上进行，保证 P(h*∈H_s) ≥ 1−α（可交换性下；漂移下用定义 439）。
**约束**：k ≤ k_max（默认 3）；每一跳必须携带类型化关系且该边有证据，否则剪枝（抑制「多跳幻觉」）。

**定义 436（盲区种群动力学 S_t）** 盲区是区域图上的**集合值随机过程**，事件强度：
- 出生 λ_b(r,t)（环境变化后的 Hawkes 自激）、死亡 λ_d(s,t)（生存模型）、迁移 λ_m（沿 adjacent 核）、
- 合并（同一根因的 merge 边）、分裂（一因多果）、**复发** λ_r(s,t)（死而复生，用 recurs 边标记）。
模型：**条件**半马尔可夫（生存分布可非指数，如 Weibull）+ 邻接迁移核 + 变点处 Hawkes 激发。
即只假设「给定变点过程后条件马尔可夫」，模型失配由定义 442 监控。

**定义 437（风险/生存与期望盲区质量）** 每盲区 s：风险率 h_s(t)（瞬时死亡/复发强度），生存函数 S_s(t)；
后果权重 w_s = 若不修则产生的期望数值误差（σ_conf × 下游使用度）。视界 H 内的**期望盲区质量**
M(H) = Σ_s w_s · P(s 在 t+H 仍存活)。该标量驱动调度。
风险率由 C-STKG 事件史（含右删失）估计，并给出 Bootstrap/共形区间；区间过宽 ⇒ 退回均匀优先级（鲁棒）。

**定义 438（时变摊销校准 Dyn-Φ / TAP-Cal）** 潜在契约参数 u_s(t) 服从 AR(1)/OU：
u_{s,k+1} = φ_s·u_{s,k} + (1−φ_s)·μ_phys + w_k，w_k ~ N(0,Q_s)，φ_s∈(0,1)。
Dyn-Φ_θ 是**预训练摊销滤波器**：(h, 带时间戳的回执流, 图邻域上下文) ↦ q_θ(u_s(t)|·)=N(μ,Σ)；
训练加入多步预测损失与时间一致性项；物理先验 p_phys 仍是 KL 锚与方差下界 κ_phys（继承定义 420）。
φ→1、Q→0 时退化为第 2 轮静态 AP-Cal。**证据老化**：回执按年龄 a 以 e^{−λ_age·a} 加权（等价地把过程噪声注入方差），陈旧证据不能过度收紧 Σ。

**定义 439（时变共形 / ACI 覆盖）** 以漂移鲁棒校准替代可交换性：
- 时间加权共形：权重 w_i ∝ e^{−γ(t−t_i)}，有效样本量 n_eff；
- 自适应共形推断 ACI：维护 α_t，α_{t+1} = α_t + η(α − err_t)，err_t=1[未覆盖]。
保证：有界漂移下长期误覆盖率 → α；有限样本覆盖 ≥ 1−α−2η′L′（延续引理 48），η′ 为每步漂移 TV；
**当动力学模型预测的 η′ 超过预算 η′_max ⇒ H_s := {UNKNOWN}（退化链第 1 级）**——由动力学**预测性**触发，而非事后 SLA 触碰。

**定义 440（证据时效与合同寿命）** 每个契约版本 v 带到期 T_exp(v) = t + τ_valid(s)，
τ_valid 由 OU 混合时间/风险率导出（预测方差升到先验方差某比例所需时间）。
到期后 v 在 C-STKG 标记 `stale`：引用陈旧回执的主张降级/剥离（扩展 423）；对应盲区重新进入调度（**软失效**，不等于必须重新探测）。
与污染的**硬失效**（定义 444）分离。

**定义 441（动力学调度器 / 主动维护）** 每个异步 tick，在全局预算 B（定义 446）下选取修复/探测动作，最大化 E[ΔM]：
优先级指数 π_s = w_s·h_s(t)/cost_s。空间分离、盲区收益独立且对探测努力边际递减时，目标为单调子模 ⇒
**等代价**下贪心按 π 排序达 (1−1/e)（引理 54）；一般代价用密度贪心（保证 (1−1/e)/2 量级），小规模用 Sviridenko 型枚举达 (1−1/e)。
**主动探测**：对预测高 urgency 的盲区，在低负载窗口预排非侵入探测（PROBING 态，定义 430），缩短未来修复时延。

**定义 442（模型失配监控与图-动力学一致性）**
- 变点检测：对回执残差跑 CUSUM/贝叶斯在线变点 → 触发风险率重估；
- 预测校准：预测 vs 实际盲区质量（P-Quarantine 的动力学版）；ECE > ε_dyn ⇒ 动力学退化为均匀先验；
- 图一致性：孤立主张（无路径）、时间悖论（边有效期与节点出生冲突）、溯源环 ⇒ 硬错误，丢弃版本并退化。
它把定义 428 的「全局符号检验」升级为**局部化、多信号、图感知**的监控。

**定义 443（图-时间一致性约束）**
(i) 溯源子图无环：不存在 v 经 {influences, derivedFrom, supersedes} 回到自身；
(ii) 路径时间一致：主张 c 到回执 ρ、再到契约版本 v 的派生链，所有边有效期含派生时刻，且 ts(ρ) ≤ t(c)；
(iii) 语言不串染：主张只能引用**未被污染**溯源路径上的有效回执，否则剥离（扩展 423）；
(iv) 污点单调：版本内只增不减；替换版本开新谱系根。

**定义 444（污染失效协议 P-Invalidate，取代/推广 428）** 对可疑 X（先验输出/假设/工具）：
1. 增量可达求出 C = Closure_{G_t}(X)；
2. 对每个 v∈C **硬失效**（tombstone），回退到最近干净祖先；若无干净祖先 ⇒ stub + RED（严格退化）；
3. 仅把 C 中盲区按 urgency 重排；**C 之外一律不碰**；
4. 记 invalidates 边与审计日志（RepairCert 扩展）；
5. 若 |C|/|V| > θ_global（污染过广 ⇒ 先验结构不可信）⇒ 升级到全局暂停（第 2 轮行为）。
故**第 2 轮 P-Quarantine 是本协议 C=V 的特例**，本协议严格推广之并修掉「过度回退」。

**定义 445（7C 闭环 + W 回写）** 扩展定义 421：H→C→E→C→V→U→**W**。
W（Weave）在 U 之后**原子地**：(a) 为每个变更字段写溯源边（uses/influences/derivedFrom/cites）；
(b) 用新回执更新动力学（风险率、OU 后验、变点状态）；(c) 设定 T_exp 与复发标记；(d) 刷新 urgency；
(e) 生成含图切片与时间戳的 RepairCert。W 事务化：写失败 ⇒ 回滚 U（溯源未提交前契约不被信任），扩展契约完整性不变式。

**定义 446（全局预算契约 G-Contract）** 把 TB-Contract（424）从「单盲区」推广到「全局+时间」：
G = (B_global(H), 每盲区 B_tools, L_max, τ_repair, τ_valid, θ_global, recovery)。
保证：(a) 无赌博（硬顶）；(b) 无饥饿（时序公平：每个存活盲区在 W_max 内被服务一次）；
(c) 预留主动预算 B_pro ≤ ρ·B_global，避免主动维护挤占紧急修复。

**定义 447（继承与退化到 ToolGauge）** 第 2 轮记号（定义 416–431）全部沿用。ChronoGauge 退化为 ToolGauge：
C-STKG→空图（Closure=全体）、动力学→静态（φ=1,Q=0、风险率常数、T_exp=∞、调度=FIFO），
即 P-Invalidate ≡ P-Quarantine、TAP-Cal ≡ AP-Cal、7C ≡ 6C；再按原链退化到 LeanGauge ⇒ MODGAUGE。

## 2. 关键算法骨架

```python
# IP-321 KG-Box + C-STKG：时空因果图、多跳假设、溯源闭包
@dataclass
class Edge:
    src: Node; rel: str; dst: Node; t0: float; t1: float = INF; w: float = 1.0

class STKG:
    PROV = {"influences", "derivedFrom", "supersedes", "uses", "cites"}
    def add_edge(self, e):
        assert e.rel in self.ontology and self.ontology.valid(e)   # 定义 433
        self.edges.append(e); self._inc_index(e)
    def view(self, t):                       # 时间切片
        return TemporalView(self, t)         # 只暴露 t 有效的边
    def closure(self, X, t):                 # 定义 434：污染闭包（增量可达）
        seen, frontier = set(X), list(X)
        while frontier:
            u = frontier.pop()
            for e in self.out_edges(u, rels=self.PROV, t=t):
                if e.dst not in seen:
                    seen.add(e.dst); frontier.append(e.dst)
        return seen

class KGBox:
    def hypothesize(self, s, R_cell, kg, cfg):
        cand = []
        for s2 in kg.khop(s, k=cfg.k_max, rels={"causes", "refines", "recurs"}):
            root = kg.root_cause(s2)                         # 已确认根因
            if kg.has_fingerprint_edge(root):                # 有跨模态指纹
                cand += kg.propagate(root, to=s)             # 定义 435
        hs = SNC_filter(cand, R_cell, kg.fingerprints)       # 定义 425（继承）
        feats = {h: self.feat(s, h, kg) for h in hs}          # 关系 + 语义特征
        q = time_varying_quantile(self.cal, alpha=0.1)        # 定义 439
        return [h for h in hs if self.score(feats[h]) <= q] or ["UNKNOWN"]

# IP-323 Dyn-Box：种群动力学 + 风险/生存 + 调度
class DynBox:
    def update(self, events, t):             # W 阶段送入
        for e in events:
            if   e.kind == "birth": self.hawkes.excite(e.r, t)
            elif e.kind == "death": self.survival.censor(e.s, t)
            elif e.kind == "recur": self.survival.mark_recur(e.s, t)
        self.changepoint.update(events)
    def expected_mass(self, horizon):
        return sum(self.w[s] * self.survival.alive_prob(s, horizon) for s in self.alive())
    def urgency(self, s, t):
        return self.w[s] * self.hazard(s, t) / self.cost(s)

class Scheduler:                             # 定义 441
    def plan(self, dyn, budget, reserve):
        ranked = sorted(dyn.alive(), key=dyn.urgency, reverse=True)
        out, spent = [], 0.0
        for s in ranked:                     # 等代价贪心 (1−1/e)，引理 54
            if spent + dyn.cost(s) > budget - reserve: break
            out.append(s); spent += dyn.cost(s)
        return out

# IP-324 Dyn-Φ / TAP-Cal：时变摊销滤波
```

## 3. 推导

**引理 51（污染闭包的可靠性与最小性）** 在 W 阶段完整写入溯源边（定义 443 不变式）的前提下，
对可疑集 X，若 C* 为「数值上可能依赖 X」的真实契约版本集，则
(a) **可靠性**：C* ⊆ Closure(X)（不遗漏真正被污染的版本）；
(b) **最小性**：Closure(X) 是包含 X 且对溯源后继封闭的最小集合（依已记录的边精确）；
(c) **附带损伤界**：回退集 = Closure(X) \ C* 只含「确实依赖 X 但数值上恰好正确」的版本；
若 X 仅被某个材质簇（m 个盲区、链路深度 D、每次修复最多 k 条上下文边）使用，则
|Closure(X)| ≤ O(m·k·D)，即污染被**结构性圈定**，而非全图。
对比第 2 轮全局暂停（回退 V \ C*，即使 |Closure(X)| ≪ |V|）。
证明思路：DAG 上可达性对路径长度归纳；可靠性与最小性直接来自「每条真实影响都有边」这一 W 不变式。
**诚实边界**：可靠性**依赖**「所有影响都被记录」；共享权重级耦合由 π_root 显式建模（定义 434），
怀疑权重即闭包=全局，故不漏判，只是退化为第 2 轮。

**引理 52（时变共形的漂移覆盖）** 时间加权共形 + 每步 TV 漂移 η′，在长度 L′ 的窗口上覆盖 ≥ 1−α−2η′L′（延续引理 48）；
ACI 步长 η 的长期误覆盖率 ≤ α + O(η + η′/η)（在线镜像下降/圆锥损失的标准结论），取 η ~ √(η′/L) 平衡。
**推论 52.1**：令 τ_valid 满足窗口内累积漂移 ≤ η′_max，则两次重验之间覆盖保持；这给定义 440 的到期时间一个可证明的取值规则。

**引理 53（OU 摊销滤波的稳态误差与陈旧界）** 对 u_{k+1}=φu_k+(1−φ)μ_phys+w_k，w~N(0,Q)：
(a) 最优 Kalman 稳态方差 Σ∞ 解 Riccati 方程；Dyn-Φ 以学习增益逼近，**跟踪 MSE 下界 = tr(Σ∞)**，与训练无关；
(b) 证据陈旧 h 步的预测方差 ≤ Σ∞ + (1−φ^{2h})(Σ_stat−Σ∞) ≤ Σ_stat，故有效 σ 随年龄单调上升——**为证据老化权重提供依据**；
(c) 模型失配偏差 ≤ (Q/(1−φ)) 量级；φ→1,Q→0 退化为静态 AP-Cal（第 2 轮）。
该引理给出「陈旧程度 × 漂移速度 × 校准置信」之间的可测量关系，并直接决定 τ_valid。

**引理 54（调度近优与公平）** 若空间分离盲区的收益独立、且对探测努力边际递减，
则期望盲区质量下降目标为**单调子模**：等代价预算下按 urgency 贪心达 (1−1/e)（Nemhauser–Wolsey）；
一般代价用密度贪心，保证 (1−1/e)/2 量级（小规模可枚举达 1−1/e）。工具耦合破坏子模性时以贪心为热启动，并按成对耦合界修正。
另由「上次服务年龄 > W_max 则强制轮转」保证**无饥饿**（活性性质），与目标函数无关。

**引理 55（图/时变层不破坏数值等价与时序预算）** 全部图、动力学、调度计算均**带外异步**，只影响
(a) 异步修复顺序、(b) 元数据（主张/到期/溯源）、(c) 选择哪个契约，绝不进入 50Hz 数值路径；
热替换仍仅在 V 通过后发生（第 2 轮引理 49），故子图数值等价性保持；
污染失效是**纯删除/投影**（回退干净祖先），不引入新数值行为，组合单调性保持；
W 事务提交失败即回滚，契约完整性保持。
时序：50Hz 内联仅为 D-Box 扫描 + 回执验证 O(1) < 0.2ms；闭包/调度异步，O(|E|+|C|·out) 均摊、稀疏触发；
故引理 45 硬实时与 G-Contract 预算不变式保持。

## 6. 本轮最大风险（一句话）

**一句话**：C-STKG 的「溯源完备性」与动力学的「条件马尔可夫 / 平稳漂移」假设互为前提——只要存在未被记为边的隐式影响（如摊销权重级的全局耦合）或模型外的制度性突变（新盲区类型、突变式漂移），
污染闭包就会**系统性漏判**、预测性维护会把预算**系统性投向错误的盲区**；而图与动力学彼此印证会制造一种「自洽幻觉」，
使系统对自身世界模型的过度自信比第 2 轮**更难**被外部观测证伪（E442/E450/E453 为证伪实验，π_root 全局根与外部抽样审计为兜底）。

**次级风险与缓解**：
1. **溯源漏边**（隐式影响未被记录）→ π_root 全局根边保守覆盖共享权重；周期性「影子重算」差分审计；
2. **动力学模型失配**（马尔可夫/OU 假设、黑天鹅 regime change）→ 变点检测 + 模型无关生存回退 + 风险率共形区间 + 主动预算封顶；
3. **图规模/陈旧** → 边 TTL、定期压实、增量可达、k_max 限制；
4. **自洽回声**（图与动力学互证）→ 图上留出 held-out 真值抽样 + 随机审计探测，不进入图内证；
5. **到期抖动**（τ_valid 过短导致反复重验）→ 迟滞回差，到期只触发重评分而非必然重探；
6. **调度饥饿/富者愈富** → W_max 强制轮转 + 公平预算；
7. **本体锁定/注入** → 预注册固定本体 + 类型校验（扩展定义 429）；
8. **W 事务半写** → commit-or-rollback，未提交不信任。

| `π_s = w_s·h_s/cost_s` | 调度优先级指数（定义 441） |
| `B_global(H), B_pro, W_max, θ_global` | 全局预算、主动预留、公平窗口、全局退化阈值（定义 446） |
| `W（Weave）` | 7C 的回写阶段（定义 445） |
| `C(V)` | ChronoGauge 退化特例：Closure=全体、φ=1、T_exp=∞、FIFO（定义 447） |

## 2. 形式化定义（要点）

**定义 432/433（C-STKG / 本体）** 类型化实体（区域、盲区、材质、工具、假设、回执、契约版本、主张、失败模式、先验输出）+ 类型化带时间戳有向边；本体预注册、运行时禁止自由扩张（防注入）。溯源子图仅含 `{influences, derivedFrom, supersedes, uses, cites}`，其中前三条构成 DAG。

**定义 434（溯源与污染闭包）** 每个契约版本记录 Lin(v)；先验分 π_local/π_root 两级粒度显式建模隐式全局耦合；Closure(X) 为 PROV_RELS 上可达版本集；污点版本内单调，干净重建开新根。可靠性/最小性/局部化见引理 51。

**定义 435（KG-Hypo 多跳假设）** 有界 k 跳（k≤3）根因迁移，每跳须有类型化证据边，否则剪枝；融合语义 + 图关系特征做共形校准；无候选 ⇒ `{UNKNOWN}`（退化第 1 级）。

**定义 436/437（种群动力学 / 生存）** 条件半马尔可夫生灭/迁移/合并/分裂/复发；风险率与生存函数由事件史（含删失）估计并给共形区间；期望盲区质量 M(H) 驱动调度。

**定义 438（Dyn-Φ / TAP-Cal）** 潜在参数 AR(1)/OU；摊销滤波器单前向输出后验；加入多步预测与时间一致性损失；物理先验仍为 KL 锚与方差下界；证据按年龄指数加权。

**定义 439（时变共形 / ACI）** 时间加权共形 + ACI 步长更新；有限样本覆盖 ≥ 1−α−2η′L′；动力学预测 η′ > η′_max ⇒ 提前降级 `{UNKNOWN}`。

**定义 440（证据时效/合同寿命）** T_exp 由 OU 混合时间/风险率给出；到期 `stale`（软失效：重评分/剥离陈旧主张），与污染硬失效分离。

**定义 441/446（调度 / G-Contract）** urgency 贪心（等代价 (1−1/e)，一般代价密度贪心 (1−1/e)/2 量级）；全局预算硬顶 + 主动预留 + W_max 公平轮转，保证无饥饿。

**定义 442（失配监控）** 变点检测 + 预测校准（ECE）+ 图一致性；任一项超标即退化（动力学→均匀、图→丢弃并 stub）。

**定义 443（图-时间一致性）** 溯源无环；路径时间一致；语言只引用未被污染路径上的有效回执；污点版本内单调。

**定义 444（P-Invalidate）** `Closure(X)` 内硬失效并回退到最近干净祖先（无则 stub+RED）；仅重排 C 内盲区；`|C|/|V|>θ_global` 才全局暂停。**P-Quarantine = C=V 特例**。

**定义 445（7C / W）** 6C + W：原子写溯源边、更新动力学、设到期、刷新 urgency、生成含图切片的 RepairCert；写失败即回滚 U。

**定义 447（退化）** 空图 + 静态动力学 ⇒ P-Invalidate≡P-Quarantine、TAP-Cal≡AP-Cal、7C≡6C ⇒ ToolGauge。

```python
# IP-321 STKG：时间切片 + 污染闭包
class STKG:
    PROV = {"influences", "derivedFrom", "supersedes", "uses", "cites"}
    def add_edge(self, e):
        assert e.rel in self.ontology and self.ontology.valid(e)
        self.edges.append(e); self._inc_index(e)
    def closure(self, X, t):
        seen, frontier = set(X), list(X)
        while frontier:
            u = frontier.pop()
            for e in self.out_edges(u, rels=self.PROV, t=t):
                if e.dst not in seen:
                    seen.add(e.dst); frontier.append(e.dst)
        return seen

# IP-321 KG-Box：k 跳根因迁移 + 共形过滤
class KGBox:
    def hypothesize(self, s, R_cell, kg, cfg):
        cand = []
        for s2 in kg.khop(s, k=cfg.k_max, rels={"causes", "refines", "recurs"}):
            root = kg.root_cause(s2)
            if kg.has_fingerprint_edge(root):
                cand += kg.propagate(root, to=s)
        hs = SNC_filter(cand, R_cell, kg.fingerprints)
        q  = time_varying_quantile(self.cal, alpha=0.1)
        return [h for h in hs if self.score(self.feat(s, h, kg)) <= q] or ["UNKNOWN"]

# IP-323 Dyn-Box：种群动力学 + 风险 + 调度
class DynBox:
    def update(self, events, t):
        for e in events:
            if   e.kind == "birth": self.hawkes.excite(e.r, t)
            elif e.kind == "death": self.survival.censor(e.s, t)
            elif e.kind == "recur": self.survival.mark_recur(e.s, t)
        self.changepoint.update(events)
    def expected_mass(self, H):
        return sum(self.w[s] * self.survival.alive_prob(s, H) for s in self.alive())
    def urgency(self, s, t):
        return self.w[s] * self.hazard(s, t) / self.cost(s)

# IP-324 TAP-Cal：时变摊销滤波 + 时间有效交叉验证
class TAPCal:
    def calibrate(self, receipts, H, s, t):
        mu, Sig = self.dyn_phi(featurize_time(receipts, H, s, t))
        return mu, clamp_min(Sig, KAPPA_PHYS)
    def cross_validate(self, mu, Sig, r_indep, t):
        if not r_indep.valid_at(t): return False
        return abs((r_indep.mu - mu) / sqrt(Sig + r_indep.var)) <= self.eps_cross

# IP-322 P-Invalidate：闭包定界失效
def p_invalidate(M, X):
    C = M.kg.closure(X, t=now())
    if len(C) / len(M.kg.contracts()) > M.cfg.theta_global:
        return global_pause(M)                        # C=V 特例
    for v in sorted(C, key=lambda v: v.version, reverse=True):
        tombstone(M.kg, v)
        clean = M.kg.last_clean_ancestor(v)
        if clean is None: stub_and_red(M.kg.spot_of(v), "tainted")
        else:            M.dpe.restore(clean)
        M.schedule.requeue(M.kg.spot_of(v))
    M.kg.add_edge(Edge(X, "invalidates", C, t0=now()))
    return True

# IP-325 7C：6C + W 事务回写
def chrono_7c(M, s):
    H        = M.kgbox.hypothesize(s, M.dbox.R[s], M.kg, M.cfg)
    prog     = M.tbox.select(H, M.tools, M.tcv, M.budget(s))
    receipts = M.tcv.execute(prog, M.env)
    if len(receipts) < M.n_min(s): return stub_and_red(s, "insufficient")
    mu, Sig  = M.tapcal.calibrate(receipts, H, s, now())
    if not M.tapcal.cross_validate(mu, Sig, M.cross_receipt(s), now()):
        mu, Sig = M.tapcal.calibrate(receipts, ["UNKNOWN"], s, now())
        if not M.tapcal.cross_validate(mu, Sig, M.cross_receipt(s), now()):
            return stub_and_red(s, "cross_failed")
    new_ec = M.tapcal.update_contract(M.dpe, mu, Sig, s)
    if not contract_regression(new_ec): return stub_and_red(s, "regression")
    if not M.kg.commit_or_rollback(new_ec, H, prog, receipts):
        return stub_and_red(s, "provenance_commit_failed")   # W 事务
    M.mreg.hot_replace(M.dpe, new_ec)
    M.dynbox.update(events_of(receipts), now())
    M.kg.set_expiry(new_ec, M.dynbox.valid_horizon(s))
    bind_claims(new_ec, H, prog, receipts, M.kg)
    return True

# IP-326 主闭环
def ChronoGauge_round(M, obs, audio, tac, depth, det):
    for s in M.dbox.detect_blind_spot():
        M.schedule.offer(s, M.dynbox.urgency(s, now()))
    for s in M.scheduler.plan(M.dynbox, M.gbudget.left(), M.gbudget.reserve()):
        if s not in M.inflight:
            M.inflight.add(s); submit_async(chrono_7c, M, s)
    for s in M.kg.stale_contracts(now()):
        M.scheduler.offer(s)
    if M.monitor.triggers():
        p_invalidate(M, M.monitor.suspects())
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 4. 推导

**引理 51（污染闭包可靠性/最小性/局部化）** 在 W 完整写边前提下，真实污染集 C* ⊆ Closure(X)；
Closure(X) 为含 X 且对溯源后继封闭的最小集；附带损伤 = Closure(X)\C* 仅含「依赖但数值正确」的版本。
若 X 仅用于材质簇（m 盲区、深度 D、每次最多 k 条上下文边），|Closure(X)| ≤ O(m·k·D)，污染结构性圈定。
共享权重级耦合由 π_root 根边覆盖：怀疑权重 ⇒ 闭包=全局，退化为第 2 轮而非漏判。
证明：DAG 可达性归纳 + W 不变式。

**引理 52（时变共形覆盖）** 加权共形 + TV 漂移 η′ ⇒ 窗口 L′ 上覆盖 ≥ 1−α−2η′L′；
ACI 步长 η 的长期误覆盖 ≤ α + O(η+η′/η)，取 η~√(η′/L) 平衡。
推论 52.1：τ_valid 取「窗口累积漂移 ≤ η′_max」⇒ 两次重验间覆盖保持，给出定义 440 的到期规则。

**引理 53（OU 滤波稳态误差/陈旧界）** 稳态 Σ∞ 解 Riccati；跟踪 MSE 下界 tr(Σ∞) 与训练无关；
陈旧 h 步预测方差 ≤ Σ∞+(1−φ^{2h})(Σ_stat−Σ∞) ≤ Σ_stat（有效 σ 随年龄升）；
模型失配偏差 O(Q/(1−φ))；φ→1,Q→0 退化为静态 AP-Cal。据此设证据老化权重与 τ_valid。

**引理 54（调度近优与公平）** 空间分离、收益独立且边际递减 ⇒ 单调子模：等代价贪心 (1−1/e)；
一般代价密度贪心 (1−1/e)/2 量级（小规模枚举 1−1/e）。工具耦合破坏子模性时贪心热启动 + 成对耦合修正；
「服务年龄 > W_max 强制轮转」保证无饥饿（活性）。

**引理 55（图/时变层不破坏数值等价与时序预算）** 全部图/动力学/调度在 50Hz 路径外异步运行，只影响修复顺序、
元数据与契约选择；热替换仍仅在 V 通过后发生（第 2 轮引理 49）⇒ 子图数值等价保持；
污染失效为纯删除/投影，不引入新数值行为；W 事务失败即回滚 ⇒ 契约完整性保持；
50Hz 内联仍仅 D-Box 扫描 + 回执验证 O(1) < 0.2ms ⇒ 引理 45 硬实时与 G-Contract 预算不变式保持。

## 8. 本轮最大风险

**一句话**：C-STKG 的「溯源完备性」与动力学的「条件马尔可夫 / 平稳漂移」假设互为前提——
只要存在未被记为边的隐式影响（摊销权重级全局耦合）或模型外的制度性突变，污染闭包会**系统性漏判**、
预测性维护会把预算**系统性投向错误盲区**；图与动力学彼此印证制造「自洽幻觉」，
使系统对自身世界模型的过度自信比第 2 轮**更难**被外部观测证伪。
以 E442/E450/E453 证伪、π_root 全局根边保守覆盖共享权重、外部 held-out 抽样审计与 W 事务回滚四重兜底。
