# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「VLA」×「热管理」）

> 第 57 轮把证据的判定权分散到元先验、跨模态对账与个性化信任，纵深做到五层，但所有机制共享一个未被审视的隐含前提：**身体是一个"稳态、随时满能力"的执行器**。证据一直在回答"这个区域能不能走"，没有一条证据回答"这具身体此刻还能不能走"。本轮两个灵感正好从两侧夹住这个缺口。**VLA** 提供开放世界语义与语言条件的动作提案，却几乎不认识这具身体的慢变量，其软置信也不携带任何物理可行性；**热管理**提供这具身体最典型的慢变量——关节/电池/算力的温度与降额，它有记忆、有滞后、不可瞬时逆转，而且**推理本身就要烧热它**。于是核心命题从第 57 轮的"少样本可校准、跨模态可对账、个性化有界的证据说可信"进一步升级为 **"语义可落地、热学可承诺、算力有代价的证据说可信"**：VLA 只提案不承诺，热状态成为一等证据与被约束对象，思考与行动共享同一份热预算。

核心矛盾：
- **H29（语义可行 vs 热学可行）**：VLA 在视觉-语言空间里判定"做得到"，但真实能力包络被热降额悄悄收缩；语义置信不携带热可行性，训练分布也几乎不含降额/热债工况——"看起来能做"与"此刻做得到"之间隔着一个不可见的慢变量。
- **H30（思考 vs 行动共享热预算）**：更多推理既降低不确定性，又抬高结温、增加时延、挤占执行热余量；"想清楚"与"做得到"在同一份热预算上竞争，且思考的代价是延迟兑现的。
- **H31（热状态可观 vs 滞后）**：热状态是最需要提前知道的慢变量，却只能被滞后观测；低估热量会诱导更多动作、产生更多热、让估计更滞后——存在"越算越热、越热越不准"的正反馈隐患。

## 0. 直觉与动机

**灵感 1（VLA → 提案与承诺分离）**
直觉：VLA 像一位见多识广却不懂这辆车的副驾——它能说"从那边绕上去"（语义与子目标），却不知道轮胎此刻多烫。若让副驾直接踩油门，安全的赌注就押在一个不认识车况的大模型上。正确分工：**VLA 只产出可核验的提案**（语言意图 ℓ′、子目标 g_sem、名义动作块 A_sem 与显式前提 pre），由本地安全栈把提案**重新落地**到当前地图与热能力包络上；VLA 的软置信永远不能替代物理证据，语义可行性必须换来"落地证书"才可承诺。"说得到"不等于"做得到"。

**灵感 2（热管理 → 身体慢变量与能力包络）**
直觉：热是身体的"疲劳记忆"——加热快、冷却慢、不可瞬时逆转。电机峰值 τ_max(T)、电池 P_max(T)、算力频率 f(T) 都随温度单调收缩，于是"当前能做到什么"不是一个静态数，而是**路径依赖的能力包络** E_th(t)。一次在凉快时做下的承诺，可能在执行途中因升温而降额失效。安全必须从"点估计此刻可行"升级为"**整条热轨迹都不越界**"。

**灵感 3（热/电信号 → 努力诚实模态）**
直觉：外观可以被物理共谋伪装（透明冰面看着干、软泥看着硬），但**电机电流与温升率是努力的结果**——爬坡、打滑、软陷都会在电流/温升曲线上留下难以伪造的签名。于是热/电通道成为第 57 轮 XMC 里最"诚实"却最"迟钝"的模态：它几乎不能被外观欺骗，但有滞后、有记忆，必须按陈旧度衰减入账。它既能佐证，也能**证伪 VLA 的语义前提**（VLA 说平地、电流说在爬坡）。

**灵感 4（思考即探针 → 热-算调度）**
直觉：第 57 轮的探针是"去碰一下"，本轮新增一种探针是"多想一步"——而想一步要烧算力。若热预算是有限资源，则**思考与行动在同一个预算上竞争**：多跑一次 VLA/规划降低不确定性，也抬结温、增时延、挤占执行余量。需要一个"认知恒温器"：热债越高，推理预算越低，模型级联自动降级到小模型/反射，把热留给执行。

**灵感 5（合流 → 热承诺证书与 PCE++）**
直觉：VLA 提案（IP-140）、热包络（IP-139）、热-算调度（IP-141）、努力模态（IP-142）在证据门汇成新证据类 **EV-thermal** 与"热承诺时界"（IP-143）：承诺只在热预报可信的时域内有效，过期须再验证。PCE++（IP-144）在探-诺-演中插入热检查点，并允许"找阴凉 / 降 duty / 换小模型 / 绕行"这类新的保守动作。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（热-滞后状态与能力包络 THM）** 隐藏热状态 T=(T_j,T_b,T_c,T_amb)∈ℝ⁴₊，非对称动力学 dT/dt=A(T,u)，加热时间常数严格小于冷却时间常数；热债 D_th(t)=∫ max(0,T−T_ref)dt。降额映射 τ_max(T)、P_max(T)、f_max(T) 单调不增。能力包络 E_th(H)={u_{1:H} : ∀t≤H, T(t)∈𝕋_safe ∧ τ_dem(t)≤τ_max(T(t)) ∧ P_dem(t)≤P_max(T(t))}。热信念 b_th(T_t|history) 用带滞后的观测模型 p(o_th|T) 做 Bayes 滤波，预报一律取悲观上界 T_hi。

**定义 140（VLA 提案-落地分离 VPG）** VLA 输出分解为 Π_VLA=(ℓ′, g_sem, A_sem, pre)，pre 为显式前提（坡度/材质/接触等级）。落地算子 Ground(Π_VLA, 𝓜, b_th) 在热包络 E_th 与地图约束下求可行变体 g*∈Reground(Π_VLA)，失败返回 ⊥。**语义置信 c_VLA 不进入 P_fail**；承诺必须另获落地证书（EV-thermal / EV-probe* / EV-margin 之一）。若 c_VLA 高而 Ground=⊥，记为"语义-能力冲突"，触发降档/协商，而非冒险执行。

**定义 141（热-算调度 TCS）** 热预算 B_th 在推理 I 与执行 A 间分配；每次推理的热成本 c_inf(π)=α·compute(π)（结温升与时延）。热 VOI：VOI_th(π)=ΔRisk_red(π) − λ_th·c_inf(π) − λ_lat·E[latency(π)]，且受 f(T) 降频约束。认知恒温器：D_th>θ_th ⇒ 推理预算↓、模型级联降级（VLA_large→VLA_small→反射）；热恢复只经"停止/减载/换阴凉"。

**定义 142（热-力证据 TMX 与 EV-thermal）** 扩充模态 ℳ←ℳ∪{elec}，o_elec=(I, dT/dt, P)。努力签名按陈旧度入账：w_elec(t)=exp(−Δt/τ_elec)。EV-thermal ⇔ 存在执行轨迹 σ 使热轨迹悲观预报全程不越 E_th 且扭矩裕度≥κ_th；可证伪语义：若 effort-signature 与 VLA 前提 pre 冲突 ⇒ 冻结该提案并要求 EV-probe*。EV-thermal 可进入不可逆接触证据集（与 EV-probe*/EV-margin 同级），因其来自物理努力而非外观。

**定义 143（热承诺时界与证书 J_t）** 承诺 c 携带有效期 TTL_th(c)=min{t : 热预报区间宽度>w_th 或需求扭矩逼近 τ_max(T_hi)}；到期须 revalidate。热风险 R_th(g)=P(∃t≤H : T(t)>T_limit ∨ τ_dem(t)>τ_max(T(t)) ∨ P_dem(t)>P_max(T(t)))。证书 J_t=(T_forecast, residuals, derating_log, compute_ledger, vla_ground_log, effort_log)，继承 J_p 全检。

**定义 144（热感知探-诺-演 PCE++）** 每检查点：①VLA 提案→Ground；②热推断（b_th + 包络）；③热-算分配（先算"想"是否值这份热）；④承诺 ⇔ 证据门过 ∧ TTL_th>执行时长 ∧ R_th≤δ_th；否则走热保守动作：换阴凉/降 duty/降级模型/绕行/协商或安全停。

## 2. 关键算法伪代码（完整版见产物区）

```python
def vla_propose_and_ground(o, lang, M, b_th):       # IP-140
    Pi = vla_policy(o, lang)                         # (l', g_sem, A_sem, pre)
    if effort_contradicts(pre, M.effort):            # 努力签名证伪语义前提
        return None, 'semantic_effort_conflict'
    g = ground(Pi, M, capability_envelope(b_th, H))  # 热可行变体
    return (g, 'ok') if g else (None, 'semantic_capability_conflict')

def thermal_compute_schedule(b_th, D_th, task):      # IP-141 认知恒温器
    model = cascade_down(vla_model) if D_th > theta_th else vla_model
    pi = argmax(policy_candidates, key=lambda p: voi_thermal(p, b_th, D_th))
    if voi_thermal(pi, b_th, D_th) < theta_voi_th:
        return 'act_conservatively', model           # 不再多想，用现有信念保守动作
    compute_ledger.spend(pi); return pi, model

def thermal_evidence(traj, b_th, kappa_th):          # IP-142
    T_hi = forecast_upper(b_th, traj.controls, traj.H)
    if max(T_hi) <= T_limit and min(torque_margin(traj, T_hi)) >= kappa_th:
        return 'EV-thermal'
    return None
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| THM | O(d_T)/更新；包络 O(\|A\|·H) | O(\|𝒯\|) 静态 | 非对称动力学、悲观上界、包络覆盖 |
| VPG | O(d_VLA)+O(\|A\|·H) | O(\|Π_VLA\|) | 提案不承诺、落地算子健全 |
| TCS | O(\|Π\|·d_π) | O(\|B_th ledger\|) | 热成本守恒、降级单调 |
| TMX | O(\|ℳ\|²·d_b) | O(\|V\|·\|ℳ\|) | 陈旧度衰减、证伪完整 |
| TCH | O(H) | O(\|σ\|) | TTL 保守、过期即失效 |
| PCE++ | O(\|CP\|·(k_p+k_c)·(C_VOI+d_φ+d_T)) | O(\|V\|+\|σ\|) | 热预算内终止 |

**正确性定理（TCS：Thermally-Calibrated Commitment Soundness）概要**：在 A33–A40 上加 (A41) 热预报校准：悲观上界覆盖 ≥1−α_th、预报误差有界且延长时域单调变宽；(A42) VLA 仅为提案源，不存在绕过 Ground 的直接承诺路径，落地算子健全；(A43) 热-算成本账诚实、推理时延上界可声明；(A44) 努力模态陈旧模型诚实，陈旧时不单独作为不可逆接触证据。则：(i) **热承诺健全性** P(fail) ≤ δ_f+ε_meta(k)+δ_probe+ε_h+δ_th+δ_ood·α_conf；(ii) **热单调性** 温度/热债上升只会经"包络收缩、TTL 缩短、推理预算下降、动作降档"影响系统，不存在升险路径；(iii) **算-热守恒** 推理与执行共享 B_th，想得越多可用的执行热余量越少，不存在"免费的思考"；(iv) PCE++ 在热预算耗尽或 k_p+k_c 内终止于 {承诺, 换阴凉, 降 duty, 绕行, 协商, 安全停}。

## 6. 本轮最大风险

**一句话**：本轮把"身体此刻还能不能做"也变成可估计、可承诺的对象后，估计本身要耗热、耗热又改变被估对象，最大的风险是"越算越热、越热越估不准"的正反馈——热滞后会让错误估计在被发现之前就已经锁进一次不可逆承诺，唯有悲观上界、热承诺时界与算-热守恒账三道护栏同时成立才不至于自欺。

def thermal_belief_update(b_th, obs, dt, u):
    b_th = bayes_filter(b_th, obs, model=ThermalODE(asym=True))  # 加热快冷却慢
    D_th = integrate_debt(b_th, T_ref)                           # ∫max(0,T-T_ref)

def capability_envelope(b_th, horizon):
    def feasible(u_seq):
        T_hi = forecast_upper(b_th, u_seq, horizon)             # 取上界而非均值
        return (max(T_hi) <= T_limit
                and all(torque_demand(u_seq, t) <= tau_max(T_hi[t]) for t in range(horizon))
                and all(power_demand(u_seq, t) <= P_max(T_hi[t]) for t in range(horizon)))
    return Subset(actions, feasible)

## 3. 解析推导 与 复杂度

### 3.1 热动力学与降额

取集总热模型 `C·dT/dt = Q_act(u) + Q_inf(π) − h(T − T_amb)`，其中 `Q_act≈k_u·u²`（近似焦耳/机械损耗正比），`Q_inf=c_inf·compute(π)`。降额取 `τ_max(T)=τ_0·clip((T_limit−T)/(T_limit−T_derate),0,1)`。平衡温度 `T* = T_amb + (Q_act+Q_inf)/h`；越限条件 `Q_act+Q_inf > h(T_limit−T_amb)`。加热时间常数 `C/h` 小、冷却（`Q_act=0`）时同一 `C/h` 但 `T_amb` 偏高使回落到安全区更慢——这就是热债的物理来源。

### 3.2 思考-行动的热预算守恒

设总热预算 `B_th = ∫(Q_act+Q_inf)dt` 有上限。把预算给推理 `ΔB`，降低动作不确定性的边际收益为 `∂Risk_red/∂B`；同时 `ΔB` 直接抬温并使 `τ_max` 收缩、时延上升。最优分配的一阶条件为
`∂Risk_red/∂B |_I − λ_th − λ_lat·∂latency/∂B = ∂Risk_red/∂B |_A`，
即"最后一单位热用在思考上的风险削减"等于"用在行动上的风险削减"。**推论**：当热债高（`D_th≫θ_th`）时 `λ_debt` 项主导，最优解自动退化为"少想、用现有信念保守做"——恒温器不是拍脑袋，而是该一阶条件的边界解。

### 3.3 热估计正反馈（本轮核心风险的形式化）

设真实温度 `T`、估计 `T̂` 滞后 `τ_lag`，控制器按感知裕度 `m̂=T_limit−T̂` 决定努力 `u=g(m̂)` 且 `g'>0`。则
`C·dT/dt = k_u·g(T_limit−T̂) − h(T−T_amb)`，一阶化后闭环增益 `G = k_u·g'·(dT̂/dT)/h`。若 `G≥1`，小的低估会被动作放大为持续升温直到硬限——**越觉得凉快越用力，越用力越热，热又因滞后来不及修正**。缓解不是"更努力地估计"（那要更多算力、更多 `Q_inf`），而是**切断反馈**：悲观上界 `T_hi≥T`、TTL 到期强制重验、热债高时直接降级到开环保守动作。

### 3.4 复杂度

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| THM | O(d_T)/更新；包络 O(\|A\|·H) | O(\|𝒯\|) 静态 | 非对称动力学、悲观上界、包络覆盖（A41） |
| VPG | O(d_VLA)+O(\|A\|·H) | O(\|Π_VLA\|) | 提案不承诺、落地健全（A42） |
| TCS | O(\|Π\|·d_π) | O(\|ledger\|) | 算-热守恒、降级单调（A43） |
| TMX | O(\|ℳ\|²·d_b) | O(\|V\|·\|ℳ\|) | 陈旧衰减、证伪完整（A44） |
| TCH | O(H) | O(\|σ\|) | TTL 保守、过期失效 |
| PCE++ | O(\|CP\|·(k_p+k_c)·(C_VOI+d_φ+d_T)) | O(\|V\|+\|σ\|+H) | 热预算内终止、六态完备 |

**正确性定理（TCS: Thermally-Calibrated Commitment Soundness）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 热预报校准：悲观上界覆盖 ≥1−α_th，预报误差有界且随时域单调变宽；**(A42)** VLA 仅为提案源，不存在绕过 `Ground` 的直接承诺路径，落地算子健全；**(A43)** 热-算成本账诚实、推理时延上界可声明；**(A44)** 努力模态陈旧模型诚实，陈旧时不单独作为不可逆接触证据。则：

1. **热承诺健全性**：`P(fail) ≤ δ_f + ε_meta(k) + δ_probe + ε_h + δ_th + δ_ood·α_conf`，其中 `δ_th` 由热预报误差与 TTL 截断共同界定；EV-thermal 仅贡献 `≤δ_th`。
2. **热单调性**：`T` 或 `D_th` 上升只能经（a）能力包络收缩、（b）TTL 缩短、（c）推理预算下降、（d）动作降档四条通道影响系统，不存在升险路径。
3. **算-热守恒**：`∫(Q_inf+Q_act)dt ≤ B_th`，推理越多执行热余量越少，"免费的思考"不存在。
4. **终止性**：每检查点推理 ≤k_c、探针 ≤k_p，PCE++ 在热预算耗尽或 k_p+k_c 内终止于 {承诺, 换阴凉, 降 duty, 绕行, 协商, 安全停}。
5. **部署界**（联合界）：
```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_th + δ_ood·α_conf)
             − P(热预报失效未检出) − P(算力账失真) − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
```

关键：**VLA 给语义、落地给许可；热给慢变量、悲观给保底；思考给信息、守恒给约束**——效率来自大模型与乐观，安全不赌在它们身上；热状态越差，系统只会更慢、更保守、更少想。

## 6. 本轮最大风险

**一句话**：本轮把"身体此刻还能不能做"也变成可估计、可承诺的对象后，估计本身要耗热、耗热又改变被估对象，最大的风险是"越算越热、越热越估不准"的正反馈——热滞后会让错误估计在被发现之前就已经锁进一次不可逆承诺，唯有悲观上界、热承诺时界与算-热守恒账三道护栏同时成立才不至于自欺。
