# 第 41 轮 · 闭环交付 v18：块率视觉伺服 × 真机评测适配 × 虚拟真机评估（「交付闭环」横切层，四层架构 v6）

> 承接第 40 轮（v17：热预算治理 × 步数感知规划 × 学习-TO 混合轨迹，四层架构 v5）。本轮灵感词「真机评测 / 视觉伺服」。第一反应是把视觉伺服塞进 v17 的 TO 里，但**直接打开官方提交仓库 README 逐字核对后，先纠正了 v17 的一个接口误读**，于是两个词指向的不再是「再加一层优化」，而是 v17 缺的那一层**闭环**：v17 把交付优化得很好，但交付是开环的、且默认评测单元与开发单元同构；而真机评测恰恰不同构，视觉伺服恰恰只能在「块率」上闭环。v18 的主轴因此是**把「开环交付」升级为「块率闭环交付」，并让整栈在未知评测单元上活下来**。

## 0. 先纠错：v17 对 `action_chunk_size` 的理解是错的（先事实后推理）

本轮我重新抓取并逐字阅读了 `github.com/unitreerobotics/unibot_submission` 的 README.md（2026-11-10，原文见产物区 F67）。有三个字面事实，v17 只对了一半：

1. **`action_chunk_size` 是 `metadata` 字段，握一次手就固定**（不是运行期旋钮）。v17 的「旋钮-时机表」写了它是 metadata，但它的算法里又保留了 `T_a_eff ← governor(...)` 的运行期自适应——**这两者矛盾，运行期改不了 `T_a`**。
2. **评测端会把整个 chunk 顺序执行完，才再调 `get_action`**（"index 0 is executed first, then the rest in order, until the evaluator calls `get_action` again"）。所以 **chunk 内部没有观测、没有反馈、没有中途重规划**。所谓「块内高频校验/纠正」（SV-VLA、CheckVLA、PhaForce 那一类）在这套接口上**根本跑不起来**。
3. **动作是绝对目标（joint 目标位或 ee 目标位姿），不是力矩、不是速度**；`obs_delta_indices` 的时间堆叠在块边界给出一小段历史。

把这三条连起来，得到本轮真正的支点（我称 F67）：**`T_a` 不是「推理批大小」，而是「控制闭环周期」，而且是整个提交里唯一、且被冻结的闭环周期旋钮**。它同时是：热/算力旋钮（v17 的 Δ 平面）、**盲区间长度**（chunk 内无反馈，漂移在此累积）、**视觉反馈频率**（每秒只有 1/T_a 次观测）。一个旋钮，三种物理。v17 只认第一种，所以它把「精度」寄托在离线 TO 上；v18 必须承认第二种与第三种，并把闭环做在唯一允许的地方——**块边界**。

## 1. 研究者直觉（先直觉与动机，后形式化）

**直觉 1（真机评测 → 「主要敌人不是不会做，而是评测单元未知」）。** 开发阶段我们总在「自己那台/仿真里」调参，但榜单跑在 N 台真实 G1 上（不同机体、随机顺序、N 个连续端口并发，F60）。真机上真正致命的不是泛化到新物体，而是**硬件级分布偏移**：关节编码器零点、驱动增益、相机安装误差、光照、工作台高度。Self-Adaptive VLA（F76）给了我最刺眼的数字——在注入 actuation bias / encoder offset 后，一个近乎 100% 的策略**直接掉到近乎 0%**，靠测试时用本体感知+动作结果自适配才救回约 80%。而我们的观测里**没有电机温度、没有电流、没有电压**（F77 的 TeAR 正是靠这三样做在线矫正，我们拿不到），所以「热」这条线在真机上只能从**动作-结果失配**间接反推。结论：v18 必须把「评测单元未知」当成一等约束，做**无需标定、能在线吸收硬件偏移**的闭环，而不是继续堆依赖精确 URDF/手眼标定的离线模型（v17 自己的最大风险已经点名了这一点）。

**直觉 2（视觉伺服 → 「在这套接口里，视觉伺服只能是块率 look-and-move」）。** 教科书 IBVS 是高频图像闭环；但 F67 说块内无观测，所以我们**做不了连续视觉伺服**。能做的、且诚实的形态是经典 **look-and-move**：每个块边界，用（腕部）相机把目标在图像里的相对位姿误差量出来，把它换算成末端的一小步修正，叠加到下一段 chunk 的**终端目标**上；块的其余部分仍由 VLA/流式策略给名义轨迹。关键是「无标定」：不假设相机内外参、不假设深度——用目标区域质心（平移）、对数面积（尺度）、二阶矩（面内旋转）这类**目标中心伺服坐标**（WM-VS，F68；CONTROLO 2026 的无标定 IBVS，F78），交互矩阵 `L = ∂s/∂x` 用块边界的 `(Δx 指令, Δs 观测)` 对做门控 Broyden/RLS 在线估计。这样相机被换、被碰、光照变了，伺服仍然收敛——这正好对冲直觉 1 的真机偏移。

**直觉 3（两词的交点 → 「T_a 一杯两用」）。** 把直觉 1、2 叠在 v17 上，冒出本轮最兴奋的一点：**「让 T_a 变大以降温/稳时延」和「让 T_a 变小以闭环/抗漂移」是一对直接冲突**，而 v17 的 governor 只会往「大」调，等于用开环漂移换热预算，在真机上可能反而降成功率。但 F67 第 2 条给了破解口：**块内无反馈，但块的「尾部」是我们的自由**。于是可以做 **「尾部驻留（tail padding）」**——如果子技能在第 `n < T_a` 步就完成了，就把第 `n..T_a` 步填成「减速—停稳」的驻留段。这样：周期 `T_a` 可以取大（省推理、稳时延、降热），而**有效盲运动时间只有 `n`**（漂移小、边界观测干净）。**把「周期」与「盲运动」解耦**，是这套接口独有的、零改造成本的结构性发现。代价是浪费 (T_a−n) 步，正好和步骤分（v17 的第二本账）对撞，需要联合优化。

**直觉 4（真机试次稀缺 → 「先在想象里评测，再上真机」）。** 真机评测的试次昂贵且不可复现，参赛者无法频繁真跑。PiL-World（F75）说明：用 chunk 级动作条件世界模型做 policy-in-the-loop 闭环想象评测，能把「真机 vs 想象的成功率差」从 63.2% 压到 12.0%。这对我们是**参赛者侧的工具**：用它在 32 任务 × 5 扰动上跑成千上万次想象 episode，筛模型、扫 `T_a`、估 `p_s` 先验、发现失败模式，只在关键分叉点花真机预算。必须诚实：这是**我们自己的**评测器，不是官方隐藏评测器，只能用于**相对排序与失败挖掘**，绝不能当绝对分。

**直觉 5（修剪 → 「v17 依赖精度的三件套，在真机上会退化成不可验证估计量」）。** v17 最值钱的 IP-50（学习-TO）吃 URDF + 跟踪模型辨识（A17/A38）；IP-48 的电机热账本吃逆动力学 `∫τ²dt`（A37）。真机上：URDF 未核实、温度无遥测、相机可能被换——这三条恰恰让「离线 TO 的力矩-能量项」「电机热代理」变成**无法验证的估计量**。而本轮新增的块率视觉伺服是**可当场验证的**（像素误差收敛即可测）。所以按 v17 自立的规则 51（每轮至少修剪 ≥2 项「能力展示型而非得分型」设计），我果断把「纯离线 DDP 全解」「电机热代理」「形式证书残余」「跨本体运动先验」降级。**这不是放弃精度，是把精度从「离线一次算准」改成「在线边界纠偏」——用可观测替换不可观测。**

## 2. 灵感词 → 落地线（新增 + 重构 + 修剪登记）

- 「**视觉伺服**」→ **IP-51 CHUNK-RATE-VISUAL-SERVO（P0 新增）**：块率、无标定、目标中心的 look-and-move 伺服。块边界量目标伺服坐标 `s=(u,v,log√A,θ)`，误差 `e=s−s*`，修正 `δx=−λL̂⁺e` 叠加到下一 chunk 终端目标；`L̂` 用门控 Broyden/RLS 从块边界 `(Δx,Δs)` 在线估计；带伺服子空间选择（单目标 4 特征只能定 3–4 自由度，其余用先验/多特征补）与「可信度正则」（修正幅度/一阶差分有界，避免被官方 `§6` 判为动作离群）。
- 「**视觉伺服 × 真机评测**」→ **IP-52 LOOP-PERIOD-CODESIGN（P0 新增）**：**把 `T_a` 升格为「周期-盲运动解耦」的设计变量**。设计期按 `J(T_a)=w_c·C+w_d·D+w_l·Var(L)+w_b·B+w_s·N` 选一次 `T_a*`（相位于子技能众数时长，PACE/RACE 证据），运行期用**尾部驻留**把有效盲运动从 `T_a` 收缩到子技能结束点 `n`；并要求 chunk 轨迹保持「可恢复裕度」（远离碰撞/掉落/目标被遮挡等不可逆集），使块内扰动能在下一边界被纠正。
- 「**真机评测**」→ **IP-53 VIRTUAL-REAL-EVAL（P1 新增）**：PiL-World 式 chunk 级动作条件世界模型，作为参赛者侧的「虚拟真机评测台」，做闭环想象 rollout、真-想差距标定、失败模式挖掘、`p_s` 先验与 `T_a` 扫描；仅用于相对决策。
- 「**真机评测（硬件偏移）」**→ **IP-54 EVAL-TIME-ADAPT（P1 新增，部分并入 IP-51）**：光照/相机扰动的光度归一与特征鲁棒化；用块边界「动作-结果失配」估计低维硬件偏置（actuation bias / encoder offset）并前馈补偿（Self-Adaptive VLA / SCOUT / T2-z 证据）；显式的「可信度正则器」。
- 修剪登记：**IP-42 跨本体运动 → P2 挂起**（单本体赛题，跨本体先验无得分价值）；**IP-48 电机热代理 `∫τ²dt` → P2 挂起**（无温度遥测 + URDF 未核实，不可验证；保留可测的 GPU/时延/并发账本）；**IP-46 残余形式证书（Lipschitz/对抗半径）→ P2 挂起**（保留 IP-33 CBF 运行期兜底）；**IP-50 完整离线 iLQR/DDP → 收窄**为「chunk 整形 + 边界条件化」（并入 IP-52），完整 DDP 仅在有 URDF 时作 P1 备选。**能量项因电机热账本被修剪而失去物理依据，只保留时间/精度项。**

## 3. 形式化直觉（严格版见产物区 §3）

**定义 29（块率闭环 / 盲区间）**：设基础控制步长 `Δt`，`t_k=k·T_a·Δt`。策略只在 `t_k` 观测 `o_k`（含时间堆叠历史）并返回 `U_k∈R^{T_a×d}`，评测端在 `[t_k,t_{k+1})` 内**开环执行整段**。故闭环带宽 `f_cl=1/(T_a Δt)`，**盲区间** `B=T_a Δt`，块内漂移无反馈累积。`T_a` 一经 `metadata` 声明即冻结。

**定义 30（块率 look-and-move 视觉伺服）**：目标中心特征 `s(o)∈R^m`（`m=4`：质心 u,v、对数尺度、面内角），期望 `s*`，误差 `e_k=s(o_k)−s*`。修正 `δx_k=−λ L̂_k⁺ e_k`（`L̂=∂s/∂x` 为图像-末端交互矩阵），在线更新（门控 Broyden 或带遗忘 RLS）：
`L̂_{k+1}=L̂_k+ g_k·(Δs_k−L̂_kΔx_{k−1})Δx_{k−1}^⊤/(Δx_{k−1}^⊤Δx_{k−1})`，
仅在 `‖Δx‖≥δ_x`、特征有效、`e` 未溢出时 `g_k=1`。约束 `‖δx_k‖≤C`、`‖δx_k−δx_{k−1}‖≤D`（可信度）。**关键限制**：单目标 4 特征秩 ≤4，故伺服只能在**任务相关子空间** `S⊆R^6`（如平移 3 + 偏航 1）闭合，其余自由度靠先验 `L̂_0`（离线粗标定）或第二视角/多特征补秩。

**定义 31（周期-盲运动解耦 / 尾部驻留）**：若子技能在块内第 `n` 步结束，则 `U_k` 的第 `n..T_a` 步填「减速—停稳」驻留。有效盲运动时间 `B_eff=nΔt`，漂移 `D(T_a)≈v̄·B_eff+ε_track`；步数代价 `(T_a−n)`。`n*` 由 `argmin_n drift_cost(n)+step_cost(T_a−n)` 决定。并要求轨迹在 `[t_k,t_{k+1}]` 内保持到不可逆失败集的距离 `≥ρ`（可恢复裕度），使块内扰动可在下一边界纠正。

**定义 32（T_a 协同设计）**：`T_a*∈argmin_{T_a∈{1,2,4,8,16,32}} w_c·c_infer/T_a + w_d·D(T_a) + w_l·Var(L|T_a) + w_b·B(T_a) + w_s·N(T_a)`；`B(T_a)` 在 `T_a Δt≈`子技能众数时长时最小（PACE），`D` 随 `T_a` 超线性（RACE：误差集中于子技能切换）。故存在内点最优。

**定义 33（可信度正则动作）**：返回的 `U` 须满足 `max_t‖u_{t+1}−u_t‖≤Δ_max`、`max_t‖u_t−ū_demo‖_{Σ_demo^{-1}}≤ρ_reg`（防离群），以匹配官方 `§6` 的「时延平滑 + 动作统计规律性」可信度条款。伺服修正被视作硬约束而非自由项。

**定义 34（虚拟真机评测估计量）**：以块级世界模型 `W` 递推 `o_{k+1}~W(·|o_k,U_k)` 得想象轨迹，估计 `Ê[score]=Ê[success]·ĝ(N)`；仅当标定后 `|Ê−E_real|` 有界（PiL 类：≤12%）方用于绝对判断，否则仅用于相对排序与失败挖掘。

## 4. 关键决断

1. **承认 `T_a` 冻结**：运行期不再妄想改周期；自适应全部下沉到「块内容整形 + 边界伺服 + 分支/驻留」。这是对 v17 的明确纠错。
2. **视觉伺服只做块率 look-and-move**：无标定、目标中心、在线交互矩阵；不做块内高频闭环（接口不允许），也不假装能做。
3. **周期与盲运动解耦**：大 `T_a` + 尾部驻留 = 既省算力又低漂移；用步数代价显式对撞。
4. **真机偏移优先**：无标定 + 动作-结果在线自适应 + 可信度正则；把「未知评测单元」当一等约束。
5. **先想象评测再上真机**：PiL 式虚拟评测器做相对筛选，真机预算只花在关键分叉。
6. **修剪四项**：跨本体、电机热代理、形式证书残余、离线 DDP 全解——把不可验证的能力展示换成可当场验证的闭环。

## 5. 本轮最大风险（一句话）

**`T_a` 被冻结意味着一个短 episode 里块边界样本可能只有个位数到十几个，块率交互矩阵/漂移估计可能来不及收敛；若真机相机与硬件偏移又没有可观测量（温度/电流/电压全不在 obs），那么「块率视觉伺服 + 测试时自适应」可能在一个 episode 内什么也纠不回来——必须以 E73（≤20 边界样本的伺服收敛）、E74（硬件偏移 A/B）、E75（`T_a` 协同设计与尾部驻留扫描）、E76（可信度正则误伤率）、E77（虚拟-真机差距标定）、E78（端到端）六重守门，任一失败即回退到「v17 静态策略 + 演示期强鲁棒化」保底。**

# 第 41 轮产物 · 创新点清单 v18：块率视觉伺服 × 真机评测适配 × 虚拟真机评估（「交付闭环」横切层，四层架构 v6）

> 承接 v17（第 40 轮：热预算治理 × 步数感知规划 × 学习-TO 混合轨迹）。本轮灵感词「真机评测 / 视觉伺服」。直接重读官方提交仓库 README（2026-11-10）后先纠正 v17 的一处接口误读：**`action_chunk_size=T_a` 是 `metadata` 字段、握手即冻结；评测端执行完整 chunk 后才再调 `get_action`，块内无观测、无反馈**。由此 `T_a` 的真身是「唯一且冻结的闭环周期」，同时是热/算力旋钮、盲区间、视觉反馈频率。v18 新增 **4 项核心 IP（IP-51 块率视觉伺服 / IP-52 周期-盲运动协同设计 / IP-53 虚拟真机评测 / IP-54 评测单元自适应）+ 1 个横切层（Ε 评测闭环平面，经 `T_a` 与 v17 的 Δ 资源平面耦合）**，**修剪 4 项依赖不可验证估计量的设计（IP-42 跨本体 / IP-48 电机热代理 / IP-46 残余形式证书 / IP-50 离线 DDP 全解）**。主轴从 v17「单位物理成本的得分效率」推进到「**在未知评测单元上、以唯一冻结闭环周期交付**」。

## 0. 结论

- **接口纠错（本轮总纲，F67）**：`T_a` 冻结且块内无反馈 ⇒ 闭环只能在**块边界**；v17 的「运行期 `T_a_eff` 自适应」不成立，必须改为「块内容整形 + 边界伺服 + 分支/驻留」。视觉伺服在本接口下只能是**块率 look-and-move**。
- **IP-51 CHUNK-RATE-VISUAL-SERVO（P0 新增）**：无标定、目标中心的图像伺服坐标 `(u,v,log√A,θ)` + 门控 Broyden/RLS 在线交互矩阵 + 伺服子空间选择 + 可信度正则；对冲真机相机/光照/安装偏移。

### 3.2 IP-51 CHUNK-RATE-VISUAL-SERVO（块率视觉伺服，完整设计）

**IP 卡片（六字段）**：
- **动机**：F67 证明块内无反馈，真机存在相机/光照/安装/硬件偏移（F76），离线 TO 的精度在评测单元上会失配；F68/F78 证明无标定、目标中心的图像伺服可用且可迁移。
- **与现有方案差异**：SV-VLA/CheckVLA/PhaForce 都假设**块内高频观测**（F69/F73/F74），本接口不支持；传统 IBVS（F78）假设**控制率闭环**。无人把「固定 `T_a` 的块率 look-and-move、在线标定交互矩阵、可信度正则」做成一个可提交的策略层。差异点：**块率样本 + 静态周期 + 官方绝对目标动作 + 可信度约束**四者耦合。
- **技术可行性**：目标中心特征（质心/面积/二阶矩）在 240×320 上毫秒级；Broyden/RLS 更新 O(m·d²)（m=4,d≤6）；每边界一次，均摊到 T_a 步；无 IL 依赖（纯 numpy/opencv）。
- **所需资源**：数据=自采「指令-实际图像位移」对（E73，约 30–60min）；算力=<1ms/边界；接口=F67 的腕部相机 + 绝对 ee/joint 目标，零改造。
- **落地步骤**：① 目标检测/分割（复用 IP-36/IP-30）出伺服特征；② 离线先验 `L̂_0`（可选粗标定）；③ 在线门控 Broyden/RLS；④ 伺服子空间选择；⑤ 可信度正则；⑥ 与 IP-52 驻留/整形联调；⑦ E73 验收。
- **风险**：单目标 4 特征秩不足（→子空间+多特征/先验）；块率样本少收敛慢（→先验强、增益保守、E73 门）；特征被遮挡（→有效性门控 + 回退无伺服）；修正被可信度判离群（→幅度/差分硬约束 + E76）。

**符号表**：

| 符号 | 含义 | 取值/来源 |
|---|---|---|
| `s(o)` | 目标中心伺服坐标 | `(u,v,log√A,θ)`，来自腕部/高位相机 + IP-36 目标区域 |
| `s*` | 期望伺服坐标 | 抓取/放置前的终端相对位姿（离线或示教） |
| `L̂=∂s/∂x` | 图像-末端交互矩阵估计 | 门控 Broyden / 遗忘 RLS |
| `S` | 伺服子空间 | 任务相关（如平移3+偏航1），秩≤特征数 |
| `δx` | 叠加到下一 chunk 终端的修正 | `−λL̂⁺e`，`λ` 保守 |
| `C,D` | 修正幅度/一阶差分上界 | 可信度预算（E76 标定） |

**算法（块边界执行一次）**：
```
输入：o_k（当前观测+堆叠历史）、s*、先验 L̂_0、伺服子空间 S、上一步 (Δx_{k-1},s_{k-1})
1. 目标区域 ← detector/segmenter(o_k 的腕部/高位相机, 语言目标)   # 复用 IP-36
2. s_k ← (质心u,v, log√轮廓面积, 主轴角)  (同一坐标系、去畸变归一化)
   e_k ← s_k − s*
   if not feature_valid(s_k) or ||e_k|| > E_MAX:  # 遮挡/跳变
        return nominal_chunk  # 回退：不做伺服
3. Δs_k ← s_k − s_{k-1}
   若 ||Δx_{k-1}|| ≥ δ_x 且特征连续：
        L̂_k ← Broyden( L̂_{k-1}, Δx_{k-1}, Δs_k )   # 或遗忘 RLS
   否则 L̂_k ← L̂_{k-1}
4. δx_raw ← −λ · pinv(L̂_k[S,:]) · e_k[S]        # 仅在子空间 S 内闭合
   δx ← clip(δx_raw, ||·||≤C)                    # 幅度上界
   δx ← rate_limit(δx, D)                         # 相对上一块差分包络
5. 终端目标 x*_k ← VLA/TO 名义终端 + δx（按块内三次缓动叠加，避免突变）
6. 记录 (Δx_k=δx, s_k) 供下一步
输出：修正后的 nominal chunk
```
**正确性论证**：
- **P51（块率收敛）**：一阶模型 `s_{k+1}=s_k+L δx_k`，`δx_k=−λL̂⁺e_k` ⇒ `e_{k+1}=(I−λLL̂⁺)e_k`。若 `‖L̂−L‖≤ε` 且 `λ` 取在稳定域使 `ρ(I−λLL̂⁺)<1`，则 `‖e_k‖≤ρ^k‖e_0‖`；边界样本数 `K` 只需 `ρ^K≤1/2`（E73 要求 ≤5 个边界）。完美模型下 `λ=1` 为一步 deadbeat，但为鲁棒取 `λ<1`。
- **P52（子空间可辨识）**：`rank(L̂[S,:]) = |S|` 时可解；单目标 m=4 故 `|S|≤4`，超出的自由度由先验 `L̂_0` 的零空间分量固定 ⇒ 修正不进入不可辨识方向，不会发散。
- **P53（可信度不降级）**：`δx` 经幅度/差分双重箝位且按缓动叠加，`U` 的一阶差分不超过 `Δ_max`、马氏距离不超过 `ρ_reg`，故不触发官方「动作离群」判据（F67 §6）；最坏回退为无伺服（P50 类）。
- **P54（无标定鲁棒）**：`L̂` 在线吸收相机内外参/安装误差，`s` 用面积/矩而不用深度 ⇒ 无标定、无深度亦可收敛（F68/F78）。

### 3.3 IP-52 LOOP-PERIOD-CODESIGN（周期-盲运动协同设计，完整设计）

**IP 卡片（六字段）**：
- **动机**：F67 证明 `T_a` 冻结且块内无反馈；v17 只把 `T_a` 当热旋钮且运行期想改（不可行）。PACE/RACE（F71/F72）证明执行时域与子技能切换是步数与成功率的杠杆。
- **与现有方案差异**：PACE 在线选执行时域（需要可重规划），本接口 `T_a` 冻结 ⇒ 把「变时域」改造为**设计期选 `T_a` + 运行期尾部驻留 + 轨迹整形**；RACE 让策略条件化切换时机，我们在**不重训策略**的约束下用「驻留/整形」近似。无人把「静态周期 + 尾部驻留」用于解耦热/时延与漂移。
- **技术可行性**：`T_a` 候选仅 6 个（1/2/4/8/16/32），设计期真机/虚拟各扫一次；尾部驻留只是 chunk 生成时对 `n..T_a` 填零速；整形是三次缓动 + 端点约束，无需重训。
- **所需资源**：数据=示教子技能时长分布（PACE 式速度谷统计，自采即可）；算力可忽略；接口=`action_chunk_size`（一次性声明）+ 绝对目标。
- **落地步骤**：① 统计示教速度曲线谷→子技能众数时长 `d*`；② 候选 `T_a` 扫 E75（真机小样本 + IP-53 虚拟放大）；③ 实现尾部驻留与终端整形；④ 可恢复裕度约束接入 IP-33；⑤ 与 IP-48/25 共享时延/热账本；⑥ E75/E78 验收。
- **风险**：驻留浪费步数（→`n*` 联合优化 + E75）；子技能时长方差大（→按场景画像选 2–3 套 `T_a`，metadata 期按指令/场景预选，仍受"整份提交单值"约束则取众数）；整形过度导致动作过慢（→与步骤分对撞）。

**符号表**：`T_a`=声明周期（冻结）；`n`=子技能实际结束步（≤`T_a`）；`τ_p=(T_a−n)Δt`=驻留时长；`B_eff=nΔt`=有效盲运动；`ρ`=可恢复裕度；`d*`=子技能众数时长；`C,Var(L),N`=算力/时延方差/步数。

**算法（设计期 + 运行期）**：
```
# ===== 设计期（一次性）=====
d* ← mode(示教速度曲线低速谷间距)              # PACE，F71
for T_a in {1,2,4,8,16,32}:
    J[T_a] = w_c·c_infer/T_a + w_d·D(T_a) + w_l·Var(L|T_a)
             + w_b·B(T_a,d*) + w_s·N(T_a)
T_a* ← argmin J   （真机小样本 + IP-53 虚拟放大，E75）
metadata.action_chunk_size ← T_a*

# ===== 运行期（每块生成时）=====
n ← 预测的当前子技能结束步（来自 IP-28v2 进度 / 速度谷 / IP-39 waypoint 切换）
n ← clip(n, 1, T_a)
U[0:n] ← 名义轨迹（VLA/TO 收窄版）
U[n:T_a] ← 减速—停稳驻留（零速、保持终端位姿）       # 尾部驻留
要求：整段轨迹到不可逆失败集距离 ≥ ρ（可恢复裕度，IP-33 校验）
      U 满足可信度正则（Δ_max, 马氏半径）
若 n 过小且 (T_a−n) 步浪费过大：n ← argmin_n drift_cost(n)+step_cost(T_a−n)
输出 U
```
**正确性论证**：
- **P55（漂移-周期解耦）**：漂移 `D≈v̄·nΔt+ε_track` 只依赖有效盲运动 `n`，与周期 `T_a` 解耦；故可选大 `T_a` 降 `c_infer/T_a` 与 `Var(L)`，同时经驻留保持小 `n`。存在 `T_a*>d*` 使两项同时改善（E75 验证）。
- **P56（可恢复性）**：若块内轨迹到不可逆集距离 `≥ρ` 且扰动有界 `≤ρ/2`，则块末状态仍在可纠正域内，下一边界伺服（IP-51）可闭合 ⇒ 不产生不可逆失败。
- **P57（步骤-精度帕累托）**：驻留步数 `(T_a−n)` 与漂移 `∝n` 构成单调对撞，`n*` 为帕累托点；在给定 `g(N)` 下可取到 `min drift_cost+step_cost`。

### 3.4 IP-53 VIRTUAL-REAL-EVAL（虚拟真机评测，完整设计）

**IP 卡片（六字段）**：
- **动机**：真机试次昂贵不可复现；PiL-World（F75）证明 chunk 级动作条件世界模型可把真-想成功率差压到 12%；v17 的 `p_s` 先验、`T_a` 扫描都缺数据源。
- **与现有方案差异**：官方隐藏评测器不可用；我们把「评测器」变成参赛者侧可微调的工具，并明确只用于相对排序/失败挖掘；与 v17 的仿真代理（IP-35 MuJoCo）不同，这是**动作条件视频/观测世界模型**，保留视觉与接触外观。
- **技术可行性**：可基于开源视频扩散/世界模型微调（或直接用官方 UnifoLM-WMA 族若可用，F62）；单 episode rollout 到分钟级；标定集 50–200 真机轨迹（含失败）。
- **所需资源**：数据=自采/开源 + 少量真机成功/失败轨迹；算力=单卡推理；接口=离线，不占评测时延。
- **落地步骤**：① 采/聚演示 + 失败轨迹；② 微调 chunk 级动作条件世界模型；③ 与之交替 rollout（VLA→chunk→WM→obs→…）；④ 在留出真机集标定真-想差；⑤ 输出 `p_s`、`T_a` 排序、失败模式报告；⑥ E77 门槛。
- **风险**：真-想差距大（→只做相对排序，E77）；想象奖励黑客（→用真机小样本锚定，报告 HFR）；算力/时间成本（→只扫关键配置）。

**算法（离线）**：
```
1. W ← finetune_world_model(demos ∪ failures)          # chunk 级动作条件，多视角
2. for cfg in grid(models × T_a × knobs × perturbations):
       for episode in 32_tasks × 5_axes:
           o ← reset();  h ← []
           while not done and steps < N_max:
               U ← policy(o, cfg)                      # 含 IP-51/52
               o' ← W(o, U)                            # 想象 rollout
               h.append((o,U,o')); o ← o'
           record success, steps, latency_var, action_regularity
3. calibrate: gap = |Ê[success] − E_real[success]|  on held-out real set
4. emit: p_s table, T_a ranking, failure-mode clusters, knob sensitivity
```
**正确性论证**：
- **P58（相对可排序）**：若 `W` 对同一策略前后版本的偏差同向（近似共模），则两配置的想象差可近似真实差，排序一致；E77 用 Spearman/成功率差验证。
- **P59（失败挖掘有效）**：`W` 用失败轨迹训练（F75），对「接近成功但倾倒/滑落」类失败敏感，可定位 F79 的放置失败主灶。

### 3.5 IP-54 EVAL-TIME-ADAPT（评测单元自适应，完整设计）

**IP 卡片（六字段）**：
- **动机**：F76 硬件偏移可使成功率 100%→0%；F80 证明动作-结果失配可在线估环境/动力学潜变量；本接口无温度/电流/电压（F77），故只能从失配反推。
- **与现有方案差异**：TeAR 用遥测（我们无）；Self-Adaptive VLA 需注入偏移训练上下文 token。我们做**轻量、可解释、低维偏置估计 + 前馈**（不重训主干），并在块边界用 IP-51 的 `(Δx,Δs)` 残差同时驱动。
- **技术可行性**：偏置低维（每臂 6 DoF 的加性/乘性增益）；块边界样本即可递推；<0.1ms。
- **所需资源**：数据=注入偏移的自采（E74）；算力可忽略；接口=F67 绝对目标 + 堆叠本体/EE 位姿。
- **落地步骤**：① 光度归一 + 特征鲁棒化；② 动作-结果观测器（命令 vs 实际位姿差）；③ 低维偏置递推 + 前馈补偿；④ 可信度正则；⑤ E74 验收。
- **风险**：偏移不可观测（→只补可观测方向，其余靠 IP-51 图像闭环兜）；过补偿震荡（→保守增益 + 回差 + 可信度限制）；训练/评测分布差（→偏移分布增广）。

**算法（块边界）**：
```
输入：o_k, 上一块命令 U_{k-1}, 实际末端/关节（来自堆叠本体/EE 位姿）
1. 光度归一化图像（白平衡/直方图/γ），特征用 DINOv2/轮廓而非原始像素
2. 观测器: ε_k ← 实际位姿 − 期望位姿（对 U_{k-1} 的跟踪残差）
   b_k ← (1−β)·b_{k-1} + β·proj_可观测(ε_k)     # 低维硬件偏置（加性/增益）
3. 前馈: U_k ← U_k ⊖ b_k                        # 在可观测子空间反向补偿
4. 可信度正则: U_k ← regularize(U_k, Δ_max, ρ_reg)
5. 若偏移突变(||ε_k||超阈): 交由 IP-51 图像闭环 + IP-24 失败监测
```

### 3.7 训练/服务伪代码（v18 增量版）

```python
# ===== 离线：选周期 + 训练伺服先验 + 虚拟评测器 =====
def design_loop(cfg):
    d_star = mode_subskill_duration(demos)                 # PACE 速度谷
    J = {T: w_c/T*infer_cost + w_d*drift(T) + w_l*latency_var(T)
            + w_b*boundary_err(T,d_star) + w_s*steps(T)
         for T in [1,2,4,8,16,32]}
    T_a = argmin(J)                                        # E75 + IP-53 放大
    L0 = init_interaction_matrix(demos)                    # 粗先验
    W  = finetune_world_model(demos, failures)             # IP-53
    return T_a, L0, W

# ===== 运行期：块边界闭环交付 =====
def act_v18(obs, state):
    # ---- 0. 账本（Δ）+ 评测自适应（Ε） ----
    ledger = update_ledger(gpu=telemetry(), latency=L_ewma, steps=state.steps)
    state.bias = update_bias_observer(obs, state.prev_cmd)      # IP-54
    obs = photometric_normalize(obs)                            # IP-54

    # ---- 1. 块边界视觉伺服观测器（IP-51）----
    feat = servo_features(obs, target=state.language_target)    # (u,v,log√A,θ)
    if state.prev_cmd is not None and feature_valid(feat):
        ds = feat - state.prev_feat
        state.Lhat = broyden_gated(state.Lhat, state.prev_cmd, ds)
    e = feat - state.s_star
    dx = clip_norm(-state.lam * solve_subspace(state.Lhat, e, state.S), C)
    dx = rate_limit(dx, D)
    dx = smooth_blend(dx)                                       # 三次缓动

    # ---- 2. 规划（低频）----
    if state.need_plan:
        state.plan = step_efficient_planner(obs.language, semantic_map,
                                            p_s, W, M_f, scenario=state.sigma)
        state.need_plan = False

    # ---- 3. 名义 chunk（VLA + IP-50 收窄版时间/精度精修）----
    U_nom = policy_chunk(state.plan.skill, obs)                 # 绝对目标 T_a 步

    # ---- 4. 周期-盲运动整形（IP-52）----
    n = predict_subskill_end(obs, state.plan)                   # 进度/速度谷
    n = argmin_n drift_cost(n) + step_cost(T_a - n)
    U = shape_chunk(U_nom, n=n, T_a=T_a,
                    tail="settle", recover_margin=rho)         # 尾部驻留
    U = apply_terminal_correction(U, dx)                        # 叠加伺服修正

    # ---- 5. 降维硬件偏置前馈 + 可信度正则（IP-54）----
    U = compensate_bias(U, state.bias)
    U = credibility_regularize(U, dmax=Delta_max, maha=rho_reg)

    # ---- 6. 块内兜底（唯一硬安全层 IP-33）----
    if not cbf_check(U):
        U = resample_or_fallback(U, r=2)

    # ---- 7. 失败监测（动作-结果失配）----
    if tracking_residual(obs, state.prev_cmd) > TAU_FAIL:
        state.need_plan = True; M_f.log(...)

    state.prev_cmd, state.prev_feat = U, feat
    return U
```

## 6. 清单迭代规则（继承 27–51 + 本轮新增 52–55）

- 继承规则 27–51（通道诚实/映射验证/SLO/fail-safe/灵感-现实校验/单模型合规/步骤分双解释/稠密监督/方法论遗产/元数据重照亮/语言口径分离/摊销/验证器分级/灵感词落地/层级联合规划/跨本体运动/流式韵律/渐进蒸馏/服务化/证书化/组合代数/热预算/期望得分/学习-TO/修剪优先）。
- **52（新增）：闭环周期一等原则**——`T_a` 是唯一且冻结的闭环周期，同时是热/算力、盲区间、视觉反馈频率；任何「运行期改 `T_a`」的设计作废；自适应只能作用于块内容、驻留、分支与准入。
- **53（新增）：块率 look-and-move 原则**——本接口不做块内高频闭环；视觉伺服只允许在块边界、无标定、目标中心特征、在线交互矩阵、伺服子空间闭合；必须带可信度正则与无伺服回退。
- **54（新增）：周期-盲运动解耦原则**——用尾部驻留把有效盲运动与实际周期解耦；每块须满足可恢复裕度；驻留步数须与步骤分显式对撞。
- **55（新增）：评测单元未知原则**——把真机相机/光照/硬件偏移当作一等不确定性；优先无标定、动作-结果在线自适应、可当场证伪的组件；虚拟评测器（相对决策）与真机小样本标定并用。

**本轮最大风险一句话**：`T_a` 冻结导致短 episode 内块率样本极少，而真机偏移无直接遥测，可能使「块率伺服 + 测试时自适应」在一个 episode 内来不及收敛；以 E73–E78 六重守门按「块率伺服 > 周期-驻留 > 评测自适应 > 虚拟评测」优先序保底，全败回退 v17 静态策略 + 演示期强鲁棒化。

**当前最值得押注**：**IP-51 CHUNK-RATE-VISUAL-SERVO + IP-52 周期-驻留解耦的组合**——它直接利用 F67 揭示的接口真相（周期冻结、块内无反馈），把 v17「离线算准」的精度目标改成「边界可观测地纠偏」，并用「大 `T_a` + 尾部驻留」同时拿下热/时延与低漂移；两者都能用 E73/E75 在真机小样本上快速证实或证伪，且即使失败也安全回退到 v17，是风险收益比最高的落子。
