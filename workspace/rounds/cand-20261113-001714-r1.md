# 第 63 轮（承接第 62 轮「ROSE」IP-183~192；灵感循环 III 第 1 轮；本轮灵感：「平衡控制」×「通用机器人」）

> 第 62 轮 ROSE 把 ESEC 升级为「在线学习 × 鲁棒编译 × 场景银行」的动态闭环，但它仍有一个被忽略的**体域盲区**：ROSE 的全部学习与安全都发生在**阻抗空间 K**——一个与具体关节/体型弱相关、却与**全身平衡可行性**无关的低维控制量。它能回答「这条腿该多硬」，却不能回答通用机器人最致命的三件事：
> 1. **平衡不是任务，而是所有任务的前置约束**：K_safe 即使逐关节安全，整体仍可能因 CoM/DCM 越界而摔倒；J_rose 的 ρ_rob 只度量阻抗安全边界，不含**跌倒不可逆性**。
> 2. **通用性被「同构假设」偷走**：OLP/WCV 的特征 h(x) 与阻抗维度默认同一台机器人；换腿长、换质量分布、换四足/轮足，W 与球半径 r 全部失效——系统没有**形态无关的平衡表征**。
> 3. **场景银行只记「险情」不记「濒临跌倒」**：滑移、振动、力超限是局部事件，真正昂贵的样本是**恢复成功/失败的近跌倒轨迹**；ROSE 没有采集，也没有把「恢复能力」作为课程信号。
>
> 本轮引入两个灵感：**平衡控制**（质心动力学、DCM/捕获点、接触力锥、可行性核）与**通用机器人**（形态无关表征、跨本体迁移、技能组合）。核心主张：**把平衡从低层控制器提升为跨任务、跨形态的不变安全核（invariant safety kernel）**——高层语义/技能先被编译为「平衡足迹」，再由一个形态无关的质心平衡层认证并投影，最后才落到关节。若 ROSE 是「语义—阻抗」闭环，COBALT 就是「语义—平衡—关节」的三层闭环。

## 0. 直觉与动机

**灵感 1（平衡控制 → 平衡是唯一任务不变的安全约束）**
直觉：走路、抓取、爬楼、被推，任务千变万化，但「不摔倒」是它们共享的唯一硬约束。传统平衡控制用 ZMP/捕获点/接触力锥逐机器人手调；关键洞见是——**质心动力学是形态无关的**：
m(com̈ − g) = Σ f_i，dL/dt = Σ (p_i − com) × f_i。
无论四足、双足还是轮足，这条方程不变，变的只是「腿能不能产生所需接触力」。因此可以把平衡层做成一个**形态无关的质心平衡核**，把形态差异下沉为一个「可达接触力集」约束。平衡不再是某个控制器，而是**所有技能的可行性证书**。

**灵感 2（通用机器人 → 无量纲平衡 + 形态条件化解码）**
直觉：一只 0.3m 四足和一台 1.8m 人形，若都用「米/秒」学平衡，永远无法共享策略；但用「腿长 L、重力 g、总质量 m」归一化后，DCM、时间、力都变成无量纲量（Buckingham π）。**在无量纲质心状态空间里，不同机器人看起来一样**。再给策略一个「本体 token」（由 URDF/运动学树图编码器产生），共享的平衡核即可零样本迁移到新形态；真正需要本体特化的只剩「接触力可达集」与「关节解码器」。

**灵感 3（从阻抗安全到可行性核 → NVK 平衡证书）**
直觉：ROSE 的球 B(φ̂,r) 描述「物理参数不确定」，却没有描述「未来 N 步还能不能救回来」。定义 **N 步可行性核 V_N**：从当前质心状态出发，存在一条接触序列与控制，使未来 N 步始终留在安全集内。ρ_bal = dist(ξ, ∂V_N) 就是「离摔倒还有多远」的签名距离。它比任何瞬时 ZMP 裕度都更接近通用机器人真正怕的东西——**不可逆性**。用逐接触模式的凸内近似（LIPM/DCM + 接触力锥 + 可达力集）保证 V_N^in ⊆ V_N，使证书成为**可靠下界**而非拍脑袋。

**灵感 4（在线学习 → OLP-B 带 CBF 约束的平衡残差学习）**
直觉：保守的可行性核会让机器人「过度安全、行动迟缓」。把基线屏障 B_0（来自 V_N^in）加一个在线残差 B_W = B_0 + wᵀΦ(ξ)，用执行数据在线缩小保守性；但 w 必须留在**使离散 CBF 条件成立的凸集 𝒲** 内——于是学习发生在安全集内部，**每一步都安全，而不只是收敛后安全**。遗憾界依然是 O(√T)，但这次是「保守性遗憾」：越学越敏捷，且从不以安全为代价。

**灵感 5（鲁棒 + 残差 → RVC 与 MOC：承认接触不确定性）**
直觉：质量、质心偏置、惯量、摩擦、执行延迟在真实机器人上永远有偏差；通用机器人还要面对未知负载与未知地面。RVC 在不确定球内对「跌倒风险 CVaR」取最坏；MOC 用**动量观测器**从质心动量残差反演外部扰动/负载，自动校准球半径。第 62 轮 RSC 的「残差被控制器吸收」风险，在质心层有一个天然补丁：**主动激励 + 可观测性监控**，不可观测时保守膨胀 r。

**灵感 6（场景驱动 → BIB：近跌倒样本是最贵的通用性素材）**
直觉：通用机器人最稀缺的数据不是成功轨迹，而是「差一点摔倒又救回来」的边界轨迹。BIB 把近跌倒（ρ_bal 低于阈值）、滑移、接触丢失、饱和、恢复成功/失败挖成场景，并变异出推、坡、冰、负载偏移、单腿支撑等复合扰动；用平衡簇遗憾调度重规划、仿真生成与适配预算。

**灵感 7（合流 → COBALT：质心在线鲁棒平衡学习与迁移）**
COBALT = Centroidal Online BAlance Learning & Transfer。闭环：语义/技能 → 平衡足迹 → VShield 投影到 V_N^rob → RVC/OLP-B 生成 DCM 参考与接触计划 → EKD 解码为全身关节 → 执行 → MOC/平衡遗憾/近跌倒回传。ROSE 的 K_safe 仍保留为**末端阻抗层**，COBALT 在其上增加**质心平衡层**；两者串联而非替代。

## 1. 形式化定义（增量：定义 185–196）

- **定义 185（COBALT 闭环）**：COBALT = (ROSE, CCS, EWR, NVK, OLP-B, RVC, MOC, BIB, SHC-B, VShield, OCB-B, J_bal)。定位：在 ROSE 的语义—阻抗闭环之上加一层形态无关的质心平衡核；所有新组件只依赖质心动力学与无量纲状态，不推翻 ROSE 接口。
- **定义 186（质心规范状态 CCS）**：给定特征长度 L（CoM 高度或腿长）、重力 g、总质量 m，无量纲状态 ξ = (c, c′, ζ, ℓ, σ)，其中 c = com/L，c′ = coṁ/(L√(g/L))，ζ = c + c′（无量纲 DCM），ℓ = L_ang/(mL²√(g/L))，σ 为接触模式。质心动力学在 ξ 上形态无关；本体差异由 EWR 承担。
- **定义 187（本体可达力集 EWR）**：E(e, ξ, σ) ⊆ ℝ^{6|σ|} 为形态 e 在该状态下经全身 QP 可实现的质心 wrench 集；由运动学树图编码器 + 可达性学习得到，且只允许**保守内近似**（宁可少算可达，不可多算）。
- **定义 188（N 步可行性核 NVK）**：V_N(φ) = {ξ_0 : ∃σ_{0:N−1}, u_{0:N−1}, ξ_k ∈ K, ξ_{k+1} = f(ξ_k,u_k,φ), u_k ∈ E(e,ξ_k,σ_k)}；ρ_bal(ξ) = dist(ξ, ∂V_N) ≥ 0 为平衡证书。计算用逐接触模式的凸内近似 V_N^in ⊆ V_N，取 ρ_bal = max_σ ρ_σ。
- **定义 189（鲁棒可行性编译 RVC）**：ρ_bal^rob(ξ) = inf_{φ∈B(φ̂,r)} ρ_bal(ξ;φ)，V_N^rob = ∩_{φ∈B} V_N^in(φ)；编译输出接触计划 σ* 与 DCM 参考，使球内最坏情形的 CVaR_ε[fall risk] 最小。
- **定义 190（动量观测器校准 MOC）**：由广义动量观测器得外部 wrench 残差 ŵ_ext；e_t = ‖J_φ⁺(ŵ_ext − w_ext^pred)‖，φ = (m, com_offset, I_diag, μ)；r_{t+1} = clip((1−β)r_t + βe_t, r_min, r_max)，并维护可观测性度量 O_t = λ_min(I_φᵀI_φ)，O_t 低时按 r_min ← r_min(1+κ/O_t) 膨胀。
- **定义 191（OLP-B 在线平衡投影）**：平衡屏障 B_W(ξ) = B_0(ξ) + wᵀΦ(ξ)，w ∈ 𝒲_t = {w : 离散 CBF 条件 B_W(f(ξ,u)) ≥ (1−γ)B_W(ξ) 在验证域内成立 ∧ B_W ≥ 0 于安全种子}；w_{t+1} = P_{𝒲_t}(w_t − η_t∇ℓ_t)，ℓ_t = hinge(δ_des − B_W(ξ_t)) + λ·effort。
- **定义 192（平衡足迹与 VShield）**：技能 s 的平衡足迹 F(s) = (接触时序, DCM 包络, 最大质心加速度, 时长, 负载)；VShield 求 p* = argmin_p ‖p − p_prop‖ s.t. F(s(p)) ⊆ V_N^rob；距离 > δ_bal 则降级（减速/加支撑）或 ask_clarify。
- **定义 193（平衡事件银行 BIB 与 SHC-B）**：BIB 记录近跌倒/滑移/接触丢失/恢复成功失败；签名用 ξ、σ、扰动估计；Mut 注入推/坡/冰/负载/单支撑/延迟。簇遗憾 R_c 驱动 Hedge，分配重规划、仿真、MOC 激励与适配预算。
- **定义 194（OCB-B 平衡预算老虎机）**：臂 = 规划保真度 {full WBC+NVK, LIPM-QP, cached DCM, static} × {robust on/off}；EXP3，奖励 = 进展 − 代价 − 跌倒风险惩罚，硬降级规则仍为安全下界。
- **定义 195（平衡证书 J_bal 与组合证书）**：J_bal = (ρ_bal^rob, V_N 版本, B_W 版本, r_t, σ* hash, e_id, planner_arm, shield_hash)；J_cobalt = (J_rose, J_bal)。Valid(J_cobalt) ⇔ Valid(J_rose) ∧ ρ_bal^rob ≥ 0 ∧ CBF 条件在活跃域验证 ∧ 接触计划可达 ∧ r_t ≤ r_max。
- **定义 196（COBALT 闭环算子）**：语义流（技能/对话 → 足迹 → VShield → RVC/OLP-B → BIB/SHC-B → MOC 更新）；实时流（质心状态估计 → NVK 证书查询 → DCM 跟踪 → EKD/WBC 解码 → 派发），实时流**零在线学习写操作**，只读证书与参数。

## 2. 关键算法骨架（完整伪代码见产物区）

```python
# NVK：形态无关的 N 步可行性证书（实时只查询，不训练）
xi = CCS(com, com_vel, L, g)
rho = NVK.signed_distance(xi, EWR(e, xi, sigma))
# OLP-B：带 CBF 约束的在线残差学习（语义流）
B_W = lambda xi: B0(xi) + w @ Phi(xi)
w = project_to_W(w - eta * grad(hinge(delta_des - B_W(xi)) + lam * effort), W_set)
# RVC + MOC：不确定球内最坏编译 + 动量残差校准
sigma_star = argmin_sigma sup_{phi in B(phi_hat, r)} CVaR(risk(xi, sigma; phi))
r = EWMA(||J_phi_pinv @ (w_ext_obs - w_ext_pred)||); r *= inflate_if_unobservable(O_t)
# VShield：技能参数投影到可行域
p_star = project(F_feasible(r, V_N_rob), p_prop)
if dist(p_star, p_prop) > delta_bal: degrade_or_clarify()
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 1（无量纲等价）**：在尺度变换 (m,L,g) 下质心动力学与接触约束在 CCS 中形式不变；跨本体差异被压缩进 EWR 与解码器。故共享平衡核的迁移误差只来自 EWR/解码器误差与本体分布距离。
- **引理 2（CBF 不变性）**：若 w_t ∈ 𝒲_t 且 B_W(ξ_0) ≥ 0，则 B_W(ξ_k) ≥ 0 ∀k；若 {B_W ≥ 0} ⊆ K，则学习轨迹全程不跌倒——**安全与学习同时成立**。
- **定理 1（在线遗憾）**：ℓ_t 对 w 凸且 ‖∇ℓ_t‖ ≤ G_B，投影 OGD 取 η_t = D_B/(G_B√t) ⇒ R_T ≤ D_B·G_B·√T，且所有迭代在 𝒲_t 内（安全不被遗憾优化破坏）。
- **定理 2（鲁棒证书可靠性）**：若 V_N^in ⊆ V_N 且 MOC 覆盖 P[φ* ∈ B(φ̂,r)] ≥ 1−α_cal，则 ξ ∈ V_N^rob ⇒ 真实 φ* 下 N 步内存活概率 ≥ 1−α_cal。跌倒风险被**核包含 + 球覆盖**双重兜底。
- **命题 1（技能可组合）**：若每个技能足迹 F(s_i) ⊆ V_N^rob 且切换点 ξ 仍在 V_N^rob，则顺序组合安全（需切换不变式，见风险节）。
- **实时性**：NVK 查询用预编译多面体/神经 HJ 蒸馏，≤0.2ms；重编译与学习在语义流，保持第 62 轮实时契约。

## 2. 形式化定义（完整版）

**定义 185（COBALT 闭环）** COBALT 是在 ROSE 的「语义流 ∘ 实时流」骨架上增加一层质心平衡核。三层结构：
1. **语义/技能层**：DMS/任务规划产生技能参数 p（速度、步长、负载、支撑方式）；
2. **质心平衡层**：CCS 编码 → VShield 投影到 V_N^rob → RVC/OLP-B 生成 DCM 参考 ζ_ref、接触计划 σ* 与平衡证书 ρ_bal^rob；
3. **关节执行层**：EWR 与 EKD 将 (ζ_ref, σ*) 解码为全身关节/力矩，经 WBC/ERTC 派发。

不变式：**语义层只提出「想做什么」，平衡层只回答「能不能、最多做到多少」，执行层只负责「如何做到」**；实时路径零在线学习写操作。

**定义 186（质心规范状态 CCS）** 设特征长度 L、重力 g、总质量 m、ω=√(g/L)、无量纲时间 τ=ωt。定义
c = p_com/L，c′ = dp_com/dτ / L = ṗ_com/(Lω)，ζ = c + c′，
ℓ = L_ang/(mL²ω)，f̃ = f/(mg)，τ̃ = τ/(mgL)，p̃ = p/L。
则质心 Newton–Euler 方程化为
**c″ = Σ_i f̃_i + ĝ**，**ℓ′ = Σ_i (p̃_i − c) × f̃_i + τ̃_i**，ĝ=(0,0,−1)。
约束：f̃_i ∈ 摩擦锥 μ、单边接触 f̃_z ≥ 0、CoP ∈ 支撑多边形 S̃(σ)、执行器/关节限幅经 EWR 表达。无量纲群：μ、I/(mL²)、质量比、Froude 数 Fr=|c′|²、ζ、time-to-fall。关键性质：**同一组 (c,c′,ζ,ℓ) 动力学对任意 (m,L) 形式相同**。

**定义 187（本体可达力集 EWR）** 对形态 e、状态 ξ、接触模式 σ：
E(e,ξ,σ) = { w = Σ_i [f̃_i; (p̃_i−c)×f̃_i+τ̃_i] : ∃ q̈, τ_act, 满足关节/执行器/接触约束 }。
实现：
- 运动学树图 GNN 编码 URDF 得本体 token e ∈ ℝ^{d_e}；
- 对一组探测方向 d_k，用全身 QP 精确求支撑函数 h_E(d_k)=max_{w∈E} d_kᵀw，再取**下界** ĥ_k ≤ h_E(d_k)（减去数值/建模裕度），拟合内多面体 E^in={w: d_kᵀw ≤ ĥ_k}；
- **只允许内近似**：E^in ⊆ E，宁少算不多算。E^in 是 NVK 中「腿能不能产生所需 wrench」的形态特化接口。

**定义 188（N 步可行性核 NVK）** 安全集 K = {ξ : 关节/执行器/接触约束满足 ∧ CoM 高度与角动量在界内}。N 步可行性核：
V_N(φ) = { ξ_0 : ∃σ_{0:N−1}, u_{0:N−1}, ξ_k∈K, ξ_{k+1}=f(ξ_k,u_k,φ), u_k∈E(e,ξ_k,σ_k) }。
证书 ρ_bal(ξ)=dist(ξ,∂V_N)（到边界的有符号距离），ρ_bal ≥ 0 ⇔ 存在 N 步安全计划。计算：
- 对每个接触模式 σ，采用 3D-LIPM/DCM 降维：dζ/dτ = ζ − p̃，dx/dτ = ζ − x，p̃∈S̃(σ)；
- 后向可达 V_0^σ=K，V_{k+1}^σ = K ∩ {ξ : ∃p̃∈S̃(σ), f(ξ,p̃)∈V_k^σ}，得到多面体；
- 对非零角动量、CoM 高度变化、执行延迟，用 tube 半径 κ_ℓ·‖ℓ‖ + κ_z·|Δz| + κ_d·Δt 收缩，保证 V_N^in ⊆ V_N（A77）；
- ρ_bal = max_σ dist(ξ,∂V_N^σ)，并返回达到最大裕度的模式 σ*。

**定义 189（鲁棒可行性编译 RVC）** 设物理参数球 B(φ̂,r)（由 MOC 给出），跌倒风险
risk(σ;φ) = CVaR_ε[ 1{∃k≤N: ξ_k∉K} ]（用 hinge(δ_risk−ρ_bal) 平滑）。
鲁棒编译：
(σ*, ζ_ref*) = argmin_{σ,ζ_ref} sup_{φ∈B(φ̂,r)} risk(σ,ζ_ref;φ) + λ_track·‖ζ_ref−ζ_des‖²，
并报告 ρ_bal^rob = inf_{φ∈B} ρ_bal(ξ;φ)。最坏情形通过球面方向采样 + Lipschitz 上界（或顶点枚举）实现；输出接触计划、DCM 参考与可行性证明片段。

**定义 190（动量观测器校准 MOC）** 广义动量 p=M(q)q̇，标准动量观测器
r(t) = K_O [ p(t) − p(0) − ∫_0^t (τ_act + Cᵀq̇ − G(q) + r(s)) ds ]，
稳态 r(t) → 外部广义力。质心版：h=[mċ;L_ang]，r_h(t)=K_O[h(t)−h(0)−∫(Σŵ_ext+τ_act+mĝ+r_h)ds]，取 ŵ_ext=r_h。
参数反演：e_t=‖J_φ⁺(ŵ_ext−w_ext^pred)‖，J_φ=∂w_ext/∂φ。球半径
r_{t+1}=clip((1−β_c)r_t+β_c e_t, r_min, r_max)，β_c=0.1。
可观测性：I_φ=Σ J_φᵀJ_φ，O_t=λ_min(I_φ)；若 O_t<O_min，则 r_min ← r_min(1+κ_O/O_t) 并注入**安全激励**（在 CBF 裕度内的小幅接触力扰动/自然任务变化）。这直接针对第 62 轮「残差被控制回路吸收」风险。

**定义 191（OLP-B 在线平衡投影）** 基线屏障 B_0 来自 V_N^in（例如 B_0=ρ_bal 的平滑代理）。带残差屏障
B_W(ξ)=B_0(ξ)+wᵀΦ(ξ)，Φ 为无量纲特征（ζ、c′、支撑裕度、接触模式 one-hot、负载估计等）。
离散 CBF 条件：B_W(ξ_{k+1}) ≥ (1−γ)B_W(ξ_k)，γ∈(0,1)。
可行集 𝒲_t={w : 条件在验证域 𝒳_ver 上成立 ∧ B_W(ξ)≥0, ∀ξ∈安全种子}。验证用区间算术/ Lipschitz 网格：对每个网格 ξ，约束对 w 线性（Φ(f(ξ,u)) 给定策略 u=π(ξ) 时可算），故 𝒲_t 是多面体（或其凸内近似）。
在线更新：w_{t+1}=P_{𝒲_t}(w_t−η_t∇ℓ_t)，ℓ_t=hinge(δ_des−B_W(ξ_t))+λ·effort(ξ_t)，η_t=D_B/(G_B√t)。
**关键性质**：投影保证 w_t∈𝒲_t ⇒ 学习过程中 CBF 不变式始终成立。

**定义 192（平衡足迹与 VShield）** 技能 s 由参数 p 实例化（速度 v、步长 d、步频 f、负载 m_p、支撑宽度 w_s、是否允许腾空）。平衡足迹
F(s(p)) = (σ 时序, ζ_ref 包络, a_com,max, T, m_p)。
可行参数集 P_feas={p : F(s(p)) ⊆ V_N^rob}。VShield：
p* = argmin_{p∈P_feas} ‖p−p_prop‖₂。
若 ‖p*−p_prop‖∞ ≤ δ_bal：执行 p*；否则：
- 若 P_feas 非空：降级到 p* 并生成解释（「为保持平衡，速度降至 0.8 m/s」）；
- 若 P_feas 空：ask_clarify（「当前地面/负载下无法完成，请减轻负载或改用扶栏」）。
对话约束（DMS/ROSE Shield）先经 VShield 的平衡可行性检查，再进入 ERTC 的阻抗安全投影。

**定义 193（平衡事件银行 BIB 与 SHC-B）** BIB={(s,meta_s)}；事件签名
sig = (ξ 归一化, σ, ŵ_ext/(mg), 地面类别, 负载估计)。
触发：ρ_bal<ρ_warn、接触丢失、力矩饱和、|c′| 突增、恢复控制激活。
Mine：若最近邻距离>d_new 建新事件；否则 n_near++ / n_recover++。
Mut：推脉冲 Δv、坡度 α、摩擦 μ(1−δ)、负载 m_p、单支撑、延迟 Δt、接触丢失、地形粗糙度。
SHC-B：簇遗憾 R_c(T)=Σ_{t∈T_c}(risk_t−risk_t^ref)，risk_ref 为保守基线（静态双支撑 + 大裕度）的风险；权重 w_c∝exp(η Ĝ_c)，分配：① 语义流重规划频率；② 仿真生成预算；③ MOC 激励采样；④ OLP-B/MEL-OA 适配批次。

**定义 194（OCB-B 平衡预算老虎机）** 臂空间 = {full WBC+NVK, LIPM-QP, cached DCM plan, static double-support} × {robust on, robust off}，K=8。每语义周期 EXP3 采样臂，奖励
r_t = progress_t − κ_c·cost_t − κ_f·max(0, ρ_warn−ρ_bal^rob)_t，
重要性加权更新 w_a ← w_a·exp(η·r̂_t(a_t)/K)。硬降级规则（延迟/温度/接触丢失）优先于老虎机，作为**安全下界**。

**定义 195（平衡证书 J_bal 与组合证书）** 
J_bal = (ρ_bal^rob, V_N 版本, B_W 版本, r_t, σ* hash, e_id, planner_arm, shield_hash)；
J_cobalt = (J_rose, J_bal)。
Valid(J_cobalt) ⇔ Valid(J_rose) ∧ ρ_bal^rob ≥ 0 ∧ CBF 条件在活跃域已验证 ∧ 接触计划 σ* 的 EWR 可达性已验证 ∧ r_t ≤ r_max ∧ anchor_fresh。
审计链：V_N/B_W 版本、σ* hash、本体 id、规划臂共同回答「谁在什么本体/什么证书下批准了这次动作」。

**定义 196（COBALT 闭环算子）** 见 IP-202 伪代码。语义流执行 [技能接地 → VShield → RVC/OLP-B → BIB/SHC-B → MOC 更新 → 预算更新]；实时流执行 [CCS 估计 → NVK 证书查询 → DCM 跟踪 → EKD/WBC 解码 → 派发 → 证书回传]，实时流**无在线学习写操作**。

```python
class CentroidalCanonicalState:
    def __init__(self, L, g):
        self.L, self.g = L, g
        self.omega = np.sqrt(g / L)

    def encode(self, p_com, v_com, L_ang, contact_mode):
        c = p_com / self.L
        c_prime = v_com / (self.L * self.omega)
        zeta = c + c_prime                       # 无量纲 DCM
        ell = L_ang / (MASS * self.L**2 * self.omega)
        return State(c=c, c_prime=c_prime, zeta=zeta, ell=ell, sigma=contact_mode)

    def decode_dcm(self, zeta, contact_mode):
        p_ref = zeta - self.dcm_dynamics(zeta, contact_mode)  # 反解 ZMP/接触参考
        return self.L * p_ref
```

```python
class EmbodimentWrenchReachability:
```

### IP-195 NVK（N 步可行性核）

```python
class NVKernel:
    def __init__(self, N=10, gamma_tube=0.02):
        self.N, self.gamma_tube = N, gamma_tube
        self.polys = {}                        # 每接触模式的 V_N^sigma 多面体

    def precompute(self, e, mode_sequence):
        for sigma in mode_sequence:
            V = safe_set(sigma)
            for _ in range(self.N):
                V = self.backward_step(V, sigma)   # LIPM/DCM 后向可达
            self.polys[sigma] = shrink_tube(V, self.gamma_tube)  # 保证内近似

    def signed_distance(self, xi, ewr, sigma):
        V = self.polys[sigma]
        d_poly = V.signed_distance(xi)          # 几何裕度
        d_wrench = ewr.inner_set(self.e, xi, sigma).min_margin(xi)
        return min(d_poly, d_wrench)            # 两者取小 -> 更保守、更可靠

    def certify(self, xi, ewr, modes):
        best = max(modes, key=lambda s: self.signed_distance(xi, ewr, s))
        return self.signed_distance(xi, ewr, best), best
```

### IP-196 OLP-B（CBF 约束的在线平衡残差）

```python
class OnlineBalanceProjection:
    def __init__(self, B0, Phi, D_B=1.0, gamma=0.1):
        self.B0, self.Phi, self.D_B, self.gamma = B0, Phi, D_B, gamma
        self.w = np.zeros(Phi.dim)

    def barrier(self, xi):
        return self.B0(xi) + self.w @ self.Phi(xi)

    def cbf_ok(self, xi, xi_next):
        return self.barrier(xi_next) >= (1 - self.gamma) * self.barrier(xi)

    def project_to_W(self, w, verified_states):
        # 每个验证状态给出一条线性约束; 取凸内近似（半空间交集）
        cons = []
        for xi in verified_states:
            xi_next = self.policy_step(xi, w)
            a, b = self.linearized_cbf_constraint(xi, xi_next)  # a^T w <= b
            cons.append((a, b))
        return project_halfspaces(w, cons)

    def online_step(self, xi, delta_des, effort_grad):
        violation = max(0.0, delta_des - self.barrier(xi))
        g = -2 * violation * self.Phi.grad(xi) + EFFORT_LAMBDA * effort_grad
        eta = self.D_B / (self.G_B * np.sqrt(self.t + 1))
        self.w = self.project_to_W(self.w - eta * g, self.verified_states)
        self.t += 1
        return self.w
```

```python
def robust_viability_compile(nvk, olp_b, ewr, xi, zeta_des, phi_hat, r,

    for phi in ball_samples(phi_hat, r, n_worst):
        for sigma in candidate_contact_modes(xi, zeta_des, phi):

    worst = sorted(candidates, key=lambda z: z[4], reverse=True)[:max(1, int(eps*n_worst))]

                rho_rob=rho_w, feasible=(rho_w >= 0))
```

### IP-198 MOC（动量观测器校准）

```python
class MomentumObserverCalibration:
    def __init__(self, K_O=20.0, beta_c=0.1, r_min=0.02, r_max=0.5):
        self.K_O, self.beta_c = K_O, beta_c
        self.r, self.r_min, self.r_max = 0.05, r_min, r_max
        self.I_phi = np.zeros((PHI_DIM, PHI_DIM))
        self.excite = SafeExcitation()

    def update(self, h, h0, integral_terms, J_phi, w_pred):
        r_h = self.K_O * (h - h0 - integral_terms)      # 外部 wrench 残差
        e = np.linalg.norm(np.linalg.pinv(J_phi) @ (r_h - w_pred))
        self.I_phi += J_phi.T @ J_phi
        O = np.linalg.eigvalsh(self.I_phi)[0]           # lambda_min
        if O < O_MIN:
            self.r_min = min(self.r_max, self.r_min * (1 + KAPPA_O / max(O, 1e-6)))
            self.excite.request(within_cbf_margin=True)  # 安全激励提升可观测性
        self.r = np.clip((1 - self.beta_c) * self.r + self.beta_c * e,
                         self.r_min, self.r_max)
        return self.r, O, r_h
```

```python
            return s
        nn.n_near += 1
        nn.n_recover += int(recover_info.success)
        return nn

    def mutate(self, s):
        return [push_impulse(s, dv), slope(s, alpha), friction_drop(s, delta),
                payload_shift(s, m_p), single_support(s), latency(s, dt),
                contact_loss(s), terrain_roughness(s)]

class BalanceCurriculum:
    def __init__(self, C, eta=0.2):
        self.w = np.ones(C) / C
        self.Ghat = np.zeros(C)
        self.eta = eta

    def step(self, cluster, risk, risk_ref):
        self.Ghat[cluster] = 0.9 * self.Ghat[cluster] + 0.1 * (risk - risk_ref)
        self.w = softmax(self.eta * self.Ghat)
        return self.w

    def allocate(self, slots):
        return {k: sample_by_weight(self.w, n) for k, n in slots.items()}
```

### IP-200 VShield（技能/对话可行性屏蔽）

```python
def viability_shield(p_prop, skill, xi, nvk, ewr, phi_hat, r,
                     delta_bal=0.1):
    def footprint_in_kernel(p):
        sigma_seq, zeta_env = skill.rollout(p, xi)
        return all(nvk.signed_distance(xi_k, ewr, sigma_k, phi)
                   >= 0.0
                   for sigma_k, xi_k in sigma_seq
                   for phi in ball_samples(phi_hat, r, 8))

    feasible, p_star = project_onto_feasible(footprint_in_kernel,
                                             p_prop, skill.param_box)
    if feasible and np.linalg.norm(p_star - p_prop, np.inf) <= delta_bal:
        return ShieldResult('accept', p_star, reason=None)
    if feasible:
        return ShieldResult('degrade', p_star,
                            reason=f'为保持平衡，参数调整至 {p_star}')
    return ShieldResult('ask_clarify', None,
                        reason='当前地面/负载下无可行的平衡计划，请减轻负载或改用扶栏')
```

### IP-201 OCB-B（平衡预算老虎机）

```python
class BalanceBudgetScheduler:
    ARMS = [(f, rb) for f in ('full', 'lipm', 'cached', 'static')
                    for rb in ('robust_on', 'robust_off')]

    def __init__(self, K=8, eta=0.3):
        self.w = np.ones(K) / K
        self.eta, self.K = eta, K

    def choose(self):
        return self.ARMS[np.random.choice(self.K, p=self.w)]

    def update(self, idx, progress, cost, rho_rob):
        reward = progress - KAPPA_C * cost - KAPPA_F * max(0.0, RHO_WARN - rho_rob)
        reward = np.clip(reward, 0.0, 1.0)
        r_hat = reward / max(self.w[idx], 1e-6) / self.K
        self.w[idx] *= np.exp(self.eta * r_hat / self.K)
        self.w /= self.w.sum()

    def clip_by_hard_rule(self, arm, hard_rule):
        return hard_rule.dominates(arm) if hard_rule else arm  # 硬规则为安全下界
```

## 4. 推导

**引理 1（无量纲等价 / 形态无关性）** 令 p_com=Lc，t=τ/ω，f=mg f̃，τ_ang=mgL τ̃，L_ang=mL²ω ℓ。代入 Newton–Euler：
m·(Lω² c″)=mg Σf̃_i − mg ĝ ⇒ c″=Σf̃_i+ĝ；
d(mL²ω ℓ)/dt = ω d(mL²ωℓ)/dτ = mL²ω² ℓ′ = mgL Σ[(p̃_i−c)×f̃_i+τ̃_i] ⇒ ℓ′=Σ[(p̃_i−c)×f̃_i+τ̃_i]。
所有约束（μ、单边、CoP、支撑多边形、EWR）亦只依赖无量纲量。故同一 CCS 动力学对任意 (m,L,g) 成立；本体差异仅通过 EWR/解码器进入。∎

**引理 2（CBF 不变性 / 学习期间安全）** 若 w_t∈𝒲_t 且 B_{W_t}(ξ_0)≥0。对任意 k，CBF 条件给出 B_{W_t}(ξ_{k+1})≥(1−γ)B_{W_t}(ξ_k)≥0。归纳得 B_{W_t}(ξ_k)≥0 ∀k。若 {B_W≥0}⊆K，则所有可达状态在安全集内，不跌倒。注意：w_t 在单个语义周期内冻结，实时流只读，故不变式成立。∎

**定理 1（在线保守性遗憾）** 设 ℓ_t(w)=hinge(δ_des−B_w(ξ_t))+λ·effort_t 对 w 凸（B_w 对 w 仿射，hinge 保凸），且 ‖∇ℓ_t‖≤G_B。投影 OGD：
‖w_{t+1}−w*‖² ≤ ‖w_t−w*‖² − 2η_t⟨∇ℓ_t,w_t−w*⟩ + η_t²G_B²。
凸性给 ℓ_t(w_t)−ℓ_t(w*)≤⟨∇ℓ_t,w_t−w*⟩。对 t 求和并取 η_t=D_B/(G_B√t)：
R_T=Σℓ_t(w_t)−min_{w∈𝒲}Σℓ_t(w) ≤ D_B²/(2η_T)+ (G_B²/2)Ση_t ≤ D_B G_B√T。
且投影保证 w_t∈𝒲_t（引理 2），所以遗憾优化不以安全为代价。∎
注：𝒲_t 随验证域/状态慢变时，退化为动态遗憾 D_B G_B√T + O(D_B G_B P_T)（标准同时化），P_T 为可行集路径长度。

**定理 2（鲁棒证书可靠性 / 从「可救」到「真能救」）** 假设：
(a) V_N^in(φ)⊆V_N(φ) 对所有 φ∈B（A77：LIPM+tube 是可靠内近似）；
(b) MOC 覆盖：P[φ*∈B(φ̂_t,r_t)]≥1−α_cal（A80）；
(c) EWR 保守：E^in⊆E_true（A79）。
若 ξ∈V_N^rob=∩_{φ∈B}V_N^in(φ)，则对真实 φ*（以 1−α_cal 概率在球内），ξ∈V_N(φ*)，故存在 N 步使 ξ_k∈K 的计划，存活概率 ≥1−α_cal。∎
与第 62 轮引理 2 的区别：ROSE 只保证「阻抗参数覆盖」，COBALT 进一步保证「存在可执行接触计划」，且失败模式从「参数越界」升级为「N 步不可逆」。

**命题 1（技能顺序可组合，条件性）** 若技能 s_1,...,s_m 的足迹 F(s_i)⊆V_N^rob，且每个切换时刻的 ξ_i 仍在 V_N^rob 内，并且切换瞬间的接触序列 σ_i→σ_{i+1} 有可行性核内的过渡计划，则顺序组合在 N 步意义下安全。证明：对每段用定理 2，切换点由假设连接。∎
注意：这是**条件性**命题——接触切换本身是最大漏洞（见风险节）。

**命题 2（跨形态迁移误差，非正式）** 设共享平衡核在训练本体分布 P_e 上学得，测试本体 e_test 的本体 token 为 e。解码误差 ≤ ε_EWR(e) + ε_dec(e) + Lip·W_1(P_e, δ_e)，其中 W_1 为嵌入分布的一阶 Wasserstein 距离，δ_e 为测试本体嵌入。形态随机化缩小 W_1；OOD 本体回退到模型基 NVK。∎（E211 实证，不作为硬定理。）

**命题 3（VShield 对话安全）** 若 P_feas 非空且投影精确，则 p*∈P_feas ⇒ F(s(p*))⊆V_N^rob ⇒ 由定理 2，规划在真实 φ* 下 N 步安全概率 ≥1−α_cal。若 P_feas 空则动作被拒绝/澄清，不安全接受率为 0（与策略质量无关）。∎
若投影用采样近似，则以采样覆盖率折减保证（E217 校验）。

## 7. 已知风险

**一句话**：若逐接触模式的凸内近似 V_N^in 在**接触切换瞬间**不再 sound（或 EWR 高估可达力、MOC 在控制器吸收扰动时不可观测），则 ρ_bal^rob 会把「不可救」误判为「可救」，J_bal 从可靠证书退化为纸面证书——这是本轮全部通用性与安全论证共同依赖的单点假设。

**次级风险与缓解**：
1. **接触切换 soundness**：V_N^in 按单模式构造，模式拼接可能不覆盖切换动力学（冲击、接触丢失、双重支撑瞬态）。缓解：显式切换守卫（guard）与模式序列枚举；切换窗口内强制保守 tube；NVK 拒绝时回退到静态双支撑/降低 CoM。
2. **EWR 高估可达力**：学习/拟合可能超出真实 QP 可达集。缓解：支撑函数只取下界 + 建模裕度；每批次用精确 WBC-QP 抽检；不确定时收缩 E^in（牺牲敏捷换可靠）。
3. **MOC 不可观测/被吸收**：低增益控制或慢变扰动使残差趋零，φ 不可辨识。缓解：可观测性 O_t 监控 + 安全激励 + 不可观测时膨胀 r_min；E215 专门验证。
4. **CBF 可行集 𝒲 为空**：高敏捷技能可能要求突破保守屏障。缓解：分层松弛（安全约束优先，任务目标次之）；先降级速度/步长，再请求澄清；绝不放开 𝒲。
5. **形态 token 外推失败**：新本体超出训练分布。缓解：程序化形态随机化 + OOD 检测回退模型基 NVK；记录 e_id 便于审计。
6. **无量纲化丢失绝对尺度效应**：执行器带宽、热约束、传感器延迟不随 L/g 缩放。缓解：增加无量纲带宽群 τ_act·ω、延迟群 Δt·ω，并在线校准；E211 报告尺度外推误差。
7. **BIB 分布漂移与课程过拟合**：近跌倒簇可能过时。缓解：簇封顶 64、低权重淘汰、lineage 审计；SHC-B 权重下限保证探索。
8. **证书组合爆炸**：J_cobalt=(J_rose,J_bal) 与 V_N 版本频繁更新导致审计链膨胀。缓解：版本化多面体哈希、增量审计、E220 回滚测试。
