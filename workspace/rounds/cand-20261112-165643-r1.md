# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC/IP-153~160；灵感循环第 7 轮；本轮灵感：「模块化设计」×「视觉定位」）

> 第 60 轮把「执行层→证据层」升级为「场景→意图→约束→阻抗→执行→证据→场景」闭环（SSM×CIEC×EPIR×SERC×PCE++++）。但**三个结构性局限**随闭环变长而暴露：
> 1. **闭环是单体式的**：SSM→CIEC→EPIR→XMC++ 的调用顺序被硬编码在 SERC 中，任何模块（尤其是定位/感知模块）升级，都要对整条链重新做一次安全论证；缺少**接口契约**，就无法「局部验证、全局复用」。
> 2. **场景信念只有「类别」，没有「位置」**：SSM 能判断「在湿滑地面」，却不能表达「距湿滑边缘 8 cm、局部坡度 12°、表面法向偏转 6°」。而阻抗先验对**局部几何**高度敏感——同一块湿地，靠近边缘处需要更大的 K_d 与更低的 v_max。类别级先验 `π_scene(K|z)` 在空间上是无条件的，因此会「整体正确、局部致命」。
> 3. **视觉定位缺位且被默认可信**：预接触阶段要「先认知后执行」，必须依靠视觉提供全局几何；但视觉在遮挡、逆光、弱纹理、运动模糊下会**静默失效**。把视觉当作 oracle，等于把不可靠模块直接接入安全链，且失败不可被证据层察觉。
>
> 本轮的回答：用「模块化设计」把闭环改造成**带 assume-guarantee 契约的可组合模块树**，用「视觉定位」把场景先验从**类别级**升级为**位置条件级**，并用「认证热插拔」处理视觉失效。

## 0. 直觉与动机

**灵感 1（模块化设计 → 模块化执行契约 MEC）**
直觉：安全闭环不应是一段写死的代码，而应是一组**可替换、可单独验证、可组合取证**的模块。每个模块像电路芯片：有类型化端口（输入/输出 + 单位 + 坐标系 + 时间语义）、有数据手册（在什么输入假设 A 下，保证什么输出性质 G、以多大概率）、有功耗包络（WCET/带宽/内存/热）、有失效引脚（降级策略），还有一枚「证据签名」。关键洞见：**模块化的本质不是代码复用，而是「安全证据的合成」**——组合两个模块时，只需检查上游保证是否满足下游假设、资源是否可加、耦合是否被见证，而不必重新证明整条链。

**灵感 2（视觉定位 → 定位质量感知场景图 LQ-SG）**
直觉：视觉给「where」，触觉给「what」。把场景表征从「类别标签」升级为**空间-语义图**：节点是语义区域/地标，携带位姿、协方差、视觉描述子与触觉可验证度；边是相对几何关系（法向、邻接、层级）。视觉定位的作用不是给一个点，而是给一个**带协方差与有效性谓词的位姿**，并据此检索局部邻域，提取局部几何特征 `g(x)=(边缘距离, 法向, 曲率, 坡度)`。关键洞见：**场景先验必须被定位质量调制**——定位越不确定，先验越宽、越保守；定位失效时，退回类别级先验。

**灵感 3（视觉-几何阻抗先验 VGIP）**
直觉：阻抗先验应写成 `π(K|z,x)` 而不是 `π(K|z)`。同一「湿滑地面」，`x` 靠近桌沿时 `Δμ_geo` 应把 K_d 推高、v_max 压低；`x` 位于大片中央时则可放宽。`Δμ_geo` 是局部几何的确定性函数（或离线学习的单调映射），并满足**单调保守性**：定位置信度 γ 下降 ⇒ 协方差膨胀 ⇒ K_safe 集合只会变大（更保守），绝不因「定位变差」而放大执行权限。

**灵感 4（三灵感合流 → 认证式模块化视觉-触觉闭环 CMVT）**
直觉：视觉模块给出「位姿 + 有效性证书」→ LQ-SG 给出「局部几何」→ VGIP 给出「位置条件先验」→ EEIS 编译「更窄但更可信的 K_safe」；若视觉有效性 `V_vis=0`，则按细化序认证热插拔到触觉里程计/惯导模块，并保持执行证据链 `seq_id` 连续。整条链输出一棵**携带证据的模块化安全论证树（MSC）**：根节点是任务级安全声明，叶节点是模块证据，边是耦合见证。

**灵感 5（模块化的悖论 → 模块化预算 PCE+++++）**
直觉：模块切得越细，局部验证越容易，但**接口与耦合成本**（序列化、坐标变换、时钟同步、重叠窗口交叉验证）越高，且时序抖动越大。因此存在一个最优粒度 `n*`。预算从「认知四维」扩展为「模块化五维」：`B_mod=(B_local, B_iface, B_couple, B_compose, B_exec)`，并用 `cost_iface + cost_couple` 显式惩罚过度模块化。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（模块化执行契约 MEC / 模块 MEM）** 一个执行模块
`M_i = (Port_i, A_i, G_i, R_i, E_i, δ_i)`，其中：
- **类型化端口** `Port_i = (In_i, Out_i)`，每个端口携带 `(数据类型, 单位, 坐标系, 时间语义)`；坐标系与时间语义是**契约的一部分**，不是注释。
- **输入假设** `A_i`：关于输入流与环境（含上游时序、坐标帧一致性、标定新鲜度）的谓词。
- **输出保证** `G_i`：关于输出流、时序与资源占用的谓词；`M_i ⊨ (A_i, G_i)` 表示对任意满足 `A_i` 的轨迹，`G_i` 至少以 `1-α_i` 概率成立。
- **资源包络** `R_i = (WCET_i, bw_i, mem_i, power_i)`。
- **证据生成器** `E_i: trace → token_i`（含输入哈希、输出哈希、契约位、签名）。
- **降级策略** `δ_i: 违约 → fallback_state`；要求**违约不静默**：`¬A_i ⇒ δ_i` 必被调用且写入证据。

**定义 162（契约合成代数 CCA）** 顺序合成 `M_i ⊗ M_j` 有定义，当且仅当：
1. **保证蕴含假设**：`G_i^out ⇒ A_j^in`（上游保证满足下游假设）；
2. **资源可加**：`R_i ⊕ R_j ≤ B_total`，其中 `⊕` 对 WCET/带宽/功耗取和、对内存取 max；
3. **时序可排**：存在调度使 `WCET_i + WCET_j` 不超过下游截止期。
合成结果：
```
A_{i⊗j} = A_i
G_{i⊗j} = G_j
α_{i⊗j} = 1 - (1-α_i)(1-α_j)              # 联合界
E_{i⊗j} = (E_i, E_j, W_ij)                 # W_ij 为耦合见证
R_{i⊗j} = R_i ⊕ R_j
```
**耦合见证** `W_ij` 必须同时校验：坐标帧变换 `T_ij`、时间戳单调性与对齐误差、单位/量纲一致、采样率匹配、以及重叠窗口内的交叉验证统计量。`⊗` 满足结合律但**不满足交换律**。  
**细化序（可替换性）**：`M' ⪯ M` 当且仅当 `A_M ⊆ A_{M'}`（新模块接受的环境不少于旧模块）且 `G_{M'} ⇒ G_M`（新保证不弱于旧保证）且 `R_{M'} ≤ R_M`。只有 `M' ⪯ M` 才允许在需要 `M` 的上下文中替换 `M`。

**定义 163（视觉定位模块 VLM）** `VLM = (Loc, V_vis, Σ_vis, ε_vis, α_vis, j_max)`：
- **定位器** `Loc: (image, calib, imu) → x̂=(p,R)`，采用 PnP+RANSAC 或特征-VIO 后端。
- **有效性谓词（可靠上近似）**：
```
V_vis = 1[ n_feat ≥ n_min ∧ rmse_reproj ≤ ρ_max ∧ texture ≥ τ_tex
          ∧ exposure ∈ [l_min,l_max] ∧ blur ≤ b_max
          ∧ calib_age ≤ a_max ∧ inlier_ratio ≥ r_min ]
```
- **保证**：若 `V_vis=1` 且环境假设 `A_vis` 成立，则 `‖x̂ ⊖ x‖_{Σ_vis} ≤ ε_vis` 以概率 `≥ 1-α_vis` 成立，且单帧跳变 `≤ j_max`。
- **无静默失败**：`V_vis` 必须是**可靠上近似**——`V_vis=1` 时保证必须真，`V_vis=0` 时必须显式置 `valid=False` 并触发降级；**禁止**在无保证时返回一个「看起来正常」的位姿。证据 `E_vis=(x̂,Σ_vis,V_vis,feature_stats,hash)`。

**定义 164（定位质量感知场景图 LQ-SG）** `G_t=(V_t,E_t,φ_t)`：
- 节点 `v=(ℓ, d, x_ℓ, Σ_ℓ, τ_ℓ)`：语义标签 `ℓ`、视觉描述子 `d`、位姿 `x_ℓ`、协方差 `Σ_ℓ`、触觉可验证度 `τ_ℓ ∈ [0,1]`。
- 边 `e=(i,j,T_ij, n_i, κ_ij)`：相对变换、法向关系、邻接/层级。
- **局部几何查询**：`g(x)=N_G(x,r)=(d_edge, normal, curvature, slope)`，由位姿 `x̂` 附近的节点与边计算。
- **节点置信度**：`γ_ℓ = f(V_vis, rmse_reproj, |Σ_ℓ|, 触觉一致性)`；未触觉验证的节点置信度不得被初始化得过高。

**定义 165（认证热插拔 CHS）** 替换算子 `S(M_old → M_new)` 被允许，当且仅当：
1. **上下文化细化**：对所有下游消费者 `C`，`M_new ⪯_{A_C} M_old`（新模块在最严格的消费者假设下仍满足细化序）；
2. **资源可容**：`R_new ≤ B_remaining`；
3. **状态可移交**：存在公共状态映射 `H`，交接误差 `≤ ε_h`（位姿/速度/阻抗状态）；
4. **重叠可验证**：存在窗口 `T_overlap`，两模块并行运行且交叉验证统计量在阈内。
任一条件不满足 ⇒ `δ_stop` 安全停机。热插拔延迟 `τ_swap ≤ τ_swap_max`，且**切换事件本身必须入证据链**（`seq_id` 连续，不因换模块而断裂）。

**定义 166（视觉-几何阻抗先验 VGIP）** 位置条件先验：
```
π(K|z,x) = N( K; μ_scene(z) + Δμ_geo(g(x)), Σ_scene(z) + Σ_geo(g(x)) )
K_safe^{scene,loc} = {K | P(K|z,x) ≥ τ_loc} ∩ K_safe_base
```
其中 `Δμ_geo`、`Σ_geo` 对局部几何（边缘距离、坡度、曲率、法向）单调。**单调保守性**：若定位置信度 `γ_vis < τ_vis`，则 `Σ_geo(g) → Σ_general`（膨胀到类别级先验），保证 `K_safe` 集合**只增不减**——定位变差只会更保守，绝不放大执行权限。

**定义 167（模块化预算 B_mod 与 PCE+++++）**
```
B_mod = (B_local, B_iface, B_couple, B_compose, B_exec)
cost_mod(π) = cost_cog(π) + cost_exec(π) + cost_iface(π) + cost_couple(π)
voi_mod(π) = VOI_meta_pessimistic(π) - cost_mod(π)
```
- `cost_iface`：序列化、坐标变换、时钟同步、单位转换。
- `cost_couple`：重叠窗口交叉验证、耦合见证生成、双模块并行开销。
- **粒度优化**：选划分 `P` 使 `cost_mod(P)` 最小，约束为「每个组合边可被契约检查」；存在最优粒度 `n*`，过细则 `cost_iface+cost_couple` 主导，过粗则 `cost_local`（单体重认证）主导。
- 任一分量耗尽：`B_local` 尽 ⇒ 复用最近通过验证的模块组合；`B_iface/B_couple` 尽 ⇒ 冻结当前拓扑、禁止热插拔；`B_compose` 尽 ⇒ 退回单体保守链；`B_exec` 尽 ⇒ 原有降级。

**定义 168（模块化安全论证 MSC）** 安全论证树 `T=(N,E)`：
- 根节点：任务级安全声明 `Claim = Safe(task, K_safe, EV-exec)`；
- 内部节点：模块实例 `M_i`；
- 叶节点：模块证据 `E_i`；
- 边 `e=(i,j)`：耦合见证 `W_ij` 与资源账本。
`T` **有效**当且仅当：每个节点局部契约成立、每条边耦合见证通过、`ΣR_i + cost_iface + cost_couple ≤ B_total`、且**无孤立义务**（每个下游假设要么由上游保证建立，要么由环境假设显式建立）。证据 `J_mod = (hash(root), signatures, budget_ledger)`。

### IP-161 MEM（模块与契约执行器）

```python
@dataclass
class Contract:
    assume: Callable[[Stream], bool]
    guarantee: Callable[[Stream], bool]
    alpha: float
    resources: ResourceEnvelope
    degrade: Callable[[Violation], str]

class ExecutionModule:
    def __init__(self, name, ports, contract, evidence_gen, impl):
        self.name, self.ports = name, ports
        self.contract, self.evidence_gen, self.impl = contract, evidence_gen, impl

    def step(self, inputs):
        if not self.contract.assume(inputs):
            v = Violation(module=self.name, kind='assumption', at=time.time())
            self.emit_evidence(v)                  # 违约必须留痕，禁止静默
            return self.contract.degrade(v)
        out = self.impl(inputs)
        assert self.contract.guarantee(out)         # 运行时断言或采样检查
        self.emit_evidence(self.evidence_gen(inputs, out))
        return out
```

### IP-162 CCA（契约合成器）

```python
def compose_sequential(mi, mj, budget):
    if not implies(mi.contract.guarantee_out, mj.contract.assume_in):
        return Incompatible('guarantee_does_not_entail_assumption')
    r = add_resources(mi.contract.resources, mj.contract.resources)
    if not r <= budget:
        return Incompatible('resource_overflow')
    if not schedulable(mi, mj):
        return Incompatible('deadline_infeasible')
    witness = coupling_witness(mi, mj)   # 坐标/时间/单位/采样率 + 重叠交叉验证
    if not witness.valid:
        return Incompatible('coupling_witness_failed', witness)
    return ComposedModule(
        assume=mi.contract.assume_in,
        guarantee=mj.contract.guarantee_out,
        alpha=1 - (1-mi.contract.alpha)*(1-mj.contract.alpha),
        resources=r,
        evidence=EvidenceNode(mi.evidence, mj.evidence, witness))

def substitutes(m_new, m_old):
    return (subset(m_old.assume, m_new.assume)
            and implies(m_new.guarantee, m_old.guarantee)
            and m_new.resources <= m_old.resources)
```

### IP-163 VLM（视觉定位模块）

```python
class VisualLocalizationModule(ExecutionModule):
    def estimate(self, image, calib, imu):
        feats = extract_features(image)
        ok, stats = self.validity(feats, image, calib)
        if not ok:
            return PoseEstimate(pose=None, cov=None, valid=False, stats=stats)

        pnp = solve_pnp_ransac(feats, self.map, calib)
        if pnp.inlier_ratio < self.r_min:
            return PoseEstimate(pose=None, cov=None, valid=False, stats=stats)

        Sigma = self.sigma_scale * pnp.reprojection_cov   # 保守放大
        return PoseEstimate(pose=pnp.pose, cov=Sigma, valid=True, stats=stats)

    def validity(self, feats, image, calib):
        stats = dict(
            n_feat=len(feats),
            rmse=pnp_rmse_estimate(feats, self.map, calib),
            texture=texture_score(image),
            exposure=exposure_level(image),
            blur=blur_metric(image),
            calib_age=time.time() - self.last_calib_time,
            inlier_ratio=self.last_inlier_ratio)
        ok = (stats['n_feat'] >= self.n_min
              and stats['rmse'] <= self.rho_max
              and stats['texture'] >= self.tau_tex
              and self.l_min <= stats['exposure'] <= self.l_max
              and stats['blur'] <= self.b_max
              and stats['calib_age'] <= self.a_max
              and stats['inlier_ratio'] >= self.r_min)
        return ok, stats
```

```python
def certified_hotswap(old, new, consumers, budget):
    if not all(substitutes_in_context(new, old, c) for c in consumers):
        return SAFE_STOP, reason='refinement_violation'
    if not (new.resources <= budget.remaining):
```

```python
def compile_with_visual_geo(eeis, scene_posterior, G, pose, delta_f_req):
    gamma = pose_confidence(pose, G)
    if (not pose.valid) or gamma < tau_vis:
        return eeis.compile_with_scene_prior(scene_posterior, delta_f_req)  # 类别级回退
    g = local_geometry(G, pose.pose)
    dmu = mu_geo(g)                    # 单调：近边缘/大坡度/高曲率 -> K_d↑, v_max↓

    K = intersect_with_base(K, eeis.K_safe_base)
    return K, SceneLocCert(z=scene_posterior.z, x=pose.pose,
                           gamma=gamma, local_geo=g, prior=prior)
```

### IP-167 PCE+++++（模块化预算）

```python
class ModularBudget:
    def __init__(self, local, iface, couple, compose, exec_budget):
        self.B_local, self.B_iface = local, iface
        self.B_couple, self.B_compose = couple, compose
        self.B_exec = exec_budget
        self.used = Counter()

    def feasible(self, tree):
        r = sum(m.resources for m in tree.modules)
        iface = sum(iface_cost(e) for e in tree.edges)
        couple = sum(couple_cost(e, T_overlap) for e in tree.edges)
        return (r + iface + couple <= self.B_exec.total
                and iface <= self.B_iface and couple <= self.B_couple)

    def granularity_cost(self, partition):
        return (self.local_revalidation_cost(partition)
                + self.iface_cost(partition)
                + self.couple_cost(partition))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| MEM | O(1) 契约检查/步 | O(1) | 违约必降级、必留痕 |
| CCA | O(#modules²) 组合检查（可增量缓存） | O(#modules) | 组合根保证成立；α 联合界 |
| VLM | O(n_feat) + PnP O(n_feat³) 最坏 | O(n_feat) | 无静默失败；`P(误差≤ε_vis) ≥ 1-α_vis` |
| LQ-SG | O(k log N) 邻域检索 | O(N+k) | 定位失效时协方差单调膨胀 |

| VGIP | O(1) 先验更新 | O(1) | γ 下降 ⇒ K_safe 只增不减 |
| MSC | O(#nodes+#edges) 建树/校验 | O(#nodes) | 无孤立义务、资源账本一致 |

**正确性定理（模块化可组合安全定理 MCST）**：设 A66–A71 成立：
- **(A66) 契约可靠性**：每个模块 `M_i` 在其 `A_i` 上确实以 `≥1-α_i` 满足 `G_i`。
- **(A67) 视觉有效性可靠上近似**：`V_vis=1 ⇒` 位姿保证成立（无静默失败）。
- **(A68) 耦合见证完备**：`W_ij` 覆盖坐标帧/时间戳/单位/采样率与重叠交叉验证。
- **(A69) 细化序替换性**：`M' ⪯ M` 时，任何依赖 `M` 的下游义务仍被满足。
- **(A70) 资源可加性**：`R_i ⊕ R_j` 是实际资源占用的上界（WCET 可加、带宽不超线性叠加）。
- **(A71) 证据持久性**：热插拔与降级不破坏 `seq_id` 单调性与影子副本完整性。

则：
1. **局部合规 ⇒ 全局合规**：任何良构组合树 `T` 的根保证成立，且 `α_T ≤ Σ_i α_i`（联合界）。
2. **视觉失效不静默**：`V_vis=0` ⇒ 无位姿保证且必触发 CHS 或安全停机。
3. **热插拔证据连续**：`seq_id` 单调、`swap` 事件入链，`EV-exec` 不因换模块丢失。
4. **定位单调保守**：`γ_vis` 下降 ⇒ `Σ_geo` 不减 ⇒ `K_safe` 不缩小；定位失效退回类别级先验。
5. **预算可组合**：`ΣR_i + cost_iface + cost_couple ≤ B_total` ⇒ WCET/带宽/热预算安全。

```python
@dataclass
class Contract:
    assume: Callable[[Stream], bool]
    guarantee: Callable[[Stream], bool]
    alpha: float
    resources: ResourceEnvelope
    degrade: Callable[[Violation], str]

class ExecutionModule:
    def __init__(self, name, ports, contract, evidence_gen, impl):
        self.name, self.ports = name, ports
        self.contract, self.evidence_gen, self.impl = contract, evidence_gen, impl

    def step(self, inputs):
        if not self.contract.assume(inputs):
            v = Violation(module=self.name, kind='assumption', at=time.time())
            self.emit_evidence(v)
            return self.contract.degrade(v)
        out = self.impl(inputs)
        assert self.contract.guarantee(out)
        self.emit_evidence(self.evidence_gen(inputs, out))
        return out
```

### IP-162 CCA（契约合成器）

```python
def compose_sequential(mi, mj, budget):
    if not implies(mi.contract.guarantee_out, mj.contract.assume_in):
        return Incompatible('guarantee_does_not_entail_assumption')
    r = add_resources(mi.contract.resources, mj.contract.resources)
    if not r <= budget:
        return Incompatible('resource_overflow')
    if not schedulable(mi, mj):
        return Incompatible('deadline_infeasible')
    witness = coupling_witness(mi, mj)
    if not witness.valid:
        return Incompatible('coupling_witness_failed', witness)
    return ComposedModule(
        assume=mi.contract.assume_in,
        guarantee=mj.contract.guarantee_out,
        alpha=1 - (1-mi.contract.alpha)*(1-mj.contract.alpha),
        resources=r,
        evidence=EvidenceNode(mi.evidence, mj.evidence, witness))

def substitutes(m_new, m_old):
    return (subset(m_old.assume, m_new.assume)
            and implies(m_new.guarantee, m_old.guarantee)
            and m_new.resources <= m_old.resources)
```

```python
def certified_hotswap(old, new, consumers, budget):

        return SAFE_STOP, reason='refinement_violation'
```

```python
class ModularBudget:
    def __init__(self, local, iface, couple, compose, exec_budget):
        self.B_local, self.B_iface = local, iface
        self.B_couple, self.B_compose = couple, compose
        self.B_exec = exec_budget
        self.used = Counter()

    def feasible(self, tree):
        r = sum(m.resources for m in tree.modules)
        iface = sum(iface_cost(e) for e in tree.edges)
        couple = sum(couple_cost(e, T_overlap) for e in tree.edges)
        return (r + iface + couple <= self.B_exec.total
                and iface <= self.B_iface and couple <= self.B_couple)

    def granularity_cost(self, partition):
        return (self.local_revalidation_cost(partition)
                + self.iface_cost(partition)
                + self.couple_cost(partition))
    # argmin_P granularity_cost(P)，约束：每条组合边可被契约检查
```
