# 第 44 轮 · Intent-Certified Navigation（ICN）：让「意图识别」成为导航证书的一等生产者，让「自主导航」成为意图消歧的安全实验场（四层架构 v9）

> 本会话第 1 轮，承接既有 v20（Persona-Cert × Concurrent-Cert）。v20 已把「用户人格」与「并发推理」纳入证书闭环，但它仍默认了两个单点假设：**(H1) 导航目标是已知的几何 waypoint，意图识别只是 L1/L2 的前端分类器，其错误不进入证书**；**(H2) 导航安全是逐点/局部性质，地图与动态障碍的不确定性可以当作独立同分布噪声**。本轮灵感词「意图识别」「自主导航」正好命中这两点：**意图识别**迫使我们把「去哪里/指的是什么」从标签升级为带覆盖保证的集合值证书；**自主导航**迫使我们把「问路/观察」本身当作必须持证的动作，并用有限时域轨迹证书把局部安全提升为可滚动组合的全局安全。核心新对象是**意图证书树**：在执行任何不可逆动作之前，先走一条对所有存活意图都合法的公共安全走廊，并在走廊内执行**可认证的消歧动作**；一旦意图坍缩为单点，才允许承诺并进入该意图的私有区域。由此得到一条干净的安全界：**系统违反安全约束的概率不超过意图集未覆盖真值的概率 α**——点估计式「先猜后走」则是把 α 换成了分类错误率，且错误率不受证书控制。

## 0. 直觉与动机

**灵感 1（意图识别 → 意图不是标签，而是「允许进入范围」的集合）**：如果机器人把「去门口」误识别成「去另一扇门」，最坏后果不是多走几步，而是进入一个对该用户/该场景而言本不该进入的区域（他人房间、施工区、隐私区）。因此正确的抽象不是「预测一个目标再规划」，而是：识别器输出一个校准的意图集合 Ĥ^α；只要真意图还在集合里，机器人就只走**所有存活意图都允许**的公共安全集 A(Ĥ)=∩_h A_h。误识别只要没有跳出集合，就只影响效率，不影响安全；真正需要防的是**集合没覆盖真值**（OOD、指代歧义、置信度投毒），这才是唯一的安全漏口。

**灵感 2（自主导航 → 最安全的导航有时要主动「问路」，但问路必须持证）**：纯保守策略可以永远待在公共安全集里，却永远到不了目标（可用性崩塌）。要恢复可用性，机器人必须主动收集信息：走到指示牌前、靠近可见的标记、或直接询问用户。关键洞察是：**信息收集动作也是动作**，它可能穿过危险区、可能泄露隐私、可能把某个意图的可能性永久排除。因此不能把「问路」当作免费的规划外操作，而必须像运动动作一样持证：执行后仍处在所有存活意图的允许集内，且不使任何存活意图失去可达性（非排除性），同时带来可证明的信息增益。这样「主动消歧」就从工程启发式升级为**证书树的一条边**。

**灵感 3（耦合 → 轨迹级证书 + 滚动组合，才是长程导航的 sound 边界）**：导航不是一步决策，而是几十秒到几分钟的连续执行；动态障碍、定位漂移、地图更新都会在途中让证书变旧。v20 的租约只解决「测量时刻 vs 使用时刻」的陈旧性，不足以解决「轨迹中段失配」。本轮引入**有限时域轨迹证书**：整条管道 X_t 必须避开地图不确定性的外近似、避开动态障碍可达集；滚动重规划时必须满足**交接包含** X_H^(k) ⊆ X_0^(k+1)，否则降级为安全停/返航。意图不确定性与运动不确定性由此在同一张证书里结算：意图集合决定 A(Ĥ)，轨迹证书决定在 A(Ĥ) 内能否安全到达分支点/目标。

**耦合升级**：ICE（意图证书引擎）把语言/指代/场景图编译成 Ĥ^α 与语义-几何接地证书；CDP（认证消歧规划器）在公共安全核内构造证书树、执行可认证的信息动作并做带滞回的承诺；NCC（导航证书合成器）生成有限时域轨迹证书并保证滚动交接。四层架构由 v8 的「人格契约 + 并发证书」升级为 v9 的「人格契约 + 并发证书 + 意图证书树 + 轨迹证书组合」。

## 1. 形式化定义（增量：定义 44–50）

**定义 44（意图识别证书与语义-几何接地）**：意图空间 H 包含语义目标、指代对象与路线偏好；识别器 R 在观测史 o_{1:t} 上输出集合 Ĥ_t^α ⊆ H，并在校准/可交换性下有 P(h*∈Ĥ_t^α) ≥ 1−α（按命令类型、场景类别、指代表达式做 Mondrian 分层；OOD 用选择性共形/风险控制集触发弃权）。**直觉**：集合覆盖真值，才谈得上「按意图安全」。对每个 h，接地映射输出三元组 γ(h)=(Γ_h^in, Φ_h^over, X_h^free)：Γ_h^in 为目标区域的内近似（到达即可宣告成功），Φ_h^over 为禁止区域的外近似（避开它即安全），X_h^free = X∖Φ_h^over。**非对称近似**是关键：目标内近似只会造成「到了却不敢宣告」的可用性损失，禁止外近似只会造成保守，二者都不破坏 soundness。于是定义单意图允许集 A_h = X∖Φ_h^over，多意图公共允许集 A(Ĥ)=∩_{h∈Ĥ}A_h。

**定义 45（意图鲁棒证书族与公共安全核）**：单意图证书族 C_h(x) 沿用 v20 的几何/人格证书。多意图证书 C(Ĥ)=∩_{h∈Ĥ}C_h；若为空，不存在同时对全部存活意图 sound 的策略。进一步定义**公共安全核** K(Ĥ) 为满足以下三条的最大集合：**(i) 允许性** K⊆A(Ĥ)；**(ii) 受控不变** 存在策略使 K 在 A(Ĥ) 内保持（可等待、可巡逻、可问路）；**(iii) 非排除性** 对每个 h∈Ĥ，K⊆Pre*_{A_h}(Γ_h^in)，即从 K 出发每个意图仍可在其自身允许集内到达。**定理 1（公共核的鲁棒安全）**：若真意图 h*∈Ĥ 且执行状态始终留在 A(Ĥ)，则不会进入 h* 的任何禁止区域。证明：A(Ĥ)⊆A_{h*}。**推论（点估计的静默风险）**：点估计承诺 ĥ≠h* 并进入 A_ĥ∖A(Ĥ) 时，定理 1 的前提被破坏，误识别直接转化为安全违例；这正是「先猜后走」不可接受的原因。

**定义 46（认证消歧动作 / epistemic safety filter）**：动作或短策略 a 在 (x,Ĥ) 上**可认证消歧**，当且仅当：**(S) 安全** 执行 a 的整段状态序列留在 A(Ĥ)（并尽量落到 K(Ĥ)）；**(N) 非排除** 执行后对每个 h∈Ĥ 仍满足 h 可达（不进入 Irr(Ĥ)={x:∃h∈Ĥ, x∉Pre*_{A_h}(Γ_h^in)}）；**(I) 信息** 期望意图熵或期望集合势下降不少于 δ，或以概率 ≥1−β 把 Ĥ 收缩为真子集；**(B) 预算** 路径/时间代价与风险消耗不超过剩余预算。在所有可认证动作中取代价最小者；若无，则退回显式询问用户或安全停/巡逻。**定理 2（消歧不破坏安全且信息单调）**：仅执行定义 46 的动作时，定理 1 的鲁棒安全性保持；且每步期望熵至少下降 δ 时，达到目标熵 ε 的期望信息动作数不超过 H(Ĥ_0)/δ。**注意**：信息增益是期望意义，单次观测可能无信息，因此证书树必须允许「观测无信息」分支继续留在 K 内，而不是强行承诺。

**定义 47（证书树与条件承诺）**：证书树 T 的内部节点为 (x,Ĥ,τ)，标注一个定义 46 的认证消歧动作；边为观测结果；叶节点为承诺意图 ĥ 与一条定义 48 的轨迹证书。**严格承诺**只在 Ĥ={h} 时发生；**宽承诺**仅在「整条轨迹在 A(Ĥ) 内且终点对所有 h∈Ĥ 都可接受」时发生（通常只用于同走廊目标）。承诺策略带滞回：新意图后验需超过当前承诺 δ_margin 且满足可切换证书才允许切换。**定理 3（证书树安全界）**：设 (A1) P(h*∈Ĥ)≥1−α；(A2) 所有消歧动作满足定义 46； (A3) 严格承诺只对单点 Ĥ={h} 执行且叶轨迹避开 Φ_h^over；(A4) 运动/轨迹证书本身无失效。则 P(安全违例) ≤ P(h*∉Ĥ) ≤ α。证明：若 h*∈Ĥ，则承诺前状态在 A(Ĥ)⊆A_{h*}；单点承诺必有 h=h*；承诺后叶轨迹避开 Φ_{h*}^over；故仅当 h*∉Ĥ 时可能违例。**这是本轮最重要的结论：意图不确定性的全部安全代价被压缩成一个可校准的覆盖率 α。**

**定义 48（有限时域轨迹证书与滚动交接）**：给定意图 h、策略 π、时域 H、初始状态集 X_0（定位误差）、地图不确定性 M、动态障碍预测集 O_t，轨迹证书 TC_h=({X_t}_{t=0..H}, S_H) 满足：**(a) 包含性** X_t 包含 π 在扰动 W_t 下的可达集；**(b) 静态安全** X_t∩Φ_h^over=∅（对 M 的所有一致地图变体）；**(c) 动态安全** X_t∩O_t=∅（对所有容许障碍轨迹）；**(d) 终止安全** X_H⊆S_H，S_H 为可安全停/等待的终端不变集。每条证书携带 v20 的租约 (m,τ,λ,κ)，λ 同时覆盖障碍加速度与地图更新率。**滚动交接条件**：第 k 段在 t_k+H 交接给第 k+1 段时要求 X_H^(k)⊆X_0^(k+1)（交接包含），且第 k+1 段在交接时刻有效。**定理 4（滚动组合安全）**：若每段 TC^(k) 在其时域内有效且所有交接满足 X_H^(k)⊆X_0^(k+1)，则拼接轨迹对所有 t 安全。证明：对 k 归纳，实际状态在交接时刻属于 X_H^(k)⊆X_0^(k+1)，被下一段管道覆盖。**工程含义**：重规划延迟、地图更新、障碍预测换模态都不能「悄悄跳过」交接检查；不满足就单调降级为减速→安全停→返航。

**定义 49（意图抖动、承诺滞回与不可逆守卫）**：定义**不可逆守卫**：当 |Ĥ|>1 时，禁止进入 Irr(Ĥ)（进入即意味着某个存活意图被永久排除）。定义**承诺滞回**：从承诺 ĥ 切换到 ĥ' 需同时满足 (i) 后验优势 ≥δ_margin；(ii) 两目标从当前状态均可达且切换路径持证；(iii) 驻留时间 ≥T_dwell。**定理 5（无 Zeno 抖动）**：在固定时域、有限意图集与正 margin δ_margin 下，承诺切换次数不超过信念总变差/δ_margin；不可逆守卫保证不会因反复横跳而永久丢失可达目标。**推论**：滞回把「识别器的概率抖动」隔离在承诺层，不让其直接变成运动层的来回摆动。

**定义 50（意图-运动联合风险预算）**：继承 v20 的人格风险容忍 ε_u，将其显式分解为 ε_u ≥ ε_motion + ε_intent + ε_ground。其中 ε_intent = P(h*∉Ĥ) + P(错误承诺 | h*∈Ĥ)；ε_ground 为接地内外近似失效概率；ε_motion 为轨迹证书/执行失效概率。**风险约束规划**：选择动作最大化期望进度，同时满足各分项预算；认证消歧动作只有在「期望意图风险下降 ΔR_intent(a) ≥ 查询代价风险 + 机会成本」时才被允许。**直觉**：这就是「何时该问、何时该走」的正式判据——问路不是零成本，但当不问导致的错误承诺风险超过查询成本时，问路是风险最优的；反之应保守前进。该判据天然支持按人格（谨慎/赶时间）调节 δ_margin 与询问阈值。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 INTENT-CERTIFICATE-ENGINE（意图证书引擎 ICE）
1. **集合值意图识别**：按命令类型/场景类别/指代表达式做 Mondrian 共形校准，输出 Ĥ^α；对开放词汇与 OOD 命令用选择性共形/风险控制集触发**弃权**而非硬猜。
2. **语义-几何接地证书**：语言/指代 → 场景图 → 目标内近似 Γ_h^in 与禁止外近似 Φ_h^over；歧义指代（两扇门、两个同名物体）自动展开为多个 h，保留在集合中而不是取 argmax。
3. **覆盖监控与信任预算**：在线监控条件覆盖率、OOD 分数、场景漂移；覆盖失效即扩大集合/弃权/降级到公共安全核，并扣减 v20 的信任预算 τ_u。
4. **意图证书发布**：向规划器发布存活意图、A(Ĥ)、K(Ĥ)、Γ/Φ 区域与风险预算；意图变更必须携带覆盖证据与时间戳。

### 2.2 IP-61 CERTIFIED-DISAMBIGUATION-PLANNER（认证消歧规划器 CDP）
1. **公共安全核计算**：在 A(Ĥ) 内做受控不变集 + 各意图可达性回溯，得到 K(Ĥ) 与不可逆集 Irr(Ĥ)；核为空/不连通时立即协商或询问，而不是硬走。
2. **认证信息动作库**：走到观察点、靠近并读取指示、显式询问用户；每个动作先过定义 46 的四条检查，再用值信息（VoI）与风险预算选择。
3. **证书树执行**：维护 (x,Ĥ,τ) 节点、观测分支与承诺叶；无信息分支继续留在 K 内；禁止跳过非排除性检查。
4. **承诺与滞回**：严格承诺只在单点；宽承诺仅在轨迹对全部存活意图合法时；切换需 margin + 驻留 + 可切换证书。
5. **人格与多用户耦合**：询问风格、隐私禁区、风险容忍来自 v20 的 Π_u；多用户冲突意图走 v20 的协商/仲裁，而不是把多个 Ĥ 直接求交后静默放行。

### 2.3 IP-62 NAVIGATION-CERTIFICATE-COMPOSER（导航证书合成器 NCC）
1. **有限时域轨迹证书**：定位/地图/动态障碍不确定性的可达管 X_t、目标内近似、禁止外近似、终端安全集 S_H；意图条件化生成多份 TC_h。
2. **滚动交接与租约**：强制 X_H^(k)⊆X_0^(k+1)；用 v20 租约衰减覆盖障碍加速度与地图更新；过期或交接失败立即降级。
3. **单调降级阶梯**：继续 → 减速 → 改道到 K(Ĥ) → 安全停 → 返航/询问；每一级都保持 A(Ĥ) 与非排除性。
4. **与几何证书/IP-51 的接口**：把 TC_h 与 IP-49 几何证书求交，输出给 CAR 的守卫条件；监控器只读快照（复用 IP-58 的 seqlock/epoch）。

## 3. 四层架构 v9

```
L0: SLAM/LIO + 场景图 + 语言/指代输入 → 地图不确定性 M, 定位 X_0, 指代表达式
L1: IP-60 ICE: 集合值意图识别 Ĥ^α + 语义-几何接地 (Γ^in, Φ^over) + 覆盖监控
    → A(Ĥ)=∩A_h, 各意图可达性回溯
L2: IP-61 CDP: 公共安全核 K(Ĥ) + 不可逆守卫 Irr(Ĥ) + 认证消歧动作/证书树
    → 承诺候选 ĥ / 询问 / 安全停
L3: IP-62 NCC: 意图条件轨迹证书 TC_h + 滚动交接 + 租约新鲜度
```

### IP-60 ICE：集合值意图识别、接地与覆盖监控
```
def intent_certificate(observation_hist, scene_graph, command, alpha):
    stratum = (command.type, scene_graph.category, command.reference_type)
    scores  = calibration_scores[stratum]              # Mondrian 分层
    q       = quantile(scores, 1 - alpha)              # 秩统计阈值
    # 按指代/场景图枚举候选语义意图，而非 argmax
    H_hat = {h for h in enumerate_intents(command, scene_graph)
               if nonconformity(h, observation_hist) <= q}
    if ood_score(command, scene_graph) > tau_ood:
        return Abstain(reason="OOD/uncovered")         # 弃权，不硬猜
    certs = {h: ground_to_regions(h, scene_graph) for h in H_hat}
    # gamma(h) = (Gamma_in, Phi_over): 目标内近似, 禁止外近似
    return IntentCertificate(H_hat, certs, coverage_monitor=stratum)

def ground_to_regions(h, scene_graph):
    referents = resolve_reference(h, scene_graph)      # 可能多个同名/多扇门
    Gamma_in  = inner_approx(union(goal_regions(referents, h)))
    Phi_over  = outer_approx(union(forbidden_regions(referents, h)))
    # 内近似只造成可用性损失；外近似只造成保守 => 两向都不破坏 soundness
    return Grounding(Gamma_in, Phi_over)

def monitor_coverage(cert, h_star, alpha):
    update_conditional_coverage(cert.stratum, h_star in cert.H_hat)
    if conditional_coverage(cert.stratum) < 1 - alpha - tol:
        return CoverageFailure(expand_or_abstain=True)
    return OK()
```

### IP-61 CDP：公共安全核、认证消歧与证书树
```
def build_kernel(H_hat, X, A):
    A_common = intersect_all(A[h] for h in H_hat)      # A(H_hat)
    # 每个意图在其自身允许集内的可达性回溯
    feasible = {h: backward_reachable(A[h], Gamma_in[h]) for h in H_hat}
    K = greatest_controlled_invariant(A_common)        # 可等待/巡逻/问路
    K = K & intersect_all(feasible[h] for h in H_hat)  # 非排除性
    Irr = X \ K                                        # 简化：进入即失去某意图
    return K, Irr

def certified_disambiguate(x, H_hat, K, Irr, budget, persona):
    if len(H_hat) == 1:
        return Commit(next(iter(H_hat)))
    acts = []
    for a in info_actions(x):                          # 观察点/读指示/询问用户
        if not stays_in(a, x, A_common(H_hat)):        # (S) 安全
            continue
        if enters(a, x, Irr):                          # (N) 非排除
            continue
        if expected_info_gain(a, H_hat) < delta:       # (I) 信息
            continue
        if cost(a, persona) > budget:                  # (B) 预算
            continue
        acts.append((cost(a, persona), a))
    if acts:
        return min(acts)[1]                            # 最小代价认证动作
    return AskUser(persona.query_style) if persona.allow_query else SafeStop()

def execute_certificate_tree(root, observations):
    node = root
    while node.is_internal():
        a = node.action
        assert certified(a, node.x, node.H_hat)        # 运行时复核
        obs = execute_and_observe(a)
        node = node.child(obs)                         # 无信息分支仍留在 K
    h = node.committed_intent
    assert len(node.H_hat) == 1 and h in node.H_hat
    return h, node.trajectory_certificate

def commitment_switch(current, candidate, belief, x, margin, dwell):
    if candidate == current or belief[candidate] - belief[current] < margin:
        return current
    if not both_reachable(x, current, candidate):
        return current
    if not switch_path_certified(x, current, candidate):
        return current
    if dwell_time(current) < dwell:
        return current
    return candidate
```

### IP-62 NCC：有限时域轨迹证书与滚动交接
```
def trajectory_certificate(x0, X0, pi, H, h, M, O):
    X = X0
    tube = [X]
    for t in range(H):
        X = reachable_set(X, pi[t], disturbance=W[t])          # (a) 包含性
        if intersects(X, outer_approx(forbidden[h], M)):       # (b) 静态安全
            return Infeasible(t)
        if intersects(X, obstacle_reachable_set(O, t)):        # (c) 动态安全
            return Infeasible(t)
        tube.append(X)
    if not subset(tube[-1], terminal_safe_set(h)):             # (d) 终止安全
        return Infeasible(H)
    lease = sign_lease(margin(x0, h), tau=now(), lam=decay_rate(O, M))
    return TrajectoryCertificate(tube, S_H=terminal_safe_set(h), lease=lease)

def rolling_navigation(x0, H_hat, pi, H, M, O):
    certs = {h: trajectory_certificate(x0, {x0}, pi, H, h, M, O) for h in H_hat}
    k = 0
    while not at_goal():
        # 规划时同时考虑意图集合与轨迹交接
        action = certified_disambiguate(x, H_hat, K=build_kernel(H_hat), ...)
        if isinstance(action, Commit):
            h = action.intent
            cert = trajectory_certificate(x, {x}, pi, H, h, M, O)
            while not done(cert):
                execute_until_handover(cert)
                cert_next = trajectory_certificate(
                    x, handover_set(cert), pi, H, h, M, O)
                if not subset(cert.tube[-1], cert_next.tube[0]):   # 交接包含
                    return degrade("safe_stop")                    # 单调降级
                cert = cert_next
        else:
            execute_certified_info_action(action)
            H_hat = update_intent_set(H_hat)
        k += 1
```

```
def car_guard(e, x, cert_obj, persona, lease, intent_cert, t):
```

回退：E95/E100 覆盖失效 → 关闭严格承诺，只走公共安全核 + 显式询问；E96 成功率不足 → 放宽 α 或增加询问，但绝不降低覆盖；E97 消歧无收益 → 直接询问/安全停；E98 抖动 → 增大 margin/驻留；E99 交接失败 → 缩短时域/提高重规划/安全停；E101 注入失效 → 意图输入隔离 + 人工确认；任何红线失败 → 熔断回退 v20。

## 6. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 开放词汇/OOD 下意图集不覆盖真值，识别器「又错又自信」 | 高 | E95/E100 红线；Mondrian 条件校准；选择性共形弃权；覆盖失效即只走公共核/显式询问 |
| 公共安全核为空或不连通，导致可用性崩塌（原地死锁） | 高 | 空核检测；最小让步协商/询问；多用户走 v20 仲裁；课程加入高歧义场景 |
| 语义-几何接地错误（同名物体、两扇门、指代漂移） | 高 | 内/外近似非对称；场景图多候选保留；E100 审计；错误宣告到达为 0 门槛 |
| 信息收集动作本身穿过危险/隐私区或排除某意图 | 中-高 | 定义 46 四条件运行时复核；不可逆守卫；E97 违例为 0 |
| 轨迹证书对动态障碍预测过于保守导致频繁停车 | 中 | 障碍可达集外近似 + 加速度界；降级阶梯；E99 重规划时延门槛 |
| 滚动交接因重规划延迟/预测换模态而失配 | 中-高 | 强制交接包含；租约衰减；超时安全停；E99 交接违例为 0 |
| 滞回过强导致对真实意图变化响应慢 | 中 | 自适应 margin/驻留；紧急变化走显式确认；E98 抖动与响应时延双指标 |
| 多用户 × 意图歧义：冲突目标被静默求交放行 | 中-高 | 复用 v20 契约协商；空集必询问；E101/E102 审计 |
| 意图识别与导航并发读写下证书撕裂 | 中 | 复用 IP-58 seqlock/epoch 快照；意图证书带 epoch；E99 一致性审计 |

## 7. 本轮最大风险

**一句话**：整套证书树的唯一系统性安全漏口是「真意图不在 Ĥ^α 中」与「语义-几何接地内外近似失效」——在开放词汇、指代歧义与分布外场景下，识别器可能又错又自信，从而把覆盖率 α 悄悄变成实际违例率；因此 E95/E100 必须设为红线，并默认回退到「公共安全核 + 显式询问/安全停机」这条不依赖识别器正确的底线。
