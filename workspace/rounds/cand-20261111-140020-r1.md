# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环新一轮 · 第 1 轮；本轮灵感：「云边协同」×「并发推理」）

> 第 54 轮把技能组合推进为「动作剖面 `α_S` + 组合图 `G_S` + 云边映射 `γ_ce` + 动作-鲁棒性联合证书 `J`」。但 `J` 隐含两个从未被写出的前提：**计划独占执行**、**云端映射在边端提交那一刻仍成立**。本轮把「并发」提升为证书的一等维度。核心矛盾：H22：证书在孤立资源下标定，却在并发负载下执行——动作空间完全兼容，时间有效性却已静默失效；H23：多个并发推理/技能各自可行，联合执行却因动作时域交叠与不可交换而冲突，串行组合的 soundness 不能直接抬升为并发组合的 soundness。

## 0. 直觉与动机

**灵感 1（并发是证书的隐藏前提 → 给证书加「并发包络」）**
直觉：第 54 轮的 `J` 像一张没有座位号的机票——它证明「这个技能能飞」，却没证明「登机时还有你的座位」。并发推理会争抢 GPU/NPU、显存、上下行带宽、执行器总线与实时核。于是每个任务 τ 需要一个 **资源占用剖面 `β_τ(r,t)`**（完全类比动作剖面 `α_S(a)`，只是从「动作空间」换到「资源空间」），系统负载 `L_r(t)=Σ β_τ(r,t)`。证书不再无条件有效，而只在 **并发包络 `𝓛_τ`** 内有效。这把「并发」从工程噪声变成可测量、可签发、可拒绝的证书作用域。

**灵感 2（并发推理的三种时间 → 计划是会过期的预测）**
直觉：一个计划不是关于「现在」的断言，而是关于「执行时状态」的预测。并发带来三种时间：计算推理延迟、云边传输延迟、以及最关键的 **状态陈旧 Δ**。负载越高、队列越长，`Δ` 越大，云端基于快照 `s(t0)` 生成的计划到边端提交时可能已经偏离现实。与其说计划错了，不如说 **证书过期了**。因此每个计划必须携带 **有效性视界 `H_val`**：在置信度 `1-δ` 下，状态漂移不超过 `ε` 的最大执行时长；`Δ+H > H_val` 即必须重新校验或重规划，而不是硬着头皮执行。

**灵感 3（并发的空间冲突 → 时间维动作交叠 + 不可交换性）**
直觉：并发不只是抢 CPU，还会让原本「动作兼容」的技能在 **时间维** 上撞车。抓取与递送各自可行，但若同时占用同一执行器、同一工作空间、同一动作区间，联合执行就会失败。更隐蔽的是 **不可交换性**：`S_i⊗S_j` 与 `S_j⊗S_i` 结果不同（例如「先开门再取物」vs「先取物再开门」）。这把问题变成数据库事务式的判定：决策是事务，执行器/动作空间是共享内存，证书是提交条件。于是定义时间动作交叠 `Ω_ij`、可交换度 `comm_ij` 与干涉量 `I_ij`，要求并发集合要么 **非干涉**，要么存在 **冲突可串行化** 的调度见证。

**灵感 4（并发不只是竞争，还有并行推测的红利）**
直觉：并发推理最大的诱惑不是把机器跑满，而是 **用并行换延迟**——边端同时推测执行 k 条候选微计划，云端结果到达后原子地提交其中一条。这样云边的长延迟被边端并行推测掩盖。但推测必须付得起回滚：只有动作 **可逆**（回滚成本 ≤ τ_rb）且推测分支在动作上 **互斥/可隔离** 时才允许。于是定义 **可逆半径 `r_rev`** 与 **推测深度 `d_spec`**，把并发从纯威胁变成「可计价的延迟隐藏资源」。

**灵感 5（云边协同 = 证书的分布式一致性 → 版本化计划与因果提交）**
直觉：云端与边端同时持有计划的不同版本，若无一致性协议，会出现 **旧证书复活**：云端新计划已撤销某动作，边端仍按旧版本提交。并发下必须给计划打 **版本向量 `ν`**，证书单调收缩（新版本只能撤销、不能默默放宽旧承诺），并用 **证书线性化** 要求：任意两个冲突证书存在与因果序一致的全序。这把第 54 轮的 `Explain` 回传闭环升级为 **因果一致的并发提交闭环**：云规划—边推测—版本校验—原子提交/回滚。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（并发推理剖面 CIP）**
资源空间 `R = R_c × R_e`，`R_c` 为云端 GPU/带宽，`R_e` 为边端 NPU/显存/执行器总线/实时核。推理任务 τ 的资源占用剖面 `β_τ : R × T → [0,1]`，系统负载 `L_r(t) = Σ_{τ∈active(t)} β_τ(r,t)`。并发可行当且仅当 `∀r,t: L_r(t) ≤ 1 - ε_r`，其中 `ε_r` 为预留给安全回路/解释回传的 **硬裕度**。争用延迟 `d_τ(L)` 对每个资源分量单调不降。

**定义 122（负载条件鲁棒性 CLR）**
并发负载下技能 τ 的鲁棒性谱 `ρ_τ(d | L)`，`d ∈ 𝔇_ρ`。其 **并发包络** 为
```
𝓛_τ(ρ_min) = { L : ∀ d∈𝔇_ρ, ρ_τ(d|L) ≥ ρ_min(d) }。
```
若 `ρ_τ(d|·)` 对 `L` 单调不增，则 `𝓛_τ` 是 **下闭集**（降载不会破坏证书）。定义降额因子 `δ_ρ(L) = max_d [ρ_τ(d|0) - ρ_τ(d|L)]`。证书必须写明「在包络内有效」。

**定义 123（状态陈旧与有效性视界 SVH）**
计划 `P` 在 `t0` 基于快照 `s(t0)` 生成，于 `t_c ≥ t0` 提交，执行窗口 `[t_c, t_c+H]`。陈旧度 `Δ = t_c - t0`，沿计划的状态漂移 `e(t) = dist(s(t), ŝ_P(t))`。**有效性视界**
```
H_val(ε,δ) = max{ H : Pr[ sup_{0≤h≤H} e(t_c+h) ≤ ε ] ≥ 1-δ }。
```
计划可执行当且仅当 `Δ + H ≤ H_val(ε,δ)`，且其版本 `ν(P)` 未被因果后继撤销（见定义 125）。

**定义 124（时间动作交叠与干涉）**
技能在时间维上的动作剖面 `α_τ(a,t)`。两并发任务的时间动作交叠
```
Ω_ij = ( ∫_t |A_i(t) ∩ A_j(t)| dt ) / ( ∫_t |A_i(t) ∪ A_j(t)| dt )，
```
可交换度 `comm_ij = 1 - sup_{s} dist(S_j∘S_i(s), S_i∘S_j(s)) / Z`。**并发干涉量**
```
I_ij = w_Ω·Ω_ij + w_c·(1 - comm_ij) + w_ρ·|ρ_i - ρ_j|。
```
若 `I_ij ≤ θ_int` 则称两者 **非干涉**。冲突图 `G_conf = (V, E_conf)`，`E_conf = {(i,j) : I_ij > θ_int}`。并发调度可接受当且仅当 `G_conf` 在重叠时间窗上的诱导子图 **无环**（冲突可串行化），或提供一个满足交换律的 **交换见证**。

**定义 125（证书感知并发契约 CAC）**
并发契约 `K = (Sched, 𝓛, H_val, G_conf, ν, witness)`，其中 `Sched` 给出各任务提交/执行窗口，`ν` 为计划版本向量。**准入** 新任务 τ 当且仅当对所有已准入 τ′：
```
∀r,t: L_r(t) + β_τ(r,t) ≤ 1 - ε_r
∧  H_val^{τ′} ≥ (t_c^{τ′} + H^{τ′} - now)
∧  G_conf 加入 τ 后仍冲突可串行化
∧  J_{τ′} 仍在更新后的包络 𝓛_{τ′} 内
```
否则执行 **降额准入**（收缩动作包络）、**延迟** 或 **回滚**。版本向量要求 `ν` 单调：新版本只能撤销旧动作，不得静默放宽旧证书承诺。

**定义 126（云边并发联合证书 JCC）**
联合并发证书
```
J* = (J, β, 𝓛, H_val, I_set, Sched, ν, evidence)
```
其中 `J = (ρ, A_cert, γ_ce, δ_a, evidence)` 为第 54 轮联合证书。**可部署条件**：`dom_J(T)=in`、`δ_a < Θ_a`、`L ∈ 𝓛`、`Δ+H ≤ H_val`、`max_{i,j} I_ij ≤ θ_int`（或存在串行化见证）、`Sched` 通过执行器语义校验。缺一即不得签发 `J*`。

## 2. 关键算法 伪代码

### IP-121 CIP（Concurrency Inference Profile）

```python
def concurrency_profile(task, resources, trace):
    beta = {}
    for r in resources:
        beta[r] = occupancy_curve(task, r, trace)   # t -> [0,1]
    return beta

def system_load(active_tasks, t, resources):
    return {r: sum(task.beta[r](t) for task in active_tasks) for r in resources}

def load_feasible(active, new_task, t, eps):
    L = system_load(active + [new_task], t, new_task.beta.keys())
    return all(L[r] <= 1.0 - eps[r] for r in L)
```

### IP-122 CLR（Concurrency-Load Robustness）

```python
def build_load_envelope(task, load_grid, dims, rho_min):
    envelope = []
    for L in load_grid:                     # 负载向量
        rho_L = task.robustness_spectrum(dims, load=L)
        if all(rho_L[d] >= rho_min[d] for d in dims):
            envelope.append(L)
    return downward_closure(envelope)       # ρ 对 L 单调不增 => 下闭
```

### IP-123 SVH（Staleness & Validity Horizon）

```python
def estimate_validity_horizon(plan, drift_model, eps, delta, n_boot=200):
    samples = []
    for _ in range(n_boot):
        traj = drift_model.sample(plan)
        samples.append(worst_window(traj, eps))   # 最大漂移<=eps 的时长
    return conformal_quantile(samples, 1 - delta)  # 分布无关覆盖率下界

def plan_temporally_valid(plan, t0, t_commit, H, eps, delta):
    return (t_commit - t0) + H <= plan.H_val[eps][delta] and not plan.superseded
```

### IP-124 CIX（Concurrency Interference eXchange）

```python
def interference(task_i, task_j, w, theta_int):
    omega = temporal_action_overlap(task_i.alpha, task_j.alpha)
    comm  = commutativity(task_i, task_j)
    drho  = abs(task_i.rho - task_j.rho)
    I = w.omega*omega + w.comm*(1-comm) + w.rho*drho
    return I

def build_conflict_graph(tasks, w, theta_int):
    G = nx.Graph()
    for i, j in combinations(tasks, 2):
        if interference(i, j, w, theta_int) > theta_int:
            G.add_edge(i, j, I=interference(i, j, w, theta_int))
    return G

def conflict_serializable(G, windows):
    # 重叠时间窗上的冲突边必须可定向为无环 DAG
    return nx.is_directed_acyclic_graph(orient_by_windows(G, windows))
```

### IP-125 CAC（Certificate-Aware Concurrency Control）

```python
def admit(active, new_task, budgets):
    if not load_feasible(active, new_task, now(), budgets.eps):
        return ('defer', 'load_envelope_exceeded')
    if not plan_temporally_valid(new_task.plan, new_task.t0, now(),
                                 new_task.H, budgets.eps_stale, budgets.delta):
        return ('revalidate', 'stale_plan')
    for t in active:
        if not within_envelope(t, after_adding=new_task, budgets):
            return ('derate', t)          # 收缩动作包络而非直接拒绝
    G = build_conflict_graph(active + [new_task], budgets.w, budgets.theta_int)
    if not conflict_serializable(G, windows_of(active + [new_task])):
        return ('serialize', topological_order(G))
    return ('ok', contract(active + [new_task]))

def speculative_commit(branches, cloud_result, tau_rb):
    # 边端并行推测 k 条互斥分支，云端结果到达后原子提交
    feasible = [b for b in branches if b.rollback_cost <= tau_rb]
    if not feasible:
        return ('abort', 'no_reversible_branch')
    best = argmax(feasible, key=lambda b: match_score(b, cloud_result))
    return ('commit', best, rollback_all_except(best))
```

### IP-126 JCC（Joint Concurrency Certificate）

```python
def joint_concurrency_certificate(skill_seq, plan, active, budgets):
    J = joint_certificate(skill_seq, plan.gamma_ce, budgets)
    if J[0] != 'ok':
        return J
    beta = concurrency_profile(plan, budgets.resources, plan.trace)
    if not load_feasible(active, plan, now(), budgets.eps):
        return ('reject', 'concurrency_envelope')
    H_val = estimate_validity_horizon(plan, budgets.drift, budgets.eps_stale, budgets.delta)
    if (now() - plan.t0) + plan.H > H_val:
        return ('reject', 'expired_plan', H_val)
    G = build_conflict_graph(active + [plan], budgets.w, budgets.theta_int)
    if not conflict_serializable(G, windows_of(active + [plan])):
        return ('reject', 'interference', G)
    return ('ok', JStar(J=J, beta=beta, H_val=H_val, I_set=G.edges(data=True),
                        Sched=plan.schedule, nu=plan.version))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CIP | O(|τ|·|R|·|T|) | O(|R|·|T|) | 剖面采样覆盖、负载可测 |
| CLR | O(|𝓛_grid|·|𝔇_ρ|·|τ|) | O(|𝓛_grid|) | ρ 对 L 单调、包络下闭 |
| SVH | O(N_cal·H) | O(N_cal) | 漂移过程可校准、conformal 覆盖 |
| CIX | O(|τ|²·|A|·|T|) | O(|τ|²) | 交叠/交换估计 sound、无隐藏耦合 |
| CAC | O(|τ| log|τ| + |E_conf|) | O(|τ|+|E_conf|) | 准入不变式、版本单调 |
| JCC | 上述之和 | O(|τ|²) | 五重门控同时成立 |

**正确性定理（Concurrent Cloud-Edge Composition Soundness）**
假设第 54 轮 (A26)–(A28) 成立，并新增：**(A29)** `β_τ` 经在线采样校准，负载测量误差 `≤ ε_L`；**(A30)** 状态漂移过程可校准且 `H_val` 以 `1-δ` 覆盖率 sound；**(A31)** 冲突图覆盖所有经共享执行器/共享状态的成对耦合，无未建模隐藏耦合；**(A32)** 准入与调度严格保持 `L∈𝓛`、版本单调，且推测分支回滚成本 `≤ τ_rb`。

则在一个执行视界内：
```
P_success ≥ 1 - Σ_d (1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
              - P(L∉𝓛) - P(Δ+H>H_val) - P(max I_ij>θ_int)
```
相比第 54 轮，多出 **三个并发失败项**：负载越界、计划过期、干涉越界。关键结论：**并发不是把串行证书乘起来，而是给证书加作用域并让调度器成为证书的联合守门人**；任何时候 `P(L∉𝓛)` 或 `P(max I_ij>θ_int)` 不可忽略，`J*` 都不得签发。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 负载/尾延迟非平稳，`𝓛` 低估最坏情况 | 高 | 硬裕度 `ε_r` + 尾部分位数 + 运行时并发哨兵 |
| 漂移模型漏掉稀有事件，`H_val` 过于乐观 | 高 | conformal 覆盖率 + 漂移触发重校验 + 保守视界 |
| 冲突图不完备（隐藏共享状态耦合） | 高 | 共享资源账本 + 运行时干涉检测 + 悲观串行化 |
| 准入过保守导致利用率/活性下降 | 中 | 降额准入 + 推测执行 + 分级优先级 |
| 推测分支副作用不可逆 | 高 | 可逆半径硬约束 + 提交前动作隔离 + 保守 abort |
| 版本回退引发旧证书复活 | 中 | 版本向量单调 + 因果提交日志 + 撤销屏障 |

## 6. 本轮最大风险

**一句话**：把并发包络、有效性视界与冲突可串行化绑定进 `J*`，能把「单线程证书」升级为「带作用域与调度见证的并发证书」，但其 soundness **同时押在负载/尾延迟模型的保守性、漂移视界的覆盖率、以及冲突图的完备性** 上；一旦尾延迟长尾或共享状态隐藏耦合让「非干涉」判定失真，多个各自持证的并发计划会在真实边端互相拆台并触发连锁回滚，故必须以硬裕度 + 运行时并发哨兵 + 悲观串行化 + 可逆推测四重护栏，宁可降低并发度，也绝不把「并发包络内的局部可行」当作联合可部署的证明。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-Concur（CIP×CLR×SVH×CIX×CAC×JCC）

> 承接第 54 轮产物 v31。本轮把第 54 轮「动作-鲁棒性双证书」升级为 **带并发作用域的云边联合证书体系**，核心是把并发推理的资源占用、状态陈旧、时间动作干涉三维度写入证书，并让调度器成为证书的联合守门人：
> - **CIP（Concurrency Inference Profile）**：任务级资源占用剖面 `β_τ(r,t)`，把「并发」从噪声变成可测资源账本；
> - **CLR（Concurrency-Load Robustness）**：负载条件鲁棒性谱 `ρ_τ(d|L)` 与并发包络 `𝓛_τ`；
> - **SVH（Staleness & Validity Horizon）**：状态陈旧 `Δ` 与有效性视界 `H_val`，计划会过期；
> - **CIX（Concurrency Interference eXchange）**：时间动作交叠 `Ω`、可交换度 `comm`、干涉量 `I` 与冲突图；
> - **CAC（Certificate-Aware Concurrency Control）**：准入控制 + 降额 + 冲突可串行化 + 推测提交；
> - **JCC（Joint Concurrency Certificate）**：`J* = (J, β, 𝓛, H_val, I_set, Sched, ν, evidence)` 联合并发证书。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-117/118/120 以纳入并发作用域与版本一致性。

## 0. 核心 IP 设计

## 2. 关键算法 伪代码

### IP-121 CIP

```python
def concurrency_profile(task, resources, trace):
    beta = {r: occupancy_curve(task, r, trace) for r in resources}
    return beta

def system_load(active, t, resources):
    return {r: sum(task.beta[r](t) for task in active) for r in resources}

def load_feasible(active, new_task, t, eps):
    resources = set(new_task.beta) | {r for s in active for r in s.beta}
    L = system_load(active + [new_task], t, resources)
    return all(L[r] <= 1.0 - eps.get(r, 0.1) for r in L)
```

### IP-122 CLR

```python
def build_load_envelope(task, load_grid, dims, rho_min):
    envelope = []
    for L in load_grid:
        rho_L = task.robustness_spectrum(dims, load=L)
        if all(rho_L[d] >= rho_min[d] for d in dims):
            envelope.append(L)
    return downward_closure(envelope)

def derating(task, L, dims):
    return {d: max(0.0, task.rho0[d] - task.robustness_spectrum(dims, load=L)[d])
            for d in dims}
```

### IP-123 SVH

```python
def estimate_validity_horizon(plan, drift_model, eps, delta, n_boot=200):
    samples = [worst_window(drift_model.sample(plan), eps) for _ in range(n_boot)]
    return conformal_quantile(samples, 1 - delta)

def plan_temporally_valid(plan, t0, t_commit, H, eps, delta):
    fresh = (t_commit - t0) + H <= plan.H_val[(eps, delta)]
    return fresh and not plan.superseded
```

### IP-124 CIX

```python
def interference(task_i, task_j, w):
    omega = temporal_action_overlap(task_i.alpha, task_j.alpha)
    comm  = commutativity(task_i, task_j)
    drho  = spectral_distance(task_i.rho, task_j.rho)
    return w.omega*omega + w.comm*(1-comm) + w.rho*drho

def build_conflict_graph(tasks, w, theta_int):
    G = nx.Graph()
    for i, j in combinations(tasks, 2):
        I = interference(i, j, w)
        if I > theta_int:
            G.add_edge(i, j, I=I)
    return G

def conflict_serializable(G, windows):
    return nx.is_directed_acyclic_graph(orient_by_windows(G, windows))
```

### IP-125 CAC

```python
def admit(active, new_task, budgets):
    if not load_feasible(active, new_task, now(), budgets.eps):
        return ('defer', 'load_envelope_exceeded')
    if not plan_temporally_valid(new_task.plan, new_task.t0, now(),
                                 new_task.H, budgets.eps_stale, budgets.delta):
        return ('revalidate', 'stale_plan')
    for t in active:
        if not within_envelope(t, extra_load=new_task.beta, budgets=budgets):
            return ('derate', t)
    G = build_conflict_graph(active + [new_task], budgets.w, budgets.theta_int)
    if not conflict_serializable(G, windows_of(active + [new_task])):
        return ('serialize', topological_order(G))
    return ('ok', make_contract(active + [new_task]))

def speculative_commit(branches, cloud_result, tau_rb):
    feasible = [b for b in branches if b.rollback_cost <= tau_rb]
    if not feasible:
        return ('abort', 'no_reversible_branch')
    best = max(feasible, key=lambda b: match_score(b, cloud_result))
    rollback_all_except(best)
    return ('commit', best)
```

### IP-126 JCC

```python
def joint_concurrency_certificate(skill_seq, plan, active, budgets):
    J = joint_certificate(skill_seq, plan.gamma_ce, budgets)
    if J[0] != 'ok':
        return J
    beta = concurrency_profile(plan, budgets.resources, plan.trace)
    if not load_feasible(active, plan, now(), budgets.eps):
        return ('reject', 'concurrency_envelope')
    H_val = estimate_validity_horizon(plan, budgets.drift,
                                      budgets.eps_stale, budgets.delta)
    if (now() - plan.t0) + plan.H > H_val:
        return ('reject', 'expired_plan', H_val)
    G = build_conflict_graph(active + [plan], budgets.w, budgets.theta_int)
    if not conflict_serializable(G, windows_of(active + [plan])):
        return ('reject', 'interference', G)
    return ('ok', JStar(J=J, beta=beta, envelope=budgets.L,
                        H_val=H_val, I_set=G.edges(data=True),
                        Sched=plan.schedule, nu=plan.version))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CIP | O(\|τ\|·\|R\|·\|T\|) | O(\|R\|·\|T\|) | 剖面采样覆盖 ≥ 95%、负载可测 |
| CLR | O(\|𝓛_grid\|·\|𝔇_ρ\|·\|τ\|) | O(\|𝓛_grid\|) | ρ 对 L 单调、包络下闭 |
| SVH | O(N_cal·H) | O(N_cal) | conformal 覆盖率 ≥ 1-δ |
| CIX | O(\|τ\|²·\|A\|·\|T\|) | O(\|τ\|²) | 交叠/交换估计 sound、无隐藏耦合 |
| CAC | O(\|τ\| log\|τ\| + \|E_conf\|) | O(\|τ\|+\|E_conf\|) | 准入不变式、版本单调、回滚有界 |
| JCC | 上述之和 | O(\|τ\|²) | 五重门控同时成立 |

**正确性定理（Concurrent Cloud-Edge Composition Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** `β_τ` 在线校准，负载测量误差 `≤ ε_L`；**(A30)** 漂移过程可校准且 `H_val` 以 `1-δ` 覆盖率 sound；**(A31)** 冲突图覆盖所有共享执行器/共享状态的成对耦合；**(A32)** 准入/调度保持 `L∈𝓛` 与版本单调，推测回滚成本 `≤ τ_rb`。
则部署成功概率：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
              - P(L∉𝓛) - P(Δ+H>H_val) - P(max I_ij>θ_int)
```
关键：**动作兼容不再充分**；并发下还需 **资源在包络内、计划在视界内、调度可串行化、版本因果单调**。串行证书的简单相乘会系统性高估并发成功率，因为三个并发失败项在负载升高时正相关放大。

## 6. 本轮最大风险

**一句话**：把并发包络、有效性视界与冲突可串行化绑定进 `J*`，能把「单线程证书」升级为「带作用域与调度见证的并发证书」，但其 soundness **同时押在负载/尾延迟模型的保守性、漂移视界的覆盖率、以及冲突图的完备性** 上；一旦尾延迟长尾或共享状态隐藏耦合让「非干涉」判定失真，多个各自持证的并发计划会在真实边端互相拆台并触发连锁回滚，故必须以硬裕度 + 运行时并发哨兵 + 悲观串行化 + 可逆推测四重护栏，宁可降低并发度，也绝不把「并发包络内的局部可行」当作联合可部署的证明。
