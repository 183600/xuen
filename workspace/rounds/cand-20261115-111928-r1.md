# 第 5 轮（灵感循环第 5 轮；本轮灵感：「机械臂」×「技能组合」）

> **基线**：第 4 轮 InstructGauge-WR（IP-328–333；定义 448–467；引理 59–62；实验 E457–E472）。第 3 轮 InstructGauge、第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架继续继承。
> 本轮纪律：**增量升级 + 严格退化**。技能组合是可选增强层，不是依赖项：技能层不可用 ⇒ 退回 InstructGauge-WR 的分块执行 ⇒ 退回 InstructGauge v3 的指令分块 ⇒ 退回 ToolGauge 的逐步执行。

## 0. 直觉与动机

**灵感 1（机械臂：把物理预算变成一等契约）**
直觉：机械臂不是「一个会输出位姿的策略」，而是一条有可达空间、自由度、负载、刚度、奇异点和接触模式的运动链。对盲区修复来说，真正的问题不是「策略能不能给出一个 Pose」，而是「这个 Pose 是否可达、无碰撞、力有界、并且在整个运动过程中目标物体仍可被认出」。第 4 轮的腕部相机给了局部证据，但机械臂本身给出了**物理预算**：可达半径、关节限位、负载、柔顺性，以及不可逆接触（夹持滑移、表面压痕）。这些预算如果只藏在控制器里，就无法在组合时被检查；所以本轮把它们提升为技能契约的显式字段。

**灵感 2（技能组合：收益在复用，风险在接缝）**
直觉：长程操作不是一条从头学起的巨型策略，而是「伸取 → 对位 → 夹持 → 旋转 → 擦拭 → 放下」这样的技能串。组合带来样本效率、可解释性和验证复用，但它把风险从「单个策略错」转移到「技能之间的接缝」：坐标系同名不同标定、前置条件被上一个技能悄悄破坏、夹爪/工具被占用、接触模式从可逆变成不可逆、误差沿链累积。我的核心判断是：**逐技能安全不等于组合安全；组合安全要求契约在组合下封闭，并且每条接缝都有被见证的物理基准（datum）**。

**灵感 3（耦合：把「技能」当作带类型资源的函数）**
直觉：机械臂技能组合最像程序语言里的函数组合，而不是动作拼接。一个技能消耗一类资源（空闲夹爪、未占用的工作区、某个物体的可抓取面），产生另一类资源（已夹持的物体、已清洁的表面、已测得的法向）。如果类型不对，组合应当在**规划期**被拒绝，而不是在执行期撞了才知道。腕部相机在这里的角色是「接缝见证器」：它不负责判断任务成功，而负责在技能边界上确认「上一个技能声称产生的基准，是否真的在下一个技能所声明的坐标系里存在」。这样，视觉只做局部、可证伪的见证，不承担全局语义；与第 3 轮「语言只改偏好、不改能力」的分层完全同构。

## 1. 研究问题（本轮要回答什么）

- **Q1（接缝安全性）**：逐技能契约满足，能否推出组合契约满足？反例的结构是什么？
- **Q2（权限与可逆性）**：组合是否会放大工具/参数权限？不可逆技能放在链中间时，能否仍用后续回执纠偏？
- **Q3（误差累积）**：组合误差是线性还是指数？重新锚定（re-anchoring）能否把它压回 `O(nε)`？
- **Q4（可退化性）**：技能库 / 接缝见证 / 类型检查任一不可用时，能否逐级退回 v4/v3/v2 且行为等价？

## 2. 四条设计原则（雏形，正式化见产物区定义 468–483）

**P1 契约闭包（Contract Closure）**
技能库 `L` 在组合算子 `⋄` 下封闭（至有界深度 `d`）；每个技能的 `auth` 落在预注册工具/参数包线 `T₀ × A₀` 内；组合只能做并集，不能做扩权。直观：如果语言不能造出新工具（v3 的能力闭包），那么技能组合也不能造出新技能或新权限。

**P2 接缝见证（Seam Witness）**
任何组合边界必须给出 `(F_out → F_in, t_b, T, δ)`，把上一技能的产出基准显式搬运到下一技能的输入坐标系；`δ > ε_frame` 即拒绝组合。直观：装配线上每个工位都要重新对基准，不能假设「上一个工位说合格，这个工位就能直接干」。

**P3 可逆性不放大（Reversibility Non-Amplification）**
`rev(κ₁⋄…⋄κₙ) = max rev(κᵢ)`；`R0`（不可逆）技能不得位于组合内部，只能作为链尾，或以提交屏障隔离。直观：可逆错误的代价可以由下一步回执吸收；不可逆错误一旦发生，后续技能只是在错误状态上继续施工。

**P4 分层退化（Layered Degradation）**
技能层 → v4 分块层 → v3 指令层 → v2 逐步层，每层只增加可选结构，不改变下层 50Hz 主路径。任何一层验证失败都必须能一键退回，绝不让「组合」成为安全必需项。

## 3. 与基线的接口（如何退化）

- 技能库不可用 / 组合证书验证失败 ⇒ 当前技能串退化为 v4 的单技能分块执行；
- 接缝见证不可用（无 TF / 标定过期）⇒ 禁止跨技能组合，强制每技能 `K=1` 并插入人工确认；
- 契约类型检查不可用 ⇒ 退回 v3 的指令条件化分块，只保留单技能；
- 不可逆技能出现在内部 ⇒ 截断为「前缀 + 屏障 + 后缀」，屏障后重新接地；
- 所有增强失效 ⇒ InstructGauge-WR ⇒ InstructGauge v3 ⇒ ToolGauge。

## 4. 预期贡献

1. 一个「接缝见证」口径，把组合安全从「逐技能正确」提升为「逐接缝可检查」；
2. 一个带权限 / 可逆性 / 资源类型的技能契约代数，证明组合不扩权、不隐藏 `R0`；
3. 一个重新锚定的误差累积定理：组合误差 `O(nε)`，并给出无见证时条件数导致指数增长的下界反例；
4. 一条可证伪实验路径 E473–E492，覆盖接缝反例、权限注入、长程实机、退化等价与 50Hz 时序。

## 5. 本轮最大风险

**一句话**：技能组合最危险的失败不是某个技能执行错，而是「所有技能都按各自契约正确执行，但接缝上的物理基准已经悄悄错了」——这类错误在逐技能回执里完全合法，却会被组合链放大成长程、不可逆的物理后果。

# 第 5 轮产物 · 创新点清单 v5：**SkillGauge**（机械臂技能组合门控）

> 背景：第 4 轮 InstructGauge-WR（IP-328–333；定义 448–467；引理 59–62；实验 E457–E472）。
> 本轮灵感：「机械臂」×「技能组合」。
> **继承纪律**：InstructGauge 五不变式、CVC 闭环、腕部相机/ROS 增强、严格退化链全部保留。技能组合层是**可选增强**：任一环节不可用 ⇒ 退回 InstructGauge-WR ⇒ 退回 InstructGauge v3 ⇒ 退回 ToolGauge。
> **状态**：设计稿 + 类型/组合代数 + 伪代码 + 可证伪实验协议。本轮未实机运行，所有数字均为预注册目标，不是实验结果。

## 0. 核心 IP 设计

直觉先行：单个技能的安全性，解决的是「这个动作在它自己的输入条件下是否安全」；而长程操作的安全性，解决的是「上一个技能说它留下了什么，下一个技能是否真的在同一个物理基准上接手」。后者不是前者的推论，必须单独设计。SkillGauge 因此把「技能」当作带类型资源的函数，把「组合」当作一次带见证的类型检查。

| 编号 | 名称 | 类型 | 关键改进（相对 InstructGauge-WR） |
|---|---|---|---|
| IP-334 | SkillContract 技能契约类型系统 | 核心模块 | 把可达性、负载、柔顺、权限、可逆性写成可检查字段；`Pre/Post` 一律带坐标系 |
| IP-335 | FrameBus 接缝坐标系总线 | 核心模块 | 在技能边界搬运并见证 datum；拒绝同名异标定与过期 TF |
| IP-336 | CompCert 组合证书 | 核心模块 | 逐接缝见证 + 逐技能回执 + 蕴含证明 + 权限审计，可独立重放 |
| IP-337 | Reversibility-Algebra 可逆性代数 | 核心模块 | `R0/R1/R2` 单调；`R0` 位于内部即被提交屏障切断 |
| IP-338 | SkillClosure 契约闭包库 | 核心模块 | 有界深度组合搜索 + 健全剪枝；越权技能直接出局 |
| IP-339 | SC-7C 闭环 | 设计模式 | S→C→W→E→B→V→U：选择技能、检查契约、见证接缝、执行、屏障、验证、更新 |
| IP-340 | SkillGauge 主闭环 | 集成 | 技能规划异步执行；50Hz 主路径不变；任一层失败自动退回 v4/v3/v2 |

**退化链声明**：技能库失效 ⇒ v4 单技能分块；FrameBus 失效 ⇒ 禁止跨技能组合、每技能 `K=1` + 人工确认；CompCert 验证失败 ⇒ 只执行已验证前缀；契约检查失效 ⇒ v3 单技能指令分块；所有增强失效 ⇒ InstructGauge-WR ⇒ InstructGauge v3 ⇒ ToolGauge。

| `σ = (x, o, T)` | 框架化状态：物理量、对象身份、坐标系注册表 |

| `Eff_κ` | 效果签名（资源与对象状态的类型化变化） |
| `rev_κ ∈ {R0,R1,R2}` | 可逆性等级：`R0` 不可逆、`R1` 可回滚、`R2` 平凡可逆 |
| `auth_κ ⊆ T₀×A₀` | 工具与参数包线权限 |
| `ρ_κ` | 资源向量（时间、能量、工作区、负载、夹持占用） |
| `r_κ` | 技能执行回执 |
| `W(κ₁,κ₂)` | 接缝见证（frame witness） |

| `ε_frame` | 接缝残差阈值（预注册，默认 2 mm / 1°） |
| `L_d` | 深度 `d` 的契约闭包技能库 |
| `Rec(seq)` | 组合序列的可恢复前缀 |
| `⊥` | 组合被拒绝 |

## 2. 形式化定义

**定义 468（框架化状态与框架限定谓词）**
```
σ = (x, o, {T_{F→B}(t) ∈ SE(3)}_{F∈𝔽})
φ = (F_φ, φ_body),   F_φ ∈ 𝔽,   φ_body ⊆ Σ
```
谓词只在声明坐标系 `F_φ` 上求值；把谓词搬到另一坐标系必须提供已注册的 TF 与时间戳，且残差不超过 `ε_frame`。这避免「同名坐标系」被当成同一个物理基准。

**定义 469（技能契约）**
```
κ = (π_κ, In_κ, Out_κ, Pre_κ, Post_κ, Eff_κ, rev_κ, auth_κ, ρ_κ)
```
其中：`π_κ` 是闭环控制器，内部可以调用第 4 轮的 InstructGauge-WR 分块执行器；`Pre_κ/Post_κ` 是定义 468 意义下的框架限定谓词；`Eff_κ` 是类型化效果签名，例如 `gripper: free ↦ holding(o)`、`surface: coated ↦ inspected`；`rev_κ` 是定义 476 的可逆性等级；`auth_κ` 是 `(工具, 参数区间)` 的集合；`ρ_κ` 是定义 477 的资源向量。直觉：技能不是「一段轨迹」，而是「带前置条件、后置条件、副作用、权限与可逆性标签的可复用程序」。

**定义 470（技能执行回执）**
```
r_κ = (κ, id, σ_in, σ_out, τ, u, sat, cert_int)
```
`σ_in/σ_out` 是执行前后状态，`τ` 是时间戳，`u` 是命令轨迹哈希，`sat` 是定义 471 的契约满足判定，`cert_int` 是内部安全证书（继承 v4 的 SpatialCert / CVC）。回执只证明「该技能在自己的输入条件下按契约执行」，不证明接缝正确。

**定义 471（契约满足）**
```
κ ⊨_σ (Pre_κ, Post_κ) ⇔
    Pre_κ(σ)
  ∧ σ' = exec(π_κ, σ)
  ∧ Post_κ(σ')
  ∧ Eff_κ(σ, σ')
  ∧ Safe_int(π_κ, σ, σ')
```
`Safe_int` 是技能内部的安全不变式（碰撞、关节限位、力上限、v4 时空一致性）。

**定义 472（接缝见证）**
```
W(κ₁,κ₂) = (F₁ = Out_{κ₁}, F₂ = In_{κ₂}, t_b,
            T_{F₁→F₂}(t_b), δ, σ_b, r_{κ₁}, r_{κ₂})
δ = ||T_{F₁→F₂}(t_b) − T̂_{F₁→F₂}(t_b)||_Σ  ≤  ε_frame
```
有效见证要求：两条回执均通过验证；`σ_b` 在边界上实测到 `κ₁` 声称的产出基准；`δ ≤ ε_frame`。直觉：见证不是「再拍一张图」，而是把「上一个技能留下的物理 datum」和「下一个技能假设的 datum」放到同一个坐标系里做可证伪的比对。

**定义 473（可组合与组合契约）**
```
κ₁ ⋄ κ₂ 有定义 ⇔
  (i)   Valid(W(κ₁,κ₂))
  (ii)  Post_{κ₁} ⊨_W Pre_{κ₂}
  (iii) ρ_{κ₁} + ρ_{κ₂} ≤ B
  (iv)  auth_{κ₁} ∪ auth_{κ₂} ⊆ T₀ × A₀
  (v)   rev_{κ₁} = R0 ⇒ κ₂ 位于提交屏障之后的新段

Pre_{κ₁⋄κ₂}  = Pre_{κ₁}
Post_{κ₁⋄κ₂} = Post_{κ₂}
Eff_{κ₁⋄κ₂}  = Eff_{κ₂} ∘ Eff_{κ₁}
rev_{κ₁⋄κ₂}  = max(rev_{κ₁}, rev_{κ₂})
auth_{κ₁⋄κ₂} = auth_{κ₁} ∪ auth_{κ₂}
ρ_{κ₁⋄κ₂}    = ρ_{κ₁} + ρ_{κ₂}
```
`⊨_W` 表示「在见证 `W` 把 `κ₁` 的输出状态搬到 `κ₂` 输入坐标系之后，`Post_{κ₁}` 蕴含 `Pre_{κ₂}`」。任一条不满足，组合为 `⊥`，不得执行。

**定义 474（组合证书）**
```
CompCert(seq) = (⟨r_i⟩, ⟨W_i⟩, ⟨π_i : Post_i ⊨_{W_i} Pre_{i+1}⟩,
                 auth_audit, rev_trace, cost)

Verify(CompCert) =
  ∧_i Verify(r_i)
  ∧ ∧_i Valid(W_i)
  ∧ ∧_i Implies(Post_i, W_i.pull(Pre_{i+1}))
  ∧ auth_audit(seq) ⊆ T₀ × A₀
  ∧ RevBarrier(seq)
```
`CompCert` 是有限、可独立重放的检查对象：它不要求检查者相信规划器，只要求重放每条回执、每个见证和每个蕴含。

**定义 475（契约闭包技能库）**
```
L₀ = L
L_{d+1} = L_d ∪ { κ₁⋄κ₂ : κ₁,κ₂ ∈ L_d, κ₁⋄κ₂ 有定义 }
L*_d = { κ ∈ L_d : auth(κ) ⊆ T₀ × A₀ }
```
组合搜索只在 `L*_d` 上进行。直觉：技能库不是「什么都能拼」，而是「在预注册技能与有界深度内闭合」；这条把 v3 的能力闭包从「语言不能造新工具」提升为「组合不能造新技能」。

**定义 476（可逆性代数与可恢复前缀）**
```
R0 ≻ R1 ≻ R2
rev(κ₁⋄…⋄κₙ) = max_i rev(κ_i)
Rec(seq) = 最长的前缀 κ₁…κ_j，使 rev(κ₁⋄…⋄κ_j) ≤ R1
```
`R0`（材料去除、热灼烧、不可逆夹持滑移）一旦出现在位置 `i`，`Rec(seq)` 到 `i−1` 为止；位置 `i` 之后必须插入提交屏障并重新接地。直觉：可逆性不是「风险分数」，而是「错误能否被后续回执吸收」的结构性质。

**定义 477（权限、参数与资源不放大）**
```
auth(seq) = ∪_i auth(κ_i)
A(seq)    = ∪_i A(κ_i)
ρ(seq)    = Σ_i ρ(κ_i)
```
要求 `auth(seq) ⊆ T₀ × A₀` 且 `ρ(seq) ≤ B`，否则 `seq = ⊥`。特别地，夹持资源是线性资源：若 `κ_{i+1}` 要求 `gripper = free`，则 `Eff_i` 必须显式释放夹爪，或 `κ_{i+1}` 继续在同一 `holding(o)` 资源上操作。

**定义 478（接缝误差与重新锚定）**
```
E(κ₁⋄…⋄κₙ) ≤ Σ_i E(κ_i) + Σ_i δ(W_i) + Σ_i E_reanchor,i
```
理想重新锚定下 `E_reanchor,i = 0`。若不重新锚定，则误差递推为
```
E_{i+1} ≤ cond(T_i) · E_i + e_i
```
其中 `cond(T_i)` 是坐标系变换的条件数。直觉：接缝见证不只是「检查」，它还是一次重新锚定；没有它，误差按条件数几何增长；有它，误差按 `O(nε)` 线性增长。

**定义 479（技能选择目标）**
```
Feasible(σ) = { seq ∈ L*_d : Verify(CompCert(seq)) = 1, cost(seq) ≤ B }
seq* = argmax_{seq ∈ Feasible(σ)} U(seq | ι)
```
`ι` 是第 3 轮的指令规格，只进入效用 `U` 的权重与排序，**不进入可行集**。因此指令可以让某个安全技能串更受偏好，但不能让不安全技能串变得可行。

**定义 480（任务级安全不变式）**
```
Safe(seq, σ₀) ⇔ ∀i:
    Pre_i(σ_{i−1})
  ∧ Post_i(σ_i)
  ∧ Eff_i(σ_{i−1}, σ_i)
  ∧ auth_i ⊆ T₀ × A₀
  ∧ RevBarrier(seq, i)
```
这是 SkillGauge 要证的组合级不变式；它不是 v4 单技能不变式的简单合取。

**定义 481（退化算子）**
```
D(skill_lib ↓)      = InstructGauge-WR
D(frame_bus ↓)      = 禁止跨技能组合；每技能 K=1 + 人工确认
D(comp_checker ↓)   = v3 单技能指令分块
D(primitive_only)   = ToolGauge 逐步执行
D(all ↓)            = MODGAUGE
```
退化必须是**行为可解释**的：不是「关掉功能」，而是「换成一个已知安全的下层执行器」。

**定义 482（坐标系别名）**
```
Alias(F,G) ⇔ name(F) = name(G) ∧
             ( calib_id(F) ≠ calib_id(G)
               ∨ ||T_{F→G}||_Σ > ε_frame )
```
同名不同标定的两个坐标系是组合层最隐蔽的攻击面；`Alias` 为真时禁止把 `F` 的谓词搬到 `G`。

**定义 483（接缝资源一致性）**
```
GripConsistent(κ_i, κ_{i+1}) ⇔
    required(κ_{i+1}).gripper = free
      ⇒ release(Eff_i) ∨ continue_holding(κ_i, κ_{i+1})
```
这条把「上一个技能还夹着物体、下一个技能却假设夹爪空闲」这类资源泄漏挡在规划期。

## 3. 关键算法骨架

```python
R0, R1, R2 = 0, 1, 2
EPS_FRAME = 2e-3          # 预注册接缝残差，单位 m

class SkillContract:
    def __init__(self, name, policy, in_frame, out_frame,
                 pre, post, eff, rev, auth, rho):
        self.name = name
        self.policy = policy
        self.in_frame = in_frame
        self.out_frame = out_frame
        self.pre = pre
        self.post = post
        self.eff = eff
        self.rev = rev
        self.auth = auth
        self.rho = rho

def compose(k1, k2, state, framebus, T0, A0):
    # (iv) 权限与参数不放大
    if not (k1.auth | k2.auth) <= (T0 | A0):
        return None
    # (i) 接缝见证
    W = framebus.witness(k1.out_frame, k2.in_frame, state)
    if W is None or W.delta > EPS_FRAME:
        return None
    # (ii) 类型检查：Post1 在 W 下蕴含 Pre2
    if not implies(k1.post, W.pull(k2.pre)):
        return None
    # (iii) 资源与夹持一致性
    if not resources_ok(k1.rho, k2.rho, state):
        return None
    if not GripConsistent(k1, k2):
        return None
    # (v) 可逆性屏障
    if k1.rev == R0 and not k2.starts_after_commit_barrier:
        return None
    return CompositeSkill(k1, k2, W)

def plan_skill_sequence(M, iota, state, depth=3):
    best = None
    for seq in M.skill_lib.enumerate_closed(depth):
        if not M.comp_checker.precheck(seq, state):
            continue
        if seq.cost > M.budget_left(state):
            continue
        # iota 只改排序，不改可行集
        score = M.selector.score(seq, iota)
        best = max(best, (score, seq))
    return None if best is None else best[1]

def execute_skill_sequence(M, seq):
    certs = []
    for i, kappa in enumerate(seq):
        # 接缝见证：i > 0 时把上一技能的输出基准搬到本技能输入坐标系
        if i > 0:
            W = M.framebus.witness(seq[i - 1].out_frame,
                                   kappa.in_frame, M.state)
            if not M.comp_checker.boundary_valid(W):
                if M.reversibility.recoverable(seq[:i]):
                    return M.rollback(seq[:i])
                return M.halt_and_ask(seq[:i])
            certs.append(W)

        # 单技能仍走 v4 的运动学可采纳性检查
        if not M.kloop.admissible(kappa, M.state):
            return M.degrade_to_v4(seq[i:])

        r = M.executor.run(kappa)       # 内部调用 InstructGauge-WR
        certs.append(r)

        # 不可逆技能：提交屏障 + 重新接地
        if kappa.rev == R0:
            M.commit_barrier()
            M.reground()

    return CompCert(certs)

def SkillGauge_round(M, obs, audio, tac, depth, det, ell=None):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s)
            seq = plan_skill_sequence(M, ell, M.state, depth)
            if seq is not None:
                spawn_async(execute_skill_sequence, M, seq)
            else:
                # 无可用技能串：退回 v4 指令分块
                spawn_async(instructgauge_wr, M, s, ell)
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 4. 手工反例：逐技能安全为何不等于组合安全

| 失败模式 | 逐技能检查 | 组合层检查 | 最小反例 |
|---|---|---|---|
| 坐标系同名异标定 | 两个技能各自都过 | `FrameBus` 的 `Alias` / `δ` 拒绝 | `cam_A` 与 `cam_B` 同名，标定相差 5 mm / 1° |
| 隐藏前置条件 | `κ₁` 的后置只保证「物体在视野内」 | `Post₁ ⊨_W Pre₂` 失败 | `κ₂` 需要「物体在夹爪坐标系内」，`κ₁` 只给了相机坐标系 |
| 夹持资源泄漏 | 两技能各自都过 | `GripConsistent` 失败 | `κ₁` 夹着物体，`κ₂` 假设夹爪空闲 |
| 权限放大 | 单技能都在包线内 | `auth` 并集越出 `T₀×A₀` | `κ₂` 请求未注册的加热工具 |
| 不可逆技能在内部 | 单技能安全 | `RevBarrier` 拒绝或切断 | `R0` 擦拭之后继续用回执纠偏 |
| 误差指数累积 | 每个接缝都「差不多」 | 无重新锚定时 `cond(T)>1` | 两坐标系反复往返，误差按 `c^{n−1}` 放大 |

## 5. 推导

**引理 63（组合可靠性）**
若 `κ₁ ⊨ (Pre₁,Post₁)`、`κ₂ ⊨ (Pre₂,Post₂)`、`W(κ₁,κ₂)` 有效且 `Post₁ ⊨_W Pre₂`，则 `κ₁⋄κ₂ ⊨ (Pre₁,Post₂)`（在 `ε_frame`-Lipschitz 意义下，`Post₂` 允许 `2ε_frame` 的边界容差）。
证明：设 `σ₀ ⊨ Pre₁`。由 `κ₁` 的契约满足，执行后 `σ₁ ⊨ Post₁` 且 `Eff₁(σ₀,σ₁)`。见证 `W` 把 `σ₁` 搬到 `κ₂` 的输入坐标系得到 `σ₁'`，且 `||σ₁'−σ₁|| ≤ δ ≤ ε_frame`。由 `Post₁ ⊨_W Pre₂` 得 `Pre₂(σ₁')`；谓词 `ε_frame`-Lipschitz 给出 `Pre₂(σ₁)` 在 `2ε_frame` 容差内成立。执行 `κ₂` 得 `σ₂ ⊨ Post₂`，效果签名复合为 `Eff₂∘Eff₁`。内部安全由 `Safe_int` 逐段保证。故组合契约成立。∎

**引理 64（接缝见证的必要性）**
存在两个技能，各自满足契约，但其朴素组合不安全；因此「逐技能回执 + 后置/前置文本相同」不足以推出组合安全，接缝见证是必要的。
证明（反例）：设 `κ₁` 在 `cam_A` 中产生谓词 `grasp_ok`，`κ₂` 在 `cam_B` 中检查 `grasp_ok`；两个坐标系名字都为 `cam`，但标定相差 `δ > ε_frame`。单独看，`κ₁` 的后置与 `κ₂` 的前置字符串相同，各自都通过检查；但在真实物理状态中，`κ₂` 检查的是另一个基准，组合可能在实际未夹稳时继续运动。任何只检查回执、不检查 `F₁→F₂` 变换的验证器都无法区分安全与不安全组合。因此必须显式给出 `W` 并检查 `δ`。∎

**引理 65（权限不放大）**
若 `L*_d` 中每个技能满足 `auth_κ ⊆ T₀×A₀`，则任意有限组合 `seq ∈ L*_d` 满足 `auth(seq) ⊆ T₀×A₀`。
证明：对组合树归纳。叶子由假设成立；内部节点 `auth(κ₁⋄κ₂)=auth(κ₁)∪auth(κ₂)`，两个子集都含于 `T₀×A₀`，并集仍含于 `T₀×A₀`。若任一子节点越权，定义 473(iv) 使组合为 `⊥`。故不存在通过组合「借道」获得新工具或新参数区间的序列。∎

**引理 66（可逆性单调与屏障必要性）**
`rev(κ₁⋄…⋄κₙ) = max_i rev(κ_i)`；若 `R0` 技能位于内部，则 `Rec(seq)` 截止于其前一位，位置 `i` 之后的回执不能把已发生的不可逆效果撤销。
证明：`rev` 的 `max` 由定义 473 直接给出。设 `κ_i` 为 `R0`，其效果 `Eff_i` 在物理状态空间上没有逆映射；后续技能 `κ_{i+1}…` 的输入状态已经包含该不可逆效果，任何后续回执只能验证「在已改变的状态上继续是否正确」，不能恢复 `σ_{i−1}`。因此可恢复前缀不可能越过 `i`。把 `R0` 放到链尾或用提交屏障隔离，是使 `Rec(seq)` 覆盖整个前缀的充要结构条件。∎

**引理 67（重新锚定把误差压回线性）**
在每个接缝执行定义 472 的重新锚定后，
```
E(κ₁⋄…⋄κₙ) ≤ Σ_i E(κ_i) + Σ_i δ(W_i) ≤ n(ε_skill + ε_frame) = O(nε)。
```
若不做重新锚定，存在组合使 `E_n ≥ c^{n−1}E_1`（`c = cond(T) > 1`），即误差可指数增长。
证明：有锚定时对 `n` 归纳：`E_n ≤ E_{n−1} + E_n^skill + δ_n`，展开即得线性界。无锚定时，构造两个坐标系 `F↔G` 的往返链，每次变换的条件数为 `c>1`，误差按 `E_{i+1} ≥ cE_i − e_i` 递推，取 `e_i→0` 得 `c^{n−1}E_1` 的下界。故「见证」不仅是安全检查，也是误差控制的结构手段。∎

**引理 68（组合证书的可审计性）**
`Verify(CompCert)=1 ⇒ Safe(seq,σ₀)`。且验证是局部的：每个 `r_i`、`W_i`、蕴含证明可独立重放，不需要信任规划器或技能库。
证明：由引理 63 得逐段契约成立；由引理 65 得权限不放大；由引理 66 得 `R0` 屏障成立；由定义 480 逐项合取即 `Safe`。验证过程只读取有限证书字段，故可独立重放。∎

**引理 69（组合搜索的健全剪枝）**
若不存在 `W` 使 `Post_i ⊨_W Pre_{i+1}`，则任何包含该相邻对的组合都不满足定义 473(ii)，应被剪枝。该剪枝是健全的，但可能不完备：蕴含检查是充分条件，谓词可弱化时可能存在更强见证使组合安全。
证明：定义 473(ii) 是组合有定义的必要条件；不存在见证则组合必为 `⊥`，故剪枝不丢失任何安全组合。反向不成立：若 `Post_i` 比 `Pre_{i+1}` 所需更强，可能存在另一种状态抽象使蕴含成立，因此剪枝是保守的。∎

**引理 70（指令不扩可行域）**
对任意指令 `ι`，`Feasible(σ)` 与 `ι` 无关；`ι` 只改变 `U(seq|ι)` 的排序。因此被选中的 `seq*` 必满足 `Verify(CompCert)=1`。
证明：由定义 479，`Feasible` 的定义中不出现 `ι`；`seq*` 只在 `Feasible` 内取 `argmax`。故 `ι` 不能把一个不可行序列变成可行。∎

**引理 71（退化等价）**
当技能库只含「单动作技能」时，SkillGauge 的组合执行逐字退化为 v4 的分块执行；当 `FrameBus` 不可用时，`D` 强制每技能 `K=1` 并插入人工确认，行为等价于 v3 的单技能分块；当技能层整体不可用时，退回 v4；全部不可用时退回 ToolGauge。
证明：单动作技能的 `Pre/Post` 是单步契约，接缝见证退化为恒等变换（`δ=0`），组合序列即 v4 的动作块序列；`K=1` 时块长为一，v4 的分块执行退化为逐步执行；逐层替换保持每步的状态转移与安全检查一致，故行为等价。∎

## 6. 复杂度分析

| 组件 | 域 | 时间 | 空间 | 正确性锚 |
|---|---|---|---|---|
| SkillContract 类型检查 | 契约 | `O(|φ|)` | `O(|φ|)` | 定义 469/471 |
| FrameBus 接缝见证 | 感知 | `O(1)` TF lookup + `O(|σ|)` | `O(1)` | 定义 472 |
| CompCert 预检查 | 组合 | `O(n·|φ|)` | `O(n)` | 定义 473/474 |
| 契约闭包枚举 | 规划 | 最坏 `O(|L|^d)`，默认 `d≤3`，带健全剪枝 | `O(|L|^d)` 最坏 | 定义 475/引理 69 |
| 可逆性审计 | 组合 | `O(n)` | `O(1)` | 定义 476 |
| 技能执行 | 控制 | 继承 v4，主路径 `< 20 ms` | 继承 v4 | 引理 71 |

最坏情况说明：一般技能序列规划是 NP-hard 的；SkillGauge 不声称解决一般规划，而是把搜索限制在**预注册、契约闭包、有界深度** `d` 上。若 `d` 或 `|L|` 超预算，规划器超时即退回 v4 单技能分块，绝不执行未验证的序列。

## 9. 本轮最大风险

**一句话**：SkillGauge 的真正薄弱点不是技能契约本身，而是**接缝见证所依赖的标定与 TF 新鲜度**——一旦同名坐标系被错误地视为同一基准，组合证书会把「所有技能都正确」误判为「整条链安全」，而这类错误恰好会在长程、不可逆的机械臂任务里被放大成物理后果。
