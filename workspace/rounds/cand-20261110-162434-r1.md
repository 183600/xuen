# 第 44 轮（新循环第 4 轮） · Competitive-Cert × General-Purpose-Transfer：把「竞品分析」变成可证的泛化差分，把「通用机器人」变成可证的证书迁移（四层架构 v9）

> 承接第 43 轮 v20（Persona × Concurrent）。v20 自陈最大风险是「共形只保边际覆盖，按人格的条件覆盖会被欺骗」。本轮灵感词「竞品分析」「通用机器人」把这条风险从**交互维度**推到**能力维度**：宣称一台机器人"通用"，本质是在声称证书在能力流形 (任务 × 本体 × 环境 × 人格) 上**既 sound 又非空**；而"竞品分析"若只比平均成功率，就会用幸存者偏差掩盖竞品**未被证明**的安全域。于是本轮做两件事：**(1)** 把竞品从"营销对照"升级为**差分见证 oracle**——竞品做到而我做不到 = 非空性缺口；我被**证明**安全而竞品出现实测违例 = 安全优势（且必须统计检验，因为竞品的 soundness 不可观测）；**(2)** 把"通用"从形容词升级为**可证的认证泛化指数 CGI** 与**证书迁移同态**，使证书能跨本体迁移、跨任务组合闭合。核心危险也随之上移：**基准覆盖 ≠ 部署分布覆盖**——这正是第 43 轮"边际 ≠ 条件"在元层面的重演。

## 0. 直觉与动机

**灵感 1（竞品分析 = 自然实验，不是打分表）**：直觉上我们习惯说"竞品 A 成功率 72%，我们 68%，所以落后"。这是**错的度量**：成功率把"侥幸成功"与"被证安全地成功"混为一谈，也把"我们根本不敢做因此记为失败"与"做了但不安全"混为一谈。正确直觉是——竞品是**免费的自然实验**：它在某能力点 m 上跑通了，就证明了该点**存在可行策略**（对我们是一个非空性缺口，告诉我们证书域漏了一块）；它出现违例，则给了我们一个**反例点**（正面加固安全谓词）。一句话：**竞品告诉我们"地图哪里还有路"，但不告诉我们"那条路安全"**。

**灵感 2（通用机器人 = 可迁移 + 可组合的证书，不是"啥都能做"）**：直觉上"通用"像是一个无限能力的承诺，无法证伪。我们把它还原为两个**可证**的性质：**(a) 跨本体可迁移**——在一台机器人上得到的证书，借助仿真关系（simulation relation）与有界失真，能搬到另一台本体，并给出边际惩罚；**(b) 跨任务可组合**——单任务 sound 的证书在任务复合 T1∘T2 下仍 sound，否则存在"组合泛化缺口"。通用性 = **广度（CGI）× 深度（组合闭合）**，二者缺一不可：一个能独立做一百个任务却一组合就崩的系统，不叫通用。

**灵感 3（耦合 = 竞品驱动的泛化飞轮）**：CGI 定义"测什么"，迁移同态定义"证书怎么搬"，竞品主动课程定义"用最少预算把证书域长到哪"。三者闭环：**跑基准 → 挖差分见证 → 定位缺口 → 仿真/迁移生成反例与正例 → 回灌 CKB/SCV → 重估 CGI → 再跑基准**。这把 v20 的"仿真-检索-边缘"飞轮，外接了一个**元层（meta）泛化飞轮**，且每一圈都消耗显式的**泛化预算 Γ**（仿真算力、实机时长、认证工时），不再假装"通用"是免费的。

**为什么不能直接抄竞品策略**：竞品跑通只提供"存在性见证"，其成功轨迹可能踩在未被证明的安全边界上。抄策略 = 继承对方**未证明的失效模式**。因此竞品只用于**定位缺口**与**提供反例/正例**，绝不作为安全证书的来源。

## 1. 形式化定义（增量：定义 44–50）

**定义 44（能力流形与证书域）**：能力流形 M = T × E × W × U，分别为任务、本体、环境、交互人格；μ 为真实部署分布。证书系统 Σ 在点 m∈M 上产出证书域 K_Σ(m) = (S_Σ(m), V_Σ(m))：S_Σ(m) 为安全谓词（m 上所有执行不越界），V_Σ(m) 为**非空**可行策略集（存在到达目标的策略）。**有效证书域** K⁺_Σ(m) = S_Σ(m) ∧ (V_Σ(m) ≠ ∅)。

**定义 45（认证泛化指数 CGI）**：CGI_Σ(μ) = μ({m : m ∈ K⁺_Σ})。分解为两条互不蕴含的曲线：
- **安全泛化** G_safe = μ({m : S_Σ(m)})，**可用泛化** G_use = μ({m : V_Σ(m)≠∅})。
显然 CGI ≤ min(G_safe, G_use)。**关键区分**：成功率 SR = E[1{达成目标}] 既可能"高 SR 低 CGI"（能到但没被证安全），也可能"低 SR 高 CGI"（保守到不试）。通用性优化是 **max CGI s.t. G_safe ≥ 1−ε**（安全地板优先），而非 max SR。

**定义 46（竞品差分见证与可观测 soundness）**：竞品 Σ_k 只能通过试验观测，记其违例率上界（Clopper–Pearson）为 v̄_k(m)。定义两类差分见证：
- **非空性缺口** Gap_use = {m : V_{Σ_k}(m)≠∅（竞品跑通，存在性见证）∧ V_Σ(m)=∅}。
- **安全优势** Lead_safe = {m : S_Σ(m) ∧ 实测到 Σ_k 违例（从而 ¬S_k 有置信度）}。
**不对称性命题**：竞品"成功"**不能**推出 S_k（成功≠被证安全）；只有**实测违例**才能推出 ¬S_k。因此安全优势是**可观测**的，而非空性缺口是**存在性**的——二者证据强度不同，不可混用。

**定义 47（证书迁移同态与迁移引理）**：本体 e1→e2 上的仿真关系 R ⊆ X_1×X_2，若存在加性失真 δ 使 ∀(x1,x2)∈R、∀a1∃a2：(x1',x2')∈R ∧ dist(x1',x2') ≤ dist(x1,x2)+δ。若证书谓词 φ 关于 dist 是 L-Lipschitz 且鲁棒裕度 ρ ≥ δ·L，则 φ 可沿 R **拉回**。**迁移引理**：若 Σ 在 e1 上 sound，且 (R,δ) 为证书同态且鲁棒裕度 ≥ δ·L，则 Σ 在 e2 上仍 sound，代价是边际按 δ·L 单调收缩。**推论**：跨本体通用性不是"重训一遍"，而是"证明一个带失真的仿真关系"。

**定义 48（泛化预算与边际 ROI）**：泛化不免费。定义泛化预算 Γ（仿真算力 + 实机时长 + 认证工时），约束 Γ ≤ Γ_max。**边际泛化收益** ROI(m) = ΔCGI/ΔΓ(m)。目标：argmax_{策略 π} CGI s.t. Γ(π) ≤ Γ_max ∧ G_safe ≥ 1−ε。**注**：这是带安全硬约束的预算分配问题，与 v20 的信任预算 τ_u 同构但作用在能力维度；二者在架构上统一为"预算守恒"。

**定义 49（竞品作为主动学习 oracle）**：采集函数 a(m) = E[ΔCGI | 在 m 观测] / cost(m)。竞品成功轨迹 → **正例**（扩张 V，抬高 G_use）；竞品违例 → **负例**（收缩/加固 S，护栏 G_safe）。竞争性课程在 a(m) 最大处采样，替代均匀扫基准，与 IP-50 课程引擎、IP-54 SCV 对接。**反例一旦回灌 CKB，就被加指纹锁定，避免重复踩坑**。

**定义 50（任务组合封闭与组合泛化缺口）**：任务 T1 的终止集须 ⊆ T2 的初始集才可复合 T1∘T2。若 Σ 对 T1、T2 分别 sound，但存在复合策略越界，则该点构成**组合泛化缺口** G_∘ = μ({m∘ : 独立 sound ∧ 复合不 sound})。**通用性 = CGI（广度）× (1 − G_∘)（深度）**。这连接 IP-47 组合代数：组合接口契约必须包含**前置/终止集匹配**与**读写集/守恒量**声明，否则单任务证书的"通用"是假象。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 COMPETITIVE-CERT-BENCHMARK（竞品证书基准 CCB）
1. **统一证书协议**：强制所有被测系统（我方 + 竞品/公开 checkpoint）在同一能力点 m 上输出 (任务、本体、环境、人格、违例证据)，而非只报成功率。
2. **差分见证挖掘**：自动分类 Gap_use（存在性缺口）与 Lead_safe（可观测安全优势），并给出每个见证的置信区间与证据类型。
3. **CGI 下限估计**：用共形下界在有限基准上给 CGI 的**统计下界**（而非点估计），显式报告"基准覆盖 ≠ 部署覆盖"的宽度。
4. **抗刷分审计**：检测"针对基准过拟合"（排名稳定性、留出能力点、对抗基准），把刷分行为记为负资产。

### 2.2 IP-61 CERT-TRANSFER-ALGEBRA（证书迁移代数 CTA）
1. **仿真关系合成**：为成对本体建立 (R, δ) 同态，验证鲁棒裕度 ρ ≥ δ·L，输出迁移后的收缩证书。
2. **组合闭合检查**：任务复合前检查前置/终止集匹配与守恒量，报告 G_∘ 与反例。
3. **迁移库**：把成功迁移的 (本体对, R, δ, 惩罚) 存入 CKB，供检索复用；失败迁移成为负例。
4. **失真校准**：δ 由仿真与实机配对数据在线校准，δ 漂移触发迁移证书失效（回退到单本体）。

### 2.3 IP-62 GENERALITY-FLYWHEEL（泛化飞轮 GFW）
1. **ROI 调度器**：在 Γ 预算下按 a(m) 采样能力点，优先采"高信息增益 / 低成本"点。
2. **竞品差分课程**：把 Gap_use 转成仿真扩张任务，把 Lead_safe 转成安全加固反例。
3. **飞轮回灌**：反例/正例 → CKB 指纹 + SCV 场景 + IP-50 课程难度，形成单调的 CGI 下界抬升。
4. **预算守恒审计**：每次泛化扩张记账，防止"用未声明的实机时间偷换通用性"。

## 4. 实验设计（E95–E102 硬门槛，承接 E87–E94）

| 实验 | 指标 | 门槛 |
|---|---|---|

## 5. 本轮最大风险

**一句话**：在有限竞品基准上估计的 CGI 只是真实部署分布 μ 的统计下界，而"通用"恰恰是关于基准之外的分布，把基准覆盖误当成分布覆盖，就是在元层面原样重演第 43 轮"边际覆盖 ≠ 条件覆盖"的错误——我们可能得到一个漂亮却不可迁移、且把竞品"侥幸成功"错记为"我方可追赶缺口"的 CGI，因此 E95（下限校准）与 E99（安全优势统计有效性）必须设为红线，并默认回退到"只报下界、不宣称通用、单本体单任务"这条永不失 sound 的底线。

## 2. 关键算法（伪代码）

### IP-60 CCB：差分见证、CGI 下限与抗刷分
```
def cert_protocol_run(system, m):
    # 统一协议：不只报成功率，必须报违例证据
    traj, viol = system.execute(m.task, m.embodiment, m.env, m.persona)
    return Evidence(goal=reached(traj, m.task), violations=viol, traj=traj)

def differential_witnesses(mine, competitors, D):
    gaps, leads = [], []
    for m in D:
        ev_me = cert_protocol_run(mine, m)
        for k in competitors:
            ev_k = cert_protocol_run(k, m)
            # Gap_use：竞品跑通 => 存在性见证；我方 V 为空
            if ev_k.goal and not mine.feasible(m):
                gaps.append(Witness(m, kind='GAP_USE', evidence='existential'))
            # Lead_safe：我方 sound 且实测竞品违例 => 可观测负例
            if mine.sound(m) and ev_k.violations:
                leads.append(Witness(m, kind='LEAD_SAFE', ci=violation_ci(ev_k)))
    return gaps, leads   # 两类证据强度不同，禁止混用

def cgi_lower_bound(samples, alpha):
    # 有限基准上只给统计下界，绝不点估计冒充真实 μ
    n = len(samples); k = sum(valid_cert(m) for m in samples)
    return clopper_pearson_lower(k, n, 1 - alpha)

def anti_gaming_audit(rankings_full, rankings_holdout):
    rho = spearman(rankings_full, rankings_holdout)   # 留出能力点秩相关
    return rho, detect_overfit(rankings_full, rankings_holdout)
```

### IP-61 CTA：迁移同态、迁移引理与组合闭合
```
def build_morphism(e1, e2, pairs):
    # 由配对数据拟合仿真关系 R 与加性失真 δ
    R = fit_simulation_relation(pairs)
    delta = calibrate_distortion(R, pairs)
    return R, delta

def transfer_certificate(cert_e1, R, delta, phi):
    L = lipschitz_const(phi)
    if cert_e1.margin >= delta * L + safety_slack:
        # 迁移引理成立：soundness 保，边际按 δ·L 收缩
        return Certificate(predicate=phi.pullback(R), margin=cert_e1.margin - delta*L,
                           sound=True, source='transfer')
    return Certificate(sound=False, reason='margin<δ·L')

def composition_closure(t1_cert, t2_cert, conservation):
    if not subset(t1_cert.terminal, t2_cert.initial):
        return Gap(reason='terminal⊄initial')
    if not preserves(conservation, [t1_cert, t2_cert]):
        return Gap(reason='conservation_violated')
    return compose(t1_cert, t2_cert)   # 组合后仍 sound 才放行

def delta_drift_check(R, delta, live_pairs):
    if abs(calibrate_distortion(R, live_pairs) - delta) > drift_tol:
        return 'INVALIDATE_TRANSFER'  # δ 漂移 => 迁移证书失效，回退单本体
```

### IP-62 GFW：ROI 调度、竞争性课程与预算守恒
```
def roi_course(D_candidates, budget, history):
    selected = []
    while budget > 0:
        # 采集函数：预期 CGI 增量 / 成本
        m = max(D_candidates, key=lambda x: expected_cgi_gain(x, history) / cost(x))
        yield_m = probe(m)                      # 竞品 + 我方各跑一次
        budget -= cost(m)
        if yield_m.kind == 'GAP_USE':
            enqueue_sim_expansion(m)            # 正例：扩张 V
        elif yield_m.kind == 'LEAD_SAFE':
            enqueue_safety_hardening(m)         # 负例：加固 S
        selected.append(m)
    return selected

def budget_conservation(tau_used, gamma_used, cap_tau, cap_gamma):
    # 双预算不得互相挪用，否则"通用"可用未声明的实机时间偷换
    assert tau_used <= cap_tau and gamma_used <= cap_gamma
    return report(tau_used/cap_tau, gamma_used/cap_gamma)

def flywheel_step():
    gaps, leads = differential_witnesses(mine, competitors, benchmark)
    gamma = roi_course(gaps + leads, Gamma_max, history)
    for g in gaps: CKB.add_fingerprint(g.m, kind='positive')
    for l in leads: CKB.add_fingerprint(l.m, kind='negative_counterexample')
    SCV.inject(gaps + leads)                    # 回灌仿真
    return cgi_lower_bound(resample(benchmark), alpha)   # 单调下界
```

## 6. 本轮最大风险

**一句话**：在有限竞品基准上估计的 CGI 只是真实部署分布 μ 的统计下界，而"通用"恰恰是关于基准之外的分布，把基准覆盖误当成分布覆盖，就是在元层面原样重演第 43 轮"边际覆盖 ≠ 条件覆盖"的错误——我们可能得到一个漂亮却不可迁移、且把竞品"侥幸成功"错记为"我方可追赶缺口"的 CGI，因此 E95（下限校准）与 E99（安全优势统计有效性）必须设为红线，并默认回退到"只报下界、不宣称通用、单本体单任务"这条永不失 sound 的底线。
