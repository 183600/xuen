# 第 67 轮（承接第 66 轮「RAS 情绪驱动闭环」IP-224~233；灵感循环第 1 轮；本轮灵感：「多传感器融合」×「数据质量」）

> 第 66 轮 RAS 把 VISTA 的「故障响应闭环」升级为「意图感知闭环」，让控制输入第一次包含主体的风险态度。但 RAS（乃至它继承的 VISTA）在最底层共享一个从未被正视的假设：**观测是均匀可靠的**。它用 `face_unobservable` 这个二值开关处理“看不见”，用一阶时序 KL 处理“抖动”，却默认“看得见”就等于“可采信”。
>
> 本轮两个灵感词恰好刺穿这个假设。「多传感器融合」的真正难点不是“如何加权平均”，而是**融合的单位是“证据”而非“数值”**；「数据质量」也不是一个可以拍阈值掉的标量，而是**多维、有因果结构、跨模态相关、且自身不确定**的隐变量。
>
> 本轮核心命题是：
>
> **把「假设观测可靠」的 RAS，升级为「对证据本身负责」的质量校准证据闭环（QCE：Quality-Calibrated Evidence loop）：给每条观测附一张多维、可保形校准的质量凭证，用相关感知的温控似然做融合，并让质量同时决定风险缩放与安全证书的置信集。**
>
> QCE 问的不再是「哪一层坏了」（VISTA）、「谁控制多少」（RAS），而是：「**这份数据配不配被相信，相信到什么程度，相信它的代价（时延/算力/再观测）是否值得？**」

## 0. 直觉与动机

**灵感 1（多传感器融合 → 融合的是“证据”，且冗余会反噬）**
直觉：卡尔曼/因子图把融合理解为「在独立高斯噪声下做精度加权」。可现实里最致命的不是单路噪声，而是**多路坏数据彼此相关**：同一盏强光同时让 RGB 过曝、深度失效，同一段网络抖动同时丢掉多路流。此时朴素融合会把「两路相关的坏数据」误读成「互相印证」，后验方差反而被压低——**冗余制造了虚假的确定**。因此质量必须以「证据强度」而非「数值权重」进入融合，并显式建模**跨模态质量相关性**与**有效独立传感器数 n_eff**。

**灵感 2（数据质量 → 不是一个阈值，而是五维“短板”凭证）**
直觉：数据质量研究早已给出多维框架（准确 accuracy、完整 completeness、一致 consistency、及时 timeliness、可信 believability/provenance）。这五维在融合里对应五种**不同的补救动作**：
- 准确低 → 降权（precision 膨胀）；
- 完整低 → 触发补观测/外推（而不是当作高置信的缺失）；
- 一致低 → 跨模态对账，冲突本身就是信息；
- 及时低 → 时效指数折扣（**实时安全环里最容易被忽视的一维**）；
- 可信低 → 溯源/对抗校验，必要时整路隔离。

关键设计：用**几何平均**合成标量质量，实现「短板语义」——任何一维塌陷，都不允许整条证据被满额采信。

**灵感 3（质量本身要被校准 → 否则它只是另一个启发式）**
直觉：如果质量分 q=0.9 只是模型随手给的数，那“按质量融合”不过是把偏见重新分配了一遍。质量要能被采信，必须**可校准**：q=s 应当意味着“该观测落在容差内的概率至少是 s”。于是用保形预测（conformal）把原始质量启发式映射为**有覆盖保证**的校准质量，让 q 从“形容词”变成“概率承诺”。

**灵感 4（质量故障有三种病，不能一种药）**
直觉：坏数据有三种截然不同的病理，必须分开归因、分开处置：
- **偶然噪声（aleatoric）**：不可消除但可降权；
- **认知缺失（epistemic）**：信息不足，正确动作是**主动再观测**（复用 RAS 的 FAS 探针）；
- **对抗篡改（adversarial）**：数据在骗你，正确动作是**隔离 + 保守回退**，而不是继续加权。

把三者混为一谈，就会出现“遇到攻击时越想看清、越被带偏”的经典失效。

**灵感 5（质量-时延三难 → 用 VoI 做预算分配）**
直觉：提高质量不是免费的：加曝光、加传感器、加复核都会推高时延，而安全环只有 <2ms。于是每帧都面临一个**质量-时延-安全三难**。正确的问题不是“能不能更高质”，而是“**在给定时延/算力预算下，把下一份算力花在哪一路，才能最大化期望安全增益**”——即价值信息（VoI）驱动的传感器选择与主动再观测。

**灵感 6（合流 → QCE）**
QCE 保留 RAS 的 `ERG×EFS×FRAS×C-RAS` 骨架，但把每一条输入证据替换为「值 + 质量凭证」：
1. **QAM Quality Attestation Module**：为每路观测计算五维质量向量；
2. **CQC Calibrated Quality Calibrator**：保形校准，q 成为覆盖承诺；
3. **CCF Correlation-aware Credibility Fusion**：温控似然 + 质量相关矩阵 + n_eff，避免虚假共识；
4. **QSL Quality-Staleness Ledger**：时效折扣，过期证据指数失效；
5. **QVA Quality-Value Allocator**：VoI 贪心分配预算，决定“看谁/再不看”；
6. **Q-FIR Quality-aware Fault Isolation**：新增 H_q 维（aleatoric/epistemic/adversarial/common）；
7. **Q-RAS risk scaling**：质量条件化、单调保守的风险缩放；
8. **QAS Quality-Active Sensing**：低认知质量时主动再观测；
9. **Q-Cert robust certificate**：在质量置信集上取最坏情形；
10. **J_QCE**：携带质量凭证链的证书。

## 1. 形式化定义（增量：定义 245–258）

- **定义 245（质量五维向量）**：第 i 路观测 `d_i` 的质量凭证为 `q_i = (a_i, c_i, k_i, τ_i, b_i) ∈ [0,1]^5`，分别表示准确、完整、一致、及时、可信。标量有效质量取「短板型」几何合成 `q̃_i = (a_i·c_i·k_i·b_i)^{1/4} · τ_i`，其中 `τ_i = exp(-λ_age·age_i)` 为时效项，`age_i = t - t_i^obs`。定位：`q̃_i = 0` 当且仅当任一维为 0（任一维塌陷即整条不可满信）。
- **定义 246（质量保形校准）**：称质量函数 `q` 在水平 `1-α` 上校准，若对任意 `s∈[0,1]`，`P(d_i ∈ TOL(s) | q_i = s) ≥ s - α`，其中 `TOL(s)` 是质量分 `s` 对应的容差球。实现上用 split-conformal 的单调分位映射 `g: 原始分 → 校准分`，`g` 只在语义流拟合、实时流只做查表。
- **定义 247（温控证据似然）**：给定校准质量 `q̃_i` 与观测 `d_i`，单路证据似然取分数次幂 `p(d_i | x)^{q̃_i}`（power posterior / fractional likelihood）。直观：`q̃_i=1` 为满证据；`q̃_i=0` 退化为常数（不提供信息），但**不删除**该路（保留其“存在过”的时序占位）。
- **定义 248（跨模态质量相关与有效独立度）**：质量相关矩阵 `R_Q ∈ [0,1]^{n×n}`，`R_Q[i,i]=1`，`ρ_ij` 由共因图给出（同光照/同网络/同场景退化）。有效独立传感器数 `n_eff = (1ᵀw)² / (wᵀ R_Q w)`，其中 `w` 为名义证据权重。`ρ_ij→1` 时 `n_eff→1`（冗余归零），`ρ_ij→0` 时 `n_eff→n`。
- **定义 249（可信融合后验）**：`p(x | D) ∝ p(x) · ∏_i p(d_i | x)^{w_i}`，其中 `w = R_Q^{-1} q̃ / (1ᵀ R_Q^{-1} q̃)` 为相关去偏后的归一化证据权重。`R_Q = I` 时退化为经典独立温控融合；`R_Q = 11ᵀ` 时权重坍缩到单路，明确拒绝“相关冗余增益”。
- **定义 250（质量条件风险缩放）**：`λ_risk(q) = clip(1 - α_risk·R_emotion·q̃_face - β_risk·(1 - q̄_scene), λ_min, λ_max)`，`q̄_scene` 为场景证据平均质量。要求单调性 `∂λ_risk/∂q̃ ≥ 0`：**质量越低越保守**；且 `q̃→0 ⇒ λ_risk→λ_min`，低质量永不放松约束。
- **定义 251（质量故障假设集）**：`H_q = {Q0 正常, Q1 偶然噪声, Q2 认知缺失, Q3 对抗篡改, Q4 共因退化}`。与 RAS 的故障/情绪假设联立：`P(H, E, H_q | ρ, face, q) ∝ p(ρ|H)·p(face|E)·p(q|H_q)·P(H)P(E)P(H_q)`。
- **定义 252（价值信息 VoI）**：`VoI(i) = E[ U(fuse(D ∪ {d_i})) ] - E[ U(fuse(D)) ] - c_i·Δτ_i`，`U` 为安全效用（负的最坏情形风险），`c_i` 为获取成本，`Δτ_i` 为时延增量。VoI 为正才值得采信/再观测。
- **定义 253（质量-时延预算与帕累托前沿）**：每帧约束 `Σ_i c_i ≤ B_τ`、`age_i ≤ τ_max`；可达质量集合 `Q(τ) = { q : 满足预算 }` 构成质量-时延帕累托前沿。QCE 在该前沿上做分配，而非追求无条件最高质量。
- **定义 254（质量置信集 ε-ball）**：`Q_α = { q' : ||q' - g(q)||_∞ ≤ ε_cal }`，`ε_cal` 由保形分位给出。它刻画“质量估计本身有多不确定”。
- **定义 255（Q-Cert 鲁棒证书）**：`J_QCE = (J_RAS, q̃, w, n_eff, H_q 后验, ε_cal, voI_trace, qce_ver)`。`Valid(J_QCE) ⇔ Valid(J_RAS) ∧ ∀q'∈Q_α: safety_margin(q') ≥ 0 ∧ n_eff ≥ n_min`。证书校验的是**质量置信集上的最坏情形**，而非点估计。
- **定义 256（质量加权一致性）**：跨模态冲突 `s_conf = Σ_{i<j} w_i w_j · d(d_i, d_j)`，其中 `d(·,·)` 为质量加权 Mahalanobis 距离。`s_conf` 高且 `n_eff` 高 → 真实分歧（值得探针）；`s_conf` 高但 `n_eff` 低 → 可能是共因退化（应整体降级而非互相调和）。
- **定义 257（QCE 总览与两流不变式）**：`QCE = (QAM, CQC, CCF, QSL, QVA, Q-FIR, Q-RAS, QAS, Q-Cert)`。不变式：质量拟合、保形校准、相关矩阵估计、VoI 规划只在语义流；实时流只做质量查表、温控融合、时效折扣、风险缩放与预算早停，零学习写操作。
- **定义 258（质量衰减与证据半衰期）**：定义证据半衰期 `T½ = ln2 / λ_age`。若 `age_i > k·T½`，该路 `q̃_i < 2^{-k}`，其在 `w` 中的份额被指数压制。给出硬门限 `age_i > τ_max ⇒ w_i := 0`（时效上不可用）。

## 2. 关键算法骨架

```python
# IP-234 QAM：质量凭证
class QualityAttestation:
    def __init__(self, lam_age=0.7):
        self.lam_age = lam_age

    def attest(self, d_i, t, noise_model, coverage, agree, provenance):
        a = accuracy_score(d_i, noise_model)       # 校准残差 → 准确
        c = coverage                              # 关键点/视场覆盖率 → 完整
        k = agree                                 # 跨模态一致性 → 一致
        b = provenance                            # 标定状态/哈希 → 可信
        tau = math.exp(-self.lam_age * (t - d_i.t_obs))   # 时效
        return {'a': a, 'c': c, 'k': k, 'b': b, 'tau': tau,
                'q': (max(a*c*k*b, 0.0) ** 0.25) * tau}


# IP-235 CQC：保形校准（离线拟合，实时查表）
class ConformalQualityCalibrator:
    def __init__(self, g, eps_cal):
        self.g, self.eps_cal = g, eps_cal   # g: 原分 → 校准分

    def calibrate(self, q_raw):
        s = self.g(q_raw)
        return s, max(0.0, s - self.eps_cal), min(1.0, s + self.eps_cal)


# IP-236 CCF：相关感知温控融合
class CorrelationAwareFusion:
    def __init__(self, R_Q, n_min=1.05):
        self.R_Q, self.n_min = R_Q, n_min

    def fuse(self, prior, evidences, q):
        # evidences: [(likelihood_fn, datum)]
        w = solve(self.R_Q, q)                 # R_Q^{-1} q̃
        w = w / (w.sum() + 1e-9)
        n_eff = (w.sum() ** 2) / (w @ self.R_Q @ w + 1e-9)
        post = prior
        for wi, (lik, d) in zip(w, evidences):
            post = temper(post, lik(d), wi)    # p ∝ p·lik^{wi}
        return post, {'w': w, 'n_eff': n_eff,
                      'overconfident': n_eff < self.n_min}


# IP-237 QSL + IP-238 Q-FIR：时效门限与质量故障归因
def attribute_quality(q, s_conf, n_eff, age_frac):
    if age_frac > 1.0:
        return {'Q2': 0.9}                      # 过期 → 认知缺失
    ev = {
        'Q0': 1.0 - s_conf,
        'Q1': aleatoric_mass(q),                # 噪声 → 偶然
        'Q2': epistemic_mass(q, s_conf),        # 缺失/冲突不可解释 → 认知
        'Q3': adversarial_mass(q),              # 溯源异常 → 对抗
        'Q4': common_cause_mass(s_conf, n_eff), # 高冲突 + 低 n_eff → 共因
    }
    return normalize(ev)


# IP-239 QVA：VoI 贪心预算分配
def allocate_budget(avail_sensors, B_tau, fuse_fn):
    chosen, spent = [], 0.0
    while True:
        gains = [(VoI(s, chosen, fuse_fn), s) for s in avail_sensors
                 if s not in chosen and spent + s.cost <= B_tau]
        if not gains:
            break
        g, s = max(gains)
        if g <= 0:
            break
        chosen.append(s); spent += s.cost
    return chosen, spent


# IP-240/241/242 Q-RAS 闭环
def QCE_round(M, obs, budget):
    # 1) 质量评估与校准
    q_raw = [M.qam.attest(d, M.t, *M.quality_ctx(d)) for d in obs]
    q_cal = [M.cqc.calibrate(x['q']) for x in q_raw]
    q_point = [c[0] for c in q_cal]

    # 2) 相关感知融合
    post, meta = M.ccf.fuse(M.prior, M.evidences(obs), q_point)

    # 3) 质量故障归因
    H_q = attribute_quality(q_point, M.conflict(obs, meta['w']),
                            meta['n_eff'], M.age_frac(obs))

    # 4) 主动再观测（认知缺失 / 高 VoI）
    if H_q.get('Q2', 0) > M.tau_epistemic:
        sensors, _ = allocate_budget(M.avail, budget, M.ccf.fuse)
        obs = M.reobserve(sensors)
        post, meta = M.ccf.fuse(M.prior, M.evidences(obs), q_point)

    # 5) 质量条件风险缩放（单调保守）
    q_scene = float(np.mean(q_point))
    lam = clip(1 - M.alpha*M.R_emotion*M.q_face
                 - M.beta*(1 - q_scene), M.lam_min, M.lam_max)

    # 6) 鲁棒前缀（质量置信集上取最坏情形）
    k = M.csc_q.certified_prefix(post, meta['w'], meta['n_eff'],
                                 q_cal, M.eps_cal, lam)
    return k, lam, post, meta, H_q
```

## 3. 推导

**引理 11（时效质量的指数压制）** 对第 i 路证据，若不采用时效项，其在权重中的份额为 `w_i^0`；采用 `τ_i = exp(-λ_age·age_i)` 后份额满足 `w_i^τ / w_i^0 ≤ e^{-λ_age·age_i}`（在 `R_Q` 对角占优时）。因此任一“高质但过期”的证据无法主导新鲜证据；取 `τ_max = ln(1/ε_w)/λ_age` 可保证过期证据权重 `< ε_w`。这把 RAS 里一阶时序 KL 的“软抖动抑制”升级为**带硬半衰期的时效保证**。

**引理 12（相关冗余的过置信放大）** 朴素独立融合对 n 路等权证据给出的融合方差为 `σ²/n`；但若两两质量相关为 `ρ`，真实方差下界为 `σ²·(1+(n-1)ρ)/n`。二者之比 `n / (1+(n-1)ρ) = 1/ρ_eff` 即**过置信倍数**。当 `ρ→1` 时真实方差回到 `σ²`，而朴素法仍以为 `σ²/n`，故系统把置信度虚高了 n 倍。引入 `n_eff` 与 `w = R_Q^{-1}q̃` 后，融合方差按 `n_eff` 而非 n 收缩，过置信倍数被压回 1。

**引理 13（短板质量不上调风险缩放）** 由定义 250，`∂λ_risk/∂q̃ ≥ 0` 且 `λ_risk ≤ λ_max`。故当任一维质量下降导致 `q̃` 下降时，`λ_risk` 单调不增，执行动作的风险包络只会收紧不会放松。特别地 `q̃_face→0`（情绪不可信）时 `λ_risk` 趋向下界 `λ_min`，与 RAS 的“看不见即保守”一致，但这里是**连续**退化而非二值跳变。

**定理 11（校准质量下融合不劣于最佳单模态）** 设各证据似然为恰当评分规则（对数损失），质量 `q` 在水平 `1-α` 上保形校准，且 `R_Q` 正确刻画相关结构。则以 `w = R_Q^{-1}q̃` 归一化作对数意见池（logarithmic opinion pool）得到的后验 `p(x|D)` 的期望对数评分满足
```
E[log p(x|D)] ≥ max_i E[log p_i(x|d_i)] - α·H(x)
```
即校准质量下的融合**不劣于最佳单路**（至多损失与校准水平成正比的熵项）。这给“多加传感器不会更糟”划定了**有条件的**边界：条件是质量校准 + 相关结构正确；二者任一失效，引理 12 就接管，融合可能更糟。

**定理 12（QCE 端到端风险一致性）** 在 A87-A91 与定义 246、250、255 下，执行指令 `τ_cmd = τ_base·λ_risk(q)` 满足：
1. `P(|τ_cmd - τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_Q`，`α_Q` 为质量校准的未覆盖概率；
2. 对任意 `q'∈Q_α`，最坏情形安全裕度 `≥ 0`（定义 255），即证书在质量估计不确定时仍成立；
3. 质量退化**不放松**约束：`q̃↓ ⇒ λ_risk↓`，且 `n_eff < n_min` 时禁止以“融合增益”名义放宽前缀。

**定理 13（VoI 分配的近似最优性）** 若安全效用 `U` 关于证据集合单调且收益递减（条件独立下 VoI 次模），则定义 252/253 的贪心预算分配在 `Σc_i ≤ B_τ` 下取得至少 `(1-1/e)` 的最优期望安全增益。因此 <2ms 预算下的“看哪几路”不再靠拍脑袋，而有次模优化的近似保证。

## 6. 本轮最大风险

**一句话**：QCE 把整套安全保证押在“质量估计器本身是可信的”这一层上，而质量估计器又是一个未经同样标准验证的信任锚——一旦发生分布漂移或对抗性的“质量洗白”（攻击者伪造高质凭证），保形校准的覆盖保证会失效，相关感知融合反而会因“被信任的冗余”产生比单模态更强的**虚假共识**，让证书在一堆精心打扮的坏数据上判定安全——这是本轮所有推导共同依赖、也最可能被现实击穿的核心假设：**质量是可校准且不可被操纵的**。

**次级风险与缓解**：
1. **质量元评估缺失**：为质量分本身定义“元质量”（`q` 的校准漂移检测），一旦 ECE 超阈即整体回退到最小信任模式；
2. **相关矩阵估计误差**：`R_Q` 用共因图 + 在线残差估计，宁高估相关（保守）不可低估；
3. **保形校准的分布漂移**：采用自适应保形（ACI）在线更新覆盖率，漂移时自动扩大 `Q_α`；
4. **VoI 与安全的错位**：安全效用必须取最坏情形而非期望，避免“信息增益高但风险更高”；
5. **实时算力**：`R_Q^{-1}` 用 Sherman–Morrison 增量更新，避免每帧 O(n³)；质量网络用查表 + 轻量回归。

## 2. 形式化定义（完整版）

**定义 245（质量五维向量）** 第 i 路观测 `d_i` 的质量凭证为 `q_i = (a_i, c_i, k_i, τ_i, b_i) ∈ [0,1]^5`，分别表示准确、完整、一致、及时、可信。标量有效质量
```
q̃_i = (a_i·c_i·k_i·b_i)^{1/4} · τ_i,   τ_i = exp(-λ_age·age_i),  age_i = t - t_i^obs
```
`q̃_i = 0` 当且仅当任一维为 0：任一维塌陷即整条证据不可满信（短板语义）。

**定义 246（质量保形校准）** 质量函数 `q` 在水平 `1-α` 上校准，若对任意 `s∈[0,1]`
```
P(d_i ∈ TOL(s) | q_i = s) ≥ s - α
```
实现用 split-conformal 的单调分位映射 `g: 原始分 → 校准分`；`g` 只在语义流拟合，实时流只查表。校准残差给出质量置信半径 `ε_cal`。

**定义 247（温控证据似然）** 给定校准质量 `q̃_i`，单路证据似然取分数次幂
```
p(d_i | x)^{q̃_i}
```
`q̃_i=1` 为满证据；`q̃_i=0` 退化为常数（不提供信息），但保留其在时序中的“存在占位”。

**定义 248（质量相关与有效独立度）** 质量相关矩阵 `R_Q ∈ [0,1]^{n×n}`，`R_Q[i,i]=1`，`ρ_ij` 由共因图给出（同光照/同网络/同场景退化）。有效独立传感器数
```
n_eff = (1ᵀw)² / (wᵀ R_Q w)
```
`ρ_ij→1 ⇒ n_eff→1`；`ρ_ij→0 ⇒ n_eff→n`。

**定义 249（可信融合后验）**
```
p(x|D) ∝ p(x) · ∏_i p(d_i|x)^{w_i},   w = R_Q^{-1} q̃ / (1ᵀ R_Q^{-1} q̃)
```
`R_Q=I` 退化为经典独立温控融合；`R_Q=11ᵀ` 时权重坍缩到单路，明确拒绝“相关冗余增益”。

**定义 250（质量条件风险缩放）**
```
λ_risk(q) = clip(1 - α_risk·R_emotion·q̃_face - β_risk·(1 - q̄_scene), λ_min, λ_max)
```
要求 `∂λ_risk/∂q̃ ≥ 0`：质量越低越保守；`q̃→0 ⇒ λ_risk→λ_min`。

**定义 251（质量故障假设集）**
```
H_q = {Q0 正常, Q1 偶然噪声, Q2 认知缺失, Q3 对抗篡改, Q4 共因退化}
P(H,E,H_q | ρ, face, q) ∝ p(ρ|H)·p(face|E)·p(q|H_q)·P(H)P(E)P(H_q)
```

**定义 252（价值信息 VoI）**
```
VoI(i) = E[U(fuse(D ∪ {d_i}))] - E[U(fuse(D))] - c_i·Δτ_i
```
`U` 为安全效用（负的最坏情形风险），`VoI>0` 才值得采信/再观测。

**定义 253（质量-时延预算与帕累托前沿）** 每帧约束 `Σ_i c_i ≤ B_τ`、`age_i ≤ τ_max`；可达质量集合 `Q(τ) = {q : 满足预算}` 构成质量-时延帕累托前沿，QCE 在其上分配而非追求无条件最高质量。

**定义 254（质量置信集）**
```
Q_α = { q' : ||q' - g(q)||_∞ ≤ ε_cal }
```

**定义 255（Q-Cert 鲁棒证书）**
```
J_QCE = (J_RAS, q̃, w, n_eff, H_q 后验, ε_cal, voI_trace, qce_ver)
Valid(J_QCE) ⇔ Valid(J_RAS) ∧ ∀q'∈Q_α: safety_margin(q') ≥ 0 ∧ n_eff ≥ n_min
```

**定义 256（质量加权一致性）** 跨模态冲突
```
s_conf = Σ_{i<j} w_i w_j · d(d_i, d_j)
```
`d(·,·)` 为质量加权 Mahalanobis 距离。`s_conf` 高且 `n_eff` 高 → 真实分歧（值得探针）；`s_conf` 高但 `n_eff` 低 → 可能共因退化（应整体降级）。

**定义 257（QCE 总览与两流不变式）**
```
QCE = (QAM, CQC, CCF, QSL, QVA, Q-FIR, Q-RAS, QAS, Q-Cert)
```
不变式：质量拟合、保形校准、相关矩阵估计、VoI 规划只在语义流；实时流只做质量查表、温控融合、时效折扣、风险缩放与预算早停，零学习写操作。

**定义 258（质量衰减与证据半衰期）** 证据半衰期 `T½ = ln2/λ_age`。若 `age_i > k·T½`，则 `q̃_i < 2^{-k}`，其权重份额被指数压制；硬门限 `age_i > τ_max ⇒ w_i := 0`。

# IP-234 QAM：质量凭证
class QualityAttestation:
    def __init__(self, lam_age=0.7):
        self.lam_age = lam_age

    def attest(self, d_i, t, noise_model, coverage, agree, provenance):
        a = accuracy_score(d_i, noise_model)       # 校准残差 → 准确
        c = coverage                              # 关键点/视场覆盖率 → 完整
        k = agree                                 # 跨模态一致性 → 一致
        b = provenance                            # 标定状态/哈希 → 可信
        tau = math.exp(-self.lam_age * (t - d_i.t_obs))   # 时效
        return {'a': a, 'c': c, 'k': k, 'b': b, 'tau': tau,
                'q': (max(a*c*k*b, 0.0) ** 0.25) * tau}


# IP-235 CQC：保形校准（离线拟合，实时查表）
class ConformalQualityCalibrator:
    def __init__(self, g, eps_cal):
        self.g, self.eps_cal = g, eps_cal

    def calibrate(self, q_raw):
        s = self.g(q_raw)
        return s, max(0.0, s - self.eps_cal), min(1.0, s + self.eps_cal)


# IP-236 CCF：相关感知温控融合
class CorrelationAwareFusion:
    def __init__(self, R_Q, n_min=1.05):
        self.R_Q, self.n_min = R_Q, n_min

    def fuse(self, prior, evidences, q):
        w = solve(self.R_Q, q)                 # R_Q^{-1} q̃
        w = w / (w.sum() + 1e-9)
        n_eff = (w.sum() ** 2) / (w @ self.R_Q @ w + 1e-9)
        post = prior
        for wi, (lik, d) in zip(w, evidences):
            post = temper(post, lik(d), wi)    # p ∝ p·lik^{wi}
        return post, {'w': w, 'n_eff': n_eff,
                      'overconfident': n_eff < self.n_min}


# IP-238 Q-FIR：质量故障三分解 + 共因
def attribute_quality(q, s_conf, n_eff, age_frac):
    if age_frac > 1.0:
        return {'Q2': 0.9}
    ev = {
        'Q0': 1.0 - s_conf,
        'Q1': aleatoric_mass(q),
        'Q2': epistemic_mass(q, s_conf),
        'Q3': adversarial_mass(q),
        'Q4': common_cause_mass(s_conf, n_eff),
    }
    return normalize(ev)


# IP-239 QVA：VoI 次模贪心
def allocate_budget(avail_sensors, B_tau, fuse_fn):
    chosen, spent = [], 0.0
    while True:
        gains = [(VoI(s, chosen, fuse_fn), s) for s in avail_sensors
                 if s not in chosen and spent + s.cost <= B_tau]
        if not gains:
            break
        g, s = max(gains)
        if g <= 0:
            break
        chosen.append(s); spent += s.cost
    return chosen, spent


# IP-240/241/242 Q-RAS 闭环
def QCE_round(M, obs, budget):
    q_raw = [M.qam.attest(d, M.t, *M.quality_ctx(d)) for d in obs]
    q_cal = [M.cqc.calibrate(x['q']) for x in q_raw]
    q_point = [c[0] for c in q_cal]

    post, meta = M.ccf.fuse(M.prior, M.evidences(obs), q_point)
    H_q = attribute_quality(q_point, M.conflict(obs, meta['w']),
                            meta['n_eff'], M.age_frac(obs))

    if H_q.get('Q2', 0) > M.tau_epistemic:
        sensors, _ = allocate_budget(M.avail, budget, M.ccf.fuse)
        obs = M.reobserve(sensors)
        post, meta = M.ccf.fuse(M.prior, M.evidences(obs), q_point)

    q_scene = float(np.mean(q_point))
    lam = clip(1 - M.alpha*M.R_emotion*M.q_face
                 - M.beta*(1 - q_scene), M.lam_min, M.lam_max)

    k = M.csc_q.certified_prefix(post, meta['w'], meta['n_eff'],
                                 q_cal, M.eps_cal, lam)
    return k, lam, post, meta, H_q

## 4. 推导

**引理 11（时效质量的指数压制）** 在 `R_Q` 对角占优时，采用 `τ_i = exp(-λ_age·age_i)` 后证据权重份额满足 `w_i^τ / w_i^0 ≤ e^{-λ_age·age_i}`。故“高质但过期”的证据无法主导新鲜证据；取 `τ_max = ln(1/ε_w)/λ_age` 可保证过期证据权重 `< ε_w`。

**引理 12（相关冗余的过置信放大）** 朴素独立融合对 n 路等权证据给出方差 `σ²/n`；若两两质量相关为 `ρ`，真实方差下界为 `σ²·(1+(n-1)ρ)/n`。二者之比
```
n / (1+(n-1)ρ) = 1/ρ_eff
```
即过置信倍数。`ρ→1` 时真实方差回到 `σ²`，朴素法仍以为 `σ²/n`，虚高 n 倍。引入 `n_eff` 与 `w=R_Q^{-1}q̃` 后按 `n_eff` 收缩，过置信倍数压回 1。

**引理 13（短板质量不上调风险缩放）** 由定义 250，`∂λ_risk/∂q̃ ≥ 0`，故任一维质量下降使 `q̃` 下降时 `λ_risk` 单调不增，执行风险包络只收紧不放松；`q̃_face→0` 时 `λ_risk→λ_min`（连续退化的保守性）。

**定理 11（校准质量下融合不劣于最佳单模态）** 若各似然为恰当评分规则，`q` 在 `1-α` 上保形校准，`R_Q` 正确，则以 `w=R_Q^{-1}q̃` 归一化的对数意见池后验满足
```
E[log p(x|D)] ≥ max_i E[log p_i(x|d_i)] - α·H(x)
```
即融合不劣于最佳单路，至多损失与校准水平成正比的熵项。边界条件是“质量校准 + 相关结构正确”；任一失效则由引理 12 接管，融合可能更糟。

**定理 12（QCE 端到端风险一致性）** 在 A87-A91 与定义 246/250/255 下，`τ_cmd = τ_base·λ_risk(q)` 满足：
1. `P(|τ_cmd - τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_Q`；
2. `∀q'∈Q_α`，最坏情形安全裕度 `≥ 0`；
3. 质量退化为保守方向：`q̃↓ ⇒ λ_risk↓`，且 `n_eff < n_min` 时禁止以“融合增益”名义放宽前缀。

**定理 13（VoI 分配的近似最优性）** 若安全效用 `U` 关于证据集合单调且收益递减（条件独立下 VoI 次模），则定义 252/253 的贪心预算分配在 `Σc_i ≤ B_τ` 下至少取得 `(1-1/e)` 的最优期望安全增益。

## 6. 本轮最大风险

**一句话**：QCE 把全部保证押在“质量估计器本身可信”这一层，而它又是一个未经同样标准验证的信任锚——一旦分布漂移或遭遇“质量洗白”（伪造高质凭证），保形校准的覆盖保证失效，相关感知融合会因“被信任的冗余”产生比单模态更强的**虚假共识**，让证书在精心打扮的坏数据上判定安全；这是本轮所有推导共同依赖、也最易被现实击穿的核心假设：**质量可校准且不可被操纵**。

**次级风险与缓解**：
1. **质量元评估缺失**：为质量分定义“元质量”（校准漂移 ECE 监测），超阈即回退到最小信任模式；
2. **相关矩阵估计误差**：`R_Q` 用共因图 + 在线残差估计，宁高估相关（保守）不可低估；
3. **保形校准的分布漂移**：采用自适应保形（ACI）在线更新覆盖率，漂移时自动扩大 `Q_α`；
4. **VoI 与安全错位**：安全效用取最坏情形而非期望，避免“信息增益高但风险更高”；
5. **实时算力**：`R_Q^{-1}` 用 Sherman–Morrison 增量更新，避免每帧 O(n³)；质量网络用查表 + 轻量回归。
