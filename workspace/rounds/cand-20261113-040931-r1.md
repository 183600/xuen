# 第 65 轮（承接第 64 轮「GRIP 接触接地四层闭环」IP-204~213；灵感循环 II 第 4 轮；本轮灵感：「单模型多任务」×「竞赛策略」）

> 第 64 轮把证书从「几何-技能-干扰」扩到「接触」，但它默认**任务已给定、时间是充裕的、目标是单次执行安全**。真实 UniBot 赛场恰恰相反：**一个模型/一台机器人要在有限总时长内连续应对异构任务，按步骤分累加排名，单次失败还有惩罚、恢复成本与重试机会**。GRIP 能保证「这一件事做得稳」，却不能回答「这场竞赛该先做哪件事、做几次、冒多大风险」。本轮把研究对象从「单任务执行器」抬到「**单模型多任务的竞赛主体**」，核心命题是：
>
> **把竞赛从「逐任务成功率的平均」重构为「证书约束下的风险-收益投资组合」：单模型多任务提供共享表示与跨任务迁移，竞赛策略在此之上在线配置任务选择、顺序、尝试次数与风险姿态，使证书从「单次执行安全」升级为「整场竞赛的得分下界与排名概率下界」。**

## 0. 直觉与动机

**灵感 1（单模型多任务 → SOMA：一个主干，多个任务适配器）**
直觉：赛场上若每个任务单独训一个策略，参数与数据都不共享；但抓取、放置、开门、按按钮共享大量「接近-对准-接触-施力」结构。单模型多任务的价值不只是省参数，而是**把一次任务中学到的技能迁移到另一次**。SOMA（Single-model Multi-task Adapter）用共享视觉-语言-动作主干 + 任务/技能适配器：π_θ(a | o, ℓ) = 主干(o, ℓ; θ_s) + Σ_k g_k(ℓ)·Δθ_k，共享部分提供跨任务先验，适配器提供任务特异容量。**关键洞见**：单模型不是「一个网络包打天下」的口号，而是**一个可度量迁移矩阵 M_ij =「训练任务 i 对任务 j 的收益」**的载体；竞赛策略必须读这个矩阵，而不是只读平均成功率。

**灵感 2（单模型多任务 → TIC：负迁移可证伪、可隔离）**
直觉：多任务最怕负迁移——共享表征被任务 A 的梯度拖坏任务 B。TIC（Task Interference Certificate）用任务梯度冲突（cosine）与表征漂移度量干扰，给出**逐任务干扰上界**：R_i^MTL ≤ R_i^STL + ι_i。当 ι_i 超过阈值时，自动路由到独立适配器/隔离参数，把「隔离」本身写进证书，避免「共享即伤害」。这把「多任务一定互相帮助」这一浪漫假设变成**可在线检验、可失效安全回退**的工程假设。

**灵感 3（竞赛策略 → SPA：带学习效应的随机背包 / bandit）**
直觉：竞赛不是平均成功率，而是**在总预算 T 内最大化总得分**：任务 i 的基础分 s_i、耗时 t_i、尝试次数 m_i、成功率 p_i(m_i)（随练习/尝试上升）。这是带学习效应的随机背包/restless bandit：先做「性价比 s_i·p_i / t_i」高的，还是先做「能提升后续任务」的（迁移）？SPA（Stochastic Portfolio Allocator）用证书给的 p_i、t_i 与迁移矩阵做在线索引分配，并允许**中途重规划**：失败一次不是结束，而是获得一次后验更新与一次重排预算的机会。

**灵感 4（竞赛策略 → ALS：排名风险姿态）**
直觉：排行榜是相对的。领先时应「保分」——低方差、做稳的任务、少冒险；落后时应「搏分」——高方差、高价值任务、允许一次豪赌。ALS（Adaptive Leaderboard Stance）用与领先者的分差 Δ 定义风险姿态 λ_rank ∈ [0,1]，在 E[score] 与 CVaR_α(score)（或 P(rank ≤ k)）之间连续插值。这把「该不该冒险」从拍脑袋变成**带证书的在线决策**。

**灵感 5（合流 → ARENA：赛场自适应风险感知多任务网络配置）**
SOMA 提供能力与迁移；TIC 防负迁移；GRIP 给每个任务的执行证书；SPA 在证书上做预算分配；ALS 调风险姿态；CCA（Correlated Catastrophe Avoidance）处理单模型的**相关性失败**——一个共享主干崩了，多个任务会一起崩。闭环：读取任务集 → SOMA 路由 → TIC 门控 → GRIP 执行 → 证书回写 (p_i, t_i) → 迁移矩阵更新 → SPA/ALS 重分配 → 下一任务。**第 64 轮是「把一件事做稳」，第 65 轮是「把一场比赛打好」：安全语义不变，但优化目标从单点成功率变成整场的得分/排名分布。**

## 1. 形式化定义（增量：定义 217–232）

- **定义 217（ARENA 闭环）**：ARENA = (SOMA, TIC, GRIP, SPA, ALS, CCA, J_arena)。定位：GRIP 之上的「竞赛层」，不替换 GRIP；不变式：**实时执行安全仍由 GRIP 实时流负责；竞赛层只做任务级选择、尝试次数与预算分配，绝不进入实时控制回路**。
- **定义 218（SOMA 单模型多任务策略）**：共享主干 f_s: 𝒪×ℒ→ℋ，任务适配器库 {Δθ_k}，路由 g(ℓ) ∈ Δ^K（软路由）或 top-1（硬路由）。策略 π_θ(a | o, ℓ) = softmax(W_π [f_s(o, ℓ) + Σ_k g_k(ℓ)Δθ_k])。训练目标 L_MTL = Σ_i w_i L_i + λ_s‖θ_s‖² + λ_aΣ_k‖Δθ_k‖²。
- **定义 219（迁移矩阵与任务干扰）**：迁移矩阵 M_ij = E_{x~𝒟_j}[ℓ_j(θ 在任务 i 上微调后)] − E_{x~𝒟_j}[ℓ_j(θ^STL_j)]（负值即负迁移）。任务干扰 ι_i = R_i^MTL(θ_s, θ_i) − R_i^STL(θ_i^STL)。梯度冲突 c_ij = cos(∇_θ L_i, ∇_θ L_j)。迁移估计 M̂_ij 由历史尝试与适配器相似度给出，带置信区间 [M̂_ij − δ_ij, M̂_ij + δ_ij]。
- **定义 220（任务竞赛证书）**：对任务 i，由 J_grip 及其历史执行压缩出 C_i = (p_i^cert, t_i^cert, s_i, ρ_safe,i, q_i^cat)，其中 p_i^cert 为成功率**下界**（置信度 ≥ 1−δ_cert），t_i^cert 为耗时**上分位**（如 90% 分位），s_i 为得分模型参数，q_i^cat 为灾难性失败（损坏/违规/零分）概率上界。
- **定义 221（竞赛得分模型）**：第 m 次尝试的期望得分 S_i(m) = s_i·p_i(m) − c_fail·(1−p_i(m)) − c_time·t_i·m + b_i·1[m ≤ m_i^bonus]，其中 c_fail 为失败/恢复代价，c_time 为时间机会成本，b_i 为连续成功/步数奖励。对 best-of-M 赛制，累计得分 S_i^best(M) = s_i·[1 − (1−p_i)^M] − 惩罚项。
- **定义 222（竞赛目标与排名目标）**：预算约束下 max_{schedule} E[Σ_i S_i(m_i)]，s.t. Σ_i t_i m_i ≤ T、m_i ≤ M_i、ρ_safe,i ≥ 0。排名目标 P(rank ≤ k) = P(Σ_i S_i ≥ θ_k)，其中 θ_k 由对手得分分布 F_{-}(·) 给出；定义 rank-CVaR_α = CVaR_α(−rank) 的等价分位目标。
- **定义 223（SPA 随机预算分配）**：状态 x = (剩余时间 T_rem, 任务后验 {Beta(a_i,b_i)}, 迁移矩阵 M̂, 当前分差 Δ)。动作 a = (任务 i, 是否再试)。SPA 用索引 I_i(x) 排序，I_i 取「单位时间边际期望得分」与「信息/迁移期权价值」之和：I_i = [∂E S_i/∂m_i] / t_i + γ·IG_i(x)，其中 IG_i 为尝试带来的后验熵下降与对其它任务迁移的期望收益；在线用 rollout/UCB 近似，保证 anytime。
- **定义 224（学习曲线与尝试信息增益）**：p_i(m) = 1 − (1−p_i0)·exp(−β_i·m)，β_i 为学习率；一次尝试后的共轭更新 Beta(a_i+1, b_i)（成功）或 Beta(a_i, b_i+1)（失败）。信息增益 IG_i = H(Beta(a_i,b_i)) − E[H(Beta(a_i',b_i'))]。
- **定义 225（风险姿态与排名插值）**：λ_rank = clip(Δ/Δ_0, 0, 1)，Δ 为「我方分数 − 第 k 名分数线」的估计。竞赛目标 J_λ = (1−λ_rank)·E[total score] + λ_rank·CVaR_α(total score)。领先（Δ>0）时 λ→1 偏保守；落后（Δ<0）时 λ→0 偏搏取；λ_rank 每 T_stance 秒重估一次，避免抖动。
- **定义 226（相关性失败与对冲）**：SOMA 的失败事件 F_i 具有共享因子 Z（主干/视觉编码器/规划器），P(F_i=1 | Z=1) = p_shared。CCA 维护一个**异质对冲器** H（独立小模型或经典技能库 + GRIP 安全回退），并保留预算 τ_H。系统失败概率 P(wipeout) ≤ P(Z=1)·P(所有任务都无对冲成功) + (1−P(Z=1))·ε_ind。CCA 在检测到连续失败/置信度骤降时切换到 H 并重排任务。
- **定义 227（J_arena 竞赛证书）**：J_arena = (schedule τ, {J_grip,i}, {C_i}, M̂ 版本, λ_rank, CCA 状态, T_rem, score_lower_bound, rank_bound)。Valid(J_arena) ⇔ 每个已执行任务 Valid(J_grip,i) ∧ 每个未执行任务有保守 C_i ∧ 预算可行 ∧ (CCA 可用 ∨ 已显式接受相关性风险) ∧ 分数下界与排名下界均由证书推导而非拍脑袋。
- **定义 228（任务指令路由与开放词汇）**：给定语言指令 ℓ，任务识别器 r(ℓ) 输出任务 id 与置信度；低置信时允许「组合已知适配器」或「安全探针/请求澄清」。路由错误进入 J_arena 的 `route_uncertain` 字段，使竞赛层可为路由不确定性预留时间/风险预算。
- **定义 229（在线重规划与 anytime 性质）**：每个检查点（任务完成、失败、超时、检测到分布漂移）触发 SPA 重规划。Anytime 性质：任意时刻 t，当前计划 τ_t 都给出剩余预算下的得分下界 L_t，且 L_t 随执行单调不减（失败后因信息增益可暂时下降，但以概率 ≥1−δ 不低于初始下界）。
- **定义 230（跨任务零样本回退）**：若任务 i 无专属适配器，按适配器相似度与技能覆盖率组合 π_i = Σ_k w_ik π_k；若组合置信不足，回退到 TSL 通用技能 + 保守 p_i（取同类任务证书的最小值），并优先安排低风险试跑以收集证据。
- **定义 231（竞赛干扰与 TIC 扩展认证）**：干扰集 ℰ_comp = ℰ_F × {光照/背景变化} × {干扰物/裁判指令歧义} × {时间压力} × {对手行为}。AIC-Comp 在 ℰ_comp 上重算 ρ_dir 与 p_i 下界，并显式认证「时间压力下策略退化」——反应时间缩短会降低 p_i，SCHED 用 p_i(T_rem) 而非常数成功率。
- **定义 232（ARENA 闭环算子）**：语义流（低频）[任务集读取 → SOMA 路由 → TIC 干扰门控 → GRIP 语义流 → 证书压缩 C_i → 迁移矩阵更新 → SPA 分配 → ALS 姿态 → 选下一任务/再试 → CCA 监控]；执行流（每个任务内）[GRIP 实时流：CGG 残差 → SLD 滑移 → FCS 力限 → WCV-F 编译 → π_σ1 派发 → J_grip 构建]；竞赛流（跨任务）[得分记录 → 排名估计 → 预算更新 → anytime 重规划]。

## 2. 关键算法骨架

```python
# SOMA 路由 + TIC 门控
h = backbone(o, ell)
route = route_task(ell)                      # 任务 id + 置信度
g = soft_route(route.id) if route.conf > tau_route else compose_adapters(route)
a = policy_head(h + sum(g[k]*adapter[k] for k in g))
if interference_bound(route.id) > iota_max:   # TIC 拒绝共享
    switch_isolation(route.id)                # 用独立适配器/经典技能

# SPA 竞赛分配（每个检查点）
for checkpoint in schedule_checkpoints:
    Delta = my_score - leaderboard_quantile(k)
    lam = clip(Delta / Delta0, 0, 1)           # ALS 风险姿态
    for i in remaining_tasks:
        C_i = cert_from_history(i)             # (p_i, t_i, s_i, q_i^cat)
        I_i = marginal_score_density(C_i) + gamma * info_gain(i) + migr_option(i)
    pick i* = argmax_i I_i subject to T_rem >= t_i*  and  rho_safe(i*) >= 0
    m_i = choose_attempts(C_i, lam, T_rem)     # 由目标 J_lam 决定
    run_task(i*, m_i)                          # 内部走 GRIP 实时流

# CCA 相关性失败对冲
if consecutive_failures >= c_hat or confidence_drop(x):
    switch_to_hedge(H); replan(avoid_shared_factor=True)
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 7（多任务干扰可证伪）**：若任务 i 的梯度与共享更新方向夹角满足 cos ≤ c_max，且共享表征漂移 ‖Δh‖ ≤ δ_h，则 R_i^MTL − R_i^STL ≤ L_h·δ_h + L_θ·c_max/(1−c_max)·‖g_i‖/μ；TIC 在线估计右侧各项，超过阈值即隔离。**推论**：多任务不是无条件变好，但「变坏多少」有证书，可据此决定共享哪些参数。
- **引理 8（竞赛得分下界）**：若每任务 p_i^cert 以 ≥1−δ_cert 覆盖真实成功率、t_i^cert 覆盖真实耗时、失败代价有界，则对任意满足预算的调度 τ，整场得分满足 P[Score(τ) ≥ Σ_i S_i^lower(m_i)] ≥ 1−Nδ_cert。**推论**：证书可直接给出「保守可承诺的分数」，竞赛策略只在这个下界上做优化，避免用乐观估计透支预算。
- **定理 7（竞赛分配近似最优与姿态单调性）**：在任务独立、可分数预算、学习曲线单调的假设下，SPA 的索引贪心是随机背包的常数近似（1/2 级）；当引入迁移矩阵后，索引增加「期权价值」项不降低近似比。且最优风险姿态 λ* 关于分差 Δ 单调：领先越大越保守、落后越大越搏取——**这为 ALS 的插值方向提供了理论依据**。
- **定理 8（ARENA 端到端）**：Valid(J_arena) ⇒ (i) 每个执行任务仍满足 GRIP 四层安全；(ii) 整场得分以 ≥1−Nδ_cert 不低于证书下界；(iii) 排名概率下界可由下界分数与对手分布保守估计；(iv) 单模型相关性失败被 CCA 对冲，wipeout 概率 ≤ 定义 226 的界；(v) 实时路径不因竞赛层增加而超 2ms（竞赛层只在语义流/检查点运行）。
- **实时性**：竞赛层在语义流（10–100Hz 之外，通常 ≤1Hz 检查点）；GRIP 实时流不变，新增的只有任务切换时的适配器加载（预加载池，切换 <5ms，且发生在任务边界而非实时控制内）。

## 5. 本轮最大风险

**一句话**：若每任务的 `p_i^cert` 被高估，或单模型的失败在任务间高度相关（共享主干/视觉编码器同源崩溃），SPA 会把预算集中投给「看起来高价值、实则会同源一起崩」的任务，ALS 在落后时又进一步放大这种集中——**「证书约束下的最优组合」反而制造风险集中与相关性灾难；这是本轮所有得分下界与排名论证共同依赖的隐藏假设：证书独立、失败不相关。**

# 第 65 轮产物 · 创新点清单 v1：ARENA（Arena-adaptive Risk-aware Embodied multi-task Network Allocation：单模型多任务 × 迁移/干扰证书 × 竞赛级预算分配 × 排名风险姿态，SOMA×TIC×MCC×SPA×ALS×CCA×ROA×AIC-Comp×ARP×J_arena）

## 2. 形式化定义（完整版）

**定义 217（ARENA 闭环）** ARENA 是挂载在 GRIP 之上的竞赛层：ARENA = (SOMA, TIC, GRIP, SPA, ALS, CCA, ROA, AIC-Comp, ARP, J_arena)。它不改变 GRIP 的实时安全流，只在其上增加「任务级选择、尝试次数、预算与风险姿态」三类决策。不变式：**(I1) 实时控制路径仍只含 GRIP 组件，零学习写操作；(I2) 任何竞赛决策不得绕过 ρ_safe ≥ 0 的硬安全下界；(I3) 竞赛层的一切估计都带置信区间显式写入 J_arena。**

**定义 218（SOMA 单模型多任务策略）** 共享主干 f_s: 𝒪×ℒ→ℋ；适配器库 {Δθ_k}_{k=1}^K，每个 Δθ_k 为低秩增量（rank r_a ≪ d）；路由 g(ℓ) = softmax(W_g·e(ℓ)/τ_g)，其中 e(ℓ) 为指令嵌入。策略
π_θ(a | o, ℓ) = softmax(W_π [f_s(o, ℓ) + Σ_k g_k(ℓ)·Δθ_k])。
训练：L_MTL = Σ_i w_i L_i(θ_s, {Δθ_k}) + λ_s‖θ_s‖² + λ_aΣ_k‖Δθ_k‖² + λ_r‖g(ℓ)‖₁（稀疏路由，鼓励技能复用）。推理时按任务 id 硬路由或 top-2 软组合；无专属适配器时按 ROA 组合已知适配器。

**定义 219（迁移矩阵、干扰与 TIC）** 定义任务 i 对任务 j 的迁移
M_ij = E_{x∼𝒟_j}[ℓ_j(θ_s^{(i)}, θ_j)] − E_{x∼𝒟_j}[ℓ_j(θ_j^STL)]，
负值表示负迁移。梯度冲突 c_ij = cos(∇_{θ_s}L_i, ∇_{θ_s}L_j)。TIC 维护在线估计 (M̂_ij, δ_ij) 与干扰上界
ι_i ≤ L_h·δ_h + η·L_θ·‖g_i‖·Σ_{j≠i} w_j‖g_j‖·[−c_ij]_+，
其中 δ_h 为共享表征漂移，L_h、L_θ 为 Lipschitz 常数，η 为共享学习率。若 ι_i > ι_max 或 c_ij < −c_max，则对该任务执行 `isolate(i)`：分配独立适配器（不共享梯度），并在 J_arena 中记录 `isolated(i)=True`。隔离不是失败，而是**用容量换可靠性**的显式选择。

**定义 220（任务竞赛证书 MCC）** 对任务 i，由历史 J_grip 与执行日志压缩
C_i = (p_i^cert, t_i^cert, s_i, ρ_safe,i, q_i^cat)：
- p_i^cert = 成功率经验估计的 Clopper-Pearson 下界（置信度 1−δ_cert），再按 AIC-Comp 的干扰/时间压力校正 p_i^cert ← p_i^cert·(1−ε_T(T_rem))；
- t_i^cert = 耗时经验分布的 90% 分位；
- s_i 为官方得分模型参数（基础分、步骤分、惩罚、best-of-M）；
- ρ_safe,i = min_t ρ_safe 的历史下界；
- q_i^cat = 灾难性失败（损坏/违规/越界）频率的置信上界。
MCC 的职责是**把连续执行证据变成离散竞赛决策可用的保守数**。

**定义 221（竞赛得分模型）** 任务 i 第 m 次尝试的期望得分
S_i(m) = s_i·p_i(m) − c_fail·(1−p_i(m)) − c_time·t_i·m + b_i·1[m ≤ m_i^bonus]，
其中 c_fail 包含恢复时间与重置成本，c_time 为时间机会成本。best-of-M 赛制下
S_i^best(M) = s_i·[1−(1−p_i)^M] − c_fail·(1−p_i)^M − c_time·t_i·M。
多任务总分 Score(τ) = Σ_i S_i(m_i)，m_i 为调度 τ 给任务 i 的尝试次数。

**定义 222（竞赛目标与排名目标）** 预算约束优化
max_τ E[Score(τ)]  s.t.  Σ_i t_i^cert·m_i ≤ T，m_i ≤ M_i，ρ_safe,i ≥ 0，q_i^cat ≤ q_max。
排名目标：设对手总分分布 F_-(·)，则 P(rank ≤ k) = P(Score(τ) ≥ θ_k)，θ_k = F_-^{-1}(1−k/(n_opp+1))。等价地定义 rank-CVaR_α = CVaR_α(−rank(Score))，用于在分差信息不足时做稳健排名优化。

**定义 223（SPA 随机预算分配）** SPA 的信念状态 x = (T_rem, {Beta(a_i,b_i)}, {M̂_ij}, Δ)。对每个候选任务 i 计算索引
I_i(x) = [∂E S_i/∂m_i]/t_i^cert + γ·IG_i(x) + γ_M·Σ_j |M̂_ij|·w_j,
第一项为「单位时间边际得分」，第二项为「尝试带来的信息期权」，第三项为「练习本任务对其它任务的迁移期权」。选择 i* = argmax_i I_i，s.t. T_rem ≥ t_i^cert 且 ρ_safe,i ≥ 0 且 q_i^cat ≤ q_max。尝试次数 m_i* 由在 J_λ 上的一维搜索给出：
m_i* = argmax_{0≤m≤M_i} E[Σ_j S_j(m_j) | m_i=m] − λ_rank·CVaR 惩罚。
SPA 在任务边界/失败/超时/漂移检查点重算，复杂度 O(N²)（N 为任务数，通常 ≤20），对实时路径零影响。

**定义 224（学习曲线与尝试信息增益）** 成功率随尝试单调上升：p_i(m) = 1−(1−p_i0)e^{−β_i m}；一次尝试后 Beta 后验更新：成功 (a_i+1,b_i)，失败 (a_i,b_i+1)。信息增益
IG_i = H(Beta(a_i,b_i)) − E_{outcome}[H(Beta(a_i',b_i'))]，
并附加迁移期权项：一次成功尝试使 M̂_i· 的置信区间收窄，其期望价值按定义 223 第三项计入。**这解释了为什么「先做能教会你其它任务的任务」在竞赛里可能优于纯密度贪心。**

**定义 225（风险姿态与排名插值）** 设 Δ = 我方当前分 − 第 k 名分数线估计，λ_rank = clip(Δ/Δ_0, 0, 1)。竞赛目标
J_λ = (1−λ_rank)·E[Score] + λ_rank·CVaR_α(Score)。
领先（Δ>0）时 λ→1，优化尾部下界、偏好低方差任务与已认证尝试；落后（Δ<0）时 λ→0，允许高方差高价值任务与额外尝试。λ_rank 每 T_stance 秒或每 3 个任务重估，并加迟滞（hysteresis）防抖。**安全硬下界 ρ_safe ≥ 0 与 q_i^cat ≤ q_max 不受 λ 影响**——姿态只调整风险偏好，不调整安全红线。

**定义 226（相关性失败与 CCA 对冲）** 设共享因子 Z ∈ {0,1}（主干/视觉编码器/世界模型失效），P(Z=1)=p_shared。任务 i 在 Z=1 时失败概率 p_i^shared，在 Z=0 时失败概率 ε_i^ind。CCA 维护异质对冲器 H（独立小模型或 TSL 经典技能 + GRIP 安全回退），保留预算 τ_H（时间与尝试次数）。系统整体失败（wipeout）界：
P(wipeout) ≤ p_shared·Π_i(p_i^shared·(1−h_i)) + (1−p_shared)·Π_i ε_i^ind·(1−h_i)，
其中 h_i 为对冲器在任务 i 上可用的概率/成功率下界。CCA 触发条件：连续失败 ≥ c_hat、任务成功率后验均值跌破 p_min、或路由/置信度骤降。触发后切 H、把共享因子相关任务排到后面、重算 MCC 的 p_i^cert。

**定义 227（J_arena 竞赛证书）** J_arena = (τ, {J_grip,i}_{i∈executed}, {C_i}_{i∈planned}, M̂ 版本, λ_rank, CCA 状态, T_rem, L_score, L_rank)。验证规则：
Valid(J_arena) ⇔ (∀i∈executed: Valid(J_grip,i)) ∧ (∀i∈planned: C_i 由 ≥n_min 次证据导出或显式标记 `weak_cert`) ∧ Σ t_i^cert m_i ≤ T ∧ (∀i: ρ_safe,i ≥ 0 ∧ q_i^cat ≤ q_max) ∧ (CCA 可用 ∨ `correlated_risk_accepted`) ∧ L_score ≤ E[Score] 且 L_rank 由 L_score 保守推出。
审计链：J_grip,i → 任务 i 的执行证据；C_i → 成功率/耗时/灾难的统计来源；M̂ → 迁移估计样本；λ_rank → 分差估计；CCA → 对冲器可用性。

**定义 228（ROA 指令路由与开放词汇）** 任务识别器 r(ℓ) 输出 (id, conf)。若 conf ≥ τ_route：硬路由到 id。若 τ_low ≤ conf < τ_route：top-2 适配器软组合，并在 J_arena 记 `route_uncertain=1`，为澄清/试跑预留 τ_route 预算。若 conf < τ_low：执行安全探针（低风险试动作）或请求澄清；不得在高不确定下直接消耗高价值任务预算。路由错误的代价通过 `q_i^cat` 与 p_i^cert 的保守校正计入。

**定义 229（MML 迁移矩阵学习与 ARP anytime 重规划）** MML 用三类证据更新 M̂：① 历史「在 i 上练习后 j 的表现变化」；② 适配器相似度（低秩子空间夹角）；③ TIC 的梯度冲突符号。带遗忘因子 ρ_M 的递推最小二乘给出 M̂ 与置信区间。ARP 在每个检查点执行：重算 T_rem、后验 Beta、M̂、Δ 与 λ_rank；输出新调度 τ_t 与得分下界 L_t。Anytime 性质：在任意检查点，L_t 由当前证书与剩余预算单调构造；失败后 L_t 可因证据变少而下降，但以概率 ≥1−δ 不低于初始保守下界（定义 220 的下界本身已含该保守性）。

**定义 230（跨任务零样本回退）** 若任务 i 无专属适配器，按适配器相似度 w_ik ∝ exp(−d(ℓ_i, ℓ_k)/τ_w) 组合 π_i = Σ_k w_ik π_k；若组合的证书 `weak_cert`，取同族任务 p 的最小值作为 p_i^cert、t_i^cert 取最大值，并优先安排一次低风险试跑（试跑不计分或低分）以收集证据。若仍无同族任务，回退 TSL 通用技能（抓取/放置/推/拉/点按）并置 `zero_shot=True`。

**定义 231（AIC-Comp 竞赛干扰认证）** 干扰集
ℰ_comp = ℰ_F × {光照/背景变化} × {干扰物/裁判指令歧义} × {时间压力} × {对手行为}。
在 ℰ_comp 上重算 ρ_dir 与 p_i^cert；时间压力项：τ_react = clip(T_rem/T_total,0,1)，p_i^cert(T_rem) = p_i^cert·(1−ε_T·(1−τ_react))，使**越临近结束，认证成功率越低**，避免「按满预算成功率排程、最后却做不完」。认证报告增 `comp_calib_ver` 与 `time_pressure_curve`。

**定义 232（ARENA 闭环算子）** 见 IP-223 伪代码。三条流：
- **语义流（低频）**：[任务集读取 → ROA 路由 → SOMA 适配器选择 → TIC 干扰门控 → GRIP 语义流 → MCC 压缩证书 → MML 更新迁移 → SPA 分配 → ALS 姿态 → ARP 重规划 → 选下一任务/再试 → CCA 监控]；
- **执行流（任务内）**：[GRIP 实时流：CGG 残差 → SLD 滑移 → FCS 力限 → WCV-F 编译 → π_σ1 派发 → J_grip 构建]；
- **竞赛流（跨任务）**：[得分记录 → 对手/分数线估计 → 预算更新 → anytime 重规划 → J_arena 构建]。

### IP-214/215 SOMA + TIC（单模型路由与干扰门控）

```python
class SOMA:
    def __init__(self, backbone, adapters, router, rank=8):
        self.f_s, self.adapters, self.router = backbone, adapters, router

    def forward(self, obs, instruction):
        h = self.f_s(obs, instruction)
        route = self.router(instruction)              # (task_id, conf)
        if route.conf >= TAU_ROUTE:
            g = one_hot(route.task_id)
        elif route.conf >= TAU_LOW:
            g = self.router.soft_top2(instruction)    # 组合已知适配器
        else:
            g = None                                  # 交给 ROA 探针/澄清
        if g is None:
            return self.zero_shot_or_probe(obs, instruction)
        h_task = h + sum(g[k] * self.adapters[k].delta for k in topk(g))
        return policy_head(h_task), route

class TIC:
    def __init__(self, iota_max=0.05, c_max=0.2):
        self.iota_max, self.c_max = iota_max, c_max
        self.M_hat = defaultdict(lambda: (0.0, np.inf))   # (mean, 95% CI)

    def bound(self, i, grads, drift, lipschitz):
        L_h, L_theta, eta = lipschitz
        harmful = 0.0
        for j, gj in grads.items():
            if j == i:
                continue
            c = cosine(grads[i], gj)
            harmful += max(0.0, -c) * norm(gj)
        return L_h * drift + eta * L_theta * norm(grads[i]) * harmful

    def gate(self, i, grads, drift, lipschitz):
        iota = self.bound(i, grads, drift, lipschitz)
        if iota > self.iota_max or min_cosine(grads, i) < -self.c_max:
            return 'isolate', iota                     # 独立适配器，不共享梯度
        return 'share', iota

    def update_migration(self, i, j, delta_perf):
        mu, ci = self.M_hat[(i, j)]
        self.M_hat[(i, j)] = ewma_update(mu, ci, delta_perf)
```

### IP-216/217 MCC + SPA（证书压缩与竞赛分配）

```python
def build_mission_cert(task_id, grip_logs, aic_comp, T_rem, T_total):
    succ = [ev.success for ev in grip_logs]
    p_lo = clopper_pearson_lower(sum(succ), len(succ), delta_cert)
    p_lo = p_lo * (1 - aic_comp.eps_T * (1 - clip(T_rem / T_total, 0, 1)))
    t_hi = quantile([ev.duration for ev in grip_logs], 0.9)
    cat_hi = clopper_pearson_upper(catastrophes(grip_logs), len(grip_logs), delta_cert)
    rho_safe = min(ev.rho_safe for ev in grip_logs)
    return MissionCert(p=p_lo, t=t_hi, s=score_params(task_id),
                       rho_safe=rho_safe, q_cat=cat_hi)

class SPA:
    def __init__(self, N, T, M_max, gamma=0.3, gamma_M=0.2):
        self.T, self.M_max = T, M_max
        self.posterior = {i: Beta(1, 1) for i in range(N)}
        self.gamma, self.gamma_M = gamma, gamma_M

    def index(self, i, certs, M_hat, T_rem):
        p = self.posterior[i].mean()
        t = certs[i].t
        marginal = score_density(certs[i], p, t)            # dE[S_i]/dm / t
        ig = self.gamma * information_gain(self.posterior[i])
        migr = self.gamma_M * sum(abs(M_hat[(i, j)][0]) * w[j] for j in others(i))
        return marginal + ig + migr

    def allocate(self, certs, M_hat, lam_rank, T_rem):
        plan = {}
        while T_rem > 0:
            cand = [i for i in certs
                    if certs[i].t <= T_rem and certs[i].rho_safe >= 0
                    and certs[i].q_cat <= Q_MAX and plan.get(i, 0) < self.M_max]
            if not cand:
                break
            i = max(cand, key=lambda k: self.index(k, certs, M_hat, T_rem))
            m = self.choose_attempts(i, certs[i], lam_rank, T_rem)
            plan[i] = plan.get(i, 0) + max(1, m)
            T_rem -= certs[i].t * max(1, m)
        return plan

    def choose_attempts(self, i, cert, lam_rank, T_rem):
        best_m, best_val = 0, -np.inf
        for m in range(0, self.M_max + 1):
            if m * cert.t > T_rem:
                break
            mean = expected_score(cert, m)
            cvar = cvar_score(cert, m, alpha=0.05)
            val = (1 - lam_rank) * mean + lam_rank * cvar
            if val > best_val:
                best_m, best_val = m, val
        return best_m
```

### IP-218/219 ALS + CCA（风险姿态与相关性对冲）

```python
class LeaderboardStance:
    def compute(self, my_score, cutline_estimate, Delta0):
        Delta = my_score - cutline_estimate
        return clip(Delta / Delta0, 0.0, 1.0)       # 1=保守，0=搏取

class CorrelatedCatcher:
    def __init__(self, hedge, tau_H=0.15, c_hat=2, p_min=0.2):
        self.hedge, self.tau_H = hedge, tau_H
        self.c_hat, self.p_min = c_hat, p_min
        self.fail_streak = 0

    def observe(self, outcome, posterior_mean):
        self.fail_streak = self.fail_streak + 1 if not outcome.success else 0
        triggered = (self.fail_streak >= self.c_hat) or (posterior_mean < self.p_min)
        if triggered:
            return 'switch_hedge', self.hedge.reserve(self.tau_H)
        return 'stay', None

    def wipeout_bound(self, p_shared, p_shared_i, h_i, eps_ind):
        shared = p_shared * np.prod([p * (1 - h) for p, h in zip(p_shared_i, h_i)])
        indep = (1 - p_shared) * np.prod([e * (1 - h) for e, h in zip(eps_ind, h_i)])
        return shared + indep
```

```python
def ARENA_campaign(tasks, T_total, M_max, opponents):
    M = SOMA.load(); tic = TIC.load(); spa = SPA(len(tasks), T_total, M_max)
    cca = CorrelatedCatcher(hedge=ClassicHedge()); stance = LeaderboardStance()
    certs = {i: build_mission_cert(i, grip_history[i], aic_comp, T_total, T_total)
             for i in tasks}

        Delta = estimate_gap(my_score(executed), opponents, k=TARGET_RANK)
        lam = stance.compute(my_score(executed), cutline(opponents, k=TARGET_RANK), DELTA0)
        plan = spa.allocate(certs, tic.M_hat, lam, T_rem)
        if not plan:
            break
        i = next(iter(plan))                       # 已按索引排序
        m = plan[i]
        for attempt in range(m):
            if T_rem < certs[i].t:
                break
            route = M.forward(obs_i, instruction_i)
            if route.conf < TAU_LOW:
                outcome = ROA.safe_probe_or_clarify(i)      # 不计高价值分
            else:
                outcome, J_grip, elapsed = GRIP_round_with_cert(i, route)
            T_rem -= elapsed
            spa.posterior[i].update(outcome.success)
            tic.update_migration(i, i, outcome.transfer_delta)
            certs[i] = update_cert(certs[i], J_grip, outcome, T_rem, T_total)
            executed.append((i, outcome, J_grip))
            state, reserve = cca.observe(outcome, spa.posterior[i].mean())
            if state == 'switch_hedge':
                outcome2 = cca.hedge.run(i, reserve)
                executed.append((i, outcome2, None))
                break
            if T_rem <= 0:
                break
        tasks.remove(i) if plan.get(i, 0) >= M_max else None
        if T_rem <= 0:
            break
    L_score = sum(lower_bound(c) for c in certs.values())
    L_rank = rank_lower_bound(L_score, opponents, k=TARGET_RANK)
```

## 4. 推导

**引理 7（多任务干扰可证伪）** 设共享参数 θ_s 的更新为 Δθ_s = −η Σ_j w_j g_j，g_j = ∇_{θ_s}L_j。对任务 i 做一阶展开：
R_i(θ_s+Δθ_s) − R_i(θ_s) ≈ g_iᵀΔθ_s = −η( w_i‖g_i‖² + Σ_{j≠i} w_j g_iᵀg_j )。
记 c_ij = cos(g_i,g_j)，仅保留有害项（c_ij<0）：
ι_i ≤ η‖g_i‖Σ_{j≠i} w_j‖g_j‖[−c_ij]_+ + L_h‖Δh‖。
由 Lipschitz 性把表征漂移项写为 L_hδ_h。因此 **干扰上界可由梯度冲突的负部与表征漂移在线估计**；当右端 > ι_max 时隔离适配器即可把该项从共享路径移除。∎

**引理 8（竞赛得分下界）** 对每个任务 i，设 Clopper-Pearson 下界 p_i^cert 满足 P(p_i^true ≥ p_i^cert) ≥ 1−δ_cert，耗时上界 t_i^cert 满足 P(t_i^true ≤ t_i^cert) ≥ 1−δ_t。对固定调度 τ（m_i 次尝试），由并集界，所有任务同时覆盖的概率 ≥ 1−N(δ_cert+δ_t)。在该事件上，
Score(τ) ≥ Σ_i [s_i(1−(1−p_i^cert)^{m_i}) − c_fail(1−p_i^cert)^{m_i} − c_time t_i^cert m_i] := L_score(τ)。
故证书直接给出**可承诺的分数下界**；SPA 的优化只需在这个下界上做，而 ALS 的 CVaR 项用下界分布而非点估计。∎

**定理 7（竞赛分配的近似最优与姿态单调性）** 在任务相互独立、预算可分数、学习曲线非降的假设下，SPA 的索引贪心等价于自适应随机背包的密度贪心，具有常数近似比（1/2 级；加入迁移期权项后仍不劣化，因为期权价值非负且与预算约束同向）。设两任务 A、B，A 的方差大于 B 而期望相近；目标 J_λ 对 λ 的导数由尾部项主导。当落后（Δ<0）时 λ→0，最优解偏向高方差高价值 A；当领先（Δ>0）时 λ→1，最优解偏向低方差 B。由一阶随机占优，argmax 的任务选择关于 λ 单调，故 λ*(Δ) 单调。∎

**定理 8（ARENA 端到端）** 假设第 64 轮 A83–A87 及：
- **(A88)** SOMA 的适配器在任务分布内可近似对应单任务策略，TIC 的 ι_i 上界有效；
- **(A89)** MCC 的 p_i^cert、t_i^cert、q_i^cat 按 δ_cert 覆盖真实值；AIC-Comp 的时间压力校正有效；
- **(A90)** SPA 的迁移与学习曲线模型在竞赛任务集上近似成立（或由保守 p_i 覆盖其偏差）；
- **(A91)** CCA 对冲器与共享主干在失败因子上非完全相关，h_i 有下界；
- **(A92)** 竞赛层只在检查点运行，任务切换的适配器加载 <5ms 且发生在任务边界。
则：
1. **执行安全不变**：每个执行任务仍满足 GRIP 四层安全链；ρ_safe ≥ 0 与 q_i^cat ≤ q_max 是硬约束，不随 λ 放松。
2. **得分可承诺**：P[Score ≥ L_score] ≥ 1−N(δ_cert+δ_t)。
3. **排名可估计**：P[rank ≤ k] ≥ P[Score ≥ θ_k] 由 L_score 与对手分布的保守分位给出。
4. **相关性可控**：P(wipeout) ≤ 定义 226 的界；CCA 触发后 p_i^cert 与调度重算。
5. **优雅降级**：路由不确定 → 组合适配器/探针；单模型失效 → CCA 对冲；时间不足 → 只做已认证低风险任务；力/几何失效 → 回落第 64 轮 GRIP 与 safe_idle。
6. **实时性不变**：GRIP 实时路径 ≤2ms；竞赛层不进入实时控制。∎

**命题（单模型多任务的竞赛净收益）** 设单任务独立训练需 m_i 个演示、总数据 M = Σm_i；SOMA 共享主干使每任务所需演示降为 m_i' = m_i/(1+κ·(N−1)/N)（κ 为共享结构强度），则总数据降至 M' ≈ M/(1+κ(N−1)/N)。竞赛净收益 ΔScore ≈ Σ_i s_i(p_i(m_i')−p_i(m_i)) − Σ_i c_failΔ(1−p_i) − TIC 隔离带来的容量损失。**只有当迁移项超过负迁移与隔离损失时，单模型才在竞赛意义上划算**——这也解释了为何需要 TIC 与迁移矩阵，而不能只看参数量。∎

**正确性定理（ARENA-Complete）** 见定理 8。核心是**把「任务已给定、时间充裕、单次安全」三个隐含假设显式化为竞赛层的决策变量**，并让每个决策都绑定保守证书：得分下界、排名下界、相关性上界。竞赛层不制造新的安全假设，只争夺「在安全前提下如何分配有限时间与尝试」。

## 7. 已知风险

**一句话**：若每任务的 `p_i^cert` 被高估，或单模型的失败在任务间高度相关（共享主干/视觉编码器同源崩溃），SPA 会把预算集中投给「看起来高价值、实则会同源一起崩」的任务，ALS 在落后时又进一步放大这种集中——**「证书约束下的最优组合」反而制造风险集中与相关性灾难；这是本轮所有得分下界与排名论证共同依赖的隐藏假设：证书独立、失败不相关（A88–A91）。**

**次级风险与缓解**：
1. **证书过度自信 / 分布漂移**：p_i^cert 由历史证据导出，赛场分布外会失效；缓解：AIC-Comp 的干扰/时间压力校正 + `weak_cert` 显式标记 + 在线 Beta 后验覆盖 + 每任务至少一次低风险试跑。
2. **相关性失败被低估**：p_shared 难估计；缓解：CCA 用异质对冲器（经典技能库/独立小模型）+ 保守 h_i 下界 + 连续失败触发；把 `correlated_risk_accepted` 写入 J_arena，不允许静默忽略。
3. **负迁移与隔离损失**：TIC 上界依赖 Lipschitz 常数与梯度估计；缓解：离线标定 + 在线 c_ij 监测 + 隔离后仍可用适配器组合。
4. **路由错误消耗高价值预算**：开放词汇指令歧义；缓解：ROA 低置信探针/澄清 + 路由不确定预算 + 路由错误计入 q_i^cat。
5. **对手/分数线建模错误**：排名目标依赖 F_-；缓解：用 rank-CVaR 而非点估计，λ_rank 加迟滞，落后时才放大方差。
6. **时间压力下的非线性退化**：p_i 随 T_rem 退化可能非线；缓解：分段标定 time_pressure_curve，临近结束只做已认证任务。
7. **得分模型被钻空子（reward hacking）**：步骤分/部分分可能被策略利用；缓解：s_i 与官方规则对齐、惩罚项 c_fail 硬约束、禁止以违规换分。
8. **安全被竞赛目标挤压**：搏分姿态可能诱导高风险动作；缓解：ρ_safe ≥ 0 与 q_i^cat ≤ q_max 是**不随 λ 变化的硬约束**，FCS 力限与 CGG 接地始终在线。
9. **单模型算力/功耗**：共享主干 + 多适配器加载影响续航；缓解：适配器预加载池、量化/蒸馏、按任务边界切换。
10. **仿真到赛场的 gap**：赛制、道具、光照与裁判行为差异；缓解：域随机化 + 赛场标定日采集 + AIC-Comp 干扰认证 + 首任务保守试跑。
