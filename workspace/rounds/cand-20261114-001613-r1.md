# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「移动底盘」×「商业模式」）

> R69 把不确定性一分为二（aleatoric / epistemic），用「流匹配多模态策略 + 主动多模态交互」去消解后者，并把「问错」列为最大风险。但它仍然默认了一件从未被检验的事：**安全是免费的、且该被无限最大化**。交互预算、λ_floor、算力、停机时间统统是外生常数；系统只会问「还能不能更稳」，不会问「这份稳值多少钱、由谁付账、付不起时该把风险转给谁」。当机器人以卖断 / 租赁 / 按任务计费 / 保险共担等不同商业形态 deployment 时，同一套「无脑收紧」策略在经济上是错的：有的契约要求高可用（停不起），有的契约只要求事故赔付上限（慢一点无所谓），有的契约把灾难风险外部化给保险方（道德风险）。
>
> 本轮两个灵感正好补上这个缺口：
> - **移动底盘**是机器人里最商品化、最资产化的一层：轮速计 / IMU / 电机电流 / 电池内阻 / 对接力给它**廉价且冗余的物理证据**，同时它的折旧、停机与维修定义了**经济成本**。它为 R66–R69 的抽象安全层提供了第一条真正意义上的「资产级计量」。
> - **商业模式**本质是**给风险定价的契约**：SLA、停机罚金、免赔额、责任归属诱导出风险影子价格 μ。商业模式不是商业计划书，而是**把「安全」从最大化问题变成带预算约束的优化问题**的那组权重。
>
> 核心命题：**给闭环加一层「经济计量」，用契约诱导的风险价格 μ 决定每一次干预是否值得；但风险必须分层——catastrophic（不可逆、外部性）永不交易，只有 non-catastrophic（可恢复的延迟 / 轻微碰撞 / 任务失败）允许按 μ 交易。** 每一笔安全干预都要像复式记账一样「有借必有贷」：借方是真实付出的时间 / 能量 / 算力 / 人力，贷方是**经认证**的风险下降；未认证的收益只能记为「应收」，不能用来给干预融资。命名 **LEDGER-RAS**（Liability- and Economics-aware Deployment Governor for Embodied Robots）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这份安全值多少、谁买单、付不起时风险转给谁**」——安全不是无限供应的公共品，而是一份必须做平、且不能把灾难记成利润的账。

## 0. 直觉与动机

**灵感 1（移动底盘 = 商品化的物理基座，天然是「计量层」）**
直觉：底盘是机器人里最像「家电」的部分——大批量、标准化、传感器便宜且冗余。轮速计与 IMU 互相印证，电机电流反映负载，电池内阻反映老化，对接力反映接触是否到位。它不需要昂贵的大模型就能给出高频、低延迟、与主感知**独立**的一致性证据。R69 的第二意见来自「动作在策略下的似然」（行为自洽），底盘给的则是「物理量之间是否自洽」（硬件自洽）；两条通道的失效模式几乎正交。更关键的是，底盘是**资产**：折旧、续航、停机、维修都由它定义。安全层第一次有了可被经济计量的物理载体。

**灵感 2（商业模式 = 风险的价格表，不是背景板）**
直觉：同一个「减速 20%」动作，在卖断契约里是 owner 的 20% 产能损失，在租赁契约里是 provider 的租金损失，在按任务计费里是违约风险，在保险共担里可能只是保费的精算微调。**动作没变，价格变了**。因此「最优 λ」不是一个安全常数，而是契约参数 (C_fail, C_downtime, D, p_cat, SLA) 的函数。R68/R69 的 λ_floor 对应契约的极端情形：事故成本无穷大、警戒成本为零、交互预算无限——即「安全不计价」。这解释了为什么前几轮的策略在安全上很漂亮、在经济上却不可部署：它们解的是 μ→∞ 的极限，而真实契约的 μ 是有限的。

**灵感 3（风险必须分层，否则「可交易」会吞掉「不可交易」）**
直觉：只引入 μ 是危险的。如果所有风险都可按价格交易，一个把灾难风险外部化的契约（保险赔付、责任转移、监管缺口）会诱导 μ_cat→0，系统就会「理性地」用一次低概率灾难去换稳定吞吐——这正是道德风险。所以第一刀不是定价，而是**分层**：catastrophic 风险（人身伤害、不可逆环境破坏、重大财产损失）永不进入交易，始终走 R68 的最保守包络；只有 non-catastrophic 风险（可恢复延迟、轻微剐蹭、任务失败、返工）才允许按 μ 权衡。**安全地板不上市，地板之上的效率才上市。**

**灵感 4（复式记账 = 让「安全」可审计、可融资、不可造假）**
直觉：R69 最大的隐患是「把一次误导性回答盖上已验证的章」。经济层会把这个隐患放大成「把一笔没发生的风险下降记成资产」。会计给的解法是复式记账：每笔干预都有借方（真实成本）与贷方（风险下降），且贷方必须**可复现认证**。未经独立认证的收益只能记为「未实现信用」（应收账款），不能用于给下一次干预融资。账本 append-only、哈希链、强制配平；出现「安全透支」（无资金来源的干预）就触发降级 / 停机，而不是默默记账。这把 R69 的证据纪律从「防被骗」升级为「防被做成漂亮的账」。

**灵感 5（底盘冗余 = 与主感知正交的第二意见，补 R68 的洞）**
直觉：R68 的缓变故障能被标定吸收，因为标定只看传感器残差；R69 用策略似然做第二意见。底盘给第三条通道：**轮速积分 vs IMU vs 视觉里程计 vs 电机电流负载模型**的四路互证。打滑、编码器偏置、电池内阻上升、轮胎磨损都会在底盘通道留下与主感知无关的签名。它便宜、在 MCU 上就能跑、且无法被「视觉标定」抹平。

**灵感 6（规模化是双刃剑：联邦先验 vs 生态谬误 vs 跨租户投毒）**
直觉：底盘商品化的最大红利是车队级数据——同一型号的退化曲线可以互相借力，冷启动不再靠单机。但商业模式意味着**多租户**：数据共享受合同与隐私约束，且一个租户可以污染共享先验。更隐蔽的是**生态谬误**：车队均值会把单台故障平均掉（偏移 b_i 只让均值动 b_i/N），于是「车队很健康」与「这台快坏了」可以同时成立。所以联邦先验必须配 per-asset 后验告警与鲁棒聚合，否则规模化恰恰是「缓变故障隐形」的新版本。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（LEDGER-RAS 总览）** LEDGER-RAS = (EBM, RP, CHS, CRF, FAP, DEL, EAG, RTA, EDM, SFE, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；μ 与账本只能慢环更新）；
(ii) **无无源安全（funded-safety）**：任何干预必须由预算或经认证的贷方融资；不得用未实现信用为干预付款；
(iii) **责任守恒**：任何风险转移必须写账并留下责任归属；风险不能在账上消失（不承认「责任洗白」）。

**定义 311（商业模式契约 C）** 契约 C = (主体 payer, 支付结构, SLA, 责任划分 liability, 免赔额 D, 罚金 penalty, 时域 horizon)。四个原型：(a) **卖断 capex**：买方承担故障与停机，卖方承担保修；(b) **租赁 / RaaS**：提供方承担停机、维修与可用率；(c) **按任务计费 per-task**：提供方承担验收前失败与返工；(d) **保险 / 共担 insured**：免赔额以上由保险方支付。契约决定「谁承担哪一项成本」，因而决定部署策略应使用的成本权重——**必须用实际承担者的权重，而非运营方的私人成本**，否则把外部性当成免费。

**定义 312（契约诱导的成本泛函）** 给定策略 π，契约成本
J_C(π) = E[ C_f·ℓ_fail(π) + C_d·T_down(π) + C_q·(1 − throughput) + C_i·N_int + C_h·N_handoff ]，
约束 CVaR_α(L(π)) ≤ D_C 且 P(ℓ_fail ≥ ℓ_cat) ≤ p_C。
契约提供权重 (C_f, C_d, C_q, C_i, C_h, α, D_C, p_C, ℓ_cat)；注意 insured 原型会把 C_f 在 D 以上截断为 0，这正是道德风险的来源，必须由定义 313 的分层约束兜住。

**定义 313（风险分层：不可交易 / 可交易）** 把损失分为
R_cat = E[ℓ_fail · 1{ℓ_fail ≥ ℓ_cat}]（灾难风险：人身、不可逆环境、重大财产）与
R_non = E[ℓ_fail · 1{ℓ_fail < ℓ_cat}]（可恢复风险：延迟、剐蹭、任务失败、返工）。
**R_cat 永不进入经济交易**，始终服从 R68/R69 的保守下界 λ_cat ≥ λ_floor(U_ale + U_epi)；只有 R_non 允许按风险价格 μ 权衡。系：即使 insured 契约把 C_f 截断，R_cat 约束仍独立地对 λ 生效——道德风险被分层挡住。

**定义 314（风险影子价格 μ）** 在定义 312 的约束优化中取拉格朗日乘子：μ = ∂J_C*/∂R_non ≥ 0，即该契约下「一单位可恢复风险的边际价格」。μ 由对偶问题的边际均衡给出：选择 λ 使
∂Cost(λ)/∂λ = −μ · ∂R_non(λ)/∂λ。
**μ→∞ 即「安全不计价」**，最优 λ 退化为 R69 的保守 floor；μ→0 即「只要不越灾难线就尽量快」。μ 是契约与运行工况的函数，属慢变量（定义 324）。

**定义 315（安全-经济门控 EAG / 安全价值 VoS）** 对候选干预 i（收紧 λ、交互、减速、绕行、请求人工）定义
VoS(i) = μ · ΔR_non^cert(i) − Cost(i)，
其中 ΔR_non^cert 是**经认证**的可恢复风险下降（定义 319）。选择 i* = argmax_i VoS(i)，且仅当 VoS(i*) > 0 且 R_cat 约束不越界时执行；否则走名义策略或降级。EAG 是 R69 的 MINT 在「收益用风险价格折算」后的推广：MINT 的 VoI 是 VoS 在 μ→∞、Cost 只计物理/社交成本时的特例。

**定义 316（底盘健康状态 CHS 与剩余寿命）** 底盘信号 h_t = (v_odo, slip, τ_motor, I_batt, R_int, T_motor, T_batt, SoC, dock_force, tire_wear)。潜健康 s_t 服从退化过程 ds/dt = −a·u_t + σ_w dw（u_t 为使用强度），RUL 分布 p(RUL | h_{1:t})。CHS 同时喂给两条通道：安全（制动/里程计/对接失效 → R_cat）与经济（维修成本、停机、折旧 → C_d、C_f）。

**定义 317（底盘冗余融合 CRF：与主感知正交的第二意见）** 四路证据 e = (Δodo, Δimu, Δvo, Δcurr)：
轮速积分位移、IMU 二次积分、视觉里程计增量、按电流/负载模型预测的位移。一致性残差 r_ch = ‖A e‖（A 为物理约束矩阵，如闭环位移应相消）。定义底盘异常分
a_ch = Mahalanobis(r_ch; Σ_ch)，
并给出「标定不可吸收」判据：a_ch 高而主感知残差 r_res 低 ⇒ 底盘/标定发生主感知看不见的漂移（打滑、编码器偏置、轮胎磨损、电池内阻上升）。**CRF 与 R69 的 FMA 构成两条正交第二意见**：FMA 测行为自洽，CRF 测硬件自洽。

**定义 318（层级资产先验与生态谬误防护）** 车队先验 μ_fleet 与资产随机效应 b_i（同型号第 i 台），观测模型 h_i = f_θ^fleet(u_i) + b_i + ε_i，b_i ~ N(0, σ_b²)，ε_i ~ N(0, σ_e²)。用分层贝叶斯 / 卡尔曼得到后验 b̂_i 与 σ̂_b。告警统计量 z_i = b̂_i / σ̂_b，**只在 per-asset 后验上告警，绝不用车队均值告警**。生态谬误：单台偏移 b_i 只让车队均值移动 b_i/N，N 越大越不可见；而 z_i 的检验功效随 |b_i|/σ_e 增长、与 N 无关。系：规模化越强，越必须做 per-asset 审计。

**定义 319（复式安全账本 DEL）** 每笔干预是一条账目
e = (t, actor, action, debit d_e, credit c_e, evidence_hash, contract_clause, certification)。
借方 d_e = 真实付出的时间 / 能量 / 算力 / 人工注意力 / 机会成本；贷方 c_e = **经认证**的可恢复风险下降（可复现证书，哈希承诺）。账本余额 B_t = Σ_e (c_e − d_e)。三不变式：(a) 只有认证通过的贷方可为借方融资；(b) 未认证的收益记为「未实现信用」，不得动用——**这与 R69「单次交互不得单独定案」是同一条纪律的经济版**；(c) append-only + 哈希链，出现「安全透支」即触发 SFE 降级 / 停机。

**定义 320（风险转移动作 RTA）** 经济动作 g_econ ∈ {handoff, reroute, degrade_scope, safe_stop}。每个动作映射到契约条款与责任主体，具有延迟 τ 与可用率 a。转移成立当且仅当接收方可用且 τ ≤ τ_h；转移必须写一条责任账目，**风险被移动而非消灭**（责任守恒）。若接收方不可用，则转移无效，回落到 R68 保守或 safe_stop。

**定义 321（经济审计 VQAuditor-E）** 审计对象：贷方证书是否可复现、成本是否重复计账、干预是否有资金来源、契约条款引用是否正确、指标是否被 Goodhart 化（只优化可记账的吞吐而牺牲不可记账的体验）。以概率 q 抽样复核，罚金 P；结论回灌账本先验与 μ 的再校准。

**定义 322（经济对抗与道德风险 ℰ_econ）** 运营方降本而偷偷关闭安全、事故严重度低报、伪造 SLA 贷方、跨租户污染 FAP、保险免赔额诱导的道德风险、逆向选择（高风险场景选择宽松契约）。并入 AIC：ℰ_LEDGER = ℰ_FLUID × ℰ_econ × ℰ_chassis（打滑 / 对接失败 / 电池失效等底盘故障模式）。

**定义 323（证书 J_LEDGER）** J_LEDGER = (J_FLUID, contract_id, μ_hat, R_cat_margin, ledger_balance, unfunded_count, CVaR_hat, fleet_prior_version, liability_trace_hash, ledger_ver)。Valid ⇔ Valid(J_FLUID) ∧ R_cat 约束满足 ∧ 无无源干预 ∧ 账本配平误差 ≤ ε_b ∧ 责任链完整。

**定义 324（经济漂移与重定价 EDM）** μ 随利用率、电价、维保延期、契约重谈而漂移。用账本残差与 CHS 做在线变点检测；只在**任务边界 / 安全前缀点**重定价（不在实时环内）。若 μ 的变化率超过重定价频率，则保守回退（临时取 μ 的上置信界），绝不用过期价格做安全—经济交易。

**定义 325（安全-经济可行域 SFE）** 可行域 F = {π : R_cat(π) ≤ ρ_cat, CVaR_α(L) ≤ D_C, J_C(π) ≤ Budget_C, B_t ≥ −ε_b}。运行点选在吞吐-风险 Pareto 前沿上由契约决定的位置。任何估计越出 F，或 UCB 触边，则触发 safe_stop + 责任转移，而不是继续「账面安全」。

**定义 326（R68/R69 的严格嵌入）** 取契约 C_∞：C_f→∞、C_q→0、交互预算→∞、单资产单租户、禁用 CHS/FAP/DEL，则 LEDGER 在任意状态上与 R69 **逐指令相同**；再令「永不交互」得 R68。强约束部分：对一切契约，R_cat 侧的 λ 下界 ≥ R69 的 λ_floor。⇒ 安全关键侧不做任何让步，经济侧是新增维度；R68 ⊆ R69 ⊆ R70。

## 2. 关键算法骨架

```python
# IP-264/265 EBM+RP：契约 -> 风险价格；风险分层（cat 不可交易）
class ContractPricer:
    def price(self, C, risk_stats):
        lam = lambda_from_sla(C)                 # 由 CVaR/P(cat) 反解安全约束
        mu  = solve_dual(C, risk_stats)          # dJ_C*/dR_non，慢变量
        return max(mu, 0.0), lam                 # mu=inf 即 R69 极限

    def split(self, loss_dist):
        R_cat = tail_mean(loss_dist, threshold=L_CAT)
        R_non = mean(loss_dist) - R_cat
        return R_cat, R_non                      # cat 永不进入交易

# IP-266/267 CHS+CRF：底盘健康 + 与主感知正交的冗余第二意见（MCU 上跑）
def chassis_second_opinion(h, odo_visual):
    e    = residuals(h, odo_visual)              # odo / imu / vo / current 四路
    a_ch = mahalanobis(affine_constraints(e), SIGMA_CH)
    slow = (a_ch > TAU_CH) and (last_r_res < TAU_RES)   # 硬件漂移疑
    rul  = bayes_rul(h)                          # p(RUL | h)
    return a_ch, slow, rul

# IP-268 FAP：联邦先验 + 生态谬误防护 + 鲁棒聚合
def federated_prior(tenants, byz_frac):
    grads = [tenant.local_stat() for tenant in tenants]
    g     = trimmed_mean(grads, trim=byz_frac)   # Byz<1/3 有界偏差
    return update_prior(version=+1, stat=dp_noise(g, eps_dp))

def asset_alarm(h_i, prior):
    b_hat, s_hat = posterior_offset(h_i, prior)  # 分层贝叶斯
    return abs(b_hat) / s_hat > TAU_ASSET       # 只对单台告警，不看车队均值

# IP-269/270 DEL+EAG：复式记账 + 安全价值门控
def try_intervene(i, mu, ledger, budget):
    d = cost_of(i)                               # 真实付出
    c = certified_credit(i)                      # 必须可复现认证
    if c is None:                                # 未认证 -> 未实现信用，不能花
        ledger.record_receivable(i, claimed=risk_gain(i)); return False
    if not (ledger.balance + c - d >= -EPS_B and budget.allow(i)):
        ledger.overdraft(i); sfe.degrade(); return False
    if mu * c - d <= 0:                           # 无利可图 -> 名义/降级
        return False
    ledger.commit(i, debit=d, credit=c)           # 有借必有贷
    return True

def certified_credit(i):
    cert = risk_certificate(i)                    # 可复现、可复核
    return cert.reduction if cert.reproducible else None

# IP-271 RTA：风险转移（责任守恒）
def risk_transfer(need, contract, ledger):
    for g in [HANDOFF, REROUTE, DEGRADE_SCOPE, SAFE_STOP]:
        if not available(g) or latency(g) > TAU_H: continue
        entry = ledger.transfer(g, liability=contract.liability(g))
        return g, entry                           # 风险移动，不消失
    return SAFE_STOP, ledger.transfer(SAFE_STOP, liability='operator')

# IP-277 主闭环（继承 R69，只在「不确定性/成本处置」处插入经济层）
```

## 3. 推导

**引理 19（风险价格的存在性与单调性）** 若 Cost(λ) 与 R_non(λ) 关于 λ 凸、可微，则最优 λ*(μ) 存在，且 λ*(μ) 关于 μ 单调不减。μ→∞ 时 λ* 收敛到 R_cat 约束下的最保守 λ_floor；μ→0 时收敛到「仅满足灾难约束」的最小成本 λ。系：**R69 是本轮在 μ=∞ 的极限**；契约价格不是推翻保守主义，而是把它变成一个可被定价的边界条件。

**引理 20（复式账本的资助约束与反造假）** 若每个贷方须提交可复现证书、审计以概率 q 复核、伪造罚金 P > (伪造收益)/(1−q)，则任何理性的记账策略在期望上诚实；若允许用未认证贷方融资，则「安全剧场」可把真实风险下降高估任意量而账面仍平衡。系：证据纪律（R69 定义 293-iii）是账本可配平的必要条件，而非可选的合规装饰。

**引理 21（生态谬误界）** 设第 i 台偏移 b_i，其余为零，车队均值偏移 b_i/N，故任何基于车队均值的固定阈值告警功效随 N→∞ 趋于 0；而 per-asset 后验统计量 z_i = b̂_i/σ̂_b 的期望随 |b_i|/σ_e 增长且与 N 无关（分层先验收缩只降低方差、不抹掉偏移）。系：**规模化越强，越不能只看车队均值**——这是 R68「缓变故障被平均掉」在车队层面的镜像。

**定理 18（LEDGER 对 R69/R68 的严格嵌入）** 取定义 326 的 C_∞（C_f→∞、交互预算∞、单资产单租户、禁用经济组件），则 λ* = λ_floor、所有干预 VoS>0、账本恒配平，LEDGER 与 R69 在任意状态逐指令相同；再关闭交互得 R68。且对任意有限契约，R_cat 侧的 λ 下界 ≥ 同状态 R69 的 λ_floor。⇒ **安全关键侧永不弱于旧层，经济侧是新增维度**，新层不是并列黑箱。

**定理 19（风险转移的责任守恒与无突变）** 经认证的 RTA 只在安全前缀点切换，且 τ ≤ τ_h；每次转移写入责任账目，故「账本 + 残余风险」的总量不因转移而下降（仅改变承担主体）。若接收方不可用则转移无效并回落 R68 保守 / safe_stop。结合 R68 换装不变式（定理 15）⇒ 控制连续、无突变，且不存在「责任洗白」的合法路径。

**定理 20（联邦先验的鲁棒性与单资产可检性）** 在 Byzantine 租户比例 β < 1/3、聚合采用坐标中位数 / 截尾均值、各租户梯度有界时，车队先验偏差 ≤ O(β·G)；同时 per-asset 后验告警对任意单台被污染资产保持一致性（只要其真实偏移超过噪声尺度）。⇒ 跨租户投毒可以略微移动先验，但**不能掩盖一台正在坏掉的底盘**。

**定理 21（可行域不越界）** 若 R_cat、CVaR 与 J_C 的在线估计取保守上置信界，且 SFE 在 UCB 触边时触发 safe_stop + 责任转移，则在置信水平 1−δ 下系统不会以正概率停留在 F 之外。⇒ 经济优化不能把系统「优化」进不可行域；账面安全与物理安全由 UCB 桥接。

## 6. 本轮最大风险

**一句话**：LEDGER-RAS 的全部效率收益押在「风险价格 μ 估得准、且账本上的风险下降是真的」这一前提上——**若契约把灾难风险外部化（道德风险）、或把可恢复风险错记成可交易、或用未认证的贷方把干预融资，系统就会「最优地」卖掉它其实测不准的安全，并把每一次事故记成一笔漂亮的利润；届时账本越平衡，现实越危险。** 前几轮的失败是「不知道自己错」，本轮的失败是「把错记成了对」。

1. **道德风险 / 外部性**（insured 契约下 μ_cat→0）→ 定义 313 风险分层，R_cat 永不交易，始终走 R68 铁律；

6. **底盘第二意见与主感知共模失败** → CRF 四路物理冗余 + 与 FMA 正交 + E328。

**定义 313（风险分层）** `R_cat` 永不交易，恒服从 `λ_cat ≥ λ_floor(U_ale+U_epi)`；`R_non` 才按 μ 权衡。系：保险免赔额把 C_f 截断也不动摇 R_cat（道德风险被挡）。

**定义 314–315（μ 与 EAG）** `μ = ∂J_C*/∂R_non`；边际均衡 `∂Cost/∂λ = −μ·∂R_non/∂λ`。`VoS = μ·ΔR_non^cert − Cost`，`VoS>0` 且不越 cat 才执行；μ→∞ 退化为 R69。

**定义 316–317（CHS 与 CRF）** 底盘健康 `ds/dt = −a·u + σ_w dw`，RUL 供安全与经济双通道。四路证据 `e=(Δodo,Δimu,Δvo,Δcurr)`，`a_ch = Mahalanobis(Ae;Σ_ch)`；`a_ch↑ ∧ r_res↓ ⇒ 主感知看不见的硬件/标定漂移`，与 R69 FMA 正交。

**定义 318（FAP 与生态谬误）** `h_i = f_fleet(u_i) + b_i + ε_i`；per-asset 后验 `z_i=b̂_i/σ̂_b` 告警；车队均值偏移仅 `b_i/N`。鲁棒聚合（截尾均值/中位数）+ DP，Byz<1/3 有界。

**定义 319（复式安全账本 DEL）** 借方=真实成本，贷方=认证风险下降；未认证记为「未实现信用」不可花；append-only + 哈希链；安全透支触发降级/停机。

**定义 320–321（RTA 与 VQAuditor-E）** 转移动作映射契约条款与责任主体，接收方不可用则无效；审计贷方可复现性、重复计账、无源干预、Goodhart。

**定义 322–323（威胁与证书）** `ℰ_LEDGER = ℰ_FLUID × ℰ_econ × ℰ_chassis`；`J_LEDGER` 并入契约、μ、R_cat 余量、账本余额、无源数、责任链哈希。

**定义 324–326（漂移/可行域/嵌入）** μ 为慢变量，变点检测 + 任务边界重定价，过期价格禁止交易；可行域 F + UCB，越界即 safe_stop；`C_∞`（C_f→∞、预算∞、单资产、禁经济组件）下与 R69 逐指令相同，R_cat 侧不下退，R68⊆R69⊆R70。

```python
# IP-264/265 EBM+RP：契约 -> 风险价格；分层（cat 不可交易）
class ContractPricer:
    def price(self, C, stats):
        lam = lambda_from_sla(C)                 # 由 CVaR/P(cat) 反解
        mu  = solve_dual(C, stats)               # dJ_C*/dR_non，慢变量
        return max(mu, 0.0), lam
    def split(self, loss):
        R_cat = tail_mean(loss, L_CAT); return R_cat, mean(loss) - R_cat

# IP-266/267 CHS+CRF：底盘健康与正交第二意见（MCU）
def chassis_second_opinion(h, odo_visual):

    a_ch = mahalanobis(affine_constraints(e), SIGMA_CH)
    slow = (a_ch > TAU_CH) and (last_r_res < TAU_RES)
    return a_ch, slow, bayes_rul(h)

# IP-268 FAP：联邦先验 + per-asset 告警 + 鲁棒聚合
def federated_prior(tenants, byz):
    g = trimmed_mean([t.local_stat() for t in tenants], trim=byz)
    return update_prior(+1, dp_noise(g, eps_dp))
def asset_alarm(h_i, prior):
    b, s = posterior_offset(h_i, prior); return abs(b) / s > TAU_ASSET

# IP-269/270 DEL+EAG：复式记账 + 安全价值门控
def try_intervene(i, mu, ledger, budget):
    d = cost_of(i); c = certified_credit(i)
    if c is None:
        ledger.record_receivable(i, risk_gain(i)); return False   # 应收不可花
    if ledger.balance + c - d < -EPS_B or not budget.allow(i):
        ledger.overdraft(i); sfe.degrade(); return False
    if mu * c - d <= 0: return False                              # 无利可图
    ledger.commit(i, debit=d, credit=c); return True

def certified_credit(i):
    cert = risk_certificate(i)
    return cert.reduction if cert.reproducible else None

# IP-271 RTA：风险转移（责任守恒）
def risk_transfer(need, contract, ledger):
    for g in [HANDOFF, REROUTE, DEGRADE_SCOPE, SAFE_STOP]:
        if available(g) and latency(g) <= TAU_H:
            return g, ledger.transfer(g, liability=contract.liability(g))
    return SAFE_STOP, ledger.transfer(SAFE_STOP, liability='operator')

# IP-277 主闭环（继承 R69，只在成本/不确定处置处插入经济层）
def LEDGER_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_calibrated)
    a_ch, slow_ch, rul = M.crf.chassis_second_opinion(M.h, M.odo)
    R_cat, R_non = M.ebm.split(M.risk_stats)
    mu, lam_sla  = M.ebm.price(M.contract, M.risk_stats)
    lam_cat = lam_floor(U_ale + U_epi)           # catastrophic 地板，绝不放松
    picked = None
    for i in candidates(U_epi, modes, slow_ch, rul):
        if M.del.try_intervene(i, mu, M.ledger, M.budget): picked = i; break
    if picked is None and slow_ch:
        picked = M.rta.risk_transfer('chassis', M.contract, M.ledger)
    U_epi_after = M.cia.update_belief(modes, picked) if is_info(picked) else U_epi
    lam = max(lam_cat, M.eag.risk_scale(mu, U_ale, U_epi_after))
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if slow_ch or (M.last_r_res < TAU_RES and a_hat > TAU_FMA):
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(A, U_cal))
    mode = select_mode(modes, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_e.submit_async(picked, M.ledger.tail())
    return k, lam, mode, M.j_ledger.build(U_ale, U_epi_after, mu, M.ledger)
```

## 4. 推导

**引理 19（风险价格存在性与单调性）** Cost、R_non 关于 λ 凸可微 ⇒ λ*(μ) 存在且关于 μ 单调不减；μ→∞ 收敛到 R_cat 约束下的保守 λ_floor，μ→0 收敛到仅满足灾难约束的最小成本 λ。系：R69 是 μ=∞ 的极限，契约定价不推翻保守主义，而把它变成可定价的边界条件。

**引理 20（账本资助约束与反造假）** 贷方需可复现证书、审计概率 q、罚金 P > 收益/(1−q) ⇒ 理性记账在期望上诚实；允许未认证贷方融资则可把风险下降高估任意量而账面仍平。系：R69 证据纪律是账本可配平的必要条件。

**引理 21（生态谬误界）** 单台偏移 b_i 使车队均值移动 b_i/N，固定阈值告警功效随 N→∞ 趋于 0；per-asset 后验 `z_i=b̂_i/σ̂_b` 的期望随 |b_i|/σ_e 增长且与 N 无关。系：规模化越强，越不能只看车队均值——R68「缓变故障被平均掉」的车队版。

**定理 18（严格嵌入 R69/R68）** 取 C_∞ ⇒ 与 R69 任意状态逐指令相同，关交互得 R68；任意有限契约下 R_cat 侧 λ 下界 ≥ R69 的 λ_floor。⇒ 安全关键侧永不让步，经济侧是新增维度。

**定理 19（风险转移责任守恒与无突变）** 认证 RTA 只在安全前缀点切换且 τ≤τ_h；每次转移写责任账目，「账本 + 残余风险」总量不因转移下降（只换承担主体）；接收方不可用则无效并回落 R68/safe_stop。结合 R68 换装不变式 ⇒ 控制连续、无责任洗白。

**定理 20（联邦先验鲁棒性）** Byz β<1/3 + 坐标中位数/截尾均值 + 有界梯度 ⇒ 先验偏差 ≤ O(β·G)；per-asset 后验对任意单台污染资产保持一致性。⇒ 跨租户投毒可移动先验，但掩盖不了一台正在坏掉的底盘。

**定理 21（可行域不越界）** R_cat/CVaR/J_C 取保守 UCB，SFE 触边即 safe_stop + 责任转移 ⇒ 置信 1−δ 下不以正概率停在 F 外。⇒ 经济优化不能把系统「优化」进不可行域。

## 7. 本轮最大风险

**一句话**：LEDGER-RAS 的全部收益押在「风险价格 μ 估得准、账本上的风险下降是真的」这一前提上——**若契约把灾难风险外部化、把可恢复风险错记成可交易、或用未认证贷方融资，系统就会「最优地」卖掉它其实测不准的安全，并把事故记成一笔漂亮的利润；账本越平衡，现实越危险。** 前几轮的失败是「不知道自己错」，本轮的失败是「把错记成了对」。

**次级风险与缓解**：道德风险/外部性（定义 313 风险分层，R_cat 永不交易）；安全剧场/贷方造假（定义 319 复式记账 + 引理 20 + VQAuditor-E）；生态谬误（定义 318 per-asset 后验 + 引理 21）；跨租户投毒/隐私（鲁棒聚合 + DP + 定理 20）；经济漂移/过期价格（定义 324 变点检测 + 安全前缀点重定价 + 保守 UCB）；底盘与主感知共模失败（CRF 四路物理冗余 + 与 FMA 正交）。
