# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；新灵感循环第 1 轮；本轮灵感：「鲁棒性」×「机械臂抓取」）

> 第 54 轮把技能组合落到动作空间剖面与云边协同。本轮回到最具代表性的接触操作任务——机械臂抓取，但两个词的交点不是“抓得更稳”，而是“**鲁棒性在抓取上到底是什么形状**”。核心矛盾：H24：第 53–54 轮的鲁棒性谱 ρ 是**标量/维度谱**，隐含“各方向同等重要、可行域近似球”的假设；而抓取的可行域在扰动空间中高度**各向异性、非凸、且薄尾**——一个抓取可以对位姿扰动很稳、却对摩擦系数从 0.6 掉到 0.4 极敏感。H25：第 54 轮的动作剖面 α_S 与组合证书把“抓取成功”当作**点事件**，忽略了抓取是相位化接触过程、且失败常可在低成本重抓中恢复，导致证书对“单次成功率高但失败不可恢复”的抓取过度乐观。

## 0. 直觉与动机

**灵感 1（抓取鲁棒性是一个“可行域”，不是一个分数）**
直觉：人类说“这个抓取稳”，其实是在说：把物体位置、质量、摩擦、传感器噪声往各个方向推一推，抓取仍然成立的那个**扰动集合**足够大。于是鲁棒性 = 扰动空间中可行域 `R_g` 离名义点 `π0` 的距离，而不是某个分类器的置信度。紧的可行域配大平均裕度是“假稳”，宽而各向异性的可行域才是“真稳”。这直接修正第 53 轮把 ρ 当标量的隐含假设。

**灵感 2（鲁棒性有“形状”：方向剖面与二阶曲率）**
直觉：对位姿 ±2cm 稳、对摩擦 μ 掉 0.2 就滑，这两种脆弱性不能用一个数相加。定义**方向鲁棒半径 `r_g(u)`**（沿扰动方向 u 的可行域边界距离），得到鲁棒性椭球/星形域；再定义边界处**曲率 `κ_g(u)`**，刻画“再推一点就崩”的陡峭程度。这把第 53 轮的维度谱 ρ 升级为**抓取鲁棒性剖面**：标量只是它的最小值投影，各向异性 `A_g` 与曲率 `κ_g` 才是抓取的本质。

**灵感 3（乐观偏差是抓取鲁棒性的头号敌人：红队抓取）**
直觉：用随机域随机化采样估出“成功率 98%”，不代表最坏扰动下也 98%。真正危险的是**薄尾失败模式**（刚好滑脱、刚好自碰撞、刚好超出可达）。必须主动搜索最坏扰动（对抗挖掘），并用**采样界与对抗界之差 `Δ_adv`** 作为证书可信度的绊线：差太大说明采样没摸到危险角落，宁可拒绝也不部署。

**灵感 4（场景证书：把“跑了 N 次没坏”变成“有置信度的保证”）**
直觉：只报成功率没有统计意义。用 scenario optimization：在可行域的**内接凸族**上，以 N 个 iid 场景样本求最大裕度解，则真实分布下的违反概率有分布无关上界 `ε(N,β,d)`。这样“仿真里没坏”被翻译成“真实分布下违反 ≤ ε（置信 1−β）”。取凸内接是为了让证书保守但可证；非凸部分交给对抗挖掘补。

**灵感 5（恢复增广鲁棒性：失败不等于任务失败）**
直觉：抓取是相位化过程（接近→预抓→闭合→抬升→搬运），滑脱/未夹住往往能在 1–2 次重抓中恢复。单次鲁棒性低但失败可廉价恢复的抓取，可能优于单次高、但一失败就撞击/掉落的抓取。定义 **RAR_k**（至多 k 次重抓的任务成功率）与**灾难失败率 `P_cat`**，把鲁棒性从“单点成功”升级为“闭环恢复”，并用支配关系做策略排序。

**灵感 6（云边抓取契约）**
直觉：云端算力足，做扰动空间场景优化、候选抓取排序与证书；边端算力紧，靠触觉高频检测滑移并触发重抓，把“为什么滑”的反例经 Explain 回传，云端重估可行域。形成“云证书—边滑移检测—重抓—反例回灌”的闭环，并用显式分布漂移 `d(P_c,P_e)` 约束防止云证书在边端失效。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（抓取构型与扰动空间）**
抓取构型 `g = (T_ee ∈ SE(3), q_g ∈ ℝ^{n_g}, C_g, f_g ∈ FC)`，其中 `C_g` 为接触集合，`FC` 为摩擦锥。扰动
```
π = (δT ∈ se(3), δμ ∈ ℝ^{m_μ}, δm, δcom, δs) ∈ Π
```
分别对应位姿、摩擦系数、质量、质心与传感噪声；名义点 `π0`，加权度量 `d_Π`，扰动球 `B(π0,r) = {π : d_Π(π,π0) ≤ r}`。

**定义 122（抓取可行域与零阶鲁棒裕度）**
```
R_g = { π ∈ Π | force_closure(C_g(π)) ∧ no_slip(π) ∧ no_collision(π) ∧ reachable(π) }
ρ_g(g) = dist_Π(π0, ∂R_g) / r_budget ∈ [0,1]   （R_g=Π 时取 1）
```
`ρ_g ≥ ρ_min` 称**鲁棒抓取**。这是第 53 轮 ρ 在抓取上的零阶特例：只有标量，看不到方向。

**定义 123（方向鲁棒剖面与边界曲率）**
对单位方向 `u ∈ S^{d-1}`：
```
r_g(u) = sup{ r ≥ 0 : π0 + r·u ∈ R_g }
ρ_g(u) = r_g(u) / r_budget
A_g = max_u ρ_g(u) / min_u ρ_g(u)                （各向异性）
κ_g(u) = -∂/∂r [ 1 / r_g(u) ]  沿射线对数导数   （边界陡峭度）
```
抓取鲁棒剖面 `𝒫_g = (ρ_g, {ρ_g(u)}_{u∈S^{d-1}}, A_g, {κ_g(u)})`。与第 53 轮相容：每个维度 d 的 `ρ_d` 恰为 `ρ_g(e_d)`，即沿该坐标轴的剖面切片。**低 `ρ_g` 但高 `A_g`** 表示“只在某方向脆”，**低 `κ_g`** 表示“越界后崩得平缓、可恢复”。

**定义 124（对抗抓取鲁棒半径与对抗间隙）**
令 `margin(g,π)` 为力旋量包络到边界的归一化距离（或力闭合残差）。最坏扰动
```
π* = argmin_{π ∈ B(π0, r_budget)} margin(g, π),     r_adv(g) = d_Π(π0, π*)
Δ_adv(g) = ρ_g(g) - r_adv(g)/r_budget
```
`Δ_adv > Δ_max` 判为**采样证书不可信**（薄尾未被覆盖），拒绝部署。这把“红色空想”变成可计算的绊线。

**定义 125（场景证书 SCC）**
在可行域的内接凸族 `R̂(θ) ⊆ R_g` 上，取 N 个 iid 场景 `π_i ~ P`，解
```
max_θ  margin(θ)   s.t.  π_i ∈ R̂(θ),  i = 1..N
```
则存在 `ε(N,β,d)` 使 `P_{π~P}(π ∉ R̂(θ*)) ≤ ε` 以概率 `≥ 1-β`，其中 d 为凸族参数维数。证书 `SCC = (N, ε, β, d, θ*)`。其 soundness 依赖**交换性**与**凸内接**；分布漂移时需重要性重加权与 ε 膨胀。

**定义 126（恢复增广鲁棒性 RAR）**
抓取策略 `π_pol`，至多 k 次重抓：
```
RAR_k(π_pol) = P( ∃ j≤k : 第 j 次抓取后任务完成 )
P_cat(π_pol) = P( 失败造成不可恢复状态 / 物体损伤 )
```
策略支配：`A ≻ B ⇔ RAR_k(A) ≥ RAR_k(B) ∧ P_cat(A) ≤ P_cat(B) ∧ E[C_A] ≤ E[C_B]`。这把“单次成功率”升级为带代价与灾难约束的闭环指标。

**定义 127（云边抓取契约）**
```
C_gce = (G_c, SCC_c, D_e, π_re, Explain_loop)
```
- `G_c`：云端 top-k 候选抓取及其证书 `J_g`；
- `SCC_c`：云端场景证书（在分布 `P_c` 下）；
- `D_e`：边端触觉滑移检测器，频率 `f_t`、检测延迟 `τ_s`；
- `π_re`：重抓策略，重抓预算 k；
- `Explain_loop`：反例 `π†` 与根因回传通道。
契约成立需边端扰动分布 `P_e` 满足 `d(P_c,P_e) ≤ δ_P`，否则云端证书需保守膨胀或拒绝。

**定义 128（抓取联合证书 J_g）**
```
J_g = (ρ_g, 𝒫_g, SCC, Δ_adv, RAR_k, P_cat, d(P_c,P_e), evidence)
```
可部署当且仅当
```
ρ_g ≥ ρ_min ∧ A_g ≤ A_max ∧ ε ≤ ε_max ∧ Δ_adv ≤ Δ_max
∧ RAR_k ≥ RAR_min ∧ P_cat ≤ P_cat,max ∧ d(P_c,P_e) ≤ δ_P
```
`evidence` 至少含对抗反例、场景样本覆盖统计与云端规划日志。`J_g` 与第 54 轮 `J=(ρ,A_cert,γ_ce,δ_a)` 兼容：把标量 ρ 替换为剖面 `𝒫_g`，并新增统计与恢复维度。

## 2. 关键算法 伪代码

### IP-121 GRS（Grasp Robust Set Estimation）

```python
def estimate_grasp_region(g, pert_space, n_dir=64, sampler):
    R = {}
    for u in sphere_directions(n_dir, pert_space.dim):
        lo, hi = 0.0, pert_space.r_budget
        while hi - lo > pert_space.tol:
            mid = 0.5 * (lo + hi)
            if sampler.feasible(g, pert_space.at(mid, u)):
                lo = mid
            else:
                hi = mid
        R[u] = lo                       # r_g(u)
    return GraspRegion(R, rho=min(R.values()) / pert_space.r_budget)
```

### IP-122 GRP（Grasp Robustness Profile）

```python
def robustness_profile(region, r_budget, eps=1e-3):
    rho = {u: r / r_budget for u, r in region.R.items()}
    A = max(rho.values()) / max(min(rho.values()), eps)
    kappa = {u: log_derivative(region, u) for u in region.R}
    return Profile(rho=rho, anisotropy=A, curvature=kappa,
                   scalar=min(rho.values()))
```

### IP-123 ARM（Adversarial Robustness Mining）

```python
def mine_worst_case(g, pert_space, margin_fn, budget):
    pi, best = pert_space.nominal(), margin_fn(g, pert_space.nominal())
    for _ in range(budget.iters):
        step = budget.step * grad_or_es(margin_fn, g, pi)
        cand = pert_space.project(pi + step)
        m = margin_fn(g, cand)
        if m < best:
            best, pi = m, cand
        if budget.early_stop(best):
            break
    return pi, best            # r_adv = pert_space.dist(pi, pert_space.nominal())
```

### IP-124 SCC（Scenario Certificate）

```python
def scenario_certificate(g, P, N, beta, d, margin_fn, inner_family):
    scenarios = [P.sample() for _ in range(N)]
    theta = solve_max_margin(inner_family, scenarios, margin_fn)
    eps = binomial_tail_inverse(N, beta, d)   # Σ_{i≤d} C(N,i) ε^i (1-ε)^{N-i} = β
    return SCC(N=N, eps=eps, beta=beta, d=d, theta=theta)
```

### IP-125 RAR（Recovery-Augmented Robustness）

```python
def recovery_augmented_eval(policy, task, k, trials):
    succ, cat, cost = 0, 0, 0.0
    for _ in range(trials):
        ok = False
        for j in range(k + 1):
            res = policy.grasp(task)
            if res.damaged:
                cat += 1
                break
            if res.success:
                ok = True
                break
            policy = policy.recover(res.explain)
        succ += ok
        cost += policy.last_cost
    return RAR_k(succ / trials, cat / trials, cost / trials)
```

### IP-126 GCE（Grasp Cloud-Edge Execution）

```python
def cloud_edge_grasp(scene, P_c, P_e, k, delta_P):
    if dist(P_c, P_e) > delta_P:
        P_c = inflate_conservatively(P_c, dist(P_c, P_e))
    deployed = [g for g in cloud_rank(scene, top_k=5) if cert_ok(g.J_g)]
    last_exp = None
    for j in range(k + 1):
        g = deployed[min(j, len(deployed) - 1)]
        a = edge_execute(g, tau_s)
        if a.slip and j < k:
            last_exp = edge_explain(a, tactile=True)
            P_e = P_e.update(last_exp.counterexample)   # 反例回灌
            cloud_reprofile(P_e)                        # 云端重剖分
            continue
        if a.success:
            return ('ok', g, j, last_exp)
    return ('fail', edge_explain(a))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| GRS | O(D·log(r/tol)·T_sim) | O(D) | 沿射线可行段单调/单峰，采样完备 |
| GRP | O(D) | O(D) | 边界可微，对数导数存在 |
| ARM | O(I·T_sim) | O(dim) | τ_adv-近似最坏，非全局需多起点 |
| SCC | O(N·T_sim + solve) | O(N·d) | 凸内接 ⊆ R_g，样本交换性 |
| RAR | O(k·trials) | O(1) | 重抓可恢复、代价可估 |
| GCE | O(|G_c| + k·τ_s^{-1}) | O(k) | 分布漂移有界、Explain 闭环收敛 |

**正确性定理（Grasp Robustness Certificate Soundness）**
假设承接第 53–54 轮 (A22)–(A28)，并新增：
**(A29)** 扰动空间 `Π` 覆盖真实扰动的支撑（无未建模薄尾）；
**(A30)** `R̂(θ) ⊆ R_g` 由凸内接构造（保守）；
**(A31)** 场景样本 iid 且满足交换性，或其重要性重加权后满足；
**(A32)** 对抗挖掘达到 `τ_adv`-近似最坏；
**(A33)** 云边分布漂移 `d(P_c,P_e) ≤ δ_P`；
**(A34)** 重抓失败可在预算 k 内恢复（无二次损伤）。
则单次成功概率 `p ≥ 1 - ε - δ_P - η`，其中 `η = P(Δ_adv > Δ_max)`，且任务成功率满足
```
P_task ≥ (1 - P_cat) · [ 1 - (ε + δ_P + η)^{k+1} ]
```
关键：**证书只对“凸内接 + 覆盖真实支撑”的扰动域成立**，`ε` 是统计保证而非经验成功率，`k` 把可恢复失败转化为闭环收益，`P_cat` 为硬风险闸门。

## 6. 本轮最大风险

**一句话**：把抓取鲁棒性从标量升级为“方向剖面 + 场景证书 + 恢复增广”后，整套 soundness 仍**根基性地依赖扰动空间 Π 的规格正确与场景样本的交换性**；一旦真实失败模式落在 Π 的薄尾之外（未建模柔顺、分布漂移、罕见自碰撞），再漂亮的 `ρ_g`、再小的 `ε` 都会变成危险的乐观——因此必须以 **对抗挖掘的 `Δ_adv` 绊线 + OOD 漂移检测 + `P_cat` 硬闸门** 三重护栏，宁可判为“不可证”，绝不把“采样没坏”当成“真的稳”。

## 2. 关键算法 伪代码

### IP-121 GRS

```python
def estimate_grasp_region(g, pert_space, n_dir=64, sampler):
    R = {}
    for u in sphere_directions(n_dir, pert_space.dim):
        lo, hi = 0.0, pert_space.r_budget
        while hi - lo > pert_space.tol:
            mid = 0.5 * (lo + hi)
            if sampler.feasible(g, pert_space.at(mid, u)):
                lo = mid
            else:
                hi = mid
        R[u] = lo
    return GraspRegion(R, rho=min(R.values()) / pert_space.r_budget)
```

### IP-122 GRP

```python
def robustness_profile(region, r_budget, eps=1e-3):
    rho = {u: r / r_budget for u, r in region.R.items()}
    A = max(rho.values()) / max(min(rho.values()), eps)
    kappa = {u: log_derivative(region, u) for u in region.R}
    return Profile(rho=rho, anisotropy=A, curvature=kappa,
                   scalar=min(rho.values()))
```

### IP-123 ARM

```python
def mine_worst_case(g, pert_space, margin_fn, budget):
    pi, best = pert_space.nominal(), margin_fn(g, pert_space.nominal())
    for _ in range(budget.iters):
        cand = pert_space.project(pi + budget.step * grad_or_es(margin_fn, g, pi))
        m = margin_fn(g, cand)
        if m < best:
            best, pi = m, cand
        if budget.early_stop(best):
            break
    return pi, best                     # r_adv = d(π0, π*)
```

### IP-124 SCC

```python
def scenario_certificate(g, P, N, beta, d, margin_fn, inner_family):
    scenarios = [P.sample() for _ in range(N)]
    theta = solve_max_margin(inner_family, scenarios, margin_fn)
    eps = binomial_tail_inverse(N, beta, d)
    return SCC(N=N, eps=eps, beta=beta, d=d, theta=theta)
```

### IP-125 RAR

```python
def recovery_augmented_eval(policy, task, k, trials):
    succ, cat, cost = 0, 0, 0.0
    for _ in range(trials):
        ok = False
        for j in range(k + 1):
            res = policy.grasp(task)
            if res.damaged:
                cat += 1
                break
            if res.success:
                ok = True
                break
            policy = policy.recover(res.explain)
        succ += ok
        cost += policy.last_cost
    return RAR_k(succ / trials, cat / trials, cost / trials)
```

### IP-126 GCE

```python
def cloud_edge_grasp(scene, P_c, P_e, k, delta_P):
    if dist(P_c, P_e) > delta_P:
        P_c = inflate_conservatively(P_c, dist(P_c, P_e))
    deployed = [g for g in cloud_rank(scene, top_k=5) if cert_ok(g.J_g)]
    last_exp = None
    for j in range(k + 1):
        g = deployed[min(j, len(deployed) - 1)]
        a = edge_execute(g, tau_s)
        if a.slip and j < k:
            last_exp = edge_explain(a, tactile=True)
            P_e = P_e.update(last_exp.counterexample)
            cloud_reprofile(P_e)
            continue
        if a.success:
            return ('ok', g, j, last_exp)
    return ('fail', edge_explain(a))
```

### IP-127 JGC

```python
def joint_grasp_certificate(g, P, P_c, P_e, cfg):
    region = estimate_grasp_region(g, cfg.pert_space, sampler=cfg.sampler)
    prof = robustness_profile(region, cfg.r_budget)
    pi_star, m_star = mine_worst_case(g, cfg.pert_space, cfg.margin_fn, cfg.budget)
    delta_adv = prof.scalar - cfg.pert_space.dist(pi_star, cfg.pert_space.nominal()) / cfg.r_budget
    scc = scenario_certificate(g, P, cfg.N, cfg.beta, cfg.d_inner, cfg.margin_fn, cfg.inner_family)
    rar = recovery_augmented_eval(cfg.policy, cfg.task, cfg.k, cfg.trials)
    drift = dist(P_c, P_e)
    ok = (prof.scalar >= cfg.rho_min and prof.anisotropy <= cfg.A_max
          and scc.eps <= cfg.eps_max and delta_adv <= cfg.delta_adv_max
          and rar.RAR_k >= cfg.RAR_min and rar.P_cat <= cfg.P_cat_max
          and drift <= cfg.delta_P)
    return ('ok' if ok else 'reject',
            JointGraspCert(prof, scc, delta_adv, rar, drift,
                           evidence=(pi_star, region, scc)))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| GRS | O(D·log(r/tol)·T_sim) | O(D) | 射线单峰/单调 + 采样完备 |
| GRP | O(D) | O(D) | 边界可微，对数导数存在 |
| ARM | O(I·T_sim) | O(dim) | `τ_adv`-近似最坏，多起点补全局 |
| SCC | O(N·T_sim + solve) | O(N·d) | 凸内接 `R̂⊆R_g` + 交换性 |
| RAR | O(k·trials) | O(1) | 重抓可恢复、代价可估 |
| GCE | O(|G_c| + k·τ_s^{-1}) | O(k) | 漂移有界、Explain 收敛 |
| JGC | O(GRS + ARM + SCC + RAR) | O(D+N·d) | 六条件联合闭合 |

**正确性定理（Grasp Robustness Certificate Soundness）**
承接 (A22)–(A28)，新增 (A29) `Π` 覆盖真实扰动支撑；(A30) `R̂(θ)⊆R_g` 凸内接；(A31) 场景样本交换（或重加权后交换）；(A32) 对抗挖掘 `τ_adv`-近似最坏；(A33) `d(P_c,P_e)≤δ_P`；(A34) 重抓可在预算 k 内无损伤恢复。则单次成功概率 `p ≥ 1 - ε - δ_P - η`（`η=P(Δ_adv>Δ_max)`），任务成功率
```
P_task ≥ (1 - P_cat) · [ 1 - (ε + δ_P + η)^{k+1} ]
```
要点：`ε` 是**统计保证**而非经验成功率；`k` 把可恢复失败转为闭环收益；`P_cat` 为硬风险闸门；`Δ_adv` 防采样乐观。若 `Δ_adv > Δ_max` 或 `d(P_c,P_e) > δ_P`，证书**降级为 reject**，不以保守参数“糊过去”。

## 6. 本轮最大风险

**一句话**：形状化抓取鲁棒性 + 场景证书 + 恢复增广虽把 `ρ` 变成可证的 `J_g`，但其 soundness **根基性地依赖扰动空间 Π 的规格正确与场景样本交换性**；一旦真实失败模式落在 Π 的薄尾之外（未建模柔顺、分布漂移、罕见自碰撞），再大的 `ρ_g`、再小的 `ε` 也会变成危险的乐观——故必须以 **对抗挖掘的 `Δ_adv` 绊线 + OOD 漂移检测 + `P_cat` 硬闸门** 三重护栏，宁可判“不可证”，绝不把“采样没坏”当成“真的稳”。
