# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；灵感循环第 1 轮；本轮灵感：「开源软件」×「鲁棒性」）

> 第 59 轮把「证据承诺」一路下沉到执行层物理：BUQ 辨识 BLDC 结构化不确定性、ERTC 契约化实时性、EEIS 把概率安全界编译成阻抗参数、CLEP 双向闭环、EV-exec 成为第 5 模态。但它仍默认整条证据链是**自产自证**的封闭系统——KG 子图来自 KGMM、微调权重来自云端、固件来自 CEB++++ 隔离区、电机参数先验来自厂商、μ 分析模板来自控制库——这些上游产物被当作「给定可信输入」，只做一次影子测试就热切换。本轮两个灵感精准击中这个**信任传递漏洞**：**开源软件**的本质不是「免费代码」，而是**由不可信多方分布式生产、靠物料清单/依赖锁定/可复现构建/签名溯源/社区审查来建立信任**的工程范式——它要求每一条证据都能被第三方从源码、数据、配方、随机种子**逐位复现**，否则证书只是一张「自证清白」的收据；**鲁棒性**则提醒：多个实现/fork 带来认知多样性，但只有当聚合规则对**拜占庭污染**与**分布漂移**鲁棒时，多样性才是安全资产，否则单个投毒 fork 即可把全局后验拖入深渊。本轮核心命题：**「把证据当作开源供应链来生产与审计，把证据融合当作对抗最坏上游故障的鲁棒统计问题」**——让信任从「被声明」变成「可复现 + 可鲁棒聚合」。

核心矛盾：
- **H32（供应链抽象泄漏·信任不可传递）**：第 59 轮的 CEB++++ 把固件/参数/模板整包做影子运行，等价于「信任单次测试」。但真实上游是**有依赖 DAG 的**：固件 A 依赖驱动 B 依赖标定表 C 依赖厂商先验 D。任一深节点被投毒、衰减（bit-rot）或版本漂移，下游所有证书都是**被洗白的脏信任**。**没有污点传播模型，隔离区越成功，污染传播得越远。**
- **H33（不可复现证据·审计剧场）**：证书 Cert_eeis/J_exec 目前是不可重建的「结论快照」。若审计者无法从「同一份遥测日志 + 同一份代码/配方 + 同一随机种子」重新算出同一个 δ_f，那么「可审计安全」只是叙事。**不可复现的证据不能作为硬证据**，只能降格为「声明级证据」并施加上界惩罚。
- **H34（鲁棒聚合缺失·fork 反噬）**：开源范式鼓励多实现（多套落脚点评估器、多份 KG 抽取器、多检查点投票）。若用朴素平均/加权融合，攻击者只需污染略多于 1/2 的 fork 即可控制输出；即便无攻击，单一维护者 fork 的系统性偏差也会被「多样」假象掩盖。**没有拜占庭鲁棒与分布鲁棒的聚合，fork 数量增加不增加安全，只增加攻击面。**

## 0. 直觉与动机

**灵感 1（开源软件 → 证据供应链 EBOM/ESC）**
直觉：开源项目不是「一堆文件」，而是**一张带元数据的可验证依赖图**：SBOM 说清「我由什么组成」，lockfile 说清「我精确用了哪个版本」，reproducible build 说清「任何人能重建出同一字节」，SLSA 溯源分级说清「这份产物经过几道独立验证」，CVE 数据库说清「已知哪里会坏」。把机器人证据体系映射过去：每份 KG 子图、每组微调权重、每个固件增量、每张阻抗证书、每个 μ 模板，都是证据供应链上的一个 **artifact 节点**；每个节点带 `(id, version, hash, provenance_level, usage_scope, maintainer_set, last_verified)`；依赖边记录「由谁派生」。关键洞见：**信任不应由节点自称，而应由其依赖闭包的溯源等级与可复现性共同决定**——这叫「信任的传递性必须可计算」，而不是「整包影子测试通过即可信」。

**灵感 2（鲁棒性 → 鲁棒证据聚合 REA 与分布鲁棒共形 DR-CP）**
直觉：鲁棒性有三个层次。其一，**对抗鲁棒**：对 K 个 fork 的输出用 Krum/坐标中位数/截尾均值聚合，只要诚实 fork 数超过崩溃点 α_B，聚合误差就被诚实 fork 的离散度界住；污染 fork 再多也只能把结果推离有限距离。其二，**分布鲁棒**：共形校准假设可交换性，但上游版本漂移、维护者更替、环境变化都会破坏它；于是把校准经验分布 P̂ 扩成一个**模糊集 B_ε(P̂)**（Wasserstein/χ² 球），取球内最坏分布的共形分位数，覆盖率保证变成 `1−α−δ_amb(ε,n)`。其三，**鲁棒性债**：像技术债一样，接受一次不可复现/低溯源/单维护者依赖，就欠下一笔「鲁棒性债」，债务超阈值必须用额外探针、更软阻抗、更保守步态来偿还——**鲁棒性不是一次性属性，而是需要持续偿付的账本**。

**灵感 3（开源 × 鲁棒 → 溯源感知风险会计 PRA）**
直觉：第 59 轮的部署界把 δ_f 当成各检查点的加性小量。现在让每个加性项都**随证据供应链的「脏度」膨胀**：`δ_f^eff = δ_f^base + Δ_taint + Δ_rep + Δ_div`。三项分别是：上游污点经 DAG 的联合界传播（`t(v)=min(1,Σ π_u)`）、不可复现惩罚（低 `ρ_rep` 节点的加权和）、多样性不足惩罚（有效诚实 fork 数 `q_eff` 越接近 1/2 惩罚越大）。三条单调性成立：**加一个依赖只会让 δ_f^eff 变大或不变；降一次可复现等级只会变大；减少一个诚实 fork 只会变大。** 于是「开源」不是宽容，而是**把不可信上游的代价显式定价**。

**灵感 4（合流 → 开源证据供应链算子 OESC）**
直觉：把上述机制串成一个算子，嵌进每个检查点：① 解析 EBOM 与 lockfile（依赖闭包、版本冲突、缺包）；② 跑 RER 复现重建（确定性配方 + 遥测日志 → 重算证书，逐位应一致）；③ TPRA 算 δ_f^eff；④ 收集同一证据函数的多个 fork，REA 鲁棒聚合，诚实 quorum 不足即降级；⑤ DR-CP 用「污点+不可复现」决定的模糊半径给区间；⑥ 用溯源调整后的证据门判定；⑦ 通过则签发 `J_osc` 可复现证据发布（含 EBOM 哈希、锁文件哈希、复现日志、quorum、模糊半径、δ_f^eff）；⑧ 记账鲁棒性债；⑨ 债超阈值则强制补偿性控制。**「承诺」现在是一次可被任何第三方重放审计的、供应链健全的发布。**

**灵感 5（鲁棒性债 RDL → 让「欠账」可积累、可偿还、可强制）**
直觉：现实部署不可能永远只吃 P3 可复现依赖——实时性、成本、厂商闭源都逼你接受 P0/P1 产物。与其假装纯净，不如**显式记账**：每次接受低溯源/不可复现/单维护者依赖，`D_rb ← γ·D_rb + accrue`；每次独立复现通过、多维护者交叉签名、额外探针证伪，`D_rb ← D_rb − repay`。当 `D_rb > θ_debt`，系统自动进入**补偿模式**：抬 δ_f 下界、缩短承诺距离、增加探针、切最软阻抗。**债务不消灭鲁棒性，它把鲁棒性从「是否满足」变成「如何分期偿付」。**

## 1. 形式化定义（增量：定义 153–160）

**定义 153（证据物料清单 EBOM 与证据锁文件）** 证据物料清单是一个带元数据的有向无环图 `EBOM=(V_E,E_E,𝔞)`。节点 `v=(id_v, type_v, ver_v, h_v, P_v, scope_v, maint_v, t_ver)`，其中 `P_v∈{P0≺P1≺P2≺P3}` 为溯源等级（P0 原始/未审、P1 单方签名、P2 封闭可复现构建、P3 独立多方复现）；`scope_v` 为用途/能力约束（等价于能力格上的许可证）；`maint_v` 为维护者集合（用于 bus-factor）。依赖边 `(u→v)` 表示 v 由 u 派生/构建。闭包 `C(v)=Anc(v)∪{v}`。锁文件 `L(v)={(id_u,ver_u,h_u) | u∈C(v)}` 精确钉死闭包内每个节点的版本与哈希。若闭包内同一 `id` 出现多个不一致 `ver`，判定为**证据版本冲突**（EBOM-conflict），无显式覆盖规则则拒绝使用。

**定义 154（可复现证据重建 RER）** 给定节点 v 的锁文件 `L(v)`、原始遥测日志 `L_tele`、确定性构建配方 `R_v`（代码哈希、编译选项、随机种子 s、禁用墙钟/未播种 RNG/线程竞态），重建算子 `reconstruct(v;L,L_tele,R_v,s)→O_v` 必须**确定性**。称 v 可复现，当且仅当对任意独立审计者 j，`reconstruct_j(v;·)=O_v` 在数值容差 `τ_rep`（逐位或 ULP 级）内一致且输出哈希相同。复现状态 `ρ_rep(v)∈{R0,R1,R2,R3}` 分别对应「不可复现、单点可复现、封闭可复现、独立多方复现」。**溯源等级必须由复现状态支撑**：`P_v≤ℓ(ρ_rep(v))`，否则自动降级；`ρ_rep<R2` 的证书一律标记为「仅声明级」，不得进入硬证据门。

**定义 155（证据污点传播 TP）** 对每个节点 u 赋缺陷先验 `π_u∈[0,1]`（由类型风险、已知弱点注册表、维护者集中度、溯源等级综合给出；未知类型默认 `π_u=π_max`）。节点 v 的污点取闭包上的联合界：
```
t(v) = min(1, Σ_{u∈C(v)} π_u)
```
单调性：`C(v)⊆C(v') ⇒ t(v)≤t(v')`。关键性质：**深节点污染会随闭包被完整计入**，不可能因为「直接父节点干净」而被洗白。

**定义 156（鲁棒证据聚合 REA）** 设 K 个 fork/实现 `{f_1,…,f_K}` 对同一证据量给出估计，其中仅 `q` 个满足 `ρ_rep≥R2` 且交叉签名（称**有效诚实集**），其余均为不可验证或潜在污染。聚合规则 `A`（标量用坐标中位数/截尾均值，向量用 Krum）需满足崩溃点 `α_B`（Krum `α_B<1/2`）。输出鲁棒估计 `ŷ=A({f_i(x)})` 与离散度 `s=max_{i,j∈H}d(f_i(x),f_j(x))`。保证：若污染比例 `f<α_B`，则 `d(ŷ, f_h(x))≤c·s`（`h∈H`）。**quorum 条件**：`q≥q_min=max(3,⌈(K+1)/2⌉)`；不满足则返回 `QUORUM_LOST` 并强制保守，禁止「少数量 fork 硬凑一致」。

**定义 157（分布鲁棒共形 DR-CP）** 校准残差经验分布 `P̂_n`，取模糊集 `B_ε(P̂_n)={Q: W_1(Q,P̂_n)≤ε}`（或 χ² 球）。DR 共形分位数
```
q̂_ε = sup_{Q∈B_ε(P̂_n)} Q_{1−α}
```
预测集 `C_α(x)={y: F̂_x(y)≤q̂_ε}`，覆盖保证 `inf_{Q∈B_ε} P_Q(Y∈C_α) ≥ 1−α−δ_amb(ε,n)`，其中 `δ_amb(ε,n)=O(ε+√(log(1/δ)/n))`。模糊半径按供应链脏度设定：
```
ε = ε_0 + κ·t(C) + λ_rep·Σ_{v∈C} w_v·1[ρ_rep(v)<R2]
```
即**证据越脏、越不可复现，区间越宽、覆盖率越保守**；这使 DR-CP 成为把供应链不确定性注入统计保证的通道。

**定义 158（溯源感知风险会计 PRA）** 检查点 cp 的有效失效界
```
δ_f^eff(cp) = δ_f^base(cp) + Δ_taint(C) + Δ_rep(C) + Δ_div
Δ_taint(C) = λ_t · min(1, Σ_{v∈C} π_v)
Δ_rep(C)   = λ_r · Σ_{v∈C} w_v·1[ρ_rep(v)<R2]
Δ_div      = λ_d · max(0, q_min − q_eff)/q_min      # 有效诚实 fork 不足的线性惩罚
```
三条单调性（PRA-soundness）：(i) 依赖闭包扩张 ⇒ δ_f^eff 不减；(ii) 任一节点复现等级下降 ⇒ δ_f^eff 不减；(iii) 有效诚实 fork 减少 ⇒ δ_f^eff 不减。PRA 是真实污染传播的**保守上界**，而非估计。

**定义 159（开源证据供应链算子 OESC）** 算子 `OESC(M, cp, δ_f^base)`：
```
① EBOM/lock:  C, L ← resolve(artifacts(cp));  若冲突/缺包 ⇒ DEGRADE_PROVENANCE
② RER:        ρ_rep(v) ← reproduce(v, L, L_tele, R_v, s) ∀v∈C
              不可复现节点 → scope 降为「声明级」
③ TPRA:       t(C), Δ_* ← taint_account(C); δ_f^eff ← PRA(δ_f^base, C, q_eff)
④ REA:        {f_i} ← collect_forks(evidence_fn(cp))
              ŷ, s, q_eff ← robust_aggregate({f_i}, provenance)
              若 q_eff<q_min ⇒ DEGRADE_PROVENANCE("quorum_lost")
⑤ DR-CP:      ε ← radius(t(C), ρ_rep); C_α ← dr_conformal.predict(ŷ, ε)
⑥ Gate:       pass ← evidence_gate_osc(cp, δ_f^eff, C_α, provenance)
⑦ Release:    J_osc ← sign_release(EBOM_hash, lock_hash, rer_log, quorum, ε, δ_f^eff)
⑧ RDL:        D_rb ← debt_update(D_rb, C, ρ_rep, q_eff)
⑨ Compensate: 若 D_rb>θ_debt ⇒ 抬 δ_f 下界、增探针、切软阻抗
⑩ Return:     (M, ŷ, C_α, J_osc, δ_f^eff, D_rb)
```

**定义 160（证据发布证书 J_osc 与鲁棒性债账本 RDL）** 发布证书
```
J_osc = (EBOM_hash, lockfile_hash, provenance_vec, RER_audit_log,
         REA_quorum(q,K,α_B), DR_radius(ε,δ_amb), δ_f^eff,
         robustness_debt, signature_chain, timestamp, version)
```
不可篡改、版本单增、可由任意第三方用 `(J_osc, L, L_tele, recipe, seed)` 重放复现。鲁棒性债账本：
```
D_rb(t+1) = clip( γ·D_rb(t) + accrue(C,ρ_rep,q_eff) − repay(cross_sign, rer_pass, falsify_probe), 0, D_max )
```
其中 `γ∈(0,1)` 为折旧；`accrue` 对低溯源/单维护者/少 fork 累加，`repay` 对独立复现/多方签名/证伪探针扣减。`D_rb>θ_debt` 触发补偿模式，`D_rb≥D_max` 直接禁止不可逆承诺。

### IP-152 EBOM 解析与证据锁文件

```python
class EBOMResolver:
    def __init__(self, registry, weakness_db):
        self.registry = registry          # artifact_id -> {version: ArtifactMeta}
        self.weakness_db = weakness_db    # 已知弱点注册表（类 CVE）

    def resolve(self, artifact_ids):
        # 深度优先展开依赖闭包，检测缺失/循环/版本冲突
        closure, stack, conflicts = {}, [], []
        def visit(aid, constraints):
            if aid in stack: raise EBOMError(f"dependency_cycle:{aid}")
            node = self.registry.get(aid)
            if node is None: raise EBOMError(f"missing_artifact:{aid}")
            ver = self._select_version(node, constraints)   # 满足约束的最高兼容版
            if aid in closure and closure[aid].ver != ver:
                conflicts.append((aid, closure[aid].ver, ver))  # 无覆盖规则即冲突
                return
            if aid in closure: return
            stack.append(aid)
            closure[aid] = node.versions[ver]
            for dep, c in node.versions[ver].deps.items():
                visit(dep, c)
            stack.pop()
        for aid in artifact_ids:
            visit(aid, None)
        if conflicts:
            raise EBOMError(f"ebom_version_conflict:{conflicts}")
        lock = {aid: (m.ver, m.hash) for aid, m in closure.items()}
        return EBOMGraph(closure), lock

    def defect_prior(self, meta):
        if meta.id in self.weakness_db: return self.weakness_db[meta.id].risk
        base = {P0: 0.30, P1: 0.15, P2: 0.05, P3: 0.01}[meta.provenance]
        bus = 1.0 / (1.0 + len(meta.maintainers))     # bus-factor 集中度
        return min(1.0, base * (0.5 + 1.5 * bus))
```

### IP-153 RER 可复现证据重建

```python
class ReproducibleEvidenceBuilder:
    def __init__(self, recipe_registry, tol=1e-12):
        self.recipes = recipe_registry
        self.tol = tol

    def build(self, aid, lock, telemetry_log, seed=0):
        recipe = self.recipes[aid]
        # 禁用非确定性源：墙钟、未播种 RNG、线程数、设备时钟
        ctx = DeterministicContext(seed=seed, forbid={'wallclock', 'unseeded_rng',
                                                      'threads>1', 'device_entropy'})
        with ctx:
            out = recipe.run(lock=lock, telemetry=telemetry_log)
        return EvidenceOutput(value=out, hash=stable_hash(out), ctx_fingerprint=ctx.fingerprint())

    def verify(self, aid, lock, telemetry_log, expected, auditors):
        reproductions = [self.build(aid, lock, telemetry_log, seed=s)
                         for s in auditors.seeds]
        bit_ok = all(r.hash == expected.hash for r in reproductions)
        num_ok = all(rclose(r.value, expected.value, self.tol) for r in reproductions)
        if bit_ok and num_ok and auditors.independent_count() >= 2:
            return R3                      # 独立多方复现
        if bit_ok and num_ok:
            return R2                      # 封闭可复现
        if num_ok:
            return R1                      # 单点数值可复现
        return R0                          # 不可复现

    def downgrade_if_unreproducible(self, meta, rho):
        max_level = {R0: P0, R1: P1, R2: P2, R3: P3}[rho]
        return min(meta.provenance, max_level)
```

### IP-154 TPRA 溯源感知风险会计

```python
class TaintRiskAccountant:
    def __init__(self, lam_t, lam_r, lam_d, q_min):
        self.lam_t, self.lam_r, self.lam_d, self.q_min = lam_t, lam_r, lam_d, q_min

    def taint(self, closure, resolver):
        # 联合界：闭包内缺陷先验求和，单调且保守
        return min(1.0, sum(resolver.defect_prior(m) for m in closure.values()))

    def delta_f_eff(self, delta_f_base, closure, rho_rep, resolver,
                    q_eff, node_weights=None):
        t = self.taint(closure, resolver)
        d_taint = self.lam_t * t
        w = node_weights or {aid: 1.0 for aid in closure}
        d_rep = self.lam_r * sum(w[aid] for aid, m in closure.items()
```

### IP-156 DR-CP 分布鲁棒共形

```python
class DistributionallyRobustConformal:
    def __init__(self, eps0=0.01, kappa=0.5, lam_rep=0.05, alpha=0.1, delta=0.05):
        self.eps0, self.kappa, self.lam_rep = eps0, kappa, lam_rep
        self.alpha, self.delta = alpha, delta

    def ambiguity_radius(self, taint, rho_rep, weights):
        d_rep = sum(w for aid, w in weights.items() if rho_rep[aid] < R2)
        return self.eps0 + self.kappa * taint + self.lam_rep * d_rep

    def calibrate(self, residuals, taint, rho_rep, weights):
        eps = self.ambiguity_radius(taint, rho_rep, weights)
        n = len(residuals)
        # W1 球上最坏分位数：经验分位数 + eps 的漂移上界
        q_emp = np.quantile(residuals, 1 - self.alpha)
        q_dr = q_emp + eps * (1 + 1/n) + sqrt(log(1/self.delta) / n)
        delta_amb = eps + sqrt(log(1/self.delta) / n)
        return ConformalModel(q_dr=q_dr, eps=eps, delta_amb=delta_amb, n=n)

    def predict(self, point_est, model):
        return Interval(point_est - model.q_dr, point_est + model.q_dr)
```

```python
def evidence_gate_osc(cp, delta_f_eff, interval, closure, rho_rep):
    # 1) 声明级证据不得单独支撑不可逆/高能力承诺
    hard_ok = all(m.provenance >= P2 for m in closure.values())
    # 2) 有效失效界必须落在门限内（PRA 已含污点/复现/多样性惩罚）
    risk_ok = delta_f_eff <= cp.delta_f_gate

    # 4) 用途约束：证据的 scope 必须覆盖 cp 所需能力
    scope_ok = all(cp.capability in m.scope for m in closure.values())
```

```python
class RobustnessDebtLedger:
    def __init__(self, theta, d_max, gamma=0.95):
        self.value, self.theta, self.d_max, self.gamma = 0.0, theta, d_max, gamma

    def update(self, closure, rho_rep, q_eff, q_min):
        accrue = sum(1.0 for m in closure.values()
                     if m.provenance <= P1 or len(m.maintainers) <= 1)
        accrue += max(0, q_min - q_eff) / q_min
        repay = sum(1.0 for a, r in rho_rep.items() if r >= R3)
```

**正确性定理（Open-Source Robust Evidence Soundness, ORES）**
假设 A22–A55（第 53–59 轮）成立；**(A56)** EBOM 音完备：`C(v)` 覆盖 v 的所有实际依赖，无隐藏依赖、无未解析版本；**(A57)** RER 确定性：配方在相同 `(lock, telemetry, seed)` 下逐位可重建，审计者集合中至少两个独立；**(A58)** REA 鲁棒：有效诚实 fork 数 `q_eff≥q_min` 且污染比例 `f<α_B`；**(A59)** DR-CP：真实部署分布 `Q_true∈B_ε(P̂_n)`，模糊半径 `ε` 诚实覆盖漂移；**(A60)** PRA 单调：污点先验 `π_u` 是真实缺陷率上界，`Δ_*` 为真实风险增量的保守上界。则：

1. **溯源调整的校准健全性**：证据层后验校准误差 `ECE ≤ ε_meta + δ_taint(C) + δ_rep(C)`；且不可复现证据的贡献被 DR 半径吸收，覆盖率 `≥1−α−δ_amb(ε,n)`。
2. **鲁棒聚合保证**：当污染 fork 比例 `f<α_B` 且 `q_eff≥q_min` 时，`d(ŷ,f_h)≤c·s`；若 quorum 丢失，系统必须进入 `DEGRADE_PROVENANCE`，不得以少数量 fork 输出承诺。
3. **供应链风险单调性**：`C` 扩张、任一 `ρ_rep` 下降、或 `q_eff` 下降，均使 `δ_f^eff` 不减；因此「新增一个看似无害的上游依赖」绝不可能降低有效失效界。
4. **声明级证据隔离**：`ρ_rep<R2` 的节点不能单独支撑高能力/不可逆承诺（证据门 hard_ok 失败），只能与 P2+ 证据联合或降档使用。
5. **可复现可审计性**：任意第三方持有 `(J_osc, L, L_tele, recipe, seed)` 可重放并逐位验证发布；不可复现的发布不得作为硬证据。
6. **鲁棒性债收敛与强制补偿**：`D_rb` 在 `γ<1` 下对固定输入收敛到 `accrue/(1−γ)` 上界；`D_rb>θ_debt` 必然触发补偿模式，`D_rb≥D_max` 禁止不可逆承诺。

### IP-152 EBOM 解析器（依赖闭包 + 锁文件 + 冲突检测）

```python
class EBOMResolver:
    def __init__(self, registry, weakness_db):
        self.registry, self.weakness_db = registry, weakness_db

    def resolve(self, artifact_ids):
        closure, stack, conflicts = {}, [], []
        def visit(aid, constraints):
            if aid in stack: raise EBOMError(f"dependency_cycle:{aid}")
            node = self.registry.get(aid)
            if node is None: raise EBOMError(f"missing_artifact:{aid}")
            ver = self._select_version(node, constraints)
            if aid in closure:
                if closure[aid].ver != ver:
                    conflicts.append((aid, closure[aid].ver, ver))
                return
            stack.append(aid); closure[aid] = node.versions[ver]
            for dep, c in node.versions[ver].deps.items(): visit(dep, c)
            stack.pop()
        for aid in artifact_ids: visit(aid, None)
        if conflicts: raise EBOMError(f"ebom_version_conflict:{conflicts}")
        return EBOMGraph(closure), {a: (m.ver, m.hash) for a, m in closure.items()}

    def defect_prior(self, meta):
        if meta.id in self.weakness_db: return self.weakness_db[meta.id].risk
        base = {P0: 0.30, P1: 0.15, P2: 0.05, P3: 0.01}[meta.provenance]
        bus = 1.0 / (1.0 + len(meta.maintainers))
        return min(1.0, base * (0.5 + 1.5 * bus))
```

### IP-153 RER 可复现证据重建（四方复现分级）

```python
class ReproducibleEvidenceBuilder:
    def __init__(self, recipe_registry, tol=1e-12):
        self.recipes, self.tol = recipe_registry, tol

    def build(self, aid, lock, telemetry_log, seed=0):
        recipe = self.recipes[aid]
        ctx = DeterministicContext(seed=seed, forbid={'wallclock','unseeded_rng',
                                                      'threads>1','device_entropy'})
        with ctx:
            out = recipe.run(lock=lock, telemetry=telemetry_log)
        return EvidenceOutput(value=out, hash=stable_hash(out),
                              ctx_fingerprint=ctx.fingerprint())

    def verify(self, aid, lock, telemetry_log, expected, auditors):
        reps = [self.build(aid, lock, telemetry_log, seed=s) for s in auditors.seeds]
        bit_ok = all(r.hash == expected.hash for r in reps)
        num_ok = all(rclose(r.value, expected.value, self.tol) for r in reps)
        if bit_ok and num_ok and auditors.independent_count() >= 2: return R3
        if bit_ok and num_ok: return R2
        if num_ok: return R1
        return R0

    def downgrade_if_unreproducible(self, meta, rho):
        return min(meta.provenance, {R0: P0, R1: P1, R2: P2, R3: P3}[rho])
```

### IP-154 TPRA 污点传播与风险会计（三项单调惩罚）

```python
class TaintRiskAccountant:
    def __init__(self, lam_t, lam_r, lam_d, q_min):
        self.lam_t, self.lam_r, self.lam_d, self.q_min = lam_t, lam_r, lam_d, q_min

    def taint(self, closure, resolver):
        return min(1.0, sum(resolver.defect_prior(m) for m in closure.values()))

    def delta_f_eff(self, delta_f_base, closure, rho_rep, resolver, q_eff):
        t = self.taint(closure, resolver)
        d_taint = self.lam_t * t
        d_rep = self.lam_r * sum(1.0 for a, m in closure.items() if rho_rep[a] < R2)
        d_div = self.lam_d * max(0.0, self.q_min - q_eff) / self.q_min
        return delta_f_base + d_taint + d_rep + d_div, TaintBreakdown(t, d_taint, d_rep, d_div)
```

### IP-155 REA 拜占庭鲁棒聚合（崩溃点 + quorum 硬约束）

```python
class RobustEvidenceAggregator:
    def __init__(self, q_min, alpha_B=0.4):
        self.q_min, self.alpha_B = q_min, alpha_B

    def aggregate(self, outputs, provenance):
        valid = [(i, o) for i, o in enumerate(outputs)
                 if provenance[i].rho_rep >= R2 and provenance[i].cross_signed]
        q_eff = len(valid)
        if q_eff < self.q_min: return None, None, q_eff, "QUORUM_LOST"
        pts = [o for _, o in valid]
        if is_scalar(pts[0]):
            vals = sorted(pts); k = max(1, int(len(vals) * self.alpha_B))
            y = mean(vals[k:len(vals)-k]) if len(vals) > 2*k else median(vals)
        else:
            y = krum(pts, f=int(len(pts) * self.alpha_B))
        s = max(distance(a, b) for a in pts for b in pts)
        return y, s, q_eff, "OK"
```

### IP-156 DR-CP 分布鲁棒共形（脏度驱动半径）

```python
class DistributionallyRobustConformal:
    def __init__(self, eps0=0.01, kappa=0.5, lam_rep=0.05, alpha=0.1, delta=0.05):
        self.eps0, self.kappa, self.lam_rep = eps0, kappa, lam_rep
        self.alpha, self.delta = alpha, delta

    def ambiguity_radius(self, taint, rho_rep):
        d_rep = sum(1.0 for r in rho_rep.values() if r < R2)
        return self.eps0 + self.kappa * taint + self.lam_rep * d_rep

    def calibrate(self, residuals, taint, rho_rep):
        eps, n = self.ambiguity_radius(taint, rho_rep), len(residuals)
        q_emp = np.quantile(residuals, 1 - self.alpha)
        q_dr = q_emp + eps * (1 + 1/n) + sqrt(log(1/self.delta) / n)
        return ConformalModel(q_dr=q_dr, eps=eps,
                              delta_amb=eps + sqrt(log(1/self.delta)/n), n=n)

    def predict(self, point_est, model):
        return Interval(point_est - model.q_dr, point_est + model.q_dr)
```

### IP-157 OESC 开源证据供应链算子（十步闭环）

```python
def open_source_evidence_operator(M, cp, delta_f_base):
    try:
        closure, lock = M.ebom.resolve(M.artifacts_for(cp))
    except EBOMError as e:
        return degrade_provenance(M, cp, f"ebom:{e}")

    rho_rep = {}
    for aid, meta in closure.items():
        rho_rep[aid] = M.rer.verify(aid, lock, M.telemetry_log[aid],
                                    M.expected_output[aid], M.auditors)

    outputs, prov = M.collect_forks(cp, closure)
    y, spread, q_eff, status = M.rea.aggregate(outputs, prov)
    if status != "OK": return degrade_provenance(M, cp, status)
```

### IP-158 RDL 鲁棒性债账本 + J_osc 可复现发布证书

```python
class RobustnessDebtLedger:
    def __init__(self, theta, d_max, gamma=0.95):
        self.value, self.theta, self.d_max, self.gamma = 0.0, theta, d_max, gamma

    def update(self, closure, rho_rep, q_eff, q_min):
        accrue = sum(1.0 for m in closure.values()
                     if m.provenance <= P1 or len(m.maintainers) <= 1)
        accrue += max(0, q_min - q_eff) / q_min
        repay = sum(1.0 for r in rho_rep.values() if r >= R3)
        self.value = min(self.d_max, max(0.0, self.gamma*self.value + accrue - repay))
        return self.value

@dataclass
class OpenSourceEvidenceCertificate:
    ebom_hash: str
    lockfile_hash: str
    provenance_vec: dict
    rer_audit_log: dict
    rea_quorum: tuple
    dr_radius: tuple
    delta_f_eff: float
    robustness_debt: float
    signature_chain: list
    timestamp: float
    version: int

    def reproduce(self, builder, telemetry_log, seed=0):
        rebuilt = builder.build(self.ebom_hash, self.lockfile_hash, telemetry_log, seed)
        return rebuilt.hash == self.signature_chain[-1].payload_hash

    def verify_chain(self):
        mono = all(self.signature_chain[i].version < self.signature_chain[i+1].version
                   for i in range(len(self.signature_chain)-1))
        hard = all(r in (R2, R3) for r in self.rer_audit_log.values())
        return mono and self.delta_f_eff > 0 and (hard or self.robustness_debt > 0)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| EBOM | O(\|V_E\|+\|E_E\|)；冲突 O(\|V_E\|log\|V_E\|) | O(\|V_E\|+\|E_E\|) | 闭包完备、冲突显式拒绝、无循环 |
| RER | O(N_aud·T_recipe)/发布 | O(\|V_E\|·output) | 定量重建、逐位/ULP 一致、失败即降级 |
| TPRA | O(\|C\|)/检查点 | O(\|C\|) | 污点联合界单调、为真实污染保守上界 |
| REA | O(K²d)（Krum）/O(K log K)（中位数） | O(Kd) | 崩溃点 α_B、quorum 绑定、少数量即 QUORUM_LOST |
| DR-CP | O(n log n)/校准 | O(n) | W1/χ² 覆盖 ≥1−α−δ_amb、半径随脏度单调 |
| OESC | O(EBOM+RER+K²d+DR+门)/cp | 复用 | 供应链健全门、声明级不作硬证据、债务驱动补偿 |
| RDL | O(\|C\|)/更新 | O(1) | 债务非负有界、折旧收敛、超阈强制补偿 |

**正确性定理（ORES, Open-Source Robust Evidence Soundness）**
在 A22–A55 基础上追加 **(A56)** EBOM 音完备（闭包覆盖全部真实依赖、无隐藏依赖）；**(A57)** RER 确定性（相同 `(lock,telemetry,seed)` 逐位可重建，≥2 独立审计者）；**(A58)** REA 鲁棒（`q_eff≥q_min` 且污染比例 `f<α_B`）；**(A59)** DR-CP 模糊集包含真实部署分布；**(A60)** PRA 的 `π_u` 与 `Δ_*` 为真实风险的保守上界。则：

1. **溯源调整校准**：`ECE ≤ ε_meta + δ_taint(C) + δ_rep(C)`；不可复现证据贡献被 DR 半径吸收，覆盖率 `≥1−α−δ_amb(ε,n)`。
2. **鲁棒聚合**：`f<α_B` 且 quorum 满足时 `d(ŷ,f_h)≤c·s`；quorum 丢失强制 `DEGRADE_PROVENANCE`，禁止少数量 fork 输出承诺。
3. **风险单调性**：闭包扩张 / 任一 `ρ_rep` 下降 / `q_eff` 下降，均使 `δ_f^eff` 不减——新增「看似无害」依赖绝不能降低有效失效界。
4. **声明级隔离**：`ρ_rep<R2` 节点不能单独支撑高能力/不可逆承诺，只能联动 P2+ 证据或降档。
5. **可复现审计**：任意第三方可用 `(J_osc,L,L_tele,recipe,seed)` 逐位重放验证；不可复现发布不构成硬证据。
6. **债务收敛与补偿**：`D_rb` 在 `γ<1` 下收敛，`>θ_debt` 触发补偿模式，`≥D_max` 禁止不可逆承诺。
7. **部署界**（新增供应链项）：

```
P_safe ≥ 1 − Σ_cp (δ_f^base + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]

                   + δ_rer·1[复现失败] + δ_rea·1[quorum丢失] + δ_amb(ε,n))
       − P(𝒢 结构性错误未检出) − P(护盾回退失败) − P(τ_int 超时 ∧ 安全停失效)
```
