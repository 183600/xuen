# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「工具调用」×「视觉编码器」）

> R69 把不确定性一分为二，并用「看 / 问 / 触」去主动消解 epistemic 部分，问出了「我该向谁求证、还能问什么」。但 R69 有两个从未写进证书的隐含前提：
> - **（H1）信息动作集是封闭且语义已知的。** R69 的 VoI 公式 `H(M|o) − E[H(M|o,y)]` 默认 `p(y|M,g)` 是已知信道，且候选只有注视/探针/问句三类。真实系统面对的是一个**开放、异构、带契约的工具库**：深度相机、OCR、检索、计算器、仿真器、另一个 VLM、人类专家、甚至一次物理拨动。每个工具都有自己的前置条件、后置条件、副作用、覆盖率、延迟与**可信度**。R69 从不问「这个工具的输出分布，能否把我的两个模态分开」——它只问「谁的信息熵降得多」。
> - **（H2）观测算子 Φ 是一个充分且唯一的视觉编码器。** R69 的「凑近看」隐含假设：换一个视角就能看见差别。但视觉编码器有**解析力上限**：分辨率、混叠、纹理偏置、视场、光谱。同一编码器的不同裁剪给出的是**相关**证据，不是独立证据；当两个模态的差异落在编码器的截止频率以下时，「看」只是**交互戏法**——熵降了，真相没变。R69 的 resolution bonus 可以是假的。
>
> 本轮两个灵感正好补上这两块缺失：
> - **工具调用**把信息动作从「三个手写动作」升级为「可检索、可组合、带类型契约的程序」；它同时引入三个新问题：**可分辨性**（工具能否区分模态）、**相关性**（两个工具是不是同一个模型戴了两顶帽子）、**副作用**（调用是否改变了世界、是否不可逆、是否泄露隐私）。
> - **视觉编码器**把「看」拆成「用哪个透镜、在什么尺度/视角/光谱上看」，并给出一个硬约束：**没有解析力的透镜，再多的注视也不产生信息**。于是「该不该交互」之前多了一道门：**现有仪器能不能分辨这个问题**。
>
> 核心命题：**在问「问谁」之前，先问「我手里的工具和眼睛，是否真的有分辨这个问题的能力」。** 把 R69 的单一 VoI 升级为**可识别 VoI（IVoI）**：先过可分辨性门与前置条件门，再扣掉副作用/不可逆/隐私成本，最后才在**经过独立性审计**的候选集上取最大值。证据纪律从「k 个来源一致」升级为「**k_eff 个有效独立来源一致**」，其中透镜与工具共用同一张相关性矩阵。命名 **ARGUS-RAS**（Active Retrieval & Grounded Uncertainty reSolution：主动检索 × 可分辨性门控的不确定性消解；百眼巨人 Argus 既指多透镜，也指多工具）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我的仪器真的能看见答案吗，还是只是在看见它自己**」——在提问之前，先校准提问的仪器。

## 0. 直觉与动机

**灵感 1（工具调用 → 信息动作是带契约的程序，不是原子动作）**
直觉：R69 的 `g ∈ {注视, 探针, 问句}` 像三个固定按钮；真实的工具调用是一个**程序**：检索工具名 → 检查前置条件 → 绑定参数 → 执行 → 解析后置条件 → 把结果作为带来源的断言返回。工具的输出不是「观测」，而是**一个带假设的声明**：「在工具 τ 的前置条件成立、其训练分布覆盖当前输入、且没有静默失败的前提下，`y` 才是关于世界的证据」。R69 把这些假设全部折叠进一个已知信道，于是 VoI 可能建立在一个根本不成立的信道上。工具调用逼我们把信道显式化：`p(y | M, τ, pre, post, π)`，其中 `π` 是来源（训练数据、厂商、版本），因为**同一来源的工具会一起错**。

**灵感 2（视觉编码器 → 「看」有解析力上限，多透镜不等于多证据）**
直觉：人凑近看能看清，是因为眼睛+大脑在更高空间频率上重新采样；机器人「凑近看」若只是把同一张低分辨率图放大，得到的是插值出来的自信。视觉编码器是一个**有截止频率的算子** `ψ_ω`：两个模态的差异若低于它的可分辨尺度，任何后处理都无法恢复——这不是统计不确定性，而是**观测算子的零空间**。更隐蔽的是，换一个编码器（CLIP→DINOv2→另一个 VLM）看似增加了独立证据，但若它们共享预训练数据/架构/蒸馏教师，它们的错误高度相关，`k=3` 个来源的 `k_eff` 可能只有 `1.2`。R69 的「k 个正交证据源」是一个**被设计者口头声明的正交性**；ARGUS 要把它变成**被数据和来源审计出来的正交性**。

**灵感 3（可分辨性先于信息增益 → 交互戏法必须被显式禁止）**
直觉：信息增益是「做完之后我对 M 的判断更确定」；但如果工具的输出分布在两个模态下几乎相同（`p(y|m_i,τ) ≈ p(y|m_j,τ)`），那么无论执行多少次、熵估计降多少，真实信息增益都为零。更糟的是，若用**被污染的标签**去估熵，系统会「看到一个更尖锐的后验」——这不是信息，是自欺。所以本轮把 VoI 拆成两个因子：`IVoI = 1[可分辨] · 1[前置成立] · (H(M) − E H(M|y)) − 成本`。可分辨性不是一个软分数，而是一个**带校准的假设检验**：在留出集上，工具 τ 对模态对 (i,j) 的 TV 距离或 AUC 必须超过阈值，否则该工具对该模态对**零权重**。

**灵感 4（副作用与不可逆 → 工具调用不是免费的「观测」，它可能改变世界）**
直觉：注视几乎无副作用，但「打开抽屉看看」「发消息问一句」「调用云 API 做超分」不同：前两者改变物理/社交状态，第三者泄露隐私且可能不可逆。R69 的交互预算只有次数/位移/社交成本；工具调用需要一套**效应代数**：每个工具有一个效应向量 `e(τ)`（物理位移、不可逆度、信息外泄、社交打扰、金钱），组合是相加（monoid），预算是一个**偏序约束**，不是标量。关键洞察：**epistemic 动作可能污染 epistemic 状态**——拨动开关后再问「它原来是什么状态」已经晚了。所以工具的前置条件里必须包含「调用不会让问题本身失效」这一条（non-confounding）。

**灵感 5（工具输出是不可信输入 → 污点与数据/指令分离是新的安全边界）**
直觉：一旦系统读 OCR、网页、另一个 VLM 的输出，它就读到了**攻击者可以书写的文本**。工具输出可能包含指令（prompt injection）、可能 schema 漂移、可能是幻觉出来的字段。R69 的「幻影模态」是模型自己产生的；R70 的「幻影工具/幻影字段」是外部产生的，攻击面更大。因此工具输出必须走一条**受污点标记的类型化管道**：外部文本永远是**数据**，永远不能变成**指令**；只有通过校验的、带来源与置信的类型化证据，才允许进入证据后验，且只以**有界似然比**进入。这不是一个过滤器，而是一条**非干扰（non-interference）**性质：即使工具被完全攻陷，它也只能让系统更保守，不能让它更激进。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（ARGUS-RAS 总览）** ARGUS-RAS = (TRM, TSC, LENS, IDA, CPL, TOG, RAS-WM†)。五条不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；工具结果只进审计缓冲，不改在线参数）；
(ii) **可分辨性先于信息增益**：任何信息动作/工具/透镜若未通过 IDA 的模态对可分辨性检验，其 IVoI 记为零，禁止据此交互；
(iii) **独立性与来源透明**：进入证据纪律的每个来源须带可核验来源 `π`，`k_eff` 由相关性矩阵估计，而非设计者声明；
(iv) **副作用与不可逆预算**：工具调用须通过效应代数与不可逆预算检查，且不得使原问题失效（non-confounding）；
(v) **污点非干扰**：工具输出只能以「数据 + 类型化证据」进入，不能以指令进入；被攻陷的工具不得放松任何安全参数。

**定义 311（工具清单与契约 TRM）** 工具 `τ` 的清单
`τ = (name, schema, pre, post, e, c, lat, cov, π, κ)`
其中 `schema` 为类型化输入/输出模式；`pre : Ω → {0,1}` 前置条件；`post : Ω × Y → {0,1}` 后置条件（输出必须满足的可验证断言）；`e ∈ E` 为效应向量（物理位移、不可逆度、隐私外泄、社交、金钱）；`c` 为标量成本、`lat` 延迟、`cov ⊂ Ω` 覆盖率；`π` 为来源（数据/厂商/版本/共享骨干），`κ ∈ [0,1]` 为经审计的信任度。执行返回 `(y, cert_τ)`，`cert_τ` 是后置条件与来源的签名。

**定义 312（效应代数与不可逆预算 EBA）** 效应空间 `(E, ⊕, 0, ⪯)` 为交换幺半群，`e_1 ⊕ e_2` 为副作用叠加，`⪯` 为不可逆偏序。调用链 `T = (τ_1,…,τ_n)` 的总效应 `e(T) = ⊕_i e(τ_i)`。预算约束为多目标偏序：`e(T) ⪯ B`（逐分量），且不可逆分量 `irr(e(T)) ≤ b_irr`。**非混淆约束**：`post(T) ∧ pre(T)` 后，原不确定性问题的模态集合 `M` 与似然 `p(y|M)` 不得被工具自身改变（否则工具把问题改掉了）。

**定义 313（工具信道与可分辨矩阵 DCM）** 对模态对 `(m_i, m_j)` 与工具 `τ`，定义输出信道 `p(y|m,τ)` 与可分辨度
`D_τ(i,j) = TV(p(y|m_i,τ), p(y|m_j,τ))`（或等价的 AUC / 1−重叠系数）。
在认证集上做校准估计 `D̂_τ(i,j)`，并用 bootstrap 给下置信界 `D_τ^-(i,j)`。可分辨阈值 `δ_res`：`D_τ^-(i,j) ≥ δ_res` 才允许 τ 参与该模态对的消解。

**定义 314（可识别 VoI，IVoI）** 对信息动作/工具 `τ`：
`IVoI(τ) = 1[pre] · 1[∃(i,j): D_τ^-(i,j) ≥ δ_res] · [H(M|o) − E_{y~p(·|τ,o)} H(M|o,y)] − λ_e·irr(e(τ)) − c(τ)`
其中 `λ_e` 把不可逆度折算为风险当量。若 `max_τ IVoI(τ) ≤ 0`：不交互，走 R69 兜底。**交互戏法（theater）**定义为「执行后名义熵下降但 `D_τ^- < δ_res`」的情形；定义 310-ii 直接禁止。

**定义 315（工具选择控制器 TSC）** 在注册表检索出的候选集 `𝒯(o)` 上，
`τ* = argmax_{τ ∈ 𝒯(o)} IVoI(τ)`，s.t. `e(τ) ⪯ B_t`、`lat(τ) ≤ L_t`、`coverage(o) = 1`、`RAS-WM†` 认证通过。候选检索本身用冻结检索器，不训练；检索失败 ⇒ 视为无可用工具（退化 R69）。

**定义 316（视觉透镜与解析力）** 一个**透镜视图** `v = (ψ, crop, scale, viewpoint, spectrum, exposure)`，其中 `ψ` 为视觉编码器（ViT/CLIP/DINOv2/深度/红外/事件相机）。其解析算子为 `ψ_v`，截止频率 `ω_c(v)` 由采样率与点扩散函数给出。模态对 (i,j) 在视图 v 下的**可分辨性**为
`R_v(i,j) = 1[ sep_{i,j}(v) ≥ δ(ω_c(v)) ]`，其中 `sep` 为在最可分的判别方向上的分离度。若差异频率 `> ω_c(v)`，则称该差异落在**透镜零空间**，任何对该视图的后处理都不能恢复（奈奎斯特/混叠）。

**定义 317（透镜路由 LENS 与不可约歧义）** `LENS` 选择视图序列以最大化可分辨性/成本比：
`v* = argmax_{v ∈ 𝒱(o)} [ Σ_{i<j} ŵ_i ŵ_j·R_v(i,j) ] / c(v)`，s.t. `e(v) ⪯ B_t`、`RAS-WM†` 通过（注视/移动不得诱发危险）。
若存在模态对 `D_τ^- < δ_res` 且**所有**预算内视图 `R_v=0`，标记**不可约歧义** `U_irr`：禁止交互戏法，直接进入 R69 的保守退避，并在审计中记录「当前仪器无法分辨」。

**定义 318（独立性与有效源数）** 来源集合 `S = {s_1,…,s_k}`（工具或透镜，含 R69 的残差/似然通道）的误差相关性矩阵 `C ∈ [0,1]^{k×k}`，`C_ii=1`。有效独立源数
`k_eff = (1ᵀw)² / (wᵀ C w)`，`w` 为各源参与证据的权重（Kish 有效样本量）。
`C` 由**留出残差**估计并做收缩 `C ← (1−γ)Ĉ + γI`，`γ` 为保守收缩系数。来源 `π` 的共享骨干/共享预训练数据/共享蒸馏教师是 `C` 的结构先验。

**定义 319（独立性-可分辨性审计 IDA）** IDA 输出证书
`Cert_IDA = ({D̂_τ(i,j)}, {C_ab}, k_eff, source_hashes, audit_time)`
Valid ⇔ 所有被使用的模态对 `D̂^- ≥ δ_res` ∧ `k_eff ≥ k_min` ∧ 来源哈希可核验。证书失败 ⇒ 禁止把多源「一致」用于定案，退回单源 + 保守。IDA 的审计集与策略训练集分离，且审计集本身须做投毒检验（定义 322）。

**定义 320（组合规划器 CPL）** 工具链 `T=(τ_1,…,τ_n)` 合法 ⇔ 对每个 `i`，`post(τ_i) ⇒ pre(τ_{i+1})`，且若 `post(τ_i)` 不被满足则链在 `i` 处**熔断**。端到端误差界（引理 21）：`ε(T) ≤ Σ_i η_i + (Π_i L_i)·ε_in + ε_parse`，其中 `η_i` 为后置条件失败概率、`L_i` 为输出的 Lipschitz 放大。CPL 只在 `ε(T) ≤ ε_budget` 时提交链，否则拆成更短、更可验证的链。

**定义 321（工具输出治理 TOG）** 工具输出走污点格 `𝕋 = {data, evidence, instruction}`：外部文本默认 `data`，**永远不得提升为 instruction**；经类型化解析与后置条件校验后可升为 `evidence`，且只以**有界似然比** `ℓ ∈ [−L_max, L_max]` 进入后验。`instruction` 只能来自系统提示与经签名的策略头，不能来自任何工具输出。TOG 同时做 schema 校验、字段级来源标记、以及数值范围/单位一致性检查。

**定义 322（Schema 约束解码与幻影工具防护 SCD）** 工具调用由注册表语法约束解码：`y_t ~ p_θ(· | context, grammar(TRM))`，输出必须是 `TRM` 中存在的工具名与合法参数类型；注册表带签名清单，未签名/版本不符的调用在**解码层**即被拒绝（幻影工具率按构造成 0）。执行前做 **dry-run**：在仿真/沙箱中检查 `pre` 与 `post` 的可满足性，通过后才允许真实调用。

**定义 323（证据纪律升级 IBG†）** 单次工具/单模态回答不得单独定案；需 `k_eff ≥ k_min`（默认 2）个**来源独立**的证据源一致，或单源 IVoI 增益超过高置信阈值且该源 `κ ≥ κ_hi`。与 R69 的差别：`k` 换成 `k_eff`，且每个来源须过 IDA 的可分辨性检验；共享骨干的工具不重复计数。

**定义 324（两级退避与对 R69 的严格包含）** 若消解成功且 `U_irr=0`：`λ = λ_floor(U_ale)`（resolution bonus）；若不可分辨/工具不可用/IDa 失败/被投毒/副作用超预算：`λ = λ_floor(U_ale + U_epi)`。当 `TRM={gaze,probe,ask}`、`𝒱={Φ}`、`C=I`、`k_eff=k` 时，ARGUS 逐指令退化为 R69（定理 18）。安全侧永不弱于 R69。

**定义 325（证书 J_ARGUS）** `J_ARGUS = (J_FLUID, Cert_IDA, D̂^-_min, k_eff, e(T), irr_used, taint_violations, phantom_tool_count, lens_res_cert, argus_ver)`。
Valid ⇔ `Valid(J_FLUID)` ∧ `Cert_IDA` 有效 ∧ 效应/不可逆预算未越界 ∧ `taint_violations=0` ∧ `phantom_tool_count=0` ∧ 透镜解析证书覆盖所有被声明的残余模态对。

**定义 326（主闭环与自适应）** 默认路径只做一次注册表检索 + 一次透镜路由；仅当 `U_epi` 高且 `Cert_IDA` 命中时展开 `n≤3` 的短工具链。实时预算以 P99 为准，检索/审计结果按 `o_t` 的粗粒度哈希缓存。

## 2. 关键算法骨架

```python
# IP-264 TRM：带契约与来源的工具清单（注册表只读，签名校验）
class ToolRegistry:
    def __init__(self, manifests, signature_db):
        self.m = {t.name: t for t in manifests}     # pre/post/effect/provenance
        self.sig = signature_db
    def retrieve(self, o_t, k=8):                   # 冻结检索器，不训练
        return topk_by_coverage(self.m.values(), o_t, k)
    def verify(self, call):
        return (call.name in self.m and self.sig.valid(call.name, call.version)
                and schema_check(call.args, self.m[call.name].schema))

# IP-265 TSC：可识别 VoI（可分辨性 × 前置 × 效应成本）
def iv_voi(tau, modes, w, o_t, budget):
    if not tau.pre(o_t) or not in_coverage(tau, o_t):        return -inf
    if not any(tau.D_minus[i, j] >= DELTA_RES
               for i in range(len(modes)) for j in range(i+1, len(modes))):
        return 0.0                                # 不可分辨 ⇒ 交互戏法，禁止
    gain = entropy(w) - expected_entropy(w, tau, o_t)
    return gain - LAM_E * irreversibility(tau.e) - tau.cost

def choose_tool(tools, modes, w, o_t, B):
    ok = [t for t in tools if effects_leq(t.e, B) and ras_wm.certify_info(t)]
    return max(ok, key=lambda t: iv_voi(t, modes, w, o_t, B), default=None)

# IP-266 LENS：透镜路由（解析力/成本比；不可分辨则报不可约歧义）
def route_lens(modes, w, o_t, budget):
    best, best_score = None, 0.0
    for v in candidate_views(o_t):                # 编码器 × 裁剪 × 尺度 × 视角 × 光谱
        if not effects_leq(v.e, budget) or not ras_wm.certify_view(v):  continue
        score = sum(w[i]*w[j]*v.resolves(i, j)
                    for i in range(len(modes)) for j < i) / v.cost
        if score > best_score: best, best_score = v, score
    if best is None: return None, "IRREDUCIBLE"  # 所有预算内视图都分辨不了
    return best, "OK"

# IP-267 IDA：独立性-可分辨性审计（来源相关性 + 有效源数）
def audit_independence(sources, holdout):
    C  = estimate_error_corr(sources, holdout)     # 留出残差相关
    C  = (1 - GAMMA) * C + GAMMA * np.eye(len(sources))
    w  = np.ones(len(sources))
    k_eff = (w.sum() ** 2) / (w @ C @ w)           # Kish 有效源数
    Dm = {s: bootstrap_lower(s.D, holdout) for s in sources}
    return Cert_IDA(Dm, C, k_eff, hashes(sources))

# IP-268 CPL：前后置链 + 误差界 + 熔断
def plan_chain(tools, goal, budget):
    chain, eps = [], 0.0
    for tau in order_by_precondition(tools, goal):
        if chain and not implies(post(chain[-1]), tau.pre):  break
        eps += tau.eta
        if eps > EPS_BUDGET: break
        chain.append(tau)
    return chain if eps <= EPS_BUDGET else truncate(chain)

# IP-269 TOG：污点非干扰（数据/指令分离 + 有界似然比）
def govern(tool_out, tau):
    if tool_out.taint == "instruction":  return REJECT  # 外部文本永不能成为指令
    y = typed_parse(tool_out, tau.schema)               # 类型化解析
    if y is None or not tau.post(y):     return REJECT  # 后置条件不成立 ⇒ 熔断
    llr = clip(calibrated_llr(y, tau), -L_MAX, L_MAX)   # 有界证据
    return Evidence(y, llr, tau.provenance)

# IP-276 主闭环（继承 R69/FLUID，仅在信息动作处置处替换为工具/透镜）
def ARGUS_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(o, K=adaptive_K(z)), z)
    # 1) 先审计：工具/透镜的可分辨性与独立性（缓存命中则复用）
    cert = M.ida.cached_or_audit(o, M.registry, M.lenses)
    # 2) 不可分辨 ⇒ 禁止交互戏法，直接 R69 保守
    v, lens_status = M.lens.route(modes, o, M.budget)
    if lens_status == "IRREDUCIBLE" or not cert.valid:
        return guarded_fallback(M, U_ale, U_epi)          # 定义 324 失败分支
    # 3) 可识别则选工具/视图；不可识别则退 R69 的 gaze/probe/ask
    tau = M.tsc.choose_tool(M.registry.retrieve(o), modes, o, M.budget) \
          if U_epi > TAU_EPI else None
    g   = tau if tau is not None else v
    # 4) 组合 + 干跑 + 执行；输出过污点治理，且 k_eff 才可定案
    if g is not None:
        chain = M.cpl.plan_chain([g], goal="disambiguate", budget=M.budget)
        assert M.scd.dry_run(chain) and M.tog.precheck(chain)
        ev    = [M.tog.govern(run(t), t) for t in chain]
        U_epi = M.cia.update_belief(modes, ev, discipline=("k_eff", cert.k_eff))
    # 5) 风险缩放与认证；工具永不能放松 λ
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(...), wm_preds)
    lam = max(lam, M.eba.safety_shadow(chain) if g is not None else 0.0)
    mode = select_mode(modes, U_epi, lam)
    M.vqa_t.submit_async(g, ev, cert, lam)            # 参与式审计
    return k, lam, mode, (U_ale, U_epi, cert.k_eff)
```

## 3. 推导

**引理 19（可分辨性决定信息增益上界）** 设工具 τ 对任意模态对的输出分布满足 `TV(p_i,p_j) ≤ ε`。则在任何后验更新下，期望熵降 `E[ΔH] ≤ h_b(ε) + ε·log(|M|−1)`（`h_b` 为二元熵），且当 `ε→0` 时 `IVoI→0`。系：**名义熵降可以任意大而真实信息为零**——只要后验被错误校准；这就是交互戏法的数学来源，也是「可分辨性先于 VoI」的原因。

**引理 20（相关证据的次可加性与伪独立）** 设 k 个来源的误差含共享潜因子（相关 `ρ`），则联合信息增益 `≤ Σ_i g_i − (ρ/2)·Σ_{i≠j}√(g_i g_j)`，有效源数 `k_eff=(1ᵀw)²/(wᵀCw)`。若 `k` 个来源共享同一骨干/预训练数据，则 `k_eff→1`，k-一致错误率上界 `δ_p·ρ^{k_eff−1}+ε_σ` 退化为单源上界 `δ_p+ε_σ`。系：**「两个工具都说 X」在 `k_eff≈1` 时只是「一个工具说了两遍」**；证据纪律必须按 `k_eff` 计数。

**引理 21（工具链误差的复合界）** 链长 n，设每个 `τ_i` 的后置条件失败概率 `≤ η_i`、输出 Lipschitz 常数 `L_i`、解析误差 `ε_parse`，则端到端误差 `ε(T) ≤ Σ_i η_i + (Π_i L_i)·ε_in + ε_parse`。系：**链越长，可验证性越差但误差上界越松**；因此默认链长 ≤ 3，且每步必须能独立验证后置条件（否则熔断）。

**引理 22（透镜解析极限）** 若模态差异的空间频率高于视图 `v` 的截止频率 `ω_c(v)`（由采样率与点扩散函数决定），则该差异落在 `ψ_v` 的零空间，任何对 `ψ_v(o)` 的后处理都不能恢复；仅当存在视图 `v'` 满足 `ω_c(v') > 频率`，或通过主动运动产生视差/多视角超分辨时，才可分辨。系：**「凑近看」必须改变截止频率，而不是放大同一张图**；否则是交互戏法。

**定理 18（ARGUS 严格包含 R69）** 在 A99–A104 下，ARGUS 的期望风险 ≤ R69；且当工具库退化为 `{gaze,probe,ask}`、透镜族退化为 `{Φ}`、相关性 `C=I` 且 `D≥δ_res` 时，两者**逐指令相同**。故 R69 是 ARGUS 在「封闭工具集 + 单一充分透镜」边界上的退化。

**定理 19（工具不获得放松安全的权限）** 任何工具调用 `τ` 都需过 `pre/post`、效应预算、`RAS-WM†` 与 TOG；`λ` 的更新只依赖 `U_ale` 与未消解 `U_epi`，工具输出只能**降低** `U_epi`（且经有界似然比），不能直接改变 `λ` 的下界。即使 `τ` 被完全攻陷并返回任意 `y`，`λ ≥ λ_floor(U_ale)` 仍成立，且 `e(T) ⪯ B` 保证副作用有界 ⇒ 控制连续、无新突变（继承 R68 定理 15、R69 定理 17）。

**定理 20（污点非干扰）** 在 TOG 强制「外部文本 ∈ data、instruction 只来自签名策略头」且证据以有界 LLR 进入时，任意工具输出对安全参数 `(λ, k, 安全包络)` 的影响为 0；对后验的影响被 `L_max` 限制，因而投毒的最大后验偏移有界。攻陷一个工具最多使系统更保守或更慢，不能使其越界。

## 6. 本轮最大风险

**一句话**：ARGUS 的全部可信度押在「工具清单是诚实的、来源审计是准的」这一前提上——**若两个工具/两个编码器其实共享同一骨干、同一预训练数据或同一蒸馏教师，而 `C` 与 `D̂` 的有限审计集又估计不准，系统会把「一个模型戴两顶帽子」认证成 `k_eff=2` 的独立共识，从而在伪独立之上盖下「已验证」的章；更糟的是工具输出可被注入，系统会以更高的自信走向一个被外部书写、且被自己的审计链背书过的错误**——**用不可信的仪器去校准仪器，比不校准更危险**。

**次级风险与缓解**：1) 可分辨性估计的分布外失效 → 审计集与训练集分离 + 保守下置信界 + E314；2) 工具链误差放大 → 链长 ≤3、逐步后置条件熔断、引理 21；3) 不可逆/副作用 → 效应代数 + 偏序预算 + 非混淆约束；4) 提示注入/字段幻觉 → 污点非干扰 + 有界 LLR + schema 约束解码；5) 注册表漂移与投毒 → 签名清单 + 来源哈希 + 定期重审 `Cert_IDA`。

## 2. 形式化定义（要点版）

**定义 310（总览与五不变式）** ARGUS-RAS=(TRM,TSC,LENS,IDA,CPL,TOG,RAS-WM†)：零学习写操作继承；**可分辨性先于信息增益**；**独立性与来源透明**；**副作用/不可逆预算 + 非混淆**；**污点非干扰**。

**定义 311–312（TRM 与效应代数）** 工具清单 `τ` 含 `pre/post/schema/effect/cost/latency/coverage/provenance/trust`，返回 `(y, cert_τ)`；效应是交换幺半群，预算为逐分量偏序 `e(T) ⪯ B` 且 `irr(e(T)) ≤ b_irr`；调用不得改变原问题的模态集与似然（non-confounding）。

**定义 313–314（可分辨矩阵与 IVoI）** `D_τ(i,j)=TV(p_i,p_j)`，用 bootstrap 下界 `D^-`；可分辨门 `D^- ≥ δ_res`。`IVoI(τ)=1[pre]·1[∃D^-≥δ]·[H(M)−E H(M|y)] − λ_e·irr(e) − c`；`IVoI≤0` 则不交互。**交互戏法** = 名义熵降但 `D^-<δ`，被不变式 (ii) 禁止。

**定义 315（TSC）** `τ*=argmax IVoI`，s.t. 效应/延迟/覆盖率/RAS-WM†；注册表检索失败 ⇒ 无工具、退 R69。

**定义 316–317（透镜与路由）** 视图 `v=(ψ,crop,scale,viewpoint,spectrum,exposure)`，截止频率 `ω_c(v)`；可分辨 `sep ≥ δ(ω_c)`。LENS 最大化 `Σŵ_iŵ_j R_v(i,j)/c(v)`；若预算内所有视图都不可分辨 ⇒ `U_irr`，禁止戏法、走 R69 保守。

**定义 318–319（独立性与 IDA）** `k_eff=(1ᵀw)²/(wᵀCw)`，`C←(1−γ)Ĉ+γI`；`Cert_IDA` 记录 `D̂`、`C`、`k_eff`、来源哈希。Valid ⇔ `D^-≥δ_res` ∧ `k_eff≥k_min` ∧ 哈希可核验；失败则退回单源保守。审计集与训练集分离并做投毒检验。

**定义 320（CPL）** 合法链 `post(τ_i)⇒pre(τ_{i+1})`，不满足即熔断；误差界 `ε(T)≤Ση_i+(ΠL_i)ε_in+ε_parse`，仅在 `ε(T)≤ε_budget` 提交。

**定义 321–322（TOG 与 SCD）** 污点格 `data/evidence/instruction`，外部文本永不为指令；类型化解析 + 后置校验后升为 evidence，仅以有界 LLR 进入后验。工具调用由 `grammar(TRM)` 约束解码、签名与 dry-run 校验 ⇒ 幻影工具按构造成 0。

**定义 323–324（证据纪律与退避）** 单源/单次不定案；需 `k_eff≥k_min` 独立源一致，或单源高增益且 `κ≥κ_hi`。消解成功 `λ=λ_floor(U_ale)`；不可分辨/不可用/IDA 失败/被投毒/超预算 `λ=λ_floor(U_ale+U_epi)`。R69 = 封闭工具集 + 单一透镜 + `C=I` 边界。

**定义 325–326（证书与主闭环）** `J_ARGUS` 并入 `Cert_IDA/D̂⁻/k_eff/e(T)/taint/phantom/lens_cert`；默认一次检索 + 一次路由，仅高 `U_epi` 且 IDA 命中时展开短链；检索/审计按粗粒度哈希缓存。

## 3. 关键算法伪代码

```python
# IP-264 TRM：带契约与来源的工具清单（只读、签名校验）
class ToolRegistry:
    def retrieve(self, o_t, k=8):  return topk_by_coverage(self.m.values(), o_t, k)
    def verify(self, call):
        t = self.m.get(call.name)
        return (t is not None and self.sig.valid(call.name, call.version)
                and schema_check(call.args, t.schema))

# IP-265 TSC：可识别 VoI（可分辨性 × 前置 × 效应成本）
def iv_voi(tau, modes, w, o_t):
    if not tau.pre(o_t) or not in_coverage(tau, o_t):  return -inf
    if not any(tau.D_minus[i, j] >= DELTA_RES
               for i in range(len(modes)) for j in range(i+1, len(modes))):
        return 0.0                                  # 不可分辨 ⇒ 交互戏法，禁止
    return (entropy(w) - expected_entropy(w, tau, o_t)
            - LAM_E * irreversibility(tau.e) - tau.cost)

def choose_tool(tools, modes, w, o_t, B):
    ok = [t for t in tools if effects_leq(t.e, B) and ras_wm.certify_info(t)]
    return max(ok, key=lambda t: iv_voi(t, modes, w, o_t), default=None)

# IP-266 LENS：解析力/成本路由；都分辨不了则报不可约歧义
def route_lens(modes, w, o_t, budget):
    best, best_s = None, 0.0
    for v in candidate_views(o_t):                  # 编码器×裁剪×尺度×视角×光谱
        if not effects_leq(v.e, budget) or not ras_wm.certify_view(v):  continue
        s = sum(w[i]*w[j]*v.resolves(i, j)
                for i in range(len(modes)) for j in range(i)) / v.cost
        if s > best_s: best, best_s = v, s
    return (best, "OK") if best else (None, "IRREDUCIBLE")

# IP-267 IDA：来源相关性 + 有效源数 + 可分辨下界
def audit_independence(sources, holdout):
    C = estimate_error_corr(sources, holdout)
    C = (1 - GAMMA) * C + GAMMA * np.eye(len(sources))
    w = np.ones(len(sources)); k_eff = (w.sum()**2) / (w @ C @ w)
    return Cert_IDA({s: bootstrap_lower(s.D, holdout) for s in sources},
                    C, k_eff, hashes(sources))

# IP-269 TOG：污点非干扰（外部文本永不为指令 + 有界证据）
def govern(tool_out, tau):
    if tool_out.taint == "instruction":  return REJECT
    y = typed_parse(tool_out, tau.schema)
    if y is None or not tau.post(y):     return REJECT
    return Evidence(y, clip(calibrated_llr(y, tau), -L_MAX, L_MAX), tau.provenance)

# IP-276 主闭环（继承 R69/FLUID，仅在信息动作处置处替换）
def ARGUS_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(o, K=adaptive_K(z)), z)
    cert = M.ida.cached_or_audit(o, M.registry, M.lenses)
    v, lens_status = M.lens.route(modes, o, M.budget)
    if lens_status == "IRREDUCIBLE" or not cert.valid:
        return guarded_fallback(M, U_ale, U_epi)            # 定义 324 失败分支
    tau = (M.tsc.choose_tool(M.registry.retrieve(o), modes, o, M.budget)
           if U_epi > TAU_EPI else None)
    g = tau if tau is not None else v
    if g is not None:
        chain = M.cpl.plan_chain([g], goal="disambiguate", budget=M.budget)
        assert M.scd.dry_run(chain)                          # 幻影工具 = 0
        ev = [M.tog.govern(run(t), t) for t in chain]
        U_epi = M.cia.update_belief(modes, ev, discipline=("k_eff", cert.k_eff))
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), wm_preds)
    if g is not None: lam = max(lam, M.eba.safety_shadow(chain))
    mode = select_mode(modes, U_epi, lam)
    M.vqa_t.submit_async(g, ev, cert, lam)
    return k, lam, mode, (U_ale, U_epi, cert.k_eff)
```

## 4. 推导

**引理 19（可分辨性决定信息增益上界）** 若 τ 对任意模态对 `TV(p_i,p_j)≤ε`，则 `E[ΔH] ≤ h_b(ε)+ε·log(|M|−1)`，`ε→0 ⇒ IVoI→0`。系：名义熵降可任意大而真实信息为零（后验被错误校准时）——**可分辨性先于 VoI**。

**引理 20（相关证据次可加与伪独立）** 共享潜因子相关 `ρ` 下联合增益 `≤ Σg_i − (ρ/2)Σ_{i≠j}√(g_i g_j)`；`k_eff=(1ᵀw)²/(wᵀCw)`。共享骨干 ⇒ `k_eff→1`，k-一致上界 `δ_p·ρ^{k_eff−1}+ε_σ` 退化为单源上界。系：**「两个工具都说 X」在 `k_eff≈1` 时只是「一个工具说了两遍」**。

**引理 21（工具链误差复合界）** 链长 n，`ε(T) ≤ Ση_i + (ΠL_i)ε_in + ε_parse`。系：链越长可验证性越差、上界越松 ⇒ 默认链长 ≤3、逐步熔断。

**引理 22（透镜解析极限）** 差异频率 `> ω_c(v)` 即落入 `ψ_v` 零空间，后处理不可恢复；须存在 `ω_c(v')>频率` 或主动视差/多视角超分辨。系：**「凑近看」必须改变截止频率，而非放大同一张图**。

**定理 18（ARGUS 严格包含 R69）** A99–A104 下期望风险 ≤ R69；当 `TRM={gaze,probe,ask}`、`𝒱={Φ}`、`C=I`、`D≥δ_res` 时逐指令相同。R69 = 封闭工具集 + 单一充分透镜边界。

**定理 19（工具不获得放松安全的权限）** 工具须过 `pre/post`、效应预算、`RAS-WM†`、TOG；`λ` 只依赖 `U_ale` 与未消解 `U_epi`，工具输出只能经有界 LLR 降低 `U_epi`。即使工具被攻陷，`λ ≥ λ_floor(U_ale)` 且 `e(T)⪯B` ⇒ 控制连续、无新突变（继承 R68 定理 15、R69 定理 17）。

**定理 20（污点非干扰）** 外部文本 ∈ data、instruction 仅来自签名策略头、证据有界 LLR ⇒ 任意工具输出对 `(λ,k,安全包络)` 影响为 0，对后验影响被 `L_max` 限制。攻陷工具最多使系统更慢/更保守，不能越界。

## 7. 本轮最大风险

**一句话**：ARGUS 的全部可信度押在「工具清单诚实、来源审计准确」这一前提上——**若两个工具/两个编码器其实共享同一骨干、同一预训练数据或同一蒸馏教师，而 `C` 与 `D̂` 的有限审计集又估计不准，系统会把「一个模型戴两顶帽子」认证成 `k_eff=2` 的独立共识，在伪独立之上盖下「已验证」的章；更糟的是工具输出可被注入，系统会以更高的自信走向一个被外部书写、且被自己的审计链背书过的错误**——**用不可信的仪器去校准仪器，比不校准更危险**。

**次级风险与缓解**：可分辨性估计的分布外失效（审计集/训练集分离 + 保守下置信界 + E314）；工具链误差放大（链长 ≤3 + 逐步熔断 + 引理 21）；不可逆/副作用（效应代数 + 偏序预算 + 非混淆）；提示注入/字段幻觉（污点非干扰 + 有界 LLR + schema 约束解码）；注册表漂移与投毒（签名清单 + 来源哈希 + 定期重审 `Cert_IDA`）。
