# 第 66 轮（承接第 65 轮「VISTA 故障归因闭环」IP-214~223；灵感循环第 1 轮；本轮灵感：「视觉问答」×「力矩控制」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述的最大风险很尖锐：**VISTA 的归因依赖「故障属于有限假设集」与「视觉/几何失效相互独立」，未知复合故障会被强行归入最近假设、只膨胀错误的球，而系统因「已经归因」反而更自信地继续执行。** 但再往下一层看，VISTA 仍在回答「哪个已知元件坏了」，它默认了「证据本身有资格被相信」。本轮换一个更朴素、也更前置的问题：**当系统用 VQA 说「这个杯子是空的 / 这个表面是干的 / 这个铰链向左开」时，它到底凭什么敢把这句话变成一个力矩？** 本轮核心命题是：
>
> **把「答案正确」升级为「答案有凭证」：VQA 只产生可错、可弃权的语义断言；力矩是唯一物理因果、有硬界、低隐私的可错校验器；用「默认保守、未验证只收紧、已验证才放开」的单向阀，把语义不确定性挡在不可逆力矩之外。**

## 0. 直觉与动机

**灵感 1（视觉问答 → 危险的不是答错，而是「没有资格被相信」）**
直觉：VQA 的常规评测问「答对了吗」。但对操作机器人，真正危险的是**一个碰巧答对、却从未被任何可能证伪的证据支撑过的答案**。这种答案和幻觉在安全上是等价的：系统都无权把它变成力。于是核心对象从「答案 a」换成「断言 q + 凭证 w」——凭证记录这句话是被语言先验猜的、被多通道印证的，还是被一次物理实验判定过的。VQA 的价值也随之重新定位：它提供**开放词汇、组合式、任务相关的语义假设**（有没有液体、是否易碎、铰链朝向、会不会倾倒），这些正是力矩控制器最缺、又最难从像素直接估出的量；但它只是**假设生成器**，不是真值。允许它说「不知道」，比逼它猜一个高置信答案安全得多。

**灵感 2（力矩控制 → 唯一「物理因果 + 硬有界 + 低隐私」的校验器）**
直觉：视觉、语言、几何可能共享同一个分布外失效源（透明、镜面、对抗 patch），但**力矩残差**来自关节力矩传感/动量观测器，不经过相机、也不经过语言骨干，失效结构不同。更重要的是，力矩有三条别处没有的性质：(i) **物理因果**——任何与操作相关的语义断言，最终都蕴含一个机械后果（质量、摩擦、刚度、铰链、易碎、是否装满）；(ii) **硬有界**——执行器饱和与力矩/能量包络是物理真实，不是预测，上层模型再错也越不过去；(iii) **低隐私**——低维力/力矩不含可识别图像。因此力矩不是「又一种感知」，而是**语义断言的物理裁判**。

**灵感 3（核心洞见 → 正确的指标是「可判定性」，不是「准确性」）**
直觉：不是所有问题都能被力矩回答。「它是猫吗」不能；「它有多重 / 多硬 / 装没装满 / 铰链朝哪 / 会不会滑」能。于是引入**力矩可判定性**：一个断言可判定 ⇔ 存在一个**被动、能量有界、可逆**的交互策略，使不同答案下的力矩残差分布可分离到给定裕度。这把「问什么、花多少机械功去问、问不出来怎么办」变成可计算的问题。必须诚实：可分离度随注入能量至多按 ∼√E 增长，而最脆弱物体的可逆能量预算 E_rev 很小——**很多最重要的语义（易碎、内容、意图）恰恰最难被安全地问出来**。

**灵感 4（合流 → LEVER：Language-Evidence Verification via Energy-bounded Robot-interaction）**
闭环：场景/任务 → VQA 生成**带力矩后果映射的语义断言**（VQC）→ 按**机械杠杆**排序该问什么（QST）→ 检查**力矩可判定性**（TAC）→ 对高杠杆且可判定的断言执行**被动能量有界探针**（PEP）→ 力矩-语义矛盾归因（TCR）→ 更新**凭证等级**（WGL）→ 断言经**语义容许力矩集**（SATS）单向阀映射为力矩约束 → 在权限内规划与执行 → 剩余预算做下一次查询（SIE）→ 对抗语义/力矩认证（AIC-L）。第 65 轮在「感知-几何-接触」层做故障归因；LEVER 在其**上一层（语义）与下一层（执行器力矩）**之间加了一道**凭证闸门**：语义只能提议，物理才能授权。

**灵感 5（VISTA 组件的原位升级）**
- **VCV → VQC/QST**：视觉接触验证扩展为「语义断言编译 + 机械杠杆排序」，只把与力矩相关的断言送进安全链，机械无关的断言不花探针。
- **FIR → TCR**：故障假设在感知/力/模型之外增 `H_vqa`（语义错）与 `H_unobs`（不可判定，不是故障）；单次矛盾不足以归因，需第二个不同构型/频段的探针。
- **RSC-V → SATS**：不确定球之上再叠一层**语义容许力矩集**，只由有凭证的断言开启。
- **AFA → PEP/SIE**：探针从「最大化故障假设互信息」升级为「在被动能量预算下最大化语义断言的机械杠杆收益」，并按每焦耳收益排序。
- **CSC → CSC-L**：认证前缀同时要求落在 SATS 内，且不可逆步需要 `adjudicated` 凭证。
- **AIC-V → AIC-L**：干扰集增文本注入、场景内误导文字、对抗 VQA，以及「可判定性欺骗」（诱导系统去做不可逆探针）。
- **J_vista → J_lever**：证书增 warrant_vector、adjudication_energy、default_envelope_hash、vqa_calib_ver、unadjudicable_flags。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（LEVER 闭环）**：LEVER = (VISTA, QST, VQC, TAC, PEP, SATS, TCR, WGL, SIE, AIC-L, J_lever)。定位：VISTA 之上的「语义凭证 + 力矩裁判」层。不变式：**未验证断言只能收紧力矩域；只有已判定断言能放开；不可逆动作必须持已判定凭证；实时流只做包络钳制、能量计量与凭证查表，零学习写操作。**
- **定义 234（语义断言 q）**：q=(φ_q, A_q, π_q, C_q, κ_q)。φ_q 为带真值条件的命题（如 m≤0.5kg、k≤200N/m、contains_liquid）；A_q 为答案空间（含 `unknown` 弃权）；π_q 为 VQA 后验；C_q: A_q→2^{T_adm} 为**力矩后果映射**（每个答案允许/禁止的力矩-力-阻抗约束）；κ_q∈{reversible, irreversible} 为兑现该断言所涉及的不可逆性。
- **定义 235（机械杠杆 L(q)）**：L(q)=E_{π_q}[ΔVol(T_adm|a)]·(1+λ_irr·1[κ_q=irreversible])，即解出该断言后容许力矩集体积（或保守裕度）的期望收缩量，乘不可逆性权重。L(q)=0 的断言**机械无关**，不进入安全链、不花探针；问题按单位能量杠杆 L(q)/E*(q) 排序。
- **定义 236（凭证等级 w）**：w(q)∈{0 `unsupported`（仅语言先验）, 1 `corroborated`（≥2 个非力矩独立通道一致）, 2 `adjudicated`（被动探针在裕度 δ 下分离答案）, 3 `contested`（力矩与 VQA 矛盾）}。只有 w=2 可放开默认包络、支撑不可逆动作；w=1 仅可收紧；w=0 视为无信息；w=3 强制保守并触发 TCR。
- **定义 237（力矩可判定性 TAC）**：断言 q 在预算 (E, τ_max, T) 下可判定 ⇔ 存在被动策略 π∈Π 使 ∀a≠a′，残差分布 P_a、P_{a′} 满足 d(P_a,P_{a′})≥δ，且注入能量 ≤E、接触力/压强 ≤限、不越过可逆阈值 E_rev。记最小能量 E*(q,δ)。若 E*(q,δ)>E_rev 或分离所需能量超过任务预算 → `unadjudicable`，**永不**当作已验证。
- **定义 238（被动能量有界探针 PEP）**：探针 π 由端口哈密顿控制器实现，能量平衡 dH/dt=−∂HᵀR∂H+yᵀu，R⪰0 保证无源性；注入能量 E_in=∫yᵀu dt≤E_budget。探针族 Π={tap（小幅冲激估有效惯量）, chirp/dither（频域估刚度/阻尼）, compliant_press（准静态估接触刚度）, ramp_sweep（估摩擦/突破力）, slow_lift（估重力负载/内容）}。每个探针带 `energy_meter` 与 `reversibility_guard`（应力/应变/滑移阈值）。
- **定义 239（语义容许力矩集 SATS）**：S_T = T_default ∩ ⋂_{q:w(q)≥1} C_q(â_q) ∩ ⋂_{q:w(q)=2} (C_q(â_q)∩T_max)。即默认保守包络先成立，未验证断言只能在其内收紧，已判定断言才可按 C_q 放到物理上限。S_T 作为附加力/阻抗约束并入第 65 轮 WCV-V 的 ℱ。
- **定义 240（单向阀与默认包络）**：T_default 为「对最坏可能物体仍安全」的保守包络（力/力矩/能量/阻抗）。规则：w≤1 ⇒ S_T←S_T∩C_q（只收不放）；w=2 ⇒ S_T←S_T∪(C_q∩T_max)（可放到已验证答案允许的上限，但不超执行器硬限）。因此**语义错误至多降低能力，不能突破 T_default；只有物理验证才能换取能力**。
- **定义 241（力矩-语义矛盾与归因 TCR）**：若探针与 VQA 断言矛盾，假设 ℋ_s={H_vqa 语义错, H_tor 力矩模型/摩擦/负载错, H_phys 真实物理超预期（如物体确实易碎/装液）}。单探针不可辨识（三者可产生同向残差）；需**第二、不同构型或不同频段**的探针使签名近正交，才做后验归因。矛盾未归因时 w←`contested`、S_T 收到最保守，并触发再探针或人类确认。
- **定义 242（凭证门控台账 WGL）**：记录 (q, a, w, provenance, t_obs, E_spent, probe_id, tau_model_ver, expiry)。口令：不可逆动作 a† 可执行 ⇔ 存在 q 使 a† 依赖其答案且 w(q)=2、未过期、探针与当前标定一致。台账可审计「这条力矩是谁批准的、花了多少机械能、被哪次探针判定」。
- **定义 243（交互能量预算与停止规则 SIE）**：总机械探针能量 B_mech 有限；选断言子集最大化 ΣL(q)（近似子模）s.t. ΣE*(q)≤B_mech，且每个探针 E≤E_rev。贪心按 L(q)/E*(q) 排序，边际杠杆/焦耳 < 影子价格则停。**问题不是免费的：问错要费机械功与物体寿命。**
- **定义 244（可判定性前沿）**：参数 θ 的两假设分离度 ≈|Δτ|/σ_τ∝√(E/E₀)（白噪声下；信号幅值随注入能量按 √E 增长），故 E*(q,δ)≈E₀(δ/SNR₀)²。该前沿给出「语义可分性—机械能」的硬边界；E_rev 小（易碎/装液/软体）时前沿急剧退化——这是本轮最重要、也最容易被忽视的限制。
- **定义 245（不可逆动作门控）**：不可逆动作集 A†（塑性变形、倾覆、溢出、掉落、切割）需 `adjudicated` 凭证或显式人类授权；w<2 时只能走「可逆等价动作」（先轻推/先抬 1cm/先测刚度）。
- **定义 246（对抗语义与不可观测断言 AIC-L）**：干扰集 ℰ_L=ℰ_V×ℰ_text×ℰ_claim，ℰ_text 含场景内误导文字/提示注入，ℰ_claim 含高置信错误答案、过多断言、诱导不可逆探针。认证要求：**即使所有 VQA 答案为对抗最坏，仍保证 S_T⊆T_default 且物理安全不变**；不可判定断言必须显式标记，不得静默通过。
- **定义 247（LEVER 证书 J_lever）**：J_lever=(J_vista, warrant_vector, adjudication_energy, default_envelope_hash, vqa_calib_ver, unadjudicable_flags, probe_reversibility_ok)。Valid ⇔ Valid(J_vista) ∧ 所有进入 S_T 的放开项 w=2 ∧ 不可逆动作持已判定凭证 ∧ 探针能量/可逆性合规 ∧ 对抗最坏语义下 S_T⊆T_default。
- **定义 248（LEVER 闭环算子）**：语义流 [VQA 生成断言→VQC 编译→QST 杠杆排序→TAC 可判定性→PEP 选探针→TCR 矛盾归因→WGL 更新→SATS 合成→CSP-V/CSC-L 规划]；实时流 [凭证查表→SATS 力矩钳制→能量计量→可逆性看门狗→触发早停]。

## 2. 关键算法骨架

```python
# VQC + QST：语义断言编译与机械杠杆排序（语义流）
claims = vqa.query(scene, task)                  # 带答案集 + 置信 + 允许弃权
claims = [compile_claim(c) for c in claims if leverage(c) > 0]
claims.sort(key=lambda q: q.leverage / est_energy(q), reverse=True)

# TAC：可判定性检查（不可判定永不升级为已验证）
for q in claims:
    if separation_bound(q, E_rev) < DELTA:       # 可逆能量内分不开
        q.warrant = UNADJUDICABLE
        continue
    if q.leverage / q.E_star < SHADOW_PRICE: break

# PEP：被动能量有界探针
probe = argmax_{p in PROBES} L(q) * IG(p, q) / energy(p)
if energy(probe) <= min(B_mech_left, E_rev):
    r = passive_execute(probe)                   # 无源、能量计量、可逆看门狗
    update_warrant(q, compare(r, q))             # 升级 / 置 contested

# SATS：单向阀（未验证只收紧，已验证才放开）
S_T = T_default
for q in claims:
    if q.warrant == CORROBORATED: S_T &= q.C(q.a)
    elif q.warrant == ADJUDICATED: S_T |= (q.C(q.a) & T_MAX)
    elif q.warrant == CONTESTED:   S_T &= most_conservative(q)

# 执行：不可逆动作门控
for a in plan:
    if a in A_DAGGER and not has_adjudicated_warrant(a):
        a = reversible_equivalent(a)             # 先轻探，不直接兑现
    dispatch(project_to(S_T, a))
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（单向阀语义安全）**：若未验证断言只交、已验证断言才放且不超 T_max，则对任意（含对抗最坏）VQA 答案，实际执行的力矩始终落在 T_default 或「已验证答案的物理上限」内；语义错误只会缩小可行集，不会放大。故 VQA 幻觉的后果是**能力下降而非危险执行**。
- **引理 10（可判定性的能量前沿）**：被动探针下信噪比 ∝√(E/E₀)，故在裕度 δ 下最小能量 E*(q,δ)=E₀(δ/SNR₀)²；当 E*(q,δ)>E_rev 时断言不可判定。故「易碎/装液/软体」等最关键语义往往不可安全判定，系统必须学会**承认不知道**，而不是硬判。
- **引理 11（矛盾归因可辨识性）**：单探针下 H_vqa/H_tor/H_phys 的签名列近似共线、不可辨识；两个不同构型或不同频段的探针使签名矩阵满秩时才可分离，否则只能判 `contested`。故「力是裁判」不是绝对——裁判自己也会被模型误差骗。
- **定理 9（LEVER 安全不依赖 VQA 正确）**：在 (i) 硬包络与无源/能量界、(ii) 单向阀、(iii) 不可逆动作需已判定凭证、(iv) 不可判定显式标记 下，即使 VQA 全错，物理安全不变；最坏是保守停滞。这把第 65 轮「归因错→更自信」在**语义层**再切一刀。
- **定理 10（探针能量最优分配）**：杠杆收益近似子模，贪心按 L(q)/E*(q) 在 (1−1/e) 内近似最优；停止规则为边际杠杆/焦耳 < 影子价格。给出「问什么、花多少功、何时停」的可计算答案。
- **实时性**：凭证查表 + SATS 钳制 <0.05ms、能量计量 <0.02ms、可逆性看门狗 <0.03ms，均在实时流；VQA、QST、TAC、TCR、SIE 全在语义流，实时路径仍 ≤2.5ms（沿用第 65 轮 A93 契约，需与 LSF/视觉 ROI 共享编码）。

## 5. 本轮最大风险

**一句话**：LEVER 把「物理裁判」当作语义真值的最后防线，但**裁判本身是可错的**——若力矩模型/摩擦/负载误差让一个弱的、模型相关的残差被误当成「已判定」（假阳性），系统就会把一个错误的 VQA 断言洗成 `adjudicated` 凭证，从而**比未验证的幻觉更危险**：它获得了放开的资格，还带着「已被物理验证」的审计自信；而最关键的语义（易碎、内容、意图）恰恰因可逆能量预算 E_rev 太小而天然不可判定，系统要么长期保守到能力崩溃，要么被迫依赖不可靠的弱判定——这是本轮全部单向阀与安全定理共同依赖的隐藏假设（A95：裁判的假阳性率可忽略且可标定）。

## 2. 形式化定义（完整版）

**定义 233（LEVER 闭环）** LEVER 是 VISTA 之上的「语义凭证 + 力矩裁判」层：在 VISTA 的六层证书外挂载 QST（问题选择）、VQC（断言编译）、TAC（可判定性）、PEP（被动探针）、SATS（语义容许力矩集）、TCR（矛盾归因）、WGL（凭证台账）、SIE（能量调度）、AIC-L（对抗认证），并整合为 J_lever。不变式：**(i) 未验证断言只能收紧力矩域，只有已判定断言能放开；(ii) 不可逆动作必须持未过期的 `adjudicated` 凭证；(iii) 任何探针必须无源、能量有界、可逆性受护；(iv) 实时流只做包络钳制、能量计量与凭证查表，零学习写操作。**

**定义 234（语义断言 q）** q=(φ_q, A_q, π_q, C_q, κ_q)。φ_q 为带真值条件的命题，例如「物体质量 m≤0.5kg」「接触刚度 k≤200N/m」「容器内含液体」「铰链轴为 z 轴」。A_q 为离散答案空间并**必须包含 `unknown`**；π_q∈Δ(A_q) 为 VQA 后验。C_q: A_q→2^{T_adm} 为**力矩后果映射**：给定答案，给出允许的力矩上界、力/压强上界、阻抗范围、允许的运动方向。κ_q 标记兑现该断言是否触及不可逆过程。若 C_q 对答案不敏感（任意 a 给出同一约束），则 L(q)=0，q 机械无关，不进入安全链。

**定义 235（机械杠杆 L(q)）** 记 T_adm 为当前容许力矩集。解出 q 后其条件期望体积收缩
L(q)=E_{π_q}[Vol(T_adm)−Vol(T_adm∩C_q(a))]·(1+λ_irr·1[κ_q=irreversible])。
它同时编码「这个问题对安全/能力有多大影响」与「兑现它的不可逆代价」。L(q)=0 ⇒ 不探测；排序用单位能量杠杆 L(q)/E*(q,δ)。

**定义 236（凭证等级）** w(q)∈{0,1,2,3}：
- 0 `unsupported`：仅由 VQA 语言/像素先验产生，无任何独立印证。
- 1 `corroborated`：≥2 个非力矩独立通道（如深度几何、触觉、本体感觉）对答案一致，且不共享失效支撑。
- 2 `adjudicated`：存在被动探针在裕度 δ 下分离了答案，且探针与当前标定一致、未过期。
- 3 `contested`：力矩与 VQA 矛盾且尚未归因。
规则：只有 w=2 可放开 T_default、支撑不可逆动作；w=1 仅可收紧；w=0 视为无信息；w=3 强制最保守并触发 TCR。

**定义 237（力矩可判定性）** 断言 q 在预算 (E,τ_max,T) 下**可判定** ⇔ 存在被动策略 π∈Π，使任意 a≠a′ 的残差分布 P_a、P_{a′} 满足 d(P_a,P_{a′})≥δ，且 E_in(π)≤E、接触力/压强≤限、应力/应变不越可逆阈值。最小能量
E*(q,δ)=inf{E_in(π): π 满足上式}。
若 E*(q,δ)>E_rev 或 E*(q,δ)>B_mech，则 `unadjudicable`：q 永不升级为 w=2，只能保持 w≤1 或弃权。**可判定性是断言的物理属性，不是模型的置信度。**

**定义 238（被动能量有界探针）** 探针由端口哈密顿控制器实现：状态 x、哈密顿量 H(x)，动力学
ẋ=(J(x)−R(x))∂H/∂x + g(x)u，y=g(x)ᵀ∂H/∂x，R(x)⪰0。
则 dH/dt=−∂HᵀR∂H+yᵀu≤yᵀu，注入能量 E_in=∫yᵀu dt 可在线计量。每个探针强制 E_in≤min(E_budget,E_rev) 与接触力/压强上限。探针族：
- `tap`：小幅冲激力矩，测加速度响应→有效惯量/质量；
- `chirp/dither`：扫频小幅力矩，测频响→刚度 k 与阻尼 c；
- `compliant_press`：准静态柔顺下压，测力-位移斜率→接触刚度、屈服前界；
- `ramp_sweep`：慢斜坡切向力，测突破力/滑移前摩擦；
- `slow_lift`：慢速抬升 1–2cm，测关节重力负载→质量/内容。
`reversibility_guard` 监控应力、应变、滑移与塑性指标，越阈立即卸载回退。

**定义 239（语义容许力矩集 SATS）** 
S_T = T_default ∩ ⋂_{q:w(q)≥1} C_q(â_q) ∩ ⋂_{q:w(q)=2} (C_q(â_q)∩T_max)。
T_default 为对最坏可能物体仍安全的保守包络；T_max 为执行器物理硬限。S_T 作为附加约束并入第 65 轮 WCV-V 的力/阻抗域 ℱ，也作为 CSC-L 认证前缀的可行域。

**定义 240（单向阀）** 随凭证变化：
- w(q)∈{0,1}：S_T←S_T∩C_q(â_q)，**只能收紧**；
- w(q)=2：S_T←S_T∪(C_q(â_q)∩T_max)，**才可放开**，且永不超过 T_max；
- 无断言：S_T=T_default。
由此语义错误最多使 S_T 收缩（能力下降），不可能使其超出 T_default；只有经过物理判定的答案才能把能力买回来。这条不对称性是本轮安全论证的核心。

**定义 241（力矩-语义矛盾与归因 TCR）** 若探针残差与 VQA 断言按 δ 显著矛盾，则存在三假设：H_vqa（VQA 语义错）、H_tor（力矩模型/摩擦/负载/关节柔性误差）、H_phys（真实物理超预期，如物体确实易碎/装有液体）。单探针下三者签名可近共线（例如「更软」与「力矩模型高估」同向），不可辨识；需第二个**不同构型/接触点/频段**的探针形成块三角签名，才可做后验归因。未归因时置 w←`contested`、S_T 收至最保守、触发再探针或人类确认；归因为 H_vqa 时下调该**问题族**的 VQA 校准，归因为 H_tor 时上调力矩模型不确定度，归因为 H_phys 时更新物体先验。

**定义 242（凭证门控台账 WGL）** 每条记录
ℓ=(q, a, w, provenance, t_obs, E_spent, probe_id, tau_model_ver, expiry)。
不可逆动作 a†∈A† 可执行 ⇔ ∃q：a† 依赖 q 的答案 ∧ w(q)=2 ∧ t_now≤expiry ∧ probe 的 tau_model_ver 与当前一致。台账可审计「这条力矩由哪条语义断言批准、花了多少机械能、被哪次探针在什么标定版本下判定」。台账只追加、不可篡改摘要链。

**定义 243（交互能量预算与停止规则 SIE）** 机械探针总能量 B_mech 有限。选断言子集 Q_sel 最大化 Σ_{q∈Q_sel} L(q)，s.t. ΣE*(q)≤B_mech，且每个探针 E_in≤E_rev。由于 L 近似子模（断言间信息重叠，边际收益递减），贪心按 L(q)/E*(q) 排序可得 (1−1/e) 近似；停止规则：当 max_q L(q)/E*(q) < μ（μ 为机械能的影子价格）时停止。**问题不是免费的：问错要费机械功、时间与物体寿命。**

**定义 244（可判定性前沿）** 对线性响应与白噪声，注入能量 E 下信号幅值 ∝√E（例如力探针幅值 f∝√(E·Z)、位移 x∝√(E/Z)），故两假设分离度 |Δτ|/σ_τ∝√(E/E₀)。达到裕度 δ 需
E*(q,δ)≈E₀·(δ/SNR₀)²。
因此可逆预算 E_rev 越小（易碎、装液、软体、高价值），可判定性前沿越低：**最重要的语义往往最难被安全问出**。这不是工程缺陷，而是被动能量有界交互的信息论代价。

**定义 245（不可逆动作门控）** 不可逆动作集 A†={塑性变形、倾覆、溢出、掉落、切割、不可恢复的抓取}。a† 仅当持 w=2 凭证或人类显式授权时可执行；否则替换为**可逆等价动作**：先轻推（判滑动/倾覆趋势）、先抬 1cm（判内容/重量）、先测刚度（判易碎）、先视觉近观。可逆等价动作本身也受 S_T 与 E_rev 约束。

**定义 246（对抗语义与不可观测断言）** 干扰集 ℰ_L=ℰ_V×ℰ_text×ℰ_claim：
- ℰ_text：场景内误导文字、海报、屏幕提示注入、语言先验诱导；
- ℰ_claim：高置信错误答案、批量冗余断言、故意诱导系统执行不可逆探针、把 `unknown` 伪装成确定答案；
- ℰ_V：沿用第 65 轮视觉对抗（透明、镜面、patch、遮挡）。
认证要求：**∀e∈ℰ_L，S_T(e)⊆T_default 且物理安全不变**；不可判定断言显式标记 `unadjudicable_flags`，不得静默通过；AIC-L 的 n_cert 在第 65 轮 128 基础上增 32 给语义/文本对抗。

**定义 247（LEVER 证书 J_lever）** J_lever=(J_vista, warrant_vector, adjudication_energy, default_envelope_hash, vqa_calib_ver, unadjudicable_flags, probe_reversibility_ok)。
Valid(J_lever) ⇔ Valid(J_vista)
∧ 所有进入 S_T 的放开项 w=2
∧ 不可逆动作持未过期 `adjudicated` 凭证
∧ 探针能量/可逆性合规（E_in≤E_rev，reversibility_guard 未触发）

```python
class ClaimCompiler:
    """把 VQA 输出编译为带力矩后果映射与不可逆标记的断言。"""
    def compile(self, raw, task):
        c = Claim(
            phi=raw.proposition,                 # 带真值条件的命题
            A=raw.answer_space | {'unknown'},    # 必须允许弃权
            pi=raw.posterior,
            C=lambda a: torque_consequence(raw.proposition, a, task),
            kappa=irreversibility(raw.proposition, task))
        c.leverage = expected_volume_reduction(c, task)
        return c

    def filter_mechanical(self, claims):
        # L(q)=0 的断言机械无关：不进安全链、不花探针
        return [c for c in claims if c.leverage > 0.0]


class QuestionSelector:
    def rank(self, claims, delta):
        for q in claims:
            q.E_star = torque_adjudicator.min_energy(q, delta)   # 见 IP-226
        # 单位机械能的杠杆收益排序；unadjudicable 排最后且不探测
        return sorted(claims, key=lambda q: (
            q.warrant_class == 'unadjudicable',
            -(q.leverage / max(q.E_star, 1e-9))))
```

### IP-226 TAC（力矩可判定性）

```python
class TorqueAdjudicator:
    """可判定性 = 被动、能量有界、可逆的探针能否在裕度 δ 下分离答案。"""
    def min_energy(self, q, delta):
        # 线性响应 + 白噪声：分离度 ∝ sqrt(E)，E*(q,δ) ≈ E0*(δ/SNR0)^2
        e0, snr0 = self.calib[q.family]
        return e0 * (delta / max(snr0, 1e-12)) ** 2

    def verdict(self, q, E_rev, B_mech, delta):
        E = self.min_energy(q, delta)
        if E > E_rev or E > B_mech:
            return 'unadjudicable'      # 永不升级为 adjudicated
        return 'adjudicable', E
```

```python
    """端口哈密顿实现：R ⪰ 0 ⇒ 无源；E_in = ∫ y^T u dt 在线计量。"""
    PROBES = ('tap', 'chirp', 'press', 'sweep', 'lift')

    def execute(self, probe, E_budget, strain_lim):
        E_in = 0.0
        for u, y, dt in self.stream(probe):        # u=力矩指令, y=速度
            E_in += float(y @ u) * dt
            if E_in > min(E_budget, E_REV):
                return self.abort('energy')        # 硬能量界
            if self.guard.strain() > strain_lim or self.guard.slip():
                return self.abort('reversibility') # 可逆性看门狗
            self.apply(u)
        return self.residual()                     # r_tau 轨迹，交 TCR 判定

    def select(self, q, claims):
        # 在可判定断言中选 单位能量互信息/杠杆 最高的探针
        return max((p for p in self.PROBES if admissible(p, q)),
                   key=lambda p: q.leverage * mutual_info(p, q) /
                                 max(self.energy(p), 1e-9))
```

```python
class SemanticTorqueSet:
    def __init__(self, T_default, T_max):
        self.T_default, self.T_max = T_default, T_max

    def compose(self, claims):
        S = self.T_default
```

### IP-231 SIE（探针能量调度）

```python
class EnergyScheduler:
    def allocate(self, claims, B_mech, shadow_price):
        claims = sorted(claims, key=lambda q: q.leverage / max(q.E_star, 1e-9),
                        reverse=True)
        chosen, spent = [], 0.0
        for q in claims:
            if q.E_star > E_REV:                     # 不可逆探针一律拒绝
                continue
            gain_per_joule = q.leverage / max(q.E_star, 1e-9)
            if gain_per_joule < shadow_price:        # 停止规则
                break
            if spent + q.E_star > B_mech:            # 子模贪心，容量约束
                continue
            chosen.append(q); spent += q.E_star
        return chosen, spent
```

## 4. 推导

**引理 9（单向阀语义安全）** 设默认包络 T_default 对最坏可行物体安全，执行器硬限 T_max⊆T_default 的物理边界。按定义 240 更新 S_T：
- 无断言：S_T=T_default；
- 仅 w≤1 断言：S_T=T_default∩⋂C_q⊆T_default；
- 含 w=2 断言：S_T⊆T_default∪(⋃_{w=2}C_q∩T_max)。
对任意 VQA 答案（包括对抗最坏），w≤1 的断言只能取交集，因此 S_T 单调不增；w=2 的断言的放开项按构造被 T_max 与「已验证答案的真实物理上限」限制。若判定可靠（A95），w=2 断言的 C_q 与真实物体一致，故放开后仍在其真实安全域内。于是任意执行的力矩 a 满足 a∈S_T⊆(T_default 或 已验证的真实安全域)，即语义错误无法把 a 推出默认安全域，只能使 S_T 收缩。∎

**引理 10（可判定性能量前沿）** 考虑单参数 θ（刚度/质量/摩擦之一）的线性化残差 r=g(θ)+ε，ε∼N(0,σ²)。被动探针注入能量 E 时，力/位移激励幅值满足 A∝√(E/Z)（能量 E∼A²Z/2），故信号 ∂r/∂θ·δθ 的幅值 ∝√E。两假设 θ,θ′ 的分离度
d(θ,θ′)=|g(θ)−g(θ′)|/σ∝√E·|θ−θ′|/σ₀。
令 d≥δ 解得 E*(θ,δ)=E₀(δ/SNR₀)²，其中 SNR₀ 为单位能量下的信噪比。又探针须满足 E≤E_rev（可逆）与 E≤B_mech（预算）。故当 E*(q,δ)>min(E_rev,B_mech) 时不存在合规的判定探针，q 不可判定。∎

**引理 11（矛盾归因可辨识性）** 线性化 E[r|H]=Sφ，φ 为故障幅度（VQA 偏差、力矩模型偏差、真实物理偏差）。单探针下（单一构型/单一频段）签名矩阵 S 的三列可近共线：例如「物体更软（H_phys）」与「力矩模型高估刚度（H_tor）」都使同一频段残差同向偏移；「VQA 把刚性当软（H_vqa）」在未接触时无残差、仅在接触后显现，但若只取加载段单点，也退化。此时 rank(S)<3，Fisher 信息 J=SᵀΣ⁻¹S 奇异，三假设不可辨识。取两个不同构型/接触点或两个不同频段（tap 与 chirp），使签名块三角：
- H_vqa 仅在「与断言相关的物理量」通道非零；
- H_tor 在「与构型无关、与速度/负载相关」的通道非零；
- H_phys 在「跨构型一致、与模型无关」的通道非零。
当块三角满秩时 J≻0，可辨识。因此单次矛盾只能判 `contested`，双探针才可归因。∎

**定理 9（LEVER 安全不依赖 VQA 正确）** 在如下条件下：
(A95-1) 执行器硬包络（|τ|≤τ_max、|τ̇|≤τ̇_max、接触力/能量≤限）由下位控制器强制执行，且本层只能收紧；
(A95-2) 单向阀：w≤1 断言只收紧、仅 w=2 可放开，且放开不超 T_max；
(A95-3) 不可逆动作 A† 需未过期 `adjudicated` 凭证（或人类授权）；
(A95-4) 探针无源、E_in≤E_rev、reversibility_guard 在线；
(A95-5) 不可判定断言显式标记，不当作已验证。
则对任意执行轨迹与任意 VQA 输出（含对抗最坏），物理状态不越出安全集 S，**无论 VQA 正确与否**。
证明要点：(1) 由引理 9，所有力矩落在 T_default 或已验证真实安全域，二者均在 S 内；(2) 若 VQA 全错，w≤1 断言只能收紧 S_T，最坏是能力下降（保守停滞），不产生越界；(3) 若系统试图放开，必须持 w=2，而 w=2 由 A95-4 的被动探针在 E≤E_rev 内产生，物理上不可能对物体造成不可逆伤害；(4) A95-3 阻止未验证语义触发不可逆动作；(5) A95-5 使「问不出来」显式降级而非静默猜测。因此第 65 轮「归因错→更自信」的因果链在语义层被切断：语义错误无法获得授权的资格。∎

**定理 10（探针能量最优分配）** 将每个断言 q 视为集合元素，收益 L(q)，成本 E*(q)。L 近似子模（断言间信息重叠，边际收益递减：一旦已知质量，再问内容对力矩集的额外收缩变小）。在预算 ΣE*(q)≤B_mech 下的子模最大化，贪心按 L(q)/E*(q) 排序得 (1−1/e) 近似。停止规则由 Lagrangian 给出：存在影子价格 μ 使最优点满足 L(q)/E*(q)≥μ 才入选；当最大单位能量收益低于 μ 时停止。由于每个探针另有硬约束 E*(q)≤E_rev，不可判定断言直接排除，不参与优化。∎

**命题 1（保守性代价有界）** 若 VQA 错误地断言「物体易碎」而物体实际刚性，则 w≤1 使 S_T 收缩到低力包络，任务可能失败；其能力损失上界为 Vol(T_adm^true)/Vol(T_default)，与 VQA 错误幅度无关（因为默认包络本就按最坏物体设定）。反之，若 VQA 正确断言「物体刚性」但未判定，仍无法放开，故**未验证的正确**与**错误**在安全上等价——只有判定能换取能力。这既是保守性的来源，也是其代价的可界性。∎

**命题 2（假阳性放大）** 设力矩判定的假阳性率为 p_fp（把不可分/矛盾误判为已判定）。一旦发生，错误的断言被赋 w=2 并获得放开资格，绕过单向阀；该断言对安全的威胁与其杠杆 L(q) 成正比。故 LEVER 的端到端安全概率下界约为 (1−p_fp)^{N_adjudicated} 乘以定理 9 的其余条件，而 p_fp 依赖力矩模型/摩擦/负载标定精度。**这是全轮最脆弱的乘子**（见风险 A95）。∎

## 7. 已知风险

**一句话**：LEVER 把「物理裁判」当作语义真值的最后防线，但**裁判本身是可错的**——若力矩模型/摩擦/负载/柔性误差让一个弱的、模型相关的残差被误当成「已判定」（假阳性），系统就会把一个错误的 VQA 断言洗成 `adjudicated` 凭证，从而**比未验证的幻觉更危险**：它获得了放开的资格，还带着「已被物理验证」的审计自信；而最关键的语义（易碎、内容、意图）恰恰因可逆能量预算 E_rev 太小而天然不可判定，系统要么长期保守到能力崩溃，要么被迫依赖不可靠的弱判定——这是本轮全部单向阀与安全定理共同依赖的隐藏假设（A95：裁判的假阳性率可忽略且可标定）。

**次级风险与缓解**：
1. **裁判假阳性（H_tor 被误判为 H_vqa/H_phys）**：力矩模型/摩擦/负载误差制造同向残差；缓解：双构型/双频段签名（引理 11）、力矩模型不确定度计入判定裕度、假阳性率 p_fp 作为证书字段显式上界，超阈只判 contested。
2. **E_rev 过小导致能力崩溃**：易碎/装液/软体对象的可判定语义极少，系统长期停在 T_default；缓解：引入可逆等价动作阶梯（轻推→抬 1cm→视觉近观→人类确认），并把「不可判定」作为一等输出，接受部分任务交给人类。
3. **可逆性阈值本身是估计的**：应力/应变/滑移阈值来自材料模型，模型错则「可逆」探针可能不可逆；缓解：用保守阈值 + 探针过程中实时看门狗 + 硬能量界三重冗余，阈值不确定时降低 E_rev。
4. **SATS 过度保守**：未验证正确断言无法放开，完成任务慢；缓解：用杠杆排序把有限探针集中在最关键断言；对高重复任务缓存已判定凭证（带过期与标定版本）。
5. **VQA 断言空间爆炸/冗余**：模型可生成大量断言刷探针预算；缓解：QST 只保留 L>0 且非冗余断言，SIE 用子模覆盖去重，设每任务断言上限。
6. **文本注入与语义欺骗**：场景内文字让 VQA 自信答错；缓解：AIC-L 显式建对抗集，安全只依赖单向阀与默认包络，不依赖 VQA 抗欺骗能力；把「高置信 + 无独立印证」强制降为 unsupported。
7. **探针本身扰动任务/磨损**：tap/chirp/sweep 消耗时间与关节寿命；缓解：能量/次数预算、在任务间隙批量探针、把探针磨损计入第 65 轮 OLP 的代价。
8. **凭证过期与标定漂移**：adjudicated 凭证在标定漂移后失效；缓解：凭证绑定 tau_model_ver 与 expiry，标定更新即失效，需重判；过期凭证不得支撑不可逆动作。

## 8. 与前序轮次的关系（承接性说明）

- **第 64 轮 GRIP**：把几何先验变成可证伪假设，并用接触四层闭环处理「先验对不对」。LEVER 不改变其几何/接触语义。
- **第 65 轮 VISTA**：把「可证伪」升级为「可归因」，回答「哪一层坏了」。LEVER 承认 VISTA 的归因仍有未知复合故障风险，于是在其**上一层（语义）与下一层（执行器力矩）**之间加「凭证闸门」：VQA 语义只能提议，物理验证才能授权。VISTA 的 FIR 被 LEVER 的 TCR 补上 `H_vqa`/`H_unobs`，VISTA 的 AFA 探针被 PEP/SIE 重新定义为「被动、能量有界、按杠杆排序」的语义判别探针。
- **本轮 LEVER**：把安全链条的最上游从「答案正确」改为「答案有凭证」。安全的最终依赖从「VQA/归因正确」转为「默认保守包络（T_default）+ 单向阀（未验证只收紧）+ 被动能量界（E≤E_rev）+ 不可逆门控（A† 需 adjudicated）」四个**不依赖语义正确性**的条件；代价是能力受可判定性前沿 E*(q,δ)≈E₀(δ/SNR₀)² 与 E_rev 的硬限制，必须学会「承认不知道」。
