# 第 47 轮（承接第 46 轮 v23；本轮灵感：技能学习 × 产学研合作） · Skill-Passport：可携带证书的技能学习与跨机构联邦验证（四层架构 v11）

> 承接第 46 轮 v23 MVR × VAD × SAB。v23 把记忆、语音、安全绑定接入全局决策 Π，但隐含假设 H5：所有技能、证书、记忆都在同一机构、同一硬件、同一安全标准下产生并消费。UniBot 若要真正「越用越会」，技能必须能从演示中学习并跨产线/跨实验室复用；而真实落地必然是产学研多方共建——高校出算法与演示数据、企业出硬件与场景、检测机构出标准与审计。两个灵感词精确命中 H5：**技能学习**要求把技能从「点策略」升级为「带前置条件、姿态/能量/安全合同与后置条件的可组合技能对象」；**产学研合作**要求这些技能及其证书能跨信任域携带、复验、聚合与追责。二者耦合出新问题：**技能合同在跨机构迁移时会因域偏移静默失配，联邦聚合又可能把局部有效证书「洗白」成全局保证，一旦注册中心给出虚假保证，安全谓词会在异地部署中失效且无法定责**。

## 0. 直觉与动机

**灵感 1（技能学习 → 合同的技能，而非点的策略）**
直觉：人类学技能不是记住一条轨迹，而是知道「什么条件下能做、做到什么程度算成功、失败怎么退」。因此每个技能 s 应是一个带护照的对象：前置条件 Pre_s（可观测性层、姿态盒、能量租约）、过程合同 C_s（P_t、ℓ_p、ℓ_e、B≥θ_safe）、后置条件 Post_s（任务谓词），以及来源链 provenance。学习目标不只是成功率，而是在合同包络内最大化覆盖率——即「在证书允许的范围内把技能练稳」，并只在统计上确证安全时才扩张包络。

**灵感 2（产学研合作 → 证书的跨域携带与复验）**
直觉：高校的技能在企业的机器人上不一定成立：相机内参、臂长、摩擦、电池内阻、甚至「安全」的阈值定义都不同。产学研合作若只交换模型权重，等于把未经复验的安全承诺一起打包。正确做法是交换「技能护照 + 可复验的锚点证据 + 本地复验协议」：护照声明技能在声明域内的合同，注册中心只做登记与版本管理，部署方必须用本地锚点集做域偏移校正后才签发本地证书。

**灵感 3（耦合 → 联邦聚合的证书守恒与风险账本）**
直觉：多方联合训练能提升技能泛化，但「平均」会把某一方的危险探索掩盖掉。需要证书守恒：聚合后的技能必须同时满足各方合同的可交集部分，且聚合扰动必须落在安全裕度内；若不能，则拒绝聚合或缩小合同。谁提供数据、谁写技能、谁部署、谁操作，出事故时按贡献与合同违约分配责任——风险账本 RAL 把不可争辩的 provenance 变成可审计的责任链，这本身也是产学研能长期合作的前提。

**耦合升级**：在 v10 四层上新增 **技能-证书交换层（SCE, Skill-Certificate Exchange）**。SCL 产出带合同的技能对象；SPR 签发/吊销技能护照；FCX 做带证书守恒的联邦聚合；RAL 记账与归因。ECPS 在执行前查询护照与本地复验状态；DCL 采集任务加入「合同边界样本」；CCA 新增护照伪造/洗白红队；CAR 守卫从单锁变为「护照有效 ∧ 本地复验通过 ∧ 合同满足」三把锁。

## 1. 形式化定义（增量：定义 59–63）

**定义 59（技能护照与技能合同）**
技能对象 s=(π_s, Pre_s, Post_s, C_s, prov_s, Dom_s, ver_s, sig_s)，其中合同
C_s={r_s（姿态证书半径）, ℓ_e（能量租约）, θ_safe^s（绑定阈值）, α_s（允许违反率）}，
声明域 Dom_s=(h 硬件域, o 传感域, d 分布域, n 标准域)。
**护照有效** ⇔ 签名可验 ∧ 未被吊销 ∧ 本地复验通过。三者缺一即视为无效。

**定义 60（合同感知技能学习与课程风险预算）**
策略族 Π_Θ，每 episode 设风险预算 ρ_e。学习目标
max_θ E[ 1{task success}·1{contract satisfied} ]  s.t. empirical violation ≤ α_s + ρ_e。
**包络扩张规则**：仅当 (a) 连续 n 次合同满足，(b) 独立审计集上的违反率上界 ≤ α_s，(c) 姿态/能量裕度 ≥ κ，才把 r_s 扩大 Δr。违反合同即终止 episode，并计入风险预算。

**定义 61（跨机构迁移与本地复验）**
域映射 T: Dom_s → Dom_local，迁移缺口
δ_T(s)=sup_x |risk_local(x)-risk_source(x)|。
本地复验在锚点集 A_local 上做共形校准，校正半径
r_s' = r_s·(1+γδ_T) + q_{1-α'}(A_local)。
**可迁移判据**：δ_T ≤ δ_max 且 A_local 覆盖合同的边界层（透明/高光/弱纹理/能量临界等）。

**定义 62（带证书守恒的联邦聚合）**
k 方本地更新 Δθ_i、信任权重 w_i（Σw_i=1）、本地合同 C_i。聚合 θ̄=Σw_iθ_i，扰动界
ε_agg=Σ_i w_i·L_i·||Δθ_i-Δθ̄||。
**证书守恒条件**：
r̄ = max_i r_i^{local} + L_π·ε_agg + L·δ_T^max ≤ r_max，
且 ᾱ=Σ_i w_iα_i ≤ α_max。
守恒失败 → 拒绝签发「certified」护照；退化为合同交集或「仅建议模式」(advisory-only)。

**定义 63（风险账本与契约优先归因）**
一次执行事件 e 的 provenance 链 P_e=(数据提供方, 技能作者, 集成方, 部署方, 操作员, 护照验证方)。违约事件 v 的责任份额
φ_j = Shapley_j(v; 各参与方对「合同满足/违约」的边际贡献)，Σ_jφ_j=1。
RAL 以哈希链记录不可篡改事件；归因遵循**契约优先原则**：先判合同违约方，再谈模型误差，避免把系统性契约缺陷稀释成「算法偶然失误」。

## 2. 三大新增产出与既有 IP 升级

**IP-69 SCL（Skill-Contract Learner）**
- 演示→技能对象：从示教数据抽取 Pre/Post 与合同初值
- 合同约束学习：违反合同即终止并计入课程风险预算
- 包络扩张：三段式统计确证（n 连满足、审计集上界、裕度 κ）
- 失败样本回灌 DCL 与记忆库 M

**IP-70 SPR（Skill Passport Registry）**
- 护照结构：技能哈希、合同、域声明、签名、版本、吊销列表
- 注册/查询/吊销/差分更新：**只登记不担保**，担保由部署方本地复验产生
- 防洗白：护照继承父技能合同，子技能不得放宽 r_s、θ_safe、α_s

**IP-71 FCX（Federated Certificate Exchange）**
- 安全聚合（DP/加密）只交换梯度与合同摘要，不交换原始数据
- 证书守恒求解：合同交集 + 扰动界 + 域偏移上界
- 顾问模式：守恒失败时仅下发建议，不签发执行许可

**IP-72 RAL（Risk Attribution Ledger）**
- 事件哈希链 + provenance 图
- Shapley 近似归因 + 契约优先规则
- 对第三方检测机构提供只读审计接口

**既有 IP 升级**
IP-66 MVR：记忆键加入 skill_id 与护照版本，过期/吊销护照命中即屏蔽
IP-67 VAD：语音指令先解析为「技能意图」，再查护照可用性
IP-68 SAB：绑定检查加入护照域匹配与本地复验结果
IP-63 ECPS：可行模态必须落在护照域允许集内
IP-61 DCL：新增合同边界样本采集任务（主动找包络边缘）
IP-62 CCA：护照伪造、降级重签、跨域洗白红队
IP-51 CAR：守卫 = 护照有效 ∧ 本地复验通过 ∧ 合同满足，任一失败 fail-closed
IP-45 总线：skill-passport / local-revalidation / federation-aggregate / risk-ledger 话题

## 3. 算法骨架

SCE 每周期：
1. SCL 从演示产出候选技能与合同初值，写 SPR 草稿
2. SPR 验签并检查合同单调性（不得放宽父合同），登记版本
3. 部署方拉取护照 → 在 A_local 上复验 → 估计 δ_T → 签发本地证书或拒绝
4. FCX 定期聚合多方更新 → 解证书守恒 → 通过则发新版护照，否则顾问模式
5. 执行时 CAR 三锁校验；RAL 记录事件与 provenance
6. 违约 → 吊销/降级 → 回灌 DCL 与 M
PSE 仍签发姿态证书，但其半径必须使用本地复验后的 r_s'。

## 4. 本轮最大风险

**一句话**：护照可能沦为「跨机构安全洗白」的工具——某机构在窄域上取得的证书经联邦聚合与签名后被误当成广域保证，域偏移使异地部署静默违约，而风险账本又因数据与合同不透明难以定责；因此必须以「只登记不担保 + 强制本地复验 + 合同单调不放宽 + 契约优先归因」为硬约束，守恒失败一律拒绝签发执行许可。

### IP-69 SCL 合同感知学习
```python
def learn_skill(demos, C0, audit_set, alpha_s, rho_e,
                n_confirm=30, kappa=0.2, dR=0.02):
    s = extract_skill_object(demos)          # pi_s, Pre, Post, prov
    C = C0                                    # (r, lease_e, theta_safe, alpha)
    theta = init_policy(s)
    streak = 0
    for episode in curriculum():
        traj = rollout(theta, C, risk_budget=rho_e)
        ok, viol = task_and_contract(traj, C)
        theta = update(theta, traj, ok, viol)
        streak = streak + 1 if ok and not viol else 0
        if streak >= n_confirm:
            r_new = C.r + dR
            ub = audit_upper_bound(audit_set, theta, r_new)   # 独立审计集
            if ub <= alpha_s and margin(traj) >= kappa:
                C = contract(C, r=r_new)                       # 包络扩张
                streak = 0
    return SkillObject(theta, s.Pre, s.Post, C, prov=prov_of(demos))
```

### IP-71 FCX 证书守恒聚合
```python
def federated_aggregate(updates, contracts, weights,
                        delta_max, r_max, alpha_max):
    theta_bar = sum(w * u.theta for w, u in zip(weights, updates))
    eps_agg = sum(w * u.L * norm(u.theta - theta_bar)
                  for w, u in zip(weights, updates))
    r_bar = max(c.r for c in contracts) + eps_agg + delta_max
    alpha_bar = sum(w * c.alpha for w, c in zip(weights, contracts))
    if r_bar <= r_max and alpha_bar <= alpha_max:
        return PassportDraft(theta_bar, r=r_bar, alpha=alpha_bar,
                             mode="certified")
    theta_int = intersect_policies(updates)        # 合同交集
    return PassportDraft(theta_int, r=r_max, alpha=alpha_max,
                         mode="advisory")          # 只建议，不签执行许可
```

## 3. 推导：迁移界与守恒裕度

**命题 1（迁移 soundness）** 设源域证书满足 sup_x risk_source(x) ≤ α_s，策略风险对域映射 T 的 Lipschitz 常数为 L。则本地风险
risk_local(x) ≤ α_s + L·δ_T。
若再在锚点集 A_local 上以水平 1-α' 做共形校准，则由 exchangeability 与并集界，本地违约概率 ≤ α_s + α' + L·δ_T。故校正半径需同时吸收 γδ_T 与共形分位 q_{1-α'}，即定义 61 的 r_s' 形式。这也说明：**δ_T 必须被上界估计，而不能被点估计**。

**命题 2（联邦守恒）** 设策略对参数的 Lipschitz 常数为 L_π，聚合 θ̄=Σw_iθ_i，则
risk(θ̄) ≤ Σ_i w_i risk(θ_i) + L_π·ε_agg。
在各方本地合同 risk(θ_i) ≤ α_i 下得到 ᾱ + L_π ε_agg；再叠加域偏移得
r̄ ≤ max_i r_i^{local} + L_π ε_agg + L δ_T^max。
因此定义 62 的守恒条件是充分条件；一旦 r̄>r_max，唯一严谨的选择是拒绝 certified 模式，而非「把裕度调大一点」。

**命题 3（三锁 fail-closed）** 若 G(s,P_t)=1 才执行，且 PassportOK 要求签名与未吊销、LocalCertOK 要求 δ_T≤δ_max 且锚点覆盖边界、ContractSat 要求 E(t)≥E_min 与 B≥θ_safe，则任何不满足联合 soundness 的执行都被前置拒绝，残存风险仅来自命题 1 的 α_s+α'+Lδ_T 与能量估计误差。故系统级安全违例率近似可加，可被独立审计。

| E117 联邦证书守恒 | certified 比例、洗白率 | certified ≥ 50%；洗白事件 = 0 |
| E118 吊销传播 | CRL 传播时延、旧护照拦截率 | 传播 ≤ 1s；拦截率 = 100% |
| E119 责任归因 | 注入故障下归因准确率 | 契约违约归因 ≥ 95% |
| E120 多机构 30 天试点 | 执行覆盖率、安全违例、争议闭环 | ≥3 域；安全违例 0；争议 100% 留痕 |

回退策略：E116 δ_T 估计不可靠 → 收紧 δ_max 并强制锚点重采；E117 certified < 30% → 全链转 advisory-only，仅人工确认后执行；E118 传播超时 → 暂停跨机构护照，回退本地技能库；E119 归因争议 > 5% → 引入第三方检测机构仲裁并冻结相关技能。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 跨域洗白（窄域证书当广域用） | 高 | 只登记不担保；强制本地复验；δ_T 上界与锚点覆盖硬校验 |
| 派生技能偷偷放宽合同 | 高 | 定义 64 单调性；派生需重认证；SPR 拒绝放宽型登记 |
| 联邦平均掩盖危险探索 | 高 | 证书守恒 + 顾问模式；危险方更新降权或剔除 |
| 吊销传播滞后导致旧护照执行 | 中 | CRL 强同步；三锁含实时吊销查询；离线模式 fail-closed |
| 归因被数据/合同不透明稀释 | 中 | 契约优先；哈希链留痕；第三方只读审计 |
| 锚点集泄漏商业数据 | 中 | 只交换锚点统计量/共形分位，不交换原始样本 |

## 6. 本轮最大风险

**一句话**：技能护照的最大威胁不是学不会技能，而是「跨机构安全洗白」——窄域证书经联邦聚合与签名被误当广域保证，域偏移令异地静默违约，责任又因合同与数据不透明而无法归属；因此必须把「只登记不担保、强制本地复验、合同单调不放宽、守恒失败即拒签、契约优先归因」写成不可绕过的系统硬约束，而不是流程建议。
