# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「腕部相机」×「多语言支持」）

> R69 问出了整个系列里最像人的一个问题：「我该向谁求证、还能问什么」。但它默认了两件从未被检验的事：**(a) 求证只有一个视角**（头/眼，稳定、宽阔、近似上帝视角），**(b) 求证只用一种语言**（且这种语言的「左/右、前/后、远/近」与机器人的动作坐标系天然对齐）。于是「看—问—做」被当成一个无摩擦、全局一致的信息管道：算得出 VoI，就能看、能问、能更新后验。
>
> 本轮两个灵感正好戳在这两处：
> - **腕部相机**把「看」从固定上帝视角，变成**与手共位、随动作移动、会被自己遮挡、且与抓取争用同一末端**的主动视角。它看见的正是「即将接触的地方」，因此是唯一能以「接触者的视角」验证**动作相关概念**的传感器；但它的视角由动作决定，视角本身也成了动作。
> - **多语言支持**把「说」从一种默认语言，变成一组**参考系与分类边界各不相同的约定**：有的语言偏好相对参考系说「左」，有的用内在参考系（物体自身的左），有的用绝对参考系（东南西北）；颜色词、量词、证示、敬语各切各的边界。**翻译不是保信息双射，回译不是逆变换。**
>
> 合起来暴露一个更深的问题：**「模态」不是纯物理对象，而是 (视角, 语言) 的联合函数**。流策略能聚出一个「模态」，但这个模态**换一个视角还成立吗？人类那种语言里真的存在这个词吗？双方说的「左」是同一个左吗？** 这些从未被检验。若不检验就提问，R69 的「追问幻影」会升级成「**跨视角、跨语言地被证实的幻影**」——错误盖上了双重验证的章。
>
> 核心命题：**指称先于提问，而指称必须同时通过「视角不变性」与「跨语言可译性」两道检验**；视角动作是受认证的信息动作，翻译必须计入谱系相关的**有效证据数**；不可译 / 不可见 / 参考系未绑定时，诚实弃权并退回 R69，再退回 R68。命名 **LENS-RAS**（Language-Embodied Naming across viewS）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我在哪个视角、用哪种语言求证？我们指的是同一个世界吗？**」

## 0. 直觉与动机

**灵感 1（腕部相机 → 一个动作耦合、部分可见、与手争用末端的视角）**
直觉：头戴相机的画面稳定、宽阔，但看不清手心里发生的事；腕部相机正好相反——它离接触点最近，却**随手的动作一起动、被手自己挡住、被运动拖出模糊**。三个直接后果：
1. **自遮挡与退化**：想看清夹爪与物体的接触面时，夹爪本体恰好在镜头前；想看清物体背面时，手必须先松开或翻转。腕部相机的「看不见」不是随机噪声，而是与「正在做什么」强相关。
2. **视差即信息，也是混淆**：同一个物体在两个视角下的位置不同；视差能验证深度/几何，但若两个视角共享同一标定/同一镜头污渍/同一种光照，它们的错误也一起错。
3. **看—做争用**：末端同一时刻只能「看」或「做」。为了看清而移动腕部，可能破坏抓取、错过时间窗。**「看」不是一个免费的信息通道，它要花掉「做」的资源。**

关键洞见：腕部相机的真正价值不是「多一路图像」，而是**它能对动作相关概念做视角不变性检验**——「这个东西是可抓的/是软的/正在滑动」这类概念，若在接触者视角与外部视角下都稳定成立，才值得据以行动。

**灵感 2（多语言 → 参考系与分类边界是约定，不是物理常数）**
直觉：中文说「把杯子放在它的左边」，英语说 "on its left"，有的语言更习惯说「放在山的这一侧/那一侧」（绝对参考系）。认知语言学的**参考系三分**（相对 relative / 内在 intrinsic / 绝对 absolute，Levinson）说明：「左」这个字本身不决定方向，**(词, 参考系, 原点)** 才决定方向。同一句话，若双方一个用自我中心、一个用物体内在，「都确认过了」也可能走向相反方向。
再往下：翻译不是双射。颜色词在不同语言里切不同段；量词把物体分成不同类；证示（evidentiality）标记「我亲眼所见 / 我听说的」——这恰是**来源可靠性**的语言级编码，却在机器翻译里最容易被抹平。用一个 MT 系统把 A 语言译成 B 语言再译回，**系统性偏移不会消失**，只会被误当成「独立验证」。

**灵感 3（双重接地 → 视角不变 × 跨语言可译）**
直觉：如何判断一个「模态」是真的而不是策略幻觉？给它做两个正交的变换测试：**换视角**它还在吗？**换语言**它还能被稳定命名/回指吗？两个都过，才叫接地。这比 R69 的单视角、单语言命名强得多，而且这两个测试用的是系统本来就要花的资源（看与问），不是额外标注。
反之，只过一个不等于接地：只在腕部视角成立的概念可能是镜头伪影；只在一种语言成立的概念可能是译员/问句模板的偏见。

**灵感 4（独立性要 DAG 化：k 个翻译器 ≠ k 个独立源）**
直觉：R69 的证据纪律是「k 个正交源多数一致」。但如果所有源都**看了同一个问句、经过同一个译员、来自同一族 MT 模型**，它们就共享同一个系统性偏差 δ。独立证据按 √k 收敛，共享偏差按 k 累积——**源越多，错得越自信**。这不是实现 bug，而是「正交」定义漏掉了**谱系**。
所以把证据建成一张 DAG：节点是观测，边是「共享视角/共享相机/共享标定」或「共享译员/共享 MT/共享问句模板」。独立性 = 无共享祖先；计数用**有效证据数** k_eff = k / (1 + (k−1)ρ)。这是统计学里设计效应/有效样本量的直接迁移。**「问了三种语言」若都经过同一个人翻译，有效证据数仍可能是 1。**

**灵感 5（弃权也是一种支持；多语言也是安全攻击面）**
直觉：低资源语言、词法空缺（这种语言根本没有这个词）、参考系无法绑定——此时最诚实的输出是「**我不确定我们说的是不是同一件事，我先保守**」，而不是硬造一个映射。「不支持」必须是一等公民输出，而不是 silently 翻译错。
更尖锐：多语言是安全过滤的攻击面。一个诱导性指令用英语会被拦，用低资源语言可能直接绕过；社交工程可以借「你们的语言里这个词是什么意思」来诱导参考系切换。**语言支持若不同时带来语言感知的安全门，就是给系统开了一扇没锁的后门。**

**灵感 6（对新层的要求：严格包含，逐步退避）**
直觉：新增的视角门/语言门若关闭，必须逐指令退回 R69；R69 的标定门若也关闭，退回 R68。**任何一层新验证失败都只能让系统更保守，不能更激进。** 否则每加一层就多一个需要独立信任的黑箱，而本轮恰恰在质疑「独立」本身。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（LENS-RAS 总览与不变量）** LENS-RAS = (FMP, AUD, MINT, CIA, FMA, WCV, VIG, MLR, FOR, TDT, DIG, OAC, RAS-WM†)。不变量：
(i) 继承 R69 定义 293 的三不变式（实时流零学习写操作、交互预算硬约束、证据纪律）；
(ii) **视角动作即信息动作**：g_view ∈ 𝒜_info，必须过 C-RAS-WM 认证，与任务动作共享末端与时间预算，不得在关键接触段改变抓取状态；
(iii) **双不变门**：只有同时通过视角不变（VIG）与跨语言可译（MLR/FOR）的模态才可进入 VoI；
(iv) **谱系证据纪律**：证据独立性由 DAG 的共享祖先决定，计数用 k_eff，不用原始 k；
(v) **诚实弃权**：不可译/不可见/参考系不可绑定 ⇒ 输出 abstain，禁止强制映射；弃权一律走 R69 保守路径。

**定义 311（腕部相机观测模型）** 腕部相机位姿 v_w ∈ SE(3)（由末端位姿与手眼标定决定，是**随动**的）。观测 o_w = C_w(x; v_w) + η_w，其中 C_w 含自遮挡、运动模糊与视差。可见性 ν(x, v_w) ∈ [0,1]；模糊度 b(v_w, ẋ)。退化判据：ν < ν_min ∨ b > b_max。注意：腕部观测的参考系是 **egocentric-to-gripper**，不是 world；把它直接当 world 坐标用，是 R69 之前所有融合的隐式错误。

**定义 312（视角族与主动视角动作）** 可达且安全的观察位姿集 𝒱_safe(o) = { v : C-RAS-WM.certify_view(v, o) }。视角动作 g_view ∈ 𝒱_safe（注视/绕看/抬腕/翻转/松手后回看），其信息增益 VoI_view(v) = H(M|o) − E_{o_w~p(·|v)}[H(M|o, o_w)]。与 R69 的 g_gaze 的本质区别：g_gaze 只改注视方向，不改变末端；**g_view 改变末端位姿，因此与抓取动作争用同一物理资源**（定义 318）。

**定义 313（视角不变指称）** 描述子 d_φ(o_v)（例如物体相对夹爪的位姿、接触状态、材质、可抓性）。跨视角一致度 κ_view = Cohen-κ( d_φ(o_{v1}), d_φ(o_{v2}) ) − chance，其中 v1、v2 必须来自**不同传感器或不同几何基**，且共偏置风险 ρ_b ≤ ρ_max。视角不变证书 Valid_view(m) ⇔ κ_view ≥ τ_view ∧ 至少两个非退化视角 ∧ ρ_b 可被界住。

**定义 314（多语言指称与参考系类型）** 语言 ℓ ∈ ℒ；词项 t_ℓ(m)；参考系 f ∈ {rel(相对), intr(内在), abs(绝对)}，原点 ω ∈ {ego, viewer, world}。空间谓词 w 的语义是三元组 (t_ℓ, f, ω)。同一「左」在 rel/ego、intr/object、abs/north 下可指向不同方向。参考系绑定 bind(w, ℓ) 给出**人侧语言先验**与**机器人动作坐标系**之间的显式映射。

**定义 315（跨语言可译性）** 回译 BT_{ℓ→ℓ′}；跨语言原型一致度 κ_lang = consistency( embed(t_ℓ), embed(t_{ℓ′}) )；可译性距离 Δ_trans = 1 − κ_lang + λ·d_BT( t_ℓ, BT(t_ℓ) )。**词法空缺** gap(m, ℓ) ⇔ 该语言无稳定词项（受限词表映射失败，或回译漂移超阈值）。Valid_lang(m, ℓ) ⇔ Δ_trans ≤ τ_trans ∧ ¬gap ∧ 词表覆盖足够。

**定义 316（视角-翻译谱系图与有效证据数）** 证据项 e = (obs, v, ℓ, τ_lineage)。建 DAG：共享同一视角/同一相机/同一标定 → `same_view` 边；共享同一译员/同一 MT 模型/同一问句模板 → `same_translation` 边（R69 的共享问句也归此）。设正交组数为 k，组间共享祖先相关为 ρ，则**有效证据数** k_eff = k / (1 + (k−1)ρ)。仅当 k_eff ≥ 2 才满足 R69 的证据纪律。ρ 由组内残差相关（或共享祖先比例）在线估计并给置信区间。

**定义 317（双不变门 DIG）** 模态 m 可进入 MINT 的充要条件：Valid_view(m) ∧ Valid_lang(m, ℓ) ∧ frame_bound(m)。任一不过 ⇒ U_epi 保持未消解，其质量并入 R68 兜底；**禁止为未接地模态生成任何问句**。

**定义 318（看-做争用与 peek 调度）** 末端同一时刻只能「看」或「做」。定义安全预抓取位姿集 𝒫_pre；peek 动作在 𝒫_pre 内执行，不改变抓取力/接触状态，有超时 T_peek。调度约束：t_peek + t_recover ≤ 任务时间窗；失败/超时 ⇒ 丢弃视角证据，不阻塞控制。

**定义 319（视角退化与遮挡欺骗检测）** 退化检测：ν、b、视差覆盖、跨视角一致性同时下降。**遮挡欺骗**：手或物体在需要判别力的关键时刻遮挡腕部相机。检测指标 Δocc = 期望可判别区域被遮挡比例随时间的突增；超阈值 ⇒ 该视角证据作废，并要求另一视角或弃权。

**定义 320（多语言安全门 MLS）** 安全过滤必须**跨语言一致**：低资源语言不得绕过。语言感知安全门 MLS：对任意 ℓ，拦截率 ≥ 1 − ε；若某语言未校准 ⇒ 拒绝该语言交互（abstain），**禁止把英语过滤器硬套到未校准语言上**（硬套会同时产生误拒与漏拒）。

**定义 321（证书 J_LENS）** J_LENS = (J_FLUID, κ_view, view_ids, ρ_b, ℒ_used, Δ_trans, gap_flags, frame_binding_hash, k_eff, peek_log_hash, lens_ver)。Valid ⇔ Valid(J_FLUID) ∧ 双门过 ∧ (若无多源要求或 k_eff ≥ 2) ∧ 弃权规则满足 ∧ (若涉及语音则 no_raw_audio)。

**定义 322（分级语言/视角上线 P0–P3）** P0 离线双语参考游戏 + 离线视角不变性验证；P1 仿真影子；P2 小预算真人在环（新语言/新视角）；P3 全量。每级晋升需证书；κ 下降或漂移触发降级。**新语言默认 P0，未过 P1 不得在真机提问**；新视角（如新腕部相机型号）同样分级。

**定义 323（两级退避与 resolution bonus）** 若双门过且交互消解：λ = λ_floor(U_ale)（获得 resolution bonus）。若未消解 / 不可译 / 视角退化 / k_eff < 2 / 超时 / ECE 越界 ⇒ λ = λ_floor(U_ale + U_epi)，回 R69；若 R69 也不可用 ⇒ R68 纯保守。**⇒ 安全侧永不弱于 R69。**

**定义 324（LQAuditor 审计）** 审计：视角证据是否真的独立（查 DAG）、翻译是否共享父、参考系是否绑定、是否发生强制映射、低资源语言是否越权、peek 是否越过安全包络。结论回灌 AuditBuf，成为下一轮成本先验与语言/视角黑白名单。

## 2. 关键算法骨架

```python
# IP-264 WCV：腕部相机主动视角（与抓取争用，须认证）
class WristView:
    def candidate_views(self, o, target):
        return [v for v in pre_grasp_poses(target)
                if c_ras_wm.certify_view(v, o)]          # 仅安全 pre-grasp 位姿
    def observe(self, v):
        o_w, nu, blur = capture(v), visibility_map(v), blur_score(v)
        return o_w, (nu < NU_MIN or blur > B_MAX)        # 退化判据（定义 311）

# IP-265 VIG：视角不变指称（不同传感器/几何，且共偏置受界）
def view_invariance(desc_fn, views, target):
    obs = [v.observe(target) for v in views if not v.degenerate]
    if len(obs) < 2 or shared_bias_risk(views) > RHO_B_MAX:
        return UNVERIFIED                                 # 单视角/共偏置 ⇒ 不接地
    return cohen_kappa([desc_fn(o) for o in obs]) - chance_level(len(obs))

# IP-266/267 MLR+FOR：双语参考游戏 + 参考系绑定（冻结 LLM/NMT，异步）
def translatability_and_frame(concept, lang):
    t   = limited_vocab_map(concept, lang)                # 受限词表，禁止自由发挥
    bt  = back_translate(t, lang)                         # 回译
    gap = (t is None) or drift(t, bt) > TAU_BT
    f   = infer_frame(t, lang)                            # rel / intr / abs + 原点
    return dict(gap=gap, delta_trans=1 - cross_lingual_consistency(t), frame=f)

# IP-268/269 TDT+VLE：谱系 DAG → 有效证据数
def effective_sources(evidence_items):
    G   = build_dag(evidence_items)                       # same_view / same_translation 边
    k   = number_of_orthogonal_groups(G)
    rho = shared_ancestor_correlation(G)                  # 组内残差相关
    return k / (1 + (k - 1) * rho)                        # 引理 20；同源翻译 k_eff→1

# IP-277 主闭环（继承 R69，只在「可否提问」处插入 LENS 层）
def LENS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(...), z, ...)
    # 1) 双不变门：先验证「这个模态是否存在、是否可问」
    eligible = []
    for m in modes:
        views = M.wcv.candidate_views(o, m.target)
        kv    = M.vig.view_invariance(m.desc, views, m.target)
        tr    = M.mlr.translatability_and_frame(m, M.lang)
        if kv >= TAU_VIEW and not tr['gap'] and tr['delta_trans'] <= TAU_TRANS:
            eligible.append((m, tr['frame']))
    if not eligible:
        return R69_fallback(M, U_ale, U_epi, modes)       # 不接地 ⇒ R69 保守（定义 323）
    # 2) 参考系绑定后才允许生成问句；问句异步、peek 受认证
    m, frame = max(eligible, key=lambda x: x[0].weight)
    g = M.mint.choose_interaction([m], o, M.budget, frame=frame)
    if g is not None and M.oac.feasible(g, M.vista.H):
        M.oac.schedule_peek(g)                            # 安全 pre-grasp 位姿，超时丢弃
        ans = M.mlr.ask_in_language_async(m, M.lang, frame)
        k_eff = M.tdt.effective_sources(M.cia.evidence_of(ans))
        U_epi = M.cia.update_belief([m], ans, k_eff=k_eff) if k_eff >= 2 else U_epi
    # 3) 风险缩放：未消解/不可译/退化 ⇒ 回 R69；否则 resolution bonus
    U_floor = U_ale + (0.0 if _resolved(U_epi) else U_epi)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    mode = select_mode(modes, U_epi, lam)
    M.lqa.submit_async(views, M.lang, frame, k_eff, g)    # 审计：独立性与参考系
    return k, lam, mode, (U_ale, U_epi)

## 3. 推导

**引理 19（共享视角偏差使跨视角一致性失效）** 设两个视角对同一潜在命题 x 的观测为 y_i = x ⊕ e_i，e_i = b ⊕ n_i，其中 b 为两视角共享的系统性偏置，n_i 独立。若 P(b=1) = p_b，则当噪声 n_i → 0 时，P(y1 = y2 | x) → 1，**即使二者都错**。因此跨视角一致度 κ_view 度量的是「一致」，不是「正确」；在共享偏置存在时，P(correct | agree) ≤ 1 − p_b。**系：** 视角不变证书必须额外界住 ρ_b（定义 313），并用一条**不同物理基**的通道（本体感受/力觉或主动视差）去打破共享偏置；只有腕部+头部两路图像、却没有共享偏置估计时，κ_view 不能单独作为接地证据。

**引理 20（翻译谱系衰减与有效证据数）** 设多个「独立源」都由同一源语言经同一译员/同一 MT 系统 T 派生，则各源误差含公共分量 δ_T。于是给定 x 后源间互信息为正，正交组数 k 的有效值为 k_eff = k / (1 + (k−1)ρ)，其中 ρ 为共享祖先相关。若 ρ ≥ ρ0 > 0，则 k_eff ≤ 1/ρ0，**与 k 无关**。进一步，回译 BT∘T 在分布意义上不是恒等：对确定性/贪心 T，公共分量 δ_T 在回译后仍保留一阶项，故「译过去再译回来一致」**不等于**「原义被保留」。**系：** R69 引理 18 的 k 源上界须把 k 替换为 k_eff；「问三种语言」若共享一个译员，上界不改善，甚至因 δ_T 被多次确认而更糟。

**引理 21（参考系错配的误差下界）** 空间谓词 w 在参考系 f 下的动作方向为 a_f。若机器人用 f_R、人用 f_H，且 f_R ≠ f_H 导致方向相反的概率为 q，则即使词义理解完全正确，动作方向错误率 ≥ P(f_R ≠ f_H)·q − ε_disc。**系：** 「左/右」不能在未绑定 (f, ω) 时被当作证据；参考系澄清问句（「你说的左边，是你的左边还是杯子的左边？」）通常是**成本最低、VoI 最高**的信息动作，应优先于任何物体识别类提问。

**定理 18（LENS 严格包含 R69）** 在 A95–A97 及 A99（视角共偏置可界）、A100（翻译谱系可估）下，LENS 的期望风险 ≤ R69；且当双门关闭、单视角、单语言、k_eff < 2 或参考系不可绑定时，两者**逐指令相同**（定义 317、323）。因此 R69 是 LENS 在「单一可信视角 + 单一可信语言」边界上的退化：安全侧不做让步，效率侧仅在双门通过时获得 resolution bonus。

**定理 19（peek 的交互安全与无突变）** peek 动作经 C-RAS-WM 认证且在安全预抓取位姿集 𝒫_pre 内执行（定义 318），不改变抓取力/接触状态；若与任务动作争用，则被调度到关键接触段之外；超时/失败即丢弃证据。故 peek 的物理风险 ≤ ε_int，交互只改变「选哪个模态」、不改变安全包络；失败/不可译/退化时 λ 单调不降地退化为 R69 ⇒ 控制连续、无突变。

**定理 20（诚实弃权不劣于强制映射）** 当 gap(m, ℓ) 为真（该语言无稳定词项）时，任何强制映射 t_ℓ(m) 都携带一个正的系统性误差下界 ε_gap > 0（由引理 20 的 δ_T 与词法空缺共同决定），而弃权使 U_epi 未消解并走 R69 保守（其风险上界为 λ_floor 保证值）。因此当 ε_gap 超过保守动作与错误动作的风险差时，**弃权的期望风险 ≤ 强制映射**；这为「不支持」提供了安全论证，而不是产品妥协。

## 6. 本轮最大风险

**一句话**：LENS 的全部安全性押在「视角与翻译是**独立**的验证通道」上——**但第二视角可能共享同一标定/镜头/光照偏差，翻译可能共享同一译员/MT 父节点，于是「跨视角 × 跨语言都一致」可能只是一个被共同祖先制造出来的共识；验证者自身的独立性无法从系统内部被验证，错误会被盖上双重验证的章——比未经验证的错误更难发现。**

**次级风险与缓解**：
1. **跨视角共偏置**（两路相机同错）→ 引理 19 界 ρ_b + 引入不同物理基（力觉/本体感受/主动视差）打破共偏置 + E306；
2. **翻译链污染 / 回译假独立** → 谱系 DAG + k_eff + 引理 20 + E305，绝不把同源翻译计为独立源；
3. **参考系诈骗**（用「左」诱导反向动作）→ 强制绑定 (f, ω) + 优先参考系澄清 + E302；
4. **词法空缺被硬填** → 词法空缺检测 + 定理 20 弃权 + E304，禁止强制映射；
5. **多语言的安全后门**（低资源语言绕过过滤）→ 语言感知 MLS + 未校准语言拒答 + E309；
6. **peek 破坏抓取/超时** → 安全预抓取位姿 + 认证 + 超时丢弃 + 定理 19 + E308。

    if len(obs) < 2 or shared_bias_risk(views) > RHO_B_MAX: return UNVERIFIED
    return cohen_kappa([desc_fn(o) for o in obs]) - chance_level(len(obs))

# IP-266/267 MLR+FOR：受限词表双语 + 参考系绑定（冻结 LLM/NMT，异步）

    gap = (t is None) or drift(t, bt) > TAU_BT
    return dict(gap=gap, delta_trans=1-cross_lingual_consistency(t),
                frame=infer_frame(t, lang))                 # rel/intr/abs + 原点

# IP-268 TDT：谱系 DAG → 有效证据数（同源翻译 k_eff→1）

    k = number_of_orthogonal_groups(G); rho = shared_ancestor_correlation(G)
    return k / (1 + (k-1)*rho)

def LENS_round(M, obs):

```

## 4. 推导

**引理 19（共享视角偏差使一致性失效）** 两视角 `y_i=x⊕e_i`，`e_i=b⊕n_i`，b 为共享偏置。n_i→0 时 `P(y1=y2|x)→1`，即使都错；故 `P(correct|agree) ≤ 1−p_b`。系：κ_view 必须额外界住 ρ_b，并用不同物理基（力觉/本体感受/主动视差）打破共偏置。

**引理 20（翻译谱系衰减）** 同源经同一译员/MT 派生的多源共享误差 δ_T，`k_eff=k/(1+(k−1)ρ) ≤ 1/ρ0`，与 k 无关；回译 `BT∘T` 在分布意义上非恒等，`δ_T` 一阶保留。系：R69 引理 18 的 k 源上界须替换为 k_eff；共享译员的「多语言」不增加独立性。

**引理 21（参考系错配下界）** 机器人用 f_R、人用 f_H，方向相反概率 q，则动作方向错误率 `≥ P(f_R≠f_H)·q − ε_disc`。系：参考系澄清问句通常是最便宜、VoI 最高的信息动作。

**定理 18（LENS 严格包含 R69）** A95–A97、A99（共偏置可界）、A100（谱系可估）下，LENS 期望风险 ≤ R69；双门关/单视角/单语言/k_eff<2/参考系不可绑定时逐指令相同。R69 = 「单一可信视角 + 单一可信语言」边界；安全不让步。

**定理 19（peek 安全与无突变）** peek 在 𝒫_pre 内、过 C-RAS-WM、不改抓取状态、超时丢弃 ⇒ 物理风险 ≤ ε_int；交互只改模态选择；失败时 λ 单调不降退 R69 ⇒ 控制连续。

**定理 20（诚实弃权不劣于强制映射）** gap 为真时强制映射带正误差下界 ε_gap；弃权使 U_epi 未消解走 R69 保守。当 ε_gap 超过保守与错误动作风险差时，`risk(abstain) ≤ risk(force)`——「不支持」有安全论证，而非产品妥协。

## 7. 本轮最大风险

**一句话**：LENS 的安全性押在「视角与翻译是**独立**验证通道」上——**但第二视角可能共享同一标定/镜头/光照偏差，翻译可能共享同一译员/MT 父节点，于是「跨视角 × 跨语言都一致」可能只是共同祖先制造的共识；验证者自身的独立性无法从系统内部被验证，错误会被盖上双重验证的章——比未经验证的错误更难发现。**

**次级风险与缓解**：跨视角共偏置（引理 19 界 ρ_b + 力觉/本体感受/主动视差打破 + E306）；翻译链污染/回译假独立（谱系 DAG + k_eff + 引理 20 + E305）；参考系诈骗（绑 (f,ω) + 优先澄清 + E302）；词法空缺硬填（gap 检测 + 定理 20 弃权 + E304）；多语言安全后门（MLS + 未校准拒答 + E309）；peek 破坏抓取/超时（安全 pre-grasp + 认证 + 超时丢弃 + 定理 19 + E308）。
