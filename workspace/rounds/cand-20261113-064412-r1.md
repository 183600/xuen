# 第 3 轮迭代（灵感循环 v3：「容错控制」×「传感器融合」）

## —— 把"撤回检测-重做"重写为**采样型主动容错**，把"视觉验证器"重写为**解析冗余融合**

> 承接第 2 轮 v2（UIP-01′~15）。本轮**换范式，不是加功能**：第 2 轮把 `regressed` 当成一个"视觉分类"问题，本轮用**容错控制**把它重写成标准的"故障检测→隔离→重构→恢复（FDD + Reconfiguration）"，用**传感器融合**回答"残差从哪里来、凭什么信"。由此得到一个可证明的硬约束：在这套"整块执行、块间重观测"的接口下，`T_a` 就是故障观测的**采样周期**，短于 `T_a·Δt` 的不可逆干扰**在原理上救不回来**。这把第 2 轮"实时性=工程优化"升格为"实时性=容错可观测性的硬边界"。

**一句话直觉**：真正的对手不是"环境会变"，而是"你**看不见自己错在哪一类**上"——回退要重做、位移要重定位、滑脱要重抓、相机坏了要换通道、底座被挪了要换参考系；用错恢复动作，越努力越丢分。

## 1. 上一轮清单诊断（升级 / 改写 / 修剪）

- **升级为容错框架**：UIP-01′（滚动验证）与 UIP-09′（撤回检测）→ 合并升格为 **UIP-16 FT-SUP**：`regressed` 只是故障类 **F1**，第 2 轮却把它当成唯一分支；而重读 §2 表可见**多数 `human_*` 其实是"把东西挪走"（F2 位移）**，恢复动作应是"重定位后重做"，不是"原地重做"。隔离错了，重做就是空转。
- **升级为传感器融合**：UIP-01′ 的"验证器"→ 拆成 **UIP-17 PRO-Res**（本体解析冗余：指令 vs 实测、物体是否跟随 EE、基座位移）+ **UIP-18 XFUSE**（跨视角/立体/时序视觉残差 + 遮挡鲁棒重定位）。第 2 轮的"几何+语言规则"是它的退化特例。
- **升级实时性**：UIP-13 ACS → **UIP-20 k-FTB**：块长不再只按"阶段经验"选，而是受**命题 1 的可检测界**约束（`T_a·Δt < T_irrev`），并给出"不可逆任务只能靠预防"的判定。
- **升级安全阀**：UIP-15 CSG → **UIP-22 FBC**：从"延迟预算"升级为**按步骤分值定价的故障预算**（重做哪个子目标最划算、误报代价多大）。
- **扩展数据工厂**：UIP-12 DRF → **UIP-19 M-DROP**：故障注入从"反向撤回"扩到 **F1–F5 全类**，尤其补**传感器故障**（丢帧/陈旧/遮挡/压缩）与**基座扰动**，做被动容错的训练分布。
- **修剪/降级**：UIP-11 GSO 明确降为"**残差阈值与 FDD 的离线标定台**"，不再自称成败裁判；UIP-14 MSGR 的每个技能节点附一个**恢复控制器**（技能=正常控制律+故障恢复律），不新增模型数量。
- **新增**：UIP-16~22（见产物区 §0）。

## 2. 两个灵感词的直觉解释

1. **容错控制（FTC）**：比赛现场**不可能加冗余硬件**（不能多装一个相机、也不能换手），所以容错只能来自两样东西：**(a) 解析冗余**——同一个量用不同途径再算一遍，不一致处就是故障信号；**(b) 主动重构**——先诊断"是哪类故障"，再切换到对应的恢复控制律。更关键的是，这套接口是**采样数据系统**：动作整块开环执行，故障若发生在两次观测之间，你最早下一块才知道。于是**块长 `T_a` 不是效率参数，而是"最短可救故障时长"**。容错分两层：**被动**（训练时把故障当数据增广、运行期优雅降级）+ **主动**（实时 FDD + 重构）。
2. **传感器融合（SF）**：这里 4 相机 + 本体感知是**互补 > 冗余**，而且各自的盲区恰好互补——`ee_pose` 定义在 **base 系**，**底座被人挪动时它几乎不变**（纯本体感知的盲区！），只有视觉/`lower_body` 看得见；反过来视觉看不清"夹爪正在打滑"，而 `gripper` 指令 vs 实测开度、以及"物体是否刚性跟随 EE"看得见。融合的第一价值不是"更准"，而是**残差组合模式 = 故障指纹**；第二价值是**通道冗余**——一路相机被挡/坏掉，用其余路继续，这就是感知层的"故障掩蔽"。

## 3. 严谨定义（把直觉变成可检验的数学对象）

### 3.1 采样数据接口的时间线

设每步执行耗时 `Δt`，块长 `T_a`，则观测周期 `T_c = T_a·Δt`。观测时刻 `t_i = i·T_c`。策略在 `t_i` 返回块 `A_i=(a_{i,0},…,a_{i,T_a-1})`，评测端在 `[t_i, t_{i+1})` 内**整块开环执行**。⇒ **块内无反馈、不可打断**；所有纠错只能发生在块边界。

### 3.2 故障分类（把"人为干扰"拆成可诊断的类）

子目标 `g=1..G`，分值 `w_g`（Σw=100）。几何进度泛函 `φ_g(o)∈[0,1]`，部分分 `Φ_t = Σ_{h<g_t} w_h + w_{g_t}·φ_{g_t}(o_t)`。

- **F1 回退型**：已完成的子目标被撤销（合上→打开、拉上→拉开、叠好→翻开、放好→放回起点）。特征：`Φ` 沿任务轨迹**反向**下降。
- **F2 位移型**：目标物/支撑物/插口/道具的位姿被移动（杯后移、锁拿走、插口移开）。特征：目标位姿**跳变**，但任务"语义进度"未必反向。
- **F3 抓持/执行器型**：滑脱、空抓、被卡住、被拔出。特征：指令与实测不一致、物体不跟随 EE。
- **F4 感知型**：丢帧/陈旧帧/遮挡/模糊/压缩失真/某路视角失效。特征：图像健康度异常，**不是环境变了**。
- **F5 基座型**：人挪动底座（`pivot`/`lower_body` 变化而臂相对不动）。特征：base 系 `ee_pose` 看似正常，但**世界系**全错。

> 关键修正：第 2 轮把所有 `human_*` 都当 F1；按 §2 表重读，**F2 占多数、F1 约 8 个、F5 至少 2 个、F3 若干**。不同类必须用不同恢复律（§3.6），这是本轮最重要的"修剪"。

### 3.3 残差库（传感器融合的具体量）

**本体解析冗余（PRO-Res）**
- 跟踪残差 `r^trk = || q̄_{t} − q_t ||_Σ`（上块最后指令 vs 当前实测臂关节）
- 夹爪残差 `r^grip = c̄_{t} − c_t`（指令闭合量 vs 实测开度）
- 物体跟随残差 `r^obj = || T^obj_t − T^EE_t·(T^EE_0)^{-1}·T^obj_0 ||`（抓稳时应刚性跟随；漂移=滑脱）
- 基座残差 `r^base = || s^body_t − s^body_{t-1} ||` 或静态背景的视觉自运动

**视觉融合（XFUSE）**
- 时序重投影残差 `r^vis_t = || π(T_{t-1→t}·P^obj(t−1)) − P^obj(t) ||`（F1/F2）
- 跨视角一致性 `r^x_t = || T_{L→R}·P^L_obj − P^R_obj ||`（立体/双高相机；F2/F4）
- 进度速度 `v^prog_t = (Φ_t − Φ_{t-1})/T_c`；回退用 CUSUM：`S_t = max(0, S_{t-1} − v^prog_t − κ)`（F1）
- 陈旧度 `r^stale`：**机器人被指令运动时**，画面像素差却≈0 ⇒ 该路相机陈旧/卡死（F4）
- 遮挡度 `r^occ`：目标可见性/特征数低于阈值（F4）

### 3.4 故障指纹矩阵与融合判据

残差的意义在**组合模式**，单看一个都会误判。记 `r_t` 为残差向量，`F0` 为无故障。用对数似然比（条件独立近似）：

`ℓ_k(t) = Σ_j w_{jk} · log[ p(r_{t,j} | F_k) / p(r_{t,j} | F_0) ]`，
`k* = argmax_k ℓ_k`，当 `ℓ_{k*} > γ` 时报警并隔离为 `F_{k*}`。

阈值 `γ` 由**误报代价**校准（见 UIP-22），而不是固定 0.6 置信度。指纹矩阵见产物区 §4。

### 3.5 两个命题（本轮的核心"推导"）

**命题 1（采样-可救界）**：故障在 `τ∈(t_i,t_{i+1})` 发生。最早的纠正输入是 `t_{i+1}` 返回、在 `[t_{i+1},t_{i+2})` 执行的块。故
- 最坏**检测延迟 ≤ T_c**，最坏**有效恢复延迟 ≤ 2T_c**；
- 若该故障在 `T_irrev < T_c` 内造成**不可逆**的分值损失（如锁被拿走、书被碰落），则**任何**反应式容错都来不及，必须靠预防（提速/护持/避免暴露）。

*证明梗概*：块内无反馈且不可打断，故 `[τ, t_{i+1})` 内系统不可能收到任何纠正输入；若损失在此时窗内已不可逆，则后验再准也无法恢复。∎

**推论 1**：反应式容错可行的必要条件是 `T_a ≤ T_irrev(g)/Δt`。F1（回退）与"物体仍在"的 F2 的 `T_irrev=∞`（可重做/重定位），故**块长可放宽**；只有"永久移除/跌落损坏"类（个别任务）必须靠预防。

**命题 2（完成后暴露窗）**：人为干扰可发生在**你完成全部子目标之后**（"拉上后再拉开""叠好后翻开"）。⇒ episode 分数**非单调**，最优策略在 `g=G` 后不能停手，必须以 `T_a=1` 维持**末态守护环**：持续复核所有"可逆子目标"，被撤销就立刻重做，直到超时。

### 3.6 重构律（故障类 → 恢复控制）

`ρ: F_k → mode`：
- **F1 → redo_g**：用更强的条件（历史帧/几何）重跑子目标 `g`；块长调小。
- **F2 → relocalize→replan_g**：先用融合视觉重估目标位姿，再从新位姿规划（**不是原地重做**）。
- **F3 → release+regrasp**：张开→重新接近→闭合→小幅回拉验证"物体跟随"。
- **F4 → degrade_fusion**：丢弃故障通道、对其余通道重加权；必要时临时提高时序堆叠（用带宽换鲁棒）。
- **F5 → re-reference base**：用静态背景/`lower_body` 估基座位移，把目标变换到新 base 系后重做。

**故障预算（FBC）**：对子目标 `g`、故障类 `F_k`，估计恢复成功概率 `ν_g`、耗时 `c_g`、误报代价 `P_FA`，定义净值
`Q_g = ν_g·w_g − λ·c_g − μ·P_FA·w_{g+1}`，仅当 `Q_g>0` 才执行恢复；在时间/重做预算下按 `w_g·ν_g/c_g`（价值密度）贪心分配。

## 4. 瓶颈假设（v3 更新）

- **H1（最高杠杆）**：多数 `human_*` 是 **F2 位移**而非 F1 回退 ⇒ 第 2 轮统一的"regressed→redo"会**用错恢复律**；把 FDD 做对，恢复成功率与步骤分同时受益。
- **H2**：主动容错的上限由**采样周期**决定（命题 1）；对不可逆干扰，唯一解是**预防**而非检测。
- **H3**：`ee_pose/gripper` 的"指令 vs 实测"残差**零额外硬件、零外部模型**即可检出 F3/F5，是绕开"非单模型"合规风险的最佳验证通道。
- **H4**：融合的价值首在**故障指纹 + 通道冗余**，其次才是精度；单残差检测必然高误报。
- **H5**：末态守护（命题 2）能以极低成本吃到"完成之后被撤销"的一大类分数，且几乎不影响正常 episode。

## 5. 候选发散 → 合并 → v3 清单

围绕两词发散 8 个草案，合并后得到 **v3：UIP-16~22（新增）+ UIP-02′/05/08′/11/12/14（保留）**。旗舰是 **UIP-16 FT-SUP**，它把第 2 轮的 UIP-01′/09′/15 统一进一个"采样型主动容错监督器"，由 **UIP-17 PRO-Res + UIP-18 XFUSE** 提供残差，**UIP-20 k-FTB** 给可检测界，**UIP-22 FBC** 给预算，**UIP-19 M-DROP** 给被动层。详见产物区。

## 6. 本轮最大风险

**一句话**：这套容错监督器可能沦为一个"需要精确标定、却频繁误报"的高开销模块——在**无故障**的 episode 里它主动制造重做与延迟，而在**真正致命且不可逆**的干扰面前，它又受采样周期所限根本来不及救；若不能把误报代价压到接近零、并如实承认命题 1 的能力边界，它救回的分会少于它丢掉的分。

## 1. 旗舰深潜：UIP-16 · FT-SUP（Fault-Tolerant Supervisor, sampled-data active FTC）

### 1.1 结构

```
obs_t ──► PRO-Res (UIP-17) ─┐
       └► XFUSE  (UIP-18) ─┴► FDD(指纹+对数似然比) ─► 隔离 F_k
                                                   │
                          ┌────────────────────────┴───────────────┐
                          ▼                                        ▼
                 重构律 ρ(F_k) (UIP-21)                   故障预算 FBC (UIP-22)
                          │                                        │
                          └──────────► 技能头/块长 k (UIP-20) ◄────┘
                                                   │
                                              action chunk
```

### 1.2 与第 2 轮 UIP-01′/09′/15 的差异

| 维度 | 第 2 轮 | 本轮 |
|---|---|---|
| 异常种类 | `done/ongoing/fail/regressed` | **F0–F5 六类**，`regressed` 只是 F1 |
| 检测来源 | 视觉验证器（可能引入外部模型） | **接口内解析冗余**（指令 vs 实测）+ 跨视角融合 |
| 恢复 | 一律"重做同一子目标" | **按类重构**：重做/重定位/重抓/降级/换参考系 |
| 触发时机 | 仅在推进过程中 | **含完成后末态守护**（命题 2） |
| 预算 | 延迟/抖动/次数护栏 | **按步骤分值定价**的恢复预算（FBC） |
| 块长 | 经验/阶段 | 受**可检测界**约束（k-FTB） |

### 1.3 关键机制

1. **块边界 FDD**：只在 `get_action` 被调用时（每 `T_c`）计算残差与判据；块内不做任何假设。
2. **故障指纹隔离**：用残差组合而非单一阈值（§4）。典型判别：`r^base` 高、`r^trk` 低 ⇒ F5；`r^obj` 高、`r^grip` 高 ⇒ F3；`v^prog<0` 且 `r^vis` 高、本体全低 ⇒ F1；目标位姿跳变但无反向 ⇒ F2；`r^stale/r^occ` 高 ⇒ F4。
3. **一次性重构**：检测到即切换，执行一块后回到 nominal（F4 除外，需持续降级直到通道恢复）。
4. **末态守护**：当 `g=G`，置 `T_a=1`，对所有"可逆子目标"循环复核（低成本几何谓词），被撤销立即重做，直到 episode 结束/超时。
5. **误报抑制**：`γ` 由误报代价反解（FBC），并加**连续两次观测一致**才确认（利用 `obs_delta_indices` 可请求 state 多帧，无需多传图像）。

## 3. 残差与融合（UIP-17 / UIP-18）

### 3.1 PRO-Res（本体解析冗余）

设上块最后一步指令为 `(q̄, c̄, p̄)`，当前实测为 `(q, c, p)`（关节、夹爪开度、EE 位姿），`T^EE` 为 EE 齐次变换。

```
r_trk(t)  = || q̄ - q ||_{Σ_q}                      # 被卡/受阻/饱和
r_grip(t) = | c̄ - c |                               # 空抓/夹住/被掰开
r_obj(t)  = || T_obj(t) - T_EE(t) · T_EE(t0)^{-1} · T_obj(t0) ||   # 是否刚性跟随
r_base(t) = || s_body(t) - s_body(t-1) ||           # 或静态背景视觉自运动
r_sat(t)  = 1[ |q| 接近关节限位 且 |q̄-q| 大 ]       # 饱和掩蔽
```

- `r_obj` 需要视觉跟踪物体位姿，是**视觉-本体融合**量（单靠任一方都不够）。
- `r_base` 在 base 系内**看不见**基座平移，只能用 `lower_body` 或视觉；这就是 F5 的探测通道。

### 3.2 XFUSE（跨视角/时序视觉）

```
r_vis(t) = || π( T_{t-1→t} · P_obj(t-1) ) - P_obj(t) ||     # 时序重投影
r_x(t)   = || T_{L→R} · P_obj^L(t) - P_obj^R(t) ||          # 立体/双高相机一致性
v_prog(t)= ( Φ(t) - Φ(t-1) ) / T_c
S(t)     = max(0, S(t-1) - v_prog(t) - κ)                   # 回退 CUSUM
r_stale  = 1[ 有指令运动 且 帧间像素差 < ε ]                # 相机陈旧/卡死
r_occ    = 1[ 目标可见性(特征数/掩码面积) < θ_occ ]         # 遮挡
```

**融合的本质**：`r_vis` 大而 `r_trk/r_grip` 小 ⇒ 环境物件动了（F1/F2）；`r_obj` 与 `r_grip` 大而 `r_vis` 局部正常 ⇒ 抓持失效（F3）；`r_x` 或 `r_stale` 大 ⇒ 感知故障（F4）；`r_base` 大 ⇒ F5。

## 4. 故障指纹矩阵（FDD 的核心）

| 故障 \ 残差 | r_trk | r_grip | r_obj | r_base | r_vis | r_x | r_stale/r_occ | v_prog |
|---|---|---|---|---|---|---|---|---|
| **F0 无故障** | 0 | 0 | 0 | 0 | ~0 | ~0 | 0 | ≥0 |
| **F1 回退** | 0 | 0 | 0 | 0 | ↑ | ~0 | 0 | **<0** |
| **F2 位移** | 0 | 0 | 0 | 0 | **↑跳变** | 可能↑ | 0 | 0/负 |
| **F3 滑脱/空抓** | 可能↑ | **↑** | **↑** | 0 | 局部 | ~0 | 0 | ≥0 |
| **F4 感知故障** | 0 | 0 | ? | 0 | ? | **↑** | **↑** | 0 |
| **F5 基座扰动** | 0 | 0 | 0 | **↑** | 全局平移 | ~0 | 0 | 0 |

> 用法：先按列"显著非零"选出候选集合，再按上表交集投票；歧义时（如 F2 vs F4）用 `r_x` 与 `r_stale` 区分（感知故障会同时破坏多路/出现陈旧，物理位移不会）。

### 4.1 融合判据（对数似然比）

```
ell_k = Σ_j w_jk · log( p(r_j | F_k) / p(r_j | F_0) )
k*    = argmax_k ell_k
报警   当 ell_{k*} > gamma 且 连续 2 个观测同向
```

- `p(r_j|F_k)` 用仿真注入（UIP-19/GSO）拟合为高斯或 Gamma，再在真机锚点校准。
- `gamma` 不取固定值：由 FBC 的误报代价反解（§7.2）。

## 5. 命题与推导（可检测界 = 块长的硬约束）

### 命题 1（采样-可救界）

设观测周期 `T_c = T_a·Δt`，块内开环不可打断。故障于 `τ ∈ (t_i, t_{i+1})` 发生，则：
1. 最坏检测延迟 `≤ T_c`；
2. 最坏**有效恢复**延迟 `≤ 2T_c`（下一块才能施加纠正）；
3. 若不可逆损失在 `T_irrev < T_c` 内完成，则**任何**反应式容错无法阻止该损失。

*证明*：`[τ, t_{i+1})` 内不存在任何纠错输入（块内无反馈），故若损失在此时窗内不可逆，事后信息再充分也无法改变已损失的分。∎

**推论**：反应式容错可行的必要条件为 `T_a ≤ T_irrev(g)/Δt`。F1 与"物体仍在"的 F2 有 `T_irrev=∞`，块长可放宽；永久移除类（T12）必须转向**预防**。

### 命题 2（完成后暴露窗）

若干扰可发生在所有子目标完成之后，则 episode 分数关于时间**非单调**。任何"完成即停"的策略都有未被观测的暴露窗。故最优策略须在 `g=G` 后维持 `T_a=1` 的**末态守护环**，持续复核可逆子目标。

### 5.1 块长选择（UIP-20 k-FTB）

```
对每个阶段 g:
    T_irrev(g) = 该子目标"不可逆损失"的时间尺度（∞ 若可恢复）
    若 T_irrev(g) == ∞:  k_g = min(K_MAX, k_efficiency)      # 追求低延迟/高吞吐
    否则:               k_g = max(1, floor(T_irrev(g)/Δt))    # 保证可救
    # 末态守护阶段: k = 1
```

- `k_efficiency` 由延迟预算与吞吐决定（第 2 轮 ACS 的经验值仍适用）。
- `metadata.action_chunk_size` 只能声明一个**上界 `K_MAX`**；每次返回的块长可 ≤ 它（README §3 允许，索引 0 先执行）。故"阶段自适应"通过**返回实际长度**实现。

## 7. 重构与预算（UIP-21 DGR / UIP-22 FBC）

### 7.1 DGR 降级模式（通道/技能重分配 = 控制分配）

```
F4（单路相机坏/挡）: 权重 w_view -> 0；剩余视角重归一化；必要时提高 state 时序堆叠
F4（全部视觉失效）: 退化为"本体+历史动作"盲操作 + 极短块 + 保守速度（保分不冒险）
F3（反复滑脱）:   切换接触更保守的技能头（慢速/更深插入/先对齐再闭合）
F5（基座位移）:   以静态背景重估 base，把全部目标变换到新 base 系
F1/F2:           redo / relocalize→replan
```

> 关键：降级是"**保命不保分**"的兜底，必须有，但不能成为常态（否则平均成功率掉）。

### 7.2 FBC 故障预算（按分值定价）

对子目标 `g`、故障类 `F_k`：恢复成功率 `ν_g`、耗时 `c_g`、误报率 `P_FA`、后续子目标价值 `V_{g+1}`。

```
净值:  Q_g = ν_g·w_g - λ·c_g - μ·P_FA·(w_g + V_{g+1})
执行恢复 当且仅当 Q_g > 0
多子目标预算分配: 按 w_g·ν_g / c_g 价值密度贪心（0/1 背包近似）
误报门限: 由 Q_g>0 反解 gamma，使"误报的期望损失 < 真故障的期望收益"
```

**误报代价的显式化**是本轮对第 2 轮 CSG 的关键升级：第 2 轮只会"限次数"，本轮会算"这次重做到底值不值"。

```python
class FaultTolerantSupervisor:            # UIP-16 = 17 + 18 + 20 + 22
    def __init__(self, policy, task, dt, K_MAX=8,
                 redo_max=2, time_budget=..., lambda_c=..., mu_fa=...):
        self.policy, self.task, self.dt = policy, task, dt
        self.K_MAX, self.redo_max = K_MAX, redo_max
        self.T_irrev = task.irreversibility_times()   # {g: float or inf}
        self.phi = task.progress_functionals()
        self.fdd = FaultDiagnoser(task)               # §4 指纹+对数似然比
        self.fbc = FaultBudget(...)                   # §7.2
        self.reset()

    def reset(self):
        self.policy.reset()
        self.g = 0
        self.hist = []            # 状态/图像历史（按 obs_delta_indices）
        self.redo = {}
        self.S_cusum = 0.0
        self.guard = False
        self.prev_ell = None

    def get_action(self, obs):                     # 每 T_c 调一次
        self.hist.append(obs); self.hist = self.hist[-H:]
        # 1) 残差（UIP-17 + UIP-18）
        R = self.compute_residuals(obs, self.hist, self.policy.last_cmd)
        # 2) FDD：指纹 + 对数似然比 + 两帧一致性
        f, ell = self.fdd(R)
        if ell is not None:
            if self.prev_ell is not None and ell * self.prev_ell > 0:
                f = self.fdd.label(ell)
            self.prev_ell = ell
        # 3) 更新计分账本（只在几何谓词确认推进时前进）
        self.g = self.advance_ledger(obs, self.g)
        self.guard = (self.g >= self.task.G)
        # 4) 重构（UIP-21），并用 FBC 决定"值不值得"
        mode = "nominal"
        if f is not None:
            mode = self.reconfigure(f)            # redo/relocalize/regrasp/degrade/rebase
            if not self.fbc.should_recover(self.g, f, mode, self.redo):
                mode = "nominal"
        # 5) 块长（UIP-20）：末态守护 k=1；否则受可救界约束
        k = 1 if self.guard else self.pick_k(self.g)
        # 6) 生成动作
        A = self.act(obs, mode, k)
        self.policy.last_cmd = A[-1]
        return A

    def pick_k(self, g):
        tir = self.T_irrev.get(g, float("inf"))
        if tir == float("inf"):
            return min(self.K_MAX, self.task.k_efficiency[g])
        return max(1, min(self.K_MAX, int(tir / self.dt)))

    def reconfigure(self, f):
        return {"F1": "redo", "F2": "relocalize_replan", "F3": "release_regrasp",
                "F4": "degrade_fusion", "F5": "rebase"}[f]
```

```python
def compute_residuals(obs, hist, last_cmd):
    q, c   = obs.arm_joints(), obs.gripper_opening()
    T_ee   = obs.ee_pose()
    q_bar, c_bar = last_cmd.arm, last_cmd.gripper
    r_trk  = maha(q_bar - q, Sigma_q)
    r_grip = abs(c_bar - c)
    r_base = norm(obs.lower_body() - hist[-2].lower_body())
    P_now  = track_objects(obs.images())              # 视觉跟踪
    r_vis  = reprojection_error(hist[-2], P_now)
    r_x    = stereo_consistency(obs.left_high(), obs.right_high(), P_now)
    r_obj  = object_ee_rigidity(P_now, T_ee, hist[0])
    r_stale = stale_flag(obs.images(), last_cmd)      # 有指令运动却几乎无像素变化
    r_occ   = occlusion_flag(P_now)
    return Residuals(r_trk, r_grip, r_obj, r_base,
                     r_vis, r_x, r_stale, r_occ)
```

## 10. 合规、资源与风险

### 10.1 合规

- **单模型**：残差与 FDD 全部基于接口现有信号；分类器若是学习式，必须是**同一骨干上的小头**，不得外挂 VLM/第二个大模型。
- **接口红线**：`T_a` 上界在 `metadata` 声明一次；每块实际长度 ≤ 上界、时间轴保留、索引 0 先执行；`meta.token` 每步携带。
- **可信度**：FDD 的跟踪/融合计算必须**低且稳**；避免"检测到时才算"造成的延迟尖峰（可预算化/异步化，但不得违反同步返回）。

### 10.2 资源

- PRO-Res：纯 numpy 级运算，<1 ms；XFUSE：轻量跟踪/光流 + 立体匹配，可在 CPU/GPU 边缘完成。
- M-DROP：Gazebo 并行注入（复用第 2 轮 GSO 场景）。
- 无需额外传感器、无需外部 API。

### 10.3 风险

- **误报**是头号杀手：无故障 episode 被误判会触发多余重做，直接掉步骤分并抬高延迟。
- **阈值标定**依赖含故障的数据，而公开数据零故障 ⇒ 只能靠仿真注入 + 少量真机锚点，存在 sim-to-real 漂移。
- **采样界**是硬天花板：不可逆干扰（T12）救不了，不要在检测上过度投入。
- **无时间戳/无触觉**：时序融合与滑脱判据只能间接推断，需在真机上验证假设。

### 11.1 粗排

- **第 1 周**：把 32 任务 `human_*` 原始文本逐条分类（复核 §2 表），定 `T_irrev` 与恢复律。

- **第 9 周起**：真机锚点校准；E309/E310。

### 11.2 本轮最大风险 & 押注

**一句话**：FT-SUP 若不能把"无故障时的误报代价"压到接近零，它会用一个精巧的容错框架，把本来能成的 episode 判成故障并反复重做——**救回的分少于丢掉的分**；同时命题 1 已明确：不可逆干扰救不了，别自欺。

**→ 押注：UIP-16 FT-SUP × UIP-17 PRO-Res × UIP-20 k-FTB 组成的"采样型主动容错闭环"**——它用接口已有的 `ee_pose/gripper` 做**零成本解析冗余**（绕开单模型合规风险），用故障指纹把第 2 轮过粗的"regressed→redo"拆成"重做/重定位/重抓/降级/换参考系"，并用命题 1 诚实地划出"能救"与"只能预防"的边界。**唯一必须先赢的，是 E304 的误报红线。**
