### 第 6 轮灵感驱动研究记录

**灵感词**：通用操作、视觉定位

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）把提议从离散规则库升级为条件流匹配、记忆升级为嵌入检索 + 固化、人因升级为情感调制，并用定理 6（证书不变性）把框架推广为「任意生成器 + 认证边界」。但 v5 有一个被默认、从未被审视的前提：**门所消费的上下文 c（物体位姿、几何、可供性）是可信的**。七个硬门都在某个参考系里计算证书，而这个参考系由视觉感知给出。当任务变成「通用操作」（开放词汇物体、未见几何、跨本体）时，视觉定位本身成为最大的不确定性源——感知一错，证书就全部算在错误的对象上，形成「垃圾进、证书出」。本轮补这个结构性缺口，主题为「感知接地的一般化认证执行」（Perception-Grounded Certified Generalist Execution, PG-CGE），形成 CADVS-v6（IP-497~500）。自律不变：**不新增硬门**（继续正面回应 R52 锚点维护负债），感知与泛化通过「前端接地 + 鲁棒裕度收缩 + 技能组合」三条非侵入路径接入；执行集嵌套升级为 Exec_v6 ⊆ Exec_v5 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **视觉定位 → 从「点上下文」到「可信上下文集合」，用保形预测把感知不确定性变成证书裕度**。直觉：如果定位误差有界（位姿误差 ≤ ε），那么只要把每个门的裕度按「门的 Lipschitz 常数 × ε」收缩，通过鲁棒门的轨迹对真实位姿也必然安全——这正是管式 MPC 的鲁棒裕度思想，只是从动力学搬到了证书门。v5 的门 kc_i(x,c(T)) 里 T 是点估计；v6 把 T 换成保形集 C_ε（分布无关、有限样本覆盖 ≥ 1−δ），门在 C_ε 上取最坏情形：kc_i^rob = 1[min_{T∈C_ε} s_i(x,c(T)) ≥ τ_i]。由于 s_i 对 T 满足 L_i-Lipschitz，最坏情形可用 s_i(x,c(T̂)) − L_i·ε 下界，无需真的对集合做优化。关键性质：**只缩不放**，ε=0 时精确退化为 v5。对称物体/遮挡给出多模态 C_ε（多个位姿假设），若各模态的证书不能同时成立则**弃权**（fail-closed 交教师/慢路径），而不是赌某一个模态。

2. **通用操作 → 把「一个通用策略」拆成「接地的技能原语 + 证书组合」，用组合可靠性替代全域覆盖**。直觉：开放词汇、无穷任务不可能有一个策略在每一点都铸证；但「抓取/推移/放置」等技能原语的证书可以参数化到接地物体/可供性上，长程任务 = 技能序列，只要相邻技能的 post/pre 条件在接地坐标系里衔接，整条计划的证书就能由各段证书合成（证书携带计划，proof-carrying plan 的机器人版）。跨本体则用「本体条件化门模板 + 有界重定向映射」：为 β 铸的证，迁移到 β′ 时按重定向畸变界再收缩一次裕度。于是「通用」不靠一个万能网络，而靠**可组合、逐段可认证的接地技能**。

3. **两者合流 → 感知误差沿组合链传播，必须在每一段接地处重新收紧**。长程任务里，前一段的落点误差会成为后一段的初始位姿误差；若只在第一段做保形覆盖，误差会累积并击穿后段证书。因此组合算子必须携带**误差传播账本**：ε_{i+1} = min(ε_max, ε_i + Δ_i^exec + Δ_i^sense)，每段按传播后的 ε_i 做鲁棒裕度。这把「视觉定位」从一次性前端升级为贯穿整条计划的不确定性预算；账本单调非减，一旦超预算即整条计划拒绝，禁止「先跑再看」。

**关键洞见**：v5 回答「提议任意、记忆反哺、人因含情感时，证书边界是否不变」；v6 回答「**参考系本身不确定、任务开放、本体各异时，证书是否仍然对真实世界成立**」。七硬门记号原样复用；本轮新增只有：保形感知集 C_ε、鲁棒门 kc^rob（裕度只缩）、接地技能组合算子 ∘_cert、本体重定向界 δ_ρ。执行集 Exec_v6 ⊆ Exec_v5 由「同门 + 裕度只缩 + 感知弃权」三重保证。

**形式化目标（增量）**：
1. 保形感知集：非一致性分数 r(T̂,T)=d_SE3(T̂,T)（位姿测地距离，多模态按最近模态）；阈值 q̂ 取校准集 ⌈(n+1)(1−δ)⌉/n 分位；C_ε(obs)={T: r(T̂,T) ≤ q̂}，在可交换性下 P(T_gt ∈ C_ε) ≥ 1−δ，记 ε=q̂ 为保形半径。
2. 鲁棒门：kc_i^rob(x)=1[s_i(x,c(T̂)) − L_i^+·ε ≥ τ_i^5]，L_i^+ 为门分数对位姿的 Lipschitz 上界；等价于阈值膨胀 τ_i^6 = τ_i^5 + L_i^+·ε（乘性情感调制 + 加性感知裕度，两种收紧正交叠加）。
3. 接地技能 σ=(pre_σ, post_σ, π_σ, cert_σ)；接地实例 σ[T̂,C_ε]；组合 P=σ_1∘_cert…∘_cert σ_n；误差账本 ε_{i+1}=Prop(ε_i)。
4. 本体重定向：ρ:β→β′ 有界畸变 δ_ρ；门模板 Γ_i(β)；迁移裕度再缩 L_i^ρ·δ_ρ。
5. 定理 9（感知鲁棒可靠性/保形覆盖）、定理 10（组合可靠性）、定理 11（嵌套保持）、定理 12（弃权完备/fail-closed），引理 45~47。
6. Exec_v6 = {x ∈ Exec_v5 : Grounded(x)=⊤ ∧ ∧_i kc_i^rob(x; C_ε)=1} ⊆ Exec_v5。

**本轮最大风险**：**保形覆盖与泛化目标的根本冲突**——保形预测的 1−δ 覆盖依赖校准集与部署样本可交换，而「通用操作」的定义就是部署分布相对校准集发生位移（新物体、新光照、新本体），恰恰在分布位移处覆盖保证失效，鲁棒证书的可靠性保证在它最需要的新场景里退化为空；在线/自适应保形（ACI）、位移检测与弃权只能缓解，无法给出分布位移下的先验保证。

## 2. 关键算法骨架

### IP-497 GPK：接地感知核（前端，10–30 Hz，与控制环解耦）

```python
@dataclass
class GroundedPerceptionKernel:
    """GPK：开放词汇视觉定位 → 保形集 C_ε。
    定理 9：C_ε 以 ≥1−δ 覆盖真实位姿（可交换性下），鲁棒门据此可靠。
    定理 12：歧义/遮挡/无检测 → 弃权（⊥），绝不产出未接地证书。"""
    detector: Any            # 开放词汇检测（GroundingDINO 蒸馏）
    segmenter: Any           # 提示分割（SAM 蒸馏）
    pose_est: Any            # 6D 位姿（FoundationPose 蒸馏 / PnP + 对称多解）
    affordance: Any          # 可供性头（抓/推/放 热图）
    conformal: ConformalCalibrator   # 校准集 → q̂
    delta: float = 0.05
    eps_max: float = 0.02    # m / rad；超过即弃权

    def ground(self, obs, task) -> Grounding:
        boxes = self.detector(obs.rgb, task.nouns)        # 开放词汇
        if not boxes:
            return Grounding.abstain('NO_DETECTION')      # 未知的未知：无法自知漏检
        M = self.segmenter(obs.rgb, boxes)
        T_hat, modes, sigma = self.pose_est(obs.depth, M) # 对称物体返回多模态
        A = self.affordance(obs.rgb, M, task.verb)
        C_eps = self.conformal.set(T_hat, modes, sigma)   # 每个模态一个球
        eps = C_eps.radius()
        if eps > self.eps_max:
            return Grounding.abstain('AMBIGUOUS', eps=eps)  # 定理 12(b)
        return Grounding(T_hat, C_eps, A, eps, modes)

    def latency_inflate(self, g: Grounding, dt: float, v_max: float) -> Grounding:
        """感知陈旧度：距上次观测 dt，半径按 v_max·dt 增长（只增不减）"""
        return g.with_eps(min(self.eps_max, g.eps + v_max * dt))
```

### IP-498 PRCI：感知鲁棒证书膨胀（离线定界 + 在线 O(1) 查表）

```python
@dataclass
class PerceptionRobustCertificateInflation:
    """PRCI：把感知半径 ε 折算成门裕度。只缩不放。
    定理 9：kc_i^rob 通过 ⇒ 对真实位姿以 ≥1−δ 通过 v5 门。"""
    L_plus: dict      # 每门 Lipschitz 上界 L_i^+（区间估计，缺省见 §4 引理 45）
    L_retarget: dict  # 跨本体畸变敏感度 L_i^ρ

    def thresholds(self, tau5: dict, eps: float, gamma: dict,
                   delta_rho: float = 0.0) -> dict:
        # τ^6 = γ·τ^4 + L^+·ε + L^ρ·δ_ρ = τ^5 + 感知裕度 + 重定向裕度
        return {i: tau5[i] + self.L_plus[i] * eps
                   + self.L_retarget.get(i, 0.0) * delta_rho
                for i in tau5}

    def robust_pass(self, gate_id, score, tau6) -> bool:
        return score >= tau6[gate_id]            # 等价 min_{T∈C_ε} s_i ≥ τ_i

    def robust_pass_multimodal(self, gate_id, scores_by_mode, eps_by_mode, tau5) -> bool:
        """多模态：所有模态都必须通过（不知道哪个是真模态 → 取最坏）"""
        return all(s - self.L_plus[gate_id] * e >= tau5[gate_id]
                   for s, e in zip(scores_by_mode, eps_by_mode))
```

### IP-499 AGSC：可供性接地技能组合（组合准入，异步）

```python
@dataclass
class AffordanceGroundedSkillComposition:
    """AGSC：通用任务 = 接地技能序列；证书携带计划 + 误差账本。
    定理 10：各段证书通过且账本不超预算 ⇒ 组合计划可认证。"""
    library: dict                       # 技能原语库
    prci: PerceptionRobustCertificateInflation
    eps_max: float = 0.02

    def instantiate(self, sigma, grounding, beta, beta_prime) -> GroundedSkill:
        delta_rho = retarget_distortion(beta, beta_prime)   # ρ 的畸变界
        return GroundedSkill(sigma, grounding, beta_prime, delta_rho)

    def compose(self, plan: list[str], grounding, beta, beta_prime,
                tau5, gamma) -> CertifiedPlan:
        eps = grounding.eps
        certs, certs_ok = [], True
        g = grounding
        for name in plan:
            gs = self.instantiate(self.library[name], g, beta, beta_prime)
            tau6 = self.prci.thresholds(tau5, eps, gamma, gs.delta_rho)
            cert = gs.certify(tau6)                    # 复用七硬门，鲁棒裕度
            if not cert.ok:
                return CertifiedPlan.reject('SKILL_CERT_FAILED', name)  # fail-closed
            certs.append(cert)
            eps = min(self.eps_max, eps + gs.delta_exec + gs.delta_sense)
            if eps > self.eps_max:
                return CertifiedPlan.reject('ERR_BUDGET', name)  # 引理 47
            g = g.predict_post(gs)                     # 推进接地坐标系（含衔接误差）
        return CertifiedPlan.ok(certs)
```

### IP-500 EFA-v6：七硬门 + 鲁棒裕度 + 感知弃权 + 组合准入

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：门集合不变；阈值 τ^6 = τ^5 + L^+·ε；感知不可信则弃权。"""
    gpk: GroundedPerceptionKernel
    prci: PerceptionRobustCertificateInflation
    agsc: AffordanceGroundedSkillComposition
    v5: EvidenceForgingAssemblerV5          # 复用 fmpp/lmem/famk + 七门全套

    def select(self, x0_state, t_now, task, context, beta) -> tuple[bool, Trajectory | None, str]:
        # 1) 接地（前端，可能弃权）
        g = self.gpk.ground(context.obs, task)
        if g is None:
            return self.v5.select(...)      # 无感知：退回 v5（如已知物体规则提议）
        g = self.gpk.latency_inflate(g, t_now - g.t_obs, self.gpk.v_max)
        # 2) 阈值：情感调制（v5）× 感知/重定向裕度（v6）
        gamma = self.v5.famk.gamma(self.v5.famk.observe(context.face, t_now))
        tau5 = {i: gamma[i] * TAU4[i] for i in TAU4}
        tau6 = self.prci.thresholds(tau5, g.eps, gamma)
        # 3) 提议（条件含接地上下文）+ 级联廉价门（鲁棒）
        c = build_ctx_v6(context, g, self.v5.lmem)
        cands = self.v5.fmpp.propose(c, self.v5.fmpp.K)
        surv = [x for x in cands if self._cheap_gates_robust(x, g, tau6)]
        if not surv:
            return self.v5._fallback_rule_proposal(gamma)   # fail-closed
        # 4) VACK / BCK 在接地坐标系 + C_ε 膨胀下评估
        finals = []
        for x in sorted(surv, key=self._prefilter_score, reverse=True)[:3]:
            vac = self.v5.v4.vack.evaluate(x, context_with(g, gamma), t_now)
            if self.prci.robust_pass('val', vac.score, tau6):
                finals.append(x)
        ok = [x for x in finals if self._bck_preview_robust(x, g, tau6)]
        if not ok:
            return False, None, 'ALL_CANDIDATES_REJECTED'
        best = max(ok, key=certified_margin)
        return True, best, 'FORGED_PG_CGE'

    def ecs_v6(self, base_ecs5, g, lam_g=0.3) -> float:
        eta_ground = (1.0 - lam_g * (g.eps / self.gpk.eps_max)
                      if g is not None and g.eps <= self.gpk.eps_max else 0.0)
        return base_ecs5 * eta_ground
```

### 集成流水线（v5 → v6）

```
离线/慢时域：
  感知校准（每日）：成对 (观测, 真值位姿) ──▶ 非一致性分数 ──▶ q̂（保形阈值）
      ──▶ 分物体类别/遮挡等级分桶；分布位移监控触发重校准（ACI）
  Lipschitz 定界：门分数 s_i 对位姿的区间分析 + 采样 ──▶ L_i^+, L_i^-
  技能库铸证：技能原语 × 本体模板 Γ_i(β) ──▶ 每模板证书 + 重定向界 δ_ρ
  固化（v5 继承）：仅取「接地覆盖通过 ∧ 铸证 ∧ 结局验证」片段

在线准入（异步，秒级）：
  GPK.ground (10–30 Hz) ──▶ C_ε；歧义/遮挡/无检测 ──▶ 弃权 → v5 回退
  latency_inflate ──▶ ε(t) 随陈旧度增长（只增）
  PRCI.thresholds ──▶ τ^6 = γ·τ^4 + L^+·ε (+ L^ρ·δ_ρ)
  FMPP.propose(K=8) ──▶ 鲁棒廉价门筛
       ├─ 全灭 ──▶ fail-closed 回退 v5
       └─ 幸存 ≤3 ──▶ 鲁棒 VACK ──▶ 鲁棒 BCK ──▶ 取边际最大者
  长程任务：AGSC.compose ──▶ 逐段证书 + 误差账本（超预算即整条拒绝）

在线控制环（目标 < 0.6 ms，感知在环外）：
  每周期消费：预计算 τ^6、缓存的鲁棒证书、膨胀后的 C_ε 半径
  接触状态变更 ──▶ 鲁棒 QP 重解（C_ε 膨胀）；否则 O(1) 内插
```

## 4. 正确性论证（增量更新）

### 引理 45（门 Lipschitz 常数的区间估计）

**陈述**：对门 i 的分数 s_i(x,c(T))，在紧致位姿域上以「区间分析 + 边界采样」给出 [L_i^-, L_i^+] 使 |s_i(T₁)−s_i(T₂)| ≤ L_i^+·d_SE3(T₁,T₂)。证书用上界 L_i^+ 保证可靠性，用下界 L_i^- 评估保守度。若 L_i^+ 无界（分数对位姿不连续，如集合包含关系跳变），则该门「不可鲁棒化」，必须弃权或改用光滑替代。∎

### 引理 46（多模态保形集的覆盖）

**陈述**：设非一致性分数 r，校准集 n 个可交换样本，q̂ 为 ⌈(n+1)(1−δ)⌉/n 分位，则 P(r(T_gt) ≤ q̂) ≥ 1−δ。对多模态 C_ε=∪_m B(T̂_m,ε_m)，若 T_gt 落入任一模态球之并则覆盖成立；因无法判定真模态，鲁棒门要求**所有模态**满足各自裕度，否则弃权。∎

### 引理 47（误差账本单调传播）

**陈述**：ε_{i+1}=min(ε_max, ε_i + Δ_i^exec + Δ_i^sense)，Δ≥0 ⇒ {ε_i} 单调非减；一旦 ε_i>ε_max 后续无法恢复（除非重新感知重置 ε=ε_0）。故组合准入必须在每段检查预算，禁止「先跑再看」。∎

### 定理 9（感知鲁棒可靠性）

**陈述**：在可交换性 (C1) 与门分数 L_i-Lipschitz (C2) 下，若轨迹 x 通过全部鲁棒门 kc_i^rob（阈值 τ_i^6=τ_i^5+L_i^+·ε），则对真实位姿 T_gt 以概率 ≥1−δ 通过 v5 全部门。

**证明**：由引理 46，T_gt∈C_ε 以概率 ≥1−δ；由 Lipschitz，s_i(x,c(T_gt)) ≥ s_i(x,c(T̂)) − L_i^+·d(T̂,T_gt) ≥ s_i(x,c(T̂)) − L_i^+·ε ≥ τ_i^5。∎

**诚实边界**：(C1) 在分布位移下失效（本轮最大风险）；L_i^+ 估计过小则结论不成立，故用区间分析上界而非点估计。

### 定理 10（组合可靠性）

**陈述**：计划 P=σ_1∘_cert…∘_cert σ_n，若每段接地证书 cert_i 在账本 ε_i 下通过且 ε_{i+1}=Prop(ε_i) ≤ ε_max，则 P 的任意执行满足各段门约束与末段 post 条件，即 Exec(P) ⊆ ∩_i Exec(σ_i[T̂_i,C_{ε_i}])。

**证明**：对 i 归纳。基例 i=1 由 cert_1 与定理 9。归纳步：由 post_i ⊨ pre_{i+1}（接地坐标衔接，衔接误差已计入 Δ_i^sense）得第 i+1 段前置成立；由账本单调（引理 47）与 ε_{i+1}≤ε_max 得第 i+1 段鲁棒门可评估；合并证书得结论。∎

**诚实边界**：pre/post 衔接谓词本身由感知估计；若衔接不可判定，组合无效并弃权（定理 12(e)）。组合不修复单段证书的错误，只保证错误被传播账本捕获。

### 定理 11（嵌套保持）

**陈述**：对任意 ε≥0、γ≥1、δ_ρ≥0，有 τ_i^6 ≥ τ_i^5，故 kc^rob 通过集 ⊆ kc^v5 通过集；Exec_v6 ⊆ Exec_v5 ⊆ … ⊆ Exec_v29；当 ε=0, γ=1, δ_ρ=0 时精确退化为 v5。∎

**证明**：τ_i^6 = τ_i^5 + L_i^+·ε + L_i^ρ·δ_ρ ≥ τ_i^5（各项非负），阈值单调升 ⇒ 通过集单调缩 ⇒ 交集缩；ε=γ−1=δ_ρ=0 时相等。∎

### 定理 12（弃权完备 / fail-closed）

**陈述**：当 (a) 无检测，(b) ε>ε_max（歧义/遮挡/对称），(c) L_i^+ 无界，(d) 误差账本超预算，(e) 组合衔接不可判定 时，GPK/AGSC 返回 ⊥ 并转教师/慢路径；系统不产生「未接地证书」。即任何被认证的 x 必满足 Grounded(x)=⊤ 且全部鲁棒门通过。∎

**证明**：各分支在 GPK.ground / PRCI.robust_pass_multimodal / AGSC.compose 中显式返回 ⊥ 或 reject，认证路径仅在全部检查通过时到达。∎

**诚实边界**：弃权不保证「该弃权时一定弃权」——**未知的未知**（完全漏检的 OOD 物体被静默当作背景）无法被弃权机制感知，这是开放词汇感知的原理性盲区，只能靠计数统计/新颖度与红队覆盖缓解。

### 定理 v6（感知接地执行集，总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) 保形可交换性、(B9) 门 Lipschitz 上界有效 下：
(i) Exec_v6 ⊆ Exec_v5 ⊆ … ⊆ Exec_v29（同门 + 裕度只缩 + 弃权）；
(ii) 感知鲁棒：通过鲁棒门的轨迹对真实位姿以 ≥1−δ 通过 v5 门（定理 9）；
(iii) 组合可靠：账本不超预算的证书组合计划逐段满足门约束（定理 10）；
(iv) 弃权完备：不可信接地不产出证书（定理 12）；
(v) 跨本体迁移：重定向畸变计入裕度，迁移证书只紧不松（定理 11 的 δ_ρ 项）。

**证明**：(i) 由定理 11；(ii) 定理 9；(iii) 定理 10；(iv) 定理 12；(v) 由 τ^6 含 L^ρ·δ_ρ 且定理 11 的单调性。∎

**诚实声明**：(B8) 分布位移下覆盖失效——这是「保形保证」与「通用泛化」的结构性张力，ACI 与弃权只能事后缓解；(B9) L_i^+ 的区间估计对跳变门失效，需人工审计不可鲁棒门清单；(iii) 组合只传播误差不创造正确性，单段错误仍靠七门与弃权兜底；(iv) 未知的未知无结构兜底；(v) 开放词汇检测的词表外物体可能根本不进入候选。

## 5. 实验设计与初步结果（仿真，单机；实机/舰队列入第 7 轮）

### 5.1 实验设计

- **平台**：MuJoCo 3.x + MJX + 合成 RGB-D 渲染（域随机化：光照/纹理/遮挡/相机位姿）；接地用 GroundingDINO + SAM + FoundationPose 的蒸馏端侧版本；保形校准集 2000 对，测试含 IID 与分布位移（新类别/新光照/新背景）两档。

## 7. 本轮最大风险（最终确认）

**一句话**：**保形覆盖与泛化目标的根本冲突**——保形预测的 1−δ 覆盖依赖校准集与部署样本可交换，而「通用操作」的定义就是部署分布相对校准集发生位移（新物体、新光照、新本体），恰恰在分布位移处覆盖保证失效，鲁棒证书的可靠性保证在它最需要的新场景里退化为空；在线/自适应保形（ACI）、位移检测与弃权只能缓解，无法给出分布位移下的先验保证。
