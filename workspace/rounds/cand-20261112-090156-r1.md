# 第 58 轮（承接第 57 轮「少样本元推断×跨模态对账×个性化信任」IP-133~138；本轮灵感：「多传感器融合」×「竞品分析」）

> 第 57 轮把安全赌注从"模型置信"推到"证据承诺"，再用元先验摊销、跨模态对账、个性化信任状态机补效率与覆盖面；但它自己承认的最大风险是"坏先验普遍"——元模型在语料盲区给出自信错误。进一步审视，这个风险其实被三个更基础的缺口放大了：**(a)** 第 57 轮的 XMC 是决策级标签对账，"条件独立"是自我声明；真实传感器可能共享镜头、供电、标定、甚至同一套物理假设，十个传感器也许是同一个错误源的十份拷贝，时间不同步还会制造"假一致"；**(b)** OOD 门只能识别"不像训练分布"，不能识别"在分布内但结构上不可观测"——若区分真假冰面的物理量根本不在任何传感器的可观测子空间里，元先验再准也只是对不可见变量的自信猜测；校准不等于可辨识；**(c)** 第 57 轮的评测是自证的：没有预注册的竞品基线、没有独立红队，系统可能通过挑选弱基线"赢"，而"可校准"不等于"比保守基线更值得部署"。本轮两个灵感各补一刀：**多传感器融合**把对账从决策级下沉到测量级——解析冗余、故障检测隔离、共因失效图、时间同步证书；**竞品分析**提供两件仪器——**竞争假设分析（ACH）**让证据必须先击败最强竞争解释才算证据，**竞品基线审计（CBA）**让部署必须先击败预注册的最强安全基线，否则系统被基线否决。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"可观测可辨识、竞争假设可证伪、竞品基线可支配的证据说可信"**。

核心矛盾：
- **H29（融合 vs 共因）**：多传感器融合的收益来自"失效模式不同"，不是"数量更多"；但共因失效会让多数票变成同一个错误的复读，且时间不同步能把两个不同时刻的观测拼成虚假一致——更多传感器也可能更自信地错。
- **H30（可辨识 vs 自信）**：校准与 OOD 处理的是"分布偏移"，可辨识性处理的是"结构不可见"；当决策变量落在传感器族的不可观测核里，任何后验都只能是猜测。系统最危险的状态不是"我不知道"，而是"我不知道自己看不见"。
- **H31（竞品 vs 自证）**：竞品分析天然可被操纵——选弱基线、复用测试种子、只报有利指标、把"赢过上一版自己"当成"值得部署"；没有预注册、密封测试集、独立红队与基线否决权，"竞品分析"就退化为营销。

## 0. 直觉与动机

**灵感 1（多传感器融合 → 从"标签投票"下沉到"测量级解析冗余 + 共因失效图"）**
直觉：真正的融合不是把五个模态的结论取平均，而是让传感器互相"物理对账"——视觉说表面湿，热像说热惯量像干混凝土，触觉说摩擦系数低，声学说回波硬；这些残差在正常表面应同时接近零，在透明冰面上会分裂。融合的第一产物不是更准的估计，而是**"谁在说谎"的诊断**：故障检测与隔离（FDI）、传感器健康度、共因失效闭包。若故障集落在共因割集内，再多传感器也不增加独立票，系统必须拒融合而不是硬融。时间同步也进入证书：超过 τ_sync 的观测不得作为"同时刻一致"的证据。

**灵感 2（可观测性 → 把"不可辨识"变成一等状态，而不是更宽的先验）**
直觉：第 57 轮遇到盲区时退回共形带，本质上仍是"用一个更宽的分布去猜"；但有些量不是"难估"，而是**结构性不可辨识**——例如被厚雪覆盖的冰面，在当前传感器配置与激励轨迹下，冰/雪/空隙的可区分物理量根本不进入观测矩阵的行空间。正确反应不是"猜一个更保守的后验"，而是显式输出 `UNOBS`：只允许对可观测投影做判定，不可逆接触一律拒绝或退回基线；若预算允许，先选一个"提升可观测性"的激励探针，而不是继续采样同一个不可见方向。可辨识性证书 κ_obs=(秩, 条件数, 激励裕度, 不可观测核 N)。

**灵感 3（竞品分析·竞争假设 → ACH：证据必须击败最强对手）**
直觉：情报分析里的"竞争假设分析"（Analysis of Competing Hypotheses）反对先立结论再找支持证据，而是列出所有合理假设，逐条看证据**区分**了谁、又同时支持了谁。移植到机器人：H0=预期信念（如"可安全踏"), H1=某传感器故障, H2=另一种物理状态（如薄冰覆雪）, H3=地图陈旧, H4=标注者错误。只有当一个证据对 H0 相对**最强竞争假设**的贝叶斯因子 BF_{0|k}≥β_diag 时，它才算"诊断性证据"；同时支持 H0 与 H2 的证据不增加承诺资格，只更新信念。额外奖励反证：主动选"最可能推翻 H0"的探针，而不是最可能确认 H0 的探针。

**灵感 4（竞品分析·基线 → CBA：用预注册支配证书换部署权，并保留基线否决权）**
直觉：竞品分析不是发布会 PPT，而是**可被对手复核的支配关系**。维护基线族 B={保守安全基线, 第 57 轮系统, 纯人类监督, 外部竞品}；在预注册、密封、配对同分布的评测协议下，只有安全指标上界不劣于基线、效率指标下界优于基线，才发"支配证书"；证书带样本量、功效、协议哈希与**过期时间**。最关键的一条：**基线拥有否决权**——当前分布上无法证明支配时，系统必须把决策权交回最保守基线，而不是"凭架构先进性"继续承诺。竞品分析因此从"证明我好"变成"限制我何时不许上场"。

**灵感 5（合流 → 证据门与探询算子的第三次升级）**
直觉：第 57 轮证据门需要再加两层滤网：EV-probe 必须同时挂**可辨识证书**与**诊断贝叶斯因子**；EV-xmodal 升级为 **EV-fusion**，必须在测量级时间同步、解析冗余与共因预算内成立，且仍仅限 L1；EV-human 的确认也必须是诊断性的，不能是"对 H0 与 H1 同时成立"的橡皮章。竞品审计不直接产生接触证据，而是控制**部署与授权**：没有支配证书就没有 A2 授权，没有基线否决就没有不可逆承诺。PCE++ 的探针选择目标从"降低方差"改为"最大化对最强竞争假设的期望诊断增益"，可辨识性不足时优先"看得见"而非"猜得准"。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（解析冗余多传感器融合 MSF-A）** 传感器族 S，测量模型 z_s(t)=h_s(x(t),f_s)+ε_s，f_s∈F_s 为故障模式；时间对齐算子 A_τ 给出最大同步偏差 τ_sync。解析冗余残差 r_{ij}(t)=φ_{ij}(z_i,z_j) 在物理一致时应在容差内近零（例：视觉湿度×热惯量×触觉摩擦×声学回波）。共因图 G_cm=(S,E_cm)：若两传感器共享供电/镜头/标定/物理假设则连边；故障集 F 若与 G_cm 的某个割集相交，则称"共因不可分"。融合器为 **c-鲁棒**：任何 |F|≤c 且不含共因割集的故障可被检出/隔离，否则拒融合；不一致估计用协方差交叉（CI）而非朴素加权。输出融合证书 κ_msf=(τ_sync, 残差带, 共因割集, 已隔离故障, 健康度 h_s)。

**定义 140（可观测-可辨识证书 OIC）** 决策变量 y=g(x)，在 x0 处由李导数构造可观测矩阵 O_y(x0)；若 rank O_y=dim y 且激励裕度 exc≥θ_exc，则 y 局部可辨识，记 OBS；否则存在不可观测核 N，记 UNOBS，只允许对投影 y_obs=proj_{N^⊥}y 做判定，y 的 N 分量永不进入后验承诺。证书 κ_obs=(status, rank, cond(O), exc, N)。不得以"更宽先验"替代 UNOBS：不可辨识不是高方差，而是零信息。UNOBS 区域的不可逆接触一律拒绝；若预算允许，先执行可观测性增强探针 π_obs 再重算。

**定义 141（竞争假设分析 ACH）** 假设集 H={H0 预期信念, H1 传感器故障模式, H2 替代理物状态, H3 地图陈旧, H4 标注/接口错误}，先验带 ε-污染。对证据 e 定义诊断贝叶斯因子 BF_{0|k}(e)=p(e|H0)/p(e|Hk)，**诊断性** ⇔ min_{k≥1} BF_{0|k}(e)≥β_diag；非诊断证据只更新信念、不增加承诺资格。诊断力 δ(e)=min_{k≥1} KL(p(·|H0)‖p(·|Hk))。反证优先：探针选择最大化"对当前最强竞争假设的期望 BF 增益"，而非最大化对 H0 的确认；负证据（不支持 H0）按对称权重入账。

**定义 142（竞品基线审计 CBA）** 基线族 B={B_safe, B_57, B_human, B_ext}，评测协议 P 预注册（密封任务集、配对同分布、固定 α、样本量、协议哈希）。支配关系 S≻B ⇔ UCB_α(fail_S)≤LCB_α(fail_B)+m_s ∧ LCB_α(eff_S)≥UCB_α(eff_B)−m_e。部署门：若存在活跃基线 B 使 S⊁B，则**基线否决**，控制权交给最保守可行基线；红队 R 独立搜索反例，发现即吊销证书。证书 κ_cba=(hash(P), 功效, 支配集, 红队轮数, 到期时间, 分布版本)——支配只在声明分布与时限内有效。

**定义 143（可辨识融合证据门 IFG 与证书 J_q）** 证据类：EV-probe\*\*（OBS ∧ ECE_k≤ε_meta(k) ∧ BF≥β_diag）；EV-fusion（测量级时间同步 ∧ 解析冗余 ∧ 共因预算内，**仅限 L1**）；EV-visit/EV-margin（继承第 57 轮，另需 OBS）；EV-human（auth≥A1 ∧ 佐证达标 ∧ 诊断性）；EV-bench 只是部署/授权门，**永不作为接触证据**。硬禁令：UNOBS ⇒ 禁 EV-probe\*\* 与一切不可逆承诺；共因割集内 ⇒ 禁 EV-fusion；非诊断证据 ⇒ 禁不可逆接触。J_q=(J_p, κ_msf, κ_obs, κ_ach, κ_cba, sensor_health, redteam_log)，继承 J_p 全检。

**定义 144（探-诺-演++ 算子 PCE++）** 每检查点：①时间同步与传感器健康检查；②OIC：UNOBS ⇒ 不猜，优先选可观测性增强探针，否则基线回退/安全停；③ACH 初始化竞争假设；④选探针 π\*=argmax_π[E 诊断增益(π)−cost(π)]，约束 k_probes+k_cons；⑤MSF-A 融合 + FDI + 共因闭包；⑥IFG 过门才可承诺；⑦部署前 CBA 支配检查，未支配则基线否决；⑧探尽→绕行→降档→L2 协商或安全停。

## 2. 关键算法伪代码（完整版见产物区）

```python
def msf_fuse(M, r, batch):                         # IP-139: 测量级、共因感知
    batch = time_align(batch, tau_sync)
    if batch.skew > tau_sync:                      # 不同步不得冒充"同时一致"
        return M, 'reject_timesync'
    for z in batch.meas: M.health[z.s] = fdi_update(M.health[z.s], z)
    res = analytical_residuals(batch, M.calib)     # 视觉×热惯量×触觉×声学
    if common_mode_closure(batch.sensors, M.cm_graph) > M.budget_c:
        return M, 'reject_common_mode'             # 割集内多数票无效
    fused = covariance_intersection(batch.meas, M.health)
    return M, fused, res

def observability_certificate(M, r, y):            # IP-140: 不可辨识是一等状态
    O = observability_matrix(M.model[r], y, x0=M.x[r])
    rank, N = rank_null(O)
    if rank < len(y) or excitation_margin(M.traj[r], O) < theta_exc:
        return Cert('UNOBS', kernel=N, y_obs=proj_orth(y, N))
    return Cert('OBS', cond=cond(O), exc=excitation_margin(M.traj[r], O))
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| MSF-A | O(\|S\|²·d_z+N_sync) | O(\|S\|²) | c-鲁棒、共因割集检测、τ_sync 硬约束 |
| OIC | O(L·d_x·d_y) | O(d_x·d_y) | 不可观测核保守过近似（不漏报 UNOBS） |
| ACH | O(\|H\|·\|E\|) | O(\|H\|) | BF 校准诚实、最强竞争假设不缺席 |
| CBA | O(N_eval·(\|B\|+1)) 离线 | O(N_eval) | 预注册、无泄漏、证书过期、基线否决 |
| IFG | O(\|σ\|·\|H\|) | O(\|σ\|) | UNOBS/共因/非诊断三类硬拒 |
| PCE++ | O(\|CP\|·(k_p+k_c)·(C_diag+C_ach+\|S\|²d_z)) | O(\|V\|+\|σ\|) | 诊断增益单调、k_p+k_c 终止 |

**正确性定理（可观测-可证伪-可支配健全性 OFDS，概要）**：在 A37–A40 上加 (A41) OIC 保守过近似：凡输出 OBS 的量在声明轨迹上局部可辨识，UNOBS 的不可观测核不小于真实核；(A42) 共因模型完备到预算 c、时间同步偏差 ≤τ_sync 诚实声明；(A43) ACH 似然与 BF 校准诚实、竞争假设集覆盖已知故障模式、无证据泄漏；(A44) CBA 协议预注册、密封、红队独立、基线否决与授权联动。则：(i) 可辨识路径承诺失效率 ≤ δ_f+ε_meta(k)+δ_probe+δ_obs+δ_ach+ε_h，其中 δ_obs 为可辨识性误判率、δ_ach 为诊断性误判率；(ii) 不可辨识/共因超预算/非诊断路径只通向基线回退或安全停，不产生新升险路径；(iii) PCE++ 在 k_probes+k_cons 内终止；(iv) 部署安全界额外扣除 δ_cm+δ_bench，且证书过期即自动降回基线。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 可辨识性分析把不可观测误判为可观测 | 高 | 不可观测核保守过近似 + 数值秩/条件数双阈值 + 多模型一致性 + 不可逆一律拒绝 |
| 共因故障库不全，割集漏建 | 高 | 异构失效图 + 故障注入测试 + c-鲁棒预算 + 超预算拒融合 |
| 竞争假设集漏掉最强对手 | 高 | 红队持续补假设 + 开放集监控 + 非诊断证据不入承诺 |
| 竞品基线被挑选/评测泄漏 | 高 | 预注册协议 + 密封测试集 + 独立红队 + 基线否决 + 证书到期 |
| τ_sync 内插值制造假一致 | 中高 | 插值不确定度并入协方差 + 超时拒证据 + 关键接触要求原始同步帧 |
| 多传感器+FDI 时延进入控制回路 | 中 | 分层触发（仅分歧/不可逆/低健康度全量审计）+ 预取 + 可退回第 57 轮路径 |

## 6. 本轮最大风险

**一句话**：本轮把"可信"的最终裁决又外包给两个新裁判——可辨识性分析与竞品基线审计；如果 OIC 把不可观测维误判为可观测，或 CBA 的竞品集遗漏了最强的安全基线，系统就会拿着一份"自证合格"的证书更快地承诺，风险从"坏先验普遍"升级为"裁判本身被收买"——因此必须让不可观测核保守过近似、共因超预算直接拒融合、竞品协议预注册且由独立红队复核、并保留最保守基线的无条件否决权，宁可承认"看不见/赢不了"，也不让系统给自己发通行证。

### IP-139 MSF-A（解析冗余多传感器融合）

```python
def msf_fuse(M, r, batch):
    batch = time_align(batch, tau_sync)                 # 统一时钟 + 插值不确定度
    if batch.skew > tau_sync:                           # 超时不得冒充同时一致
        return Fusion(M, status='reject_timesync')
    for z in batch.meas:
        M.health[z.s] = fdi_update(M.health[z.s], z)    # 故障检测与隔离
    res = analytical_residuals(batch, M.calib)          # 视觉×热惯量×触觉×声学
    cm = common_mode_closure(batch.sensors, M.cm_graph) # 共因割集闭包
    if cm.exceeds(M.budget_c):
        return Fusion(M, status='reject_common_mode')   # 割集内多数票无效
    est = covariance_intersection(batch.meas, M.health) # 不一致时 CI，不硬平均
    cert = K_msf(tau_sync=batch.skew, residuals=res, cm=cm,
                 isolated=M.isolated, health=M.health)
    return Fusion(M, est=est, cert=cert, status='ok')

def fdi_update(h, z):
    h.resid = update_residual_bank(h.resid, z)
    if detect(h.resid) and isolate(h.resid):
        return Health(h.s, state='fault', weight=0.0)
    return Health(h.s, state='ok', weight=clip(h.weight * h.consistency))
```

def observability_certificate(M, r, y):
    O = observability_matrix(M.model[r], y, x0=M.x[r])  # 李导数构造
    rank, N = numerical_rank_null(O, tol=rank_tol)      # 保守估计不可观测核
    exc = excitation_margin(M.traj[r], O)
    if rank < dim(y) or exc < theta_exc:
        y_obs = proj_orth(y, N)                         # 只判定可观测投影
        return Cert(status='UNOBS', kernel=N, y_obs=y_obs, exc=exc)
    return Cert(status='OBS', cond=cond(O), exc=exc)

def unobs_policy(cert, level):
    if cert.status == 'OBS':
        return 'normal'

        return 'refuse_or_baseline'                     # 不猜不可逆

### IP-141 ACH（竞争假设分析）

```python
def ach_init(M, r, task):
    return { 'H0': prior(M.b[r], 'intended'),
             'H1': fault_modes(M.health, M.cm_graph),
             'H2': alternative_physics(M.zone_class[r]),
             'H3': stale_map_modes(M.ver),
             'H4': human_input_error_modes(M.auth_log) }

def ach_update(H, e, model):
    for h in H:
        H[h].lik = model.likelihood(e, h) * H[h].lik
    bf = {k: H['H0'].lik / H[k].lik for k in H if k != 'H0'}
    strongest = min(bf, key=bf.get)                     # 最强竞争假设
    diag = bf[strongest] >= beta_diag
    return H, diag, bf[strongest], strongest

def choose_probe_ach(H, cands, cost):
    return argmax(cands, key=lambda p:
                  expected_bf_gain(H, p) - cost(p))     # 反证优先，非确认优先

def ach_commit_eligible(H, diag, e):
    return diag and strongest_competitor_excluded(H, e) \
           and not evidence_supports_multiple(H, e)     # 同时支持对手的证据不算
```

### IP-142 CBA（竞品基线审计与基线否决）

```python
def cba_audit(system, B, protocol):
    if not protocol.preregistered or protocol.leaked:
        return Cert(status='invalid', reason='protocol')
    if protocol.expired:
        return Cert(status='expired', fallback='B_safe')
    for b in B:
        s_ucb = ucb(fail_rate(system, protocol), protocol.alpha)
        b_lcb = lcb(fail_rate(b, protocol), protocol.alpha)
        e_lcb = lcb(eff(system, protocol), protocol.alpha)
        b_ucb = ucb(eff(b, protocol), protocol.alpha)
        if not (s_ucb <= b_lcb + protocol.margin_s
                and e_lcb >= b_ucb - protocol.margin_e):
            return Cert(status='baseline_veto', baseline=b)  # 未支配不许上场
    red = independent_redteam(system, rounds=protocol.red_rounds)
    if red.found_counterexample:
        return Cert(status='revoked', counterexample=red.case)
    return Cert(status='dominant', baselines=B, power=protocol.power,
                hash=protocol.hash, expires=protocol.expiry)

def deployment_gate(auth_level, cba_cert):
    if cba_cert.status != 'dominant':
        return Deploy(control=cba_cert.fallback, auth='A0')
    return Deploy(control='system', auth=auth_level)     # 支配只换取上场权
```

def identifiable_fusion_gate(c, certs, persona, ood_reg):
    if c.ev == 'EV-probe**':
        ok = (certs.obs.status == 'OBS'
              and certs.obs.cond <= cond_max
              and c.inf.cls == 'ID'
              and c.inf.ece_k <= eps_meta(c.k)
              and certs.ach[0] and certs.ach[1] >= beta_diag)
    elif c.ev == 'EV-fusion':
        ok = (c.level == 'L1'
              and certs.msf.status == 'ok'
              and certs.msf.timesync <= tau_sync
              and certs.msf.cm_ok and certs.msf.health_ok
              and certs.ach[0])
    elif c.ev == 'EV-human':
        ok = (persona[c.op].auth >= 'A1'
              and c.corrob >= quarantine_exit(persona[c.op].auth)
              and certs.ach[0])                       # 人体确认也须诊断性
    elif c.ev in ('EV-visit', 'EV-margin'):
        ok = round57_checks(c, certs)
    else:
        return ('reject', 'no_evidence_class', c)
    if not ok:
        return ('reject', 'evidence_insufficient', c)
    if certs.obs.status == 'UNOBS':
        return ('reject', 'unidentifiable', c)        # 硬禁令
    if c.irreversible and (c.ev == 'EV-fusion' or not certs.ach[0]):
        return ('reject', 'nondiagnostic_on_irreversible', c)
    return ('ok', c)

def certificate_q(sched, log, M, certs, redteam_log):

### IP-144 PCE++（可辨识感知的探-诺-演++）

```python
def probe_commit_evolve_plus_plus(x0, M, task, budget, consent, personas):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        M, sync_ok = msf_sync_check(M, cp)
        if not sync_ok:
            return baseline_or_stop(cp, M, 'timesync')      # 不同步不承诺
        obs = observability_certificate(M, cp.region, y=cp.decision_var)
        if obs.status == 'UNOBS':
            p_obs = best_observability_probe(cp, M, budget)
            if p_obs and budget.probes_left > 0:
                M, _ = msf_fuse(M, cp.region, execute(p_obs, cap=F_abs))
                obs = observability_certificate(M, cp.region, cp.decision_var)
            if obs.status == 'UNOBS':
                return baseline_or_stop(cp, M, 'unidentifiable')  # 不猜
        H = ach_init(M, cp.region, task)
        while budget.probes_left > 0:
            cands = admissible_probes(cp, M, F_abs)
            p = argmax(cands, key=lambda q:
                       expected_diagnostic_gain(H, q)
                       - cost(q) - risk_penalty(q, M))
            if expected_diagnostic_gain(H, p) < theta_diag_gain:
                break
            batch = execute(p, cap=F_abs)
            M, fused = msf_fuse(M, cp.region, batch)
            H, diag, bf, strongest = ach_update(H, evidence(batch), M)
            if diag and select_gait(schedule_risk(foothold_schedule(x0, cp, M), M)) != 'halt':
                break
        sigma = foothold_schedule(x0, cp, M); R = schedule_risk(sigma, M)
        g = select_gait(R)
        lv = contact_level(cp)
        certs = collect_certs(M, cp, H, diag, bf, lv)
        if g != 'halt' and identifiable_fusion_gate(
               core_contact(cp), certs, personas, ood_reg)[0] == 'ok':
            if not cba_audit(system, baselines, protocol).dominant:
                return defer_to_baseline(cp, M, 'baseline_veto')
            sched.append(commit(sigma, g)); log.append(tag_evidence_p(sigma, M, lv))
            continue
        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, M)) != 'halt':
            route = alt; continue
        return negotiate_or_stop(cp, M, sigma, R, consent,
                                 tau_int=tau_int(personas.active.auth))
    return sched, log, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| MSF-A | O(\|S\|²·d_z+N_sync) | O(\|S\|²) | c-鲁棒、共因割集检测、τ_sync 硬约束（A42） |
| OIC | O(L·d_x·d_y) | O(d_x·d_y) | 不可观测核保守过近似，不漏报 UNOBS（A41） |
| ACH | O(\|H\|·\|E\|) | O(\|H\|) | BF 校准、最强竞争假设覆盖、无泄漏（A43） |
| CBA | O(N_eval·(\|B\|+1)) 离线 | O(N_eval) | 预注册、独立红队、证书过期、基线否决（A44） |
| IFG | O(\|σ\|·\|H\|) | O(\|σ\|) | UNOBS/共因/非诊断三类硬拒 |
| PCE++ | O(\|CP\|·(k_p+k_c)·(C_diag+C_ach+\|S\|²d_z)) | O(\|V\|+\|σ\|) | 诊断增益单调、k_p+k_c 终止、四态完备 |

**正确性定理（可观测-可证伪-可支配健全性 OFDS）**
假设 A22–A32（第 53–55 轮）、A33–A36（第 56 轮）、A37–A40（第 57 轮）成立；**(A41)** OIC 保守过近似：OBS 蕴含声明轨迹上局部可辨识，UNOBS 返回的不可观测核不小于真实核；**(A42)** 共因模型完备到预算 c、时间同步偏差 ≤τ_sync 且插值不确定度诚实进入协方差；**(A43)** ACH 似然与 BF 校准诚实、竞争假设集覆盖已知故障模式、证据无泄漏；**(A44)** CBA 协议预注册、测试集密封、红队独立、证书带样本量与到期时间、基线否决与授权联动。则：

1. **可辨识承诺健全性**：可辨识路径 P(fail) ≤ δ_f + ε_meta(k) + δ_probe + δ_obs + δ_ach + ε_h(w_max)；其中 δ_obs 为可辨识性误判率、δ_ach 为诊断性误判率；UNOBS/共因超预算/非诊断路径不产生承诺，只通向基线回退或安全停。
2. **交互单调性第三次强化**：MSF-A、OIC、ACH 只能经 (a) 更准的诊断（含拒绝融合）或 (b) 更保守的动作参数（UNOBS→基线、共因→拒融合、非诊断→拒承诺）影响系统；CBA 只控制"何时不许上场"，不增加升险路径。
3. **终止性**：每检查点诊断探针 ≤k_probes+k_cons，PCE++ 在预算内终止于 {承诺, 绕行, 基线回退, L2 协商, 安全停}。
4. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + δ_obs + δ_ach + ε_h)
             − P(共因超预算未检出) − P(不可观测核低估)
             − P(竞品协议失效/泄漏) − P(护盾回退失败)
```

关键：**融合的价值是诊断而非投票**（测量级解析冗余让"传感器是否共谋"可检验）；**不可辨识不是高方差而是零信息**（OIC 让系统显式承认"看不见"，而不是用更宽先验把猜测伪装成保守）；**证据资格由击败最强竞争假设定义**（ACH 把确认偏误挡在承诺之外）；**部署资格由预注册支配最强安全基线定义**（CBA 让竞品分析从自证改为他证，并保留基线否决权）。

云边协议 CEB++ → **CEB+++**：云端可下发**(a)** 传感器故障签名库与共因图增量、**(b)** 竞争假设模板、**(c)** 密封竞品评测集；三类更新都必须过隔离区：故障库与竞品集先在边端影子模式运行，验证"共因检出率不降 ∧ UNOBS 正确率不降 ∧ 基线否决不失灵"后才接管；竞品评测集必须预注册并封存，红队由独立方执行，边端只回传聚合指标与反例，不上传可反向拟合测试集的原始样本。第 57 轮"一切判定器走隔离"在本轮细化为"**裁判（可辨识性、竞争假设、竞品基线）与选手（元模型）分离，且裁判自身也要被外部红队审计**"。

## 6. 本轮最大风险

**一句话**：本轮把"可信"的最终裁决又外包给两个新裁判——可辨识性分析与竞品基线审计；如果 OIC 把不可观测维误判为可观测（数值秩估计偏乐观、激励条件被轨迹偶然满足），或 CBA 的竞品集遗漏了最强的安全基线（弱基线诱导、测试集泄漏、分布漂移后证书未过期），系统就会拿着一份"自证合格"的证书更快地承诺，风险从"坏先验普遍"升级为"裁判本身被收买"——因此必须以不可观测核保守过近似、共因超预算直接拒融合、竞品协议预注册且由独立红队复核、最保守基线保留无条件否决权四重护栏，宁可承认"看不见/赢不了"，也不让系统给自己发通行证。
