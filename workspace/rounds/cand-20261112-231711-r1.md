# 第 63 轮（承接第 62 轮「ROSE 鲁棒在线场景进化闭环」IP-183~192；灵感循环 III 第 1 轮；本轮灵感：「云边协同」×「预训练」）

> 第 62 轮用 ROSE 补上了在线学习（OLP）、鲁棒编译（WCV+RSC）、场景银行（SBR+SHC）三个动力学维度，但它仍默认：**学习发生在单个边缘、经验不离开本体、先验从零或本地旧状态开始、通信不进入任何界**。这留下四个结构性缝隙：
> 1. **冷启动与重复学习**：OLP 的 W 从零或本地旧值出发，跨机器人、跨任务、跨场景共享的物理规律被每个边缘反复重新学习；ROSE 的遗憾界是单机界，不含「已有先验能把起点推进多少」。
> 2. **RSC 可辨识性单点**：ROSE 自述的最大风险是 J_φ 病态或残差被控制回路吸收。单机的信息不足是**结构性秩亏**，不是估计算法能修的——再多本地数据也补不出缺失的观测方向。
> 3. **场景银行局部封闭**：Bank 上限 64 簇且只装单机险情，无法把机队其他成员的险情转化为生成式预训练语料，也无法合成训练集之外的复合场景。
> 4. **通信与预算割裂**：OCB 只选本地推理模式，不决定「什么上云、什么留边、多久同步」；带宽/时延非平稳时，既无遗憾保证也无安全保证。

## 0. 直觉与动机

**灵感 1（云边协同 → 云端只给「提示」，边缘保留否决权）**
直觉：最自然的云边分工是「云端算大模型、边缘跑控制」，但这会把安全绑在云链路上，竞赛现场一断网就失效。更好的隐喻是**云端像一位会犯错的老教授，只提供建议，边缘像持证的驾驶员，永远保留否决权**。形式化：云端每个慢周期发布提示 H_k = (W^g_k, M_k)（全局投影先验与预测梯度），边缘把 H_k 当作**在线预测（hint）**喂给乐观在线学习。关键洞见：乐观 FTRL 的遗憾界由「预测误差」而非仅由 T 决定——于是云先验有多准、同步有多旧，都显式地写进了界里；先验错了可被门控拒绝，退化为 ROSE 的 O(√T)，不会比单机更差。

**灵感 2（预训练 → 可迁移先验 + 低维适配 + 测试时自监督）**
直觉：预训练的价值不是「一次训完就冻结」，而是把学习搬到**条件数更好的低维子空间**：云端在机队全局场景上预训练语义骨干与物理世界模型，边缘只学一个小适配器与低秩 W。这样 OLP 的参数维度和 J_φ 的病态程度一起下降。更进一步，边缘用无标签流做**测试时预训练（PTA）**：掩码物理状态预测、时序对比、多步动力学一致性——预训练不是云端的专利，边缘在两个云周期之间也能持续「自我预训练」。

**灵感 3（合流 → CAPE：云边预训练进化闭环）**
四者不是并列而是闭环咬合：云端预训练（ACP）降低提示误差 ε_hint；边缘乐观学习（OLCP）把 ε_hint 转成遗憾；异步同步产生陈旧 τ，显式进入界；CPG 保证再坏的云先验也越不过边缘安全域；FIR 用机队联合观测修复单机秩亏；GSB 把险情变成云端的生成式预训练语料；CLA 在通信代价与陈旧风险之间选分层卸载臂。闭环：边缘险情 → 隐私签名 → 全局银行 → 云端持续预训练 → 版本化提示 → 边缘 OLCP/PTA → 新险情。ROSE 是「单机学习-鲁棒闭环」，CAPE 是「机队-云-边两层时间尺度的学习-通信-安全闭环」。

**灵感 4（安全 → CPG：云先验守卫 + 鲁棒聚合）**
云不是可信的：它可能因异质本体而失配，也可能被少数坏机器人投毒。安全必须留在边缘、且是机制而非假设：云先验先投影到本地可信域与安全域的交集 W_used = P_{𝒲_safe ∩ B(W_t, ρ_trust)}(W_cloud)，再交给 ROSE 的 WCV/Shield。于是**云只能影响性能，不能影响安全**。同时用「提示-梯度对齐」与「损失变化」做二假设检验，区分「先验错了」与「环境漂移了」：持续负对齐 → 拒绝先验；正对齐但损失升 → 判为漂移，提高本地学习率。

**灵感 5（可辨识性 → FIR：用机队秩修复单机秩亏）**
ROSE 的 RSC 单点风险本质是观测矩阵秩亏。不同本体/位姿/任务对同一物理参数 φ 的灵敏度方向不同：单机 J_i 可能缺秩，但堆叠 J = [J_1;…;J_N] 可能满列秩。定义**集体可辨识性**：rank(J) = d_φ。云端据此解全局物理偏差后验，边缘用协方差交叉与本地后验融合；若冲突超阈值，判为「未建模动力学」并主动膨胀球，而不是硬套全局值。

**灵感 6（通信预算 → CLA：把「什么上云」做成延迟反馈老虎机）**
把 ROSE 的 OCB 从「本地模式选择」升级为「分层卸载选择」：臂 = {纯本地, 适配器同步, 全量云预训练, 场景蒸馏, 混合}，奖励 = 任务进展 − λ_c·通信代价 − λ_s·陈旧风险，反馈延迟 d_t。用延迟反馈 EXP3 / 睡眠老虎机处理断网与云过载；ROSE 的 PCE+++++ 硬降级阶梯仍是不可突破的安全下界。

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 1（乐观 FTRL 惊讶界）**：凸损失、𝒲 直径 D、二次正则下，带提示 M_t 的 OFTRL 满足 R_T ≤ D²/(2η) + (η/2)Σ‖g_t − M_t‖²；取 η = D/√(Σ‖g_t−M_t‖²) 得 **R_T ≤ D·√(T·Ē_T)**，Ē_T 为平均预测误差。提示完美则近常数遗憾；无提示（M=0）退化为 D·G·√T。
- **定理 1（陈旧提示的遗憾分解）**：若 ‖g_t − M_t*‖ ≤ ε_hint 且提示随时间 L_drift-Lipschitz，则 ‖g_t − M_{κ(t)}‖ ≤ ε_hint + L_drift·τ_t，故 **R_T ≤ D·√T·(ε_hint + L_drift·τ̄)**。通信间隔与云先验质量以加性方式显式进入界；带拒绝门控时 R_T ≤ D·√(Σ min(G², (ε_hint+L_drift·τ_t)²))，**永不劣于单机 ROSE**。
- **定理 2（先验迁移/冷启动）**：以云先验为中心的正则化把初始项从 D²/(2η) 降为 Δ_i²/(2η)（Δ_i = ‖W^g − W_i*‖）；机队任务越同质，冷启动遗憾下降越多。
- **定理 3（联邦可辨识性）**：单机 J_i 秩亏时局部物理偏差不可辨识（误差无界）；若堆叠 J 满列秩且局部未建模偏差零均值，则 FIR 误差 ≤ σ_ε/σ_min(J) + 异质项。这为 ROSE 的 A72 单点风险提供**可检验的修复条件**，而非无条件保证。
- **命题 1（安全不变性）**：W_used ∈ 𝒲_safe，故无论云先验多坏，ROSE 的 WCV/Shield 仍给出 ≥ 1−α_cal 的安全概率；云先验只影响性能。
- **命题 2（双时间尺度）**：α_k ≪ η_t 且云目标光滑、方差有界时，云端迭代收敛到全局预训练目标的 O(σ + heterogeneity) 邻域；异质性是云先验误差的下界来源（已声明缝隙）。

## 2. 形式化定义（完整版）

**定义 185（云边预训练进化闭环 CAPE）** CAPE 是 ROSE 的跨层升级，由九个组件与一个证书组成。其核心不变式有三条：
1. **控制权在边缘**：云端不发送 K、不发送动作、不直接写实时流；只发布版本化提示 H_k 与全局物理后验。
2. **安全在边缘**：任何云先验必须经过 CPG 投影到 𝒲_safe 后才能进入 ROSE 的 WCV/Shield，因此云先验的良莠只改变性能，不改变安全机制。
3. **学习分层**：云端慢时间尺度做持续预训练与聚合（分钟级），边缘快时间尺度做 OLCP/PTA（语义步级），实时流零学习写操作（微秒级）。

**定义 186（分层预训练先验 HPP）** 云端在机队全局场景分布 D^g 上预训练 θ^c = (θ_bb, W^g, ψ^g)：θ_bb 为跨本体可复用的语义-物理骨干，W^g 为全局投影先验（OLP 的初始/中心参数），ψ^g 为动力学与世界模型先验。边缘 i 只持有 θ_bb 的冻结副本、低秩 LoRA A_i 与本地投影 W_i ∈ ℝ^{m×d_out}。参数划分 π: {θ_bb, A, W, ψ} → {cloud, shared, edge} 由 CLA 选择，且 𝒲 的区间算术校验（ROSE A71）保证 K_{W_i}(x) ∈ 𝒦。**预训练不是一次性动作，而是以 ACP 为算子的持续过程**。

**定义 187（云先验提示与预测误差）** 云端在第 k 个云周期（每 T_c 语义步）发布 H_k = (W^g_k, M_k)，其中 M_k 是全局鲁棒损失在 W^g_k 处的期望梯度。边缘 t 时刻只能读到最新已同步版本 κ(t)，故有效提示是陈旧的 M_{κ(t)}，滞后 τ_t = t − κ(t)T_c。预测误差 ε_t = g_t − M_{κ(t)} 同时包含「云端先验本身不准」（ε_hint）与「从发布到使用期间世界变了」（L_drift·τ_t）两部分。Ē_T = (1/T)Σ‖ε_t‖² 是边缘可在线估计的量（用梯度延迟差分近似）。

**定义 188（OLCP 乐观在线投影学习）** OLCP 用乐观 FTRL 而非普通 OGD：
W_t = argmin_{W∈𝒲} { ⟨S_{t−1} + M_{κ(t)}, W⟩ + (1/(2η_t))‖W‖² },  S_{t−1} = Σ_{s<t} g_s.
其含义：在遗憾最小化时**预先相信云端提示**，只在实际梯度与提示的「惊讶」上付代价。带拒绝门控时令 M̃_t = M_{κ(t)}·𝟙[ρ̂_t ≥ ρ_min 且 Â_t > 0]，其中 Â_t 为对齐统计量的 EWMA；拒绝后 M̃_t = 0，退化为 ROSE 的普通 OLP。η_t 可按 D/√(Σ_{s≤t}‖g_s − M̃_s‖²) 自适应。

**定义 189（异步云预训练 ACP）** 每个云周期 k，参与集 S_k（由 CLA 与在线状态决定，允许子集与掉队）上传本地适配器增量 ΔA_i、投影梯度或物理后验草图。云端按陈旧度 w_i ∝ exp(−λ_s τ_i) 与鲁棒聚合 Agg（坐标中位数/截尾均值）计算全局更新：
θ^c_{k+1} = θ^c_k − α_k · Agg_{i∈S_k}{ w_i · ∇ℓ_pretrain(θ^c_k; D_i ∪ Bank^g) }.
双时间尺度要求 α_k ≪ η_t（云慢边快）；θ^c 的版本号单调，边缘按版本号与 checksum 校验。全局预训练目标包含三项：多步动力学预测、跨本体对比对齐、场景生成似然。

**定义 190（联邦可辨识残差校准 FIR）** 设边缘 i 的执行残差在局部线性化下为 r_i = J_i Δφ + b_i + ε_i，其中 b_i 为未建模动力学。单机 J_i 秩亏时 Δφ 不可辨识。云端堆叠 J = [J_i]_{i∈S}；若 rank(J) = d_φ（**集体可辨识**），则全局加权最小二乘解 Δφ̂ = (JᵀWJ)⁺JᵀWr（W 由各边缘噪声与陈旧度决定）。边缘将全局后验 N(φ̂_g, Σ_g) 与本地 N(φ̂_i, Σ_i) 用协方差交叉融合：
Σ_f⁻¹ = Σ_i⁻¹ + Σ_g⁻¹,  φ̂_f = Σ_f(Σ_i⁻¹φ̂_i + Σ_g⁻¹φ̂_g),  r_i^f = √(λ_max(Σ_f)·χ²_{d,1−α}).
融合前做 Mahalanobis 冲突检验：d_M² = (φ̂_i − φ̂_g)ᵀ(Σ_i+Σ_g)⁻¹(φ̂_i − φ̂_g)。若 d_M² > χ²_{d,1−α_c}，判为「未建模动力学」并执行 r ← r·(1+γ) 膨胀，而不是盲目采信全局值；若 σ_min(J) < σ_min^thr，则不执行全局校正，仅记录不可辨识告警。

**定义 191（全局场景银行与生成式预训练 GSB）** 边缘只上传隐私化签名 sig_s = LSH(DP(V_s, T_s, φ_s))，云端维护 Bank^g = {(sig_s, meta_s)} 并按签名聚类。云端在 Bank^g 上持续预训练生成式世界模型 g_ψ（条件于签名生成多模态观测与动力学），并用它合成复合场景（材质+湿滑+动态障碍）作为 E215 的课程来源。生成模型经蒸馏得到边缘可执行的小采样器，边缘无需上传原始视觉/触觉数据。全局覆盖度 Cov(Bank^g) 作为先验质量的代理：覆盖度低时，OLCP 自动降低对提示的信任（ρ_min 上调）。

**定义 192（云先验守卫 CPG）** CPG 是「云先验进入边缘」的唯一闸门。给定云先验 W_cloud 与本地当前 W_t：
W_used = P_{𝒲_safe ∩ B(W_t, ρ_trust)}(W_cloud),
其中 𝒲_safe 为 ROSE 的安全参数域，B(W_t, ρ_trust) 为可信域。随后做二假设检验：
- H_prior（先验错了）：对齐统计量 Â_t 持续为负且显著（云建议方向与本地真实梯度相反）；
- H_drift（环境漂移了）：Â_t 为正但本地损失持续上升（云方向对，但世界变了）。
用 anytime-valid e-value 累积证据，控制误拒率；H_prior 成立则拒绝先验并回退本地，H_drift 成立则保留先验并提高 PTA/OLCP 学习率。**该检验只影响是否采纳先验，不影响 ROSE 的安全算子。**

**定义 193（通信感知分层卸载 CLA）** CLA 在「分层卸载」而非「本地推理模式」上做在线决策。臂 a ∈ {local, adapter-sync, full-cloud, distill, hybrid}：local 表示完全边缘；adapter-sync 只同步 LoRA/低秩 W；full-cloud 做完整云预训练并回传；distill 让云端把大模型蒸馏成边缘小模型；hybrid 按层划分 π 组合。观测链路状态 z_t = (latency, bandwidth, cloud_load, packet_loss)，奖励
r_t = progress_t − λ_c·cost_comm(a_t, z_t) − λ_s·stale_risk(a_t, τ_t),
其中 stale_risk 用 OLCP 的预测误差估计。反馈延迟 d_t，故采用延迟反馈 EXP3 / 睡眠老虎机；ROSE 的 PCE+++++ 硬降级规则作为**安全下界**：任何臂不得突破硬规则给定的最低可用模式。

**定义 194（边缘测试时预训练 PTA）** PTA 在两个云周期之间用无标签边端流持续预训练：
L_PTA = L_ssl + λ_con·L_consistency + λ_F·EWC,
L_ssl = 掩码物理状态预测（随机遮蔽关节角/速度/接触力并重建）+ 时序对比（同轨迹相邻帧为正、跨轨迹为负）；L_consistency = 多视图（视觉/触觉/本体）与多步动力学一致性；EWC 以 Fisher 对角代理约束 A_i 不遗忘。PTA 只更新 A_i 与轻量预测头，**永不更新 WCV/Shield 所依赖的安全参数**。PTA 使「预训练」在边缘也持续发生，而不是只依赖云端下发。

**定义 195（CAPE 证书 J_cape）** J_cape = (J_rose, hint_ver, τ_t, Ê_T, partition_arm, σ_min(J), prior_accept, pta_ver)。
验证规则：
Valid(J_cape) ⇔ Valid(J_rose) ∧ (prior_accept ∨ τ_t ≥ τ_max 时已回退到本地先验)
∧ (σ_min(J) ≥ σ_min^thr ∨ 已执行球膨胀或声明不可辨识)
∧ anchor_fresh ∧ hint_ver 与 EWC/adapter 版本一致。
审计链把「用了哪个云版本、旧了多少、预测误差多大、选了哪个卸载臂、机队是否可辨识、先验是否被接受、边缘适配到第几版」全部落盘，使跨层责任可追溯。

**定义 196（CAPE 闭环算子）** CAPE 的三层时间尺度：
- **实时流（1–10kHz）**：只做 ROSE 的锚点原子读、OLP 前向、WCV 编译、Shield 执行、派发——**零学习写、零网络阻塞**。
- **边缘语义流（10–100Hz）**：PTA → OLCP 更新 → CPG 先验守卫 → FIR 本地融合 → ROSE 的 RSC/SBR/SHC/OCB。
- **云端异步流（分钟级）**：ACP 聚合 → GSB 生成式预训练 → FIR 全局后验 → 发布版本化提示 H_k。
三层通过「版本化提示 + 隐私签名 + 物理后验」三种消息异步耦合，任何一层失效时其余两层按预定义降级策略运行。

### IP-195 OLCP（乐观在线投影学习 + 提示门控）

```python
class OptimisticOLP:
    def __init__(self, W0, D=1.0, rho_min=0.1):
        self.W, self.D, self.rho_min = W0.copy(), D, rho_min
        self.S = np.zeros_like(W0)            # 累计真实梯度 S_{t-1}
        self.surprise_sq = 0.0                # Σ‖g_s − M_s‖²
        self.align_ema = 0.0                  # Â_t（提示-梯度对齐，仅用历史）

    def gate(self, M):
        """因果门控：只依据历史对齐 Â_{t-1}，不偷看当前梯度 g_t。"""
        if M is None or np.linalg.norm(M) < 1e-9:
            return np.zeros_like(self.W)
        return M if (self.align_ema > self.rho_min) else np.zeros_like(M)

    def step(self, g, M_raw):
        M = self.gate(M_raw)                   # 用 Â_{t-1} 决定是否采纳
        self.surprise_sq += float(np.sum((g - M) ** 2))
        eta = self.D / np.sqrt(self.surprise_sq + 1e-12)
        # W_t = argmin ⟨S_{t-1}+M, W⟩ + ‖W‖²/(2η) => Π_𝒲(−η(S_{t-1}+M))
        self.W = project_convex(-eta * (self.S + M), self.D)
        self.S += g                            # 观测 g_t 后再更新累计梯度
        self.observe_alignment(g, M_raw)       # 更新 Â_t（供下一步门控）
        return self.W, np.sqrt(self.surprise_sq)

    def observe_alignment(self, g, M):
        if M is None or np.linalg.norm(M) < 1e-9:
            return
        a = float(np.dot(g, M) / (np.linalg.norm(g) * np.linalg.norm(M) + 1e-12))
        self.align_ema = 0.9 * self.align_ema + 0.1 * a
```

### IP-197 FIR（联邦可辨识残差校准）

```python
def fir_fuse(local, glob, alpha_cal=0.05, sigma_min_thr=1e-3,
             conflict_chi2=None):
    """local = (phi_i, Sigma_i, J_i); glob = (phi_g, Sigma_g, J_stack, r_stack)."""
    J = glob.J_stack
    sigma_min = np.linalg.svd(J, compute_uv=False)[-1]
    if sigma_min < sigma_min_thr:              # 机队也不可辨识：只膨胀不校正
        return local.phi_i, inflate(local.Sigma_i, gamma=0.5), sigma_min, False

    # 全局加权最小二乘（W 由各边缘精度与陈旧度构成）
    W = glob.weights
    dphi = np.linalg.pinv(J.T @ W @ J) @ (J.T @ W @ glob.r_stack)
    phi_g = glob.phi_prior + dphi

    # 冲突检验：未建模动力学 vs 真实偏差
    dM2 = (local.phi_i - phi_g) @ np.linalg.inv(local.Sigma_i + glob.Sigma_g) \
          @ (local.phi_i - phi_g)
    if dM2 > (conflict_chi2 or chi2_ppf(0.95, len(phi_g))):
        return local.phi_i, inflate(local.Sigma_i, gamma=0.5), sigma_min, False

    # 协方差交叉融合
    Sigma_f = np.linalg.inv(np.linalg.inv(local.Sigma_i)
                            + np.linalg.inv(glob.Sigma_g))
    phi_f = Sigma_f @ (np.linalg.inv(local.Sigma_i) @ local.phi_i
                       + np.linalg.inv(glob.Sigma_g) @ phi_g)
    r_f = np.sqrt(np.linalg.eigvalsh(Sigma_f).max()
                  * chi2_ppf(1-alpha_cal, len(phi_f)))
    return phi_f, r_f, sigma_min, True          # 第三返回值写入 J_cape
```

### IP-199 CPG（云先验守卫与二假设检验）

```python
class CloudPriorGuard:
    def __init__(self, rho_trust=0.2, rho_min=0.1):
        self.rho_trust, self.rho_min = rho_trust, rho_min
        self.log_e_prior, self.log_e_drift = 0.0, 0.0      # anytime-valid 证据

    def guard(self, W_cloud, W_local, W_safe, g_t, M_t, loss_delta):
        if M_t is None:
            return W_local, False
        a = float(np.dot(g_t, M_t) /
                  (np.linalg.norm(g_t) * np.linalg.norm(M_t) + 1e-12))
        # 二假设证据累积（简化 e-value）
        self.log_e_prior += max(0.0, -a) * np.linalg.norm(g_t)
        self.log_e_drift += max(0.0, loss_delta) * (a > 0)

        W_used = project_convex(W_cloud, radius=self.rho_trust, center=W_local)
        W_used = project_safe(W_used, W_safe)              # 安全域硬投影
        prior_bad = self.log_e_prior > np.log(1 / self.rho_min)
        drift = self.log_e_drift > np.log(1 / self.rho_min)
        if prior_bad:
            return W_local, False                          # 拒绝先验，回退本地
        if drift:
            raise SignalDrift()                            # 保留先验，调高学习率
        return W_used, True
```

### IP-200 CLA（通信感知分层卸载）

```python
class CommAwareOffloader:                                  # 延迟反馈 EXP3
    ARMS = ('local', 'adapter-sync', 'full-cloud', 'distill', 'hybrid')

    def __init__(self, K=5, eta=0.2):
        self.w = np.ones(K) / K; self.eta = eta; self.K = K
        self.pending = deque()                             # (arm, due_t)

    def choose(self, link_state):
        avail = [i for i, a in enumerate(self.ARMS) if self._available(a, link_state)]
        if not avail:
            return 'local'                                  # 断网硬降级
        p = self.w[avail] / self.w[avail].sum()
        return self.ARMS[int(np.random.choice(avail, p=p))]

    def update_delayed(self, t, progress, cost, stale_risk, lam_c, lam_s):
        self.pending.append((t, progress, cost, stale_risk))  # 等反馈到齐再更新
        while self.pending and self.pending[0][0] <= t - D_MAX:
            _, p, c, s = self.pending.popleft()
            reward = np.clip(p - lam_c * c - lam_s * s, 0, 1)
            self._exp3_update(arm=self._last_arm, reward=reward)

    def _exp3_update(self, arm, reward):
        i = self.ARMS.index(arm)
        r_hat = reward / max(self.w[i], 1e-9) / self.K
        self.w[i] *= np.exp(self.eta * r_hat / self.K)
        self.w /= self.w.sum()
```

### IP-201 PTA（边缘测试时预训练）

```python
def edge_test_time_pretrain(edge, stream, lam_con=0.1, lam_F=1e-2, lr=1e-4):
    """两个云周期之间，用无标签流持续预训练；只动 LoRA 与轻量头。"""
    for batch in stream:
        x, tau, views = batch
        masked = random_mask(tau, p=0.3)                   # 遮关节/速度/力
        L_ssl = mse(edge.predict(tau, masked), tau)        # 掩码物理状态预测
        L_ssl += temporal_contrastive(edge.encode(views))  # 时序对比
        L_con = multi_view_consistency(edge, views)        # 视觉-触觉-本体一致
        L_ewc = lam_F * fisher_penalty(edge.A, edge.A_prev, edge.fisher)
        loss = L_ssl + lam_con * L_con + L_ewc
        edge.A -= lr * grad(loss, edge.A)                  # 仅 LoRA
        edge.ssl_steps += 1
    return edge.A.version
```

## 4. 推导

**引理 1（乐观 FTRL 惊讶界）** 设 ℓ_t 凸、𝒲 为直径 D 的凸紧集、正则 R(W)=½‖W‖²。考虑带提示 M_t 的乐观 FTRL：
W_t = argmin_{W∈𝒲}{⟨Σ_{s<t} g_s + M_t, W⟩ + (1/(2η))‖W‖²}.
把提示视为对当前梯度的预测，标准乐观 FTRL 的惊讶界（等价地对「惊讶序列」g_t − M_t 做 FTRL，常数吸收）给出：对任意 W*∈𝒲，
Σ_t⟨g_t, W_t − W*⟩ ≤ ‖W*‖²/(2η) + (η/2)Σ_t‖g_t − M_t‖² ≤ D²/(2η) + (η/2)Σ_t‖g_t − M_t‖².
取 η = D/√(Σ_t‖g_t−M_t‖²)，得
R_T ≤ D·√(Σ_t‖g_t−M_t‖²) = D·√(T·Ē_T).
当提示完美（M_t=g_t）时 R_T ≤ D²/(2η)，取大 η 可任意小；当无提示（M_t=0）时 Ē_T ≤ G²，退化为 D·G·√T，与 ROSE 定理 1 一致。∎

**推论 1（陈旧提示的遗憾分解）** 设理想非陈旧提示 M_t* 满足 ‖g_t − M_t*‖ ≤ ε_hint，且提示随时间的漂移 L_drift-Lipschitz：‖M_t* − M_{κ(t)}‖ ≤ L_drift·τ_t。则
‖g_t − M_{κ(t)}‖ ≤ ε_hint + L_drift·τ_t,
故 R_T ≤ D·√T·(ε_hint + L_drift·τ̄)，τ̄ = (1/T)Στ_t。
读法：**通信间隔 T_c 与云端预训练质量 ε_hint 以加性方式进入遗憾**。云端预训练降低 ε_hint，但更频繁同步会增加通信代价并可能降低可用带宽；CLA 正是在这个权衡上做决策。若启用 CPG 拒绝门控（坏提示置零），则每步惊讶被截断为 min(G², (ε_hint+L_drift·τ_t)²)，于是
R_T ≤ D·√(Σ_t min(G², (ε_hint + L_drift·τ_t)²)) ≤ D·G·√T,
**永不劣于单机 ROSE**。∎

**定理 2（先验迁移与冷启动收益）** 设边缘 i 的局部最优为 W_i*，云先验为 W^g，Δ_i = ‖W^g − W_i*‖。以 W^g 为中心的正则化（即 W_0 = W^g）把 OLCP 的初始项从 D²/(2η) 替换为 Δ_i²/(2η)。故前 N 步遗憾（或适应时间）满足
R_N^prior − R_N^zero ≤ (Δ_i² − D²)/(2η) + (η/2)Σ_{t≤N}‖g_t − M_t‖²,
当 Δ_i < D 时冷启动严格更优；机队任务越同质（Δ_i 越小），收益越大。取 η = Δ_i/√(Σ‖g_t−M_t‖²) 可把前 N 步遗憾压到 Δ_i·√(N·Ē_N)。∎

**定理 3（联邦可辨识性与 ROSE 单点风险的修复）** 设局部观测 r_i = J_i Δφ + b_i + ε_i，ε_i 独立次高斯（参数 σ_ε），b_i 为局部未建模偏差。单机若 rank(J_i) < d_φ，则存在 Δφ ≠ 0 使 J_i Δφ = 0，任何局部估计器的最坏误差无界。若机队堆叠 J = [J_i]_{i∈S} 满列秩且 Σ_i b_i = 0（未建模偏差在机队上零均值），则加权最小二乘估计 Δφ̂ 满足
‖Δφ̂ − Δφ‖ ≤ σ_ε·√(d_φ/λ_min(JᵀWJ)) + ‖(JᵀWJ)⁻¹JᵀWb‖.
当 b=0 时误差 ≤ σ_ε/σ_min(J)。因此 **ROSE 的 A72「J_φ 最小奇异值 ≥ σ_J」可从单机条件弱化为机队集体条件**；代价是需要跨本体上传 (J_i, r_i) 草图与可辨识指数监控。若集体也不可辨识，FIR 不强行校正，而是膨胀球并记录告警——保证「不假装知道」。∎

**命题 1（安全不变性 / 云先验不可破坏安全）** CPG 输出 W_used = P_{𝒲_safe ∩ B(W_t,ρ_trust)}(W_cloud) ∈ 𝒲_safe。ROSE 的 WCV 在 B(φ̂,r) 上最坏情形编译、Shield 投影到 𝒞_safe，均只依赖 W_used 与边缘本地先验，不依赖云端策略质量。故对任意云先验（包括对抗先验），
P[K_safe 在真实 φ* 下安全] ≥ 1 − α_cal
仍成立；云先验只改变 ρ_rob 与任务性能，不改变安全概率下界。∎

**命题 2（鲁棒聚合的投毒容忍）** 设参与集 S_k 中恶意边缘比例 < 1/2。坐标中位数聚合的 breakdown point 为 1/2，故全局梯度/先验被有界污染；结合 CPG 的可信域投影，云先验对本地 W 的影响被 ρ_trust 截断。于是即使云先验被投毒，W 仍停留在本地信任域内，安全不变性（命题 1）不受影响。∎

**命题 3（双时间尺度收敛，非正式）** 取云步长 α_k = α/(k+1)、边缘步长 η_t = η/√t，满足 Σα_k=∞、Σα_k²<∞、η_t/α_k → 0（快慢分离）。在全局预训练目标 L-smooth、梯度方差有界、异质度有界的标准假设下，云端迭代收敛到 L 的 O(σ + heterogeneity) 邻域；异质度是云先验误差 ε_hint 的下界来源。该命题只保证收敛到邻域，不保证零误差——这是 CAPE 的固有理论缝隙（见第 7 节）。∎

**命题 4（断云优雅退化）** 当云不可达（CLA 选择 local 或 τ_t ≥ τ_max）时，H 失效，OLCP 的 M̃_t = 0，退化为 ROSE 的 OLP；CPG 返回 W_local；FIR 只做本地 RSC 或膨胀球；J_cape 的 prior_accept=false 且记录 τ_t。此时 CAPE 的界退化为 ROSE 的单机界，安全不变性（命题 1）仍成立。∎

6. **通信自适应**：CLA 在带宽/时延非平稳下给出延迟反馈遗憾界，且受 ROSE 硬降级阶梯约束；断云时优雅退化为本地 ROSE（命题 4）。
7. **实时性不变**：实时路径零学习写、零网络阻塞，≤1ms 契约与 ROSE 完全一致。

## 7. 已知风险

**一句话**：云先验的预测误差在边缘**不可直接观测**——若异质本体、陈旧同步与环境漂移使云先验系统性失配，而本地又无法区分「先验错了」与「环境变了」，CPG 可能锁死坏先验或频繁丢弃好先验，于是 OLCP 的遗憾保证与 CPG 的安全不变性同时退化为纸面结论。

**次级风险与缓解**：
1. **负迁移 / 异质本体**：云先验在差异大的本体上可能比从零更差 → CPG 可信域 + 对齐门控硬拒绝；OLCP 的 min(G²,·) 截断保证不劣于单机；E211/E216 专项检验。
2. **CPG 二假设不可分**：先验错与环境漂移在有限样本下可能混淆 → 用 anytime-valid e-value 控制误判，并保留「不确定时回退本地 + 膨胀球」的第三条安全路径；监控误拒率与漏拒率。
3. **FIR 的未建模偏差假设**：b_i 零均值/可界若不成立，全局校正会被局部未建模动力学污染 → Mahalanobis 冲突检验 + σ_min 门控 + 不可辨识时只膨胀不校正；E214 注入非零均值 b_i 做压力测试。
4. **通信延迟与版本乱序**：异步聚合可能用到旧版本 → hint_ver/checksum 单调校验；ACP 陈旧度加权；CLA 延迟反馈；τ_max 强制回退。
5. **隐私与投毒的对偶**：签名可能泄露/被投毒 → DP + LSH；鲁棒聚合 breakdown 1/2；CPG 截断云先验影响；隐私预算 ε_dp 与先验质量的权衡需在 E215/E216 联合评估。
6. **PTA 与 OLCP 双学习耦合**：无标签自监督与有标签遗憾学习可能互相追逐 → 交替更新（奇偶步分离）+ EWC + 安全参数冻结；监控 surprise 序列是否出现振荡。
7. **双时间尺度的非平稳性**：α_k ≪ η_t 在非平稳环境中可能过慢 → 云端设置漂移检测触发「快进」临时增大 α_k；此时命题 3 的邻域界变松，需在 J_cape 中记录。
