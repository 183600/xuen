# 第 44 轮（新循环第 4 轮） · Fusion-Cert × Latency-Cert：把「跨模态一致性」与「推理尾延迟」纳入可验证证书闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形仅边际覆盖 + 多用户契约求交可空」，但它仍压着两个更靠上游、更致命的单点假设：**(H7) 融合算子可信且各模态彼此一致**——v20 的 TRI-FUSE 输出 C_ms+B_t+L_m 后，几何/人格/并发证书都默认这个融合结果是「真值 + 有界噪声」，却从未认证**跨模态是否在说同一件事**：一个错帧、错外参、标定漂移或被投毒的模态，可以在所有下游证书仍「相对正确」的情况下，把整条链拖向一个**共同错误**；**(H8) 延迟是一个有界标量、anytime 单调**——v20 的租约 ℓ=(m,τ,λ,κ) 只有一个时间原点，隐含所有模态同时到达；真实多模态栈的延迟是**重尾、异质、异步**的，融合发生在「快模态的现在 + 慢模态的过去」拼出的不一致快照上，而且等得更久未必更好：慢模态变准的同时，整个融合证书因滞后而变旧。本轮灵感词「多模态融合」「推理延迟」精确命中这两点：**多模态融合**迫使我们把融合从「算子」提升为「带共识秩与冲突见证的证书」；**推理延迟**迫使我们把延迟从「工程指标」提升为「分布级证书 + 因果一致快照」，并承认融合的新鲜度由**最慢模态**决定。二者耦合处是本轮真正的新问题：**一致性与新鲜度互为前提**——判断一致性需要可信时间戳，而时间戳由可能被延迟/欺骗的模态驱动提供；「一致但共同错误」与「新鲜但已过时」会同时骗过两条闸门。

## 0. 直觉与动机

**灵感 1（多模态融合 → 融合不是平均，而是一个可证伪的集合投票）**：直觉上，融合像「取平均」，更多模态 = 更准。但平均对**共同错误**毫无防御：三个模态若因同一块标定错误、同一次时间戳错位而一起偏，平均只会把错误「平均得更自信」。真正的可验证融合必须是**集合投票**：每个模态给出一个「真值必在其中」的集合 X_i（含协方差、外参误差、运动膨胀），融合输出「至少 n−f 个模态都覆盖」的区域 X_f。这样只需假设「至多 f 个模态坏」，无需知道谁坏；X_f 非空即证书成立，为空则输出**最小冲突见证**（minimal infeasible subset）而非硬融。一句话：**融合的产出不是点估计，而是一个带故障预算的包含性证明。**

**灵感 2（推理延迟 → 延迟不是标量，是尾分布 + 一条会被穿越的因果边界）**：直觉上「推理慢」只是 p99 变大。但在异步多模态里，延迟真正的杀伤是**时间对齐**：你拿到的是 t_i 时刻的快照，用它做 t 时刻的决策，中间隔着的 a_i=t−t_i 内世界已移动 L_x v_max a_i。于是每条证据都必须带年龄，且有效集要按年龄膨胀。更反直觉的是 **anytime 在跨模态融合下不单调**：多等 Δ 让慢模态更准，却让它的年龄增加 Δ、整个融合半径增加 L_x v_max Δ；超过拐点后「等」反而使证书更差。因此存在**最优停止时刻**，而不是「算得越久越好」。再进一步，融合快照的新鲜度由**最慢模态**决定（滞后税 A=max_i a_i），不是平均值；一条很慢但很准的模态可能净拖累整条链。

**灵感 3（耦合 → 一致性与新鲜度互为前提，必须联合认证）**：要判「两个模态是否在描述同一时刻的同一世界」，需要可信时间戳与因果一致的快照；而时间戳来自驱动/固件，恰恰可能被重放、伪造成「新鲜」。反过来，只判新鲜不判一致，会放过「刚采到的错误帧」；只判一致不判新鲜，会放过「三个模态一起复读昨天的世界」。因此定义**联合证书**：既要共识秩 f_break 足够、冲突见证为空，又要最老模态年龄 A≤A_max、尾延迟违约概率≤δ；并强调 **No self-attestation of time**——时间必须由独立单调计数器/attestation 背书，否则「新鲜」是自证循环。

**耦合升级**：CFE（认证融合引擎）把每个模态编译成带外参/年龄膨胀的有效集，做 n−f 共识融合并给出冲突见证；LCR（延迟证书运行时）维护逐模态尾延迟证书、水位线与因果快照，按「滞后税」做证书感知的模态调度与最优停止；FLV（融合-延迟验证器）注入错帧、漂移、时间欺骗、重放与尾延迟尖峰，联合压测两条闸门。四层架构由 v8 的「人格契约层 + 并发证书层」升级为 v9：在感知入口下插一个**证据/时间根平面**，让所有上层证书第一次拥有「跨模态包含性 + 因果新鲜度」的双重地基。

## 1. 形式化定义（增量：定义 44–50）

**定义 44（模态证据与逐模态包含集）**：模态 i∈M={1..n} 在采集时刻 t_i 产生证据 e_i=(x_i,Σ_i,t_i,π_i)，π_i 为来源（标定 id、帧 id、驱动/固件版本、签名）。外参 T_i 带认证误差 ε_extr,i。在决策时刻 t（要求 t≥t_i，否则判为时间欺骗并拒收），年龄 a_i=t−t_i，逐模态包含集
X_i(t) = {x : (x−T_i x_i)ᵀΣ_i⁻¹(x−T_i x_i) ≤ 1} ⊕ Ball(ε_extr,i) ⊕ Ball(L_x v_max a_i)。
**命题**：若传感器模型 sound、外参误差有界、状态位移满足 ||x(t)−x(t_i)||≤L_x v_max a_i，则真实 x(t)∈X_i(t)。**推论**：X_i 同时编码「噪声」「外参」「迟到」三种不确定性，任一模态的失败模式都不能被其他模态的精度「抵消」。

**定义 45（n−f 共识融合与冲突见证）**：设至多 f 个模态 Byzantine，诚实模态满足真值∈X_i。定义共识融合集
X_f(t) = {x : |{i∈M : x∈X_i(t)}| ≥ n−f} = ⋃_{S⊆M,|S|=n−f} ⋂_{i∈S} X_i(t)。
**定理（包含性）**：诚实集 H 满足 |H|≥n−f 且真值∈⋂_{i∈H}X_i⊆X_f，故真值∈X_f，即 X_f 是 sound 的过近似。**紧性**：X_f 之外的点至多被 n−f−1 个模态覆盖，与「补集恰为 f 个 Byzantine」一致，故无法被认证——X_f 是最大可认证区域。**冲突见证**：若 X_f=∅，输出最小不可行子集 MIS（去掉其中任一模态即可非空的冲突核），作为协商/降级的可解释依据，而非静默硬融。**可计算性**：精确 X_f 需枚举子集；用逐坐标 Marzullo 算法得到外近似盒 X_f^box=∏_j Marzullo_j(f)，其满足 X_f⊆X_f^box（因每个含 x 的模态在每一维投影也含 x_j），O(d·n log n) 且 sound，仅损失相关性带来的紧致度。

**定义 46（时间对齐、因果快照与滞后税）**：融合快照的「as-of」时刻 t_f=min_{i∈S} t_i，有效年龄 A(S,t)=max_{i∈S}(t−t_i)。**滞后税命题**：任何使用模态集 S 的融合，其包含集半径至少含 L_x v_max·A(S,t) 项；特别地，加入一个年龄为 a_j 的慢模态会把整条链的新鲜度下界拉到 a_j，即使它对精度有贡献。**因果一致快照**：要求存在向量时钟 v 使所选证据满足 v_i≤v（无未来证据、无跨流因果倒置），且水位线 w(t)=min_i t_i 单调不减；任何 t_i>t 或水位线回退都判为时钟异常并降级。

**定义 47（尾延迟证书与分布漂移）**：延迟 L_i 为随机变量。用 anytime-valid e-process/置信序列（Ville 不等式）给出在时刻 t 一致成立的尾界 D_i^δ(t)：P(L_i>D_i^δ(t))≤δ（对负载漂移用 change-detection 重置，而非假设可交换）。融合延迟 L_fuse=max_{i∈S}L_i（barrier 同步），**并集界**：P(L_fuse>D)≤Σ_{i∈S}P(L_i>D)≤Σ_i δ_i（不要求独立）。**命题**：给定总违约预算 δ_req，δ_i 的最优分配是按尾指数/代价的注水（water-filling）；硬实时路径仍以静态 WCET 兜底，经验尾界只用于标称模式与预算规划。

**定义 48（融合-延迟联合证书与可用谓词）**：联合证书 C=(X_f, f_break, A, D^δ, δ, clock_ok)，其中 f_break=max{f:X_f≠∅} 为共识秩（可容忍故障数）。**可用谓词**：usable(C) ⇔ X_f≠∅ ∧ f_break≥f_req ∧ A≤A_max ∧ P(L_fuse>D)≤δ_req ∧ clock_ok。**联合 sound 定理**：若定义 44 命题成立、诚实模态≥n−f、时钟单调且 A 有界，则 x_true(t)∈X_f(t)，且任何以 center(X_f) 与 rad(X_f) 为 margin 的守卫（IP-51）仍 sound；其误差上界
rad(X_f) ≤ rad_consensus(f) + L_x v_max A + ε_extr + ε_tail，
其中 ε_tail 由尾延迟违约时的保守膨胀给出。**推论**：v20 的标量租约是「n=f=1、A 用单一 τ」的退化特例，本定义把租约向量化并与共识秩耦合。

**定义 49（证书感知的模态调度与最优停止）**：选择 S⊆M 与截止期 D，最大化 U(S)=V(X_f(S))−μ·A(S,t)−ν·Σ_{i∈S}D_i^δ，约束 usable(C(S))。**边际判据**：只有当模态 j 的精度增益 ΔV_j 超过其引入的滞后税 L_x v_max·max(0,a_j−A(S)) 与尾预算成本时，才纳入 S。**非单调 anytime 命题**：若等待慢模态 Δ 使其协方差从 Σ 收缩为 Σ(Δ)、年龄增至 a_j+Δ，则净增益 G(Δ)=rad(Σ(Δ))−L_x v_max·Δ 在超过拐点 Δ* 后满足 G'(Δ)<0；因此存在最优停止时刻，超过后「再等」会使联合证书严格变差。**推论**：anytime 的单调性只在单模态内成立，跨模态融合必须在 Δ* 处主动停止并签发带时间戳的 best-so-far 证书。

**定义 50（模态降级阶梯与单调性）**：降级阶梯 L0(全模态共识)→L1(剔除低信任/冲突模态)→L2(剔除慢模态以缩短 A)→L3(单最可信模态+保守膨胀)→L4(安全保持/停机)。**定理（单调降级安全）**：每一级只删除模态、只增大包含集（X^{r+1}⊇X^r）且只收紧可用谓词，故任意级与任意切换点上 X_f 仍包含真值，守卫不会因降级而不 sound，只会变保守。**调度耦合**：与定义 42 的混合关键级一致——HI 模式优先保留 κ≥geometry 且低年龄的模态，砍个性化/投机；退化路径与模式切换共用「只删不增」不变式。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 CERTIFIED-FUSION-ENGINE（认证融合引擎 CFE）
1. **证据编译**：每模态 →(X_i, a_i, π_i)，做外参误差与运动膨胀；拒收 t_i>t、来源缺失、年龄超限的证据。
2. **n−f 共识融合**：Marzullo 外近似 + 精确/离线紧化双轨；输出 X_f、共识秩 f_break、MIS 冲突见证。
3. **一致性证书**：覆盖「逐对/逐坐标冲突」与「共同错误检测」——当所有模态高置信但彼此偏移超过膨胀界时，优先怀疑共同外参/时间基准而非单模态。
4. **可解释输出**：非空 → 给守卫；空 → 给「最小让步集/降级建议」，绝不硬融。

### 2.2 IP-61 LATENCY-CERT-RUNTIME（延迟证书运行时 LCR）
1. **逐模态尾延迟证书**：e-process/置信序列 + 漂移检测，输出 D_i^δ(t)，并维护未过期证书的缓存。
2. **因果快照与水位线**：向量时钟/水位线单调检查；拒绝未来时间戳与因果倒置；快照原子化。
3. **证书感知调度 + 最优停止**：按定义 49 的边际判据选模态、在 Δ* 停止；δ_i 注水分配；HI 模式保留低年龄关键模态。
4. **租约向量化**：把定义 41 的标量 ℓ 扩展为逐模态 ℓ_i，并向上层签发「融合租约」ℓ_fuse=(X_f,f_break,A,D^δ,κ)。

### 2.3 IP-62 FUSION-LATENCY-VALIDATOR（融合-延迟验证器 FLV）
1. **模态对抗注入**：错帧、外参/标定漂移、时间戳伪造、重放、慢模态、突发尾延迟、时钟回拨。
2. **时间因果审计**：水位线回退、未来证据、因果倒置、快照撕裂的检测。
3. **联合压测**：f 个 Byzantine 模态 × 尾延迟尖峰 × 时钟异常同时发生，验证 f_break 与 δ 的联合界不被击穿。
4. **反例回灌**：失败签名（共同外参错误、时间欺骗模式）入 CKB/SCV，驱动课程与回归。

    ← IP-62 FLV(错帧/漂移/时间欺骗/重放/尾延迟) + IP-54 SCV(异步多模态仿真)

## 2. 关键算法（伪代码）

### IP-60 CFE：证据编译、n−f 共识与冲突见证
```
def compile_evidence(mod_i, x_i, Sigma_i, t_i, t, prov):
    if t_i > t:                       # 未来时间戳 => 时间欺骗
        return None, 'future_ts'
    if not prov.attested():           # 来源/签名缺失 => 不可认证
        return None, 'unattested'
    a = t - t_i
    if a > A_max:
        return None, 'too_old'
    X = ellipsoid(x_i, Sigma_i) \
        + Ball(eps_extr[mod_i]) \
        + Ball(L_x * v_max * a)       # 定义 44：噪声+外参+迟到
    return Evidence(X=X, age=a, prov=prov), None

def marzullo_1d(intervals, f):
    # 返回被 >= n-f 个区间覆盖的部分（一维精确）
    events = []
    for (lo, hi) in intervals:
        events += [(lo, +1), (hi, -1)]
    events.sort(key=lambda e: (e[0], -e[1]))   # 同点先加后减
    need = len(intervals) - f
    cnt, segs, start = 0, [], None
    for pos, delta in events:
        prev = cnt
        cnt += delta
        if prev < need <= cnt and start is None:
            start = pos
        elif prev >= need > cnt and start is not None:
            segs.append((start, pos)); start = None
    return hull(segs)                  # 可能多段；取外包保证 sound

def consensus_box(evs, f):
    n = len(evs)
    if n - f <= 0:
        return None
    box = []
    for j in range(d):                 # 逐坐标投影
        seg = marzullo_1d([(lo(ev.X,j), hi(ev.X,j)) for ev in evs], f)
        if seg is None:
            return None
        box.append(seg)
    return Box(box)                    # 定理：X_f ⊆ X_f^box

def certified_fusion(evs, f_req):
    Xf = consensus_box(evs, f_req)
    if Xf is None:
        return None, mis_witness(evs, f_req)      # 冲突见证，不硬融
    # X_f 关于 f 单调不减 => 二分求共识秩
    f_break = binary_search_max_f(lambda f: consensus_box(evs, f) is not None,
                                  hi=len(evs))
    A = max(ev.age for ev in evs)
    return FusionCert(Xf, f_break, A), None
```

### IP-61 LCR：尾延迟证书、因果快照、最优停止
```
def latency_cert(stream_i, delta_i, t):
    # anytime-valid 上分位（e-process / 置信序列），对漂移做 change-detection
    if stream_i.detect_shift(t):
        stream_i.reset_calibration(t)          # 不假设跨漂移可交换
    return stream_i.upper_quantile(1 - delta_i, t)   # D_i^δ(t)

def causal_snapshot(states, t):
    if any(s.t > t for s in states):
        return None, 'future_ts'
    vc = merge_vector_clocks([s.vc for s in states])
    if not causally_consistent(states, vc):
        return None, 'inconsistent_cut'
    if w(t) < w(t - 1):                        # 水位线回退
        return None, 'clock_rollback'
    return states, vc

def fuse_latency_bound(S, deltas):
    # L_fuse = max_i L_i，并集界 P(L_fuse>D) <= sum_i delta_i
    return sum(deltas[i] for i in S)

def choose_modalities(S, t, deltas):
    while len(S) > 1:
        A = max(age(i, t) for i in S)
        worst = min(S, key=lambda j: gain(j) - L_x*v_max*max(0, age(j,t)-A)
                                       - cost_tail(j, deltas))
        marginal = gain(worst) - L_x*v_max*max(0, age(worst,t)-A) \
                   - cost_tail(worst, deltas)
        if marginal >= 0:
            break                              # 定义 49 边际判据
        S.remove(worst)                        # 剔除慢/低增益模态
    return S

def anytime_fuse(S, t, horizon):
    best = fusion(S, t, age_cost=True)
    for dt in horizon:                         # 非单调：超过 Δ* 停止
        cand = fusion(S, t + dt, age_cost=True)
        if radius(cand) + L_x*v_max*dt < radius(best):
            best = cand
        else:
            break                              # Δ* 已过，再等更差
    return best                                # 带时间戳的 best-so-far 证书
```

def degrade(cert, reason):
    if reason == 'conflict':      # L1：剔除冲突/低信任模态
        return refusion(drop=mis_witness(cert.evs, cert.f_req))
    if reason == 'too_old':       # L2：剔除慢模态，缩短 A
        return refusion(drop=slowest(cert.evs))
