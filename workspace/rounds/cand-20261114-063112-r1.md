# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS」IP-287~294；灵感循环第 1 轮；本轮灵感：「推理延迟」×「快速原型」）

> R72 把 GAUGE 下沉到具身实时执行图（REG）、意图隐变量（IRL）、灵巧接触计量（DMEM）、三层反作用（EREFLEX）与 sim2real 桥接（S2R-UQ），并用 J_EMB 把「调度时序 + 认知计量」绑成一张证书。但 R72 仍隐含两个奢侈假设：
> - **推理是瞬时的**：REG 给 n_intent/n_tac 一个 deadline，却把 `b_t(s,z)` 当作「在 t 时刻就绪」的量。真实系统中，观测在 τ_obs 产生，推理在 τ_avail 完成，控制域在 t 使用的是 `b_{τ_obs}` 的一个**过期副本**。延迟 L = τ_avail − τ_obs 不是一个性能数字，而是**证据有效性的一部分**：接触模式可在一帧内从 sticking 变 sliding，意图可在数百毫秒内漂移，位姿在高速运动下迅速失效。**延迟改变证据的含义，而不只是到达时间。**
> - **原型是免费的**：R72 的实验可以「先跑起来再说」，但快速原型（小模型、合成数据、mock 传感器、桌面 GPU、Python 胶水）与部署系统之间的 **latency cliff / validity cliff / debt cliff** 没有被计量。原型里的 20ms 在 Jetson 上可能是 200ms 的 p99.9；原型里「够用」的校准在实机负载下可能失效；原型里的捷径（surrogate、缓存、降采样）会变成**安全边际上的隐性负债**。
>
> 本轮两个灵感正好补两块：
> - **推理延迟 → 易腐证据（perishable evidence）**：每条证据/后验必须携带时间戳、延迟分布、龄期、传输算子与「保质期」；过期后验必须**时间传输**到当前时刻，或显式膨胀不确定度；延迟尾部与输入相关，必须按 p99.9/对抗上界而非均值做认证。
> - **快速原型 → 原型契约与债务账本**：原型不是「小号部署」，而是一笔**以安全边际为抵押的贷款**；每次捷径都要登记 `Δrisk`、到期日、退休测试；快速迭代只在债务可偿、影子证据充分、任意时刻校准成立时被允许。
>
> 核心命题：**不仅问「我的测量链可信吗、调度能兑现吗」，还要问「当推理本身有延迟、原型本身带债时，我在 t 时刻拿到的后验是否仍然是关于 t 时刻世界的有效证据？」** 把 R72 的具身证书升级为 **FRESH-GAUGE-RAS**（Freshness-aware, Rapid-prototyped, Evidence-transported, Shadow-certified, Honest-debt GAUGE for RAS）——**易腐证据 × 原型债务的时序计量闭环**。

## 0. 直觉与动机

**灵感 1（推理延迟 → 后验是易腐品，不是快照）**
直觉：牛奶有保质期，后验也有。`b_t(s,z)` 只在它对应的观测时刻附近有效；把它原样拿到 100ms 后使用，等于把「上一帧的接触模式」当成「当前的接触模式」。更麻烦的是，不同证据的腐败速度不同：接触模式半衰期 ~10ms，意图半衰期 ~1s，物体位姿半衰期 ~100ms。**统一的 50Hz 计量频率掩盖了这种异质性。** 必须给每个通道定义**时间敏感度 σ_ch** 与**半衰期 A_half(ch)**，并让风险缩放看见「龄期」。

**灵感 2（推理延迟 → 均值是谎言，尾部才是安全）**
直觉：一个意图识别器「平均 20ms」没有意义；如果 1% 的输入让它跑 300ms（长语音、复杂手势、OOD 场景、内存压力、热降频），那 1% 就决定了机器人是否在截止时间后还拿着过期意图去抓人。延迟是**输入相关、重尾、可被对抗放大**的随机变量。认证必须用 `p99.9` 与**输入条件最坏延迟**，而不是均值或 p50。**延迟尾部是安全边界的一部分。**

**灵感 3（任意时刻推理 → 截止时刻的部分后验，胜过迟到的完美后验）**
直觉：在 1kHz 控制环里，控制域不能等一个 50ms 的完整贝叶斯更新。正确做法不是「等到算完」，而是**在截止时刻返回一个已校准的部分后验** `b^D`，并知道它的校准误差 `ECE(D)` 与决策稳定性 `ι_lat`。计算深度本身是一个**动作**：多算一层可能降低物理风险，但也推迟了动作、消耗了 deadline。**「何时停止思考」和「何时停止交互」一样，是可优化的停止问题。**

**灵感 4（快速原型 → 原型债务是安全债务，且有利息）**
直觉：快速原型之所以快，是因为它借了债：借了「合成数据代表真实分布」的债、借了「桌面 GPU 代表 Jetson」的债、借了「mock 传感器代表真实噪声」的债、借了「离线校准代表在线校准」的债。每笔债都应记 `Δrisk` 与到期日。债不会自己消失，**越晚偿还，利息越高**（分布漂移、硬件老化、依赖升级）。如果原型债务总额超过安全边际，再快的原型也不许上车。**「先上线再补测试」不是快速原型，是抵押安全。**

**灵感 5（时序追溯 → 没有时间戳的数字是裸奔的数字）**
直觉：R72 的 TCHAIN 追溯「这个数字从哪来」，但不追溯「这个数字属于哪个时刻、花了多久算出来、在什么延迟分布下仍然成立」。需要 **4D 追溯**：value + variance + timestamp + latency。任何进入风险缩放的量，若缺少 `(τ_obs, L, p_L, A, A_half)`，一律视为不可信。**时间戳不是元数据，是有效性域的一部分。**

## 1. 形式化定义（增量：定义 366–382）

**定义 366（FRESH-GAUGE-RAS 总览与六不变式）** FRESH-GAUGE-RAS = (CHRO, ANT, PROTO, DEBT, SHADOW, GAUGE-RAS†)。六不变式：
(i) **时序证据完整性**：每条证据/后验必携带 `(τ_obs, τ_avail, L, p_L, A, σ_ch, A_half, D_temp, τ_chain)`；缺一不得进入风险缩放；
(ii) **任意时刻校准**：进入决策的任意计算深度 c 的输出必须满足 `ECE(D) ≤ ε_ece`、`ι_lat ≤ ε_stab`、选择性风险 `R_sel(D) ≤ ε_sel`；
(iii) **原型契约优先**：任何快速原型必须有 PROTO 契约与 DEBT 账本，且债务膨胀后仍在安全边际内；
(iv) **计算-安全耦合**：延迟不确定度 `U_lat` 与龄期不确定度 `U_age` 同权进入 λ 与 WCET；
(v) **影子默认**：原型默认在 shadow 模式运行，未经晋升不得驱动执行器；
(vi) **严格时序退化链**：CHRO 失效 ⇒ 用预测后验 + 膨胀 λ；ANT 失效 ⇒ 退化为上一有效后验/固定先验；PROTO/DEBT 失效 ⇒ 禁止原型上车，回退 R72/R71/R68。

**定义 367（时序证据元组 CHRONO-Evidence）** 一条证据
`e = (y, τ_obs, τ_avail, L, p_L(·|x,hw,load), A, σ_ch, A_half, D_temp, τ_chain)`
其中 `L = τ_avail − τ_obs`，`A = t − τ_obs`，`p_L` 是输入/硬件/负载条件下的延迟分布（不只均值），`σ_ch = ∂ log U_age/∂A` 为通道时间敏感度，`A_half = inf{A : U_age(A) > ε_valid}` 为保质期，`D_temp = {(A,L): U_age(A)+U_lat(L) ≤ ε_valid}` 为时序有效域。**证据的新鲜度不是权重，而是有效域的门票。**

**定义 368（时间传输算子与传输包络）** 给定已知机器人动作 `a_{t−A:t}`，时间传输算子
`(T_A b)(s_t,z_t) = ∫ p(s_t,z_t | s_{t−A},z_{t−A}, a_{t−A:t}) b(s_{t−A},z_{t−A}) d(s,z)`。
真实后验与传输后验的 Wasserstein 误差满足包络
`W_1(T_A b, b_t) ≤ ε_dyn(A) + ε_model(A) + ε_lat`，
其中 `ε_dyn` 由动力学李雅普诺夫指数/收缩系数决定（稳定模式 ≤ κ^A ε_0，接触滑移等扩张模式 ≤ e^{λ_max A} ε_0），`ε_model` 为模型误差，`ε_lat` 为龄期 A 本身的不确定度。定义 **龄期不确定度** `U_age = ε_dyn + ε_model + ε_lat`。**关键：过期不是「乘以一个衰减系数」，而是「用动力学搬到现在，并把搬运误差算进风险」。**

**定义 369（延迟关键度与通道保质期）** 对通道 ch，定义延迟关键度
`κ_ch = sup_{A≤A_max} (1/U_age) · dU_age/dA`，
以及**延迟裕度** `M_ch = A_half(ch) − L_{p99.9}(ch) − L_queue(p99)`。若 `M_ch < 0`，该通道**时序不可用**。典型量级：接触 c-通道 `A_half ≈ 10–20ms`（滑移），意图 z-通道 `A_half ≈ 0.5–2s`（漂移），位姿 s-通道 `A_half ≈ 50–150ms`（高速运动）。**统一计量频率在时序上是错误的；应按保质期分配频率与计算预算。**

**定义 370（任意时刻后验与截止条件校准）** 计算深度 `c ∈ 𝒞`，成本 `L(c)`；任意时刻后验 `b^c = p(s,z | ℋ, 计算深度 c)`。给定截止 D，`b^D = b^{c*(D)}`，其中 `c*(D)` 是 D 内可完成的最深/最优深度。定义**截止条件校准剖面**
`𝒞_ant = {(D, ECE(D), ι_lat(D), R_sel(D), coverage(D))}`，
其中 `ECE(D) = E[|P(correct|conf,D) − conf|]`，`ι_lat(D) = sup_{c,c': L(c),L(c')≤D} W_1(b^c,b^{c'})` 为**延迟诱导的 gauge 间隙**，`R_sel(D)` 为选择性风险。**任意时刻可采纳** ⇔ `ECE(D) ≤ ε_ece ∧ ι_lat(D) ≤ ε_stab ∧ R_sel(D) ≤ ε_sel`。**一个只在「算完」时校准的模型，在实时系统里没有资格进入决策。**

**定义 371（计算价值 VoC 与「计算即动作」）** 给定当前后验 b、截止 D、计算深度 c，
`VoC(c | b, D) = E[ΔRisk_phys(c)] + η·ΔH_z(c) + ζ·ΔH_c(c) − α·L(c) − β·max(0, L(c) − D) − c_energy(c) − c_switch(c)`。
联合动作 `(g,c)* = argmax_{g,c} [VoI^E(g) + VoC(c|b,D)]`，满足三层稳态、时序有效域与预算约束。**最优计算深度由「边际风险下降 = 边际延迟成本」决定**；若所有 c 的 VoC ≤ 0，则立即停止计算、用当前后验或反射策略。**这把「推理延迟」从被动性能指标变成主动决策变量。**

**定义 372（原型契约 PROTO）** 一个快速原型
`Π = (π_id, pipeline, hw_target, L_profile, 𝒞_ant, D_temp, debt_ledger, monitors, expiry, signature)`，
其中 `L_profile = (p50, p99, p99.9, adversarial_max, L_queue)`，`monitors` 为运行时延迟/龄期/漂移哨兵。**可部署** ⇔
`p99.9(L) + L_queue ≤ D − slack` ∧ `𝒞_ant` 达标 ∧ `D_temp` 覆盖任务域 ∧ `Σ Δ_d ≤ margin` ∧ `expiry > now` ∧ `shadow_evidence ≥ N_min`。**原型是带到期日与签名的第一类工件，不是脚本目录。**

**定义 373（原型债务账本 DEBT 与复利）** 债务项
`d_i = (type, scope, assumption, evidence, Δrisk_i, t_i, expiry_i, retire_test_i, owner)`，
type ∈ {data, latency, hardware, calibration, abstraction, test, dependency}。未偿还债务的**风险膨胀**
`Δ_i(t) = Δ_i^0 · exp(γ_i · max(0, t − t_i))`，`Δ_total(t) = Σ_i Δ_i(t)·𝟙[¬retired_i]`。
可部署条件 `ε_base + Δ_total(t) ≤ ε_allow`。**快速迭代允许加债，但必须满足「本次新增债务 ≤ 本次偿还债务 + 剩余边际」；否则拒绝合并/部署。** 债务有复利，原型有保质期。

**定义 374（快速原型搜索与可采纳 Pareto 前沿）** 原型候选空间 𝒫，评价
`J(Π) = (R_risk(Π), L_{p99.9}(Π), coverage(Π), energy(Π), Δ_total(Π), complexity(Π))`。
**可采纳前沿** `𝒫* = Pareto{J(Π): Π 通过定义 372 与 373 的约束}`。搜索算子：`Generate`（模板/LLM 生成候选）→ `Probe`（目标硬件延迟与校准测量）→ `Counterexample`（自动生成延迟/精度/接触/意图反例）→ `Refine`（级联、早退、量化、缓存）→ `Retire`（还债）。**快速原型的目标不是「最快出 demo」，而是「最快找到可采纳前沿上的点」。**

**定义 375（时序风险缩放 T-RISK）** 在 R72 E-RISK 上加入时间不确定度：
`U_time = U_age + U_lat`，`U_lat = L_{p99.9} − L_{p50}`（或延迟分布的分位数跨度），
`λ = max( risk_scale(U_ale, U_epi, H_z, u_tac, U_time),
          λ_floor(U_ale + U_epi + H_z + u_tac + U_time) )`。
**高置信但过期的后验必须抬高 λ，而不是降低 λ。** 时序不确定度与物理/意图/接触不确定度**同权**，不可补偿。

**定义 376（Chrono-IVG：C-IVG 门控）** 在 E-IVG 上新增失效条件：
- 时序：`A > A_half(ch)`、`L_{p99.9} > D`、`M_ch < 0`、`U_time > τ_time`；
- 任意时刻：`ECE(D) > τ_ece`、`ι_lat > τ_stab`、`R_sel(D) > τ_sel`；
- 原型：`Π` 契约过期、`Δ_total > margin`、shadow 证据不足、延迟剖面与目标硬件不匹配。
任一成立 ⇒ 对应证据/原型失效：时序失效 ⇒ 传输后验+膨胀 λ 或 R68；任意时刻失效 ⇒ 退化为上一有效后验/固定先验；原型失效 ⇒ 禁止上车，回退 R72。

**定义 377（影子-金丝雀生命周期 SHADOW）** 原型状态机：
`sandbox → shadow → canary → active → deprecated`。
- sandbox：不驱动执行器，仅离线/回放；
- shadow：与主系统并行推理，记录延迟/校准/反事实，不产生动作；
- canary：在受限动作包络内执行，λ_floor 提高、速度/力矩上限收紧；
- active：完整形态；
- deprecated：过期/债务超限/漂移，自动降级。
**晋升条件**：连续 N_min 个任务、跨分布 D_shadow 上 p99.9 延迟达标、ECE/ι_lat 达标、零安全违规、债务已登记且可偿。**降级条件**：延迟漂移 > δ、校准漂移 > δ、债务复利超阈、影子证据与实机不一致。

**定义 378（时序威胁模型 AIC-CHRONO）** `ℰ_CHRONO = ℰ_EMB × ℰ_lat × ℰ_proto`：
- ℰ_lat = {算法复杂度攻击（构造使模型跑更久的输入）、缓存/内存压力、批处理饥饿、热降频、网络抖动、时间戳伪造、过期证据重放、延迟侧信道}；
- ℰ_proto = {原型债务隐瞒、影子证据投毒、开发机-部署机延迟剖面替换、依赖升级导致的隐性漂移、过期契约复用、mock 传感器数据泄漏进训练}。
**新增攻击面：攻击者不必让模型错，只需让模型慢，就能让系统在过期证据上做出高置信错误动作。**

**定义 379（时序证书 J_FRESH）**
`J_FRESH = (J_EMB, L_profile_hash, ant_calib_hash, tchain_4d, proto_contract_hash, debt_ledger_hash, shadow_evidence_hash, chrono_ver)`。
Valid ⇔ `Valid(J_EMB)` ∧ 延迟剖面与目标硬件匹配 ∧ 任意时刻校准有效 ∧ 债务膨胀在边际内 ∧ 影子证据充分 ∧ 4D 追溯链完整 ∧ 契约未过期。

**定义 380（严格时序退化链）**
- 全有效 ⇒ FRESH 完整形态；
- CHRO 失效（年龄超保质期）⇒ 传输后验 + `U_age` 进 λ；若传输包络超阈 ⇒ 停止使用该证据；
- ANT 失效（截止条件校准失败）⇒ 使用上一有效后验 + 膨胀 λ；若无可信后验 ⇒ R71 固定先验；
- PROTO/DEBT 失效 ⇒ 禁止原型上车，回退 R72；
- REG/IRL/DMEM 失效 ⇒ 继承 R72 定义 364 的逐指令退化链。
**安全侧只增不减：时间与债务只会让系统更保守。**

**定义 381（4D 追溯链 TCHAIN-4D）** 每个进入风险缩放的数字附带
`τ_4D = (source, transform, value, variance, τ_obs, L, p_L, A, A_half, transport_op, validator)`。
追溯图必须满足：时间单调、因果有序、传输可复算、延迟分布可追溯到硬件/负载/输入、任一字段缺失即断链。**没有时间戳与延迟分布的数字，等同于没有来源的数字。**

**定义 382（FRESH 主流水线）** 见算法骨架 IP-295~302：控制域只读「带龄期的快照」；计量域做时间传输与任意时刻后验；感知域产出带 `p_L` 的证据；原型编排器只允许可采纳前沿上的 Π 进入 shadow/canary。

## 2. 关键算法骨架

```python
# IP-295 CHRO：时序证据与传输（计量域，软实时）
@dataclass
class ChronoEvidence:
    y: Any
    tau_obs: float          # 观测时刻
    tau_avail: float        # 后验可用时刻
    latency_dist: Distribution   # p_L(. | x, hw, load)，含 p99.9
    age: float              # A = t - tau_obs
    sigma_ch: float         # 通道时间敏感度
    half_life: float        # A_half
    valid_domain: TemporalValidity
    tchain: bytes

def transport_to_now(ev, b_old, dynamics, actions):
    A = now() - ev.tau_obs
    b_pred = dynamics.transport(b_old, actions, A)     # T_A b
    U_age  = dynamics.error_envelope(A, ev.sigma_ch)
    U_lat  = ev.latency_dist.quantile(0.999) - ev.latency_dist.quantile(0.5)
    if A > ev.half_life:
        return None, U_age + U_lat                  # 过期证据不得原样使用
    return b_pred, U_age + U_lat

# IP-296 ANT：任意时刻后验 + 截止条件校准（计量/控制交界）
class AnytimeInference:
    def __init__(self, cascade, calib_profile):
        self.cascade, self.calib = cascade, calib_profile
    def infer_until(self, x, deadline):
        t0 = now(); b = None; c = 0
        for c, stage in enumerate(self.cascade):
            if now() + stage.est_latency(x) > deadline: break
            b = stage(x, prior=b)                   # 嵌套早退/级联
        D = deadline - t0
        ece, iota, r_sel = self.calib.at(b, c, D)   # 截止条件校准
        return DeadlinePosterior(b=b, depth=c, D=D,
                                 ece=ece, iota_lat=iota,
                                 selective_risk=r_sel,
                                 admissible=(ece <= EPS_ECE and
                                             iota <= EPS_STAB and
                                             r_sel <= EPS_SEL))

# IP-297 VOC：计算即动作
def value_of_computation(b, z_dist, c_dist, D, candidates, params):
    best = None
    for c in candidates:
        if c.est_latency > D: continue
        b2, U_time = expected_posterior_after_compute(b, c)
        risk_gain  = expected_risk_reduction(b, b2, U_time)
        ig_z       = params.eta * (z_dist.entropy() - expected_z_entropy(c))
        cost       = params.alpha * c.est_latency + \
                     params.beta * max(0.0, c.est_latency - D) + \
                     c.energy + c.switch_cost
        score = risk_gain + ig_z - cost - \
                params.gamma * expected_future_loss(b, c)
        if best is None or score > best.score:
            best = (c, score)
    return best if best and best.score > 0 else STOP

# IP-298 PROTO：原型契约与可采纳前沿
def is_deployable(proto, now, margin, eps):
    L = proto.latency_profile
    return (L.p999 + L.queue <= proto.deadline - proto.slack and
            proto.ant_calib.ece <= eps.ece and
            proto.ant_calib.iota_lat <= eps.stab and
            proto.ant_calib.selective_risk <= eps.sel and
            proto.debt.total(now) <= margin and
            proto.expiry > now and
            proto.shadow_evidence.n >= N_MIN and
            proto.has_4d_tchain())

def proto_pareto_search(task, candidates, hw, now):
    admissible = []

        measured = probe_on_target(pi, hw)      # 目标硬件 + 负载 + 热

# IP-299 DEBT：债务复利与偿还
def debt_total(ledger, now):
    return sum(d.delta0 * math.exp(d.gamma * max(0.0, now - d.t0))
               for d in ledger.items if not d.retired)

def can_iterate(ledger, new_debt, repaid_debt, margin, now):
    return new_debt <= repaid_debt + max(0.0, margin - debt_total(ledger, now))

# IP-300 SHADOW：影子/金丝雀晋升

            evidence.p999_latency <= pi.deadline - pi.slack and

# IP-301 T-RISK：时序风险缩放（控制域，硬实时 <0.05ms）
def fresh_risk_scale(U_ale, U_epi, H_z, u_tac, U_time, params):
    denom = U_ale + U_epi + H_z + u_tac + U_time
    lam = params.lam_base * (1 + denom / params.lam_scale)
    return max(lam, params.lam_floor * (1 + denom))

# IP-302 FRESH 主闭环（控制域只读带龄期快照）
def FRESH_round(M, obs, audio, tac_frame):
    # === 控制域 1kHz ===
    snap = M.snapshot.read_latest()              # 带 tau_obs / age / p_L
    b_t, U_time = M.chro.transport_to_now(snap.best_ev, snap.b_prev,
                                          M.dynamics, M.last_actions)
    if b_t is None:
        M.mode = 'REFLEX'; return M.reflex_step()   # 过期且不可传输 -> R68
    U_ale, U_epi = decompose_ctrl(b_t, M.fmp, obs)
    H_z   = snap.z_dist.entropy() if snap.z_dist else float('inf')
    u_tac = snap.tac_ev.u_tac if snap.tac_ev else float('inf')
    lam   = fresh_risk_scale(U_ale, U_epi, H_z, u_tac, U_time, M.risk_params)
    A     = M.ach.propose_ctrl(...)
    k     = M.c_ras_wm.certified_prefix(A, lam, ...)
    M.ctrl_out.publish(k, lam)
    M.cert_ctrl.write(k=k, lam=lam, U_time=U_time, age=snap.age,
                      wcet=M.rtm.wcet_us(), breaker=M.breaker.status())

    # === 计量域 50Hz（可抢占） ===
    if M.clock.due_metric():
        # 对每个证据做时间传输，再做联合更新
        evs = M.chro.transport_all(M.evidence_buf, M.dynamics, M.last_actions)
        b_full = M.bse.step_full(M.b_prev, evs, ...)
        # 任意时刻后验（受 n_intent 截止约束）
        b_D = M.ant.infer_until(M.y_intent_buf, deadline=now()+D_INTENT)
        z_dist = b_D.b

                             M.tac_ev, b_D, M.debt, M.proto)
        if not gate.valid:
            M.mode = gate.fallback            # R72 / R71 / R68
        M.snapshot.write(b_full, z_dist, gate, M.psi_hat,
                         M.tac_ev, age=now()-evs[-1].tau_obs,
                         U_time=evs[-1].U_time)

    # === 感知域（异步，Best-effort） ===
    ev_audio = M.aura.update_with_latency(audio)   # 返回 p_L
    ev_tac   = M.dmem.update_with_latency(tac_frame, M.last_action)
    M.evidence_buf.append((ev_audio, ev_tac,
                           extract_intent_obs(obs, audio, M.last_action)))

    # === 原型编排（异步，不驱动控制域） ===
    for pi in M.proto_registry.shadowing():
        ev = M.shadow.run(pi, obs, audio, tac_frame)  # 并行、无动作
        if shadow_gate(pi, ev, M.eps):
            M.proto_registry.promote(pi, 'canary')
        elif ev.debt.total(now())+ev.debt_interest > pi.margin:
            M.proto_registry.demote(pi, 'deprecated')

    return k, lam, J_FRESH(M)
```

## 3. 推导

**引理 33（时间传输误差包络）** 若动力学 `p(s_t|s_{t−A},a)` 在 Wasserstein 意义下满足 `W_1 ≤ σ^A W_1^0 + ε_model(A)`，且 `A` 的估计误差为 `δA`，则 `W_1(T_A b, b_t) ≤ σ^A W_1^0 + ε_model(A) + L_σ·δA`（`L_σ` 为对 A 的 Lipschitz 常数）。证明：三角不等式 + 耦合。系：**过期后验的误差可计算，关键在于把 `σ^A` 与 `δA` 显式写进包络，而不是假装 `A=0`。**

**引理 34（截止条件校准的必要性）** 若模型仅在「完整计算」时校准，而系统在 D 时刻截断，则存在输入使 `|P(correct|conf,D) − conf|` 任意大；此时风险缩放使用的置信度不再对应真实错误率，`λ` 会系统性低估。系：**任意时刻系统必须报告 `ECE(D)` 与 `R_sel(D)`；「算完才准」的模型在实时闭环里是不可证的。**

**引理 35（延迟诱导 gauge 间隙下界）** 设两个计算深度 `c,c'` 在 D 内均可完成，且 `W_1(b^c,b^{c'}) = ι_lat`。若 `ι_lat > ε_stab`，则存在一个安全相关决策（如抓取/放弃）在 `c` 与 `c'` 下不同；在延迟抖动使实际深度随机切换时，决策序列不可复现。系：**`ι_lat` 是「同一模型、不同算力」下的 gauge 不变性间隙，必须作为 veto 指标。**

**引理 36（原型债务复利与有限可部署窗口）** 若每笔未偿债务 `Δ_i(t)=Δ_i^0 e^{γ_i(t−t_i)}`，`γ_i>0`，且债务只增不减，则存在有限 `T* = min_i {t_i + (1/γ_i) ln(margin/Δ_i^0)}` 使 `Δ_total(T*) = margin`；此后原型不可部署。证明：指数单调 + 有限和。系：**原型不是「做完就完了」；它有明确的过期时刻，快速迭代必须把还债排进时间表。**

**引理 37（计算停止的有限性）** 若每层计算的边际物理风险下降随深度非增、边际延迟成本有正下界 `ε_L>0`，则 `VoC(c)` 最终为负；在有限计算深度内存在最优停止点 `c*`。系：**「多想一会儿」不是无限免费的；延迟成本给出可证明的停止边界。**

**定理 27（时序严格包含与安全单调）** 在 A111–A116（传输包络有界、任意时刻校准有效、延迟剖面可测、债务膨胀可算、影子证据充分、时序退化链逐指令等价）下：FRESH 在退化条件下逐指令等于 R72/R71/R68；任意有效执行的风险界 ≤ R72 的风险界。**时间与债务只会让系统更保守。**

**定理 28（J_FRESH 有效性 ⇒ 时序安全）** 若一次执行通过 `J_FRESH`，则 (i) 每条进入 λ 的证据都在时序有效域内；(ii) 任意时刻后验满足 `ECE(D), ι_lat, R_sel` 约束；(iii) 原型契约与目标硬件匹配且未过期；(iv) 债务膨胀未侵蚀安全边际；(v) 4D 追溯完整。综上，**在「延迟分布与债务模型真实」的前提下，动作所依据的后验是关于当前时刻的有效证据，物理风险 ≤ ε_fresh。** 证明重量落在 **延迟尾部测量** 与 **债务风险膨胀校准** 上。

**定理 29（影子晋升的安全性单调）** 若原型从 shadow 晋升 canary 需通过 `shadow_gate`，且 canary 的 `λ_floor` 严格高于 active，则任意晋升路径上的即时风险不超过 shadow 估计的风险上界；晋升不会降低安全侧。**快速原型的「快」被限制在影子与受限包络内，不能直接换取执行器权限。**

**定理 30（4D 追溯断链检测）** 若 `TCHAIN-4D` 的任一字段（尤其 `τ_obs`、`L`、`p_L`、`A_half`）缺失或被篡改，则存在一个可构造的证据替换攻击使系统把过期证据当作新鲜证据；反之，若 4D 链完整且时间单调，则该类替换被检出。**没有时间戳的数字不是「弱证据」，而是「不可审计的证据」。**

## 6. 本轮最大风险

**一句话**：FRESH-GAUGE-RAS 把安全从「相信调度契约与认知计量」进一步转移到「相信 **延迟分布测量**、相信 **原型债务风险膨胀**、相信 **任意时刻校准在分布外仍成立**」——**如果 p99.9 的测量漏掉了热降频/批处理饥饿造成的重尾，或者原型债务的 `Δrisk` 是手调的先验而非可验证的界，或者早退模型在 OOD 输入上「越算越错」导致 `ι_lat` 爆表而校准剖面没覆盖到——系统就会在「每条证据都有时间戳、每个原型都有契约、每张证书都盖章」的情况下，用一份合法但过期的信念，在截止时间之后做出高置信动作；事后审计会发现所有数字都在各自的（被错误定义的）有效域内。** 这是 **时序层面的「自信地错自己的新鲜度」**。

次级风险与缓解：
1. **延迟尾部测量偏差** → 目标硬件 + 真实负载 + 热循环 + 输入分层测量；用极值理论/分位数回归估 p99.9，并加入对抗性延迟输入。
2. **债务 Δrisk 拍脑袋** → 每笔债务绑定可复算的替代测试/置信上界；债务必须由独立审计器登记，原型作者不能自报。
3. **任意时刻模型越算越错** → 强制 `ι_lat` 监控与「早退单调性」检查；若深层输出显著偏离浅层且无证据增益，冻结深层。
4. **影子证据不代表性** → 影子集按任务/人群/接触模式分层；加入 OOD 与对抗影子样本；shadow→canary 需分布覆盖证明。
5. **原型契约与实机漂移** → 运行时延迟哨兵 + 4D 链；契约哈希与硬件/驱动/负载指纹绑定，漂移即降级。
6. **时间戳伪造/重放** → 单调时钟 + 签名 + 因果序号；4D 链断链即拒绝证据。
7. **复杂度爆炸** → |𝒞|≤5、|𝒫|≤32、债务项≤32、每项一条可复算证明；时序字段与债务项本身纳入审计。

## 2. 形式化定义（要点版）

**定义 366（FRESH 总览与六不变式）** 时序证据完整性、任意时刻校准、原型契约优先、计算-安全耦合、影子默认、严格时序退化链。**任何缺失时间戳/延迟分布/债务登记的组件不得进入风险缩放或执行器。**

**定义 367（时序证据元组）** 证据必须携带 `(τ_obs, τ_avail, L, p_L, A, σ_ch, A_half, D_temp, τ_chain)`。**新鲜度不是权重，是有效域的门票。**

**定义 368（时间传输与包络）** `(T_A b)` 用已知动作把旧后验搬到当前；误差包络 `W_1(T_A b,b_t) ≤ ε_dyn(A)+ε_model(A)+ε_lat`。稳定模式 `ε_dyn ≤ κ^A ε_0`，接触滑移等扩张模式 `≤ e^{λ_max A} ε_0`。**过期不是乘衰减系数，而是搬到现在并把搬运误差算进风险。**

**定义 369（延迟关键度与保质期）** `κ_ch`、`A_half(ch)`、延迟裕度 `M_ch = A_half − L_{p99.9} − L_queue`；`M_ch<0` 即时序不可用。**接触通道按 10ms 级、意图按秒级、位姿按 100ms 级分配计算预算。**

**定义 370（任意时刻后验与截止条件校准）** 级联/早退返回 `b^D`，报告 `(ECE(D), ι_lat(D), R_sel(D), coverage(D))`。可采纳 ⇔ 三者均达标。**只在算完时校准的模型没有资格进入实时决策。**

**定义 371（计算即动作 VoC）** `VoC = ΔRisk_phys + ηΔH_z + ζΔH_c − αL − β·max(0,L−D) − c_energy − c_switch`；联合优化物理动作 g 与计算深度 c；VoC≤0 即停止计算。**延迟从被动指标变为主动决策变量。**

**定义 372（原型契约 PROTO）** 原型是带 `L_profile`、`𝒞_ant`、`D_temp`、`debt_ledger`、`monitors`、`expiry`、`signature` 的第一类工件。可部署 ⇔ `p99.9(L)+L_queue ≤ D−slack` ∧ 任意时刻校准达标 ∧ 时序域覆盖 ∧ `ΣΔ_d ≤ margin` ∧ 未过期 ∧ shadow 证据充分。

**定义 373（原型债务 DEBT 与复利）** 债务类型 {data, latency, hardware, calibration, abstraction, test, dependency}；`Δ_i(t)=Δ_i^0 e^{γ_i(t−t_i)}`；可部署 ⇔ `ε_base+Δ_total(t) ≤ ε_allow`；迭代 ⇔ 新增债 ≤ 偿还债 + 剩余边际。**债务有复利，原型有保质期。**

**定义 374（快速原型 Pareto 搜索）** 候选空间 𝒫，评价 `J(Π)=(risk,p99.9,coverage,energy,Δ_total,complexity)`；算子 `Generate→Probe→Counterexample→Refine→Retire`；只允许可采纳前沿 `𝒫*` 进入 shadow。**目标不是最快出 demo，而是最快找到可采纳前沿上的点。**

**定义 375（时序风险缩放 T-RISK）** `λ = max(risk_scale(U_ale,U_epi,H_z,u_tac,U_time), λ_floor(U_ale+U_epi+H_z+u_tac+U_time))`，`U_time=U_age+U_lat`。**高置信但过期的后验必须抬高 λ，而非降低 λ；时序不确定度不可被物理置信度补偿。**

**定义 376（C-IVG 门控）** 时序失效：`A>A_half`、`L_{p99.9}>D`、`M_ch<0`、`U_time>τ_time`；任意时刻失效：`ECE(D)>τ`、`ι_lat>τ`、`R_sel(D)>τ`；原型失效：契约过期、`Δ_total>margin`、shadow 证据不足、延迟剖面与硬件不匹配。任一失效 ⇒ 对应降级：传输后验+膨胀 λ / 上一有效后验 / 固定先验 / R72 / R68。

**定义 377（影子-金丝雀生命周期 SHADOW）** `sandbox→shadow→canary→active→deprecated`；晋升需分层 shadow 证据、p99.9/ECE/ι_lat 达标、零安全违规、债务可偿；canary 提高 λ_floor、收紧速度力矩；漂移/债务超阈自动 deprecated。**快速原型的「快」不能直接换取执行器权限。**

**定义 378（时序威胁模型 AIC-CHRONO）** `ℰ_CHRONO = ℰ_EMB × ℰ_lat × ℰ_proto`。新增：算法复杂度攻击、缓存/内存压力、批处理饥饿、热降频、时间戳伪造、过期证据重放、债务隐瞒、影子证据投毒、开发机-部署机延迟剖面替换。**攻击者不必让模型错，只需让模型慢。**

**定义 379（时序证书 J_FRESH）** `Valid ⇔ Valid(J_EMB) ∧ 延迟剖面与硬件匹配 ∧ 任意时刻校准有效 ∧ 债务在边际内 ∧ shadow 证据充分 ∧ 4D 链完整 ∧ 未过期`。

**定义 380（严格时序退化链）** 全有效→FRESH；CHRO 失效→传输+膨胀 λ，超阈停用证据；ANT 失效→上一有效后验/固定先验；PROTO/DEBT 失效→禁止原型上车、回退 R72；REG/IRL/DMEM 失效→继承 R72 定义 364。**安全侧只增不减。**

**定义 381（4D 追溯链 TCHAIN-4D）** `τ_4D = (source, transform, value, variance, τ_obs, L, p_L, A, A_half, transport_op, validator)`；时间单调、因果有序、传输可复算、延迟分布可追溯到硬件/负载/输入；缺字段即断链。**没有时间戳与延迟分布的数字，等同于没有来源的数字。**

**定义 382（FRESH 主流水线）** 控制域只读带龄期快照 + T-RISK；计量域时间传输 + 任意时刻后验 + C-IVG；感知域产出带 `p_L` 的证据；原型编排器只让 `𝒫*` 进入 shadow/canary。

```python
# IP-295 CHRO：时序证据 + 时间传输
@dataclass
class ChronoEvidence:
    y: Any
    tau_obs: float
    tau_avail: float
    latency_dist: Distribution       # p_L(. | x, hw, load)
    sigma_ch: float                  # 时间敏感度
    half_life: float                 # A_half
    valid_domain: TemporalValidity
    tchain: bytes

def transport_to_now(ev, b_old, dynamics, actions):
    A = now() - ev.tau_obs
    b_pred = dynamics.transport(b_old, actions, A)     # T_A b
    U_age  = dynamics.error_envelope(A, ev.sigma_ch)
    U_lat  = ev.latency_dist.quantile(0.999) - ev.latency_dist.quantile(0.5)
    if A > ev.half_life:
        return None, U_age + U_lat
    return b_pred, U_age + U_lat

# IP-296 ANT：截止条件任意时刻后验
class AnytimeInference:
    def infer_until(self, x, deadline):
        t0 = now(); b = None; c = 0
        for c, stage in enumerate(self.cascade):
            if now() + stage.est_latency(x) > deadline: break
            b = stage(x, prior=b)
        D = deadline - t0
        ece, iota, r_sel = self.calib.at(b, c, D)
        return DeadlinePosterior(b=b, depth=c, D=D, ece=ece,
                                 iota_lat=iota, selective_risk=r_sel,
                                 admissible=(ece <= EPS_ECE and
                                             iota <= EPS_STAB and
                                             r_sel <= EPS_SEL))

# IP-297 VOC：计算即动作
def value_of_computation(b, z_dist, c_dist, D, candidates, params):
    best = None
    for c in candidates:
        if c.est_latency > D: continue
        b2, U_time = expected_posterior_after_compute(b, c)
        score = (expected_risk_reduction(b, b2, U_time)
                 + params.eta * (z_dist.entropy() - expected_z_entropy(c))
                 - params.alpha * c.est_latency
                 - params.beta * max(0.0, c.est_latency - D)
                 - c.energy - c.switch_cost
                 - params.gamma * expected_future_loss(b, c))
        if best is None or score > best.score: best = (c, score)
    return best if best and best.score > 0 else STOP

# IP-298 PROTO：契约可部署判定 + 可采纳前沿
def is_deployable(proto, now, margin, eps):
    L = proto.latency_profile
    return (L.p999 + L.queue <= proto.deadline - proto.slack and
            proto.ant_calib.ece <= eps.ece and
            proto.ant_calib.iota_lat <= eps.stab and
            proto.ant_calib.selective_risk <= eps.sel and
            proto.debt.total(now) <= margin and
            proto.expiry > now and
            proto.shadow_evidence.n >= N_MIN and
            proto.has_4d_tchain())

def proto_pareto_search(task, candidates, hw, now):
    ok = []
    for pi in candidates:
        measured = probe_on_target(pi, hw)       # 目标硬件 + 负载 + 热
        stressed = counterexample_stress(pi)     # 延迟/精度/接触/意图反例
        if admissible_after(measured, stressed) and is_deployable(measured, now, ...):
            ok.append(measured)
    return pareto_front(ok, keys=('risk','p999','coverage','debt'))

# IP-299 DEBT：复利与偿还
def debt_total(ledger, now):
    return sum(d.delta0 * math.exp(d.gamma * max(0.0, now - d.t0))
               for d in ledger.items if not d.retired)

def can_iterate(ledger, new_debt, repaid_debt, margin, now):
    return new_debt <= repaid_debt + max(0.0, margin - debt_total(ledger, now))

# IP-300 SHADOW：晋升门控
def shadow_gate(pi, evidence, eps):
    return (evidence.n >= N_MIN and
            evidence.p999_latency <= pi.deadline - pi.slack and
            evidence.ece <= eps.ece and
            evidence.iota_lat <= eps.stab and
            evidence.safety_violations == 0 and
            evidence.debt.total(now) <= pi.margin)

# IP-301 T-RISK：时序风险缩放（控制域 <0.05ms）
def fresh_risk_scale(U_ale, U_epi, H_z, u_tac, U_time, params):
    denom = U_ale + U_epi + H_z + u_tac + U_time
    lam = params.lam_base * (1 + denom / params.lam_scale)
    return max(lam, params.lam_floor * (1 + denom))

# IP-302 FRESH 主闭环
def FRESH_round(M, obs, audio, tac_frame):
    # 控制域 1kHz
    snap = M.snapshot.read_latest()              # 带 tau_obs / age / p_L
    b_t, U_time = M.chro.transport_to_now(snap.best_ev, snap.b_prev,
                                          M.dynamics, M.last_actions)
    if b_t is None:
        M.mode = 'REFLEX'; return M.reflex_step()
    U_ale, U_epi = decompose_ctrl(b_t, M.fmp, obs)
    H_z   = snap.z_dist.entropy() if snap.z_dist else float('inf')
    u_tac = snap.tac_ev.u_tac if snap.tac_ev else float('inf')
    lam   = fresh_risk_scale(U_ale, U_epi, H_z, u_tac, U_time, M.risk_params)
    A = M.ach.propose_ctrl(...); k = M.c_ras_wm.certified_prefix(A, lam, ...)
    M.ctrl_out.publish(k, lam)
    M.cert_ctrl.write(k=k, lam=lam, U_time=U_time, age=snap.age,
                      wcet=M.rtm.wcet_us(), breaker=M.breaker.status())

    # 计量域 50Hz
    if M.clock.due_metric():
        evs = M.chro.transport_all(M.evidence_buf, M.dynamics, M.last_actions)
        b_full = M.bse.step_full(M.b_prev, evs, ...)
        b_D = M.ant.infer_until(M.y_intent_buf, deadline=now()+D_INTENT)
        z_dist = b_D.b
        gate = M.c_ivg.check(M.registry, b_full, z_dist,
                             M.tac_ev, b_D, M.debt, M.proto)
        if not gate.valid:
            M.mode = gate.fallback            # R72 / R71 / R68
        M.snapshot.write(b_full, z_dist, gate, M.psi_hat, M.tac_ev,
                         age=now()-evs[-1].tau_obs, U_time=evs[-1].U_time)

    # 感知域（异步）
    ev_audio = M.aura.update_with_latency(audio)
    ev_tac   = M.dmem.update_with_latency(tac_frame, M.last_action)
    M.evidence_buf.append((ev_audio, ev_tac,
                           extract_intent_obs(obs, audio, M.last_action)))

    # 原型编排（异步，无动作）
    for pi in M.proto_registry.shadowing():
        ev = M.shadow.run(pi, obs, audio, tac_frame)
        if shadow_gate(pi, ev, M.eps):
            M.proto_registry.promote(pi, 'canary')
        elif ev.debt.total(now()) + ev.debt_interest > pi.margin:
            M.proto_registry.demote(pi, 'deprecated')

    return k, lam, J_FRESH(M)
```

## 4. 推导

**引理 33（时间传输误差包络）** 若动力学满足 `W_1 ≤ σ^A W_1^0 + ε_model(A)`，龄期估计误差为 `δA`，则 `W_1(T_A b,b_t) ≤ σ^A W_1^0 + ε_model(A) + L_σ·δA`。系：**过期后验的误差可计算，必须把 `σ^A` 与 `δA` 写进包络，而不是假装 `A=0`。**

**引理 34（截止条件校准的必要性）** 若模型只在完整计算时校准，而系统在 D 截断，则存在输入使 `|P(correct|conf,D)−conf|` 任意大，`λ` 系统性低估。系：**「算完才准」的模型在实时闭环里不可证。**

**引理 35（延迟诱导 gauge 间隙下界）** 若两个计算深度在 D 内均可完成且 `W_1(b^c,b^{c'})=ι_lat>ε_stab`，则存在安全相关决策在 c 与 c' 下不同；延迟抖动使决策序列不可复现。系：**`ι_lat` 是「同一模型、不同算力」的 gauge 不变性间隙，必须作为 veto。**

**引理 36（债务复利与有限可部署窗口）** 若 `Δ_i(t)=Δ_i^0 e^{γ_i(t−t_i)}`、`γ_i>0` 且债务只增不减，则存在有限 `T* = min_i {t_i + (1/γ_i) ln(margin/Δ_i^0)}` 使 `Δ_total(T*)=margin`，此后不可部署。系：**原型有明确过期时刻，快速迭代必须把还债排进时间表。**

**引理 37（计算停止的有限性）** 若每层计算的边际风险下降随深度非增、边际延迟成本有正下界 `ε_L>0`，则 `VoC(c)` 最终为负，有限深度内存在最优停止点 `c*`。系：**「多想一会儿」不是无限免费的。**

**定理 27（时序严格包含与安全单调）** 在 A111–A116 成立时，FRESH 在退化条件下逐指令等于 R72/R71/R68；任意有效执行的风险界 ≤ R72 的风险界。**时间与债务只会让系统更保守。**

**定理 28（J_FRESH 有效性 ⇒ 时序安全）** 通过 J_FRESH ⇒ (i) 进入 λ 的证据都在时序有效域内；(ii) 任意时刻后验满足 ECE/ι_lat/R_sel 约束；(iii) 原型契约与目标硬件匹配且未过期；(iv) 债务未侵蚀安全边际；(v) 4D 追溯完整。**在「延迟分布与债务模型真实」的前提下，动作所依据的后验是关于当前时刻的有效证据，物理风险 ≤ ε_fresh。** 证明重量落在 **延迟尾部测量** 与 **债务风险膨胀校准** 上。

**定理 29（影子晋升的安全性单调）** 若 shadow→canary 需通过 `shadow_gate` 且 canary 的 λ_floor 严格高于 active，则任意晋升路径上的即时风险不超过 shadow 估计的风险上界；晋升不会降低安全侧。**快速原型的「快」不能直接换取执行器权限。**

**定理 30（4D 追溯断链检测）** 若 TCHAIN-4D 的任一字段（尤其 τ_obs、L、p_L、A_half）缺失或被篡改，则存在可构造的证据替换攻击使过期证据被当作新鲜证据；反之，4D 链完整且时间单调时该类替换被检出。**没有时间戳的数字不是弱证据，是不可审计的证据。**

## 7. 本轮最大风险

**一句话**：FRESH-GAUGE-RAS 把安全从「相信调度契约与认知计量」进一步转移到「相信 **延迟分布测量**、相信 **原型债务风险膨胀**、相信 **任意时刻校准在分布外仍成立**」——**如果 p99.9 测量漏掉热降频/批处理饥饿造成的重尾，或者原型债务的 `Δrisk` 是手调先验而非可验证的界，或者早退模型在 OOD 输入上「越算越错」导致 `ι_lat` 爆表而校准剖面没覆盖到——系统就会在「每条证据都有时间戳、每个原型都有契约、每张证书都盖章」的情况下，用一份合法但过期的信念，在截止时间之后做出高置信动作；事后审计会发现所有数字都在各自的（被错误定义的）有效域内。** 这是 **时序层面的「自信地错自己的新鲜度」**。

次级风险与缓解：
1. **延迟尾部测量偏差** → 目标硬件 + 真实负载 + 热循环 + 输入分层测量；极值理论/分位数回归估 p99.9，并加入对抗性延迟输入。
2. **债务 Δrisk 拍脑袋** → 每笔债务绑定可复算的替代测试/置信上界；债务由独立审计器登记，原型作者不能自报。
3. **任意时刻模型越算越错** → 强制 `ι_lat` 监控与早退单调性检查；深层输出显著偏离浅层且无证据增益时冻结深层。
4. **影子证据不代表性** → 影子集按任务/人群/接触模式分层；加入 OOD 与对抗影子样本；shadow→canary 需分布覆盖证明。
5. **原型契约与实机漂移** → 运行时延迟哨兵 + 4D 链；契约哈希与硬件/驱动/负载指纹绑定，漂移即降级。
6. **时间戳伪造/重放** → 单调时钟 + 签名 + 因果序号；4D 链断链即拒绝证据。
7. **复杂度爆炸** → |𝒞|≤5、|𝒫|≤32、债务项≤32、每项一条可复算证明；时序字段与债务项本身纳入审计。
