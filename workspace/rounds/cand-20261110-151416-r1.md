# 第 46 轮（承接第 45 轮 v10；本轮灵感：抗干扰 × 联邦学习） · Fed-Robust-Cert：干扰鲁棒的分层证书联邦校准与拜占庭可审计覆盖账本（四层架构 v11）

> 承接第 45 轮 v10 Energy-Context-Depth。v10 把能量租约、深度门控、上下文预测纳入联合证书 J_t=(P_t,ℓ_p,ℓ_e,m_t)，但隐含假设 H5：**分层共形半径 r_ω(m)、上下文预测器 P(ω|c,m)、能量模型 P_m 都是单机、静态、良性标定的**。UniBot 是机队（fleet）而非单机：每台机器人所处场景不同，稀有退化层（透明/镜面/深度空洞/强光）在单机上样本极稀疏，共形分位数统计噪声大；同时真实部署存在传感器干扰、分布漂移、以及恶意或故障客户端。两个灵感词精确命中 H5：**抗干扰**要求证书在输入扰动与分布漂移下仍然 sound（而非仅在可交换假设下成立）；**联邦学习**允许机队共享标定统计量（不共享原始数据）以补齐稀有层覆盖，却引入拜占庭投毒、非独立同分布、通信/能耗、版本陈旧等新的信任面。核心新问题：**如何在机队联邦校准分层条件证书，使覆盖保证在干扰与恶意客户端下依然成立，同时避免把单机安全押注在一个可被投毒或陈旧的全局半径上**。

## 0. 直觉与动机

**灵感 1（抗干扰 → 干扰鲁棒共形半径）**
直觉：v10 的共形保证建立在可交换性上；一旦传感器被干扰（强光、镜面反射、深度相机被激光/图案欺骗、快速运动模糊）或测试分布漂移，覆盖会静默跌破 1-α。把干扰显式建模为扰动预算 ε_t，用**鲁棒分数** s_rob(x)=max_{x'∈B_ε(x)} s(x',y) 做共形，或对 Lipschitz 姿态残差做半径膨胀 r^rob = r + L_ε·ε_t + Δ_shift。干扰越大，证书越宽；超过预算即 fail-closed。

**灵感 2（联邦学习 → 稀有层覆盖的跨机池化）**
直觉：单机在 Ω_deg 稀有层可能只有个位数样本，共形分位数不可信。机队联邦可把各客户端的分层分位数/覆盖统计聚合，用鲁棒聚合补齐稀有层；原始数据不出本地（隐私 + 带宽 + 能量三重约束）。联邦不是免费午餐：它把"本地统计不足"换成"全局聚合可被污染"。

**灵感 3（两者耦合 → 覆盖 vs 信任面权衡）**
直觉：联邦提升覆盖，却制造"单点信任"：全局半径被投毒或陈旧时，所有机器人静默继承不 sound 的证书，且故障是**同时、系统性**的（比单机故障更危险）。因此全局半径只能作为**有审计账本背书的"增益"叠加到本地安全下限之上**，而非替代本地证据。定义 r̂_ω(m)=max(r^local_ω(m), r^fed_ω(m)+L_ε·ε_t)，其中 r^fed 由鲁棒聚合 + 覆盖账本证明；任何审计失败都回退本地或 fail-closed。

**耦合升级**：在 v10 四层上新增**联邦校准平面 FCP（Federated Calibration Plane）**，它不改变在线安全路径，只以"带版本 + 覆盖账本 + 客户端证明"的方式向根信任层注入 r_ω(m)、P(ω|c,m)、P_m。四层 v11：根信任层增加联邦证书版本与覆盖账本；L1 几何层用干扰鲁棒半径；L2 上下文预测器接受联邦先验但受本地证据约束；L3 CAR 守卫校验联邦版本新鲜度与拜占庭审计；L4 DCL 将稀有层样本按隐私预算上行触发联邦轮次。

## 1. 形式化定义（增量：定义 54–58）

**定义 54（分层联邦校准）**
客户端 k∈[K]，本地标定集 D_k，层 ω，模态 m。本地共形半径
r_{k,ω}(m)=Quantile_{1-α}({s_i : (x_i,y_i)∈D_k, ω(x_i)=ω, m_i=m})。
服务端鲁棒聚合
r^fed_ω(m)=AGG_{k∈S_ω(m)}( r_{k,ω}(m) ),  AGG∈{坐标中位数, trimmed-mean, median-of-means}，
其中 S_ω(m) 为报告该层且通过客户端证明的子集。上行前做裁剪 + 差分隐私加噪，原始数据不出本地。

**定义 55（干扰模型与鲁棒覆盖）**
输入扰动集 B_ε(x)={x':‖x'-x‖≤ε}，分布漂移 Q 满足 D_f(Q‖P)≤ρ。**干扰鲁棒覆盖**定义为
inf_{x'∈B_ε(x)} P( X∈P | ω,m ) ≥ 1-α，或在漂移下 P_Q(X∈P)≥1-α。
鲁棒半径膨胀：r^rob_ω(m)=r^fed_ω(m)+L_ε·ε_t+Δ_shift(ρ)，其中 L_ε 为姿态残差对输入扰动的 Lipschitz 常数，Δ_shift 为漂移补偿项。

**定义 56（拜占庭鲁棒联邦证书）**
恶意客户端比例 β，聚合器崩溃点 β_max。**拜占庭 soundness**：若 β<β_max 且每层有效客户端数 |S_ω(m)|≥q_min，则任意 β 比例投毒最多使 r^fed_ω(m) 的覆盖下降 δ_byz，即 P(X∈P)≥1-α-δ_byz。

**定义 57（联邦覆盖账本）**
账本 L={(ω,m, r^fed, ĉ_ω, n_ω, ver, proof)}，ĉ_ω 为聚合留出集上的经验覆盖，n_ω 为有效样本数，proof 为客户端 attestation/quorum。**账本一致判据**：ĉ_ω≥1-α-δ 且 n_ω≥n_min，否则该层半径必须膨胀或标记 UNTRUSTED。

**定义 58（联邦证书 soundness 与安全下限）**
P( X_t∈P_t | ω_t,m_t, ver 新鲜, β<β_max, ε_t≤ε_max ) ≥ 1-α-Δ_shift-δ_byz。
**安全下限约束**：r̂_ω(m)=max(r^local_ω(m), r^fed_ω(m)+L_ε·ε_t+Δ_shift)，即联邦永远不能使半径小于本地已验证下限。任一条件失效 → 回退本地或 fail-closed。

## 2. 三大新增产出与既有 IP 升级

**IP-66 FED-CAL（Federated Stratified Conformal Calibrator）**
- 本地分层分位数 + 裁剪 + 差分隐私加噪，原始数据不出本地
- 鲁棒聚合（坐标中位数 / trimmed-mean / median-of-means）
- 每层样本数门槛 n_min 与覆盖账本发布
- 版本化半径 r^fed_ω(m) 与客户端 attestation / quorum 证明

**IP-67 ROBUST-CONFORMAL / SHIFT-GUARD**
- 干扰估计 ε_t（CUSUM / 残差异常检测 / 深度质量跳变）
- 鲁棒分数 s_rob 或 Lipschitz 半径膨胀 L_ε·ε_t
- 分布漂移检测（密度比 / MMD），漂移超阈 → 半径膨胀或本地回退

**IP-68 BYZ-CERT-AUDITOR**
- 投毒红队：伪造稀有层高分位、恶意缩小半径
- 覆盖账本交叉校验与 quorum 证明
- 崩溃点监测：β 估计超 β_max → 冻结联邦、回退上一认证版本

**既有 IP 升级**
IP-60 PSE：半径来源增加 provenance（local/fed/ver），强制安全下限 max
IP-61 DCL：稀有层样本按隐私预算触发联邦上行；采集效用加入通信成本
IP-62 CCA：新增干扰注入、投毒客户端、版本陈旧三类红队
IP-51 CAR：守卫加入 ver 新鲜度、覆盖账本一致、β<β_max、ε_t≤ε_max
IP-45 总线：新增 fed-calib / coverage-ledger / client-attestation / shift-alarm 话题

## 3. 算法骨架

FCP 离线/低频：
1. 各客户端在 D_k 上算分层分位数 r_{k,ω}(m)，裁剪加噪
2. 上行至服务端（仅在能量租约 ℓ_e 有余量时执行，复用 IP-63）
3. 服务端鲁棒聚合 r^fed_ω(m)，计算覆盖账本 ĉ_ω、n_ω
4. 若 ĉ_ω<1-α-δ 或 n_ω<n_min 或 β≥β_max → 该层标记 UNTRUSTED
5. 发布 r^fed + 账本 + ver + 证明
在线：
6. 客户端读 ver、ε_t，计算 r^rob=r^fed+L_ε·ε_t+Δ_shift
7. 安全下限 r̂=max(r^local, r^rob)；若 UNTRUSTED 或 ver 陈旧或 ε_t>ε_max → 用 r^local 或 fail-closed
8. PSE 用 r̂ 签发 P_t，CAR 用联合证书守卫

## 4. 本轮最大风险

**一句话**：联邦聚合的全局半径一旦被投毒缩小或被陈旧版本污染，且安全下限/覆盖账本校验被绕过，就会让整支机队同时继承不 sound 的姿态证书；因此必须坚持"本地安全下限 + 鲁棒聚合 + 覆盖账本 quorum + 版本新鲜度"四重约束，任一不满足即回退本地或 fail-closed。

## 2. 关键算法 伪代码

### IP-66 FED-CAL 本地标定 + 鲁棒聚合
```
def local_stratum_quantile(D_k, omega, m, alpha, clip, eps_dp):
    scores = [s(x,y) for (x,y) in D_k
              if stratum(x) == omega and modality(x) == m]
    if len(scores) < n_min_local:
        return None
    r = quantile(scores, 1 - alpha)
    r = min(r, clip)                          # 裁剪抗离群
    r_tilde = r + laplace(scale=clip/eps_dp)  # 差分隐私
    return (omega, m, r_tilde, len(scores))

def robust_aggregate(reports, q_min):
    out = {}
    for key, group in groupby(reports, key=lambda z: (z[0], z[1])):
        rs = sorted(z[2] for z in group)
        if len(rs) < q_min:
            out[key] = UNTRUSTED
            continue
        out[key] = median(rs)                 # 崩溃点 50%；或 trimmed-mean
    return out

def build_ledger(r_fed, audit_sets, ver):
    ledger = {}
    for key, r in r_fed.items():
        if r == UNTRUSTED:
            ledger[key] = Entry(r, c_hat=0, n=0, ver=ver, trusted=False)
            continue
        c_hat = empirical_coverage(audit_sets[key], r)   # 聚合留出覆盖
        n = total_samples(audit_sets[key])
        trusted = (c_hat >= 1 - alpha - delta) and (n >= n_min)
        ledger[key] = Entry(r, c_hat, n, ver, trusted)
    return ledger
```

### IP-67 ROBUST-CONFORMAL / SHIFT-GUARD
```
def estimate_interference(residual_stream):
    # CUSUM / 残差异常，输出扰动预算估计
    return cusum_statistic(residual_stream, drift=nu)

def robust_radius(r_fed, eps_t, L_eps, rho_t, delta_shift_fn):
    if eps_t > eps_max:
        return None                       # fail-closed
    return r_fed + L_eps*eps_t + delta_shift_fn(rho_t)

def resolve_radius(omega, m, r_local, ledger, ver, required_ver, eps_t):
    entry = ledger.get((omega, m))
    if ver < required_ver:                # 版本陈旧 → 回退本地
        return r_local
    if entry is None or not entry.trusted:
        return r_local                    # 账本不可信 → 回退本地
    r_rob = robust_radius(entry.r, eps_t, L_eps, rho_t, delta_shift_fn)
    if r_rob is None:
        return None                       # fail-closed
    return max(r_local, r_rob)            # 安全下限：联邦不得低于本地证据
```

### IP-68 BYZ-CERT-AUDITOR
```
def audit_federation(reports, ledger, beta_hat, ver):
    if beta_hat >= beta_max:
        return Freeze('byzantine')
    if not quorum_ok(reports):
        return Freeze('quorum')
    for key, entry in ledger.items():
        if not entry.trusted:
            return InflateOrUntrust(key)  # 该层膨胀或弃用
    return Accept(ver)

def redteam_poison(reports, victim_key, shrink=0.5):
    # 红队：伪造稀有层高分位/缩小半径，验证聚合崩溃点
    return [(w, m, r*shrink, n) if (w, m) == victim_key else (w, m, r, n)
            for (w, m, r, n) in reports]
```

### IP-51 CAR v7 守卫（联邦版）
```
def car_guard_v7(e, x, cert, persona, lease_p, lease_e, m_t,
                 ver, required_ver, ledger, beta_hat, eps_t, t):
    if not pose_lease_valid(lease_p, t) or \
       not energy_lease_valid(lease_e, t, E_min(e)):
        cascade_invalidate('pose_energy')
        return FailClosed()
    if ver < required_ver or beta_hat >= beta_max or eps_t > eps_max:
        cascade_invalidate('federation')
        return FailClosed()
    r = resolve_radius(x.stratum, m_t, cert.r_local, ledger,
                       ver, required_ver, eps_t)
    if r is None:
        return FailClosed()
    m_pose = L_phi[e] * r
    m_energy = L_e * max(0.0, B_min - E(t))
    m = min(cert.lookup, lease_p.m, persona_cap) - m_pose - m_energy
    return m >= theta(e)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| FED-CAL 本地标定 | O(|D_k| log|D_k|) 每轮 | O(|Ω|·|M|) | 分层分位数 + DP ⇒ 原始数据不出本地 |
| 鲁棒聚合 | O(K log K) 每层 | O(K) | β<β_max ∧ \|S_ω\|≥q_min ⇒ 覆盖下降 ≤δ_byz |
| 覆盖账本 | O(|Ω|·|M|·n_audit) | O(|Ω|·|M|) | ĉ_ω≥1-α-δ ∧ n_ω≥n_min ⇒ 该层可信 |
| SHIFT-GUARD | O(1) | O(1) | ε_t≤ε_max ⇒ 覆盖 ≥1-α-Δ_shift |
| CAR v7 | O(1) | - | 四重约束任一失败 ⇒ fail-closed |

正确性定理：若 ver 新鲜、β<β_max、每层 |S_ω(m)|≥q_min、账本 ĉ_ω≥1-α-δ 且 n_ω≥n_min、ε_t≤ε_max，且 P_t 使用 r̂_ω(m)=max(r^local_ω(m), r^fed_ω(m)+L_ε·ε_t+Δ_shift)，则联邦证书覆盖
P(X_t∈P_t | ω_t,m_t) ≥ 1-α-Δ_shift-δ_byz，
联合证书 J_t 的鲁棒提升 φ^□(P_t) 保持 sound。任一条件失效则回退本地半径或进入 fail-closed，绝不使用未经证明的全局半径。

| 全局半径被投毒缩小，机队同时失效 | 高 | 鲁棒聚合（中位数/trimmed-mean）+ 覆盖账本 quorum + 本地安全下限 max |
| 差分隐私噪声过大使稀有层半径失真 | 中 | 按层自适应 DP 预算 + n_min 门槛 + 本地回退 |
| 漂移/干扰估计滞后导致 ε_t 低估 | 高 | CUSUM 快速告警 + 保守 L_ε 上界 + 超阈 fail-closed |
| 版本陈旧使机器人使用过期证书 | 高 | ver 单调 + 新鲜度校验 + 陈旧即回退本地 |
| 联邦通信/能耗挤占感知预算 | 中 | 仅在 ℓ_e 有余量时上行；稀有层优先；通信成本入 DCL 效用 |
| 非 IID 导致聚合偏差 | 中 | 分层聚合 + 每层样本数门槛 + 漂移加权 |

## 6. 本轮最大风险

**一句话**：联邦聚合的全局半径一旦被投毒缩小或被陈旧版本污染，且安全下限/覆盖账本校验被绕过，就会让整支机队同时继承不 sound 的姿态证书；因此必须坚持"本地安全下限 + 鲁棒聚合 + 覆盖账本 quorum + 版本新鲜度"四重约束，任一不满足即回退本地或 fail-closed。
