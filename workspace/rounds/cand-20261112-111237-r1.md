# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 7 轮；本轮灵感：「多模态大模型」×「用户体验」）

> 第 60 轮用 SSM×CIEC×EPIR×SERC×PCE++++ 把「场景语义→意图→执行约束→证据回传」闭了起来，但它把三个隐含假设当成了真理，本轮正面拆解：
> 1. **认知词表是封闭的**：SSM 的 10 个场景、CIEC 的 5 个意图全部人工枚举。面对开放世界的「这布有点潮」「别碰那只花瓶」「像上次那样轻一点」，封闭词表直接退化到 `unknown`。多模态大模型（MLLM）具备开放词表理解能力，却**慢、会幻觉、且不懂物理**——把「语言流畅」直接当「执行安全」，是把语义幻觉注入安全关键回路的最短路径。
> 2. **认知产物不可验证**：第 60 轮的 `π_scene`、`φ_intent→constraint` 被当作先验即真理，缺少机制去检验「语义假设」是否被「执行证据」背书。`EV-exec` 只能事后证伪错误语义，无法事前拦截；一旦 `K_safe` 提前收敛到错误场景，证据链反而会「自洽地」记录一次灾难。
> 3. **用户体验维度整体缺失**：前 60 轮优化的是正确性 / 证据完整性 / 执行安全，但人机协作的质量还包括**响应感、可预测性、信任校准、控制权、可恢复性**。UX 不是事后满意度问卷，而应是可测量、可计入预算、可约束控制器的**一等资源**；更危险的是，若把 UX 当优化目标而无安全硬约束，「少打扰、快响应」会诱导系统削减验证强度。

## 0. 直觉与动机

**灵感 1（多模态大模型 → 多模态可验证提议器 MVSP）**
直觉：把 MLLM 放在「副驾驶」而非「驾驶员」位置。它看图像（I_vis）、读力矩曲线（T_ft）、听对话（D_dlg）、查历史证据（E_hist），输出**开放词表的场景/意图假设 + 自评置信度 + 接地查询**。例如它说「疑似湿滑桌面，请做一次低幅扫掠测摩擦」。关键洞见：**MLLM 的输出必须是一组「待验证假设」，而不是控制参数**——把「语义猜测」降级为「提案」，用执行证据回填真值。这样既拿到开放词表能力，又不让幻觉直连执行器。

**灵感 2（用户体验 → 五维体验预算 UXB）**
直觉：UX 可拆成五个可测维度——响应感（延迟分布）、可预测性（动作熵/一致性，但不能为 0 否则僵化）、信任校准（置信度-准确率偏差）、控制权（人类接管成本）、可恢复性（错误可解释且可回滚）。把 `B_ux` 做成与 `B_exec` 并列的资源：**打断用户要消耗体验预算，静默自主同样消耗信任预算**。UX 预算耗尽时进入「最小打扰 / 最高透明」模式。

**灵感 3（信任校准 TCA）**
直觉：人最易在两个极端出错——过度信任（把幻觉当可靠）与信任不足（频繁接管）。系统应主动**校准**展示置信度，让「系统说 90% 可靠」在统计上真是 90%；当期望校准误差 ECE 过大时，把展示置信度向先验收缩，并显式呈现「不确定」。这是「体验」与「安全」的交点：**好的 UX 不是让人更信任系统，而是让人的信任匹配系统的真实可靠度**。

**灵感 4（三灵感合流 → PVA 提议-验证-仲裁循环）**
直觉：MVSP 提议 → 接地验证器 GV 用物理一致性/阻抗可行性/证据一致性三重验证 → TCA 依据校准置信度与 `B_ux` 仲裁（自主执行 / 请求确认 / 主动探测 / 降级）→ 交给第 60 轮 SERC 执行 → 证据回填。形成「**语义提议 → 物理接地 → 体验仲裁 → 执行 → 证据回填**」闭环，实现三权分立：提议者、验证者、仲裁者互不越权。

**灵感 5（PCE+++++ → 五预算与 LLM 成本）**
直觉：新增 `B_ux` 与 `B_llm`（token / 延迟 / 调用率）。MLLM 调用昂贵且慢，必须**投机缓存 + 分层调用**：常见场景走缓存/小模型，罕见场景才调大模型；`B_llm` 耗尽立刻退回第 60 轮的封闭词表先验。**慢模型不进快回路**：MLLM 永远在低速认知线程，执行线程只消费已接地证书。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（多模态可验证提议器 MVSP）** 提议器 Π = (f_llm, P_prop, Q_ground, C_cache)。其中：
- **多模态输入**：f_llm: (I_vis, T_ft, D_dlg, E_hist, M_mem) → P_prop
- **提议集合**：P_prop = {(z_h, I_h, π_scene^h, c_h, Q_h)}_h；`z_h` 为**开放词表**场景假设，`I_h` 为意图假设，`π_scene^h = N(K; μ_h, Σ_h)` 为提议阻抗先验，`c_h ∈ [0,1]` 为自评置信度，`Q_h` 为接地查询集合
- **接地查询**：Q_h = {(probe_type, expected_signature, cost)}，如 (低幅扫掠, 摩擦系数∈[μ_lo, μ_hi], B_probe)
- **投机缓存**：C_cache: key(I_vis, D_dlg) → P_prop，命中则 O(1) 返回，避免重复调用
- **核心约束（分离原则）**：P_prop **永不直接写入 EEIS/ERTC**；只能进入验证队列 `VerifyQueue`。MLLM 的权限是「提名」，不是「任命」。

**定义 162（接地验证器 GV）** G = (G_phys, G_feas, G_evid, τ_g)。对提议 h：
- **物理一致性**：G_phys(h) ⟺ log P(T_ft | π_scene^h) ≥ τ_phys
- **阻抗可行性**：G_feas(h) ⟺ π_scene^h ∩ K_safe_base ≠ ∅ ∧ K_safe^scene(h) ≠ ∅
- **证据一致性**：G_evid(h) ⟺ 与 EV-exec 历史不矛盾（复用第 60 轮 SIC 三元校验）
- **接地证书**：Cert_g(h) = (h, G_phys, G_feas, G_evid, hash(EV-support), timestamp)
- **三态判定**：G_phys ∧ G_feas 失败 ⇒ `REPROBE`（下 Q_h 主动探测）；G_evid 失败 ⇒ `REFUTE`（语义与历史冲突，拒绝）；三项全过 ⇒ `GROUNDED`
- 只有 `Cert_g.status = GROUNDED` 的提议才可交给 SERC。

**定义 163（用户体验预算 UXB）** B_ux = (B_resp, B_pred, B_trust, B_auth, B_rec)，五维体验度量：
- **响应感** R_resp = P(τ_response ≤ τ_ux_target)
- **可预测性** R_pred = 1 − H(a | context)/H_max（保留下限 R_pred ≥ ε_habit，避免完全可预测导致的僵化）
- **信任校准** R_trust = 1 − |c_h^shown − acc(h)|
- **控制权** R_auth = 1/(1 + C_takeover)，C_takeover 为人类接管所需操作成本
- **可恢复性** R_rec = P(错误被解释 ∧ 可回滚 | 错误发生)
- **体验预算**：B_ux 是五维配额向量；`EXECUTE(silent)` 消耗 B_trust，`CONFIRM` 消耗 B_resp/B_auth，`REPROBE` 消耗 B_resp。任一维 ≤ 0 ⇒ 触发体验降级策略（提高确认率、缩短延迟、显式解释）。

**定义 164（信任校准 TCA）** 令系统对提议 h 报置信度 c_h，实际准确率 acc(h)：
- **期望校准误差**：ECE = Σ_b (n_b/N)·|acc_b − conf_b|
- **过度信任风险**：R_over = P(采纳 h | c_h 高 ∧ acc(h) 低)
- **展示校准**：若 ECE > τ_ece，则 c_h^shown = (1−λ_u)·c_h + λ_u·c_prior，并置 `uncertain=True`，强制向用户显式提示不确定
- **仲裁约束**：c_h^shown < τ_confirm 或 `uncertain=True` ⇒ 不得 `EXECUTE(silent)`，只能 `CONFIRM` 或 `REPROBE`。

**定义 165（提议-验证-仲裁 PVA 循环）** 算子 PVA(M, ctx, ux_state)：
```
① Propose:  P_prop = Π.f_llm(ctx)                     # 低优先级认知线程，可缓存/可跳过
② Verify:   for h in P_prop: Cert_g(h) = G(h, EV-exec) # 只读执行证据，不写执行参数
③ Calibrate: c_h^shown, uncertain = TCA(c_h, ECE)
④ Arbitrate: a* = argmax_{a ∈ 𝒜} U(a; Cert_g, B_ux, c^shown)
   𝒜 = {EXECUTE(h), CONFIRM(h), REPROBE(h), DEGRADE(h)}
⑤ Act:      若 EXECUTE → 交给第 60 轮 SERC(h)；若 CONFIRM → 人机确认并消耗 B_ux
⑥ Bind:     写 EV-ux = (proposal_id, cert_g_hash, a*, reason_code, ux_cost, ts)
⑦ Return:   (a*, Cert_g, EV-ux, ΔB_ux)
```

**定义 166（UX-执行联合效用，安全为硬约束）** 对动作 a：
```
U(a) = w_s·Safety(a) + w_t·Task(a) + w_u·UX(a) − cost_llm(a)
UX(a)   = Σ_i β_i·R_i(a),  i ∈ {resp, pred, trust, auth, rec}
Safety(a) = P(SIC_valid | a) · (1 − R_over(a))
s.t.  Safety(a) ≥ S_min            # 硬约束：体验不得越过安全红线
      cost_llm(a) ≤ B_llm          # LLM 调用成本约束
```
**关键**：UX 只在安全可行域 `{a: Safety(a) ≥ S_min}` 内优化；任何「为提速而降低验证强度」的动作被硬约束直接排除。

**定义 167（五预算 PCE+++++）** B = (B_scene, B_intent, B_ros, B_exec, B_ux, B_llm)。其中：
- **B_llm** = (Token_budget, Latency_budget, Call_rate)
- **B_ux** = (B_resp, B_pred, B_trust, B_auth, B_rec)（定义 163）
- **耗尽策略**：B_llm 耗尽 ⇒ 仅用 C_cache + 第 60 轮封闭词表先验；B_ux 耗尽 ⇒ 最小打扰模式（只在高安全风险时 CONFIRM）；其余沿用第 60 轮
- **单调性**：六维预算单调消耗，任一耗尽触发对应安全/体验策略，绝不出现「预算为负仍静默执行」。

**定义 168（交互证据链 EV-ux）** EV-ux = (proposal_id, cert_g_hash, action, reason_code, ux_cost, timestamp)，与结果证据链 EV-exec 通过 `proposal_id` **双向绑定**：
- **正向**：语义提议 → 执行证据（证明「我说的」被执行了，拦截「只说不做」）
- **反向**：执行证据 → 语义提议（证明「我做的」符合「我说的」，拦截「说一套做一套」）
- **绑定不变式**：任一进入 SERC 的语义，必须存在 Cert_g 与至少一条 EV-exec 的哈希匹配；否则整段交互标记为 `UNBACKED`，进入审计。

## 2. 关键算法伪代码

### IP-161 MVSP（多模态可验证提议器）

```python
class MultimodalVerifiableProposer:
    def __init__(self, llm, cache, token_budget=4096, tau_cache=0.9):
        self.llm = llm
        self.cache = cache
        self.token_budget = token_budget
        self.tau_cache = tau_cache
        self.used_tokens = 0

    def propose(self, I_vis, T_ft, D_dlg, E_hist):
        key = self._cache_key(I_vis, D_dlg)
        hit = self.cache.get(key)
        if hit is not None and hit.similarity >= self.tau_cache:
            return hit.props                      # 投机缓存命中，O(1)
        if self.used_tokens >= self.token_budget:
            return []                             # B_llm 耗尽：交回封闭词表先验
        prompt = self._grounding_prompt(T_ft, D_dlg, E_hist)  # 强制 JSON schema
        raw = self.llm.generate(prompt, images=I_vis)         # 低优先级认知线程
        props = self._parse_proposals(raw)        # 每项: scene,intent,pi,c,Q
        self.used_tokens += raw.token_count
        self.cache.put(key, props)
        return props

    def _grounding_prompt(self, T_ft, D_dlg, E_hist):
        return (
            "只输出 JSON 数组，每项含 scene(开放词表)、intent、"
            "impedance_prior(mu,Sigma)、confidence∈[0,1]、"
            "grounding_queries[(probe,expected,cost)]。"
            "禁止输出任何直接控制参数。"
        )
```

### IP-162 GV（接地验证器）

```python
class GroundingVerifier:
    def __init__(self, eeis, sic, tau_phys=0.6):
        self.eeis = eeis
        self.sic = sic
        self.tau_phys = tau_phys

    def verify(self, h, ev_exec):
        phys = self._loglik(h.pi_scene, h.observations)
        feas = self.eeis.intersect_nonempty(h.pi_scene, self.eeis.K_safe_base)
        evid = not self.sic.contradicts(h.scene, ev_exec)
        if phys < self.tau_phys or not feas:
            return Cert(status='REPROBE', queries=h.queries)
        if not evid:
            return Cert(status='REFUTE', reason='证据与语义冲突')
        support = self._hash_support(h, ev_exec)
        return Cert(status='GROUNDED', support_hash=support,
                    checks=(phys, feas, evid))
```

### IP-163 UXB（用户体验预算）

```python
class UXBudget:
    def __init__(self, resp=1.0, pred=1.0, trust=1.0, auth=1.0, rec=1.0):
        self.b = dict(resp=resp, pred=pred, trust=trust, auth=auth, rec=rec)

    def cost(self, action):
        if action.kind == 'EXECUTE_SILENT':
            return {'trust': 0.05, 'pred': 0.0}
        if action.kind == 'CONFIRM':
            return {'resp': 0.20, 'auth': 0.05}
        if action.kind == 'REPROBE':
            return {'resp': 0.10, 'trust': 0.02}
        return {}

    def apply(self, action):
        for k, v in self.cost(action).items():
            self.b[k] = max(0.0, self.b[k] - v)

    def exhausted(self):
        return any(v <= 0.0 for v in self.b.values())

    def minimal_intrusion(self):
        self.b['resp'] = max(self.b['resp'], 0.3)   # 降级为最小打扰模式
        return 'minimal_intrusion'
```

### IP-164 TCA（信任校准）

```python
class TrustCalibrator:
    def __init__(self, tau_ece=0.10, lam=0.5):
        self.tau_ece = tau_ece
        self.lam = lam
        self.bins = defaultdict(lambda: [0, 0])   # conf_bin -> [n, n_correct]

    def update(self, c_h, correct):
        b = int(c_h * 10) / 10
        self.bins[b][0] += 1
        self.bins[b][1] += int(correct)

    def ece(self):
        n = sum(v[0] for v in self.bins.values()) or 1
        return sum(v[0] / n * abs(v[1] / max(v[0], 1) - b)
                   for b, v in self.bins.items())

    def calibrate(self, c_h, c_prior):
        if self.ece() > self.tau_ece:
            return (1 - self.lam) * c_h + self.lam * c_prior, True
        return c_h, False
```

### IP-165 PVA（提议-验证-仲裁循环）

```python
def propose_verify_arbitrate(M, ctx, ux_state):
    props = M.mvsp.propose(ctx.vision, ctx.ft, ctx.dialog, M.ev_hist)

    grounded = []
    for h in props:
        cert = M.gv.verify(h, M.ev_exec[-1])
        if cert.status == 'GROUNDED':
            c_shown, uncertain = M.tca.calibrate(h.conf, M.c_prior)
            grounded.append((h, cert, c_shown, uncertain))

    if not grounded:
        return 'DEGRADE', None            # 无可接地提议：退回第 60 轮先验/封闭词表

    actions = []
    for h, cert, c_shown, uncertain in grounded:
        if uncertain or c_shown < M.tau_confirm:
            actions.append(('CONFIRM', h))
        else:
            actions.append(('EXECUTE', h))

    def utility(a):
        kind, h = a
        safety = M.sic.valid_prob(h) * (1 - M.tca.over_trust_risk(h))
        if safety < M.S_min:              # 安全硬约束：直接排除
            return -float('inf')
        return M.w_s * safety + M.w_t * M.task_gain(h) + M.w_u * M.ux_score(kind, h)

    best = max(actions, key=utility)
    M.ux_budget.apply(best)
    ev_ux = bind_evidence(best, M.ev_exec[-1], M.ux_budget.snapshot())
    M.ev_ux.append(ev_ux)

    if best[0] == 'EXECUTE':
        return scenario_perception_evolution_loop(
            M, M.current_cp, best[1].intent, M.delta_f_req)
    return best[0], best[1]               # CONFIRM / REPROBE
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| MVSP | O(1) 缓存命中 / O(L) LLM 推理 | O(|cache| + |P_prop|) | 提议永不直达执行；B_llm 耗尽退化封闭词表 |
| GV | O(N) 每提议 | O(N) | 三态判定，误接地率 ≤ α |
| UXB | O(1) 记账 | O(1) | 体验预算单调非负 |
| TCA | O(1) 校准 / O(B) 统计 ECE | O(B=10) | ECE ≤ τ_ece 时展示置信度偏差 ≤ τ_ece |
| PVA | O(闭环 + 提议数) | 复用 | 安全硬约束 Safety ≥ S_min 不被 UX 突破 |

**正确性定理（PVA-Safety）**：
假设 A22–A69 成立；**(A66)** GV 三重验证 sound：Cert_g = GROUNDED ⇒ π_scene^h ⊆ K_safe_base ∧ 与 EV-exec 不矛盾（概率 ≥ 1−α）。**(A67)** TCA 校准：ECE ≤ τ_ece 时，|c_h^shown − acc(h)| ≤ τ_ece。**(A68)** UX 不越安全线：Safety(a) ≥ S_min 为硬约束，U(a) 的优化域严格限于安全可行域。**(A69)** 六预算单调消耗，任一耗尽触发对应策略。

则：
1. **语义接地性**：任一 `EXECUTE` 动作都存在 Cert_g = GROUNDED 与哈希匹配的 EV-exec；未接地语义无法进入 SERC。
2. **信任真实性**：系统展示置信度与实际准确率偏差 ≤ τ_ece；超出则强制 CONFIRM，抑制过度信任。
3. **体验不侵蚀安全**：UX 仅在 `{a: Safety(a) ≥ S_min}` 内优化，任何降低验证强度的动作被硬约束排除。
4. **慢回路隔离**：MLLM 始终运行在低优先级认知线程，执行线程只消费已接地证书，`B_llm` 耗尽即回退封闭词表。
5. **证据双向绑定**：EV-ux 与 EV-exec 通过 proposal_id 双向绑定，消除「说一套做一套」与「只说不做」。

### IP-161 MVSP（多模态可验证提议器）

```python
class MultimodalVerifiableProposer:
    def __init__(self, llm, cache, token_budget=4096, tau_cache=0.9):
        self.llm = llm
        self.cache = cache
        self.token_budget = token_budget
        self.tau_cache = tau_cache
        self.used_tokens = 0

    def propose(self, I_vis, T_ft, D_dlg, E_hist):
        key = self._cache_key(I_vis, D_dlg)
        hit = self.cache.get(key)
        if hit is not None and hit.similarity >= self.tau_cache:
            return hit.props                      # 投机缓存命中，O(1)
        if self.used_tokens >= self.token_budget:
            return []                             # B_llm 耗尽：交回封闭词表先验
        prompt = self._grounding_prompt(T_ft, D_dlg, E_hist)  # 强制 JSON schema
        raw = self.llm.generate(prompt, images=I_vis)         # 低优先级认知线程
        props = self._parse_proposals(raw)        # 每项: scene,intent,pi,c,Q
        self.used_tokens += raw.token_count
        self.cache.put(key, props)
        return props

    def _grounding_prompt(self, T_ft, D_dlg, E_hist):
        return (
            "只输出 JSON 数组，每项含 scene(开放词表)、intent、"
            "impedance_prior(mu,Sigma)、confidence∈[0,1]、"
            "grounding_queries[(probe,expected,cost)]。"
            "禁止输出任何直接控制参数。"
        )
```

### IP-162 GV（接地验证器）

```python
class GroundingVerifier:
    def __init__(self, eeis, sic, tau_phys=0.6):
        self.eeis = eeis
        self.sic = sic
        self.tau_phys = tau_phys

    def verify(self, h, ev_exec):
        phys = self._loglik(h.pi_scene, h.observations)
        feas = self.eeis.intersect_nonempty(h.pi_scene, self.eeis.K_safe_base)
        evid = not self.sic.contradicts(h.scene, ev_exec)
        if phys < self.tau_phys or not feas:
            return Cert(status='REPROBE', queries=h.queries)
        if not evid:
            return Cert(status='REFUTE', reason='证据与语义冲突')
        support = self._hash_support(h, ev_exec)
        return Cert(status='GROUNDED', support_hash=support,
                    checks=(phys, feas, evid))
```

### IP-163 UXB（用户体验预算）

```python
class UXBudget:
    def __init__(self, resp=1.0, pred=1.0, trust=1.0, auth=1.0, rec=1.0):
        self.b = dict(resp=resp, pred=pred, trust=trust, auth=auth, rec=rec)

    def cost(self, action):
        if action.kind == 'EXECUTE_SILENT':
            return {'trust': 0.05, 'pred': 0.0}
        if action.kind == 'CONFIRM':
            return {'resp': 0.20, 'auth': 0.05}
        if action.kind == 'REPROBE':
            return {'resp': 0.10, 'trust': 0.02}
        return {}

    def apply(self, action):
        for k, v in self.cost(action).items():
            self.b[k] = max(0.0, self.b[k] - v)

    def exhausted(self):
        return any(v <= 0.0 for v in self.b.values())

    def minimal_intrusion(self):
        self.b['resp'] = max(self.b['resp'], 0.3)   # 降级为最小打扰模式
        return 'minimal_intrusion'
```

### IP-164 TCA（信任校准）

```python
class TrustCalibrator:
    def __init__(self, tau_ece=0.10, lam=0.5):
        self.tau_ece = tau_ece
        self.lam = lam
        self.bins = defaultdict(lambda: [0, 0])   # conf_bin -> [n, n_correct]

    def update(self, c_h, correct):
        b = int(c_h * 10) / 10
        self.bins[b][0] += 1
        self.bins[b][1] += int(correct)

    def ece(self):
        n = sum(v[0] for v in self.bins.values()) or 1
        return sum(v[0] / n * abs(v[1] / max(v[0], 1) - b)
                   for b, v in self.bins.items())

    def calibrate(self, c_h, c_prior):
        if self.ece() > self.tau_ece:
            return (1 - self.lam) * c_h + self.lam * c_prior, True
        return c_h, False

    def over_trust_risk(self, h):
        b = int(h.conf * 10) / 10
        n, ok = self.bins.get(b, [1, 0])
        return max(0.0, h.conf - ok / max(n, 1))
```

### IP-165 PVA（提议-验证-仲裁循环）

```python
def propose_verify_arbitrate(M, ctx, ux_state):
    props = M.mvsp.propose(ctx.vision, ctx.ft, ctx.dialog, M.ev_hist)

    grounded = []
    for h in props:
        cert = M.gv.verify(h, M.ev_exec[-1])
        if cert.status == 'GROUNDED':
            c_shown, uncertain = M.tca.calibrate(h.conf, M.c_prior)
            grounded.append((h, cert, c_shown, uncertain))

    if not grounded:
        return 'DEGRADE', None            # 无可接地提议：退回第 60 轮先验/封闭词表

    actions = []
    for h, cert, c_shown, uncertain in grounded:
        if uncertain or c_shown < M.tau_confirm:
            actions.append(('CONFIRM', h))
        else:
            actions.append(('EXECUTE', h))

    def utility(a):
        kind, h = a
        safety = M.sic.valid_prob(h) * (1 - M.tca.over_trust_risk(h))
        if safety < M.S_min:              # 安全硬约束：直接排除
            return -float('inf')
        return M.w_s * safety + M.w_t * M.task_gain(h) + M.w_u * M.ux_score(kind, h)

    best = max(actions, key=utility)
    M.ux_budget.apply(best)
    ev_ux = bind_evidence(best, M.ev_exec[-1], M.ux_budget.snapshot())
    M.ev_ux.append(ev_ux)

    if best[0] == 'EXECUTE':
        return scenario_perception_evolution_loop(
            M, M.current_cp, best[1].intent, M.delta_f_req)
    return best[0], best[1]               # CONFIRM / REPROBE
```

### IP-168 EV-ux（交互证据链绑定）

```python
def bind_evidence(action, ev_exec, ux_snapshot):
    kind, h = action
    cert = h.cert
    assert cert.status == 'GROUNDED', '未接地语义禁止绑定执行证据'
    assert cert.support_hash in ev_exec.support_hashes or cert.checks_valid()
    return {
        'proposal_id': h.id,
        'cert_g_hash': cert.digest(),
        'action': kind,
        'reason_code': h.reason,
        'ux_cost': ux_snapshot,
        'ev_exec_hash': ev_exec.digest(),
        'timestamp': time.time(),
        'backed': True,
    }
```

| EV-ux | O(1)/条 | O(链长) | 语义-证据双向绑定，未接地禁止执行 |

**正确性定理（PVA-Safety）**：
若 A66–A69 成立，则：
1. 任一 `EXECUTE` 动作均存在 `GROUNDED` 证书与哈希匹配的 EV-exec ⇒ **语义可接地**。
2. 展示置信度与实际准确率偏差 ≤ τ_ece，超出强制 `CONFIRM` ⇒ **信任可校准**。
3. UX 仅在 `{a: Safety(a) ≥ S_min}` 内优化 ⇒ **体验不侵蚀安全**。
4. MLLM 运行于低优先级认知线程，`B_llm` 耗尽回退封闭词表 ⇒ **慢模型不进快回路**。
5. EV-ux 与 EV-exec 通过 proposal_id 双向绑定 ⇒ **无「说一套做一套」/「只说不做」**。
