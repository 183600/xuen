### 第 8 轮灵感驱动研究记录

**灵感词**：数据采集、移动底盘

**继承关系**：第 7 轮 CADVS-v7（IP-501~IP-504）把系统从「指令响应」推进到「需求推导」，用 DIM/DRC/DAC 与 η_demand 把用户意图纳入软评分链。但 v7 仍有两个未触及的前提：其一，移动底盘被 MCTM 当作「静态拓扑查询器」，底盘只是约束的来源，而不是可主动调用的自由度；其二，所有记忆、原型与阈值都被默认为「已经给定的数据」，系统从不追问「这些数据够不够、从哪来、能否审计」。本轮以「数据采集 × 移动底盘」为轴，提出**移动即采集（Mobility-as-Acquisition）**：把底盘的位移同时视为（a）扩大操作可达域的自由度、（b）降低认知不确定性的主动测量动作；并用「底盘可达-稳定包络」与「数据充分性」两个新的质量因子把它们接入软评分链。与此同时，本轮修正 v7 的一个结构性缺陷：v7 一方面声称 η_j ≥ 1、Π_factor ∈ [1,1.3]，另一方面又定义 η_affect ∈ [2/3,4/3]，导致「软因子既收紧又放松」的单调性自相矛盾。本轮改用「质量因子 φ_j ∈ (0,1] + 保守乘子 t_j = 1+ε(1−φ_j)」的对偶表示，使 fail-closed 第一次可以被严格证明。

**直觉与动机**：

1. **数据采集 → 从「被动记忆」到「主动测量」**。v7 的 LMEM/DIM 假设历史数据足以推断需求，但真实移动操作中大量不确定性其实是**可消除的认知不确定性**（epistemic uncertainty）：没见过这个杯子、没看过柜子背面、没试过这条抓取。关键洞见：**把「再走一步、再看一眼、再试一次」当作一种合法动作**——它的收益是信息增益，成本是时间、能耗与风险。设计「主动数据采集核」(ADAK)：用集成分歧或密度 OOD 分数估计不确定性 U，用「底盘移动到新视点」或「轻触探测」来降低 U；只有当 U 足够低（数据充分）时才允许进入抓取/放置。

2. **移动底盘 → 从「静态拓扑查询」到「可达-稳定包络上的主动放置」**。v6 的 MCTM 只回答「当前位置连通吗」。关键洞见：**底盘位置本身是一个待优化变量**——同一目标，从不同基座位置出发，机械臂的可达性、奇异位形、支撑多边形稳定裕度、避障间隙都不同。设计「底盘可放置包络」(BAE)：BAE 是 SE(2) 上满足「臂可达 ∧ 稳定裕度 ≥ m_min ∧ 拓扑可达 ∧ 无碰撞」的基座位姿集合；再设计「底盘放置规划器」(BPP) 在 BAE 内最大化任务质量，而不是只最大化信息增益。这把底盘从「约束」变成「解的一部分」。

3. **两者的耦合 → 采集与放置争夺同一个底盘自由度**。关键洞见：**一次底盘移动既可能提升抓取可达性（任务收益），也可能只是换视角（信息收益）**，因此不能各算各的，必须联合优化：J(p_base) = λ_task·Q_task(p_base) + λ_info·IG(p_base) − λ_cost·Cost(p_base)，约束 p_base ∈ BAE，且采集尝试有有限预算 B 与明确终止条件。

**关键洞见**：第 7 轮回答「如何推导用户真正要什么」；第 8 轮回答「当系统不知道、也够不着时，如何用底盘主动去『知道』和『够到』，同时不破坏 fail-closed」。七硬门 kc_evidence_forged_v5 记号原样复用，**不新增硬门**；本轮新增仅为软质量因子与底盘决策层：
- IP-505 BAE（底盘可达-稳定包络），
- IP-506 BPP（底盘放置规划器），
- IP-507 ADAK（主动数据采集核），
- IP-508 DPL（数据采集溯源账本），
- IP-509 EFA-v8（质量因子-保守乘子对偶表示 + 软链扩展）

**形式化目标（增量）**：

1. **BAE（Base Affordance Envelope）**：给定目标抓取位姿 g、地图 M、地形 T，
   - BAE(g) = { p ∈ SE(2) : Reach_arm(p,g) ∧ m_stab(p,T) ≥ m_min ∧ p ∈ Conn(M,p_now) ∧ Clear(p,M) ≥ d_min }
   - m_stab 为支撑多边形内的最小稳定裕度（ZMP/重心投影余量）；Reach_arm 为逆可达性的保守布尔化；Conn 为 MCTM 上的拓扑可达；Clear 为最小障碍间隙。
   - 质量因子 φ_base(p) = clip(min(1, m_stab/m_ref, Clear/d_ref), 0, 1] ∈ (0,1]。

2. **BPP（Base Placement Planner）**：
   - p_base* = argmax_{p ∈ BAE(g)} J(p)，J = λ_task·Q_task(p) + λ_info·IG(p) − λ_cost·Cost(p)
   - Q_task(p) 为从 p 出发的 FMPP 候选的最大 ECS_v6（廉价代理：可达裕度 × 稳定裕度）
   - IG(p) = U(θ|D) − E_{z∼p(z|p)}[U(θ|D∪{z})]，用不确定性模型的方差近似其期望熵减
   - 离散化：SE(2) 上 0.1 m × 0.1 m × 5° 栅格 + 局部 refine。

3. **ADAK（Active Data Acquisition Kernel）**：
   - 不确定性：U = α·Var_ensemble(FMPP) + (1−α)·OOD_density(z)
   - 触发：若 U > τ_U 且 max_{p∈BAE} IG(p)/Cost(p) ≥ ρ，则执行「采集机动」：底盘移动到 p*（该运动本身须先通过七硬门），采集样本 z，经 DPL 校验后写入 LMEM 并更新原型；预算 B 次。
   - 数据质量因子 φ_data = exp(−U/U_ref) ∈ (0,1]；φ_data 越高表示数据越充分。
   - 终止：U ≤ τ_U、或预算耗尽、或 IG 边际收益 < ρ_min；耗尽则回退到 v7 保守提议并标记「数据不足」。

4. **DPL（Data Provenance Ledger）**：
   - 每条样本 e = (id, sensor, pose, base_pose, t, model_version, consent, h=H(prev,e))
   - 追加式哈希链；只有通过签名校验且 consent=True 的样本可进入原型更新；支持审计与回放。
   - 目的：阻断「自生成数据污染 → 自指博弈」的静默回路（对应 R57），并为采集数据的可复现性提供证书。

5. **EFA-v8（质量因子-保守乘子对偶表示）**：
   - 质量因子 φ_j ∈ (0,1]（越大越好）：φ_g, φ_topo, φ_interp, φ_cmd, φ_demand, φ_affect, φ_base, φ_data
   - 聚合 φ = ∏_j φ_j ∈ (0,1]；保守乘子 t = 1 + ε·(1−φ)，ε=0.3 ⇒ t ∈ [1,1.3]
   - 软评分 ECS_v8 = ECS_v6 · φ；硬门阈值 τ_i^v8 = γ_i·τ_i^v6·t
   - 关键性质：φ ≤ 1 ⇒ ECS 不升且 τ 不降 ⇒ Exec_v8 ⊆ Exec_v6（严格 fail-closed）；v7 的 η_affect<1 反例被消除。

6. **形式化定义（联合决策）**：给定指令 L、目标 g、记忆 M，
   - 由 v7 得 ρ_demand、η_demand；
   - 由 BAE(g) 与 BPP 得 p_base* 与 φ_base；
   - 由 ADAK 得 U、φ_data 与「是否采集」；
   - 若 U > τ_U 且预算未耗尽：执行采集机动 → 更新 DPL/LMEM → 重算；
   - 否则在 p_base* 处执行 EFA-v7 提议，并以 φ = φ_v7·φ_base·φ_data、t = 1+ε(1−φ) 接入七硬门；
   - 全程不新增硬门，只收紧。

**本轮最大风险**：**认知不确定性被误当作任务风险**——ADAK 用 U 触发底盘采集，但 U 混淆了「可消除的认知不确定性」与「不可消除的偶然不确定性」：对后者，采集永远降不下 U，系统可能在预算内反复移动却一无所获，形成「采集—仍不确定—再采集」的活锁，并在移动过程中持续消耗安全与时间预算；BAE 虽保证单步稳定，却无法保证「为采集而移动」在任务层面是值得的。

### 0.3 结构性修正：从「η 双义」到「φ / t 对偶」

v7 存在一个未被点破的单调性矛盾：它一边声明「η_j ≥ 1、Π_factor ∈ [1,1.3]、软因子只收紧」，一边又定义 η_affect = 1 + affect/3 ∈ [2/3, 4/3]。当 affect < 0 时 η_affect < 1，Π_factor 可能 < 1，阈值被**放松**，执行集扩张，直接破坏 fail-closed 声明。

v8 把「一个 η 同时承担『评分』与『阈值』两种语义」拆成两个单调一致的对象：

- **质量因子** φ_j ∈ (0,1]：越大越好，进入评分 ECS_v8 = ECS_v6 · ∏φ_j；
- **保守乘子** t_j = 1 + ε·(1−φ_j) ∈ [1,1+ε]：φ_j 越小（质量越差）阈值越严，进入 τ_i^v8 = γ_i·τ_i^v6·∏t_j。

两者由同一 φ_j 单调耦合，从而「质量差 ⇒ 分数降 + 阈值升」方向一致。取 ε=0.3 时 ∏t_j ≤ 1+ε（因每个 t_j ≤ 1+ε 且聚合时以单一 φ=∏φ_j 计算 t，见 §1 定义 2411）。这为定理 13 的严格证明铺路。

## 2. 关键算法骨架

### IP-505 BAE：底盘可达-稳定包络

```python
@dataclass
class BaseAffordanceEnvelope:
    """BAE：SE(2) 上满足 可达 ∧ 稳定 ∧ 连通 ∧ 无碰撞 的底盘位姿集合。
    只提供查询，不做决策；决策交给 BPP。"""
    arm: ArmKinematics
    mctm: MobileChassisTopologyMap
    stability: StabilityModel
    m_min: float = 0.15
    d_min: float = 0.05
    m_ref: float = 0.25
    d_ref: float = 0.30
    grid: tuple = (0.1, 0.1, math.radians(5.0))

    def contains(self, p: SE2, g: Pose, M: Map, T: Terrain) -> bool:
        return (self.arm.reachable(p, g)
                and self.stability.margin(p, T) >= self.m_min
                and self.mctm.connected(self.mctm.current, p)
                and self.mctm.clearance(p, M) >= self.d_min)

    def quality(self, p: SE2, g: Pose, M: Map, T: Terrain) -> float:
        m = self.stability.margin(p, T)
        c = self.mctm.clearance(p, M)
        return float(np.clip(min(1.0, m / self.m_ref, c / self.d_ref), 0.0, 1.0))

    def enumerate(self, g: Pose, M: Map, T: Terrain) -> list[SE2]:
        return [p for p in self._grid(M, self.grid)
                if self.contains(p, g, M, T)]
```

### IP-506 BPP：底盘放置规划器

```python
@dataclass
class BasePlacementPlanner:
    """BPP：在 BAE 内联合优化 任务收益 + 信息增益 − 代价。"""
    bae: BaseAffordanceEnvelope
    fmpp: FlowMatchingProposalPolicyKernel
    v6: EvidenceForgingAssemblerV6
    lam: tuple = (1.0, 0.3, 0.2)   # (task, info, cost)

    def place(self, g: Pose, M: Map, T: Terrain, context) -> tuple[SE2 | None, float]:
        cands = self.bae.enumerate(g, M, T)
        if not cands:
            return None, 0.0
        best_p, best_j = None, -float('inf')
        for p in cands:
            q_task = self._task_value(p, g, context)
            ig = self._info_gain(p, context)
            cost = self._cost(p, context)
            j = self.lam[0] * q_task + self.lam[1] * ig - self.lam[2] * cost
            if j > best_j:
                best_p, best_j = p, j
        return best_p, self.bae.quality(best_p, g, M, T)

    def _task_value(self, p: SE2, g: Pose, context) -> float:
        ctx = build_ctx(context, base_pose=p, goal=g)
        cands = self.fmpp.propose(ctx, K=4)
        return max((self.v6.ecs_v6(x, ctx.n_flow, ctx.s_emo, ctx.eta) for x in cands),
                   default=0.0)

    def _info_gain(self, p: SE2, context) -> float:
        # 期望熵减的可微代理：当前均值不确定性 − 移动到 p 后的预测不确定性
        return float(context.uncertainty.mean() - context.uncertainty.predict_after(p))

    def _cost(self, p: SE2, context) -> float:
        return float(context.path_cost(self.bae.mctm.current, p)
                     + context.energy_weight * context.energy(p))
```

### IP-507 ADAK：主动数据采集核

```python
@dataclass
class ActiveDataAcquisitionKernel:
    """ADAK：把「底盘移动/探测」当作降低认知不确定性的动作。
    预算有限，预算耗尽必须放行并标记『数据不足』，禁止无限采集。"""
    fmpp: FlowMatchingProposalPolicyKernel
    lmem: LongTermMemoryEmbeddingConsolidation
    bpp: BasePlacementPlanner
    bae: BaseAffordanceEnvelope
    ledger: DataProvenanceLedger
    v6: EvidenceForgingAssemblerV6
    tau_u: float = 0.35
    rho: float = 0.10
    rho_min: float = 0.02
    u_ref: float = 0.5
    alpha: float = 0.5
    budget: int = 3
    budget_left: int = 3

    def uncertainty(self, context) -> float:
        var = float(self.fmpp.ensemble_variance(context))
        ood = float(self.lmem.density_ood(context.obs))
        return self.alpha * var + (1.0 - self.alpha) * ood

    def quality(self, u: float) -> float:
        return float(math.exp(-u / self.u_ref))

    def should_acquire(self, context) -> tuple[bool, SE2 | None, float]:
        u = self.uncertainty(context)
        phi_data = self.quality(u)
        if u <= self.tau_u or self.budget_left <= 0:
            return False, None, phi_data
        p_star, _ = self.bpp.place(context.goal, context.map, context.terrain, context)
        if p_star is None:
            return False, None, phi_data
        ig = self.bpp._info_gain(p_star, context)
        cost = self.bpp._cost(p_star, context) + 1e-6
        if ig / cost < self.rho or ig < self.rho_min:
            return False, None, phi_data
        return True, p_star, phi_data

    def acquire(self, p_star: SE2, context) -> Sample:
        # 采集机动本身必须通过七硬门（底盘轨迹也要 fail-closed）
        base_traj = self._base_traj(p_star, context)
        if not self.v6.gate(base_traj, context):
            self.budget_left = 0
            return None
        self.move_base(p_star)
        z = self.sensors.capture(context)
        rec = self.ledger.append(z, pose=context.pose, base_pose=p_star,
                                 model_version=context.model_version,
                                 consent=context.consent)
        if rec.verified and rec.consent:
            self.lmem.consolidate(z)       # 只有审计通过的样本才可更新原型
        self.budget_left -= 1
        return z
```

### IP-508 DPL：数据采集溯源账本

```python
@dataclass
class DataProvenanceLedger:
    """DPL：追加式签名哈希链。保证完整性/来源，不保证语义正确性。"""
    signer: Signer
    _head: str = "GENESIS"
    _log: list = field(default_factory=list)

    def append(self, sample: Sample, pose, base_pose, model_version, consent) -> Record:
        payload = dict(sensor=sample.sensor, pose=pose, base_pose=base_pose,
                       t=time.time(), model_version=model_version,
                       consent=bool(consent), h_prev=self._head)
        h = hashlib.sha256(canonical(payload) + sample.bytes).hexdigest()
        rec = Record(**payload, h=h, sig=self.signer.sign(h))
        self._log.append(rec)
        self._head = h
        return rec

    def verify_chain(self) -> bool:
        head = "GENESIS"
        for r in self._log:
            if r.h_prev != head:
                return False
            if not self.signer.verify(r.h, r.sig):
                return False
            head = r.h
        return True

    def replay(self) -> list[Record]:
        return [r for r in self._log if r.consent and self.signer.verify(r.h, r.sig)]
```

### IP-509 EFA-v8：七硬门 + φ/t 对偶软链

```python
@dataclass
class EvidenceForgingAssemblerV8:
    """EFA-v8：七硬门数量不变；用 φ/t 对偶替换 v7 的 η 链。"""
    v7: EvidenceForgingAssemblerV7
    bae: BaseAffordanceEnvelope
    bpp: BasePlacementPlanner
    adak: ActiveDataAcquisitionKernel
    ledger: DataProvenanceLedger
    epsilon: float = 0.3

    def select(self, L, t_now, context) -> tuple[bool, Trajectory | None, str]:
        # 0. 数据充分性 + 底盘放置（联合决策）
        need, p_star, phi_data = self.adak.should_acquire(context)
        if need:
            z = self.adak.acquire(p_star, context)
            if z is not None:
                return self.select(L, t_now, context.with_base(p_star))
            # 采集机动被硬门拒绝：预算清零后继续，绝不越过硬门去采集

        if p_star is not None:
            context = context.with_base(p_star)
        phi_base = self.bae.quality(context.base_pose, context.goal,
                                    context.map, context.terrain)

        # 1. 内层 v7 需求链（得到 φ_demand 等质量因子与候选 x）
        ok, x, tag = self.v7.select(L, t_now, context)
        if not ok:
            return False, None, tag

        # 2. 聚合质量因子与保守乘子（对偶）
        phi = context.phi_v7 * phi_base * phi_data
        t = 1.0 + self.epsilon * (1.0 - phi)

        # 3. 用收紧阈值复核七硬门：硬门数不变，只收紧
        if not self._refgate(x, context, t):
            return self._fallback(context, phi)
        return True, x, 'FORGED_CGE_V8'

    def ecs_v8(self, x, n_flow, s_emo, eta_factors, phi_base, phi_data) -> float:
        phi = eta_factors['phi'] * phi_base * phi_data
        return self.v7.v6.ecs_v6(x, n_flow, s_emo, eta_factors) * phi

    def _refgate(self, x, context, t) -> bool:
        for i in range(7):                      # 七硬门，数量不变
            if context.gate_score[i] < context.tau_v6[i] * t:
                return False
        return True

    def _fallback(self, context, phi):
        # 收紧后不通过：回到 v7 的保守提议并标记；不得放宽阈值
        return self.v7.select(None, context.t_now, context)
```

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 | 实时性指标 |

## 4. 正确性论证（增量更新）

### 定理 13（φ/t 对偶表示的 fail-closed 保持）

**陈述**：设质量因子 φ_j ∈ (0,1]，φ = ∏_j φ_j ∈ (0,1]，t = 1 + ε(1−φ) ∈ [1,1+ε]（ε=0.3）。定义 ECS_v8 = ECS_v6·φ，τ_i^v8 = γ_i·τ_i^v6·t，且七硬门判定函数不变。则对任意候选 x：

ECS_v8(x) ≥ τ_i^v8 ⟹ ECS_v6(x) ≥ γ_i·τ_i^v6，

即 Exec_CADVS-v8 ⊆ Exec_CADVS-v6（严格 fail-closed），并因此消除 v7 中 η_affect<1 造成的执行集扩张反例。

**证明**：由 φ ≤ 1 得 ECS_v8 = ECS_v6·φ ≤ ECS_v6；由 φ > 0 且 t = 1+ε(1−φ) ≥ 1 得 τ_i^v8 = γ_i·τ_i^v6·t ≥ γ_i·τ_i^v6。若 ECS_v8(x) ≥ τ_i^v8，则 ECS_v6(x) ≥ ECS_v8(x) ≥ τ_i^v8 ≥ γ_i·τ_i^v6。七硬门集合与判定规则不变，故 v8 通过者必通过 v6。v7 的 η_affect 可小于 1，使「阈值乘子」<1 而放松阈值；v8 的 t 由 φ≤1 保证恒 ≥1，矛盾不再出现。∎

### 定理 14（BAE 的可靠性）

**陈述**：若 p ∉ BAE(g)，则从 p 出发执行任何满足 v6 物理模型的轨迹，至少违反以下之一：(i) 机械臂不可达 g；(ii) 稳定裕度 m_stab(p,T) < m_min；(iii) 与 p_now 拓扑不连通；(iv) 与障碍间隙 < d_min。因此在 BAE 内放置底盘不会引入新的可达性/稳定性/碰撞违规。

**证明**：BAE 定义为四个谓词的合取；p ∉ BAE 即至少一个谓词为假，逐项对应 (i)–(iv)。BPP 只在 enumerate 返回的集合（即 BAE）内取值，故放置结果满足四谓词。可靠性的前提是 Reach_arm 取保守下界、m_stab 模型对实际支撑多边形不高估、MCTM 的 Conn/Clear 为保守近似；这些前提在诚实声明中列明。∎

### 定理 15（采集终止性 / 无活锁）

**陈述**：在单决策回合内，ADAK 的每次采集使 budget_left 严格减 1；当 budget_left = 0 或 U ≤ τ_U 或 IG/Cost < ρ 或 IG < ρ_min 时不再采集并放行。因此单回合采集次数 ≤ B，决策必然在有限步内终止，不会出现「采集—仍不确定—再采集」的无限循环。

**证明**：budget_left 初始为 B，只在 acquire 成功路径减 1，且 should_acquire 在 budget_left ≤ 0 时返回 False；其余三个终止条件为单调谓词，一旦成立即不再进入 acquire。递归调用 self.select 仅在 acquire 返回非空时发生，每次递归 budget_left 至少减 1，故递归深度 ≤ B。∎

**注意**：定理 15 只保证单回合有限，不保证「为采集而移动」在任务层值得——这是本轮最大风险的来源，见 §7。

### 诚实声明

- U 只是认知不确定性的**代理**：集成分歧可能与真实误差脱节（模型共同犯错时方差反而低），OOD 密度也可能把「罕见但正确」误判为「不确定」；偶然不确定性无法通过采集消除，却被 U 一并计入。
- IG 采用方差/线性化代理，非精确互信息；在强非线性（如透明、反光、可变形物体）下偏差较大。
- BAE 在离散 SE(2) 栅格上枚举，完备性只到栅格分辨率；栅格间的窄可行域可能被漏掉（保守方向，但会降低可用性）。
- DPL 只保证完整性与来源可追溯，**不保证语义正确、也不保证 consent 声明真实**；被签名污染的样本仍可能进入原型。
- 采集机动虽逐步通过七硬门，但七硬门是单步 fail-closed，**不刻画多次采集的累积风险**（能耗、时间、暴露）。
- BPP 的 λ_task/λ_info/λ_cost 权重敏感；权重选择本身缺乏原则性推导，需靠实验与红队调参。

  - 任务成功率、首次成功时间、采集次数、底盘移动能耗；

  - DPL 校验通过率、被阻断污染样本数、审计可回放率；
  - 活锁率（预算耗尽仍未降 U 的比例）、P99 控制延迟。

## 7. 本轮最大风险（最终确认）

**一句话**：**认知不确定性被误当作任务风险**——ADAK 用 U 触发底盘采集，但 U 混淆了「可消除的认知不确定性」与「不可消除的偶然不确定性」：对后者，采集永远降不下 U，系统可能在预算内反复移动却一无所获，形成「采集—仍不确定—再采集」的活锁，并在移动过程中持续消耗安全与时间预算；BAE 虽保证单步稳定，却无法保证「为采集而移动」在任务层面是值得的。
