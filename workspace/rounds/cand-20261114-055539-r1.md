# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「小样本学习」×「能耗优化」）

> R69 把不确定性一分为二，让 epistemic 歧义通过「看/问/触」主动消解，并用流似然做标定不可吸收的第二意见。但它留下两张未付的账单：
> (1) **标定的样本账单**：R69 的 MCG 要求模态权重 ECE 达标——这本身需要大量带标签标定数据，而部署现场恰恰是「新环境、零标签、只来得及问几次」。R69 用「不可信就退回 R68」回避了「如何在几次交互内变得可信」。
> (2) **交互的能量账单**：R69 的 VoI 只减物理/社交成本，完全无视 K 次采样、ODE 积分、Hutchinson 散度、轨迹聚类、主动模态对搜索所烧掉的**计算能量**。在无人机、可穿戴、野外机器人上，能量是比时延更硬的约束；R69 的「多采样—多交互」在能量紧张时会把安全环路饿死。
>
> 本轮两个灵感正好各补一张账单：
> - **小样本学习**：把每次交互看成一次 **episode**，维护极小的支持集与低秩适配器，让系统在 5–20 个交互内把「不可信」变成「有有限样本覆盖保证的可信」。校准从「一次性大标定」变成「持续 episodic 元学习」。
> - **能耗优化**：给每个计算块标价（焦耳），把 VoI 升级为**每焦耳信息增益**，用 anytime 调度 + 能量储备 + 摊销/回本，让「问不问、采几个样、跑不跑第二意见」都变成一笔能量投资。
>
> 更深一层：这两个灵感不是并列，而是**对偶**——few-shot 积累的知识会降低未来每步能耗（学会就不必多问、多采样），而能耗预算决定了你能买多少次 episode。于是涌现一个可检验的行为：**系统会自己学会停止提问**（interaction taper），把交互从「每次都要付的支出」变成「一次买断的资产」。
>
> 核心命题：**把 R69 的「交互消歧」重构为「能量预算下的 episodic 小样本校准」——用共形模态集给出有限样本覆盖保证，用低秩情景适配器把交互沉淀为可复用知识，用每焦耳 VoI + 摊销回本决定是否值得再问；安全关键路径由能量储备硬保护，退化序单调、永不弱于 R68。** 命名 **FRUGAL-RAS**（Few-shot, Resource-budgeted Uncertainty resolution via Active Learning）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这几焦耳，值不值得用来问，还是用来学会不再问**」。

## 0. 直觉与动机

**灵感 1（小样本学习 → 校准不是一个数据集，而是一串 episode）**
直觉：R69 的 ECE 门像一个「考试及格才准提问」的考官——可现场没有考场，只有零星几次提问机会。小样本学习说：别追求一次大标定，追求**从少数支持样本快速泛化**。把每个交互结果当成一个带标签 episode（观察 → 信息动作 → 结果 → 真实模态），系统就拥有一个不断增长的迷你支持集；每个新歧义都是 query。校准于是变成 episodic 任务：不是「我的权重全局准不准」，而是「在与我相似的历史 episode 上，我的模态集合覆盖没覆盖真值」。这天然适配共形预测（conformal）：它给的是**有限样本、分布无关的边际覆盖保证**，样本少只是集合变大，而不是保证消失——这正是 few-shot 需要的诚实契约。

**灵感 2（能耗优化 → 不确定性消解有焦耳价）**
直觉：R69 把不确定性当成「要不要踩刹车」，却没算「看清路况要多少电」。流策略的 K 采样、ODE、散度、聚类都是真实功耗；在电池驱动的具身系统里，这些功耗与推进/续航直接竞争。能耗优化给的不是一句「省电」，而是一套**预算化计算**：给每块计算贴价签，做边际收益/焦耳的贪心分配，紧张时按固定优先级优雅降级，并永远给安全路径留一笔不可挪用的储备。这把 R69 的「信息动作预算」扩展成完整的**能量预算**——信息动作的物理能耗、计算块的计算能耗、以及「多问一次导致后续更费电」的机会成本，统一进一个拉格朗日账本。

**灵感 3（对偶 → 交互是支出，也是资产）**
直觉：R69 每次交互都是「现付现结」的孤立成本；但人不是这样——被问过一次「左边还是右边」之后，下次遇到同类岔口会更快、更省。few-shot 适配器就是把交互沉淀成资产：每次 episode 更新一点低秩参数，未来需要更少的 K 采样、更少的提问。能耗优化则问一个投资问题：**这笔交互的能量，多久能回本？** 当适配器逐渐饱和，可学的边际价值趋零，「再问一次」的每焦耳收益跌破门槛，系统就会自发停止提问。这是本轮最可检验、也最优雅的涌现性质。

**灵感 4（正面回应 R69 最大风险 → 用共形替代点校准）**
直觉：R69 最怕「模态权重未校准却自信地追问幻影」。ECE 是点校准，需要大样本且假设同分布。共形预测换一个契约：不承诺「权重准」，只承诺「真模态落在我给的集合里，概率 ≥ 1−α」——哪怕模态权重很烂，只要非一致性分数可交换，覆盖仍成立（集合会变大，系统会因为集合太大而选择不交互/保守）。这把 R69 的「自信地错」改造成「诚实地宽」：不确定性从藏在权重里，变成摆在集合大小上。few-shot 正好匹配共形的少量样本性质。

**灵感 5（诚实的裂缝 → 省电 + 小样本会制造「被选择的确定性」）**
直觉：共形的覆盖是对**被查询分布**的边际保证。可交互学习有个内生偏差：你只给「你选择去问」的样本打标签。能耗优化又让「少问难题」在经济上更划算。于是系统可能只问容易的、只校准常见的、覆盖率漂亮，却把真正危险的稀有尾部永久留在未观测区——**它测到的确定性，恰是它选择去测的那部分确定性**。这不是可以忽略的工程细节，而是本轮方案最大的理论软肋，必须在设计里就放上对治（强制探索配额、倾向加权共形、非交换监测与回滚、尾部专用安全支持集），否则「省电」会变成「制造虚假自信」的流水线。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（FRUGAL-RAS 总览）** FRUGAL-RAS = (FMP, AUD, MINT-E, EAL, CMC, EBS, RAS-WM†)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i / R69 定义 293-i）：EAL 只产生「候选适配器版本」，实时路径只读**已认证的冻结快照** Δθ†；任何学习写都在安全窗口内异步完成。
(ii) **能量硬约束**：累计能耗 E(t)=∫P dτ ≤ E_max，瞬时功率 P_t ≤ P_max；其中 E_res 为不可挪用安全储备，效率性计算只能用 E_eff=E_max−E_res。
(iii) **覆盖契约与安全门**：任何驱动交互/效率决策的模态集合必须带 CMC 的 (1−α) 覆盖标记；适配器版本必须过 ASG；任一不满足 → 逐指令退化为 R69，再退化为 R68。

**定义 311（能量计量模型）** 计算块集合 B={ode, mode_head, cluster, fma, cia, upd, int}。块 b 单次能耗 e_b = α_b·FLOPs_b + β_b·MemB_b + γ_b（静态漏电/唤醒），由板上功率模型在线估计并以低频实测校准。瞬时功率 P_t = (Σ_b n_b(t)·e_b)/Δt_t；交互能量含机械执行能耗 e_mech(g) 与「等待/注视」的驻留能耗。目标不是精确到毫瓦，而是**可比较、可预算、可审计**的相对计价。

**定义 312（每焦耳 VoI / 能量 ROI）** R69 的 VoI(g)=H(M|o)−E[H(M|o,y)]。定义能量 ROI：
ρ(g) = [V_disc(g) + β·V_learn(g) − c_social(g)] / [e(g) + e_comp(g)]，
其中 e_comp 含「为了评估候选 g 而额外触发的采样/似然」能耗。选择 g*=argmax ρ(g) s.t. risk(g)≤ε_int 且预算可行；若 ρ(g*)≤ρ_min 或剩余能量<储备 → 不交互。R69 是「能量价格均一、β=0」的退化边界。

**定义 313（episode 与支持集）** 第 i 次交互产生 episode e_i=(φ(o_i), g_i, y_i, m_i*)，φ 为轻量特征（复用 z_t 的低维投影）。支持集 S_t={e_1..e_n}，容量 n≤n_max（常数内存，按相关性/年龄有界淘汰）。当前歧义状态为 query q_t。

**定义 314（低秩情景适配器 EAL）** 适配器 Δθ_t = U_t V_t^T，rank r≤r_max，作用于冻结主干的低秩旁路（模态先验 logits + 条件速度场的低秩修正）。更新：在 S_t 上做一步邻近（proximal）few-shot 损失下降，带范数约束 ‖Δθ‖_F ≤ δ_max、‖Δθ‖_2 ≤ σ_max。冻结副本 Δθ† 供实时路径读取；候选版本写入影子区，待 ASG 认证后原子换装（继承 R68 换装不变式）。

**定义 315（元目标：能耗-样本-风险三元）** max E[Σ_t R_task(s_t,a_t)] s.t. E[Σ_t e_t]≤E_max, N_int≤N_max, CVaR_β(risk)≤ε。拉格朗日形式 L = E[R_task] − λ_E·E[e] − λ_N·N_int − λ_R·CVaR，λ 由 EBS 在线对偶更新。该目标显式把「样本（交互次数）」和「能量」都当稀缺资源。

**定义 316（共形模态校准 CMC）** 对模态身份预测定义非一致性分数 s(q,m)=1−p̂(m|q)。用支持集（或独立标定集）取经验分位数 q̂=Quantile_{⌈(1−α)(1+1/n)⌉}({s_i})，模态集合 C_α(q)={m: s(q,m)≤q̂}。在可交换性下 P(M*∈C_α(q))≥1−α（有限样本、分布无关）。|C_α|=1 → 无歧义；|C_α| 大或含「低支持模态」→ 视为不可约，走 R68。CMC 取代 R69 的 ECE 点校准门：不要求权重准，只要求集合覆盖，且把不可信**显式表现为集合膨胀**。

**定义 317（覆盖-效率自适应 α）** α 由能量-风险控制器给出。系统维护两个覆盖层级：效率层 α_eff 由 E_eff 预算决定（能量越紧 α_eff 越大 → 集合越小 → 更少交互、更省）；安全层 α_safe（小 α，严格覆盖）由 E_res 保障、不可被效率预算挪用。能量紧时只收缩效率层，安全层保持不变。

**定义 318（适配器安全门 ASG）** 候选 Δθ 提升为 Δθ† 需同时满足：(i) 在留出 episode 上覆盖 ≥1−α_safe 且无安全违规；(ii) 范数/秩界满足；(iii) 影子评估：认证前缀上动作偏移上界 L_θ‖Δθ‖_F ≤ 认证裕度 m_cert（引理 21）。任一不满足 → 拒绝，保留旧版本并记入 AuditBuf。

**定义 319（能量预算调度 EBS / anytime）** 每步按「边际 VoI/焦耳」贪心分配计算给可分离块；能量紧张时按固定**退化序**：先停 CIA 主动模态对搜索 → 降 K（4→1）→ 停非安全触发的 FMA → 停交互 → 进入 R68 纯保守路径。安全相关 FMA（slow-fault 疑）与认证开销由 E_res 保障，不参与退化序。EBS 同时更新 λ_E 对偶，使长期能耗贴合预算。

**定义 320（能量储备与安全下限）** E_res = e_safety_loop·H_guard + e_cert·N_cert + e_rollback，其中 H_guard 为保障视界。效率性计算（多采样、CIA、交互、适配器评估）只能用 E_eff=E_max−E_res。断言 E_eff<0 ⇒ 直接进入 R68 最省电路径（仍满足安全）。这保证「没电」首先砍效率，永不砍安全。

**定义 321（能耗摊销与回本时间）** 一次交互/episode 的能耗 e_epi（含机械、计算、适配器评估）。若适配后每步期望节能 Δē，回本时间 T_pay=e_epi/Δē。交互/适配仅在 T_pay ≤ 剩余视界 H_rem 或即时风险下降主导时被采纳。Δē 由影子回放估计（复用 R69 的似然回放通道，额外开销记账）。

**定义 322（交互价值的二分：消歧 vs 学习）** V_disc(g) 沿用 R69（当前歧义的熵降）；V_learn(g)=E_{(q,m*)~S_held}[ℓ_meta(Δθ;S_t∪e(g)) − ℓ_meta(Δθ;S_t)]，即在留出 episode 上的元验证损失改善。总价值 = V_disc + β·V_learn，均按焦耳归一。V_learn 让系统偏爱「可复用」的提问（典型场景、边界样本），而非只解这一题的提问。

**定义 323（交换性/选择偏差监测 XSM）** 维护：(i) 覆盖追踪统计（滚动覆盖率的 CUSUM）；(ii) 查询倾向 π(g|q)（EBS/PEG 记录），用于**倾向加权共形** s_w(q,m)=s(q,m)/π̂(q) 的加权分位数；(iii) 分布漂移分数（支持集特征与当前 query 的 MMD）。任一越界 → 触发 α 膨胀、冻结适配器、回滚至上一认证版本，并强制安全支持集补采。诚实声明：无条件共形覆盖在非交换/选择偏差下失效；XSM 只能**检测并降级**，不能凭空恢复保证。

**定义 324（FRUGAL 证书 J_FRUGAL）** J_FRUGAL = (J_FLUID, coverage=1−α 及实测覆盖率, n_support, r, E_used/E_max, J_per_task, adapter_ver+hash, T_pay, xsm_stat, tail_support_size, exploration_ratio)。Valid ⇔ Valid(J_FLUID) ∧ 覆盖契约满足 ∧ 能耗 ≤ E_max ∧ 适配器经 ASG 认证 ∧ XSM 未报警（或已按规程回滚）。

**定义 325（能耗-样本-覆盖预算恒等式 / frugal 三难）** 一个视界内：E = N_int·e_epi + Σ_t [K_t·e_ode + 1_{FMA}·e_fma + e_cia + e_head] + N_upd·e_upd。覆盖保证随支持集有效样本 n_eff、α 与分布漂移变化，而 n_eff ≤ N_int。于是三者构成显式权衡：**在固定 E_max 下，覆盖（α 小）、交互次数（N_int）、适配器计算（r、更新频次）不能同时最大化**。这不是严格不可能定理，而是一条可计算的设计约束；EBS 的任务就是在这条预算面上找任务风险最小点。

**定义 326（FRUGAL 主闭环）** 见算法骨架 IP-264。

```python
# IP-265 EAL：低秩 few-shot 情景适配器（旁路冻结主干；实时只读快照）
class EpisodicAdapter:
    def __init__(self, trunk, r_max=4, n_max=32, delta_max=0.5):
        self.trunk, self.r_max, self.n_max, self.delta_max = trunk, r_max, n_max, delta_max
        self.S = Deque(maxlen=n_max)                  # 有界支持集
        self.U, self.V = zeros(d, r_max), zeros(d, r_max)   # 候选
        self.U_dag, self.V_dag = None, None           # 已认证冻结快照

    def observe(self, q, g, y, m_star):               # 一次交互 = 一个 episode
        self.S.append((self.phi(q), g, y, m_star))

    def propose_update(self):                         # 安全窗口内异步
        loss = few_shot_loss(self.trunk, self.U @ self.V.T, self.S)
        U, V = prox_step(loss, self.U, self.V, delta_max=self.delta_max)
        return AdapterCandidate(U, V, rank=self.r_max)

    def snapshot(self):                               # 推给实时路径的只读版本
        return (self.U_dag, self.V_dag)

# IP-266 CMC：共形模态集（有限样本覆盖；少样本只是集合变大）
def conformal_modes(p_hat, support_scores, alpha):
    n = len(support_scores)
    qhat = quantile(support_scores, ceil((1 - alpha) * (1 + 1 / n)))  # 有限样本校正
    return [m for m in modes if 1 - p_hat[m] <= qhat]                 # 集合而非点权重

# IP-267 MINT-E：每焦耳 VoI + 学习价值 + 回本
def choose_interaction_E(modes, q, energy, support, adapter):
    best = None
    for g in info_action_candidates(modes):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, q):
            continue
        v_disc  = entropy(modes) - expected_entropy(modes, g, q)
        v_learn = meta_validation_gain(adapter, support + [simulate(g)])
        e_g     = energy.mech(g) + energy.comp_for(g) + energy.upd_amortized()
        roi     = (v_disc + BETA * v_learn - cost_social(g)) / max(e_g, EPS)
        if best is None or roi > best.roi:
            best = (g, roi, e_g)
    if best is None or best.roi <= RHO_MIN:
        return None                                   # 不值得这几焦耳
    if not payback_ok(best.e_g, adapter, horizon_left()):
        return None                                   # 回不了本
    return best

# IP-268 EBS：anytime 能量分配 + 单调退化序
def energy_schedule(E_left, E_reserve, ambiguity, slow_suspect):
    E_eff = E_left - E_reserve
    if E_eff <= 0:
        return {"path": "R68_safe"}                   # 只保安全
    plan = {"cia": False, "K": 1, "fma": slow_suspect, "interact": False}
    if E_eff >= e_cia:                    plan["cia"] = True
    if E_eff >= e_K4 and ambiguity > TAU: plan["K"] = 4
    if E_eff >= e_int and plan["K"] == 4: plan["interact"] = True
    return plan                                       # 退化序固定 ⇒ 单调、无突变

    elif M.cmc.unsupported(Cset):
        U_epi = U_epi; plan["interact"] = False                   # 不可信 → 保守
    # 第二意见（仅当安全触发或能量 ROI 允许）
    a_hat = M.fma.flow_anomaly(...) if (plan["fma"] or M.energy.roi_ok_fma()) else None
    slow = a_hat is not None and a_hat > TAU_FMA and M.last_r_res < TAU_RES
    g = (M.mint_e.choose_interaction_E(modes, o, M.energy, M.eal.S, M.eal)
         if (U_epi > TAU_EPI and plan["interact"] and not slow) else None)
    if g is not None:
        y = M.cia.execute(g)
        M.eal.observe(o, g, y, M.cmc.resolve(modes, y))           # episode 入库
        U_epi = M.cia.update_belief(modes, y)
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    if slow:
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(...))
    # 异步：候选适配器 → ASG → 原子换装；XSM 可回滚
    M.eal.maybe_launch_update(M.energy.idle_window())
    M.asg.review_async(M.eal.latest_candidate(), M.xsm.stat())
    M.vqa_e.submit_async(g, U_epi, a_hat, plan, M.energy.ledger())
    return k, lam, M.select_mode(modes, U_epi, lam), (U_ale, U_epi)
```

## 3. 推导

**引理 19（每焦耳贪心的近似最优）** 若各计算块的边际 VoI 关于能量递减（diminishing returns）且块可分离，则按边际 VoI/焦耳贪心分配在 knapsack 约束下达到 (1−1/e) 近似；对固定交互次数的基数约束同样达到 1−1/e。系：EBS 的贪心 + 固定退化序在「递减收益」假设下既近似最优又可预测延迟。

**引理 20（少样本共形覆盖与集合膨胀）** 对可交换样本，split conformal 满足 P(M*∈C_α)≥1−α 对任意 n；但可实现的最小 α 粒度 ≥1/(n+1)，样本少时经验分位数波动 O(1/√n)，集合期望尺寸随 α↓ 与分布重叠度↑ 单调增。故「少样本」不破坏覆盖，只会**把不确定性从概率移到集合大小**。在查询倾向 π 已知的协变量偏移下，倾向加权共形（权重有界）可恢复边际覆盖。

**引理 21（有界适配器不越安全包络）** 若策略对适配器参数 L_θ-Lipschitz 且 ‖Δθ‖_F≤δ_max，则认证前缀上的动作偏移 ≤ L_θ·δ_max。若认证裕度 m_cert > L_θ·δ_max，则适配后前缀仍通过 C-RAS-WM，安全包络不变。故 ASG 只需核对这一个不等式 + 留出覆盖，即可在换装处保住 R68 的换装不变式。

**引理 22（摊销与自发停止提问）** 设 V_learn 对支持集大小 n 边际递减且最终饱和（有限秩/有限数据信息），则存在 n* 使 ρ(g*)<ρ_min；当 n≥n* 时 MINT-E 对一切 g 返回 None，交互次数趋于 0。且若 T_pay>H_rem，交互在任何 n 下都不被采纳。系：「学会停止提问」不是玄学，而是有限容量适配器 + 回本约束的必然；E308 可证伪。

**引理 23（选择偏差下的覆盖失效——诚实边界）** 若支持集只来自系统选择去问的区域 A（倾向 π(q)=P(ask|q)），则对全分布 D，朴素共形的覆盖 P_{q~D}(M*∈C) 可任意低于 1−α，缺口由 1/π 的重尾控制；只有在被查询分布 D_A 上才有 1−α。以 π≥π_floor 截断做倾向加权、或强制探索配额，才给出全分布的可审计界。系：能耗优化越倾向「只问便宜的」，这个缺口越大——所以 PEG 的探索配额与尾部安全支持集是**安全性而非效率性**组件。

**定理 18（FRUGAL 严格包含 FLUID 与 R68）** 在 ASG 认证、E_res 保障与可交换/已校正假设下：
(1) 取 E_max→∞（e 比价均一）、β=0、Δθ=0、α=α_MCG，则 FRUGAL 的决策类逐指令包含 R69 的 FLUID（CMC 退化为 MCG 门、MINT-E 退化为 MINT）；
(2) 再令 N_int=0，则退化为 R68；
(3) 对任意能量水平，安全相关决策（认证前缀、λ floor、slow-fault 处置）由 E_res 保障，风险 ≤ R68；
(4) 能量受限但非零时，FRUGAL 以 ≤ FLUID 的每任务焦耳达到 ≥ FLUID 的任务成功率（摊销收益），或在回本不划算时选择 R68 稳妥路径。
故 R69 与 R68 都是 FRUGAL 在「能量无限/交互关闭」边界上的严格退化，安全侧不做让步。

**定理 19（能量约束下安全退化的单调性与无突变）** EBS 的退化序固定且只移除效率块；E_res 使安全块始终有偿付能力；λ 随能量收紧单调不降；适配器换装受 ASG 单界约束。故能量衰减过程中控制连续、无突变，最坏退化为 R68（继承 R69 定理 17）。

## 6. 本轮最大风险

**一句话**：FRUGAL-RAS 的覆盖契约与能耗收益都建立在「支持集可交换且代表性足够」上，但交互天然只给系统**选择去问**的样本打标签、能耗优化又系统性偏好便宜的提问——**系统会学到一个自证清白、只覆盖「它愿意去测」的区域、而在真正危险的稀有尾部永久保持无知的校准**。

**次级风险与缓解**：
1. **非平稳导致共形覆盖失效** → XSM（覆盖 CUSUM + MMD）检测、α 膨胀、适配器冻结回滚（定义 323、E310）；
2. **选择偏差/尾部饿死** → PEG 探索配额 + 倾向加权共形 + 尾部安全支持集（不占效率预算）（引理 23、定义 317/323）；
3. **few-shot 过拟合或适配器投毒** → 低秩+范数界、ASG 留出验证、影子评估（定义 314/318、引理 21、E311）；
4. **能量模型误差导致预算击穿** → 在线功率模型 + 实测校准 + E_res 硬兜底（定义 311/320、E303/E306）；
5. **V_learn 估计器自欺**（元验证集与被查询分布同源）→ 独立留出集 + 周期性重采样 + 把它列为审计对象（定义 322/324）。

**一句话（结尾）**：越省电，越容易把「我没测到危险」误当成「没有危险」——FRUGAL-RAS 若不把探索配额与尾部安全支持集当作安全组件而非效率组件，它的「覆盖」就会成为一台精密的虚假自信生产机。

```python
# IP-265 EAL：低秩 few-shot 情景适配器（实时只读快照）
class EpisodicAdapter:
    def observe(self, q, g, y, m_star):
        self.S.append((self.phi(q), g, y, m_star))

    def propose_update(self):                        # 安全窗口内异步
        loss = few_shot_loss(self.trunk, self.U @ self.V.T, self.S)
        U, V = prox_step(loss, self.U, self.V, delta_max=self.delta_max)
        return AdapterCandidate(U, V, rank=self.r_max)

    def snapshot(self):                              # 实时路径读 (U_dag, V_dag)
        return (self.U_dag, self.V_dag)

# IP-266 CMC：共形模态集（有限样本覆盖）
def conformal_modes(p_hat, support_scores, alpha):
    n = len(support_scores)
    qhat = quantile(support_scores, ceil((1 - alpha) * (1 + 1 / n)))
    return [m for m in modes if 1 - p_hat[m] <= qhat]

# IP-267 MINT-E：每焦耳 VoI + 学习价值 + 回本
def choose_interaction_E(modes, q, energy, support, adapter):
    best = None
    for g in info_action_candidates(modes):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, q): continue
        v_disc  = entropy(modes) - expected_entropy(modes, g, q)
        v_learn = meta_validation_gain(adapter, support + [simulate(g)])
        e_g     = energy.mech(g) + energy.comp_for(g) + energy.upd_amortized()
        roi     = (v_disc + BETA * v_learn - cost_social(g)) / max(e_g, EPS)
        if best is None or roi > best.roi: best = (g, roi, e_g)
    if best is None or best.roi <= RHO_MIN: return None
    if not payback_ok(best.e_g, adapter, horizon_left()): return None
    return best

# IP-268 EBS：anytime 能量分配 + 单调退化序
def energy_schedule(E_left, E_reserve, ambiguity, slow_suspect):
    E_eff = E_left - E_reserve
    if E_eff <= 0: return {"path": "R68_safe"}
    plan = {"cia": False, "K": 1, "fma": slow_suspect, "interact": False}
    if E_eff >= e_cia:                    plan["cia"] = True
    if E_eff >= e_K4 and ambiguity > TAU: plan["K"] = 4
    if E_eff >= e_int and plan["K"] == 4: plan["interact"] = True
    return plan

# IP-264 主闭环：R69 + few-shot 校准 + 能量预算
def FRUGAL_RAS_round(M, obs):
```

## 4. 推导

**引理 19（每焦耳贪心近似最优）** 各计算块边际 VoI 关于能量递减且可分离时，按边际 VoI/焦耳贪心在 knapsack 约束下达 (1−1/e) 近似；固定交互次数的基数约束同样 1−1/e。系：EBS「贪心 + 固定退化序」既近似最优又可预测延迟。

**引理 20（少样本共形覆盖与集合膨胀）** 可交换样本下 split conformal 对任意 n 满足 `P(M*∈C_α)≥1−α`；最小 α 粒度 ≥`1/(n+1)`，经验分位数波动 `O(1/√n)`，集合尺寸随 `α↓` 与分布重叠度↑ 单调增。故少样本只把不确定性从概率**移到集合大小**，不破坏覆盖；倾向加权在已知 π 且有界权重下恢复边际覆盖。

**引理 21（有界适配器不越安全包络）** 策略 `L_θ`-Lipschitz 且 `‖Δθ‖_F≤δ_max` ⇒ 认证前缀动作偏移 `≤L_θ δ_max`。若 `m_cert>L_θ δ_max`，适配后前缀仍过 C-RAS-WM，安全包络不变。ASG 因此只需核验「这一不等式 + 留出覆盖」，保住 R68 换装不变式。

**引理 22（摊销与自发停止提问）** `V_learn` 对 n 边际递减并饱和（有限秩/有限数据信息）⇒ 存在 `n*` 使 `ρ(g*)<ρ_min`，`n≥n*` 时 MINT-E 对所有 g 返回 None，交互趋于 0；若 `T_pay>H_rem` 则任何 n 都不采纳。系：interaction taper 是有限容量适配器 + 回本约束的必然，E308 可证伪。

**引理 23（选择偏差下的覆盖失效——诚实边界）** 若支持集只来自系统选择提问的区域 A（倾向 `π(q)=P(ask|q)`），则对全分布 D，朴素共形覆盖可任意低于 1−α，缺口由 `1/π` 重尾控制，仅在 `D_A` 上成立。倾向加权（`π≥π_floor` 截断）或强制探索配额才给出全分布可审计界。系：能耗优化越偏好便宜提问，缺口越大——PEG 的探索配额与尾部安全支持集是**安全组件**。

**定理 18（FRUGAL 严格包含 FLUID 与 R68）** 在 ASG 认证、E_res 保障、可交换/已校正假设下：(1) `E_max→∞`、`β=0`、`Δθ=0`、`α=α_MCG` ⇒ 逐指令包含 R69（CMC→MCG、MINT-E→MINT）；(2) 再令 `N_int=0` ⇒ R68；(3) 任意能量水平下安全决策由 E_res 保障，风险 ≤ R68；(4) 能量受限但非零时，以 ≤FLUID 的每任务焦耳达到 ≥FLUID 成功率（摊销），或回本不划算时退回 R68。故 R69/R68 均为「能量无限/交互关闭」边界的严格退化，安全不让步。

**定理 19（能量约束下安全退化的单调性与无突变）** EBS 退化序固定且只移除效率块；E_res 保证安全块始终有偿付能力；λ 随能量收紧单调不降；适配器换装受 ASG 单界约束。故能量衰减中控制连续、无突变，最坏退化为 R68（继承 R69 定理 17）。

## 7. 本轮最大风险

**一句话**：FRUGAL-RAS 的覆盖契约与能耗收益都建立在「支持集可交换且代表性足够」上，但交互天然只给系统**选择去问**的样本打标签、能耗优化又系统性偏好便宜的提问——**系统会学到一个自证清白、只覆盖「它愿意去测」的区域、而在真正危险的稀有尾部永久保持无知的校准**。

**次级风险与缓解**：
1. 非平稳使共形覆盖失效 → XSM（覆盖 CUSUM + MMD）检测、α 膨胀、冻结回滚（定义 323、E310）；
2. 选择偏差/尾部饿死 → PEG 探索配额 + 倾向加权共形 + 尾部安全支持集（不占效率预算）（引理 23、E301/E310）；
3. few-shot 过拟合或适配器投毒 → 低秩+范数界 + ASG 留出验证 + 影子评估（定义 314/318、引理 21、E311）；
4. 能量模型误差致预算击穿 → 在线功率模型 + 实测校准 + E_res 硬兜底（定义 311/320、E303/E306）；
5. V_learn 估计器自欺（元验证与被查询分布同源）→ 独立留出集 + 周期重采样 + 审计（定义 322/324、E315）。

**一句话（结尾）**：越省电，越容易把「我没测到危险」误当成「没有危险」——FRUGAL-RAS 若不把探索配额与尾部安全支持集当作安全组件而非效率组件，它的「覆盖」就会成为一台精密的虚假自信生产机。
