# 第 69 轮（承接第 68 轮「CALM-RAS 自标定风险自适应闭环」IP-243~252；本轮灵感：「时空推理」×「双臂协调」）

> 第 68 轮把「标定」提为一等公民，用自监督驱动在线 EKF，让闭环第一次能问「我的测量还准吗」。但它在结尾亲手写下了自己的原罪：**标定能力越强，缓变故障越隐形**——只要故障落在标定带宽内，COF 就会把它「标好」，CFA 把 H_cal 后验推高，系统在「越来越准」的假象中失去最后一道检出能力。这不是参数没调好，而是**单流观测的结构性盲区**：一个传感器无法把自己产生的偏置与世界的真实变化分开，因为两者在它自己的时间序列里同构。
>
> 本轮灵感恰好提供了破局的两个正交维度：**时空推理**（不只看「此刻是否自洽」，而看「这条漂移轨迹在因果上像不像标定」）与**双臂协调**（第二只臂是一个物理上独立的观测者与执行者，既提供互证，也提供主动激励）。
>
> 核心命题：**把标定从「可拟合的慢变量」升级为「必须被物理因果解释的慢变量」，用双臂闭链提供空间差模互证、用轨迹可逆性/事件对齐提供时间因果检验、用另一只臂的受控激励把「标定 vs 缓变故障」从被动猜测变为主动可辨识——STAR-RAS（Spatio-Temporal dual-Arm Reasoning RAS）。**
>
> 一句话定位：R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 追问「**我凭什么相信这是漂移而不是坏掉**」——不能给出因果解释与可逆证据的慢变化，一律按故障处理。

## 0. 直觉与动机

**灵感 1（时空推理 → 标定不是拟合，是因果解释）**
直觉：R68 的 COF 是一个「有速率限制的万能拟合器」——任何慢残差都能被它吸收，因为它只有一个先验（慢 = 漂移）。但真实的标定漂移有**物理成因**：温漂随温度可逆、负载引起弹性形变随外力回归、几何间隙随构型周期变化。它们都满足「可由协变量 u_t 预测 + 扰动撤除后回到原位」。而缓变故障（密封慢泄漏、渐进老化、缓慢松动）是**不可逆、单调、与协变量无关**的。于是判据从「快慢」升级为「**可解释性 + 可逆性 + 与共享协变量的共模性**」：一条既无物理协变量解释、又不可逆的慢漂移，哪怕再慢，也是故障。时间维度给出因果性，空间维度（双臂）给出来源定位。

**灵感 2（双臂协调 → 第二只臂是免费的独立见证人，也是主动实验装置）**
直觉：单臂的物理约束是「自己证自己」——它看见的对象位姿变化，既可能是对象动了，也可能是自己歪了，二者在单臂观测里不可分。双臂闭链抓持同一刚体时，环闭合残差 η ≈ δ_A − δ_B：**共模误差自动抵消，差模误差被放大两倍**。这天然把「世界变了（共模）」与「一只臂歪了（差模）」分开。更关键的是，双臂还能**做实验**：让一只臂刚性保持对象、另一只臂施加已知小载荷/小位移，用受控激励去激发标定模型的预测响应；如果残差对外部激励的响应不符合任何物理标定模型，则它不是标定而是故障。这把「被动一致性检验」升级为「主动可辨识性检验」——因果干预远强于相关观察。

**灵感 3（为什么 R68 的盲区在双臂下仍可能存活 → 必须诚实建模共模盲区）**
直觉：双臂互证只对**差模**有效。若两只臂共享同一失效原因（同批传感器、同一基座热源、同一模型、同一次碰撞），δ_A = δ_B，环残差恒为零——系统会自信地宣布「两臂一致，一切正常」。这正是双臂冗余最危险的地方：**冗余的强度等于失效的独立性**。因此本方案不把「低不对称」当作安全证据，反而把「低不对称 + 高不可解释慢漂移 + 无主动探针证据」判为最高风险（λ 抬到 0.8 以上）——因为那正是共模故障的典型指纹。空间互证只用于**定位**，因果解释与主动探针才用于**定性**。

**灵感 4（第二重危险 → 闭链既是观测通道，也是传染通道）**
直觉：让两臂刚性闭链，差模误差会被放大而可观测；但同一个耦合意味着 A 臂的指令误差会通过对象与力闭环传到 B 臂。故障不会被「隔离」，反而可能沿闭链扩散。尤其交接（handover）时刻——放松一只臂、由另一只接管——正是最脆弱的窗口：此时闭链约束短暂软化，既无法互证，又可能在负载突加时把 A 的偏置变成 B 的过载。故协调策略不能只做「收缩」，必须做**保持闭链的权限再分配**（coordinated authority handover），并在交接期间维持一个显式的协调不变式。

**灵感 5（合流 → STAR-RAS 七组件）**
1. **MTM-B**：R68 的 MTM 加「臂身份 token」，两臂共享 trunk 但可区分——共享参数保证共模噪声高相关（利于差模检验），token 保证差模不被抹平；
2. **BSG Bimanual Spatio-temporal Graph**：滑窗因子图，空间闭链因子 + 时间平滑/事件因子，输出残差 η 与协方差；
3. **CCM Causal Calibration Model bank**：把标定拆成「物理协变量可解释部分 f(θ;u)」与「残余 ε」，只有可解释部分享有全带宽吸收权；
4. **APX Active Probe eXcitation**：用另一只臂在安全包络内设计激励 ξ，最大化「标定参数 θ vs 故障参数 φ」的 Fisher 信息，把不可辨识变为可辨识；
5. **STL Spatio-Temporal Localizer**：把因子残差反投影到「哪只臂 / 哪个连杆 / 哪个传感器 / 哪个时间窗」，输出故障世界线；
6. **CWA Cross-arm Witness Attribution**：升级 R68 的 CFA，H_cal 的成立必须同时满足「可解释 ∧ 可逆 ∧ 共模一致或探针支持」；
7. **HLC Handover-Load Coordination + CAC-B†**：保持闭链的权限再分配与耦合安全收缩；认证提交新增「因果一致性闸」与「探针可辨识闸」，坏适配器不能靠抹平差模残差过关。

**灵感 6（对 R68 风险的对症下药）**
- R68「缓变故障被标定吸收」：CCM 的因果解释 + 可逆性 + APX 主动探针，使**慢**不再是吸收的充分条件；
- R68「金标集未覆盖故障则放行适配器」：CAC-B† 新增 canary 探针关——注入缓慢故障的 canary 必须在主动激励下暴露，否则一票否决；
- 双臂新增风险「共模盲区」：显式建模为不可观测子空间（引理 16），并用「低不对称 ⇒ 更保守」的反直觉纪律（定义 306）兜底；
- 双臂新增风险「闭链传染」：协调不变式 + 传染增益界（引理 18）限制交接与耦合收缩。

## 1. 形式化定义（增量：定义 293–310）

**定义 293（STAR-RAS 总览与不变式）** STAR-RAS = (MTM-B, BSG, CCM, APX, STL, CWA, HLC, CAC-B†, CALM†)。继承 CALM† 的「实时流零学习写操作」与「不确定只收紧」纪律，新增三不变式：
(i) **因果吸收不变式**：只有能被物理协变量模型解释且通过可逆性检验的慢分量，才可作为标定被全带宽吸收；否则残差进入 H_sensor^trans；
(ii) **闭链保持不变式**：任一时刻若对象被两臂共同抓持，禁止单臂无条件释放；交接必须经过保持 η 有界的过渡态；
(iii) **共模保守不变式**：当差模信号低于噪声而不可解释慢漂移高时，视同共模盲区，风险下限抬升至 0.8，绝不因「两臂一致」而放宽。

**定义 294（MTM-B 双臂多任务骨干）** 在定义 277 的 MTM 上加入臂身份编码 e_i ∈ {A,B}：trunk Φ: (obs_t^i, a_{t−1}^i, ctx, e_i) → z_t^i ∈ ℝ^{256}。两臂共享 Φ 与五个任务头（emo/fault/wm/cal/qual），仅以 e_i 作 FiLM 条件；定义跨臂共模相关 ρ_cm = corr(Φ 在两臂上的噪声)，差模可辨识度 ρ_diff = 1 − ρ_cm。共享参数是刻意的：共模噪声高相关 → 环残差 η 的噪声方差 ∝ 2(1−ρ_cm)σ²，差模信噪比提升 1/√(1−ρ_cm)（引理 16 的统计版）。

**定义 295（双臂闭链状态与抓持约束）** 臂 i 末端位姿 T_i(q_i) ∈ SE(3)，对象位姿 X ∈ SE(3)，抓持偏置 G_i。刚性抓持约束 e_i = log((T_i G_i)^{−1} X) ∈ ℝ⁶ ≈ 0。双臂环残差：
η = log((T_A G_A)^{−1}(T_B G_B)) = e_A − e_B + O(‖e‖²)。
在测量漂移 δ_i 下 η ≈ δ_A − δ_B。定义共模/差模分解 c = (δ_A + δ_B)/2，d = (δ_A − δ_B)/2，故 **η ≈ 2d，c 在 η 中严格抵消**。

**定义 296（BSG 因子图与残差）** 在滑窗 W（2s）上建图：节点 {x_A^τ, x_B^τ, X^τ, e^τ}_{τ∈W}；因子分两类：
- 空间因子 F_s：闭链 η、接触力平衡（Σ w_i = 0，力矩平衡）、摩擦锥/非穿透；
- 时间因子 F_t：速度/加速度平滑、事件对齐（接触起始 τ_c 与力峰/视觉形变对齐）、构型连续性。
总残差 r_ST = ⊕_{f∈F_s∪F_t} r_f，协方差由 MTM-B 各头预测的不确定度组装。

**定义 297（可观测分解）** 记环残差观测算子 J_η，则 η = J_η(δ_A − δ_B) = 2J_η d。定义共模子空间 𝒞 = ker(J_η) 在 δ 空间的原像（当 J_η 满秩时为 {(δ,δ)}），差模子空间 𝒟 为其正交补。**空间互证只能观测 𝒟，对 𝒞 结构性失明**——这是本方案必须诚实写下的边界。

**定义 298（CCM 标定因果模型库）** 标定参数 c_t 被拆为可解释主部与残余：
c_t = Σ_{k∈K} f_k(θ_k; u_t) + ε_t，u_t = (温度 T、负载 F、基座位姿、上电时长、湿度)，
物理基 K = {热漂移 a(T−T₀) + b(1−e^{−t/τ_th})，负载弹性 K_e^{−1}F，几何间隙 g(q)}。θ 低维在线估计。**只有 f(θ;u) 享有全带宽吸收权**；ε_t 的吸收需通过定义 299–301 的检验，否则判为故障候选。R68 的 COF 退化为「θ-滤波器」，其自由标定维度被压缩。

**定义 299（可解释性检验）** ρ_exp = 1 − ‖ε_t‖²/‖c_t‖²，并要求 u_t 落在标定数据支撑集内（禁止外推，防止「用没见过的温度解释一切」）。H_cal 的成立要求 ρ_exp ≥ ρ₀（默认 0.85）且无协变量外推。

**定义 300（可逆性/迟滞检验）** 取扰动前后协变量匹配的两时刻 t₀,t₁（‖u_{t0}−u_{t1}‖ ≤ ε_u），定义迟滞 H = ‖ĉ(t₁) − ĉ(t₀)‖。热漂移/负载弹性应在协变量回归后近似归零（H < h₀）；泄漏/老化/松动不可逆（H ≥ h₀）且呈单调趋势。辅以「事件无关性」：漂移率与接触事件、负载事件无对齐，可排除外部扰动。

**定义 301（APX 主动探针）** 在安全包络内设计激励 ξ（对保持臂施加已知小载荷 ΔF 或小位移 Δq，幅度受抓持稳定/摩擦锥余量约束），以最大化标定参数 θ 与故障参数 φ 的可分 Fisher 信息：
ξ* = argmax_ξ log det(ℐ(ξ; θ, φ))，s.t. ‖ΔF‖ ≤ F_p, ‖Δq‖ ≤ q_p, 对象位移 ≤ ε_probe, 抓持稳定裕度 ≥ m_p。
探针增益 G_probe = √(λ_min(ℐ))。G_probe < g₀ ⇒ 判「不可辨识」，冻结吸收并按最坏情况归因（继承定义 281 的超时纪律）。

**定义 302（STL 时空定位）** 故障位点 ℓ ∈ L = {臂} × {连杆} × {传感器} × {时间窗}。对每个因子残差做反向投影 r_f ↦ J_f^T Σ_f^{−1} r_f，聚合得后验 P(ℓ | r_ST)；输出故障世界线 W = {(τ, ℓ, conf)}。定位精度以「命中真位点的时间窗比例」度量。

**定义 303（CWA 跨臂互证归因，升级 CFA）** H_sensor 仍拆为 H_cal / H_sensor^trans，但证据向量扩为 (ρ, face, η, ε, ρ_exp, H, G_probe, U)：
P(H_cal | ·) 高 ⇔ [可解释 ρ_exp ≥ ρ₀] ∧ [可逆 H < h₀] ∧ [共模一致（差模近零且协变量支持）∨ 探针支持 H_cal]；
P(H_sensor^trans | ·) 高 ⇔ [差模显著 ∧ 不可解释] ∨ [不可逆] ∨ [探针判别支持故障]；
当 [差模近零 ∧ 不可解释 ∧ 探针不可辨识] 时进入**共模盲区保守态**：不判 H_cal（拒绝以「两臂一致」为由吸收），H 后验取最大熵并按最坏情况缩放 λ。红线（定义 276-ii）照旧：超界直接判真实故障，禁止任何标定吸收。

**定义 304（HLC 权限分配与耦合安全收缩）** 权限 α = (α_A, α_B) ∈ Δ¹（负载/权威份额），由 CWA 的每臂可信度与 STL 定位给出。协调安全响应不是「停一条臂」，而是：
- 若一臂被判不可信，沿**保持闭链的交接轨迹**把 α 连续迁移到另一臂（先夹紧再卸载，η 始终有界）；
- 耦合前缀 k_pair = min_i k_i^safe，其中 k_i^safe 在「两臂联合包络」下计算（绑定约束取两臂最小），而非各自独立；
- 过渡态定义协调不变式：‖η_t‖ ≤ η_max 且 d‖η‖/dt ≤ η̇_max，否则回退到双人协作最保守抓持。

**定义 305（自监督时空损失族）** L_ssl-ST = λ_loop‖η‖² + λ_caus‖ε‖² + λ_rev·H + λ_event·L_align + λ_tc·L_tempContrast + λ_arm·L_armInv + λ_vc·L_VICReg(z)。
其中 L_armInv 惩罚「换臂后除差模通道外表征漂移」（共享 trunk 的一致性自监督）；L_align 用接触事件对齐力/视觉/位姿三流（时间维度监督）；全部零人工标签。

**定义 306（STAR 阈值重参数化，关键反直觉条款）** 继承定义 284 的 U(ĉ) 联动，并引入差模 d 与探针增益：
τ_diff = τ⁰_diff·(1 + κ_d·U)，τ_probe = τ⁰_probe·(1 − κ_p·G_probe)。
λ_floor^STAR = max(0.6, 0.8·1[C_blind])，其中共模盲区指标 C_blind = 1[‖η‖ < τ_diff]·1[‖ε‖ > τ_ε]·1[G_probe < g₀]——**「两臂太一致 + 慢漂移无法解释 + 探针问不出」恰恰是最危险态，λ 抬到 0.8**；这条故意与「一致性 = 安全」的直觉相反，用于堵住共模故障。

**定义 307（AIC-STAR 干扰集）** ℰ_STAR = ℰ_CALM × ℰ_space × ℰ_time × ℰ_coord。
ℰ_space = {共模故障、差模伪装、单臂遮挡导致的假差模}；ℰ_time = {不可逆慢漂移、事件错对齐、协变量外推}；ℰ_coord = {交接抖动、闭链传染、负载突加、探针失稳}。

**定义 308（J_STAR 证书）** J_STAR = (J_CALM, η_hash, d_stat, ρ_exp, H, G_probe, ℓ_worldline, α, coord_invariant, star_ver)。Valid ⇔ Valid(J_CALM) ∧ 共模盲区未触发或已按保守态处理 ∧ 协调不变式全程满足 ∧ 红线未越界。

**定义 309（管线）** 离线：双臂自监督预训练（闭链一致 + 换臂不变 + 事件对齐）→ 有标签微调 → CCM 基函数标定 → CAC-B† 首装。在线：每 60s 影子训练 → 五关 + 因果关 + 探针关 → 原子换装；每 2s 跑一次 BSG/CWA；当 C_blind 或差模超阈时，异步触发一次 APX 探针（仅在认证安全态）。

**定义 310（协调不变式）** 对任意交接区间 [t_a,t_b]：对象位姿漂移 ‖ΔX‖ ≤ ε_X，环残差 ‖η_t‖ ≤ η_max，接触力始终在摩擦锥内，且不出现「双臂同时松」或「单臂独占却未完成再抓持」的状态。该不变式是 HLC 与 CAC-B† 提交的共同前置。

# IP-253 MTM-B：共享 trunk + 臂 token（共模高相关，差模不抹平）
class BimanualMTM:
    def forward(self, obs_A, obs_B, a_prev, ctx):
        zA = self.trunk(obs_A, a_prev, ctx, arm='A')
        zB = self.trunk(obs_B, a_prev, ctx, arm='B')
        return {'A': self.heads(zA), 'B': self.heads(zB), 'z': (zA, zB)}


# IP-254 BSG：滑窗双臂时空因子图（空间闭链 + 时间事件）
class BimanualSpatioTemporalGraph:
    def residual(self, win):
        eta = log_se3((T(win.A)*G_A).inverse() * (T(win.B)*G_B))   # ≈ δ_A-δ_B
        fs  = [eta, contact_wrench_balance(win), friction_cone(win)]
        ft  = [velocity_smooth(win), event_alignment(win)]
        return stack(fs + ft), block_cov(win)                      # r_ST, Σ


# IP-255 CCM：只有物理可解释部分享有全带宽吸收权
class CausalCalibrationBank:
    BASES = ('thermal', 'load_elastic', 'geometric_play')
    def explained(self, u, theta):
        return sum(self.f[k](u, theta[k]) for k in self.BASES)
    def test(self, c_hat, u, t0, t1):
        eps = c_hat - self.explained(u, self.theta)
        rho = 1 - (eps @ eps) / (c_hat @ c_hat + 1e-9)
        hyst = norm(c_hat[t1] - c_hat[t0]) if covariate_matched(t0, t1) else INF
        return {'eps': eps, 'rho_exp': rho, 'H': hyst,
                'extrap': not in_support(u)}


# IP-256 APX：用另一只臂做受控激励，把不可辨识变可辨识
def design_probe(win, theta, phi, envelope):
    xi = argmax_xi logdet(fisher(xi, theta, phi))
    if violates(xi, envelope): return None            # 摩擦锥/位移/力限
    G = sqrt(min_eig(fisher(xi, theta, phi)))
    return {'xi': xi, 'G_probe': G} if G >= G0 else None


# IP-257 STL：把因子残差反投影成「哪只臂/哪个传感器/哪个时间窗」
def localize(r_ST, J):
    score = defaultdict(float)
    for f, r in r_ST.items():
        for locus, Jf in J[f].items():
            score[locus] += r @ solve(Jf, r)
    return normalize(score)                            # P(ℓ | r_ST)


# IP-258/259 CWA：跨臂互证归因（升级 R68 的 CFA）
def cross_arm_attribution(eta, ccm, probe, cwa_prior):
    d = norm(eta) / 2
    blind = (d < TAU_DIFF) and (norm(ccm['eps']) > TAU_EPS) and (probe is None)
    if ccm['extrap'] or ccm['H'] >= H0:
        H = 'H_sensor_trans'                         # 不可逆/外推 -> 故障
    elif ccm['rho_exp'] < RHO0 and d >= TAU_DIFF:
        H = 'H_sensor_trans'                         # 差模且不可解释 -> 故障
    elif ccm['rho_exp'] >= RHO0 and ccm['H'] < H0 and (d < TAU_DIFF or probe):
        H = 'H_cal'                                  # 可解释+可逆+互证/探针
    else:
        H = 'conservative'                           # 共模盲区：拒绝吸收
    return worst_case(cwa_prior, H) if blind else cwa_prior.update(H)


# IP-260 HLC：保持闭链的权限再分配（不是简单停机）
def coordinated_handover(alpha, pair_actions, eta, eta_dot):
    k_pair = min_safe_steps(pair_actions, joint_envelope=True)
    if eta_dot > ETA_DOT_MAX or norm(eta) > ETA_MAX:
        return conservative_grasp(alpha), 0          # 退回双人最保守抓持
    alpha_new = transfer_load(alpha, toward=most_trusted(pair_actions))
    return alpha_new, k_pair


# IP-261 CAC-B†：五关 + 因果一致关 + 探针可辨识关 + 闭链保持关
class BimanualCertifiedCommit:
    GATES = [gold_regression, auditbuf_replay, tv_bound, risk_bound,
             canary_unfixable, causal_consistency, probe_identifiable,
             closed_chain_preserved]
    def maybe_commit(self, shadow, dt):
        if dt < self.T_commit: return None
        verdict = {g.__name__: g(shadow) for g in self.GATES}
        if all(verdict.values()):
            atomic_swap(self.live_ptr, shadow); return 'PASS'
        log_to_ecac(verdict); return 'REJECT'


# IP-262 主闭环：STAR-RAS round
def STAR_RAS_round(M, obs):
    oA, oB = M.mtm_b.forward(obs.A, obs.B, M.a_prev, M.scene_ctx)   # 1) 双臂一次前向
    r_ST, Sig = M.bsg.residual(obs.win)                              # 2) 时空因子图
    c_hat, U = M.cof_theta.step(oA['cal'] + oB['cal'], r_ST)         # 3) 仅 theta 可全带宽
    ccm = M.ccm.test(c_hat, obs.u, *M.ccm.matched_pair(obs.win))     # 4) 因果/可逆检验
    probe = None
    if M.should_probe(ccm, r_ST, Sig):                               # 5) 条件触发主动探针
        probe = M.apx.design_probe(obs.win, M.ccm.theta, M.phi, M.envelope)
    joint_post = M.cwa(r_ST, ccm, probe, M.prior)                    # 6) 跨臂互证归因
    loc = M.stl.localize(r_ST, Sig)                                  # 7) 时空定位
    k_pair = M.hlc.certified_prefix(M.ach.propose_pair(obs), joint_post)
    lam = max(M.efs.risk_scale(joint_post), M.car.floor(U, ccm, probe))
    tau = M.pi_sigma.prefix_dispatch_pair(M.ach.pair_actions[:k_pair]) * lam
    tau = M.hlc.emotion_response_shaping_pair(tau, joint_post, loc, probe)
    M.vqa_c.submit_async(r_ST, {'ccm': ccm, 'probe': probe, 'loc': loc})
    M.cac_b.maybe_commit(M.shadow, M.time_since_last_commit)
    return k_pair, lam, joint_post, (ccm, probe, loc)

## 3. 推导

**引理 16（差模可观测与共模盲区）** 由定义 295，η = J_η(δ_A − δ_B) = 2J_η d。若 J_η 在对象 6 维位姿上满秩，则可观子空间恰为差模子空间 𝒟（维数 ≤ 6），共模子空间 𝒞 落在核空间：任意 δ_A = δ_B = c 产生 η = 0。故双臂互证对共模故障检出概率等于单臂先验（无增益）；对差模故障，信号被放大 2 倍且噪声方差 ∝ 2(1−ρ_cm)σ²，SNR ∝ 1/√(1−ρ_cm)。系：**R68 的「单流盲区」在同批同源共模失效下依然存在，本方案不掩盖这一点，而用定义 306 的保守态兜底。**

**引理 17（缓变故障的主动可辨识性）** 设 θ 为标定参数、φ 为故障参数，激励 ξ 下 Fisher 信息 ℐ(ξ;θ,φ)。在局部渐近正态下，H_cal 与 H_trans 的判别错误率 ≤ exp(−½·G_probe²·Δ²)，其中 Δ 为两假设的残差均值差、G_probe = √λ_min(ℐ)。故当 G_probe ≥ g₀ 时可辨识；当 G_probe < g₀（探针受安全包络限制）时存在不可消除的模糊区，必须回退保守（定义 303）。**慢**不再是吸收的充分条件：不可逆慢漂移即便 ω ≤ ω_cal，也因 ρ_exp/H 检验被拒。

**引理 18（闭链传染界）** 双臂刚性闭链的柔顺耦合记 C，A 臂指令端扰动 ε_A 经对象传到 B 臂的传递增益 g_c = ‖C_AB C_BB^{−1}‖。若交接期间负载突加 ΔF，则 B 臂诱导误差 ≤ g_c·‖ε_A‖ + ‖C_BF‖‖ΔF‖。故 HLC 必须（a）先夹紧再卸载以压低 g_c，（b）把 k_pair 在联合包络下取值，（c）用协调不变式（定义 310）保证交接窗口内 η 有界。系：**差模可观测性与故障传染性共用同一个耦合 C——观测增益与传染增益同源**。

**引理 19（探针安全性）** 若探针满足定义 301 的 ‖ΔF‖ ≤ F_p、‖Δq‖ ≤ q_p、抓持稳定裕度 ≥ m_p，则探针引起对象位移 ≤ ε_probe 且不破坏摩擦锥；探针期间风险缩放取 λ ≥ λ_floor，且任一时刻可由协调不变式回退到保守抓持。

**定理 16（STAR-RAS 端到端风险一致性）** 在 A87–A94 与新增 A95–A98（A95 标定漂移可由物理协变量解释；A96 双臂失效存在独立差模分量或可被主动激励激发；A97 共模失效在盲区内按保守态处理；A98 协调不变式可执行）下：
1. P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + **α_cross + α_ident**，其中 α_cross 由引理 16 的差模 SNR 限制，α_ident 由引理 17 的 G_probe 限制；
2. **差模缓变故障**（落在 R68 盲区内的那一类）在 T_det 内检出，且 T_det 与 ω_f 无关（因果/可逆检验不受标定带宽限制）——直接修补 R68 原罪；
3. **共模缓变故障** 退化为 R68 的检出保证（需越红线），并在 C_blind 触发时 λ ≥ 0.8、k_pair 收缩；
4. 交接窗口内若协调不变式被破坏，系统回退保守抓持，期间 λ 单调不减（不出现「因交接而放宽」）。

**定理 17（双臂认证提交与交接安全性）** 八关认证中，canary 关要求「注入的缓慢故障在主动探针下暴露」，结合因果一致关与探针可辨识关，有害适配器上线概率 ≤ (1−r_canary^ST)·p_h；闭链保持关确保换装只在协调不变式成立的窗口生效，双缓冲原子换装 < 1μs；回滚路径与提交同构，回滚失败即全局降级（k_pair = 0 且保守抓持）。

## 6. 本轮最大风险

**一句话**：STAR-RAS 的双臂互证只对差模有效，而它最想解决的缓变故障若以**共模**形式出现（两臂同批传感器、共享基座热源、共享模型或同一次碰撞同时劣化），环残差恒为零、系统会以「两臂一致」自我确认安全；更糟的是，赋予它可观测性的闭链耦合同时是故障传染通道——一臂的偏置可经协调控制器传给另一臂，因此**双臂冗余的强度完全等于其失效独立性，而观测增益与传染增益同源**。

**定义 299（可解释性）** `ρ_exp=1−‖ε‖²/‖c‖²`；H_cal 需 `ρ_exp≥ρ₀` 且无协变量外推。

**定义 300（可逆性）** 协变量匹配两时刻的迟滞 `H=‖ĉ(t₁)−ĉ(t₀)‖`；热/弹性应回归（H<h₀），泄漏/老化/松动不可逆（H≥h₀）且单调、与事件无关。

**定义 301（APX）** `ξ*=argmax logdet ℐ(ξ;θ,φ)` s.t. 力/位移/摩擦锥余量；`G_probe=√λ_min(ℐ)`；`G_probe<g₀ ⇒` 不可辨识，冻结吸收、最坏情况归因。

**定义 302（STL）** 位点 `ℓ∈{臂}×{连杆}×{传感器}×{时间窗}`；由 `r_f↦J_f^TΣ_f⁻¹r_f` 聚合 `P(ℓ|r_ST)`，输出世界线 `W`。

**定义 303（CWA）** 证据 = (ρ, face, η, ε, ρ_exp, H, G_probe, U)。`H_cal ⇔ 可解释 ∧ 可逆 ∧ (共模一致 ∨ 探针支持)`；`H_sensor^trans ⇔ (差模显著 ∧ 不可解释) ∨ 不可逆 ∨ 探针判故障`；`C_blind` 时拒绝 H_cal、最大熵、最坏情况缩放；红线超界直接判故障。

**定义 304（HLC）** 权限 `α∈Δ¹`；一臂不可信时沿保持闭链的交接轨迹连续迁移负载（先夹紧再卸载，η 有界）；`k_pair=min_i k_i^safe` 在联合包络下计算；过渡态满足协调不变式。

**定义 305（自监督时空损失）** `L_ssl-ST = λ_loop‖η‖² + λ_caus‖ε‖² + λ_rev·H + λ_event·L_align + λ_tc·L_tempContrast + λ_arm·L_armInv + λ_vc·L_VICReg`，全部零标签。

**定义 306（阈值重参数化，反直觉条款）** `τ_diff=τ⁰(1+κ_dU)`、`τ_probe=τ⁰(1−κ_pG_probe)`；`λ_floor^STAR=max(0.6, 0.8·1[C_blind])`——“两臂太一致 + 慢漂移不可解释 + 探针问不出”是最危险态。

**定义 307–310（干扰集/证书/管线/协调不变式）** `ℰ_STAR=ℰ_CALM×ℰ_space×ℰ_time×ℰ_coord`；`J_STAR` 增 η/d/ρ_exp/H/G_probe/世界线/α/协调不变式；在线 2s 检验 + 条件探针 + 60s 影子提交；交接满足 `‖η‖≤η_max、d‖η‖/dt≤η̇_max`、摩擦锥内、禁止双松/单臂独占未再抓持。

# IP-253 MTM-B：共享 trunk + 臂 token（共模高相关、差模不抹平）
class BimanualMTM:
    def forward(self, obs_A, obs_B, a_prev, ctx):
        zA = self.trunk(obs_A, a_prev, ctx, arm='A')
        zB = self.trunk(obs_B, a_prev, ctx, arm='B')
        return {'A': self.heads(zA), 'B': self.heads(zB), 'z': (zA, zB)}

# IP-254 BSG：滑窗双臂时空因子图
class BimanualSpatioTemporalGraph:
    def residual(self, win):
        eta = log_se3((T(win.A)*G_A).inverse() * (T(win.B)*G_B))   # ≈ δ_A-δ_B = 2d
        fs  = [eta, contact_wrench_balance(win), friction_cone(win)]
        ft  = [velocity_smooth(win), event_alignment(win)]
        return stack(fs + ft), block_cov(win)

# IP-255 CCM：只有物理可解释部分可全带宽吸收
class CausalCalibrationBank:
    BASES = ('thermal', 'load_elastic', 'geometric_play')
    def explained(self, u, theta):
        return sum(self.f[k](u, theta[k]) for k in self.BASES)
    def test(self, c_hat, u, t0, t1):
        eps  = c_hat - self.explained(u, self.theta)
        rho  = 1 - (eps @ eps) / (c_hat @ c_hat + 1e-9)
        hyst = norm(c_hat[t1] - c_hat[t0]) if covariate_matched(t0, t1) else INF
        return {'eps': eps, 'rho_exp': rho, 'H': hyst, 'extrap': not in_support(u)}

# IP-256 APX：用另一只臂做受控激励
def design_probe(win, theta, phi, envelope):
    xi = argmax_xi logdet(fisher(xi, theta, phi))
    if violates(xi, envelope): return None            # 摩擦锥/位移/力限
    G = sqrt(min_eig(fisher(xi, theta, phi)))
    return {'xi': xi, 'G_probe': G} if G >= G0 else None

# IP-257 STL：残差反投影定位
def localize(r_ST, J):
    score = defaultdict(float)
    for f, r in r_ST.items():
        for locus, Jf in J[f].items():
            score[locus] += r @ solve(Jf, r)
    return normalize(score)                            # P(ℓ | r_ST)

# IP-258/259 CWA：跨臂互证归因（升级 CFA）
def cross_arm_attribution(eta, ccm, probe, prior):
    d = norm(eta) / 2
    blind = (d < TAU_DIFF) and (norm(ccm['eps']) > TAU_EPS) and (probe is None)
    if ccm['extrap'] or ccm['H'] >= H0:
        H = 'H_sensor_trans'
    elif ccm['rho_exp'] < RHO0 and d >= TAU_DIFF:
        H = 'H_sensor_trans'
    elif ccm['rho_exp'] >= RHO0 and ccm['H'] < H0 and (d < TAU_DIFF or probe):
        H = 'H_cal'
    else:
        H = 'conservative'                             # 共模盲区：拒绝吸收
    return worst_case(prior, H) if blind else prior.update(H)

# IP-260 HLC：保持闭链的权限再分配
def coordinated_handover(alpha, pair_actions, eta, eta_dot):
    k_pair = min_safe_steps(pair_actions, joint_envelope=True)
    if eta_dot > ETA_DOT_MAX or norm(eta) > ETA_MAX:
        return conservative_grasp(alpha), 0
    return transfer_load(alpha, toward=most_trusted(pair_actions)), k_pair

# IP-261 CAC-B†：八关认证
class BimanualCertifiedCommit:
    GATES = [gold_regression, auditbuf_replay, tv_bound, risk_bound,
             canary_unfixable, causal_consistency, probe_identifiable,
             closed_chain_preserved]
    def maybe_commit(self, shadow, dt):
        if dt < self.T_commit: return None
        verdict = {g.__name__: g(shadow) for g in self.GATES}
        if all(verdict.values()):
            atomic_swap(self.live_ptr, shadow); return 'PASS'
        log_to_ecac(verdict); return 'REJECT'

# IP-262 主闭环
def STAR_RAS_round(M, obs):
    oA, oB = M.mtm_b.forward(obs.A, obs.B, M.a_prev, M.scene_ctx)
    r_ST, Sig = M.bsg.residual(obs.win)
    c_hat, U = M.cof_theta.step(oA['cal'] + oB['cal'], r_ST)       # 仅 theta 全带宽
    ccm = M.ccm.test(c_hat, obs.u, *M.ccm.matched_pair(obs.win))
    probe = (M.apx.design_probe(obs.win, M.ccm.theta, M.phi, M.envelope)
             if M.should_probe(ccm, r_ST, Sig) else None)
    joint_post = M.cwa(r_ST, ccm, probe, M.prior)
    loc = M.stl.localize(r_ST, Sig)
    k_pair = M.hlc.certified_prefix(M.ach.propose_pair(obs), joint_post)
    lam = max(M.efs.risk_scale(joint_post), M.car.floor(U, ccm, probe))
    tau = M.pi_sigma.prefix_dispatch_pair(M.ach.pair_actions[:k_pair]) * lam
    tau = M.hlc.emotion_response_shaping_pair(tau, joint_post, loc, probe)
    M.vqa_c.submit_async(r_ST, {'ccm': ccm, 'probe': probe, 'loc': loc})
    M.cac_b.maybe_commit(M.shadow, M.time_since_last_commit)
    return k_pair, lam, joint_post, (ccm, probe, loc)

## 4. 推导

**引理 16（差模可观测与共模盲区）** `η=J_η(δ_A−δ_B)=2J_η d`。J_η 满秩时，可观子空间为差模 𝒟（≤6 维），共模 𝒞 落核空间：δ_A=δ_B=c ⇒ η=0。故双臂互证对共模故障无增益；对差模故障信号 ×2、噪声方差 ∝ 2(1−ρ_cm)σ²，SNR ∝ 1/√(1−ρ_cm)。**R68 的单流盲区在同源共模失效下依然存在。**

**引理 17（缓变故障主动可辨识性）** Fisher 信息 ℐ(ξ;θ,φ)，`G_probe=√λ_min(ℐ)`；局部渐近下判别错误率 ≤ exp(−½G_probe²Δ²)。`G_probe≥g₀` 可辨识；否则必须回退保守。**慢不再是吸收的充分条件**：不可逆慢漂移即便 ω≤ω_cal 也因 ρ_exp/H 被拒。

**引理 18（闭链传染界）** 传递增益 `g_c=‖C_AB C_BB⁻¹‖`；交接负载突加 ΔF 时 B 臂诱导误差 ≤ `g_c‖ε_A‖+‖C_BF‖‖ΔF‖`。HLC 需先夹紧再卸载、联合包络取 k_pair、维持协调不变式。**观测增益与传染增益同源。**

**引理 19（探针安全性）** 满足力/位移/摩擦锥余量约束时，对象位移 ≤ ε_probe、不破摩擦锥；探针期 λ ≥ λ_floor，随时可回退保守抓持。

**定理 16（STAR-RAS 端到端风险一致性）** A87–A98 下：
1. `P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+α_cross+α_ident`；
2. **差模缓变故障**在 T_det 内检出，且 T_det 与 ω_f 无关（因果/可逆检验不受标定带宽限制）——直接修补 R68 原罪；
3. **共模缓变故障**退化为 R68 保证（需越红线），C_blind 触发时 λ≥0.8、k_pair 收缩；
4. 交接窗口若破坏协调不变式，回退保守抓持且 λ 单调不减。

**定理 17（双臂认证提交与交接安全性）** 八关中 canary 关要求「注入缓慢故障在主动探针下暴露」，结合因果/探针关，有害适配器上线概率 ≤ (1−r_canary^ST)p_h；闭链保持关确保换装只在协调不变式成立窗口生效；原子换装 <1μs；回滚失败即 k_pair=0 且保守抓持。

## 7. 本轮最大风险

**一句话**：STAR-RAS 的双臂互证只对差模有效，而它最想解决的缓变故障若以**共模**形式出现（两臂同批传感器、共享基座热源、共享模型或同一次碰撞同时劣化），环残差恒为零、系统会以「两臂一致」自我确认安全；更糟的是，赋予它可观测性的闭链耦合同时是故障传染通道——一臂的偏置可经协调控制器传给另一臂，因此**双臂冗余的强度完全等于其失效独立性，而观测增益与传染增益同源**。
