### 第 7 轮灵感驱动研究记录

**灵感词**：具身智能大模型、碰撞检测

**继承关系**：第 6 轮 CADVS-v6（IP-497~500）在「七硬门不增」前提下引入 GGC（抓取几何凿）、MCTM（空间拓扑图）、STM（语义-轨迹映射）与软因子链 EFA-v6。本轮把提议源从「有界流匹配生成器」换成「开放词汇、黑箱、可能幻觉的具身智能大模型（VLA）」，并把碰撞检测从「启发式点云预览」升级为「可证明的连续碰撞证书」。问题因此从 v6 的「如何让生成提议符合物理/空间/意图」升级为：**当提议者本身不可信时，证书边界如何仍然 fail-closed**。

**直觉与动机**：

1. **具身大模型 → 从「有界生成器」到「开放提议器」**。v5/v6 的流匹配提议 π_θ^FM 是一个可估密度的有界生成分布，n_flow 密度门还能作为「分布外」的代理信号。但 VLA（RT-2 / OpenVLA / π0 一类）输出离散动作 token，支持集是开放词汇的，n_flow 在结构上失去意义。**洞见**：不要试图给大模型本身发证书（它不可验证），而应把它的输出**降格为不可信提议**，用与模型无关的几何证书去**证伪**。泛化交给大模型，证伪交给几何——一种「泛化/证伪分工」。

2. **碰撞检测 → 从「布尔预检」到「连续证书」**。v6 的 BCK 只是点云匹配式预览：离散采样、无误差界、可能漏检高速穿越。引入**连续碰撞证书（CCC）**：输出整条连续轨迹扫掠体与障碍 SDF 的最小间隙 c_min 及其误差界；借助距离函数的 Lipschitz 性，把「有限采样」升级为「整条轨迹」的保守证明。**洞见**：碰撞检测的真正价值不在「检测到碰撞」，而在「当它说安全时我们能证明安全」；无法证明时返回 UNKNOWN，而 UNKNOWN 一律拒绝。

3. **注意力落地 → 从「语义对齐」到「几何归因」**。v6 的 STM 解决了「指令→轨迹」检索，却无法回答「模型到底看了哪里才产生这个动作」。VLA 的视觉注意力经深度反投影到 3D 点云 A，与轨迹扫掠体 Sweep(x) 求交，得到**接地一致性** η_ground。**洞见**：若动作撞上了模型「没看」的区域，说明提议的归因不可信，应降低信任、收紧阈值，而不是直接采信。

**关键洞见**：v6 回答「生成器提议如何符合物理/空间/意图」；v7 回答「当提议者是不可信的基础模型时，如何用可证伪的几何证书把不可信提议变成可执行动作」。这迫使我们对「硬门不增」做一次**诚实修订**：门数可以因「升级/合并」而保持 7，但**证书强度必须单调不减**（Cert_v7 ⊒ Cert_v6）。具体地，v6 的 BCK 碰撞预览被**提升**为 CCC 硬门（BCK-v7）：门数不变，证书变强。

**形式化目标（增量）**：

1. **EPA（Embodied Proposal Adapter）**：<br>
   - 采样 K 个动作 chunk a_{1:H} ~ π_VLA(·|I_t,L,proprio)，解码为连续轨迹 x；<br>
   - 记录提议溯源 prov=(logp, entropy, attention, src)；<br>
   - chunk 拼接：对拼接轨迹做 C¹ 连续化并**整体重认证**，杜绝「单 chunk 安全、拼接处碰撞」。

2. **CCC（Continuous Collision Certificate）**：<br>
   - Cert(x) = (status, c_min, t*, witness, ε_cert)，status ∈ {SAFE, UNSAFE, UNKNOWN}；<br>
   - 保守推进：Δt ≤ 2(d_min − c_safe)/(L_φ·v_max)，由 Lipschitz 性得下界 c(x) ≥ d_min − ½·L_φ·v_max·Δt；<br>
   - **UNKNOWN 视为拒绝**（fail-closed），区间算术给 ε_cert。

3. **CGR（Certificate-Guided Repair）**：<br>
   - 静态障碍：沿 ∇φ 做最小位移投影 x ← x − ρ·∇φ(x(t*))，再认证，迭代 ≤ N_repair；<br>
   - 动态障碍：时间膨胀 x_τ(t)=x(t/τ)，τ ∈ {1.2,1.5,2,3}，让障碍先通过，再认证；<br>
   - **修复只产生新候选，绝不绕过证书**。

4. **GCA（Grounding Consistency Auditor）+ NCP（Neural Clearance Prior）**：<br>
   - η_ground = clip(1 − λ_g·(1 − coverage(A, Sweep(x))), 0.1, 1)；<br>
   - η_col = σ(ncp(x)) 为学习到的间隙先验，**仅作软排序**，不作硬门；<br>
   - 统一软因子量纲：所有 η ∈ (0,1]，阈值膨胀 κ(η)=clip(1+λ_tight(1−η),1,1.3)。

5. **EFA-v7**：<br>
   - 提议级联：VLA → FMPP(v6) → 规则；<br>
   - ECS_v7 = ECS_v6 · η_ground · η_col · η_src；<br>
   - τ_i^v7 = γ_i·τ_i^v6·Π_tight，Π_tight = ∏_j κ(η_j) ≤ 1.3；<br>
   - 证书带 TTL，控制环内按 TTL 重认证。

**形式化定义（增量）**：给定观测 I_t、指令 L、目标 ρ、记忆 M：
- (a_{1:H}^{(k)}, prov_k) = EPA.propose(I_t,L,proprio,K=8)；
- x_k = Decode(a_{1:H}^{(k)})，并 stitch 到上一 chunk；
- Cert_k = CCC.certify(x_k, v_max)；
- x_k' = (Cert_k.status=UNSAFE ? CGR.repair(x_k) : x_k)，再认证；
- surv = {x_k' : Cert(x_k').status = SAFE ∧ v6 几何/语义筛通过}；
- Exec_v7 = {x ∈ surv : ∧_i kc_i(x,c;τ_i^v7)=1}；
- 若 surv=∅ → 回退 FMPP(v6)，再空 → 规则提议。

**本轮最大风险**：**证书保守性导致的可用性塌缩**——为保证 soundness，CCC 在高动态/高自由度/感知不完备场景会大量返回 UNKNOWN，fail-closed 于是频繁回退到弱提议器，系统可能退化为「大模型名义在场、规则控制器实际执行」的空转。

## 2. 关键算法骨架

### IP-501 EPA：具身提议适配器

```python
@dataclass
class EmbodiedProposalAdapter:
    """EPA：VLA 动作 chunk → 连续轨迹 + 溯源。
    红线：VLA 输出仅作不可信提议；溯源只用于软排序与审计，不参与硬门放行。"""
    vla: VLA
    decode: ActionDecoder
    H: int = 16

    def propose(self, I_t, L, proprio, K: int = 8):
        out = self.vla.sample(I_t, L, proprio, n=K)  # a_{1:H}, logp, entropy, attn
        trajs, provs = [], []
        for o in out:
            x = self.decode(o.actions)               # 离散 chunk → 平滑连续轨迹
            trajs.append(x)
            provs.append(Provenance(logp=o.logp, entropy=o.entropy,
                                    attn=o.attn, src='vla'))
        return trajs, provs

    def stitch(self, x_prev, x_new, blend: float = 0.1):
        """chunk 拼接：overlap-blend 做 C¹ 连续化。
        关键：拼接后的整条轨迹必须交给 CCC 整体重认证，
        不能只认证单个 chunk——碰撞常发生在 chunk 边界。"""
        x_join = overlap_blend(x_prev, x_new, blend)
        return x_join, {'c1_continuous': c1_residual(x_join) < 1e-3}
```

### IP-502 CCC：连续碰撞证书

```python
@dataclass
class ContinuousCollisionCertificate:
    """CCC：连续碰撞证书（硬门）。
    SAFE 必须可证明；UNKNOWN 与 UNSAFE 一律拒绝（fail-closed）。"""
    sdf: ESDF                 # 必须是可审计的解析/栅格 ESDF，而非学习 SDF
    L_phi: float = 1.0
    c_safe: float = 0.02
    dt_min: float = 1e-4

    def certify(self, x, v_max: float) -> Cert:
        # 1) 保守推进采样：采样点间距随当前间隙自适应
        samples = []
        t = 0.0
        while t <= x.T:
            d = self.sdf.dist(Sweep(x(t)))
            samples.append((t, d))
            gap = max(d - self.c_safe, 0.0)
            dt = max(2.0 * gap / (self.L_phi * v_max + 1e-9), self.dt_min)
            t += dt
        d_min, t_star = min(samples, key=lambda p: p[1])

        # 2) Lipschitz 下界：c(x) ≥ d_min − ½·L_φ·v_max·Δt
        dt_max = max(b[0] - a[0] for a, b in zip(samples, samples[1:]))
        c_lb = d_min - 0.5 * self.L_phi * v_max * dt_max
        c_ub = d_min + 0.5 * self.L_phi * v_max * dt_max

        # 3) 仅在 t* 附近做精确区间算术细化
        if c_lb >= self.c_safe:
            return Cert('SAFE', c_lb, t_star, self._witness(x, t_star), 0.0)
        if c_ub < self.c_safe:
            return Cert('UNSAFE', c_ub, t_star, self._witness(x, t_star), 0.0)
        # 4) 边界不确定：细化后仍不确定则 UNKNOWN → 拒绝
        refined = self._interval_refine(x, t_star, v_max)
        if refined.lb >= self.c_safe:
            return Cert('SAFE', refined.lb, t_star, refined.witness, refined.eps)
        return Cert('UNKNOWN', refined.lb, t_star, None, refined.eps)
```

### IP-503 CGR：证书引导修复

```python
@dataclass
class CertificateGuidedRepair:
    """CGR：只产生新候选，绝不绕过证书。
    静态障碍→沿 SDF 梯度最小位移投影；动态障碍→时间膨胀。"""
    ccc: ContinuousCollisionCertificate
    N_repair: int = 5
    rho: float = 0.01

    def repair(self, x, dynamic: bool):
        if dynamic:
            # 动态：时间膨胀让障碍先通过（仅当障碍速度有界且可预测时成立）
            for tau in (1.2, 1.5, 2.0, 3.0):
                x_tau = time_dilate(x, tau)
                cert = self.ccc.certify(x_tau, x.v_max / tau)
                if cert.status == 'SAFE':
                    return x_tau, cert
            return None, None

        # 静态：沿 ∇φ 把轨迹推出障碍，逐步加步长，防振荡
        x_rep = x
        for k in range(self.N_repair):
            cert = self.ccc.certify(x_rep, x.v_max)
            if cert.status == 'SAFE':
                return x_rep, cert
            t = cert.t_star if cert.t_star is not None else 0.5 * x.T
            g = self.ccc.sdf.grad(Sweep(x_rep(t)))       # 指向自由空间
            x_rep = push_along(x_rep, t, g, self.rho * (2 ** k))
        return None, None
```

### IP-504 GCA + NCP：接地审计与神经间隙先验

```python
@dataclass
class GroundingConsistencyAuditor:
    """GCA：注意力-几何接地一致性（软因子，不作硬门）。
    NCP：学习到的间隙先验（软排序，绝不替代 CCC）。"""
    depth: DepthModel
    ncp: NeuralClearancePrior
    lambda_g: float = 0.5

    def audit(self, attn, x) -> float:
        A = backproject(attn, self.depth)            # 2D 注意力 → 3D 点集
        S = Sweep(x)
        cov = coverage(A, S)                         # 扫掠体表面被关注的比例
        return clip(1.0 - self.lambda_g * (1.0 - cov), 0.1, 1.0)

    def neural_prior(self, x) -> float:
        return clip(sigmoid(self.ncp.score(x)), 0.1, 1.0)   # η_col

    def source_confidence(self, prov) -> float:
        # 序列对数似然归一化 + 熵惩罚；仅作软排序
        logp = float(prov.logp.mean())
        ent = float(prov.entropy.mean())
        return clip(exp(logp) * exp(-0.1 * ent), 0.1, 1.0)  # η_src
```

### IP-505 EFA-v7：提议级联 + 证书单调 + 软因子统一

```python
@dataclass
class EvidenceForgingAssemblerV7:
    """EFA-v7：七硬门不变（BCK 预览升级为 CCC），软因子只收紧。"""
    epa: EmbodiedProposalAdapter
    ccc: ContinuousCollisionCertificate
    cgr: CertificateGuidedRepair
    gca: GroundingConsistencyAuditor
    v6: EvidenceForgingAssemblerV6
    v5: EvidenceForgingAssemblerV5
    lam_tight: float = 0.3
    ttl_cert: float = 0.05

    def _kappa(self, eta: float) -> float:
        return min(max(1.0 + self.lam_tight * (1.0 - eta), 1.0), 1.3)

    def select(self, I_t, L, t_now, context):
        # 1) 提议级联：VLA → FMPP(v6) → 规则
        trajs, provs = self.epa.propose(I_t, L, context.proprio, K=8)
        if not trajs:
            return self.v6.select(L, t_now, context)     # 级联回退

        scored = []
        for x, prov in zip(trajs, provs):
            x, _ = self.epa.stitch(context.x_prev, x)
            cert = self.ccc.certify(x, context.v_max)

            # 2) 不可修复的碰撞/不确定：丢弃（fail-closed）
            if cert.status == 'UNSAFE':
                x_rep, cert = self.cgr.repair(x, context.dynamic)
                if cert is None or cert.status != 'SAFE':
                    continue
                x = x_rep
            elif cert.status == 'UNKNOWN':
                continue

            # 3) 软证据（仅排序/收紧，不放行）
            eta_ground = self.gca.audit(prov.attn, x)
            eta_col = self.gca.neural_prior(x)
            eta_src = self.gca.source_confidence(prov)
            scored.append((x, cert, prov, eta_ground, eta_col, eta_src))

        if not scored:
            return self.v6.select(L, t_now, context)     # 全灭 → v6 → 规则

        # 4) 阈值膨胀：τ_i^v7 = γ_i·τ_i^v6·Π_tight
        best = None
        for x, cert, prov, eg, ec, es in scored:
            pi_tight = min(self._kappa(eg) * self._kappa(ec) * self._kappa(es), 1.3)
            s_emo = self.v6.famk.observe(context.face, t_now)
            tau = {k: v * pi_tight for k, v in self.v6.thresholds(s_emo).items()}
            if not self.v6.hard_gates(x, context, tau):   # 七硬门（含 BCK-v7）
                continue
            ecs = self.v6.ecs(x) * eg * ec * es
            if best is None or ecs > best[0]:
                best = (ecs, x, cert)

        if best is None:
            return self.v6.select(L, t_now, context)
        _, x_best, cert_best = best
        return True, x_best, cert_best, 'FORGED_CGE_V7'

    def revalidate(self, x, cert, dt) -> bool:
        """控制环按 TTL 重认证；证书过期或动态障碍移动超界即失效。"""
        if dt > self.ttl_cert:
            return self.ccc.certify(x, x.v_max).status == 'SAFE'
        return True
```

### 集成流水线（v6 → v7）

```
离线/慢时域：
  VLA 微调（小时级）：指令-动作数据 + 碰撞丰富场景增广 → 提议分布
  ESDF 构建（分钟级）：场景解析/栅格 ESDF，标定 L_φ 与 c_safe
  NCP 蒸馏（小时级）：CCC 标签 → 学习间隙先验（仅软用）
  联邦下发：VLA 权重、ESDF 版本、c_safe、λ_tight、TTL_cert → 站内签名分发

在线准入（异步，50–200 ms）：
  VLA.sample(I_t,L,proprio,K=8) ──▶ 动作 chunk + 溯源
       └─ chunk 拼接 ──▶ CCC.certify ──┬─ SAFE ──▶ 软证据排序
                                        ├─ UNSAFE ──▶ CGR 修复 ──▶ 重认证
                                        └─ UNKNOWN ──▶ 丢弃（fail-closed）
  全灭 ──▶ FMPP(v6) 提议 ──▶ 仍空 ──▶ 规则提议

在线控制环（目标 < 0.6 ms）：
  消费已认证轨迹 + 证书指纹；按 TTL 触发增量重认证（仅动态障碍附近）
  七硬门调用链路不变（v5/v6 缓存复用）；CCC 只查增量 SDF 区域
```

## 4. 正确性论证（增量更新）

### 定理 11（CCC 可靠性 / 无误报安全）

**陈述**：设 SDF 满足 |φ(z)−φ(z')| ≤ L_φ‖z−z'‖，轨迹速度 ≤ v_max，采样间隔 ≤ Δt。若 CCC 返回 SAFE，则真实最小间隙 c(x) ≥ c_safe。

**证明**：令 d(t)=φ_O(Sweep(x(t)))。由 SDF 的 L_φ-Lipschitz 性与扫掠体速度界，d 是 L_φ·v_max-Lipschitz 的。对任意 t 落在某采样 t_k 的 ±Δt/2 邻域内，有 d(t) ≥ d(t_k) − ½·L_φ·v_max·Δt ≥ d_min − ½·L_φ·v_max·Δt = c_lb。CCC 仅在 c_lb ≥ c_safe 时返回 SAFE，故 c(x)=min_t d(t) ≥ c_lb ≥ c_safe。区间细化只可能提高下界，不改变结论。UNSAFE 与 UNKNOWN 一律拒绝，故不存在「误报安全」的放行。∎

**推论（fail-closed）**：执行集只依赖 SAFE 证书；任何不确定都被拒绝，不会因证书缺失而放行。

### 定理 12（证书边界不变 / 提议源可变）

**陈述**：设 G_v6 为 v6 七硬门谓词，G_v7 为其升级（BCK 预览→CCC，阈值膨胀）。若设计要求「CCC SAFE ⇒ v6 BCK 预览通过」，则 G_v7 ⇒ G_v6。于是无论提议来自 VLA、FMPP 还是规则，Exec_v7 = {x : G_v7(x)=1 ∧ x∈proposals_v7} ⊆ {x : G_v6(x)=1}，即**认证可行域不被扩大**。

**证明**：由 G_v7 ⇒ G_v6，任何满足 G_v7 的 x 也满足 G_v6。提议源只改变候选集合 proposals，不改变门谓词；集合交的子集关系对任意 proposals_v7 成立。故换用更强大的 VLA 提议不会打开新的证书逃逸口。∎

**注**：该定理把「换提议器」与「改证书边界」解耦——这正是 v7 能安全引入基础模型的结构性依据。

### 定理 13（软因子只收紧 / 修正 v6 量纲不一致）

**陈述**：对任意 η ∈ (0,1]，κ(η)=clip(1+λ_tight(1−η),1,1.3) ∈ [1,1.3] 且关于 η 单调不增。令 τ_i^v7=γ_i·τ_i^v6·Π_tight，Π_tight=∏_j κ(η_j) ≤ 1.3。则 Exec_v7 随 τ 增大只收缩；当所有 η_j=1 时 κ=1，恢复 v6。

**证明**：λ_tight>0 ⇒ κ 单调不增且 κ(1)=1；clip 保证上界 1.3。τ_i^v7 ≥ τ_i^v6。硬门指示函数 1[s_i ≥ τ] 关于 τ 单调不增，故放行集合只收缩。η_j=1 ⇒ Π_tight=1 ⇒ τ^v7=τ^v6。ECS_v7=ECS_v6·∏η_j ≤ ECS_v6，仅用于更保守的排序。∎

**注（诚实修订）**：v6 同时使用 η_g≥1 与 η_topo∈[0,1]，量纲不一致，可能相互抵消而意外放松。v7 统一为 η∈(0,1]、以 κ 膨胀阈值，从结构上排除「乘积>1 导致阈值下降」的漏洞。

### 定理 14（修复可靠性）

**陈述**：CGR 只在修复后轨迹通过 CCC 认证（status=SAFE）时返回该轨迹，否则返回 None。因此修复不能引入任何 CCC 会拒绝的轨迹。

**证明**：CGR.repair 的所有返回路径都以 `cert.status == 'SAFE'` 为条件；否则返回 (None, None)，调用方随即丢弃该候选。故修复只是「产生并重新认证新候选」，从不绕过证书。∎

### 诚实声明

- CCC 的硬门资格依赖**可审计的解析/栅格 ESDF**；若仅有学习型神经 SDF，则只能降级为软先验（NCP），硬门必须回退到几何网格 + 精确 CCD，否则定理 11 的 Lipschitz 前提不成立；
- Lipschitz 下界依赖 v_max 与加速度/加加速度界；若轨迹含冲击式加减速，需按弧长重参数化或显式约束 jerk，否则速度界失效；
- 注意力溯源本身是启发式的，深度反投影有标定误差；η_ground 只是软信任信号，不构成归因证明；
- 时间膨胀修复仅对「速度有界且可预测」的动态障碍成立；预测误差会破坏其可靠性，须配合反应式急停；
- 证书 TTL 必须短于障碍穿越 c_safe 所需时间，否则出现「过期但看似安全」的证书；
- VLA 推理 50–200 ms 与 <0.6 ms 控制环存在时域错配，必须异步准入 + 每帧重认证，长尾抖动仍是工程风险。

## 7. 本轮最大风险（最终确认）

**一句话**：**证书保守性导致的可用性塌缩**——为保证 soundness，CCC 在高动态/高自由度/感知不完备场景会大量返回 UNKNOWN，fail-closed 于是频繁回退到弱提议器，系统可能退化为「大模型名义在场、规则控制器实际执行」的空转。
