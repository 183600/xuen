# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「机器人竞赛」×「桌面操作」）

> 第 54 轮把技能组合升级为「动作剖面 α_S + 云边映射 γ_ce + 动作-鲁棒性联合证书 J」，回答的是「能否安全部署」。但**参加 UniBot 这类机器人竞赛，问题不是“能否部署”，而是“在计分规则、时间预算、隐藏测试与部分得分下能否稳定拿分”**。桌面操作（tabletop manipulation）是竞赛的天然试验场：动作可离散为抓/放/推/拉/开/关/倒/递的文法，接触丰富、遮挡严重、长程重排，且隐藏测试会系统性放大“仿真-现实”与“符号-连续”之间的鸿沟。核心矛盾：H24：证书体系证明 soundness，但 soundness ≠ competition utility——过保守的证书“正确但不得分”（拒绝率过高、耗时过长），存在 soundness-utility gap；H25：桌面操作的连续动作剖面 α_S 与符号任务谓词之间存在“可供性鸿沟”（affordance gap），可见验证集上的高分会因隐藏测试的分布漂移而塌陷，形成 benchmark overfitting。

## 0. 直觉与动机

**灵感 1（竞赛契约 → 把“能不能”升级为“值不值”）**
直觉：竞赛有一张计分表 R、一个时间预算 B、一个不公开的隐藏测试分布 T_hidden，以及部分得分规则。一个技能组合哪怕证书完美，如果耗时超过 B、或在隐藏配置上失败、或为了稳妥大量拒绝任务，都可能拿零分。于是把第 54 轮的部署契约扩展为**竞赛契约** `C_comp=(R,B,T_hidden,D)`，证书里新增**计分证书** `S_cert`：期望分、风险调整分（CVaR）、P95 完成时间、覆盖证据。soundness 只是入场券，utility 才是目标。

**灵感 2（桌面动作文法 → 把连续 α_S 落到可供性动作空间）**
直觉：桌面操作的动作不是抽象的 `a∈A`，而是 `(抓取|放置|推|拉|开|关|倒|递)` × `物体 o` × `目标位姿 g` × `抓取位姿 ψ` × `朝向 ω`。并非所有组合都物理可行——杯子通常只能侧抓、薄片不能叠、容器要先清空才能放。定义**可供性动作空间** `A_T = {(p,o,g,ψ,ω) : afford(p,o,ψ)=1}`，技能剖面 `α_S` 只在 `A_T` 上有意义。这把第 54 轮的空泛动作空间变成可枚举、可标注、可复现的桌面文法。

**灵感 3（符号-连续桥接 → 可供性鸿沟是隐藏测试的放大器）**
直觉：竞赛评分按符号谓词（`on_table`、`in_bin`、`stacked`、`cleared`）给分，而策略输出的是连续动作。连续动作→符号谓词的 grounding 函数 `ground` 在接触、遮挡、微小位移处最容易错。可见验证集通常物体少、遮挡轻，隐藏测试却会加杂物、改光照、换物体。**可供性鸿沟** `gap_aff = sup_o |score_visible(o) - score_hidden(o)|` 正是 benchmark overfitting 的可度量代理。

**灵感 4（裁判对抗 + 部分得分保全 → 竞赛是带“弃权期权”的随机最短路）**
直觉：真实赛场的最优策略往往不是“把最难任务做完”，而是“先稳拿部分分，再在剩余预算内赌高价值任务”。把规划建模为带**中止期权（abort option）**的约束随机最短路：每到一个检查点，可选择继续、回退或**冻结已得分**（bank partial credit）。同时用**裁判对抗**在约束歧义集内生成隐藏配置，估计 CVaR 而非均值。规划目标是 `max E[score] - λ·CVaR_tail`，并受计分证书约束。

**灵感 5（竞赛迁移 → 多赛道/多轮次的技能复用）**
直觉：UniBot 通常有多个赛道/多轮赛制（初赛、复赛、决赛，或不同桌面布局）。把第 54 轮的 JTC 扩展为**赛道迁移证书** `CTC`：记录赛道签名 `σ_track`（物体集、布局、评分权重）、鲁棒性谱漂移 `Δρ`、动作对齐漂移 `Δa` 与 rubric 差异 `ΔR`。只有当迁移预算闭合时才复用技能，否则触发重组合或重训练。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（桌面动作文法与可供性动作空间）**
桌面动作文法 `G_T=(P,O,G,Ψ,Ω)`，`P={pick,place,push,pull,open,close,pour,handover}`，`O` 为物体集，`G` 为目标位姿集，`Ψ` 为抓取位姿集，`Ω` 为朝向集。动作 `a=(p,o,g,ψ,ω)`，可供性谓词 `afford(p,o,ψ)∈{0,1}`。可供性动作空间 `A_T={(p,o,g,ψ,ω) : afford(p,o,ψ)=1}`。技能 `S` 的桌面剖面 `α_S: A_T→[0,1]`，**桌面覆盖** `cover_T(S,A_τ)=1 ⟺ ∀a∈A_τ, α_S(a)≥θ_cov`。

**定义 122（符号谓词与可供性鸿沟）**
任务谓词集 `Π={on_table,in_bin,stacked,cleared,open,...}`，grounding 函数 `ground: A_T^* × O → 2^Π`。轨迹 `τ` 的符号得分 `score(τ)=Σ_{π∈Π} w_π·[π∈ground(τ)]`。**可供性鸿沟**
```
gap_aff(S) = sup_{o~T_hidden} | E_{τ~π_S}[score(τ)|o] - E_{τ~π_S}[score_visible(τ)|o] |
```

**定义 123（竞赛契约与风险调整计分）**
竞赛契约 `C_comp=(R,B,T_hidden,D)`：`R` 计分表、`B` 时间预算、`T_hidden` 隐藏测试分布、`D` 披露约束。轨迹得分 `score(τ)∈[0,S_max]`，允许部分得分。**风险调整目标** `J_risk(π)=E_{T_hidden}[score] - λ·CVaR_α(loss)`，`loss=S_max-score`，并满足 `P(T(τ)≤B) ≥ 1-ε_t`。

**定义 124（计分证书）**
计分证书 `S_cert=(ŝ, CVaR_α, t_p95, cov, evidence)`：`ŝ` 期望分估计、`CVaR_α` 尾部风险、`t_p95` 完成时间 P95 分位、`cov` 隐藏分布覆盖证据（共形/对抗采样）、`evidence` 至少含对抗反例与预算日志。若 `ŝ≥s_min ∧ CVaR_α≥c_min ∧ t_p95≤B` 则计分证书成立。

**定义 125（裁判对抗与隐藏测试鲁棒性）**
裁判对抗 `Adv_η` 在歧义集 `U_η(T_visible)={T' : W(T',T_visible)≤η}` 内生成隐藏配置。**benchmark overfitting gap** `G_bo = E_{T_visible}[score] - E_{T_hidden}[score]`。要求 `G_bo ≤ Γ_bo` 且 `P_{T_hidden}(score≥s_min) ≥ 1-δ_h`。

**定义 126（部分得分保全与中止期权）**
中止策略 `π_abort` 在检查点 `c_k` 选择 `{continue, backtrack, bank}`，`bank` 冻结当前已得分。**保全价值** `V_bank(c_k)=max(score_banked, E[continue]-c_risk)`。规划目标为带中止期权的约束随机最短路。

**定义 127（赛道迁移证书）**
赛道迁移证书 `CTC=(σ_track, Δρ, Δa, ΔR, budget)`：`σ_track=(O_track, layout, rubric_weights)`，`Δρ` 鲁棒性谱漂移、`Δa` 动作对齐漂移、`ΔR` rubric 差异。若 `||Δρ||+||Δa||+||ΔR|| ≤ budget` 则允许跨赛道复用，否则重组合。

## 2. 关键算法 伪代码

### IP-121 TAG（Tabletop Action Grammar）

```python
def build_tabletop_space(objects, goals, grasps, orientations, afford):
    A_T = set()
    for o in objects:
        for g in goals:
            for psi in grasps:
                for p in PRIMITIVES:
                    for omega in orientations:
                        if afford(p, o, psi):
                            A_T.add((p, o, g, psi, omega))
    return A_T

def tabletop_cover(skill, A_tau, theta_cov=0.8):
    return all(skill.alpha.get(a, 0.0) >= theta_cov for a in A_tau)
```

### IP-122 SGP（Symbolic Grounding Profiler）

```python
def ground_score(traj, objects, pi_set, weights):
    preds = ground(traj, objects)
    return sum(weights[p] for p in preds if p in pi_set)

def affordance_gap(policy, visible_set, hidden_set, pi_set, weights):
    sv = mean(ground_score(policy.run(o), o.objects, pi_set, weights) for o in visible_set)
    sh = mean(ground_score(policy.run(o), o.objects, pi_set, weights) for o in hidden_set)
    return abs(sv - sh), sv, sh
```

### IP-123 CARP（Competition-Aware Risk-adjusted Planner）

```python
def competition_plan(skills, C_comp, checkpoints, K=512):
    best = None
    for path in enumerate_candidate_paths(skills, C_comp.rubric):
        samples = simulate_score(path, C_comp.T_hidden, n=K)
        s_hat = mean(samples)
        cvar = cvar_alpha(samples, C_comp.alpha)
        t_p95 = quantile([path.runtime(s) for s in samples], 0.95)
        if s_hat < C_comp.s_min or cvar < C_comp.c_min or t_p95 > C_comp.B:
            continue
        val = s_hat - C_comp.lambda_risk * (C_comp.S_max - cvar)
        val += option_value(path, checkpoints, C_comp)   # 中止期权
        if best is None or val > best.val:
            best = Plan(path, val, ScoreCert(s_hat, cvar, t_p95))
    return best
```

### IP-124 RAV（Referee Adversary Validation）

```python
def referee_validate(policy, T_visible, eta, n_adv=256):
    configs = []
    for _ in range(n_adv):
        T_adv = sample_ambiguity(T_visible, eta)   # 杂物/光照/物体/初始位姿
        traj = policy.run(T_adv)
        configs.append((T_adv, ground_score(traj, ...)))
    gap = mean_visible(policy) - mean([s for _, s in configs])
    cvar = cvar_alpha([s for _, s in configs], alpha=0.1)
    ok = (gap <= Gamma_bo)
    return ('ok' if ok else 'reject', gap, cvar, worst_configs(configs))
```

### IP-125 SCC（Score Certificate Compiler）

```python
def compile_score_cert(policy, C_comp, n=512):
    test = sample(C_comp.T_hidden, n)
    samples = [ground_score(policy.run(T), ...) for T in test]
    s_hat = mean(samples)
    cvar = cvar_alpha(samples, C_comp.alpha)
    t_p95 = quantile([policy.runtime(T) for T in test], 0.95)
    cov = conformal_coverage(samples, C_comp.delta)
    if s_hat < C_comp.s_min or cvar < C_comp.c_min or t_p95 > C_comp.B:
        return ('reject', s_hat, cvar, t_p95)
    return ('ok', ScoreCert(s_hat, cvar, t_p95, cov, evidence=samples))
```

### IP-126 PCP（Partial-Credit Preservation）

```python
def bank_aware_plan(path, checkpoints, score_banked, budget_left, c_risk):
    if not checkpoints:
        return ('continue', score_banked)
    c_k = checkpoints[0]
    cont_val = expected_remaining(path, c_k) - c_risk
    if score_banked >= cont_val or budget_left < path.min_time(c_k):
        return ('bank', score_banked)          # 冻结部分分
    return ('continue', bank_aware_plan(path, checkpoints[1:],
                                        score_banked, budget_left, c_risk))
```

### IP-127 CTC（Competition Track Certificate）

```python
def track_transfer_certify(CTC_source, track_target, budget):
    sigma = track_signature(track_target)     # 物体集/布局/rubric 权重
    d_rho = rho_drift(CTC_source.rho, track_target.rho)
    d_a = action_alignment_drift(CTC_source.gamma_ce, track_target.phi)
    d_R = rubric_divergence(CTC_source.rubric, track_target.rubric)
    if norm(d_rho) + norm(d_a) + norm(d_R) > budget:
        return ('reject', 'transfer_budget_exceeded', d_rho, d_a, d_R)
    return ('ok', CTC(sigma, d_rho, d_a, d_R, budget))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| TAG | O(|O|·|G|·|Ψ|·|P|·|Ω|) | O(|A_T|) | afford 谓词 sound、文法完备 |
| SGP | O(|τ|·|Π| + |T|) | O(|Π|) | grounding 确定性、谓词可观测 |
| CARP | O(|paths|·K·(|S|+|Π|)) | O(|paths|) | 采样无偏、CVaR 一致估计 |
| RAV | O(n_adv·(|T|+|τ|)) | O(n_adv) | 歧义集覆盖、对抗采样有效 |
| SCC | O(n·(|τ|+|Π|)) | O(n) | 共形可交换性、分位估计收敛 |
| PCP | O(|checkpoints|) | O(1) | 检查点可观测、得分可冻结 |
| CTC | O(|ρ|+|A|+|R|) | O(|ρ|+|A|+|R|) | 漂移度量满足度量公理、预算闭合 |

**正确性定理（Competition Utility Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 隐藏测试分布 `T_hidden` 与对抗歧义集 `U_η` 的 Wasserstein 距离 ≤ η，且 `Adv_η` 采样覆盖其支撑；**(A30)** grounding 函数在桌面动作文法上可观测且确定性；**(A31)** 计分函数 `score` 满足 Lipschitz 连续性（避免奖励黑客的断崖式跳变）。
则对任意满足 `S_cert` 的计划 `π`：
```
P_{T_hidden}(score(π) ≥ s_min) ≥ 1 - δ_h - P(G_bo > Γ_bo) - P(CVaR_α < c_min)
```
且风险调整目标 `J_risk` 的估计偏差 ≤ `O(η + 1/√K)`。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 奖励黑客：优化 rubric 产生退化行为 | 高 | rubric 平滑化 + 行为审计 + 反例回放 |
| 隐藏测试分布不可知，对抗集失配 | 高 | 多歧义集 DRO + 共形覆盖 + 在线校准 |

| 迁移证书跨赛道失真 | 中 | 赛道签名对齐 + 迁移预算 + 冷启动重组合 |

## 6. 本轮最大风险

**一句话**：竞赛计分证书把“能否部署”升级为“能否拿分”，但其有效性**三重依赖计分函数的可信建模、隐藏测试分布与裁判对抗歧义集的匹配、以及桌面可供性 ground 的可观测性**；一旦计分函数被奖励黑客利用、或对抗歧义集与真实隐藏测试失配、或可供性鸿沟在杂乱遮挡下被系统性低估，系统就会“优化出一个高分的假象”，在真实赛场上稳定失分——因此必须以 **rubric 平滑 + 多歧义集 DRO + 可供性 gap 绊线** 三重护栏，宁可保守拿稳部分分，绝不把可见验证集的虚高分数当作竞赛能力。

```python
    return A_T

def tabletop_cover(skill, A_tau, theta_cov=0.8):
    return all(skill.alpha.get(a, 0.0) >= theta_cov for a in A_tau)
```

```python
def ground_score(traj, objects, pi_set, weights):
    preds = ground(traj, objects)
    return sum(weights[p] for p in preds if p in pi_set)

def affordance_gap(policy, visible_set, hidden_set, pi_set, weights):
    sv = mean(ground_score(policy.run(o), o.objects, pi_set, weights) for o in visible_set)
    sh = mean(ground_score(policy.run(o), o.objects, pi_set, weights) for o in hidden_set)
    return abs(sv - sh), sv, sh
```

### IP-123 CARP

```python
def competition_plan(skills, C_comp, checkpoints, K=512):
    best = None
    for path in enumerate_candidate_paths(skills, C_comp.rubric):
        samples = simulate_score(path, C_comp.T_hidden, n=K)
        s_hat = mean(samples)
        cvar = cvar_alpha(samples, C_comp.alpha)
        t_p95 = quantile([path.runtime(s) for s in samples], 0.95)
        if s_hat < C_comp.s_min or cvar < C_comp.c_min or t_p95 > C_comp.B:
            continue
        val = s_hat - C_comp.lambda_risk * (C_comp.S_max - cvar)
        val += option_value(path, checkpoints, C_comp)   # 中止期权
        if best is None or val > best.val:
            best = Plan(path, val, ScoreCert(s_hat, cvar, t_p95))
    return best
```

```python
def bank_aware_plan(path, checkpoints, score_banked, budget_left, c_risk):
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TAG | O(|O|·|G|·|Ψ|·|P|·|Ω|) | O(|A_T|) | afford 谓词 sound，文法完备 |
| SGP | O(|τ|·|Π| + |T|) | O(|Π|) | grounding 确定性、谓词可观测 |
| CARP | O(|paths|·K·(|S|+|Π|)) | O(|paths|) | 采样无偏、CVaR 一致估计 |
| RAV | O(n_adv·(|T|+|τ|)) | O(n_adv) | 歧义集覆盖、对抗采样有效 |
| SCC | O(n·(|τ|+|Π|)) | O(n) | 共形可交换性、分位估计收敛 |
| PCP | O(|checkpoints|) | O(1) | 检查点可观测、得分可冻结 |
| CTC | O(|ρ|+|A|+|R|) | O(|ρ|+|A|+|R|) | 漂移度量满足度量公理、预算闭合 |

**正确性定理（Competition Utility Soundness）**
假设第 54 轮 (A26)-(A28) 成立；**(A29)** `T_hidden` 与对抗歧义集 `U_η` 的 Wasserstein 距离 ≤ η，且 `Adv_η` 采样覆盖其支撑；**(A30)** grounding 在桌面动作文法上可观测且确定性；**(A31)** 计分函数 `score` 满足 Lipschitz 连续性（抑制奖励黑客的断崖跳变）。
则对任意满足 `S_cert` 的计划 `π`：
```
P_{T_hidden}(score(π) ≥ s_min) ≥ 1 - δ_h - P(G_bo > Γ_bo) - P(CVaR_α < c_min)
```
且 `J_risk` 估计偏差 ≤ `O(η + 1/√K)`。
关键：**soundness 先于 utility**，**utility 由风险调整而非均值决定**，**隐藏分布由对抗歧义集近似且可校准**。

## 5. 本轮最大风险

**一句话**：竞赛计分证书把“能否部署”升级为“能否拿分”，但其有效性**三重依赖计分函数的可信建模、隐藏测试分布与裁判对抗歧义集的匹配、以及桌面可供性 ground 的可观测性**；一旦计分函数被奖励黑客利用、或对抗歧义集与真实隐藏测试失配、或可供性鸿沟在杂乱遮挡下被系统性低估，系统就会“优化出一个高分的假象”，在真实赛场上稳定失分——因此必须以 **rubric 平滑 + 多歧义集 DRO + 可供性 gap 绊线** 三重护栏，宁可保守拿稳部分分，绝不把可见验证集的虚高分数当作竞赛能力。
