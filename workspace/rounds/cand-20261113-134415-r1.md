# 第 66 轮（承接第 65 轮「VISTA 故障可归因安全时序」IP-214~223；灵感循环第 3 轮；本轮灵感：「成本控制」×「SLAM」）

> 第 65 轮把第 64 轮的「几何可证伪」升级为「故障可归因」，其自述最大风险一如既往地准确：**归因依赖"故障属于有限假设集、且视觉与几何失效相互独立"；真实故障是未知类型的组合，透明/镜面/对抗 patch 让视觉与几何共享同一个分布外失效源，FIR 会把未知复合故障强行归入最近假设、只膨胀错误的球——系统因"已经归因"而更自信地继续执行。** 本轮不换模态，而换尺度与账本：第 65 轮问「这一块里谁坏了」，LEDGER 问「**在整个会话的地图上，这个故障是否全局可解释？以及，花多少代价才值得再确认一次？**」

## 0. 直觉与动机

**灵感 1（SLAM → 把单块 15 维快照升级为会话级因子图）**
直觉：VISTA 的三阶段签名本质是"一个动作块内的 15 维快照"。有三类故障在单块内**根本不可辨识**：(i) F/T 零偏随温度缓慢爬升（慢漂移）；(ii) 两个外形相似的物体造成感知混叠（perceptual aliasing）；(iii) 接触模型在换物体/换接触点后才错。它们只有"回到同一个物体、同一个位置、同一种接触"时才会暴露——这正是 SLAM 的回环（loop closure）：局部里程计必然漂移，回环把漂移拉回来。于是把整个操作会话写成因子图：节点是机器人/物体位姿、接触事件与故障参数，边是视觉、接触、力、触觉、本体感觉；**回环 = 再次观察 / 再次接触 / 换手重抓 / 对称加载**。局部不可辨识的故障，在回环处第一次变成可辨识。

**灵感 2（SLAM 鲁棒后端 → 可切换约束本身就是归因器）**
直觉：鲁棒 SLAM 处理离群观测用 switchable constraints / dynamic covariance scaling / max-mixture：每条边带开关 s∈[0,1]，坏边被自动关掉，图仍自洽。VISTA 用"离线故障注入拟合 p(ρ|H)"，本质上仍是**先枚举全局假设、再匹配**；未知故障只能被塞进最近假设。LEDGER 反过来：不先枚举全局故障，而是让**每条边的开关自己说话**；再看开关的**结构**——哪些因子族、哪些时段、是否与载荷相关、能否被一个公共偏置变量解释、是否空间聚集。这天然能表达未知/复合故障：解释不了就输出 `unexplained`，而不是强行归因。**归因从"匹配模板"变成"解释开关"**。

**灵感 3（成本控制 → 信息/成本比与影子价格）**
直觉：VISTA 的 AFA 最大化故障假设互信息，却没问"值不值"。探测有真实成本：力冲量（可能压坏）、时间、能耗、计算、磨损；还有"被诱导探测"的攻击面。成本控制的核心不是省钱，而是**把有限预算配给边际安全收益最大的证据**。于是探针目标从 `I(H;ρ)` 变为 `I(H;ρ)/C(a)`，并用预算的**影子价格 λ\*** 做停止：当边际信息/成本 < λ\* 时停止探测、转为保守执行。λ\* 随预算收紧而升高——钱越少，越只在刀刃上花；这与"安全预算"的经济学解释天然一致。

**灵感 4（成本控制 → 账本化 anytime 证书 + 预算耗尽攻击）**
直觉：安全证书应是"随时可审计的账本"：已花成本、剩余预算、最坏下一步成本、以及"任意时刻都不超支"的概率保证。更关键的是——**成本本身可被攻击**：对手用诱饵制造大量假故障，让你把探测预算耗在假目标上（denial-of-wallet / 预算耗尽），真正危险的故障反而没钱查。SLAM 侧也有同构攻击：**伪造回环**（感知混叠/重放）污染地图，从而骗过全局一致性检查。因此 AIC-L 必须把"成本攻击"和"假回环"纳入最坏情形，并预留**安全储备金 R**。

**灵感 5（合流 → LEDGER：Loop-closure Enabled Drift-corrected Graph Evidence & Risk-budget，回环使能的漂移校正图证据与风险预算闭环）**
闭环：FAFG 建图 → SCA 开关归因 → LCO 回环可观测性 → BIG 预算化探针 → LBC 账本化证书 → DCS-V 定向协方差 → CSP-L 回环感知块规划 → AIC-L 成本/回环对抗认证 → J_ledger。一句话：第 64 轮「可证伪」→ 第 65 轮「可归因」→ **第 66 轮「全局自洽、成本可审计、无法被预算耗尽」的可归因**。

**灵感 6（VISTA 组件的原位升级）**
- **CGG-V → CGG-G**：几何假设须与 FAFG 全局一致；局部力残差高但图一致时，优先查开关结构而非直接降级几何。
- **FIR → SCA**：从 `p(ρ|H)` 贝叶斯匹配升级为"开关结构 + BIC 模型选择"，支持 `unexplained`。
- **AFA → BIG**：从"最大化互信息"升级为"最大化单位成本互信息"，带影子价格停止与预算约束。
- **CSC → LBC**：块级认证前缀加成本账本与 anytime 不超支保证，保留安全储备金。
- **RSC-V → DCS-V**：按归因结果对**因子族**做动态协方差缩放，而非只调三个半径；地图漂移协方差显式传播。
- **WCV-V → WCV-G**：搜索域加图一致性约束 `χ²(G)≤τ_χ`；归因不明时按开关后验加权。
- **CSP-V → CSP-L**：在图上规划，把回环/重访/对称接触作为**主动取证元技能**，边成本含预算。
- **AIC-V → AIC-L**：干扰集增成本耗尽、假回环、地图投毒；证书含预留储备与最坏成本。
- **J_vista → J_ledger**：证书增 switch_profile、explanation_bic、loop_closure_gain、cost_ledger、shadow_price、budget_slack。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（LEDGER 闭环）**：LEDGER = (VISTA, FAFG, SCA, LCO, CAB, BIG, LBC, DCS-V, WCV-G, CSP-L, AIC-L, J_ledger)。定位：VISTA 的"会话级图自洽 + 成本预算"升级。不变式：**图优化、开关归因、回环检测、预算规划、证书构建只在语义流与低频线程；实时流只做开关残差评估、预算记账、认证前缀执行与早停，零学习写操作。**
- **定义 234（故障增广因子图 FAFG）**：FAFG 为 `G=(X∪M∪Θ∪S, F)`。`X` 为机器人/物体位姿与接触事件节点；`M` 为几何地图节点；`Θ=(b,k,δ_model)` 为故障参数（F/T 偏置、接触刚度、模型偏差）；`S={s_k}` 为每条因子边上的开关。每条因子 `f_k∈F` 有残差 `r_k` 与信息矩阵 `Ω_k`。联合估计
  `min_{X,M,Θ,S} Σ_k ρ(s_k r_k; Ω_k) + Ψ(s_k)`，
  其中 `ρ` 为鲁棒核、`Ψ` 为开关先验（鼓励 s=1，除非残差无法解释）。**建图与归因在同一个优化里完成。**
- **定义 235（因子族与开关剖面）**：`F=F_vis∪F_contact∪F_force∪F_tactile∪F_loop∪F_prior`。开关剖面
  `π = { s̄_{F_i}（各族平均开关）, corr(s, f_n)（与载荷相关）, corr(s,t)（与时间相关）, spatial_cluster(s)（空间聚集度）, Δχ²_bias（公共偏置能否解释） }`。
  剖面是归因的**结构指纹**，而非标量残差。
- **定义 236（可切换约束归因 SCA）**：候选解释 `E={H0,H_geo,H_force,H_model,H_vis,H_policy,H_unknown}`。对每个解释 `E` 施加**结构化开关先验**：`H_force` 要求所有力因子开关由同一公共偏置 `b` 驱动（`s` 与 `b` 联合下降）；`H_geo` 要求视觉/回环因子开关**空间聚集**而接触因子完好；`H_model` 要求接触因子开关随载荷单调；`H_policy` 要求开关与块间不一致同步。选择
  `E* = argmin_E [ χ²_E + λ_c·d_E ]`（BIC：`χ²_E + d_E ln n`）。
  若 `min_E χ²_E > τ_χ`，判 `H_unknown / unexplained`，**不强行归因**。解释权重 `w_E ∝ exp(−BIC_E/2)`。
- **定义 237（回环可观测性与回环增益 LCO）**：线性化信息矩阵 `Λ=JᵀΩJ`。故障模式 `v` 可观测 ⇔ `vᵀΛv>0`；其可观测裕度 `κ_obs(v)=vᵀΛv / (vᵀv·λ_max(Λ))`。回环集 `L` 的增益
  `G_lc(L)=logdet(Λ + J_LᵀΩ_LJ_L) − logdet(Λ)`（D-最优信息增量）。
  关键构造：**反向对称回环**（回到同一接触构型但法向力反号）使公共偏置 `b` 的符号项相消，从而使 `H_force` 方向从 `Λ` 的零空间中被"点亮"，`κ_obs` 由 0 变正。这是 VISTA 零力窗之外的**第二个可辨识机制**，且不需要停力。
- **定义 238（漂移状态与协方差传播）**：地图/位姿漂移 `δ_t`，协方差 `Σ_δ(t)` 随里程计传播；回环观测以卡尔曼增益 `K` 做校正：`δ_t⁺=δ_t⁻+K(z−Hδ_t⁻)`，`Σ_δ⁺=(I−KH)Σ_δ⁻`。LEDGER 不再把几何先验 `φ̂` 当常量，而是把 `(φ̂,Σ_δ)` 作为 WCV-G 的输入；拒绝回环需给出协方差依据，不能只凭单次残差。
- **定义 239（成本向量与风险调整账本 CAB）**：单次证据动作 `a` 的成本向量 `c(a)=(c_f 力冲量, c_t 时间, c_e 能耗, c_c 计算, c_w 磨损)`；风险调整标量成本
  `C(a)=wᵀc(a)+λ_risk·CVaR_α(L(a))`。
  账本 `Ledger_t=(C_used, B_rem, c_worst_next, R)`，`R` 为不可动用的安全储备金。
- **定义 240（预算化信息增益探针 BIG）**：探针选择
  `a* = argmax_{a∈A} I(ℋ;ρ(a)|G) / C(a)`，
  `s.t. C(a)≤B_rem−R`、`f_n≤f_safe`、`strain≤ε_strain`、`χ²(G_after)≤τ_χ`。这是 AFA 的"每单位成本互信息"版本；易损物体仍先走 `visual_probe`/`null_test`。
- **定义 241（影子价格与停止准则）**：预算约束的拉格朗日乘子 `λ*`（预算的边际安全价值）。最优投入满足 `dI/dC=λ*`；当 `max_a ΔI(a)/C(a) < λ*` 时停止主动取证，转保守执行。`λ*` 由对偶问题求得，预算越紧 `λ*` 越高；它同时给出"再花一元钱买多少安全"的可审计解释。
- **定义 242（账本化随时证书 LBC）**：`J_ledger` 含成本账本。`Valid(J_ledger) ⇔ Valid(J_vista) ∧ χ²(G)≤τ_χ ∧ (¬unexplained ∨ 已进入保守回退) ∧ C_used + c_worst_next ≤ B − R ∧ 回环支持度≥τ_lc`。账本在**任意时刻**有效，不只在块边界。
- **定义 243（预算的 anytime 鞅界）**：设单步成本增量 `c_t` 条件均值 `μ`、条件次高斯参数 `σ`。则对任意 `T`，
  `P[sup_{t≤T} C_used(t) ≥ B] ≤ exp(−(B−μT)²/(2Tσ²))`；
  用 Ville 型非负上鞅可在不知 `T` 时给出 anytime 界。预算耗尽攻击等价于对手抬高 `μ`，LBC 通过预留 `R` 与 `λ*` 上升自动降级。
- **定义 244（DCS-V 定向协方差缩放）**：对每个因子族 `F_i` 采用动态协方差缩放核 `ρ_DCS(r)=(χ²/(χ²+r²))²`，缩放尺度 `s_i` 只作用于被 SCA 归因的族：`H_force→s_force↑`（并零力窗重标定 `b`），`H_geo→s_vis/s_loop↑`（并保持 `s_force`），`H_model→s_contact↑`（切柔顺）。融合协方差 `Σ=Σ_geo+Σ_force+Σ_model` 只用被归因分量，避免第 65 轮"总膨胀同一个球"。
- **定义 245（CSP-L 回环感知块规划）**：在 FAFG 上以块为边做 A*；显式加入**取证型回环元技能** `revisit`、`regrasp`、`symmetric_load`、`null_test`、`visual_probe`。块边代价含风险调整成本 `C` 与归因熵 `λ_fi·H(P(E|G))`，并要求 `C_used+C(edge)≤B−R` 与 `Valid(J_ledger)`。规划器可为了长期可辨识性**主动绕路回访**——用一点时间/能耗换一次关键回环，这是 SLAM 主动回环（active loop closure）在安全上的对应物。
- **定义 246（AIC-L 成本/回环对抗认证）**：干扰集 `ℰ_L=ℰ_V×ℰ_cost×ℰ_loop`。`ℰ_cost` 含诱饵故障引发的预算耗尽（denial-of-wallet）、假报警洪泛；`ℰ_loop` 含伪造回环、重放、感知混叠导致的错误闭环。认证要求：最坏成本 `C_worst(ℰ_L)`、安全储备 `R`、假回环拒识率、以及"预算被耗尽时仍能安全降级"。`J_dir` 增 `cost_calib_ver`、`loop_support_ver`。
- **定义 247（LEDGER 证书 J_ledger）**：`J_ledger=(J_vista, switch_profile, explanation_bic, unexplained, loop_closure_gain, graph_chi2, cost_ledger, shadow_price, budget_slack, aic_l_ver)`。Valid 条件见定义 242；审计链新增：为何判这个故障（开关剖面与 BIC）、为何再做/不再做探针（`λ*` 与边际信息）、这张图是否靠回环才自洽（`loop_closure_gain`）、预算还剩多少且是否含储备。
- **定义 248（LEDGER 闭环算子）**：语义流 `[LiDAR→LSF→USR/MEL→FAFG 建图→VPG/VCV→SCA 开关归因→LCO 回环规划→BIG 探针→WCV-G→CSP-L 块规划→LBC 认证前缀→Shield→执行 k* 步→EV_exec→DCS-V→OLP→DIR→AIC-L]`；实时流 `[锚点读→开关残差评估→预算记账→LBC 早停→WCV-G 编译→π_σ 前缀派发→J_ledger 构建]`。

## 2. 关键算法骨架

```python
# SCA：开关剖面 → 结构化解释 → BIC 选择（语义流）
G = fafg.optimize(obs, switches_init=1.0)          # 联合估计 X,M,Theta,S
prof = switch_profile(G.S)                          # 族均值/载荷相关/时间相关/空间聚集
bics = {E: explained_chi2(G, E) + complexity(E)*log(n) for E in EXPLANATIONS}
E_star = argmin(bics)
unexplained = bics[E_star] > TAU_CHI
if unexplained:
    target = 'conservative_fallback'               # 不强行归因
else:
    G = dcs_v.scale_family(G, E_star)              # 只缩放被归因的族

# LCO + BIG：回环值不值得走，探针值不值得做
for L_c in candidate_loops:                         # revisit / regrasp / symmetric_load
    gain[L_c] = logdet(info(G) + info(L_c)) - logdet(info(G))
for a in PROBES:
    ratio[a] = expected_mutual_info(E_post, a, G) / cost(a)
a_star = argmax(ratio) if cost(a_star) <= B_rem - R else None

# LBC：账本化随时证书
C_next = worst_case_cost(next_chunk, E_post)
valid = (valid(J_vista) and chi2(G) <= TAU_CHI
         and (not unexplained or in_fallback)
         and C_used + C_next <= B - R)
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（回环可辨识性）**：若存在一条回环因子 `ℓ`，使故障模式 `v` 满足 `vᵀJ_ℓᵀΩ_ℓJ_ℓv>0`，则 `vᵀΛv>0`，`v` 可观测；Laplace 近似下估计误差 `‖v̂−v‖² ≤ σ/λ_min(Λ_L)`。反向对称回环使公共偏置的符号项相消、打破其零空间，从而把 VISTA 需要"零力窗"才能辨识的 `H_force` 变成"回环即可辨识"。
- **引理 10（预算化探针的近似与不超支）**：归一化等成本下，互信息对测量集单调子模，成本-收益贪心达 `(1−1/e)` 近似；任意成本下用拉格朗日松弛，近似比含对偶间隙。anytime 预算超支概率由定义 243 的鞅界控制，预留 `R` 保证安全关键证据永不被饿死。
- **定理 9（LEDGER 全局一致-归因-安全）**：在 A94–A99 下，`Valid(J_ledger)` ⇒ 地图全局自洽（`χ²≤τ_χ`）∧（归因正确 ∨ 显式 `unexplained` 并保守回退）∧ 预算不超支且保留储备 ∧ 前缀安全 ∧ 回环支持充分。证书链从"几何-技能-干扰-接触-归因"扩到"**全局自洽-归因-成本**"。
- **定理 10（成本最优取证）**：对凹信息-成本前沿，`λ*` 停止策略在拉格朗日意义下最优；其经济学解释是"边际安全/边际成本 = 预算影子价格"。储备金 `R` 使预算耗尽攻击不能把安全证据预算压到 0。
- **命题（开关吸收风险，本轮的核心张力）**：鲁棒核在前 `s→0` 会**把真实故障当作离群边吸收**，使 `χ²(G)` 变小而物理状态错误；当故障残差落在核的影响区间内时，归因在信息论上不可辨识。故 LEDGER 必须用 BIC 惩罚 + 回环交叉验证 + 储备金来对抗"过度自洽"。
- **实时性**：FAFG 优化、SCA、LCO、BIG、CSP-L 全在语义流；实时流只增开关残差评估（<0.1ms）、预算记账（<0.02ms）、LBC 早停（<0.02ms），目标仍 ≤2.5ms。

## 2. 形式化定义（完整版）

**定义 233（LEDGER 闭环）** LEDGER 是 VISTA 的"会话级图自洽 + 成本预算"升级：在 VISTA 的"语义流 ∘ 实时流"骨架上挂载 FAFG（故障增广因子图）、SCA（开关归因）、LCO（回环可观测性）、CAB（成本预算）、BIG（预算化探针）、LBC（账本证书），并原位升级 DCS-V/WCV-G/CSP-L/AIC-L/J_ledger。不变式：**所有图优化、开关归因、回环检测、预算规划、证书构建只发生在语义流与低频线程；实时路径只做开关残差评估、预算记账、安全前缀执行与早停，零学习写操作。**

**定义 234（故障增广因子图 FAFG）** FAFG 为 `G=(X∪M∪Θ∪S, F)`。`X` 为机器人/物体位姿与接触事件节点，`M` 为几何地图节点，`Θ=(b,k,δ_model)` 为故障参数，`S={s_k}` 为每条因子边的开关。每条因子 `f_k∈F` 有残差 `r_k` 与信息矩阵 `Ω_k`。联合估计
`min_{X,M,Θ,S} Σ_k ρ(s_k r_k; Ω_k) + Ψ(s_k)`，
`ρ` 为鲁棒核、`Ψ` 为开关先验（鼓励 `s=1`，除非残差无法被任何结构化故障解释）。**建图、接触估计与故障归因在同一个优化里完成**，因此"几何先验"不再是一个外部常量，而是图的一部分。

**定义 235（因子族与开关剖面）** 因子族 `F=F_vis∪F_contact∪F_force∪F_tactile∪F_loop∪F_prior`。开关剖面
`π = { s̄_{F_i}（各族平均开关）, corr(s,f_n)（与法向力相关）, corr(s,t)（与时间相关）, spatial_cluster(s)（空间聚集度）, Δχ²_bias（公共偏置能否解释） }`。
剖面刻画故障的**结构指纹**：例如"力因子开关整体下降且与载荷无关、可由公共偏置解释"指向 `H_force`；"视觉/回环因子开关空间聚集、接触因子完好"指向 `H_geo`/感知混叠；"接触因子开关随载荷单调"指向 `H_model`。

**定义 236（可切换约束归因 SCA）** 候选解释 `E={H0,H_geo,H_force,H_model,H_vis,H_policy,H_unknown}`。对每个解释施加**结构化开关先验**，然后做模型选择：
`E* = argmin_E BIC_E = argmin_E [ χ²_E(G|E) + d_E ln n ]`，
其中 `χ²_E` 是"用解释 `E` 重优化后"的图残差，`d_E` 是解释的自由度（公共偏置 1 维、空间簇若干维等）。若 `min_E χ²_E > τ_χ`，判 `H_unknown / unexplained`，**不强行归因**，进入保守回退。解释权重 `w_E ∝ exp(−BIC_E/2)` 供 WCV-G 做边缘化。与第 65 轮 FIR 的根本区别：FIR 在"残差签名 → 预定义似然"上做贝叶斯；SCA 在"开关结构 → 可解释性"上做**模型选择**，因此未知/复合故障有合法的"说不清"出口，而不是被塞进最近假设。

**定义 237（回环可观测性与回环增益 LCO）** 线性化信息矩阵 `Λ=JᵀΩJ`。故障模式 `v` 可观测 ⇔ `vᵀΛv>0`，可观测裕度 `κ_obs(v)=vᵀΛv/(vᵀv·λ_max(Λ))`。回环集 `L` 的 D-最优信息增益
`G_lc(L)=logdet(Λ + J_LᵀΩ_LJ_L) − logdet(Λ)`。
关键构造是**反向对称回环**：回到同一接触构型但法向力反号。若公共偏置 `b` 在两次测量中进入残差的符号相反，则 `b` 项相消，`b` 方向的零空间被打破，`κ_obs(b)` 由 0 变正。这给 VISTA 的"零力窗"补了**第二个可辨识机制**：不必停止接触、不必空载，只需一次对称回访。类似地，"重抓/换手"可分离工具坐标系偏置，"回到同一物体"可分离地图漂移与真实几何变化。

**定义 238（漂移状态与协方差传播）** 地图/位姿漂移 `δ_t` 及其协方差 `Σ_δ(t)` 随里程计传播；回环观测 `z` 以卡尔曼增益 `K` 校正：`δ_t⁺=δ_t⁻+K(z−Hδ_t⁻)`，`Σ_δ⁺=(I−KH)Σ_δ⁻`。LEDGER 把 `(φ̂,Σ_δ)` 而非常量 `φ̂` 输入 WCV-G；拒绝一条回环必须给出协方差/支持度依据，不能只凭单次残差，避免把真实回环当离群丢掉（否则漂移永不校正）。

**定义 239（成本向量与风险调整账本 CAB）** 单次证据动作 `a` 的成本向量
`c(a)=(c_f 力冲量, c_t 时间, c_e 能耗, c_c 计算, c_w 磨损)`；
风险调整标量成本
`C(a)=wᵀc(a)+λ_risk·CVaR_α(L(a))`。
账本 `Ledger_t=(C_used, B_rem, c_worst_next, R)`，其中 `R` 是**不可动用**的安全储备金。成本不是事后统计，而是探针选择、块规划与证书验证的一等约束。

**定义 240（预算化信息增益探针 BIG）** 探针选择
`a* = argmax_{a∈A} I(E;ρ(a)|G) / C(a)`，
`s.t. C(a)≤B_rem−R`、`f_n≤f_safe(φ̂,f̂_vis)`、`strain≤ε_strain`、`χ²(G_after)≤τ_χ`。
候选集 `A={visual_probe, null_test, press, rub, tap, lift, revisit, regrasp, symmetric_load}`。这是 AFA 的"每单位成本互信息"版本：同样一次判别，优先选便宜且信息量大的；易损物体仍禁用接触类探针。

**定义 241（影子价格与停止准则）** 预算约束的拉格朗日乘子 `λ*` 是预算的边际安全价值（`∂V/∂B`）。对凹信息-成本前沿 `I(C)`，最优投入满足 `dI/dC=λ*`。当 `max_a ΔI(a)/C(a) < λ*` 时停止主动取证，转保守执行。`λ*` 随预算收紧而升高：**安全预算越少，越要求每一元买到更多信息**。`λ*` 同时写进证书，作为"为何不再探测"的审计依据。

**定义 242（账本化随时证书 LBC）** `J_ledger` 含成本账本。验证规则
`Valid(J_ledger) ⇔ Valid(J_vista)`
`∧ χ²(G)≤τ_χ`
`∧ (¬unexplained ∨ 已进入保守回退)`
`∧ C_used + c_worst_next ≤ B − R`
`∧ 回环支持度 ≥ τ_lc`
`∧ aic_l_ver 为当前版本`。
账本在**任意时刻**有效，不只在块边界：实时流每个控制周期更新 `C_used` 并检查 `B−R` 余量。这样"安全"不再是一个块结束时的快照，而是一条全程可审计的花费曲线。

**定义 243（预算的 anytime 鞅界）** 设单步成本增量 `c_t` 的条件均值 `μ`、条件次高斯参数 `σ`。对任意 `T`，
`P[sup_{t≤T} C_used(t) ≥ B] ≤ exp(−(B−μT)²/(2Tσ²))`；
用 Ville 型非负上鞅可在未知 `T` 时给出 anytime 界。预算耗尽攻击等价于对手抬高 `μ`（用诱饵制造大量假证据动作）；LBC 通过预留 `R`、抬高 `λ*`、并对"低信息/高成本"动作直接拒绝，使安全关键证据预算不会被饿死。

**定义 244（DCS-V 定向协方差缩放）** 对每个因子族 `F_i` 使用动态协方差缩放核 `ρ_DCS(r)=(χ²/(χ²+r²))²`，缩放尺度 `s_i` 只作用于被 SCA 归因的族：`H_force→s_force↑`（并触发零力窗/对称回环重标定 `b`）；`H_geo→s_vis,s_loop↑`（保持 `s_force`）；`H_model→s_contact↑`（切柔顺）；`H_policy→` 缩短 H、减小 k。融合协方差 `Σ=Σ_geo+Σ_force+Σ_model` 只用被归因分量；从而避免第 65 轮"任一拒绝都总膨胀同一个球"的过度保守，也避免第 65 轮"只调三个半径却漏掉地图漂移"的问题。

**定义 245（CSP-L 回环感知块规划）** 在 FAFG 上以块为边做 A*；显式加入取证型回环元技能 `revisit`、`regrasp`、`symmetric_load`、`null_test`、`visual_probe`。块边代价
`J_edge = C(edge) + λ_fi·H(P(E|G)) + λ_k·Σ hinge(k*−k_req)`，
并要求 `C_used + C(edge) ≤ B−R` 与 `Valid(J_ledger)`。规划器可以为长期可辨识性**主动绕路回访**：用一点时间/能耗换一次关键回环，把"当前多花 2 秒"换成"整段会话不再漂移"。这是 SLAM 主动回环（active loop closure）在安全与归因上的对应物。

**定义 246（AIC-L 成本/回环对抗认证）** 干扰集 `ℰ_L=ℰ_V×ℰ_cost×ℰ_loop`。`ℰ_cost` 含诱饵故障引发的预算耗尽（denial-of-wallet）、假报警洪泛；`ℰ_loop` 含伪造回环、重放、感知混叠导致的错误闭环、地图投毒。认证要求：最坏成本 `C_worst(ℰ_L)`、安全储备 `R` 在攻击下仍非空、假回环拒识率、以及"预算被耗尽时仍能安全降级"。假回环的拒识判据：该回环诱发的开关簇与真实观测支持度不一致、`G_lc` 增益高但`χ²` 不降反升、或与 `Σ_δ` 的先验严重冲突。`J_dir` 增 `cost_calib_ver`、`loop_support_ver`。

**定义 247（LEDGER 证书 J_ledger）** `J_ledger=(J_vista, switch_profile, explanation_bic, unexplained, loop_closure_gain, graph_chi2, cost_ledger, shadow_price, budget_slack, aic_l_ver)`。Valid 条件见定义 242。审计链新增四问：**为何判这个故障**（开关剖面 + BIC）、**为何再做/不再做探针**（`λ*` 与边际信息/成本）、**这张图是否靠回环才自洽**（`G_lc`）、**预算还剩多少且是否含储备**（`Ledger`）。

**定义 248（LEDGER 闭环算子）** 语义流：`[LiDAR→LSF→USR/MEL→FAFG 建图→VPG/VCV→SCA 开关归因→LCO 回环规划→BIG 探针→WCV-G→CSP-L 块规划→LBC 认证前缀→Shield-Skill→OCB-Skill→执行 k* 步→EV_exec→DCS-V→OLP→DIR→SSB→AIC-L]`；实时流：`[锚点读→开关残差评估→预算记账→LBC 早停→WCV-G 编译→π_σ 前缀派发→J_ledger 构建]`。

```python
    def switch_profile(self, S):
        return {
            'family_mean': group_mean(S, by='family'),
            'corr_load':   corr(S[F_force], load),
            'corr_time':   corr(S, t),
            'spatial_cluster': cluster_score(S[F_vis | F_loop]),
            'bias_explains': delta_chi2_with_common_bias(S),
        }


class SwitchableConstraintAttribution:
    EXPL = ('H0', 'H_geo', 'H_force', 'H_model', 'H_vis', 'H_policy', 'H_unknown')

    def attribute(self, G, obs):
        prof = G.switch_profile(G.S)
        bics = {}
        for E in self.EXPL[:-1]:
            G_E = reoptimize_with_structure(G, obs, E)   # 结构化开关先验
            bics[E] = graph_chi2(G_E) + dof(E) * np.log(len(obs))
        E_star = min(bics, key=bics.get)
        unexplained = bics[E_star] > self.tau_chi
        w = softmax({E: -0.5 * b for E, b in bics.items()})
        return E_star, unexplained, w, prof, bics
```

### IP-226 LCO（回环可观测性）与 IP-228 BIG（预算化探针）

```python
class LoopClosureObservability:
    def gain(self, G, loop_candidates):
        L0 = info_matrix(G)
        out = {}
        for L in loop_candidates:                      # revisit/regrasp/symmetric_load
            out[L] = np.linalg.slogdet(L0 + info_matrix(L))[1] \
                     - np.linalg.slogdet(L0)[1]
        return out

    def observability(self, G, v):                     # v: 故障模式方向
        L = info_matrix(G)
        return float(v @ L @ v / (v @ v * np.linalg.eigvalsh(L).max()))


class BudgetedInfoGainProbe:
    PROBES = ('visual_probe', 'null_test', 'press', 'rub', 'tap', 'lift',
              'revisit', 'regrasp', 'symmetric_load')

    def choose(self, post, G, ledger, phi_hat, f_safe, fragile):
        lam = ledger.shadow_price()                    # λ*
        best, best_ratio = None, -np.inf
        for a in self.PROBES:
            if fragile and a in CONTACT_PROBES:
                continue
            if cost(a) > ledger.B_rem - ledger.R:
                continue
            traj = predict_probe(a, phi_hat)
            if traj.max_force > f_safe or traj.max_strain > EPS_STRAIN:
                continue
            ig = expected_mutual_info(post, a, G)
            ratio = ig / cost(a)
            if ratio > best_ratio:
                best, best_ratio = a, ratio
        if best_ratio < lam:                            # 影子价格停止
            return None, best_ratio
        return best, best_ratio
```

### IP-229 LBC（账本化随时证书）

```python
class LedgerBoundedCertificate:
    def certify_prefix(self, A, G, post, m, ledger, alpha_chunk):
        support = topk(post, 2)                        # 只对 top-2 解释做最坏
        k_best, C_acc = 0, ledger.C_used
        for k in range(1, min(len(A), m) + 1):
            c_next = worst_case_cost(A[k - 1], support)
            if C_acc + c_next + ledger.c_worst_rest > ledger.B - ledger.R:
                break                                   # 预算不足即截止
            if any(safety_margin(A[k - 1], E) < 0 for E in support):
                break
            if graph_chi2(G) > TAU_CHI and not in_fallback(post):
                break
            C_acc += c_next
            k_best = k
        return k_best, C_acc

    def anytime_valid(self, ledger, t):
        return ledger.C_used <= ledger.B - ledger.R and \
               budget_overrun_prob(ledger, t) <= self.alpha_budget
```

```python
def LEDGER_round(M, obs, budget, delta_f_req):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    # ———— 语义流（10–100Hz）————
    M.lsf.update_geometry(P_cloud)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))
    y_vis = M.f_vis(img, depth, flow)

    # 1) FAFG：建图 + 开关（位姿/地图/故障参数联合）
    G = M.fafg.optimize((x_prime, M.mws.last_contacts, W_meas, tactile, y_vis,
                         M.residual_log))
    # 2) SCA：开关剖面 → 结构化解释 / unexplained
    E_star, unexplained, w_E, prof, bics = M.sca.attribute(G, obs)
    # 3) LCO：候选回环的信息增益与可观测性
    loops = M.lco.candidates(G, M.csp_v.goal)
    gain = M.lco.gain(G, loops)
    # 4) BIG：预算内最有信息/成本的取证（或回环）
    a, ratio = M.big.choose(w_E, G, M.ledger, x_prime, M.f_safe, M.object_fragile)
    if a is not None:
        M.execute_evidence(a); G = M.fafg.optimize(obs)   # 观测回填后重估
        E_star, unexplained, w_E, prof, bics = M.sca.attribute(G, obs)
    # 5) 定向处置：只在被归因的因子族上缩放
    if not unexplained:
        G = dcs_v_scale(G, E_star)
    # 6) WCV-G + CSP-L + LBC：图约束规划与账本证书
    goal = M.dms.parse_goal((M.usr.U_ep, M.usr.U_al))
    tau = M.csp_l.plan_blocks(goal, G, w_E, M.ledger)     # 含回环取证元技能
    k_star, C_used = M.lbc.certify_prefix(tau.A, G, w_E, M.m, M.ledger)
    # 7) 实时执行 + 开关残差/预算/力觉早停
    K_safe, EV_exec, cert_exec = realtime_step_ledger(
        M, delta_f_req, tau, k_star, G, G.switch_profile(G.S))
    # 8) 在线更新（纯语义流）
    evidence = M.olp.fuse_evidence(x_prime, W_meas, tactile, y_vis, w_E)
    M.olp.online_step(evidence, execution_loss_grad(K_safe, EV_exec, w_E))
    M.dcs_v.update(EV_exec, W_meas, G, w_E)
    M.ledger.charge(C_used); M.ledger.update_shadow_price(budget)
    rho_dir = M.aic_l.certify(G, tau, w_E, M.ledger)
    return M, K_safe, EV_exec, build_j_ledger(
        cert_exec, J_vista=M.j_vista, switch_profile=prof,
        explanation_bic=bics[E_star], unexplained=unexplained,
        loop_closure_gain=gain, graph_chi2=graph_chi2(G),
        cost_ledger=M.ledger.snapshot(), shadow_price=M.ledger.lam,
        budget_slack=M.ledger.B - M.ledger.R - M.ledger.C_used,
        aic_l_ver=AIC_L_VERSION)
```

## 4. 推导

**引理 9（回环可辨识性）** 设故障模式 `v` 在无回环图 `G0` 中属于 `Λ0=J0ᵀΩ0J0` 的零空间，即 `Λ0v=0`（例如公共偏置 `b` 与所有接触力共线，无法分离）。加入回环因子集 `L` 后 `Λ_L=Λ0+J_LᵀΩ_LJ_L`。若存在 `ℓ∈L` 使 `vᵀJ_ℓᵀΩ_ℓJ_ℓv>0`，则 `vᵀΛ_Lv>0`，`v` 可观测。对反向对称回环，残差中 `b` 的系数在两次测量中反号，`J_ℓ` 在 `b` 方向上的两个分量异号，故二次型严格为正、打破零空间。由 Laplace 近似，`v` 的估计协方差 `≈(vᵀΛ_Lv)^{-1}`，误差 `‖v̂−v‖² ≤ σ/λ_min(Λ_L)`。**推论**：VISTA 需要零力窗才能辨识的 `H_force`，在 LEDGER 中可由一次 `symmetric_load` 回环辨识，且不损失接触信息。∎

**引理 10（预算化探针的近似与不超支）** 设互信息 `I(E;ρ(a)|G)` 对测量集 `A` 单调子模（条件独立测量下成立），成本 `C` 模加。当所有动作等成本时，成本-收益贪心达到 `(1−1/e)·OPT`（预算最大覆盖的标准结论）。一般成本下用拉格朗日松弛 `max_a [I(a)−λ*C(a)]`，近似比含对偶间隙；`λ*` 即最优对偶变量。预算侧：令 `M_t=exp(θ(C_used(t)−μt)−θ²σ²t/2)`，`M_t` 为非负上鞅，Ville 不等式给出 `P[sup_t C_used(t)≥B] ≤ exp(−(B−μT)²/(2Tσ²))`。预留 `R` 保证即使诱饵动作消耗 `B−R`，仍有 `R` 用于安全关键取证。∎

**定理 9（LEDGER 全局一致-归因-安全）** 在 A94–A99 下：
1. **全局自洽**：若 `Valid(J_ledger)`，则 `χ²(G)≤τ_χ`，地图/位姿/故障参数在同一图上自洽，且回环支撑度充分；
2. **归因正确或显式未知**：SCA 在解释集上做 BIC 选择；若最优解释仍不能解释开关结构则输出 `unexplained` 并保守回退，**不把未知复合故障塞进最近假设**；
3. **成本受控**：`C_used+c_worst_next≤B−R` 且 anytime 超支概率 ≤ `α_budget`，安全储备在预算耗尽攻击下仍非空；
4. **可辨识性**：若存在打破故障零空间的回环，则对应故障方向可观测（引理 9），VISTA 的零力窗不再是唯一辨识机制；
5. **前缀安全**：`k*≤m` 且对后验支持集内解释逐一验证，单块越界概率 ≤ `α_chunk+δ_fi+α_vis`（承接引理 8）；
6. **优雅降级**：视觉失效→图退化为力-接触子图；力失效→依赖视觉/回环；两者共因失效→`unexplained` + `safe_idle`；预算耗尽→`λ*` 上升、只保留储备内的安全动作。∎

**定理 10（成本最优取证）** 设信息-成本前沿 `I(C)` 凹且可微。拉格朗日问题 `max_C I(C)−λC` 的最优解满足 `I'(C)=λ`（KKT）。预算约束的影子价格 `λ*` 是 `V(B)=max_{C≤B}I(C)` 的导数，故"边际信息/边际成本 = 影子价格"处停止是最优的。对离散动作集，成本-收益贪心在等成本下达 `(1−1/e)`，一般成本下由对偶界控制误差。经济学解释：`λ*` 就是"再花一元预算买到的安全"；预算越紧 `λ*` 越高，系统自动更挑剔。∎

**命题（开关吸收风险）** 鲁棒核 `ρ(sr)` 在 `s→0` 时使任意大残差的代价饱和为常数。若真实故障产生的残差 `r_fault` 落在核的饱和区，则"丢弃该边"与"修正故障参数"在 `χ²` 上不可分（两者都把残差压到常数），归因在信息论上不可辨识。此时 BIC 的复杂度惩罚不足以区分，必须靠**回环交叉验证**（同一故障在独立回环上再次出现）与**储备金强制取证**来打破。若既无回环又无预算，LEDGER 与 VISTA 一样无法归因——这是本框架的边界。∎

## 7. 已知风险

**一句话**：LEDGER 把"归因"变成"图自洽 + 开关解释"，但鲁棒核与开关会把**真实的几何/接触故障当作离群边吸收**，得到一张"很自洽却物理错误"的图；而成本最优的期望信息获取会系统性低估低概率高后果的尾部故障，再叠加预算耗尽与假回环攻击——系统可能"省钱地、自信地"沿错误地图继续执行。这是本轮全部全局一致性与预算证书共同依赖的隐藏假设（A94）。

**次级风险与缓解**：
1. **开关吸收真实故障**：鲁棒核饱和区不可辨识；缓解：BIC 复杂度惩罚 + 回环交叉验证 + 储备金强制独立取证；对高后果故障设"不可吸收白名单"（如几何穿透必须硬约束，不允许 s→0）。
2. **回环保真/假难分**：感知混叠造成错误闭环会污染地图；缓解：回环支持度（多假设一致、协方差相容）+ 事后 `χ²` 校验 + AIC-L 假回环训练；错误回环可被后续回环推翻（鲁棒图回环）。
3. **预算耗尽攻击**：诱饵让 `λ*` 飙升、真实故障无钱查；缓解：安全储备 `R` + 对"反复假报警"做信誉/异常检测 + 关键证据优先级队列。
4. **尾部风险被期望值低估**：`I/C` 只看期望信息；缓解：目标改用风险调整 `CVaR` 或用约束 `P(漏检关键故障)≤ε` 的 chance-constrained 版本，对低概率高后果故障单独设预算。
5. **图规模与实时性**：长会话 FAFG 增长；缓解：滑动窗口 + 关键帧/因子边缘化 + 回环只在语义流；实时流只读压缩后的开关残差。
6. **成本模型标定偏差**：`w`、`CVaR_α`、`λ_risk` 主观；缓解：离线标定 + 在线对偶校正，把成本误差写入 `budget_slack` 并保守化。
7. **`λ*` 对偶不稳定**：预算约束非凸/离散时对偶间隙大；缓解：用拉格朗日松弛 + 贪心可行化，证书按最坏间隙保守。
8. **回环依赖可重访性**：一次性/不可逆任务没有回环；缓解：退化为 VISTA + `null_test`/symmetric_load 的局部回环；显式在 `J_ledger` 标注 `loop_unavailable` 并降级保证。
