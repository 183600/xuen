# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「论文创新点」×「鲁棒性」）

> 第 54 轮把体系推到 v31：动作空间剖面、技能组合图、云边闭环、联合证书。问题已经从“缺想法”变成“想法过多且彼此交叉”。本轮两个灵感词恰好构成一对张力：“论文创新点”要求**收敛**（评审只记得住三个贡献），“鲁棒性”要求**扩散**（每条主张都要经受扰动）。核心矛盾：H22：IP 数量与论文贡献度不单调——31 个 IP 可能只对应 0 个可辩护创新点；H23：鲁棒性既是研究内容又是论文自身的评价标准，二者尚未统一。

## 0. 直觉与动机

**灵感 1（创新点不是 IP 的数量，而是可证伪主张的最小闭包）**
直觉：一个“论文创新点” = 一条**可被单一实验杀死**的主张 + 一个**他人不易复现的机制** + 一条**与 prior art 的严格差分**。当前 31 个 IP 更像工程清单，不是贡献。应做**创新点蒸馏（Innovation Distillation）**：把 IP 依赖图压缩为 3 个“贡献原子”，其余 IP 降格为支撑组件/消融项。判据：若删掉某 IP，论文主张仍成立，则它不是创新点，只是实现细节。

**灵感 2（新颖性 = 能力格上的差分，而不是形容词）**
直觉：用第 53/54 轮已有的能力格与鲁棒性谱，把“新颖”形式化为 `Novelty = (OurCapability ⊖ PriorArt)`：先定义能力坐标（可传递性、可判定性、闭环性、可解释性、动作粒度），prior art 在格上占据一个下闭集，我们的创新点是该下闭集之外的**最小上界点**。若差分体积 `vol(Δ)` 低于阈值，则该点不成立——这直接杀死“换皮式创新”。

**灵感 3（鲁棒性作为论文主轴，而非一个章节）**
直觉：把 ρ（鲁棒性谱）、Explain（反向解释）、α_S（动作剖面）、J（联合证书）统一为同一件事的四个投影：**可传递的失效结构**。论文的中心主张从“我们做了一个系统”变成“**鲁棒性是可组合、可证伪、可跨层传递的证书对象**”。C1 可传递性（ρ + RTL）、C2 可判定性（α_S + SCOM）、C3 闭环可解释性（CEC + AEC）。鲁棒性从实验指标升级为**组织全文的第一性概念**。

**灵感 4（论文自身的鲁棒性：主张对假设扰动的存活率）**
直觉：既然研究鲁棒性，就应对论文主张做**对抗性审计**：对每个假设 `A_i` 施加扰动 δ（换数据集、换基线、放宽 Lipschitz、降低采样预算），测主张的存活率 `ρ_paper(C) = P(claim holds | A_i perturbed)`。一篇“鲁棒”的论文 = 主张在假设邻域内不崩。这把“论文创新点”与“鲁棒性”焊死：创新点强度 = 新颖性差分 × 鲁棒存活率。

**灵感 5（三贡献三证伪的实验骨架）**
直觉：每个贡献配一个**杀手实验（kill-criterion）**：C1 若“证书跨层传递后 ρ 掉幅 > 20%”则死；C2 若“动作兼容图的可判定性不优于启发式拼接”则死；C3 若“闭环反向解释不带来重剖分增益”则死。论文实验章不再是堆指标，而是**三个证伪关卡 + 一个消融归因矩阵**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（贡献原子与贡献图）**
贡献原子 `C = (claim, mechanism, evidence, kill)`。贡献图 `G_C = (𝒞, ≺)`，`𝒞 = {C1,C2,C3}`，`≺` 为“支撑关系”；支撑 IP `s ∈ Supp(C)` 满足：删除 s 后 claim 仍成立，则 `s ∉ Innovative(C)`。

**定义 122（新颖性差分）**
能力坐标 `κ = (τ_rob, dec, loop, expl, gran)`。Prior art 在能力格 `𝕂` 上的占据集 `P ⊂ 𝕂` 为下闭集。新颖性差分
```
Δ = Up(κ_ours) \ P,    d_nov = vol(Δ) / vol(Up(κ_ours))
```
创新点成立的必要条件：`d_nov ≥ θ_nov` 且 `κ_ours ∉ P`。

**定义 123（论文鲁棒性 / 主张存活率）**
对假设族 `𝒜 = {A_i}` 及扰动 `δ_i ∈ Δ_i`，主张 `C` 的论文鲁棒性
```
ρ_paper(C) = E_{δ~𝒟}[ 1{ C holds under A_i ⊕ δ_i } ]
```
“鲁棒创新点” = `d_nov(C) ≥ θ_nov ∧ ρ_paper(C) ≥ θ_paper`。

**定义 124（证伪测试 / 杀手条件）**
证伪测试 `F(C) = (E_C, m_C, θ_C, δ_C, π_C)`：实验 `E_C`、指标 `m_C`、阈值 `θ_C`、最小可检测效应 `δ_C`、统计功效 `π_C`。`kill(C)=1` 当 `m_C(E_C) ≤ θ_C`。要求 `π_C ≥ Π_min`，避免“设计成必过”的自证实验。

**定义 125（鲁棒性传递账本 RTL）**
跨层账本 `𝔗 = {(ℓ→ℓ', ρ_{ℓ→ℓ'}, Δρ, evidence)}`，记录从物理层到任务层每跳鲁棒性谱的传递与损耗；总损耗 `Loss(C) = Σ Δρ`，要求 `Loss(C) ≤ Θ_L`。

**定义 126（贡献-证据对齐）**
对齐映射 `μ: 𝒞 → 2^{E}`。若实验 `E` 无法区分“有该机制”与“无该机制”（消融不可分辨），则 `μ` 未对齐；要求每个 `C` 至少有一个**单变量消融**证据。

## 2. 关键算法 伪代码

### IP-121 IDC（Innovation Distillation Compiler）

```python
def distill(ip_graph, claims):
    C = []
    for claim in claims:
        mech = minimal_mechanism(ip_graph, claim)   # 删除后 claim 失效的最小 IP 集
        if not mech:
            continue                                # 无可定位机制 -> 不是创新点
        C.append(ContribAtom(claim, mech, evidence=[], kill=None))
    return ContributionGraph(C, support_edges(ip_graph, C))

def deletion_test(ip_graph, claim, ip):
    return still_holds(claim, ip_graph.without(ip))  # True -> ip 仅为实现细节
```

### IP-122 NDC（Novelty Differential Calculus）

```python
def novelty_differential(kappa_ours, prior_closure, theta_nov):
    up = upset(kappa_ours, capability_lattice)
    delta = up - prior_closure
    d_nov = volume(delta) / max(volume(up), eps)
    return ('novel' if d_nov >= theta_nov else 'collision', d_nov, delta)
```

### IP-123 PRA（Paper Robustness Audit）

```python
def paper_robustness(claim, assumptions, perturb_dist, n=200):
    alive = 0
    for _ in range(n):
        A = perturb(assumptions, sample(perturb_dist))
        alive += verify(claim, A)        # 形式检查或可复现实验
    return alive / n
```

### IP-124 FCH（Falsification Harness）

```python
def falsification_gate(C, E_C, m_C, theta_C, power):
    if power < POWER_MIN:
        return ('reject', 'underpowered', power)   # 防止“注定通过”的实验
    return ('kill' if m_C <= theta_C else 'survive', m_C - theta_C)
```

### IP-125 RTL（Robustness Transfer Ledger）

```python
def build_transfer_ledger(layers, rho_by_layer):
    T = []
    for a, b in zip(layers, layers[1:]):
        rho_pred = transfer(rho_by_layer[a])
        d = {k: rho_by_layer[a][k] - rho_by_layer[b].get(k, rho_pred[k])
             for k in rho_by_layer[a]}
        T.append((a, b, d, evidence_cross_layer(a, b)))
    return T
```

### IP-126 CEA（Contribution-Evidence Alignment）

```python
def align_evidence(contrib_graph, experiments):
    for C in contrib_graph.nodes:
        ablations = [e for e in experiments if e.target == C and e.single_variable]
        if not ablations:
            return ('misaligned', C)       # 贡献无单变量消融证据
    return ('aligned', None)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| IDC | O(\|IP\|·\|𝒞\|) | O(\|IP\|+\|𝒞\|) | 最小机制唯一、删除测试可判定 |
| NDC | O(\|𝕂\|) | O(\|𝕂\|) | prior 为下闭集、体积可计算 |
| PRA | O(n·cost(verify)) | O(n) | 扰动分布覆盖假设邻域 |
| FCH | O(cost(E_C)) | O(1) | 统计功效 ≥ 下限 |
| RTL | O(L·\|𝔇_ρ\|) | O(L·\|𝔇_ρ\|) | 每跳证据同分布可比 |
| CEA | O(\|𝒞\|·\|E\|) | O(\|𝒞\|) | 消融单变量、可分辨 |

**正确性定理（Distilled Contribution Soundness）**
假设第 54 轮 (A26)–(A28) 成立，且 **(A29)** 每个 `C` 满足 `d_nov ≥ θ_nov`、`ρ_paper ≥ θ_paper`、`kill=0`、`π ≥ Π_min`。则论文组合主张的联合存活率
```
ρ_paper(∧ C_i) ≥ 1 - Σ_i (1 - ρ_paper(C_i)) - P(collision)
```
其中 `P(collision)` 为新颖性差分被 prior art 侵占的概率。关键：**贡献原子相互独立可证伪**、**新颖性差分非空**、**证伪实验有功效**。

## 6. 本轮最大风险

**一句话**：把 31 个 IP 蒸馏为 3 个可证伪贡献、并用论文鲁棒性审计它们，能让论文从“工程清单”变成“可辩护主张”，但整套框架的生死取决于**贡献原子划分是否被审稿人接受、新颖性差分坐标是否被认可为公平、杀手实验功效是否真能杀死主张**——一旦划分主观或坐标可被质疑，创新点就会被重排为“已有工作的组合”，故必须以**预注册坐标 + 双人独立划分 + 功效下限**三重护栏，宁可少报一个贡献，也不把“自证式鲁棒”当成新颖性。

## 6. 实验设计 E162–E166（论文证伪骨架）

| 实验 | 指标 | 目标 | 若失败 |
|---|---|---|---|
| E162 创新点压缩率 | 31 IP → \|𝒞\| | ≤ 4 且每原子可独立证伪 | 说明仍是工程清单 |
| E163 新颖性碰撞 | `d_nov` vs 3 条 prior art | ≥ 0.3，无完全碰撞 | 该贡献降格 |
| E164 论文鲁棒性 | `ρ_paper` 对 5 类假设扰动 | ≥ 0.8 | C1 主张不成立 |
| E165 证伪功效 | 每个 kill test 的 `π` | ≥ 0.8 且报告 `δ_C` | 实验无说服力 |
| E166 消融归因 | 单变量消融的 claim 差异 | 每 `C` 有 ≥1 个显著消融 | CEA 未对齐 |

**扰动族 𝒟（PRA 用）**：`{换数据集, 换基线, 放宽 Lipschitz 常数, 降低采样预算 50%, 注入 10% 动作噪声}`。

## 7. 本轮最大风险

**一句话**：把 31 个 IP 蒸馏为 3 个可证伪贡献、并用论文鲁棒性审计它们，能让论文从“工程清单”变成“可辩护主张”，但整套框架的生死取决于**贡献原子划分是否被审稿人接受、新颖性差分坐标是否被认可为公平、杀手实验功效是否真能杀死主张**——一旦划分主观或坐标可被质疑，创新点就会被重排为“已有工作的组合”，故必须以**预注册坐标 + 双人独立划分 + 功效下限**三重护栏，宁可少报一个贡献，也不把“自证式鲁棒”当成新颖性。
