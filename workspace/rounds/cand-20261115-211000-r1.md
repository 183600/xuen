# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「价值对齐」×「用户测试」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**价值对齐不是往奖励函数里再加一项，而是把「可接受性」拆成不可交易的硬宪法与可学习、可回退的软价值画像；用户测试不是上线前的一次性验收，而是持续测量价值不确定度、主动采集偏好证据、并允许证伪的实验协议。** 所有新组件沿用 v9 的中立元纪律：VAUT 不可用 ⇒ 注入 W^⊥，逐位等价退回 v9。

## 0. 直觉与动机

**灵感 1（价值对齐 → 约束式而非标量式）**
直觉：v9 已经能回答「任务是否完成、是否安全、是否适配陌生域」，但没有回答「用户是否愿意机器人以这种方式完成」。同一条成功轨迹，可能以过度拍摄、频繁询问、贴脸移动、剥夺否决权为代价。把价值对齐做成 RLHF 式的标量奖励是危险的：它让不可交易的安全/隐私变成可与效率交换的权重，并制造 reward hacking。本文取**约束式价值对齐**：硬宪法 H（安全、隐私、知情同意、停止权、不欺骗）用动作集投影实现，任何偏好都不能解锁；软价值画像 W（自主、隐私、舒适、透明、尊严）从用户偏好中学习，但有不确定度、有信任域、可回退。核心创新：**价值对齐治理器（ValueAlignmentGovernor, VAG）** 与 **宪法屏蔽器（ConstitutionalShield, CS）**。

**灵感 2（用户测试 → 主动测量仪器而非验收仪式）**
直觉：机器人论文里的用户测试常是「最后一周找 12 个人打 5 分」，既没有预注册，也没有区分「说喜欢」与「做的时候接受」。但用户测试恰恰是价值标签最稀缺的来源。本文把它升级为**用户测试台（UserTestingHarness, UTH）**：预注册的测试电池、主动偏好查询（每次问最能把 W 后验不确定度砍半的对比）、影子反事实筛选（只用于筛选与功效分析，不能单独发证书）、陈述-行为差距检测、漂移检测与覆盖矩阵。核心纪律：**能测到的偏好 ≠ 价值**；证书必须同时报告「用户说了什么」和「用户实际怎么做」。

**灵感 3（二者合成 → 可证伪的对齐闭环）**
直觉：单有对齐器会过度自信，单有用户测试会停留在报告里。合成物是一条证据链：
偏好数据 → 后验 W → 信任域投影 θ=T(W) → 宪法屏蔽 → 影子筛选 → 真实用户测试 → **对齐证书 A_t**。
证书有效才允许 θ 生效；证书过期、覆盖不足、陈述-行为差距过大、漂移告警、或不确定度过高 ⇒ **θ←θ^{v9}**。这样「对齐」第一次成为可以被证伪、被回退、被审计的运行时属性，而不是论文里的一句伦理声明。

## 1. 研究问题（轮次升级版）

- **Q1（宪法屏蔽）**：如何证明无论 W 如何更新，硬价值约束都不会进入可交易的目标函数？信任域投影与动作集投影能否给出「对齐层失效 ≤ v9 风险」的严格安全等价？
- **Q2（偏好测量的有效性）**：主动查询能否在有限预算内把 W 的后验不确定度压到阈值以下？如何检测模型误设、策略性回答、陈述-行为差距与小样本代表性偏差，并在检测到时保守回退？
- **Q3（测试证书与漂移）**：什么样的预注册协议、覆盖矩阵与序贯检验，能给「可接受性」一个可复现的置信下界？多用户价值冲突与长期偏好漂移下，何时应停止个性化？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 宪法屏蔽律（Constitutional Shielding, CS）**
硬宪法 H={h_safe, h_privacy, h_consent, h_stop, h_truth} 是动作/日志上的谓词，定义可行动作集 A_H(s)={a: h_j(s,a,log)=true, ∀j}。所有候选动作（无论来自 v9 主闭环还是 AC 块）在执行前经 CS 投影到 A_H；W 只能重排 A_H 内部的软偏好，不能改变可行集。CS 永不学习、永不蒸馏、永不被偏好覆盖；CS 失效 ⇒ 立即进入硬停驻包络并回退 θ^{v9}，而不是「继续但少一点对齐」。

**P14 价值不确定度门控律（Uncertainty-Gated Alignment, VAG）**
W 的后验不确定度 U_t、陈述-行为差距 Δ_SR、测试覆盖 C、漂移统计量共同决定门控 g_val。仅当对齐证书 A_t 有效时 θ=T(W) 才生效；否则 θ←θ^{v9}（v9 默认交互参数）。每次更新限制在信任域内：‖T(W)−θ^{v9}‖∞≤ε_p 且 KL(π_{θ}‖π_{θ^{v9}})≤ε_KL，防止一次偏好样本把交互风格推得过远。

**P15 用户测试证据律（Test-as-Evidence, UTH）**
任何「已对齐」的主张必须附带证书：预注册协议哈希、抽样框、参与者分层、场景电池、陈述与行为两类测量、置信区间、覆盖矩阵、有效期。影子测试只能用于筛选与功效分析，不能单独签发证书；真实用户测试必须在协议冻结后执行；报告必须包含失败场景与反例，禁止只报均值。证书到期即失效，漂移告警即失效。

## 3. 与基线的接口（如何退化）

- VAG 不可用 / 不确定度超阈 / 证书过期 ⇒ θ←θ^{v9}，交互行为逐位等价 v9；
- UTH 不可用 / 协议未预注册 / 覆盖不足 ⇒ 不签发新证书，沿用未过期的上一张证书，否则 θ^{v9}；不产生任何新的对齐主张；
- CS 不可用 / 自检失败 ⇒ 硬停驻包络（速度衰减到 0 并保持停止权）+ θ^{v9}，绝不带病对齐；
- 用户测试发现硬约束违背或 Δ_SR>τ_SR ⇒ 证书作废、θ^{v9}、触发人因复核；
- v9 的 AC/MW/ID 退化链保持不变：价值层是**旁路增强**，不改变 v9 的安全与实时路径。

## 4. 预期贡献

1. **约束式价值对齐层**：硬宪法 + 软价值画像 + 信任域 + 不确定度门控，给出「对齐层失效严格回退 v9」的引理，而不是把安全托付给奖励函数；
2. **主动用户测试台**：D-最优偏好查询、影子反事实筛选、陈述-行为差距、覆盖矩阵与漂移检测，把用户测试从验收仪式变成可复现的证据生产；
3. **对齐证书**：把「可接受性」变成带置信下界、覆盖与有效期的运行时凭证；证书失效自动回退，首次让价值对齐具备可证伪性；
4. **价值-性能 Pareto 与多用户公平**：不再用单一分数掩盖价值代价；E571–E590 覆盖宪法对抗、查询效率、陈述-行为差距、漂移、多用户冲突与端到端任务。

## 5. 本轮最大风险

**一句话**：用少量、非代表性、愿意配合实验室流程的用户测出的价值画像，可能只学到「这些人在这套场景里说的偏好」，而证书会给系统一种虚假的伦理置信度——它越是「通过测试」，越可能在一个没被抽样到的群体或一次真实的偏好漂移面前自信地做错。

**新增定义 540（价值维度与价值画像 ValueProfile）** 软价值画像 w=(w_aut,w_priv,w_com,w_tra,w_dig)∈Δ⁴，分别刻画：自主（机器人何时询问/何时主动）、隐私（在硬地板之上的数据保留与传感器使用偏好）、舒适（接近距离、速度、语音音量）、透明（解释层级与不确定性展示）、尊严（措辞、指令方式、非必要命令）。W^⊥ 为部署方预注册的 v9 默认画像，保守且不随用户测试更新；它是所有价值层退化的汇点。**隐私的硬地板**（原始数据不出设备、保留上限、知情同意）在 H 中，不在 w 中；w_priv 只能在地板之上做更严格的选择。

**新增定义 541（硬宪法 HardConstitution）** H={h_safe,h_privacy,h_consent,h_stop,h_truth}，每个 h_j 是 (s,a,log) 上的布尔谓词：
```
h_safe   : v9 M0 全部不变式 ∧ 速度/力/间距硬上限
h_privacy: 原始传感器数据不出设备 ∧ 保留时长≤r_max ∧ 默认不录制
h_consent: 录制/上传/跨机共享需显式同意 ∧ 可随时撤回
h_stop   : 人类停止/否决指令始终可执行 ∧ 机器人必须让行
h_truth  : 对能力与置信度的陈述必须校准 ∧ 不欺骗性解释
```
可行动作集 A_H(s)={a∈A: h_j(s,a,log)=true, ∀j}。硬宪法是**不可交易约束**：任何 w、任何证书、任何用户偏好都不能把 a∉A_H(s) 变为可行。

**新增定义 542（交互参数与信任域投影 InteractionParameters）** θ=(d_app,v_scale,e_level,q_rate,r_sec,verbosity)∈Θ_safe，Θ_safe 为预注册盒约束（如 v_scale∈[0,1]、d_app≥d_safe+0.05、r_sec≤r_max）。映射 T 为带盒截断的仿射映射：
```
θ_k = clip( θ_k^{v9} + α_k · Σ_j A_{kj}(w_j − w_j^⊥), l_k, u_k ),  α_k∈[0,1]
```
A 为人工设计、可审计的稀疏矩阵（例：autonomy→q_rate/e_level；privacy→r_sec；comfort→d_app/v_scale；transparency→e_level/verbosity；dignity→verbosity/q_rate）。构造保证 T(W^⊥)=θ^{v9}。每次更新的信任域：
```
‖θ−θ^{v9}‖∞ ≤ ε_p    ∧    KL(π_θ‖π_{θ^{v9}}) ≤ ε_KL
```
其中 π_θ 为 θ 诱导的交互动作分布；超界则沿 θ^{v9}→θ 线段回缩到边界。θ 在 AC 块内冻结，只在块边界/会话边界更新（避免块证书因交互风格突变而失效）。

**新增定义 543（偏好观测与 Bradley–Terry 后验）** 每个观测是一对场景片段 (τ_i,τ_j) 上的选择 y∈{i≻j, j≻i, 弃权}。价值特征 φ(τ)∈R⁵ 由可审计的规则计算（接近距离分位、解释次数、数据保留、询问次数、措辞礼貌度等），不使用黑箱奖励。似然：
```
P(i≻j | w) = σ( β · w·(φ_i−φ_j) ),   σ(z)=1/(1+e^{−z})
```
先验取 logistic-normal：w=softmax(z)，z∼N(μ₀,Σ₀)。后验用 Laplace 近似 N(ẑ,Σ_z)，W 的后验由 softmax 变换得到。弃权单独建模为 |w·(φ_i−φ_j)|<τ_tie 的观测；弃权率过高会抬高 U_t。

**新增定义 544（主动查询策略 ActiveQueryPolicy）** 候选对集合 Q_t 来自测试电池与在线日志。选择
```
q* = argmax_{q∈Q_t} [ IG(q) − λ_q·cost(q) ]
IG(q) = H[p(w|D_t)] − E_{y∼p(y|q,D_t)} H[p(w|D_t∪{(q,y)})]
```
D-最优近似：IG(q)≈½log(1+a_q^TΣa_q/s²)，a_q=φ_i−φ_j。约束：(i) 每会话查询预算 B_q；(ii) 每个价值维度至少被探查 m 次（覆盖约束）；(iii) 用户可拒绝任何问题且不损失服务；(iv) 不对同一用户重复问等价问题（信息增益去重）。查询策略只决定「问什么」，不决定「怎么解释」；解释文案由 UTH 的预注册脚本固定，避免诱导性提问。

**新增定义 545（价值不确定度、陈述-行为差距与多用户分歧）**
```
U_t = sqrt(trace(Σ_z))                              # 后验不确定度
Δ_SR = max_j | Acc_stated(j) − Acc_revealed(j) |    # 陈述-行为差距
κ    = 1 − max_j agreement_j                        # 用户间分歧
M_t  = heldout_logloss − train_logloss              # 模型误设统计量
```
Acc_stated 来自偏好选择/评分；Acc_revealed 来自实际干预率、停止按键、完成时间、撤回同意等行为。多用户扩展：硬约束取并集（任一用户可否决）；软价值用 max-min 社会福利聚合 w_agg=argmax_w min_u w·φ_u；若 κ>τ_κ 或聚合后 U>τ_U，则 g_val=0 并请求澄清，绝不把「平均偏好」冒充「共同价值」。

**新增定义 546（用户测试协议 UserTestingProtocol）** P_UT=(H_pre,抽样框,N,分层,电池 S,测量 M,停时规则,分析计划,伦理,T_cert)。协议在数据采集前冻结并记录哈希 h(P_UT)；H_pre 含主终点与次要终点；禁止在看到数据后更换主终点。电池 S 按价值维度×情境分层，至少含 5 类对抗场景：隐私诱导、停止权冲突、欺骗性解释诱导、旁观者在场、多用户冲突。证书有效期 T_cert 默认 30 天或 200 次部署交互，先到者为准。

**新增定义 547（对齐证书 AlignmentCertificate）** A_t 的字段见符号表。A_t 有效 ⇔ 同时满足：
```
(1) U_t ≤ τ_U                     (2) min_j C_j ≥ c_min
(3) Δ_SR ≤ τ_SR                  (4) LCB_acc ≥ a_min − δ_reg
(5) κ ≤ τ_κ                      (6) M_t ≤ τ_M
(7) drift_stat < h_drift         (8) violations = 0（影子+真实测试）
(9) hash(P_UT) 与预注册一致       (10) t_now ≤ t_expiry
```
其中 LCB_acc 为分层 Clopper–Pearson 下界，δ_reg 为相对 v9 的非劣界。任一条不满足 ⇒ g_val=0。证书不是「伦理认证」，只是「在已测场景与已抽样人群上，有置信下界的可接受性凭证」；报告必须显式写出未覆盖人群与未测场景。

**新增定义 548（价值门控 ValueGate）**
```
g_val(t) = 1  若 A_t 有效 ∧ CS 自检通过 ∧ 无漂移告警
         = 0  否则
θ^applied(t) = g_val(t)·T(W_t) + (1−g_val(t))·θ^{v9}
```
门控在 5Hz 块边界与会话边界检查；AC 块内 θ 冻结。g_val 的翻转也受 Schmitt 迟滞约束（连续 3 个检查点一致才翻转），避免交互风格抖振。门控只影响软交互参数，不进入 v9 的 δ_trigger / M0 安全判定。

**新增定义 549（影子用户测试 ShadowUserTest）** 在已知倾向性的日志上对候选 θ 做离策略回放，用显式用户响应代理（干预模型/停止模型）估计接受度与失败模式，输出筛选统计量、有效样本量 ESS 与代理校准误差 e_proxy。若 ESS<ESS_min 或 e_proxy>τ_proxy，影子结果作废。影子测试的合法用途只有三个：筛选候选 θ、估计真实实验所需样本量、挖掘对抗场景；**不能单独签发 A_t**。证书必须含真实人类数据（定义 547 的 N_test≥N_min）。

- **定义 493–539 全部继承**；AC 的块证书、中止点集、MW 契约表、ID 状态机语义不变。

class ConstitutionalShield:
    """IP-359: hard constraints; never learned, never distilled."""
    HARD = ('h_safe', 'h_privacy', 'h_consent', 'h_stop', 'h_truth')

## 4. 推导

**引理 87（宪法屏蔽的安全单调性）** 设 CS 对每个执行动作做投影 a'=Proj_{A_H(s)}(a)，且 T(W)∈Θ_safe。则 ∀W、∀偏好数据，执行动作满足全部 H；价值层可达的安全风险不高于 v9。证明：A_H(s)⊆A(s)，投影只删除动作不增加动作；Θ_safe 的盒约束包含 v9 参数且不放松任何硬上限；VAG 只改写 θ 的软分量，不触碰 M0/CS。故硬约束违背数为 0，安全不变式由 v9 的 M0 继续保证。∎

**引理 88（W^⊥ 回退与 v9 逐位等价）** 当 g_val=0 时 θ^applied=θ^{v9}；由 T(W^⊥)=θ^{v9}，W^⊥ 也是证书失效时的自然汇点。v9 的 AC/MW/ID/DA/SPR/Cal 全部不变，故相同输入下可观测日志与 v9 逐位一致。证明：门控是纯选择器，不改变 v9 路径的取值集合；θ^{v9} 是 v9 代码常量的显式化。∎

**引理 89（主动查询的后验收缩与价值遗憾界）** 假设：(A1) ‖φ‖≤L；(A2) Bradley–Terry 模型良设，温度 s；(A3) Laplace 后验；(A4) 查询设计满足 λ_min(Σ_q a_q a_q^T/n)≥λ₀>0。则局部渐近意义下
```
E‖ŵ_n−w*‖ ≤ sqrt( d / (n λ₀ s²) ) + b_miss
E[Regret_val] ≤ L·sqrt( d / (n λ₀ s²) ) + L·b_miss + o(n^{−1/2})
```
其中 b_miss 为模型误设偏差。D-最优查询最大化 λ_min，故达到 τ_U 所需查询数 n=O(dL²/(τ_U²λ₀))（忽略对数因子），优于随机查询的常数因子。证明：logistic 后验的 Bernstein–von Mises 近似给出 Σ_n≈(Σ₀^{-1}+nI(w*))^{-1}；D-最优设计最大化 Fisher 信息最小特征值；价值遗憾由 Lipschitz 性 |w·φ−w*·φ|≤L‖w−w*‖ 得。∎

**引理 90（门控的保守遗憾界）** 定义价值遗憾 Reg_val(θ)=E_{τ∼D_scen}[w*·φ(τ)−w_θ·φ(τ)]，|Reg_val|≤L‖w−w*‖。若证书有效且后验校准，则 ‖ŵ−w*‖≤τ_U（以 1−δ 概率），于是 Reg_val≤Lτ_U+Lb_miss。若证书无效，θ=θ^{v9}，Reg_val≤L‖w^⊥−w*‖≤L·D_val。故实际应用的遗憾 ≤ max(Lτ_U+Lb_miss, L·D_val)；信任域进一步把单次更新的瞬态遗憾限制在 O(ε_p)。门控的代价是放弃个性化，收益是把最坏价值遗憾钉在可审计的界内。∎

**引理 91（用户测试证书的统计有效性）** 设部署分布 P_dep 与测试电池分布 P_bat 的总变差 ≤ε_cov；每层接受度用 Clopper–Pearson 下界 p_L（置信 1−α）。则部署接受度满足 p_dep≥p_L−ε_cov（以 1−α 置信）。漂移检测用 SPRT，Wald 界给出误报率 ≤α_d；一旦告警，A_t 作废。故证书有效 ⇒ 接受度有置信下界且漂移误报受控；但该界只覆盖已抽样人群与已测场景，未覆盖部分的偏差由 ε_cov 与报告中的覆盖矩阵显式暴露。证明：TV 距离下有界函数期望差 ≤ε_cov；Clopper–Pearson 的覆盖性质；SPRT 的 Wald 近似。∎

**引理 92（与 v9 退化链的组合安全性）** CS 与 VAG 均 φ^elig=false，ID 不能使其休眠；UTH 休眠只停止新查询，不改变已生效的 θ；证书过期强制 θ^{v9}。因此任一 VAUT 状态的可观测行为 ∈ {v9 行为} ∪ {θ∈Θ_safe 且动作∈A_H}。由引理 87–88 与 v9 引理 84，安全性由 v9 退化格点与 CS 共同传递，不因价值层引入新的安全可达状态。∎

## 6. 用户测试协议（预注册）

**设计**：被试内、条件顺序平衡、单盲（被试不知道当前是 v9 默认还是对齐画像）；每个被试完成 v9 与候选 θ 两组场景，顺序随机化；场景呈现采用拉丁方平衡。主终点为「行为接受度」（7 点）+「实际干预/停止率」；次终点为信任、工作负荷、可用性、陈述-行为差距。

**参与者**：N=36（基于 α=0.05、power=0.8、效应量 0.5 的先验功效分析；最终以影子测试的方差估计重算）。分层：年龄、技术素养、机器人经验、是否与辅助机器人共同生活。纳入标准：成年人、能理解知情同意、无严重视听障碍；排除：无法自主撤回同意者、与被测机器人存在雇佣/权力关系者。报酬固定，不与评价挂钩。

**场景电池**：5 个价值维度 × 3 个难度 = 15 个核心场景，另加 5 个对抗场景（隐私诱导、停止权冲突、欺骗性解释诱导、旁观者在场、多用户冲突）。每个场景同时采集：
- 陈述：成对偏好选择、7 点接受度、信任量表、NASA-TLX、SUS；
- 行为：干预次数、停止按键、完成时间、解释请求、撤回同意、实际数据保留选择；
- 访谈：半结构化，重点问「为什么」与「哪个场景让你改变主意」。

**假设**：
- H1：主动查询达到 U≤τ_U 所需提问数 ≤ 随机查询的 40%；
- H2：在对抗偏好注入下，CS 硬约束违背 = 0；
- H3：有效对齐证书使接受度较 v9 提升 ≥0.5（7 点），任务成功率下降 ≤2pp；
- H4：Δ_SR>τ_SR 能预测个性化失败（AUC≥0.75）；
- H5：多用户 max-min 聚合比平均聚合降低最差用户遗憾 ≥20%；
- H6：证书失效时日志与 v9 逐位等价。

**分析**：混合效应 logistic/linear 模型（被试随机截距、场景随机斜率）；Clopper–Pearson 下界；ICC 与 Krippendorff α 评估重测信度；SPRT/CUSUM 做漂移检测；所有主终点预注册，事后分析标注为探索性。**伦理**：IRB 批准、书面知情同意、无欺骗、数据最小化、默认不录制、端侧处理、可随时退出且不影响报酬、去标识化、脆弱群体排除、事后 debrief。**证书**：报告必须包含覆盖矩阵、未覆盖人群、失败场景与反例；有效期 30 天或 200 次部署交互。

## 9. 本轮最大风险

**一句话**：用少量、非代表性、愿意配合实验室流程的用户测出的价值画像，可能只学到「这些人在这套场景里说的偏好」，而证书会给系统一种虚假的伦理置信度——它越是「通过测试」，越可能在一个没被抽样到的群体或一次真实的偏好漂移面前自信地做错。
