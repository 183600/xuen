# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「评测指标」×「夹爪控制」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**元评测 + 接触即证书**。v9 有两个未被追问的"真值假设"：其一把六层指标与 MetaWeight 的权重视为给定真值，从不校准"量具"本身；其二把抓取压成一个布尔 γ_grasp，抹掉了接触瞬间的半毫秒动力学。本轮把这两处同时升级为一等公民，并坚持 v9 的中立元退化纪律：任一新模块失效 ⇒ 注入恒等元、严格等价退回 v9/v8，而非行为漂移。

## 0. 直觉与动机

**灵感 1（评测指标 → 元评测：谁来评估评估者）**
直觉：系统名叫 MetricVoiceGauge，却从未给"量具"做过校准。v8/v9 直接相信六层指标读数、直接相信 MetaWeight 的 5 维权重，甚至直接相信"抓取成功"这个由视觉判定的代理指标。但任何被优化的代理指标都会被优化坏——这是 Goodhart 定律，不是工程 bug。一个严谨的研究者必须给指标本身加一层"可证伪性"：每个指标都要同时报告"它的读数"和"它有多可信"。
严谨化：把指标 m_i 建模为一个含噪测量器，估计其可信度 ρ_i∈[0,1]；ρ_i 由三路证据合成——重测一致性（同一状态下重复测量的稳定性）、跨指标一致性（同层独立指标的一致程度）、结果预测效度（与慢速真值锚的时序相关）。决策权重按 ρ_i 收缩；当 ρ_i→0 或检测到"代理-目标解耦"时注入**指标中立元**——即回落到 v8 的固定权重。关键安全设计：**元评测失效不是"没有指标"，而是"退回 v8 权重"**，因此元评测本身也是一个可退化模块，而不是新的单点故障。

**灵感 2（夹爪控制 → 接触即证书）**
直觉：v9 的 δ_trigger 里 γ_grasp 是一个布尔量。可抓取是一个接触富集的控制问题：成败在接触后几毫秒决定，滑移在 50Hz 的一个周期内就可能完成。用 50Hz 的布尔判定去守 1kHz 的接触事件，等于用秒表测子弹。夹爪需要自己的快反射层与连续证书，而不是布尔真值。
严谨化：把抓取状态表示为**连续抓取证书** γ_gc=(m_slip, m_closure, r_wrench, f_n)：m_slip 为滑移裕度（接触切向力与可用摩擦之比），m_closure 为力闭合裕度，r_wrench 为接触力矩残差，f_n 为法向力。1kHz 阻抗/滑移反射在**对象级安全力包络** [f_min, f_obj] 内动作；反射只允许单调增大抓力（或触发安全重抓），因此它是一个"只修复、不破坏"的单调算子。

**灵感 3（两灵感的接缝：物理真值锚）**
直觉：元评测最痛的地方是真值稀疏且滞后（竞赛成功/失败要等到回合结束）。但夹爪是全系统里最高频的接触传感器：滑移、掉落、力突变是**事件级、毫秒级**的物理真值。于是用夹爪的力/触觉信号作为"抓取成功"代理指标的物理锚 A_phys，用任务结果作为稀疏锚 A_task。两条锚形成快慢互补：物理锚压 Goodhart 检测窗口，任务锚做长期校准。

## 1. 研究问题（轮次升级版）

- **Q1（指标可信度可证伪性）**：在真值锚稀疏、滞后且可能被同一策略影响的前提下，ρ_i 能否在指标被 Goodhart 污染时及时降权？检测延迟、误报率与锚密度之间的可证伪权衡是什么？ρ_i→0 的"指标中立元"能否保证严格退回 v8 权重？
- **Q2（抓取证书鲁棒性）**：在摩擦系数 μ∈[μ_min,μ_max] 不确定、触觉有延迟/丢帧时，连续抓取证书 γ_gc 能否给出不劣于布尔 γ_grasp 的安全保证？1kHz 反射与 50Hz 决策/5Hz 分块如何做到时标分离、互不干扰、且随对象自适应力包络？
- **Q3（联合退化边界）**：当元评测失效、夹爪反射失效、或触觉/力传感整体失效时，组合系统能否沿"γ_gc→布尔 γ_grasp→固定抓力"与"ρ→1→v8 固定权重"两条独立中立元路径严格退回 v9/v8？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 指标可证伪律（Falsifiable Metric, MMA）**
任何参与决策的指标必须同时输出读数 m_i(t) 与可信度 ρ_i(t)；ρ_i 低于阈值 τ_ρ，或代理-目标解耦 d_i 超过 τ_G 并持续 H_G 个窗口，即把该指标权重注入中立元 w_i^⊥ = w_i^{v8}。禁止在无可信度标注的情况下静默使用指标；抓取成功等稀疏代理必须绑定至少一个物理锚。

**P14 接触即证书律（Contact-as-Certificate, GRC）**
抓取安全判据由连续抓取证书 γ_gc 给出，禁用布尔 γ_grasp 作为唯一安全判据；1kHz 反射仅在对象级安全力包络 [f_min, f_obj] 内动作，且只允许单调修复（增力或安全重抓），不得主动减小抓力至滑移区。f_obj 由对象刚度/形变估计与易碎等级给出。

**P15 时标分离律（Timescale Separation）**
1kHz 夹爪反射 / 50Hz 中块守卫 / 5Hz 块生成。反射层运行于隔离 RT 核，只写夹爪力/位置指令，不回写决策状态、不参与块证书生成；跨层只通过只读状态快照与事件信号通信，避免优先级反转与跨频抖动。

## 3. 与基线的接口（如何退化）

- GRC 失效（1kHz 反射超时 / 触觉连续失效 / 力包络标定失败）⇒ 退回固定抓力 + v9 布尔 γ_grasp，等价 v9 抓取语义；
- MMA 失效（ρ 计算超时 / 锚缺失 / Goodhart 检测器故障）⇒ ρ_i≡1 且权重回 v8 固定值 w^{v8}，等价 v9 权重；
- 触觉/力传感失效 ⇒ m_slip 改用关节电流-力矩估计 + 保守 μ_min，仍保持连续证书；电流估计也失效 ⇒ 退化到 GRC 失效路径；
- v9 的 AC 失效 ⇒ K_eff←1，等价 v8 决策粒度；MW 失效 ⇒ v8 手写网关；ID 失效 ⇒ 全模块 active；
- v8 的 DA/SPR/Cal 任一失效 ⇒ 中立元注入（Δ_dom≡0 / risk_SLAM≡0 / sensor_weight≡1），等价 v7；
- 全部失效 ⇒ 完整退回 v7，再退回 v6。

## 4. 预期贡献

1. **元评测框架（MMA）**：把"指标可信度"变成一等公民，用三路证据 + 代理-目标解耦检测给出可证伪的指标使用权；指标中立元使元评测失效严格等价 v8 固定权重；
2. **接触即证书（GRC）**：用连续滑移/闭合/力矩裕度替代布尔 γ_grasp，1kHz 反射 + 对象级力包络，把抓取从"判定"变成"控制"；
3. **快慢真值锚**：以夹爪物理锚补任务锚的稀疏滞后，给出 Goodhart 检测延迟-锚密度-误报的可量化权衡；
4. **三层时标闭环**：1kHz/50Hz/5Hz 的契约化分离，把 v9 释放的算力余量大一部分用于接触层，同时不破坏 50Hz 主环；E571–E590 覆盖滑移标定、压碎边界、对抗 Goodhart、时标 WCET、联合退化与端到端任务。

## 5. 本轮最大风险

**一句话**：元评测的真值锚稀疏滞后，Goodhart 检测在渐变解耦下要 12–33 秒才触发，而夹爪反射在这段时间里只能把力推向 f_obj 上限自救——系统可能同时处在"指标已被污染"与"力已达易碎物上限"的双重边缘，这正是评测与夹爪两处灵感共同的最脆弱接缝。

**新增定义 540（指标可信度 MetricReliability）** 对每个参与决策的指标 m_i，在窗口 W_ρ 上估计：
```
ρ_i(t) = σ( a·Retest_i + b·Concord_i + c·PV_i )
Retest_i  = 1 − Var(m_i | 静止状态) / Var_ref           # 重测一致性
Concord_i = 1 − |m_i − median_{j∈layer(i)} m_j| / range  # 跨指标一致性
PV_i      = |corr_{W_ρ}(m_i, A_i)|                     # 结果预测效度
```
σ 为 logistic，a,b,c 为离线标定系数。ρ_i 与读数同帧输出，禁止无标注使用。

**新增定义 541（快慢真值锚 Two-rate Ground-Truth Anchor）**
```
A_task(t)：任务成功/失败/裁判分，更新周期 T_task（秒~分钟级），滞后 L_task
A_phys(t)：滑移事件、掉落、力突变、对象位移，事件级（ms），滞后 L_phys ≤ 3ms
```
抓取成功等稀疏代理必须绑定 A_phys；A_task 用于长期校准与 ρ 的慢分量。

**新增定义 542（代理-目标解耦 GoodhartDecoupling）**
```
d_i(t) = 1 − corr_{W_ρ}(m_i, A_i)
```
解耦判据（双通道，防单一相关失效）：
```
Goodhart(m_i) ⇔ [ d_i > τ_G 持续 H_G 个窗口 ] ∨ [ slope(regress A_i ~ m_i) 符号翻转 ]
```
一旦触发，m_i 进入 quarantine：权重注入 w_i^{v8}，并在日志中标记 `METRIC_INTEGRITY_FAIL`。

**新增定义 543（指标中立元 MetricNeutralElement）**
权重聚合与中立元：
```
w̃_i = w_i^{v8}·ρ_i / Σ_j w_j^{v8}·ρ_j        若 Σ_j w_j^{v8}·ρ_j ≥ ε
w̃   = w^{v8}                                 否则（v_MMA^⊥ 注入）
```
即：个别指标低可信 → 相对降权；元评测整体失效 → **整体回退 v8 固定权重（= v9）**。这正是"元评测失效不是没有指标，而是退回 v9"的形式表达。

**新增定义 544（连续抓取证书 GraspCertificate）**
```
γ_gc = (m_slip, m_closure, r_wrench, f_n)
γ_gc valid ⇔ m_slip ≥ γ_min ∧ m_closure ≥ m_closure^min
             ∧ r_wrench ≤ τ_r ∧ f_n ∈ [f_min, f_obj]
```
布尔 γ_grasp 只作为 γ_gc 的边界特例（γ_grasp := m_slip ≥ 0）。γ_gc 是布尔判定的严格细化。

**新增定义 545（滑移裕度 SlipMargin）**
```
m_slip = 1 − ‖f_t‖₂ / (μ_min · f_n)
```
对任意 μ ≥ μ_min，m_slip ≥ 0 ⇒ ‖f_t‖ ≤ μ_min f_n ≤ μ f_n ⇒ 静摩擦成立、无宏观滑移（引理 87）。m_slip > 0 的部分即对未建模切向扰动的鲁棒余量。

**新增定义 546（抓取阻抗律 GripperImpedanceLaw）**
```
f_n^des = sat_[f_min, f_obj] ( f_n^ff + K_p·(m_slip^des − m_slip) − K_d·ṁ_slip )
|f_n(t+Δt) − f_n(t)| ≤ R_f·Δt,   Δt = 1ms
```
1kHz 执行；K_p、K_d、R_f 由抓取评测套件（定义 552）离线标定；f_obj 由对象刚度/形变估计给出。

**新增定义 547（滑移反射事件 ReflexEvent）**

```
m_slip < γ_trig  ∨  tactile_slip_classifier = true  ∨  r_wrench > τ_r
```

**新增定义 550（对象安全力包络 GraspEnvelope）**
```
f_obj(o) = min( f_max_hw, k_stiff(o)·δ_allow(o), f_fragile(o) )
```
k_stiff 由接触刚度估计、δ_allow 为允许形变、f_fragile 为易碎等级上限。力包络是反射的硬饱和边界；包络标定失败 ⇒ GRC 失效（Level-1a）。

**新增定义 551（层级时标与优先级）**
```
优先级：GRC反射(1kHz, 隔离核) > 50Hz中块守卫/安全路径 > 5Hz块生成 > ID归因/MMA统计
```
跨层通信只允许：GRC 读取只读状态快照、向上发事件；禁止回写决策状态（引理 91）。

**新增定义 552（抓取评测套件 GraspEvalSuite）**
```
Brier      = mean( (p_success − y_success)² )        # 抓取成功预测校准
SlipIntegral = ∫ max(0, ‖f_t‖ − μ̂ f_n) dt            # 滑移冲量

```
前两项为 proper scoring / 物理量，既给 GRC 打分，也作为 MMA 的 A_phys 供给。

```python
# IP-357 MetaMetricAuditor：元评测审计器
class MetaMetricAuditor:
    def __init__(self, a=1.0, b=1.0, c=1.5, tau_rho=0.3, tau_G=0.3,
                 H_G=3, W=200, eps=1e-6):
        self.a, self.b, self.c = a, b, c
        self.tau_rho, self.tau_G, self.H_G = tau_rho, tau_G, H_G
        self.W, self.eps = W, eps
        self.quarantine = set()
        self.d_count = defaultdict(int)

    def reliability(self, m_hist, layer_hist, anchors):
        retest  = 1.0 - var_stationary(m_hist) / var_ref
        concord = 1.0 - abs(m_hist[-1] - median(layer_hist[-1])) / range_ref
        pv      = abs(corr(m_hist[-self.W:], anchors[-self.W:]))
        rho = sigmoid(self.a*retest + self.b*concord + self.c*pv)
        d   = 1.0 - pv                                   # 定义 542
        sign_flip = slope_sign(anchors[-self.W:], m_hist[-self.W:]) < 0
        if d > self.tau_G or sign_flip:
            self.d_count[m] += 1
            if self.d_count[m] >= self.H_G:
                self.quarantine.add(m)                    # 定义 542 quarantine
        else:
            self.d_count[m] = 0
        return rho

    def weights(self, rho, w_v8):
        denom = sum(w_v8[i] * rho[i] for i in rho)
        if denom < self.eps:                              # v_MMA^⊥ 注入
            log('METRIC_NEUTRAL_INJECT'); return dict(w_v8)
        w = {i: w_v8[i]*rho[i]/denom for i in rho}
        for i in self.quarantine:                         # 隔离指标回退基线权重
            w[i] = w_v8[i]
        return normalize(w)

@dataclass
class GraspCert:
    m_slip: float; m_closure: float; r_wrench: float; f_n: float

        return (self.m_slip >= gc_min and self.m_closure >= clos_min
                and self.r_wrench <= tau_r and f_min <= self.f_n <= f_obj)

class GraspReflexController:
    def __init__(self, f_min, kp, kd, rate_limit, mu_min=0.45,
                 m_target=0.20, gamma_trig=0.02, tau_r=0.8):
        self.f_min, self.kp, self.kd = f_min, kp, kd
        self.rate_limit, self.mu_min = rate_limit, mu_min
        self.m_target, self.gamma_trig, self.tau_r = m_target, gamma_trig, tau_r

    def slip_margin(self, ft, fn):
        return 1.0 - norm(ft) / (self.mu_min * fn)        # 定义 545

    def step(self, obs, dt=1e-3):
        m = self.slip_margin(obs.ft, obs.fn)
        cert = GraspCert(m, closure_margin(obs), obs.wrench_residual, obs.fn)
        f_obj = grasp_envelope(obs.object_class)          # 定义 550
        if m < self.gamma_trig or obs.tactile_slip or obs.wrench_residual > self.tau_r:
            self.reflex_event(obs, f_obj)                  # 定义 547
        f_des = obs.fn + self.kp*(self.m_target - m) - self.kd*obs.m_dot
        f_cmd = rate_clamp(sat(f_des, self.f_min, f_obj), obs.fn, self.rate_limit, dt)
        return f_cmd, cert, f_obj

    def reflex_event(self, obs, f_obj):
        if obs.fn >= f_obj - 1e-3 and self.slip_margin(obs.ft, obs.fn) < 0:
            raise RegraspRequired(obs)                     # 升级为安全重抓
        # 否则单调增力，由阻抗律在下一 tick 执行


# IP-361 GoodhartMonitor：解耦检测与延迟-误报账本
class GoodhartMonitor:
    def __init__(self, W=200, tau_G=0.3, H_G=3):
        self.W, self.tau_G, self.H_G = W, tau_G, H_G

    def observe(self, metric_hist, anchor_hist):
```

## 4. 推导

**引理 87（滑移裕度的鲁棒充分性）** 设摩擦系数 μ ≥ μ_min、法向力 f_n ∈ [f_min, f_obj]，切向接触力 f_t。若 m_slip = 1 − ‖f_t‖/(μ_min f_n) ≥ 0，则对任意 μ ≥ μ_min 有 ‖f_t‖ ≤ μ_min f_n ≤ μ f_n，静摩擦锥保持，无宏观滑移；若 m_slip ≥ m_min，则可容忍至多 m_min·μ_min·f_n 的未建模切向扰动。证明：库仑摩擦锥直接代入。∎

**引理 88（元评测门控的连续性与回退等价）** 决策泛函 F(w̃) 对权重连续。定义 543 的归一化权重满足：(i) 对任一指标，ρ_i 下降 ⇒ w̃_i 相对下降（单调降权）；(ii) 当所有 ρ_i→0 或 MMA 超时/锚缺失时，注入 v_MMA^⊥ ⇒ w̃ = w^{v8}，逐位复现 v9 的权重与决策。故任意 MMA 输出都落在 v8 权重与全可信权重的可行域内，MMA 失效严格等价 v9。∎

**引理 89（Goodhart 检测的延迟-误报权衡）** 在平稳映射下，滚动相关 r_W 的阈值 τ_G 给出误报率 ≤ δ(τ_G, W)（E577 标定）；在每窗口相关下降 ε 的渐变解耦模型下，首次跌破 τ_G 的期望窗口数 ≈ (r₀ − τ_G)/(c·ε) + H_G，c 为解耦速率常数。故检测延迟与 ε 成反比、与窗口长 W 成正比。**关键推论**：仅靠稀疏 A_task 时，W 必须足够大才能抑制误报，导致检测延迟达数十秒；引入密快 A_phys（定义 541）可在不增大误报的前提下缩小 W。∎

**引理 90（抓取反射的有界性与单调修复）** 反射动作 f_n 被饱和在 [f_min, f_obj] 且受限速率 R_f，故永不越出对象安全力包络；又 ∂m_slip/∂f_n = ‖f_t‖/(μ_min f_n²) ≥ 0，增力单调弱增滑移裕度，因此反射不会制造滑移，只做"单调修复"或"安全重抓"。前提：f_obj 估计正确；f_obj 低估会压碎、高估会掉落（见 §9 风险）。∎

**引理 91（时标分离与 50Hz 无干扰）** GRC 仅写夹爪力指令、仅读只读状态快照，不回写 MW 决策状态；运行于隔离核且 Ŵ_GRC=0.6ms < 1ms。跨层通信为无锁快照 + 事件队列，不引入 50Hz 主环的额外阻塞。故 50Hz WCET 与 v9 相同（≤20ms），1kHz 反射在线可调度（引理 86 的分层版本）。∎

**引理 92（联合证书健全性）** 布尔抓取判据是连续证书的边界特例：γ_grasp ⇔ m_slip ≥ 0，而 γ_gc valid ⇒ m_slip ≥ γ_min > 0 ⇒ γ_grasp，故 γ_gc 的失效集是 γ_grasp 失效集的子集。若块证书含 γ̂_gc 且余量 β_g、GRC 维持 m_slip ≥ γ_min，则块内抓取失败上界不劣于 v9 布尔判据；GRC+MMA 同时失效 ⇒ 抓取回退固定力 + 布尔、权重回退 v8 ⇒ 逐位退回 v9（引理 88/90）。∎

**引理 93（全链退化等价）** 由引理 88（MMA→v9）、90/92（GRC→v9 抓取语义）、v9 引理 83（MW/ID/AC→v8）、v8 严格退化链（→v7→v6）逐级复合，v10 在任意模块子集失效下的可观测行为均落在 v9/v8/v7/v6 的退化格点上，无行为漂移。∎

结论：保守 μ_min（低估）使反射提前触发，滑移冲量下降约 100%；即使 μ 高估 33%，滑移冲量仍 ↓≈99%。**但代价是力在约 200ms 内从 10N 饱和到 20N**——这正是"压碎风险"，也是定义 550 力包络与 E574 存在的理由。

| 渐变解耦速率 ε | 平均检测延迟（窗口） | p95（窗口） | 折算时间（窗=200 采样@50Hz=4s） |

## 9. 本轮最大风险

**一句话**：元评测的真值锚稀疏滞后，Goodhart 检测在渐变解耦下要 12–33 秒才触发，而夹爪反射在这段时间里只能把力推向 f_obj 上限自救——系统可能同时处在"指标已被污染"与"力已达易碎物上限"的双重边缘，这正是评测与夹爪两处灵感共同的最脆弱接缝。
