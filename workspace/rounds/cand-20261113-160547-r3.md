# 第 66 轮（承接第 65 轮「VISTA 故障归因闭环」IP-214~223；灵感循环第 3 轮；本轮灵感：「行为克隆」×「指标体系」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述的最大风险极为锋利：**归因依赖「故障属于有限假设集」与「视觉/几何失效相互独立」；未知复合故障会被强行归入最近假设、只膨胀错误的球，而系统因「已经归因」反而更自信地继续执行。** 但 VISTA 仍把一个东西当作可信背景：**策略 π 本身**。第 64/65 轮只用「块间不一致」把策略异常压成一个离散假设 `H_policy`，等于假设「策略在分布外也只会以一种可被块一致性捕捉的方式坏」。这与行为克隆（BC）的真实失效结构不符：BC 在演示分布内近乎完美，在分布外会**沉默、自信、复合**地犯错。本轮不加传感器、不加故障类别，而换一个元问题：**「策略还可信多久？用来判断可信度的那些数字本身可信吗？」** 核心命题：
>
> **把「策略可信度」从不可观测隐变量，升级为分层、因果有效、抗 Goodhart 的指标体系；用 BC 的支撑域与复合误差定义「能力视界」，让先导指标先于伤害报警，让执行只到能力视界与不可逆视界的较小者。**

## 0. 直觉与动机

**灵感 1（行为克隆：错误是分布性的、复合的、沉默的）**
直觉：BC 只在演示状态分布 `D` 上最小化动作似然；一旦测试状态滑出 `supp(D)`，它就进入「没有老师、也没有标签」的区域。三个结构性事实：
(i) **分布偏移**：小动作误差把状态推离演示流形，策略在最需要正确动作的地方最没有监督，误差沿时间复合（最坏 `O(εT²)`，交互式修正可降到 `O(εT)`）；
(ii) **因果混淆**：BC 会抓住与动作在演示中相关、但非因果的特征（背景、时刻、物体颜色），在分布内「看起来对」，一干预就错；
(iii) **沉默自信**：高似然 ≠ 分布外正确；单个策略的熵/置信度不是可靠的不确定性。
关键：这三点恰好是第 64/65 轮证书最脆弱处；而 BC 也提供了一个**可测对象**——演示支撑域及其边界。支撑域是「策略还知道自己在干什么」的可观测量。

**灵感 2（指标体系：单一证书是「独裁指标」）**
直觉：指标系统理论（OECD 复合指标、Balanced Scorecard、SRE 的 SLI/SLO/error budget）的第一原则不是「多加指标」，而是**分层与制衡**：
- **层级**：目标→维度→指标→数据源；不同层用不同聚合。
- **先导 vs 滞后**：先导指标预测，滞后指标确认；安全系统必须两者都有，否则只能事后验尸。
- **有效性/可靠性/敏感性/特异性**：指标必须测到它声称测的东西，且对干扰不敏感。
- **非补偿 vs 补偿**：硬约束必须字典序否决，绝不能被加权和「补偿」。
- **反指标/配对指标**：任何被优化的单一指标都会被 Goodhart；必须用配对指标守住「没有免费午餐」。
- **误差预算**：把阈值变成预算，按燃烧率提前降档。
第 64/65 轮造了很多数字（`ρ_rob`、`ρ_slip`、`ρ_force`、`fault_entropy`、`k*`），但没有**系统**：`J` 是一个合取式，不区分先导/滞后，没有反指标，没有有效性审计。于是「低残差/低熵」可以被「不动、不接触、不探索」刷出来。

**灵感 3（合流 → CALIPER）**
CALIPER = Calibrated Anti-Goodhart Layered Indicators for Policy competence & Execution Risk。三层 + 三机制：
- **L0 硬包络**（非补偿、字典序否决、与策略无关、物理/传感器接地）：力、速度、能量、停止距离、形变、碰撞。
- **L1 先导指标**（面向策略、预测性）：支撑域得分 `s_sup`、逆动力学一致性、集成/块间不一致、激励覆盖度、因果混淆干预残差、安全评论家 hazard、能力视界 `T_c`。
- **L2 滞后指标**（结果/审计）：成功率、损伤、恢复时间、归因准确率、误降级率；只用于校准与审计，不进实时控制。
- **C 反指标配对**：每个被优化的 L1 都配一个反向指标（低力↔接触完成、低残差↔探索覆盖、低熵↔归因正确），并定义 Goodhart 裕度。
- **B 误差预算**：每维有预算与燃烧率，预算将尽先降档，硬越界前进入 safe-idle。
- **V 有效性证书**：每个指标必须通过干预检验（对因果因子响应、对干扰不响应），否则不得进入聚合。
聚合：L0 字典序否决 → 有效性/预算门控 → L1 软聚合 → L2 只做事后校准。核心是**安全性不再依赖 L1 的权重**（L0 独立），**Goodhart 被限制在反指标预算的松弛里**。

**灵感 4（与 VISTA 的原位耦合：不是替换，是给策略补上「保质期」）**
- **ACH → CHK（Competence-Horizon Chunking）**：区分预测视界 `H` 与可信视界 `T_c`；执行前缀 `k* ≤ min(m, ⌊T_c⌋)`。演示未被激励的方向，`T_c=0`（不得外推），由支撑指标接管。
- **FIR → IFA（Indicator-Fused Attribution）**：`H_policy` 从离散假设变成由 L1 指标给出的分布似然；未知/复合故障表现为指标互相矛盾（有效性失败、预算无故燃烧）→ ambiguous，而不是强行归类。
- **CSC → 预算感知**：`k*` 同时受 L0 与 L1 约束；预算燃烧率超过阈值即缩短 `k*`。
- **AFA → 约束化探针**：探针在最大化互信息之外，必须通过有效性/反指标约束，防止「为了降熵而做危险或自证式探测」。
- **RSC-V/WCV-V → 指标调制**：L1 只调软球，L0 独立钳制；避免把「策略不确定」误当成「几何不确定」。
- **AIC-V → 指标攻击**：新增「指标博弈」对手——直接优化仪表盘而违反任务；以及陈旧指标、指标失效、共因（同一分布偏移同时打击策略与感知）。
- **J_vista → J_caliper**：证书增 `indicator_vector`、`T_c`、`validity_cert`、`budget_burn`、`goodhart_margin`、`counter_metrics`、`meta_health`。

**灵感 5（为什么这不是「又加一个指标」）**
区别在**系统级可证伪性**：(1) 先导/滞后分离让系统能**先于伤害**行动；(2) L0 字典序使安全性**不依赖权重与 L1**；(3) 反指标配对 + Goodhart 裕度把「刷指标」变成**有预算上限的有限松弛**；(4) 有效性证书让指标本身可被证伪。单独再加一个数，只是多一个攻击面。

## 1. 形式化定义（增量：233–248）

- **定义 233（BC 策略、演示分布与支撑得分）**：演示 `D={(s_i,a_i)}~p_D`，BC 学 `π_θ(a|s)`；支撑得分 `s_sup(s)=-log p̂_D(s)`（或 kNN/Mahalanobis/energy），越界集 `S_out(τ_s)={s:s_sup(s)>τ_s}`。`s_sup` 只是先导证据，不是正确性证明。
- **定义 234（激励方向与可辨识视界）**：以特征 `φ(s)` 定义激励矩阵 `E=∫φφᵀdp_D`；本征值 `<ε_ex` 的方向为未激励方向。未激励方向上的策略外推**不可由演示数据辨识**，故其能力视界强制为 0。
- **定义 235（能力视界 `T_c`）**：在闭环误差动力学 `e_{t+1}=Ae_t+w_t`、`‖A‖=L<1`、`‖w_t‖≤ε` 下，`‖e_t‖≤Lᵗ‖e₀‖+ε(1−Lᵗ)/(1−L)`；`T_c=max{t: 该上界≤d_safe}`。`L≥1` 用相应增长式。未激励方向 `T_c=0`。`T_c` 是*已激励子空间*上的可信下界，不覆盖因果混淆。
- **定义 236（分层指标体系 `O`）**：`O=(L0,L1,L2,C,B,V,Agg)`；要求 L0 独立于策略与 L1 可测，L1 在线可测，L2 可离线。
- **定义 237（指标测量质量四元组）**：`Q(ℓ)=(Val,Rel,Sen,Spe)`，分别为有效性、可靠性、敏感性、特异性；低于阈值者不得进入 L1 聚合。
- **定义 238（干预有效性）**：`γ_val(ℓ)=E[ℓ|do(f=f+Δ)]−E[ℓ|do(f=f)]−λ_n·|E[ℓ|do(n=n+Δ)]−E[ℓ|do(n=n)]|`；`γ_val≥γ_min` 才判有效。指标因此是可证伪的。
- **定义 239（先导/滞后指标向量）**：`z_t=[s_sup,e_id,d_chunk,u_chunk,c_cf,h_crit,1/T_c,…]`；`y_t=[success,damage,recovery,attribution_acc,…]`。先导性由 `I(z_t;y_{t+τ}|past)>0` 且 `τ>0` 定义。
- **定义 240（非补偿 L0 包络）**：可行集 `F₀=∩_j{ℓ₀ʲ≤c_j}`；任何 `s∉F₀` 一律 `Valid=false`，其他指标再好也不能补偿。L0 必须由独立物理传感器或保守上界计算。
- **定义 241（误差预算与燃烧率）**：维度 `j` 预算 `B_j`、消耗 `c_j(t)`、燃烧率 `b_j=dc_j/dt`；`b_j>b_max` 先降档，`c_j≥B_j` 进 safe-idle。阈值由此变成**越界前动作**。
- **定义 242（反指标配对与 Goodhart 裕度）**：被优化指标 `ℓ_k` 配反指标 `ℓ_{c(k)}`；更新是 Goodhart 容许的当 `Δℓ_k>0 ⇒ Δℓ_{c(k)}≥−γ_G(k)`。`γ_G` 由预算与任务下限共同确定。
- **定义 243（Goodhart 容许集）**：`Θ_G={θ: ℓ_{c(k)}(θ)≥ℓ_{c(k)}^{min} 且燃烧率在预算内}`；证书只接受 `θ∈Θ_G`，于是刷指标的松弛被预算封顶。
- **定义 244（分层聚合算子）**：字典序 `L0 否决 → 有效性命中冻结 → 预算门控降档 → L1 软聚合 → L2 离线校准`；L1 单维告警可升级为软否决，避免加权补偿。
- **定义 245（指标融合归因 IFA）**：`H_policy` 扩为连续能力变量，用 `z_t` 给 `p(z,ρ|H)`；指标互相矛盾（低残差但高支撑分、低力但零进度、有效性失败）时判 `ambiguous` 并保守降级，而非强行归类。
- **定义 246（CALIPER 证书 `J_caliper`）**：`J_caliper=(J_vista,z,T_c,V,B,γ_G,y_c,meta_health,agg_ver)`；`Valid ⇔ Valid(J_vista) ∧ L0 ∈ F₀ ∧ 所用 L1 有效 ∧ 预算未耗尽 ∧ k*≤min(m,⌊T_c⌋) ∧ θ∈Θ_G ∧（指标矛盾⇒已判 ambiguous）`。
- **定义 247（元指标与指标系统健康度）**：覆盖度、冗余度、可博弈度、审计新鲜度、标定漂移；健康度 `m` 过低时**指标系统本身不可信**，退回 L0 包络 + safe-idle。
- **定义 248（CALIPER 闭环算子）**：语义流 `[演示库→支撑模型→L1 计算→有效性门→预算/Goodhart 门→L0→IFA→CSC/CHK→执行 k*→预算/元健康更新→L2 审计]`；实时流 `[L0 包络→支撑分/块不一致/T_c 增量→预算燃烧→早停/降档]`，零学习写。

## 2. 关键算法骨架

```python
# CHK：能力视界 → 执行前缀
T_c = competence_horizon(demo_stats, closed_loop, d_safe)  # 未激励方向=0
k_star = min(m, floor(T_c), csc.certified_prefix(A, post, budget))

# 分层聚合：L0 字典序否决
def aggregate(z, l0, budgets, validity, counter):
    if any(not l0_ok(l0)): return VETO
    for k in z:
        if not validity[k]: z[k] = FREEZE
    if burn_rate(budgets) > B_MAX: level = downgrade(level)
    if not goodhart_admissible(z, counter): return VETO
    return composite(z, weights=health(budgets, validity))
```

## 3. 保证概要

- **引理 9（激励感知的能力视界）**：已激励子空间上 `T_c` 由收缩/增长界给出；未激励方向上存在两个演示似然相同、外推行为不同的策略，故任何数据驱动证书都只能取 `T_c=0`。这把「BC 不可外推」从经验说法变成可证明的不可能性。
- **引理 10（先导指标的提前量）**：若 `z_t` 对 `y_{t+τ}` 有信息，按 `z` 早停可在伤害前 `τ` 步动作；若 `I(z_t;y_{t+τ})=0`，则不存在先导保护。先导指标的价值被量化为可提前的停止距离。
- **定理 9（非补偿安全）**：只要 L0 包络被正确设定并字典序执行，`Valid(J_caliper) ⇒ 物理硬约束成立`，与 L1 权重、`T_c` 估计误差、BC 能力强弱**无关**。这是对第 65 轮「归因错则更自信」的结构性回答：物理安全不再条件于归因/指标正确。
- **定理 10（抗 Goodhart 的有限松弛）**：在 `Θ_G` 内优化复合指标，反指标不会跌破其下限；相对无约束最优的效用损失被反指标预算的松弛量封顶。即反 Goodhart 不消灭博弈，只把博弈关进有刻度的笼子。
- **定理 11（CALIPER-VISTA 端到端）**：在 A94–A99 下，`Valid(J_caliper)` ⇒ VISTA 的归因/几何/接触保证 ∧ L0 ∧ `k*` 同时受 `m` 与 `T_c` 约束 ∧ 指标有效 ∧ Goodhart 容许；未知/复合故障表现为指标矛盾 → ambiguous + 保守。

## 5. 本轮最大风险

**一句话**：CALIPER 把「指标的合法性」当成近乎免费的假设——一旦反指标覆盖不全、或干预有效性检验只在分布内样本上通过，策略（或对手）就会学会优化仪表盘而非任务，而分层证书会让这种 Goodhart 失效比单一证书**更隐蔽、更自信**；同时 L0 包络本身若标定错误，整套指标层级都无法兜底。

## 2. 形式化定义（完整版）

**定义 233（BC 策略、演示分布与支撑得分）** 设演示数据 `D={(s_i,a_i)}_{i=1}^n ~ p_D(s,a)`，行为克隆最小化
`L_BC(θ)=−E_{(s,a)~p_D}[log π_θ(a|s)]`
（确定性策略用 `E‖π_θ(s)−a‖²`）。记演示状态边缘为 `p_D(s)`，其估计 `p̂_D`。支撑得分定义为
`s_sup(s) = −log p̂_D(s)`，
可取 kNN 距离、Mahalanobis 距离或 energy score；越界集 `S_out(τ_s)={s:s_sup(s)>τ_s}`。**`s_sup` 只产生「状态离开了演示覆盖」的证据，不产生「动作正确」的结论。**

**定义 234（激励方向与可辨识视界）** 取特征 `φ(s)∈ℝ^{d_φ}`（含任务相关坐标），定义演示激励矩阵
`E = ∫ φ(s)φ(s)ᵀ dp_D(s)`。
其特征值 `<ε_ex` 的子空间称为**未激励方向**。若某方向未被激励，则演示数据对该方向上的动作敏感性没有持续激励（persistency of excitation），任何仅依赖演示的估计都无法辨识该方向的外推误差。**结论：未激励方向上不得声称任何有限能力视界，强制 `T_c=0`。**

**定义 235（能力视界）** 设闭环误差动力学线性化为
`e_{t+1}=A e_t + w_t,  ‖A‖=L,  ‖w_t‖≤ε`。
若 `L<1`，则
`‖e_t‖ ≤ Lᵗ‖e₀‖ + ε(1−Lᵗ)/(1−L)`；
若 `L=1`，则 `‖e_t‖≤‖e₀‖+εt`；若 `L>1`，用 `‖e_t‖≤Lᵗ‖e₀‖+ε(Lᵗ−1)/(L−1)`。定义
`T_c(e₀,d_safe) = max{ t∈ℕ : ‖e_t‖上界 ≤ d_safe }`，仅对已激励子空间计算；未激励方向 `T_c=0`。
`T_c` 是**已激励子空间上的可信下界**，它不覆盖因果混淆与接触冲击等非 Lipschitz 效应，故不能替代 L0 与 L1。

**定义 236（分层指标体系）** 一个 CALIPER 指标系统为
`O=(L0,L1,L2,C,B,V,Agg)`，
其中 `L0={ℓ₀ʲ}` 为硬包络指标，`L1={ℓ₁ᵏ}` 为先导指标，`L2={ℓ₂ᵐ}` 为滞后/审计指标，`C={(ℓ₁ᵏ,ℓ₁^{c(k)})}` 为反指标配对，`B={B_k}` 为预算，`V={v_k}` 为有效性证书，`Agg` 为定义 244 的聚合算子。结构性约束：
- **L0 独立于策略与 L1**：只由物理传感器或保守上界计算，防止「策略把仪表盘调好」影响安全。
- **L1 在线可测**：可在实时流增量计算。
- **L2 允许离线**：只用于阈值/权重校准与事后审计，不得直接驱动实时控制。

**定义 237（指标测量质量四元组）** 对指标 `ℓ` 定义
`Q(ℓ)=(Val,Rel,Sen,Spe)`：
有效性 `Val`（是否测到构造目标）、可靠性 `Rel`（重复测量的一致性/噪声）、敏感性 `Sen`（对真实变化的响应）、特异性 `Spe`（对干扰的不响应）。仅当 `Q(ℓ)` 各分量超过阈值才可进入 L1 聚合，否则冻结并置 `meta_flag`。

**定义 238（干预有效性）** 设 `f` 为目标因果因子，`n` 为干扰因子，`do(·)` 为干预算子。定义有效性裕度
`γ_val(ℓ) = E[ℓ | do(f=f+Δ)] − E[ℓ | do(f=f)] − λ_n·|E[ℓ | do(n=n+Δ)] − E[ℓ | do(n=n)]|`。
`ℓ` 有效当且仅当 `γ_val(ℓ) ≥ γ_min`。该定义是可证伪的：指标若对干扰敏感、或对因果因子不敏感，即判无效。有效性检验本身必须在**留出的分布外扰动**上重复，避免「只在内分布通过」的元 Goodhart。

**定义 239（先导/滞后指标向量）** 先导指标
`z_t=[s_sup, e_id, d_chunk, u_chunk, c_cf, h_crit, 1/T_c, …] ∈ ℝ^{d_z}`，
其中 `e_id` 为逆动力学一致性残差（执行 `a_t` 后预测 `s_{t+1}` 与实际之差）、`d_chunk/u_chunk` 沿用第 65 轮块间不一致/集成方差、`c_cf` 为因果混淆残差（定义 230 的 CCA）、`h_crit` 为安全评论家 hazard。滞后指标
`y_t=[success, damage, recovery, attribution_acc, false_demotion, …] ∈ ℝ^{d_y}`。
先导性由条件互信息定义：存在 `τ>0` 使 `I(z_t; y_{t+τ} | z_{1:t−1}) > 0`；滞后指标在事件后才可实现。

**定义 240（非补偿 L0 包络）** 对每个硬约束 `j` 给定限值 `c_j`，可行集
`F₀ = ∩_j { (s,a) : ℓ₀ʲ(s,a) ≤ c_j }`。
L0 为**非补偿**：只要 `(s,a) ∉ F₀`，无论 L1/L2 多好，`Valid(J_caliper)=false`。L0 必须由相互独立的物理通道（力/电流/速度/停止距离/形变、必要时硬件限位）计算，且带自检；其正确性不由学习模型背书。

**定义 241（误差预算与燃烧率）** 对维度 `j`，给定预算 `B_j>0`（可为累计违例概率、力-时间积分、能量或探针次数），消耗 `c_j(t)` 单调不减，燃烧率
`b_j(t)=dc_j(t)/dt`。
门控规则：`b_j>b_max` 时降低保真度档位（缩短 `H`/`k*`、减少探针、收紧软球）；`c_j≥B_j` 时进入 safe-idle。预算把「阈值」变成**越界前的可行动信号**，这是滞后阈值做不到的。

**定义 242（反指标配对与 Goodhart 裕度）** 对每个被优化的 L1 指标 `ℓ_k`，指定反指标 `ℓ_{c(k)}`（例如：低力↔接触完成、低残差↔探索覆盖、低归因熵↔归因正确、低速度↔循环时间）。一次参数更新是 **Goodhart 容许**的，当
`Δℓ_k>0 ⇒ Δℓ_{c(k)} ≥ −γ_G(k)`，
其中 `γ_G(k)` 由反指标预算与任务下限共同确定。`γ_G` 越大越保守；`γ_G=0` 表示不允许以任何反指标退化为代价换取主指标。

**定义 243（Goodhart 容许集）** 定义
`Θ_G = { θ : ∀k, ℓ_{c(k)}(θ) ≥ ℓ_{c(k)}^{min} 且 b_{c(k)}(θ) ≤ b_max }`。
证书只接受 `θ∈Θ_G`。于是优化复合指标的自由度被反指标下限与预算封顶；未被反指标覆盖的维度仍是残余博弈面（见元健康度）。

**定义 244（分层聚合算子）** `Agg` 按字典序执行：
1. **L0 否决**：若 `∃j: ℓ₀ʲ>c_j`，返回 `VETO`；
2. **有效性门**：若 `v_k` 失败，冻结 `ℓ_k`（不参与聚合）并置 `meta_flag`；
3. **预算门**：若某维 `b_j>b_max`，执行 `downgrade`（降 `H/k*`、减探针、收紧软球）后重算；
4. **L1 软聚合**：对存活 L1 先归一化，再取加权几何平均
`S = (∏_k ℓ̃_k^{w_k})^{1/Σw_k}`，
`w_k` 由有效性/可靠性/预算健康度给出；任一 L1 超过告警线可升级为软否决，**禁止用其他维度的加权和补偿**；
5. **L2 校准**：只在离线用 `y` 校准阈值、权重与 `γ_G`，不进入实时许可。
返回 `(level, S, flags)`；`level∈{idle, coarse, full, active}` 对应保真度档位。

**定义 245（指标融合归因 IFA）** 在第 65 轮 `ℋ={H0,H_geo,H_force,H_model,H_vis,H_policy}` 上，把 `H_policy` 扩为连续能力变量 `θ_p∈[0,1]`（剩余可信能力比例）。归因似然用阶段签名 `ρ` 与先导指标 `z` 共同给出
`p(ρ,z|H) = ∫ p(ρ|H,θ_p) p(z|H,θ_p) p(θ_p|H) dθ_p`。
若指标互相矛盾——低 `ē_force` 但高 `s_sup`、低力但零接触完成、`γ_val<γ_min`、预算无故燃烧——则定义矛盾度
`D(z) = Var_k( z̃_k ) / (1+Var_k(z̃_k))`（`z̃` 为归一化指标），`D(z)>τ_dis` 或任一有效性失败即判 `ambiguous`，不强行归入最近假设，转保守联合膨胀 + safe-idle。

**定义 246（CALIPER 证书）** 
`J_caliper=(J_vista, z, T_c, V, B, γ_G, y_c, meta_health, agg_ver)`。
验证规则：
`Valid(J_caliper) ⇔`
`Valid(J_vista)`
`∧ (s,a)∈F₀`（L0 全部满足）
`∧ ∀k∈used: v_k=pass`
`∧ c_j<B_j`（预算未耗尽）
`∧ k* ≤ min(m, ⌊T_c⌋)`
`∧ θ∈Θ_G`
`∧ (D(z)>τ_dis ⇒ 已判 ambiguous 并保守降级)`
`∧ meta_health ≥ m_min`
`∧ agg_ver` 为当前版本。
审计链新增：为何执行这个 `k*`（`T_c`）、为何相信这组指标（有效性证书）、是否在刷指标（Goodhart 裕度/反指标）、指标系统本身是否健康（`meta_health`）。

**定义 247（元指标与指标系统健康度）** 定义元指标：
- 覆盖度 `cov`：故障模式集合中被至少一个有效 L1 覆盖的比例；
- 冗余度 `red`：指标间相关结构（过高=共因风险，过低=覆盖不足）；
- 可博弈度 `game`：在不改变真实任务效用的前提下，把复合指标提高的最大幅度（用小规模对抗搜索估计）；
- 新鲜度 `fresh`：标定/审计距今天数或分布漂移；
- 标定漂移 `drift`。
`meta_health = min(cov, 1−game, fresh, 1−drift)`。当 `meta_health<m_min` 时，**指标系统本身不可信**，退回 L0 包络 + safe-idle，而不是继续用「看起来很好」的仪表盘执行。这是「谁来监督监督者」的有限层：元健康度本身不再递归，而由固定的 L0 与硬件自检兜底。

**定义 248（CALIPER 闭环算子）** 语义流：
`[演示库→BC-DS 支撑/激励→L1 指标计算→IVC 有效性门→EBU 预算/GCM Goodhart 门→L0 包络→IFA 归因→CSP-V 块规划→CHK/CSC 前缀→执行 k*→EV_exec→预算/元健康更新→L2 审计→AIC-C 认证]`。
实时流：
`[L0 包络检查→支撑分增量→块不一致/T_c 增量→预算燃烧率→早停/降档→派发]`，零学习写操作。

### IP-224 BC-DS（支撑域与能力视界）

```python
class BCDistributionalShadow:
    """保存演示统计；输出支撑分、可辨识子空间与能力视界。"""
    def __init__(self, demo_states, demo_actions, eps_ex=1e-3):
        self.mu = demo_states.mean(0)
        self.cov = np.cov(demo_states.T) + 1e-6 * np.eye(demo_states.shape[1])
        self.inv_cov = np.linalg.inv(self.cov)
        self.E = self._excitation(demo_states)          # ∫ φφᵀ dp_D
        self.excited = self._excited_subspace(self.E, eps_ex)

    def support_score(self, s):
        d = s - self.mu
        return float(d @ self.inv_cov @ d)              # Mahalanobis²，越大越外

    def competence_horizon(self, e0, d_safe, L, eps, max_t=10_000):
        # 只对已激励子空间；未激励方向返回 0
        e0_ex = self.project_excited(e0)
        if np.linalg.norm(e0_ex) < 1e-9 and eps <= 0:
            return 0
        for t in range(max_t + 1):
            if L < 1:
                bound = L**t * np.linalg.norm(e0_ex) + eps * (1 - L**t) / (1 - L)
            elif L == 1:
                bound = np.linalg.norm(e0_ex) + eps * t
            else:
                bound = L**t * np.linalg.norm(e0_ex) + eps * (L**t - 1) / (L - 1)
            if bound > d_safe:
                return max(0, t - 1)
        return max_t
```

### IP-225/226/227/228 分层聚合与门控

```python
def caliper_aggregate(z, l0, budgets, validity, counter, meta_health,
                      weights=None, b_max=1.0, m_min=0.6):
    # 1) L0 非补偿否决
    if any(not l0_ok(l0[j], j) for j in l0):
        return {'level': 'idle', 'valid': False, 'reason': 'L0_violation'}
    # 2) 有效性门：无效指标冻结，不参与聚合
    active = {k: v for k, v in z.items() if validity.get(k) == 'pass'}
    flags = [k for k, v in z.items() if validity.get(k) != 'pass']
    # 3) 预算门：越界前降档
    level = 'full'
    if any(burn_rate(budgets[j]) > b_max for j in budgets):
        level = 'coarse'
    if any(consumed(budgets[j]) >= budgets[j].total for j in budgets):
        return {'level': 'idle', 'valid': False, 'reason': 'budget_exhausted'}
    # 4) Goodhart 容许检查
    if not goodhart_admissible(active, counter):
        return {'level': 'idle', 'valid': False, 'reason': 'goodhart_violation'}
    # 5) 元健康度：指标系统本身是否可信
    if meta_health < m_min:
        return {'level': 'idle', 'valid': False, 'reason': 'meta_unhealthy'}
    # 6) L1 软聚合（几何平均，禁止单维补偿）
    w = weights or {k: 1.0 for k in active}
    S = float(np.exp(sum(w[k] * np.log(normalize(k, active[k])) for k in active)
                     / sum(w.values())))
    if any(over_alert(k, active[k]) for k in active):
        level = 'coarse'
    return {'level': level, 'valid': True, 'score': S, 'flags': flags}
```

### IP-229 CHK（能力视界截断执行前缀）

```python
def chk_prefix(A, m, T_c, csc, post, budgets):
    # 先由 CSC 给出安全前缀，再用能力视界与预算截断
    k_csc = csc.certified_prefix(A, post, m, alpha_chunk)
    k = min(m, int(np.floor(T_c)), k_csc)
    if any(burn_rate(budgets[j]) > B_MAX for j in budgets):
        k = max(1, k // 2)          # 预算将尽：缩短承诺
    return max(0, k)
```

### IP-230 CCA（因果混淆审计）

```python
def causal_confusion_residual(policy, state, causal_feats, nuisance_feats,
                              delta=0.1, n=8):
    """干预因果特征应改变动作；干预干扰特征不应改变动作。"""
    base = policy(state)
    resp_causal = np.mean([np.linalg.norm(
        policy(perturb(state, f, delta)) - base) for f in causal_feats])
    resp_nuis = np.mean([np.linalg.norm(
        policy(perturb(state, n, delta)) - base) for n in nuisance_feats])
    return float(resp_nuis / (resp_causal + 1e-9))   # 越大越可疑
```

```python
def CALIPER_round(M, obs, delta_f_req):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    # —— 语义流 ——
    M.lsf.update_geometry(P_cloud)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))
    y_vis = M.f_vis(img, depth, flow)

    # 1) L0：与策略无关的硬包络（永远先算）
    l0 = M.envelope.measure(W_meas, tactile, M.robot_state)
    # 2) BC-DS：支撑分 + 能力视界（未激励方向=0）
    s_sup = M.bc_ds.support_score(x_prime)
    T_c = M.bc_ds.competence_horizon(M.bc_ds.error_state(x_prime),
                                     M.d_safe, M.L_hat, M.eps_hat)
    # 3) L1 先导指标
    z = M.indicators.compute(x_prime, W_meas, M.residual_log, y_vis)
    z['s_sup'], z['1/T_c'] = s_sup, (1.0 / T_c if T_c > 0 else np.inf)
    # 4) 有效性/预算/Goodhart/元健康门控
    agg = caliper_aggregate(z, l0, M.budgets, M.validity, M.counter,
                            M.meta_health)
    if not agg['valid']:
        return M, M.envelope.safe_idle(), build_j_caliper(M, agg, T_c, z)

    # 5) IFA 归因（H_policy 为连续能力）
    A = M.ach.propose(x_prime, H=M.H)
    visual = M.vpg.verify_and_predict(y_vis, A, M.mws.last_contacts)
    phases = M.stage.split(M.residual_log, visual)
    post, h_star, ambiguous = M.ifa.attribute(phases, z)
    if ambiguous:
        a, ig = M.afa.choose_probe(post, M.phi_hat, M.f_safe,
                                   M.object_fragile, validity=M.validity)
        if a is not None:
            M.execute_probe(a)
            post, h_star, ambiguous = M.ifa.attribute(
                M.stage.split(M.residual_log, visual), z)

    # 6) 规划 + CHK/CSC 认证前缀
    goal = M.dms.parse_goal((M.usr.U_ep, M.usr.U_al))
    tau = M.csp_v.plan_chunks(goal, x_prime, M.phi_hat, M.balls, post)
    k_star = chk_prefix(tau.A, M.m, T_c, M.csc, post, M.budgets)
    if k_star < 1:
        return M, M.envelope.safe_idle(), build_j_caliper(M, agg, T_c, z)
    K_safe, EV_exec, cert_exec = realtime_step_caliper(
        M, delta_f_req, tau, k_star, x_prime)

    # 7) 更新预算/元健康（语义流，零实时写）
    M.budgets.update(EV_exec, l0, z)
    M.meta_health.update(M.validity, M.counter, M.drift_monitor)
    M.ifa.update(EV_exec, z, post)
    return M, K_safe, EV_exec, build_j_caliper(
        M, agg, T_c, z, cert_exec=cert_exec)
```

## 4. 推导

**引理 9（激励感知的能力视界）** 设闭环误差在已激励子空间上满足 `e_{t+1}=Ae_t+w_t`、`‖A‖=L`、`‖w_t‖≤ε`。由三角不等式与归纳得
`‖e_t‖≤Lᵗ‖e₀‖+ε(1−Lᵗ)/(1−L)`（`L<1`），故 `T_c` 的定义给出一个可计算的可信视界。反过来，若方向 `v` 未被激励（`E` 在 `v` 上的特征值 `<ε_ex`），则存在两个策略 `π,π'`，它们在演示分布上的似然任意接近，但在 `v` 方向上的外推增益可任意不同（因为演示没有在该方向提供动作敏感性约束）。因此任何仅依赖演示的证书都无法给出该方向上的有限 `T_c`，只能取 `T_c=0`。∎

**引理 10（先导指标的提前量）** 设先导指标 `z_t` 满足 `I(z_t; y_{t+τ}|past)>0`，且存在阈值 `τ_z` 使 `z_t>τ_z` 在真实越界前 `ℓ` 步触发。则按 `z` 早停可在滞后指标 `y` 实现前 `ℓ` 步采取动作；若停止/降档所需距离为 `d_stop`，当 `ℓ·v ≤ margin` 时可避免越界。若 `I(z_t;y_{t+τ})=0`，则任何基于 `z` 的早停都不比被动等待 `y` 更好。故「先导」的价值等于可提前的停止距离，而不是一个模糊的「更早」。（证明：互信息的 data-processing 与阈值事件的单调性。）∎

**定理 9（非补偿安全）** 若 L0 包络 `F₀` 被正确设定（覆盖所有物理硬约束）且按定义 244 字典序执行，则 `Valid(J_caliper) ⇒ (s,a)∈F₀`，即所有物理硬约束成立。该结论**不依赖** L1 权重、`T_c` 估计、BC 能力强弱、归因后验是否正确。证明：`Valid` 的第一条门是 L0 否决；L0 由独立物理通道计算，其逻辑不经过 L1/L2。∎ 这是对第 65 轮头号风险的结构性回答：即使归因错了、指标被刷了，物理层仍独立兜底。但须诚实：L0 只覆盖**物理**硬约束，不覆盖任务正确性；任务安全仍需 L1/L2。

**定理 10（抗 Goodhart 的有限松弛）** 设真实效用 `U(θ)` 对每个反指标 `ℓ_{c(k)}` 单调不降，且 `Θ_G` 中要求 `ℓ_{c(k)}≥ℓ_{c(k)}^{min}`。则对任意 `θ∈Θ_G`，`U(θ) ≥ U_min`，其中 `U_min` 是满足反指标下限的效用下界。于是任何通过牺牲反指标换取主指标的更新，在跌破下限前即被 `Θ_G` 拒绝；相对无约束最优的损失被反指标预算的松弛量 `Σ_k γ_G(k)` 封顶。反 Goodhart 不消灭博弈，而是把博弈限制在**有刻度、可审计**的笼子里。∎

**定理 11（CALIPER-VISTA 端到端）** 在 A94–A99 下：
1. **物理安全独立**：由定理 9，L0 否决与归因/指标无关；即使 `H_geo/H_force` 归错，力/速度/停止距离仍被钳制。
2. **策略保质期**：`k*≤min(m,⌊T_c⌋)`，且未激励方向 `T_c=0`，故不会在「演示没教过」的方向上凭 BC 外推执行。
3. **先导保护**：L1 指标在滞后伤害前触发降档/早停（引理 10），预算燃烧率把「接近阈值」变成可行动信号。
4. **抗刷指标**：证书要求 `θ∈Θ_G` 且元健康度过阈值，刷仪表盘被反指标预算与有效性检验限制（定理 10）。
5. **未知/复合故障**：指标矛盾（有效性失败、预算无故燃烧、低力零进度）→ `D(z)>τ_dis` → ambiguous + 保守联合膨胀 + safe-idle，而不是强行归入最近假设。
6. **优雅降级**：指标失效→冻结该指标并降级；L1 全失效→退回 L0 + 保守策略；L0 失效→硬件限位/safe-idle；元健康过低→指标系统整体停用。
7. **实时性**：L0 <0.05ms、支撑分 <0.1ms、`T_c` O(1)、L1 聚合 <0.2ms、预算/Goodhart <0.1ms，实时路径仍 <2.5ms（A93 修订契约）。∎

**命题（分层指标降低过保守）** 设单一保守证书必须对所有维度取最坏，故其可行域为 `∩_j {ℓ_j≤c_j^{worst}}`；CALIPER 的 L1 允许按维度预算与 `T_c` 自适应放宽（只收紧不放松 L0）。若各维度失效相关性低，则 CALIPER 的可行域体积不小于单证书，且 L0 保证硬安全不变。故在保持 `违规=0` 的前提下，循环时间/成功率不劣，通常更优。∎

**命题（能力视界与不可逆视界的分工）** 第 65 轮的 `m` 由物理停止距离与力限决定，回答「越过哪个点就不可逆」；本轮的 `T_c` 由 BC 的分布内可信度决定，回答「策略还知道该做什么多久」。二者独立：`m` 大而 `T_c` 小（策略先失效）或 `m` 小 `T_c` 大（物理先越界）都可能。执行前缀必须同时满足 `k*≤m` 与 `k*≤T_c`，故 `k*=min(m,⌊T_c⌋,k_CSC)`。这把「长预测、短执行」中的「短」拆成了两个可分别估计、可分别审计的原因。

## 7. 合成预实验（非真机，仅验证机制方向）

**Toy A：BC 的「演示内完美、未激励方向失效」与先导指标提前量。**
二维状态 `(x,y)`，动力学 `x'=0.95x+u`、`y'=1.01y+u`；专家 `u*=−0.45x−0.5y`。演示 `x~N(0,1)`、`y~N(0,0.01²)`，动作加 `N(0,0.05²)`；用岭回归 BC（`α=1.0`）。得到 `β_x≈−0.444`、`β_y≈−0.004`——由于 `y` 在演示中几乎无激励，岭回归把它的增益收缩到近零，学习策略在 `y` 方向几乎不施救。闭环 `y` 系数 ≈ `1.006>1`。取 `d_safe=10`、`x₀=0`，不同初始 `y₀` 的实测能力视界 `T_c` 与支撑分：

| `y₀` | `T_c`（实测越界时刻） | 支撑分 `s_sup≈y₀/0.01` | 先导提前量 |
|---|---|---|---|
| 2 | 171 | 200 | 171 |
| 5 | 74 | 500 | 74 |
| 8 | 25 | 800 | 25 |
| 10 | 1 | 1000 | 1 |

结论：(i) BC 在演示内（`y≈0`）对 `x` 跟踪良好，却在未激励的 `y` 方向失败——这正是「沉默自信」；(ii) `β_y≈0` 说明 `T_c` 在该方向**不可由演示辨识**，只能由支撑分接管，验证定义 234/引理 9；(iii) 支撑分在 `t=0` 即越界，先导提前量等于整个 `T_c`，说明支撑指标是有效的先导指标（Toy 中为理想上界；真实系统会因支撑阈值与噪声打折）。

**Toy B：单指标 Goodhart 与反指标配对。**
设 `success(g)=1−e^{−3g}`、`damage(g)=0.1g²`、真实效用 `U=success−2·damage`，`g∈[0,1]` 为激进程度。只用「低力/低激进」单指标，最优是 `g=0`——零进度、零损伤，任务完全失败（`U=0`）。CALIPER 把「低力」与「接触完成/进度≥0.9」配对，得最小可行 `g≈0.77`，`U≈0.782`；无约束真实最优 `g≈0.76`、`U≈0.782`。结论：反指标配对把「不动最安全」的退化解排除，恢复到真实最优点附近；这验证了定义 242/243 与定理 10 的方向（本 Toy 中反指标下限恰好不活跃，故约束解≈无约束解）。

> 说明：以上为机制验证用的小规模合成实验，数值来自固定随机种子；不构成真机证据。真机实验按 E241–E250 执行。

## 8. 已知风险

**一句话**：CALIPER 把「指标合法性」当成近乎免费的假设——一旦反指标覆盖不全、或干预有效性检验只在分布内样本上通过，策略（或对手）就会学会优化仪表盘而非任务，而分层证书会让这种 Goodhart 失效比单一证书**更隐蔽、更自信**；同时 L0 包络本身若标定错误，整套指标层级都无法兜底。

**次级风险与缓解**：
1. **元 Goodhart（指标刷指标）**：有效性检验本身可被「针对检验优化」；缓解：有效性样本与优化样本分离、周期性换用未公开扰动、把 `game` 纳入 `meta_health`。
2. **反指标覆盖不全**：未被配对的活动维度仍是博弈面；缓解：按故障模式清单做覆盖审计，新维度上线前必须绑定反指标。
3. **`T_c` 的 Lipschitz/收缩假设在接触中失效**：冲击、粘滑、软接触是非 Lipschitz；缓解：`T_c` 只用于自由空间/轻触段，重载段由 L0 与 CSC 主导，`T_c` 遇接触即置 0 重估。
4. **L0 单点故障**：硬包络传感器偏置/饱和会直接破坏定理 9；缓解：L0 多通道冗余 + 硬件限位 + 周期自检，L0 失效即 safe-idle。
5. **先导指标误报**：支撑分/块不一致在真实分布漂移下噪声大，导致过度保守；缓解：分视界/分任务校准阈值，误报率纳入预算，允许短时降档而非直接停机。
6. **指标系统组合爆炸**：层次、权重、预算、反指标、元健康引入大量超参；缓解：固定最小可行指标集，权重由有效性/健康度自动给出，超参只离线调、版本化审计。
7. **演示分布随时间漂移**：支撑模型陈旧，`s_sup` 失真；缓解：持续估计演示统计 + 漂移检测 + 周期性 re-grounding（沿用第 65 轮零力窗/标定动作）。
8. **实时成本**：kNN 支撑分与块级指标可能逼近预算；缓解：参数化密度/马氏距离、ROI 降采样、把重计算留在语义流。
9. **元健康度的递归**：`meta_health` 本身也是指标；缓解：在 L0 + 硬件自检处截断递归，元健康只做「降级开关」，不做「安全证明」。
