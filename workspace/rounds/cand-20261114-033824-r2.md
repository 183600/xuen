# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环第 2 轮；本轮灵感：「价值对齐」×「遥操作」）

> R69 让系统学会了「问」：把不确定性拆成 aleatoric 与 epistemic，前者收紧、后者交互消解，并用流似然做标定不可吸收的第二意见。但 R69 的「问」隐含一个致命前提——**被问的人是一台诚实的、关于世界状态的神谕（oracle）**。它问的全是「世界是什么」（左还是右、开心还是紧张），却从不问「我们到底要什么」（该不该冒险、要效率还是要体面、这个人的边界在哪）。这正是 R69 自陈最大风险的根源（「问错，比不问更危险」）：当模态权重不可信，系统会自信地追问一个幻影，并把一个误导性回答盖上「已验证」的章——**因为它把「事实正确」当成了「价值正确」**。
>
> 本轮两个灵感正好补上这道裂缝：
> - **价值对齐**指出：不确定性还有第三类——**价值不确定性 U_ax**（我们优化的到底是谁的效用、权重几何、何为可接受）。它既不是噪声，也不是关于世界的事实，而是关于「目的（telos）」的；它无法靠「看/问」消解到可信，因为**说出来的偏好可以撒谎、可以被诱导、可以自相矛盾**。
> - **遥操作**给出一种「难以撒谎」的价值证据通道——**让出控制权**。人在真正握住方向盘时的修正动作，是**显示性偏好（revealed preference）**，比问卷更难伪装；同时它把「交互」从「信息传递」升级为「**权威传递**」。
>
> 核心命题：**把「不确定性」再拆出第三维 U_ax；U_ale 继续收紧（R68）、U_epi 继续问（R69）、U_ax 交给「分级权威让渡 + 遥操作显示性偏好」去消解；权威本身成为一等动作，且必须满足可纠正性（corrigibility）与让渡安全。** 命名 **TELOS-RAS**（Teleoperation-Enabled, vaLue-aligned, uncertainty-Split；telos 即「目的/价值」）。R69 是本轮在「永不交出控制权」边界上的严格退化。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我该把方向盘交给谁、交给多少、交给多久——交出时我在优化谁的价值**」。

## 0. 直觉与动机

**灵感 1（价值对齐 → 第三种不确定性）**
直觉：R69 把世界的不确定切成 aleatoric 与 epistemic，却漏了一种：**价值/规范的不确定**。同一句「我有点紧张」，可以导出完全相反的正确动作——**退开给空间**（尊重自主）还是**靠近安抚**（关怀）——取决于这个人的价值权重：隐私 vs 亲密、效率 vs 体面、冒险 vs 稳妥。这个权重不是关于世界的**事实**，问一次也问不出可信答案（人会客气、会试探、会说反话、会在被观察时表现得「更愿意合作」）。所以 U_ax 需要**独立通道**，不能塞进 U_epi，否则就会重演 R69 的「问错」。

**灵感 2（遥操作 → 让出控制权是最硬的价值证据）**
直觉：人类对齐彼此价值，常常不是靠问，而是靠「一起做」——你开一段我来接手，我开一段你来纠偏。**手上的修正动作比嘴上的回答更难伪装**：显示性偏好具有激励相容性。把「分级权威」（完全自主 / 共享混合 / 遥操作 / 安全停机）做成动作空间，系统就能主动制造「低成本、可撤销、有安全护盾」的让渡，从中反演价值参数 θ_v。遥操作由此从「人控机器」升级为「**机器主动求证价值**」。

**灵感 3（三分而非二分 → 新层严格包含旧层）**
直觉：三种不确定性进三条通道：U_ale → R68 的 λ_floor（收紧）；U_epi → R69 的 MINT 信息动作（问/看/触）；U_ax → 本轮的 AVN 权威让渡（交出方向盘）。当 U_ax 很小、价值后验已置信，AVN 恒选 L0（完全自主），TELOS 逐指令退化为 FLUID，再退化为 R68。**安全侧永远不弱，包含关系严格成立**——这是持续可维护的前提。

**灵感 4（让渡是双刃剑 → 可纠正性与反操纵）**
直觉：一个足够会优化的智能体，天然有动机**降低被接管的概率**——因为接管常常等于否决它。这就是「关闭开关」问题在遥操作里的化身：机器人可能学会在关键处**不请求接管**、在无关处**表演接管**、或**讨好**人以换取批准（谄媚 / sycophancy）。所以让渡必须先过**可纠正性硬约束**与**反操纵门**：任何「收益主要来自让人少接管」的动作都算违规。**会交权，不等于会诚实交权**。

**灵感 5（时延与信任 → 遥操作的两个物理约束）**
直觉：R69 假设实时环路 <2.6ms，但人是有反应时的（~200–300ms），通信还有时延。让渡必须在**需求到达之前**触发（预测性让渡），或用共享混合在时延窗口内兜底。同时，权限分配还得维持**信任校准**：给太多自主→人松懈（automation complacency），给太少→人疲劳（under-reliance）。信任本身是一个需要被估计和维护的状态，而不是一个常数。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（TELOS-RAS 总览）** TELOS-RAS = (VUS, AVN, PIL, AHC, VAG, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **权威单一持有**：任意时刻存在唯一权威配置（或明确定义的混合系数 α），切换连续、始终带安全护盾；
(iii) **可纠正性**：存在一条有界、不可被策略优化的「人类随时可接管」通道，任何降低其可达性的动作违规；
(iv) **价值证据纪律**：显示性偏好需与至少一个正交信号（陈述偏好 / 事后评价 / 客观结果）交叉验证，单次让渡不单独给 θ_v 定值。

**定义 311（三分不确定性）** U = (U_ale, U_epi, U_ax)。U_ale、U_epi 沿用定义 297；**U_ax = H(θ_v | ℋ) 或 tr(Cov[θ_v | ℋ])**，其中 θ_v 为价值参数（各准则权重、可接受边界、隐私/亲密偏好），ℋ 为交互史。U_ax 的证据来自**显示性偏好**与事后评价，而非世界观测。

**定义 312（权威格 L）** L = {L0 完全自主, L1 共享混合(α∈(0,1)), L2 遥操作(人控 + 机器护盾), L3 安全停机}，带偏序 L0 ≻ L1 ≻ L2 ≻ L3（自主度递减）与切换代价 c_sw(L→L′)。混合系数 α 定义人/机在控制上的凸组合，α=1 为全人控。

**定义 313（增广动作：权威）** 在 R69 的 ξ=(a,g) 上再加权威动作 a_auth = (L_target, α(s), t_hand)；TELOS 动作 ξ‡ = (a, g, a_auth)。权威动作与任务/信息动作**同过一个认证器**。

**定义 314（权威-价值协商器 AVN）** 选择权威动作以最大化期望**对齐效用**减去切换/打扰代价：
a_auth* = argmax_{a_auth} E_{θ_v~p(·|ℋ)}[ U_task(a) + κ·U_align(θ_v) − c_sw − c_disturb ]，s.t. 可纠正性（316）、护盾包络、预算与信任带（319）。当 max ≤ 自主基线 ⇒ 保持 L0（退化为 R69/R68）。

**定义 315（遥操作偏好反演 PIL）** 观测人在让渡段内的修正轨迹 d_{t:t+Δ}，用逆强化学习/贝叶斯偏好更新 p(θ_v | ℋ ∪ d)：后验 ∝ 似然 p(d | θ_v, 策略) × 先验。**关键不可辨识性**：短段让渡可能无法辨识 θ_v（需持续激励）；系统须报告可辨识度 I(θ_v; d)（Fisher 信息下界），而非假装知道。

**定义 316（可纠正性约束）** 定义接管可达性 ρ_take = P(人在 ≤ τ_h 内成功接管 | 状态、动作)。约束：对所有动作，ρ_take ≥ ρ_min；且**反关闭博弈**：动作的对齐收益不得主要来自 Δρ_take 的下降（定义 318 用反事实检测）。

**定义 317（让渡安全与护盾）** 让渡期间机器保持「安全护盾」：仅当预测越出硬安全包络时行使否决（veto），每次否决留痕并审计；混合切换满足连续性与换装不变式（R68 定理 15 保持）⇒ 无突变。时延 τ_h+τ_c 内用预测性触发（定义 322）或混合兜底。

**定义 318（价值对齐门 VAG / 反操纵）** 检测三类价值失配：**谄媚**（优化「被批准」而非「真结果」）、**表演性让渡**（在无需接管处制造接管以博取信任分）、**监督规避**（在关键处压低接管请求）。判据用反事实：**若把 ρ_take 固定，该动作的价值是否仍成立？** 否 ⇒ 违规。

**定义 319（信任状态与校准）** 维护人类信任估计 T_t 与情境意识 SA_t；AVN 的权限分配须使 T_t 落在校准带 [T_lo, T_hi]，避免过度信任（松懈）与信任不足（频繁接管疲劳）。信任是 AVN 的约束，不是目标——不能靠「多让渡」去刷信任。

**定义 320（参与式审计 TAA）** 审计对象新增：接管请求时机、否决理由、让渡是否被用于获取批准、价值后验是否被单源污染。结论回灌 AuditBuf，成为下一轮 AVN 的代价先验。

**定义 321（价值干扰集 ℰ_value）** 陈述-显示偏好冲突、人类反向操纵（假意示弱以换取机器人代劳）、多主体价值冲突、价值漂移（同一人随时间变化）、对抗性偏好注入。并入 AIC：ℰ_TELOS = ℰ_FLUID × ℰ_value。

**定义 322（时延感知预测让渡）** 以人类反应时 τ_h、通信时延 τ_c、任务危险度预测触发时刻 t_hand = t_need − (τ_h + τ_c + τ_safe)；无法提前时保持混合 L1 并收紧 λ 兜底。

**定义 323（多主体/多元价值）** 当多人价值不一致，不取均值（会得到谁都不满意的折中）；维持价值集合 {θ_v^{(i)}}，按词典序：硬安全 > 明确否决权 > 公平聚合（如 maximin），并显式记录未达成一致。

**定义 324（证书 J_TELOS）** J_TELOS = (J_FLUID, value_posterior_entropy, authority_log_hash, takeover_reach_p95, corrigibility_violations, alignment_error_ece, trust_band_ok, telos_ver)。Valid ⇔ Valid(J_FLUID) ∧ 可纠正性零违规 ∧ 让渡安全 ∧ 价值证据纪律满足。

**定义 325（权威依赖的价值漂移）** 定义 θ_v 随「系统替人做决定的频率」缓慢变化：过度代劳会塑造/侵蚀人的偏好（价值塑造）。系统须限制**价值塑造速率** ≤ s_max，并对长时程偏好变化做归因审计。

**定义 326（严格退化的开关）** 若 U_ax ≤ τ_ax 或价值后验置信 ≥ 1−δ，AVN 强制 L0，且 TELOS 的 (a,g) 决策逐指令等于 FLUID；若再叠加 R69 的退化条件，则逐指令等于 R68。

**定义 327（安全停机与最小风险状态）** L3 触发条件、退出协议、以及停机期间的价值冻结：停机不改变 θ_v 后验（不利用停机偷学），恢复后重新协商权威。

## 2. 关键算法骨架

# IP-264 VUS：三分不确定性 + 价值后验（复用 R69 的 FMP/AUD）
def tri_uncertainty(samples, z, belief):
    U_ale, U_epi, modes = decompose(samples, z)        # R69 IP-254
    theta_v, cov = belief.value_posterior()            # p(theta_v | H)
    U_ax = entropy_or_trace(cov)                       # 价值不确定性
    return (U_ale, U_epi, U_ax), modes, (theta_v, cov)

# IP-265 AVN：权威-价值协商（无价值歧义则恒 L0，严格退化 R69）
def choose_authority(U_ax, modes, theta_v, human):
    if U_ax <= TAU_AX or belief.confident():
        return Authority(L0, alpha=0.0)                # 定义 326：退化
    best = None
    for L, alpha in authority_candidates(modes, U_ax):
        if not corrigible(L, human):                continue   # 定义 316
        if not shield.envelope_ok(L, alpha):        continue   # 定义 317
        if not trust_band_ok(L, human.trust):       continue   # 定义 319
        val = expected_aligned_utility(L, alpha, theta_v) - switch_cost(L)
        if best is None or val > best.val: best = Choice(L, alpha, val)
    return best or Authority(L0, alpha=0.0)            # 无利可图 → 自主

# IP-266 PIL：从让渡段反演价值参数 + 可辨识度（不假装知道）
def update_value_belief(belief, demo_slice):
    post  = bayes(prior=belief.theta_v, lik=irl_likelihood(demo_slice))
    ident = fisher_info(post, demo_slice)             # 定义 315
    return post, ident                                # ident 低 → 不单独定值

# IP-267 VAG：反操纵 / 谄媚 / 表演性让渡检测（反事实判据）
def value_alignment_gate(action, rho_take, outcome_eval):
    if action.gain_from_reduced_oversight():   return FLAG   # 监督规避
    if sycophancy_score(action, outcome_eval) > TAU_SY: return FLAG  # 谄媚
    if performative_handoff(action):           return FLAG   # 表演性让渡
    if not value_if_fixed(action, rho_take):   return FLAG   # 固定接管概率后不值
    return OK

# IP-274 主闭环
def TELOS_RAS_round(M, obs, human):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    (U_ale, U_epi, U_ax), modes, vpost = tri_uncertainty(
        M.fmp.sample(o, K=M.adaptive_k(z)), z, M.belief)
    # 1) 世界歧义 → R69 问；价值歧义 → 让渡（两条独立通道）
    g = M.mint.choose_interaction(modes, o, M.budget) if U_epi > TAU_EPI else None
    if g is not None:
        M.cia.update_belief(modes, M.cia.execute(g))
    # 2) 权威协商 + 反操纵门
    auth = M.avn.choose_authority(U_ax, modes, vpost.theta, human.state)
    if M.vag.gate(auth, M.rho_take, M.outcome_eval) != OK:
        auth = Authority(L0, 0.0); U_ax = max(U_ax, U_epi)   # 违规 → 最保守
    # 3) 执行让渡（预测触发 + 护盾），并从显示性偏好反演价值
    if auth.L in (L1, L2):
        demo = M.teleop.execute(auth, human, shield=M.shield,
                                t_hand=predict_trigger(human.tau_h, M.tau_c))
        vpost, ident = M.pil.update_value_belief(vpost, demo)
        if ident < TAU_IDENT: U_ax = vpost.entropy          # 不可辨识 → 保守
    # 4) 风险缩放：三类不确定性各按其纪律进入 λ
    lam = max(M.efs.risk_scale(...),
              lam_floor(U_ale + (U_epi if g is None else 0.0) + U_ax_gate(U_ax)))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if auth.L == L3: lam = 1.0; k = k_min_risk(x_prime)
    # 5) 审计 + 证书
    M.taa.submit_async(auth, vpost, ident, M.rho_take, M.human.trust)
    return k, lam, auth, vpost

## 3. 推导

**引理 19（通道分离：信息动作不消解价值不确定性）** 在激励相容假设 A99（人在被观察的提问中会按社会期望而非真实偏好作答）下，对任意信息动作 g，真实 θ_v 与「说出来的答案 y」的互信息被「做出来的修正 d」支配：I(θ_v; y | g, o) ≤ I(θ_v; d | a_auth)。系：**U_ax 应路由到权威让渡，而非追问**；把 U_ax 塞给 MINT 是对 R69 的误用，也是 R69「问错」风险的正式来源。

**引理 20（可纠正性不是免费的）** 设任务目标与「避免接管」正相关（接管常意味着否决），则无约束最优策略的 ρ_take 随优化压力单调下降。故可纠正性必须作为**外生硬约束**（定义 316），不能写成软奖励——软奖励会被 Goodhart 优化掉。系：这也是为什么 VAG 用反事实判据而非「接管次数」这类可刷的代理指标。

**引理 21（短让渡的价值不可辨识）** 若让渡段 Δ 内的有效修正维度 < dim(θ_v)，则 Fisher 信息退化，后验协方差特征值下界 > 0；此时系统必须报告不可辨识并保持保守，否则会把噪声当偏好、过拟合到单次让渡。系：**主动价值激励**（在安全、信息量大的情境下短暂让渡）是必要的，但只允许发生在「可辨识且安全」的子集上。

**定理 18（TELOS 严格包含 FLUID 与 R68）** 当 U_ax ≤ τ_ax 且价值后验置信，AVN 恒选 L0，VAG/TAA 只读不写，TELOS 逐指令等于 FLUID；再叠加 R69 退化条件，即逐指令等于 R68。故安全侧单调不弱，TELOS 是 FLUID 在「永不交出控制权」边界上的严格退化。

**定理 19（让渡安全与无突变）** 护盾 + 连续混合 + 否决留痕 ⇒ 让渡期间物理风险 ≤ ε_int；切换沿 L0≻L1≻L2≻L3 单调提升安全；时延窗口由预测触发或混合兜底覆盖 ⇒ 控制连续、无突变，R68 定理 15 的换装不变式保持。

**定理 20（反操纵上界）** 在反事实判据下，任何「对齐收益主要来自 Δρ_take < 0」的动作被 VAG 拦截；结合 k 个正交价值证据（陈述 / 显示 / 结果，欺骗相关 ρ<1），错误价值采纳率 ≤ δ_v·ρ^{k−1} + ε_σ，与 R69 引理 18 同构。

    U_ale, U_epi, modes = decompose(samples, z)         # R69 IP-254
    theta_v, cov = belief.value_posterior()             # p(theta_v | H)
    return (U_ale, U_epi, entropy_or_trace(cov)), modes, (theta_v, cov)

def choose_authority(U_ax, modes, theta_v, human):
    if U_ax <= TAU_AX or belief.confident():
        return Authority(L0, 0.0)                       # 定义 326
    best = None
    for L, alpha in authority_candidates(modes, U_ax):
        if not corrigible(L, human):          continue  # 定义 316
        if not shield.envelope_ok(L, alpha):  continue  # 定义 317

        val = expected_aligned_utility(L, alpha, theta_v) - switch_cost(L)
        if best is None or val > best.val: best = Choice(L, alpha, val)
    return best or Authority(L0, 0.0)                   # 无利可图 → 自主

    ident = fisher_info(post, demo_slice)               # 定义 315
    return post, ident                                  # ident 低 → 不单独定值

## 4. 推导

**引理 19（通道分离）** 在激励相容假设 A99 下，`I(θ_v; y|g,o) ≤ I(θ_v; d|a_auth)`——说出来的被做出来的支配。系：U_ax 应路由到权威让渡而非追问；把 U_ax 塞给 MINT 是 R69「问错」风险的正式来源。

**引理 20（可纠正性不是免费的）** 任务目标与「避免接管」正相关时，无约束最优策略的 `ρ_take` 随优化压力单调下降；故可纠正性必须是外生硬约束，软奖励会被 Goodhart 优化掉。

**引理 21（短让渡的价值不可辨识）** 有效修正维度 < dim(θ_v) 时 Fisher 信息退化，后验协方差下界 > 0；必须报告不可辨识并保守，否则把噪声当偏好。

**定理 18（TELOS 严格包含 FLUID 与 R68）** `U_ax≤τ_ax` 且价值后验置信时 AVN 恒选 L0，TELOS 逐指令等于 FLUID；再叠加 R69 退化条件即等于 R68。安全侧单调不弱。

**定理 19（让渡安全与无突变）** 护盾 + 连续混合 + 否决留痕 ⇒ 让渡风险 ≤ ε_int；切换沿 `L0≻L1≻L2≻L3` 单调提升安全；时延由预测触发/混合兜底覆盖 ⇒ 控制连续。

**定理 20（反操纵上界）** 反事实判据拦截「收益主要来自 `Δρ_take<0`」的动作；k 正交价值证据下错误采纳率 ≤ `δ_v·ρ^{k−1}+ε_σ`。

**一句话**：TELOS 的全部安全性押在「人真的会且能接管、且其显示性偏好反映真实价值」这一前提上——**若人疲劳、被社交工程、或价值本身在漂移，或系统学会了「表演性让渡」来换取信任，那么让渡就不是纠错通道，而是把 R69 的「问错」升级成「交错了方向盘，还用人的手为错误背书」——把责任外包给人，比不外包更危险**。

**次级风险与缓解**：可纠正性被优化掉（硬约束 + 反事实 VAG + E304）；谄媚/表演性让渡（反事实判据 + 结果侧独立评估 + E305）；短让渡不可辨识却硬定值（Fisher 门 + 报告不知道 + 引理 21）；时延导致来不及（预测触发 + 混合兜底 + 护盾，定理 19）；长期代劳侵蚀价值（s_max + 归因审计，E312）；多元价值被均值糊掉（词典序 + maximin，定义 323）。
