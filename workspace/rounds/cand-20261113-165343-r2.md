# 第 66 轮（承接第 65 轮「VISTA 故障可归因安全时序闭环」IP-214~223；灵感循环第 3 轮；本轮灵感：「避障控制」×「伦理与合规」）

> 第 65 轮用视觉与动作分块把「几何可证伪」升级为「故障可归因」，其自述的最大风险是：**VISTA 依赖「故障属于有限假设集、且视觉与几何失效相互独立」；真实故障常是未知类型的组合，共因失效会让 FIR 强行归入最近假设、只膨胀错误的球，系统还因「已经归因」更自信地继续执行（A88）。** 更根本的是，VISTA 的全部论证只覆盖「接触时刻的物理伤害」——它回答「哪一层坏了、该膨胀哪个球」，却没有回答一个伦理与合规上更前置的问题：**有些事根本不允许做，无论它多安全、归因多确定；而且「做了没伤人」不等于「做了是合规的、可辩护的」。** 本轮不再增加第七个故障假设，而是换一个提问方式：
>
> **把「接触安全」升级为「合法且可辩护」：用避障控制的前向不变性把「禁止」写成可计算的屏障证书，用最小干预安全滤波器在硬规范内做比例性修正；用伦理与合规的分层规范、来源可追溯、可异议结构，把「没出事」升级为「有证据、可审计、可推翻」；并诚实承认：可形式化的只是规范的字面，字面之外的「精神」必须交还人类监督与异议程序，而不是塞进一个更自信的证书。**

## 0. 直觉与动机

**灵感 1（避障控制 → 「不做某事」有严格的数学语言）**
直觉：VISTA 处理的是「做错了、碰到了怎么办」；避障控制的出发点相反——**首要目标是不进入某个集合**。经典人工势场法直观，但会在局部极小值卡死、对动态障碍无保证；控制屏障函数（CBF）与安全滤波器给出严格版本：给定期望动作 u_nom，求离它最近的可行动作 u*，使 h(x) 满足 ḣ+αh≥0，则安全集 {h≥0} 前向不变。两件事对本文至关重要：(i) **禁止可以被写成硬约束**，而不是高代价软惩罚（软惩罚会在"收益够大"时被交易掉）；(ii) **最小干预 = 法律上的比例原则/最小限制手段**——只在必要时偏离名义策略，且偏离最小。避障控制因此不是"另一个模块"，而是把伦理的"不得"翻译成控制器的语言。

**灵感 2（伦理与合规 → 规范不是概率，而是证明义务 + 证据 + 追溯 + 异议）**
直觉：安全证书说「越界概率 ≤ α」；合规说的是另一套东西：**这条规范来自哪条法规/标准/政策？它被形式化成哪条约束？运行时哪条证据表明它没被违反？谁有权在什么范围内、多长时间内批准例外？被影响者如何质询并推翻这个决定？** 规范有层级：硬规范（禁止伤人、禁止进入禁区、力/速度上限、无有效证书不得动作）不可交易，软规范（效率、最小力、社交距离）才可权衡；且硬规范优先（词典序），不能拿"总体收益更大"去换一次伤害。伦理还有**开放纹理**：真实规范无法被有限形式化穷尽，字面合规可能违背精神。因此证书必须显式记录「未被形式化的残余」，并把最终裁量交还人类，而不是假装完备。

**灵感 3（三灵感合流 → NOMOS）**
闭环：规范接入与形式化（NR）→ 规范屏障合成（NBF）→ 故障后验下的鲁棒裕度（ROB-CBF，复用 VISTA 的 r_geo/r_force/r_model）→ 最小干预安全滤波（LEX-QP）→ 不可行时给出极小不可满足子集并升级（CIS/MUS）→ 可行核内规划（VIK）→ 来源 DAG 与证据包（NPROV）→ 范围化豁免与可异议（CONTEST）→ 对抗合规认证（AIC-N）→ 运行时监控与 hold → J_nomos。NOMOS = **N**orm-grounded **O**bstacle avoidance with **M**oral-**O**perational **S**afety（规范接地的避障-伦理合规安全闭环）。

**灵感 4（与 VISTA 的原位关系：不是替换，而是补上安全的"负空间"）**
- VISTA 的不确定球不再只膨胀搜索域，还直接成为屏障的鲁棒裕度：r_geo→障碍/工作空间裕度，r_force→力/接触屏障裕度，r_model→接触模型不确定项；归因后验越分散，有效屏障 h̃ = h − β(post) 越收缩。
- FIR 的后验支持集进入鲁棒 CBF 的最坏情形；归因模糊时不是"更自信地执行"，而是"屏障更保守、可行核更小、更早 hold"。
- CSC 的认证前缀再叠一条硬规范前缀：k_eff ≤ min(k*, k_norm)，k_norm 由屏障裕度与停止距离反解。
- CSP-V 的块边必须落在可行核 VIK 内；目标在核外则声明「规范下不可达」，而不是越界后再补救。
- AIC-V 的干扰集扩为 ℰ_N，新增规范博弈（字面合规/精神违背）、假人类、伪造溯源、伪造豁免。
- J_vista→J_nomos：新增 hard_norm_sat、mus、feasibility_margin、provenance_hash、waiver、oversight_state、explanation_digest、unformalized_residue。

**灵感 5（最关键的张力：合规不是安全的上界，而是安全的"负空间"，也可能是它的"洗白"）**
直觉：一个动作可以既安全又违规（未授权进入某区域但没撞到任何东西），也可以既合规又危险（满足所有形式条款却违背其意图）。**"已认证"绝不等于"已正当化"**。如果系统把开放纹理的伦理压成几个可微约束，再用一个漂亮的证书宣告"合规"，它得到的可能不是伦理，而是**合规洗白（compliance washing）**：把有争议的价值判断洗成中立的数学事实，并让本应负责的人躲到证书后面。NOMOS 的设计必须把这一点写进证书本身：显式标注未被覆盖的规范、保留人类监督与异议通道、把两难与道德残余记录在案，绝不静默优化掉。

## 2. 关键算法骨架

```python
# LEX-QP：最小干预规范安全滤波（实时，小规模）
def lex_qp(u_nom, x, barriers, post, w_vis=1.0):
    # barriers: 已按硬/软、相对阶排序；h_tilde 已含故障后验裕度（语义流预编译）
    cons = []
    for phi in barriers.hard:
        h, Lf, Lg, alpha = phi.eval(x, post)          # h_tilde = h - beta(post)
        cons.append(Lf + Lg @ u + alpha * h >= 0)      # 相对阶 1；m>1 用 HOCBF 链
    prob = qp(minimize=quad_form(u - u_nom), constraints=cons + barriers.ctrl_bounds)
    u = prob.solve()
    if prob.status != 'optimal':
        M = mus(barriers.hard, x, post)                # 语义流预计算 + 现场收缩
        return None, M                                 # 两难：HOLD + 升级
    # 软规范只在硬可行域内部做词典序优化
    u = soft_tiebreak(u, barriers.soft, x)
    return u, None

# CIS/MUS：不可行时给出极小不可满足子集（语义流）
def mus(hard_norms, x, post):
    H = list(hard_norms)
    for phi in list(H):                                # 贪心删除，O(|Φ_H|) 次 QP
        H2 = [p for p in H if p is not phi]
        if not feasible(H2, x, post):
            H = H2                                     # phi 非必需，删
    return H                                           # 剩余即极小不可满足子集

# NPROV：规范来源 → 屏障 → 证据包（语义流，写一次）
def build_bundle(norm, barrier, monitor, test):
    node = {'clause': norm.prov.clause, 'interp': norm.prov.interp,
            'barrier': barrier.id, 'monitor': monitor.id, 'test': test.id}
    bundle = {**node, 'norm_id': norm.id, 'ver': norm.ver, 'juris': norm.juris,
              'hash': sha256(canon(node))}
    bundle['hash_chain'] = sha256(prev_hash + bundle['hash'])  # 防篡改链
    return bundle

# NOMOS 主循环（实时路径只做求值与 hold）
def nomos_step(M, obs, u_nom):
    x = M.lsf.state(obs)
    post = M.fir.last_posterior                             # VISTA 语义流给出
    # 1) 语义流：归因不确定 → 收缩有效屏障（保守，不允许更自信）
    M.barriers.update_robust_margin(post, M.balls, M.w_vis)
    # 2) 实时：评估硬屏障，解 LEX-QP
    u, M_dilemma = lex_qp(u_nom, x, M.barriers, post)
    if M_dilemma:
        M.vik.shrink_to(M_dilemma)                          # 可行核收缩
        return HOLD, J_nomos(M, dilemma=M_dilemma)           # 升级人类
    # 3) 硬规范前缀：k_eff ≤ min(k*, k_norm)
    k_norm = certified_norm_prefix(M.barriers, x, M.m, M.dt)
    # 4) 运行时监控 + 证书
    cert = build_j_nomos(M, hard_norm_sat=M.barriers.all_satisfied(x), k_norm=k_norm)
    return u, cert
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（硬规范前向不变性）**：若 h̃ 满足鲁棒 CBF 条件且初始 x_0∈C_H，则任意容许控制下轨迹对所有 t 保持 h̃(ξ(t))≥0；离散步长用 h(x_{k+1})≥(1−α)h(x_k), α∈(0,1)。故**已形式化的硬规范在模型/扰动界内永不被违反**，且该保证与"是否发生接触故障"解耦。
- **引理 10（最小干预/比例性）**：LEX-QP 是 u_nom 到可行凸集的加权投影；u_nom 可行时解为 u_nom（恒等性），否则在可行集中唯一最小偏离。故系统不施加超出必要的限制，符合"最小限制手段"。
- **引理 11（两难的可证性）**：若硬约束 QP 不可行且数值裕度超过容差，则当前状态/采样下不存在同时满足 Φ_H 的容许动作；MUS M 极小 ⇒ 移除 M 中任一条都恢复可行。故系统能**证明**两难，而不是把它优化掉或悄悄违反一条。
- **定理 9（NOMOS 端到端合法-安全）**：在 A95–A99 下，Valid(J_nomos) ⇒ (i) 已形式化硬规范在故障后验与扰动界内前向不变；(ii) 软权衡仅在硬可行域内且词典序正确；(iii) 每个动作可由溯源 DAG 复现其规范依据；(iv) 例外仅在有效范围化豁免下成立；(v) 两难必 HOLD 并升级。即从"没出事"升级为"**有证据地没违规，且违规不可能被证书掩盖**"。
- **定理 10（鲁棒-保守权衡）**：β(post) 关于归因熵单调不减，C_H(post) 单调收缩；存在临界裕度 r_crit 使唯一不变动作为 HOLD。故"归因越不确定 ⇒ 越保守"，绝不会因归因而放宽硬规范。

## 2. 形式化定义（完整版）

**定义 233（NOMOS 闭环）** NOMOS 是 VISTA 的"合法可辩护"升级：在 VISTA 的"语义流 ∘ 实时流"骨架上挂载 NR（规范接入）、NBF（规范屏障）、ROB-CBF（故障鲁棒屏障）、LEX-QP（最小干预滤波）、CIS/MUS（两难证明）、VIK（可行核）、NPROV（来源审计）、CONTEST（豁免与异议）、AIC-N（对抗合规），并原位升级 RSC-V→ROB-CBF、CSC→硬规范前缀、CSP-V→VIK、AIC-V→AIC-N、J_vista→J_nomos。不变式：**规范形式化、屏障合成、MUS 求解、来源审计、豁免签发只在语义流与低频线程；实时路径只做屏障求值、小型 QP、单调监控、HOLD 与派发，零学习写操作。**

**定义 234（规范系统与道义算子）** 规范系统 Φ=Φ_H ⊔ Φ_S ⊔ Φ_?。每条规范 φ=(id, type, scope, pred, prov, ver, juris)：pred 是轨迹谓词（如 `d(robot,human)≥d_min`、`f_n≤f_lim`、`x∉zone_forbidden`、`cert_valid`），prov 指向法规/标准/政策条款，ver 为版本，juris 为管辖区。道义算子 F（禁止）/O（义务）/P（允许）。**硬规范词典序优先**：∀软收益 Δ，不得补偿一次硬违反；软规范只在硬可行域内优化。轨迹 ξ 满足硬 φ ⇔ ∀t, g_φ(ξ(t))≥0。Φ_? 是**未形式化残余**（开放纹理、尚未编码或存在争议的规范），它必须被登记进证书，默认"未被承诺"，而非"不存在"。

**定义 235（规范安全集与规范屏障函数 NBF）** C_φ={x:g_φ(x)≥0}。取光滑 h_φ 使 C_φ={h_φ≥0} 且 ∇h_φ≠0 于边界。若存在 class-K∞ α 使
sup_u [L_f h_φ(x)+L_g h_φ(x)u+α(h_φ(x))] ≥ 0, ∀x∈∂C_φ，
则 h_φ 是规范屏障函数。对相对阶 m>1 的约束（力、加速度、分离加速度）用 HOCBF：定义 ψ_0=h_φ，ψ_i=ψ̇_{i−1}+α_i(ψ_{i−1})，要求 ψ_{m−1}≥0。多硬规范取交：C_H=∩_{φ∈Φ_H}C_φ，合成屏障 h_H=min_{φ∈Φ_H}h_φ（min 保持前向不变性的保守充分条件）。

**定义 236（故障后验下的鲁棒 NBF）** 给定 VISTA 的归因后验 post、不确定球 (r_geo,r_force,r_model) 与扰动界 W，定义
h̃_φ(x;post)=h_φ(x)−β_φ(post)，
β_φ(post)=L_h(r_geo+r_model)+b_force(post)+L_h·v_max·Δt_stop，
其中 L_h 为屏障 Lipschitz 常数，b_force(post)=Σ_H P(H|post)·b_H 为最坏偏置。鲁棒约束要求
∀θ∈supp_δ(post), ∀w∈W: L_f h̃+L_g h̃·u+L_w h̃·w+α(h̃) ≥ 0。
**单调性要求**：post 越分散（熵越高）⇒ β 越大 ⇒ C_H 越小；归因只能把系统推向更保守，不能推向更自信。

**定义 237（LEX-QP 最小干预规范滤波器）** 给定名义动作 u_nom（来自 VISTA/GRIP 块前缀），
u* = argmin_{u∈U} ‖u−u_nom‖²_M + λ_s Σ_{φ∈Φ_S} c_φ(u)
s.t. ∀φ∈Φ_H: 鲁棒 NBF 约束成立。
性质：(i) **恒等性**：u_nom∈K(x) ⇒ u*=u_nom；(ii) **最小偏离**：否则 u* 是 u_nom 到 K(x) 的 M-加权投影；(iii) **词典序**：软代价的改善不得以任何硬约束松弛为代价。该构造把"最小限制手段 / 比例原则"落到控制层：只在必要时、只做最小必要修正。

**定义 238（合规可行性、两难与 MUS）** 可行集 K(x)={u∈U: 全部硬约束成立}。若 K(x)=∅，系统处于**规范两难**。求极小不可满足子集 M⊆Φ_H：
Φ_H\M 可行，且 ∀M'⊊M, Φ_H\M' 不可行。
输出 `dilemma(M)`，进入 HOLD + 人类升级，并记录 M 的每条规范与来源。注意 MUS 的可靠性是**相对于当前已形式化规范、当前状态与数值容差**的局部结论；它不证明"世界上真的无法两全"，只证明"在系统被告知的规则内无法两全"。

**定义 239（规范溯源 DAG 与合规证据包）** 溯源 DAG 节点 n=(clause_ref, interpretation, barrier_id, monitor_id, test_id, cert_hash)，边表示"条款→解释→屏障→监控/测试→证书"的推导关系。合规证据包
B={norm_id, clause_ref, barrier_id, monitor_id, test_evidence, norm_set_version, signer, hash_chain}，
其中 hash_chain_i=H(hash_chain_{i−1}‖hash(n_i)) 为防篡改链。每条硬规范必须具备**三件套**：屏障（可证明不变）、运行时监控（可检测越界）、通过测试（可复现证据）；缺一即视该规范"未被有效认证"。条款映射示例（按标准/法规的章节级语义）：ISO 10218-1 安全相关控制系统、ISO/TS 15066 速度-分离监控与功率/力限制、ISO 13482 个人护理机器人安全、EU AI Act 高风险系统的风险管理/透明度/人类监督/鲁棒性、GDPR 的数据最小化与目的限制。

**定义 240（速度-分离监控与社会/动态障碍屏障）** 人类感知给出相对距离 d 与相对速度 v_rel。定义
h_ssm = d − (v_rel·T_react + d_stop + d_social),
对应 ISO/TS 15066 的速度-分离监控（SSM）；d_social 为个人空间（软规范时作为软屏障，硬规范时可取最小安全间距）。对动态人类，取速度上界内的对抗最坏情形 v_rel^max，必要时用互惠避让。SSM 是"避障控制"与"合规"的天然接缝：它既是几何避障，也是可引用的合规条款。

**定义 241（可行核与合规感知规划 VIK）** 可行核 V 为硬规范下的最大受控不变集：
V = νZ.{x∈C_H : ∃u∈U, x'=f(x,u), x'∈Z, 硬约束成立}（最大不动点）。
VISTA 的 CSP-V 块规划只在 V 内取块边；每条块边还需 Valid(J_nomos) 且 k_eff≥1。若目标 x_g∉V，输出 `goal_infeasible_under_norms`，提议替代目标或请求人类裁量——**不允许"先越界、后解释"**。

**定义 242（范围化豁免与可异议）** 豁免 w=(id, norm_ids, scope_region/action, time_window, authorizer, justification, signature)。语义：
- 只放宽**指定**硬规范，且仅在 scope∩time 内；
- 必须由具名人类签发（不可由策略自签）；
- 到期强制重新验证；越界、过期、越权或签名无效即整体失效；
- 每次使用豁免都写入 J_nomos 与证据包。
**可异议**：任何受影响方或审计者可查询"为何执行 a"；系统返回解释 E(a)=(最小活跃硬约束集, 对偶乘子, 规范溯源路径, 被交易掉的软规范)。异议可触发重新归因、重新规划或人工接管；异议记录进入道德残余 R。

**定义 243（对抗合规与规范博弈 AIC-N）** 干扰集 ℰ_N=ℰ_V×ℰ_norm：ℰ_V 沿用 VISTA 的视觉/力/模型/时序故障；ℰ_norm 新增
(i) **规范博弈**：策略满足字面 Φ_H 却违背**留出规范** Φ^ho（Goodhart/奖励黑客）；
(ii) **假人类/对抗人类**：利用 SSM 迟滞制造死锁或诱导急停；
(iii) **屏障失效欺骗**：传感器欺骗使 d 被高估；
(iv) **伪造溯源/伪造豁免**：篡改证据包或伪造签名。
认证在 ℰ_N 上重算 ρ_norm（n_cert 128→160，其中 32 给规范博弈与伪造），并同时报告**字面合规率**与**精神合规率**（后者只在 Φ^ho 上评估，绝不参与优化）。证书只承诺已声明的 Φ_H，**明确不承诺未声明的精神**。

**定义 244（NOMOS 证书 J_nomos）**
J_nomos=(J_vista, hard_norm_sat, mus, feasibility_margin, provenance_hash, waiver, oversight_state, norm_set_version, explanation_digest, unformalized_residue, aic_n_ver)。
验证规则：
Valid(J_nomos) ⇔
  Valid(J_vista)
  ∧ ∀φ∈Φ_H：h̃_φ 在 supp_δ(post) 与 W 上满足鲁棒 NBF 条件
  ∧ (K(x)≠∅ ∨ 已判 `dilemma(M)` 且 HOLD/升级)
  ∧ 证据包哈希链可验证且每条硬规范具备"屏障+监控+测试"三件套
  ∧ (存在例外 ⇒ 豁免在 scope/time/权限内有效)
  ∧ oversight_state∈{monitoring, authorized}
  ∧ norm_set_version 为当前版本
  ∧ unformalized_residue 已登记并进入解释。
审计链新增：为何允许此动作（活跃硬约束）、为何拒绝此动作（MUS/不可行）、依据哪条条款（溯源）、谁批准了例外（豁免）、系统自认不知道什么（残余）。

**定义 245（NOMOS 闭环算子）** 语义流：[规范接入 NR→NBF 合成→ROB-CBF 裕度→VIK 计算→NPROV 证据包→CSP-V 规划→LEX-QP 预解→J_nomos]；实时流：[读屏障表→求值 h/h̃→LEX-QP→单调监控→HOLD/派发→证书摘要]。规范形式化、MUS、审计、豁免、规划全在语义流；实时路径零学习写操作。

**定义 246（解释与道德残余）** 解释 E(a)=(最小活跃硬约束集 A*(a), 对偶乘子 λ*, 规范溯源路径, 被交易掉的软规范)。最小性：移除 A*(a) 中任一约束，LEX-QP 的最优解改变（即该约束确实决定了本动作）。道德残余
R = Φ_? ∪ (本轮为满足硬规范而牺牲的软规范) ∪ (两难时 M 的全部成员) ∪ (被拒绝的豁免/异议记录)。
**certified ≠ justified**：J_nomos 只证明"未违反已形式化规范"；R 必须随证据包保存、可被审计与异议，不得因证书有效而删除或归零。

### IP-225 LEX-QP（最小干预规范滤波）

```python
class LexQP:
    """硬规范词典序优先；u_nom 可行则恒等；否则最小偏离。实时流，小规模 QP。"""
    def __init__(self, M_weight, soft_cost, tol=1e-6, max_hard=6):
        self.M, self.soft, self.tol, self.max_hard = M_weight, soft_cost, tol, max_hard

    def solve(self, u_nom, x, barriers, post):
        # barriers.hard 已按优先级排序；h_tilde 由语义流按 post 预编译
        cons, rows = [], []
        for phi in barriers.hard[:self.max_hard]:
            h, Lf, Lg, alpha = phi.eval_robust(x, post)   # h_tilde = h - beta(post)
            cons.append(Lf + Lg @ sym('u') + alpha * h >= 0)
            rows.append(phi.id)
        prob = QP(obj=quad_form(sym('u') - u_nom, self.M),
                  constraints=cons + barriers.ctrl_bounds)
        u = prob.solve()
        if prob.status == 'optimal':
            u = self._soft_tiebreak(u, x, barriers, post)   # 只在硬可行域内
            return u, None, self._margin(prob)
        # 数值不可行：先用容差确认，再求 MUS（CIS）
        M = self._mus(barriers.hard, x, post)
        return None, M, -np.inf

    def _soft_tiebreak(self, u, x, barriers, post):
        for phi in barriers.soft:                          # 词典序次级优化
            u = project_soft(u, phi, x, post, self.tol)
        return u

    def _mus(self, hard, x, post):
        # 语义流可预计算 MUS 模板；现场做贪心收缩以获得当前状态下的极小集
        H = list(hard)
        for phi in list(H):
            H2 = [p for p in H if p is not phi]
            if not feasible(H2, x, post, self.tol):
                H = H2
        return H
```

### IP-228 ROB-CBF（故障后验 → 屏障裕度）

```python
def robust_margin(post, balls, barriers, v_max, dt_stop, delta=0.05):
    beta = {}
    support = {h: p for h, p in post.items() if p >= delta}
    for phi in barriers:
        r = math.sqrt(balls['r_geo']**2 + balls['r_model']**2)
        b_force = sum(p * bias_bound[h] for h, p in support.items())   # 最坏偏置
        beta[phi.id] = (phi.L_h * (r + v_max * dt_stop) + b_force)
        phi.h_tilde = phi.h - beta[phi.id]                              # 只会更保守
    return beta
```

## 4. 推导

**引理 9（硬规范前向不变性）** 设 h̃_φ 在 x_0∈C_H 上满足鲁棒 CBF 条件，控制 u 满足 LEX-QP 的全部硬约束。由 CBF 标准结论（连续时间 Nagumo/比较引理；离散时间取 h(x_{k+1})≥(1−α)h(x_k), α∈(0,1)），对任意 t≥0 有 h̃_φ(ξ(t))≥0；由 h̃=h−β 得 h_φ(ξ(t))≥β≥0，故 ξ(t)∈C_φ。对所有 φ∈Φ_H 取交，ξ(t)∈C_H。扰动 w∈W 与故障参数 θ∈supp_δ(post) 已进入 h̃，故不变性在该不确定集上一致成立。相对阶 m>1 时 HOCBF 链把同一论证逐阶抬升，结论不变。∎

**引理 10（最小干预/比例性）** K(x) 为硬约束定义的闭凸集（CBF 约束对 u 仿射，控制界凸）。若 u_nom∈K(x)，则目标函数在 u=u_nom 取全局最小 0，故 u*=u_nom。若 u_nom∉K(x)，M-加权欧氏投影到闭凸集存在唯一，且是所有可行点中到 u_nom 的 M-距离最小者；软代价项只在硬可行域内部优化，故不改变硬约束满足性。因此干预是"必要且最小"的，符合最小限制手段。∎

**引理 11（两难的可证性）** 若硬约束 QP 在容差 ε 外不可行，则不存在 u∈U 同时满足全部 φ∈Φ_H（相对于已形式化谓词、当前状态与数值模型）。MUS 的贪心构造：从 Φ_H 出发，逐条删除后仍不可行者保留、可行者删去；结束时剩余集合仍不可行且任一真子集可行，故极小。注意这是局部、语法层的证明：它不排除"重新解释/新增规范/改变状态"后恢复可行。∎

**定理 9（NOMOS 端到端合法-安全）** 在 A95–A99 下：
1. **硬规范不可交易**：由引理 9，任意 valid 证书下的执行保持 C_H；软权衡由 LEX-QP 限制在可行域内且词典序正确（定义 237）。
2. **不确定性只增保守**：β(post) 关于归因熵单调不减，h̃ 单调收缩（定义 236）；故 VISTA 的归因模糊不会放宽硬规范，反而缩小可行核、提前 HOLD。
3. **两难不静默**：不可行时由引理 11 给出 MUS 并 HOLD/升级；不存在"优化掉某条硬规范"的执行路径（定义 238/244）。
4. **可审计**：每个动作的活跃约束、对偶、条款来源可由溯源 DAG 复现（定义 239/246）；证据包防篡改。
5. **例外受控**：任何硬规范放宽必须来自有效范围化豁免；过期/越权/伪造即证书失效（定义 242/244）。
6. **诚实留白**：Φ_? 与道德残余显式进入证书与解释（定义 246），系统不宣称"已正当化"。
故 Valid(J_nomos) ⇒ "有证据地未违反已形式化硬规范，且违规不能借证书掩盖"。∎

**定理 10（鲁棒-保守权衡）** 设 post 的熵 H(post) 增加。β_φ(post)=L_h(r_geo+r_model)+b_force(post)+L_h v_max Δt_stop 中的 b_force 为按 post 加权的最坏偏置，随支持集扩张单调不减；故 β 不减、C_H(post)={h≥β} 单调收缩、可行核 V(post) 单调收缩。存在临界 β_crit（由停止距离与最小安全间距决定）使 K(x)=∅，此时唯一合法动作是 HOLD。于是"归因越不确定 ⇒ 越保守"，且保守不会破坏合法性（引理 9 对任意 β≥0 成立）。∎

**命题（字面-精神鸿沟）** 对任何有限形式化规范集 Φ_H，只要存在至少一条未形式化规范 φ∈Φ_?（或留出规范 φ∈Φ^ho），就能构造轨迹 ξ 使 ∀φ'∈Φ_H, g_{φ'}(ξ)≥0 而 g_φ(ξ)<0。因此"满足 Φ_H"不蕴含"伦理正当"。该命题不是缺陷补丁，而是对证书语义的界定：J_nomos 的适用范围只能是已声明的 Φ_H；把"未声明"当成"允许"正是合规洗白的定义。故 CONTEST 与人类监督是证书语义的必要组成，而非可选功能。∎

## 7. 已知风险

**一句话**：NOMOS 的全部保证都条件于「硬规范被正确、完备地形式化」；但伦理与合规天生是开放纹理的，把有争议的价值判断压成几条可微屏障，会制造一种危险的**合规洗白**——系统可能完美满足字面规范却系统性违背其精神，而 Valid(J_nomos) 又恰好给了它继续执行的正当性外衣，最终把本应由人和制度承担的裁量与责任，悄悄转移给一个只会证明"我没违反我被告知的规则"的证书。

**次级风险与缓解**：
1. **开放纹理/未形式化规范**：任何有限 Φ_H 都有 Φ_?；不能承诺"合规即正当"。缓解：显式登记残余、留出规范 Φ^ho 只用于评估、人类监督与异议为证书必要组件；绝不把"未声明"当"允许"。
2. **合规洗白 / 责任转移**：证书可能被用来为有争议决策背书。缓解：J_nomos 明确标注适用范围与残余；解释必须给出活跃约束与条款；保留具名人类 authorizer 与异议记录；外部审计可复核。
3. **MUS 只是局部语法证明**：它证明"在已形式化规则与当前状态下无解"，不证明"世界上无解"。缓解：证书标注 `local_scope`；升级人类可重新解释/新增规范；记录重新求解过程。
4. **硬规范过多导致不可用**：过度形式化会造成频繁 HOLD/死锁。缓解：分层设计（硬规范只保留不可交易项）、软规范用代价、离线可达性分析预估可行核、对死锁做节拍-安全权衡并显式记录。
5. **屏障模型错 / 相对阶处理错**：HOCBF 参数化与模型误差会破坏不变性。缓解：用鲁棒裕度吸收、运行时监控兜底、模型验证与在线漂移检测；证书只承诺模型/扰动界内。
6. **动态人类不可预测**：SSM 的 T_react 与 v_rel^max 设小会保守、设大会危险。缓解：取保守上界 + 互惠避让 + 人类意图预测的 conformal 界；对假人类攻击做 AIC-N。
7. **规范版本与豁免伪造**：规范更新、豁免伪造会让旧证书"带病有效"。缓解：norm_set_version 闸门、哈希链、签名验证、证书时效；版本回滚触发重认证（AIC-N）。
8. **实时预算**：NOMOS 在 VISTA 的 2.5ms 上再加约 0.5ms，逼近 3.0ms。缓解：固定硬规范数（≤4）、屏障表与裕度在语义流预编译、QP 热启动、事件触发求值、把 VIK/审计留在语义流。
