# 第 11 轮（新灵感循环第 2 轮；本轮灵感：「面部表情识别」×「开源生态」）
> **基线**：第 10 轮 MetricVoiceGauge-STF-NRB-LS（定义 540–548；引理 87–91；实验 E571–E590；IP-340–360）。
> 本轮纪律：**他证单侧 + 来源可核 + 叠加不漂移**。两个灵感分别治理 v10 的两种余债：**见证债**（v10 的全部证据都是"自证"——STF 是机器人自己看环境、NRB 是内部自审、Λ 是自记；对手只要同时骗过机器人感知与前向模型，语义守卫与规范审查会一起沉默）、**来源债**（F̂_q、β/τ 标定表、规范包、地标原型、修复算子库都被默认可信，无签名/哈希/新鲜度/维护期，多机共享使其成为供应链攻击面）。必须保持十轮铁律：新模块失效 ⇒ 行为**等价**于 v10（见证/来源模块整体不可用时回退 v10 的隐式信任）或**不劣**（只收紧不扩权、只降级不放行），绝不新增物理行为。

## 0. 直觉与动机

**灵感 1（面部表情识别 → 从自证到人证：一条只许收紧的独立通道）**
直觉：v10 承认的最大风险是「τ_sem 分割面是经验校准，对抗纹理可同时穿透嵌入检测与前向模型，语义守卫不响」。其根因不是阈值没调好，而是**所有见证都来自同一个视角**（机器人怎么看环境）。可房间里有人：人的皱眉、闪避、痛苦，是机器人行为的**后果反馈**，是一条与语义嵌入**正交**的通道——纹理可以骗过机器人的眼睛，却骗不过被它逼近的人的反应。核心创新：**情感见证通道（AffectiveWitnessChannel, AWC）**——复用 v8 人脸/人体检测栈（不新增重网络），设备端轻量表情分类（7 类 → {舒适, 中性, 不适, 痛苦}），只提炼**不适质量** m_dis，并把 FER 当**单侧统计检验**：见证只用于**否决/收紧**（降 K_eff、抬 d_eth、提前中止、撤销同意），**绝不用于授权/放宽**（"笑"不等于"可抓"）。由此得到本轮最强的一条定理式保证——**加入 AWC 后，任何输入/种子下可达的原始动作序列集 ⊆ v10 的可达集**：安全方向上零回归，代价被完整地赶到**活性**（可能过度收缩），而活性是可测、可预注册的。必须诚实划界：AWC 覆盖的是**有可读诚实人在环的社会性危险**（逼近、记录、抓私人财物、违规行为），**不是**无人在场的快速物理碰撞（人的反应 + 检测延迟来不及）——划清域比夸大全覆盖更重要。

**灵感 2（开源生态 → 从自审到可复现的外部治理：来源与重放）**
直觉：安全论证叠了 11 轮，底下压着一堆**制品**（INT8 模型、β/τ 标定、规范包、地标原型、修复算子）。开源生态最硬的经验不是"代码公开就更安全"，而是四件事：**来源可核**（签名/哈希）、**依赖可溯**（SBOM/DAG）、**构建可复现**（reproducible build）、**过时即淘汰**（TTL/deprecation）。把它们编译进安全栈：**开放来源生态（OpenProvenanceEcosystem, OPE）** 两件套——(i) **来源门控**：每个制品带描述符（哈希、签发者、签发时、TTL、依赖哈希、评审单），加载与周期校验；不可验 ⇒ 该制品视为缺失 ⇒ 沿 v10 既有失效语义**精确降级**（模型→FP、规范→Π_r、原型→该类 ν=1、β/τ→保守默认、修复库→软违规升级为硬违规）；(ii) **可复现见证**：把 v10 的 Λ 升级为**可重放证明日志**（记录制品哈希、RNG 种子、输入/中间量摘要、判定向量），外部审计者用**独立重写的、开源的证书谓词**离线复算——把"相信机器人"换成"自己算一遍"。这补上 v10 台账"只防篡改、仍需信任"的缺口。多机共享规范包/地标图（E588）正是开源生态的 fork/合并，OPE 给出版本兼容（semver）+ 来源验证 + 冲突降级。

**咬合**：AWC 出**人证**（横向、后果侧、只收紧），OPE 出**物证**（纵向、来源侧、可重放），两者都绕开 v10 的自证回路；证书升级 Ĉ⁺ → Ĉ^⊕ = (ĝ_min, ê_max, γ̂_grasp, β_STF, n_t, ω_t, π_t)。原则 **P16 他证单侧律**、**P17 来源即信任律**。二者都受 P15 证据预算约束、都有明确退化路径。第三重（合成）关切：两个"保守叠加"的模块会共同侵蚀活性——因此把**活性**提升为一等可预注册指标（E594/E598/E609），并证明过度收缩有界（引理 96）。

## 1. 研究问题（轮次升级版）

- **Q1（他证·单侧）**：如何把设备端 FER 做成**单侧、单调、可标定**的见证通道（≤0.4ms/帧、≤12KB、原始图像不出设备），使"有可读诚实人在环的社会性危险"在 v10 之上再获一条正交检测通道，且严格保证加入后物理动作集 ⊆ v10（无安全回归），把代价限定为可测的活性损失（任务完成率 ≥90%）？
- **Q2（来源·可复现）**：如何把制品来源（签名/哈希/TTL/依赖 DAG）与可复现见证编译为 O(1) 摊销的运行时机制，使任一制品不可验时宿主模块**严格降级到 v10 对应失效语义**（而非新行为），并让外部审计者用独立实现的开源谓词确定性重放任一危险决策（重放一致率 100%、篡改检出 100%）？
- **Q3（叠加·活性）**：AWC 与 OPE 叠加后，如何在 v10 的 50Hz/25W/内存预算与退化链上不新增行为漂移，并给出过度收缩的活性下界与可预注册阈值（误冻结率、平均 K_eff 损失、队级同时降级风险）？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P17）

**P16 他证单侧律（One-Sided Witness, AWC）**
任何"外部见证"（人脸情感、旁观者、外部审计）只用于**收紧/否决**，绝不允许**授权/放宽**；见证不可读 = 未知 ≠ 舒适；见证的加入不得改变"无见证时已由内部证书允许的动作以外"的任何动作。形式化为：对任意见证状态 ω，v11 可达原始动作序列集 F^⊕(ω) ⊆ F^⊕(FAIL) = F^{v10}。见证整体不可用（FAIL）⇒ 等价 v10；见证可读但未达阈值（COMFORT/NEUTRAL）⇒ 中性，不授予任何权限。

**P17 来源即信任律（Provenance-as-Trust, OPE）**
安全相关制品无有效来源证明 ⇒ 等同缺失；来源验证是加载与周期刷新的一等公民；可复现证明日志必须足以让独立第三方**重算证书逻辑**，不能只防篡改。TTL 过期、签名失效、哈希不符、依赖破损、API 版本不兼容任一成立即触发对应降级；接近 TTL 的制品按年龄做**保守漂移**（β 随 age/TTL 增大），越界即硬降级。**来源证明只保证真实性/完整性/新鲜度，不保证制品语义正确性**——后者由标定覆盖实验（E601）与评审单承担，禁止把 OPE 当成正确性证明。

（不设 P18：维护/时效并入 P17；活性并入 P16 的代价项与 Q3。）

## 3. 与基线的接口（如何退化）

- **AWC 失效**（模块崩溃/超时/模型不可验）⇒ ω=FAIL ⇒ 见证算子为恒等 ⇒ 行为**等价 v10**；**可读性失败**（有人在环但质心距离/朝向/遮挡使 q<q_min 超过 T_unread）⇒ ω=unknown-present ⇒ **轻度**收紧（K_eff≤⌈K_max/2⌉、d_eth+δ_a^mild），不全 Π_r，以免活性被遮挡拖垮；
- **OPE 失效**（验证器崩溃/时钟严重漂移/签名服务不可达）⇒ 回退 v10 的"部署期冻结哈希"隐式信任模型，行为**等价 v10**（不把验证器故障放大成全栈降级）；
- **AWC → NRB**：同意撤销 ξ_i(t) 只减不增，喂给 ν-PRIV/ν-PROP；**OPE → STF**：地标原型不可验 ⇒ 该类匹配强制 ν=1（最大创新度）⇒ 保守收缩；**OPE → LS**：F̂_q 不可验 ⇒ 退 FP 前向模型 + β_base；
- AC 证书失效 ⇒ K=1（v10 Level-3）；ID 失效 ⇒ 全模块 active、归因冻结（v10 Level-4）；**AWC/OPE/Λ^rep 与 STF/NRB 一样 φ^elig=false 永不消融**，仅"地标原型缓存维护"可蒸馏；
- MW 失效 ⇒ v10 手写网关；v8 组件失效 ⇒ 中立元注入 ⇒ v7 ⇒ v6。

## 4. 预期贡献

1. **他证单侧律与零回归安全**：把人脸情感编译成只收紧的外部见证，证明 v11 物理可达集 ⊆ v10（引理 92），首次把"新增感知通道"的代价从安全风险隔离到可测活性；
2. **v10 风险的残余刻画与部分拆除**：对"有可读诚实人在环的社会性危险"，语义与情感双通道并联使漏检概率由 ε_sem 降到约 ε_sem·ε_a（引理 93，含独立性假设与域边界），并把剩余风险明确限定为"无人在场 / 快速物理 / 人伪装"；
3. **制品来源与可复现治理**：来源门控精确降级 + 可重放证明日志 + 外部独立谓词审计，把 v10 的"自审台账"升级为"他证台账"（引理 94–95）；
4. **叠加预算与活性界**：给出两模块叠加后的时延/内存/功耗账本与过度收缩的活性下界（引理 96）；
5. **E591–E610** 覆盖单侧性影子对比、跨文化标定、对抗表情、来源门控逐类失效、TTL 漂移、外部重放、供应链攻击、队级 DoS、含"对手皱眉干扰"的竞赛场景。

## 5. 本轮最大风险

**一句话**：P16 把人脸变成"只许收紧"的见证，等价于给每个在场者发了一个**可合法冻结机器人的否决按钮**——皱眉即可触发收缩甚至停驻（社会性拒绝服务），而 OPE 的 TTL/签名失败又可能让整机队在同一时刻集体降级；于是 v11 把安全单调性换来的是**可用性与生态级系统性风险**，且对"无人在场 / 快速物理危险 / 人刻意压表情"的残余盲区仍停在 v10 水平，容易因新增两条通道而高估真实覆盖。

**新增定义 549（情感观测与不适质量）** 对每个被跟踪者 i，设备端 FER 输出 e_i(t)∈Δ⁷。不适质量 m_i^dis = Σ_{c∈{fear,sad,anger,disgust}} e_i(c)，取保守并集是因为误报只会导致收缩（P16 允许），漏报才是危险。原始图像帧处理完立即丢弃，不落盘、不上行。

其中 δ_a^mild=0.10m、δ_a=0.25m、δ_a^hi≥0.5m、ε 同量级。收缩后仍须重验 Ĉ^⊕；验证不过 ⇒ 单步 fallback。**核心**：算子对每个分量单调（K 不减、d 不增？注意是 d_eth 只增、K_eff 只减、s 只增），且所有动作集为向下封闭（越保守越可行）。

# IP-361 AWC：情感见证通道（复用 v8 检测栈，设备端，不新增重网络）
class AffectiveWitnessChannel:
    def __init__(self, tau_a=0.45, tau_a_hi=0.70, q_min=0.6, theta_a=60,
                 R_a=3.0, ema=0.25, T_unread=1.0):
        self.fer = OnDeviceFER(int8=True)            # 12KB，7 类
        self.tau_a, self.tau_a_hi = tau_a, tau_a_hi
        self.q_min, self.theta_a, self.R_a = q_min, theta_a, R_a
        self.ema, self.T_unread = ema, T_unread
        self.prev, self.unread_since = {}, {}

    def observe(self, persons, now):                  # 50Hz，≤0.4ms，O(#persons)
        if not self.fer.available():                  # 模块级失败
            return WitnessState(failed=True)          # FAIL ⇒ 恒等（等价 v10）
        sig, unread_present = {}, False
        for p in persons:
            readable = (self.fer.quality(p) >= self.q_min
                        and abs(p.head_yaw) <= self.theta_a
                        and p.range <= self.R_a and not p.occluded)
            if not readable:
                t0 = self.unread_since.setdefault(p.id, now)
                if now - t0 >= self.T_unread:
                    unread_present = True
                continue
            self.unread_since.pop(p.id, None)
            if p.consent == 0:                        # ν-PRIV：非自愿者只做即时安全用途
                sig[p.id] = self.distress_only(p)     # 返回布尔，不带身份/表情
                continue
            e = self.fer.expression(p)                # Δ⁷
            m_dis = sum(e[c] for c in (FEAR, SAD, ANGER, DISGUST))
            w = self.ema * clip((m_dis - self.tau_a)/(1 - self.tau_a), 0, 1) \
                + (1 - self.ema) * self.prev.get(p.id, 0.0)
            self.prev[p.id] = w
            level = (DISTRESS if m_dis >= self.tau_a_hi else
                     DISCOMFORT if m_dis >= self.tau_a else
                     COMFORT if e[HAPPY] >= 0.5 else NEUTRAL)
            level = max(level, self.distress_only_level(p))
            sig[p.id] = (level, w)
        lvl = max((s[0] for s in sig.values() if isinstance(s, tuple)),
                  default=NEUTRAL)
        w_bar = max((s[1] for s in sig.values() if isinstance(s, tuple)),
                    default=0.0)
        return WitnessState(level=lvl, w=w_bar,
                            unknown_present=unread_present, failed=False)

    def distress_only_level(self, p):                 # ξ=0：只读取"是否痛苦"，去标识
        return DISTRESS if self.fer.pain_mass(p) >= self.tau_a_hi else NEUTRAL


# IP-354-v11：见证约束执行（单侧收紧，承重来源门控）
def tighten(K0, d0, s0, omega, cfg):
    if omega.failed:                                  # FAIL ⇒ 恒等（等价 v10）
        return K0, d0, s0
    K, d, s = K0, d0, s0
    if omega.unknown_present:                         # 遮挡/不可读：温和收紧，不全 Π_r
        K = min(K, ceil(cfg.K_max / 2)); d += cfg.delta_mild
    if omega.level == DISCOMFORT:
        K = min(K, 2); d += cfg.delta_a * omega.w; s += cfg.eps_a * omega.w
    if omega.level == DISTRESS:                       # 强收紧：K=1 或受控停驻
        K = 1; d += cfg.delta_hi; s += cfg.eps_hi
    return K, d, s                                    # K 只减、d/s 只增（单调）


# IP-362 OPE：来源门控与保守漂移
class OpenProvenanceEcosystem:
    def __init__(self, registry, sig, store, rho=0.2, T_ref=60.0):
        self.registry, self.sig, self.store = registry, sig, store
        self.rho, self.T_ref = rho, T_ref
        self.cache = {}

    def verify(self, a, now):                          # 记忆化 DAG；摊销 O(1)
        key = (a.id, a.semver)
        hit = self.cache.get(key)
        if hit and now - hit[0] < self.T_ref:
            return hit[1]
        ok = (self.sig.verify(a) and a.hash == self.store.hash(a.id, a.semver)
              and now <= a.issued_at + a.ttl
              and all(self.verify(dep, now) for dep in a.deps)
              and api_compatible(a))
        self.cache[key] = (now, ok)
        return ok

    def gate(self, cls, now):                          # 定义 555：返回降级动作
        a = self.registry.current(cls)
        if a is None:
            return Degrade(cls, reason='absent')
        if not self.verify(a, now):
            return Degrade(cls, reason='invalid')
        age = (now - a.issued_at)
        drift = self.rho * clamp(age / a.ttl, 0, 1)    # 接近 TTL ⇒ β 保守上浮
        return Attested(cls, a, drift=drift)

## 4. 推导

**引理 92（单侧见证的支配性——v11 安全零回归）** 设 F^{v10}(s) 为 v10 在状态 s 下可执行的原始动作序列集；F^⊕(ω,s) 为 v11 在同一 s、见证状态 ω 下的可达集。则对任意 ω 与任意 s：F^⊕(ω,s) ⊆ F^{v10}(s)。证明：𝒯_ω 的每个分量单调——K_eff 只减（更短的块仍可执行其前缀单步）、d_eth/d_safe/中止余量只增；同意撤销只减 ξ；来源门控只把制品替换为 v10 的失效语义（更保守）或保持；见证聚合取 max、无投票放行。故 v11 的可行原始动作集是 v10 可行集与若干向下封闭约束之交，逐点包含。特别地 ω=FAIL 时 𝒯_ω 为恒等，F^⊕(FAIL,s)=F^{v10}(s)。安全不变量（CVC/SpatialCert/停车不变式）在子集上继承。代价：活性，见引理 96。∎

**引理 93（首批风险的部分拆除与残余刻画）** 设 A4：对"社会性危险" H_soc（机器人动作会伤害/冒犯一位在场、可读、诚实的被跟踪者），该人在反应窗 T_react=300ms 内产生 m_dis>τ_a 的概率 ≥1−ε_a；可读性门控通过概率 ≥1−ε_ℓ。则在 H_soc 且存在此类人时，v11 以概率 ≥1−ε_a−ε_ℓ 在 T_react+1 帧内触发 DISCOMFORT/DISTRESS 收缩或中止，**与语义创新度 ν 无关**（正交通道）。与 v10 语义通道并联：若二者失效在给定危险下近似独立（假设 A5），漏检概率 ≤ ε_sem·ε_a（相对 v10 的 ε_sem）。证明：A4+门控 ⇒ m_dis>τ_a ⇒ 定义 552 触发 𝒯_ω 收紧；ω 逐帧更新、无 Δ_dom 的 20 帧滞后；引理 92 保证收紧方向安全。并集/交集界收尾。**边界**：H_phys（无人在场的快速物理危险）、人伪装/压表情、人被对手操控时不满足 A4，v11 退回 v10 的 τ_sem 风险；E596/E597 量化该残余。∎

**引理 94（来源门控的精确降级与不劣性）** 对每个制品类 c，V(a_c)=false ⇒ v11 以 g(c)（定义 555）执行，且 g(c) 的输出与 v10 在"c 缺失/失效"时的对应路径**逐字节等价**（复用 v10 失效代码路径）。因此 OPE 不引入新物理行为；(ii) 单调性：V 失败只会增大 β、缩 K_eff、或触发 Π_r，故相对"v10 + 被篡改制品"其行为不劣（阻止了本会发生的违规），相对"v10 + 正确制品"则可能更保守（活性代价）。∎

**引理 95（可复现见证的审计可靠性）** (i) 若制品签名/哈希真实（L1）且 v11 管线对给定 (artifacts, seed, inputs) 的证书计算确定，则外部独立谓词 P_open 的重放结果与记录一致（L2 完备性）；(ii) κ_h=256 链 ⇒ 历史记录删改以 ≥1−2⁻²⁵⁶ 被检出；每 C_w=64 块校验点 ⇒ 在线缺口至多存续 64 块即触发 Π_r（继承 v10 引理 90）；(iii) **范围限制**：P_open 只验证证书算术与来源一致性，**不验证制品语义正确性**——正确性由 E601（TTL 漂移下覆盖 ≥99%）与 review_ticket 承担。∎

**引理 96（叠加预算与活性界）** (i) 预算：新增时延 0.4+0.1+0.05=0.55ms、内存 404KB、功耗 82mW，均在 v10 预算余量内，50Hz/25W 保持（E607）；(ii) 活性下界：设非危险帧上误判 DISCOMFORT/DISTRESS 的每人在场帧概率为 f，任务时长 T 帧、平均在场人数 n，则期望通过帧比例 ≥ (1−f)^{nT}·(1−loss)，其中 loss 为收缩导致的平均 K_eff 损失；阈值取 τ_a=0.45、τ_a^hi=0.70 并加 3 帧 EMA 与迟滞，E594 目标任务完成率 ≥90%，否则按预注册放宽非安全项；(iii) 过度收缩有界：unknown_present 只到 K=2 与 δ_mild，不触发全 Π_r，限定遮挡场景的活性损失。∎

## 8. 本轮最大风险

**一句话**：P16 把人脸变成"只许收紧"的见证，等价于给每个在场者发了一个**可合法冻结机器人的否决按钮**——皱眉即可触发收缩甚至停驻（社会性拒绝服务），而 OPE 的 TTL/签名失败又可能让整机队在同一时刻集体降级；于是 v11 把安全单调性换来的是**可用性与生态级系统性风险**，且对"无人在场 / 快速物理危险 / 人刻意压表情"的残余盲区仍停在 v10 水平，容易因新增两条通道而高估真实覆盖。
