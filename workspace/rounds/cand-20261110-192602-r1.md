# 第 47 轮（承接第 46 轮产物 v23；本轮灵感：仿真训练 × 成功率） · Sim-Port：以竞赛成功率为目标的仿真标定证书组合（架构 v11）

> 承接第 46 轮产物 v23 Memory-Safety-Voice。v23 把记忆检索、语音槽位、安全绑定统一纳入 fail-closed 证书纪律，v10 的能量-上下文-深度调度也已成体系。但全部版本共享一条从未写进定义的隐含假设 **H6：证书的逐样本 worst-case soundness 与竞赛的平均成功率目标一致**。UniBot 通才赛道按 32 项桌面任务的平均成功率与步骤分排名、覆盖五类泛化场景（位置/干扰物/背景/未见物品/人为干扰），而榜首平均成功率也不到 30%——绝大多数失败不是"安全违例"，而是"根本没做成"。一个只追求 soundness 的证书在不确定时选择弃权，安全账本正确、记分账本却等于 0。两个灵感词精确击中 H6：**仿真训练**提供一个真实机器人上无法获得的反事实引擎，能在海量 rollout 上估计"若执行/若弃权"的成功-违例操作特性；**成功率**把目标从逐样本最坏情形改写为跨任务、跨场景的组合平均。于是核心问题变成：**如何在全局安全预算下，用仿真标定并按格点分配风险预算与训练/数据资源，使 32 项任务的平均成功率最大，且不因仿真-现实差距把风险错配到现实更脆弱的格点**。

## 0. 直觉与动机

**灵感 1（成功率 → 这是组合指标，不是逐样本最坏情形）**
直觉：竞赛只数"做成了几次"，弃权与失败同分。把 32 项任务看成资产组合，总成功率是各格点成功率的加权平均。给每个任务同一个保守阈值是错的：应把"安全预算"视为稀缺资源，投向"每单位风险换取成功率提升最大"的任务/场景格点。这正是机会约束下的资源分配，而非逐任务独立守门；阈值存在内部最优点，而不是越保守越好。

**灵感 2（仿真训练 → 廉价反事实与证书操作特性曲线）**
直觉：现实中无法反复追问"如果我当时动作会怎样"。仿真可以：同一初始状态并行跑执行/弃权，直接估出每个阈值 τ 下的执行覆盖率 a(τ)、成功条件率 s(τ)、违例条件率 v(τ)，得到证书操作特性曲线（COC）。仿真还是数据工厂：可沿竞赛五类泛化轴做可控域随机化，专门补齐拉低均值的短板任务，而不是平均撒数据。

**灵感 3（耦合 → 仿真生产、现实校正、组合决策三层闭环）**
直觉：仿真曲线不能直接信。用少量真实（准）配对样本与分轴域差异，估计仿真-现实差距 γ(τ)，给出"现实成功率下界、现实违例率上界"，再用这条保守曲线做组合优化；部署后在线更新 γ。若某格点真实校正样本不足，则对该格点恢复 fail-closed——绝不用未验证的成功率去赌安全。仿真是先验来源，不是风险预算的最终签发者。

**耦合升级**：在 v10/v23 既有模块上新增**成功率-证书组合层**。SCPO 求风险预算分配与逐格点阈值；SimFarm 生成沿五泛化轴对齐的课程与域随机化；GapCert 负责仿真-现实差距证书与保形校正。ECPS 的模态效用从"证书宽度缩减/能耗"升级为"期望成功率增益/能耗"；DCL 采集从覆盖驱动升级为"边际成功率增益/成本"驱动；CAR 从固定阈值升级为"按格点风险预算的动态守门"；CCA 增加仿真-现实差距红队与跨轴外推审计。

## 1. 形式化定义（增量：定义 59–64）

**定义 59（任务-场景成功率分解与组合目标）**
任务 i∈[N]（N=32），场景轴 j∈[J]（J=5 泛化轴）。单次 rollout 成功指示 Y_{ij}∈{0,1}，违例指示 V_{ij}∈{0,1}。证书策略 π_θ 给出动作决策 A_{ij}∈{0,1}（1=执行，0=弃权/fail-closed）。记 Z_{ij} 为"若执行则成功"的潜在结果、W_{ij} 为"若执行则违例"。则
Y_{ij}=A_{ij}·Z_{ij}，V_{ij}=A_{ij}·W_{ij}。
组合目标（竞赛均成功率）
S(θ)=Σ_{ij} w_{ij}·P(A_{ij}=1, Z_{ij}=1)，Σ_{ij} w_{ij}=1（均分时 w=1/(NJ)）。
全局安全预算约束
R(θ)=Σ_{ij} w_{ij}·P(A_{ij}=1, W_{ij}=1) ≤ ε。
**要点**：弃权使 Y=V=0——它同时"省下风险"和"丢掉成功率"，因此阈值存在可优化的内部平衡点。

**定义 60（证书操作特性曲线 COC）**
对格点 (i,j) 与证书阈值 τ（允许半径 rad_max、置信 α 或综合门限），在仿真分布 P_sim 下定义
a_{ij}(τ)=P_sim(A=1|τ)，s_{ij}(τ)=P_sim(Z=1|A=1,τ)，v_{ij}(τ)=P_sim(W=1|A=1,τ)。
COC_{ij}={(a,s,v)(τ): τ∈T}。策略 π 是在每个格点选一个 τ_{ij}，即一个**风险配置** τ∈T^{N×J}。称 τ 为 **ε-成功标定**，若真实分布下 Σw·a·s 的估计下界 ≥ 目标且 Σw·a·v 的上界 ≤ ε。

**定义 61（风险预算组合优化）**
给定（修正后的）COC 与预算 ε，求解
τ* = argmax_τ Σ_{ij} w_{ij}·a_{ij}(τ_{ij})·s_{ij}(τ_{ij})
s.t. Σ_{ij} w_{ij}·a_{ij}(τ_{ij})·v_{ij}(τ_{ij}) ≤ ε，
可选每格点局部约束 a·v ≤ ε_{ij}。以安全影子价格 λ 解耦：
τ*_{ij}(λ)=argmax_{τ∈T} [a·s − λ·a·v]_{ij}，
再二分 λ 使预算取等（风险随 λ 单调不增）。**边际原则**：预算投向"每单位风险的成功率增益" ∂(a·s)/∂(a·v) 最大的格点，而非平均分配；λ 即"多允许一单位违例所换得的成功率价格"。

**定义 62（仿真-现实证书迁移与保形校正）**
设真实分布 P_real。对格点 (i,j) 与阈值 τ，定义缺口上界与风险低估上界
γ^{s}_{ij}(τ) ≥ E_real[Z|A,τ] − E_sim[Z|A,τ]，
γ^{v}_{ij}(τ) ≥ E_real[W|A,τ] − E_sim[W|A,τ]。
保守曲线 s̃=(s_sim−γ^s)_+，ṽ=(v_sim+γ^v)∧1。γ 由**分轴域差异**（五泛化轴上 MMD/域分类器差距）先验与少量真实样本的保形分位数共同给出：差距越大、样本越少，γ 越保守；样本数 < K_min 时置 γ=1（等价 fail-closed）。

**定义 63（仿真训练资源分配）**
总预算 C（仿真步数 + 真实工时）。格点成功率边际收益 M_{ij}=∂S/∂C_{ij}。分配
C_{ij} ∝ softmax(M_{ij}/η)，并设下限 C_min 保证每格点非零覆盖；每轮用真实表现重估 M。即把数据采集从"覆盖驱动"改为"均成功率边际驱动"。

**定义 64（闭环与后悔）**
部署 epoch k 观测 (Y,V)，在线更新 γ 与 COC（保形/贝叶斯）。策略序列 {τ_k} 相对全知真实 COC 最优配置的后悔
Reg_K=Σ_{k=1}^{K}[S*(ε)−S(τ_k)]，
平稳段目标 Reg_K=O(√K)；检测到分布漂移（分轴域差异突增）时对相关轴重置 γ=1。

## 2. 新增产出与既有 IP 升级

**IP-69 SCPO（Success-Cert Portfolio Optimizer）**
- 输入：修正后 COC、全局预算 ε、权重 w、可选局部预算 ε_{ij}
- 拉格朗日解耦求逐格点阈值；二分 λ 满足预算；格点过多时用多重选择背包 DP 精确兜底
- 输出：风险配置 τ*、影子价格 λ（用于解释"哪个任务的边际风险最贵"）
- 边际报告：给出各格点 ∂(a·s)/∂(a·v) 排名，直接指导采集/训练投入

**IP-70 SimFarm（Simulation Curriculum & Randomization Allocator）**
- 沿五泛化轴的参数化生成器：位置/干扰物/背景/未见物体/人为干扰，每轴独立强度旋钮
- 课程：按定义 63 的边际成功率增益分配仿真与真实预算
- 一致性：把仿真 COC 与真实 held-out 结果做成"对齐看板"，暴露轴级偏差
- 反事实采样：同一初始状态并行执行/弃权，产出配对日志供 GapCert 与 SCPO

**IP-71 GapCert（Sim-Real Gap Certifier）**
- 分轴域差异估计（域分类器/MMD）+ 少量真实（准）配对样本
- 保形分位数给出 γ^s 上界与 γ^v 上界；样本不足自动 fail-closed
- 漂移检测：轴级差异突增即重置保守裕度并触发重标定
- 产出"可迁移预算"：只有在 γ 被真实数据压低后才放宽某格点预算

**既有 IP 升级**
- IP-63 ECPS：模态效用 U(m)=E[Δ成功率]/(P_m+能量风险)，证书宽度只作中介量
- IP-61 DCL：采集效用 = 边际成功率增益 /（仿真+真实成本），并强制产出 GapCert 所需真实配对样本
- IP-62 CCA：新增仿真-现实差距红队、跨泛化轴外推审计、成功率-违例帕累托伪造检测
- IP-51 CAR：守卫阈值改为按格点风险预算动态下发；预算耗尽即该格点 fail-closed
- IP-45 总线：新增 success-estimate / portfolio-plan / sim-gap / axis-shift 话题

## 3. 算法骨架

SCPO/SimFarm/GapCert 每标定周期：
1. SimFarm 沿五轴生成各格点 rollout，估原始 COC(a,s,v)
2. GapCert 用分轴差异 + 真实配对样本估 γ^s,γ^v；样本不足格点 γ=1
3. 用 (s̃,ṽ) 解 SCPO：二分 λ → 逐格点 argmax(as−λav) → 校验 Σw·a·v≤ε
4. 下发风险配置 τ* 与每格点预算 ε_{ij} 给 CAR/ECPS/DCL
5. DCL 按边际成功率增益分配下一轮仿真/真实预算，并补齐缺失的真实配对
6. 部署后在线更新 γ；轴级漂移突增 → 相关格点立即 fail-closed 重标定

## 4. 本轮最大风险

**一句话**：仿真标定的成功-违例曲线若在竞赛最看重的长尾泛化轴（未见物体、人为干扰）上与现实失真，组合优化会系统性地把风险预算错配到"仿真里安全、现实里脆弱"的格点，成功率优化会静默转化为安全违例与均值崩塌；因此仿真只能提供先验，风险预算的最终签发必须由独立真实校准集、分轴保守裕度（γ）和样本不足即 fail-closed 三重兜底。

## 2. 关键算法 伪代码

### IP-70 SimFarm：COC 估计与预算分配
```
def build_coc(sim_logs, cells, tau_grid):
    coc = {}
    for c in cells:
        for tau in tau_grid:
            rs = [r for r in sim_logs[c] if r.tau == tau]
            acted = [r for r in rs if r.act]
            a = mean([r.act for r in rs])
            s = mean([r.success for r in acted]) if acted else 0.0
            v = mean([r.violation for r in acted]) if acted else 0.0
            coc[(c, tau)] = (a, s, v)
    return coc

def sim_farm(cells, marginals, C_total, eta=0.2, C_min=1.0):
    m = array([marginals[c] for c in cells])
    p = softmax(m / eta)
    C = maximum(C_total * p, C_min)
    return C * (C_total / C.sum())          # 保下限后重新归一

def axis_curriculum(axis_gain, B_axis):
    # 每轴按边际增益分配随机化强度，保证每轴有 B_min
    w = softmax(array([axis_gain[j] for j in range(J)]))
    return maximum(B_axis * w, B_min)
```

### IP-71 GapCert：保形校正
```
def conformal_upper(residuals, alpha):
    # 单侧上界：取 (1-alpha) 分位
    n = len(residuals)
    q = ceil((n + 1) * (1 - alpha))
    return sorted(residuals)[min(q, n) - 1]

def gap_cert(sim_coc, real_pairs, axis_shift, alpha=0.05, K_min=30):
    gs, gv = {}, {}
    for c in cells:
        d = axis_shift[c]                      # 分轴域差异，[0,1]
        prior = clip(kappa * d + c0, 0.0, 1.0) # 差距越大先验越保守
        Rs = [r.z - sim_coc[(c, r.tau)][1] for r in real_pairs[c]]
        Rv = [r.w - sim_coc[(c, r.tau)][2] for r in real_pairs[c]]
        if len(real_pairs[c]) < K_min:
            gs[c], gv[c] = 1.0, 1.0            # 样本不足 -> fail-closed
        else:
            gs[c] = max(prior, conformal_upper(Rs, alpha))
            gv[c] = max(prior, conformal_upper(Rv, alpha))
    return gs, gv

def corrected_coc(sim_coc, gs, gv):
    out = {}
    for (c, tau), (a, s, v) in sim_coc.items():
        out[(c, tau)] = (a, max(0.0, s - gs[c]), min(1.0, v + gv[c]))
    return out
```

### IP-69 SCPO：拉格朗日 + 二分
```
def lagrangian_select(coc, cells, tau_grid, lam):
    tau_star = {}
    for c in cells:
        tau_star[c] = max(tau_grid,
            key=lambda t: coc[(c, t)][0]*coc[(c, t)][1]
                          - lam*coc[(c, t)][0]*coc[(c, t)][2])
    return tau_star

def risk_of(coc, tau_star, w):
    return sum(w[c] * coc[(c, t)][0] * coc[(c, t)][2]
               for c, t in tau_star.items())

def scpo(coc, cells, tau_grid, w, eps, tol=1e-4):
    lo, hi = 0.0, 1.0                       # lambda 上界按 max(v/s) 取
    if risk_of(coc, lagrangian_select(coc, cells, tau_grid, lo), w) <= eps:
        return lagrangian_select(coc, cells, tau_grid, lo), lo, 'infeasible-free'
    if risk_of(coc, lagrangian_select(coc, cells, tau_grid, hi), w) > eps:
        return None, hi, 'budget-infeasible' # 全保守仍超预算 -> 全局 fail-closed
    while hi - lo > tol:
        lam = 0.5 * (lo + hi)
        tau = lagrangian_select(coc, cells, tau_grid, lam)
        if risk_of(coc, tau, w) > eps:
            lo = lam
        else:
            hi = lam
    return lagrangian_select(coc, cells, tau_grid, hi), hi, 'ok'
```

### 与既有层耦合
```
def ecps_utility(m, c, B, coc, gs, gv, budget_ij):
    # 期望成功率增益 / 能耗，证书仅作可行性约束
    ds = expected_success_gain(m, c)
    if not energy_feasible(m, B) or budget_ij <= 0:
        return -inf
    return ds / (P_m[m] + c_risk * Risk_e(B))

def dcl_score(cell, C_sim, C_real, marginals):
    # 边际成功率增益 / 总成本；强制保留真实配对预算
    return marginals[cell] / (C_sim + C_real + eps)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SimFarm COC 估计 | O(|cells|·|T|·n_sim) | O(|cells|·|T|) | held-out 仿真估计，按 cell 分层 |
| GapCert 保形校正 | O(|cells|·(K + K log K)) | O(|cells|·K) | 单侧覆盖 ≥ 1−α；样本 < K_min ⇒ γ=1 |
| SCPO 拉格朗日二分 | O(|cells|·|T|·log(1/tol)) | O(|cells|·|T|) | 风险随 λ 单调不增 ⇒ 二分收敛；预算不可行即 fail-closed |
| 多重选择背包精确兜底 | O(|cells|·|T|·B/δ) | O(B/δ) | 离散预算下全局最优 |

**正确性定理（成功率-证书组合）**：设 GapCert 的 γ^s,γ^v 在置信度 1−α 下分别上界真实缺口与风险低估，SCPO 返回 ε-可行配置 τ*。则对任意格点 c 的真实分布：
① P(真实违例率 Σw·a·ṽ ≤ ε) ≥ 1−α；
② 真实成功率 S(τ*) ≥ Σw·a·(s̃)（以校正下界计），且当 λ* 为预算取等处的影子价格时，任何其他 ε-可行配置的成功率提升都需以更高边际违例为代价；
③ 若某格点真实样本 < K_min，则该格点 γ=1 ⇒ s̃=0 ⇒ 不执行 ⇒ 该格点退化 fail-closed，绝不进入风险预算。
即"仿真只提供先验、真实校正签发预算、样本不足即弃权"三者共同保证：成功率优化不会以未验证的 soundness 为代价。

## 4. 实验设计 E115–E120

| 实验 | 指标 | 门槛 |
|---|---|---|
| E115 COC 仿真估计 | held-out 仿真上 a/s/v 的估计误差 | s、v 的 MAE ≤ 0.03 |
| E116 差距校正覆盖率 | 真实配对上 γ 的单侧覆盖 | ≥ 95%（α=0.05）；跨轴不低配 |
| E117 组合 vs 统一阈值 | 同 ε 下平均成功率差 | ≥ +5 个百分点 |
| E118 风险错配 | 各泛化轴实际违例 ≤ 该轴预算 | 每轴违例 ≤ ε_j；未见物体轴 0 超配 |
| E119 数据分配效率 | 每仿真/真实工时的成功率增益 | 相比均分 ≥ +30% |
| E120 100h 闭环/榜单代理 | 平均成功率、步骤分、安全停机 | 成功率 ≥ 基线 +8pp；安全停机 0 起 |

回退策略：E116 覆盖率 < 90% → 全轴 γ 上调一档并缩小 ε；E117 无增益 → 关闭组合优化，回退统一保守阈值；E118 任一轴超配 → 该轴预算清零并强制 fail-closed 重标定；E119 边际估计失真 → 回退均分并降低 SimFarm 置信。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 仿真-现实差距在长尾轴失真 | 高 | 分轴 γ 先验 + 真实保形校正；样本 < K_min 即 fail-closed；独立审计集 |
| COC 过拟合仿真伪影/物理错误 | 高 | held-out 仿真 + 物理参数随机化 + 真实抽检；CCA 帕累托伪造检测 |
| 为估反事实而探索导致真违例 | 高 | 影子模式/受限半径安全探索；任何探索不得突破格点 ε_{ij} |
| 风险预算错配或分布漂移 | 中 | 在线更新 γ；轴级差异突增即重置 γ=1 并重标定 |
| 刷均值（只优化简单任务） | 中 | 权重按场景覆盖与步骤分约束；报告逐任务成功率而非只报均值 |
| 组合优化不可行/退化 | 低 | 多重选择背包精确兜底；全保守仍超预算则全局 fail-closed |

## 6. 本轮最大风险

**一句话**：仿真标定的成功-违例曲线若在竞赛最看重的长尾泛化轴（未见物体、人为干扰）上与现实失真，组合优化会系统性地把风险预算错配到"仿真里安全、现实里脆弱"的格点，成功率优化会静默转化为安全违例与均值崩塌；因此仿真只能提供先验，风险预算的最终签发必须由独立真实校准集、分轴保守裕度（γ）和样本不足即 fail-closed 三重兜底。
