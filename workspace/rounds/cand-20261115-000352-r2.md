# 第 3 轮（灵感循环第 3 轮；本轮灵感：「演示方案」×「语义分割」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440），
> 上承 **LeanGauge**（IP-310–314；定义 398–415）与 **MODGAUGE** 五不变式。
> **本轮纪律**：在前人基础上改进，而不是推倒重来——6C 骨架、MTC/TCV、L-Box、AP-Cal、TB-Contract、
> P-Quarantine 与语言审计层全部保留；本轮只升级两个此前被当作“给定”的东西：
> (1) 盲区的**空间/语义索引**：从网格格子 (d,m,i) 升级为“段-物体-材质-边界”；
> (2) 探测与校准的**经验来源**：从“预训练先验 + VLA 自由编程”升级为“**演示方案锚定** + **语义分割分账**”；
> 同时审计并修复第 2 轮遗留的 9 处结构性缺陷（§5）。

## 双轴映射（升级而非重写）

| 灵感词 | 第 2 轮对象 | 升级为 | 一句话动机 |
|---|---|---|---|
| 语义分割 | D-Box 的格子 (d,m,i) + L-Box 的扁平假设集 | **S-Box**：段-物体-材质-边界索引的盲区格 + 语义-数值四象限 | “这个格子没验证过”缺少宾语：没验证的是哪个物体、哪块材质、哪条边界？跨材质的格子观测本身就是混合信号 |
| 演示方案 | IP-317 T-Box：VLA 在预注册工具上自由编程序；AP-Cal 只靠预训练先验 | **E-Box + DGP**：把人类/脚本/系统演示编译成带语义前置-后置条件的技能宏，程序只能在演示流形内适配；演示同时是校准锚、漂移金丝雀与可执行测试 | 对物理系统而言，最省样本、最可审计的先验不是“更多预训练”，而是“在真实物件上做过一遍并留下可重放的回执” |
| 合流轴（本轮新增） | 分割与演示各自只是感知/交互前端 | **“分账 + 接地”对偶**：分割回答“哪些段共享同一误差源”，演示回答“这些段在真实材质上应该怎么测”；二者共同把第 2 轮最大风险（跨盲区相关偏差）变成可观测、可检验的结构 | 没有分割，证据独立性是假的；没有演示，语义索引只是另一个不可验证的标签 |

**统一命题**：
> **语义分割负责“把盲区分账”，演示方案负责“把经验接地”。**
> 计量真值仍由数值层独占；VLA 仍只做三件被审计的事（提假设、选工具、写主张）；
> 分割与演示只提供**索引、先验、约束与证据独立性结构**，绝不进入数值通道。

**不变式保持声明**：
- MODGAUGE 五不变式全部保留；
- **新增“索引-证据不变式”**：任何跨段/跨对象的证据合并，必须显式声明其共享混淆变量
  （同一物体、同一材质、同一分割模型版本），并按有效样本量 n_eff 折扣；
- **严格退化链延长**：DemoGauge 失效（分割不可信 / 演示库为空 / 人工不可达）⇒ ToolGauge 的 6C；
  ToolGauge 失效 ⇒ LeanGauge 纯数值探测；再失效 ⇒ MODGAUGE。演示请求是**异步可选支路**，不是依赖项。

## 0. 直觉与动机

**灵感 1（语义分割 → 盲区的最小单位不是格子，而是“段”）**
直觉：ToolGauge 的 D-Box 用格子 (d,m,i) 记账，L-Box 在这个格子上生成扁平假设集。但一个格子可能同时覆盖
玻璃、金属与桌面边缘：数值探测得到的是**混合信号**，校准却按单一材质处理；更糟的是，同一物体的不同格子
会给出高度相关的观测，而 AP-Cal 把它们当作独立样本，输出过度自信的 σ。语义分割补上的正是这一层“分账”：
(a) **索引**：把盲区从格子细化到段 g（同材质、同物体、近似同几何），修复单元与热替换子图对齐；
(b) **先验**：材质/affordance 标签条件化 MP-Φ 与工具兼容性（镜面适合光照扫描，透明适合双目+IR，
弹性体适合敲击）；
(c) **独立性结构**：同一物体的段共享对象级误差，跨物体的段才近似独立——这正是 V 阶段交叉验证与
P-Quarantine 一直缺的统计结构。
注意：分割不是“真值前端”，它自身会错（伪装、贴纸、透明边界）。因此分割必须作为**带契约的传感器**
接入（定义 445），其错误进入 SNC 与隔离区，而不是被当作物理事实。

**灵感 2（演示方案 → 最可审计的先验是“做过一遍”）**
直觉：ToolGauge 把 VLA 的自由编程限制在预注册工具上，但“工具合法”不等于“程序在物理上可行”；
AP-Cal 的预训练先验又可能偏离部署现场的真实材质。人类操作者的演示恰好同时提供两样东西：
(a) **技能约束**：一条演示轨迹可以被编译成带类型的**技能宏**（工具调用 DAG 模板 + 参数包络 +
语义前置/后置条件）；VLA 只能在宏的邻域内适配，越界即拒绝——这比“只选预注册工具”强一个量级；
(b) **部署锚点**：演示是在**真实物件**上做的，配对（分割掩码，计量回执）直接构成部署分布的校准样本，
且可重放：重放同一演示计划，预期结果与实际结果的偏差就是**漂移金丝雀**。
“演示方案”在本轮不是展示脚本，而是**可执行的物理契约**：它既教会系统怎么做，又让系统能证明自己仍然会做；
它还可作为热替换后的回归测试与给人类的可审计解释（演示修复证书，定义 444）。

**灵感 3（合流 → 把“相关性”从不可见的风险变成一等公民）**
直觉：第 2 轮最大风险是摊销先验在分布偏移下产生**跨盲区强相关**的系统性偏差。分割给出相关性结构
（同物体/同材质的段相关），演示给出**部署现场的独立锚点**与漂移证据。二者合流后可做三件第 2 轮做不到的事：
1. **对象级误差分解**：u_s = v_obj + u_res，样本量再多也不能把同一物体的 v_obj 误差平均掉（引理 54）；
2. **语义不相交交叉验证**：V 阶段不再随便拿一条“数值独立”的回执，而要求段不相交、物体不同、模态不同；
   不满足就按 n_eff 膨胀方差（定义 443）；
3. **演示回放金丝雀**：用有已知预期结果的演示计划检测“先验是否已经漂了”，比无监督的残差符号统计更早、
   更可解释（定义 440）。
一句话：**分割让误差“分得开”，演示让误差“看得见”。**

**语义-数值覆盖四象限**（本轮的组织性视角）：

| | 语义已知 Known_S=1 | 语义未知 Known_S=0 |
|---|---|---|
| **数值已覆盖 Cov_N=1** | Q1 常规监控：只需低频复验 | Q3 开放世界审计：数值对但“不知道是什么”，禁止声称理解 |
| **数值盲区 Cov_N=0** | Q2 经典校准问题：按材质/边界条件化探测 | Q4 双重盲区：探索或结构化演示请求 |

第 2 轮的 D-Box/L-Box 只区分了“盲/不盲”，没有区分 Q1–Q4；这导致它把 Q3 的“数值已验证但语义错标”
误当作安全，也把 Q2 中跨材质的混合观测误当作单材质样本。

## 1. 形式化定义（增量：定义 432–447）

**定义 432（语义分割场与段契约）** Σ = (G, L, B, κ, ver)：
- G = {g}：像素/体素的一个有限划分（段），内部不交、并覆盖工作空间支撑集；
- L(g) ∈ L_M ∪ {UNKNOWN}：材质/affordance 标签及其校准后验，**不是** VLA 的自由文本；
- B(g)：边界带（boundary band），记录段边缘的几何不确定区域与宽度；
- κ(g)：分割器对该段的校准可靠度（类条件覆盖与边界误差）；
- ver：分割模型版本/哈希，进入所有证据的 provenance。
Σ 是**传感器契约**而非真值：其错误由定义 445 的 OOD 门与 SNC 处理。

**定义 433（段索引盲区格）** s = (g, d, m, i, w_s)，其中 g ∈ G，d 为模态、m 为干扰、i 为实例条件；
w_s = |g| / Σ_{g'} |g'| 为面积权重；π_R(s) ⊆ R 为投影到的网格格子集合。
Cov(s) 继承定义 398/399 的覆盖判定；O(g) 为物体实例 id。**共享混淆变量** C(s) = (O(g), L(g), ver)。
段格按包含关系构成偏序：s ⪯ s′ ⇔ g ⊆ g′。该定义是定义 398 的严格细化：格子是段的粗化投影。

**定义 434（语义-数值覆盖四象限）** 令 Cov_N(s) ∈ {0,1} 为数值覆盖，Known_S(s) ∈ {0,1} 为
“L(g) 非 UNKNOWN 且 κ(g) ≥ κ_min”。四象限 Q1–Q4 按上表定义，各自绑定动作：
Q1 低频复验；Q2 条件化探测；Q3 开放世界语义审计（禁止把数值正确升级为语义理解）；
Q4 探索或演示请求。**任何跨象限的结论迁移都被禁止**。

**定义 435（边界纯度与纯区探测）** 对探测足迹 P 与段 g，purity(P,g) = |P ∩ g| / |P|。
纯区探测要求 purity ≥ 1 − η_b。混合回执（purity < 1 − η_b）有两种处置：
(i) 若 purity ≥ 1/2，按定义 441 的混合模型**膨胀方差**并降权；
(ii) 否则作废（定义 417），永不进入校准样本集。校准样本只接受纯区回执。

**定义 436（演示方案 δ）** δ = (π, K, ℓ_int, E_pre, E_post, o, prov)：
- π：工具调用 DAG（定义 418），可由人、脚本或系统生成；
- K：关键帧语义掩码序列（执行前/中/后）；
- ℓ_int：意图标签（如“检查镜面反射”“验证透明件厚度”）；
- E_pre / E_post：**掩码级**语义前置/后置谓词（不是自然语言）；
- o：演示期间的有效回执流；prov = (操作者/设备签名, ts, 演示库版本)。
origin ∈ {human, scripted, system}。**演示方案是可执行规格**：它同时是示教、校准样本、回归测试与解释材料。

**定义 437（技能宏与演示库）** 宏 m = (T_m, holes, Pre_m, Eff_m, Θ_m, ρ_m, sig)：
T_m 为带类型洞的程序模板；Θ_m 为演示得到的参数包络（凸包或 Lipschitz 包络）；
ρ_m 为演示支持度；sig 为来源签名。演示库 D = {m_j}，带版本与准入记录（定义 446）。
宏是**工具调用的高阶类型**：它把“哪些工具、什么顺序、参数在什么范围、语义效果应如何”打包成一个可复用单元。

**定义 438（演示接地编程器 DGP 与接地谓词）** DGP 对盲区 s 与假设集 H_s 只能做**有界适配**：
Π_s = adapt(m, H_s)，m ∈ D，且
Ground(m,s) ⇔ d_feat(m,s) ≤ ε_demo ∧ θ ∈ Θ_m ∧
masks_match(pred_pre(H_s), K_pre) ∧ masks_imply(pred_post(H_s), Eff_m)。
任一不满足 ⇒ 拒绝该宏；无可用宏 ⇒ 发出演示请求（定义 439），**绝不退回自由编程**。
d_feat 是在（材质、几何、工具、干扰）特征空间中的距离；ε_demo 是可审计的“离演示多远”旋钮。

**定义 439（演示请求与人工升级预算）** DR = (s, H_s, missing_skill, safety_envelope, max_latency)：
结构化请求，只说明缺哪类技能、在哪个段、允许什么物理包络，**不包含自由文本指令**。
演示预算 B_demo 以班次计；DR 异步排队，τ_demo 内无响应 ⇒ 该盲区退回 ToolGauge 数值路径。
DR 永不阻塞 50Hz 路径，也永不成为正确性的必要条件。

**定义 440（演示回放金丝雀 DRC）** 对演示 δ 保存预期结果 e_δ 与不确定度 Σ_δ。
在修复后（或任意时刻）于当前上下文重放 δ，得到 y_replay：
z_δ = (y_replay − e_δ) / sqrt(Σ_replay + Σ_δ)，|z_δ| > ε_replay ⇒ 触发**对象级**先验隔离
（暂停该 O(g) 的 AP-Cal 更新）并要求回归测试。回放属于 PROBING 显式状态（定义 430），有预算上界。

**定义 441（段解耦参数化）** 契约参数分解为
u_s = v_{O(g)} + u_res(g)，
其中 v 为物体级共享潜变量（材质/几何/装配的公共偏差），u_res 为段级残差。
先验因子化 p(v, u) = p(v) · Π_g p(u_res(g))；MP-Φ 同时输出两者的摊销后验与协方差块。
混合回执按定义 435 的权重进入 u_res，并以材质响应差膨胀方差。

**定义 442（语义组条件共形覆盖）** 对每个材质组 a = L(g)，要求
P(h* ∈ H_s | a) ≥ 1 − α_a；关键材质（透明、镜面、柔性）取更小 α_a。
运行期 SLA 为最差组覆盖 min_a coverage_a ≥ 1 − α_max；跌破 ⇒ 该组 H_s := {UNKNOWN}，
进入退化链，而不是用全局边际覆盖掩盖局部失效。

**定义 443（语义不相交交叉验证与有效样本量）** 两条回执 r, r′ **语义不相交**当且仅当
g ∩ g′ = ∅ ∧ O(g) ≠ O(g′) ∧ d ≠ d′；否则不构成独立证据。
若同组/同物体回执数 n、组内相关 ρ̂，则 n_eff = n / (1 + (n−1)ρ̂)。
V 阶段使用 Σ_eff = Σ · (n / n_eff) 做保守膨胀；只有 n_eff ≥ n_min 才允许校准（修正定义 426 的计数口径）。

**定义 444（演示修复证书 DRC）** DRC(s) = (δ_explain, H_s, Π_s, receipts, masks, claims)：
δ_explain 是系统生成、人类可重放的**解释性演示方案**（预期掩码与预期回执）；
每条语言主张必须逐字引用 receipts 或 masks 中的数值/标签；无引用者按定义 423 剥离。
DRC 绑定进 EC.claims，既是审计材料，也是热替换后的可执行回归测试。

**定义 445（分割契约与语义 OOD 门）** 分割器必须报告类条件可靠度 κ(g)、边界带宽与 OOD 分数。
若 L(g)=UNKNOWN 或 OOD 分数超阈值：Known_S(g)=0，禁止应用任何材质物理先验，
H_s 不得包含依赖该材质的假设；必要时发出演示请求或退化。
**分割错误是一等故障**：它经 SNC 进入失败指纹库，并触发对应段/对象的重验。

**定义 446（演示来源与投毒隔离）** 演示必须带操作者/设备签名与时间戳；新演示先进入**影子库**，
在重放与计量一致性检查（预期回执 vs 实际回执、掩码一致性、物理包络）通过后才可晋升为宏。
未晋升演示不得更新校准或技能库；已晋升演示若被后续证据证伪，按 provenance 回溯降权并回滚受影响段。

**定义 447（继承与退化约定）** 令 G = 每个网格格子一个段、L = 已知单材质、v ≡ 0、D = ∅、
回放关闭、分割恒为 Known_S=0 ⇒ **DemoGauge ≡ ToolGauge**。
再令 VLA = ∅、T₀ = {被动观测}、MP-Φ = 物理先验 GP ⇒ ToolGauge ≡ LeanGauge。
因此正确的集成链是 **MODGAUGE ⊃ DemoGauge ⊃ ToolGauge ⊃ LeanGauge**（修正第 2 轮写反的包含关系）。

# IP-321 S-Box：语义分割索引 + 盲区四象限 + 边界纯度
class SBox:
    def update(self, rgbd, R):
        Sigma = self.seg.contract(rgbd)                 # (G,L,B,kappa,ver)，定义 432/445
        self.lut = project_segments_to_cells(Sigma, R)  # O(|R|)，50Hz 只查 LUT
        return Sigma

    def blind_spots(self, Sigma, R):
        for g in Sigma.segments:
            for d in MODALITIES:
                for i in INTERFERENCES:
                    s = Spot(g, d, i, w=Sigma.area(g)/Sigma.area(),
                             C=(Sigma.obj(g), Sigma.L(g), Sigma.ver))
                    s.quadrant = quadrant(cov_n=s.cov, known_s=Sigma.known(g))
                    yield s

    def pure(self, P, g):
        return area(P & g) / area(P) >= 1 - ETA_B   # 定义 435


# IP-322/323 E-Box + DGP：演示方案编译为宏，程序只在演示流形内适配
class EBox:
    def compile(self, delta):                        # human / scripted / system
        return Macro(template=abstract(delta.pi),
                     Pre=delta.E_pre, Eff=delta.E_post,
                     Theta=envelope(delta.pi.params),
                     support=1, sig=sign(delta))

    def retrieve(self, s, H, k=3):
        return ann_topk(self.D, feat(s, H), k, max_dist=EPS_DEMO)

    def explain(self, s, H, prog, receipts):         # 生成可重放解释
        return DemoPlan(prog, expected_masks(H), expected_receipts(receipts),
                        prov=self.version)

class DGP:
    def synthesize(self, s, H, ebox, tools):
        ms = ebox.retrieve(s, H)
        if not ms:
            return DemoRequest(s, H, missing=missing_skill(s), budget=B_DEMO)
        prog = adapt(ms[0], H, tools)                # 只在 Theta_m 内改参数
        if not self.grounded(prog, s, ebox):
            return NUMERIC_FALLBACK                  # 退化到 ToolGauge 数值探测
        return prog

    def grounded(self, prog, s, ebox):
        return (prog.dist <= EPS_DEMO and
                prog.params in prog.macro.Theta and
                masks_match(prog.pred_pre, s.Sigma) and
                masks_imply(prog.pred_post, prog.macro.Eff))


# IP-324/325 SD-Cal：对象/段解耦摊销校准 + 语义不相交交叉验证
class SDCal:
    def calibrate(self, receipts, H, s, Sigma):
        v = self.mp_phi_obj(feat_obj(receipts, Sigma.obj(s)))   # 物体共享潜变量
        u = self.mp_phi_res(feat_seg(receipts, s, H))           # 段残差
        Sig = clamp_min(covariance(v, u), KAPPA_PHYS)
        return compose(v, u), Sig

    def cross_validate(self, mu, Sig, r, s, Sigma):
        if not (disjoint(s.g, r.g) and
                Sigma.obj(s) != Sigma.obj(r) and r.d != s.d):
            n_eff = n / (1 + (n - 1) * rho_hat(Sigma))          # 定义 443
            Sig = inflate(Sig, n / max(n_eff, 1.0))
        z = (r.mu - mu) / sqrt(Sig + r.var)
        return abs(z) <= EPS_CROSS

## 3. 推导

**引理 51（段细化保持覆盖不变式）** 设网格 {c} 是工作空间的有限划分，Σ 的段集合 G 细化该划分。
对任意格子 c 与任意 (d,m,i)，若所有 g ⊆ c 都满足 Cov(g,d,m,i)，则 Cov(c,d,m,i)；
反之不成立。若边界带总面积占比 ≤ η_b，则段级覆盖到格子级覆盖的测度误差 ≤ η_b。
证明：覆盖定义对子区域可加；边界带是未覆盖测度的上界。系：S-Box 不削弱 D-Box 的安全不变式，
只增加定位分辨率；而格子覆盖**不能**推出段覆盖（跨材质格子是混合观测）。

**引理 52（边界纯度的校准偏差界）** 设探测足迹 P 内材料混合权重为 a_k，主材质 k=1，
purity = a_1 ≥ 1 − η_b；材质响应差 |f_j − f_1| ≤ Δ，噪声方差差 ≤ Δ_σ。
若校准器按主材质建模，则
|E μ̂ − μ_1| ≤ 2 η_b Δ，额外方差 ≤ η_b (Δ_σ + Δ²)。
故取 η_b ≤ ε_b/(2Δ) 可把系统偏差压到 ε_b。证明：加权平均展开并控制一阶余项；
投影估计器的残差至多再引入一个 η_b Δ 项。系：定义 435 的纯度门槛有明确物理含义，不是经验阈值。

**引理 53（演示接地编程的安全包络）** 设宏参数包络 Θ_m 为凸集，物理可行域 F = {θ : g(θ) ≥ 0}，
且 ∀θ ∈ Θ_m，g(θ) ≥ m_0；g 为 L-Lipschitz。DGP 输出 θ̂ 满足 d(θ̂, Θ_m) ≤ ε_demo。
若 m_0 > L ε_demo，则 g(θ̂) > 0。概率版：若演示本身以概率 1−δ 可行，则
P(适配程序失败) ≤ δ + L ε_demo / m_0。
证明：三角不等式 g(θ̂) ≥ g(θ_m) − L d(θ̂, θ_m)。系：演示接地把 VLA 的开放世界编程变成有界适配，
ε_demo 是可审计的安全旋钮；ε_demo 越大，允许的创新越多，失败上界越松。

**引理 54（对象级误差地板）** 在定义 441 下，同物体 O 的段误差 e_s = e_O + ε_s，
其中 e_O 为共享偏差、ε_s 为段残差。若 ε_s 独立、方差 σ_res²，e_O 方差 σ_obj²，则
n 个同物体段的池化估计方差 = σ_res²/n + σ_obj²，且当 n → ∞ 时收敛到**地板** σ_obj²；
同物体任意两段的协方差 = σ_obj²。
证明：复合误差的方差分解。系：增加同物体段数不能无限降低不确定度；校准精度最终由**物体数**决定。
这正是第 2 轮 AP-Cal 把同物体多段当独立样本时过度自信的根源。

**引理 55（有效样本量与语义不相交交叉验证的可靠性）** 设同组 n 条回执的组内相关为 ρ，
则样本均值的方差为 (σ²/n)[1 + (n−1)ρ] = σ²/n_eff，n_eff = n/(1+(n−1)ρ)。
若 V 阶段忽略相关性、用名义 σ²，则实际检验统计量方差被低估为 c = 1 + (n−1)ρ 倍，
双侧误接受概率由 α 升至 2Φ̄(ε/√c) ≥ α。
采用定义 443 的 n_eff 膨胀后，检验恢复保守性：在 H0 下误接受概率 ≤ α。
证明：独立同分布近似 + 方差膨胀；高斯尾单调性。系：**“数值上不同来源”不等于“统计上独立”**；
语义不相交（不同段、不同物体、不同模态）才是可操作的独立性代理。

        for g in Sigma.segments:
            for d in MODALITIES:
                for i in INTERFERENCES:
                    yield Spot(g, d, i, w=Sigma.area(g)/Sigma.area(),
                               C=(Sigma.obj(g), Sigma.L(g), Sigma.ver))

    def pure(self, P, g):
        return area(P & g) / area(P) >= 1 - ETA_B      # 定义 435


# IP-322/323 E-Box + DGP：演示宏 + 有界适配
class EBox:
    def compile(self, delta):
        return Macro(template=abstract(delta.pi),
                     Pre=delta.E_pre, Eff=delta.E_post,
                     Theta=envelope(delta.pi.params),
                     support=1, sig=sign(delta))
    def retrieve(self, s, H, k=3):
        return ann_topk(self.D, feat(s, H), k, max_dist=EPS_DEMO)

class DGP:
    def synthesize(self, s, H, ebox, tools):
        ms = ebox.retrieve(s, H)
        if not ms: return DemoRequest(s, H, missing=missing_skill(s), budget=B_DEMO)
        prog = adapt(ms[0], H, tools)                   # 只在 Θ_m 内改参数
        return prog if self.grounded(prog, s, ebox) else NUMERIC_FALLBACK
    def grounded(self, prog, s, ebox):
        return (prog.dist <= EPS_DEMO and prog.params in prog.macro.Theta and
                masks_match(prog.pred_pre, s.Sigma) and
                masks_imply(prog.pred_post, prog.macro.Eff))


# IP-324/325 SD-Cal：对象/段解耦 + 语义不相交交叉验证
class SDCal:
    def calibrate(self, receipts, H, s, Sigma):
        v = self.mp_phi_obj(feat_obj(receipts, Sigma.obj(s)))
        u = self.mp_phi_res(feat_seg(receipts, s, H))
        return compose(v, u), clamp_min(covariance(v, u), KAPPA_PHYS)
    def cross_validate(self, mu, Sig, r, s, Sigma):
        if not (disjoint(s.g, r.g) and Sigma.obj(s) != Sigma.obj(r) and r.d != s.d):
            Sig = inflate(Sig, n / max(n_eff(n, rho_hat(Sigma)), 1.0))
        return abs((r.mu - mu) / sqrt(Sig + r.var)) <= EPS_CROSS


# IP-326 DemoGauge-7C
def demogauge_7c(M, s):
    H = M.lbox.hypothesize(s, M.sbox.context(s))          # H
    prog = M.dgp.synthesize(s, H, M.ebox, M.tools)        # C
    if isinstance(prog, DemoRequest):
        M.ebox.enqueue(prog); return stub_and_red(s, "await_demo")
    receipts = M.tcv.execute(prog, M.env)                 # E
    if n_eff(receipts, M.sigma) < n_min(s): return stub_and_red(s, "insufficient")
    mu, Sig = M.sdcal.calibrate(receipts, H, s, M.sigma)  # C
    if not M.sdcal.cross_validate(mu, Sig, M.cross_receipt(s), s, M.sigma):
        return stub_and_red(s, "cross_failed")            # V
    new_ec = M.sdcal.update_contract(M.dpe, mu, Sig, s)   # U
    if not contract_regression(new_ec): return stub_and_red(s, "regression")
    M.mreg.hot_replace(M.dpe, new_ec)
    M.dbox.update_from_posterior(s, mu, Sig)
    d = M.ebox.explain(s, H, prog, receipts)              # D
    bind_claims(new_ec, H, prog, receipts, d)
    if not M.canary.replay(d):                            # 金丝雀
        M.mreg.rollback(M.dpe, s); M.pquar2.trip(obj=M.sigma.obj(s))
        return False
    return True


# IP-326 主闭环
def DemoGauge_round(M, obs, rgbd):
    Sigma = M.sbox.update(rgbd, M.dbox.R)
    for s in M.sbox.blind_spots(Sigma, M.dbox.R):
        if s not in M.inflight:
            M.inflight.add(s); submit_async(demogauge_7c, M, s)
    if M.pquar2.triggered():
        M.sdcal.pause(); M.use_toolgauge = True
    return MODGAUGE_round(M, obs, rgbd)

## 4. 推导

**引理 51（段细化保持覆盖不变式）** 段集合细化格子划分；子段全覆盖 ⇒ 格子覆盖，反之不成立。
边界带占比 ≤ η_b 时，段级到格子级的覆盖测度误差 ≤ η_b。系：S-Box 不削弱 D-Box 安全性，只提升定位分辨率。

**引理 52（边界纯度偏差界）** 主材质纯度 ≥ 1−η_b、材质响应差 ≤ Δ 时，
|E μ̂ − μ_1| ≤ 2η_bΔ，额外方差 ≤ η_b(Δ_σ + Δ²)；取 η_b ≤ ε_b/(2Δ) 即得偏差 ≤ ε_b。
证明：混合权重展开 + 投影估计残差控制。

**引理 53（演示接地安全包络）** Θ_m 凸、物理可行裕度 m_0、可行谓词 L-Lipschitz、适配距离 ≤ ε_demo；
若 m_0 > Lε_demo 则适配程序可行；概率版 P(失败) ≤ δ + Lε_demo/m_0。
证明：三角不等式。系：ε_demo 是可审计的“创新半径”。

**引理 54（对象级误差地板）** e_s = e_O + ε_s，同物体 n 段池化方差 = σ_res²/n + σ_obj²，
n→∞ 存在地板 σ_obj²；同物体段协方差 = σ_obj²。系：校准精度最终由物体数而非回执数决定。

**引理 55（n_eff 与语义不相交可靠性）** 组内相关 ρ 下 n_eff = n/(1+(n−1)ρ)；
忽略相关性会把误接受概率从 α 抬到 2Φ̄(ε/√c)（c>1）。用 n_eff 膨胀后恢复 ≤ α。
证明：方差膨胀 + 高斯尾单调。系：“不同来源”不等于“统计独立”；语义不相交是可操作的独立性代理。

## 8. 本轮最大风险

**一句话**：语义分割会把“材质边界”变成所有校准共享的**混淆变量**——一次系统性分割错误会让段索引、
对象级解耦与“语义不相交”检验同时失效，系统把同一个错误当成多条独立证据，再由演示回放与语言证书
把它包装成“已被验证”的物理事实。
