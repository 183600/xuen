# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 1 轮；本轮灵感：「电池管理」×「力矩传感」）

> R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」。四轮共享一个未言明的前提：**被控对象是一台「永新的机器」**——安全包络是常数，λ_floor 只由感知/决策的不确定性决定，resolution bonus 可以放心把不确定性节约出来的裕度花掉。但真实机器人在**老化**：电池容量衰减、内阻上升，关节摩擦/齿隙增大，力矩传感器随温度与时间漂移。电池管理（BMS）这一整门学科处理的正是这类「不可直接观测、路径相关、临近边界高度非线性」的潜状态，并用**功率降额**换安全；力矩传感则给出唯一能同时看见「即时接触力」与「累计机械载荷」的物理通道。
>
> 核心命题：**安全能力不是常数，而是一个只可部分观测、路径相关、随使用衰减的潜状态 h。把 R69 的二分解升级为三分解 (U_ale, U_epi, U_prog)：U_ale 收紧、U_epi 靠「问人/看/触」消解、U_prog（健康/能力不确定性）只能靠「探机」估计或直接降额，且其安全储备永远不得被任务侧 resolution bonus 释放。** 命名 **VITA-RAS**（Vital-state Informed Torque-Aware Risk-Adaptive Safety）。
>
> 一句话定位：R69 的不确定性可以「问出来」；R70 的不确定性有些**只能「探出来」、有些连探都探不出、只能「留余量」**——不确定性第一次有了「寿命」与「不可逆」的维度。

## 0. 直觉与动机

**灵感 1（电池管理 → 能力是一个电量式的潜状态）**
直觉：BMS 从不直接测 SoC/SoH，它靠等效电路模型 + 观测器从电压/电流/温度反推；而且它永远不把电充到「真实 100%」，总留一段安全余量，因为接近边界时小误差会被非线性放大成热失控。机器人同理：真正的「可用力矩 / 可用能量 / 可用带宽」是不可直接测的潜状态，临近饱和与热限时，估计误差被放大。R69 的 resolution bonus 相当于「把预留的 5% 电量也花掉」——健康时没事，老化时就是事故。→ 安全包络必须 **health-conditioned**。

**灵感 2（力矩传感 → 唯一同时看见「当下」与「消耗」的通道）**
直觉：力矩传感器既测即时接触力（安全），又记录载荷历史（寿命）。电机电流是「电气侧」力矩，关节力矩传感器是「机械侧」力矩；两者之差既可能是传感器漂移，也可能是执行器退化——这正是电池里「容量衰减 vs 内阻上升」需要两个工作点才能分开的同构问题。→ 用双通道把「传感器坏了」和「机器坏了」分开。

**灵感 3（阻抗谱 → 主动探健康，而不是被动等坏）**
直觉：电池用 EIS 注入小幅交流、测阻抗来无损诊断。机器人可注入小幅叠加力矩激励、测关节机械阻抗（摩擦/刚度/阻尼/齿隙）——**机械阻抗谱 MISP**。这把 R69 的「探针」从「探环境歧义」升级为「探自身健康」；但探针本身消耗寿命、有安全风险、也可能被恶意共振利用。→ 探测也要过认证、也要计入损伤预算。

**灵感 4（路径相关 → 不确定性有记忆，也有寿命预算）**
直觉：电池 SoH 依赖充放电深度 / C-rate / 温度历史；关节磨损依赖力矩幅值与循环（雨流计数 + Miner 法则）。健康估计不能是 Markov 的，必须带迟滞/老化状态；「今天多花的力」会减少「明天的安全余量」。安全从静态约束变成**带速率限制的寿命资源分配**：每窗口损伤 ΔD ≤ δ_max，RUL 的不确定性进证书。

**灵感 5（三分解 → R66–R69 是「健康且静止」的切片）**
直觉：不确定性分三类——U_ale（噪声，收紧）、U_epi（任务歧义，问人/看/触）、U_prog（健康潜状态，探机或留余量），分三通道。当 h 健康且已知、且不探测不交互时，VITA-RAS 必须逐指令退化为 R68/R69——**新层仍是旧层的严格泛化**，否则每加一层就多一个需要独立信任的黑箱。这是本轮的理论红线。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（VITA-RAS 总览）** VITA-RAS = (HOB, TCA, MISP, DERATE, LBR, VQA-H, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **健康储备不可释放**：任务侧 epistemic 消解带来的 resolution bonus 只能把 λ 降到 λ_health 为止，绝不动用为健康不确定性预留的储备 ρ；
(iii) **损伤速率约束**：单位窗口累计损伤增量 ΔD ≤ δ_max，探测动作计入损伤；任一违反 ⇒ 强制降额并回 R68 最保守。

**定义 311（潜健康状态 h）** h_t ∈ H = H_elec × H_mech × H_sense，含 SoC、SoH、温度、内阻；关节摩擦、齿隙、刚度/阻尼；力矩/电流传感器偏置与增益。演化 h_{t+1} = F(h_t, u_t, τ_t, T_t, w_t)，F 含老化与迟滞，**路径相关**（同一读数可由不同历史到达，真值却不同）。

**定义 312（健康后验与能力包络）** p(h_t | y_{1:t})；状态-能力 SOP_t = {(τ,v,T) : 在 h 下违规概率 ≤ δ_cap}；鲁棒可信包络 Ê_t = ⋂_{h ∈ H_α(t)} E(h)，H_α 为后验可信集。降额因子 α_t = vol(Ê_t)/vol(E_0) ≤ 1。

**定义 313（电池式健康观测器 HOB）** 快状态（SoC、温度）用等效电路 + 卡尔曼/滑模观测器；慢状态（SoH、摩擦/齿隙）用递推最小二乘 + 老化模型；输出后验与可信集并做校准（ECE）。平坦平台（OCV-SoC 平台区、力矩近饱和区）处 Fisher 信息退化 ⇒ 可信集**非对称**扩张。

**定义 314（力矩双通道一致性 TCA）** 两个力矩估计：τ_m = k_t·i（电气侧）、τ_s（机械侧力矩传感器）。残差 r_τ = τ_m − τ_s 分解为 sensor bias b_s(T)、actuator gain loss、电池压降耦合。可辨识条件：两通道对 (b_s, 退化) 的灵敏度向量线性无关；否则判为不可分，走保守。

**定义 315（机械阻抗谱探针 MISP）** 信息动作 g_p(t) = A sin(ωt) 叠加到任务力矩，A ≤ A_max、ω ∈ Ω_safe、时长 T_p；测 θ̇(t) 得 Z(ω) = τ(ω)/θ̇(ω)，拟合摩擦 f_v、刚度 k、阻尼 c、齿隙 δ_b。成本 = 任务扰动 + 损伤 ΔD_p + 安全风险。

**定义 316（三分解）** U_ale = 模态内噪声；U_epi = 任务歧义（R69）；U_prog = **后果加权**的健康不确定性 = E_{h~p}[d(Ê(h), Ê(ĥ))]，只在「影响能力包络」的方向上计，而非原始熵。三者分通道，不做标量加和。

**定义 317（健康条件风险下限 DERATE）** λ_floor^H = max( λ_RAS(U_ale + 未消解 U_epi), λ_health(Ê_t, ρ_t) )，λ_health 关于能力单调减、关于 U_prog 单调增；ρ_t 为储备裕度（近边界非对称加大）。**resolution bonus 只能压低第一项，不能压低第二项。**

**定义 318（寿命预算调节 LBR）** 雨流计数 + Miner：D_t = Σ_i n_i / N_i(τ_i, T_i)，SoH ≈ 1 − D；RUL = inf{t : D_t ≥ 1}。每窗口 ΔD ≤ δ_max(v,T)；把 λ 的「进取」与 ΔD 挂钩，形成效率–寿命 Pareto。

**定义 319（探针的 VoI）** VoI_h(g_p) = E[U_prog 的后果加权下降] − c(g_p) − β·ΔD_p(g_p)；仅当 > 0 且过认证才探；优先安排在低负载窗口。

**定义 320（探针安全认证）** g_p 过 C-RAS-WM 前缀认证；不得跨越 Ê_t、不得激发危险共振、不得越热/力矩包络；不过则禁止探测，U_prog 直接进降额。

**定义 321（健康校准门 HCG）** 健康后验 ECE > τ_h ⇒ 进入「跛行模式」：取最大降额、禁用探针与 resolution bonus；绝不让不可信的健康模型驱动放行。

**定义 322（健康感知证书 J_VITA）** J_VITA = (J_FLUID, SoH, SoP_margin, U_prog, ΔD_rate, RUL_p10, probe_log_hash, reserve_margin, vita_ver)。Valid ⇔ Valid(J_FLUID) ∧ 储备未越界 ∧ ΔD ≤ δ_max ∧ 健康后验校准。

**定义 323（严格包含链）** h 健康且已知、且不探测不交互 ⇒ VITA-RAS 逐指令退化为 R69；再取消交互 ⇒ 退化为 R68。即 R66–R69 是 VITA 在「健康、静止、无探测」切片上的特例。

**定义 324（探测攻击面 ℰ_probe）** 恶意共振激励、力矩传感器伪造、虚假健康报告、以探针为名的过度磨损攻击；并入 AIC：ℰ_VITA = ℰ_FLUID × ℰ_probe × ℰ_aging。

**定义 325（快慢时间尺度）** 控制环（ms）只用固定下界 λ_health 与 Ê_t；健康更新（s~min）异步、零实时写学习；探针在低需求窗口调度。

**定义 326（探针–降额对偶）** 探针降低 U_prog 从而松开降额；降额换取安全。二者构成「测量–保守」对偶：不能探时保守，能探时按 VoI_h 有节制地探——这是 R69「交互–标定对偶」在健康维度的镜像。

## 2. 关键算法骨架

```python
# IP-264 HOB：电池式健康观测器（快慢分离，零实时学习写）
class HealthObserver:
    def __init__(self, ec_model, aging_model, kf, rls):
        self.ec, self.aging = ec_model, aging_model   # 等效电路 + 老化
        self.kf, self.rls = kf, rls                   # 快状态 / 慢状态

    def step(self, v, i, temp, tau_hist):
        soc  = self.kf.update(v, i, temp)             # 快：SoC/温度
        soh  = self.rls.update(tau_hist, temp)        # 慢：SoH/内阻
        post = self.aging.posterior(soc, soh, temp)   # p(h|y)，带可信集
        return post, credible_set(post, alpha=0.05)

# IP-265 TCA：力矩双通道（电气侧 vs 机械侧）
def torque_dual_channel(i, tau_s, temp, V_bus):
    tau_m = k_t(temp) * i                             # 电气侧
    r     = tau_m - tau_s
    # 分解 bias(T)/gain_loss/压降耦合；可辨识性检查
    if not identifiable(r, temp, V_bus):
        return None, UNSAFE                    # 不可分 → 保守
    return decompose(r), OK

# IP-266 MISP：机械阻抗谱探针（有损伤、需认证、要排程）
def plan_probe(belief_h, envelope, load_window, budget):
    if load_window.is_high_demand(): return None       # 只在低负载窗口探
    cands = [g for g in probe_candidates()             # A,ω,T_p 网格
             if envelope.contains(g) and c_ras_wm.certify(g)]
    best = max(cands, key=lambda g: voi_health(g, belief_h)
                                    - beta * damage(g), default=None)
    return best if best and voi_health(best, belief_h) > cost(best) else None

# IP-267 DERATE：健康条件包络 + 非对称储备
def derate(h_post, H_alpha, U_prog):
    E_hat = robust_envelope(H_alpha)                   # 可信集上的交集
    rho   = reserve_margin(E_hat, h_post)              # 近边界非对称加大
    lam_h = lam_health(E_hat, rho, U_prog)
    return E_hat, lam_h

# IP-268 LBR：雨流计数 + Miner，损伤速率限制
class LifeBudget:
    def __init__(self, miner_table, delta_max): self.tab, self.dmax = miner_table, delta_max
    def update(self, tau_seq, temp):
        self.D += rainflow_increment(tau_seq, temp, self.tab)   # 增量累积
        return self.D, self.rul_p10()

# IP-269/270/274 主闭环（继承 R69，插入健康层）
def VITA_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)   # R68
    # 1) 健康观测（异步；本拍用最近后验）
    h_post, H_alpha = M.hob.latest()
    # 2) 力矩双通道：区分传感器漂移 vs 机器退化
    tau_hat, ok = torque_dual_channel(o.i, o.tau_s, o.T, o.V)
    if not ok: h_post = widen(h_post, H_alpha)                  # 不可分 → 加宽可信集
    # 3) R69 的任务三分解（沿用 FMP/AUD/MINT）
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    # 4) 健康不确定性（后果加权）+ 探针决策
    U_prog = consequence_weighted(h_post, H_alpha)
    E_hat, lam_h = M.derate(h_post, H_alpha, U_prog)
    g_p = M.misp.plan_probe(h_post, E_hat, M.load, M.budget)
    if g_p is not None:
        M.misp.execute(g_p); h_post, H_alpha = M.hob.refresh()
        U_prog = consequence_weighted(h_post, H_alpha)
        E_hat, lam_h = M.derate(h_post, H_alpha, U_prog)
    # 5) 任务交互（R69）——其 bonus 只能压第一项
    g = M.mint.choose_interaction(modes, o, M.budget) if U_epi > TAU_EPI else None
    if g is not None: U_epi_after = M.cia.update_belief(modes, M.cia.execute(g))
    else:             U_epi_after = U_epi
    # 6) 健康条件风险下限 + 寿命速率约束
    lam_task = lam_floor(U_ale + (U_epi_after if g is None else 0.0))
    lam      = max(M.efs.risk_scale(...), lam_task, lam_h)      # 储备不可释放
    if M.lbr.would_exceed(delta_max, lam): lam = max(lam, lam_life)  # 速率限
    A = M.ach.propose(x_prime, H=M.vista.H) & E_hat             # 只在可信包络内
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    # 7) 选模态执行 + 审计/证书
    mode = select_mode(modes, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.lbr.update(tau, o.T); M.vqa_h.submit(g_p, g, h_post, U_prog)
    return k, lam, mode, (U_ale, U_epi_after, U_prog, E_hat)
```

## 3. 推导

**引理 19（健康储备不可释放性）** 设 λ_health 为在可信集 H_α 上保持违规概率 ≤ δ_cap 的最小缩放。若任务侧 resolution bonus 把 λ 压到 λ_health 以下 δ>0，则存在 h ∈ H_α 使该 h 下安全裕度 < 0，于是按后验对该 h 的支撑质量至少有 α 比例贡献正违规概率。故不变式 (ii) 是安全所必需，而非保守偏好：**任务侧的信息不能替代对硬件的了解**。

**引理 20（探针信息–损伤折中）** MISP 对 h 的 Fisher 信息近似 ∝ A²·T_p / σ_θ²（信号能量 / 噪声），而疲劳损伤近似 ΔD ∝ N_cycles·f(A)，f 在疲劳阈值以上超二次增长。故单位损伤的信息增益 ∝ A²/f(A) 在 A* 处取极大（f' > 2f/A 时下降）；给出**内点最优探针幅值**：幅值太小信噪比不足，太大则以寿命换信息且可能损伤。系：探针不是「越强越好」，而是与电池 EIS「小幅信号保线性」同构。

**引理 21（双通道可辨识性）** 传感器偏置 b_s 与执行器增益损失 γ 的可辨识性取决于灵敏度矩阵 S = [∂r_τ/∂b_s, ∂r_τ/∂γ] 是否满秩。若工作点单一（温度/负载无变化），S 近共线 ⇒ 二者不可分，必须加宽可信集并保守；若有两个以上工作点（不同温度/负载），det S 有下界 ⇒ 可分离。这解释了「以探针制造第二个工作点」为何能救可辨识性。

**引理 22（路径依赖的反例）** 存在两条载荷历史 H1≠H2，使传感器快照 y 相同但真实 SoH 不同（高幅短时 vs 低幅长时，Miner 累积可比但微观损伤机制不同）。任何仅基于 y_t 的 Markov 观测器给出同一估计，误差 ≥ |SoH(H1)−SoH(H2)|。故 h 必须含老化/迟滞状态，HOB 必须递推而非快照——这是「电池式」建模不可省的核心理由。

**引理 23（平台区不可观测放大）** 在 OCV-SoC 平台区或力矩近饱和区，Fisher 信息 J(x) → 0，可信区间宽 ~ 1/√J 发散。因此同样大小的测量噪声在边界处被放大为更大的能力估计误差；储备 ρ_t 必须是**非对称**的（向危险侧加得更多），这直接支撑定义 317 的非对称 λ_health。

**定理 18（VITA 严格包含 R69 与 R68）** 在健康、已知、无探测时，λ_health ≤ λ_floor^RAS（储备为 0），故 VITA 的 λ 与 R69 相同、指令逐条一致；再令 VoI 永不交互则退化为 R68。健康退化或 U_prog 升高时 λ_health 单调上升，故任意状态风险 ≤ R69。R66–R69 是把 h 固定为「健康常数」的切片。

**定理 19（探针安全与无突变）** g_p 经 C-RAS-WM 认证且限制在 Ê_t 内，则物理风险 ≤ ε_p；探针只更新健康后验，不改变当前安全包络的连续性；探针失败/超时/被投毒时 λ_health 单调不降地退化；换装不变式（R68 定理 15）保持 ⇒ 控制连续、无突变。

**定理 20（损伤速率给出 RUL 下界）** 若每窗口 ΔD ≤ δ_max 且 D_t 为当前累计损伤，则至少还能撑 ⌈(1−D_t)/δ_max⌉ 个窗口；取最坏老化模型与可信集上界，得 RUL_p10 ≥ (1 − D_t^upper)/δ_max − slack。故 δ_max 是一个可审计的「寿命安全系数」，把效率–寿命折衷变成显式约束。

## 4. 复杂度分析

## 6. 本轮最大风险

**一句话**：VITA-RAS 的全部安全论证都押在「健康观测器的老化模型是对的、且力矩双通道能把传感器病与机器病分开」这一前提上——**一旦老化模型失配（等效电路/ Miner 表在真实损伤机制外失效），系统会用一个自信的错误 SoH 去计算储备：要么长期过度降额把可用能力浪费掉，要么更糟，在临近边界时把「模型以为还剩的余量」当成真余量释放，并用证书把模型误差洗成「已验证安全」；而主动探针还会一边消耗寿命、一边把错误模型拟合得更自信**——**用错误的尺子量寿命，比不量更危险**。

## 4. 推导

**引理 19（健康储备不可释放性）** λ_health 为可信集 H_α 上保持违规概率 ≤ δ_cap 的最小缩放。若任务侧 bonus 把 λ 压到 λ_health 以下 δ>0，则存在 h∈H_α 使该 h 下安全裕度 < 0，按后验其支撑质量 α 贡献正违规概率。故「任务信息不能替代硬件了解」，不变式 (ii) 是安全必需。

**引理 20（探针信息–损伤折中）** MISP 的 Fisher 信息 ∝ `A²T_p/σ_θ²`，疲劳损伤 ∝ `N·f(A)`（f 超二次）。单位损伤信息增益 `∝ A²/f(A)` 在 `A*` 取极大 ⇒ 内点最优探针幅值：太小信噪比不足，太大以寿命换信息。与电池 EIS「小幅信号保线性」同构。

**引理 21（双通道可辨识性）** 偏置 b_s 与执行器损失 γ 可辨识 ⇔ 灵敏度矩阵 `S=[∂r_τ/∂b_s, ∂r_τ/∂γ]` 满秩；单工作点近共线 ⇒ 不可分、必须加宽可信集；两个以上工作点 ⇒ det S 有下界、可分离——这解释了「探针制造第二工作点」为何能救可辨识性。

**引理 22（路径依赖反例）** 存在 H1≠H2 使传感器快照 y 相同而真实 SoH 不同；任何仅用 y_t 的 Markov 观测器误差 ≥ |SoH(H1)−SoH(H2)|。故 h 必须含老化/迟滞递推状态。

**引理 23（平台区不可观测放大）** 平台区/近饱和区 Fisher 信息 `J(x)→0`，可信区间宽 `~1/√J` 发散；同噪声在边界放大为更大能力估计误差，故储备 ρ_t 必须向危险侧非对称加大。

**定理 18（VITA 严格包含 R69 与 R68）** 健康、已知、无探测时 λ_health=0 贡献，VITA 与 R69 逐指令一致；令 VoI 永不交互则退化为 R68。退化/U_prog 升高时 λ_health 单调上升 ⇒ 任意状态风险 ≤ R69。R66–R69 = 「健康常数切片」。

**定理 19（探针安全与无突变）** g_p 过 C-RAS-WM 认证且限制在 Ê_t 内 ⇒ 物理风险 ≤ ε_p；探针只更新后验、不改安全包络连续性；失败/超时/投毒时 λ_health 单调不降退化；换装不变式保持 ⇒ 控制连续、无突变。

**定理 20（损伤速率给出 RUL 下界）** 若每窗口 ΔD ≤ δ_max、当前累计 D_t，则至少还能撑 `⌈(1−D_t)/δ_max⌉` 个窗口；取最坏老化模型与可信集上界：`RUL_p10 ≥ (1−D_t^upper)/δ_max − slack`。δ_max 是可审计的寿命安全系数。

## 7. 本轮最大风险

**一句话**：VITA-RAS 的全部安全论证都押在「老化模型正确、且双通道能把传感器病与机器病分开」上——**一旦老化模型失配，系统会用一个自信的错误 SoH 计算储备：要么长期过度降额浪费能力，要么更糟，在临近边界时把「模型以为还剩的余量」当成真余量释放，并用证书把模型误差洗成「已验证安全」；主动探针还会一边消耗寿命、一边把错误模型拟合得更自信**——**用错误的尺子量寿命，比不量更危险**。

**次级风险与缓解**：探针致损/致险（定义 315/320 认证 + 定理 19 + E307）；双通道不可辨识（引理 21 判据 + 加宽可信集 + 制造第二工作点）；路径依赖被 Markov 化（引理 22 + 老化状态递推 + E309）；平台区非线性放大（引理 23 + 非对称储备 + E310/E311）；健康模型失配假放行（HCG 跛行 + 证书保留 + E313/E316，宁可不放行也不放错）。
