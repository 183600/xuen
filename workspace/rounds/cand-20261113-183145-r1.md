# 第 67 轮（新灵感驱动研究循环 第 2 轮；本轮灵感词：「机械臂抓取」×「真机评测」）

> 承接第 66 轮：v1 把赌注押在「仿真编译五轴场景」上，回答了「训练分布怎么来」，但没有回答两个更基本的问题——(1) 32 个任务的成功到底由哪一个共享能力决定？(2) 我们凭什么相信有限次真机评测给出的分数？本轮的灵感词正好各戳一个洞：**「机械臂抓取」指向成功率的共同物理瓶颈，「真机评测」指向测量本身的统计瓶颈。** 因此本轮不再加一条仿真管线，而是把 v1 的清单按「抓取中心」与「评测统计」两条轴重新配平（产物区 v2；新增 C11/C12，合并 C06/C07，C02/C08 深化）。

## 0. 本轮新增假设与核实边界（检索日期沿用 2026-11-13）

1. 官方事实沿用第 66 轮：32 任务 / 32k 演示 / 169h / 五类泛化 / 平均成功率 + 步骤分；4 路 RGB；双臂 7-DoF；接口按 chunk 返回动作。
2. **A1（末端执行器）**：数据集命名 `G1_Dex1_*` 与提交 README 的「夹爪」维度暗示桌面任务使用 1-DoF 平行夹爪或简化的 Dex1 手；本轮按「单自由度开合 + 腕部 6-DoF」建模抓取。若实际为多指灵巧手，C11 的抓取位姿空间需从 SE(3)+开度扩展到手指关节，结论方向不变、实现变重。
3. **A2（真机可达性）**：C12 的完整形态要求团队至少有 1 台 G1 或稳定的真机评测槽；若没有，C12 退化为「用官方返回的少量结果做序贯决策 + 用仿真/离线数据做控制变量校准」，不能凭空创造真机样本。
4. **A3（步骤分语义）**：假设步骤分随任务进展单调增加、不是纯时间惩罚；若步骤分等价于「越短越好」，则 C08 的抢救重试与 C12 的序贯延长都要改符号。这是必须在飞书规则手册核对的第一件事。
5. **A4（任务分类）**：并非 32 个任务都以抓取为前提（推盘/排列类可能是非抓取接触）。本轮用 α 表示「成功必须经过抓取」的任务比例，并把它作为 E-C09 要测的量，而不是先验常数。

## 1. 直觉解释（两个灵感如何咬合）

**直觉 1：抓取是 32 个任务之间唯一的「共享物理货币」。** 把 32 个任务摊开看，它们的语言指令、目标容器、接触序列都不同，但大多数共享同一条骨架：接近 → 对准 → 闭合夹爪 → 抬起/搬运 → 放置/操作。32,000 条演示因此不只是 32 个任务的 32 份数据，而是**三万多次成功交互，其中大多数包含一次成功抓取**；物体外观、初始位姿、背景、干扰物都已经在其中出现过。赛题五轴里的「未见物品」本质上就是抓取的分布外测试。更关键的是失败归因：我们押注大多数任务失败的主要断点不是「不知道去哪」，而是「没抓稳/没抓对」。所以抓取是一个**跨任务可迁移、且边际收益极高**的低层能力，v1 却把它留给端到端 VLA 隐式学习，这是最大的浪费。

**直觉 2：真机评测不是裁判，而是一个高方差的测量仪器。** 评测分数是「在未知任务×场景分布上对成功率的平均」。每个任务只有少量试验，而任务间成功率差异很大、场景间失败率重尾（少数场景贡献多数失败）。在这种条件下，直接用少量真机试验的均值做模型选择，会同时遭遇两件事：置信区间很宽，以及「赢家诅咒」——你选中的策略可能只是这次抽样运气好。于是出现一个反直觉结论：**在真机预算固定的比赛里，提升「评测的统计效率」与提升「策略的真实成功率」同等重要。** 而抓取质量恰好是一个在每次试验开始前就能算出的协变量：如果它能预测本集成败，就可以当控制变量（control variate）把真机评测的方差压下去。

**合流直觉：让同一个抓取质量模型，既做训练信号，又做评测仪器。** 训练侧，它把「抓取成功/失败」从稀疏的 episode 标签变成每个 chunk 都能用的稠密信号，并驱动重抓/抢救；评测侧，它是与结果相关、但不需要额外真机成本的协变量，用来降低成功率估计的方差。抓取因此从「一个技能」升级为「训练与评测共用的测量基」。

## 2. 严谨定义

**定义 1（评测分数）**：任务集 T，|T|=32；任务 t 的场景分布 D_t；策略 π；单集成功指示 S(π;t,s)∈{0,1}，步数 N(π;t,s)∈[0,H]。评测分数
J(π) = w1·(1/|T|)Σ_t E_{s~D_t}[S] + w2·(1/|T|)Σ_t E_{s~D_t}[N]/H。
w1,w2 未公开；A0 下榜首 <30% 意味着第一项是主战场。

**定义 2（抓取事件与成功分解）**：G(π;t,s)∈{0,1} 表示本集是否发生一次「稳定抓取」（闭合后抬升/搬运未脱落）；M(π;t,s)∈{0,1} 表示抓取后的操作是否完成。对抓取型任务，S = G∧M。由条件概率恒等式，
P(S)=P(G)·P(M|G)。
这个恒等式是 C11 的全部理由：抓取头只能抬 P(G)，后抓取规划只能抬 P(M|G)；两者的边际收益相乘，而 P(G) 是跨任务共享的，所以**先修共享项、再修任务特异项**在预算上更优（命题 4）。

**定义 3（抓取质量预测器）**：q_φ(o,g)∈[0,1]，输入接口允许的 4 路 RGB、本体、候选抓取位姿/开度 g，输出该抓取在抬起后仍稳定的概率。训练集由三部分组成：演示中的成功抓取（正样本）、TwinCal 可信域内对抓取位姿/时机做反事实扰动得到的负样本、以及本地真机失败日志（若 A2 成立）。q 不要求是新架构，可以是 VLA 特征上的轻量头。

**定义 4（真机评测的控制变量估计）**：对第 i 次真机试验，观测 S_i 与试验前可计算的 q_i（冻结的抓取头对本次候选抓取的预测）。设 μ=E[q] 可由大规模仿真/离线数据预先估计。控制变量估计
\hat J_cv = \bar S − β(\bar q − μ),  β* = Cov(S,q)/Var(q)。
则 E[\hat J_cv]=E[S]，Var(\hat J_cv)=Var(S)(1−ρ²)/n。**有效样本倍率 = 1/(1−ρ²)**：ρ=0.5 → 1.33×，ρ=0.7 → 1.96×，ρ=0.8 → 2.78×。这把「抓取头准不准」从一句工程判断变成一个可验收的统计量（E-C10）。

**定义 5（抓取门控策略）**：在每个 chunk 调用时刻，若 q_φ < τ 或抓取阶段预测为「未对准」，则返回短块并切到 re-approach/re-grasp 技能；否则按长块执行。门控是 fail-open 的：q 不可用时回退基座策略，不阻断任务。

**定义 6（评测感知的模型选择）**：候选策略集合 Π；用分层（按任务×场景轴）序贯试验分配真机槽，以固定错误率识别最优臂（best-arm identification），而不是对每个候选跑满固定次数。C12 给出分层 Neyman 分配与 SPRT/sequential halving 的组合。

## 3. 本轮核心命题

> **把「抓取质量」做成跨任务共享的测量基：训练侧用它把 32k 演示里的抓取先验显式化，直接攻「未见物品/位置」两轴并驱动重抓抢救；评测侧用它作为真机成功率的控制变量，把有限的真机试验放大 1/(1−ρ²) 倍。抓取不只是要学的技能，还是我们用来「看见」自己分数的仪器。**

## 4. 对 v1 的修剪（只动结构，不重开清单）

- **深化 C02 TwinCal**：验收从「整条轨迹末端误差」改为「抓取接触段误差」为主指标。整条轨迹误差会被自由空间的准确运动稀释，恰好掩盖最要命的接触偏差。
- **深化 C08 SalvageChunk**：把「扰动后切短块」扩展为「抓取门控重试」：q 低 → 先 re-approach 再闭合；q 高但闭合后滑移 → retreat-re-grasp。目标同时抬成功率与步骤分（命题 4）。
- **合并 C06 StereoPrior → C11**：双目深度不再单列，降级为抓取头的辅助输入与候选抓取预筛选；保留「静默降级」原则。
- **降级 C07 CrossPhys**：从独立创新点降为 C11 负样本生成与 C12 不确定性特征的诊断工具；不再单独占实验主线。
- **保留 C01/C03/C04/C05/C09/C10**：C01 场景编译器仍是数据工厂；C03 课程吸收 C12 的评测反馈；C04 提供恢复段；C05 是学生基座；C09 是部署底座；C10 是预演门。C09 的工程优先级不降（N 端口与延迟是硬约束）。
- **新增 C11 GraspCore、C12 EvalCV**（编号续写，不重排）。

## 5. 本轮最大风险（一句话）

**如果抓取质量预测器在真实评测分布上与 episode 成功只是伪相关（例如它只学会了「物体是否在训练集里见过」，而不是「这次抓取是否稳」），那么 C12 的方差缩减会制造虚假的置信度，让我们用更少的真机试验更自信地选错策略——这比不缩减方差更危险。**

（次级风险：A1 末端执行器判断错误会让 C11 的位姿空间建模返工；A2 无本地真机则 C12 只能半实现；A3 步骤分语义若为纯时间惩罚，C08/C12 的符号要改。）

## 1. 评分分解与「抓取中心」假设

J = w1·平均成功率 + w2·平均步骤分。对抓取型任务 S=G∧M，故
E[S] = E[G]·E[M|G]（恒等式；把 P(M|G) 视为给定场景的稳定量时，ΔE[S]≈E[M|G]·ΔE[G]）。
设计要求：
- 若 α 为「成功必须经过抓取」的任务比例，则抓取模块的边际收益 ≈ α·(1/|T|)Σ_{t∈grasp} P(M_t|G)·ΔP(G)。
- 因此 C11 的优先级取决于 α 与 ΔP(G)；E-C09 先测 α 与基线抓取成功率，再决定是否把 C11 提到第一优先级。
- 对非抓取任务（推/排/擦等），C11 退化为「接触事件质量」或直接用 C05 基座；不强行套抓取。

## 2. 创新点详表（C01~C12）

### IP-C11 GraspCore：跨任务抓取质量与门控（★ 本轮新增、第一优先）
- **动机**：32k 演示 = 三万多次含成功抓取的交互；抓取是跨任务共享的低层货币；「未见物品」轴本质是抓取 OOD；失败多发生在抓取而非自由空间运动。
- **差异**：与 GG-CNN/GraspNet 类「单物体 6-DoF 抓取检测」不同（记忆，未逐一复核），本点不追求通用抓取检测，而是：(a) 以比赛 4 路 RGB + 本体 + 双臂可达性为输入；(b) 输出「抓取稳定概率 + 接触阶段 + 可达性」三件事；(c) 正样本来自官方演示，负样本来自 TwinCal 可信域内的反事实扰动，形成「同分布正样本 + 受控负样本」的校准集；(d) 同一头在部署时当门控，在评测时当控制变量。
- **可行性**：中高。轻量头挂在 VLA 特征上；深度用 C06 的 SGBM/轻量匹配兜底；负样本生成复用 C01。
- **资源**：2–3 GPU-天训练 + 1 人周负样本管线；无新硬件。
- **步骤**：①从演示对齐抓取时刻（夹爪闭合 + 抬升）②构建正样本与反事实负样本（位姿平移/旋转/时机偏移/遮挡）③训练多任务头（稳定概率、接触阶段、可达性）④接入 C08 门控与 C05 辅助损失 ⑤在 E-C09 上验收。
- **风险**：演示只有正样本 → 校准依赖仿真负样本；若 TwinCal 对某任务不可信，该任务的负样本也禁用（fail-closed 到基座）。

### IP-C12 EvalCV：真机评测的控制变量与分层序贯设计（★ 本轮新增）
- **动机**：真机槽稀缺、单任务试验少、场景失败重尾；直接用均值做模型选择会宽 CI + 赢家诅咒。抓取质量 q 是试验前可得的协变量。
- **差异**：常规真机评测固定次数、报告均值±CI；本点把评测当实验设计：(a) 控制变量降方差（有效样本 ×1/(1−ρ²)）；(b) 按任务/轴分层，Neyman 分配；(c) 序贯 halving/SPRT 提前淘汰差臂；(d) q 必须冻结/交叉拟合，防止在同一批真机上泄漏。
- **可行性**：中高。离线部分（分层/序贯）可用历史结果 bootstrap 先验证；控制变量需要 A2 的真机或官方返回的逐集结果。
- **资源**：无额外硬件；1 人周统计实现 + 少量真机槽。
- **步骤**：①冻结 q（C11）②在独立小样本上估 ρ、β*、μ ③分层 Neyman 分配试验 ④序贯停止规则 ⑤输出校正后的 \hat J_cv 与选择决策。
- **风险**：ρ 低或伪相关 → 方差缩减失效甚至制造虚假置信；ρ<0.4 时强制退回普通均值 + 全量试验。

### IP-C01 ScenarioForge：五轴场景编译器（保留）
- **v2 增量**：为 C11 生成「同物体、不同抓取位姿/遮挡/时机」的反事实场景；场景编译输出同时带特权抓取真值，供 C11 负样本自动标注。
- **其余不变**：一份 SceneSpec DSL，双后端（Gazebo 系统在环 + MuJoCo 数据工厂）；场景轴仍是约 4/5 权重的主要杠杆。

### IP-C02 TwinCal：数字孪生标定与验收（深化）
- **新验收主指标**：抓取接触段重放误差——夹爪闭合前 0.5s 到闭合后 1s 内物体相对腕部的位姿误差；整轨迹末端误差只作辅助。
- **trust 拆两档**：scene_trust（位置/背景/干扰物）与 contact_trust（抓取/插拔/柔性）。C11 负样本只用 contact_trust 高的任务；两档可分离，避免「背景对齐好」被误当成「接触可信」。
- **资源**：在 v1 的 1–2 人月上增加约 1 人周接触段标注。

### IP-C03 Axis-Bandit：任务 × 泛化轴课程（保留并接入 C12）
- **v2 增量**：真机槽反馈从「每臂跑满」改为「分层序贯」；C12 的停时规则作为 bandit 的观测预算控制器。bandit 的后验同时使用 \hat J_cv，降低每槽噪声。
- **其余不变**：Thompson 采样；若平台只返回总分则退化为 A0 静态配比。

### IP-C04 HumanPerturber：人为干扰预演与恢复数据（保留）
- **v2 增量**：恢复段与 C11 的「抓取失败→重抓」配对，形成「扰动导致掉物→re-grasp」的专门片段；服务 C08 的门控重试。

### IP-C05 SimDistill：特权教师 → 接口学生（保留）
- **v2 增量**：C11 的抓取头作为辅助任务/辅助损失挂在学生特征上；学生输入仍严格是接口允许的 4 路 RGB + 本体，不用特权状态。
- **其余不变**：开源 VLA + 动作块头；数据配比由 C03 控制。

### IP-C06 StereoPrior：双目免费度量深度（并入 C11）
- **v2 定位**：不再单列为主线，作为 C11 的深度输入与候选抓取预筛选；SGBM 零训练兜底，失败静默降级回 RGB。E-C04 仍保留，但指标改为「对抓取成功率的增益」。

### IP-C07 CrossPhys：多引擎分歧（降级为诊断）

def control_variate_estimate(S, q, mu, beta=None):
    S, q = np.asarray(S), np.asarray(q)
    if beta is None:
        beta = np.cov(S, q, ddof=1)[0, 1] / np.var(q, ddof=1)
    return S.mean() - beta * (q.mean() - mu), beta

def stratified_neyman(tasks, pilot):
    # 每任务 pilot 方差估计；按 n_t ∝ N_t * sigma_t / sqrt(cost_t) 分配
    sigma = {t: np.std(pilot[t]) for t in tasks}
    w = {t: len(pilot[t]) * sigma[t] for t in tasks}
    return {t: max(N_MIN, int(N_TOTAL * w[t] / sum(w.values()))) for t in tasks}

def sequential_select(policies, evaluate_one, delta=0.05):
    # successive halving + 配对比较；每轮淘汰下界最差的一半
    alive = list(policies)
    while len(alive) > 1:
        scores = {p: [evaluate_one(p) for _ in range(R_PER_ROUND)] for p in alive}
        # 用 C12 的控制变量均值排序，而不是原始均值
        ranked = sorted(alive, key=lambda p: cv_mean(scores[p]), reverse=True)
        alive = ranked[:max(1, len(ranked) // 2)]
    return alive[0]

## 4. 推导：三条小命题

**命题 3（控制变量的有效样本倍率）**：设第 i 次试验的成功 S_i 与试验前协变量 q_i 满足 E[q]=μ 已知，β*=Cov(S,q)/Var(q)。则 \hat S_cv = \bar S − β*(\bar q−μ) 无偏，且 Var(\hat S_cv)=Var(S)(1−ρ²)/n。证明：标准最小二乘投影；残差 S−β*(q−μ) 与 q 正交，方差为 Var(S)(1−ρ²)。推论：ρ=0.7 时有效样本约 1.96×；ρ=0.5 时仅 1.33×，不值得增加实现复杂度——这给出 C12 的启用阈值（ρ≥0.6）。
注意：若 μ 也用同批样本估计，需用样本均值并损失 1 个自由度；若 q 依赖历史结果（自适应），必须交叉拟合，否则 β 有偏、方差估计过于乐观。

**命题 4（抓取优先的边际收益）**：对抓取型任务 S=G∧M，恒有 P(S)=P(G)P(M|G)。设共享抓取模块把 P(G) 提升 Δ，任务特异后抓取模块把 P(M|G) 提升 δ_t。则一阶增量
ΔJ_grasp ≈ (1/|T|)Σ_t P(M_t|G)·Δ，  ΔJ_post ≈ (1/|T|)Σ_t P(G_t)·δ_t。
因为 P(M_t|G) 在多数任务上已不低（演示本身就是成功抓取后的操作），而 P(G_t) 可能是瓶颈，所以早期预算应先投共享 Δ；当 P(G) 接近饱和后，再投任务特异 δ_t。这解释了 C11 的优先级，也给出「何时停止投抓取头」的判据：当抓取头的边际收益/成本低于任务特异项时切换。

**命题 5（分层序贯的样本节省，定性）**：若候选臂之间差异为 Δ、单臂方差 σ²，固定 n 的成对比较需要 n ∝ σ²/Δ² 才能以给定功效分辨；successive halving 在差臂 early-stop 下期望样本数可显著低于固定方案（理想条件下约 1/log K，K 为候选数），且控制变量把 σ² 换成 σ²(1−ρ²)。两者相乘给出 C12 的「有效预算」上界；实际节省需 E-C11 用历史结果 bootstrap 校准，不能直接引用理论上界。
