## 1. 三个灵感的第一性原理

### 灵感 1 ·「SLAM」的未兑现承诺：只估不动 = 新的单点故障

第 3 轮的 P10「先估后动」把「现在在哪、目标是谁、卡没卡住」显式化，方向正确；但它有一个**反讽的结构缺陷**：若断言/伺服/介入都必须先经过状态层，那么一个低频、可能失效的估计模块就成了整条执行链的**强制闸门**。SLAM 在移动机器人里的真正教训不是「先建图再走」，而是 **VIO 与控制器同时跑、互为闭环**——估计服务控制，控制回馈估计。

- **从「门」到「先验源」**：状态层不再返回「通过/不通过」的单值裁决，而是返回一个**先验分布** `(x̂, Σ, Ẑ, Σ_cal)`；高频控制可以在特征空间直连，只借用这份先验。P10 需要加一条显式例外——**特征旁路**（P13）。
- **精度需求的分离**：断言（U17 卡方）要求位姿误差 ≤ 容差/3；但 IBVS 只要求**相对深度误差 ε≤20%**（L14）。这是一个被第 3 轮混同的关键区别：**同一份估计不该同时满足两种精度需求**，而应双率分工。
- **失效可退化**：状态层失效时，内环退化为纯图像伺服（仍能收敛），而不是整链停摆——这比第 3 轮的 Level-1.6（退回固定阈值断言）更细一级。

**策略含义**：第 3 轮给出了「状态」，本轮把状态接进控制回路，**消解「感知延迟」这个第 3 轮自登记风险**——慢估计不再阻塞快控制。

### 灵感 2 ·「视觉伺服」的第一性：把误差放回特征空间

视觉伺服的核心不是「用摄像头控制」，而是**在一个标定鲁棒的空间里定义误差**：

- **IBVS（图像空间）**：误差 `e = s − s*` 直接是特征误差；增益 `v = −λ L̂_s⁺ e`。优势：不吃相机/手眼标定误差、不吃位姿估计误差；劣势：交互矩阵 `L_s` 依赖深度 `Z`，且可能有相机后退/局部极小。
- **PBVS（位姿空间）**：误差在笛卡尔位姿；优势：路径直、无深度耦合；劣势：**完全继承位姿估计误差 Σ**——而任务容差往往与 Σ 同量级（最后一厘米），这正是第 3 轮的弱点。
- **互补性定理式的直觉**：IBVS 的软肋（深度）恰是状态层的强项；PBVS 的软肋（位姿误差）恰是 IBVS 的强项。**两者不是二选一，而是按「哪种不确定度占主导」调度**（U20）。

**策略含义**：第 3 轮把「最后一厘米」交给伺服只是口号；本轮给出可执行的误差空间选择——**位姿可信时用 PBVS 走近路，位姿不可信/进入容差邻域时切 IBVS 做精对齐**。

### 合成 ·「SLAM × 视觉伺服」= 双率嵌套环（外环估计 / 内环伺服）

- **定义直觉**：外环慢（0.5–2 Hz，SLAM/场景图，产深度+协方差+失效门限）；内环快（15–30 Hz，特征伺服，产动作）。内环把特征轨迹回馈给外环作测量更新，外环把深度先验与「信任半径」下发给内环。
- **为什么现在做**：榜单 F3 证明最难的正是插入/对齐任务；F4 证明可以放心多花步数收敛（分数不看时长）；F5 证明失败模式异质、需要按任务切换伺服体制。三条实测证据同时指向控制层。
- **与第 3 轮的关系**：不是替换，而是**把 IP-13 从「断言的地基」扩展为「伺服的先验源」**，并新增内环 IP-16 与残差看门狗 IP-17。

## 3. 设计原则（新增 P13–P15；修订 P10/P12）

- **P13（特征旁路）**：高频控制允许直接消费图像特征，状态层只作为**深度/标定先验与失效门限**而非强制闸门；旁路必须由 L14 的深度精度门槛守护（ε≤ε_max），且旁路状态必须可观测（残差看门狗在线）。
- **P14（双率解耦）**：状态估计与控制频率解耦；慢估计不得阻塞快控制；两者各自独立退化（状态层失效→纯 IBVS；特征失效→退回 PBVS/路标）。
- **P15（精度优先于省步，修订 P12）**：由 F4 实测，分数由成功率/进度主导、时长几乎不相关；因此在**硬步数上限内**应优先保精度/收敛，把步数账从「评分目标」降级为「硬约束」。（第 3 轮 P12/L12/L13 的记账逻辑保留，但只在接近步数上限时生效。）
- **修订 P10（先估后动的例外）**：原文「任何断言/伺服/介入不得直接消费原始像素」改为「**断言与介入**必须经状态层；**伺服**可按 P13 特征旁路直连，但必须携带先验并受 L14 门限与 IP-17 看门狗约束」。

## 5. 本轮最大风险

**过期/有偏的先验被高频内环当作真值放大——「自信的错误收敛」**：外环若给出偏差较大的深度或位姿先验，IBVS 会在错误的特征几何上平稳收敛，残差看起来在下降（因为误差是在错误的 Σ 下归一化的），系统比「慢」更危险地「自信地做错」；切换抖振是其次要形态。对冲：①P13 要求旁路必须带可观测残差；②L14 深度门槛把 ε 限制在收敛可容忍区；③IP-17 用未归一化残差 + 慢漂移项做交叉检查；④信任半径外强制回 PBVS/路标。**一句话：本方案最大的风险是先验一旦有偏，双率环会把偏差放大成「看起来成功的失败」。**

## 3. 新增 IP 详述

### IP-16 · VS-Plus 双率混合视觉伺服（P0，新）

- **动机**：榜单 F3 显示最弱五项全是插入/旋转/对齐（最后一厘米）；第 3 轮状态层解决了「在哪」，但把「怎么在这最后几厘米里稳、准、不抖」仍交给单一伺服。IBVS 与 PBVS 的软肋在结构上互补（前者怕深度、后者怕位姿误差），而深度恰是状态层能给的。
- **与现有方案差异**：v3 的 IP-09 是「路标 + 固定增益伺服 + 到点断言」单环。IP-16 把圈内运动拆成**特征空间内环**，并按状态层协方差在 IBVS/PBVS 间调度（U20）；路标层只保留离散语义，形成「离散×连续」混合自动机。组件全部成熟件（交互矩阵、单应/特征跟踪、增益调度），无新模型。
- **技术可行性**：高。IBVS 交互矩阵与增益为教科书件；调度只需协方差的 Mahalanobis 信任检验；粗深度可先用单目/档案尺度（L14 允许 ε≤20%），不阻塞上线。
- **资源**：数据=IP-06 已有的精度任务阶段标注（导出特征目标 s*）；算力=小（内环仅传统控制 + 轻量特征跟踪）；接口=无新增字段。
- **落地步骤**：①在 IP-09 的每个路标内定义特征目标 `s*`（从阶段标注导出，或首帧特征）；②IBVS 最小实现（`v=−λL̂_s⁺e`），深度先验先用档案尺度；③加入 PBVS 支路与协方差调度 + 滞回（U20）；④双率调度器（外环 T_L、内环 T_H，E635）；⑤在精度切片做 A/B（E636）；⑥接入 IP-17 残差输出。
- **风险**：深度先验有偏导致「自信错误收敛」（§5 最大风险）；切换抖振（滞回 + 驻留时间，L16）；遮挡/运动模糊丢特征（回 PBVS 兜底，Level-1.7）。

### IP-17 · ServoResidual Watchdog 伺服残差看门狗（P1，新）

- **动机**：只有内环时，「残差在降」无法区分「真收敛」与「在错误 Σ 下自洽」。需要一个不依赖目标真值的在线探针，把「看起来成功」翻译成可检验的统计量，并在失败前驱动介入（IP-02）。
- **差异**：不是新控制器，而是**控制器的观测器**——把 L11 的卡方思想从「断言」搬到「残差流」：`r_t = e_tᵀΣ_e⁻¹e_t`，正常应递减，失效（卡住/遮挡/滑移）表现为平台期/漂移/振荡；用 EWMA+CUSUM 检测，阈值锚定设计 α。
- **可行性**：高。纯统计后处理，零训练；复用 IP-16 已有的特征与 Σ_e。
- **资源**：近零；依赖 IP-16 的残差与协方差校准质量。
- **步骤**：①定义 `Σ_e`（特征噪声 + 先验传递）；②EWMA/CUSUM 与阈值查表（L17）；③预警档位映射到 IP-02 介入（先重检测、再换体制、最后重抓）；④E637 标定 AUROC/虚警/提前量。
- **风险**：Σ_e 校准失配→虚警或漏警；与 IP-15 干扰检测的事件重叠（统一到同一事件总线，避免双触发）。

### IP-18 · SpecialistSideBet 单任务专精侧注（P2·条件，新）

- **动机**：F2 显示 **specialist 列表为空**，F5 显示模型失败曲线近乎不相关；这意味着「专攻最难几项」在榜单上可能是无人竞争的头寸，而通用榜提升 1 分越来越难。

## 5. 符号与定义（新增 U19–U21；U1–U18 沿用第 1–3 轮）

- **定义 U19（双率视觉伺服环 DRVS）**：二元组 `(S_L, C_H)`；`S_L` 为状态层，周期 `T_L`，输出先验 `π_t=(x̂_T,Σ_T,Ẑ,Σ_cal)`；`C_H` 为特征伺服，周期 `T_H≪T_L`，输入观测 `o_t` 与 `π_{⌊t/T_L⌋}`，输出关节速度 `v_t`；`C_H` 将特征轨迹 `s_t` 上行作 `S_L` 的测量更新。
- **定义 U20（协方差调度混合伺服 CSS）**：调度变量 `σ_t∈{IBVS,PBVS}`；`σ_t=PBVS` 当且仅当位姿信任检验通过 `d²=(x̂−g)ᵀΣ⁻¹(x̂−g) ≤ χ²_{d,β}` **且** 相对深度误差 `ĥ=‖Ẑ−Z‖/Z ≤ ε_max`；否则 `σ_t=IBVS`；切换带滞回 `β→β′` 与驻留时间 `τ_dwell`（防抖）。控制律：
  `v_t = 𝟙[σ=PBVS]·(−λ_P ξ̂_pose) + 𝟙[σ=IBVS]·(−λ_I L̂_s⁺ e)`。
- **定义 U21（伺服残差与看门狗）**：`e_t = s_t − s*`，`Σ_e` 为特征噪声与先验传递的合成协方差；`r_t = e_tᵀΣ_e⁻¹e_t`；看门狗为 EWMA/CUSUM 统计量 `W_t`，当 `W_t > h(α)` 判失效；正常时 `r_t ~ χ²_d`（L17）。

## 6. 关键算法骨架（新增片段；主体沿第 1–3 轮 `UniBotSAGEPolicy`）

```python
# ===== IP-16: 双率混合视觉伺服（外环先验 + 内环调度）=====
class VSPlus:
    def __init__(self, lam_i=0.6, lam_p=0.8, eps_max=0.20, dwell=3):
        self.prev, self.cnt = "PBVS", 0

    def step(self, obs, pi, s_star, wp):
        # pi = (x_hat, Sigma, Z_hat, Sigma_cal) 来自 IP-13（可为粗深度）
        d2 = mahalanobis(wp.goal, pi.x_hat, pi.Sigma)
        eps_z = rel_depth_err(pi.Z_hat, obs)          # 估计相对深度误差
        want = "PBVS" if (d2 <= chi2_ppf(wp.dim, BETA) and eps_z <= eps_max) else "IBVS"
        mode = self.hysteresis(want)                  # U20: 滞回 + 驻留时间
        if mode == "PBVS":
            v = -lam_p * pose_error(obs, wp, pi)      # 位姿空间
        else:
            s = features(obs.wrist)                   # 特征空间
            L = interaction_matrix(s, pi.Z_hat)       # 深度先验进交互矩阵
            v = -lam_i * pinv(L) @ (s - s_star)       # IBVS
        return v, mode
```

```python
# ===== U20: 带滞回的调度器（防抖）=====
def hysteresis(self, want):
    if want == self.prev:
        self.cnt = 0
        return want
    self.cnt += 1
    if self.cnt >= DWELL:                              # L16: 驻留时间下界
        self.prev, self.cnt = want, 0
    return self.prev
```

```python
# ===== IP-17: 残差看门狗（CUSUM；虚警锚定 α）=====
def servo_watchdog(e_t, Sigma_e, state):
    r = e_t.T @ inv(Sigma_e) @ e_t                   # U21: Mahalanobis 残差
    dev = max(0.0, (r - CHI2_MEDIAN) / SIGMA_R)      # 单向漂移
    state.g = max(0.0, state.g + dev - K_DRIFT)       # CUSUM
    if state.g > H_ALPHA:                             # L17: 阈值由 α 定
        return "INTERVENE"                            # → IP-02 介入
    return None
```

```python
# ===== 混合自动机：离散路标 × 连续伺服 =====
def execute(task, obs):
    state = SceneState(task)                          # IP-13 外环
    servo = VSPlus()
    for wp in waypoints(task):                        # IP-09 离散层
        s_star = feature_target(wp, obs, state)
        while not assert_waypoint(wp, state, obs):    # U17 断言
            state.update(obs)                         # 低频 + 事件触发
            v, mode = servo.step(obs, state.prior(), s_star, wp)
            warn = servo_watchdog(feature_err(obs), state.Sigma_e, state)
            if warn: intervene(wp, state, servo)      # IP-17 → IP-02
            send(v)
    return
```

## 7. 推导（新增引理 L14–L17；L1–L13 沿用第 1–3 轮）

**引理 L14（IBVS 的深度误差只缩放收敛速度、不破坏稳定性）** 设真实/估计深度为 `Z, Ẑ=Z(1+ε)`，仅含平移分量的点到点特征误差在 `v=−λL̂⁺e` 下满足一阶近似 `ė = −λ(1+ε)⁻¹ e`（因 `ṡ_z=−(f/Z)v_z`，而 `v_z ∝ Ẑ`）。故 `ε>−1` 时指数稳定，收敛速率 `λ/(1+ε)`；含旋转耦合时失配项 `M=L̂⁺L−I=O(ε)` 产生稳态偏置 `‖e_ss‖ ≲ ε·‖v_ref‖/λ`。⇒ **深度先验只需满足 `ε ≤ λ·tol/‖v_ref‖`（工程上 ε≈20% 足够）**；对比断言需位姿 ≤ 容差/3，两种精度需求分离。∎

**引理 L15（双率失配的漂移界）** 外环估计陈旧 `τ≤T_L`，PBVS 令 `v_t=−λ(x̂(t−τ)−g)`；设理想跟踪 `ẋ=v`，则 `ė ≈ −λe + λ(x(t)−x(t−τ))`，稳态偏置 `‖e_ss‖ ≤ v_max T_L`。⇒ 双率设计约束 **`v_max T_L ≤ tol/3`**（与 E628 的 MAE 判据同源），且内环需 `T_H ≪ 1/λ`。这给出 E635 的验收不等式，并证明「外环慢」只在 PBVS 模式有害、IBVS 模式由 L14 兜底。∎

**引理 L16（混合切换的稳定性与驻留时间）** 若两模式共享同一平衡点 `g`，且分别存在公共 Lyapunov 函数 `V` 使 `V̇ ≤ −2λ_min V`，则任意切换下闭环仍指数稳定（公共 Lyapunov 判据）；每次切换的瞬时误差放大倍数设为 `κ`，则驻留 `τ_dwell ≥ ln(κ)/λ_min` 可保证切换不导致暂态发散。⇒ U20 的滞回 + 驻留是**稳定性必要条件**而非工程偏好；切换次数期望受 `⌈log(tol_0/tol)/log(1/(1−λ_min T_H))⌉` 约束，进而 E636 的切换次数上限可预注册。∎

**引理 L17（伺服残差看门狗的虚警控制）** 若 `Σ_e` 校准正确且标称收敛中残差由特征噪声主导，则 `r_t=e_tᵀΣ_e⁻¹e_t ~ χ²_d`，故单步虚警 `P(r_t>χ²_{d,α})=α`；CUSUM 的漂移参数可把平均运行长度（ARL₀）标定到 `≈1/α`。失效（卡住/遮挡/滑移）给残差加偏置 `b`，`r_t ~ χ²_d(δ²)`，`δ²=bᵀΣ_e⁻¹b`，检测功效对 `δ²` 单调（与 L11 同构）。⇒ **残差看门狗的虚警率是可设计的 α，不靠调参**；E637 只需验 Σ_e 校准与预警提前量。∎
