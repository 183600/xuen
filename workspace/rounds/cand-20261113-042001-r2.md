# 第 65 轮（承接第 64 轮「GRIP 接触接地四层闭环」IP-204~213；灵感循环 II 第 4 轮；本轮灵感：「视觉语言模型」×「分层规划」）

> 第 64 轮用接触接地（CGG）把几何先验变成可证伪假设，但其自述最大风险一针见血：**当 F/T 漂移、偏置、饱和或接触模型错误时，CGG 会把「传感器/模型错误」误判为「几何幻觉」——在正确几何上主动降级、在错误几何上放行，而 APP 的主动探测还可能对未知易损物体施加超限力。** 根因不只是力觉不够可靠，而是 GRIP 的判决结构太扁平：`单一标量残差 → 单阈值 → 二值 demote/promote` 没有**归因能力**，也没有**跨层语义冗余**来区分「谁错了」。本轮引入两个正交结构：
>
> **把「接触接地」升级为「语言-契约-层级接地」：VLM 不是控制器，而是分层计划的可证伪提议者；自然语言意图在每一层被编译为契约（前置/后置/不变式/可供性/预算），低层证书反证高层语义，高层语义约束低层技能选择。安全来自「层级精化证明 + 语义-物理一致性 + 分层保形风险预算 + 语言安全核」，而不是来自 VLM 的置信度。**

## 0. 直觉与动机

**灵感 1（视觉语言模型 → 语言是可证伪的语义先验，不是控制信号）**
直觉：VLM 能说出「杯子在桌沿」「抓把手」「别碰刀具」「这个物体易碎」，这比闭集检测器多出的是**开放词汇的语义与可供性**。但 VLM 有两个致命性质：① 它的 softmax 置信度不是校准概率，越接近训练分布越过度自信；② 它能生成*听起来合理但物理错误*的分解与解释。关键洞见：**自然语言命题天然可证伪**——「抓取后杯子离开桌面」「该表面可承受 5N 法向力」都可以写成可观测谓词并接受检验；而一个隐向量不能。于是 VLM 的输出不应直接驱动执行，而应被编译成**带观测谓词的契约**，由低层证据逐条签发或驳回。

**灵感 2（分层规划 → 每一层都能独立失败、独立检验、独立回退）**
直觉：分层规划常被当作「分而治之」的工程技巧，但对安全而言它真正提供的是**故障定位的坐标系**：任务分解错了、子目标契约错了、技能选错了、感知/力觉错了，各自会在不同的层留下不同签名。若只有「任务→技能」平铺两层，任何异常都只能归咎于技能或几何；有了「任务→子目标→技能→力契约」的多层精化链，就能回答「最深层仍然成立的祖先是谁」，并从那里重规划。**层次不是为搜索加速，而是为归因与回退提供偏序。**

**灵感 3（VLM × 分层规划 → 契约树：把语言计划变成可验证义务）**
直觉：VLM 负责「提出」层级分解与契约，分层规划负责「组织」这些契约并保证父子精化，底层 GRIP 负责「执行与取证」。把每个计划节点写成 `C_v = (Pre, Post, Inv, Aff, Budget)`：前置是执行条件，后置是预期效果，不变式是全程约束，可供性是对物体/区域的可用性断言，预算是时间/力/能量/风险。VLM 的每条自然语言断言都必须落到某个 `C_v` 的谓词上；落不下来的「解释」不具备执行权威。**这把 VLM 从「黑箱策略」降格为「可被证伪的语义提议器」，同时保留其开放词汇泛化能力。**

**灵感 4（三灵感合流 → LATTICE：Language-Anchored Task Tree with Interaction Contracts & Execution）**
LATTICE 在第 64 轮 GRIP 上挂载：LAG（语言-可供性接地，把指令与场景变成带校准置信的原子断言）、HCT（分层契约树）、CRV（契约精化验证器，用 SMT 检查父子义务）、SPC（语义-物理一致性残差，在线检验 VLM 断言与低层证据）、HCR（分层保形风险预算，把总风险 α 分配到节点）、RPE/HFA（故障归因与重规划，区分 VLM 幻觉/几何幻觉/力觉故障/模型错误/技能错误）、LSL（语言索引技能库，VLM 提议、验证器裁决）、SSK（语言安全核，把「易碎/禁触/人机距离」编译成硬约束）、HCSP（分层条件规划）、AIC-H（语言与语义干扰认证）、J_lat（跨层证书）。闭环：语言指令 → LAG 接地 → HCT 建树 → CRV 精化验证 → HCSP 规划 → GRIP 执行 → SPC/HFA 归因 → HCR 更新预算 → RPE 从最深有效祖先重规划。**第 64 轮让几何先验可证伪；LATTICE 让「语义计划」也第一次具备可证伪性与可归因性。**

**灵感 5（GRIP 组件的原位升级）**
- **CGG → CGG-H**：接触检验保留，但输出改为「证据向量」`(T_t, e_t^struct, ρ_force, ρ_slip, sat_t)`，交由 HFA 归因，不再单独裁决几何。
- **TSL → LSL**：技能以「语言嵌入 + 符号签名 + 可供性 + 力契约」索引；VLM 检索提议 top-k，CRV/CSP-F 验证后才可执行。
- **CSP-F → HCSP**：从线性技能序列升级为契约树上的分层条件规划；节点可行性 = 存在精化 + 叶子证书有效 + 风险预算足够。
- **OLP-F → OLP-H**：投影输入增加「节点契约满足度、层深、风险预算余量、VLM 断言校准值」；遗憾界增加层级切换项，但契约过滤使探索更集中。
- **AIC-F → AIC-H**：干扰集增语言扰动（改写、否定、干扰物、提示注入）与 VLM 语义幻觉（对象/属性/可供性错误），认证对象从单次执行扩到整棵计划。
- **J_grip → J_lat**：证书增 `contract_hash, refinement_proof_hash, alpha_allocation, credibility_vector, fault_attribution_log, safety_kernel_hash`。

## 1. 形式化定义（增量：定义 217–230，完整版见产物区）

- **定义 217（LATTICE 闭环）**：LATTICE = (GRIP, LAG, HCT, CRV, SPC, HCR, HFA, RPE, LSL, SSK, HCSP, AIC-H, J_lat)。不变式：**VLM 推理、建树、精化证明、归因与重规划只在语义流/低频线程；实时流只做已编译谓词检查、SSK 硬约束投影与 GRIP 前向，零 VLM 调用、零学习写操作。**
- **定义 218（语言-可供性接地 LAG）**：`f_VLM: (ℓ, o) → (G_sem, A, K)`，其中 G_sem 为对象/属性/关系场景图，A 为区域-可供性分布，K 为原子断言集；每条断言 `k=(s,p,o,scope,conf,prov)` 可映射到可观测谓词 π_k。置信经温度缩放与保形校准，输出 p 值而非裸 softmax。
- **定义 219（分层契约树 HCT）**：`T=(V,E,root,κ,ℓ,C)`，节点类型 κ∈{task,subgoal,skill}；契约 `C_v=(Pre_v,Post_v,Inv_v,Aff_v,B_v)` 为状态/物理/力上下文上的谓词集合；叶子必须来自 LSL；边表示「分解或绑定」。
- **定义 220（契约精化 CRV）**：`C_v ⊑ {C_u}_{u∈ch(v)}` 当且仅当：父前置可推出子链前置（存在参数绑定）；子链后置可推出父后置；父不变式覆盖并保持子不变式；子预算之和不超过父预算；子效果帧一致，不破坏父不变式。CRV 用 SMT 对上述五项义务逐条检查，任一失败则该分解不可用。
- **定义 221（语义-物理一致性 SPC）**：VLM 对节点 v 预测效果 `ŷ_v` 与可供性断言；低层观测 `y_v`（视觉/几何/力/触觉）。定义语义残差 `r_sem = d_S(ŷ_v,y_v)` 与物理残差 `r_phys`（GRIP 残差）。用 e-process 做随时有效检验：`E_t = ∏ (p_1(o_t)/p_0(o_t))`；Ville 不等式保证误报 ≤ α_sem。
- **定义 222（分层保形风险预算 HCR）**：给定总风险 α，为节点分配 `α_v = α·w_v/Σw`，`w_v = 2^{-depth(v)}·crit(v)`；用保形 p 值 `p_v` 检验契约满足，`Valid_v ⇔ p_v ≤ α_v`。在线阶段用 e-process 财富自适应重分配未用完的 α。
- **定义 223（分层故障归因 HFA）**：假设集 `H={H_sem, H_geo, H_force, H_model, H_skill, H_task}`；证据向量 `o_t=(r_sem,r_geo,r_force,r_model,r_skill)` 各通道来自不同层。故障签名矩阵 `S` 的列给出各假设的残差模式；后验 `b_t(h) ∝ L(o_t|h)·b_{t-1}(h)`；仅当最大后验 ≥θ_diag 且优势比 ≥θ_odds 才允许归因，否则进入 `H_unknown` 并发起判别动作。
- **定义 224（重规划与修复 RPE）**：异常发生在节点 v 时，取「最深层仍 Valid 的祖先」`a(v)`；修复动作 ∈ {retry_skill, replace_subplan, requery_VLM_with_counterexample, recalibrate_sensor, safe_idle}。原则：**未重新验证的子树一律不执行**；回退深度 ≤ 树高 h；VLM 重询预算 Q。
- **定义 225（语言索引技能库 LSL）**：`s=(z_lang, sig, aff, C_s, θ_s)`，检索分数 `score(s|v)=⟨z_lang,z_v⟩+λ·aff_match`；返回 top-k 后由 CRV 与 CSP-F 验证。VLM 只排序提议，不直接授权执行。
- **定义 226（语言安全核 SSK）**：从指令与场景抽取硬约束集 `H=(F_forbid,F_force,F_keepout,F_never)`；`Proj_H` 把计划/控制投影到 H；约束单调，只允许被物理证据**收紧**，不允许被 VLM 置信度放松；解析失败时取最保守默认。
- **定义 227（分层条件规划 HCSP）**：在契约树上做 AND-OR 搜索；OR 节点选分解/技能，AND 节点按 SPC 观测分支；边代价 `cost = Σ child_cost + λ_r·risk_v + λ_q·query_cost`；启发式由叶子证书与剩余风险预算给出，需可采纳。
- **定义 228（AIC-H 干扰认证）**：`ℰ_H=ℰ_F×ℰ_sem×ℰ_lang`；`ℰ_lang` 含改写、否定、干扰物、提示注入、越权指令；`ℰ_sem` 含对象/属性/可供性幻觉。`ρ_sem` 在 ℰ_lang×ℰ_sem 上取最坏契约违反率；`ρ_lat=min(ρ_grip,ρ_sem,ρ_lang,ρ_ssk)`。
- **定义 229（J_lat 跨层证书）**：`J_lat=(J_grip^leaves, contract_hash, refinement_proof_hash, α_allocation, credibility_vector, fault_attribution_log, safety_kernel_hash, sem_calibration_ver, plan_hash)`。`Valid(J_lat) ⇔` 所有叶子 Valid ∧ 所有边精化验证通过 ∧ 所有节点 p_v≤α_v ∧ SSK 满足 ∧ 归因日志与证据一致 ∧ 无未验证子树被执行。
- **定义 230（LATTICE 算子）**：语义流 `[ℓ→LAG→HCT→CRV→HCSP→派发首技能]`；执行流 `[GRIP 实时→SPC 谓词监控→SSK→证据回灌]`；归因流 `[异常→HFA→RPE→最深有效祖先→重询/重规划]`；慢速流 `[保形重校准、契约模板挖掘、AIC-H 重认证]`。

## 2. 关键算法骨架

```python
# LAG：VLM 只产生可证伪断言与可供性，置信度经保形校准
belief = lag.ground(instruction, obs)             # claims -> 可见谓词 + p 值
# HCT + CRV：建树并逐边验证精化义务（SMT）
tree = hct.build(instruction, belief)             # 叶子来自 LSL
for v in tree.internal_nodes():
    assert crv.verify(v.contract, [c.contract for c in v.children])
# HCSP：在已验证的契约树上做 AND-OR 条件规划
plan = hcsp.plan(tree, belief, alpha, budget)      # 只展开精化通过的边
# 执行 + SPC/HCR：已编译谓词检查，实时零 VLM
for node in plan.frontier():
    ok, p_v = spc.monitor(node, obs, belief)       # e-process + 保形 p 值
    if p_v > alpha[node]:
        h, b = hfa.attribute(obs.residuals, belief) # 区分语义/几何/力/模型/技能
        plan = rpe.repair(tree, node, h, b, budget) # 从最深有效祖先重规划
        break
    ssk.enforce(node)                              # 硬约束，VLM 不可放松
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 7（精化传递性）**：若每条边满足定义 220 的五项义务，则叶子契约的合取蕴含根契约；归纳证明，且帧一致条件保证子效果不会从侧门破坏父不变式。
- **引理 8（语义伪证的可检测性）**：若 VLM 断言与真实分布的 KL 散度 ≥δ，则 e-process 在期望 `O(log(1/β)/δ)` 步内越界，误报由 Ville 不等式 ≤α_sem；检出后该节点及后代**禁止执行**。
- **引理 9（故障归因可辨识性）**：若任意两故障假设的残差签名分离度 ≥m，则 N 次观测后误归因概率 ≤ `exp(−N m²/2)`；这直接对冲第 64 轮「把力觉偏置误判为几何幻觉」的结构缺陷。
- **定理 7（分层组合安全）**：若 CRV 全部通过、叶子以概率 ≥1−α_v 满足契约、且 Σα_v≤α，则根契约以概率 ≥1−α 成立——**证书从「单次执行」扩为「整棵计划」**。
- **定理 8（分层查询复杂度）**：设树高 h、节点数 |V|、单节点违反概率 p，则每回合期望 VLM 调用 ≤ `|V| + p·h·|V|`，显著低于逐步调用 VLM 的 `O(T)`；且仅在契约违反时重询。
- **定理 9（语义-物理联合安全）**：`P[不安全] ≤ α_grip + α_sem + α_lang + α_ssk`；SSK 作为硬约束使「已解析安全约束」下的违反概率为 0，其余为解析/分布偏移误差。
- **实时性**：SSK 与 SPC 谓词在离线编译为查表/区间判定，实时新增 `<0.1ms`；VLM 与 SMT 全在语义流，不进入 2ms 实时契约。

## 5. 本轮最大风险

## 2. 形式化定义（完整版）

**定义 217（LATTICE 闭环）** LATTICE 是 GRIP 的「语言-契约-层级」升级：在第 64 轮「语义流 ∘ 实时流」上挂载 LAG（语言接地）、HCT/CRV（契约树与精化验证）、SPC/HCR（语义-物理一致性与风险预算）、HFA/RPE（归因与修复）、LSL（语言技能库）、SSK（安全核）、HCSP/AIC-H（分层规划与认证），并原位升级 J_grip→J_lat。不变式：**VLM 调用、建树、SMT 证明、归因与重规划只发生在语义流/低频线程；实时流只执行已编译谓词、SSK 硬约束与 GRIP 前向，零 VLM 调用、零学习写操作。**

**定义 218（语言-可供性接地 LAG）** 给定指令 ℓ 与观测 o，VLM 输出
`f_VLM(ℓ,o) = (G_sem, A, K)`，
其中 G_sem=(O,R,Att) 为对象/关系/属性场景图；A: (对象或区域)×可供性 → [0,1]；K={k_i} 为原子断言。每条 k 带作用域 scope（对象/区域/时间窗）与出处 prov（引自指令、VLM 常识、感知证据）。LAG 将 k 映射为可观测谓词 π_k(x,φ)，并对置信做温度缩放 + split-conformal 校准：在标定集上得到 `p_k`，使得对可交换样本 `P[π_k 为真 | p_k ≤ α] ≥ 1−α`。**未映射为可观测谓词的断言不进入契约，只作为人机解释。**

**定义 219（分层契约树 HCT）** 契约树 `T=(V,E,root,κ,ℓ,C)`：
- κ_v∈{task,subgoal,skill}；root 对应用户指令；叶子必须是 LSL 中的技能；
- `C_v=(Pre_v,Post_v,Inv_v,Aff_v,B_v)`，其中 Pre/Post/Inv 是状态 x、物理参数 φ、接触/力上下文上的谓词合取；Aff_v 是可供性断言（如 graspable、fragile、support_surface）；B_v=(T_max,E_max,F_max,R_max) 为时间/能量/力/风险预算。
- 内部节点带分解算子 δ_v：把父目标绑定到子节点的参数与执行顺序（顺序/并行/条件）。
- 叶子还携带 GRIP 的力契约 `force_spec` 与技能参数 θ_s。

**定义 220（契约精化 CRV）** `C_v ⊑ {C_u}_{u∈ch(v)}` 当且仅当存在参数绑定 σ 使以下五项成立：
1. **前置充分**：`Pre_v ⇒ chain_pre(ch(v))`，其中 chain_pre 为按 δ_v 顺序展开、前一子后置满足后一子前置；
2. **后置充分**：`chain_post(ch(v)) ⇒ Post_v`；
3. **不变式保持**：`Inv_v ⇒ ∧_u Inv_u`，且每个子效果不违反 `Inv_v`（帧一致）；
4. **预算闭合**：`Σ_u B_u ⪯ B_v`（逐分量，含并行重叠修正）；
5. **可供性一致**：`Aff_v` 不被子契约否定（如父称「可抓」而子要求「不可接触」则冲突）。
CRV 把五项编码为一阶/线性算术公式，交给 SMT（Z3/νZ）检查；返回 `(ok, proof_hash, counterexample)`。**任一项失败 ⇒ 该分解边不可用；禁止运行时「先试再说」。**

**定义 221（语义-物理一致性 SPC）** 对节点 v，VLM 预测效果 `ŷ_v`（对象位移、接触建立、容器状态、可供性成立）与断言 π_k；低层观测 `y_v`（视觉/几何/力/触觉）。定义
`r_sem = d_S(ŷ_v, y_v)`（离散谓词不匹配数 + 连续状态归一化距离），
`r_phys = GRIP 的接触/滑移/力残差`。
在 H0（VLM 断言与 GRIP 模型均正确）下给出 `p_0`，在 H1（至少一个错误）下给出 `p_1`。e-process
`E_t = ∏_{i=1}^t p_1(o_i)/p_0(o_i)`
满足 `E[E_t|H0] ≤ 1`；当 `E_t ≥ 1/α_sem` 时拒绝 H0，误报率 ≤ α_sem（Ville）。检测后节点及后代进入 `unverified`，不得执行。

**定义 222（分层保形风险预算 HCR）** 给定总风险 α 与契约树，分配
`w_v = 2^{-depth(v)} · crit(v)`，`α_v = α · w_v / Σ_u w_u`，
其中 crit(v) 由 SSK 的关键度（涉及人/易损物/不可逆动作）给出。每个节点用保形 p 值 `p_v` 检验；`Valid_v ⇔ p_v ≤ α_v`。在线阶段维护每个节点的 e-wealth `W_v`，未用完的 α 回收给高不确定节点：`α_v ← α_v + η·(α_v − p_v)_+`，并由 e-process 的 anytime 有效性保证不超支。总体失败概率由 Σα_v ≤ α 控制。

**定义 223（分层故障归因 HFA）** 故障假设集
`H={H_sem(VLM 幻觉), H_geo(几何幻觉), H_force(力觉偏置/漂移/饱和), H_model(接触/动力学模型错误), H_skill(技能执行错误), H_task(任务分解错误)}`。
证据向量 `o_t=(r_sem,r_geo,r_force,r_model,r_skill,r_task)`，各分量来自对应层。故障签名矩阵 `S∈ℝ^{6×6}` 的列给出假设 h 下各残差的期望模式（如常值偏置在自由空间也有残差、几何幻觉只在接触面出现、技能错误在后置条件失败但力/几何正常）。后验
`b_t(h) ∝ L(o_t|h)·b_{t-1}(h)`。
仅当 `max_h b_t(h) ≥ θ_diag` 且 `b(h_1)/b(h_2) ≥ θ_odds` 才允许归因；否则 `H_unknown`，由 RPE 选择判别动作（复用第 64 轮 APP 的 D-最优思想，但探针目标是区分假设而非估 φ）。

**定义 224（重规划与修复 RPE）** 异常发生在节点 v 时，取 `a(v)=` 从 v 向上第一个仍 `Valid` 的祖先。修复动作集
`A_repair={retry_skill, replace_subplan, requery_VLM_with_counterexample, recalibrate_sensor, safe_idle}`。
选择规则：H_sem/H_task → 从 `a(v)` 重询 VLM 并附反例（最小失败证据）；H_force/H_model → 重标定后重试；H_skill → 替换子技能或参数；H_geo → 触发 GRIP 的 CGG 降级并重规划；归因不确定 → 先做判别动作或 safe_idle。**硬约束：未通过 CRV/SPC 的子树不得执行；回退深度 ≤ h=树高；VLM 重询次数 ≤ Q。**

**定义 225（语言索引技能库 LSL）** `LSL={s_i}`，`s=(z_lang, sig, aff, C_s, θ_s)`：z_lang 为技能描述的语言嵌入；sig 为符号签名（参数类型、前置/后置谓词）；aff 为适用可供性；C_s 为 TSL 力契约（f_min/f_max、ρ_slip≥0、ρ_force≥0、grasp_stable）；θ_s 为技能参数。检索 `score(s|v)=⟨z_lang,z_v⟩+λ·aff_match(v,s)`，返回 top-k。**VLM 只负责排序提议；CRV 检查 C_s 与父契约精化，CSP-F 检查力/滑移可行性，二者都通过才可绑定。**

**定义 226（语言安全核 SSK）** 从指令与场景抽取硬约束：
- `F_forbid`：禁触/禁入区域（如刀具、人、宠物）；
- `F_force`：按物体易损性与 ISO/TS 15066 给出的力/压强上限；
- `F_keepout`：人机最小距离、不可逆动作前置确认；
- `F_never`：明确否定（「不要」「禁止」「avoid」）。
SSK 把每条约束编译为可投影集 H，控制/计划经 `Proj_H` 投影。约束格是单调的：**允许物理证据收紧 H（例如发现更易碎），禁止 VLM 置信度放松 H**。解析否定/多语言/指代失败时取全局最保守默认（停或退）。

**定义 227（分层条件规划 HCSP）** 在已验证边构成的树上搜索 AND-OR 计划：
- OR 节点：选择分解 δ_v 或技能绑定 s；
- AND 节点：按 SPC 可能观测分支（成功/失败/未知），每个分支继续规划；
- 边代价 `cost = Σ child_cost + λ_r·risk_v + λ_q·query_cost + λ_t·time_v`；
- 可行性：`Valid_v ∧ ρ_lat ≥ 0 ∧ ΣB_child ⪯ B_v`；
- 启发式 `h(v)=` 叶子证书的乐观代价 + 剩余风险预算的下界，需可采纳。
若目标不可达，插入 `discriminate` 元动作（调用 HFA 的判别探针）或返回 `safe_idle`。

**定义 228（AIC-H 分层干扰认证）** 干扰集
`ℰ_H=ℰ_F×ℰ_sem×ℰ_lang`，
`ℰ_lang` = {改写、否定、指代歧义、干扰物、提示注入、越权指令}；
`ℰ_sem` = {对象误识别、属性错误（易碎/可抓）、可供性错误、关系错误}；
`ℰ_F` 继承第 64 轮的力觉干扰。`ρ_sem` 在 `ℰ_lang×ℰ_sem` 上取最坏契约违反率；`ρ_ssk` 在越权指令集上取最坏安全核违反率。认证对象是整棵计划树，而非单个技能。J_lat 增 `sem_calibration_ver` 与 `lang_perturbation_hash`。

**定义 229（J_lat 跨层证书）**
`J_lat=(J_grip^leaves, contract_hash, refinement_proof_hash, α_allocation, credibility_vector, fault_attribution_log, safety_kernel_hash, sem_calibration_ver, plan_hash)`。
验证规则：
`Valid(J_lat) ⇔` 所有叶子 Valid(J_grip) ∧ 所有内部边 CRV 通过（proof_hash 可复算）∧ 所有节点 p_v≤α_v 且 Σα_v≤α ∧ SSK 满足 ∧ 归因日志与证据一致 ∧ 无未验证子树被执行 ∧ sem_calibration_ver 为当前标定版本。
审计链：contract_hash 追溯语义来源，refinement_proof_hash 追溯组合证明，fault_attribution_log 追溯每次降级/重规划的原因。

**定义 230（LATTICE 算子）**
- **语义流**：`ℓ → LAG → HCT → CRV → HCSP → 派发首技能`；
- **执行流**：`GRIP 实时（CGG/MWS/SLD/FCS/WCV-F）→ SPC 谓词监控 → SSK 投影 → 证据回灌`；
- **归因流**：`异常 → HFA → RPE → 最深有效祖先 → 重询/重规划/安全态`；
- **慢速流**：`保形重校准、契约模板挖掘、LSL 增删、AIC-H 重认证、SMT 证明缓存`。
实时流保持 GRIP 的 2ms 契约；VLM/SMT 延迟全部落在语义流。

### IP-215/216 HCT + CRV（建树与精化验证）

```python
class HierarchicalContractTree:
    def build(self, instruction, belief):
        root = Node('task', instruction, contract_from_language(instruction, belief))
        frontier = [root]
        while frontier:
            v = frontier.pop()
            if v.depth >= MAX_DEPTH or v.is_skill_level():
                v.children = self.lsl.retrieve(v, k=5)
                continue
            v.children = self.vlm_decompose(v, belief)      # 子目标 + 参数绑定
            v.contract = self.vlm_contract(v, belief)        # Pre/Post/Inv/Aff/Budget
            frontier.extend(v.children)
        return root

class ContractRefinementVerifier:
    def verify(self, parent, children, binding):
        P, Q = parent.contract, [c.contract for c in children]
        obligations = [
            implies(P.pre, chain_pre(Q, binding)),           # 1 前置充分
            implies(chain_post(Q, binding), P.post),          # 2 后置充分
            implies(P.inv, And([q.inv for q in Q])),          # 3 不变式保持
            frame_consistent(Q, P.inv),                       #   帧一致
            budget_leq(sum_budget(Q), P.budget),              # 4 预算闭合
            afford_consistent(P.aff, [q.aff for q in Q]),     # 5 可供性一致
        ]
        for o in obligations:
            r = self.smt.check(o)
            if not r.ok:
                return False, None, r.counterexample
        return True, hash_proof(obligations), None
```

```python
def allocate_alpha(alpha, tree):
    w = {v: 2.0 ** (-v.depth) * criticality(v) for v in tree.nodes()}
    Z = sum(w.values())
    return {v: alpha * w[v] / Z for v in tree.nodes()}

def spc_monitor(node, obs, belief, alpha_v):
```

```python
HYP = ('H_sem', 'H_geo', 'H_force', 'H_model', 'H_skill', 'H_task')

def attribute(residuals, belief, signatures, theta_diag, theta_odds):
    ll = {h: loglik(residuals, signatures[h]) for h in HYP}
    post = softmax({h: ll[h] + log(belief[h] + 1e-9) for h in HYP})
    top = sorted(post.values(), reverse=True)
    if top[0] < theta_diag or top[0] / max(top[1], 1e-9) < theta_odds:
        return 'H_unknown', post
    return max(post, key=post.get), post

def repair(tree, v, h, post, budget):
```

```python
def LATTICE_round(M, instruction, obs, alpha):

    belief = M.lag.ground(instruction, obs)

        if not ok:
            v.disable(cex)                         # 该分解禁止使用
    alpha_v = M.hcr.allocate(alpha, tree)
    plan = M.hcsp.plan(tree, belief, alpha_v, M.budget)
    plan = M.ssk.project(plan, M.ssk.compile(instruction, belief))
    if plan is None:
        return safe_idle(), build_j_lat_failed('ssk')

    # ———— 执行流 + 逐节点证书 ————
    for node in plan.frontier():
        ok_exec, ev, cert_exec = GRIP_execute(node, M, obs)
        verified, p_v, res = spc_monitor(node, ev, belief, alpha_v[node])
        if not verified:
            h, post = attribute(res, M.hfa.belief, M.hfa.signatures,
                                THETA_DIAG, THETA_ODDS)
            plan = M.rpe.repair(tree, node, h, post, M.budget)
            if plan is None or plan.is_safe_idle():
                break
            continue
        M.hfa.update(res, h=None)                  # 正常证据也更新信念
        M.hcr.update_wealth(node, p_v, alpha_v)

    return plan, build_j_lat(M, tree, plan, alpha_v, belief)
```

## 4. 推导

**引理 7（契约精化的传递性与组合性）** 若树 T 的每条边 `C_v ⊑ {C_u}` 均满足定义 220 的五项义务，则对任意叶子执行序列满足各自 `Pre/Post/Inv`，根契约 `C_root` 的 `Post` 与 `Inv` 成立。
证明：对树高归纳。基例为叶子，直接由执行契约成立。归纳步：由义务 1 与 2，子链前置/后置分别推出父前置/后置；由义务 3 与帧一致，父不变式在子执行期间不被破坏；由义务 4，父预算覆盖所有子；由义务 5，可供性无冲突。因此父契约成立，逐层上推至根。∎
**注**：该引理只保证「若叶子契约被满足，则根契约被满足」，不保证契约本身表达真实意图——这是本轮根基风险。

**引理 8（语义伪证的检测时延与失效安全）** 设 VLM 断言下的观测分布为 p_1，真实/GRIP 一致分布为 p_0，`KL(p_1‖p_0) ≥ δ`。e-process `E_t=∏ p_1/p_0` 在 H0 下是上鞅。由 Ville 不等式，`P[∃t: E_t ≥ 1/α_sem] ≤ α_sem`。在 H1 下，`E[log E_t] = t·δ`，故期望检测时间 `T_detect ≤ log(1/α_sem)/δ`。检出后节点置 `unverified`，其所有后代不得执行，系统回退到 `a(v)`。**因此 VLM 幻觉的最坏后果是「计划回退」，不是「执行未验证语义」。** ∎

**引理 9（故障归因的可辨识性）** 设任意两故障假设 h_i,h_j 的残差签名在 Mahalanobis 度量下分离度 `‖S_i−S_j‖_{Σ^{-1}} ≥ m`，观测噪声有界/次高斯，则 N 次独立观测后误归因概率 `≤ exp(−N m²/2)`（Hoeffding/次高斯尾界）。若分离度不足或后验优势比低于 θ_odds，算法返回 `H_unknown` 并选择判别动作而非强行归因。**这把第 64 轮的「单阈值误归因」变成「证据不足时拒绝归因」。** ∎

**定理 7（分层组合安全）** 假设：(A88) 每次 VLM/人工契约生成后，CRV 的 SMT 编码忠实于定义 220；(A89) 保形校准在交换性下有效，节点契约失败概率 ≤ α_v；(A90) SSK 的硬约束解析正确或失败时最保守。若 `Σ_v α_v ≤ α`，CRV 全部通过，且 `Valid(J_lat)`，则根契约成立的概率 ≥ 1−α。
证明：由引理 7，精化链把叶子成功传到根；由 (A89) 与并集界，至少一个节点契约失败的概率 ≤ Σα_v ≤ α；由 (A90)，SSK 违反概率为 0（在解析正确条件下）。合并得 ≥1−α。∎

**定理 8（分层查询复杂度）** 设契约树有 |V| 个节点、高 h、单节点契约违反概率 p_v，且 RPE 最多重询 h 层祖先。则每回合期望 VLM 调用次数
`E[N_VLM] ≤ |V| + p_v·h·|V| = O(|V|(1+p_v h))`，
而逐步调用 VLM 的平铺策略为 `O(T)`（T 为执行步数）。当 `|V| ≪ T` 且 `p_v` 小时，层级策略把调用降一个量级；且 VLM 只在建树与违反时调用，满足「语义流低频」约束。∎

**定理 9（语义-物理联合安全）** 在 GRIP 的 A83–A87、A88–A90 及：
- **(A91)** 语言分布偏移有界，或加权保形以可估的似然比覆盖；
- **(A92)** LAG 的谓词映射对定义域内指令是单射/可验证的（无歧义指代）；
- **(A93)** HCSP 的启发式可采纳，规划返回的计划确实在已验证边上；
则 `P[不安全事件] ≤ α_grip + α_sem + α_lang + α_ssk`，其中 α_grip 为第 64 轮四层安全失败概率，α_sem 为语义伪证漏检，α_lang 为语言偏移/解析误差，α_ssk 为安全核解析误差。∎

**命题（保形风险分配的有效性）** 若各节点 p 值在交换性下各自有效，且 α_v 按定义 222 分配使 Σα_v≤α，则「至少一个节点契约被错误接受」的概率 ≤α。在线财富重分配使用 e-process，Ville 不等式保证任意停时下仍 ≤α；因此 HCR 既能在建树时静态分配，也能在运行时动态回收预算而不破坏保证。∎

**命题（VLM 提议-验证分离的收益）** 设 VLM 直接执行的成功率为 q_VLM，验证器拒绝错误提议的召回率为 r，误拒率为 f。则「VLM 提议 + 验证器裁决」的成功率下界约为 `q_VLM + (1−q_VLM)·r − q_VLM·f`；当 r 高、f 低时严格优于直接执行。代价是验证延迟与 VLM 调用减少（只在 top-k 上验证）。∎

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| LAG（VLM 推理） | 50–300ms，语义流 | O(|claims|) | 保形校准，p 值有效 |

**正确性定理（LATTICE-Complete）** 见定理 7–9：核心是把「语义计划正确」从 VLM 的不可检验置信度，变成**可精化证明、可在线伪证、可保形预算、可故障归因**的分层假设；同时明确承认其有效性以「契约语义正确」为前提（A88 的解释项），而非无条件保证。

## 7. 已知风险

**一句话**：若 VLM 生成的契约本身空洞、过弱或语义错位（例如把后置条件写成恒真、把易碎物标成可压、把「不要」解析成「要」），CRV 会为一份「精化正确」的错误契约签发形式化证书，而 SPC 只检验契约声称的那部分世界——系统将带着层级证明自信地执行语义上错误的任务；**契约质量是整套方案唯一无法由内部证明的根基，形式化在这里可能把语义错误放大成「有证书的错误」。**

**次级风险与缓解**：
1. **空洞契约 / 弱契约**：VLM 倾向生成 `Post=True` 之类不可证伪的契约；缓解：契约模板库 + 谓词覆盖率检查（每个后置必须至少含一个可观测状态变化）+ 反例生成（CRV 主动搜索能同时满足父子契约但违反意图的模型）；仍不能根治，故列为最大风险。
2. **语言分布偏移**：改写、否定、低资源语言使保形覆盖失效；缓解：加权保形（似然比估计）、语言扰动增强、偏移检测触发重新标定、解析不确定时最保守默认。
3. **SSK 解析错误**：否定/双重否定/指代/隐喻可能把「不要」解析成「要」；缓解：安全核使用独立的小模型 + 规则双通道，冲突时取最保守；高风险动作强制人类确认。
4. **SMT 可扩展性**：接触/摩擦/时序谓词含非线性，SMT 可能超时；缓解：契约 DSL 限制为可判定片段、离线证明缓存、超时即拒绝该边（安全侧失败）。
5. **HFA 可辨识性不足**：某些故障在残差上不可分（如力觉常值偏置与几何偏移在同接触点下等价）；缓解：主动判别动作、跨任务证据累积、返回 `H_unknown` 而非强行归因。
6. **层级承诺与回退代价**：深层子树失败可能需大量重规划；缓解：契约树局部化修复、检查点、限制回退深度、缓存已验证子树。
7. **VLM 提示注入与越权**：场景文本/物体上的对抗文字可能劫持 VLM；缓解：指令-观测隔离、SSK 独立于 VLM、输出只接受结构化断言、拒绝含执行代码/URL 的提议。
8. **实时预算**：SSK/SPC 谓词虽轻，但若谓词复杂会超 2ms；缓解：离线编译为区间/查表、限制实时谓词复杂度、复杂检查延后到语义流并先进入保守态。
