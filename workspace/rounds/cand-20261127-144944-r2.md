### 第 2 轮灵感驱动研究记录（灵感词：本体感知、服务设计）

**直觉与动机**：

前几轮（KEMPC → CADVS，v29）把控制问题重构为「证书证据链驱动的动作选择」，但证书主要来自外感知：视觉伺服 FQC、差分定位 DLC、多机一致性 MRCC。这条路线有一个结构性盲点：**机器人对「自己身体此刻能做什么」缺少一等公民级别的证据**。视觉与定位告诉它世界在哪，却没有告诉它「我的 CoM 是否还在支撑多边形内」「我的关节/执行器还剩多少裕度」「我学到的身体模型是否还匹配真实身体」。这正是「本体感知」的用武之地——本体感知是带宽最高（1kHz 级）、延迟最低、且不依赖外部基础设施的自指感觉。它的独特价值不是替代外感知，而是充当外感知的**独立校验器**与**时间锚点**：当视觉证书说「有效」而本体感知说「该动作在动力学上不可行」时，系统第一次拥有了跨模态的怀疑能力。

但只加一个证书模块是不够的。若把每个新证书都做成硬 AND 门，执行集会不断收缩，回退/急停频率上升——系统变得「安全但不可用」。这里需要「服务设计」的视角：把控制回路看成一个**向利益相关者（操作员、其他机器人、安全系统）持续交付服务的系统**，证书是**服务证据/服务承诺**，回退不是中性的安全动作，而是系统自身失败所诱发的**失败需求（failure demand）**。服务设计告诉我们：可靠性不是靠无限加约束，而是靠**服务蓝图**（分清前台/后台/支撑）、**服务补救**（分级、低成本地恢复）与**服务分级**（不同情境承诺不同服务水平）共同达成。于是本轮的真正命题是：**用本体感知把「身体能力」变成可验证的服务承诺，用服务设计把证书链从「只会拒绝的守门人」升级为「会分级交付、会优雅补救的服务系统」**。

**关键洞见**：本体感知提供「自我能力真值」，服务设计提供「如何据此做出可承诺、可补救、可审计的交付」。二者结合，把 v29 的「外感知证据驱动」补全为「内外感知互证 + 服务级别管理」，直接针对上一轮最大风险（分布式时序造成的「证书通过但实则失效」的虚假安全感）：本体感知以更高频率、更低延迟提供独立参照，使「证书说通过、身体说不行」的矛盾可被即时发现；而服务分级则避免为了消除该风险而把系统推向过度保守的另一极端。

**形式化目标（增量）**：
1. 定义本体感知身体图式证书 PBSC = (valid, m_cap, m_joint, m_act, r_model, t)，其中 m_cap 为 DCM（发散运动分量）到可达落足集 P_step 的有符号距离，作为「一步可捕获」的裕度判据。
2. 定义跨模态服务一致性证书 CMSC：以腿部里程计预测外感知速度，构造 Mahalanobis 残差 d²，按 χ² 门控；给出本体偏差有界时的检测功效界与共模盲区。
3. 定义服务蓝图运行时 SBR：服务证据记录 SER 与来源链 provenance、可计算的服务级别 SL(t) 与失败需求率 FD。
4. 定义失败需求感知补救控制器 FDARC：在「正常→降级→补救→安全停机」阶梯上以最小服务补救成本选择动作，并签发服务补救证书 SRC。
5. 定义服务情境感知准入 SCA-KC：在残差风险预算 ρ_budget(σ) 约束下最大化期望服务级别，得到情境相关的必需证书子集 M(σ)。
6. 证明：Exec_new ⊆ Exec_CADVS ⊆ Exec_v29（更严格的包容），且在本体偏差有界、身体模型残差达标时，跨模态门控可将「本会导致回退的外感知失效」中的一部分提前拦截，使 FD 下降而 SL 维持；并诚实指出共模偏差下该保证失效。

**本轮最大风险**：**本体感知证书的自我指涉悖论**——PBSC/CMSC 用「身体模型」去验证「身体」，而身体模型本身可能因磨损、负载变化、标定漂移而失配；此时系统会以极高的置信度给出「一切正常」，且跨模态校验在共模偏差（外感知与本体共享同一标定错误）下无法察觉。换言之，系统在最需要外部真值的时刻，恰恰丧失了对自身模型有效性的独立判据——这是一种比时序失效更隐蔽的「自信的错误」。

### IP-478 Proprioceptive Body-Schema Certificate (PBSC)

```python
@dataclass
class ProprioceptiveBodySchemaCertificate:
    """PBSC：LIPM-DCM 可捕获裕度 + 关节/执行器裕度 + 动力学残差"""
    omega0: float = 3.13          # sqrt(g/z_c), z_c=1.0m
    H_cap: float = 0.30           # 单步捕获允许时间 (s)
    delta_joint: float = 0.05     # 归一化关节裕度下界
    delta_act: float = 0.10       # 归一化执行器裕度下界
    delta_model: float = 0.15     # 归一化动力学残差上界
    epsilon_robust: float = 0.01  # 对模型残差的鲁棒裕度补偿 (m)

    def capture_margin(self, x, xdot, P_step) -> float:
        """m_cap = signed_dist(ξ, P_step)，ξ = x + ẋ/ω0；≥0 表示一步可捕获"""
        xi = x + xdot / self.omega0
        return signed_distance_to_convex(xi, P_step)

    def evaluate(self, q, qdot, qdd, tau, M, C, g, Jc, fc,
                 q_lim, tau_max) -> "PBSC":
        P_step = self._reachable_footholds(q, self.H_cap)
        x, xdot = self._com(q), self._com_vel(q, qdot)
        m_cap = self.capture_margin(x, xdot, P_step) - self.epsilon_robust
        m_joint = self._joint_margin(q, q_lim)
        m_act = self._actuator_margin(tau, tau_max)
        r_model = self._dynamics_residual(q, qdot, qdd, tau, M, C, g, Jc, fc)
        valid = (m_cap >= 0.0 and m_joint > self.delta_joint and
                 m_act > self.delta_act and r_model < self.delta_model)
        return PBSC(valid=valid, m_cap=m_cap, m_joint=m_joint,
                    m_act=m_act, r_model=r_model, t=time.time())

    def _dynamics_residual(self, q, qdot, qdd, tau, M, C, g, Jc, fc) -> float:
        """r_model = ||M q̈ + C q̇ + g − τ − J_c^T f_c||_{Σ_τ^{-1}} 的归一化值"""
        r = M @ qdd + C @ qdot + g - tau - Jc.T @ fc
        return float(np.linalg.norm(r) / (1.0 + np.linalg.norm(tau)))

    def cert_payload(self, c: "PBSC") -> dict:
        return {
            'cert_id': 'kc_body_valid',
            'payload': {'valid': c.valid, 'm_cap': c.m_cap,
                        'm_joint': c.m_joint, 'm_act': c.m_act,
                        'r_model': c.r_model},
            't_stamp': c.t, 'validity_window': 0.02, 'src_node': 'proprio'
        }
```

### IP-479 Cross-Modal Service Consistency (CMSC)

```python
@dataclass
class CrossModalServiceConsistency:
    """CMSC：腿部里程计预测外感知速度，Mahalanobis χ² 门控"""
    alpha: float = 0.01          # 第一类错误率
    bias_bound: float = 0.02     # 本体偏差范数上界 b̄ (m/s)

    def leg_odometry(self, qdot, contacts, foot_jacobians):
        """支撑脚速度反解基座速度；返回 (v_leg, Σ_leg)"""
        if not contacts:
            return np.zeros(3), np.eye(3) * 1e-2
        vs = [-foot_jacobians[i] @ qdot[i] for i in contacts]
        v_leg = np.mean(vs, axis=0)
        Sigma_leg = np.cov(np.array(vs).T) / max(len(vs), 1) + 1e-6 * np.eye(3)
        return v_leg, Sigma_leg

    def evaluate(self, v_vis, Sigma_vis, v_leg, Sigma_leg,
                 Sigma_model) -> "CMSC":
        e = v_vis - v_leg
        S = Sigma_vis + Sigma_leg + Sigma_model
        d2 = float(e @ np.linalg.solve(S, e))
        thr = chi2.ppf(1.0 - self.alpha, df=3)
        valid = d2 < thr
        # 共模盲区：若 v_vis 与 v_leg 同向同幅偏差，e≈0，d2 仍小
        return CMSC(valid=valid, d2=d2, e=e, S=S, t=time.time())

    def cert_payload(self, c: "CMSC") -> dict:
        return {
            'cert_id': 'kc_cross_consistent',
            'payload': {'valid': c.valid, 'd2': c.d2,
                        'residual_norm': float(np.linalg.norm(c.e))},
            't_stamp': c.t, 'validity_window': 0.05, 'src_node': 'cmsc'
        }
```

### IP-480 Service Blueprint Runtime (SBR)

```python
@dataclass
class ServiceBlueprintRuntime:
    """SBR：服务证据记录 + 来源链 + 服务级别/失败需求计量"""
    required_certs: set = field(default_factory=lambda: {
        'kc_vs_active', 'kc_loc_valid', 'kc_body_valid',
        'kc_cross_consistent', 'kc_student_admit', 'kc_teacher_admit'})
    sl_target: float = 0.95

    def record_evidence(self, cert_msg, provenance: list[str]) -> "SER":
        ser = SER(cert_id=cert_msg.cert_id, src=cert_msg.src_node,
                  t_gen=cert_msg.t_stamp, t_consume=time.time(),
                  validity=cert_msg.validity_window,
                  provenance=provenance)          # 来源链（DAG 路径）
        self.evidence_log.append(ser)
        return ser

    def _is_valid(self, cert_id, t_now) -> bool:
        ser = self.latest.get(cert_id)
        return (ser is not None and
                t_now - ser.t_gen < ser.validity)

    def service_level(self, t_now) -> float:
        coverage = sum(self._is_valid(c, t_now)
                       for c in self.required_certs) / len(self.required_certs)
        quality = self._control_quality()        # 1 − 归一化跟踪误差
        return float(np.clip(coverage * quality, 0.0, 1.0))

    def failure_demand_rate(self, window_s=60.0) -> float:
        events = [e for e in self.recovery_log if e.cause == 'cert_fail'
                  and time.time() - e.t < window_s]
        return len(events) / window_s

    def provenance_complete(self, output) -> bool:
        """每个控制输出都能追溯到时间有效的源证书（服务证据链完整）"""
        return all(self._has_valid_chain(c)
                   for c in output.justification_certs)
```

### IP-481 Failure-Demand-Aware Recovery Controller (FDARC)

```python
@dataclass
class FailureDemandAwareRecoveryController:
    """FDARC：按服务补救成本选择最小代价动作，并签发服务补救证书 SRC"""
    w_time: float = 0.5
    w_intervene: float = 0.3
    w_loss: float = 0.2
    sl_restore_target: float = 0.95
    LADDER = ('NONE', 'VSERVO_DEGRADE', 'FORCE_TEACHER',
              'STANCE_RECOVER', 'SAFE_STOP')

    def recovery_cost(self, t_restore, n_intervene, perf_loss) -> float:
        return (self.w_time * t_restore +
                self.w_intervene * n_intervene +
                self.w_loss * perf_loss)

    def select_recovery(self, violations, sl_now):
        """阶梯上选成本最低、且能把 SL 恢复到目标的动作"""
        best, best_c = 'SAFE_STOP', float('inf')
        for a in self.LADDER:
            if not self._feasible(a, violations):
                continue
            t_r, n_i, loss = self._predict(a, violations, sl_now)
            if self._predict_sl(a, sl_now) < self.sl_restore_target:
                continue
            c = self.recovery_cost(t_r, n_i, loss)
            if c < best_c:
                best, best_c = a, c
        return best, best_c

    def issue_recovery_cert(self, action, sl_after) -> dict:
        return {
            'cert_id': 'kc_recovery_ok',
            'payload': {'action': action, 'sl_after': sl_after,
                        'restored': sl_after >= self.sl_restore_target},
            't_stamp': time.time(), 'validity_window': 0.1,
            'src_node': 'fdarc'
        }
```

### IP-482 Service-Context-Aware Admission (SCA-KC)

```python
@dataclass
class ServiceContextAwareAdmission:
    """SCA-KC：情境 σ → 风险预算内期望 SL 最大的必需证书子集 M(σ)"""
    risk_budget: dict = field(default_factory=lambda: {
        'LOW': 1e-3, 'MID': 1e-4, 'HIGH': 1e-5})
    pareto: dict = field(default_factory=dict)   # 离线预计算

    def build_pareto(self, sigma, cert_subsets, risk_fn, sl_fn):
        front = []
        for M in cert_subsets:
            r, sl = risk_fn(sigma, M), sl_fn(sigma, M)
            if r <= self.risk_budget[sigma.risk_tier]:
                front.append((frozenset(M), r, sl))
        self.pareto[sigma.key] = pareto_filter(front)   # (风险↓, SL↑) 非支配

    def admit(self, sigma, certs_now) -> frozenset:
        front = self.pareto.get(sigma.key, [])
        if not front:
            return frozenset(self._all_certs())          # 无可行解→最保守
        return max(front, key=lambda x: x[2])[0]         # 预算内 SL 最大
```

### 服务闭环统一执行流（单步）

```python
def service_grounded_step(robot_state, sensor_data, sigma) -> ControlOutput:
    """证书链路 + 本体/跨模态互证 + 服务分级准入 + 失败需求感知补救"""
    # 0) v29 十二证聚合
    cert_agg = wait_for_topic('/cert/aggregated', timeout=0.005)
    if cert_agg is None or not cert_agg.all_passed:
        return fdarc.recover(cert_agg, sigma, cause='cert_agg_fail')

    # 1) 本体感知证书（1kHz，同进程零拷贝）与跨模态一致性
    pbsc = wait_for_topic('/cert/proprio', timeout=0.001)
    cmsc = wait_for_topic('/cert/cmsc', timeout=0.002)

    # 2) 服务分级准入：按情境决定必需证书子集 M(σ)
    M_sigma = sca.admit(sigma, certs_now={'pbsc': pbsc, 'cmsc': cmsc,
                                          **cert_agg})
    if not admission_ok(M_sigma, pbsc, cmsc, cert_agg):
        return fdarc.recover(M_sigma, sigma, cause='admission_fail')

    # 3) 学生 + 视觉伺服（多两道本体/跨模态门）
    student_out = wait_for_topic('/ctrl/student', timeout=0.001)
    if student_out and student_out.admitted:
        vs_out = wait_for_topic('/ctrl/vservo', timeout=0.002)
        if vs_out and pbsc.valid and cmsc.valid:
            u = blend_student_vservo(student_out.u, vs_out.u, alpha=0.3)
            return ControlOutput(u, path='student+vservo+proprio',
                                 justification={'pbsc', 'cmsc', 'vs'})
        return ControlOutput(student_out.u, path='student',
                             justification={'pbsc'})

    # 4) 教师兜底
    teacher_out = wait_for_topic('/ctrl/teacher', timeout=0.020)
    if teacher_out and teacher_out.admitted:
        return ControlOutput(teacher_out.u, path='teacher',
                             justification={'pbsc'})

    # 5) 服务补救（最小代价恢复 SL）
    return fdarc.recover(None, sigma, cause='no_path')
```

## 3. 复杂度分析（增量）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 | 实时性指标 |
|---|---|---|---|---|
| PBSC 可捕获裕度 | O(\|C\| + \|P_step\|) | O(\|P_step\|) | \|C\|≤2 | < 0.05ms |
| PBSC 动力学残差 | O(n²) | O(n²) | n≈20 | < 0.1ms |
| CMSC 腿部里程计 | O(\|C\|·6) | O(\|C\|·6) | \|C\|≤2 | < 0.05ms |
| CMSC χ² 门控 | O(3³) | O(3²) | 3 维 | < 0.01ms |
| SBR 证据记录/校验 | O(1) 摊还 / O(\|J\|) | O(\|J\|) | \|J\|≤12 | < 0.02ms |
| FDARC 阶梯选择 | O(5) | O(1) | 5 级 | < 0.01ms |
| SCA-KC 准入查表 | O(log\|front\|) | O(\|front\|) | 离线预计算 | < 0.01ms |
| **端到端单步（学生+VS+本体）** | **期望 < 4.5ms** | **O(n² + \|J\|)** | **P99 < 8ms** | **仍满足 200Hz** |

**通信开销增量**：PBSC 与 CMSC 各约 200–400 bytes，1kHz 本体流 ≈ 0.4 MB/s，可完全放入同进程零拷贝通道；服务证据记录仅在后台聚合，不进入控制热路径。

## 4. 正确性论证（增量）

### 引理 32（PBSC 可捕获裕度的可靠性）

**陈述**：考虑 LIPM，CoM 位置 x、速度 ẋ，自然频率 ω_0，DCM ξ = x + ẋ/ω_0；可达落足集 P_step(q) 为非空凸集。若 m_cap = dist(ξ, P_step) ≥ 0 且动力学残差 r_model < δ_model，则存在 p* ∈ P_step 使落足后 DCM 恒定、CoM 指数收敛到 ξ，即机器人一步可捕获。

**证明**：取 p* = proj_{P_step}(ξ) = ξ（因 ξ ∈ P_step）。DCM 动力学 ξ̇ = ω_0(ξ − p*) = 0，故 ξ(t) ≡ ξ。CoM 动力学 ẋ = ω_0(ξ − x)，解得 x(t) = ξ + (x(0) − ξ)e^{−ω_0 t} → ξ。故一步落足即可捕获。r_model < δ_model 保证真实动力学与 LIPM 偏差有界；PBSC 中以 ε_robust 补偿该偏差，故鲁棒意义下仍成立。∎

**工程含义**：m_cap 把「平衡」从模糊的经验阈值变成几何量——DCM 是否落在可达落足集内。当 m_cap < 0 时需多步规划，此时证书应报告 n-step viability 而非简单判否，避免过度保守。

### 引理 33（CMSC 的检测功效与共模盲区）

**陈述**：设 e_cm = v_vis − v_leg = (b_e − b_p) + (n_e − n_p)，n_e − n_p ∼ 𝒩(0, S)，本体偏差有界 ‖b_p‖ ≤ b̄。检验 d² = e_cm^T S^{-1} e_cm < χ²_{3,1−α}。则：
(i) 无故障（b_e = 0）时误报率 = α；
(ii) 若 ‖b_e − b_p‖_{S^{-1}} ≥ λ*(β)，检测功效 ≥ 1 − β，其中 λ* 由非中心 χ²_3(λ) 在阈值 χ²_{3,1−α} 处达到功效 1−β 确定；
(iii) 若 b_e = b_p（共模偏差），则无论故障幅值多大，检测功效恒为 α（不可检测）。

**证明**：(i) 标准 χ² 分布。(ii) e_cm 均值非零、协方差 S，d² 服从非中心 χ²_3(λ)，λ = ‖b_e − b_p‖_{S^{-1}}²；令功效 P(χ²_3(λ) ≥ χ²_{3,1−α}) ≥ 1−β 解出 λ*。(iii) b_e = b_p ⇒ E[e_cm] = 0，d² 分布与零假设完全相同，功效 = α。∎

**工程含义**：CMSC 能捕获「外感知单侧失效」，但**结构性地无法捕获本体与外感知共享的标定偏差**——这正是本轮最大风险的理论根源，必须靠独立第三方真值（如离线标定、外部动捕）打破共模。

### 引理 34（服务证据链的可审计性）

**陈述**：设服务蓝图 SB 为有向无环图。若每个被准入的控制输出 u 携带理由集 J(u)，且每个 c ∈ J(u) 都有到源节点的有效来源路径并满足 t_consume − t_gen < validity，则 (a) u 可由记录的服务证据 SER 复现；(b) 若任一 c ∈ J(u) 在消费时失效，则 provenance_complete(u) = False，u 被拒绝或降级。

**证明**：对 SB 拓扑序归纳。每个 SER 记录源节点、时间戳与父 SER，DAG 无环保证来源链有限且可回溯至源；逐条校验时间有效性即得 (a)(b)。∎

**工程含义**：这把上一轮的「可解释性」从人机界面升级为**可审计的服务责任链**——每个动作都能回答「凭哪几条证据、在何时、由哪个节点签发」。

### 引理 35（失败需求对证书约束的非单调性）

**陈述**：设 M ⊆ C_all 为必需证书集，FD(M) 为失败需求率。一般地 FD(M) 对 M 非单调：增加约束可减少「逃逸失败」从而降低 FD，但超过某点后增加「误拒」反而抬高 FD。故存在（可能情境相关的）M* 在风险预算下最小化 FD。

**证明（结构）**：分解 FD(M) = FD_escaped(M) + FD_false(M)。FD_escaped 关于 M 单调不增（更多约束拦截更多真实失败）；FD_false 关于 M 单调不减（更多约束误拒更多有效动作）。一非增与一非减函数之和不必单调；在有限格上必存在极小点。∎

**工程含义**：这是 SCA-KC 存在的理由——「证书越多越安全」在服务层面是错的；真正要优化的是风险预算下的 FD/SL 折中，而非证书数量。

### 定理（服务闭环的执行集收缩与失败需求下降）

**陈述**：在假设 (A1) v29 十二证时序有效；(A2) PBSC 有效且 m_cap ≥ 0（引理 32）；(A3) CMSC 有效且本体偏差 ≤ b̄（引理 33）；(A4) SCA-KC 在 ρ_budget(σ) 内选取 M(σ)；(A5) FDARC 将 SL 恢复至目标；则：
(i) Exec_new ⊆ Exec_CADVS ⊆ Exec_v29；
(ii) FD_new ≤ FD_CADVS − Δ_cm + Δ_false，其中 Δ_cm ≥ 0 为跨模态提前拦截所避免的失败需求，Δ_false ≥ 0 为误拒新增的失败需求；SCA-KC 通过选择 M(σ) 最大化 (Δ_cm − Δ_false)；
(iii) 在共模偏差 b_e = b_p 下 Δ_cm = 0，上述失败需求保证失效。

**证明**：(i) 新框架在 v29 准入之上仅增加 AND 门（PBSC、CMSC、M(σ) 必需集），故执行集只减不增。(ii) 由引理 35 的分解与引理 33 的检测功效：被 CMSC 提前拦截的失败原本会在下游触发回退，计入 Δ_cm；新增误拒计入 Δ_false；SCA-KC 在可行 M 中取期望 SL 最大者，等价于在风险预算内最大化净收益。(iii) 由引理 33(iii) 直接得。∎

**诚实声明**：(A2)(A3) 在实机中并非恒真。PBSC 依赖 LIPM 近似，跑步/跳跃/大姿态机动会破坏该假设（需切换 SLIP 或全动力学 viability）；CMSC 依赖接触检测准确，打滑/软地面会使腿部里程计产生系统偏差；更关键的是共模标定误差使 (iii) 成立而系统毫无察觉。服务闭环用 SBR 的在线监控与 FDARC 的分级补救管理这些风险，但**不能消除自我指涉的盲区**。

## 5. 实验设计（待验证）

**平台**：MuJoCo 简化双足（Cassie/Atlas 类，20 自由度），控制 200Hz，本体 1kHz，视觉 30Hz，定位 10Hz。

**场景**（每场景 200 episode，共 5 类 × 200 = 1000）：
1. 平地行走 + 随机推力（50–150N，0.1s）；
2. 湿滑地面（摩擦系数 0.3–0.6）；
3. 负载突变（行走中 +5kg，模拟身体模型失配）；
4. 视觉退化（光照突变、遮挡 30% 画面）；

|---|---|---|---|---|
| R19–R32 | v29/CADVS 既有风险 | — | 原样继承 | 不变 |
| R33 | **身体模型漂移导致「自信的错误」**（磨损/负载/标定使 PBSC 失效却仍报 valid） | **极高** | 1) r_model 在线监控 + 缓慢自适应标定；2) 周期性离线标定与外部真值校验；3) 模型残差超阈值时强制降级到教师路径；4) 对模型参数维护不确定度带，按鲁棒裕度 ε_robust 保守化 | 缓变漂移可被 r_model 捕捉，但**快变且自洽**的漂移（模型与传感器同时偏）仍会漏检 |

## 7. 本轮最大风险（最终确认）

**一句话**：**本体感知证书的自我指涉悖论**——PBSC/CMSC 用「身体模型」去验证「身体」自身，而身体模型会因磨损、负载变化与标定漂移而失配；此时系统以极高置信度给出「一切正常」，且跨模态校验在共模偏差下（引理 33(iii)）结构性地无法察觉。这不是时序问题、也不是算法精度问题，而是**认识论层面的盲区**：系统在最需要外部真值的时刻，恰恰丧失了对自身模型有效性的独立判据——只能靠独立第三方真值与周期性离线标定打破共模，而不能靠系统内部的自洽性证明。
