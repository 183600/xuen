# 第 10 轮（新灵感循环第 1 轮；本轮灵感：「预测性维护」×「实时推理」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**事前预测 + 任意时间推理**。预测性维护治理 v9 的「滞后债」——退化靠 Δ_dom 的 20 帧滑窗事后触发；实时推理治理 v9 的「静态债」——把神经时延当成常数 Ŵ_m，无法表达输入相关的长尾。关键纪律：新组件全部以中立元/无操作退化，任一失效逐位退回 v9；领先信号只在**可证安全**的包络内获取，绝不以安全换探索。

## 0. 直觉与动机

**灵感 1（预测性维护 → 前向模型与模块健康的预后）**
直觉：v9 的退化是"坏了才补"：Δ_dom 越阈、证书失效、模块超时之后才注入 v^⊥。预测性维护是"在坏之前换件"。系统里存在三类可被预后的"磨损"：(a) 冻结前向模型 F̂ 的残差随域漂移单调增厚；(b) 神经模块的时延长尾随负载/缓存/温度变厚；(c) 块证书的余量在块内被逐步消耗。关键观察：**块每执行一步都能观测到真实指标**，与块生成时 F̂ 的预测形成残差 r_t——这是比 Δ_dom 更直接、更快（1 步 vs 20 帧滑窗）的前置信号。核心创新：**预后健康监测器（PrognosticHealthMonitor, PHM）**：为每模块维护健康 h_m 与剩余寿命 τ̂_m，并用**在线共形上界 β_t**（ACI 自适应更新）替代 v9 的静态余量 β。证书余量从此是"会呼吸的"：残差变厚 ⇒ β_t 上升 ⇒ 证书自动收紧；残差平稳 ⇒ β_t 回落 ⇒ 释放保守性。

**灵感 2（实时推理 → 质量-预算曲线与推测执行）**
直觉：v9 契约把 Ŵ_m 当静态最坏执行时间，但神经推理的时延是输入相关分布：静态上界要么保守浪费预算，要么在长尾上引发超时风暴（v8 遗留的"抖动→虚假退化"）。实时推理思想：不追求"一次算完"，而追求"在截止期内给出尽可能好的结果"。核心创新：**任意时间推理契约（AnytimeInferenceContract, AIC）**：模块暴露早退阶段链，质量-预算曲线 Q_m(b) 单调不减；到点即用当前阶段输出并附校准置信；无阶段完成才注入 v^⊥。配套 **推测式分块生成器（SpeculativeChunkGenerator, SCG）**：低成本生成大量候选、预算内用全保真 F̂ 只验证前 ν 个——把 5Hz 块生成的尾延迟压下来，且**不改变接受谓词**。

**融合（关键创新）**
两者不是并列，而是一个闭环：**预测性实时推理（Prognostic Real-Time Inference, PRTI）**。预算治理不再是"到点超时再退化"的反馈，而是"预测下一周期将超时/残差将越界 ⇒ 提前降低推理深度、缩短块长、启动维护"的前馈。核心创新：**预后预算治理器（PrognosticBudgetGovernor, PBG）** + **事前风险压力 ρ_t = max(Δ_dom/τ_dom, β_t/β_max)** 驱动 K_eff 与 anytime 深度。即：把 v9 的"事后中立元退化"升级为"事前预测性降级 + 事后中立元兜底"。

## 1. 研究问题（轮次升级版）

- **Q1（前置信号有效性）**：执行条件残差 r_t 的共形上界 β_t 能否在 Δ_dom 之前捕捉域跳变？领先量如何定义与测量？系统的保守动作会否把危险状态"删失"出观测分布，从而让 β_t 系统性低估？
- **Q2（任意时间的等价性）**：早退输出的任意截断是否仍落在 v9 退化格点内（不得产生比 v9 更激进的安全证书）？质量-预算曲线 Q_m(b) 如何标定并验证其单调性与置信校准？
- **Q3（维护安全边界）**：重标定 β、刷新 F̂、缓存预热等维护动作，在什么安全窗口 W_safe 内、以什么可退化方式执行，才不引入新的瞬态风险？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 预测性维护律（Prognostic Maintenance, PHM）**
每模块维护 (h_m, τ̂_m)；维护动作 α 自身是一条带截止期 D_α 与中立元 no-op 的契约，仅在安全窗口 W_safe 内执行、且只在块边界原子生效；维护失败 ≡ 未维护（逐位无操作）。

**P14 任意时间推理律（Anytime Inference, AIC）**
神经模块返回 (y, q, b_used)；Q_m(b) 单调不减；q < q_req 的输出视同低置信分支，不得用于放宽任何证书；无阶段完成 ⇒ v^⊥。降低预算只会让输出沿 v9 退化格点**向下**移动，绝不允许向上。

**P15 共形证书律（Conformal Certificate, PHM-MW）**
块证书余量 β_t 由在线共形上界给出，长期覆盖率 ≥ 1−α；数据稀缺或更新滞后时按"不确定性乐观膨胀"增大 β_t；β_t 只允许收紧安全判据，不允许放宽既有硬约束。

## 3. 与基线的接口（如何退化）

- PHM 失效 ⇒ β_t 冻结为 v9 静态 β，K_eff 退回纯 Δ_dom 门控（逐位 = v9）；
- AIC 失效 ⇒ 仅在末阶段完成时输出、否则 v^⊥（= v9 固定 WCET 语义）；
- SCG 失效 ⇒ 退回 v9 全量候选生成 + 全保真验证；
- PBG 失效 ⇒ 退回 v9 的 EDF 静态预算表；
- v9 的 AC/MW/ID 任一失效 ⇒ 沿引理 83/92 注入对应中立元，继续退回 v8；
- 全部失效 ⇒ 完整退回 MetricVoiceGauge-OTL-GC-ER v7，再退回 v6。

## 4. 预期贡献

1. **预后-共形证书**：把前向模型可靠性从"离线标定常数"变成"在线、自适应、带长期覆盖保证的时变量"，并证明其逐位包含 v9 的退化；
2. **任意时间推理契约**：用质量-预算曲线取代静态 WCET，使 EDF 可行性从"最坏情形"转为"可截断质量"；
3. **推测式分块**：候选生成与验证解耦，尾延迟由 b0+b_ver 直接界定，且接受谓词不变、安全性可复用；
4. **预测性预算-维护闭环**：把 prognostic maintenance 落地到计算管线，事前降级 + 安全窗口维护；E571–E590 覆盖覆盖性、领先量、删失审计、anytime 校准、维护安全与端到端任务。

## 5. 本轮最大风险

**一句话**：预测性维护的全部领先信号都只在"已执行的轨迹"上可观测，而系统自身的保守门控会主动回避高风险状态——安全动作把危险证据从校准分布中删失，一旦风险集中在被回避的陌生区域，β_t 与 τ̂_m 会系统性低估，形成"越安全越看不见危险"的自审查盲区。

## 1. 符号体系增量（定义 540–547）

**新增定义 540（模块健康态与剩余寿命 PrognosticHealth）**
模块 m 在 t 的健康由协变量经风险模型给出（Cox/Weibull 或带协变量的指数风险）：
```
z_m(t) = ( L_m^p99(t)/D_m ,  Ṅ_m(t) ,  q_{1−α}(r_m)(t)/β_max ,  1 − margin_m(t) )
λ_m(t) = λ_0 · exp(⟨w_m, z_m(t)⟩) ,   h_m(t) = exp(−λ_m(t)Δt)
τ̂_m(t) = inf{ Δ ≥ 0 : E[h_m(t+Δ)] ≤ h_fail }
```
其中 Ṅ_m 为超时 strike 速率，margin_m 为块证书/契约的归一化余量。τ̂_m 以分位区间给出；区间过宽时按保守端使用。健康模型仅在离线证据覆盖的工况内可信，越出即视为 h_m=0 并触发最保守门控（定义 546）。

**新增定义 541（执行残差与在线共形上界 ConformalResidualBound）**
块生成时 F̂ 预测指标轨迹；块内第 k 步执行后观测真实指标 m_k^real，聚合最大归一化残差：
```
r_t = max_{k executed} | m_k^real − m̂_k | / scale
```
ACI 自适应共形更新（β 有界于 [β_min, β_max]）：
```
β_{t+1} = clip( β_t + η·(α − 1[ r_t > β_t ]), β_min, β_max )
β_t^+ = β_t · (1+γ) + κ·sqrt( log(1/δ) / max(1, n_eff) )     # 数据稀缺时悲观膨胀
```
`n_eff` 为当前工况下的有效残差样本数（含逆倾向加权，见定义 547）。证书使用 β_t^+（定义 533 升级）。**β_t^+ 只进入收紧方向**：任何 \hat g 判据中的余量减项只能取 max(β_t^+, β_static)。

**新增定义 542（任意时间推理契约 AnytimeInferenceContract）**
模块 m 暴露早退阶段链 {(w_{m,e}, q_{m,e})}_{e=1..E_m}，累计最坏耗时 W_{m,e}=Σ_{j≤e} w_{m,j}，质量 q 单调不减。给定预算 b：
```
e*(b) = max{ e : W_{m,e} ≤ b }
output = (y_{e*}, q_{e*}, W_{m,e*})   若 e* 存在；否则 (v_m^⊥, 0, 0)
Q_m(b) = q_{m,e*(b)}                  （非减阶梯，取凹包络 Q̄_m 供 PBG 优化）
```
契约从 v9 的 (In,Out,D_m,Ŵ_m,v^⊥,π_m,φ^elig) 升级为 (In,Out,D_m,Q_m,v^⊥,π_m,φ^elig)；Ŵ_m=W_{m,E_m} 仅作静态可行性校验的兜底上界。

**新增定义 543（推测式分块 SpeculativeChunk）**
在阶段预算 b0 内用低成本策略生成 N 个候选前缀，按廉价得分排序取前 ν；剩余预算 b_ver 内用全保真 F̂ 逐个验证：
```
cands = [ low_fidelity(state, K) for _ in range(N) ]          # 总耗 ≤ b0
for cand in top_ν(cands, key=cheap_score):
    if b_ver ≤ 0: break
    pred = F.rollout(state, cand, budget=b_ver); b_ver -= pred.cost
    if accept(cand, pred) and abort_points(cand, pred): accept_best(cand)
return accept_best or single_step_fallback(state)             # AC 的中立元
```
**关键不变式**：`accept(·)` 与中止点判据（定义 533/534）与 v9 **逐字相同**；推测只改变候选的枚举顺序与数量，不改变接受集合的上界，故引理 82 的证书可靠性继续成立。未验证候选永不接受；无候选通过则返回单步 fallback。

**新增定义 544（预后预算治理 PrognosticBudgetGovernor）**
设安全关键集合 S0（M₀ 硬检查、SpatialCert、FaultCert、MW 自身、AC 证书检查）。每周期：
```
Phase 1（字典序安全）: b_m ← b_min(m), ∀m∈S0；若 Σ_{S0} b_min > B_dec ⇒ 直接退回 v9 静态预算（fail-safe）
Phase 2（质量水填）:   在剩余预算上最大化 Σ_{m∉S0} Q̄_m(b_m) + λ·Σ_m u(τ̂_m)
                     s.t. 0 ≤ b_m ≤ D_m，按 Q̄ 的凹性做 water-filling
Phase 3（前馈降级）: 若 max_m P( latency_m > D_m | z_m ) > ε 或 min_m τ̂_m < τ_warn
                     ⇒ 提前把 AC 的 K_eff 与 AIC 的最大阶段数各降一档，并登记维护候选
```
安全关键模块的 b_min 享有字典序优先，任何优化都不得挤占；挤占即视为 PBG 失效并回退 v9。

**新增定义 545（维护动作与安全窗口 MaintenanceAction）**
维护动作 α ∈ {重标定 β_t、刷新 F̂、缓存预热、契约再协商、预算碎片整理}，每个 α 是一条契约 (D_α, v_α^⊥=no-op)。仅当同时满足：
```
W_safe:  存在已认证块且 P_t ≠ ∅
         且 live_clearance − d_brake(v) − d_safe ≥ 2·d_safe
         且无挂起中止、无未决 L1 退化
```
方可在**块边界**执行。α 的输出只在下一块生成时被消费（原子生效）；超时或失败 ⇒ MW 注入 no-op ⇒ 系统状态与执行前逐位一致。故维护对当前块无副作用，只可能改变后续块的 β/F̂/缓存。

**新增定义 546（事前风险压力与 K_eff EffectiveRiskPressure）**
```
ρ_t = max( Δ_dom(t)/τ_dom ,  β_t^+/β_max ,  1[ min_m τ̂_m(t) < τ_warn ] )
K_eff(t) = 1                                         若 ¬U_t 或 ρ_t ≥ 1
         = max(1, ⌊ K_max·(1 − ρ_t) ⌋)                否则
```
当 PHM 失效（β 项置 0）且去掉 τ̂ 项时，ρ_t 退化为 Δ_dom/τ_dom，K_eff 逐位等于 v9 定义 539。β 项是**前馈**通道：残差增厚会在 Δ_dom 尚未越阈时先抬高 ρ_t、先收缩 K_eff。

**新增定义 547（执行条件残差删失与安全包络探针 CensoredResidualProbe）**
残差仅在块步被真正执行时可观测：o_t∈{0,1}。为抑制"系统回避危险 ⇒ 看不见危险"的自审查偏差，定义：
- **安全包络探针**：以概率 ε_probe，在 P_t≠∅ 且余量 ≥ 2(d_brake+d_safe) 时执行探针步（取当前块首步或 K=1 fallback），采样被保守策略回避区域的残差；
- **逆倾向加权**：r̃_t = o_t·r_t / π_t，π_t=P(o_t=1|z_t) 由健康协变量估计；
- **保守兜底**：探针关闭、π_t 不可信或 n_eff < n_min 时，β_t^+ ← β_max（等价 K_eff=1 的最保守门控）。
探针只允许在证书认证的停机距离之外进行，探针本身不得改变当前块的中止点集与执行动作集合。

## 2. 形式化定义（要点与升级）

**定义 493（六层指标层级）/ 495 / 524 / 521** 继承 v8/v9 不变。

# IP-357 PrognosticHealthMonitor：预后健康监测 + ACI 共形余量
class PrognosticHealthMonitor:
    def __init__(self, beta0, alpha=0.05, eta=0.02, gamma=0.2,
                 beta_max=0.10, kappa=0.5, delta=0.05):
        self.beta, self.alpha, self.eta = beta0, alpha, eta
        self.beta_max, self.gamma, self.kappa = beta_max, gamma, kappa
        self.delta, self.n_eff = delta, 1

    def observe(self, pred_metrics, real_metrics, scale):
        r = max(abs(a - b) / scale for a, b in zip(real_metrics, pred_metrics))
        self.beta = clip(self.beta + self.eta * (self.alpha - (1.0 if r > self.beta else 0.0)),
                         self.beta_min, self.beta_max)
        self.n_eff += 1
        return r

    def beta_conservative(self):
        inflate = self.kappa * sqrt(log(1.0 / self.delta) / max(1, self.n_eff))
        return min(self.beta_max, self.beta * (1.0 + self.gamma) + inflate)

    def health(self, z):            # 风险模型映射，越界工况 h=0
        if not self.in_envelope(z): return 0.0
        return exp(-dot(self.w, z) * self.dt)

    def rul(self, m, z):
        return self._first_passage(m, z, h_fail=self.h_fail)  # 分位区间，取保守端

    def risk_pressure(self, delta_dom, tau_dom, beta_max, tau_warn):
        beta_term = 0.0 if self.disabled else self.beta_conservative() / beta_max
        rul_term = 1.0 if min(self.rul.values(), default=1e9) < tau_warn else 0.0
        return max(delta_dom / tau_dom, beta_term, rul_term)


# IP-358 AnytimeInferenceContract：早退阶段链
class AnytimeModule:
    def __init__(self, stages):     # [(wcet_ms, quality, head_fn), ...]
        self.stages = stages

    def infer(self, x, budget_ms):
        used, best = 0.0, None
        for w, q, head in self.stages:
            if used + w > budget_ms:
                break
            y = head(x); used += w; best = (y, q, used)
        if best is None:
            return self.neutral, 0.0, 0.0     # 无阶段完成 ⇒ v^⊥
        return best

    def quality_curve(self, b):
        return self.stages[max(0, self._e_star(b) - 1)][1] if self._e_star(b) else 0.0


# IP-359 SpeculativeChunkGenerator：低成本枚举 + 预算内全保真验证
class SpeculativeChunkGenerator(ActionChunkCertifier):
    def __init__(self, *args, N=64, nu=8, b0_ms=2.0, **kw):
        super().__init__(*args, **kw)
        self.N, self.nu, self.b0 = N, nu, b0_ms

    def generate_speculative(self, state, K, beta_t, budget_ms):
        if K == 1:
            return self._single_step_fallback(state)          # AC 中立元
        cheap = [self.low_fidelity_policy(state, K) for _ in range(self.N)]
        ranked = sorted(cheap, key=self.cheap_score, reverse=True)[:self.nu]
        b_ver, best = budget_ms - self.b0, None
        for cand in ranked:
            if b_ver <= 0:
                break
            pred = self.forward_model.rollout(state, cand, budget_ms=b_ver)
            b_ver -= pred.cost
            if not self._cert_ok(pred, beta_t):                # 定义 533'
                continue
            pts = self._abort_points(state, cand, pred)        # 定义 534
            if not pts:
                continue
            sc = self.policy.score(cand, pred)
            if best is None or sc > best.score:
                best = Chunk(cand, Cert(pred, beta_t), pts, sc)
        return best or self._single_step_fallback(state)       # 未验证不采用


# IP-360 PrognosticBudgetGovernor：字典序安全 + 质量水填 + 前馈降级
class PrognosticBudgetGovernor:
    def __init__(self, safety_set, b_min, b_dec_ms=20.0, eps=0.05):
        self.safety_set, self.b_min = safety_set, b_min
        self.b_dec, self.eps = b_dec_ms, eps

    def allocate(self, modules, phm, load_pred):
        if sum(self.b_min[m] for m in self.safety_set) > self.b_dec:
            return self.v9_static_fallback()                  # fail-safe
        alloc = {m: self.b_min[m] for m in self.safety_set}
        free = self.b_dec - sum(alloc.values())
        alloc.update(water_fill(modules_rest(modules), free,
                                utility=lambda m, b: modules[m].quality_curve(b)))
        # 前馈：预测将超时/健康将越界 ⇒ 提前降档
        self.forecast_downgrade(phm, load_pred, alloc)
        return alloc

    # ---- v9 继承路径（早退推理按预算截断；低置信路由到保守分支）----

## 4. 推导

**引理 87（共形余量的长期覆盖与保守性）** 设残差有界 r_t∈[0,β_max]，按定义 541 的 ACI 更新。则长期失配率满足
```
| (1/T)Σ_{t≤T} 1[r_t > β_t] − α | ≤ (β_max − β_min)/(ηT) + o(1)
```
故 β_t^+ = β_t(1+γ)+膨胀项以长期概率 ≥1−α−O(1/(ηT)) 覆盖真实残差；证书判据使用 β_t^+ 时对前向模型误差保守。若残差在工况内可交换，可改用 split-conformal 的 ⌈(n+1)(1−α)⌉ 阶统计量，得到有限样本覆盖 P(r≤β̂)≥1−α。**注意**：这是边际（长期）保证，不给出逐点条件保证；突变后的下一步仍可能失配，故需 γ 安全系数与定义 547 的悲观兜底。

**引理 88（残差通道相对 Δ_dom 的测量领先量）** 令漂移期残差单调增厚 r_{t+1}−r_t ≥ δ>0，安全阈值 β*，Δ_dom 的滑窗长度为 W=20、检测器附加延迟 d_det≥0。残差 r_t 在第 t+1 周期即可用于更新 β_t（测量延迟 1 周期），而 Δ_dom 需累积 W+d_det 周期。故在相同阈值、相同漂移速率下，β 通道的门控触发时刻满足
```
t_gate^β ≤ t_gate^Δ − (W − 1)        （⇒ 至少提前 W−1 ≈ 19 周期 ≈ 380ms）
```
若漂移平滑，RUL 外推还可再提前 ⌈(β*−β_t^+)/δ⌉ 周期。证明：由单步可观与滑窗定义直接比较两者的首次越阈时刻。**边界**：若残差只在极少数执行步被观测（n_eff 小），膨胀项会把 β_t^+ 直接抬到 β_max，此时领先量退化为 0，但仍不会晚于 v9（最保守）。∎

**引理 89（任意时间推理的单调性与不夸大安全性）** Q_m(b) 对 b 单调不减 ⇒ e*(b) 单调；预算降低只会让输出停在更早阶段 e'≤e*。任一阶段输出只携带自身 q_{e'}，证书与安全判据不得引用未完成的高阶段结论；当 q_{e'}<q_req 时输出被路由到保守分支或 v^⊥。因此 anytime 截断使系统输出沿 v9 退化格点**向下**移动，永不向上；对任意预算序列，安全不变式由归纳保持。∎

**引理 90（推测式分块的时限安全与完备性）** SCG 的总耗时为 b0+b_ver≤B_dec，且 N 只影响廉价阶段（受 b0 约束），不影响验证阶段上界 ⇒ 尾延迟独立于 N。接受谓词 accept(·) 与中止点判据与 v9 逐字相同，未验证候选永不接受，故被接受块集合 ⊆ v9 可接受集合，引理 82 的证书可靠性与中止安全性继续成立。若无候选通过或预算耗尽，返回单步 fallback（AC 中立元），即引理 89 的最保守端。故推测只改变搜索顺序/采样数，不改变安全语义。∎

**引理 91（维护动作的安全性与可退化性）** 每个 α 是带 (D_α, no-op) 的契约，仅在 W_safe 且块边界执行，输出只被下一块生成消费。若 α 超时/失败，MW 注入 no-op ⇒ 状态与执行前逐位一致（引理 92 的实例）。W_safe 要求已认证块且 P_t≠∅、余量 ≥2(d_brake+d_safe)，保证维护期间始终存在可中止点，维护不会吃掉唯一的安全余量。由于维护不改变当前块的动作序列或中止点集，当前块的安全证书不受影响；下一块以新 β/F̂ 重新生成并重新认证。故维护不降低安全不变式。∎

**引理 92（严格退化到 v9）** 逐项关闭新组件：PHM⇒β_t^+≡β、ρ 去掉 β 与 τ̂ 项；AIC⇒Q_m 为末阶段阶跃、W_{m,E}=Ŵ_m；SCG⇒N 全量、ν=N、b0=0（全保真验证）；PBG⇒v9 EDF 静态表；维护⇒no-op。此时定义 533'/535'/536'/539'/546 逐条还原为 v9 的 533/535/536/539，算法骨架中所有分支与 v9 主环逐指令相同，故可观测行为逐位等于 v9；再应用 v9 引理 83 得 v8/v7 的严格退化。任一子集失效给出对应的 v9 子行为，组合失效按格点下确界退化。∎

## 8. 本轮最大风险

**一句话**：预测性维护的全部领先信号都只在"已执行的轨迹"上可观测，而系统自身的保守门控会主动回避高风险状态——安全动作把危险证据从校准分布中删失，一旦风险集中在被回避的陌生区域，β_t 与 τ̂_m 会系统性低估，形成"越安全越看不见危险"的自审查盲区；安全包络探针与逆倾向加权只能缓解、不能根除，且探针本身要消耗安全余量。
