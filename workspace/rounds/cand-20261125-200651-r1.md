（灵感驱动研究循环·新灵感二元组第 1 轮；本轮灵感：「传感器融合」×「语音合成」）

> **基线**：上一轮产出 MetricVoiceGauge-NCD-HUTDH-v23 + IP-431–439（云边同步 CESC / 少样本有效 FSVC / 知识产权 IPAM / 四证准入门 HPC-E+ / 共识 CFC+++），其上承 v22 分层 PGEV（HDL/ACSC/DCSC/HPC-E/CFC++）、v21 语义-规范层（SDC/CAC/DCL/GIC/HPC+/CFC+）、v20 联邦感知证书（PCA/CTS/CFC/HPC/CFCtrl）与 v19/v17 全部模块。
> 本轮纪律：**不推倒 v23**。IP-431–439、P37–P42、定义 926–999 全部保留。本轮只做两件互相咬合的事：**(A) 用传感器融合把「投票式共识」升级为「信息形态、对相关性免疫的估计融合」——正面封堵贯穿全会话的最大风险（相关误判共识／众口铄金）；(B) 用语音合成把「证书」从只读的内部对象扩展为「可发声、可承诺、可追责的言语行为」，并严格约束「说出去的话不得超出已证能力」**。一句话：v24 = v23 之上的「融合–言说层」（Fusion–Utterance Layer）。

## 0. 直觉与动机

**灵感 1（传感器融合 → 从「数票」到「信息形态」，让融合对未知相关免疫）**
直觉：前几轮其实一直在「数票」。v20 的 CFC、v21 的 CFC+、v22 的 CFC++、v23 的 CFC+++，越来越努力地给票数打补丁：要求模态数 ≥ 2、NMS 去重、层级一致、云边版本一致。但数票有一个从未真正拆掉的地基假设——**它把不同来源当成相互独立的信息**。传感器融合的经典结论恰好把这个假设掀翻：在独立假设下把信息矩阵相加，会**重复计数、过分自信（double counting）**；而协方差交叉（Covariance Intersection, CI）在「各源互相关未知、但每个源的边缘不确定上界有效」时，给出**保证一致、且永不比独立融合更自信**的估计。这正是「众口铄金」的数学解药。**反直觉点**：融合的目标不是「更准」，而是「更不自欺」——一个正确的融合器在相关故障下应当比单传感器**更保守**，而不是更激进地缩小不确定集。于是「共识」从**计数问题**变成**一致性检验问题**：票多不再等于可信，只有在信息形态上通过一致性闸门的证据才能收缩安全集。

严谨表述：每个源 `i` 产出证书化估计 `(x̂_i, P_i)`，其中 `P_i` 是由 SDC/DCSC/CAC/conformal 给出的**上界协方差**（已含安装、标定、时间同步误差）。CI 融合为

`P_CI^{-1} = Σ_i ω_i P_i^{-1},  x̂_CI = P_CI · Σ_i ω_i P_i^{-1} x̂_i,  ω_i ≥ 0, Σ_i ω_i = 1`

若每个源满足 `E[e_i e_i^T] ⪯ P_i`（`e_i = x_i − x̂_i`）且互相关**任意未知**，则 `E[e_CI e_CI^T] ⪯ P_CI`（一致性），且 `P_CI ⪰ P_ind := (Σ_i P_i^{-1})^{-1}`（永不比「假装独立」更自信）。收缩安全集前还必须过**两两一致性闸门** `d_ij^2 = (x̂_i−x̂_j)^T (P_i+P_j)^{-1} (x̂_i−x̂_j) ≤ χ²_{d,1−α}`；不过门 ⇒ 不得收缩，只能取并/膨胀。共同模式误差用加性项 `P_i ← P_i + κ_cm Σ_cm` 计入，并引入一条**非共享 sanity 通道**（压感地垫／机械触须／独立信标）做相关故障探测。

顺带一个被忽视的推论：**负信息也必须按相关性融合**。「没检测到」不是免费的空集，而是一次带灵敏度模型的测量；在相关未知时，`M` 个冗余的「没看见」不能被当成 `M` 份独立证据相乘，只能用凸组合，有效独立计数 `M_eff ≤ M`，于是冗余只能把「空」证成「空」，绝不能把「空」证成「真空」。

**灵感 2（语音合成 → 言语即承诺：把证书外化为可依赖、可撤回、可送达的公共行为）**
直觉：v21 的 GIC 只把「人的手势」当输入，机器人自己是**哑的**。语音合成让机器人成为会说会做的行动者——但说话本身就是行动。按言语行为理论（Austin/Searle），警告、承诺、命令都是**以言行事（illocutionary act）**：话一出口就产生义务、也产生人类的**依赖**。最危险的不是「说错词」，而是「说对话」：一句「我要停下／我要让行」若被人类采信并据此移动，而上游证书随后失效，机器人就制造了一个**真诚的陷阱**。语音合成又是生成模型，天然会**幻觉**——说出未被证书支持的内容。因此必须**接地（grounding）**：合成文本只能是已准入证书的**确定性投影**，不能自由生成。**反直觉点**：语音不是「多了一个输出通道」，而是把内部证书**外化为人类可依赖的公共承诺**；正因为它公开、一对多、且时间上不可撤回，它必须是**单向、可撤回、且带送达保证**的——「说了」不等于「听到了」，「听到了」不等于「照做了」。

严谨表述：接地投影 `U = Proj(π, Cert)`，`Proj` 是确定性模板投影，仅当 `π ∈ Exec` 且 `Cert` 覆盖该句子的真值条件时才允许发声（**无证不言**）。每个承诺携带四元组 `Cmt = (plan_id, τ_commit, Y_set, retract_id)`，并附**真诚性条件**：被承诺的计划必须在 `H_sincerity = τ_commit + τ_delivery + τ_reaction` 的整个地平线内保持可行；否则降级为**非承诺性警告**（只说「注意，我在此」，不承诺具体让行动作）。送达义务只有满足 `p_deliv(τ) ≥ 1−α ∧ Ack(τ)`（信息年龄 `AoI ≤ τ`）才算履行；否则升级到更高保证的非语言通道（灯／声／减速／停），并收缩 Exec。声学闭环还须**自证隔离**：机器人自己合成的语音是**已知相关**的证据，先扣除自相关；未知部分走 CI；自己的话永不作为「有人在场」的证据。

**两者如何统一**
v23 的证书是**单侧**的：只把世界融进内部（感知），不把内部约束送到世界（言说）。v24 把证书变成**双向信息流**：感知侧用信息形态融合保证「进来的证据不重复计数」，言说侧用接地投影保证「出去的话不超出已证能力」，两侧都用同一条纪律——**宁可保守，不可自欺**。共享状态扩展为 `ζ_fu = ζ_ce ∪ (I_t, P_t^cm, U_t, Cmt_t, Ack_t, ALC_t)`，其中 `I_t` 是信息形态集合、`ALC_t` 是声学闭环状态。统一准入门 **HPC-F = HPC-E+ ∧ CI-consistent ∧ GroundedUtterance ∧ (Delivered-if-obliged)**：只有「上游四证仍在 ∧ 融合一致 ∧ 言语接地 ∧ 该送达的已送达」才进入执行；任一缺失只向收缩方向退化。共识协议升级为 **CFC++++**：用「信息矩阵一致、且扣除相关后独立信息非零」替代「票数 ≥ N−F」——数学上把「众口」折回「一口」，除非确有独立依据。

## 1. 研究问题（轮次升级版）

- **Q12（相关未知下的融合可靠性界）**：如何用 conformal/证书化手段得到每个源的**有效上界协方差** `P_i`（含共同模式项 `κ_cm Σ_cm`），使 CI 的一致性与「永不比独立融合更自信」真正成立？两两 Mahalanobis 闸门的阈值 `χ²_{d,1−α}` 如何在「漏报相关故障」与「过度保守导致活性坍缩」之间标定？当所有模态共享同一物理病因（雾、逆光、同版固件、同批训练偏差）时，非共享 sanity 通道能以多小概率、多大延迟把共同模式偏置识别出来？

- **Q13（负信息的相关融合）**：如何把「没检测到」写成带灵敏度模型的测量，并在相关未知时用 `M_eff ≤ M` 的有效独立计数融合，使冗余传感器不能把 AbsCert 从「空」放大成「真空」？κ_c 这一**经验召回下界**与 CI 上界如何叠加而不互相抵消？AbsCert 在「共同模式漏检」被 sanity 通道触发时，如何 fail-safe 地翻转为全域「假设有人」并回收已赎回的自由空间？

- **Q14（接地与承诺的形式化）**：如何定义确定性投影 `Proj`，保证任何合成句子都是已准入证书的纯函数、不引入幻觉内容？如何把 DCL 的 F/O/P 义务编译为对应的言语行为义务（警告/承诺/撤回），使「说了必须做、做不到不许说」成为可机械检查的约束？`H_sincerity` 内计划可行性的证书如何给出，且不因口头承诺反向扩大 `Exec`？

- **Q15（送达保证与时序）**：如何在 50Hz 控制环之外，用信道模型 + 确认（ASR/显式应答/行为应答）判定「告知义务已在 τ 内以 ≥1−α 送达」？AoI 阶梯与 v17 APS 新鲜度阶梯、v23 CESC 双轨切换窗口 `T_switch` 如何叠加而不产生相位共振？送达失败的多级升级（语音→视听→声光→减速/停）如何保证每一步都只收缩 Exec？

- **Q16（声学闭环与自证隔离）**：自播语音与麦克风之间的已知相关（自回波）如何精确扣除，未知残余如何用 CI 保守处理，从而杜绝「机器人听见自己的合成语音→误判有人回应/在场」？人类口头回应作为新证据重新进入融合时，如何携带自己的证书（说话人确认、语义解析置信、时延），且其相关性不被二次计数？

## 2. 设计原则（在 P37–P42 基础上新增 P43–P46）

**P43 信息形态不重复计数律（Information-form Non-Double-Counting）**
安全集收缩只能基于信息形态融合，且融合必须是相关性鲁棒的：`I_CI = Σ_i ω_i I_i`（`I_i = P_i^{-1}`，`Σω_i = 1`），`P_CI = I_CI^{-1}`。每个 `P_i` 是含共同模式项的**上界**；只有两两一致性闸门 `d_ij^2 ≤ χ²_{d,1−α}` 全部通过，才允许用 `P_CI` 收缩；否则取并（`P_∪ ⪰ P_i`）并只增不减。因 `ω_i ≤ 1 ⇒ P_CI ⪰ P_ind`，融合**永不比独立假设更自信**。负信息同理：`Δlog-odds = Σ_i ω_i Δ_i`（凸组合），冗余不得相乘。故 `Obs_t` 与「人可能在此」的保守集在任何相关未知情形下都不会被错误收缩。

**P44 承诺-能力耦合律（Commitment–Capability Coupling）**
任何合成语句都是 `Proj(π, Cert)`，其中 `π ∈ Exec_v23` 且 `Cert` 覆盖其真值条件；**言语不创造新的执行能力**。每个承诺携带截止期、可执行集合与撤回动作；真诚性要求被承诺计划在 `H_sincerity = τ_commit + τ_delivery + τ_reaction` 全窗口可行，否则只发非承诺性警告。言语的输出不改变 `Exec_v24` 的准入条件（除人类回应作为**带证书的新证据**重新进入感知外）；言语通道的任何失效只使 `Exec_v24` 收缩。故 `Exec_v24 ⊆ Exec_v23`。

**P45 送达保守律（Delivery Conservatism）**
「已发出」≠「已收到」≠「已理解」≠「已照做」。告知义务只有在 `p_deliv(τ) ≥ 1−α ∧ Ack(τ) ∧ AoI ≤ τ` 时才视为履行；否则必须升级到更高保证的非语言通道，并在等待/不确定期间收缩执行域。**绝不把未确认送达的语音计为义务已履行**，也绝不以「我已经说过了」为由放宽几何证书。

**P46 声学自证隔离律（Acoustic Self-Evidence Isolation）**
机器人自身合成的语音是**已知相关**证据：先由声学闭环扣除自回波相关；未知残余用 CI 保守融合；自播语音在结构上不得作为「有人在场／有人回应」的证据。任何未经接地的音频（外部注入、重放、幻觉）不得进入 deontic 状态机，只可作为「异常声学事件」触发保守降级。

## 3. 与基线的接口（如何退化）

- 融合失效（CI 不可解／权重搜索失败）⇒ 退回 v23 的 CFC+++ 计数仲裁（模态数 ≥ 2），并取保守并集 ⇒ 等价或更保守于 v23；
- 一致性闸门无法判定（协方差不可信）⇒ 不收缩安全集，仅取并/膨胀 ⇒ 比 v23 更保守，安全继承方向不变；
- STRC 失效（时间同步/外参标定漂移）⇒ 所有测量按 APS 新鲜度阶梯判为陈旧 ⇒ 保守；
- 声学闭环失效（自回波无法扣除）⇒ 静音 + 忽略麦克风 ⇒ 退回无言语通道的 v23；
- 接地失效（Proj 无法找到被证书覆盖的模板）⇒ 不发声（沉默模式），只用预置固定告警音 ⇒ 子集；
- 送达失效（信道模型不可信 / 无确认）⇒ 升级非语言通道，仍不能确认则减速/停 ⇒ 子集；
- 全部失效 ⇒ 完全回退 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`。
- **安全继承**：CI 只保守、闸门只拒缩、负信息只凸组合、言语只投影已证能力、送达失败只升级保守；任意失效都向更保守方向退化，绝不静默放宽。

## 4. 预期贡献（在 1–9 基础上延伸）

10. **相关性鲁棒融合证书**：首次把「模态数 ≥ 2」的计数式共识换成「信息形态 + 两两一致性 + 共同模式膨胀」的融合证书，证明 `P_CI ⪰ P_ind`，从数学上封堵「相关误判共识／众口铄金」的重复计数根因；
11. **负信息的相关融合**：把 AbsCert 从「独立证据相乘」改写为「相关折扣的凸组合」（`M_eff ≤ M`），使冗余传感器不能把「没看见」放大成「确信无人」，并把共同模式探测接到非共享 sanity 通道；
12. **接地言语行为层**：给出 `Proj` 的确定性接地、承诺四元组、真诚性地平线与撤回动作，使「说了必须做、做不到不许说」成为可机械检查的证书约束；
13. **送达保证的义务履行**：给出「发出≠送达≠理解」的显式谓词（`p_deliv`、`Ack`、`AoI`）与多级升级阶梯，把告知义务从「广播了」升级为「确认送达且时间受控」；
14. **声学自证隔离**：把机器人自身语音建模为已知相关证据并扣除，杜绝「听见自己→误判有人」，使语音合成在安全链上只作输出、不作输入；
15. **HPC-F 统一门与闭环**：`HPC-F = HPC-E+ ∧ CI-consistent ∧ GroundedUtterance ∧ Delivered-if-obliged`，`Exec_v24 ⊆ Exec_v23 ⊆ … ⊆ Exec_v18` 闭环，且每一失效分支都显式向保守退化。

## 5. 本轮最大风险

**一句话**：语音把证书外化成人类会**真的依赖**的公共承诺，而承诺在「说出—送达—人类反应」的地平线内是**时间上不可撤回**的；一旦上游证书在这个窗口里失效（尤其是 CI 无法察觉的共同模式偏置），一句被正确送达、真诚说出的话就会变成把人引进危险区的诱饵——即「承诺地平线缺口（commitment horizon gap）」。

| `ω_i ≥ 0, Σ_i ω_i = 1` | CI 凸组合权重（在单纯形上搜索，最小化 `det P_CI` 或 `tr P_CI`） |
| `P_CI, x̂_CI` | 协方差交叉融合后的上界协方差与均值 |
| `P_ind := (Σ_i P_i^{-1})^{-1}` | 「假装独立」的朴素融合协方差（错误下界的参照） |
| `d_ij^2` | 两两 Mahalanobis 距离 `(x̂_i−x̂_j)^T(P_i+P_j)^{-1}(x̂_i−x̂_j)` |
| `χ²_{d,1−α}` | 一致性闸门阈值（`d` 维、置信 `1−α`） |
| `M_eff = 1 + (M−1)·(1−ρ̄)` | 相关折扣后的有效独立模态数（`ρ̄∈[0,1]` 为估计的平均相关） |
| `Δ_i` | 源 `i` 对「有人」对数几率的单源增量（负信息时为负） |
| `Δ_abs = Σ_i ω_i Δ_i` | 相关折扣的负信息融合增量（凸组合，`|Δ_abs| ≤ max_i|Δ_i|`） |
| `U_t = (uid, tmpl, tok, proof_hash, t_emit)` | 已发出语句记录：唯一 id、模板、内容 token、接地证明哈希、发出时刻 |
| `Cmt = (plan_id, τ_commit, Y_set, retract_id)` | 承诺四元组：被承诺计划、承诺截止、允许行为集、撤回语句 id |
| `H_sincerity = τ_commit + τ_delivery + τ_reaction` | 真诚性地平线：承诺必须覆盖的人类依赖窗口 |
| `p_deliv(τ; ch)` | 通道 `ch` 在 `τ` 内成功送达的概率（由信道模型 + 标定给出） |
| `Ack(τ)` | 确认谓词：显式应答 ∨ ASR 语义确认 ∨ 行为应答（让行/停步） |
| `AoI(t)` | 信息年龄：人类动作所依赖语句的「最新已确认送达」时间与当前时间之差 |
| `ALC_t = (ê(t), ρ_self, r_res)` | 声学闭环状态：自回波估计、已知自相关、未知残余相关上界 |
| `Proj(π, Cert)` | 确定性接地投影：由计划与证书索引模板，不自由生成 |
| `GroundedUtterance(U) ≜ U.proof_hash = H(Proj(π,Cert)) ∧ π∈Exec_v23 ∧ Cert⊨truth(U)` | 接地谓词 |
| `Delivered(τ) ≜ p_deliv(τ) ≥ 1−α ∧ Ack(τ) ∧ AoI ≤ τ` | 送达义务谓词 |
| `CIConsistent(X) ≜ ∀i<j, d_ij^2 ≤ χ²_{d,1−α}` | 融合一致性谓词 |
| `Fil_fus, Fil_utt` | 融合一致过滤器 / 言语接地与送达过滤器 |

# ============================================================
# IP-440 Correlation-Robust Fusion Certificate (CRFC)
# ============================================================
@dataclass
class CertifiedEstimate:
    x: np.ndarray          # 证书化均值
    P: np.ndarray          # 上界协方差（含 reg/clk/common-mode）
    t: float               # 时间戳
    modality: str
    cert_hash: bytes       # 上游证书（SDC/DCSC/CAC）哈希，供审计

def inflate_common_mode(X: list[CertifiedEstimate],
                        Sigma_cm: np.ndarray, kappa_cm: float):
    """P_i ← P_i + κ_cm·Σ_cm；共同模式项只能让界更宽"""
    for e in X:
        e.P = e.P + kappa_cm * Sigma_cm

def pairwise_gate(X: list[CertifiedEstimate], alpha: float, d: int) -> bool:
    """单边可靠的一致性闸门：报警必真（在正/未知相关下），放行未必真"""
    thr = chi2.ppf(1.0 - alpha, df=d)
    for i in range(len(X)):
        for j in range(i + 1, len(X)):
            dx = X[i].x - X[j].x
            S = X[i].P + X[j].P
            d2 = float(dx @ np.linalg.solve(S, dx))
            if d2 > thr:
                return False          # 发现足以判定不一致的证据
    return True

def covariance_intersection(X: list[CertifiedEstimate],
                            grid: int = 41) -> tuple[np.ndarray, np.ndarray]:
    """P_CI^{-1} = Σ ω_i P_i^{-1}, Σω=1；在单纯形上最小化 det(P_CI)"""
    M = len(X)
    invs = [np.linalg.inv(e.P) for e in X]
    best = (np.inf, None)
    for w in simplex_grid(M, grid, normalize=True):   # ω_i ≥ 0, Σω=1
        I = sum(wi * Pi_inv for wi, Pi_inv in zip(w, invs))
        P = np.linalg.inv(I)
        score = np.linalg.slogdet(P)[1]               # log det，数值更稳
        if score < best[0]:
            best = (score, (w, P, I))
    w, P_CI, I_CI = best[1]
    x_CI = P_CI @ sum(wi * Pi_inv @ e.x
                      for wi, Pi_inv, e in zip(w, invs, X))
    return x_CI, P_CI

def fused_shrink(X, alpha, d, Sigma_cm, kappa_cm):
    """只有一致通过才允许用 P_CI 收缩；否则返回保守并集（只增不减）"""
    inflate_common_mode(X, Sigma_cm, kappa_cm)
    if not pairwise_gate(X, alpha, d):
        return conservative_union(X), "UNION"     # 闸门报警 ⇒ 不收缩
    x_CI, P_CI = covariance_intersection(X)
    return (x_CI, P_CI), "CI"

# ============================================================
# IP-441 Spatio-Temporal Registration Certificate (STRC)
# ============================================================
def register(X_raw, reg_calib, clk_sync, t_now, max_age):
    """把外参/时钟不确定性膨胀进 P_i；超龄测量按 APS 阶梯降级"""
    out = []
    for e in X_raw:
        age = t_now - e.t
        if age > max_age:
            continue                               # 陈旧 → 丢弃（保守）
        J = reg_calib.jacobian(e.x)
        e.P = e.P + J @ reg_calib.Sigma @ J.T + clk_sync.Sigma * (age ** 2)
        out.append(e)
    return out

def fuse_absence(X_abs, rho_bar):
    """负信息相关融合：M_eff ≤ M，凸组合不得相乘"""
    M = len(X_abs)
    M_eff = 1.0 + (M - 1.0) * (1.0 - rho_bar)     # 相关折扣
    w = [1.0 / M_eff if i < M_eff else 0.0 for i in range(M)]
    # 把剩余权重均摊到最强源，保证 Σω=1
    w[0] += 1.0 - sum(w)
    delta = sum(wi * e.delta for wi, e in zip(w, X_abs))
    return delta                                   # |Δ_abs| ≤ max_i|Δ_i|

# ============================================================
# IP-442 Acoustic Loop Isolation Certificate (ALIC)
# ============================================================
class AcousticLoopIsolation:
    def __init__(self, echo_cancel, alpha=0.01):
        self.echo = echo_cancel
        self.alpha = alpha
        self.rho_self = 1.0      # 自播→自听的已知相关（上界）
    def observe(self, mic_frame, last_utt: Optional[U_t]):
        """先扣已知自相关，再对未知残余用 CI 保守融合"""
        if last_utt is None:
            return mic_frame
        echo_est = self.echo.predict(last_utt.tok, mic_frame.t)
        residual = mic_frame - echo_est
        # 残余相关未知 → 不给任何「独立」信用：只保留单源信息
        return residual, {"rho_self": self.rho_self, "independent": False}
    def never_self_evidence(self):
        """自播语音在结构上不得进入「有人在场」证据集"""
        return True

# ============================================================
# IP-443 Grounded Speech-Act Certificate (GSAC)
# ============================================================
@dataclass
class Utterance:
    uid: str
    tmpl: str
    tok: str
    proof_hash: bytes
    t_emit: float
    cmt: Optional['Commitment']

@dataclass
class Commitment:
    plan_id: str
    tau_commit: float
    Y_set: set          # 允许的行为集
    retract_id: str     # 撤回语句 id

def project(plan, cert, truth_index):
    """确定性投影：只选真值条件被 cert 覆盖的模板；无证不言"""
    for tmpl in truth_index.templates_for(plan.kind):
        if cert.entails(tmpl.truth_condition):
            return Utterance(
                uid=hash_uuid(plan.id, tmpl.id),
                tmpl=tmpl.text, tok=tmpl.tok,
                proof_hash=sha256(plan.canonical() + cert.digest()),
                t_emit=time.now(), cmt=None)
    return None                                     # 找不到被覆盖的模板 → 沉默

def maybe_commit(utt, plan, cert, tau_c, tau_d, tau_r, feasibility_oracle):
    """真诚性：承诺必须在 H_sincerity 全窗口可行，否则只发非承诺性警告"""
    H = tau_c + tau_d + tau_r
    if not feasibility_oracle.valid_over(plan, H):
        return utt                                  # 降级为非承诺性警告
    utt.cmt = Commitment(plan.id, tau_c, plan.y_set,
                         retract_id=f"retract-{utt.uid}")
    return utt

def retract(cmt, reason):
    """撤回也是一条接地语句：只能撤回自家承诺，且不扩大 Exec"""
    return project_retraction(cmt, reason)

# ============================================================
# IP-444 Audible Obligation Delivery Certificate (AODC)
# ============================================================
def certified_delivery(utt, channel, tau, ack_probe, p_deliv_model):
    """发出≠送达≠理解：三谓词同时成立才算履行告知义务"""
    p = p_deliv_model.predict(channel, utt, tau)
    if p < 1.0 - ALPHA_DELIV:
        return False, "UNDELIVERED"
    if aoi(utt, ack_probe) > tau:
        return False, "STALE"
    if not (ack_probe.explicit() or ack_probe.asr_semantic(utt) or
            ack_probe.behavioral(utt)):
        return False, "UNACKED"
    return True, "DELIVERED"

def escalate(utt, channel_ladder):
    """语音→视听→声光→减速/停：每一级只增保守，不增执行域"""
    for ch in channel_ladder:
        ok, why = certified_delivery(utt, ch, utt.tau, ...)
        if ok:
            return ch, "OK"
        exec_shrink(level=ch)                       # 升级同时收缩
    return "STOP_SLOW", "MAX_CONSERVATIVE"

# ============================================================
# IP-445 HPC-F 统一融合–言说准入门
# ============================================================
@dataclass
class HPCF:
    hpc_e_plus: 'HPCEPlus'
    crfc: 'CorrelationRobustFusionCertificate'
    gsac: 'GroundedSpeechActCertificate'
    aodc: 'AudibleObligationDeliveryCertificate'

    def admits(self, plan, X, utterances, obliged_utt, modules) -> bool:
        # 1. 上游四证（v23）不退化
        if not self.hpc_e_plus.admits(plan, ..., modules):
            return False
        # 2. 融合一致（否则只允许保守并集，不收缩）
        state, mode = self.crfc.fused_shrink(X, ...)
        if mode == "UNION" and plan.requires_shrink:
            return False
        # 3. 言语接地：每句都是已证能力的投影
        for u in utterances:
            if not self.gsac.grounded(u, plan):
                return False
        # 4. 该送达的义务必须送达（否则已收缩，不得照常执行）
        if obliged_utt is not None:
            ok, _ = self.aodc.certified_delivery(obliged_utt, ...)
            if not ok:
                return False
        return True

# ============================================================
# IP-446 CFC++++：相关折扣的信息形态共识
# ============================================================
class CFCPlusPlusPlusPlus:
    def consensus_round(self):
        results = {}
        for key, votes in self.votes.items():
            X = [v.to_certified_estimate() for v in votes.values()]
            inflate_common_mode(X, self.Sigma_cm, self.kappa_cm)
            # 条件一：信息形态一致（不是票数够）
            if not pairwise_gate(X, self.alpha, self.d):
                results[key] = "CI"                 # 不一致 → 保守
                continue
            # 条件二：扣除相关后仍有独立信息（不是模态数≥2）
            I_indep = self._independent_information(X, rho_est=self.rho_bar)
            if np.trace(I_indep) <= self.eps_info:
                results[key] = "CI"                 # 独立信息为零 → 不采信
                continue
            x_CI, P_CI = covariance_intersection(X)
            results[key] = self._decide(x_CI, P_CI)
        return results

# ============================================================
# 端到端流水线（感知 → 融合 → 共识 → 接地言语 → 送达 → 准入）
# ============================================================
class FusionUtterancePipeline:
    def step(self, sensor_data, human_reply, obligation=None):
        # 1. 时空配准 + 共同模式膨胀
        X = register(sensor_data.estimates, ...)
        # 2. 负信息相关融合（AbsCert）
        if sensor_data.absence_obs:
            delta = fuse_absence(sensor_data.absence_obs, rho_bar=self.rho_bar)
            self.cac.apply_absence(delta)
        # 3. 声学闭环隔离：人类回应是新证据（带自己的证书）
        if human_reply is not None:
            reply, meta = self.alic.observe(human_reply, self.last_utt)
            if meta["independent"]:
                X.append(reply.as_certified_estimate())
        # 4. 共识（CI 一致 → 收缩；否则保守）
        consensus = self.cfc.consensus_round()
        # 5. 生成接地语句（输出侧，不扩 Exec）
        utt = project(self.plan_from(consensus), self.cert, self.truth_index)
        if obligation is not None:
            utt = maybe_commit(utt, self.plan_from(consensus), self.cert,
                               ..., feasibility_oracle=self.feo)
        # 6. 送达（独立于 50Hz 控制环的事件路径）
        delivered = True
        if utt is not None and obligation is not None:
            delivered, why = certified_delivery(utt, "speech", utt.tau, ...)
            if not delivered:
                chan, _ = escalate(utt, CHANNEL_LADDER)
                delivered = (chan == "OK")
        # 7. HPC-F 准入
        admitted = self.hpcf.admits(self.plan_from(consensus), X,
                                    [utt] if utt else [], utt, self.modules)
        if not delivered:
            admitted = False
            shrink_exec("delivery_failed")
        return admitted, {"consensus": consensus, "utt": utt,
                          "delivered": delivered}

## 3. 正确性论证

### 引理 1（CI 一致性 / 不重复计数）
**陈述**：设各源满足 `E[e_i e_i^T] ⪯ P_i`，互相关矩阵**任意未知**。则 CI 融合一致，即 `E[e_CI e_CI^T] ⪯ P_CI`；并且 `P_CI ⪰ P_ind := (Σ_i P_i^{-1})^{-1}`（在 PSD 序下），即融合永不比「假装独立」更自信。

**证明**：
1. 令 `I_CI = Σ_i ω_i P_i^{-1}`，`Σω_i=1`。由标准 CI 定理（Julier & Uhlmann, 1997），对任意互相关满足上述边缘界时 `P_CI = I_CI^{-1}` 是融合误差的合法上界。
2. 因 `ω_i ≤ 1` 且 `P_i^{-1} ≻ 0`，有 `ω_i P_i^{-1} ⪯ P_i^{-1}`，求和得 `I_CI ⪯ Σ_i P_i^{-1} = I_ind`。
3. PSD 序在取逆下反转：`P_CI = I_CI^{-1} ⪰ I_ind^{-1} = P_ind`。故任何相关未知场景下 CI 都不会比独立融合更窄，重复计数被结构性排除。∎

### 引理 2（一致性闸门单边可靠）
**陈述**：若各源边缘上界有效，则「`d_ij^2 > χ²_{d,1−α}`」是两源不一致的**可靠报警**（无假阳性，在非负相关下）；但「通过闸门」不保证一致（可能有假阴性）。

**证明**：
1. 两估计之差 `e_i − e_j` 的协方差为 `P_i + P_j − Cov_ij − Cov_ji`。当 `Cov_ij ⪰ 0` 时 `Cov(e_i−e_j) ⪯ P_i+P_j`，故以 `(P_i+P_j)^{-1}` 计算的 `d_ij^2` 是真实 Mahalanobis 距离的**下界**。
2. 下界已超阈值 ⇒ 真实距离亦超阈值 ⇒ 在有效边缘界下两源不可能同时一致，报警可靠。
3. 反之，下界未超阈值可能因正相关掩盖了偏差，故放行不构成一致性证明（单边可靠）。因此闸门只用于**拒绝收缩**，不用于**授权收缩之外的乐观**。∎

### 引理 3（负信息不放大）
**陈述**：在互相关未知时用凸权重融合负信息，`Δ_abs = Σ_i ω_i Δ_i`，`Σω_i=1, ω_i≥0`，则 `|Δ_abs| ≤ max_i |Δ_i|`；且有效独立计数 `M_eff = 1+(M−1)(1−ρ̄) ≤ M`。故冗余的「没看见」不能把 AbsCert 放大成「真空」。

**证明**：
1. 由三角不等式，`|Σω_iΔ_i| ≤ Σω_i|Δ_i| ≤ max_i|Δ_i|`。
2. `ρ̄∈[0,1]` ⇒ `M_eff ∈ [1, M]`，权重被 `1/M_eff` 归一，多出的相关源不增加独立信用。
3. 因此 `M` 个高度相关的缺席观测至多等价于 `M_eff` 个独立观测，相关故障无法制造确定性。∎

### 引理 4（接地言语不扩执行域 / 单调退化）
**陈述**：任一被准入的语句都是 `π∈Exec_v23` 的确定性投影；言语通道的任何失效（接地失败、送达失败、自证隔离失败）都使 `Exec_v24` 收缩。故 `Exec_v24 ⊆ Exec_v23`；且 `Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18` 保持。

**证明**：
1. `GroundedUtterance(U)` 要求 `U.proof_hash = H(Proj(π,Cert))` 且 `Cert⊨truth(U)`，即句子的内容由 `π` 与 `Cert` 唯一决定，`Proj` 无自由生成分支（找不到覆盖模板即沉默）。
2. HPC-F 的四个合取项均为「允许/拒绝」型，不含「扩域」型；`Delivered-if-obliged` 为假时令 `admitted=False` 并 `shrink_exec`。
3. 言语作为输出不进入 `admitted` 的正向条件（人类回应须作为带证书的新证据重新进入感知，见引理 5/流水线第 3 步），故言语不会把 `π` 从 `Exec_v23` 之外拉进来。
4. 逐项失效只删减合取项 ⇒ 集合单调不增；对 v23 以下各级同样成立。∎

### 引理 5（真诚性地平线）
**陈述**：若 `feasibility_oracle.valid_over(π,H_sincerity)` 为假，则不发承诺、只发非承诺性警告。因此任何**已发出**的承诺，在「说出—送达—人类反应」全窗口内都带有一份可行性证书（其有效性仍依赖该证书本身在该窗口内为真，见风险 R2）。

**证明**：`maybe_commit` 仅在 `valid_over(π,H)` 为真时写入 `Cmt`；否则原样返回无 `cmt` 的警告。故「已承诺」蕴含「发射时存在覆盖 `H_sincerity` 的可行性证书」。该蕴含是**条件性**的：它保证发射时刻的证书存在，不保证地面真值在窗口内不漂移。∎

### 定理（HPC-F 融合–言说门的可靠性闭环）
**陈述**：对任意计划 `π`，`HPCF.admits(π)=True` 当且仅当同时满足：
(1) v23 四证 `HPC-E+` 成立；
(2) 融合一致（`CIConsistent`）或计划不依赖安全集收缩；
(3) 所有语句接地（`GroundedUtterance`）；
(4) 若存在告知/承诺义务，则该义务已送达（`Delivered(τ)`）。
且恒有 `Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`。

**证明**：由 `admits` 的四个合取项直接得充要性。必要性：任一为假即拒证，对应一类未缓解风险（重复计数 / 幻觉言语 / 未送达义务）。充分性：四者全真时，引理 1–3 保证融合与负信息不产生过分自信，引理 4 保证言语不扩域，引理 5 保证承诺带地平线证书，合起来构成闭环；单调链由引理 4 逐级传入。∎

## 4. 已知风险与缓解

| 风险编号 | 描述 | 严重度 | 缓解措施 | 剩余风险 |
|---|---|---|---|---|
| R1 | 共同模式偏置（雾/逆光/同版固件/同批训练偏差）超出各源证书上界，CI 无法察觉，闸门也可能放行 | 最高 | 1) `κ_cm` 显式膨胀；2) 非共享 sanity 通道（压感地垫/机械触须/独立信标）；3) 对抗共同模式注入测试 | 若所有通道共享同一物理病因且无独立参照，仍会「一致地错」 |
| R2 | 承诺地平线缺口：发射时可行，送达+人类反应窗口内证书失效，人类已据承诺行动 | 最高 | 1) `H_sincerity` 限幅承诺；2) 预置撤回语句；3) 优先非承诺性警告；4) 更保守的可行性 oracle | 撤回本身有延迟，且「已依赖」无法回滚 |
| R3 | CI 保守性 + 送达升级阶梯叠加 → 活性坍缩（频繁并集/减速/停） | 高 | 1) 仅疑似相关时才用 CI，否则 v23 计数；2) 权重自适应；3) 升级阶梯带滞回 | 「疑似相关」的判定一旦错误即回到重复计数 |
| R4 | 声学注入/重放/TTS 幻觉：外部伪造告警，或合成越证内容 | 高 | 1) 确定性模板 + 签名 `uid`；2) 自证隔离；3) 未接地音频只作异常事件触发保守降级 | 高保真重放 + 同模板伪造仍需声纹/物理信道认证 |
| R5 | 送达模型误标定（听障、语言、强噪声工厂），把「未送达」判成「已送达」 | 高 | 1) 多通道冗余；2) 行为应答优先于口头应答；3) 保守 `p_deliv`；4) `AoI` 上限 | 人类「沉默」既可能是拒绝也可能是没听见，二者不可完全区分 |

## 6. 本轮最大风险（最终确认）

**一句话**：HPC-F 把「融合一致」与「言语送达」都做成了可审计的证书，但**唯一无法被内部证书覆盖的，是「所有通道共享同一病因的共同模式偏置」与「承诺在地平线内被人类依赖后无法回滚」这两件事的交汇**——届时系统会以完全合规、完全可审计、语气完全真诚的方式，把人引向它自己也没看见的危险。
