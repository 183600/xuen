# 第 58 轮（承接第 57 轮「少样本元推断×跨模态对账×个性化信任」IP-133~138；灵感循环第 4 轮；本轮灵感：「流匹配策略」×「可重构机构」）

> 第 57 轮给证据补了三条腿（跨区域摊销先验、跨模态对账、个性化信任状态机），把安全赌注进一步押到「证据质量」上；但它留下三个未被触及的结构性盲点：**(a) 证据是点状的**——检查点处的裕度、探针后验、跨模态一致都在离散点上成立，两个检查点之间的连续动作段无人认证，而四足摔倒往往发生在「看似都对的点之间」（进脚瞬间打滑、支撑转移时滚转）；**(b) 身体被当作常量**——所有证书都隐含「同一台机器、同一套腿长/足形/刚度」；一旦可重构，证书所依赖的物理量本身随形态改变，「证书可迁移」从来不是事实而只是有待证明的断言；**(c) 策略被当作取最大值的黑箱**——多模态地形上本有多种过法，系统只保留一个 argmax 动作，而「策略置信」这个新数字若被当证据，等于把第 56/57 轮刚埋掉的「模型置信」重新挖出来。本轮两个灵感各补一块：**流匹配策略**把动作从「采样点」变成「可认证的生成器」——用速度场 + 障碍滤波得到整根**认证流管**，把安全性从「逐点抽检」升级为「对生成元的前向不变性证明」；**可重构机构**把身体从常量变成状态——形态本身是探针（不同形态观测不同物理量），重配置是一次「先证后动」的承诺，必须携带后置模式证书与跨形态迁移误差。核心命题由「少样本-跨模态-个性化的证据说可信」升级为 **「轨迹可流化、形态可探询、重配置可证伪的证据说可信」**。

核心矛盾：
- **H29（点证 vs 轨迹）**：检查点证据无法排除点间失效；但「多采几条轨迹」只是用有限样本逼近连续统，采得再多也证不了整根管——真正要认证的是**生成速度场**，而速度场是学出来的，于是赌注从「先验质量」移到「场模型质量」。
- **H30（形态 vs 可迁移）**：重配置改变证书所依赖的自模型（μ,k,F_bear 随 (m,ξ) 变），旧证据在新形态下不自动成立；「迁移算子」若不许声明误差，就是把跨轮次刚建立的诚实性一次性透支。更糟的是重配置可能把机器带进**不可逆锁定模式**（进入后既不能认证也不能退回）。
- **H31（生成 vs 校准）**：流模型天然给出轨迹密度（瞬时变量替换），看起来像「策略置信」；但密度高≠正确、低≠危险，把它当证据会重蹈「模型置信」覆辙——密度只能作 OOD 触发器，不能作承诺凭据。

## 0. 直觉与动机

**灵感 1（流匹配策略 → 认证的是生成器，不是样本）**
直觉：与其让策略吐一个动作再事后抽检，不如让策略成为一个**速度场**，再用障碍函数把场「削」进安全集：每个 ODE 步把速度投影到安全集的切锥上（v^Π=Π_{T_C}(v_ψ)）。只要流场满足流障碍条件 ∇h·v^Π≥−αh，整条轨迹就**前向不变**地留在 C 内——这是对「生成元」的证明，不是对「采样点」的统计。再叠加模型误差 ε_flow、离散化误差 ε_ode(N)、状态估计误差 ε_est，得到一根**认证流管** 𝕋_ε(H)：证书说的是「整根管都在 C 内」，而不是「几个点碰巧都在 C 内」。代价是 N_ode 进入控制回路——积分步数从此是一个**安全参数**（少步快但管粗，多步准但延迟高）。

**灵感 2（流密度 → 只做 OOD 门，绝不做证据）**
直觉：流模型能顺带算出轨迹似然（变量替换），这很像「策略有多确信」。但第 56/57 轮的教训是：**任何自报的置信都不能当证据**。所以这里刻意把密度降级：只用它判断「这条轨迹不像训练分布」以触发更宽共形带 / 更保守步态；绝不因为「密度高」就放行。这保住「效率来自模型、安全来自证据」的解耦。

**灵感 3（可重构机构 → 身体是状态，形态是探针）**
直觉：若腿长、足形、刚度、轮足可切换，则「当前形态」就是决策变量。关键洞见是**形态即实验**：尖足能探硬度、轮足能测滚阻、宽支撑能测承载——换形态本身就是向地形提一个不同的问题。于是重配置不只是执行动作，也可以是一种**主动探询**，其信息增益可与其他探针一起进 VOI 预算。但形态也是**承诺**：重配置期间无法做不可逆接触、可能锁死，所以必须「先证后动」——先证明目标形态下检查点可认证，再允许迁移。

**灵感 4（流 + 可重构 → 用流做形态迁移）**
直觉：重配置不应是「瞬间变形」，而应是一条在 (x,ξ) 联合空间里从 (x,ξ_m) 到 (x',ξ_{m'}) 的**平滑迁移轨迹**。用流匹配桥接两个形态分布，并约束它全程经过合法配置集 Ξ_adm（避开奇异、自碰撞、关节限位、锁定边界）。于是「变形」与「走路」统一成同一种对象——一条受证书约束的流；迁移管 𝕋_R 与动作管 𝕋_ε 共用同一套滤波与复核机制。

**灵感 5（合流 → 证据门从五类到七类、从「再采一次」到「换副身体去问」）**
直觉：第 57 轮证据门有五类（probe*/visit/margin/xmodal/human）。本轮新增 **EV-tube**（流管证书）与 **EV-morph / EV-reconf**（形态证书与迁移证书），并立一条硬规则：**跨形态证据不免费迁移**——未经声明误差 ≤δ_T^max 的迁移算子，旧证据在新形态下一律作废重采。探询算子也升级：除了「再探一次 / 换个模态探」，现在还能「**换副身体探**」（形态即探询），但重配置是带后置证书的承诺，VOR（重配置价值）必须悲观估计且防陷阱。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（流匹配认证策略 FMCP）** 条件速度场 v_ψ(a,t|c)，c=(x,z_r,m,ξ)，策略 π_ψ 为 ODE da/dt=v_ψ(a,t|c) 从基分布 p_0 的推前。安全集 C={a:h(a)≥0}。认证滤流 v^Π(a,t)=argmin_u‖u−v_ψ(a,t|c)‖² s.t. ∇h(a)·u≥−αh(a)（半空间 QP，闭式）。**流障碍条件**：沿流 ∇h·v^Π≥−αh。**流管** 𝕋_ε(H)={轨迹 τ: dist(τ,ODE 标称解)≤ε(H)}，ε(H)=ε_flow+ε_ode(N)+ε_est 经 Lipschitz 常数放大。**步数证书** N_ode(ε)=min{N:ε_ode(N)≤ε}。**密度仅作 OOD**：n_π(τ)=−log p_ψ(τ|c)（瞬时变量替换），n_π>θ_dens ⇒ 切宽管/降档，**不得**作为承诺证据。

**定义 140（可重构形态模型 RCM）** 混合状态 (x,ξ,m)，ξ∈Ξ_m，m∈𝔐；自模型 η=(μ,k,F_bear)=S(x,ξ,m,terrain)。可达图 G_R=(𝔐,E) 带边代价、guard、可逆标志。**形态证书** Cert_m=(C_m,h_m,𝕋_ε,m,N_ode,m)；**迁移算子** T_{m→m'}:b_m↦b_{m'}，声明迁移误差 δ_T(m,m')（TV 或 W_1）。**可重构判据**：边 e=(m→m') 仅当（i）后置证书 Cert_{m'} 存在且覆盖目标检查点（lookahead）；（ii）e 可逆或存在已认证安全回退；（iii）迁移管 𝕋_R⊂Ξ_adm 时方可承诺。**防陷阱**：G_R 中「进入后既无法认证亦无法退回」的模式集 𝔐_trap 预先计算并硬禁。

**定义 141（流形态迁移 FMT）** 联合空间 (x,ξ) 上的桥接流 v_ψ^R(x,ξ,t|e)，从 (x,ξ_m) 推前到 (x',ξ_{m'})，约束流经合法配置集 Ξ_adm（避开奇异/自碰撞/关节限位/锁定边界）。**迁移管** 𝕋_R=𝕋_R(ε_flow^R+ε_ode^R+ε_est)。证书要求：(i) 全程 (x,ξ)∈Ξ_adm；(ii) 终点 (x',ξ_{m'})∈C_{m'}（后置模式认证）；(iii) 迁移期间「证据冻结」——只允许依赖已认证接触，禁止发起需要新证据的不可逆接触。故重配置严格「**先证后动**」。

**定义 142（形态证据门 MEG 与证书 J_r）** 扩展 FSE(IP-137)：证据类新增 **EV-tube**（须流障碍条件成立、N_ode 达 N_ode(ε)、𝕋_ε(H)⊂C）、**EV-morph**（Cert_m 覆盖检查点且 δ_T 声明诚实）、**EV-reconf**（迁移管合法 ∧ 后置 Cert_{m'} 认证 ∧ e∉𝔐_trap）。**不免费迁移规则**：m 下证据在 m' 下仅当经 T_{m→m'} 且 δ_T≤δ_T^max 才可作佐证，否则作废重采。不可逆接触必要证据集={EV-probe*∨EV-margin∨EV-tube}∪佐证，**不含 EV-morph/EV-reconf 单独项**（换身体不等于证明地形）。J_r=(G_R 路径, Cert_m 链, T 误差, N_ode, 𝕋_ε/𝕋_R, VOR 记录, 模式审计)，继承 J_p 全检。

**定义 143（探-诺-演++ PCX+：重构即探询）** 每检查点：①流生成候选管；②管查验（EV-tube/EV-morph，失败则滤波/加宽）；③不过则**形态探询**：在候选边集 E_adm 上算悲观 **VOR(e)=Ê[Δ可认证性(e)]−λ_R·R_trans(e)−λ_T·Time(e)−λ_E·Energy(e)**，仅当 VOR(e)≥θ_R 且后置可证 ⇒ 执行 FMT（计入 k_probes 预算，迁移期冻结外部承诺）；否则常规探针→绕行→降档→L2 协商。④重配置本身产生形态证据（O_m 观测不同物理量），可替代一次探针但**不得**替代不可逆接触证据。终止：模式变更 ≤N_mode，E_adm 上无陷阱环。

**定义 144（跨形态证伪回放 MFR）** 观测失败 (m,ξ,x_f) ⇒ ①沿流反演（反向时间 ODE）定位最近失败邻域与失败指纹 φ_f=(地形特征, m, ξ, 失效约束)；②经 T 把证伪传播到形态相似模式（sim(c,c')≥s_0）并降权其 Cert/ρ；③把 φ_f 写入 OOD 注册表与形态选择先验。这是第 57 轮「事后证伪回溯」的形态版：**证伪随身体传播，不随身体消失**。

## 2. 关键算法伪代码（完整版见产物区）

```python
def flow_policy_certify(v_psi, h, c, N, H):          # IP-139: 认证生成元
    a, tube = sample_base(c), 0.0
    for k in range(N):
        v = project_safe(v_psi(a, k / N, c), h, a, alpha)   # 切锥/半空间 QP
        a, e = ode_step(a, v, H / N)
        tube = max(tube, bound_flow(e, N, H))               # Lipschitz 放大
    ok = tube <= eps_budget and forward_invariant(h, v_psi, c)
    return Cert_flow(a, tube, N_ode=min_steps(eps_budget)), ok

def reconfig_gate(M, e, certs):                      # IP-140/142: 先证后动
    if e.m_to in traps(G_R) or not certs.cover(e.m_to):
        return ('reject', 'no_post_cert')
    if not (e.reversible or certs.has_safe_fallback(e.m_from)):
        return ('reject', 'no_fallback')
    if transport_err(e) > delta_T_max:
        return ('reject', 'transport_unproven')
    return ('ok', e)

def flow_morph_transport(x, src, dst, v_R):          # IP-141: 形态迁移管
    tau = integrate(v_R, (x, src), until=dst)
    if any(cfg not in Xi_adm for cfg in tau):
        return ('reject', 'illegal_config')
    if tau[-1] not in C(dst):
        return ('reject', 'post_uncertified')
    return ('ok', Tube_R(tau, eps_R))
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| FMCP | O(N_ode·d_a) + QP/步 | O(H·d_a+\|ψ\|) | 流障碍条件 + 管 ⊂ C；密度仅 OOD |
| RCM | 离线 O(\|𝔐\|·\|E\|)；查询 O(1)+O(d_b) | O(\|𝔐\|²) 迁移矩阵 | δ_T 声明诚实、𝔐_trap 预计算 |
| FMT | O(N_ode^R·d_(x,ξ)) | O(H·d_(x,ξ)) | 全程 Ξ_adm、终点 C_{m'}、证据冻结 |
| MEG | O(\|σ\|+\|𝔐\|) | O(\|σ\|) | 不免费迁移、EV-morph 不单证地形 |
| PCX+ | O(\|CP\|·(N_ode+k_p+\|E_adm\|·C_VOR)) | O(\|V\|+\|σ\|+\|𝔐\|) | N_mode/探针双预算终止 |
| MFR | O(N_ode^R+N_cal) | O(\|φ_f\|) | 反演有界、传播只降权 |

**正确性定理（CFRS 概要）**：在 A33–A40 之上加 (A41) 流认证诚实（ε_flow/ε_ode(N)/ε_est 上界成立，滤波后前向不变，密度只作 OOD）；(A42) 形态模型与迁移诚实（δ_T 声明成立、G_R 完整、无未建模模式切换）；(A43) 重配置原子且安全（后置证书 ∧ 可逆或回退 ∧ 证据冻结 ∧ 禁止带载重配置）；(A44) 形态探询独立性（观测算子的信息不依赖它要检验的自模型假设，否则循环自证）。则：(i) EV-tube 通过 ⇒ 全程管⊂C，失效概率 ≤δ_flow+δ_ode(N)+δ_est；(ii) 重配置失效 ≤δ_R+δ_T+δ_post，且 1[e∈𝔐_trap]=0；(iii) 跨形态佐证误差 ≤δ_T，δ_T>δ_T^max 时拒绝率=1（只更保守）；(iv) 交互单调性：滤波/加宽/降档/迁移拒绝只经「更宽管、更小安全集、更多证据、更慢动作」影响系统；(v) 每检查点 N_ode+k_p 有界、模式变更 ≤N_mode，PCX+ 终止于 {承诺, 绕行, 重配置, L2 协商, 安全停}。

## 6. 本轮最大风险

**一句话**：本轮把安全性从「采样点」押到「生成器的模型」上——若流场模型与形态迁移模型共享同一个系统偏差，整根流管与整条模式链会自洽地错，而且因为平滑、确定、可微，比离散抽检更难暴露；必须以独立物理证据在管端点与模式边界重新落地、滤波不可行即停、δ_T 超界即拒，绝不把「证书可迁移」当作免费假设。

# 第 58 轮产物 · 创新点清单 v34：Flow-Reconfig（流匹配认证策略×可重构形态，FMCP×RCM×FMT×MEG×PCX+×MFR）

> 承接第 57 轮 IP-133~138（MFSL/XMC/PTM/MXI/FSE/PCE+）与第 56 轮 IP-127~132（SMM/PCE/BVK/ISE/TAF/MEC）。本轮把部署前提从「少样本-跨模态-个性化的证据承诺」升级为 **「轨迹可流化、形态可探询、重配置可证伪的证据承诺」**：动作由可认证流生成（管级而非点级），身体由常量变状态（形态即探针），重配置是携带后置证书与迁移误差的承诺，「证伪随身体传播」。第 57 轮「一切判定器走隔离」在本轮推广为「**一切生成器与迁移算子走隔离**」：流场、迁移算子在被承诺采信前必须先过影子模式与端点复证。

### IP-139 FMCP（流匹配认证策略）

```python
def fmcp_generate(v_psi, h, c, N, H, alpha):
    a = sample_base(c)                                # a_0 ~ p_0
    tube = 0.0
    for k in range(N):
        v = project_safe(v_psi(a, k / N, c), h, a, alpha)   # QP: min‖u−v_ψ‖² s.t. ∇h·u ≥ −αh
        a, e = ode_step(a, v, H / N)
        tube = max(tube, lipschitz_bound(e, N, H))          # ε(H) = ε_flow+ε_ode+ε_est 放大
    return a, tube

def fmcp_certify(v_psi, h, c, eps_budget):
    N = min_steps(eps_budget)                          # N_ode(ε)
    a, tube = fmcp_generate(v_psi, h, c, N, H, alpha)
    invariant = all(nabla_h(a_k) @ v_psi(a_k, k / N, c) >= -alpha * h(a_k) for k, a_k in traj)
    if not invariant: return ('reject', 'barrier_violated')
    if tube > eps_budget: return ('reject', 'tube_too_wide')
    return ('ok', Cert_flow(a, tube, N))

def density_is_ood(v_psi, tau, theta_dens):            # 仅 OOD，不作证据
    n = -log_density_flow(v_psi, tau)                  # 瞬时变量替换
    return n > theta_dens
```

### IP-140 RCM（可重构形态模型）

def build_mode_certs(M, modes, G_R):
    traps = {m for m in modes if not reachable_home(m, G_R)}   # 进入后无法认证亦无法退回
    certs = {m: Cert_m(D, h_m, eps_budget) for m in modes if m not in traps}

def transport_belief(b_m, m_from, m_to, T):
    err = declared_error(T, m_from, m_to)             # δ_T(m,m')
    if err > delta_T_max:
        return None, err                               # 不免费迁移：作废重采
    return T(b_m), err

def reconfig_gate(certs, G_R, e):
    if e.m_to in traps(G_R):            return ('reject', 'trap_mode')
    if not certs[e.m_to].covers(e.target_checkpoint):
        return ('reject', 'no_post_cert')              # lookahead
    if not (e.reversible or certs[e.m_from].has_safe_fallback()):
        return ('reject', 'no_fallback')
    if e.transport_err > delta_T_max:   return ('reject', 'transport_unproven')
    return ('ok', e)

### IP-141 FMT（流形态迁移，先证后动 + 证据冻结）

```python
def flow_morph_transport(x0, e, v_R, certs):
    if not certs[e.m_to].covers(e.target_checkpoint):   # 先证
        return ('reject', 'post_uncertified')
    tau, ok = integrate_checked(v_R, (x0, e.m_from), until=(x1, e.m_to))
    if not ok or any(cfg not in Xi_adm for cfg in tau): # 奇异/自碰撞/限位/锁定
        return ('reject', 'illegal_config')
    if not in_safe_set(tau[-1], certs[e.m_to]):         # 后置认证
        return ('reject', 'endpoint_unsafe')
    return ('ok', Tube_R(tau, eps_R), 'evidence_frozen')  # 迁移期冻结外部承诺

def morphology_evidence_gate(c, M, certs, G_R, ood_reg):
    if c.ev == 'EV-tube':
        ok = c.flow_cert.invariant and c.flow_cert.N >= min_steps(c.eps) \
             and c.flow_cert.tube <= c.eps_budget
    elif c.ev == 'EV-morph':
        ok = certs[c.m].covers(c.cp) and certs[c.m].delta_T_declared <= delta_T_max
    elif c.ev == 'EV-reconf':
        ok = c.tube_R.legal and certs[c.m_to].covers(c.cp) and c.edge not in traps(G_R)
    elif c.ev == 'EV-probe*':
        ok = (c.inf.cls == 'ID' and c.inf.ece_k <= eps_meta(c.k)) or \
             (c.inf.cls == 'OOD' and c.region in ood_reg.certified)
    elif c.ev == 'EV-xmodal':
        ok = c.level == 'L1' and c.indep_declared and D(c.region) <= theta_D
    elif c.ev == 'EV-human':
        ok = c.persona.auth >= 'A1' and c.corrob >= quarantine_exit(c.persona.auth)
    elif c.ev in ('EV-visit', 'EV-margin'):
        ok = round56_checks(c, M)
    else:
        return ('reject', 'no_evidence_class', c)
    if not ok: return ('reject', 'evidence_insufficient', c)
    if c.irreversible and c.ev in ('EV-morph', 'EV-reconf', 'EV-xmodal'):
        return ('reject', 'not_ground_truth_evidence', c)   # 换身体/一致性不证明地形
    if not evidence_transfers(c.m_from, c.m_to, c.T):
        return ('reject', 'evidence_not_transferable', c)
    return ('ok', c)

def reconfig_certificate_jr(route, certs, G_R, T, VOR_log, mode_audit):
    for e in route.reconfigs:
        if reconfig_gate(certs, G_R, e)[0] != 'ok': return ('reject', e)
    if route.mode_changes > N_mode:        return ('reject', 'mode_budget')
    if any(m in traps(G_R) for m in route.modes): return ('reject', 'trap')
    return ('ok', Jr(G_R, [certs[m] for m in route.modes], T.errors,
                     route.N_ode, route.tubes, VOR_log, mode_audit))
```

def probe_commit_evolve_pp(x0, M, task, budget, personas, certs, G_R):

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| FMCP | O(N_ode·d_a + N_ode·QP) | O(H·d_a+\|ψ\|) | 流障碍条件、𝕋_ε⊂C；密度仅 OOD（A41） |
| RCM | 离线 O(\|𝔐\|·\|E\|)；查询 O(1)+O(d_b) | O(\|𝔐\|²) 迁移矩阵 | δ_T 诚实、𝔐_trap 预计算（A42） |
| FMT | O(N_ode^R·d_(x,ξ)) | O(H·d_(x,ξ)) | 全程 Ξ_adm、终点 C_{m'}、证据冻结（A43） |
| MEG | O(\|σ\|+\|𝔐\|) | O(\|σ\|) | 不免费迁移、非地形证据不单证（A42/A44） |
| PCX+ | O(\|CP\|·(N_ode+k_p+\|E_adm\|·C_VOR)) | O(\|V\|+\|σ\|+\|𝔐\|) | 双预算终止、悲观 VOR |
| MFR | O(N_ode^R+N_cal) | O(\|φ_f\|) | 反演有界、只降权 |

**正确性定理（Certified Flow-Reconfigurable Soundness, CFRS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 流认证诚实：ε_flow、ε_ode(N)、ε_est 上界成立，滤波后流前向不变，密度仅作 OOD；**(A42)** 形态模型与迁移诚实：δ_T(m,m') 声明成立、G_R 完整、无未建模模式切换；**(A43)** 重配置原子且安全：后置证书 ∧（可逆 ∨ 安全回退）∧ 证据冻结 ∧ 禁止带载重配置；**(A44)** 形态探询独立性：观测算子 O_m 的信息不依赖它所要检验的自模型假设（否则循环自证）。则：

1. **流管承诺健全性**：EV-tube 通过 ⇒ 全程 𝕋_ε(H)⊂C，失效概率 ≤ ε_flow+ε_ode(N)+ε_est（确定性管 + 概率模型误差分离）。
2. **重配置健全性**：重配置诱发失效 ≤ δ_R+δ_T+δ_post，且 1[e∈𝔐_trap]=0（硬禁）。
3. **证据不免费迁移**：m→m' 佐证误差 ≤ δ_T；δ_T>δ_T^max 时拒绝率=1，故迁移只会更保守，绝无「未声明迁移」。
4. **交互单调性强化**：滤波、加宽、降档、迁移拒绝只经 (a) 更宽管/更小安全集、(b) 更多证据、(c) 更慢更保守动作 影响系统；重配置扩展能力仅在 C_{m'} 重新认证后生效，不存在未认证升险路径（条件于 A42）。
5. **终止性**：每检查点 N_ode+k_p 有界、模式变更 ≤N_mode、E_adm 无陷阱环 ⇒ PCX+ 终止于 {承诺, 绕行, 重配置, L2 协商, 安全停}。

4. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                  + ε_flow + ε_ode(N) + ε_est + δ_R + δ_T)
             − P(𝓜 陈旧未检出) − P(护盾回退失败) − P(滤波不可行 ∧ 安全停失效)
```

关键：**认证生成器把「点证」升级为「元证」，但元证的可信上限 = 场模型的可信度**；**形态即探询把「换身体」并入证据经济，但换身体不允许自证地形**（A44）；**迁移不是免费午餐**，δ_T 超界即拒、迁移后端点必复证；三个新机制全部经「更宽管 / 更小安全集 / 更多证据 / 更慢动作」四个保守通道起作用。

## 6. 本轮最大风险

**一句话**：本轮把安全性从「采样点」押到「生成器的模型」上——若流场模型与形态迁移模型共享同一个系统偏差，整根流管与整条模式链会自洽地错（平滑、确定、可微，因而比离散抽检更难暴露）；必须以独立物理证据在管端点与模式边界重新落地、滤波不可行即停、δ_T 超界即拒，绝不把「证书可迁移」当作免费假设。
