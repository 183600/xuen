# 第 3 轮迭代（灵感循环 v3：「夹爪控制」×「参数高效微调」）—— 从"看得见的进度"到"握得住的进度"

> 承接 v2（UIP-01′~15：Gazebo 计分神谕 × 实时性 × 模块化）。本轮不是再叠一层模块，而是**换传感器 + 换注入方式**：把一直被当成"执行末端"的**夹爪**提升为**主反馈通道**；把"每个技能训一个模型"的冲动，收敛为**参数高效微调 + 合并成单一权重**的合规路径。触发这次转向的是两个逐键核对出来的硬事实（§0）：接口里夹爪只有**一个开合标量**，且**没有任何力/力矩/触觉通道**；而图像要被 JPEG 编码、跨网络传输，动作块还要**整段开环执行**。于是"到底握没握住"这件事，图像看得慢、看得糊、还常被手挡住；**夹爪自己却每一步都知道**。

**这两个硬事实合起来给出一句可操作的判断**：在"图像慢 + 动作开环 + 无力觉"的约束下，**夹爪开合是唯一高频、物理接地、且不被遮挡的反馈通道**；但它是标量，所以必须用**"命令 vs 实际"的残差**把接触、滑移、撤回"读"出来，而不是等视觉去发现。

## 1. 上轮清单诊断（v2 → v3）

- **升级为旗舰**：UIP-01′（滚动验证-重做）→ **UIP-01″ RHPV-G**：验证器增加一条**夹爪物理通道**，并在**原语边界**而非固定 k 步处核验；`regressed` 不再只靠视觉时序差分，而优先由"滑移/被打开"的物理信号触发。
- **升级**：UIP-13（自适应块长）→ **UIP-13′ PAC（原语对齐分块）**：块长不是按"阶段"拍脑袋，而是**一个动作块 = 一个自终止夹爪原语**（或一个计分步子段），使开环块天然收敛、且每次 `get_action` 都落在可判定边界上。
- **升级**：UIP-14（模块化技能图）→ **UIP-14′ MSGR-L**：技能图节点改为"夹爪原语 + 手臂运输"的复合原语；每个技能配一个**可合并的 LoRA 适配器**，而不是并列的多个模型。
- **保留并接到新通道**：UIP-02′（计分步安全网）——把"抓稳"设为推进计分步的**前置门**；UIP-09′（扰动恢复）——其检测器现在有了物理实现；UIP-11 GSO / UIP-12 DRF——DRF 必须**记录夹爪开合与命令轨迹**，GSO 的谓词增加 `grasp_signature`；UIP-15 CSG——新增"过挤压/反复重抓"预算；UIP-05、UIP-08′ 保留。
- **新增（命中两词）**：UIP-16 GCS（夹爪接触/滑移签名）、UIP-17 GPC（夹爪原语控制器 + 物体宽度先验）、UIP-18 GAL（抓取反射 LoRA）、UIP-19 TAM（任务适配器合并 + 秩预算）、UIP-20 GVF（夹爪-视觉决策级融合）。

## 2. 两个灵感词的解读

### 2.1 夹爪控制：先给直觉

人手做精细活时，真正判断"拿起来没有"的不是眼睛，而是**指尖的感觉**：东西被夹住时，手指合不拢；滑脱时，指缝会被撑开；插不进去时，手指/手腕会顶住。夹爪也一样，只是它不"说"力，它只"说"**开合到了哪里**。所以我们不需要额外的力传感器，只需要问一个反事实问题：**如果手指间什么都没有，它此刻应该合到哪里？** 实际开合比这个"空手预测"更开，就说明**有东西挡着**；保持夹紧时开合反而变大，就说明**东西在滑**；已经握住的物体开合突然回到张开，就说明**被拿走了/被打开了**——这正是 v2 从规则里读到的"反向撤回"。

### 2.2 夹爪控制：再给严谨定义

记夹爪开合观测量 `g_t ∈ [0,1]`（或米，量纲待真机标定），命令量 `g*_t ∈ [0,1]`。先只用**无接触帧**拟合一个一阶"空手动力学"

```
ĝ_{t+1} = a·g_t + b·g*_t + c,        e_{t+1} := g_{t+1} − ĝ_{t+1}
```

在空手时 `e ≈ N(0, σ²)`。定义**接触残差** `r_{t+1} = e_{t+1}/σ`（闭合方向为正）。于是：

- **接触/握持**：闭合命令下 `r` 持续为正（实际比空手预测更开 ⇒ 指间有物）；
- **空夹**：`g` 单调到达最小位且 `r≈0`；
- **滑移**：保持段内 `g` 出现正向漂移，且 EE 高度在上升（抬升测试失败）；
- **撤回**：某子目标已 `done` 后，`g` 回到张开且 EE 远离 ⇒ 触发 v2 的 `regressed`。

单帧阈值噪声大，因此用**序贯变点检测**（单边 CUSUM）而不是硬阈值：

```
S_{t+1} = max(0, S_t + r_{t+1} − ν),   报警当 S_{t+1} > h
```

在空手数据上把 `(ν,h)` 标到目标**平均运行长度** `ARL₀`（例如 10⁴ 帧才误报一次），再在 DRF 注入的接触段上最小化**检测延迟**。这把"夹爪是不是握住了"从拍脑袋阈值，变成一个**有误报率控制**的统计检验。

**自终止原语**：闭合命令不追"固定时长"，而追"略小于物体宽度的目标开合" `g* = ŵ_τ − δ`（`ŵ_τ` 为该任务/物体在公开数据里握持时的开合中位数，`δ` 为挤压余量）。因为目标本身"够不着空手最小位"，手指会在接触处**自然停住**——即使整块开环执行，也不会无限挤压。这就是把"闭环"藏进物理里。

### 2.3 参数高效微调：先给直觉

我们想要的是"会 32 个任务、还会从干扰里恢复"，但**不想在评测时加载 32 个模型**——那既可能踩"单模型"红线，也吃显存、抬延迟。参数高效微调的正确用法不是"多训几个小模型并排站着"，而是**给同一条骨干拧上少量可插拔旋钮，训完把旋钮焊进主权重**：部署时**只有一个权重文件、一次前向**，能力却来自多个专家。

### 2.4 参数高效微调：再给严谨定义

对权重 `W` 用 LoRA：`W' = W + (α/r)·B A`，`A∈R^{r×d_in}`、`B∈R^{d_out×r}`。设模块 `m` 的秩为 `r_m`，参数量约 `c_m·r_m`（`c_m≈d_in+d_out`）。**秩预算问题**：

```
max_{r_m ≥ 0}  Σ_m U_m(r_m)     s.t.  Σ_m c_m r_m ≤ B
```

`U_m` 为模块 `m` 的验证集增益（可用 Fisher 信息/梯度范数估计），通常凹 ⇒ 贪心按"每参数边际增益"分配即近似最优。训练完成后做**适配器合并**（TIES/DARE 一类）：裁剪小幅值、按符号多数投票、对同号分量取均值，得到 `W_merged = W_0 + λ·Στ_i`，并以**任务间干扰** `I = max_i [L_i(W_merged) − L_i(W_i)]` 作为是否可合并的门槛。**部署即单模型**；若某适配器无法低干扰合并，则退化为一个共享门控适配器，而不是并列多模型。

## 3. 瓶颈假设（更新）

- **H1（最高杠杆，换轴）**：v2 认为最大缺口是"检测进度被撤回"；v3 进一步认为**检测手段选错了模态**——视觉验证器慢且易被遮挡，而夹爪开合是**零额外模型、零网络开销**的接触证据。谁先把"夹爪残差→接触/滑移/撤回"做成带误报率控制的检验，谁就以最低成本拿到步骤分。
- **H2（开环的真正敌人是"块内不可判定"）**：危险不是块长本身，而是**一个块里塞了多个不可自终止的动作**。把块切成**自终止原语**后，开环执行反而变成优点（块内不需要决策）。
- **H3（PEFT 的杠杆在"接触密集技能"而非全任务）**：32 任务共享大量视觉-语义能力，真正需要专家化的是少数插入/旋转/折叠/拉链步；把秩预算集中投到 action head 与接触相关层，比均匀铺开更划算。
- **H4（合并优于路由）**：推理期路由会引入额外前向/显存与"是否多模型"的合规争议；**训练期多适配器 + 部署期合并**在合规、延迟、显存三方面同时占优。
- **H5（双通道的收益不对称）**：夹爪通道**快但语义弱**（只知道"有没有东西、滑没滑"），视觉**慢但语义强**（知道"是什么、到没到位"）。正确做法不是二选一，而是**按代价做决策级融合**。

## 4. 候选与合并 → v3 清单（详见产物区）

围绕两词发散 8 个草案，合并后得到 v3：升级 4 个（01″、13′、14′、02′）、保留 6 个（05、08′、09′、11、12、15）、新增 5 个（16–20）。**旗舰从 v2 的"纯视觉滚动验证"改为 UIP-16 × UIP-17 × UIP-01″ 的"夹爪物理闭环"**：GCS 读接触，GPC 出原语，RHPV-G 在原语边界决策；GAL/TAM 负责用参数高效微调把"重抓反射"焊进单模型；GVF 负责与视觉做代价敏感融合。

## 5. 本轮最大风险

**一句话**：若接口里的夹爪开合在真机上是**近二值、强饱和或量纲不一致**的，那么"空手动力学残差"会把正常闭合误判为接触、把接触误判为滑移，触发反复重抓，反而同时烧掉步骤分与延迟可信度——所以必须先做**跨仿真/真机的夹爪标定**（空手曲线、最小/最大开合、命令-响应延迟），并给重抓设置硬预算后才放大自动化。

**→ 本轮最值得押注：UIP-16（夹爪接触/滑移签名）+ UIP-17（自终止抓取原语）+ UIP-01″（原语边界的重做决策）**——它把"握没握住"从视觉猜测变成**有误报率控制的物理检验**，成本几乎为零，且与 v2 的扰动恢复闭环严丝合缝。

## 2. 夹爪信号：从"一个标量"到"可检验的接触证据"

### 2.1 空手动力学标定（UIP-16 的核心）

只用**无接触帧**（张开接近阶段、空夹回程）拟合

```
ĝ_{t+1} = a·g_t + b·g*_t + c          （按任务/左右手分别拟合，Huber 鲁棒回归）
e_{t+1} = g_{t+1} − ĝ_{t+1}
σ²      = Var(e) 在空手帧上的稳健估计
r_{t+1} = e_{t+1} / σ                  （闭合方向为正 = 实际比空手预测更开）
```

**语义**：`r>0` 表示"有东西挡住了闭合"；`r≈0` 表示"空手按预期闭合"；保持段 `r` 持续为负且 `g` 上升表示"命令在张开"。

### 2.2 序贯变点检测（控制误报）

单边 CUSUM：

```
S_{t+1} = max(0, S_t + r_{t+1} − ν)
contact_alarm(t) = (S_{t+1} > h)
```

- 在空手帧上标定 `(ν,h)`，使**平均运行长度** `ARL₀ ≥ 10⁴` 帧（误报率受控）；
- 在 DRF 注入的"闭合→接触"段上，最小化平均检测延迟 `ADD`；
- 同一套机制复用到两个方向：`r` 正漂移=接触/握持；保持段 `Δg` 正漂移=滑移；`g` 突跳到张开=被打开（撤回）。

### 2.3 夹爪状态机（UIP-16 输出）

| 状态 | 判据（示意） | 对上层的含义 |
|---|---|---|
| `EMPTY` | `g→g_min`，`r≈0`，无抬升 | 空夹，抓取失败 |
| `HOLD` | 闭合后 `r>0` 持续，且抬升测试中 `g` 稳定 | 抓稳，可推进计分步 |
| `SLIP` | `HOLD` 后保持段 `g` 正漂移 ∧ EE 上升 | 正在滑脱，立即重抓 |
| `JAM` | `r` 很大但 `g` 不变 ∧ EE 位移被阻断 | 顶住/卡住（插入过深或撞障碍） |
| `RELEASED` | `HOLD` 后 `g→g_open` ∧ EE 远离 | 主动/被动松开 |
| `REGRESSED` | 某子目标已 `done`，随后出现 `SLIP/JAM/RELEASED` 且位置回退 | 人为撤回，触发重做 |

> `REGRESSED` 是把 v2 的视觉时序差分换成**物理先行**：视觉只在夹爪通道"不确定"时补判。

### 2.4 物体宽度先验与挤压余量（UIP-17）

对任务/物体 `τ`，从公开数据的握持帧估计 `ŵ_τ = median(g | HOLD)`，命令闭合目标取

```
g*_close = ŵ_τ − δ,     δ ∈ [0.05, 0.15]·(g_open − g_min)
```

`δ` 太小 → 夹不牢、易滑；太大 → 过挤压、损伤/变形。`δ` 用 DRF 的抓取成功率曲线选（见 E203），并按物体类别（软/硬/薄/细）分档。**关键性质**：目标开合"够不到空手最小位"，所以即使整块开环执行，手指也会在接触处**自然停住**——把闭环藏进机械/位置控制里。

### 2.5 抬升测试（把"抓住"变成可判定事件）

在一个原语块内完成"闭合→小幅抬升（2–3 cm）"，下一个 `get_action` 时检查：

```
grasp_ok = (|g_{t+k} − g_t| < ε_g) ∧ (z_{t+k} − z_t > ε_z) ∧ (S_contact 报警)
```

只有 `grasp_ok` 才允许把"抓取"计分步标为 `done`（UIP-02′ 的前置门）。这直接减少"以为抓住了、其实空夹"的伪完成。

## 3. 原语对齐分块（UIP-13′ PAC）

v2 的 ACS 按"阶段"选 k，但阶段边界与开环块边界不重合，导致"块内发生的事看不见"。v3 把分块粒度改为**原语**：

| 原语 | 典型步数（30 Hz） | 自终止条件 | 下一块核验 |
|---|---:|---|---|
| `MOVE_TO(pre)` | 8–20 | EE 到位容差 | 到位否 |
| `CLOSE_TO(width)` | 4–8 | 接触残差报警或到达目标 | HOLD/EMPTY |
| `LIFT_TEST(h)` | 3–6 | 高度增量 | HOLD/SLIP |
| `INSERT(depth)` | 6–15 | 位移被阻断（JAM）或达深 | 插入深度/回退 |
| `TURN(angle)` | 6–12 | 角度增量或扭矩式阻断 | 角度/被拧回 |
| `PULL(distance)` | 6–15 | 位移或滑移 | 完成/滑移 |
| `RELEASE()` | 2–4 | 开合到达 | RELEASED |
| `REGRASP()` | 4–8 | 重新闭合+抬升 | HOLD/EMPTY |

**部署约束**：`metadata.action_chunk_size` 只能握手时定一次，故取**全局最大原语步数** `K_MAX`，每次实际返回长度 `k_t ≤ K_MAX`（接口允许每块长度不超过声明值；索引 0 先执行）。这既满足形状检查，又让不同原语用不同有效块长。

**与计分点的关系**：一个计分步可含多个原语（如"抓杯并挂上" = `MOVE→CLOSE→LIFT→MOVE→RELEASE`），但**每个原语结束都可核验**，于是即使计分步很长，也不会"整段盲执行"。

## 4. 参数高效微调：UIP-18 GAL 与 UIP-19 TAM

### 4.1 UIP-18 · GAL（Grasp-Reflex LoRA）

- **目标**：把"检测到 `SLIP/REGRESSED` → 重抓/重做"的反射，以**极少量** DRF 数据注入策略。
- **数据**：UIP-12 DRF 生成三元组 `(干扰前 → 撤回 → 恢复)`，并记录夹爪 `g,g*` 与 EE 轨迹；真实公开数据作**回放正则**，防止灾难性遗忘。
- **注入位置**：优先 `action` 头 + 接触相关的中层（value/action projection），视觉编码器**冻结**；只训低秩增量。
- **条件化**：把 UIP-16 的状态（`HOLD/SLIP/JAM/REGRESSED` 的 one-hot 或标量）作为额外 token/偏置注入，使同一骨干"知道现在在恢复模式"。
- **为何是 PEFT 而非全参**：(a) 恢复数据稀少，全参易过拟合；(b) 全参微调会破坏 32 任务既有能力；(c) 低秩增量可在部署前**合并**，无推理开销。

### 4.2 UIP-19 · TAM（Task-Adapter Merge）

- **训练**：每个技能/任务一个 LoRA（或技能簇共享），秩 `r_m` 由预算分配。
- **秩预算**（背包）：

```
max Σ_m U_m(r_m)   s.t.  Σ_m c_m r_m ≤ B,   c_m ≈ d_in + d_out
```

`U_m` 用验证集动作误差下降估计；贪心每次给"每参数边际增益最大"的模块加 1 秩（凹收益下近似最优）。
- **合并**：TIES 式——裁剪小幅值、符号多数、同号取均值：

```
τ_i = W_i − W_0
trim_p(τ_i) → sign election → disjoint mean → W_merged = W_0 + λ·Σ τ̄_i
```

- **合并门槛**：任务间干扰 `I = max_i [L_i(W_merged) − L_i(W_i)]`，要求 `I < ε`；超阈值的适配器不硬并，改为**一个共享门控适配器**（仍是一套权重）。
- **部署收益**：单权重文件、单次前向、无路由分支；合规风险与延迟同时下降。

> 注意：如果"单模型"被严格解释为"只能有一个可训练/加载的权重集合"，合并方案天然满足；如果允许"多适配器但共享骨干"，也可保留未合并版本作为训练期对照。二者在评测时应**只暴露合并版**。

## 5. UIP-20 · GVF（夹爪-视觉代价敏感融合）

两通道的误差结构不同：夹爪**快、物理接地、但语义弱**；视觉**慢、语义强、但遮挡/延迟**。用一个决策规则融合，而不是简单"或"：

- 视觉给 `p_v = P(regressed | o_t)`（可由几何谓词或同骨干小头给出，避免外部大模型合规风险）；
- 夹爪给似然比 `Λ_g = P(evidence | regressed) / P(evidence | normal)`（来自 CUSUM 统计量）；
- 后验对数几率 `logit(p) = logit(p_v) + log Λ_g + logit(p_prior)`。

**代价敏感决策**（只看 `redo` vs `advance`，`observe` 作为可选第三动作）：

```
E[C(redo)]    = (1−p)·c_r
E[C(advance)] = p·L_step
redo  ⟺  p > c_r / (c_r + L_step)
```

其中 `c_r` = 一次重做的延迟/可信度代价，`L_step` = 该计分步的分值（30/40/50）。因为 `L_step` 远大于 `c_r`，阈值天然偏低：**在不确定时倾向重做**——这与"步骤分是主要抓手"的赛制一致。`observe` 仅在"多等一帧能把 `p` 推过阈值且延迟预算允许"时选择，由 UIP-15 的预算约束把关。

## 6. 关键算法（伪代码）

```python
# ---------- UIP-16: 空手残差 + CUSUM ----------
class GripperSignature:
    def __init__(self, a, b, c, sigma, nu, h, eps_g=0.02, eps_z=0.01):
        self.a, self.b, self.c, self.sigma = a, b, c, sigma
        self.nu, self.h = nu, h
        self.S_contact = 0.0; self.S_slip = 0.0
        self.g_prev = None; self.mode = "OPEN"

    def update(self, g, gstar, z):
        if self.g_prev is None:
            self.g_prev = g; self.z_prev = z; return "UNKNOWN"
        g_hat = self.a * self.g_prev + self.b * self.gstar_prev + self.c
        r = (g - g_hat) / self.sigma
        self.S_contact = max(0.0, self.S_contact + r - self.nu)
        dg = g - self.g_prev
        self.S_slip = max(0.0, self.S_slip + dg / self.sigma - self.nu)
        self.g_prev, self.gstar_prev, self.z_prev = g, gstar, z
        if self.S_contact > self.h and dg <= 0:      return "HOLD"
        if self.S_slip > self.h and z > self.z_prev: return "SLIP"
        if g < self.g_min + 1e-3 and abs(r) < 2:     return "EMPTY"
        return "ONGOING"
```

```python
# ---------- UIP-17 + 13′ + 01″: 原语对齐的抓取闭环 ----------
class GripperPolicy:                      # 外层仍实现 metadata/get_action/reset
    PRIMITIVES = ["MOVE", "CLOSE", "LIFT", "INSERT",
                  "TURN", "PULL", "RELEASE", "REGRASP"]

    def reset(self):
        self.g = 0                        # 当前计分步
        self.prim = None; self.buf = []
        self.redo = 0; self.fail = 0
        self.sig.reset(); self.policy.reset()

    def get_action(self, obs):
        if self.prim is not None:         # 上一块刚执行完，先核验
            st = self.sig.update(self._g(obs), self._gstar(), self._z(obs))
            self._update_progress(st)
            if st == "SLIP" or st == "REGRESSED":
                self._regrasp()            # -> 下一块 REGRASP
            elif st == "HOLD" and self._done():
                self.g += 1; self.redo = 0
                self._plan_next()
            elif st == "EMPTY" and self.fail < 2:
                self.fail += 1; self._regrasp()
            else:
                self._plan_next()
        if not self.buf:                   # 一块 = 一个自终止原语
            self.prim = self._next_primitive()
            self.buf = list(self.policy.act(obs, self.prim,
                                            k=self._k_for(self.prim)))[:K_MAX]
        return self.buf.pop(0)
```

```python
# ---------- UIP-19: 秩预算 + 合并 ----------
def allocate_rank(modules, U, B):
    r = {m: 0 for m in modules}                    # 每模块起始秩 0
    while True:
        best = max(modules, key=lambda m: (U[m](r[m]+1) - U[m](r[m])) / c[m])
        if sum(c[m]*r[m] for m in modules) + c[best] > B:
            break
        r[best] += 1
    return r

def ties_merge(base, task_vectors, p=0.2, lam=1.0):
    trimmed = [trim(tv, p) for tv in task_vectors]
    signs   = elect_sign(trimmed)                  # 逐元素符号多数
    merged  = disjoint_mean(trimmed, signs)
    return {k: base[k] + lam * merged[k] for k in base}
```

## 8. 合规与风险

- **单模型**：TAM 合并后**只暴露一个权重文件**；训练期的多适配器不随提交上线。若手册要求更严，连训练期多适配器也只作为离线蒸馏教师，最终蒸回单体。
- **无外部大模型**：UIP-16/GVF 的视觉概率优先用**几何谓词或同骨干小头**，避免"非单模型"争议。
- **接口红线**：`action_chunk_size` 握手定一次；每次返回长度 `≤ K_MAX`，形状 `(k_t, …)`，索引 0 先执行；`meta.token` 每步携带。
- **可信度**：重抓/重做必须有硬预算（次数/延迟/抖动），对应 UIP-15；过挤压与动作突变也会被统计规律性检查捕捉。
- **仿真过拟合**：DRF 的干扰时机/速度必须随机化；GSO 只做结构裁判。

## 9. 资源与时间线（粗排）

- 第 1–2 周：在 32 数据集上抽夹爪 `g,g*` 序列，拟合空手模型与 `σ`；做 E201 离线 AUC。
- 第 3–4 周：真机（或 GSO）标定空手曲线、命令-响应延迟、`g_min/g_max`；拟合物件宽度先验 `ŵ_τ`。

- 第 7–8 周：UIP-12 DRF 采集夹爪轨迹；UIP-18 GAL 训练（100/500/2000 三档）。
- 第 9–10 周：UIP-19 秩预算 + TIES 合并；UIP-20 融合阈值标定；E204–E208。
- 第 11 周起：真机校准锚点 + 全链路压测（N 端口、延迟方差）。

## 10. 本轮最大风险 & 押注

**一句话**：若夹爪开合在真机/评测端是**近二值、饱和或量纲漂移**的，空手残差模型将系统性误报，导致"越检测越重抓"的负反馈，同时损失步骤分与延迟可信度。

**→ 押注：UIP-16 + UIP-17 + UIP-01″ 的"夹爪物理闭环"**——用**有误报率控制**的接触/滑移检验替代纯视觉猜测，把"握没握住"变成可判定事件；再以 UIP-18/UIP-19 的"少量数据 + 合并单模型"把恢复反射合规地焊进策略。它对准的是 32 任务中至少 20 个的抓取关键步，成本近乎为零，且与 v2 的扰动恢复闭环完全兼容。
