# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；灵感循环第 2 轮；本轮灵感：「热管理」×「仿真训练」）

> 第 59 轮把「执行物理」纳入证据链：BLDC 转矩脉动、电流采样抖动、实时契约、阻抗安全编译、执行证据回传。但它仍留下两个未言明的理想化假设：**(i) 热只是一个慢漂移标量 T_junc，可塞进 ξ_exec 的随机游走，热约束只是预算余量；(ii) 仿真/离线预计算给出的 Pareto 前沿、先验与证书天然可迁移到现实**。本轮两个灵感精准击中这两个假设：**热管理**揭示热是**慢时间尺度但带阈值、空间梯度、历史记忆、跨关节耦合与不可逆损伤**的一等状态——慢不等于安全，热降额会“静默收缩”安全包络；**仿真训练**揭示仿真是**带覆盖度与 sim-to-real 差距界的压缩先验**，不是事实，领域随机化还可能把系统性偏差“平均掉”，制造“认证过自信”。本轮核心命题：**「把热状态提升为一等执行状态并纳入证据鲜度与安全编译；把仿真从‘可信先验’降格为‘带覆盖度、差距界与漂移监测的可证伪证据源’」**，形成**热-仿真接地层（TSGE）**。

核心矛盾：
- **H32（热记忆非马尔可夫·慢状态泄漏）**：第 59 轮的 BUQ 用 ξ_{t+1}=ξ_t+w_t、Q 极小来刻画参数慢漂移，本质是**无记忆随机游走**。真实热过程是 C_th·dT/dt = Q_gen(ξ_exec,u,T) − Q_diss(T,T_amb,coolant)，含分钟级时间常数、绕组/磁钢/轴承/功率级/电池的**空间梯度**、跨关节共享冷却与热传导，以及“曾经热过”的**历史记忆**（热循环损伤 D_cum）。把 T_junc 当慢漂移标量，会把“热到临界后突然降额/退磁”误判为“平滑漂移”，导致证据层用旧热状态下的似然校准新热状态的后验。
- **H33（热-力-电耦合·安全包络静默收缩）**：温度改变相电阻 R(T)=R₀[1+α(T−T₀)]、磁链 λ_pm(T)（超过退磁温度后**不可逆**下降）、摩擦/润滑黏度、功率级饱和与电流上限、传感器增益/零偏、结构热膨胀。第 59 轮的 EEIS 在固定电机模型上离线算 K_safe；热降额后真实可行的 (K_p,K_d,F_max,ω_traj) 集合会收缩，若仍按旧证书下发，就是**证书未过期但物理已失效**。热管理必须进入阻抗编译，而不只是进入“预算告警”。
- **H34（仿真可信度·覆盖度盲区）**：仿真训练给出先验、Pareto 前沿、异常检测器甚至热降额策略；但 sim-to-real 差距是**状态相关**的，且在训练分布外可被系统性放大。领域随机化扩大覆盖的同时，可能把某个真实系统性偏差平均成零均值噪声，使验证集看似通过而部署区持续偏置。仿真证据若被当作独立佐证，就会与执行证据形成**同源共模**——两者都错时仍然“互相一致”。
- **H35（热循环损伤·分布漂移与证据陈旧）**：加速热循环/寿命仿真产生的是训练分布，不是部署分布；损伤 D_cum 随热循环单调累积，使电机参数、摩擦、传感器漂移**非平稳**。热时间常数长，容易让人误以为“几分钟前的证据仍新鲜”；但热阈值跨越与损伤累积是**不可逆**的，低频校准可能来不及。证据鲜度必须分成**接触鲜度（ms 级）与热鲜度（s~min 级）双时钟**，且热状态分层后的共形校准才可信。

## 0. 直觉与动机

**灵感 1（热管理 → 热状态一等公民 TSO/TSEB）**
直觉：机器人不是“恒温执行器”。热像一位**慢动作的记账员**：每一次电流、每一次接触摩擦、每一次堵转都在账本上记一笔，且账本有**阈值**（绝缘等级、磁钢退磁、轴承润滑失效）和**不可逆条目**（热损伤、退磁、材料老化）。因此不能只测一个 T_junc，而要维护**热执行状态** ξ_therm=(T_winding,T_magnet,T_bearing,T_powerstage,T_battery,∇T,h_therm,D_cum,C_cool,T_amb)，用**电-热耦合模型 + 热观测器**在线估计，并把热历史核 h_therm 与累积损伤 D_cum 一并纳入。关键洞见：**热约束应是“带前瞻的硬包络 + 带热储备的预算”**，而不是事后告警；热管理可以**主动**（预冷、分配关节负载、热感知检查点调度），但主动热操作本身消耗预算且可能推迟证据获取。

**灵感 2（仿真训练 → 仿真可信度契约 SCC）**
直觉：仿真是一张**压缩过的地图**，不是领土。地图在覆盖范围内很准，在边界外可能把人带进沟里。仿真训练可以廉价生成罕见热故障、加速热循环、预训练降额策略与异常检测器；但必须同时产出**覆盖度证书、sim-to-real 差距界、漂移监测**，否则“仿真里 99.9% 安全”只是“地图上 99.9% 安全”。关键洞见：**仿真证据只能改变先验/条件化与保守方向，不能替代现场证据，也不能减少探针需求**；覆盖度外一律退回现场证据与保守动作。

**灵感 3（合流 → 热数字孪生 TDT + 仿真训练安全编译 STSC）**
直觉：把电-热模型、sim-to-real 差距模型、在线遥测合成一个**热数字孪生**：它可以在接触前前瞻预测 T_peak、D_cum 与热降额后的 K_safe 是否仍非空；一旦孪生预测误差持续偏大（CUSUM/Page-Hinkley 检出），就**膨胀不确定度、收缩安全包络、进入保守热模式**。仿真训练则用于离线预计算“热-力-电”耦合下的 Pareto 前沿，但上线前必须用**差距界**做鲁棒外扩：δ_f^real ≤ δ_f^sim + L·ε_gap + δ_cov + δ_drift；覆盖度外无证书。

**灵感 4（新模态 → 条件化模态，而非第 6/第 7 个“独立观测” XMC++）**
直觉：热与仿真都可以提供信息，但它们与执行/触探**不独立**：热模型与电机模型共享物理假设，仿真与控制器共享建模假设。若把它们当独立模态投票，就会把**同源误差**误当“多模态一致”。因此定义模态角色：**现场模态 F={vis,tap,prop,acou,exec} 负责证据门；条件化模态 C={therm,sim} 只负责调整先验、膨胀不确定度、触发保守**。热/仿真与现场分歧只能让系统更保守，绝不能让证据门更容易通过。

**灵感 5（预算 → 六预算耦合 PCE++++ + 热储备）**
直觉：第 59 轮已有 B_probe/B_ft/B_ux/B_exec；本轮新增 **B_therm**（温度余量、温升速率余量、损伤余量、**锁定的安全热储备**）与 **B_sim**（仿真查询/验证预算、可信度）。VOI 同时扣除执行成本、热成本与仿真成本：为了一次高信息量探针而把关节推到退磁边缘，或为一个覆盖度外的仿真结论反复查询，都是**负价值**。热储备只能用于安全停/不可逆接触前的最终验证，不能被探索性探针挪用。

## 1. 形式化定义（增量：定义 153–162）

**定义 153（热执行状态与电-热记忆模型 TSO）** 热执行状态 ξ_therm=(T_w,T_m,T_b,T_ps,T_bat,∇T,h_therm,D_cum,C_cool,T_amb)∈ℝ^{d_T}。电-热动力学：
```
C_w Ṫ_w = i_d²R_s(T_w)+i_q²R_s(T_w)+k_iron|ω_e|^β+k_sw|i_q| − (T_w−T_m)/R_wm − h_wA_w(T_w−T_amb)
C_m Ṫ_m = (T_w−T_m)/R_wm − (T_m−T_amb)/R_ma + Q_demag(T_m)
C_b Ṫ_b = Q_fric(τ,ω,T_b) + (T_m−T_b)/R_mb − Q_cool(C_cool,T_b,T_amb)
C_ps Ṫ_ps = Q_sw(i_q,f_sw,T_ps) − Q_cool,ps
C_bat Ṫ_bat = i_bat²R_int(T_bat) − Q_cool,bat
```
热记忆用多时间常数核近似：T(t)=T_ss+Σ_j a_j∫₀^t e^{−(t−s)/τ_j}Q_gen(s)ds；累积损伤
```
D_cum(t)=Σ_cycles n_i/N_i(ΔT_i,T_i) + ∫₀^t ds/L_arr(T(s)),  N_i 由 Coffin-Manson-Arrhenius 给出
```
热观测器 TSO 为 UKF/EKF/MHE，观测 y_T=(热敏电阻、绕组电阻反演、功率级温度、冷却液温度/流量、电流/转速)，先验来自仿真但以 SCC 可信度加权；输出 (ξ̂_therm,P_therm) 与热 OOD 指示。热观测器误差契约：Pr[‖ξ̂_therm−ξ_therm‖_{P_therm^{-1}} ≤ χ²_{d_T}(1−α_T)] ≥ 1−δ_T。

**定义 154（热-力-电耦合映射 Γ_T）** 将热状态映射为执行参数：
```
R(T)=R₀[1+α_Cu(T−T₀)]
λ_pm(T)=λ₀[1+β(T−T₀)],  若 T_m≥T_demag−Δ_safe 则 λ_pm 发生不可逆损失且标记 D_mag=1
c_fric(T)=c₀exp(−E_a/(k_BT))（润滑黏温关系）
K_t(T)=1.5p·λ_pm(T),  F_abs(T)=min(F_thermal(T),F_struct),  ω_bw(T)=ω_bw,0·g_derate(T)
ADC_gain(T),ADC_offset(T) 由温漂模型给出
```
于是第 59 轮的结构化似然升级为
```
L_exec^T(obs\|θ,ξ_exec,ξ_therm)=N(obs; h_probe(θ,Γ_T(ξ_exec,ξ_therm)), Σ_exec(ξ_exec,T)+Σ_therm(P_therm)+Σ_damage(D_cum))
```
**定义 155（热感知结构化似然与热分层共形 TASL）** 令热工作域划分为 R={cold,warm,hot,derated,demag-risk}。对每个热域 r，维护校准集 S_r={(X_i,Y_i,T_i,D_i)}。热分层共形预测：
```
q̂_r = Quantile_{1−α}({s_i | T_i∈r, D_i∈bucket_r}),  s_i=score(X_i,Y_i)
覆盖保证：Pr[Y∈C(X)|T∈r] ≥ 1−α−TV(p_T^{test},p_T^{cal})−δ_D
```
当某热域样本不足时，使用加权共形（权重 w_i∝p_test(T_i)/p_cal(T_i)）并在置信度上扣减 δ_therm；若热域发生迁移（T 分布漂移、D_cum 跳跃），强制膨胀共形带并触发保守，而非沿用旧 q̂。**热域不可交换**：不能把 cold 域的残差直接用于 derated 域。

**定义 156（热安全包络与热预算 TSEB）** 热安全包络
```
H_therm={ T_w≤T_w,max, T_m≤T_demag−Δ_safe, T_b≤T_b,max, T_ps≤T_ps,max, T_bat≤T_bat,max,
          \|Ṫ\|≤r_max, D_cum≤D_max, margin_demag≥Δ_safe, margin_insulation≥Δ_ins }
```
预测性热屏障：给定前瞻 H_p 与最坏产热，要求
```
Pr[∃t∈[0,H_p]: ξ_therm(t)∉H_therm] ≤ δ_therm^req
```
用离散时间屏障证书 B(ξ)=min_j h_j(ξ)（h_j 为各约束裕度）与最坏情况产热上界验证 B_{t+1}≥(1−γ)B_t；模型不确定度经 P_therm 传播。热预算
```
B_therm=(H_T=T_max−T_now, H_rate=r_max−\|Ṫ\|, H_D=D_max−D_cum, R_safe=β_th·B_therm)
```
其中 R_safe 为**锁定热储备**，仅可用于安全停、不可逆接触前的最终验证、或从过热态主动预冷；探索性探针不得消耗 R_safe。热降额映射 Δ_therm: ξ_therm→(F_max↓,K_p,max↓,ω_bw↓,I_max↓) 由 Γ_T 与 H_therm 共同决定；当 H_T<0 或 D_cum≥D_max 或 D_mag=1 时，禁止新的不可逆接触。

**定义 157（仿真可信度契约 SCC 与仿真证据 EV-sim）** 仿真资产 S=(仿真器版本, 参数先验, 场景库, 验证集, 热-力-电耦合模型)。覆盖度 Cov_S(x,u,ξ) 由场景库密度/k-NN 距离/马氏距离分层估计；sim-to-real 差距界
```
ε_gap(x,u,ξ) = Quantile_{1−δ_gap}(|y_real−y_sim| | (x,u,ξ)∈bin),  仅在 Cov_S≥Cov_min 的覆盖域 C_cert 上有效
漂移界 ε_drift 由在线配对校验/漂移检测给出
```
仿真可信度 ρ_sim(x,u,ξ)=σ(κ_1(Cov_S−Cov_min)+κ_2(ε_gap,max−ε_gap)+κ_3(ε_drift,max−ε_drift)+κ_4·recency)。仿真契约 C_sim=(Cov_min,δ_gap,ε_gap,max,ε_drift,max,coverage_hash,version)。覆盖度外 ρ_sim=0，退回现场证据与保守动作。仿真证据
```
EV-sim=(coverage, gap_residual, drift_residual, rho_sim, sim_version, ood_sim)
```
**EV-sim 只可作为先验/条件化/保守触发器，绝不作为 EV-xmodal/EV-human/EV-exec 的独立佐证**；仿真与现场一致时不减少探针需求，只在分歧时增加保守。

**定义 158（仿真训练安全编译 STSC）** 设仿真给出的证书为 (δ_f^sim,K_safe^sim,γ_margin^sim,F_max^sim,ω_bw^sim)，真实风险泛函对模型误差满足 Lipschitz 常数 L_f，覆盖域 C_cert 上差距界 ε_gap、覆盖风险 δ_cov、漂移 δ_drift。则对 x∈C_cert：
```
δ_f^real(x) ≤ δ_f^sim(x)+L_f·ε_gap(x)+δ_cov+δ_drift
```
鲁棒编译：
```
K_safe^real={k∈K_safe^sim | γ_margin(k)≥γ_margin^sim+γ_gap,
              F_max(k)≤F_abs(T)−F_gap,
              K_p(k)≤K_p,max(T),  ω_traj(k)≤ω_bw(T)−ω_gap,
              δ_f^sim+L_f·ε_gap+δ_cov+δ_drift≤δ_f^req}
```
若 K_safe^real=∅ ⇒ **仿真证书不可迁移**，必须补现场数据/重训/降级，禁止把仿真证书直接下发。训练侧可采用覆盖度感知的领域随机化与热角例优先采样，但认证侧只认**最坏差距界**，不认训练集平均误差。

**定义 159（热数字孪生 TDT）** 孪生状态 z=(ξ_exec,ξ_therm,D_cum,环境模型)，预测 ŷ_{t+H}。孪生误差 e_twin=\|y_real−ŷ\|，用 CUSUM/Page-Hinkley 检测持续偏置；孪生可信度 ρ_twin∈(0,1] 随误差与漂移更新。规则：
```
ρ_twin<ρ_min ⇒ Σ←Σ·(1+κ(1−ρ_twin)/ρ_twin), K_safe←shrink(K_safe,ρ_twin), 进入 DEGRADE_THERM
```
TDT 用于接触前热前瞻：在候选检查点/轨迹上预测 T_peak、D_cum、降额后的 K_safe 是否非空，并选择“证据价值 − 热成本 − 损伤成本”最大的动作。

**定义 160（跨模态对账扩展 XMC++：现场模态 vs 条件化模态）** 模态角色划分：
```
现场模态 F={vis,tap,prop,acou,exec}；条件化模态 C={therm,sim}
融合：p(θ|D) ∝ p(θ|C,ρ_sim) · Π_{m∈F} L_m^{ρ_m}
条件化模态只允许：调整先验、膨胀协方差、触发保守；不得作为证据门佐证、不得降低 D⁺。
D^{++}(r)=D⁺(r)+w_th·TV(lbl_therm,lbl_F)+w_sim·(1−ρ_sim)·TV(lbl_sim,lbl_F)
规则：(R1++) D^{++}>θ_D^{++} ⇒ 后验加宽+补探针；(R2++) EV-therm/EV-sim 永不进入 EV-xmodal/EV-human/EV-exec 佐证集；
(R3++) sim/therm 与现场一致 ⇒ 不得减少探针；(R4++) ρ_sim=0 或热 OOD ⇒ 强制条件化模态失效、退回现场证据+保守。
```
注意：热模态与执行模态虽都来自本体，但热是**慢上下文**、执行是**快观测**；二者不独立（共享电机模型），因此热不能被当作“第二票”。

**定义 161（六预算耦合 PCE++++）** 预算
```
B=(B_probe,B_ft,B_ux,B_exec,B_therm,B_sim)
VOI(π)=VOI_meta_pessimistic(π)−cost_exec(π)−cost_therm(π)−cost_sim(π)
cost_therm=λ_T·max(0,T_peak(π)−H_T)+λ_D·max(0,ΔD(π)−H_D)+λ_R·1[π 消耗 R_safe]
cost_sim=λ_q·query_cost(π)+λ_g·(1−ρ_sim)·risk_exposure(π)
```
六预算单调消耗、互不挪用；**R_safe 锁定**，仅安全停/不可逆接触前最终验证可用。B_therm 耗尽或 H_T<0 ⇒ DEGRADE_THERM（限流、降 K_p、降速、预冷、放弃不可逆接触）；B_sim 耗尽或 ρ_sim<ρ_min ⇒ DEGRADE_SIM（退回现场先验与保守参数）。

**定义 162（热-仿真双向契约闭环 T-SCLEP 与执行证书 J_therm）** 算子
```
T-SCLEP(M,cp,δ_f^req,B):
 ① TSO: ξ̂_therm,P_therm ← thermal_observer.update(telemetry, sim_prior)
 ② SCC: (ok,ρ_sim,ε_gap) ← C_sim.check(cp); ok=false ⇒ DEGRADE_SIM
 ③ TDT: (T_peak,D_peak,p_therm) ← twin.rollout(cp,H_p)
```

### IP-152 TSO（热状态观测器与损伤账户）

```python
class ThermalStateObserver:
    def __init__(self, thermal_model, sim_prior, scc):
        self.model = thermal_model          # C_w,C_m,C_b,C_ps,C_bat,R_th,h,A
        self.kf = UKF(dim=len(STATE), obs_dim=len(THERM_SENSORS))
        self.kf.x = sim_prior.mean          # 仿真先验按 rho_sim 加权
        self.kf.P = sim_prior.cov / max(scc.rho, 1e-3)
        self.damage = DamageAccount(model=thermal_model)

    def predict(self, dt, u, xi_exec):
        def f(x):
            Tw,Tm,Tb,Tps,Tbat = x[:5]
            Qw = xi_exec.R_s*(u.i_d**2+u.i_q**2) + self.model.iron(u.omega) + self.model.sw(u.i_q,u.f_sw)
            Qb = self.model.friction(xi_exec.tau, u.omega, Tb)
            return self.model.step(x, Qw, Qb, u.coolant, dt)
        self.kf.predict(f, Q=self.model.process_noise(u))

    def update(self, y_T, u):
        self.kf.update(y_T, h=self.model.sensor_model)   # 热敏+电阻反演+冷却液
        if self.kf.mahalanobis() > chi2.ppf(0.99, df=len(STATE)):
            self.ood_thermal = True
            self.kf.P *= self.model.ood_inflation
        return self.kf.x, self.kf.P

    def thermal_derating(self):
        Tw,Tm,Tb,Tps,Tbat = self.kf.x[:5]
        F_abs = min(self.model.F_thermal(Tm), self.model.F_struct)
        Kp_max = self.model.Kp_max(Tm)          # 磁链/电流上限约束
        w_bw   = self.model.bandwidth(Tps,Tm)   # 功率级/磁链带宽
        return Derating(F_abs, Kp_max, w_bw,
                        I_max=self.model.I_max(Tw,Tps))

    def update_damage(self, dt, T_hist):
        self.damage.integrate(dt, T_hist)        # Coffin-Manson + Arrhenius
        return self.damage.D_cum, self.damage.dD
```

### IP-153 TASL（热分层共形与热条件似然）

```python
class ThermalAwareLikelihood:
    def __init__(self, alpha=0.01):
        self.calib = {r: ConformalCalibrator(alpha) for r in REGIMES}

    def regime(self, T, D):
        if T.magnet >= T_demag - DELTA_SAFE: return 'demag_risk'
        if T.winding >= T_w_derate:          return 'derated'
        if T.winding >= T_w_hot:             return 'hot'
        if T.winding >= T_w_warm:            return 'warm'
        return 'cold'

    def calibrate(self, residuals, T, D):
        for i,(s,t,d) in enumerate(zip(residuals,T,D)):
            self.calib[self.regime(t,d)].add(s, weight=reweight(t,d))

    def quantile(self, T, D):
        r = self.regime(T,D)
        if self.calib[r].n < N_MIN:
            q = self.calib[r].weighted_quantile()
            return q + CONFORMAL_INFLATION      # 样本不足 → 加宽
        return self.calib[r].quantile()

    def likelihood(self, obs, h_probe, xi_exec, xi_therm):
        Sigma = propagate_exec_cov(xi_exec) \
              + propagate_thermal_cov(xi_therm) \
              + damage_cov(xi_therm.D_cum)
        return Gaussian(mean=h_probe(xi_exec, xi_therm), cov=Sigma)
```

### IP-154 TSEB（热包络与热预算）

```python
class ThermalSafetyEnvelope:
    def __init__(self, limits, horizon, delta_req):
        self.L, self.Hp, self.delta = limits, horizon, delta_req

    def margins(self, x):
        Tw,Tm,Tb,Tps,Tbat = x[:5]
        return np.array([self.L.Tw-Tw, self.L.Tm_margin-Tm,
                         self.L.Tb-Tb, self.L.Tps-Tps,
                         self.L.Tbat-Tbat, self.L.r_max-abs(x.dot),
                         self.L.D_max-x.D_cum, self.L.demag_margin-Tm])

    def predictive_check(self, tdt, cp, P_therm):
        samples = tdt.rollout_samples(cp, self.Hp, P_therm)
        B = np.array([self.margins(s).min() for s in samples])
        p_viol = np.mean(B < 0)
        reserve_ok = self.budget.reserve_after(cp) >= 0
        return p_viol <= self.delta and reserve_ok, p_viol

class ThermalBudget:
    def __init__(self, B_therm, beta_reserve=0.4):
        self.H_T, self.H_rate, self.H_D = B_therm.headroom
        self.R_safe = beta_reserve * self.H_T
        self.spent_explore = 0.0

    def cost(self, dT_pred, dD_pred, uses_reserve):
        c = LAMBDA_T*max(0, dT_pred-self.H_T) + LAMBDA_D*max(0, dD_pred-self.H_D)
        if uses_reserve and not ALLOWED_SAFETY_USE:
            c += LAMBDA_R*self.R_safe      # 探索性挪用热储备：极高惩罚
        return c
```

### IP-155 SCC（仿真可信度契约）

```python
class SimulationCredibilityContract:
    def __init__(self, coverage, gap_model, drift_detector):
        self.Cov = coverage
        self.gap = gap_model              # 分层 sim-to-real 差距
        self.drift = drift_detector       # 在线配对/漂移

    def check(self, x, u):
        cov = self.Cov.score(x, u)
        if cov < self.Cov.cov_min:
            return False, 0.0, float('inf'), 'out_of_coverage'
        eps = self.gap.quantile(x, u, self.Cov.delta_gap)
        dft = self.drift.statistic(x, u)
        rho = sigmoid(K1*(cov-self.Cov.cov_min) + K2*(self.Cov.eps_max-eps)
                      + K3*(self.Cov.drift_max-dft) + K4*self.Cov.recency)
        ok = (eps <= self.Cov.eps_max and dft <= self.Cov.drift_max and rho >= RHO_MIN)
        return ok, rho, eps, 'ok' if ok else 'gap_or_drift'

class SimulationEvidence:
    def __init__(self, coverage, gap_residual, drift_residual, rho, version, ood):
        self.coverage, self.gap_residual = coverage, gap_residual
        self.drift_residual, self.rho = drift_residual, rho
        self.version, self.ood = version, ood
```

### IP-156 STSC（仿真训练安全编译）

```python
class SimulationTrainedSafetyCompiler:
    def __init__(self, sim_front, lipschitz_f, gap_model):
        self.front = sim_front          # 离线仿真 Pareto 前沿
        self.Lf = lipschitz_f
        self.gap = gap_model

    def compile(self, delta_req, fused, xi_exec, xi_therm, eps_gap, rho_sim):
        if rho_sim < RHO_MIN:
            return None, None           # 覆盖外：无证书
        der = ThermalDerating(xi_therm)
        feasible = []
        for p in self.front:
            if p.F_max > der.F_abs - F_GAP:            continue
            if p.K_p   > der.Kp_max:                  continue
            if p.omega > der.w_bw - W_GAP:            continue
            risk_real = (p.delta_f_sim + self.Lf*eps_gap
                         + DELTA_COV + DELTA_DRIFT)
            if risk_real > delta_req:                 continue
            feasible.append((p, risk_real))
        if not feasible:
            return None, None           # 不可迁移 ⇒ 降级/重训/补数据
        p, risk = max(feasible, key=lambda x: (x[0].omega, -x[0].K_p))
        cert = ThermalCertificate(p, risk, eps_gap, rho_sim,
                                  der.F_abs, der.Kp_max, der.w_bw,
                                  sim_version=self.front.version)
        return p, cert
```

### IP-157 TDT（热数字孪生与发散检测）

```python
class ThermalDigitalTwin:
    def __init__(self, model, scc):
        self.model, self.scc = model, scc
        self.rho_twin = 1.0
        self.cusum = CUSUM(k=0.5, h=5.0)

    def rollout(self, cp, horizon, P_therm, n=64):
        samples = []
        for _ in range(n):
            z = self.model.sample_state(P_therm)
            for t in range(int(horizon/DT)):
                z = self.model.step(z, cp.thermal_action(t), cp.load(t))
            samples.append(z)
        T_peak = max(s.T_winding for s in samples)
        D_peak = max(s.D_cum for s in samples)
        p_therm = np.mean([not self.model.in_envelope(s) for s in samples])
        return T_peak, D_peak, p_therm

    def update(self, y_real, y_hat):
        e = abs(y_real - y_hat)
        alarm = self.cusum.update(e)
        self.rho_twin = max(RHO_TWIN_MIN, self.rho_twin - ETA*e)
        if alarm:
            self.rho_twin *= 0.5
            self.model.inflate_cov(1/self.rho_twin)
        return self.rho_twin, alarm
```

```python
def t_sclep(M, cp, delta_f_req, budget):
    # ① 热观测
    M.tso.predict(DT, M.u_latest, M.buq.ukf.x)
    xi_T, P_T = M.tso.update(M.telemetry.thermal, M.u_latest)

        return degrade_sim(M, cp, why)
    # ③/④ 热前瞻与包络

    ok_T, p_viol = M.tseb.predictive_check(T_peak, D_peak, p_therm)
    if not ok_T:
        return degrade_therm(M, cp, 'thermal_envelope')
    # ⑤ BUQ + 热条件似然
    M.buq.update(M.telemetry.fast)
    inf = meta_infer_thermal(M, cp.region, xi_T, P_T, M.tasl)
    # ⑥ XMC++：exec 现场、therm/sim 条件化
    M, fused, Dpp = xmodal_fuse_pp(M, cp.region, inf,
                                   M.EV_exec_latest, EV_therm(xi_T), M.EV_sim_latest)

    if K_safe is None:
        return degrade_therm(M, cp, 'K_safe_empty')
    # ⑧ 下发/执行
    dispatch_impedance(K_safe, cert)
    tel = execute_contact(cp, K_safe, timeout=M.contact_timeout)
    # ⑨ 证据与热账本
    M.EV_exec_log.append(build_exec_evidence(tel, cert))
    M.EV_therm_log.append(build_thermal_evidence(tel, xi_T, P_T))
    M.EV_sim_log.append(M.scc.evidence(cp))
    M.tso.update_damage(DT, tel.T_hist)
    M.tdt.update(tel.thermal_obs, M.tdt.last_pred)
    # ⑩ 预算闭环
    budget.spend(cost_exec=..., cost_therm=M.tseb.cost(...), cost_sim=M.scc.cost(...))
    return M, fused, Dpp, K_safe, cert
```

**正确性定理（Thermal-Simulation Grounded Evidence Soundness, T-SGES）**
假设 A22–A55（第 53–59 轮）成立；**(A56)** TSO 电-热模型偏差有界，观测器满足 Pr[‖ξ̂_therm−ξ_therm‖_{P_therm^{-1}}≤χ²_{d_T}(1−α_T)]≥1−δ_T；热 OOD 漏检率 ≤δ_T,ood。**(A57)** 损伤模型 D_cum 对真实损伤单调且保守（不低估），退磁判据 T_m≥T_demag−Δ_safe 是真实退磁的充分条件。**(A58)** 热分层共形在每一热域内满足可交换性，或加权共形的密度比估计误差 ≤δ_w；跨热域迁移被显式检测并膨胀。**(A59)** SCC 的覆盖度估计、sim-to-real 差距界 ε_gap 与漂移界 ε_drift 在 C_cert 上诚实（真实差距落入界内的概率 ≥1−δ_gap，漂移漏检 ≤δ_drift）。**(A60)** STSC 中风险泛函对模型误差满足 Lipschitz 常数 L_f，覆盖风险与漂移界可加；覆盖外不签发证书。**(A61)** TDT 发散检测延迟 ≤N_twin 步，检测后 ρ_twin 单调下降且协方差膨胀。**(A62)** XMC++ 中热/仿真仅进入先验与保守方向，不进入现场证据门；融合对条件化模态的更新是“只能加宽”的单调映射。**(A63)** PCE++++ 六预算单调消耗、互不挪用；R_safe 只用于安全用途；热/仿真成本诚实上界真实消耗。则：

1. **热接地校准健全性**：在热域 r 内，证据层后验校准误差
   `ECE_k ≤ ε_meta(k)+δ_T(ξ_therm)+δ_therm(ρ_twin)+δ_sim(ρ_sim)+δ_w`；
   热分层共形覆盖率 ≥1−α−TV−δ_D−δ_T,ood；热 OOD 时强制退回保底带。
2. **热包络预测安全**：若 TSEB 预测检查通过，则未来 H_p 内热约束违例概率 ≤δ_therm^req+δ_T+δ_model；若检查失败或 R_safe 不足，则禁止不可逆接触并进入 DEGRADE_THERM。
3. **仿真迁移健全性**：对 x∈C_cert，`δ_f^real(x) ≤ δ_f^sim(x)+L_f·ε_gap(x)+δ_cov+δ_drift`；K_safe^real 非空 ⇒ 下发参数满足真实热-力约束的概率 ≥1−δ_f^req；K_safe^real=∅ ⇒ 仿真证书不可迁移，强制补现场数据/重训/降级。
4. **热降额声音性**：热感知编译输出满足 `F_max≤F_abs(T)−F_gap, K_p≤K_p,max(T), ω_traj≤ω_bw(T)−ω_gap`；D_mag=1 或 D_cum≥D_max ⇒ 永久禁止相应不可逆动作。
5. **单向安全通道**：热/仿真模态只能通过“膨胀不确定度、收缩动作集、触发降级”影响系统；即便与现场一致，也不得减少探针、降低证据门或替代现场证据。六预算耗尽只能使动作更保守。
6. **终止性与部署界**：T-SCLEP 在 k_probes+k_cons+k_ft+k_ux+k_exec+k_therm+k_sim 内终止于 {承诺(带 Cert), 绕行, 降档, L2 协商, 安全停, DEGRADE_EXEC, DEGRADE_THERM, DEGRADE_SIM}。对检查点取联合界：
```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                  + δ_ft·1[回滚] + δ_kg·1[检索失败] + δ_ux·1[μ_mis>θ]
                  + δ_exec·1[ξ_exec 漂移] + δ_ξood·1[执行 OOD]
                  + δ_ertc·1[契约违例] + δ_eeis·1[μ 漏报]
                  + δ_T·1[热观测误差] + δ_T,ood·1[热 OOD]
                  + δ_therm·1[热包络违例] + δ_damage·1[D 低估]
                  + δ_gap·1[sim-to-real 差距漏界] + δ_cov·1[覆盖外]
                  + δ_twin·1[孪生发散]) − P(共模建模错误) − P(硬件热保护失效)
```
关键：**热状态不是“慢噪声”，而是带阈值与不可逆账本的一等状态**——TSO 把它辨识出来，TASL 按热域校准，TSEB 用前瞻屏障与锁定热储备守住不可逆边界；**仿真不是“事实”，而是带覆盖度与差距界的先验**——SCC 给证书，STSC 把差距编译成鲁棒裕度，TDT 用在线误差证伪孪生。二者都只能让系统**更保守**，不能充当独立佐证。三条安全单向通道继续延伸：**信念更准（热-仿真条件化）、不确定性更大（热域/覆盖外膨胀）、动作更保守（降额/热储备/降级）**。

## 6. 本轮最大风险

**一句话**：热模型与仿真器可能共享同一套未验证的物理假设（同一套热-力-电耦合方程、同一批材料参数、同一个被领域随机化“抹平”的系统性偏差），于是热观测器、仿真证书与执行证据会**同源共模地互相印证**，而现实已在覆盖外或未建模的热耦合路径上失效——这类共模错误无法靠“多模态一致”发现，只能靠独立的硬件热保护、真实配对校验与覆盖外拒签来兜底。

```python
class ThermalAwareLikelihood:
    def __init__(self, alpha=0.01):
        self.alpha = alpha
        self.calib = {r: WeightedConformal(alpha) for r in REGIMES}

    def regime(self, T):
        if T.Tm >= T_DEMAG - DELTA_SAFE: return 'demag_risk'
        if T.Tw >= T_W_DERATE:          return 'derated'
        if T.Tw >= T_W_HOT:             return 'hot'
        if T.Tw >= T_W_WARM:            return 'warm'
        return 'cold'

        r = self.regime(T)
        w = density_ratio(T, D, r)      # 加权共形，处理热协变量偏移
        self.calib[r].add(score, weight=w)

        r = self.regime(T)
        q = self.calib[r].quantile()
        if self.calib[r].effective_n < N_MIN:
            q += CONFORMAL_INFLATION      # 样本不足/热域迁移：只加宽
        return q + DELTA_DAMAGE(D)

    def likelihood(self, obs, h_probe, xi_exec, xi_therm):
        Sigma = propagate_exec_cov(xi_exec) \
              + propagate_thermal_cov(xi_therm.P) \
              + damage_cov(xi_therm.D_cum)
```

### IP-155 SCC（仿真可信度契约）

```python
class SimulationCredibilityContract:
    def __init__(self, coverage, gap_model, drift_detector, contract):
        self.Cov, self.gap = coverage, gap_model
        self.drift, self.C = drift_detector, contract

    def check(self, x, u):
        cov = self.Cov.score(x, u)
        if cov < self.C.cov_min:
            return False, 0.0, float('inf'), 'out_of_coverage'
        eps = self.gap.quantile(x, u, self.C.delta_gap)
        dft = self.drift.statistic(x, u)
        rho = sigmoid(K1*(cov-self.C.cov_min) + K2*(self.C.eps_max-eps)
                      + K3*(self.C.drift_max-dft) + K4*self.C.recency)
        ok = eps <= self.C.eps_max and dft <= self.C.drift_max and rho >= RHO_MIN
        return ok, rho, eps, 'ok' if ok else 'gap_or_drift'

    def evidence(self, x, u):
        ok, rho, eps, why = self.check(x, u)
        return SimulationEvidence(coverage=self.Cov.score(x,u), gap_residual=eps,
                                  drift_residual=self.drift.statistic(x,u),
                                  rho=rho, version=self.C.version,
                                  ood=(not ok))
```

```python
class SimulationTrainedSafetyCompiler:
    def __init__(self, sim_front, lipschitz_f, gap_model):
        self.front, self.Lf, self.gap = sim_front, lipschitz_f, gap_model

    def compile(self, delta_req, fused, xi_exec, xi_therm, eps_gap, rho_sim):
        if rho_sim < RHO_MIN:
            return None, None                     # 覆盖外：拒签
        der = ThermalDerating(xi_therm)
        feasible = []
        for p in self.front:
            if p.F_max > der.F_abs - F_GAP:       continue
            if p.K_p   > der.Kp_max:              continue
            if p.omega > der.w_bw - W_GAP:        continue
            risk_real = p.delta_f_sim + self.Lf*eps_gap + DELTA_COV + DELTA_DRIFT
            if risk_real > delta_req:             continue
            feasible.append((p, risk_real))
        if not feasible:
            return None, None                     # 不可迁移：降级/重训/补现场数据
        p, risk = max(feasible, key=lambda x: (x[0].omega, -x[0].K_p))
        return p, ThermalCertificate(
            K_p=p.K_p, K_d=p.K_d, F_max=p.F_max, omega=p.omega,
            delta_f_sim=p.delta_f_sim, delta_f_real=risk,
            eps_gap=eps_gap, rho_sim=rho_sim,
            F_abs=der.F_abs, Kp_max=der.Kp_max, w_bw=der.w_bw,
            sim_version=self.front.version, timestamp=time.monotonic())
```

```python
class ThermalDigitalTwin:
    def __init__(self, model, scc):
        self.model, self.scc = model, scc
        self.rho_twin = 1.0
        self.cusum = CUSUM(k=0.5, h=5.0)

        return self.rho_twin, False
```

### IP-158 XMC++（现场模态与条件化模态分离）

```python
def xmodal_fuse_pp(M, region, inf, EV_exec, EV_therm, EV_sim):
    # 现场模态：唯一可进入证据门的通道
    field = ['vis','tap','prop','acou','exec']
    for m in field:
        if m in inf.likelihood:
            M.b[region][m] = bayes_update(M.b[region][m], inf.likelihood[m], w=M.rho[m])

    # 条件化模态：仅调整先验 / 膨胀 / 触发保守；不参与“投票”
    prior = M.b[region]['prior']
    prior = condition_prior(prior, EV_therm, weight=w_th)
    prior = condition_prior(prior, EV_sim, weight=w_sim*EV_sim.rho)
    fused = Fuse(field_beliefs=M.b[region], prior=prior, rhos=M.rho)

    # 分歧只增不减：一致不奖励，分歧就加宽
    Dpp = disagreement_plus(M.b[region], M.rho_exec)
    Dpp += w_th * TV(EV_therm.label_dist, fused.label_dist)
    Dpp += w_sim * (1.0 - EV_sim.rho) * TV(EV_sim.label_dist, fused.label_dist)

    if EV_sim.ood or EV_therm.ood:
        fused = inflate(fused, DELTA_OOD)
    return M, fused, Dpp
```

```python
        return voi_meta_pessimistic(pi, M, fused) - c_exec - c_therm - c_sim

    def spend(self, pi, M, fused):
        if self.voi(pi, M, fused) < THETA_VOI:
            return False
        self.B_probe.spend(); self.B_exec.spend(pi)
        self.B_therm.spend(pi.dT_pred, pi.dD_pred, pi.uses_reserve)
        self.B_sim.spend(pi.sim_queries)
        return True

    def thermal_viable(self):
        return self.B_therm.H_T > 0 and self.B_therm.H_D > 0 \
               and self.B_therm.H_rate > 0

    def simulation_viable(self, rho_sim):
        return self.B_sim.remaining > 0 and rho_sim >= RHO_MIN
```

### IP-160 T-SCLEP（热-仿真双向契约闭环）

```python
def t_sclep(M, cp, delta_f_req, budget):
    # ① 热观测
    M.tso.predict(DT, M.u_latest, M.buq.ukf.x)
    xi_T, P_T = M.tso.update(M.telemetry.thermal, M.u_latest)

    # ② 仿真可信度（覆盖外直接降级）
    ok_sim, rho_sim, eps_gap, why = M.scc.check(cp.state, cp.action)
    if not ok_sim:
        return degrade_sim(M, cp, why)

    # ③④ 热前瞻 + 热包络
    T_peak, D_peak, p_therm = M.tdt.rollout(cp, M.Hp, P_T)
    ok_T, p_viol = M.tseb.predictive_check(T_peak, D_peak, p_therm)
    if not ok_T or not budget.thermal_viable():
        return degrade_therm(M, cp, 'thermal_envelope_or_budget')

    # ⑤ 热条件似然
    M.buq.update(M.telemetry.fast)
    inf = meta_infer_thermal(M, cp.region, xi_T, P_T, M.tasl)

    # ⑥ XMC++：exec 是现场，therm/sim 是条件化
    M, fused, Dpp = xmodal_fuse_pp(
        M, cp.region, inf, M.EV_exec_latest,
        EV_therm(xi_T, P_T, M.tso.D_cum), M.EV_sim_latest)

    # ⑦ 热感知 + sim-to-real 鲁棒编译
    K_safe, cert = M.eeis.compile_thermal(
        delta_f_req, fused, M.buq.ukf.x, xi_T, eps_gap, rho_sim)
    if K_safe is None:
        return degrade_therm(M, cp, 'K_safe_empty')
    K_safe = M.tdt.shrink_safe_set(K_safe)       # 孪生发散 ⇒ 收缩

    # ⑧ 执行
    dispatch_impedance(K_safe, cert)
    tel = execute_contact(cp, K_safe, timeout=M.contact_timeout)

    # ⑨ 证据回传 + 热账本
    M.EV_exec_log.append(build_exec_evidence(tel, cert))
    M.EV_therm_log.append(build_thermal_evidence(tel, xi_T, P_T))
    M.EV_sim_log.append(M.scc.evidence(cp.state, cp.action))
    M.tso.update_damage(DT, tel.T_hist)
    rho_twin, alarm = M.tdt.update(tel.thermal_obs, M.tdt.last_pred)
    if alarm:
        M.thermal_degraded = True

    # ⑩ 预算闭环
    budget.spend(cp, M, fused)
    return M, fused, Dpp, K_safe, cert, (rho_twin, rho_sim)

def degrade_therm(M, cp, reason):
    M.thermal_degraded = True
    dispatch_impedance(CONSERVATIVE_THERMAL_PRESET, null_certificate())
    M.budget.ft_frozen = M.budget.ux_frozen = True
    M.thermal_degradation_log.append((time.monotonic(), cp, reason))
    return M, None, float('inf'), None, null_certificate(), (None, None)

def degrade_sim(M, cp, reason):
    M.sim_degraded = True
    M.scc.freeze_for(cp.state)
    return degrade_therm(M, cp, f'DEGRADE_SIM:{reason}')
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TSO | UKF O(14³)≈2.7k flops/周期 | O(14²) | 观测误差 ≤χ² 界；热 OOD 触发膨胀 |
| TASL | 校准 O(N_cal)；查询 O(log N_r) | O(Σ\|S_r\|) | 热分层覆盖 ≥1−α−TV−δ_D−δ_w |
| TSEB | 采样 O(n·H_p/DT) | O(n·d_T) | 前瞻热违例 ≤δ_therm^req；R_safe 锁定 |
| SCC | O(log N) 覆盖查询 + O(1) 分位 | O(验证集) | 覆盖外拒签；差距/漂移界诚实 |
| STSC | 离线 O(网格×仿真)；在线 O(\|前沿\|) | O(\|前沿\|) | δ_f^real≤δ_f^sim+Lε_gap+δ_cov+δ_drift |
| TDT | O(n·H_p) 前瞻；CUSUM O(1) | O(n) | 发散检测延迟 ≤N_twin；ρ↓⇒Σ↑,K_safe↓ |
| XMC++ | O((\|F\|+\|C\|)²·d_b) | O(\|V\|·(\|F\|+\|C\|)·d_b) | 条件化模态不作佐证；分歧只增 |
| PCE++++ | 与 PCE+++ 同阶 + 热/仿真前瞻 | O(n·H_p) | 六预算单调、热储备不可挪用 |
| T-SCLEP | O(TSO+TDT+STSC+融合)/接触 ≈300 μs | 复用各组件 | 闭环 ≤τ_contact_max；任一契约违例即降级 |
| J_therm | O(1)/接触追加 | O(接触数) | 证书链可验证、热/仿真审计完整 |

**正确性定理（Thermal-Simulation Grounded Evidence Soundness, T-SGES）**
假设 A22–A55（第 53–59 轮）成立；**(A56)** TSO 模型偏差有界，观测器误差满足 χ² 契约，热 OOD 漏检 ≤δ_T,ood；**(A57)** D_cum 对真实损伤单调且保守，退磁判据是真实退磁的充分条件；**(A58)** 热域内共形可交换或加权密度比误差 ≤δ_w，热域迁移被检测并膨胀；**(A59)** SCC 的覆盖度、ε_gap、ε_drift 在 C_cert 上诚实，覆盖外不签发证书；**(A60)** STSC 中风险泛函 Lipschitz 常数 L_f 有限，覆盖/漂移风险可加；**(A61)** TDT 发散检测延迟有界，检测后 ρ_twin 单调下降；**(A62)** XMC++ 中热/仿真仅进入先验与保守方向，不得降低证据门；**(A63)** PCE++++ 六预算单调、互不挪用，R_safe 仅安全用途。则：

1. **热接地校准健全性**：热域 r 内 `ECE_k ≤ ε_meta(k)+δ_T+δ_therm(ρ_twin)+δ_sim(ρ_sim)+δ_w`；热分层共形覆盖 ≥1−α−TV−δ_D−δ_T,ood。
2. **热包络预测安全**：TSEB 通过 ⇒ 未来 H_p 内热违例概率 ≤δ_therm^req+δ_T+δ_model；失败/R_safe 不足 ⇒ 禁止不可逆接触并 DEGRADE_THERM。
3. **仿真迁移健全性**：x∈C_cert 时 `δ_f^real≤δ_f^sim+L_f ε_gap+δ_cov+δ_drift`；K_safe^real 非空 ⇒ 真实热-力约束满足概率 ≥1−δ_f^req；为空 ⇒ 拒签、补数据/重训/降级。
4. **热降额声音性**：编译输出满足 `F_max≤F_abs(T)−F_gap ∧ K_p≤K_p,max(T) ∧ ω_traj≤ω_bw(T)−ω_gap`；D_mag=1 或 D_cum≥D_max ⇒ 永久禁止相应不可逆动作。
5. **单向安全通道**：热/仿真模态只能“膨胀不确定度、收缩动作集、触发降级”；即便与现场一致也不得减少探针、降低证据门或替代现场证据；六预算耗尽只能更保守。
6. **终止性与部署界**：T-SCLEP 在有限预算内终止于 {承诺(带 Cert), 绕行, 降档, L2 协商, 安全停, DEGRADE_EXEC, DEGRADE_THERM, DEGRADE_SIM}。部署界在 EGES 基础上追加：
```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                  + δ_ft·1[回滚] + δ_kg·1[检索失败] + δ_ux·1[μ_mis>θ]
                  + δ_exec·1[ξ_exec 漂移] + δ_ξood·1[执行 OOD]
                  + δ_ertc·1[契约违例] + δ_eeis·1[μ 漏报]
                  + δ_T·1[热观测误差] + δ_T,ood·1[热 OOD]
                  + δ_therm·1[热包络违例] + δ_damage·1[D 低估]
                  + δ_gap·1[sim-to-real 差距漏界] + δ_cov·1[覆盖外]
                  + δ_twin·1[孪生发散])
         − P(共模建模错误) − P(硬件热保护失效) − P(固件回滚失败)
```

关键：**热是带阈值与不可逆账本的一等状态**——TSO 估计它，TASL 按热域校准它，TSEB 用前瞻屏障与锁定热储备守住它；**仿真是带覆盖度与差距界的先验**——SCC 签发/拒签它，STSC 把差距编译成鲁棒裕度，TDT 用在线误差证伪它。二者都只能让动作更保守：**热更诚实、仿真更可证伪、安全更提前**。
