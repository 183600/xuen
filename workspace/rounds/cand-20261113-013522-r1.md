# 第 64 轮（承接第 63 轮「LIRO 几何-技能-干扰闭环」IP-193~203；灵感循环 III 第 1 轮；本轮灵感：「实例分割」×「比赛策略」）

> 第 63 轮的 LIRO 把 ROSE 从「参数在线鲁棒」推进到「几何先验 × 技能抽象 × 干扰免疫」，但它自述的最大风险仍是**全局几何先验的单点幻觉**：E_geo 一旦在透明/镜面/新拓扑物体上给出系统性错误法向或虚假接触面，GeoInit 的 φ̂_0 与 𝒢(g) 就会把「不确定性压缩」反转为「确定性错误注入」。
>
> 本轮的两个灵感正好从**空间粒度**与**决策粒度**两端拆掉这个单点：
> 1. **实例分割**把「一个全局几何假设」拆成**每个物体一个可独立验证的几何假设**——几何先验不再整体接受或整体拒绝，而是逐实例交叉验证、逐实例给出置信半径；未通过验证的实例不允许进入 WCV 的“自信几何”通道。
> 2. **比赛策略**把「安全证书」接入**有限预算、有限尝试、按分计奖**的真实赛制——系统不只要“做得安全”，还要决定**做哪些任务、按什么顺序做、何时放弃、何时花预算去补验证**；证书从“事后合规文件”变成“赛制资源分配的依据”。

## 0. 直觉与动机

### 灵感 1（实例分割 → PIV + OIM：把几何先验拆成可验证的实例假设）

**直觉**：第 63 轮的 LSF 是 `g = E_geo(P_cloud)`，把整帧点云压成一个全局嵌入；一旦某个物体几何异常，整帧的 g、φ̂_0、𝒢(g) 都被污染。人眼并不是这样工作的：人先分出“杯子、盘子、夹子”等**实例**，再分别判断每个物体的姿态、可抓面、是否透明/反光；看不清的物体不会被“脑补”成确定几何，而是被标记为“需要再看一眼”。

**关键洞见**：把 LSF 从「全局几何编码」升级为「**逐实例几何假设 + 逐实例验证**」。
- 实例分割算子 `ISeg` 从 RGB-D 与点云得到每个实例的观测掩码 `m_i`、**amodal（补全遮挡）掩码** `m_i^am`、类别 `c_i`、分割不确定度 `u_i`；
- 每实例点云 `P_i = P_cloud ⊙ m_i` 经 `E_geo` 得到实例几何 token `g_i` 与几何假设 `h_i = (T_i, b_i, n_i, κ_i, χ_i)`（位姿、包围盒、主法向、曲率、拓扑特征）；
- **PIV（Per-Instance Verification）** 用四类证据给每个实例打分：多视角/多帧重投影一致性、掩码边界与深度断裂对齐、实例内法向/曲率一致性、物理合理性（无穿模、支撑关系、类别尺寸先验）。只有 `v_i ≥ τ_v` 的实例进入“已验证集合” `V`；
- **OIM（Object Instance Memory）** 用匈牙利匹配维护跨帧实例 ID，使几何、接触历史、证书都挂在**同一个持久实例**上；遮挡消失后重新出现、物体在双手间传递，都不会把“杯子”的证书错挂到“盘子”上。

**直接收益**：
1. 幻觉被**局部隔离**：坏实例被拒绝，其余实例的几何仍可用；
2. WCV 球从“一个全局球”变成“每接触实例一个球”，半径由该实例的 `v_i` 决定，未验证实例使用保守大球或仅允许 probe 技能；
3. 接触力可以**归属到实例**，证书从“整机安全”细化到“物体安全”，为后续赛制分配提供原子单位。

### 灵感 2（比赛策略 → CAP + SAR：把安全证书兑换成赛制分数）

**直觉**：研究原型可以只追求“单任务成功率”，但比赛是**有限时间、有限尝试、按任务计分、违规扣分**的组合优化。一个“每项都稳但做得慢”的策略会输给“先银行简单分、再集中预算攻高价值任务”的策略；一个“为了高分强行尝试透明物体”的策略可能因一次碰撞把总分打负。比赛策略的核心不是“更激进”，而是**在风险预算内最大化分数分位数**。

**关键洞见**：把赛制显式写成一个**预算约束的竞赛 MDP**：
`C = (𝒯, S, A, P, R, B_time, B_verify, δ_contest)`，
- 状态：剩余时间/验证预算、已完成任务、每任务 PISCES 证书、可选排行榜位置 ℓ；
- 动作：`(task i, mode ∈ {attempt, verify, skip, retry}, skill_mode)`；
- 奖励：得分增量 − λ·算力/时间成本 − 违规惩罚；
- 约束：`P(任何安全违规) ≤ δ_contest`，总预算 `≤ B`。

**CAP（Contest-Aware Portfolio）** 用**证书门控的索引策略**：
- 每个任务的成功率 `p̂_i` 由 `J_pisces` 校准得到，使用时取**下置信界** `p_i^-` 保安全、上界估价值；
- 尝试索引 `I_i = (p_i^-·s_i − λ·c_i)/τ_i`，其中 `s_i` 为任务分、`c_i` 为预期成本、`τ_i` 为耗时；只尝试 `J_pisces` 有效且 `p_i^- ≥ p_min(B, ℓ)` 的任务；
- 若落后且预算充足，`p_min` 下调（提高风险预算）；若领先或预算紧张，`p_min` 上调（银行分数、拒绝高方差任务）；
- **SAR（Score-at-Risk）** 作为目标：`SAR_α(π) = max{s: P(S_π ≥ s) ≥ 1−α}`，在违规概率约束下最大化 α-分位总分，而不是只最大化期望分。

**关键连接**：比赛策略不是独立外挂。它消费的正是**实例级证书**：一个任务如果涉及的物体实例 `v_i` 低、`ρ_dir,i` 小，`p_i^-` 就低，CAP 自然会把预算让给“实例可验证”的任务；反之，CAP 可以花 `B_verify` 去做**主动验证**（多视角、重分割、触觉探针），把某个实例从“不确定”提升为“已验证”，从而解锁高价值任务。

### 灵感 3（合流 → PISCES：实例级证书作为竞赛预算的原子货币）

**直觉**：第 63 轮的证书是“整机级”的，比赛策略只能看到“这个任务大概行不行”。而比赛里真正决定风险与收益的，是**具体物体实例**：同一个“抓取放置”任务，抓透明杯子与抓不透明夹子的难度完全不同。把实例级证书作为“货币”，系统就能做**任务内的实例选择**、**任务间的组合选择**、以及**验证预算与尝试预算的联合分配**。

**合流后的闭环（PISCES）**：
`ISeg → PIV/OIM → 逐实例 LSF/USL 绑定 → 逐实例 WCV/AIC → 实例证书 J_inst → CAP/SAR 赛制决策 →（可选）VCA 主动验证 → 执行/重规划`。

- **空间轴**：全局几何 → 实例几何（解决幻觉单点）；
- **时间轴**：单任务闭环 → 多任务预算组合（解决赛制单点）；
- **价值轴**：安全裕度 → 分数分位数（把 ρ 转成 SAR 的约束与收益）；
- **信息轴**：被动验证 → VOI 驱动的主动验证（把验证预算花在最能改变赛制决策的实例上）。

### 灵感 4（LIRO 组件的原位升级）

- **LSF → PILSF（Per-Instance LSF）**：`g_i = E_geo(P_i, m_i^am)`，`x_i' = CrossAttn(x, g_i, g_i)`；全局表征由实例 token 的注意力池化得到；E_geo 冻结，新增的实例投影矩阵参与 OLP-Geo 更新。
- **WCV-Geo → WCV-Inst**：球心 `φ̂_{0,i} = GeoInit(g_i, c_i, v_i)`，半径 `r_{0,i} = r_base·γ_geo(v_i) + r_am·(1 − |m_i^obs|/|m_i^am|)`；只在已验证实例上施加几何约束 `𝒢_i(g_i)`；接触实例未验证时退回 `r_max` 或只允许 probe。
- **USL/CSP → USD/CSP-Inst**：技能参数增加**实例绑定** `β`（如 `grasp(o_3)`、`place(o_3, o_7)`）；CSP 在 `(σ, β)` 上搜索，前置/后置条件按实例属性求值；未验证实例只能绑定到“验证/探测”技能。
- **SSB → ISB（Instance Scenario Bank）**：场景签名从“整帧指纹”扩展为“实例指纹多重集 + 实例关系图”；Mine 按实例指纹召回，Mut 做实例级变异（替换物体、局部遮挡、单实例形变、接触面翻转）。
- **DIR/AIC → AIC-Inst**：干扰集按实例分解，额外加入**分割扰动**（掩码膨胀/腐蚀、实例合并/拆分、遮挡）；`ρ_dir,i` 与 `J_inst,i` 逐实例给出；只有被接触的已验证实例才进入最终安全约束。
- **OCB-Skill → CAB（Contest-Aware Bandit）**：臂空间扩为 `{任务簇} × {技能模式} × {验证级别}`；奖励改为“得分增量 − 成本 − 违规惩罚”；安全门控硬屏蔽 `J_pisces` 无效的臂。
- **J_liro → J_pisces**：新增 `{J_inst,i}`、`seg_hash`、`v_min`、`oim_ver`、`cap_plan_hash`、`sar_est`、`contest_spec`；`Valid(J_pisces)` 要求所有**被接触实例**已验证且 `ρ_dir,i ≥ 0`，否则只能以保守回退模式运行并在证书中标记 `instance_degraded=True`。

## 1. 形式化定义（增量：定义 201–216）

- **定义 201（PISCES 闭环）**：`PISCES = (LIRO, ISeg, PIV, OIM, USD, ISB, AIC-Inst, CAP, SAR, VCA, J_pisces)`。定位：LIRO 的「逐实例空间分解 × 赛制决策分解」升级；新增组件挂载在 LIRO 骨架上，实时路径只增加 O(1) 实例查表与逐实例前向。
- **定义 202（实例分割算子 ISeg）**：`ISeg(I, D, P_cloud) = {(m_i, m_i^am, c_i, u_i)}_{i=1}^{K}`，`m_i ∈ {0,1}^{H×W}` 为观测掩码，`m_i^am ⊇ m_i` 为 amodal 补全掩码，`c_i` 为类别，`u_i ∈ [0,1]` 为分割不确定度；同时输出实例与持久 ID 的关联假设。
- **定义 203（PIV 逐实例几何验证）**：对实例 `i`，`P_i = P_cloud ⊙ m_i`，`g_i = E_geo(Voxelize(P_i), m_i^am)`，`h_i = (T_i, b_i, n_i, κ_i, χ_i)`。验证分
  `v_i = (c_view,i)^{w1}·(c_edge,i)^{w2}·(c_norm,i)^{w3}·(c_phys,i)^{w4}`，
  其中四项分别为多视角深度/掩码重投影一致性、掩码边界与深度断裂对齐度、实例内法向与曲率一致性、物理合理性（无穿模/支撑/类别尺寸先验）。`V_τ = {i: v_i ≥ τ_v}` 为已验证实例集；`γ_geo,i = max(0, (v_i − τ_v)/(1 − τ_v))`。
- **定义 204（OIM 对象实例记忆）**：`M_inst = {(id_i, g_i, h_i, φ̂_i, r_i, v_i, t_i^last, H_i^contact, J_inst,i)}`。帧间匹配代价
  `C_ij = λ_IoU(1 − IoU(m_i, m_j)) + λ_geo·d_SE3(T_i, T_j) + λ_cls·1[c_i ≠ c_j] + λ_app·d_app(e_i, e_j)`，
  匈牙利求解；遮挡期间保留 ID 并用 `m^am` 维持“对象永久性”，重出现时优先复联而不是新建。
- **定义 205（实例级 GeoInit 与实例球）**：`φ̂_{0,i} = GeoInit(g_i, c_i, v_i)`，`r_{0,i} = r_base·γ_geo(v_i) + r_am·(1 − |m_i^obs|/|m_i^am|)`；实例几何约束集 `𝒢_i(g_i) = {φ: n(φ) ≈ n_i, κ(φ) ≤ κ_max(g_i), b(φ) ≈ b_i}`。未验证实例 `i∉V_τ` 置 `𝒢_i = ∅`、`r_i = r_max`，只允许 probe/澄清类技能。
- **定义 206（接触归属与实例证书）**：接触事件 `(p, w, t)` 的归属
  `a_t = argmax_i P(i | p, w) ∝ exp(−d(p, ∂m_i)/σ_p − λ_f·angle(w, n_i)/σ_f)`；
  若 `max_i P(i|p,w) < δ_a` 或距离超阈值，记为 `unattributed` 并使用保守全局球。实例安全裕度 `ρ_i = min_t margin(π, φ; φ∈B(φ̂_i, r_i))`，实例证书 `J_inst,i = (id_i, φ̂_i, r_i, v_i, ρ_i, ρ_dir,i, seg_hash_i)`。
- **定义 207（ISB 实例场景银行）**：`scene_sig = (fp_global, {(fp_cloud,i, g_i, c_i, v_i)}_{i∈V_τ}, E_graph)`，`E_graph` 为实例间支撑/接触/包含关系。Mine 按实例指纹多重集召回；Mut 增加实例级变异：替换同类别实例、单实例局部形变（FFD）、单实例遮挡/透明化、接触面法向翻转。
- **定义 208（USD 实例绑定技能）**：技能 `σ = (name, pre, eff, π_σ, cost, 𝒫_feas)` 的谓词与策略接受实例绑定 `β: Var → {id_i}`；`pre_σ(φ̂, x', β)` 与 `eff_σ(φ̂, x', β)` 在绑定实例的属性上求值。CSP 搜索 `(τ, β_bind, θ_bind)`，其中 `β_bind` 只允许绑定 `V_τ` 中的实例，或绑定到 `verify/probe` 技能。
- **定义 209（竞赛 MDP）**：`C = (𝒯, S, A, P, R, B_time, B_verify, δ_contest)`；`A = {(i, mode, m_skill): i∈𝒯, mode∈{attempt, verify, skip, retry}, m_skill∈USL模式}`；奖励 `R = Δscore − λ·cost − λ_v·violation_penalty`；约束 `P(any violation) ≤ δ_contest`，`Σ time ≤ B_time`，`Σ verify_cost ≤ B_verify`。
- **定义 210（SAR 分数风险）**：对计划 `π` 的总分随机变量 `S_π`，`SAR_α(π) = max{s: P(S_π ≥ s) ≥ 1 − α}`；赛制目标为
  `max_π SAR_α(π)  s.t.  P(violation | π) ≤ δ_contest,  cost(π) ≤ B`。
  SAR 用 `n_scen` 个情景的样本分位数估计，并用 CVaR 凸近似做优化。
- **定义 211（CAP 竞赛感知组合规划）**：给定证书集 `{J_pisces,i}`、校准成功率 `p̂_i`、预算 `B`，CAP 选择动作序列最大化 SAR。尝试索引
  `I_i = (p_i^-·s_i − λ·c_i)/τ_i`，其中 `p_i^-` 为成功率下置信界；仅当 `J_pisces,i` 有效且 `p_i^- ≥ p_min(B, ℓ)` 时尝试。`p_min` 由风险预算的 Lagrange 乘子给出：预算紧/领先时升高，落后/充裕时降低。
- **定义 212（证书驱动成功率预测）**：`p̂_i = Cal(ψ(J_pisces,i, task_embed_i))`，`Cal` 为等渗回归/Platt 校准；输出 `[p_i^-, p_i^+]` 且满足 `P(p_i ∈ [p_i^-, p_i^+]) ≥ 1 − α_p`。CAP 用 `p_i^-` 做安全门控、`p_i^+` 做价值估计。
- **定义 213（VOI 主动验证分配）**：验证动作 `v`（额外视角、重分割、触觉探针、人问）对实例 `i` 的价值
  `VOI_i(v) = E_{u_i|v}[SAR(π | v) − SAR(π)] − λ_v·cost(v)`；
  在 `B_verify` 下按 `VOI_i(v)/cost(v)` 排序做背包/拉格朗日分配，只对能改变 CAP 决策的实例花验证预算。
- **定义 214（AIC-Inst 实例级抗干扰认证）**：`ℰ_i = ℰ_sens,i × ℰ_occ,i × ℰ_adv,i × ℰ_ood,i × ℰ_seg,i`，其中 `ℰ_seg,i` 包含掩码膨胀/腐蚀、实例合并/拆分、边界抖动；`ρ_dir,i = min_{η∈ℰ_i} min_t margin(π, η)`，`J_dir,i = (ρ_dir,i, ℰ_spec,i, seg_ver_i)`。
- **定义 215（CAB 竞赛感知预算老虎机）**：臂 `(task_cluster, skill_mode, verify_level)`，奖励 `r_t = Δscore_t − λ·compute_t − skill_switch_penalty − violation_penalty`；安全门控只允许 `J_pisces` 有效的臂；EXP3 在剩余预算内更新。
- **定义 216（PISCES 扩展证书）**：`J_pisces = (J_liro, {J_inst,i}_{i∈V_τ}, seg_hash, v_min, oim_ver, cap_plan_hash, sar_est, contest_spec)`。
  `Valid(J_pisces) ⇔ Valid(J_liro) ∧ v_min ≥ τ_v ∧` 所有被接触实例 `∈ V_τ ∧ ρ_dir,i ≥ 0 ∧` CAP 计划满足预算/风险约束。
  若有被接触实例未验证，则只能进入 `instance_degraded` 保守模式：`r = r_max`、只执行 probe/安全 idle，且 `J_pisces` 不计入正常得分。

# 竞赛感知组合规划（索引策略 + SAR 约束）
def CAP_plan(tasks, certs, p_hat, B, ell):
    p_min = threshold_from_risk(B, ell, delta_contest)
    plan = []
    while B > 0:
        candidates = []
        for i in tasks:
            if not Valid(certs[i]): continue
            if p_hat[i].lower < p_min: continue
            idx = (p_hat[i].lower * score[i] - LAMBDA * cost[i]) / time[i]
            v = VOI_verify(i, certs[i]) if certs[i].v_min < TAU_STRONG else 0
            candidates.append((idx + v, i, "attempt" if v <= 0 else "verify"))
        if not candidates: break
        _, i, mode = max(candidates)
        plan.append(Action(i, mode))
        B -= time[i] if mode == "attempt" else verify_cost(i)
    return plan
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 5（实例幻觉隔离界）**：设每个实例验证的误接受概率为 `α_v,i`（即 `v_i ≥ τ_v` 但几何误差 `> δ_geo`）。则
  `P(∃ 被接受的坏实例) ≤ Σ_i α_v,i`；
  若未验证实例被排除出 WCV，则“自信几何”通道的污染概率从第 63 轮的全局 `α_global` 降为 `Σ_i α_v,i`。当 `α_v,i < α_global/K` 时严格改进——**逐实例验证把单点幻觉变成可加的有界风险**。
- **引理 6（实例球收缩）**：若当前技能只接触单个实例 `i`，则其搜索域 `B_i = B(φ̂_i, r_i) ⊆ B_global`；在 `r_i ≤ r_global` 时，WCV 最坏搜索体积比 `≤ (r_i/r_global)^{d_φ}`。若全局球原为覆盖所有实例而放大，则逐实例球带来 `1/K^{1/d_φ}` 量级的收缩（条件性命题，需实例可分离）。
- **定理 4（赛制级证书安全）**：若每个被尝试任务都有 `Valid(J_pisces)`，且每个有效证书的实例级失败概率 `≤ α_i`；未通过验证的任务一律 skip/保守回退，则整场比赛的安全违规概率
  `P(violation) ≤ Σ_{attempted} α_i + δ_cert`，其中 `δ_cert` 为 AIC 采样认证误差（Hoeffding）。**比赛策略不会把“未认证实例”偷偷送入执行**。
- **定理 5（预算索引策略的分数遗憾）**：在任务成功独立、成功率校准误差 `ε_p`、预算是主要约束的设定下，CAP 的证书门控索引策略相对全知 oracle 的期望分数遗憾满足
  `Regret_T ≤ O(√(K·B·log K)) + O(B·ε_p)`；
  证明把每个任务视为消耗预算的 bandit 臂，索引策略是预算约束下的 Whittle/Gittins 近似，校准误差通过 `p_i^-` 的门控放大为至多线性项。
- **实时性**：实时路径新增实例分割前向（10Hz 缓存，<0.3ms）、逐实例查表 O(1)、仅接触实例的 WCV-Inst（<0.5ms）；总实时预算仍 ≤ 2ms（继承 A82/A90）。

## 2. 形式化定义（完整版）

**定义 201（PISCES 闭环）** PISCES 是 LIRO 的「逐实例空间分解 × 赛制决策分解」升级：在 LIRO 的「语义流 ∘ 实时流」骨架上，挂载 ISeg/PIV/OIM（实例层）、USD/CSP-Inst（技能实例绑定）、ISB（实例场景银行）、AIC-Inst（实例认证）、CAP/SAR/VCA（赛制层），并原位升级 LSF→PILSF、WCV-Geo→WCV-Inst、SSB→ISB、OCB-Skill→CAB。不变式：
1. **只有 `V_τ` 中的实例几何可进入 WCV 的“自信约束”通道**；未验证实例必须走保守回退或 probe；
2. 所有学习/规划/验证只在语义流与低频线程；实时路径只做实例查表、PILSF 前向、WCV-Inst 编译、首技能展开；
3. 赛制决策（CAP）从不绕过 `Valid(J_pisces)` 的安全门控。

**定义 202（实例分割算子 ISeg）** `ISeg(I, D, P_cloud) = {(m_i, m_i^am, c_i, u_i)}_{i=1}^K`。实现：2D 实例分割（Mask2Former/SAM）与 3D 实例分割（PointGroup/SST）经深度反投影融合；`m_i` 为观测可见掩码，`m_i^am` 为类别条件形状先验 + 深度补全得到的 amodal 掩码；`u_i` 为掩码熵与边界不确定度的归一化组合。ISeg 同时输出候选关联 `(i, id_j, s_ij)` 供 OIM 复联。

**定义 203（PIV 逐实例几何验证）** 对每个实例：
- `P_i = P_cloud ⊙ m_i`，`g_i = E_geo(Voxelize(P_i), m_i^am)`，`h_i = GeometryHead(g_i)`；
- 四类证据：
  - `c_view,i`：把 `P_i` 重投影到相邻视角/帧，落在同类实例掩码内且深度差 `≤ τ_d` 的比例；
  - `c_edge,i`：掩码边界 `∂m_i` 与深度断裂边缘的 Chamfer 对齐度 `exp(−Chamfer/σ_e)`；
  - `c_norm,i`：实例内法向落在主法向锥内的比例 × 曲率方差稳定度；
  - `c_phys,i`：无穿模、有支撑、包围盒符合类别尺寸先验、质量估计为正；
- `v_i = (c_view,i)^{w1}(c_edge,i)^{w2}(c_norm,i)^{w3}(c_phys,i)^{w4}`（乘积形式：任一证据崩塌都会显著降低 `v_i`，避免“强证据掩盖弱证据”）；
- `V_τ = {i: v_i ≥ τ_v}`；`γ_geo,i = max(0,(v_i−τ_v)/(1−τ_v))`。未验证实例：`𝒢_i = ∅`、`r_i = r_max`、只允许 `verify/probe/safe_idle` 绑定。

**定义 204（OIM 对象实例记忆）** OIM 维护 `M_inst`。每帧对候选实例与记忆条目构造代价 `C_ij`，匈牙利求最小匹配；匹配成功则更新 `g_i,h_i,φ̂_i,r_i,v_i,t_i^last` 并追加接触历史；未匹配候选若 `u_i` 低且持续 `T_new` 帧则新建 ID；消失条目保留 `T_ttl` 帧，重出现时优先复联。amodal 掩码在遮挡期间维持实例边界与体积先验，使 `r_i` 按遮挡比例膨胀而不是直接丢弃实例。ID 稳定性是接触历史与实例证书可追溯的前提。

**定义 205（实例级 GeoInit 与实例球）** 
`φ̂_{0,i} = GeoInit(g_i,c_i,v_i)`，其中先验网络输入加入 `c_i` 与验证分 `v_i`，低 `v_i` 时输出向类别先验收缩（shrinkage）：
`φ̂_{0,i} = v_i·φ̂_i^{geo} + (1−v_i)·φ̄_{c_i}`。
`r_{0,i} = r_base·γ_geo(v_i) + r_am·(1−|m_i^obs|/|m_i^am|)`：几何越不可信、遮挡越多，球越大。实例约束集 `𝒢_i(g_i)` 只在 `V_τ` 上构造；WCV-Inst 在 `B(φ̂_{0,i},r_i) ∩ 𝒢_i(g_i)` 内搜索最坏 `φ`。

**定义 206（接触归属与实例证书）** 对接触事件 `(p,w,t)`：
`P(i|p,w) ∝ exp(−d(p,∂m_i)/σ_p − λ_f·angle(w,n_i)/σ_f)`；
`a_t = argmax_i P(i|p,w)`。若 `max_i P < δ_a` 或 `d(p,∂m_i) > d_max`，记 `unattributed`，使用保守全局球并标记 `contact_ambiguous=True`。实例安全裕度
`ρ_i = min_{φ∈B(φ̂_i,r_i)} min_t margin(π,φ)`，
实例证书 `J_inst,i = (id_i,φ̂_i,r_i,v_i,ρ_i,ρ_dir,i,seg_hash_i)`。只有被接触实例的 `J_inst,i` 进入 `J_pisces` 的硬约束。

**定义 207（ISB 实例场景银行）** 
`scene_sig = (fp_global,{(fp_cloud,i,g_i,c_i,v_i)}_{i∈V_τ},E_graph)`，
`fp_cloud,i = SimHash(voxel_normal_hist(P_i,32³))`，`E_graph` 记录实例间支撑/接触/包含关系。
- `Mine(EV_exec,anchor)`：先按 `fp_global` 粗召回，再按实例指纹多重集的 Earth Mover/汉明距离精排；若存在险情且无匹配，则创建新场景并存储实例级签名。
- `Mut(s)`：继承 SSB 的材质/刚度/湿滑/动态障碍变异，新增实例级变异：① 替换同类别实例；② 单实例 FFD 局部形变（控制点 ±5%）；③ 单实例遮挡/透明化；④ 单实例接触面法向翻转。
簇数封顶 64，Hedge 权重 < 0.01 定期合并/淘汰。

**定义 208（USD 实例绑定技能）** 技能 `σ = (name,pre,eff,π_σ,cost,𝒫_feas)` 的谓词与策略接受实例绑定 `β: Var → {id_i}`。例如：
- `grasp(o)` 的 `pre` 在 `o` 的绑定实例上求值：`‖n_o·f‖ ≤ μ_o‖f_t‖ ∧ κ_o ≤ κ_max ∧ approach_dir ∈ 𝒞_approach(o)`；
- `place(o,r)` 的 `eff` 断言 `on(o,r) ∧ stable(o)`，`r` 为支撑实例或区域绑定。
CSP 搜索 `(τ, β_bind, θ_bind)`：高层技能图搜索需同时满足 `eff_σi(β) ⊨ pre_σ{i+1}(β)`；低层对 `θ_bind` 做 L-BFGS。若某变量只能绑定未验证实例，CSP 必须插入 `verify(instance)` 技能或回退 `safe_idle`，不得直接展开阻抗轨迹。

**定义 209（竞赛 MDP）** 
`C = (𝒯,S,A,P,R,B_time,B_verify,δ_contest)`。
- `𝒯`：任务集，每任务 `i` 有分数 `s_i`、预计耗时 `τ_i`、最大重试 `R_i`；
- `S`：`(B_time^rem, B_verify^rem, done⊆𝒯, {J_pisces,i}, ℓ)`，`ℓ` 为可选排行榜位置；
- `A = {(i,mode,m_skill)}`，`mode∈{attempt,verify,skip,retry}`；
- `R = Δscore − λ·cost − λ_v·violation_penalty`；
- 约束 `P(any violation) ≤ δ_contest`、`Σ time ≤ B_time`、`Σ verify_cost ≤ B_verify`。
赛制模型允许“分数非负/可部分得分/违规扣分/尝试次数上限”等变体，通过 `R` 与约束参数化。

**定义 210（SAR 分数风险）** 对计划 `π`，总分 `S_π = Σ_i s_i X_i − penalties`，`X_i∈{0,1}` 为任务成功指示。`SAR_α(π) = max{s: P(S_π≥s) ≥ 1−α}`。赛制目标：
`max_π SAR_α(π) s.t. P(violation|π)≤δ_contest, cost(π)≤B`。
实现：用 `n_scen` 个情景（由证书成功区间与任务相关性采样）估计样本分位数；优化时用 CVaR 凸近似 `CVaR_α(S_π)` 做梯度/贪心，最终用样本分位数校验。若任务间相关性强，则用 copula 或 block bootstrap 保留相关结构。

**定义 211（CAP 竞赛感知组合规划）** 给定证书集、校准成功率 `p̂_i`、预算与排行榜，CAP 选择动作序列最大化 SAR。尝试索引
`I_i = (p_i^-·s_i − λ·c_i)/τ_i`，
其中 `p_i^-` 为 `p̂_i` 的下置信界。门控：
- `Valid(J_pisces,i)` 为假 → 只能 `verify` 或 `skip`；
- `p_i^- < p_min(B,ℓ)` → 延迟/跳过；
- `p_min` 由风险预算的 Lagrange 乘子 `ν` 给出：`p_min = (λ_v·penalty + ν·time + λ·c)/(s_i + λ_v·penalty)`，预算越紧或 `ν` 越大，`p_min` 越高；落后时可通过提高 `δ_contest` 的有效风险预算降低 `p_min`。
每次尝试后重规划（receding horizon），用 OIM 与 `J_inst` 更新成功率。

**定义 212（证书驱动成功率预测）** 
`p̂_i = Cal(ψ(J_pisces,i, task_embed_i))`，
`ψ` 输入实例级特征（`v_min`、`ρ_dir,min`、`r_i`、`J_liro`、任务难度嵌入、历史同类任务结果），`Cal` 为等渗回归/Platt；输出区间 `[p_i^-,p_i^+]`，满足 `P(p_i∈[p_i^-,p_i^+]) ≥ 1−α_p`。CAP 用 `p_i^-` 做安全门控，用 `p_i^+` 做价值上界；校准集按任务簇分层，避免跨任务负迁移。

**定义 213（VOI 主动验证分配）** 验证动作 `v`（额外视角、重分割、触觉探针、人问）对实例 `i` 的价值
`VOI_i(v) = E_{u_i|v}[SAR(π|v) − SAR(π)] − λ_v·cost(v)`。
在 `B_verify` 下按 `VOI_i(v)/cost(v)` 做背包/拉格朗日分配；只对“可能改变 CAP 决策”的实例花预算。若 `v_i` 已高于强验证阈值 `τ_strong`，VOI 记为 0；若 `v_i` 低但任务价值低，也不验证。VOI 用历史验证结果训练的小模型估计，并用保守下界做门控。

**定义 214（AIC-Inst 实例级抗干扰认证）** 
`ℰ_i = ℰ_sens,i × ℰ_occ,i × ℰ_adv,i × ℰ_ood,i × ℰ_seg,i`；
`ℰ_seg,i` 包含掩码膨胀/腐蚀（±3px）、实例合并/拆分（与最近实例交换边界）、边界抖动、以及“把 `i` 与邻居合并”的对抗掩码。`ρ_dir,i = min_{η∈ℰ_i} min_t margin(π,η)`，采样 `n_cert,i` 组（低 `v_i` 实例自动增采）。`J_dir,i = (ρ_dir,i,ℰ_spec,i,seg_ver_i)`。只有 `V_τ` 中被接触实例的 `ρ_dir,i` 进入最终安全约束；未验证实例不产生“负 ρ”混淆，而是直接不认证。

**定义 215（CAB 竞赛感知预算老虎机）** 臂 `a = (task_cluster, skill_mode, verify_level)`，`skill_mode∈{full_seq,single_skill,cached_seq,frozen}`，`verify_level∈{none,light,full}`。奖励
`r_t = Δscore_t − λ·compute_t − skill_switch_penalty·1[σ_t≠σ_{t−1}] − violation_penalty`。
安全门控：只允许 `J_pisces` 有效的臂；预算不足时按硬规则降级。EXP3 重要性加权更新，`w_a ← w_a·exp(η·r̂_t)`，归一化；与 CAP 的索引策略正交：CAP 决定“做哪个任务”，CAB 决定“用哪种技能/验证档位”。

**定义 216（PISCES 扩展证书）** 
`J_pisces = (J_liro, {J_inst,i}_{i∈V_τ}, seg_hash, v_min, oim_ver, cap_plan_hash, sar_est, contest_spec)`。
`Valid(J_pisces) ⇔ Valid(J_liro) ∧ v_min ≥ τ_v ∧` 所有被接触实例 `∈V_τ ∧ ρ_dir,i ≥ 0 ∧` CAP 计划满足预算/风险约束 ∧ `oim_ver` 与当前记忆一致。
若存在被接触实例未验证或 `contact_ambiguous`，则进入 `instance_degraded=True` 保守模式：`r=r_max`、只执行 probe/safe_idle、`J_pisces` 不计正常得分；审计链 `seg_hash→oim_ver→J_inst→cap_plan_hash` 可追溯每个分数的来源。

class PerInstanceVerifier:
    """实例分割 + 四证据验证。验证分 v_i 为乘积，任一证据崩塌即拒绝。"""
    def __init__(self, tau_v=0.7, weights=(0.3, 0.25, 0.25, 0.2)):
        self.tau_v, self.w = tau_v, weights

    def segment(self, I, D, P_cloud):
        seg2d = mask2former(I)                      # 2D 实例
        seg3d = pointgroup(P_cloud)                 # 3D 实例
        instances = fuse_by_depth(seg2d, seg3d, D)  # m_i, m_i^am, c_i, u_i
        return instances

    def verify(self, inst, P_cloud, I, D, depth_edges, view_bank):
        P_i = P_cloud * inst.mask
        inst.g = self.E_geo(voxelize(P_i), inst.amodal_mask)
        inst.h = self.geometry_head(inst.g)
        c_view = self.reprojection_consistency(P_i, inst, view_bank, tau_d=0.01)
        c_edge = np.exp(-chamfer(boundary(inst.mask), depth_edges) / 0.02)
        c_norm = self.normal_coherence(P_i, inst.h.n) * self.curvature_stability(P_i)
        c_phys = self.physical_plausibility(inst.h, inst.c)
        inst.v = (c_view ** self.w[0]) * (c_edge ** self.w[1]) * \
                 (c_norm ** self.w[2]) * (c_phys ** self.w[3])
        inst.verified = inst.v >= self.tau_v
        inst.gamma = max(0.0, (inst.v - self.tau_v) / (1 - self.tau_v))
        return inst


class ObjectInstanceMemory:
    """持久 ID：匈牙利匹配 + amodal 维持 + 复联。"""
    def __init__(self, T_ttl=30, T_new=3):
        self.entries, self.T_ttl, self.T_new = {}, T_ttl, T_new
        self.pending = {}

    def update(self, instances):
        if not self.entries:
            for inst in instances: self._create(inst)
            return self.entries
        cost = np.array([[self._match_cost(e, inst) for inst in instances]
                         for e in self.entries.values()])
        rows, cols = linear_sum_assignment(cost)
        matched = set()
        for r, c in zip(rows, cols):
            e = list(self.entries.values())[r]
            self._update_entry(e, instances[c]); matched.add(c)
        for c, inst in enumerate(instances):
            if c in matched: continue
            self.pending[inst.key] = self.pending.get(inst.key, 0) + 1
            if self.pending[inst.key] >= self.T_new: self._create(inst)
        self._expire()
        return self.entries

    def _match_cost(self, e, inst):
        return 2.0 * (1 - iou(e.mask, inst.mask)) + \
               1.0 * se3_distance(e.h.T, inst.h.T) + \
               0.5 * (e.c != inst.c) + 0.5 * app_distance(e.emb, inst.emb)
```

def wcv_inst_compile(olp, x_i_prime, eeis, inst, phi_hat=None, r=None,

    r = inst.r if r is None else r
    G_set = inst.geo_constraint_set                      # 𝒢_i(g_i)

class InstanceCSP:
    def __init__(self, usl, max_horizon=5):
        self.usl, self.H = usl, max_horizon

    def plan(self, goal, x_prime, M_inst, V_tau, budget=100.0):
        # 状态: (技能, beta_bind, theta_bind, 序列, 代价)
        open_set = [([], {}, [], 0.0)]
        while open_set:
            seq, beta, thetas, cost = heapq.heappop(open_set)
            if seq and self.usl[seq[-1]].eff.eval(beta, M_inst) >= goal:
                thetas = self._opt_params(seq, beta, x_prime, M_inst, V_tau)
                return seq, beta, thetas
            if len(seq) >= self.H: continue
            for name, skill in self.usl.items():
                for b2 in self._bindings(skill, M_inst, V_tau):
                    if seq and not compatible(self.usl[seq[-1]].eff, skill.pre, beta, b2):
                        continue
                    if cost + skill.cost > budget: continue
                    heapq.heappush(open_set, (seq + [name], {**beta, **b2},
                                              thetas + [skill.default_theta],
                                              cost + skill.cost))
        return ["safe_idle"], {}, [None]

    def _bindings(self, skill, M_inst, V_tau):
        # 只允许已验证实例；未验证只能绑定 verify/probe
        if skill.name in ("verify", "probe"):
            return [{"o": i} for i in M_inst if i not in V_tau]
        return [{"o": i} for i in V_tau if skill.pre.compatible_class(M_inst[i])]

### IP-211/212 CAP + SAR + VCA

```python
class ContestAwarePortfolio:
    def __init__(self, alpha=0.1, delta_contest=0.01, lam=0.1):
        self.alpha, self.delta, self.lam = alpha, delta_contest, lam
        self.n_scen = 512

    def plan(self, tasks, certs, p_hat, B_time, B_verify, leaderboard=None):
        p_min = self._risk_threshold(B_time, leaderboard)
        plan = []
        while B_time > 0:
            cands = []
            for i, task in tasks.items():
                if not Valid(certs[i]): continue
                if p_hat[i].lower < p_min: continue
                idx = (p_hat[i].lower * task.score - self.lam * task.cost) / task.time
                voi = self._voi(i, certs[i], tasks, certs, p_hat) if B_verify > 0 else 0
                cands.append((idx + voi, i, "verify" if voi > idx else "attempt"))
            if not cands: break
            _, i, mode = max(cands)
            plan.append(Action(i, mode))
            if mode == "attempt": B_time -= tasks[i].time
            else: B_verify -= verify_cost(tasks[i])
        return plan

    def sar(self, plan, p_hat):
        scores = []
        for _ in range(self.n_scen):
            S = 0.0
            for a in plan:
                if a.mode == "attempt":
                    S += a.task.score * np.random.binomial(1, p_hat[a.task.id].mean)
            scores.append(S)
        return np.quantile(scores, self.alpha)

    def _risk_threshold(self, B_time, ell):
        # 预算紧/领先 → 提高门槛；落后且充裕 → 降门槛
        base = 0.55
        if ell is not None and ell > 0: base += 0.05
        if B_time < 0.3 * B_TIME_TOTAL: base += 0.1
        return min(0.95, base)

    def _voi(self, i, cert, tasks, certs, p_hat):
        if cert.v_min >= TAU_STRONG: return 0.0
        # 估计验证后成功率提升带来的 SAR 增益，减去验证成本
        delta_p = estimated_verification_gain(cert, tasks[i])
        return max(0.0, delta_p * tasks[i].score / tasks[i].time - VERIFY_LAMBDA)
```

## 4. 推导

**引理 5（实例幻觉隔离界）** 设实例 `i` 的验证误接受事件 `E_i = {v_i ≥ τ_v 且 ‖h_i − h_i^*‖ > δ_geo}`，概率 `P(E_i) ≤ α_v,i`（由验证器在标定集上的经验误接受率给出）。则
`P(∃i∈V_τ: E_i) = P(∪_i E_i) ≤ Σ_i P(E_i) ≤ Σ_i α_v,i`。
第 63 轮的全局几何只产生一个接受/拒绝决策，其幻觉概率为 `α_global`；逐实例把风险**可加分解**。若 `K` 个实例中每个 `α_v,i ≤ α_global/K`，则整体污染概率不超过 `α_global`；实际中坏实例通常是少数，且未验证实例被排除出 WCV，故“自信几何”通道的污染概率显著低于全局方案。注意：该界不要求实例间独立（用 union bound），但要求验证器的误接受率可标定。∎

**引理 6（实例球收缩）** 设技能只接触单实例 `i`，其参数球 `B_i = B(φ̂_i, r_i)`，全局方案为覆盖所有实例而使用 `B_global = B(φ̂_g, r_g)`。若 `φ̂_i` 由实例几何初始化且 `r_i/r_g = γ`，则 WCV 最坏搜索体积比
`vol(B_i)/vol(B_global) = γ^{d_φ}`。
当 `γ < 1` 时搜索域收缩、候选数下降。若全局球半径按 `K` 个实例的并集放大到 `r_g ≈ K^{1/d_φ}·r_i`，则逐实例球带来 `1/K` 量级的体积收缩（条件：实例参数可分离、接触一次只涉及一个实例）。∎

**定理 4（赛制级证书安全）** 设 CAP 的每个 `attempt` 动作满足 `Valid(J_pisces)`；每个有效证书的实例级失败概率 `≤ α_i`（由引理 5 + AIC 采样认证给出）；所有未通过验证或 `contact_ambiguous` 的任务被 `skip` 或进入保守模式。则整场比赛发生安全违规的概率
`P(violation) ≤ Σ_{i∈attempted} α_i + δ_cert`，
其中 `δ_cert` 为 AIC 采样误差（Hoeffding：`P(|ρ̂−ρ|>ε) ≤ 2exp(−2n_certε²/Δ²)`）。证明：违规只能来自被尝试且证书有效的任务（未尝试任务不产生执行风险），对每个这样的任务用实例级 union bound，再对所有尝试任务做 union bound；`δ_cert` 由认证采样与真实干扰集的覆盖误差给出。∎

**定理 5（预算索引策略的分数遗憾）** 将每个任务视为消耗预算 `τ_i` 的 bandit 臂，成功收益 `s_i`、成功率 `p_i`，CAP 的索引 `I_i = (p_i^- s_i − λc_i)/τ_i` 是预算约束下 Whittle 索引的近似。设成功率校准误差 `|p_i^- − p_i| ≤ ε_p`，任务成功独立，则相对全知 oracle 的期望分数遗憾
`Regret_T ≤ O(√(K·B·log K)) + O(B·ε_p)`。
第一项来自预算 bandit 的索引学习（标准 EXP3/UCB 分析），第二项来自 `p_i^-` 门控与索引计算中的校准误差线性放大。SAR 目标通过 CVaR 凸近似求解，样本分位数误差由 `n_scen` 的 DKW 不等式控制：`P(sup|F̂−F|>ε) ≤ 2exp(−2n_scenε²)`。∎

**命题（实例指纹检索）** `fp_cloud,i` 对同一实例不同视角的汉明距离均值 < 4，不同类别实例 > 20；ISB 采用“实例多重集 + 关系图”召回，相比第 63 轮整帧指纹，在遮挡/堆叠场景下的新场景识别 F1 提升，因为只需匹配部分实例而非整帧。∎

**命题（验证预算的边际收益）** 若 `SAR(π|v)` 对实例验证分 `v_i` 单调不减且在 `v_i < τ_v` 区间严格增，则 `VOI_i(v)` 在“该实例是 CAP 候选任务的关键物体”时最大；按 `VOI/cost` 贪心分配验证预算，在子模性假设下达到 `1−1/e` 近似。∎

- **(A86)** USD 覆盖任务相关技能与实例绑定（扩展 A78）；未验证实例只能绑定 verify/probe。
- **(A87)** 竞赛模型 `(𝒯,s_i,τ_i,B,δ_contest)` 已知或可从赛制文档解析；成功率校准误差 `≤ ε_p`。
- **(A88)** SAR 的情景采样保留任务相关性结构，`n_scen` 足够大使得分位数估计误差 `≤ ε_sar`。
- **(A89)** VOI 估计的误差有界，验证动作对 `v_i` 的提升单调（否则 CAP 不使用该验证动作）。
- **(A90)** 实时路径新增实例查表 O(1)、PILSF/WCV-Inst 前向总延迟 ≤2ms，且无学习写操作。

则：
1. **幻觉局部隔离**：`P(∃ 被接受的坏实例) ≤ Σ_i α_v,i`，未验证实例不进入自信几何通道（引理 5）。
2. **实例球收缩**：单实例接触时 WCV 搜索体积 `≤ (r_i/r_g)^{d_φ}`（引理 6）。
3. **赛制级安全**：`P(violation) ≤ Σ_{attempted} α_i + δ_cert`（定理 4）。
4. **分数遗憾**：`Regret_T ≤ O(√(K·B·log K)) + O(B·ε_p)`（定理 5）。
5. **预算感知验证**：VOI 分配在子模假设下 `1−1/e` 近似（命题）。
6. **可追溯性**：`J_pisces` 的 `seg_hash→oim_ver→J_inst→cap_plan_hash` 链可追溯每个分数的实例来源与赛制决策依据。
7. **优雅降级**：实例分割失败 → `instance_degraded=True`，退回第 63 轮 LIRO 的全局几何/保守球；LiDAR/分割完全失效 → 仅 probe/safe_idle，绝不带病执行。

## 7. 已知风险

**一句话**：若实例分割在透明、镜面、强遮挡或密集堆叠场景下发生**系统性实例合并/拆分**，PIV 会把同一错误几何复制到多个“已验证”实例上，OIM 又把错误 ID 永久固化，CAP 再依据失真的实例级证书把预算集中投向看似安全的任务——第 63 轮的“几何幻觉”被升级为“实例级确定性幻觉 + 竞赛级预算错配”，这是本轮所有逐实例论证与赛制分配共同依赖的单点假设。

**次级风险与缓解**：
1. **分割器的域偏移**：真实透明/反光物体分割差 → 引入深度/触觉辅助分割与“不可验证”显式标签；PIV 拒真优先于误接受。
2. **OIM ID 漂移**：长时间遮挡后复联错误 → 保留 appearance/几何双通道 + 人工确认阈值；证书随 ID 迁移需重新认证。
3. **实例级证书爆炸**：K 大时 AIC 采样成本线性增长 → 只认证被 CAP 选中/被接触实例；低 `v_i` 实例先验证再认证。
4. **CAP 过拟合排行榜**：按排行榜调 `p_min` 可能鼓励冒险 → 风险预算上限硬约束 + SAR 分位数校验；排行榜仅作弱先验。
5. **成功率校准漂移**：任务分布变化导致 `p_i^-` 失真 → 在线等渗校准 + 分层回放；校准误差超过 `ε_p` 时退回保守 `p_min`。
6. **VOI 估计偏差**：验证收益模型不准 → 用保守下界 + 小规模 A/B 校准；VOI 为负则不验证。
7. **实时路径退化**：实例查表/PILSF 缓存失效 → 回退全局 LSF 与第 63 轮 WCV-Geo；证书标记 `instance_degraded=True`。
8. **赛制规则变化**：分数/违规/重试规则与假设不符 → 将 `contest_spec` 作为证书字段；规则变化触发 CAP 重规划，不沿用旧 SAR 估计。
