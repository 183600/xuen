# 第 69 轮（承接第 68 轮「CALM-RAS 自标定风险自适应闭环」IP-243~252；本轮灵感：「视觉感知」×「人机交互」）

> 第 68 轮把「标定」升格为在线潜变量，用零标签残差持续更新 c_t，解决了「漂移 vs 故障」的**时间尺度**分离问题；但它自陈的最大风险暴露了一个更深的结构性缺口：**速率限制只区分快慢，不区分可辨识与不可辨识**。若缓变故障在每一个观测时刻都落在标定雅可比的列空间里，那么无论采样多少、滤波多稳，故障与标定在信息论上都是同一个分布——R68 的 COF 会把故障「标好」，且越标越自信。
>
> 本轮的两个灵感正好补上「可辨识性」这一层：**视觉感知**提供独立于本体感受的外部几何参照系（运动视差、事件流同步、接触几何、标定板锚点），使原本落在标定零空间里的方向被主动激发成可观测方向；**人机交互**提供语义级见证与物理级参照（放置标定板、点击、示教、异常判断），同时把「人」建模为有可靠性、有信任偏差、会被社会工程操纵的**噪声见证者**，而不是免费的 ground truth。
>
> 核心命题：
>
> **把「标定」升级为「主动计量」——先问「这个量可观测吗」，再问「它漂了多少」；不可观测时，唯一正确的动作不是换先验，而是改变实验（安全探测）或询问独立见证者（混合主动交互）。AVIM-RAS（Active Visual-Interactive Metrology for Risk-Adaptive Safety）。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**我凭什么知道它准——这个判断本身可观测吗**」。可观测性不足时，标定、归因、前瞻、放行全部自动收缩。

## 0. 直觉与动机

**灵感 1（视觉感知 → 视觉不是第二个传感器，而是外部参照系）**
直觉：R68 的标定全部依赖「本体感受 + 力 + 自身预测」的闭环，这是一个**自证系统**：所有模态都可以一起漂，残差仍然很小。视觉的独特价值不是多一个通道，而是它观测的是**机器人之外的同一物理世界**：相机运动产生视差，视差给出米制尺度；事件相机观测运动边缘，边缘流与 IMU 的相位差给出时间同步误差；视觉估计接触点与法向，与力方向对照可分离力零偏和真实接触；已知标定板给出绝对外参锚点。人眼正是靠主动注视、运动视差与双眼视差把「不可辨识」变成「可辨识」的——机器人应显式复制这一机制。
**关键约束**：视觉也会失效（光照、纹理、遮挡、标定板被移动），所以视觉不能当 ground truth，只能当**有独立失效模式的见证者**。

**灵感 2（视觉感知的盲区 → 单一见证必然共因失效）**
直觉：若把视觉当成真值去标定力传感器，那么一次灯光变化、一次镜头污渍、一次纹理缺失就会被误标成力漂移；反之，力传感器缓慢老化也可能让视觉「看起来」在漂。任何**单一**见证者都无法区分「世界变了 / 我歪了 / 另一个见证者坏了」。人机交互中的「三人成虎」在计量学里同样成立：只有**成对独立**的见证者出现分歧，才能定位故障；只有一个见证者时，分歧本身不可解释。

**灵感 3（人机交互 → 人是语义见证者、实验者与安全否决者，不是免费标签）**
直觉：人能做机器人做不到的三件事：(i) 提供**稀疏但绝对**的物理参照——放一块已知尺寸的标定板、在屏幕上点一下接触点、手把手示教一段已知轨迹；(ii) 提供**语义判断**——「这次运动是正常的 / 它刚才明显不对」；(iii) 提供**安全否决与知情同意**。但人也有三种系统性偏差：过度信任（automation complacency）、信任不足（频繁干预）、查询疲劳（query fatigue）；人还可能被社会工程欺骗，或出于善意给出错误标签。因此人必须被建模为带可靠性 q_h、偏差 b_h、信任状态 T_h 的**噪声 oracle**，且其可靠性只能由独立物理见证者交叉验证，绝不能用系统自己的输出来证明人是对的。

**灵感 4（主动计量 → 不可辨识时，改变实验而不是换先验）**
直觉：R68 在不可辨识方向上继续做贝叶斯更新，只会把先验变成更精致的后验幻觉。正确的做法是**主动实验设计**：选择一段安全、可读、代价可接受的探测动作，使联合 Fisher 信息在这些方向上严格增加。视觉提供探测基元（横向微动制造视差、已知轨迹激发事件流、视觉引导的接触探测、标定板重观测），人提供实验协助（放置参照物、确认意图）。**但探测本身有零空间**：任何有限的安全探测基都无法覆盖其正交补；落在探测零空间里的故障仍然不可见——这是本轮必须诚实承认并显式证书化的边界。

**灵感 5（合流 → AVIM-RAS 七组件）**
把「可观测性监控 + 主动视觉探测 + 混合主动询问 + 见证溯源 + 三角化共识 + 信任校准 + 安全诊断协议」装进 R68 的闭环：
1. **AOM Observability Monitor**：在线联合 Fisher 信息 / 歧义子空间监控，输出 α_t（故障估计落在不可观测子空间的比例），直接给 R68 的「标定吸收」拍 X 光；
2. **AVP Active Visual Prober**：在安全动作集内最大化 D-最优信息增益，用视差/事件流/接触几何/标定板四类视觉探测基元激发不可观测方向；
3. **MIP Mixed-Initiative Prober**：基于价值信息（VoI）选择是否询问人类、问什么、何时问；查询受安全门、预算与知情同意约束；
4. **WPG Witness Provenance Graph**：记录「谁为谁的标定作证」的有向无环图，强制见证者成对独立，禁止自证；
5. **MCT Metrological Consensus Triangulation**：三见证者鲁棒共识，一票异常则定位故障，无共识则判「不可观测」并保守回退；
6. **TCN Trust-Calibrated Negotiation**：观测人的干预/依赖行为，用可读探测与透明度把人的依赖度拉回真实可靠度附近的校准带；
7. **SDP Safe Diagnostic Protocol**：安全 ≻ 信息 的字典序约束、探测预算、随时中止与人类否决；
8. **AVIM† 继承核**：CALM-RAS 的 MTM/SSG/COF/CFA/CAC 全部保留，只是 COF 只在可辨识子空间更新，CFA 在歧义时退化为最坏情况。

**灵感 6（对 R68 风险的对症下药）**
- R68「缓变故障被标定吸收」→ AOM 显式计算吸收比例 ρ_abs，若故障方向落在歧义子空间则拒绝标定更新，改用 AVP 激发或 MIP 询问；
- R68「canary 被标定头修好」→ WPG 的「禁止自证」不变式：canary 的裁决必须由独立于标定头的见证者给出；
- R68「模型动物园/单模型漂移」→ 继承 MTM 同源共模；新增视觉见证作为**跨源**（不同失效模式）见证，而非同源；
- 两轮共同的「不确定却放宽」→ 新增 **λ_floor(A,U) = max(0.6, 0.8·1[U>τ_cal ∨ α_t>τ_obs ∨ 共识为空])**：任何不可观测性都只导向收紧。

## 1. 形式化定义（增量：定义 293–307）

**定义 293（AVIM-RAS 总览与五不变式）** AVIM-RAS = (AOM, AVP, MIP, WPG, MCT, TCN, SDP, AVIM†)，其中 AVIM† 继承 CALM-RAS 的 (MTM, SSG, COF, CFA, CAC, RAS-WM†)。不变式：
(i) 继承 R68 的实时流零学习写操作、标定安全红线、标定速率受限；
(ii) **先可观测后标定**：COF 只允许在 F_t 的可辨识子空间内更新，不可辨识方向上的更新一律冻结，禁止用先验「补」；
(iii) **探测安全支配**：探测动作按字典序 (Safety, Information) 选择，绝不把安全与信息加权求和；
(iv) **见证独立 / 禁止自证**：任一标定声明必须至少由一个与「被标定对象」相互独立的见证者背书，溯源图无环、无自环；
(v) **交互诚实**：询问人类必须披露目的、当前不确定性与可能的后果，人可随时否决探测并撤回同意。

**定义 294（联合测量模型与故障-标定歧义）** 把 R68 的标定状态 c_t ∈ ℝ¹² 与新增慢故障状态 f_t ∈ ℝ⁸ 联合为 θ_t = (c_t, f_t) ∈ ℝ²⁰。线性化观测模型：
r_t = J_c(x_t)·δc_t + B_f(x_t)·δf_t + ε_t，ε_t ~ 𝒩(0, Σ_r)，
其中 J_c ∈ ℝ^{m×12} 是标定雅可比，B_f ∈ ℝ^{m×8} 是故障签名矩阵（力增益/方向相关柔顺/结构松动/慢泄漏/外参蠕变/焦距漂移/同步漂移/曝光漂移中**不能由 c 参数化解释**的残余方向）。令 Φ_t = [J_c(x_t), B_f(x_t)]，W = Σ_r^{-1}，联合 Fisher 信息 F_t = Σ_{τ≤t} Φ_τ^T W Φ_τ。
**歧义子空间**：A_t = ker(F_t)（数值上用最小特征子空间近似）。**吸收算子**：
Π_c = J_c (J_c^T W J_c)^+ J_c^T W，**吸收指数** ρ_abs(f) = ‖Π_c B_f f‖ / ‖B_f f‖。
ρ_abs = 1 表示该故障在观测上完全等价于一次标定；R68 的速率限制只处理「快慢」，ρ_abs 处理「方向」——二者正交，缺一不可。

**定义 295（可观测性证书）** O_t = (λ_min(F_t), basis(A_t), α_t, B_probe)：
- λ_min(F_t)：最弱可观测方向的 Fisher 信息（可观测裕度）；
- α_t = ‖P_{A_t}(B_f f̂_t)‖ / ‖B_f f̂_t‖ ∈ [0,1]：当前故障估计中落在不可观测子空间的比例（**歧义指数**）；
- B_probe = ∩_{π∈Π_safe} ker(Φ_π)：所有安全探测都激发不到的**探测盲子空间**。
O_t 判定：λ_min ≥ λ_0 ∧ α_t ≤ τ_obs ⇒ 可标定；α_t > τ_obs 但故障在 B_probe 之外 ⇒ 需探测；故障在 B_probe 内 ⇒ **显式判不可观测**（而不是假装收敛）。

**定义 296（主动探测的实验设计）** 探测是一段带能量的动作序列 π ∈ Π_safe，产生附加回归块 Φ_π。信息增益
Δ(π) = ½ log det(I + (F_t^+)^{1/2} F_π (F_t^+)^{1/2})，F_π = Φ_π^T W_π Φ_π
（F_t 奇异时在 range(F_t) ⊕ null(F_t) 的正交基下按伪行列式计算，只奖励对不可观测方向的激发）。选择
π* = argmax_{π∈Π_safe} Δ(π)  s.t.  Risk(π) ≤ R_max,  E(π) ≤ E_max,  consent = true.
若 Δ(π*) < Δ_min，说明安全探测对当前歧义方向无信息 ⇒ 转 MIP 询问人类或保守回退；绝不为了信息突破 Risk ≤ R_max。

**定义 297（视觉探测基元）** 𝒫_vis = {π_par, π_evt, π_ctc, π_fid}：
- π_par（视差探测）：相机/末端横向微动基线 b_π，产生多视极线残差 e_π，灵敏度 J_π^par = ∂e_π/∂(δp_ext, δR_ext, δf)，信息量 ∝ b_π²·纹理梯度；
- π_evt（事件流探测）：已知轨迹下事件相机边缘流与 IMU/本体感受的相位差，灵敏度 J_π^evt = ∂(phase lag)/∂(Δt_sync, δ_exposure)；
- π_ctc（接触几何探测）：视觉估计接触点 p̂ 与法向 n̂，与力方向 f̂ 对照，灵敏度 J_π^ctc = ∂(f̂ − R̂ n̂)/∂(b_F, δR_ext)；在多接触点变化下可分离「常值零偏」与「方向相关故障」；
- π_fid（锚点探测）：已知尺寸标定板/ArUco 的位姿测量，给外参与焦距提供绝对锚点。
每个基元返回 z_π = h_π(c) + ε_π，向 F_t 注入 J_π^T W_π J_π；四者失效模式不同，构成**视觉见证**的探测覆盖。

**定义 298（见证者与溯源图）** 见证者集合 W = {w_p（本体/力）, w_v（视觉）, w_h（人类）}。溯源图 G_w 是节点为见证者、边为「w_i 为 w_j 提供参照/校验」的有向无环图。每条边带独立度 κ_ij ∈ [0,1]，由共因测试估计（是否共享电源/光照/时基/场景纹理；故障是否同步出现）。见证集合有效 ⇔ 无环 ∧ 无自环 ∧ 两两 κ_ij ≥ κ_min。
**操作主义定义（标定 vs 故障）**：给定有效见证集 W，观测到的变化判为 H_cal 当且仅当存在单一 δc 使**所有**见证者的标定后残差都在噪声内；否则判为 H_sensor^trans 或「不可判定」。若见证不足或高度相关，则两者在操作上不可区分，必须探测或询问，禁止二选一硬判。

**定义 299（计量共识三角化）** 各见证者给出 ĉ_w 与协方差 Σ_w。鲁棒共识
ĉ = argmin_c Σ_w ρ_H((c − ĉ_w)^T Σ_w^{-1}(c − ĉ_w))，ρ_H 为 Huber。
残差 d_w = ‖ĉ_w − ĉ‖_{Σ_w}。裁决：
- max_w d_w ≤ τ_wit：全一致 ⇒ H_cal；
- 恰有一个 d_w > τ_wit：该见证者为离群 ⇒ 用其余见证者标定，并把离群者标为疑似故障；
- ≥2 个超阈或不存在一致对：**无共识** ⇒ 不可判定，λ 收紧、k 收缩，并触发 MIP。
理论上，至少需要 3 个两两独立见证者才能**定位**单个故障；2 个只能发现「不一致」而无法指出谁错。

**定义 300（人类见证者模型）** 对查询 q，人类响应 y ~ p(y | s, q, T_h)，其中真状态 s，信任状态 T_h ∈ [0,1]。记可靠性 q_h = P(y = s | q)，偏差 b_h = E[y − s | q]。人类可提供的证据分三类：
(i) 语义标签（「这次运动正常吗」「它是否接触到了」）；
(ii) 物理参照（放置标定板、点击图像中的接触点、手把手示教一段已知轨迹）；
(iii) 安全否决/同意（是否允许执行探测）。
**关键约束**：q_h 只能由与人类判断独立的本体/视觉物理见证交叉验证，绝不能用被标定系统自己的输出来估计 q_h（否则是循环自证）。

**定义 301（查询价值与混合主动策略）** 查询 q ∈ Q 的价值
VoI(q) = E_y[ min_a E_{s|y} L(a,s) ] − min_a E_s L(a,s)，
净价值 NV(q) = VoI(q) − λ_q c_q − λ_d T_delay(q)。策略：在 Q ∪ {∅} 上选 NV 最大者；仅当 NV(q) > 0、当前处于安全窗口、且预算未耗尽时才询问；否则退回 AVP 或保守回退。这就是把人机交互形式化为**离散贝叶斯实验设计**。

**定义 302（信任校准与可读性）** 真实系统可靠度 R_sys 由证书 J_AVIM 给出；人的依赖度 r_h 由干预率、接管率、遵从率在线估计。信任校准误差 e_T = |r_h − R_sys|，目标带 [R_sys − ε_T, R_sys + ε_T]。
透明度/可读性策略 π_e 选择解释粒度、置信度展示与探测动作的「可读化」：
- 过度信任（r_h > R_sys + ε_T）⇒ 强制验证/主动探测，并显式展示歧义；
- 信任不足（r_h < R_sys − ε_T）⇒ 展示独立见证证据或可读演示，减少无谓干预。
可读探测的意图推断代价 L_leg = E[KL(p(intent | ξ) ‖ p(true intent | ξ))] ≤ τ_leg，确保探测动作被理解为「校准」而不是「故障/失控」。

**定义 303（安全诊断协议）** 探测动作集
A_probe(x) = { a ∈ A_task(x) : Risk(a,x) ≤ R_max, E(a) ≤ E_max, consent = true }。
选择按字典序：先最大化安全裕度，再最大化信息增益；**信息永远不能以突破安全为代价**。协议包含探测预算 B_E、查询预算 B_q、超时中止、人类否决即停、风险门打开即冻结探测。探测不是「为了诊断可以冒一点险」，而是「只在本来就安全的动作里找信息」。

**定义 304（歧义感知的风险自适应）** 在 R68 的 CAR 之上加入歧义项：
τ_temporal(θ) = τ⁰_temporal·(1 + κ_T·U + κ_A·α_t)，
τ_wm(θ) = τ⁰_wm·(1 + κ_W·U + κ_A·α_t)，
τ_risk(θ) = τ⁰_risk·(1 − κ_r·U − κ_a·α_t)，
λ_floor(U, α) = max(0.6, 0.8·1[U > τ_cal ∨ α_t > τ_obs ∨ MCT = ∅])，
k ≤ k_cal_shrink(A, U)·(1 − c_a·α_t)。
语义：不可观测性既让一致性检验更宽容（防误报），又让风险阈值更紧、前缀更短（更保守）——**两个方向同时联动，杜绝「不确定却放宽」**。

**定义 305（AIC-AVIM 干扰集）** ℰ_AVIM = ℰ_CALM × ℰ_obs × ℰ_probe × ℰ_wit × ℰ_hci：
- ℰ_obs = {探测零空间故障, 模型误设, 伪可观测}；
- ℰ_probe = {探测诱发失稳, 探测越界, 过度探测拖垮任务}；
- ℰ_wit = {见证者伪造, 共因失效, 循环自证, 相关投票}；
- ℰ_hci = {社会工程/恶意反馈, 过度信任, 信任不足, 查询疲劳, 同意撤回竞态}。

**定义 306（J_AVIM 证书）**
J_AVIM = (J_CALM, O_t, probe_log, witness_graph_hash, independence_cert, query_log, consent_state, trust_error, avim_ver)。
Valid ⇔ Valid(J_CALM) ∧ (α_t < τ_obs^hard ∨ 已穷尽安全探测且显式声明不可观测) ∧ probe_log 无越界 ∧ independence_cert ≥ κ_min ∧ consent_state = VALID ∧ trust_error ≤ ε_T。

# IP-253 AOM：联合 Fisher + 歧义子空间监控（给 R68 的「标定吸收」拍 X 光）
class ObservabilityMonitor:
    def __init__(self, d_c=12, d_f=8, tau_obs=0.2):
        self.F = np.eye(d_c + d_f) * 1e-6      # 联合 Fisher，(c, f)
        self.tau_obs = tau_obs

    def update(self, J_c, B_f, W):
        Phi = np.hstack([J_c, B_f])            # m × (d_c+d_f)
        self.F += Phi.T @ W @ Phi
        lam, V = np.linalg.eigh(self.F)
        A = V[:, lam <= 1e-9]                  # 歧义子空间 basis
        alpha = self._ambiguity(B_f, A)        # 故障估计落在 A 的比例
        return ObservabilityCert(lam.min(), A, alpha,
                                 self._probe_blind_subspace())

    def _ambiguity(self, B_f, A):
        f_hat = self.f_hat                   # 当前慢故障估计
        num = np.linalg.norm(A.T @ (B_f @ f_hat))
        den = np.linalg.norm(B_f @ f_hat) + 1e-12
        return num / den

    def _probe_blind_subspace(self):
        return null_space(np.vstack([Phi_pi for Phi_pi in SAFE_PROBE_JACOBIANS]))


# IP-254 AVP：安全探测设计（D-最优 + 覆盖约束，监督层 2–5 Hz）
class ActiveVisualProber:
    def __init__(self, safe_set, E_max, tau_gain=0.05):
        self.safe_set, self.E_max, self.tau_gain = safe_set, E_max, tau_gain

    def propose(self, F, state, consent=True):
        if not consent: return None
        best, best_gain = None, 0.0
        for pi in self.safe_set:               # 视差/事件/接触/锚点四类基元
            if not safe(pi, state):            # Risk(pi) <= R_max 的硬门
                continue
            if energy(pi) > self.E_max:
                continue
            F_pi = fisher_block(pi, state)
            gain = d_opt_gain(F, F_pi)         # 只奖励对 null(F) 的激发
            if gain > best_gain:
                best, best_gain = pi, gain
        return best if best_gain > self.tau_gain else None


# IP-255 MIP：VoI 查询（离散贝叶斯实验设计）
class MixedInitiativeProber:
    def __init__(self, queries, lam_q, budget):
        self.queries, self.lam_q, self.budget = queries, lam_q, budget

    def choose(self, posterior, state):
        if self.budget <= 0 or not safe_window(state):
            return None
        best, best_nv = None, 0.0
        for q in self.queries:
            voi = expected_voi(q, posterior)               # E_y[loss] 下降量
            nv = voi - self.lam_q * cost(q) - delay_penalty(q, state)
            if nv > best_nv:
                best, best_nv = q, nv
        return best


# IP-256/257 WPG + MCT：见证溯源 + 鲁棒共识三角化
class WitnessProvenanceGraph:
    def __init__(self, witnesses):
        self.W = witnesses
        self.edges = []                         # (i, j, kappa_ij)

    def valid(self):
        return (acyclic(self.edges) and
                all(k >= KAPPA_MIN for _, _, k in self.edges))

    def consensus(self, estimates, covs):
        # estimates: {w: c_hat_w}, covs: {w: Sigma_w}
        c = robust_huber_fuse(estimates, covs)
        d = {w: mahalanobis(estimates[w], c, covs[w]) for w in estimates}
        outliers = [w for w in d if d[w] > TAU_WIT]
        if not outliers:
            return c, 'ALL_AGREE'
        if len(outliers) == 1 and self.valid():
            rest = {w: estimates[w] for w in estimates if w != outliers[0]}
            return robust_huber_fuse(rest, covs), 'ONE_OUTLIER'
        return None, 'NO_CONSENSUS'             # 不可判定 → 保守回退


# IP-258 TCN：信任校准 + 可读探测
class TrustCalibratedNegotiation:
    def __init__(self, band=0.1):
        self.band = band

    def update(self, r_h, R_sys):
        e_T = abs(r_h - R_sys)
        if r_h > R_sys + self.band:             # 过度信任
            return 'FORCE_VERIFY', e_T
        if r_h < R_sys - self.band:             # 信任不足
            return 'SHOW_EVIDENCE', e_T
        return 'CALIBRATED', e_T


# IP-262 主闭环：AVIM-RAS supervisory round（2–5 Hz，实时环不变）
def AVIM_round(M, obs, consent=True):
    # 0) 继承 R68 的实时环结果（MTM 前向、COF、CFA、C-RAS-WM）
    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)
    r = residuals(x_prime, o, M.wm_residual_cache)
    c, U, thr = M.cof.step(o['cal'], r, sigma_stat(M))

    # 1) AOM：联合 Fisher + 歧义证书
    J_c, B_f = M.aom.jacobians(x_prime, M.residual_log)
    O = M.aom.update(J_c, B_f, W_r)

    # 2) 歧义处理：先探测，再询问，最后保守回退
    if O.alpha > TAU_OBS:
        pi = M.avp.propose(M.aom.F, M.state, consent)
        if pi is not None:
            z_pi = M.avp.execute(pi)            # 安全动作集内执行
            O = M.aom.update(*probe_jacobians(pi, z_pi), W_pi)
        elif (q := M.mip.choose(M.posterior, M.state)) is not None:
            y = M.mip.ask(q)                    # 语义标签/物理参照/否决
            M.posterior = M.mip.update(M.posterior, q, y)
            O = M.aom.update(*human_jacobians(q, y), W_h)
        else:
            M.freeze_calibration(); M.alpha = O.alpha

    # 3) MCT：三角化共识（本体/力、视觉、人类）
    c_hat, verdict = M.wpg.consensus(M.witness_estimates, M.witness_covs)
    if verdict == 'NO_CONSENSUS':
        M.freeze_calibration(); M.alpha = max(M.alpha, O.alpha)

    # 4) 标定只在可辨识子空间更新（禁止沿 null(F) 吸收故障）
    if verdict in ('ALL_AGREE', 'ONE_OUTLIER') and O.alpha <= TAU_OBS:
        c = M.cof.update_identifiable(c_hat, O.A)
    else:
        c, U = M.cof.freeze(), max(U, TAU_CAL)

    # 5) CFA：先可观测、后标定、再归因（R68 的 EFS 升级）
    rho = M.fir_signature(z, M.residual_log)
    joint_post = M.cfa(rho, o['pi'], c, U, alpha=M.alpha)

    # 6) 歧义感知风险缩放：任何不可观测性都只收紧
    lam = max(M.efs.risk_scale(joint_post),
              lambda_floor(U, M.alpha),
              0.8 if (o['qual']['face'] < 0.8 or M.wm_drift) else 0.6)
    k = M.c_ras_wm.certified_prefix(A, joint_post, m_ras, M.alpha_chunk, wm_preds)
    k = min(k, k_cal_shrink(A, U), int(k * (1 - C_A * M.alpha)))

    # 7) TCN：信任校准（异步、不阻塞控制）
    action_tcn, e_T = M.tcn.update(M.human_reliance(), M.reliability())
    if action_tcn == 'FORCE_VERIFY':
        M.schedule_probe(priority='verify')
    elif action_tcn == 'SHOW_EVIDENCE':
        M.ui.show(M.witness_evidence, legible=True)

    # 8) 证书与影子提交
    M.javim.write(J_CALM, O, M.probe_log, M.wpg.hash(),
                  M.mip.log, consent, e_T)
    M.cac.maybe_commit(M.shadow, dt=M.time_since_last_commit)
    return k, lam, joint_post, (c, U, O, verdict)
```

## 3. 推导

**引理 16（被动不可辨识界——R68 盲区的信息论坐标）** 在线性高斯联合模型（定义 294）下，若存在非零 v = (δc, δf) ∈ A_t = ker(F_t)，则参数 θ 与 θ + v 产生完全相同的残差分布；任何被动（不改变 x_t 分布）的估计器都无法以高于显著水平 α 的概率区分二者。特别地，故障分量 f_abs = Π_c B_f f 与某次标定漂移不可区分，其可检测性恒等于检验水平；只有 f_⊥ = (I − Π_c)B_f f 进入真实故障归因。
**证明**：残差 r_t 的均值只通过 Φ_t(θ) 进入；Φ_t v = 0 ⇒ 两个参数点的似然函数逐点相等，由 Neyman–Pearson 引理，任何检验的功效 ≤ α。R68 的速率限制把「快变」故障移出标定通带，但若 B_f f 落在 J_c 的列空间内，慢变分量仍在 A_t 内，采样再多也无法分离。∎
**系**：R68 的风险不是「滤波器不够好」，而是「观测设计不可辨识」；提升采样率/降噪只能缩小 f_⊥ 的检测阈值，不能消除 f_abs。

**引理 17（主动探测的可观测性增益与覆盖极限）** 设探测 π 注入 F_π。对任意方向 u，探测后 Fisher 信息为 u^T(F_t + F_π)u。若 u^T F_t u = 0（被动不可观测），则 u^T F_π u = ‖W_π^{1/2} Φ_π u‖²。设探测能量为 E、灵敏度矩阵沿 u 的最小奇异值为 σ_π(u) ≥ c_π(u)√E，则对该方向故障幅度 a 的检测信噪比
SNR_π(u) = a·σ_π(u)/σ_noise ≥ a·c_π(u)√E/σ_noise，
随 √E 增长；D-最优设计 π* 最大化 ½log det(I + F_t^+ F_π)，等价于在 null(F_t) 上最大化几何平均激发。**但**若 u ∈ B_probe = ∩_{π∈Π_safe} ker(Φ_π)，则对任意安全探测和任意预算 SNR_π(u) = 0——**不存在有限安全探测基能覆盖其正交补**。
**证明**：线性高斯下 Fisher 信息对探测块可加；u ∈ ker(Φ_π) ⇒ F_π u = 0。D-最优性由 Kiefer–Wolfowitz 等价定理给出。∎
**系**：AVIM 的诚实边界是 B_probe，而不是「全部故障」。证书必须显式声明 B_probe，落入其中的故障只能靠独立见证者或人工介入，不能靠加预算/加时间解决。

**引理 18（见证共识的辨识性）** 设 n = 3 个两两独立见证者，观测 ĉ_i = c + b_i + ε_i，ε_i ~ 𝒩(0, Σ_i)，且至多一个 b_i ≠ 0。若 ‖b_i‖ ≥ 2τ_wit 且 κ_ij ≥ κ_min，Huber 共识以概率 ≥ 1 − 3exp(−τ_wit²/(2σ²)) 将该离群者定位；若两个见证者共享共模偏差 b（κ→1），共识偏差为 b 且无法被自身发现——**相关投票会把错误变成多数**。一般地：n_eff ≥ 3 才能定位单个故障，n_eff ≥ 2 只能检测「不一致」而不能指出谁错；n_eff = 1 时标定与故障在操作上不可区分（定义 298）。
**证明**：两两独立 ⇒ 离群残差 d_i 的分布与其余两个分离，Huber 的 breakdown point 在 n=3、单离群时为 1/3；共模偏差下三个残差同向偏移，一致对仍成立，故不可辨。∎
**系**：人机交互增加的不是「第四票」，而是**独立性**：若人类只是重复系统已经给出的结论（κ_h,sys → 1），它不增加 n_eff；只有人类提供独立的物理参照或语义反例，才真正提升辨识性。

**引理 19（查询的 VoI 安全性与信任校准收敛）** (i) 若查询策略仅在安全窗口内、预算内、且 NV(q) > 0 时询问，并且查询本身不直接驱动执行器，则查询不增加即时物理风险；其引入的延迟风险被 T_delay(q) 显式计入 NV，且可由「查询期间保持 R68 的保守前缀」吸收。(ii) 若人类可靠性估计 q̂_h 仅由独立物理见证者监督，且信任动力学取 T_{h,t+1} = T_{h,t} + η(r_h − R_sys)，则在 R_sys 分段常值时 e_T 指数收敛；R_sys 缓变时稳态误差 ≤ η·sup|ΔR_sys|/(1−η)。过度信任触发强制验证，等价于在 e_T > ε_T 时把决策权暂时移交给独立见证者，因而不会因人的错误而放宽安全。
**证明**：(i) 由 A_probe 的字典序安全约束与查询不进入执行器通道直接得到；(ii) 一阶跟踪器的标准收敛界；验证动作是 e_T 的超调反馈，闭环特征值位于单位圆内。∎

**定理 16（AVIM 端到端慢故障可检测性与安全单调性）** 在 A95–A99（慢故障模型、探测覆盖、见证独立、人类 oracle 可靠性、探测安全）下：
1. 对任意满足 P_{B_probe^⊥} B_f f ≠ 0 的慢故障，存在有限探测预算使检测概率 ≥ 1 − β；且检测后残余中可由标定吸收的比例 ≤ α_t ≤ τ_obs；
2. 若 B_f f ∈ B_probe 且无独立见证者，系统**必须**输出「不可观测」并令 λ_floor = 0.8、k 收缩——绝不输出「已标定」的假证书；
3. P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + **α_obs**，其中 α_obs ≤ P(α_t > τ_obs ∧ 无探测 ∧ 无见证) 被第 2 条降级为保守项；
4. 探测不增加物理风险：P(unsafe | probe) ≤ P(unsafe | no probe)，因为 π ∈ A_probe 且探测期间保持 R68 的认证前缀。
**证明**：第 1 条由引理 17 的 SNR 增长与引理 18 的共识定位；第 2 条由引理 16/17 的不可辨识性直接构造；第 3 条把 R68 定理 14 的误差项按新的歧义项展开；第 4 条由定义 303 的字典序约束与 R68 定理 15 的前缀冻结。∎

**定理 17（交互见证的健全性）** 在定义 298 的有效见证图与定义 299 的共识下：
1. 若至多一个见证者被破坏（故障/伪造/恶意），且存在 ≥3 个两两独立见证者，则 AVIM 不会签发错误的 H_cal 证书（soundness），概率 ≥ 1 − η；
2. 任何人类查询/否决都不能使 λ_risk 低于 R68 的 λ_floor；过度信任只会触发更多验证，不会减少验证；
3. 社会工程/恶意反馈的影响被 WPG 的「禁止自证」与物理见证交叉验证限制在单个见证者的权重内，不能单独翻转标定结论；
4. 信任校准误差 e_T 在持续激励下收敛到带内（引理 19）。
**证明**：第 1 条由引理 18；第 2 条由定义 304 的 max 结构与定义 303 的字典序；第 3 条由无环 + 独立度约束，恶意节点无法同时占据两条独立路径；第 4 条由引理 19(ii)。∎

| E300 长尾/跨本体泛化 | 未见过的慢故障与不同机器人 | 视觉探测基元迁移后检出 +15%；B_probe 声明保持诚实 |

## 6. 本轮最大风险

**一句话**：AVIM-RAS 把安全性从「标定可信」转移到了「见证者相互独立且探测覆盖充分」——但**任何有限的安全探测基都存在零空间 B_probe，且视觉与人类见证者都可能与故障共因或共谋**：一旦光照/纹理失效让视觉与力传感器同时偏移，或人出于过度信任/社会压力给出与系统一致的错误确认，三个「独立」见证者就会退化成相关投票，系统将以更高的置信度签发一个错误标定证书；更根本地，落在 B_probe 正交补之外的缓变故障仍会被「我们已经检查过了」的假象掩盖——可观测性证书只能证明「在我们能做的实验下不可见」，不能证明「不存在」。

**次级风险与缓解**：
1. **探测诱发失稳/越界** → 定义 303 的字典序安全约束 + 探测预算 + 50 ms 中止 + R68 认证前缀全程保持；
2. **探测零空间盲区** → 证书显式输出 B_probe，落入其中即判不可观测并保守回退，禁止伪收敛；
3. **见证共因/伪造** → WPG 无环 + 独立度 κ 估计 + 物理参照交叉验证 + 禁止自证；
4. **人类过度/不足信任** → TCN 校准带 + 强制验证/证据展示 + 可读探测；
5. **查询疲劳与同意竞态** → 查询预算 B_q + 安全窗口 + 同意状态纳入 J_AVIM，撤回即冻结；
6. **AOM 模型误设导致伪可观测** → 鲁棒 Fisher 下界 + 残差重采样校准 + 模型失配时 α_t 上修（宁可判不可观测）。

# 第 69 轮产物 · 创新点清单 v1：AVIM-RAS（Active Visual-Interactive Metrology for Risk-Adaptive Safety：主动视觉-交互计量的风险自适应闭环；AOM×AVP×MIP×WPG×MCT×TCN×SDP×AVIM†）

>
> 定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**我凭什么知道它准——这个判断本身可观测吗**」。AVIM 的诚实边界是：可观测性证书只能证明「在我们能做的实验下不可见」。

## 2. 形式化定义（要点版）

**定义 293（总览与五不变式）** AVIM-RAS 继承 CALM-RAS 的三条不变式，并新增：(ii) **先可观测后标定**——COF 只沿可辨识子空间更新，禁止用先验补不可辨识方向；(iii) **探测安全支配**——(Safety, Information) 字典序，绝不加权求和；(iv) **见证独立/禁止自证**——任一标定声明至少由一个独立见证者背书，溯源图无环；(v) **交互诚实**——询问披露目的与不确定性，人可否决并撤回同意。

**定义 294（联合模型与歧义）** `r_t = J_c(x_t)δc_t + B_f(x_t)δf_t + ε_t`；θ=(c,f)，Φ=[J_c,B_f]，F=ΣΦ^T WΦ；A_t=ker(F_t)；Π_c 为吸收算子，ρ_abs 为吸收指数。R68 的速率限制处理「快慢」，ρ_abs 处理「方向」，二者正交。

**定义 295（可观测性证书）** O_t=(λ_min(F_t), A_t 的基, α_t, B_probe)。判定：λ_min≥λ_0 ∧ α_t≤τ_obs ⇒ 可标定；α_t>τ_obs 且故障在 B_probe 外 ⇒ 需探测；故障落在 B_probe 内 ⇒ **显式判不可观测**，禁止假装收敛。

**定义 296（主动探测设计）** 在 π∈Π_safe、Risk(π)≤R_max、E(π)≤E_max、consent 下最大化 Δ(π)。若 Δ(π*)<Δ_min ⇒ 转 MIP 或保守回退；绝不为了信息突破安全门。

**定义 297（视觉探测基元）** 视差 π_par（多视极线残差 → 外参/焦距）、事件流 π_evt（事件边缘流与 IMU 相位差 → Δt_sync/曝光）、接触几何 π_ctc（视觉接触点/法向 vs 力方向 → 力零偏/外参）、锚点 π_fid（已知标定板 → 绝对外参/焦距）。四者失效模式不同，构成视觉见证的探测覆盖。

**定义 298（见证与溯源图）** W={w_p,w_v,w_h}；G_w 为有向无环的「作证」图，边带独立度 κ_ij（共因测试估计）。有效见证集 ⇔ 无环 ∧ 无自环 ∧ 两两 κ_ij≥κ_min。**操作主义定义**：变化是 H_cal 当且仅当存在单一 δc 使所有见证者残差在噪声内；否则是 H_sensor^trans 或不可判定；见证不足时禁止硬判。

**定义 299（计量共识三角化）** 鲁棒 Huber 融合得 ĉ；残差 d_w；全一致 ⇒ H_cal；恰一离群 ⇒ 用其余标定并标疑似故障；≥2 离群或无一致对 ⇒ 无共识，判不可观测并保守回退。至少 3 个两两独立见证者才能定位单个故障；2 个只能发现不一致。

**定义 300（人类见证者模型）** y~p(y|s,q,T_h)；可靠性 q_h、偏差 b_h、信任 T_h。人类提供语义标签、物理参照、安全否决/同意三类证据。**关键约束**：q_h 只能由独立物理见证交叉验证，不能用被标定系统自身输出估计（防循环自证）。

**定义 301（VoI 查询）** `VoI(q)=E_y[min_a E_{s|y}L]−min_a E_s L`；`NV(q)=VoI−λ_q c_q−λ_d T_delay`；在 Q∪{∅} 上取 NV 最大，仅当 NV>0 ∧ 安全窗口 ∧ 预算未耗尽时询问。人机交互 = 离散贝叶斯实验设计。

**定义 302（信任校准与可读性）** e_T=|r_h−R_sys|，目标带 [R_sys−ε_T,R_sys+ε_T]；过度信任 ⇒ 强制验证/探测；不足 ⇒ 展示独立见证证据/可读演示。可读探测满足 L_leg=E[KL(p(intent|ξ)‖p(true intent|ξ))]≤τ_leg，避免被误解为失控。

**定义 303（安全诊断协议）** A_probe(x)={a∈A_task(x): Risk≤R_max, E≤E_max, consent}；选择按字典序 (Safety, Information)；探测预算、50ms 中止、人类否决即停、风险门打开即冻结。信息不得以安全为代价。

**定义 304（歧义感知风险自适应）** `τ_* = τ⁰_*(1 ± κU ± κ_A α_t)`，`λ_floor(U,α)=max(0.6,0.8·1[U>τ_cal∨α_t>τ_obs∨无共识])`，`k≤k_cal_shrink·(1−c_a α_t)`。不可观测性同时放宽一致性检验、收紧风险阈值、缩短前缀——只收紧，绝不放宽。

**定义 305（AIC-AVIM）** `ℰ_AVIM=ℰ_CALM×ℰ_obs×ℰ_probe×ℰ_wit×ℰ_hci`：ℰ_obs={探测零空间故障,模型误设,伪可观测}；ℰ_probe={探测诱发失稳,越界,过度探测}；ℰ_wit={伪造,共因,循环自证,相关投票}；ℰ_hci={社会工程,过度/不足信任,查询疲劳,同意撤回竞态}。

**定义 306（J_AVIM）** Valid ⇔ Valid(J_CALM) ∧ (α_t<τ_obs^hard ∨ 已穷尽安全探测且显式声明不可观测) ∧ probe_log 无越界 ∧ independence_cert≥κ_min ∧ consent=VALID ∧ e_T≤ε_T。

**定义 307（管线）** 继承 R68 离线预训练与在线 60s 影子提交；新增 2–5Hz 监督层：AOM → AVP/MIP → MCT → 仅可辨识方向更新 COF/CFA → 歧义感知风险缩放 → 写 J_AVIM。R68 实时环 <2.6ms 不变，只多读 α_t 与冻结标志。

# IP-253 AOM：联合 Fisher + 歧义子空间监控
class ObservabilityMonitor:
    def update(self, J_c, B_f, W):
        Phi = np.hstack([J_c, B_f])
        self.F += Phi.T @ W @ Phi
        lam, V = np.linalg.eigh(self.F)
        A = V[:, lam <= 1e-9]                  # A_t = ker(F_t)
        alpha = norm(A.T @ (B_f @ self.f_hat)) / (norm(B_f @ self.f_hat)+1e-12)
        return ObservabilityCert(lam.min(), A, alpha,
                                 null_space(np.vstack(SAFE_PROBE_JACOBIANS)))


# IP-254 AVP：安全探测设计（D-最优，盲子空间显式化）
class ActiveVisualProber:
    def propose(self, F, state, consent=True):
        if not consent: return None
        best, best_gain = None, 0.0
        for pi in SAFE_PROBES:                 # 视差/事件/接触/锚点
            if not safe(pi, state) or energy(pi) > E_MAX: continue
            gain = d_opt_gain(F, fisher_block(pi, state))
            if gain > best_gain: best, best_gain = pi, gain
        return best if best_gain > TAU_GAIN else None


# IP-255 MIP：VoI 查询（人机异步，安全窗口 + 预算）
class MixedInitiativeProber:
    def choose(self, posterior, state):
        if self.budget <= 0 or not safe_window(state): return None
        return argmax_or_none(
            {q: expected_voi(q, posterior) - LAM_Q*cost(q) - delay_penalty(q, state)
             for q in QUERIES if expected_voi(q, posterior) > LAM_Q*cost(q)},
            default=None)


# IP-256/257 WPG + MCT：见证溯源 + 鲁棒共识三角化
class WitnessProvenanceGraph:
    def valid(self):
        return acyclic(self.edges) and all(k >= KAPPA_MIN for _,_,k in self.edges)

    def consensus(self, estimates, covs):
        c = robust_huber_fuse(estimates, covs)
        d = {w: mahalanobis(estimates[w], c, covs[w]) for w in estimates}
        out = [w for w in d if d[w] > TAU_WIT]
        if not out: return c, 'ALL_AGREE'
        if len(out) == 1 and self.valid():
            rest = {w: estimates[w] for w in estimates if w not in out}
            return robust_huber_fuse(rest, covs), 'ONE_OUTLIER'
        return None, 'NO_CONSENSUS'            # 不可判定 → 保守回退


# IP-258 TCN：信任校准
class TrustCalibratedNegotiation:
    def update(self, r_h, R_sys):
        e_T = abs(r_h - R_sys)
        if r_h > R_sys + BAND: return 'FORCE_VERIFY', e_T
        if r_h < R_sys - BAND: return 'SHOW_EVIDENCE', e_T
        return 'CALIBRATED', e_T


# IP-262 主闭环：AVIM supervisory round（2–5 Hz，实时环不变）
def AVIM_round(M, obs, consent=True):
    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)       # 继承 R68
    r = residuals(x_prime, o, M.wm_residual_cache)
    c, U, thr = M.cof.step(o['cal'], r, sigma_stat(M))

    O = M.aom.update(*M.aom.jacobians(x_prime, M.residual_log), W_r)  # 1) 可观测性

    if O.alpha > TAU_OBS:                                        # 2) 先探测再询问
        pi = M.avp.propose(M.aom.F, M.state, consent)
        if pi is not None:
            O = M.aom.update(*probe_jacobians(pi, M.avp.execute(pi)), W_pi)
        elif (q := M.mip.choose(M.posterior, M.state)) is not None:
            M.posterior = M.mip.update(M.posterior, q, M.mip.ask(q))
            O = M.aom.update(*human_jacobians(q, y), W_h)
        else:
            M.freeze_calibration()

    c_hat, verdict = M.wpg.consensus(M.witness_estimates, M.witness_covs)  # 3) 三角化

    if verdict in ('ALL_AGREE', 'ONE_OUTLIER') and O.alpha <= TAU_OBS:     # 4) 只在可辨识子空间更新
        c = M.cof.update_identifiable(c_hat, O.A)
    else:
        c, U = M.cof.freeze(), max(U, TAU_CAL)

    joint_post = M.cfa(rho, o['pi'], c, U, alpha=M.alpha)        # 5) 先可观测后标定再归因
    lam = max(M.efs.risk_scale(joint_post), lambda_floor(U, M.alpha),
              0.8 if (o['qual']['face'] < 0.8 or M.wm_drift) else 0.6)  # 6) 只收紧
    k = min(k_cal_shrink(A, U), int(k * (1 - C_A * M.alpha)))

    action, e_T = M.tcn.update(M.human_reliance(), M.reliability())        # 7) 信任校准
    if action == 'FORCE_VERIFY': M.schedule_probe(priority='verify')
    elif action == 'SHOW_EVIDENCE': M.ui.show(M.witness_evidence, legible=True)

    M.javim.write(J_CALM, O, M.probe_log, M.wpg.hash(), M.mip.log, consent, e_T)  # 8) 证书
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit)
    return k, lam, joint_post, (c, U, O, verdict)
```

## 4. 推导

**引理 16（被动不可辨识界）** 若存在非零 v=(δc,δf)∈A_t=ker(F_t)，则 θ 与 θ+v 产生完全相同的残差分布；任何被动估计器都无法以高于显著水平 α 的概率区分二者。故障的可检测分量只有 f_⊥=(I−Π_c)B_f f；f_abs=Π_c B_f f 与标定不可区分。
**证明**：残差均值仅通过 Φ_t θ 进入；Φ_t v=0 ⇒ 似然逐点相等，由 Neyman–Pearson 引理功效 ≤ α。R68 的速率限制只移出快变故障，若 B_f f 落在 J_c 列空间，慢分量仍在 A_t 内。∎
**系**：提升采样率/降噪只能降低 f_⊥ 的阈值，不能消除 f_abs；问题在观测设计，不在滤波器。

**引理 17（主动探测增益与覆盖极限）** 探测 π 注入 F_π。对被动不可观测方向 u（u^T F_t u=0），有 u^T F_π u=‖W_π^{1/2}Φ_π u‖²；若沿 u 的灵敏度最小奇异值 σ_π(u)≥c_π(u)√E，则故障幅度 a 的检测 SNR ≥ a·c_π(u)√E/σ_noise，随 √E 增长。D-最优 π* 在 null(F_t) 上最大化几何平均激发。**但** u∈B_probe=∩_{π∈Π_safe}ker(Φ_π) ⇒ 任意安全探测与预算下 SNR=0。
**证明**：Fisher 信息对独立探测块可加；u∈ker(Φ_π)⇒F_π u=0；D-最优性由 Kiefer–Wolfowitz 等价定理。∎
**系**：AVIM 的诚实边界是 B_probe；落入其中的故障只能靠独立见证者或人工介入，加预算/加时间无效。

**引理 18（见证共识辨识性）** 3 个两两独立见证者 ĉ_i=c+b_i+ε_i，至多一个 b_i≠0；若 ‖b_i‖≥2τ_wit、κ_ij≥κ_min，Huber 共识以概率 ≥1−3exp(−τ_wit²/(2σ²)) 定位离群者。若两个见证者共享共模偏差（κ→1），共识偏差为 b 且自身无法发现。一般地：n_eff≥3 定位单故障；n_eff≥2 只能检测不一致；n_eff=1 时标定与故障操作上不可区分。
**证明**：两两独立使离群残差与其余分离，n=3 单离群时 Huber breakdown point 为 1/3；共模偏差下三残差同向偏移，一致对仍成立。∎
**系**：人类增加的不是「第四票」而是**独立性**；若人只是重复系统结论（κ_h,sys→1），n_eff 不增。

**引理 19（VoI 安全性 / 信任收敛）** (i) 仅在安全窗口、预算内、NV>0 时查询，且查询不直接驱动执行器 ⇒ 不增加即时物理风险；延迟风险由 T_delay 计入 NV，并由查询期间的保守前缀吸收。(ii) 若 q̂_h 仅由独立物理见证监督，且 T_{h,t+1}=T_{h,t}+η(r_h−R_sys)，则 R_sys 分段常值时 e_T 指数收敛；缓变时稳态误差 ≤η·sup|ΔR_sys|/(1−η)。过度信任触发强制验证，等价于 e_T>ε_T 时把决策权移交独立见证者。
**证明**：(i) 由定义 303 字典序与查询不进入执行器通道；(ii) 一阶跟踪器标准界；验证反馈使闭环特征值在单位圆内。∎

**定理 16（端到端慢故障可检测性与安全单调性）** 在 A95–A99 下：
1. 对 P_{B_probe^⊥}B_f f≠0 的慢故障，存在有限探测预算使检测概率 ≥1−β；检测后可由标定吸收的比例 ≤α_t≤τ_obs；
2. 若 B_f f∈B_probe 且无独立见证者，系统必须输出「不可观测」并令 λ_floor=0.8、k 收缩，绝不签发「已标定」假证书；
3. `P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+α_obs`，其中 α_obs 被第 2 条降级为保守项；
4. P(unsafe|probe)≤P(unsafe|no probe)：π∈A_probe 且探测期间保持 R68 认证前缀。
**证明**：1 由引理 17/18；2 由引理 16/17 的不可辨识性构造；3 按 R68 定理 14 展开新误差项；4 由定义 303 字典序与定理 15 前缀冻结。∎

**定理 17（交互见证健全性）** 在有效见证图与鲁棒共识下：
1. 至多一个见证者被破坏、且 ≥3 个两两独立见证者 ⇒ 不签发错误 H_cal 证书，概率 ≥1−η；
2. 任何查询/否决都不能使 λ_risk 低于 R68 的 λ_floor；过度信任只会触发更多验证；
3. 社会工程/恶意反馈被「禁止自证」与物理交叉验证限制在单个见证者权重内，不能单独翻转标定结论；
4. 信任校准误差在持续激励下收敛到带内（引理 19）。
**证明**：1 由引理 18；2 由定义 304 的 max 结构与定义 303 字典序；3 由无环 + 独立度约束，恶意节点无法同时占据两条独立路径；4 由引理 19(ii)。∎

## 7. 本轮最大风险

**一句话**：AVIM-RAS 把安全性从「标定可信」转移到「见证者相互独立且探测覆盖充分」——但**任何有限安全探测基都有零空间 B_probe，且视觉与人类见证者都可能与故障共因或共谋**：一旦光照/纹理失效让视觉与力传感器同时偏移，或人因过度信任/社会压力给出与系统一致的错误确认，三个「独立」见证者就退化为相关投票，系统将以更高置信度签发错误标定证书；落在 B_probe 内的缓变故障仍被「我们已经检查过了」的假象掩盖——可观测性证书只能证明「在我们能做的实验下不可见」，不能证明「不存在」。

**次级风险与缓解**：探测诱发失稳/越界（字典序安全约束 + 50ms 中止 + R68 前缀保持）；探测零空间盲区（证书显式输出 B_probe，落入即判不可观测）；见证共因/伪造（WPG 无环 + 独立度估计 + 物理参照交叉验证 + 禁止自证）；人类过度/不足信任（TCN 校准带 + 强制验证/证据展示 + 可读探测）；查询疲劳与同意竞态（查询预算 + 安全窗口 + 同意状态纳入 J_AVIM）；AOM 模型误设（鲁棒 Fisher 下界 + 残差重采样 + 失配时上修 α_t）。
