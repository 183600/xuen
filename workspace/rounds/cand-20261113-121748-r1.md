# 第 67 轮（承接第 66 轮「RAS 情绪驱动闭环」IP-224~233；灵感循环第 1 轮（新循环）；本轮灵感：「共享控制」×「模块化设计」）

> 第 66 轮 RAS 把「被动故障响应闭环」升级为「主动意图感知闭环」：用面部表情捕获风险态度，用 `λ_risk` 做全局风险缩放，用时空一致性抑制感知误差。这是重要的一步，但它有一个被自身成功掩盖的结构性缺陷：**RAS 仍然是一个「单控制器 + 单标量」的中央集权系统**。
>
> `λ_risk` 是一个全局标量，它只能表达「整体收紧/放宽」，却无法表达「谁对哪一个控制维度拥有多少权威」。真实的人机协作恰恰是多主体、多维度、可切换的：人可能保留「往哪走」的权威，机器人保留「多大力」的权威；某个感知模块失效时，应只隔离该模块，而不是把整个系统降级。
>
> 本轮灵感的核心命题是：
>
> **把 RAS 的「标量风险缩放」升级为「模块化权威路由」——MASCOT（Modular Authority-Sharing COntrol with Typed contracts）：把共享控制中的「权威」显式建模为可分配、可认证、可隔离的资源；把系统拆成带类型契约的模块图；让情绪、风险、故障归因都成为「权威分配」的输入，而不是直接改写控制量。**
>
> RAS 问「谁控制、何时控制、控制多少」；MASCOT 追问的是：**「哪一个维度，由哪一个模块，在什么契约下，承担多少权威？」** 它把共享控制从「权重混合」提升为「契约化权威编排」。

## 0. 直觉与动机

**灵感 1（共享控制 → 权威是一张矩阵，不是一个标量）**
直觉：现有共享控制常写成 `u = α·u_H + (1-α)·u_R`，α 是标量。这在多自由度任务里等于「人和机器人永远同比例地分享所有维度」，显然不对。卧床老人可能希望自己控制「去哪」，但把「扶稳杯子」的力控完全交给机器人；新手司机希望机器人接管「横向」，自己保留「纵向」。因此权威应写成矩阵 `A ∈ [0,1]^{|M|×D}`：行是模块/主体，列是控制维度，列和为 1。`λ_risk` 只是 D=1、单主体、无契约隔离时的退化情形。这个视角把 RAS 从「全局缩放」变成「逐维路由」。

**灵感 2（模块化设计 → 契约让安全可组合）**
直觉：模块化不是「把代码拆小」，而是「让每个模块的安全承诺可以在接口处被独立检查、替换和组合」。若每个模块 `m` 都带有契约 `C_m = (I_m, O_m, A_m, Pre_m, Post_m, κ_m)`，且上下游满足 assume-guarantee 关系，则整体安全可由局部证书**组合**得到，而不必对整体重新做端到端认证。这正好补上 RAS 的短板：RAS 的 EFS/C-RAS/ERS 是硬耦合的，改一个就要重证全部；MASCOT 让「换一个情绪模块」或「换一个规划器」只需检查接口契约。

**灵感 3（合流 → 权威路由是带约束的分配问题）**
直觉：把 RAS 的情绪后验 `P(H,E | face)` 与故障后验 `P(H | ρ)` 作为「权威偏好」的输入：恐惧/疼痛 → 权威向人类或安全模块倾斜；几何故障 → 权威从规划模块移到安全模块；情绪不可观测 → 保持权威分布不变（不因「看不见」而误放大机器人权威）。于是共享控制变成一个**带安全约束与变化率约束的权威分配优化**：

```
α* = argmax_{A ∈ 𝒜}  U_task(A) + β·⟨A, B⟩ − γ·R_gap(A)
s.t.  逐列 Σ_m α_{m,d} = 1,  α_{m,d} ∈ A_m,
      κ_s(α_s) ≤ κ_max,     ‖α_t − α_{t−1}‖_∞ ≤ Δ
```

这不是新的控制律，而是把「谁控制」提升为一等决策变量。`B` 是权威偏好矩阵，`R_gap` 是责任真空惩罚。

**灵感 4（模块化的代价 → 新故障维度：接口漂移与责任真空）**
直觉：模块化并非免费。两个模块各自满足契约，组合后仍可能违约——这就是 assume-guarantee 的循环依赖。共享控制又引入「责任真空」（moral crumple zone）：当权威矩阵某一维没有任何一方 `α > 1/2` 时，出事后无人可追溯。因此 MASCOT 必须把 RAS 的故障假设集再扩两维：`H_interface`（接口漂移/契约失配）与 `H_authority`（权威迟滞/冲突/真空）。安全不再只是「力/几何」，还包括「权威是否清晰、是否可追溯」。

**灵感 5（RAS 组件的模块化升级）**
- **ERG → ERG-M**：情绪网关变成可插拔模块，输出「权威偏好先验」而非直接 λ；
- **EFS → ARS（Authority Routing Supervisor）**：不再直接缩放控制量，而是解一个权威分配问题；
- **C-RAS → C-MASCOT**：认证前缀 = min(各模块认证前缀, 权威稳定视界)；
- **J_RAS → J_MASCOT**：证书由模块证书组合而成，附权威矩阵、契约状态、责任真空指标；
- **FAS → QS（Quarantine Supervisor）**：模块契约违约时隔离该模块，并在子图上重路由，实现「故障局部化」。

## 1. 形式化定义（增量：定义 251–266）

- **定义 251（MASCOT 总览）**：`MASCOT = (MG, CT, AR, CM, QS, MC)`。MG 为类型化模块图，CT 为契约表，AR 为权威路由器，CM 为契约监控器，QS 为隔离监督器，MC 为模块化证书。不变式：所有权威分配、契约检查、证书组合只在语义流；实时流只做命令混合、契约断言求值与权威早停，零学习写操作。
- **定义 252（类型化模块与契约）**：模块 `m ∈ M` 的契约 `C_m = (I_m, O_m, A_m, Pre_m, Post_m, κ_m)`。`I_m, O_m` 为带类型的输入/输出端口；`A_m ⊆ [0,1]^D` 为模块可承担的权威域；`Pre_m, Post_m` 为接口断言；`κ_m` 为局部风险上界。
- **定义 253（模块图）**：`MG = (M, E, T)`，`E ⊆ M×M` 为带类型连接，`T` 为组合算子（串行 `∘`、并行 `⊗`、反馈 `μ`）。
- **定义 254（权威矩阵）**：`A_t = [α_{m,d}] ∈ [0,1]^{|M|×D}`，满足逐列 `Σ_m α_{m,d} = 1`。集合 `M` 至少含人类模块 `h`、安全模块 `s`、机器人规划模块 `p`。行和可小于 1（模块可弃权）。
- **定义 255（共享命令）**：逐维混合 `u_d(t) = Σ_m α_{m,d}(t)·u_{m,d}(t)`；整体记为 `u_t = Σ_m (α_{m,·} ⊙ u_{m,·})`。
- **定义 256（权威偏好）**：由 RAS 后验导出偏好矩阵 `B = [b_{m,d}]`，`b_{m,d} = g_m(P(H,E | face), P(H | ρ), d)`。例如 `b_{h,d}` 随 `P(E1 恐惧)` 单调上升，`b_{s,d}` 随 `P(H_geo)` 单调上升。
- **定义 257（权威路由优化）**：`α* = argmax_{A ∈ 𝒜} U_task(A) + β⟨A,B⟩ − γR_gap(A)`，其中 `𝒜` 是列和、权威域、安全包络 `κ_s ≤ κ_max`、变化率 `‖α_t − α_{t−1}‖_∞ ≤ Δ` 的交集。为可解性，`R_gap` 使用 hinge 光滑化 `R_gap^τ = (1/D)Σ_d max(0, τ − max_m α_{m,d})`。
- **定义 258（责任真空 / 权威模糊度）**：`R_gap(A) = (1/D)Σ_d 1[max_m α_{m,d} < 1/2]`。若 `R_gap > τ_gap`，触发权威澄清（人类确认或安全模块兜底）。
- **定义 259（契约监控 / 接口漂移）**：运行时逐步求值 `Pre_m, Post_m`。若某模块输入违约或输出越界，置 `H_interface = 1`，并将该模块标记为 `quarantined`。
- **定义 260（模块隔离与子图重路由）**：隔离后 `M' = M \ {m}`，在 `MG'` 上重解定义 257，并抬高安全模块权威下界 `α_{s,d} ≥ α_s^min`，保证降级后的兜底。
- **定义 261（无扰权威切换）**：权威经一阶滤波 `α_t = (1−η)α_{t−1} + η α*_t`，并要求 `‖u_t − u_{t−1}‖ ≤ ε_b`；必要时在命令空间做插值。
- **定义 262（模块化证书）**：`J_MASCOT = ({J_m}_{m∈M'}, A*, contract_status, R_gap, authority_hash, composition_hash)`。`Valid ⇔ ∀m Valid(J_m) ∧ contract_status = PASS ∧ R_gap ≤ τ_gap ∧ 权威在认证前缀内稳定`。
- **定义 263（认证权威前缀）**：`k*_MASCOT = min( min_{m∈M'} k*_m, k_stable )`，其中 `k_stable` 是预测视界内权威矩阵不触发隔离/切换的最大步数。
- **定义 264（权威故障假设）**：`H_auth = {A0 正常, A1 迟滞, A2 冲突, A3 责任真空}`，并入联合假设集 `ℋ_MASCOT = ℋ_RAS × H_interface × H_auth`。
- **定义 265（对 RAS 的包含关系）**：当 `D = 1`、`α_h = α_s = 0`、`α_p = 1`、无契约隔离时，MASCOT 退化为 RAS 的风险缩放环节；`λ_risk` 是 MASCOT 的一个对角特例。因此 MASCOT 严格更一般。
- **定义 266（可组合安全）**：若 `∀(m→n) ∈ E: Post_m ⊨ Pre_n`，且组合算子 `T` 保序（保前置、保后置），则组合系统满足 `∧_{m∈M'} Post_m`。

## 2. 关键算法骨架

```python
# AR：权威路由器（带安全/契约/变化率约束）
class AuthorityRouter:
    def __init__(self, D, beta=0.5, gamma=0.8, delta=0.15, tau_gap=0.25):
        self.D, self.beta, self.gamma = D, beta, gamma
        self.delta, self.tau_gap = delta, tau_gap

    def solve(self, modules, B, prev_A, safety_lb):
        # 变量：A ∈ R^{|M|×D}；约束：列和=1、α∈A_m、κ_s≤κ_max、|A-prev_A|≤delta
        obj = lambda A: -task_utility(A) - self.beta * inner(A, B) \
                        + self.gamma * soft_gap(A, tau=0.5)
        A = convex_solver(obj, modules, prev_A, safety_lb, self.delta)
        return A

    def soft_gap(self, A, tau):
        return sum(max(0.0, tau - A[:, d].max()) for d in range(self.D)) / self.D


# CM：契约监控器（assume-guarantee 运行时断言）
class ContractMonitor:
    def check(self, m, inp, out):
        ok = eval_assert(m.Pre, inp) and eval_assert(m.Post, out)
        if not ok:
            return {'module': m.id, 'H_interface': 1, 'action': 'QUARANTINE'}
        return {'module': m.id, 'H_interface': 0, 'action': 'PASS'}


# QS：隔离 + 子图重路由
class QuarantineSupervisor:
    def isolate(self, graph, bad_module, router, B, prev_A):
        G2 = graph.without(bad_module)
        safety_lb = {d: max(0.5, prev_A[graph.safety, d]) for d in range(router.D)}
        A2 = router.solve(G2.modules, B, prev_A, safety_lb)
        return G2, A2


# MC：模块化证书组合
class ModularCertificate:
    def compose(self, local_certs, A, contract_status, R_gap):
        valid = all(c.valid for c in local_certs) \
                and contract_status == 'PASS' \
                and R_gap <= self.tau_gap \
                and self._authority_stable(A)
        return {'valid': valid, 'A': A, 'R_gap': R_gap,
                'authority_hash': hash_matrix(A),
                'composition_hash': hash_contracts(local_certs)}


# MASCOT 主循环
def MASCOT_round(M, obs):
    # 1) RAS 前向：感知、情绪、故障归因（复用第 66 轮）
    face_gate = M.erg_m.recognize(obs.img)
    rho = M.fir.signature(M.stage.split(M.residual_log))
    joint_post = M.efs.synthesize(rho, face_gate)

    # 2) 偏好矩阵：情绪/故障 → 权威先验
    B = M.ar.build_preference(joint_post, face_gate)

    # 3) 契约监控（实时断言）
    for m in M.graph.modules:
        st = M.cm.check(m, m.last_in, m.last_out)
        if st['action'] == 'QUARANTINE':
            M.graph, prev_A = M.qs.isolate(M.graph, m, M.ar, B, M.prev_A)
            B = B.without(m)

    # 4) 权威路由
    A = M.ar.solve(M.graph.modules, B, M.prev_A, M.safety_lb)
    A = M.bat.filter(A, M.prev_A)          # 无扰切换
    R_gap = M.rga.score(A)

    # 5) 逐维混合命令
    u = blend_commands(M.graph.modules, A)

    # 6) 认证权威前缀
    k = min(min(c.k for c in M.local_certs), M.authority_stable_horizon(A))
    J = M.mc.compose(M.local_certs, A, M.contract_status, R_gap)

    M.prev_A = A
    return u[:k], A, J, R_gap, joint_post
```

## 3. 推导

**引理 11（权威路由可行性）** 若安全模块的权威域包含 `α_s^min` 且 `𝒜` 的列和约束与 box 约束相交非空，则定义 257 的可行域非空。证明：取每列主导权交给安全模块、其余模块按 `A_m` 投影，列和可归一；变化率约束通过一阶滤波投影满足。

**引理 12（无扰切换的 Lipschitz 界）** 若模块命令有界 `‖u_m‖ ≤ U_max`，权威变化率 `‖α_t − α_{t−1}‖_∞ ≤ Δ`，则混合命令满足 `‖u_t − u_{t−1}‖ ≤ |M|·D·U_max·Δ + max_m‖Δu_m‖`。当 `Δ → 0` 时切换连续。

**引理 13（隔离的单调安全性）** 若隔离后安全模块权威下界满足 `α_s^min ≥ α_s(t−1)`，且被隔离模块不承担不可替代的安全职责，则 `κ_composed(M') ≤ κ_composed(M)`。直觉：移走一个模块只会减少可选权威，安全模块的下界抬高只会收紧可行域。

**定理 11（模块化组合安全）** 在 A-M1（模块图无环，或每个反馈环带收缩证书）、A-M2（契约精化 `Post_m ⊨ Pre_n`）、A-M3（逐列权威主导或安全兜底）、A-M4（人类命令可被安全过滤器截断）下，若 `∀m Valid(J_m)` 且 `contract_status = PASS`，则组合系统满足 `∧_m Post_m`，且 `R_gap ≤ τ_gap` 时每一维存在唯一可追溯的责任主体。

**定理 12（MASCOT 对 RAS 的严格包含）** 在定义 265 的退化参数下，MASCOT 的混合命令与 RAS 的 `λ_risk` 缩放等价；当 `D > 1` 时，存在 RAS 无法表达的权威分配（如「人控平移、机控力」），故 MASCOT 的可行策略集严格包含 RAS。

**定理 13（责任可追溯性）** 若 `R_gap = 0`，则每一控制维度存在 `α_{m,d} ≥ 1/2` 的主导模块；事故可归因到该模块的契约与命令，而非「系统整体」。这是共享控制伦理上可审计的必要条件。

## 6. 本轮最大风险

**一句话**：MASCOT 的组合安全定理依赖「模块图无环 + 契约精化 + 人类命令可截断」三个强假设，而真实共享控制中人类权威是不可建模、甚至可能对抗性的扰动，模块间又常出现循环依赖——于是系统可能**每个模块证书都有效、每条契约都 PASS，组合后的共享控制回路却不安全**，形成一个「被认证的责任真空」，这是本轮全部理论的核心脆弱点。

**次级风险与缓解**：
1. **循环依赖**：对反馈环强制要求收缩性证书；无证书则退化为端到端验证并禁止隔离重路由。
2. **人类不可建模**：把人类命令视为有界扰动，安全模块始终保留逐维否决权；`R_gap` 超阈值即强制澄清。
3. **契约伪造**：契约哈希 + 运行时签名，模块替换需重新组合证书。
4. **路由振荡**：变化率约束 + 滞回（hysteresis），避免权威在边界反复切换。
5. **计算开销**：QP 在嵌入式平台可能超 2ms；预计算可行域的顶点缓存，或降为 LP 松弛。

# 第 67 轮产物 · 创新点清单 v1：MASCOT（Modular Authority-Sharing COntrol with Typed contracts；MG×CT×AR×CM×QS×MC）

> 承接第 66 轮 IP-224~233（RAS：情绪驱动的闭环控制）。RAS 解决了「谁控制、何时控制、控制多少」，但它用**一个全局标量 `λ_risk`** 表达权威，无法处理「人控平移、机控力」这类逐维共享，也无法在模块失效时只隔离局部。本轮把「标量风险缩放」升级为「模块化权威路由」：**权威是可分配、可认证、可隔离的资源；模块带类型契约；情绪与故障只作为权威偏好先验。**
>
> IP 编号：IP-234~IP-243（共 10 个），全部为 MASCOT 的核心组件。

## 2. 形式化定义（完整版）

**定义 251（MASCOT 总览）** MASCOT 把 RAS 的「故障闭环」升级为「权威闭环」：
```
MASCOT = (MG, CT, AR, CM, QS, MC)
```
不变式：所有权威分配、契约检查、证书组合只在语义流；实时流只做命令混合、契约断言求值与权威早停，零学习写操作。

**定义 252（类型化模块与契约）** 模块 `m ∈ M` 的契约
```
C_m = (I_m, O_m, A_m, Pre_m, Post_m, κ_m)
```
其中 `I_m, O_m` 为带类型端口，`A_m ⊆ [0,1]^D` 为权威域，`Pre_m, Post_m` 为接口断言，`κ_m` 为局部风险上界。

**定义 253（模块图）**
```
MG = (M, E, T),  E ⊆ M×M,  T ∈ {∘, ⊗, μ}
```
`T` 分别为串行、并行、反馈组合算子。

**定义 254（权威矩阵）** `A_t = [α_{m,d}] ∈ [0,1]^{|M|×D}`，满足
```
∀d: Σ_m α_{m,d} = 1
```
集合含人类模块 `h`、安全模块 `s`、机器人规划模块 `p`；行和可小于 1（模块可弃权）。

**定义 255（共享命令）**
```
u_d(t) = Σ_m α_{m,d}(t)·u_{m,d}(t)
```

**定义 256（权威偏好）** 由 RAS 后验导出
```
b_{m,d} = g_m(P(H,E|face), P(H|ρ), d)
```
例：`b_{h,d}` 随恐惧后验单调上升，`b_{s,d}` 随几何故障后验单调上升。

**定义 257（权威路由优化）**
```
α* = argmax_{A∈𝒜} U_task(A) + β⟨A,B⟩ − γR_gap^τ(A)
```
`𝒜` = 列和约束 ∩ 权威域 ∩ 安全包络 `κ_s ≤ κ_max` ∩ 变化率 `‖α_t−α_{t−1}‖_∞ ≤ Δ`；`R_gap^τ = (1/D)Σ_d max(0, τ−max_m α_{m,d})` 为 hinge 光滑化。

**定义 258（责任真空）**
```
R_gap(A) = (1/D)·Σ_d 1[max_m α_{m,d} < 1/2]
```
`R_gap > τ_gap` 时触发权威澄清或安全模块兜底。

**定义 259（契约监控 / 接口漂移）** 运行时求值 `Pre_m, Post_m`；违约则 `H_interface = 1` 并标记 `quarantined`。

**定义 260（隔离与子图重路由）** `M' = M \ {m}`，在 `MG'` 上重解定义 257，并抬高安全模块下界 `α_{s,d} ≥ α_s^min`。

**定义 261（无扰权威切换）**
```
α_t = (1−η)α_{t−1} + ηα*_t,   ‖u_t − u_{t−1}‖ ≤ ε_b
```

**定义 262（模块化证书）**
```
J_MASCOT = ({J_m}_{m∈M'}, A*, contract_status, R_gap, authority_hash, composition_hash)
```
`Valid ⇔ ∀m Valid(J_m) ∧ contract_status = PASS ∧ R_gap ≤ τ_gap ∧ 权威在认证前缀内稳定`。

**定义 263（认证权威前缀）**
```
k*_MASCOT = min( min_{m∈M'} k*_m, k_stable )
```

**定义 264（权威故障假设）**
```
H_auth = {A0 正常, A1 迟滞, A2 冲突, A3 责任真空}
ℋ_MASCOT = ℋ_RAS × H_interface × H_auth
```

**定义 265（对 RAS 的包含关系）** 当 `D=1`、`α_h=α_s=0`、`α_p=1`、无契约隔离时，MASCOT 退化为 RAS 的风险缩放环节；`λ_risk` 是 MASCOT 的对角特例，MASCOT 严格更一般。

**定义 266（可组合安全）** 若 `∀(m→n)∈E: Post_m ⊨ Pre_n` 且 `T` 保序，则组合系统满足 `∧_{m∈M'} Post_m`。

## 3. 关键算法伪代码

```python
# IP-236 ARS：权威路由器
class AuthorityRouter:
    def __init__(self, D, beta=0.5, gamma=0.8, delta=0.15):
        self.D, self.beta, self.gamma, self.delta = D, beta, gamma, delta

    def build_preference(self, joint_post, face_gate):
        B = {}
        for m in self.modules:
            for d in range(self.D):
                B[m, d] = self._prior(m, d, joint_post, face_gate)
        return B

    def solve(self, modules, B, prev_A, safety_lb):
        obj = lambda A: -task_utility(A) - self.beta*inner(A, B) \
                        + self.gamma*self.soft_gap(A, tau=0.5)
        return convex_solver(obj, modules, prev_A, safety_lb, self.delta)

    def soft_gap(self, A, tau):
        return sum(max(0.0, tau - A[:, d].max())
                   for d in range(self.D)) / self.D


# IP-237 CM：契约监控
class ContractMonitor:
    def check(self, m, inp, out):
        if not (eval_assert(m.Pre, inp) and eval_assert(m.Post, out)):
            return {'module': m.id, 'H_interface': 1, 'action': 'QUARANTINE'}
        return {'module': m.id, 'H_interface': 0, 'action': 'PASS'}


# IP-238 QS：隔离 + 子图重路由
class QuarantineSupervisor:
    def isolate(self, graph, bad, router, B, prev_A):
        G2 = graph.without(bad)
        lb = {d: max(0.5, prev_A[graph.safety, d]) for d in range(router.D)}
        A2 = router.solve(G2.modules, B, prev_A, lb)
        return G2, A2


# IP-240 BAT：无扰切换
def bumpless_filter(A_new, A_prev, eta=0.3):
    return (1 - eta)*A_prev + eta*A_new


# IP-239 MC：模块化证书组合
class ModularCertificate:
    def compose(self, local_certs, A, contract_status, R_gap, tau_gap=0.25):
        valid = all(c.valid for c in local_certs) \
                and contract_status == 'PASS' \
                and R_gap <= tau_gap \
                and self._authority_stable(A)
        return {'valid': valid, 'A': A, 'R_gap': R_gap,
                'authority_hash': hash_matrix(A),
                'composition_hash': hash_contracts(local_certs)}


# IP-243 MASCOT 主循环
def MASCOT_round(M, obs):
    face_gate = M.erg_m.recognize(obs.img)
    rho = M.fir.signature(M.stage.split(M.residual_log))
    joint_post = M.efs.synthesize(rho, face_gate)

    B = M.ar.build_preference(joint_post, face_gate)

    for m in list(M.graph.modules):
        st = M.cm.check(m, m.last_in, m.last_out)
        if st['action'] == 'QUARANTINE':
            M.graph, _ = M.qs.isolate(M.graph, m, M.ar, B, M.prev_A)
            B = B.without(m)

    A = M.ar.solve(M.graph.modules, B, M.prev_A, M.safety_lb)
    A = bumpless_filter(A, M.prev_A)
    R_gap = M.rga.score(A)

    u = blend_commands(M.graph.modules, A)
    k = min(min(c.k for c in M.local_certs),
            M.authority_stable_horizon(A))
    J = M.mc.compose(M.local_certs, A, M.contract_status, R_gap)

    M.prev_A = A
    return u[:k], A, J, R_gap, joint_post
```

## 4. 推导

**引理 11（权威路由可行性）** 若安全模块权威域含 `α_s^min` 且列和约束与 box 约束相交非空，则定义 257 可行域非空。证明：逐列把主导权交给安全模块、其余模块向 `A_m` 投影后归一，变化率约束由滤波投影满足。

**引理 12（无扰切换 Lipschitz 界）** 若 `‖u_m‖ ≤ U_max` 且 `‖α_t−α_{t−1}‖_∞ ≤ Δ`，则
```
‖u_t − u_{t−1}‖ ≤ |M|·D·U_max·Δ + max_m ‖Δu_m‖
```
`Δ→0` 时切换连续。

**引理 13（隔离的单调安全性）** 若隔离后 `α_s^min ≥ α_s(t−1)` 且被隔离模块不承担不可替代的安全职责，则 `κ(M') ≤ κ(M)`。

**定理 11（模块化组合安全）** 在 A-M1（模块图无环或反馈环带收缩证书）、A-M2（`Post_m ⊨ Pre_n`）、A-M3（逐列权威主导或安全兜底）、A-M4（人类命令可被安全过滤器截断）下，若 `∀m Valid(J_m)` 且 `contract_status = PASS`，则组合系统满足 `∧_m Post_m`；且 `R_gap ≤ τ_gap` 时每维存在唯一可追溯责任主体。

**定理 12（MASCOT 严格包含 RAS）** 在定义 265 的退化参数下，MASCOT 混合命令与 RAS 的 `λ_risk` 缩放等价；`D>1` 时存在 RAS 无法表达的权威分配（人控平移、机控力），故 MASCOT 策略集严格包含 RAS。

**定理 13（责任可追溯性）** 若 `R_gap = 0`，则每维存在 `α_{m,d} ≥ 1/2` 的主导模块，事故可归因到该模块的契约与命令，而非「系统整体」。

## 6. 本轮最大风险

**一句话**：MASCOT 的组合安全定理依赖「模块图无环 + 契约精化 + 人类命令可截断」三个强假设，而真实共享控制中人类权威是不可建模、甚至可能对抗性的扰动，模块间又常出现循环依赖——于是系统可能**每个模块证书都有效、每条契约都 PASS，组合后的共享控制回路却不安全**，形成一个「被认证的责任真空」，这是本轮全部理论的核心脆弱点。

**次级风险与缓解**：
1. **循环依赖**：反馈环强制收缩性证书；无证书则退化为端到端验证并禁止隔离重路由。
2. **人类不可建模**：人类命令视为有界扰动，安全模块保留逐维否决权；`R_gap` 超阈值强制澄清。
3. **契约伪造**：契约哈希 + 运行时签名，模块替换需重新组合证书。
4. **路由振荡**：变化率约束 + 滞回，避免权威在边界反复切换。
5. **计算开销**：QP 可能超 2ms；预计算可行域顶点缓存或降为 LP 松弛。
