研究循环·灵感续轮（本轮灵感：「末端位姿」×「视觉感知」）

> **基线**：MetricVoiceGauge-NCD-HUTDH-v23 + IP-436–439（CESC 云边同步 / FSVC 少样本 / IPAM 知识产权 / HPC-E+ 四证门），其上承 v22 的 HDL/ACSC/DCSC/CFC++、v21 的 SDC/CAC/DCL/GIC，再下承 v20 的 PCA/CTS/HPC、v19 与 v17 全部模块。
> **本轮纪律**：**位姿是感知与行动之间唯一的接口；视觉是位姿假设的供应商，不是事实本身**。不推倒 v23：CESC/FSVC/IPAM/HPC-E+/HDL/ACSC/DCSC/CFC++ 全部保留。本轮只做一件事：**在 v23 四证门之上再加一层"位姿-视觉"闭环层（Pose-Vision Loop, PVL）**，把"机器人本体安全"升级为"末端位姿可信、视觉不确定性可标定、闭环时序可证伪"的任务级证书，并顺手封堵 v23 的最大风险（云边共振崩塌）——因为 PVL 是纯边端、在线、与云端版本链解耦的**独立安全锚**。

## 0. 直觉与动机

**灵感 1（末端位姿 → 安全的作用点其实在工具端，而不在机器人本体）**
直觉：v22 的 ACSC 证明"整条臂的构型无碰撞、能量可行"，v23 证明"版本一致、少样本覆盖、专利完备"，但都没有回答最要命的问题：**工具实际会到哪个 SE(3) 位姿？那个位姿是否既无碰撞、又恰好完成任务？** 末端位姿 `p=(R,t)∈SE(3)` 才是与世界发生物理交互的量。碰撞不发生在"关节角"上，而发生在"工具扫过的空间"里；抓取失败也不发生在"分类置信度"上，而发生在"工具没进到抓取位姿的容差内"。更反直觉的是：**位姿不确定度应当调制碰撞裕度，而不是全局膨胀**——位姿证书紧，工具扫掠体小，允许贴障；位姿证书松，扫掠体大，必须退让。这把 v21"自由空间只能被缺席证书**有偿赎回**"的同构思想，平移到"裕度只能被位姿证书**有偿收紧**"。核心创新：**末端位姿证书 EEPC**——一个带 `≥1-α` 覆盖保证的 SE(3) 测地球 `P̂={p:d_S(p,p̂)≤ε_pose}`，准入门要求 `P̂⊆G_task`（任务位姿包含）**且** `Swept(P̂)⊆Free_cert`（扫掠体落在已认证自由空间内）。这是一类全新谓词：**任务可达性 × 碰撞安全性**的联立，而非二者之一。

**灵感 2（视觉感知 → 位姿误差是视点/对称性相关的场，而不是标量）**
直觉：视觉 6D 位姿估计（直接回归或 PnP）的误差强烈依赖视点、纹理、光照与**物体对称性**。一个标量 `ε_pose` 是错的：圆柱绕自身轴可任意旋转而物理上无差别（连续对称 `C_∞`），杯子在把手朝向上有离散对称，弱纹理时沿视线方向的误差近似二次增长。更危险的是**多峰误差**：对称或弱纹理物体常出现"180° 翻转"——模型以极高置信度给出一个**整簇错误位姿**，而边际误差检验还会通过。核心创新：**位姿不确定性场 PUF + 对称商 conformal SQC**。用 conformal 把误差做成以视点 `v` 与类别 `c` 为条件的预测集（Mondrian 分箱）；用**任务条件对称群 `S_task`** 对 SE(3) 取商，在商空间上定义度量 `d_S(p,q)=min_{s∈S_task} d_SE3(p,q·s)`，使对称物体的证书既不过大（活性）也不漏掉任务相关的区分（把手朝向若影响抓取，则该翻转不在 `S_task` 中，必须被证书区分）。关键反直觉点：**对称性既是敌人也是解药**——错误的对称商会把"抓反了"当成"等价"（安全漏洞），正确的任务条件对称商则在保持安全的同时不因无关自由度而膨胀。

**灵感 3（视觉感知 → 闭环里最危险的错误是"持续的小错"，不是"偶发的大错"）**
直觉：视觉伺服是闭环。单帧位姿离群只造成一拍抖动，但一个**缓慢、持续、与指令运动同向的偏差**（相机-末端标定漂移、光照渐变、轮子打滑导致的里程计漂移）会让控制器"自信地"越走越偏，而每帧的边际误差看起来都在容忍范围内。v23 完全没有"位姿估计在时间上是否自洽"的概念。核心创新：**位姿时序一致性证书 TPCC**。把指令速度旋量 `ξ_cmd` 与实测位姿增量 `Δp_t=p̂_t⊖p̂_{t-1}` 在 se(3) 上作残差 `r_t=log(p̂_{t-1}^{-1}p̂_t)-ξ_cmdΔt`，用 conformal 分位数给 `‖r_t‖` 设界，并叠加 CUSUM 监测**累积漂移**；一旦越界，位姿证书即时**失效**（fail-safe：退回开环几何保守界或受控停机），绝不带着漂移继续伺服。关键反直觉点：**同一套 conformal 核换了 score 函数就能同时认证"检测框""位姿误差""时序创新"**——统一为"证据 = 分数 + 分位数 + 失效方向"的证书代数。

**三者如何统一**
统一为 v23 之上的 **位姿-视觉闭环层 PVL**：EEPC 回答"工具到哪、到了算不算完成任务"，PUF/SQC 回答"视觉给的位姿凭什么可信、对对称物体如何不重不漏"，TPCC 回答"闭环里这个位姿在时间上还成不成立"，TTCC 回答"以这个位姿，工具端离人到底还有多远"。共享状态扩展为 **`ζ_pvl = ζ_ce ∪ (P̂_t, U_pose(v,c), S_task, r_t, CUSUM_t, G_task, clear_t)`**。统一准入门 **HPC-E++ = (HPC-E+, EEPC, PUF-valid, TPCC, TTCC)** 六证一体。并且 TTCC 把 v22 的"本体人距上限"升级为"**工具端-人体**精距可证下界"——只在有证时收紧裕度，永不放宽。位姿证书是**带 TTL 的租约**，不是永久产权。

## 1. 研究问题（轮次升级版）

- **Q12（SE(3) 位姿证书与任务包含）**：如何在 SE(3) 上标定（加权）测地半径 `ε_pose` 使 `P(p*∈P̂)≥1-α`？任务目标域 `G_task`（抓取容差、插入轴对齐容差、交接朝向）如何从示教/任务规格规范化为 SE(3) 子集？位姿集的扫掠体 `Swept(P̂)` 如何用 **Lipschitz 杠杆界 / Minkowski 和**保守且不过度膨胀地包裹？

- **Q13（视觉位姿的条件覆盖与对称商）**：marginal conformal 的 `1-α` 覆盖在"给定视点/对称类"的**条件**下并不成立，视点分箱的 Mondrian conformal 如何逼近 conditional coverage、稀疏箱如何 fail-safe？任务条件对称群 `S_task` 如何由物体对称群与任务（把手朝向、插销方向）自动求交？商度量 `d_S` 在群平均/极小化下是否仍保 `1-α`，取商会否破坏可交换性？

- **Q14（闭环时序一致与漂移）**：如何在 se(3) 上定义考虑参考系搬运的创新残差 `r_t`（左不变 vs 右不变、body-fixed vs world-fixed）？CUSUM 与 conformal 分位数如何组合才能既抓突变又抓缓漂而不误报（低速静止段信噪比极低）？TPCC 失效时如何无缝退化为开环保守界而不引入控制振荡？

## 2. 设计原则（新增 P43–P45）

**P43 位姿证书即任务-安全联立律（Pose Certificate as Task–Safety Conjunction）**
EEPC 只在 `P̂ ⊆ G_task ∧ Swept(P̂) ⊆ Free_cert` 时签发。**位姿不确定性只允许有偿收紧**扫掠裕度：`released = max(0, ε_arm^default - ε_pose^effective)`，且收紧后仍需 `Swept_{base-released}(P̂) ⊆ Free_cert`；失效一律膨胀。视觉位姿假设**不得减少** `Obs_t`（与 P34 单调律一致）：视觉只能提供"目标在何处"的假设，不能提供"障碍不存在"的证据。故 `Exec_v24 = Exec_v23 ∩ Fil_pose ⊆ Exec_v23`。

**P44 任务条件对称商律（Task-Conditioned Symmetry Quotient）**
证书在商空间 `SE(3)/S_task` 上定义，`S_task = S_object ∩ Sym(Task)`。若某对称性改变任务结果（把手朝向决定能否抓、插销方向决定能否插），则它**不属于** `S_task`，必须被证书区分。**错误的对称商是安全漏洞，不是性能问题**：把任务相关翻转当成等价，等于给"抓反了"发合格证。对称群未知时回落到 `S_task={e}`（按完整 SE(3) 膨胀，偏保守但绝不误判等价）。

**P45 闭环创新有界律（Bounded Loop Innovation）**
位姿证书的时效性由 TPCC 守护：`‖r_t‖≤q_1-α ∧ CUSUM_t≤h` 是证书有效的前提；越界即失效并向保守退化。**位姿证书永远是"带 TTL 的租约"，不是"永久产权"**；静止/低速段以运动学下限豁免误报，但豁免本身不得解除 EEPC 的有效期约束。

## 3. 与基线的接口（如何退化）

- EEPC 失效（无位姿标定 / 任务域非法）⇒ 退回 v22 ACSC 的**构型级**证书（本体安全仍成立，任务精度不承诺）⇒ 等价 v22，⊆ v23；
- PUF 失效（视点未标定 / 分布外）⇒ `ε_pose=∞` 的保守扫掠体，或退回纯几何锚 ⇒ 比 v23 更保守；
- SQC 失效（对称群未知）⇒ `S_task={e}`，按完整 SE(3) 膨胀（对对称物体偏保守，但绝不误判等价）；
- TPCC 失效（创新越界 / CUSUM 报警）⇒ 位姿证书降级为**开环保守界**（停用视觉前馈），仍 ⊆ v23；
- TTCC 失效（工具端精距不可证）⇒ 回退 v22 本体人距上限；
- 全失效 ⇒ 完全回退 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`（引理 4 的延续）。
- **云边解耦（封堵 v23 风险）**：PVL 的校准集、分位数、对称库全部在**边端本地**维护，不依赖 CESC 版本链。当 `T_switch` 窗口内发生"分布剧变 + 云端断联"的共振时，CESC/FSVC 可能同时拒证，但 PVL 仍可独立签发**位姿-保守模式**证书（收紧扫掠、降低速度、收紧工具端精距阈值），把 v23 的"三重失效"降级为"位姿活性损失"而非"决策能力归零"。

## 4. 预期贡献

7. **末端位姿证书（EEPC）**：首次把 SE(3) 测地球证书与任务包含、扫掠体碰撞联立，给出"任务可达 ∧ 碰撞安全"的单一谓词；
8. **对称商 conformal（SQC）**：视点条件 Mondrian + 任务条件对称商的 conformal 位姿集，正面处理对称/弱纹理物体的"高置信错误位姿簇"；
9. **闭环创新证书（TPCC）**：把 conformal 从"单帧证据"扩展到"时序证据"，用创新界 + CUSUM 俘获缓漂，位姿证书 TTL 化；
10. **工具端精距证书（TTCC）**：把人体安全的作用点从本体移到工具端，给出 Minkowski 下界；只在有证时收紧裕度，永不放宽；
11. **封堵 v23 共振风险**：PVL 作为边端独立安全锚，云边崩溃时仍退化为位姿保守模式而非决策归零；
12. **六证一体 HPC-E++**：`Exec_v24 ⊆ Exec_v23` 闭环，安全继承方向不变。

## 5. 本轮最大风险

**一句话**：位姿证书的**边际** conformal 覆盖不等于**条件**覆盖——对对称/弱纹理物体，视觉位姿误差可呈多峰重尾，边际分位数可能以高置信度覆盖了"平均意义下的真值"却容许整簇错误位姿；一旦任务条件对称群 `S_task` 划错（把任务相关翻转误判为等价），机器人将以"持证"的方式抓空或在错误位姿上插入——即"位姿证书的边际覆盖幻觉"。

class SymmetryQuotientConformal:
    def __init__(self, alpha: float = 0.01, n_min: int = 30,
                 sym_resolver=None, sigma_t=1.0, sigma_r=1.0):
        self.alpha = alpha
        self.n_min = n_min                  # 每箱最少校准样本
        self.sym = sym_resolver             # (cls, task) -> S_task
        self.sigma_t, self.sigma_r = sigma_t, sigma_r
        self.bins: dict[tuple, list] = {}   # (view_bin, cls) -> [conformal score]
        self._radii: dict[tuple, float] = {}

    def _key(self, view, cls):
        return (self._view_bin(view), cls)

    def _view_bin(self, view):
        # 视点分箱：方位/仰角/距离三轴离散（如 12×4×3）
        az, el, dist = view
        return (int(az // 30), int(el // 30), int(np.log2(max(dist, 0.1))))

    def calibrate(self, samples):
        """samples: (p_hat, p_true, view, cls, task) 的标定集。"""
        for p_hat, p_true, view, cls, task in samples:

            self.bins.setdefault(self._key(view, cls), []).append(score)
        self._refit()

                self._radii[key] = float(np.quantile(scores, 1 - self.alpha))
            else:
                # 稀疏箱 fail-safe：用全局分位数再乘保守因子，绝不下探
                self._radii[key] = float(np.quantile(pooled, 1 - self.alpha)) * 1.5
        self._pooled_radius = float(np.quantile(pooled, 1 - self.alpha)) * 1.5

    def predict_set(self, p_hat, view, cls, task):
        S = self.sym.task_symmetry(cls, task)
        r = self._radii.get(self._key(view, cls), self._pooled_radius)
        return PoseBall(center=p_hat, radius=r, S_task=S,
                        sigma_t=self.sigma_t, sigma_r=self.sigma_r)


class PoseBall:
    """P̂ = {p : d_S(p, center) ≤ radius}，以 (center, radius, S_task) 隐式表示。"""
    def __init__(self, center, radius, S_task, sigma_t, sigma_r):
        self.center, self.radius, self.S_task = center, radius, S_task
        self.sigma_t, self.sigma_r = sigma_t, sigma_r

    @property
    def eps_t(self): return self.radius * self.sigma_t

    @property
    def eps_r(self): return self.radius * self.sigma_r

    def contains(self, p) -> bool:
        return d_S(p, self.center, self.S_task, self.sigma_t, self.sigma_r) <= self.radius


class TaskGoal:
    """任务目标域 G_task：以位姿容差 + 任务相关对称子群定义。"""
    def __init__(self, center, tol_t, tol_r, S_task):
        self.center, self.tol_t, self.tol_r, self.S_task = center, tol_t, tol_r, S_task

    def contains_set(self, P: PoseBall) -> bool:
        # P̂ ⊆ G_task 的充分条件：半径 + 中心偏离容差 ≤ 目标容差（商意义下）
        offset = d_S(P.center, self.center, self.S_task, P.sigma_t, P.sigma_r)
        return (P.radius * P.sigma_t) + offset * P.sigma_t <= self.tol_t + 1e-9 \
            and (P.radius * P.sigma_r) <= self.tol_r + 1e-9


# ============================================================
# IP-440 EEPC — 末端位姿证书（任务包含 × 扫掠碰撞）
# ============================================================
class EndEffectorPoseCertificate:
    def __init__(self, sqc: SymmetryQuotientConformal, tool, base_margin: float,
                 eps_arm_default: float, ttl: float = 0.2):
        self.sqc = sqc
        self.tool = tool                    # .points (N,3), .radius, .max_lever(L_tool)
        self.base_margin = base_margin
        self.eps_arm_default = eps_arm_default
        self.ttl = ttl

    def _swept_ball(self, P: PoseBall, released: float):
        """扫掠体的 Lipschitz 杠杆界：以工具在 p̂ 处的包围球 + 膨胀半径表示。"""
        inflation = P.eps_t + P.eps_r * self.tool.max_lever
        # 有偿收紧：只允许把 v23 的默认臂膨胀压到实测位姿不确定性
        effective = min(self.eps_arm_default, inflation + released)
        return (P.center, self.tool.radius + effective)

    def issue(self, p_hat, view, cls, task, free_cert, now):
        P = self.sqc.predict_set(p_hat, view, cls, task)
        # (1) 任务包含：P̂ ⊆ G_task
        if not task.G.contains_set(P):
            return None
        # (2) 有偿收紧：仅当 free_cert 在收紧后的扫掠体上仍成立
        released = max(0.0, self.eps_arm_default - (P.eps_t + P.eps_r * self.tool.max_lever))
        released = min(released, self.base_margin)
        center, swept_radius = self._swept_ball(P, released)
        if not free_cert.sphere_contains(center[:3, 3], swept_radius):
            # 收紧失败则退回不收紧（base_margin）再验一次
            released = 0.0
            center, swept_radius = self._swept_ball(P, released)
            if not free_cert.sphere_contains(center[:3, 3], swept_radius):
                return None
        # (3) 不得减少 Obs_t：视觉位姿只作"目标位姿"假设，不作自由空间证据
        return EEPCCert(P=P, swept=(center, swept_radius),
                        released=released, expires_at=now + self.ttl)


# ============================================================
# IP-442 TPCC — 位姿时序一致性证书
# ============================================================
class TemporalPoseConsistency:
    def __init__(self, alpha: float = 0.01, k: float = 0.05, h: float = 0.5):
        self.alpha, self.k, self.h = alpha, k, h
        self.innov_calib: list[float] = []
        self.cusum = 0.0
        self.valid = True

    def calibrate(self, innovations: list[float]):
        self.innov_calib = sorted(innovations)

    def _quantile(self):
        if not self.innov_calib:
            return 0.0
        return float(np.quantile(self.innov_calib, 1 - self.alpha))

    def update(self, p_prev, p_cur, xi_cmd, dt, is_static=False):
        r = se3_log(np.linalg.inv(p_prev) @ p_cur) - xi_cmd * dt
        nr = float(np.linalg.norm(r))
        # 静止/低速：以运动学下限豁免，避免信噪比过低误报
        if is_static and nr < self.k:
            self.valid = True
            return True, r
        q = self._quantile()
        self.cusum = max(0.0, self.cusum + nr - self.k)
        self.valid = (nr <= q) and (self.cusum <= self.h)
        if not self.valid:
            self.cusum = min(self.cusum, self.h)  # 防浮点residual堆积
        return self.valid, r


# ============================================================
# IP-443 TTCC — 工具端-人体精距证书
# ============================================================
class ToolTipClearanceCertificate:
    def __init__(self, required_clearance: float):
        self.required = required_clearance

    def lower_bound(self, eepec: 'EEPPCert', human_cert) -> float:
        p = eepec.P.center
        tool_pts = (p[:3, :3] @ eepec.tool.points.T).T + p[:3, 3]
        d0 = min_distance(tool_pts, human_cert.H_cert)        # 对认证人体集的最近距离
        v = eepec.P.eps_t + eepec.P.eps_r * eepec.tool.max_lever + human_cert.eps_h
        return max(0.0, d0 - v)

    def admits(self, eepec, human_cert) -> bool:
        return self.lower_bound(eepec, human_cert) >= self.required

# IP-444 HPC-E++ — 六证一体准入门
# ============================================================
@dataclass
class HPCEPlusPlus:
    hpc_e_plus: 'HPCEPlus'            # v23 四证门（几何∧规范∧负信息∧能量∧差距∧云边∧少样本∧IP）
    ee: EndEffectorPoseCertificate
    tpcc: TemporalPoseConsistency
    ttcc: ToolTipClearanceCertificate

    def admits(self, plan, obs) -> bool:
        # 1. v23 四证门
        if not self.hpc_e_plus.admits(plan, obs.x, obs.v, obs.z,
                                      obs.E_res, obs.margin_req, obs.modules):
            return False
        # 2. 位姿证书（PUF-valid 体现在 issue 内部：稀疏箱/分布外 → 半径保守或 None）
        cert = self.ee.issue(obs.p_hat, obs.view, obs.cls, obs.task,
                             obs.free_cert, obs.now)
        if cert is None:
            return False
        # 3. 时序一致性（TTL 租约）
        if not self.tpcc.valid:
            return False
        # 4. 工具端-人体精距
        if not self.ttcc.admits(cert, obs.human_cert):
            return False
        return True

## 2. 关键推导

**推导 A（扫掠体 Lipschitz 杠杆界）**：设 `P̂ = B_S(p̂, ε)`，即 `‖t-t̂‖≤ε_t=εσ_t` 且 `‖log(R^T R̂)‖≤ε_r=εσ_r`。工具点集 `Tool` 在末端系的包围球半径为 `r_tool`、旋转中心到最远点为 `L_tool`。对任意 `p∈P̂`、工具点 `x`：`‖T_p x - T_{p̂} x‖ ≤ ‖t-t̂‖ + ‖R-R̂‖·‖x‖ ≤ ε_t + ε_r·L_tool`。故 `Swept(P̂) ⊆ B(T_{p̂}⊛Tool, ε_t+ε_r·L_tool)`。⇒ 用单球 `sphere_contains` 即可保守判定，复杂度 O(1)。

**推导 B（有偿还收紧不越界）**：v23 的 ACSC 以 `ε_arm^default` 膨胀扫掠体。EEPC 令 `effective = min(ε_arm^default, ε_pose + released)`，且仅在 `sphere_contains(center, r_tool+effective)` 成立时签发。由于 `effective ≤ ε_arm^default` 且放行还需 free_cert 显式同意，所得可达位姿集 ⊆ v23 的 ACSC 可达集 ⇒ `Exec_v24 ⊆ Exec_v23`。若收紧失败则 `released=0`，退化为 `ε_pose` 膨胀（可能大于默认，则拒证）。

**推导 C（对称商不破坏可交换性）**：`d_S` 对 `S_task` 作用右侧不变：`d_S(p·s', q·s') = d_S(p,q)`。校准分数 `s_i=d_S(p*_i,p̂_i)` 仅依赖等价类，故在同一视点箱内仍可交换；经验分位数给出商空间上的 `1-α` 覆盖。若 `s∉S_task` 改变任务结果，则 `d_S(p,p·s)>0`，证书无法把二者判等——这正是任务条件子群的安全意义。

## 3. 复杂度分析

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|

| SQC 预测集 | O(1) 查表 + O(\|S_task\|) | O(视点箱×类别) | 12×4×3 箱 |
| EEPC issue | O(1)（Lipschitz 球包含） | O(1) | L_tool, ε_arm |

## 4. 正确性论证

### 引理 5（EEPC 覆盖与任务-安全联立）
**陈述**：若 PUF 在同视点箱内校准且 `S_task` 正确，则 `P(p*∈P̂) ≥ 1-α`；在 `P̂⊆G_task ∧ Swept(P̂)⊆Free_cert` 下执行任一 `p∈P̂`，则**无碰撞且任务达成**的联合概率 ≥ `1-α - Σα_i`（多证书取并集界）。

**证明**：Mondrian conformal 在每箱内以可交换性给 `1-α` 边际覆盖；扫掠体由推导 A 的 Lipschitz 界保守包裹，`Free_cert` 是 v23 认证自由空间；`P̂⊆G_task` 由 TaskGoal.contains_set 判定。条件于覆盖事件，碰撞与任务均成立；多证书用并集界。∎

### 引理 6（任务条件对称商：不误等价、保覆盖）
**陈述**：`S_task=S_object∩Sym(Task)` 下，`d_S` 保持可交换性并给出商空间 `1-α` 覆盖；且对任意 `s∉S_task`，若 `s` 改变任务结果，则 `d_S(p,p·s)>0`，证书不会把二者判为等价。

**证明**：由推导 C 的右不变性与子群构造；反证：若证书判等则 `d_S=0`，即 `∃s'∈S_task: p·s=p·s'`，与 `s∉S_task` 且任务区分矛盾。∎

### 引理 7（闭环创新界抑制漂移且失效安全）
**陈述**：若对所有 `t` 有 `‖r_t‖≤q` 且 `CUSUM_t≤h`，则视觉前馈导致的累计位姿偏差被 `(q,h,k)` 界约束；一旦越界 TPCC 失效、EEPC 停发，执行集单调收缩（fail-safe）。

**证明**：单边 CUSUM 递推 `CUSUM_t=max(0,CUSUM_{t-1}+‖r_t‖-k)` 度量累计超额创新；阈值 `h` 限定累积漂移上界。越界使 `tpcc.valid=False`，HPC-E++ 拒证，退回开环保守/停机，`Exec` 只减不增。∎

### 引理 8（六证单调退化链）
**陈述**：任意单点/组合失效下 `Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18` 恒成立。

**证明**：EEPC/PUF/TPCC/TTCC 均为连言过滤器；失效即移除该证或膨胀扫掠（只减不增可达集）；收紧由推导 B 限制在 `ε_arm^default` 与 `Free_cert` 之内；云边崩溃时 PVL 退化为位姿保守模式，仍 ⊆ v23。组合失效取交。∎

### 定理（HPC-E++ 六证准入门完备性）
**陈述**：`HPCEPlusPlus.admits(π)=True` ⟺ π 同时满足：(1) v23 全部四证（物理接地/规范/负信息/能量/差距/云边/少样本/IP）；(2) 末端位姿以 `≥1-α` 落在任务域且扫掠体落于已认证自由空间；(3) 位姿不确定性按视点/对称类标定有效；(4) 闭环位姿时序自洽；(5) 工具端-人体精距达阈。

**证明**：由 `admits` 的五个连言分支与引理 5–8 直接可得；必要性与充分性分别对应每张证书缺失时的风险面。∎
