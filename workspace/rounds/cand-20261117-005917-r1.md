# 第 11 轮（新灵感循环第 3 轮；本轮灵感：「技术融合」×「用户测试」）

> **基线**：第 10 轮 MetricVoiceGauge-LRC（定义 540–549；引理 87–93；实验 E571–E590）。
> 本轮纪律：**融而只紧 + 异源可证伪 + 外证优先**。两个灵感各治 v10 的一处残债——「技术融合」治**紧度债**（v10 的 L0 只用单一最坏运动学包络与固定膨胀 `r_o`，障碍密集时过松，直接制造 K=1 性能债），「用户测试」治**自证债**（v10 的紧度与排行榜都在系统内部自我标定，缺少外部真值，因而无法发现“所有模态一致地错”的共同因失效）。仍以中立元退化保证：FGF 失效退回 v10 LWC，UFL 失效冻结在“最近一次通过证伪的级别”，MIL 失效退回并集，全失效退回 v10→v9→v8→v7→v6。

## 0. 直觉与动机

**灵感 1（技术融合 → 异源输入融合，把硬界的最坏包络收紧而非放宽）**
直觉：v10 的第一性原理是“先用模型无关的硬界兜底”。但它的硬界其实非常粗：`v∈[0,v_max]`、`a∈[a_min,a_max]` 是全局最坏包络，障碍膨胀 `r_o` 是一个固定值。它不是“物理上最紧的硬界”，而是“最不依赖任何传感器的硬界”。技术融合的第一性原理不是“多接几个传感器然后更信学习模型”，而是 **不同物理原理的独立测量能以各自可证明的误差界去收窄同一批硬界输入**：轮式编码器/接触开关给出更紧的 `v`、`a` 包络（滑移由接触传感器上界），结构化光 + LiDAR + 深度给出更小的障碍外扩（在各自覆盖假设内），IMU 检测未建模接触。关键在于 **融而只紧**：融合只能把 v10 的硬界往“更紧但仍保守”的方向推，任何一致性冲突都退回 v10 的最坏包络。于是紧度债不是靠“更信模型”还，而是靠“更多独立的物理证据”还。核心创新：**融合证书器（FusionCertifier, FC）** 与 **模态独立性账本（Modality Independence Ledger, MIL）**。

**灵感 2（用户测试 → 用外部、对抗、预注册的证伪替代内部自证）**
直觉：v10 的自证债是结构性的——L0 的松紧由手调、排行榜的成对比较来自同一个可能失配的前向模型。系统内部再精巧，也无法证明“自己没骗自己”。用户测试的第一性原理不是“找人打分”，而是 **把用户当作分布外对抗采样器 + 唯一的外部真值**：用户在真实任务里做出的、设计者没预料到的行为，恰好是对“所有模态一致地错”这类共同因失效唯一有检测力的探针。为了避免把用户测试做成走过场（Goodhart），它必须是 (i) 留出（held-out）且预注册，(ii) 对抗采样（专挑跨模态欺骗场景），(iii) 用 anytime 有效的 e-过程做否决，从而允许“边跑边看”而不膨胀误否率。核心创新：**用户证伪账本（User Falsification Ledger, UFL）** 与 **对抗性用户采样器（Adversarial User Sampler, AUS）**。

**灵感 3（合成：证伪门控融合）**
直觉：技术融合让系统“更敢紧”，用户测试让系统“更容易被推翻”。二者相乘正好补上 v10 的闭环缺口：**融合只能提出更紧的候选级，用户证伪才能批准它**。于是运行期规则是“取最紧的、既通过跨模态一致性、又未被用户试验否决的级；否则退回 v10 硬界”。这把 v10 的“自证”改成“他证”：学习/融合永远只能提出，外部证据才能处置。同一份用户试验还顺带为 v10 的 RankLedger 提供**外部成对标签**（用户接地排行榜 UGR），直接拆掉 v10 自陈的最大风险——“比较来自同一个失配模型”。核心创新：**证伪门控融合（Falsification-Gated Fusion, FGF）**。

## 1. 研究问题（轮次升级版）

- **Q1（融合的可靠性与紧度）**：如何用一批异质模态在保持确定性硬界兜底的前提下收紧 L0？同时有效性的 α 预算、union bound、模态相关性与浮点余量如何统一核算，使“宣称的紧度增益”可审计？
- **Q2（共同因的可检测性）**：一致性残差在什么意义上能零假阳性地证伪“至少一个模态失效”？当所有模态同向一致地错（相关失效）时，需要多少外部用户试验、覆盖到什么场景，才能把检测时延压到可接受？
- **Q3（外证的统计有效性）**：预注册 + 对抗采样 + e-过程的用户证伪，能否在允许随时查看的条件下把误否率控制在 ≤δ，并把“未被否决”诚实地换算成有界的残余风险？FGF 的最坏情形是否严格等价 v10？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 融而只紧律（Fuse-to-Tighten-Only）**
融合只作用于硬界的**输入包络**，且只能收紧：更紧的 `v/a` 上界、更小的障碍外扩 `r_o`、更早的接触检出。每一级融合必须有独立的 α 预算与 union bound 保险。任何跨模态一致性冲突（Φ>0）⇒ 立即退回 Tier0（v10 确定性硬界）。融合绝不能放宽任何下界。

**P17 外证优先律（External-Falsification-Only-Promotion）**
任何比 Tier0 更紧的级，只有在通过预注册的留出用户试验（e-过程未否决）且覆盖账本已覆盖当前场景时才可启用。内部指标（前向模型、排行榜、自评覆盖率）无权晋升级别——只能提出候选，不能裁决。

**P18 相关即合并律（Correlation-Merge）**
当 MIL 估计的模态失效相关超过 `ρ_max`，相关模态在 union bound 与紧度增益主张中合并为单一超模态（取并集、放弃 1/m 增益），并在一致性检测中降权——宁可少紧，不可虚紧。

## 3. 与基线的接口（如何退化）

- FGF 无任何 admissible 统计级 ⇒ Tier0 = v10 LWC 的 L0 硬界（确定性保守）；
- UFL 不可用 / 无新试验 ⇒ 冻结在“最近一次未被否决的级”，不晋升；
- MIL 判定相关/不可信 ⇒ 该对模态合并为并集，禁用融合增益主张；
- 一致性 Φ>0 ⇒ 该块退回 Tier0，并记一次“共同因疑似”事件供 AUS 采样；
- FC 整体不可用 ⇒ 退回 v10 LWC（L0/L1/L2）；
- 再沿 v10 七级链：LWC 失效→v9 AC；RL 失效→v9 绝对评分；LCC 失效→v9 EDF；v9 失效→v8→v7→v6。

## 4. 预期贡献

1. **融合证书**：异源、只紧、带 α 预算的硬界收紧，熟悉域 L0 通过率与 K=1 回退率同时改善，且最坏情形严格退回 v10；
2. **一致性证伪**：`Φ>0` 是零假阳性的单侧证伪器，配合 MIL 给出“何时可宣称紧度增益、何时必须合并降权”的可审计规则；
3. **用户证伪闭环**：预注册 + 对抗采样 + e-过程，把“外部真值”变成可统计、可随时停、误否有界的运行时对象；UGR 为 v10 排行榜提供外部成对标签；
4. **四账本闭环**：融合账本（FC/MIL）、外证账本（UFL/USC）、排序账本（RL+UGR）、退化账本（FGF）；E591–E610 覆盖紧度、证伪效力、退化等价与端到端任务。

## 5. 本轮最大风险

**一句话**：整个方案的安全上限由“用户试验对相关失效的检测功效”决定——若对抗采样覆盖不到某类共同因失效（例如同一标定漂移同时污染所有深度类模态），一致性检测会给出一致而非冲突的假象，e-过程又因覆盖不足而长期无法否决，于是融合会以“已被外部验证”的名义把系统锁死在一个一致地错、且越来越紧的证书上。

# 第 11 轮产物 · 创新点清单 v11：**MetricVoiceGauge-UFC**（User-Falsified Convergence）

> 背景：第 10 轮 MetricVoiceGauge-LRC（定义 540–549；引理 87–93；实验 E571–E590）。
> 本轮灵感：「技术融合」×「用户测试」
> **继承纪律**：MetricVoiceGauge 九不变式（CVC-闭环、SpatialCert、RT-CVC、FaultCert、PrimitiveGraph、严格退化链、OTL、GCT、ER）与 v10 的 LWC/RL/LCC/LightweightGuard 全部保留。新增组件一律为**可选增强**：任一环节不可用 ⇒ 注入中立元，严格退回 v10 行为，而非行为漂移。

## 1. 符号体系增量（定义 550–559）

| 符号 | 含义 |
|---|---|
| `M = {1..m}` | 异质证书模态集合（编码器、接触、LiDAR、结构化光、深度、IMU…） |
| `[ℓ_{i,k}, r_{i,k}]` | 模态 i 在第 k 步对“最近障碍间隙”给出的双侧区间 |
| `[e^lo_{i,k}, e^hi_{i,k}]` | 模态 i 在第 k 步对“最大力矩/执行器应力”给出的双侧区间 |
| `W_τ ⊆ M` | 第 τ 级融合所用的活跃模态子集（`W_0 = ∅` 即 Tier0 硬界） |
| `α_i, α_τ` | 模态 i 的失效概率预算 / 第 τ 级的合并预算 |
| `Φ` | 一致性残差（定义 551），`Φ>0` ⇒ 至少一模态失效 |
| `ρ̂_ij, ρ_max` | 失效事件相关估计 / 允许相关上限 |
| `g̃_τ, ẽ_τ` | 第 τ 级融合给出的间隙下界 / 力矩上界 |
| `u_i, v_i` | 用户试验的观测结局 / 系统预注册主张 |
| `M_t^{(τ)}` | 对第 τ 级的 e-过程（定义 553） |
| `δ, λ_s` | e-过程误否预算 / 可预测下注系数 |
| `USC` | 用户场景覆盖账本（定义 555） |
| `≺_tier` | 按“紧度”排序的级别全序（越紧越靠前） |

**新增定义 550（异质证书模态 Heterogeneous Certificate Modality）** 每个模态 `i∈M` 对**同一功能**（最近障碍间隙 `g_k`、最大力矩 `e_k`）给出双侧区间，并声明其有效性类型：
```
hard:  ℓ_{i,k} ≤ g_k ≤ r_{i,k}  (确定性，模型无关)
soft:  P(∀k: ℓ_{i,k} ≤ g_k ≤ r_{i,k}) ≥ 1 − α_i  (统计，依赖标定/覆盖假设)
```
间隙用下界收紧（越小越保守），力矩用上界收紧（越大越保守）。`soft` 模态的 `α_i` 只在其自身假设（标定不变、无 OOD）下成立，这是后面共同因风险的根源。

**新增定义 551（融合区间与一致性残差 Fused Interval & Consistency Residual）** 对活跃集 `W`，定义
```
g̃(W) = min_k max_{i∈W} ℓ_{i,k} − ε_ulp
ẽ(W) = max_k min_{i∈W} e^hi_{i,k} + ε_ulp
Φ(W) = max_{k} max{ max_{i∈W} ℓ_{i,k} − min_{i∈W} r_{i,k},
                   max_{i∈W} e^lo_{i,k} − min_{i∈W} e^hi_{i,k} }
```
`Φ(W) > 0` 表示至少一对区间在工作点上不相交。**Tier0** 取 `W_0=∅`，即 v10 的确定性 L0（引理 87）；`Tier τ≥1` 取 `W_τ`，其可靠性是统计的（引理 94）。

**新增定义 552（模态独立性账本 MIL）** 在带真值/已知结局的残差流上估计失效事件相关性：令 `E_i` 为模态 i 的区间在整块内未含真值的事件，取其代理指示 `ê_i = 1[残差超过 i 的保守阈值]`，
```
ρ̂_ij = corr( ê_i , ê_j )
```
`ρ̂_ij ≤ ρ_max` ⇒ 该对可参与“独立收紧增益”主张；否则标记为相关：在 union bound 与紧度增益中把相关模态集**合并为一个超模态**（区间取并集，`α` 相加，放弃 `1/m` 增益），并在 `Φ` 检测中降权（防“同向一致”被误判为一致）。

**新增定义 553（用户证伪检验与 e-过程 User Falsification Test）** 一次用户试验 `t` 给出 `(任务, 操作者, 观测结局 y_t, 预注册主张 τ, α_τ)`。定义违反指示 `V_t^{(τ)} = 1` 当且仅当第 τ 级的“违反率 ≤ α_τ”主张被这次试验反驳（如：证书判定安全却发生碰撞/不安全事件）。对每个级维护 e-过程
```
M_0^{(τ)} = 1,   M_t^{(τ)} = M_{t-1}^{(τ)} · (1 + λ_t (V_t^{(τ)} − α_τ)),   λ_t ∈ [0, 1/α_τ] 可预测
```
当 `M_t^{(τ)} ≥ 1/δ` 即**否决**该级（Ville 不等式，引理 97）。主张与 `α_τ` 必须在试验前冻结（预注册），否决后该级被移出 admissible 集，只在新的预注册批次通过后才可能复级。

**新增定义 554（对抗性用户采样器 AUS）** 在预注册场景分类（taxonomy）上定义采样策略 `q`，目标是在覆盖约束下最大化对当前级的期望证伪信息：
```
q* ≈ argmax_q  E_q[ log M_{t+1}^{(τ)} − log M_t^{(τ)} ]
      s.t.  q(cell) ≥ n_min  ∀cell ∈ taxonomy
```
必备欺骗场景族：透明玻璃（深度失效、LiDAR 尚可）、镜面/反光（LiDAR 失效）、黑色吸光（深度与 LiDAR 同向失效）、强遮挡、快速非专家操作、重复抓放。AUS 既服务 UFL 的证伪，也把 `Φ>0` 事件序列作为主动学习信号。

**新增定义 555（用户场景覆盖账本 USC）** 维护覆盖向量 `c: taxonomy → 已试行数`。只有当 `c(cell) ≥ n_min` 时，`cell` 才算“已覆盖”。**未覆盖场景**下不允许主张任何统计级，只允许 Tier0 硬界——把“未测不宣称”落成硬约束。

**新增定义 556（证伪门控融合 FGF）** 运行期按紧度从紧到松选择
```
admissible(τ) ⇔ (τ ∉ Falsified) ∧ (Φ(W_τ) ≤ 0) ∧ USC.covers(state) ∧ MIL.ok(W_τ)
τ* = argmin_{τ∈Tiers, admissible(τ)} rank_tightness(τ)   # 最紧者
若无 admissible 的 τ≥1 ⇒ τ* = 0 (Tier0 确定性硬界)
```
`Falsified` 只增不减；`τ*` 的证书才被允许进入 v10 的块选择/执行流程。

**新增定义 557（融合增益与 α 预算 Fusion Gain & Risk Budget）** 定义融合增益
```
Γ(W) = E[width(L0_Tier0)] / E[width(g̃(W))]
```
仅在 `Γ(W) ≥ Γ_min` 且 `Σ_{i∈W} α_i ≤ α_budget` 且 MIL 通过时，才为第 τ 级登记“可宣称增益”。否则该级仍可运行但按 Tier0 日志记账（不算创新收益）。

**新增定义 558（用户接地排行榜 UGR）** 当用户试验能观测两组动作的结局差（执行块 vs 影子块/回放候选）时，产出外部成对标签 `y_ext∈{0,1}`。UGR 把它注入 v10 RankLedger 的成对比较：
```
observe(winner, loser) 用 y_ext 优先；仅当模型比较与 y_ext 一致时才混合，冲突时外部优先
```
外部标签稀疏，故 UGR 只做校正/覆盖，不替代 v10 的模型比较；但它直接降低“比较来自同一个失配模型”的相关性。

**新增定义 559（校准间隙再验证 Calibration-Gap Revalidation）** 记录预注册成功概率 `P̂` 与用户观测成功率 `P_obs`，定义
```
Δ_cal = |P̂ − P_obs|
```
若 `Δ_cal > γ_cal`，对被检验级执行 α 膨胀（`α_τ ← min(1, α_τ·κ)`），主动降级直至再验证通过——把“说得好听”折算成“更保守”。

```python
# IP-361 FusionCertifier：融而只紧，冲突即退回 Tier0
class FusionCertifier:
    def __init__(self, hard, mods, alpha_budget=0.05, rho_max=0.3,
                 eps_ulp=1e-6, gamma_min=1.15):
        self.hard, self.mods = hard, mods          # hard = v10 L0（确定性）
        self.alpha, self.rho_max = alpha_budget, rho_max
        self.eps, self.gamma_min = eps_ulp, gamma_min
        self.mil = ModalityIndependenceLedger(rho_max)

    def fusion_set(self, tier):
        return TIERS[tier].W                      # 由 LCC 类静态表定义

    def consistency(self, ints, W):
        phi = 0.0
        for k in range(ints.n_steps):
            phi = max(phi,
                      max(ints.lo(i, k) for i in W) - min(ints.hi(i, k) for i in W),
                      max(ints.e_lo(i, k) for i in W) - min(ints.e_hi(i, k) for i in W))
        return phi

    def certify(self, state, actions, tier):
        hard = self.hard.level0(state, actions)    # Tier0 永远可用（引理 87）
        if tier == 0:
            return hard, True
        W = self.fusion_set(tier)
        if not self.mil.ok(W):
            return hard, False                     # 相关/不可信 ⇒ 只信硬界
        ints = self.intervals(state, actions, W)
        if self.consistency(ints, W) > 0.0:
            return hard, False                     # Φ>0：至少一模态失效（引理 95）
        g = min(max(ints.lo(i, k) for i in W) for k in range(len(actions)))
        e = max(min(ints.e_hi(i, k) for i in W) for k in range(len(actions)))
        return Cert(g - self.eps, e + self.eps, tier=tier), True


# IP-363 UserFalsificationLedger：预注册 + anytime e-过程
class UserFalsificationLedger:
    def __init__(self, alpha, delta=1e-3):
        self.alpha, self.delta = alpha, delta
        self.M, self.falsified = {}, set()

    def observe(self, tier, violated, lam):
        m = self.M.get(tier, 1.0)
        m *= (1.0 + lam * (1.0 if violated else 0.0) - lam * self.alpha)
        self.M[tier] = m
        if m >= 1.0 / self.delta:                  # Ville：误否 ≤ δ（引理 97）
            self.falsified.add(tier)
        return m


# IP-365 FalsificationGate：取最紧且 admissible 的级
class FalsificationGate:
    def __init__(self, certifier, ufl, usc, tiers):
        self.cert, self.ufl, self.usc, self.tiers = certifier, ufl, usc, tiers

    def select(self, state, actions):
        for tier in sorted(self.tiers, key=lambda t: t.tightness):  # 由紧到松
            if tier.id == 0:
                break
            if tier.id in self.ufl.falsified:
                continue
            if not self.usc.covers(state, tier.id):
                continue                            # 未覆盖 ⇒ 不晋升
            cert, ok = self.cert.certify(state, actions, tier.id)
            if ok:
                return cert, tier.id
        return self.cert.certify(state, actions, 0)[0], 0   # Tier0 兜底


# IP-364 AdversarialUserSampler（覆盖约束下最大化证伪信息；贪心近似）
class AdversarialUserSampler:
    def sample(self, tier, taxonomy, n_min, n):
        cells = [c for c in taxonomy if self.count[c] < n_min]
        if cells:                                  # 先补覆盖空洞
            return [self.draw(c, tier) for c in cells][:n]
        return [self.argmax_log_growth(tier) for _ in range(n)]


# 主闭环集成：MetricVoiceGauge-UFC
def metricvoicegauge_round_11(M, s, obs, modalities, user_trials, ...):
    gate = FalsificationGate(certifier, ufl, usc, tiers)

    # ---- 5Hz 块边界：FGF 选级 + v10 LWC/RL 选块 ----
    if current_chunk is None or current_chunk.exhausted:
        feasible = []
        for cand in policy.sample_sequences(ctx.state, K_max, n=64):
            cert, tier = gate.select(ctx.state, cand)
            if cert.valid(ctx.state) and abort_points(ctx.state, cand):
                feasible.append(Feasible(cand, cert, tier))
        current_chunk = rank_ledger.select(feasible) if feasible else \
                        single_step_fallback(ctx.state)

    # ---- 50Hz 轻量守卫：Tier0 硬界 + 一致性冲突检测 ----
    verdict, k_next = lightweight_guard(current_chunk, k_exec, live_obs)
    if verdict == 'abort':
        current_chunk.execute_safe_stop_at(k_next); current_chunk = None
    else:
        execute(current_chunk.actions[k_next])

    # ---- 外证回灌（低频）：UFL 否决 / MIL 相关 / UGR 外部比较 ----
    for trial in user_trials.drain():
        ufl.observe(trial.tier, trial.violated, lam=trial.lam)
        mil.update(trial.residuals)
        if trial.pairwise is not None:
            rank_ledger.observe_external(*trial.pairwise)   # IP-366 UGR
    return M.inherited_v9_path(ctx)
```

## 3. 推导

**引理 94（融合下界的可靠性）** Tier0 由引理 87 确定性保守。对融合级 `W`，若每个模态 `i` 在其自身假设下以概率 `≥1−α_i` 同时包含整块真值，则
```
P( g̃(W) ≤ g_min ) ≥ 1 − Σ_{i∈W} α_i
```
证明：令 `E_i` 为模态 i 的区间在块内某处未含真值。在 `∩E_i^c` 上 `∀i,k: ℓ_{i,k} ≤ g_k`，故 `max_i ℓ_{i,k} ≤ g_k`，再对 k 取 min 得 `≤ g_min`，减 `ε_ulp` 仍 `≤`。故失效 ⊆ `∪E_i`，由 union bound 得结论。**该界不要求模态独立**——独立性只影响紧度增益与共同因可检测性。∎

**引理 95（一致性残差的零假阳性与共同因盲区）** `Φ(W)>0` ⇒ 至少一个模态的区间在块内未含真值；反之若所有区间同时有效则 `Φ(W)≤0`。故 `Φ>0` 对“全有效”假设是**零假阳性**的单侧证伪。但它对“所有模态同向一致地错”（存在共同因 `C` 使 `ℓ→ℓ+δ, r→r+δ`）无检测力，此时区间仍重叠、`Φ≤0`。证明：全有效 ⇒ 每区间含 `g_k` ⇒ `max ℓ ≤ g_k ≤ min r` ⇒ `Φ≤0`；同向平移不改变 `max ℓ − min r`，故可不触发。∎

**引理 96（融合紧度增益）** 设模态 i 的保守余量 `e_i = g − ℓ_i ≥ 0` 独立，尾分布 `P(e_i > x)=exp(−x/μ_i)`。则融合余量 `e_(1)=min_i e_i` 服从指数分布，参数 `Σ 1/μ_i`，当 `μ_i=μ` 时 `E[e_(1)] = μ/m`，即过保守宽度按 `1/m` 收缩；当两模态相关 `ρ→1`（同向），`e_(1)` 退化为单模态，增益 `→1`。故 `Γ(W)` 只在 `ρ̂≤ρ_max` 时可宣称（P18）。证明：指数分布最小值参数为各率之和；正相关使“最小值”不再来自独立样本。∎

**引理 97（用户证伪 e-过程的 anytime 有效性）** 对可预测 `λ_t∈[0,1/α_τ]`，`M_t^{(τ)}` 非负且在 `P(V_t=1)≤α_τ` 下满足 `E[M_t | F_{t-1}] ≤ M_{t-1}`，即为上鞅，`E[M_t]≤1`。Ville 不等式给出 `P(∃t: M_t ≥ 1/δ) ≤ δ`。故“任意时刻查看、达阈值即否决”仍把误否率控制在 `δ` 内，无需 Bonferroni 修正。∎

**引理 98（证伪时延与采样覆盖的对偶界）** 设真实违反率 `α_τ+Δ`，单步对数增长近似
```
E[log(1+λ(V−α_τ))] ≈ λΔ − ½λ²α_τ(1−α_τ)
```
最优 `λ* = Δ/(α_τ(1−α_τ))`，最大增长率 `≈ Δ²/(2α_τ(1−α_τ))`，故达到 `1/δ` 的期望试验数
```
T ≈ (2α_τ(1−α_τ)/Δ²)·log(1/δ)
```
若 AUS 对致因失效场景的覆盖为 `c`，有效 `Δ_eff ≈ c·Δ`，于是 `T ∝ 1/(c²Δ²)·log(1/δ)`。**覆盖越低、失效越隐蔽、否决越慢**——这是最大风险的定量来源。∎

**引理 99（FGF 的单调退化与最坏情形等价 v10）** FGF 的 `τ*` 必满足：`τ*=0` 或（一致 ∧ 未否决 ∧ 已覆盖）。否决集 `Falsified` 单调增长；每次否决至多把 `τ*` 降一档且不可自动回升（需新预注册批次）。级数有限，故退化终止于 Tier0。Tier0 = v10 L0，其后仍走 v10 的 LWC→…→v6 链，故最坏情形行为与 v10 逐位一致。`Φ>0` 只触发退回 Tier0（安全方向），不影响健全性。∎

## 8. 本轮最大风险

**一句话**：整个方案的安全上限由“用户试验对相关失效的检测功效”决定——若对抗采样覆盖不到某类共同因失效（例如同一标定漂移同时污染所有深度类模态），一致性检测会给出一致而非冲突的假象，e-过程又因覆盖不足而长期无法否决，于是融合会以“已被外部验证”的名义把系统锁死在一个一致地错、且越来越紧的证书上。
