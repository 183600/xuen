# 第 4 轮（灵感循环第 4 轮；本轮灵感：「研究空白」×「多机协同」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 1/2 轮 LeanGauge / ToolGauge 骨架继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。两个新灵感各沿一条轴升级：一条把「盲区」从几何可见性升级为**证据认知缺口**，一条把单机修复升级为**带来源与独立性的舰队协同**；任一环节不可用都可一键退回 InstructGauge。

## 0. 直觉与动机

**灵感 1（研究空白 → 把「看不见」升级为「不知道」）**
直觉：前几轮的盲区是**几何遮挡**——看得见还是看不见。但一个区域「可见」并不等于「我们知道它」：可能没有任何机器人持有它当前、可追溯、可交叉验证的证据。真正的「研究空白」是**证据层面的缺口**，而不是像素层面的空洞。它至少由四种缺失构成：**没有证据（missing）**、**证据互相冲突（conflicting）**、**证据过期（stale）**、**证据来源不可信（provenance-invalid）**。把「研究空白」做成可度量、可出证的一阶对象，是本轮第一根轴。关键纪律：**缺口本身也要有证书**——「为什么我们认为这里是缺口」，否则系统会把「我没查」误报成「这里没有东西」。

**灵感 2（多机协同 → 分布式证据获取，但证据带来源与相关性）**
直觉：多机最大的收益是互相填补证据缺口；最大的风险不是通信带宽，而是 **evidence laundering（证据洗白）**——A 的一次接地错误被 B 引用后变成舰队共识；尤其当 A、B 共享同一模型、同一视角、同一失效模式时，「多数同意」只是**同一个错误的多次拷贝**。因此协同不能被建模成「投票」，而必须被建模成**带来源链、带独立权重、带跨机校准、带证据隔离**的分布式证据聚合。

**灵感 3（耦合 → 假填空与假缺口同时被放大）**
直觉：多机 + 缺口检测会把两类错误都放大：**假填空**（以为覆盖了，其实证据相关/陈旧/伪造）和**假缺口**（以为没覆盖，其实本机或邻机已有有效证据）。解法不是关掉协同，而是给缺口一个**四类分解证书**，并用**独立性加权**而非票数累计覆盖率；同时在舰队级状态切换上加**联合静默屏障**，保证没有机器人观察到混合契约。

## 1. 研究问题（本轮要回答什么）

- **Q1（缺口的一阶化）**：「研究空白」能否从文献隐喻变成可测、可出证的对象？四类分解（缺失/冲突/陈旧/来源无效）是否互斥完备、可操作？
- **Q2（协同的交换条件）**：多机证据共享在什么条件下带来**真实**覆盖增益，而不是相关性造成的虚假共识？独立性假设失效时能否优雅降级而不是自信地犯错？
- **Q3（舰队级时序）**：缺口检测、跨机校准与合同热替换如何在不破坏 50Hz 实时性与严格退化链的前提下协同？

## 2. 四条设计原则（正式化见产物区定义 448–463）

**P1 证据来源闭包（Evidence Provenance Closure, EPC）**
任何非本机产生的证据都必须携带可验证的来源链 π；来源链不可验证 ⇒ 视为**不存在**，而不是「低权重存在」。这给出「舰队证据集 ⊆ 可归因证据集」的健全性，避免不可信证据以低权重慢性污染聚合结果。

**P2 缺口证书（Gap Certificate, GC）**
声明一个研究缺口，必须同时给出四类分解中至少一类的**见证集**（缺什么、与谁冲突、何时过期、哪条来源失效）。无证书的缺口声明只能作为提示，不能进入规划；缺口证书与修复证书同级可审计。

**P3 独立性加权聚合（Independence-Weighted Aggregation, IWA）**
同一证据簇（同模型/同视角/同失效模式）的重复证据**不重复计数**；覆盖增益按独立权重累计。多数票不是证据，独立才是证据；相关性不可判定时取保守权重，宁可退回单机也不虚假自信。

**P4 联合静默屏障（Joint Quiescence Barrier, JQB）**
舰队级合同/缺口状态切换只允许发生在**联合静默点**（所有机器人无在途块、无待处理不可逆动作、证据 gossip 已对齐）；跨机否决只能在联合屏障处生效，不可逆动作要求**跨机独立回执**。

## 3. 与基线的接口（如何退化）

- 舰队不可用 / `n = 1` ⇒ 退回 InstructGauge 单机闭环；
- 邻机来源链不可验证 ⇒ 丢弃该证据 ⇒ 缺口退化为「本机几何盲区 + 本机证据」（等价 InstructGauge 盲区定义）；
- 独立性不可判定 ⇒ 邻机证据仅作提示、不参与覆盖计数（权重归入同簇）；
- 跨机共形校准失败 / 样本不足 ⇒ 逐机校准（InstructGauge SC-Cal）；
- 联合静默屏障不可用 ⇒ 逐机热替换（InstructGauge q_quiesce）；
- InstructGauge 失效 ⇒ ToolGauge；ToolGauge 失效 ⇒ LeanGauge；LeanGauge 失效 ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个把「研究空白」转成**四类分解 + 缺口证书**的一阶口径，使「我们不知道」本身可审计、可优先级化；
2. 一个**来源闭包 + 独立加权**的舰队证据聚合，把「多机虚假共识」压到与独立证据簇数成比例，并在相关性失效时优雅降级；
3. 一个**跨机分层共形校准 + 联合静默屏障**，修正「跨机可交换性破坏」与「混合契约」两类系统性错误；
4. 一条可证伪路径：E457–E472 覆盖缺口效度、证据洗白、来源伪造、相关失效、跨机覆盖、断连鲁棒、扩展性与 50Hz 时序。

## 5. 本轮最大风险

**一句话**：多机协同的价值完全建立在「证据相互独立」这个**无法从系统内部验证**的前提上——一旦邻机证据与本机错误同源，舰队会把一次接地错误洗白成高置信共识，并自信地宣布一个「研究空白」已被填满；因此本轮真正的残余风险是**独立性假设本身的可证伪性**，而非任一组件。

## 2. 形式化定义（要点）

**定义 448（舰队与机器人状态）** `F = {r_1,…,r_n}`，每个 `r` 有状态 `σ^r`、执行契约 `EC^r`、校准集 `C_cal^r`、在途块集 `Inflight^r`。`n=1` 时本定义退化为 InstructGauge 单机状态。

**定义 449（证据原子）** `e = (p, ρ, r, t, π, q)`：`p` 是关于位点 `s` 的**可测谓词**（沿用定义 443 对可测守卫的要求），`ρ` 为回执 id，`r` 为来源机，`t` 为逻辑+物理时间戳，`π` 为来源链，`q` 为校准层及其覆盖证书。证据只有在 `valid_prov(π) ∧ fresh(e)` 时才进入 `E_F`。

**定义 450（来源链与来源闭包 EPC）** `π = [(r_0,ρ_0,τ_0),…,(r_k,ρ_k,τ_k)]`，`τ_j` 为派生/变换链节。`valid_prov(π) = 1` 当且仅当：每个链节签名可验证、每个回执在其来源机真实存在、链深 `k ≤ D_prov`、且无自证环。来源闭包公理：`E_F(t) = {e : valid_prov(e.π) ∧ fresh(e)}`——**不可验证即不存在**，而非低权重存在。

**定义 451（新鲜度与置信度）** `fresh(e) = 1[t − t_e ≤ H_e]`；`conf(e) = min(回执置信, 来源链置信)`；`rel(e) = fresh(e)·conf(e)`。

**定义 452（独立性与独立权重）** `w_ind(e) = 1 / (1 + Σ_{e'≠e, cluster(e')=cluster(e)} κ(e,e'))`，其中 `κ(e,e') ∈ [0,1]` 为可测相关度（联合残差估计）。`κ` 不可判定时取 `κ=1`（保守），此时重复证据只按簇计一次。**P3 的形式含义**：覆盖增益由独立簇数决定，而非证据条数。

**定义 453（相关证据簇与相关失效）** `cluster(e) = (model_id, pose_bucket, failure_mode_sig)` 的等价类；同簇证据视为可能同源失效。相关失效指 `∃` 同簇证据在相同扰动下同时错误——这是"多数票"失效的根源。

**定义 454（认知覆盖率）** `Cov(s) = Σ_{e∈E_F(s)} w_ind(e)·rel(e)`。**关键区分**：几何可见性 `vis(s)` 与 `Cov(s)` 正交；`vis(s)=1 ∧ Cov(s)=0` 正是「研究空白」——看得见但没有可信知识。

**定义 455（研究缺口四类分解）** `G(s) = (W_m, W_c, W_st, W_pv)`，其中 `W_m` 为作用于 s 的证据为空；`W_c` 为存在两条有效证据谓词不相容且无可信裁决；`W_st` 为所有覆盖 s 的证据 `fresh=0`；`W_pv` 为存在指向 s 但 `valid_prov=0` 的证据。缺口判定 `s ∈ 𝔾_F ⇔ Cov(s) < τ_cov`，且证书须给出覆盖亏空的主因（优先级 `W_pv ≻ W_c ≻ W_st ≻ W_m`，保证主因唯一、可去重）。

**定义 456（缺口证书）** `GapCert(s) = (s, Cov(s), τ_cov, G(s), primary, t, R_s, checksum)`，`R_s` 为贡献该判断的机器人集。缺口声明**仅在证书有效时**进入规划；否则降级为「unknown-unknown 提示」，不分配探测预算。

**定义 457（舰队缺口集与优先序）** `𝔾_F = {s : GapCert(s) 有效}`；`≻_gap` 按「单位成本期望信息增益 × 安全相关度」排序，且必须延拓安全序（`≻_gap` 把安全攸关缺口置于其下界之上）。

**定义 458（跨机分层共形校准 XRC）** 逐机层 `q_{r,s}` 由 `C_cal^{r,s}` 取分位；舰队层 `q_s^F` 仅在**异质性检验**（逐机覆盖证书 + 分布差异 ≤ δ_r）通过时由池化校准得到。部分可交换下覆盖保证 `P(h*∈H_s) ≥ 1−α − Σ_r π_r·δ_r`；检验失败或 `|C_cal^{r,s}|<n_min` ⇒ 回退逐机阈值（InstructGauge SC-Cal）。

**定义 459（联合静默点）** `q_quiesce^F` 指 `∀r`：无在途块、无待处理不可逆动作、证据 gossip 已对齐到一致快照。舰队级契约/缺口状态切换**只允许**发生在 `q_quiesce^F`。

**定义 460（联合否决 JVeto）** 邻机可在 `q_quiesce^F` 以 `JVeto(ρ_peer, block_id)` 否决**未来**块，要求来源绑定回执；否决对在途块与不可逆动作无效——不可逆动作只能靠执行前的跨机独立回执阻止，不能靠事后否决追回。

**定义 461（证据洗白风险与有效独立数）** 设单源错误概率 `p_err`，`EL(e) = 1 − Π_{e'∈support(e)}(1 − p_err(e'))`（在独立性下）；相关性下定义 `n_eff = (Σ w_ind)² / Σ w_ind²`，虚假填空概率按 `n_eff` 而非证据条数界住。`κ→1 ⇒ n_eff→簇数 ⇒ 退化为单机`（优雅降级，见引理 61）。

**定义 462（缺口分配拍卖 GAA）** `assign: 𝔾_F → 2^F`，效用 `u_r(s) = 期望覆盖增益 / 成本`；拍卖以良基秩 `rank`（每轮严格递减、下界 0）保证有界轮数 `≤ n·|𝔾_F|`；**可分配性约束**：只能分配给能产生**独立新簇**证据的机器人（同簇复制不计），从结构上防止"自证式填空"。

**定义 463（舰队修复证书）** `RepairCert″(s) = (GapCert(s), assign, {e_new}, {ChunkCert_r}, {receipts_r}, claims, q_used)`，使审计可沿「缺口→分配→新增独立证据→逐机块证书→主张」复现一次舰队级修复。

## 3. 关键算法骨架

```python
# IP-328 EPC：来源闭包验证（不可验证即不存在）
class EPC:
    def filter(self, atoms, now):
        return [e for e in atoms
                if self.valid_prov(e.pi, max_depth=D_PROV)
                and fresh(e, now)]

    def valid_prov(self, pi, max_depth):
        if len(pi) > max_depth:                 return False
        seen = set()
        for (r, rho, tau) in pi:
            if (r, rho) in seen:                return False   # 自证环
            if not verify_sig(r, rho, tau):     return False
            if not receipt_exists(r, rho):      return False
            seen.add((r, rho))
        return True

# IP-329 EGD：四类证据缺口检测 + 缺口证书
class EGD:
    def detect(self, s, atoms, now):
        valid = EPC().filter(atoms, now)
        cov   = sum(w_ind(e) * rel(e, now) for e in valid if targets(e, s))
        if cov >= TAU_COV:
            return None
        W_pv = [e for e in atoms if targets(e, s) and not valid_prov(e.pi, D_PROV)]
        W_c  = self.contradictions(valid, s)     # 谓词不相容且无裁决
        W_st = [e for e in atoms if targets(e, s) and not fresh(e, now)]
        W_m  = [] if atoms else [s]              # 完全无证据
        primary = ("pv" if W_pv else "conflict" if W_c
                   else "stale" if W_st else "missing")
        return GapCert(s, cov, TAU_COV,
                       (W_m, W_c, W_st, W_pv), primary, now,
                       robots_of(valid), checksum(valid))

# IP-330 FIA：独立性加权聚合（同簇去重）
class FIA:
    def aggregate(self, atoms, s):
        buckets = defaultdict(list)
        for e in atoms:
            buckets[cluster(e)].append(e)
        cov = 0.0
        for c, es in buckets.items():
            es.sort(key=lambda e: rel(e), reverse=True)
            best = es[0]                         # 同簇只取最可信一条
            kappa = self.residual_correlation(es)  # 不可判 ⇒ 1
            cov += rel(best) / (1.0 + kappa * (len(es) - 1))
        return cov

# IP-331 XRC：跨机分层共形校准（异质性检验 + 回退）
class XRC:
    def threshold(self, s, cal_by_robot, cal_fleet):
        if not self.heterogeneity_ok(cal_by_robot, DELTA):
            return self.per_robot(s, cal_by_robot)     # 回退 SC-Cal
        if len(cal_fleet.get(s, [])) < N_MIN:
            return self.per_robot(s, cal_by_robot)
        return conformal_quantile(cal_fleet[s], alpha=ALPHA)

# IP-332 JQB：联合静默屏障 + 联合否决
def joint_barrier(M):
    return all(not M.inflight[r] and not M.pending_irr[r] for r in M.fleet) \
           and M.gossip.synced()

def apply_fleet_update(M, update):
    if not joint_barrier(M):
        return False                                # 非静默点：拒绝切换
    for r in M.fleet:
        M.commit[r] = update[r]                     # 无机器人观察混合契约
    return True

# IP-333 GAA：缺口→机器人拍卖（活性 + 可退化）
def assign_gaps(gaps, fleet, M):
    assign, rank = {}, {s: len(gaps) for s in gaps}
    while any(rank[s] > 0 for s in gaps):
        for s in sorted(gaps, key=lambda x: rank[x], reverse=True):
            bidders = [r for r in fleet
                       if can_produce_independent(r, s, M)]   # 只允许新簇
            if not bidders:
                rank[s] = 0                              # 本地兜底
                assign[s] = {local_robot(s)} if local_robot(s) else set()
                continue
            assign[s] = {max(bidders, key=lambda r: u(r, s))}
            rank[s] -= 1                                 # 良基递减 ⇒ 有界轮数
    return assign

# IP-334 8C 闭环（在 7C 前加缺口、在 V 后加共享）
def fleetgauge_8c(M, s):
    gap = M.egd.detect(s, M.epc.filter(M.gossip.atoms(s), M.now), M.now)
    if gap is None:
        return M.instructgauge_7c(M, s, M.ell)       # 无缺口 ⇒ 7C 原样
    if M.gossip.atoms(s) and not gap.primary:
        return M.instructgauge_7c(M, s, M.ell)
    C = M.iac.plan_chunk(M.iota_for(gap), M.lbox.hypothesize(s, M.dbox.R[s]),
                         M.tools, M.budget_left(s), M.drift_bound(s))
    cert = M.cvc.commit(C, M.env, M.iota_for(gap))
    if not M.xrc.usable(s):
        return M.instructgauge_7c(M, s, M.ell)       # 校准不可用 ⇒ 回退
    M.apcal.calibrate(cert.receipts, M.hyp(s), s)
    if not apply_fleet_update(M, M.contract_from(s)):  # 非联合静默 ⇒ 不切换
        return False
    M.gossip.publish(EvidenceAtom(s, cert.receipts, M.robot_id,
                                  M.now, M.provenance(), M.calib_stratum(s)))
    M.gac.assign([gap], M.fleet, M)
    bind_claims(cert, M.iota_for(gap), cert.receipts)
    return True

# 主闭环（50Hz 路径不变）
def FleetGauge_round(M, obs, audio, tac, depth, det):
    for s in M.egd.fleet_gaps(M):                    # 异步
        if s not in M.inflight_any():
            submit_async(fleetgauge_8c, M, s)
    return InstructGauge_round(M, obs, audio, tac, depth, det)
```

## 4. 推导

**引理 59（来源闭包健全性）** 在 EPC 公理与签名不可伪造假设下，`E_F(t) ⊆` 可归因证据集；任何不可验证链节的证据被完全排除（而非降权）。故伪造/重放归因错误只能以 `≤ D_prov·negl(λ)` 的概率进入舰队证据集。*证明骨架*：对链深归纳；每个链节通过签名与回执存在性双检，自证环被 `seen` 拒绝；不可验证即不在过滤结果中。

**引理 60（缺口证书的健全与分解完备）** 若 `Cov(s) < τ_cov`，则四类见证中至少一类非空（否则每条证据都有效、新鲜、相容且累计覆盖 ≥ τ_cov，矛盾）；反之，若证书给出见证集能覆盖全部亏空成因且 `Cov(s) ≥ τ_cov`，则不应声明缺口。主因按 `W_pv ≻ W_c ≻ W_st ≻ W_m` 唯一化，避免同一缺口被重复分配预算。估计误差由 `τ_cov` 的共形裕度吸收。

**引理 61（相关失效下的虚假共识界与优雅降级）** 设同簇相关度上界 `κ_max`、有效独立数 `n_eff = (Σw_ind)²/Σw_ind²`，则虚假填空概率 `P_fill ≤ exp(−n_eff·D(τ_cov‖p_err))`（Chernoff 型）。当 `κ→1`，`n_eff→` 簇数 `→1`，界退化为**单机**错误率——即相关性失效时不是"更自信地错"，而是**退回 InstructGauge 的覆盖**。这是本轮最重要的性质：独立性不可验证时，系统降级为单机而非放大错误。

**引理 62（跨机分层共形覆盖）** 在逐机层内可交换、且异质性项 `δ_r` 已由证书界住时，舰队覆盖 `P(h*∈H_s) ≥ 1−α − Σ_r π_r δ_r`；异质性检验失败则回退逐机阈值，覆盖回到每层 `1−α`。相比不校准的池化，跨机池化在 `δ_r` 大时可**逐机失效**，故必须先检验再池化（由 E465 检验）。

**引理 63（联合静默等价与退化）** 若舰队级更新仅在 `q_quiesce^F` 发生，则在途块必已 drain 或按 `abort` 截断补偿，无机器人观察到混合契约。`n=1` 时 `q_quiesce^F` 退化为 InstructGauge 的 `q_quiesce`，逐指令等价性回到引理 57 → 49 → 44。

**引理 64（无假填空单调性）** 加入同簇、同来源链根的重复证据不增加 `Cov` 超过其 `w_ind`；要闭合一个缺口，`Cov` 的增量必须来自**新的独立簇**。故"把同一回执换个机器人再报一遍"不能降低缺口。*证明*：`FIA` 对同簇取单条最优后按 `1/(1+κ(#peers))` 折算，重复项严格次可加；`κ=1` 时增量为 0。

**引理 65（缺口分配活性与有界性）** GAA 的秩 `rank` 每轮严格递减且有下界 0，故轮数 `≤ n·|𝔾_F|`；无独立投标者时按本地兜底分配，不产生死锁。分配只允许新簇，故不会把"自证"当作填空（与引理 64 一致）。

**引理 66（开销摊销与 50Hz 保全）** 证据 gossip 与缺口检测均在异步域，单轮代价 `O(n·|E|)` 不进入内联路径；主循环仅做 `submit_async` 判重，新增周期 `< 0.2ms`，继承 InstructGauge 引理 58 与 ToolGauge 引理 50 的硬实时结论。

## 8. 本轮最大风险

**一句话**：FleetGauge 的全部覆盖增益都建立在「邻机证据与本机错误独立」这一**系统内部不可验证**的前提上；`n_eff` 与 `w_ind` 只能由残差估计间接近似，一旦同源错误在观测上伪装成独立证据，舰队会把一次接地错误洗白成高置信共识并宣布「研究空白」已填满——因此本轮的证伪重点是 E461/E463/E464 对独立性假设的主动攻击，而不是对单个模块的功能测试。
