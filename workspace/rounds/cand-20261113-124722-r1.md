# 第 67 轮（承接第 66 轮「RAS 情绪驱动闭环」IP-224~233；灵感循环第 1 轮；本轮灵感：「姿态估计」×「长程任务」）

> 第 66 轮 RAS 把闭环从「被动故障响应」推进到「主动意图感知」，但它和 VISTA 都默认了一个隐藏前提：**任务从头到尾是“同一个任务”**。真实长程任务（做饭、装配、护理、巡检）执行数分钟到数小时，策略的隐状态会无声漂移：物体被移动、视角改变、里程碑被误判、早期小错误被后续观测“自圆其说”。这类失败不是某一步的故障，而是**任务同一性的缓慢溶解（task-identity dissolution）**。
>
> 本轮命题是：
>
> **把长程任务执行重新表述为“任务空间中的里程计（odometry）+ 回环闭合（loop closure）”问题：用多尺度姿态估计构建几何锚点，把姿态锚点当作任务状态的回环闭合，从而把随 T 线性累积的漂移，压成随锚点间隔 Δ 有界的漂移。** 框架名 **TETHER**（Task-Embodiment Tethering via Hierarchical Estimation & Re-anchoring，任务-具身系绳）。
>
> TETHER 问的不是“哪层坏了”“该控制多少”，而是「**任务还是不是那个任务**」。它把 VISTA 的技术故障、RAS 的意图风险之外，补上第三层——**任务同一性层**，构成「故障层 ⊂ 意图层 ⊂ 同一性层」的三闭环嵌套。

## 0. 直觉与动机

**灵感 1（长程任务 → 任务空间里程计）**
直觉：长程任务的失败谱系与视觉里程计惊人相似。单步误差都很小，但隐状态 `z_t` 相对真值 `z*_t` 的偏差随时步累积；系统没有绝对参考，只能“相对自己”往前推。于是误差不在某一步突然爆掉，而是**在数十步后表现为整体偏航**：机器人以为自己还在切菜，其实砧板已被推走；以为自己完成了“倒入”，其实量杯从未倾斜。要治它，不能只改单步策略，必须引入**绝对参考 + 周期性重定位**。

**灵感 2（姿态估计 → 长程任务的回环闭合）**
直觉：姿态估计恰好提供这种“绝对参考”：`T ∈ SE(3)` 是低维、度量、几何可验证的量；它可以复合（相对变换）、可以传播不确定度（`Σ ∈ ℝ^{6×6}`）、可以跨外观变化保持语义。把「预测姿态」与「观测姿态」求相对残差 `r = log(T_pred⁻¹ T_obs)`，本质上就是一个**回环闭合残差**。当残差在门限内且里程碑谓词被满足，就用它把 latent task state “拉回”到几何自洽的位置——这正是 SLAM 里 loop closure 修正 drift 的同构操作。区别只在于：SLAM 修正的是相机轨迹，TETHER 修正的是**任务轨迹**。

**灵感 3（多尺度姿态 → 分层锚点，快慢分离）**
直觉：单一姿态不够。长程任务里至少有三种锚：**人/手姿态**（意图与操作者状态）、**物体 6D 姿态**（任务对象“到底在哪、朝哪”）、**末端执行器姿态**（具身自定位）。三者可观测性与时间尺度不同：末端由本体感知高频获得（毫秒级、低噪声），物体 6D 依赖视觉（较慢、易受遮挡），人/手姿态最慢但语义最强。把它们组织成**分层锚图（anchor graph）**，就得到快慢分离的“任务惯性系”：慢锚提供绝对语义，快锚提供局部几何。

**灵感 4（三灵感合流 → TETHER 七件套）**
TETHER = (HPE, PAG, ACM, RAK, LTM, CRP, AFC)：
1. **HPE 分层姿态估计**：手/物体/末端/人体，多率、带协方差；
2. **PAG 姿态锚图**：节点=锚点，边=相对变换约束，构成滑窗因子图；
3. **ACM 锚点一致性监视**：残差 + Mahalanobis 门限，检测“漂移/回环候选”；
4. **RAK 重锚核**：在多假设消歧后做鲁棒 pose-graph 优化，投影并重置任务状态 `z`；
5. **LTM 长程任务记忆**：只存锚点+里程碑+故障指纹，不存原始帧，支持跨块故障记忆；
6. **CRP 认证重锚前缀**：只执行到“下一次安全重锚边界”之前，保证段内漂移有界；
7. **AFC 锚点感知故障归因**：把 `H_anchor = {遮挡, 对称歧义, 标定漂移, 真实漂移}` 接入 VISTA 的假设集。

**灵感 5（与 VISTA/RAS 的关系：三闭环嵌套）**
- VISTA 回答“哪一层坏了”（技术故障归因）；
- RAS 回答“谁控制、控制多少”（意图/风险闭环）；
- **TETHER 回答“任务还是不是那个任务”（同一性闭环）**。
三者不是替代，而是**不同时间尺度的嵌套**：`T_ee ≪ T_fault(VISTA, ~10ms) ≪ T_reanchor(TETHER, ~1s)`。TETHER 把重锚后的 `z` 与里程碑注入 VISTA/RAS，使后两者在“正确的任务上下文”里做归因与风险缩放；反过来，VISTA/RAS 的降级不得篡改 `z` 的里程碑语义。这与第 66 轮“实时流只做早停、语义流做归因”的分离原则一致。

## 1. 形式化定义（增量：定义 251–268）

- **定义 251（TETHER 总览）**：`TETHER = (HPE, PAG, ACM, RAK, LTM, CRP, AFC)`。定位：在 VISTA（故障层）与 RAS（意图层）之外新增**任务同一性层**。不变式：重锚**单调安全**——只允许把 `z` 投影到“不降低已验证安全边际”的锚点邻域；实时流只做姿态前向、残差与门限判定，零学习写操作。
- **定义 252（多尺度姿态观测）**：`Pose_t = {T_body, T_hand, T_obj, T_ee}`，各带协方差 `Σ_* ∈ ℝ^{6×6}`（se(3) 切空间）。时间尺度：`T_ee = FK(q_t)`（≥200Hz，本体感知），`T_obj` 由 6D 姿态网络给出（10–30Hz），`T_hand/T_body` 由视觉给出（5–15Hz）。
- **定义 253（姿态锚）**：锚 `a_i = (kind_i, T_i, Σ_i, m_i, t_i)`，其中 `kind ∈ {obj, hand, ee, body}`，`m_i` 为绑定的里程碑谓词，`t_i` 为时间戳。
- **定义 254（姿态锚图）**：`G_t = (V_t, E_t)`，`V_t = {a_i}`，边 `(i,j)` 携带相对约束 `T_ij = T_i⁻¹ T_j` 与协方差 `Σ_ij`。`G_t` 是滑窗因子图，窗口 `W` 内做增量优化。
- **定义 255（锚点一致性残差）**：`r_ij = log_SE3(T̂_ij⁻¹ · T_ij) ∈ ℝ^6`；Mahalanobis `d²_ij = r_ijᵀ Σ_ij⁻¹ r_ij`。回环候选当且仅当 `d²_ij < χ²_{6,1-α}`。
- **定义 256（任务状态里程计与漂移）**：策略维护 `z_{t+1} = f(z_t, a_t, o_t)`；漂移 `δ_t = z_t - z*_t`。称长程任务发生**同一性溶解**当 `||δ_t||` 超过任务相关阈值且不可由局部观测纠正。
- **定义 257（重锚算子）**：给定回环候选与里程碑一致证据，`z⁺ = Π_anchor(z⁻, a_i) := argmin_z [ ||z - z⁻||²_{Σ_z} + ||φ(z) - T_i||²_{Σ_i} ]`，并伴随 pose-graph 更新；`φ` 把任务状态映射到几何姿态。**硬约束**：`SafetyMargin(z⁺) ≥ SafetyMargin(z⁻) - ε_mono`。
- **定义 258（里程碑-锚绑定）**：`m_i = (pred_i, evidence_i)`，`pred_i` 是里程碑谓词（如 “cup 已进入 receptacle 且末端减速”），`evidence_i` 是独立于姿态的证据（触觉、力、音频、语义分割）。**只有 `pred_i ∧ evidence_i` 同时成立，重锚才被接受**。
- **定义 259（锚密度与漂移界）**：设最大锚间隔 `Δ = max_i (t_{i+1}-t_i)`、单步漂移噪声方差 `σ_d²`、锚观测方差 `σ_a²`，则任意 t 的漂移满足 `E||δ_t||² ≤ c(σ_d²·Δ + σ_a²)`，与总时程 T 无关（见定理 11）。
- **定义 260（锚点故障假设）**：`H_anchor = {H_occ 遮挡, H_sym 对称歧义, H_calib 标定漂移, H_drift 真实漂移}`；`P(H_anchor | r, d²) ∝ p(r | H) P(H)`，接入 VISTA 的 `ℋ`。
- **定义 261（认证重锚前缀）**：`k_CRP = min{m : ∀s≤m, DriftBound(s) ≤ ε_drift}`，且 `k_CRP ≤ steps_to_next_anchor`。只执行 `A[:k_CRP]`，保证下一次重锚前漂移仍可控。
- **定义 262（长程任务记忆）**：`LTM = {landmark_j = (a_j, m_j, fault_fp_j)}`，容量 `N_max`，按几何近邻 + 语义哈希检索；`fault_fp` 取自 VISTA 的 32 维签名，用于判断“同类故障在长程内是否复发”。
- **定义 263（对称感知多假设）**：对对称物体，6D 姿态存在等价类 `S = {g·T : g ∈ Sym(O)}`。RAK 维护 `K` 个假设 `{T^{(k)}}`，用后续观测似然比消歧；**未消歧前禁止重锚**（输出 `DEFER`）。
- **定义 264（锚点可观测性）**：`obs(a_i) = 1 - exp(-κ·vis_i·texture_i·(1 - sym_ambiguity_i))`；`obs < τ_obs` 时锚点降级为“弱锚”，只用于局部约束，不触发全局重锚。
- **定义 265（J_TETHER 证书）**：`J_TETHER = (J_RAS, z_version, anchor_chain_hash, Δ_max, drift_bound, milestone_evidence_hash, H_anchor_posterior)`。Valid ⇔ `Valid(J_RAS) ∧ drift_bound ≤ ε_drift ∧ Δ_max ≤ Δ_max^allow ∧ milestone_evidence 已验证`。
- **定义 266（快慢时标分离）**：`T_ee ≪ T_fault ≪ T_reanchor`；任一层不得跨越上层周期做不可逆决策（重锚永远比故障降级“慢”，避免抖动）。
- **定义 267（跨具身锚迁移）**：锚点以“物体-环境”相对位姿为主、末端位姿为辅存储，故 `a_i` 可在不同机器人本体间迁移；末端锚迁移时按新本体 FK 重建，不继承旧标定。
- **定义 268（三闭环不变式）**：任意 TETHER 重锚必须保持 VISTA 故障归因有效性（不掩盖故障）与 RAS 风险缩放安全性（不降低风险上限）；反之，VISTA/RAS 的降级不得篡改 `z` 的里程碑语义。

## 2. 关键算法骨架

```python
from dataclasses import dataclass

@dataclass
class Anchor:
    kind: str            # 'obj' | 'hand' | 'ee' | 'body'
    T: 'np.ndarray'      # SE(3)
    Sigma: 'np.ndarray'  # 6x6, se(3) 切空间
    milestone: str
    t: int
    sym_class: 'object' = None


class HierarchicalPoseEstimator:          # HPE
    def estimate(self, rgbd, proprio):
        body = body_pose_net(rgbd.rgb)            # SMPL-X, Σ_body
        hand = hand_pose_net(rgbd)                # MANO,   Σ_hand
        obj  = object_6d_pose(rgbd, self.cad)     # SE(3),  Σ_obj, 对称类
        ee   = forward_kinematics(proprio.q)      # SE(3),  Σ_ee（标定）
        return {'body': body, 'hand': hand, 'obj': obj, 'ee': ee}


class AnchorConsistencyMonitor:           # ACM
    def __init__(self, alpha=0.01, tau_obs=0.6):
        self.chi2 = chi2_ppf(1 - alpha, df=6)
        self.tau_obs = tau_obs

    def residual(self, T_pred, T_obs, Sigma):
        r = log_se3(inv_se3(T_pred) @ T_obs)       # 6 维
        d2 = float(r.T @ inv(Sigma) @ r)
        return r, d2

    def is_loop_candidate(self, a_pred, a_obs):
        r, d2 = self.residual(a_pred.T, a_obs.T, a_obs.Sigma + a_pred.Sigma)
        return d2 < self.chi2, r, d2


class ReanchoringKernel:                  # RAK
    def __init__(self, chi2_alpha=0.01, trust_region=0.15):
        self.acm = AnchorConsistencyMonitor(chi2_alpha)
        self.delta = trust_region

    def step(self, z, pred_poses, anchors, milestone_belief):
        cands = []
        for a in anchors:
            ok, r, d2 = self.acm.is_loop_candidate(pred_poses[a.kind], a)
            if ok:
                cands.append((a, r, d2))
        if not cands:
            return z, 'CONTINUE'

        # 定义 263：对称多假设，未消歧则 DEFER
        hyp = self.symmetry_hypotheses(cands)
        if hyp.ambiguous:
            return z, 'DEFER'

        # 定义 257：带信任域的鲁棒投影 + pose-graph 增量优化
        z_new = self.project(z, hyp.best, self.delta)
        self.pose_graph.optimize(window=self.W, robust='huber')

        # 定义 258：必须有独立里程碑证据，否则拒绝重锚（防绑架）
        if not milestone_belief.consistent(hyp.best):
            return z, 'DEFER'
        return z_new, 'REANCHOR'


class LongHorizonTaskMemory:              # LTM
    def __init__(self, max_landmarks=256):
        self.landmarks = deque(maxlen=max_landmarks)

    def push(self, anchors, milestone, fault_fp):
        self.landmarks.append((anchors, milestone, fault_fp))

    def recall(self, query_pose, radius=0.3):
        return [l for l in self.landmarks
                if se3_distance(l[0].T, query_pose) < radius]


class CertifiedReanchorPrefix:            # CRP
    def prefix(self, chunk, drift_bound, steps_to_anchor, eps_drift):
        k = 0
        for s, _ in enumerate(chunk, start=1):
            if drift_bound(s) <= eps_drift:
                k = s
            else:
                break
        return min(k, steps_to_anchor)


class AnchorAwareFaultClosure:            # AFC
    def infer(self, r, d2, obs):
        return normalize({
            'H_occ':   p_occ(r, obs),
            'H_sym':   p_sym(r, obs),
            'H_calib': p_calib(r),
            'H_drift': p_drift(r, d2),
        })


def TETHER_round(M, obs):
    # 1) 多尺度姿态
    poses = M.hpe.estimate(obs.rgbd, obs.proprio)
    anchors = M.pag.attach(poses, obs.milestone)

    # 2) 一致性监视 + 重锚（任务同一性闭环）
    pred = M.motion_model.predict_poses(M.z)
    z, mode = M.rak.step(M.z, pred, anchors, M.milestone_belief)
    if mode == 'REANCHOR':
        M.ltm.push(anchors, obs.milestone, M.vista.last_fault_fp)

    # 3) 认证重锚前缀（只执行到下一次安全重锚边界）
    k = M.crp.prefix(M.chunk, M.drift_bound(M.z),
                     M.steps_to_next_anchor(), M.eps_drift)

    # 4) 与 VISTA / RAS 组合：在正确任务上下文里归因与风险缩放
    tau = M.policy.dispatch(M.chunk[:k], z)
    fault = M.vista.attribute(M.vista.residual_log)
    anchor_fault = M.afc.infer(*M.acm.last_residual, obs)
    tau = M.ras.risk_scale(tau, fault, anchor_fault)
    M.z = z
    return k, z, tau, fault, anchor_fault
```

## 3. 推导

**引理 11（锚残差是漂移的一致估计）** 若姿态估计器无偏（`E[T̂] = T`）且重锚门限只筛除离群点，则对回环候选有 `E[r_ij | 回环] = δ_ij + o(σ)`，即相对残差近似等于两锚间累积漂移。故 ACM 的 `d²` 可作为漂移的一致统计量，用于无监督漂移检测。

**引理 12（重锚的协方差收缩）** 定义 257 的投影在姿态观测上线性化后等价于 Kalman 更新，其后验协方差 `Σ_z⁺ = (Σ_z⁻⁻¹ + J_φᵀ Σ_i⁻¹ J_φ)⁻¹ ⪯ Σ_z⁻`。故每次成功重锚使漂移方差严格不增；对称多假设未消歧时 `J_φ` 秩亏，更新退化为部分观测，故必须 `DEFER`。

**定理 11（长程漂移有界）** 在定义 259 条件下，对任意 T，`E||δ_T||² ≤ c(σ_d²·Δ + σ_a²)`。证明要点：把 `[0,T]` 按锚点切为 `N ≈ T/Δ` 段；段内漂移最多累积 `Δ` 步随机游走（方差 `σ_d²Δ`），段末被锚观测拉回（方差 `σ_a²`）；段间独立，取上界即得，**与 T 无关**。直觉：锚点把 O(T) 的随机游走切成 O(T/Δ) 个有界“科”。

**定理 12（任务同一性保持）** 若每个里程碑至少绑定 K 个独立证据模态，且门限在显著性 α 下做卡方检验，则错误重锚（把任务搬到错误里程碑）的概率 `P_wrong ≤ α^K·(1+o(1))`。即 K 越大，任务被“绑架”的概率指数下降。

**定理 13（与 VISTA/RAS 的组合保序）** 若 TETHER 重锚满足定义 268 的单调安全约束，则 `Valid(J_TETHER) ⇒ Valid(J_vista) ∧ Valid(J_RAS)`。TETHER 只改变状态估计 `z` 与执行前缀，不改变 VISTA 故障后验与 RAS 风险缩放的定义域，故三闭环可嵌套而不破坏各自证书。

from dataclasses import dataclass

@dataclass
class Anchor:
    kind: str            # 'obj' | 'hand' | 'ee' | 'body'
    T: 'np.ndarray'      # SE(3)
    Sigma: 'np.ndarray'  # 6x6
    milestone: str
    t: int
    sym_class: 'object' = None


class HierarchicalPoseEstimator:          # IP-234
    def estimate(self, rgbd, proprio):
        body = body_pose_net(rgbd.rgb)            # SMPL-X
        hand = hand_pose_net(rgbd)                # MANO
        obj  = object_6d_pose(rgbd, self.cad)     # SE(3) + 对称类
        ee   = forward_kinematics(proprio.q)      # 本体感知
        return {'body': body, 'hand': hand, 'obj': obj, 'ee': ee}


class AnchorConsistencyMonitor:           # IP-236
    def __init__(self, alpha=0.01):
        self.chi2 = chi2_ppf(1 - alpha, df=6)

    def residual(self, T_pred, T_obs, Sigma):
        r = log_se3(inv_se3(T_pred) @ T_obs)
        d2 = float(r.T @ inv(Sigma) @ r)
        return r, d2

    def is_loop_candidate(self, a_pred, a_obs):
        r, d2 = self.residual(a_pred.T, a_obs.T, a_obs.Sigma + a_pred.Sigma)
        return d2 < self.chi2, r, d2


class ReanchoringKernel:                  # IP-237
    def step(self, z, pred_poses, anchors, milestone_belief):
        cands = [a for a in anchors
                 if self.acm.is_loop_candidate(pred_poses[a.kind], a)[0]]
        if not cands:
            return z, 'CONTINUE'

        hyp = self.symmetry_hypotheses(cands)          # IP-242
        if hyp.ambiguous:
            return z, 'DEFER'                          # 对称未消歧

        z_new = self.project(z, hyp.best, self.delta)  # 定义 257
        self.pose_graph.optimize(window=self.W, robust='huber')

        if not milestone_belief.consistent(hyp.best):  # IP-241
            return z, 'DEFER'                          # 无独立证据，拒绝
        return z_new, 'REANCHOR'


class LongHorizonTaskMemory:              # IP-238
    def __init__(self, max_landmarks=256):
        self.landmarks = deque(maxlen=max_landmarks)

    def push(self, anchors, milestone, fault_fp):
        self.landmarks.append((anchors, milestone, fault_fp))

    def recall(self, query_pose, radius=0.3):
        return [l for l in self.landmarks
                if se3_distance(l[0].T, query_pose) < radius]


class CertifiedReanchorPrefix:            # IP-239
    def prefix(self, chunk, drift_bound, steps_to_anchor, eps_drift):
        k = 0
        for s, _ in enumerate(chunk, start=1):
            if drift_bound(s) <= eps_drift:
                k = s
            else:
                break
        return min(k, steps_to_anchor)


class AnchorAwareFaultClosure:            # IP-240
    def infer(self, r, d2, obs):
        return normalize({
            'H_occ':   p_occ(r, obs),
            'H_sym':   p_sym(r, obs),
            'H_calib': p_calib(r),
            'H_drift': p_drift(r, d2),
        })


def TETHER_round(M, obs):                 # IP-243 闭环
    poses = M.hpe.estimate(obs.rgbd, obs.proprio)
    anchors = M.pag.attach(poses, obs.milestone)

    pred = M.motion_model.predict_poses(M.z)
    z, mode = M.rak.step(M.z, pred, anchors, M.milestone_belief)
    if mode == 'REANCHOR':
        M.ltm.push(anchors, obs.milestone, M.vista.last_fault_fp)

    k = M.crp.prefix(M.chunk, M.drift_bound(M.z),
                     M.steps_to_next_anchor(), M.eps_drift)

    tau = M.policy.dispatch(M.chunk[:k], z)
    fault = M.vista.attribute(M.vista.residual_log)
    anchor_fault = M.afc.infer(*M.acm.last_residual, obs)
    tau = M.ras.risk_scale(tau, fault, anchor_fault)

    M.z = z
    return k, z, tau, fault, anchor_fault

## 4. 推导

**引理 11（锚残差是漂移的一致估计）** 若姿态估计器无偏且门限只筛除离群点，则 `E[r_ij | 回环] = δ_ij + o(σ)`，相对残差近似等于两锚间累积漂移，故 `d²` 可作漂移的一致统计量。

**引理 12（重锚的协方差收缩）** 定义 257 在线性化下等价于 Kalman 更新：
```
Σ_z⁺ = (Σ_z⁻⁻¹ + J_φᵀ Σ_i⁻¹ J_φ)⁻¹ ⪯ Σ_z⁻
```
故每次成功重锚使漂移方差严格不增；对称未消歧时 `J_φ` 秩亏，必须 `DEFER`。

**定理 11（长程漂移有界）** 在定义 259 条件下，任意 T 满足 `E||δ_T||² ≤ c(σ_d²Δ + σ_a²)`，**与 T 无关**。证明：把 `[0,T]` 按锚切为 `N≈T/Δ` 段；段内随机游走方差 `σ_d²Δ`，段末被锚拉回方差 `σ_a²`；段间独立取上界。

**定理 12（任务同一性保持）** 若每个里程碑绑定 K 个独立证据模态、门限在显著性 α 下卡方检验，则 `P_wrong ≤ α^K·(1+o(1))`，K 越大越难被“绑架”。

**定理 13（三闭环组合保序）** 若重锚满足定义 268 的单调安全约束，则 `Valid(J_TETHER) ⇒ Valid(J_vista) ∧ Valid(J_RAS)`。
