# 第 66 轮（承接第 65 轮「VISTA 视觉知情的安全时序归因闭环」IP-214~223；灵感循环第 2 轮；本轮灵感：「关节空间控制」×「机械臂」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述的最大风险一针见血：**故障假设集有限，且视觉与几何被假定失效相互独立；真实故障常是未知类型的组合，透明/镜面/对抗 patch 会让视觉与几何共享同一个分布外失效源，于是 FIR 把未知复合故障强行归入最近假设、只膨胀错误的球——系统反而因为「已经归因」而更自信地继续执行。** 本轮不新增第五个模态，而是换一个坐标系发问：第 65 轮在**任务空间**里猜「哪个球坏了」，JANUS 追问「**是什么关节级根因让这些球同时看起来像坏了**」。本轮核心命题是：
>
> **症状在任务空间，根因常在关节空间：用关节残差构造「正运动学—视觉—关节力矩」因果校验三角，用可组合的关节故障原语替代有限假设枚举，用零空间探针在不改变末端接触的前提下激励根因，用故障感知的姿态把安全裕度重新「造」出来，并把执行前缀的安全承诺下沉到关节不可逆包络。**

## 0. 直觉与动机

**灵感 1（机械臂 → 任务空间症状只是关节状态的像）**
直觉：第 65 轮的四个证据——几何先验、F/T 力残差、视觉预测残差、接触模型残差——都被当成平级的「旁观者」，于是只能比较「谁更可信」。但一条真实机械臂是关节链：末端位姿是正运动学 `T_FK(q)` 的像，几何先验/接触斑来自位姿，接触力经雅可比 `τ = Jᵀ f` 反作用到关节，视觉看到的是同一个末端在相机里的投影。**它们在因果上不是并列的，而是共享同一个上游父节点 q 与关节驱动 τ。** 一旦承认这点，VISTA 的「视觉 vs 几何是否独立」就不再是信仰问题，而是一个**可以用关节侧独立见证去检验的结构问题**：正运动学与视觉是否一致（`Π_kin-vis`）、F/T 与关节力矩反推是否一致（`Π_force`）、动力学残差是否异常（`Π_dyn`）。三角形里任意两条边一致、第三条不一致，就足以定位根因，而不必枚举「透明物体同时骗视觉和几何」这种组合。

**灵感 2（关节空间控制 → 真正的不可逆边界在关节侧）**
直觉：第 65 轮的不可逆视界 m 是任务空间的（力限、几何裕度、停止距离）。但机械臂真正不可逆的越界往往发生在关节侧：**关节限位、力矩饱和、奇异位形（σ_min(J)→0 导致某些任务方向突然失去力/位移权威）、自碰撞、速度/加速度超限、线缆过伸**。这些事件在任务空间证书里可能完全不可见——同一个末端轨迹在某个构型合法，转过 30° 后经过奇异点就崩溃。因此「长预测、短执行」的前缀 k* 必须在**关节安全包络**里认证，真正的前缀应取 `k* = min(k*_VISTA, k*_J)`。

**灵感 3（关节空间控制 → 姿态是一种可再生的安全资源）**
直觉：VISTA 遇到不确定只会**膨胀球、收缩允许集**，越不确定越保守。但冗余机械臂（n>6）有一个免费自由度：**零空间自运动**——不改变末端位姿的整臂姿态。安全裕度（σ_min、关节限位余量、力矩余量、自碰撞距离）是构型 q 的函数。于是我们可以在不改变任务的前提下，**选一个让安全集更大的姿态**；更妙的是，若某个关节被归因为故障（摩擦/背隙/柔顺），可以让姿态**少用这个关节**（负载重分配），把裕度从别的关节「借」回来。这不是保守化，而是**用冗余把安全集重新造大**——直接对冲第 65 轮「总膨胀同一个球」的过度保守。

**灵感 4（关节空间控制 → 零空间探针：不碰任务也能做实验）**
直觉：第 65 轮的 AFA 靠 press/rub/tap/lift 物理探针区分假设，对易损物体有伤害风险。但冗余臂可以做一种**任务不变的主动实验**：沿零空间 `q̇ = N(q) ξ` 运动，理想情况下 `J N ξ = 0`，末端（以及正在接触的物体）**纹丝不动**，却能激励关节摩擦、背隙、编码器偏置、关节柔顺等根因。也就是说，**信息量最大的探针恰好可以是伤害最小的探针**。而且姿态本身就是实验设计变量：选一个让「根因→残差」签名矩阵条件数最好的构型，等价于在构型空间做持续激励（persistent excitation）。

**灵感 5（合流 → JANUS：Joint-space Attribution with Null-space Uncertainty Separation）**
闭环：关节残差采集（编码器/力矩/正运动学）→ 因果校验三角（parity）→ 可组合根因原语稀疏归因（CCF）→ 归因模糊时做零空间探针（NS-PROBE）或姿态式实验设计 → 定向膨胀到关节级球（r_enc/r_kin/r_act/r_cal）并经雅可比映射回 VISTA 的任务球 → 故障感知姿态重构（FPR）把裕度造回来 → 关节安全包络认证前缀 k*_J（JSC）→ 执行 → 再归因。JANUS 不是替代 VISTA，而是**把 VISTA 的「任务空间归因」下沉到「关节空间根因」，再用雅可比把根因不确定度映射回原证书链**；当关节侧完全健康时，JANUS 严格退化为 VISTA。

**灵感 6（相对第 65 轮的原位升级）**
- **FIR → JCG-CCF**：有限任务假设集 → 关节故障原语的可组合稀疏支持；未知组合故障 = 稀疏并集，不再被强行归入最近假设。
- **AFA → NS-PROBE + 姿态式实验设计**：物理探针 → 零空间任务不变探针；易损物体不再需要接触探针。
- **CSC → JSC**：任务空间前缀 → 关节安全包络前缀；`k* = min(k*_VISTA, k*_J)`。
- **RSC-V → JS-RSC**：任务球 → 关节级球，经 `Σ_task = J Σ_q Jᵀ` 映射回任务球，避免把「编码器偏置」误记成「几何幻觉」。
- **WCV-V → WCV-J**：搜索域增关节可实现性/奇异/力矩约束；归因模糊时对**支持集**边缘化，而非只对 6 个假设边缘化。
- **CSP-V → CSP-J**：块边需同时通过任务证书与关节证书；新增 `null_probe`、`posture_probe` 元技能。
- **AIC-V → AIC-J**：干扰集增编码器偏置/丢帧、背隙/迟滞、谐波减速器摩擦、奇异混叠、零空间标定误差与关节级共因。
- **J_vista → J_janus**：证书增 primitive_support、support_entropy、parity_residuals、null_probe_gain、posture_id、JSC 裕度。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（JANUS 闭环与三平面）**：JANUS = (VISTA, JRM, JCG, CCF, NS-PROBE, FPR, JSC, JS-RSC, WCV-J, CSP-J, AIC-J, J_janus)。三个平面：**任务平面**（VISTA 的几何/力/视觉）、**关节平面**（q, q̇, τ 与雅可比）、**因果平面**（关节根因原语到任务残差的 parity 映射）。不变式：语义流做根因归因/姿态设计/证书；实时流只做关节残差采集、parity 计算、关节包络早停与派发，零学习写操作。
- **定义 234（关节观测量与四类关节残差）**：关节环以 1–2 kHz 采集 `(q_m, q̇_m, τ_m, q_d)`。定义
  - 跟踪残差 `e_q = q_m − q_d`；
  - 动力学残差 `e_τ = τ_m − RNEA(q_m,q̇_m,q̈_m) − Jᵀ f_FT`（若 F/T 可用；不可用则去掉该项）；
  - **运动学-视觉一致性** `Π_kin = log(T_FK(q_m)⁻¹ T_vis) ∈ se(3)`，只依赖关节状态与外部视觉，**不依赖接触**；
  - **力双通道 parity** `Π_force = f_FT − f̂_J`，其中 `f̂_J = (J(q_m)ᵀ)† τ_m^ext`，`τ^ext = τ_m − τ_model`。
  四者构成关节证据向量 `ρ_J = [e_q, e_τ, Π_kin, Π_force]`。**关键：`Π_force` 是不经过 F/T 的第二条力通道；`Π_kin` 是不经过接触的运动学见证。**
- **定义 235（关节故障原语与可组合原因分解 CCF）**：关节故障原语字典 `Φ = {φ_enc, φ_back, φ_fric, φ_comp, φ_kin, φ_gain, φ_sat, φ_dyn}`，分别对应编码器偏置/漂移、背隙/迟滞、摩擦（Stribeck）、关节柔顺、连杆/运动学标定误差、控制器增益/跟踪误差、力矩/速度饱和、惯性/负载模型错。观测的线性化 parity 方程 `ρ_J = P(q) φ + ε`，`P(q)` 为构型相关的**签名矩阵**（parity signature matrix）。归因不是从固定 ℋ 里选一个，而是求**稀疏支持** `Ŝ = supp(φ)`：
  `φ̂ = argmin_φ ½‖ρ_J − P(q)φ‖²_{Σ⁻¹} + λ‖φ‖_{2,1}`（按关节分组）。
  未知组合故障 = `Ŝ` 的稀疏并集；后验 `P(Ŝ|ρ_J)` 由 spike-and-slab 或 group-lasso 路径给出。**这直接消除「强制归入最近假设」的系统性错误。**
- **定义 236（因果校验三角与结构可辨识性）**：parity 残差在理想情形下按根因呈现**结构稀疏模式**：视觉故障只进 `Π_kin`；F/T 偏置只进 `Π_force`；编码器/运动学误差同时进 `Π_kin` 与 `Π_force`（因 `J(q)` 与 `T_FK(q)` 共用 q）；摩擦/柔顺/动力学错主要进 `e_τ` 与 `Π_force`；控制器跟踪进 `e_q` 与 `e_τ`。故 `P(q)` 的列近正交度为 `μ(P)`，可辨识裕度 `κ_J = λ_min(PᵀΣ⁻¹P)/λ_max(·)`。**共因故障的判别不再依赖「视觉与几何独立」的假设，而依赖「关节通道是否同时异常」的 parity 模式。**
- **定义 237（关节空间可辨识性与姿态式实验设计）**：`P(q)` 依赖构型。冗余臂的自运动流形 `M_task = {q: T_FK(q)=T_task}` 给出可免费选择的姿态。定义**可辨识性姿态设计**：
  `q* = argmax_{q∈M_task∩Q_safe} λ_min(P(q)ᵀΣ⁻¹P(q))`，或最小化 `μ(P(q))`。
  即姿态不只是避障变量，而是**让根因可分离的实验设计变量**；与 NS-PROBE 联用时还要求探针轨迹满足持续激励（摩擦需速度反向、背隙需方向反转、编码器偏置需足够运动量）。
- **定义 238（零空间探针 NS-PROBE）**：取零空间基 `N(q)`（`J(q)N(q)=0`），探针 `q̇ = N(q)ξ(t)`。精确模型下末端 twist 恒为零，接触力不变。模型误差 `δJ` 下有界任务漂移
  `‖Δx_task‖ ≤ ∫‖δJ(q)N(q)ξ‖dt ≤ ε_task`，
  接触力扰动 `‖Δf‖ ≤ K_c ε_task`。探针选择
  `ξ* = argmax_ξ I(Φ; ρ_J(ξ) | ρ_J^{past})`，s.t. `ε_task ≤ δf_safe/K_c`、`q(t)∈Q_safe`、`T_probe≤T_max`。
  **相比第 65 轮 AFA 的 press/rub/tap，NS-PROBE 在理想情形下对接触零扰动；其风险只剩「零空间本身标定不准」。**
- **定义 239（关节安全包络 JSE）**：构型相关安全集
  `Q_safe = {q: q_min+m ≤ q ≤ q_max−m, σ_min(J(q)) ≥ σ*, d_self(q) ≥ d*, |q̇|≤q̇_max, |q̈|≤q̈_max, |τ_i|≤τ_max,i−ε_τ}`。
  在根因支持 `Ŝ` 与 conformal 跟踪误差界 `e_q(α)` 下，预测关节管 `Q_tube(t)`。**关节不可逆视界** `m_J = inf{t: Q_tube(t) ⊄ Q_safe}`；关节认证前缀
  `k*_J = max{k ≤ m_J : ∀φ∈supp_δ(P(Ŝ|ρ)), ∀s≤k, margin_J(s;φ)≥0}`。
- **定义 240（故障感知姿态重构 FPR）**：在 `M_task∩Q_safe` 上重优化姿态：对已归因的故障关节集合 `Ŝ_act`，
  `q* = argmin_{q} max_{i∈Ŝ_act} |τ_i(q)|/τ_max,i + λ·max(0, −min_margin(q))`，
  保持任务位姿不变。即**把负载从故障关节转移到健康关节**，把关节限位/奇异裕度重新造出来。FPR 只能提高（或不变）可认证前缀上界，见定理 10。
- **定义 241（关节级定向膨胀 JS-RSC）**：维护关节级半径 `r_enc, r_kin, r_act, r_cal`，只膨胀被归因者，并经
  `Σ_task = J Σ_q Jᵀ + Σ_kin + Σ_cal` 映射回 VISTA 的任务球：
  `r_geo ← ‖J‖·r_enc + r_kin`，`r_force ← r_act`，`r_model ← r_cal`。
  与第 65 轮不同：当根因是编码器/运动学误差时，**不会再误膨胀 r_geo 而把正确几何判成幻觉**，而是同时扩大「位姿不确定」与「力映射不确定」，并触发关节侧重标定。
- **定义 242（WCV-J 关节-任务联合压缩）**：搜索域
  `B(φ̂,r) ∩ 𝒢(g) ∩ K(μ̂) ∩ ℱ(f_lim) ∩ 𝒱 ∩ Q_safe(q) ∩ K_reach(q,τ_max)`。
  归因模糊时对**支持后验** `P(Ŝ|ρ_J)` 做边缘化尾部（每个支持采一个最坏构型/力矩），而非只对假设集边缘化；交集为空先试 FPR 换姿态，再试软化，最后 safe_idle。
- **定义 243（CSP-J 关节感知块规划）**：块边需同时 `Valid(J_vista)` 与 `Valid(JSC)`；新增元技能 `null_probe`（零空间根因实验）、`posture_probe`（姿态式可辨识性优化）、`joint_recal`（关节侧重标定）。技能绑定「关节签名分布」`𝒟_σ^J`，实际 `ρ_J` 的 Mahalanobis 距离超阈值即判关节 OOD、不入图。
- **定义 244（AIC-J 关节级对抗认证）**：干扰集
  `ℰ_J = ℰ_V × ℰ_enc × ℰ_joint × ℰ_sing`，
  `ℰ_enc` 含编码器偏置/漂移/丢帧/量化；`ℰ_joint` 含背隙/迟滞、谐波减速器摩擦、关节柔顺、运动学标定误差、力矩饱和；`ℰ_sing` 含奇异混叠（`σ_min→0` 时 `τ=Jᵀf` 不可唯一反解）与零空间标定误差。并新增**关节级共因**（同一标定误差同时污染 FK、视觉投影与力矩映射）。`n_cert` 由 128 增至 160，其中 32 给关节侧；共因下只要求判「支持不唯一」并安全降级。
- **定义 245（J_janus 证书）**：`J_janus = (J_vista, primitive_support, support_entropy, parity_residuals, null_probe_gain, posture_id, jsc_margins, aic_j_ver)`。验证规则：
  `Valid(J_janus) ⇔ Valid(J_vista) ∧ (支持唯一 ∨ 已执行 NS-PROBE ∨ 已判 ambiguous 并安全降级) ∧ Valid(JSC) ∧ k* = min(k*_VISTA,k*_J) ≥ 1 ∧ (Π_kin 一致 ∨ 视觉标记不可观测) ∧ 姿态未越出自碰撞/关节限位`。
- **定义 246（关节-任务安全编译 JTS）**：把任务块 `A_t` 经逆运动学（含全部 IK 分支与姿态选择）编译为关节轨迹 `Q_t`，在关节管上认证 `k*_J`，再映射回任务前缀 `k*`。**预测仍在任务空间（长视界），承诺在关节空间（短前缀）**——这是第 65 轮「长预测、短执行」的坐标系修正。
- **定义 247（JANUS 归因算子）**：`ρ_J ← [e_q,e_τ,Π_kin,Π_force]` → `P(q)` → 稀疏支持 `P(Ŝ|ρ_J)` → 若 `H(Ŝ)>δ_S` 则 NS-PROBE/姿态式实验 → 定向膨胀 `r_enc/r_kin/r_act/r_cal` → FPR 姿态重构 → JSC 认证 `k*_J` → 执行 `k*=min(k*_VISTA,k*_J)` → 关节侧重标定/再归因。
- **定义 248（退化与包含关系）**：当关节侧健康（`φ=0`、`Π≈0`、无关节越界）且姿态固定时，JANUS 的 `P(Ŝ|ρ_J)` 退化为单一空支持，`r_*` 不变，`k*_J ≥ k*_VISTA`，故 `J_janus ≡ J_vista`。**这保证 JANUS 是 VISTA 的严格扩展，而非另起炉灶。**

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（关节 parity 的结构可分离性）**：在 `ρ_J = P(q)φ+ε` 下，若 `P(q)` 在支持 `Ŝ` 上满足限制特征值条件（RE）与互相关 `μ(P)<1/(2|Ŝ|−1)`，则稀疏支持可辨识；结构模式（视觉只进 `Π_kin`、F/T 只进 `Π_force`、编码器/运动学同时进两者、动力学进 `e_τ/Π_force`）使 `P` 的列近正交。故「未知组合故障」被表示为稀疏并集而非被强行归类，支持错误率随 `exp(−n·κ_J/2)` 下降。
- **引理 10（零空间探针的任务不变性与有界伤害）**：精确模型下 `J N=0` ⇒ 末端 twist 与接触力不变；模型误差 `δJ` 下 `‖Δf‖≤K_c‖δJ‖‖Nξ‖T`。只要设计时预留 `ε_task≤δf_safe/K_c`，NS-PROBE 对易损物体仍零伤害。**这是第 65 轮 AFA 的物理探针无法给出的保证。**
- **引理 11（关节视界必要性）**：存在任务空间证书合格但关节侧越界的轨迹（奇异附近力权威丧失、力矩饱和、关节限位）。故任务证书不蕴含关节可行，真实不可逆视界 `m_true = min(m_task, m_J)`，认证必须同时满足两侧。
- **定理 9（JANUS 根因-安全）**：在 A94–A99 下，JANUS 要么给出唯一稀疏支持 `Ŝ` 并把膨胀定向到正确关节级半径，要么判支持模糊并执行任务不变 NS-PROBE 或安全空闲；`Valid(J_janus)` ⇒ 前缀 `k*` 内无任务/关节不可逆越界，且**关节级共因（编码器/标定误差同时污染 FK、视觉投影与力矩映射）不会被误归因为 H_vis 或 H_geo**，因为 parity 三角要求三通道同时满足，而非依赖视觉-几何独立性。
- **定理 10（姿态作为安全资源的支配性）**：若自运动流形上存在 `q'` 使最小关节裕度更大，则 FPR 在不改变末端位姿的前提下使 `k*_J` 不减；对关节局部故障，负载重分配降低故障关节的 `max|τ_i|/τ_max,i`。故「换姿态」在可达时严格优于「只膨胀球」。
- **命题（VISTA 严格包含）**：关节健康且姿态固定时 JANUS 退化为 VISTA（定义 248），因此所有 VISTA 保证保留，新增保证不引入额外前提到 VISTA 内部。
- **实时性**：parity 与关节包络在实时流（<0.3ms）；稀疏支持、NS-PROBE 设计、FPR、JSC 全在语义流；目标实时路径 ≤2.6ms。

## 2. 形式化定义（完整版）

**定义 233（JANUS 闭环与三平面）** JANUS 是 VISTA 的「关节空间根因归因」升级，由三个平面构成：
- **任务平面**：VISTA 的几何/力/视觉/接触证据与任务球 `r_geo/r_force/r_model`；
- **关节平面**：`(q_m,q̇_m,τ_m,q_d)` 与 `J(q), T_FK(q), Q_safe`；
- **因果平面**：关节故障原语 `Φ` 经 `P(q)` 生成任务空间症状的 parity 映射。

闭环为：JRM 关节残差 → JCG parity → CCF 稀疏支持 →（模糊时）NS-PROBE/FPR → JS-RSC 定向膨胀 → WCV-J 联合压缩 → CSP-J 块规划 → JSC 认证前缀 → 执行 `min(k*_VISTA,k*_J)` → 关节侧重标定/再归因 → AIC-J。不变式：**所有稀疏归因、探针设计、姿态优化、证书构建在语义流；实时流只做关节残差采集、parity 计算、关节包络早停与派发，零学习写操作。**

**定义 234（关节观测量与四类关节残差）** 关节环以 1–2 kHz 同步采集 `(q_m,q̇_m,τ_m,q_d)`，语义流缓存最近一个动作块窗口。定义
```
e_q(t)   = q_m(t) − q_d(t)
e_τ(t)   = τ_m(t) − RNEA(q_m,q̇_m,q̈_m) − J(q_m)ᵀ f_FT(t)
Π_kin(t) = log( T_FK(q_m(t))⁻¹ T_vis(t) ) ∈ se(3)
Π_force(t)= f_FT(t) − f̂_J(t),   f̂_J = (J(q_m)ᵀ)† (τ_m − τ_model)
ρ_J(t)   = [ e_q(t), e_τ(t), Π_kin(t), Π_force(t) ]
```
其中 `RNEA` 为刚体逆动力学，`τ_model` 为不含接触项的模型力矩；F/T 不可用时 `e_τ` 去掉 `Jᵀf_FT` 项，`Π_force` 标记 `force_channel_unobservable`。**`Π_kin` 是唯一不依赖接触、也不依赖 F/T 的位姿见证；`Π_force` 是唯一不依赖 F/T 传感器的力见证。** 二者与 `e_τ` 共同构成「正运动学—视觉—关节力矩」三角。

**定义 235（关节故障原语与可组合原因分解 CCF）** 关节故障原语字典
```
Φ = { φ_enc   编码器偏置/漂移/量化,
      φ_back  背隙/迟滞（谐波减速器方向反转）,
      φ_fric  关节摩擦（Stribeck/Coulomb/viscous）,
      φ_comp  关节柔顺/传动弹性,
      φ_kin   连杆长度/关节零位/运动学标定误差,
      φ_gain  控制器增益/跟踪带宽误差,
      φ_sat   力矩/速度/加速度饱和,
      φ_dyn   惯性/负载/未建模动力学 }
```
观测线性化为 `ρ_J = P(q)φ + ε`，`ε` 为零均值、协方差 `Σ` 的残差（含传感器噪声与模型线性化误差）。归因不再是「从 6 个任务假设里选一个」，而是**稀疏支持恢复**：
```
φ̂ = argmin_φ  ½‖ρ_J − P(q)φ‖²_{Σ⁻¹} + λ‖φ‖_{2,1}
P(Ŝ|ρ_J) ∝ P(ρ_J|Ŝ) P(Ŝ),   Ŝ = supp(φ)
```
其中 `‖·‖_{2,1}` 按关节分组，使同一关节的多个原语可同时激活。**未知组合故障被表示为 `Ŝ` 的稀疏并集**；若 `P(Ŝ|ρ_J)` 在多个支持间分散，则判 `support_ambiguous` 而非归入最近假设。

**定义 236（因果校验三角与结构可辨识性）** 理想情形下 `P(q)` 的列具有结构稀疏模式（0 表示该通道对原语一阶不敏感）：

| 原语 \ 通道 | `e_q` | `e_τ` | `Π_kin` | `Π_force` | 机理 |
|---|---|---|---|---|---|
| `φ_vis`（外部视觉错） | 0 | 0 | ≠0 | 0 | 只污染视觉投影 |
| `φ_FT`（F/T 偏置） | 0 | 0 | 0 | ≠0 | 只污染力通道 |
| `φ_enc`（编码器） | ≠0 | ~0 | ≠0 | ≠0 | q 同时进 FK 与 J |
| `φ_kin`（运动学标定） | ~0 | ~0 | ≠0 | ≠0 | FK 与 J 共用运动学 |
| `φ_fric`（摩擦） | ~0 | ≠0 | 0 | ≠0 | 经 `τ^ext` 进入 |
| `φ_comp`（关节柔顺） | ≠0 | ≠0 | ~0 | ≠0 | 跟踪与力矩耦合 |
| `φ_gain`（控制器） | ≠0 | ≠0 | 0 | ~0 | 跟踪误差 |
| `φ_sat`（饱和） | ≠0 | ≠0 | 0 | ≠0 | 事件性饱和 |
| `φ_dyn`（动力学模型） | ~0 | ≠0 | 0 | ≠0 | 模型残差 |

定义互相关 `μ(P)=max_{i≠j}|P_iᵀΣ⁻¹P_j|/(‖P_i‖‖P_j‖)` 与可辨识裕度 `κ_J=λ_min(PᵀΣ⁻¹P)/λ_max(PᵀΣ⁻¹P)`。**共因故障（如同一标定误差同时污染 FK、视觉投影与力矩映射）不再依赖「视觉与几何独立」，而是表现为 `Π_kin` 与 `Π_force` 同时异常、且与 `e_q/e_τ` 的模式一致。** `φ_vis` 与 `φ_FT` 作为外部列并入，用于把关节根因与第 65 轮的 `H_vis/H_force` 对齐。

**定义 237（关节可辨识性与姿态式实验设计）** `P(q)` 依赖构型，冗余臂有自运动流形 `M_task={q:T_FK(q)=T_task}`（n>6 时非空）。定义可辨识性姿态
```
q* = argmax_{q∈M_task∩Q_safe} λ_min(P(q)ᵀΣ⁻¹P(q))
```
或等价地最小化 `μ(P(q))`。这使姿态成为**实验设计变量**：同一任务下，换一个姿态可能让 `φ_enc` 与 `φ_kin` 的列从近共线变为可分（编码器偏置是关节 DC，运动学误差随位形变化，二者在多个姿态下的一致性不同）。与 NS-PROBE 联用时，还要求探针在关节侧满足持续激励：摩擦需速度反向、背隙需方向反转、编码器偏置需足够运动量，即
```
∫₀^T N(q)ξ(t)ξ(t)ᵀN(q)ᵀ dt ≻ 0  且  探针含 ≥k_rev 次关节速度变号。
```

**定义 238（零空间探针 NS-PROBE）** 取零空间基 `N(q)`（`J(q)N(q)=0`），探针轨迹 `q̇=N(q)ξ(t)`，`q(0)=q_m`。精确模型下末端 twist `J q̇=0`，接触点与接触力不变。模型误差 `δJ` 下
```
‖Δx_task(t)‖ ≤ ∫₀ᵗ ‖δJ(q(τ))N(q(τ))ξ(τ)‖ dτ ≤ ε_task
‖Δf(t)‖      ≤ K_c ε_task
```
其中 `K_c` 为接触刚度上界。探针选择
```
ξ* = argmax_ξ  I(Φ; ρ_J(ξ) | ρ_J^past)
     s.t.  ε_task ≤ δf_safe/K_c,  q(t)∈Q_safe,  T_probe≤T_max,
           探针满足持续激励与 ≥k_rev 次反向.
```
若 `δf_safe` 极小（易损物体）则收紧 `ε_task`，退化为**纯零空间低速探针**；若零空间标定不可信（`δJ` 上界未知）则禁止 NS-PROBE，改走被动观测或 `null_test`。

**定义 239（关节安全包络 JSE 与认证前缀 JSC）** 构型相关安全集
```
Q_safe(q) = { q : q_min+m_q ≤ q ≤ q_max−m_q,
                 σ_min(J(q)) ≥ σ*,
                 d_self(q) ≥ d*,
                 |q̇_i|≤q̇_max,i, |q̈_i|≤q̈_max,i,
                 |τ_i| ≤ τ_max,i − ε_τ }
```
对根因支持 `P(Ŝ|ρ_J)` 与 conformal 关节跟踪误差 `e_q(α_J)`，预测关节管
`Q_tube(t) = { q̂(t)+e : |e_i|≤e_{q,i}(α_J) }`。关节不可逆视界
```
m_J = inf{ t : Q_tube(t) ⊄ Q_safe(q(t)) }.
```
关节认证前缀
```
k*_J = max{ k ≤ m_J : ∀Ŝ'∈supp_δ(P(Ŝ|ρ_J)), ∀s≤k,
                    margin_J(s;Ŝ') ≥ 0 }.
```
最终执行前缀 `k* = min(k*_VISTA, k*_J)`。**任务空间证书合格不再等于安全：奇异、力矩饱和、关节限位与自碰撞是任务空间不可见的不可逆事件，必须在关节侧认证（引理 11）。**

**定义 240（故障感知姿态重构 FPR）** 在 `M_task∩Q_safe` 上重新优化姿态，保持末端位姿不变。对已归因的故障关节集合 `Ŝ_act`：
```
q* = argmin_{q∈M_task∩Q_safe}  max_{i∈Ŝ_act} |τ_i(q)|/τ_max,i
                              + λ_s · max(0, −min_margin(q))
                              + λ_c · path_cost(q_m→q)
```
即把负载从故障关节（摩擦/背隙/柔顺）转移到健康关节，并顺带最大化奇异/限位/自碰撞裕度。若最优姿态只差一个自运动量，轨迹须限制在 `Q_safe` 内并做自碰撞检查。FPR 输出的 `posture_id` 写入证书。

**定义 241（关节级定向膨胀 JS-RSC）** 维护四个关节级半径：
- `r_enc`：编码器偏置/漂移/量化 → 关节位置不确定；
- `r_kin`：运动学标定/连杆误差 → 位姿映射不确定；
- `r_act`：摩擦/柔顺/饱和/动力学模型 → 力矩与力映射不确定；
- `r_cal`：接触模型/刚度标定 → 接触不确定。

只膨胀被归因的原语所属半径，并经
```
Σ_task = J Σ_q Jᵀ + Σ_kin + Σ_cal,   Σ_q = diag(r_enc²),  Σ_kin = r_kin² I,
r_geo   = ‖J‖₂ r_enc + r_kin,        r_force = r_act,      r_model = r_cal
```
映射回 VISTA 的任务球 `r_geo/r_force/r_model`。与第 65 轮的关键差别：**编码器/运动学误差导致的不一致不再被误记为「几何幻觉」而膨胀 r_geo 到把正确几何降级；它被记为位姿映射不确定，并触发关节侧重标定。**

**定义 242（WCV-J 关节-任务联合压缩）** 搜索域
```
B(φ̂,r) ∩ 𝒢(g) ∩ K(μ̂) ∩ ℱ(f_lim) ∩ 𝒱 ∩ Q_safe(q*) ∩ K_reach(q*,τ_max)
```
其中 `K_reach` 为构型相关的关节可实现集（力矩可兑现、非奇异、限位可行）。归因模糊时对**支持后验**边缘化尾部：对每个 `Ŝ'∈supp_δ` 采一个最坏构型 `q'∈M_task` 与最坏原语幅度，按 `P(Ŝ'|ρ_J)` 加权。交集为空时依次：FPR 换姿态 → 软化任务/力需求 → `safe_idle`；任何一步只使动作更保守。

**定义 243（CSP-J 关节感知块规划）** 在 CSP-V 的块级 A* 上，每条块边需 `Valid(J_vista) ∧ Valid(JSC)` 且 `k*≥1`。新增元技能：
- `null_probe`：零空间根因实验，目标最大化 `I(Φ;ρ_J)`；
- `posture_probe`：姿态式可辨识性优化，目标最小化 `μ(P(q))`；
- `joint_recal`：关节侧重标定（编码器零位/背隙/摩擦参数）。
技能绑定关节签名分布 `𝒟_σ^J`；实际 `ρ_J` 到 `𝒟_σ^J` 的 Mahalanobis 距离 `>τ_J` 即判关节 OOD、不入图。软约束增 `λ_S·H(P(Ŝ|ρ_J))` 与 `λ_J·Σ hinge(k*_J−k_req)`。

**定义 244（AIC-J 关节级对抗认证）** 干扰集
```
ℰ_J = ℰ_V × ℰ_enc × ℰ_joint × ℰ_sing
```
- `ℰ_enc`：编码器偏置/漂移/丢帧/量化、零位跳变；
- `ℰ_joint`：背隙/迟滞、谐波减速器摩擦、关节柔顺、运动学标定误差、力矩饱和；
- `ℰ_sing`：奇异混叠（`σ_min(J)→0` 时 `τ=Jᵀf` 方向不可唯一反解）、零空间标定误差 `δJ`、自运动路径自碰撞；
- **关节级共因**：同一标定误差同时污染 `T_FK`、视觉投影与 `J`，使 `Π_kin` 与 `Π_force` 同向偏移。

`ρ_J` 在 `ℰ_J` 上重算，`n_cert` 由 128 增至 160（32 给关节侧）；`J_dir` 增 `joint_calib_ver`、`parity_model_ver`、`ns_calib_ver`。**关节级共因下不要求支持唯一，只要求 `support_entropy` 有界、判 `support_ambiguous` 并安全降级。**

**定义 245（J_janus 证书）** 
```
J_janus = ( J_vista, primitive_support, support_entropy,
            parity_residuals, null_probe_gain, posture_id,
            jsc_margins, aic_j_ver )
```
验证规则：
```
Valid(J_janus) ⇔ Valid(J_vista)
  ∧ ( H(P(Ŝ|ρ_J)) ≤ δ_S  ∨  已执行 NS-PROBE  ∨  已判 support_ambiguous 且安全降级 )
  ∧ Valid(JSC)  ∧  k* = min(k*_VISTA,k*_J) ≥ 1
  ∧ ( ‖Π_kin‖ 一致  ∨  视觉标记 visual_unobservable )
  ∧ posture_id 对应姿态满足 Q_safe（含自碰撞/限位）
  ∧ aic_j_ver = 当前版本。
```
审计链新增：**为何膨胀这个关节半径（primitive_support）、parity 三角是否一致（parity_residuals）、零空间探针是否真的没碰任务（null_probe_gain/ε_task）、执行前缀为何停在 k*_J（jsc_margins）、当前姿态是否安全（posture_id）。**

**定义 246（关节-任务安全编译 JTS）** 给定任务块 `A_t`（VISTA 生成），经逆运动学（枚举全部 IK 分支，按 `posture_id` 选支）编译为关节轨迹
```
Q_t = IK(A_t; q*, branch) ∈ ℝ^{H×n}
```
在 `Q_t` 上做 JSC 得到 `k*_J`，并映射回任务前缀 `k* = min(k*_VISTA,k*_J)`。**预测仍在任务空间（长视界 H 保持方差缩减），承诺在关节空间（短前缀 k*_J 保证关节不可逆事件不越界）。** 这是第 65 轮「长预测、短执行」的坐标系修正：长视界属于任务，短承诺属于关节。

**定义 247（JANUS 归因算子）** 
```
ρ_J ← [e_q, e_τ, Π_kin, Π_force]
P(q), Ŝ, P(Ŝ|ρ_J) ← CCF(ρ_J, Φ, q)
if H(P(Ŝ|ρ_J)) > δ_S:
    ξ* ← NS-PROBE(Ŝ, δf_safe, Q_safe) 或 posture_probe(q)
    ρ_J ← ρ_J ∪ probe evidence
r_enc,r_kin,r_act,r_cal ← JS-RSC(Ŝ)
q* ← FPR(q, M_task, Ŝ, Q_safe)
balls ← map_to_task_balls(J(q*), r_enc,r_kin,r_act,r_cal)
k*_J ← JSC(Q_t, P(Ŝ|ρ_J), Q_safe)
k* ← min(k*_VISTA, k*_J)
```
若 `Ŝ` 涉及 `φ_enc/φ_kin` 且 `P(Ŝ)` 高，则触发关节侧重标定并在重标定前禁止高力任务；若只涉及 `φ_fric/φ_comp`，则 FPR 重分配负载 + 提高柔顺；若 `Π_kin` 与 `Π_force` 模式无法匹配任何原语，则判 `unknown_joint_fault` 并 `safe_idle`。

**定义 248（退化与包含关系）** 当 `φ=0`（关节健康）、`Π_kin,Π_force,e_τ` 均在噪声带内、且不触发 FPR 时，`P(Ŝ|ρ_J)` 退化为空支持，`r_*` 不变，`Q_safe` 对 `k*_VISTA` 无约束（`k*_J≥k*_VISTA`），故 `J_janus ≡ J_vista`。因此 JANUS **严格包含** VISTA：不改变其任何保证，只在其上游补上关节根因与关节安全。

class JointSafetyCertificate:
    def certified_prefix(self, Q_t, support_post, Q_safe, tau_max, alpha_J, delta=0.1):
        supp = {S: p for S, p in support_post.items() if p >= delta}
        k_best = 0
        for k in range(1, len(Q_t) + 1):
            ok = True
            for S in supp:
                for s in range(k):
                    m = joint_margin(Q_t[s], S, Q_safe, tau_max,
                                     e_q_bound=conformal_q(alpha_J))
                    if m < 0:
                        ok = False
                        break
                if not ok:
                    break
            if not ok:
                break
            if self._violation_prob(Q_t[:k], supp) <= alpha_J:
                k_best = k
        return k_best

    def monitor(self, q_now, support_post):
        # 实时：关节限位/奇异/力矩/CUSUM 是否越界
        return AbortFlag(abort=joint_envelope_violated(q_now, support_post))

                singularity_margin(q),
                self_collision_margin(q),
                torque_margin(q, S, tau_max),

class FaultAwarePosture:
    def optimize(self, q_now, M_task, S_act, Q_safe, tau_max, lambda_s=1.0):
        # 在自运动流形上搜索，末端位姿不变
        def cost(q):
            load = max(abs(tau_of(q, i)) / tau_max[i] for i in S_act) if S_act else 0.0
            return load + lambda_s * max(0.0, -min_margin(q, Q_safe))
        q_best, best = q_now, cost(q_now)
        for q in self_motion_candidates(q_now, M_task, n_samples=64):
            if not inside_safe(q, Q_safe) or self_collision(q):
                continue
            c = cost(q)
            if c < best:
                q_best, best = q, c
        return q_best, best

## 4. 推导

**引理 9（关节 parity 的结构可分离性）** 设 `ρ_J=P(q)φ+ε`，`ε∼N(0,Σ)`，`φ` 至多 `s`-稀疏（按关节分组）。若 `P(q)` 在 `supp(φ)` 上满足限制特征值条件
`(1−δ_s)‖φ‖² ≤ ‖Pφ‖²_{Σ⁻¹} ≤ (1+δ_s)‖φ‖²`，
或更易验证的互相关条件 `μ(P) < 1/(2s−1)`，则由 group-lasso/group-OMP 恢复的支持满足
`P(Ŝ ≠ supp(φ)) ≤ 2|Φ|·exp(−n·κ_J/2 + o(n))`。
结构上，定义 236 的零模式使视觉故障（仅 `Π_kin`）、F/T 故障（仅 `Π_force`）、编码器/运动学故障（`Π_kin∧Π_force`）、驱动/动力学故障（`e_τ∧Π_force`）落在不同的通道子集；当成对通道的「一致/不一致」模式匹配某原语列时，该原语被支持；不匹配任何列时判 `unknown_joint_fault`。因此**未知组合故障被表示为稀疏并集，而不是被投影到最近的任务假设**。∎

**引理 10（零空间探针的任务不变性与有界伤害）** 精确模型下 `J(q)N(q)=0`，故 `ẋ = J q̇ = JNξ = 0`，末端位姿与接触点不变；接触力由接触点相对位移决定，故 `Δf=0`。当存在运动学误差 `δJ` 时，
`‖Δx(t)‖ = ‖∫δJ N ξ dτ‖ ≤ ‖δJ‖_∞ ‖Nξ‖_∞ T =: ε_task`，
接触刚度 `K_c` 下 `‖Δf‖≤K_c ε_task`。只要探针设计满足 `ε_task ≤ δf_safe/K_c`，则 `‖Δf‖≤δf_safe`，对易损物体无伤害。若 `δJ` 上界不可信，则禁止探针（定义 238）。∎

**引理 11（关节视界必要性）** 构造反例：设某任务方向对应最小奇异值 `σ_min(J)`。要产生该方向的接触力 `f`，最小范数关节力矩含分量 `‖τ‖ ≥ ‖f‖/σ_min`（因为 `Jᵀ(JJᵀ)⁻¹` 的奇异值为 `1/σ_i`）。当 `σ_min→0`（接近奇异）时，`‖τ‖→∞` 超过 `τ_max`，而任务空间的力/几何裕度可能仍然为正。同理，末端在可达工作空间内时，IK 解仍可能越过关节限位或自碰撞。故存在 `Valid(J_vista)` 但关节侧越界的轨迹，任务证书不蕴含关节可行；真实不可逆视界 `m_true=min(m_task,m_J)`，必须双侧认证。∎

**定理 9（JANUS 端到端根因-安全）** 在以下假设下：
- **A94**：parity 线性化模型结构正确，`ε` 有界且协方差已知；
- **A95**：`φ` 稀疏，且经姿态/探针设计后 `P(q)` 满足引理 9 的 RE 或互相关条件；
- **A96**：零空间标定误差 `δJ` 上界已知，探针满足 `ε_task≤δf_safe/K_c`；
- **A97**：关节跟踪误差满足 conformal 覆盖 `P(e_q≤e_q(α_J))≥1−α_J`；
- **A98**：力双通道仅在 `σ_min(J)≥σ*` 时可信，否则标记 `force_channel_unobservable`；
- **A99**：FPR 与 IK 均在 `Q_safe` 内并做过自碰撞检查；
则：
1. **根因可分离**：`Ŝ` 以引理 9 的速率恢复，未知组合故障表示为稀疏并集；关节级共因（`φ_enc/φ_kin`）因同时触发 `Π_kin∧Π_force` 而不被误归因为 `φ_vis` 或 `φ_geo`。
2. **探针安全**：`support_ambiguous` 时优先 NS-PROBE；在 A96 下接触力扰动 `≤δf_safe`；若不可行则安全空闲，绝不对易损物体施加未认证接触探针。
3. **定向膨胀**：JS-RSC 只膨胀被归因的关节半径并映射回任务球，正确几何不因传感器/运动学故障被降级。
4. **执行安全**：`Valid(J_janus)` ⇒ `Valid(J_vista)` 且 `k*≤m_J`，故前缀内无任务或关节不可逆越界。
5. **优雅降级**：关节侧未知故障 → `support_ambiguous` + `safe_idle`；视觉不可用 → `Π_kin` 仍可提供关节-视觉一致性（若视觉不可用则退化为纯关节/力）；F/T 不可用 → `f̂_J` 提供第二力通道（需 A98）。
6. **证书链**：从「几何-技能-干扰-接触-归因」扩展到「几何-技能-干扰-接触-归因-关节根因-关节包络」。∎

**定理 10（姿态作为安全资源的支配性）** 设 `M_task` 非空（冗余臂 n>6）。定义关节侧最坏裕度 `M(q)=min_i margin_i(q)`。若存在 `q'∈M_task∩Q_safe` 使 `M(q')>M(q)`，则 FPR 选择 `q'` 后，对任意支持 `Ŝ`，`k*_J(q') ≥ k*_J(q)`（因为 JSC 的可行性由最坏裕度决定，裕度越大可行前缀越长），且末端位姿任务完全不变。对已归因的故障关节集合 `Ŝ_act`，FPR 的最小最大化目标直接降低 `max_{i∈Ŝ_act}|τ_i|/τ_max,i`；若该最坏比值是 JSC 的瓶颈，则 `k*_J` 不减而故障关节负载下降。故在可达时，「换姿态」严格优于「只膨胀球」：后者只收缩允许集，前者同时改变 `J(q)` 与力矩映射以扩张安全集。∎

**命题 1（VISTA 严格包含）** 当 `φ=0` 且 `Π_kin,Π_force,e_τ` 在噪声带内、FPR 不改变姿态时，`Ŝ=∅`，`r_enc=r_kin=r_act=r_cal` 不变，`r_geo/r_force/r_model` 与第 65 轮一致；`Q_safe` 对 `k*_VISTA` 无额外约束（`k*_J≥k*_VISTA`），故 `k*=k*_VISTA`、`J_janus≡J_vista`。JANUS 不改变 VISTA 的任何保证，只在其上游增加关节根因与关节包络。∎

**命题 2（力双通道可观测性）** `f̂_J=(Jᵀ)†τ^ext` 仅在 `J` 行满秩（`σ_min(J)>0`）时唯一。定义不可观测方向 `𝒩_f = null(Jᵀ)`（`dim = n−rank(J)`，冗余臂上包含零空间力矩对应的「不产生末端力的关节力矩」）。误差界
`‖δf̂_J‖ ≤ (1/σ_min)‖δτ‖ + (‖f‖/σ_min²)‖δJ‖`。
因此 `Π_force` 的信任权重应为 `w_J = σ_min²/(σ_min²+c·δJ²)`；当 `σ_min<σ*` 时对 `𝒩_f` 方向标记 `force_channel_unobservable`，退回 F/T 与视觉交叉验证。**这防止在奇异/冗余退化处把关节力矩不可观测误判为 F/T 偏置。** ∎

## 7. 已知风险

**一句话**：JANUS 把安全与归因的根都扎在关节状态 `q` 与模型 `J(q)` 上，但最危险的故障恰恰是编码器偏置、运动学标定误差与关节柔顺——它们直接污染 `q`、`T_FK` 与 `J` 本身；此时零空间探针不再是任务不变的（残余任务运动可能撞上接触），关节安全包络也是用被污染的构型算出来的，系统实际上在**用可能出错的关节通道去证明关节通道可信**，而 parity 模型又会把由此产生的不一致部分地推给视觉/力，形成新的自指盲区（隐藏假设 A94）。

**次级风险与缓解**：
1. **关节级共因/自指**：编码器与运动学误差同时污染 `q`、`T_FK`、`J`；缓解：AIC-J 显式建模共因，要求 `Π_kin` 与 `Π_force` 模式一致才归因；引入第三个物理独立通道（IMU/本体外部跟踪/激光跟踪仪）做离线标定校验；标定不可信时禁止 NS-PROBE 与高力任务。
2. **力双通道在奇异/冗余处不可观测**：`Jᵀ` 秩亏，`f̂_J` 在 `𝒩_f` 上无定义；缓解：命题 2 的 `w_J` 加权与 `force_channel_unobservable` 标记，退回 F/T；奇异附近禁用高力。
3. **零空间标定误差使探针不再零任务运动**：`δJ N ξ≠0`；缓解：引理 10 的 `ε_task≤δf_safe/K_c` 硬约束 + 低速短探针；每次探针后用视觉/力验证接触未变。
4. **摩擦/背隙/迟滞的非线性与负载依赖**：线性化 `P(q)` 失配；缓解：局部线性化 + 多工况标定表；用 NS-PROBE 的方向反转/速度扫描分段辨识；残差超界即判 `support_ambiguous`。
5. **稀疏性假设失效**：真实故障可能非稀疏（多点同时漂移）；缓解：支持熵阈值 + 最坏联合膨胀回退；离线扩充原语字典；非稀疏时退化为保守 `safe_idle`。
6. **姿态重构的运动代价与自碰撞**：FPR 可能大幅自运动；缓解：`path_cost` 正则 + 自碰撞检查 + 只在语义流低频执行；若换姿态风险高于收益则不换。
7. **IK 分支与关节限位不一致**：任务块映射到关节时可能无解/跳支；缓解：枚举全部分支、按 `posture_id` 连续选支、无解即缩短 k* 并重规划。
8. **实时预算**：关节 parity + 包络逼近 2.6ms；缓解：parity 只算所需行、RNEA 与控制器共享中间量、FPR/CCF 全部留语义流。
