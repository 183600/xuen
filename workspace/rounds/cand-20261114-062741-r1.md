# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS 具身计量审计」IP-287~294；灵感循环第 1 轮；本轮灵感：「运动学」×「双臂协作」）

> R72 把 R71 的「认知层 GAUGE」下沉为「具身 GAUGE」：REG 实时执行图、IRL 意图隐变量、DMEM 灵巧接触计量、EREFLEX 三层反作用、S2R-UQ 桥接，核心命题是「在 ROS 实时调度下、面对意图模糊的人、用灵巧手触摸世界时，仍逐指令兑现风险界」。它审计了**外部感知链**（视觉/语言/触觉/音频）、**调度时序**与**意图/接触不确定度**。但 R72 有两处结构性盲区，恰好被「运动学」与「双臂协作」同时刺中：
> - **运动学视角**：R72 把机器人自己的**身体模型**当成真值。正/逆运动学、Jacobian、DH 参数、连杆长度、关节零点、减速比、回差、连杆柔性——这些不是「已知常数」，而是一条**同样需要标定、追溯与不确定度传播的测量链**。更尖锐的是：任务空间里「很小」的风险，经 Jacobian 逆映射到关节空间可能在**奇异方向被放大到无穷**；标定参数本身存在**规范自由度（gauge freedom）**，其 Fisher 信息在规范轨道上奇异，直接报「参数协方差」在数学上是**不可辨识**的。**R72 的 λ 分母里没有「身体模型不确定度」，也没有「条件数」；它会自信地把机械臂开进奇异点。**
> - **双臂协作视角**：R72 的接触计量是**单臂/单手的接触模式**。双臂协作把问题变成**闭运动链**：两只手同时抓住同一物体时，系统是**过约束**的，任何相对标定误差、柔性、跟踪误差都不会消失，而会转化为**内力（internal wrench）**——两臂「互相较劲」，轻则滑移，重则把物体捏碎、把关节拧坏。同时，两只臂的观测**不是独立的**：它们共享世界系、共享相机、共享标定误差（公共模），把两份相关证据当独立证据融合会**系统地过度自信**。**R72 的「单源不定案」只防了单传感器，没防「两只手一起错」。**
>
> 本轮两个灵感不是并列补丁，而是同一条链的两端：
> - **运动学** 把「身体」纳入计量：**KIN-MET**（运动学计量链）、**SE3-GAUGE**（标定规范商与帧不变性）、**SING-VETO**（奇异/条件数非补偿否决）。
> - **双臂协作** 把「耦合」纳入计量：**BIM-MET**（闭链一致性与内力计量）、**XCOV-FUSE**（跨臂相关证据融合与分歧检验）、**COOP-RISK**（协作风险缩放）。
> - **两者交汇**：证书不再只属于单个体，而属于**一对相互约束的体**——**J_DUAL 联合证书与组合定理**：两张各自有效的单臂证书**不能**推出双臂安全，必须额外证明「闭链一致、内力可控、相关性未被低估、决策帧不变」。
>
> 核心命题：**从「在实时调度下我的外部测量链可信吗」，进化为「我对自己身体的模型可信吗、我和另一只臂之间的耦合被正确计量了吗、换一个参考系/换一种标定规范我的结论还成立吗？」** —— **KIN-COOP-GAUGE-RAS：运动学自模型 × 双臂闭链耦合 × 规范不变 × 联合证书的具身证据闭环。**

## 0. 直觉与动机

**灵感 1（运动学 → 身体模型不是真值，是第一条测量链）**
直觉：我们用视觉测物体、用触觉测接触，却默认「我知道我的手在哪」。但 `T = FK(q; θ_kin)` 里的 θ_kin（连杆长度、关节零点、减速比、工具坐标系）来自**标定**；q 来自**编码器**（有噪声、量化、温漂）；「刚体连杆」是**近似**（有柔性、回差、热膨胀）。于是「末端位姿」本身是一个**带不确定度的估计量**：`Σ_ξ = J Σ_q Jᵀ + K Σ_θ Kᵀ + Σ_unmodeled`。把它当真值，等于把一条**未标定的量具**接进证书。**运动学不是背景知识，它是第一条测量链；R72 恰恰漏审了它。**

**灵感 2（奇异 → 风险不能只在任务空间写，条件数会放大它）**
直觉：在奇异位形附近，末端想在某个方向动一点点，关节可能要转很多；反过来，关节的一点点噪声，会在任务空间被放大成很大的位姿误差。数学上，最小范数关节速度 `‖q̇‖ ≥ |u_mᵀ ξ_d| / σ_min`。当 σ_min → 0，要么关节速度/力矩爆掉（饱和、失稳），要么任务跟踪误差爆掉（撞上）。**两条路都是安全违规，且都无法用「抬高 λ」在任务空间里补偿**——因为问题不是「信心不足」，而是「这个方向上根本没有可用的运动学通道」。所以奇异必须是**非补偿性否决**，并且风险函数里必须显式出现 `1/σ_min` 或 `κ(J)`。

**灵感 3（标定规范 → 先商掉不可辨识的方向，再谈不确定度）**
直觉：同一组末端位姿，可以由无穷多组关节零点/基座/工具帧参数解释——把基座坐标整体转一下、把关节零点整体挪一下，末端轨迹不变。这些方向就是运动学标定的**规范轨道（gauge orbit）**。观测只约束**规范不变量**（末端相对位姿），不约束参数本身。若直接对 Fisher 信息求逆报「参数协方差」，在规范方向上得到的是**无意义的巨方差或伪逆的零方差**，二者都会污染下游 λ。正确做法是：把不确定度定义在**商流形 Θ/G** 上，只报告**可辨识的、帧不变的**部分。**这正好把 R71 的「规范/单位审计」推进到「SE(3) 参考系与标定规范审计」。**

**灵感 4（双臂闭链 → 不一致不是噪声，不一致是内力与形变）**
直觉：双手端一个盘子时，左手的「盘子位姿」和右手的「盘子位姿」必须一致；若不一致，盘子要么被挤压（内力），要么相对滑动。R72 会把这个残差 `r_cc = log((T_L T_L^o)⁻¹(T_R T_R^o))` 当成又一个观测噪声。但闭链残差是**关于标定误差、柔性、对象形变、跟踪误差的混合证据**：它可能被用来在线估计相对标定，也可能被内力「吃掉」。**把不一致当噪声 ⇒ 看不见内力 ⇒ 两臂越抓越紧，直到捏碎。** 必须把内力显式分解出来，并给出四分量不确定度（相对标定 / 柔性 / 对象形变 / 力传感）。

**灵感 5（相关证据 → 两只手不是一个独立双传感器）**
直觉：两臂各自估计物体位姿，看起来是「两份独立证据」，融合后置信度翻倍。但它们共享世界系、共享相机、共享同一次标定误差——存在**公共模（common-mode）误差 b**。此时 `y_i = x + b + n_i`，跨臂协方差 `Cov(y_L, y_R) = Σ_b ≠ 0`。若按独立融合，后验方差会被压低到**小于真实值**；臂越多、公共模占比 ρ 越高，过度自信越严重。**有效样本量 `n_eff = n / (1+(n-1)ρ)`**。而且两臂「吵架」（残差马氏距离大）本身是**模型错误/对象形变的证据**，不是要平均掉的噪声。**R72 的「单源不定案」必须升级为「相关源不独立定案」。**

**灵感 6（联合证书 → 两张单臂证书推不出双臂安全）**
直觉：左臂 J_EMB 有效、右臂 J_EMB 有效，直觉上「双保险」。但双臂风险里多出一个**耦合项**：内力、闭链奇异、相关性低估。两个各自「安全」的臂，可以一起把物体捏碎（各自力都在限内，合力挤压超限）。因此必须引入**联合证书 J_DUAL**，并用**并集界**组合：`P(Fail_dual) ≤ P(Fail_L)+P(Fail_R)+P(Fail_couple)`；当耦合项无法界定时，`P(Fail_couple)` 不可控，**必须降级**而不是「两个都过了就放行」。**安全不是可加的，耦合项必须单独审计。**

## 1. 形式化定义（增量：定义 366–379）

**定义 366（KIN-MET 运动学计量链）** 运动学模型不是真值，而是六元组
`K_t = (θ_kin, Σ_θ, q_t, Σ_q, D_kin, τ_kin)`：
- θ_kin：连杆长度、关节零点、减速比、工具/基座外参；
- Σ_θ：标定参数协方差（**在规范商上定义，见定义 367**）；
- q_t, Σ_q：编码器读数及其噪声（量化、温漂）；
- D_kin：**运动学有效域**（已标定构型邻域、非奇异、关节/工作空间裕度足够、未超温度/负载范围）；
- τ_kin：从标定数据、编码器、温度到参数的追溯链（复用 TCHAIN）。
末端右平凡化误差一阶传播：
`ξ̂ = J(q) δq + K(q) δθ + ε_unmod`，
`Σ_ξ = J Σ_q Jᵀ + K Σ_θ Kᵀ + J Σ_{qθ} Kᵀ + K Σ_{θq} Jᵀ + Σ_unmod`，
其中 `K = ∂/∂θ log(T(q;θ)⁻¹ T(q;θ+δθ))`。**Σ_unmod 覆盖柔性、回差、热膨胀；不可省略。**

**定义 367（SE(3) 标定规范商与帧不变性）** 设参数到观测的映射 `h: Θ → (SE(3))^m`。规范群 `G`（基座/工具帧重定义、关节零点平移的组合）作用在 Θ 上满足 `h(g·θ) = h(θ), ∀g∈G`。称 θ 与 g·θ **规范等价**；物理量只能依赖商空间 `Θ/G` 上的**规范不变量**（末端相对位姿、距离、条件数、范数）。Fisher 信息 `F = Dhᵀ Σ_obs^{-1} Dh` 在规范轨道方向 `T_θ G` 上**奇异**。定义**可辨识协方差**
`Σ_θ^obs = Pᵀ · pinv(P F Pᵀ) · P`，`P = I − Q Qᵀ`，Q 为 `T_θ G` 的正交基。
**规则：证书里禁止出现未商掉规范的参数协方差；Σ_θ 必须推送到任务空间后才可进 λ。** 另定义**帧不变性审计**：对任意 `g∈SE(3)`，风险/控制决策满足 `R(gT_1,…,gT_n) = R(T_1,…,T_n)`。

**定义 368（奇异裕度与可操作度计量）** 对 `J = U Σ Vᵀ`，`σ_1 ≥ … ≥ σ_m`：
- 条件数 `κ(J) = σ_1 / σ_m`；倒数条件数 `κ⁻¹ = σ_m/σ_1`；
- 可操作度 `w = √det(JJᵀ) = ∏ σ_i`；
- 奇异裕度 `m_sing = σ_m − σ_req(ε)`；
- 关节裕度 `m_lim = min_i min(q_i − q_i^lo, q_i^hi − q_i)`；工作空间裕度 `m_ws`。
**运动学风险** `R_kin = c_κ(κ−1)_+ + c_w / max(w,ε) + c_lim / max(m_lim,ε) + c_ws / max(m_ws,ε)`。
**非补偿否决**：若 `σ_m < σ_veto` 或 `κ > κ_veto` 或 `m_lim < m_lim^veto`，**无论 λ 多低、无论收益多大，都禁止该指令**（VETO）。

**定义 369（双臂闭链约束残差）** 设对象位姿 `T_o`，臂 i 末端 `T_i`，抓取偏置 `T_i^o`（臂 i 末端到对象）。理想刚性抓取下
`T_L T_L^o = T_R T_R^o = T_o`。
闭链残差 `r_cc = log_SE(3)( (T_L T_L^o)⁻¹ (T_R T_R^o) ) ∈ se(3)`。
一阶分解：`r_cc ≈ A_L δθ_L − A_R δθ_R + C δc + ν_track`，其中 δc 为柔性/对象形变，ν_track 为跟踪误差。**r_cc ≠ 0 不是「噪声」，是关于 {相对标定, 柔性, 形变, 跟踪} 的混合证据。**

**定义 370（内力扳手与四分量内力不确定度）** 设抓取映射 `G = [G_L, G_R]`，接触扳手堆叠 `f = [f_L; f_R]`。对象所受合力 `w_obj = G f`。**内力扳手**为不产生净对象运动的分量
`f_int = (I − G⁺G) f ∈ N(G)`。
内力幅值 `‖f_int‖` 直接对应挤压/扭转应力。内力不确定度四分量：
`u_int² = u_rel² + u_comp² + u_obj² + u_sens²`，
分别对应相对标定、柔性/回差、对象形变模型、力/力矩传感。**非补偿否决**：若 `‖f_int‖ + z_{1−α} u_int > f_safe(object)`，禁止继续夹持（改为松手/换抓/单臂搬运）。每项独立追溯链 τ_int,i。

**定义 371（跨臂联合后验与相关证据）** 共享对象状态 x_o 的观测 `y_i = x_o + b + n_i`，i∈{L,R}，b 为公共模（共享世界系/相机/标定误差），`b ~ N(0,Σ_b)`，`n_i ~ N(0,Σ_i)` 独立。联合后验必须使用**含交叉协方差**的似然：
`Cov(y_i,y_j) = Σ_b (i≠j)`，`Cov(y_i,y_i) = Σ_b + Σ_i`。
**禁止**使用 `p(y_L|x)p(y_R|x)` 的独立乘积形式，除非已证明 `Σ_b = 0` 或给出其上界。

**定义 372（有效样本量与过度置信界）** 设公共模占比 `ρ = tr(Σ_b) / (tr(Σ_b) + tr(Σ_indep))`。n 个相关源的有效样本量
`n_eff = n / (1 + (n−1)ρ)`。
标量情形下，独立融合与真实后验的方差差
`ΔVar = Var_true − Var_naive ≥ 0`，且随 n、ρ 单调增。
**证书必须携带 (ρ, n_eff) 或 ρ 的保守上界；ρ 未知时按 ρ=ρ_max 保守融合。**

**定义 373（跨臂分歧检验）** 设两臂对共享对象的估计 `(x̂_L, Σ_L)`、`(x̂_R, Σ_R)` 与交叉协方差 `Σ_LR`。分歧统计量
`d² = (x̂_L − x̂_R)ᵀ (Σ_L + Σ_R − 2Σ_LR)^{-1} (x̂_L − x̂_R)`。
若 `d² > χ²_{6,1−α}`，拒绝「两臂共享同一刚性对象」假设，触发**模型错误**流程（重标定 / 检查形变 / 降级单臂），**不得简单平均**。**一致时也须用相关协方差，不能因一致就宣称独立。**

**定义 374（协作风险缩放 COOP-RISK）** 风险缩放因子
`λ = max( risk_scale(U_ale, U_epi, H[b_t(z)], u_tac, u_kin, u_cc, u_int),
          λ_floor(U_ale + U_epi + H[b_t(z)] + u_tac + u_kin + u_cc + u_int) )`，
其中 `u_kin = √(tr(P_ξ Σ_ξ P_ξᵀ))` 为任务空间运动学不确定度（投影到任务相关子空间），`u_cc = ‖r_cc‖` 的标准化版本。**运动学与耦合不确定度和物理/意图/接触不确定度同权进入分母**。此外**非补偿否决集** `V = {SING, LIMIT, INT_FORCE, XCOV_INCONSISTENT, GAUGE_VIOLATION}` 与 λ 并行：任一成立即拒绝，不参与加权。

**定义 375（运动学/协作反作用 EREFLEX†，新增 L4/L5）** 在 R72 三层（L1 ψ / L2 z / L3 c）之上：
- **L4 运动学反作用**：控制动作 `a_t` 改变构型 ⇒ 改变 `κ(J_t)`、`σ_m`、关节裕度。成本
  `c_reflex^kin = c_κ · [κ(J_{t+1}) − κ(J_t)]_+ + c_lim · [m_lim^t − m_lim^{t+1}]_+`。**动作可能把系统「开进」奇异点，这是可预算的。**
- **L5 协作反作用**：动作/角色分配改变内力与一致性。成本
  `c_reflex^coop = ‖f_int^{t+1}‖ − ‖f_int^t‖_+ + λ_role · 1[角色切换] + λ_cc · [u_int^{t+1} − u_int^t]_+`。
**累计预算**：`Σ_t (c^ψ + c^z + c^c + c^kin + c^coop) ≤ B_reflex_total`；任一层越界 ⇒ 触发 E-IVG 降级。**运动与协作反作用使得「走近奇异」和「加大夹持」都成为有预算的干预，而不是免费动作。**

**定义 376（双臂联合证书 J_DUAL）**
`J_DUAL = (J_EMB_L, J_EMB_R, kin_valid, gauge_invariant, cc_consistent, int_force_ok, xcov_consistent, composition_proof, dual_ver)`。
`Valid ⇔ Valid(J_EMB_L) ∧ Valid(J_EMB_R) ∧ KIN 有效 ∧ 帧/规范不变审计通过 ∧ 闭链一致 ∧ 内力在界 ∧ (ρ,n_eff) 未低估 ∧ 组合证明可复算。` **两张单臂证书都有效，不蕴含 J_DUAL 有效。**

**定义 377（双臂退化包含链）** 逐指令严格退化：
- KIN 失效（奇异/标定出域）⇒ 冻结任务空间承诺，退化为 R72 的关节空间保守阻抗 + R68 硬包络；
- BIM 失效（内力不可认证）⇒ **单臂模式**：安全松开一臂（力控泄压）或刚性共动并限力，退化为 R72 单臂；
- XCOV 失效（相关未知）⇒ 按 ρ=ρ_max 保守融合 + λ 抬高，退化为保守 R72；
- GAUGE 失效（决策依赖绝对帧/规范代表）⇒ 冻结该决策，回退到帧不变量；
- 全失效 ⇒ R68。
**安全侧只增不减：任何退化都保留 R68 硬安全包络与 λ_floor。**

**定义 378（威胁模型 AIC-DUAL）** 在 ℰ_EMB 上扩展：
`ℰ_kin = {标定投毒（悄悄改连杆长度/零点）、编码器欺骗、奇异陷阱（诱导进入奇异位形）、帧混淆（换参考系使风险看似变小）}`；
`ℰ_coop = {单臂被攻陷后伪造「一致」、诱导内力（对抗性推/拉）、角色劫持（伪主臂）、公共模注入（让两臂同时错向同一边）}`。
**关键新增威胁是「公共模攻击」：只要让两臂共享同一个错误，相关融合会把错误当成高置信共识。**

**定义 379（运动学运行时监控 K-RTM）** 最高优先级、静态内存、零依赖：每控制周期抽检 `σ_m`、`κ`、`m_lim`、`‖r_cc‖`、`‖f_int‖`、标定残差漂移与帧不变性抽检；超阈即熔断/降级并记录。**K-RTM 是运动学层的信任锚点，自身不被监控。**

# IP-295 KIN-MET：运动学计量链（控制域，每周期）
def kinematic_metrology(q, theta_kin, Sigma_q, Sigma_theta, model, tchain):
    T = fk(q, theta_kin)
    J = jacobian(q, theta_kin)                 # 6 x n
    K = dfk_dtheta(q, theta_kin)               # 6 x p（右平凡化敏感度）
    # 一阶传播；若 q 与 θ 相关，加入交叉项
    Sigma_xi = J @ Sigma_q @ J.T + K @ Sigma_theta @ K.T + model.Sigma_unmod
    if model.cross_cov is not None:
        Sigma_xi += J @ model.cross_cov @ K.T + K @ model.cross_cov.T @ J.T
    U, S, Vt = svd(J)
    sigma_m, sigma_1 = S[-1], S[0]
    kappa = sigma_1 / max(sigma_m, EPS)
    w = float(np.prod(S))
    ok = in_calibrated_region(q, theta_kin, model.D_kin)
    return KinEvidence(T=T, J=J, Sigma_xi=Sigma_xi, sigma_m=sigma_m,
                       kappa=kappa, w=w, valid=ok, tau=tchain)

# IP-296 SE3-GAUGE：标定规范商 + 帧不变性审计（部署期/慢环）
def gauge_quotient(Fisher, gauge_basis):
    # gauge_basis: 列向量张成不可辨识方向 T_θG
    Q, _ = np.linalg.qr(gauge_basis)
    P = np.eye(Fisher.shape[0]) - Q @ Q.T
    F_obs = P @ Fisher @ P
    Sigma_obs = np.linalg.pinv(F_obs, rcond=1e-9)   # 仅在可辨识子空间有意义
    return Sigma_obs, P

def frame_invariance_audit(risk_fn, poses, n_trials=256, tol=1e-6):
    base = risk_fn(poses)
    for _ in range(n_trials):
        g = random_se3()
        if abs(risk_fn([g @ T for T in poses]) - base) > tol:
            return False, "FRAME_DEPENDENT"
    return True, "OK"

# IP-297 SING-VETO：奇异/条件数非补偿否决（控制域，硬实时）
def singularity_veto(kin, q, q_lo, q_hi, p):
    m_lim = min(np.min(q - q_lo), np.min(q_hi - q))
    if kin.sigma_m < p.sigma_veto:      return Veto("SINGULAR")
    if kin.kappa   > p.kappa_veto:     return Veto("ILL_CONDITIONED")
    if m_lim       < p.limit_veto:     return Veto("JOINT_LIMIT")
    if not kin.valid:                  return Veto("KIN_OUT_OF_DOMAIN")
    r_kin = p.c_kappa * (kin.kappa - 1.0) + p.c_w / max(kin.w, EPS) \
            + p.c_lim / max(m_lim, EPS)
    return Pass(r_kin)

# IP-298 BIM-MET：双臂闭链一致性与内力计量（计量域，50Hz）
def bimanual_internal_metrology(TL, TR, TL_o, TR_o, wL, wR, G, model):
    r_cc = log_se3( inv(TL @ TL_o) @ (TR @ TR_o) )       # 6 维残差
    f    = np.concatenate([wL, wR])
    f_int = f - G_pinv(G) @ (G @ f)                      # N(G) 分量（内力）
    u_rel  = model.rel_calib_uncertainty()               # 相对标定
    u_comp = model.compliance_uncertainty(r_cc)          # 柔性/回差
    u_obj  = model.object_deform_uncertainty(f_int)      # 对象形变
    u_sens = model.force_sensor_uncertainty()            # 力传感
    u_int  = sqrt(u_rel**2 + u_comp**2 + u_obj**2 + u_sens**2)
    ok = np.linalg.norm(f_int) + Z_ALPHA * u_int <= model.f_safe
    return BimEvidence(r_cc=r_cc, f_int=f_int, u_int=u_int, ok=ok,
                       tau=(model.tau_rel, model.tau_comp, model.tau_obj, model.tau_sens))

# IP-299 XCOV-FUSE：跨臂相关融合 + 分歧检验（计量域）
def xcov_fuse(priors, obs, Sigma_common, rho_max=0.5):
    # obs[i] = (mean_i, Sigma_i)：共享公共模 Sigma_common
    n = len(obs)
    diag  = [S + Sigma_common for (_, S) in obs]
    blocks = [[diag[i] if i == j else Sigma_common for j in range(n)]
              for i in range(n)]
    Sigma_joint = np.block(blocks)
    # 用相关协方差做 GLS/贝叶斯融合（省略具体先验求逆细节）
    x_hat, Sigma_post = gls_fuse(priors, [m for m, _ in obs], Sigma_joint)
    rho = 0.0 if not Sigma_common.any() else trace(Sigma_common) / \
          (trace(Sigma_common) + np.mean([trace(S) for _, S in obs]))
    rho = max(rho, rho_max if Sigma_common is None else rho)
    n_eff = n / (1.0 + (n - 1) * rho)
    return x_hat, Sigma_post, rho, n_eff

def disagreement_test(xL, xR, SL, SR, SLR, alpha=0.01):
    S_diff = SL + SR - 2 * SLR
    d2 = mahalanobis(xL - xR, S_diff)
    return d2 > chi2.ppf(1 - alpha, df=6)     # True ⇒ 模型错误/形变，不是噪声

# IP-300 COOP-RISK：协作风险缩放（控制域，硬实时）
def coop_risk_scale(U_ale, U_epi, H_z, u_tac, u_kin, u_cc, u_int, p):
    denom = U_ale + U_epi + H_z + u_tac + u_kin + u_cc + u_int
    lam = p.lam_base * (1.0 + denom / p.lam_scale)
    return max(lam, p.lam_floor * (1.0 + denom))

# IP-301 EREFLEX†：L4 运动学 / L5 协作反作用（计量域）
def ereflex_step2(psi, z, c, kin, bim, g, budget):
    psi2, cost_psi, _ = reflex_step(psi, g, robot_prosody(g), None, budget)
    z2,   cost_z      = intent_transition(z, g, psi)
    c2,   cost_c      = contact_transition(c, g)
    kin2, cost_kin    = kinematic_transition(kin, g)      # 预演构型条件数
    bim2, cost_coop   = coordination_transition(bim, g)   # 预演内力/角色
    total = cost_psi + cost_z + cost_c + cost_kin + cost_coop
    if (not kin2.valid or bim2.veto or budget.spent + total > budget.B):
        return None                                      # 拒绝该动作/指令
    return psi2, z2, c2, kin2, bim2, total

# IP-302 DUAL-PIPELINE + J_DUAL：双臂三域执行与联合证书
def KIN_COOP_GAUGE_RAS_round(M):
    # ===== 控制域（1kHz，硬实时，只读快照）=====
    snap = M.snapshot.read_latest()
    kinL = M.kinL.step(snap.qL); kinR = M.kinR.step(snap.qR)
    vL = singularity_veto(kinL, snap.qL, *M.limL, M.p)
    vR = singularity_veto(kinR, snap.qR, *M.limR, M.p)
    if not (vL.ok and vR.ok):
        return M.degrade_to_conservative_R68(reason=(vL.reason or vR.reason))
    bim  = snap.bim                                # 计量域最新快照（可能滞后）
    lam  = coop_risk_scale(snap.U_ale, snap.U_epi, snap.H_z, snap.u_tac,
                           snap.u_kin, snap.u_cc, snap.u_int, M.p)
    if bim is not None and not bim.ok:
        return M.degrade_to_single_arm(load_transfer=True, reason="INT_FORCE")
    # 相对雅可比 + 零空间自运动（改善条件数）
    J_rel = relative_jacobian(kinL.J, kinR.J, kinL.T, kinR.T)
    tauL, tauR = M.dual_ctrl(kinL, kinR, J_rel, lam, snap.role)
    M.ctrlL.publish(tauL); M.ctrlR.publish(tauR)
    M.cert_ctrl.write(lam=lam, sigma_m=min(kinL.sigma_m, kinR.sigma_m),
                      f_int=getattr(bim, "f_int", None), rtm=M.krtm.status())

    # ===== 计量域（50Hz，软实时，可抢占）=====
    if M.clock.due_metric():
        kinL_f = M.kinL.full(snap.qL); kinR_f = M.kinR.full(snap.qR)
        bim_f  = M.bim.update(snap.TL, snap.TR, snap.wL, snap.wR, M.G)
        xo, Sxo, rho, n_eff = xcov_fuse(M.prior_o, snap.obs_obj, M.Sigma_common)
        if disagreement_test(snap.xL, snap.xR, snap.SL, snap.SR, snap.SLR):
            M.mode = "MODEL_ERROR"; M.registry.freeze("XCOV_DISAGREE")
        gauge_ok, why = frame_invariance_audit(M.risk_fn, snap.poses)
        if not gauge_ok: M.registry.freeze(why)
        gate = M.e_ivg.check(M.registry, xo, Sxo, bim_f, kinL_f, kinR_f, rho, n_eff)
        if not gate.valid: M.mode = gate.fallback
        M.snapshot.write(xo, Sxo, bim_f, kinL_f, kinR_f, rho, n_eff, gate)

    # ===== 感知域（Best-effort，异步）=====
    psi_hat, _ = M.aura.update(M.audio)
    tacL = M.tacL.update(M.tacL_frame); tacR = M.tacR.update(M.tacR_frame)
    M.obs_obj_buf.append(M.vision_pose()); M.obs_obj_buf.append(M.tac_pose())
    # ERVOI 事件触发（含 L4/L5 成本）
    if M.mode == "FULL" and (entropy(xo) > M.TAU_EPI or M.z.entropy() > M.TAU_HZ):
        g = M.ervoi2.choose(xo, psi_hat, M.z, M.tac, M.kin, M.bim, M.budget)
        if g: M.last_g, M.last_y = g, M.cia.execute(g)

    return J_DUAL(M)   # 联合证书：由 J_EMB_L/R + KIN + BIM + XCOV + GAUGE 组合

## 3. 推导

**引理 33（运动学不确定度放大引理）** 在定义 366 下，末端右平凡化误差协方差的一阶近似为 `Σ_ξ = J Σ_q Jᵀ + K Σ_θ Kᵀ + 交叉项 + Σ_unmod`。对 `J = U Σ Vᵀ`，实现期望任务扭速 `ξ_d` 的最小范数关节速度 `q̇ = V Σ⁻¹ Uᵀ ξ_d` 满足
`‖q̇‖ ≥ |u_mᵀ ξ_d| / σ_m`。
因此：**要么关节速度/加速度无界（饱和、失稳），要么任务跟踪误差 `≥ σ_m ‖q̇‖` 有界但不可消除。** 系：**任何只写在任务空间、不含条件数或 σ_m 的风险界，在奇异邻域都不可兑现。**

**引理 34（奇异否决必要性）** 设控制器要求 `‖q̇‖ ≤ v_max` 且任务误差 `‖δx‖ ≤ e_max`，并要求沿 u_m 方向保持非零速度 `v_task > 0`。可实现的该方向任务速度为 `σ_m ‖q̇‖ ≤ σ_m v_max`。当 `σ_m < v_task / v_max` 时，两个约束必有一个被违反；而二者分别对应饱和失控与跟踪撞上，都是安全违规。故**不存在有限 λ 能使任务空间风险有界；必须非补偿否决（或 λ→∞）。** 系：`R_kin` 必须含 `1/σ_m` 项；λ 不能替代 veto。

**引理 35（闭链残差的可辨识性）** 由定义 369，`r_cc ≈ A_L δθ_L − A_R δθ_R + C δc + ν`。若回归矩阵 `[A_L, −A_R, C]` 列满秩，且构型/力激励持续（persistence of excitation），则相对标定误差与柔性/形变可分离，`u_int` 四分量可分别估计；若 `col(C) ∩ col([A_L,−A_R]) ≠ {0}` 或激励不足，则只能得到**联合上界**，此时必须使用保守 `u_int`，**不得把残差全部归因于噪声**。系：**「一致」不证明标定好，「不一致」也不等于故障；必须先做可辨识性分析再分配不确定性。**

**引理 36（相关融合过度置信引理）** 设标量情形：先验方差 σ_0²，公共模 `b~N(0,σ_b²)`，独立噪声 `n_i~N(0,σ_n²)`，n 个观测。真实后验方差
`Var_true = (σ_0⁻² + n/(σ_b²+σ_n²))⁻¹`；
独立融合（错误地假设观测方差为 σ_n²）给出
`Var_naive = (σ_0⁻² + n/σ_n²)⁻¹`。
因 `σ_b²+σ_n² ≥ σ_n²`，有 `Var_naive ≤ Var_true`，且差随 n、`ρ=σ_b²/(σ_b²+σ_n²)` 单调增。有效样本量 `n_eff = n/(1+(n−1)ρ)`。系：**双臂融合的置信度不能用「2 份证据」计价；公共模占比 ρ 必须进证书，否则 J_DUAL 会系统性过度自信。**

**引理 37（标定规范自由度引理）** 设规范群 G 作用满足 `h(g·θ)=h(θ)`。则 `Dh · v = 0, ∀v ∈ T_θG`，故 `F = DhᵀΣ⁻¹Dh` 在 `T_θG` 上零特征值，`F` 奇异；直接求逆不存在，伪逆在规范方向给零方差（伪确定），正则化求逆给依赖正则项的任意方差。**参数协方差本身不可辨识；只有推送后的、商掉规范的、帧不变的泛函（末端相对位姿协方差、条件数分布、可操作度）可进证书。** 系：**报告「θ_kin 的 95% 置信区间」在规范方向上没有物理意义；R71 的 gauge 审计在此获得 SE(3) 版本。**

**引理 38（L4/L5 反作用预算的单调性与有限停止）** 设总成本 `C(n)=Σ_{i≤n}(c^ψ+c^z+c^c+c^kin+c^coop)`。L4 成本由条件数的正部增量界定，L5 成本由内力幅值增量与角色切换界定，均有正下界（非零动作时）且随接近安全边界增大；边际信息增益随 n 非增。故存在有限 `n*` 使第 n*+1 步净收益 ≤0，ERVOI† 在 n* 停止。**「是否值得再挪一下以改善条件数」「是否值得再夹紧一点」都是可证明的有限停止问题。**

**定理 27（双臂联合安全组合定理）** 在 A111–A114（KIN 有效、BIM 可认证、XCOV 未低估、L4/L5 Lipschitz）下，双臂失效概率满足并集界
`P(Fail_dual) ≤ P(Fail_L) + P(Fail_R) + P(Fail_couple)`，
且当 J_EMB_L、J_EMB_R、J_DUAL 均有效时，右端各项分别 ≤ ε_L、ε_R、ε_couple，故 `P(Fail_dual) ≤ ε_dual`。反之，若 BIM 或 XCOV 无效，则 `P(Fail_couple)` **无界**，即使两张单臂证书都有效也不能推出双臂安全。**系：安全不可加，耦合项必须单独认证；这是 J_DUAL 存在的根本理由。**

**定理 28（SE(3) 规范不变性定理）** 若风险/控制泛函 R 只依赖相对位姿 `T_i⁻¹T_j`、体坐标扭速、以及范数/奇异值/距离等不变量，则对任意 `g∈SE(3)`，`R(gT_1,…,gT_n)=R(T_1,…,T_n)`。证明：左乘 g 在相对位姿中消去。逆命题：若 R 显式依赖绝对坐标，则存在 g 改变 R 而物理不变 ⇒ 该决策可被「换参考系」攻击。系：**帧不变性是可测试的安全属性（定义 367 的审计），也是 AIC-DUAL 中「帧混淆」威胁的正面防御。**

**定理 29（严格包含与风险单调定理）** 在定义 377 的退化条件下，KIN-COOP 逐指令等价于 R72/R71/R68；且对任意有效执行，其风险界 ≤ R72 的风险界（定理 23）。非补偿否决只删除动作、不新增动作，故安全单调不减，效率仅在「运动学可辨识、闭链可认证、相关性未低估」时获益。

**定理 30（J_DUAL 有效性 ⇒ 双臂物理安全）** 若一次执行通过 J_DUAL，则：(i) J_EMB_L/R 有效 ⇒ 各臂感知/接触/意图风险有界；(ii) KIN 有效且 K-RTM 无超阈 ⇒ 运动学不确定度与条件数在有效域，奇异被否决；(iii) BIM 有效 ⇒ 内力 `‖f_int‖+z u_int ≤ f_safe`，闭链残差已被解释而非当噪声；(iv) XCOV 有效 ⇒ `(ρ,n_eff)` 未低估，后验不过度自信；(v) GAUGE 有效 ⇒ 决策帧/规范不变。综上，**双臂物理执行风险 ≤ ε_dual（相对于联合测量模型）**。证明重量落在「Σ_θ 的规范商定义真实成立」「公共模上界未被投毒」「内力四分量在分布外仍可估」三点上。

## 6. 本轮最大风险

**一句话**：KIN-COOP-GAUGE-RAS 把安全的地基又往下挖了一层——从「相信传感器与调度」变成「相信**身体模型（标定可辨识、奇异可检出）**与**两臂相关性（公共模、闭链内力）**都被正确计量」——**如果两台臂共享一个未建模的标定偏差、或共享同一相机/世界系导致的公共模误差，相关融合就会把两份相关证据当独立证据而系统性过度自信；如果闭链残差被当成噪声而不是内力/形变，系统就会用两张各自盖章的证书，微笑着一同把物体捏碎、把关节拧坏，事后审计发现「两张单臂证书都有效、所有指标都在域内」，这就是运动学与协作层面的「自信地错自己的耦合」。**

次级风险与缓解：
1. **奇异否决过保守导致任务不可达** → 用**零空间自运动**主动改善条件数（L4 成本显式建模），并在任务规划层预留奇异回避通道；否决只删指令，不篡改任务语义。
2. **Σ_θ 规范商实现错误** → 把**帧不变性审计（定理 28）** 作为部署期门禁；任何依赖绝对帧/参数代表的决策一律拒绝；用合成数据做单元测试（已知规范轨道）。
3. **公共模占比 ρ 低估** → 保守取 `ρ_max` 并做**跨通道交叉验证**（视觉/力/本体/外部动捕），单通道不独立定案；把公共模攻击纳入 AIC-DUAL。
4. **内力四分量不可辨识** → 按引理 35 只给**联合上界**，不强行分解；内力不可认证即触发单臂/松手降级，绝不「两个都在限内就继续」。
5. **KIN-MET 在控制域超时** → Jacobian/SVD 预符号化 + 固定构型缓存；KIN 计量分解到硬实时（只算 σ_m/κ）与软实时（完整 Σ_ξ），控制域只读最小标量。
6. **两臂时钟/状态不同步导致 r_cc 假残差** → REG 增加**跨臂同步话题**（PTP/硬件触发），r_cc 计算带时间对齐不确定度并计入 u_cc。
7. **复杂度爆炸** → 模块化上限：`|Z|≤8`、`|C|≤5`、`|V|≤6`（否决项）、`|N_REG|≤24`；每个否决一条可复算证明，复杂度本身纳入审计。

## 2. 形式化定义（要点版）

**定义 366（KIN-MET）** 身体模型是六元组 `(θ_kin, Σ_θ, q, Σ_q, D_kin, τ_kin)`；末端位姿是**估计量**。一阶传播 `Σ_ξ=JΣ_qJᵀ+KΣ_θKᵀ+交叉项+Σ_unmod`。**Σ_unmod 覆盖柔性/回差/热膨胀，不可省略。**

**定义 367（SE(3) 标定规范商与帧不变性）** 规范群 G 满足 `h(g·θ)=h(θ)`；Fisher `F=DhᵀΣ⁻¹Dh` 在 `T_θG` 上奇异。可辨识协方差 `Σ_θ^obs=Pᵀ pinv(PFPᵀ)P`，`P=I−QQᵀ`。**证书禁止裸报参数协方差；须推送为帧不变泛函。** 帧不变性：`R(gT)=R(T),∀g∈SE(3)`。

**定义 368（奇异裕度与可操作度）** `κ=σ_1/σ_m`、`w=∏σ_i`、`m_sing=σ_m−σ_req`、`m_lim`、`m_ws`。`R_kin=c_κ(κ−1)_++c_w/w+c_lim/m_lim+c_ws/m_ws`。**否决：`σ_m<σ_veto ∨ κ>κ_veto ∨ m_lim<m_lim^veto`。**

**定义 369（闭链残差）** `r_cc=log((T_L T_L^o)⁻¹(T_R T_R^o))`；一阶 `r_cc≈A_Lδθ_L−A_Rδθ_R+Cδc+ν_track`。**残差是混合证据，不是噪声。**

**定义 370（内力与四分量）** `f_int=(I−G⁺G)f`；`u_int²=u_rel²+u_comp²+u_obj²+u_sens²`。**否决：`‖f_int‖+z_{1−α}u_int>f_safe`。**

# IP-295 KIN-MET：运动学计量链（控制域，1kHz）
def kinematic_metrology(q, theta_kin, Sigma_q, Sigma_theta, model, tchain):
    T = fk(q, theta_kin)
    J = jacobian(q, theta_kin)                 # 6 x n
    K = dfk_dtheta(q, theta_kin)               # 6 x p
    Sigma_xi = J @ Sigma_q @ J.T + K @ Sigma_theta @ K.T + model.Sigma_unmod
    if model.cross_cov is not None:
        Sigma_xi += J @ model.cross_cov @ K.T + K @ model.cross_cov.T @ J.T
    U, S, Vt = svd(J)
    sigma_m, sigma_1 = S[-1], S[0]
    return KinEvidence(T=T, J=J, Sigma_xi=Sigma_xi,
                       sigma_m=sigma_m, kappa=sigma_1 / max(sigma_m, EPS),
                       w=float(np.prod(S)),
                       valid=in_calibrated_region(q, theta_kin, model.D_kin),
                       tau=tchain)

# IP-296 SE3-GAUGE：规范商 + 帧不变性审计
def gauge_quotient(Fisher, gauge_basis):
    Q, _ = np.linalg.qr(gauge_basis)
    P = np.eye(Fisher.shape[0]) - Q @ Q.T
    return np.linalg.pinv(P @ Fisher @ P, rcond=1e-9), P

def frame_invariance_audit(risk_fn, poses, n_trials=256, tol=1e-6):
    base = risk_fn(poses)
    for _ in range(n_trials):
        g = random_se3()
        if abs(risk_fn([g @ T for T in poses]) - base) > tol:
            return False, "FRAME_DEPENDENT"
    return True, "OK"

# IP-297 SING-VETO：奇异/条件数非补偿否决（控制域，硬实时）
def singularity_veto(kin, q, q_lo, q_hi, p):
    m_lim = min(np.min(q - q_lo), np.min(q_hi - q))
    if kin.sigma_m < p.sigma_veto:   return Veto("SINGULAR")
    if kin.kappa   > p.kappa_veto:  return Veto("ILL_CONDITIONED")
    if m_lim       < p.limit_veto:  return Veto("JOINT_LIMIT")
    if not kin.valid:               return Veto("KIN_OUT_OF_DOMAIN")
    r_kin = (p.c_kappa * (kin.kappa - 1.0) + p.c_w / max(kin.w, EPS)
             + p.c_lim / max(m_lim, EPS))
    return Pass(r_kin)

# IP-298 BIM-MET：双臂闭链一致性与内力计量（计量域，50Hz）
def bimanual_internal_metrology(TL, TR, TL_o, TR_o, wL, wR, G, model):
    r_cc = log_se3(inv(TL @ TL_o) @ (TR @ TR_o))
    f = np.concatenate([wL, wR])
    f_int = f - G_pinv(G) @ (G @ f)                     # N(G) 内力分量
    u_rel  = model.rel_calib_uncertainty()
    u_comp = model.compliance_uncertainty(r_cc)
    u_obj  = model.object_deform_uncertainty(f_int)
    u_sens = model.force_sensor_uncertainty()
    u_int  = sqrt(u_rel**2 + u_comp**2 + u_obj**2 + u_sens**2)
    ok = np.linalg.norm(f_int) + Z_ALPHA * u_int <= model.f_safe
    return BimEvidence(r_cc=r_cc, f_int=f_int, u_int=u_int, ok=ok,
                       tau=(model.tau_rel, model.tau_comp, model.tau_obj, model.tau_sens))

# IP-299 XCOV-FUSE：相关融合 + 分歧检验（计量域）
def xcov_fuse(priors, obs, Sigma_common, rho_max=0.5):
    n = len(obs)
    diag = [S + Sigma_common for (_, S) in obs]
    blocks = [[diag[i] if i == j else Sigma_common for j in range(n)] for i in range(n)]
    Sig_joint = np.block(blocks)
    x_hat, Sig_post = gls_fuse(priors, [m for m, _ in obs], Sig_joint)
    rho = (0.0 if not Sigma_common.any() else
           trace(Sigma_common) / (trace(Sigma_common) + np.mean([trace(S) for _, S in obs])))
    rho = max(rho, rho_max if Sigma_common is None else rho)
    return x_hat, Sig_post, rho, n / (1.0 + (n - 1) * rho)

def disagreement_test(xL, xR, SL, SR, SLR, alpha=0.01):
    d2 = mahalanobis(xL - xR, SL + SR - 2 * SLR)
    return d2 > chi2.ppf(1 - alpha, df=6)

# IP-300 COOP-RISK：协作风险缩放（控制域，硬实时）
def coop_risk_scale(U_ale, U_epi, H_z, u_tac, u_kin, u_cc, u_int, p):
    denom = U_ale + U_epi + H_z + u_tac + u_kin + u_cc + u_int
    return max(p.lam_base * (1.0 + denom / p.lam_scale),
               p.lam_floor * (1.0 + denom))

# IP-301 EREFLEX†：L4/L5 反作用预演（计量域）
def ereflex_step2(psi, z, c, kin, bim, g, budget):
    psi2, cost_psi, _ = reflex_step(psi, g, robot_prosody(g), None, budget)
    z2,   cost_z      = intent_transition(z, g, psi)
    c2,   cost_c      = contact_transition(c, g)
    kin2, cost_kin    = kinematic_transition(kin, g)      # 预演构型条件数/裕度
    bim2, cost_coop   = coordination_transition(bim, g)   # 预演内力/角色切换
    total = cost_psi + cost_z + cost_c + cost_kin + cost_coop
    if not kin2.valid or bim2.veto or budget.spent + total > budget.B:
        return None
    return psi2, z2, c2, kin2, bim2, total

# IP-302 DUAL-PIPELINE + J_DUAL：双臂三域执行与联合证书
def KIN_COOP_GAUGE_RAS_round(M):
    # ===== 控制域（1kHz，硬实时，只读快照）=====
    snap = M.snapshot.read_latest()
    kinL = M.kinL.step(snap.qL); kinR = M.kinR.step(snap.qR)
    vL = singularity_veto(kinL, snap.qL, *M.limL, M.p)
    vR = singularity_veto(kinR, snap.qR, *M.limR, M.p)
    if not (vL.ok and vR.ok):
        return M.degrade_to_conservative_R68(reason=(vL.reason or vR.reason))
    bim = snap.bim
    lam = coop_risk_scale(snap.U_ale, snap.U_epi, snap.H_z, snap.u_tac,
                          snap.u_kin, snap.u_cc, snap.u_int, M.p)
    if bim is not None and not bim.ok:
        return M.degrade_to_single_arm(load_transfer=True, reason="INT_FORCE")
    J_rel = relative_jacobian(kinL.J, kinR.J, kinL.T, kinR.T)
    tauL, tauR = M.dual_ctrl(kinL, kinR, J_rel, lam, snap.role)
    M.ctrlL.publish(tauL); M.ctrlR.publish(tauR)
    M.cert_ctrl.write(lam=lam, sigma_m=min(kinL.sigma_m, kinR.sigma_m),
                      f_int=getattr(bim, "f_int", None), rtm=M.krtm.status())

    # ===== 计量域（50Hz，软实时，可抢占）=====
    if M.clock.due_metric():
        kinL_f = M.kinL.full(snap.qL); kinR_f = M.kinR.full(snap.qR)
        bim_f = M.bim.update(snap.TL, snap.TR, snap.wL, snap.wR, M.G)

        if disagreement_test(snap.xL, snap.xR, snap.SL, snap.SR, snap.SLR):

        if not gauge_ok: M.registry.freeze(why)
        gate = M.e_ivg.check(M.registry, xo, Sxo, bim_f, kinL_f, kinR_f, rho, n_eff)
        if not gate.valid: M.mode = gate.fallback
        M.snapshot.write(xo, Sxo, bim_f, kinL_f, kinR_f, rho, n_eff, gate)

    # ===== 感知域（Best-effort，异步）=====
    psi_hat, _ = M.aura.update(M.audio)
    tacL = M.tacL.update(M.tacL_frame); tacR = M.tacR.update(M.tacR_frame)
    M.obs_obj_buf.append(M.vision_pose()); M.obs_obj_buf.append(M.tac_pose())
    if M.mode == "FULL" and (entropy(xo) > M.TAU_EPI or M.z.entropy() > M.TAU_HZ):
        g = M.ervoi2.choose(xo, psi_hat, M.z, M.tac, M.kin, M.bim, M.budget)
        if g: M.last_g, M.last_y = g, M.cia.execute(g)

    return J_DUAL(M)   # J_EMB_L/R + KIN + BIM + XCOV + GAUGE 组合

## 4. 推导

**引理 33（运动学不确定度放大）** `Σ_ξ=JΣ_qJᵀ+KΣ_θKᵀ+交叉项+Σ_unmod`；对 `J=UΣVᵀ`，最小范数 `q̇=VΣ⁻¹Uᵀξ_d` 满足 `‖q̇‖≥|u_mᵀξ_d|/σ_m`。故 σ_m→0 时，要么关节速度/力矩无界，要么任务误差 `≥σ_m‖q̇‖` 不可消除。**只写在任务空间、不含条件数的风险界在奇异邻域不可兑现。**

**引理 34（奇异否决必要性）** 要求 `‖q̇‖≤v_max`、`‖δx‖≤e_max`，且沿 u_m 保持非零任务速度 v_task。可实现速度 `≤σ_m v_max`。当 `σ_m<v_task/v_max` 时两约束必违其一（饱和失控或跟踪撞上），均为安全违规。**不存在有限 λ 能使任务空间风险有界；必须非补偿否决。**

**引理 35（闭链残差可辨识性）** `r_cc≈A_Lδθ_L−A_Rδθ_R+Cδc+ν`。若 `[A_L,−A_R,C]` 列满秩且激励持续，四分量可分离；若 `col(C)∩col([A_L,−A_R])≠{0}` 或激励不足，只能给**联合上界**。**「一致」不证明标定好，「不一致」也不等于故障。**

**引理 36（相关融合过度置信）** 标量情形 `Var_true=(σ_0⁻²+n/(σ_b²+σ_n²))⁻¹`，`Var_naive=(σ_0⁻²+n/σ_n²)⁻¹`，故 `Var_naive≤Var_true`，差随 n、`ρ=σ_b²/(σ_b²+σ_n²)` 单调增；`n_eff=n/(1+(n−1)ρ)`。**双臂融合不能用「2 份证据」计价。**

**引理 37（标定规范自由度）** `h(g·θ)=h(θ) ⇒ Dh·v=0, ∀v∈T_θG`，故 F 在规范方向零特征值、奇异；直接求逆不存在，伪逆给零方差（伪确定），正则化给任意方差。**只有推送后的帧不变泛函可进证书。** 系：R71 的 gauge 审计获得 SE(3) 版本。

**引理 38（L4/L5 反作用有限停止）** 总成本含 L4（条件数正部增量）与 L5（内力幅值增量、角色切换），均有正下界且随接近安全边界增大；边际信息增益随 n 非增 ⇒ 存在有限 n* 使下一步净收益 ≤0。**「再挪一下改善条件数」「再夹紧一点」都是可证明的有限停止问题。**

**定理 27（双臂联合安全组合）** 在 A111–A114 下，`P(Fail_dual)≤P(Fail_L)+P(Fail_R)+P(Fail_couple)`；J_EMB_L/R 与 J_DUAL 有效时右端 ≤ ε_L+ε_R+ε_couple = ε_dual。若 BIM 或 XCOV 无效，`P(Fail_couple)` 无界，**两张单臂证书都有效也不能推出双臂安全**。**安全不可加，耦合项必须单独认证。**

**定理 28（SE(3) 规范不变性）** 若 R 只依赖相对位姿 `T_i⁻¹T_j`、体坐标扭速与不变量（范数/奇异值/距离），则 `R(gT_1,…,gT_n)=R(T_1,…,T_n), ∀g∈SE(3)`；逆命题：依赖绝对坐标的 R 可被「换参考系」攻击。**帧不变性是可测试的安全属性。**

**定理 29（严格包含与风险单调）** 定义 377 的退化条件下逐指令等价 R72/R71/R68；有效执行的风险界 ≤ R72（定理 23）。否决只删动作，**安全单调不减**。

**定理 30（J_DUAL 有效性 ⇒ 双臂物理安全）** J_DUAL 有效 ⇒ (i) 各臂感知/接触/意图风险有界；(ii) 运动学不确定度与条件数在有效域、奇异被否决；(iii) 内力 `‖f_int‖+z u_int≤f_safe`，闭链残差被解释而非当噪声；(iv) `(ρ,n_eff)` 未低估、后验不过度自信；(v) 决策帧/规范不变。故**双臂物理风险 ≤ ε_dual**。证明重量落在「Σ_θ 规范商定义真实成立」「公共模上界未被投毒」「内力四分量在分布外仍可估」三点。

## 7. 本轮最大风险

**一句话**：KIN-COOP-GAUGE-RAS 把安全的地基又往下挖了一层——从「相信传感器与调度」变成「相信**身体模型（标定可辨识、奇异可检出）**与**两臂相关性（公共模、闭链内力）**都被正确计量」——**如果两台臂共享一个未建模的标定偏差、或共享同一相机/世界系导致的公共模误差，相关融合就会把两份相关证据当独立证据而系统性过度自信；如果闭链残差被当成噪声而不是内力/形变，系统就会用两张各自盖章的证书，微笑着一同把物体捏碎、把关节拧坏，事后审计发现「两张单臂证书都有效、所有指标都在域内」，这就是运动学与协作层面的「自信地错自己的耦合」。**

次级风险与缓解：
1. **奇异否决过保守导致任务不可达** → 零空间自运动主动改善条件数（L4 成本显式建模）；任务规划层预留奇异回避通道；否决只删指令，不篡改任务语义。
2. **Σ_θ 规范商实现错误** → 部署期帧不变性审计（定理 28）作为门禁；合成数据单元测试（已知规范轨道）；禁止依赖绝对帧/参数代表的决策。
3. **公共模占比 ρ 低估** → 保守取 ρ_max；跨通道交叉验证（视觉/力/本体/外部动捕），单通道不独立定案；公共模攻击纳入 AIC-DUAL。
4. **内力四分量不可辨识** → 按引理 35 只给联合上界，不强行分解；内力不可认证即单臂/松手降级。
5. **KIN-MET 控制域超时** → Jacobian/SVD 预符号化 + 固定构型缓存；硬实时只算 σ_m/κ，完整 Σ_ξ 放软实时。
6. **跨臂时钟不同步导致假残差** → REG 增加跨臂同步（PTP/硬件触发）；r_cc 带时间对齐不确定度并入 u_cc。
7. **复杂度爆炸** → 上限 `|Z|≤8, |C|≤5, |V|≤6, |N_REG|≤24`；每个否决一条可复算证明；复杂度纳入审计。
