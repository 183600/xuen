# 第 3 轮（新灵感循环第 3 轮；本轮灵感：「基线复现」×「多机协同」）

> **基线**：上一轮（灵感「深度相机」×「跨物体泛化」×「联邦学习」）MetricVoiceGauge-NCD-HUTDH-v20（定义 767–820；引理 151–156；实验 E751–E770；IP-420–424）。
> 本轮纪律：**复现是证书的准入、协同是复现的冗余、异构是冗余真伪的判据**。不推倒 v20：v20 的 PCA/CTS/CFC/HPC/CFCtrl、v19 的 DCM/OGCC/CCV/DRS/OGC、v18 的 SAS/影子晋升、v17 的 CLP/S2C/HCG/PSV/APS/AMC、v16 及更早全部保留。本轮只做一件事：**把"基线复现"改写为"可重放的证书推导"，把"多机协同"改写为"跨机复现的证据交换"，从而给 v6→v20 的包含链补上它一直缺失的"可复现地基"**。

## 0. 直觉与动机

**灵感 1（基线复现 → 证书不是"声明"，而是"可重放的推导"）**
直觉：v6→v20 一路宣称 `Exec_v20 ⊆ Exec_v19 ⊆ … ⊆ Exec_v6`，但这是**包含性的声明**，不是**可复现的事实**。若 v6 的地基从未被独立复现——同一份种子、同一份标定、同一份软件栈、同一份传感器快照——那么整条链悬在一个不可复现的楼层上；只要作者私域里少了一个超参、错了一版容器、换了一块 GPU，包含性就可能在实际执行里悄悄断裂。核心创新：**复现证书协议（Reproduction Certificate Protocol, RCP）**。每张节点证书 `NC_n` 升级为 `RC_n = (NC_n, recipe, evidence_root, δ_repro, repro_status)`，其中 `recipe` 是**与作者私域无关**的规范配方（无绝对路径、无时间戳、无硬件 ID、依赖全部钉死），`evidence_root` 是原始证据的 Merkle 根。证书只有在**一个独立复现者**按 recipe 重放、且 `d_rep(Replay(recipe, evidence_root), NC_n) ≤ δ_repro` 时才 `VERIFIED`。关键反直觉点：**复现不是为了证明基线"安全"，而是为了证明"安全声明不依赖于作者的私域上下文"**——一张不可复现的证书不是"更保守"，而是"未定义"，必须置 ⊥（拒绝），因此复现**只会缩小**可执行集，绝不会授权新动作。

**灵感 2（多机协同 → 协同的原子是"可复现的证据"，不是"结论"）**
直觉：多机协同的常规做法是共享地图、共享计划、共享模型——本质是**共享结论**，代价是必须信任另一台机器人的私有上下文。v20 的 PCA 聚合观测、CFC 对结论投票，已比"信任结论"进了一步，但它仍无法区分"我真的算过"和"我声称我算过"。核心创新：**复现可达图（Reproduction Reachability Graph, RRG）+ 协同复现协议（Coordinated Reproduction Protocol, CRP）**。协同的原子从"结论"变成"**可复现的推导**"：机器人 i 向 j 发送证据包 `E_{i→j} = (recipe, evidence_root, provenance, claimed_cert, δ_repro, replay_transcript)`，j **亲自重放**并核对；重放一致才把该证书纳入 j 的复现格。关键反直觉点：**你无法为一个自己复现不出来的推导撒谎**——谎报结论只需一行字，谎报推导却必须伪造一份能从真实证据重放出假结论的配方，其难度接近"让 bug 在别人的机器上稳定复现"。于是拜占庭抵抗不再依赖投票多数，而依赖**重放的确定性**：任一个诚实复现者的"已验证不一致"即可否决（veto）。

**灵感 3（多机协同的真伪 → 复现冗余是认知冗余，不是实现冗余）**
直觉：直觉上"5 台机器人各自复现一遍"似乎提供了 5 倍信心。但如果这 5 台机器人跑同一版容器、同一套 V-HACD、同一条标定流程，它们只是**同一错误的 5 份副本**——这正是 v20 结尾点出的"correlated error"在复现层的化身。核心创新：**异构-单一栽培检测器（Diversity-Monoculture Detector, DMC）**。为每个复现者计算**指纹** `φ(r) = (toolchain_digest, sensor_model, calib_lineage, core_lib_digest, hardware_arch)`，把"独立复现者"定义为**指纹类不同**的复现者；定义有效冗余 `κ(c) = 成功复现 c 的指纹类数`，以及结构异构度 `D_struct` 与算法异构度 `D_alg`。关键反直觉点：**复现冗余只有是"异构"的时候才是冗余**——同构的 N 个复现者等效于 1 个；DMC 一旦判定单一栽培，就把 `κ_eff` 坍缩为 1，系统自动退回最保守基线。多机协同的价值因此不在"更多传感器看到更多"，而在"更多**异构**复现者压缩单点私域"。

**三者如何统一**
统一为 **v20 之上的"复现-协同层"**：v20 回答"给定联邦感知，节点 n 在 θ 下的碰撞概率与感知可达域"（`Exec_v20`），v21 回答"这张证书能否被足够的**异构**机器人独立复现，从而成为**协同级（coordination-grade）**证据"（`Exec_v21`）。RCP 是推导侧（规范配方+重放），BGR 是地基侧（快照+包含 witness），RRG 是拓扑侧（谁能复现谁），CRP 是交换侧（证据包+veto），RAG 是闸门侧（准入/退化），DMC 是真伪侧（异构度）。共享状态 `ζ_repro = (recipe_registry, B*, evidence_graph, repro_lattice, κ, φ, δ_repro, D_min, mode_repro)`。**RCP 回答"这张证书能不能被重放出来"，BGR 回答"这条包含链的每一跳有没有被复现过"，RRG 回答"谁能独立复现它"，CRP 回答"跨机证据交换是否一致"，RAG 回答"它能不能进入 v20 的证书格"，DMC 回答"这些复现者是不是同一错误的副本"**。统一接口：**RCP 复现通过 ∧ BGR witness 齐备 ∧ κ ≥ F+1 ∧ DMC 判定异构 → 该证书为协同级，可支撑 v20 的 PCA/CTS/CFC；否则该分量置 ⊥，退回 v20 的声明式（更保守的本地）路径**。

## 1. 研究问题（轮次升级版）

- **Q1（复现的语义与可判定性）**：何为"同一张证书"？`d_rep` 如何定义才能让域体积、margin、边界 Hausdorff 三类偏差同时被约束？`δ_repro` 如何与浮点/GPU/线程的**有界非确定性**联合标定，使"真证书必过、伪证书必拒"？配方规范形式如何做到与作者私域无关（路径、时间戳、硬件、随机种子）？**复现只验证"推导"，不验证"证据"**——证据真实性靠什么锚（硬件信任根、多源物理佐证）？

- **Q2（复现成本与增量等价）**：全量复现的代价等于原始管线本身，不可承受时，如何用**内容寻址 + 依赖切片**做到增量复现 `Replay_Δ` 且与全量 `Replay_full` 在 `δ_repro` 内等价？复现预算如何在"地基跳（v6→v7）"与"叶跳（v19→v20）"之间分配？缓存失效的边界（工具链升级、证据变更、参数漂移）如何精确定义？

- **Q3（跨机复现的冗余与拜占庭）**：`κ(c)` 如何定义与计算才能既刻画"独立"又不陷入最大独立集 NP 难？veto 模型的 soundness/liveness 边界（`k ≥ F+1`）如何证明？复现者**伪造指纹**（假装异构）如何被识别？`D_min` 与 `D_alg_min` 如何用离线标定集确定？跨机证据交换的延迟如何不阻塞 50Hz 控制？

- **Q4（基线治理与退化）**：BGR 如何固定快照 `B*`（容器、标定、传感器模型、种子、核心库）、保存每一跳包含 witness、并处理工具链漂移导致旧配方不可复现？某跳缺 witness 时如何**精确置 ⊥** 而不误伤同链上仍可复现的分量？DMC 触发单一栽培时，如何平滑退化到最保守基线而不产生活性悬崖？

## 2. 设计原则（在 P31–P33 基础上新增 P34–P36）

**P34 复现准入律（Reproduction Admission Law）**
任何进入 v20 证书格的证书 `c` 必须携带 `(recipe, evidence_root, provenance)`，且存在**至少一个独立复现者**使 `d_rep(Replay(recipe, evidence_root), c) ≤ δ_repro`。若 `repro_status ≠ VERIFIED`，则 `c` 置 ⊥，**不得以"作者已声明安全"替代"独立重放"**。复现准入是**纯删除算子**：它只能把 v20 已接受的证书剔除，不能新增任何证书。形式化：`Admit_v21(c) = Admit_v20(c) ∧ ReproVerified(c) ∧ (κ(c) ≥ k_min) ∧ Diverse(c)`。

**P35 基线固定律（Baseline Pinning Law）**
安全继承链 `Exec_v20 ⊆ … ⊆ Exec_v6` 必须在**固定快照** `B* = (code_hash, container_digest, calib_snapshot, sensor_model, core_lib_digest, seed)` 上**逐跳保存 witness** `W_k : Exec_vk ⊆ Exec_{v(k-1)}`，且每个 `W_k` 本身可被独立复现。**未保存 witness 的跳记为 ⊥**，其上的包含性在该分量上"未定义"而非"成立"；不得用"声明传递"冒充"复现传递"。缺 witness 只坍缩对应分量，不污染同链可复现分量（分量级 ⊥）。

**P36 异构冗余律（Heterogeneous Redundancy Law）**
协同级证书要求有效冗余 `κ(c) ≥ F+1`（`F = ⌊(N-1)/3⌋`）**且**异构度 `D_struct ≥ D_min`、`D_alg ≥ D_alg_min`。若 DMC 判定单一栽培（同指纹或共享核心算法族占比过高），则 `κ_eff(c) = 1`，系统退回最保守基线。**复现冗余是认知冗余，不是实现冗余**：同构复现者不提供额外信息，不得计入 `κ`。

## 3. 与基线的接口（如何退化）

- RCP 失效（无 recipe / 无法重放）⇒ 证书 `UNVERIFIED` ⇒ RAG 拒绝 ⇒ 退回 v20 的声明式证书；
- BGR 失效（lineage 断 / 快照丢失）⇒ 包含性仅"声明"、不可复现 ⇒ 按分量置 ⊥ ⇒ 退回 v20；
- RRG 失效（跨机不可达）⇒ `κ = 1` ⇒ 只信任本地复现 ⇒ 退回 v20 本地保守；
- CRP 失效（网络分区）⇒ 无跨机复现 ⇒ `κ = 1` ⇒ 退回 v20；
- DMC 失效（无法测指纹）⇒ 视为单一栽培 ⇒ `κ_eff = 1` ⇒ 最保守；
- 六者全失效 ⇒ 完全退回 v20 的 PCA/CTS/CFC/HPC；
- **安全继承**：RAG 只删不加、BGR 只把"声明"降为"未定义"、DMC 只把 `κ` 坍缩为 1，故 `Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ … ⊆ Exec_v6`（在 `B*` 上且 witness 齐备时），由引理 157–163 保证。

## 4. 预期贡献

1. **可复现证书**：首次把机器人安全证书从"声明"改写为"与作者私域无关、可被独立重放的推导"，给出 RCP 的规范配方、证据根、重放距离与有界非确定性界定，使"基线复现"成为证书的**准入条件**而非事后审计；
2. **可复现地基**：用 BGR 在固定快照上逐跳保存包含 witness，使 v6→v20 的包含链第一次成为"可机械复核的事实"，并把"缺 witness"精确降为分量级 ⊥；
3. **跨机复现协同**：用 RRG+CRP 把多机协同的原子从"结论"升级为"可复现的推导"，给出基于重放确定性的 veto 拜占庭模型（`k ≥ F+1` 即得 soundness），使"谎报"从"说一句"变成"伪造一份能稳定复现的配方"；
4. **异构冗余判据**：用 DMC 的指纹与结构/算法异构度，揭示"复现冗余可能是单一栽培的幻觉"，并给出 `κ_eff` 坍缩到 1 的自动退化；
5. **复现-协同闭环**：RCP+BGR+RRG+CRP+RAG+DMC 构成 v20 之上的复现-协同层，`Exec_v21 ⊆ Exec_v20`，实现"地基可复现→跨机可复现→协同级证书→碰撞安全"的闭环。

## 5. 本轮最大风险

**一句话**：复现只在"推导"层面成立——若**证据本身同源污染或被伪造**（多台深度相机共享同一物理盲区、或证据根可被拜占庭节点伪造），则所有**异构复现者都会忠实地复现同一个错误前提**，"形式上人人可复现、κ≥F+1、DMC 判定异构"的协同级证书，恰恰把"一致的假前提"误认成"独立验证的真结论"——即**复现幻觉**。

# IP-425 Reproduction Certificate Protocol
@dataclass(frozen=True)
class Recipe:
    ops: tuple            # 有序算子：(op_id, params_digest, code_hash)
    toolchain_digest: str # 容器 + 依赖 + 编译器 + 核心库版本，全部钉死
    params_digest: str    # 超参 + 随机种子
    # 规范形式：无绝对路径、无时间戳、无硬件 ID、无 locale 依赖

@dataclass
class ReproductionCertificate:
    cert: object          # 原始证书 NC_n / HPC / ColDom_fed 等
    recipe: Recipe
    evidence_root: str
    provenance: dict      # 硬件信任根签名 + 多源物理佐证
    delta_repro: float
    repro_status: str     # VERIFIED / DIVERGED / UNVERIFIED


class ReproductionCertificateProtocol:
    def __init__(self, cache, delta_repro=1e-3):
        self.cache = cache                     # 内容寻址缓存
        self.delta_repro = delta_repro

    def seal(self, cert, recipe, evidence, provenance):
        root = merkle_root(evidence)
        return ReproductionCertificate(
            cert=cert, recipe=recipe, evidence_root=root,
            provenance=provenance, delta_repro=self.delta_repro,
            repro_status="UNVERIFIED")

    def replay(self, rc, changed_ops=None):
        """增量复现：仅重算依赖切片变化的子配方，其余命中缓存。"""
        key = (rc.recipe.toolchain_digest, rc.evidence_root,
               rc.recipe.params_digest, frozenset(changed_ops or ()))
        if key in self.cache:
            return self.cache[key]
        out = {}
        for op_id, params_digest, code_hash in rc.recipe.ops:
            if changed_ops is not None and op_id not in changed_ops:
                out[op_id] = self.cache[(op_id, params_digest, rc.evidence_root)]
            else:
                out[op_id] = execute(op_id, params_digest, rc.evidence_root)
        result = compose(out)
        self.cache[key] = result
        return result

    def verify(self, rc, changed_ops=None):
        try:
            out = self.replay(rc, changed_ops)
        except MissingEvidence:
            return "UNVERIFIED", float("inf")
        d = certificate_distance(out, rc.cert)   # 对称差 + margin + Hausdorff
        return ("VERIFIED" if d <= rc.delta_repro else "DIVERGED"), d

class BaselineGovernanceRegistry:
    def __init__(self, rcp, baseline_snapshot):
        self.rcp = rcp
        self.B = baseline_snapshot      # 固定快照 B*
        self.lineage = {}               # v -> (recipe, witness, repro_status)

    def register_upgrade(self, v_src, v_tgt, recipe, witness):
        # witness 必须在 B* 上可复现，且证明 Exec_v_tgt ⊆ Exec_v_src
        ok = self._replay_witness_on_B(witness)
        if not ok:
            raise BaselineWitnessError(f"W_{v_tgt} not reproducible on B*")
        self.lineage[v_tgt] = (recipe, witness, "VERIFIED")

    def _replay_witness_on_B(self, witness):
        out = self.rcp.replay(witness.recipe)
        return out.contains_ok(witness.claim, self.B)

    def reproduce_containment(self, v_tgt, floor="v6"):
        """沿 lineage 回溯到地板，逐跳复现；返回分量级结果。"""
        chain = self._path_to_floor(v_tgt, floor)
        status = {}
        for step in chain:
            entry = self.lineage.get(step)
            if entry is None or entry[2] != "VERIFIED":
                status[step] = "BOTTOM"      # 分量级 ⊥，不污染其他分量
                continue
            status[step] = "VERIFIED" if self._replay_witness_on_B(entry[1]) else "BOTTOM"
        return status


# IP-427 Reproduction Reachability Graph
class ReproductionReachabilityGraph:
    def __init__(self, rcp):
        self.rcp = rcp
        self.fingerprint = {}            # robot_id -> φ(r)
        self.edges = {}                  # cert_id -> set(robot_id that reproduced)

    def try_reproduce(self, robot_id, rc):
        status, _ = self.rcp.verify(rc)
        if status == "VERIFIED":
            self.edges.setdefault(id(rc.cert), set()).add(robot_id)
        return status

    def effective_redundancy(self, cert_id):
        reproducers = self.edges.get(cert_id, set())
        classes = {self.fingerprint[r] for r in reproducers}
        return len(classes)             # 独立指纹类数 = κ（O(N)）


# IP-428 Coordinated Reproduction Protocol
class CoordinatedReproductionProtocol:
    def __init__(self, rcp, rrg, F, k_min=None):
        self.rcp, self.rrg = rcp, rrg
        self.F = F
        self.k_min = k_min or (F + 1)

    def make_bundle(self, robot_id, cert):
        rc = cert.rc
        transcript = self.rcp.replay(rc)
        return EvidenceBundle(rc=rc, transcript=transcript,
                              origin=robot_id, sig=sign(robot_id, transcript))

    def receive(self, bundle, verifier_id):
        rc = bundle.rc
        # 1. 先校验证据来源（复现不验证证据真实性，靠 provenance）
        if not self._provenance_ok(rc.provenance):
            return "REJECT_PROVENANCE"
        # 2. 亲自重放：已验证不一致即 veto
        status, d = self.rcp.verify(rc)
        if status == "DIVERGED":
            return "VETO_MISMATCH"
        if status == "UNVERIFIED":
            return "PENDING"
        self.rrg.try_reproduce(verifier_id, rc)
        # 3. 统计独立复现类
        kappa = self.rrg.effective_redundancy(id(rc.cert))
        if kappa >= self.k_min:
            return "COORDINATION_GRADE"
        return "PENDING_REPRODUCTION"


# IP-429 Reproduction Admission Gate（纯删除算子）
class ReproductionAdmissionGate:
    def __init__(self, rcp, rrg, dmc, k_min):
        self.rcp, self.rrg, self.dmc = rcp, rrg, dmc
        self.k_min = k_min

    def admit(self, cert):
        rc = cert.rc
        status, _ = self.rcp.verify(rc)
        if status != "VERIFIED":
            return False, "UNREPRODUCED"            # → 退回 v20
        kappa = self.rrg.effective_redundancy(id(cert))
        if kappa < self.k_min:
            return False, "INSUFFICIENT_REDUNDANCY"
        if not self.dmc.diverse_enough(cert):
            return False, "MONOCULTURE"             # → κ_eff 坍缩，退回 v20
        return True, "ADMITTED"


# IP-430 Diversity-Monoculture Detector
class DiversityMonocultureDetector:
    def __init__(self, rrg, d_min=0.6, d_alg_min=0.5):
        self.rrg = rrg
        self.d_min, self.d_alg_min = d_min, d_alg_min

    def diversity(self, reproducers):
        phis = [self.rrg.fingerprint[r] for r in reproducers]
        if not phis:
            return 0.0, 0.0
        d_struct = len(set(phis)) / len(phis)
        libs = [p[3] for p in phis]              # core_lib_digest
        d_alg = 1.0 - max(libs.count(x) for x in set(libs)) / len(libs)
        return d_struct, d_alg

    def diverse_enough(self, cert):
        reps = self.rrg.edges.get(id(cert), set())
        d_struct, d_alg = self.diversity(reps)
        return d_struct >= self.d_min and d_alg >= self.d_alg_min

    def effective_kappa(self, cert, kappa_raw):
        return kappa_raw if self.diverse_enough(cert) else 1   # 单一栽培 ⇒ 1

## 3. 推导

**引理 157（复现单调性 / Reproduction Monotonicity）** RAG 的准入是 `Admit_v20(c) ∧ ReproVerified(c) ∧ (κ ≥ k_min) ∧ Diverse(c)` 的合取；任一项失败即拒绝，且 RCP 只读证据、只重放、不改证书、不产生新动作。故 `Exec_v21 ⊆ Exec_v20`，复现层只能删除、不能授权。∎

**引理 158（基线包含传递性 / Baseline Containment Transitivity）** 若 BGR 对每跳 `k ∈ {7,…,20}` 保存了在固定快照 `B*` 上可复现的 witness `W_k : Exec_vk ⊆ Exec_{v(k-1)}`，则包含关系在 `B*` 上传递，`Exec_v20 ⊆ Exec_v6`。若某跳缺 witness，则该跳置分量级 ⊥，该分量上的包含性"未定义"而非"成立"。证明：包含是偏序，固定快照下逐跳成立即链式成立；缺一跳则链断于该分量。∎

**引理 159（拜占庭复现可靠性 / Byzantine Reproduction Soundness）** 在 N 个复现者中至多 F 个拜占庭，法定人数 `k ≥ F+1`，采用"已验证不一致即 veto"。则任何与证据不符的证书必被拒绝。证明：`k ≥ F+1` 保证至少一个诚实复现者参与；诚实者确定性重放得到真实结果，与伪证书偏差 `> δ_repro`，触发 veto。soundness 无需多数；多数仅用于 liveness（避免诚实者因数值噪声误 veto，由 `δ_repro` 吸收）。∎ **前提**：证据真实性由 `provenance` 保证——复现只证推导，不证证据。

**引理 160（异构坍缩 / Diversity Collapse）** 若 c 的复现者集合 S 满足 `D_struct < D_min` 或 `D_alg < D_alg_min`，则 `κ_eff(c) = 1`。证明：同指纹复现者共享工具链/传感器/标定/核心库，系统性缺陷被同构复制；它们对"该实现是否正确"提供零额外信息，等效单点。故 `Exec_v21(κ_eff=1) ⊆ Exec_v21(κ ≥ k_min)`，检测到单一栽培即自动退化到最保守基线。∎

**引理 161（协同级可组合性 / Coordination-Grade Composability）** 多机协同计划 P 若其每条跨机依赖（共享碰撞域、共享计划缝、共享 CFC 投票）都由 `coordination-grade` 证书背书，则 P 的全局碰撞安全可归约为各证书的独立复现；否则 P 退回逐机保守基线 `Exec_v20^{local}`。证明：跨机依赖的每个断言都可被至少 `k_min` 个异构复现者独立重放，拜占庭者无法在不伪造证据的前提下令诚实复现者一致通过。∎

**引理 162（增量复现等价性 / Incremental Replay Equivalence）** 内容寻址缓存下，增量复现 `Replay_Δ` 与全量复现 `Replay_full` 在相同证据/参数上满足 `d_rep(Replay_Δ, Replay_full) ≤ δ_repro`。证明：未变化子配方命中缓存，其输出与原执行逐位一致；变化子配方按确定性算子重算；组合算子 `compose` 对未变输入确定。故差异仅来自有界非确定性，被 `δ_repro` 吸收。∎

**引理 163（v21 整体安全继承 / Global Inheritance）** 在 `B*` 快照且所有 witness 齐备时，`Exec_v21 ⊆ Exec_v20 ⊆ … ⊆ Exec_v6`；若任一 witness 缺失或 DMC 触发，则相应分量置 ⊥，`Exec_v21` 进一步收缩。证明：RAG 删除、BGR 把"声明"降为"未定义"、DMC 把 `κ` 坍缩为 1，三者叠加只产生子集。∎

## 7. 已知风险与失效模式

1. **复现幻觉（Reproduction Illusion）**：复现只证"推导"，不证"证据"。若多台相机共享物理盲区，或证据根可被伪造，则异构复现者会忠实地复现同一假前提。缓解：`provenance` 硬件信任根 + 多源物理佐证（触觉/激光/声呐）+ 跨模态一致性检查。
2. **单一栽培（Monoculture）**：同构工具链/传感器/标定使 N 个复现者等效 1 个。缓解：DMC 指纹多维化、算法族交叉核验、强制异构复现者池。
3. **复现成本爆炸**：全量重放等于重跑整条管线，无法承受。缓解：内容寻址 + 依赖切片 + 地基跳优先 + 并行重放。
4. **`δ_repro` 两难**：过紧则真证书误拒（活性悬崖），过松则放行发散证书（安全漏洞）。缓解：按证书类型分层标定、与浮点误差界联合推导、在线校准。
5. **隐藏非确定性**：GPU 原子操作、线程调度、库版本漂移使重放不可逐位一致。缓解：确定性内核、种子/线程钉死、以 `δ_repro` 吸收残余、E787 压力测试。
6. **指纹伪造**：拜占庭复现者谎报 `hardware_arch`/`core_lib_digest` 以伪装异构。缓解：provenance 签名、指纹交叉核验、可信硬件度量。
7. **快照漂移**：容器/核心库升级使旧配方不可复现，包含链断裂。缓解：BGR 版本化快照、漂移登记、重钉迁移脚本、分量级 ⊥ 隔离。

## 8. 本轮最大风险

**一句话**：复现只在"推导"层面成立——若**证据本身同源污染或被伪造**（多台深度相机共享同一物理盲区、或证据根可被拜占庭节点伪造），则所有**异构复现者都会忠实地复现同一个错误前提**，"形式上人人可复现、κ≥F+1、DMC 判定异构"的协同级证书，恰恰把"一致的假前提"误认成"独立验证的真结论"——即**复现幻觉**。
