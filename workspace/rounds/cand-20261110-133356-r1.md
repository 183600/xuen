# 第 44 轮（新循环第 4 轮） · Transfer-Cert × Contact-Cert：把「迁移学习」与「四足接触丰富动力学」纳入可验证证书闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形条件覆盖被欺骗 + 多用户契约求交为空」，但它仍压着两个未言明的单点假设：**(H3) 认证域 = 部署域**——证书默认在其被使用的任何地方成立（同一模型、同一形态、同一地形），而迁移学习恰恰是把策略/证书搬离原域，使证书的有效域被静默越界；**(H4) 接触/模型不确定性被标称证书的标量 margin 吸收**——四足机器人是混合、接触丰富的系统，仿真到现实迁移改变摩擦、柔顺、时延，标量 margin 无法表达「模态切换瞬间 reset 映射把状态跳出不变集」。本轮灵感词「四足机器人」「迁移学习」精确命中这两个假设：**四足机器人**迫使证书从「连续标称系统」升级为「带 guard/reset 的接触混合自动机」；**迁移学习**迫使证书从「域内 sound」升级为「跨域可搬迁且代价可审计」。二者耦合处才是本轮真正的新问题：迁移后的证书可能静默 unsound，微调又可能灾难性遗忘旧证书——**前向安全 ≠ 后向安全**。

## 0. 直觉与动机

**灵感 1（迁移学习 → 迁移不是免费，代价 ∝ 域差）**：直觉上，在水泥地上校准好的「安全余量」搬到冰面上不会自动成立。v20 说「收缩免费、扩张持证」；本轮补上第三条：**迁移也不免费**。给定源域 D_S 上 sound 的证书 C_S，迁到目标域 D_T，若两域距离 ≤ δ 且动力学对状态 L-Lipschitz、对参数 κ-Lipschitz，则迁移证书 C_T = erode(C_S, L·δ) 在 D_T 上 sound——**域差直接侵蚀安全余量**。一旦 δ 超过预算或侵蚀后不变集为空，唯一合法动作是**拒绝迁移、从头重新认证**，绝不把源域证书「贴个新标签」放行。这把「迁移」从工程建设降格为一条可静态审计的算子：输入源证书 + 域差上界，输出目标证书 + 侵蚀见证。

**灵感 2（四足机器人 → 接触是证书的隐藏模式）**：四足证书不能只写连续流，必须写成带模式（支撑/摆动/腾空）、guard（触地/离地）、reset（冲击）的混合自动机。接触安全的核心标量是**摩擦裕度** m_fric = μ̂ − μ_req：需求切向力超过可用摩擦即打滑。迁到低摩擦地形时摩擦锥收缩，触地冲击还会通过 reset 映射把状态「跳」到集外。于是给出**接触迁移引理**：若冲击速度有界、摩擦裕度非负，则迁移后的 reset 把状态保持在侵蚀不变集内；在线打滑检测负责持续重估 μ̂，让 m_fric 始终 sound。四足由此从「一个难标的被控对象」升级为「验证接触迁移引理的最佳压力床」。

**灵感 3（耦合 → 迁移会遗忘证书：前向安全 ≠ 后向安全）**：在冰面数据上微调策略，会让原本在水泥地上成立的证书**灾难性遗忘**——这是「保证的灾难性遗忘」。因此必须同时要**前向迁移 soundness**（新域不打滑/不摔）与**后向迁移 soundness**（旧域证书不被新参数破坏）。做法是证书关键状态 replay 缓冲 + 更新后 retention 检查 + 保护证书谓词的弹性正则；retention 失败即触发旧域重新认证，而非静默失效。一句话：**迁移不仅要「搬得过去」，还要「回得去」**。

**耦合升级**：CTC（迁移演算）把域差编译成证书侵蚀；HCTC（接触迁移证书）处理四足的模态/摩擦/reset 迁移；CRV（证书保持验证器）防止微调遗忘。四层架构由 v8 的「人格契约 + 并发证书」升级为 v9 的「人格契约 + 并发证书 + 迁移演算层 + 接触混合层」。

## 1. 形式化定义（增量：定义 44–48）

**定义 44（证书迁移算子与域差预算）**：证书 C = (I, θ, D, ℓ) 含不变集 I、阈值 θ、有效域 D、租约 ℓ。域差 δ = sup_{z∈D_S∪D_T} d_∞(D_S, D_T)，或证书相关特征分布间的 Wasserstein 距离。若动力学 f 对状态 L-Lipschitz、对参数 κ-Lipschitz，定义迁移算子 Trans_δ(C_S) = (erode_{Lδ}(I_S), θ_S + κδ, D_T, ℓ_T)。**定理（迁移 sound 性）**：若 δ ≤ δ_max 且 erode_{Lδ}(I_S) ≠ ∅，则 C_T 在 D_T 上 sound；否则必须拒绝迁移并重新认证。**推论**：迁移代价是 O(Lδ) 的余量侵蚀，域差可被静态审计；「迁移成功」不是布尔值而是带见证的证书。

**定义 45（传输见证与加权共形迁移覆盖）**：用耦合/传输计划 γ 定义迁移见证；权重 w(z) = dμ_T/dμ_S(z)。加权共形仅在权重有界或有效样本量 ESS(w) ≥ N_min 时给覆盖 P ≥ 1−α。**迁移覆盖条件**：若权重尾部重（无重叠/域外推），可交换性被破坏到无法修复，则拒绝迁移而非伪造覆盖。δ 由成对/非成对 rollout 上的证书相关特征差估计，并取保守上包络。**注**：共形在域内只需可交换，跨域必须换成加权共形 + 重叠假设，这是迁移与 v20 共形层的接缝。

**定义 46（接触混合自动机证书与摩擦裕度）**：四足证书是混合自动机 H = (Q, f_q, G, R)，Q = {stance, swing, flight}，G 为 guard，R 为 reset。证书额外携带摩擦裕度 m_fric = μ̂ − μ_req 与冲击界 v_imp。**打滑事件**：需求切向力 > m_fric。**接触迁移引理**：迁到摩擦 μ_T（Δμ = μ_T − μ_S），若 m_fric,T ≥ 0 且 v_imp ≤ v_imp_max，则对每个模态 q 的 reset 都把状态保持于 erode(I, η(Δμ, v_imp)) 内。在线打滑检测以指数滑动更新 μ̂。**推论**：摩擦与冲击不是「噪声」，而是证书里两个必须显式出现、可迁移、可在线重估的字段。

**定义 47（证书保持与后向迁移 soundness）**：策略更新 θ→θ′。保持集 R(C, θ′) = {C_i : C_i 在 θ′ 下仍成立}；遗忘度 F = 1 − |R|/|C_old|。**后向迁移 soundness**：更新必须满足 F = 0，或对被遗忘域显式触发重新认证。证书关键状态 replay 缓冲 B_cert 存 (z, pred)；若任一 pred 在新参数下失效，则该域进入 re-certify 队列。**命题**：仅做前向验证的迁移，其 F 可在不触发任何新域告警的情况下悄悄增大——后向审计不可省。

**定义 48（迁移感知认证课程与域选择）**：源域集合 S 的选择最小化迁移总代价 J_transfer(S) = E[erode_{Lδ}] + λ·ReCertCost(S) + μ·F(θ′(S))。用贪心/子模最大化选域，优先挑「域差小、覆盖率增益大、遗忘风险低」的源域组合；课程难度显式含「迁移侵蚀率」与「打滑率」。**推论**：源域越多不一定越好——域差大时边际收益被侵蚀成本吃掉，存在最优源域子集。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 CERTIFICATE-TRANSFER-CALCULUS（迁移演算 CTC）
1. **域差估计**：成对/非对 rollout 的证书相关特征 Wasserstein/最大偏差，输出 δ 及其保守上界（取上包络，不取均值）。
2. **迁移算子 + 拒绝逻辑**：C_T = erode(C_S, Lδ)；空集或 δ > δ_max → 拒绝迁移、从头认证，绝不做「贴标签式迁移」。
3. **加权共形覆盖**：ESS 闸门 + 权重尾部检测；无重叠即拒绝，覆盖不达标不回退到伪造。
4. **迁移见证账本**：记录 (C_S, δ, L, 侵蚀量, 目标域)，供审计、回放与消融。

### 2.2 IP-61 HYBRID-CONTACT-TRANSFER-CERT（接触迁移证书 HCTC）
1. **混合自动机证书**：模式/guard/reset 显式建模，证书随模态更新，禁用「一个连续不变集打天下」。
2. **摩擦裕度 + 在线 μ̂**：足端切向/法向比、IMU 残差做打滑检测，指数滑动更新 μ̂，m_fric 随地形迁移重估。
3. **冲击 reset 鲁棒性**：冲击速度界 + reset 侵蚀，防「落地一跳跳出不变集」。
4. **地形条件证书模板**：按摩擦/柔顺条件索引，迁移即换模板 + 侵蚀，模板与地形哈希绑定防张冠李戴。

### 2.3 IP-62 CERTIFICATE-RETENTION-VALIDATOR（证书保持验证器 CRV）
1. **证书关键状态 replay 缓冲**：存高风险/边界状态与谓词，优先存「离违例最近」的样本。
2. **更新后 retention 检查**：计算遗忘度 F，超阈值即对旧域 re-certify。
3. **证书谓词弹性正则**：微调时惩罚破坏旧证书谓词的参数漂移，像 EWC 但正则在证书谓词上而非权重。
4. **遗忘审计与回灌**：被遗忘域反例回灌 CKB/SCV，形成「遗忘 → 重认证 → 课程」闭环。

回退：E96 δ 低估 → 取更保守上包络 / 缩短有效域，绝不放宽侵蚀；E97 打滑/re​set 不可界 → 关闭跨低摩擦迁移，只保留域内认证；E98 遗忘不可控 → 禁止在线微调，冻结证书谓词或用完整重认证；E99 无重叠 → 拒绝迁移；E100 形态迁移超界 → 只接受出厂形态；任何红线失败 → 全链路熔断回退 v20「不迁移、仅域内认证 + 串行安全监控」。

## 5. 本轮最大风险

**一句话**：迁移证书的 soundness 完全依赖域差 δ 的保守上界，而四足接触丰富的 sim-to-real 缺口是重尾、随地形/负载/磨损漂移且难以离线测量——一旦 δ 被低估，侵蚀不足会让迁移证书静默 unsound，且微调的灾难性遗忘会同时抹掉旧域保证；因此 E96（δ 不得低估）与 E97（接触/打滑）必须设为红线实验，并默认回退到「不迁移、仅域内认证 + 全程串行安全监控」这条永不失 sound 的底线。

## 1. 符号体系（增量：定义 44–48 符号）

## 2. 关键算法（伪代码）

### IP-60 CTC：域差估计、迁移算子与加权共形
```
def estimate_domain_gap(src_rollouts, tgt_rollouts, L_f, feat_map):
    # 只用证书相关特征，避免被无关维度稀释
    S = [feat_map(z) for z in src_rollouts]
    T = [feat_map(z) for z in tgt_rollouts]
    delta_point = wasserstein_inf(S, T)          # 或最大偏差
    delta_upper = bootstrap_upper_bound(S, T, 0.99)  # 取上包络，不取均值
    return delta_upper, L_f * delta_upper        # (域差, 余量侵蚀)

def transfer_certificate(C_S, delta, L, kappa, delta_max):
    erosion = L * delta
    I_T = erode(C_S.I, erosion)
    if I_T.is_empty() or delta > delta_max:
        return RefuseTransfer(reason="gap_or_empty", witness=(C_S, delta))
    return Certificate(
        I=I_T,
        theta=C_S.theta + kappa * delta,   # 参数灵敏性也计入阈值
        domain=C_S.domain,                 # 目标域由调用方替换
        lease=C_S.lease,
        witness=TransferWitness(C_S, delta, L, erosion))

def weighted_conformal_transfer(scores, weights, alpha, N_min):
    ess = effective_sample_size(weights)
    if ess < N_min or has_heavy_tail(weights):
        return RefuseTransfer(reason="no_overlap")   # 不伪造覆盖
    q = weighted_quantile(scores, weights, 1 - alpha)
    return IntentSet(radius=q)
```

### IP-61 HCTC：摩擦裕度、打滑重估与接触迁移
```
def contact_transfer(C_contact, mu_hat_T, mu_req, v_imp, v_imp_max):
    m_fric = mu_hat_T - mu_req
    if m_fric < 0 or v_imp > v_imp_max:
        return RefuseContactTransfer(reason="slip_or_impact")
    # reset 侵蚀：冲击越大、摩擦裕度越小，侵蚀越多
    eta = impact_erosion(v_imp, m_fric)
    return Certificate(I=erode(C_contact.I, eta), m_fric=m_fric,
                       witness=ContactWitness(mu_hat_T, v_imp, eta))

def slip_update(mu_hat, slip_event, eta=0.1):
    if slip_event:
        mu_slip = estimate_friction_from_slip()   # 切向/法向比 + IMU 残差
        mu_hat = mu_hat * (1 - eta) + mu_slip * eta
    return mu_hat

def guard_by_mode(cert, q, z):
    # 混合自动机：每个模态有自己的不变集与 guard
    if not cert.I_q[q].contains(z):
        return False
    if q in (STANCE, FLIGHT) and cert.m_fric < 0:
        return False                              # 摩擦裕度为负，禁入守卫
    return True

def contact_step(cert, q, z, u, dt):
    z_next = f_q(z, u, dt)
    if guard_fires(q, z_next):                    # 触地/离地
        q_next = next_mode(q)
        z_next = R[q, q_next](z_next)             # reset 可能跳变
        if not cert.I_q[q_next].contains(z_next):
            return cert, q, z, "IMPACT_ESCAPE"    # 显式暴露，不静默吞掉
        return cert, q_next, z_next, "OK"
    return cert, q, z_next, "OK"
```

### IP-62 CRV：证书保持与反遗忘
```
def retention_check(theta_new, replay_buffer, C_old, rho):
    violated_domains = set()
    for (z, pred, domain) in replay_buffer:
        if not holds(pred, theta_new, z):
            violated_domains.add(domain)
    F = len(violated_domains) / max(1, len(C_old))
    if F > rho:
        return ReCertify(domains=violated_domains), F
    return None, F

def transfer_aware_finetune(theta, data_new, replay, cert_preds, beta):
    for batch in data_new:
        loss = task_loss(theta, batch)
        # 证书谓词弹性正则：越接近边界的样本权重越大
        loss += beta * certificate_penalty(theta, replay, cert_preds)
        theta = theta - lr * grad(loss, theta)
    return theta

def select_source_domains(candidates, goal, budget):
    chosen = []
    while budget > 0:
        best = argmax(candidates, key=lambda d:
                      gain(d, goal) - cost_of_transfer(d, chosen))
        if gain(best, goal) - cost_of_transfer(best, chosen) <= 0:
            break
        chosen.append(best); budget -= cost(best)
    return chosen
```

### IP-51 升级：迁移-接触-人格感知的守卫
```
def car_transition_guard(e, x, cert_obj, persona, lease, transfer, contact, t):
    theta = cert_obj.alpha_e[e] * cert_obj.theta_sim[e]
    m_lookup = cert_lookup_L0(x).m_lo[e]
    m_lease  = lease.m - lease.lam * (t - lease.tau)
    m_cap    = persona_cap[e](persona)            # v20：人格只做上限收缩
    m_trans  = cert_obj.margin[e] - transfer.erosion   # v21：迁移侵蚀
    m_fric   = contact.m_fric if e in (STANCE, FLIGHT) else +inf
    m = min(m_lookup, m_lease, m_cap, m_trans, m_fric)
    return m >= theta and lease_valid(lease, theta, t) and not transfer.refused
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性保证 |
|---|---|---|---|
| IP-60 域差估计 | O(N log N)（排序/分位） | O(N) rollout 特征 | 上包络 δ ⟹ 侵蚀保守；低估率由 E96 红线约束 |
| IP-60 迁移算子 | O(侵蚀网格) 离线 | 不变集网格 | δ ≤ δ_max ∧ 非空 ⟹ C_T 在 D_T sound（定理 44） |
| IP-60 加权共形 | O(N log N) | 权重/分数 O(N) | ESS ≥ N_min ∧ 尾部有界 ⟹ 覆盖 ≥ 1−α（条件 45） |
| IP-61 接触迁移 | O(|Q|·网格) 离线 | 每模态不变集 | m_fric ≥ 0 ∧ v_imp ≤ v_imp_max ⟹ reset 保持侵蚀集（引理 46） |
| IP-61 打滑重估 | O(1)/步 | μ̂ O(1) | 指数滑动跟踪；μ̂ 单调保守时可证不提前放行 |
| IP-61 混合 step | O(|Q|) 查 guard/reset | O(1) | 每步检查模态不变集；escape 显式上报（不静默） |

## 4. 实验设计（E95–E102，硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E95 证书迁移 soundness | 跨地形迁移后违例；侵蚀量 vs 真实域差 | 0 起；侵蚀 ≥ 真实偏差 |
| E96 域差估计 | δ 上包络覆盖率；低估率；配对真机对照 | ≥99%；0；报告上/下包络 |
| E97 接触/摩擦迁移 | 打滑事件；冲击跳出不变集；m_fric 预警提前率 | 0 起；0 起；100% |
| E98 证书保持/后向迁移 | 20 次顺序微调旧域违例；遗忘度 F；re-certify 正确率 | 0 起；0；100% |
| E99 加权共形迁移覆盖 | 漂移下覆盖率；ESS 拒绝率；权重尾部指数 | ≥1−α(α=0.1)；不重叠必拒绝；尾部有界 |
| E100 形态迁移 | 腿长 ±20%、质量 ±15% 下 soundness；侵蚀敏感度误差 | 0 起；<20% |
| E101 迁移拒绝校准 | 超预算拒绝率；静默 unsound 迁移；误拒绝率 | 100%；0；<10% |
| E102 长时程四足迁移 | 100h 多地形切换摔倒；打滑恢复时延；接触证书过期率 | 0 起；<200ms；<5% |

回退：E96 δ 低估 → 取更保守上包络 / 缩小有效域，绝不放宽侵蚀；E97 打滑/reset 不可界 → 关闭跨低摩擦迁移，只保留域内认证；E98 遗忘不可控 → 禁止在线微调，冻结证书谓词或完整重认证；E99 无重叠 → 拒绝迁移；E100 形态迁移超界 → 只接受出厂形态；E101 误拒绝过高 → 细化地形模板而非放宽 soundness；任何红线失败 → 全链路熔断回退 v20「不迁移、仅域内认证 + 串行安全监控」。

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 域差 δ 被低估，迁移证书侵蚀不足，静默 unsound | 高 | E96 红线；只用保守上包络；配对真机校准；δ 超预算即拒绝 |
| 四足 sim-to-real 接触缺口重尾、随负载/磨损漂移，离线 δ 失效 | 高 | E97 红线；在线打滑重估 μ̂；δ 带租约定期刷新；重尾即判不可迁移 |
| 微调灾难性遗忘旧域证书，前向验证完全察觉不到 | 高 | E98 红线；证书关键状态 replay；遗忘度 F 触发 re-certify；禁止静默在线微调 |
| 加权共形在无重叠区伪造覆盖，域外推被当成域内 | 高 | E99 红线；ESS 闸门 + 尾部检测；无重叠直接拒绝迁移 |
| reset/冲击模型不准，落地跳出不变集 | 中-高 | 冲击速度界保守化；reset 侵蚀；E97 专项注入；escape 显式上报 |
| 混合自动机证书状态爆炸（地形 × 模态 × 人格） | 中 | 模板化 + 哈希绑定；只对高风险组合精细证书；其余走保守模板 |
| 迁移见证账本被当作「一次性盖章」，过期不刷新 | 中 | 见证带租约 ℓ_T；地形/负载变化即失效；总线审计 |
| 源域选择贪心陷入局部最优，多源迁移得不偿失 | 中 | 子模性验证；负边际即停；与全量重认证做成本对照 |

## 6. 本轮最大风险

**一句话**：迁移证书的 soundness 完全依赖域差 δ 的保守上界，而四足接触丰富的 sim-to-real 缺口是重尾、随地形/负载/磨损漂移且难以离线测量——一旦 δ 被低估，侵蚀不足会让迁移证书静默 unsound，且微调的灾难性遗忘会同时抹掉旧域保证；因此 E96（δ 不得低估）与 E97（接触/打滑）必须设为红线实验，并默认回退到「不迁移、仅域内认证 + 全程串行安全监控」这条永不失 sound 的底线。
