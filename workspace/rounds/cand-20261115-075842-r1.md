# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「示教学习」×「UniBot世界挑战赛」）

> R69 给闭环装上了一张嘴：它把不确定性分成 aleatoric 与 epistemic，对可约的 epistemic 主动去看、去问、去触。但这个设计有一个隐含前提——**总有一个在场、可信、愿意回答的人**。R69 自陈的最大风险也正是从这里长出来的：一旦那个「回答者」不可信（或流模型幻觉出一个幻影模态），系统就会把「诚实的不知道」升级成「被证实的错误」。
>
> 本轮两个灵感正好把这个前提拆掉：
> - **示教学习**告诉我们，回答者不必实时在场——示范是**老师离线留下的消歧记录**：既给出「怎么做」，也给出「老师在自己的不确定处怎么处理」。于是可以把 R69 的提问能力，从「运行时问人」迁移成「部署前从示范里学」。
> - **UniBot 世界挑战赛**给了一个最残酷的部署约束：**评分时没有人可问、试次有限、held-out 分布、排行榜只认分数、一次灾难性失败可能让整轮归零**。
>
> 核心命题：**在 R69 的二分之上再加第三类不确定性——迁移不确定性 U_tr（我的示范/老师，是否覆盖并解释得了眼前这个情境）。U_tr 不能靠问世界消除（问物体「你属于哪个示范簇」是无效的），只能靠「带覆盖证书的示范答案库 + 示范质量审计 + 无人时的共形鲁棒选择」来消解；消解不了就弃权/保守，绝不猜。再把 R69 的逐步 VoI 升级成「全局预算 + 风险破产」的元控制，并在进入无人竞赛前交出一张可统计检验的交接证书。** 命名 **COACH-RAS**（Competition-Oriented Apprenticeship with Calibrated Handoff）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**没人可问时，我该向谁学、学到的还能信吗**」。

## 0. 直觉与动机

**灵感 1（示教不是克隆，是「老师的消歧记录」）**
直觉：行为克隆把示范看成 (o, a) 的监督对，这是把老师当成一个「动作生成器」；但人在示教时做的远不止生成动作——他会**停下来看**、会**把物体转一下**、会**说「不是这个，是那个」**、会在自己也不确定时**换一个更稳的抓法**。这些恰恰是 R69 里 MINT 想主动生成的信息动作。也就是说，示范天然包含一份**「人类如何在不确定时消歧」的策略**。R70 的第一个动作，是把人类示范里的干预/纠正轨迹，与 R69 运行时的「不确定—信息动作—回答—结果」轨迹合并成 **D_ask**，用 LfD 学出一个 π_ask：**从示教中学会「何时该问、问什么」**。这把 R69 的交互从「手工 VoI 枚举」升级为「有老师先验的交互策略」。

**灵感 2（示范支撑集 = 一张「我凭什么可信」的地图）**
直觉：R69 的 U_epi 是**自指的**——它来自策略自己对动作的采样。一个自信地幻觉出某个模态的策略，会同时给出「模态很清晰、权重很高」的错误信念，这就是 R69 最大风险的根源。示范提供了**外部锚点**：不是「我的策略觉得这个动作像不像」，而是「**老师的数据支持不支持这个动作**」。于是可以把「策略自洽」与「示范自洽」做成两条独立通道；两者一致才认证，只有策略自洽而示范不支持，恰恰是幻影模态的签名。更妙的是，示范支撑集还能给出一个**可证伪的覆盖承诺**：用共形预测（conformal prediction）把「这个情境下的真实模态落在候选集里」变成一个**分布无关、可在线检验的覆盖率**，而不是一句「大概没问题」。

**灵感 3（竞赛 = 一次不可作弊的「迁移考试」）**
直觉：UniBot 世界挑战赛不是又一组离线 benchmark。它同时施加四个约束：(a) **评分时无人可问**——R69 的交互通道被物理切断；(b) **试次/时间/算力有限**——每一步提问都在花预算，且花掉就没了；(c) **held-out 物体/场景/指令**——正好打在示范支撑集的边缘；(d) **排行榜与失败恢复**——单次灾难性失败可能让整轮归零，而部分完成仍有分。这四条合起来，把 R69 的「每步贪心 VoI」变成了一个**全局预算分配 + 风险破产（risk-of-ruin）**问题：早期一个诱人的提问，可能吃掉后面高价值任务的预算。R70 必须把「交互」从一个 step-level 动作，提升为一个 **episode-level / run-level 的资源**。

**灵感 4（人类干预的选择性偏置——一个尖锐的坑）**
直觉：如果直接用「人类介入的轨迹」训练 π_ask，会踩中一个漂亮的陷阱：**人恰恰是在机器人不会的地方才介入**。所以介入样本的状态分布天然偏向 OOD，而这个分布正是部署时最危险、也最缺数据的地方——朴素 BC 会在最该准的地方最不准（DAgger 的协变量偏移，在「学提问」上更严重）。因此 R70 的 π_ask 训练必须用 **DAgger 式状态聚合**：让机器人在自己的状态分布上跑、只在需要处请人标注，而不是照着人类的介入分布学。这个细节决定了「从示教学提问」是科学还是自欺。

**灵感 5（无人可问时，正确答案可能不是一个模态，而是一个鲁棒动作）**
直觉：R69 假设「问完就能把后验收成一个尖峰」。竞赛里问不了，但歧义仍在。此时最自然的做法是「选权重最大的模态」——这正是最危险的：在模态间距大、代价不对称时，MAP 可能是最坏选择。更好的做法是：用共形集给出**一组仍然可能的模态**，然后求一个**在所有可能模态下都不太差**的动作（若各模态的安全集有交集，就直接取交集）。这不是把歧义抹平，而是**在歧义下做鲁棒决策**。R69 的 MAP+ask 是它在「共形集收缩成单点」时的特例——新层再次严格包含旧层。

**灵感 6（交接必须可检验，而不是表忠心）**
直觉：从「练习赛有人兜底」到「决赛无人兜底」，不能靠一句「模型收敛了」。需要一张**预注册的交接证书**：在高置信度下，无人策略的价值下界不低于有人策略减去 ε_h（HCOPE / 安全策略改进），共形覆盖在偏移检验下仍达标，风险破产概率 ≤ ρ。任一不达标，就单调退化回影子模式/有人模式/保守模式。**没证书不上场**，这是把 R68/R69 的「安全不放宽」原则，推进到「部署资格」这一层。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（COACH-RAS 总览）** COACH-RAS = (DAT, TCG, DIL, DQA, DMM, RSA, ILP, BRC, HOC, FLUID-RAS†)。四条不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **无 oracle 诚实性**：无可信回答者时，任何「回答」都不得计为消解；U_tr 保持未消解并走保守；
(iii) **覆盖纪律**：示范答案只有在「共形覆盖成立且偏移检验通过」时才能消解 U_tr，否则弃权；
(iv) **预算-破产约束**：全局交互/试次预算 B、安全下限 S_floor，元控制器保证 P(ruin) ≤ ρ。

**定义 311（示范语料与支撑集）** D = {(o_i, ξ_i, y_i, s_i, w_i)}_{i=1}^N，y_i 为结果、s_i 为来源/本体/操作者、w_i 为可信权重。示范支撑集 supp_ε(D) = {o : d_Φ(o, D) ≤ ε}，d_Φ 为学到的任务度量。示范模式集 M_D(o) = 在 o 附近可取的示范动作簇（含权重与来源分布）。

**定义 312（不确定性三分）** 继承 R69：U_ale（世界噪声，不可约）、U_epi（当前观测下动作模态歧义，可经世界交互消解）。新增 **U_tr = (U_cov, U_spec)**：U_cov 为覆盖亏空（眼前情境落在示范支撑外/偏移超限），U_spec 为示范内部规格歧义（多个同样合法但互斥的老师意图/风格）。三者语义不同，**不做简单加和**，分别进入：λ_floor / 世界交互 / 示范答案或鲁棒选择。

**定义 313（示范答案库 DAT）** 查询 q = (o, r)（r 为 π_ask 请求的证据类型）；检索 top-k 示范，构造非一致性分 s_i(q)，共形 p 值 p(q) = (1 + #{i : s_i ≥ s_q}) / (k+1)；回答集 C_α(q) = {m : p_m(q) > α}。返回 Answer = (C_α, p, γ)，γ 为偏移统计量。**C_α 为空 ⇒ 不回答（abstain），绝不取最大权重补位。**

**定义 314（迁移覆盖门 TCG）** 设标定集与部署流的分布偏移为 γ（e-value / MMD / 密度比上界）。门开 ⇔ C_α ≠ ∅ ∧ γ ≤ γ_max(α)。门开时给出 U_cov = 0（已认证），门关时 U_cov = 1（未消解），并把 (α, γ) 写入证书。**共形覆盖率在偏移下会衰减（引理 20），因此 TCG 不是可选项。**

**定义 315（示范一致性似然 DIL，第三通道）** d_score(ξ, o) = min_{m ∈ M_D(o)} d_Φ(ξ, m)（或 −log p_D(ξ|o)）；Δd = |d_score(o) − d_score(o_cal)|。三通道证据：r_res（传感器自洽，R68）、a_score（策略自洽，R69 FMA）、d_score（示范外锚，R70）。**联合签名：a_score 低 ∧ d_score 高 ⇒ 幻影模态 / 分布外**（引理 21）。

**定义 316（示范质量与投毒审计 DQA）** 逐示范影响 infl_i = L_val(π_D) − L_val(π_{D\{i}})（leave-one-out / influence function）；并计入来源可信度、跨本体一致性、结果条件过滤（失败示范只提供负例）、陈旧度。ℰ_demo = {投毒示范, 异构本体示范, 陈旧示范, **故意歧义示范**（构造两个互斥但都像真的老师）}。低质量/高影响样本被降权或剔除，并记入 provenance_hash。

**定义 317（示范-策略模态对齐 DMM）** 把 R69 的 FMP 模态 {m_k} 与示范模态 M_D(o) 做匹配（Wasserstein / 匈牙利）。定义 **覆盖召回** ρ_cov = 被示范解释的策略模态质量；**幻觉率** ρ_hall = 无示范对应的策略模态质量；**遗漏率** ρ_miss = 无策略对应的示范模态质量。三者进入 U_tr 与审计，不进入 λ 的简单加和。

**定义 318（共形鲁棒选择 RSA）** 已知 C_α(q) 与损失 L(a, m)。安全集 𝒮(m) = {a : risk(a|m) ≤ ε}。若 ∩_{m∈C_α} 𝒮(m) ≠ ∅：取其中风险最小者（Pareto 安全）；否则取 a* = argmin_a max_{m∈C_α} L(a,m)。**MAP 选择只是 |C_α|=1 的特例。**

**定义 319（从示教中学提问 ILP）** D_ask = 人类示范中的信息动作/纠正 ⊕ R69 运行时的 (U, g, answer, outcome) 轨迹。训练用 DAgger 聚合：机器人按 π 跑出自己的状态分布，人类在这些状态上只标注「该不该问、问什么」，再聚合。π_ask = argmax E_{s~d_π}[log π(g|s)]，并加 **覆盖约束**：π_ask 触发的问题必须落在 DAT 能认证的区域（否则问也白问）。

**定义 320（预算-破产元控制器 BRC）** 状态 (b, n)：剩余预算与剩余任务；动作 (k_e, λ_e)：本 episode 的交互额度与风险姿态。目标 max E[Σ_e S_e] s.t. P(Σ_e S_e < S_floor) ≤ ρ 且每步安全约束。离线用离散化 DP / 拉格朗日求解，在线 O(1) 查表。**R69 的 MINT = BRC 在 B=∞、N=1（或无限视界折扣）下的边界。**

**定义 321（竞赛成本与弃权成本）** 竞赛模式下每次信息动作有显式成本 c_comp(g) = c_time + c_trial + c_opportunity（排行榜影子价格）。**弃权不是免费的**：abstain 有分数成本 c_abs，但安全上恒不劣。MINT 的成本升级为 c(g) + c_comp(g) + c_abs·1[abstain]。资源在三者（问 / 做 / 弃）之间分配。

**定义 322（交接证书 HOC）** 进入无人竞赛前，用离线示范与有人 rollout 估计：
- HCOPE 高置信下界 V_LB(π_auto) ≥ V(π_assist) − ε_h；
- 共形覆盖在偏移检验下 ≥ 1 − α − γ_shift；
- 风险破产 P(ruin) ≤ ρ；
- J_FLUID 有效。
Valid ⇔ 四项全过；否则只能以影子 / 有人 / 保守模式参赛。

**定义 323（三通道证据纪律）** 竞赛模式下，一个模态被采纳需满足 {r_res(+人类回答), a_score, d_score} 中**至少两源一致**，且 DAT 已认证（或 U_epi = 0）。单源、单次示范、单次检索不得单独定案（继承并强化 R69 定义 293-iii）。

**定义 324（证书 J_COACH）** J_COACH = (J_FLUID, C_α 覆盖, γ_shift, ρ_cov / ρ_hall / ρ_miss, hcope_lb, ruin_bound, demo_provenance_hash, coach_ver)。Valid ⇔ Valid(J_FLUID) ∧ 覆盖达标 ∧ 偏移达标 ∧ 证据纪律 ∧ 预算未越界 ∧ HOC 有效。

**定义 325（部署协议与单调退化）** 四阶段：练习（人可答）→ 影子（人答但机器人执行）→ 资格（小规模无人，受控）→ 竞赛（完全无人）。任一证书失效 ⇒ **只能向更保守阶段单调退化**，不得在同一赛事内无重新认证地跳回。切换沿用 R68 定理 15 / R69 定理 17 的提交-换装不变式，保证控制连续。

```python
# IP-264 DAT：示范答案库（检索 + 共形预测集 + 覆盖证书）
class DemoAnswerer:
    def __init__(self, index, calib, alpha, shift_test):
        self.index, self.calib = index, calib        # ANN over demo (o, xi, y, src)
        self.alpha, self.shift = alpha, shift_test

    def query(self, o, q):
        nb     = self.index.search(embed(o, q), k=K) # top-k 示范
        scores = conformity(nb, o, q)                # 非一致性分
        C      = {m for m, s in scores if p_value(s) > self.alpha}
        gamma  = self.shift.e_value(o)               # 部署 vs 标定偏移
        certified = (len(C) > 0) and (gamma < GAMMA_MAX)
        return Answer(C, certified, gamma)           # 不可认证 -> abstain

# IP-265/266 TCG+DIL：覆盖门 + 第三证据通道
def transfer_gate(ans):
    if not ans.certified:
        return False, 1.0                            # U_cov 置满，未消解
    return True, 0.0

def demo_likelihood(xi, ans, metric):
    if not ans.C:
        return +inf                                  # 无示范 => 不可认证
    return min(metric(xi, m) for m in ans.C)         # d↑ = 示范不支持

# IP-267 DQA：示范质量与投毒审计（离线 + 增量）
def demo_audit(D, val):
    infl = [loo_influence(D[i], val) for i in range(len(D))]
    bad  = {i for i, x in enumerate(infl) if x > TAU_INF}
    return filter_demo(D, bad), provenance_hash(D)

# IP-269 RSA：共形鲁棒选择（无人可问时的默认）
def robust_select(modes, C, lam):
    safe = intersect(safe_set(m) for m in C)         # 各假设都安全的动作
    if safe:
        return argmin(safe, risk)                    # 交集非空：Pareto 安全
    return argmin(modes, lambda a: max(loss(a, m) for m in C))  # 最坏情况

# IP-270 ILP：从「人类介入/回答」示范学习何时问（DAgger 纠正）
def train_ask_policy(D_ask, policy, iters=3):
    for _ in range(iters):
        roll   = policy.rollout()                    # 机器人自己的状态分布
        labels = human_intervene(roll)               # 只在需要处标注
        D_ask += roll                                # 聚合，避免选择性偏置
    return fit_interaction_policy(D_ask)             # π_ask

# IP-271 BRC：全局预算 + 风险破产（离线 DP，在线查表）
def budget_controller(b, n, tasks, rho):
    # V(b,n) = max_{k_e, lam_e} E[S_e + V(b-k_e, n-1)]
    #          s.t. P(ΣS < S_floor) ≤ rho，交互/试次预算 b
    return dp_lookup(b, n, tasks, rho)               # 逐 episode 给 (k_e, λ_e)

# IP-272 HOC：交接证书（离线，高置信）
def handoff_certificate(pi_auto, pi_assist, D, rho):
    lb = hcope_lower_bound(pi_auto, D, delta=1e-3)   # 高置信价值下界
    return ((lb >= value(pi_assist) - EPS_H)
            and coverage_ok(last_coverage)
            and ruin_ok(rho))

# IP-276 主闭环（继承 FLUID-RAS，仅替换回答者与决策层）
def COACH_RAS_round(M, obs, stage):
    # 0) 元控制：本 episode 的交互额度与风险姿态
    k_e, lam_e = M.brc.allocate(M.budget, M.episodes_left)
    # 1) R69 世界侧不确定性
    U_ale, U_epi, modes = M.fluid.estimate(obs)
    # 2) 迁移侧不确定性：示范覆盖 + 偏移
    ans       = M.dat.query(obs, q=M.ask.plan(modes))
    ok, U_tr  = M.tcg.check(ans)
    # 3) 三通道证据：传感器 / 策略自洽 / 示范外锚
    d_score = M.dil(M.last_action, ans, M.metric)
    if stage == 'competition' and not M.evidence.agree(
            M.last_r_res, M.last_a_score, d_score):
        ok = False
    # 4) 能认证则用示范答案，否则共形鲁棒选择（不猜 MAP）
    if ok:
        mode = M.rsa.select(modes, ans.C)
        lam  = lam_floor(U_ale + M.fluid.residual_epi)
    else:
        mode = M.rsa.robust_select(modes, ans.C, lam_e)
        lam  = max(lam_floor(U_ale + U_epi + U_tr), lam_e)
    # 5) 安全执行（继承 R68/R69 认证）
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., M.wm_preds)
    # 6) 审计 + 证书
    M.audit.log(ans, U_tr, d_score, k_e, lam, stage)
    return k, lam, mode, (U_ale, U_epi, U_tr)

## 3. 推导

**假设 A99（示范覆盖）** 真实模态以概率质量 ≥ 1−β 落在 D 的 ε-支撑内，且标定/部署的密度比有界。
**假设 A100（偏移可检）** 标定与部署分布的密度比 e-value 有界或可估，使加权共形仍然有效。
**假设 A101（度量正则）** d_Φ 与策略密度对条件 Lipschitz（继承 A98）。
**假设 A102（DAgger 聚合充分）** π_ask 训练的状态分布覆盖部署可达状态，选择性干预偏差被聚合修正。

**引理 19（世界交互无法消解迁移不确定性）** 固定示范库 D，取任一仅作用于世界的信息动作 g。若老师模式身份 M_D 在给定世界观测 o 后与 g 条件独立（g 不携带关于「老师是谁」的信息），则 I(M_D ; y(g) | o) = 0。故 R69 的 VoI 对任何世界查询都给不出关于 U_tr 的增益；U_tr 只能由示范侧操作（检索/扩充）或人类回答消解。系：竞赛中把 R69 的交互预算投给世界查询，对 U_tr 是纯浪费；「问」必须被重定向到示范库，或被弃权替代。

**引理 20（覆盖的分布偏移衰减）** 在 A99–A100 下，对 D_cal 做分裂共形得 P(m* ∈ C_α) ≥ 1 − α − γ_shift，其中 γ_shift 可由 ||P_cal − P_test||_TV 或密度比 e-value 控制；若密度比 w 已知且有界，则加权共形恢复 ≥ 1−α。系：TCG 必须在线估计 γ_shift；当 γ_shift 吃掉 α 的余量时门关闭、U_cov 置满。**竞赛分布下没有免费覆盖。**

**引理 21（幻影模态的联合可检测性）** 设模态 m 示范不支持（d_score ≥ τ_d）但策略自洽（a_score ≤ τ_a）。在 A99 下，真正任务模态落在示范支撑外的概率 ≤ β，故 (a_score 低 ∧ d_score 高) 的联合判据把「新奇但真实」与「幻觉」分开，其误报率 ≤ β，检出功效由 DIL 的 FNR 给出。对比 R69：FMA 单通道无法区分这两者，因为它只问「我的策略惊不惊讶」，不问「老师支不支持」。**这正是对 R69 最大风险的正面修补。**

**引理 22（共形鲁棒选择的后悔界）** 若真模态 m* ∈ C_α 以概率 ≥ 1−α 成立，取 a* = argmin_a max_{m∈C_α} L(a,m)，则对任一批较器 a_ref：
Regret(a*) ≤ α·L_max + PoA(C_α)，其中 PoA(C_α) = min_a max_{m∈C_α} L(a,m) − min_a L(a,m*) 为「歧义代价」。当 ∩_{m∈C_α} 𝒮(m) ≠ ∅ 时 PoA = 0，鲁棒解 Pareto 安全。系：在模态冲突且代价不对称时，「取 MAP」的最坏后悔可达 α·L_max + Δ_min·L_lip；无人可问时，鲁棒选择在worst-case下严格优于 MAP。

**定理 18（COACH 严格包含 FLUID / R68）** 在 A99–A102 下：
- 若可信人类回答者在场且预算不受限：DAT 退化为人类、TCG 旁路、RSA 退化为「人类消解后的单一模态」，与 FLUID-RAS **逐指令相同**；
- 若无人可答且 U_tr 未消解：DAT 返回不可认证，RSA 在全集上取最坏情况，λ = λ_floor(U_ale + U_epi + U_tr) ≥ R69 的 λ，退化为 R68 纯保守；
- 竞赛模式且覆盖已认证时：期望风险 ≤「FLUID 被迫猜 MAP」的风险（引理 22），且安全侧不低于 R68。
故 R70 同时把 R69 与 R68 收为边界情形，安全侧不做任何让步。

**定理 19（预算-破产分离）** 设全局预算 B、任务数 N、单 episode 得分 S_e。存在任务序列使 R69 的逐步贪心 VoI 在早期歧义 episode 上耗尽预算，导致后续高价值 episode 无预算可交互，贪心与最优的差距可接近全部价值差。BRC 的 DP 值 ≥ 贪心值，且在机会约束 P(ΣS_e < S_floor) ≤ ρ 下仍可行。**R69 的 MINT 恰是 BRC 在 B=∞、N=1 时的边界**——竞赛把「无限预算 + 单步」这个假设同时拿掉了，所以元控制不是装饰。

**定理 20（交接安全与单调退化）** 若 J_COACH 有效，则无人竞赛模式的失败率 ≤ 有人模式 + ε_h（HCOPE），破产概率 ≤ ρ；若任一组件失效（覆盖 / 偏移 / 示范质量 / HCOPE），部署协议只能向更保守阶段单调退化，且重新认证前不得回跳。控制连续、无突变继承 R68 定理 15 与 R69 定理 17。**交接是带证书的状态迁移，不是信仰之跃。**

## 6. 本轮最大风险

**次级风险与缓解**：
1. **示范库本身有偏/被投毒** → DQA 影响函数 + 来源审计 + ℰ_demo 对抗训练；高影响样本降权；
2. **竞赛偏移使共形保证失效** → TCG 在线 e-value + 门关即弃权，绝不把「覆盖衰减」当成「已解决」；
3. **HCOPE 下界依赖示范分布** → 用多源 rollout + 保守基线（SPIBB 式）做安全策略改进，证书不可信则退回影子模式；
4. **π_ask 的选择性偏置** → DAgger 状态聚合 + 覆盖约束（只问 DAT 能认证的问题）；
5. **预算元控制过于保守导致分数低** → E306/E307 给出 Pareto 前沿，ρ 作为可调安全档位，但不为零。

**一句话（本轮最大风险）**：COACH-RAS 的全部「手把手教」收益押在「示范库覆盖且可交换」这一前提上，而竞赛分布恰恰是为违反它而设计的——当 held-out 任务落在示范支撑之外、或示范被投毒/来自异构本体时，共形覆盖失效，系统仍可能以「已认证」的姿态把示范库给出的、自信但错误的答案当作已消解；于是 R69 的「问错比不问更危险」升级为「**把老师教错的东西当成自己验证过的真理——错误的示教，比没有示教更危险**」。

**定义 310（总览与四不变式）** 零学习写操作继承；无 oracle 诚实性（无可信回答者时回答不得计为消解）；覆盖纪律（共形 + 偏移通过才可消解 U_tr）；预算-破产约束（P(ruin) ≤ ρ）。

**定义 320–321（BRC 与竞赛成本）** 预算-破产机会约束下的 episode 级分配；信息动作成本含时间/试次/机会影子价格，弃权有分成本但安全恒不劣。**R69 MINT = BRC 在 B=∞、N=1 的边界。**

**定义 322–325（HOC / 三通道 / 证书 / 协议）** HCOPE 下界 + 覆盖 + 破产 + J_FLUID；竞赛模式至少两源一致；J_COACH 汇总；四阶段部署且失效只能单调退化。**没证书不上场。**

    for _ in range(iters):
        roll = policy.rollout(); D_ask += roll         # 机器人自身状态分布
        human_intervene(roll, D_ask)                   # 只在需要处标注
    return fit_interaction_policy(D_ask)

# IP-271 BRC：预算-破产元控制（离线 DP，在线 O(1)）
def allocate(b, n, rho):
    # max E[Σ S_e] s.t. P(Σ S_e < S_floor) ≤ rho
    return dp_lookup(b, n, rho)                        # -> (k_e, λ_e)

# IP-272 HOC：交接证书（离线）
def handoff_certificate(pi_auto, pi_assist, D, rho):
    lb = hcope_lower_bound(pi_auto, D, delta=1e-3)
    return lb >= value(pi_assist) - EPS_H and coverage_ok() and ruin_ok(rho)

# IP-276 主闭环
def COACH_RAS_round(M, obs, stage):
    k_e, lam_e = M.brc.allocate(M.budget, M.episodes_left)
    U_ale, U_epi, modes = M.fluid.estimate(obs)
    ans      = M.dat.query(obs, q=M.ask.plan(modes))
    ok, U_tr = M.tcg.check(ans)
    d_score  = M.dil(M.last_action, ans, M.metric)
    if stage == 'competition' and not M.evidence.agree(
            M.last_r_res, M.last_a_score, d_score):
        ok = False
    if ok:
        mode = M.rsa.select(modes, ans.C)
        lam  = lam_floor(U_ale + M.fluid.residual_epi)
    else:
        mode = M.rsa.robust_select(modes, ans.C, lam_e)
        lam  = max(lam_floor(U_ale + U_epi + U_tr), lam_e)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., M.wm_preds)
    M.audit.log(ans, U_tr, d_score, k_e, lam, stage)
    return k, lam, mode, (U_ale, U_epi, U_tr)
```

## 4. 推导

**假设 A99–A102** 示范覆盖真实模态（质量 ≥ 1−β）且密度比有界；标定–部署偏移可由 e-value 控制；度量与策略密度 Lipschitz（继承 A98）；DAgger 聚合使 π_ask 训练分布覆盖部署可达状态。

**引理 19（世界交互无法消解迁移不确定性）** 对仅作用于世界、且与「老师身份」条件独立的信息动作 g，有 `I(M_D; y(g) | o)=0`。故 R69 的 VoI 对 U_tr 增益为零；U_tr 只能由示范检索/扩充或人类回答消解。系：竞赛中把交互预算投给世界查询对 U_tr 是纯浪费。

**引理 20（覆盖的分布偏移衰减）** 分裂共形在偏移下有 `P(m*∈C_α) ≥ 1−α−γ_shift`；密度比有界时加权共形恢复 `≥1−α`。系：TCG 必须在线估计 γ_shift；余量被吃掉即关门、`U_cov=1`。**没有免费覆盖。**

**引理 21（幻影模态联合可检测性）** 若某模态示范不支持（`d_score↑`）但策略自洽（`a_score↓`），在 A99 下其为真模态的概率 ≤ β，联合判据误报率 ≤ β、功效由 DIL 的 FNR 决定。对比 FMA 单通道只问「策略惊不惊讶」，不问「老师支不支持」——这是对 R69 最大风险的正面修补。

**引理 22（共形鲁棒选择的后悔界）** 若 `m*∈C_α` 以概率 ≥1−α 成立，则鲁棒选择的 `Regret ≤ α·L_max + PoA(C_α)`；当各模态安全集交集非空时 PoA=0、Pareto 安全。系：模态冲突且代价不对称时，鲁棒选择在最坏情况下严格优于 MAP。

**定理 18（COACH 严格包含 FLUID / R68）** 有人可信且预算不受限 ⇒ 与 FLUID-RAS 逐指令相同；无人且 U_tr 未消解 ⇒ `λ=λ_floor(U_ale+U_epi+U_tr) ≥ R69`，退化为 R68 保守；竞赛且覆盖认证 ⇒ 期望风险 ≤「FLUID 被迫猜 MAP」且安全侧不低于 R68。安全不让步。

**定理 19（预算-破产分离）** 存在任务序列使 R69 逐步贪心 VoI 在早期歧义 episode 耗尽预算，后续高价值任务无预算，差距可接近全部价值差；BRC 的 DP 值 ≥ 贪心值且满足 `P(ΣS<S_floor) ≤ ρ`。**R69 MINT = BRC 的 B=∞、N=1 边界**。

**定理 20（交接安全与单调退化）** 若 J_COACH 有效，则无人竞赛失败率 ≤ 有人模式 + ε_h、破产概率 ≤ ρ；任一组件失效只能向更保守阶段单调退化，重新认证前不得回跳。控制连续、无突变继承 R68 定理 15 / R69 定理 17。**交接是带证书的状态迁移，不是信仰之跃。**

## 7. 本轮最大风险

**次级风险与缓解**：示范库有偏/投毒 → DQA 影响函数 + 来源审计 + ℰ_demo 对抗训练；竞赛偏移使共形失效 → TCG 在线 e-value + 门关即弃权；HCOPE 依赖示范分布 → 多源 rollout + 保守安全策略改进，证书不可信退影子模式；π_ask 选择性偏置 → DAgger 聚合 + 覆盖约束；元控制过保守 → E306/E307 给 Pareto 前沿，ρ 可调但不为零。

**一句话（本轮最大风险）**：COACH-RAS 的全部「手把手教」收益押在「示范库覆盖且可交换」这一前提上，而竞赛分布恰恰是为违反它而设计的——当 held-out 任务落在示范支撑之外、或示范被投毒/来自异构本体时，共形覆盖失效，系统仍可能以「已认证」的姿态把示范库给出的、自信但错误的答案当作已消解；于是 R69 的「问错比不问更危险」升级为「**把老师教错的东西当成自己验证过的真理——错误的示教，比没有示教更危险**」。
