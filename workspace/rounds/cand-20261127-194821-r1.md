## 1. 直觉与动机（两个灵感的碰撞）

**灵感 1（视觉定位 → 策略缺的不是更强的编码器，而是一个显式、度量正确的三维空间状态）**
直觉：端到端 VLA 把「物体在哪」和「手该怎么动」纠缠在同一组权重里，定位误差会直接变成不可恢复的动作误差；而 5 类泛化轴（位置、干扰物、背景、未见物品……）本质上都是**定位分布的偏移**——物体被挪动（度量定位）、换外观（外观定位）、换背景（特征匹配退化）、加干扰（歧义）。人类操作是「先看清东西在哪，再闭环动手」。平台恰好把定位所需的一切摆在我们面前：已校正双目（度量深度）、base 系已知 EE 位姿（自运动已知）、腕部相机（近距 + 刚性随动）、已知夹爪开度、已知 base 坐标系。核心反直觉点：**不要让 VLA 去学定位，而要把一个已定位的世界交给它**；把「零样本泛化」拆成「鲁棒定位 + 鲁棒控制」两个可分别验证的问题。

**灵感 2（UniBot-V1 → 固定且已知的平台既是约束也是礼物）**
直觉：G1 Dex1、固定相机、绝对 EE 位姿控制、单模型、无触觉、步骤分——这些约束把问题从「通用 SLAM / 通用抓取」缩小成「桌面尺度、已知运动学、已知相机的定位」，这是一个**良态得多**的问题。三个直接推论：(a) 步骤分制且失败保留已得分（F17/F22 沿用）→ 定位必须**跨整个 episode 持久**（物体被拿起后还要记得它在哪、要放到哪），并在里程碑处可核验；(b) 无触觉 → 腕部相机刚性随动给出一个**免费的视觉滑移传感器**：抓住后物体在腕部画面里应近似静止，滑移即相对运动；(c) 官方基线只用 3/4 路图像（F23）→ **右目是平台白送、基线没用的度量深度**。反直觉点：**这场比赛的「视觉定位」不是再加一个大模型，而是把已经被采集、却被浪费的几何信息接回策略。**

**两者统一（本轮核心）**：第 2 轮结论是「中期胜负手在数据引擎」；但那个数据引擎只有像素与动作，**没有度量三维标签**。视觉定位补上的正是这个坐标系：
- 训练侧：给 32k 示教自动打上「物体位姿 / 抓取点 / 滑移事件 / 接触区间」标签 → 辅助监督 + 质量加权 + 几何一致增广；
- 推理侧：reset 期建一次场景度量状态，事件触发地更新（不是每步跑大模型），给动作头提供「相对抓取变换」先验，并驱动一个视觉滑移/接触监视器。

一句话：**数据引擎需要坐标系，平台自带双目与已知末端位姿，视觉定位就是把二者接起来的那根线。**

## 2. 对第 2 轮的增量修订

- **P2 拆分**：外观定位（未见物品/背景，靠 I9 几何检索 + 开放词汇分割）与度量定位（位置/放置精度，靠 I10 双目度量）是两类问题，此前混为一谈。

- **新增 P11–P14**：
  - **P11 标定缺口**：无公开内参/外参/基线（F27），立体尺度与手眼误差线性传播到放置。

  - **P14 外观偏移下的定位脆性**：未见物品轴正是外观式位姿估计失效处；几何（双目深度/尺寸）更不变，但分割更难。

## 3. 研究问题（本轮立项 Q9–Q12）

- **Q9（度量定位的最小充分状态）**：给 VLA 的最小三维状态应是「物体 6D 位姿」还是「抓取点 + 接近轴 + 间隙」？精度容差如何由成功示教的相对位姿方差反推？哪一轴的分数对定位误差最敏感？
- **Q10（定位的接入方式）**：度量 3D 以 (a) 训练期辅助损失、(b) 显式输入 token、(c) 推理期伺服 三种方式接入，哪种在单模型边界内收益最大、代价最小？
- **Q11（视觉滑移/接触）**：腕部相对运动 + 已知夹爪几何能否在无触觉下可靠检测滑移/接触？刚性假设在哪些任务族失效（毛巾/袋/拉链）？假阳性代价如何按 PR6 校准？
- **Q12（自标定）**：无公开标定下，能否用「机器人看自己夹爪」+ 运动 AX=XB 自标定头外参/手眼/双目基线？误差多大仍可接受？

## 4. 设计原则（新增 PR6，其余保留）

## 1. I10 双目度量物体定位层（SMOG, Stereo-Metric Object Grounding）★★★★★

- **动机**：5 类泛化轴本质是定位分布偏移（P2 拆分）；动作是 base 系绝对 EE 位姿（F21），只要把物体也定位到 base 系，抓取/放置就变成几何题。平台提供已校正双目（F22）与已知 EE 位姿（F20），但官方基线只用 3/4 路图像（F23），右目被浪费。SMOG 把这些几何信息接回策略。
- **与现有方案差异**：现有端到端 VLA 隐式定位，定位误差与动作误差纠缠；I3 只用 2D 关键点、I9 只用外观检索。SMOG 提供**度量三维、base 系、带不确定性**的物体/抓取状态，是 I3/I9/I2 的共同底座。核心差异：**不追求完整 6D 位姿，而追求「抓取点 + 接近轴 + 间隙」这一最小充分 affordance 状态**，从而绕开无 CAD 新物体的位姿估计难题（P14）。
- **关键设计：事件触发定位 + 连续跟踪**（部署预算的关键）。不在每步跑大模型：reset 首帧、pre-grasp、post-grasp、pre-place、VSCM 异常时才跑完整 SMOG；其余步用光流/UKF 跟踪物体在 base 系的位姿。由于动作分块（chunk 16–30），`get_action` 每次调用有约 0.5–1s 预算，完整定位可摊销，单步控制回路仍保持 <66ms（F12 参照）。
- **三闸**：
  - *计分轴对齐*：位置轴（度量）、未见物品轴（几何比外观稳）、背景/干扰轴（分割+几何）、放置精度（直接命中步骤分）。
  - *单模型边界*：合规阶梯——L0 仅训练期辅助标签（完全合规）；L1 作为确定性观测预处理（类比 image_resize，需确认）；L2 推理期伺服/决策（需书面确认）。确认前只上 L0/L1，L2 用 I10' 降级（纯辅助监督，推理端到端）。
  - *部署预算*：双目深度 240×320 + SGBM/RAFT-Stereo，事件触发；跟踪 <2ms；检测/分割只在事件帧。均摊 <15ms/步，chunk 内可摊销。
- **技术可行性**：中-高。已校正双目→深度是成熟技术；开放词汇检测/分割成熟；难点是自标定（§4.3）与遮挡下抓取点估计。自标定可用「机器人看自己夹爪」闭环验证。
- **所需资源**：标定 1 GPU 日；32k 示教打标签 2–3 GPU 日；1 人周工程（深度/分割/跟踪）+ 1 人周标定。
- **落地步骤**：①自标定 CB（头外参/手眼/双目尺度）；②在留出帧验证重投影 <1px、EE 重建 <5mm；③affordance 状态估计（抓取点/接近轴/间隙）；④事件触发 + 跟踪；⑤训练期辅助标签接入 I2；⑥L0 容差分析；⑦单任务通道 L2。
- **风险**：自标定误差传播（缓解：容差反推 + 每 episode 用已知 EE 位姿核验）；未见物体分割失败（缓解：语言提示 + 深度聚类 + 几何先验，失败则退回 I9 外观检索）；遮挡下抓取点偏差（缓解：腕部近距 + 多帧融合 + 不确定性门控）。

## 2. I11 腕部参照视觉滑移/接触监视器（VSCM, Wrist-Referenced Visual Slip/Contact Monitor）★★★★★

- **动机**：无触觉/力觉（F20），而搬运段滑移是步骤分主要漏点（P4）。腕部相机刚性随动于夹爪：**抓住后物体在腕部画面里应近似静止**，滑移即相对运动——这是一个零训练、零额外传感器的伪触觉。
- **与现有方案差异**：I3 用几何伺服处理接触，但仍无「是否抓稳」的在线判据；I4 只识别人手干预。VSCM 直接给出 GRASPED/SLIP/APPROACH 三态，驱动 HOLD 与 I5 的恢复触发。它不新增动作策略，只做状态监视（与 I4 同构，合规风险低）。
- **三闸**：
  - *计分轴对齐*：搬运/放置段的滑移恢复直接保步骤分与成功率。
  - *单模型边界*：纯监视器，只在异常时发 HOLD/触发恢复，不改变动作分布；若被禁止，降级为训练期滑移标签（喂 I5）。
  - *部署预算*：腕部 ROI 光流 160×120，<5ms；训练免费。
- **技术可行性**：高（刚性物体族）；中（可变形族）。
- **所需资源**：1 人周工程；无需训练（阈值按 PR6 校准）。
- **落地步骤**：①腕部物体/接触 ROI 分割或跟踪；②相对流 + 夹爪闭合 + 头视共动三信号融合；③状态机与迟滞；④按任务族标定阈值；⑤接入 I4/I5；⑥L0 ROC + 真机抽测。
- **风险**：可变形物体（毛巾/袋/拉链）违反刚性假设 → 假滑移；缓解：ROI 限制在夹爪邻域、per-task 阈值、可变形族关闭 VSCM 退回头视共动；运动模糊导致假流 → 归一化 + 中值滤波 + 连续 m 帧确认。

## 3. 被深化点的接口变化

### 3.1 I1 v3：几何一致增广（GCA）
位置轴不再盲目 2D 重拼接：用双目深度 + 桌面平面（RANSAC）把物体放到**物理可行**的新 3D 位置（贴桌面、工作空间内、无碰撞、IK 可解），按正确透视/遮挡序重渲染，校验原示教动作仍可行。**通过判据：物理可行率 >95%**，否则该样本丢弃。这直接消解 v1.1 的「不可行动作 >5% 即降级」风险。

### 3.2 I2 v3：数据引擎加度量标签
在 110 语料 + 32 任务示教上自动生成：物体/抓取点位姿、抓取闭合帧、滑移事件、接触区间。用途：①质量分加「抓取稳定性」（低滑移加权）；②辅助监督（§4.7 的相对位姿损失）；③为 I5 挖掘「偏离→修正」段提供事件边界。

### 3.3 I3 v3：3D 度量伺服
接触段目标位姿 = 物体抓取位姿 + 接近轴偏置（SMOG 提供），替代 2D 关键点；2D 关键点仅作 SMOG 低置信回退。控制仍是 base 系 EE 位姿，天然对齐（F21/F24）。

### 3.4 I4：接入 VSCM
人手干预状态机增加 GRASPED/SLIP 子态：SLIP 触发短 chunk + 重估；与 I4 的 INTERFERED 态互斥优先级为 INTERFERED > SLIP > NORMAL。

### 3.5 I5 v3：滑移事件驱动恢复段挖掘
VSCM 的 SLIP 边界 + SMOG 的物体位姿，自动切出「滑移前→滑移→重新抓稳」段，作为恢复示教；只有达成下一得分点的段保留（沿用 v2 门禁）。

### 3.6 I6 v3：调度
新增「定位任务队列」：完整 SMOG 与分割作为低优先级任务在 chunk 间隙执行；结果带时间戳缓存；过期结果降级为跟踪。PR4 门禁增加「定位不可用时的端到端回退」测试。

### 3.7 I7：进一步降级
SMOG 已能给几何短时预测（物体位姿 + 已知夹爪运动），世界模型的测试时前瞻边际价值下降；维持缓，若第 4 轮延迟余量不足即裁撤，资产转 I5 数据引擎。

### 3.8 I8 v3：定位误差轴
L0 增加「注入标定/深度噪声 → 离线放置误差」曲线；注册表增加「离线定位误差 vs 真机放置误差」「VSCM AUC vs 真机恢复增益」两列，相关性 >0.6 才可单独准入 L2。

### 3.9 I9 v2：几何检索键
检索键 = 外观嵌入 ⊕ 度量尺寸 (w,h,d) ⊕ 宽高比 ⊕ 相对夹爪布局 ⊕ affordance 类型；检索目标从「同物体」改为「同 affordance/抓取几何」。腕部近距图提供细粒度外观。缓解 v1.1「VLM 嵌入对同类新外观不敏感」。

## 4. 严格定义

### 4.1 场景度量状态
设 base 系 B（x 前、y 左、z 上，F24）。t 时刻场景状态
\[
z_t=\Big(\{T^B_{O_i,t}\}_{i=1}^{M},\ \Gamma_t,\ \Sigma_t\Big),\quad
\Gamma_t=\{\text{grasp}(i),\text{contact}(i),\text{contain}(i,j)\},
\]
其中 \(T^B_{O_i}\in SE(3)\) 为物体位姿，\(\Sigma_t\) 为其不确定性。双夹爪位姿 \(T^B_{G_L,t},T^B_{G_R,t}\) **由观测直接给出**（F20），不估计。

### 4.2 定位算子与误差传播
\[
\Lambda_\theta:(I^L_t,I^R_t,I^{WL}_t,I^{WR}_t,q_t,\ell)\mapsto(\hat z_t,\hat\Sigma_t),
\]
分解：
1. 已校正双目视差 \(d\) → 深度 \(Z=fb/d\)；
2. 反投影到头相机系 \(p^H=K^{-1}[u,v,1]^\top Z\)；
3. 变到 base 系 \(p^B=T^B_H\,p^H\)（\(T^B_H\) 由 §4.3 自标定）；
4. 腕部像素经手眼 \(T^B_W=T^B_G\,T^G_W\) 提升（单目无尺度，仅用于近距分割/滑移）；
5. 语言提示开放词汇分割得 \(M_i\)，点云 \(P_i=\{p^B\}\)，估计 affordance
\[
a_i=(g_i,\ n_i,\ c_i)=(\text{抓取点},\ \text{接近轴},\ \text{间隙}).
\]
只有已知 CAD 时才估完整 \(T^B_{O_i}\)；否则只保留 \(a_i\)（最小充分状态，Q9）。
误差传播（一阶）：
\[
\delta Z\approx\frac{Z^2}{fb}\,\delta d,\qquad
\delta x\approx\frac{Z}{f}\,\delta u+Z\,\delta\theta_{\text{calib}}.
\]
在 \(Z\approx0.6\text{m}\)、\(\delta\theta=1^\circ\) 时位置误差约 10mm——**标定是一阶项**，故 PR6 要求先标定再谈度量。

### 4.3 自标定（CB, Calibration Bootstrap）
回应 F27（无公开标定）：
- **头外参 \(T^B_H\)**：夹爪在头视图中可见，其 base 系位姿 \(T^B_G\) 已知（F20）；检测夹爪 2D 关键点 \(u\)，PnP 解 \(T^H_G\)，则
  \[
  T^B_H=T^B_G\,(T^H_G)^{-1}.
  \]
  多帧/多 episode 做鲁棒平均（RANSAC/中值）。
- **手眼 \(T^G_W\)**：经典 \(AX=XB\)，用 \(A=T^B_{G_1}(T^B_{G_2})^{-1}\)、\(B=T^{W_1}_{W_2}\)（腕部图像特征跟踪）解 X。
- **双目尺度 \(fb\)**：用已知夹爪的度量深度 \(Z_G=\|p^B_G-p^B_H\|\) 与其视差 \(d_G\)，得 \(fb=Z_G\,d_G\)，多帧聚合；或由桌面平面 + 相机高度反解。
- **验证门禁**：留出帧重投影误差 <1px、EE 重建误差 <5mm，否则不启用推理期度量（退回 I10'）。

### 4.4 视觉滑移信号（VSCM）
设腕部物体/接触 ROI 为 \(\Phi_t\)，相对光流
\[
r_t=\frac{1}{|\Phi_t|}\sum_{x\in\Phi_t}\|\mathrm{flow}_t(x)\|.
\]
夹爪闭合 \(g_t<g_{\text{close}}\) 且 \(r_t\) 低 → GRASPED；闭合且 \(r_t\) 高且夹爪在动 → SLIP：
\[
s_t=\frac{r_t}{\|\bar v_G\|+\epsilon},\qquad
\text{SLIP}\iff s_t>\tau_s\ \text{连续 }m\text{ 帧}.
\]
头视共动辅助：\(h_t=\|\bar v_{\text{obj}}-\bar v_{\text{grip}}\|\)，\(h_t\) 大而夹爪在动 = 抓空/未抬起。可变形族关闭 \(r_t\) 判据，仅用 \(h_t\) + 夹爪指令一致性。

### 4.5 几何一致增广（GCA）
物体掩码 + 深度 → 点云；RANSAC 拟合支撑平面 \(\Pi\)；新位姿 \(T'^B_O\) 从考纲卡采样，约束：
\[
T'^B_O\in\mathcal W\ (\text{可达}),\quad z_{\min}(P'_O)\approx\Pi,\quad
\mathrm{Collide}(P'_O,\text{scene})=\varnothing,\quad \mathrm{IK}(T'^B_O)\ \text{可解}.
\]
任一不满足即丢弃。重渲染按新深度排序 + 接触阴影。

### 4.6 几何检索键（I9 v2）
\[
k=\big[e_{\text{app}};\ (w,h,d);\ (w/h,h/d);\ \text{layout}_{rel};\ \text{affordance class}\big],
\]
检索目标为 affordance 类 + 抓取几何，而非物体身份。

### 4.7 相对位姿辅助损失（I2 v3）
\[
\mathcal L=\mathcal L_{\text{flow}}
+\lambda_1\big\|\hat T^G_O-T^G_O\big\|_{\mathrm{SE3}}
+\lambda_2\,\mathrm{CE}(\hat a,a)
+\lambda_3\,\mathcal L_{\text{slip}},
\]
其中 \(T^G_O=(T^B_G)^{-1}T^B_O\) 是**物体相对夹爪**的位姿——帧一致、避免 base 漂移，且正是抓取所需量。辅助头仅训练期使用（I10' 合规形态）。

## 5. 关键伪代码

### 5.1 SMOG（事件触发定位）
```python
class SMOG:
    def __init__(self, calib):          # calib: K, T_B_H, fb, T_G_W[arm]
        self.calib = calib
    def reset(self, obs):               # reset 每 episode 一次（F18）
        self.scene = self.localize(obs)
        self.tracker = ObjectTracker(self.scene)
    def update(self, obs, event=None):
        if event in {"pre_grasp","post_grasp","pre_place","anomaly"}:
            self.scene = self.localize(obs)        # heavy, per-event
        else:
            self.scene = self.tracker.step(obs)    # cheap flow/UKF
        return self.scene
    def localize(self, obs):
        D   = stereo_depth(obs["observation.images.cam_left_high"],
                           obs["observation.images.cam_right_high"],
                           self.calib.K, self.calib.fb)
        pts = backproject_base(D, self.calib.K, self.calib.T_B_H)
        masks = open_vocab_segment(obs, obs["observation.language"])
        objs  = [estimate_affordance(pts[m]) for m in masks]  # g, n, c
        return SceneState(objs, gripper=ee_pose(obs),
                          unc=propagate(D, self.calib))
```

### 5.2 VSCM
```python
def vscm_step(wrist_prev, wrist_now, grip, ee_vel, roi):
    r = mean_flow(wrist_prev, wrist_now, roi)     # object motion in wrist frame
    closed = grip < GRIP_CLOSE
    if closed and r < TAU_STATIC:
        return "GRASPED"
    if closed and r / (norm(ee_vel) + EPS) > TAU_S:
        return "SLIP"
    return "APPROACH"
```

### 5.3 自标定 CB
```python
def calibrate_head(episodes):
    samples = []
    for ep in episodes:
        for t in range(len(ep)):
            u = detect_gripper_2d(ep.head_left[t])
            if u is None: continue
            T_H_G = solve_pnp(u, GRIPPER_KEYPOINTS_3D)
            samples.append(ep.T_B_G[t] @ inv(T_H_G))
    return robust_avg(samples)                    # -> T_B_H

def calibrate_handeye(episodes):
    pairs = []
    for ep in episodes:
        for a, b in consecutive(ep):
            A = ep.T_B_G[a] @ inv(ep.T_B_G[b])
            B = track_wrist_motion(ep.wrist_left[a], ep.wrist_left[b])
            pairs.append((A, B))
    return solve_AX_eq_XB(pairs)                  # -> T_G_W
```
