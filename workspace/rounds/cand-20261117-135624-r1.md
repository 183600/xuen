# 第 12 轮（新灵感循环第 1 轮；本轮灵感：「双足机器人」×「遥操作」）

> **基线**：第 11 轮 MetricVoiceGauge-NCD-H（定义 554–561；引理 96–103；实验 E589–E606）。
> 本轮纪律：**多接触平衡证书 + 权威租约 + 人类证据去污染**。不推倒 v11：NGE/DSL/CC/HCC/CWM/CAE/NCP/HAS/HATD/HDT 与九不变式全部保留；新组件以四个**互不重叠、带依赖偏序的端口**接入，失效即注入中立元，严格退回 v11（引理 110），再沿 v11 十三级链退回 v10/v9/v8/v7/v6。本轮只做三件事：让"站不稳"成为一等安全约束，让"谁在控制"成为可撤销的证书，让"人类遥操作"成为不被安全过滤器污染的证据。

## 0. 直觉与动机

**灵感 1（双足机器人 → 多接触平衡证书与安全迈步中止）**
直觉：v11 的接触证书默认机器人是固定基座：手接触的世界反力由底座默默吸收，平衡从来不是约束。双足把这条假设连根拔掉——每一次抓取、推拉、拧转都会经手-臂-躯干传到脚底；脚底接触不是"背景"，而是与手接触同等的、会滑动、会失去的多接触资源。更致命的是 v11 的中止语义：遇到危险就"纯阻尼保持"（K_p=0, K_d=K_d_diss）。在双足上，**mid-step 的保持可能根本不可行**：单支撑相中冻结关节等于把 ZMP 推出支撑多边形，安全中止反而导致跌倒。核心创新：**全身多接触平衡证书（Whole-Body Certificate, WBC）** 把脚底支撑多边形、ZMP/CoM/捕获点裕度、摩擦锥、手接触力旋量、以及 v11 的谐波柔顺度统一成一张随时间演化的证书；**安全迈步原语（Safe-Stepping Primitive, SSP）** 把中止从"一个点"升级为"一个带接触时序的策略"：hold → step → brace → sit 的有界恢复阶梯。谐波在这里不是外挂：腿关节的柔轮偏转直接改变 CoM 跟踪，**柔顺度既会毁掉接触，也会毁掉平衡**。

**灵感 2（遥操作 → 权威租约与延迟感知的共享自治）**
直觉：v11 的"问人"（a_ask）是离散的、低带宽的、被当作规范证据。遥操作把这条通道变成连续的、延迟的、会丢包的、且人类会犯错的高带宽控制回路。真正的矛盾不是"人类与机器人谁更聪明"，而是**命令的时间有效性**：一个在 t−d 时刻完美的人类命令，在 t 时刻可能已经因为状态漂移、负载变化、脚下打滑而变成危险命令；而一个永远不会过期的"人类权威"是安全事故的温床。核心创新：**权威租约（Authority Lease）**——任何命令，无论来自自主策略还是远端人类，都必须携带一张带时间戳、有效期、作用域、证书与 nonce 的租约；**过期即无权**。**延迟感知共享自治监督器（LAS）** 把人类命令投影到"当前时刻的证书安全管"内：不是拒绝人类，而是在最小干预意义下把人类意图"拉回"可行域；并显式定义**人类权威保持**（authority preservation）指标，避免"安全但把人类架空"。

**灵感 3（二者交汇 → 人类证据去污染与遥操作-双足孪生）**
直觉：遥操作不仅是控制通道，也是**最宝贵的人类证据源**——人类在接触丰富场景中的修正、让路、抓取策略，能教会机器人规范、接触模式和谐波参数。但这里有一个阴险的回路：安全过滤器会拦截/修改人类命令；如果 NGE 把"被过滤器修改后的命令"当成人类意图去学习，它学到的不是人类规范，而是**自己的安全策略**，于是越来越不信任人类，拦截越来越多，形成"自证式的权威剥夺"。核心创新：**人类证据消歧器（HED）** 把每条人类输入标注为"已执行/被拦截/被投影/延迟超界"，用删失感知（censoring-aware）的似然更新规范信念，并把"安全干预"作为混杂因子显式校正；**权威转移账本（ATL）** 记录每一次权威交接，既用于审计也用于反事实评估。**遥操作-双足数字孪生（TBDT）** 在 v11 HDT 上增加操作者模型（延迟分布、反应时间、技能水平、干预策略）与双足接触动力学，对"人-机-地"三者同时域随机化，训练 LAS 与 SSP 的鲁棒策略。

**三者如何统一**
把决策写成**带租约的证书化多接触控制**：WBC 回答"这组手-脚接触在下一段时间内是否物理可行"；TCL/LAS 回答"这条人类命令在当前时刻还配不配拥有控制权、若配，应该被投影多少"；HED/ATL 回答"这次人类干预/修正能否、以及如何进入规范与因果学习"；TBDT 回答"延迟与双足接触漂移下，这些证书为什么仍然可信"。四者共享一个对象——**证书携带命令（certificate-carrying command）** c = (u, τ_issue, lease, cert, evidence_tag)。**双足回答"站得住吗"，遥操作回答"谁说了算、算多久"，证据层回答"从人身上学到的到底是不是人"**。这不是三个补丁，而是把 v11 的"执行器-分解-仿真"闭环扩展为**"平衡-权威-证据-孪生"**闭环。

## 1. 研究问题（轮次升级版）

- **Q1（多接触平衡证书的可组合性与保守性）**：如何把脚底支撑、ZMP/捕获点、手接触旋量、腿关节谐波柔顺度组合成一张可在线检查、可优化、可解释的证书，且不因多重合取而清空可行集？证书的保守性下界能否用"与真实可行域的 Hausdorff 距离"或"可行段非空率"来量化？
- **Q2（延迟下的权威分配最优性）**：给定延迟 d、抖动 j、丢包 ℓ、证书有效视界 h_cert，人类权威 α 的最大安全值 α_max(d, j, ℓ) 是多少？如何在保证安全的前提下最小化干预、最大化人类权威保持？是否存在可计算的"延迟-权威前沿"（latency-authority frontier）？
- **Q3（人类证据的可辨识性与去污染）**：当人类命令被安全过滤器删失/投影时，从遥操作数据中估计规范参数、接触策略参数、谐波参数的可辨识条件是什么？偏差有多大？如何用逆概率加权/删失似然/影子模式得到一致估计？
- **Q4（兼容性与退化）**：新增四端口如何严格退回 v11？WBC/SSP 与 v11 的 P^h、Ĉ_h、HATD 如何合取而不产生"证书死锁"？权威租约过期/被撤销时，如何保证系统仍有可执行的兜底而不是冻结？

## 2. 设计原则（在 P16–P18 基础上新增 P19–P21）

**P19 权威租约律（Authority is a Leased Certificate）**
任何执行命令必须携带有效租约 L=(α, scope, τ_issue, τ_exp, cert, nonce)；τ_exp ≤ τ_issue + h_cert − d_max。租约过期、证书失效、nonce 被撤销、或作用域不匹配 ⇒ 该命令无权威，系统必须执行证书化的兜底（hold/step/brace/sit），而不是"最后一条命令"。人类权威不是默认值，而是**需要持续续租的资源**。

**P20 多接触平衡一等公民律（Multi-Contact Balance First-Class）**
任何技能必须携带接触时序 σ_C 与平衡证书 Ĉ_wb；前后置条件包含支撑多边形、ZMP/捕获点裕度、脚底摩擦、腿关节谐波偏转。中止不再是一个配置点，而是一个**带接触时序的恢复策略**；"纯阻尼保持"只是 SSP 的一个退化分支，且在单支撑相中默认不可用。

**P21 人类证据非污染律（Intervention-Censored Human Evidence）**
人类输入只有在携带"执行/拦截/投影/延迟"元数据时才可进入规范/因果/谐波学习；安全过滤器的输出不得被当作人类意图的干净样本。学习更新必须使用删失感知或逆概率加权；当干预率过高时，系统应主动进入影子模式或 a_ask，而不是继续"自学自己的安全策略"。

## 3. 与基线的接口（如何退化）

- **双足端口（WBC/SSP）失效** ⇒ 注入固定基座中立元：S(C)≡全平面、ρ_bal≡+∞、σ_C≡双手接触、P^wb≡v11 的 P^h、SSP 退化为 v11 的纯阻尼保持；**等价 v11**。注意：双足端口是遥操作端口的物理前提，失效时遥操作降级为 v11 的 a_ask/人类反馈通道。
- **遥操作端口（TCL/LAS/ATL）失效** ⇒ 人类命令通道关闭，退回 v11 的离散 a_ask 与规范反馈；**等价 v11**。
- **证据端口（HED）失效** ⇒ 人类输入只作为命令、不作为规范/因果证据；NGE 只用机器人自身反馈更新；**等价 v11**。
- **孪生端口（TBDT/AHD）失效** ⇒ 退回 v11 HDT/HATD 的固定基座、无操作者模型版本；**等价 v11 推理/规划路径**。
- **依赖偏序**：孪生端口独立；双足 ≺ 遥操作 ≺ 证据。任一端口失效，按偏序把其下游端口一并注入中立元，保证任意失效子集都落到 v11 的一个明确退化点，而不是"半双足半遥操作"的灰色状态。
- **安全继承**：物理/接触/谐波/平衡/租约/规范六重证书合取；新模块只能删候选、投影命令、重切分、改预测，不能绕过 v11 任何适用证书（引理 101 升级版 + 引理 110）。

## 4. 预期贡献

1. **全身多接触平衡证书与安全迈步中止**：把脚底支撑、ZMP/捕获点、手接触、腿关节谐波统一成一张可在线检查的证书，并把"中止"从点升级为带接触时序的策略，覆盖 v11 完全未建模的"站不稳"风险；
2. **权威租约与延迟感知共享自治**：把"谁在控制、控制多久、控制哪些自由度"变成可撤销、可审计、可证明安全的租约；给出延迟-权威前沿与最小干预投影，解决"远端人类命令过期即危险"的部署现实；
3. **人类证据去污染**：显式建模安全过滤器对人类证据的删失/混杂，用干预感知的更新避免"越安全越不信任人类"的自证偏差，把遥操作从"控制通道"升级为"可辨识的证据通道"；
4. **四端口统一的平衡-权威-证据-孪生闭环**：E607–E626 覆盖多接触证书、迈步中止、延迟鲁棒、权威保持、证据去污染、TBDT 保真、Sim-to-Real、消融与长跑。

## 5. 本轮最大风险

**一句话**：安全过滤器为了守住平衡/接触/谐波证书而不断拦截和投影人类命令，NGE 又把这些被过滤后的动作当成人类规范去学习，于是系统学到一个"人类也同意被拦截"的虚假规范，进一步收紧证书、增加拦截——形成"越安全越不信任人类、越不信任越安全"的**权威-证据自证偏差**，最终机器人安全地站在角落里，却再也学不会人类真正想让它做的事。

x_b = (q, q̇, C, σ_C, p_c, v_c, p_z, ξ, h)
```
其中 C=(C_L,C_R,C_H)，C_L,C_R∈{0,1} 表示脚接触，C_H 为承力手接触集；接触时序 σ_C 给出每段的接触集与起止时间。支撑区域 S(C)=Conv(⋃_{i∈C_foot} P_i)，P_i 为第 i 个接触多边形在地面投影；若手接触承力（扶墙、撑桌），其接触点并入凸包。S(C) 上的可行 CoP 还须满足各接触点的摩擦锥约束。

**定义 572（全身多接触平衡证书 WBC）**
```
Ĉ_wb = ( σ_C, h_cert, ρ_ZMP^min, ρ_cap^min, ρ_bal^min, μ_foot^min,
         W_hand^max, Ĉ_h^leg, Ĉ_contact^hand )
```
在 t 时刻有效 ⇔ 存在各接触旋量 w_c∈F_c（摩擦锥）使
```
Σ_c w_c = m(g + a_c),   Σ_c (p_c − p_z) × w_c = dL/dt
```
（力/矩平衡）且
```
p_z ∈ S(C)  ∧  dist(p_z,∂S(C)) ≥ ρ_ZMP^min
ξ ∈ S_step  ∧  dist(ξ,∂S_step) ≥ ρ_cap^min
μ_foot ≥ μ_foot^min,  W_hand ≤ W_hand^max
Ĉ_h^leg valid  ∧  Ĉ_contact^hand valid
σ_C 覆盖 [t, t+h_cert]，且段内切换数 ≤ N_switch
```
注意：这是"多接触 + 浮基 + 谐波"的合取，不是把 v11 接触证书简单加一项。腿关节的 θ_flex 直接进入 CoM 跟踪误差，故 Ĉ_h^leg 与 ZMP 裕度不可分离检查。

**定义 573（平衡裕度与捕获点可恢复性）** 捕获点 ξ=p_c+v_c/ω，ω=√(g/z_c)。定义
```
ρ_bal(x) = min( dist(p_z,∂S(C)), λ_cap·dist(ξ,∂S_step) )
R_ρ = { x : ∃π_abort, N_steps≤N_max, T≤h_abort,
       轨迹全程满足 Ĉ_wb 且终态∈S_stand, 全程 ρ_bal≥ρ }
```
R_ρ 是"可恢复核"，由中止策略族与接触时序共同定义——**改进 SSP 即扩张 R_ρ**，这与 v11"改进恢复策略即扩张可恢复域"同构，但这里恢复的物理手段是迈步与支撑重构，而非仅仅阻尼耗散。

**定义 574（全身安全中止核与安全迈步）** 中止策略族
```
Π_abort = {hold, step_L, step_R, brace, sit, protected_fall}
```
全身安全中止核
```
P^wb = { x : ∃π∈Π_abort, ∃T≤h_abort,
        轨迹全程满足 Ĉ_wb ∧ 终态∈S_stand∪S_protected }
```
关键区别：P^wb 不是点集，而是"存在一条带接触时序的中止轨迹"的状态集。当双足中立（固定基座）时 hold 可用且 P^wb=P^h；在单支撑相中 hold 可能把 ZMP 推出支撑多边形，此时必须 step 或 brace。**"安全中止"从"停住"变成"换一个支撑"。**

**定义 575（遥操作通道与证书携带命令）** 通道由延迟分布 D_d、抖动 D_j、丢包 D_ℓ、带宽 B 刻画。机器人于 t 收到包 c_t=(u_h,τ_issue,z_intent,conf,seq)，延迟 d=t−τ_issue。证书携带命令
```
c = ( u, τ_issue, L, Ĉ_cmd, e_tag )
```
其中 Ĉ_cmd 证明闭环轨迹在 [τ_issue, τ_issue+h_cmd] 内落在 Ĉ_wb 内；e_tag∈{issued,executed,projected,intercepted,expired}。**命令的有效性绑定时间，而不是绑定"最后一条"。**

**定义 576（权威租约 Authority Lease）**
```
L = ( α, scope, τ_issue, τ_exp, cert_id, nonce, issuer )
```
α∈[0,1] 为人类权威份额（或按 DOF 的向量），scope⊆DOF×任务×时间。L 在 t 有效 ⇔
```
τ_issue ≤ t ≤ τ_exp ∧ cert_id 在 t 有效 ∧ nonce 未被撤销
∧ scope 与当前上下文匹配 ∧ issuer 有授权
```
续租条件（TTL 约束）：
```
τ_exp ≤ τ_issue + h_cert − d_max
```
租约可被人类或安全层即时撤销。权威状态 A(t)=α(t)·human+(1−α(t))·autonomy，切换须带滞回与最小驻留时间，防止抖动。

**定义 577（延迟感知安全过滤器与命令时证书）** 在执行时刻 t（而非签发时刻），计算安全动作集
```
U_safe(x_t, Ĉ_wb, L) = { u : ∀w∈W, ∀τ∈[t,t+h_cmd],
    x(τ) = f(x_t,u,w,τ) ∈ Ĉ_wb  ∧  L 在 τ 有效 }
```
若 U_safe≠∅，执行
```
u_exec = argmin_{u∈U_safe} ‖u − u_h(τ_issue)‖_W
```
否则执行 SSP 的证书化中止。**这是"命令时证书"：它不假设人类命令签发时的状态仍然成立。**

**定义 578（共享自治策略与权威保持）** 共享自治策略 π_SA:(x,c)→(u_exec,α) 求解
```
max_{u_exec,α}  E[任务进度] − λ_I·InterventionCost(u_exec,u_h)
                − λ_A·D_α(α,1) − λ_C·CertificateSlack
s.t.  Ĉ_wb valid ∧ L valid ∧ u_exec∈U_safe
```
权威保持定义为 D_α=∫(1−α)dt 或"干预幅度/次数"的单调函数。延迟-权威前沿
```
A_front(d) = { α : ∃π_SA 在延迟 d 下安全且任务进度>0 }
```
A_front(d) 随 d 单调不增；当 d+τ_react ≥ h_cert 时 α=0（人类权威不可续租），系统完全自治并请求人类重新签发。

**定义 579（遥操作证书）**
```
Ĉ_tel = ( d̂, d_max, ĵ, ℓ̂, freshness, Ĉ_cmd, α, intervention_history, e_credit )
```
有效 ⇔ d_max+τ_react≤h_cert ∧ freshness≤δ_fresh ∧ Ĉ_cmd valid ∧ L valid ∧ α 在 A_front(d̂) 内。Ĉ_tel 与物理证书互补：物理证书说"动作可行"，遥操作证书说"这条人类命令还有资格被执行"。

**定义 580（人类证据模型与干预删失）** 人类命令
```
u_h(t) = π_h(s(t−d), z, n),  e = 1[命令被安全过滤器执行]
```
其中 z 为意图（任务/规范/接触/安全/风格），n 为噪声。机器人观测 (s,u_h,e,d) 但不观测 z,n。由于 e 是安全过滤器的函数，**e 与 z 相关**：被拦截的命令不是从 P(u_h|z) 的干净样本。定义倾向得分 p(e=1|s,z)，则正确似然是 P(u_h|z,e=1)，朴素似然 P(u_h|z) 有选择偏差。

**定义 581（去污染的人类证据更新）** 对规范/接触/谐波参数 θ，用逆概率加权
```
θ_{k+1} = θ_k + η · (e_k / p̂(e_k=1|s_k,z_k)) · ∇ log P(u_h,k | z_k, θ_k)
```
并做权重裁剪与预算限制。若 p̂<p_min，则该样本降权；若滑动窗口干预率 >γ，进入**影子模式**：机器人不执行人类命令、只记录"若执行会怎样"的反事实，得到无删失证据（但任务进度为零），或触发 a_ask。p̂ 由 ATL 的干预记录估计。

**定义 582（权威转移账本 ATL）** 只追加记录
```
ATL_record = ( t, command_id, lease_id, α, u_h, u_exec,
               verdict, cert_hash, e_tag, d, p̂ )
```
用哈希链保证防篡改；热路径只写环形缓冲，低频批量落 Merkle 根。ATL 同时服务于审计、透明度、倾向得分估计与反事实评估——**没有账本，就无法区分"人类想这么做"与"安全层允许人类这么做"。**

**定义 583（遥操作-双足数字孪生 TBDT）** TBDT=(M_biped,M_op,D_DR,Calibrator)：
- M_biped：在 v11 M_h 上增加浮基、接触动力学、ZMP/CoM/捕获点与脚底摩擦；
- M_op：操作者模型，含延迟 d∼D_d、抖动、丢包、反应时间 τ_react、命令噪声、技能水平与干预策略；
- D_DR：双足参数（质量分布、摩擦、接触刚度、谐波参数）与操作者参数（d∈[0,300]ms、丢包 0–20%、技能分位）的联合随机化；
- Calibrator：用实机遥操作轨迹更新 M_biped 与 M_op 的后验，供 LAS/AHD 采样。

**定义 584（权威感知任务分解 AHD）** AHD 在 HATD 上为每段附加权威模式
```
seg = ( π_h^α^{1:K}, m_seg∈{auto,shared,teleop}, Ĉ_wb, Ĉ_h, Ĉ_contact,
        L_handoff, P^nav, P^c, P^h, P^wb )
```
目标
```
min M + λ_s·#(m_seg 切换) + λ_a·Σ authority_change
s.t. ∀seg: Ĉ_wb valid ∧ 至少一种权威模式可行
     ∧ 租约交接点存在 ∧ 接触模式连贯
```
求解：在"接触 × 权威"的混合状态空间上做分层 A*/MCTS；启发式为剩余语义距离 + 平衡能量距离 + 权威切换代价。

**定义 585（复合证书与执行规则）**

J_v12 = ( J_v11, Ĉ_wb, L, Ĉ_tel, HED_stats, TBDT_version )
Valid(J_v12) ⇔ Valid(J_v11) ∧ Ĉ_wb valid ∧ L valid ∧ Ĉ_tel valid

执行规则：仅当 J_v12 有效才执行 u_exec；否则按 SSP 中止；SSP 无解则保护性跌倒/sit；再否则退回 v11 的 hold。**安全执行集是"物理 ∧ 接触 ∧ 谐波 ∧ 平衡 ∧ 租约 ∧ 规范"的交集。**

class AuthorityLease:
    def __init__(self, alpha, scope, t_issue, cert, nonce, issuer, h_cert, d_max):
        self.alpha, self.scope = alpha, scope
        self.t_issue, self.t_exp = t_issue, t_issue + h_cert - d_max
        self.cert, self.nonce, self.issuer = cert, nonce, issuer

    def valid_at(self, t, nonce_registry, context):
        return (self.t_issue <= t <= self.t_exp
                and self.cert.valid_at(t)
                and not nonce_registry.revoked(self.nonce)
                and self.scope.matches(context)

class LatencyAwareSupervisor:
    def __init__(self, model, atl, p_min=0.2, gamma=0.3, h_cmd=0.2):

    def filter(self, packet, x, cert, lease, nonce_registry, context):
        t = now()
        if not lease.valid_at(t, nonce_registry, context):
            self.atl.log(t, packet, None, "lease_invalid", 0.0)
            return self.fallback(x, cert), 0.0, "lease_invalid"

        u_exec = project(packet.u_h, U, norm="W")       # 定义 577

class HumanEvidenceDisambiguator:
    def __init__(self, nge, atl, p_min=0.2, gamma=0.3):
        self.nge, self.atl, self.p_min, self.gamma = nge, atl, p_min, gamma

        if intervention_rate(records) > self.gamma:
            self.enter_shadow_mode()          # 不执行，只记录反事实
            return
        for r in records:
            p = self.atl.propensity(r)        # p(e=1|s,z)

            w = r.executed / p                # 逆概率加权
            self.nge.update_norm(r.u_h, r.s, weight=w, delay=r.d)

        cands = segments_to_candidates(segments)  # 每段带 WBC/HCC/CC/L_handoff
        current_chunk = planner.plan_with_authority(
            ctx.state, nge.b, ctx.delta_dom, ctx.tau_dom,
            balance_pred=balance_pred, authority=ctx.authority)

    # ---- 50Hz：WBC + v11 守卫 + LAS 投影（≤1.1ms）----
    cert = wbc.certify(ctx.state, current_chunk.contact_schedule,
                       hcc.get_estimates(), lease)
    if cert is None:
        abort = ssp.plan(ctx.state, wbc.last_valid(), ctx.env_est, ctx.authority.mode)
        execute_abort(abort); current_chunk = None
    else:
        if packet is not None:
            u_exec, alpha, verdict = las.filter(packet, ctx.state, cert, lease,
                                                nonce_registry, ctx.context)
        else:
            u_exec, alpha, verdict = current_chunk.next_auto_action(), 0.0, "auto"
        if verdict == "abort":
            abort = ssp.plan(ctx.state, cert, ctx.env_est, ctx.authority.mode)
            execute_abort(abort); current_chunk = None
        else:
            ctx.authority = AuthorityState(alpha=alpha, mode=verdict)
            execute(u_exec)

    # ---- 5Hz：HED 去污染证据更新（≤0.2ms，摊销 0.04ms）----
    if cycle_idx % T_evidence == 0:
        hed.update()

    # ---- 低频：ATL 落账 + TBDT 校准 ----
    if cycle_idx % T_atl == 0: atl.flush_merkle_root()
    if cycle_idx % T_calib == 0 and real_teleop_available():
        tbdt.update_calibration(real_teleop_traj)

    C, spatial_cert, claims, metrics, rewards = M.inherited_v11_path(ctx)
    return C, spatial_cert, claims, metrics, rewards
```

## 4. 推导（引理 104–112）

**引理 104（全身证书安全性）** 若 Ĉ_wb 在 [t_0,t_1] 全程有效且执行动作属于 U_safe，则对任意 t∈[t_0,t_1]：ZMP 在支撑区域内且裕度≥ρ_ZMP^min，脚底摩擦锥满足，无脚滑，手接触证书与腿/臂谐波证书均有效。证明：Ĉ_wb 是力/矩平衡、摩擦锥、ZMP/捕获点裕度、v11 谐波与接触证书的合取；力/矩平衡与摩擦锥保证存在可行接触旋量，ZMP 条件保证 CoP 不越界，v11 引理 97 保证谐波偏转与扭矩不越限。多接触情形只需把"支撑多边形"替换为 S(C)，合取逐项成立。∎

**引理 105（安全迈步是 v11 保持的保守扩张）** 双足中立时 P^wb=P^h 且 SSP 退化为 v11 的纯阻尼保持；一般情形 P^h⊆P^wb。存在单支撑状态使 P^h=∅ 但 P^wb≠∅（通过迈步）。若 x∈S_step 且 V_step(x)≤N_max，则 SSP 返回证书化中止。证明：hold 是步长为 0 的退化步；双支撑且 ZMP 在支撑域内时 hold 可行，故 P^h⊆P^wb。单支撑反例：CoM 已越过支撑边界，冻结关节使 ZMP 不可实现，而一次落脚可把捕获点拉回 S_stand。有界性由 N_max 与定义 588 直接给出。∎

**引理 106（权威租约的输入无关安全性）** 对任意人类输入序列（含过期、对抗、伪造、重放），只要执行规则要求"有效租约 ∧ 命令时证书"，则实际执行轨迹满足 Ĉ_wb。形式化地，安全性与人类输入无关。证明：对时间归纳。每步或 u_exec∈U_safe（由引理 104 安全），或 SSP 中止（由引理 105 安全）；租约有效性保证证书在 [t,t+h_cmd] 内未过期；nonce/issuer 校验拒绝伪造与重放；过期命令直接进入 fallback。故不存在绕过物理证书的人类输入路径。∎

**引理 107（延迟-权威前沿）** 设延迟 d 下状态预测误差满足 ‖x̂(t)−x(t)‖≤ε(d)=L_f·d·(1+σ_w)，证书裕度为 ρ_min，安全管半径随 ε(d) 单调收缩。则存在单调不增函数 α_max(d) 使 d 增大时人类权威必须下降；当 d+τ_react≥h_cert 时 α_max(d)=0。一个可用的充分设计规则是
```
α_max(d) ≤ max(0, 1 − c·d / (h_cert − τ_react))
```
其中 c 由 Lipschitz 常数、扰动界与裕度共同决定。证明：预测误差随 d 增长，U_safe 随误差膨胀而收缩；当 ε(d) 超过证书裕度时，任何非零人类动作都可能把状态推出 Ĉ_wb，故只能由自治兜底；当命令在到达时已超过证书视界，租约无法续期，权威为零。∎

**引理 108（最小干预与权威保持）** 若 U_safe 凸、‖·‖_W 严格凸，则 u_exec 是 U_safe 中距 u_h 唯一的最近点；若 u_h∈U_safe 则 u_exec=u_h，零干预；干预幅度≤dist_W(u_h,U_safe)。因此 LAS 在 W 范数意义下最大化人类权威保持。证明：希尔伯特空间投影定理；凸集上的最近点唯一且满足变分不等式；u_h 可行时投影为自身。接触模式使 U_safe 非凸时，用其凸内近似，结论变为"在近似集上最小干预"，保守但可证。∎

**引理 109（干预删失下的证据偏差）** 设 e∈{0,1} 为执行指示，p(s,z)=P(e=1|s,z)≥p_min>0。逆概率加权估计
```
θ̂_IPW = argmax_θ Σ_k (e_k/p̂_k)·log P(u_h,k|z_k,θ)
```
在倾向得分正确时一致；朴素估计（只用 e=1 样本）的偏差满足
```
‖E[θ̂_naive]−θ*‖ ≤ C·Cov(e, ∇log P)/p_min
```
有限样本方差为 O(1/(n·p_min²))。证明：重要性采样恒等式 E[e·g/p]=E[g]；朴素估计相当于对 e=1 条件分布采样，偏差由选择偏差公式给出；方差由权重二阶矩控制。∎

**推论 109.1（权威-证据自证偏差的不动点）** 若 NGE 用朴素似然从被拦截后的命令学习，且干预率随学到的规范单调上升，则闭环可能存在"高干预、低权威、规范收缩"的不动点；当 p_min>0 且使用 IPW/影子模式时，该不动点被消除。证明：朴素更新把安全策略的动作分布当作人类意图，等价于对 e=1 条件分布做最大似然；若干预策略随 θ 收紧，则 e=1 集合进一步偏向安全动作，形成正反馈。IPW 用 1/p 校正选择，恒等式保证目标仍是人类意图分布，故正反馈被切断。∎

**引理 110（中立元退化等价 v11）** 将定义 586 的四个中立元分别注入四端口，则 v12 主闭环的可行集、评分与调用序列退化为 v11：双足中立 ⇒ 固定基座、P^wb=P^h、SSP=hold；遥操作中立 ⇒ α=0、无连续命令、仅 a_ask；证据中立 ⇒ e≡1、无删失校正；孪生中立 ⇒ v11 HDT/HATD。按依赖偏序任一失效子集落到唯一 v11 退化点，再由 v11 引理 102 退回 v10。∎

**引理 111（预算守恒 v12）** 新增在线成本上界：WBC/ZMP 证书 ≤0.4ms（6 DOF 浮基 + 4 接触）；SSP 仅在 abort 时 ≤0.3ms；租约检查 ≤0.05ms；LAS 投影 ≤0.3ms（小规模 QP，热启动）；HED 5Hz ≤0.2ms（摊销 0.04ms）；TBDT 异步 10Hz、16 样本 GPU 摊销 ≤1ms；ATL 追加 ≤0.02ms。总新增 ≤1.5ms；v11 决策 p99 22ms、留 2ms 余量，故 v12 p99 ≤22ms，50Hz 保持。若 LAS QP 超时，降级到预编译 CBF 或保守 hold，仍满足安全但增加干预。∎

**引理 112（无死锁性与安全活性）** 若复合证书 J_v12 在当前状态为空，则 SSP 的 Π_abort 至少包含一个物理可执行终态（brace/sit/protected_fall），故系统永远有可执行动作；但这只保证**安全活性**，不保证任务活性。证明：Π_abort 含 sit 与 protected_fall 两个吸收终态；即使所有动态步均不可行，保护性卸力/坐下仍可执行（可能任务失败）。因此不存在"无动作可执行"的死锁；但"证书死锁"会转化为任务失败或频繁接管，需由 AHD 改权威模式/重切分缓解。∎

## 8. 已知风险与失效模式

1. **多接触证书过度保守导致"证书死锁"**：脚底支撑、ZMP、手接触、谐波多重合取可能清空可行集。缓解：分层硬/软裕度、AHD 自动重切分、改权威模式、SSP 主动迈步扩展可行域、以任务级松弛换安全。
2. **延迟估计误差导致"命令时证书"失效**：d̂ 低估会让过期命令被误认为有效。缓解：d_max 取保守上界、时间戳+序号、租约 TTL 硬限制、非对称延迟监测、超界即降 α。
3. **人类证据污染与规范漂移**：安全过滤器删失人类命令，NGE 学到"自己的安全策略"。缓解：ATL+IPW、影子模式、p_min/γ 阈值、a_ask 打破回路、把"干预"作为显式混杂因子。
4. **权威交接抖动/模式振荡**：安全层与人类反复争夺控制权，造成操作不适。缓解：滞回、最小驻留时间、平滑混合、交接预告、把切换代价写入 AHD。
5. **安全迈步在受限空间/易损环境中不可行**：扶墙、狭窄、地面湿滑时 step/brace 失败。缓解：环境感知落脚点、保护性卸力/sit 终态、降低任务速度、请求人类确认。
6. **多接触传感失效**：脚底力/触觉/IMU 失效使 WBC 不可信。缓解：冗余传感、保守中立元、降级到 v11 固定基座、限制动作幅度。
7. **操作者模型 Sim-to-Real 差距**：真实人类的延迟、技能、干预策略与 DR 分布不匹配。缓解：在线贝叶斯校准、真实人类在环训练、按操作者个性化先验、保留保守 α。
8. **租约伪造/重放/越权**：遥操作链路被攻击或误配置。缓解：认证租约、nonce 缓存、issuer/scope 校验、速率限制、异常检测、最小权限。
9. **证据学习与安全目标的长期冲突**：为了收集无删失证据而进入影子模式会降低任务吞吐。缓解：把影子模式限制在低风险子任务、主动 a_ask 代替被动学习、设置证据预算。

## 9. 本轮最大风险

**一句话**：安全过滤器为了守住平衡/接触/谐波证书而不断拦截和投影人类命令，NGE 又把这些被过滤后的动作当成人类规范去学习，于是系统学到一个"人类也同意被拦截"的虚假规范，进一步收紧证书、增加拦截——形成"越安全越不信任人类、越不信任越安全"的**权威-证据自证偏差**，最终机器人安全地站在角落里，却再也学不会人类真正想让它做的事。
