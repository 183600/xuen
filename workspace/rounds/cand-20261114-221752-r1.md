# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「数据集构建」×「模型量化」）

> R69 给了闭环一张「嘴」（主动问）和一个「鼻子」（流似然第二意见），并用 aleatoric / epistemic 的二分取代了 R68 的单一标量。但它把两个更深的依赖藏在地毯下：
>
> 1. **模态分布是从数据里学来的。** 如果数据没有覆盖某个模态、某个安全分支，R69 所谓的 U_epi 就不是「问得清楚的歧义」，而是「根本没见过、也不知道该问什么」的空白。数据集构建不是训练前的杂活，而是 R69「resolution bonus」的**供给链**——没有覆盖证书，bonus 就是空头支票。
> 2. **闭环最终要跑在量化后的边缘模型上。** R69 的所有阈值（τ_ece、TAU_EPI、TAU_FMA、Δ_min ≥ 3σ_in）都是全精度下标定的。INT8/INT4 会同时扰动速度场、模态权重与流似然，而且这种误差是**系统性、相关、非零均值**的——既不是 aleatoric 噪声，也不是 epistemic 歧义。R69 没给它留位置：它要么被误当噪声（过度保守），要么被忽略（悄悄吃掉安全裕度）。
>
> 核心命题：**不确定性不只有「可不可约」一个轴，还有「从哪来」一个轴。** 本轮把 U 按**来源（provenance）**拆成四谱：U_ale（噪声）、U_epi（歧义）、U_cov（数据覆盖缺口）、U_rep（量化表示误差）。只有 U_epi 能被「问」消解；U_cov 只能靠「采」（数据集构建）；U_rep 只能靠「提精度 / 重标定」（模型量化）；U_ale 谁都治不了。**在花掉任何交互预算之前，先做来源分型。** 命名 **PRISM-RAS**（Provenance- and Representation-aware Interactive Safety Measurement）——像棱镜把一束白光分成光谱，它把一坨标量不确定性分成来源可归因、可分别消解、可分别审计的成分。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这个不确定，问得出来吗？数据里有吗？低比特模型还信得过吗？**」——不确定性不是一种东西，先分型，再治疗。

## 0. 直觉与动机

**灵感 1（数据集构建 → 歧义也有「供给曲线」）**
直觉：R69 的 VoI 隐含假设「问一下，后验就会变好」。但如果该状态落在训练分布之外，任何回答都不会把后验变成可信的——系统只会把一个新情况硬塞进旧模态。真正的瓶颈不是「问不问得起」，而是「有没有见过足够多、足够难、来源足够干净的数据」。于是数据集构建从「训练前的准备工作」升级为闭环里的一个**消解算子**，与「问」并列。关键设计：主动采集的目标不该是「模型最不确定的点」（那会把数据堆在 aleatoric 噪声上），而该是「覆盖缺口 × 安全影响 × 来源可信」三者乘积最大的点。数据是唯一能收紧 U_cov 的算子——问不出来，只能采出来。

**灵感 2（模型量化 → 部署精度是一个安全变量，不是工程折扣）**
直觉：把 40MB 的流策略压成 10MB 的 INT8，速度场会变、模态会挪、似然会偏。最危险的不是「变差」，而是**变差的方向恰好让系统显得更确定**：两个本来分得开的模态被粗粒度量化权重抹平、合并，H_mode 下降、Δ_min 下降，R69 会读成「歧义消解了」，于是发放 resolution bonus、松开安全裕度，而实际动作成了两个不相容模态的危险平均。这是本轮最锋利的发现：**量化可以伪造「确定性」**。所以量化必须携带一张「模式保持证书」，而不是一句「精度损失 < 1%」。

**灵感 3（四分光谱 → 类型学先于治疗学）**
直觉：R69 的退避只有「消解了 / 没消解」两档；PRISM 先问「这是什么病」，再决定用哪种药：噪声不可治（λ_floor）；歧义可问（MINT）；覆盖缺口只能采（CADF）；表示误差只能提精度或重标定（QARC）。若分不清类型，就把全部当作不可约——**类型不确定本身就是最该保守的东西**。这继承 R69 的理论姿态：新层必须是旧层的严格泛化。PRISM 在「覆盖有效 + 全精度 + 类型已知 + 不交互」的边界上逐指令退化为 FLUID，再退化为 CALM/R68。

**灵感 4（三角测量 → 量化的「影子模型」）**
直觉：R69 用「流似然 Δa」给标定层做第二意见；PRISM 再引入一个**影子量化模型**做第三意见：同一观测下，全精度策略与量化策略的决策差异 U_rep 就是表示误差的可观测代理。它既是量化证书的在线监控，也是来源分型的一个正交特征——标定骗得过残差、量化骗得过似然，但「两个模型在同一输入上给出不同模态权重」这件事很难同时被伪造。三条通道（传感器残差、流似然、影子差异）构成来源分型的三角测量。

**灵感 5（数据即攻击面 → 防「信任洗白」）**
直觉：R69 的交互回答若进入训练集，就把「一次可能被投毒的对话」永久写进了模型。R69 的 k-正交一致纪律保护的是**当下决策**，保护不了**数据供应链**。所以数据集构建必须带来源账本与**信任单调性**：任何模型派生变换都不能把低信任数据「洗」成高信任；合成数据有自消费上限，否则模型会像近亲繁殖一样逐代坍缩；交互得来的答案只是「候选证据」，需跨会话复现才可升级为训练数据。一句话：**问对一次，不能变成信错一辈子。**

## 1. 形式化定义（增量：定义 310–330）

**定义 310（PRISM-RAS 总览与三不变式）** PRISM-RAS = (FMP†, PROV, CADF, DTL, QARC, MPCQ, QAC, RAS-WM††)。三不变式：
(i) **类型先于治疗**：未完成不确定性来源分型（或分型置信不足）前，禁止发起交互、禁止发放 resolution bonus，一律按全不可约保守；
(ii) **实时流零学习写操作**（继承 R68 定义 276-i / R69 定义 293-i）：数据集构建、量化重训、重标定全部在离线慢环，部署必须带证书且可原子回滚；
(iii) **可溯源与可回滚**：任何进入训练集的数据、任何部署的比特图都必须有来源账本与证书哈希；证书失效即回退到上一已认证版本。

**定义 311（不确定性光谱）** 对安全状态 s，定义四分向量
U(s) = (U_ale, U_epi, U_cov, U_rep)：
- U_ale = Σ_k ŵ_k tr(Σ_k)（继承 R69 定义 297，模态内噪声）；
- U_epi = H_mode · g(Δ_min)（继承 R69 定义 297，模态间歧义）；
- U_cov(s) = h(d_k(Φ(s)))，d_k 为到训练集 D 的 k-近邻（在表示空间 Φ 中）经保形标定后的非一致性分数，h 单调增；
- U_rep(s) = D_dec(π_θ(·|s), π_{θ_q}(·|s))，决策层差异（见定义 318）。
另有**类型不确定** U_type = H(p_type | evidence)（定义 322）。四分不做简单加和，各自进入不同通道（定义 323）。

**定义 312（来源算子与正交性假设 A99）** 三类消解算子：交互 g（R69 MINT）、数据采集 d（CADF）、精度提升 q（QARC）。在安全状态分布上假设
∂U_epi/∂g < 0，∂U_cov/∂d < 0，∂U_rep/∂q < 0，且组间交叉导数在容差内 ≈ 0（A99）。
注意交互有**双重效应**：对当前决策的即时信息效应（只作用于 U_epi），以及若回答被保形复现后进入数据集的延迟覆盖效应（作用于 U_cov）；后者必须通过来源账本（定义 315）才计入，绝不允许即时效应冒充覆盖。

**定义 313（覆盖证书 C_cov(ε, δ)）** 设 Φ 为表示映射、D 为已认证训练集、s(x) = d_k(Φ(x), Φ(D)) 为非一致性分数。对可交换安全分布，取保形阈值 ρ_α 使 ℙ[s(x) ≤ ρ_α] ≥ 1−α。称 D 满足 (ε, δ)-覆盖证书，若 ρ_α ≤ ε 且 δ ≤ α。并附两项结构条件：(a) **模态覆盖**——参考模态目录 M_ref 中每个模态 m 在 ε-邻域内拥有 ≥ w_min 的样本质量；(b) **分支覆盖**——每个安全关键决策点的两个反事实分支都各有 ≥ w_min 支持。缺任一项 ⇒ 覆盖不成立，U_cov 不可消解。

**定义 314（覆盖感知主动数据构建 CADF）** 候选池 C（真实 + 交互复现 + 合成）。批量采集
B* = argmax_{B⊆C, |B|≤b, prov-ok} Σ_{x∈B} a(x) − λ_red · Red(B)，
其中 a(x) = Δ_cov(x) · I_safe(x) · τ(x)：Δ_cov 为期望覆盖半径收缩、I_safe 为对安全风险估计的影响（影响函数 / 梯度范数）、τ 为来源信任。Red 为冗余惩罚（DPP / 多样性）。A99 下 a 单调次模，贪心获得 1−1/e 近似。**采集目标不是最大不确定，而是最大「可消解且影响安全」的覆盖缺口。**

**定义 315（数据来源账本 DTL 与信任单调性）** 每条数据 x 带 provenance prov(x) ∈ {real, human_verified, interactive_corroborated, interactive_single, synthetic, self_generated}、信任 τ(x) ∈ [0,1]、血缘 DAG L(x)。训练权重 w(x) = τ(x)·anchor(x)·fresh(x)。**信任单调性公理**：对任何模型派生变换 f（含融合、重标注、生成、推测），τ(f(x)) ≤ τ(x)；低信任数据只能经外部验证或跨会话正交复现升级，绝不能被模型自身「洗白」。由此把 R69 的 k-正交纪律从决策层延伸到数据层。

**定义 316（抗合成坍缩纪律 ACD）** 自消费比 r_self = Σ w(x)1[self_generated] / Σ w(x)，硬约束 r_self ≤ γ。合成数据权重随生成深度 t 指数衰减 τ_t = τ_0·κ^t（κ<1）。**模态多样性地板**：生成数据集的模态熵 H_mode(D_gen) ≥ H_mode(D_real) − δ_H，且不得使参考模态目录中任一模态质量跌破 w_min；否则整批丢弃。此定义直接对冲「用自己输出训练自己」导致的逐代坍缩。

**定义 317（量化算子与敏感度）** 量化 Q: θ → θ_q（仿射/逐通道/混合精度），逐参数误差 |θ_{q,i} − θ_i| ≤ Δ_i/2，Δ_i = range_i/(2^{b_i}−1)。对任一标量安全泛函 f（风险、λ、模态权重、Δ_min），若其 Lipschitz 常数为 L_f，则
|f(θ_q) − f(θ)| ≤ L_f‖θ_q − θ‖₂ ≤ (L_f/2)√(Σ_i Δ_i²)。
定义量化敏感度 S_f = (L_f/2)√(Σ_i Δ_i²) / tol_f；**证书有效 ⇔ 对所有安全关键 f 有 S_f ≤ 1**。

**定义 318（表示不确定性 U_rep）** 取**决策层**而非 logit 层的差异：
U_rep(s) = max( |λ(θ_q)−λ(θ)|/tol_λ,
                 TV(ŵ(θ_q), ŵ(θ)),
                 W₂(ξ̄_k(θ_q), ξ̄_k(θ)) / Δ_min,
                 |a_score_q − a_score| / tol_a )。
强调：U_rep 是系统性、相关的偏差（对同一输入重复采样不会平均掉），与零均值 aleatoric 噪声在统计上可区分，这是它能被单独估计的前提。

**定义 319（模式保持量化 MPCQ）** 量化模型称 (δ_H, δ_Δ)-模式保持，若对安全状态集：
|H_mode(θ_q) − H_mode(θ)| ≤ δ_H，
Δ_min(θ_q) ≥ Δ_min(θ) − δ_Δ，
且无模态合并：∀ i≠j，W₂(ξ̄_i, ξ̄_j) ≥ 3σ_in（A95 在量化后仍成立）。
训练期正则 L_MP = max(0, |ΔH|−δ_H) + max(0, Δ_min(θ)−δ_Δ−Δ_min(θ_q))。**这是防止「量化伪造确定性」的核心**：若两模态被抹平，H_mode 与 Δ_min 同时下降，R69 会误判歧义已消解。

**定义 320（风险感知混合精度分配 RA-MPQ）** 给定总比特预算 B：
min_{b} Σ_l Risk_l(b_l) s.t. Σ_l n_l b_l ≤ B，
其中 Risk_l = w_l · S_{f_l}(b_l)，w_l 为该模块对安全决策的影响权重。安全关键模块（模态边界附近的速度网、mode_head、标定头、FMA 散度估计器）优先高比特。背包用「每比特边际风险下降」贪心；因 Δ_i ∝ 2^{−b_i}，敏感度随比特近似二次下降。

**定义 321（量化感知标定 QAC）** 量化后必须重新标定 ECE 与全部阈值（τ_ece、TAU_EPI、TAU_FMA、λ_floor），并在量化分数上重算保形阈值以维持覆盖。规则：若 ECE_q > τ_ece 或 S_q > 1，则先 (a) 对关键模块升比特；仍不满足则 (b) 禁用 VoI、退化为 R69 纯保守。**禁止沿用全精度阈值**——阈值漂移会直接打开安全裕度。

**定义 322（来源分类器与类型混淆）** 特征：集成分歧、保形 OOD 距离 d_k、影子量化差异 U_rep、交互响应稳定性、传感器噪声底。分类器 C_U 输出单纯形 {ale, epi, cov, rep, unknown}。定义**类型混淆率** ε_t = ℙ(C_U 判为 epi | 真值为 cov 或 rep)。**类型安全规则**：若 max p_type < τ_type 或 top-2 间隔 < δ_gap，则判 unknown，所有分量按不可约处理。U_type = H(p_type) 是新一层的元不确定性。

**定义 323（三阶退避，严格包含 R69）** 记 U_irr = U_ale + U_epi + U_cov + U_rep。
- **Tier 0（全消解）**：类型已知 ∧ 交互消解 U_epi ∧ 覆盖证书有效 ∧ 量化证书有效 ⇒ λ = λ_floor(U_ale)（resolution bonus）；
- **Tier 1（部分消解）**：覆盖与量化证书有效、但部分分量未消解 ⇒ λ = λ_floor(U_ale + U_unresolved)；
- **Tier 2（类型未知 / 证书失效）**：λ = λ_floor(U_irr)，禁用 VoI；若量化证书失效，先回退全精度，否则回退 R69 纯保守。
单调性：λ_Tier0 ≤ λ_Tier1 ≤ λ_Tier2。**安全裕度只有在有效证书支撑下才允许收缩。**

**定义 324（统一证据预算 EBA）** 预算 B_total = (n_ask, n_data, n_bits)。边际价值 μ_g = ΔU_epi/cost_ask、μ_d = ΔU_cov/cost_data、μ_q = ΔU_rep/cost_bits。按 μ 贪心分配，且始终优先满足安全证书约束。这把 R69 的「交互预算」扩展为「问 / 采 / 压」三种证据资源的统一经济学，产出可解释的 Pareto 前沿。

**定义 325（证书 J_PRISM）** J_PRISM = (J_FLUID, coverage_cert(ε,δ), provenance_root_hash, r_self, mode_diversity_margin, quant_bits_map_hash, S_q_max, ECE_q, mode_preserve_δ, U_type_p95, prism_ver)。Valid ⇔ Valid(J_FLUID) ∧ 覆盖证书有效 ∧ 信任单调性未被违反 ∧ r_self ≤ γ ∧ S_q ≤ 1 ∧ ECE_q ≤ τ_ece ∧ 模式保持 ∧ 重标定版本一致。

**定义 326（溯源审计 VQAuditor-D）** 审计对象新增数据与量化决策：是否发生投毒洗白、合成上限是否被绕过、证书是否伪造 / 过期、阈值是否用全精度旧值、量化是否以「模态合并」伪装确定性。结论回灌 AuditBuf，成为下一轮 CADF 与 EBA 的成本先验。

**定义 327（威胁模型 ℰ_PRISM）** ℰ_PRISM = ℰ_FLUID × ℰ_data × ℰ_quant。ℰ_data：标签投毒、来源伪造、合成数据投毒、反馈回环投毒（交互答案洗白入训练集）、模态擦除；ℰ_quant：量化诱导弹模态坍缩（假确定性）、阈值漂移、标定集过拟合、强制低比特降级攻击。

**定义 328（快慢双时间尺度）** 快环（实时，≤ 3ms）：PROV + 固定 θ_q 推理，零学习写操作。慢环（离线）：CADF 采集、QAT、QAC 重标定、审计。慢环任何更新必须先取得 J_PRISM 证书才允许部署，且部署为原子换装 + 回滚（继承 R68 定理 15 / R69 定理 17）。**「问」是快环，「从问中学习」是慢环**——这条隔离是数据安全的关键。

**定义 329（退化与包含关系）** 当覆盖证书有效、S_q = 0（全精度）、类型已知、且不发起交互时，PRISM 逐指令等于 FLUID；再令 VoI ≤ 成本，则逐指令等于 CALM/R68。故 PRISM ⊇ FLUID ⊇ CALM，且安全侧永不弱化。

**定义 330（重认证触发与时序耦合）** 触发重认证：保形覆盖跌破名义值、r_self 上升、比特图 / 编译器 / 硬件变更、参考模态目录变化、U_type 持续偏高。重认证频率与 U_cov、U_rep 的增长率挂钩；快环内只做廉价影子差异监控，不在线重训。

```python
# IP-264 PROV：把不确定性按来源分解（先分型，再花钱）
def decompose_provenance(M, s):
    U_ale, U_epi, modes = r69_decompose(M.fmp.sample(s, K=4), M.trunk(s))
    d_cov = M.coverage_index.conformal_distance(M.phi(s))      # 覆盖缺口
    U_cov = coverage_to_uncertainty(d_cov)
    U_rep = decision_divergence(M.fmp(s), M.fmp_q(s))          # 影子量化差异
    feats = [d_cov, U_rep, M.ensemble_disagreement(s),
             M.sensor_noise_floor, M.interaction_stability]
    p_type = M.prov_classifier(feats)                          # ale/epi/cov/rep/unknown
    if p_type.max() < TAU_TYPE or top2_gap(p_type) < DELTA_GAP:
        return {"type": "unknown", "U": (U_ale,U_epi,U_cov,U_rep)}
    return {"type": argmax(p_type), "U": (U_ale,U_epi,U_cov,U_rep),
            "p_type": p_type}

# IP-265 CADF：覆盖感知主动采集（离线慢环；来源门槛 + 多样性）
def acquire_batch(M, candidates, b):
    scored = []
    for x in candidates:
        if not M.dtl.provenance_ok(x):            continue
        gain = M.coverage_index.expected_radius_gain(x)   # Δ_cov
        inf  = M.influence.safety_influence(x)            # I_safe
        trust= M.dtl.trust(x)                             # τ
        scored.append((gain * inf * trust, x))
    return greedy_submodular(scored, b, redundancy=M.dpp) # 1-1/e

# IP-266 DTL：信任单调，拒绝「洗白」
def admit(x, transform):
    tau = min(trust(x), transform.max_trust)      # τ(f(x)) <= τ(x)
    if x.prov == "interactive_single":
        tau = min(tau, TAU_INTERACTIVE_SINGLE)    # 未经复现不得升信任
    if x.prov == "self_generated" and self_ratio() > GAMMA_SELF:
        return REJECT                             # 合成上限
    return DatasetEntry(x, tau, lineage=transform.lineage)

# IP-268/269 QARC + MPCQ：带证书的量化
def quantize_with_certificate(M, bits_budget):
    b_map   = risk_aware_bit_allocation(M.fmp, bits_budget)   # 背包
    fmp_q   = qat(M.fmp, b_map, reg=mode_preserve_regularizer) # L_MP
    S_q     = max_sensitivity(M.fmp, fmp_q, M.safety_set)
    ece_q   = expected_calibration_error(fmp_q, M.calib_set)
    mp_ok   = mode_preservation_report(M.fmp, fmp_q).ok
    if not mp_ok:   fmp_q = escalate_bits(fmp_q, M.critical_modules)
    if ece_q > TAU_ECE or S_q > 1:
        return fallback_to_full_precision(M)                  # 或 R69 保守
    return fmp_q, Certificate(S_q, ece_q, mp_ok, b_map)

# IP-273/276 主闭环：PRISM = 先分型 → 按类型选算子 → 三阶退避
def PRISM_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    prov = M.prov.decompose(M, o)
    U_ale, U_epi, U_cov, U_rep = prov["U"]
    # 类型未知：不交互、不发 bonus，全按不可约
    if prov["type"] == "unknown":
        return r69_conservative(M, o, U_ale + U_epi + U_cov + U_rep, U_cal)
    # 只有 epi 且量化/覆盖证书有效时，才值得「问」
    g = None
    if prov["type"] == "epi" and U_rep < TAU_REP and U_cov < TAU_COV:
        g = M.mint.choose_interaction(M.modes, o, M.budget)
    if g is not None:
        U_epi = M.cia.update_belief(M.modes, M.cia.execute(g))
    # 覆盖缺口走离线采集；表示误差走高比特 / 重标定（不在快环重训）
    if prov["type"] == "cov":
        M.cadf.submit(o, M.dtl, M.audit)              # 慢环
    if U_rep > TAU_REP:
        M.qarc.escalate_or_fallback(o)
    # 三阶退避
    U_floor = U_ale + (0.0 if g is not None else U_epi) + U_cov + U_rep
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_mode(M.modes, U_epi, lam)
    M.vqa_d.submit(prov, g, U_rep, M.audit)
    return k, lam, mode, prov["U"]
```

## 3. 推导

**引理 19（来源正交性与交互的零收益）** 在 A99 下，若真值 ∈ {cov, rep}，则对任意信息动作 g 有 E[ΔU_epi | g] = 0，故 VoI(g) ≤ 0；R69 若因模态权重把 U_cov/U_rep 误记为 U_epi 而发起交互，其期望信息增益为零。系：PRISM 的来源分型把 R69 的交互预算浪费比例上界压到类型混淆率 ε_t 以下；分型越准，「问」越只花在问得出来的地方。

**引理 20（类型混淆对安全裕度的侵蚀，量化是放大镜）** 设 ε_t = ℙ(C_U=epi | 真值∈{cov,rep})。resolution bonus Δλ = λ_floor(U_irr) − λ_floor(U_ale) 被错误发放的概率 ≤ ε_t，期望风险增量 ≤ ε_t·L_risk·Δλ。更危险的是**假确定性**：量化若使两模态间距由 Δ 缩到 Δ−δ，则测得 H_mode 与 Δ_min 同时下降，U_epi 被低估、bonus 被错误触发，而真实选错模态概率反而上升。故模式保持证书（定义 319）不是可选项，而是 bonus 的**前置条件**。

**引理 21（量化敏感度传播与混合精度收益）** 由定义 317 的 Lipschitz 界，对安全泛函 f 有 |f(θ_q)−f(θ)| ≤ (L_f/2)√(Σ_i Δ_i²)。因 Δ_i = range_i/(2^{b_i}−1) ∝ 2^{−b_i}，把关键模块比特从 b 提到 b+1，误差平方项约降为 1/4，故 Risk_l(b) 近似二次下降；这解释了为何少量关键比特能买到大部分安全证书。

**引理 22（覆盖证书 → 可认证风险界）** 若风险泛函对表示距离 L_risk-Lipschitz，且覆盖证书 (ε,δ) 成立，则对 s 落在 D 的 ε-邻域外的事件，风险估计误差 ≤ L_risk·ε 且概率 ≤ δ。系：U_cov 不只是启发式 OOD 分数，而是能转成**带概率保证的风险上界**；且在所有算子中，只有数据采集能收紧它。

**定理 18（PRISM 严格包含 FLUID 与 R68）** 在 A95–A102 下，PRISM 的任意状态期望风险 ≤ FLUID ≤ CALM；当覆盖证书有效、全精度、类型已知且不交互时，PRISM 与 FLUID 逐指令相同；再令 VoI ≤ 成本则与 R68 逐指令相同。安全侧不做任何让步，效率增益只来自**有证书支撑**的 resolution bonus。

**定理 19（数据飞轮不退化）** 在信任单调性（定义 315）、合成上限 γ 与模态多样性地板（定义 316）、影响隔离下，用 CADF 增广后重训的模型安全损失 ≤ 原模型 + ε_data；低于信任门槛的投毒无法进入高信任池，因而无法抬升已部署证书。证明思路：信任单调性把毒样本的影响上界锁在其 τ 上，r_self 上限阻断坍缩放大，影响函数隔离把超阈值样本移出训练。

**定理 20（统一预算的次模最优性与 Pareto）** 在 A99 下 U_epi(g)、U_cov(d)、U_rep(q) 的值函数对各自资源单调次模，故 EBA 的贪心分配达到 (1−1/e) 最优，且「问 / 采 / 压」三资源的等边际条件给出凹 Pareto 前沿。这为 E299/E314 的成本-收益曲线提供理论依据。

**定理 21（交互与量化的无突变）** 信息动作 g 经 C-RAS-WM 认证（R69 定义 302）后物理风险 ≤ ε_int；量化换装必须带 J_PRISM 证书且原子回滚，故其只改变「用哪个精度的策略选模态」，不改变安全包络；类型未知 / 证书失效时 λ 单调不降地退化为 R69/R68，换装不变式保持 ⇒ 控制连续、无突变。

## 6. 本轮最大风险

**一句话**：PRISM-RAS 的安全性完全押在「来源分型正确」这一前提上——**一旦把 U_rep 或 U_cov 误判成 U_epi，它会自信地去问一个数据里根本不存在的问题（浪费预算、被投毒答案洗白入训练集），而更致命的是把量化诱发的模态合并读成「歧义已消解」，从而在没有任何告警的情况下发放 resolution bonus、悄悄松开 R68/R69 好不容易守住的安全裕度；类型误判不是让系统变笨，而是让它「更自信地变危险」。**

**次级风险与缓解**：量化假确定性（MPCQ 模式保持证书 + 定理 18/21，证书不成立即回退全精度）；数据投毒洗白（信任单调性 + DTL + 影响隔离 + ℰ_data 对抗训练 + E304）；合成自消费坍缩（r_self 上限 + 模态多样性地板 + E305）；覆盖证书在分布漂移下失效（保形重标定 + 定义 330 重认证触发 + E302）；统一预算被错误边际估计误导（EBA 的次模近似 + E314 校准）；离线慢环更新破坏实时安全（快慢隔离 + 原子换装回滚，定义 328）。

```python
    scored = [(M.coverage.radius_gain(x) * M.influence.safety(x) * M.dtl.trust(x), x)
              for x in cand if M.dtl.provenance_ok(x)]
    return greedy_submodular(scored, b, redundancy=M.dpp)

def admit(x, transform):
    tau = min(M.dtl.trust(x), transform.max_trust)              # τ(f(x)) <= τ(x)
    if x.prov == "interactive_single": tau = min(tau, TAU_INTERACTIVE_SINGLE)
    if x.prov == "self_generated" and self_ratio() > GAMMA_SELF:
        return REJECT
    return DatasetEntry(x, tau, transform.lineage)

# IP-268/269/270 QARC + MPCQ + QAC：带证书的量化
def quantize_with_certificate(M, bits_budget):
    b_map = risk_aware_bit_allocation(M.fmp, bits_budget)       # 风险加权背包
    fmp_q = qat(M.fmp, b_map, reg=mode_preserve_regularizer)    # L_MP
    S_q   = max_sensitivity(M.fmp, fmp_q, M.safety_set)
    ece_q = expected_calibration_error(fmp_q, M.calib_set)
    mp_ok = mode_preservation_report(M.fmp, fmp_q).ok
    if not mp_ok: fmp_q = escalate_bits(fmp_q, M.critical_modules)
    if ece_q > TAU_ECE or S_q > 1:
        return fallback_to_full_precision(M)                    # 或 R69 保守
    return fmp_q, Certificate(S_q, ece_q, mp_ok, b_map)

# IP-276 主闭环：分型 → 按型选算子 → 三阶退避
def PRISM_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    prov = M.prov.decompose(M, o)
    U_ale, U_epi, U_cov, U_rep = prov["U"]
    if prov["type"] == "unknown":                               # 类型未知：全保守
        return r69_conservative(M, o, U_ale+U_epi+U_cov+U_rep, U_cal)
    g = None
    if prov["type"] == "epi" and U_rep < TAU_REP and U_cov < TAU_COV:
        g = M.mint.choose_interaction(M.modes, o, M.budget)     # 只有 epi 才问
    if g is not None:
        U_epi = M.cia.update_belief(M.modes, M.cia.execute(g))
    if prov["type"] == "cov": M.cadf.submit(o, M.dtl, M.audit)  # 离线采
    if U_rep > TAU_REP:       M.qarc.escalate_or_fallback(o)    # 提精度/重标定
    U_floor = U_ale + (0.0 if g is not None else U_epi) + U_cov + U_rep
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_mode(M.modes, U_epi, lam)
    M.vqa_d.submit(prov, g, U_rep, M.audit)
    return k, lam, mode, prov["U"]
```

## 4. 推导

**引理 19（来源正交性与交互零收益）** A99 下，真值∈{cov,rep} 时 `E[ΔU_epi|g]=0`、`VoI≤0`；R69 若误发交互，期望信息增益为零。系：分型把交互预算浪费比例压到类型混淆率 ε_t 以下。

**引理 20（类型混淆侵蚀安全裕度，量化是放大镜）** bonus `Δλ` 被错误发放的概率 ≤ ε_t，期望风险增量 ≤ `ε_t·L_risk·Δλ`。量化使模态间距 `Δ→Δ−δ` 时，测得 H_mode 与 Δ_min 同降，U_epi 被低估、bonus 被误触发，而真实选错概率上升——故 MPCQ 是 bonus 的前置条件。

**引理 21（量化敏感度传播）** `|f(θ_q)−f(θ)| ≤ (L_f/2)√(ΣΔ_i²)`；`Δ_i ∝ 2^{−b_i}`，关键模块加 1 比特误差平方约降 1/4，故少量关键比特即可买到大部分安全证书。

**引理 22（覆盖证书 → 可认证风险界）** 风险对表示距离 `L_risk`-Lipschitz 且覆盖 (ε,δ) 成立时，邻域外风险估计误差 ≤ `L_risk·ε`、概率 ≤ δ。U_cov 因而是带概率保证的风险上界，且只有数据采集能收紧它。

**定理 18（严格包含）** A95–A102 下 PRISM 期望风险 ≤ FLUID ≤ CALM；覆盖有效、全精度、类型已知、不交互时逐指令等于 FLUID；再令 VoI≤成本则等于 R68。

**定理 19（数据飞轮不退化）** 信任单调性 + r_self 上限 + 模态地板 + 影响隔离下，增广重训安全损失 ≤ 原模型 + ε_data；低于门槛的投毒无法抬升已部署证书。

**定理 20（统一预算次模最优）** 三资源值函数单调次模，EBA 贪心达 (1−1/e) 最优，等边际条件给出凹 Pareto 前沿。

**定理 21（交互与量化无突变）** 信息动作过 C-RAS-WM 认证后风险 ≤ ε_int；量化换装带 J_PRISM 且原子回滚；类型未知/证书失效时 λ 单调不降退化为 R69/R68，换装不变式保持 ⇒ 控制连续。

## 7. 本轮最大风险

**一句话**：PRISM-RAS 的安全性完全押在「来源分型正确」上——**一旦把 U_rep 或 U_cov 误判成 U_epi，系统会自信地追问一个数据里根本不存在的问题，或把量化诱发的模态合并读成「歧义已消解」，在没有告警的情况下发放 resolution bonus、松开安全裕度；类型误判不是让系统变笨，而是让它更自信地变危险。**

**次级风险与缓解**：量化假确定性（MPCQ 证书 + 定理 18/21，不成立即回退全精度）；数据投毒洗白（信任单调性 + DTL + 影响隔离 + ℰ_data + E304）；合成自消费坍缩（r_self 上限 + 模态地板 + E305）；覆盖证书在漂移下失效（保形重标定 + 定义 330 重认证 + E302）；预算边际估计失准（次模近似 + E314 校准）；慢环更新破坏实时安全（快慢隔离 + 原子换装回滚，定义 328）。
