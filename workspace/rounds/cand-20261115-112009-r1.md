# 第 5 轮（灵感循环第 5 轮；本轮灵感：「状态机」×「手眼标定」）

> **基线**：第 4 轮 InstructGauge-WR（IP-328–333；定义 448–467；引理 59–62；实验 E457–E472）。LeanGauge / MODGAUGE / ToolGauge / InstructGauge 骨架继续继承不变。
> 本轮纪律：**结构升级 + 严格退化**。状态机把「安全检查」升级为「受守卫的转移不变式」；手眼标定把「空间证书」升级为「带不确定度的估计证书」。二者都是可选增强，任一不可用即退回第 4 轮。

## 0. 直觉与动机

**灵感 1（状态机 → 安全是转移的不变式，而不是一次次的事后检查）**
直觉：第 4 轮的 CVC 在每步 `joint_pre` 里查一次，但块执行期间「当前处于哪个阶段、还持有哪些有效证书」是隐式散落在控制流里的。工程上真正出事的往往不是「某次检查算错了」，而是「状态迁移没对齐」——比如已经进入执行态，证书却在上一拍失效，代码却因为顺序问题又放行了一步。把执行生命周期显式化为有限状态机，并让**每条进入执行态的边都被证书守卫**，安全就从「逐点断言」变成「结构性不变式」（类似硬件里的 FSM + assertion-based verification）。再补一条 well-founded 排序，修复循环才不会因反复重规划而活锁。

**灵感 2（手眼标定 → 空间证书的地基是一个带协方差的估计量，而不是真值）**
直觉：`SpatialCert` 默认 `TF_base→Cam` 精确。但腕部相机的 `T_gripper→cam` 来自手眼标定 `AX = XB`，它 (a) 有协方差 Σ_X，(b) 会随温漂/碰撞缓慢变化，(c) 在某些位姿激励不足时根本不可辨识。固定阈值 ε_vis 于是同时犯两类错：远处小角度误差被力臂放大成「违规」→ 误截断；近处真实违规被大阈值吞掉 → 漏检。正确做法是把 Σ_X 传播到残差上，得到**深度自适应阈值**：`ε(d) = ε₀ + k_σ·sqrt(σ_t² + d²σ_θ²)`。

**灵感 3（两者耦合 → 标定健康是状态机的正交维度，构成产品自动机）**
直觉：标定不是一个布尔量，而是有生命周期的（标定中 / 有效 / 漂移 / 不可辨识 / 失效）。把它做成一条独立的健康自动机 H，再与执行状态机 Q 做**乘积**，就得到「只有局势与标定都健康时才允许执行」的统一守卫。最危险的耦合是：标定已漂移、但 H 还没切走，而 Q 已在长块里执行——此时空间证书会系统性地偏，而且偏得「看起来自洽」。因此守卫必须是产品态的联合谓词，而不是两个独立判断的简单「与」。

## 1. 研究问题（本轮要回答什么）

- **Q1（状态机）**：把安全写成受守卫的转移不变式后，能否机械地证明「无证书不执行」，同时保证修复循环终止（无活锁）？
- **Q2（标定）**：手眼标定的协方差、漂移与可辨识性如何进入空间证书？固定阈值相比标定感知阈值，会造成多大的误截断/漏检？
- **Q3（耦合）**：当标定健康与执行状态做乘积，能否在不牺牲 50Hz 主路径的前提下，把「标定漂移 × 长块」的放大误差压回可界？

## 2. 三条设计原则（雏形，正式化见产物区定义 468–483）

**P1 证书守卫转移（Certificate-Guarded Transition）**
任何进入执行态（或执行态内部的下一步）的转移，都必须同时持有 `(G, K, S)` 三元组：接地证书、运动学证书、标定感知空间证书。安全是「转移关系上的不变式」，不是某行 `if`。

**P2 标定感知阈值（Calibration-Aware Threshold）**
阈值必须随深度 d 与标定协方差 Σ_X 变化；禁止使用与位姿无关的固定 ε_vis。标定的可辨识性（激励量 ξ）不足时，证书必须显式降级而不是假装有效。

**P3 良基修复（Well-Founded Repair）**
每条「重新规划」边都严格降低一个非负测度 μ（剩余盲区不确定质量 + 剩余预算的加权），从而保证修复-重规划循环终止，而不是在长块与短块之间来回抖动。

## 3. 与基线的接口（如何退化）

- `Σ_X → 0` 且 `H ≡ H_valid` 且阈值取常数 ⇒ 等价于第 4 轮 InstructGauge-WR 的静态 TF 假设；
- 状态机折叠为「单步 + 立即验证」⇒ 等价于 ToolGauge 逐步执行；
- 标定不可辨识（`ξ < ξ_min`）⇒ 冻结块长 `K=1` 或进入 `SafeHold`，退回单步安全模式；
- 任一证书缺失/失效 ⇒ 不进入执行态（不是「执行后补救」）；
- CalibGauge 失效 ⇒ InstructGauge-WR ⇒ ToolGauge；ToolGauge 失效 ⇒ LeanGauge ⇒ MODGAUGE。

## 4. 预期贡献

1. 一个**证书守卫的执行状态机**，把「无证书不执行」从人工审查升级为可模型检验的结构性质，并用良基测度证明修复循环终止；
2. 一个**标定感知空间证书**，把 `AX=XB` 的协方差、激励量与漂移检测传播进残差阈值，定量刻画固定阈值的误截断/漏检代价；
3. 一个**健康-执行产品自动机**，把「标定漂移 × 长块」从隐性放大压成联合守卫下的可界失效；
4. 一条完整可证伪路径：E473–E488 覆盖协方差传播、深度阈值、漂移检测、不可辨识处置、状态机安全性/终止性、退化等价与 50Hz 时序。

## 5. 本轮最大风险

**一句话**：整轮的可靠性其实系于「标定协方差 Σ_X 是否可信」——若 Σ_X 被低估（模型误差、非高斯、温漂非线性），标定感知阈值会自信地放行真实违规，产品自动机越优雅，错误放行就越隐蔽。

## 2. 形式化定义

**定义 468（手眼标定同余模型）** 给定成对位姿 `{(A_i, B_i)}_{i=1..n}`，求解
```
X* = argmin_{X ∈ SE(3)}  Σ_i || log( (A_i X) (X B_i)^{-1} ) ||²
```
以 Gauss-Newton 得 `X̂`；令 `J` 为堆叠残差对 `X` 的雅可比，则
```
Σ_X ≈ σ² (Jᵀ J)^{-1}
```

**定义 469（标定不确定半径）** 设特征深度 `d`（相机系下沿光轴距离），`k_σ` 为覆盖因子（如 3σ）。定义
```
ρ(d) = k_σ · sqrt( σ_t² + d² σ_θ² )
```
第一阶直觉：平移误差直接平移投影点，旋转误差 `δθ` 在力臂 `d` 处产生约 `d·δθ` 的位移，二者独立叠加。

**定义 470（标定感知阈值与一致性）**
```
ε(d) = ε₀ + ρ(d)
Consistent_t  ⇔  ||r_t|| ≤ ε(d_t)
```
其中 `r_t` 为第 t 帧的重投影/位姿残差，`d_t` 为该帧特征深度。当 `Σ_X = 0` 时 `ρ ≡ 0`，退化为固定阈值 `ε₀`。

**定义 471（标定激励与可辨识性）**
```
ξ = λ_min(Jᵀ J)
```
`ξ ≥ ξ_min` 才允许判定标定「可辨识」；否则在 `JᵀJ` 近零空间方向上 `X` 不可辨识，必须显式降级。

**定义 472（标定漂移检测）** 对残差超阈量做单边 CUSUM：
```
S_t = max(0, S_{t-1} + (||r_t|| - ε(d_t) - ν)),   S_0 = 0
```
`S_t > h` 触发 `H_valid → H_drifting`。

**定义 473（标定健康自动机 H）** `H = {H_calibrating, H_valid, H_drifting, H_unobservable, H_invalid}`，转移由 `(ξ, S_t, 重标定结果)` 守卫：
```
H_calibrating --ξ≥ξ_min--> H_valid
H_valid       --S_t>h-----> H_drifting
H_drifting    --重标定成功-> H_valid      （需 ξ≥ξ_min）
H_*           --ξ<ξ_min---> H_unobservable
H_*           --标定失败--> H_invalid
```

**定义 474（证书三元组）** 对块 `C`：
```
Cert(C) = (G, K, S) ∈ {⊥, weak, strong}³
```
`G`：接地/指代有效；`K`：`KinematicAdmissibleSet` 下前缀封闭成立；`S`：`∀t: Consistent_t` 且 `S_t ≤ h`。

**定义 475（证书强度偏序）** `Cert ⪰ Cert'` 当且仅当三分量逐项满足 `⪰`，其中 `strong ⪰ weak ⪰ ⊥`。安全要求 `Cert(C) ⪰ Cert_min`。

**定义 476（证书守卫执行状态机 Q）** `Q = {Idle, Grounded, Planned, Admitted, Executing, Verifying, Committed, Truncated, SafeHold}`，转移关系 `_Q→ ⊆ Q × E × Q`，每条边带守卫谓词 `φ`。

**定义 477（守卫转移语义）** 转移 `q --e[φ]→ q'` 可发生当且仅当
```
φ(σ, Cert) ∧ Inv(q')        （σ 为当前环境/标定快照）
```
安全不变式：`q = Executing ⇒ Cert ⪰ Cert_min`。特别地，`Admitted → Executing` 的守卫强制 `(G,K,S)` 全非 `⊥`。

**定义 478（块内微状态机）** `Executing` 细化为 `E_1 … E_K`；每个 `E_j --apply→ E_{j+1}` 之前重验 `Consistent_j`，失败则 `E_j --truncate→ Truncated`，随后 `Truncated --rollback/safe→ SafeHold`。这使「提前截断」成为一个显式转移而非跳出循环。

**定义 479（健康-执行产品自动机）** `P = Q × H`，转移
```
(q,h) --e[φ]→ (q',h')   当且仅当  q--e[φ₁]→q' ∧ h--e[φ₂]→h' ∧ (φ₁∧φ₂)
```
其中 `Admitted→Executing` 额外要求 `h ∈ {H_valid}`（`H_drifting` 只允许 `K=1`）。

**定义 480（良基修复测度）** 令 `U(s)` 为盲区剩余不确定质量、`B(s)` 为剩余预算，
```
μ(q) = α·U(s) + β·B(s),   α,β > 0
```
每条「重规划」边 `Planned → Planned` 必须满足 `μ(q') < μ(q)`；`μ ≥ 0` 且转移有限 ⇒ 修复循环终止。

**定义 481（标定感知空间证书）**
```
SCC(C) = ( TF_seq, {r_t}, {d_t}, Σ_X, ξ, H_snapshot, violations, coverage )
```

**定义 482（严格退化映射）**
```
Σ_X→0 ∧ H≡H_valid ∧ ε(d)≡ε₀ ∧ Q 折叠单步  ⇒  InstructGauge-WR ⇒ ToolGauge
```

**定义 483（回执映射）** 产品自动机的每条 `Admitted→Executing` 边对应一条 CVC 回执；`Truncated` 边对应带 `violations` 的 `SpatialCertMsg`，从而状态机的运行轨迹可被第 4 轮的 ROS 协议完整回放。

# IP-334 HandEye-Calibrator
class HandEyeCalibrator:
    def __init__(self, xi_min=1e-3, k_sigma=3.0):
        self.pairs = []            # [(A_i, B_i)]
        self.X_hat = np.eye(4)
        self.Sigma_X = None
        self.xi = 0.0
        self.xi_min = xi_min
        self.k_sigma = k_sigma

    def add_sample(self, A, B):
        self.pairs.append((A, B))

    def solve(self):
        """Gauss-Newton 解 AX=XB，并给出 Σ_X 与激励量 ξ"""
        X = self.X_hat.copy()
        J = []
        for _ in range(20):                     # LM/IRLS 迭代
            r, Jr = self._linearize_ax_xb(X)
            J.append(Jr)
            X = se3_retract(X, lstsq(np.vstack(J), -np.concatenate(r_list(self))))
        Jfull = np.vstack(J)
        self.X_hat = X
        self.Sigma_X = self._sigma2(Jfull) * np.linalg.inv(Jfull.T @ Jfull)
        self.xi = np.linalg.eigvalsh(Jfull.T @ Jfull)[0]
        return self.X_hat, self.Sigma_X, self.xi

    def covariance_components(self):
        s_t = float(np.sqrt(np.trace(self.Sigma_X[:3, :3]) / 3.0))
        R = self.Sigma_X[3:, 3:]
        s_th = float(np.sqrt(max(np.linalg.eigvalsh(R)[-1], 0.0)))
        return s_t, s_th

    def residual_bound(self, depth):
        s_t, s_th = self.covariance_components()
        return self.k_sigma * np.hypot(s_t, depth * s_th)

# IP-335 CalibHealth-FSM
class CalibHealthFSM:
    STATES = {"H_calibrating", "H_valid", "H_drifting",
              "H_unobservable", "H_invalid"}
    def __init__(self, xi_min, cusum_h=5.0, cusum_nu=0.0):
        self.h = "H_calibrating"
        self.S = 0.0
        self.xi_min, self.cusum_h, self.cusum_nu = xi_min, cusum_h, cusum_nu

    def update(self, xi, residuals, eps_at):
        self.S = max(0.0, self.S + (residuals - eps_at - self.cusum_nu))
        if xi < self.xi_min:
            self.h = "H_unobservable"
        elif self.h in ("H_calibrating", "H_unobservable") and xi >= self.xi_min:
            self.h = "H_valid"
        elif self.h == "H_valid" and self.S > self.cusum_h:
            self.h = "H_drifting"
        return self.h

def calib_aware_consistent(r_t, d_t, epsilon0, calib):
    eps = epsilon0 + calib.residual_bound(d_t)
    return norm(r_t) <= eps, eps

def make_spatial_calib_cert(block, tf_seq, depths, res, calib, health):

# IP-336 / IP-338 证书守卫 + 产品守卫
CERT_MIN = ("strong", "strong", "weak")

def cert_ok(cert, need=CERT_MIN):
    order = {"⊥": 0, "weak": 1, "strong": 2}
    return all(order[c] >= order[n] for c, n in zip(cert, need))

def product_guard(q, h, cert, full=True):
    """进入执行态的产品守卫：Q 与 H 联合判定"""
    if not cert_ok(cert):
        return False
    if not full:                       # 退化：忽略健康维度
        return True
    return h == "H_valid"              # H_drifting 仅允许 K=1，另行判定

class CertifiedExecFSM:
    def __init__(self):
        self.q = "Idle"
        self.edges = {
            ("Idle", "ground"): "Grounded",
            ("Grounded", "plan"): "Planned",
            ("Planned", "admit"): "Admitted",
            ("Admitted", "exec"): "Executing",
            ("Executing", "verify"): "Verifying",
            ("Verifying", "commit"): "Committed",
            ("Executing", "truncate"): "Truncated",
            ("Truncated", "safe"): "SafeHold",
        }

    def fire(self, event, cert, health, inv_holds=True):
        nxt = self.edges.get((self.q, event))
        if nxt is None:
            return self.q, False
        guard = (product_guard(self.q, health, cert)
                 if event in ("admit", "exec") else True)
        if guard and inv_holds:
            self.q = nxt
            return nxt, True
        return self.q, False

# IP-339 主闭环（异步修复，50Hz 主路径不变）
def calibgauge_repair(M, s, ell=None):
    iota = M.nlib.ground(ell, M.scene, M.ontology) if ell else M.default_iota
    H = M.lbox.hypothesize(s, M.dbox.R[s], iota)

    while True:
        C = M.iac.plan_chunk(iota, H, M.tools,
                             M.budget_left(s), M.drift_bound(s),
                             maxK=1 if M.health.state == "H_drifting" else None)
        # 1) 证书三元组
        G = "strong" if iota is not None else "⊥"
        K = "strong" if M.kloop.verify_prefix_closed(C)[0] else "weak"
        cert = (G, K, "weak")

        # 2) 产品守卫（Q × H），不通过则不进入执行
        if not product_guard("Planned", M.health.state, cert):
            M.fsm.q = "SafeHold"
            return C, None, []

        # 3) 执行 + 块内微状态机（标定感知阈值）
        for j, a in enumerate(C.actions):
            ok, eps = calib_aware_consistent(
                M.wristcam.residual(j), M.wristcam.depth(j),
                M.epsilon0, M.calib)
            M.health.update(M.calib.xi, M.wristcam.residual(j),
                            M.epsilon0 + M.calib.residual_bound(M.wristcam.depth(j)))
            M.fsm.fire("exec" if j == 0 else "verify", cert, M.health.state)
            if not ok or M.health.state in ("H_unobservable", "H_invalid"):
                C = C.truncate(j)
                M.fsm.fire("truncate", cert, M.health.state)
                M.fsm.fire("safe", cert, M.health.state)
                break
            M.env.apply(a)

        # 4) 良基测度：重规划必须严格下降
        mu_new = M.mu(s)
        if mu_new >= M.mu_prev:
            break                      # 触发终止，避免活锁
        M.mu_prev = mu_new

        sc = make_spatial_calib_cert(C, M.wristcam.tf_seq, M.wristcam.depths,
                                     M.wristcam.residuals, M.calib,
                                     M.health.state)
        M.ros_cvc.publish_cvc(C.id, len(C.actions), C.actions,
                              C.pre_conditions, C.post_conditions, [sc])
        return C, sc, bind_claims(C, iota, M.tcv.get_receipts())

def CalibGauge_round(M, obs, audio, tac, depth, det, ell=None):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s)
            spawn_async(calibgauge_repair, M, s, ell)
    return MODGAUGE_round(M, obs, audio, tac, depth, det)   # 50Hz 主路径不变

## 4. 推导

**引理 63（标定误差传播界）** 设残差对 `X` 局部 Lipschitz 常数为 `L`。若 `X̂` 满足 `||X̂ ⊖ X*|| ≤ δ`，则任意深度 `d` 的残差偏差满足 `| ||r(d)| - ||r*(d)| | ≤ L·(δ_t + d δ_θ) + O(δ²)`；取 `δ_t = k_σσ_t, δ_θ = k_σσ_θ` 即得 `ρ(d)` 的一阶上界。证明：对残差在 `X*` 处一阶展开，平移项系数为 1、旋转项系数为力臂 `d`，三角不等式合并。

**引理 64（阈值覆盖性）** 若标定误差近似高斯且 `Σ_X` 校准正确，则对任一帧，真实一致却被判违规（误截断）的概率 `≤ 2Φ(-k_σ)`；`k_σ=3` 时约 `0.27%`。证明：归一化残差超阈事件即标准化高斯尾事件；深度自适应阈值恰好把不同 `d` 的分布标准化到同一尾概率。

**引理 65（状态机安全性）** 在产品自动机 `P=Q×H` 上，若初始 `q₀ ≠ Executing` 且执行边均满足守卫，则对任意可达状态，`q = Executing ⇒ Cert ⪰ Cert_min ∧ h = H_valid`。证明：对转移步数归纳；唯一进入 `Executing` 的边 `Admitted→Executing` 被 `product_guard` 守卫，其余边不改变 `q=Executing` 的证书前提。

**引理 66（修复终止性）** 设 `μ: Q → [0, μ_max]`，每条重规划边严格满足 `μ(q') ≤ μ(q) - c`（`c>0`）。则任意重规划链长度 `≤ μ_max / c`，修复循环终止。证明：严格单调下降序列在有下界实数中有限。

**引理 67（严格退化等价）** 当 `Σ_X→0`、`H≡H_valid`、`ε(d)≡ε₀`、且 `Q` 折叠为单步即时验证时，CalibGauge 的守卫与阈值逐项退化为第 4 轮 InstructGauge-WR 的固定阈值与逐步 `joint_pre`；再折叠分块即退化为 ToolGauge。证明：逐条比对定义 469–482 在极限下与第 4 轮定义 448–452 的表达式。

**引理 68（不可辨识必降级）** 若 `ξ = λ_min(JᵀJ) < ξ_min`，则存在非零方向 `v` 使 `Jv ≈ 0`，`X` 在该方向不可辨识，`Σ_X` 在 `v` 上发散。此时任何有限 `ρ(d)` 都不可信，必须置 `H_unobservable` 并强制 `K=1` 或 `SafeHold`。证明：Fisher 信息矩阵奇异 ⇒ Cramér–Rao 下界在该方向无界。

**引理 69（块内证书单调性）** 在块 `C` 执行期间，若不变量 `Inv(Executing)` 成立且每步重验，则证书强度沿微状态机非增；一旦某分量降到 `⊥`，必在下一步 `apply` 之前发生 `Executing→Truncated`。证明：由定义 478 的边守卫与 `Inv` 归纳。

**引理 70（轨迹-CVC 回放等价）** 产品自动机的每条提交/截断轨迹，可唯一映射为第 4 轮 `CVC_Spec`/`SpatialCertMsg` 回执序列，且重放该序列可重建 `Q×H` 的转移序列。证明：由定义 483 的边-回执一一映射与定义 450 的消息唯一性。

## 8. 本轮最大风险

**一句话**：全轮的正确性都押在 `Σ_X` 的校准上——一旦协方差被低估（非高斯、温漂非线性、观测野值），标定感知阈值就会「自信地」放行真实违规，而产品自动机只会让这种放行看起来更合规、更难被发现；缓解是加大 `k_σ` + 分层共形校准 + 独立关节编码器冗余，但这会重新牺牲一部分提前截断的灵敏度。
