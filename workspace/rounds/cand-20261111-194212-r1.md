# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「奖励设计」×「人机交互」）

> 第 54 轮已把技能组合约束到「动作占用剖面 α_S + 鲁棒性谱 ρ + 云边映射 γ_ce」的三重可判定域，并用联合证书 J 保证动作-鲁棒性对齐。本轮追问一个此前被默认掉的问题：**值从哪来、由谁裁定、人类能否真的理解这份裁定**。核心矛盾：H22：奖励不是可加的全局标量，组合后代理奖励会与真实人类偏好系统性漂移，形成组合级 reward hacking，而现有证书只保动作与鲁棒性、不保「值」；H23：人类反馈是有带宽、有噪声、非平稳的标注信道，上一轮的 Explain 只是形式化反事实，未被证明「人类可理解」，导致形式上可解释、人类实际不可理解的假性对齐。

## 0. 直觉与动机

**灵感 1（奖励不是标量，而是动作空间上的偏好场）**
直觉：同一个技能在不同动作上「值得做」的程度不同——开门这个技能，轻推比猛推更值得。因此奖励应建模为与 α_S 同域的场 `r_S : A → ℝ`，并附置信 `ψ_S : A → [0,1]`。人类偏好只在这个场上留下带噪的成对样本。**奖励设计 = 指定偏好场的一致性结构**，而不是给整机一个全局数字；在场外（α_S≈0）谈奖励没有意义。

**灵感 2（组合会产生奖励漂移与奖励黑客）**
直觉：`r(S1⊗S2) ≠ r(S1)+r(S2)`。技能单独看都「友善」，组合后代理奖励可能被策略利用：代理分升高而真实人类偏好下降，即 **组合级 reward hacking**。因此技能组合图的边不能只查动作兼容与鲁棒性，必须加一条 **奖励绊线**：在共享动作区与留出的人类偏好查询上，比较代理奖励与真实偏好，超阈值即否决或回滚。

**灵感 3（人是有限带宽、非平稳的标注源）**
直觉：人机交互不能假设人类无限回答、永远一致。人类信道 `HC` 有容量 `C_h`、延迟 `τ_h`、标签噪声 `ε_h`、偏好漂移率 `ν_h` 与总预算 `B_h`。既然如此，就不该平均采样，而应做 **主动偏好查询**：把每一比特预算花在信息增益最大的动作对上；同时用折扣/滑窗与漂移检测处理非平稳，避免旧偏好污染新证书。

**灵感 4（从「可解释」升级为「可理解」）**
直觉：第 54 轮的 Explain 是形式化反事实（`Explain(sim_e) → ΔP_c`），但形式正确不等于人类看懂。需要 **可读性证书 L_cert**：用人类阅读解释后的理解准确率、阅读时间、以及人类后验与真实机制之间的 KL 来度量。解释的目标不是生成一段文本，而是 **改变人的后验**；改不动后验的解释在部署意义上等于没解释。

**灵感 5（云边奖励契约 + 人类仲裁闭环）**
直觉：云端设计全局奖励 `r_c` 并承诺价值目标，边端执行局部奖励 `r_e` 并实时监控 `Δr` 与 `H_R`；一旦越界，边端生成人类可读解释交给人类仲裁，人类裁决 `z_h` 回传云端触发重设计。形成 **云设计 - 边监控 - 人解释 - 人裁决 - 云重设计** 的闭环，人类成为价值争议的最终裁决者，而不是被动的标签机。

**灵感 6（金字塔第三层：奖励-交互层）**
直觉：在第 53 轮鲁棒性层 `𝕃` 与第 54 轮动作层 `𝔸` 之上叠加 **奖励-交互层 `ℝ`**：`ℝ_0` 物理价值极限（不可达成的目标）、`ℝ_1` 技能奖励场 `R_S`、`ℝ_2` 人类偏好信道 `HC`、`ℝ_3` 任务价值对齐。跨层传递证书需同时携带 `ρ`、`A_cert`、`R_cert` 与 `L_cert`，形成 **可解释的鲁棒性-动作-价值三证书体系**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（奖励剖面 / 偏好场）**
技能 `S` 的奖励剖面 `R_S = (r_S, ψ_S)`，其中 `r_S : A → ℝ` 为动作上的奖励强度，`ψ_S : A → [0,1]` 为奖励置信。真实人类偏好为动作对上的偏序 `r* : A × A → {≻, ≺, ~}`，对智能体不可直接观测。奖励只在动作占用域内有定义：`α_S(a) = 0 ⟹ R_S(a) = ⊥`。

**定义 122（奖励-动作一致性与可辨识域）**
奖励-动作一致性
```
coh(S) = ∫_A α_S(a)·ψ_S(a) da / ∫_A α_S(a) da
```
奖励可辨识域 `A_R(S) = { a ∈ A | α_S(a) ≥ θ_cov ∧ ψ_S(a) ≥ θ_ψ }`。**可辨识性约束**：仅当 `A_R(S) ≠ ∅` 且 `coh(S) ≥ θ_coh` 时，`r_S` 才允许参与组合；否则该技能的奖励视为未知，只能走保守奖励下界。

**定义 123（奖励兼容性与奖励黑客指数）**
两技能在共享动作区上的奖励兼容性
```
compat_R(S_i,S_j) = 1 - E_{a∈A_i∩A_j} [ |r_i(a)-r_j(a)| / (|r_i(a)|+|r_j(a)|+ε) ]
```
组合代理奖励 `r̂_comp = compose_reward(r_{S_1},...,r_{S_k})`；在留出的人类查询集 `Q_hold` 上估计真实偏好奖励 `r̂*_h`。**奖励黑客指数**
```
H_R(π_comp) = E_{a~π_comp} [ r̂_comp(a) - r̂*_h(a) ]_+
```
组合图边可判定条件在定义 116 基础上增加：`compat_R ≥ θ_R ∧ H_R ≤ Θ_H ∧ coh(S_i),coh(S_j) ≥ θ_coh`。

**定义 124（有界人类反馈信道）**
人类信道 `HC = (C_h, τ_h, ε_h, ν_h, B_h)`：单次查询容量上界 `C_h` bit，响应延迟 `τ_h`，标签噪声率 `ε_h`，偏好漂移率 `ν_h`（单位时间 KL），总交互预算 `B_h`。查询 `q=(a^+,a^-)` 的反馈
```
y_q = 1[ r*(a^+) ≻ r*(a^-) ] ⊕ Bern(ε_h)
```
且查询成本满足 `Σ_q cost(q) ≤ B_h`。信道是 **非平稳** 的：`r*_t` 随 `ν_h` 漂移，旧样本需按 `e^{-ν_h(t-t')}` 折扣。

**定义 125（主动偏好查询与可读性证书）**
在预算与容量约束下，查询选择为
```
q* = argmax_{q∈Q} IG(q) / cost(q),   IG(q) = I(r*; y_q | D_t)
```
其中 `D_t` 为截至 t 的偏好数据集。**可读性证书**
```
L_cert = (ℓ_leg, h_acc, τ_read)
```
`ℓ_leg = D_KL( P_h(· | E) || P_true(·) )` 为人类在解释 `E` 之后的后验与真实机制后验的 KL；`h_acc` 为解释后理解测验准确率；`τ_read` 为平均阅读时间。解释可读当且仅当 `ℓ_leg ≤ Θ_leg ∧ h_acc ≥ θ_acc ∧ τ_read ≤ τ_read_max`。

**定义 126（人机在环奖励契约与扩展联合证书）**
人机奖励契约
```
C_hl = (r_c, r_e, Δr, Q_h, Explain_h, L_cert)
```
- `r_c` 云端全局奖励，`r_e` 边端局部奖励；
- `Δr = sup_{a∈A_core} |r_c(a) - r_e(a)|` 为价值对齐误差；
- `Q_h` 人类查询日志，`Explain_h` 人类可读解释，`L_cert` 可读性证书。
扩展联合证书
```
J+ = (ρ, A_cert, R_cert, H_R, h_cert, evidence)
R_cert = (r̂_comp, A_R, compat_R, Δr),   h_cert = L_cert
```
**可部署条件**：`dom_{J+}(T)=in ∧ δ_a<Θ_a ∧ H_R≤Θ_H ∧ ℓ_leg≤Θ_leg ∧ h_acc≥θ_acc ∧ Σcost≤B_h`。

## 2. 关键算法 伪代码

### IP-121 RPF（Reward Profile Field）

```python
def reward_profile(skill, A_R, pref_model, action_profile):
    R = {}
    for a in A_R:
        if action_profile.get(a, 0.0) < theta_cov:
            R[a] = None                      # 域外：奖励无定义
            continue
        r, psi = pref_model.predict(a)       # 均值 + 置信
        R[a] = (r, psi)
    return R

def coherence(R, alpha, theta_psi=0.6):
    num = sum(alpha[a] * R[a][1] for a in R if R[a] and R[a][1] >= theta_psi)
    den = sum(alpha.values())
    return num / (den + 1e-9)
```

### IP-122 RHT（Reward Hacking Tripline）

```python
def reward_hacking_check(pi_comp, r_hat_comp, held_out_queries, Theta_H):
    diffs = []
    for (a_plus, a_minus, y) in held_out_queries:      # 留出的人类偏好
        r_h = estimate_human_reward(a_plus, a_minus, y)
        diffs.append(max(0.0, r_hat_comp(a_plus) - r_h))
    H_R = mean(diffs)
    if H_R > Theta_H:
        return ('reject', 'reward_hacking', H_R)
    return ('ok', H_R)
```

### IP-123 APE（Active Preference Elicitation under Budget）

```python
def active_query(D_t, Q_pool, HC, drift_rate):
    best, best_score = None, -inf
    for q in Q_pool:
        if q.cost > HC.remaining:
            continue
        ig = mutual_information(D_t, q) * exp(-drift_rate * q.age)
        score = ig / (q.cost + 1e-9)
        if score > best_score:
            best, best_score = q, score
    return best

def update_belief(D_t, q, y, HC):
    D_t.add(q, y, weight=1.0)                      # 新样本
    for s in D_t:                                  # 非平稳：旧样本折扣
        s.weight *= exp(-HC.nu * (now() - s.t))
    return D_t
```

### IP-124 LEG（Legibility Certificate）

```python
def legibility_certificate(explanation, user_study_or_model):
    post = user_study_or_model.posterior_after(explanation)
    true = user_study_or_model.true_mechanism_posterior()
    ell_leg = kl_divergence(post, true)
    h_acc = user_study_or_model.comprehension_accuracy()
    tau_read = user_study_or_model.mean_reading_time()
    return L_cert(ell_leg, h_acc, tau_read)
```

### IP-125 CERC（Cloud-Edge Reward Contract）

```python
def reward_contract(r_c, r_e, A_core, H_R, L_cert, budgets):
    delta_r = sup_abs_diff(r_c, r_e, A_core)
    if delta_r > budgets.delta_r:
        exp = human_explain(r_c, r_e, A_core, delta_r)   # 可读解释
        z_h = request_human_adjudication(exp)            # 人裁决
        return ('redesign', z_h, exp)
    if H_R > budgets.Theta_H:
        return ('reject', 'reward_hacking', H_R)
    if L_cert.ell_leg > budgets.Theta_leg or L_cert.h_acc < budgets.theta_acc:
        return ('reject', 'illegible_explanation', L_cert)
    return ('ok', R_cert(r_c, A_core, delta_r))
```

### IP-126 RJTC（Reward Joint Transfer Certificate）

```python
def reward_joint_transfer(J_plus_src, L_target, phi, budgets):
    R_cert = J_plus_src.R_cert
    r_target = transfer_reward(R_cert.r_hat, phi)
    delta_r = max_abs(r_target - R_cert.r_hat)
    H_R_hat = estimate_hacking_on_target(r_target, L_target, phi)
    if delta_r > budgets.delta_r or H_R_hat > budgets.Theta_H:
        return ('reject', 'reward_transfer_budget', delta_r, H_R_hat)
    if not domain_check_robust(J_plus_src.R, compute_action_domain(J_plus_src, phi, L_target)):
        return ('reject', 'domain_mismatch')
    return ('ok', TRC_JointPlus(J_plus_src, L_target, R_cert, delta_r, H_R_hat))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| RPF | O(|A_R|·d) | O(|A_R|) | 偏好模型校准、域外置空 |
| RHT | O(|Q_hold|·|π_comp|) | O(|Q_hold|) | 留出查询独立同分布、H_R 下界 |
| APE | O(|Q_pool|·|D|·d) | O(|D|) | 信息增益估计无偏、漂移折扣正确 |
| LEG | O(|E|·|H|) | O(|H|) | 人类后验可测、样本量足够 |
| CERC | O(|A_core| + |Q_h|) | O(|A_core|) | Δr 上确界可估、裁决闭环 |
| RJTC | O(|S|·|A| + |Q_hold|) | O(|A|) | 奖励迁移有界、H_R 可复核 |

**正确性定理（Human-in-the-Loop Reward Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 奖励剖面 `R_S` 由校准过的偏好模型给出，且在 `A_R(S)` 上 `|r_S - r*| ≤ ε_r`；**(A30)** 人类信道满足 `HC` 参数上界，标签噪声独立且 `ε_h < 1/2`；**(A31)** 主动查询在预算内使偏好估计误差以 `O(1/√n)` 收敛，且漂移被折扣因子正确跟踪；**(A32)** 可读性证书由独立人类样本测得，`ℓ_leg` 可辨识。
则组合部署成功概率
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
            - P(H_R>Θ_H) - P(ℓ_leg>Θ_leg) - ε_pref
```
其中 `ε_pref = P(|r̂*_h - r*| > ε_r)` 为偏好估计失败概率。关键：**先在动作可辨识域上定义奖励，再在组合图上加奖励绊线，最后用人类可读性证书封口**。

## 6. 本轮最大风险

**一句话**：把奖励设计与人机交互纳入证书，使技能组合从「动作-鲁棒性双证书」升级为「动作-鲁棒性-价值三证书」，但 `H_R` 与 `ℓ_leg` 均以人类留出查询为锚，一旦人类反馈被策略诱导（hacking 留出集）或偏好发生非平稳漂移，证书会用「人类已理解、人类已认可」的假象掩盖真实价值错位，故必须以 **隐藏留出集 + 漂移感知的偏好折扣 + 多群体独立可读性测量** 三重护栏，宁可把「人类认可」当作有时效、可撤销的证据，也不把它当作永久真理。

### IP-121 RPF

```python
def reward_profile(skill, A_R, pref_model, alpha, theta_cov=0.8):
    R = {}
    for a in A_R:
        if alpha.get(a, 0.0) < theta_cov:
            R[a] = None                         # 动作域外：奖励无定义
            continue
        r, psi = pref_model.predict(a)          # 后验均值 + 置信
        R[a] = (r, psi)
    return R

def coherence(R, alpha, theta_psi=0.6):
    num = sum(alpha[a] * R[a][1] for a in R if R[a] and R[a][1] >= theta_psi)
    den = sum(alpha.values())
    return num / (den + 1e-9)

def identifiable(S):
    return S.A_R != set() and coherence(S.R, S.alpha) >= theta_coh
```

### IP-122 RHT

```python
def reward_hacking_check(pi_comp, r_hat_comp, held_out_queries, Theta_H):
    # held_out_queries 由独立流程采集，策略不可探测
    diffs = []
    for (a_plus, a_minus, y) in held_out_queries:
        r_h = estimate_human_reward(a_plus, a_minus, y)
        diffs.append(max(0.0, r_hat_comp(a_plus) - r_h))
    H_R = mean(diffs)
    return ('reject','reward_hacking',H_R) if H_R > Theta_H else ('ok',H_R)
```

### IP-123 APE

```python
def active_query(D_t, Q_pool, HC, drift_rate):
    best, best_score = None, -inf
    for q in Q_pool:
        if q.cost > HC.remaining:
            continue
        ig = mutual_information(D_t, q) * exp(-drift_rate * q.age)
        score = ig / (q.cost + 1e-9)
        if score > best_score:
            best, best_score = q, score
    return best

def update_belief(D_t, q, y, HC):
    D_t.add(q, y, weight=1.0)
    for s in D_t:
        s.weight *= exp(-HC.nu * (now() - s.t))   # 非平稳折扣
    HC.remaining -= q.cost
    if drift_detected(D_t):                        # 漂移则重置锚点
        D_t.reanchor(recent_window=HC.window)
    return D_t
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| RPF | O(|A_R|·d) | O(|A_R|) | 域外置空、置信校准 |
| RHT | O(|Q_hold|·|π_comp|) | O(|Q_hold|) | 留出集独立、H_R 下界可估 |
| APE | O(|Q_pool|·|D|·d) | O(|D|) | 信息增益无偏、漂移折扣收敛 |
| LEG | O(|E|·|H|) | O(|H|) | 后验可测、样本量充分 |
| CERC | O(|A_core|+|Q_h|) | O(|A_core|) | Δr 可估、仲裁闭环终止 |
| RJTC | O(|S|·|A|+|Q_hold|) | O(|A|) | 奖励迁移有界、H_R 可复核 |

**正确性定理（Human-in-the-Loop Reward Soundness）**
假设第 54 轮 (A26)-(A28) 成立；**(A29)** `|r_S-r*|≤ε_r` 于 `A_R(S)`；**(A30)** 人类信道参数满足 `HC` 上界且 `ε_h<1/2`；**(A31)** 主动查询使偏好误差 `O(1/√n)` 收敛并跟踪漂移；**(A32)** `L_cert` 由独立人类样本测得。
则
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
            - P(H_R>Θ_H) - P(ℓ_leg>Θ_leg) - ε_pref
```
关键：**动作可辨识域先于奖励定义，奖励绊线先于组合采纳，可读性证书先于人类认可**。

## 5. 本轮最大风险

**一句话**：把奖励设计与人机交互纳入证书，使技能组合从「动作-鲁棒性双证书」升级为「动作-鲁棒性-价值三证书」，但 `H_R` 与 `ℓ_leg` 均以人类留出查询为锚，一旦人类反馈被策略诱导或偏好发生非平稳漂移，证书会用「人类已理解、人类已认可」的假象掩盖真实价值错位，故必须以 **隐藏留出集 + 漂移感知的偏好折扣 + 多群体独立可读性测量** 三重护栏，宁可把「人类认可」当作有时效、可撤销的证据，也不把它当作永久真理。
