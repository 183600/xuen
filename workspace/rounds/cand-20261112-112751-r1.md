# 第 59 轮（承接第 58 轮「可靠性×VLA」IP-139~144；本轮灵感：「仿真到现实迁移」×「仿真到现实」）

> 第 58 轮把 VLA 从"会说话的策略"降格为"可靠性未知、但可被独立核验的提议者"，用 VRC 的置信下界包络、SPAC 的证明携带行动、DRA 的多样性运行时保证、RLL/DFT 的共因账本把"自信"从授权里赶了出去。但它默认了一个更隐蔽的前提：**作为可靠性证据主要来源的仿真，本身是可信任的证人**。仿真便宜、可控、可重复，"在仿真里跑了十万次没坏"于是很容易被当作"现实里大概不会坏"。可仿真不是第二个现实，它是**我们自己假设的投影**：它与被认证的策略共享建模选择、奖励设计、训练分布，甚至共享同一个物理引擎。仿真给出的"成功"与被审查对象高度相关，仿真给出的"失败"却相对便宜且常是保守的。本轮把仿真从"认证者"降格为**不对称的证伪者 + 受现实锚点约束的迁移提议者**：用迁移契约给仿真证据上"迁移税"，用证伪不对称性规定仿真只能推翻、不能背书，用现实锚点给一整类场景"付清迁移税"，用仿真器多样性与伪影检测暴露盲区，用迁移信任阶梯把授权一级一级建在真实世界上。核心命题从"可分解、可监测、可切换的可靠性契约下的 VLA 行动"升级为 **"仿真只许证伪、现实锚点才许认证的迁移可信承诺"**。

核心矛盾：

- **H33（丰富 vs 相关）**：仿真能提供海量证据，但这些证据与被认证策略共享建模假设与训练分布；不独立的丰富只是把同一个错误重复很多遍。仿真的"成功"越便宜，越容易把共因失效伪装成统计显著性。
- **H34（平均 vs 最坏）**：域随机化优化的是随机化分布上的平均鲁棒性，安全需要的却是现实差距上的最坏情形；随机化分布不是现实的超集，更多随机化甚至可能掩盖一个从未被采样的脆弱角落。
- **H35（正证据 vs 负证据的不对称）**：仿真失败常能有效预警现实失败，仿真成功却远不足以证明现实安全。把二者对称使用，要么浪费稀缺现实探针去重复确认，要么让仿真成功悄悄变成承诺依据。
- **H36（校准 vs 双重计数）**：用现实数据校准仿真，再用校准后的仿真预测现实，同一条现实数据被算了两次；若不追踪证据来源与推导关系，"现实锚点"会凭空放大支持度。
- **H37（迁移 vs 非平稳）**：差距不是常数，它随磨损、载荷、季节、传感器老化与仿真版本漂移；一张迁移证书有半衰期，负迁移必须被在线检出并使整类锚点失效。
- **H38（数字孪生 vs 自证）**：用来认证策略的数字孪生，可能与被认证策略共享同一套物理假设；孪生的保真度若也由孪生自己评定，就回到第 58 轮刚拆掉的"自证"循环，只是换了一层外壳。

## 0. 直觉与动机

**灵感 1（仿真不是第二个现实，而是带我们假设的投影）**
直觉：把仿真当"便宜的现场"是 category error；它更像一张**由我们的物理假设绘制的海图**。海图能告诉你哪里可能有礁石（证伪），但不能因为海图上画着安全航线就保证现实无礁。差距应当被显式建模为一个**按能力、上下文、仿真版本、时间分账的场** `g_c(x,t)`，而不是一个全局的"sim-to-real 准确率"。

**灵感 2（灵感词重复两次 → 把闭环补全：real→sim→real）**
直觉：本轮灵感词出现两次，我们把它读成一个强制要求——**不能只谈 sim→real，必须同时谈 real→sim**。现实锚点把真实的少量测量"注入"仿真，给整类场景付清迁移税；仿真再把这笔信用迁移到大量未测场景。闭环的关键不是多跑仿真，而是**来源可追溯**：只允许现实的叶子节点产生独立证据权重，仿真是由锚点与假设推导出的"利息"，不能重复计入本金。

**灵感 3（证伪不对称 → 仿真当猎犬，不当法官）**
直觉：仿真最擅长的不是证明安全，而是**低成本地找出反例**。一个在仿真里被找到的失败，可能是伪影，但它至少值得一次现实核查；而一个仿真里的成功，最多说明"在当前假设下没问题"。因此证据方向必须不对称：`sim failure` 可以抬高现实风险下界、阻塞承诺、触发核查；`sim success` 只能作为提议或降低"仿真内部"的不确定性，**永远不能降低现实风险上界，也永远不能提升授权**。这把第 58 轮的"反自证"原则从模型解释推广到了整条仿真证据链。

**灵感 4（迁移税与现实锚点 → 差距有界证书）**
直觉：与其估计一个点值的 gap，不如给一个**有置信度的差距上界** `δ^U`，并把现实风险写成 `q_real^U ≤ q_sim + δ^U`（或用鲁棒 MDP 在最坏差距集合上取上确界）。现实锚点就是"缴税凭证"：一条真实配对观测可以在声明的同质类内把整类场景的 `δ^U` 降下来。锚点覆盖不到的角落，仿真证据税率近乎 100%——只能提议，不能承诺。

**灵感 5（仿真器多样性与伪影检测 → 分歧是廉价的不确定性探针）**
直觉：单一仿真器被策略"刷穿"时最危险，因为它内部自洽。多个**结构不同**的仿真器（不同接触模型/求解器/渲染/时延模型）之间的分歧 `D_S` 是一个可计算的分歧信号：分歧大处优先花现实探针，分歧小而现实又没锚定处则是**最危险的"共同自信区"**。但仿真器也可能共享代码与资产，必须像第 58 轮处理多模态一样过 CCRD 独立性检验，同源仿真器只算一个通道。

**灵感 6（合流 → 证据门增加"来源×迁移等级"两维）**
直觉：第 57~58 轮证据按类型分（EV-probe/visit/margin/xmodal/human，及可靠性证据）。本轮给每条证据再加两维：**来源** `src∈{real, anchor, sim}` 与**迁移等级** `T0..T3`。规则极简：`src=sim` 的正面证据在 `T<2` 时权重为 0；`src=anchor` 只能通过声明同质类迁移，且不得重复计数；`L2/不可逆` 承诺必须有 `src=real` 或 `T≥2` 的锚定证据，且没有未解决的证伪反例。

## 1. 形式化定义（增量：定义 145–150）

**定义 145（仿真到现实迁移契约 STR）** 能力 `c`、上下文 `x`、仿真版本 `s`。配对数据 `𝒟_pair={(ξ_i,y_i^sim,y_i^real)}`（场景/仿真结果/现实结果）。迁移状态
`g_c(x,t)=(δ̂_gap,δ_gap^U,u_gap,n_pair,s,r_sim,drift_twin,cov_anchor,τ_anchor)`，
其中 `δ_gap^U` 是在声明同质类内、以 `1−α_gap` 置信度成立的差距上界，`u_gap` 是其估计不确定度，`r_sim` 为随机化分布描述，`drift_twin` 为孪生漂移统计量。**迁移包络**
`E_transfer(c,t)={x: δ_gap^U(x)≤δ_max ∧ u_gap(x)≤u_max ∧ drift_twin≤δ_twin ∧ cov_anchor(x)≥γ_a ∧ artifact_free(x)}`。
现实风险界：`q_real^U(x)≤min{1, q_sim^U(x)+δ_gap^U(x)}`（差距可加模型）或鲁棒 MDP 形式 `q_real^U=sup_{M∈U(g)}q_M`。**包络外或有任何仿真版本变更/孪生重校准/负迁移检出时进入迁移烧机期**：所有基于旧版本的正面证据失效，锚点需重新验证，`T` 级回落至 `T0`。

**定义 146（仿真证伪不对称 SFA）** 仿真结果到现实证据的迁移算子
`T_sim(e_sim)∈{falsify,proposal,none}`。**不对称公理**：(A) `e_sim=success` 只能产生 `proposal`，不得降低 `q_real^U`、不得提高迁移信任级、不得充当任何证据门的正面证据；(B) `e_sim=fail` 若通过伪影判定，产生 `falsify`，可抬高 `q_real^L`、阻塞该锚点类内的承诺、或触发一次现实/独立见证核查；(C) 伪影可疑时产生 `none`，连证伪也不采信。**证伪记录** `ℱ={(ξ,e_sim,artifact_class,status)}`，`status∈{open,reproduced,artifact}`；类内存在 `open` 反例时该类的正面承诺一律拒绝。对抗仿真目标是 `max_ξ q_sim(ξ)`（找失败），不是 `E_ξ[q_sim]`（刷平均）。

**定义 147（差距有界证书 GBC）** 差距模糊集 `U(g)={M_real: d(M_real,M_sim)≤δ_gap^U}`，`d` 为动力学/观测/奖励上的传输度量或参数 Lipschitz 度量。**鲁棒证书** `q_real^U(π)=sup_{M∈U(g)}q_M(π)`，可用区间值迭代/敏感性上界近似；若 `q` 关于差距参数 `L`-Lipschitz，则退化为可加界 `q_real^U≤q_sim+L·δ_gap^U`。`δ_gap^U` 由**配对共形**给出：对同质类内残差 `{|y^real−y^sim|}` 取 `(1−α_gap)` 分位并加有限样本修正，要求类内可交换或慢漂移。证书 `J_t=(g,δ_gap^U,U(g),π,anchors,provenance,n_eff,artifact_log,sim_versions)` 记录全部假设与来源。

**定义 148（现实锚点协议与迁移覆盖 RAP）** 锚点 `a=(C_a,y_a,ŷ_a,res_a,expiry_a)`，`C_a` 为声明的同质场景类。**迁移覆盖** `cov_anchor(x)=P_{ξ∼class(x)}[y(ξ) 由锚点集在声明不变性下确定]`，聚合为 `cov_anchor`。**来源 DAG** `P=(V,E)`：节点是证据项，边表示"由……推导"；独立证据权重只在**现实叶子节点**上计数，仿真预测是锚点与假设的确定性/随机性推导，其权重为 `n_eff(P)=|leaves_real(P)|`，不得再次计入。准入规则：仿真正面证据只有在 `cov_anchor≥γ_a` 且 `n_eff(P)≥1` 时才可迁移到该类；否则权重为 0。**锚点漂移**：若现实残差超过 `δ_gap^U`，整类锚点失效并降级，而不是逐点修补。

**定义 149（仿真器多样性与伪影检测 SED）** 结构仿真器集 `S={s_1,…,s_K}`，通道须过 CCRD 独立性检验（共享物理引擎/资产/奖励代码的合并为一个通道）。分歧 `D_S(x)=Σ_{k<k'}TV(q_{s_k}(·|x),q_{s_k'}(·|x))`，经锚点校准后作为迁移不确定性的**下界代理**与探针采集函数，不作为认证依据。**伪影检测器** `Art` 标注已知仿真伪影（无时延、理想摩擦、无变形、确定性接触、完美感知、可穿透碰撞），若策略收益依赖这些伪影，则标记 `sim_exploiting`，从所有正面证据中剔除，并优先安排现实核查。

**定义 150（迁移治理承诺与信任阶梯 TRC）** 对能力-上下文对定义迁移信任级 `T∈{T0,T1,T2,T3}`：`T0` 仅仿真（只可提议/证伪）；`T1` 仿真且伪影检测通过；`T2` 锚定（`cov_anchor≥γ_a` 且差距界有效）；`T3` 现实验证（`n_real≥N_T` 且无 open 反例）。**升级**只能由新增现实锚点/配对探针触发，且有界速率 `Δ_T/T`；**降级实时**：负迁移（现实残差超界）、孪生漂移、伪影检出、仿真版本变更立即降级。**承诺门**：`L2/不可逆` 需要 `src=real` 或 `T≥2` 且无 open 反例；`src=sim` 的正面证据在任何等级都不足以单独承诺。**差距导向 VOI**：
`VOI_tr(p)=E[ΔRiskBound 或 ΔH(g) 或 Δcov_anchor]−cost(p)`，
优先在"仿真高自信 ∧ 锚点覆盖低 ∧ 后果重"的危险象限花现实探针。

## 2. 关键算法伪代码

```python
def transfer_contract(c, x, sim, pair_data):          # IP-145
    g = gap_state(c, x, sim, pair_data)                # δ_U,u_gap,anchors,drift
    if sim.version_changed() or twin_drift(g):
        g = reanchor_and_burn_in(g)                    # 旧正面证据全部失效
    return g

def sim_evidence(e_sim, g, art):                       # IP-146 不对称
    if art.suspect(e_sim): return ('none', 'sim_artifact')
    if e_sim.outcome == 'fail': return ('falsify', e_sim)
    return ('proposal', e_sim)                          # 成功永不背书

def gap_bounded_certificate(pi, sim, g, anchors):      # IP-147
    delta_U = paired_conformal(g.residuals, alpha=alpha_gap)
    q_sim_U = robust_sim_risk(pi, sim, g.ambiguity)
    q_real_U = min(1.0, q_sim_U + delta_U)              # 或 sup_{M in U(g)}
    prov = provenance_dag(anchors, g.residuals)
    return q_real_U, delta_U, prov

def transfer_gate(c, x, g, anchors, prov, level):      # IP-148/150
    if not in_transfer_envelope(g, x): return 'reject'
    if open_counterexample(c, x): return 'reject'
    if level in ('L1', 'L2') and \
       (transport_coverage(x, anchors) < gamma_a or n_eff(prov) == 0):
        return 'reality_probe_required'
    return 'ok'

def gap_directed_probe(cands, g, anchors, cost):       # 现实探针按危险象限定价
    return argmax(cands, key=lambda p: voi_transfer(p, g, anchors) - cost(p))
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| STR | O(1) 查询；O(\|𝒟_pair\|) 重估 | O(\|C\|·\|X\|) | 差距界诚实、漂移检出、版本变更即烧机 |
| SFA | O(\|ℱ\|) 反例检索 | O(\|ℱ\|) | 只许证伪、伪影可判、open 反例阻塞 |
| GBC | O(\|S\|·d_M) 鲁棒求界 | O(\|𝒟_pair\|) | 配对可交换、模糊集包含现实、Lipschitz 界有效 |
| RAP | O(\|A\|) 覆盖/来源查询 | O(\|A\|+\|P\|) | 覆盖诚实、来源 DAG 完整、叶子计数不重复 |
| SED | O(K²·d_q) 分歧 | O(K²) | 同源仿真器合并、伪影检测健全 |
| TRC | O(\|CP\|·(\|p\|+C_VOI)) | O(\|V\|+\|σ\|) | 升级靠锚点、降级实时、四态完备 |

**正确性定理（Transfer-Governed Soundness, TGS 概要）**：在 A22–A44 基础上增加 **(A45)** 配对残差在声明同质类内可交换或慢漂移，`δ_gap^U` 以 `1−α_gap` 覆盖真实差距，模糊集 `U(g)` 包含现实 MDP；**(A46)** 证伪不对称被执行：仿真成功从不进入正面证据，仿真失败经伪影判定后才可计为证伪，伪影误判率 `≤δ_fp`；**(A47)** 锚点覆盖声明诚实，来源 DAG 完整，独立证据只在现实叶子上计数；**(A48)** 仿真器结构多样性经 CCRD 检验，共享组件合并，`D_S` 经锚点校准；**(A49)** 仿真版本/孪生/现实漂移可检出，检出后烧机并使旧证书失效；**(A50)** 迁移治理升级只经现实锚点、降级实时，仿真自信无法扩大包络。则：

1. **迁移健全性**：包络内 `q_real^U≤q_sim^U+δ_gap^U`（或鲁棒上确界），现实承诺失效率 `≤q_real^U+δ_fp+δ_artifact`；包络外仿真只能产生 `proposal/falsify`，正面证据权重为 0。
2. **证伪不对称单调性**：增加任意数量仿真成功不降低 `q_real^U`、不提高 `T`、不减少所需现实锚点；增加仿真失败只可能抬高 `q_real^L`、增加阻塞或触发核查，不能降低风险上界。
3. **来源不重复计数**：一条现实观测的独立权重至多计一次；锚点迁移只降低同质类的差距界，不制造新的独立证人；`n_eff(P)` 随现实叶子数增长，不随仿真运行次数增长。
4. **迁移信任单调性**：升级需新增现实锚点且有界速率；负迁移、孪生漂移、伪影、版本变更实时降级；`T0/T1` 永不满足 `L2/不可逆` 的正面证据要求。
5. **终止性**：差距导向 VOI 在 `k_probes_real+k_probes_sim` 与维护预算内终止于 {承诺, 补锚点, 退回基线, 安全停}。

**部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp [ q_sim^U + δ_gap^U + δ_fp + δ_artifact + q_C + q_G ]
             − P(差距界失效) − P(负迁移未检出) − P(来源 DAG 双重计数)
             − P(仿真器共因未合并) − P(治理器切换失败 ∧ 安全停失效)
```

关键：**仿真给效率与反例、锚点给信用、现实给认证**；差距界把"仿真到现实"从口号变成可审计的上界；证伪不对称把仿真从法官降为猎犬；来源 DAG 保证校准数据不被二次计息。

## 6. 本轮最大风险

**一句话**：本轮最大的风险是"迁移自证"——如果差距界与锚点是在被同一策略/孪生选出的场景上估计的，或者现实数据在注入仿真后又被当作仿真证据二次计息，那么 sim-to-real 收敛会变成一间共享偏见的回音室，迁移包络恰恰会在仿真与策略共同盲区处开得最大；必须以"仿真只许证伪、来源 DAG 不重复计息、差距界由预注册的独立配对探针给出"三重护栏，宁可让包络窄而慢，也不让仿真成功变成现实承诺。

def add_anchor(anchor, cls, real_obs, sim_pred):
    a = Anchor(cls=cls, y_real=real_obs, y_sim=sim_pred,
               residual=dist(real_obs, sim_pred), expiry=now()+HALF_LIFE(cls))

def transport_coverage(x, anchors):
    cls = transport_class(x)
    if not anchors.valid(cls): return 0.0
    # 在声明不变性下，该类场景结果由锚点确定的比例（经验估计 + 保守下界）
    return lower_confidence(frac_determined(x, anchors[cls]), alpha=alpha_cov)

def provenance_dag(anchors, residuals):
    # 仿真预测节点只从 {假设节点, 锚点节点} 推导；真实观测是叶子
    P = DAG()
    for a in anchors:
        P.add_leaf(('real', a.id), weight=1)
        P.add_node(('sim', a.id), parents=[('real', a.id), ('assumption', a.cls)])
    return P

def n_eff(P):
    return len({v for v in P.leaves() if v.src == 'real'})   # 仿真运行次数不增权重

def invalidate_class(cls, reason):
    # 锚点漂移：整类失效，不做逐点幸存者修补
    for a in index[cls]:
        if residual_exceeds(a, reason.delta_U):
            mark_expired(a)
    demote_trust(cls, to='T0')

def trust_update(cls, new_anchor, g, neg_transfer=False):

        return demote(cls, to='T0')                  # 降级实时

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| STR | O(1) 查询；O(\|𝒟_pair\|) 重估 | O(\|C\|·\|X\|) | 差距界诚实、漂移检出、版本变更即烧机（A45/A49） |
| SFA | O(\|ℱ\|) 反例检索；O(budget) 对抗搜索 | O(\|ℱ\|) | 只许证伪、伪影可判、open 反例阻塞（A46） |
| GBC | O(\|S\|·d_M) 鲁棒求界 | O(\|𝒟_pair\|) | 配对可交换、模糊集包含现实、Lipschitz 界有效（A45） |
| RAP | O(\|A\|) 覆盖/来源查询 | O(\|A\|+\|P\|) | 覆盖诚实、来源 DAG 完整、叶子计数不重复（A47） |
| SED | O(K²·d_q) 分歧 | O(K²) | 同源仿真器合并、伪影检测健全（A48） |
| TRC | O(\|CP\|·(\|m\|+C_VOI)) | O(\|V\|+\|σ\|) | 升级靠锚点、降级实时、四态完备（A50） |

**正确性定理（Transfer-Governed Soundness, TGS）**
假设 A22–A44（第 53–58 轮）成立；**(A45)** 配对残差在声明同质类内可交换或慢漂移，`δ_gap^U` 以 `1−α_gap` 覆盖真实差距，模糊集 `U(g)` 包含现实 MDP（差距可加或 Lipschitz 界成立）；**(A46)** 证伪不对称被执行：仿真成功从不进入正面证据，仿真失败经伪影判定后才可计为证伪，伪影误判率 `≤δ_fp`；**(A47)** 锚点覆盖声明诚实，来源 DAG 完整，独立证据只在现实叶子上计数；**(A48)** 仿真器结构多样性经 CCRD 检验，共享组件合并，`D_S` 仅在锚点上校准且只作采集代理；**(A49)** 仿真版本/孪生/现实漂移可检出，检出后进入烧机并使旧证书失效；**(A50)** 迁移治理升级只经现实锚点、降级实时，仿真自信无法扩大包络。则：

1. **迁移健全性**：包络内 `q_real^U≤q_sim^U+δ_gap^U`（或 `sup_{M∈U(g)}q_M`），现实承诺失效率 `≤q_real^U+δ_fp+δ_artifact`；包络外仿真只能产生 `proposal/falsify`，正面证据权重为 0。
2. **证伪不对称单调性**：增加任意数量仿真成功不降低 `q_real^U`、不提高 `T`、不减少所需现实锚点；增加仿真失败只可能抬高 `q_real^L`、增加阻塞或触发核查，不能降低风险上界。
3. **来源不重复计数**：一条现实观测的独立权重至多计一次；锚点迁移只降低同质类差距界，不制造新独立证人；`n_eff(P)` 随现实叶子数增长，不随仿真运行次数增长。
4. **迁移信任单调性**：升级需新增现实锚点且有界速率 `Δ_T/T`；负迁移、孪生漂移、伪影、版本变更实时降级；`T0/T1` 永不满足 `L2/不可逆` 的正面证据要求。
5. **终止性**：差距导向 VOI 在 `k_probes_real+k_probes_sim` 与维护预算内终止于 {承诺, 补锚点, 退回基线, 安全停}。

**部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp [ q_sim^U + δ_gap^U + δ_fp + δ_artifact + q_C + q_G ]
             − P(差距界失效) − P(负迁移未检出) − P(来源 DAG 双重计数)
             − P(仿真器共因未合并) − P(治理器切换失败 ∧ 安全停失效)
```

关键：**仿真给效率与反例、锚点给信用、现实给认证**；差距界把"仿真到现实"从调参经验变成可审计上界；证伪不对称把仿真从法官降为猎犬；来源 DAG 保证校准数据不被二次计息。

## 6. 本轮最大风险

**一句话**：本轮最大的风险是"迁移自证"——如果差距界与锚点是在被同一策略/孪生选出的场景上估计的，或者现实数据在注入仿真后又被当作仿真证据二次计息，那么 sim-to-real 收敛会变成一间共享偏见的回音室，迁移包络恰恰会在仿真与策略共同盲区处开得最大；必须以"仿真只许证伪、来源 DAG 不重复计息、差距界由预注册的独立配对探针给出"三重护栏，宁可让包络窄而慢，也不让仿真成功变成现实承诺。
