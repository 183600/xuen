# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感：「轻量化结构」×「技术路线图」）

> R69 用流匹配与主动交互问出「我该向谁求证、还能问什么」，把不确定性一分为二，是本轮之前最完整的一层。但它也把闭环推到 309 条定义、十余个在线模块、3.4ms 的歧义路径——**每轮只加层，从不卸载**。这留下三重债：(i) 实时预算与验证负担随轮数单调增长；(ii) 信任面膨胀，任一层的校准失效都能把「已验证」变成「被证实的错误」；(iii) 研究循环没有「进度」概念，答不出「现在到哪一级、下一步建什么、什么该退役」。
>
> 本轮两个灵感是两把手术刀：
> - **轻量化结构**：真正的轻不是把每个部件做小，而是做**拓扑优化**——找承重路径、删零力杆、只在单点失效会塌处保留冗余。对应：对 69 轮模块图做承重分析，把**唯一安全证据**压到最小认证脊，其余降为条件支路；用**降阶认证包络**替代在线全量模态分解。
> - **技术路线图**：工程计划不靠「下轮再加什么」，而靠成熟度阶梯、门禁、依赖 DAG 与**退役/抵消**。对应：把 R1–R69 的 IP 编成路线图，新增组件必须用退役/吸收等价质量来付费。
>
> 核心命题：**R70 不再加能力层，而是对 69 轮语料做一次「承重拓扑 + 路线图治理」的轻量化重构**：在保持 R69 证书不弱化的前提下，把常路径压到最小认证脊，把昂贵路径降为条件支路，并用成熟度阶梯与复杂度账本约束未来演化。命名 **LEAN-RAS**（Lightweight Evidence-preserving Architecture-pruned, Roadmap-governed RAS）。
>
> 一句话定位：R66 问「谁控制」，R67「未来怎样」，R68「测量还准吗」，R69「该向谁求证」；R70 问「**这些层里哪些真正承重、哪些该拆掉，下一步该建在哪一级**」——从「加能力」转向「保承重」。

## 0. 直觉与动机

**灵感 1（轻量化结构 → 闭环也有承重拓扑）**
直觉：桁架不是越粗越安全。给定载荷，多数杆的应力为零或可被替代；真正决定塌不塌的是少数**承重路径**。工程做法是拓扑优化：删零力杆、合并共线杆、在单点失效会引发连锁倒塌处保留**失效安全冗余**。69 轮的 RAS 闭环正是一座未经拓扑优化的桁架：MTM、COF、EFS、ACH、VISTA、C-RAS-WM、PI-Σ、FMP、AUD、MINT、CIA、FMA、VQAuditor、MCG 层层叠加，很多模块在常见工况下对**认证风险上界**的边际贡献为零，却都在关键路径上消耗延迟与信任预算。于是「轻量化」不是把网络做小，而是**先问每个模块是否承重**：承重 = 去掉它认证风险上界会变差；零载 = 去掉它证书不变。零载模块可删或降为异步；承重模块形成认证脊；只有单点失效会击穿脊的地方才保留冗余（如 FMA 之于 COF 的第二意见）。
这里有一个必须警惕的结构陷阱：**不能贪心逐一删除**。三根杆互为备用时，每根单独看都是零载，一起删却会塌（循环冗余）。因此 STO 必须解**全局最小证据覆盖**，而不是对每个模块独立做「去掉试试」。

**灵感 2（降阶模型 → 用「有证书的近似」替代全量计算）**
直觉：结构工程从不每次都做全尺寸有限元；它用降阶模型/影响线，并给出误差界。R69 的在线全量模态分解（K 采样 + 轨迹聚类 + Hutchinson）就是一次全尺寸有限元。但大部分时间歧义要么明显存在、要么明显不存在，只有边界地带需要精确解。于是构造**降阶模态骨架**：离线学到低秩模态流形与区间误差界；在线只算廉价投影与上下界。若上界已低于「可忽略」，直接走脊；若下界已高于「必须交互」，直接走全量；只有**包络跨越阈值**时才回退全量 FLUID。这把「可信」从「相信流模型的精确模态权重」换成「相信一个可被监控的误差界」——正好回应 R69 的最大风险。

**灵感 3（技术路线图 → 研究循环需要「进度」而非「层数」）**
直觉：技术路线图的价值不在列出所有想做的事，而在三件事：**成熟度阶梯**（现在能做什么、下一级需要什么）、**门禁**（证书没闭合不许升级）、**依赖与退役**（哪些是前置、哪些是弯路、哪些该停止维护）。69 轮语料缺的正是这三件：定义只增不减，新层总是「并列替代」而非「吸收退休」，没人回答「这轮让系统升了哪一级」。R70 把路线图形式化为：能力阶梯 L0–L5、每级退出证书、IP 依赖 DAG、复杂度账本与债务预算。规则很硬：**任一新增组件必须说明它推进了哪一级，并用退役/吸收等价的质量付费**；否则不许进入认证脊。

**灵感 4（两者相乘 → 轻量必须被路线图「限定有效期」）**
直觉：轻量结构最怕的不是算错，而是**载荷变了而模型没变**：按旧载荷优化出的桁架，在新工况下可能恰好删掉了真正的承重杆。因此「轻」必须带**资格包络**：降阶骨架只在某个工况/分布域内被认证；一旦在线监控发现越界（漂移、OOD、FMA 上升），立即**吊销轻量证书、退回全量栈**，并触发复qualification 与路线图重规划。路线图在此不只是计划文档，而是**轻量的有效期与复检机制**：没有复检的轻量化是静默失载。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（LEAN-RAS 总览）** LEAN-RAS = (STO, ROCE, SBS, RMG, CL, RQ, RAS-WM‡, Φ_LEAN)。四不变式：
(i) **安全不弱化**：任一在线决策的认证风险上界 ≤ R69 FLUID-RAS 在相同观测下的上界；
(ii) **承重不可删**：认证脊内模块不得被 STO 删除，除非提供等价证书替换；
(iii) **轻量限域**：ROCE 仅在资格包络 𝒬 内有效，越界即吊销并回退全量；
(iv) **演化付费**：任何新增在线组件必须从 CL 中退役/吸收等价质量，否则不得进入认证脊。

**定义 311（模块图与唯一证据）** 模块图 G = (V, E)，v ∈ V 为在线计算单元，e = (u→v) 表示 v 的证书依赖 u 的输出。对每个 v 定义唯一证据集 E_v = Evidence(v) \ ⋃_{u≠v} Evidence(u)，即去掉 v 后其余模块无法提供的证据；D(v) ⊆ V 为证书依赖闭包。

**定义 312（结构载荷）** 在运行包络 𝒪 与故障集 ℱ 上，模块 v 的载荷
L(v) = sup_{o∈𝒪, f∈ℱ} [ R_cert(G \ {v}; o, f) − R_cert(G; o, f) ]_+，
即删除 v 后认证风险上界的最大恶化量。L(v)=0 ⇔ v 为零载模块（其证据被其余模块蕴含，或对最坏风险无贡献）。

**定义 313（承重拓扑与剪枝证书）** 认证脊 S* = MinimalCover{E_v ≠ ∅} ∪ S_fault，其中 S_fault 为满足 k-故障冗余约束（定义 314）所需的最小补集。剪枝算子 Prune: G ↦ G|S*。剪枝证书 J_topo = (S*, {L(v)}, redundancy_witness, topo_hash)，断言 R_cert(G|S*) = R_cert(G) 且 S* 满足 k-故障冗余。**MinimalCover 是全局覆盖，不是逐点贪心删除**（见定义 313′）。

**定义 313′（循环冗余反例与全局解）** 若三个模块的证据集两两可互相替代（E_i ⊆ E_j ∪ E_k 等），逐点删除会把三者全删而失载。STO 因而求解集合覆盖：S* = argmin_{S⊆V} |S| s.t. ⋃_{v∈S} E_v = ⋃_{v∈V} E_v 且 S 满足 k-故障约束。循环冗余在图上表现为交替负载路径，必须整环保留一条。

**定义 314（结构冗余 vs 功能冗余）** 结构冗余 = 常见工况下可删的重复计算（由 STO 删除）；功能冗余 = 单点故障下才启用的独立证据通道（必须保留，如 COF 失效时 FMA 的第二意见、标定不可吸收通道）。k-故障约束：对 ℱ 中任一小基数故障子集 F（|F| ≤ k），剩余图仍存在至少一条通往 S_fault 的认证路径。

**定义 315（认证脊/条件支路 SBS）** 在线模块分为脊 V_sp（每周期必跑，构成 z→风险→认证→执行的最小链）与支路 V_br（条件触发：K=4 采样、LLM 解码、全量 Hutchinson、VQ 审计）。SBS 调度规则：支路只在 (a) ROCE 包络不确定、(b) FMA 异常、(c) 复qualification 期间触发；其余走脊，保证常路径最轻。

**定义 316（降阶模态骨架）** 离线在模态流形上学习秩-r 骨架 B_r = {b_1,…,b_r}，以及从廉价特征 φ(o) 到模态权重/熵的低秩映射：Ĥ_mode = f_r(φ(o))，Δ̂_min = g_r(φ(o))。骨架带残差界 ε_r（由离线留出集与覆盖半径给出）。r 与 ε_r 的折中即轻量化的「截面尺寸」。

**定义 317（认证区间包络 ROCE）** 在线输出区间 [H_lo, H_hi] ∋ H_mode 与 [Δ_lo, Δ_hi] ∋ Δ_min，满足 P(真值 ∈ 区间) ≥ 1−δ_q。由区间导出 U_epi 的保守上下界：U_epi^hi = H_hi·g(Δ_lo)，U_epi^lo = H_lo·g(Δ_hi)。注意上界用「最大熵 × 最小间距」，下界反之，保证序关系单调。

**定义 318（资格包络 𝒬）** 𝒬 = {o : ε_r(o) ≤ ε̄ ∧ d(o, D_train) ≤ d̄ ∧ FMA(o) ≤ τ_fma}。𝒬 是 ROCE 的有效域；证书记录 𝒬 的哈希与版本。**轻量只在 𝒬 内被认证。**

**定义 319（区间三分与回退）** 设交互阈值 τ_epi。若 U_epi^hi ≤ τ_epi：判定「无需交互」，走脊；若 U_epi^lo > τ_epi：判定「确定有歧义」，走 R69 全量 MINT；若区间跨越 τ_epi：判「不确定」，回退全量 FMP 且本周期不做轻量加速。三分保证轻量从不改变「确定」情形的安全性。

**定义 320（复杂度账本 CL）** 每个模块 v 记质量 m(v) = (t(v), mem(v), τ_trust(v))，其中 τ_trust 为需独立验证的接口/假设数。总质量 M(G) = Σ_v m(v)（按危险度加权）。账本只追加，记录每轮的加入、退役、吸收。

**定义 321（债务预算与演化规则）** 阶段 p 的债务预算 D_p。新增组件 Δ 必须满足 m(Δ) ≤ D_p + Σ_{v∈Retire_p} m(v) + m(absorbed)，即**付费入场**；否则只能进支路、不得进脊。退休必须附「证据等价」证明（被吸收或不再需要）。

**定义 322（能力成熟度阶梯 L0–L5）** L0 开环控制；L1 安全包络（C-RAS-WM/PI-Σ）；L2 预测世界模型（VISTA/WM）；L3 测量可信（COF/EFS/校准）；L4 交互消歧（FLUID/FMP/MINT）；L5 架构治理（STO/ROCE/RMG/CL/RQ，本轮到）。每级由一组**闭合不变式**定义，升级 = 该级所有不变式均有证书。

**定义 323（相门与路线图证书）** 相门 Gate_{Lk→Lk+1} = (Cin_1..Cin_m)，每项为一个可判定谓词（证书 Valid、实验门槛、故障注入通过、债务非负）。路线图证书 J_road = (rung, gate_witnesses, DAG_hash, D_p, debt_balance, next_phase_plan)。

**定义 324（IP 依赖 DAG 与关键路径）** 节点为 IP/组件，边为「证书前置」。路线图是 DAG 而非列表：只有入度为 0 的未建节点可开工；关键路径 = 最长证书链；松弛 = 可并行或可退役的余量。**退役也是 DAG 操作**：删除节点并重连其被吸收的证据。

**定义 325（复qualification RQ）** 触发条件 Trig = {d(o,D_train) > d̄, ε_r(o) > ε̄, FMA > τ_fma, ECE > τ_ece, 硬件/任务切换}。触发后：吊销 ROCE 证书 → 回退全量 FLUID（安全不弱化）→ 记录越界样本 → 累计 N_req 样本后重估骨架/包络 → 通过新门禁才恢复轻量。轻量是**可吊销的租约**，不是永久状态。

**定义 326（证书 J_LEAN）** J_LEAN = (J_FLUID, topo_hash, S*, L-vector, ROCE 版本与 ε_r, 𝒬_hash, rung, debt_balance, requal_log_hash, lean_ver)。Valid ⇔ Valid(J_FLUID) ∧ Valid(J_topo) ∧ o∈𝒬 ∧ 债务非负 ∧ 相门闭合。

# IP-264 STO：离线承重拓扑优化（全局最小证据覆盖 + 故障冗余）
def structural_optimize(G, O, F, k_fault):
    load = {}
    for v in G.nodes:
        load[v] = max(0.0, max(                 # 最坏工况/故障下的边际承重
            cert_risk(G.without(v), o, f) - cert_risk(G, o, f)
            for o in O for f in F))
    # 关键：全局覆盖，避免"三杆互为备用却全删"的循环冗余反例
    spine = min_set_cover({v: unique_evidence(v) for v in G.nodes})
    spine |= min_fault_redundancy(G, spine, k_fault)   # 单点失效不塌
    assert cert_risk(G.restrict(spine), o, f) == cert_risk(G, o, f)
    return PruneResult(spine, load, witness=redundancy_witness(spine))

# IP-265 ROCE：降阶认证包络（离线骨架 + 在线区间 + 三分）
class CertifiedEnvelope:
    def __init__(self, skeleton, f_mode, g_sep, eps_r, delta_q, Q):
        self.B, self.f, self.g = skeleton, f_mode, g_sep
        self.eps_r, self.delta_q, self.Q = eps_r, delta_q, Q

    def bounds(self, o):
        phi = cheap_features(o)
        h_hat, d_hat = self.f(phi), self.g(phi)
        # 覆盖半径 -> 区间，离线留出集标定，保证 1-delta_q 覆盖
        return (h_hat-self.eps_r, h_hat+self.eps_r), \
               (d_hat-self.eps_r, d_hat+self.eps_r)

    def triage(self, o, tau_epi):
        if o not in self.Q: return "REVOKE"           # 越界：吊销轻量
        (h_lo, h_hi), (d_lo, d_hi) = self.bounds(o)
        u_hi, u_lo = h_hi * g(d_lo), h_lo * g(d_hi)   # 保守上/下界
        if u_hi <= tau_epi: return "NO_INTERACT"      # 确定无需交互：走脊
        if u_lo >  tau_epi: return "FULL"             # 确定有歧义：全量
        return "INCONCLUSIVE"                          # 跨界：回退全量

# IP-266/269/326 主闭环：脊优先，支路条件触发，越界即吊销
def LEAN_RAS_round(M, o):
    # 0) 资格检查：轻量是租约
    if M.roce.triage(o, TAU_EPI) == "REVOKE" or M.debt.balance < 0:
        M.roce.revoke(); M.rq.log(o)
        return FLUID_RAS_round(M, o)                  # 安全回退 R69 全量
    z = M.mtm.trunk(o)                                # 共享脊的一拍
    c, U_cal = M.cof.step(z, o)
    verdict = M.roce.triage(o, TAU_EPI)
    # 1) 确定无歧义：走脊，但用保守上界算 λ（不只 U_ale）
    if verdict == "NO_INTERACT":
        u_hi = M.roce.u_epi_hi(o)
        lam  = max(M.efs.risk_scale(z), lam_floor(M.roce.u_ale_hi(z) + u_hi))
        k    = M.c_ras_wm.certified_prefix(M.ach.propose(...), ...)
        return k, lam, M.sbs.select_spine(z), ("lean", verdict)
    # 2) 确定有歧义 / 不确定：回退全量 FLUID（支路），并记账
    M.debt.charge("full_fluid")
    return FLUID_RAS_round(M, o)

# IP-267/268 RMG：路线图治理（阶段末，非实时）
def roadmap_review(ledger, ladder, dag, gate_witnesses):
    rung = ladder.current
    missing = [g for g in ladder.gates[rung] if not gate_witnesses[g]]
    if missing:
        return BlockUpgrade(rung, missing)            # 门未闭合，不许升级
    D_next = ledger.debt_budget(rung + 1)
    frontier = [n for n in dag if dag.indegree(n) == 0]   # 只有前置已闭合可开工
    plan = select_with_budget(frontier, D_next)
    return PhasePlan(rung + 1, plan.build,
                     plan.retire_cheap_nodes(), D_next)   # 付费入场

## 3. 推导

**引理 19（零载剪枝不弱化证书）** 设 A99：模块证据集族可被全局最小覆盖 S* 表达，且被删模块的唯一证据并集为空（⋃_{v∉S*} E_v = ∅）。则对任意 o∈𝒪、f∈ℱ，R_cert(G|S*; o,f) = R_cert(G; o,f)。证：S* 覆盖全部唯一证据，被删模块提供的证据均可由 S* 中模块重构；认证风险上界只依赖唯一证据集。**注意**：若只做逐点 L(v)=0 删除，A99 不成立（三杆互备反例），故必须用定义 313′ 的全局覆盖。

**引理 20（ROCE 保守性与成本）** 设 A100：在 𝒬 上骨架残差 ‖H−Ĥ‖ ≤ ε_r、‖Δ−Δ̂‖ ≤ ε_r，且 g 单调递减。则真值以 ≥1−δ_q 落入区间，且 U_epi^lo ≤ U_epi ≤ U_epi^hi。在线成本 O(r·d_φ) 与 O(K·H·d) 无关，即与全量分解的采样数解耦。

**引理 21（吊销回退的单调安全）** 一旦 o∉𝒬 或任一 Trig 触发，LEAN 立即执行 FLUID_RAS_round，其决策与 R69 逐指令相同。故 LEAN 的认证风险上界 = min(轻量分支上界, R69 上界) ≤ R69 上界。轻量失效的代价是延迟，不是安全。

**定理 18（LEAN 逐状态不弱于 FLUID/R69）** 在 A99–A100 下，对任意 o：(a) o∉𝒬 或触发 RQ ⇒ 与 R69 逐指令相同；(b) o∈𝒬 且三分为 NO_INTERACT ⇒ 用 U_epi^hi 与 U_ale^hi 计算 λ，认证风险 ≤ R69；(c) o∈𝒬 且三分 FULL/INCONCLUSIVE ⇒ 回退全量，等于 R69。故 LEAN 在安全上严格包含 R69，在 𝒬 的常见子集上减少计算与信任面。

**定理 19（相门单调安全）** 若每级 Gate 的所有谓词闭合、且每次退休都满足 A99 的全局覆盖前提，则沿路线图升级时 R_cert 关于级别单调不降。证：升级只允许加入经过门禁的组件或删除零载组件；前者不降低上界（认证门保证），后者由引理 19 保持上界。推论：**路线图把「研究进度」定义为认证上界不退化下的能力增长，而不是定义数量的增长。**

**定理 20（信任面收缩）** 设原图需独立验证 |V| 个模块的接口/假设。经 STO 与 ROCE 后，认证只依赖 |S*| 个承重模块加上 1 个可监控的包络监视器；在 𝒬 内，独立信任面由 |V| 降为 |S*|+1，且监视器失效可由 RQ 检出。故轻量化不仅省算力，也缩小了「被单独骗过」的攻击面。

# IP-264 STO：离线承重拓扑（全局覆盖 + 故障冗余）
def structural_optimize(G, O, F, k_fault):
    load = {v: max(0.0, max(cert_risk(G.without(v), o, f)
                            - cert_risk(G, o, f) for o in O for f in F))
            for v in G.nodes}
    spine = min_set_cover({v: unique_evidence(v) for v in G.nodes})  # 非贪心
    spine |= min_fault_redundancy(G, spine, k_fault)                 # 单点失效不塌
    assert cert_risk(G.restrict(spine), o, f) == cert_risk(G, o, f)
    return PruneResult(spine, load, redundancy_witness(spine))

# IP-265 ROCE：降阶认证包络
class CertifiedEnvelope:
    def bounds(self, o):
        phi = cheap_features(o)
        h_hat, d_hat = self.f(phi), self.g(phi)
        return (h_hat-self.eps_r, h_hat+self.eps_r), \
               (d_hat-self.eps_r, d_hat+self.eps_r)      # 1-delta_q 覆盖

    def triage(self, o, tau_epi):
        if o not in self.Q: return "REVOKE"
        (h_lo,h_hi),(d_lo,d_hi) = self.bounds(o)
        u_hi, u_lo = h_hi*g(d_lo), h_lo*g(d_hi)
        if u_hi <= tau_epi: return "NO_INTERACT"
        if u_lo >  tau_epi: return "FULL"
        return "INCONCLUSIVE"

## 4. 推导

**引理 19（零载剪枝不弱化证书）** 在 A99（唯一证据可被全局最小覆盖 S* 表达、被删模块唯一证据并集为空）下，对任意 o,f 有 `R_cert(G|S*) = R_cert(G)`。要点：必须用集合覆盖；逐点 `L(v)=0` 删除会在「三杆互备」的循环冗余下把承重路径全删。

**引理 20（ROCE 保守性与成本）** 在 A100（𝒬 上骨架残差 ≤ε_r、g 单调）下，区间以 ≥1−δ_q 覆盖真值，且 `U_epi^lo ≤ U_epi ≤ U_epi^hi`；在线成本 O(r·d_φ)，与全量 K 采样解耦。

**引理 21（吊销回退单调安全）** 越界或 Trig 触发即执行 `FLUID_RAS_round`，与 R69 逐指令相同；故 LEAN 上界 = min(轻量分支, R69) ≤ R69，失效只付延迟代价。

**定理 18（LEAN 逐状态不弱于 FLUID/R69）** (a) o∉𝒬/触发 ⇒ 与 R69 相同；(b) 𝒬 内 NO_INTERACT ⇒ 用保守上界算 λ，风险 ≤R69；(c) FULL/INCONCLUSIVE ⇒ 回退全量 = R69。故安全严格包含 R69，常见路径更轻。

**定理 19（相门单调安全）** 若每级门禁闭合、退休满足 A99，则沿阶梯升级 `R_cert` 单调不降。推论：**进度 = 认证上界不退化下的能力增长，而非定义数量增长。**

**定理 20（信任面收缩）** 认证独立依赖从 |V| 降为 |S*|+1（包络监视器）；在 𝒬 内信任面收缩，监视器失效由 RQ 检出，攻击面同步缩小。

## 8. 本轮最大风险

**一句话**：LEAN-RAS 的全部收益押在「资格包络与承重证书仍然有效」这一前提上——**若在线有效性监控失效或路线图变得陈旧，降阶包络会把真实歧义压进证书盲区，剪枝会把真正的承重杆当成零载删掉；此时「轻」不再是省算力，而是静默失载——结构已塌，证书仍显示合格。**

**次级风险与缓解**：陈旧骨架/分布漂移（RQ 租约 + 𝒬 监控 + 越界全量回退）；循环冗余误删（全局集合覆盖 + 故障注入 E302/E315）；路线图官僚化或停滞（相门可判定 + 债务账本 + 每轮必须申报 rung 与退役清单）；降阶包络过紧导致频繁回退（E304 调 r 与 ε_r，用 Pareto 选截面）；质量账本被博弈（按危险度加权 + VQAuditor-R 审计架构决策）。
