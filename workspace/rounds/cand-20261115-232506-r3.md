# 第 10 轮（灵感循环第 3 轮；本轮灵感：「力控」×「ROS」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**用"不依赖预测的安全"补上 v9 的死穴，用标准中间件卸掉自研集成债**。两个灵感恰好对应 v9 遗留的两处结构性弱点：其一是 v9 自陈的最大风险——块证书在前向模型最不可靠（域偏移）时失效；其二是 ContractMiddleware 虽理论优雅却是不可移植的自研调度器。前者由**力控的被动力学安全**兜底，后者由 **ROS 2 的 QoS/lifecycle/Action 标准语义**承载。所有新增一律为可选增强：力层缺失注入中立元即严格退回 v9；ROS 不可用即退回 v9 自研 MW。

## 0. 直觉与动机

**灵感 1（力控 → 不依赖预测的接触安全）**
直觉：v9 的位置域证书 Ĉ 是**预测性**的——它赌前向模型误差 ‖F̂−F‖∞ ≤ β。而 DA-ML 检测到的域偏移恰恰使这个赌注最不可靠，于是"最需要安全的时刻证书最不可信"。力控提供了一条正交的安全来源：**接触安全是被动力学性质保证的，不是被预测保证的**。只要 (i) 接触力被投影到力上限与摩擦锥内，(ii) 执行器经能量罐保持无源性（只能花掉已吸收/储备的能量），(iii) 接近速度受动能预算约束，那么任何**未预见**接触向环境转移的能量都有一个**与 F̂ 无关**的上界。于是 v9 的"预测失效即安全失效"被替换为"预测失效 ⇒ 退入被动安全包络"。核心创新：**力域证书（ForceCertificate, FC）** + **能量罐无源柔顺层（EnergyTankCompliance, ETC）**，与位置证书组成**双证书互补**——任一刻至少一张证书有效（**无证书空洞律**）。

**灵感 1 的严谨定义（预告，详见产物定义 540–544）**
- 接触层指标 M_τ：状态 c∈{free,contact}，扳量 w=(f_n,f_t,τ_z)，安全域 0≤f_n≤f_n^max、‖f_t‖≤μf_n、冲量 J≤J_max。
- 力域证书 Ĉ^τ=(f̂_n^max, ĵ_max, Ê_tank, t_cert)，有效性只依赖力传感标定余量 β_τ 与能量罐不变式，**不出现 β**。
- 能量罐：dE_tank/dt = P_abs − P_cmd，不变式 E_tank≥0；指令按 λ=E_tank/E_req 缩放。
- 被动包络 Π：‖q̇‖≤√(2E_safe/m_max)、力锥、E_tank≥ε_E；Π 内碰撞动能 ≤E_safe，模型无关。
- 双证律：D_t ≜ (Ĉ^pos valid) ∨ (Ĉ^τ valid) 每周期成立；两者同时失效才允许紧急停驻。

**灵感 2（ROS → 契约的标准落地，而不是又一层自研中间件）**
直觉：v9 的 ContractMiddleware 把"时限、失效、生命周期"抬成一等公民，方向对，但实现是自研的、不可移植的调度器——集成债只是从 v8 的手写网关转移到了 v9 的自研中间件。ROS 2 恰好已把这些语义标准化：**Deadline / Liveliness QoS** 做时限与存活监测，**transient_local durability** 做契约表分发（晚加入节点可读），**reliability** 区分安全关键与高频遥测，**lifecycle 节点**表达可配置/停用/激活状态，**Action** 表达"目标—反馈—结果—取消"。ROS 灵感的价值不是"再写一个中间件"，而是把 κ_m **降维**成标准 QoS 配置 + 生命周期状态机 + Action 接口，只保留"确定性 EDF + 中立元注入"这一最小不可替代内核。同时必须诚实划线：**ROS 2/DDS 不是硬实时脊梁**——1kHz 力控不能进 DDS，于是需要**三域执行架构**（1kHz 力控 RT 线程 / 50Hz 决策 RT executor / 5Hz 规划 soft executor），跨域只交换带时间戳的证书。

**灵感 2 的严谨定义（预告，详见产物定义 545–549）**
- QoS 契约 q_m=(reliability,durability,deadline D_m,liveliness L_m,history h_m)；D_m 与 v9 契约同值。
- 生命周期映射 Φ：active↔active、dormant↔inactive（仍在契约表、可 activate）、frozen↔unconfigured（需离线证据）。
- 动作块 ζ ↔ ROS Action：goal=a^{1:K}+双证+P_t，feedback=50Hz 守卫遥测，result=执行前缀+最终证书，cancel=中止到 p*。
- 三域 Dom_F/Dom_D/Dom_P 与跨域新鲜度 Δ_fresh；证书时间戳偏差超 ε_clock 时两证不得同时判 valid（防共模）。

## 1. 研究问题（轮次升级版）

- **Q1（双证互补性）**：在什么传感/时钟假设下，位置证书与力域证书的失效事件"不相关"，从而使无证书空洞律的强形式成立？若二者共享状态估计、时钟与 F/T 链，如何用冗余、独立通道与新鲜度界把"共模失效"降为可检测失效？
- **Q2（被动包络的性能代价）**：模型无关的速度/力/能量界会把任务吞吐压低多少？能否在线辨识 m_max、f_n^max 的**保守**上界来紧化包络，同时仍不引入对 F̂ 的依赖？
- **Q3（QoS 语义的可判定性）**：ROS 2 的 deadline/liveliness 是"监控事件"而非"抢占"，如何在执行器上实现确定性的 v^⊥ 注入而不与迟到的真实结果竞态？三域时间戳一致性如何形式化并可测试？
- **Q4（与 v9 的退化兼容）**：力层缺席（无 F/T 硬件）时注入中立元，是否严格回到 v9 的位置证书路径与 K_eff 门控？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 双证书互补律（Dual-Certificate Complementarity, FC）**
每个控制周期必须满足 D_t ≜ (Ĉ^pos valid) ∨ (Ĉ^τ valid)。位置证书依赖信任域 U_t（Δ_dom<τ_dom ∧ risk_SLAM<τ_SLAM）；力域证书依赖无源性 + 力界 + 新鲜度。仅当二者同时失效才允许紧急安全停驻——把"单证失效"从安全事件降级为模式切换。

**P14 被动安全包络律（Passive Safety Envelope, PSE）**
在预测不可信的退化态，控制指令必须落在 Π = {‖q̇‖≤√(2E_safe/m_max), 0≤f_n≤f_n^max, ‖f_t‖≤μf_n, E_tank≥ε_E} 内。Π 的能量上界不引用前向模型，故构成对 v9 "β 依赖"的独立兜底。

**P15 QoS 原生契约律（QoS-Native Contract, ROS）**
κ_m 的时限/失效/生命周期语义必须可由 ROS 2 标准 QoS + lifecycle + Action 表达；自研只保留"确定性 EDF 执行器 + 中立元注入"最小内核。硬实时力控不进 DDS：1kHz 在专用 RT 线程，ROS 只承载 50Hz 决策与 5Hz 规划及证书分发。

## 3. 与基线的接口（如何退化）

- 位置证书失效（Δ_dom≥τ_dom ∨ risk_SLAM≥τ_SLAM ∨ Ĉ^pos invalid）⇒ K_eff←1 **且**进入被动安全包络（力受限柔顺）；力域证书仍有效；
- 力层失效（F/T 断线/饱和/能量罐耗尽）⇒ Ĉ^τ invalid，退回 v9 位置证书路径（K_eff 门控不变）；
- **双证同时失效** ⇒ 紧急安全停驻（最大中止点 + 速度衰减），不再执行任何新块；
- 力层缺席（无 F/T 硬件）⇒ 注入 v^⊥（f≡0、E_tank≡∞ 的恒等）⇒ 纯位置控制，逐位等价 v9；
- QoS/ROS 不可用（单进程/裸机）⇒ 用 v9 自研 MW，契约表退化为本地字典；lifecycle 不可用 ⇒ 蒸馏状态机退化为 v9 内存状态机；
- v9/AC/MW/ID 失效 ⇒ 按 v9 五级退化链；最终退回 v8 → v7 → v6。

## 4. 预期贡献

1. **力域证书 + 双证书互补**：把 v9 的"预测失效即安全失效"改写为"预测失效 ⇒ 被动力学兜底"，并给出无证书空洞律的**条件性**陈述（条件即风险）；
2. **能量罐无源层 + 被动包络**：给出与前向模型无关的碰撞能量上界 E_safe 与接触稳定性条件；
3. **ROS 2 QoS 原生契约**：把自研中间件降维到 deadline/liveliness/durability/lifecycle/Action 标准语义，保留最小内核；
4. **三域执行架构**：明确 1kHz/50Hz/5Hz 的职责边界与跨域证书新鲜度约束，防止 DDS 抖动放大到力闭环；
5. **E571–E592** 覆盖力域证书、能量罐、碰撞能量界、双证无空洞、QoS 注入、三域时限、接触丰富任务与对抗传感故障。

## 5. 本轮最大风险

**一句话**：双证书互补性假设"位置证据"与"力证据"独立失效，但二者共享同一状态估计、同一时间基准与同一 F/T 传感链——一次时钟同步偏差或 F/T 饱和/断线就会让两张证书同时失守，"互补"退化为"共模"，无空洞律的强形式随之失效。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-ACMD-FQ**（Force-compliant, QoS-native）

> 背景：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮灵感：「力控」×「ROS」
> **继承纪律**：MetricVoiceGauge 九不变式（CVC-闭环、SpatialCert、RT-CVC、FaultCert、PrimitiveGraph、严格退化链、OTL、GCT、ER）与 v9 的 AC/MW/ID 三模块全部保留。新增组件一律为**可选增强**：力层缺失 ⇒ 注入中立元 v^⊥（f≡0、E_tank≡∞），严格退回 v9 位置证书路径（引理 90）；ROS 不可用 ⇒ 退回 v9 自研 MW（引理 91 的"等价⋆"）。不做行为漂移。

**退化链声明（v10 力位双证七级）：**
- **Level-0（双证正常）**：Ĉ^pos valid ∧ Ĉ^τ valid ⇒ 执行块；
- **Level-1（位置证书失效）**：Δ_dom≥τ_dom ∨ risk_SLAM≥τ_SLAM ∨ Ĉ^pos invalid ⇒ K_eff←1 ∧ 进入被动安全包络（力受限柔顺），Ĉ^τ 仍 valid；
- **Level-2（力层失效）**：F/T 断线/饱和 ∨ E_tank<ε_E ⇒ Ĉ^τ invalid ⇒ 退回 v9 位置证书路径（K_eff 门控不变）；
- **Level-3（双证失效）**：Ĉ^pos∧Ĉ^τ 同时 invalid ⇒ 紧急安全停驻（最大中止点 + 速度衰减），不执行新块；
- **Level-4（QoS/MW 失效）**：切 v9 自研网关（本地契约字典），等价 v9 集成方式；
- **Level-5（ID/lifecycle 失效）**：全模块 active、归因冻结，等价 v9 全模块常开；
- **Level-6（v8 DA/SPR/Cal 失效）**：中立元注入（Δ_dom≡0 / risk_SLAM≡0 / sensor_weight≡1），等价 v7；全失效 ⇒ v6。

## 1. 符号体系增量（定义 540–549）

| 符号 | 含义 |

**新增定义 540（接触层指标 Contact Layer M_τ）** 把六层指标层级扩展为七层：M=(M₀,M₁,M₂,M₃,M_dom,M_SLAM,M_τ)。接触层状态 c∈{free,contact}，扳量 w=(f_n,f_t,τ_z)，安全域：
```
0 ≤ f_n ≤ f_n^max,   ‖f_t‖ ≤ μ·f_n,   |τ_z| ≤ τ_max,   J = ∫|f|dt ≤ J_max
```
直觉：位置层的 d_safe 管"别撞上"，接触层的 f_n^max/摩擦锥管"撞上了也别捏碎、别打滑"。μ 为摩擦系数保守下界。

**新增定义 541（力域证书 ForceCertificate）** 在块时域 [t,t+KΔt] 上由 F/T 传感与能量罐给出：
```
f̂_n^max = max_{s∈块} |f_n(s)| + β_τ
ĵ_max   = ∫_{块} f_n dt + β_J
```
证书有效 ⇔
```
f̂_n^max ≤ f_n^max ∧ ĵ_max ≤ J_max ∧ Ê_tank ≥ ε_E
∧ (t_now − t_cert ≤ Δ_fresh) ∧ γ_slip = valid
```
关键区别：β_τ、β_J 只依赖力传感标定不确定度，**不出现前向模型误差 β**。故 Ĉ^τ 在域偏移时不解耦失效——除非传感链本身故障（见本轮风险）。

**新增定义 542（能量罐无源性 Energy Tank Passivity）** 令 q̇ 为关节速度、τ_ext 为外部扳量、f_cmd 为指令力：
```
dE_tank/dt = P_abs − P_cmd,   P_abs = max(0, τ_extᵀq̇),   P_cmd = |f_cmdᵀq̇|
```
不变式 E_tank(t)≥0。指令 a 可执行仅当所需能量 E_req ≤ E_tank；否则按
```
λ = clamp(E_tank / E_req, 0, 1),   f_cmd ← λ·f_cmd,   q̇_cmd ← λ·q̇_cmd
```
缩放。直觉：机器人只能"花"它已经吸收或储备的能量，不能凭空向环境注入能量 ⇒ 接触无源稳定（Franken 能量罐思想）。

**新增定义 543（被动安全包络 Passive Envelope Π）**
```
Π = { (q̇,f,E_tank) : ‖q̇‖ ≤ v_safe = √(2E_safe/m_max),
      0 ≤ f_n ≤ f_n^max,  ‖f_t‖ ≤ μf_n,  E_tank ≥ ε_E }
```
在 Π 内，任何未预见接触向环境转移的动能 ≤ E_safe = ½·m_max·v_safe²，**与前向模型无关**。m_max 取末端+最大负载的保守上界（可在线辨识但只允许上调）。

**新增定义 544（双证书互补与无证书空洞律 Dual-Certificate / No-Gap）**
安全前提 D_t ≜ (Ĉ^pos valid) ∨ (Ĉ^τ valid) 在每个控制周期成立。Ĉ^pos 依赖信任域 U_t；Ĉ^τ 依赖 (E_tank≥ε_E ∧ 力界 ∧ 新鲜度 ∧ γ_slip)。两者同时失效 ⇒ 进入 Level-3 紧急停驻。**强形式**（无空洞且不停驻）额外要求两证失效事件不相关——这是本轮风险所在。

**新增定义 545（QoS 契约映射 QoSContract）** 每模块 m 的 κ_m 映射为 q_m=(rel, dur, D_m, L_m, h_m)：

| 端口/模块 | reliability | durability | deadline | liveliness | history |
|---|---|---|---|---|---|
| M₀/SpatialCert/FaultCert/证书 | reliable | transient_local | D_m | L_m=3D_m | keep_last 1 |
| 契约表 `/mvg/contracts` | reliable | transient_local | — | — | keep_last 1（晚加入可读） |
| DA-ML / SPR / Calib-FI | reliable | volatile | 1.0/0.2/0.1 ms | 3D_m | keep_last 1 |
| AC 块生成（5Hz） | reliable | volatile | 200 ms | 600 ms | keep_last 1 |
| AC 中块守卫（50Hz） | best_effort | volatile | 20 ms | 60 ms | keep_last 1 |
| 力状态 `/mvg/force_state`（1kHz） | best_effort | volatile | 1 ms | 3 ms | keep_last 1 |
| 守卫遥测（反馈） | best_effort | volatile | 20 ms | 60 ms | keep_last 5 |

deadline 事件 ⇒ 标记 stale 并注入 v^⊥；liveliness 丢失 ⇒ 同上。rel/durability 的选择遵循"安全关键用可靠持久、高频遥测用 best effort"，避免可靠重传堵塞 50Hz 环路。

**新增定义 546（生命周期与蒸馏状态映射 LifecycleMap）**
```
Φ: active  ↦ active        (计算运行、输出真实值)
   dormant ↦ inactive      (不计算、输出 v^⊥，但仍在契约表、可被 activate)
   frozen  ↦ unconfigured  (不发布不接收；仅离线证据可 configure+activate)
```
契合 P12 提炼不删码律：dormant 只是 lifecycle inactive，节点与契约条目都还在；frozen 是 unconfigured，需显式证据解冻。迁移回调负责 v^⊥ 的注入与解除，等价 v9 `set_dormant/set_active`。

**新增定义 547（三域执行架构 Three-Domain Execution）**
- **Dom_F**：1kHz 力控，专用 RT 线程/隔离核，**不经 DDS**，硬件时间戳；只消费 Dom_D 已签发证书的指令；
- **Dom_D**：50Hz 决策，单线程 RT executor（静态回调组、预分配、零拷贝 intra-process）；
- **Dom_P**：5Hz 规划/块生成，多线程 soft executor，可容忍抖动。
跨域只传 (值, t_cert, τ_d)；进入 Dom_F 的指令必须已过 Dom_D 证书检查且 t_now−t_cert ≤ Δ_fresh。DDS 抖动被隔离在 Dom_D↔Dom_P，不放大到力闭环。

**新增定义 548（动作块与 ROS Action 映射 ChunkActionMap）**
```
goal    = a^{1:K} + Ĉ^pos + Ĉ^τ + P_t
feedback= 50Hz 守卫遥测 (live_clearance, f_n, E_tank, cert_ok)
result  = 执行前缀 + 末态证书
cancel  = 中止到 p* + 被动包络停驻（定义 534）
abort   = 双证失效紧急停驻
```
v9 的 `midchunk_guard` 映射为 Action feedback 的回调；`generate_chunk` 映射为 Action server 的 goal 处理。

**新增定义 549（证书新鲜度 Certificate Freshness）**
```
fresh(Ĉ,t) ⇔ t − t_cert ≤ Δ_fresh(Ĉ)
```
位置证书 Δ_fresh=20 帧（DA 滑窗）；力域证书 Δ_fresh=τ_d≤2ms。跨域用 PTP/硬件时钟；若两证时间戳偏差 |t_pos−t_frc| > ε_clock，则**不得同时判 valid**（强制降级为单证或停驻），用于阻断共模时间故障。

# IP-358/359 ForceCompliantSafetyLayer：能量罐 + 被动包络（Dom_F, 1kHz）
class ForceCompliantSafetyLayer:
    def __init__(self, ft, m_max=8.0, f_n_max=40.0, mu=0.6, J_max=0.5,
                 E_safe=0.5, eps_E=1e-3):
        self.ft, self.m_max, self.f_n_max = ft, m_max, f_n_max
        self.mu, self.J_max, self.E_safe, self.eps_E = mu, J_max, E_safe, eps_E
        self.tank = E_safe
        self.v_safe = math.sqrt(2.0 * E_safe / m_max)     # 定义 543

    def step(self, qd_cmd, f_cmd, dt):
        # (1) 无源能量罐（定义 542）
        w = self.ft.read()
        P_abs = max(0.0, w.dot(qd_cmd))
        P_cmd = abs(f_cmd.dot(qd_cmd))
        self.tank += (P_abs - P_cmd) * dt
        if self.tank < self.eps_E:                        # 能量不足则缩放
            lam = max(0.0, self.tank / max(abs(P_cmd) * dt, 1e-9))
            f_cmd, qd_cmd = lam * f_cmd, lam * qd_cmd
            self.tank = max(0.0, self.tank)
        # (2) 力上限 + 摩擦锥投影（定义 540）
        f_cmd = project_wrench(f_cmd, self.f_n_max, self.mu)
        # (3) 速度包络：碰撞动能界（定义 543）
        qd_cmd = clamp_norm(qd_cmd, self.v_safe)
        return qd_cmd, f_cmd, self.tank

    def certificate(self, t_cert):
        f_peak = self._peak_force_bound() + self.ft.beta_tau()
        j_pred = self._impulse_bound() + self.ft.beta_J()
        valid = (f_peak <= self.f_n_max and j_pred <= self.J_max
                 and self.tank >= self.eps_E
                 and self._slip_margin() > 0)
        return ForceCert(f_peak, j_pred, self.tank, t_cert, valid)  # 定义 541


# IP-360 DualCertificateGuard：无证书空洞律（Dom_D, 50Hz）
def dual_guard(pos_cert, force_cert, k_exec, t_now, eps_clock):
    pos_ok = pos_cert.valid and (t_now - pos_cert.t_cert <= D_POS)
    frc_ok = force_cert.valid and (t_now - force_cert.t_cert <= D_FRC)
    # 时间共模阻断：两证时间戳偏差超限则不得同时判 valid（定义 549）
    if abs(pos_cert.t_cert - force_cert.t_cert) > eps_clock:
        frc_ok = False
    if pos_ok and frc_ok:
        return ('chunk', k_exec + 1)          # Level-0
    if pos_ok and not frc_ok:
        return ('chunk_guarded', k_exec + 1)  # Level-2：位置路径，接触无兜底
    if frc_ok and not pos_ok:
        return ('compliant_fallback', k_exec) # Level-1：K_eff=1 + 被动包络
    return ('emergency_stop', None)           # Level-3

# IP-362 ThreeDomainExecutor：三域调度（定义 547）
class ThreeDomainExecutor:
    def __init__(self, force_layer, bridge, chunker):
        self.force = force_layer
        self.force_thread = RTThread(self.force.step, period_ms=1.0, cpu=2)
        self.decision = StaticSingleThreadedExecutor(num_threads=1)  # 50Hz
        self.planning = MultiThreadedExecutor(num_threads=2)         # 5Hz

    def tick(self, ctx):
        # Dom_D：读力层最新证书 → 双证守卫
        verdict, k = dual_guard(ctx.pos_cert, ctx.force.certificate(hw_now()),
                                ctx.k_exec, hw_now(), EPS_CLOCK)
        # Dom_F 只接收已签发指令（新鲜度已校验）
        if verdict == 'chunk':
            self.force_thread.post(ctx.chunk.actions[k])
        elif verdict == 'chunk_guarded':
            self.force_thread.post(ctx.chunk.actions[k])
        elif verdict == 'compliant_fallback':
            self.force_thread.post(ctx.single_step_compliant())
        elif verdict == 'emergency_stop':
            self.force_thread.post(ctx.safe_stop())
        # Dom_P：5Hz 块生成（ROS Action goal）
        if self.planning.due():
            self.planning.spin_once(timeout_sec=0)
        return verdict, k

## 4. 推导

**引理 87（力域证书的模型无关性）** 设 F/T 测量满足 |f_meas−f_true|∞≤β_τ、|∫f_meas−∫f_true|≤β_J，则 Ĉ^τ 的 f̂_n^max、ĵ_max 是真实接触力/冲量的上界；其有效性只引用 β_τ/β_J、能量罐不变式与力锥，**不引用 F̂ 或 β**。证明：由测量误差界逐项相加即得最坏界；能量罐缩放与力锥投影是控制器的代数性质，与前向模型无关。∎

**引理 88（被动包络的碰撞能量界）** 在 Π 内运动，任何未预见接触向环境转移的动能 ≤ E_safe=½m_max·v_safe²；若接触力被夹在 f_n^max、检测延迟 ≤τ_d，则冲量 J ≤ f_n^max·τ_d + ∫_detect 主动力。证明：动能由速度包络界定；冲量由力界乘以时间界；m_max≥真实等效质量、f_n^max≥真实峰值力保证保守性。∎ 推论：E_safe 与 J 的上界不依赖 ‖F̂−F‖∞，故 v9 的"域偏移时证书最不可靠"在力域不成立（除非传感链故障）。

**引理 89（双证书无空洞，条件性）** 若 (A1) 力传感新鲜度 t_now−t_cert≤Δ_fresh 且 (A2) 能量罐不变式与力锥成立，则任一周期至少一张证书 valid；当 Ĉ^pos 因 U_t 破坏失效时 Ĉ^τ 仍 valid ⇒ 进入 Level-1 柔顺退化而非裸停。若 A1 或 A2 被破坏，无空洞律不成立，必须 Level-3。**强形式（永不停驻）额外要求两证失效事件不相关；该要求不被本引理保证，见本轮风险。** ∎

**引理 90（柔顺退化与 v9 逐位兼容）** 力层缺席时注入 v^⊥：f≡0 且令 E_tank≡∞（恒等元），则 dual_guard 只剩 pos_ok 分支，退化为 v9 的 K_eff 门控；力层存在但某一周期失效则走 Level-2（chunk_guarded），决策粒度与 v9 相同。故 v10 ⊒ v9（行为集合包含关系）。∎

**引理 91（QoS 契约等价，条件性：等价⋆）** 在 reliable、有界时延（≤D_m）的 DDS 上，deadline/liveliness 事件到 v^⊥ 注入的映射与 v9 deadline_guard/strikes 语义一致；DDS 无界时延时只能单向（v9 可保证截止期，ROS 只能事后监测），故 ROS 路径记为"等价⋆"，并以 E582（三域时限）与 E581（日志等价）作经验验证，不以形式化断言。∎

**引理 92（三域时限守恒）** Dom_F 不经 DDS，1kHz 由专用 RT 线程保证；Dom_D 50Hz 由单线程 RT executor + 预分配/零拷贝保证；Dom_P 5Hz 容忍抖动。跨域只传带时间戳证书，故 DDS 抖动不进入力闭环，Pi 闭环时延 ≤ Δ_fresh。∎

**引理 93（生命周期冻结的安全传递）** frozen⇒unconfigured：节点不发布、不接收、不执行，但契约条目仍在表内；解冻需离线证据（configure+activate）。故冻结不改变 v8/v7 退化格点的可达性，P12 的"提炼不删码"在标准生命周期语义下仍成立。∎

## 8. 本轮最大风险

**一句话**：双证书互补性假设"位置证据"与"力证据"独立失效，但二者共享同一状态估计、同一时间基准与同一 F/T 传感链——一次时钟同步偏差或 F/T 饱和/断线就会让两张证书同时失守，"互补"退化为"共模"，无空洞律的强形式随之失效。
