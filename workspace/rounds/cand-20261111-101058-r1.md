# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「深度相机」×「数据配比」）

> 第 54 轮把技能组合升级为动作-鲁棒性双证书（ACS×SCOM×CEC×AEC×JTC），但几何感知层 L1 仍停留在抽象接口：「深度」既没有物理噪声模型，也没有进入鲁棒性谱的维度。本轮以 **深度相机** 为 L1 的物理锚点、以 **数据配比** 为训练侧唯一可控的覆盖杠杆，把二者统一为「传感器条件空间上的测度对齐」问题。核心矛盾：H22：深度噪声在远距、低反射、掠射角与深度不连续处呈重尾，而按平均损失优化的数据配比会把质量堆在近距易样本上，形成"平均好、尾部差"的鲁棒性假象；H23：仿真深度与真实深度在噪声谱上存在结构性差异，固定 sim:real 比例无法对齐部署时的传感器条件，配比必须条件化到「深度 × 材质 × 动作关键性」。

## 0. 直觉与动机

**灵感 1（深度相机 = 条件化噪声谱，而非一个标量精度）**
直觉：深度相机的误差不是"±2mm"一个数，而是随距离、材质、入射角、结构边缘系统变化的谱。主动立体/ToF 的轴向噪声近似 `σ_z(z) ≈ a·z² + b`（ToF 还有多径与反射率相关偏差），横向噪声 `σ_xy(z) ∝ z`，深度不连续处产生"飞点"，镜面/低反射/透明材质出现整片丢失。于是"深度"应成为鲁棒性谱的一个**物理条件维度**：`ρ_S(z, m)` 而非单一 `ρ_S`。同一技能在 0.5m 木桌上稳如磐石，在 3m 玻璃门前可能完全失效——平均值掩盖的正是动作最需要的那部分条件尾部。

**灵感 2（数据配比 = 条件空间上的测度，而非一个比例）**
直觉：把训练数据来源（真实、光线追踪仿真、栅格化仿真、合成深度增强、局部边端采集）视为若干测度，配比 `w` 是单纯形上的权重。固定 `sim:real=1:1` 的谬误在于：它按**样本数**配平，而不是按**部署条件覆盖**配平。正确的对象是 `w` 经数据生成过程推前到「深度-材质-视角」条件空间上的测度 `ν_w`；目标是让 `ν_w` 在**动作关键且鲁棒性最低的条件尾部**有足够质量。一句话：配比要买的是尾部覆盖，不是平均精度。

**灵感 3（配比响应面有饱和、互补与交互）**
直觉：增加仿真数据提升几何泛化，但边际收益递减；真实数据补噪声真实性；二者**互补而非可加**。若把 `R_S(w)=E_{c~ν_w}[min_d ρ_S(c,d)]` 看作配比响应面，它近似单调、凹（边际收益递减），并带来源间交互。配比优化因此不是网格搜索，而是**带证书的边际收益 water-filling**：每单位数据成本买到的尾部鲁棒性增量最大的源优先加码；当再加码也无法把最差条件抬过 `ρ_min` 时，应**拒绝配比**而不是交出一个"平均达标"的模型。

**灵感 4（云边配比契约：基座广覆盖 + 边端窄校准）**
直觉：云端用广覆盖配比 `w_c` 训练基座，边端只用少量本地真实数据 `w_e` 校准（应对具体安装高度、光照、镜头污渍）。风险是本地校准把基座证书"改坏"——典型灾难性遗忘与配比漂移。故需**配比-传感器契约**：云端承诺在条件集 `Ω_c` 上的证书，边端承诺 `w_e` 的支撑集落在 `Ω_c` 内且深度域差距 `D_DS ≤ Δ_w`；违反时宁可拒绝部署，也不带假证书上线。

**灵感 5（金字塔扩展：深度-数据层 𝔻 与动作层 𝔸 耦合）**
直觉：在 `𝕃`（鲁棒性）与 `𝔸`（动作协同）之间插入 `𝔻`：`𝔻_0` 传感器物理噪声、`𝔻_1` 深度条件鲁棒谱、`𝔻_2` 配比响应面、`𝔻_3` 云边配比契约。跨层证书从"动作-鲁棒性双证书"升级为 **传感器-配比-动作-鲁棒性四元证书**，其中每一维都可被独立审计、独立回滚。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（深度噪声剖面 DNP）**
深度传感器剖面 `M = (Z, σ_z(·), σ_xy(·), r_fp(·), p_drop(·;m), b(·;m))`：
- `Z=[z_min,z_max]` 有效量程；
- `σ_z(z)` 轴向噪声，校准为分段形式（近距三角化主导、中距 `a z²+b`、远距 ToF 多径主导）；
- `σ_xy(z)` 横向噪声；
- `r_fp(Δz)` 深度不连续处的飞点率，`Δz` 为邻域深度跳变；
- `p_drop(z;m)` 材质 `m` 下的丢失率（镜面、深色、透明）；
- `b(z;m)` 系统偏差（多径、温度漂移）。
剖面在标定集 `C_cal` 上以分箱鲁棒回归拟合，必须同时输出外推不确定度 `u_M(z,m)`。

**定义 122（深度条件鲁棒谱）**
技能 `S` 在深度条件 `c=(z,m,θ_v)`（距离、材质、入射角）与扰动维 `d` 上的鲁棒性 `ρ_S(c,d) ∈ [0,1]`。**可部署条件集**：
```
Adm_S(ρ_min) = { c ∈ Z×M_adm×Θ_v | ∀d, ρ_S(c,d) ≥ ρ_min }
```
与第 54 轮动作剖面耦合：动作 `a` 在条件 `c` 下可执行当且仅当 `α_S(a|z,m) ≥ θ_cov` 且 `ρ_S(c,d) ≥ ρ_min ∀d`。

**定义 123（数据配比与条件覆盖测度）**
数据源 `{D_1,...,D_K}`，配比 `w ∈ Δ^{K-1}`。数据生成过程 `G_i: D_i → 𝒞` 将样本映射到条件空间，推前测度 `ν_w = Σ_i w_i (G_i)_# D_i`。条件覆盖 `Cov(w, Ω) = ν_w(Ω)`；尾部覆盖 `Tail(w) = ν_w({c : R_S(c) ≤ q_τ})`，其中 `R_S(c)=min_d ρ_S(c,d)`，`q_τ` 为 τ-分位阈值。有效样本量 `ESS(w) = 1 / Σ_i w_i²/|D_i|`。

**定义 124（配比响应面）**
`R_S(w) = E_{c~ν_w}[R_S(c)]`，并假设正则性：
- **(R1) 单调**：`w_i↑ ⇒ R_S(w)↑`（该源不含纯噪声）；
- **(R2) 边际递减**：`∂²R_S/∂w_i² ≤ 0`；
- **(R3) 有界交互**：`|∂²R_S/∂w_i∂w_j| ≤ κ`。
配比弹性 `e_i(w)=∂R_S/∂w_i`，单位成本弹性 `ẽ_i = e_i / cost_i`。

**定义 125（深度域差距 DDS）**
在噪声特征空间 `Φ(c)=(σ_z(z), σ_xy(z), r_fp, p_drop, b)` 上，
```
D_DS(P_real, P_sim) = W_2(Φ_# P_real, Φ_# P_sim)
```
可分解为 `D_DS = D_ax + D_lat + D_fp + D_mat + D_bias`，并按动作关键性加权 `D_DS^ω = Σ_j ω_j D_j`。

**定义 126（配比-传感器契约 MSC）**
云边契约 `C_ms = (w_c, w_e, Ω_c, Δ_w, ρ_min)`：
- 云端基座配比 `w_c`，承诺 `Cov(w_c, Ω_c) ≥ 1-ε` 且 `∀c∈Ω_c, R_S(c) ≥ ρ_min`；
- 边端校准配比 `w_e`，要求 `supp(ν_{w_e}) ⊆ Ω_c` 且 `D_DS(P_e, P_c) ≤ Δ_w`；
- 违反任一条件即 `reject`，不得以基座证书替代边端证书。

**定义 127（深度-配比联合证书 DMC）**
```
J_DP = ( ρ_S(c,d), D_cert(M; C_cal, u_M), w,
         W_cert(Cov, Tail, ESS), D_DS^ω, δ_w, evidence )
```
其中 `W_cert` 记录配比覆盖、尾部质量与有效样本量，`δ_w` 为配比漂移上界。若 `∀c∈Ω_adm: R_S(c) ≥ ρ_min`、`D_DS^ω ≤ Δ_w`、`δ_w ≤ Θ_w`，且 `u_M` 在可接受带内，则 `J_DP` 可部署。

## 2. 关键算法 伪代码

### IP-121 DNP（Depth Noise Profiling）
```python
def profile_depth_sensor(calib_frames, bins, materials):
    M = {'sigma_z':{}, 'sigma_xy':{}, 'r_fp':{}, 'p_drop':{}, 'bias':{}}
    for b in bins:                       # 距离分箱
        zs = [f.z for f in calib_frames if b.contains(f.z)]
        M['sigma_z'][b] = robust_fit(zs, model='piecewise(a*z^2+b)')
        M['sigma_xy'][b] = robust_fit_lateral(zs)
        M['r_fp'][b] = edge_flying_pixel_rate(zs)
        for m in materials:
            M['p_drop'][(b, m)] = drop_rate(zs, m)
            M['bias'][(b, m)] = robust_bias(zs, m)
    M['u_M'] = extrapolation_uncertainty(M, bins)   # 外推不确定度
    return M
```

### IP-122 DCR（Depth-Conditioned Robustness）
```python
def depth_conditioned_rho(skill, M, cond_grid, robust_dims, sampler, n0=32):
    rho, unc = {}, {}
    for c in cond_grid:                  # (z, m, theta_v) 稀疏网格
        sigma = sensor_perturbation(M, c)         # 用噪声剖面注入，不靠真实硬件穷举
        r_hat, u = sequential_estimate(
            lambda d: skill.robustness(c, d, sigma),
            robust_dims, n0=n0,
            stop_when=lambda u: u <= u_tol)
        rho[c], unc[c] = r_hat, u
    return rho, unc
```

### IP-123 CCM（Condition Coverage Measure）
```python
def coverage(w, sources, cond_bins, smoothness_prior):
    nu = defaultdict(float)
    for i, D in enumerate(sources):
        for x in D:
            nu[cond_bins.assign(Phi(x))] += w[i] / max(1, len(D))
    cov = {b: nu[b] for b in cond_bins}
    ess = 1.0 / sum((w[i] ** 2) / max(1, len(sources[i]))
                    for i in range(len(w)))
    tail_bins = low_quantile_bins(cov, smoothness_prior, q=0.2)
    tail_mass = sum(cov[b] * smoothness_prior[b] for b in tail_bins)
    return Cov(cov), Tail(tail_mass), ESS(ess)
```

### IP-124 AMO（Adaptive Mixture Optimization）
```python
def optimize_mixture(sources, M, budget, rho_min, action_criticality,
                     eps_explore=0.1):
    w = uniform(len(sources))
    R_hat = fit_response_surface(probe_mixes(sources), rho_hat,
                                 constraints=['monotone', 'concave', 'kappa'])
    while cost(w) < budget:
        grads = estimate_elasticities(R_hat, w)
        i_star = argmax(grads[i] / unit_cost[i] for i in sources)
        w = water_fill_step(w, i_star, eps_explore)   # 保留探索质量，防局部最优
        if certified_tail(R_hat, w, rho_min, action_criticality):
            break
    if not certified_tail(R_hat, w, rho_min, action_criticality):
        return ('reject', 'tail_uncertified', w)      # 保守拒绝
    return ('ok', w, W_cert(coverage(w), ESS(w), R_hat.uncertainty))
```

### IP-125 MSC（Mixture-Sensor Contract）
```python
def mixture_sensor_contract(w_c, w_e, M_c, M_e, Omega_c, Delta_w, rho_min):
    dds = depth_domain_gap(M_e, M_c)              # 在 Phi 上做 W2
    dds_w = criticality_weighted(dds)
    if dds_w > Delta_w:
        return ('reject', 'sensor_gap', dds_w)
    if not subset_support(w_e, Omega_c):
        return ('reject', 'support_escape', w_e)
    if not all(R_S(c) >= rho_min for c in Omega_c):
        return ('reject', 'base_cert_invalid')
    return ('ok', Contract(w_c, w_e, dds_w, Delta_w))
```

### IP-126 DMC（Depth-Mixture Certificate）
```python
def depth_mixture_certificate(skill_seq, M, w, Omega_adm, rho_min,
                              Delta_w, Theta_w):
    D_cert = build_sensor_cert(M, u_M=M['u_M'])
    rho, unc = depth_conditioned_rho_chain(skill_seq, M, Omega_adm)
    if any(rho[c] < rho_min + unc[c] for c in Omega_adm):
        return ('reject', 'uncertain_tail', worst(Omega_adm, rho, unc))
    wcert = W_cert(coverage(w), tail_mass(w), ESS(w))
    dds = depth_domain_gap_decomposed(M, w)
    if dds.weighted > Delta_w or wcert.drift > Theta_w:
        return ('reject', 'mix_shift', dds, wcert)
    return ('ok', J_DP(rho, D_cert, w, wcert, dds, evidence=calib_logs))
```

### IP-127 SDA（Sensor-Directed Augmentation）

```python
def sensor_directed_augment(D_sim, M, target_c):
    # 用目标条件 c 的噪声剖面反向注入，生成"该传感器在该条件下必然看到"的样本
    out = []
    for x in D_sim:
        if in_condition(x, target_c):
            out.append(inject_noise(x, M, target_c))   # 轴向/横向/飞点/丢失
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| DNP | O(N_cal·B·|M|) | O(B·|M|) | 分箱覆盖、外推不确定度有界 |
| DCR | O(|Ω|·|D_ρ|·n) | O(|Ω|·|D_ρ|) | 噪声注入保真、序列置信区间收敛 |
| CCM | O(N·K) | O(B) | 条件映射 Φ 一致、ESS 无偏 |
| AMO | O(K·M_probe + T·K) | O(K·M_probe) | (R1)-(R3) 成立、探索质量非零 |
| MSC | O(|Ω|·|D_ρ|) | O(|Ω|) | D_DS 可度量、支撑集可判定 |
| DMC | O(|S|·|Ω|·|D_ρ|) | O(|S|·|Ω|) | 证书逐维可审计、保守拒绝 |
| SDA | O(N_sim) | O(N_sim) | 注入模型与 M 一致 |

**正确性定理（Depth-Conditioned Mixture Soundness）**
假设第 54 轮 (A26)-(A28) 成立；新增：
**(A29)** 噪声剖面在条件集上的校准误差 `sup |M̂ - M| ≤ u_M`；
**(A30)** 配比响应面满足 (R1)-(R3)，且在探测配比上的估计误差 `|R̂_S - R_S| ≤ ε_R`；
**(A31)** 部署条件测度与训练测度的传输距离 `W_1(ν_w, ν_deploy) ≤ c·D_DS^ω`，且 `D_DS^ω ≤ Δ_w`。
则部署成功概率满足
```
P_success ≥ 1 - E_{c~ν_deploy}[1 - R_S(c)] - ε_R - β_E
          ≥ 1 - E_{c~ν_w}[1 - R_S(c)] - L_ρ·c·D_DS^ω - ε_R - β_E
```
其中 `L_ρ` 为 `R_S(·)` 关于条件度量的 Lipschitz 常数，`β_E` 为仿真-现实残差。**关键推论**：优化目标必须是**尾部加权风险** `E_{c~ν_deploy}[1-R_S(c)]`，若只最小化平均经验风险 `E_{c~ν_w}[1-R̂]`，则 `D_DS^ω` 项会把尾部误差放大成部署失败——这正是"平均好、尾部差"的数学来源。

**证明草图**：由 A30 得全条件集上的一致估计误差；将部署风险按 `ν_deploy` 分解为训练测度项与传输项，用 Kantorovich-Rubinstein 对偶把传输项界定为 `L_ρ·W_1`；再由 A31 把 `W_1` 收到 `D_DS^ω`；最后对 `Ω_adm` 上有限个条件箱做并集界，得到 `ε_R` 项。保守拒绝分支保证只在 `ρ_min+u` 之下才拒绝，故不会把不确定的尾部当成达标。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 噪声模型外推失效（室外/强光/镜面/透明） | 高 | 分域标定 + 外推不确定度门控 + 超出量程直接拒绝 |
| 配比响应面在有限探测配比上过拟合 | 高 | 结构化先验 (R1)-(R3) + 留出配比验证 + 保守下置信界 |
| 尾部样本稀缺导致估计方差大 | 高 | 传感器定向增强 SDA + 重要采样 + 尾部 ESS 下限 |
| 小样本真实集难以度量 `D_DS` | 中 | 分解为可单测量的物理子项 + 主动标定采集 |
| 云边配比漂移/灾难性遗忘 | 中 | 契约门控 + 基座参数冻结 + 回滚锚点 |
| 配比优化与动作关键性标注不一致 | 中 | 动作关键性由第 54 轮 ACS 剖面导出，避免双源真值 |

## 6. 本轮最大风险

**一句话**：把深度相机噪声剖面与数据配比统一为"条件覆盖测度"后，证书的 soundness 从"模型在平均分布上够好"转为"模型在**标定集张成的条件空间及其外推**上够好"；一旦真实部署落入标定未覆盖的材质/量程（如阳光下的黑色玻璃、2cm 近距微操作），或配比响应面在少量探测配比上被 (R1)-(R3) 先验强行平滑，`D_DS^ω` 与 `ε_R` 会被系统性低估，尾部条件上的动作失败将以"证书全绿、部署全红"的方式出现，因此必须以 **分域标定 + 外推不确定度硬门控 + 尾部独立红队集** 三重护栏，宁可拒绝配比，也不把"平均精度换来的覆盖假象"当作部署前提。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim+++D（DNP×DCR×CCM×AMO×MSC×DMC×SDA）

> 承接第 54 轮产物 v31。本轮把几何感知层 L1 从抽象接口落到**深度相机物理噪声**，并把训练侧的**数据配比**提升为一等公民，新增「深度-配比」层 𝔻：
> - **DNP（Depth Noise Profiling）**：深度传感器条件化噪声剖面 `M`；
> - **DCR（Depth-Conditioned Robustness）**：`ρ_S(c,d)`，把距离/材质/入射角纳入鲁棒性谱；
> - **CCM（Condition Coverage Measure）**：配比在条件空间的推前测度、尾部覆盖与 ESS；
> - **AMO（Adaptive Mixture Optimization）**：带证书的边际收益 water-filling 配比优化；
> - **MSC（Mixture-Sensor Contract）**：云边配比-传感器契约与漂移门控；
> - **DMC（Depth-Mixture Certificate）**：传感器-配比-动作-鲁棒性四元证书；
> - **SDA（Sensor-Directed Augmentation）**：用目标条件噪声反向注入的定向增强。
>
> IP 编号：IP-121~IP-127（共 7 个新增），升级 IP-115/118/120 以纳入深度条件与配比维度。

## 2. 配比响应面的具体参数化（可拟合形式）

为把 (R1)-(R3) 变成可优化的显式形式，采用带交互的饱和模型：
```
R_S(w) = R_∞ - Σ_i c_i (1 - w_i)^{α_i} + Σ_{i<j} κ_ij w_i w_j
```
- `α_i ≥ 1` 控制边际递减速度（`α_i` 越大越早饱和）；
- `c_i ≥ 0` 为第 `i` 源的"差距项"；
- `κ_ij` 为互补/替代交互（实测中 sim×real 常为正，即互补）；
- 约束 `|κ_ij| ≤ κ` 对应 (R3)。

单位成本弹性估计：
```
ẽ_i(w) = [α_i c_i (1-w_i)^{α_i-1} + Σ_{j≠i} κ_ij w_j] / cost_i
```
AMO 每步沿 `argmax_i ẽ_i` 做 simplex 上的投影梯度步，并保留 `ε_explore` 质量给低覆盖源，避免把尾部覆盖优化成 0。

### IP-121 DNP
```python
def profile_depth_sensor(calib_frames, bins, materials):
    M = {'sigma_z':{}, 'sigma_xy':{}, 'r_fp':{}, 'p_drop':{}, 'bias':{}}
    for b in bins:
        zs = [f.z for f in calib_frames if b.contains(f.z)]
        M['sigma_z'][b] = robust_fit(zs, model='piecewise(a*z^2+b)')
        M['sigma_xy'][b] = robust_fit_lateral(zs)
        M['r_fp'][b] = edge_flying_pixel_rate(zs)
        for m in materials:
            M['p_drop'][(b, m)] = drop_rate(zs, m)
            M['bias'][(b, m)] = robust_bias(zs, m)
    M['u_M'] = extrapolation_uncertainty(M, bins)
    return M
```

### IP-122 DCR
```python
def depth_conditioned_rho(skill, M, cond_grid, robust_dims, sampler, n0=32):
    rho, unc = {}, {}
    for c in cond_grid:                          # (z, m, theta_v)
        sigma = sensor_perturbation(M, c)        # 轴向+横向+飞点+丢失+偏置
        r_hat, u = sequential_estimate(
            lambda d: skill.robustness(c, d, sigma),
            robust_dims, n0=n0,
            stop_when=lambda u: u <= u_tol)
        rho[c], unc[c] = r_hat, u
    return rho, unc

def action_profile_cond(skill, A, M, cond):

    return {a: skill.can_execute(a, cond, noise=M) for a in A}
```

### IP-123 CCM
```python
def coverage(w, sources, cond_bins, action_criticality):
    nu = defaultdict(float)
    for i, D in enumerate(sources):
        for x in D:
            nu[cond_bins.assign(Phi(x))] += w[i] / max(1, len(D))
    cov = {b: nu[b] for b in cond_bins}
    ess = 1.0 / sum((w[i] ** 2) / max(1, len(sources[i]))
                    for i in range(len(w)))
    tail_bins = low_quantile_bins(cov, action_criticality, q=0.2)
    tail_mass = sum(cov[b] * action_criticality[b] for b in tail_bins)
    return Cov(cov), Tail(tail_mass), ESS(ess)
```

### IP-124 AMO
```python
def optimize_mixture(sources, M, budget, rho_min, action_criticality,
                     eps_explore=0.1):
    w = uniform(len(sources))
    R_hat = fit_response_surface(probe_mixes(sources), rho_hat,
                                 form='saturating_interaction',
                                 constraints=['monotone', 'concave', 'kappa'])
    while cost(w) < budget:
        e = estimate_unit_elasticities(R_hat, w, unit_cost)
        w = simplex_projected_step(w, argmax(e), eps_explore)
        if certified_tail(R_hat, w, rho_min, action_criticality):
            break
    if not certified_tail(R_hat, w, rho_min, action_criticality):
        return ('reject', 'tail_uncertified', w)
    return ('ok', w, W_cert(coverage(w), ESS(w), R_hat.uncertainty))
```

### IP-125 MSC
```python
def mixture_sensor_contract(w_c, w_e, M_c, M_e, Omega_c, Delta_w, rho_min):
    dds_w = criticality_weighted(depth_domain_gap(M_e, M_c))
    if dds_w > Delta_w:
        return ('reject', 'sensor_gap', dds_w)
    if not subset_support(w_e, Omega_c):
        return ('reject', 'support_escape', w_e)
    if not all(R_S(c) >= rho_min for c in Omega_c):
        return ('reject', 'base_cert_invalid')
    return ('ok', Contract(w_c, w_e, dds_w, Delta_w))
```

### IP-126 DMC
```python
def depth_mixture_certificate(skill_seq, M, w, Omega_adm, rho_min,
                              Delta_w, Theta_w):
    D_cert = build_sensor_cert(M, u_M=M['u_M'])
    rho, unc = depth_conditioned_rho_chain(skill_seq, M, Omega_adm)
    if any(rho[c] < rho_min + unc[c] for c in Omega_adm):
        return ('reject', 'uncertain_tail', worst(Omega_adm, rho, unc))
    wcert = W_cert(coverage(w), tail_mass(w), ESS(w))
    dds = depth_domain_gap_decomposed(M, w)
    if dds.weighted > Delta_w or wcert.drift > Theta_w:
        return ('reject', 'mix_shift', dds, wcert)
    return ('ok', J_DP(rho, D_cert, w, wcert, dds, evidence=calib_logs))
```

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DNP | O(N_cal·B·|M|) | O(B·|M|) | 分箱覆盖、`u_M` 可校准 |
| DCR | O(|Ω|·|D_ρ|·n) | O(|Ω|·|D_ρ|) | 噪声注入保真、序列界收敛 |
| CCM | O(N·K) | O(B) | `Φ` 一致、ESS 无偏、尾部可分 |
| AMO | O(K·M_probe + T·K) | O(K·M_probe) | (R1)-(R3) + 探索质量 > 0 |
| MSC | O(|Ω|·|D_ρ|) | O(|Ω|) | `D_DS` 可度量、支撑集可判定 |
| DMC | O(|S|·|Ω|·|D_ρ|) | O(|S|·|Ω|) | 逐维审计、保守拒绝 |
| SDA | O(N_sim) | O(N_sim) | 注入模型与 `M` 一致 |

**正确性定理（Depth-Conditioned Mixture Soundness）**
假设第 54 轮 (A26)-(A28) 成立；新增 **(A29)** `sup|M̂-M| ≤ u_M`；**(A30)** 响应面满足 (R1)-(R3) 且 `|R̂_S-R_S| ≤ ε_R`；**(A31)** `W_1(ν_w,ν_deploy) ≤ c·D_DS^ω` 且 `D_DS^ω ≤ Δ_w`。则：
```
P_success ≥ 1 - E_{c~ν_deploy}[1 - R_S(c)] - ε_R - β_E
          ≥ 1 - E_{c~ν_w}[1 - R_S(c)] - L_ρ·c·D_DS^ω - ε_R - β_E
```
**关键推论**：目标函数必须是尾部加权风险；最小化平均经验风险会因 `D_DS^ω` 项在尾部被放大而系统性高估部署成功率。

## 6. 本轮最大风险

**一句话**：把深度相机噪声剖面与数据配比统一为"条件覆盖测度"后，证书的 soundness 从"模型在平均分布上够好"转为"模型在**标定集张成的条件空间及其外推**上够好"；一旦真实部署落入标定未覆盖的材质/量程（如阳光下的黑色玻璃、2cm 近距微操作），或配比响应面在少量探测配比上被 (R1)-(R3) 先验强行平滑，`D_DS^ω` 与 `ε_R` 会被系统性低估，尾部条件上的动作失败将以"证书全绿、部署全红"的方式出现，因此必须以 **分域标定 + 外推不确定度硬门控 + 尾部独立红队集** 三重护栏，宁可拒绝配比，也不把"平均精度换来的覆盖假象"当作部署前提。
