# 第 47 轮（承接第 46 轮 v10/MVR；本轮灵感：同步定位与建图 × 多传感器融合） · Map-Fusion-Localizability：地图版本化可定位性证书与融合完整性监控（五层架构 v11）

> 承接第 46 轮 v23（MVR/VAD/SAB）与第 45 轮 v10（Energy-Context-Depth）。v10 把姿态做成能量-上下文-深度联合证书，v23 又叠加记忆-语音-安全绑定，但两者共享未检验的隐含假设 H5：**姿态的几何根「给定且静态」**，**多传感器「独立冗余」**。SLAM 与多传感器融合精确击穿 H5：SLAM 的地图会因闭环/重定位/场景结构变化而被改写，姿态只是相对某地图版本的坐标；融合的可靠性依赖故障独立性，相关/共模故障会让冗余变成「一致但错误」的假信心。新耦合问题：**如何让姿态证书对地图版本与融合完整性都 sound，并在地图增量或完整性失效时回溯地撤销/重验已签发证书，同时不因过度回溯而级联成大面积 fail-closed**。

## 0. 直觉与动机

**灵感 1（同步定位与建图 → 地图版本化、可定位性证书）**
直觉：姿态不是绝对量，而是「相对于地图版本 ν 的坐标」。闭环优化会整体重写地图，重定位会把机器人从一个子图搬到另一个子图，家具移动会改变地标锚点。此前签发的姿态证书在坐标系被改写后已不再是同一命题。做法：把地图版本号 ν 与地图哈希 h(M) 写入证书租约；每当闭环/重定位产生地图增量 ΔM，对一致性窗口 T_rev 内的历史证书做回溯重验，超出容忍半径 κ 者一律失效。

**灵感 2（多传感器融合 → 完整性监控，而非简单平均）**
直觉：更多传感器 ≠ 更可信。真正的融合安全是 RAIM 式完整性监控：新息卡方门限、故障检测与排除（FDE）、计算保护级 PL，只有 PL ≤ 告警限 AL 且完整性风险 ≤ 预算时证书才成立。必须显式建模**相关故障**（阳光同时致盲全部相机、同源标定漂移、共同热漂移），否则独立性假设会系统性低估 PL。

**灵感 3（耦合 → 融合作为可定位性「修复」资源）**
直觉：SLAM 退化（长走廊、弱纹理、动态遮挡）表现为信息矩阵最小特征值塌陷，退化子空间 D_ε 内姿态不可观测；LiDAR/IMU/深度恰好在这些方向补观测性。融合子集 F_t 的选择因此可复用 v10 的能量租约：在能量约束下选择使「动作相关方向」脱离 D_ε 的最小融合子集。SLAM 退化检测、融合完整性、能量调度在此焊为一体。

**耦合升级（五层 v11）**：在 v10 四层之上新增 **L0 地图-融合完整性层**。SLAM-CERT 产出地图版本化证书 P_t^M；FIM 做融合完整性并输出 PL/可用子集 F_t；MCM 监控地图增量并驱动回溯重验。上层：ECPS 的效用函数加入可定位性增益并选择 F_t；PSE 输出带地图版本的姿态；CAR 守卫加入 PL≤AL 与地图哈希一致；DCL 采集退化/闭环/故障样本；MVR 记忆键加入地图版本，跨版本记忆强制失效；CCA 新增共模故障与地图投毒红队。

## 1. 形式化定义（增量：定义 59–63）

**定义 59（地图版本化姿态证书）**
`P_t^M = (x̂_t, Σ_t, ν_t, h(M_t), ℓ_p, ℓ_m)`，其中 ν_t 为地图版本、h(M_t) 为地图哈希、ℓ_m 为地图一致性租约。
**有效性**：`hash(M_t)=h(M_t)` 且 `‖x̂_t - π_ν(x̂_t)‖_Σ ≤ κ`（π_ν 为投影回版本 ν 的一致性检查）且闭环一致性成立。

**定义 60（融合完整性与保护级）**
传感器子集 F，残差 r_i=z_i-ẑ_i，创新协方差 S_i。故障集 `Fault={i: r_iᵀS_i⁻¹r_i > χ²_τ}`。
融合协方差 `Σ_f = (Σ_{i∈F∖Fault} S_i⁻¹)⁻¹`。
保护级 `PL = k_σ·√λ_max(Σ_f)·√(1+(|F∖Fault|-1)·ρ_max)`，ρ_max 为相关故障上界。
**完整性判据**：`PL ≤ AL(φ)` 且 `P(|x̂-x|>AL) ≤ I_budget`。

**定义 61（可定位性 / 退化子空间）**
观测信息矩阵 `Λ=HᵀWH`，最小特征值 λ_min。退化子空间
`D_ε = {v : vᵀΛv < ε}`，动作相关方向 `d_φ ∈ D_ε` 时该方向姿态不可观测。
**可定位性判据**：`d_φ ∉ D_ε`，否则证书不得覆盖该动作。

**定义 62（地图增量与回溯重验）**
地图增量 `ΔM = M_new - M_old`，`‖ΔM‖_∞` 为最大地标位移。
一致性窗口 `T_rev`。对 `t'∈[t-T_rev, t]` 的证书：若 `‖ΔM‖>κ` 或重验失败 → invalidate；否则用新地图重签。
**回溯 soundness**：无任何在闭环后仍被执行、却基于过期地图签发的证书。

**定义 63（地图-融合-能量联合证书）**
`J_t=(P_t^M, ℓ_m, ℓ_e, m_t, F_t)`。
**联合 soundness**：`P(X_t∈P_t^M | map 一致, PL≤AL, ℓ_e 有效) ≥ 1-α_p`，且 `E(t)≥E_min`，且 `d_φ∉D_ε(F_t)`。

## 2. 三大新增产出与既有 IP 升级

**IP-69 SLAM-CERT（地图锚定姿态证书）**
- 地图版本化：每次地图更新生成 ν、h(M)；证书绑定版本
- 地标锚定：姿态以地标子集为锚，锚点位移直接放大 Σ_t
- 一致性半径 κ 与回溯重验队列：闭环后批量重验
- 过期证书熔断：版本不匹配立即 fail-closed

**IP-70 FIM（Fusion Integrity Monitor）**
- 新息卡方门限 + FDE：检测并排除故障传感器
- 保护级 PL 与告警限 AL：按任务相位 φ 动态设 AL
- 相关故障膨胀：ρ_max 显式进入 PL，抵御共模故障
- 可用子集输出：F_t 供 ECPS 做能量-可定位性联合选择

**IP-71 MCM（Map Change Monitor）**
- 闭环/重定位增量检测：ΔM 幅度与方向分解
- 动态物体地图维护：区分永久结构与临时遮挡
- 回溯失效：驱动证书重验与重定位调度
- 地图投毒检测：与独立审计集比对地标一致性

**既有 IP 升级**
IP-63 ECPS：效用函数加入可定位性增益 `Δλ_min(F)`，与能量租约联合选 F_t
IP-60 PSE：输出 P_t^M，Σ_t 叠加地图漂移项
IP-51 CAR：守卫加入 `PL≤AL`、`hash(M)=h(M)`、`d_φ∉D_ε`
IP-61 DCL：采集退化方向、闭环事件、共模故障样本
IP-62 CCA：新增共模故障注入、地图投毒、闭环回溯红队
IP-66 MVR：记忆键加入地图版本，跨版本记忆强制失效
IP-45 总线：新增 map-version / fusion-integrity / map-delta / revalidation-queue 话题

## 3. 算法骨架

L0 完整性层每控制周期：
1. 读传感器残差 r_i、地图状态 (M_t,ν_t)、动作相位 φ
2. FIM 做 FDE，得故障集 Fault、PL、可用子集 F_t
3. 若 PL>AL 或故障不可排除 → 触发降级/重定位请求
4. MCM 计算 ΔM；若闭环/重定位事件，批量重验窗口 T_rev 内证书
5. SLAM-CERT 用 F_t、Λ(F_t) 判退化，签发/拒绝 P_t^M
6. 交 ECPS 在能量与可定位性联合约束下选 m_t、F_t，再进 MVR/VAD/SAB
7. 任一地图哈希不一致、PL>AL、`d_φ∈D_ε` 或 ℓ_e 失效 → fail-closed

## 4. 本轮最大风险

**一句话**：融合完整性界若仍默认故障独立，相关/共模故障会让冗余产生「一致但错误」的高置信姿态，证书看似 sound 实则已失配；同时闭环回溯若过度激进又会把大量历史证书级联撤销、导致系统陷入持续 fail-closed；因此必须显式膨胀相关项、保留独立物理故障通道，并在地图版本不一致或闭环改写超阈时无条件 fail-closed。

## 2. 关键算法 伪代码

### IP-70 FIM
```
def fusion_integrity(sensors, z, pred, chi2_thr, k_sigma, rho_max, AL):
    active = [s for s in sensors if s.healthy]
    faulty = []
    for s in active:
        r = z[s] - pred[s]
        if r.T @ inv(S[s]) @ r > chi2_thr:
            faulty.append(s)
    healthy = [s for s in active if s not in faulty]
    if len(healthy) < MIN_FUSION or len(faulty) > MAX_EXCLUDABLE:
        return None  # 完整性不可判定 -> fail-closed
    Sigma_f = inv(sum(inv(S[s]) for s in healthy))
    PL = k_sigma * sqrt(largest_eig(Sigma_f)) * sqrt(1 + (len(healthy)-1) * rho_max)
    if PL > AL:
        return None  # 完整性失效
    return FusionDiag(healthy=healthy, Sigma_f=Sigma_f, PL=PL, faults=faulty)
```

### IP-71 MCM
```
def map_change_monitor(map_old, map_new, certs, kappa, T_rev, now):
    delta = map_delta(map_old, map_new)          # 地标位移场
    event = (norm_inf(delta) > kappa) or map_new.loop_closed or map_new.relocalized
    if not event:
        return delta, []
    invalidated = []
    for c in certs:
        if now - c.t <= T_rev:
            if norm_inf(delta) > kappa or not revalidate(c, map_new):
                invalidate(c)
                invalidated.append(c)
    if norm_inf(delta) > kappa:
        schedule_relocalization()
    return delta, invalidated
```

### IP-69 SLAM-CERT
```
def issue_map_cert(x_hat, Sigma, map_state, diag, lease_e, task_phase):
    if diag is None:
        return None                              # 融合完整性失败
    nu, hmap = map_state.version, map_state.hash
    if map_state.poisoned or not map_state.healthy:
        return None
    # 退化判据：动作相关方向必须可观测
    Lambda = information_matrix(map_state, diag.healthy)
    if action_direction(task_phase) in degenerate_subspace(Lambda, eps):
        return None
    Sigma_M = Sigma + diag.Sigma_f + map_state.drift_cov   # 叠加地图漂移
    if not energy_feasible(lease_e, task_phase):
        return None
    return PoseCert(x_hat, Sigma_M, nu, hmap, t=now, lease_p=lease_p)
```

### 联合决策（在地图-融合层之后）
```
def decision_v11(c_t, omega_t, B_t, v_t, map_state, sensors, task_phase, M, Q_safe):
    diag = fusion_integrity(sensors, z, pred, chi2_thr, k_sigma, rho_max, AL(task_phase))
    cert = issue_map_cert(x_hat, Sigma, map_state, diag, lease_e, task_phase)
    if cert is None:
        return 'fail-closed', 'integrity_or_map'
    # 记忆检索按地图版本分桶，跨版本不可复用
    mem = memory_lookup(v_t, c_t, B_t, M, map_version=cert.nu)
    if mem and map_version_valid(mem, cert.nu) and energy_lease_valid(mem.lease, t+Delta, E_min):
        m_t = mem.m
    else:
        m_t, F_t = ecps_select(c_t, B_t, cert, diag.healthy, task_phase)
    # SAB 绑定使用地图版本化证书
    B_prob = safety_bind(v_t, cert, omega_t)
    if B_prob < theta_safe:
        push(Q_safe, v_t); return m_t, 'queued'
    return m_t, 'execute'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| FIM 完整性 | O(|F|·d²) | O(|F|·d²) | FDE 后 PL≤AL ⇒ 完整性风险 ≤ I_budget（含相关膨胀） |
| MCM 地图监控 | O(|L|·d) | O(|L|·d) | ΔM 超 κ 或重验失败 ⇒ 相关证书失效 |
| SLAM-CERT 签发 | O(d³)（特征分解） | O(d²) | 地图哈希一致 ∧ d_φ∉D_ε ∧ 能量可行 ⇒ P_t^M sound |
| 联合决策 | O(|M|+|F|·d²) | O(|Q|+d²) | 完整性/地图/能量/退化任一失败 ⇒ fail-closed |

**正确性定理（v11）**：设相关故障上界为 ρ_max、回溯窗口为 T_rev、一致性半径为 κ。若 FIM 返回 diag 使 `PL≤AL` 且 `|Fault|≤MAX_EXCLUDABLE`，且地图哈希匹配、`d_φ∉D_ε(F_t)`、能量租约有效，则 SLAM-CERT 签发的 `P_t^M` 满足 `P(X_t∈P_t^M)≥1-α_p`。任何在闭环后发生 `‖ΔM‖>κ` 的历史证书，若未被重验通过即被 invalidate；决策层只接受有效证书，否则 fail-closed。因此不存在基于过期地图执行的动作。

**回溯 soundness 定理**：若 `T_rev ≥ max(闭环处理延迟, 证书缓存寿命)`，则闭环事件后不存在「未重验即执行」的证书；代价是窗口内证书召回率与 fail-closed 率之间需按 E119 调参。

## 4. 实验设计 E115–E120

| 实验 | 指标 | 门槛 |
|---|---|---|
| E115 地图版本证书 | 失效召回率、误失效率 | 召回 ≥ 99%；误失效 ≤ 5% |
| E116 融合 FDE | 故障检测率、误报率 | 检测 ≥ 98%；误报 ≤ 2% |
| E117 共模故障完整性 | 相关故障下 PL 覆盖率 | 实际误差超 AL 比例 ≤ 5%（1-α=0.95） |
| E118 退化可定位性 | 退化召回率、动作方向违例 | 召回 ≥ 95%；违例 0 起 |
| E119 闭环回溯 | 误执行过期证书数、fail-closed 率 | 误执行 0；fail-closed ≤ 3% |
| E120 100h 全局闭环 | 定位漂移、安全违例 | 漂移 ≤ 2cm；安全违例 0 起 |

回退策略：E115 误失效 > 10% → 增大 κ 并引入地标子集重锚；E117 覆盖率不足 → 提高 ρ_max 或强制双物理通道交叉校验；E119 fail-closed > 8% → 缩短 T_rev 并延迟执行而非整单撤销；E116 误报 > 5% → 放宽 χ²_τ 但同步抬高 AL。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 相关/共模故障使 PL 低估 | 高 | ρ_max 显式膨胀；保留独立物理故障通道；共模注入红队 |
| 闭环回溯过度导致持续 fail-closed | 高 | 调 T_rev/κ；窗口内先降级（暂停动作）再重验，非整单撤销 |
| 地图投毒/地标被恶意改变 | 高 | 独立审计地图比对；哈希+版本双绑定；异常地标隔离 |
| 记忆跨地图版本复用错误决策 | 中 | 记忆按 ν 分桶；跨版本强制失效并回退实时求解 |
| 退化子空间误判 | 中 | 多阈值 ε + 动作方向投影复核；退化时请求主动观测 |
| 融合延迟导致证书签发滞后 | 低 | 证书有效期 ℓ_p 与融合帧率绑定；超时自动失效 |
