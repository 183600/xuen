# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS 具身计量审计」IP-287~294；灵感循环第 1 轮；本轮灵感：「末端执行器控制」×「消融实验」）

> R72 把 GAUGE 从「认知层」推进到「具身层」：REG 调度契约、IRL 意图、DMEM 接触计量、EREFLEX 三层反作用、S2R-UQ、三域分离。它回答的是「测量链在实时系统里还能不能兑现风险界」。
> 但 R72 仍留下两个**没有被自己的方法审计**的缺口：
> - **末端执行器控制（EE control）缺口**：λ 只在关节/阻抗增益层面缩放；**证书到物理力之间还隔着一层任务空间控制律**。同一个 J_EMB 通过的系统，在雅可比奇异附近、在力/位混合切换瞬间、在摩擦锥因接触几何不确定而收缩时，会把「被认证的不确定度」放大成**未被认证的真实力/位移**。R72 的 DMEM 说「接触模式不确定」，却没回答「**这个不确定度经 EE 控制器之后，是否仍落在任务空间可容许集内**」。末端执行器控制不是执行细节，而是**风险证书的最后一厘米**。
> - **消融实验（ablation）缺口**：R72 声称「逐指令严格退化包含」（定义 364），但这是一条**未经实验证伪的宣言**。哪些层是**必要**的、哪些只是**充分**的、哪些在交互下**冗余甚至拮抗**？没有预注册、没有置信区间、没有交互项、没有安慰剂负控制的「消融」，很容易退化为**消融表演（ablation theater）**：删掉一个本来就不在关键路径上的模块，然后在有利于剩余模块的基准上宣布「去掉它也没差」。
>
> 本轮两个灵感恰好构成一对**对偶**：
> - **末端执行器控制 = 把风险证书在「任务空间」里执行出来**；
> - **消融实验 = 把退化链在「证据空间」里执行出来**。
>
> 两者都是 **realization（兑现）问题**：抽象的证书如何变成物理事实 / 经验事实，且都必须在不确定度下 **fail-closed（失败即降级）**。于是本轮把 R72 的「具身 GAUGE」再压一层，提出 **XEC-GAUGE-RAS**（eXecutable End-effector Control × Certifiable Ablation GAUGE for RAS，可执行末端控制 × 可证伪消融归因）：
>
> 核心命题：**不再只问「证书是否在有效域内」，而问「证书能否被末端执行器**执行**（executable）、能否被消融实验**证伪**（falsifiable）？**——**执行可证、归因可证伪**，才是真正的证据闭环。

## 0. 直觉与动机

**灵感 1（末端执行器控制 → 证书在任务空间会被「重新定价」）**
直觉：关节空间里一个很小的误差 `ε_q`，到末端会变成 `J ε_q`，在雅可比接近奇异时被放大 `κ = σ_max(J)/σ_min(J)` 倍。R72 在关节层设 `λ_floor`，但**物理世界只认任务空间的力/位移**。一个在关节空间「安全」的控制器，可以在任务空间里把 0.1° 的关节误差变成 1cm 的末端偏移；把 0.01N 的力偏差变成把杯子捏碎。更隐蔽的是**导纳控制**：力传感器零点偏置 `b` 不会被当成「测量误差」，而会被控制器当成真实外力，积分成**持续漂移的运动**——**计量误差被 EE 控制器静默地翻译成未建模的运动**。所以：**末端执行器控制是风险证书的「汇率兑换所」，它决定了认知层的不确定度在物理层值多少钱。**

**灵感 2（可容许扳手集 → 抓取安全是非空性，不是平均误差）**
直觉：R72 用 `u_tac` 抬高 λ、软化阻抗，这是**补偿性**的「平均更小心」。但抓取安全在几何上是一个**可行性问题**：存在一个接触力分布 `f`，同时满足摩擦锥 `‖f_t‖ ≤ μ f_n`、内力平衡（内力的零空间分量）、执行器力矩上限。这个集合记为 **𝒲_adm**。当接触几何不确定 `u_geom` 增大时，摩擦锥收缩，`𝒲_adm` **单调收缩**；一旦 `𝒲_adm = ∅`，无论你把 λ 调多大都不是「更安全」，而是「**不存在安全力**」。所以 EE 层必须**每周期检查非空性**，空了就换模式/松手/中止——这是 R71/R72 「非补偿性安全否决」在末端执行器上的**物理对应物**。

**灵感 3（零空间 → 安全余量要预置在冗余里，而不是临时借）**
直觉：冗余机械臂的零空间 `N = I − J⁺J` 是「不影响主任务」的自由度。成熟的 EE 控制会用它避奇异、避关节限位、维持可操作度。但**不确定度上升时，最危险的做法是让主任务先吃掉全部余量**，等奇异真的来了再补救。正确顺序相反：**不确定度越高，越要先把安全势垒 `h(q)` 预置进零空间预算 `ρ_null`**，宁可主任务误差略微变大，也不能让系统滑向 `𝒲_adm = ∅`。这是一条**非补偿性的资源分配律**：**安全余量不是剩余物，是优先扣除项。**

**灵感 4（消融实验 → 归因本身是一个带不确定度的测量）**
直觉：我们习惯说「组件 i 贡献了 Δ_i」。但 Δ_i 是**随机变量**：换随机种子、换数据划分、换评测协议都会变。所以严谨的说法是「在协议 P 下，Δ_i 的 95% CI 不含 0」。更关键的是**交互**：`Δ_{ij} ≠ Δ_i + Δ_j`。三个传感器冗余时，逐个删都「没用」，一起删才崩——这叫**冗余交互**；两个模块互相拆台时，单独删反而变好——这叫**拮抗交互**。没有交互项和安慰剂负控制的消融，会把「冗余」误判为「可删」，把「拮抗」误判为「必要」。**消融不是删代码，是对「必要性/充分性」做计量。**

**灵感 5（对偶 → 消融是「研究层的末端控制」，退化链是「研究层的摩擦锥」）**
直觉：把两个灵感并置会看到同构：
- EE 控制：抽象风险证书 → 任务空间可容许集 → 真实力；
- 消融实验：抽象退化链（定义 364）→ 组件必要性/充分性格 → 真实证据。
- 任务空间的「摩擦锥」= **消融可辨识域**；任务空间的「奇异放大」= **小样本/分布外下的效应放大**；零空间余量 = **实验预算**。
因此可以定义一条**消融-退化对偶一致性**：**凡在消融中被判为「安全必要」的组件，部署时就必须是不可旁路的 veto；凡只是「效率充分」的组件，部署时才允许降级。** 若二者矛盾，则 R72 宣称的「严格包含」不成立——**消融是退化偏序关系的经验见证人。**

## 1. 形式化定义（增量：定义 366–390）

**定义 366（XEC-GAUGE-RAS 总览与六不变式）** XEC-GAUGE-RAS = (EEC, ABL, J_XEC, GAUGE-RAS†, EMBODIED†)。六不变式：
(i) **任务空间兑现**：任何认知/具身证书必须经 **REO（风险执行算子）** 映射到任务空间可容许集 `A_x`，并证明映射后仍有效；未兑现的证书不得进入控制；
(ii) **可容许集非空**：每个控制周期必须验证鲁棒可容许扳手集 `𝒲_adm(u) ≠ ∅` 且任务空间误差椭球 `ℰ_x ⊆ A_x`；空即降级/中止；
(iii) **零空间优先**：不确定度上升时，安全余量先从零空间预算 `ρ_null` 扣除，再允许主任务降级；
(iv) **消融可证伪**：每个「必要性/充分性」断言必须携带 `(Δ, CI, u_abl, 交互阶数 k, 预注册哈希, 安慰剂负控制位)`；
(v) **消融-退化一致**：`ABL-Lattice` 的偏序必须与退化链（定义 364 的扩展）同构，否则证书无效；
(vi) **严格逐指令退化**：EEC 失效 ⇒ 退化为 R72 关节层 λ；ABL 失效 ⇒ 所有「组件必要性」断言降级为「未证」；两者全失效 ⇒ R68。

**定义 367（末端执行器控制模式）** `m ∈ M_ee = {pos, vel, imp, adm, force, hybrid}`（位置/速度/阻抗/导纳/力控/力位混合）。每种模式 `m` 定义：
- 任务坐标 `x ∈ ℝ^p`（p 可为 3/6，含姿态用李代数增量）；
- 控制律 `τ = Jᵀ F_m(x, ẋ, q, q̇; θ) + Nᵀ τ_null`；
- 不确定度传播算子 `P_m: (Σ_q, u_tac, u_switch) → Σ_x^{(m)}`；
- 有效域 `D_m ⊆ ℝ^p × 𝒮_q`（奇异、限位、摩擦锥外为空）。
**模式不是实现细节**：不同 `P_m` 对同一 `u_tac` 给出完全不同的任务空间风险，故 `m` 必须与证书一起被选择与验证。

**定义 368（风险执行算子 REO）** `REO: (J_EMB, λ, m, q) → (x_des, F_des, K, D, 𝒲_req)`。REO 是「证书 → 物理指令」的映射。其**兑现误差**
`ε_ro = d( REO(cert), 物理可实现指令集 )`
必须满足 `ε_ro ≤ ε_ro_max`。**J_EMB 有效只保证「模型认为安全」；REO 有效才保证「硬件能够安全地产生该指令」。** `J_EEC` 的核心就是认证 `REO` 与 `P_m`。

**定义 369（任务空间不确定度传播 TS-UQ）** 设关节后验协方差 `Σ_q`，雅可比 `J(q)`，则
`Σ_x = J Σ_q Jᵀ + Σ_kin + Σ_sw + Σ_tool`，
其中 `Σ_kin` 为运动学标定残差，`Σ_sw` 为模式切换暂态，`Σ_tool` 为末端工装/抓取偏移。定义**条件数放大因子** `κ(q) = σ_max(J)/σ_min(J)` 与**可操作度** `w(q) = √det(JJᵀ)`。当 `w → 0` 时 `Σ_x` 的迹以 `κ²` 量级爆炸。**任务空间风险缩放下界**
`λ_x ≥ λ_floor_x · (1 + tr(Σ_x)/s_x) · (1 + κ/κ_0)`。
**这是 R72 的 λ_floor 在任务空间的严格强化：关节安全 ≠ 任务安全。**

**定义 370（任务空间可容许集与风险缩放）** 可容许姿态/力域
`A_x = A_pose ∩ A_force ∩ A_vel`（避障、力上限、速度上限、关节限位投影）。
任务空间误差椭球 `ℰ_x(δ) = {e : eᵀ Σ_x⁻¹ e ≤ δ²}`。**任务空间 IVG 条件**：`ℰ_x(δ_99.9) ⊆ A_x`。若失败，先提 λ_x，再切模式，最后中止。
`λ_x = max( M_efs.risk_scale(U_ale, U_epi, H_z, u_tac, tr(Σ_x), κ), λ_floor_x(...) )`。
**物理/意图/接触/运动学不确定度同权进入分母。**

**定义 371（鲁棒可容许扳手集 CAWS）** 抓取矩阵 `G(q, c)`，接触力 `f = [f_1..f_k]`。名义集
`𝒲_adm = { w : w = G f, f_i ∈ ℱ_i(μ_i), ∃ f_int ∈ null(G) 使合力/内力平衡, τ = Jᵀ w ∈ [τ⁻, τ⁺] }`，
`ℱ_i(μ_i)` 为摩擦锥（可线性化为金字塔）。不确定度 `u = (u_geom, μ_lo, μ_hi, u_force, u_sens, u_slip)` 下定义**鲁棒集**
`𝒲_adm(u) = ⋂_{θ ∈ Θ(u)} 𝒲_adm(θ)`。
**安全裕度** `d_margin(u) = max_f min_i slack_i(f; θ)`。**非补偿性判据**：`d_margin(u) > 0 ⇔ 鲁棒可抓取`；`= 0` 即**不存在安全力**，与 λ 大小无关。

**定义 372（零空间安全预算 NSB）** 冗余度 `r = n − p`。安全势 `h(q) = min( d_joint_limits, d_self_collision, w(q)/w_0, d_singularity )`。零空间投影 `N = I − J⁺J`。预算 `ρ_null ∈ [0,1]`：
`τ_null = ρ_null · Nᵀ ∇h(q)`，主任务可用力矩为 `(1−ρ_null)` 的部分。
**预算律**：`ρ_null ≥ ρ*(u) = clip( ρ_0 + α·(u_tac + H_z + u_real + tr(Σ_x)/s_x), ρ_min, ρ_max )`。
**当 `ρ_null` 达到上限仍无法维持 `h ≥ h_min`，触发主任务降速/换模式，而不是继续借零空间。** 安全余量是优先扣除项。

**定义 373（控制模式切换证书 MSC）** 模式切换 `m → m'` 是一个**计量事件**：需记录切换时刻、切换前后力/位不连续量 `ΔF_sw, Δx_sw`、无扰切换（bumpless transfer）匹配误差 `ε_bump`、暂态不确定度 `u_switch`。
**切换暂态界**：`‖ΔF_sw‖ ≤ L_sw ‖Δparam‖ + u_switch`；`ε_bump ≤ ε_bump_max`。
**切换窗口**：只有在 `ℰ_x ⊆ A_x`、`𝒲_adm(u) ≠ ∅`、`ρ_null ≤ ρ_max` 同时成立时才允许切换；否则保持当前模式并降速。**切换不能成为绕开非空性检查的后门。**

**定义 374（末端执行器证书 J_EEC）** `J_EEC = (mode_m, REO_hash, P_m_proof, Σ_x_cert, CAWS_margin, NSB_budget, MSC_log, eec_ver)`。
`Valid(J_EEC) ⇔` `REO` 兑现误差 ≤ 上限 ∧ `ℰ_x(99.9%) ⊆ A_x` ∧ `d_margin(u) > 0` ∧ `ρ_null ≤ ρ_max` ∧ 所有切换都带 MSC 且 `ε_bump ≤ ε_bump_max` ∧ 参数携带 `S2R-UQ` 链。

**定义 375（消融算子与消融效应）** 系统 `S = compose(C_1..C_n)`，存在向量 `α ∈ {0,1}ⁿ` 表示组件在场。评测泛函 `Φ(S_α; D, P)`（可为安全/效率向量）。对子集 `A ⊆ N`，
`Δ_A = E_{D∼P, seed}[ Φ(S_N) − Φ(S_{N∖A}) ]`。
**注意符号约定**：`Δ_A > 0` 表示「删除 A 使指标变差，故 A 有价值」。**Δ_A 是随机变量，必须报 CI，不得只报点估计。**

**定义 376（消融不确定性）** `u_abl² = u_data² + u_seed² + u_protocol² + u_interaction² + u_leak²`，分别对应数据抽样、随机种子/优化、协议敏感性、交互未建模、泄漏/污染。**消融断言有效条件**：`CI_95(Δ_A) ∌ 0` ∧ `u_abl ≤ u_abl_max` ∧ 预注册协议哈希匹配 ∧ 安慰剂负控制通过。**一个只有点估计的消融不构成证据。**

**定义 377（交互效应与 k-稀疏交互模型）** 对 `i ≠ j`，
`I_{ij} = Δ_{N∖{i,j}}?` 用标准展开统一为：`I_{ij} = Φ(S_N) − Φ(S_{N∖{i}}) − Φ(S_{N∖{j}}) + Φ(S_{N∖{i,j}})`。
一般地 `I_B` 为 `|B|` 阶混合差分。**k-稀疏交互假设**：`|I_B| ≤ β^{|B|}·M`（`0<β<1`），即高阶交互快速衰减。**该假设本身必须被检验（E378），不能默认为真。**

**定义 378（必要性/充分性/冗余/拮抗格 ABL-Lattice）** 对组件 `i`：
- **必要（necessary）**：`Δ_{N∖{i}} > τ_nec`（删它变差）；
- **充分（sufficient）**：单独加入基座可恢复 `≥ (1−ε_suf)·Δ_i^{full}`；
- **冗余（redundant）**：`CI(Δ_{N∖{i}}) ∋ 0` 且无强交互；
- **拮抗（antagonistic）**：`Δ_{N∖{i}} < −τ_ant`（删它反而变好）。
**偏序**：必要性/拮抗性按「安全维度」优先于效率维度；安全必要组件构成**下集（down-set）**，任何降级都不得删除下集中的元素。**这正是退化链必须满足的偏序。**

**定义 379（安慰剂组件与负控制）** 加入一个**形状/算力/接口与真实组件相同但语义无效**的安慰剂 `C_p`（如等维随机投影、固定零输出）。理想情况 `CI(Δ_p) ∋ 0`。**若安慰剂被检出「有效应」，说明实验存在泄漏、选择偏差或评测 Goodhart，J_ABL 直接无效。** 安慰剂是消融自己的 gauge。

**定义 380（消融证书 J_ABL）** `J_ABL = (prereg_hash, coverage_matrix, Δ_table, CI_table, interaction_order_k, placebo_null, budget_report, abl_ver)`。
`Valid ⇔` 预注册匹配 ∧ 覆盖矩阵（每个被断言组件至少一次 leave-one-out、每对强交互至少一次 screen）完整 ∧ 安慰剂零效应通过 ∧ `k ≤ k_max` 且高阶截断界 ≤ ε ∧ `u_abl ≤ u_abl_max`。
**消融证书不是「做过实验」，而是「实验足以支撑该断言」。**

**定义 381（Shapley 归因与截断界）** 归因
`φ_i = Σ_{A⊆N∖{i}} [|A|!(n−|A|−1)!/n!] · (Φ(A∪{i}) − Φ(A))`，
用 bootstrap 给 CI。全枚举 `2ⁿ` 不可行时，在 k-稀疏交互下只枚举 `|A| ≤ k` 的子集，截断误差
`err_k ≤ Σ_{|B|>k} |I_B|/|B| ≤ M β^{k+1}/((k+1)(1−β))`。
**只有 `err_k ≤ ε_attr` 时才允许发布 Shapley 归因；否则只能发布「主效应 + 一阶交互」区间。**

**定义 382（消融-退化对偶一致性）** 设退化链给出的「可旁路偏序」`≼_deg`，消融格给出的「安全必要偏序」`≼_abl`。**对偶一致条件**：
`i ≼_abl j ⇔ i ≼_deg j` 对所有被断言组件成立；且 `i` 安全必要 ⇒ 部署时 `i` 位于不可旁路 veto 集。
**若不一致：要么退化链谎称包含（删除安全必要组件仍宣称安全），要么消融谎称必要（把冗余当关键）。两者都以 J_XEC 无效处理。**

**定义 383（联合证书 J_XEC）** `J_XEC = (J_EMB, J_EEC, J_ABL, dual_consistency_proof, xec_ver)`。
`Valid ⇔ Valid(J_EMB) ∧ Valid(J_EEC) ∧ Valid(J_ABL) ∧ 消融-退化对偶一致 ∧ 所有被断言组件在 J_ABL 覆盖矩阵中`.
**J_XEC 是第一个同时要求「物理可执行」与「经验可证伪」的证书。**

**定义 384（消融预算与预注册）** 消融实验本身有成本：`B_abl = (算力, 实机时长, 数据配额, 人类负担)`。预注册内容：假设集合 `H`、主指标与其方向、样本量/功效分析、多重比较校正、停止规则、排除标准、安慰剂定义。**任何事后改主指标 = 预注册失效 = J_ABL 无效。** `B_abl` 在 `(n, k)` 上的下界由定理 29 给出。

**定义 385（分布外消融与地板效应）** 在分布 `P_in` 上 `Δ_A` 可能因**地板/天花板效应**被压缩（基线已经饱和或已经失败）。定义**效应可辨域** `D_abl = {P : Φ(S_N) 与 Φ(S_{N∖A}) 均不在地板/天花板}`。**消融结论只能外推到 `D_abl`**；`P_in ∉ D_abl` 时该组件结论标为「不可辨（censored）」，不得当作「冗余」。

**定义 386（末端执行器威胁模型）** `ℰ_eec = {力/力矩零点偏置投毒（偏置被导纳积分成漂移）、雅可比标定错误（κ 被低估）、摩擦锥参数攻击（μ 被高估导致 d_margin 虚假为正）、模式切换重放/竞态、零空间注入恶意力矩、执行器饱和隐藏}`。

**定义 387（消融威胁模型）** `ℰ_abl = {预注册篡改、安慰剂泄漏、交互阶数低报（把高阶协同藏起来）、评测集污染、选择性报告（只报显著子集）、多重比较未校正、分布外外推}`。

**定义 388（严格退化链扩展）** 继承定义 364 并追加两层：
- `EEC` 失效（`J_EEC` 无效）⇒ 退化为 R72 的关节层 λ 控制，**保留 R68 硬安全包络**；
- `ABL` 失效（`J_ABL` 无效）⇒ **所有组件必要性断言降级为「未证」**，系统仍可运行，但**不得对外宣称「逐指令严格包含」**，不得据此裁剪安全组件；
- `EEC` 与 `ABL` 均有效 ⇒ 完整 XEC-GAUGE-RAS。
**安全侧只增不减：任何退化都保留 R68 硬安全包络与非补偿性 veto。**

**定义 389（部署-消融闭环 DABL）** 部署日志（含 `J_EEC` 每周期 `d_margin, κ, ρ_null` 与熔断记录）作为**在线证据**回流消融：若某组件在部署中从未进入关键路径（`Δ` 恒 0 且 `d_margin` 不敏感），标记为**候选冗余**，进入下一轮离线消融的优先队列。**消融指导部署裁剪，部署反向挑战消融结论——闭环而非一次性。**

**定义 390（运行时末端监控器 EEM）** 与 RTM 同级：每控制周期自测 `κ(q)`, `d_margin(u)`, `ρ_null`, `ε_bump`, 饱和率、力/力矩零漂估计；超阈即**先降 λ_x、再提 ρ_null、再切模式、最后中止**。EEM 静态内存、零依赖、形式化验证，且其自身的「零漂估计」必须由**独立第二通道**（视觉/本体）交叉校验，防止「监控器与传感器一起漂」。

def end_effector_certify(q, qd, J, Sigma_q, u, mode, params):
    # 1) 任务空间不确定度（含奇异放大）
    Sigma_x = J @ Sigma_q @ J.T + Sigma_kin + Sigma_sw + Sigma_tool
    kappa   = cond(J)                       # sigma_max / sigma_min
    w       = sqrt(max(det(J @ J.T), 0.0))
    # 2) 可操作度/奇异 -> 抬升任务空间地板
    lam_x   = max(risk_scale_x(u, trace(Sigma_x), kappa, params),
                  params.lam_floor_x * (1 + trace(Sigma_x)/params.s_x)
                                    * (1 + kappa/params.kappa_0))
    # 3) 任务空间误差椭球必须落在可容许集内
    if not ellipsoid_subset(Sigma_x, params.delta_999, admissible_set(q, params)):
        return EECResult(valid=False, reason='A_x_violation', lam_x=lam_x)
    # 4) 鲁棒可容许扳手集非空（非补偿性）
    margin = robust_caws_margin(q, u, params)     # d_margin(u)
    if margin <= 0.0:
        return EECResult(valid=False, reason='CAWS_empty', lam_x=lam_x)
    # 5) REO 兑现：证书 -> 可物理实现指令
    cmd = reo_map(lam_x, mode, q, qd, params)
    if reo_realizability_error(cmd, params) > params.eps_ro_max:
        return EECResult(valid=False, reason='REO_unrealizable', lam_x=lam_x)
    return EECResult(valid=True, lam_x=lam_x, margin=margin, cmd=cmd, J_EEC=...)

# IP-296 TS-UQ + IP-297 CAWS + IP-298 NSB：任务空间实现（控制域）
def ee_control_step(M, snap, q, qd):
    J   = M.kin.jacobian(q)
    Sig_q = snap.Sigma_q
    u   = UncertaintyBag(u_tac=snap.u_tac, H_z=snap.H_z,
                         u_real=snap.u_real, u_q=trace(Sig_q))
    mode = M.mode_selector.current
    cert = end_effector_certify(q, qd, J, Sig_q, u, mode, M.eec_params)
    if not cert.valid:
        mode = M.msc.next_safe_mode(mode, u)          # 切换受 MSC 约束
        if mode is None: return M.abort('EEC_no_safe_mode')
        cert = end_effector_certify(q, qd, J, Sig_q, u, mode, M.eec_params)
        if not cert.valid: return M.abort(cert.reason)
    # 零空间优先扣除：不确定度越高，安全势权重越大
    rho = clip(M.nsb.rho0 + M.nsb.alpha * (u.u_tac + u.H_z + u.u_real
                                           + trace(Sig_q)/M.nsb.s_q),
               M.nsb.rho_min, M.nsb.rho_max)
    h   = safety_potential(q, M.scene)
    if h < M.nsb.h_min and rho >= M.nsb.rho_max:
        label = 'primary_degrade'                     # 不再借零空间
    else:
        label = 'nominal'
    tau_null = rho * nullspace_projector(J).T @ grad(h)
    tau      = J.T @ cert.cmd.wrench + tau_null
    M.msc.record_switch(mode, cert.cmd)               # 记录暂态与 ε_bump
    return tau, cert.lam_x, label

# IP-299 MSC：模式切换的无扰与暂态界
def switch_mode(m_from, m_to, state, u):
    dF = force_discontinuity(m_from, m_to, state)
    eps_bump = bump_mismatch(state)
    u_switch = L_SW * norm(dF) + u.u_force
    if eps_bump > EPS_BUMP_MAX or u_switch > U_SWITCH_MAX:
        return None                                   # 拒绝切换，保持降速
    return Switched(mode=m_to, u_switch=u_switch, dF=dF, eps_bump=eps_bump)

# IP-300 ABL-OPS：消融算子（离线，带预注册与 CI）
def ablation_effect(components, target_A, data, protocol, seeds, n_boot=2000):
    deltas = []
    for s in seeds:
        full   = evaluate(compose(components, all_on), data, protocol, seed=s)
        ablate = evaluate(compose(components, off=target_A), data, protocol, seed=s)
        deltas.append(full - ablate)
    mean, lo, hi = bootstrap_ci(deltas, n_boot)       # Δ_A 与 95% CI
    u_abl = decompose_abl_uncertainty(deltas, data, protocol)
    return AblationResult(delta=mean, ci=(lo, hi), u_abl=u_abl,
                          valid=(lo > 0 or hi < 0) and u_abl <= U_ABL_MAX)

# IP-301 ABL-LATTICE：必要性/充分性 + 交互 + 安慰剂
def build_ablation_lattice(components, data, protocol, budget):
    base  = ablation_table(components, order=1, data=data, protocol=protocol)
    k_hat = estimate_interaction_order(base)          # 必须检验，不默认
    pairs = screen_pairs(components, base)            # 交互 screen
    lattice = {}
    for i in components:
        d_i, ci_i = base[i]
        inter = sum(abs(I_ij) for j in pairs[i])
        if ci_i[0] > TAU_NEC and d_i > inter: lattice[i] = 'necessary'
        elif d_i < -TAU_ANT:                  lattice[i] = 'antagonistic'
        elif contains_zero(ci_i):             lattice[i] = 'redundant_or_uncertain'
        else:                                 lattice[i] = 'sufficient_only'
    placebo = ablation_effect(components + [placebo_component()], [], data, protocol)
    placebo_ok = contains_zero(placebo.ci)
    # Shapley 仅在高阶交互可忽略时发布
    shapley = shapley_with_truncation(components, k_hat, budget)
    return LatticeResult(lattice=lattice, order_k=k_hat, placebo_ok=placebo_ok,
                         shapley=shapley if shapley.err_k <= EPS_ATTR else None)

# IP-302 联合证书 J_XEC + 部署-消融闭环
def xec_gauge_round(M, obs, audio, tac_frame, deploy_log):
    tau, lam_x, label = ee_control_step(M, M.snapshot.read_latest(), M.q, M.qd)
    ctrl_cert = make_ctrl_cert(tau, lam_x, label, M.eem.status())  # 最小片段
    if M.clock.due_metric():
        J_emb = M.embodied.assemble(M, obs, audio, tac_frame)
        J_eec = M.eec.assemble(M.eem.log(), M.msc.log())
        # 部署证据 -> 候选冗余 -> 下一轮消融优先队列
        cand = M.dabl.candidates(deploy_log, M.eec.sensitivity_table)
        J_abl = M.abl.assemble(prereg=M.prereg.hash, candidates=cand,
                               coverage=M.coverage_matrix)
        dual_ok = M.dual.check(M.lattice, M.degradation_order)
        J_xec = JointCert(J_emb, J_eec, J_abl, dual_ok)
        if not J_xec.valid:
            M.policy = 'claim_downgrade'              # 不许宣称严格包含
    return tau, lam_x, J_xec

## 3. 推导

**引理 33（任务空间风险放大）** 设关节误差协方差 `Σ_q`，雅可比 `J` 条件数 `κ`。则 `tr(Σ_x) = tr(J Σ_q Jᵀ) ≥ σ_min(J)² tr(Σ_q)` 且上界 `≤ σ_max(J)² tr(Σ_q) = κ² σ_min² tr(Σ_q)`。故当 `σ_min → 0`（近奇异），同样的关节不确定度在任务空间被放大至 `O(κ²)`。系：**关节层 λ_floor 无法覆盖任务空间风险，必须显式加入 `κ` 与 `Σ_x`。**

**引理 34（鲁棒 CAWS 单调收缩）** 记置信集 `Θ(u)`，若 `u₁ ≤ u₂` 逐分量则 `Θ(u₁) ⊆ Θ(u₂)`，故 `𝒲_adm(u₂) = ⋂_{θ∈Θ(u₂)} 𝒲_adm(θ) ⊆ ⋂_{θ∈Θ(u₁)} 𝒲_adm(θ) = 𝒲_adm(u₁)`。系：**不确定度上升只会让可容许扳手集变小，不会变大；`d_margin(u)` 单调不增。因此「非空性检查」在不确定度增加时必须重跑，不能缓存。**

**引理 35（零空间预算充分性）** 设冗余 `r ≥ 1`、安全势 `h(q)` 的零空间分量 `‖Nᵀ∇h‖ ≥ g_0 > 0`、执行器力矩余量 `τ_res`。则存在 `ρ* = τ_res/(L_h ‖Nᵀ∇h‖)` 使 `ρ_null ≥ ρ*` 时 `ḣ ≥ 0`（安全势不降），而主任务误差增量 `≤ (1−ρ*)·ε_task`。**安全余量的代价可定量预支，不必等奇异发生才补救。**

**引理 36（切换暂态有界）** 若 `F_m(·;θ)` 对 `θ` 与状态 Lipschitz（常数 `L_F, L_SW`），则 `‖ΔF_sw‖ ≤ L_F‖Δθ‖ + L_SW‖Δx‖`。切换前用 `state` 预测 `ΔF_sw` 与 `ε_bump`，超阈即拒绝切换（定义 373）。系：**MSC 把「切换」从隐式瞬态变成可验证事件。**

**引理 37（消融交互稀疏可辨识）** 在 k-稀疏交互假设 `|I_B| ≤ Mβ^{|B|}` 下，枚举所有 `|A| ≤ k` 的子集即可估计全部主效应与 ≤k 阶交互，误差 `≤ Mβ^{k+1}/((k+1)(1−β))`；对固定 `k` 需 `O(n^k)` 次系统评测，且最坏情形下界为 `Ω(n^k)`（存在构造使高阶交互不可忽略）。系：**消融预算下界不是经验值，是信息论下界。**

**引理 38（安慰剂负控制的效力）** 若实验无泄漏/选择偏差/协议 Goodhart，则安慰剂 `C_p` 与指标独立，`E[Δ_p] = 0`；因此拒绝 `CI(Δ_p) ∋ 0` 的等价于拒绝「实验有效」。注意这是**必要非充分**条件：安慰剂通过不能证明无偏，只能证明「未检出明显泄漏」。系：**安慰剂是消融的「零点校准」，不是「精度保证」。**

**定理 27（任务空间安全支配）** 在引理 33–34 下：存在执行使 `Σ_q` 在关节有效域内、`λ` 在 R72 界内，但 `ℰ_x ⊄ A_x` 或 `𝒲_adm(u) = ∅`。因此**仅凭 J_EMB + 关节 λ 不能推出物理安全**；必须 `J_EEC` 有效。**这是 R72 证书体系的严格缺口，也是本轮 EEC 存在的必要性证明。**

**定理 28（J_EEC 有效 ⇒ 任务空间非补偿安全）** 若 `Valid(J_EEC)`，则对该周期：(i) `ℰ_x(99.9%) ⊆ A_x` ⇒ 任务空间误差在可容许域；(ii) `d_margin(u) > 0` ⇒ 存在满足摩擦锥/内力/执行器约束的力；且该结论**不依赖 λ 的大小**（非补偿）；(iii) `ε_bump ≤ ε_bump_max` 且切换窗口条件成立 ⇒ 无未认证瞬态；(iv) `REO` 兑现 ⇒ 指令物理可实现。故**物理力/位风险 ≤ ε_eec（相对 EE 测量与运动学模型）。**

**定理 29（消融可辨识性与预算）** 在 k-稀疏交互与安慰剂有效下，`J_ABL` 有效 ⇒ 所有被断言组件的必要性/充分性分类可辨识，且 Shapley 截断误差 ≤ `ε_attr`；所需系统评测数 `N_eval = Θ(n^k)`。若 `N_eval > B_abl`，则只能发布低于 `k` 阶的断言（定理给出「预算 → 可断言阶数」的映射）。**消融结论的强度被预算严格限制，不能免费得到高阶归因。**

**定理 30（消融-退化对偶）** 若 `J_XEC` 有效，则 `≼_abl` 与 `≼_deg` 同构：安全必要组件恰为退化链中不可旁路的 veto 组件。证明：若某安全必要组件在退化链中可旁路，则存在一个退化配置删除它但仍被宣称安全，与消融的 `Δ > τ_nec` 矛盾；反之若某可旁路组件被消融判为必要，则消融的 CI 与退化实验不一致，J_ABL 或退化实验之一失效。系：**「严格逐指令包含」不再是宣言，而是可被消融反驳的经验命题。**

**定理 31（XEC 证书 ⇒ 可执行且可证伪）** 若 `Valid(J_XEC)`，则 (i) 物理执行满足任务空间非补偿安全（定理 28）；(ii) 所有组件贡献断言有 CI 与交互界支撑（定理 29）；(iii) 退化链与消融格一致（定理 30）；(iv) 认知层风险界（J_EMB）成立。故系统同时**可执行（executable）**与**可证伪（falsifiable）**。**证书的重量从「我们验证过」转移到「我们验证过验证方法本身」。**

def ablation_effect(components, target_A, data, protocol, seeds, n_boot=2000):
    deltas = [evaluate(compose(components, all_on), data, protocol, s)
              - evaluate(compose(components, off=target_A), data, protocol, s)
              for s in seeds]
    mean, lo, hi = bootstrap_ci(deltas, n_boot)
    u_abl = decompose_abl_uncertainty(deltas, data, protocol)
    return AblationResult(delta=mean, ci=(lo, hi), u_abl=u_abl,
                          valid=((lo > 0) or (hi < 0)) and u_abl <= U_ABL_MAX)

# IP-301 ABL-LATTICE：必要性/充分性 + 交互 + 安慰剂 + Shapley
def build_ablation_lattice(components, data, protocol, budget):
    base  = ablation_table(components, order=1, data=data, protocol=protocol)
    k_hat = estimate_interaction_order(base)        # 必须检验
    pairs = screen_pairs(components, base)
    lattice = classify(base, pairs, TAU_NEC, TAU_ANT, EPS_SUF)
    placebo = ablation_effect(components + [placebo_component()], [],
                              data, protocol)
    placebo_ok = contains_zero(placebo.ci)
    shapley = shapley_with_truncation(components, k_hat, budget)
    return LatticeResult(lattice, k_hat, placebo_ok,
                         shapley if shapley.err_k <= EPS_ATTR else None)

# IP-302 J_XEC：联合证书 + 部署-消融闭环
def xec_gauge_round(M, obs, audio, tac_frame, deploy_log):
    tau, lam_x, label = ee_control_step(M, M.snapshot.read_latest(), M.q, M.qd)
    if M.clock.due_metric():
        J_emb = M.embodied.assemble(M, obs, audio, tac_frame)
        J_eec = M.eec.assemble(M.eem.log(), M.msc.log())
        cand  = M.dabl.candidates(deploy_log, M.eec.sensitivity_table)
        J_abl = M.abl.assemble(prereg=M.prereg.hash, candidates=cand,
                               coverage=M.coverage_matrix)
        dual_ok = M.dual.check(M.lattice, M.degradation_order)
        J_xec = JointCert(J_emb, J_eec, J_abl, dual_ok)
        if not J_xec.valid:
            M.policy = 'claim_downgrade'            # 不许宣称严格包含
    return tau, lam_x, J_xec

## 4. 推导

**引理 33（任务空间放大）** `tr(Σ_x) = tr(JΣ_qJᵀ) ∈ [σ_min²trΣ_q, κ²σ_min²trΣ_q]`；近奇异 `σ_min→0` 时以 `O(κ²)` 放大。系：**关节 λ_floor 无法覆盖任务空间风险。**

**引理 34（鲁棒 CAWS 单调收缩）** `u₁≤u₂ ⇒ Θ(u₁)⊆Θ(u₂) ⇒ 𝒲_adm(u₂)⊆𝒲_adm(u₁) ⇒ d_margin(u₂)≤d_margin(u₁)`。系：**非空性必须随不确定度变化重算，不能缓存。**

**引理 35（零空间预算充分性）** 若 `r≥1`、`‖Nᵀ∇h‖≥g_0`、力矩余量 `τ_res`，取 `ρ*=τ_res/(L_h‖Nᵀ∇h‖)`，则 `ρ_null≥ρ*` 时 `ḣ≥0`，主任务误差增量 `≤(1−ρ*)ε_task`。系：**安全余量可定量预支。**

**引理 36（切换暂态有界）** Lipschitz 下 `‖ΔF_sw‖≤L_F‖Δθ‖+L_SW‖Δx‖`；超阈拒绝切换。系：**切换从隐式瞬态变为可验证事件。**

**引理 37（消融交互稀疏可辨识）** k-稀疏 `|I_B|≤Mβ^{|B|}` 下，枚举 `|A|≤k` 可估全部主效应与 ≤k 阶交互，误差 `≤Mβ^{k+1}/((k+1)(1−β))`；需 `O(n^k)` 次评测，最坏下界 `Ω(n^k)`。系：**消融预算有信息论下界。**

**引理 38（安慰剂效力）** 无泄漏时 `E[Δ_p]=0`；拒绝 `CI(Δ_p)∋0` 等价于拒绝「实验有效」。**安慰剂是零点校准，不是精度保证。**

**定理 27（任务空间安全支配）** 存在执行使 `Σ_q` 关节安全、`λ` 在 R72 界内，但 `ℰ_x⊄A_x` 或 `𝒲_adm(u)=∅`。故 **J_EMB + 关节 λ ⇏ 物理安全**，必须 `J_EEC`。**这是 R72 的严格缺口。**

**定理 28（J_EEC 有效 ⇒ 任务空间非补偿安全）** 有效 J_EEC ⇒ `ℰ_x⊆A_x` ∧ `d_margin>0`（与 λ 无关）∧ `ε_bump` 受控 ∧ REO 兑现，故物理力/位风险 `≤ ε_eec`。

**定理 29（消融可辨识性与预算）** k-稀疏 + 安慰剂有效 + J_ABL 有效 ⇒ 分类可辨识、Shapley 截断 `≤ε_attr`，评测数 `Θ(n^k)`；若超预算则只能发布低于 k 阶的断言。**结论强度被预算严格限制。**

**定理 30（消融-退化对偶）** J_XEC 有效 ⇒ `≼_abl` 与 `≼_deg` 同构，安全必要组件 = 不可旁路 veto。**「严格包含」从宣言变为可被消融反驳的经验命题。**

**定理 31（XEC 证书 ⇒ 可执行且可证伪）** J_XEC 有效 ⇒ 物理非补偿安全（定理 28）∧ 归属断言有 CI/交互界（定理 29）∧ 退化链与消融一致（定理 30）∧ 认知风险界（J_EMB）。**证书的重量从「我们验证过」转移到「我们验证过验证方法本身」。**

## 7. 本轮最大风险

**一句话**：XEC-GAUGE-RAS 的安全现在同时依赖两套**自身需要被计量**的前提——EE 侧的力/力矩零点、雅可比标定、摩擦锥参数，以及消融侧的预注册、安慰剂负控制、交互阶数——而这两套前提都由**同一批在分布内表现良好的工具**产出；如果力偏置被导纳积分成漂移、雅可比误差让 `κ` 被低估、`μ` 被高估使 `d_margin` 虚假为正，同时安慰剂恰好泄漏、交互阶数被低报、预注册事后被微调，系统就会生成一份**「物理可执行、经验可证伪」双盖章的 J_XEC**：消融显示「每层都必要」、EE 显示「椭球在可容许集内、扳手集非空」，而真实世界里杯子已被捏碎、人已被撞到——这就是**证伪工具与被证伪对象共享同一个未审计测量前提**所导致的「自信地错自己的可证伪性」。**

次级风险与缓解：
1. **EE 计量前提共模失效** → EEM 的零漂估计强制由**独立第二通道**（视觉/本体）交叉校验；力/力矩双传感器冗余，单源不定案。
2. **消融 Goodhart/泄漏** → 安慰剂负控制 + 预注册哈希 + 多重比较校正 + 分布外留出；任一失败即 J_ABL 无效。
3. **交互阶数低报** → 强制报告 `k̂` 与截断界 `err_k`；预算不足时**主动降低可断言阶数**，不默认为 0。
4. **地板/天花板效应** → 先测效应可辨域 `D_abl`；在饱和基准上标「不可辨（censored）」，禁止判为冗余。
5. **任务空间证书计算超时** → 控制域只做 `Σ_x/κ` 近似与保守 CAWS 界，精确 LP/QCQP 在计量域异步更新并带版本号。
6. **零空间与主任务博弈** → `ρ_null` 有硬上限 `ρ_max`；达上限仍不满足 `h_min` 时降主任务/换模式，绝不无限借余量。
7. **复杂度/实验成本爆炸** → 模块化上限 `|M_ee|≤6, |C|≤24, k_max≤3`；用定理 29 的 `Θ(n^k)` 显式核算 `B_abl`，超预算则裁剪断言而非裁剪实验。
