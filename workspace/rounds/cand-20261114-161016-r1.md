# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~302；灵感循环第 4 轮；本轮灵感：「姿态估计」×「仿真到现实」）

> R73 把 GAUGE 从「具身计量审计」推进为「计量契约代数」：MMS 让证据成为带类型、带预算、带反作用通道、带否决语义的模块；CPB 把体系蒸馏为三条可证伪主张；热替换定理把「换本体零改核心」从实验希望升为结构定理。但 R73 留下三个**类型级**问题，本轮灵感正好各补一块：
> - **流形类型缺失（姿态估计）**：R73 的证据不确定度是标量/欧氏向量，组合律是 u_out ≥ u_A + L_B·u_A。可位姿住在 SE(3)/SO(3)：非交换、需伴随（adjoint）搬运、对物体对称性呈多峰、且误差沿运动链被杠杆臂放大。把位姿塞进标量预算不是「近似」，而是**类型错误**——一个 2° 的腕部朝向误差在 20cm 杠杆臂上就是约 7mm 指尖误差；标量 Lipschitz 界要么真空（L 大到无信息），要么系统性低估（漏掉 κ(τ) 放大因子）。R73 的 CCA 只在零杠杆臂极限才可靠。
> - **仿真契约缺失（仿真到现实）**：R73 只在部署域（真实）校准证据，从未声明「仿真器证据契约」是什么，更没有证明仿真与真实的关系。而现代机器人策略几乎都在仿真里训练：仿真有精确位姿、真实有位姿估计误差；仿真有简化材质、真实有透明/镜面；仿真有理想时延、真实有抖动。领域随机化（DR）把这些差异当作「随机化参数」去赌覆盖，但**随机化不等于覆盖**——它没有给出「仿真契约保守支配真实契约」的证明，也没有给出「支配在何处失效」的审计。
> - **证书无有效域（差距 × 闭环）**：即使能证「仿真契约 ⊒ 真实契约」，这个支配关系也是**状态相关**的（对称物体、遮挡、工作空间边缘处差距最大），且策略自身的动作会改变位姿分布——机器人可能走出被认证的区域。R73 的证书是全局的、开环的；它没有回答「这张证书在哪里有效、由谁保证策略不走出去」。
>
> 本轮三个想法：
> - **姿态估计 → MEC + POSEM + ACT**：证据契约升级为**流形证据契约**（流形类型/参考系/伴随/对称群/模态支撑全部成为接口类型）；位姿证据用**六分量 + 对称模态混合后验**；组合用**伴随因果传输**（Loewner 序单调，杠杆臂放大显式进入预算）。
> - **仿真到现实 → RGC + S2R-GAP + R_xfer**：把 sim-to-real 重构为「**契约支配的可靠性**」——仿真契约是真实契约的保守抽象（abstract interpretation 的 soundness），迁移证书 J_XFER 只在「支配成立 ∧ 未被证伪 ∧ 策略被约束在认证域」时有效。领域随机化被降级为「构造保守仿真契约的一个启发式」，不再是安全论据。
> - **自我批判（蒸馏的第二次应用）→ 证伪优先**：任何迁移证书必须附带**证伪器**（主动搜索最大差距的现实扰动）和**有效域**；没有证伪器的「已认证迁移」在本文中视为无效。这把 R73 的 CPB 从「主张-证明绑定」推进为「主张-证明-证伪三元绑定」。
>
> 核心命题：**不再问「仿真训练的策略能否迁移到现实」，而问「仿真证据契约能否被证明保守覆盖真实证据契约，且这张迁移证书在何处、对何种任务、在何种闭环约束下是可证伪有效的？」** 把 R73 的 MODGAUGE-RAS 重构为 **PACT-RAS**（Pose-Aware Contract Transfer for RAS）——**位姿感知的契约迁移**。

## 0. 直觉与动机

**灵感 1（姿态估计 → 位姿不是「更大的噪声」，而是另一种类型的证据）**
直觉：给位姿估计算一个标量方差，就像给旋转矩阵算算术平均——看似可行，实则丢掉了群结构。位姿误差的真实结构是：
- **非交换与参考系**：同一个位姿误差，在相机系、物体系、工具系里协方差不同，搬运必须用伴随 Ad_T；忽略伴随 = 在错误的坐标系里做预算。
- **杠杆臂放大**：末端位置误差 ≈ 朝向误差 × 杠杆臂。R73 的标量串联 u_out ≥ u_A + L_B·u_A 只有在杠杆臂为零时才是紧的；真实装配里杠杆臂是主导项。
- **对称导致的模态**：杯子、瓶子、盒子、螺栓的位姿后验是多峰的（绕对称轴任意旋转、180° 翻转）。用单峰高斯覆盖多峰后验，conformal 的**边缘**覆盖率仍可能达标，但**逐模态**覆盖率会在模态切换时系统性失效。
- **遮挡与部分视图**：只看到杯口时，位姿沿视线方向近乎不可观；误差是重尾而非高斯。
- **链路与时间**：物体在手中时，位姿由正运动学 + 手眼标定决定，误差沿关节链相关；时延与运动模糊让误差带记忆。
因此 POSEM 的六分量是：u_obs（观测）、u_sym（对称模态）、u_occ（遮挡/部分视图）、u_kin（运动链/正运动学）、u_frame（手眼/外参）、u_time（时延/运动/滤波滞后）。与 DPEM 的六分量同构，但组合律必须换成流形版本。

**灵感 2（仿真到现实 → 仿真契约是真实契约的抽象，迁移是 soundness）**
直觉：抽象解释里，若抽象域 A 保守覆盖具体语义 C（C ⊆ γ(A)），则在 A 上证明的性质对 C 成立。sim-to-real 完全同型：
- 真实证据分布 = 具体语义 C_real；
- 仿真证据分布 = 抽象域 C_sim；
- 若 C_real ⊆ γ(C_sim)（真实噪声不超出仿真声明的噪声包络、真实模态集合 ⊆ 仿真模态集合、真实支撑 ⊆ 仿真支撑），则任何**只依赖契约**的安全证明从仿真迁移到真实；
- 领域随机化是「猜一个足够大的 A」，但不验证 C_real ⊆ γ(A)；它是**不可靠的抽象**，可能刚好漏掉真实的一个模态。
所以本文不认证策略，认证**契约支配关系**；不追求「仿真越像真实越好」，而追求「仿真契约保守覆盖真实契约，且覆盖的裕度可审计」。这把 sim-to-real 从「调参玄学」变成「可靠性证明」——代价是必须承认：证书只在支配成立、且策略不走出认证域时有效。

**灵感 3（证伪优先 → 迁移证书必须自带反例搜索）**
直觉：任何「分布外仍然安全」的声明都不可证；可做的是**主动找死**。对每个迁移证书构造差距证伪器：在现实扰动族（光照/材质/遮挡/传感器/时延/动力学/参考系）上搜索最大契约差距 δ；若找到 δ > δ*，证书作废。这把 Popper 的可证伪性写进系统架构：**没有被尝试推翻过的证书不算证书**。同时定义状态相关的 δ(x) 与认证迁移域 R_xfer——证书不是全局真，而是「在此区域内、对此任务度量、在闭环约束下」真。一个诚实的「局部已认证」胜过虚假的「全局已认证」。

**灵感 4（任务相关度量 → 位姿误差的正确单位是任务，不是米）**
直觉：SE(3) 上没有唯一的「距离」。装配任务关心插入轴方向的偏差与角向错位；抓取关心接触点位置；导航关心水平位置与偏航。用环境欧氏距离做预算，会把「不影响任务的误差」与「致命误差」同等计价，导致预算既过保守又漏关键方向。因此引入**任务相关李度量（TPM）**：d_task(T1,T2) = ||Φ_task·log(T1⁻¹T2)||_W，Φ_task 是任务雅可比。关键纪律：TPM 必须**预注册**，并用扰动实验证明「度量大的方向确实导致任务失败」——否则度量本身成为刷指标的工具（metric gaming）。

**灵感 5（闭环 → 认证域必须是控制不变集）**
直觉：位姿不确定度会因机器人动作而改变（走近、转动、在手中翻转），这正是 R73 ΣREFLEX 的 χ 通道。sim-to-real 差距也随动作改变：某些视角、对称模态、接触模式下差距大。因此「已认证」必须是**控制不变**的：存在安全滤波 GASF，把动作投影到「下一状态仍在 R_xfer 且位姿不确定度受控」的集合。否则证书只是开环快照，策略一步就走出去了。

## 1. 形式化定义（增量：定义 383–396）

**定义 383（流形证据契约 MEC）** MEC = (T_in, T_out, M, 𝔤, exp/log, Σ^∧, G_sym, ℳ_mode, Ad, D, χ_R, τ_merge, I⊥, W, seal_ref)：
- M ∈ {R^n, SO(3), SE(3), SE(2)×R^k}；𝔤 = Lie(M)；Σ^∧ ∈ Sym⁺(𝔤) 为右不变协方差，σ^∧ = log(μ⁻¹μ̂) ∈ 𝔤；
- G_sym ≤ Iso(M)：物体/环境对称群；ℳ_mode = M/G_sym 为模态商空间，evidence 携带模态后验 w；
- Ad：参考系变换的伴随搬运，Σ′ = Ad_T Σ Ad_Tᵀ；
- 其余字段继承 R73 定义 367（预算/通道/域/追溯/否决/时序/密封）。
**类型规则**：两个 MEC 仅当其流形、参考系图与 Ad 标签一致（或存在已认证的参考系图同构且失真 ≤ δ_Ad）时才可组合；标量证据是 M=R 的特例。**R73 的 EC = MEC 在 M=R、G_sym 平凡、Ad=1 时的退化实例。**

**定义 384（POSEM 位姿证据计量）** 观测 y_p（RGB-D/点云/IMU/关节编码器），后验为对称模态混合：
b_t(ξ) = Σ_{k∈K} w_k · N_𝔤(ξ; μ_k, Σ_k)，ξ = log(T̂⁻¹T) ∈ 𝔤。
六分量（在 TPM 下度量）：u_pose² = u_obs² + u_sym² + u_occ² + u_kin² + u_frame² + u_time²。
有效域 D_pose = {H(w) < τ_H 或模态可判别} ∧ 遮挡率 < τ_o ∧ 位姿在工作空间 ∧ 无标定断链。
**位姿反作用通道 χ_pose**：动作 g（相机重定位、接近、在手中旋转）→ 可观测性变化 → 调制 (u_obs, u_sym, u_occ) 与 D_pose。每分量独立追溯链，模态后验 w 与每模态协方差分别入证书（不允许压成单峰标量）。

**定义 385（ACT 伴随因果传输）** 设位姿证据链 T_0 → T_1 → … → T_n（运动链 / 证据因果图 ECG 的位姿路径），节点局部协方差 Σ_i，变换 T_{i→j}：
Σ_j = Σ_i Ad_{T_{i→j}} Σ_i Ad_{T_{i→j}}ᵀ + Σ_{node,j}。
放大因子 κ_{i→j} = ||Ad_{T_{i→j}}||₂ ≥ 1，等号当且仅当平移为零。ACT 把 R73 的标量 SER 替换为 Loewner 序合成；因果链断裂（模态未判别 / Ad 标签不一致 / 断链）⇒ I⊥ 否决。**ACT 是 R73 定义 370 的严格推广，标量串联是其在 𝔤=R、κ=1 的特例。**

**定义 386（CCA† 流形组合代数）**
- **SER†**：Σ_out ⪰ Ad Σ_A Adᵀ + Σ_B（Loewner），D_out = D_A ∩ D_B，τ_out = τ_merge，I⊥,out = I⊥,A ∪ I⊥,B，χ 串联；
- **PAR†**：先做**模态对齐审计**——跨模态残差在**每模态** conformal 集内且模态后验相容，才允许缩窄；缩窄在 TPM 下进行；模态不相容 ⇒ 按模态并集取保守（max over modes），并标记 MODE_AMBIG；
- **VETO†**：非补偿；位姿模态未判别时，**依赖具体模态的任务主张被否决**（不准「赌一个模态」）。
**单调性（引理 39）**：Loewner 序下 Σ_out ⪰ Σ_in；不存在缩窄到低于所有输入且通过模态审计的路径。

**定义 387（RGC 现实差距证书 / 契约支配）** 给定仿真契约 C_s、真实契约 C_r（在 SEAL-Gap 上估计），定义 **C_s ⊒_δ C_r** 当且仅当：
(i) **噪声支配**：在共同参考系/流形上 Σ_s ⪰ Σ_r（Loewner），或 C_s 的噪声包络包含 C_r；
(ii) **支撑支配**：supp(C_r) ⊆ supp(C_s)（真实可能出现的情形仿真都声明过）；
(iii) **模态支配**：ℳ_mode(C_r) ⊆ ℳ_mode(C_s)（真实的模态不被仿真漏掉）；
(iv) **参考系相容**：存在已认证的参考系图同构，Ad 失配 ≤ δ_Ad；
(v) **差距界**：sup_{f∈F} |E_{C_s}[f] − E_{C_r}[f]| ≤ δ，F 为预注册的有界 Lipschitz 风险泛函类。
δ 是迁移证书的**显式裕度**；δ=0 且 (i)–(iv) 成立即仿真=真实。**方向性**：C_s 必须比 C_r 更悲观（噪声更大、支撑更宽、模态更多），否则是「不可靠抽象」，迁移不成立。

**定义 388（S2R-GAP 差距证伪器）** 在现实扰动族 Π（光照/材质/遮挡/传感器/时延/动力学/参考系）上求
x* = argmax_{x∈Π} Δ(C_s(x), C_r(x))，
Δ 为 TPM 加权的契约差距（Wasserstein 项 + 模态散度 + 支撑越界罚）。
若 Δ(x*) > δ*（预注册阈值）⇒ 证书作废并记录反例；否则记录「未找到反例」及其搜索预算（**证伪强度**）。**没有证伪器的迁移证书 = 无效证书。**

**定义 389（局部差距与认证迁移域）** 差距状态相关：δ(x) 定义在 (位姿, 对称模态, 遮挡率, 工作空间区域, 接触模式) 上。
R_xfer = {x : δ(x) ≤ δ* ∧ u_pose(x) ≤ τ_p ∧ 模态可判别}。
迁移证书的效力范围 = R_xfer；R_xfer 外的行为必须由保守回退处理（位姿 stub / 触觉-本体主导 / 请求重标定）。

**定义 390（TPM 任务相关李度量）** d_task(T1,T2) = ||Φ_task · log(T1⁻¹T2)||_W，Φ_task 为任务雅可比（插入轴 / 接触点 / 偏航），W 为预注册权重。要求：TPM 须在扰动实验中被验证「d_task 大的方向确实导致任务失败」（度量效度），且**预注册**（不可见结果后调权重）。

**定义 391（GASF 差距感知安全滤波）** 在控制域把动作投影到
A_safe = {a : x_{t+1}(a) ∈ R_xfer ∧ E[u_pose^{t+1}(a)] ≤ τ_p ∧ ΣREFLEX 预算闭合}，
GASF(a) = argmin_{a′∈A_safe} ||a′ − a||²；A_safe = ∅ ⇒ 紧急停止/回退（非补偿）。
这是「证书闭环有效」的执行机制：认证域不是被假设不变，而是被滤波**强制**不变。

**定义 392（差距感知风险尺度 λ†）** λ = λ_floor + κ_gap·δ(x) + κ_pose·u_pose(x) + κ_epi·U_epi（继承 R72 E-RISK）。直觉：差距大 / 位姿烂的地方控制器更保守；差距被证伪器压小后才允许激进。λ† 进入 R72 的 certified_prefix。

**定义 393（迁移证书 J_XFER）** J_XFER = J_MOD ⊗ J_RGC ⊗ J_GAP ⊗ J_INV，其中 J_RGC 校验支配 (i)–(v)；J_GAP 校验证伪器已运行且未找到反例；J_INV 校验 GASF 使 R_xfer 为控制不变集。**Valid(J_XFER) ⇒ 在 R_xfer 内、对 TPM、在闭环约束下，真实风险 ≤ 仿真认证风险 + L·δ*（定理 31）。**

**定义 394（保守仿真构造与契约膨胀）** 契约膨胀算子 ↑_ε 把噪声协方差按 ε 膨胀、支撑按 ε 扩张、模态集合按 ε 增补，得到 C_s(ε) ⊒ C_r。存在权衡：ε 越大越可能支配真实（soundness↑），但策略越保守（任务进展↓）；存在**认证悬崖** ε*（引理 42）。定义**可迁移保守性** ε* − ε_min（既支配真实又保持任务可行）。构造纪律：仿真参数不得只由仿真内部拟合，必须用 SEAL-Gap 的真实数据校准膨胀下界。

**定义 395（SEAL-Pose / SEAL-Gap 审计集）** SEAL-Pose：动捕/基准物/多视角独立真值下的位姿误差分布（用于 POSEM 校准）；SEAL-Gap：同一物理场景在仿真与真实中的成对证据（用于 δ 估计与证伪）。密封、预注册、不可用于训练。**自举防御**：真值本身用独立计量（动捕 + 已知几何 + 接触）交叉验证，单一来源不作真值。

**定义 396（位姿 stub 与退化链）** 位姿失效（模态不可判别 / δ(x) > δ* / 断链）⇒ **pose stub**：u_pose = ∞、模态集合 = 全、仅否决位姿相关主张、χ = 平凡；系统退化为触觉-本体主导。RGC 作废 ⇒ 全局退到「仅认证域内保守控制」，再退到 R68。**安全侧只增不减（定理 33）。**

## 2. 关键算法骨架

```python
# IP-303 MEC：流形证据契约与类型校验
@dataclass(frozen=True)
class ManifoldEvidenceContract:
    group: str                          # 'R^n' | 'SO3' | 'SE3'
    frame: FrameId                      # 参考系图节点
    adjoint: Callable[[FrameId], Matrix]# Ad_T：参考系搬运
    sigma_lie: np.ndarray               # Sym+(g) 右不变协方差
    sym_group: SymmetryGroup            # 物体/环境对称群
    modes: FrozenSet[ModeId]            # M/G_sym 模态商
    domain: Predicate                   # D（模态可判别/遮挡/工作空间）
    task_metric: TaskLieMetric          # TPM（预注册）
    chi_R: Callable[[Action], NoiseMod] # 反作用通道（含 χ_pose）
    seal_ref: str                       # SEAL-Pose / SEAL-Gap / SEAL-Contact
    # ... 继承 R73 EC 的预算/追溯/否决/时序字段

def typecheck(a: MEC, b: MEC) -> bool:
    return a.group == b.group and frame_graph_compatible(a.frame, b.frame) \
       and adjoint_distortion(a, b) <= DELTA_AD

# IP-304 POSEM：位姿六分量 + 对称模态混合后验
class PoseMetrology:
    def update(self, y_p, motion, kin_state, calib_state):
        mu, Sigma, w, modes = self.pose_net(y_p)          # 模态混合 + 群协方差
        u_obs   = self.calib.obs_unc(mu, Sigma)
        u_sym   = self.calib.sym_unc(w, self.sym_group)   # 模态分离/切换风险
        u_occ   = self.calib.occ_unc(y_p, self.view)      # 遮挡/部分视图
        u_kin   = self.kin.unc(kin_state)                 # 正运动学/关节标定
        u_frame = self.calib.handeye_unc(calib_state)     # 手眼/外参
        u_time  = self.calib.temporal_unc(motion, self.latency)
        valid   = (entropy(w) < TAU_H or mode_resolvable(w)) \
                  and u_occ < TAU_O and in_workspace(mu)
        return PoseEvidence(mu=mu, Sigma=Sigma, w=w, modes=modes, valid=valid,
               u=self.tpm.norm((u_obs,u_sym,u_occ,u_kin,u_frame,u_time)),
               breakdown=(u_obs,u_sym,u_occ,u_kin,u_frame,u_time),
               chi_pose=chi_pose(mu, w, self.view))

# IP-305 ACT：伴随因果传输
def adjoint_transport(chain, Sigma0, T):
    S = Sigma0
    for node in chain:                     # 沿运动链/ECG 位姿路径
        Ad = adjoint(T[node.src, node.dst])
        S = Ad @ S @ Ad.T + node.Sigma      # Loewner 单调
        if node.break_flag: return None, node.veto   # 断链 ⇒ 否决
    return S, set()

# IP-306 CCA†：流形 + 模态条件组合
def compose_manifold(a_ev, b_ev, op, audit):
    assert typecheck(a_ev.ec, b_ev.ec)
    if op == 'SER':
        return Ev(Sigma=transport(a_ev.Sigma, a_ev.ec, b_ev.ec) + b_ev.Sigma,
                  D=a_ev.D & b_ev.D, tau=merge(a_ev.tau, b_ev.tau),
                  veto=a_ev.veto | b_ev.veto)
    if op == 'PAR':
        aligned = modal_alignment(a_ev, b_ev)          # 逐模态残差
        if audit.per_mode_conformal_covers(aligned):   # 每模态都覆盖才缩窄
            return fuse_modal(a_ev, b_ev, a_ev.ec.task_metric, audit.corr())
        out = mode_union_conservative(a_ev, b_ev)      # 模态并集，保守
        return Ev(*out, veto=a_ev.veto | b_ev.veto | {'MODE_AMBIG'})
    if op == 'VETO':
        if a_ev.veto or b_ev.veto or not mode_resolvable(a_ev, b_ev):
            return Ev(valid=False, veto=a_ev.veto | b_ev.veto)
        return Ev(Sigma=min_lowner(a_ev.Sigma, b_ev.Sigma), D=a_ev.D & b_ev.D)

# IP-307 RGC：契约支配审计（部署期 + 1Hz 增量）
def rgc_dominance(c_sim, c_real, F, audit):
    ok = lowner_dominates(c_sim.Sigma, c_real.Sigma) \
         and support_subset(c_real.support, c_sim.support) \
         and modes_subset(c_real.modes, c_sim.modes) \
         and audit.frame_isomorphic(c_sim, c_real, delta_Ad=DELTA_AD)
    delta = max(abs(audit.E_sim(f) - audit.E_real(f)) for f in F) if ok else float('inf')
    return ok and delta <= DELTA_STAR, delta

# IP-308 S2R-GAP：差距证伪器（离线/低频）
def gap_falsifier(c_sim, c_real, Pi, budget):
    best = (None, 0.0)
    for x in Pi.sample(budget):                       # 光照/材质/遮挡/时延/参考系
        d = delta_tpm(c_sim(x), c_real(x))            # TPM 加权契约差距
        if d > best[1]: best = (x, d)
    if best[1] > DELTA_STAR: return False, best       # 找到反例 ⇒ 证书作废
    return True, best                                 # 记录证伪强度

# IP-309 GASF + λ†：认证域闭环强制 + 差距感知风险
def gasf(a, x, mods, budget, risk):
    def feasible(a_):
        x2, u2 = predict(x, a_, mods)
        return x2 in R_xfer and u2.pose <= TAU_P and sigmareflex_ok(mods, a_, budget)
    a_safe = project(a, feasible)                     # 控制域 <0.5ms
    if a_safe is None: return None, 'EMERGENCY'
    lam = risk.lam_floor + risk.k_gap * delta_hat(x) + risk.k_pose * u_pose(x)
    return a_safe, lam

# IP-310 J_XFER：迁移证书组装
def J_XFER(M):
    ok_mod  = all_valid(M.module_certs)
    ok_rgc, delta = rgc_dominance(M.c_sim, M.c_real, M.F, M.audit)
    ok_gap  = M.falsifier.passed and delta <= DELTA_STAR
    ok_inv  = M.gasf.invariant(R_xfer)                # HJB/CBF 片段
    return ok_mod and ok_rgc and ok_gap and ok_inv

# IP-311 PACT 主闭环（沿用 R73 三域，位姿与差距进契约）
def PACT_round(M, obs, audio, tac_frame, depth_img, sim_state=None):
    # 感知域：DPEM† + POSEM + DMEM†
    d_ev = M.dpe.update(depth_img, obs.rgb, M.cam_state, M.motion, M.peers)
    p_ev = M.pose.update(obs, M.motion, M.kin_state, M.calib_state)
    p_ev = p_ev if p_ev.valid else stub(M.pose)       # 位姿 stub（定义 396）
    # 计量域：ACT 传输 → CCA† 组合 → 差距感知规划
    if M.clock.due_metric():
        seq = M.act.transport([d_ev, p_ev, M.kin_state])   # 伴随合成
        b_t = M.bse.step_full(..., d_ev=d_ev, p_ev=p_ev)   # BSE†
        delta_hat = M.rgc.delta_at(b_t.pose)               # 局部差距 δ(x)
        M.pvop = viewpoint_aware_plan(b_t, M.mods, M.risk, delta_hat)
        M.mreg.audit()
    # 控制域：GASF 强制留在 R_xfer，λ† 含差距项
    snap = M.snapshot.read_latest()
    a, info = gasf(M.ach.propose_ctrl(..., pvop_bias=snap.pvop), snap, M.mods,
                   M.budget, M.risk)
    if a is None: M.ctrl_out.stop(); return None, float('inf'), False
    k = M.c_ras_wm.certified_prefix(a, info_lam)
    return k, info_lam, J_XFER(M)
```

## 3. 推导

**引理 38（伴随放大 / 杠杆臂律）** 对 T = (R, p) ∈ SE(3)，Ad_T 的平移分块含 p^ 项。设某旋转分量的方差为 σ_θ²，则经杠杆臂 r 搬运后位置方差含 r²σ_θ² 项，故 κ = ||Ad_T||₂ ≥ max(1, ||p||) 量级；任何省略 r 的标量界在 r > 0 时**低估**真实位置误差。系：**R73 的标量 CCA 只在零杠杆臂极限 sound；PACT 的 ACT 显式把 κ 放进预算。**

**引理 39（流形组合单调性）** SER† 给出 Σ_out = Ad Σ_A Adᵀ + Σ_B ⪰ Σ_B 且 ⪰ Ad Σ_A Adᵀ；Σ_B ⪰ 0 ⇒ trace 非降；PAR† 仅在逐模态 conformal 审计通过时缩窄；VETO† 单调收缩有效域。⇒ 任何组合路径在 Loewner 序下都不可能低于所有输入的单调组合而同时通过模态审计。系：**组合无认知免费午餐，且标量 CCA 是 M=R、κ=1 的特例——PACT 严格包含 MODGAUGE。**

**引理 40（对称模态与 conformal 覆盖退化）** conformal 只保证**边缘**覆盖 1−α，不保证**逐模态**覆盖；当模态与难度相关时，稀有模态的条件覆盖可显著低于 1−α，且单峰高斯集无法在不随模态分离度膨胀的情况下覆盖多峰后验。⇒ 位姿的 PAR 必须**逐模态校准**，否则覆盖率保证不成立。系：**R73 的 PAR 在对称物体上是无保证的。**

**引理 41（支配 ⇒ 风险上界）** 若 C_s ⊒_δ C_r，且风险泛函 f 在证据质量序上单调非降、对差距 L-Lipschitz，则 E_{C_r}[f] ≤ E_{C_s}[f] + L·δ。证明：单调性给出 E_{C_r}[f] ≤ 以 C_s 为界的值，再由定义 387(v) 的 sup 差控制。系：**迁移界 = 仿真认证风险 + L·δ；δ 是证书里唯一诚实的外生量。**

**引理 42（保守性-性能权衡 / 认证悬崖）** 契约膨胀 ↑_ε 下，认证鲁棒性 R_cert(ε) 单调非降，可达任务进展 P(ε) 单调非增；若 P 有上界且严格递减，则 ε* = sup{ε : P(ε) ≥ P_min} 存在。ε > ε* 时证书仍可存在但策略任务不可行——**认证悬崖**。系：**过度保守的仿真不是免费的；有用证书必须落在 [ε_min, ε*]。**

**引理 43（差距可识别性的极限）** 用 n 个 SEAL-Gap 样本在函数类 F 上估计 δ，统计误差为 Ω(√(VC(F)/n)) 量级；对一切分布偏移做无分布一致界不可能。证伪器在 Π 上的搜索亦有样本复杂度下界。⇒ **任何迁移证书都是条件性的**：必须声明审计分布、F 与搜索预算；未声明者不可证伪，因而无效。系：**证书的诚实形式是「在给定审计下、未找到反例、σ 置信」，不是「已证明安全」。**

**定理 30（PACT 严格包含 MODGAUGE）** 在 A114–A117 下：取零杠杆臂（κ≡1）、平凡对称群、δ=0、参考系一致、真实=仿真，PACT 逐指令退化为 MODGAUGE；再由定理 27 退化为 R72/R71/R68。**安全侧单调不减，效率仅在支配与任务度量满足时获益。**

**定理 31（迁移可靠性定理）** 在 A114（支配成立且真实支撑受仿真覆盖）、A115（风险泛函单调 + 对 δ Lipschitz）、A116（GASF 使 R_xfer 控制不变；模态后验忠实；估计器报告模态覆盖真实模态）、A117（Ad 标签一致、审计样本在区域内可交换）下：Valid(J_XFER) ⇒ 对任意 x ∈ R_xfer，真实执行风险 ≤ ε_sim + L·δ* + ε_est（ε_est 为位姿估计误差在 TPM 下的界）。**证明重量落在「支配是方向正确的抽象」与「GASF 真的把闭环关住」上。**

**定理 32（模态感知融合安全）** 在对称群 G_sym 非平凡时，CCA† 的 PAR 绝不静默提交到错误模态：模态可判别则逐模态审计后缩窄；不可判别则输出模态并集保守值并置 MODE_AMBIG，依赖具体模态的任务主张被 VETO† 否决。故「错误模态灾难性合并」概率 ≤ 模态后验误差，且是**被检测到的降级**而非静默失效。

**定理 33（降级单调性）** 位姿 stub、RGC 作废、R_xfer 退出均触发保守回退（触觉-本体主导 / 认证域内控制 / R68）；每次回退只减少能力、不减少安全裕度。结合引理 39 与定理 29 ⇒ **PACT 的能力-安全曲线单调：安全侧只增不减。**

**假设 A114–A117**：A114 契约支配方向正确且真实支撑被仿真覆盖；A115 风险泛函在证据质量序上单调；A116 GASF 的 R_xfer 控制不变性可证、模态后验忠实；A117 Ad 标签一致、审计样本在区域内可交换、F 预注册。

## 6. 本轮最大风险

**一句话**：PACT 把 sim-to-real 的证明负担转移到「**契约支配关系 C_sim ⊒ C_real**」上——但这个关系是在有限审计分布、有限函数类 F 与有限搜索预算下验证的，真实部署分布可能落在审计覆盖之外；更糟的是，策略自身的动作会改变位姿分布（闭环）与差距分布，使机器人可能走出被认证的 R_xfer，于是系统拿着一套「类型正确、Loewner 支配、证伪器未找到反例」的证书，在一个系统性错误的位姿上**自信地执行**，而审计日志会证明「每一步都合规」——**证书在错误的地址上生效**。

次级风险与缓解：
1. **支配的样本乐观**（有限 SEAL-Gap 导致 δ 低估）→ δ 用保守置信上界 + 证伪器搜索预算显式记账（引理 43）；证书标注置信水平与审计分布。
2. **对称群误设**（近对称/连续对称被当成离散）→ 连续对称用轨道距离 + 模态密度；近对称触发 MODE_AMBIG 与 VETO†，不准强行单峰。
3. **任务度量刷分（metric gaming）** → TPM 预注册 + 度量效度实验（扰动方向与失败相关性）+ 第三方复现。
4. **认证悬崖** → 同时报告 ε 窗口 [ε_min, ε*] 与「单位保守性任务进展」，不允许只报安全界。
5. **闭环逃逸** → GASF 的 R_xfer 不变性须有 CBF/HJB 片段证明，而非仅运行时监控（E404）。
6. **仿真契约自举**（用真实标定仿真、再声称仿真支配真实）→ 膨胀下界只用 SEAL-Gap 的独立真值校准；仿真内部拟合不构成支配证据。
7. **证伪器搜索不足** → 记录搜索预算与覆盖的扰动族；未覆盖族显式列为证书的前提，而非沉默。
8. **与「又一个 sim2real 论文」混淆** → 定位声明：本文不改进策略，只认证**契约迁移**；对照实验必须同时报告「DR 的盲区」与「本方法的有效域」，以证伪优先而非性能领先为卖点。

**结论句（最大风险）**：PACT 最大的风险不是算不动，而是它可能在一张「各处都合规」的证书下，把安全性质悄悄认证到一个真实系统并不居住的位姿分布上——**证书有效，地址错了**。

# 第 74 轮产物 · 创新点清单 v5：PACT-RAS（Pose-Aware Contract Transfer for RAS：位姿感知的契约迁移；MEC × POSEM × ACT × RGC × S2R-GAP × GASF × MODGAUGE-RAS†）

> 承接第 73 轮 IP-295~302（MODGAUGE-RAS 计量契约代数）。R73 完成「证据即契约」：MMS 类型化、CCA 组合单调、热替换定理、CPB 主张绑定。但它的契约默认证据住在欧氏空间、默认只在真实域校准、且证书是全局开环的。本轮以「姿态估计 × 仿真到现实」补齐三处类型级缺口：
> - **MEC**：证据契约升级为流形证据契约（流形/参考系/伴随/对称群/模态支撑成为接口类型），标量 EC 成为其特例；
> - **POSEM + ACT**：位姿六分量 + 对称模态混合后验 + 伴随因果传输（Loewner 序、杠杆臂放大显式入预算），修复「标量 CCA 在零杠杆臂外不 sound」；
> - **RGC + S2R-GAP + R_xfer + GASF**：把 sim-to-real 重构为「**契约支配的可靠性**」（抽象解释 soundness），迁移证书必须自带证伪器与可证伪有效域，并由差距感知安全滤波**强制闭环不变**。
>
> 核心命题：**不认证策略，认证契约迁移；不追求仿真像真实，追求仿真契约保守覆盖真实且覆盖裕度可审计、可证伪、有有效域。**
>

## 2. 形式化定义（要点版）

**定义 383（MEC）** 契约字段加入 M、𝔤、Σ^∧、G_sym、ℳ_mode、Ad、TPM；类型规则：流形/参考系/Ad 一致才可组合；R73 的 EC 是 M=R 退化。

**定义 384（POSEM）** 位姿后验为对称模态混合；六分量各有独立追溯链；χ_pose 声明动作→可观测性；有效域要求模态可判别或熵低。

**定义 385（ACT）** 沿运动链/ECG 用 Ad_T 传输协方差；κ≥1；断链/标签不一致 ⇒ I⊥。

**定义 386（CCA†）** SER† Loewner 单调；PAR† 逐模态 conformal 审计才缩窄，否则模态并集 + MODE_AMBIG；VETO† 非补偿且拒绝赌模态。

**定义 387（RGC 支配）** C_s ⊒_δ C_r ⇔ 噪声支配 ∧ 支撑支配 ∧ 模态支配 ∧ 参考系相容 ∧ 差距界 ≤ δ；方向必须是「仿真更悲观」。

**定义 388（S2R-GAP）** 在 Π 上最大化 TPM 加权契约差距；Δ > δ* ⇒ 证书作废；记录搜索预算作为证伪强度。

**定义 389（R_xfer）** δ(x)、u_pose、模态可判别共同定义认证域；域外必须保守回退。

**定义 390（TPM）** d_task = ‖Φ_task log(T1⁻¹T2)‖_W；预注册 + 度量效度实验，禁止事后调权重。

**定义 391（GASF）** 投影动作到 A_safe；A_safe 空 ⇒ 紧急停止；使 R_xfer 成为控制不变集。

**定义 392（λ†）** 风险尺度显式含 δ(x) 与 u_pose；差距大处更保守。

**定义 393（J_XFER）** 模块证书 ∧ RGC 支配 ∧ 证伪未爆 ∧ GASF 不变性；有效 ⇒ 定理 31 的区域迁移界。

**定义 394（契约膨胀/认证悬崖）** ↑_ε 提升 soundness、降低任务进展；有用证书须在 [ε_min, ε*]；膨胀下界由真实数据校准。

**定义 395（SEAL-Pose/Gap）** 密封成对审计集；真值多源交叉验证，单源不作真值；自举防御。

**定义 396（位姿 stub/退化）** 位姿失效 ⇒ stub；RGC 作废 ⇒ 认证域内保守控制；再退 R68；安全单调。

## 3. 关键算法伪代码

```python
# IP-303 MEC：流形证据契约与类型校验
@dataclass(frozen=True)
class ManifoldEvidenceContract:
    group: str; frame: FrameId
    adjoint: Callable[[FrameId], Matrix]     # Ad_T
    sigma_lie: np.ndarray                    # Sym+(g)
    sym_group: SymmetryGroup; modes: FrozenSet[ModeId]
    domain: Predicate; task_metric: TaskLieMetric
    chi_R: Callable[[Action], NoiseMod]; seal_ref: str

def typecheck(a, b):
    return a.group == b.group and frame_graph_compatible(a.frame, b.frame) \
       and adjoint_distortion(a, b) <= DELTA_AD

# IP-304 POSEM：六分量 + 对称模态混合
def posem_update(y_p, motion, kin, calib):
    mu, Sigma, w, modes = pose_net(y_p)          # 模态混合 + 群协方差
    u = tpm_components(mu, Sigma, w, modes, motion, kin, calib)
    valid = (entropy(w) < TAU_H or mode_resolvable(w)) \
            and u.occ < TAU_O and in_workspace(mu)
    return PoseEvidence(mu, Sigma, w, modes, u, valid,
                        chi_pose=chi_pose(mu, w, view))

# IP-305 ACT：伴随传输
def transport(chain, S0):
    S = S0
    for e in chain:
        Ad = adjoint(e.T)
        S = Ad @ S @ Ad.T + e.Sigma
        if e.broken: return None, e.veto
    return S, set()

# IP-306 CCA†：流形 + 模态条件组合
def compose(a, b, op, audit):
    assert typecheck(a.ec, b.ec)
    if op == 'SER':
        return Ev(S=transport_edge(a, b), D=a.D & b.D,
                  veto=a.veto | b.veto)
    if op == 'PAR':
        if audit.per_mode_covers(modal_alignment(a, b)):
            return fuse_modal(a, b, a.ec.task_metric, audit.corr())
        return Ev(*mode_union_conservative(a, b),
                  veto=a.veto | b.veto | {'MODE_AMBIG'})
    if op == 'VETO':
        return Ev(valid=not (a.veto or b.veto or not mode_resolvable(a, b)),
                  veto=a.veto | b.veto)

# IP-307 RGC：契约支配审计
def dominance(c_s, c_r, F, audit):
    ok = lowner_dominates(c_s.sigma, c_r.sigma) \
         and support_subset(c_r.support, c_s.support) \
         and modes_subset(c_r.modes, c_s.modes) \
         and audit.frame_iso(c_s, c_r, DELTA_AD)
    delta = max(abs(audit.E_sim(f) - audit.E_real(f)) for f in F) if ok else inf
    return ok and delta <= DELTA_STAR, delta

# IP-308 S2R-GAP：证伪器
def falsify(c_s, c_r, Pi, budget):
    x, d = None, 0.0
    for z in Pi.sample(budget):
        d2 = delta_tpm(c_s(z), c_r(z))
        if d2 > d: x, d = z, d2
    return (d <= DELTA_STAR), (x, d)      # False ⇒ 证书作废

# IP-309 GASF + λ†
def gasf(a, x, mods, budget, risk):
    def feas(a_):
        x2, u2 = predict(x, a_, mods)
        return x2 in R_xfer and u2.pose <= TAU_P and sigmareflex_ok(mods, a_, budget)
    a2 = project(a, feas)
    if a2 is None: return None, 'EMERGENCY'
    return a2, risk.lam_floor + risk.k_gap*delta_hat(x) + risk.k_pose*u_pose(x)

# IP-310 J_XFER
def transfer_cert(M):
    return all_valid(M.certs) and M.rgc_ok and M.falsifier_passed \
           and M.gasf.invariant(R_xfer)

# IP-311 PACT 主闭环
def PACT_round(M, obs, audio, tac, depth):
    d_ev = M.dpe.update(depth, obs.rgb, M.cam_state, M.motion, M.peers)
    p_ev = M.pose.update(obs, M.motion, M.kin, M.calib)
    if not p_ev.valid: p_ev = stub(M.pose)                 # 位姿 stub
    if M.clock.due_metric():
        _ = M.act.transport([d_ev, p_ev, M.kin])           # 伴随合成
        b_t = M.bse.step_full(..., d_ev=d_ev, p_ev=p_ev)
        delta_hat = M.rgc.delta_at(b_t.pose)               # 局部差距
        M.pvop = viewpoint_aware_plan(b_t, M.mods, M.risk, delta_hat)
        M.mreg.audit()
    snap = M.snapshot.read_latest()
    a, lam = gasf(M.ach.propose_ctrl(..., pvop_bias=snap.pvop),
                  snap, M.mods, M.budget, M.risk)
    if a is None: M.ctrl_out.stop(); return None, inf, False
    k = M.c_ras_wm.certified_prefix(a, lam)
    return k, lam, transfer_cert(M)
```

## 4. 推导

**引理 38（杠杆臂律）** Ad_T 平移分块含 p^；旋转方差 σ_θ² 经杠杆臂 r 搬运后贡献 r²σ_θ² 到位置方差，κ=‖Ad_T‖≥max(1,‖p‖) 量级。⇒ 省略 r 的标量界在 r>0 时低估；R73 CCA 仅零杠杆臂极限 sound。

**引理 39（流形组合单调性）** SER†：Σ_out=AdΣ_A Adᵀ+Σ_B ⪰ Σ_B 且 ⪰ AdΣ_A Adᵀ，trace 非降；PAR† 仅在逐模态审计通过时缩窄；VETO† 单调收缩域。⇒ 组合无免费午餐；标量 CCA 是 M=R、κ=1 特例。

**引理 40（对称模态与覆盖退化）** conformal 只保边缘覆盖 1−α，不保逐模态覆盖；模态与难度相关时稀有模态条件覆盖可远低于 1−α；单峰集覆盖多峰需随模态分离度膨胀。⇒ 位姿 PAR 必须逐模态校准，否则 R73 PAR 在对称物体上无保证。

**引理 41（支配 ⇒ 风险界）** C_s⊒_δC_r 且 f 在证据质量序单调非降、对 δ L-Lipschitz ⇒ E_{C_r}[f] ≤ E_{C_s}[f] + Lδ。⇒ 迁移界 = 仿真认证风险 + Lδ。

**引理 42（认证悬崖）** ↑_ε 下 R_cert(ε) 非降、P(ε) 非增；ε*=sup{ε:P(ε)≥P_min} 存在；ε>ε* 证书仍可真但任务不可行。⇒ 有用证书须在 [ε_min, ε*]。

**引理 43（可识别性极限）** n 个 SEAL-Gap 样本上估计 δ 有 Ω(√(VC(F)/n)) 统计误差；无分布一致界；证伪器搜索有样本下界。⇒ 证书必须显式声明审计分布/F/搜索预算，否则不可证伪、无效。

**定理 30（严格包含）** κ≡1、平凡对称、δ=0、参考系一致 ⇒ PACT 逐指令退化为 MODGAUGE → R72 → R71 → R68；安全侧单调不减。

**定理 31（迁移可靠性）** 在 A114–A117（支配方向正确且支撑覆盖；风险泛函单调且对 δ Lipschitz；GASF 使 R_xfer 控制不变、模态后验忠实；Ad 标签一致、审计样本区域内可交换）下：Valid(J_XFER) ⇒ ∀x∈R_xfer，真实风险 ≤ ε_sim + Lδ* + ε_est。证明重量在「抽象方向正确」与「闭环真被关住」。

**定理 32（模态感知融合安全）** 对称非平凡时 PAR† 不静默提交错误模态：可判别则逐模态审计后缩窄；不可判别则保守并集 + MODE_AMBIG，依赖模态的主张被 VETO†。错误模态灾难概率 ≤ 模态后验误差，且是被检测的降级而非静默失效。

**定理 33（降级单调性）** 位姿 stub / RGC 作废 / 越域回退只减能力、不减安全裕度；结合引理 39 与定理 29 ⇒ 能力-安全曲线单调，安全侧只增不减。

| E410 DR 对照 | 大预算 DR vs 契约迁移 | DR 盲区失败；契约组正确降级 |
| E411 遮挡/部分视图 | 只看到局部几何 | 重尾被校准；抓取失败率显著降 |
| E412 时延/运动/滞后 | 高速 + 传感器时延 | u_time 进 λ，碰撞率下降 |
| E413 手眼/外参漂移 | 温度/碰撞后漂移 | u_frame 跟踪；R_xfer 自动收缩 |
| E414 跨本体位姿迁移 | 换相机/臂/手热替换 | 同 MEC 逐指令 diff=0；核心改动 0 行 |
| E415 MBench-S2R 复现 | 预注册+固定种子+密封集 | 三方偏差 < 带宽；三主张各有最小可证伪实验 |

**MB4 最小基准**：对称物体插装 + 遮挡 + 手眼漂移；仿真/真实成对采集；≤3h 单卡（或 CPU）可复现；TPM 与 δ* 跑前锁定；SEAL-MB-Pose/Gap 密封保持。

## 7. 本轮最大风险

**一句话**：PACT 把 sim-to-real 的证明负担转移到「契约支配关系 C_sim ⊒ C_real」上——但该关系只在有限审计分布、有限函数类 F 与有限证伪预算下成立，真实部署分布可能在其外；且策略动作会改变位姿分布与差距分布（闭环），使系统可能走出 R_xfer。于是它可能拿着一套「类型正确、Loewner 支配、证伪器未找到反例」的证书，在一个**系统性错误**的位姿上自信执行，而审计日志证明每一步都合规——**证书有效，但认证的地址不是真实系统居住的地址**。

次级风险与缓解：
1. **样本乐观** → δ 用置信上界；记录审计分布与搜索预算（引理 43）。
2. **对称群误设** → 连续/近对称用轨道距离，触发 MODE_AMBIG 与 VETO†，不许强行单峰。
3. **度量刷分** → TPM 预注册 + 度量效度实验 + 第三方复现。
4. **认证悬崖** → 同时报告 ε 窗口与「单位保守性任务进展」，不只报安全界。
5. **闭环逃逸** → R_xfer 不变性需 CBF/HJB 片段证明，非仅运行时监控（E404）。
6. **仿真自举** → 膨胀下界只能用 SEAL-Gap 独立真值；仿真内部拟合不算支配证据。
7. **证伪不足** → 未覆盖扰动族显式列为证书前提，而非沉默。
8. **定位混淆** → 不以性能领先为卖点，以「DR 盲区被暴露 + 证书有效域」为可证伪卖点。

**结论句（最大风险）**：我们能证明的只是「在审计覆盖到的地方、在闭环关住的区域内、没有人找到反例」，而 PACT 的最大危险正是把这句条件句在叙事上悄悄读成「已经安全」——**证书有效，地址错了**。
