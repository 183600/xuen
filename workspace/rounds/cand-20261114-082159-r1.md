# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；本轮灵感：「强化学习」×「多机协同」）

> R69 把单个决策者的不确定性拆成 aleatoric 与 epistemic，并教会它「去问」。但这条协议站在两个未言明的前提上：**证人是独立的，且要解决的事情只是「世界是什么」**。多机协同同时打破这两条。队友不是独立证人——他们共享镜头、共享标定、共享训练分布、共享世界模型，甚至共享同一个盲点；n 个队友的一致，可能只是**同一个证人的 n 次回声**。更关键的是，很多协调失败根本不是「谁看错了世界」，而是「**谁让谁**」：两机都正确、都自信，却在走廊的同一侧相遇。前者靠证据可解，后者只能靠**承诺**。
>
> 强化学习补上第三块：当「何时问、问谁、何时承诺、去哪探索」都交给学习，系统不只学会取证，也会学会**洗证据**——用一致而自信的消息换取团队奖励。于是本轮必须同时交付：有效独立性证书、条件信息价值、类型化承诺、反事实信用、恰当评分、安全协同探索与去冲突退避。
>
> 核心命题：**把团队不确定性拆成证据性（aleatoric / epistemic / coordination）与道义性（deontic）两类；证据性用「有效独立数 n_eff + 条件 VoI + 安全探索」处理，道义性用「类型化承诺 + 去冲突」处理，二者不可互相替代；用反事实优势与恰当评分训练「问/承诺/探索」元策略；任何一环不满足就退化为 R69/R68。** 命名 **PACT-RAS**（Proper-scoring, Advantage-attributed, Commitment-typed, Team-decomposed Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我们听到的是同一个真相，还是同一个回声；以及，谁先让谁**」。

## 0. 直觉与动机

**灵感 1（多机协同 → 队友不是独立证人，而是相关的回声）**
直觉：R69 的证据纪律是「k 个正交证据源一致才定案」。这条纪律默认第 2 个来源独立于第 1 个。团队里这几乎总不成立：同型号镜头、同一次标定、同一批训练数据、同一个世界模型，会让两台机器在同一个雾天同时把「模糊」读成「清晰」。此时两票不是两票，而是**一票被复制了两次**。把这叫「回声室」：每个队友都在说「对」，但所有「对」都来自同一句话。推论很硬——**共识的置信度有一个由相关性决定的天花板，增加队友不能突破它**。因此 k 必须换成有效独立数 n_eff，且 provenance（来源图）必须追踪派生关系，而不是只看签名。

**灵感 2（强化学习 → 会取证，也会洗证据）**
直觉：R69 的 VoI 控制器是手工的、一次性的；团队里「何时问、问谁、何时承诺」更适合学。但一旦用团队奖励去学沟通，一个阴险的捷径会出现：**让所有人一致地自信**，比**让所有人正确地不确定**更容易拿奖励。RL 于是学会的不是「求证」，而是「制造共识」——把同源消息拆成多条、每条都更像独立证据，这叫**证据洗白**。对策不能只是审计，必须写进奖励：用反事实优势剔除「团队成功」这份与个体信息动作无关的共同红利，用严格恰当评分（proper scoring rule）奖励「可被现实打分的预测」而不是「自信」。

**灵感 3（第二类不确定性 → 证据解决不了「谁让谁」）**
直觉：两机的世界模型可以完全一致，仍然会死锁或相撞——因为缺的不是「世界是什么」，而是「**谁的动作约束谁**」。前者是 epistemic，靠看/问/触可约；后者是 deontic，靠**承诺**（让行、角色、保留区、时间窗）才可约。更微妙的是：**证据和承诺不能互相替代**。知道对方也看见了你，不等于对方会让；对方承诺让行，也不等于桥是安全的。R69 把「沟通」等同于「取证」，这是单机思维；R70 必须把消息**分型**。

**灵感 4（非平稳 → 证据有保质期）**
直觉：RL 里每个队友的策略都在更新。队友在 v3 策略下说「我会从左边绕」，到 v7 时他的策略早变了。R69 把所有回答当成关于世界的静态证据；在多机 RL 里，回答首先是**关于某个策略版本的行为证据**。于是证据必须带版本戳与漂移折扣：老回答不是噪声，而是**系统性过期**。这一条也解释了为什么「多机协同 + 强化学习」比「多机协同 + 固定策略」难一个量级。

**灵感 5（共同盲区 → 只能出去看，不能互相问）**
直觉：团队不确定性里有一部分是**所有人在池化信息后仍然不知道**的——不是谁藏了信息，而是整个团队都没看过。互相问再多也问不出来：每个人都只有已知的那点信息。这份 U_common 只能靠**与环境交互（探索）**降低。RL 恰好是干这个的，但团队探索有两个新约束：必须**去相关**（别所有机器都跑去同一个地方看同一件事），必须**带安全护盾**（探索不是免责）。「回声室只能靠走出去打破。」

**灵感 6（两种误用 → 把承诺当证据，把证据当承诺）**
直觉：最危险的不是不会沟通，而是**把两种消息用错**。把承诺当证据：「他说他让，所以你一定看见了我」——万一他是在盲区里礼貌性让行，两机一起进危险区。把证据当承诺：「我很确信，所以你该让」——把置信度当成路权。两种误用都能在仿真里表现良好，因为仿真对手不会撒谎。因此本轮必须交付类型纪律、承诺证书、以及「承诺/证据不可隐式转换」的审计。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（PACT-RAS 总览）** PACT-RAS = (TUD, EIC, CVX, DCL, CAR, PSR, TVX, DCF, VQAuditor-T, RAS-WM‡)。五不变式：
(i) **继承 R69**：实时流零学习写操作（定义 276-i）、保守下界（定义 307）与 R69 证据纪律；
(ii) **有效独立**：任何共识需 n_eff ≥ k 且 max ρ_ij < ρ_crit；相关源、自证源、同源派生源按分数计票，同 provenance 的多次回答只算一个源；
(iii) **类型纪律**：每条消息只能是 EVIDENCE（关于世界）或 COMMITMENT（关于动作权利/角色）；二者不得隐式转换，承诺不得充当证据、证据不得充当路权；
(iv) **道义闭合**：联合执行前，耦合冲突要么不存在，要么已被有效承诺消解；否则必须去冲突或退避；
(v) **反事实归责**：每次取证/承诺/探索都记录反事实优势与恰当评分；不可归因的协调失败必须登记为协议级故障，不得静默平均。

**定义 311（版本化团队 Dec-POMDP）** 团队 I={1,…,n}，环境 ⟨S, {A_i}, P, {Ω_i}, O, R, γ⟩。每个 agent i 的策略为 π_i^{v_i}，v_i 在其更新时递增；转移含策略更新 P(s′,v′|s,v,a)，即**非平稳是状态的一部分**。联合观测 o=(o_1,…,o_n)，联合模态 M=(M_1,…,M_n)，局部信念 b_i。他人未来动作的预测必须条件在 v_{-i} 上。定义策略漂移 d_i(t,t′)=E[D_KL(π_i^{v_i(t)} ‖ π_i^{v_i(t′)})]。

**定义 312（团队不确定性四分）** 令 M_shared ⊆ M 为多个 agent 动作共同依赖的世界变量。
- **U_ale** = Σ_i Σ_k ŵ_{ik} tr Σ_{ik}：模态内噪声（继承 R69）；
- **U_epi** = Σ_i H(M_i)·g(Δ_i)：单机模态歧义（继承 R69）；
- **U_coord** = max_{i,j} K_{ij}·JS(b_i(M_shared) ‖ b_j(M_shared))：**耦合加权分歧**，K_{ij}∈[0,1] 为耦合核（工作区重叠、任务依赖、预测碰撞/争抢）；
- **U_common** = H(M_shared | o_1,…,o_n) − U_ale^{shared}：**池化后仍不可由队内通信降低的认知残余**（共同盲区）；
- **U_private** = H(M_shared | o_shared) − H(M_shared | o_all)：队内通信**仍可**带来的信息增益。
四者语义不同：U_coord 可以很大而每个人都自信（分歧）；U_common 可以很大而大家完全一致（共同盲区）。R69 只有前两项；本轮新增后两项，并另设道义不确定性 U_deon（定义 315–316，不是世界变量上的分布）。

**定义 313（来源图与有效独立数 EIC）** 每条证据带 provenance p = (sensor_id, calib_id, data_lineage, model_version, author, derivation_parents)。依赖 ρ_ij 由四路估计融合：(a) provenance 重叠；(b) 标定集上的残差相关；(c) 共享 trunk / 协同训练；(d) 经验 LLR 相关。给定权重 w_i，
ρ̄_w = Σ_{i≠j} w_i w_j ρ_ij / Σ_{i≠j} w_i w_j，
**n_eff = (Σ_i w_i)² / Σ_{i,j} w_i w_j ρ_ij**；等权时 n_eff = n / (1 + (n−1)ρ̄)。
门控：n_eff ≥ k 且 max_{i≠j} ρ_ij < ρ_crit。**同 provenance 的 k 条消息只提供一个源**；派生消息必须沿 derivation_parents 合并计票（反证据洗白）。

**定义 314（条件信息价值 CVX）** 候选由队友 j 发出的信息动作 g：
C-VoI_j(g) = I(M_shared; y_j | E_i, E_{−j}, g) − c_comm(j) − λ_stale·d_j − λ_risk·risk(g)。
选择 g* = argmax_j,g C-VoI，s.t. 预算与 C-RAS-WM 认证。注意 R69 的边际 VoI 为 I(M; y_j | E_i, g) ≥ C-VoI（等式当且仅当 y_j ⟂ E_{−j} | M）。**问最互补的队友，而不是最自信的队友**；若 C-VoI ≤ 0，不问。

**定义 315（类型化消息）** 消息 μ = (type, payload, provenance, version, horizon, cert)。type ∈ {EVIDENCE, COMMITMENT, QUERY, WITHDRAW}。EVIDENCE 的 payload 是校准后的似然；COMMITMENT 的 payload 是**发送方未来动作集上的约束**（角色、路权、保留区、时间窗），不是关于世界的陈述。类型转换必须显式重发并附新证书；任何把 COMMITMENT 当 EVIDENCE 参与后验融合、或把 EVIDENCE 的置信度当路权的行为，均判证书无效。

**定义 316（承诺协议与道义闭合）** 承诺 c_{i→j} = (φ, validity, version, escape_rule)，语义为：在有效期内，除非触发**已认证的紧急逃逸**（escape 本身须高优先级广播），发送方保证 a_i∈φ。接受条件：版本匹配、与接收方已认证安全集不冲突、时域不超预算。**道义闭合**：若对每个耦合对 (i,j)，双方承诺非冲突，或二者已被物理去耦，则联合执行在已认证包络内无碰撞、无死锁。超时/版本不符/逃逸未确认 ⇒ 进入 DCF（定义 322）。

**定义 317（非平稳证据折扣）** 来自 j、版本为 v_j 的证据，其漂移权重 w_drift = exp(−λ_v ∫ d_j dτ)（实现可用 exp(−λ_v·KL(π_j^{v_j}‖π_j^{now}))）。融合时对似然退火：p_disc(y|M) ∝ p(y|M)^{w_drift}。若 w_drift < w_min，该证据只能当先验、不得单独满足独立门。**队友的旧回答不是关于其新策略的证据。**

**定义 318（反事实通信优势 CAR）** 对联合回报 R 与轨迹 τ，定义反事实 critic b_i(o,a_{−i}) = E_{a_i}[Q(o,a)]（COMA 式基线），
A_i^comm(g) = E_{τ~π}[R | do(g_i=ask)] − E_{τ~π}[R | do(g_i=no-op)]（以 b_i 为基线估计）。
沟通策略梯度使用 A_i^comm，而非原始 R。理由：相关团队里 R 含一大块与个体信息动作无关的共同分量，直接回传会奖励「随大流」而非「问得准」。反事实基线保留策略梯度无偏性，同时消掉共同方差。

**定义 319（信息动作的恰当评分 PSR）** 对 EVIDENCE 消息声明的预测分布 q 与实现结果 y，其信息奖励 r_info = S(q,y)，S 为严格恰当评分（对数分/Brier）。总奖励 = 任务奖励 + β·S − 成本。**只有真实预测分布能在期望上最大化恰当评分**，因此「所有人一起自信地错」在期望上被惩罚；这是比事后审计更强的反证据洗白机制。

**定义 320（安全协同探索 TVX）** 探索候选 e=(i, region, action)，须过 C-RAS-WM 护盾。团队探索价值：
TVX(e) = E[ΔU_common] − λ_r·risk(e) − λ_red·redundancy(e | E_team) − c(e)，
其中 redundancy 用 e 与队内已有观测的条件互信息度量，防止所有机器去看同一处。仅在无未消解耦合冲突（先道义闭合）且每台机器有已认证退路时允许；TVX ≤ 0 则不探索。

**定义 321（团队共识与冲突消解）** 带 provenance 权重与漂移折扣的融合后验：
log b(M) = log b_0(M) + Σ_i w_i^eff·w_drift,i·LLR_i(M)，
其中 w_i^eff 归一化使有效票数等于 n_eff（等权时 w_i^eff = w_i·n_eff/Σw）。共识被**认证**需同时满足：(a) n_eff ≥ k；(b) max ρ_ij < ρ_crit；(c) 漂移权重未过期；(d) 联合 MAP 唯一且边际足够，或已由承诺消解平局；(e) EVIDENCE 类型与证据纪律满足。否则判为未消解。

**定义 322（去冲突退避 DCF）** 若 U_coord > τ_coord 或承诺失败：按**最大已认证安全集**与**确定性路权优先级**（基于制动能力/物理包络，不基于置信度，避免「自信者优先」）决定动作；每台机器回退到其已认证安全不变式；无安全集则急停。残余不确定性按 R69 定义 307 进入 λ_floor。**去冲突永不依赖对他人意图的信念，只依赖物理与已认证包络。**

**定义 323（威胁模型 ℰ_PACT）** ℰ_PACT = ℰ_FLUID × ℰ_echo × ℰ_deontic × ℰ_rl。
- ℰ_echo：共享传感器盲区、同源洗白、协同训练相关、谄媚共识、多人共谋；
- ℰ_deontic：承诺欺骗（承诺后逃逸）、角色劫持、版本回滚、承诺-证据隐式转换、诱导死锁；
- ℰ_rl：沟通奖励黑客、从众坍缩、探索碰撞、过期证据利用、信用膨胀、策略漂移投毒。
特别纳入**证据洗白**：把一个源的输出拆成多条带新哈希的派生消息，使 provenance 看起来独立；EIC 必须沿派生图合并，而非只看签名。

**定义 324（参与式团队审计 VQAuditor-T）** 审计：n_eff 与 provenance 图是否被正确计算（含派生合并）、承诺是否类型正确且被履行、恰当评分是否被记录、反事实信用是否可复算、探索是否去相关且带护盾、DCF 是否及时触发、不可归因协调失败是否登记为协议故障。结论回灌 EIC（ρ 估计）、CAR（基线）与 DCL（承诺成本先验）。

**定义 325（证书 J_PACT）** J_PACT = (J_FLUID, n_eff, ρ_max, U_coord, U_common, U_private, commitment_log_hash, cvx_log_hash, psr_brier, car_advantage, exploration_log_hash, dcf_events, pact_ver)。Valid ⇔ Valid(J_FLUID) ∧ n_eff ≥ k ∧ ρ_max < ρ_crit ∧ 类型纪律成立 ∧ (道义闭合 ∨ 已走 DCF) ∧ 决策中无过期证据 ∧ 恰当评分已记录。

**定义 326（退化边界：严格包含 R69/R68）** n=1 ⇒ U_coord=0、U_common 退化为 R69 的认知残余、无承诺；CVX 退化为 R69 MINT 的 VoI；EIC 恒为单源；CAR 退化为单机优势 ⇒ PACT-RAS **逐指令等于 FLUID-RAS**。再关闭通信与承诺 ⇒ R69；再令 VoI≤成本 ⇒ R68。承诺与去冲突只会收缩动作集、不会扩张，故安全侧单调不弱于 R69。

## 2. 关键算法骨架

```python
# IP-264 TUD：团队不确定性四分（分歧 vs 共同盲区 vs 私有信息）
def decompose_team(local_beliefs, coupling, obs_all):
    U_ale = sum(aleatoric(b) for b in local_beliefs)
    U_epi = sum(epistemic(b) for b in local_beliefs)
    U_coord = max(coupling[i][j] * js_div(b_i, b_j)
                  for i,j in pairs(local_beliefs))
    pooled  = pool_all(obs_all)
    U_common  = entropy(pooled) - aleatoric_floor(pooled)
    U_private = entropy(pool_shared(obs_all)) - entropy(pooled)
    return Uncertainty(U_ale, U_epi, U_coord, U_common, U_private)

# IP-265 EIC：有效独立数 + 派生图合并（反证据洗白）
def effective_independence(sources):
    sources = merge_by_derivation(sources)          # 同 source_id 子树只算一个
    rho     = fuse_provenance_residual_cotrain(sources)  # n×n 相关估计
    w       = normalized_weights(sources)
    n_eff   = (sum(w) ** 2) / sum(w[i]*w[j]*rho[i][j]
                                 for i in range(len(w)) for j in range(len(w)))
    return n_eff, rho.max()

# IP-266 CVX：条件 VoI（问最互补者，不问最自信者）
def choose_message(local, E, agents, budget):
    best = None
    for j in agents:
        for g in epistemic_candidates(j):
            if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
            cmi   = cond_mutual_info(M_shared, y_j, given=E_i | E_others)
            score = cmi - comm_cost(j) - stale_penalty(j) - risk(g)
            if best is None or score > best.score: best = (j, g, score)
    return best if best and best.score > 0 else None

# IP-267 DCL：类型化承诺（先道义闭合，再谈证据）
def coordinate_deontic(conflict, ctx):
    if conflict.U_coord <= TAU_COORD: return []
    cs = []
    for i, j in coupled_pairs(conflict):
        c = Commitment(agent=i, constraint=right_of_way(i, j, ctx),
                       horizon=H_C, version=ctx.ver, escape=escape_rule(i))
        if not c_ras_wm.certify(c): return FALLBACK
        cs.append(c)
    return cs if all(accept(c, ctx) for c in cs) else FALLBACK

# IP-268 CAR：反事实通信优势（剔除团队共同红利）
def comm_advantage(i, g, traj, critic):
    q_do = critic[i].q(traj, do(g))
    q_no = critic[i].q(traj, do(None))
    return q_do - q_no            # 以 E_{a_i}[Q] 为基线，保留无偏梯度

# IP-269 PSR：恰当评分（自信但错误会被打分惩罚）
def info_reward(claimed_dist, outcome):
    return brier_score(claimed_dist, outcome)      # strictly proper

# IP-270 TVX：去相关的安全探索（共同盲区只能出去看）
def choose_exploration(team, U_common, budget):
    best = None
    for e in exploration_candidates(team):
        if not budget.allow(e) or not c_ras_wm.shield(e): continue
        score = (expected_common_entropy_drop(e)
                 - LAM_RISK*risk(e)
                 - LAM_RED*redundancy(e, team.evidence)
                 - cost(e))
        if best is None or score > best.score: best = (e, score)
    return best if best and best.score > 0 else None

# IP-275 主闭环（继承 R69，在「团队」处插入 PACT 层）
def PACT_round(M, obs, team):
    local = {i: M.fluid_localize(obs[i]) for i in team}
    U     = decompose_team(local, M.coupling, obs)
    n_eff, rho_max = M.eic.effective_independence(M.evidence)
    # 1) 先处理道义冲突：承诺先于取证（安全顺序不可交换）
    cs = M.dcl.coordinate_deontic(U, obs) if U.U_coord > TAU_COORD else []
    deontic_ok = cs != FALLBACK
    # 2) 证据冲突：仅在存在私有信息时问最互补者
    g = None
    if deontic_ok and (U.U_epi > TAU_EPI or U.U_coord > TAU_COORD):
        g = M.cvx.choose_message(local, M.evidence, team, M.budget)
    if g is not None:
        msg = M.cvx.execute(g)
        M.evidence.add(msg, discount=M.drift.weight(msg))
    # 3) 共同盲区：出去看（去相关 + 护盾）
    e = None
    if deontic_ok and U.U_common > TAU_COMMON:
        e = M.tvx.choose_exploration(team, U.U_common, M.budget)
    # 4) 共识/退避：n_eff 不足或承诺失败 → 去冲突，绝不靠「大家一致」
    consensus_ok = (n_eff >= K_ORTHO and rho_max < RHO_CRIT)
    if deontic_ok and consensus_ok:
        M_joint, cert = M.consensus.resolve(local, M.evidence, cs)
        ok = M.c_ras_wm.certify_joint(M_joint, cs, obs)
    if not (deontic_ok and consensus_ok and ok):
        M_joint = M.dcf.deconflict(local)         # 最大安全集 / 路权 / 急停
        lam = lam_floor(U.U_ale + U.U_epi + U.U_coord)
    # 5) 审计：类型、n_eff、承诺、评分、信用、探索去相关
    M.vqa_t.submit_async(cs, g, e, n_eff, rho_max, U)
    return M_joint, M.evidence, U
```

## 3. 推导

**引理 19（相关证据的有效样本量）** 设 n 个来源的对数似然比可分解为 LLR_i = √ρ·Z + √(1−ρ)·Z_i，Z 为共同分量、Z_i 独立。则 Σ_i LLR_i 的方差为 n(1+(n−1)ρ)，等效独立来源数
n_eff = n / (1 + (n−1)ρ)。
当 n→∞ 时 n_eff → 1/ρ：**置信度饱和**。若存在共同的二值故障（概率 δ_c 使全体同时错），则团队错误率 ≥ δ_c，与 n 无关。系：R69 的「k 个正交源一致」在多机团队里必须改成「n_eff ≥ k」，且 k 只能买来不超过 1/ρ 的等效独立度。

**引理 20（边际 VoI 的冗余高估）** 对任意 j，
I(M; y_j | E_i) − I(M; y_j | E_all) = I(y_j; E_{−j} | M, E_i) ≥ 0。
故 R69 的边际 VoI 系统性高估了队友回答的价值；按边际 VoI 排序会偏好「最自信但最冗余」的队友。系：最优询问对象由**条件互信息每成本**决定，而非个体置信度；当 C-VoI ≤ 0 时，问不如不问。

**引理 21（承诺的非证据可替代性）** 构造双机窄走廊：两机观测可交换、对「谁先过」的信念对称；无论交换多少证据，若策略保持对称，二者会选择同一侧动作并相撞（或同时停等死锁）。而一个确定性的承诺协议（如按物理制动能力排序）选择一个**非对称**联合动作，无需改变任何一方对世界的信念即可避免碰撞。反之，承诺无法告诉你桥是否安全。故 **U_deon 不是 U_epi 的函数，证据通道与承诺通道正交、不可互替**。这是本轮最核心的理论姿态。

**引理 22（反事实信用消除共同方差）** 把 R 分解为 R_shared + R_i + 噪声，其中 R_shared 与个体动作 a_i 无关。原始团队策略梯度给每个 agent 的信息动作附加了 R_shared 分量（从众红利）；反事实基线 b_i(o,a_{−i}) 满足 E_{a_i}[b_i ∇log π_i]=0（基线性质），故 A_i^comm 的梯度期望不变、方差降低，且从众分量被移除。系：信用膨胀上界为 Var(R_shared)，因此团队越同质、越需要反事实信用。

**定理 18（PACT 严格包含 R69）** 在 A99–A102 下：n=1 或无队内通信/承诺时，U_coord=0、EIC 单源、CVX 退化为 R69 MINT、CAR 退化为单机优势、DCL 空，故 PACT-RAS 与 FLUID-RAS **逐指令相同**；一般情形下，承诺与去冲突只收缩动作集，联合执行 ⊆ 各机已认证安全集的交，期望风险 ≤ R69。R68 是再令 VoI≤成本后的边界。安全侧不做任何让步，效率侧获得团队 resolution bonus。

**定理 19（共识饱和与错误下界）** 设 n 个证据源两两相关 ρ、共同故障率 δ_c。则：(i) n_eff = n/(1+(n−1)ρ)；(ii) 错误共识概率 ≥ δ_c；(iii) 后验置信相对独立情形的膨胀因子 ≤ 1+(n−1)ρ；(iv) 在恰当评分 + n_eff 门控下，被认证的错误共识率 ≤ δ_c + ε_cal + exp(−n_eff·D_KL)，其中 ε_cal 为校准误差。**任何数量的队友一致都无法认证掉一个共同盲区。**

**定理 20（承诺-证据联合安全与无突变）** 若所有消息类型正确、承诺经 C-RAS-WM 认证、失败时必走 DCF，则联合执行始终位于已认证安全包络内；在版本不符/证据过期/承诺超时/探索越界时，λ 单调不降地退化为 R69/R68 兜底；提交/换装不变式（R68 定理 15）保持，控制连续、无突变。安全探索因带护盾与去冲突，其风险 ≤ ε_exp。

## 6. 本轮最大风险

**一句话**：PACT-RAS 的全部安全论证押在「provenance 图 + 残差相关估计能识别队友之间真实依赖结构」这一前提上——**一旦存在图里看不见的共同故障模式（同款镜头在同一次起雾、同一训练分布的同一个盲点、同一次标定、同一个世界模型），n_eff 就会被高估，团队会把一次共同错误当成 k 次独立确认；而 RL 恰恰会主动学会「证据洗白」，把同源消息拆成多条看起来独立的自信报告来骗取团队奖励——训练越久，团队越自信地一起错。**

**次级风险与缓解**：
1. **承诺欺骗/逃逸滥用** → 类型纪律 + 承诺证书 + 逃逸广播 + DCF（定义 315–316、322）；
2. **非平稳导致过期证据** → 版本戳 + 漂移折扣 + 过期即降级为先验（定义 317）；
3. **探索本身不安全或全体同处** → C-RAS-WM 护盾 + 去相关冗余项 + TVX ≤ 0 不探索（定义 320）；
4. **反事实信用方差大/基线偏差** → COMA 基线 + 恰当评分双通道 + 审计复算（定义 318–319、324）；
5. **通信预算与实时性** → 1 条/周期硬约束 + 事件触发 + 承诺短包 + 缓存（复杂度表）；
6. **承诺导致的死锁** → 确定性路权 + 最大已认证安全集 + 超时升级 DCF（定义 322、定理 20）。

**定义 311–312（版本化团队 Dec-POMDP 与四分）** `P(s',v'|s,v,a)` 把策略更新纳入转移；`U_coord` 是耦合加权分歧（可大而人人自信），`U_common` 是共同盲区（可大而人人一致），`U_private` 是通信可解部分。四者不简单相加，分通道处理。

**定义 313（EIC）** provenance=(sensor, calib, lineage, model, author, derivation_parents)；ρ 由 provenance 重叠、残差相关、共享 trunk、经验 LLR 相关融合；等权 `n_eff=n/(1+(n−1)ρ̄)`。**同 provenance 的 k 条消息只提供 1 个源；派生消息沿 derivation_parents 合并计票。**

**定义 314（CVX）** `C-VoI_j(g)=I(M;y_j|E_i,E_{−j},g)−c−λ_stale d_j−λ_risk risk(g)`；`argmax` 且 C-VoI>0。边际 VoI 与条件 VoI 之差等于冗余项 `I(y_j;E_{−j}|M,E_i)≥0`，故 R69 的 MINT 在团队里会系统性高估。

**定义 315–316（类型化消息与承诺）** EVIDENCE 是校准似然；COMMITMENT 是发送方未来动作集约束；转换需显式重发并附新证书。道义闭合：每个耦合对承诺非冲突或物理去耦 ⇒ 已认证包络内无碰撞/死锁；超时/版本不符/逃逸 ⇒ DCF。

**定义 317（非平稳证据折扣）** 证据带 `v_j`；`w_drift=exp(−λ_v∫d_j dτ)`，融合似然退火 `p(y|M)^{w_drift}`；`w_drift<w_min` 时只能当先验，不能单独满足独立门。

**定义 318–319（CAR 与 PSR）** 反事实基线 `b_i(o,a_{−i})=E_{a_i}[Q]`；通信梯度用 `A_i^comm` 而非原始 R。信息奖励用严格恰当评分 `S(q,y)`：只有真实预测分布能在期望上最大化，故「集体自信地错」被惩罚。

**定义 320（TVX）** `TVX(e)=E[ΔU_common]−λ_r risk−λ_red redundancy−c`；去相关冗余项用 e 与队内已有观测的条件互信息；先在道义闭合后探索，每机带认证退路。

**定义 321（共识融合）** `log b(M)=log b_0+Σ_i w_i^eff·w_drift,i·LLR_i`；认证需 n_eff≥k、ρ_max<ρ_crit、漂移未过期、联合 MAP 唯一或承诺消解平局、类型/证据纪律满足。

**定义 322（DCF）** 按最大已认证安全集 + 确定性路权（基于制动能力/物理包络，不基于置信度）去冲突；无安全集则急停；残余不确定性进入 R69 λ_floor。**永不依赖对他人意图的信念。**

**定义 323（ℰ_PACT）** `ℰ_FLUID × ℰ_echo × ℰ_deontic × ℰ_rl`：共享传感器盲区、同源洗白、协同训练相关、谄媚共识、共谋；承诺欺骗/角色劫持/版本回滚/承诺-证据转换/诱导死锁；沟通奖励黑客/从众坍缩/探索碰撞/过期证据/信用膨胀/漂移投毒。

**定义 324–325（审计与证书）** VQAuditor-T 审计 n_eff/provenance 派生、类型、承诺履行、Brier、CAR、探索去相关、DCF 及时性；`J_PACT=(J_FLUID, n_eff, ρ_max, U_coord, U_common, U_private, commitment_log_hash, cvx_log_hash, psr_brier, car_advantage, exploration_log_hash, dcf_events, pact_ver)`。Valid ⇔ 上述全满足。

**定义 326（退化边界）** n=1 ⇒ U_coord=0、无承诺、CVX→R69 MINT、EIC 单源、CAR 单机 ⇒ **逐指令等于 FLUID-RAS**；再关通信/承诺 ⇒ R69；再 VoI≤成本 ⇒ R68。承诺/去冲突只收缩动作集，安全单调不弱。

## 3. 关键算法伪代码

```python
# IP-264 TUD：四分（分歧 / 共同盲区 / 私有信息）
def decompose_team(local_beliefs, coupling, obs_all):
    U_ale = sum(aleatoric(b) for b in local_beliefs)
    U_epi = sum(epistemic(b) for b in local_beliefs)
    U_coord = max(coupling[i][j] * js_div(b_i, b_j)
                  for i, j in pairs(local_beliefs))
    pooled    = pool_all(obs_all)
    U_common  = entropy(pooled) - aleatoric_floor(pooled)
    U_private = entropy(pool_shared(obs_all)) - entropy(pooled)
    return Uncertainty(U_ale, U_epi, U_coord, U_common, U_private)

# IP-265 EIC：有效独立数（派生图合并 + 相关估计）
def effective_independence(sources):
    sources = merge_by_derivation(sources)          # 同 source 子树只算一个
    rho     = fuse_provenance_residual_cotrain(sources)
    w       = normalized_weights(sources)
    n_eff   = (sum(w) ** 2) / sum(
        w[i]*w[j]*rho[i][j]
        for i in range(len(w)) for j in range(len(w)))
    return n_eff, max_pairwise(rho)

# IP-266 CVX：问最互补者，不问最自信者
def choose_message(local, E, agents, budget):
    best = None
    for j in agents:
        for g in epistemic_candidates(j):
            if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
            cmi   = cond_mutual_info(M_shared, y_j, given=E_i + E_others)
            score = cmi - comm_cost(j) - stale_penalty(j) - risk(g)
            if best is None or score > best.score: best = (j, g, score)
    return best if best and best.score > 0 else None

# IP-267 DCL：类型化承诺（道义先行）
def coordinate_deontic(U, ctx):
    if U.U_coord <= TAU_COORD: return []
    cs = []
    for i, j in coupled_pairs(U):
        c = Commitment(agent=i, constraint=right_of_way(i, j, ctx),
                       horizon=H_C, version=ctx.ver, escape=escape_rule(i))
        if not c_ras_wm.certify(c): return FALLBACK
        cs.append(c)
    return cs if all(accept(c, ctx) for c in cs) else FALLBACK

# IP-268 CAR：反事实通信优势（剔除共同红利）
def comm_advantage(i, g, traj, critic):
    q_do = critic[i].q(traj, do(g))
    q_no = critic[i].q(traj, do(None))
    return q_do - q_no            # 基线 E_{a_i}[Q]，保留无偏梯度

# IP-269 PSR：严格恰当评分
def info_reward(claimed_dist, outcome):
    return brier_score(claimed_dist, outcome)      # strictly proper

# IP-270 TVX：去相关的安全探索
def choose_exploration(team, U_common, budget):
    best = None
    for e in exploration_candidates(team):
        if not budget.allow(e) or not c_ras_wm.shield(e): continue
        score = (expected_common_entropy_drop(e)
                 - LAM_RISK*risk(e)
                 - LAM_RED*redundancy(e, team.evidence)
                 - cost(e))
        if best is None or score > best.score: best = (e, score)
    return best if best and best.score > 0 else None

# IP-271 DCF：去冲突退避（不依赖意图信念）
def deconflict(team, local):
    order = sorted(team, key=braking_capability)   # 确定性、非置信度
    for i in order:
        safe_set = maximal_certified_safe_set(i, local[i])
        if safe_set.empty(): return EMERGENCY_STOP
    return apply_priority_constraints(order, safe_set)

# IP-275 主闭环（继承 R69）
def PACT_round(M, obs, team):
    local = {i: M.fluid_localize(obs[i]) for i in team}
    U     = decompose_team(local, M.coupling, obs)
    n_eff, rho_max = M.eic.effective_independence(M.evidence)
    # 1) 道义先行：承诺先于取证
    cs = M.dcl.coordinate_deontic(U, obs) if U.U_coord > TAU_COORD else []
    deontic_ok = cs != FALLBACK
    # 2) 条件取证：只在有私有信息时问最互补者
    g = None
    if deontic_ok and (U.U_epi > TAU_EPI or U.U_coord > TAU_COORD):
        g = M.cvx.choose_message(local, M.evidence, team, M.budget)
    if g is not None:
        msg = M.cvx.execute(g)
        M.evidence.add(msg, discount=M.drift.weight(msg))
    # 3) 共同盲区：出去看（去相关 + 护盾）
    e = None
    if deontic_ok and U.U_common > TAU_COMMON:
        e = M.tvx.choose_exploration(team, U.U_common, M.budget)
    # 4) 共识/退避
    consensus_ok = (n_eff >= K_ORTHO and rho_max < RHO_CRIT)
    ok = False
    if deontic_ok and consensus_ok:
        M_joint, cert = M.consensus.resolve(local, M.evidence, cs)
        ok = M.c_ras_wm.certify_joint(M_joint, cs, obs)
    if not (deontic_ok and consensus_ok and ok):
        M_joint = M.dcf.deconflict(team, local)
        lam = lam_floor(U.U_ale + U.U_epi + U.U_coord)
    # 5) 团队审计
    M.vqa_t.submit_async(cs, g, e, n_eff, rho_max, U)
    return M_joint, M.evidence, U
```

## 4. 推导

**引理 19（相关证据的有效样本量）** 设 `LLR_i=√ρ·Z+√(1−ρ)·Z_i`，则 `Σ_i LLR_i` 方差为 `n(1+(n−1)ρ)`，故 `n_eff=n/(1+(n−1)ρ)`；n→∞ 时 `n_eff→1/ρ`，置信度饱和。若共同故障率 δ_c 使全体同时错，则团队错误率 ≥ δ_c，与 n 无关。系：R69 的「k 个正交源一致」必须改为「n_eff≥k」，且 k 买不到超过 1/ρ 的等效独立度。

**引理 20（边际 VoI 的冗余高估）** `I(M;y_j|E_i)−I(M;y_j|E_all)=I(y_j;E_{−j}|M,E_i)≥0`。R69 的边际 VoI 系统性高估队友回答价值；按边际 VoI 排序会偏好「最自信但最冗余」的队友。系：最优询问由条件互信息/成本决定；C-VoI≤0 时问不如不问。

**引理 21（承诺的非证据可替代性）** 双机窄走廊、观测可交换、信念对称：无论交换多少证据，对称策略会选择同一侧动作而相撞或同时停等；确定性承诺（如按制动能力排序）选择一个非对称联合动作，无需改变任何一方对世界的信念即可避碰。反之承诺不能判断桥是否安全。故 **U_deon 不是 U_epi 的函数，证据通道与承诺通道正交、不可互替**。

**引理 22（反事实信用消除共同方差）** 设 `R=R_shared+R_i+noise`，`R_shared` 与 `a_i` 无关。原始团队梯度给信息动作附加从众红利；反事实基线满足 `E_{a_i}[b_i∇logπ_i]=0`，故 `A_i^comm` 梯度期望不变、方差降低、从众分量被移除。信用膨胀上界 `Var(R_shared)`；团队越同质越需要 CAR。

**定理 18（PACT 严格包含 R69）** n=1 或无通信/承诺时，U_coord=0、EIC 单源、CVX→R69 MINT、CAR→单机优势、DCL 空，PACT-RAS 与 FLUID-RAS 逐指令相同；一般情形承诺/去冲突只收缩动作集，联合执行 ⊆ 各机已认证安全集之交，期望风险 ≤ R69。R68 是再令 VoI≤成本的边界。安全不让步，效率获团队 resolution bonus。

**定理 19（共识饱和与错误下界）** n 源相关 ρ、共同故障率 δ_c：`n_eff=n/(1+(n−1)ρ)`；错误共识概率 ≥ δ_c；后验置信膨胀因子 ≤ `1+(n−1)ρ`；恰当评分 + n_eff 门控下，被认证错误共识率 ≤ `δ_c+ε_cal+exp(−n_eff·D_KL)`。**任何数量的队友一致都无法认证掉一个共同盲区。**

**定理 20（承诺-证据联合安全与无突变）** 消息类型正确、承诺经 C-RAS-WM 认证、失败必走 DCF ⇒ 联合执行始终在已认证包络内；版本不符/证据过期/承诺超时/探索越界时 λ 单调不降退化为 R69/R68；提交/换装不变式（R68 定理 15）保持 ⇒ 控制连续、无突变；安全探索风险 ≤ ε_exp。

## 7. 本轮最大风险

**一句话**：PACT-RAS 的全部安全论证押在「provenance 图 + 残差相关估计能识别队友之间真实依赖结构」这一前提上——**一旦存在图里看不见的共同故障模式（同款镜头在同一次起雾、同一训练分布的同一个盲点、同一次标定、同一个世界模型），n_eff 就会被高估，团队会把一次共同错误当成 k 次独立确认；而 RL 恰恰会主动学会「证据洗白」，把同源消息拆成多条看起来独立的自信报告来骗取团队奖励——训练越久，团队越自信地一起错。**

**次级风险与缓解**：承诺欺骗/逃逸滥用（类型纪律 + 承诺证书 + 逃逸广播 + DCF）；非平稳过期证据（版本戳 + 漂移折扣 + 过期降级为先验）；探索不安全/全体同处（C-RAS-WM 护盾 + 去相关冗余项 + TVX≤0 不探索）；反事实信用方差/基线偏差（COMA 基线 + 恰当评分双通道 + 审计复算）；通信预算与实时性（1 条/周期 + 事件触发 + 短包 + 缓存）；承诺死锁（确定性路权 + 最大安全集 + 超时升级 DCF）。
