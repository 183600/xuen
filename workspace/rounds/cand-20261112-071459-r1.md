# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「数据采集」×「机器人」）

> 第 57 轮把证据质量做到"少样本可校准、跨模态可对账、个性化有界"，但它默认了一件从未被检验的事：**元语料是世界的一份忠实抽样**。事实恰好相反——机器人只在"安全策略允许它去"的地方采集，于是数据集由它本应改进的那条策略亲手剪裁：最危险、最未知、最需要先验的区域，恰恰被采得最少，甚至一次也没被采过。这不是随机缺失，而是**策略性缺失（MNAR）**；"幸存者偏差"在具身系统里是结构性的：我们只统计飞回来的飞机。本轮两个灵感把这个盲点提升为设计公理：**数据采集**不是被动日志，而是一种**有风险、有价值、可被审计的动作**（采集即动作，collection-as-action）；**机器人**是测量仪器本身，每一个样本都带着"体检报告"（执行保真、打滑、标定新鲜度、传感器健康）与来源链（采集即证词，collection-as-testimony）。二者合流：**"采集可知情、支持可检验、来源可追溯的证据说可信"**。同时给车队共享加一道闸：跨机器人数据迁移必须持**运输契约**，只传认证充分统计量，不传原始共享状态——否则 A 的偏差会变成 B 的先验。核心命题由第 57 轮的"少样本可校准"升级为 **"可识别性先于校准性：先问'这片世界我到底有没有资格谈'，再谈'谈得多准'"**。

核心矛盾：
- **H29（采集 vs 安全，内生性/MNAR）**：安全策略决定采什么数据，越危险的区域采得越少；于是元先验在"被回避的世界"上最无知，却最被需要。倾向加权（IPW/DR）只能修正**有正倾向**的区域；对"永不采集"的区域是正性违背（positivity violation），不存在无偏估计量——这是**可识别性的硬边界**，不是样本量问题。而且选择偏差无法用被选中的数据自证，必须审计**选择过程本身**。
- **H30（数据量 vs 数据质，具身性）**：并非所有样本等价。打滑时采的探针、标定过期后的视觉、执行未达预期的接触，都是"坏证词"；数据飞轮若只追数量，会把系统偏差和噪声一起放大成"自信的错误先验"。
- **H31（共享 vs 异质，跨机器人）**：车队共享能补盲区，但不同机器人的传感器几何、标定、磨损不同；原始数据共享会把源机器人的系统偏差变成目标机器人的先验（域偏移污染）。泛化必须是**持证迁移**，不是偷偷共享。

## 0. 直觉与动机

**灵感 1（数据采集 → 采集是动作，数据是策略性缺失的样本）**
直觉：机器人的部署不是"被动测温"，而是一场由安全策略设计的实验。类比临床试验：最重的病人被排除在试验之外，于是结论对最重的病人无效。机器人在冰面、陡坡、未知材质上选择绕行或安全停——这些正是它最不了解的区域，也永远不会出现在训练集里。更麻烦的是，你**无法用被筛过的数据发现筛子**：OOD 检测只能对"已经采到的数据"报警，对"从未采到"的区域永远静默。所以必须记录**采集倾向** e(r)=P(该区域被采)，用倾向加权/双重稳健去修正支持内的偏差；并把 e(r) 过低的区域登录为"阴影区"，永不采信元先验，只能靠新探针、最坏情况带或人。

**灵感 2（机器人 → 具身数据质量与共享契约）**
直觉：机器人是仪器。仪器在打滑、过载、标定漂移时读数不可信；同一探针在落地相位不同、执行力未达预期时，是两种不同的证据。故每个样本必须携带来源五元组（区域、模态、执行 vs 意图、本体状态、标定版本）与质量分 q_col；低于阈值的样本进"隔离语料"，只可用于标定诊断，**不得作为证据、不得进元训练**。车队层面，这像多中心临床数据的** harmonization **：不能直接合并原始记录，要先做跨中心校准（传感器几何映射），再做域偏移检验，通过后才以"认证充分统计量"形式共享。

**灵感 3（合流 → 采集-判定分离、数据隔离、影子采集）**
直觉：如果"采集数据"的目标和"决定是否承诺"的目标由同一个模块优化，系统就会滑向"为了让自己敢赌而采集对自己有利的数据"——自我交易。故必须**采集者与判定者分离**（separation of duties）：采集规划不能改判定阈值；只为自身区域承诺服务的样本被打上"自利"标签并限权。主动采集是一种冒险，须装进**探索安全包络**：非不可逆、可恢复、有安全停回退、力有上限；任何越出包络的采集都要**知情同意**（人明确听到最坏情况）。数据飞轮与第 57 轮的元模型更新一样，走影子模式与隔离区，通过回归测试才允许接管。

**灵感 4（对第 57 轮的反噬 → 可识别性是校准性的前提）**
直觉：第 57 轮的摊销先验在"语料像不像"上做文章（OOD 门），却没问"语料是不是被挑过的"。若语料被安全策略剪裁，跨区域摊销会把**选择偏差按类放大**——被回避的类别越多，元先验在那些类上越"整齐地错"，正是它自己警告的"坏先验普遍"，只是这次不是新材质，而是"已知但不敢看"的世界。结论：MFSL 的 ε_meta(k) 校准声明**只在采集支持集 𝒮_e 上成立**；支持外必须换成"必须自己买证据"，而不能拿摊销先验顶账。

**灵感 5（PCE++ → 决策价值与采集价值分账）**
直觉：探针有两个用途——为自己的承诺降险（决策 VOI），或为车队/未来补盲（采集价值 CV）。二者混在一个预算里，必然牺牲长期覆盖去满足当下承诺，或用当前安全去换数据。PCE++ 把预算拆成 B_dec 与 B_col：承诺只用决策 VOI；采集在安全包络内按 CV 排程；阴影区驱动下一轮主动采集或遥操作请求；所有数据经来源/质量/倾向三证后，才进入元语料的"支持内"部分。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（采集动作与倾向记录 CAA）** 部署策略 π=(π_x,π_col)；每次采集事件 i 记采集记录 c_i=(r_i,m_i,u_i^int,u_i^exe,s_i^prop,k_i,π_i^col,cal_ver_i,level_i)，倾向 e_i=Pr(collect (r_i,m_i)|ℱ_{t_i})，由日志策略估计得 ê_i。观测语料 𝒟_obs={(o_i,c_i):δ_i=1}，δ_i=1 表示被采到。因 π_col 依赖风险与不确定性，δ_i 与真实 θ(r_i) 相关 ⇒ **MNAR**：p(o|δ=1)≠p(o)。目标是在全区域 V 上估计 θ(r)，而非仅在采到的子集上。

**定义 140（采集支持、正性证书与倾向加权元推断 PWML）** 策略诱导支持集 𝒮_e={r∈V: ê(r)≥e_min ∧ ESS(r)≥n_min}，ESS(r)=(Σ_i ê_i^{−1})²/Σ_i ê_i^{−2}。正性证书：𝒮_e 内 ê 校准误差 ≤ε_e。区域若 ê(r)<e_min 或 ESS 不足 ⇒ 登录为**阴影区** 𝒮̄，**禁 MFSL 摊销先验**。元训练用倾向/双重稳健风险：L_PW(φ)=|𝒟|^{-1}Σ_i δ_i w_i ℓ(q_φ(o_i),θ̂_i)，w_i=min(1/ê_i,W_cap)；L_DR(φ)=|𝒟|^{-1}Σ_i[m̂(o_i)+δ_i w_i(ℓ_i−m̂(o_i))]。声明 ε_meta(k) 仅对 𝒮_e 有效。**两个正交门**：OOD 门（语义新颖，需有数据才能触发）× 正性门（策略诱导缺席，数据本身永远无法触发，只能由倾向日志审计）。可识别性：∃r 使 e(r)=0 ⇒ 不存在 θ(r) 的无偏估计（非样本量问题，硬边界）。

**定义 141（采集质量证书与来源追踪 CPQ）** 每样本质量 q_col(i)=Φ(1−‖u^exe−u^int‖/u_scale, −slip_i, −f(cal_age_i), sensor_health_i, gait_phase_valid_i)∈[0,1]。资格：q_col≥q_min 才能作为证据或进元语料；否则进隔离语料 𝒬（只用于标定/诊断）。来源链 L_prov 为哈希链 (o_i,c_i,q_col,cal_ver,code_ver)。**事后回溯失效**：若某标定/传感器缺陷事后确认，按 cal_ver 找出全部受影响样本，逐出/降权，并**回滚**吃过它们的模型；对回滚前已被它们支撑的承诺打"待复核"标记——把第 57 轮"模态 ρ 回溯"下沉到**数据来源层**。

**定义 142（主动采集预算与探索安全包络 ACB）** 预算拆为 B_dec（承诺探针）与 B_col（采集探针）。采集价值 CV(q)=E[𝒮̄ 上后验熵下降]+λ·coverage−cost(q)；决策价值 VOI_dec 只用于承诺。探索安全包络 ℰ_safe={非不可逆 ∧ 可恢复 ∧ 存在安全停回退 ∧ F≤F_col ∧ level≤L1}。包络外采集需**包络扩展知情同意**（明确最坏情况与回退方案），且速率有界。**采集-判定分离**：采集规划器不得改承诺阈值；仅为自身区域承诺增信的样本打 self_serving 标签，证据权重设上限。

**定义 143（跨机器人数据运输契约 CDC）** 样本从机器人 B 供 A 使用须持运输契约 T_{B→A}=(g_{B→A} 传感器几何/标定映射, cal_attestation, δ_shift, shift_test)。域偏移检验：Δ_{B→A}=sup_r|q_φ^A(r)−g_{B→A}(q_φ^B(r))|（在 A 的标定集上回放）；接受 ⇔ Δ≤δ_shift，运输权重 w_i^tr=(1−Δ/δ_shift)_+；否则重标定/降权/拒绝。**只传认证充分统计量**，不传原始共享状态（延续第 56 轮"认证抽象才可越界"）。车队语料按契约取并集，元训练权重乘 w_i^tr。

**定义 144（采集-判定分离的数据飞轮 DCP 与证书 J_d）** 闭环算子：部署 → CAA 倾向+质量日志 → 隔离/影子模式下做去偏元更新 → 维护阴影区登记 𝒮̄ → 在包络内排程主动采集/遥操作 →（越界则）人同意 → 语料更新 → **仅在留出认证数据上通过回归测试后才允许接管**（支持内 ECE 不劣化 ∧ 覆盖不下降 ∧ 支持集不收缩 ∧ 无阴影区被静默重分类）。证书 J_d=(propensity_log, support_cert, quality_ledger, collection_consent_log, transport_contracts, shadow_registry, self_serving_flags, rollback_records)。证据门升级：EV-probe\* 增加"**数据资格**"——若推断来自摊销先验，则必须 r∈𝒮_e 且样本 q_col 合格；阴影区/OOD 只能以**新采探针的实证**或最坏情况带进入 P_fail。

## 2. 关键算法伪代码（完整版见产物区）

```python
def censoring_aware_meta(phi, D, e_hat, m_hat, W_cap):
    # 倾向/双重稳健元风险（只对支持内声明校准）
    L = 0
    for o, theta, delta, e in D:
        w = min(1.0 / max(e, 1e-9), W_cap)
        L += m_hat(o) + delta * w * (loss(phi(o), theta) - m_hat(o))
    return L / len(D)

def collection_gate(r, e_hat, ess, q_col, level):
    if e_hat(r) < E_MIN or ess(r) < N_MIN: return 'shadow'   # 正性门：禁摊销
    if q_col < Q_MIN:                      return 'quarantine'
    return 'eligible'

def collect_or_commit(cp, M, budget, consent):
    inf = meta_infer(cp.region, M, support)          # 仅 𝒮_e 内用摊销
    if inf.cls != 'ID' or cp.region in shadow:       # 阴影/OOD：必须自买证据
        q = argmax(admissible_probes(cp), key=voi_dec)
        M = execute_and_log(q, propensity=pi_col, provenance=True)
    if can_commit(M, cp): return commit(cp, M)
    if cup.safe_envelope(cp) and budget.B_col > 0:   # 采集与承诺分账
        q = argmax(coverage_probes(M, shadow), key=CV)
        M = execute_and_log(q, propensity=pi_col, provenance=True)
    return reroute_or_stop(cp, M, tau_int=tau_int(persona.auth))
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| CAA/PWML | 训练 O(\|𝒟\|·d_φ)；推理 O(d_φ) | O(\|𝒟\|) | 倾向模型校准（ε_e）、权重裁尾、支持内声明 |
| 正性/阴影门 | O(\|V\|) 每轮 | O(\|V\|) | ê∈𝒮_e 校准、ESS 阈值、**数据无法自证筛选** |
| CPQ | O(1)/样本；回溯 O(\|𝒟\|) | O(\|𝒟\|) | q_col 诚实、来源链完整、回滚完备 |
| ACB | O(\|𝒮̄\|·C_CV) | O(\|𝒮̄\|) | 包络内采集、越界须同意、采集-判定分离 |
| CDC | O(\|cal\|·d) / 契约 | O(#contracts) | 偏移界诚实、只传认证统计量 |
| DCP/PCE++ | O(\|CP\|·(k_p+k_c+k_col)·(C_VOI+d_φ)) | O(\|V\|+\|𝒮̄\|) | 支持外必自买证据、飞轮可回滚、终止 |

**正确性定理（Causal-Collection Certified Soundness, CCCS 概要）**：在 A37–A40 上加 (A41) 倾向模型在声明支持上校准 |ê−e|≤ε_e 且 𝒮_e 上正性成立；(A42) 质量证书诚实（误收 q<q_min ≤δ_q）且回溯逐出完备；(A43) 采集只在包络内、越界有同意、采集-判定分离；(A44) 运输契约的偏移检验诚实。则：(i) **仅支持内**承诺失效率 ≤δ_f+ε_meta^{𝒮}(k)+L·ε_e+δ_probe+ε_h；支持外**没有任何 ε_meta 项**，必须由新探针/最坏情况带承担，且 P(把支持外误判为支持内)≤δ_pos；(ii) 交互单调性：采集/质量/运输只能经"支持内信念更准"、"动作更保守（拒绝/加宽带/须同意）"或"显式同意的包络扩展"影响系统，不存在静默升险路径；(iii) 飞轮每次写入要么过回归并接管，要么隔离/回滚，阴影区只增不漏；(iv) 部署界额外扣除 P(正性误判)。**明确不给阴影世界任何安全界**——这是本轮诚实划出的可识别性硬边界。

## 6. 本轮最大风险

**一句话**：本轮把"是否值得采信"从"数据像不像"推进到"数据是怎么被选出来的"，但正性违背是不可识别的——安全策略越可靠，最关键的区域采样倾向越接近零，任何倾向校正都无法凭空造出从未采过的证据；于是最大的风险不是"去偏不够"，而是把"阴影世界的不可知"包装成"已做去偏的自信"，或用数据飞轮之名对危险区域施压采集——必须以阴影区永久降级、包络外强制知情同意、采集-判定分离三道护栏，宁可承认"这片世界我没有资格谈"，也不让可识别性边界被效率叙事侵蚀。

# 第 58 轮产物 · 创新点清单 v34：Censoring-Aware Collection（数据采集即动作×具身数据可信×跨机器人运输，CAA×PWML×CPQ×ACB×CDC×DCP）

> 承接第 57 轮 IP-133~138（MFSL/XMC/PTM/MXI/FSE/PCE+）与第 56 轮 IP-127~132（SMM/PCE/BVK/ISE/TAF/MEC）。本轮把部署前提从"少样本可校准的证据承诺"再降一层到它的地基：**语料本身是不是世界的忠实抽样**。答案是否定的——机器人只在安全策略允许处采集，数据集被它本应改进的策略亲手剪裁，最需要的区域被系统性地采得最少（MNAR / 幸存者偏差）。本轮把采集从被动日志升级为**有风险、有价值、可审计的动作**，把机器人当作**会漂移的仪器**，把车队共享变成**持证运输**。命题升级为 **"可识别性先于校准性：采集可知情、支持可检验、来源可追溯的证据说可信"**。
> IP 编号：IP-139~IP-144（共 6 个），升级 IP-133/134/137/138 以纳入采集倾向、数据资格与采集-判定分账。

### IP-140 PWML（去偏元推断 + 正性/阴影门）

```python
def support_certificate(V, e_hat, ess, e_min, n_min):
    S, shadow = set(), set()
    for r in V:
        if e_hat[r] >= e_min and ess[r] >= n_min: S.add(r)
        else:                                     shadow.add(r)
    return S, shadow                                # 阴影区：禁摊销先验

def meta_risk_dr(phi, D, e_hat, m_hat, W_cap):
    total = 0.0
    for s in D:
        e = max(e_hat(s.c.r, s.c.m), 1e-9)
        w = min(1.0 / e, W_cap)
        l = loss(phi(s.o, ctx(s.c.r)), s.theta_hat)
        total += m_hat(s.o) + s.delta * w * (l - m_hat(s.o))   # 双重稳健
    return total / len(D)

def meta_infer_in_support(r, obs, phi, S, shadow, ece):
    if r in shadow:                                          # 正性门：不可识别
        return Inf(cls='SHADOW', belt=None)                  # 不输出点估计
    if ood_score(obs) > theta_ood:                           # 语义门
        return Inf(cls='OOD', belt=conformal_belt(...))
    return Inf(cls='ID', post=phi(obs, ctx(r)), ece_k=ece[len(obs)])
```

```python
def active_collect(M, shadow, budget, consent, persona):
    cands = [q for q in reachable_probes(M)
             if in_envelope(q, E_safe)]          # 非不可逆/可恢复/有安全停
```

```python
def transport_contract(B, A, calA):
    g = fit_geometry_map(B.sensors, A.sensors)              # 几何/标定对齐
```

### IP-144 DCP（采集-判定分离的数据飞轮）

```python
def data_flywheel(M, ledger, shadow, models):
    D = censoring_reweight(eligible(ledger), ledger.e_hat)   # 去偏语料
    cand = train_meta_shadow(D)                              # 影子模式
    if not regression_test(cand, heldout=contracted_data()):  # ECE/覆盖/支持不劣化
        return M, 'reject_model'

def regression_test(cand, heldout):
    return (ece(cand, heldout) <= ece(current, heldout) + 1e-3
            and coverage(cand, heldout) >= coverage(current, heldout) - 1e-3
            and support_size(cand) >= support_size(current))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CAA/PWML | 训练 O(\|𝒟\|·d_φ)；推理 O(d_φ) | O(\|𝒟\|) | 倾向校准 ε_e、权重裁尾、仅支持内声明（A41） |
| 正性/阴影门 | O(\|V\|)/轮 | O(\|V\|) | ê∈𝒮_e 校准、ESS、数据无法自证筛选（A41） |
| CPQ | O(1)/样本；回溯 O(\|𝒟\|) | O(\|𝒟\|) | q_col 诚实、来源链完整、回滚完备（A42） |
| ACB | O(\|𝒮̄\|·C_CV) | O(\|𝒮̄\|) | 包络内、越界须同意、采集-判定分离（A43） |
| CDC | O(\|cal\|·d)/契约 | O(#contracts) | 偏移界诚实、只传认证统计量（A44） |
| DCP/PCE++ | O(\|CP\|·(k_p+k_c+k_col)·(C_VOI+d_φ)) | O(\|V\|+\|𝒮̄\|) | 支持外必自买证据、飞轮可回滚、终止 |

**正确性定理（Causal-Collection Certified Soundness, CCCS）**
假设 A37–A40（第 56–57 轮）成立；**(A41)** 倾向模型在声明支持集上校准 |ê−e|≤ε_e，且 𝒮_e 上正性成立（e>0）；**(A42)** 质量证书诚实：P(误收 q<q_min)≤δ_q，回溯逐出完备；**(A43)** 采集只在探索安全包络内，越界须知情同意，采集规划不得修改承诺阈值（采集-判定分离）；**(A44)** 运输契约的域偏移检验诚实，Δ 有界。则：

1. **支持内少样本健全性**：ID ∧ r∈𝒮_e 路径 P(fail) ≤ δ_f + ε_meta^{𝒮}(k) + L·ε_e + δ_probe + ε_h(w_max) + δ_q。倾向误差项 L·ε_e 是选择偏差校正的代价；权重裁尾 W_cap 控制方差。
2. **支持外的可识别性硬边界**：若 r∈𝒮̄（ê<e_min 或 e=0），CCCS **不提供任何点估计与 ε_meta 保证**；系统只能以新采探针实证、最坏情况带或人；P(把 𝒮̄ 误判为 𝒮_e) ≤ δ_pos。这与第 57 轮 OOD 门互补：OOD 处理"没见过的世界"，正性门处理"不敢看的世界"，且后者**无法用被选中的数据检测**。
3. **交互单调性强化**：采集/质量/运输只能经 (a) 支持内信念更准、(b) 更保守动作（拒绝/加宽带/须同意/降档）、(c) 显式同意的包络扩展 影响系统；自利样本被限权，不存在"靠采集给自己放行"的升险路径。
4. **飞轮可回滚与终止**：每次语料写入要么过回归测试并接管，要么隔离/回滚；阴影区登记单调不减（禁止被模型"洗白"）；PCE++ 每检查点探针 ≤k_p+k_c+k_col，终止于 {承诺, 绕行, L2 协商, 安全停}。
5. **部署界**：

```
P_safe ≥ 1 − Σ_{cp: r∈𝒮_e} (δ_f + ε_meta^{𝒮}(k) + L·ε_e + δ_probe + δ_q)
             − P(支持外误判为支持内)            [δ_pos]
             − P(未同意的包络扩展)
             − P(𝓜 陈旧未检出) − P(护盾回退失败) − P(τ_int∧τ_mm 超时∧安全停失效)
```

关键：**支持内去偏、支持外认怂**——CCCS 的诚实之处不是把界做得更小，而是明确它对阴影世界**不给界**；**采集价值与决策价值分账**，防止飞轮用当下安全换数据；**采集-判定分离**切断自我交易；**只传认证充分统计量**避免 A 的偏差变成 B 的先验。

## 6. 本轮最大风险

**一句话**：本轮把"是否值得采信"从"数据像不像"推进到"数据是怎么被选出来的"，但正性违背是**不可识别**的——安全策略越可靠，最关键区域的采集倾向越接近零，倾向校正无法凭空造出从未采过的证据；于是最大风险不是"去偏不够"，而是把"阴影世界的不可知"包装成"已去偏的自信"，或以数据飞轮之名向危险区域施压采集；必须以阴影区永久降级、包络外强制知情同意、采集-判定分离三道护栏，宁可承认"这片世界我没有资格谈"，也不让可识别性边界被效率叙事侵蚀。
