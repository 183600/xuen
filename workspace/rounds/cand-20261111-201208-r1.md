# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；新灵感循环第 1 轮；本轮灵感：「安全对齐」×「运动规划」）

> 第 54 轮把技能组合推进到动作空间剖面 α_S、技能组合图 G_S、云边映射 γ_ce 与动作-鲁棒性联合证书 J。本轮从一组新的张力出发：**安全对齐（约束/价值的合法性）** 与 **运动规划（约束的可满足性与轨迹见证）** 在以往工作中被割裂。核心矛盾：H24：对齐声明若没有一条运动见证，就是不可证伪的——约束集合可以被退化解“空满足”，也可以在未建模执行中被系统性违反；H25：人的安全意图随任务相位与分布而漂移，静态约束 + 滚动时域规划会产生 **对齐滞后**，即“按旧意图安全的计划在当下意图下已经不安全”。

## 0. 直觉与动机

**灵感 1（对齐是约束的合法性，规划是约束的可满足性）**
直觉：安全对齐回答“机器人应不应该做”，运动规划回答“机器人做不做得到”。第 54 轮已经能判定“技能拼不拼得起来”，但一个动作可行的技能完全可能 **价值不可接受**。把二者接起来的桥梁不是又一层约束，而是 **见证（witness）**：一条同时满足编译约束、鲁棒管道与应急回退的具体运动。没有见证的对齐主张一律降级为“未验证假设”。

**灵感 2（对齐即见证 → 把声明式对齐变成可反证证书）**
直觉：安全对齐的常见失败不是“约束写错”，而是“约束写了却无人能证明它被执行”。定义 **对齐见证** `W = (ξ, 𝒯, F)`：标称轨迹、鲁棒管道、应急回退树。对齐主张 `(Φ, W)` 只有在 GenSim/数字孪生中被对抗搜索仍找不到反例时才成立。这把对齐从“伦理声明”变成“可被证伪的工程对象”，并与第 53/54 轮的 Explain 与鲁棒谱 ρ 对接。

**灵感 3（意图→约束的编译必须带价值序与残差）**
直觉：人的意图不是一个布尔约束，而是 **分层价值序**（硬安全 ≻ 人体舒适 ≻ 效率 ≻ 平滑）。把意图编译为字典序约束组 `(G_1 ≻ ... ≻ G_k)`，并显式记录 **对齐残差** `ε_align`：编译结果与审计集上人类判断之间的规范化偏差。残差不是噪声，而是证书的一部分——它告诉部署方“这条规划最多偏离意图多少”。

**灵感 4（不可行是常态 → 最小对齐违约，而非随意松弛）**
直觉：真实场景里硬约束与任务目标经常冲突。传统做法是加权惩罚或人工放宽阈值，往往违反价值序（例如为了效率牺牲了舒适，甚至悄悄牺牲安全）。定义 **最小对齐违约 MAV**：在字典序下取违约向量的字典序最小解；硬约束不可同时满足时，进入显式紧急模式，先最小化最高价值组的违反严重度，再逐级向下。**优雅退化本身必须是对齐的**。

**灵感 5（相位对齐 → 安全约束是时变的，规划必须跟得上相变）**
直觉：接近、接触、操作、撤离各相位的安全约束不同，且切换瞬间最脆弱。用 **相位对齐自动机 PA** 给约束打相位标签，规划在 STL/自动机语义下求解；运行时监控器检测相位错配（例如还没确认接触就进入加载相）。这把第 54 轮的动作切换脆弱性与本轮的安全相位对齐统一起来。

**灵感 6（应急包络 → 标称计划必须自带“可控退路”）**
直觉：安全不能只靠“预测不会出事”，而要靠“出事时一定退得回安全集”。为标称计划配一个 **应急包络**：控制不变集 `C_inv` + 备用控制器 `κ_b` + 可达回退树 `F`。证书要同时证明“标称轨迹满足约束”和“任意时刻都能在停车距离内切入 `C_inv`”。这把 shielding / CBF 从运行时补丁提升为规划期一等产物。

**灵感 7（对齐漂移与主动探询 → 运动也能用来“问问题”）**
直觉：偏好与场景会漂移，静默执行会积累错位。让规划器在安全预算内执行 **信息性安全探针**（例如缓慢接近、征询式停顿、展示两个可行方案），主动降低对意图参数的不确定性；一旦漂移检测器报警，就通过 Explain 回传触发云端重编译。云负责慢的“意图→约束”编译，边负责快的“见证+shielding”，形成 **云编译 - 边见证 - 漂移回传 - 重编译** 的对齐闭环。

**灵感 8（金字塔再扩一层）**
直觉：在第 54 轮动作-协同层 `𝔸` 之上叠加 **安全对齐层 `𝕊`**：`𝕊_0` 硬安全约束，`𝕊_1` 相位约束与价值序，`𝕊_2` 见证与应急包络，`𝕊_3` 跨域对齐迁移。跨层证书需同时携带 `ρ`、`A_cert` 与 **对齐证书 `SAC`**，形成“鲁棒-动作-对齐”三证书体系。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（意图-约束编译）**
意图 `ι`（演示、语言、风险偏好、审计标注）经编译器 `Comp` 映射为
```
Comp(ι) = (Φ_hard, {G_1 ≻ G_2 ≻ ... ≻ G_k}, ε_align)
```
其中 `Φ_hard` 为不可违反的硬约束（碰撞、稳定、力/力矩极限），`G_i` 为第 i 级软约束组（`G_1` 最优先，通常是人体安全裕度），`≺` 为字典序价值序，`ε_align = D(Comp(ι), ι_audit)` 为在审计集上的对齐残差（规范化违反率或分布距离）。

**定义 122（对齐见证 / 运动见证）**
见证 `W = (ξ, 𝒯, F)`：
- `ξ : [0,T] → X×U` 为标称运动；
- `𝒯` 为鲁棒管道，满足 `∀t, dist(ξ(t), ∂X_safe) > r_𝒯(t)` 且覆盖有界扰动与模型误差；
- `F` 为应急回退树，其根挂在 `ξ` 的任意时刻，叶子落在控制不变集 `C_inv` 内。
称 `(Φ, W)` 为 **对齐见证**，当且仅当 `ξ` 满足 `Φ_hard`、在字典序下满足各 `G_i` 且 `ε_align ≤ Θ_align`。**未带见证的对齐主张记为 `unverified`。**

**定义 123（对齐残差与对齐距离）**
对齐残差
```
ε_align(ι, Comp) = (1/|𝒜|) Σ_{a∈𝒜} d_val(Comp(ι)(a), ι_audit(a))
```
`𝒜` 为审计场景集，`d_val` 为价值一致距离（约束违反指示 + 严重度 + 排序反转惩罚）。运行时对齐距离 `ε_align(t) = d_val(Comp_t(ι), ι_t)`，用于定义漂移。

**定义 124（最小对齐违约 MAV）**
设计划 `ξ` 的违约向量 `v(ξ) = (v_1,...,v_k)`，`v_i` 为 `G_i` 的规范化违反严重度（硬约束违反记 `v_0=∞`）。定义字典序支配：`ξ ≺_v ξ'` 当且仅当存在 j 使 `v_j(ξ) < v_j(ξ')` 且 `∀i<j, v_i(ξ)=v_i(ξ')`。**MAV 解** `ξ* = lexmin_{ξ∈Ξ_feasible} v(ξ)`；若 `Φ_hard` 不可满足，则进入紧急模式，在最小化最高价值组严重度后再逐级最小化，且必须输出可解释的违约证书。

**定义 125（相位对齐自动机）**
`PA = (Q, Σ, δ, q_0, F, {φ_q}, {≺_q})`：状态 `q` 为任务相位（approach/contact/manipulate/retreat），事件 `Σ` 为接触建立、力阈值、时间窗等，`φ_q` 为相位约束（STL 公式），`≺_q` 为相位价值序。规划必须使轨迹在 `PA` 语义下可接受；监控器输出相位错配事件 `mismatch(q_t, x_t)`。

**定义 126（应急包络）**
`E = (C_inv, κ_b, T_stop, r_b)`：`C_inv ⊆ X_safe` 为控制不变集，`κ_b : C_inv → U` 为备用控制器，满足 `∀x∈C_inv, f(x,κ_b(x)) ∈ C_inv` 且不进入硬危险集；`T_stop` 为最坏停车时间，`r_b` 为回退可达半径。证书要求 `∀t, Reach(ξ(t), T_stop) ⊆ C_inv`（在管道 𝒯 内）。

**定义 127（对齐漂移）**
漂移
```
d_t = W_1( p_t(θ_pref), p_0(θ_pref) ) + λ·1[Φ_t ⊄ Φ_0]
```
`p_t` 为部署时意图参数后验，`p_0` 为编译时后验，`W_1` 为 1-Wasserstein 距离，第二项捕捉约束集扩张/收缩。报警条件 `d_t > Θ_drift` 或后验熵 `H(p_t) > Θ_H`（不确定即视为漂移）。

**定义 128（安全对齐证书 SAC）**
```
SAC = (Φ_compiled, W, ε_align, E, d_t, evidence)
```
`evidence` 至少含 GenSim 对抗反例搜索日志、审计集、回退演练记录。部署判定：
```
deploy ⇔ witness_valid(W, Φ_compiled) ∧ ε_align ≤ Θ_align ∧ d_t ≤ Θ_drift ∧ fallback_reachable(E)
```
否则降级为 `unverified` 并触发重编译或保守策略。

## 2. 关键算法 伪代码

### IP-121 ACP（Alignment Constraint Compilation）

```python
def compile_alignment(intent, audit_set, value_order):
    hard = extract_hard_constraints(intent)          # collision, stability, force limits
    groups = rank_soft_constraints(intent, value_order)  # G1 > G2 > ... > Gk
    eps = audit_residual(hard, groups, audit_set)    # value-consistent distance
    slack = calibrate_slack(hard, groups, audit_set) # per-group admissible slack
    if eps > THETA_ALIGN:
        return ('unverified', 'intent_ambiguous', eps, request_audit(intent))
    return ('ok', CompiledSpec(hard, groups, eps, slack, value_order))
```

### IP-122 WMP（Witnessed Motion Planning）

```python
def witnessed_plan(spec, x0, task, PA, tube_model, fallback_lib):
    # 1) 相位感知的 STL 约束展开
    phi = stl_product(spec.groups, PA)
    # 2) 字典序轨迹优化：硬约束优先，软约束按价值序
    xi = lexicographic_opt(x0, task, phi, spec.value_order, spec.slack)
    if xi is None:
        return ('infeasible', 'hard')            # 交给 MAV
    # 3) 鲁棒管道：对抗扰动/模型误差
    tube = inflate(xi, tube_model, beta=0.99)
    if not tube_safe(tube, spec.hard):
        return ('infeasible', 'tube')
    # 4) 应急回退树：沿轨迹挂接 C_inv
    F = attach_fallbacks(xi, tube, fallback_lib, t_stop=tube_model.T_stop)
    if not all_reachable(F):
        return ('infeasible', 'fallback')
    W = Witness(xi, tube, F)
    return ('ok', W)
```

### IP-123 MAV（Minimal Aligned Violation）

```python
def minimal_aligned_violation(spec, x0, task, PA, epsilon=1e-3):
    # 硬约束先尽力满足；不可行则进入显式紧急模式
    for group_level in range(0, len(spec.groups) + 1):
        sub_spec = hard_plus_groups_up_to(spec, group_level)
        sol = solve_lexicographic(sub_spec, x0, task, PA)
        if sol.feasible:
            return ('ok', sol, ViolationCert(sol.violations, spec.value_order))
        # 不可行：最小化当前组严重度，再逐级放开下一组
        sol = minimize_severity(group_level, spec, x0, task, PA)
        if sol.severity <= epsilon:
            return ('degraded', sol, ViolationCert(sol.violations, spec.value_order))
    return ('emergency', emergency_stop(spec, x0), ViolationCert.emergency())
```

### IP-124 PAS（Phase-Aware Shield）

```python
def phase_aware_shield(xi, PA, E, sensor_stream):
    q = PA.q0
    for t, x in enumerate(execute(xi)):
        q = PA.step(q, sensor_stream[t])
        if PA.mismatch(q, x):
            return ('abort_to_fallback', E, Explain('phase_mismatch', q, x))
        if not within_tube(x, xi.tube, t):
            return ('abort_to_fallback', E, Explain('tube_exit', t, x))
        if not fallback_reachable_from(x, E):
            return ('abort_to_fallback', E, Explain('fallback_unreachable', t))
    return ('ok', q)
```

### IP-125 ADD（Alignment Drift Detection + Active Probing）

```python
def alignment_drift_loop(spec, probe_lib, budget):
    post = spec.prior
    spent = 0
    while executing:
        d_t = wasserstein(post, spec.p0) + lambda_ * constraint_drift(spec)
        if d_t > THETA_DRIFT or entropy(post) > THETA_H:
            probe = argmax_info_gain(probe_lib, post, subject_to=spec.hard,
                                     cost_budget=budget - spent)
            if probe is not None:
                obs = execute_safe_probe(probe)      # 信息性运动也是运动规划
                post = bayes_update(post, obs)
                spent += probe.cost
                continue
            return ('recompile', request_cloud_recompile(post))
    return ('stable', post)
```

### IP-126 SAC（Safety Alignment Certificate）

```python
def safety_alignment_certificate(spec, W, E, drift, sim_model, adversarial_iters=10_000):
    if not witness_valid(W, spec):
        return ('reject', 'no_witness')
    if spec.eps_align > THETA_ALIGN:
        return ('reject', 'alignment_residual', spec.eps_align)
    if drift.d_t > THETA_DRIFT:
        return ('reject', 'drift', drift.d_t)
    if not fallback_reachable(E, W):
        return ('reject', 'fallback_unreachable')
    cex = adversarial_search(sim_model, W, spec, iters=adversarial_iters)
    if cex is not None:
        return ('reject', 'counterexample', cex, Explain(cex))
    return ('ok', SAC(spec, W, spec.eps_align, E, drift.d_t,
                      evidence=(sim_model.log, cex is None)))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| ACP | O(|𝒜|·|Φ|) | O(|Φ|) | 审计覆盖、价值序一致 |
| WMP | O(T·(n_x+n_u)³) 局部 + 采样项 | O(T·n_x) | 管道 sound、STL 鲁棒度 > β |
| MAV | O(k·T·(n_x+n_u)³) | O(k·T·n_x) | 字典序支配正确、紧急证书可解释 |
| PAS | O(T·|Q|) | O(|Q|+|E|) | C_inv 真正不变、相位监控无漏检 |
| ADD | O(T·|probe|·H) | O(|post|) | 漂移检测假阴 ≤ β_d、探针安全 |
| SAC | O(adversarial_iters·T) | O(T) | 反例搜索充分、证据可审计 |

**正确性定理（Witnessed Safety-Alignment Soundness）**
假设第 54 轮 (A26)–(A28) 成立；新增：
**(A29)** 编译 `Comp` 在审计集上的价值偏差 ≤ `ε_c`；
**(A30)** 管道 `𝒯` 以置信度 `1-β_𝒯` 覆盖真实扰动与模型误差；
**(A31)** `C_inv` 对 `κ_b` 控制不变，且 `∀t, Reach(ξ(t),T_stop) ⊆ C_inv`；
**(A32)** 漂移检测假阴率 ≤ `β_d`，且探针在 `Φ_hard` 内。
则对携带 `SAC` 的部署：
```
P(违反人类意图 ∧ 实际执行 ξ)
  ≤ ε_c + β_d + β_𝒯 + P(回退不可达) + P(反例搜索漏检)
```
关键：**对齐必须是“有见证的”**，**管道必须覆盖真实误差**，**回退必须先于危险可达**，**漂移必须被检测而非假设不存在**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 意图编译语义偏差（写错价值） | 高 | 审计集 + 人审 + 多编译器交叉验证 |
| 见证只在仿真成立（sim-to-real 缺口） | 高 | 对抗搜索 + 实机回退演练 + 保守管道 |
| 应急包络过于乐观 | 高 | 收缩 `C_inv` + 在线可达性复核 + 停车距离留裕度 |
| 漂移检测假阴 / 探针本身不安全 | 高 | 探针硬约束门禁 + 多信号漂移融合 + 不确定即保守 |
| MAV 字典序与真实价值序不符 | 中 | 价值序可配置 + 违约证书人工复核 |
| 计算开销使规划不可实时 | 中 | 云编译/边见证分层 + 见证缓存 + 热启动 |

## 6. 本轮最大风险

**一句话**：把安全对齐变成“运动见证 + 应急包络 + 漂移闭环”能显著提升可证伪性，但整条链路的 soundness **同时依赖意图→约束编译的语义正确、鲁棒管道对真实误差的覆盖、以及控制不变集在真实扰动下的不变性**；一旦编译写错了价值、或管道/不变集过于乐观，证书就会以极高的可信度证明“机器人正在对齐地违反人类真正的意图”，这比没有证书更危险——因此必须以 **人审编译 + 对抗反证 + 保守不变集 + 不确定即降级** 作为四重护栏，宁可把对齐判为 `unverified`，也绝不让一个漂亮的见证掩盖错误的价值。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-SafeWitness（ACP×WMP×MAV×PAS×ADD×SAC）

> 承接第 54 轮产物 v31。本轮在动作-鲁棒性双证书体系之上，引入 **安全对齐（Safety Alignment）** 与 **运动规划（Motion Planning）** 的耦合，核心是把对齐从“声明”升级为“可反证的见证”：
> - **ACP（Alignment Constraint Compilation）**：意图 → 分层价值序约束 + 对齐残差；
> - **WMP（Witnessed Motion Planning）**：标称轨迹 + 鲁棒管道 + 应急回退树的对齐见证；
> - **MAV（Minimal Aligned Violation）**：不可行时的价值一致优雅退化；
> - **PAS（Phase-Aware Shield）**：相位对齐自动机 + 应急包络的运行时护栏；
> - **ADD（Alignment Drift Detection）**：对齐漂移检测 + 信息性安全探针；
> - **SAC（Safety Alignment Certificate）**：可部署的“鲁棒-动作-对齐”三证书。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-118/120 以纳入对齐维度 `v` 与对齐证书 `SAC`。

## 2. 关键算法 伪代码

### IP-121 ACP

```python
def compile_alignment(intent, audit_set, value_order):
    hard   = extract_hard_constraints(intent)           # collision/stability/force
    groups = rank_soft_constraints(intent, value_order) # G1 > G2 > ... > Gk
    eps    = audit_residual(hard, groups, audit_set)    # value-consistent distance
    slack  = calibrate_slack(hard, groups, audit_set)
    if eps > THETA_ALIGN:
        return ('unverified', 'intent_ambiguous', eps, request_audit(intent))
    return ('ok', CompiledSpec(hard, groups, eps, slack, value_order))
```

### IP-122 WMP

```python
def witnessed_plan(spec, x0, task, PA, tube_model, fallback_lib):
    phi = stl_product(spec.groups, PA)                  # 相位感知 STL 展开
    xi  = lexicographic_opt(x0, task, phi,
                            spec.value_order, spec.slack)
    if xi is None:
        return ('infeasible', 'hard')                   # 转 MAV
    tube = inflate(xi, tube_model, beta=0.99)           # 对抗扰动/模型误差
    if not tube_safe(tube, spec.hard):
        return ('infeasible', 'tube')
    F = attach_fallbacks(xi, tube, fallback_lib,
                         t_stop=tube_model.T_stop)
    if not all_reachable(F):
        return ('infeasible', 'fallback')
    return ('ok', Witness(xi, tube, F))
```

### IP-123 MAV

```python
def minimal_aligned_violation(spec, x0, task, PA, epsilon=1e-3):
    for level in range(0, len(spec.groups) + 1):
        sol = solve_lexicographic(hard_plus_groups(spec, level),
                                  x0, task, PA)
        if sol.feasible:
            return ('ok', sol, ViolationCert(sol.violations, spec.value_order))
        sol = minimize_severity(level, spec, x0, task, PA)
        if sol.severity <= epsilon:
            return ('degraded', sol,
                    ViolationCert(sol.violations, spec.value_order))
    return ('emergency', emergency_stop(spec, x0),
            ViolationCert.emergency())
```

### IP-124 PAS

```python
def phase_aware_shield(xi, PA, E, sensor_stream):
    q = PA.q0
    for t, x in enumerate(execute(xi)):
        q = PA.step(q, sensor_stream[t])
        if PA.mismatch(q, x):
            return ('fallback', E, Explain('phase_mismatch', q, x))
        if not within_tube(x, xi.tube, t):
            return ('fallback', E, Explain('tube_exit', t, x))
        if not fallback_reachable_from(x, E):
            return ('fallback', E, Explain('fallback_unreachable', t))
    return ('ok', q)
```

### IP-125 ADD

```python
def alignment_drift_loop(spec, probe_lib, budget):
    post, spent = spec.prior, 0
    while executing:
        d_t = wasserstein(post, spec.p0) + lambda_ * constraint_drift(spec)
        if d_t > THETA_DRIFT or entropy(post) > THETA_H:
            probe = argmax_info_gain(probe_lib, post,
                                     subject_to=spec.hard,
                                     cost_budget=budget - spent)
            if probe is not None:
                obs = execute_safe_probe(probe)
                post, spent = bayes_update(post, obs), spent + probe.cost
                continue
            return ('recompile', request_cloud_recompile(post))
    return ('stable', post)
```

### IP-126 SAC

```python
def safety_alignment_certificate(spec, W, E, drift, sim_model,
                                 adversarial_iters=10_000):
    if not witness_valid(W, spec):
        return ('reject', 'no_witness')
    if spec.eps_align > THETA_ALIGN:
        return ('reject', 'alignment_residual', spec.eps_align)
    if drift.d_t > THETA_DRIFT:
        return ('reject', 'drift', drift.d_t)
    if not fallback_reachable(E, W):
        return ('reject', 'fallback_unreachable')
    cex = adversarial_search(sim_model, W, spec, iters=adversarial_iters)
    if cex is not None:
        return ('reject', 'counterexample', cex, Explain(cex))
    return ('ok', SAC(spec, W, spec.eps_align, E, drift.d_t,
                      evidence=(sim_model.log, cex is None)))
```

### IP-118+ / IP-120+ 联合证书扩展

```python
def joint_certificate_v2(skill_seq, gamma_ce, delta_a_budget,
                         rho_min, alignment_spec, drift):
    A_core = reduce(intersection, [s.alpha for s in skill_seq])
    delta_a = max_alignment_error(gamma_ce, A_core)
    if delta_a > delta_a_budget:
        return ('reject', 'action_mismatch', delta_a)
    rho_comp = compose_robustness_chain([s.rho for s in skill_seq], K)
    if min(rho_comp.values()) < rho_min:
        return ('reject', 'robustness_fail', rho_comp)
    sac = safety_alignment_certificate(alignment_spec, W, E, drift, sim_model)
    if sac[0] != 'ok':
        return ('reject', 'alignment_fail', sac)
    return ('ok', JointCertV2(rho_comp, A_cert=(A_core, buffer_zone(A_core, delta_a)),
                              gamma_ce, delta_a, sac, alignment_dim='v'))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| ACP | O(|𝒜|·|Φ|) | O(|Φ|) | 审计覆盖、价值序一致、残差可报告 |
| WMP | O(T·(n_x+n_u)³ + sampl) | O(T·n_x) | 管道 sound、STL 鲁棒度 > β |
| MAV | O(k·T·(n_x+n_u)³) | O(k·T·n_x) | 字典序支配正确、紧急证书可解释 |
| PAS | O(T·|Q|) | O(|Q|+|E|) | `C_inv` 控制不变、相位监控无漏检 |
| ADD | O(T·|probe|·H) | O(|post|) | 漂移假阴 ≤ β_d、探针受硬约束门禁 |
| SAC | O(adversarial_iters·T) | O(T) | 反例搜索充分、证据可审计 |

**正确性定理（Witnessed Safety-Alignment Soundness）**
假设第 54 轮 (A26)–(A28) 成立；新增 **(A29)** 编译价值偏差 ≤ `ε_c`；**(A30)** 管道以 `1-β_𝒯` 覆盖真实扰动/模型误差；**(A31)** `C_inv` 对 `κ_b` 控制不变且任意时刻回退可达；**(A32)** 漂移检测假阴 ≤ `β_d` 且探针在 `Φ_hard` 内。则：
```
P(违反人类意图 ∧ 实际执行 ξ)
  ≤ ε_c + β_d + β_𝒯 + P(回退不可达) + P(反例漏检)
```
关键：**对齐必须带见证**、**管道必须覆盖真实误差**、**回退先于危险可达**、**漂移必须被检测而非假设不存在**。

## 5. 本轮最大风险

**一句话**：把安全对齐变成“运动见证 + 应急包络 + 漂移闭环”能显著提升可证伪性，但整条链路的 soundness **同时依赖意图→约束编译的语义正确、鲁棒管道对真实误差的覆盖、以及控制不变集在真实扰动下的不变性**；一旦编译写错了价值、或管道/不变集过于乐观，证书就会以极高的可信度证明“机器人正在对齐地违反人类真正的意图”，这比没有证书更危险——因此必须以 **人审编译 + 对抗反证 + 保守不变集 + 不确定即降级** 作为四重护栏，宁可把对齐判为 `unverified`，也绝不让一个漂亮的见证掩盖错误的价值。
