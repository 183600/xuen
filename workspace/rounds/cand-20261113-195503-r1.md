# 第 69 轮（承接第 68 轮「CALM-RAS」IP-243~252；本轮灵感：「步骤分」×「情感语音」）

> R68 把「标定」升为一等公民，回答「我的测量还准吗」；但其自陈风险指出一个结构性悖论：**标定能力越强，落在标定带宽内的缓变故障越隐形**。这是「先标定后归因」的原罪，靠再加一层标定无法解决——因为问题不在估计精度，而在**观测的独立性与时间尺度**：当所有证据都来自同一条会被低通吸收的链路时，慢故障与慢漂移在原理上不可分。
>
> 本轮两个灵感词给出两把不同的钥匙：
> - 「步骤分」→ 把风险从 episode 级标量拆成 **step 级分数与信用**；关键不是分数大小，而是**序数（rank）**——共模增益漂移保序，上下文局部化的故障乱序。序数统计在标定带宽内仍然可辨。
> - 「情感语音」→ 人类对机器人动作的语音韵律反应是**逐步、零标签、半非自愿的过程奖励**；它走独立声学物理链路，时间分辨率（音节 4–8 Hz）远高于标定带宽，是面部情绪与低频漂移之外的高频见证。
>
> 核心命题：**PROSE-RAS（Prosody-Referenced Ordinal-Step Engine）——用情感语音生产步骤分，用步骤分的序数结构做慢故障检测，用逐步信用做风险归因与最小干预。**
>
> 一句话定位：R68 问「测量还准吗」，R69 问「**是哪一步、哪条链路、在什么时间尺度上不准**」——把不可观测的慢故障，转成可观测的序数异常与声学见证。

## 0. 直觉与动机

**灵感 1（步骤分 → 风险的时间分解与序数不变性）**
直觉：R68 的 λ 是整段 episode 的一个标量，既无法定位「哪一步开始变坏」，也无法区分全局漂移与局部故障。真实故障几乎总是**上下文局部**的：某个姿态、某个接触模式、某段光照下才触发。把它拆成 step 分数 s_t 后，全局增益漂移 g_t 只把所有分数整体缩放，**不改变步与步之间的排序**；而局部故障会改变受影响步骤的相对排序。于是「慢」不再是不可见的理由——只要故障在 step 维度上不是共模的，rank 就会泄漏它。
第二个直觉：**步骤分是「相对量」而非「绝对量」**。绝对残差会被 EKF 当漂移吸收；但「这一步比那一步更危险」是序数陈述，低通滤波器没有对应的吸收机制。序数统计是我们为慢故障留下的后门。

**灵感 2（情感语音 → 高频、独立、半非自愿的见证）**
直觉：面部表情可被主动管理（假笑、面具、美颜），语音韵律的**微特征**却难以逐音节伪装：基频微扰动、jitter/shimmer、气声、呼吸、停顿微结构、F0 抖动在 4–8 Hz 的调制，更多由自主神经系统驱动。更重要的是，它走的是**独立物理链路**（麦克风/声学）而非视觉/力链路，在频域上远离 ω_cal≈0.1 Hz。所以「语音 vs 面部」的分歧是 COF 无法解释的：它不是标定残差，只能是故障或欺骗。这正好补上 R68 里「标定越强、慢故障越隐形」的缺口——至少对情绪/视觉链路成立。

**灵感 3（两词合流 → 语音即过程奖励）**
直觉：人类在机器人做出动作后 200–500 ms 内就会用韵律作出反应（惊讶的升调、迟疑的拖音、紧张的急促、满意的降调）。这是一条**天然的、逐步的、零人工标签的过程奖励流**：s_t 不必等 episode 结束才由结果反推，而可以从「动作 t 之后的语音韵律变化」直接读出。这把「步骤分」从训练技巧变成**在线传感信号**，也把「情感语音」从情绪分类标签变成**时序信用源**。
因此：**情感语音 → 步骤分 → 序数异常 → 慢故障定位 → 逐步最小干预**，形成一条从声学到安全的完整链路。

**灵感 4（合流后的六组件与对旧风险的对症）**
PROSE-RAS = CALM-RAS ⊕ (PSR, SPM, ORD, PVA, SCA, SAI)：
1. **PSR 韵律步解析器**：音节/呼吸组切分 + 动作步对齐，输出 100 Hz 韵律状态；
2. **SPM 步骤过程监视器**：以韵律反应与结果回报为弱监督，输出 step 分数 s_t 与优势 A_t；
3. **ORD 序数残差检测器**：在滑动窗口内用 rank 统计分离「保序漂移」与「乱序故障」；
4. **PVA 韵律-视觉锚**：音节时间尺度上的跨模态情绪见证，标定不可吸收；
5. **SCA 步骤信用归因**：把 A_t 按模态做 Shapley/积分梯度分解，定位「哪条链路、哪一步」；
6. **SAI 步骤感知干预**：λ_t 只在必要步骤抬升，且单调不低于 λ_floor，兼顾安全与不过度保守。
对症：R68 慢故障 → ORD + PVA；R66 假笑/欺骗 → PVA + 韵律非自愿微特征；R67 黑箱前瞻 → SPM 提供稠密 step 级审计；R68 标定不确定 → 继承 CAR/λ_floor，并把 prosody 的独立性作为能否采信的前置条件。

## 1. 形式化定义（增量：定义 293–306）

**定义 293（PROSE-RAS 总览）** PROSE-RAS = CALM-RAS ⊕ (PSR, SPM, ORD, PVA, SCA, SAI)。三条新不变式：
(i) **步级可归因**：任何风险干预必须携带步索引 t 与模态出处 m；禁止无步归属的整段收紧（紧急降级除外）；
(ii) **序数优先**：慢故障判别使用 rank/序数统计而非幅值，以对共模增益漂移不变；
(iii) **见证独立**：语音见证只有在与视觉/力链路物理独立（κ_w ≤ κ_max）时才可采信；独立性被破坏即降权回退 CALM-RAS。

**定义 294（步格与韵律对齐）** 控制步 t=1..T（Δ_ctl≈50–100 ms）；韵律帧 f（100 Hz）经 VAD 与能量包络互相关聚成韵律单元 u_k（音节/呼吸组）。对齐映射 α: f ↦ t，带对齐不确定度 σ_α。步骤分在控制步上定义，见证残差在韵律帧上定义——两套时间轴通过 α 连接。

**定义 295（韵律状态与情绪后验）** p_f ∈ ℝ^{24} = (log-F0 均值/斜率/范围、RMS 能量、过零率、jitter、shimmer、HNR、共振峰离散度、谱倾斜、停顿比、气声度、4–8 Hz F0 微颤)。说话人归一化用 x-vector 投影 p̃_f = p_f − W·x_speaker。π^v_f ∈ Δ^4 为韵律情绪后验（E0–E3）。

**定义 296（步骤过程奖励与优势）** s_t = R_φ(z_t, p̄_{α(t)}, a_t) ∈ [0,1]；价值 V_ψ(z_t)；步级优势 A_t = s_t − V_ψ(z_t)。弱监督来自三处：结果回报的蒙特卡洛回填 G_t = Σ γ^k r_{t+k}、韵律反应的即时变化 Δp_t、以及步间偏好对 (t≻t')。episode 风险 λ = clip(λ0 − η Σ_t w_t A_t, λ_min, 1)。

**定义 297（序数残差）** 在窗口 W（≈2 s）内，r_t = rank_W(s_t)（并列取平均）。给定健康基线 s*_t（由校准后反事实/历史健康段给出），序数残差 o_t = r_t − r*_t，窗口统计 O_W = (1/|W|) Σ |o_t| 或 1 − Kendall τ(r, r*)。**关键性质**：若 s'_t = g_t s_t 且 g 在 W 内近似常数（共模慢增益），则 r'_t = r_t，O_W 不变；若故障只影响上下文子集 S，则 S 中步的相对次序系统偏移，O_W > 0。序数检验（Mann–Whitney/Kendall）的检出功效与 ω_f 无关。

**定义 298（韵律-视觉锚 PVA）** 在韵律帧上 r_pva(f) = JS(π^v_f ‖ π^face_{α(f)}) + λ_e·|log(E_f / E^ref_f)|。因韵律调制主频 ω_p ≥ 4 Hz ≫ ω_cal = 0.1 Hz，COF 的低通抑制 G = ω_cal/ω_p ≤ 2.5%，故 r_pva 的 97.5% 以上不能被标定吸收。于是判据：r_pva > τ_pva ⇒ cause ∈ {H_sensor^trans, deception, H_emotion^genuine-mismatch}，**禁止归入 H_cal**。

**定义 299（声学泄漏与欺骗证据）** 自愿通道 v_t = (面部 AU 强度, 文本情感)；非自愿通道 u_t = (jitter, shimmer, F0 微颤, 气声度, 停顿微结构)。欺骗证据 D_t = d(v_t, u_t) − C_t，其中 C_t 为音节率上的自愿-非自愿一致性（相关）。真笑/真情绪通常 v 与 u 同步；装出的正情绪常 u 不跟随。D_t 与 R66 的 r_emo 并联：一个查跨模态环，一个查同一模态内的自愿/非自愿层。

**定义 300（步骤信用归因 SCA）** 对模态组 m ∈ {face, prosody, force, geo, wm}，用积分梯度/Shapley 把 s_t 分解为 A_t^{(m)}，得到信用矩阵 A ∈ ℝ^{T×M}。归因偏置 B_m = mean_{t: a_{m,t}>ε} sign(A_t^{(m)} − A_t^{ref,(m)})。若 B_m 在 m 活跃的步上持续同号、而其他模态稳定 ⇒ 报 H_sensor_m（局部故障）；若所有 m 同比缩放 ⇒ 报全局漂移。**这是把「慢故障 vs 漂移」从幅值域搬到信用域。**

**定义 301（步骤感知干预 SAI）** λ_t = max(λ_floor(U), λ0 + γ(1−s_t) + γ_o·|o_t|)，且 λ_t 单调、永不低于 λ_floor。实际下发用作用窗口上的保守算子 λ_eff = max_{τ∈H(t)} λ_τ（H(t) 为影响当前动作的前缀/前瞻步集合）。语义：步骤分只用于**额外收紧**，不许把基线安全裕度「松开」；效率来自不再把最坏步的保守度外推到所有步，而非降低任何一步的下界。

**定义 302（步级证书 J_PROSE）** J_PROSE = (J_CALM, step_score_hash, ord_stat O_W, pva_residual_vec, credit_matrix_hash, alignment_uncertainty σ_α, witness_independence κ_w, prose_ver)。Valid ⇔ Valid(J_CALM) ∧ witness_independence κ_w ≤ κ_max ∧ 对齐不确定度 σ_α < τ_α。

**定义 303（步骤分自监督）** L_step = λ_mc·|s_t − G_t|² + λ_pr·max(0, m − s_t + s_{t'})（步间偏好）+ λ_ps·|s_t − f_ps(Δp_{α(t)})|²（韵律反应回归）+ λ_ord·[1 − Kendallτ(rank(s), rank(s*))] + λ_vic·L_VICReg。全部零人工标签；韵律反应提供稠密项，结果回报提供稀疏锚点。

**定义 304（干扰集）** ℰ_PROSE = ℰ_CALM × ℰ_ord × ℰ_prosody × ℰ_step：ℰ_ord = {保序共模故障、秩伪装攻击、窗口选择偏差}；ℰ_prosody = {噪声/Lombard 效应、说话人/语种混淆、TTS/回放克隆}；ℰ_step = {对齐错位、步分 Goodhart、信用误归因}。

**定义 305（见证独立性判据）** 定义语音-视觉共模耦合 κ_w = I(π^v; π^face | z_shared) 的估计，或声学/视觉噪声的偏相关。采信语音见证需 κ_w ≤ κ_max；若共享热源/电源/时钟或同一神经网络骨干导致共模，κ_w 上升，语音证据权重 w_v → 0，回退 CALM-RAS 的保守纪律。**没有独立性，见证只是回声。**

**定义 306（管线）** 离线：韵律编码器预训练（自监督掩码预测）→ SPM 三源弱监督训练 → ORD 健康基线标定。在线：PSR/PVA 每韵律帧 → SPM 每控制步 → ORD 每 2 s 窗口 → SCA 归因 → SAI 下发；全部进 J_PROSE 审计链。

# IP-253 PSR：韵律步解析器（100 Hz，独立声学链路）
class ProsodicStepResolver:
    def step(self, audio_frame, speaker_emb):
        p = self.prosody(audio_frame)              # 24 维：F0/jitter/shimmer/HNR/...
        p = p - self.W @ speaker_emb               # 说话人归一化
        u = self.vad_units(audio_frame)            # 音节/呼吸组
        return p, u, self.align(u)                 # 对齐到控制步 α

# IP-254 SPM：步骤过程监视器（语音即过程奖励）
class StepProcessMonitor:
    def score(self, z_t, p_bar, a_t):
        s = self.R(z_t, p_bar, a_t)                # step 分数
        v = self.V(z_t)
        return s, s - v                            # (s_t, A_t)

    def train_step(self, batch):                   # 三源弱监督，零人工标签
        L = self.mc_return(batch) + self.pref_pair(batch) \
          + self.prosody_response(batch) + self.ordinal_consistency(batch)
        return L

# IP-255 ORD：序数残差检测（对共模增益漂移不变）
class OrdinalResidualDetector:
    def update(self, s_window, s_ref_window):
        r  = rankdata(s_window)                    # 序数变换
        r0 = rankdata(s_ref_window)
        o  = r - r0
        O  = np.mean(np.abs(o))                    # 或 1 - kendalltau(r, r0)
        return O, self.rank_test(o)                # p 值

# IP-256 PVA：韵律-视觉锚（标定不可吸收的高频见证）
def prosody_vision_anchor(pi_v, pi_face, sigma_alpha, kappa_w):
    if kappa_w > KAPPA_MAX: return 0.0, 'witness_untrusted'
    r = js_div(pi_v, pi_face) + L_E * abs(np.log(E_v / E_ref))
    return r, ('exempt_from_cal' if r > TAU_PVA else 'consistent')

# IP-257 SCA：步骤信用归因（定位哪条链路、哪一步）
def step_credit(model, z, p, a, m_groups):
    A = {}
    for m, (z_m, p_m) in m_groups.items():
        A[m] = integrated_gradients(lambda x: model.score(x, p, a), (z_m, p_m))
    B = {m: np.mean(np.sign(A[m] - A_ref[m])) for m in A}
    return A, B                                    # B_m 持续同号 => H_sensor_m

# IP-259 SAI + IP-262 主闭环
def PROSE_RAS_round(M, obs):
    V,T,P,L,P_cloud,W,tactile,img,depth,flow,audio = obs
    x_prime = M.lsf.fuse(M.usr.fuse(V,T,P,L))
    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)

    r  = residuals(x_prime, o, M.wm_residual_cache)
    c, U, thr = M.cof.step(o['cal'], r, sigma_stat(M))       # 继承 CALM-RAS

    p, u, alpha = M.psr.step(audio, M.spk_emb)               # 1) 韵律解析
    s_t, A_t   = M.spm.score(z, p_bar(alpha), M.a_prev)      # 2) 步骤分
    O, p_ord   = M.ord.update(M.score_win(s_t), M.ref_win)   # 3) 序数残差
    r_pva, tag = prosody_vision_anchor(o['pi'], M.face_pi,
                                       alpha.sigma, M.kappa_w)  # 4) 高频见证
    A_cm, B    = M.sca.credit(z, p, M.a_prev)                # 5) 信用归因

    joint_post = M.cfa(rho, o['pi'], c, U)                   # 继承：先标定后归因
    if p_ord < P_ORD_MAX and tag == 'exempt_from_cal':
        joint_post = penalize_h_cal(joint_post, r_pva)       # 禁止标定吸收见证残差

    lam_t = step_lambda(s_t, O, U, thr['lam_floor'])
    k = M.c_ras_wm.certified_prefix(A, joint_post, m_ras, M.alpha_chunk, wm_preds)
    lam_eff = max_over_horizon(lam_t)                        # 只收紧，不放松
    tau = M.pi_sigma.prefix_dispatch(A[:k]) * lam_eff
    M.jprose.log(J_CALM=..., O=O, r_pva=r_pva, B=B, kappa=M.kappa_w)
    return k, lam_eff, joint_post, (s_t, A_cm), (O, r_pva)

## 3. 推导

**引理 16（序数对共模增益漂移不变）** 设 s'_t = g_t s_t，W 内 g_t ∈ [g_-, g_+]。若 g 在 W 内常数，则 rank 完全不变，O_W = 0；若缓慢变化 |g_t − g_s| ≤ δ，则仅当 |s_t − s_s| ≤ δ·max(s) 时次序可能翻转，翻转数 ≤ O(δ/Δ_min)。故 ORD 对带宽极低的共模漂移天然免检，而对上下文局部故障（改变 S 内相对次序）灵敏。系：**「慢」不再是检测失败的充分理由；共模性才是。**

**引理 17（韵律见证不可被标定吸收）** COF 速率限制使其等效低通带宽 ω_cal ≈ 0.1 Hz。韵律调制主频 ω_p ≥ 4 Hz，一阶跟踪抑制 G = ω_cal/ω_p ≤ 1/40。故 PVA 残差 r_pva 的 ≥ 97.5% 保留在标定后残差中。与引理 13（ω_f ≥ 3ω_cal ⇒ 残余 ≥ 2/3）相比，语音见证把可检测频段向下延伸了两个数量级——**只要故障在语音-视觉一致性上留下高频痕迹**。

**引理 18（步骤信用可辨识性）** 在线性可加模型 s_t = Σ_m φ_m(x_t) a_{m,t} + ε 下，若模态激活矩阵 [a_{m,t}] 在活跃步上满列秩（A95 激活多样性），则信用 A_t^{(m)} = φ_m(x_t) a_{m,t} 可由积分梯度无偏估计（Shapley 唯一性）。共模漂移对所有 m 同比例缩放，不改变 B_m 的符号模式；局部故障只改一个 m 的符号模式。

**定理 16（PROSE 端到端风险一致性，含 R68 残余风险收缩）** 在 A87–A95 下，输出 τ_cmd 满足：
1. P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + **α_ord + α_pva + α_step**；
2. 对带宽 ω_f < ω_cal 的故障：若其上下文非共模 ⇒ P(miss) ≤ exp(−|W|·D_ord)（引理 16），与 ω_f 无关；若其共模保序 ⇒ ORD 失明，但若它在语音-视觉链路留下 ≥4 Hz 痕迹 ⇒ P(miss) ≤ exp(−n_p·D_pva)（引理 17）；
3. 两者皆失明时，继承 CALM-RAS 的 λ_floor(U) 与 k_cal 收缩仍成立；因此 R68 的盲区从「所有 ω_f < ω_cal 故障」收缩为「共模、保序、且不触及语音见证的故障」；
4. λ_t 单调且 ≥ λ_floor ⇒ 步骤分解不引入新的过度放宽通道。

**定理 17（声学欺骗上界）** 若攻击者只能控制自愿通道（面部/文本）而无法控制非自愿微韵律，则欺骗检出率由 D_t = d(v,u) − C_t 给出；若攻击者用 TTS/回放克隆完全控制韵律，则 PVA 的 liveness 特征（呼吸、微颤、环境耦合）使其至少触发 'witness_untrusted'，系统回退 CALM-RAS 的保守纪律而非放宽。故声学攻击的收益 ≤ 0（不能换来安全裕度）。

## 6. 本轮最大风险

**一句话**：PROSE-RAS 的最大风险是**见证独立性的不可保证与序数盲区的叠加**——若声学/视觉/力链路共享热源、电源、时钟或同一个骨干网络（κ_w 上升），语音见证会退化为「回声」，而专门为忽略共模增益漂移设计的序数统计，又恰好对「共模且保序」的慢故障天然失明；两套机制在同一条共模慢故障上同时失效，R68「标定吸收慢故障」的原罪只是被缩小到这条残余盲区，并未被真正消除。

**次级风险与缓解**：
1. **韵律混淆**（疲劳、话题、他人说话）→ 说话人归一化 + 交互对齐 + 只用动作后 200–500 ms 的差分韵律；

4. **序数统计低功效**（步数少、并列多）→ 与幅值法并联，任一报警即收紧；
5. **声学隐私/伦理** → 韵律特征本地提取、不上传原始音频，只存证书哈希。

**定义 296（步骤过程奖励）** `s_t = R_φ(z_t, p̄_{α(t)}, a_t)`，`A_t = s_t − V_ψ(z_t)`；弱监督 = 蒙特卡洛回填 G_t + 韵律反应 Δp_t + 步间偏好。

## 4. 推导

**引理 16（序数对共模增益漂移不变）** `s'_t = g_t s_t`，W 内 g 常数 ⇒ rank 完全不变、O_W=0；g 缓慢变化且 `|g_t−g_s| ≤ δ` 时，仅当 `|s_t−s_s| ≤ δ·max(s)` 才可能翻转，翻转数 ≤ O(δ/Δ_min)。故「慢」不是检测失败的充分理由，**共模性才是**：上下文局部故障必乱序，共模漂移必保序。

**引理 17（韵律见证不可被标定吸收）** COF 等效低通 ω_cal ≈ 0.1 Hz；韵律调制 ω_p ≥ 4 Hz ⇒ 一阶跟踪抑制 G = ω_cal/ω_p ≤ 1/40，PVA 残差 ≥ 97.5% 保留。相比引理 13（ω_f ≥ 3ω_cal 才保留 2/3），语音见证把可检频段下移约两个数量级。

**引理 18（步骤信用可辨识性）** 线性可加模型 `s_t = Σ_m φ_m(x_t)a_{m,t} + ε`，A95 激活多样性（活跃步激活矩阵满列秩）下，积分梯度/Shapley 无偏恢复 `A_t^{(m)}`；共模漂移等比缩放所有 m（B_m 符号模式不变），局部故障只改一个 m 的符号模式。

**定理 16（端到端风险一致性 + R68 残余风险收缩）** 在 A87–A95 下：
1. `P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+α_ord+α_pva+α_step`；
2. `ω_f<ω_cal` 且上下文非共模 ⇒ `P(miss) ≤ exp(−|W|·D_ord)`，与 ω_f 无关；共模保序 ⇒ ORD 失明，但若在语音-视觉链路留下 ≥4 Hz 痕迹 ⇒ `P(miss) ≤ exp(−n_p·D_pva)`；
3. 两者皆失明时，继承 CALM-RAS 的 λ_floor(U) 与 k_cal 收缩仍成立 ⇒ R68 盲区从「所有 ω_f<ω_cal 故障」收缩为「共模、保序、且不触及语音见证的故障」；
4. `λ_t` 单调且 ≥ λ_floor ⇒ 步骤分解不引入新的放宽通道。

**定理 17（声学欺骗上界）** 攻击者仅控自愿通道 ⇒ 由 `D_t = d(v,u) − C_t` 检出；完全控韵律（TTS/回放）⇒ liveness（呼吸/微颤/环境耦合）至少触发 `witness_untrusted`，系统回退保守纪律而非放宽 ⇒ 声学攻击的安全收益 ≤ 0。

## 7. 本轮最大风险

**一句话**：PROSE-RAS 的最大风险是**见证独立性的不可保证与序数盲区的叠加**——若声学/视觉/力链路共享热源、电源、时钟或同一个骨干网络（κ_w 上升），语音见证退化为「回声」，而专为忽略共模增益漂移设计的序数统计又恰好对「共模且保序」的慢故障天然失明；两套机制在同一条共模慢故障上同时失效，R68「标定吸收慢故障」的原罪只是被缩小到这条残余盲区，并未被真正消除。

**次级风险与缓解**：韵律混淆（说话人归一化 + 动作后 200–500 ms 差分韵律）；步骤分 Goodhart（SAI 只收紧不放松 + E300 红队 + 步分不进策略奖励）；对齐错位（σ_α 进 J_PROSE，超限回退）；序数低功效（与幅值法并联，任一报警即收紧）；声学隐私（本地提取、只存证书哈希）。
