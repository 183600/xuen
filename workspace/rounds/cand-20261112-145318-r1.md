# 第 61 轮（承接第 60 轮「认知驱动场景执行」IP-153~160；灵感循环第 7 轮；本轮灵感：「同步定位与建图」×「云端协同」）

> 第 60 轮的 SGEC 把「执行层→证据层」升级为「认知驱动场景闭环」：SSM 用场景-阻抗先验提前收敛 K_safe、CIEC 把意图时序化为 ERTC 约束锁定、EPIR 用 seq_id+hash 防 ROS 丢包、SERC 统一闭环、PCE++++ 管四维认知预算。但**三个结构性缺口**仍在：
> 1. **场景无空间锚点**：SSM 只回答「当前是什么场景」，回答不了「这个场景在哪里、前方三步之后是什么场景」。同一标签 `table_smooth` 在厨房与实验室被混为一谈；执行层缺乏**空间记忆**，每次到同一位置都要重新试错，无法把历史 EV-exec 变成「地图上的先验」。
> 2. **云端协同是单向证据同步**：EPIR 只有「边端影子副本→云端校验」的单向链路，云端从未参与**建图/位姿优化/多机一致性**。边端把原始力/视觉流上传既费带宽又高延迟，真正的全局信息（回环、跨机约束）却无法回流到边端的 K_safe 决策。
> 3. **置信度是标量而非场**：第 60 轮的 SIC 以单个 `scene_conf` 概括一切，无法表达「桌子左半可信、右半未知」「回访同一位置应增强置信」。缺少空间化的置信传播，导致「地图已知」与「地图未知」在决策中被同等对待。

## 0. 直觉与动机

**灵感 1（同步定位与建图 → 执行语义 SLAM，ESLAM）**
直觉：机器人执行过的每个接触点，天然就是一个带位姿的「路标」。位姿图回答「我在哪」，阻抗关键帧回答「这里的接触性质是什么」。二者联合估计，就把执行从「无记忆试错」变成「空间记忆复用」：下次走到同一格点，直接取历史阻抗后验，而不是重新探测。关键洞见：**接触即观测（contact-as-observation）**——每一次 EV-exec 都是同时服务于定位与阻抗建图的空间观测。

**灵感 2（云端协同 → 云边因子图分工，CEFG）**
直觉：边端要实时，云端要全局，二者不该互传原始数据流，而应分工同一张因子图：边端维护「滑动窗口 + 里程计/接触因子」（低延迟），云端维护「回环因子 + 多机因子」（全局一致）。边端把被边缘化的老关键帧通过 Schur 补压成一个先验因子，只上传「窗口边界的边缘分布」而非原始力/视觉流，带宽从 O(数据量) 降为 O(边界维数)。关键洞见：**云边协同的通信单位应是「因子/边缘分布」，不是「数据/证据」**。

**灵感 3（回环 → 地图锚定证据对账，MAER）**
直觉：第 60 轮 EPIR 用 seq_id+hash 保「因果顺序」，但顺序正确不等于空间正确：两条 EV-exec 可以时序合法、却锚定在同一格点并给出互相矛盾的阻抗。回环检测纠正位姿图时，历史证据的坐标必须被重新投影。关键洞见：**证据链必须同时通过「时间一致性」与「空间一致性」双检，回环是触发对账的天然时机**。

**灵感 4（建图置信 → 空间置信场，SCF）**
直觉：置信度不是一个全局常数，而是定义在地图格点/关键帧上的场：一次观测在空间上按位姿协方差扩散置信；回环降低位姿协方差会顺带抬升沿途置信；未观测区域随时间衰减。关键洞见：**置信度是空间函数 γ(c)，SIC 必须升级为 SIC 场**。

**灵感 5（多机协同与预算 → 联邦阻抗图集 FIA、五预算 PCE+++++、地图感知决策 CESC++）**
直觉：多机各建局部阻抗图，云端融合为「阻抗图集」；但简单平均会被一台标定错误的机器人污染全局，必须用信息形式 + 信任权重 + 冲突隔离。同时建图、通信、位姿图都消耗资源，故 PCE++++ 扩展为五预算。最终由 CESC++ 做「沿轨迹的地图感知决策」：置信度足够处直接用地图先验，未知处主动探测。五者合流为 **CEM（Cloud-Edge Map-aware execution）**。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（执行语义 SLAM，ESLAM）** 执行地图 M_e = (G, X, K, Ω)。其中：
- **位姿图**：G = (V, E)，V 为关键帧，E = E_odo ∪ E_contact ∪ E_loop 分别为里程计边、接触边、回环边。
- **关键帧**：k = (x_k, z_k, π_k, γ_k, t_k)，x_k ∈ SE(3) 为位姿，z_k 为场景标签，π_k(K) = N(μ_k, Σ_k) 为该点的阻抗后验，γ_k ∈ [0,1] 为置信，t_k 为时间戳。
- **接触观测模型**：o_t = (Δp, f_n, f_t, z_contact, d_visual) 由力/触觉、相对位姿、视觉描述子融合，给出相对约束
  z_ij ⊖ h(x_i, x_j, K_i, K_j) ~ N(0, Ω_ij^{-1})。
- **MAP 目标**：X*, K* = argmin_{X,K} Σ_{(i,j)∈E} ‖e_ij‖²_{Ω_ij} + Σ_{(i,j)∈E_loop} ρ(‖e_ij‖²_{Ω_ij})，ρ 为鲁棒核（Huber/Cauchy）以抑制回环误匹配。
- **查询算子**：Query(x) = (z_k, π_k, γ_k)，k = argmin_{k∈V} dist_SE3(x, x_k)。

**定义 162（云边因子图分工，CEFG）** 将因子图分解为 G = G_edge ⊎ G_cloud ⊎ G_marg：
- **边端子图** G_edge：滑动窗口 W 个关键帧，含里程计边与接触边；要求单次优化时延 ≤ τ_edge（如 50 ms）。
- **云端子图** G_cloud：回环边、跨机边、全局位姿；异步求解，时延容忍 τ_cloud（如 2 s）。
- **边缘化压缩**：边端对滑出窗口的变量 a 做 Schur 补，得到边界 b 上的先验因子
  Λ_marg = Λ_bb − Λ_ba Λ_aa^{-1} Λ_ab，η_marg = η_b − Λ_ba Λ_aa^{-1} η_a；
  上传 (Λ_marg, η_marg) 与关键帧摘要，不上传原始传感流。
- **卸载决策**：对因子集合 f，VoO(f) = ΔH(X,K | 卸载 f) − λ_bw·bytes(f)/B_link − λ_lat·latency(f)；当 VoO(f) > 0 且 B_link 允许时卸载。

**定义 163（地图锚定证据对账，MAER）** 每条执行证据 e 附带空间锚 a(e) = (k, T_k)，T_k 为相对关键帧的变换。回环求得位姿修正 ΔX 后，重投影 a'(e) = ΔX ⊕ a(e)。对锚定到同一格点 c 的证据集合 E_c，要求：
- **时间一致**：t_i < t_j ⇒ seq_i < seq_j；
- **空间一致**：‖μ_K(c) − K(e_i)‖²_{Σ^{-1}} ≤ χ²_{1−α}。
若任一不满足，标记 SPATIO_TEMPORAL_CONFLICT，隔离该证据并要求重观测；对账通过后以地图后验覆盖阶跃的历史值，避免「旧坐标污染新地图」。

**定义 164（空间置信场，SCF）** 置信场 γ_t: X_free → [0,1]，离散到格点 c。一次位于 x、位姿协方差 Σ_x 的观测按高斯核注入：
γ_{t+1}(c) = γ_t(c) + (1 − γ_t(c))·κ·exp(−½ (c−x)^T Σ_x^{-1} (c−x))，κ ∈ (0,1]。
未观测衰减：γ_{t+1}(c) = λ·γ_t(c)，λ < 1。回环使 Σ_x 收缩后，按信息比提升沿途置信：γ' = 1 − (1−γ)^{Σ_old/Σ_new}，Σ_new ≼ Σ_old ⇒ γ' ≥ γ。
**SIC 场**：SIC(x) = (γ(x), K_certainty(x), feasibility(x))；SIC_valid(x) ⇔ γ(x) ≥ τ_γ ∧ K_certainty(x) ≥ τ_K ∧ feasibility(x) = true。

**定义 165（联邦阻抗图集，FIA）** 云端将各机器人局部地图 M_e^{(r)} 融合为图集 A。对格点 c 以信息形式合并：
Σ_A^{-1} = Σ_r w_r Σ_r^{-1}，μ_A = Σ_A (Σ_r w_r Σ_r^{-1} μ_r)；
信任权重 w_r 由标定分数、近期残差、漂移协方差决定，Σ_r w_r = 1。
**冲突检测**：若两机后验 Mahalanobis 距离 d² = (μ_r − μ_s)^T (Σ_r + Σ_s)^{-1} (μ_r − μ_s) > χ²_{1−α}，则判为冲突；冲突时不做平均，改为**隔离少数派 + 请求复核**，并输出图集证书 Cert_atlas（列明参与机、权重、冲突格点）。

**定义 166（五预算 PCE+++++）** B = (B_map, B_link, B_pose, B_cog, B_exec)：
- **B_map** = (关键帧容量, 地图更新频率, 内存上限)；
- **B_link** = (上行带宽, 下行带宽, 延迟上限, 丢包预算)；
- **B_pose** = (滑动窗口 W, 回环频率, 图节点预算)；
- **B_cog** = 第 60 轮四维认知预算；
- **B_exec** = 第 59 轮执行预算。
**降级链**：B_map 耗尽 ⇒ 冻结建图、用带膨胀协方差的旧地图；B_link 耗尽 ⇒ 纯边端闭环；B_pose 耗尽 ⇒ 降回环频率并强边缘化；B_cog 耗尽 ⇒ 回退第 60 轮；B_exec 耗尽 ⇒ 回退第 59 轮。
**VOI**：voi_map(π) = VOI_meta_pessimistic(π) − cost_map(π) − cost_link(π) − cost_exec(π)。

**定义 167（云卸载价值与主动阻抗建图，COV-AIM）** 
- **卸载**：仅当 VoO(f) > 0 时把因子/边缘分布卸载到云端（见定义 162）。
- **主动建图**：当计划轨迹经过区域的 γ(c) < τ_γ 时，选择探测动作
  a* = argmax_a { E[IG(a)] − λ_cost·cost(a) }，s.t. 执行可行性约束；
  其中 IG(a) 为观测与目标格点阻抗之间的互信息，兼顾定位信息增益与阻抗信息增益。探测本身仍受 ERTC 安全契约约束。

**定义 168（地图感知序列决策，CESC++）** 给定当前定位 x_t、预测时域 H、阻抗场 (μ(c), Σ(c), γ(c))，求解
K*(x_{t:t+H}) = argmin_{K(·)} Σ_{τ=t}^{t+H} [λ_traj·ω_traj(K, path_τ) − (1−λ_traj)·K_p]
s.t. ∀τ: SIC_valid(x_τ) ∧ 力/阻抗约束成立。
若某 τ 的 SIC 无效：若 B_map 允许则先触发 AIM 主动探测；否则用第 60 轮 CESC 的保守编译；仍为空则返回 DEGRADE_EXEC。

### IP-161 ESLAM（执行语义 SLAM）

```python
class ExecutionSemanticSLAM:
    def __init__(self, window=15):
        self.graph = PoseGraph()
        self.keyframes = {}
        self.window = window
        self.next_id = 0

    def add_keyframe(self, pose, scene_label, imp_posterior, conf):
        kf = Keyframe(self.next_id, pose, scene_label, imp_posterior, conf)
        self.keyframes[kf.id] = kf
        self.graph.add_vertex(kf.id, pose)
        self.next_id += 1
        return kf.id

    def add_contact_factor(self, i, j, z_ij, omega):
        self.graph.add_edge(i, j, z_ij, omega, kind='contact')

    def detect_loop(self, curr_id, descriptor_db, radius=2.0):
        cand = descriptor_db.query(self.keyframes[curr_id].descriptor, radius)
        for cid, score in cand:
            if score > self.tau_appearance:
                self.graph.add_edge(curr_id, cid, relative_pose(curr_id, cid),
                                    omega_loop, kind='loop')
        return [cid for cid, _ in cand if _ > self.tau_appearance]

    def optimize(self, iterations=10):
        for _ in range(iterations):
            H, b = self.graph.linearize()          # 高斯-牛顿 / iSAM2
            H += self.graph.prior_information()
            dx = solve_sparse(H, b)
            self.graph.retract(dx)
        self.reproject_keyframes()

    def reproject_keyframes(self):
        for kf in self.keyframes.values():
            kf.pose = self.graph.vertex(kf.id)
        return self.keyframes

    def query(self, pose):
        cid = min(self.keyframes, key=lambda i: dist_se3(pose, self.keyframes[i].pose))
        kf = self.keyframes[cid]
        return kf.scene_label, kf.imp_posterior, kf.conf
```

### IP-162 CEFG（云边因子图分工）

```python
class CloudEdgeFactorGraph:
    def __init__(self, edge_window=15, link_budget=None):
        self.edge = ExecutionSemanticSLAM(window=edge_window)
        self.cloud = PoseGraph()
        self.link = link_budget
        self.marginals = []

    def step(self, new_kf, contact_factors):
        self.edge.add_keyframe(*new_kf)
        for f in contact_factors:
            self.edge.add_contact_factor(*f)
        if len(self.edge.keyframes) > self.edge.window:
            marginal = self.edge.marginalize_oldest()   # Schur 补
            self.marginals.append(marginal)
            if self.link.allows(marginal.bytes):
                self.cloud.add_prior(marginal)
                self.link.consume(marginal.bytes)
        self.edge.optimize(iterations=3)

    def offload_value(self, factor_set):
        dH = self.expected_entropy_reduction(factor_set)
        return dH - self.link.bw_cost(factor_set) - self.link.latency_cost(factor_set)
```

### IP-164 SCF（空间置信场）

```python
class SpatialConfidenceField:
    def __init__(self, resolution=0.05, decay=0.995):
        self.field = defaultdict(float)
        self.res = resolution
        self.decay = decay

    def observe(self, pose, cov, kappa=0.5):
        for cell in self.cells_within(pose, 3 * cov):
            d2 = mahalanobis_sq(cell, pose, cov)
            gain = kappa * math.exp(-0.5 * d2)
            self.field[cell] += (1 - self.field[cell]) * gain

    def decay_unobserved(self):
        for cell in self.field:
            self.field[cell] *= self.decay

    def loop_closure_boost(self, cells, sigma_old, sigma_new):
        ratio = sigma_old / max(sigma_new, 1e-9)
        for cell in cells:
            g = self.field[cell]
            self.field[cell] = 1 - (1 - g) ** ratio

    def sic_valid(self, cell, tau_gamma=0.7):
        return self.field[cell] >= tau_gamma
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| ESLAM | O(iter·\|E\|) 稀疏 GN；滑动窗口 O(W³) | O(\|V\|+\|E\|) | ATE/RPE 有界；回环后阻抗后验收紧 |
| CEFG | 边端 O(W³)，云端 O(\|E_cloud\|) | O(W + 边界维数) | Schur 边缘化信息损失 ≤ ε_schur |
| MAER | O(\|E_c\| log \|E_c\|) 分桶对账 | O(\|E_c\|) | 时空双一致率 ≥ 99.9% |
| SCF | O(观测覆盖格点) | O(格点数) | γ 单调不降（同点重复观测） |
| FIA | O(格点 × 机器数) | O(图集) | 冲突检出率 ≥ 99%，无污染传播 |
| CESC++ | O(H·查询) | 复用 | 地图感知不劣于场景仅感知基线 |

**正确性定理（CEM，Cloud-Edge Map-consistent execution）**：
假设 A66–A72 成立：**(A66)** 接触观测噪声零均值、协方差有界；(A67) 回环误检率 ≤ ε_lc 且鲁棒核抑制外点；**(A68)** Schur 边缘化在 ε_schur 内保持边界信息；(**(A69)** 回环修正使相关格点后验协方差单调收缩；(**(A70)** FIA 信任权重和为 1，冲突格点被隔离而非平均；(**(A71)** 五预算单调消耗；(**(A72)** SCF 的注入核与衰减满足单调性。
则：
1. **定位-建图一致性**：回环闭合后位姿漂移有界，且同一格点的阻抗后验收紧，Query 返回的先验与真实阻抗的偏差 ≤ δ_map。
2. **云边一致性**：边端边缘分布与云端全局解在 ε_schur 内一致；B_link 耗尽时边端纯本地解的退化有界。
3. **证据时空一致**：MAER 通过时间+空间双检，冲突证据被隔离，污染不进入图集。
4. **置信场可靠性**：γ(c) 对重复观测单调不降、对未观测单调衰减，SIC 场阈值判定校准误差 ≤ ε_γ。

### IP-161 ESLAM（执行语义 SLAM）

```python
class ExecutionSemanticSLAM:
    def __init__(self, window=15):
        self.graph = PoseGraph()
        self.keyframes = {}
        self.window = window
        self.next_id = 0

    def add_keyframe(self, pose, scene_label, imp_posterior, conf):
        kf = Keyframe(self.next_id, pose, scene_label, imp_posterior, conf)
        self.keyframes[kf.id] = kf
        self.graph.add_vertex(kf.id, pose)
        self.next_id += 1
        return kf.id

    def add_contact_factor(self, i, j, z_ij, omega):
        self.graph.add_edge(i, j, z_ij, omega, kind='contact')

    def optimize(self, iterations=10):
        for _ in range(iterations):
            H, b = self.graph.linearize()
            H += self.graph.prior_information()
            dx = solve_sparse(H, b)
            self.graph.retract(dx)
        self.reproject_keyframes()

    def query(self, pose):
        cid = min(self.keyframes, key=lambda i: dist_se3(pose, self.keyframes[i].pose))
        kf = self.keyframes[cid]
        return kf.scene_label, kf.imp_posterior, kf.conf
```

### IP-162 CEFG（云边因子图分工）

```python
class CloudEdgeFactorGraph:
    def __init__(self, edge_window=15, link_budget=None):
        self.edge = ExecutionSemanticSLAM(window=edge_window)
        self.cloud = PoseGraph()
        self.link = link_budget
        self.marginals = []

    def step(self, new_kf, contact_factors):
        self.edge.add_keyframe(*new_kf)
        for f in contact_factors:
            self.edge.add_contact_factor(*f)
        if len(self.edge.keyframes) > self.edge.window:
            marginal = self.edge.marginalize_oldest()   # Schur 补
            self.marginals.append(marginal)
            if self.link.allows(marginal.bytes):
                self.cloud.add_prior(marginal)
                self.link.consume(marginal.bytes)
        self.edge.optimize(iterations=3)

    def offload_value(self, factor_set):
        dH = self.expected_entropy_reduction(factor_set)
        return dH - self.link.bw_cost(factor_set) - self.link.latency_cost(factor_set)
```

### IP-164 SCF（空间置信场）

```python
class SpatialConfidenceField:
    def __init__(self, resolution=0.05, decay=0.995):
        self.field = defaultdict(float)
        self.res = resolution
        self.decay = decay

    def observe(self, pose, cov, kappa=0.5):
        for cell in self.cells_within(pose, 3 * cov):
            gain = kappa * math.exp(-0.5 * mahalanobis_sq(cell, pose, cov))
            self.field[cell] += (1 - self.field[cell]) * gain

    def decay_unobserved(self):
        for cell in self.field:
            self.field[cell] *= self.decay

    def loop_closure_boost(self, cells, sigma_old, sigma_new):
        ratio = sigma_old / max(sigma_new, 1e-9)
        for cell in cells:
            g = self.field[cell]
            self.field[cell] = 1 - (1 - g) ** ratio

    def sic_valid(self, cell, tau_gamma=0.7):
        return self.field[cell] >= tau_gamma
```
