# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配×主动交互的不确定性二分」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「桌面操作」×「模型预测控制」）

> R69 已经把不确定性拆成 aleatoric / epistemic，并让系统学会「看、问、触、等」。但它仍有两个结构性缺口：
> 1. **信息动作是离散、外挂、与任务分离的**：先停下来问，再继续做；在桌面这种接触密集、时间敏感的场景里，「停一下」本身就可能错过时机、打断任务流，甚至因为额外接触而引入新的风险。
> 2. **信息与安全由同一族学习模型背书**：VoI 用流模型算，安全用 C-RAS-WM 认证；当两个模型一起错时，系统会「自信地追问一个幻影」并「用错误的模型盖章」。R69 自陈的最大风险正是这一点。
>
> 本轮两个灵感把问题拉回物理世界：
> - **桌面操作**给了机器人一个天然的**实验台**：桌子是已知的支撑面与重力参照，接触是测量，物体是待测样品。很多 epistemic 问题不需要额外「问」，只需要在本来就要做的动作里多走一步「可证伪的接触」。
> - **模型预测控制**给了机器人一条**带硬约束的未来**：它能把 R69 的「动作块」变成「对多个假设都安全的共享前缀 + 等观测再分支的后缀」，把「信息」写进滚动时域目标（对偶控制），并用可达集 / CBF 给出不依赖学习世界模型的安全证书。
>
> 核心命题：**用「接触日程语法」把 epistemic 状态离散成有限、可解释的物理假设；用「共享前缀 + 分支后缀」的场景 MPC 把 R69 的「看—问—做」压进同一条任务轨迹；用「接触物理残差」提供标定不可吸收的证据；用「鲁棒可达集 + CBF + 回退」提供不弱于 R69 的安全；R69 是本轮在『不信任物理模型 / 信息价值为零』边界上的退化。** 命名 **BENCH-RAS**（Belief-space, Experiment-design, Non-anticipative Contact-aware Hybrid risk-adaptive system）。
>
> 一句话定位：R69 问「我该向谁求证」，R70 问「**我能不能让任务本身成为实验**」——最好的探针，往往不是额外的一次注视，而是你本来就要做的那一次接触。

## 0. 直觉与动机

**灵感 1（桌面操作 → 桌子是实验室，不是背景板）**
直觉：桌面操作与野外操作最大的区别，是它有一个**已知的物理参照系**。桌面法向就是重力方向，桌面近似刚性、静止、可重复；物体的质量、摩擦、质心会直接写在「推、滑、抬、翻」的力—位移曲线里。R68 用传感器残差问「我的测量还准吗」，R69 用流似然问「我的行为自洽吗」，但都没有利用这个**免费的计量标准**。桌子可以当砝码、当导轨、当力台：轻敲桌面可测末端柔顺与力偏置；在桌面上匀速滑动可测摩擦系数；准静态抬起可测质量；绕支撑边翻转可测质心。**桌面不是任务背景，而是实验室的工作台。**

**灵感 2（MPC → 未来不是一条轨迹，而是一个带约束的可行域）**
直觉：R69 的流匹配策略输出一个动作块 ξ_{t:t+H}，再用标量 λ 收缩风险。但动作块没有显式的**非穿透、摩擦锥、力矩平衡、关节/力限**约束；它只能说「这个动作概率低」，不能说「这个动作物理上不可行」。MPC 的语言正好相反：它直接在一个**硬约束集**里优化，滚动时域，每一拍都用最新观测重解。把 R69 的生成分布当作**提议分布与热启动**，把 MPC 当作**可行性与安全性的认证器**，两者不是替代，而是「生成—认证」的分工。

**灵感 3（对偶控制 → 信息不是额外的动作，而是任务的副产品）**
直觉：R69 的 MINT 把信息动作 g 和任务动作 a 并列，用 VoI 决定要不要「停下来问」。但人类在桌面上很少这样：他不会先停下来「测量杯子有多重」，而是**在拿起杯子的过程中**通过手腕的力感知道它有多重；不会先「测量抽屉的摩擦」，而是**拉的时候**根据阻力调整。这就是 Feldbaum 的对偶控制：**控制信号同时承担调节与探测**。把互信息项写进 MPC 的目标，最优解自然会在「任务进度」与「可分辨性」之间取折中；纯探针（R69 的 g）只是当任务轨迹的信息增益为零时的**边界解**。

**灵感 4（场景 / 分支 MPC → 不确定性是一组必须同时安全的假设）**
直觉：R69 遇到歧义的处理是「都慢下来」（λ_floor），或者「问一次再选」。但多峰不确定性真正需要的，是一个**非预期（non-anticipative）的计划树**：在还没拿到能区分假设的观测之前，所有假设共用同一段前缀，这段前缀必须对**每一个**假设都安全；一旦某个接触事件把假设分开，再切换到对应的后缀。这样既不像「都慢下来」那样牺牲效率，也不像「先猜一个」那样赌命。**共享前缀保证不赌，分支后缀保证不慢。**

**灵感 5（接触物理 → 世界会给出标定吸收不了的答案）**
直觉：R69 的流似然是对「行为自洽」的第二意见，但它仍是一个学习出来的密度，可能和策略一起错。接触物理给出的是另一类证据：**非穿透、摩擦锥、准静态力矩平衡、互补性（力与速度不能同时非零）**。这些是**物理一致性**，不是传感器偏差；标定可以把一个恒定的力偏置解释掉，但很难同时让「物体没被穿透」「摩擦锥没被突破」「力矩平衡成立」这三件事在一个错误的接触模式下继续成立。R70 因此把 R69 的黑箱似然，补成一条**可解释、低维、可检验**的物理证据通道。

**灵感 6（双刃剑升级 → 世界会推回来，实验也可能弄坏样品）**
直觉：R69 的新攻击面是「人会撒谎」；R70 的新攻击面是「**物理世界会主动配合你撒谎**」——粘滞陷阱让物体在轻推时显得可动、抓住时却锁死；先软后硬的顺应让探针得到错误的柔顺；外力注入让鲁棒 MPC 以为扰动仍在界内；一个「看起来像抽屉」的固定装饰会诱导 CSG 解析出错误的日程。更麻烦的是，**主动接触可能损坏易碎物体**：信息不是免费的，它可能以样品为代价。因此本轮必须同时交付：物理干扰集、接触力 / 能量 / 损害预算，以及「物理证据也不得单源定案」的纪律。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（BENCH-RAS 总览）** BENCH-RAS = (CSG, HBM, SC-MPC, DIO, CPI, TMR, GVG, RAS-WM†)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **物理证书优先**：任何进入执行器的计划必须持有有效鲁棒证书；证书缺失 / 超时 / 监控越界时，只能执行 R69 已验证的回退计划，绝不执行未认证的 MPC 计划；
(iii) **实验纪律**：接触实验受力 / 能量 / 损害预算约束；任何单个接触或单个物理通道不得单独定案一个模态（R69 证据纪律的物理加强版）。

**定义 311（桌面物理场景与准静态假设 A99）** 支撑平面 S = (n, d)，n = −g/‖g‖；物体 O_i 的物理参数 θ_i = (m_i, c_i ∈ ℝ³, I_i ∈ SPD³, μ_i, e_i, k_i)，分别为质量、质心、惯性、摩擦、恢复系数、刚度。接触图 C 的每条接触 c = (body_a, body_b, p, n_c, mode)。状态 x = (q, q̇, {pose_i, vel_i})，控制 u 为关节力矩或末端力旋量。**A99（准静态）**：存在 ε_q, v_q，使 ∀t，‖Mẍ‖ ≤ ε_q‖f_c + mg‖ 且 ‖ẋ‖ ≤ v_q。桌面任务的低速抓取 / 放置 / 推动通常满足 A99；高速抛掷、强冲击不在此列（显式排除，避免过度承诺）。

**定义 312（接触日程语法 CSG）** 技能集 K = {approach, grasp, lift, transport, place, release, push, slide, pivot, handover, …}。接触日程 σ = (s_1, …, s_n)，每个阶段 s_j = (κ_j, C_j, π_j)，κ_j 为技能，C_j 为活跃接触集，π_j 为阶段参数（时长、路点、力上限）。CSG 是带前置条件的语法：例如 lift 需要先 grasp，place 需要先 transport 且目标在支撑面上，push 不允许同时 grasp。对场景 x 的解析给出有限日程集 Σ(x)，再按几何可达性、碰撞、力上限剪枝。**分支纪元** B(σ) = 阶段边界 ∪ 接触切换事件；MPC 只允许在 B(σ) 处分支，避免毫秒级抖动。

**定义 313（混合信念 HBM）** 模态 M = (σ, θ)。信念 b_t 是有限加权场景集 S_t = {(σ_m, θ_m, w_m)}_{m=1}^{K} 加连续参数后验 p(θ | σ_m)（高斯或粒子）。模态熵
H(M) = −Σ_m w_m log w_m + Σ_m w_m H(p(θ | σ_m))；
物理可分性 Δ_phys(i, j) = 在共同阶段上的参数 / 轨迹距离（W₂ 或归一化物理量差）。与 R69 的流聚类不同，**每个模态都是物理类型化的假设**（哪个技能、哪组接触、哪组参数），因此可以被接触证伪，而不只是被另一个学习模型打分。

**定义 314（场景-分支计划）** 规划时域 H，分支纪元 t_b ≤ H。计划树
Π = (u_{0:t_b−1}^{pre}, {u_{t_b:H}^{(m)}}_m)。
**非预期性**：k < t_b 时所有场景共用同一 u_k（因为此时还没有能区分它们的观测）。**鲁棒前缀可行性**：对 ∀m ∈ S_t，前缀在模态 m 下满足硬约束 U_adm(x, m)。**后缀追索**：分支后每个 m 有各自可行的后缀。t_b 只能取 B(σ) 中的元素，且必须在一次「认证可分辨」的观测之后。

**定义 315（桌面硬约束集 U_adm）** 对每个 m：
- 非穿透：φ_j(x) ≥ 0（所有物体对、物体—桌面、机器人—物体、机器人—人）；
- 摩擦锥：‖f_t‖ ≤ μ f_n，f_n ≥ 0；
- 准静态平衡：‖Jᵀf + mg‖ ≤ ε_b，力矩平衡同类；
- 互补性：f_n·v_n ≈ 0；粘着时 v_t = 0，滑动时 f_t = −μ f_n v_t/‖v_t‖；
- 限幅：|u| ≤ u_max，|q̇| ≤ v_max，‖f‖ ≤ f_max，工作空间 / 可达性；
- 支撑：未抓取物体保持在桌面之上（z ≥ z_table − ε）；
- 人机距离：‖p_robot − p_human‖ ≥ d_safe。
U_adm(x, m) 是这些集合的交。它们是**硬约束**，不是软惩罚；这是与 R69「用 λ 收缩风险」最本质的区别。

**定义 316（对偶控制信息目标 DIO）** 任务代价 c_task（进度、目标误差、能耗、时间），风险代价 ρ·c_risk，损害代价 γ·D(Π)。计划目标
J(Π) = E_{m∼b}[Σ c_task + ρ c_risk] − β·I(M; Y_{0:H} | Π, b) + γ·D(Π)。
高斯接触观测下，互信息用成对 KL 近似：
I ≈ Σ_{i<j} w_i w_j D_KL(p(y|m_i, Π) ‖ p(y|m_j, Π))，
D_KL = ½[tr(Σ_j^{-1}Σ_i) + (μ_i−μ_j)ᵀΣ_j^{-1}(μ_i−μ_j) − d]。
连续参数用接触 Fisher 信息
F_θ = Σ_{contacts} J_cᵀ Σ_y^{-1} J_c，
D-最优代理为 max log det(F_θ + F_0)。β 是温度 / 拉格朗日乘子：β=0 ⇒ 不主动收集信息（R68 边界）；β→∞ ⇒ 纯实验（R69 纯探针边界）。

**定义 317（分支准则与迟滞）** 成对对数似然比 L_{ij}(y) = log[p(y|m_i)/p(y|m_j)]。当
max_{i,j} min(L_{ij}, L_{ji}) ≥ τ_b
连续 h 帧成立，且两个模态后验仍大于 w_min，才允许在 t_b ∈ B(σ) 分支；否则继续执行鲁棒前缀。迟滞 h 与阈值 τ_b 共同保证无 Zeno 抖动（定理 19）。

**定义 318（接触物理辨识 CPI）** 残差向量 r(θ, y) = (r_pen, r_fric, r_bal, r_comp, r_inertial)，各分量按观测噪声归一化。似然
p(y|θ) ∝ exp(−½ rᵀΣ_r^{-1}r)（Huber 鲁棒化）。
贝叶斯更新 p(θ|y) ∝ p(y|θ)p(θ)。**标定不变特征**：μ̂ = ‖f_t‖/f_n（摩擦比）、m̂ 由差分 Δf_z/g 或 Δf/Δa 估计、质心由 τ/f 估计、惯量由角加速度比估计。比值与差分抵消加性偏置 b；公共尺度 s 由桌面计量参照（定义 319）或机器人已知惯量锚定。形式化见引理 20。

**定义 319（桌面计量参照 TMR）** 把桌面当作已知参考：法向由重力确定、近似刚性、静止、面积大。四个典范实验，均可嵌入任务阶段：
- **Tap**：轻敲桌面（已知刚性）→ 估计末端柔顺与力偏置；
- **Slide**：在桌面上以受控法向力滑动 → 摩擦系数 μ = f_t/f_n（临界滑动时）；
- **Lift**：准静态竖直抬起 → 质量 m = Δf_z/g（差分消偏置）；
- **Pivot**：绕支撑边翻转 → 质心由力矩平衡 τ = mg·r 估计。
每个实验给出测量方程与 Fisher 信息；关键是它们可以**顺便完成**（滑向放置点、抬起搬运、翻转对位），而不是额外动作。

**定义 320（物理安全证书）** 模型误差界 e_max（由保形校准或区间分析得到）。鲁棒可达集 R_k = {x_k : ‖w‖ ≤ e_max}；证书有效当且仅当 ∀m ∈ S_t：
R_k ⊆ Safe（非穿透、力限、人机距离），且 CBF h(x) ≥ 0 且 h(x_{k+1}) ≥ (1−γ)h(x_k) 在最坏扰动下成立，且损害预算未越界。若求解超时 / 无可行计划 / 证书失效 ⇒ 回退 R69 已验证计划（不变式 310-ii）。

**定义 321（语法有效性门 GVG）** 用保形 / OOD 分数 s(x) 判断场景与接触是否落在 CSG 的支持内。保形 p 值 p = (1 + #{s_i ≥ s(x)})/(N+1)；若 p < α 或解析置信度 < τ_g，则判定「语法失效」，禁用 CSG / MPC，回退 R69 的流多模态 + λ_floor。**注意**：保形覆盖保证依赖校准集与测试点的可交换性；在真实分布漂移下它退化为启发式门控，必须与执行监控联合使用。这是对「模型族错误」的正面防护，也是对 R69 MCG 的物理版。

**定义 322（执行监控与回退）** 在线监控接触残差 r_t、约束裕度、模型误差估计。若裕度 < 0、r_t > τ_monitor 或实测误差超出 e_max，立即中止当前计划，执行安全停或 R69 回退，并记录事件。**未认证动作永不抵达执行器**。

**定义 323（R69 / R68 的包含关系）** 定义限制算子 R：(i) 用 R69 的流模态替代 CSG 场景；(ii) 用 R69 的 C-RAS-WM 证书替代鲁棒证书；(iii) β=0；(iv) t_b ∈ {0, H}（纯探针或不分支）。则 BENCH 的计划集包含 R69 计划。执行器在 {R69 已验证计划} ∪ {持有有效物理证书的 MPC 计划} 中取代价最小者。因此：**R69 计划始终可用 ⇒ 安全不弱于 R69；GVG 失效时 BENCH 精确退化为 R69；β=0 且无信息时退化为 R68**。代价不劣性在扣除求解开销后成立（求解开销单独计入实时预算，见定义 326）。

**定义 324（接触实验预算与损害约束）** 单次接触的力 / 能量 / 时长上限；累计损害风险 D ≤ D_max 且 CVaR_α(D) ≤ D_max。未知易碎性时使用保守力上限；人附近禁止尖锐探针。信息收益必须与损害风险做显式权衡（引理 19 的 f* 公式）。

**定义 325（物理干扰集 ℰ_phys）** 对抗性外力、粘滞陷阱（轻推可动、抓取锁死）、欺骗性顺应（先软后硬）、力注入、传感器欺骗、语法投毒（伪可供性）、破坏性表面。并入 R69 的 AIC：
ℰ_BENCH = ℰ_FLUID × ℰ_phys。
鲁棒 MPC 只对 ‖d‖ ≤ d_max 的扰动给保证；超出界的攻击由执行监控与多源证据发现，不由证书保证（诚实声明）。

**定义 326（自适应场景与实时预算）** 场景数 K、时域 H、任意时间求解器。用 R69 流策略热启动；熵低时 K=1 退化为单轨迹 MPC。求解预算 T_solve（如 30ms）：超时则执行当前最优可行 incumbent；若无 incumbent，回退 R69。H 随接触距离自适应：远离接触时短，接近接触时长。

**定义 327（场景剪枝与 anytime 下界）** 对每个场景 m 用松弛问题（凸松弛 / 忽略信息项 / 粗离散）得下界 L_m。若 w_m(L_m − J*) > ε_gap 或 w_m < ε_w，则剪枝。任意时间次优界：
J(Π) − J* ≤ Σ_{pruned} w_m (L_m − J*) + ε_solver。
这给出的是**可审计的近似最优证书**，不是「跑得动就算」。

**定义 328（证书 J_BENCH）** J_BENCH = (J_FLUID, scenario_coverage, robustness_margin, cpi_residual, branch_log_hash, constraint_margin, gvg_pvalue, damage_risk, bench_ver)。Valid ⇔ Valid(J_FLUID) ∧ GVG 通过 ∧ 鲁棒证书有效 ∧ 损害预算未越界 ∧ 监控无违规。审计从「问了什么」扩展到「做了什么实验、实验是否信息有效、是否破坏样品、是否单接触定案、分支是否有据」。

## 2. 本轮最大风险（一句话预演）

## 4. 推导

**引理 19（接触实验的 Fisher 信息与最优力度）** 设测量 y = h(θ) + ε，ε ∼ 𝒩(0, Σ_y)，线性化 y ≈ y_0 + J_c(θ−θ_0) + ε，则 Fisher 信息 F = J_cᵀΣ_y^{-1}J_c，后验协方差 Σ_post = (Σ_θ^{-1}+F)^{-1}，期望信息增益
`IG = ½ log det(I + Σ_θ^{1/2} F Σ_θ^{1/2})`。
特例：竖直抬升测质量 J_c = g，`IG_m = ½ log(1 + g²σ_θ²/σ_f²)`；滑动测摩擦 J_c = f_n，`IG_μ = ½ log(1 + f_n²σ_μ²/σ_f²)`；绕边翻转测质心 J_c ∝ mg·r。系 1：信息随接触力平方增长，但损害随 f^p 增长；令 `dIG/df = γ dD/df`，大 f 下最优力 `f* ≈ (β/(γ d p))^{1/p}`——给出可解释的力上限，而不是拍脑袋。系 2：D-最优行列式由接触法向的多样性最大化，**单点接触很少最优**，这从信息论上支持「多接触 / 多源证据」纪律。

**引理 20（接触物理残差的标定不变性）** 设慢变标定可写成 y′ = s A y + b，A 已知，s>0，b 未知。CPI 使用比值（μ̂=‖f_t‖/f_n、r̂=τ/f）与差分（Δf_z、Δf/Δa）特征：加性 b 在差分中抵消，公共尺度 s 在比值中抵消；s 的绝对尺度由桌面计量参照（已知重力 / 机器人已知惯量 / 标定质量）锚定。因此，**共模的慢变标定漂移无法解释掉一个真实的接触模式不一致**；只有「模式相关的结构化欺骗」才能同时骗过比值与差分，而这正是 ℰ_phys 要覆盖的。证明为代数消去；在接触非退化（f_n>0、接触点不共线）时，错误模态与真实模态的残差似然比有正下界。这是 R69 引理 17（流似然不可吸收）的物理镜像。

**引理 21（非预期分支的安全性）** 若 (a) 真模态 m* ∈ S_t；(b) 模型误差 ≤ e_max；(c) 前缀对 ∀m∈S_t 鲁棒可行；(d) 仅在认证分支纪元切换且后缀对后验选定模态可行，则执行轨迹在监控触发前对 m* 满足 U_adm（允许 e_max 的裕度）。证明梗概：分支前前缀对 m* 可行（因 m* 在场景集内）；分支后若选对 m*，后缀可行；若选错，误分支概率由引理 19 / 定理 19 的观测噪声界控制，且监控残差会在有界时间内触发回退。**注意这是条件保证：m* 不在场景集内时，定理不成立——这正是 GVG 与主风险存在的原因。**

**引理 22（场景剪枝的 anytime 下界）** 设 J* 为未剪枝最优值，L_m 为场景 m 的松弛下界。剪掉满足 `w_m(L_m−J*) > ε_gap` 或 `w_m<ε_w` 的场景后，
`J(Π) − J* ≤ Σ_{pruned} w_m(L_m−J*) + ε_solver`。
证明：被剪场景对最优值的贡献不超过其下界；求和即得。系：实时预算下的解带有可审计的次优证书，而不是「跑得动就算」。

**定理 18（BENCH 对 R69 / R68 的包含）** 定义限制算子 R（流模态替代 CSG、C-RAS-WM 替代鲁棒证书、β=0、t_b∈{0,H}）。BENCH 执行器的计划集是 {R69 已验证计划} ∪ {有效物理证书的 MPC 计划}，故 R69 计划始终可用 ⇒ 安全不弱于 R69；GVG 失效时只剩 R69 ⇒ **逐指令相同**；当 β=0 且无可用信息时，R69 的 VoI 决策退化为「不交互」，再叠加 λ_floor 即 R68 的保守边界。效率侧：当物理证书有效且信息项非零时，BENCH 可用分支后缀获得 resolution bonus，期望代价低于 R69（扣除求解开销，见复杂度表）。**姿态：新层不是并列替代，而是把旧层作为回退下界包含进来。**

**定理 19（分支无 Zeno、误分支有界）** 分支只在 B(σ) 发生（有限个阶段边界），且需要似然比连续 h 帧越过 τ_b 并保持两模态仍可能。在次高斯观测噪声下，误分支概率 ≤ exp(−h·τ_b²/(2σ²)) 量级；每次切换需要一次「持续的证据翻转」，故切换次数有限（a.s.），不会出现毫秒级抖动。证明用似然比鞅与迟滞能量论证；这里给出界的形式，严格常数留待 E313 校准。

## 7. 预注册判定与「结果」说明

本轮**不伪造实测结果**。上表是预注册目标与判定阈值；E301–E317 的实际数值需在仿真（MuJoCo / Isaac）与真机（桌面 32 任务）上按固定随机种子、固定训练集 / 测试集划分测出。我们只声明可检验的**定性预测**：
1. 在准静态桌面任务上，硬约束违规应显著低于 R69 的「λ 软收缩」；
2. 在接触可辨识的任务（滑动、抬起、翻转）上，CPI 的参数误差应随接触力增大而下降，直到损害上限；
3. 在真实模态落在 CSG 内的场景，分支后缀应比「都慢下来」更快且不更危险；
4. 在真实模态落在 CSG 外的场景，GVG 应触发回退，且回退后的行为与 R69 一致；
5. 在物理投毒场景，单接触证据应被多源纪律拦截，监控应触发回退。

## 8. 与 R69 的差异一览

| 维度 | R69 FLUID-RAS | R70 BENCH-RAS |
|---|---|---|
| 不确定性表示 | 流采样的无类型模态簇 | 物理类型化的 (日程 σ, 参数 θ) |
| 信息动作 | 离散 g（看/问/触），与任务分离 | 嵌入任务轨迹的连续接触实验（对偶控制） |
| 消歧时机 | 先问再做（两阶段） | 共享前缀 + 分支后缀（非预期计划树） |
| 安全来源 | 学习 WM 的 C-RAS-WM 认证 | 鲁棒可达集 + CBF + 模型误差界；R69 为回退 |
| 第二意见 | 流似然 Δa | 接触物理残差 r(θ) + 流似然（双通道） |
| 标定 | 传感器残差 | 桌面计量参照 + 比值 / 差分不变特征 |
| 主要失效 | 模态分布不可信 → 追问幻影 | 真实日程在 CSG 外 → 在错误假设族内「精确地错」 |
| 实时 | 2.6ms | 10–30ms（10–20Hz），任意时间 + 回退 |

## 9. 本轮最大风险

**一句话**：BENCH-RAS 的全部保证都条件于「真实接触日程在 CSG 假设族内，且模型误差在 e_max 内」——一旦世界用语法之外的接触模式回应，MPC 会在错误假设族里把约束满足得很漂亮、把参数辨识得很精确，主动实验还会让这个错误信念**更自信**；不是「不知道」，而是「精确地错」。

**次级风险与缓解**：
1. **场景爆炸 / 实时击穿** → 场景剪枝 + anytime 下界（引理 22）+ R69 热启动 + 超时回退；
2. **接触模型 sim-to-real 误差** → 鲁棒误差界 + 保形校准 + 保守力上限；E302/E312；
3. **标定不变性只覆盖共模漂移** → 比值 / 差分只对共模有效；结构化欺骗交给 ℰ_phys、多源证据与监控（引理 20 的边界显式声明）；
4. **主动实验损坏样品** → 损害预算 + CVaR + 未知易碎性保守上限（定义 324，引理 19 的 f*）；
5. **人机安全 / 社交** → CBF + 能量界 + 人附近禁尖锐探针（定义 315、320）；
6. **GVG 误拒** → 退化为 R69，代价是保守；E317 量化；
7. **对物理残差过度自信** → 单接触不定案；k 个正交证据源（物理 / 视觉 / 语言 / 环一致）一致才定案（定义 310-iii、328）。
