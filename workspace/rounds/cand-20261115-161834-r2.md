# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧」IP-253~263；本轮灵感：「夹爪控制」×「评测基准」）

> R69 给了系统一张嘴：它会把不确定性分成 aleatoric 与 epistemic，会算 VoI，会去「看、问、触」。但它有两个未兑现的承诺。第一，「触」只是一个抽象维度 g_probe——真正的接触是连续的力/位移轨迹，是**不可逆**的；问错了可以重问，捏碎了不能重来。第二，R69 判断「这次交互值不值」用的是它自己的模态后验，而**没有任何外部裁判**能证明它的「我不知道所以我去问」不是事后编故事。
>
> 本轮两个灵感正好补上这两块：
> - **夹爪控制**把「探询」落到物理：夹爪是唯一既能测量世界、又能改变世界的传感器；轻触、加载、微滑移都是实验，但都是不可逆实验。
> - **评测基准**把「值不值」落到可证伪：只有在隐藏真值 + 反事实 oracle 下，才能区分「探询赚到了信息」与「碰巧成功」。
>
> 核心命题：**抓取不是单纯的动作，而是一次有预算的物理实验；物理实验的 VoI 必须在不可逆性下重定义；而「这次实验值不值」只能由一个知道世界真值的裁判来判定。** 命名 **CAGE-RAS**（Contact-Aware Grasp Epistemics for Risk-Adaptive Safety），其配套基准 **GRIP-Bench**（Grounded Referee for Irreversible Probing）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我这一下捏下去，值不值；捏坏了，谁来证明我本不该捏**」。

## 0. 直觉与动机

**灵感 1（夹爪控制 → 接触是最后一厘米，也是不可逆性的边界）**
直觉：R69 的 g_probe 只是一个「探针方向 + 力度」的抽象向量；真实夹爪面对的是一整套接触物理——平行爪/欠驱动/软指、力控与阻抗控、摩擦锥、滑移裕度、接触刚度、加载速率。抓取不是一个瞬时动作，而是一条阶段链：接近 → 轻触 → 加载 → 提起 → 运输 → 释放。每个阶段的可辨识性不同、不可逆性也不同：轻触可测刚度，加载可测摩擦与质量，释放一旦松手就不可逆。**探询必须被限制在低损坏、可回复的阶段**，而不是像 R69 那样把「触」当成一个随时可用的免费动作。

更关键的是，柔顺硬件本身就是一个「机械贝叶斯」：串联弹性、软指尖、欠驱动结构会把物体的形状/刚度信息编码进自身变形，**不计算、不冒险就完成了一次被动估计**。这不是工程细节，而是「免费的认知资本」——同样的信息，软夹爪需要的主动探询更少，因而损坏预算更低。

一句话：接触是唯一能把「隐藏物理属性」从不可观测变成可观测的通道，也是唯一能造成不可逆损坏的通道。**信息与伤害同源**，这是本轮的核心张力。

**灵感 2（评测基准 → 没有裁判的认知只是自恋）**
直觉：R69 的证书 J_FLUID 记录了 ECE、U_epi、VoI ratio，但这些量全部在策略自己的信念空间里计算。一个自信的错误策略完全可以生成一份自洽、漂亮、毫无破绽的证书。要判断「它是不是真的在不确定性下做了正确的事」，需要一个**知道世界真值的裁判**：隐藏物理参数 h、反事实重放、留出物理族、对抗性欺骗物体。

基准不是数据集，而是**认识论仪器**——它决定什么算「知道」。因此它也有自己的不确定性：构念效度（construct validity，是否测到了「认知能力」而非「碰巧成功」）、污染泄漏、Goodhart 间隙、仿真保真度。基准的版本哈希必须写进证书；否则 J_GRIP 只是「对某个基准过拟合」的别名。

最有力的工具是**反事实探询 oracle**：在同一隐藏状态下重放三种世界——(a) 不探询直接抓，(b) 策略的探询，(c) oracle 最优探询。只有三者对照，才能把「本可以不问」与「本应该问」从结果里分离出来。

**灵感 3（不可逆性 → 安全探询存在信息论上限）**
直觉：想知道一个杯子多脆，最直接的方法就是用力一点看它碎不碎；但它一碎，信息与损失同时到达。如果你坚持不做任何可能损坏它的事，那么在所有「低于两个对象脆性阈值」的探询下，观测分布完全相同，你什么也学不到。这不是工程限制，而是信息论下界。

形式化（见引理 19）：两个对象只在脆性阈值上不同，低于阈值时观测同分布；任何最坏情况损坏概率 ≤ δ 的探针，其观测分布的总变差距离 TV ≤ 2δ，故等先验下的最小判别错误率 ≥ 1/2 − δ。**想更确定，就必须更敢弄坏。** 推论是刺耳的：对某些属性而言，「安全探询」本身是矛盾的；正确回应是弃抓、换柔顺硬件、或寻找前兆信号（微裂声、刚度软化）。这正面回应了 R69 的「问错比不问更危险」——在接触里，问错的代价是不可逆的。

**灵感 4（评测即安全论证 → 证书的证书）**
直觉：如果基准被污染、被应试、或被仿真保真度欺骗，J_GRIP 就是虚假保证，甚至比没有证书更危险。所以基准本身需要负对照：一个「应试策略」应当被识别出来；隐藏留出物理族必须与公开种子分离；策略不能区分「评测模式」与「部署模式」；Goodhart 间隙要作为一等指标报告。评测不是研究流程的最后一步，而是**安全架构的一个组件**。

由此还有一个运行时的用法：**GRIP-Live**，在程序化合成任务上周期性自测，监测 CPM 校准与损坏模型残差随时间的漂移。它只做监测，不提供部署时的在线真值，也不得用自测标签更新任何安全关键参数——否则基准就会变成另一个可被标定层吸收的通道。

**灵感 5（回到 R69 的风险 → 模态幻觉的物理版）**
直觉：R69 怕流模型幻觉出不存在的动作模态；R70 怕 CPM 幻觉出**不可辨识的物理属性**——例如从一张图里「读出」质量，然后基于这个幻觉去选择探询或抓取。解药是 Fisher 可辨识子空间：只报告能测的属性方向，不可辨识分量永远进入保守项，任何「探询」都不能声称消解它。这是「幻影模态」在接触侧的严格镜像。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（CAGE-RAS 总览）** CAGE-RAS = (CPM, CEBox, PIV, DCM, ICS, GRIP-Bench)。三不变式：
(i) **接触期零学习写操作**（继承 R68 定义 276-i：接触过程中不更新任何安全关键参数）；
(ii) **认证实验盒**：任何物理探询 g_c 必须满足最坏情况损坏概率 ≤ δ_dmg、滑移概率 ≤ δ_slip、力/位移/时间包络，并通过 C-RAS-WM 前缀认证；
(iii) **裁判纪律**：任何关于「值不值得探询」的声称，必须在 GRIP-Bench 的隐藏真值与反事实 oracle 下可证伪；自报置信度不算证据。

**定义 311（隐藏物理属性）** h = (m, r_c, μ_s, μ_k, k_n, k_t, τ_f, ρ_s) ∈ H，分别为质量、质心偏移、静/动摩擦系数、法向/切向接触刚度、脆性阈值、表面粗糙度。策略观测 o = (v, τ_tac, q_g, i_m)：视觉、触觉阵列、夹爪位形、电机电流。真值 h 只在基准中可见。

**定义 312（接触属性后验 CPM）** p_θ(h | o_{0:t}, ξ_{0:t}) ∝ p_θ(o | h, ξ) p(h)。用 Fisher 信息定义可辨识子空间 Π_id = {u : uᵀ I(h) u ≥ κ_id}，只在 Π_id 上报告属性后验；不可辨识方向保持保守先验。记 U_prop = H(Π_id h | o) 为可辨识属性不确定性，U_unid = H((I−Π_id)h | o) 为不可辨识分量——后者永远进入保守项，不允许被任何探询声称消解。

**定义 313（接触实验 / 探询）** g_c = (f_n(s), f_t(s), δ(s), T, c_contact)：法向力、切向力、位移、时长、接触点剖面。do(g_c) 产生观测 y = (slip_event, force_response, deformation, tactile_signature, acoustic)。探询是**干预**而非被动观测；y 的分布依赖 h，且可能改变 h 所描述的对象状态。

**定义 314（认证接触实验盒 CEBox）** 𝒢_cert = {g_c : ∀h ∈ H_plausible，F_max(g_c) ≤ F_safe(h)，P_damage(g_c; h) ≤ δ_dmg，P_slip(g_c; h) ≤ δ_slip，C-RAS-WM(g_c) = pass，budget.allow(g_c)}。H_plausible 为后验可信集（如 p(h|o) ≥ ε_p 的 CVaR 集）。认证是对最坏情况/风险度量成立，不是对点估计成立。

**定义 315（损坏–柔顺模型 DCM）** 损坏事件 D = 断裂 / 永久变形 / 磨损失效。P_damage(g_c; h) 由接触力学近似给出：峰值接触应力 σ_max = max_t f_n(t)/A(δ(t)) 超过 τ_f 的概率，加上滑移跌落造成的二次损坏；A(δ) 由接触柔顺 k_n 决定。柔顺度 c_mech = ∂δ/∂f_n 给出被动似然 p(δ | f_n, h)，在不增加损坏概率的前提下提供关于 k_n 的信息（引理 20）。

**定义 316（不可逆探询信息价值 PIV）** 以任务效用而非熵定义：
U_task(p) = max_{a ∈ 𝒜_grasp^cert} E_{h~p}[u(a,h)] − λ_slip R_slip(a,p) − λ_dmg R_dmg(a,p)
PIV(g_c) = E_{y~p(·|o,g_c)}[U_task(p(·|o,g_c,y))] − U_task(p(·|o)) − E[cost_damage(g_c)] − c_probe(g_c) − λ_irr I_irrev(g_c)
其中 I_irrev(g_c) 为不可恢复状态变化（塑性变形、物体移出工作区、密封破坏）。决策使用下置信界 PIV_LCB = PIV − κ_σ σ_PIV，以抵御后验误差与损坏模型误差。标准 VoI 是 U_task = −H 且 cost = 0 的特例。

**定义 317（ICS 安全探询控制器）** 若 max_{g_c ∈ 𝒢_cert} PIV_LCB(g_c) > 0，执行 g* = argmax PIV_LCB；否则不探询。不探询时在认证抓取集中选择；若最大期望效用 ≤ 0 或 U_unid > τ_unid，则**弃抓/交接**（abstain）。abstain 是一等动作，不是失败。

**定义 318（接触风险缩放与柔顺先验）** λ_contact = max(λ_floor(U_ale + U_prop^unresolved), λ_slip(U_slip))；力上限 F_cmd = min(F_safe, F_λ(λ_contact))。柔顺 c_mech 通过降低 U_prop 获得 resolution bonus；U_unid 永远计入保守项。若 P_damage^{LCB} > δ_dmg 或 U_unid > τ_unid，强制 abstain。

**定义 319（接触认知不确定性原理 CEP）** 对两个仅在脆性阈值上不同、且在低于两者阈值时观测分布完全相同的对象 h₀, h₁，任何满足最坏情况损坏概率 ≤ δ 的探询 g_c，其观测分布的总变差距离 TV(p₀,p₁) ≤ 2δ；故等先验下最小判别错误率 ≥ 1/2 − δ。系：要把脆性判别错误率降到 ε，必须付出 δ ≥ 1/2 − ε 的损坏预算；「安全」与「确定」不可同时任意逼近。若存在前兆信号，上界放松——**发现前兆本身就是基准要测的能力**。

**定义 320（反事实探询 oracle CPO）** 在仿真中保留隐藏 h，重放三种反事实：(a) 不探询直接抓，(b) 执行 g_c，(c) oracle 最优探询。定义探询后悔
R_probe = U_task^{oracle} − U_task^{policy}
并分解为 R_perc（后验误差）+ R_voi（探询决策误差）+ R_exec（执行/控制误差）+ R_dmg（损坏/滑移）。CPO 是 GRIP-Bench 的核心：没有反事实，就只能看到结果，看不到「本可以不问 / 本应该问」。

**定义 321（GRIP-Bench 分层任务族）** L1 仿真特权真值（质量/摩擦/脆性可控）；L2 域随机化 + 传感器噪声；L3 真机牺牲件（可破坏的 3D 打印件/食品对象，限量破坏实验）；L4 隐藏留出物理族（程序化生成，不公开参数分布）。任务族包含：表观–物理不一致（看着轻其实重、看着硬其实是薄壳）、空心/偏心、滑腻涂层、可变形、易碎、堆叠遮挡。每个任务带 h 真值与反事实 oracle。

**定义 322（元认知校准 MCS）** MCS = (ECE_prop, AUROC(U_prop; error), VoI-decision accuracy, abstain appropriateness, probe regret)。VoI-decision accuracy = 策略「探询/不探询」与 oracle 决策的一致率；abstain appropriateness = 在 oracle 也认为应弃抓/交接的状态上弃抓的比例，减去在可安全完成状态上误弃抓的比例。MCS 不是单一分数而是 profile；证书必须记录全 profile 与基准版本哈希。

**定义 323（基准污染与 Goodhart 防护 BCG）** 污染泄漏 L_contam = 策略在公开种子上的性能 − 在隐藏留出族上的性能；Goodhart 间隙 G_goodhart = 基准分数 − 下游真实分布分数。防护：程序化生成 + 隐藏参数分布 + 种子轮换 + 反基准识别测试（策略能否区分「评测模式」与「部署模式」）+ 对抗性「应试」策略作为负对照。基准自身的不确定性（有限样本、仿真保真度）也必须报告。

**定义 324（证书 J_GRIP）** J_GRIP = (J_FLUID, P_damage^{LCB}, U_prop, U_unid, MCS profile, R_probe decomposition, benchmark_hash, sim_fidelity, irreversibility_ledger)。Valid ⇔ Valid(J_FLUID) ∧ P_damage^{LCB} ≤ δ_dmg ∧ U_unid ≤ τ_unid ∧ MCS 不低于阈值 ∧ 基准哈希与部署声明的版本一致。

**定义 325（运行时自裁判 GRIP-Live）** 定期在程序化合成任务上运行 mini-GRIP-Bench，监测 CPM 校准、PIV 决策、损坏模型残差随时间的漂移；结果作为 MCG（R69 定义 306）与 COF（R68）的先验输入。自裁判只做监测，不提供部署时的在线真值，不得用其生成标签更新安全关键参数。

**定义 326（接触阶段与探询许可）** 抓取阶段链：接近 → 轻触 → 加载 → 提起 → 运输 → 释放。每个阶段有独立的可辨识性与不可逆性；只有「轻触/加载」允许探询，且探询不得使物体位置/朝向改变超过 ε_g；释放阶段不可逆性最高，禁止探询。探询许可 permiss(g_c, phase) 是 CEBox 的硬前置条件。

## 2. 关键算法骨架

```python
# IP-264 CPM：接触属性后验 + Fisher 可辨识子空间（复用 R69 trunk）
class ContactPropertyModel:
    def posterior(self, o_hist, xi_hist):
        z      = self.trunk(o_hist)                    # 复用 CALM/FLUID 的 z_t
        h_post = self.flow_head(z)                     # p(h | o)
        J      = self.fisher(h_post)
        Pi_id  = identifiable_subspace(J, KAPPA_ID)
        U_prop = entropy(project(h_post, Pi_id))
        U_unid = entropy(project(h_post, 1 - Pi_id))   # 永远进保守项
        return h_post, Pi_id, U_prop, U_unid

# IP-265 CEBox：对可信集做最坏情况/风险认证，而不是对点估计
def certify_probe(g, h_post, phase, budget, cras):
    if not permiss(g, phase) or not budget.allow(g): return False
    if not cras.prefix_ok(g):                        return False
    for h in cvar_plausible_set(h_post, ALPHA_CVAR):
        if F_max(g) > F_safe(h):          return False
        if P_damage(g, h) > DELTA_DMG:    return False
        if P_slip(g, h)   > DELTA_SLIP:   return False
    return True

# IP-266 PIV：不可逆性下的探询价值（下置信界决策）
def probing_value(g, h_post, o):
    base = U_task(h_post)
    exp_after = 0.0
    for y, p in predict_outcomes(g, h_post, o):      # 接触力学似然
        exp_after += p * U_task(update(h_post, y))
    p_dmg = worst_case_damage(g, h_post)
    return (exp_after - base
            - p_dmg * C_DMG
            - c_probe(g)
            - LAMBDA_IRR * irreversibility(g))

def select_probe(h_post, o, phase, budget, cras):
    best = None
    for g in propose_probes(h_post, k=5):
        if not certify_probe(g, h_post, phase, budget, cras): continue
        piv_lcb = probing_value(g, h_post, o) - KAPPA_SIGMA * sigma_piv(g)
        if best is None or piv_lcb > best.piv:
            best = Probe(g, piv_lcb)
    return best if best and best.piv > 0 else None  # 无利可图 → 不探询

# IP-268 ICS：探询后的抓取 / 弃抓
def grasp_after_probe(h_post):
    if U_unid(h_post) > TAU_UNID:      return ABSTAIN
    a = argmax_grasp(h_post, A_GRASP_CERT)           # 力闭合 + 滑移裕度
    if expected_utility(a, h_post) <= 0: return ABSTAIN
    return a

# IP-275 主闭环：R69 闭环的接触阶段展开
def CAGE_RAS_round(M, o, phase):
    h_post, Pi_id, U_prop, U_unid = M.cpm.posterior(o, M.hist)
    g = (M.ics.select_probe(h_post, o, phase, M.budget, M.cras)
         if U_prop > TAU_PROP else None)
    if g is not None:
        y = M.hardware.execute_probe(g)              # 认证力控/阻抗控
        h_post = M.cpm.update(h_post, y)
        U_prop, U_unid = M.cpm.decompose(h_post)
    a = M.ics.grasp_after_probe(h_post)
    if a is ABSTAIN:
        return M.handoff_or_regrasp(o, U_prop, U_unid)
    lam_c = contact_lambda(U_prop, U_unid, M.aud.aleatoric)
    F_cmd = min(F_safe(h_post), F_from_lambda(lam_c))
    tau   = M.ctrl.impedance(a, F_cmd, c_mech=M.hardware.compliance)
    M.grip_live.log(h_post, g, a, U_prop, U_unid, lam_c)
    M.jgrip.issue(...)
    return tau, lam_c, a
```

## 3. 推导

**假设 A99–A102**：A99 两对象只在 τ_f 上不同，低于两者阈值时观测同分布（无前兆）；A100 损坏模型是真实失效概率的保守上界；A101 柔顺变形的观测噪声已知且不增加损坏；A102 CPM 在可辨识子空间内校准误差 ≤ ε_cal。

**引理 19（安全探询的信息上限 / 接触认知不确定性原理）** 在 A99 下，对任意满足最坏情况损坏概率 ≤ δ 的探询 g_c，有 TV(p₀,p₁) ≤ 2δ；故等先验下的最小判别错误率 ≥ 1/2 − δ。证明要点：在损坏事件 D₀ ∪ D₁ 的补集上，两对象的观测分布完全相同（两者都处在低于阈值的同一弹性区间），分布差异只能来自损坏事件本身，故 TV ≤ P(D₀ ∪ D₁) ≤ 2δ；再用 Le Cam 两点下界 err ≥ (1−TV)/2。系：若要求判别错误率 ≤ ε，必须 δ ≥ 1/2 − ε。**这条引理把「安全探询」从工程口号变成一个可计算的 Pareto 前沿。**

**引理 20（柔顺的免费信息）** 在 A101 下，被动柔顺观测 δ = f/k_n + ε 给出关于 k_n 的 Fisher 信息 I_pass = f²/σ_ε² > 0；高斯近似下后验熵至少下降 ½log(1 + I_pass σ_prior²)，而 P_damage 不增加。系：**硬件柔顺度是可预先投资的认知资本**；同等信息下，软夹爪所需的主动探询损坏预算严格更低。

**引理 21（PIV 退化为 R69 VoI）** 当 P_damage = 0、I_irrev = 0、c_probe = 0，且取 u 使 U_task = −H 时，PIV 退化为 R69 的熵减 VoI。当 CEBox = ∅ 或 max PIV_LCB ≤ 0 时，CAGE-RAS 的接触决策与 R69 的「不交互」分支逐指令相同；再若无接触观测，则整体退化为 R69/R68。

**定理 18（CAGE-RAS 的保守优势与严格包含）** 在 A99–A102 与认证实验盒下，任意状态有：(i) P_damage ≤ δ_dmg + ε_cal；(ii) CAGE-RAS 的期望任务效用 ≥ R69 的「不能物理探询」策略，因为不探询动作始终在候选集中且 PIV 用下置信界比较；(iii) 若不存在 PIV_LCB > 0 的认证探针，则行为与 R69 不交互分支逐指令相同。证明要点：认证保证损坏上界；LCB 使「模型误差翻转 PIV 符号」的概率被 κ_σ 控制；退化分支与 R69 共用同一决策函数。**安全侧不让步，效率侧获得「接触分辨率」红利。**

**定理 19（仅任务成功率的基准不可辨识探询能力）** 存在两个策略 π_A、π_B，它们在所有任务上的最终成功率分布完全相同，但探询后悔 R_probe 与损坏率不同（π_A 在稳健物体上做正确但无收益的探询，π_B 从不探询却碰巧成功）。因此任何只记录最终成功、不记录隐藏 h 与反事实结果的基准，都无法识别「探询是否值得」。系：GRIP-Bench 必须带特权真值与 CPO；这是构念效度的必要条件，而非可选项。

**命题 1（CPO 估计的无偏性）** 在仿真保真度假设下，对隐藏 h 与探询随机种子做期望，CPO 的三路重放给出 R_probe 的无偏估计；其方差随 h 采样数 N 以 O(1/√N) 下降。系：基准的可信度可以用置信区间报告，而不是单一榜单分数。

## 6. 本轮最大风险

**一句话**：CAGE-RAS 把不可逆伤害压缩成一个可计算的损坏预算 δ_dmg，但整个安全论证依赖损坏模型是真实失效模式的保守上界——**一旦模型漏掉内裂、疲劳、隐藏脆性或接触几何的分布外变化，认证实验盒就变成了给不可逆伤害盖章：在仿真里证明安全，在现实里第一次真正接触就碎**。

**次级风险与缓解**：
1. **损坏模型误设** → CVaR 最坏情况 + 模型族 ensemble + 真机牺牲件校准 + 不确定性高即弃抓；
2. **基准污染 / Goodhart** → 隐藏留出物理族 + 程序化生成 + 反基准识别 + benchmark_hash 入证书；
3. **探询时间破坏节拍** → 只允许轻触/加载阶段探询 + 探询预算 + 低速执行；
4. **柔顺硬件漂移** → GRIP-Live 监测 + 力/位移标定 + 继承 R68 COF；
5. **反事实 oracle 的仿真保真度** → L1–L4 分层 + sim_fidelity 入证书 + L3 真机牺牲件；
6. **弃抓被滥用成「安全地什么都不做」** → abstain 成本与交接协议 + 误弃抓指标 + 任务效用约束。

**结尾一句话**：本轮最大的风险是——我们用「认证过的探针盒」把不可逆的物理伤害变成了一个可计算的约束，但一旦损坏模型漏掉一种真实失效模式，认证就只是给不可逆伤害盖了一个漂亮的章。

class ContactPropertyModel:
    def posterior(self, o_hist, xi_hist):
        z, h_post = self.trunk(o_hist), self.flow_head(self.trunk(o_hist))
        J = self.fisher(h_post); Pi_id = identifiable_subspace(J, KAPPA_ID)
        return (h_post, Pi_id,
                entropy(project(h_post, Pi_id)),
                entropy(project(h_post, 1 - Pi_id)))     # U_unid 永进保守项

def certify_probe(g, h_post, phase, budget, cras):
    if not permiss(g, phase) or not budget.allow(g) or not cras.prefix_ok(g):
        return False
    return all(F_max(g) <= F_safe(h)
               and P_damage(g, h) <= DELTA_DMG
               and P_slip(g, h) <= DELTA_SLIP
               for h in cvar_plausible_set(h_post, ALPHA_CVAR))

                    for y, p in predict_outcomes(g, h_post, o))

            - worst_case_damage(g, h_post) * C_DMG
            - c_probe(g) - LAMBDA_IRR * irreversibility(g))

## 4. 推导

**引理 19（安全探询的信息上限 / CEP）** A99 下，两对象仅在脆性阈值上不同且低于阈值时观测同分布。任意最坏情况损坏 ≤ δ 的探针，其观测分布差异只能来自损坏事件，故 `TV(p₀,p₁) ≤ P(D₀∪D₁) ≤ 2δ`；Le Cam 两点下界给出 `err ≥ (1−TV)/2 ≥ 1/2−δ`。系：错误率 ≤ ε 需要损坏预算 `δ ≥ 1/2−ε`；**安全与确定不可同时任意逼近**。存在前兆（微裂声/刚度软化）时上界放松，发现前兆成为基准要测的能力。

**引理 20（柔顺的免费信息）** 被动柔顺 `δ = f/k_n + ε` 给出 `I_pass = f²/σ_ε² > 0`，高斯近似下后验熵至少降 `½log(1+I_pass σ_prior²)`，且不增加 `P_damage`。系：柔顺硬件是可预先投资的认知资本；同等信息下主动探询的损坏预算更低。

**引理 21（PIV 退化为 R69 VoI）** 当损坏、不可逆、探询成本均为零且 `U_task = −H` 时，PIV 退化为 R69 的熵减 VoI；当 `𝒢_cert = ∅` 或 `max PIV_LCB ≤ 0` 时，接触决策逐指令退化为 R69 不交互分支；无接触观测时整体退化为 R69/R68。

**定理 18（保守优势与严格包含）** 在 A99–A102 与认证实验盒下：`P_damage ≤ δ_dmg + ε_cal`；CAGE-RAS 期望任务效用 ≥ R69 的不可物理探询策略（不探询动作始终在候选集，且用 LCB 比较）；无正 PIV 认证探针时行为与 R69 不交互分支逐指令相同。安全不让步，效率侧获得接触分辨率红利。

**定理 19（仅成功率基准的不可辨识性）** 存在两个策略 π_A、π_B：最终成功率分布相同，但探询后悔与损坏率不同。故仅记录任务成功、不记录隐藏 h 与反事实的基准无法识别「探询是否值得」；GRIP-Bench 必须带特权真值与 CPO。这是构念效度的必要条件。

**命题 1（CPO 无偏性）** 在仿真保真度假设下，对 h 与探询种子取期望，CPO 的三路重放给出 `R_probe` 的无偏估计，方差 `O(1/√N)`；基准可信度应以置信区间报告，而非单一榜单分数。

## 7. 本轮最大风险

**一句话**：CAGE-RAS 把不可逆伤害压缩成一个可计算的损坏预算 δ_dmg，但整个安全论证依赖损坏模型是真实失效模式的保守上界——**一旦模型漏掉内裂、疲劳、隐藏脆性或接触几何的分布外变化，认证实验盒就变成了给不可逆伤害盖章：在仿真里证明安全，在现实里第一次真正接触就碎**。

**次级风险与缓解**：损坏模型误设（CVaR + ensemble + 真机牺牲件 + 高不确定即弃抓）；基准污染/Goodhart（隐藏留出族 + 程序化生成 + 反基准识别 + benchmark_hash 入证书）；探询时间破坏节拍（阶段限制 + 探询预算 + 低速）；柔顺硬件漂移（GRIP-Live + 力/位移标定 + R68 COF）；仿真保真度（L1–L4 分层 + sim_fidelity 入证书）；弃抓滥用（abstain 成本 + 交接协议 + 误弃抓指标）。

**结尾一句话**：本轮最大的风险是——我们用「认证过的探针盒」把不可逆的物理伤害变成了一个可计算的约束，但一旦损坏模型漏掉一种真实失效模式，认证就只是给不可逆伤害盖了一个漂亮的章。
