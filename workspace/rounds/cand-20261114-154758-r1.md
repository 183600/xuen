# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「课程学习」×「续航能力」）

> R69 给了闭环一张「嘴」：把不确定性拆成 aleatoric / epistemic，用流匹配多模态策略 + 主动交互去问、去看、去碰。但它默认了两个常量：**(a) 问是廉价的**——VoI 减去一个静态社交成本就完事；**(b) 问过就忘**——这次消解的歧义，下次还要重新问。对插电的短程任务这没问题；对要连续工作数小时乃至数天的移动系统，这会把「会提问」变成「会耗电」：系统可能在一次无关紧要的犹豫上花光返航电量，也可能反复追问同一件事，而真正可学的歧义从未被系统性地学会。
>
> 本轮两个灵感正好补上两块缺失：
> - **课程学习**：不是所有歧义都值得现在学。按「可学性 × 难度」排序（最近发展区），先学能显著降低未来交互需求的类别，掌握即停止；把一次性的「问」变成可积累的「能力」。
> - **续航能力**：注视、探针、移动、语言查询都消耗能量/热/社交注意力；长时程系统的目标不是单步 VoI 最大，而是「每焦耳的任务成功率」最大，且永不低于安全返航储备。
>
> 核心命题：**把 R69 的交互从「无记忆的单步 VoI」升级为「有预算、有课程、有记忆的续航型主动消歧」**：用能量影子价格给 VoI 定价（E-VoI），用课程调度器把有限的交互能量分配给「最可学、最能减少未来交互」的歧义类，用认证消解缓存把已解决的歧义固化成可复用先验，用能量储备盾保证任何提问都不吃返航/安全电量；当预算耗尽或缓存不可信时，严格退化回 R69（再退 R68）。命名 **ENDURE-RAS**（Energy-aware, Novelty-graded, Difficulty-scheduled, Uncertainty-Resolving Embodied loop）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这点电、这点时间，先学什么、问什么、什么可以不问**」——不确定性管理不只是刹车和提问，还是一门关于注意力的经济学。

## 0. 直觉与动机

**灵感 1（课程学习 → 交互是可积累的能力，不是一次性消费）**
直觉：人类小孩不会随机问问题，也不会只问最难的；他们在「跳一跳够得着」的区间里学得最快。R69 的 VoI 是一个 myopic 量：它只知道「问了之后这一步的熵降多少」，不知道「学会之后以后都不用问」。课程学习提供第二个轴：**学习进展（learning progress）**——同一类歧义，解决一次后下次解决得更快/更省，才值得优先投入。把「消解歧义」看成学习一个概念，则存在难度 d_c、可学性 LP_c、掌握阈值；调度器应优先选择 `LP_c / 能量` 最大的类别，并在掌握后停止。这样交互次数随经验下降，续航随经验上升。

**灵感 2（续航能力 → 能量是硬预算，不是软惩罚）**
直觉：R69 的交互预算「单位时间 ≤ 1 次」管的是频率，不管总能量；而续航是一个**跨时间耦合**约束：现在花的 1 焦耳，可能就是返航时的 1 焦耳。把能量状态 e_t、安全储备 e_res、能量影子价格 μ_t 引入：μ_t 在电量充足时低（信息便宜），在接近储备时高（信息昂贵）。于是同一个 VoI，满电时值得问、低电时不值得问——不是因为它不重要，而是因为**现在问它的机会成本是安全返航**。这就是约束优化里的对偶价格，也是「续航感知」的严格形式。

**灵感 3（课程 × 续航 → 每焦耳学习进展）**
直觉：课程学习天然有「太简单不值得学、太难学不会」的两端；续航给它加了第三个约束「太贵学不起」。三者交集就是**最近发展区 + 能量预算**：只学那些「在剩余电量内可被解决、且解决后能显著减少未来交互」的歧义。这把 R69 的「可约的歧义才交互」细化为「**可学且付得起的歧义才交互**」。

**灵感 4（缓存 → 把一次消解变成长期续航）**
直觉：如果每次遇到同一类歧义都重新采样、重新问，课程就白学了。需要一个认证消解缓存：把「在条件范围 S 内，歧义类 c 已由 k 个正交源确认为 m*」写成带出处、有效期、适用范围的概念条目；下次命中就直接降低 U_epi 先验。它是**只读**的（控制回路不训练），巩固只发生在充电/安全停靠窗口。缓存把「省电」和「变强」接起来：越用越省，越省越能走远。

**灵感 5（课程与缓存也是攻击面 → 续航型威胁模型）**
直觉：一旦系统按「学习进展/能量」排序，就有了新的作弊方式：伪造电量让系统少问、污染课程让系统只学简单类别、投毒缓存让一次谎言被永久复用、用「耗电查询」做拒绝服务。「越省电越不复检」意味着**一次错误可能被固化成一生的能力**。因此必须交付：能量账本认证、返航储备盾、缓存出处与失效、尾部类别保底、课程审计。否则 ENDURE 不是让系统走得更远，而是让它更快地走向一个被固化的错误。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（ENDURE-RAS 总览）** ENDURE-RAS = (EBS, EVI, CUS, CFL, CRC, MEC, ERS, RAS-WM†)。四条不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；控制回路只允许经审计的只读缓存查询与有界记账，不允许梯度更新策略）；
(ii) **能量账本硬约束**：任意信息动作 g 的能量消耗计入 e_t，且执行后余量不得低于安全储备；交互频率/位移/社交预算继承 R69 定义 293-ii；
(iii) **课程安全无关性**：课程调度只决定「何时问、问什么、问到什么分辨率」，绝不改变 C-RAS-WM 安全包络与 λ floor 的构造；
(iv) **退化次序**：预算不足/缓存不可信/尾部保底触发 → R69；R69 的 VoI≤成本或 ECE 越界 → R68。

**定义 311（续航状态与多资源预算）** e_t = (e^bat_t, e^thm_t, e^att_t, e^time_t) ∈ ℝ⁴≥0：电量、热余量、社交注意力、任务时间；动作 (a,g) 的消耗向量 c(a,g)；充电/散热/恢复输入 r_t。安全储备 e_res（四分量下限）。续航余量 m_t = min_i (e^i_t − e^i_res)。m_t < 0 ⇒ 进入返航/停靠模式，禁止一切信息动作。

**定义 312（能量影子价格）** 设任务效用 U、总能量预算 E_mission。μ_t ≥ 0 为「1 焦耳在 t 时刻的边际任务效用」，由对偶上升或漂移加惩罚在线更新：μ_{t+1} = [μ_t + η·(e_target − e_t)]⁺（余量越低，μ 越高）。μ_t=0 表示能量不稀缺；μ_t→∞ 表示能量成为唯一约束。

**定义 313（续航感知 VoI，E-VoI）** 信息动作 g 的拉格朗日净值
U_E(g) = α·VoI(g) − c_soc(g) − μ_t·e(g)，
其中 α 为 nats→任务效用的换算，e(g) 含采样 K、注视、探针、LLM 查询的能量。交互条件：max_g U_E(g) > 0，且 e_t − e(g) ≥ e_res + e_tail，且 g 通过 C-RAS-WM 认证。辅助排序量 EVR(g) = (α·VoI(g) − c_soc(g)) / (e(g)+ε) 用于「每焦耳价值」比较。**μ_t=0、e(g) 为常数时，U_E 与 R69 的 VoI−c 同序。**

**定义 314（歧义类与课程骨架）** 歧义类 c = (语义类别, 条件范围 S_c)，如「笑容是否真诚」「地面是否承重」「此门是否可通过」。每个类有难度 d_c ∈ [0,1]（由 R69 的 Δ_min、U_epi、观测质量估计）、可学性 LP_c、掌握度 κ_c ∈ [0,1]、安全关键度 σ_c ∈ {0,1}。课程骨架 C={c} 为有限集（|C| ≤ C_max），由离线课程编译 + 审计统计维护。

**定义 315（学习进展）** LP_c = E[ΔH_c]·(1−κ_c) / (e_c+ε)：尚未掌握的残余熵 × 单位能量可降熵。更贴近部署的定义：LP_c = E[ΔE_future(c)] / (e_c+ε)，其中 ΔE_future(c) 为掌握 c 后未来交互能量的期望下降（由 AuditBuf 的配对前后统计估计）。

**定义 316（最近发展区门控 ZPD）** 仅当 d_c ∈ [d_lo, d_hi]、0 < LP_c < ∞、且 (1−κ_c) > τ_mastery 时才把 c 纳入候选；d_c < d_lo（太简单/已会）或 d_c > d_hi（当前不可学）不调度。σ_c=1 的安全关键类不受 d_hi 上限约束（尾部保底，见定义 322）。

**定义 317（分辨率阶梯 CFL）** 对类 c，信息动作有 L+1 档：ℓ=0 缓存/先验（零新增能量），ℓ=1 廉价一瞥（K=1 + mode_head），ℓ=2 主动注视，ℓ=3 触/力探针，ℓ=4 语言询问，ℓ=5 多源交叉验证。e_ℓ 随 ℓ 单调增，ΔH_ℓ 边际递减。选择 ℓ*(c) = min{ℓ : (1−κ_c)·ΔH_ℓ(c) ≥ ΔH_req(c; μ_t)}，即**够用即止**——不用探针解决一个瞥一眼就能解决的问题。

**定义 318（课程调度器 CUS）** 每轮从候选中选
c* = argmax_c [ LP_c · σ_c^γ / (1 + d_c) ]（或按 LP_c / e_{ℓ*(c)} 排序），
s.t. 能量与频率预算。调度器是「睡眠老虎机」：只在有限课程表上选择，不训练策略；其统计量写入 AuditBuf，受总变差预算约束。

**定义 319（掌握与停止）** κ_c 由认证消解缓存命中率与后验熵更新；当 κ_c ≥ κ_master 且缓存失效检测通过率 ≥ τ_valid，停止对 c 的主动交互，转为 ℓ=0 先验。掌握不是永久：缓存过期/OOD/审计红旗 ⇒ κ_c 回退，c 重新进入课程。

**定义 320（认证消解缓存 CRC）** 条目 x = (c, S_c, m*, provenance, k-source, t_created, t_expire, novelty_key, signature)。查询时仅当 (i) 条件在 S_c 内，(ii) novelty_key 匹配（R69 定义 301 的 Δa 与 OOD 检测通过），(iii) 未过期，(iv) 审计未红旗，才允许把 m* 作为先验注入：U_epi ← (1−β)·U_epi，β ∈ [0, β_max]。缓存只是先验，**永不把 U_epi 降到 U_epi_min 以下，也永不单独满足证据纪律**；控制回路只读缓存，绝不写入。

**定义 321（巩固与有意遗忘 MEC）** 仅在充电/安全停靠窗口执行巩固：把已消解且通过 k 源一致的条目写入 CRC；巩固能量 e_cons 计入预算，仅当预期未来节省 > e_cons/η_cons 才执行。条目按效用 u_c = 命中频次 × 任务价值 − 检索成本排序；超出容量 C_cache 时淘汰低效用且非安全关键条目（有意遗忘），σ_c=1 条目永不被淘汰。

**定义 322（能量储备盾 ERS）** 安全储备 e_res 与尾部保底 e_tail（每任务周期预留 τ_tail 比例能量给罕见安全关键类）。任一信息动作 g 必须满足 e_t − e(g) ≥ e_res + e_tail；否则禁用交互，U_epi 未消解，走 R69/R68 保守。尾部保底触发时，即使 LP_c 低，也必须至少完成一次 σ_c=1 类抽检。

**定义 323（三级退化）** 能量充足、缓存可信、课程有候选 → ENDURE 正常交互；μ_t 过高/储备不足/缓存不可信 → 只读先验、不交互，等价 R69（U_epi 未消解）；R69 条件也不满足（VoI≤成本、ECE>τ_ece）→ R68 纯保守。退化沿「信息获取量」单调不增，安全侧永不弱化。

**定义 324（续航证书 J_ENDURE）** J_ENDURE = (J_FLUID, energy_ledger_hash, e_remaining, reserve_margin, e_voi_ratio, curriculum_regret, cache_hit_rate, cache_provenance_ok, tail_coverage, consolidation_energy, endur_ver)。Valid ⇔ Valid(J_FLUID) ∧ 能量账本自洽 ∧ reserve_margin ≥ 0 ∧ tail_coverage ≥ τ_tail ∧ 缓存出处/失效检查通过 ∧ 无实时学习写。

**定义 325（续航型对抗集 AIC-ENDURE）** ℰ_ENDURE = ℰ_FLUID × ℰ_energy × ℰ_curr × ℰ_cache。ℰ_energy：电量/热/注意力欺骗、耗电查询 DoS；ℰ_curr：难度/可学性标签投毒、课程优先级 Goodhart、尾部类饥饿；ℰ_cache：缓存投毒、陈旧复用、作用域越界、出处伪造。

**定义 326（课程/能量审计 VQAuditor-E）** 审计：能量账本与动作日志是否一致；课程优先级是否按声明策略（而非被学习的「逃避难类」）；尾部类覆盖率；缓存条目出处与 k 源一致；巩固是否发生在允许窗口。红旗 ⇒ 冻结相应缓存/课程项，回退 R69。

**定义 327（续航-学习对偶）** 对一个歧义类 c，主动交互的能量成本 e_c 与缓存/课程带来的未来节省 ΔE_future(c) 构成一对「投资-回报」；当且仅当 ΔE_future(c) > e_c/η_learn（η_learn 为学习效率）时，课程才值得安排 c。这把「续航」从约束变成可投资本：花费可再生的注意力/能量，换取不可逆的能力增长，但回报必须在证书中可核验。

# IP-265 EVI：续航感知 VoI（μ=0 时严格退化为 R69）
def endurance_voi(cands, modes, w, o_t, mu_t, e_state, reserve):
    best = None
    for g in cands:
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o_t):
            continue
        e_g = energy_model(g, K=budget.K(g), o_t)
        if e_state - e_g < reserve.e_res + reserve.e_tail:
            continue                                   # ERS：返航电量不可动
        voi = entropy(w) - expected_entropy(w, g, o_t)
        u   = alpha * voi - cost(g) - mu_t * e_g      # 拉格朗日净值
        if u <= 0:
            continue
        if best is None or u > best.u:
            best = (g, u, e_g)
    return best                                        # None -> R69/R68 退化

# IP-266/268 CUS：课程调度（有限表 + 审计统计，不训练策略）
def schedule_curriculum(classes, kappa, lp, d, sigma):
    cand = [c for c in classes
            if d[c] >= D_LO and (d[c] <= D_HI or sigma[c] == 1)
            and (1 - kappa[c]) > TAU_MASTERY]
    if not cand:
        return None
    return max(cand, key=lambda c: lp[c] * (SIGMA_W ** sigma[c]) / (1 + d[c]))

# IP-268 CFL：分辨率阶梯，够用即止
def choose_fidelity(c, kappa, dh_req, energy):
    for l in range(0, L + 1):
        if (1 - kappa[c]) * dh_hat[c][l] >= dh_req:
            if energy.afford(c, l):
                return l
    return None                                        # 付不起 -> 不交互

# IP-270 CRC：只读缓存查询（作用域 / 新颖度 / 有效期 / 审计 四检）
def cache_lookup(c, o_t):
    x = crc.retrieve(c, novelty_key(o_t))
    if x is None:
        return None
    if not in_scope(x.S, o_t):
        return None
    if ood_or_flow_anomaly(o_t, x):                    # 复用 R69 的 Δa
        return None
    if now() > x.t_expire or auditor.red_flag(x):
        return None
    return x.mode                                      # 仅作先验，β 受限

# IP-274 主闭环（继承 R69，仅在交互决策前插入续航课程层）
def ENDURE_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    mu = M.ebs.shadow_price()                          # 能量影子价格
    U_ale, U_epi, modes, _ = M.aud.decompose(
        M.fmp.sample(o, M.k), z, M.fmp.mode_head)
    # 0) 缓存先验（只读，且只降低不归零）
    hit = M.crc.lookup(M.cus.current_class(), o)
    if hit is not None:
        U_epi *= (1 - BETA_MAX)
    # 1) 课程选类 -> 分辨率档 -> E-VoI 决策
    cls = M.cus.select(M.classes, M.mec.kappa, M.ebs.e, mu)
    lvl = (M.cfl.choose(cls, M.mec.kappa, M.dh_req(cls, mu), M.ebs.e)
           if cls else None)
    g = (M.evi.choose(M.cfl.candidates(cls, lvl), modes, o, mu,
                      M.ebs.e, M.ers)
         if lvl is not None else None)
    # 2) 交互或退化（E-VoI<=0 / 储备不足 => R69 兜底）
    if g is not None:
        ans = M.cia.execute(g)                         # 认证 + 证据纪律
        U_epi = M.cia.update_belief(modes, ans)
        M.mec.note_outcome(cls, ans, g)                # 仅审计统计，不训练
        M.consolidate_if_charging(cls, ans)            # 仅充电窗口写 CRC
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(
        M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if M.ers.critical() or M.ebs.margin() < 0:         # 三级退化：R68
        lam, g = max(lam, 0.8), None
    mode = select_mode(modes, U_epi, lam)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_e.submit_async(g, cls, lvl, U_epi, M.ebs.ledger)
    return k, lam, mode, (U_ale, U_epi, mu)

## 3. 推导

**引理 19（能量影子价格的阈值最优性）** 对拉格朗日量 L = U_task + μ·(E_mission − E_consumed)，任一平稳策略下使 L 最大的交互决策为：当且仅当 α·VoI − c_soc ≥ μ·e(g) 时交互；μ 为能量约束的对偶价格。若值函数对能量是凸的，该阈值策略最优；EVR 是它的「每焦耳」排序。系：**μ=0 严格退化为 R69；μ→∞ 严格退化为「永不交互」的 R68 边界。** 这把「省电」从拍脑袋的惩罚项变成有对偶解释的约束。

**引理 20（课程学习进展的可加性与贪心近似）** 若各类的预期未来能量节省 ΔE_c ≥ 0，且总节省对已调度类集合单调次模（掌握重叠概念带来递减回报），则按 LP_c/e_c 排序并配合掌握停止，可得到最优能量节省组合的 (1−1/e) 近似；且每掌握一个类，未来期望交互能量下降至少 (κ_master−κ_c)·e_c。系：**课程不是「更努力地问」，而是让需要问的次数随经验单调下降。**

**引理 21（缓存先验的校准与污染上界）** 缓存以 β≤β_max 注入先验。即使条目被投毒，后验偏移至多 β_max（且 k 源出处使投毒成功率先按 R69 引理 18 衰减 ρ^{k−1}）；又因 β_max 与 U_epi_min 设定保证 `U_epi ≥ U_epi_min > τ_epi`，单一缓存命中永远不能把歧义「认证为已解决」。系：**缓存可以省电，但不能代替证据纪律**——这是把最大风险关进笼子的关键结构。

**定理 18（ENDURE 严格包含 FLUID / R68）** 在 A95–A98 与有界能量模型下：
(i) μ=0、e_res=e_tail=0、缓存关闭、单一课程类、固定分辨率时，ENDURE 的交互决策与 FLUID-RAS 逐指令一致（定义 313、323）；
(ii) 对任意 μ≥0，因能量而跳过交互只会让 U_epi 保持未消解（λ floor 单调不减），安全包络不被改变，故单步物理风险 ≤ FLUID-RAS，不引入任何新的不安全动作；
(iii) 当 FLUID 也拒绝交互（VoI≤成本、ECE>τ_ece）时，ENDURE 与 R68 逐指令一致。
故安全侧 R68 ⊂ FLUID ⊂ ENDURE；效率侧 ENDURE 多出一条「能量约束下的 Pareto 前沿」。

**定理 19（续航预算可行性与安全停止）** 设每步交互能量有界，μ_t 按对偶上升更新，且 ERS 生效。则在有界能量采集/有界噪声下，累计交互能量满足 Σ e_t ≤ E_mission − e_res（以概率 ≥ 1−δ），且 margin<0 时系统进入安全返航/停靠模式；漂移加惩罚给出期望续航下界 ≥ (E_mission−e_res)/max_t E[e_t] − O(√T)。**续航因此成为证书中的可计算量，而不是一句愿望。**

**定理 20（课程-缓存闭环的后悔与尾部保底）** 把课程类视为未知 LP_c/e_c 的臂，CUS 在有限类集 C 上做 UCB 式探索，其相对神谕排序的后悔 ≤ O(√(T|C| log T))，同时受能量预算约束；掌握会移除臂，缓存命中会降低单臂成本，二者共同降低后悔与能耗。尾部保底（定义 322）额外牺牲常数比例的探索预算 τ_tail，换取对安全关键类的**与 LP 排序无关的最坏情况覆盖**。

**定理 21（课程/缓存不破坏控制连续性）** 课程切换、分辨率切换或缓存命中只改变先验 U_epi 与所选模态；C-RAS-WM 认证前缀与 λ_floor 构造不变。交互失败/超时/缓存失效时 U_epi 单调回升，λ 回到 R69/R68。故 R69 定理 17（交互安全、无突变）保持：**省电策略永远不会让系统变得更激进。**

## 6. 本轮最大风险

**一句话**：ENDURE 的全部效率来自「少问、多记、按课程学」，但这也意味着**一次错误一旦通过证据纪律被写进缓存/课程，就会被系统当作「已经学会」而长期免检复用**——课程把单次错误放大成持续能力，缓存把一次谎言变成一生先验；系统越省电，就越不愿意为复检花电，于是「续航能力」与「认识论警觉」互为代价。

**次级风险与缓解**：
1. **尾部类饥饿**（课程按平均学习进展排序，系统性忽视罕见但高风险的歧义）→ 安全关键类 d_hi 豁免 + e_tail 尾部保底 + E309/E311；
2. **缓存投毒/陈旧复用** → 出处签名 + 作用域/新颖度/有效期四检 + β_max 与 U_epi_min 下限 + k 源证据纪律 + E308；
3. **能量/热状态欺骗**（伪造低电量诱导少问，或伪造高电量诱导耗尽）→ 多源能量估计 + 账本哈希 + ERS 硬约束 + E310；
4. **课程优先级 Goodhart**（优化 LP 指标而逃避难类）→ VQAuditor-E 审计 + 周期性尾部抽检 + 与「难度覆盖」联合约束；
5. **巩固能量吃掉续航**（为了未来省电反而现在耗电）→ 仅在高收益且充电窗口执行，投入产出比进证书；
6. **实时预算**（缓存检索/课程选择击穿控制周期）→ ANN 检索 + 有限课程表 + 仅歧义时触发 + E315 消融。

# IP-265 EVI：续航感知 VoI（μ=0 时严格退化为 R69）
def endurance_voi(cands, modes, w, o_t, mu_t, e_state, reserve):
    best = None
    for g in cands:
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o_t):
            continue
        e_g = energy_model(g, K=budget.K(g), o_t)
        if e_state - e_g < reserve.e_res + reserve.e_tail:
            continue                                   # ERS：返航电量不可动
        voi = entropy(w) - expected_entropy(w, g, o_t)
        u   = alpha * voi - cost(g) - mu_t * e_g      # 拉格朗日净值
        if u <= 0:
            continue
        if best is None or u > best.u:
            best = (g, u, e_g)
    return best                                        # None -> R69/R68 退化

    if x is None or not in_scope(x.S, o_t):
        return None
    if ood_or_flow_anomaly(o_t, x):                    # 复用 R69 的 Δa
        return None
    if now() > x.t_expire or auditor.red_flag(x):
        return None
    return x.mode                                      # 仅作先验，β 受限

# IP-274 主闭环（继承 R69，仅在交互决策前插入续航课程层）
def ENDURE_RAS_round(M, obs):

           if cls else None)
    g = (M.evi.choose(M.cfl.candidates(cls, lvl), modes, o, mu,
                      M.ebs.e, M.ers)
         if lvl is not None else None)
    if g is not None:                                  # 2) 交互或退化
        ans = M.cia.execute(g)
        U_epi = M.cia.update_belief(modes, ans)
        M.mec.note_outcome(cls, ans, g)                # 仅审计统计
        M.consolidate_if_charging(cls, ans)            # 仅充电窗口写 CRC
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(
        M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if M.ers.critical() or M.ebs.margin() < 0:         # 三级退化：R68
        lam, g = max(lam, 0.8), None
    mode = select_mode(modes, U_epi, lam)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_e.submit_async(g, cls, lvl, U_epi, M.ebs.ledger)

## 4. 推导

**引理 19（影子价格阈值最优性）** 拉格朗日量 `L=U_task+μ(E_mission−E_consumed)` 下，使 L 最大的交互决策为 `αVoI−c_soc ≥ μ·e(g)`；值函数对能量凸时阈值策略最优，EVR 是其每焦耳排序。系：μ=0 严格退化为 R69，μ→∞ 严格退化为 R68 的「永不交互」边界。

**引理 20（课程贪心与单调性）** 若各类未来节省对已掌握集合单调次模，按 `LP_c/e_c` 排序 + 掌握停止达到最优能量节省组合的 `(1−1/e)` 近似；每掌握一类，未来期望交互能量至少下降 `(κ_master−κ_c)e_c`。系：课程让「需要问的次数」随经验单调下降。

**引理 21（缓存先验的污染上界）** 缓存以 `β≤β_max` 注入先验；即使被投毒，后验偏移至多 `β_max`，且 k 源出处使投毒成功率先按 R69 引理 18 衰减 `ρ^{k−1}`；又因 `β_max` 与 `U_epi_min>τ_epi`，**单次缓存命中永不单独把歧义认证为已解决**。缓存能省电，但不能替代证据纪律。

**定理 18（ENDURE 严格包含 FLUID / R68）** A95–A98 与有界能量下：(i) μ=0、无储备、缓存关、单课程、固定分辨率时与 FLUID 逐指令一致；(ii) 任意 μ≥0 下，能量性跳过只让 U_epi 未消解（λ floor 单调不减），安全包络不变，单步物理风险 ≤ FLUID；(iii) FLUID 也拒绝交互时与 R68 一致。安全侧 R68 ⊂ FLUID ⊂ ENDURE；效率侧多出能量约束下的 Pareto 前沿。

**定理 19（续航预算可行性与安全停止）** 每步交互能量有界、μ 按对偶上升、ERS 生效时，累计交互能量 `Σe_t ≤ E_mission−e_res`（概率 ≥1−δ），margin<0 即进入安全返航/停靠；漂移加惩罚给出期望续航下界 `(E_mission−e_res)/max_t E[e_t] − O(√T)`。

**定理 20（课程-缓存后悔与尾部保底）** 有限课程集上的 UCB 式 CUS 相对神谕排序后悔 ≤ `O(√(T|C|log T))` 且受能量预算约束；掌握移除臂、缓存降低单臂成本，共同降低后悔与能耗；尾部保底以常数探索比例 `τ_tail` 换取与 LP 排序无关的安全关键类最坏覆盖。

**定理 21（无突变）** 课程/分辨率/缓存只改先验 U_epi 与所选模态；C-RAS-WM 认证前缀与 λ_floor 不变；交互失败/超时/缓存失效时 U_epi 单调回升、λ 回 R69/R68。R69 定理 17 保持：**省电策略永不让系统更激进。**

## 7. 本轮最大风险

**一句话**：ENDURE 的全部效率来自「少问、多记、按课程学」，但这也意味着**一次错误一旦通过证据纪律被写进缓存/课程，就会被系统当作「已经学会」而长期免检复用**——课程把单次错误放大成持续能力，缓存把一次谎言变成一生先验；系统越省电，就越不愿意为复检花电，于是「续航能力」与「认识论警觉」互为代价。

**次级风险与缓解**：尾部类饥饿（安全关键类 d_hi 豁免 + e_tail 尾部保底 + E309/E311）；缓存投毒/陈旧复用（出处签名 + 四检 + β_max/U_epi_min 下限 + k 源证据纪律 + E308）；能量/热状态欺骗（多源能量估计 + 账本哈希 + ERS 硬约束 + E310）；课程优先级 Goodhart（VQAuditor-E + 周期性尾部抽检 + 难度覆盖约束）；巩固能量吃掉续航（仅高收益充电窗口 + 投入产出比进证书）；实时预算（ANN 检索 + 有限课程表 + 仅歧义触发 + E315）。
