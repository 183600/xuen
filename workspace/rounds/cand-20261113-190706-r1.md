# 第 69 轮（承接第 68 轮 CALM-RAS IP-243~252；灵感循环新循环第 1 轮；本轮灵感：「最小可行产品」×「对话管理」）

> 第 68 轮 CALM-RAS 把「测量可信度」做成在线潜变量，却在其自陈风险里留下一个结构性隐患：整套闭环的安全底座是**一条单边防线**（标定速率限制 + canary），而且为追求同源一致，架构被收敛成一个越来越厚的**单体**（单 trunk 五头 + EKF + 五关 + 一份证书）。单体压低了共模噪声，也制造了共模盲区：慢故障一旦落在标定带宽内，共享 trunk 的所有头会一起「相信一切正常」。更根本的是，前三轮的全部药方都是「再加一个内部推断层」——感知（R65）→ 标定（R68）→ 世界模型（R67）→ 认证提交（R68）——架构单调增厚，却从未回答两个问题：**(a) 这一层真的带来了可验证的边际价值吗？(b) 当内部推断自身形成自我确认的闭环时，谁从外部把它打破？**
>
> 本轮的两个灵感恰好是这两问的答案，而且它们本来就是一个闭环的两半：
>
> - **最小可行产品（MVP）**：先做最小可验证内核，部署到真实使用者，用反馈决定下一步；每一层都要用「边际价值 > 成本」证明自己，否则剪掉。
> - **对话管理（DM）**：维护对伙伴的信念状态，用有限的对话动作（确认 / 澄清 / 解释 / 交接）降低不确定性，并在误解时**修复**。
>
> 合流成一句命题：**MVP 缺的正是「来自使用者的反馈通道」，而对一个与人类协作的机器人，这个通道就是对话；反过来，对话若不受「信息价值必须为正」约束，就会退化成无休止的过度询问。于是「最小可行」成为对话策略的准则，「对话」成为最小可行迭代的传感器——安全不再只靠更强的内部推断，而靠一个可验证的外部反馈闭环。**
>
> 命名：**DiaRAS（Dialogue-mediated, Minimal-viable Risk-Adaptive System）**。一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**我不确定的事，该不该问、问什么、问完信多少**」。

## 0. 直觉与动机

### 灵感 1（最小可行产品 → 用「边际价值」给 68 轮架构做减法）

直觉：MVP 的第一性原理不是「做得少」，而是「**只保留能被真实反馈证明有价值的东西**」。R68 的 CALM-RAS 是一个典型反例：单 trunk 五头、EKF、五关认证、一整套证书——每一件都能自圆其说，但没有一件被**单独计量过边际安全增益**。复杂度不是免费的：它带来延迟、不透明、误报，以及最隐蔽的**信任成本**（操作者不理解系统为何收紧，就会绕过它）。

于是本轮把 MVP 落成两个可执行对象：
1. **最小可行内核 MVK**：从 R65–R68 中裁出「删掉任何一个都会破坏安全界」的最小子集 K*；其余模块一律降级为**特性开关**（feature flag），开关状态由带置信下界的边际价值 v_f 决定；
2. **复杂度预算 C_max**：任何新能力上线都要在延迟 / 内存 / 不透明度上「付账」，超预算必须先剪枝再加新。

这不是否定 R68，而是给 R68 装上「可证伪」的接口：**一个模块若无法在留出集上证明自己，就不配待在安全链路里。** 需要强调的是，MVP 的「最小」是**相对于已验证分布**而言的，不是绝对最小——这一点会在定理 18 里成为本方案最尖锐的自我限制。

### 灵感 2（对话管理 → 安全缺失的执行器是「一次询问」）

直觉：任务型对话系统早就解决了 R68 的同类难题——伙伴意图不可直接观测。它们的答案不是「再建一个内部模型」，而是：维持信念状态 b_t，选择对话动作（询问 / 确认 / 告知 / 澄清），在误解时**修复**。R68 把「不确定」一律映射为「收紧 λ」。但收紧是**单边的**：人不知道为什么被收紧、无法纠正机器人的错误信念，甚至会绕开它。对话补上的正是这个缺失的执行器：**关于人类意图 / 同意的某些不确定性，从原理上无法靠追加传感器消除，只能靠「花一个回合去问」来消除。**

关键迁移：
- **信念状态跟踪（BST）** 跟踪人的意图 g、授权 a、注意力 α、能力 κ，而不是只更新机器人的世界状态；
- **对话策略** 在 ACT / CONFIRM / CLARIFY / EXPLAIN / HANDOVER / WAIT 之间选；
- **修复协议（REP）** 检出「人的回答与机器人信念矛盾」这类**对话残差**，有限次修复，超预算就交回人类。

### 灵感 3（合流 → 一个准则：「价值为正才动作」）

把 MVP 的边际价值与对话的 VoI 写成同一个量：**任何动作（加模块、升自动化、问一句）都应满足「它降低风险的期望收益 > 它的成本」。** 于是：
- 对**架构**：特性开关只在 LCB(v_f) > κ 时打开（少即是多）；
- 对**交互**：只在 VoI(m) > 0 时询问（问即是问）；
- 对**自动化等级**：只在「新增自动化」的 VoI 置信下界 > 0 时升级（升即是证）。

这把「最小可行」从口号变成一条可优化的准则，也把「对话」从交互技巧变成安全机制：**沉默的收紧**与**无休止的询问**是同一枚硬币的两面，都由 VoI 校准。

### 灵感 4（六件套 → DiaRAS 的组成）

1. **MVK + FLG**：最小可行内核 + 特性开关 / 复杂度预算（架构侧 MVP）；
2. **BST**：人类意图 / 授权 / 注意力 / 能力的贝叶斯信念跟踪（与 R68 MTM 共享 z_t，新增 dialogue head）；
3. **VoI-DP**：价值信息对话策略，只在询问比行动更值钱时才问；
4. **REP**：有界修复协议，超预算强制交接；
5. **MLADDER**：最小可行安全阶梯 L0–L5，每级是「一个可验证的 MVP」，逐级认证升降；
6. **RAS-D†**：R65–R68 的感知 / 标定 / 归因 / 认证核保留，但 λ、认证前缀 k、以及「是否必须问」由对话信念调制。

### 灵感 5（对症下药：R66–R68 的三个遗留风险）

- **R68 缓变故障被标定吸收**：人对「读数是否合理」有独立于传感器的判断力；当内部风险或新颖性触发时，一个 CONFIRM 就是一条正交的检测通道（引理 19）。这是「标定越强、慢故障越隐形」的解药：**让人类直觉去做最后审计**——但必须承认它可能疲劳、可能被欺骗（见第 6 节）。
- **R66 欺骗 / R67 黑箱误放宽**：EXPLAIN 让收紧变得可理解、可反驳；对话残差（人不同意）本身是「错误信念」的告警，而不是噪声。
- **R65 目标歧义 vs 测量歧义**：必须区分「世界没看清」与「人没问清」——前者靠标定，后者只能靠 CLARIFY；把两者混在一个 H_sensor 里正是历轮误归因的根源。
- 既有纪律延伸为：**对话只收紧，绝不放宽**——H(b_t) 高或 a_t = unknown ⇒ λ 下限抬升；a_t = deny ⇒ 直接交接。

## 1. 形式化定义（增量：定义 293–310）

**定义 293（DiaRAS 总览与五不变式）** DiaRAS = (MVK, FLG, BST, VoI-DP, REP, MLADDER, RAS-D†)。不变式：
(i) **预留优先（reserve-first）**：任一对话回合 pending 时，控制内环无条件走预留策略 Π_reserve；内环从不阻塞等待人类；
(ii) **最小性**：K* 之外模块均为特性开关，开启需 LCB(v_f) > κ；
(iii) **有界修复**：每个任务 REP 回合 ≤ B_repair = 2，超限强制 HANDOVER（安全终态）；
(iv) **对话只收紧**：λ_t ≥ max(λ_RAS, λ_floor(U), λ_dial(b))；a_t = deny ⇒ λ = 1；
(v) **同意完整性**：不可逆动作需显式同意，且 nonce 一次性，禁止重放 / 复用。

**定义 294（最小可行内核 MVK）** 设 R68 模块集 M_R68 = {LSF, USR, FIR, EFS, C-RAS-WM, ERS-WM, COF, MTM, CAC}，必需核 K_req = {LSF/USR 融合, EFS 风险缩放, C-RAS-WM 认证前缀}。
K* = argmin_{K ⊆ M_R68, K ⊇ K_req} |K|，s.t. RiskBound(K) ≤ ε_safe；
**最小性**：∀k ∈ K*，RiskBound(K* \ {k}) > ε_safe。RiskBound 用 D_val 上的保守上界（见定理 16）。

**定义 295（对话状态）** s_t^dia = (b_t, h_t, ρ_t^rob, ℓ_t)，其中 b_t 是对人类潜变量的信念，h_t 为对话历史，ρ_t^rob 为 R68 的风险后验与标定不确定 U，ℓ_t ∈ {L0,…,L5} 为当前阶梯等级。

**定义 296（信念状态跟踪 BST）**
b_t ∝ P(o_t | z_t^dial, g, a, α, κ) · Σ_{s_{t−1}} T(s_t | s_{t−1}) b_{t−1}，
潜变量：意图 g_t ∈ 𝒢、授权 a_t ∈ {grant, deny, unknown}、注意力 α_t ∈ [0,1]、能力 κ_t ∈ [0,1]。观测 o_t = (NLU 意图分布, 响应时延 τ_resp, 注视 / 朝向, MTM dialogue head 输出)。H(b_t) 为信念熵。

**定义 297（对话动作集）** 𝕄 = {ACT, CONFIRM, CLARIFY, EXPLAIN, HANDOVER, WAIT}：
ACT 执行计划；CONFIRM 就某命题「是 / 否」求证（授权或机器人信念）；CLARIFY 降低目标歧义；EXPLAIN 面向人解释收紧理由（可理解性）；HANDOVER 带交接包移交控制；WAIT 暂缓动作。

**定义 298（信息价值 VoI 与策略）** 单步效用
U(s) = −E[risk] − γ·T(m) − η·1[m ∈ {CONFIRM, CLARIFY, EXPLAIN}] + ξ·Legibility(m)。
VoI(m) = E_{o′~P(·|b,m)}[U(s′)] − U(s | ACT)。
策略：在安全自动机允许的可行集内，若存在 m ≠ ACT 使 VoI(m) > 0，则 m* = argmax VoI；否则若允许则 ACT，退化时 WAIT / HANDOVER。

**定义 299（风险门控安全自动机 A_safe）** A_safe 的状态转移以对话动作为标签，硬约束：
(i) 若 r̂_t > τ_ask 或 H(b_t) > τ_H，则 ACT 之前必须先 CONFIRM；
(ii) 若 a_t = unknown 且动作不可逆，则 CLARIFY / CONFIRM 必选；
(iii) 若 a_t = deny，仅允许 WAIT / HANDOVER。
Feasible(s) 返回允许动作，VoI 只在可行集内优化——**安全是约束，不是偏好项。**

**定义 300（对话残差）** r^dia_t = D(π̂_t^human ‖ π_t^human)，π̂ 为 BST 对人回答的预测分布，π 为观测分布；另设矛盾标志：若观测回答以似然比 > τ_lr 反驳 b_t 关于授权 / 意图的信念，则 r^dia_t 记为正无穷。r^dia_t > τ_rep 触发 REP。

**定义 301（有界修复协议 REP）** 修复序列 Π_rep = ⟨re-CONFIRM(nonce), 重构式 CLARIFY, EXPLAIN, 示范⟩；预算 B_repair = 2。修复成功当 r^dia ≤ τ_rep；超预算则 HANDOVER，交接包 H = (b_t, ρ_t^rob, 候选计划 A, 理由, ℓ_t)。**对话长度 ≤ 1 + B_repair，不存在死锁。**

**定义 302（最小可行安全阶梯 MLADDER）** 等级 L0–L5：L0 遥操作；L1 共享 + 仅 EXPLAIN；L2 CONFIRM 门控自治；L3 CLARIFY 门控目标自治；L4 协商式计划自治；L5 全自治 + 事后解释。每级有认证包络 E_ℓ，且 E_0 ⊇ E_1 ⊇ … ⊇ E_5。
升级 ℓ → ℓ+1 当且仅当：(a) D_val 上零违规；(b) LCB(VoI(新增自治)) > 0；(c) Valid(J_DIA)。
任一违规、修复率 > ρ_rep、或运行出 E_ℓ ⇒ 降级到 ℓ−1。

**定义 303（特性开关与复杂度预算 FLG）** 每个非 MVK 模块 f 有开关 φ_f ∈ {0,1} 与成本向量 c(f) = (Δτ, mem, opacity)；边际价值 v_f = ΔRisk(f) / |c(f)|。开启当且仅当 LCB(v_f) > κ；全局约束 Σ_f c(f) ≤ C_max。开关交互不做协同假设，须做两两交互回归（防止「各自无害、组合致命」）。

**定义 304（对话调制风险缩放）** λ_dial(b) = 0.6 + 0.4·1[H(b) > τ_H ∨ a = unknown]；
λ_t = max(λ_RAS(ρ_t), λ_floor(U), λ_dial(b_t))；a = deny ⇒ λ_t = 1。**任何人类侧不确定只抬升 λ，绝不降低。**

**定义 305（时标分离 / 预留控制）** 控制周期 T_c < 5 ms；对话回合间隔 T_d ∈ [1,10] s。预留策略 Π_reserve 给出保守上限。不变式：任何时刻 T_ctrl ≤ T_c，人类响应时延**永不进入**控制路径；对话优先对齐到任务相位边界，内环只在相位切换处读取最新 b_t。

**定义 306（可理解性与信任校准）** 用户模型 Û 预测机器人动作；Legibility L_t = 1 − KL(π^robot(· | plan, EXPLAIN) ‖ Û(·))；信任校准误差 e_trust = |r̂_user − r_true|。EXPLAIN 的目标是**降低 e_trust 而不制造过度信任**（过度信任单独度量，因为它是确认疲劳的前兆）。

**定义 307（DiaRAS 证书 J_DIA）** J_DIA = (J_CALM, ℓ_t, hash(b_t), VoI 日志, 修复计数, 开关集合 φ, hash(K*), hash(Π_reserve))。
Valid ⇔ Valid(J_CALM) ∧ ℓ_t 已认证 ∧ Σc(φ) ≤ C_max ∧ 修复计数 ≤ B_repair ∧ 预留不变式成立。

**定义 308（AIC-DIA 干扰集）** ℰ_DIA = ℰ_CALM × ℰ_dial × ℰ_mvp。ℰ_dial = {橡皮图章式确认 / 确认疲劳、社会工程与提示注入、分心或过载的人类、澄清漂移}；ℰ_mvp = {错误剪枝（剪掉分布外唯一冗余）、边际价值估计偏差、开关交互 bug、未验证升级}。

**定义 309（管线）** 离线：在 D_val 上剪枝得 K*；用日志交互校准 BST；用离线上下文老虎机 / 保守离线 RL 训练 VoI-DP；红队对话。
在线：回合级 BST + VoI（1–10 s）；毫秒级控制走 Π_reserve；60 s 影子流沿用 R68 CAC；阶梯升降在小时 / 天时标上执行。

**定义 310（VoI 门控的增长统一式）** 新模块、新自动化等级、新询问，三者统一准入：
**当且仅当 LCB(VoI) > 0**（模块用 v_f，等级用新增自治的 VoI，询问用单回合 VoI）。
一句话：一切增长都必须是「降低不确定性的期望收益为正」，否则宁可保持沉默与最小。

```python
# IP-253 MVK：消融驱动的最小可行内核裁剪（保守上界）
def prune_to_MVK(modules, D_val, eps_safe):
    K = set(modules)
    for m in sorted(modules, key=expected_ablation_cost, reverse=True):
        if safety_bound_ucb(K - {m}, D_val) <= eps_safe:
            K.discard(m)                      # 删了仍达标 ⇒ 非必要
    return frozenset(K)                        # 定义 294：K* 最小


# IP-255/256 BST + VoI-DP：只在「问」比「做」更值钱时才问
class DialogueManager:
    def update(self, b_prev, h, obs, z_dial):
        b_pred = self.transition(b_prev)                        # 人状态慢变（A96）
        b = normalize(b_pred * self.obs_model(obs, z_dial))     # NLU+注视+时延+dialogue head
        return b

    def select(self, s, risk, feasible):                        # feasible ← 安全自动机
        if 'ACT' not in feasible and 'WAIT' not in feasible:
            return 'HANDOVER', float('inf')
        best, best_m = 0.0, 'ACT'
        for m in feasible:                                      # 定义 298，仅优化可行集
            if m == 'ACT':
                continue
            v = self.voi(s, m, risk) - self.cost(m)             # 打断 + 延迟成本
            if v > best:
                best, best_m = v, m
        return best_m, best                                     # VoI≤0 ⇒ 不做多余交互


# IP-257 REP：有界修复，超预算强制交接（定义 301）
def repair(s, budget=2):
    for _ in range(budget):
        if dialogue_residual(s) <= TAU_REP:
            return s, 'OK'
        m = self.choose_repair_move(s)                          # re-CONFIRM(nonce)/CLARIFY/EXPLAIN/示范
        s = self.observe_turn(s, m)
    return self.handover_packet(s), 'HANDOVER'                  # 安全终态，绝不死循环


# IP-258 主闭环：对话与控制时标分离（定义 305；绝不阻塞内环）
def DiaRAS_round(M, obs, dialogue):
    tau_safe = M.reserve_policy(M.x_prev)                       # 1) 预留优先，先给保守指令
    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)       # 2) R68 内环照常
    r = residuals(M.x_prev, o, M.wm_cache)
    c, U, thr = M.cof.step(o['cal'], r, sigma_stat(M))
    joint = M.cfa(o['pi'], c, U)
    lam = max(M.efs.risk_scale(joint), thr['lam_floor'])

    b = dialogue.update(M.b, dialogue.history, dialogue.obs, o['dial'])  # 3) 人状态信念
    Hb = entropy(b)
    feasible = M.safety_automaton.feasible(joint, b, M.last_action)      # 风险门控是硬约束
    move, voi = dialogue.select(s=(b, joint), risk=joint, feasible=feasible)
    if move in ('CONFIRM', 'CLARIFY', 'EXPLAIN'):
        dialogue.emit(move, M.legible_reason(o, joint))          # 4) 异步发出，不阻塞控制
    if move == 'HANDOVER' or b.consent == 'deny':
        return M.reserve_policy.handover_packet(), 1.0           # 5) a=deny ⇒ λ=1

    lam = max(lam, lam_dialogue(Hb, b.consent))                  # 6) 对话只收紧
    if move == 'ACT' and M.safety_automaton.allows(joint, b):
        return M.pi_sigma.prefix_dispatch(M.A[:M.k]) * lam, lam  # 7) 已被显式授权才放行
    return tau_safe, lam                                         # 8) 否则维持预留指令


# IP-258 MLADDER：升/降级（定义 302）
def ladder_step(M, level, D_val):
    if any_violation(M) or repair_rate(M) > RHO_REP or out_of_envelope(M, level):
        return level - 1
    if safety_bound_ucb(M, D_val) <= EPS and lcb(voi_new_autonomy(M)) > 0:
        return level + 1
    return level
```

## 3. 推导

**引理 16（VoI 停止规则的遗憾界）** 设意图空间 𝒢 有限、先验 b_0、单步效用幅度 ≤ ΔU_max。策略只在 VoI > 0 时询问、VoI ≤ 0 时停止。则相对全知者的期望遗憾满足
E[U* − U_π] ≤ (ΔU_max / ln 2)·H(b_0) + 强制安全回合成本。
证明要点：一次询问能带来的期望效用增益不超过它诱导的后验熵下降乘以 ΔU_max（信息价值 ≤ 熵变）；对各回合望远镜求和即得；当 b_t 收敛到点质量或剩余动作 VoI ≤ 0 时停止，有限假设空间下回合数有限。**系**：过度询问不是「更安全」，而是把成本花在 VoI ≤ 0 的回合上——这正是 MVP 准则想要的减法。

**引理 17（有界修复不死锁）** 设单次修复成功概率 p，REP 预算 B。未解决概率 = (1−p)^B；期望回合数 ≤ 1 + Σ_{i=1}^{B}(1−p)^{i−1} ≤ 1 + B；未解决 → HANDOVER 为安全终态。故对话不能在误解中无限循环，且最坏情形是可界交接。

**引理 18（预留优先的零延迟）** 控制内环在任一控制节拍上，若存在 pending 回合则选择 Π_reserve，而 pending 状态在当地即可判定，不依赖人类返回。因此控制路径的最坏时延 = T_c，与人类响应时延 T_human 无关：**对话图层的加入对内环延迟的贡献严格为 0。**

**引理 19（人类作为独立检测器）** 对 COF 会吸收的慢故障类 F_slow，设内部漏检 1−p_int；设对话检查被触发的覆盖率为 cov，人类检出率 p_h，且 p_h 条件独立于内部传感器。则
P_miss(F_slow) ≤ (1 − p_int)·(1 − cov·p_h)。
cov = 1、p_h = 0.8 时漏检降为原来的 0.2 倍——这是 R68「慢故障隐形」的直接解药。**注意**：结论依赖触发覆盖率与人类未疲劳，二者正是第 6 节的风险来源。

**定理 16（DiaRAS 端到端安全性）** 在 A95–A100 下：
1. **MVK 可靠**：若剪枝用保守上界且 K* ⊇ K_req，则 RiskBound(K*) ≤ ε_safe，且 K* 最小；
2. **对话补盲**：对已被对话检查覆盖的慢故障，P_miss ≤ (1−p_int)(1−cov·p_h)（引理 19）；对未覆盖者退化为 R68 界，不劣化；
3. **零延迟**：对话对控制内环新增延迟 = 0（引理 18）；
4. **只收紧**：λ_t ≥ max(λ_RAS, λ_floor, λ_dial)，a = deny ⇒ λ = 1；
5. **有界交互**：每任务对话回合 ≤ 1 + B_repair（引理 17），超限必为 HANDOVER。

**定理 17（阶梯升降的安全性单调）** 若升级只用保守检验（D_val 零违规 ∧ LCB(VoI) > 0 ∧ Valid(J_DIA)），降级恢复包络 E_{ℓ−1} ⊇ E_ℓ，则在置信 1−δ 下各等级的违规率随 ℓ 单调不增；E_ℓ 嵌套保证「降级不会比升级前更差」。**系**：自动化不是一次跃迁，而是一条可回退的单调安全链。

**定理 18（最小性—鲁棒性不可兼得）** 对 D_val，K* 按定义 294 最小。但对任意支撑超出 D_val 的偏移分布 D′，存在被剪掉的模块 k，使 Risk_{D′}(K*\{k}) > ε_safe 而 Risk_{D_val}(K*) 不变。故「最小可行」只在 A98（验证分布覆盖部署分布）下成立；一旦分布外，被当作「无边际价值」剪掉的冗余，恰是唯一救命的东西。**这不是 bug，而是 MVP 范式在安全系统里的结构性代价**——它直接构成第 6 节的最大风险。

**假设 A95–A100**
A95：人类回答携带关于意图 / 授权的信息（p_h > 0.5），且给定真值时条件独立于内部传感器；
A96：人类潜状态（注意力 / 能力）慢变、可跟踪；
A97：任务时标允许在相位边界进行回合级对话（≳1 s），内环仍为毫秒级；
A98：D_val 覆盖部署分布（MVP 剪枝与验收的前提，强假设，须显式监控偏移）；
A99：VoI / v_f 的离线反事实估计覆盖足够，偏差有界；
A100：不可逆动作需显式同意 + 一次性 nonce，禁止重放。

## 6. 本轮最大风险

**一句话**：DiaRAS 把安全的最后一道关外包给了最慢、最不可靠、且可被社会工程攻击的通道——人；一旦确认疲劳 / 自动化偏见把每一句确认变成橡皮图章，「已获人类确认」反而会为错误决策背书，而 MVP 剪枝又恰好剪掉了分布外唯一能救命的冗余，系统于是同时失去内部冗余和外部审计，安全净值可能不升反降。

**次级风险与缓解**：
1. **确认疲劳 / 橡皮图章** → nonce 一次性 + 理由必填 + 随机抽检 + E290 监控；
2. **分布偏移使 MVP 剪枝失效**（定理 18）→ 漂移监控触发「重新加回冗余模块」并冻结升级；
3. **对话延迟 vs 快动态** → 预留优先（引理 18）+ 只在相位边界问 + E299 压测；
4. **VoI / v_f 估计偏差** → 保守 LCB + 离线反事实覆盖检查 + 拒绝越权；
5. **对抗对话 / 提示注入** → 安全自动机是硬约束（VoI 不能越过授权）+ 不可逆动作双因子确认；
6. **过度询问侵蚀信任** → 单一 VoI 准则 + E297 把「询问次数」本身作为成本纳入优化。

## 2. 形式化定义（要点版）

**定义 293（总览与五不变式）** 预留优先（内环永不等人）、最小性（非 MVK 模块需 LCB(v_f) > κ）、有界修复（≤2 回合后交接）、对话只收紧（λ ≥ max(λ_RAS, λ_floor, λ_dial)，deny ⇒ λ=1）、同意完整性（不可逆动作需显式同意 + 一次性 nonce）。

**定义 295（对话状态）** `s^dia = (b_t, h_t, ρ_t^rob, ℓ_t)`；把 R68 的风险后验 / 标定 U 与人类信念放进同一状态，实现「测量不确定」与「意图不确定」的**显式分离**。

**定义 297（动作集）** ACT / CONFIRM / CLARIFY / EXPLAIN / HANDOVER / WAIT，六动作覆盖「做 / 求证 / 问清 / 解释 / 交回 / 暂缓」。

**定义 298（VoI）** `U(s) = −E[risk] − γT(m) − η·1[询问] + ξ·Legibility`；`VoI(m) = E_{o'}[U(s')] − U(s|ACT)`；仅在可行集内取 `argmax`，`VoI≤0` 则不动作。

## 3. 关键算法伪代码

```python
# IP-253 MVK：消融驱动裁剪（保守上界，定义 294）
def prune_to_MVK(modules, D_val, eps_safe):
    K = set(modules)
    for m in sorted(modules, key=expected_ablation_cost, reverse=True):
        if safety_bound_ucb(K - {m}, D_val) <= eps_safe:
            K.discard(m)                       # 删了仍达标 ⇒ 非必要
    return frozenset(K)

# IP-255/256 BST + VoI-DP：只在「问」比「做」更值钱时才问（定义 296/298/299）
class DialogueManager:
    def update(self, b_prev, h, obs, z_dial):
        return normalize(self.transition(b_prev) * self.obs_model(obs, z_dial))

    def select(self, s, risk, feasible):       # feasible 来自安全自动机，硬约束
        if 'ACT' not in feasible and 'WAIT' not in feasible:
            return 'HANDOVER', float('inf')
        best, best_m = 0.0, 'ACT'
        for m in feasible:
            if m == 'ACT': continue
            v = self.voi(s, m, risk) - self.cost(m)
            if v > best: best, best_m = v, m
        return best_m, best                    # VoI≤0 ⇒ 不做多余交互

# IP-257 REP：有界修复，超预算强制交接（定义 301）
def repair(s, budget=2):
    for _ in range(budget):
        if dialogue_residual(s) <= TAU_REP: return s, 'OK'
        s = self.observe_turn(s, self.choose_repair_move(s))
    return self.handover_packet(s), 'HANDOVER' # 安全终态，绝不死循环

# IP-258 主闭环：对话与控制时标分离（定义 305，绝不阻塞内环）
def DiaRAS_round(M, obs, dialogue):
    tau_safe = M.reserve_policy(M.x_prev)                  # 1) 预留优先
    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)  # 2) R68 内环照常
    c, U, thr = M.cof.step(o['cal'], residuals(M.x_prev, o, M.wm_cache), sigma_stat(M))
    joint = M.cfa(o['pi'], c, U)
    lam = max(M.efs.risk_scale(joint), thr['lam_floor'])

    b = dialogue.update(M.b, dialogue.history, dialogue.obs, o['dial'])   # 3) 人类信念
    feasible = M.safety_automaton.feasible(joint, b, M.last_action)      # 硬约束
    move, voi = dialogue.select((b, joint), joint, feasible)
    if move in ('CONFIRM', 'CLARIFY', 'EXPLAIN'):
        dialogue.emit(move, M.legible_reason(o, joint))   # 4) 异步，不阻塞
    if move == 'HANDOVER' or b.consent == 'deny':
        return M.reserve_policy.handover_packet(), 1.0    # 5) deny ⇒ λ=1

    lam = max(lam, lam_dialogue(entropy(b), b.consent))   # 6) 只收紧
    if move == 'ACT' and M.safety_automaton.allows(joint, b):
        return M.pi_sigma.prefix_dispatch(M.A[:M.k]) * lam, lam
    return tau_safe, lam                                   # 7) 否则维持预留指令

# IP-258 MLADDER：升 / 降级（定义 302）
def ladder_step(M, level, D_val):
    if any_violation(M) or repair_rate(M) > RHO_REP or out_of_envelope(M, level):
        return level - 1
    if safety_bound_ucb(M, D_val) <= EPS and lcb(voi_new_autonomy(M)) > 0:
        return level + 1
    return level
```

## 4. 推导

**引理 16（VoI 停止规则遗憾界）** 有限意图空间、先验 b_0、效用幅度 ≤ ΔU_max，只在 VoI > 0 时询问：`E[U*−U_π] ≤ (ΔU_max/ln2)·H(b_0) + 强制安全回合成本`。信息价值不超过它诱导的熵降；望远镜求和即得。系：过度询问把成本花在 VoI≤0 的回合上，是负收益。

**引理 17（有界修复不死锁）** 单次修复成功概率 p、预算 B：未解决概率 `(1−p)^B`，期望回合数 ≤ 1+B，未解决 → HANDOVER 安全终态。

**引理 18（预留优先零延迟）** pending 状态本地可判、不依赖人类返回 ⇒ 控制最坏时延 = T_c，与 T_human 无关；对话对内环延迟贡献 = 0。

**引理 19（人类独立检测器）** 对 COF 会吸收的慢故障，`P_miss ≤ (1−p_int)(1−cov·p_h)`；cov=1、p_h=0.8 时漏检降为 0.2 倍——R68「慢故障隐形」的解药。依赖触发覆盖率与人类未疲劳。

**定理 16（端到端安全性）** A95–A100 下：① MVK 可靠且最小；② 对话覆盖的慢故障 `P_miss ≤ (1−p_int)(1−cov·p_h)`，未覆盖者不劣化；③ 零延迟；④ 只收紧（deny ⇒ λ=1）；⑤ 每任务回合 ≤ 1+B，超限必交接。

**定理 17（阶梯安全单调）** 保守升级（零违规 ∧ LCB(VoI)>0 ∧ Valid）+ 嵌套包络降级 ⇒ 置信 1−δ 下违规率随 ℓ 单调不增；自动化成为可回退的单调安全链。

**定理 18（最小性—鲁棒性不可兼得）** K* 对 D_val 最小；但对支撑超出 D_val 的 D′，∃ 被剪模块 k 使 `Risk_{D′}(K*\{k}) > ε_safe` 而 `Risk_{D_val}(K*)` 不变。故 MVP 只在 A98 下成立——这是 MVP 范式在安全系统中的结构性代价，也是本轮最大风险的正式表述。

## 7. 本轮最大风险

**一句话**：DiaRAS 把安全的最后一道关外包给了最慢、最不可靠、且可被社会工程攻击的通道——人；一旦确认疲劳 / 自动化偏见把每一句确认变成橡皮图章，「已获人类确认」反而会为错误决策背书，而 MVP 剪枝又恰好剪掉了分布外唯一能救命的冗余，系统于是同时失去内部冗余和外部审计，安全净值可能不升反降。

**次级风险与缓解**：确认疲劳（nonce + 理由必填 + 随机抽检 + E290）；分布偏移使剪枝失效（定理 18 → 漂移监控触发加回冗余并冻结升级）；对话延迟 vs 快动态（预留优先 + 相位边界询问 + E299）；VoI / v_f 估计偏差（保守 LCB + 反事实覆盖检查 + 拒绝越权）；对抗对话 / 提示注入（安全自动机硬约束 + 不可逆动作双因子确认）；过度询问侵蚀信任（把询问次数作为成本纳入 VoI，E297 监控）。
