# 第 68 轮（承接第 67 轮「SimRAS 仿真增强闭环」IP-233~242；灵感循环第 1 轮；本轮灵感：「技术路线图」×「低延迟推理」）

> 第 67 轮 SimRAS 把闭环从「在线反应式」升级为「离线仿真预训练 + 在线世界模型推理 + 视觉问答审计」的三层架构，理论上把长尾风险压到了可审计的范围。但它和 VISTA、RAS 一样，默认了一个从未被检验的前提：**每个组件都能在固定的亚毫秒预算内完成，且这个预算不随硬件、温度、调度、批次而漂移**。翻遍第 65~67 轮，所有「<1ms」「<3ms」都是**设计目标**，不是**可度量的随机变量**。
>
> 本轮灵感的两个词恰好击中这个盲区：
> - 「技术路线图」不是甘特图，而是一张**认证能力的单调阶梯**——每一阶段都要能独立取证、且不得比上一阶段更不安全；
> - 「低延迟推理」不是把模型量化到 INT8 就完事，而是承认推理是**可截断的 anytime 过程**：给的时间越少，输出越不确定。
>
> 由此提出 **LARA（Latency-Aware Roadmap Architecture，延迟感知路线图架构）**：
>
> **把「延迟」从隐含的常数升级为一等公民的不确定源，把「路线图」从工程排期升级为带证书继承的安全格；用延迟预算编译器分配截止期、用截断感知认证把「超时」翻译成「更宽的安全球」、用降级格保证任意超载下都安全回退，最终给出一条按门控逐级放行的可部署路线。**
>
> LARA 回答的不是「用什么算法」，而是「**在什么硬件、什么阶段、以多大延迟、能安全地启用哪一层能力**」。

## 0. 直觉与动机

**灵感 1（技术路线图 → 认证能力的安全阶梯）**
直觉：前三轮不断「加能力」：VISTA → RAS → SimRAS。但真实部署不可能一次上齐：边缘算力、传感器、法规认证、现场数据都受限。工程上通常画一张「先上 A，再上 B，最后上 C」的路线图；可安全系统里，路线图不能只写功能，必须写**每级的安全下界**。直觉上我们要的是一张**单调格（monotone lattice）**：L0=VISTA、L1=+RAS、L2=+SimRAS 离线、L3=+WM 在线、L4=+VQA 在线。每条边都是一次「能力增量」，每个节点都要有独立的延迟/安全门控；升级必须证明 `S_{ℓ+1} ≥ S_ℓ`，而不是「功能更多所以更好」。

**灵感 2（低延迟推理 → 推理是可截断的预算过程，不是布尔操作）**
直觉：第 67 轮把 WM 推理写成「<1ms，INT8，k=5」。可是世界模型不是查表：给 0.3ms 它可能只跑了 1 步、只给出粗粒度情绪；给 2ms 它才滚完 5 步、给出较准的故障后验。这就是经典的 **anytime algorithm（随时算法）**：**任何时刻中断都有输出，但输出带有随预算单调收窄的不确定性**。
一旦接受这一点，「超时」就不该被建模成「组件失效/跳过」，而应被建模成「**这次认证必须用一个更宽的不确定性球**」。第 67 轮最危险的做法是 `wm_preds = []` 直接当作「WM 没意见」——这会把不确定性悄悄丢掉。正确的做法是让超时**显式地膨胀风险**：`ρ_safe(b) = ρ_safe^∞ + κ·U(b)`，截断得越早，球越大，能认证的前缀越短。

**灵感 3（合流 → LARA 的五元结构）**
LARA = (LBC, ACI, DGL, RMP, J_lat)：
1. **LBC（Latency Budget Compiler）**：在总预算 `D_max` 与错失概率上限 `p_max` 下，为每个组件解出截止期 `d_i`，最小化端到端认证风险膨胀 `α_eff`；输出预算向量与其影子价格。
2. **ACI（Anytime-Certified Inference）**：所有在线推理（情绪、WM、VQA）暴露 `(y(b), U(b))`；认证器按「实际用掉的预算 b」膨胀安全球，而不是按「组件是否返回」二值判断。
3. **DGL（Degradation Lattice）**：超载时沿 `L4→L3→L2→L1→L0` 单调回退，每次回退都在一个控制周期内完成，并沿用回退等级的认证前缀。
4. **RMP（Roadmap Planner / DAG）**：把组件部署写成带前置依赖的 DAG；每个阶段有延迟门控、安全门控、Sim2Real 门控；只有全部通过才允许升级。
5. **J_lat（Latency Certificate）**：把截止期向量、实测 P99、WCET、松弛、错失概率、降级等级、anytime 预算、不确定性膨胀、路线图等级都写进证书，使「快」和「安全」在同一个可审计对象里。

**灵感 4（关键洞察：延迟存在一个硬下界 D†）**
直觉：如果总预算低到连「一次最小的可认证前向」都跑不完，那么再聪明的算法也无法给出 `k*≥1` 的安全前缀。这个阈值 `D†` 是硬件等级的物理属性，路线图必须在 `D†` 之上才允许启用对应在线组件。于是「路线图」有了可判定的放行条件：`D_max ≥ D†(组件集)`。

**灵感 5（对前序组件的延迟化改造）**
- **SimRAS 的 WM 滚动**：从固定 k=5 改为「预算内可变 k」；滚动长度 k(b) 与 U(b) 共同决定 `k_wm`；
- **C-RAS-WM 的认证前缀**：从 `min(k_ras, k_wm)` 改为 `min(k_ras, k_wm(b), k_trunc(b))`，其中 `k_trunc` 由截断不确定性决定；
- **EFS 的联合后验**：WM 头若只跑到第 i 步，后验权重使用 `w_i(b)` 而非固定指数衰减；
- **VQAuditor**：从「异步 50ms」改为「按剩余预算分片」，审计结果附带 `audit_budget`，低预算审计只允许**收紧**不允许**放宽**；
- **AIC**：新增共因延迟故障 `ℰ_lat`（热降频、GC 停顿、总线争用、模型热切换），并承认 `p_i` 跨组件相关；
- **J 证书**：新增 `J_lat`，让「这次决策用了多少时间、还剩多少余量、在哪个路线图等级」成为可追溯字段。

## 1. 形式化定义（增量：定义 266–285）

- **定义 266（LARA 总览）**：`LARA = (LBC, ACI, DGL, RMP, J_lat)`。定位：把 SimRAS 的「仿真增强闭环」升级为「**可按时部署的认证闭环**」。不变式：实时流只执行「带硬截止的 anytime 组件 + 查表的降级状态机」，不做动态预算重编译；延迟建模、预算编译、证书与路线图重规划只在语义流以低频（≥100ms）运行。
- **定义 267（组件延迟与截止）**：组件 i 的延迟是随机变量 `L_i ~ F_i`；分配硬截止 `d_i`，错失概率 `p_i(d_i) = 1 - F_i(d_i)`；最坏执行时间 `W_i = F_i^{-1}(1 - ε_wc)`。串行结构的端到端延迟 `D = Σ_{i∈S} d_i + max_{i∈P} d_i`。
- **定义 268（预算分配）**：预算向量 `D* = (d_1, …, d_n)`；可行当且仅当 `D_total(D*) ≤ D_max` 且 `d_i ≥ W_i`。松弛 `s_i = d_i - E[L_i]`，利用率 `ν = Σ_i E[L_i] / D_max`。
- **定义 269（认证风险膨胀）**：`α_eff(D*) = α_base + Σ_i c_i · p_i(d_i)`，其中 `c_i ∈ [0,1]` 是组件 i 错失的后果权重（例如 WM 错失 0.4、VQA 错失 0.05、ERG 错失 0.8）。证书有效当且仅当 `α_eff ≤ α_max`。
- **定义 270（anytime 推理曲线）**：组件 i 在预算 b 时输出 `(y_i(b), U_i(b))`，不确定性 `U_i(b) = U_i^∞ + (U_i^0 - U_i^∞)·exp(-β_i·b)`，`β_i > 0` 为信息增益率；若 `b < b_i^min` 则输出 `⊥`（不可用）。`U_i` 关于 b 单调不增且凸。
- **定义 271（截断感知安全裕度）**：`ρ_safe(b) = ρ_safe^∞ + κ_i·U_i(b)`，`κ_i` 为不确定性→安全裕度的换算系数。认证前缀必须使用膨胀后的球，而非满预算的球。
- **定义 272（延迟预算编译器 LBC）**：求解
  ```
  D* = argmin_{d} α_eff(d)
       s.t. D_total(d) ≤ D_max,  d_i ≥ W_i,  p_i(d_i) ≤ p_i^max
  ```
  并输出影子价格 `μ = -∂α_eff*/∂D_max`（每多 1ms 预算换来的风险下降）。LBC 只在语义流运行，结果缓存为查找表。
- **定义 273（关键延迟阈值 D†）**：`D† = inf{ D_max : ∃D* 可行且 α_eff ≤ α_max 且 k*(D*) ≥ 1 }`。物理含义：预算低于 D† 时不存在任何可认证的在线前缀，必须停留在离线等级或 L0。
- **定义 274（降级格 DGL）**：状态偏序 `L4(VQA) ≻ L3(WM) ≻ L2(RAS) ≻ L1(VISTA) ≻ L0(SAFE_STOP)`。转移 `δ(L_ℓ, b_remain) = max{ ℓ' ≤ ℓ : P99(C_{ℓ'}) ≤ b_remain }`，其中 `C_{ℓ'}` 为该等级的组件集。安全性要求 `S(L_{ℓ'})` 随 ℓ' 递减而单调回退。
- **定义 275（路线图 DAG RMP）**：节点 `v = (component, phase)`，有向边表示前置依赖；等级 `ℓ = (C_ℓ, D_ℓ, S_ℓ, G_ℓ)` 分别表示组件集、延迟预算、安全下界、门控集。
- **定义 276（证书继承）**：`Valid(J_ℓ) ⇒ Valid(J_{ℓ-1})`。高等级证书必须蕴含低等级证书，否则不允许升级（防止「新功能破坏旧保证」）。
- **定义 277（路线图单调安全性）**：`S_0 ≤ S_1 ≤ … ≤ S_L`。在任意输入分布与任意超载下，等级 ℓ+1 的最坏安全概率不低于等级 ℓ。
- **定义 278（延迟证书 J_lat）**：`J_lat = (deadline_vec, p99_vec, wcet_vec, slack, α_eff, degradation_level, anytime_budget, uncertainty_inflation, roadmap_level, lara_ver)`。
- **定义 279（部署门控）**：`g_ℓ = (latency_gate: P99(C_ℓ) ≤ D_ℓ, safety_gate: α_eff ≤ ε_ℓ, sim_gate: TV(P_sim, P_real) ≤ δ_ℓ, field_gate: 现场样本支持 P99 上界)`。四项全过才允许从 ℓ-1 升到 ℓ。
- **定义 280（预算-安全前沿）**：`F = { (D, S(D)) : S(D) = 在预算 D 下可达的最优安全概率 }`。路线图只允许选择前沿上或其下方的点；在预算不变时声称更高 S 即伪造证书。
- **定义 281（anytime 早停决策）**：若剩余预算 `b < b_i^min` 或 `U_i(b) > U_max`，组件返回 partial 并标记 `truncated=True`；认证器据此膨胀球；若膨胀后 `k*<1`，立即触发 DGL 回退。
- **定义 282（延迟预测器）**：用分位数回归 + 保形预测（conformal）给出 P99 上界：`\hat{F}_i^{-1}(0.99) + q_{1-δ}`；用 CUSUM/漂移检测处理非平稳性，检测到漂移时冻结预算重编译并强制降一级。
- **定义 283（共因延迟故障）**：`ℰ_lat = {热降频, GC 停顿, 总线争用, 模型热切换, 网络抖动, 时钟偏斜}`。共享资源使 `p_i` 相关；有效错失概率用联合界 `p_∪ ≤ Σ p_i` 或 copula 上界，而非独立假设。
- **定义 284（LARA 实时不变式）**：一个控制周期内禁止动态重编译预算或重规划路线图；预算只在语义流周期性求解。实时流读到的 `D*` 与降级状态在周期内保持不变，保证时序可分析。
- **定义 285（J_lara 总证书）**：`J_lara = (J_SimRAS, J_lat, roadmap_level, gate_hash)`。Valid ⇔ `Valid(J_SimRAS) ∧ J_lat.valid ∧ 当前降级等级 ≥ 路线图等级要求的最低等级`。

## 2. 关键算法骨架

```python
# LBC：延迟预算编译器（语义流，低频）
class LatencyBudgetCompiler:
    def __init__(self, p_max=1e-3, alpha_max=0.02, eps_wc=1e-4):
        self.p_max, self.alpha_max, self.eps_wc = p_max, alpha_max, eps_wc

    def compile(self, comps, D_max):
        # comps: [{id, F, c, beta, U0, Uinf, kappa, serial}]
        # 用拉格朗日/注水求截止期：风险越大的组件分到越多松弛
        W = {c['id']: quantile(c['F'], 1 - self.eps_wc) for c in comps}
        d = dict(W)                                  # 初值 = WCET
        while self._total(d, comps) < D_max:
            # 把 next ms 给「边际风险下降最大」的组件
            i = max(comps, key=lambda c: self._marginal(c, d[c['id']]))
            d[i['id']] += self._step
            if self._total(d, comps) > D_max:
                d[i['id']] -= self._step
                break
        return Budget(d, alpha_eff=self._alpha_eff(d, comps),
                      mu=self._shadow_price(d, comps))

    def _alpha_eff(self, d, comps):
        return self.alpha_max_base + sum(
            c['c'] * (1 - cdf(c['F'], d[c['id']])) for c in comps)

    def _total(self, d, comps):
        return sum(d[c['id']] for c in comps if c['serial']) + \
               max([d[c['id']] for c in comps if not c['serial']] or [0])


# ACI：截断感知认证（实时流，只读预算）
def anytime_certified_prefix(A, cert, budget_left, t_start):
    k_best, U_used = 0, {}
    for i in range(len(A)):
        b_i = cert.deadline[i]
        if budget_left() < b_i:                      # 硬截止
            U_used[i] = infinity_uncertainty
            break
        y, U = cert.component[i].run_until(b_i)      # anytime
        U_used[i] = U
        rho = cert.safety_margin(A[i]) + cert.kappa[i] * U   # 膨胀球
        if rho < 0:
            break
        k_best = i + 1
    return k_best, U_used


# DGL：降级格状态机（实时流，O(h)）
class DegradationLattice:
    LEVELS = ['L4_VQA', 'L3_WM', 'L2_RAS', 'L1_VISTA', 'L0_STOP']
    def step(self, current, budget_left, lat_pred):
        for lvl in self.LEVELS[self.LEVELS.index(current):]:
            if lat_pred.p99(lvl) <= budget_left:
                return lvl
        return 'L0_STOP'
    def is_monotone(self, a, b):
        return self.LEVELS.index(a) <= self.LEVELS.index(b)


# RMP：路线图门控（离线/发布流水线）
class RoadmapPlanner:
    def __init__(self, levels, gates):
        self.levels, self.gates = levels, gates
    def can_promote(self, ell, profile):
        g = self.gates[ell]
        return (profile.p99(self.levels[ell].C) <= self.levels[ell].D and
                profile.alpha_eff <= g.eps and
                profile.tv_sim_real <= g.delta and
                profile.field_n >= g.n_min and
                self._cert_inherits(ell))
    def _cert_inherits(self, ell):
        return self.levels[ell].J.implies(self.levels[ell - 1].J)


# LARA 闭环：实时路径
def LARA_round(M, obs, t_now):
    # 语义流已缓存 D*, 降级状态与 J_lat；实时流只读
    lvl = M.dgl.current
    if lvl == 'L0_STOP':
        return safe_stop()
    budget = M.lat.budget_for(lvl, t_now)
    face = M.erg.recognize(img=obs.img, budget=budget['erg'])
    A = M.vista.ach.propose(obs.x_prime, H=M.vista.H)
    if lvl in ('L3_WM', 'L4_VQA'):
        k_wm, U_wm = anytime_certified_prefix(A, M.wm, budget['wm'], t_now)
    else:
        k_wm, U_wm = len(A), {}
    joint_post = M.efs.synthesize(obs.rho, face, U_wm)
    k_ras, U_cert = anytime_certified_prefix(A, M.csc, budget['csc'], t_now)
    k = min(k_wm, k_ras, M.vista.m)
    tau = M.vista.pi_sigma.prefix_dispatch(A[:k]) * M.efs.risk_scale(joint_post)
    # 预算耗尽则降级，下一周期生效
    if budget.remaining() < M.lat.d_min_next:
        M.dgl.request(M.dgl.step(lvl, budget.remaining(), M.lat.pred))
    return k, tau, U_cert
```

## 3. 推导

**引理 13（anytime 不确定性的可达预算）** 对 `U_i(b) = U_i^∞ + (U_i^0-U_i^∞)e^{-β_i b}`，达到目标不确定性 Δ 所需预算为 `b_i(Δ) = (1/β_i)·ln((U_i^0-U_i^∞)/(Δ-U_i^∞))`，且该预算随 Δ 减小而单调增大、凸增。推论：存在最小可用预算 `b_i^min = b_i(U_max)`。

**引理 14（LBC 的凸性与影子价格）** 若各 `p_i(d_i)` 关于 `d_i` 是对数凸的（指数尾、高斯尾均满足），则 `α_eff(D*)` 在约束集上是凸的，LBC 的唯一最优解满足等边际条件：存在 `μ ≥ 0`，使各串行组件的边际风险下降相等 `c_i·f_i(d_i) = μ`（并行分支按最紧者取）。`μ` 即「每多 1ms 预算换来的风险下降」。

**引理 15（截断认证的保守性）** 用膨胀球 `ρ_safe(b) = ρ_safe^∞ + κU(b)` 认证得到的前缀 `k_trunc` 满足 `k_trunc ≤ k_full`；且当 `U(b) ≤ Δ_max` 时，安全裕度损失有界 `Δρ ≤ κ·Δ_max`。因此「早停」只可能让认证更保守，不会更激进——这是 LARA 与「超时即跳过」方案的本质区别。

**定理 14（关键延迟下界）** 设组件集为 C，最小可认证预算 `D_min(C) = Σ_{i∈S} b_i(U_max) + max_{i∈P} b_i(U_max)`。则 `D† ≥ D_min(C)`；当 `D_max < D_min(C)` 时，不存在任何预算分配使 `α_eff ≤ α_max ∧ k* ≥ 1`。故路线图在硬件等级 `h` 上启用在线组件 `C` 的必要条件是 `P99_h(C) < D†`。

**定理 15（路线图证书继承与单调安全）** 若 (i) 每级 `α_eff ≤ α_max`，(ii) 降级格满足 `L_{ℓ+1}` 的任何超时都能在一个控制周期内落到 `L_ℓ`，(iii) `Valid(J_{ℓ+1}) ⇒ Valid(J_ℓ)`，则对任意输入分布与超载序列，`S_{ℓ+1} ≥ S_ℓ`。证明要点：把 `L_{ℓ+1}` 的执行与「先跑 `L_{ℓ+1}`、一旦不可认证就路由到 `L_ℓ`」耦合，二者在路由后逐步同分布，而路由前的 `L_{ℓ+1}` 已由证书保证安全，故最坏概率不升。

**定理 16（降级的状态收敛与切换有界）** 降级格高度 `h ≤ 5`。在任意超载下，DGL 最多经过 h 次状态迁移即到达可行等级；每次迁移在下一个控制周期内生效，且生效期间控制指令由回退等级的认证前缀给出，故不产生「无证书空窗」。

**定理 17（延迟门控的现场样本复杂度）** 用 DKW 不等式估计延迟分布，欲使 P99 上界以 `1-δ` 置信、误差不超过 ε 成立，需 `n ≥ (1/(2ε²))·ln(2/δ)` 个现场样本；若用 split-conformal，则需 `n ≥ ⌈(1-δ)/δ⌉` 个校准样本给出单侧 P99 上界。路线图的 `field_gate` 由此给出可执行的样本量。

**定理 18（相关错失下的安全下界）** 若组件错失事件相关（共享热/总线/GC），独立假设会低估 `α_eff`。用联合界 `α_eff^∪ = α_base + Σ_i c_i p_i` 仍成立但偏保守；用 copula 上界 `α_eff^cop ≤ α_base + Σ_i c_i p_i + Σ_{i<j} c_{ij}√(p_i p_j)` 可在相关性有界时进一步收紧。LARA 默认采用联合界，直到在线估计出 `c_{ij}`。

## 6. 本轮最大风险

**一句话**：LARA 把「延迟」当作可测量、可建模、且组件间近似独立的随机变量，但真实部署中的延迟是**非平稳且强相关**的（热降频、GC/调度停顿、共享总线、模型热切换会同时拖慢多个组件），一旦 P99 与错失概率被低估，`α_eff` 与 `D†` 都会被算小——路线图会在一个「看似达标」的硬件等级上放行在线组件，而 DGL 的回退又恰好踩在同一个被拖慢的共享资源上，导致「认证前缀过度乐观 + 降级延迟触发」在真实故障到来时同时发生；这是本轮全部理论依赖的核心假设：**延迟分布可被保形上界可靠刻画，且跨组件错失事件可用联合界安全兜底**。

```
α_eff(D*) = α_base + Σ_i c_i·p_i(d_i)
```

若 `b<b_i^min` 输出 `⊥`。

```
D* = argmin_d  α_eff(d)

μ = -∂α_eff*/∂D_max
```

```python
# IP-243 LBC：延迟预算编译器（语义流，低频）
class LatencyBudgetCompiler:
    def __init__(self, p_max=1e-3, alpha_max=0.02, eps_wc=1e-4, step=0.05):
        self.p_max, self.alpha_max, self.eps_wc, self.step = p_max, alpha_max, eps_wc, step

    def compile(self, comps, D_max):
        W = {c['id']: quantile(c['F'], 1 - self.eps_wc) for c in comps}
        d = dict(W)                                   # 初值 = WCET
        while True:
            if self._total(d, comps) + self.step > D_max:
                break
            # 把下一毫秒给边际风险下降最大的组件（等边际条件）
            i = max(comps, key=lambda c: self._marginal(c, d[c['id']]))
            d[i['id']] += self.step
        budget = Budget(deadline=d,
                        alpha_eff=self._alpha_eff(d, comps),
                        mu=self._shadow_price(d, comps))
        return budget

    def _alpha_eff(self, d, comps):
        return self.alpha_base + sum(c['c'] * (1 - cdf(c['F'], d[c['id']])) for c in comps)

    def _total(self, d, comps):
        serial = sum(d[c['id']] for c in comps if c['serial'])
        par = max([d[c['id']] for c in comps if not c['serial']] or [0])
        return serial + par


# IP-244 ACI：截断感知认证（实时流，只读预算）
def anytime_certified_prefix(A, cert, budget_left):
    k_best, U_used = 0, {}
    for i in range(len(A)):
        b_i = cert.deadline[i]
        if budget_left() < b_i:                       # 硬截止：不再往前认证
            U_used[i] = float('inf')
            break
        y, U = cert.component[i].run_until(b_i)       # anytime
        U_used[i] = U
        rho = cert.safety_margin(A[i]) + cert.kappa[i] * U   # 膨胀球
        if rho < 0:
            break
        k_best = i + 1
    return k_best, U_used


# IP-245 DGL：降级格状态机（实时流，O(h)）
class DegradationLattice:
    LEVELS = ['L4_VQA', 'L3_WM', 'L2_RAS', 'L1_VISTA', 'L0_STOP']

    def step(self, current, budget_left, lat_pred):
        start = self.LEVELS.index(current)
        for lvl in self.LEVELS[start:]:
            if lat_pred.p99(lvl) <= budget_left:
                return lvl
        return 'L0_STOP'

    def is_monotone(self, before, after):
        return self.LEVELS.index(before) <= self.LEVELS.index(after)

                uncertainty_inflation={i: budget.kappa[i] * u
                                       for i, u in profile.U.items()},
                roadmap_level=profile.roadmap_level,
                lara_ver='1.0')


# IP-248 WM-LC：预算内可变滚动
class WorldModelLatencyCutting(WorldModel):
    def rollout_budgeted(self, obs_t, act_seq, budget):
        z = self.enc(obs_t.half())
        preds, used = [], 0.0
        for i, a in enumerate(act_seq):
            cost = self.cost_estimate(z.shape)
            if used + cost > budget:
                break                                 # 早停，不假装跑完
            z = self.dyn(z, a.half())
            preds.append({'pi': self.emo(z).float(),
                          'pH': self.fault(z).float(),
                          'b': used + cost,
                          'U': self.uncertainty(used + cost)})
            used += cost
        return preds, used


# IP-249 C-RAS-WM-T：截断感知前缀
class ChunkSafetyCertificateRASWMT(ChunkSafetyCertificateRASWM):
    def certified_prefix_trunc(self, A, joint_post, m_ras, wm_preds,
                               k_wm_budget, U_wm):
        k_wm = min(k_wm_budget, len(wm_preds))
        k_trunc = 0
        for i in range(min(len(A), m_ras)):
            if U_wm.get(i, 0.0) > self.U_max_trunc:
                break
            k_trunc = i + 1
        k_ras = self.certified_prefix_ras(A, joint_post, m_ras, self.alpha_chunk)
        return min(k_ras, k_wm, k_trunc, m_ras)


# IP-250 EFS-WM-B：预算收缩的时序先验
def synthesize_budgeted(self, rho, face_gate, wm_preds, used_budget):
    joint_post, post_H = super().synthesize(rho, face_gate)
    for i, pred in enumerate(wm_preds):
        # 预算越少，权重越弱；未跑到的步不参与
        w = math.exp(-(i + 1) / self.tau_h) * (used_budget / self.D_wm)
        for h, p in pred['pH'].items():
            key = (h, 'E0')
            if key in joint_post:
                joint_post[key] *= (p ** max(w, 1e-6))
    return normalize(joint_post), post_H


# IP-251 VQA-S：分片审计，只能收紧
def audit_sliced(self, rollout_preds, scene_context, budget):
    vid = self.render.render_rollout(rollout_preds)
    ans = self.vqa.ask(vid, self.prompts[budget.template], max_tokens=budget.tokens)
    rec = self.parse(ans)
    rec['lambda_adjust'] = min(rec.get('lambda_adjust', 1.0), 1.0)  # 禁止放宽
    rec['audit_budget'] = budget.used
    return AuditReport(rec)


# IP-252 LARA 实时闭环
def LARA_round(M, obs, t_now):
    lvl = M.dgl.current
    if lvl == 'L0_STOP':
        return safe_stop()

    budget = M.lat.budget_for(lvl, t_now)             # 只读缓存 D*
    img = obs.img

    # 1) ERG anytime
    face = M.erg.recognize(img, budget=budget['erg'])

    # 2) ACH 提议
    A = M.vista.ach.propose(obs.x_prime, H=M.vista.H)

    # 3) WM 预算内滚动
    if lvl in ('L3_WM', 'L4_VQA'):
        wm_preds, used = M.wm.rollout_budgeted(obs.x_prime, A[:5], budget['wm'])
    else:
        wm_preds, used = [], 0.0

    # 4) EFS-WM 预算收缩先验
    joint_post, _ = M.efs_wm.synthesize_budgeted(obs.rho, face, wm_preds, used)

    # 5) 截断感知认证前缀
    m_ras = min(M.vista.m, M.er.max_m_emotion)
    k = M.csc_wmt.certified_prefix_trunc(
        A, joint_post, m_ras, wm_preds,
        k_wm_budget=len(wm_preds),
        U_wm={i: p['U'] for i, p in enumerate(wm_preds)})

    # 6) 控制指令
    tau = M.vista.pi_sigma.prefix_dispatch(A[:k])
    tau = tau * M.efs_wm.risk_scale(joint_post)
    tau = M.ers_wm.shaping(tau, joint_post, wm_preds)

    # 7) 预算耗尽 → 请求降级（下一周期生效）
    if budget.remaining() < M.lat.d_min_next:
        M.dgl.request(M.dgl.step(lvl, budget.remaining(), M.lat.pred))

    # 8) VQA 分片审计（仅 L4，后台，低预算只收紧）
    if lvl == 'L4_VQA' and budget.has_async_slice():
        M.vqa_s.audit_sliced(wm_preds, {'scene': obs.x_prime}, budget.async_slice())

    return k, tau, joint_post, face, used
```

## 4. 推导

**引理 13（anytime 不确定性的可达预算）** 对 `U_i(b)=U_i^∞+(U_i^0-U_i^∞)e^{-β_i b}`，
```
b_i(Δ) = (1/β_i)·ln((U_i^0-U_i^∞)/(Δ-U_i^∞))
```
随 Δ 减小单调增大且凸增。推论：最小可用预算 `b_i^min=b_i(U_max)`。

**引理 14（LBC 凸性与影子价格）** 若 `p_i(d_i)` 对数凸（指数尾、高斯尾满足），则 `α_eff(D*)` 在约束集上凸，LBC 唯一最优解满足等边际条件：存在 `μ≥0`，使串行组件 `c_i·f_i(d_i)=μ`（并行分支取最紧者）。`μ=-∂α_eff*/∂D_max` 表示每多 1ms 预算换来的风险下降。

**引理 15（截断认证的保守性）** 用膨胀球 `ρ_safe(b)=ρ_safe^∞+κU(b)` 认证的 `k_trunc` 满足 `k_trunc≤k_full`；当 `U(b)≤Δ_max` 时裕度损失有界 `Δρ≤κΔ_max`。故「早停」只会更保守，不会更激进。

**定理 14（关键延迟下界）** 设 `D_min(C)=Σ_{i∈S}b_i(U_max)+max_{i∈P}b_i(U_max)`，则 `D†≥D_min(C)`。当 `D_max<D_min(C)` 时不存在预算分配使 `α_eff≤α_max ∧ k*≥1`；因此路线图在硬件等级 h 启用在线组件集 C 的必要条件是 `P99_h(C)<D†`。

**定理 15（路线图证书继承与单调安全）** 若 (i) 每级 `α_eff≤α_max`，(ii) `L_{ℓ+1}` 任一超时可在 1 周期内落到 `L_ℓ`，(iii) `Valid(J_{ℓ+1})⇒Valid(J_ℓ)`，则任意输入与超载序列下 `S_{ℓ+1}≥S_ℓ`。证：把 `L_{ℓ+1}` 与「先跑 ℓ+1、不可认证即路由到 ℓ」耦合，路由前由证书保证、路由后同分布，故最坏概率不升。

**定理 16（降级收敛与切换有界）** 格高 `h≤5`。任意超载下 DGL 最多 h 次迁移即到可行等级，每步在下一控制周期生效，生效期控制指令由回退等级认证前缀给出，零无证书空窗。

**定理 17（延迟门控样本复杂度）** DKW：`n≥(1/(2ε²))ln(2/δ)` 使 P99 上界以 1-δ 置信、误差 ≤ε。Split-conformal：`n≥⌈(1-δ)/δ⌉` 个校准样本给出单侧 P99 上界。路线图 `field_gate` 由此确定 `n_min`。

**定理 18（相关错失下的安全界）** 独立假设会低估 `α_eff`。联合界 `α_eff^∪=α_base+Σ_i c_i p_i` 恒成立但保守；copula 上界 `α_eff^cop≤α_base+Σ_i c_i p_i+Σ_{i<j}c_{ij}√(p_i p_j)` 在相关有界时收紧。LARA 默认联合界，直到在线估出 `c_{ij}`。

## 7. 本轮最大风险

**一句话**：LARA 把「延迟」当作可测量、可建模、且组件间近似独立的随机变量，但真实部署中的延迟是**非平稳且强相关**的（热降频、GC/调度停顿、共享总线、模型热切换会同时拖慢多个组件），一旦 P99 与错失概率被低估，`α_eff` 与 `D†` 都会被算小——路线图会在一个「看似达标」的硬件等级上放行在线组件，而 DGL 的回退又恰好踩在同一个被拖慢的共享资源上，导致「认证前缀过度乐观 + 降级延迟触发」在真实故障到来时同时发生；这是本轮全部理论依赖的核心假设：**延迟分布可被保形上界可靠刻画，且跨组件错失事件可用联合界安全兜底**。
