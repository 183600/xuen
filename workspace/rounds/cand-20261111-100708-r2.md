# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 2 轮；本轮灵感：「放置」×「失败恢复」）

> 第 54 轮把技能组合建立在动作空间剖面 `α_S`、技能组合图 `G_S` 与云边联合证书 `J` 之上。本轮追问两个更底层的问题：**失败发生在地形的哪里（放置），以及失败之后如何把系统放回可生存的构型（失败恢复）**。核心矛盾：H22：失败并非在能力空间均匀分布，而被“放置配置”地形化——同一技能在不同节点/位姿/检查点放置下的失败热区不同，第 53 轮的 `ρ` 缺少“放置条件化”；H23：恢复不是免费重试，恢复动作本身占用动作空间、必须满足第 54 轮的 SCOM/J 证书，并可能诱发级联失败，即“恢复也需要被恢复”。

## 0. 直觉与动机

**灵感 1（放置作为第一性变量 → 失败地形化）**
直觉：技能不是“在真空中失败”，而是在一个由节点位置、技能绑定、恢复锚点、物体位姿共同决定的**放置配置** `π_p` 中失败。换一个放置，同一个技能的失败热区会整体平移。因此不能只问“这个技能鲁棒吗”，而要问“**在这个放置下，失败发生在哪里、有多重、能否被救回**”。这把第 53 轮的 `ρ` 升级为放置条件化失败分布 `P(f | π_p, T)`。

**灵感 2（恢复 = 重新放置 → 恢复盆地）**
直觉：恢复的目标不是“继续执行”，而是“回到某个已知良好的放置/构型”。一个恢复锚点 `r`（检查点、安全位姿、备用智能体、降级技能）能救回的失败状态集合，就是它的**恢复盆地** `𝓑(r)`。可恢复性于是从“有没有重试”变成几何覆盖问题：`⋃_{r∈R} 𝓑(r)` 是否覆盖失败空间 `F` 的加权主体。

**灵感 3（放置-恢复联合优化 → 子模覆盖 + 证书）**
直觉：放置锚点不是越多越好，也不是均匀铺开，而是要把有限预算放在能覆盖高概率、高严重度失败的“分水岭”上。对固定放置，加权覆盖函数 `Cov_w(R)` 对锚点集合 `R` 单调子模，故可用 CELF 懒贪心获得 `1-1/e` 近似；但放置与锚点联合优化一般不再子模，需交替优化并诚实报告经验间隙。

**灵感 4（云边检查点放置 → RTO/RPO 的层级 DP）**
直觉：检查点放在机器人本地、边缘、云端，决定了恢复要回退多远（RPO，状态陈旧度）以及恢复要多快（RTO，回滚+重放时延）。这是一个沿云边层级链的放置问题，必须与第 54 轮的动作映射 `γ_ce`、边端带宽 `τ_e` 联动，而不是独立的存储配置。

**灵感 5（恢复闭包 → 恢复本身必须被认证）**
直觉：最危险的失败不是“没恢复”，而是“恢复动作把系统带进更坏的区域”。因此每次恢复动作都要携带第 54 轮的联合证书 `J_rec`；恢复轨迹要做闭包检查：最终进入良好集合 `G`、不得在 `G` 外成环、累计风险与代价不得越预算。这把恢复从“重试策略”提升为**带活性与安全性的递归证书**。

**灵感 6（金字塔扩展：在 𝕃 与 𝔸 之上叠加恢复层 ℝ）**
直觉：恢复本身是分层的：`ℝ_0` 物理级（安全位姿/急停/重抓取）、`ℝ_1` 技能级（重试/换技能，须在 `G_S` 内）、`ℝ_2` 任务级（重放置到其他智能体/边缘节点）、`ℝ_3` 云边级（检查点回滚与状态对账）、`ℝ_4` 全局级（Explain 驱动的重剖分与重放置）。跨层传递必须同时携带 `ρ`、`A_cert` 与新的 `R_cert`。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（放置配置与放置成本）**
放置配置 `π_p = (x_node, σ_skill, R_anchor, g_obj) ∈ Π(T)`：
- `x_node`：机器人/边缘节点的空间或拓扑放置；
- `σ_skill`：技能到执行主体的绑定；
- `R_anchor`：恢复锚点集合（检查点/安全位姿/备用智能体）；
- `g_obj`：物体放置位姿（若任务含操作）。
`cost_place(π_p) = w_x·||x_node|| + w_σ·migrate(σ_skill) + w_R·|R_anchor| + w_g·dist(g_obj, g_target)`。

**定义 122（放置条件化失败地理）**
失败单元 `f = (d, c, e)` 由第 53 轮 Explain 给出：维度 `d`、上下文 `c`、根因 `e`。失败地理 `F(π_p, T)` 是带权单元集合，分布为 `P(f | π_p, T)`，严重度为 `sev(f)`。定义失败权重 `w(f) = P(f | π_p, T)·sev(f)`，总权重 `W = Σ_f w(f)`。

**定义 123（恢复动作空间与可认证恢复）**
恢复动作空间 `A_rec ⊆ A`，恢复算子 `Rec: S × A_rec ⇀ S`。从失败 `f` 到锚点 `r` 的恢复代价 `d_rec(f, r; a_rec)`。**可认证恢复**要求该恢复动作携带有效联合证书 `J_rec`（承接第 54 轮定义 120）且 `ρ_rec ≥ ρ_min^rec`；否则该恢复动作不可采纳。此定义使恢复递归地受动作空间与鲁棒性约束。

**定义 124（恢复盆地与加权覆盖）**
锚点 `r` 的恢复盆地：
```
𝓑(r; π_p) = { f ∈ F(π_p,T) | ∃ a_rec ∈ A_rec:
              d_rec(f,r;a_rec) ≤ B_T ∧ J_rec valid }
```
加权覆盖 `Cov_w(R; π_p) = Σ_{f ∈ ⋃_{r∈R} 𝓑(r)} w(f) / W`，其中 `R ⊆ A_anchor`。`Cov_w=1-ε_f` 表示仅剩 `ε_f` 的失败权重未被任何锚点覆盖。

**定义 125（放置-恢复联合优化）**
```
π_p* = argmax_{π_p∈Π(T), R⊆A_anchor}
       Cov_w(R; π_p) - λ·cost_place(π_p)
s.t.  |R| ≤ k,  RTO_p95 ≤ B_T,  RPO_p95 ≤ B_S,
      ∀r∈R: ρ(r) ≥ ρ_min,  ∀a_rec: J_rec valid
```
对固定 `π_p`，`Cov_w(·; π_p)` 在 `R` 上单调子模；联合问题一般非子模，采用“放置候选枚举/局部搜索 + 锚点 CELF 贪心 + 证书过滤”的交替优化，并报告相对上界的经验间隙。

**定义 126（恢复证书）**
```
R_cert = (π_p, R, 𝓑, Cov_w, RTO_p95, RPO_p95,
          ε_f, ε_rec, ε_clo, evidence, expiry)
```
其中 `ε_f = 1 - Cov_w`，`ε_rec` 为恢复动作自身失败率，`ε_clo` 为恢复闭包逃逸率，`evidence` 至少包含失败采样、盆地反例与检查点回放。若 `Cov_w ≥ 1-ε_f^budget`、`RTO_p95 ≤ B_T`、`RPO_p95 ≤ B_S`、`ε_rec+ε_clo ≤ ε_r`、`dom=in` 且未过期，则可部署。

**定义 127（恢复闭包与闭包安全性）**
恢复策略 `π_rec` 从失败状态 `s_0=f` 产生轨迹 `Cl_R(f) = (s_0, s_1, ...)`，`s_{t+1} = Rec(s_t, a_t)`。**闭包安全**要求：
1. 活性：存在 `T_rec ≤ T_max` 使 `s_{T_rec} ∈ G`（良好集合）；
2. 安全：`∀t, risk(s_t) ≤ R_budget`，且轨迹在 `G` 外无环；
3. 预算：`Σ_t d_rec(s_t, a_t) ≤ B_T`。
违反任一条即判定 `ε_clo=1` 并回退到最保守安全锚点。

**定义 128（鲁棒性-可恢复性联合谱）**
对每个鲁棒维度 `d`，扩展谱 `ρ^+(d) = (ρ_d, υ_d)`，其中 `υ_d = P(在预算 B_T 内被恢复 | d 上发生失败)`。部署条件升级为 `∀d: ρ_d ≥ ρ_min(d) ∧ υ_d ≥ υ_min(d)`。这使“鲁棒”与“可恢复”成为并列的一等公民。

def build_failure_geography(placement, task, sim, n_samples, k=8):

### IP-122 RBA（Recovery Basin Analysis）

```python
def recovery_basins(F, anchors, A_rec, B_T, cert_lib):
    G_rec = build_recovery_graph(F, anchors, A_rec, cert_lib)
    # 只保留携带有效 J_rec 的恢复边
    basins = {}
    for r in anchors:
        dist = reverse_dijkstra(G_rec, source=r, max_cost=B_T)
        basins[r] = {f for f, d in dist.items() if f in F and d <= B_T}
    return basins

def weighted_coverage(basins, R, weights):
    covered = set().union(*(basins[r] for r in R))
    return sum(weights[f] for f in covered) / sum(weights.values())
```

### IP-123 RAP（Recovery-Aware Placement）

```python
def recovery_aware_placement(placements, F_builder, anchors, A_rec,
                             B_T, k, lam, cert_lib):
    best = None
    for placement in placements:
        if not placement_certificate_ok(placement, cert_lib):
            continue
        F = F_builder(placement)
        basins = recovery_basins(F, anchors, A_rec, B_T, cert_lib)
        R, cov = celf_greedy(basins, anchors, k, weights=F.weights)
        score = cov - lam * cost_place(placement)
        best = argmax(best, (score, placement, R, F, cov))
    return best

def celf_greedy(basins, anchors, k, weights):
    R, covered, heap = [], set(), []
    for r in anchors:
        push(heap, -marginal(r, covered, basins, weights), r)
    while len(R) < k and heap:
        gain, r = pop(heap)
        new_gain = marginal(r, covered, basins, weights)
        if -gain == new_gain:                 # 惰性上界仍成立
            R.append(r)
            covered |= basins[r]
        else:
            push(heap, -new_gain, r)
    return R, sum(weights[f] for f in covered) / sum(weights.values())
```

### IP-124 CPP（Checkpoint Placement Policy）

```python
def checkpoint_placement(chain, rpo, rto, state_rate, restore_speed, cost):
    # chain = [robot, edge, cloud]；选择每层检查点间隔 l_i
    # 约束：max 陈旧度 <= rpo；restore_time(最近有效检查点) <= rto
    # 目标：min Σ cost_i(l_i)
    dp = {0: (0, None, None)}                 # idx -> (cost, plan, staleness)
    for i, tier in enumerate(chain):
        ndp = {}
        for l in feasible_intervals(tier, state_rate):
            stale = l / state_rate
            if stale > rpo:
                continue
            for prev_cost, plan, prev_stale in dp.values():
                rt = restore_time(i, l, stale, restore_speed)
                if rt > rto:
                    continue
                c = prev_cost + cost_i(l)
                ndp[i] = argmin(ndp.get(i), (c, plan + [(tier, l)]))
        dp = ndp
    return min(dp.values(), key=lambda x: x[0])
```

### IP-126 RCC（Recovery Certificate Constructor）

```python
def build_recovery_certificate(placement, R, F, basins, closure_analyzer,
                               budgets):
    cov = weighted_coverage(basins, R, F.weights)
    eps_f = max(0.0, 1.0 - cov)
    eps_rec = estimate_recovery_action_failure(R, F)
    clo = closure_analyzer(R, F)
    if eps_f > budgets.eps_f or clo.escape_risk > budgets.eps_clo:
        return ('reject', 'coverage_or_closure', eps_f, clo.escape_risk)
    if clo.rto_p95 > budgets.B_T or clo.rpo_p95 > budgets.B_S:
        return ('reject', 'rto_rpo', clo.rto_p95, clo.rpo_p95)
    return ('ok', RecoveryCert(placement, R, basins, cov,
                               clo.rto_p95, clo.rpo_p95,
                               eps_f, eps_rec, clo.escape_risk,
                               evidence=F.evidence, expiry=now()+TTL))
```

### IP-127 RCL（Recovery Closure Guard）

```python
def safe_recover(f, policy, cert_lib, max_steps, budget):
    s, seq, spent, seen = f, [], 0.0, set()
    for _ in range(max_steps):
        a = policy(s)
        if not cert_lib.valid_recovery(a, s):
            return ('unsafe_recovery', seq)          # 缺 J_rec 或越动作空间
        s2, cost = Rec(s, a)
        if spent + cost > budget:
            return ('budget_exceeded', seq)
        if risk(s2) > R_budget:
            return ('risk_exceeded', seq)
        seq.append((a, s2)); spent += cost
        if s2 in G:
            return ('recovered', seq, spent)
        if s2 in seen:
            return ('recovery_cycle', seq)           # 闭包成环
        seen.add(s2); s = s2
    return ('recovery_timeout', seq)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| FGG | O(N_sim · cost_rollout) | O(|F|·k) | 失败采样覆盖、概率校准 |
| RBA | O(|A_anchor|·(|F| log|F| + |E_rec|)) | O(|F|+|E_rec|) | 恢复图仅含认证边、代价可加 |
| RAP | O(|Π|·(N_sim + k·|F|·|A_anchor|))，CELF 近线性 | O(|F|·|A_anchor|) | 固定放置下覆盖子模 |
| CPP | O(|tiers|·L²) | O(L) | RTO/RPO 约束闭合 |
| TRP | O(|agents|·|A|) | O(|agents|) | 复用 J 证书、组合可达 |
| RCC | O(|F| + |E_rec|) | O(|F|) | 证书 sound、预算闭合 |
| RCL | O(T_max·|A_rec|) | O(T_max) | 闭包活性 + 安全 + 无环 |

**引理 1（覆盖子模性）**：固定 `π_p`，`g(R)=Σ_{f∈⋃_{r∈R}𝓑(r)} w(f)` 单调且子模。证明：对 `A⊆B`、`r∉B`，边际增益 `g(A∪{r})-g(A)=Σ_{f∈𝓑(r)\(⋃A)} w(f) ≥ Σ_{f∈𝓑(r)\(⋃B)} w(f)=g(B∪{r})-g(B)`，因 `⋃A ⊆ ⋃B`。

**推论（贪心近似）**：在基数约束 `|R|≤k` 下，CELF 贪心返回 `≥ (1-1/e)·OPT` 的加权覆盖。预算/RTO 约束下不保证常数近似，改用成本-效益贪心并以经验上界报告间隙。

**正确性定理（Placement-Recovery Soundness）**
承接第 53–54 轮 (A22)–(A28)。新增假设：**(A29)** 失败地理校准误差 `sup_f |P̂(f|π_p)-P(f|π_p)| ≤ ε_cal`；**(A30)** 仿真恢复盆地与现实盆地差距（Hausdorff/度量）`≤ ε_gap`；**(A31)** 每个被采纳恢复动作携带有效 `J_rec`；**(A32)** 闭包护栏保证 `ε_clo` 逃逸率；**(A33)** 检查点陈旧度 `≤ RPO` 且恢复 `≤ RTO`；**(A34)** 证书有效期 TTL 内放置/任务漂移 `≤ ε_drift`。则
```
P_rec ≥ 1 - [ (1 - Cov_w(R)) + ε_cal + ε_gap + ε_rec + ε_clo + ε_drift ]
```
且部署成功下界为 `P_success · P_rec`（恢复与执行按条件独立近似）。关键：**覆盖的是校准后的真实失败地形，恢复动作本身被认证，闭包不逃逸。**

### IP-122 RBA

```python
def recovery_basins(F, anchors, A_rec, B_T, cert_lib):
    G_rec = build_recovery_graph(F, anchors, A_rec, cert_lib)  # 仅认证边
    return {
        r: {f for f, d in reverse_dijkstra(G_rec, r, max_cost=B_T).items()
            if f in F and d <= B_T}
        for r in anchors
    }

def weighted_coverage(basins, R, weights):
    covered = set().union(*(basins[r] for r in R))
    return sum(weights[f] for f in covered) / sum(weights.values())
```

### IP-123 RAP

```python
def recovery_aware_placement(placements, F_builder, anchors, A_rec,
                             B_T, k, lam, cert_lib):
    best = None
    for placement in placements:
        if not placement_certificate_ok(placement, cert_lib):
            continue
        F = F_builder(placement)
        basins = recovery_basins(F, anchors, A_rec, B_T, cert_lib)
        R, cov = celf_greedy(basins, anchors, k, weights=F.weights)
        score = cov - lam * cost_place(placement)
        best = argmax(best, (score, placement, R, F, cov))
    return best

def celf_greedy(basins, anchors, k, weights):
    R, covered, heap = [], set(), []
    for r in anchors:
        push(heap, -marginal(r, covered, basins, weights), r)
    while len(R) < k and heap:
        gain, r = pop(heap)
        new_gain = marginal(r, covered, basins, weights)
        if -gain == new_gain:
            R.append(r); covered |= basins[r]
        else:
            push(heap, -new_gain, r)
    return R, sum(weights[f] for f in covered) / sum(weights.values())
```

### IP-124 CPP

```python
def checkpoint_placement(chain, rpo, rto, state_rate, restore_speed, cost):
    # 沿 [robot, edge, cloud] 选择每层检查点间隔 l_i
    dp = {0: (0, [])}
    for i, tier in enumerate(chain):
        ndp = {}
        for prev_cost, plan in dp.values():
            for l in feasible_intervals(tier, state_rate):
                stale = l / state_rate
                if stale > rpo:
                    continue
                if restore_time(i, l, stale, restore_speed) > rto:
                    continue
                c = prev_cost + cost_i(l)
                if c < ndp.get(i, (inf,))[0]:
                    ndp[i] = (c, plan + [(tier, l)])
        dp = ndp
    return min(dp.values(), key=lambda x: x[0])
```

def safe_recover(f, policy, cert_lib, max_steps, budget):
    s, seq, spent, seen = f, [], 0.0, set()
    for _ in range(max_steps):
        a = policy(s)
        if not cert_lib.valid_recovery(a, s):
            return ('unsafe_recovery', seq)
        s2, cost = Rec(s, a)
        if spent + cost > budget:
            return ('budget_exceeded', seq)
        if risk(s2) > R_budget:
            return ('risk_exceeded', seq)
        seq.append((a, s2)); spent += cost
        if s2 in G:
            return ('recovered', seq, spent)
        if s2 in seen:
            return ('recovery_cycle', seq)
        seen.add(s2); s = s2
    return ('recovery_timeout', seq)

## 3. 推导与正确性

**引理 1（覆盖子模性）**：固定 `π_p`，`g(R)=Σ_{f∈⋃_{r∈R}𝓑(r)} w(f)` 单调且子模。
证明：对 `A⊆B`、`r∉B`，
```
g(A∪{r}) - g(A) = Σ_{f∈𝓑(r)\(⋃A)} w(f)
                ≥ Σ_{f∈𝓑(r)\(⋃B)} w(f) = g(B∪{r}) - g(B)
```
因 `⋃A ⊆ ⋃B`，故边际增益随集合增大而递减。

**推论 1（贪心近似）**：基数约束 `|R|≤k` 下，CELF 贪心返回 `≥(1-1/e)·OPT`。预算/RTO 约束破坏该保证，改用成本-效益贪心并报告经验间隙。

**定理（Placement-Recovery Soundness）**
假设 (A22)–(A28) 承接第 53–54 轮；新增：
- **(A29)** 失败地理校准误差 `sup_f |P̂(f|π_p)-P(f|π_p)| ≤ ε_cal`；
- **(A30)** 仿真恢复盆地与现实盆地差距 `≤ ε_gap`；
- **(A31)** 每个被采纳恢复动作携带有效 `J_rec` 且 `ρ_rec ≥ ρ_min^rec`；
- **(A32)** 闭包护栏保证逃逸率 `≤ ε_clo`；
- **(A33)** 检查点陈旧度 `≤ RPO`、恢复时间 `≤ RTO`；
- **(A34)** 证书 TTL 内放置/任务漂移 `≤ ε_drift`。

则
```
P_rec ≥ 1 - [ (1 - Cov_w(R)) + ε_cal + ε_gap + ε_rec + ε_clo + ε_drift ]
P_success^rec ≥ P_success · P_rec
```
关键：**覆盖的是校准后的真实失败地形；恢复动作本身被认证；闭包不逃逸良好集合。** 该下界显式暴露四类误差来源，避免把“对已知失败的覆盖”误读为“真实可生存性”。
