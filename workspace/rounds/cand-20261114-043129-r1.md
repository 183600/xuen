# 第 71 轮（承接第 70 轮「BELIEF-RAS 贝叶斯状态估计层」IP-264~274；灵感循环新循环第 4 轮；本轮灵感：「轮足机器人」×「语义建图」）

> R70 把 epistemic 从「动作模态」升级为「世界状态后验 b_t(s)」，并交付了基线协议与原型验收。但 b_t(s) 仍是**无空间、无介质、无接触**的抽象状态——它不知道「我脚下这块地是什么」、不知道「这块地会不会塌」、也不知道「换一种接触方式能不能问出答案」。R70 自陈的最大风险是「后验自信地错」，而当状态空间里根本没有**地形/介质**时，这个风险恰恰最致命：地图说「瓷砖」，轮子却在打滑；地图说「草地」，脚却陷进泥里。
>
> 本轮两个灵感正好补上「空间—介质—形态」这一整层缺失：
> - **语义建图**给出一个**空间化、可持久、带标签但会过时/会撒谎**的地形先验——它本质上是「给动力学用的先验」，却被传统上只当成「给规划看的图层」；
> - **轮足机器人**给出一种**天然的双通道接触形态**——轮式接触连续、高效、对滑动敏感；足式接触离散、高越障、对支撑/沉陷敏感。两种接触对地形物理参数的**信息方向正交**，而 α∈[0,1] 的轮足混合让「换模式」成为连续可微的**信息动作**。
>
> 核心命题：**把语义地图从「标签图层」升级为「可被接触证伪的动力学先验」；把轮足的「换模式」从执行动作升级为「探询动作」；用接触证据做一条语义层无法吸收的一致性检验；但只在「认证探询包络」内主动探询——因为信息最大的地方，往往也是最危险的地方。** 命名 **TREAD-RAS**（Terrain-REliability-Aware Dynamics for RAS）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「我的信念是什么」，R71 问「**我脚下的世界是什么，我该以什么方式踩上去**」——语义不是看完就算的知识，它是可以被轮子与脚一次一次验证或推翻的假设。

## 0. 直觉与动机

**灵感 1（轮足机器人 → 接触形态本身就是探针）**
直觉：同一个机器人，用轮子压过一块地和用脚踩上这块地，得到的物理信息是**不同方向**的。轮子滑移率直接反映摩擦系数 μ 与滚动阻力；脚掌的沉陷/力曲线直接反映支撑刚度 κ、局部高度 h 与粗糙度 ρ。传统做法把「轮 / 足」当成效率与越障的取舍；但对 epistemic 不确定性地形，轮足的价值是**两种正交的测量模态**——这正好是 R69「正交证据纪律」缺的物理底座。更关键的是 α 可以连续过渡：不必二选一，可以「先轻踩再上轮」「半驱半撑」地把接触当作可控力度的探针。
> 直觉的反面：接触探针不是免费的，它**同时是执行**。轮子压上去的那一刻，你已经在承担这块地的后果。这是本轮与 R69/R70 最本质的区别：R69 的「看一眼/问一句」几乎可逆，R71 的「踩一下」可能不可逆。

**灵感 2（语义建图 → 地图是地形物理的先验，而不是真相）**
直觉：语义分割/建图模型会给出「这是台阶 / 这是玻璃 / 这是地毯」的标签，人看到标签就默认了背后的物理（台阶有高差、玻璃很滑、地毯软而摩擦大）。机器人也应该这样用地图：**标签→物理参数分布→步态参数**。但必须同时承认地图会**自信地错**：分布外纹理、遮挡、动态场景、甚至有人故意把坑洞伪装成平地（语义伪装，semantic camouflage）。所以语义地图只能做**先验**，必须有另一条物理通道来证伪它。R68 的「标定不可吸收」在 R71 变成「**语义不可吸收**」：标定可以解释传感器偏置，解释不了「地图把坑画成了地」。

**灵感 3（耦合 → 语义不确定性必须落到步态上，而不是停在概率里）**
直觉：如果 SAF 在某个格子上熵很高，正确的反应不是「继续规划、祈祷均值对」，而是**改变接触方式降低风险同时获取信息**：降低轮速、缩小步高、改用足式轻触、绕行、或者先停下用外感知补一张图。也就是说，语义地图的熵应当直接进入 R70 的 λ_floor 与模式选择。**地图不确定性 = 步态保守度**，这是本轮要建立的第一条硬耦合。

**灵感 4（探询悖论 → 安全与信息在这里天然冲突）**
直觉：接触探针的 VoI 在「未知/歧义地形」最高，而危险也在那里最高。R69 的探询是「看/问/触」，其中「触」已经隐含风险；R71 把「触」变成了字面意义上的**承载全身体重**。于是出现一个 R69/R70 没有的悖论：**最该探的地方最不能探**。本轮必须交付「认证探询包络」：只有后备恢复可行、屏障证书成立、接触力/电流在包络内的状态才允许探询；包络外一律退化为「不探、绕行、最保守步态」。这把 R69 的「安全认证」从工程检查升格为**带恢复可行性的不变式**。

**灵感 5（严格包含 → 语义层、接触层都必须是可退化的）**
直觉：任何新层若不能被关掉，就多一个必须被信任的黑箱。TREAD 必须能在「地图不可信 / 探询包络为空 / 平台无轮足」时逐指令退化到 BELIEF → FLUID → R68。与前几轮一致，**新层永远是旧层的严格泛化**：地图不给力时不至于更差，地图给力时获得效率与安全裕度。

## 1. 形式化定义（增量：定义 331–350）

**定义 331（TREAD-RAS 总览）** TREAD-RAS = (SAF, HLC, CPX, MRB, SMI, SMCG, EPX, VQAuditor-III, AIC-TERRAIN, RAS-Baselines v2, Proto-Val v2, BELIEF-RAS†)。四不变式：
(i) **实时零学习写操作**（继承 R70 定义 310-i）；
(ii) **探询预算与认证包络**：单位时间接触探询 ≤ 1 次、接触能量 ≤ e_max、且必须落在定义 340 的认证探询包络内；
(iii) **接触证据纪律**：单次接触/单张语义地图不得单独支撑高风险模式切换，需 ≥2 个正交通道（轮/足/外感知）一致，或在包络内以有界风险换取信息；
(iv) **地图可证伪**：SAF 的每个格子必须携带来源、时龄与证伪记录，禁止「无来源的地图直接驱动高风险步态」。

**定义 332（地形场）** 位置 p 处地形 T(p) = (l(p), θ(p))：语义标签 l ∈ L（可数语义类）；物理参数 θ = (μ, κ, s_θ, ρ, h) ∈ ℝ⁵（摩擦系数、支撑刚度、坡度、粗糙度、局部高差）。θ 是真正驱动动力学的东西，l 只是 θ 的廉价索引。

**定义 333（语义-可承载场 SAF）** 地图 M_t 为空间格胞集合，每胞 c 的后验
b_{t,c}(l,θ) = Σ_l w_{c,l} · Cat(l; w_{c,·}) · 𝒩(θ; μ_{c,l}, Σ_{c,l}),
并附时龄 a_c 与来源集合 src_c。SAF 同时输出两个量：语义后验 w_{c,·}（离散）与物理后验 𝒩(θ; μ_{c,l}, Σ_{c,l})（连续）。语义熵 H_l(c) = −Σ_l w log w；物理熵 H_θ(c) = ½ log det(2πeΣ)。**地图不确定性 = 两者的耦合，不是单一标量。**

**定义 334（轮足混合模式流形）** 模式 u = (α, h_s, k_l, τ_w) ∈ ℳ，α ∈ [0,1]：α=1 纯滚动、α=0 纯跨步，中间为轮足协同；h_s 步高、k_l 腿刚度、τ_w 轮驱力矩。要求 ℳ 上存在连续切换核：‖u_{t+1} − u_t‖ ≤ L_M·Δt（无跳变，对应 R68 定理 15 的连续性延伸）。

**定义 335（接触观测模型与双通道 Fisher 信息）** 在胞 c 以模式 u 接触，观测 y ~ p(y | θ_c, u)。轮通道 y_w 主要由 (μ, 滚动阻力) 决定，足通道 y_f 主要由 (κ, h, ρ) 决定。定义 Fisher 信息 J_u(θ) = E_y[∇_θ log p(y|θ,u) ∇_θᵀ log p(y|θ,u)]。**双通道正交性**：J_w 与 J_f 在 θ 的主方向上互补（见引理 23），这是轮足形态用于估计而非仅用于移动的正式理由。

**定义 336（SAF-BSE 扩展滤波器）** 全状态 b_t = (pose_t, ψ_t, M_t)。预测：里程计 + 地图坐标变换（并给每胞时龄 a_c += Δt）；更新：由接触观测 y、外感知（RGB-D/LiDAR）与既有 R70 的 BSE 融合，逐胞更新 w_{c,·} 与 (μ, Σ)。对数域加和，M ≤ 20、N ≤ 500 不变（继承 R70 定义 314）。**接触更新与视觉更新必须保留来源标签**，供证据纪律与审计使用。

**定义 337（可承载风险）** 在地形后验 b_{t,c} 下以模式 u 通过胞 c 的风险
R(c,u) = E_{θ~b_{t,c}}[ r_trav(θ,u) ] + λ_map · (H_l(c) + H_θ(c)),
其中 r_trav 为打滑/翻覆/沉陷代价，第二项是**地图不确定性安全裕度**。系：地图越不确定，越倾向于降速、降步高、绕行——语义熵直接进入安全决策。

**定义 338（模式-鲁棒规划 MRB）** 规划模式轨迹 π = (u_{t:t+H}, 路径 P)，最小化 CVaR_β[Σ R(c,u)]，满足屏障约束 h(x,b) ≥ 0 与模式连续性（定义 334）。若 CVaR 的最坏情形代价超过阈值，则触发「保守步态」子问题（限制 h_s、τ_w、α 的可行集）。

**定义 339（接触探询 VoI）** 候选探询 (c,u)：VoI(c,u) = H[b_{t,c}] − E_{y~p(·|θ_c,u)}[ H[b_{t,c} | y] ]。选 (c,u)* = argmax [VoI − c_phys(c,u) − c_time]，s.t. 落在认证包络内、预算未超。若最大净收益 ≤ 0，则不探询（退化 R70）。

**定义 340（认证探询包络 EPX）** 包络 𝒫_t = { (x,u) : h_barrier(x,b_t) ≥ 0 ∧ F_contact(u) ≤ F_max ∧ I_motor(u) ≤ I_max ∧ ∃ 恢复策略 π_rec 使 worst-case 停稳时间 ≤ t_rec }。**探询只允许在 𝒫_t 内发生**；包络外一律不探、绕行或最保守步态。这是本轮安全的核心不变式。

**定义 341（探询悖论的安全规则）** 若某探询点的 VoI 高但不在 𝒫_t 内，则**不得**用「高 VoI」作为越界理由；替代动作是「用外感知补图」或「绕行」。严格禁止以信息收益为名放宽安全包络（否则 R71 会变成「为了知道坑多深而跳下去」）。

**定义 342（语义地图完整性残差 SMI）** 对每次接触，r_map(c) = y − E_{θ~b_{t,c}}[ y | u ]。若 r_map 大而 R68/R70 的传感器残差 r_res 小、且外感知通道也自洽，则判为**语义层错误或语义伪装**（地图说 A、物理是 B）。这构成对 R70「标定不可吸收」的镜像：**语义不可吸收**。

**定义 343（双通道判据）** 记 D = (r_map, r_res, r_ext)。结构性错误模式：语义错/伪装 → (r_map↑, r_res↓, r_ext↓)；传感器偏置 → (r_map↑ 或 ↔, r_res↑, r_ext↔)；真实地形突变 → (r_map↑, r_res↑, r_ext↑)。三元组用于分离三类故障，避免把所有不一致都归给地图。

**定义 344（语义地图校准门 SMCG）** 校准 SAF 的语义可靠性：ECE_map（按置信度分箱的标签正确率偏差）与物理参数覆盖度 cov_θ。ECE_map > τ_ece,map 或 cov_θ < τ_cov ⇒ 禁止 SAF 驱动高风险步态与探询决策，退化 R70；地图仅作软先验。

**定义 345（参与式审计 VQAuditor-III）** 审计对象新增：地图来源/时龄是否合规、探询是否越出 𝒫_t、接触证据是否被单源采纳、语义伪装是否触发、模式切换是否连续。结论回灌 AuditBuf，成为下一轮 SMCG 与 EPX 的先验。

**定义 346（AIC-TERRAIN 对抗集）** ℰ_TREAD = ℰ_BELIEF × ℰ_camouflage（语义伪装：以视觉/纹理伪造地形物理）× ℰ_dynamic（动态地形：可变形/移动支撑）× ℰ_probe（探询诱发翻覆/沉陷）× ℰ_mapdrift（地图过期/坐标系漂移）× ℰ_gait（模式切换振荡/腿轮冲突）。

**定义 347（证书 J_TREAD）** J_TREAD = (J_BELIEF, ECE_map, cov_θ, probe_violations, r_map_p95, mode_switch_jerk_p99, map_age_p99, tread_ver)。Valid ⇔ Valid(J_BELIEF) ∧ ECE_map ≤ τ_ece,map ∧ probe_violations = 0 ∧ 证据纪律满足 ∧ 探询预算未越界。

**定义 348（严格退化链）** 若 M_t 不可信（SMCG 越界）或 𝒫_t = ∅ 或平台退化为纯轮/纯足，则 TREAD 逐指令退化为 BELIEF-RAS（→ FLUID-RAS → CALM-RAS）。安全侧永不弱于 R70；效率侧仅在「地图可信 ∧ 包络非空」时获得收益。**新层是可关闭的，不是必须被信任的。**

**定义 349（基线协议 RAS-Baselines v2）** 在 v1 五基线基础上增加：Semantic-Map-Only、Wheel-Only、Leg-Only、Gait-Blind（有图不用图）、TREAD-NoProbe（只规划不接触探询）。固定种子/分割/指标/检验（Wilcoxon + Bonferroni），新增地形分层报告（平地/台阶/松软/湿滑/伪装/动态）。

**定义 350（原型验收 Proto-Val v2）** 三平台：Isaac Sim 轮足模型、ROS 2 + 真实轮足平台（含轮/腿独立力控）、以及纯轮与纯足两个消融平台。验收：探询违规 = 0、模式切换 jerk P99 < 阈值、ECE_map < 0.08、伪装检出 ≥ 85%、动态地形通过率 ≥ 85%、P99 < 4.0ms。

```python
# IP-275 SAF：语义-可承载场（逐胞语义后验 × 物理参数后验，带来源/时龄）
class SemanticAffordanceField:
    def __init__(self, semantic_net, phys_prior, grid):
        self.sem, self.prior, self.grid = semantic_net, phys_prior, grid

    def observe_extero(self, rgbd, pose):
        logits = self.sem(rgbd)                      # 逐像素语义
        for c in self.grid.cells_under(pose):
            self.update_label(c, logits, src='extero')

    def query(self, c):
        return dict(w=self.w[c], mu=self.mu[c], Sigma=self.Sigma[c],
                    age=self.age[c], src=self.src[c])

    def update_contact(self, c, y, u):
        # 用接触观测 y 对胞 c 的 (l, θ) 做逐标签贝叶斯更新（保留来源）
        for l in self.w[c]:
            ll = self.contact_likelihood(y, u, self.mu[c][l], self.Sigma[c][l])
            self.w[c][l] *= ll
        self.w[c] = normalize(self.w[c]); self.src[c].add('contact')

# IP-276 HLC：连续轮足混合控制（α 平滑，jerk 有界）
class HybridLocomotionController:
    def __init__(self, Kp, L_M):
        self.Kp, self.L_M, self.u_prev = Kp, L_M, None

    def blend(self, u_cmd, dt):
        if self.u_prev is None: self.u_prev = u_cmd
        du = u_cmd - self.u_prev
        du = clip_norm(du, self.L_M * dt)            # 定义 334 连续性
        self.u_prev = self.u_prev + du
        return self.u_prev                            # (alpha, h_s, k_l, tau_w)

# IP-277 CPX：接触探询（先在认证包络里筛，再算 VoI）
def choose_probe(saf, b_t, epx, budget):
    best = None
    for (c, u) in candidate_contacts(b_t, saf):     # 近邻胞 × 离散模式
        if not budget.allow(u):            continue
        if not epx.contains(b_t.pose, u):  continue  # 定义 340/341：越界不谈 VoI
        voi = saf.entropy(c) - expected_entropy_after_contact(saf, c, u)
        score = voi - phys_cost(c, u) - time_cost(c)
        if best is None or score > best.score: best = (c, u, score, voi)
    return best if best and best.score > 0 else None

# IP-278 MRB：模式-鲁棒 CVaR 规划（对 SAF 后验做最坏情形）
def plan_mode_robust(b_t, saf, beta=0.9, H=8):
    def cost(pi):
        samples = [rollout_cost(pi, saf_sample(saf)) for _ in range(N_mc)]
        return cvar(samples, beta)                  # 定义 338
    pi = argmin_pi(cost(pi), s.t. barrier_ok(pi, b_t))
    if cost(pi) > TAU_CVAR:
        pi = conservative_gait_subproblem(pi)       # 降 h_s/tau_w，缩可行集
    return pi

# IP-279 SMI：语义完整性残差（语义不可吸收的第二意见）
def semantic_integrity(y, u, saf, c, r_res, r_ext):
    r_map = y - expected_contact_under(saf, c, u)
    if norm(r_map) > TAU_MAP and norm(r_res) < TAU_RES and norm(r_ext) < TAU_EXT:
        return 'semantic_error_or_camouflage'       # 定义 342/343
    if norm(r_map) > TAU_MAP and norm(r_res) > TAU_RES:
        return 'terrain_change'
    return 'ok'

# IP-280 TREAD 主闭环（在 R70 的 BELIEF 环上插入 SAF / HLC / CPX / SMI）
def TREAD_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)   # R68/R70 层
    b_t = M.bse.step(M.b_prev, o, M.last_action, M.last_g, M.last_y)
    # 1) 融合外感知，得到 SAF（带来源/时龄）
    M.saf.observe_extero(obs.rgbd, b_t.pose)
    if M.smcg.reject(M.saf):                        # 定义 344：地图不可信
        return M.belief_round(M, obs)               # 逐指令退化 R70
    # 2) 地图不确定性 → 可承载风险与模式-鲁棒规划
    pi = M.mrb.plan_mode_robust(b_t, M.saf)
    # 3) 认证包络内做接触探询（越界不谈 VoI）
    probe = (M.cpx.choose_probe(M.saf, b_t, M.epx, M.budget)
             if M.saf.max_entropy() > TAU_MAP_ENT else None)
    if probe is not None:
        (cell, u) = probe
        y = M.epx.execute_contact(cell, u)          # 有界风险探询
        verdict = M.smi.semantic_integrity(y, u, M.saf, cell,
                                            M.last_r_res, M.last_r_ext)
        M.saf.update_contact(cell, y, u)
        if verdict == 'semantic_error_or_camouflage':
            M.vqa_iii.flag(M.saf, cell, verdict)    # 审计 + 降低该区信任
    # 4) 风险缩放：语义熵 + 未消解物理熵进入 λ_floor
    U_epi_map = M.saf.max_entropy()
    lam = max(M.efs.risk_scale(...),
              lam_floor(U_cal + alpha_gate(U_epi_map)))   # 定义 337/348
    # 5) 模式-鲁棒执行（连续性由 HLC 保证）
    u_exec = M.hlc.blend(pi.first_mode(), dt=M.dt)
    k = M.c_ras_wm.certified_prefix(u_exec, ..., wm_preds)
    # 6) 审计 + 证书
    M.vqa_iii.submit_async(M.saf, probe, verdict, U_epi_map, lam)
    M.baseline_logger.log_if_eval(M.cfg.eval_mode)
    M.b_prev = b_t
    return k, lam, u_exec, (U_cal, U_epi_map)
```

## 3. 推导

**引理 23（轮/足接触信息互补）** 设轮通道与足通道的 Fisher 信息为 J_w、J_f，且其主特征方向在 θ=(μ,κ,s_θ,ρ,h) 上分别集中于 (μ, 滚动) 与 (κ,h,ρ)。在 A102（两通道观测条件独立、各自主方向夹角 > θ_min）下，交替使用两通道的估计误差满足 tr(J_w + J_f)^{-1} ≤ (1−δ)·max(tr J_w^{-1}, tr J_f^{-1})，δ>0 随正交度增大。系：**轮足交替接触严格优于任一单模态**，为「模式即探针」提供信息论依据，也为 R69 的「≥2 正交证据」补上物理来源。

**引理 24（安全-信息缺口与包络的必要性）** 记 𝒫 为认证探询包络（定义 340）。一般存在状态 x 与候选探询 (c,u) 使 VoI(c,u) > 0 而 (x,u) ∉ 𝒫。若允许越界探询，则期望最坏情形代价的下界严格大于零且随地形不确定性单调上升；限制在 𝒫 内可将探询诱发事故概率压到 O(ε_rec)，其中 ε_rec 为恢复策略失败率。系：**高 VoI 不能替代安全证明**；探询悖论只能靠包络消解，不能靠加权折中消解。

**引理 25（语义伪装的不可吸收性）** 设标定只作用于传感器偏置（r_res），语义伪装改变的是地图标签与真实 θ 的映射。若接触观测 y 与地图生成过程在给定 θ 下条件独立，则伪装造成的 r_map 期望不随标定窗口缩小而消失；n 次接触、m 种模式下的检出概率 ≥ 1 − Π_i (1 − p_det(u_i,c_i))，随接触次数与**模式多样性**上升。系：**语义错误只能被物理接触证伪，不能被标定解释掉**，这是 R70「标定不可吸收」在语义层的镜像。

**定理 20（严格包含链 TREAD ⊇ BELIEF ⊇ FLUID ⊇ R68）** 在 A102–A104 下，TREAD 的期望风险 ≤ BELIEF ≤ FLUID ≤ R68；且当 SMCG 越界、𝒫 = ∅ 或平台为纯轮/纯足时，TREAD 与 BELIEF 逐指令相同（定义 344/348）。安全侧层层不让步；效率与信息侧仅在「地图可信 ∧ 包络非空」时获得 resolution/affordance bonus。

**定理 21（模式切换安全与无突变）** 若 MRB 的解满足屏障约束 h(x,b) ≥ 0，且 HLC 的切换核满足 ‖u_{t+1}−u_t‖ ≤ L_M Δt（定义 334），则模式轨迹的物理风险 ≤ ε_mode，且控制连续（无 jerk 突变）；探询失败/超时/包络收缩时，π 单调退化到保守步态子问题。⇒ 轮足切换不会把 R70 的连续性保证打穿。

**定理 22（包络内探询的近优性）** 在 A105（胞级观测条件独立、探询收益随已探胞递减即子模）下，包络内贪心探询在预算 B 下达 (1−1/e) 近似最优；且因包络约束只删去不可行动作，贪心的近似比不劣于无约束情形。系：**在安全可行动作集上做 VoI 贪心，既有安全保证又有信息近似保证**。

class SemanticAffordanceField:
    def __init__(self, sem_net, grid, lambda_map=1.0):
        self.sem, self.grid, self.lambda_map = sem_net, grid, lambda_map

    def observe_extero(self, rgbd, pose):

        for c in self.grid.cells_under(pose):
            self._bayes_label(c, logits, src='extero')

    def query(self, c):
        return dict(w=self.w[c], mu=self.mu[c], Sigma=self.Sigma[c],
                    age=self.age[c], src=self.src[c])

    def risk(self, c, u, r_trav):
        H_l = entropy(self.w[c])
        H_th = 0.5 * logdet(2*np.pi*np.e*self.Sigma[c])
        return expectation(self.mu[c], lambda th: r_trav(th, u)) \
               + self.lambda_map * (H_l + H_th)          # 定义 337

    def update_contact(self, c, y, u):
        for l in self.w[c]:
            self.w[c][l] *= self._lik(y, u, self.mu[c][l], self.Sigma[c][l])
        self.w[c] = normalize(self.w[c]); self.src[c].add('contact')

# IP-276 HLC：连续混合（jerk 有界）
class HybridLocomotionController:
    def __init__(self, L_M): self.L_M, self.u_prev = L_M, None
    def blend(self, u_cmd, dt):
        if self.u_prev is None: self.u_prev = u_cmd
        du = clip_norm(u_cmd - self.u_prev, self.L_M * dt)
        self.u_prev = self.u_prev + du
        return self.u_prev                             # 定义 334

# IP-281 EPX：认证探询包络（安全先于信息）
class CertifiedProbingEnvelope:
    def __init__(self, barrier, Fmax, Imax, t_rec):
        self.barrier, self.Fmax, self.Imax, self.t_rec = barrier, Fmax, Imax, t_rec
    def contains(self, x, u, b_t):
        return (self.barrier(x, b_t) >= 0
                and contact_force(u) <= self.Fmax
                and motor_current(u) <= self.Imax
                and exists_recovery(x, u, b_t, self.t_rec))

# IP-277 CPX：包络内 VoI 贪心探询
def choose_probe(saf, b_t, epx, budget):
    best = None
    for (c, u) in candidate_contacts(b_t, saf):
        if not budget.allow(u) or not epx.contains(b_t.pose, u, b_t):
            continue                                   # 定义 340/341：越界不谈 VoI
        voi = saf.entropy(c) - expected_entropy_after_contact(saf, c, u)
        score = voi - phys_cost(c, u) - time_cost(c)
        if best is None or score > best.score:
            best = (c, u, score, voi)
    return best if best and best.score > 0 else None

# IP-278 MRB：模式-鲁棒 CVaR 规划
def plan_mode_robust(b_t, saf, beta=0.9, H=8, N_mc=16):
    def cost(pi):
        return cvar([rollout_cost(pi, saf_sample(saf)) for _ in range(N_mc)], beta)
    pi = argmin_pi(cost(pi), s.t. barrier_ok(pi, b_t))
    return conservative_gait_subproblem(pi) if cost(pi) > TAU_CVAR else pi

# IP-279 SMI：三残差语义完整性（语义不可吸收）
def semantic_integrity(y, u, saf, c, r_res, r_ext):
    r_map = y - expected_contact_under(saf, c, u)
    if norm(r_map) > TAU_MAP:
        if norm(r_res) < TAU_RES and norm(r_ext) < TAU_EXT:
            return 'semantic_error_or_camouflage'      # 定义 342/343
        if norm(r_res) > TAU_RES and norm(r_ext) > TAU_EXT:
            return 'terrain_change'
    return 'ok'

# IP-280/283 TREAD 主闭环（BELIEF 环上插入地形层；可逐指令退化）
def TREAD_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    b_t = M.bse.step(M.b_prev, o, M.last_action, M.last_g, M.last_y)  # pose,ψ,M_t
    M.saf.observe_extero(obs.rgbd, b_t.pose)                          # 外感知融合
    if M.smcg.reject(M.saf):                                          # 定义 344
        return M.belief_round(M, obs)                                 # 退化 R70
    pi = M.mrb.plan_mode_robust(b_t, M.saf)                           # 模式-鲁棒规划
    probe = (M.cpx.choose_probe(M.saf, b_t, M.epx, M.budget)
             if M.saf.max_entropy() > TAU_MAP_ENT else None)
    verdict = 'ok'
    if probe is not None:
        cell, u = probe
        y = M.epx.execute_contact(cell, u)                            # 有界风险探询
        verdict = M.smi.semantic_integrity(y, u, M.saf, cell,
                                           M.last_r_res, M.last_r_ext)
        M.saf.update_contact(cell, y, u)
        if verdict == 'semantic_error_or_camouflage':
            M.vqa_iii.flag(M.saf, cell, verdict)                      # 降低该区信任
    U_epi_map = M.saf.max_entropy()
    lam = max(M.efs.risk_scale(...), lam_floor(U_cal + alpha_gate(U_epi_map)))
    u_exec = M.hlc.blend(pi.first_mode(), dt=M.dt)                    # 连续切换
    k = M.c_ras_wm.certified_prefix(u_exec, ..., wm_preds)
    M.vqa_iii.submit_async(M.saf, probe, verdict, U_epi_map, lam)
    M.baseline_logger.log_if_eval(M.cfg.eval_mode)
    M.b_prev = b_t
    return k, lam, u_exec, (U_cal, U_epi_map)

## 4. 推导

**引理 23（轮/足接触信息互补）** 在 A102（轮/足观测条件独立、主方向夹角 > θ_min）下，J_w 与 J_f 在 θ 主方向上互补，交替接触的 tr(J_w+J_f)^{-1} 严格小于任一单模态的 tr J^{-1}。**含义**：轮足不只是效率/越障的折中，更是两条正交测量通道；「换模式」= 「换探针」。

**引理 24（安全-信息缺口）** 一般存在 VoI>0 但不在 𝒫 内的探询；允许越界会使最坏情形代价下界 > 0 且随地形不确定性上升；限制在 𝒫 内可把探询诱发事故概率压到 O(ε_rec)。**含义**：探询悖论不能靠加权折中，只能靠包络消解。

**引理 25（语义伪装的不可吸收性）** 标定只作用于传感器偏置；伪装改变「地图标签↔真实 θ」映射，r_map 期望不随标定窗口缩小而消失；n 次接触、m 种模式检出概率 ≥ 1−Π_i(1−p_det)，随接触与模式多样性上升。**含义**：语义错误只能被物理接触证伪。

**定理 20（严格包含链）** A102–A104 下 TREAD 风险 ≤ BELIEF ≤ FLUID ≤ R68；SMCG 越界/𝒫=∅/纯轮纯足时逐指令相同。**含义**：新层可关闭，安全不倒退。

**定理 21（模式切换安全无突变）** 屏障 + 连续性核 ⇒ 模式风险 ≤ ε_mode、控制连续；探询失败/包络收缩时单调退化到保守步态。**含义**：轮足切换不打穿 R70 连续性保证。

**定理 22（包络内探询近优）** A105（胞级独立、探询子模）下，包络内贪心达 (1−1/e) 近似最优，且近似比不劣于无约束情形。**含义**：在安全可行动作集上做 VoI 贪心既安全又有信息保证。
