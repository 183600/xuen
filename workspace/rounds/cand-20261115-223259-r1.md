# 第 11 轮（新灵感循环第 2 轮；本轮灵感：「长期记忆」×「模仿学习」）

> **基线**：第 10 轮 MetricVoiceGauge-STF-NRB-LS（定义 540–548；引理 87–91；实验 E571–E590）。
> 本轮纪律：**证据只加不减（Monotone Evidence）**。v10 看似三钥（语义 / 规范 / 轻量），但真正界定安全余量的只有一把——语义钥。τ_sem、β_STF 与 ν̄ 全部建立在“当前观测可校准、可及时看见变化”上；上轮自认的最大风险正是“τ_sem 是经验校准，对抗纹理可在 ν≤τ_sem 下同时击穿语义与学习模型”。本轮两个灵感各补一条**性质不同、失败模式不同**的证据源：长期记忆回答“这种情境我们**经历过并活着回来**吗”（经验证据）；模仿学习回答“这个动作**被人示范过、且动力学上还做得到**吗”（行为证据）。纪律是：新证据**只许加严、不许放宽**——可抬高有效余量、增加触发条件、扩充经认证的中止点，但绝不能降低 v10 的硬余量或抬高 τ_sem。由此 v11 对 v10 是**单调保守扩张**：执行集只缩不扩，认证中止集只扩不缩。

## 0. 直觉与动机

**灵感 1（长期记忆 → 只作证、不减负的经验证据）**
直觉：v10 的记忆只有 5 帧 EMA、20 帧 Δ_dom 与 2 s freshness，这是**工作记忆**，不是长期记忆。它不回答“同类情境过去错过多少次、错多大”。长期记忆的真正用途不是“记住地图”，而是把**跨回合的预测误差**变成可审计的统计量：按上下文签名 σ 分层，保留带出处的经验记录，用保形分位数给出“同类情境下一次误差的 (1−δ) 上界” β_mem，并要求**有效余量 β_eff = max(β_STF, β_mem)**。关键在方向：不是让记忆“降低”余量（那正是投毒攻击想要的），而是让记忆**只作证、不减负**——证据不足时 fail-closed，证据显示误差更大时抬高余量。由于 max 与合取都是单调的，**投毒最坏只能把系统退回 v10，而不能把 v10 变得更不安全**；代价移到可用性：攻击者可注入小误差记录制造“记忆支持”的假象，或注入大误差记录把 K_eff 压到 1。核心创新：**经验信任记忆（Episodic Trust Memory, ETM）**——分层经验库 + 出处/隔离（PQC）+ 保形上分位 β_mem + 自适应保形（ACI）+ 分层收缩（层内不足时取层间上界，仍只增不减）。

**灵感 2（模仿学习 → 无权威的三项用法）**
直觉：v10 的候选来自随机采样 64 条 + 证书过滤；模仿学习给出 π_D(a|c)，但它有复合误差与协变量偏移，**不能给权威**。于是只取三样没有权威的东西：(i) **提案分布**——提高采样效率，执行前仍逐块认证；(ii) **行为新颖度 ν_beh**——到示范动作流形的距离，它捕捉的不是“场景变了”而是“动力学/执行变了”（负载、磨损、标定漂移、执行器退化），是语义钥与记忆钥都不管的第三类故障；(iii) **示范导出中止点（DCAP）**——每个候选点必须经“从该点可认证安全停驻”的重放验证才可入集。三者都不改硬余量：执行集只会缩小，认证中止集只会扩大（多一个合法退路，最近中止距离不会变大）。核心创新：**示范锚定行为模型（Demonstration-Anchored Behavior Model, DABM）** + **证据门控证书（Evidence-Gated Certificate, EGC）**：Ĉ^★ = (Ĉ^+, β_eff, S, β_mem, ν_beh, γ_max)。

**三钥咬合**：语义钥（场景新不新）× 记忆钥（经验有没有、误差多大）× 行为钥（动力学像不像）。三者分别对应**感知漂移、经验外推、动力学漂移**三类失败；取合取，任一失败 ⇒ K=1 / 安全停。妙处与风险同源：若三者来自同一狭窄运营分布，“三钥皆过”可能只是同源偏差的三次复述——这是本轮必须显式量化并披露的（P19）。

## 1. 研究问题（轮次升级版）

- **Q1（经验证据）**：如何把跨回合经验压缩成带出处、可漂移、可保形校准的 β_mem，使“证据只加不减”在投毒、漂移与选择偏差下仍是可证的单向算子，而不是又一个不可证的全局前提？
- **Q2（行为证据）**：模仿先验在“无权威”约束下，能否用行为新颖度与示范导出中止点同时提升故障覆盖与采样效率，并保持 Exec_{v11} ⊆ Exec_{v10}、Abort_{v11} ⊇ Abort_{v10}？
- **Q3（证据经济学）**：当三钥证据同源时，如何量化其相关性 ρ_src 与“虚假确证”，并在可用性（K=1 比例）与对抗鲁棒性之间给出可预注册的权衡？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P19）

**P16 证据只加不减律（Monotone Evidence, EGC）**
新证据源只能抬高有效余量、增加触发条件、扩充经认证中止集；不得降低 β、不得放宽 τ_sem/τ_dom/Π_r。任何“有证据所以可放松”的提案一律拒绝并写入台账。

**P17 出处即证据律（Attestation-is-Evidence, PQC）**
只有带可验证出处且未隔离的样本可进入校准集；未认证样本再多也不构成支撑（S 只计 attested 记录）；认证失败或无支撑 ⇒ fail-closed（K=1），绝不以“样本多”代替“可追溯”。

**P18 示范无权威律（Demonstration-without-Authority, DABM）**
示范只提供提案、行为新颖度与经重放认证的中止点；不得直接产生可执行动作，不得改硬余量。行为先验失效 ⇒ 严格回退 v10 采样与触发集。

**P19 同源证据披露律（Source-Correlation Disclosure）**
三钥联合通过时必须同时报告同源比例 ρ_src 与条件独立性检验结果；ρ_src 高时不得声称“对抗鲁棒性提升”，只能声称“在已见分布内更保守”。该披露进入 Λ⁺，离线复盘可追责。

## 3. 与基线的接口（如何退化）

- **DABM 失效/超时** ⇒ 候选回退 v10 采样、ν_beh 触发移除 ⇒ 严格等价 v10（无权威，故无安全损失）；
- **ETM 失效/新鲜度超期/无支撑** ⇒ S<S_min ⇒ K=1（对 v10 的保守支配）；
- **PQC 失效** ⇒ 全部未认证记录隔离；若 attested S<S_min ⇒ K=1（fail-closed）；
- **DCAP 重放失败** ⇒ 该点丢弃，中止集回退 v10；
- 其余沿 v10 六级退化链（STF/NRB/AC/ID/MW/v8 中立元）。
- **形式化接口**：Exec_{v11} ⊆ Exec_{v10}；Abort_{v11} ⊇ Abort_{v10}（均经认证）⇒ 任何 v11 不安全事件 ⊆ v10 不安全事件（弱支配，引理 95–96）。

## 4. 预期贡献

1. **经验证据证书**：把“β 覆盖误差”从不可审计假设变成可失败的、单向的保形断言——记忆只能加严不能减负，投毒最多退回 v10（引理 92–94）；
2. **示范的三项无权威用法**：提案先验、行为新颖度（动力学故障通道）、示范导出中止点；模仿学习从“策略权威”降为“证据/提案”，安全上免费、效率上有益（引理 95–96）；
3. **三钥证据分类学**：感知漂移 / 经验外推 / 动力学漂移三类失败的合取门控，并显式量化同源偏差（P19、引理 97）；
4. **E591–E610** 覆盖保形覆盖、漂移、投毒、低慢投毒、行为新颖度、DCAP、同源偏差、可用性与长跑。

## 5. 本轮最大风险

**一句话**：三钥可能根本不独立——长期记忆与示范都从同一狭窄运营分布采样，于是“三钥皆过”只是同源偏差的三次复述，真正的 τ_sem 盲区仍在；更糟的是系统会因“三重证据”而降低人类警惕，并把频繁 K=1 的可用性压力转化为对 S_min/τ_beh 的行政性放宽，从制度层把单调安全律悄悄破坏。

# 第 11 轮产物 · 创新点清单 v11：**MetricVoiceGauge-REMI**（Recall-Evidence Memory & Imitation-gated Certificate）

**新增定义 549（上下文签名与分层）** σ(c) 由固定分箱的语义直方图、T 分位、Δ_dom 桶、任务原语与时段桶组成，先于观测结果固定（A5），不依赖 r_m。σ 相同或 Hamming 距离 ≤h_σ 的上下文并入同层；分层只用于**保守地取条件分位**，不允许用结果反向选择分层。

**新增定义 550（经验记录与记忆库）** m=(σ, t, a, φ̂, y, ω)，其中 φ̂=(ĝ_min, ê_max) 为生成时的证书预测，y=(观测最小间隙, 观测最大力矩, 接触标志, NRB 判定)，ω 为出处。ETM 在线仅保存每层 KLL 草图（ε_q=0.02，≤512B/层）与计数；原始 m 追加到 Λ⁺。记录一旦写入不可原地修改，只可被隔离标记覆盖。

**新增定义 551（记忆支撑与记忆新颖度）** S(c)=|{m: σ(m)=σ(c), ω attested, ¬quarantined, age(m)≤T_mem}|；ν_mem(c)=clip(1−S/S_min,0,1)。S<S_min ⇒ 记忆钥失败，K=1。T_mem 随漂移收缩：T_mem(t)=min(T_mem^0, c_τ/Δ_dom(t))，并在漂移事件时对受影响层重置 ACI。

**新增定义 552（保形记忆余量）** 设同层校准误差 r_(1)≤…≤r_(S)。取 k=⌈(S+1)(1−δ_cp)⌉；若 k>S 则 β_mem=⊥（无定义，K=1），否则 β_mem=r_(k)。ACI：δ_{cp,t+1}=δ_{cp,t}+η(α−err_t)，α=δ_cp，err_t 为最近一次是否 r_t>β_mem。分层收缩：β_mem(σ)=max(β_mem^local(σ), β_mem^pool(parent(σ)))，取 max 保持 P16。A4：漂移率有界使 ACI 长期误覆盖率 ≤δ_cp+ε_aci；A7：层内误差可交换；二者任一被检出违反 ⇒ fail-closed。

**新增定义 553（证据有效余量）** β_eff(ζ,t)=max(β_STF(ζ,t), β_mem(σ(c)))。证书的 ĝ_min 与 ê_max 一律用 β_eff；β_mem 无定义时整块不可证。单调性：任何 r_m 变化只能改变 β_mem，从而 β_eff 不降于 β_STF（引理 94）。

**新增定义 554（三钥信任域）** U_t^3key = U_t^sem ∧ (S(c)≥S_min) ∧ (β_mem 有定义) ∧ (ν_beh(c,a*)≤τ_beh) ∧ (freshness(ETM)≤T_mem)。任一子项为假 ⇒ K_eff=1。

**新增定义 555（示范先验与行为流形）** π_D(a|c) 为 INT8 两层 MLP（观测嵌入 64→64→动作 14），由带出处的示范离线训练、在线只前向；M_D 为示范动作块在低维嵌入空间的 ε-支撑（k 近邻距离）。π_D 只用于候选混合与打分，**不直接执行**。

**新增定义 556（行为新颖度）** ν_beh(c,a)=clip(d_emb(a,M_D)/τ_beh,0,1)，d_emb 为动作块嵌入空间中到 M_D 的 k 近邻距离。它监控的是**动力学/执行一致性**（负载、磨损、标定漂移），不是场景新颖性；其失效（DABM 不可用）只会移除一个触发条件，回退 v10。

**新增定义 557（示范导出中止点 DCAP）** 对每条示范轨迹抽取人类选定的退避位姿候选 p，仅当 (i) 出处 attested；(ii) 在当前 F̂_q 下从当前状态到 p 的 rollout 可生成有效证书；(iii) 从 p 可认证安全停驻（停车不变式 + 中止点集非空）时，才把 p 并入 Abort 集。验证失败即丢弃。并入后 `_nearest_abort` 在更大的合法集上取最近点，故停止距离不增。

**新增定义 558（证据门控证书）** Ĉ_t^★=(Ĉ_t⁺, β_eff, S, β_mem, ν_beh, γ_max)。Ĉ_t^★ valid ⇔ Ĉ_t⁺ 在 β_eff 下 valid ∧ U_t^3key ∧ (β_mem 有定义) ∧ (β_eff≤β_cap)，其中 β_cap 为使候选仍可满足 d_safe 的余量上限；若 β_mem 抬升导致无候选通过，则本块退回 K=1/安全停。

**新增定义 559（证据台账 Λ⁺）** Λ⁺ 继承 v10 定义 548 的哈希链，新增证据记录类型 EV：H(prev‖t‖type‖σ‖cert_digest‖evidence_digest‖ω)。块边界批量写；每 C_w=64 块校链头；缺口或认证失败 ⇒ 下一块 Π_r，并把未认证层全部隔离。

## 2. 形式化定义（要点与升级）

**定义 539-v11（有效块长）**：
```
K_eff(t) = 1                                     若 ¬U_t^3key 或 Ĉ_t^★ 不可得
         = 2                                     若 NRB 失效（Π_r）
         = max(1, ⌊K_max·(1 − min(1, max(Δ_dom/τ_dom,
                                          sup_走廊 T/τ_sem,
                                          max(0, β_mem/β_STF − 1),
                                          ν_beh/τ_beh)))⌋)   否则
```
与 v10 的双门控相比，新增两项**只可能增大**被 min 的自变量：β_mem 超过 β_STF 时按超出比例收缩块长；ν_beh 越接近 τ_beh 越收缩。两项都不出现在“放松”方向。

**定义 543-v11（结构化块证书）** 继承定义 543，但 `ĝ_min=min_k F̂_q,clearance−β_eff`、`ê_max=max_k F̂_q,effort+β_eff`；valid 条件追加 U_t^3key 与 β_mem 有定义。其余（停车不变式、中止点集非空、freshness、n_t）原样。

# IP-361 EpisodicTrustMemory：只作证、不减负
class EpisodicTrustMemory:
    def __init__(self, S_min=100, delta_cp=0.01, eta=0.01, T_mem0=14*24*3600):
        self.strata = {}                  # σ -> {sketch(KLL), n, aci_delta, last_t}
        self.S_min, self.delta_cp, self.eta, self.T_mem0 = S_min, delta_cp, eta, T_mem0

    def support(self, c):
        st = self.strata.get(signature(c))
        if st is None or age(st) > self.mem_horizon(c):
            return 0
        return st.attested_n           # 只计 attested、未隔离

    def beta_mem(self, c):
        st = self.strata.get(signature(c))
        if st is None or self.support(c) < self.S_min:
            return None                # 无定义 => 记忆钥失败 => K=1
        local = st.sketch.quantile(1.0 - st.aci_delta)   # 保形上分位
        pooled = self.pooled_quantile(parent(signature(c)))
        return max(local, pooled)      # 定义 552：分层收缩只增不减

    def update(self, rec):             # 块边界批量；ω 未认证则直接隔离
        if not pqc.attest(rec.omega):
            ledger.quarantine(rec); return
        st = self.strata.setdefault(rec.sigma, new_stratum())
        st.sketch.add(rec.r); st.attested_n += 1
        st.aci_delta += self.eta * (self.delta_cp - (1.0 if rec.r > self.beta_mem_of(st) else 0.0))
        ledger.append_evidence(rec)    # Λ⁺：append-only


# IP-362 DemonstrationAnchoredBehavior：提案、触发、认证中止点，均无权威
class DemonstrationAnchoredBehavior:
    def __init__(self, prior_int8, manifold, tau_beh=0.35, k=8):
        self.pi_D, self.MD, self.tau_beh, self.k = prior_int8, manifold, tau_beh, k

    def propose(self, c, n):
        return self.pi_D.sample(c, n)                  # 只提案

    def novelty(self, c, a):
        return clip(self.MD.dist(a, k=self.k) / self.tau_beh, 0.0, 1.0)

    def dcap(self, state, certifier, demos):
        out = []
        for p in demos.retreat_candidates(state):
            if certifier.replay_certifies(state, p):   # 定义 557 三条件
                out.append(p)
        return out


# IP-363 EvidenceGate：三钥合取 + β_eff
class EvidenceGate:
    def __init__(self, stf, etm, dabm, beta_cap=0.15):
        self.stf, self.etm, self.dabm, self.beta_cap = stf, etm, dabm, beta_cap

    def beta_eff(self, chunk, c):
        bm = self.etm.beta_mem(c)
        return None if bm is None else max(self.stf.beta_stf(chunk), bm)

    def trust_3key(self, c, a):
        return (self.stf.trust_ok(c)
                and self.etm.support(c) >= self.etm.S_min
                and self.etm.beta_mem(c) is not None
                and self.dabm.novelty(c, a) <= self.dabm.tau_beh
                and self.etm.fresh(c))


# IP-354（升级）：证据门控分块执行器
class EvidenceGatedCertifier(StructuredChunkCertifier):
    def generate_chunk(self, state, ctx, stf, nrb, etm, dabm, egc):
        K = self.effective_K_v11(ctx, stf, etm, dabm)
        if K == 1:
            return self._single_step_fallback(state)
        cands = self.policy.sample_sequences(state, K, n=48) + dabm.propose(ctx, 16)
        best = None
        for cand in cands:
            pred = self.Fq.rollout(state, cand)
            beta_eff = egc.beta_eff(pred, ctx)          # max(β_STF, β_mem)
            if beta_eff is None or beta_eff > egc.beta_cap:
                continue
            g_min = pred.min_clearance - beta_eff
            e_max = pred.max_effort + beta_eff
            if g_min < self.d_safe or e_max > state.tau_eff:
                continue
            pts = self._abort_points(state, cand, pred)
            pts = validate_and_merge(pts, dabm.dcap(state, self, ctx.demos))
            if not pts:
                continue
            chunk = Chunk(cand, CertStar(g_min, e_max, beta_eff,
                                         egc.etm.support(ctx.c),
                                         egc.etm.beta_mem(ctx.c)), pts)
            chunk, verdict = nrb.review_chunk(chunk, stf, ctx)
            if chunk is None:
                continue
            score = self.policy.score(chunk, pred)
            if best is None or score > best.score:
                best = chunk
        return best or self._single_step_fallback(state)

    def midchunk_guard(self, chunk, k_exec, live_obs, stf, nrb, etm, dabm, egc):
        """50Hz 四检 ≤0.6ms；检 3 升级为三钥（语义∧记忆∧行为）"""
        if not chunk.cert_still_valid(live_obs):                    # 检 1（v9 原检）
            return self._nearest_abort(chunk, k_exec)
        stop_inv = (live_obs.nearest_clearance
                    - self.d_brake(live_obs.speed) - self.d_safe)
        if stop_inv < chunk.remaining_len(k_exec):                  # 检 2（v9 原检）
            return self._nearest_abort(chunk, k_exec)
        a = chunk.actions[k_exec]
        if not egc.trust_3key(live_obs.context, a):                 # 检 3：三钥
            return self._nearest_abort(chunk, k_exec)
        if nrb.fast_norms(live_obs).violated:                       # 检 4：快规范
            return self._nearest_abort(chunk, k_exec)
        return ('continue', k_exec + 1)

## 4. 推导

**假设 A4–A7.** A4：漂移有界，ACI 长期误覆盖率 ≤δ_cp+ε_aci；A5：σ 与分层先于结果固定、不依 y 选择；A6：PQC 认证根不可伪造，未认证记录不能进入校准集；A7：同层内历史与当前误差可交换（无未观测时变混杂）。

**引理 92（保形记忆覆盖与单向性）** 在 A6、A7 下，若同层有 S≥S_min 条 attested 记录且 k=⌈(S+1)(1−δ_cp)⌉≤S，则对同层下一条记录，P(r>β_mem)≥1−δ_cp；且 β_eff=max(β_STF,β_mem)≥β_STF。证明：β_mem 取第 k 阶次序统计量即 split-conformal 上界，A7 给边际覆盖；A6 保证校准集无污染；max 的单调性给第二式。∎ 推论：v11 的误差覆盖不弱于 v10；记忆只能在证据显示误差更大时抬高 β_eff，绝不会降低它。

**引理 93（漂移下 ACI 覆盖与失效关闭）** 在 A4 下，ACI 更新使长期误覆盖率 ≤δ_cp+ε_aci；一旦 Δ_dom 检出漂移超过阈值，受影响层 T_mem 收缩、ACI 重置，且在新层 S<S_min 期间记忆钥失败、K=1。证明：ACI 的长期 regret 界（A4）+ 定义 551 的新鲜度门控；失效方向恒为保守。∎

**引理 94（投毒不可减负，最坏退回 v10）** 对任意记录扰动（含注入小误差或大误差、伪造 S），β_eff=max(β_STF,β_mem) 满足 β_eff≥β_STF；因此任何投毒都不能把有效余量降到 v10 以下。若攻击者用小误差记录伪造 S≥S_min，使其突破记忆钥，则 β_mem 变小、β_eff=β_STF，记忆钥退化为“无额外保守”，系统行为**至多等于 v10**；若注入大误差，则 β_mem 上升、β_eff 上升、K 收缩（可用性攻击）。故安全上投毒无收益，代价仅可用性与证据可信度。∎ 注：这正是“只作证、不减负”的核心；若允许记忆降低 β（常见做法），本引理立即失效。

**引理 95（示范无权威与弱支配）** DABM 只做三件事：向候选集加提案、把 ν_beh 作为 U_t^3key 的合取项、向 Abort 集加经定义 557 三条件验证的点。故 (i) 任一被执行的 continue 动作都通过 β_eff 下的 Ĉ_t^★，而 β_eff≥β_STF ⇒ Exec_{v11}⊆Exec_{v10}；(ii) 每个 DCAP 点都单独通过“从该点可认证安全停驻”，故 Abort_{v11}⊇Abort_{v10} 且最近合法中止距离不增；(iii) DABM 失效只移除提案与一个合取项，等价回退 v10。合起来：v11 不安全事件集 ⊆ v10。∎

**引理 96（行为新颖度的故障覆盖与复合误差界）** 设执行轨迹与最近示范轨迹的初始偏差为 0，单步模型误差 ≤β_q、跟踪误差 ≤δ_track，则第 H 步偏差 ≤H(β_q+δ_track)+H²·L/2（L 为动力学 Lipschitz），故 ν_beh 随偏差单调上升并在有限步内触发 K=1。该界是**充分而非必要**：若示范系统性避开某层（证据饥饿），该层 ν_beh 可能长期低位但记忆钥 S<S_min 仍会触发 K=1——两钥互补，不保证性能。∎

**引理 97（同源证据不可乘）** 设三钥在同一危险情境下的通过概率分别为 p_sem、p_mem、p_beh，联合通过概率 p_joint 满足 p_joint ≥ max_i p_i − ρ_src（ρ_src 为同源偏差可解释的质量上限），仅在条件独立时才可写成乘积。故 v11 **不声称**对抗逃逸率按 ε_sem·ε_mem·ε_beh 下降；报告必须给出 ρ_src 与最坏单钥逃逸率。证明：全概率分解 + 同源分量共享同一偏差项；P19 的披露要求是该界的可操作形式。∎

| 低慢投毒（E596） | 无安全回归 | 缩短 T_mem、加强 attested 抽检、冻结受影响层 |
| 提案效率（E597） | 候选 ↓≥40% | 调混合比、蒸馏 π_D、回退纯 v10 采样 |
| 行为触发（E598） | 领先 ≥5 帧、误报 ≤5% | 调 τ_beh/流形 k、加执行器残差通道 |
| 三钥消融（E599） | 逐级下降且如实报告 ρ_src | 若 ρ_src>0.7，撤回“对抗鲁棒性提升”声明 |
| 规避攻击（E600） | 最坏单钥逃逸有界且披露 | 加通道、限制声明范围、回退 K=1 策略 |
| DCAP（E601） | 中止点 +≥20%、错误 0 | 加严重放条件、缩短候选集 |
| 证据饥饿（E602） | 量化损失、不掩盖 | 报告性能-覆盖 Pareto，不调低 S_min 换指标 |

| 遗忘（E605） | 漂移稳定 | 缩短 T_mem、加漂移触发失效 |
| 台账（E606） | 检出 100% | 修链实现、缩短校验周期 |

| 配额（E608） | ≤160KB、≤65mW、总 ≤25W | 剪枝 DABM、降 KLL 精度 |
| 长跑（E609） | 漂移/体积稳定 | 周期重认证、层合并、ACI 重置 |

## 8. 本轮最大风险

**一句话**：三钥可能根本不独立——长期记忆与示范都从同一狭窄运营分布采样，于是“三钥皆过”只是同源偏差的三次复述，真正的 τ_sem 盲区仍在；更糟的是系统会因“三重证据”而降低人类警惕，并把频繁 K=1 的可用性压力转化为对 S_min/τ_beh 的行政性放宽，从制度层把单调安全律悄悄破坏。
