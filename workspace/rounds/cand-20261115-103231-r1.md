# 第 5 轮（灵感循环新周期第 1 轮；本轮灵感：「异常检测」×「Gazebo」）

> **基线**：第 4 轮 InstructGauge-WR（IP-328–333；定义 448–467；引理 59–62；实验 E457–E467）。第 3 轮 InstructGauge 五不变式、CVC 闭环、严格退化链继续继承。
> **本轮纪律**：**增量升级 + 严格退化**。异常检测与 Gazebo 都只允许**收缩**可采纳动作集，不允许扩张；任一增强失效必须一键退回 WR v4。

## 0. 直觉与动机

**灵感 1（异常检测 → 捕捉「未被契约枚举的失败」）**
直觉：前四轮的契约、漂移界、时空证书本质上都是「已知故障的白名单」——它们能证明「没发生我们想到的坏事」，但不能证明「没发生我们没想到的坏事」。异常检测的价值不是再做一个故障分类器，而是把高维执行遥测压成一个**开放的、无标签的新颖性信号**：当真实失败模式落在预注册契约之外时，它仍可能先以「分布外」的形态露头。但无监督信号没有语义、也没有天然的安全保证，所以它只能做**单向否决**：异常 ⇒ 截断/弃权/求助，绝不 ⇒ 授权。把「已知故障分类」与「未知异常弃权」分开，是本轮的第一条分层。

**灵感 2（Gazebo → 执行前的可证伪沙盒，而不是真实性的替身）**
直觉：Gazebo 给了我们一个数字孪生，可以在**物理提交之前**把候选块跑一遍：碰撞、IK 越界、时序超差、末端漂移都能先以仿真残差的形式暴露。这相当于把「事后回执」提前成「事前反证」。但仿真不是真值：sim2real gap 会让「仿真通过」与「现实安全」之间出现系统性偏差。正确用法不是相信 Gazebo，而是让 Gazebo 输出一个**带间隙证书的三值判断**：在 gap 界内可证明通过 / 可证明否决 / 其余一律弃权。Gazebo 的第二个用途是**故障合成实验室**：注入卡死、遮挡、摩擦突变、通信丢包，为异常检测提供校准与开放集评估，但必须按故障族切分，防止「只检测自己注入过的故障」。

**灵感 3（两者耦合 → 仿真校准的异常闸门，必须防止共模盲区）**
直觉：Gazebo 给异常检测提供标签与反事实，异常检测给 Gazebo 提供停机规则与 OOD 报警；两者耦合后，块内没有新契约回执的「证据真空」第一次有了传感器频率的实时信号。但最危险的耦合是**共模盲区**：如果仿真的物理模型错了，影子执行会稳定地「通过」同一类真实故障，而异常检测又恰好在同一特征上被仿真校准歪了。因此必须叠加三根结构：**单向否决**（异常只能收缩动作集）、**间隙门控**（gap 不可证时影子只能建议不能否决）、**盲区独立性**（至少一路独立于仿真模型的物理遥测：关节编码器/力矩/TF）。

## 1. 研究问题（本轮要回答什么）

- **Q1（开放集安全）**：无标签异常检测能否在不引入新攻击面的前提下，捕捉契约未枚举的失败？误报如何用共形/ACI 控制在可预注册的水平？
- **Q2（影子可迁移性）**：Gazebo 影子执行在什么 gap 条件下可以**可靠地**否决或放行一个块？三值逻辑能否给出「无错误放行、无误否决」的可证界？
- **Q3（耦合与块长）**：异常检测的检测延迟如何反过来约束分块长度 K？影子 + 异常能否把第 3/4 轮的「证据陈旧窗口」从定性风险变成可计算的 `K_anom`？

## 2. 四条设计原则（正式化见产物区定义 468–487）

**P1 单向否决（One-Sided Veto）**
任何异常/影子信号只能**删除**候选动作或**降低** K，不能新增动作、不能放宽阈值、不能替代硬契约。形式化：`A_ASG ⊆ A_WR`，且对异常分数单调不增（分数越高，集合越小）。

**P2 三值影子迁移（Three-Valued Shadow Transfer）**
影子结论只有三种：`pass`（在 gap 界内可证真实残差低于阈值）、`veto`（可证高于阈值）、`abstain`（gap 界内无法判定）。禁止把 `abstain` 当 `pass` 用；gap 证书缺失时，影子降级为 advisory（只能触发重规划，不能单独否决）。

**P3 传感器频率监测（Sensor-Rate Monitoring）**
块内决策可以稀疏（K 步一次），但异常监测必须每个传感器帧都跑；CUSUM/序贯检验的误报率用 `ARL₀` 预注册。K 只影响「决策摊销」，不允许影响「监测频率」——这是把证据陈旧窗口压回可界的关键。

**P4 盲区独立性（Blind-Spot Independence）**
影子执行与异常检测不得共享同一物理模型作为唯一证据源；至少一路必须是独立物理遥测（编码器、力矩、TF、腕部图像）。若独立性审计失败，异常层退化为已知故障分类器，影子层退化为名义单次仿真。

## 3. 与基线的接口（如何退化）

- Gazebo 不可用 / 影子超时 ⇒ `v_shadow ≡ abstain`，只保留异常监测；K 取漂移界与 `K_anom` 的较小者；
- gap 证书不可用或覆盖率不足 ⇒ 影子仅 advisory，不得单独 veto；
- 异常校准样本不足（`n < ⌈1/α⌉ − 1`）或独立性审计失败 ⇒ 关闭 `novel-abstain`，仅保留已知故障分类器；
- 异常监测与影子同时失效 ⇒ 退回 InstructGauge-WR v4；再失效 ⇒ InstructGauge v3 ⇒ ToolGauge；
- 跨不可逆动作 ⇒ 强制 K=1，影子只能模拟到屏障前，禁止跨屏障滚动。

## 4. 预期贡献

1. 一个「异常只收缩、不放行」的开放集安全口径，把无监督信号接入硬约束系统而不污染其可靠性；
2. 一个带 gap 证书的三值影子执行器，把 Gazebo 从「仿真演示」变成「可证伪的事前过滤器」；
3. 一条把检测延迟写进分块长度的定量规则 `K_anom(β)`，补齐第 3/4 轮「证据陈旧」只有定性约束的缺口；
4. 一套按故障族切分的开放集评估协议（E473–E488），显式检验「只检测自己注入过的故障」这一失败模式；
5. 完整退化链：ASG ⇒ WR v4 ⇒ InstructGauge v3 ⇒ ToolGauge。

## 5. 本轮最大风险

**一句话**：异常检测与 Gazebo 可能共享同一个错误的物理/特征假设，导致「影子通过 + 异常低分」的共模盲区——系统会以更高的置信度放行一类真实故障；这不是检测率不足，而是**独立证据缺失**，只能靠 P4 的硬性独立性审计与 gap 门控兜底。

# 第 5 轮产物 · 创新点清单 v5：**InstructGauge-ASG**（Anomaly-Shadow-Gazebo）

> 背景：第 4 轮 InstructGauge-WR（IP-328–333；定义 448–467；引理 59–62；实验 E457–E467）。
> 本轮灵感：「异常检测」×「Gazebo」
> **继承纪律**：WR 的 8C 闭环、CVC 证书、时空一致性、严格退化链全部保留。ASG 的每个组件都是**可选增强**，且只能收缩可采纳集。

## 2. 形式化定义（要点）

**定义 468（多模态遥测与名义参考）**
在时刻 `t`，T-Bus 输出
```
τ_t = [r_TF(t), r_enc(t), Δe_vis(t), r_CVC(t), Δt_j(t), u_t, q̇_t, f_t] ∈ ℝ^d
```
其中 `r_TF` 为旋转/平移残差，`r_enc` 为编码器-运动学残差，`Δe_vis` 为视觉嵌入漂移，`r_CVC` 为 CVC 后置残差，`Δt_j` 为时延抖动，`u_t` 为关节指令，`q̇_t` 为关节速度，`f_t` 为可选力矩。名义参考分布 `P_0^r` 在 regime `r=(scene, instruction_class, tool, speed_bin)` 下由预注册的名义 episode 估计；校准集 `S_0^r={s_1,…,s_n}` 假定在 `r` 内可交换。

**定义 469（异常集成分数）**
```
s_t = max{ s_t^dens, s_t^pred, s_t^proto }
s_t^dens  = -log p_θ(τ_{t-h:t})                  # 归一化流/密度模型
s_t^pred  = ||τ_t − f_φ(τ_{t-h:t-1})||_{Σ^{-1}}   # 一步时序预测残差
s_t^proto = min_{c∈C_known} ||φ(τ_t) − c|| / σ_c  # 到已知故障原型的距离
```
采用 `max` 是为了让任一通道报警都能抬高分数（对 veto 保守）；但阈值必须由共形校准决定，禁止直接比较原始分数。

**定义 470（分层共形 p 值）**
```
p_t = (1 + |{ s_i ∈ S_0^r : s_i ≥ s_t }|) / (|S_0^r| + 1)
```
若 `|S_0^r| < n_min(α) = ⌈1/α⌉ − 1`，按 `r → 粗粒度 r' → global` 逐级回退；回退路径记入 `AnomalyCert`。该样本量条件来自：要让一个超过校准集最大值的点满足 `p=1/(n+1) ≤ α`，至少需要 `n ≥ 1/α − 1`。

**定义 471（ACI 在线校准）**
```
α_{t+1} = clip( α_t + γ(α_0 − err_t), [α_min, α_max] ),  err_t = 1[p_t ≤ α_t]
```
在漂移有界时，标准 ACI 给出长程误报率 `≤ α_0 + O(γ)` 的松弛；`γ` 预注册后禁止在线调大，避免用校准换通过率。

**定义 472（CUSUM 报警）**
```
λ_t = max(0, λ_{t-1} + s_t − μ_0 − k),   k = (μ_1 − μ_0)/2
alarm_t = 1[λ_t > h]
N_d = inf{ t : alarm_t = 1 }
```
`h` 由 `ARL_0 ≥ N_0` 反解；对持续偏移 `μ_1`，检测延迟近似 `h/(μ_1 − μ_0 − k)`。

**定义 473（间隙证书）**
对配对 episode（同一块在仿真与真实各执行一次）：
```
δ_gap = Q_{1-β_g}({ |r_real(t) − r_sim^(nom)(t)| : t, episode })
GapCert = (δ_gap, β_g, coverage, regime, timestamp)
```
若 `coverage < 1-β_g` 或 regime 不匹配，则证书 invalid；invalid 的证书不能支撑 sound pass/veto。

**定义 474（影子 rollout 与逐场景最坏残差）**
```
Π_C = { π_C^(l) : l = (i,j), i∈[N_s], j∈[M_p] }
M_l = max_t r_sim^(l)(t)
M_max = max_l M_l,   M_min = min_l M_l
```
`i` 为物理种子，`j` 为扰动族 `P` 中的样本；`M_max` 是「最坏场景的最坏时刻」，`M_min` 是「最乐观场景的最坏时刻」。

**定义 475（ShadowCert）**
```
ShadowCert(C) = (C.id, {M_l}, M_max, M_min, v_shadow,
                 budget_used, seed_hash, P_hash)
```
`P_hash` 固定扰动族版本，防止事后换族；`seed_hash` 固定随机种子，支持回放审计。

**定义 476（AnomalyCert）**
```
AnomalyCert(C) = ({p_t}, {λ_t}, {tri_state_t}, t_alarm, t_trunc,
                  regime_backoff, α_path)
```
`t_trunc` 为按定义 479 截断后的最后保留步；`α_path` 用于审计 ACI 是否被异常拉动。

**定义 477（置信块长）**
```
K_anom(β) = min{ k : P(N_d > k) ≤ β } = F_{N_d}^{-1}(1-β)
```
并 clip 到 `[1, K_drift]`。若 `N_d` 校准不足或不可估计，`K_anom = 1`。直观：以至少 `1-β` 的概率，异常在块结束前触发并截断。

**定义 478（ASG 可采纳集）**
```
A_ASG(s) = { (C,ι) ∈ A_WR(s) :
             |C| ≤ K_anom(β) ∧
             v_shadow(C) ≠ veto ∧
             (C 不跨不可逆屏障 ∨ |C| = 1) }
```
单调性：异常分数上升、`δ_gap` 变宽、影子 veto 都只会使 `A_ASG` 变小；任何组件失效都只能退化为 `A_WR`，不能得到更大的集合。

**定义 479（异常感知截断）**
```
trunc_ASG(C,t) = C_{1:j*},  j* = max{ j < t : C_{1:j} ∈ A_kin ∧ C_{1:j} 前缀封闭 }
```
若不存在这样的 `j*`，`trunc_ASG(C,t)=∅`（整块放弃并求助）。这继承第 3 轮的前缀封闭，确保截断点本身是合法程序。

**定义 480（三值影子判定）**
给定有效 `δ = δ_gap`：
```
v_shadow = veto    if M_min > ε + δ
         = pass    if M_max < ε − δ
         = abstain otherwise
```
注意：`veto` 要求**所有**场景都违反（最乐观场景也违反），`pass` 要求**所有**场景都安全（最坏场景也安全）。这是在「扰动族 `P` 含真实 plant」假设下保持 soundness 的必要保守性；`P` 为单点时退化为 `M` 与 `ε±δ` 的直接比较。

**定义 481（gap-aware 可靠谓词）**
```
Sound(v, δ) = 1  iff  GapCert valid ∧
              (v = pass  ⇒ M_max < ε − δ) ∧
              (v = veto  ⇒ M_min > ε + δ)
```
`v = abstain` 时不声称结论，不参与放行；`Sound` 失败时影子只能 advisory。

**定义 482（已知故障后验与三态门）**
```
nominal        if p_t > α_t
known_anomaly  if p_t ≤ α_t ∧ max_k D_known(k|τ_t) ≥ β_known
novel_abstain  otherwise
```
`known_anomaly` 走已知故障处置；`novel_abstain` 走「截断 + 求助」；二者都不授权新动作。

**定义 483（反事实扰动族与鲁棒裕度）**
`P` 为预注册扰动族（摩擦系数、质量、通信时延、传感器噪声的区间/分布）。定义
```
m_C^pass = ε − M_max,   m_C^veto = M_min − ε
```
则 `pass ⇔ m_C^pass > δ`，`veto ⇔ m_C^veto > δ`；`|m| ≤ δ` 时 abstain。裕度把「三值」变成可画的标量区间。

**定义 484（anytime 影子预算）**
`B_C = (deadline d_C, N_max)`。若在 `d_C` 前未完成全部场景，返回 `abstain` 并记录 `budget_used`；**禁止用部分场景做 pass/veto**。允许的降级只有两种：完整三值 → 名义单点三值（显式假设真实 plant 为名义）→ abstain；不允许「抽掉难场景」这种会破坏 `P` 覆盖的做法。

**定义 485（故障族切分与泄漏谓词）**
故障族 `F={F_1,…,F_m}` 按「传感模态 × 注入机制 × 物理机制」切分。校准族 `F_cal` 与留出族 `F_test` 满足 `F_cal ∩ F_test = ∅`；`Leak(F_cal,F_test)=1` 当且仅当某测试族签名以相同参数出现在校准中。评估必须报告 `Leak=0`，否则「开放集」结论无效。

**定义 486（ASG 8C 组合算子）**
```
(C, ShadowCert, AnomalyCert, GapCert) = ⊙(C_WR, GSE, CAG, 3VL, S2R-G)
W → R → C → G(shadow) → E → S(sensor-rate anomaly) → V → U
```
相对 WR 的 7C，在 `C` 与 `E` 之间插入 `G`，并把 `S` 从「后置时空」扩展为「传感器频率异常 + 时空」双通道。

**定义 487（退化映射）**
```
D_ASG = ASG            if GSE 可用 ∧ GapCert valid ∧ CAG 已校准 ∧ 独立性审计通过
      = WR + K_anom    if GSE 不可用 ∨ GapCert invalid
      = WR + K_drift   if CAG 未校准 ∨ 独立性审计失败
      = WR             if 以上增强全失效
      = InstructGauge  if WR 失效
      = ToolGauge      if InstructGauge 失效
```

# IP-334 T-Bus：只观测，不决策
class TelemetryBus:
    def push(self, obs, tf, enc, vis_emb, cvc, t):
        tau = np.concatenate([
            tf.residual(), enc.residual(), vis_emb.delta(),
            cvc.residual(), [t - self.last_t], obs.u, obs.qdot,
            getattr(obs, "force", np.zeros(6)),
        ])
        self.ring.append((t, tau))
        self.last_t = t
        return tau

# IP-335 / IP-336：异常集成 + 分层共形 + ACI + 三态门
class ConformalAnomalyGate:
    def __init__(self, alpha0=0.01, gamma=0.005, beta_known=0.8):
        self.alpha0, self.alpha, self.gamma = alpha0, alpha0, gamma
        self.beta_known = beta_known
        self.S0 = defaultdict(list)          # regime -> calibration scores
        self.known = KnownFaultPosterior()

    def p_value(self, s, regime):
        S = self._resolve(regime)            # r -> coarse r' -> global
        return (1 + sum(x >= s for x in S)) / (len(S) + 1)

    def update_aci(self, p):
        err = 1.0 if p <= self.alpha else 0.0
        self.alpha = float(np.clip(
            self.alpha + self.gamma * (self.alpha0 - err), 0.001, 0.2))

    def decide(self, tau, regime):
        s = self.ensemble.score(self.tbus.window(8), regime)
        p = self.p_value(s, regime)
        self.update_aci(p)
        if p > self.alpha:
            return "nominal", p, s
        if self.known.max_posterior(tau) >= self.beta_known:
            return "known_anomaly", p, s
        return "novel_abstain", p, s

# IP-337 / IP-339：Gazebo 影子执行 + 三值判定
class GazeboShadowExecutor:
    def shadow(self, C, gap_cert, budget):
        if not gap_cert.valid:
            return ShadowCert(C.id, [], None, None, "abstain", 0, None, None)
        scenarios = self.sampler.sample(C, N_s=self.Ns, M_p=self.Mp)
        done, partial = parallel_rollout(self.sim, scenarios,
                                         deadline=budget.deadline)
        if not done:
            # 禁止部分场景做 pass/veto；只能退到名义单点或 abstain
            return self._nominal_or_abstain(C, gap_cert, budget)
        M = [max(r.trajectory) for r in partial]
        M_max, M_min = max(M), min(M)
        delta = gap_cert.delta
        if M_min > self.eps + delta:
            v = "veto"
        elif M_max < self.eps - delta:
            v = "pass"
        else:
            v = "abstain"
        return ShadowCert(C.id, M, M_max, M_min, v,
                          budget.used, self.seed_hash, self.P_hash)

# IP-338：配对回放估计 gap
class Sim2RealGapGovernor:
    def certify(self, paired_episodes, beta_g=0.05):
        diffs = [abs(r_real - r_sim)
                 for ep in paired_episodes
                 for r_real, r_sim in ep.aligned_residuals()]
        delta = quantile(diffs, 1 - beta_g)
        coverage = empirical_coverage(diffs, delta)
        return GapCert(delta, beta_g, coverage,
                       regime=paired_episodes.regime, valid=coverage >= 1 - beta_g)

# IP-340：ASG 主闭环（在 WR 的规划之后插入影子与传感器频率监测）
def asg_chunk(M, s, iota, H):
    C = M.iac.plan_chunk(iota, H, M.tools, M.budget_left(s), M.drift_bound(s))

    # 1) 置信块长 + 不可逆屏障
    K = min(M.drift.k_drift(s), M.cag.k_anom(beta=M.beta_k))
    if C.crosses_irreversible():
        C = C.truncate_to_barrier()
        K = 1
    C = C.cap_length(K)

    # 2) 影子前置过滤（决策边界只跑一次）
    shadow = None
    if M.shadow.available:
        shadow = M.shadow.shadow(C, M.gap.cert, M.budget.shadow(C))
        if shadow.verdict == "veto" and M.gap.cert.valid:
            C = M.iac.replan(C, reason="shadow_veto")
            if C is None:
                return ABSTAIN

    # 3) 执行 + 传感器频率异常监测
    t_alarm, t_trunc = None, len(C.actions)
    for t, a in enumerate(C.actions):
        if not M.cvc.joint_pre(a) or not still_grounded(iota, M.env):
            t_trunc = t
            break
        M.env.apply(a)
        tau = M.tbus.push(M.env.observe(), M.env.tf,
                          M.env.enc, M.env.vis_emb, M.env.cvc, M.env.time())
        state, p, score = M.cag.decide(tau, M.regime(s))
        if M.cusum.update(score) or state == "novel_abstain":
            t_alarm = t
            C = trunc_asg(C, t)
            t_trunc = len(C.actions)
            break
    anomaly = AnomalyCert(C.id, M.cag.p_path, M.cusum.path,
                          state, t_alarm, t_trunc,
                          M.cag.backoff_path, M.cag.alpha_path)

    # 4) 在线更新 gap 与校准（只更新，不上调阈值）
    M.gap.update_from_pair(C, M.env.telemetry_log())
    M.cag.absorb_calibration(M.env.telemetry_log(), regime=M.regime(s))

    # 5) 证书合并进 CVC
    M.ros_cvc.publish_cvc(C.id, len(C.actions), C.actions,
                          C.pre_conditions, C.post_conditions,
                          [M.last_spatial_cert, shadow, anomaly])
    return C, shadow, anomaly, bind_claims(C, iota, M.tcv.get_receipts())

def InstructGauge_ASG_round(M, obs, audio, tac, depth, det, ell=None):

    return MODGAUGE_round(M, obs, audio, tac, depth, det)   # 50Hz 主路径不变

## 4. 推导

**引理 63（单向安全 / 单调性）** `A_ASG(s) ⊆ A_WR(s)`；且对任意 `s ≤ s'`、`δ ≤ δ'`，`A_ASG(s',δ') ⊆ A_ASG(s,δ)`。
证明：`A_ASG` 由 `A_WR` 与三个额外约束（`|C|≤K_anom`、`v_shadow≠veto`、不可逆屏障）的交集定义，额外约束只会删元素；`s` 增大使 `p_t` 减小、更易进入 `known/novel` 否决分支，`δ` 增大使 pass 区间 `(ε−δ, ε+δ)` 变宽、更易 abstain，二者都只删元素。故 WR 的任何安全性质对 ASG 仍成立；异常/影子的**漏报**最多让 `A_ASG` 退化为 `A_WR`，不会越权。∎

**引理 64（共形误报控制与样本复杂度）** 在 regime 内可交换假设下，对名义点 `p_t` 超均匀，`P(p_t ≤ α) ≤ α`；若新颖点分数严格超过校准集最大值，则 `p_t=1/(n+1)`，要使其 `≤α` 需 `n ≥ ⌈1/α⌉−1`。在分布漂移下，ACI 的 `α_t` 路径满足长程误报率 `≤ α_0 + O(γ)` 的标准松弛。
证明：共形 p 值的秩论证给出超均匀性；样本量结论由 `1/(n+1) ≤ α` 直接解得；ACI 结论引用 Gibbs–Candès 的自适应共形推断界，`γ` 固定时漂移有界则误报率以 `O(γ)` 逼近目标。分布漂移破坏可交换性时，必须按 regime 分层并记录回退，否则该界失效。∎

**引理 65（三值影子的 gap-条件可靠性）** 设 `GapCert` 有效，且真实 plant 属于扰动族 `P`，真实残差与对应仿真残差满足 `|r_real(t) − r_sim^(l*)(t)| ≤ δ`。则：`v_shadow=veto ⇒` 真实轨迹违反 `ε`；`v_shadow=pass ⇒` 真实轨迹满足 `ε`；`v_shadow=abstain` 不作声称。
证明：设 `l*` 为真实 plant 对应场景。若 `veto`，则 `M_min > ε+δ`，故 `M_{l*} ≥ M_min > ε+δ`，存在 `t` 使 `r_sim^(l*)(t) > ε+δ`，于是 `r_real(t) ≥ r_sim^(l*)(t) − δ > ε`，违反成立。若 `pass`，则 `M_max < ε−δ`，故 `M_{l*} ≤ M_max < ε−δ`，对任意 `t` 有 `r_sim^(l*)(t) < ε−δ`，于是 `r_real(t) ≤ r_sim^(l*)(t) + δ < ε`，安全成立。中间区间无法判定，只能 abstain。∎
注意：`veto` 用 `M_min` 是保守的——要求最乐观场景也违反；`pass` 用 `M_max` 要求最坏场景也安全。两者都以更高的 abstain 率为代价换取 soundness。

**引理 66（检测延迟与块暴露界）** 若监测器以传感器频率运行，CUSUM 检测延迟为 `N_d`，块长为 `K`，则新型故障在块内的未检测暴露步数 `E ≤ min(K, N_d)`；若 `K ≤ K_anom(β)`，则以至少 `1−β` 的概率在块结束前触发截断，未检测暴露 `≤ K_anom(β)−1`。
证明：若 `N_d > K`，整块执行完才可能报警，暴露 `K`；若 `N_d ≤ K`，首次报警发生在第 `N_d` 帧，按定义 479 截断到最后一个合法前缀，暴露至多 `N_d`。故 `E ≤ min(K,N_d)`。由 `K_anom(β)` 的定义，`P(N_d ≤ K_anom(β)) ≥ 1−β`，在该事件下暴露不超过 `K_anom(β)−1`。∎

**引理 67（场景覆盖的统计裕度，仅 advisory）** 若扰动场景 iid 采样自 `P`，观测到 `N` 个场景全部安全，则真实 plant 的违反概率 `p` 满足 `P(p ≤ β) ≥ 1 − (1−β)^N`；给定置信 `1−γ`，需 `N ≥ ln γ / ln(1−β) ≈ (1/β) ln(1/γ)`。
证明：`P(全部 N 个安全 | p) = (1−p)^N`；令 `(1−β)^N ≤ γ` 即得。该结论把 `P` 当作先验采样分布，是对「随机抽取的 plant」的统计保证，不是对单一真实 plant 的确定性保证，因此只能用于 advisory 与预算设计，不能替代引理 65 的 sound pass/veto。∎

**引理 68（退化等价性）** `D_ASG` 满足：Gazebo 不可用 ⇒ `v_shadow≡abstain` ⇒ `A_ASG = A_WR ∩ {|C|≤K_anom}`；CAG 未校准 ⇒ `K_anom=K_drift` 且关闭 `novel_abstain` ⇒ `A_ASG=A_WR`；两者都失效 ⇒ ASG 与 WR 在动作集上等价；WR 失效 ⇒ 回到 InstructGauge v3 的既定退化链。
证明：逐项代入定义 478 与 487：`v_shadow≡abstain` 不删任何块，仅保留 `K_anom` 约束；CAG 未校准使 `K_anom=K_drift` 且三态门只剩 `nominal`，不再额外否决；两项均失效时额外约束为空，`A_ASG=A_WR`。其余由 WR 的退化链传递。∎

## 9. 本轮最大风险

**一句话**：异常检测与 Gazebo 可能共享同一个错误的物理/特征假设，形成「影子通过 + 异常低分」的共模盲区，使系统以更高置信度放行一类真实故障；这不是检测率不足，而是**独立证据缺失**，只能靠盲区独立性审计与 gap 门控兜底。
