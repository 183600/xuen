# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化证据」IP-133~138；灵感循环第 4 轮；本轮灵感：「安全交互」×「6D位姿估计」）

> 第 57 轮把承诺的凭证从"证据质量"升级为"少样本可校准、跨模态可对账、个性化有界的证据承诺"——元先验给效率、共形带保底、模态分账对账、信任单向有界。但它全部的信念对象仍是**标量化的区域属性** θ=(μ,k,F_bear)：默认"接触发生在哪里"已知，只对"接触起来什么感觉"不确定。这个默认在真正需要交互时崩塌：扶门把、掀箱盖、踏上凸起、把物体递给人的手，第一步都是**先知道目标在 6D 空间里到底在哪、朝哪、有多大不确定**。本轮两个灵感正好补上这一维：**6D位姿估计**把信念对象从标量属性升级为 SE(3) 上的**位姿不确定性集合**，并把对称性、遮挡、多峰后验这些"点估计时代被抹平"的结构重新摆上台面；**安全交互**把安全从"点谓词"升级为"集合上的鲁棒谓词"——交互必须对**整个位姿集合**都安全，而不是只对最可能的位姿安全。两者合流出一个更强的命题：**安全不是对预测的置信，而是对不确定集合的鲁棒**；接触不仅是验证材质的探针，更是在安全前提下**主动消歧位姿**的信息动作。核心命题由"证据说可信"升级为 **"位姿集合可认证、对称可商化、接触可安全地学习"**。

核心矛盾：
- **H29（点估计 vs 集合安全）**：6D 位姿在对称、遮挡、重复纹理下天然多峰；点估计+高斯协方差在"最可能位姿"附近高置信，却可能整块漏掉真实位姿（欠保护），同时又沿任务无关方向（例如绕对称轴的偏航）虚耗裕度（过保护）。安全必须对集合成立，且只在**任务相关方向**上收窄。
- **H30（安全 vs 信息）**：最安全的动作（不接触、后退）零信息；最能消歧位姿的动作（在模糊接触面上试触）恰恰风险最高。安全交互必须把风险当成购买位姿信息的货币，且只允许在"当前整个位姿集合都安全"的动作上花这笔钱——否则主动感知本身就是赌博。
- **H31（位姿-材质混淆）**：接触响应（力、滑移、声、本体挠度）同时受位姿误差与材质影响——"按深了"与"更硬"在低维力信号上不可分。若第 57 轮的地形/材质信念与本轮的位姿信念不联合推断，位姿误差会被记成材质，材质误差也会被记成位姿，二者互相"洗白"。

## 0. 直觉与动机

**灵感 1（6D位姿估计 → 从点估计到可认证的集合）**
直觉：位姿网络吐出一个数字，但真实世界给的是一片云。物体对称（杯子可绕轴转任意角）、遮挡（只看到三条棱）、重复纹理都会让这片云**分成好几个峰**，取 argmax 等于把多峰压成单峰，然后把"选错了峰"这件事伪装成一个很小的协方差。正确的问法不是"最可能是哪个位姿"，而是"**哪些位姿还可能是真的**"：用分裂共形预测把位姿误差的 (1−α_pose) 分位包成 SE(3) 上的集合 P_r，允许它是多个球的并集；一旦分布漂移（新物体、新光照、标定漂移）就借第 57 轮的 OOD 门把半径放大，宁可又宽又慢，不可又窄又错。位姿集合才是感知交给交互的**诚实接口**。

**灵感 2（安全交互 → 安全是集合上的最坏情形，而不是点上的平均情形）**
直觉：若真实位姿可能在 P_r 里的任何一处，那么"按最可能位姿算出来力不会超限"根本不构成安全论证——真实位姿落在集合边缘时可能已经压穿或打滑。安全交互的正确形式是**对集合取最坏**：对每个 T∈P_r 算安全裕度 Φ(T,u)，要求 min_T Φ ≥ m_safe。逐点求最坏代价高且不可导，于是用一个**保守内近似**：裕度对位姿在任务度量下 Lipschitz，取名义位姿裕度减去 L_Φ·集合半径——只会低估、不会高估裕度，方向永远偏向保守。

**灵感 3（合流 → 接触即"安全可学习"的位姿探针）**
直觉：接触是天然的消歧器——推一下就知道把手在哪一侧，压一下就知道是硬壳还是软垫。但接触不可逆，随便碰就是拿硬件试错。把灵感 1、2 合起来，定义**安全可学习接触**：只在"对所有可能的位姿假设都安全"的动作集合里，挑信息增益/风险最大者去碰。于是探索的信息价值与安全约束被同时满足——**信息只能安全地买**，因为安全约束在碰之前已对整个集合评估过，哪怕真实位姿正是少数派假设，这一碰仍然安全。

**灵感 4（对称商 → 不为无关不确定性付费，但必要时主动破对称）**
直觉：杯子绕竖直轴转 37° 还是 90°，对"从正上方抓"毫无区别；把这些位姿都当成不同假设，就是在为**任务无关**的方向支付安全裕度。用对称群把位姿空间商掉（T∼T·g），再投影到任务相关特征 π_τ，只对剩下的"有效不确定性"付钱。但商化有暗礁：若任务恰需要区分对称等价位姿（"哪一侧是把手"），商会把它们并成一类——此时必须**主动**设计一个对所有对称等价位姿都安全、又能区分它们的接触，这正是灵感 3 的特例。

**灵感 5（联合辨识 → 位姿与材质写进同一张因子图）**
直觉：H31 的混淆是致命的。解决之道不是"先估位姿再估材质"的串行管线，而是把位姿结点和材质结点放在同一张因子图上联合推断；再设计**可辨识探针**——在"已知材质、未知位姿"和"已知位姿、未知材质"两种条件下各取一次接触，用差分把两个混淆项分开。这类探针同样要过灵感 2、3 的安全门。

**灵感 6（PCE++ → 位姿集-安-学的内循环嵌进探-诺-演）**
直觉：第 57 轮的 PCE+ 在区域层做"探-诺-演"；本轮在它的每个检查点里再嵌一个内循环：**位姿集合 → 鲁棒安全 → 安全消歧接触 → 联合更新**。外层探针预算 k_probes 与内层接触预算 k_contact 分离且总量守恒，所有新机制仍只经"信念更准（集合更小）或动作更保守（裕度更大、更早撤退）"两条通道影响系统，延续并强化交互单调性。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（可认证位姿不确定性集合 CPUS）** 6D 位姿估计器输出多源多假设集 Ĥ={(T_i,w_i)}（RGB-D/点云/触觉/本体），按位姿度量聚为 K 个模态簇；一致性得分 s(T;o)=min_k d(T,T_k)（d 取 ADD-S 或任务残差）。分裂共形校准：在校准集上取残差 e_j=s(T_j^true;o_j)，阈值 q̂_α=Quantile_{⌈(n+1)(1−α_pose)⌉}({e_j})；观测 o 的认证集合 P_r={T:s(T;o)≤q̂_α}=∪_k Ball(T_k,r_k)（各簇按质量分配 α 并用 union bound 得 r_k）。覆盖契约：可交换性下 P(T_true∈P_r)≥1−α_pose；OOD 门（继承 IP-133）判分布外 ⇒ 半径乘 γ_shift 或拒绝交互。任务相关投影 π_τ:SE(3)→ℝ^d（接触点、法向、接近轴、可达姿态），有效半径为 r_τ(P_r)=diam_{M_τ}(π_τ(P_r))，M_τ 为任务度量。与第 57 轮共形带的区别：那里保标量后验覆盖，这里保"真实位姿落在 SE(3) 集合内"，且集合允许多峰。

**定义 140（位姿条件鲁棒安全包络 PRSE）** 交互计划 u=(接触帧、法向力曲线 f(t)、阻抗 K_d、时长、撤退轨迹)。对 T∈P_r 定义安全裕度 Φ(T,u)=min{力上限余量, 压强余量, 滑移稳定余量, 倾覆余量, 力矩余量, 碰撞距离余量}（可挂 ISO/TS 15066 式功率-力限制约束）。鲁棒安全 ⇔ Φ_min(P_r,u)=min_{T∈P_r}Φ(T,u)≥m_safe，m_safe 吸收第 56/57 轮的模型与证据误差。可计算化：若 Φ 在任务度量下 L_Φ-Lipschitz，则 Φ_min≥Φ(T̂,u)−L_Φ·r_τ(P_r)（各向异性椭球版用 M_τ 加权），这是**保守内近似**——只低估裕度，不高估。

**定义 141（安全可学习接触 SLC）** 候选接触 u 的位姿信息增益 IG(u)=H(P_r)−E_{z∼p(z|T,u)}[H(P_r|z)]（H 取集合微分熵或有效半径 r_τ 的下降），观测 z=(六维力/力矩、滑移、声、本体挠度)。可执行集 U_safe(P_r)={u: Φ_min(P_r,u)≥m_safe ∧ recovery_reachable(u) ∧ cost(u)≤budget}。选 u\*=argmax_{u∈U_safe} IG(u)/risk(u)；若 U_safe 为空或最优 IG 低于阈值 ⇒ 后退/换路/请人。关键保证：安全约束在**整个 P_r** 上评估，故真实位姿为集合内任一假设时该接触仍安全——信息不能以瞬时安全为代价购买。接触观测按 IP-134 模态分账入账并参与位姿假设的贝叶斯/粒子更新。

**定义 142（安全交互契约 SIC 与证书 J_i）** 交互承诺需同时满足：(a) 位姿集合已认证且分布内（覆盖≥1−α_pose，OOD 通过或已放大）；(b) 鲁棒安全 Φ_min(P_r,u)≥m_safe；(c) 消歧风险预算未超（继承第 55/56 轮风险预算/同意阶梯，累计接触风险≤B_risk）；(d) 撤退可达：对最坏位姿 T_worst∈P_r 存在 ≤τ_abort 的安全退出；(e) 高风险交互需人授权（继承 IP-135 PTM，auth 决定佐证与超时）；(f) 接触扳手锥/接触帧验证通过。证书 J_i=(P_r,q̂_α,r_τ,Φ_min,u,IG,risk_budget,recovery,J_p)，继承 J_p 全检。

**定义 143（对称商与各向异性裕度 SAQ）** 对称群 G_sym（离散如 90° 旋转，连续如绕轴旋转）；位姿等价 T∼T·g。任务相关商：若 π_τ(T)=π_τ(T·g) ∀g∈G_sym，则有效集合 [P_r]_τ=π_τ(P_r)/G_sym，其直径决定真正需支付的裕度。各向异性度量 M_τ：安全关键方向（接触法向、重力投影、接近轴）权重高，对称/冗余方向权重低；关键方向永不被商掉。破对称检测：当任务需区分对称等价位姿（"哪一侧是把手"），商把它们并成一类，此时必须**主动**设计对所有对称等价位姿都安全且能区分它们的接触（SLC 特例）。

**定义 144（安全-估计共演化算子 SIE / PCE++）** 交互检查点内循环：①多源 6D 位姿推断→认证集合 P_r（OOD→放大或拒）；②鲁棒安全评估 Φ_min（含 L_Φ 界）；③若 Φ_min<m_safe：枚举 U_safe 的消歧接触，有信息且预算允许则执行并更新 P_r，否则后退/换路/请人；④**联合更新**：接触同时更新位姿集合与地形/材质信念（IP-133/134），用共享因子图避免 H31 混淆；⑤以 SIC 承诺，交互中在线监控（力/位姿跟踪），实测离开鲁棒包络即中止并进入恢复；⑥终止于 {安全交互, 后退改道, 人工接管, 安全停}。与 IP-138 的关系：PCE+ 只在区域层探-诺-演，SIE 在其每个检查点内嵌"位姿集-安-学"内循环，外层 k_probes 与内层 k_contact 分离且总量守恒。

## 2. 关键算法伪代码（完整版见产物区）

```python
def certified_pose_set(obs, pose_net, cal, alpha_pose):
    H = pose_net.hypotheses(obs)                   # 多源多假设
    clusters = cluster_pose(H, metric=adds)        # 对称/遮挡 → 多峰
    r = cal.split_conformal_radius(clusters, alpha_pose)  # 各簇 union bound
    P = union(Ball(T_k, r_k) for T_k in clusters)
    if ood_score(obs) > theta_ood:                 # IP-133 门
        P = inflate(P, gamma_shift)                # 宁可宽、不可错
    return P

def robust_margin(P, u, task):
    T_hat = nominal(P); r_tau = diam_task(P, task.M_tau)
    return margin(T_hat, u) - task.L_phi * r_tau   # 保守内近似

def safe_to_learn(P, task, budget):
    U = [u for u in contact_candidates(task)
         if robust_margin(P, u, task) >= task.m_safe
         and recovery_reachable(u) and budget.allows(u)]
    return max(U, key=lambda u: info_gain(P, u) / risk(u)) if U else None

def safe_interaction_loop(P, terrain, task, budget):
    while True:
        u = plan(P, task)
        if robust_margin(P, u, task) >= task.m_safe:
            return commit(u, SIC(P, u, terrain))   # 承诺（附证书 J_i）
        u_probe = safe_to_learn(P, task, budget)
        if u_probe is None:
            return retreat_or_ask(P, task)         # 无安全信息动作 → 退
        z = execute(u_probe)
        P = bayes_update(P, z, contact_likelihood) # IP-141
        terrain = joint_update(terrain, z, P)      # IP-144 防 H31 混淆
        P = recalibrate_conformal(P, cal)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| CPUS | O(N_h·d_pose+N_cal log N_cal)/次 | O(N_cal) | 共形覆盖≥1−α_pose、OOD 放大诚实 |
| PRSE | O(\|P_r\|·C_Φ) 或 O(C_Φ)（Lipschitz 界） | O(d_τ) | Φ 的 Lipschitz 界成立、m_safe 足够 |
| SLC | O(\|U\|·(IG+C_risk)) | O(\|P_r\|) | U_safe 内选、恢复可达 |
| SAQ | O(\|G_sym\|·d_τ) | O(d_τ) | 关键方向不被商掉 |
| SIC | O(\|σ\|·C_Φ) | O(\|σ\|) | 六条件全过才签发 J_i |
| SIE | O(k_contact·(\|U\|·IG+N_h·d_pose)) | O(N_h+\|σ\|) | k_contact 终止、内外预算守恒 |

**正确性定理（Pose-Set Safe Interaction, PSSI 概要）** 在 A33–A40 上加：**(A41)** 位姿集合覆盖 P(T_true∈P_r)≥1−α_pose，OOD/漂移检测诚实；**(A42)** 安全裕度 Lipschitz 界 \|Φ(T,u)−Φ(T̂,u)\|≤L_Φ d_τ(T,T̂) 成立且度量任务相关；**(A43)** 接触观测模型诚实、接触预算有限；**(A44)** 位姿-材质联合可辨识，或由可辨识探针强制满足。则：(i) 若签发 SIC，交互违反安全约束的概率 ≤α_pose+δ_model+δ_force，且交互中监控把超界暴露时间限制在 τ_abort 内；(ii) **信息不能购买安全**：所有执行的消歧接触在 P_r 上鲁棒安全，探索不提高瞬时越界概率（除集合漏覆盖项）；(iii) **无免费对称**：商化不削弱安全关键方向，因 M_τ 始终包含关键方向且裕度只在非关键方向收缩；(iv) SIE 在 k_probes+k_contact 内终止于 {安全交互, 后退改道, 人工接管, 安全停}。

### IP-139 CPUS（可认证位姿不确定性集合）

```python
def certified_pose_set(obs, pose_net, cal, alpha_pose, ood_gate):
    H = pose_net.hypotheses(obs)                    # 多源多假设
    clusters = cluster_pose(H, metric=adds)         # 对称/遮挡 → K 个峰
    # 各簇按质量分配 α，并 union bound 得每簇半径
    rs = cal.split_conformal_radius(clusters, alpha=alpha_pose)
    P = union(Ball(T_k, rs[k]) for k in range(len(clusters)))
    if ood_gate.score(obs) > ood_gate.theta:        # 继承 IP-133
        P = inflate(P, gamma_shift)                 # 漂移 -> 宁可宽
    return PoseSet(P, coverage=1 - alpha_pose, r_tau=diam_task(P, task.M_tau))
```

### IP-140 PRSE（位姿条件鲁棒安全包络）

```python
def robust_margin(P, u, task):
    T_hat = nominal(P)
    r_tau = diam_task(P, task.M_tau)
    phi_nom = min_constraint_slack(T_hat, u)         # 力/压强/滑移/倾覆/力矩/碰撞
    return phi_nom - task.L_phi * r_tau              # 保守内近似，只低估

def robust_safe(P, u, task):
    return robust_margin(P, u, task) >= task.m_safe
```

```python
def safe_to_learn(P, task, budget):
```

```python
def safe_interaction_contract(P, u, terrain, persona, budget, task):
```

### IP-143 SAQ（对称商与各向异性裕度）

```python
def task_quotient(P, task):
    Pq = [canonical(T, task.G_sym) for T in P.hypotheses]
    Pq = project(Pq, task.pi_tau)              # 只保留接触相关特征
    return PoseSet(Pq, M_tau=task.M_tau)

def diam_task(P, M_tau):
    # 各向异性：关键方向权重高，对称/冗余方向权重低
    return max(norm(M_tau @ (pi_tau(T) - pi_tau(T2)))
               for T in P for T2 in P)

def break_symmetry_needed(P, task):
    # 任务需要区分对称等价类 -> 必须主动设计安全破对称接触
    return len({pi_tau(T) for T in P}) < len(P) and task.requires_disambiguation
```

```python
def safe_interaction_estimation(x0, terrain, task, persona, budget):
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CPUS | O(N_h·d_pose+N_cal log N_cal)/次 | O(N_cal) | 共形覆盖≥1−α_pose、OOD 放大诚实（A41） |
| PRSE | O(\|P_r\|·C_Φ) 或 O(C_Φ)（Lipschitz） | O(d_τ) | Φ 的 Lipschitz 界、m_safe 充分（A42） |
| SLC | O(\|U\|·(IG+C_risk)) | O(\|P_r\|) | U_safe 内选、恢复可达（A43） |
| SIC | O(\|σ\|·C_Φ) | O(\|σ\|) | 六条件全过才签发 J_i |
| SAQ | O(\|G_sym\|·d_τ) | O(d_τ) | 关键方向不被商掉 |
| SIE | O(k_probes·N_h·d_pose+k_contact·\|U\|·IG) | O(N_h+\|σ\|) | k_probes+k_contact 终止、内外预算守恒 |

**正确性定理（Pose-Set Safe Interaction, PSSI）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 位姿集合覆盖：可交换性下 P(T_true∈P_r)≥1−α_pose，OOD/漂移检测诚实，放大因子 γ_shift 覆盖检出残差；**(A42)** 安全裕度 Lipschitz：‖Φ(T,u)−Φ(T̂,u)‖≤L_Φ d_τ(T,T̂)，且 M_τ 包含全部安全关键方向；**(A43)** 接触观测模型诚实、接触预算 k_contact 有限、恢复轨迹在 τ_abort 内可达；**(A44)** 位姿-材质联合可辨识，或由可辨识探针强制满足。则：

1. **鲁棒安全性**：若签发 SIC，则 P(交互违反力/滑移/倾覆等硬约束) ≤ α_pose+δ_model+δ_force；交互中在线监控把超界暴露时间限制在 τ_abort 内，且触发即进入恢复。
2. **信息不能购买安全**：所有被执行的消歧接触在整个 P_r 上鲁棒安全，因此主动感知只可能通过"集合缩小"降低未来风险，不提高当下越界概率（除集合漏覆盖项 α_pose）。
3. **无免费对称**：商化仅在非关键方向收缩裕度；π_τ 的白名单保证接触法向、重力投影、接近轴等关键方向始终计入 r_τ。
4. **终止性**：每检查点接触 ≤k_contact，外层探针 ≤k_probes，SIE 在 k_probes+k_contact 内终止于 {安全交互, 后退改道, 人工接管, 安全停}。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (α_pose·1[集合漏覆盖] + δ_model + δ_force·1[接触])
             − P(漂移未检出) − P(接触模型共谋) − P(τ_abort ∧ 恢复失效)
```

关键：**感知交给交互的是集合而不是点**（点估计的自信不再能代表安全）；**安全是对集合取最坏再减去 Lipschitz 保守量**（可计算且只偏保守）；**信息只能安全地买**（消歧接触先对整个集合验安全）；**对称只在无关方向免费，关键方向白名单永在**；四者共同把"位姿误差"从一种会被材质信念洗白的隐变量，变成一条有覆盖契约、可证伪、可主动消减的显式风险。
