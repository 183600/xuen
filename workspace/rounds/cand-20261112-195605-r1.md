# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 7 轮；本轮灵感：「视觉编码器」×「点云配准」）

> 第 60 轮用 SSM 把「场景→阻抗先验」前置化，用 SERC 闭环把「场景→意图→约束→阻抗→执行→EV-exec→场景更新」串起来。但**三个结构性缺口**仍然存在：
> 1. **场景识别仍是触后反应**：SSM 的观测是 force/position telemetry，必须「摸到」才开始辨识；「看见湿滑地面」到「接触打滑」之间的窗口完全未被利用，预接触适应仍是空的。
> 2. **语义与几何没有互相证伪**：SSM 的 z 是语义标签，π_scene(K|z) 却缺少米制几何锚点；视觉编码器给出的是「自信的假设」，透明杯、镜面、湿滑反光会让语义先验高度自信地错。第 60 轮最大风险正是「湿滑误判为粗糙桌面 → K_safe 提前收敛到错误约束」。
> 3. **阻抗与证据都缺几何身份**：K_safe 基本是各向同性/标量，而真实接触刚度是方向性的（法向硬、切向滑）；EPIR 的 seq_id+hash 只保证「顺序与内容」，不保证「这条 EV-exec 对应地图上哪个几何对象、哪个接触帧」——配准失败与执行成功在证据链上不可区分。

## 0. 直觉与动机

**灵感 1（视觉编码器 → 预接触语义阻抗先验 VSP）**
直觉：视觉编码器把「看」变成「预期摸感」。冻结的自监督/多模态编码器输出嵌入 e，再接一个轻量预测头，给出场景标签 z、阻抗均值 μ_vis(z) 与协方差 Σ_vis(z)。关键洞见：**视觉先验必须自带「 epistemic 不确定度」u_vis**——多视角嵌入越不一致、ensemble 分歧越大，u_vis 越高；只有 u_vis 足够小，视觉先验才被允许参与「接触前收窄 K_safe」。视觉是「会自信说谎」的传感器，必须让它先承认自己可能错。

**灵感 2（点云配准 → 几何证伪证书 GRC）**
直觉：配准是「用几何投票」。把当前深度/LiDAR 点云 P_t 对齐到先验地图或物体模型 P_map，输出相对位姿 T、重叠率 ρ、残差 r、位姿协方差 Σ_T。关键洞见：**配准的真正产物不是 T，而是「可证伪性」**——语义说「这是粗糙木桌」，几何就去测平面度、法向离散度、尺度；测不出对应的几何属性，就拒绝预收敛。GRC 把「配准是否可信」变成一个可检验的谓词，而不是一个黑箱分数。

**灵感 3（触觉点云 × 视觉点云 → 各向异性接触阻抗 ACI）**
直觉：接触刚度是方向性的：法向硬、切向易滑。把触觉阵列/力探针得到的接触斑点点云 P_tac 配准到视觉物体表面 P_obj，得到接触帧 R_c、接触点曲率 κ_c 与法向 n_c，则 K_c = R_c · diag(k_n, k_t, k_t) · R_cᵀ。关键洞见：**配准把「几何朝向」翻译成「阻抗朝向」**，让第 60 轮的标量 K_safe 升级为方向相关的 6D 刚度；滑移风险不再由单一 K_p 猜测，而由 k_t 与局部摩擦等级共同给出。

**灵感 4（双证一致性门 SGCG → 语义假设 + 几何证书）**
直觉：只有语义先验与几何配准**各自独立地同意**，才允许 π_scene 收窄 K_safe。语义预测的几何属性 a_vis(z)（尺度、平面度、法向分布、粗糙度/摩擦等级）与配准测得的 a_geo(T·P_t) 做 Mahalanobis 一致性检验；不通过就回退第 60 轮触后 SSM。关键洞见：**双证不是互相背书，而是互相证伪**——这正好把第 60 轮最大风险结构化为一个可计算门控。

**灵感 5（合流 → VGR-SGEC + 配准感知证据链 + 主动配准探测）**
直觉：把四者合成闭环：视觉编码（看）→ 点云配准（对）→ 语义-几何门控（判）→ 双证安全集（收窄）→ 触觉配准（定向）→ 执行（摸）→ EV-exec⁺（带几何身份证）→ 地图与先验更新（重锚定）。配准失败不是异常，而是一等公民：触发降级、冻结地图锚点、放大 Σ_T、回退触后先验。再往前一步：主动选择「下一个视角/下一个接触点」以最大化配准信息增益，即把「看哪里、摸哪里」纳入控制。PCE++++ 随之扩展为 PCE+++++（新增 B_vis、B_reg）。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（视觉语义阻抗先验 VSP）** 视觉先验 V = (f_v, h_vis, u_vis)。其中：
- **多视角编码**：e_t = f_v(I_t)，ē_t = Attn({e_{t-k},...,e_t})，d 为嵌入维度
- **预测头**：h_vis(ē_t) → (p(z|e), μ_vis(z), Σ_vis(z))，z ∈ Z_scene
- **视觉先验**：π_vis(K|z) = N(K; μ_vis(z), Σ_vis(z) + u_vis² I)
- **认知不确定度**：u_vis = σ(α·Disagree_ensemble + β·(1 − cos_sim(ē_t, ē_t^view2)) + γ·OOD_score)，由 deep ensemble、多视角一致性与 OOD 检测共同构成
- **可用性谓词**：Use_vis(z) = 1[p(z|e) ≥ τ_z ∧ u_vis ≤ τ_u]。仅当 Use_vis=1 时，π_vis 才允许进入预收敛流程。

**定义 162（几何配准证书 GRC）** 配准 R: (P_t, P_map) → (T_t, ρ_t, r_t, Σ_T,t, κ_H)。其中：
- **T_t ∈ SE(3)**：当前点云到地图的刚体位姿
- **ρ_t ∈ [0,1]**：内点/重叠率；**r_t**：内点 RMSE
- **Σ_T,t**：位姿协方差，由 ICP Hessian 逆或内点 bootstrap 估计
- **κ_H = cond(H)**：Hessian 条件数，度量几何退化（平面/对称物体）
- **证书谓词**：Cert_reg = 1[ρ_t ≥ τ_ρ ∧ r_t ≤ τ_r ∧ tr(Σ_T,t) ≤ τ_Σ ∧ κ_H ≤ κ_max]
- **证书置信度**：g_reg = σ(a₁ρ_t − a₂r_t − a₃tr(Σ_T,t) − a₄log κ_H + b)

**定义 163（语义-几何一致性 SGC）** 一致性算子 C = (a_vis, a_geo, D_sg, G_sg)。其中：
- **语义属性向量**：a_vis(z) = (尺度 s, 平面度 π_flat, 法向分布 μ_n, 粗糙度等级 ℓ_rough, 摩擦等级 ℓ_fric)
- **几何属性向量**：a_geo(T·P_t) = (s_geo, π_flat^geo, μ_n^geo, ℓ_rough^geo, ℓ_fric^geo)，由配准后的点云局部邻域估计
- **一致性距离**：D_sg = (a_vis − a_geo)ᵀ Σ_a⁻¹ (a_vis − a_geo)，Σ_a 由属性估计误差传播得到
- **一致性分数**：C_sg = exp(−½ D_sg) ∈ (0,1]
- **门控**：G_sg = 1[Cert_reg=1 ∧ C_sg ≥ τ_c ∧ Use_vis=1]；另加方向性检查：预测支撑面法向与配准平面法向夹角 ≤ τ_angle，预测坡度与测量坡度差 ≤ τ_slope。

**定义 164（配准导出的各向异性接触阻抗 ACI）** 触-视配准 T_tv = (R_c, t_c, r_tv, κ_c, n_c)，其中 P_tac 配准到 P_obj：
- **接触帧**：R_c = [n_c, t₁, t₂] ∈ SO(3)，n_c 为配准后局部法向，t₁,t₂ 为切向
- **各向异性刚度**：K_c = R_c diag(k_n, k_t, k_t) R_cᵀ，k_n = μ_n(z) + α_n·κ_c，k_t = μ_t(z) − α_t·κ_c
- **滑移风险**：S_slip = P(|F_t| > μ_fric·F_n | k_t, z)，由切向刚度与摩擦等级共同估计
- **定向证书**：Cert_aci = 1[r_tv ≤ τ_tv ∧ κ_c 有界 ∧ R_cᵀR_c ≈ I]

**定义 165（双证安全阻抗集 DCS 与保形校准）** 给定场景 z、视觉先验 π_vis、配准证书 Cert_reg 与一致性门 G_sg：
- **非一致性分数**：s(K) = sqrt((K − μ_vis)ᵀ Σ_vis⁻¹ (K − μ_vis))
- **保形分位**：在标定集 {(z_i, K_i)} 上取 q_{1−α} = Quantile_{(1−α)(1+1/n)}({s(K_i)})
- **双证安全集**：K_safe^dual(z) = {K : s(K) ≤ q_{1−α}} ∩ {K : K 与 K_c 的接触帧/曲率相容} ∩ K_safe^base
- **门控规则**：若 G_sg=1，则用 K_safe^dual 做预收敛；若 G_sg=0，则 K_safe^dual := K_safe^contact（第 60 轮触后 SSM 结果）
- **覆盖保证**：在可交换性假设下，P(K_true(z) ∈ K_safe^dual(z)) ≥ 1−α−δ_false，δ_false 为语义与配准失败模式相关导致的保守松弛。

**定义 166（配准感知证据链 RAE / EPIR++）** 增强证据 EV-exec⁺ = (timestamp, seq_id, hash, reg, K_c, SIC)。其中：
- **reg** = (T_t, ρ_t, r_t, Σ_T,t, map_id, pointcloud_hash, Cert_reg)
- **证据有效性**：Valid_ev = Valid_epir(seq, hash) ∧ Cert_reg ∧ map_id 与已提交地图版本一致
- **几何溯源**：云端除做「时间戳顺序 + 内容哈希」检验外，还将 EV-exec⁺ 的 T_t 与地图做二次配准；若二次配准残差与上报 r_t 的差超过 τ_replay，标记「几何溯源失配」
- **配准丢失处理**：执行中若 Cert_reg 失效，显式写入 `reg_status=LOST` 并触发本地闭环；获得下一次有效配准后执行 `re-anchor`，绝不让缺失静默通过

**定义 167（主动配准信息探测 ARIP）** 候选动作 a = (视角 v, 接触点 c, 接近方向 d)：
- **信息增益**：IG(a) ≈ ½ log det(Σ_prior) − ½ log det(Σ_post(a))，Σ_post 为在 DCS 投影下的后验协方差
- **配准成本**：cost(a) = λ_vis·Enc_cost(v) + λ_reg·Reg_cost(c) + λ_exec·Probe_cost(c)
- **探测规则**：a* = argmax_a IG(a)/cost(a)，受 B_vis/B_reg/B_exec 三重预算约束；候选集由视觉显著区域与配准高不确定区域共同给出

**定义 168（VGR-SGEC 闭环算子与 PCE+++++）** 算子 VGR_SGEC(M, I_t, P_t, intent, δ_f_req)：
```
① VSP:  e ← f_v(I_t); (z, μ_vis, Σ_vis, u_vis) ← h_vis(ē_t)
```

### IP-161 VSP（视觉语义阻抗先验）

```python
class VisualSemanticPrior:
    def __init__(self, encoder, head, ensembles=5, tau_z=0.6, tau_u=0.25):
        self.f_v = encoder
        self.h = [head.clone() for _ in range(ensembles)]
        self.tau_z, self.tau_u = tau_z, tau_u
        self.mu_table, self.cov_table = {}, {}

    def infer(self, frames):
        embs = [self.f_v(f) for f in frames]
        e_bar = self._multi_view_attention(embs)
        preds = [h(e_bar) for h in self.h]
        p_z = np.mean([p['z_prob'] for p in preds], axis=0)
        mu = np.mean([p['mu'] for p in preds], axis=0)
        sigma = np.mean([p['cov'] for p in preds], axis=0)
        u_ens = np.std([p['mu'] for p in preds], axis=0).mean()
        u_view = 1.0 - np.mean([cos_sim(embs[0], e) for e in embs[1:]]) if len(embs) > 1 else 0.0
        u_vis = float(np.clip(0.5*u_ens + 0.3*u_view + 0.2*preds[0]['ood'], 0, 1))
        z = int(np.argmax(p_z))
        return {'z': z, 'p_z': float(p_z[z]), 'mu': mu,
                'Sigma': sigma + u_vis**2 * np.eye(len(mu)), 'u_vis': u_vis}

    def usable(self, out):
        return out['p_z'] >= self.tau_z and out['u_vis'] <= self.tau_u
```

### IP-162 GRC（几何配准证书）

```python
class RegistrationCertificate:
    def __init__(self, tau_rho=0.55, tau_r=0.02, tau_S=1e-3, kappa_max=1e3):
        self.tau_rho, self.tau_r, self.tau_S, self.kappa_max = tau_rho, tau_r, tau_S, kappa_max

    def register(self, P_t, P_map):
        T0 = self._global_align(P_t, P_map)          # FPFH + RANSAC
        T, inliers, r = self._icp(P_t, P_map, T0)
        rho = len(inliers) / max(1, len(P_t))
        H = self._icp_hessian(P_t, P_map, T, inliers)
        Sigma_T = np.linalg.pinv(H)
        kappa = np.linalg.cond(H)
        cert = (rho >= self.tau_rho and r <= self.tau_r
                and np.trace(Sigma_T) <= self.tau_S and kappa <= self.kappa_max)
        g = sigmoid(2.0*rho - 10.0*r - 1e3*np.trace(Sigma_T) - 0.1*np.log1p(kappa))
        return {'T': T, 'rho': rho, 'r': r, 'Sigma_T': Sigma_T,
                'kappa_H': kappa, 'Cert_reg': bool(cert), 'g_reg': float(g)}
```

### IP-163 SGC（语义-几何一致性门）

```python
def semantic_geometric_gate(a_vis, P_aligned, Sigma_a, tau_c=0.6,
                            tau_angle=np.deg2rad(20), tau_slope=0.1):
    a_geo = estimate_geometric_attributes(P_aligned)   # 尺度/平面度/法向/粗糙/摩擦
    d = a_vis - a_geo
    D_sg = float(d.T @ np.linalg.inv(Sigma_a) @ d)
    C_sg = float(np.exp(-0.5 * D_sg))
    angle_ok = angle_between(a_vis['normal'], a_geo['normal']) <= tau_angle
    slope_ok = abs(a_vis['slope'] - a_geo['slope']) <= tau_slope
    return {'C_sg': C_sg, 'D_sg': D_sg,
            'G_sg': bool(C_sg >= tau_c and angle_ok and slope_ok)}
```

```python
def anisotropic_contact_impedance(P_tac, P_obj, z, mu_table):
    T_tv, r_tv = register_tactile_to_object(P_tac, P_obj)
```

### IP-165 DCS（双证安全集 + 保形校准）

```python
class DualCertificateSafeSet:
    def __init__(self, alpha=0.1):
        self.alpha = alpha
        self.scores = []

    def calibrate(self, calib_pairs):
        self.scores = [self._score(mu, Sigma, K) for mu, Sigma, K in calib_pairs]
        n = len(self.scores)
        self.q = np.quantile(self.scores, min(1.0, (1-self.alpha)*(1+1/n)))

    def _score(self, mu, Sigma, K):
        d = K - mu
        return float(np.sqrt(d.T @ np.linalg.pinv(Sigma) @ d))

    def compile(self, vis_out, reg_cert, sgc, K_base, K_c=None):
        if not (reg_cert['Cert_reg'] and sgc['G_sg']):
            return {'K_safe': K_base, 'mode': 'contact_only_fallback'}
        mu, Sigma = vis_out['mu'], vis_out['Sigma']
        cand = ellipsoid_samples(mu, Sigma, self.q)
        cand = [K for K in cand if self._compatible(K, K_c)]
        K_safe = intersect_with_base(cand, K_base)
        return {'K_safe': K_safe, 'mode': 'dual_certificate',
                'coverage_lb': 1 - self.alpha}
```

### IP-166 RAE（配准感知证据链）

```python
class RegistrationAwareEvidence:
    def __init__(self, epir):
        self.epir = epir

    def append(self, ev_exec, reg, K_c, sic):
        payload = {'exec': ev_exec, 'reg': reg, 'K_c': K_c, 'SIC': sic}
        msg = self.epir.append(payload)
        msg.reg_status = 'OK' if reg['Cert_reg'] else 'LOST'
        return msg

    def verify(self, msg, P_map, tau_replay=0.03):
        if not valid_epir_chain(msg):
            return 'EPIR_INVALID'
        if msg.reg_status == 'LOST':
            return 'GEOMETRIC_PROVENANCE_LOST'
        T2, r2 = re_register(msg.payload['reg']['T'], P_map)
        if abs(r2 - msg.payload['reg']['r']) > tau_replay:
            return 'GEOMETRIC_REPLAY_MISMATCH'
        return 'VALID'
```

### IP-167 ARIP（主动配准信息探测）

```python
def active_registration_probe(candidates, Sigma_prior, budget):
    best, best_score = None, -np.inf
    for a in candidates:
        Sigma_post = predict_posterior(Sigma_prior, a)
        ig = 0.5*np.log(np.linalg.det(Sigma_prior)) - 0.5*np.log(np.linalg.det(Sigma_post))
        cost = (0.2*budget.enc_cost(a.view) + 0.5*budget.reg_cost(a.point)
                + 0.3*budget.probe_cost(a.point))
        if not budget.feasible(a):
            continue
        score = ig / max(cost, 1e-6)
        if score > best_score:
            best, best_score = a, score
    return best
```

则：
1. **预接触可靠性**：若 G_sg=1，则 P(K_true(z) ∈ K_safe^dual(z)) ≥ 1−α−δ_false−δ_vis。
2. **无回退退化**：若 G_sg=0，算子严格退化为第 60 轮触后 SSM，故安全性能不低于基线（no-regression）。
3. **几何定向性**：若 Cert_aci=1，则 K_c 与真实接触帧的偏差 ≤ ε_T，各向异性估计误差随 r_tv 与 κ_c 有界。

### IP-161 VSP（视觉语义阻抗先验）

```python
class VisualSemanticPrior:
    def __init__(self, encoder, head, ensembles=5, tau_z=0.6, tau_u=0.25):
        self.f_v = encoder
        self.h = [head.clone() for _ in range(ensembles)]
        self.tau_z, self.tau_u = tau_z, tau_u

    def infer(self, frames):
        embs = [self.f_v(f) for f in frames]
        e_bar = self._multi_view_attention(embs)
        preds = [h(e_bar) for h in self.h]
        p_z = np.mean([p['z_prob'] for p in preds], axis=0)
        mu = np.mean([p['mu'] for p in preds], axis=0)
        sigma = np.mean([p['cov'] for p in preds], axis=0)
        u_ens = np.std([p['mu'] for p in preds], axis=0).mean()
        u_view = 1.0 - np.mean([cos_sim(embs[0], e) for e in embs[1:]]) if len(embs) > 1 else 0.0
        u_vis = float(np.clip(0.5*u_ens + 0.3*u_view + 0.2*preds[0]['ood'], 0, 1))
        z = int(np.argmax(p_z))
        return {'z': z, 'p_z': float(p_z[z]), 'mu': mu,
                'Sigma': sigma + u_vis**2 * np.eye(len(mu)), 'u_vis': u_vis}

    def usable(self, out):
        return out['p_z'] >= self.tau_z and out['u_vis'] <= self.tau_u
```

### IP-162 GRC（几何配准证书）

```python
class RegistrationCertificate:
    def __init__(self, tau_rho=0.55, tau_r=0.02, tau_S=1e-3, kappa_max=1e3):
        self.tau_rho, self.tau_r, self.tau_S, self.kappa_max = tau_rho, tau_r, tau_S, kappa_max

    def register(self, P_t, P_map):
        T0 = self._global_align(P_t, P_map)          # FPFH + RANSAC
        T, inliers, r = self._icp(P_t, P_map, T0)
        rho = len(inliers) / max(1, len(P_t))
        H = self._icp_hessian(P_t, P_map, T, inliers)
        Sigma_T = np.linalg.pinv(H)
        kappa = np.linalg.cond(H)
        cert = (rho >= self.tau_rho and r <= self.tau_r
                and np.trace(Sigma_T) <= self.tau_S and kappa <= self.kappa_max)
        g = sigmoid(2.0*rho - 10.0*r - 1e3*np.trace(Sigma_T) - 0.1*np.log1p(kappa))
        return {'T': T, 'rho': rho, 'r': r, 'Sigma_T': Sigma_T,
                'kappa_H': kappa, 'Cert_reg': bool(cert), 'g_reg': float(g)}
```

```python
def semantic_geometric_gate(a_vis, P_aligned, Sigma_a, tau_c=0.6,
                            tau_angle=np.deg2rad(20), tau_slope=0.1):
    a_geo = estimate_geometric_attributes(P_aligned)   # 尺度/平面度/法向/粗糙/摩擦

            'G_sg': bool(C_sg >= tau_c and angle_ok and slope_ok)}
```

### IP-165 DCS（双证安全集 + 保形校准）

```python
class DualCertificateSafeSet:
    def __init__(self, alpha=0.1):
        self.alpha = alpha
        self.scores = []

    def calibrate(self, calib_pairs):
        self.scores = [self._score(mu, Sigma, K) for mu, Sigma, K in calib_pairs]
        n = len(self.scores)
        self.q = np.quantile(self.scores, min(1.0, (1-self.alpha)*(1+1/n)))

    def _score(self, mu, Sigma, K):
        d = K - mu
        return float(np.sqrt(d.T @ np.linalg.pinv(Sigma) @ d))

    def compile(self, vis_out, reg_cert, sgc, K_base, K_c=None):
        if not (reg_cert['Cert_reg'] and sgc['G_sg']):
            return {'K_safe': K_base, 'mode': 'contact_only_fallback'}
        mu, Sigma = vis_out['mu'], vis_out['Sigma']
        cand = ellipsoid_samples(mu, Sigma, self.q)
        cand = [K for K in cand if self._compatible(K, K_c)]
        K_safe = intersect_with_base(cand, K_base)
        return {'K_safe': K_safe, 'mode': 'dual_certificate',
                'coverage_lb': 1 - self.alpha}
```

### IP-167 ARIP（主动配准信息探测）

```python
def active_registration_probe(candidates, Sigma_prior, budget):
    best, best_score = None, -np.inf
    for a in candidates:
        Sigma_post = predict_posterior(Sigma_prior, a)
        ig = 0.5*np.log(np.linalg.det(Sigma_prior)) - 0.5*np.log(np.linalg.det(Sigma_post))
        cost = (0.2*budget.enc_cost(a.view) + 0.5*budget.reg_cost(a.point)
                + 0.3*budget.probe_cost(a.point))
        if not budget.feasible(a):
            continue
        score = ig / max(cost, 1e-6)
        if score > best_score:
            best, best_score = a, score
    return best
```

**一句话**：视觉编码器与点云配准的失败模式可能高度相关——透明杯、镜面、湿滑反光与对称/平面退化会让两者同时「自信地错」，SGC 双证退化为「双份偏见」，把第 60 轮的「触后才发现」升级为「接触前就锁死在错误 K_safe」；必须以「多视角/多模态独立性约束、u_vis 与 Σ_T 保守校准、保形覆盖下界、κ_H 条件数地板、门控失败强制回退触后 SSM」五重护栏，确保预收敛只收窄集合、永不绕过力/速度安全硬约束。
