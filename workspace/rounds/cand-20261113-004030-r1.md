# 第 1 轮 · 灵感循环（「UniBot世界挑战赛」×「仿真训练」）—— 从"离线判分"转向"按榜单边际收益做仿真训练"

> 承接跨轮保留的 UIP v2。v2 的主线是"在 API 内做滚动验证 + 在 Gazebo 里造扰动数据"。本轮把镜头从"离线判分"推到"训练目标"与"竞赛策略"：**仿真不只是裁判，而是唯一能按官方步骤分做密集奖励训练的地方；比赛也不是普通 benchmark，而是一个只有 32 题、榜首 29.7%、前二仅差 1.2 分的排名博弈。**

---

## 0. 直觉解释（先讲人话）

1. **榜首只有 29.7% 成功率，但步骤分有 39.0。** 8 个公开模型的"步骤分 − 成功率"缺口全部落在 6.9~10.4 分之间（均值约 8.6）。这说明大多数 episode 会失败，但失败里仍能拿到大量前置步骤分。**边际分数不在"再学会一个完整任务"，而在"别把已经完成的计分步丢掉"。**
2. **没有全能冠军。** MolmoAct2 只在 8/32 个任务上拿第一；把每个任务交给 8 个模型中最好的那个（oracle best-of-8），平均成功率 29.70 → 33.96（+4.26），步骤分 39.00 → 45.54（+6.54）。**"任务级专长"本身值 4 个百分点**——这是"世界挑战赛"给出的最直接策略信号。
3. **头部差距小于评测噪声。** 第 1 名与第 2 名只差 1.2 个成功率点 / 0.1 个步骤分；若每任务只有几十次评测，这个差距在统计上不可分辨。**没有置信区间的"涨分"很可能只是公开榜单过拟合。**
4. **"仿真训练"的正确用法不是再造一个评分器**（v2 已有 GSO），而是：用官方 32 任务计分表做 dense reward；用仿真合成失败、撤回、临界状态；用有限真机时段校准 sim2real；用"排名感知"的离线影子评测决定算力押在哪些任务上。

---

## 1. 严谨定义（把直觉写成可检验对象）

**定义 1（竞赛效用）** 设任务集 \(T=\{1,\dots,32\}\)，策略 \(\pi\) 在任务 \(t\) 上的成功率为 \(s_t(\pi)\in[0,1]\)，步骤分为 \(q_t(\pi)\in[0,100]\)。榜单效用
\[
U(\pi)=\frac{1}{32}\sum_{t\in T} f\big(s_t(\pi),\,q_t(\pi)\big),
\]
其中 \(f\) 对两个自变量单调递增（具体权重未公开；因此不假设其解析形式，只做**排名/序数**分析）。排名 \(\operatorname{rank}(\pi)\) 由 \(U\) 降序决定。

**定义 2（任务级 headroom）** 给定参照策略 \(\pi_0\)（本轮取榜首 MolmoAct2），
\[
h_t(\pi_0)=\max_{m\in B}s_{m,t}-s_{\pi_0,t},
\]
其中 \(B\) 是 8 个公开 generalist 模型集合。\(h_t\) 是"若把该任务换成当前最好模型"的可回收上界；它把"该练哪个任务"变成一个可排序的量。

**定义 3（计分塑形奖励）** 在仿真中，令 \(\Phi_t(o)\) 为任务 \(t\) 的官方计分谓词集合（由 `scoring_points` 逐条翻译成几何/接触谓词），则
\[
r_t(o_{k-1},o_k)=\sum_i \Delta_i\,score_i-\lambda\,\mathbf 1[\text{regressed}]-\mu\,\Delta time-\nu\,\|\Delta a\|^2,
\]
其中 \(\Delta_i\in\{0,1\}\) 表示第 \(i\) 个计分谓词从假变真。该奖励与榜单第二口径**同构**，而不是二值成功；这是"仿真训练"相对"仿真评测"的真正增量。

**定义 4（sim2real 校准）** 设仿真参数 \(\theta\)（摩擦、质量、相机外参、执行延迟等）。用有限真机 episode \(D_{real}\) 估计
\[
\hat\theta=\arg\min_\theta \operatorname{MMD}\big(P_{sim}(\cdot;\theta),P_{real}\big)+\gamma\,\mathcal R(\theta),
\]
其中 \(\mathcal R\) 是参数先验/正则。校准只服务于"结构/顺序/恢复"决策，不承诺像素级保真（沿用 v2 的 H4）。

**定义 5（排名感知评测）** 对候选 \(\pi\) 与基线集合 \(B\)，用 bootstrap 在任务与 episode 两个层级重采样，报告
\[
\Pr\big(\operatorname{rank}(\pi)=1\big),\quad \Delta U \text{ 的 }95\%\text{ CI},\quad \text{以及每任务所需 episode 数的功效曲线}.
\]
只有当 \(\Pr(\text{rank}=1)\) 超过预设阈值且 CI 下界为正时，才把离线改进送去真机。

## 4. 三个候选方向与合并

- **A（训练目标）PCS-RL**：用官方步骤分做 dense reward。直接对准最大缺口——失败 episode 的部分分。
- **B（竞赛策略）CASP**：按 headroom / 排名敏感度分配仿真算力，并决定 generalist vs specialist。
- **C（可信度）DTC + LSE**：有限真机校准 + 排名感知影子评测，防止"仿真里涨分、隐藏评测不涨"。

合并为旗舰 **RAST（Rank-Aware Simulation Training）**：
**LSE 量化 headroom 与噪声 → CASP 选任务/分配算力 → PCS-RL + FSR 在仿真里训练 → DTC 用真机锚点校准 → LSE 复核排名 → 提交**。一句话：把"训练什么、练多少、算不算数"三件事都交给榜单边际收益。

> **战略分叉（本轮最高优先级待核实）**：若规则允许"专才/单任务"赛道，空白的 `specialist` 队列可能是期望收益最高的蓝海——因为 best-of-8 oracle 已证明任务级专长值 +4.26 分。若规则要求单模型多任务，则用 CASP + 技能路由在单模型内逼近该 oracle。**在拿到规则手册前，不把任何一边写死。**

| 1 | MolmoAct2 | 29.70 | 39.00 | 9.30 | 44.02 |
| 2 | WALL-OSS-0.5 | 28.50 | 38.90 | 10.40 | 43.74 |
| 3 | DreamZero | 27.90 | 37.90 | 10.00 | 44.59 |

- **每个任务占 1/32**：+10 分放在一个任务上 = 总平均 +0.3125；想追平第 2 名的 +1.2，需要在一个任务上 +38.4 分，或在 10 个任务上各 +3.84 分。
- **统计功效**：若每任务评测 \(n\) 次、成功率约 0.3，则总平均成功率的标准误约 \(0.081/\sqrt{n}\)（即 \(8.1/\sqrt{n}\) 个百分点）。\(n=50/100/200/500\) 时约 1.15/0.81/0.57/0.36 个百分点；**当前第 1–2 名 1.2 分的差距在 \(n<100\) 时不可分辨**。

- **结论**：若能把 top-8 任务的 headroom 各回收一半，理论上足以从榜首附近再挤出约 1.2 分；但这需要至少 ~200 次/任务的评测才统计可分。**因此"选对任务"和"证明有效"与"模型更强"同等重要。**

## 6. 本轮最大风险（一句话）

**一句话**：把公开榜单快照当 ground truth、按 headroom 过拟合，会用"仿真里涨分、隐藏评测不涨"的假进步换掉真正的泛化；必须让 LSE 的置信区间和 DTC 的真机锚点成为提交前的硬门槛。

### 1.4 统计功效：1.2 分到底能不能分辨？

设每任务 \(n\) 次评测、成功率约 0.3，则 32 任务平均成功率的标准误约 \(8.1/\sqrt{n}\) 个百分点：

| n（每任务） | 50 | 100 | 200 | 500 | 1000 |
|---|---|---|---|---|---|
| SE（百分点） | 1.15 | 0.81 | 0.57 | 0.36 | 0.26 |
| 1.2 分相当于几个 SE | 1.0 | 1.5 | 2.1 | 3.3 | 4.6 |

**结论**：若官方每任务评测次数 <100，当前第 1–2 名差距统计上不可分辨；任何"提升"必须用配对/bootstrap 来证明。若把 top-8 headroom 各回收一半（理论 +1.16 分），在"候选与基线都加噪"的保守模拟下，\(n=50/100/200/500\) 时超过现榜首的概率约 **0.76/0.84/0.93/0.99**。这给出了一条可执行的"要多少次真机评测才敢说赢了"的曲线。

### 1.5 战略分叉：`specialist` 空队列

`leaderboard_data.json` 同时返回：

```json
{"generalist": [ ...8 个模型... ], "specialist": []}
```

两种解释必须分开处理：

- **解释 A（赛道）**：存在专才/单任务榜单，当前为空 → 提交 per-task / per-cluster 专家是最高期望收益选项，因为 oracle 已证明任务级专长值 +4.26 分。
- **解释 B（字段）**：只是数据 schema 里的分类字段，规则仍要求单模型多任务 → 用单骨干 + 技能头/软路由在单模型内逼近 oracle。

**行动**：先拿到飞书规则手册或向主办方确认；在确认前，代码层把"策略组合"做成可配置（单模型路由 / 多专家），不写死。

## 2. 旗舰 RAST：闭环与伪代码

### 2.1 五步闭环

1. **Measure（LSE）**：用公开快照 + bootstrap 计算每任务 headroom \(h_t\)、排名敏感度、评测噪声。
2. **Allocate（CASP）**：在总算力 \(B\) 下解一个带覆盖约束的背包：\(a_t \propto h_t/c_t\)，并保留 15%~30% 算力给"鲁棒性/多样性"任务。
3. **Train（PCS-RL + FSR）**：仿真中用官方步骤分做 dense reward；用失败合成补齐负样本；特权教师（全状态/几何）蒸馏到仅用 API 观测的学生。
4. **Calibrate（DTC）**：用预约到的真机时段做系统辨识与残差校准；主动选择"对排名影响最大"的校准任务。
5. **Validate（LSE）**：bootstrap 排名分布；只有 \(\Pr(\text{rank}=1)\) 超过阈值且 CI 下界为正才提交。

### 2.2 CASP 预算分配伪代码

```python
def allocate_budget(headroom, cost, rank_sens, B,
                    floor_frac=0.15, top_k=8):
    # rank_sens[t] = 该任务成功率变化对总排名的边际影响（有限差分/局部线性化）
    score = {t: rank_sens[t] * headroom[t] / max(cost[t], 1e-6)
             for t in headroom}
    alloc = {t: floor_frac * B / len(headroom) for t in headroom}
    remaining = B - sum(alloc.values())
    order = sorted(score, key=score.get, reverse=True)
    # 前 top_k 拿主要增量，其余保持 floor，保证鲁棒性
    z = sum(max(score[t], 0) for t in order[:top_k]) or 1.0
    for t in order[:top_k]:
        w = remaining * max(score[t], 0) / z
        alloc[t] += w
    return alloc

# 战略分叉：若 specialist 赛道可用，则对每个 t 单独训练；
# 否则用共享骨干 + 技能头，按 alloc 采样任务训练单模型。
```

### 2.3 计分塑形奖励伪代码（UIP-16）

```python
def step_shaped_reward(preds, scores, prev, cur,
                       lam=1.0, mu=0.1, nu=0.01, a_prev=None, a=None):
    r = 0.0
    for i, p in enumerate(preds):
        was, now = p(prev), p(cur)
        if (not was) and now:
            r += scores[i]              # 新完成一个计分步
        elif was and (not now):
            r -= lam * scores[i]        # 进度被撤回/破坏：对称扣分
    r -= mu * (cur.t - prev.t)          # 时间成本
    if a is not None and a_prev is not None:
        r -= nu * ((a - a_prev) ** 2).sum()   # 动作抖动/可信度
    return r
```

> 关键：扣分项与加分项使用**同一套官方分值**，因此"保前置、搏末步"不是启发式，而是奖励函数的直接推论。

### 2.4 榜单影子评测伪代码（UIP-20）

```python
def lse(candidate, baselines, tasks, n_ep, n_boot=10000):
    # candidate/baselines: task -> (success, step)
    ranks, deltas = [], []
    for _ in range(n_boot):
        bs = bootstrap_tasks(tasks)                 # 任务层重采样
        c = sample_utility(candidate, bs, n_ep)     # episode 层二项噪声
        b = [sample_utility(m, bs, n_ep) for m in baselines]
        ranks.append(1 + sum(x > c for x in b))
        deltas.append(c - max(b))
    return {
        "P_rank1": mean(r == 1 for r in ranks),
        "delta_CI": percentile(deltas, [2.5, 97.5]),
        "rank_hist": histogram(ranks),
    }
```

### 2.5 RAST 主循环

```python
policy = bc_warm_start(public_demos)          # 公开 32 数据集
for r in range(R):
```

## 3. UIP-16~20 细节

### UIP-16 · PCS-RL（Partial-Credit-Shaped RL）
- **机制**：把 32 个任务的 `scoring_points` 逐条翻译成仿真几何/接触谓词；用 §2.3 的奖励做仿真 RL（BC 热启动 + PPO/离线 RL）；特权教师看全状态，学生只看 API 观测。
- **与 v2 差异**：v2 的 GSO 只对 rollout 打分；PCS-RL 把同一套谓词变成**训练信号**。这是"仿真训练"相对"仿真评测"的核心增量。
- **可行性**：中高。谓词可写；仿真有真值状态；单卡可训小模型。
- **风险**：谓词与官方判定不一致、奖励被 hack（例如反复触碰谓词）→ 用 DTC 真机校准 + LSE 守门。

### UIP-17 · FSR（Failure Synthesis & Replay）
- **机制**：失败分类学——滑脱、夹空、碰撞、掉落、超时、人类撤回、物体被移动。用初始状态扰动、对抗力、脚本化"破坏者"、真机失败日志生成 `(失败前 → 失败/撤回 → 恢复)` 三元组，并标注步骤分变化。
- **与 v2 差异**：v2 的 DRF 只复现 `human_*` 撤回；FSR 覆盖全部失败模式，训练"进度批评家 + 恢复策略"。
- **可行性**：中高（纯仿真 + 现有资产）；数据量可按 CASP 定向生成。
- **风险**：仿真失败分布 ≠ 真机；用真机失败日志与域随机化兜底。

### UIP-18 · CASP（Competition-Aware Sim Portfolio）
- **机制**：输入 \(h_t\)、成本 \(c_t\)、排名敏感度；解带覆盖约束的背包；输出"任务子集 + 算力分配 + generalist/specialist 选择"。
- **关键数字**：top-8 任务覆盖 55% headroom；建议 60%~70% 算力给 top 8~12，30%~40% 留给鲁棒性/隐藏扰动。
- **与 v2 差异**：v2 的 MSGR 只做推理期路由；CASP 把"练什么"也纳入竞赛策略。
- **风险**：过拟合公开榜单；用 LSE 的 CI 与留出任务/扰动做门禁。

### UIP-19 · DTC（Digital Twin Calibration）
- **机制**：真机时段只用于**校准 + 验证**，不用于大规模训练；系统辨识摩擦/质量/延迟/相机外参；拟合残差模型；主动选择"对排名预测误差下降最多"的校准任务。
- **与 v2 差异**：v2 只把真机当"锚点"；DTC 把锚点变成可优化的主动学习问题。
- **风险**：真机时段昂贵、分布非平稳；按任务簇分别校准，保留校准集。

### UIP-20 · LSE（Leaderboard Shadow Evaluation）
- **机制**：任务层 + episode 层双重 bootstrap；输出 \(P(\text{rank}=1)\)、\(\Delta U\) 的 CI、功效曲线；用配对比较减少方差。
- **关键发现**：第 1–2 名 1.2 分差距在 \(n<100\) 时不可分辨；需要 ~200–500 次/任务才能有把握。
- **与 v2 差异**：v2 只看离线分数；LSE 把"排名"作为统计对象，直接服务于竞赛决策。
- **风险**：公开榜单被污染/隐藏评测不同；只用于相对决策，不用于绝对承诺。

## 6. 失败模式、合规与红线

- **公开榜单过拟合**：`leaderboard_data.json` 是公开快照，不能当隐藏测试；训练/调参禁用其逐任务分数做直接监督，只用于**分配与评估**。
- **步骤谓词错配**：几何谓词与官方裁判不一致会"仿真涨分、真机不涨"；用 DTC 真机片段做谓词一致性抽检。
- **sim2real gap**：仿真只做"结构/顺序/恢复"裁判（沿用 v2 H4），不承诺像素级成败。
- **单模型合规 / specialist 资格**：规则手册未取到前，不默认多模型可提交；代码保留单骨干 + 技能头的回退路径。
- **接口红线**：N 台真机 → 8765 起 N 个连续端口；每端口状态隔离；`meta.token` 每步携带；动作形状/块长严格匹配；避免异常动作统计。
- **可信度**：逐步延迟与波动、动作规律性会被展示；重试/重做必须受 UIP-15 的延迟/抖动预算约束。

## 8. 本轮最大风险 & 押注

**一句话风险**：若没有 LSE 的置信区间与 DTC 的真机锚点，RAST 会把"公开榜单的随机波动"误判为"仿真训练的胜利"，并在隐藏评测上归零。

**→ 押注**：**CASP × PCS-RL 在 top-8 headroom 任务上的组合**——它用最少的仿真算力对准最确定的分数缺口（top-8 覆盖 55% 的可回收 headroom），且不需要先解决全部 32 个任务；由 LSE 判断"是否真的赢"，由 DTC 保证"真机上也赢"。
