# 第 44 轮（新循环第 4 轮） · Context-Cert × Safety-Floor：把「上下文理解」从标签升级为证书的条件变量与攻击面，把「安全性」从轨迹布尔升级为分层安全案例（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形边际覆盖被欺骗 + 多用户契约求交为空」，但它仍压着两个更底的单点假设：**(H1) 上下文是一个被正确识别的离散标签**——证书按上下文在边界处切换，仿佛上下文来自可靠分类器；而真实上下文由 VLM/LLM 语义理解给出，**多峰、时变、可被语言注入，且其正确性无法由数值裕度保证**。**(H2) 安全性是轨迹上的一个物理布尔**——但安全是**相对上下文与危害集合**的分层声明（物理 / 功能 / 语义 / 安保），证书只覆盖被枚举的已知危害，而「哪些危害相关」恰好由上下文理解定义。本轮灵感词「上下文理解」「安全性」精确命中这两个假设：**上下文理解**迫使我们把上下文从标签升级为**偏序格上的定位 + 带见证的信念集**；**安全性**迫使我们把证书从「一条裕度不等式」升级为**带危害账本、见证、来源证明与未知危害预算的安全案例**。二者耦合处是本轮真正的新问题：**上下文选错不是让裕度变小，而是让「所声称的危害集合」整体错位**——一张为错误上下文编译、逐字 sound 的证书，在危害层面可以静默地不 sound；而上下文管线本身是攻击面，攻击者可通过语义注入选择一张更宽松的证书。

## 0. 直觉与动机

**灵感 1（上下文理解 → 不是分类，而是在偏序格上「定位」，细化免费、泛化持证）**：直觉上，「厨房 / 有儿童 / 正在烧水 / 用户递来刀具」不是互斥标签，而是**层层加约束的具体化**。因此把上下文建成偏序格：c′ ⪯ c 表示 c′ 是 c 的细化（条件更强、危害更少、不确定性更小）。对在 c 上验证过的证书，落到任一 c′ ⪯ c 应当**无需重复验证**即可复用——这与 v20「人格契约收缩免费」同构，但收缩的是**证书的有效域**而非动作集。反向则绝不免费：从窄上下文走向更宽或不可比上下文，必须交付**迁移证书**（新增危害已覆盖、动力学差有界、阈值已重导）。一句话：**细化永远可用，泛化必须持证**。

**灵感 2（安全性 → 从「一条物理裕度」到「分层安全案例 + 未知危害预算」）**：直觉上，「不撞」只是安全的一层。真正的安全声明至少有三层：**物理层**（不与硬障碍/人发生超阈接触、关节与力矩在界内）、**功能层**（监控器活着、失效可导向安全态）、**语义层**（不违反任务与社会规范，如不在儿童旁高速挥臂、不把刀具递给不该递的人）。再加一层**安保层**（上下文与证书不被篡改/注入）。于是证书不再等价于安全，而是安全案例中的一条证据：(声明, 危害集合 H_c, 假设集, 见证, 残余风险)。**证书只对枚举出的 H_c 负责**；对 OOD 与未知危害，必须显式维护一个「未知危害预算」并触发降级/求助，而不是让「未枚举」被误读为「不存在」。

**灵感 3（耦合 → 语境歧义下只能「安全消歧」，语义是主张、见证才是证据）**：上下文不确定时，最危险的动作是「先按最可能的上下文执行」。正确做法是：先取所有候选上下文的**安全动作交集**；若任务动作不在交集内，则在交集内选择**信息增益最大**的动作去消歧（安全探询 / 主动感知），而不是猜；若交集为空，退回只依赖**安全底 F** 的保底动作并请求澄清。同时，语义模型输出必须被视为**不可信主张**：只有当物理可验证的**见证**（深度一致性、力/触觉、因果反事实、跨模态互证）支持时，才允许把上下文「提升」为可用于放宽证书的状态。安全保障因此收敛为：**无见证不升级，无迁移不放宽，只自动收缩**。

**耦合升级**：CXC（上下文证书编译器）把 ODD/任务/规范编译成上下文格、危害账本、上下文条件证书与迁移证书；CSR（上下文安全运行时）维护带见证的上下文信念、信念鲁棒安全集、安全消歧与安全棘轮，并以来源证明抵御语义注入；CAV（上下文安全验证器）在仿真中枚举歧义、漂移、OOD 与对抗性语义，把反例回灌 CKB 与 SCV。四层架构由 v8 的「人格契约层 + 并发证书层」升级为 v9 的「… + 上下文证书层 + 分层安全案例层」。

## 1. 形式化定义（增量：定义 44–50）

**定义 44（上下文格、细化序与三条单调性义务）**：上下文空间 C 配偏序 ⪯，c′ ⪯ c 读作「c′ 是 c 的细化（更具体）」。每个上下文带危害集 H(c)、动力学不确定集 U(c)、允许动作集 A(c)。称一条细化边合法「免费」当且仅当同时满足：
(M1) **危害单调**：c′ ⪯ c ⟹ H(c′) ⊆ H(c)；
(M2) **不确定单调**：U(c′) ⊆ U(c)；
(M3) **动作单调**：A(c′) ⊆ A(c)。
全部边满足时称该格**危害单调**。**注**：M1 不是自然定律而是**建模义务**——「厨房」细化到「厨房 + 儿童」会**新增**儿童相关危害；若不在粗上下文把该危害上提（hazard closure），这条边就不得享受免费细化，必须显式重验。这一点是 v9 的承重假设，也是本轮最大风险。

**定义 45（安全底与上下文条件证书）**：定义**安全底** F 为与上下文无关的硬不变式（不超阈接触、关节/力矩/速度界、禁入体、失联即停）。上下文条件证书 κ_c = (D_κ, C_c, H_c, A_c, p) 中：D_κ ⊆ C 是一个**下闭集**（down-set，对 ⪯ 封闭），表示该证书可复用的上下文区域；C_c ⊆ F 是安全包络；H_c 为所覆盖危害；p 为来源证明（验证语料哈希、阈值表版本、代码哈希、签名）。**命题（安全底不可越）**：对任意上下文与任意误判，可执行包络始终 ⊆ F；故上下文错误至多降低可用性，不能凭「选错证书」突破硬安全底。**注**：该命题只保住物理/法律硬约束，语义危害仍需 H_c 覆盖来保证。

**定义 46（上下文信念、见证与接地）**：语义估计给后验 b_t ∈ Δ(C)；物理可验证证据给见证集 W_t（深度/触觉/力/跨模态一致性/因果检验）。接地关系 G(W_t, c) 表示 W_t 与 c 相容。**可采信信念** B_t = { c : b_t(c) ≥ ε_b ∧ G(W_t, c) }。**接地覆盖率** γ_t = P(c_t^true ∈ B_t)。若 γ_t < 1−α，判为 **OOD / 未接地**，安全声明失效，只能走 F 保底或请求人类澄清。**原则**：语义是主张，见证才是证据；无见证的上下文不得用于放宽任何证书。

**定义 47（信念鲁棒安全集与歧义代价）**：给定状态 x 与信念 B_t，**信念鲁棒安全动作集**
A_safe(B_t, x) = ⋂_{c∈B_t} A_c(x)，
对应安全包络 C_safe(B_t) = ⋂_{c∈B_t} C_c。**歧义代价**定义为相对任务动作集的收缩率 1 − |A_safe|/|A_task|。**命题**：若 a ∈ A_safe(B_t,x)，则 a 对 B_t 内每个候选上下文均安全；因此「按交集执行」把上下文不确定性转化为可用性损失，而非安全损失。空集时禁止猜测，必须进入定义 48 或 F 保底。

**定义 48（安全消歧动作与信息-安全分离定理）**：动作 a 是**安全消歧动作**，当且仅当
a ∈ A_safe(B_t,x)，且 IG(a) = H(B_t) − E_o[H(B_{t+1})] ≥ δ，且风险暴露 risk(a) ≤ ρ。
消歧控制器取 a* = argmax_{可行} IG(a)。**定理（信息不以安全为代价）**：消歧只在 A_safe 内选动作，故对 B_t 中任何真实上下文都不产生新的越界；它消耗的是时间与任务进度，不是安全性。若不存在 IG ≥ δ 的安全动作，则不探询，改走澄清/保底。**推论**：主动感知在此被安全约束「包住」，不会为了看得更清楚而冒险靠近。

**定义 49（证书域、不可迁移性与安全棘轮）**：证书可用于运行时上下文 c_t，当且仅当
c_t ∈ D_κ ∧ W_t 支持 c_t ∧ Attest(p) = 1。
扩大有效域 D_κ → D′ ⊇ D_κ（含走向更宽或不可比上下文）必须携带**迁移证书** T：对 D′\D_κ 逐项证明危害已覆盖、动力学差 ≤ Δ_max、监控阈值已重导。**安全棘轮**：可执行集满足
E_{t+1} ⊆ E_t ∩ ⋂_{c∈B_t} C_c（自动收缩），
仅当 T 验证通过且（对高影响放宽）获得授权时才允许 E_{t+1} ⊋ E_t。**定理（不可迁移性抗注入）**：若来源证明不可伪造、复用仅限 c_t ∈ D_κ、扩张仅经有效 T，则语义注入改变信念最多使 E 收缩（可用性下降），不能使可执行集越过 F 或越过已验证证书域扩张。**注**：该定理的边界正是「D_κ 的下闭性 + 定义 44 的 M1」，一旦 M1 被违反，注入可借「看似细化」的上下文落入未覆盖危害。

**定义 50（分层安全案例与上下文条件安全定理）**：上下文 c 的安全案例 SC_c = (Claim_c, H_c, A_c, W_c, Residual_c)，三层证据为物理层（F 不变）、功能层（监控/失效导向安全态）、语义层（H_c 内规范），另设**未知危害预算** β_unk：当 OOD 或新危害证据出现即扣减，耗尽即声明失效。**定理（上下文条件安全）**：若 (i) F 在所有执行下前向不变；(ii) ∀c ∈ B_t，所执行 a ∈ A_safe(B_t,x) ⊆ A_c 且 C_c 在该上下文动力学下不变；(iii) 信念更新见证一致（真实上下文 c* ∈ B_t，或已触发 OOD 回退）；(iv) E 仅经有效迁移与授权扩张；则任意轨迹不进入 ⋃_{c∈B_t} H_c。**推论（承重假设显形）**：上下文错误若仍保持 c* ∈ B_t，只损失可用性；若把 c* 挤出 B_t 而未被接地/OOD 捕获，定理前提失效——因此**见证覆盖率 γ_t 与危害单调 M1 是两条真正的承重梁**，必须作为红线实验与运行时断言，而非默认成立。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 CONTEXT-CERT-COMPILER（上下文证书编译器 CXC）
1. **上下文格构建**：从 ODD、任务、社会/法规规范枚举上下文，建立细化序；对每条边做 M1–M3 检查，违反者标记「非免费边」并强制重验。
2. **危害账本与向上闭包**：为每个上下文枚举物理/功能/语义/安保危害；把「细化才出现」的危害**上提**到粗上下文，保证 H 单调；无法上提的危害在账本中显式标为「域外」。
3. **上下文条件证书编译**：C_c = F ∩ K_c，离线证明前向不变与安全；绑定来源证明 p（语料/阈值/代码/版本签名）。
4. **迁移证书生成**：对扩域逐项证明危害覆盖、动力学差上界与阈值重导，产出可验证 T 并登记审计日志。

### 2.2 IP-61 CONTEXT-SAFETY-RUNTIME（上下文安全运行时 CSR）
1. **带见证的上下文信念**：融合 VLM/LLM 后验与物理见证，输出 B_t 与接地覆盖率 γ_t；无见证不提升上下文。
2. **格上定位与 OOD 门控**：把 B_t 定位到已部署下闭集；无覆盖即判 OOD，冻结放宽、只保留 F。
3. **信念鲁棒守卫**：执行 ⋂_{c∈B_t} A_c；空集触发安全消歧或 F 保底。
4. **安全消歧规划器**：在安全集内最大化信息增益，主动消除歧义；无安全探询则澄清。
5. **安全棘轮 + 来源证明**：自动收缩、持证扩张、限速放宽；对语义注入做接地校验、跳变检测与审计。

### 2.3 IP-62 CONTEXT-SAFETY-VALIDATOR（上下文安全验证器 CAV）
1. **上下文歧义 fuzz**：构造多峰后验、快速切换、互相矛盾的语义/见证。
2. **语义注入与欺骗**：提示注入、场景文本投毒、伪造证人、跨模态不一致，验证「注入只降可用性、不越 F」。
3. **迁移与棘轮审计**：在不可比上下文尝试复用证书；检查未持证扩张、审计日志缺环、来源证明伪造。
4. **安全案例压力测试**：在 Isaac Sim 注入 OOD、儿童/宠物/湿滑/多人等新增危害，测未知危害预算与残余风险。
5. **长时程上下文漂移**：100h 场景内上下文漂移/回切，测证书域是否被悄悄扩张。

    → IP-47 组合(危害并集契约) → IP-39 规划(CBF margin=min(查表, 租约, 上下文))

def build_context_lattice(ODD, tasks, norms):
    C = enumerate_contexts(ODD, tasks, norms)
    leq = refinement_order(C)
    H = close_hazards_upward(C, leq)        # 细化才出现的危害上提到粗上下文

### IP-61 CSR：见证接地、信念鲁棒守卫、安全消歧与棘轮
```
def update_context(obs, semantic_model, verifier, alpha):
    b = semantic_model.posterior(obs)          # 不可信主张
    W = verifier.witnesses(obs)                # 深度/触觉/力/跨模态/因果
    B = {c for c in support(b) if b[c] >= eps_b and compatible(W, c)}
    gamma = grounding_coverage(B)
    ood = gamma < 1 - alpha
    return Belief(B, W, gamma, ood)

def safe_action_set(x, B, lattice):
    return intersect_all([lattice[c].admissible(x) for c in B])   # 空集 => 不猜

def select_action(x, B, task_action, ood, lattice):
    if ood: return floor_action(x)             # 只保 F，求助/澄清
    A_safe = safe_action_set(x, B, lattice)
    if task_action in A_safe and deployed(B, lattice):
        return task_action
    probes = [a for a in A_safe if info_gain(a, B) >= delta and risk(a) <= rho]
    if probes: return argmax(probes, key=lambda a: info_gain(a, B))
    return floor_action(x)                     # 无安全探询 => 澄清/保底

def ratchet(E_prev, B, transfer=None, auth=None):
    E = intersect(E_prev, union_cert_sets(B))  # 自动收缩，永不隐含放宽
    if transfer and transfer.valid() and auth_ok(transfer, auth):
        E = union(E, transfer.expanded())      # 持证 + 授权才扩张
    else:
        audit("ratchet_shrink_only")
    return E

def admit_semantic_claim(claim, W, p):
    if not grounded(claim, W):            return REJECT   # 无见证不升级
    if claim.widens and not Attest(p):    return REJECT   # 无来源证明不放宽
    if rate_limited(claim.widening):      return THROTTLE # 防注入突发
    return ACCEPT
```

def fuzz_context(seed, lattice, budget):
    for _ in range(budget):
        b      = sample_multimodal_posterior(seed)     # 多峰/快速切换
        W      = sample_witnesses(seed, conflict=True) # 伪造/矛盾见证

def audit_transfer(cert, ctx, verifier):
    if ctx in cert.domain:
        return verifier.attest(cert) and verifier.witness_supports(ctx)
    T = verifier.transfer_for(cert, ctx)
    return T is not None and T.valid() and T.covers(ctx)   # 否则必须拒绝

def safety_case_audit(SC, traces):

            and budget_ok(SC.beta_unk)
            and no_unknown_hazard_escalation_gap(SC, traces))
