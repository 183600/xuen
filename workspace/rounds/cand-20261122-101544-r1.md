# 第 1 轮（UniBot 线 · 本轮灵感：「可重构机构」×「抓取规划」）

> **延续而非重基线**：继承上一份 UniBot-SAGE 状态（U1–U12 / L1–L7 / E601–E618 / IP-01–IP-08）为 **v1 背景**；本轮不推翻 v1，而是解冻 v1 里被写死的一个假设——**「抓取 = 用同一个二指对捏机构完成一次闭合」**。新增 U13–U24 / L8–L14 / E619–E634 / IP-09–IP-13，构成 v2。v1 的剪枝预案继续有效（IP-06/02/03 必保）。
> **数据纪律**：本轮**不新增赛事事实断言**。所有榜单数字沿用 v1 的 teaser 缓存（8 模型 × 32 任务，检索日期 2026-11-17）；凡涉及「官方数据里是否真有环境接触 / 基座与 pivot 是否被跟踪 / 夹具是否可用」一律标为**待 E619/E621 核验**，不当作已知。

## 0. v1 被冻住的那个假设

v1 的 IP-02 已经把「抓住了吗」变成隐变量，但它的**动作集合**仍然只有三种：继续、重抓、改用非抓取原语。也就是说，v1 默认了：

> **机构是固定的**：G1 + Dex1 二指夹爪只能做「对捏 / 夹持」；环境（桌面、桌沿、墙、其他物体）只是障碍物或背景，不是机构的一部分。

这个假设在简单抓放任务上够用，但在 v1 自己统计出的**最难 6 任务**（Plug In Ethernet 17.7、Unlock 20.1、Spell robot 21.8、Organize Stationery 22.5、Open Pill Bottle 22.7、Pick Out Battery 23.3）上恰好失效——这些任务要求**插入、旋转、细粒度对准、把物体从容器里弄出来**。在单自由度二指夹爪上，它们不是「抓得不够稳」，而是**机构本身不够用**。

本轮两个灵感词各补一刀：

- **「可重构机构」**：机构的自由度 / 拓扑不是硬件的固定属性，而是**由接触约束组装出来的**。换一组接触（手指、手掌、桌面、桌沿、墙、另一只手、其他物体），就换了一个机构。
- **「抓取规划」**：抓取不该是策略末端的一次闭合，而应是**在候选机构与候选抓取位姿上的一次带物理判据的规划**；规划目标不是「抓稳」，而是「让任务所需的那部分运动被约束住」。

## 1. 直觉解释（先直觉，后定义）

### 1.1 「可重构机构」：1 自由度不是缺陷，只用一个机构才是缺陷

**直觉**：把机器人、物体、环境看成一堆刚体，接触就是铰链 / 约束。二指夹爪只提供 2 个接触点；空间力封闭一般需要 ≥7 个接触（含摩擦）。所以单靠夹爪，很多任务在**力封闭意义上根本不可行**。但人做这些任务时并不需要 7 根手指——人会**把物体按在桌上、抵住桌沿、靠住墙、用另一只手扶住**。人是在**临时组装一个可重构机构**：桌子是机架，桌沿是止推轴承，墙是定位块，手指是驱动器。

**本轮最关键的转换**：把「环境」从**障碍物**重新归类为**可被征用的被动机构元件**。可重构性 = 在任务过程中**主动改变接触拓扑**，从而改变有效自由度、力封闭性与可操作方向。这把 v1 的「不可抓 → 换个抓法」升级为「**不可抓 → 换一个机构**」。

**多尺度重配置**（同一思想在三个时间尺度上的投影）：

- 快（ms）：夹爪开合 / 接触力；
- 中（0.1–1 s）：手臂姿态、接近方向、双手角色（一只手当夹具）；
- 慢（1–10 s）：基座 / 站位、把物体按到桌面 / 桌沿、释放后从另一方向重抓、双手交接。

### 1.2 「抓取规划」：把抓取从「末端闭合」变成「带物理判据的机构选择」

**直觉**：端到端 VLA 把「抓哪里、怎么接近、何时闭合」全塞进一个网络，数据里没出现过的机构它就不会。经典抓取规划恰好相反：它显式枚举候选抓取，用力封闭 / 稳定性 / 可达性 / 碰撞打分。两者互补——VLA 擅长语义与视觉泛化，抓取规划擅长**几何与物理可行性**。

**本轮的用法不是用经典规划替换 VLA**，而是让它当**低频的「机构 / 抓取顾问」**：只在相位边界（接近前、插入前、卡住时）运行，输出候选机构与候选抓取，蒸馏进一个快速策略；闭环仍由 VLA 以高频执行。这样既拿到物理判据，又不违反评测的延迟约束。

### 1.3 合成：MORPH = 在「可重构机构图」上做抓取规划

**一句话**：v1 规划的是「一条动作块」；本轮规划的是「**一个机构 + 该机构内的一条动作 + 必要时切换到下一个机构**」。

形式直觉：把抓取状态空间切成若干**层（stratum）**，每层是一个接触拓扑（一个机构）；层内是连续控制，层间是离散重配置。抓取规划 = 在**分层配置空间**上找一条从初始机构到「满足任务后置条件」的机构的路径，且每一层内都用任务空间力封闭裕度保证可行。这天然是一个**混合自动机 / options** 结构：神经网络管层内，一个小型离散控制器管层间。

## 2. 严谨定义（U13–U24）

先给记号。刚体集合 `B = {L, R, O_1..O_n, T(桌面), W(墙/桌沿), H(另一只手)}`；接触 `c = (i, j, p, n, μ)`（位置、法向、摩擦系数）。记任务 τ 的**允许运动子空间** `T_τ ⊆ R^6`（插入：垂直于插入轴的 2 平移 + 2 倾转；拧盖：绕盖轴 1 转动 + 1 轴向压；抓放：3 平移）。

**U13（机构）** 机构 `M = (B_M, C_M, A_M)`，`B_M ⊆ B` 为参与刚体，`C_M` 为活跃接触集，`A_M` 为被驱动关节（夹爪开合 + 手臂 6/7 DoF + 可选基座）。机构不是硬件型号，而是**当前接触约束的一次快照**。

**U14（接触力旋量与任务空间力封闭）** 每个接触 `c` 的摩擦锥 `K_c` 产生力旋量集 `W_c = { [f; p_c × f] : f ∈ K_c }`，机构总力旋量空间 `W(M) = Σ_{c∈C_M} W_c`。对任务子空间 `T_τ`，投影 `P_τ: R^6 → T_τ`。**任务空间力封闭**：`0 ∈ int(P_τ W(M))`；**任务空间裕度** `κ_τ(M) = dist(0, ∂ P_τ W(M)) / κ_0`（用 Ferrari–Canny ε 或投影后的最小支撑距离）。

**U15（可重构机构图）** `R = (V, E)`，`V = {M : κ_τ(M) ≥ κ_min 且前置条件成立}`，`E = {(M, M', ρ, cost)}`，`ρ` 为一次重配置原语（regrasp / slide / pivot / fixture-engage / fixture-release / hand-off）。边存在需同时满足：运动学可达、准静态下接触不失效、可观测（能用 U4 的 `g_t` 确认成功）、代价有限。

**U16（机构库）** `𝓜 = {(M_k, pre_k, post_k, fail_k)}`，每个机构带前置条件（物体尺寸 vs 夹爪开口、表面可夹性、目标可达性、夹具可用性）、后置条件（任务子空间被约束住）、已知失效模式。

**U17（机构 token 与分层策略）** `z_mech = emb(M)`，策略 `π(a_{1:T} | o, ℓ, z_task, z_phase, z_mech, c)`；`z_mech` 只经 FiLM / AdaIN 调制共享主干与单一动作头（**单 checkpoint、单 API**），不复制整套权重。

**U18（重配置算子与触发）** `R: M → M'`，触发条件为 `VOR(M→M') > 0` 且安全不变式成立（见 U24）；`VOR` 见 U21。

**U19（环境夹具原语集）** `Φ = {brace(抵墙/抵桌沿), pin(按在桌面), edge-stop(用桌沿止推), topple(借重力翻倒), cage(用另一只手/杂物围笼), wedge(塞入缝隙)}`；每个原语声明其可建立的接触与所需感知。

**U20（任务条件抓取规划目标）** 对候选抓取 `g ∈ SE(3) × width` 与机构 `M(g)`，`Q_τ(g) = κ_τ(M(g)) − λ_col·collision(g) − λ_reach·reach_cost(g) + λ_sem·affordance_ℓ(g) − λ_rec·reconfig_cost(M(g))`；规划输出 `top-k` 而非单一最优（保留不确定性）。

**U21（重配置价值）** `VOR(M→M') = E[ΔP_succ] − λ_T·ΔT − λ_R·Risk − λ_C·Cost`；在代价不对称时取阈值形式（见 L10）。

**U22（分层配置空间与转移代价）** `𝒳 = ⊔_k 𝒳_k`，`𝒳_k` 为机构 `k` 内的连续状态流形；转移代价 `c(M,M')` 含时间、掉落风险、已完成的阶段被破坏的风险。

**U23（规划蒸馏）** 慢规划器 `Π_slow: (o, τ) → (M*, g*, 子目标)`；蒸馏损失 `L_distill = ‖π_fast(o,τ) − Π_slow(o,τ)‖`，只在相位边界状态上采样，避免污染高频闭环。

**U24（重配置安全不变式）** 仅在 `‖v_ee‖ ≤ v_max`、夹持标量在安全区、且 `κ_τ(M) ≥ κ_min` 时允许转移；禁止「带载高速换机构」，保证最坏滑移冲量有界。

## 3. 本轮研究问题（在 v1 之上）

- **Q6（机构的可观测与可建立）**：在 4 路相机 + 1 维夹爪 + EE 位姿的观测下，能否识别「此刻可用哪个环境夹具」并可靠地把物体建立到该夹具上？识别错的代价是什么？
- **Q7（数据里有没有机构）**：官方 32 个数据集里，除对捏外还出现了哪些接触拓扑？若 extrinsic dexterity 在数据中几乎不存在，我们如何用少量遥操 / 仿真 / 规划合成补上，而不掉进 sim-to-real 坑？
- **Q8（规划 vs 学习的边界）**：哪些决策交给低频物理规划（机构 / 抓取候选），哪些交给高频 VLA（伺服 / 柔顺 / 避碰）？边界放错会不会既慢又差？
- **Q9（重配置的计分价值）**：在「只认终态成功、时长无红利」的计分下，重配置增加的时间是否值得？触发阈值应如何按任务难度分层？
- **Q10（合规与可信度）**：机构 token 是否仍算「单模型」？重配置带来的动作不连续是否会被「动作统计规律性」审核判为不可信？

## 4. 设计原则（在 v1 P1–P6 上追加）

- **P7 机构优先于抓法**：先问「该任务需要哪种接触拓扑」，再问「在这个机构里抓哪里」。抓法选择是机构选择的子问题。
- **P8 环境是被动机构库**：桌面 / 桌沿 / 墙 / 另一只手 / 其他物体都登记为可征用的机构元件，并各自声明可建立的接触与风险。
- **P9 层内神经、层间符号**：连续控制用 VLA，离散重配置用可审计的小型控制器；层间转移必须有可观测的成功判据（复用 `g_t`）。
- **P10 规划低频、闭环高频**：物理规划只在相位边界跑；任何时刻的高频路径不得依赖慢规划器在线返回。
- **P11 机构可退化**：机构库不可用 / 识别失败 ⇒ 退回 v1 的单机构（对捏）策略；重配置不安全 ⇒ 禁止转移，只做层内控制。

## 5. MVP 与退化链

**MVP = IP-09（机构库 + 重配置图，先做离线挖掘与可行性判定） + IP-10（环境夹具原语：pin / brace / edge-stop 三个最常用） + IP-11（任务空间裕度估计器） + v1 的 GraspVerify 与代理评测**。
理由：先用 E619/E621 回答「数据里有没有、夹具识别准不准」这两个生死问题；再决定是否投入 IP-12 的机构 token 与 IP-13 的规划蒸馏。

**严格退化链**：

- L0 环境夹具识别不可靠 ⇒ 只保留「桌面 pin + 桌沿 edge-stop」两个高置信原语；
- L1 任务空间裕度估计不可用 ⇒ 退回 v1 的 `g_t` 二值确认 + 固定对捏；
- L2 机构 token 路由错配 ⇒ 退回单机构（对捏）专家；
- L3 重配置触发不安全 ⇒ 关闭层间转移，仅层内控制；
- L4 整条新链路失效 ⇒ 退回 v1 的纯基线提交（安全网）。

## 6. 预期贡献

1. **把「抓取规划」从单次抓取位姿升级为机构级规划**：给出「任务空间力封闭」作为机构可行性判据，并用它解释为什么最难 6 任务是机构问题而非抓取问题。
2. **把环境从障碍物重新归类为可征用的被动机构**：给出环境夹具原语集与「识别—建立—确认—释放」闭环，且每个原语都有可观测成功判据。
3. **一个可审计的分层架构**：层内 VLA、层间符号控制器，天然适配单 checkpoint / 单 API 的合规要求，并给出退化链。
4. **机构感知的失败分解**：把 v1 的六因子 `P(grasp|reach)` 细化为 `Σ_M P(M) P(grasp|M)`，让「换机构能救多少」可量化。
5. **对官方数据的机构普查**：给出 32 任务里接触拓扑的经验分布，这是全赛道可复用的公共品。

## 7. 本轮最大风险（一句话）

**本轮把赌注压在「环境夹具可被可靠识别并建立」上，而评测场景恰好是随机化的泛化场景——一旦策略把一个并不存在的「墙 / 桌沿 / 支撑」当成机构的一部分，规划出的力封闭在真实接触里根本不存在，重配置就会把「抓不稳」升级成「带载撞飞 / 掉落」；更糟的是官方示范里可能几乎没有 extrinsic dexterity，机构库的上半部分只能靠合成数据，分布漂移会让最需要它的难任务最不可信。**

## 8. 下一轮迭代计划

- **深化**：把 U14 的任务空间裕度从「几何估计」升级为「在线接触状态估计」（用腕部形变 / 滑移线索），并把 U15 的边代价与 v1 的六因子对齐（每条边负责一个因子）。
- **修剪预案**：若 E619 显示官方数据中环境接触拓扑占比 <5%，则**砍掉从数据学习机构库的路线**，只保留「几何规划合成 + 少量真机示教」的机构库；若 E621 的夹具识别 AUROC <0.8，则只保留桌面 pin 与 edge-stop 两个原语。
- **保留项**：IP-09（规划底座）、IP-10（最常用三原语）、IP-11（裕度估计）不砍；IP-12/IP-13 视前两项结果推进。

## 0. 结论摘要

**一句话路线**：把「抓取」从「一次闭合」升级为「**在一个可重构机构图上做任务空间力封闭规划**」——机构 = 由手指 / 手掌 / 桌面 / 桌沿 / 墙 / 另一只手 / 其他物体组装出的接触拓扑；抓取规划 = 在分层配置空间上选机构、选抓取、必要时重配置。工程上仍是一个 checkpoint、一个 API：层内由 VLA 连续控制，层间由可审计的符号控制器切换。

**四条依据**：

| 证据 | 数值 / 事实 | 推出的设计 |
|---|---|---|
| 最难 6 任务全是插入 / 旋转 / 细粒度 | 17.7–23.3，显著低于 29.7 榜首 | 不是「抓不稳」，是「机构不够用」→ IP-09/10 |
| 1-DoF 夹爪只给 ≤2 个接触力旋量；空间力封闭需 ≥7 | 经典力封闭结论 | 单靠夹爪不可能封闭 → 必须征用环境接触 |
| 任务只需要**任务空间**封闭，不需全 6-DoF | 插入 / 拧盖的允许运动子空间维度低 | 用 `P_τ W(M)` 判据，环境只需补少数约束 → L9 |
| v1 已证明时长无红利、只认终态 | corr(dur,succ)≈−0.011 | 重配置必须用 VOR 门控，不能无脑加步骤 → U21 |

**合规红线**：机构 token 只做条件化，不复制整套权重；重配置只在安全不变式下发生；不使用评测侧私有信息；一切「识别夹具」只用观测。

## 2. 创新点详述

### IP-09 · RML 可重构机构库 + 重配置图（P0）

- **动机**：v1 的动作集合是「继续 / 重抓 / 非抓取原语」，默认机构固定为二指对捏。最难 6 任务（插入 / 旋转 / 细粒度）恰恰要求夹爪之外的环境约束。若把环境接触纳入机构，单自由度夹爪的有效能力被显著扩展。
- **与现有方案的差异**：现有 VLA 方案与环境的关系是「避碰」；我们把环境建模为**可征用的被动机构元件**，并把「选机构」放在「选抓取」之前。与经典抓取规划相比，我们不只规划一次抓取，而是规划**接触拓扑的转移序列**。
- **技术可行性**：中。机构库的「下半部分」（对捏、双手围笼、桌面 pin）在官方数据里大概率存在，可挖掘；「上半部分」（edge-stop、wedge、topple）可能需几何合成 + 少量遥操。重配置图规模小（机构数 ~10–20），可离线建好。
- **所需资源**：数据 = 官方 32 数据集 + 少量自采遥操（≤5 h）；算力 = 离线挖掘与图构建，单卡数小时；接口 = 无新增字段（纯策略内部）。
- **落地步骤**：
  1. 从官方数据自动挖掘接触事件（夹爪闭合、物体随臂运动、物体与桌面 / 其他物体接触），得到经验机构分布（E619）；
  2. 用几何规则补全机构库：物体宽度 vs 夹爪开口、目标到桌沿距离、可夹表面、可达方向；
  3. 对每个机构估计 `κ_τ(M)`（见 IP-11），建重配置图 `R`；
  4. 用 E621 在难任务上验证「机构库是否覆盖任务所需拓扑」；
  5. 若覆盖不足，优先补「桌面 pin / 桌沿 edge-stop」两个最通用的原语（IP-10）。
- **风险**：①机构库过度膨胀 → 路由歧义；缓解：每个机构必须服务 ≥2 个任务（沿用 v1 P3），并做边际价值剪枝（L14）；②环境接触在数据里太稀疏 → 图的上半部分不可信（见 §9 剪枝预案）。

### IP-10 · EFP 环境夹具原语（P0）

- **动机**：单自由度夹爪在「拧盖 / 插钥匙 / 细线 / 宽物」上物理不可行，但人靠桌面、桌沿、墙、另一只手就能完成。把这类操作固化为可复用的**环境夹具原语**，是性价比最高的机构扩展。
- **与现有方案的差异**：v1 的「非抓取原语」（推 / 扫 / 倾倒 / 钩）只是「换动作」；本轮的原语是「**换机构**」——不仅换动作，还改变物体受到的约束，使后续插入 / 旋转在力封闭意义上可行。
- **技术可行性**：中–高。pin（按在桌面）与 edge-stop（桌沿止推）只需要桌平面估计 + 接触确认，感知要求低；brace（抵墙）需要墙 / 桌沿检测；cage（另一只手）需要双手协调，最难但收益也最大。
- **所需资源**：数据 = 几何规则 + 少量示教；算力 = 小；接口 = 无。
- **落地步骤**：
  1. 定义每个原语的状态机（approach → establish contact → verify → use → release）；
  2. 用 `g_t` + 腕部几何 + EE 速度确认「夹具已建立」；
  3. 在 Unlock / Open Pill Bottle / Plug In Ethernet 上做 A/B（E622）；
  4. 失败回退：夹具建立失败 → 回 v1 对捏或非抓取原语。
- **风险**：①误判「有墙 / 有桌沿」→ 建立失败并撞飞物体；缓解：只用高置信几何（桌平面 RANSAC + 深度一致性），并设「建立失败即释放重试 ≤2 次」；②夹具使用可能破坏场景（推倒其他物体）→ 限用于单物体 / 稀疏场景。

### IP-11 · WME 任务空间裕度估计（P0）

- **动机**：重配置需要两个量：**现在这个机构够不够用**（裕度）、**换了值不值**（VOR）。v1 的 `g_t` 只回答「抓住了吗」，不回答「抓得够不够稳、够不够转」。任务空间裕度把「够用」变成可估计、可校准的量。
- **与现有方案的差异**：v1 的抓握确认是二值 / 概率；本轮估计的是**投影到任务子空间后的力封闭裕度**，直接对应「这个任务需要的那部分运动是否被约束住」。这比通用抓取质量分更贴合任务。
- **技术可行性**：中。离线标签可由几何 + 物理仿真生成（物体网格 + 接触点 → `κ_τ`）；在线用视觉 + 本体感觉回归。难点是「部分点云 + 未知摩擦」下的校准。
- **所需资源**：数据 = 仿真标签 + 真机校准；算力 = 小 CNN / MLP；接口 = 无。
- **落地步骤**：
  1. 离线：对官方任务物体做网格重建 / 近似，采样接触，计算 `κ_τ` 标签；
  2. 在线：从腕部帧 + 夹爪标量 + EE 速度回归 `κ_τ` 与不确定性；
  3. 校准：可靠性图 + 分任务阈值；
  4. 把 `κ_τ` 同时喂给触发（U18）与抓取打分（U20）。
- **风险**：①摩擦系数未知 → 裕度系统性偏乐观；缓解：用保守摩擦下界 + 在线滑移检测修正；②标签来自仿真 → sim-to-real 漂移；缓解：用真机少量标定 + 只在高置信区间介入。

### IP-12 · MSP 机构分层策略（P1）

- **动机**：机构是离散的接触拓扑，层内是连续控制。用 token 条件化一个共享主干，可以在**单 checkpoint** 内表达多个机构，同时避免为每个机构复制整套模型（合规 + 参数效率）。
- **与现有方案的差异**：v1 的 IP-01 是 `(z_task, z_phase)` 技能条件化；本轮扩展为 `(z_task, z_phase, z_mech)`。机构 token 与技能 token 正交：技能回答「做哪段」，机构回答「用哪种接触拓扑做」。
- **技术可行性**：中–高。实现上就是 FiLM / AdaIN 多一个条件；训练数据按机构分层采样即可。
- **所需资源**：算力 = 与 v1 主干同量级；数据 = 分层后的官方数据 + 合成 / 示教；接口 = 仍是单 `get_action`。
- **落地步骤**：
  1. 先做「单机构 + 机构 token」消融，验证 token 本身是否涨点；
  2. 再加层间符号控制器（见 §4 伪代码）；
  3. 做路由消融（oracle 机构 vs 真实机构），量化兑现率；
  4. 准备「单机构降级」形态并实测损失（合规兜底）。
- **风险**：①机构路由错 → 错上加错；缓解：只在 `VOR > 0` 且高置信时切换，否则留在当前机构；②多机构数据不均衡 → 少数机构欠拟合；缓解：分层重采样 + 合成数据。

### IP-13 · PDD 规划蒸馏（P2）

- **动机**：经典抓取规划器（采样 + 力封闭评估 + 运动规划）精度高但慢，不能每步跑；而 VLA 快但缺乏显式物理判据。蒸馏让「慢顾问」的低频输出变成「快策略」的先验。
- **与现有方案的差异**：不是把规划器当在线模块，而是**只在相位边界**调用，把结果蒸馏进策略；部署时零额外延迟。
- **技术可行性**：中。难点是相位边界状态分布覆盖不足（L12）。
- **所需资源**：算力 = 离线；接口 = 无。
- **落地步骤**：①离线跑慢规划器生成 `(M*, g*, 子目标)`；②在相位边界状态上训练蒸馏头；③用 E626 测一致率；④只在一致率高时启用。
- **风险**：①蒸馏覆盖不足 → 分布外失效；缓解：只在高置信相位边界启用 + 回退到 v1 策略；②慢规划器本身依赖物体模型 → 真实场景部分点云下失真；缓解：用部分点云规划 + 不确定性输出。

@dataclass
class Mechanism:
    bodies: set          # {L,R,O,T,W,H,...}
    contacts: list       # [(i,j,p,n,mu), ...]
    actuators: set       # {'gripper','arm_l','arm_r','base'}

def build_graph(library, task_tau, kappa_min):
    V = [M for M in library if M.pre(scene) and kappa_tau(M, task_tau) >= kappa_min]
    E = []
    for M in V:
        for M2 in V:
            if M is M2: continue
            for rho in RECONFIG_PRIMITIVES:
                if kinematic_ok(M, M2, rho) and \
                   quasi_static_ok(M, M2, rho) and \
                   observable(M, M2) and \
                   cost(M, M2, rho) < INF:
                    E.append((M, M2, rho, cost(M, M2, rho)))
    return Graph(V, E)

# ===== 任务空间力封闭裕度（IP-11 的几何内核）=====
def kappa_tau(M, task_tau):
    W = minkowski_sum([wrench_cone(c) for c in M.contacts])
    Wp = project(W, task_tau)             # P_tau W(M)
    if not contains_origin_interior(Wp):
        return 0.0
    return distance_to_boundary(0.0, Wp) / KAPPA_0

# ===== 分层策略 + 重配置控制器（IP-12）=====
class MORPHPolicy:                        # 仍是单 checkpoint、单 API
    def __init__(self, ckpt, library, graph):
        self.model = load_single_checkpoint(ckpt)   # 主干 + FiLM + 单动作头
        self.gv = GraspVerifier()                   # 复用 v1 U4
        self.wme = WrenchMarginEstimator()          # IP-11
        self.library = library
        self.graph = graph
        self.sessions = {}                          # 按端口隔离

    def reset(self, port=None):
        self.sessions.setdefault(port, Session()).reset()

    def get_action(self, obs, port=None):
        s = self.sessions[port]
        phase = self.fc.predict(obs)                # v1 U3
        ztask = self.task_router(obs["observation.language"])
        zmech = s.mech_token                         # 当前机构 token

        # --- 只在相位边界评估重配置（P10）---
        if phase in BOUNDARY_PHASES:
            M_now = self.library[s.mech_id]
            kappa = self.wme.estimate(obs, M_now)    # IP-11
            if kappa < s.kappa_threshold:
                best, vor = None, 0.0
                for M2 in self.graph.neighbors(M_now):
                    v = self.value_of_reconfig(M_now, M2, obs, phase)
                    if v > vor and safety_invariant(obs, M_now):
                        best, vor = M2, v
                if best is not None:
                    s.pending_transition = (best, self.graph.primitive(M_now, best))
                    # 先执行重配置原语，成功后切换 token
        if s.pending_transition is not None:
            a = self.execute_transition(obs, s.pending_transition)
            if self.transition_done(obs, s.pending_transition):
                s.mech_id, s.mech_token = s.pending_transition[0].id, emb(s.pending_transition[0])
                s.pending_transition = None
            return self.pack(a, obs)

        # --- 层内连续控制（复用 v1 的缝合 / 限幅 / 审计）---
        a = self.model.act(obs, ztask, phase, s.mech_token, s.context, s.chunk_len(phase))
        a = self.st.stitch(a, s.last_action)         # v1 U7
        a = self.audit.clamp_and_log(a, obs, s.t0, self.tau_budget_ms)
        s.last_action = a[-1]
        return self.pack(a, obs)

    def value_of_reconfig(self, M, M2, obs, phase):
        dp = self.success_gain_model(M, M2, obs, phase)     # 学出来的或查表
        dt = self.time_cost(M2) - self.time_cost(M)
        risk = self.risk_model(M2, obs)
        return dp - LAM_T * dt - LAM_R * risk - LAM_C * self.cost(M, M2)

# ===== 机构感知的六因子分解（扩展 v1 IP-06）=====
def mechanism_aware_taxonomy(episode, phase_labels, mech_labels):
    """P(success) ≈ P(reach) · [Σ_M P(M|reach) P(grasp|M)] · P(transport) · P(align) · P(insert) · P(release)"""
    p_grasp = 0.0
    for M in set(mech_labels):
        mask = [i for i, m in enumerate(mech_labels) if m == M]
        p_grasp += len(mask) / len(mech_labels) * grasp_success_rate(episode, mask)
    factors = {j: 1.0 for j in ["reach", "transport", "align", "insert", "release"]}
    factors["grasp"] = p_grasp
    return factors

## 5. 推导（引理 L8–L14）

**引理 L8（机构增广的单调性只对「可行集」成立，不对「实现成功率」成立）**
设机构库 `𝓜 ⊆ 𝓜'`。任务所需运动子空间可被力封闭的任务集合满足 `Feasible(𝓜) ⊆ Feasible(𝓜')`（增广只会增加可封闭的机构）。但学习到的路由器的实现成功率不自动单调：若新增机构被误选的概率为 `ε_add`，则净收益 `≥ (1−ε_add)·Δ_gain − ε_add·Δ_loss`。因此「加机构」必须配「高精度触发」，否则会重蹈 v1 L3 的误判不对称。∎

**引理 L9（环境接触补全任务空间封闭：以拧盖为例）**
考虑 2D 圆盘（瓶盖）绕中心轴 `z` 的转动。二指夹爪在过圆心的对径点接触，无摩擦时接触法向过圆心 ⇒ 力臂为零，`τ_z = p × f = 0`；故 `W(M_gripper)` 在 `τ_z` 方向没有分量，单靠夹爪**无法**完成「拧」这一任务子空间。现在加入桌面接触：桌面在半径 `r_T` 处提供法向力 `f_N` 与切向摩擦 `f_T ≤ μ f_N`，产生 `τ_z = r_T·f_T`。当 `μ f_N r_T ≥ τ_req` 且夹爪侧能提供反向切向力平衡净力时，`P_τ W(M)` 在 `τ_z` 方向包含 0 的邻域 ⇒ 任务空间封闭成立。这定量说明：**环境补的是「旋转约束」这一特定缺失维度，而非全部 6-DoF**。∎

**引理 L10（重配置触发是 Bayes 阈值）**
设「当前机构其实已失效」的后验为 `p`，不必要重配置的代价 `C_fp`，漏掉必要重配置的代价 `C_fn`。则期望代价 `p·C_fn·[不换]` vs `(1−p)·C_fp·[换]`，最优触发为
`p > C_fp / (C_fp + C_fn)`。
因 `C_fn`（带载硬失败 / 超时）通常远大于 `C_fp`（多花几秒），阈值应偏低（更愿意换），但前提是 `κ_τ` **已校准**——这解释了为何 IP-11 的可靠性图是前置条件。∎

**引理 L11（机构 token 的分离性）**
若机构对应不同的接触拓扑，则其状态流形 `𝒳_k` 在拓扑上是分离的（离散切换）。一个共享主干 + token 调制的头可以分别表示各 `𝒳_k`，层间干扰由调制函数的 Lipschitz 常数界定；且每个机构只需覆盖自己的流形，数据效率优于单体策略覆盖并集。∎

**引理 L12（规划蒸馏的误差界）**
若慢规划器 `Π_slow` 在相位边界状态分布上 `L`-Lipschitz，蒸馏策略在半径 `δ` 的覆盖上训练误差为 `ε_train`，则次优性 `≤ L·δ + ε_train`（高概率）。因此**覆盖相位边界状态**比堆样本量更重要。∎

**引理 L13（重配置安全）**
若转移被 `‖v_ee‖ ≤ v_max`、夹持标量安全区、`κ_τ ≥ κ_min` 三重门控，则失败转移的最大滑移冲量 `≤ m·v_max`，物体位移误差有界，不会出现无界弹射。注意：该界假设准静态且摩擦模型有效；真实接触的瞬时冲击可能突破该界，故仍需真机安全测试。∎

**引理 L14（机构库的边际价值递减）**
设最难任务需要机构 `k` 的经验概率为 `p_k`，相对对捏的增益为 `Δ_k`，则增广期望收益 `Σ_k p_k Δ_k`；若机构间功能重叠（同一任务可被多个机构完成），则边际价值随重叠度递减。故机构库应按「覆盖难任务 + 低重叠」剪枝，而非越多越好。∎

## 9. 风险登记册与剪枝预案

| 风险 | 概率 | 影响 | 对冲 |
|---|---|---|---|
| **环境夹具被幻觉**（把不存在的墙 / 桌沿当机构） | 中高 | 高（撞飞 / 掉落） | 只用高置信几何；建立失败即释放重试 ≤2；安全不变式 |
| **官方数据缺 extrinsic dexterity** | 中高 | 高（机构库上半部分不可学） | E619 先普查；不足则几何合成 + 少量遥操；不硬从数据学 |
| **sim-to-real 漂移**（仿真标签 / 合成示教） | 中 | 中高 | 保守摩擦下界；真机小样本校准；高置信才介入 |
| **重配置增加时长 / 步骤** | 中 | 中 | VOR 门控；只在相位边界；时长无红利 ⇒ 不追求快但避免无谓切换 |
| **机构 token 被判多模型** | 中 | 高 | 单 checkpoint + FiLM；预备单机构降级形态；书面确认 |
| **动作不连续被审核判不可信** | 中 | 中 | 层间转移只在安全不变式下发生；审计导出；保留策略随机性 |
| **规划器延迟拖垮闭环** | 中 | 中 | 规划只在相位边界；缓存；高频路径零调用 |
| **机构库膨胀导致路由歧义** | 中 | 中 | 每机构 ≥2 任务复用；低重叠剪枝（L14） |

**剪枝预案（下一轮起执行）**：

- **必保**：IP-09（规划底座）、IP-10（pin / brace / edge-stop）、IP-11（裕度估计）。
- **优先深化**：IP-10 的 edge-stop 与 pin（性价比最高、感知要求最低）。
- **条件推进**：IP-12（依赖 E619/E621）、IP-13（依赖 E626）。
- **暂存**：cage（双手围笼）与 wedge（最难的夹具原语，放到机构库稳定后再做）。
