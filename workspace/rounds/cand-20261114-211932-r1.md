# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环第 3 轮；本轮灵感：「轨迹优化」×「伦理与合规」）

> R69 终于让系统学会了「问」：把不确定性拆成 aleatoric 与 epistemic，用流匹配的多模态动作显式表达歧义，用注视/探针/问句去主动消解。但 R69 的整个安全观仍是**可补偿的**：一切都被压进一个标量 λ_floor 和一个成本预算 c(g)，于是系统永远可以**用一点点更多风险/成本，换一点点更少保守**。这在工程上漂亮，在伦理上是范畴错误——**同意、隐私、不歧视、不操纵、可解释、可申辩，不是可加权的项，而是不可越过的可行域边界**。把「撞到人的概率」从 1e-6 压到 1e-9 叫安全；把「未经同意使用某人的情绪数据」从 1 次压到 0.01 次不叫合规，叫**仍然违规**。期望效用算术在这里恰好是最不该用的工具。
>
> 两个灵感正好补两块：
> - **轨迹优化**不是又一种控制器，而是把「约束」从事后惩罚变成**事先的可行域**：在整条轨迹（含未来的看/问/触）上搜索，并对不可行给出**不可行证书**（对偶/Farkas）。它天然处理带 deadline 的义务（「使用数据前必须先取得同意」），这正是 R69 只看 certified prefix、从不看整段义务链的盲点。
> - **伦理与合规**提供内容与优先级：道义逻辑（义务/许可/禁止）、时间逻辑（until/deadline）、管辖与版本、问责与可争辩。合规不是「风险低」，而是「**被允许**」。
>
> 本轮引入第三类不确定性 **U_norm（规范不确定性）**，并把它劈成 **U_app（适用性：事实问题，可被感知，但取证本身受隐私约束）** 与 **U_int（解释/效力/权限：不是世界事实，感知不可约，只能由合法权威或预防原则处置）**。R69 的 VoI 机制只能碰 U_app；对 U_int 用 VoI 是把价值判断伪装成经验问题，是**用提问洗白一个没有权限的决定**。
>
> 核心命题：**在 R69 的可补偿层之下，垫一层不可补偿的规范可行域；用约束轨迹优化在「任务动作 × 信息动作 × 信息流」的整条增广轨迹上硬性执行；用携带证明的合规证书把「我没违规」变成「可被第三方验证的我没违规」；规范不确定性走升级/预防，不走采样/追问。** 命名 **LEX-RAS**（Lexicographic EXecution with Rights, Accountability, Safety；lex 亦为「法」）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我凭什么被允许这么做，即使它有效**」——R69 学会提问，R70 必须先学会**哪些问题不许问、哪些答案不许用、哪些轨迹即使成功也不许走**。

## 0. 直觉与动机

**灵感 1（轨迹优化 → 约束是可行域，不是惩罚项）**

直觉：R69 的 λ_floor 是在一个已选动作上踩刹车，本质是**惩罚/缩放**；轨迹优化是在整条轨迹空间里搜索，本质是**约束**。两者差别不是快慢，而是逻辑：惩罚可以被更大的奖励「买断」，可行域不能。人行横道前，「不撞行人」不该是一个权重很大的软项——它应该直接删除那族轨迹。更关键的是，轨迹优化在不可行时会给出**不可行证书**：不是「我没找到」，而是「在给定动力学与规范下，不存在合规轨迹」。这是面对硬约束唯一诚实的回答；优化器最危险的行为不是找不到解，而是**悄悄返回一个最小违规解**并把它当成解。

第二层直觉：义务是**时间性**的。「先取得同意再用数据」「拒绝后 T 秒内停止」「探针前先示警」都是对轨迹的时序约束，而不是对某一帧的约束。R69 的 C-RAS-WM 只认证 committed prefix，从不检查「这条前缀之后还存在合规完成吗」。轨迹优化把「存在合规后缀」变成可计算的存在性/可行性问题——这正是「先看一步」与「先看一整段义务」的差别。

**灵感 2（伦理与合规 → 合规是许可，不是低风险）**

直觉：安全问「最坏会怎样」，合规问「我有没有资格做」。前者是概率与代价，后者是**许可与边界**。权利的一个定义性特征就是**不可补偿**：不能因为收益足够大就买断。因此把伦理写成一个惩罚项，在结构上就错了；它必须进入约束，且在冲突时进入**词典序**（权利 > 法规 > 契约/政策 > 偏好），而不是加权和。有限罚的大惩罚项总能在某个状态被更大的任务收益淹没，这不是调参问题，是 Goodhart 的结构性问题。

第三层直觉：合规还是**制度性**的——有管辖、有版本、有授权主体、有举证责任、有申辩权。一个系统即使碰巧守了规矩，若说不出「依据哪一版规范、由谁授权、证据是什么、如何申辩」，它在合规意义上仍是不合格的。所以证书必须绑定 **norm_version × jurisdiction × authority**，审计必须能回答「当时生效的是哪一条」，行为不能靠事后换规范来「追溯合规」。

**灵感 3（第三类不确定性 → 规范不确定性不可被感知消解）**

直觉：R69 把所有「不知道」都当成世界的不确定，于是默认「多看一眼/多问一句就能减少」。但「我该不该问这个」「这个回答我有没有资格用」「这条规范在此地此刻适用吗」不是世界事实。把 U_norm 劈开：

- **U_app（适用性）**：这是不是未成年人？是不是医疗急症？是不是禁区？——是事实，原则上可感知；但**感知本身可能被隐私/同意规范禁止**（不能为了判断是不是未成年人就偷偷人脸估龄）。这产生一个漂亮的循环：**用信息动作消解 U_app 的许可，本身受规范约束**。
- **U_int（解释/效力/权限）**：这条规范到底要求什么？两个管辖冲突时谁优先？这个「人」有没有资格代表机构作答？——这不是感知能回答的。对它用 VoI，等于**问路人一个只有立法者/监管者才能回答的问题**，然后把这个回答当成事实。R69 的 MINT 会毫不犹豫地这么做，因为 VoI 只看「熵降不降」，不看「谁有资格降」。

所以 R70 的核心分离是：**世界不确定性 → 交互（R69）；规范适用性 → 在合规前提下取证；规范解释/效力 → 升级到合法权威或按预防原则取更严解释。三者不可混用。** 一旦混用，系统就会用「我问过了」来为一个它根本无权做的决定背书。

**灵感 4（严格包含 → 空规范集时逐指令退化为 R69）**

直觉：继续 R69 的理论姿态。若规范集为空（或全部动作被许可且 U_norm=0），LEX 的可行域就等于 R69 的可行域，所有新增模块成为恒等/空操作，逐指令行为相同。规范一旦非空，可行域是 R69 的**子集**。因此本轮不是「能力扩张」，而是「**许可收缩**」：R69 让系统能做更多事，R70 规定哪些事即使做得到也不许做。安全/合规侧永不更弱；效率侧可能更低，这个差额就是**合规税**，必须被显式测量而不是藏起来。

**灵感 5（字面 vs 实质 → 证书是双刃剑）**

直觉：形式验证证明的是**模型的性质**，不是世界的性质，更不是道德的正确性。若规范写漏了一条义务、把某类人排除在「人」的定义外、或优化器学会在字面合规与实质合规之间钻空子，那么一份「携带证明的合规证书」只会让错误**更可信**。这是 R69 操纵风险的规范层对偶：R69 怕「问错比不问更危险」，R70 怕「**被证明合规的错误比未被证明的错误更危险**」。所以本轮必须同时交付：规范来源与合法性（谁写的、凭什么）、对抗性规范红队（letter vs spirit）、反事实「精神测试」、可争辩通道，以及一个在解释未定时**拒绝出证**的 U_int 通道。证书越硬，越要问「它证的是什么」。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（LEX-RAS 总览）** LEX-RAS = (DTO, NMS, CGE, CFI, PCCC, NUT, DLA; RAS-WM††)。四条不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i / R69 定义 293-i）；
(ii) **不可补偿性**：规范约束与可补偿目标分层，任何有限权重 α·J_task 不得抵消一次硬规范违反；
(iii) **无证书不执行**：任何 committed prefix 必须携带与当时生效 norm_version × jurisdiction 绑定的有效 PCCC；证书不可评估视同无效（fail-closed）；
(iv) **规范不确定性隔离**：U_int > τ_int 时只允许预授权兜底/升级，禁止用采样、交互或 LLM 自行「解释」规范。

**定义 311（增广轨迹与信息流）** 物理-信息轨迹 τ_{t:t+H} = (x_{t:t+H}, g_{t:t+H}, ι_{t:t+H})，其中 x 为物理状态/动作、g 为信息动作（R69 定义 294）、ι 为信息流事件（读取/推断/使用/留存/删除，带对象、目的、依据）。规范同时作用于 x、g 与 ι；「我看了但没用」与「我用了」在合规上不同。

**定义 312（道义时序规范 DSTL）** 规范原子命题作用于 τ 的时序片段。道义算子：义务 Oφ、许可 Pφ、禁止 Fφ，统一编译为带裕度的时序公式 φ（STL 片段 + 过去算子），语义为鲁棒度 ρ_φ(τ) ∈ ℝ，ρ_φ ≥ 0 ⇔ 满足。示例：
`F(use(pii) ∧ ¬consent_before)` ⇔ `G(use(pii) → ◇_{[0,T_c]} consent)`；
`O(stop | refusal)` ⇔ `G(refusal → ◇_{[0,T_s]} stop)`；
`F(leading_question)` 由定义 316 的操纵界给出。
每条规范带元组 (φ, ℓ, η_φ, ν, auth)，ℓ 为词典序层级（0 权利/宪法、1 法规、2 契约/政策、3 偏好），η_φ 为鲁棒度裕量，ν=(norm_id, version, jurisdiction, effective_time) 为版本，auth 为授权主体。

**定义 313（不可补偿词典序）** 对层级 ℓ，记 V_ℓ(τ)=Σ_{φ:ℓ(φ)=ℓ} max(0, η_φ−ρ_φ(τ))。决策序为 `τ ≺_lex τ'` 当且仅当存在 ℓ 使 V_ℓ(τ)<V_ℓ(τ') 且所有 ℓ'<ℓ 上 V_{ℓ'}(τ)=V_{ℓ'}(τ')；J_task 只作为最后一层 tie-break。硬层（ℓ≤1）要求 V_ℓ=0；软层（ℓ≥2）在硬层为 0 的前提下最小化。**不允许**把不同 ℓ 的 V 相加，也不允许用 J_task 抵消任何 V_ℓ。

**定义 314（规范可行集与不可行证书）** 𝒯_feas(N,o,t) = {τ : ρ_φ(τ) ≥ η_φ, ∀φ∈N} ∩ 𝒯_dyn ∩ 𝒯_safe。若为空，输出不可行证书 κ_inf（对偶可行解/Farkas 证书，或区间算术下界为 −∞ 的可验证证明），并强制进入定义 322 的退避；**禁止返回最小违规解**。

**定义 315（道义轨迹优化 DTO）**
`τ* = argmin_{τ∈𝒯_feas} J_task(τ)`，s.t. 动力学（VISTA）、物理安全（R69 C-RAS-WM）、规范（DSTL）、同意状态机（定义 316）、反事实不变性（定义 317）。
优化用光滑鲁棒度代理求梯度；**认证用可靠区间/可达集下界**，两者分离。只提交被认证的前缀 k_lex；若认证失败或预算不足，缩短 k_lex；若 k_lex=0，进入退避。R69 的流匹配采样只作为**提议分布**（warm start），不承担合规责任——采样器永远不被信任为「已合规」。

**定义 316（同意状态机与交互伦理 CGE）** 同意自动机 S_c ∈ {U, Rq, Gr, Rf, Rv, Ex}（未知/已请求/已授予/已拒绝/已撤回/已过期），转移只能由人类显式动作触发，系统**不得**自行置为 Gr。信息动作 g 可采纳当且仅当：
`Admissible(g) ⇔ purpose(g)⊆purpose_granted ∧ minimal(g) ∧ ¬coercive(g) ∧ ¬deceptive(g) ∧ authority_ok(g)`。
- **purpose binding**：目的变更需重新同意；
- **minimality**：只采集完成 g 与任务所必需的信息；
- **non-coercion**：`Δcost_refusal(g) ≤ 0`（不得提高拒绝的期望代价，含权力不对称）；
- **non-deception**：问句不得预设虚假事实（接地检查，复用 R69 的冻结 LLM 解码侧过滤）；
- 拒绝/撤回后 T_del 内删除派生数据；脆弱群体只走授权代理通道。

**定义 317（反事实合规 CFI）** 对受保护/私密属性 z，要求**策略级**（非单轨迹级）不变性：`sup_{o,o' 仅在 z 上不同} W_2(π(·|o), π(·|o')) ≤ δ_cf`；并要求信息泄漏 `I(z; τ | s_task) ≤ ε_leak`。二者作用于策略分布，防止「单条轨迹守规矩、策略整体歧视/泄漏」。估计器（critic/审计对）带版本，误差计入证书（A100）。

**定义 318（规范运行时监控 NMS）** 执行期用可达集 R_t 与模型误差 W_t 计算可靠下界 `ρ̲_φ(τ_{t:t+H}) ≥ ρ_model − L_ρ·W_t`；要求 `ρ_model ≥ η_φ + L_ρ·W_t`（裕量吃进模型误差）。若下界跌破，立即撤销本前缀认证、进入退避、并只允许 k_lex 收缩。NMS 只做「减法」（更保守），永不做「加法」（不得把不可证的部分当成立）。

**定义 319（规范不确定性三分）** 除 U_ale、U_epi 外，定义 `U_norm = U_app + U_int`：`U_app=H(适用性|o)`（事实、可取证，但取证受定义 316 约束），`U_int=H(解释/效力/权限|authority,o)`（不可由世界观测约简）。信息源分为世界观测 𝒜_world 与权威通道 𝒜_auth；在 A101 下，`g∈𝒜_world` 对 U_int 的期望信息增益为 0，故禁止用其「消解」U_int；`g∈𝒜_auth` 只能经升级协议调用，且其回答只作为**有出处的证据**，不自动成为事实。

**定义 320（证明携带合规证书 PCCC）**
`C_LEX = (C_FLUID, ν, {ρ̲_φ}, κ_feas/inf, δ_cf, ε_leak, consent_ledger_digest, retention_policy, monitor_trace_digest, fallback_used, signer)`。
Valid ⇔ Valid(C_FLUID) ∧ ν 与执行时刻生效规范一致 ∧ 所有 ρ̲_φ ≥ η_φ（或存在有效 κ_inf 且 fallback 合法）∧ 每次 ι 使用均有当时有效的同意/法定依据 ∧ 反事实/泄漏界达标（或附授权例外）∧ 监控未放过未认证前缀 ∧ 签名可验。证书可由**不信任策略的第三方**用公开的规范与区间重放验证。

**定义 321（规范账本与可争辩性 DLA）** 只追加账本记录 (duty, evidence, decision, ν, counterfactual, contest)。每次执行必须能产出**最小反事实**：「在什么最小改变下，决定会不同」；人类可对任一决定发起争辩，系统须按被争辩的 ν 重算并给出可验证答复。争辩不是可选 UI，而是合规的一部分（申辩权）。

**定义 322（词典序退避与升级）** 退避集 ℱ：
- **F0**：满足所有 ℓ≤1 规范的最小风险动作（停/保持/安全断电）；等待期间维持 F0；
- **F1**：在规定时限内向合法权威请求裁决或人类接管；
- **F2**：无权威可达时，采用**更严解释**（预防原则），绝不选「最小违规」；
- 若连 F0 都不可行（如停车阻塞救护通道），这是**规范冲突**，必须记录并升级到 F1/F2，禁止优化器自行「权衡」出一个解。
R69 的 `slow_fault_suspect` 保守路径嵌入为 F0 的一种实现。

**定义 323（规范版本与管辖绑定）** 行为绑定执行时刻的 ν；规范更新不溯及既往；审计按当时 ν 重放；跨管辖部署需显式选择或叠加（叠加时取更严，冲突则升级）。这防止「事后换规范」的合规造假。

**定义 324（合规税与合规-性能前沿）** `J_comp(η) = min_{τ∈𝒯_feas(η)} J_task(τ)`，对 η 单调不降；合规税 `ΔJ(η)=J_comp(η)−J_R69(η)`。在 (ΔJ, Violation) 平面上给出前沿；任何「零违规」声明必须同时报告 ΔJ，否则是无成本的合规神话。

**定义 325（世界-规范不确定性对偶）** 世界不确定性用交互消解（R69），规范不确定性用权威/预防消解（R70）。两种混淆对应两类新故障：
- **越权消解**：用 𝒜_world（路人、模型、众包）回答 U_int；
- **以权压实**：用权威断言覆盖可由感知纠正的 U_app（例如「规定如此」而无视眼前事实）。
二者都记入 AIC-LEX（IP-273）。

**定义 326（失效安全与心跳）** PCCC 带 TTL 与监控心跳；传感器丢失/监控不可评估/规范版本不可判定 ⇒ 证书立即失效 ⇒ F0。**fail-closed，不是 fail-open**；不允许「先执行再补证」。

```python
        self.nms, self.norms = nms, norms            # norms 已编译、带版本

    def optimize(self, o_t, budget):
        # 1) R69 的多模态提议（warm start，不承担合规责任）
        modes = self.flow.sample(o_t, K=4)
        best = None
        for tau0 in modes:
            # 2) 光滑代理上做 2-3 步约束精修（barrier + CBF 引导）
            tau = constrained_refine(tau0, self.vista, self.norms, iters=3)
            # 3) 认证：可靠下界，不用代理的乐观值
            rb = {phi: sound_robustness_lower(tau, phi, self.vista.error_bound())
                  for phi in self.norms.hard}
            if any(rb[p] < self.norms.eta[p] for p in rb):
                continue                              # 不可认证 → 丢弃
            if not self.wm.certify_prefix(tau, o_t):
                continue
            j = self.vista.task_cost(tau)
            if best is None or j < best.j: best = (tau, rb, j)
        if best is None:
            return None, infeasibility_certificate(self.norms, o_t)  # κ_inf
        # 4) 只提交被认证且 NMS 通过的前缀
        k = self.nms.certified_prefix_len(best.tau, o_t)
        return best.tau[:k], best.rb

# IP-266 NMS：规范运行时监控（只做减法）
def certified_prefix_len(tau, o_t):
    R = reachable_set(o_t, horizon=H)
    for k in range(len(tau), 0, -1):
        rb = {p: sound_robustness_lower(tau[:k], p, R) for p in hard_norms}
        if all(rb[p] >= eta[p] + L_rho * W for p in hard_norms):
            return k
    return 0

# IP-267 CGE：同意门 + 交互伦理
def admissible_info_action(g, state, purpose):
    if not purpose_subset(g.purpose, state.granted_purpose): return False
    if not minimal(g):                                      return False
    if refusal_cost_delta(g) > 0:                           return False
    if leading_KL(g) > kappa or not grounded(g):            return False
    if state.s in (REFUSED, REVOKED, EXPIRED):              return False
    if state.vulnerable and not state.guardian_channel:     return False
    return True

# IP-268 CFI：策略级反事实不变性（离线/低频，不入实时关键路径）
def counterfactual_bound(policy, o_pairs):
    return max(wasserstein2(policy(o), policy(o2)) for o, o2 in o_pairs)

# IP-274 LEX 主闭环（R69 之上加「规范投影 + 认证 + 退避」）
def LEX_RAS_round(M, obs):

    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)

    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    # R70：先做规范不确定性分诊，再决定能不能交互

    if U_int > TAU_INT:
        return M.fallback.escalate(F1, reason='U_int', cert=M.pccc.stub(o))
    # 只在「可采纳」的信息动作里用 VoI；越权通道被 CGE 直接过滤
    g = M.mint.choose_interaction(
            modes, o, M.budget,
            filter=lambda g: M.cge.admissible(g, M.consent, M.purpose))
    if g is not None:
        U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    # 道义轨迹优化：把 R69 的候选压进规范可行域
    tau, rb = M.dto.optimize(o, M.budget)          # 可能返回 None + κ_inf
    if tau is None:
        return M.fallback.escalate(F0, reason='infeasible', cert=rb)
    # 运行时监控 + 失效安全
    k = M.nms.certified_prefix_len(tau, o)
    if k == 0:
        return M.fallback.escalate(F0, reason='monitor', cert=rb)
    # 证书（无证书不执行）
    cert = M.pccc.emit(o, tau[:k], rb, M.consent, M.cfi.bound, M.nms.trace)
    if not cert.valid:
        return M.fallback.escalate(F0, reason='cert', cert=cert)
    M.dla.log(cert, counterfactual_min(tau, tau_alt))
    return tau[:k], cert
```

## 3. 推导

**引理 19（可靠下界即合规）** 设 A99：可达集过近似与区间算术均 sound，模型误差 W_t 有界且 L_ρ 为鲁棒度对状态扰动的 Lipschitz 常数。若 `ρ̲_φ(τ) = ρ_model(τ) − L_ρ W_t` 且 `ρ̲_φ ≥ η_φ`，则真实轨迹满足 φ 且裕量 ≥ η_φ。系：NMS 只会产生假阴性（过度保守），不产生假阳性；因此「合规」是可证的单边性质。

**引理 20（不可补偿性）** 对任意有限罚 M，标量化目标 `J_task + M·Σ max(0, η_φ−ρ_φ)` 总存在状态使最优解违反硬约束：取 J_task 沿某方向梯度 R > M·m（m 为该方向上 ρ_φ 的下降斜率），则最优解落在违反区。词典序/硬约束在可行集非空时违反数恒为 0。系：**「把伦理写成大惩罚项」在有限罚下必被 Goodhart**；不可补偿必须结构性保证，不能靠调参。

**引理 21（反事实不变性 ⇒ 有界差距与有界泄漏）** 若 `W_2(π(·|o),π(·|o')) ≤ δ_cf` 且下游结果对动作 L_out-Lipschitz，则两组结果分布 W_2 ≤ L_out·δ_cf；若 `I(z;τ|s_task) ≤ ε_leak`，则任何仅基于 τ 的 z-推断器优势 ≤ f(ε_leak)（Pinsker/Fano 界）。系：歧视与隐私可以被**策略级**约束，而不是靠单条轨迹事后审查。注意：界依赖估计器与审计对，估计误差须进证书（A100）。

**引理 22（规范不确定性的不可约部分）** 设 y 为任意 `g∈𝒜_world` 的世界观测。在 A101（世界观测不携带解释/效力/权限信息，除非观测对象本身是合法权威）下，`I(U_int; y | o,g)=0`；故对 U_int 的任何 VoI（R69 定义 298）期望增益为 0。更糟的是，把非权威回答当作权威，会引入**伪消解**：后验熵下降但错误率不降。系：U_int 只能经 𝒜_auth 或预防原则处理；`g∈𝒜_world` 对 U_int 的追问应被 CGE 拒绝。U_app 虽可约，但其取证许可本身是规范问题，故 VoI 必须被同意状态机约束——这是一个不动点，而不是两个独立步骤。

**定理 18（LEX 对 R69 的严格退化与许可收缩）** 当 N=∅ 且 U_norm=0 时，LEX 与 FLUID-RAS 逐指令相同。当 N≠∅ 时，`𝒯_feas(LEX) ⊆ 𝒯_feas(R69)`，且若证书 sound、可行集非空，则硬规范违反数=0（R69 仅约束期望物理风险，可 >0）。代价是 `J_task(LEX) ≥ J_task(R69)`，差额为合规税 ΔJ；等号在 N=∅。故：**R69 扩张能力，LEX 收缩许可；安全/合规侧永不更弱，效率侧明码标价**。

**定理 19（交互伦理上界）** 在 A102（同意状态机不可被系统自触发、拒绝代价模型与接地检查误差有界）下，CGE 采纳的信息动作满足：被迫披露概率 ≤ ε_consent，操纵导致的答案分布偏移 ≤ κ + ε_ground。系：把「问」变成「可拒绝、可撤回、非诱导、目的限定」的问，才允许进入 VoI 优化；否则 VoI 再高也不可采纳。

**定理 20（三类不确定性不可互相替代）** 若 U_int > τ_int 且无合法权威通道，则唯一可认证动作集 = F0∪F1（定义 322）；任何 `g∈𝒜_world`、任何增加采样/交互/LLM 自解释都不能产生有效 PCCC。系：这从制度上禁止「用提问洗白规范判断」，也解释了为什么 R69 的 MINT 必须被 CGE 与 NUT 包住，而不能直接接在规范问题上。

## 6. 本轮最大风险

**一句话**：LEX-RAS 的全部保证都建立在「规范被正确、完整、无偏地形式化」这一前提上——若 DSTL 规范漏掉一条义务、把某类人排除在「人」的定义之外、或被优化器在字面合规与实质合规之间钻了空子，那么系统会带着一份数学上可验证的证书去做一件伦理上错误的事，把 R69 的「被证实的错误」升级为「被证明合规的错误」；**证书越硬，错得越有说服力**。

**次级风险与缓解**：
1. **规范来源不合法/不完整**（谁写的规范？代表谁？）→ ν 绑定授权主体 + 多方规范来源 + E311 对抗性红队 + 可争辩改判；
2. **字面合规、实质违规**（规范博弈）→ 最小反事实「精神测试」+ DLA 争辩 + 对规范本身做变异测试；
3. **合规导致不可接受的性能/延迟**→ 快速路径 + 只认证短前缀 + 明码标价合规税 ΔJ，拒绝「零成本合规」叙事；
4. **估计器骗过 CFI/隐私界**→ critic 版本化 + 误差进证书 + 独立审计对 + E306 成员推断压力测试；
5. **规范冲突被优化器偷偷「权衡」**→ 定义 322 明令禁止最小违规解，冲突必须升级；E314 专测；
6. **失效开放**（拿不到证书仍执行）→ fail-closed + TTL/心跳 + E313 故障注入。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** LEX-RAS = (DTO, NMS, CGE, CFI, PCCC, NUT, DLA; RAS-WM††)；零学习写操作继承；不可补偿性（有限权重不得抵消硬规范违反）；无证书不执行（fail-closed）；规范不确定性隔离（U_int 只升级/预防）。

**定义 311–312（增广轨迹与 DSTL）** `τ=(x,g,ι)`，信息流 ι 区分「看/推断/使用/留存/删除」；规范编译为带裕度的 STL+过去算子片段，`ρ_φ ≥ 0 ⇔ 满足`；每条规范带层级 ℓ、裕量 η、版本 ν、授权主体 auth。示例：`G(use(pii) → ◇_{[0,T_c]} consent)`、`G(refusal → ◇_{[0,T_s]} stop)`。

**定义 313–314（词典序与可行集）** `V_ℓ=Σ max(0,η_φ−ρ_φ)`；词典序比较，J_task 仅作末层 tie-break；硬层（ℓ≤1）V=0。`𝒯_feas` 为空时输出 κ_inf 并退避，**禁止返回最小违规解**。

**定义 315（DTO）** `argmin J_task s.t. 动力学 + 物理安全 + DSTL + 同意状态机 + 反事实不变性`；光滑代理求梯度、可靠下界做认证，二者分离；流采样只作提议；只提交认证前缀 k_lex。

**定义 316–317（CGE / CFI）** 同意自动机 `U/Rq/Gr/Rf/Rv/Ex`，系统不得自置 Gr；可采纳性 = 目的限定 ∧ 最小化 ∧ 非强制（Δcost_refusal≤0）∧ 非欺骗 ∧ 授权正确；拒绝/撤回后 T_del 删除。CFI：策略级 `W_2` 不变性 ≤ δ_cf 且 `I(z;τ|s_task) ≤ ε_leak`。

**定义 318–319（NMS / NUT）** `ρ̲=ρ_model−L_ρW_t ≥ η_φ` 才认证；跌破即撤销、只收缩前缀。`U_norm=U_app+U_int`；`g∈𝒜_world` 对 U_int 的期望信息增益 = 0；`g∈𝒜_auth` 只作为有出处证据，不自动成为事实。

**定义 320–321（PCCC / DLA）** 证书绑定 `C_FLUID + ν + {ρ̲} + κ + δ_cf + ε_leak + 同意账本 + 留存策略 + 监控轨迹 + 退避 + 签名`，第三方可重放。只追加账本记录 duty/evidence/decision/ν/最小反事实/申辩；申辩必须按被争辩的 ν 重算。

**定义 322–324（退避 / 版本 / 合规税）** F0 停/保持（满足 ℓ≤1）→ F1 权威升级 → F2 预防原则取更严；冲突必须升级，禁止优化器自行权衡。行为绑定执行时 ν，不溯及既往。`J_comp(η)` 单调，合规税 ΔJ 必须与「零违规」声明一起报告。

**定义 325–326（对偶 / 失效安全）** 越权消解（用 𝒜_world 答 U_int）与以权压实（用权威压可纠正的 U_app）都入 AIC-LEX；PCCC 带 TTL/心跳，不可评估即失效 → F0，禁止先执行后补证。

## 3. 关键算法伪代码

```python
# IP-264 DTO：流策略提议 + 约束精修 + 可靠认证（提议永不等于合规）
class DeonticTrajectoryOptimizer:
    def optimize(self, o_t, budget):
        modes, best = self.flow.sample(o_t, K=4), None
        for tau0 in modes:
            tau = constrained_refine(tau0, self.vista, self.norms, iters=3)
            rb  = {p: sound_robustness_lower(tau, p, self.vista.error_bound())
                   for p in self.norms.hard}
            if any(rb[p] < self.norms.eta[p] for p in rb):        continue
            if not self.c_ras_wm.certify_prefix(tau, o_t):        continue
            j = self.vista.task_cost(tau)
            if best is None or j < best.j: best = (tau, rb, j)
        if best is None:
            return None, infeasibility_certificate(self.norms, o_t)  # κ_inf
        k = self.nms.certified_prefix_len(best.tau, o_t)
        return best.tau[:k], best.rb

# IP-266 NMS：只做减法，认证前缀从长到短收缩
def certified_prefix_len(tau, o_t):
    R = reachable_set(o_t, horizon=H)
    for k in range(len(tau), 0, -1):
        rb = {p: sound_robustness_lower(tau[:k], p, R) for p in hard_norms}
        if all(rb[p] >= eta[p] + L_rho * W for p in hard_norms):
            return k
    return 0

# IP-267 CGE：同意 + 非强制 + 非欺骗 + 最小化
def admissible_info_action(g, state, purpose):
    if not purpose_subset(g.purpose, state.granted_purpose): return False
    if not minimal(g) or refusal_cost_delta(g) > 0:         return False
    if leading_KL(g) > kappa or not grounded(g):            return False
    if state.s in (REFUSED, REVOKED, EXPIRED):              return False
    if state.vulnerable and not state.guardian_channel:     return False
    return True

# IP-270 NUT：规范不确定分诊（U_int 不进 VoI）
def split(o, norms):
    U_app = entropy(applicability_posterior(o, norms))      # 可取证，但取证受 CGE 约束
    U_int = entropy(interpretation_posterior(o, norms))     # 只能权威/预防
    return U_app, U_int

# IP-274 LEX 主闭环
def LEX_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    U_app, U_int = M.nut.split(o, M.norms)
    if U_int > TAU_INT:                                    # 规范不确定 → 不采样、不追问
        return M.fallback.escalate(F1, reason='U_int', cert=M.pccc.stub(o))
    g = M.mint.choose_interaction(                         # 只在可采纳信息动作里算 VoI
            modes, o, M.budget,
            filter=lambda g: M.cge.admissible(g, M.consent, M.purpose))
    if g is not None:
        U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    tau, rb = M.dto.optimize(o, M.budget)                  # 不可行 → None + κ_inf
    if tau is None:
        return M.fallback.escalate(F0, reason='infeasible', cert=rb)
    k = M.nms.certified_prefix_len(tau, o)                 # 运行期只收缩
    if k == 0:
        return M.fallback.escalate(F0, reason='monitor', cert=rb)
    cert = M.pccc.emit(o, tau[:k], rb, M.consent, M.cfi.bound, M.nms.trace)
    if not cert.valid:                                     # fail-closed
        return M.fallback.escalate(F0, reason='cert', cert=cert)
    M.dla.log(cert, counterfactual_min(tau, tau_alt))
    return tau[:k], cert
```

## 4. 推导

**引理 19（可靠下界即合规）** A99：可达集过近似与区间算术 sound、模型误差 W_t 有界、鲁棒度 L_ρ-Lipschitz。若 `ρ̲_φ = ρ_model − L_ρW_t ≥ η_φ`，则真实轨迹满足 φ 且裕量 ≥ η_φ。系：NMS 只有假阴性、无假阳性；合规是单边可证性质。

**引理 20（不可补偿性）** 对任意有限罚 M，`J_task + M·Σmax(0,η_φ−ρ_φ)` 总存在状态使最优解违反：取任务梯度 R > M·m（m 为约束下降斜率）即可。硬约束/词典序在可行集非空时违反数恒为 0。系：伦理写成有限大惩罚项必被 Goodhart，必须结构性保证。

**引理 21（反事实不变性 ⇒ 有界差距/泄漏）** `W_2(π(·|o),π(·|o'))≤δ_cf` 且下游 L_out-Lipschitz ⇒ 结果差距 ≤ L_outδ_cf；`I(z;τ|s_task)≤ε_leak` ⇒ 任意仅基于 τ 的 z-推断器优势 ≤ f(ε_leak)（Pinsker/Fano）。系：歧视/隐私可在策略级约束，但估计误差必须进证书（A100）。

**引理 22（规范不确定性不可约部分）** 对 `g∈𝒜_world` 的世界观测 y，在 A101 下 `I(U_int;y|o,g)=0`，故 VoI 增益为 0；把非权威回答当权威会产生「伪消解」：熵降而错误率不降。系：U_int 只能经 𝒜_auth 或预防原则；U_app 的取证许可本身受 CGE 约束，形成不动点。

**定理 18（严格退化与许可收缩）** N=∅ 且 U_norm=0 时 LEX ≡ FLUID-RAS（逐指令）。N≠∅ 时 `𝒯_feas(LEX) ⊆ 𝒯_feas(R69)`；证书 sound 且可行时硬规范违反 = 0；`J_task(LEX) ≥ J_task(R69)`，差额为合规税 ΔJ，N=∅ 时取等。故 R69 扩张能力、LEX 收缩许可，安全/合规永不更弱。

**定理 19（交互伦理上界）** A102 下（状态机不可自触发、拒绝代价模型与接地检查误差有界），CGE 采纳的信息动作满足：被迫披露 ≤ ε_consent，操纵导致答案分布偏移 ≤ κ+ε_ground。系：VoI 再高，不可采纳的信息动作也不进入优化。

**定理 20（三类不确定性不可互替）** 若 U_int>τ_int 且无 𝒜_auth，则可认证动作集 = F0∪F1；任何 𝒜_world 追问、额外采样、LLM 自解释都不能产生有效 PCCC。系：从制度上禁止用提问洗白规范判断，MINT 必须被 CGE 与 NUT 包住。

## 7. 本轮最大风险

**一句话**：LEX-RAS 的全部保证都建立在「规范被正确、完整、无偏地形式化」这一前提上——若 DSTL 规范漏掉一条义务、把某类人排除在「人」的定义之外、或被优化器在字面合规与实质合规之间钻了空子，那么系统会带着一份数学上可验证的证书去做一件伦理上错误的事，把 R69 的「被证实的错误」升级为「被证明合规的错误」；**证书越硬，错得越有说服力**。

**次级风险与缓解**：规范来源不合法/不完整（ν 绑定授权主体 + 多方来源 + E311 红队 + 可争辩改判）；字面合规实质违规（最小反事实精神测试 + 对规范做变异测试）；合规税不可接受（快速路径 + 短前缀 + 明码标价 ΔJ）；估计器骗过 CFI/隐私界（critic 版本化 + 误差进证书 + 独立审计对 + E306）；规范冲突被偷偷权衡（定义 322 禁止最小违规解，冲突必须升级，E314 专测）；失效开放（fail-closed + TTL/心跳 + E313 故障注入）。
