# 第 58 轮（承接第 57 轮「少样本元推断×跨模态对账×个性化有界信任」IP-133~138；灵感循环第 1 轮；本轮灵感：「移动底盘」×「开源软件」）

> 第 57 轮把安全的赌注从"模型置信"一路押到"证据质量"，再用元先验摊销、共形保底、跨模态对账与单向信任机层层兜住；它自陈的最大风险是"坏先验普遍"——元模型在语料盲区之外自信地错。但第 57 轮仍默认了两件从未被正面检验的事：**(i) 机器人的物理底座是静态、透明、与证书无关的**——底盘只是"载着传感器到处走"，载荷、重心、胎面磨损、悬架、电池与地面附着不进入证书；**(ii) 被认证的东西等于被部署的东西**——安全证书是对某个软件/模型快照的一次性证明，而真实机器人靠第三方库、驱动、学习模型与持续更新活着，认证的是快照，部署的是流动的依赖树。**移动底盘**让物理前提变成一个会退化、会被载荷改写、会打滑的活变量；**开源软件**让部署栈变成一个带出处、可复现、可撤销、可分叉回滚的供应链。二者合流，本轮把命题从"部署时证明安全"推进为 **"全生命周期可维护的安全"**：**底盘为物理之根、可复现出处为软件之根，安全证书必须像开源制品一样可审计、可复现、可撤销、可分叉回滚——证书不是一次判决，而是一份需要持续维护的活契约。** 核心命题：**"物理前提可门控、软件出处可复现、失效可撤销、维护可规划的活证书说可信"**。

核心矛盾：
- **H29（物理前提漂移 vs 一次性证书）**：每张证书都隐含"载荷≤m、重心≤c、胎损≤w、温度≤T、附着≥μ"等前提，但底盘状态每天都在漂移；没有机制把证书效力绑回物理底座，证书就会在底座已经退化后继续以"仍然有效"的名义放行。安全证书没有物理保质期，是比坏先验更隐蔽的普遍风险。
- **H30（依赖漂移 vs 认证快照）**：机器人行为是自有代码、第三方库、模型权重、训练数据与构建工具的共同产物；一次传递依赖更新可以在不改动"我们的代码"的情况下改变行为。认证对象是快照，部署对象是流动的树——"认证过"与"正在运行"之间没有可复现的等式。
- **H31（开源治理悖论 vs 维护债务）**：开放带来可审计性与可分叉性，也带来维护者接管、依赖混淆、废弃包与"many eyes 其实没人看"的责任稀释；分叉是安全阀，但分叉会失去补丁；更根本的是，若证书过期/撤销的速度超过组织复验能力，"活证书"就会退化为"批量续签"的橡皮章——维护债务把技术安全重新变回制度表演。

## 0. 直觉与动机

**灵感 1（移动底盘 → 物理根信任与证书的物理保质期）**
直觉：底盘是机器人的地基。地基沉降了，图纸再漂亮也不能住人。移动底盘的载荷、重心高度与偏移、悬架行程、胎面磨损、电池 SOC、电机温度、地面附着，决定了上一轮所有"位置裕度/接触等级/探针结论"是否还成立。于是每张证书都应像食品一样带**前提域与保质期**：只在底盘状态落在 D_J 内、且健康度高于 h_min 时有效；越域不是"再确认一下"，而是**立即降级到保守包络**。物理新鲜度 φ_c 与剩余寿命 τ_J 成为与置信度并列的一等量。**先看地基，再信图纸。**

**灵感 2（移动底盘 → 牵引-稳定包络与滑移对账）**
直觉：轮式底盘最诚实的证据来自地面：不打滑、不侧翻、不超载。轮速里程计与 IMU/视觉的外部位移在打滑时会分歧——这和第 57 轮的跨模态分歧同构：**打滑不是普通噪声，而是地面在投反对票**。把滑移做成一个只可否决的模态：分歧大 ⇒ 附着按保守下界重算 ⇒ 速度、加速度、载荷上界一起收缩；牵引回执可以喊停，但不能单独放行。移动底盘的安全不是一个速度值，而是一个由附着、坡道、重心与载荷共同围成的**动态包络**。

**灵感 3（开源软件 → 出处物料清单与可复现构建）**
直觉：开源最值得偷的不是代码，而是**可信的问责结构**：每个制品能回答"你从哪来、谁改的、怎么构建、依赖了什么、有没有已知漏洞"。把这套结构搬进安全证书：PBOM 记录仓库/提交/构建配方/二进制与权重哈希/数据血缘/许可证/维护者/漏洞状态；可复现构建 R(c) 保证"重建即同一物"；行为指纹 B(c;𝒞) 在一组固定 canary 场景上保证"同一物即同一行为"。**证书若不能复现，就只是声明。**

**灵感 4（开源软件 → 供应链信任门与可分叉回滚）**
直觉：开源不等于免检，而是把检查从"厂商盖章"改成"出处、复核、复现、影子验证、撤销"五件事。维护者与包也有类似第 57 轮操作者的信任状态：事故与密钥异常实时降级，升级要攒独立复核与无漏洞记录且有界速率。更新先隔离、再影子运行、行为等价才接管；回滚与可信分叉不是失败，而是**安全动作**。**分叉是安全阀，不是免责声明。**

**灵感 5（两灵感合流 → 活证书、出处-裕度交换与维护感知规划）**
直觉：物理退化与出处风险是同一个"有效安全因子"的两项扣减。出处越可疑、底盘越不健康、地面越不确定，就必须用越保守的操作来补偿：降速、降载、降加速度、加裕度、缩短证书寿命——**想怎么开，先证明维护到了什么程度**。探-诺-演也从"探不探/走不走"扩展为"探、走、维护、回滚、重证"的联合规划：维护本身是安全动作，安全债务要显式计价。所有新机制仍然只经三个安全通道起作用：**信念更宽、动作更慢更软、失效更早更保守**。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（底盘根信任与物理前提 CRC）** 底盘状态 s_c=(m_p,c_g,h_s,w_t,soc,T_m,μ̂,κ_slip)∈S_c（载荷、重心偏移、悬架行程、胎面磨损、SOC、电机温度、附着估计、滑移史），健康度 h_c(s_c)∈[0,1] 对磨损/偏移单调不增。每个证书 J 携带物理前提域 D_J⊆S_c 与谓词 Pre_J（m_p≤m_max、|c_g|≤c_max、h_c≥h_min、T_m≤T_max 等）。物理新鲜度 φ_c=min_i(1−dist_i(s_c,D_J)/scale_i)_+；剩余寿命 τ_J=min_i(margin_i/rate_i)。规则：Pre_J(s_c)=0 或 φ_c<φ_min ⇒ 证书降级，承诺只能在保守包络 E_cons 内继续；越域绝不静默续期。状态估计用 set-membership 给出 Ŝ_c（真值∈Ŝ_c）；关键量不可观测时取最坏界，不允许用点估计冒充事实。

**定义 140（牵引–稳定包络 TBE）** 地面参数 g=(μ,slope,roughness)，轮地约束 F_t≤μN(load)；侧翻裕度由静态稳定因子 SSF 与重心高度给出。动态包络 E_tbe(s_c,g)={(v,a,m_p): traction_util≤1−η_μ ∧ rollover_margin≥η_r ∧ m_p≤m_max(h_c)}。滑移对账 D_slip=|v_odo−v_ext|/v_scale+|ω_odo−ω_imu|/ω_scale，滑移作为模态 m_slip（可靠性 ρ_slip）。三规则：(T1) D_slip>θ_slip ⇒ 用 μ_low=μ̂−kσ_μ 重算包络（不确定性下限）；(T2) 牵引回执 EV-traction 只可否决、不可单独放行（地面回执可证伪）；(T3) 底盘模块间佐证（轮/悬架/驱动）必须现场检验独立性，共享同一力路或同一减速器时不得互证。

**定义 141（出处物料清单 PBOM）** 对部署树 T 的每个组件 c，pbom(c)=(repo,commit,build_recipe,hash,weights_hash,data_lineage,license,maintainers,cve_status)。可复现性 R(c)=1[hermetic_rebuild(c)=hash(c)]。行为指纹 B(c;𝒞)=σ_c(𝒞)（固定 canary 场景集 𝒞 上的输出分布）。行为等价 c≡_ε c′ ⇔ TV(B(c;𝒞),B(c′;𝒞))≤ε_b ∧ R(c)=R(c′)=1。若部署树 T 与认证树 T\* 的每个差异节点都满足 c≡_ε c\*，称**认证可继承**；否则必须重认证，或把操作包络收缩到与出处风险相称的保守域。

**定义 142（依赖信任门 DTG）** 维护者/包信任状态 s_d=(rep_d,inc_d,key_d)（复核记录、事故史、密钥连续性），单向有界：事故、密钥异常、废弃/接管信号实时降级；升级需独立复核 n_rev≥k_rev ∧ 无未决 CVE ∧ 影子行为等价 ∧ 速率≤Δ_d/T。更新准入 gate(u)=签名出处 ∧ 独立复核 ∧ 可复现构建 ∧ 影子行为等价 ∧ CVE 清零 ∧ 维护者信任 ∧ 非依赖混淆/非废弃包；任一失败 ⇒ 更新进隔离区，绝不静默替换部署树。回滚 rollback(T,T_cert) 与可信分叉 trusted_fork(T) 均视为安全动作，但都必须重新过 gate。

**定义 143（活证书 LAC 与出处–裕度交换）** 活证书 J^live=(J_core,D_J,pbom(T),R(T),B(T;𝒞),issuer,t_issue,T_exp,revocation_feed,maintenance_contract)。有效谓词 Valid(J^live,s_c,t)=Pre_J(s_c) ∧ t<T_exp ∧ (∀c∈T: ¬revoked(c,t) ∧ cve(c,t)=∅) ∧ B(T;𝒞)≡_ε B\*(T\*;𝒞) ∧ maintenance_contract.satisfied。撤销传播：advisory 命中任一组件 ⇒ 证书立即 suspended，直到重验证（重探/重建/回滚）完成或操作包络收缩到 E_cons。安全债务 debt(J)=P(失效)·renewal_cost+downtime_risk，显式进入规划代价。**出处–裕度交换律**：有效安全因子 SF_eff(π)=SF_0·exp(α·P_prov(T)+β·(1−h_c(s_c))+γ·U_terrain(g))，其中 P_prov 为出处风险（未复现/未复核/CVE/维护者异常）。包络随 SF_eff 单调收缩：P_prov↑、h_c↓、U_terrain↑ ⇒ v_max↓、m_p,max↓、a_max↓、刚度/速度裕度↓。逆式给出"想以 (v,m_p) 运行，必须把出处风险压到 P_prov^max、把底盘健康维持在 h_c^min"。

**定义 144（维护感知探-诺-演 PCE+++）** 每个检查点：①元推断与物理门控（第 57 轮 MFSL + 本轮 CRC/TBE）；②出处门控（Valid(J^live) 与 DTG）；③若证书失效：从维护动作集 A_m={recalibrate,swap_module,rollback,rebuild,re-certify,fork} 中选 argmax[VOM(a)−cost(a)−λ·debt]，预算不允许则安全停/请求服务；④若有效：在 E_tbe∩E(SF_eff) 内做探询与对账，承诺 ⇔ 证据门过 ∧ 包络内 ∧ Valid；否则绕行→降档→维护→L2 协商或安全停。总预算 E_total=E_motion+E_probe+E_maint、T_total 同理；终止于 k_probes+k_cons+k_maint。

## 2. 关键算法伪代码（完整版见产物区）

```python
def chassis_gate(s_c, J, t):                       # IP-139/143
    if not Pre_J(s_c) or t >= J.T_exp or not cert_chain_valid(J, t):
        return downgrade(J, envelope=E_cons)        # 只向保守失效
    return J

def provenance_gate(u, T, maint):                  # IP-141/142
    if not (signed(u) and review_ok(u, k_rev) and reproduce(u)
            and shadow_equiv(u, T) and cve_clear(u)
            and maintainer_trust_ok(u) and not dependency_confusion(u)):
        return quarantine(u), T                    # 更新隔离，不静默替换
    return admit(u, T)

def live_envelope(s_c, T, g, SF0):                 # IP-140/143
    SF = SF0 * exp(alpha*prov_risk(T) + beta*(1-chassis_health(s_c))
                   + gamma*terrain_uncertainty(g))
    return traction_balance_envelope(s_c, g) & shrink_by(SF)

def commit_or_maintain(cp, s_c, T, budget):        # IP-144
    if not live_certificate_valid(active_J, s_c, t_now):
        a = argmax(maintenance_actions(cp), key=lambda m: VOM(m)-cost(m)-lam*debt(active_J))
        return execute_maintenance(a) if budget.can(a) else safe_stop(cp)
    E = live_envelope(s_c, T, terrain(cp), SF0)
    return probe_and_commit_if(admissible(cp, E) and evidence_gate(cp))
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |

## 6. 本轮最大风险

**一句话**：本轮把安全从"一次性证明"变成"终身可维护的供应链"，最大风险是**维护债务不可持续**——当证书过期/撤销/底盘退化的速度超过组织的复验与维护能力时，人会以"批量续签"把活证书重新变成橡皮章；必须让证书默认失效方向是降级与停、维护动作本身也进入可审计的信任状态机，并且证书寿命只能由可兑现的维护预算签发，绝不能由期望签发。

### IP-140 TBE（牵引-稳定包络与滑移对账）

```python
def traction_balance_envelope(s_c, g):
    mu_low = max(mu_min, mu_hat(s_c, g) - k_sigma * sigma_mu(s_c, g))
    N = normal_load(s_c, g.slope)                  # 载荷/重心/坡度决定法向力
    return Envelope(
        v_max = v_limit(mu_low, g.slope, s_c),
        a_max = a_limit(mu_low, s_c.c_g, g.roughness),
        payload_max = payload_capacity(s_c.h_c, g.slope),
        rollover_margin = SSF(s_c.c_g, s_c.h_s) - required_margin(g),
        traction_util = Ft(s_c, g) / (mu_low * N + eps))

def slip_reconcile(M, r, obs):
    D = abs(obs.v_odo - obs.v_ext)/v_scale + abs(obs.w_odo - obs.w_imu)/w_scale
    if D > theta_slip:                             # T1: 分歧即不确定性下限
        M.mu[r] = mu_low(M.mu[r], k_sigma); M.rho['slip'] = max(rho_min, M.rho['slip']*gamma_slip)
    ev = 'EV-traction' if D <= theta_veto else None # T2: 只可否决/停，不可放行
    return M, D, ev

def admissible(cp, E, SF):
    return (E.traction_util <= 1 - eta_mu*SF and
            E.rollover_margin >= eta_r*SF and
            E.payload_max >= payload(cp) and
            E.v_max >= v(cp) and E.a_max >= a(cp))
```

            and all((not revoked(c, adv, t)) and cve_clear(c, adv) for c in J.T)

            + w3*frac_cve_open(T) + w4*maint.anomaly_score)

def provenance_margin_exchange(s_c, T, g, SF0):

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CRC | O(d_s)/检查点；估计 O(\|Ŝ_c\|) | O(\|S_c\|) | 真值∈Ŝ_c、不可观测取最坏界（A41） |
| TBE | O(\|contact\|)/基元 | O(\|V\|) | 附着下界保守、滑移只证伪（A42） |
| PBOM | O(\|T\|) 校验；重建 O(build) | O(\|T\|) | hermetic 构建、清单完整（A43） |
| DTG | O(\|reviewer\|+shadow) | O(\|packages\|) | 复核独立、隔离完备、单向有界（A44） |
| LAC | O(\|T\|)+O(advisory) | O(\|T\|) | 撤销传播即时、指纹有界（A43/A44） |
| MCE | O(\|CP\|·(k_p+k_cons+k_maint)·(C_VOI+C_maint)+\|T\|) | O(\|V\|+\|σ\|+\|T\|) | 维护动作有限、四态+维护态完备 |

**正确性定理（Living Assurance Soundness, LAS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 底盘状态 set-membership 估计健全：真实 s_c∈Ŝ_c，或关键量不可观测时以最坏值进入判定；**(A42)** 牵引/侧翻模型对真实地面保守，滑移/牵引证据只具备否决权；**(A43)** PBOM 完整且 hermetic 构建诚实，行为指纹覆盖声明的 canary 分布且等价误差 ≤ε_b；**(A44)** DTG 的复核相互独立、撤销与漏洞源及时、维护契约可兑现，回滚/分叉必须重新过门。则：

1. **活证书健全性**：Valid(J^live,s_c,t) ⇒ 物理前提 Pre_J(s_c)、出处无撤销/漏洞、行为与认证树 ε_b-等价、维护契约成立；单检查点承诺失效率
   `P(fail) ≤ δ_f + ε_meta(k) + δ_probe + ε_h + P(s_c∉Ŝ_c) + P(出处漏检) + P(行为漂移越指纹) + P(撤销源过期)`。
2. **单调性**：底盘退化（h_c↓）、出处风险（P_prov↑）、地形不确定度（U_terrain↑）只能使包络收缩、裕度增加、维护提前、证书寿命缩短；不存在"越不确定越激进"的通道。滑移证据只否决不推荐放行，牵引回执不能替代证据门。
3. **维护即保守转移**：重标定、换模块、回滚、重建、重证、分叉都是状态转移而非"续期魔法"；每次转移必须重新过 DTG/LAC，且动作本身计入审计。证书寿命只能由可兑现的维护预算签发。
4. **终止性与部署界**：维护动作有限，PCE+++ 在 k_probes+k_cons+k_maint 内终止于 {承诺,绕行,维护,协商,安全停}；对检查点取联合界：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf
                  + P(s_c∉Ŝ_c) + P(prov_miss) + P(behav_drift))
             − P(撤销源过期) − P(维护契约失效) − P(护盾回退失败)
```

关键：**物理根信任给"何时还能信"，出处供应链给"凭什么还能信"，活证书给"什么时候必须停"**；移动底盘把不确定性变成可测量的包络，开源治理把信任变成可复现、可撤销、可回滚的证据链。二者都只经"信念更宽 / 动作更慢 / 失效更早"三个安全通道起作用。

## 6. 本轮最大风险

**一句话**：本轮把安全从"一次性证明"变成"终身可维护的供应链"，最大风险是**维护债务不可持续**——当证书过期/撤销/底盘退化的速度超过组织的复验与维护能力时，人会以"批量续签"把活证书重新变成橡皮章；必须让证书默认失效方向是降级与停、维护动作本身也进入可审计的信任状态机，并且证书寿命只能由可兑现的维护预算签发，绝不能由期望签发。
