# 第 2 轮 · UniBot-SERVO（UniBot 线；承接第 1 轮 UniBot-SAGE；本轮灵感：「关节驱动」×「关节空间控制」）

> **承接声明**：本轮不推倒 SAGE。SAGE 第 1 轮的最大风险是"抓握隐变量只有间接标签、在泛化场景最不可信"（上一轮 §7），且 §8 已明确下一轮要把 IP-02 升级为"含滑移检测的时序状态机"、把 IP-06 与 IP-01 对齐。本轮用「关节驱动」给出的物理量——**指令关节角与实际关节角之差（伺服残差）**——把"抓住没有 / 撞上没有 / 卡住没有 / 到位没有"从**学习出来的隐变量**降级为**可直接测量的物理信号**。编号续：定义 U13–U24、引理 L8–L14、实验 E619–E636、创新点 IP-09–IP-15。

## 0. 一句话直觉

在 joint 控制空间里，策略输出的不是"运动"，而是"给底层伺服环的参考"；参考与实现之差 `e = q_实际 − a_指令` 是接口里唯一免费、稠密、无需标注的力/接触信号。本轮把这条信号做成贯穿感知、规划、执行、评估的**物理总线**。

## 1. 灵感的第一性原理

### 1.1 「关节驱动」：action 是参考，不是运动

- **直觉**：人抬手时，肌肉发出的是"驱动"，手实际到哪由负载、摩擦、限位共同决定。机器人同理：我们发 `action.left_arm`（关节目标），底层 PD/阻抗控制器把它变成实际关节角 `observation.state.left_arm`，中间隔着一个**未知的、带延迟和限幅的伺服环**。
- **严谨**：把底层视为未知动力系统 `q_{t+1} = S(q_t, a_t, τ_ext, θ_servo)`。我们只能看到 `(a_t, q_{t+1})`，看不到外力 `τ_ext` 与伺服参数 `θ_servo`；但 `e_t = q_{t+1} − a_t` 是二者的可观测量。⇒ 接触与饱和不是"不可测"，而是"藏在残差里"。
- **关键升级**：上一轮 `g_t`（抓握）是从视觉+几何**推断**的，有分布漂移；本轮 `e_t` 是**测量**的，只有噪声与对齐误差。这是对 SAGE 最大风险的正面拆解。

### 1.2 「关节空间控制」：坐标系选择本身就是信息

- **直觉**：EE 空间只告诉你"手在哪"；joint 空间还告诉你"每个关节离限位多远、速度多大、是否接近奇异"。插入任务常常死在"手到了，但某个关节已经拧到极限或接近奇异"，这在 EE 观测里不可见，在 joint 观测里直接可读。
- **严谨**：joint 空间暴露 (i) 逐关节限位裕度 `m_j = min(q_j−q_min, q_max−q_j)`；(ii) 冗余零空间 `N(J)`；(iii) 逐关节残差（哪一关节被卡住）。EE 空间把这些都投影掉了。⇒ 选 joint 不只是"控制方式"，而是**为了可观测性**。
- **推论**：即便最终要 EE 精度，也应"joint 执行 + EE 校验"（FK 把 joint 映到 EE），而不是"EE 执行 + 放弃关节可观测性"。这为 SAGE 的 IP-07 双空间提供了新论据。

### 1.3 合成：一条残差总线，四个消费者

`e_t` 经自由空间基线 `e^0` 分解为接触残差 `ρ_t = e_t − e^0_t`，同时喂给：

1. **抓握/滑移**（IP-09/10）：物体重量 → 特征残差；掉落 → 残差突变；
2. **接触/插入**（IP-10）：被挡 → 残差指向运动反方向；用其方向做合规搜索；
3. **可行性**（IP-11）：残差里的"饱和成分"说明指令本身不可行 → 先投影到可行域，让残差只反映外部世界；
4. **归因/路由**（IP-14）：残差签名 = 免费失败标签，替代/补强 VLM 六因子，并作为 IP-01 专家路由的输入。

外加 **NSP（IP-13）** 用零空间把关节推离限位/奇异，从源头减少"不可行指令"；**RCC（IP-12）** 用残差而不是预测相位来决定 chunk 长度；**RAA（IP-15）** 把残差当作稠密自监督标签。

## 3. 研究问题（Q6–Q10）

- **Q6（对齐）**：评测端的 chunk 执行/插值/观测延迟，使 `(a_t, q_{t+1})` 的对齐未知。如何估计并补偿？在什么对齐置信度下残差才可用？
- **Q7（自由空间基线）**：能否从官方数据学出 `e^0(q, \dot a)`，使接触残差 `ρ` 的假阳率可控？OOD 下基线漂移多大？
- **Q8（接触即力）**：`ρ` 的方向/幅值能否作为接触法向与法向力的单调代理，支撑插入搜索与滑移检测？
- **Q9（可行投影）**：把 chunk 投影到关节位置/速度/加速度/加加速度可行域，能否在不降成功率的前提下降低饱和与 jerk、并让残差更可解释？
- **Q10（零空间）**：用冗余零空间整形（远离限位/奇异）能否提升插入类任务，且一阶不改变 EE 意图？

## 4. 设计原则（续 P1–P6，新增 P7–P10）

- **P7 可测量优先于可推断**：能用物理测量替代学习隐变量的地方，优先测量；推断只用于测量不可及处。
- **P8 先对齐，后解释**：任何依赖 `(a,q)` 对齐的模块，必须先通过 E619；未通过则自动降级，绝不"带病上线"。
- **P9 可行性先于优化**：先把动作投影到可行域，再谈缝合/平滑/自适应；不可行指令下的一切优化都是给底层控制器添乱。
- **P10 残差门控的保守主义**：残差大时只做"减小动作/搜索/停止"，不做"加大动作/外推/激进重抓"。

## 5. 系统架构（SAGE 三层 + 一条物理总线）

SAGE：接地层 → 技能层 → 适应层 → 工程层。SERVO 在工程层与接地层之间插入 **Servo Bus（物理信号总线）**：

- **观测侧**：`(a_{t-1}, q_t)` → 对齐器 → `e_t` → 自由空间模型 → `ρ_t` → 驱动状态 `s^act_t`。
- **执行侧**：策略 chunk → NSP 零空间整形 → KFP 可行投影 → RCC 残差门控 → 发送。
- **反馈侧**：`s^act_t` → 抓握状态机 / 接触搜索 / 失败归因 / 专家路由。

**顺序为什么是 NSP → KFP**：NSP 可能把关节推向限位，KFP 最后兜底保证可行；两者都记录"是否被修改"进入审计。**为什么 KFP 必须在 CfR 之前**：先让指令本身可行，底层不再静默限幅，残差才只含外部接触，接触检测才可校准（见 L9）。

## 6. 预期贡献（可验收）

1. 提出"伺服残差即力传感器"的接口级观测，给出无触觉/无力矩下的接触与滑移检测口径。
2. 给出 joint 空间的"可观测性论证"：为什么 joint 比 ee 更适合做失败诊断。
3. KFP：一个实时可行投影，使动作"良构"并对齐官方可信度口径。
4. 残差归因：把六因子从 VLM 标注变成物理签名，降低代理评测成本。
5. 与 SAGE 完全兼容的增量路线（不推倒），并给出严格降级链。

## 7. 本轮最大风险（一句话）

**本轮最大风险是"指令-执行对齐"未知：若评测端的 chunk 执行/插值/观测延迟使 `q_t` 与 `a_{t-1}` 不可对齐，伺服残差会退化为噪声，接触检测、残差门控、残差归因会同时失效；因此必须先复刻官方 client 测出对齐延迟与噪声底，未通过则默认关闭 CfR，只保留不依赖对齐的 KFP 与 NSP。**

## 2. 创新点详述

### IP-09 · ServoBus / ASE 伺服残差与驱动状态估计（P0）

- **动机**：接口无力/触觉，但 `(a,q)` 之差是外力与伺服状态的投影。SAGE 的 `g_t` 依赖视觉间接标签；`e_t` 是直接测量。
- **与现有方案的差异**：不是再训一个隐变量，而是先做**物理分解**：`e = e^0(q,\dot a) + ρ + ε`。`e^0` 从官方数据"自由空间段"回归（无接触），`ρ` 是接触残差，`ε` 是模型/量化误差。视觉只用来分段与交叉验证，不承担主判据。
- **技术可行性**：高。只需对齐 `(a_{t-1}, q_t)`；速度用差分；自由空间基线用线性 ARX 或 2 层 MLP 即可。
- **落地步骤**：① E619 对齐；② 用腕部视觉+夹爪+残差自洽挑"自由空间段"；③ 拟合 `e^0`；④ 标定 `ε` 分布与阈值 `τ_c`；⑤ 输出 `s^act` 并接入 SAGE 的抓握状态机。
- **风险**：对齐误差（见 L13）；自由空间基线 OOD 漂移；观测降采样/量化。**缓解**：按关节速度自适应收紧/关闭 CfR；每 episode 用前段重标定。

### IP-10 · CfR 接触残差驱动的插入搜索与滑移检测（P0）

- **动机**：插入/旋转类最差（teaser 榜 Plug In Ethernet 17.7 / Unlock 20.1 / Open Pill Bottle 22.7），失败在"对齐/插入"；无力传感器时，接触只能从残差读。
- **与现有方案的差异**：把 `ρ` 当作力代理，而不是再训接触分类器；方向 `n = −ρ/||ρ||`（残差指向运动反方向）给出接触法向；在 `n` 的切平面做小幅合规搜索，沿 `−n` 轻推。
- **落地步骤**：① 接触检测 `c_t = 1[||ρ|| > τ_c]`；② 法向估计；③ 合规搜索（螺旋/抖动，步长与次数上限）；④ 滑移：夹爪闭合且负载特征残差突变 → 报警；⑤ 与 SAGE IP-02 状态机合并为"抓握/接触"统一状态机。
- **风险**：残差含摩擦/重力/惯量；多接触下法向多义；误触发会打断正常插入。**缓解**：高阈值 + 最大搜索步数 + 多信号交叉（夹爪、EE 速度、视觉接触）。

### IP-11 · KFP 关节运动学可行投影（P0）

- **动机**：策略可能输出超限/超速/超加速度的关节目标，底层静默限幅 → 实际运动 ≠ 意图，且残差被"饱和成分"污染（见 L9）。
- **与现有方案的差异**：不是事后平滑，而是**事前投影到可行域** `F`，最小加权改动。使"发出的动作"本身良构，对齐官方"动作良构、无异常离群"的可信度口径。
- **算法**：`min_{A'} ||A'−A||_W² s.t. q_min≤a≤q_max, |Δa|≤v_maxΔt, |Δ²a|≤a_maxΔt², |Δ³a|≤j_maxΔt³`。用 Dykstra/ADMM 迭代投影或三对角 QP；`T≤16`、DoF≤14，实时可行。
- **落地步骤**：① 从官方数据估 `v_max/a_max/j_max` 的分位数（不是拍脑袋）；② 实现投影；③ 与不投影做 A/B；④ 记录"被修改比例"进入审计。
- **风险**：限幅过紧 → 策略被"阉割"；QP 延迟。**缓解**：用数据分位数而非硬规格；批量/早停；默认只在超限时激活。

### IP-12 · RCC 残差门控分块与缝合（P0）

- **动机**：SAGE 用相位预测 chunk 长度；相位可能错，残差是**测量**。
- **与现有方案的差异**：残差稳定 → 长块（8–16）；残差上升 → 立即截断、短块（1–2）、**禁止外推缝合**（P10）。把"缝合"从无条件变"仅自由空间启用"。
- **落地步骤**：① 定义稳定性（滑动方差 + 阈值滞回）；② 接入 chunk 调度；③ 接触时清空缝合残差，改为重规划。
- **风险**：短块增调用；残差噪声导致频繁切换。**缓解**：滞回 + 最小驻留 + 调用次数上限（L11）。

### IP-13 · NSP 冗余零空间姿态整形（P1）

- **动机**：插入失败常因接近奇异（小 EE 修正需大关节速度）或关节到限位。
- **与现有方案的差异**：不用 WBT 学姿态先验，直接用运动学零空间：`δq = α P_N ∇h`，`h = 可操作度 − λ_l·限位惩罚 − λ_c·自碰撞惩罚`，`P_N = I − J⁺J`。
- **落地步骤**：① 标定 G1 FK/URDF（E631）；② 实现 `h` 与零空间投影；③ trust-region 限幅；④ 真机验证 EE 偏差与抖动。
- **风险**：FK/URDF 不准；底层也可能做零空间，叠加；大步会二阶改变 EE。**缓解**：小 `α`、EE 偏差断言、默认可关。

### IP-14 · RFA 残差失败归因（P1）

- **动机**：SAGE IP-06 的六因子靠 VLM 标注，贵且有噪；残差签名是免费的。
- **与现有方案的差异**：给出物理签名——reach 失败（早段无位移+残差小）、grasp 失败（闭合后负载残差缺失）、transport 碰撞（残差尖峰）、align 失败（残差振荡）、insert 失败（推而残差高）、release 失败（松爪后残差仍高=粘住）。规则 + 轻分类器；VLM 只做抽检。
- **落地步骤**：① 在官方数据上打残差签名；② 与 VLM/人工因子标注对齐（E627）；③ 输出因子向量喂给 IP-01 专家路由与 IP-06 代理评测。
- **风险**：签名非唯一。**缓解**：多信号交叉 + 一致率门槛。

### IP-15 · RAA 残差辅助自监督目标（P2）

- **动机**：残差是稠密标签（每步都有），远多于终态成功标签。
- **与现有方案的差异**：辅助头预测 `e^0` 与接触 `c_t`，从视觉+本体回归；测试时可**提前**预判接触。
- **落地步骤**：① 冻结主干加辅助头；② 小权重联合训练；③ 探针评估；④ 端到端 A/B。
- **风险**：辅助目标与主任务冲突。**缓解**：小权重、可一键关闭。

## 3. 符号与定义（U13–U24）

| 符号 | 含义 |
|---|---|
| `a_t` | 第 t 步下发的关节目标（`action.left_arm/right_arm`，可含 pivot） |
| `q_t` | 第 t 步观测到的关节位置（`observation.state.left_arm/right_arm`） |
| `e_t` | 伺服残差（指令−执行差） |
| `e^0_t` | 自由空间伺服基线 |
| `ρ_t` | 接触残差 |
| `c_t` | 接触指示 |
| `n_t` | 接触法向估计 |
| `s^act_t` | 驱动状态向量 |
| `F` | 关节运动学可行域 |
| `N(J)` | 冗余零空间 |
| `T_a` | action chunk 长度 |

**定义 U13（指令-执行对与对齐）** `(a_{t-1}, q_t)` 经对齐映射 `A_τ` 配为 `q_t ↔ a_{t-τ(t)}`；`τ` 由 E619 估计，带置信区间。

**定义 U14（伺服残差）** `e_t = q_t − a_{t-τ(t)}`（逐关节向量）。

**定义 U15（自由空间伺服模型）** `e^0_t = f_φ(q_{t-1}, \dot a_{t-1}, a_{t-1})`，仅在无接触段拟合。

**定义 U16（接触残差与指示）** `ρ_t = e_t − e^0_t`，`c_t = 1[||ρ_t|| > τ_c]`。

**定义 U17（接触法向）** `n_t = −ρ_t / ||ρ_t||`（或把 `ρ_t` 投影到指令速度方向后取反）。

**定义 U18（驱动状态）** `s^act_t = [e_t, ρ_t, \dot q_t, m_t, c_t]`，`m_t` 为逐关节限位裕度。

**定义 U19（可行域）** `F = {A : q_min ≤ a_k ≤ q_max, |a_k − a_{k-1}| ≤ v_max Δt, |a_k − 2a_{k-1} + a_{k-2}| ≤ a_max Δt², |Δ³a| ≤ j_max Δt³}`。

**定义 U20（可行投影）** `A* = Π_F^W(A) = argmin_{A'∈F} ||A' − A||_W²`。

**定义 U21（零空间）** `N(J) = {δq : J(q)δq = 0}`，投影 `P_N = I − J⁺J`。

**定义 U22（零空间姿态整形）** `q' = q + α P_N ∇h(q)`，`h = w(q) − λ_l Σ_j φ(m_j) − λ_c C_self(q)`，`w` 为可操作度。

**定义 U23（残差门控）** `T_a = T_long` 若 `||ρ|| < τ_s` 且滑动方差稳定，否则 `T_short`；切换带滞回与最小驻留。

**定义 U24（残差辅助损失）** `L_aux = ||\hat e^0 − e^0||² + BCE(\hat c, c) + λ_n(1 − cos(\hat n, n))`。

```python
# ===== IP-09：伺服残差总线 =====
class ServoBus:
    def __init__(self, servo_model, tau_c, align, dt=1/30):
        self.f0 = servo_model          # e^0 = f0(q_prev, da)
        self.tau_c = tau_c
        self.align = align             # 由 E619 标定，含置信度
        self.dt = dt
        self.prev_q = None
        self.prev_a = None
        self.a_prev2 = None

    def step(self, obs, a_last):
        q = concat(obs["observation.state.left_arm"][-1],
                   obs["observation.state.right_arm"][-1])
        dq = (q - self.prev_q) / self.dt if self.prev_q is not None else zeros_like(q)
        e = self.align.residual(a_last, q)                 # q_t - a_{t-tau}
        da = (a_last - self.a_prev2) / self.dt if self.a_prev2 is not None else zeros_like(q)
        e0 = self.f0(self.prev_q if self.prev_q is not None else q, da)
        rho = e - e0
        c = float(np.linalg.norm(rho) > self.tau_c)
        n = -rho / (np.linalg.norm(rho) + 1e-8)
        m = np.minimum(q - Q_MIN, Q_MAX - q)
        self.prev_q, self.a_prev2 = q, a_last
        return ActState(e=e, rho=rho, c=c, n=n, dq=dq, margin=m)
```

```python
# ===== IP-13：零空间姿态整形 =====
def nullspace_shape(q, h_grad, J, alpha=0.05, delta_max=0.02):
    Jpinv = np.linalg.pinv(J)
    P = np.eye(len(q)) - Jpinv @ J
    dq = alpha * (P @ h_grad)
    n = np.linalg.norm(dq)
    if n > delta_max:
        dq *= delta_max / n
    return q + dq
```

## 5. 推导（引理 L8–L14）

**引理 L8（残差可观测性与接触可识别性）** 设 (A1) `q_t` 与 `a_{t-1}` 已对齐；(A2) 自由空间模型误差 `ε = e^0 − f_φ` 有界；(A3) 外部接触在残差上近似可加 `e = e^0 + ρ + ε`。则检测器 `1[||e − f_φ|| > τ]` 的假阳率 ≤ `P(||ε|| > τ)`，且在 `||ρ|| > τ + ||ε||` 时必检出。取 `τ = quantile_{1−α}(||ε||)` 即得假阳 ≤ α；检测功效由接触信噪比 `||ρ||/||ε||` 决定。∎

**引理 L9（KFP 提升残差可解释性）** 把残差分解为 `e = e_lag + e_sat + ρ + noise`，其中 `e_sat` 只在指令离开可行域 `F` 时出现。若 KFP 强制 `A ∈ F` 且底层限幅是 `F` 的超集，则 `e_sat = 0`，检测器的干扰项从 `||e_lag + e_sat||` 降为 `||e_lag||`；同一假阳率下阈值可下调，检测功效上升。⇒ **KFP 是 CfR 的前置条件**。∎

**引理 L10（零空间一阶不变性）** 若 `δq ∈ N(J(q))`，则 `FK(q + δq) = FK(q) + Jδq + O(||δq||²) = FK(q) + O(||δq||²)`。取 `||δq|| ≤ δ`，任务空间偏差 ≤ `½||H||δ²`（`H` 为 FK Hessian 界）。⇒ 小步零空间整形一阶不改变 EE 意图。∎

**引理 L11（RCC 调用次数上界）** 设接触步占比为 `p`，短/长块为 `T_s/T_l`，总步数 `T`。则调用次数 `N ≤ (1−p)T/T_l + pT/T_s`，相对固定长块的增幅 ≤ `1 + p(T_l/T_s − 1)`。当接触稀疏（`p` 小）时开销有界且小。∎

**引理 L12（保守接触检测的净收益）** 设接触检测真阳率 `r`、假阳率 `α`，搜索救回收益 `G`、误触发损失 `L`、开销 `O`。净收益 `Δ = rG − αL − O`。取高阈值使 `α ≤ 0.02` 且 `G ≥ 5L` ⇒ `Δ > 0`。⇒ 与 SAGE 的 L3 同构：**只在高置信时介入**。∎

**引理 L13（对齐延迟的误差传播界）** 设真实延迟为 `τ`、估计为 `τ̂`。则 `e_t = q_t − a_{t−τ̂} = (q_t − a_{t−τ}) + (a_{t−τ} − a_{t−τ̂})`，第二项 ≈ `(τ̂−τ)Δt·\dot a`。故 `||e_err|| ≤ |τ̂−τ|Δt||\dot a||_∞`。CfR 可用的充分条件为
`|τ̂−τ| < (τ_c − ||ε||) / (Δt·||\dot a||_∞)`。
⇒ **关节速度越高，对齐容差越紧**；高速时应收紧阈值或直接关闭 CfR。这是本轮风险的定量护栏。∎

**引理 L14（SERVO 对 SAGE 漏判风险的降险界）** 在残差高斯模型下，滑移检测 AUROC 为 `Φ(μ_slip / (√2 σ_servo))`。若视觉代理的等效标签噪声 `σ_v ≥ σ_servo`，则 `AUROC_servo ≥ AUROC_vision`；SAGE 的漏判非对称损失随 AUROC 单调下降，故在相同介入阈值下 `Loss_servo ≤ Loss_vision`。该不等式是否成立由 E622 直接检验，而非默认成立。∎

## 9. 风险登记册与降级链

| 风险 | 概率 | 影响 | 对冲 |
|---|---|---|---|
| **对齐未知**（chunk 执行/插值/观测延迟） | 高 | 高（CfR 全栈失效） | E619 先行；按 L13 速度-延迟包络门控；未通过默认关 CfR |

| FK/URDF 失配 | 中 | 中 | E631 标定；NSP trust-region；默认可关 |
| KFP 过度约束 | 中 | 中 | 数据分位数而非硬规格；A/B |
| KFP QP 延迟 | 低 | 中 | 批量/早停/降迭代 |
| 短块增调用/抖动切换 | 中 | 中 | 滞回 + 最小驻留 + 调用上限（L11） |
| NSP 与底层控制器叠加 | 中 | 中 | 小步、默认关、真机 A/B |

**严格降级链**：
- Level 0 对齐失败 ⇒ 关闭 IP-10/IP-12/IP-14，保留 IP-11/IP-13（不依赖对齐）。
- Level 1 自由空间模型失败 ⇒ 原始残差 + 高阈值，或只做滑移。
- Level 2 KFP 失败/超时 ⇒ 恒等投影，仅记录。
- Level 3 NSP 失败 ⇒ 恒等整形。
- Level 4 全部失效 ⇒ 退回 **SAGE 基线**（永远保留可跑、可信的最小提交）。

## 11. 本轮最值得押注的创新点（一句话）

**押注 IP-09 + IP-10（伺服残差即力传感器）：它把 SAGE 最脆弱的"抓握/接触只能靠视觉猜"换成"关节空间的直接测量"，而插入/旋转类（Plug In Ethernet / Unlock / Open Pill Bottle）正是 teaser 榜最差、且跨基准一致暴露的断点；KFP 保证这条信号不被自身饱和污染，二者构成"测量 + 可行"的最小闭环。**

**本轮最大风险**：若评测端的 chunk 执行/插值/观测延迟使 `q_t` 与 `a_{t-1}` 不可对齐，伺服残差会退化为噪声，接触检测、残差门控、残差归因将同时失效——所以 E619 必须先行，未通过就默认关闭 CfR，只保留不依赖对齐的 KFP 与 NSP。
