## 1. 直觉与动机（两个灵感的碰撞）

**灵感 1（记忆检索 → 策略不是「记住」了示教，而是「压缩」了示教；压缩会丢索引）**

直觉：32k 条示教训练出的策略把记忆压进权重——这是「只保留统计规律、丢掉具体案例」的记忆。人类专家不是这样工作的：遇到新杯子，他会想起「上次那个类似的杯子，我是从上方 45° 抓的」。所以零样本泛化的另一半不在参数里，而在**可检索的案例记忆**里。反直觉点有两个：

1. **检索的难点不是「有没有记忆」，而是「检索哪一层」**。同一场景可以检索同类物体（抓取可供性）、同技能阶段（接近/抓取原型）、同布局（路径与避障）、同恢复片段（偏离→修正）。检索错层比不检索更糟——把「同类物体怎么抓」误用成「同布局怎么绕」，会直接注入错误先验。
2. **检索不一定要在推理期做**。把检索邻域当「教师」在训练期蒸馏进权重（海马体→皮层的系统巩固），推理期就能删掉检索器：既拿到记忆的好处，又不破坏单模型边界与部署预算。**记忆因此有两条通道：推理期检索（快、可解释、有误检索风险）与训练期蒸馏（慢、内化、零推理开销）。**

**灵感 2（数字孪生 → 孪生不是「仿真器」，而是「可校准的反事实机器」）**

直觉：I5 的痛点是「没有失败示教」，I8 的痛点是「没有真机预算」，两者本质是同一个缺失——**没有一台能回答「如果……会怎样」的机器**。数字孪生就是这个机器：在孪生里把杯子左移 2cm、换个颜色、加个干扰物，立刻知道策略会不会失败、失败后能不能救回来。但关键的反直觉点是：**未经校准的孪生比没有孪生更危险**——它会给出「看起来合理」的结论，把团队引向错误方向。孪生只有在「干预一致」时才是科学仪器：同样的干预，孪生与真实的结果分布足够接近。因此孪生的第一产物不是数据，而是**保真度证书**；没有证书的孪生结论，一律不得进入训练或评测决策。

**灵感 3（碰撞与统一 → 记忆是孪生的标尺，孪生是记忆的练武场）**

直觉：两者不是并列的两个模块，而是一个闭环。真实示教 → 记忆库；记忆库 → 校准孪生（用留出真实轨迹当标尺）；孪生 → 生成反事实、筛选该合成哪些扰动、预演不同检索策略；筛选结果 → 增广记忆 / 蒸馏权重 → 真机验证。核心统一：**记忆提供「真实长什么样」，孪生提供「改变之后会怎样」；没有记忆，孪生无法校准；没有孪生，记忆无法在稀缺真机上试错。** 本轮结论：v1.1 的「数据引擎」缺一个闭环试验台；记忆检索与数字孪生正好补上这个台子的两端。

## 4. 设计原则（新增 PR6–PR8，PR1–PR5 保留）

- **PR8 独立锚定律**：保留一批真实 episode（建议 ≥10%），既不用于建记忆库、也不用于校准孪生，只用于审计二者。没有独立锚定集，PR6/PR7 都无法被验证。

## 1. 严谨定义（先直觉、后定义；定义供实现与消融共用）

### 1.1 情景记忆库（Episodic Memory Bank）

**直觉**：把每条示教拆成「可被检索的卡片」，而不是一整段视频。

**定义 1**：记忆库 `M = {m_j}`，每条记忆
`m_j = (φ_j, ψ_j, z_j, τ_j, q_j, ℓ_j)`
- `φ_j = f_vis(o_j^0) ∈ R^{d_o}`：首帧/关键帧物体—场景嵌入；
- `ψ_j = f_lang(ℓ_j) ∈ R^{d_s}`：指令/技能嵌入；
- `z_j = {(t, a_t, o_t)}_{t=0}^{T_j}`：动作—观测轨迹，按阶段切分为 `z_j^{(0..P)}`；
- `τ_j = (τ_j^0, …, τ_j^K)`：官方得分点里程碑达成时刻（F17 逆向）；
- `q_j ∈ [0,1]`：质量分（进度效率 × 平滑度 × 成功裕度，I2 v2）；
- `ℓ_j`：布局/相机/物体位姿等结构化元数据。

索引：`H_obj, H_skill, H_layout, H_phase` 四棵（FAISS 或等价）。

### 1.2 分层检索算子（Hierarchical Retrieval）

**直觉**：不同问题要查不同的「抽屉」；查错抽屉要允许「不回答」。

**定义 2**：对查询 `q = (φ_q, ψ_q, layout_q, phase p)`，
`R_p(q; M, k, τ_p) = TopK_j { m_j : d_p(q, m_j) ≤ τ_p }`，
`d_p = α_p·d_o(φ_q, φ_j) + β_p·d_s(ψ_q, ψ_j) + γ_p·d_l(layout_q, layout_j) + δ_p·d_phase(p, j)`。
- `p=0`（reset）：物体可供性记忆 → 抓取开度、接近向量、接触高度；
- `p=1`（阶段边界）：技能阶段记忆 → 阶段原型、时长分布；
- `p=2`（偏离检测）：恢复片段记忆 → 「偏离→修正」动作段。

**弃权规则**：若 `|R_p| < 1` 或 `d_min > τ_p`，返回 `∅`（无先验），而非硬塞最近邻。

**软注入与伤害上界**：`a_t = a_t^π + w(d)·Δa(m*)`，`w(d)=clip((τ-d)/(τ-τ_0), 0, w_max)`。
则单步动作偏差满足 `||a_t - a_t^π|| ≤ w_max·B`（`B = max ||Δa||`）。
消融时必须报告「标称场景的 Δprog 下界」，确保 `w_max` 不伤已会任务。

### 1.3 数字孪生与干预一致性（Digital Twin）

**直觉**：孪生不是「看起来像」，而是「改变之后也像」。

**定义 3**：任务族 `k` 的数字孪生 `D_k = (S, A, T̂, Ô, C)`，`T̂` 为（物理或视频）转移模型，`Ô` 为观测/渲染模型，`C` 为校准参数。给定干预族 `I`（位置/干扰物/背景/未见物品），称 `D_k` 在 `I` 上 **ε-干预一致**，若
`sup_{do(i) ∈ I} TV( P_real(Y | do(i)), P_D(Y | do(i)) ) ≤ ε`，
其中 `Y` 为任务级结果（里程碑序列或成功指示）。

**保真度四指标**（可操作代理）：
- `F_kin`：开环末端轨迹误差（mm，真实动作序列回放 vs 孪生回放）；
- `F_contact`：接触类里程碑的时序一致性（事件匹配率）；
- `F_vis`：渲染帧 vs 真实帧的特征 MMD / FID；
- `F_task`：同一策略在孪生与真实上的进度一致率（最关键）。

**准入规则**：只有 `F_task ≥ 0.8` 且 `F_kin ≤ δ_k` 的任务—干预族，才允许进入 I1/I5/I8 主链；否则仅作探索。

### 1.4 记忆蒸馏（Memory Consolidation）

**直觉**：把「查卡片」变成「记住了」；海马体（情景记忆）→ 皮层（参数记忆）。

**定义 4**：对训练样本 `(o_t, ℓ)` 检索邻域 `R(q;M,k,τ)`，构造辅助一致性目标
`L_cons = E[ Σ_t Σ_{j∈R} softmax(-d_j/T) · ||a_t^π(o_t,ℓ) − a_t^{(j)}||² ]`，
仅在**训练期**计算；推理期删除检索器与记忆库。这样最终提交仍是单一策略，PR2 无争议。

  2. **阶段感知检索**（定义 2）：reset 查 p=0；进度头检测阶段边界时查 p=1；偏离检测时查 p=2；

### I10 任务数字孪生工坊（新） ★★★★

### 3.1 分层记忆与阶段感知检索（I9 v2）

```python
LEVELS = {0: ("obj", 0.7, 0.2, 0.1, 0.0),   # reset: 物体为主
          1: ("phase", 0.2, 0.4, 0.1, 0.3), # 阶段边界: 技能+阶段
          2: ("recover", 0.3, 0.2, 0.2, 0.3)}# 偏离: 恢复片段

class HierarchicalMemory:
    def __init__(self, index, quality_min=0.3):
        self.index = index                 # FAISS: obj/skill/layout/phase
        self.quality_min = quality_min

    def query(self, q, level, k=3, tau=None):
        w_o, w_s, w_l, w_p = LEVELS[level][1:]
        d = (w_o * self.d_obj(q) + w_s * self.d_skill(q)
             + w_l * self.d_layout(q) + w_p * self.d_phase(q))
        order = np.argsort(d)[:k]
        hit = [(j, d[j]) for j in order
               if d[j] <= (tau or TAU[level])
               and self.quality[j] >= self.quality_min]
        return hit or []                   # 弃权：返回空，不硬塞

def inject(a_policy, hit, B, w_max):
    if not hit: return a_policy
    j, d = hit[0]
    w = np.clip((TAU[level] - d) / (TAU[level] - TAU0[level]), 0, w_max)
    return a_policy + w * np.clip(DA[j], -B, B)   # 有界软注入
```

### 3.3 孪生标定与保真度证书（I10）

def certify_twin(D, real_anchor, policy, delta_kin):
    F_kin = mean_ee_error(D.replay(real_anchor.actions), real_anchor.ee)
    F_contact = milestone_timing_agreement(D, real_anchor)
    F_vis = feature_mmd(D.render(real_anchor.frames), real_anchor.frames)
    F_task = progress_agreement(D.rollout(policy), real_anchor.progress)
    ok = (F_task >= 0.8) and (F_kin <= delta_kin)
    return {"F_kin": F_kin, "F_contact": F_contact,
            "F_vis": F_vis, "F_task": F_task, "certified": ok}

def twin_filter_perturbations(D, candidates):
    # 孪生只筛「哪些扰动值得在真实示教上重放」，不直接生成训练帧
    return [c for c in candidates
            if D.rollout_with_perturb(c).reaches_next_score_point()]

### 3.4 保真度门控的 L0 与独立锚定（I8 v3）

```python
def l0_with_fidelity_gate(policy, axes, heldout, twin, cert, anchor):
    scores = {}
    for axis, dose in axes:
        if not cert[axis]["certified"]:
            continue                         # PR6：未过闸的轴不进入结论
        pert = apply_axis(heldout, axis, dose)
        scores[(axis, dose)] = {
            "d_prog": progress(policy, pert) - progress(policy, heldout),
            "d_act":  action_consistency(policy, pert, heldout),
        }
    # PR8：所有结论在独立锚定集上复核，锚定集不参与建库/标定
    assert not overlaps(anchor, heldout)
    return scores, audit_on_anchor(policy, scores, anchor)
```
