# 第 43 轮（新循环第 3 轮） · 度量合同 × 差异化定位：从「可验证」到「可取胜、可审计、不可替代」（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR 飞轮）。上一轮自陈的最大风险是「仿真偏差累积 + 检索幻觉」，本质是**内部正确性**失效链。本轮灵感词「评测指标」「差异化定位」把镜头从内部拉到外部：**评测指标不是赛后裁判，而是设计期的合同**——它决定算力往哪花、什么才算赢；**差异化定位不是营销话术，而是战略约束**——它决定不进入哪些红海、加深哪条护城河。核心主张：证书栈只有在「被正确度量」且「与竞争者形成结构性差异」时，才从学术玩具变成比赛武器。

## 0. 直觉与动机

### 灵感 1（评测指标 → 把 rubric 变成可优化的「合同」，再用 proper scoring 防 Goodhart）

第 42 轮的 anytime 调度目标是「最大化 soundness / 最小化超时」，但比赛真正打分的是一组加权指标：任务成功率、完成质量、碰撞与违规、恢复时间、人工干预、耗时与能耗。两者并不等价——一个处处 sound 但长期 SafeStop 的系统，soundness 满分、得分却是零。直觉拆成三步：

1. **指标合同化**：把官方 rubric 显式写成效用泛函 U_w(π)=Σ_k w_k·M_k(π)，每个指标带不确定区间；anytime 调度从「固定档位」改为「在预算内最大化 U 的**置信下界**」（risk-aware DP / bandit），用下界而非均值对抗乐观偏差。
2. **测量科学化**：指标须过「构念效度—区分效度—抗博弈性」三关；用 proper scoring rule（Brier / 对数分）让**诚实报告不确定性**成为占优策略，用校准误差 ECE 惩罚「嘴上 99%、实际 70%」。
3. **证书卡化**：证书本身也要被评测——像 model card 一样输出 certificate card：覆盖率、余量分布、Sim2Real 系数、已知失效模式、版本哈希与复现指纹。指标由此从被动得分变成主动设计变量，但必须用 proper scoring + 安全硬约束挡住指标博弈。

### 灵感 2（差异化定位 → 在「能力—成本—可信度」空间找空象限，用证据筑护城河）

具身智能赛道大致有三类竞争者：端到端大模型 VLA（成功率高、成本高、不可审计）、经典 TAMP/规划（可解释、安全、泛化差）、纯 RL（快、脆、难复现）。若只在「端到端成功率」这条轴上和 VLA 硬拼，是以短击长。差异化定位的直觉是画**能力—成本—可信度**三维定位图，找**空象限**：高泛化 × 高可审计 × 边缘低成本 × 可迁移——这恰好是第 42 轮证书栈的天然位置。护城河不是功能清单，而是三层结构性壁垒：**数据**（CKB 的反例与证书语料网络效应）、**工具链**（SCV→ECR 从验证到部署的闭环）、**标准**（证书卡与评测基准成为别人对标的接口）。

### 灵感 3（两者耦合 → 「度量—定位—证书」三角，而非单向流水线）

指标定义「优化什么」，定位定义「不优化什么 / 不跟谁比」，证书提供「凭什么信」的证据，三者构成三角而非流水线。因此飞轮每轮不仅按分布偏移 W_1 触发更新，还按**指标回归**（metric regression）与**定位证据缺口**（evidence gap）触发更新。差异化从「宣称」变成「可复现的测量结果」，评测从「赛后」变成「设计期合同」。

## 1. 形式化定义（增量：定义 38–43）

**定义 38（比赛效用泛函）**：指标向量 M(π) = (S, Q, R, H, C, G)，分别为任务成功率、完成质量、恢复时间、人工干预率、单位任务成本、跨任务泛化。归一化后 U_w(π) = Σ_k w_k·\hat M_k(π)，w 为官方 rubric 权重。**指标合同**要求每个 \hat M_k 附带置信区间 [\hat M_k^-, \hat M_k^+]，优化目标取 U_w^-(π)（下界），以对抗均值乐观偏差。

**定义 39（风险调整效用 RAU 与安全硬约束）**：RAU(π) = U_w^-(π) − λ·CVaR_α(L(π))，L 为安全/违规损失；并要求 P(不安全事件) ≤ ε_safe 为**硬约束**。形式化为约束优化：指标优化不得以放松安全约束为代价，安全项不进入可交易的权重空间。

**定义 40（证书覆盖-性能比 CPR）**：对任务相关域 X_task，覆盖率 CCR = |C_sim ∩ X_task| / |X_task|；证书余量 σ(x) = m_lo(x) − θ；CPR = E_{x∼X_task}[σ(x)·1{x∈C_sim}] / E[σ]。CPR 同时奖励「覆盖广」与「留足裕度」，替代单一 soundness 指标，防止「覆盖广但处处贴边」。

**定义 41（指标对齐度与 Goodhart 系数）**：对齐度 A = Spearman(U_w^- 预测, 官方得分)。Goodhart 系数 G_M = max_{π∈Π_audit} [\hat M(π) − U(π)]_+ / U(π)，在独立审计策略族上估计。**命题**：若 M 为严格 proper scoring rule 且审计集与训练集独立，则诚实报告下 G_M ≤ δ_audit，δ_audit 由审计样本量与策略族复杂度给出（类似泛化界）。

**定义 42（差异化指数 DI 与定位边际 PM）**：能力向量 c(π) ∈ R^d，评委显著性权重 s，竞争者集合 C。DI_i = min_{j∈C, j≠i} ‖s⊙(c_i − c_j)‖_1 / (1 + Cost_i/Cost_ref)，DI 越大表示离最近竞争前沿越远。**定位边际** PM_i = U_i − max_{j≠i} U_j 在空象限约束下的投影；PM>0 且 DI 大，才是真差异化。

**定义 43（证书卡 Certificate Card）**：CC = (版本哈希, 指标向量及 CI, CCR/CPR, α_e 与 W_1 估计, 漂移阈值 τ_drift, 已知失效模式清单, 复现脚本指纹)。证书卡是差异化定位的**证据单元**：每条定位宣称必须绑定至少一条 CC 字段，否则自动降级为「待验证假设」。

## 2. 产出设计（新增 IP-57/58/59 + 升级既有 IP）

### 2.1 IP-57 METRIC-ORACLE（MOR，度量预言机）

1. **rubric 解析与权重学习**：从官方文档与历史榜单估计 w 与归一化曲线，输出带 CI 的 U^-。
2. **proper-scoring 报告层**：成功率用 Brier/对数分，校准用 ECE，防「自信爆表」。
3. **指标感知 anytime 调度**：把 LCS 档位选择建模为有限时域 DP，状态 =（剩余预算, 当前 U^- 分布），动作 = 升档/降档/停，目标 max E[U^- − λ·CVaR]。
4. **对抗指标审计**：构造「刷分策略」（只挑简单任务、贴边通关、隐瞒失败、虚报置信）作为攻击集，量化 G_M 并回填硬约束。

### 2.2 IP-58 CERT-BENCH / CERTIFICATE-CARD（CBC，证书基准与证书卡）

1. **分层评测集**：名义 / 长尾 / 对抗 / 分布偏移四层，附 hidden holdout 防基准过拟合。
2. **证书卡生成器**：任意证书或策略 → CC（指标 + CI + 覆盖率 + 失效模式），可机器校验。
3. **指标回归门禁**：A、G_M、CPR、CI 宽度四项写入 CI/CD，退化即拦截。
4. **第三方复现包**：容器 + 固定随机种子 + sim_config_hash，确保「宣称即可复现」。

### 2.3 IP-59 POSITION-STRATEGIST（DPS，定位策略器）

1. **竞争者能力挖掘**：从公开榜单与论文抽取 c_j 与成本，维护定位图。
2. **空象限搜索与 DI/PM 计算**：输出「进入 / 回避」清单及理由。
3. **证据闸门**：每条定位宣称绑定 CC 字段，无证据的宣称自动标为假设。
4. **护城河路线图**：数据（CKB 反例增长曲线）、工具链（SCV→ECR 闭环时延）、标准（证书卡采用度）三线指标。

## 2. 关键算法（伪代码）

### IP-57 MOR：指标合同、校准与防博弈

```
def estimate_utility(policy, eval_batches, rubric_weights, alpha=0.05):
    # 1. 分层评测，逐指标估计均值与置信区间
    metrics = {}
    for name in ['S','Q','R','H','C','G']:
        xs = [metric_fn[name](trace) for b in eval_batches for trace in b]
        lo, hi = bootstrap_ci(xs, alpha)          # 下界用于优化
        metrics[name] = {'mean': mean(xs), 'lo': lo, 'hi': hi}
    # 2. proper scoring：成功率同时记录预测概率 p，用 Brier 分
    brier = mean((p - y)**2 for p,y in predictions)
    ece   = expected_calibration_error(predictions, bins=15)
    # 3. 归一化 + 加权下界
    U_lo = sum(rubric_weights[k] * normalize(k, metrics[k]['lo']) for k in metrics)
    return {'U_lo': U_lo, 'metrics': metrics, 'brier': brier, 'ece': ece}

def metric_aware_anytime(x, tiers, budget_us, value_model, lam=0.5):
    # 状态: (剩余预算, 当前边际下界估计); 动作: 升档/降档/停
    # 价值函数缓存：V[b, u] = 在预算 b、估计 u 下的最优期望 RAU
    candidates = []
    for action in ['stay','upgrade','downgrade','stop']:
        cost = tier_cost(action)
        if cost > budget_us: continue
        u_next = value_model.predict(x, action)          # 带 CI
        risk   = value_model.cvar(x, action, alpha=0.05)
        candidates.append((V(budget_us-cost, u_next) + u_next - lam*risk, action))
    return max(candidates)                                # 返回最优动作与价值

def adversarial_metric_audit(policy_family, holdout, metric_fn, budget=1e4):
    # 构造刷分策略：只做简单任务 / 贴边通关 / 隐瞒失败 / 虚报置信
    attacks = [EasyTaskOnly(), EdgeRiding(), HideFailure(), Overconfident()]
    gaps = []
    for atk in attacks:
        pi = atk.compose(policy_family)
        m_hat = metric_fn.estimate(pi, holdout)          # 指标上看到的分
        u_true = ground_truth_utility(pi, holdout)       # 真实效用（含安全硬约束）
        gaps.append(max(0.0, m_hat - u_true) / max(1e-6, u_true))
    G_M = max(gaps)
    # 回填约束：G_M > tau_g 时禁止该指标参与调度优化
    return {'G_M': G_M, 'per_attack': gaps, 'metric_usable': G_M <= tau_g}
```

```
        'adversarial': sample(task_corpus, level='adversarial'),
        'shift':     sample(task_corpus, level='distribution_shift'),
        'hidden':    private_holdout(task_corpus)   # 不进 CI 日志，防基准过拟合
    }

def certificate_card(cert, policy, suite, alpha=0.05):
    M = estimate_utility(policy, suite['nominal']+suite['longtail'], cert.rubric_weights)
    CCR, CPR = coverage_stats(cert, suite['nominal'])
    card = {
        'version': cert.hash,
        'metrics': M['metrics'], 'U_lo': M['U_lo'],
        'calibration': {'brier': M['brier'], 'ece': M['ece']},
        'CCR': CCR, 'CPR': CPR,
        'sim2real': {'alpha_e': cert.alpha_e, 'W1': cert.W1_est},
        'drift_tau': cert.tau_drift,
        'known_failures': cert.failure_modes,
        'repro': repro_fingerprint(cert, suite)
    }
    return card

def regression_gate(card_old, card_new, thresholds):
    checks = {
        'A':    card_new['alignment'] >= thresholds['A'],
        'G_M':  card_new['G_M'] <= thresholds['G_M'],
        'CPR':  card_new['CPR'] >= card_old['CPR'] * thresholds['CPR_ratio'],
        'CI_w': card_new['ci_width'] <= thresholds['ci_width'],
        'safe': card_new['P_unsafe'] <= thresholds['eps_safe']
    }
    return all(checks.values()), checks   # 任一失败则 CI/CD 拦截
```

```
def build_position_map(competitors, our_caps, salience):
    # c ∈ R^d: 泛化/安全/成本/可审计/迁移/人机协作; cost 单列
    pts = [{'id': c.id, 'c': c.vector, 'cost': c.cost} for c in competitors]
    pts.append({'id': 'ours', 'c': our_caps, 'cost': our_cost})
    return pts

def differentiation_index(ours, others, salience, cost_ref):
    dists = []
    for o in others:
        d = sum(salience[i]*abs(ours.c[i]-o.c[i]) for i in range(len(salience)))
        dists.append(d / (1 + ours.cost/cost_ref))
    return min(dists) if dists else float('inf')

def find_empty_quadrant(points, salience, grid=20):
    # 在能力—成本—可信度空间做加权核密度，找最低密度且高价值的单元
    density = kernel_density(points, salience, grid)
    value   = expected_competition_value(grid, salience)
    score   = value / (density + eps)
    return argmax_cell(score), score

def evidence_gate(claim, card):
    # 每条定位宣称必须绑定至少一条证书卡字段
    field = claim.bound_field
    if field not in card: return {'status': 'hypothesis', 'evidence': None}
    if not claim.predicate(card[field]): return {'status': 'refuted', 'evidence': card[field]}
    return {'status': 'supported', 'evidence': card[field]}

def moat_metrics(ckb, scv, cbc):
    return {
        'data_moat':   ckb.counterexample_growth_rate(),      # CKB 反例增长曲线
        'tool_moat':   scv.to_deploy_latency(),               # 验证→部署闭环时延
        'standard_moat': cbc.certificate_card_adoption()      # 证书卡被外部采用度
    }
```

## 6. 本轮最大风险
