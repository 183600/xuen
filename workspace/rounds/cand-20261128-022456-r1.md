### 第 5 轮灵感驱动研究记录

**灵感词**：用户画像、论文发表

**继承关系**：第 4 轮 CADVS-v4（IP-489~492）在 v3 五锚点（3DCF/MSRG/HICK/EEK/LTEM + FFA）上追加价值锚 VACK 与平衡锚 BCK，形成七硬门 kc_evidence_forged_v4 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem ∧ kc_val ∧ kc_bal，软评分 ECS_v4 = ECS_v3 · η_val · η_bal，执行集 Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。v4 留下两个未解问题：(i) VACK 只有一个全局 λ_vec，R51 已指出联邦价值异构会收敛到「无人满意的平均」；(ii) v4 把「论文创新点」仅当作事后提炼，没有把「论文声称」本身纳入证据体系。本轮以「用户画像」与「论文发表」为灵感，把二者统一为**人格分层证据**：证据不仅要对「平均用户」成立，还要对每个用户画像分层成立；论文声称必须被分层证据链支撑。形成 CADVS-v5（IP-493~497）。关键约束：**不碰控制环**——Exec_cycle-v5 = Exec_CADVS-v4，新增锚点全部位于准入/部署/发表等慢时标，故不恶化 v4 的最大风险（实时性）。

**直觉与动机**：

1. **用户画像：把「一个全局价值权重」拆成「人群 × 风险预算」的条件化证书**。直觉上，同一台机器人在养老陪护、工业分拣、家庭服务三类用户手里，安全阈值、效率偏好、接管习惯完全不同；用一个 λ_vec 去对齐所有人，等于对所有人都不对齐。因此引入用户画像 P（风险偏好 ρ、价值权重 λ_vec(P)、操作技能 skill、任务分布 task_mix、上下文 ctx、漂移 drift），把 VACK 从 R_val 升级为条件奖励 R_val|P，把固定阈值 τ_val 升级为风险自适应阈值 τ_val(P)=clip(τ_0+ρ(P)Δτ, τ_min, τ_max)，并增加风险预算 B_P 与接管策略兼容性。硬门 kc_persona = (α_val ≥ τ_val(P)) ∧ (risk_used ≤ B_P) ∧ handoff_compatible(P, rule)；软因子 η_persona 衡量规则与画像的贴合裕度。这样 v4 的 R51「平均化」问题被正面解决：不是求一个全局 λ，而是按画像分层个性化（PFP）。

2. **论文发表：把「声称」变成一等证据对象（Claim-Evidence 演算）**。直觉上，审稿人攻击的从来不是代码量，而是「你的 claim 比你的 evidence 强」。工程系统有大量模块，却没有显式的 claim→evidence 映射，导致过度声称、消融缺失、复现困难。因此引入声称证书 CC 与声称-证据图：每条 claim（定理/经验/系统）绑定证据集合（证明、实验、消融、反例）、威胁模型、可执行证伪器与适用范围；硬门 kc_claim = coverage ∧ significance（CI 排除零效应且效应量达标）∧ reproducibility（种子/哈希/一键复现）∧ falsifier_ok ∧ ¬unresolved_objection。这把「论文发表」从叙事变成可审计的证据契约，并让证书演算从「运行时安全」扩展到「知识声称的可靠性」。

3. **二者的真正交汇：人格分层的外部效度**。论文里最常见的过度声称是「平均性能提升」，部署中最常见的失效是「对某类用户不安全」。把二者合起来得到核心洞见：**经验 claim 必须在画像分层上成立，聚合 claim 必须附带最差分层界，而不是平均界**。于是引入人格分层评估协议 PSEP：把总体风险分解为分层风险 R_j，claim 的通过条件是 max_j R_j ≤ R_max（worst-stratum），并用分层样本量 n_j 给出均匀收敛界。这同时回应了「用户画像」（部署公平性）与「论文发表」（审稿人对外部效度的攻击）。

**关键洞见**：v4 回答「需要哪些证据」；v5 回答「证据对谁成立、能否被第三方复核为知识」。VACK/BCK 仍在 L0/L1；PAK/PFP/PSEP/CEC 位于 L1/L2（准入/部署/发表）。执行集与部署/发表集分离：Exec_cycle-v5 = Exec_CADVS-v4；Exec_Deploy-v5 = Exec_CADVS-v4 ∩ {kc_persona}；Publishable-v5 = Exec_Deploy-v5 ∩ {kc_claim}。新增严格性只收缩「部署/发表」，不增加控制环延迟。

**形式化目标（增量）**：
1. 定义画像 P=(id, ρ_risk, λ_vec, skill, task_mix, ctx, drift)、条件奖励 R_val|P、风险自适应阈值 τ_val(P)、风险预算 B_P；定义 kc_persona 与 η_persona。
2. 定义画像联邦个性化 PFP：全局簇先验 λ_c^0 + 本地 Δλ_i，画像聚类误差 δ_cluster；定理 5 给出个性化泛化界，并给出「个性化优于全局平均」的充分条件。
3. 定义声称-证据演算 CEC：claim DAG、证据项 e、kc_claim、审稿攻击面 RAS；定理 6 证明 claim 的强度不弱于其证据。
4. 定义人格分层评估 PSEP：分层风险 R_j、worst-stratum 准则、均匀收敛界；定理 7 给出外部效度证书。
5. 定义发布门 PGA-v5：kc_release_v5 = kc_evidence_forged_v4 ∧ kc_persona ∧ kc_claim（含画像漂移与证书新鲜度）。
6. 定义执行/部署/发表三层集合与收缩关系：Exec_cycle-v5 = Exec_CADVS-v4；Exec_Deploy-v5 ⊆ Exec_CADVS-v4；Publishable-v5 ⊆ Exec_Deploy-v5。
7. 给出可发表产物：claim 表、分层实验矩阵、消融、复现包、审稿攻击面清单、隐私与公平说明。

**本轮最大风险**：**画像误分类与分层挑选（stratum cherry-picking）会让「可发表」与「真实安全」脱钩**——系统在纸面画像上通过 kc_persona/kc_claim，却对真实用户总体（尤其少数/边缘画像）不安全，而 claim ledger 反而为这种分层过拟合背书。

## 2. 关键算法骨架

### IP-493 PAK：用户画像锚（准入时 O(1)/规则；控制环只读缓存阈值）

```python
@dataclass
class PersonaAnchorKernel:
    """PAK：画像条件化价值阈值、风险预算与接管兼容；kc_persona 硬门"""
    tau_0: float = 0.6
    delta_tau: float = 0.25
    tau_min: float = 0.5
    tau_max: float = 0.95
    s_P: float = 0.1                 # logistic 温度
    risk_models: dict = field(default_factory=dict)

    def threshold(self, P: Persona) -> float:
        return float(np.clip(self.tau_0 + P.rho_risk * self.delta_tau,
                             self.tau_min, self.tau_max))

    def evaluate(self, vac: VAC, P: Persona, rule: Rule, t_now: float) -> PersonaCert:
        tau_P = self.threshold(P)
        margin = vac.alpha_val - tau_P
        eta_persona = float(1.0 / (1.0 + np.exp(-margin / self.s_P)))
        c_used = self._expected_cost(rule, P)
        handoff_ok = self._handoff_compatible(P, rule)
        return PersonaCert(tau_P=tau_P, margin=margin, eta_persona=eta_persona,
                           risk_used=c_used, handoff_ok=handoff_ok, t=t_now)

    def kc_persona(self, pc: PersonaCert, P: Persona) -> bool:
        """引理 43：通过 ⟹ 在声明的画像下价值裕度非负且风险预算未超"""
        return (pc.margin >= 0.0 and pc.risk_used <= P.B_P and pc.handoff_ok)

    def _expected_cost(self, rule, P) -> float: ...
    def _handoff_compatible(self, P, rule) -> bool: ...
```

### IP-494 PFP：画像个性化联邦（慢时域，离线/秒~分钟级）

```python
def persona_federated(global_prior, sites, K_clusters, eps, clip, rounds):
    """按画像聚类后分簇 FedAvg；每站 = 簇先验 + 本地偏移"""
    labels = cluster_personas([s.persona for s in sites], K_clusters)
    lam_c = {}
    for c in range(K_clusters):
        members = [s for s in sites if labels[s.id] == c]
        lam_c[c] = fedavg([s.delta_lambda for s in members],
                          global_prior[c], eps, clip, rounds)
        for s in members:
            s.lambda_personal = lam_c[c] + s.delta_lambda
    return lam_c, labels
```

### IP-495 CEC：声称-证据演算（离线，发表前）

```python
@dataclass
class ClaimEvidenceCalculus:
    """CEC：每条 claim 必须有覆盖、显著、可复现、可证伪的证据链"""
    alpha: float = 0.05
    min_effect: float = 0.05
    require_replay: bool = True

    def kc_claim(self, C: Claim, E: list[Evidence], n_claims: int) -> tuple[bool, str]:
        if not self._coverage(C, E):                     return False, 'EVIDENCE_GAP'
        if not self._significant(E, n_claims):           return False, 'UNDERPOWERED'
        if self.require_replay and not all(e.replay_ok for e in E):
            return False, 'NOT_REPRODUCIBLE'
        if not self._falsifier_ok(C, E):                 return False, 'UNFALSIFIABLE'
        if C.ras > C.ras_max:                            return False, 'REVIEWER_ATTACK_SURFACE'
        return True, 'CERTIFIED'

    def _significant(self, E, m):
        a_eff = self.alpha / max(m, 1)                   # Bonferroni over claims
        return all((e.ci_low > 0 or e.ci_high < 0) and abs(e.effect) >= self.min_effect
                   for e in E)

    def _coverage(self, C, E) -> bool: ...
    def _falsifier_ok(self, C, E) -> bool: ...
```

### IP-496 PSEP：人格分层评估（离线，发表前）

```python
def persona_stratified_certificate(metrics, strata, R_max, delta):
    """定理 7：worst-stratum 而非平均；均匀收敛界"""
    K = len(strata)
    out = {}
    for j in strata:
        n_j = metrics[j].n
        rad = np.sqrt(np.log(2.0 * K / delta) / (2.0 * n_j))
        out[j] = dict(risk_hat=metrics[j].risk_hat, radius=rad,
                      ok=(metrics[j].risk_hat + rad <= R_max))
    return out, all(v['ok'] for v in out.values())
```

### IP-497 PGA-v5：发布门（准入/部署/发表时，不在控制环）

```python
@dataclass
class PublicationReleaseGateV5:
    efa: EvidenceForgingAssemblerV4
    pak: PersonaAnchorKernel
    cec: ClaimEvidenceCalculus
    n_claims: int = 7

    def release_gate(self, x, t_now, rule_id, hic, eec, bcc, P, pc,
                     claim, evidence) -> tuple[bool, str]:
        ok, why = self.efa.hard_gate(x, t_now, rule_id, hic, eec, bcc, ...)
        if not ok:                                   return False, why
        if not self.pak.kc_persona(pc, P):           return False, 'PERSONA_INADMISSIBLE'
        cok, cwhy = self.cec.kc_claim(claim, evidence, self.n_claims)
        if not cok:                                  return False, cwhy
        return True, 'RELEASE_OK'
```

## 4. 正确性论证（增量更新）

### 引理 43（画像条件化与误分类的线性腐蚀界）

**陈述**：设 α_val(·) 关于画像度量为 L_α-Lipschitz，τ_val(·) 为 L_τ-Lipschitz。若估计画像 P̂ 满足 d(P̂,P*) ≤ ε_P，且 kc_persona 在 P̂ 下通过（m_{P̂} ≥ 0），则真实画像 P* 下的裕度满足 m_{P*} ≥ −(L_α+L_τ)ε_P。特别地，若 τ_val 的取值域宽为 Δτ_max，则误分类造成的安全违例概率上界为 P(p_err) 加上一个 O(ε_P) 的线性项。

**证明**：由 Lipschitz 性，|α_val(P̂)−α_val(P*)| ≤ L_α ε_P，|τ_val(P̂)−τ_val(P*)| ≤ L_τ ε_P。于是 m_{P*} = α_val(P*) − τ_val(P*) ≥ α_val(P̂) − τ_val(P̂) − (L_α+L_τ)ε_P = m_{P̂} − (L_α+L_τ)ε_P ≥ −(L_α+L_τ)ε_P。∎

**工程含义**：误分类不会造成无界失效，而是把有效裕度按画像误差线性腐蚀。可在 kc_persona 中预留安全裕度 `m_min = (L_α+L_τ)ε_P + m_0`，并在画像置信度低于阈值时回退到保守画像 P_safe（ρ_risk 取上界）。

### 引理 44（声称-证据的显著性控制）

**陈述**：设论文共有 m 条经验 claim，每条证据在水平 α/m 下构造置信区间。若 kc_claim 要求每条 claim 的 CI 排除 0 且 |effect| ≥ δ_min，则「至少一条 claim 为假阳性」的概率 ≤ α。

**证明**：由 Bonferroni 不等式，m 个水平 α/m 的区间同时覆盖真值的概率 ≥ 1−α，故任一 CI 排除 0 而真效应为 0 的概率合计 ≤ α。∎

**工程含义**：kc_claim 把「统计显著性」从单条 claim 的口头声明升级为全论文族错误率控制；复现与证伪器进一步排除 p-hacking 与不可证伪声称。

### 定理 5（画像个性化联邦的泛化界）

**陈述**：设 n 个站点、维度 d、DP 预算 (ε,δ)、毒化比例 β，画像聚类误差 δ_cluster = max_i d(P_i, c(i))。PFP 输出本地先验 λ_i 满足
E‖λ_i − λ*_{P_i}‖ ≤ O( √(d/(n_i ε²)) + δ_cluster + β/ε )，
其中 n_i 为站点 i 的样本量，λ*_{P_i} 为画像 P_i 的最优先验。

**证明草图**：分簇 FedAvg 的 DP 噪声项为 √(d/(n_i ε²))；簇内非 IID 偏移被 δ_cluster 控制（因同一簇内画像距离 ≤ δ_cluster）；毒化项由 L2 裁剪使单站影响 ≤ clip/n_i，至多偏移 β·clip/ε。对比 v4 全局界 O(√(d/(nε²)) + D_div + β/ε)，PFP 用 δ_cluster 替代跨画像散度 D_div。∎

**个性化收益的充分条件**：若 δ_cluster < D_div − (√(d/n_i) − √(d/n)) 的常数项，则 PFP 的期望误差严格小于全局 FedAvg；当画像高度异构（D_div 大）且簇内较同质（δ_cluster 小）时收益最大。若 n_i 过小导致方差项反超，则退化为全局先验 + 收缩的本地偏移（partial pooling）。

### 定理 6（声称-证据演算的可靠性）

**陈述**：设 claim 集合按强度偏序 ⊑ 构成 DAG，supp(C) 为其证据支撑强度（证据项的合取上界）。若对每条 claim 有 strength(C) ⊑ supp(C) 且 kc_claim 通过，则论文的 claim 集合中不存在「强于其证据」的声称；在引理 44 的显著性控制下，整体声称以概率 ≥ 1−α 为真。

**证明**：对 claim DAG 作拓扑归纳。原子 claim 由 kc_claim 的 coverage 与 significance 直接保证；合取/引理组合 claim 的支撑为其子 claim 支撑的 meet，由归纳假设与 ⊑ 的传递性得 strength ⊑ supp。不可证伪或证据缺口对应 ⊥，被 fail-closed 拒绝。∎

### 定理 7（人格分层的外部效度证书）

**陈述**：设 K 个画像分层，损失 ∈ [0,1]，分层样本量 n_j。以概率 ≥ 1−δ，对所有 j 同时有 |R_j − R̂_j| ≤ √(log(2K/δ)/(2n_j))。若 PSEP 要求 max_j (R̂_j + √(log(2K/δ)/(2n_j))) ≤ R_max，则真实最差分层风险 max_j R_j ≤ R_max 以概率 ≥ 1−δ 成立。

**证明**：对每个分层用 Hoeffding 不等式并以 union bound 合并 K 个事件；worst-stratum 判据直接由逐层上界取最大得到。∎

**工程含义**：任何「总体平均提升」的经验 claim，只有在同时给出 worst-stratum 界时才被 kc_claim 接受；这直接对抗「平均掩盖少数画像失效」的过度声称。

### 定理 v5（三层集合的收缩关系与实时性保持）

**陈述**：在 v4 假设 (B1)~(B6) 及新增 (B7) 画像在评估窗内稳定、(B8) 证据 artifact 未被篡改下：
(i) Exec_cycle-v5 = Exec_CADVS-v4（控制环执行集不变，延迟零增量）；
(ii) Exec_Deploy-v5 ⊆ Exec_CADVS-v4，且若 kc_persona 非恒真则严格 ⊂；
(iii) Publishable-v5 ⊆ Exec_Deploy-v5，且若 kc_claim 非恒真则严格 ⊂；
(iv) 画像误分类的安全腐蚀由引理 43 线性界定；
(v) 个性化联邦误差由定理 5 界定；
(vi) 声称可靠性由引理 44 与定理 6 保证；
(vii) 外部效度由定理 7 保证。

**证明**：(i) v5 未在控制环路径上追加任何硬门；(ii)(iii) 由在部署/发表路径上追加合取项，路径集只缩不涨，非恒真保证严格性；(iv)~(vii) 分别由引理 43、定理 5、引理 44/定理 6、定理 7。∎

**诚实声明**：(B7) 画像稳定性在真实部署中未必成立（用户偏好会漂移、画像可能被错误推断）；(B8) 证据完整性依赖 artifact 供应链安全。价值/画像的「分层」本身是一种建模选择，可能把连续异质人群切成虚假的离散类别。缓解：画像采用连续嵌入 + 在线漂移检测；分层使用层次贝叶斯部分池化；证据使用内容哈希 + 第三方 artifact evaluation。

## 7. 本轮最大风险（最终确认）

**一句话**：**画像误分类与分层挑选（stratum cherry-picking）会让「可发表」与「真实安全」脱钩**——系统在纸面画像上通过 kc_persona 与 kc_claim，却对真实用户总体（尤其少数/边缘画像）不安全，而 claim ledger 反而为这种分层过拟合背书。
