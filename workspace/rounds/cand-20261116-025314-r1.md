# 第 10 轮（新灵感循环第 1 轮；本轮灵感：「指标体系」×「深度相机」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**先计量、后融合、再认证**。两个灵感分别治理 v9 的两处结构性债：语义债（六层指标只是分类清单，缺单位/聚合/溯源/版本/反 Goodhart 的体系性）与证据债（空间证书的 dist(s,O) 来自学习/累积管线，却没有任何独立的物理见证者）。所有新模块必须能整体摘除并严格退回 v9（引理 90）。

## 0. 直觉与动机

**灵感 1（指标体系 → 指标图的编译与治理）**
直觉：v8/v9 反复使用「M₀–M₃、M_dom、M_SLAM」六层指标，但这是一张**分类表**，不是一套**体系**：谁的单位是什么、聚合是否单调、同一指标是否被重复计权、代理指标被优化到失真时由谁兜底、指标定义换版后旧日志还能否复现——都没有回答。核心创新：**指标编译器（IndicatorCompiler, IC）**，把「任务约束 + 传感器清单 + 模块契约」编译成一张**带类型、带聚合算子、带中立元、带证据来源、带 Goodhart 守卫的指标有向无环图 Π**，并做六项静态检查（量纲、单调、无环、覆盖、防双计、双源独立），产出可签名、可回放的**指标清单（MetricManifest）**。指标体系因此从「论文里的一张表」变成「可编译、可审计、可版本化的对象」。

**灵感 2（深度相机 → 几何计量的独立见证者）**
直觉：v9 最大的风险是块证书依赖学习前向模型 F̂，而 Δ_dom 的 20 帧滑窗（400ms）滞后于真实突变。深度相机是系统里唯一**直接、非学习、米制尺度**的几何测量——它可以当 F̂ 的「物理对质者」。但深度不是真值：它异方差、长尾、在透明/反光/吸光表面结构化失效，且常以「无回波」出现。核心创新：**深度计量证书器（DepthMetrologyCertifier, DM）**：逐像素误差模型 σ̂(z)、共形分位数、valid/uncertain/invalid 三态掩码（**无回波绝不等于无障碍**）、飞点与多视角一致性检测、自运动重投影的延迟补偿；输出间隙的**下置信界 g_D** 而非点估计。

**灵感 3（两灵感乘积 → 证据独立与互证门控）**
直觉：把 F̂ 的间隙预测与深度的间隙 LCB 当作两路**独立证据**；当模型比深度更乐观时（单侧、危险方向），不必等 Δ_dom 抬头就立刻收缩块长。核心创新：**证据互证器（EvidenceCrossChecker, EC）**：ρ_ev 单侧分歧统计 + CUSUM 序列检验，触发 K_eff←1 与 β 膨胀。配合 IC 的「双源独立」静态检查，安全关键指标不再可能由单一传感器共模失效一次性打穿。

## 1. 研究问题（轮次升级版）

- **Q1（指标体系的可编译性）**：如何定义带类型/聚合/中立元/溯源的指标图 Π，使六层层级成为其保序嵌入？六项静态检查能否在部署期消除量纲错配、双计权与单源共模？
- **Q2（深度的计量可靠性）**：如何把异方差、长尾、结构化失效的深度误差转成有覆盖保证的间隙下界 g_D？「无效像素」如何以保守而非乐观语义进入证书？
- **Q3（证据独立与检测时延）**：在什么独立性度量 κ_ind 与单侧分歧统计下，EC 能在 1 帧深度（20ms）内发现前向模型乐观误差，而 v9 的 Δ_dom 需要 400ms？误报率如何由 CUSUM 的 ARL 控制？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 指标可编译律（Compile-the-Metrics, IC）**
每个指标声明 τ_v=(unit, range, dir)、聚合 ⊕_v、中立元 ν_v、证据来源 prov(v)、有效性 φ_v、Goodhart 守卫 G_v；全体构成有限无环图，六层层级保序嵌入。部署期六项静态检查全过才允许上线；运行期日志绑定 manifest 哈希。

**P14 深度计量律（Depth-as-Measurement, DM）**
深度读数一律先过计量层：逐像素 σ̂(z)、共形分位 q_{1−α}、valid/uncertain/invalid 三态掩码。只有 valid 像素可支撑下界；uncertain 计入惩罚 δ_unk；**invalid 不得解释为自由空间**。几何证书一律用 LCB g_D，不用点估计；时序做自运动重投影并计残差。

**P15 证据独立律（Evidence-Independence, EC）**
安全关键指标（M₀ 硬检查、SpatialCert、停车不变式）须 ≥2 条来源不重叠的证据路径（κ_ind ≥ κ_min）。模型相对深度「更乐观」（ρ_ev>0）是唯一危险方向，必须单侧门控：ρ_ev>θ_ev 或 CUSUM 超阈 ⇒ K_eff←1、β 膨胀、强制 M₀ 复核。

## 3. 与基线的接口（如何退化）

- EC 失效 ⇒ 关闭互证门控，K_eff 仅由 v9 的 Δ_dom/risk_SLAM 决定，等价 v9；
- DM 失效（掉线/无效率超阈/未标定）⇒ g_D 置为 +∞（不参与取小），β←β_v9，等价 v9 的纯模型证书；
- IC 失效 ⇒ 指标图退化为 v9 六层硬编码默认聚合，日志退回旧格式，等价 v9；
- AC 失效 ⇒ K_eff←1（v9 Level-1）；
- MW / ID / v8 三模块失效 ⇒ 逐级退回 v9 → v8 → v7 → v6（沿用 v9 链）。

## 4. 预期贡献

1. **指标图与指标清单**：把六层指标从分类表升级为可编译、可审计、可版本化的 DAG，附六项静态检查与反 Goodhart 守卫；
2. **深度计量证书**：异方差/结构化失效下的间隙下界，明确「无回波≠自由空间」的保守语义；
3. **证据互证门控**：以深度为独立见证者，把前向模型乐观误差的检测时延从 400ms 压到 20ms，直接给 v9 最大风险上保险；
4. **实验 E571–E590**：覆盖编译检查、Goodhart 注入、深度 LCB 覆盖、透明/反光失效、分歧时延、玻璃门场景、退化等价与长跑。

## 5. 本轮最大风险

**一句话**：深度相机恰恰在玻璃、镜面、深色吸光这些最危险的表面上大量返回 invalid/无回波，而指标体系若把「缺测」在任一聚合路径上默认为「无障碍」，则模型证书与深度证书会因**同一片缺失**而同时乐观——表面上满足「双源」，实则共享同一个盲区，P15 的证据独立被伪证。

## 1. 符号体系增量（定义 540–549）

| 符号 | 含义 |
|---|---|
| Π=(V,E) | 指标有向无环图：节点为指标，边为聚合依赖 |
| τ_v=(unit, range, dir) | 指标类型：量纲、值域、方向（+1 越大越好 / −1 越小越好） |
| ⊕_v, ν_v | 节点聚合算子与其中立元（x ⊕_v ν_v = x） |
| prov(v) ⊆ S∪M | 指标证据来源集（传感器/模块） |
| φ_v, G_v | 指标有效谓词与 Goodhart 守卫 |
| manifest = (Π, h) | 指标清单：Π 的规范化序列化 + 签名哈希 h |
| κ_ind(u,v) | 证据独立度：1 − \|prov(u)∩prov(v)\|/\|prov(u)∪prov(v)\| |
| σ̂(z), q_{1−α} | 深度逐像素误差尺度与共形分位（置信水平 1−α） |
| λ(u) ∈ {valid, uncertain, invalid} | 深度像素三态标签 |
| g_D(t) | 深度间隙下置信界（DepthClearanceLCB） |
| δ_unk, μ_inv | 不确定/无效像素惩罚项与无效占比 |
| ρ_ev(t) | 单侧证据分歧：模型比深度乐观的程度（标准化） |
| θ_ev, h_ev | 分歧瞬时阈与 CUSUM 判决阈 |
| χ_v ∈ [0,1] | 指标可信度（区别于指标值本身） |

**新增定义 540（指标图 Indicator DAG）** Π=(V,E) 为有限无环图。每个节点 v∈V 携带九元组
```
v = (id, τ_v, ⊕_v, ν_v, prov(v), φ_v, G_v, calib_v, layer_v)
```
其中 layer_v∈{M₀,M₁,M₂,M₃,M_dom,M_SLAM} 给出六层归属。边 (u→v) 表示 v 的取值依赖 u。约束：(a) 对边 (u→v) 有 unit(v)=agg_unit(⊕_v,{unit(u)})；(b) ⊕_v 在其输入偏序上单调；(c) 六层层级通过 layer 字段**保序嵌入**（若层 a 优先于层 b，则不存在从 b 到 a 的依赖边）。

**新增定义 541（指标清单 MetricManifest）** manifest=(canonical(Π), h=H(canonical(Π)))。规范序列化包含每个节点的九元组与全部守卫表达式；h 绑定到运行日志。任一次运行的全部指标可由 (manifest, 输入流) 确定性重放（引理 87）。指标定义换版 = 新 h，旧日志仍可按旧 manifest 重放——这是「指标体系」可审计性的硬要求。

**新增定义 542（证据独立度 Evidence Independence）** 对指标 u、v，
```
κ_ind(u,v) = 1 − |prov(u) ∩ prov(v)| / |prov(u) ∪ prov(v)|
```
v 为**双源安全指标** ⇔ 存在两个子节点 u₁,u₂ 使 κ_ind(u₁,u₂) ≥ κ_min 且 prov(u₁)∩prov(u₂)=∅。IC 对 M₀ 硬检查、SpatialCert、停车不变式强制要求双源；否则部署期拒绝上线。

**新增定义 543（Goodhart 守卫 Guard）** 代理指标 p 必须配对守卫 g，并声明守卫方向 ψ_g。若 p 改善且 g 相对基线恶化超过 τ_g 持续 T_g 周期，则判定 p 的改善为「疑似指标游戏」，将其从蒸馏归因（定义 537）中剔除，且不计入贡献证据。守卫本身必须是**不可被同一优化通道直接最大化**的量（如：任务进展的守卫是真实间隙下界与操作员接管率）。

**新增定义 544（深度计量模型 DepthMetrology）** 深度读数 z̃(u)=z(u)+ε(u)，ε 异方差且长尾。离线标定得到 σ̂(z)=a z²+b z+c 与 split-conformal 分位 q_{1−α}；在线按
```
λ(u) = valid      若 回波通过飞点/多视角/强度一致性检查
     = uncertain  若 置信度 ∈ [c_low, c_high) 或轻度不一致
     = invalid    若 无回波、飞点、透明/镜面/吸光判定、超量程
```
**语义纪律（P14）**：invalid 是「未知」，不是「自由」；unknown 区域一律按保守惩罚进入几何证书。

**新增定义 545（深度间隙下置信界 DepthClearanceLCB）**
```
g_D(t) = min_{p ∈ P_valid(t)} ( dist_lb(p, S_t) ) − δ_unk · 1[ μ_inv(t) > τ_inv ]
dist_lb(p, S_t) = (z̃_p − q_{1−α}·σ̂(z̃_p)) · cos θ_p − r_robot
```
其中 P_valid 为运动补偿后的有效点集，S_t 为机器人扫掠体，θ_p 为视线与表面法向夹角，r_robot 为机器人包络半径。g_D 是**下界**：噪声越大、无效越多，g_D 越小（越保守）。

**新增定义 546（证据分歧 EvidenceDisagreement）** 单侧、仅惩罚「模型更乐观」：
```
ρ_ev(t) = max( 0, (g_model(t) − g_D(t)) / (σ_model(t) + σ_D(t) + ε₀) )
```
σ_model 为块证书中的模型误差尺度（由 E554 标定），σ_D 为深度 LCB 的聚合误差。g_model ≫ g_D 时 ρ_ev 大，表示模型认为很安全而物理测量认为不安全。

**新增定义 547（互证门控 CrossCheckGate）** 在定义 539 之上追加：
```
K_eff(t) = 1                         若 ρ_ev(t) > θ_ev 或 CUSUM_ev(t) > h_ev 或 U_t 不成立
β_t      = β + λ·max(0, ρ_ev(t) − θ_ev)
CUSUM_ev(t) = max(0, CUSUM_ev(t−1) + ρ_ev(t) − θ_ev/2)
```
门控是单侧的：g_D ≫ g_model（深度更保守）不触发，只降低效率不损害安全。

**新增定义 548（指标可信度 MetricConfidence）** 每个指标 v 的可信度
```
χ_v = min( 源有效率, 标定新鲜度, 1 − 单源惩罚, 守卫健康度 )
```
其中单源惩罚在 κ_ind < κ_min 时为正；χ_v 是**独立于指标值**的一等输出。安全证书要求 χ_v ≥ χ_min，否则即使数值「好看」也按 v^⊥ 处理。这解决了「指标值正确但来源不可信」的隐性风险。

**新增定义 549（深度健康指标 DepthHealth）** h_D = (valid_ratio, temporal_consistency, latency_residual, baseline_drift) 作为 Π 中的一个节点，direction=−1（越低越好），其守卫为「invalid_ratio 突增」。h_D 进入分级告警与 DM 的 Level-0 判定，但**不单独承担安全认证**。

## 2. 形式化定义（要点与升级）

**定义 493（六层指标层级）** 继承 v8，但 v10 中六层是 Π 的 layer 标注：六层不再是并列清单，而是 Π 的保序分层（定义 540c）。
**定义 495/524（MetaWeight/情感，5 维）** 继承 v8 不变。
**定义 521（DA-OTL）** 继承 v8 不变；τᵢ(t) 在 K_eff>1 时以块证书替代逐层逐步复核。
**升级定义 496（软证书，v10）**
```
δ_trigger = {σ < τ_safe ∧ γ_grasp valid ∧ Δ_dom < τ_dom ∧ risk_SLAM < τ_SLAM
             ∧ Ĉ_t valid ∧ g_D ≥ d_safe ∧ χ_{M0} ≥ χ_min}
```
块证书失效、深度下界不足与单步条件同样触发 M₀ 硬检查；无「块内软通过硬失」空洞（引理 82+88+89 联合）。
**升级定义 531（软硬约束衔接）** M₀ 判据增加深度入口：g_D < d_safe 或 ρ_ev 越阈 ⇒ 立即切换中止点或安全停驻，不等块边界，也不等 Δ_dom 滑窗。
**升级定义 533（块证书）** Ĉ_t=(ĝ_min, ê_max, γ̂_grasp) 的间隙项改为
```
ĝ_min = min( min_{k≤K} F̂_clearance(s,a^{1:k}) − β_t , g_D(t) )
```
深度 LCB 与模型下界取小——单侧保守，任一来源悲观即悲观。

## 3. 关键算法骨架

```python
# IP-357 IndicatorCompiler：指标编译器
@dataclass
class Indicator:
    id: str; unit: str; rng: tuple; direction: int      # +1 good-up / -1 good-down
    agg: str                                            # 'min','max','wsum','and','prod'
    neutral: object                                     # ν_v
    provenance: set                                     # 传感器/模块 id
    valid: Callable; guard: Optional[str]; calib: Optional[str]
    layer: str                                          # M0..M_SLAM

class IndicatorCompiler:
    CHECKS = ('unit', 'monotone', 'acyclic', 'coverage',
              'no_double_count', 'independence')

    def compile(self, task, sensors, contracts):
        Pi = self._build(task, sensors, contracts)
        for chk in self.CHECKS:
            getattr(self, f'_check_{chk}')(Pi)
        self._check_layer_embedding(Pi)                 # 定义 540(c)
        manifest = MetricManifest(canonical(Pi),
                                  H(canonical(Pi)), version=task.version)
        self._emit_runtime(Pi)                          # 生成聚合执行器
        return Pi, manifest

    def _check_unit(self, Pi):
        for v in Pi.topo():
            for u in Pi.parents(v):
                if not compatible(unit(u), v.agg, v.unit):
                    raise CompileError(f'量纲错配 @{u.id}->{v.id}')

    def _check_monotone(self, Pi):
        for v in Pi.topo():
            if not is_monotone(v.agg, v.direction):
                raise CompileError(f'聚合非单调 @{v.id}')

    def _check_no_double_count(self, Pi):
        # 同一叶指标不得在同一条 wsum 路径被计权两次
        for root in Pi.roots():
            counts = defaultdict(int)
            for leaf, w in Pi.weighted_paths(root):
                counts[leaf] += 1
            if any(c > 1 for c in counts.values()):
                raise CompileError(f'双计权 @{root.id}')

    def _check_independence(self, Pi):
        for v in Pi.safety_critical():                  # M0/SpatialCert/停车不变式
            kids = Pi.children(v)
            if not any(k1.provenance.isdisjoint(k2.provenance)
                       for k1, k2 in combinations(kids, 2)):
                raise CompileError(f'{v.id} 单源共模风险')

    def _check_coverage(self, Pi):
        for c in self.task.constraints:
            if not Pi.covers(c):                        # 每条约束至少一条指标路径
                raise CompileError(f'约束未覆盖 {c.id}')

    def _check_acyclic(self, Pi):
        if has_cycle(Pi): raise CompileError('指标图含环')
```

```python
# IP-358 DepthMetrologyCertifier：深度计量证书器
class DepthMetrologyCertifier:
    def __init__(self, calib, alpha=0.01, tau_inv=0.15,
                 delta_unk=0.10, tau_stereo=0.02):
        self.sigma = calib.sigma_fn                 # σ(z)=a z^2+b z+c
        self.q = calib.conformal_quantile(1 - alpha)
        self.tau_inv, self.delta_unk = tau_inv, delta_unk
        self.tau_stereo = tau_stereo

    def classify(self, D, intensity, stereo_res):
        flying = local_gradient_inconsistent(D)                # 飞点
        transp = transparent_like(intensity, stereo_res)       # 透明/镜面/吸光
        valid = D.in_range & ~flying & ~transp & (stereo_res < self.tau_stereo)
        uncertain = ~valid & (D.confidence >= self.c_low) & ~transp
        invalid = ~valid & ~uncertain
        return valid, uncertain, invalid

    def clearance_lcb(self, D, mask, robot_swept,
                      pose_prev, pose_now, t):
        D_now = motion_compensate(D, pose_prev, pose_now)      # 延迟重投影
        pts = backproject(D_now, mask.valid)                   # 仅 valid 支撑下界
        if len(pts) == 0:
            return DepthCert(g_lcb=-inf, sigma_agg=inf,
                             mu_inv=1.0, stamp=t)            # 无有效点 ⇒ 不认证
        sigma = self.sigma(D_now.valid)
        dist = min_clearance(pts, robot_swept)
        g_valid = float(np.min(dist - self.q * sigma))         # 定义 545
        mu_inv = mask.invalid.mean()
        penalty = self.delta_unk if mu_inv > self.tau_inv else 0.0
        return DepthCert(g_lcb=g_valid - penalty,
                         sigma_agg=robust_agg(sigma), mu_inv=mu_inv,
                         latency_res=reproj_residual(D, pose_prev, pose_now),
                         stamp=t)
```

```python
# IP-359 EvidenceCrossChecker：证据互证器
class EvidenceCrossChecker:
    def __init__(self, theta_ev=1.5, h_ev=5.0, lam=0.5,
                 tau_inv=0.15, eps0=1e-6):
        self.theta_ev, self.h_ev, self.lam = theta_ev, h_ev, lam
        self.tau_inv, self.eps0 = tau_inv, eps0
        self.cusum = 0.0

    def update(self, g_model, sigma_model, depth_cert):
        if depth_cert is None or depth_cert.mu_inv > self.tau_inv:
            return GateResult(K=1, beta_inflate=self.lam,
                              reason='depth_invalid')          # Level-0
        rho = max(0.0, (g_model - depth_cert.g_lcb) /
                  (sigma_model + depth_cert.sigma_agg + self.eps0))
        self.cusum = max(0.0, self.cusum + rho - self.theta_ev / 2)
        if rho > self.theta_ev or self.cusum > self.h_ev:
            return GateResult(K=1,
                              beta_inflate=self.lam * max(rho, 1.0),
                              reason='model_optimistic')
        return GateResult(K=None, beta_inflate=0.0, reason='agree')
```

## 4. 推导

**引理 87（指标图良构性与可复现性）** 若 Π 通过六项静态检查，则 Π 为有限 DAG，每个节点的量纲唯一、聚合单调、无重复计权路径，且六层层级保序嵌入。故运行时任一指标值可由 (manifest, 输入流) 确定性重放。证明：对拓扑序归纳；量纲检查保证每节点聚合类型合法；单调检查保证证书在下游可组合；无环与无环路径唯一保证求值良定义；manifest 绑定规范序列化，输入相同则求值树相同。∎

**引理 88（深度 LCB 的覆盖保证）** 设校准集与测试同分布（可交换），σ̂ 与 q_{1−α} 由 split-conformal 得到。则对 valid 像素，P(dist_true ≥ dist_lb) ≥ 1−α。若无效占比 μ_inv 且 unknown 区域最大可观跨度 L_unk，则
```
P(g_true ≥ g_D) ≥ 1 − α − μ_inv·L_unk
```
且 g_D 的偏差方向恒为保守（偏小）。证明：valid 点由共形覆盖给出单点界，对 |P_valid| 取 min 用 union bound；unknown 区域以 δ_unk·1[μ_inv>τ_inv] 计惩罚，最坏情况下每个无效像素可隐藏 L_unk 的间隙，合并得第二式。∎

**引理 89（互证门控的检测时延与安全性）** 设模型乐观误差 e_F=g_model−g_true>0 且深度有效。则每帧 ρ_ev ≥ (e_F−qσ_D)/(σ_model+σ_D+ε₀)。当 e_F > θ_ev(σ_model+σ_D+ε₀)+qσ_D 时，EC 在 1 个深度帧内触发 K_eff=1；由 v9 引理 82（β 已按定义 547 膨胀）该步与逐步执行安全等价。检测时延 ≤ τ_depth+τ_guard ≈ 20.3ms，v9 的 Δ_dom 需 20 帧 ≈ 400ms。CUSUM 在 H₀ 下的平均运行长度 ARL₀ ≥ e^{h_ev}（近似），故误报受控。∎

**引理 90（v10→v9 严格退化）** (i) IC 关闭 ⇒ Π 塌缩为 v9 六层硬编码与默认聚合（保序嵌入的逆）；(ii) DM 关闭 ⇒ 令 g_D=+∞，定义 533 的 min 退化为 g_model，β←β_v9，K_eff 仅由定义 539 决定；(iii) EC 关闭 ⇒ ρ_ev 门控失效，K_eff 仅由定义 539/547 的其余项决定。故 v10 的任一降级状态的可观测行为 ∈ v9 退化格点，安全性由引理 82–86 传递成立。∎

**引理 91（反 Goodhart 守卫的检测界）** 设代理 p 与守卫 g 满足：任何以牺牲 g 换取的 p 改善都使 g 单调下降。则此类改善在 g 跌破 τ_g 后 ≤ T_g 周期内被标记；被标记改善按定义 543 不计入蒸馏归因，故不会把「指标游戏」误判为模块贡献。证明：由单调性与持续性判据直接得检测时延上界；归因剔除由定义 537 的守卫过滤保证。∎

**引理 92（证据移除的单调保守性）** 在 Π 上以中立元 ν_v 移除任一证据（或令 g_D=+∞），对安全方向统一（direction=−1 且聚合为 min/∧）的安全下界单调不增；即「去掉证据」不会制造虚假安全。证明：min 与 ∧ 对新增/移除输入分别是单调不增/不增的；中立元满足 x⊕ν=x，移除即回到更弱信息集，下界只能变松（更保守）。∎
