### 第 1 轮灵感驱动研究记录（新循环 · 继承 CADVS-v7）

**灵感词**：可用性评估、数据标注

**继承关系**：上一循环第 7 轮 CADVS-v7（IP-501~IP-504）以 DIM/DRC/DAC 把系统从「指令响应」推进到「需求意图推导」，在七硬门 kc_evidence_forged_v5 之外加入 η_demand/η_affect 软因子，并新增 kc_demand。v7 把「系统该做什么」讲清楚了，却默认了两个从未被审计的前提：**(i) 所有门与阈值所依赖的标签是可信的**——可它们来自人手的「数据标注」；**(ii) 被服务的人会正确使用系统**——可这需要「可用性评估」来证明。本轮回到证据链的两个源头——**标签从哪来（供给端）** 与 **人能不能用对（需求端）**，提出「**标注-可用性双证书**」(Annotation–Usability Dual Certificate)，升级为 EFA-v8。核心原则：**证书的可信度不得超过其标注证据的可信度；不可用的系统即使可解释也不得自治。**

**直觉与动机**：

1. **数据标注 → 从「标签是事实」到「标签是带方差的证据」**。七硬门的阈值 τ_i、软因子的标定、乃至「安全/不安全」的训练目标，全都是在标注数据上拟合出来的。但标注不是 oracle：多个标注者对同一「是否可抓取/是否可接受」会分歧，标注规范本身也可能含混。关键洞见是：**不要把标签当成标量真值，而要把它当成后验分布**——用标注者混淆矩阵（Dawid–Skene 类标签模型）估计每个标签的置信度 η_annot，并把「标注可用性」量化成规范可靠性 U_rub。当分歧超过 α_min，标签在证书意义上「不可用」，系统必须拒绝用它签发证书，而不是继续拟合。

2. **数据标注 → 从「全量标注」到「在安全边界上标注」**。标注是稀缺、昂贵且带偏的资源。既然证书只在阈值附近才「薄」，就没有必要对远离决策边界的样本做精细标注。关键洞见是：**把标注预算花在证书裕度最薄处**——用主动标注（按裕度与区间宽度加权的采集函数）优先标注边界样本，使有限的标签最大化地缩小证书的不确定区间。这把「数据标注」从离线苦工变成安全闭环的一部分。

3. **可用性评估 → 从「离线准确率」到「在线人因证书」**。准确率不等于可用：一个回退路径即使可解释，如果用户看不懂、来不及接管、或被迫反复澄清，系统在真实部署里仍然不安全。关键洞见是：**可用性是可被认证的系统属性**——按 ISO 9241-11 的 effectiveness / efficiency / satisfaction 三轴，加上「有害干预率」与「回退恢复时间」，构造在线可用性评分 U_sys，作为自治准入的硬条件。

4. **可用性评估 → 从「事后报告」到「准入硬闸」**。传统可用性评估是发布后的报告，无法阻止危险部署。本轮把它前置为 kc_usability：当 U_sys 不达标时，系统只允许影子模式或遥操作，禁止自动执行。关键洞见是：**「人用不对」应被视为与「轨迹不安全」同等级的 fail-closed 触发条件**。

**关键洞见**：第 7 轮回答「系统该做什么」；本轮回答「**系统凭什么相信它的证据，以及人凭什么敢用它**」。七硬门 kc_evidence_forged_v5 与 v7 的 kc_demand 记号原样复用；本轮新增的只有：
- IP-505 AUQ（标注可用性量化器，标签模型 + 规范可靠性），
- IP-506 CEP（证书证据传播器，保形区间 + 下界判定），
- IP-507 UEL（可用性评估闭环，在线人因评分 + 边界主动标注），
- IP-508 EFA-v8（风险单调软因子链 + 标注闸 kc_annot + 可用性闸 kc_usability）。

**形式化目标（增量）**：

1. **AUQ（Annotation Usability Quantifier）**：<br>
   - 标注集 D = {(x_i, y_i^{(1)},…,y_i^{(J)})}，标签模型 p(y_i | y_i^{(1:J)}, x_i) 由各标注者混淆矩阵 π_j 推断；<br>
   - 标注置信度：η_annot,i = 1 - H(p(y_i | ·))/log C ∈ [0,1]；<br>
   - 规范可用性：U_rub = g(α_Krippendorff, κ_Cohen, 标注时延, 澄清率) ∈ [0,1]；<br>
   - 可用性硬闸：kc_annot 要求 U_rub ≥ α_min 且 min_i η_annot,i ≥ τ_annot，否则该批标签不得用于证书标定。

2. **CEP（Certificate Evidence Propagator）**：<br>
   - 每个学习型软因子得分 s_j(x) 配一个分割保形区间 [s_j^- (x), s_j^+ (x)]，覆盖率 ≥ 1 - α_cp（交换性假设下）；<br>
   - 硬门改用**下界**判定：s_j^-(x) ≥ τ_j^v8，而非点估计；<br>
   - 标注噪声经标签后验进入残差，得到「标注感知」的保守分位数。

3. **UEL（Usability Evaluation Loop）**：<br>
   - 在线可用性：U_sys = w_e·E_eff + w_f·(1 - T_norm) + w_s·(SUS/100) - w_h·H_harm，各权重非负、和为 1；<br>
   - 可用性硬闸 kc_usability：U_sys ≥ τ_usa 且 有害干预率 ≤ h_max 且 回退恢复时间 ≤ T_rec；<br>
   - 主动标注：采集分数 a(x) = w(x)·1[μ(x) < μ_0] / cost(x)，其中 μ(x) = min_j (s_j(x) - τ_j) 为证书裕度，w(x) 为区间宽度；预算 B 下按 argmax a(x) 选批。

4. **EFA-v8（风险单调软因子链 + 双闸）**：<br>
   - **修正 v7 缺陷**：v7 直接乘 η_i（η_affect 可低至 2/3），会把阈值「越乘越低」、放松 fail-closed；v8 把每个软因子转成风险 r_i = 1 - s_i，用倍率 m_i = (1+ε_max)^{w_i·r_i}；<br>
   - 则 Π_i m_i = (1+ε_max)^{Σ_i w_i r_i} ∈ [1, 1+ε_max]，默认 ε_max = 0.3，恒 ≤ 1.3；<br>
   - 阈值：τ_j^v8 = γ_j·τ_j^v7·(Π_i m_i)·(1 + w_annot·r_annot) ≥ τ_j^v7，只升不降；<br>
   - 排序分数：ECS_v8 = ECS_v7 · Π_i (1 - δ_i·r_i) · (1 - δ_a·r_annot)，仅用于排序、不放松硬门。

5. **形式化定义（双证书）**：给定轨迹 x、标注证据 D、在线可用性证据 U：<br>
   - 安全子证书：∀j，s_j^-(x) ≥ τ_j^v8（阈值含标注风险倍率）；<br>
   - 标注子证书：kc_annot(D) = 1；<br>
   - 可用性子证书：kc_usability(U) = 1；<br>
   - 仅当三子证书同时成立才执行 x；任一不成立则依次退化为「回退 v7 保守提议 → 影子/遥操作 → 拒绝」。

**本轮最大风险**：**「标注与可用性可被可靠测量」的假设**——标签模型假设标注者误差独立同分布，但真实标注受经济激励、制度压力与规范歧义共同塑造（可能是系统性偏差而非随机噪声），可用性评分也可能被优化目标反向「刷分」；于是证书可以在数学上自洽、却在被错误定义的标签上「自信地正确」，而 fail-closed 仍只对错误的分布守门。

## 2. 关键算法骨架

### IP-505 AUQ：标注可用性量化器

```python
@dataclass
class AnnotationUsabilityQuantifier:
    """AUQ：把『标签』变成『带置信度的证据』，并判断这批标注是否可用。
    输入：标注集 D；输出：η_annot[i]、U_rub、kc_annot。"""
    num_classes: int = 2
    tau_annot: float = 0.8
    alpha_min: float = 0.67

    def fit_label_model(self, D):
        """Dawid–Skene EM：估计每个标注者的混淆矩阵 π_j 与真值后验。"""
        pi = self._init_confusions(D)                     # J×C×C
        for _ in range(self.max_iter):
            post = self._e_step(D, pi)                    # N×C 真值后验
            pi = self._m_step(D, post)                    # 更新混淆矩阵
        return post, pi

    def annot_confidence(self, post) -> torch.Tensor:
        """η_annot,i = 1 - H(p_i)/log C，归一化到 [0,1]。"""
        H = -(post * torch.log(post + 1e-8)).sum(dim=-1)
        return 1.0 - H / math.log(self.num_classes)

    def rubric_usability(self, D, eta_annot) -> float:
        """规范可用性：一致性为主，时延与澄清率为辅。"""
        alpha_K = krippendorff_alpha(D, level="nominal")
        kappa = cohen_kappa(D) if D.has_two_annotators else alpha_K
        t_norm = normalize(D.annot_time, ref=REF_TIME)
        c_norm = normalize(D.clarify_rate, ref=REF_CLARIFY)
        U = 0.5 * max(0.0, alpha_K) + 0.2 * max(0.0, kappa) \
            + 0.15 * (1 - t_norm) + 0.15 * (1 - c_norm)
        return float(min(1.0, max(0.0, U)))

    def gate(self, D):
        post, _ = self.fit_label_model(D)
        eta = self.annot_confidence(post)
        U_rub = self.rubric_usability(D, eta)
        kc_annot = (U_rub >= self.alpha_min) and (eta.min().item() >= self.tau_annot)
        return {"eta_annot": eta, "U_rub": U_rub, "kc_annot": kc_annot}
```

### IP-506 CEP：证书证据传播器（保形下界）

```python
@dataclass
class CertificateEvidencePropagator:
    """CEP：把点估计软因子换成保形区间，并用下界做硬门判定。
    关键：证书只用『在标注不确定性下仍然成立』的那部分。"""
    alpha_cp: float = 0.1

    def calibrate(self, scorer, calib_loader):
        """分割保形：在标注校准集上收集非一致性分数。"""
        scores = []
        for x, y, eta in calib_loader:
            pred = scorer(x)
            # 标注感知残差：低置信标签给出更宽的残差
            scores.append((pred - y).abs() / max(eta, 1e-3))
        n = len(scores)
        k = math.ceil((n + 1) * (1 - self.alpha_cp))
        self.q = torch.quantile(torch.tensor(scores), min(1.0, k / n))
        return self.q

    def interval(self, scorer, x, eta_annot: float):
        """输出 [s^-, s^+]，低置信样本区间更宽。"""
        s = scorer(x)
        half = self.q * max(eta_annot, 1e-3)
        return float(s - half), float(s + half)

    def gate_lower_bound(self, s_lo: float, tau: float) -> bool:
        """硬门判定改用下界：只有保守成立才算通过。"""
        return s_lo >= tau
```

### IP-507 UEL：可用性评估闭环（在线评分 + 边界主动标注）

```python
@dataclass
class UsabilityEvaluationLoop:
    """UEL：在线人因评分 U_sys + 把标注预算投向证书最薄处。"""
    w_e: float = 0.4
    w_f: float = 0.2
    w_s: float = 0.2
    w_h: float = 0.2
    tau_usa: float = 0.7
    mu_0: float = 0.05

    def usability_score(self, log) -> float:
        E_eff = log.completed_without_harm / max(log.attempts, 1)
        T_norm = normalize(log.task_time, ref=log.time_budget)
        SUS = log.sus_score / 100.0
        H_harm = log.harmful_interventions / max(log.attempts, 1)
        U = self.w_e * E_eff + self.w_f * (1 - T_norm) \
            + self.w_s * SUS - self.w_h * H_harm
        return float(min(1.0, max(0.0, U)))

    def kc_usability(self, log) -> bool:
        U = self.usability_score(log)
        return (U >= self.tau_usa
                and log.harm_rate <= log.h_max
                and log.recovery_time <= log.T_rec)

    def acquisition_score(self, x, cep, scorers, taus, cost) -> float:
        """a(x) = 宽度 × 是否贴近边界 / 成本。"""
        intervals = [cep.interval(s, x, eta_annot=1.0) for s in scorers]
        widths = [hi - lo for lo, hi in intervals]
        margins = [lo - tau for (lo, _), tau in zip(intervals, taus)]
        near_boundary = 1.0 if min(margins) < self.mu_0 else 0.0
        return max(widths) * near_boundary / max(cost, 1e-6)

    def select_batch(self, pool, budget, **kw):
        ranked = sorted(pool, key=lambda x: self.acquisition_score(x, **kw),
                        reverse=True)
        return ranked[:budget]
```

### IP-508 EFA-v8：风险单调软因子链 + 双前置闸

```python
@dataclass
class EvidenceForgingAssemblerV8:
    """EFA-v8：kc_annot ∧ kc_usability 前置；软因子链只收紧（风险加权幂律）。"""
    v7: EvidenceForgingAssemblerV7
    auq: AnnotationUsabilityQuantifier
    cep: CertificateEvidencePropagator
    uel: UsabilityEvaluationLoop
    eps_max: float = 0.3
    w_annot: float = 0.2

    def select(self, L, t_now, context):
        # 0. 系统级双前置闸：标注证据是否可用、人是否用得了
        ann = self.auq.gate(context.annotation_batch)
        if not ann["kc_annot"]:
            return False, None, "KC_ANNOT_FAILED"
        if not self.uel.kc_usability(context.usage_log):
            return False, None, "KC_USABILITY_FAILED"

        # 1. v7 先给出候选（需求意图、七硬门不变）
        ok, x, reason = self.v7.select(L, t_now, context)
        if not ok:
            return False, None, reason

        # 2. 计算每个软因子的风险与单调倍率
        s = self._soft_factor_margins(x, context)          # dict name->[0,1]
        r = {k: 1.0 - v for k, v in s.items()}
        weights = self._risk_weights(r)                     # Σ w ≤ 1
        m = {k: (1 + self.eps_max) ** (weights[k] * r[k]) for k in r}
        prod_m = 1.0
        for v in m.values():
            prod_m *= v
        annot_mult = 1.0 + self.w_annot * self._annot_risk(ann)
        # 单调性：prod_m ∈ [1,1.3]，annot_mult ∈ [1,1.2]
        taus = {k: self._tau_v7(k) * prod_m * annot_mult for k in s}

        # 3. 用保形下界重新判定硬门（证据传播）
        for k, (scorer, tau) in self._learned_gates(context).items():
            lo, _ = self.cep.interval(scorer, x, ann["eta_annot"].mean().item())
            if not self.cep.gate_lower_bound(lo, taus[k]):
                return False, None, f"CEP_GATE_FAILED:{k}"

        # 4. 仅排序用的软评分，不放松任何硬门
        ecs = self.v7.ecs_v7(x, context.n_flow, context.s_emo, self._eta_dict(s))
        ecs *= 1.0
        for k in r:
            ecs *= (1.0 - self._delta(k) * r[k])
        ecs *= (1.0 - 0.2 * self._annot_risk(ann))
        return True, x, "FORGED_CGE_V8"

    def _annot_risk(self, ann) -> float:
        return 1.0 - float(ann["U_rub"] * ann["eta_annot"].mean())
```

### 集成流水线（v7 → v8）

```
离线 / 慢时域：
  标注采集 → AUQ 估计 π_j、η_annot、U_rub
  若 kc_annot 失败：退回重标 / 修订规范 / 缩小标签适用范围（fail-closed on labels）
  CEP 在校准集上拟合保形分位数 q_j（按 η_annot 加权残差）
  阈值标定：τ_j^v8 = γ_j τ_j^v7 · (Π m_j) · (1 + w_annot r_annot)，只升不降
  主动标注：UEL.select_batch 按 a(x) 选边界样本，优先补标

在线准入（亚秒级）：
  kc_annot(D) ∧ kc_usability(U) ── 不通过 ──▶ SHADOW / TELEOP / 拒绝
        │通过
        ▼
  EFA-v7 在线流程（DIM/DRC/DAC + 七硬门）产生候选 x
        ▼
  CEP：对学习型软因子取保形下界 s^-，按 τ_j^v8 判定
        ▼
  通过 ──▶ 执行；失败 ──▶ v7 保守回退 ──▶ 影子/遥操作
```

## 4. 正确性论证（增量更新）

### 定理 13（标注-可用性单调性 / 执行集只收缩）

**陈述**：设每个软因子得分 s_j ∈ [0,1]、风险 r_j = 1 - s_j、权重 w_j ≥ 0 且 Σ_j w_j ≤ 1、ε_max = 0.3，令 m = (1+ε_max)^{Σ_j w_j r_j}，标注倍率 a = 1 + w_annot·r_annot（w_annot=0.2, r_annot ∈ [0,1]）。则：
- m ∈ [1, 1.3]，a ∈ [1, 1.2]，故 τ_j^v8 = γ_j τ_j^v7·m·a ≥ τ_j^v7；
- 硬门改用保形下界 s_j^- ≤ s_j 后，判定 s_j^- ≥ τ_j^v8 ⇒ s_j ≥ τ_j^v7；
- 因此 Exec_CADVS-v8 ⊆ Exec_CADVS-v7（软因子与标注只收紧，不放松）。

**证明**：m 关于每个 r_j 单调不减，且 Σ w_j r_j ≤ Σ w_j ≤ 1，故 m ∈ [1,(1+ε_max)] = [1,1.3]；a 同理 ∈ [1,1.2]。τ_j^v8 ≥ τ_j^v7 直接由乘子 ≥ 1 得。又 s_j^- ≤ s_j，若 s_j^- ≥ τ_j^v8 ≥ τ_j^v7 则 s_j ≥ τ_j^v7，故任何通过 v8 的轨迹必通过 v7 的同名门；其余门不变，执行集包含关系成立。∎

### 定理 14（标注感知保形覆盖率）

**陈述**：设校准样本与测试样本可交换（exchangeable），非一致性分数 S_i = |s(x_i) - y_i|/η_annot,i 在两者同分布。取 q 为校准集上 ⌈(n+1)(1-α_cp)⌉/n 分位数，则对新的测试点 x，
P(y ∈ [s(x) - q·η_annot, s(x) + q·η_annot]) ≥ 1 - α_cp。

**证明**：令 E_i = S_i，则 {E_i} 可交换，标准分割保形（split conformal）论证给出 P(E_{n+1} ≤ q) ≥ 1 - α_cp；而 E_{n+1} ≤ q ⇔ |s(x)-y| ≤ q·η_annot ⇔ y 落入区间。∎

**推论**：在覆盖率 ≥ 1-α_cp 下，凡满足 s^- ≥ τ 的判定，其真实得分以至少 1-α_cp 的概率不低于 τ，即「保守通过」是可证的。

### 命题 15（边界主动标注的效率，启发式）

**陈述（非严格保证）**：在证书裕度 μ(x) < μ_0 的边界样本上标注，其期望区间宽度缩减量正比于 w(x)，因此按 a(x) = w(x)·1[μ<μ_0]/cost 选批，比均匀采样更快把边界处的保形分位数 q 压低到目标 ε。

**直觉与限定**：区间宽度由 q·η_annot 决定，而 q 是残差分位数；边界样本的残差对 q 的贡献最大，故优先标注边界能更有效地降低 q。但该结论依赖「边界样本可被准确识别」与「标注噪声不随位置系统变化」，后者在真实数据上常被违反，故仅作为采集策略的启发式，不作安全保证。

### 诚实声明

- **标签模型是假设，不是事实**：Dawid–Skene 假设标注者误差条件独立，真实标注常存在相关偏差（同一培训、同一激励），此时 η_annot 会被高估；缓解是分层估计混淆矩阵并做敏感性分析，但无法根除。
- **一致性 ≠ 正确性**：α_K 高只说明标注者彼此一致，不说明规范正确；一批「一致地错」的标注会同时通过 kc_annot 并污染阈值。
- **保形覆盖率依赖交换性**：部署分布漂移会破坏定理 14 的前提；本轮把漂移检测留给后续轮次，暂以「部署期定期重标定 + 覆盖率在线监控」缓解。
- **可用性评分可被博弈**：若 U_sys 成为优化目标，团队可能通过降低任务难度或筛选用户来「刷分」；缓解是把有害干预率 H_harm 设为不可交易的硬项，并做盲评与外部审计。
- **计算与标注成本**：AUQ 的 EM 与 α 计算是离线开销；主动标注会改变数据分布（选择偏差），需在训练时用重要性加权校正。

## 5. 实验设计与验证计划（仿真 → 实机）

### 5.1 实验设计（MuJoCo 3.x + MJX + 人因实验）

- **平台**：UR10e（6DOF）+ 移动底盘（2DOF）+ 摄像头 + 标注平台（J=3 标注者/样本）。
- **数据与标注**：
  - 从 v7 的 10k 条交互日志中抽取 2k 条作为标注池；
  - 注入可控标注噪声：随机噪声（ε∈{0.05,0.1,0.2}）与相关偏差（同一标注者偏好）；
  - 用 AUQ 估计 η_annot、U_rub，并检验 kc_annot 的拒绝率是否符合预期。
- **对照**：v7-full、v8-full、消融 A21（去掉 AUQ/kc_annot）、A22（去掉 CEP 下界，改回点估计）、A23（去掉 kc_usability）、A24（主动标注改均匀采样）、A25（用 v7 的乘积式软因子链）。
- **场景**：
  - (a) 标签噪声：在 20% 随机噪声下测「错误接受率」（把不安全轨迹判为安全）；
  - (b) 相关偏差：单一标注者主导时，AUQ 是否能识别 U_rub 下降并拒绝签发证书；
  - (c) 边界标注：固定预算 B=200，比较主动标注与均匀采样的保形区间宽度与错误接受率；
  - (d) 可用性：20 名用户完成「监督—接管—恢复」任务，测 SUS、完成率、恢复时间、有害干预；
  - (e) 可用性闸：故意给一个「可解释但难用」的回退 UI，验证 kc_usability 是否阻断自治。
- **指标**：
  - 安全性：错误接受率、保形经验覆盖率、执行集大小；
  - 标注：η_annot 校准误差（ECE）、U_rub 与真实标注错误的相关系数、达到目标区间宽度所需标签数；
  - 可用性：SUS、完成率、恢复时间、有害干预率；
  - 实时性：在线增量 P99。

## 7. 本轮最大风险（最终确认）

**一句话**：**「标注与可用性可被可靠测量」的假设**——标签模型假设标注误差独立同分布，但真实标注受经济激励、制度压力与规范歧义共同塑造（可能是系统性偏差而非随机噪声），可用性评分也可能被反向「刷分」；于是证书可以在数学上自洽、却在被错误定义的标签上「自信地正确」，而 fail-closed 仍只对错误的分布守门。
