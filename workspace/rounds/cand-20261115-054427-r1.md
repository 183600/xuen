# 第 4 轮（灵感循环第 4 轮；本轮灵感：「扩散策略」×「多端口部署」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。扩散策略只升级「候选探测轨迹如何生成」，多端口只升级「同一策略如何被多个执行端共享」；任一环节不可重放、不可支撑、不可隔离或覆盖失效，都必须能一键退回 InstructGauge（确定性单端口分块），再退回 ToolGauge / LeanGauge / MODGAUGE。随机性与并发是增强项，不是依赖项。

## 0. 直觉与动机

**灵感 1（扩散策略 → 把「探测计划」从单点回归变成多模态采样）**
直觉：盲区修复的本质往往不是「算一个最优动作」，而是「在若干互相竞争的物理解释之间做区分」——反光、透明层、遮挡、深腔，各自最优的探测轨迹很可能完全不同。回归式策略会把多种解释平均成一条「谁都不像」的轨迹；扩散策略从噪声逐步去噪，天然保留多模态，一条策略可同时给出「上偏振」「换角度」「加结构光」几族候选。代价同样直接：**采样是随机的、迭代的、昂贵的**，同一条策略在不同硬件后端上未必产生同一条轨迹。因此在计量系统里，扩散策略的第一性问题不是「生成得像不像」，而是「**这条轨迹能否被重放、能否被物理支撑、能否被安全否决**」。这就把问题从模型能力转向证据学：没有采样证书的轨迹只是探索，不是计量证据。
**严谨化方向**（产物区定义 450–455）：用带约束的去噪算子把终态投影到端口可采纳集 `𝔸_adm^p`，用模式支撑检验剪除无回执支撑的「幻觉模式」，用采样证书与种子账本把随机性钉成可重放记录。

**灵感 2（多端口部署 → 并行吞吐，但状态是真正的风险面）**
直觉：同一套策略部署到 M 个端口（边缘盒子、云端副本、不同机械臂/传感器）可以并行探测、共享经验、互为备份。但端口之间共享的是**模型先验**，绝不能共享的是**可变状态**：每个端口的物理包线、工具集、校准层、契约代际、回执与预算都不同。天真地「全局单例」会让一个端口的漂移污染另一个端口的校准；天真地「完全独立」又拿不到舰队级学习与舰队级覆盖保证。正确口径是：**读隔离 + 显式且钉住代际的共享 + 舰队级同时覆盖**——共享只经由不可变全局先验 `𝔾_g`，任何跨端口迁移必须过兼容性证书。
**严谨化方向**（定义 448/449/456/457/458–462）：端口隔离不变式限制读集；代际两阶段提交禁止同一次决策看到混合契约；舰队同时共形覆盖把「每端口 1−α」修正为 `P(∀p) ≥ 1−α`。

**灵感 3（两者耦合 → 随机生成 × 并发执行 = 来源可追溯性的塌陷）**
直觉：扩散的随机性本身不可怕，多端口的并发本身也不可怕；可怕的是二者相乘后，**「这条动作/这条回执到底由哪个种子、哪个端口、哪个契约代际产生」变得不可追溯**。于是会出现三种静默失败：(a) 同一逻辑策略在不同端口因数值后端不同而给出不同样本，审计无法重放；(b) 每端口名义 1−α 覆盖，合起来最坏只有 1−Mα，舰队指标好看而单端口早已失效；(c) 端口 A 还在旧代际、端口 B 已切新代际，跨代回执被无意识地汇入同一个校准。三者都不会让主循环报警，却会让「计量结论」整体失真。解法仍是结构，而不是调参：**采样证书/种子账本**（可重放）、**约束去噪 + 模式支撑**（不幻觉、不越权）、**端口隔离 + 代际两阶段提交 + 舰队同时覆盖**（不串扰、不混代、覆盖不塌）。

## 1. 研究问题（本轮要回答什么）

- **Q1（随机策略的可审计性）**：扩散策略能否在硬实时计量系统里既保留多模态收益，又满足可重放、可支撑、可安全否决？
- **Q2（多端口的收益条件）**：什么条件下多端口共享优于独立部署？状态隔离、代际一致与舰队覆盖如何共同界定这个条件？
- **Q3（耦合的放大与界）**：随机生成 × 并发执行是否会把单点错误放大成舰队级来源混乱？能否用结构把来源不确定性压回可界、可审计？

## 2. 四条设计原则（雏形，正式化见产物区定义 448–463）

**P4 可重放采样（Replayable Sampling）**
任何进入数值路径或计量证据链的扩散样本，必须携带采样证书 `SampCert`：种子由 `(episode, port, t, epoch, k)` 确定性派生，采样器配置、样本数、确定性等级与轨迹哈希一并记录。禁止环境隐式随机源。可重放是审计的前提，不可重放样本只能作为探索，不能作为证据。

**P5 约束去噪与模式支撑（Constrained Denoising + Mode Support）**
去噪终态必须通过端口可采纳集投影、前缀封闭检查与不可逆屏障；未通过则拒绝重采样，重试耗尽退回确定性策略 `π_det`。每个采样模式还须通过模式支撑检验：其预测观测必须与既有回执在容差内一致，否则作为幻觉模式剪除。随机生成不获得任何越权能力。

**P6 端口隔离与代际一致（Port Isolation + Epoch Consistency）**
数值路径在端口 `p` 上的读集被限制为 `𝕊_p ∪ 𝔾_{g_p}`，写集限制为 `𝕊_p`；跨端口只允许读不可变全局先验。共享契约的更新走两阶段代际提交：每端口本地验证 + 兼容性检查通过后才发布新代际，各端口在自身块静默点切换，跨代回执绝不混合聚合。

**P7 采样预算与实时守门（Sampling Budget + Latency Guard）**
扩散采样按端口异步下沉，受采样预算 `B_samp^p` 与截止 `d_samp^p` 约束；超时/超预算/证据陈旧则退回 `π_det` 或上一已验证块，绝不阻塞 50Hz 主路径。舰队级吞吐收益必须扣除采样与验证的摊销成本后才成立。

## 3. 与基线的接口（如何退化）

- 采样不可重放（确定性等级不满足）/ 采样证书缺失 ⇒ 该端口禁用扩散，退回 InstructGauge 的 IAC 确定性分块；
- 投影失败 / 模式无支撑 / 前缀不封闭 / 跨不可逆屏障 ⇒ 单次退回 `π_det`（等价于 InstructGauge）；
- 端口隔离或兼容性校验失败 / 代际无法安全提交 ⇒ 该端口独立运行、独立校准，舰队聚合禁用；
- 舰队同时覆盖不达门槛 ⇒ 回退到每端口独立阈值，再回退到 InstructGauge 全局共形阈值；
- 扩散/多端口整体失效 ⇒ InstructGauge ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个**采样证书 + 种子账本**口径，把随机扩散策略纳入与确定性策略同级的可审计证据链；
2. 一个**约束去噪 + 模式支撑 + 前缀封闭/不可逆屏障**的生成器，给出「扩散不越权、不幻觉、不捆绑不可逆动作」的结构保证；
3. 一个**端口隔离不变式 + 代际两阶段提交 + 舰队同时共形覆盖**的方案，给出多端口不串扰、不混代的正式定义，以及随端口数 M 的覆盖界；
4. 一条完整可证伪路径：E457–E472 覆盖可重放性、约束可行性、幻觉剪枝、多模态消歧、端口分层/舰队覆盖、隔离故障注入、代际原子性、兼容迁移、采样实时性与舰队扩展。

## 5. 本轮最大风险

**一句话**：扩散策略会制造「样本足够多所以不确定度已被表达」的错觉，而多端口会把这种错觉并行放大——一个不可重放或被无支撑模式污染的样本、一次跨代际的无意识聚合，都会让舰队级覆盖与审计同时失效，却仍让每个单端口指标看起来达标；真正的残余风险在「采样来源 × 端口代际」的可追溯性接口，而非单个生成器或单个端口。

## 2. 形式化定义（要点）

**定义 448（端口舰队与端口配置）** 设端口集合 `P = {p_1,…,p_M}`。每个端口配置
`Θ_p = (T₀^p, M_phys^p, 𝕊_p, g_p, backend_p, B_samp^p, d_samp^p)`，
分别表示预注册工具集、物理幅值包线、可变状态命名空间、当前契约代际、数值后端、采样预算与截止。舰队状态为不相交并 `𝕊(P) = ⊔_{p∈P} 𝕊_p`；共享先验为按代际钉住的不可变对象 `𝔾_{g_p}`。端口可以异构：`T₀^p ≠ T₀^q`、`M_phys^p ≠ M_phys^q` 均允许。

**定义 449（端口隔离不变式 Iso）** 记一次数值路径运行在端口 `p` 上读取的状态位置集合为 `Read_p(Run)`、写入集合为 `Write_p(Run)`。隔离不变式为
`∀p: Read_p(Run) ⊆ 𝕊_p ∪ 𝔾_{g_p}` 且 `Write_p(Run) ⊆ 𝕊_p`。
跨端口信息只能经显式只读 API 读取 `𝔾_{g_p}`，且读取结果与 `g_p` 绑定。该不变式同时覆盖故障隔离与安全隔离：端口 `q` 的任何可变状态都不在端口 `p` 的读集内。

**定义 450（扩散探测策略）** `π_θ(· | o, ι, p)` 是端口 `p` 上关于轨迹 `τ = a_{1:H} ∈ (T₀^p × Args)^H` 的分布，由反向扩散过程定义：
`x_T ~ 𝒩(0,I)`，`x_{t-1} = D_θ(x_t, t, o, ι, p) + σ_t ξ_t`，`τ = decode(x_0)`。
多模态由样本集合体现，而非单一均值；端口条件 `p` 把动作空间限制在 `T₀^p × Args` 内，从生成源头避免跨端口动作空间污染。

**定义 451（约束去噪算子与可行过滤）** 约束去噪在每步施加端口投影：
`x_{t-1} = Π_{𝔸_adm^p}(D_θ(x_t,t,o,ι,p) + σ_t ξ_t)`。
终态过滤 `F_p(x_0) = 1[φ_pre ∧ shield(ι) ∧ prefix_closed(x_0) ∧ Barrier(x_0)]`。
若 `F_p = 0`，至多重采样 `N_retry` 次；仍失败则返回确定性策略 `π_det`（定义 461）。对非凸 `𝔸_adm^p`，逐位投影不保证每个中间步可行，**真正的安全承诺由终态过滤 + 提交前 CVC 给出**，逐位投影只是采样偏置。

**定义 452（采样证书 SampCert）** 每个进入计量路径的样本附带
`SampCert = (p, g_p, seed, sampler_cfg, N_s, det_level, h(τ), replay_hash, ts)`，
其中 `sampler_cfg = (steps, η, solver)`，`det_level ∈ {bitwise, statistical(ε_rep)}`。缺少证书、或 `replay_hash` 无法在审计时复现的轨迹，只可作为探索动作，**不得**用于契约更新或覆盖声明。

**定义 453（种子账本 ℒ_seed）** 种子由确定性函数派生：
`seed(p,t,k) = H(episode_id ‖ p ‖ t ‖ g_p ‖ k)`，
`H` 为抗碰撞哈希。禁止任何环境隐式随机源；同一元组在任何端口 / 任何重放中必须得到同一种子。`k` 为同一步内的样本编号，`t` 为决策步。

**定义 454（模式支撑检验 MST）** 把样本按模式聚类 / 按假设标签分组得到 `{m}`。对模式 `m` 的预测观测 `ô_m` 与既有回执集 `R`，定义
`supp(m) = 1[ d(ô_m, R) ≤ δ_mst ]`，保留集 `M_supp = {m : supp(m)=1}`。
`δ_mst` 取真实模式残差在校准集上的共形分位，于是 `P(真模式被误剪) ≤ α_mst`。幻觉模式若其残差随机占优于真模式残差，则误接受率可界为 `β_fa`；不满足占优假设时**不宣称界**，直接保守剪除。

**定义 455（样本分散度校准）** 扩散样本的原始方差不是校准不确定度。定义非一致性分数 `s(τ) = d(τ, H_s)`（到假设集的距离，或等价地用 `−log p_θ`），在校准集上取有限样本修正分位
`q_s = Quantile_{⌈(n+1)(1−α)⌉/n}(s_1,…,s_n)`，预测集 `H_s = {h : s(h) ≤ q_s}`。
校准对象是**采样随机性 + 模型误差的联合非一致性**，不是单步噪声。

**定义 456（端口分层共形 FleetCal）** 分层标签
`stratum(p,ι,g) = (p, instruction-type(ι), g)`。
每层用校准集 `C_cal^s` 取 `q_{p,s}`，使层内 `P(h* ∈ H_{p,s} | s) ≥ 1−α_p`。样本不足时按 `(p,类型,g) → (类型,g) → 全局` 逐级回退，回退按第 3 轮引理 55 的 `−2η` 优雅降级。

**定义 457（舰队同时覆盖）** 给定舰队风险预算 `α_fleet`，要求
`P(∀p ∈ P : h* ∈ H_{p,s}) ≥ 1 − α_fleet`。
两种可行分配：并集界 `α_p = α_fleet/M`；或 e-value 聚合（对每端口构造有效 e-value 后取平均）。朴素地给每端口 `α` 只能保证最坏 `1 − Mα`。报告须同时给出名义（per-port）与同时（fleet）覆盖。

**定义 458（契约代际）** 契约版本 `g ∈ ℕ`，记 `C_g`；动作与回执均携带 `epoch(·) = g_p`。一次决策的所有契约读取必须钉在单一 `g_p` 上；`𝔾_g` 在发布后不可变。跨代回执允许共存于存储，但**禁止**被汇入同一校准 / 同一次覆盖统计。

**定义 459（代际两阶段提交 EpochGate）** `prepare(p, g+1)` 返回 `(holdout_ok_p, compat_p)`；`commit(g+1)` 仅当所有必需端口 `p ∈ P_req` 的 `holdout_ok_p ∧ compat_p` 成立（或显式声明部分舰队并给出兼容矩阵）时执行：发布 `𝔾_{g+1}`，各端口在自身 `q_quiesce`（第 3 轮定义 439）切换到 `g+1`。切换窗口内允许不同端口处于不同代际，但**每次决策不混读、跨代不聚合**。

**定义 460（端口兼容证书）** `Compat(p,q) = 1[ tools(p) ⊆ T₀^q ∧ M_phys^p ⊆ M_phys^q ∧ δ_shift(p,q) ≤ δ_max ]`，其中 `δ_shift` 在共享审计集上估计。只有 `Compat=1` 才允许把端口 `p` 的契约 / 校准迁移到 `q`；否则必须独立校准。兼容证书是跨端口共享的**前置条件**，不是性能优化。

**定义 461（采样预算、截止与回退）** 端口 `p` 的采样预算 `B_samp^p`（去噪步数 / FLOPs 上限）与截止 `d_samp^p`（墙钟）。准入条件 `c_samp^p + c_verify ≤ slack_p`。若样本未在 `d_samp^p` 前就绪或预算耗尽 ⇒ 返回 `π_det`（等价 InstructGauge-IAC）或上一已验证块。主循环永不因采样而阻塞。

**定义 462（陈旧样本守卫）** `age(τ) = now − ts(τ)`。若 `age(τ) > H_c`、或 `still_grounded(ι,σ)` 失败、或 `g_p` 在采样后已改变 ⇒ 丢弃样本，不提交、不聚合、不出证。陈旧判定同时覆盖时间与语义两个维度。

**定义 463（舰队修复证书 FleetRepairCert）** `FleetRepairCert = (g, {RepairCert′_p}_{p∈P}, {SampCert}, coverage_report, compat_matrix, sched_trace)`。它把第 3 轮的「指令→块→回执→主张」证据链扩展到「端口→代际→采样→轨迹→回执」五级，使跨端口审计可复现。

# IP-328 DPG：约束扩散探测生成（多模态 + 端口条件化）
class DiffusionProbePlanner:
    def sample(self, obs, iota, port, H, k):
        seed = self.ledger.derive(port.id, self.t, self.epoch(port), k)
        cfg  = self.sampler_cfg
        for attempt in range(N_RETRY + 1):
            traj = self._denoise(obs, iota, port, seed + attempt)  # 见下
            if self.feasible(port, iota, traj):
                break
        else:
            traj = self.det.plan_chunk(iota, H, port.tools, K=1)   # π_det
        if crosses_irreversible(traj):
            traj = truncate_at_barrier(traj, I_IRR)                # 继承定义 445
        cert = SampCert(port.id, self.epoch(port),
                        seed, cfg, N_s, self.det_level,
                        h(traj), replay_hash(traj, cfg, seed), now())
        return traj, cert

    def _denoise(self, obs, iota, port, seed):
        x = noise(seed)                                            # ℒ_seed，禁止隐式 RNG
        for t in reversed(range(self.cfg.steps)):
            x = D_theta(x, t, obs, iota, port)
            x = project_admissible(x, port.tools, port.envelope)   # Π_{𝔸_adm^p}
            x = x + self.cfg.sigma[t] * noise(seed ^ (t * 0x9E3779B9))
        return decode(x)

# IP-329 采样证书与种子账本
class SeedLedger:
    def derive(self, port, t, epoch, k):
        return sha256(f"{self.episode}|{port}|{t}|{epoch}|{k}".encode()).digest()

# IP-330 MST：模式支撑检验（纯过滤，不扩可行域）
def mode_support(samples, receipts, delta_mst):
    modes = cluster_modes(samples)                  # 按轨迹/假设聚类
    kept = []
    for m in modes:
        o_hat = predict_observation(m)              # 前向预测该模式应看到的回执
        if dist(o_hat, receipts) <= delta_mst:      # 必须被既有回执支撑
            kept.append(m)
    return kept                                     # 未支撑模式被剪除

# IP-331 FleetCal：端口分层 + 舰队同时共形
class FleetCal:
    def threshold(self, port, iota, g, cal):
        typ = instruction_type(iota)
        for key, a in [((port, typ, g), self.alpha_p(port)),
                       ((FLEET, typ, g), self.alpha_fleet),
                       ((GLOBAL,),       self.alpha_fleet)]:
            if len(cal.get(key, [])) >= N_MIN:
                return conformal_quantile(cal[key], alpha=a)
        return self.instructgauge_global_threshold

# IP-332 EpochGate：代际两阶段提交
class EpochGate:
    def prepare(self, g_next):
        return {p: (p.holdout_ok(g_next), p.compat(g_next))
                for p in self.ports}

    def commit(self, g_next, report):
        required = [p for p in self.required if report[p][0] and report[p][1]]
        if len(required) < len(self.required):
            return False                            # 失败：保持旧代际
        self.publish_immutable_prior(g_next)        # 发布 𝔾_{g+1}
        for p in self.ports:
            p.defer_swap_until(g_next, p.q_quiesce) # 各端口静默点切换
        return True

# IP-333 PortSched：采样预算 / 截止 / 陈旧守卫
class PortScheduler:
    def submit(self, port, task, budget, deadline):
        if not self.admit(port, budget):            # c_samp + c_verify ≤ slack
            return port.det_policy                  # π_det
        fut = self.executor.submit(task)
        if fut.wait(deadline) is None:              # 超时
            return port.last_verified_chunk
        return fut.result()

    def admit(self, port, budget):
        return budget <= port.B_samp and self.slack(port) >= budget + C_VERIFY

# IP-334 DiffPortGauge-8C 闭环
def diffportgauge_8c(M, p, s, iota):
    H = p.lbox.hypothesize(s, p.dbox.R[s], iota)            # 继承 7C 的 H
    traj, scert = M.dpg.sample(p.env.obs(), iota, p, H, k=0) # D：多模态采样
    modes = mode_support(traj.samples, p.receipts, M.delta_mst)
    if not modes:
        traj, scert = M.dpg.det.plan_chunk(iota, H, p.tools, K=1), None
    traj = traj.select_mode(modes)                          # M：只留支撑模式
    if M.epochgate.epoch(p) != scert.epoch or age(traj) > H_C:
        return stub_and_red(s, "stale_or_mixed_epoch")      # 定义 462
    if not M.tcv.verify(traj.as_program(), p.budget_left(s))[0]:
        traj = M.det.plan_chunk(iota, H, p.tools, K=1)
    cert = M.cvc.commit(traj, p.env, iota)                  # 继承 CVC 定义 435
    receipts = cert.receipts
    if len(receipts) < n_min(s):
        return stub_and_red(s, "insufficient")
    mu, Sig = M.apcal.calibrate(receipts, H, s)
    if not M.apcal.cross_validate(mu, Sig, p.cross_receipt(s)):
        return stub_and_red(s, "cross_failed")
    if not M.fleetcal.covers(p, s, mu, M.alpha_p(p)):       # F：分层覆盖
        return stub_and_red(s, "coverage_fail")
    new_ec = M.apcal.update_contract(p.dpe, mu, Sig, s)
    if not contract_regression(new_ec):
        return stub_and_red(s, "regression")
    if not M.epochgate.commit_if_ready(p, new_ec):          # G：代际门
        return stub_and_red(s, "epoch_blocked")
    M.mreg.hot_replace_at_quiescence(p.dpe, new_ec, cert.boundary)
    bind_claims(cert, iota, receipts)                       # 继承 IP-325
    return True

# IP-335 主闭环：每端口隔离，50Hz 路径不变
def DiffPortGauge_round(M, inputs):
    for p in M.ports:
        with M.isolation(p):                                # Iso(P)，定义 449
            for s in p.dbox.detect_blind_spot():
                if s not in p.inflight:
                    p.inflight.add(s)
                    M.portsched.submit(
                        p,
                        lambda: diffportgauge_8c(M, p, s, M.iota),
                        budget=M.samp_budget(p),
                        deadline=M.samp_deadline(p))
    return {p.id: MODGAUGE_round(p, *inputs[p.id]) for p in M.ports}

## 4. 推导

**引理 59（可重放性界）** 若 `det_level = bitwise`、`backend_p` 为确定性内核、且 `seed / sampler_cfg / g_p` 相同，则重放得到逐位相同的 `h(τ)`。若 `det_level = statistical(ε_rep)`，设每步去噪核与重放核的 TV 距离 ≤ `ε_step`，则整条轨迹分布的 `TV ≤ T·ε_step`，存在耦合使 `P(h(τ) ≠ h(τ')) ≤ T·ε_step`；当 `T·ε_step > ε_rep` 时该样本判为不可重放并逐出计量路径。
*证明骨架*：确定性内核的复合仍是确定性函数，故第一条成立。第二条对 `T` 个核用三角不等式累加 TV，再用耦合不等式把分布距离转成轨迹哈希不一致概率。因此「可重放」是可检验的契约，而非期望。

**引理 60（约束去噪不引入新的不安全动作类）** 若终态过滤 `F_p` 按定义 451 执行、前缀封闭与不可逆屏障按定义 434/445 保留、且失败时退回 `π_det`，则任何被提交的轨迹满足 `τ ∈ 𝔸_adm^p`，且沿前缀每一步保持安全盾不变量 `Inv`；未通过过滤的样本不进入 CVC。故扩散层不扩大第 3 轮已证明的安全动作集。
*证明*：终态过滤直接给出 `τ ∈ 𝔸_adm^p`；前缀封闭使 CVC（定义 435）可在任意前缀截断；引理 52 逐步归纳给出 `Inv`。若 `N_retry` 耗尽则执行 `π_det`，其安全性等价于 InstructGauge。逐位投影仅影响采样分布，不承担安全证明，故非凸 `𝔸_adm^p` 也不破坏结论。

**引理 61（模式支撑的误剪 / 误接受界）** 设 `δ_mst` 取真模式残差在校准集上的 `1−α_mst` 共形分位，则在层内可交换下 `P(真模式被误剪) ≤ α_mst`。若幻觉模式残差随机占优于真模式残差，则 `P(幻觉模式被误接受) ≤ β_fa(δ_mst)`；若占优假设不成立，**只能保守剪除**，此时不宣称 `β_fa` 界。
*证明*：第一句是共形预测的标准边际覆盖结论。第二句由占优性把幻觉残差尾部压到真模式尾部之下，再代入经验 CDF。第三句是诚实性声明：无占优性时无法从数据支撑得到有限界，故设计上取保守分支（宁可误剪不可误收）。

**引理 62（端口非干扰）** 在 `Iso(P)` 与「跨端口只读不可变 `𝔾`」下，端口 `p` 的执行轨迹与「单独运行端口 `p`」逐值相同；任一端口 `q` 的故障或污染不能改变 `𝕊_p`。调度器只改变时序，不改变数值状态；时序导致的证据陈旧由定义 462 显式处理并计入端口局部风险。
*证明*：对执行步归纳。基础步：初始化只读 `𝕊_p ∪ 𝔾_{g_p}`。归纳步：由 `Write_p ⊆ 𝕊_p`，`p` 的下一状态只依赖 `𝕊_p` 与不可变先验；`q` 的任何写入都在 `𝕊_q`，不在读集内。调度影响的是 `now`，由 `age(τ)` 守卫转为显式的丢弃事件，而非隐式数值串扰。

**引理 63（代际原子性）** 在代际钉住读（定义 458）与两阶段提交（定义 459）下，任何一次决策只观察单一代际 `g_p`；在途块在 `q_quiesce` 前 drain 或按 `abort` 截断（引理 57），故无块观察混合契约。切换窗口 `W = max_p drain_p` 内舰队可处于混合代际，但**跨代回执不聚合**，因此覆盖与校准不会被静默污染。
*证明*：决策内所有契约读取被钉在 `g_p`，故单次决策原子。`q_quiesce` 排除在途块观察到新契约。跨代不聚合是构造性约束（回执带 `epoch` 标签，聚合入口拒绝异代混合），因此混合窗口只影响吞吐，不影响统计有效性。

**引理 64（舰队同时覆盖）** 并集界给出
`P(∃p: h* ∉ H_{p,s}) ≤ Σ_p P(h* ∉ H_{p,s}) ≤ Σ_p α_p`；
取 `α_p = α_fleet/M` 即得 `P(∀p: h* ∈ H_{p,s}) ≥ 1 − α_fleet`。朴素每端口 `α` 最坏只有 `1 − Mα`。分层低样本回退再叠加第 3 轮引理 55 的 `−2η`。
*证明*：第一条为测度次可加性；其余为代入。e-value 版本把每端口有效 e-value 取平均后由 Markov 不等式给出同时保证，通常比 Bonferroni 更紧，但要求各端口 e-value 构造有效。

**引理 65（采样摊销与 50Hz 保全）** 设样本生成时间为随机变量 `S`、块长 `K`、验证开销 `c_verify`。异步下沉后每步摊销采样代价 `E[S]/K + c_verify`；准入条件保证其不超过 `slack`。由 Markov 不等式，`P(S > d_samp) ≤ E[S]/d_samp`，超时触发 `π_det` 回退，故截止违约只损失信息增益、不破坏安全，也不阻塞主路径。继承第 3 轮引理 58 的硬实时结论。
*证明*：分摊由 `K` 步共享一次采样；准入是代数条件；超时概率为 Markov 界；回退路径等价 InstructGauge，安全性与实时性由引理 58 承接。

**引理 66（异构端口迁移界）** 设损失函数 `L`-Lipschitz。跨端口迁移的性能差满足
`|R_p(C) − R_q(C)| ≤ L·( TV(𝒟_p, 𝒟_q) + κ·1[tools(p) ≠ tools(q)] + λ·env_mismatch(p,q) )`。
当该界超过 `δ_max` 时 `Compat(p,q)=0`，禁止迁移并要求独立校准。
*证明*：用 Pinsker / 耦合把不同数据分布下的期望损失差转成 TV 距离；工具与包线差异是不可消除的结构项，直接计入；最后以 `δ_max` 截断定义 460。

## 8. 本轮最大风险

**一句话**：`DPG` 的随机采样与 `EpochGate` 的端口代际在接口处形成**来源可追溯性风险**——一个不可重放或被无支撑模式污染的样本、一次跨代际的无意识聚合，会让舰队覆盖与审计同时失效，而每个单端口的名义指标仍然达标；缓解只能依赖结构（采样证书使随机性可重放、约束去噪与 MST 使生成不越权不幻觉、端口隔离与两阶段提交使状态不串扰不混代、`α_fleet` 分配使覆盖不塌），并以 E458/E460/E464/E465/E466 主动证伪。
