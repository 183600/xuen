# 第 3 轮（新灵感循环第 3 轮；本轮灵感：「长程任务」×「多模态大模型」）

> **基线**：第 2 轮产出 MetricVoiceGauge-NCD-HUTDH-v20+IP-420–424（v20 完整方案）。
> 本轮纪律：**语义只提案、证书只收缩、长程只拼接**。不推倒 v20：v17 的 CLP/S2C/HCG/PSV/APS/AMC、v19 的 DCM/OGCC/CCV/DRS/OGC、v20 的 PCA/CTS/CFC/HPC/CFCtrl 全部保留。本轮只做一件事：**把多模态大模型给出的语义分解，编译成可组合的时序证书，使长程任务的安全成本随时长线性而非指数增长**。

## 0. 直觉与动机

**灵感 1（长程任务 → 安全是可组合的契约代数，不是一条超长轨迹）**
直觉：传统做法把长程任务当成一条长轨迹，逐点做碰撞/约束验证；误差与保守性沿时间累积，可行域被一段段取交，活性按 `α^H` 指数衰减，而重规划一旦触发就“全链重来”。核心创新：**时序证书代数 (Temporal Certificate Algebra, TCA)**。每个技能 `s` 携带一个证书 `C_s = (Pre_s, Post_s, Inv_s, K_s, ε_s, τ_s)`；两个技能只有在 `Post_{s1} ⊆ Pre_{s2}` 时才允许拼接，拼接后风险按 `1-(1-ε1)(1-ε2)` 累积、不变式取交、viability kernel 取交。关键反直觉点：**长程安全的活性成本不是随时长指数爆炸，而是由“再锚点 (checkpoint)”的密度决定**——在每段末尾回到一个已认证的恢复集 `R`，不变式与误差预算被**分段重置**，于是 H 段任务的活性损失由每块的段数 `κ` 决定（≈`α^κ`），而不是由总长 `H` 决定（≈`α^H`）；风险本身仍随 H 线性累积（这是不可避免的），但“可行性”不再随 H 指数消失。

**灵感 2（多模态大模型 → 语义是约束提案器，不是安全裁判）**
直觉：MLLM 能看 RGB + 深度 + 语言，提出物体属性（易碎/重/可变形）、子目标、可供性与危险区域；但它是随机的、会幻觉的、不可形式验证的。若把 MLLM 当“安全裁判”，长程任务里一次幻觉就能贯穿后续所有步骤，且越往后的步骤越依赖前面的错误结论。核心创新：**语义到证书编译器 (Semantic-to-Certificate Compiler, SCC)**。MLLM 只输出**带类型的约束程序** `π ∈ L_sem`；SCC 把每条约束编译成对可执行域的**单调收缩算子** `⟦·⟧`。凡是没有证明项的约束一律按“收缩”处理；凡是要**放宽**安全域的约束，必须附带 v20 的 HPC/CTS 证明项 `p` 并通过验证，否则拒绝。关键反直觉点：**MLLM 的幻觉在安全上是“无害”的——它最多让计划更保守、活性更低，绝不会让不安全动作被放行**；安全性由类型系统保证，活性由“带证明的放宽”恢复。语义层的角色从“决策者”降格为“约束提案者”，这正是把不可靠模型安全接入闭环的正确姿势。

**灵感 3（二者统一 → 在任务图上粘合局部证书的层 (sheaf)）**
直觉：长程任务天然是一张任务 DAG，MLLM 给出分解；真正的难点不在每段中间（那里 v19/v20 的证书已经能管），而在**段与段的边界**：上一段的出口集是否落进下一段的入口集、两个不变式在重叠处是否一致、风险预算是否在边界处被正确结转。核心创新：**语义-时序契约网 (Semantic-Temporal Contract Net, STCN)**。把每个子目标视为一张局部证书图卡，把边界视为重叠区；全局安全证书存在，当且仅当所有边界满足**粘合条件**（`Post_u ∩ Pre_v ≠ ∅` 且不变式在重叠处一致），即证书层存在**全局截面 (global section)**。若某条边粘合失败，不重规划整条任务，而是插入一个**适配技能** `A_e`（重抓、重观测、回中立位）；若适配也不存在，则把**失败证书 `FailCert(e)`** 作为“编译错误”反馈给 MLLM，让它只修这条边。关键反直觉点：**MLLM 不该负责规划整条长程任务，而应负责修局部边界的“编译错误”**——这把长程规划从“一次生成一条脆弱长链”变成“局部修复一张可验证的契约网”，使修复循环有界、可审计。

**三者如何统一**
统一为 **v20 证书体系之上的语义-时序层**：v20 回答“当前几何/感知下 θ 是否零碰撞”，v21 回答“给定 MLLM 的语义分解，这条长程技能序列是否存在可组合的全局安全证书”。TCA 是组合侧（段内证书与拼接），SCC 是编译侧（语义→单调收缩），STCN 是结构侧（任务图上的粘合与修复）。共享状态 `ζ_sem = (task_graph, seg_certs, semantic_proposals, glue_obligations, checkpoint_set, mode_sem)`。统一接口：**若 STCN 存在全局截面且每段 T-Cert 在 v20 的 HPC 下通过，则整条长程计划进入 `Exec_v21`；否则降级为逐段在线重认证，或退回 v20 的单步执行**。

## 1. 研究问题（轮次升级版）

- **Q1（时序证书的组合与误差累积）**：如何定义 T-Cert，使守卫式拼接满足结合律与守卫正确性？H 段之后的风险界与活性损失如何做到“风险随 H 线性、活性由 κ 而非 H 决定”？检查点的放置如何最优化（在风险上界约束下最小化活性损失）？

- **Q2（语义约束的类型安全）**：如何设计 `L_sem` 与 `⟦·⟧`，使得**任何** MLLM 输出都只能收缩、不能扩张可执行域？哪些“放宽”需要哪一种证明项（HPC 几何证明 / CTS 谱系证明 / 语义-感知一致性证明）？如何量化语义精度与活性损失之间的权衡，并在精度不足时安全降级？

- **Q3（任务图上的粘合与修复）**：STCN 的粘合条件如何形式化（出口/入口/不变式在重叠处的一致）？适配技能的存在性与最小插入代价如何判定？`FailCert(e)` 如何反馈给 MLLM 才能保证修复循环**收敛**（有界步数）而不是无限重试？

- **Q4（双时钟与长程时序协调）**：语义时钟（秒级、MLLM 推理）与几何时钟（50Hz、CCV/PCA 再认证）如何解耦？段内几何再认证失败时，如何用 viability kernel `K_s` 做**局部恢复**而不是全局重规划？v20 的 `τ_consensus` 感知漂移如何被检查点重置，从而不沿长程累积？

## 2. 设计原则（在 P31–P33 基础上新增 P34–P36）

**P34 时序组合保守律（Temporal Composition Conservatism）**
技能 `s` 的证书 `C_s = (Pre_s, Post_s, Inv_s, K_s, ε_s, τ_s)` 满足：若 `x(t0) ∈ Pre_s` 且执行 `s`，则 `∀t∈[t0,t0+τ_s], x(t) ∈ Inv_s`，且 `x(t0+τ_s) ∈ Post_s` 以概率 `≥ 1-ε_s`。守卫式拼接 `C_1 ⊗ C_2` 仅当 `Post_1 ⊆ Pre_2` 时定义，结果为
`(Pre_1, Post_2, Inv_1∩Inv_2, K_1∩K_2, 1-(1-ε_1)(1-ε_2), τ_1+τ_2)`。
**拼接只能收窄入口、收窄不变式、收窄 kernel，且风险单调不减**；空拼接（`Post_1 ∩ Pre_2 = ∅`）视为类型错误，不得静默通过。

**P35 语义单调收缩律（Semantic Monotone Contraction）**
MLLM 提案 `π` 经编译器 `⟦·⟧: L_sem → (2^X → 2^X)` 作用到基线可执行域 `D_0`。类型系统只有两类规则：
- `Shrink`：`⟦c⟧(D) = D ∩ φ_c`，恒有 `⟦c⟧(D) ⊆ D`，无需证明即可接受；
- `Expand⟨p⟩`：仅当证明项 `p` 通过验证器 `Verify(p)=1`（来自 v20 的 HPC/CTS 或语义-感知一致性检查）时，才允许在 `p` 所界定的子域内放宽。
**任何未通过类型检查的约束一律丢弃并记录**。因此对任意 `π`（包括幻觉/投毒），`⟦π⟧(D_0) ⊆ D_0`，安全性不依赖 MLLM 的正确性。

**P36 粘合可修复律（Gluing Reparability）**
任务图 `G=(V,E)` 的每条边 `e=(u,v)` 带边界契约 `B_e = (Post_u, Pre_v, Agree_e)`，其中 `Agree_e` 要求两段不变式在重叠区一致。全局安全证书存在当且仅当存在全局截面：`∀e, Post_u ∩ Pre_v ≠ ∅ ∧ Agree_e`。若不成立，允许插入适配技能 `A_e` 使 `Post_u → Pre_{A_e} → Post_{A_e} → Pre_v`；适配失败则生成 `FailCert(e)` 并回传给语义层。**修复过程必须带良基测度（未粘合边数 + 剩余预算），每次接受的修复严格降低测度，否则在预算耗尽时强制降级到 v20 单步执行**。

## 3. 与基线的接口（如何退化）

- TCA 失效（证书无法组合）⇒ 只执行当前单段，段末强制 v20 单步再认证 ⇒ 等价 v20（更保守）；
- SCC 失效（MLLM 不可用/编译失败）⇒ 只接受脚本化技能库的 `Shrink` 约束，拒绝一切 `Expand` ⇒ 等价 v20（语义不参与放宽）；
- STCN 失效（任务图无法粘合）⇒ 退回逐段串行 + 每段 v20 证书 ⇒ 等价 v20（长程优势消失，安全不变）；
- 检查点失效（恢复集 `R` 不可再认证）⇒ 不允许重置误差预算，退化为全局取交 ⇒ 活性回落到 `α^H`，但安全不降；
- 双时钟失效（语义/几何时钟失步）⇒ 语义计划冻结、几何层持续 50Hz 再认证 ⇒ 等价 v20 的 APS/CFCtrl 路径；
- 全部失效 ⇒ 完全回退 v20 ⇒ 等价 v20；
- **安全继承**：TCA 只拼接已认证段、SCC 只收缩、STCN 只粘合或降级、检查点只重置预算不扩张域；任意失效都只会进一步收窄，故 `Exec_v21 ⊆ Exec_v20` 由引理 163 保证。

## 4. 预期贡献

1. **时序证书代数**：首次把“长程任务安全”改写为守卫式、可结合、可审计的证书拼接代数，给出 `⊗` 的守卫条件、风险累积律与检查点重置机制，把活性从 `α^H` 降到 `α^κ`；
2. **语义单调收缩编译**：发现“MLLM 的正确性不应是安全前提”，给出带类型、带证明项的语义→证书编译规则，使幻觉在安全上无害、只在活性上有代价；
3. **契约网与全局截面**：把任务图上的段边界形式化为证书层粘合问题，给出全局截面的存在性判据与“失败证书→局部适配→语义修复”的有界修复循环；
4. **双时钟长程协调**：把语义慢时钟与几何快时钟解耦，用 viability kernel 做段内局部恢复，用检查点重置 v20 的感知漂移，使长程风险线性可控；
5. **语义-时序闭环**：TCA+SCC+STCN 落在 v20 的感知证书之上，`Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`，实现“语义提案→时序组合→边界粘合→感知再认证”的闭环。

## 5. 本轮最大风险

**一句话**：若 MLLM 的“语义放宽证明项”与 v20 的感知证书**共享同一种系统性偏差**（例如二者都把反光薄壁当成实心、把透明容器当成空），则 SCC 会合法地“证明”一个错误的安全域，STCN 会在每个检查点处**系统性地回到同一个不安全状态**——形式上每条边都粘合、每段都有证书、风险随 H 线性，实际上长程任务被反复“重置”进同一个被误判的恢复集，形成**检查点复用的系统性盲区**。

# IP-425 Temporal Certificate Algebra
@dataclass(frozen=True)
class TemporalCert:
    Pre: Region
    Post: Region
    Inv: Region
    K: Region                 # viability kernel
    eps: float                # risk bound in [0, 1]
    tau: float                # duration
    proof: Optional[Proof] = None

class GuardViolation(Exception):
    pass


class TemporalCertificateAlgebra:
    def compose(self, C1: TemporalCert, C2: TemporalCert) -> TemporalCert:
        """守卫式拼接：只有 Post1 ⊆ Pre2 才允许。空拼接是类型错误，不得静默通过。"""
        if not C1.Post.subset_of(C2.Pre):
            raise GuardViolation("Post_1 ⊄ Pre_2")
        return TemporalCert(
            Pre=C1.Pre,
            Post=C2.Post,
            Inv=C1.Inv.intersect(C2.Inv),
            K=C1.K.intersect(C2.K),
            eps=1.0 - (1.0 - C1.eps) * (1.0 - C2.eps),
            tau=C1.tau + C2.tau,
        )

    def certify_horizon(self, segs, checkpoints, R, eps_budget):
        """按检查点分块，块内拼接、块间重置误差预算。"""
        blocks = split_at(segs, checkpoints)
        certs, total_eps = [], 0.0
        for block in blocks:
            C = reduce(self.compose, block)
            if not C.Post.subset_of(R):
                return None, "CHECKPOINT_UNREACHABLE"
            total_eps = 1.0 - (1.0 - total_eps) * (1.0 - C.eps)
            certs.append(C)
        if total_eps > eps_budget:
            return None, "RISK_BUDGET_EXCEEDED"
        return HorizonCert(blocks=certs, eps=total_eps, R=R), "OK"


# IP-426 Semantic-to-Certificate Compiler
@dataclass
class TypedConstraint:
    kind: str                 # "Shrink" | "Expand"
    predicate: Region         # for Shrink
    relaxation: Optional[Region] = None   # for Expand
    proof: Optional[Proof] = None         # required for Expand


class SemanticToCertificateCompiler:
    def __init__(self, hpc_verifier, cts_verifier, d_safe):
        self.hpc = hpc_verifier
        self.cts = cts_verifier
        self.d_safe = d_safe          # hard upper bound = v20 certified domain

    def verify(self, p: Proof) -> bool:
        if p is None:
            return False
        if p.source == "HPC":
            return self.hpc.verify(p) and p.domain.subset_of(self.d_safe)
        if p.source == "CTS":
            return self.cts.verify(p) and p.domain.subset_of(self.d_safe)
        return False

    def compile(self, proposal, D0):
        """任意 proposal 都被编译进 D_safe；未验证的 Expand 被丢弃。"""
        D = D0
        rejected = []
        for c in proposal.constraints:
            if c.kind == "Shrink":
                # 单调收缩：无条件安全
                D = D.intersect(c.predicate)
            elif c.kind == "Expand":
                # 放宽必须带证明，且证明域仍在 v20 硬上界内
                if not self.verify(c.proof):
                    rejected.append(c)
                    continue
                D = D.union(c.relaxation.intersect(c.proof.domain))
            else:
                rejected.append(c)
        assert D.subset_of(self.d_safe)   # 引理 160 的运行期断言
        return D, rejected


# IP-427 Viability Kernel Checkpoint Planner
class ViabilityKernelCheckpointPlanner:
    def __init__(self, eps_budget, max_block=8):
        self.eps_budget = eps_budget
        self.max_block = max_block

    def backbone_invariant(self, segs):
        """I* = 所有段不变式的交；若为空则无 backbone。"""
        I_star = Region.universe()
        for C in segs:
            I_star = I_star.intersect(C.Inv)
        return I_star if not I_star.is_empty() else None

    def place_checkpoints_dp(self, segs, R):
        """
        DP：在风险预算内最小化活性损失。
        cost(i,j) = -log(μ(∩_{k=i..j} Inv_k))  （块内可行域的对数体积损失）
        约束：块风险 ≤ eps_budget，块长 ≤ max_block，块末 Post ⊆ R。
        """
        n = len(segs)
        dp = [inf] * (n + 1)
        back = [-1] * (n + 1)
        dp[0] = 0.0
        for j in range(1, n + 1):
            for i in range(max(0, j - self.max_block), j):
                block = segs[i:j]
                C = reduce(TemporalCertificateAlgebra().compose, block)
                if not C.Post.subset_of(R) or C.eps > self.eps_budget:
                    continue
                loss = -log(max(C.Inv.measure(), EPS))
                cand = dp[i] + loss
                if cand < dp[j]:
                    dp[j], back[j] = cand, i
        if dp[n] == inf:
            return None, "NO_FEASIBLE_CHECKPOINTS"
        return reconstruct(back, n), "OK"


# IP-428 Semantic-Temporal Contract Net
class SemanticTemporalContractNet:
    def __init__(self, tca, scc, mllm, adapter_lib, max_budget=8):
        self.tca, self.scc, self.mllm = tca, scc, mllm
        self.adapter_lib = adapter_lib
        self.max_budget = max_budget

    def glue(self, G, certs):
        """返回未粘合的边及其失败契约。"""
        obligations = []
        for u, v in G.edges:
            Cu, Cv = certs[u], certs[v]
            B = BoundaryContract(Post_u=Cu.Post, Pre_v=Cv.Pre,
                                 Agree_e=invariant_agreement(Cu.Inv, Cv.Inv))
            if not B.glues():
                obligations.append((u, v, B))
        return obligations

    def repair(self, G, certs, obligations):
        """良基测度 m=(|Unglued|, budget) 严格下降 ⇒ 有界终止。"""
        budget = self.max_budget
        while obligations and budget > 0:
            e = choose_worst(obligations)
            A = self.adapter_lib.find(e)          # 先查已验证适配库
            if A is None:
                fc = FailCert(edge=e, contract=e_contract(e),
                              witness=obligation_witness(e))
                proposal = self.mllm.repair(fc)   # 只让 MLLM 修这一条边
                A, _ = self.scc.compile(proposal, D0=adapter_lib.default_domain(e))
            if A is not None and self.tca.compose_ok(certs[e.u], A, certs[e.v]):
                certs = insert_adapter(certs, e, A)
                obligations = self.glue(G, certs)  # 测度下降或预算下降
            budget -= 1
        if obligations:
            return None, "FALLBACK_V20"           # 预算耗尽，降级
        return GlobalSection(G, certs), "OK"

class DualClockHorizonController:
    def __init__(self, aps, cfctrl, ccv, tca, ttl_sem=10.0):

## 3. 推导

**引理 157（时序证书组合保守性）**
若 `C_1, C_2` 为有效证书且 `Post_1 ⊆ Pre_2`，则 `C_1 ⊗ C_2` 为有效证书，且 `Pre ⊆ Pre_1`、`Post ⊆ Post_2`、`Inv ⊆ Inv_1 ∩ Inv_2`、`K ⊆ K_1 ∩ K_2`、`ε = 1-(1-ε_1)(1-ε_2) ≥ max(ε_1, ε_2)`。故拼接只收窄可执行域、只增加风险上界，不产生新的安全动作。∎

**引理 158（结合律与单位元）**
在守卫条件同时成立时，`⊗` 满足结合律：`(C_1⊗C_2)⊗C_3 = C_1⊗(C_2⊗C_3)`。证明：集合交与 kernel 交结合，`1-∏(1-ε_i)` 亦结合；两侧所需守卫均为 `Post_1 ⊆ Pre_2 ∧ Post_2 ⊆ Pre_3`。恒等元为 `skip = (X, X, X, X, 0, 0)`。故长程证书可按任意结合顺序归约，便于并行/增量验证。∎

**引理 159（检查点把活性指数从 H 降到 κ）**
设每段不变式使可行域测度按 `μ(Inv_i) ≤ α·μ(Inv_{i-1})` 收缩。无检查点时 `Inv_H = ⋂_{i=1}^H Inv_i`，活性 `μ(Inv_H) ≤ α^H·μ(X)`。若每 κ 段经 `Post_block ⊆ R` 回到已独立认证的恢复集 `R` 且 `R` 在每个块内保持可行，则任一时刻的约束只来自当前块的 `κ` 段交集，活性 `≥ α^κ·μ(R)`；同时总风险仍满足 `ε_H ≤ Σ_block ε_block ≤ H·ε_max`（线性、不可避免）。故**活性由 κ 决定，风险由 H 决定**。∎

**引理 160（语义编译安全）**
对任意 MLLM 提案 `π`（含幻觉/投毒），SCC 输出 `D = ⟦π⟧(D_0)` 满足 `D ⊆ D_safe`。证明：初始 `D_0 ⊆ D_safe`；`Shrink` 取交保持包含；`Expand⟨p⟩` 仅在 `Verify(p)=1` 且 `p.domain ⊆ D_safe` 时执行 `D ∪ (relaxation ∩ p.domain) ⊆ D_safe`；未验证项被丢弃。故 `Exec_v21 ⊆ Exec_v20`，且 MLLM 错误只会减少被接受的放宽，不会放行不安全动作。∎

**引理 161（契约网全局截面）**
若任务图 `G` 的每条边 `e` 或满足 `B_e.glues()`，或存在已验证适配技能 `A_e` 使 `Post_u ⊆ Pre_{A_e} ∧ Post_{A_e} ⊆ Pre_v ∧ Agree`，则按拓扑序归纳可构造全局证书 `Γ`，且 `Γ` 的每段均通过 v20 HPC 再认证。故 `Exec(STCN) ⊆ Exec_v20`。∎

**引理 162（修复循环有界终止）**
定义测度 `m = (|Unglued|, budget)`，按字典序。每轮：若插入已验证适配且粘合成功，则 `|Unglued|` 严格下降；若失败/无适配，则 `budget` 严格下降。`m` 良基，故循环至多执行 `|E| + budget_max` 轮后终止；终止时或得到全局截面，或返回 `FALLBACK_V20`。∎

**引理 163（v21 整体安全继承）**
在同一几何快照、同一感知快照、同一机器人集合下，`Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`。证明：TCA 只拼接已认证段（引理 157/158），SCC 只输出 `D ⊆ D_safe`（引理 160），STCN 只接受粘合成功或已验证适配（引理 161），VKP 的检查点只重置误差预算而不扩张域（引理 159），DHC 失败即回退。五者叠加只能产生子集。∎

## 7. 已知风险与失效模式

1. **语义精度坍塌（活性风险）**：SCC 的“只收缩”虽保证安全，但若 MLLM 语义精度低，`Shrink` 过多、`Expand` 证明过严，长程计划会保守到不可行。缓解：语义精度指标 + 证明项来源多样化 + 精度不足时回退脚本技能库。

2. **证明项共享偏差（安全风险）**：若 `Expand` 的证明项来自与 MLLM 同源的感知/几何偏差，则“被证明的安全域”可能系统性错误，形成合法但错误的放宽。缓解：证明项来源与语义源正交（不同传感器/不同验证器）、偏差检测、周期性人工抽检。

3. **恢复集 R 的伪可恢复性**：检查点重置依赖 `R` 真正可再认证；若 `R` 在分布偏移下不再安全，则长程任务被反复重置进同一不安全状态。缓解：`R` 的多重认证、在线可恢复性探测、漂移告警。

4. **修复循环抖动**：MLLM 可能反复给出无效适配，虽然预算保证终止，但会浪费大量语义调用。缓解：FailCert 结构化、缓存失败模式、修复优先级排序。

5. **任务图规模爆炸**：长程任务 DAG 可能很大，粘合/修复的组合开销上升。缓解：分层任务抽象、证书宏缓存、增量粘合。

6. **符号区域表示爆炸**：高维 `X` 上集合交/包含判定可能不可行。缓解：谓词化表示、采样近似 + 保守包络、区域抽象域。

7. **T-Cert 缓存失效**：长程执行中物体/环境变化会使缓存证书过时。缓解：版本号 + 检查点强制刷新 + 在线再认证。

8. **提示注入/语义漂移**：MLLM 输入可被对抗性文本/图像影响。缓解：约束类型系统兜底（引理 160）、输入净化、语义源可信度。

## 8. 本轮最大风险

**一句话**：若 MLLM 的“语义放宽证明项”与 v20 的感知证书**共享同一种系统性偏差**（如都把反光薄壁当成实心、把透明容器当成空），则 SCC 会合法地“证明”错误的安全域，STCN 会在每个检查点处系统性地回到同一个不安全状态——形式上每条边都粘合、每段都有证书、风险随 H 线性，实际却是**检查点复用的系统性盲区**。
