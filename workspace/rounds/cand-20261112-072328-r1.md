# 第 58 轮（承接第 57 轮「少样本×多模态×个性化」IP-133~138；灵感循环第 4 轮；本轮灵感：「模型量化」×「力矩传感」）

> 第 57 轮把安全的赌注从"模型置信"换到"证据质量"——MFSL 摊销先验 + 共形保底、XMC 分账对账、PTM 单向信任、FSE 五类证据门，使单点坏证据难以独力产生承诺；但它的风险自陈指出一个更深的递归：**(a)** 所有证书（ECE、共形覆盖、OOD 检出、风险模型）本身都是被学习出来的判定器算的，若这些判定器在边缘被量化压缩，证书就可能是"用被压缩的尺子量自己"——量化误差不是零均值噪声，而是结构性失真（rounding 累积、clipping 打尾、calibration shift）；**(b)** 第 57 轮的一切证据仍停留在"关于表面的信念"，而真正决定伤害的是"接触处的力矩/冲量"这一后果量；表面判断再准也无法替代对后果的直接测量；**(c)** 第 57 轮的动作集只有{承诺, 绕行, 降档, 协商, 停}，把不确定性一味推向"避免接触"，但很多任务必须接触——缺少一种"错了也可承受"的动作。本轮两个灵感各补一条：**模型量化**提供"可验证的推断偏差界"（不信任判定器，信任其误差的可测上界；精度本身成为可分配预算）；**力矩传感**提供"物理后果硬界"（τ_cap 与柔顺接触使错误代价有界，且 tau 是与危险物理耦合最紧、相对抗欺骗的模态）。核心命题由"证据说可信"升级为 **"偏差可界定、后果可承受的证据说可信"**——安全性从"判定必须正确"变为"判定错误时代价有界"。

核心矛盾：
- **H29（量化 vs 证书）**：安全证书由量化网络算出；量化误差结构性（clipping 只伤尾部、rounding 逐层累积、校准集漂移），可能让证书在最需要它的 OOD 尾部恰好失真。用失真判定器去证明判定器安全，是自我指涉。
- **H30（力矩 vs 因果）**：力矩是"后果"不是"原因"——大力矩可能来自坡度/载荷/长杠杆而非坏表面，小力矩可能是尚未接触或杠杆极短。把力矩当 ground truth 会犯"以果代因"；且传感器有漂移/饱和/串扰/温漂，物理通道也会撒谎。
- **H31（柔顺 vs 可辨识）**：柔顺接触用阻抗吸收不确定性，却污染了刚度观测（"观察者效应"）——越柔顺越安全，越难辨识表面；若把柔顺段产生的力矩当辨识证据，系统会"越探索越自信地错"。安全动作会腐蚀它自己产生的证据。

## 0. 直觉与动机

**灵感 1（模型量化 → 偏差界 + 精度经济）**
直觉：量化最重要的不是"变小"，而是它给了**一个误差预算**：舍入误差有界（≤Δ/2）、裁剪误差只伤尾部、校准漂移可在线估计。第 57 轮把安全押在"元先验正确"，但坏先验不可怕，**不可测的坏先验**才可怕。量化的思路是换一个信任对象：不信任量化判定器 q_Q，信任"q_Q 与全精度参考 q_ref 的偏差界 B(o)"——B 由 Lipschitz 常数、到量化支持集的距离、量化误差预算合成；B≤β 才采信快路径，B 一松就升级到影子全精度/共形带。于是"是否相信模型"变成一个**可在线测量、可被证伪的量**，而不是一个信念。顺带得到"精度经济"：bit 和探针一样是预算，高敏感/OOD 区域自动提位宽（悬崖边不压缩），低风险区域用低位宽换实时。

**灵感 2（力矩传感 → 后果证据 + 物理硬界）**
直觉：视觉会被透明冰面骗，触探会被薄壳骗，先验会有盲区，但**力矩传感器量的是伤害本身**。把 tau 加入模态集，不是"多一个投票者"，而是把证据从"关于表面"转成"关于后果"。更强的是：执行器的力矩上限 τ_cap 是**不依赖任何模型的物理界**——即使表面判断全错，柔顺接触下的接触能量/冲量仍 ≤G(τ_cap)。这给动作集补上第三态"**有界柔顺探触 yield**"：用可承受的接触去换信息/推进任务，而不是非承诺即绕行。风险不再是"会不会判断错"，而是"判断错时最多付出多少"。

**灵感 3（合流 → 双硬界安全 DHS：认知界 × 物理界）**
直觉：第 57 轮的安全链再长，本质仍是"证据足够所以相信"；本轮加两条**不依赖证据正确性**的硬界：**(i) 认知硬界**——判定器的偏差被在线界定，超界即降级；**(ii) 物理硬界**——动作后果被力矩/能量限制，错了也可承受。于是总风险可分解为"非柔顺承诺的认知失效" + "柔顺接触的物理界失效"，后者与元先验质量无关。这才是对第 57 轮"坏先验普遍"的真正回答：**不要求先验正确，只要求先验的错误可界定、且动作的后果可承受。**

**灵感 4（量化审计 → 元模型更新与证书同走隔离）**
直觉：第 57 轮已让元模型更新走影子隔离；本轮把"量化版"也纳入同一隔离：任何新量化配置必须在影子流上同时通过"偏差界回归"（实测 |q_Q−q_ref|≤B ∧ ECE 不劣化 ∧ OOD 检出率不降）才可接管。量化不是部署细节，而是**证书的一部分**——换位宽等于换保证，必须重新签发。

**灵感 5（PCE++ → 精度-力矩-探询三元预算）**
直觉：每检查点不只问"探不探"，还问"用多高精度判定"与"允许多大力矩接触"。VOI 分成 VOI_q（多一位精度/一个探针能收缩多少偏差界）与 VOI_τ（放松 τ_cap 能换多少任务收益 vs 后果上界增量）。三个预算同向保守：精度有上限 b_max、探针 k_max、力矩有下限 τ_min，保证终止。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（证书保全量化 CPQ）** 量化配置 Q=(b_w,b_a,S_cal,[−c,c])，映射 Q(x)=s·round(x/s)+z，s=2c/(2^b−1)。误差分解 ε_Q(o)=ε_round+ε_clip(o)+ε_shift(o)：ε_round≤(Δ/2)√d 或逐层 Lip 传播；ε_clip=|y(x)−y(clip(x))|，只伤尾部、OOD 时激增；ε_shift=|y_{S_cal}−y_{S_deploy}|。证书膨胀：任何安全输出 y∈{ECE_k, coverage, OOD score, P_fail, 后验分位} 以 y_Q±ε_Q 进入下游，且只允许膨胀方向影响决策。动态精度：σ_sens(o)=|∂y/∂x|·d_Q(o)>θ_sens 或 OOD 分数高 ⇒ 提位宽/切全精度。契约：∀安全输出 |y_Q−y_ref|≤ε_Q（以 1−δ_Q），ε_Q 随位宽单调不增。

**定义 140（偏差界与影子验证 DBV）** 快路径 q_Q 与参考路径 q_ref（全精度慢速非参/集成）。可证偏差界
B(o)=Lip(q_Q)·d_Q(o)+ε_Q(o)+δ_cal(o)，
Lip(q_Q) 为量化网络 Lipschitz 上界，d_Q 为观测到量化校准支持集的距离，δ_cal 为参考路径自身误差界。采信 ⇔ B(o)≤β；否则按精度阶梯 escalate：提位宽→影子全精度→共形带。影子验证：抽样算实测 |q_Q−q_ref|，若实测>B ⇒ 判 B 失效，全局降级并审计。EV-bound 为 B≤β 且影子一致的偏差界证书。

**定义 141（力矩传感模态与后果模型 TS/CM）** 关节力矩 τ_j 经 Jacobian 映为接触 wrench w=(f,m)=(J^T)^+τ。tau∈ℳ。在线零偏 b̂=EMA(τ−τ_model)（自由空间）；饱和、漂移、串扰、带宽进 ρ_tau。后果模型 C(o)=h(w,l_eff,m_sup,μ,k)（l_eff 有效杠杆臂，m_sup 支撑多边形裕度）。区分**原因证据**（vis/tap 给表面属性）与**后果证据**（tau 给实际 wrench）；tau 经多值反演得表面推断，反演歧义（大力矩可能坡度/载荷/长杠杆）必须由其他模态消歧，不得单独定表面。

**定义 142（有界柔顺探触 YPC）** 动作第三态 yield(τ_cap,K_imp,Δt)：τ_cap 为硬件力矩上限（电流限/力矩限制器，策略不可逾越），K_imp 阻抗，Δt 接触时长。后果上界 G(τ_cap,l,Δt)：接触能量 E≤τ_cap·|Δθ| 或冲量 ≤τ_cap·Δt/l_eff。**安全接触与辨识探针分离**：yield 期间控制器阻抗污染刚度观测，故 yield 段不得作刚度辨识证据；辨识须独立 stiff-probe（K_imp 高、τ 小步）。接触级别扩展 L1.5"有界接触"：τ_cap≤τ_safe(l_eff,m_sup) 且 Δt 有界时可承接原 L2 任务，但不得进入"无界不可逆"必要证据集。

**定义 143（双硬界证据门 DHS 与证书 J_q）** 证据类 EV-probe*（须 EV-bound 或共形）/EV-visit/EV-margin/EV-xmodal（限 L1）/EV-torque（yield/实测，需 ρ_tau≥ρ_0 ∧ 未饱和 ∧ τ-reconciliation 一致）/EV-human（auth≥A1 ∧ 佐证≥corrob*(auth)）。不可逆接触必要证据集={EV-probe*∨EV-margin∨EV-torque}∪佐证，且 τ_cap≤τ_safe(l_eff,m_sup) 且 τ-reconciliation 无故障。J_q=(J_p 全部字段, quant_cfg, dev_bound_log, shadow_log, torque_log, bias_log, saturation_log, yield_log, tau_recon_log, τ_cap_audit)。

**定义 144（探-诺-演++ 算子 PCQ）** 每检查点：①量化推断+偏差界：B>β ∨ OOD ⇒ 精度阶梯/影子/共形；②对账（含 tau）：D(r)>θ_D ⇒ 共识探针；tau 与 vis/tap 分歧 ⇒ 后果复核（以 tau 为后果侧，重估 C）；③动作选择 {commit, yield(τ_cap), reroute, downgrade, negotiate, stop}，yield 的 VOI 用后果上界做悲观估计且不得替代辨识证据；④三元预算（k_probes,b,τ_cap）在 k_max,b_max,τ_min 内终止。

## 2. 关键算法伪代码（完整版见产物区）

```python
def cert_quant_infer(M, r, obs, qQ, qref):          # IP-139/140
    yQ = qQ(obs, z=ctx(r))
    B = lip(qQ)*dist_to_calib(obs) + qQ.eps_round + qQ.eps_clip(obs) + delta_ref
    if B <= beta:
        return Inf('Q-OK', post=yQ, bound=B)         # 膨胀证书入下游
    if B <= beta_shadow and shadow_agree(qQ, qref, obs):
        return Inf('SHADOW', post=qref(obs), bound=B)
    return Inf('ESCALATE', belt=conformal_belt(...)) # 提位宽或共形

def torque_reconcile(tau_s, tau_c, tau_m, J):        # IP-141: 冗余对账
    w = pinv(J.T) @ tau_s
    fault = (abs(tau_s-tau_c) > k1*sig_c) or (abs(tau_s-tau_m) > k2*sig_m) \
            or saturated(tau_s)
    rho_tau = down(rho_tau) if fault else up(rho_tau)
    return w, rho_tau, fault
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| CPQ | O(d/w) 推理；O(1) 误差合成 | O(b·|W|) | ε_Q 分解诚实、动态精度触发可靠（A41） |
| DBV | O(1)+O(d) 距离 | O(影子样本) | B 为上界、影子可证伪（A42） |
| TS/CM | O(1)+O(J⁺) | O(|ℳ|) | 零偏/饱和/故障在 ρ_tau 诚实（A43） |
| YPC | O(1)/tick | O(1) | τ_cap 不可逾越、后果界有效、证据解耦（A44） |
| DHS | O(|σ|) | O(|σ|) | 无证据类即拒、yield 不作不可逆证据 |
| PCQ | O(|CP|·(k_p+k_c)·(C_VOI+d/w)) | O(|V|+|σ|) | 三元预算终止、精度阶梯有限 |

**正确性定理（Certified-Bounded Physical Soundness, CBPS 概要）** 在 A33–A40 上加 (A41) 量化误差界诚实且动态精度可靠；(A42) 偏差界 B 以 1−δ_b 为上界、影子证伪即降级；(A43) τ_cap 硬件不可逾越、力矩传感故障经 τ-reconciliation 检出（漏检 ≤δ_τ）、饱和/漂移诚实；(A44) yield 后果界有效且安全接触与辨识探针分离。则：
(i) **认知界**：非柔顺承诺失效率 ≤ δ_f+ε_meta(k)+ε_Q+δ_bound+δ_probe+ε_h+δ_ood·α_conf+δ_xm·1[L1]；
(ii) **后果界（新）**：任何 yield 接触的实际能量 E≤G(τ_cap,l_eff)，与信念正确性无关，故 P(损伤|yield) ≤ P(τ_cap 失效)+δ_τ，**不随 ε_meta 增大**；
(iii) **解耦**：总伤害 ≤ P(yield)·(δ_phys) + P(non-yield)·P_epi——提高 yield 占比即用物理界替换认知界，二者独立失效才致伤；
(iv) **交互单调性**：提精度、紧 τ_cap、增探针、切柔顺均只向保守方向，膨胀证书只增宽；
(v) **终止性**：精度阶梯 b≤b_max、探针 k≤k_max、力矩 τ_cap≥τ_min，PCQ 有限步终止。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 量化尾部失真使证书在最需要处失效 | 高 | 动态精度（悬崖边不压缩）+ 膨胀证书 + 影子证伪 |
| 力矩传感器故障把危险读成安全 | 高 | τ-reconciliation（电流/模型冗余）+ 饱和检测 + 故障即停 |
| 柔顺掩盖刚度、污染辨识证据 | 高 | 安全接触与辨识探针彻底分离；yield 不作刚度/不可逆证据 |
| 杠杆臂/支撑几何估计错使 τ_safe 失真 | 中高 | 几何不确定度进 τ_safe 保守化 + 视觉/本体交叉校验 |
| 精度阶梯/影子带来时延 | 中 | 预取 + 分级触发 + 可退回 r57 纯共形路径 |

## 6. 本轮最大风险

**一句话**：本轮把安全的最后兜底押在"物理硬界"上，但 τ_cap 的"硬"依赖三样会撒谎的东西——力矩传感器（漂移/饱和/串扰）、杠杆臂与支撑多边形的几何估计（可能错）、执行器限幅的实现（可能被绕过）；一旦传感器把大接触读成小力矩，"有界接触"就成了"盲目的有界"，而柔顺控制还会掩盖本可用于发现错误的刚度证据——必须以电流/模型对力矩做冗余对账、把安全接触与辨识探针彻底分离、并坚持 yield 永不作为不可逆接触的证据，否则"可承受的错误"会退化为"未被发现的错误"。

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CPQ | O(d/w) 推理；O(1) 合成 | O(b·|W|) | ε_Q 诚实、动态精度可靠（A41） |
| DBV | O(1)+O(d) | O(影子样本) | B 为上界、影子可证伪（A42） |
| TS/CM | O(1)+O(J⁺) | O(|ℳ|) | 零偏/饱和/故障诚实（A43） |
| YPC | O(1)/tick | O(1) | τ_cap 不可逾越、后果界有效（A44） |
| DHS | O(|σ|) | O(|σ|) | 无证据即拒、yield 不作不可逆证据 |
| PCQ | O(|CP|·(k_p+k_c)·(C_VOI+d/w)) | O(|V|+|σ|) | 三元预算终止 |

**正确性定理（Certified-Bounded Physical Soundness, CBPS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 量化误差界：ε_Q=ε_round+ε_clip+ε_shift 可测且 |y_Q−y_ref|≤ε_Q（以 1−δ_Q），动态精度触发可靠；**(A42)** 偏差界：Lip(q_Q) 有效、d_Q 为有效距离、B(o) 以 1−δ_b 为上界，影子实测超界即全局降级；**(A43)** 力矩通道：τ_cap 为硬件不可逾越界、τ-reconciliation 对传感器故障漏检 ≤δ_τ、饱和/漂移/串扰在 ρ_tau 诚实；**(A44)** 有界柔顺：yield 接触能量 E≤G(τ_cap,l_eff) 且安全接触与辨识探针分离（yield 证据不入刚度辨识）。则：

1. **认知界**：非柔顺承诺 P(fail) ≤ δ_f + ε_meta(k) + ε_Q + δ_bound + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]。
2. **后果界（新）**：对任何 yield 接触，实际 E ≤ G(τ_cap,l_eff)，与信念无关；故 P(损伤|yield) ≤ P(τ_cap 失效) + δ_τ，且此项不含 ε_meta——**先验再坏也不能把有界接触变成无界伤害**。
3. **双硬界解耦**：总伤害 ≤ P(yield)·(δ_phys) + P(non-yield)·P_epi；仅当认知界与物理界**同时**失效才产生未被兜底的伤害；提高 yield 占比即以物理界替换认知界。
4. **交互单调性**：提精度、紧 τ_cap、增探针、切柔顺、膨胀证书均只经"信念更准/更宽"或"动作更保守/后果更小"两个通道影响系统，无升险路径。
5. **终止性**：精度阶梯 b≤b_max、探针 k≤k_max、力矩 τ_cap≥τ_min，PCQ 终止于 {承诺, 有界接触, 绕行, L2 协商, 安全停}。

**部署界**（对检查点取联合界，区分柔顺/非柔顺）：

```
P_safe ≥ 1 − Σ_cp [ P(non-yield_cp)·(δ_f+ε_meta+ε_Q+δ_bound+δ_probe+ε_h+δ_ood·α_conf+δ_xm·1[L1])
                  + P(yield_cp)·(P(τ_cap 失效)+δ_τ) ]
             − P(𝓜 陈旧未检出) − P(护盾回退失败)
```

关键：**量化不使证书变假，而让证书变宽**（误差预算显式进入下游，效率与安全再次解耦）；**力矩界让错误代价封顶**（物理硬界独立于任何学习判定器）；**柔顺动作把"不可逆承诺"变成"有界接触"**（用后果界换信息，而非用证据换承诺）；**安全接触与辨识探针分离**防止"越探索越自信地错"；四个新机制全部经"信念更准/更宽"或"后果更小"两个安全通道起作用。

## 6. 本轮最大风险

**一句话**：本轮把安全的最后兜底押在"物理硬界"上，但 τ_cap 的"硬"依赖三样会撒谎的东西——力矩传感器（漂移/饱和/串扰）、杠杆臂与支撑多边形的几何估计（可能错）、执行器限幅的实现（可能被绕过）；一旦传感器把大接触读成小力矩，"有界接触"就成了"盲目的有界"，而柔顺控制还会掩盖本可用于发现错误的刚度证据——必须以电流/模型对力矩做冗余对账、把安全接触与辨识探针彻底分离、并坚持 yield 永不作为不可逆接触的证据，否则"可承受的错误"会退化为"未被发现的错误"。
