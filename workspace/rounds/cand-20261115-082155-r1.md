# 第 4 轮（灵感循环第 4 轮；本轮灵感：「最优控制」×「泛化能力」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。最优控制只升级「IAC 的块规划」，泛化能力只升级「SC-Cal 的校准与热替换闸门」；两者都是可一键关闭的增强项。降级链：OptiGauge ⇒ InstructGauge ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE。

## 0. 直觉与动机

**灵感 1（最优控制 → 探测是一次对偶控制，而不是贪心选块）**
第 3 轮的 IAC 在每个决策点只解一次「当前信念下哪一块信息增益最大」，执行完再重来；这其实是**视界 H=1 的短视策略**。真实探测有**对偶效应**：动作既改变工件/场景，也改变我们对它的信念；先探哪里、探多深、何时停，应在信念空间里由**有限时域约束最优控制**统一决定。把状态从「几何 + 契约」提升为**信念 b**，动作从「块」提升为**探测控制 u**，就得到一个可滚动求解的 MPC：目标 = 风险 + 执行代价 − 信息价值 + 终端价值；硬约束（安全、预算、契约、不可逆屏障）全部留在约束侧，绝不折进软目标。结构收益：**块长 K 成为最优解的前缀，而不再是输入超参**；`H=1` 且阶段代价取 IAC 同式时，逐指令退回 InstructGauge。

**灵感 2（泛化能力 → 证书必须声明「在哪个域上成立」）**
ToolGauge 的共形契约与 InstructGauge 的分层校准，都默认校准集与部署同分布。产线换材料/批次/照明/工具时，问题不是覆盖率「略降」，而是**可交换性直接失效**：证书仍以 `1−α` 的名义说话，却已不成立。泛化能力要求把证书从「一个阈值」升级为 `GenCert = (claim, A, ε_gen, 1−α, evidence)`：只在适用域 `A` 内声称覆盖，出 `A` 就降级为短视 + 全局阈值。同时，MPC 用的动力学模型本身也会泛化失败，必须用**共形扰动集 + 鲁棒管**把模型误差显式入账，而不是假装模型正确。

**灵感 3（两者耦合 → 泛化误差被视界放大，必须用 H_MAX 夹住）**
最危险的不是「长视界」也不是「分布外」，而是**在分布外做长视界规划**：MPC 会主动利用模型误差，把「模型以为信息量大」的轨迹排到最前，真实世界却不买账——这是**优化器诅咒**。误差沿视界累积，于是「看得越远、错得越自信」。解法与第 3 轮的 `κ_sem` 同构：定义**视界-模型误差放大因子** `κ_oc = H·ε_model`，由泛化证书给出 `H_MAX(ε_model)`，再叠加 `CBF-QP`、共形鲁棒管与 `GenGate`。**证书先于视界，视界先于收益**。

## 1. 研究问题（本轮要回答什么）

- **Q1（可退化性）**：探测能否写成信念空间的有限时域约束最优控制，并保证 `H=1` 时**精确**退回 IAC，而不是「近似像」？
- **Q2（视界的净收益）**：多步前瞻相对贪心到底买到了什么？模型误差多大时，长视界反而有害（优化器诅咒），阈值如何定量？
- **Q3（泛化的可判定性）**：契约/校准的「泛化」能否变成带适用域与容差的证书？域偏移如何进入约束满足与覆盖保证，而不是一句「泛化良好」？
- **Q4（耦合放大）**：泛化误差是否随视界放大？`H_MAX(ε_model)` + 共形鲁棒管能否把放大从无界压回可界，并在不可认证处退化为单步？

## 2. 四条设计原则（雏形，正式化见产物区定义 448–463）

**P1 视界可退化（Horizon Degradability）**
`H=1` 且阶段代价取 IAC 同式 ⇒ 与 InstructGauge 逐指令等价。MPC、VoI、CBF、tube、DG-Cal 全部是可关闭增强；任何求解失败都退回贪婪分块，而不是「降级为一个更差的控制器」。

**P2 证书先于视界（Certificate-before-Horizon）**
只有 `GenCert` 在当前域有效时才允许 `H>1`；`H ≤ H_MAX(ε_model)`，其中 `ε_model` 来自共形扰动集。**没有泛化证书，就没有长视界**——这是本轮把「泛化」接进「最优控制」的唯一正确入口。

**P3 探索须付费且不可越界（Bounded Exploration）**
信息价值只能作为**有界**负代价进入目标；任何硬约束（安全、预算、不可逆）都不因探索而放松；`CBF-QP` 对 MPC 名义控制做最小侵入修正。探索是「买信息」，不是「买许可」。

**P4 分布外即降级（OOD ⇒ Degrade）**
`GenGate` 判定出适用域 ⇒ 强制 `H=1`、禁止契约热替换。宁可退回已经验证过的短视策略，也不在未认证域上滚动长视界。

## 3. 与基线的接口（如何退化）

- MPC 求解失败 / 超时 / 动力学模型不可用 ⇒ IAC 贪婪分块（InstructGauge）；
- `GenGate` 拒斥或 OOD 得分越界 ⇒ `H=1` + 禁用热替换 ⇒ 逐步/分块 InstructGauge；
- 共形扰动集失效（残差重尾 / 可交换性检验失败）⇒ 确定性最坏情况管或 `K=1` ⇒ ToolGauge；
- DG-Cal 样本不足 / 元测试不通过 ⇒ SC-Cal 分层 ⇒ 全局共形 ⇒ ToolGauge；
- CBF-QP 不可行 ⇒ 离散安全盾 / `K=1` ⇒ ToolGauge；
- InstructGauge 失效 ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个**信念空间约束 MPC** 的探测控制器，把对偶控制、终端信息价值与硬约束统一，并严格包含 IAC 为 `H=1` 特例；
2. 一套**共形鲁棒管**保证：把模型误差变成显式扰动集，给出 `1−α−Δ_gen` 的约束满足界与递归可行性条件；
3. 一个**域泛化元共形校准 + GenGate**：让「泛化」成为可判定的适用域与可入账容差，而不是一句口号；
4. 一条完整可证伪路径：E457–E472 覆盖退化等价、递归可行、视界收益、优化器诅咒、共形管覆盖、留一域泛化、OOD 闸门、证书重放与 50Hz 时序。

## 5. 本轮最大风险

**一句话**：整套保证的分母是 `GenCert` 的适用域——若校准覆盖的源域并未真正包住部署域，`H_MAX` 会被系统性高估，长视界 MPC 会把「证书没覆盖到的模型误差」当成可利用的信息价值放大执行，于是越「认证」越错；真正残余的风险在证书自身的适用域，而不在控制器。

## 2. 形式化定义（要点）

**定义 448（探测信念 MDP）** `M_b = (S, U, Θ, f, O, β, b_0, ℓ)`。状态 `x_t = (s_t, b_t)`；转移 `s_{t+1} ~ f(·|s_t,u_t)`，观测 `y_{t+1} ~ O(·|s_{t+1})`，信念 `b_{t+1} = β(b_t,u_t,y_{t+1})`。`U = U_c × U_d`：`U_c` 为连续探测参数（位姿、驻留、曝光），`U_d` 为离散工具/模式选择（`⊆ T₀`，继承 ToolGauge 工具集）。信念的后验同时覆盖几何盲区与计量契约参数，因此「探测」天然是**对偶**的：它同时改变 `s` 与 `b`。

**定义 449（有限时域约束最优探测 OCP_H）**
`min_{u_{0:H-1}} E[ Σ_{t=0}^{H-1} ℓ(s_t,b_t,u_t) + V_H(b_H) ]`，其中
`ℓ(s,b,u) = c(u) + λ_r R(s,b,u) − λ_i VoI_t(u)`，
约束：`s_{t+1}=f(s_t,u_t)`、`b_{t+1}=β(b_t,u_t,y_{t+1})`、`u_t ∈ U_safe(s_t)`、`s_t ∈ S_safe`、`Σ_t c(u_t) ≤ B_left`、契约约束（InstructGauge 定义 433 的 `Φ/B/≻`）、不可逆屏障（定义 445）。`V_H(b) = max_{u} E[−λ_i VoI_H(u) + λ_r R]` 是终端信息价值，而不是零终端代价。所有硬约束在约束侧，`λ_i` 只在目标侧。

**定义 450（滚动时域策略与前缀执行）** 在每个决策边界由当前信念解 `OCP_H` 得 `u*_{0:H-1}`；取满足 CVC（InstructGauge 定义 435）与预算的最长可行前缀 `K* ≤ H`，执行 `u*_{0:K*-1}`，到边界重规划。`π_MPC(b) = u*_{0:K*-1}`。**`K` 是输出，不是输入**：它由最优解与 CVC 共同决定。`H=1` 时无前瞻，退化为单步贪心。

**定义 451（对偶效应与有界探索）** `VoI_t(u) = I(b_t; y_{t+1} | u_t) = H(b_t) − E_{y|u}[H(b_{t+1})] ≥ 0`。探索项强制截断：目标中实际使用 `−λ_i·min(VoI_t(u), V_max)`，其中 `V_max = log|S|` 或预注册常数。关键性质：截断只改目标值，不改可行集，因此 `λ_i` 取任意大都不会使硬约束失效。定义对偶系数 `D_t = ∂H(b_{t+1})/∂u_t`，用于诊断「为控制而探」与「为信息而探」两类动作。

**定义 452（CBF-QP 安全过滤器）** 设 MPC 名义控制 `u⁰_t`。过滤器解
`u*_t = argmin_{u∈U} ‖u − u⁰_t‖²_Q`
`s.t. L_f h_j(s_t) + L_g h_j(s_t) u + α_j(h_j(s_t)) ≥ 0, ∀j; u ∈ U_box`。
若可行，`u*` 是名义控制的最小侵入修正；若不可行，不松弛约束，而是**触发回退**：离散工具切到安全可采纳集，连续动作退回 `K=1` + ToolGauge 离散盾。CBF 只作用于 `U_c`；`U_d` 由 `𝔸_adm` 与不可逆屏障先行过滤，避免把离散选择塞进 QP 造成不可行。

**定义 453（共形扰动集）** 在校准轨迹上收集一步残差 `r_i = s_{i+1} − f̂(s_i,u_i)`。用 split conformal 取分位 `q_δ`，令 `D_δ = {r : ‖r‖_{Σ^{-1}} ≤ q_δ}`。若残差可交换，则 `P(r ∈ D_δ) ≥ 1−α`。`ε_model := q_δ` 是模型误差的**可入账**上界；它同时进入管收紧与 `H_MAX`。

**定义 454（广义证书 GenCert）** `G = (claim, A, ε_gen, 1−α, evidence, expiry)`。`claim` 是「在适用域 `A` 内，覆盖/误差满足 `ε_gen`」；`evidence` 含源域校准集、留一域元测试结果、样本量 `n` 与可交换性检验。`valid(G,d) = (d ∈ A) ∧ meta_test(G) ∧ (n ≥ n_min)`。`GenCert` 是**带域的命题**，不是全局真值；离开 `A` 它不声称任何东西。

**定义 455（DG-Cal 域泛化元共形校准）** 域嵌入 `φ(d)`；元先验 `q_0`；对目标域 `d` 用加权分位
`q_d = Quantile_{1−α}({r_i : d_i ∈ D_src}, weights w_i ∝ exp(−‖φ(d)−φ(d_i)‖²/2σ²))`。
若权重密度比有界 `w_i ≤ w_max`，加权共形给出 `P(r ≤ q_d) ≥ 1−α − (w_max−1)/(w_max+1)` 形式的保守界；若密度比未知，则用 `A` 内的 TV 界（引理 63）。`|C_cal^d| < n_min` 时回退 SC-Cal 分层，再回退全局。

**定义 456（适用域 A 与 GenGate）** `s_OOD(d,x) = dist(φ(d), supp(φ(D_src)))`（可用 kNN/Mahalanobis）。阈值 `τ_gate` 由源域留出集按误接受率 `≤ β` 校准。闸门输出三元组
`GenGate(d,x) = (allow_long, allow_hot_replace, fallback_stratum)`：
`allow_long = (s_OOD ≤ τ_gate) ∧ valid(G,d)`；
`allow_hot_replace = allow_long ∧ 元测试覆盖达标`。
不通过时 `H ← 1` 且禁用热替换，并记录一次「证书拒斥」审计事件。

**定义 457（视界-模型误差放大因子）** `κ_oc = ε_model · Σ_{i=0}^{H-1} L_f^i`（`L_f` 为 `f̂` 的 Lipschitz 常数）。稳定系统 `L_f<1` 时 `κ_oc ≤ ε_model/(1−L_f)`，与 `H` 脱钩；临界/不稳定系统 `κ_oc = O(H)`。这就是「误差沿视界放大」的定量形式，也是与第 3 轮 `κ_sem = K·H(ι|ℓ)` 的结构对应。

**定义 458（泛化感知视界上界 H_MAX）** `H_MAX(G,ε_model) = max{H : κ_oc(H,ε_model) ≤ κ₀ ∧ 管可收紧 ∧ 预算可准入}`。实用简化 `H_MAX = ⌊H₀/(1+κ_oc)⌋`。`G` 无效或 OOD ⇒ `H_MAX = 1`。证书先于视界：`H` 一律取 `min(H_plan, H_MAX)`。

**定义 459（鲁棒管与收紧约束）** 误差动力学 `e_{t+1} = A_K e_t + w_t`，`w_t ∈ D_δ`；管不变量 `Z` 满足 `A_K Z ⊕ D_δ ⊆ Z`。收紧状态/控制约束 `S_t ⊖ Z`、`U ⊖ KZ`；tube-MPC 在收紧约束上求解。`Z` 越大（泛化越差），可行域越小，直到 `H_MAX=1`——这是泛化失败在几何上的可见后果。

**定义 460（风险敏感目标，可选）** 将期望目标替换为 `CVaR_β(ℓ + 1{约束违反}·c_v)`；`β→1` 退化为最坏情况，`β→0` 退化为期望。默认关闭（风险中性），仅作为 E468 消融项，保证主链与 InstructGauge 可比。

**定义 461（留一域泛化协议）** 把源域划分为 `D_train / D_cal / D_test`，元训练只在 `D_train`，校准只在其一，测试在**完全未参与**的留出域上进行；报告每域的覆盖差 `|cov_test − (1−α)|` 与 `Δ_gen` 估计。该协议是 `GenCert.evidence` 的唯一合法来源；同域随机划分不算泛化证据。

**定义 462（OptiCert 组合证书）** `OptiCert(s) = (ι, u*_{0:K-1}, CVC, GenCert, TubeCert, DGCalCert, receipts, claims)`。每个子证书有独立验证器；组合规则是**与**：任一子证书缺失或过期 ⇒ 返回降级标记，由定义 463 执行回退。`OptiCert` 使审计可沿「指令 → 视界/管 → 块 → 逐步回执 → 主张」五级链复现。

**定义 463（闸门与回滚语义）** 热替换允许当且仅当
`q_quiesce ∧ GenGate.allow_hot_replace ∧ OptiCert valid`。
否则保留旧契约、`H=1`、继续探测；回滚在 `q_quiesce` 原子完成（继承 InstructGauge 定义 439 与引理 57）。所有拒斥/回退写入审计日志，绝不以「静默继续」代替降级。

# IP-328/329 B-MPC：信念空间约束最优探测（滚动时域）
class BeliefMPC:
    def solve(self, b, iota, budget, gen_cert, tube):
        H = min(self.horizon, H_MAX(gen_cert, tube.epsilon))
        if H <= 1 or not gen_cert.allow_long:
            return self.myopic(b, iota, budget)          # = IAC，见引理 59
        x0 = (self.env.state(), b)
        # 目标：风险 + 代价 - 有界信息价值 + 终端价值；约束：安全/预算/契约/屏障
        u_star = self.ilqr_or_box_qp(
            x0, H,
            stage=self.stage_cost,                        # ℓ = c + λr·R - λi·min(VoI,Vmax)
            terminal=self.terminal_value,                 # V_H = -λi·VoI + λr·R
            constraints=self.tightened_constraints(tube), # S⊖Z, U⊖KZ
            barrier=self.irreversibility_barrier(iota),   # 跨不可逆强制 H=1
            budget=budget,
        )
        if u_star is None:
            return self.myopic(b, iota, budget)           # 求解失败 ⇒ IAC
        return u_star

    def stage_cost(self, s, b, u):
        voI = mutual_information(b, u)                    # H(b) - E[H(b')]
        risk = self.risk_model(s, b, u)                   # 与 ToolGauge 风险同口径
        return self.cost(u) + self.lam_r * risk - self.lam_i * min(voI, V_MAX)

    def terminal_value(self, b):
        # 视界末端仍带信息价值，避免"到边界就停止探索"的短视
        return -self.lam_i * self.expected_future_voi(b) + self.lam_r * self.tail_risk(b)


# IP-330 CBF-QP：对名义控制做最小侵入修正
def cbf_qp(u0, s, h_fns, alphas, Q):
    # min ||u-u0||_Q^2  s.t.  Lf h_j + Lg h_j u + alpha_j(h_j) >= 0,  u in U_box
    u = solve_qp(u0, s, h_fns, alphas, Q)
    if u is None:                                         # 不可行 ⇒ 不松弛
        return None, "fallback_discrete_shield_or_K1"
    return u, "ok"


# IP-331 CT-Tube：共形扰动集 + 管不变量 + 约束收紧
class ConformalTube:
    def build(self, residuals, alpha):
        q = conformal_quantile(residuals, alpha)          # P(r in D_delta) >= 1-alpha
        D = Ellipsoid(radius=q, metric=self.sigma_inv)
        Z = invariant_set(self.A_K, D)                   # A_K Z + D ⊆ Z
        self.epsilon = q
        return Tube(D, Z, tighten(self.S_safe, Z), tighten(self.U_box, self.K @ Z))

    def tightenable(self, H):
        return self.S_tightened.nonempty() and self.U_tightened.nonempty()


# IP-332 DG-Cal：域泛化元共形
class DGCal:
    def calibrate(self, d, residuals_by_domain):
        s = stratum(d) if len(residuals_by_domain.get(d, [])) < N_MIN else d
        if s not in residuals_by_domain or len(residuals_by_domain[s]) < N_MIN:
            return SC_Cal.threshold(d, residuals_by_domain)   # 回退分层/全局
        w = self.domain_weights(d, residuals_by_domain)        # 与 phi(d) 的相似度
        return weighted_quantile(residuals_by_domain[s], w, alpha=ALPHA)

    def meta_update(self, q_prior, domain_scores):
        # 元先验 + 域内证据；仅在留一域元测试通过后写入 GenCert.evidence
        return self.meta_learner.update(q_prior, domain_scores)


# IP-333 GenGate：适用域 + 元测试 + 闸门
class GenGate:
    def check(self, d, x, gen_cert, meta_test):
        ood = self.ood_score(d, x)                        # dist to source support
        base = (ood <= self.tau_gate) and gen_cert.valid(d)
        return {
            "allow_long": base,
            "allow_hot_replace": base and meta_test.coverage >= 1 - ALPHA - EPS_GEN,
            "fallback_stratum": "global" if ood > self.tau_gate else stratum(d),
            "ood": ood,
        }


# IP-334 8C 闭环
def optigauge_8c(M, s, ell):
    out  = M.nlib.ground(ell, M.scene, M.ontology)
    iota = out[0] if out else M.default_iota            # ⊥ ⇒ InstructGauge 默认目标
    H    = M.lbox.hypothesize(s, M.dbox.R[s], iota)
    gate = M.gengate.check(M.domain(s), M.scene, M.gen_cert, M.meta_test)
    if not gate["allow_long"]:
        C = M.iac.plan_chunk(iota, H, M.tools, M.budget_left(s), M.drift_bound(s))
        cert = M.cvc.commit(C, M.env, iota)              # 精确退回 InstructGauge
        return finish_instructgauge(M, cert, iota, H, s)
    tube = M.cttube.build(M.residuals, ALPHA)            # 共形扰动集 + 管
    if not tube.tightenable(H_MAX(M.gen_cert, tube.epsilon)):
        C = M.iac.plan_chunk(iota, H, M.tools, M.budget_left(s), M.drift_bound(s))
        return finish_instructgauge(M, M.cvc.commit(C, M.env, iota), iota, H, s)
    u_star = M.bmpc.solve(M.belief(s), iota, M.budget_left(s), M.gen_cert, tube)
    if u_star is None:
        C = M.iac.plan_chunk(iota, H, M.tools, M.budget_left(s), M.drift_bound(s))
        return finish_instructgauge(M, M.cvc.commit(C, M.env, iota), iota, H, s)
    u_nom = u_star[0]                                    # MPC 名义控制
    u_safe, status = cbf_qp(u_nom, M.env.state(), M.h_fns, M.alphas, M.Q)
    if u_safe is None:
        return fallback_to_toolgauge(M, s, status)        # 离散盾 / K=1
    C = M.iac.prefix(u_star, M.cvc, iota)                # K* 为最优解 + CVC 前缀
    cert = M.cvc.commit(C, M.env, iota)
    receipts = cert.receipts
    if len(receipts) < n_min(s):
        return stub_and_red(s, "insufficient")
    mu, Sig = M.apcal.calibrate(receipts, H, s)
    if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):
        return stub_and_red(s, "cross_failed")
    new_ec = M.apcal.update_contract(M.dpe, mu, Sig, s)
    if not contract_regression(new_ec):
        return stub_and_red(s, "regression")
    if gate["allow_hot_replace"] and M.mreg.at_quiescence(cert.boundary):
        M.mreg.hot_replace(M.dpe, new_ec)                # 仅在静默点 + 闸门通过
    bind_claims(cert, iota, receipts)
    M.optcert.record(iota, u_star, cert, M.gen_cert, tube, M.dgcal.last)
    M.pquar.record(M.apcal.last_gain, realized_gain(receipts))
    return True


# IP-335 主闭环（50Hz 路径不变；MPC 异步下沉）
def OptiGauge_round(M, obs, audio, tac, depth, det, ell=None):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s)
            submit_async(optigauge_8c, M, s, ell)          # 不阻塞 50Hz
    return MODGAUGE_round(M, obs, audio, tac, depth, det)

## 4. 推导

**引理 59（H=1 退化等价）** 若 `H=1` 且阶段代价取 InstructGauge 定义 436 的同一目标（符号按 `ℓ = −ΔH − w_align·A − w_ens·smooth + λ_cost·c` 对齐），前缀/截断规则沿用 CVC，则 `π_MPC` 与 IAC 的 `C*` 逐指令相同；当 `GenGate` 判 `H=1` 时，OptiGauge 的整条执行路径与 InstructGauge **逐指令等价**。
*证明骨架*：`H=1` 时 `OCP_1` 的可行集与 IAC 的 `admissible` 集逐条对应（安全盾、`K_MAX`、`Barrier`、预算均相同），目标退化为同一阶段目标的 argmax，终端项为常数；CVC 前缀选择不依赖控制来源。对决策边界归纳即得全链等价。

**引理 60（滚动时域递归可行性与稳定性）** 假设 (i) 终端集 `X_f ⊆ S_safe ⊖ Z` 在终端控制器 `κ_f` 下受控不变；(ii) 终端代价 `V_H` 在 `X_f` 上是 Lyapunov 函数，满足 `V_H(f(x,κ_f)) − V_H(x) ≤ −ℓ(x,κ_f)`；(iii) 真实扰动 `w ∈ D_δ`；(iv) `t=0` 时 `OCP_H` 可行。则对任意 `t` `OCP_H` 可行，闭环满足收紧约束；无扰动时渐近稳定，有界扰动下 ISS。
*证明骨架*：标准 Mayne–Rawlings 移位论证。把 `t` 时刻最优序列的尾部 `u*_{1:H-1}` 与终端控制器 `κ_f` 拼接，作为 `t+1` 的可行候选；终端不变性保证拼接后仍满足约束，终端 Lyapunov 性给出代价下降。`H_MAX` 只限制候选视界，不破坏该论证。

**引理 61（信息价值上界与探索不越界）** `0 ≤ VoI_t ≤ H(b_t) ≤ log|S|`，故截断 `min(VoI,V_max)` 有界且不改变可行集；对任意 `λ_i ≥ 0`，硬约束仍逐条成立。模型精确时 `V_H^*(b) ≥ V_1^*(b)`，前瞻收益至多 `(H−1)·ΔI_max`，其中 `ΔI_max` 为单步最大可获信息。
*证明*：互信息非负且不超过熵；截断只作用于目标项；可行集由约束定义，与 `λ_i` 无关。`V_H ≥ V_1` 因 `H=1` 策略是 `H` 步策略的特例；收益上界由每步信息增量求和。

**引理 62（共形管约束满足，分布内）** 若校准残差与部署残差可交换、`P(w ∈ D_δ) ≥ 1−α`，且 tube 对 `D_δ` 内所有扰动可行，则单步闭环约束满足概率 `≥ 1−α`；对 `H` 步采用轨迹级共形时 `≥ 1−α`，逐点共形 + 并集界时 `≥ 1−Hα`。
*证明*：管不变量把任意 `w∈D_δ` 的误差锁在 `Z` 内；收紧约束 `S⊖Z` 保证真实状态留在 `S_safe`。覆盖概率由 split conformal 的可交换性给出；多步版本按「轨迹级」或「逐点 + 并集」分别计数。

**引理 63（泛化间隙传播）** 设源域与目标域分布的总变差 `TV(P_src,P_tgt) ≤ Δ_gen`。则对任意事件 `E`，`P_tgt(E) ≥ P_src(E) − Δ_gen`；因此目标域覆盖 `≥ 1−α−Δ_gen`。对 `L`-Lipschitz 的期望代价，`|J_tgt − J_src| ≤ L·Δ_gen`。
*证明*：总变差定义直接给出任意事件概率差的上界；代价差用对偶表示/Lipschitz 性质。该式说明 `GenCert` 必须显式携带 `Δ_gen`；`Δ_gen` 未知时不能声称目标域覆盖。

**引理 64（视界-泛化放大与收益阈值）** 单步模型偏差对代价的贡献 `≤ L·ε_model`，`H` 步累计 `≤ L·H·ε_model`；前瞻信息收益 `≤ (H−1)ΔI_max`。故长视界**净收益为正的充分条件**为 `(H−1)ΔI_max ≥ L·H·ε_model`，等价于 `ε_model ≤ ΔI_max/L · (H−1)/H`。当 `ε_model > ΔI_max/L` 时，任何 `H>1` 都可能劣于 `H=1`；这给出 `H_MAX` 的显式形式，也解释了优化器诅咒：MPC 优化的是 `f̂` 下的收益，真实收益的误差项随 `H` 增长，而信息项饱和。
*证明*：对单步代价差用 Lipschitz 界并求和；信息收益上界由引理 61。比较 `H` 与 `1` 的下界即可。推论：由引理 63，`Δ_gen↑ ⇒ ε_model↑ ⇒ H_MAX↓`；`Δ_gen` 足够大时只剩 `H=1` 可认证。

**引理 65（元共形覆盖界）** 在留一域协议与元先验 `Q` 下，目标域覆盖满足（示意形式）
`cov_tgt ≥ 1−α − sqrt((KL(Q‖P) + log(1/δ))/(2n_domains)) − Δ_gen`；
若目标域密度比有界 `w_max`，加权共形把 `Δ_gen` 收紧到 `(w_max−1)/(w_max+1)` 量级。低样本域回退 SC-Cal 时，覆盖按第 3 轮引理 55 的 `−2η_global` 优雅降级，而不是无界崩塌。该界是 `GenCert.ε_gen` 的取值来源；`ε_gen` 必须把 PAC-Bayes 项与 `Δ_gen` 同时计入，否则证书偏乐观。

**引理 66（OptiCert 组合与全链退化等价）** 若所有子证书有效且 `GenGate` 通过，`OptiCert` 的端到端保证是各子证书保证的交（取最弱项）；若任一子证书缺失/过期，按定义 463 的回退映射 `D` 执行，且 `D` 在每条路径上**恒等于**对应基线的语义：`GenGate` 失败 ⇒ 恒等映射到 InstructGauge（引理 59），tube 失效 ⇒ ToolGauge，DG-Cal 不足 ⇒ SC-Cal（引理 55），CBF 不可行 ⇒ 离散盾。热替换仅在 `q_quiesce` 且闸门通过，故不存在「混合契约」被任何在途块观察到。
*证明骨架*：对闸门标志与子证书有效性做有限情形枚举；每支由对应引理的等价性给出。组合处取交是标准证书组合；回退处由构造保证不含近似超参，因此是语义恒等而非「近似」。

| 泛化覆盖（E463/E466） | 留出域 ≥ 0.90 − ε_gen | 增大元校准集或回退 SC-Cal |
| OOD 闸门（E465/E471） | AUROC ≥ 0.90，误接受 < 1% | 降低 `τ_gate`，宁可多拒斥 |
| 共形管（E462） | 违反 ≤ α + 0.02 | 增大分位或退确定性最坏情况管 |
| 时序（E469） | 新增 < 0.2ms | 缩短 `H_MAX` 或进一步异步下沉 |
| 证书组合（E472） | 重放一致且混合契约 = 0 | 禁用热替换，回退 InstructGauge |

预期：E457/E458/E472 为「结构级」判据，应严格成立；E459/E461/E462/E463/E466 为「统计级」判据，按置信区间验收；E467/E470 为「系统级」判据，给出效应量与置信区间。最关键的反直觉对照是 E460：**长视界在分布内更好、在分布外可能更差**——这直接检验本轮的核心论点。

## 8. 本轮最大风险

**一句话**：整套保证的分母是 `GenCert` 的适用域——有限源域给出的 `ε_gen` 与 `Δ_gen` 只是**估计**，若部署域落在 `A` 的边缘或之外，`H_MAX` 会被系统性高估，长视界 MPC 会把未被证书覆盖的模型误差当成可利用的信息价值放大执行，于是「证书齐全、指标漂亮」恰好在最需要安全的新材料/新场景上系统性失败；真正的残余风险是证书自身适用域的可信度，而不是 MPC 或 CBF 的局部正确性。
