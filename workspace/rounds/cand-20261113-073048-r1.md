# 第 3 轮迭代（灵感循环 v3：「数据标注」×「零样本泛化」）—— 把"造数据"升级为"造监督信号"，把"泛化"拆成可测量的五个缺口

> 承接 v2（UIP-01′~15）。v2 的核心工程是"用 Gazebo 造数据 + 物理判分"，它补上了公开数据缺失的人为干扰轴，但也暴露出 v2 自述的最大风险：**容易用仿真过拟合仿真**。本轮不推翻 v2，而是换一个更省、更可验证的杠杆：**赛题本身已经给了一份恰好够用的标注本体**（32 任务、94 个计分步、逐条泛化轴），真正的瓶颈不是再采十万条演示，而是**把这 3.2 万条无标注轨迹变成步骤级、方向级、角色级的监督信号**；同时把"零样本泛化"从一句口号变成**五轴可分解、可预算、可证伪**的指标。一句话：**v2 买数据，v3 买标签；v2 碰泛化，v3 量泛化。**

---

## 0. 事实基线与方法边界（避免"新事实"幻觉）

本轮为**离线综合轮**，不新增外部检索。以下事实均沿用 v2 已核实项（检索日期 2026-11-12）；本轮只增加**明确标注为 [推论]/[设计]** 的内容，不把推论写成事实。

| F2 | 全部计分步总数 = 11×2 + 14×3 + 5×4 + 2×5 = **94 个**；末步分值恒 ≥ 前序步 | [v2 核实] 由 F1 直接计算 |

**本轮最关键的重新解读（[推论]，高置信）**：F2 的 94 个计分步本身就是一套**领域标注本体（ontology）**——每个 `scoring_points` 文本天然对应一个"标签函数"的规格说明。于是问题从"如何人工标注 3.2 万条长轨迹"变成"如何为 94 个子目标各写一个可自动执行的谓词，并用少量人审校准"。这是一个**小本体 × 大数据**的弱监督问题，而不是传统意义上的大规模人工标注问题。

## 1. 直觉解释（先讲人话）

### 1.1 「数据标注」的直觉

模型不缺动作，缺的是"这一步算不算数"。赛制按**计分步**给分（50/50、30/30/40……），但公开数据只告诉你"整段演示最后成功了"，没告诉你"第几帧完成了第几步、第几步被退回了"。这就像考试只给总分、不给每道题的判分点：你能模仿，但学不会"哪一步值 30 分、哪一步一旦被退回要立刻补做"。所以**步骤级标注是把"模仿"变成"应试"的转换器**；而"进度被撤回"的标注，是把"应试"变成"抗干扰"的转换器。

### 1.2 「零样本泛化」的直觉

评测会换你没见过的杯子、把物体挪到训练分布外、加干扰物、换背景，甚至伸手把你的进度撤回去。你不可能把这些组合穷举进训练集。能迁移的不是"某个杯子的像素"，而是**关系与角色**："有个可抓的容器、有个目标槽位、要先对准再插入"。所以零样本不是免费午餐，而是**用正确的归纳偏置（角色 / 关系 / 方向）去换不变性**；换来多少，必须能分轴测量，否则只是"碰巧没翻车"。

### 1.3 合起来：标注是泛化的"买入期权"

你不需要为每个未见物体重新训练；你需要**标注一次"角色-关系-方向"**，让模型在未见实例上复用。标注买的是"可迁移的监督"，泛化是其兑现。v3 的全部设计围绕这条主线：**先造便宜且可审计的标签，再买可分解的泛化。**

## 2. 严谨定义

### 2.1 标注算子

轨迹 `τ = {(o_t, s_t, a_t)}_{t=1..T}`，任务语言 `l`，计分步 `{g_1..g_G}`、权重 `{w_g}`、`Σ w_g = 100`。定义标注算子

`A(τ, l) = ({b_j}, {c_{t,g}}, {r_t}, {ρ_t})`

- `b_j`：技能段边界（抓 / 放 / 插 / 拧 / 折 / 拉链 / …）；
- `c_{t,g} ∈ {0,1}`：t 时刻计分步 g 是否已被满足（步骤完成标签）；
- `r_t ∈ {−1, 0, +1}`：进度方向（回退 / 停滞 / 前进），由进度势 `Φ_g(s)` 的差分符号给出；
- `ρ_t`：角色图，把场景实例映射到 `{grasper, target, receptacle, tool, obstacle}`。

关键点：`s_t` 是公开数据里**训练期可用、推理期不可用**的特权信息，因此它只用于造标签，绝不进入推理路径。

### 2.2 弱监督标签与标签模型

每个计分步不写"硬标签"，而写一族标签函数 `λ_k: τ → {0,1,⊥}`（几何谓词、接触事件、语言约束）。用生成式标签模型估计各 `λ_k` 的准确率并聚合，得到去噪后的 `c_{t,g}` 与置信度。这样"标注质量"可估计、可审计，而不是拍脑袋。

### 2.3 五轴零样本泛化

记训练分布 `P_tr` 与测试分布 `P_te`，五轴 O/P/D/B/H 分别表示未见物体、位置布局、干扰物、背景、人为干扰。零样本条件：**不在 `P_te` 上做任何梯度更新**，只用推理期观测。定义单轴保持率

`R_a = M(P_te^a) / M(P_tr)，a ∈ {O, P, D, B, H}`

其中 `M = α · 成功率 + (1−α) · (步骤分 / 100)`。综合指标

`ZSG-5 = (1/5) Σ_a clip(R_a, 0, 1)`。

必须同时报告每轴 `Δ_a = M(P_te^a) − M(P_tr)`，因为平均值会掩盖"物体轴崩、背景轴好"的假象。

### 2.4 零样本干扰恢复率

对人为干扰轴单独定义：在 g 已完成后被撤回的条件下，策略在后续 H 步内重新完成 g 的比例

`ZDR = P(recomplete g within H | g: done → regressed)`。

这是 v2 UIP-09′ 的形式化版本，也是本轮可被直接优化的目标。

### 2.5 标注迁移收益

锚任务集 `A`（`|A| = 5`），其余任务 `t ∉ A`。用 A 上经人工审计的标签训练 / 校准后迁移到 t，比较

`TG_t = M_t(transfer) − M_t(scratch)`，

并报告零样本标注预算 `B` 下的 `TG_t(B)` 曲线。

- **升级为"标注驱动"**：UIP-01′（滚动验证）→ **UIP-01″**：验证器不再依赖外部 VLM，而由 UIP-19 RAV 提供；UIP-09′（干扰恢复）→ 用 UIP-19 的**方向感知头**实现；UIP-12 DRF 从"主线"降为"L3 标签的一个来源"。

- **保留**：UIP-02（计分安全网）、UIP-08′（多端口延迟工程）、UIP-11（GSO 作为 L2 精确标签源与物理反事实源）、UIP-13（ACS）、UIP-15（CSG）。
- **停手 / 降优先级**：不再扩大 Gazebo 场景数量（把算力转去造标签与做五轴评测）；不再追"更多同分布演示"，因为 F4 的边际价值低于步骤级监督。

## 4. 瓶颈假设（本轮）

- **H1（最高杠杆）**：步骤分瓶颈是**步骤级监督缺失**，不是模型容量；94 个计分步的自动标注覆盖率，是比参数量更强的预测变量。
- **H2**：零样本失败的分布高度不均；**O 轴与 H 轴**是两个断崖，P/D/B 轴相对便宜（可用 2D 合成 + 位姿随机化买到）。
- **H3**：**角色 / 关系标签比实例标签更可迁移**；"这是杯子"会过时，"这是可抓容器"不会。
- **H4**：标注噪声在**接触密集边界**（插入 / 合盖 / 拉链 / 折叠）系统性偏高 → 验证器必须能**弃权**并校准，否则会制造"自信地做错"。
- **H5**：每单位算力下，**便宜 2D 反事实 + 物理撤回**产生的零样本信号，远高于再采一批同分布真机数据。

## 6. 本轮押注

**押注：标注即泛化。** 用官方 94 个计分步作为免费本体，自动生成步骤 / 方向 / 角色三级标签，训练共享骨干上的角色-可供性验证器；再用五轴协议证明它真的在未见物体与人为撤回上兑现，而不是在自建谓词上自洽。**若这条成立，v2 的 Gazebo 工厂就从"必需品"降为"可选增强"，整个方案的成本结构与可信度都会变好。**

## 7. 本轮最大风险

**一句话**：最大的风险是"**用谓词标注、又用同一批谓词评测**"的循环论证——验证器可能只是在拟合我们手写的 94 个几何谓词，在未见物体与接触密集步上系统性失效；必须保留**谓词族留出 + 小规模人工金标审计 + 真机 / 榜单锚点**，否则越自动、越自欺。

## 1. 旗舰：UIP-16 · SAL（State-Aligned Labeling，状态对齐的自动标注）

### 1.1 为什么是"小本体、大数据"

| 步数 | 任务数 | 每任务步数 | 步数小计 |
|---|---|---|---|
| 2 步 | 11 | 2 | 22 |
| 3 步 | 14 | 3 | 42 |
| 4 步 | 5 | 4 | 20 |
| 5 步 | 2 | 5 | 10 |
| **合计** | **32** | — | **94** |

只需为 **94 个子目标**各写一个谓词族，就能给约 **32,000 条轨迹**打上帧级完成标签；标注成本与数据量解耦。这是本轮最硬的结构性优势。

### 1.2 四级标签（标注对象是"关系"，不是"实例"）

| 级别 | 标签 | 信号来源 | 用途 |
|---|---|---|---|
| L0 | 任务 / 语言标签 | 数据集自带 | 条件化、路由 |
| L1 | 技能段边界 `b_j` | 夹爪开合、末端速度过零、接触跃变、物体位姿不连续 | MSGR 技能图、ALTA 迁移 |
| L2 | 步骤完成 `c_{t,g}` | 94 个谓词族 + 时序逻辑（eventually & persist） | RAV 验证头、SSG 调度 |
| L3 | 方向 / 回退 `r_t` | 进度势差分；真实状态中罕见，主要由 GSO 脚本撤回与状态编辑增广 | 撤回检测、ZDR |
| L4 | 角色图 `ρ_t` | 语言 + 几何 + 特权状态 | 物体无关迁移、零样本替换 |

### 1.3 谓词族示例（可直接落地为标签函数）

| 任务 | 计分步谓词（示意） |
|---|---|
| T26 插网线 | `holds(rj45) ∧ near(port) ∧ insert_depth > D` |
| T27 叠碗 | `stacked_on(bowl2, bowl1) ∧ stable(Δt)`；`stacked_on(bowl3, bowl2)` |
| T19 拉链 | `zipper_pos ≥ z1`；`zipper_pos ≥ z2 ∧ ¬reopened` |
| T16 叠毛巾 | `fold_edge(毛巾, 边k) ∧ flat(毛巾)` 逐折递增 |
| T12 开锁 | `rotated(锁芯, θ) ∧ ¬relocked` |
| T14 倒药 | `cap_off ∧ poured(药, 目标) ∧ ¬cap_back` |

每个谓词都是 `τ → {0,1,⊥}` 的标签函数；`⊥`（弃权）是**一等公民**，用于接触遮挡与视角不可判。

### 1.4 自动标注伪代码

```python
def label_episode(tau, task):
    L1 = segment_skills(tau)                      # 夹爪/接触/速度边界
    votes = {}
    for g, step in enumerate(task.scoring_points):
        for k, lf in enumerate(step.label_fns):
            votes[g, k] = lf(tau)                 # 0 / 1 / None(弃权)
    c, conf = label_model.aggregate(votes)        # 生成式标签模型去噪
    r = direction_from_potential(tau, task, c)    # ΔΦ 的符号
    rho = role_graph(tau, task.language)          # 实例 -> 角色
    return Labels(L1=L1, step=c, direction=r, roles=rho, conf=conf)
```

### 1.5 标注质量与主动标注

- **质量指标**：与人工金标的时间 IoU、逐计分步 macro-F1、标签模型估计准确率、非弃权覆盖率、验证器校准 ECE。
- **类别不平衡**：末步权重最大但正样本最少；按 `w_g` 做平衡采样，并单独报告末步 F1。
- **主动标注预算 B**：采集函数 `a(t,g) = 不确定度 × w_g / 审计成本`，只把最不确定且分值最高的边界送人审。默认 `B = 5%` 的步骤级金标。
- **防循环论证**：留出**谓词族**（不是留出帧）做测试，确保验证器不是只拟合手写谓词。

## 2. 次旗舰：UIP-19 · RAV（Role-Affordance Verifier，角色-可供性验证器）

### 2.1 设计要点

- **物体无关**：不输入实例类别，输入**角色 token + 相对几何关系**；"杯子"会过时，"可抓容器 / 目标槽 / 工具"不会。
- **方向感知**：不只判 `done/ongoing/fail`，还输出进度增量符号，直接支撑 `regressed`。
- **噪声鲁棒**：用标签模型给出的样本权重训练；置信度低时**弃权**；在人工金标上做温度校准。
- **单模型合规**：视觉 / 语言骨干共享，角色头与验证头都是骨干上的轻量头；**推理期不调用任何第二个大模型**。外部 VLM 最多用于离线抽检，不进推理路径。
- **替代关系**：直接替代 v1/v2 设想的"外部 VLM 验证器"，消除"非单模型"合规风险。

### 2.2 结构伪代码

```python
class RAV(nn.Module):                 # 所有头共享同一条骨干
    def forward(self, obs, lang, g):
        z      = self.backbone(obs, lang)
        rho    = self.role_head(z)            # 实例 -> 角色 + 关系
        rel    = self.relation_encoder(rho, z)
        logits = self.verifier_head(rel, self.step_embed[g])
        state  = softmax(logits[:4])          # done / ongoing / fail / regressed
        delta  = tanh(logits[4])              # 进度方向
        return state, delta, calib_conf(state)
```

### 2.3 与 UIP-01″ 状态机接口

```python
def on_chunk_end(self, obs):
    st, d, conf = self.rav(obs, self.lang, self.g)
    if conf < self.conf_thr:                 # 弃权：不冒险重做
        return "continue"
    if st == "done":
        self.g += 1; self.redo = 0
    elif st == "regressed" or d < -self.delta_thr:
        if self.redo < self.max_redo:        # ZDR 的核心分支
            self.redo += 1
            return "replay_step_g"           # 重做当前子目标
    return "continue"
```

## 3. UIP-17 · ZSG-5（五轴零样本泛化协议）

### 3.1 五轴构造与留出

| 轴 | 含义 | 测试构造 | 留出方式 |
|---|---|---|---|
| O | 未见物体 | 替换为留出类别的网格 / 实例，保持同一角色 | leave-one-category-out |
| P | 位置布局 | 采样到训练支持集之外（如超出 95 分位） | 分位数留出 |
| D | 干扰物 | 工作区插入训练中不存在的干扰物 | 干扰物清单留出 |
| B | 背景 | 换桌面 / 背景纹理 / 光照（2D 合成，便宜） | 背景池留出 |
| H | 人为干扰 | 按 `human_*` 文本脚本化撤回，随机时机 / 速度 / 幅度 | 干扰模板留出 |

### 3.2 协议（先注册、后训练，防偷看）

1. 训练前固定五轴 split 与候选池，写入配置并冻结。
2. 测试期**禁止任何梯度更新**；也禁止在测试集上做校准（校准只用验证集）。
3. 报告每轴 `R_a`、`Δ_a` 与 `ZSG-5`，附 bootstrap 置信区间与 episode 数。
4. 单列 `ZDR`（人为撤回后的 H 步内恢复率）与 `末步分`（末步权重最大）。
5. 明确区分 zero-shot 与 few-shot：任何测试样本触达即标注预算，必须显式记账。

### 3.3 反事实生成成本排序（[设计]）

`B（2D 合成） < P（重采样位姿） < D（插资产） < H（脚本撤回） < O（换网格）`。
优先用便宜轴扩大覆盖，把昂贵轴留给锚任务与真机锚点。

## 4. UIP-18 · ALTA（Anchor-task Label Transfer，锚任务标注迁移）

- **锚任务**：T26 插网线（插入）、T27 叠碗（堆叠）、T19 拉链（连续接触）、T16 叠毛巾（折叠）、T12 开锁（旋转）。它们覆盖约 10 个技能节点。
- **迁移机制**：① 技能图节点复用 L1 段；② 角色图替换 L4 角色；③ 谓词模板迁移 L2（改参数不改结构）。
- **度量**：`TG_t(B)` 曲线，`B ∈ {0, 2, 5, 10, 20}%`；同时报告负迁移（`TG_t < 0`）的任务清单。
- **门控**：每个任务先在一小批 episode 上验证迁移是否为正，负迁移则回退到 scratch。

## 7. v3 闭环伪代码（SAL → RAV → ACS/CSG）

```python
# 离线：一次性造标签 + 训练（不进入推理路径）
labels = {task: label_episode(tau, task) for task in TASKS for tau in data}
gold   = audit_top_uncertain(labels, budget=0.05)
rav    = train_rav(labels, gold, shared_backbone)

# 在线：episode 级闭环（单模型、纯 API 内）
class V3Policy:
    def reset(self):
        self.g = 0; self.redo = 0; self.k = K_MAX
    def get_action(self, obs):
        st, d, conf = self.rav(obs, self.lang, self.g)
        self.k = self.acs(conf, self.g)          # 低置信 -> 小 k
        if st == "regressed" and self.redo < MAX_REDO and self.csg.ok():
            self.redo += 1
            obs = obs                          # 重做当前子目标
        elif st == "done":
            self.g += 1; self.redo = 0
        return self.policy(obs, self.g, self.k)
```

## 8. 合规与风险

- **单模型合规**：RAV 是共享骨干上的头；推理期不调用外部 VLM。外部模型仅可用于离线抽检，并在文档中披露。
- **特权信息边界**：`s_t` 只在训练期造标签，推理只用接口可见的观测；不得把特权状态泄漏进推理。
- **测试期零适应**：ZSG-5 的测试集上不做梯度更新、不做测试集校准；校准参数冻结自验证集。
- **循环论证控制**：谓词族留出 + 人工金标审计 + 真机 / 榜单锚点，三者缺一不可。
- **标签噪声**：接触密集边界系统性偏高；必须启用弃权、样本加权与分步校准。
- **仿真过拟合**：GSO 只作结构 / 顺序裁判与标签源，不作成败裁判。
- **手册仍未取到**：位置 / 干扰物 / 背景三轴的官方定义、评测轮次与时限仍待飞书手册公开后核实。
