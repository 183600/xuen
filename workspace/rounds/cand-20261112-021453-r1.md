# 第 59 轮（承接第 58 轮「KG-SFT-UX」IP-139~144；新灵感循环第 1 轮；本轮灵感：「结构优化」×「用户画像」）

> 第 58 轮把安全支柱换成了知识图谱 𝒢：同一张图驱动检索、OOD 判定、微调触发、证据合成、心智预测，换来结构化记忆的威力，也换来它自陈的共模失效——**图的结构一旦系统性错了，五条机制一起错，却没有一条机制能独立发现「图本身错了」**。同时它把操作者压成 s_o.mental 四元组 + auth 三级：比第 57 轮有序，但仍是"一次定型的少量标量"，不是"随人、随岗、随时间演化、且允许自己错"的画像。本轮两个灵感正好各补一个"结构"：**结构优化**借拓扑优化的语言，把知识图谱从"建好就用"变成"可优化、但只在可证伪约束下优化"的图——挖低应力材料、保承力构件、每条被删的边留墓碑可复原；**用户画像**把操作者从少数标量升级为"分布式的、可证伪的、只影响效率不影响底线的"多维画像。更关键的是二者合流：**图和画像都是对经验的压缩，而压缩最会过拟合**——所以本轮真正的贡献不是"优化"，而是给优化配一个能发现"自己优化错了"的负向控制：反优化审计（RAA）与世界/主体两套证据的溯源独立性证书（PISC）。核心命题由"结构化记忆守护下的安全自适应"升级为 **"结构可证伪、画像可怀疑的联合证据承诺"**。

核心矛盾：
- **H29（结构优化 vs 证据完整性）**：拓扑优化的目标（省成本、提精度）恰好奖励删掉"只在罕见工况才承力"的边；而安全最需要的往往就是这些罕见边。最优化 ≠ 安全，删边是**单调的减操作**，删错一次就永久失去一个失败模式的显式见证——除非墓碑与见证保留把它变回可逆。
- **H30（用户画像 vs 刻板印象/反馈回路）**：画像越细越省交互成本，但细画像会自证：判你"新手"→少给解释→你表现更差→更确信你是新手；细画像还可被博弈、泄露隐私、把"群体统计"强加给个体。画像必须是**假设分布**而非标签，且必须保留探索配额防止坍缩。
- **H31（联合优化 vs 循环验证）**：图和画像都从同一批历史经验里优化，会互相"背书"——画像因图里 familiar_with 边判你专家，图又因你历次标注判该区域熟悉，闭环自证；当两套学习结构同时错且方向一致时，任何单侧审计都看不出异常。

## 0. 直觉与动机

**灵感 1（结构优化 → 承力保留的图裁剪）**
直觉：机械拓扑优化在做什么？在应力低处挖空、在承力处留料，最后得到"最轻但扛得住这组载荷"的结构。KG 也可以这样优化：把检索成本与 OOD 噪声当"重量"，把"每条边对安全决策的边际影响"当"应力"，只挖低应力边。但拓扑优化的经典事故正是**删掉了只在该罕见载荷下才承力的杆**——所以本轮约束不是"对训练载荷扛得住"，而是 **(C1) 见证保留**：历史上出现过的每个失败模式，其见证路径要么仍在，要么被替换成一条"必须探针"义务边；**(C2) 墓碑可复原**：删边进 𝒯，带溯源与版本，可 O(1) 复活；**(C3) 结构 OOD**：当查询路径落到墓碑见证区，判定不许用优化后的图，退回向量检索 + 手工先验。承力边集 𝔏 在每次证伪后重算，只有非承力边才可删。

**灵感 2（用户画像 → 可证伪的分布画像）**
直觉：真实操作者是一束属性：能力、风险偏好、错误指纹、疲劳相位、通道偏好、受骗易感性、适应速率。把它们压成一个 auth 等级，等于把一本书压成一句话。但画像的反面同样危险：标签化会自我实现。于是画像的定义方式是"**每个维度都是一个带证伪器与保质期的假设分布**"——能力只能被事后实测更新（自报"我懂了"不动它），长期未被证伪的维度不自动变可信，而是**不确定性膨胀**（防陈旧）；画像只允许调"效率参数"（要几条佐证、给多少解释、超时多久），全局证据地板与决策规则本体永不被画像穿越。

**灵感 3（两者合流 → 压缩的过拟合与负向控制）**
直觉：KG 压缩"世界"，画像压缩"人"，两者都是经验的低秩近似，过拟合会在同一方向发生。故本轮引入两个**不属于优化器**的部件：**PISC（溯源独立性证书）**——一次不可逆承诺携带的"世界侧证据源"与"主体侧证据源"若高度重叠（同一批标注既建图又建画像），视为循环验证，强制补一次不相交溯源探针；**RAA（反优化审计）**——周期性把墓碑边、被降权的画像维度当"零假设"放回影子沙盒重跑决策，若决策翻转，说明现结构在"靠删掉异类来显得干净"，触发结构调查。优化器负责变瘦，负向控制负责证明瘦得没错。

**灵感 4（结构优化不止于图 → 交互结构的极小充分化）**
直觉：结构优化的对象可以再上一层：整个"探-诺-演"协议本身也是一棵证明树。PCC（proof-carrying commitment）要求每次承诺附带**极小充分证书**：用到了哪些 KG 边、哪些画像维度、哪些证据 ID、独立性检查结果。审计只需重放这棵树，而非整张图。附带好处：交互本身也能被优化——哪些检查点对任何可接受承诺都不必要，可被结构优化掉，但同样受见证保留约束。

**灵感 5（PCX*** → 优化器异步、证书同步、地板永在）**
直觉：把结构优化做成与 SFT-KG 同构的影子任务（异步、审计、热切换、可回滚），把画像委托做成带地板的参数映射（只动效率），把 PISC 与证据门一起做成承诺前的硬检查。前三条安全单向通道不变（信念更准 / 不确定性更大 / 动作更保守）；本轮新增第四条但只允许单向：**结构更简 ⟹ 必须有见证保留且可复原**。简，只有在可证伪的前提下才是安全。

## 1. 形式化定义（增量：定义 145–150）

**定义 145（结构可证伪的 KG 优化 SO-KG）** 编辑算子 E={prune, contract, shortcut, reweight}，𝒢'=E(𝒢)，墓碑 𝒯={(e,src,ver,evidence)}。承力边集 𝔏(β)={e∈ℛ : ΔRisk_e(𝔅_replay)>β}，其中 ΔRisk_e 为删除 e 后回放集上决策风险的边际变化。优化
`min_{E, |E|≤B_so} C_ret(𝒢') + λ·Risk(𝒢') + μ·|E|`，约束：
(C1) ∀f∈𝔅_fail：`Path_f(𝒢')≠∅ ∨ Obligation_probe(f)≠∅`；
(C2) ∀v：`cov_v(𝒢') ≥ 1−α_conf−δ_so`；
(C3) `prune(e) ⇒ e∈𝒯 ∧ e∉𝔏(β)`；
(C4) version 单增、src 诚实。
结构 OOD：`n_struct(o)=1[argmin_path(o,𝒢') ∩ 𝒯_witness ≠ ∅] > θ_struct` ⇒ 判定退回第 57 轮手册/向量路径。

**定义 146（可证伪分布画像 OPR）** π_o={(d, p_d, unc_d, src_d, ver_d, τ_d, F_d)}_{d∈D}，D={comp, risk_att, err_fp, fatigue_ph, chan_pref, decep_susc, adapt_rate}；p_d 为分布，unc_d 为可信宽度，F_d 为声明的证伪器，τ_d 为保质期。更新只在**实测裁决**后发生（自报不计入 comp）；τ_d 过期 ⇒ unc_d 单调膨胀而非 p_d 收缩。画像写入走隔离区，带溯源与版本。

**定义 147（带地板的画像委托 DPF）** 委托映射 Δ_deleg: π_o → Θ_eff ⊆ {corrob_req, w_h, τ_int, explain_granularity, probe_share}；保守序 ≽ 逐分量定义，硬约束 `Θ_eff ≽ Θ_floor`（全局地板）。仅在 `LCB(unc_d) ≤ θ_unc` 的维度上允许"放松"，方向单向：可在证据下放松至地板为止，任何维度不得低于地板。探索配额：∀窗口 W，`|{交互用群体先验参数}|/|W| ≥ ε_explore`。

**定义 148（溯源独立性证书 PISC）** 承诺证书 `C_c=(W_𝒢, D_π, S_ev, Ω, ver)`，W_𝒢 为所用 KG 见证子图，D_π 为所用画像维度，S_ev 为证据 ID 集。世界侧溯源 `S_W=src(W_𝒢)∪src(S_ev)`，主体侧 `S_O=src(D_π)`；重叠度 `Ω=|S_W∩S_O| / min(|S_W|,|S_O|)`。不可逆承诺要求 Ω≤θ_indep，否则强制补一次 `src∉S_W∪S_O` 的独立探针/独立标注。承诺以 PCC 形式携带 C_c 供审计重放。

**定义 149（反优化审计 RAA）** 影子沙盒 `𝒢_†=𝒢'∪𝒯_resurrected`（复活墓碑边）、`π_†=π_o∪{被降权维度按先验复位}`；对回放集抽样重跑决策，结构后悔 `SR=TV(Decision(𝒢',π_o), Decision(𝒢_†,π_†))`。若 `SR>θ_sr` 且方向为"优化后更自信" ⇒ 触发结构调查。RAA 预算独立于在线预算，周期 T_raa。

**定义 150（PCX*** 探-诺-演***）** 在 PCX++ 检查点序列上：①KG 检索 + n_struct；②元推断（MFSL/ACC）；③异步 SO-KG 影子优化（审计/热切换/回滚）；④跨模态对账（XMC）；⑤画像估计 + DPF 委托（受地板与 ε_explore）；⑥UX 前置（UXSE）；⑦六类证据门 + **PISC 硬检查** + 地板检查；⑧承诺（PCC）或绕行/降档/L2 协商/安全停。结构优化不阻塞主流程；PISC 不通过不得提交不可逆接触。

## 2. 关键算法伪代码（完整版见产物区）

```python
def so_kg_optimize(G, replay, failbuf, budget):
    L = load_bearing_edges(G, replay, beta)          # 承力边只算不删
    cand = [e for e in G.edges if e not in L and e not in protect(G, failbuf)]
    ed = greedy_prune(G, cand, J=lambda g: C_ret(g) + lam*Risk(g), cap=budget.B_so)
    if not witness_preserved(ed.G, failbuf):   return None, "witness_violation"
    if not coverage_ok(ed.G, alpha_conf, delta_so): return None, "coverage_drop"
    return shadow_audit_and_hotswap(ed.G), "ok"

def dpg_delegate(pi, risk):
    theta = population_prior()
    for d, p in pi.items():
        if lcb(p.unc) <= theta_unc:                  # 只在可信维度放松
            theta[d] = relax(theta[d], p, floor=THETA_FLOOR[d])
        else:
            theta[d] = THETA_FLOOR[d]                # 高不确定 -> 用地板
    theta = apply_explore_quota(theta, eps_explore)
    assert all(theta[k] >= THETA_FLOOR[k] for k in theta)
    return theta
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| SO-KG | 影子 O(\|ℛ\|·\|𝔅_replay\|·C_risk)；热切换 O(1) | O(\|𝒯\|+\|ℱ\|) | 非承力才删、见证保留、墓碑完整、版本单增 |
| OPR | 更新 O(\|D\|)；推断 O(\|D\|) | O(\|操作者\|·\|D\|) | 仅实测更新、证伪器与保质期齐备 |
| DPF | O(\|D\|·\|Θ\|)/委托 | O(1)/决策 | Θ_eff≽Θ_floor 逐分量、探索配额 |
| PISC | O(\|W_𝒢\|+\|D_π\|+\|S_ev\|)/承诺 | O(\|W_𝒢\|) | Ω≤θ_indep、证书可重放、独立溯源不相交 |
| RAA | 摊销 O(\|sample\|·C_dec/T_raa) | O(\|𝒯\|) | 反优化审计周期有界、检测诚实 |
| PCX*** | 同 PCX++ + O(\|D\|)+O(\|W_𝒢\|) | O(\|V\|+\|σ\|+\|𝒢\|) | 优化异步、证书同步、地板永在、终止性保持 |

**正确性定理（SOPAS 概要）**：在 A22–A45 上补 (A46) SO-KG 仅删非承力边且见证保留、墓碑完整、结构 OOD 漏检 ≤δ_struct、影子审计诚实且回滚 ≤1 接触；(A47) OPR 仅由实测更新、每维有证伪器与保质期、过期即膨胀；(A48) DPF 逐分量 Θ_eff≽Θ_floor、放松仅当 LCB(unc)≤θ_unc、ε_explore>0；(A49) PISC 证书诚实可重放、不可逆 Ω≤θ_indep；(A50) RAA 周期有界、结构后悔检测诚实。则：
(i) **结构健全性**：任何不可逆承诺用到已删承力见证的概率 ≤δ_struct，未触发时删边对失败率的额外贡献为 0（见证保留）；
(ii) **画像沙盒性**：Θ_eff∈[Θ_floor, Θ_population]，承诺失败率的证据项仍以地板参数评估，画像只影响效率不影响安全下界；
(iii) **反循环性**：Ω>θ_indep 的承诺被拒或补独立溯源，两套结构相关的共模错误未被纠正的概率 ≤δ_circ；
(iv) **反过拟合性**：ε_explore>0 使轨迹保留群体先验支撑，自证坍缩被打破，画像后悔有界；
(v) **终止性**：PCX*** 在 k_probes+k_cons+k_ft+k_ux+k_so 内终止于 {承诺, 绕行, L2 协商, 安全停}，影子结构优化不阻塞。

## 6. 本轮最大风险

**一句话**：本轮把"世界"（KG）与"人"（画像）同时交给"结构优化"去压缩，而优化的目标函数天然奖励删掉那些只在罕见工况/罕见操作者上才起作用的承力边与异常维度——一张越来越干净、越来越自信的图与画像，看起来像能力提升，实则可能是过拟合的指纹；越优化，系统就越难发现"自己的结构错了"，这是比第 58 轮 KG 共模失效更隐蔽的"优化诱发的认识论封闭"，必须靠见证保留、墓碑复原、ε_explore、PISC 溯源独立性与 RAA 反优化审计五重负向控制，宁可保留臃肿可疑、也绝不接受"因为整洁所以可信"。

### IP-145 SO-KG（承力保留的结构优化）

```python
def load_bearing_edges(G, replay, beta):
    """承力边 = 删除后回放集上决策风险边际变化 > beta；只计算，不删除"""
    L = set()
    for e in G.edges:
        d_risk = 0.0
        for (obs, decision, outcome) in replay.sample():
            g_minus = G.without(e)
            d_risk += abs(decision_risk(g_minus, obs) - decision_risk(G, obs))
        if d_risk / max(1, len(replay)) > beta:
            L.add(e)
    return L

def so_kg_optimize(G, replay, failbuf, budget, delta_so, alpha_conf):
    """影子执行：不阻塞主流程；输出新图或拒绝原因"""
    L = load_bearing_edges(G, replay, beta=BETA)
    protect = witness_edges(G, failbuf)              # 每个失败模式的见证边
    cand = [e for e in G.edges if e not in L and e not in protect]

    def J(g):
        return retrieval_cost(g) + LAM * decision_risk_replay(g, replay)

    G_new = greedy_prune(G, cand, J=J, cap=budget.B_so, mu=MU)

    # (C1) 见证保留：失败模式要么仍有见证路径，要么留下必须探针义务
    if not witness_preserved(G_new, failbuf):
        return None, "witness_violation"
    # (C2) 覆盖不退化
    if not coverage_ok(G_new, replay, alpha_conf, delta_so):
        return None, "coverage_drop"
    # (C3) 只有非承力边进墓碑
    if any(e in L for e in G_new.tombstoned):
        return None, "load_bearing_pruned"
    # (C4) 版本与溯源
    G_new.bump_ver()
    for e in G_new.tombstoned:
        assert e.src and e.ver <= G_new.ver

    return shadow_audit_and_hotswap(G_new, replay, failbuf), "ok"

def witness_preserved(G_new, failbuf):
    for f in failbuf.modes:
        if path_exists(G_new, f.witness_path):
            continue
        if G_new.has_obligation(f, relation='requires_probe'):
            continue                                  # 见证改成必须探针义务
        return False
    return True

def structural_ood(G_new, obs, tombstones):
    p = argmin_path(G_new, obs)
    hit = any(e in tombstones.witness_edges for e in p.edges)
    return 1.0 if hit else 0.0                        # >theta_struct -> 退向量+手册
```

### IP-146 OPR（可证伪分布画像）

```python
class OperatorProfile:
    """每维一个假设分布 + 证伪器 + 保质期；只由实测裁决更新"""
    def __init__(self, operator_id):
        self.o = operator_id
        self.dims = {
            d: ProfileDim(prior=POP_PRIOR[d], unc=UNC0[d],
                          src=set(), ver=0, born=now(), falsifier=FALSIFIER[d])
            for d in DIMS
        }

    def update(self, dim, outcome):
        if not outcome.verified:
            return                                    # 自报「我懂了」不计入能力
        d = self.dims[dim]
        d.posterior = bayes_update(d.posterior, FALSIFIER[dim].likelihood(outcome))
        d.unc = credible_width(d.posterior)           # 证据增加 -> 宽度下降
        d.src.add(outcome.source_id)
        d.ver += 1
        d.born = now()

    def tick(self, now):
        """过期不自动可信，而是不确定性膨胀（防陈旧刻板印象）"""
        for d in self.dims.values():
            if now - d.born > TAU[d]:
                d.unc = inflate(d.unc, now - d.born, TAU[d])
                d.born = now
        return self

    def snapshot(self):
        return ProfileSnapshot({d: (p.posterior, p.unc, p.src, p.ver)
                                for d, p in self.dims.items()})
```

```python
def dpg_delegate(pi, risk_type):
    """画像只调效率参数；逐分量不低于证据地板"""
    theta = dict(POPULATION_PRIOR_THETA)
    for d, p in pi.dims.items():
        if lcb(p.unc) <= THETA_UNC[d]:
            # 只在可信维度上「放松」到地板为止
            theta = relax_component(theta, d, p, floor=THETA_FLOOR[d])
        else:
            theta = enforce_floor(theta, d, floor=THETA_FLOOR[d])
    # 任何维度不得低于地板（硬断言，非软惩罚）
    for k in THETA_FLOOR:
        theta[k] = max_conservative(theta[k], THETA_FLOOR[k])
    # 探索配额：一定比例交互强制用群体先验，防自证坍缩
    if explore_budget_available():
        theta = population_prior_theta()
    return theta

def relax_component(theta, d, p, floor):
    """放松仅限效率侧：佐证数下探、超时缩短、解释粒度变粗；不碰决策规则"""
    cand = {
        'corrob_req':         max(floor['corrob_req'],  dec_corrob(p)),
        'w_h':                min(floor['w_h'],         inc_weight(p)),
        'tau_int':            max(floor['tau_int'],     dec_timeout(p)),
        'explain_granularity':max(floor['explain_granularity'], coarsen(p)),
        'probe_share':        max(floor['probe_share'], dec_probe_share(p)),
    }
    theta.update(cand)
    return theta
```

### IP-148 PISC（溯源独立性证书 + PCC）

```python
def build_certificate(W_G, D_pi, evidences):
    S_W = set(src(e) for e in W_G.edges) | set(src(ev) for ev in evidences)
    S_O = set(src(d) for d in D_pi)
    denom = max(1, min(len(S_W), len(S_O)))
    return Certificate(W_G=W_G, D_pi=D_pi, S_ev=evidences,
                       Omega=len(S_W & S_O) / denom,
                       ver=current_ver())

def pisc_check(cert, level):
    """不可逆承诺要求溯源独立；否则必须补不相交溯源探针"""
    if level != 'L2_irreversible':
        return Gate('ok', cert)
    if cert.Omega <= THETA_INDEP:
        return Gate('ok', cert)
    return Gate('need_independent_probe',
                required_src=trace_sources(cert) )  # 补 src 不在两集合并集内

def proof_carrying_commit(sigma, gait, cert, ev):
    """承诺自带极小充分证明树，审计重放此树而非整张图"""
    return Commitment(sigma=sigma, gait=gait, certificate=cert,
                      evidence=ev, reproducible=True)

def audit_replay(commit):
    W = commit.certificate.W_G
    assert all(e.src and e.ver <= commit.certificate.ver for e in W.edges)
    assert witness_preserved(W, commit.evidence.failure_modes)
    assert commit.certificate.Omega <= THETA_INDEP or commit.evidence.independent
    return True
```

### IP-149 RAA（反优化审计）

```python
def raa_audit(G_opt, pi, replay, theta_sr):
    """零假设：把墓碑边与降权维度放回去，看决策是否翻转"""
    G_dag = G_opt.resurrect_tombstones()
    pi_dag = pi.reset_downweighted_dims()
    flips, n = 0, 0
    for (obs, decision, _) in replay.sample(T_RAA_SAMPLE):
        n += 1
        d_opt = decide(G_opt, pi, obs)
        d_dag = decide(G_dag, pi_dag, obs)
        if d_opt != d_dag:
            flips += 1
    sr = flips / max(1, n)
    # 方向：优化后更自信且零假设更保守 -> 疑似靠删异类变干净
    direction = compare_conservatism(G_opt, pi, G_dag, pi_dag)
    if sr > theta_sr and direction == 'optimized_more_confident':
        return RAAReport(flag=True, structure_regret=sr,
                         suspect_edges=G_opt.tombstoned, silent_deletions=True)
    return RAAReport(flag=False, structure_regret=sr)
```

**正确性定理（SOPAS: Structure-Optimized, Profile-Aware Soundness）**
假设 A22–A45（第 53–58 轮）成立；**(A46) SO-KG**：仅删除 e∉𝔏(β) 的边，见证保留约束 (C1) 恒成立，墓碑 𝒯 完整可复原，结构 OOD 漏检 ≤δ_struct，影子审计诚实且回滚在 ≤1 接触内生效；**(A47) OPR**：画像更新仅由实测裁决驱动，每维有声明证伪器 F_d 与保质期 τ_d，过期只膨胀 unc 不收缩分布，画像写入仅经证据门通过的接触；**(A48) DPF**：Θ_eff 逐分量 ≽Θ_floor，放松仅当 LCB(unc_d)≤θ_unc，探索配额 ε_explore>0；**(A49) PISC**：证书诚实、可重放，不可逆承诺 Ω≤θ_indep 或已补不相交溯源证据；**(A50) RAA**：审计周期 T_raa 有界，结构后悔 SR 检测诚实。则：

1. **结构健全性**：任意不可逆承诺使用已删承力见证的概率 ≤δ_struct；未触发结构 OOD 时，结构优化对承诺失败率的额外贡献为 0（见证保留使删边不改变可证伪性）。
2. **画像沙盒性**：∀决策时刻，Θ_eff∈[Θ_floor, Θ_population]，证据门与 L2 超时的失败项仍以地板参数评估；画像只能改变"多快、多省、多细"，不能改变"多敢赌"。
3. **反循环性**：两套学习结构（𝒢 与 π）在不可逆承诺上的溯源重叠 Ω≤θ_indep，否则承诺被拒或补独立溯源；共模错误未被纠正的概率 ≤δ_circ。
4. **反过拟合性**：ε_explore>0 ⇒ 轨迹分布保留群体先验支撑，自证坍缩被打破，画像后悔与结构后悔有界；RAA 在 SR>θ_sr 时以有界时延暴露"靠删异类变干净"的结构。
5. **终止与异步性**：PCX+++ 在 k_probes+k_cons+k_ft+k_ux+k_so 内终止于 {承诺, 绕行, L2 协商, 安全停}；结构优化与 RAA 均在影子中运行，不阻塞主流程。
6. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp ( δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                    + δ_ft·1[回滚窗口] + δ_kg·1[检索失败] + δ_ux·1[μ_mis>θ_mis]
                    + δ_struct·1[结构OOD] + δ_prof·1[画像误估] + δ_circ·1[Ω>θ_indep] )
         − P(𝒢 结构性错误未检出) − P(π 与 𝒢 同源错误未检出) − P(护盾回退失败)
         − P(τ_int 超时 ∧ 安全停失效)
```

关键：**结构优化不是"让系统更强"，而是"让系统更瘦且仍可证伪"**——承力边只算不删、删边必留墓碑、结构 OOD 退回手册；**画像不是"让系统更信任人"，而是"让系统更省地与一个假设分布交互"**——分布而非标签、证伪器而非定论、地板而非可穿越、探索配额而非坍缩；**PISC 与 RAA 是负向控制**——前者查"世界与人是不是同一批证据在互相背书"，后者查"干净是不是删出来的"。

## 6. 本轮最大风险

**一句话**：本轮把"世界"（KG）与"人"（画像）同时交给"结构优化"去压缩，而优化的目标函数天然奖励删掉那些只在罕见工况/罕见操作者上才起作用的承力边与异常维度——一张越来越干净、越来越自信的图与画像，看起来像能力提升，实则可能是过拟合的指纹；越优化，系统就越难发现"自己的结构错了"，这是比第 58 轮 KG 共模失效更隐蔽的"优化诱发的认识论封闭"，必须靠见证保留、墓碑复原、ε_explore、PISC 溯源独立性与 RAA 反优化审计五重负向控制，宁可保留臃肿可疑、也绝不接受"因为整洁所以可信"。
