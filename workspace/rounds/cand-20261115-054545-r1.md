# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配×主动多模态交互的不确定性二分闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「场景驱动创新」×「多任务学习」）

> R69 让不确定性第一次“有形状”，也让“提问”成为可认证的动作。但它把流策略的多峰性几乎全部解释成**同一任务内部的动作歧义**——绕左还是绕右。这个解释只在“任务已被给定、场景已被识别”时成立。真实具身系统是一条多任务、多场景的长尾：同一观测下流模型吐出的两个模态，可能不是“同一件事的两种做法”，而是“**两件不同的事**”（去搬箱子，还是去开门）。R69 会为后者付一次交互，问一个错层的问题；更糟的是，多任务共享表征使各任务错误**同源**，于是 R69 赖以自保的“k 个正交证据源一致”可能只是同一副错误特征的复读。
>
> 本轮两个灵感正好把分析单位抬高一层：
> - **场景驱动创新**：创新不来自“更强的通用策略”，而来自“**被看见的具体场景**”。场景不是背景，而是一等公民：有描述子、有邻域、有覆盖、有边界；真正的创新发生在“场景 × 任务”的空白格上。
> - **多任务学习**：它同时给出**可辨识性**（用任务头/任务令牌把“任务身份”从“动作模态”里拆出来）与**危险**（共享参数导致任务间错误相关、负迁移）。它让“多任务一致”既成为新的验证通道，也成为新的攻击面。
>
> 核心命题：**用 (场景, 任务) 瓦片（tile）作为闭环的第一性对象；把 R69 的 U_epi 按链式法则拆成 U_task（我在哪个瓦片）与 U_mode（瓦片内怎么做），并用数据侧的 U_cov（这个瓦片学过没有）与 U_share（共享表征在此刻可不可信）补齐模型自省的盲区；不同不确定性映射到不同的交互算子与保守级别，而不是都去“问一句”。** 命名 **MOSAIC-RAS**（Multi-task, Scenario-attributed, Interaction-Certified Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我现在到底在哪个场景、做哪件事——而这几件事共享的那套本事，此刻还可信吗**」。

## 0. 直觉与动机

**灵感 1（场景驱动创新 → 场景是一等公民，不是数据集的标签）**
直觉：通用策略的进步常用一个平均值衡量，但平均值会把“在 A 场景极好、在 B 场景极差”抹平。场景驱动创新反过来：先承认能力是**分场景、分任务**的，再把“场景 × 任务”的覆盖矩阵当作研究对象。每个场景格有描述子 s、邻域关系、已覆盖证据与失效边界；创新的目标不是把平均分抬高 1%，而是**在矩阵空白格上提出并验证一个此前不存在的能力**。对闭环的直接后果：R69 的 U_epi 是一个全局标量，MOSAIC 把它落到 tile 上——每次交互、每次保守，系统都知道自己在为哪个场景的哪件事买单。于是“探索/创新”也从随机试错变成 coverage frontier 上期望信息增益最大的一格。

**灵感 2（多任务学习 → 多峰有两种来源，必须可辨识）**
直觉：一个在十个任务上训练的流策略，在状态 o 上出现多峰，至少有两种来源：(a) **任务身份不确定**（该做哪件事）；(b) **任务内动作歧义**（这件事怎么做）。R69 只在动作轨迹空间聚类，看不到任务令牌，于是把二者混成一个 H_mode：它可能对“我该搬箱子还是开门”这种任务级歧义，做出“往左一点还是往右一点”的动作级追问。若给策略显式任务条件（task token / task head），就能用条件熵精确拆分：H(T,M|o)=H(T|o)+H(M|T,o)。这是本轮最硬的一刀——**不是再叠一个不确定性，而是把 R69 的一个数正确地拆成两个**；拆对之后，交互算子与安全策略随之分化。

**灵感 3（任务一致性图 → “多任务一致”既是新证据，也是新漏洞）**
直觉：R69 的证据纪律假设多个来源独立。多任务天然提供多个“来源”：一个回答或模态若为真，应同时改善**相关任务**的预测，且不应让**无关任务**变差。用梯度余弦、表征 CKA、场景共现构造任务一致性图，可把“k 个证据源”升级为“k 个**应当同向变化**的任务”。但危险也在这里：共享表征让任务错误相关（ρ→1），“一起变对”可能只是“一起错”。所以证据纪律必须增加**任务支持正交性**判据，而不是数一数几个任务头点了头。

**灵感 4（负迁移 → 共享不是免费的，U_share 必须显式）**
直觉：多任务最隐蔽的失败不是某个任务差，而是**当前场景下共享表征被邻居任务带偏**。R69 的 MCG 只校准模态权重，看不见这种“被拖累”。定义 U_share 为：在当前 tile 上，用共享表征与用该任务隔离头/适配器的期望风险差。U_share 超阈时，正确动作既不是问、也不是单纯慢，而是**隔离**：切到任务专用适配器、重新认证、缩短前缀。多任务由此从“默认收益”变成“有条件的、可审计的收益”。

**灵感 5（场景创新是双刃剑 → 必须防“场景幻觉”）**
直觉：场景生成器能提出人类没想到的检验场景，这是创新来源；它也会生成物理不成立、社会语义无意义、或把长尾当主线的场景，把系统训练成“解决不存在的问题”。因此场景创新必须有**现实性证书**、来源血统与人类闸门；生成只进离线候选池，实时环路仍坚持零学习写操作。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（MOSAIC-RAS 总览）** MOSAIC-RAS = (SCN, TID, SMT, TCG, CVA, NTD, SGA, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i / R69 定义 293-i）；
(ii) **瓦片归属可认证**：每次执行都附带 tile 后验与证书，禁止无归属的“通用动作”；
(iii) **支持正交性**：跨任务验证所用的证据源必须在特征/因果支持上足够不重合（定义 328），否则不得计为独立证据；
(iv) **交互与隔离同等认证**：信息动作、任务切换、适配器隔离都要过 C-RAS-WM 前缀认证（继承 R69 定义 302）。

**定义 311（场景描述子与场景格）** 场景描述子 s_t = (s_sym, s_lat)：s_sym 为可审计的符号槽（地形类别、物体集合、交互模式、社交情境、时间窗），s_lat = Φ_s(o_t) 为学习到的连续嵌入。场景格 c = Quant(s_t) 由可学习的 Voronoi/量化器给出，p(c|o_t) 经温度标定。相邻格共享边界样本；场景切换带迟滞（定义 324），避免抖动。

**定义 312（场景-任务瓦片 tile）** 瓦片 T = (c, τ) ∈ 𝒯 = 𝒞 × 𝒯_task，表示“在场景格 c 下执行任务 τ”。tile 后验 p(T|o_t) = p(c|o_t)·p(τ|o_t,c)（允许任务在格内共享或专属）。定义**瓦片支持度** U_cov(T,o) 为 o 在该瓦片条件嵌入中到最近 K 个演示/成功轨迹的校准距离；由 conformal 预测给出覆盖保证。

**定义 313（认知不确定性的链式三分解）** 设 T 为瓦片身份、M 为瓦片内动作模态：
H(T,M|o) = H(T|o) + H(M|T,o)。
于是 U_task = H(T|o)（我在哪）；U_mode = H(M|T,o)·g(Δ_min)（在已知瓦片内怎么做，沿用 R69 的可分性折扣）；U_share = E_{T~p(T|o)}[R(shared|T,o) − R(isolated|T,o)]_+（共享表征的额外风险）。三者语义不同、不做简单加和，分别进入定义 319 的算子与定义 322 的退化通道。

**定义 314（场景-任务条件流策略 SMT）** 速度场 v_θ(x_s, s | o_t, e_c, e_τ)，其中 e_c、e_τ 为场景与任务嵌入；trunk 仍复用 R68 MTM，场景适配器与任务适配器为低秩增量。训练按 tile 分层采样并做场景平衡，避免“多数场景吃掉梯度”。采样沿用 R69 的 rectified flow（Heun, N_step=2）。

**定义 315（任务一致性图 TCG）** 节点为任务，边权 w_{ij} = σ(α·cos(g_i,g_j) + β·CKA(φ_i,φ_j) + γ·CoOcc(s_i,s_j))，其中 g_i 为任务梯度、φ_i 为任务表征、CoOcc 为场景共现。阈值化后取连通分量为“应当同向变化”的任务组 G_1,…,G_m。

**定义 316（覆盖证书 CVA）** 对每个 tile T，用 conformal 分位数给 U_cov 的覆盖上界；U_cov(T,o) > τ_cov 记为“无支持”。无支持不是“更慢地做”，而是“不得声称有能力”（定义 322）。覆盖只由数据决定，不由流模型自省决定，因此不可被模态幻觉伪造。

**定义 317（负迁移检测 NTD）** 在线监测两类信号：(a) 任务梯度冲突 GC_{ij} = ⟨g_i,g_j⟩/(‖g_i‖‖g_j‖) 的滑动均值；(b) 共享头与隔离头在同一 tile 上的滚动风险差。若 |GC| 或风险差越阈，则触发 U_share 告警；告警时执行定义 323 的隔离。

**定义 318（场景驱动的瓦片生成 SGA，仅离线）** 在覆盖矩阵上维护空白/薄弱格集合 ℱ。生成器提出候选瓦片 T′，目标为 argmax_{T′∈ℱ} E[IG(capability; T′)]·Feasible(T′) − Cost(T′)，并须通过**现实性证书**（物理可行性、语义合理性、与已知因果机制不矛盾）与人类闸门。产物只进离线候选池，不进入实时策略。

**定义 319（不确定性 → 算子映射）** 交互不再是“有问题就问一句”，而是按不确定性的层级选算子：
| 主导不确定性 | 正确算子 | 禁止算子 |
|---|---|---|
| U_mode 高、U_task 低、U_cov 低 | R69 的看/触/问（模态级消歧） | 场景级追问 |
| U_task 高 | 场景/任务澄清（问“哪件事/在哪”，或走到判别性 vantage 做场景探针） | 继续在错误任务上做动作级微调 |
| U_cov 高 | 请求演示/遥操作、拒做、改派 | 用“更慢”冒充“会做” |
| U_share 高 | 隔离适配器、重新认证、缩短前缀 | 继续用共享表征并加问一句 |

**定义 320（跨任务验证纪律）** 一个回答/模态被采纳，须同时满足：(a) 在同一 TCG 连通分量内，至少两个任务的预测似然同向改善；(b) 其他分量任务退化不超过 δ_neg；(c) **支持正交性**：参与验证的证据源在 top-k 特征/梯度支持上的重合度 < ρ_max，且给定共享特征后的误差条件相关 < ρ_err。只满足“多个头都同意”不构成证据。

**定义 321（证书 J_MOSAIC）** J_MOSAIC = (J_FLUID, tile_ece, U_task, U_mode, U_cov, U_share, tcg_hash, operator_id, isolation_log_hash, generator_provenance)。Valid ⇔ Valid(J_FLUID) ∧ tile ECE ≤ τ_tile ∧ 支持正交性满足 ∧ 隔离/切换认证通过。

**定义 322（四级风险缩放与 R69 退化）**
- R0（瓦片已知、共享可信、覆盖足）：λ = λ_floor(U_ale + 未消解 U_mode)，保留 R69 的 resolution bonus；
- R1（瓦片不确定）：λ = λ_floor(U_ale + U_mode + γ·U_task)，γ ≥ 1，且在瓦片澄清前不执行不可逆任务动作；
- R2（共享告警）：λ = λ_max，切隔离头，前缀长度收缩，重新认证；
- R3（覆盖缺口）：λ = λ_max，请求演示/拒做，不走“慢速执行”。
安全侧单调：R0 ≤ R1 ≤ R2 ≤ R3 的保守度逐级不降；单瓦片、U_share=0、U_cov=0 时逐指令退化为 R69。

**定义 323（隔离与无扰切换）** 共享↔隔离切换须 bumpless：动作、速度、力矩连续，前缀经 C-RAS-WM 重新认证；单位时间至多切换一次，带迟滞与切换成本；切换失败则保持上一安全模式并降级。

**定义 324（瓦片稳定与迟滞）** 场景格切换使用双阈值迟滞与最小驻留时间；tile 后验的抖动不得直接驱动 λ 或算子切换，须经滑动证据累积。

**定义 325（参与式审计 VQAuditor-T）** 审计对象新增：tile 归属是否被场景幻觉污染、跨任务证据是否真的支持正交、隔离是否过度、生成场景是否越权进入实时。结论回灌 AuditBuf 与 TCG 边权先验。

**定义 326（威胁模型 AIC-MOSAIC）** ℰ_MOSAIC = ℰ_FLUID × ℰ_task_spoof × ℰ_negative_transfer × ℰ_scenario_hallucination × ℰ_shared_feature_poison：任务标签伪装、跨任务共谋、生成场景失真、共享特征投毒（让多个头同时错）。

**定义 327（自适应计算）** 廉价 tile_head 与 mode_head 先跑；仅当 tile 后验熵或 U_mode 越阈才升 K、启用任务头集成与隔离评估，保证 P99 实时预算。

**定义 328（支持正交性）** 对证据源 e_i,e_j，定义支持重合度 Ω_{ij} = |supp(∇_{φ}e_i) ∩ supp(∇_{φ}e_j)| / |supp(∇_{φ}e_i) ∪ supp(∇_{φ}e_j)|（φ 为共享表征）。若 Ω_{ij} ≥ ρ_max，则二者视为“同一副特征的复读”，不计为独立证据；k 源验证的有效独立源数 k_eff = 1 + Σ_{j>1}(1−Ω_{1j})。

```python
# IP-264 SMT：场景-任务条件流策略
class ScenarioTaskFlowPolicy:
    def sample(self, o, c, tau, K, N_step=2):
        z = self.trunk(o)
        e = self.scn_emb(c) + self.task_emb(tau)
        xs = randn(K, D)
        for i in range(N_step):
            xs = xs + (1.0/N_step) * self.v(xs, i/N_step, z, e)
        return [self.decode(x) for x in xs]       # ξ=(a,g)

# IP-265 TID：瓦片归属与链式三分解
def attribute(o, model):
    p_c   = model.scn.post(o)                     # p(c|o)
    p_tau = model.task.post(o)                    # p(τ|o,c)
    U_task = entropy(p_c) + E_c[entropy(p_tau|c)] # H(T|o)
    tile   = argmax_(c,tau) p_c[c]*p_tau[tau,c]
    return tile, U_task

def decompose_epi(samples, tile, model):
    modes  = cluster_trajectories(samples)
    U_mode = entropy(mode_weights(modes)) * sep_factor(modes)  # H(M|T,o)
    U_cov  = model.cva.coverage_gap(tile)
    U_share= model.ntd.risk_gap(tile)             # shared vs isolated
    return U_mode, U_cov, U_share

# IP-266 算子选择：不同层级的不确定性用不同动作
def choose_operator(U_task, U_mode, U_cov, U_share):
    if U_share > TAU_SHARE: return 'isolate'      # 先止损，不交互
    if U_cov   > TAU_COV:   return 'request_demo' # 没学过，不要假装会
    if U_task  > TAU_TASK:  return 'scenario_probe'
    if U_mode  > TAU_MODE:  return 'mode_probe'   # R69 的看/触/问
    return 'act'

# IP-267 TCG + 支持正交性验证
def verify(answer, evidence, tcg, rho_max):
    comp  = tcg.component_of(answer.tile.tau)
    gains = {t: delta_loglik(t, answer) for t in comp}
    if sum(g > 0 for g in gains.values()) < 2: return False
    if any(degrade(t) > DELTA_NEG for t in tcg.other_components(comp)): return False
    k_eff = effective_independent_sources(evidence, rho_max)  # 定义 328
    return k_eff >= 2

# IP-268 NTD：负迁移告警与隔离
def negative_transfer(tile, shared_pred, isolated_pred):
    gap      = risk(shared_pred) - risk(isolated_pred)
    conflict = rolling_mean(gradient_cosine())
    return gap > TAU_GAP or abs(conflict) > TAU_GC

# IP-269 MOSAIC 主闭环（继承 R69，只在“问什么/信不信/做不做”处插入瓦片层）
def MOSAIC_round(M, obs):
    tile, U_task = M.tid.attribute(obs)
    K = 1 if M.fmp.mode_head(obs) < TAU_MODE else 4
    samples = M.smt.sample(obs, tile.c, tile.tau, K)
    U_mode, U_cov, U_share = M.tid.decompose_epi(samples, tile, M)
    op = M.tid.choose_operator(U_task, U_mode, U_cov, U_share)
    if op == 'isolate':
        M.iso.switch(tile); lam = M.efs.lam_max
        return M.hold_safe(obs, lam)
    if op == 'request_demo':
        return M.teleop.request_supervised_hold(tile)     # 覆盖缺口：交接，不慢做
    if op == 'scenario_probe':
        ans = M.scn.execute_probe(tile)                   # 场景/任务澄清
        U_task = M.tid.update_task(ans)
    elif op == 'mode_probe':
        ans = M.mint.execute(M.mint.choose_interaction(samples, obs, M.budget))
        if not M.tcg.verify(ans, M.evidence): U_mode = U_mode  # 不被单源说服
        else: U_mode = M.tid.update_mode(ans)
    lam = M.efs.risk_scale(tile, U_task, U_mode, U_cov, U_share)
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., M.wm)
    mode= select_mode(samples, U_mode, lam)
    M.vqa_t.submit_async(tile, op, U_task, U_mode, U_cov, U_share, lam)
    return k, lam, mode

# IP-270 SGA：离线场景创新（只产候选，不改实时）
def scenario_innovation_loop(pool, coverage, human_gate):
    for T in coverage.frontier():
        if not feasible_and_realistic(T): continue
        cand = generate_scenario(T)
        if expected_info_gain(cand) > threshold:
            pool.add(cand)
    human_gate.review(pool)          # 人类闸门后才可能进入训练集
```

## 3. 推导

**引理 19（R69 的 U_epi 是一个混合量，且系统性地高估瓦片内歧义）** 由链式法则，H(T|o)+H(M|T,o) = H(M|o)+H(T|M,o)。因此 R69 的 U_epi = H(M|o) = U_task + U_mode − H(T|M,o)。当模态几乎由任务决定（H(T|M,o)≈0）时，R69 把整个任务身份熵当成动作熵；当模态与任务无关（H(T|M,o)=H(T|o)）时，R69 恰好只测到 U_mode。系：R69 的 VoI 在任务级歧义上会**问错层**——花动作级交互去解任务级熵，期望增益被 H(T|M,o) 截断。

**引理 20（共享表征会摧毁“正交证据”的独立性）** 设 k 个任务头共享特征 φ，其错误在给定 φ 后的条件相关为 ρ。若 ρ→1，则 k 个“一致”并不比 1 个证据多；R69 引理 18 的上界 δ_p·ρ^{k−1}+ε_σ 退化为 δ_p+ε_σ。定义 328 的有效独立源数 k_eff = 1+Σ(1−Ω_{1j})。系：**多任务不是白送的正交性**；不度量支持重合就数头，等于把相关误差当独立证据。这是 MOSAIC 必须自带支持正交性判据的原因。

**引理 21（覆盖证书的有限样本保证）** 若每个 tile 的校准样本可交换，则 conformal 分位数给出的 U_cov 上界以 1−α 概率覆盖真实覆盖缺口；因此 R3 的“拒做”判据不依赖流模型自省，不能被模态幻觉伪造。

**定理 18（MOSAIC 严格包含 R69）** 在单场景格、单任务组、U_share=0、U_cov=0 的边界，TCG 无跨任务边、算子退化为 R69 的看/触/问，定义 313 退化为 H(M|o)；故 MOSAIC 与 R69 逐指令相同。一般情况下，MOSAIC 只在 R69 的动作之前插入“瓦片归属 + 算子选择”，安全包络不放松；当 U_task 高时它还禁止在错误瓦片上执行不可逆动作，故安全侧不弱于 R69。

**定理 19（分层算子减少无效交互）** 设任务级歧义的真实占比为 α = H(T|M,o)/H(M|o)。R69 用动作级算子的期望有效增益 ≤ (1−α)·G_mode；MOSAIC 将 α 部分改派给场景/任务算子，期望有效增益 ≥ max{(1−α)G_mode, αG_task}。当 G_task > G_mode 时严格更优；当 G_task ≤ G_mode 时退回 R69，不劣化。

**定理 20（负迁移隔离的安全与有界损失）** 若 U_share 告警后执行隔离切换（定义 323），切换本身经认证且 bumpless，则闭环风险 ≤ R2 通道的 λ_max 保守界；相对“永久共享”的性能损失不超过隔离头与共享头在覆盖内 tile 上的风险差上界。切换迟滞保证单位时间切换次数有界，避免抖振。

**定理 21（场景创新的现实性闸门）** 定义 318 的生成器只在离线候选池产生样本，且须过现实性证书与人类闸门；实时策略的写操作数仍为 0。因此场景创新不会在无人监督时改变安全证书所描述的策略分布。

## 6. 本轮最大风险

**一句话**：MOSAIC 的全部验证能力押在“多任务一致 = 独立证据”这一假设上；但**共享表征会让任务错误相关（ρ→1），多个任务头可能只是同一副错误特征的复读机**——于是系统可能用一个被共享表征污染的 tile 归属，在所有任务上“一致地错误”，并把这种一致性盖上“已验证”的章；这比 R69 的问错更危险，因为它错得更有组织。

**次级风险与缓解**：
1. **场景幻觉**：生成器造出物理/语义不成立的场景 → 现实性证书 + 人类闸门 + 仅离线候选池（定义 318、定理 21）；
2. **tile 伪造成本低**：任务标签可被环境或对手伪装 → tile 后验须多证据、场景探针可主动验证（定义 311、319）；
3. **负迁移告警滞后**：U_share 依赖滑窗，可能晚于性能塌陷 → 梯度冲突在线监测 + 保守默认（定义 317、322）；
4. **隔离抖动**：频繁切换破坏连续性 → 迟滞 + 最小驻留 + 单位时间切换上限（定义 323–324）；
5. **附加层延迟**：tile/TCG 验证挤占预算 → 廉价头 + 事件触发 + 自适应 K（定义 327）。

# 第 70 轮产物 · 创新点清单 v1：MOSAIC-RAS（Multi-task, Scenario-attributed, Interaction-Certified Risk-Adaptive System：场景×任务瓦片化、多任务可辨识与负迁移治理的闭环；SCN×TID×SMT×TCG×CVA×NTD×SGA×RAS-WM‡）

> 承接第 69 轮 IP-253~263（FLUID-RAS）。R69 让不确定性“有形状”，把 U 拆成 aleatoric 与 epistemic，并把“问/看/触”变成可认证的信息动作。但它有一个未言明的前提：**任务已给定，场景已识别**。于是流策略的多峰性被一律解释为“同一任务内的动作歧义”。真实具身系统是多任务、多场景长尾：同一观测下的两个模态，可能是“两件不同的事”。R69 会为任务级歧义支付动作级交互，问错层；更严重的是，多任务共享表征让各任务错误同源，R69 的“k 个正交证据源一致”可能只是同一副错误特征的复读。

## 3. 关键算法伪代码

```python
# IP-264/265 场景-任务条件采样 + 瓦片归属
def sample_and_attribute(M, o, K):
    p_c, p_tau = M.scn.post(o), M.task.post(o)
    tile  = argmax((c, tau), p_c[c] * p_tau[tau, c])
    U_task = entropy(p_c) + sum(p_c[c] * entropy(p_tau[:, c]) for c in p_c)
    z = M.trunk(o); e = M.scn_emb(tile.c) + M.task_emb(tile.tau)
    xs = randn(K, D)
    for i in range(2):                                  # rectified, Heun/1~2 步
        xs = xs + 0.5 * M.v(xs, i/2, z, e)
    return tile, U_task, [M.decode(x) for x in xs]

# IP-266/269 三分解 + 负迁移
def decompose(M, samples, tile):
    modes  = cluster_trajectories(samples)
    U_mode = entropy(mode_weights(modes)) * sep_factor(modes)
    U_cov  = M.cva.coverage_gap(tile)
    U_share= M.ntd.risk_gap(tile)
    return U_mode, U_cov, U_share

# IP-271 算子选择
def choose_operator(U_task, U_mode, U_cov, U_share):
    if U_share > TAU_SHARE: return 'isolate'
    if U_cov   > TAU_COV:   return 'request_demo'
    if U_task  > TAU_TASK:  return 'scenario_probe'
    if U_mode  > TAU_MODE:  return 'mode_probe'
    return 'act'

# IP-272 跨任务验证（含支持正交性）
def verify(answer, evidence, tcg, rho_max):
    comp  = tcg.component_of(answer.tile.tau)
    gains = [delta_loglik(t, answer) for t in comp]
    if sum(g > 0 for g in gains) < 2: return False
    if any(degrade(t) > DELTA_NEG for t in tcg.other_components(comp)): return False
    return effective_independent_sources(evidence, rho_max) >= 2

# IP-275 主闭环
def MOSAIC_round(M, obs):
    tile, U_task, samples = sample_and_attribute(M, obs, K=1)
    U_mode, U_cov, U_share = decompose(M, samples, tile)
    op = choose_operator(U_task, U_mode, U_cov, U_share)
    if op == 'isolate':
        M.iso.switch(tile); return M.hold_safe(obs, M.efs.lam_max)
    if op == 'request_demo':
        return M.teleop.request_supervised_hold(tile)
    if op == 'scenario_probe':
        U_task = M.tid.update_task(M.scn.execute_probe(tile))
    elif op == 'mode_probe':
        ans = M.mint.execute(M.mint.choose_interaction(samples, obs, M.budget))
        U_mode = M.tid.update_mode(ans) if M.tcg.verify(ans, M.evidence) else U_mode
    lam  = M.efs.risk_scale(tile, U_task, U_mode, U_cov, U_share)
    k    = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., M.wm)
    mode = select_mode(samples, U_mode, lam)
    M.vqa_t.submit_async(tile, op, U_task, U_mode, U_cov, U_share, lam)
    return k, lam, mode

# IP-270 离线场景创新
def scenario_innovation_loop(pool, coverage, human_gate):
    for T in coverage.frontier():
        if not feasible_and_realistic(T): continue
        if expected_info_gain(generate_scenario(T)) > threshold:
            pool.add(generate_scenario(T))
    human_gate.review(pool)              # 人类闸门后才有资格进训练集
```

## 4. 推导

**引理 19（R69 的 U_epi 是混合量且系统性高估瓦片内歧义）** 链式法则给出 `H(T|o)+H(M|T,o)=H(M|o)+H(T|M,o)`，故 `U_epi^R69=H(M|o)=U_task+U_mode−H(T|M,o)`。当模态由任务决定（`H(T|M,o)≈0`），R69 把任务身份熵全当作动作熵，VoI 会问错层；当模态与任务独立（`H(T|M,o)=H(T|o)`），R69 恰只测到 U_mode。系：分层算子的期望增益 ≥ `max{(1−α)G_mode, αG_task}`，`α=H(T|M,o)/H(M|o)`。

**引理 20（共享表征摧毁“正交证据”）** 若 k 个任务头共享特征 φ、给定 φ 后误差条件相关 ρ，则 ρ→1 时 R69 的 `δ_p ρ^{k−1}+ε_σ` 退化为 `δ_p+ε_σ`，k 个“一致”不比 1 个证据多。有效独立源 `k_eff=1+Σ(1−Ω_1j)`。系：多任务不是白送的正交性；必须显式度量支持重合度。

**引理 21（覆盖证书的有限样本保证）** 每个 tile 的校准样本可交换时，conformal 分位数以 1−α 覆盖真实覆盖缺口；R3 的“拒做”判据不依赖流模型自省，不能被模态幻觉伪造。

**定理 18（MOSAIC 严格包含 R69）** 单场景格、单任务组、`U_share=0`、`U_cov=0` 时 TCG 无跨任务边、算子退化为 R69 探询、定义 313 退化为 `H(M|o)`，故逐指令相同。一般情形只在 R69 动作前插入“瓦片归属 + 算子选择”，安全包络不放松；U_task 高时禁止在错误瓦片执行不可逆动作，安全侧不弱于 R69。

**定理 19（分层算子减少无效交互）** 任务级歧义占比 α 时，R69 动作级算子的有效增益 ≤ `(1−α)G_mode`；MOSAIC 将其改派给场景/任务算子，增益 ≥ `max{(1−α)G_mode, αG_task}`；`G_task≤G_mode` 时退回 R69，不劣化。

**定理 20（隔离的安全与有界损失）** U_share 告警后的隔离切换经认证且 bumpless，闭环风险 ≤ R2 的 λ_max 保守界；相对永久共享的损失不超过隔离/共享头在覆盖内 tile 的风险差上界；迟滞保证切换次数有界。

**定理 21（场景创新的现实性闸门）** SGA 只在离线候选池生成，须过现实性证书与人类闸门；实时写操作数仍为 0，故不会在无人监督时改变证书所描述的策略分布。

## 7. 本轮最大风险

**一句话**：MOSAIC 的全部验证能力押在“多任务一致 = 独立证据”这一假设上；但**共享表征会让任务错误相关（ρ→1），多个任务头可能只是同一副错误特征的复读机**——系统可能用一个被共享表征污染的 tile 归属，在所有任务上“一致地错误”，并把这种一致性盖上“已验证”的章；这比 R69 的问错更危险，因为它错得更有组织。

**次级风险与缓解**：场景幻觉（现实性证书 + 人类闸门 + 仅离线池）；tile 伪装（多证据 + 场景探针主动验证）；负迁移告警滞后（梯度冲突在线监测 + 保守默认）；隔离抖动（迟滞 + 最小驻留 + 频率上限）；附加延迟（廉价头 + 事件触发 + 自适应 K）。
