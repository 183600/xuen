## 1. 两个灵感的第一性原理

### 灵感 1 ·「抓取位姿估计」→ 抓取不是一个点，是一组带任务语义的流形

**直觉解释**：经典抓取位姿估计回答的是「这个 6-DoF 位姿能不能抓住」，输出一组候选、按抓取成功率排序。但在操作任务里**抓得住 ≠ 任务成**：抓杯口能提起，却拧不动盖；抓得深能施力矩，却可能伸不进窄缝。真正该最大化的不是 `P(grasp success)`，而是 `P(task success | grasp)`；而且抓取位姿永远有误差，它不是一个点，而是一个以 `Σ_g` 为协方差的分布。于是问题从「选最高分点」变成「选一个对任务力矩最兼容、且稳定域能覆盖自身误差分布的抓取」——这正是经典抓取理论（力旋量空间、Ferrari–Canny ε 度量）与任务语义的接缝，也是端到端 VLA 完全隐式化掉的一层。

**严谨定义**：
- **任务力旋量锥** `W_task`：任务轨迹上期望外力的凸锥（自重、插入反力、抹拭法向力、拧转力矩），带量级尺度；
- **抓取力旋量空间** `F(g)`：抓取 `g` 在摩擦锥接触力下可抵抗的力旋量集合；
- **任务兼容**：`W_task ⊆ F(g)`（不是「能抓」，而是「能抵抗这个任务要求的全部力旋量」）；
- **稳定域** `B_ε(g) = { δ ∈ SE(3) : W_task ⊆ F(g∘δ) }`：抓取位姿被扰动 `δ` 后仍任务兼容的集合；
- **认证鲁棒分**：`c(g) = max{ c : E_c(g) ⊆ B_ε(g) }`，其中 `E_c(g) = { δ : δᵀΣ_g⁻¹δ ≤ c }` 是以抓取位姿协方差为度量的椭球。于是 `P(任务兼容) ≥ F_{χ²_d}(c(g))`（L14），选 `argmax_g p_exec(g)·F_{χ²_d}(c(g))`，并把候选按分数排成**有序回退集**。
- 纯抬升任务下 `W_task` 退化为「抗重力」，`c(g)` 退化为经典 ε 度量——本定义是经典理论的任务化推广，而不是替换。

**与现有栈的接缝**：`p_exec` 由 IP-13 的位姿/协方差与场景图提供；回退集交给 IP-02 的介入家族；「禁止回到已失败抓取」复用第 3 轮的复读检测（IP-13）。

### 灵感 2 ·「力矩控制」→ 接触的另一半是柔顺，而柔顺可以被「代理」出来

**直觉解释**：位置伺服在自由空间是优点，在接触相是缺点——它把毫米级位置误差直接放大成公斤级接触力（力 ≈ 刚度 × 误差），于是插不进、压不稳、抹不平。力矩/阻抗控制的核心其实不是「力矩电机」，而是「**不要和环境硬顶**」：沿接触法向让位、把接触力限制在期望值，横向保持刚性。挑战接口只给关节位置、没有力矩、没有力传感，所以真力矩控制不可用；但观测里同时有**指令关节 `q_cmd` 与实测关节 `q`**（F5 已核实），在准静态接触中 `q_cmd − q` 近似正比于外力——这就是一个免费的「虚拟力传感器」。用估计力去驱动一个导纳滤波器整形路标，就能在不改底层控制器的前提下实现「准阻抗控制」。

**严谨定义**：
- **低层虚拟弹簧模型**：`τ = K_p(q_cmd − q) + K_d(q̇_cmd − q̇) + g(q)`（重力补偿假定在低层完成）；
- **扰动观测器**：用广义动量残差 `r`（De Luca–Mattone 形式）补偿惯性/科氏后得 `τ̂_ext`；准静态退化 `F̂ ≈ (Jᵀ)⁺(K_p(q_cmd − q) − g(q))`；
- **导纳整形**：`M_d ẍ + D_d ẋ + K_φ(x − x_des) = F̂`，解出的 `x` 作为路标命令；`K_φ` 随相位 `φ` 调度（自由空间高、insert/press/wipe/release 低）；
- **摩擦锥先验**：`‖F_t‖ > μ F_n` 预测滑移，作为 SlipGuard 的力学第二通道（视觉光流做确认）；
- **延迟无源性**：导纳回路在块延迟 `Δ` 下要稳定，须满足阻尼下界（L16）。

**两者合起来**：第 1 轮说「崩在最后一厘米」，第 2 轮把这一厘米做成伺服路标，第 3 轮补上「该信什么状态」，本轮发现这一厘米其实是**三段**：接近（已有）→ 抓（几何：抓取位姿估计）→ 接触（力：力矩控制的代理）。**抓取位姿估计管「在哪接触」，力矩控制管「多大力接触」**，两者都不重训底座，都是包在动作外的「接触外壳」。

## 2. 研究问题（新增 Q13–Q15，接第 1–3 轮 Q1–Q12）

- **Q13（任务条件抓取）**：以「任务力旋量兼容 + 稳定域认证下界」选抓取，相比「抓取成功率最高」选择，下游任务成功率能高多少？稳定域认证下界对真实鲁棒性是否校准（预测 vs 观测差 ≤0.1）？（E634）
- **Q14（虚拟力可观测性）**：在位置接口、无力传感、30 fps 观测下，关节跟踪误差能多准地估计接触力旋量（准静态相 RMSE、动态相偏差）？刚度 `K_p` 是否可从数据辨识？估计力能否支撑导纳整形与摩擦锥滑移预测？（E635/E636）
- **Q15（延迟下的柔顺稳定性）**：块延迟/低频动作下，导纳整形的稳定边界在哪里（`K_φ` 上限 vs `Δ`）？是否能在接触密集任务上提分而不拖累自由空间精度？（E637）

## 3. 设计原则（新增 P13–P15，接第 1–3 轮 P1–P12）

- **P13（任务条件抓取）**：不得只用抓取成功率选抓取；必须以「下游任务期望成功率 × 位姿不确定度下的认证下界」排序，并始终保留有序回退集；失败后禁止重试同一抓取（接 IP-13 复读检测）。
- **P14（接触相才柔顺，失败即刚）**：导纳/阻抗整形只在**准静态接触相**启用（L15 可观测域）；自由空间维持原高刚度；刚度标定失败或 `recomputed_ee_valid` 为假时，立即退回固定高刚度（fail-stiff），绝不因伪力反馈牺牲已稳住的自由空间精度。
- **P15（无源性预算）**：任何柔顺增益都必须满足延迟无源性下界（L16）；延迟未知时取保守 `K_φ` 或直接关闭柔顺——**柔顺预算是延迟预算的一部分**，与 U12/E633 共用同一本账。

## 5. 本轮最大风险

**力不可观且刚度不可辨识**：若低层 `K_p` 未知/时变、动态项（加速度、通信延迟）主导了 `q_cmd − q`，那么「估计力」就是错的；用错误伪力去软化控制，会把第 2–3 轮已经稳住的刚性伺服变成漂移的软伺服，**连自由空间精度一起赔进去**——这比不做柔顺更糟。对冲见 P14/P15：准静态门 + `K_p` 先标定 + `recomputed_ee_valid` 门控 + fail-stiff 退化（Level-1.7）+ 摩擦锥只作先验、视觉做确认。次要风险：抓取稳定域在未见物体上的协方差未校准（手眼误差被低估）→ 选错「稳健」抓取；新接触数据与 32 项评测分布不同 → 只作课程/辅助，不改主口径。

## 3. 新增 IP 详述

### IP-16 · GraspManifold 任务条件抓取流形（P1，新）

- **动机**：经典抓取估计按 `P(grasp success)` 排序，但任务失败常来自「抓得住却做不成」——抓点无法施加任务所需力矩/力（拧盖、插拔、抹拭、折叠）。且抓取位姿误差是分布不是点；忽略 `Σ_g` 会选到「名义最优、扰动即碎」的抓取。IP-16 把抓取选择变成**任务力旋量兼容 + 协方差认证稳定域**的优化，并输出**有序回退集**供 IP-02 重试。
- **与现有方案差异**：与 GraspNet/AnyGrasp 类「抓取成功率打分」不同，本方案打分 = `p_exec · F_{χ²}(c)`，目标是下游任务；与纯任务抓取（affordance）不同，本方案带**不确定度认证下界**与**执行可行性** `p_exec`（可达、接近净空、无碰撞）。
- **技术可行性**：高。抓取采样与力旋量/摩擦锥计算均为成熟件（点云 + 平行夹爪/灵巧手模型）；`c(g)` 用采样估计稳定域边界 + 椭球内切；不需要新网络。唯一工程量是手眼标定与 `Σ_g` 的来源（IP-13 提供相对位姿协方差 + 手眼协方差）。
- **资源**：算力小（抓取选择在抓取前一次，失败时按回退集再选）；数据用 IP-06 标注 + 官方回放；接口无新增字段（全在策略内部，合规安全）。
- **落地步骤**：①从 IP-13 目标档案导出点云/掩码与 `Σ_g`；②任务→`W_task` 锥（从 IP-06 任务/阶段标注生成：自重、插入方向反力、抹拭法向、拧转力矩）；③抓取采样 + 摩擦锥 `F(g)` + `W_task ⊆ F(g)` 过滤；④认证稳定域 `c(g)`（采样内切椭球）；⑤打分排序 + 回退集接口；⑥与 IP-02 重抓、IP-13 复读检测联动（禁止回到失败抓取）。
- **风险**：`Σ_g` 低估（手眼/检测误差）→ 认证下界虚高（见 L14 与 E634 校准）；未见物体上摩擦锥/质量先验错 → `W_task` 或 `F(g)` 错；抓取采样器域差 → 回退集为空。对冲：多帧一致性、`p_exec` 严格化、空回退集时退回 v3 的单点抓取。

### IP-17 · ContactCompliance 虚拟力 + 导纳整形（P0，新）

- **动机**：F5 证实观测有 `q_cmd`/`q`（关节与 EE 位姿）但**无任何力/力矩字段**；而接触密集任务（插、压、抹、折、装）的失败主要来自刚性位置伺服「硬顶」。真力矩控制不可用，但准静态下跟踪误差是外力的代理。IP-17 以最小改动把位置伺服升级为**准阻抗**，直接服务新增的接触类任务面。
- **与现有方案差异**：不改底层、不改接口、不训新策略；只在动作外侧加三件：①虚拟力传感（虚拟弹簧 + 扰动观测器）；②相位刚度调度 `K(φ)`；③导纳滤波器整形路标。与「力控策略学习」相比，本方案零训练、可解释、可在任意 checkpoint 上外挂；与「纯视觉柔顺」相比，本方案有物理量纲与可标定性。
- **技术可行性**：中高（**有条件**）。`K_p` 需先辨识（准静态加载）；准静态门外可信，动态相只作参考（L15）；延迟下需无源性约束（L16）。若标定失败则关闭（fail-stiff）。
- **资源**：算力近零（每步几次矩阵运算）；数据=官方回放里的 `q_cmd`/`q` 对（可直接算跟踪误差）；接口无新增。
- **落地步骤**：①从 `q_cmd − q` 与已知负载/标定工装辨识 `K_p, K_d, M_nom`（E635）；②实现扰动观测器 + 准静态门（用 `recomputed_ee_valid` 与 `‖q̇‖,‖q̈‖`）；③相位刚度表（approach 高、transport 中、insert/press/wipe/release 低），从 IP-06 阶段标注取相位；④导纳整形接入 IP-09 路标；⑤用 F̂ 做 IP-02 的物理抓握确认、IP-14 的摩擦锥滑移预测；⑥按 L16 定 `K_φ` 上界（E637）。
- **风险**：**力不可观/刚度误辨 → 伪力反馈使软伺服漂移**（本轮最大风险）；延迟导致导纳振荡；`F̂` 双向混叠（接触力与加速度/重力补偿误差）；把柔顺用在自由空间吃掉精度。对冲：P14（准静态门 + fail-stiff）、P15（无源性预算）、Level-1.7 退化、先标定后启用。

### IP-18 · ForceCurriculum 伪力标签与力剖面课程（P2·条件，新）

- **动机**：官方回放有 `q_cmd`/`q`，可离线算出跟踪误差 → 伪力剖面；接触密集新数据（折衣/装凳）提供了带接触相的回放。若 IP-17 的 VFS 标定通过（E635），则可把伪力做成训练信号：课程里加入「力剖面匹配」段，让策略/残差学会产生正确的接触力形状（而非硬顶）。
- **与现有方案差异**：不依赖力传感（不存在）；不直接回归力矩（接口不支持）；只回归「由伪力剖面导出的期望路标修正」，作为 IP-17 的学习版增强，失败可整体回退到规则版。
- **资源**：回放裁剪 + 伪力计算（离线、便宜）；训练中算力（残差头/课程微调）；**强前置条件**：E635 标定通过 + E636 显示接触任务收益。
- **步骤**：①离线对回放算 `F̂(t)` 与相位；②挑接触相力矩剖面（力上升/保持/卸载）作标签；③训练力感知残差或课程段；④与 IP-17 规则版 A/B；⑤不达标即归档。
- **风险**：伪力本身有偏（E635 不过则全线失效）；回放与评测域差；过拟合接触相分布。

## 5. 符号与定义（新增 U19–U21；U1–U18 沿用第 1–3 轮）

- **定义 U19（任务条件抓取流形）**：目标 `T` 的任务力旋量锥 `W_task`；抓取 `g` 的力旋量空间 `F(g)`；抓取任务兼容 ⇔ `W_task ⊆ F(g)`。稳定域 `B_ε(g) = {δ: W_task ⊆ F(g∘δ)}`；认证鲁棒分 `c(g) = max{c: E_c(g) ⊆ B_ε(g)}`，`E_c(g)={δ: δᵀΣ_g⁻¹δ ≤ c}`；抓取流形 `G = {(g, p_exec(g), c(g))}` 按 `p_exec·F_{χ²_d}(c)` 排序，形成**有序回退集**。若任务仅需抗重力，退化为经典 ε 度量。
- **定义 U20（虚拟力与可观测域）**：低层虚拟弹簧 `τ = K_p(q_cmd−q)+K_d(q̇_cmd−q̇)+g(q)`；外扰估计 `F̂ = (Jᵀ)⁺ τ̂_ext`，`τ̂_ext` 由广义动量观测器给出；**可观测域** `Q = {t: recomputed_ee_valid ∧ ‖q̇‖≤v0 ∧ ‖q̈‖≤a0}`。准静态退化 `F̂→(Jᵀ)⁺(K_p(q_cmd−q)−g(q))`。摩擦锥滑移预测：`‖F_t‖ > μ F_n`。
- **定义 U21（相位刚度与导纳整形）**：相位 `φ ∈ {approach, transport, insert, press, wipe, release}`；刚度矩阵 `K(φ)`（自由空间高、接触低，横向/法向各向异性）；导纳滤波器 `M_d ẍ + D_d ẋ + K_φ(x−x_des)=F̂`，输出 `x` 作为路标命令；无源性要求 `D_d ≥ (K_φ+K_e)Δ/2`（L16，保守充分条件）。

```python
# ===== IP-16: 任务条件抓取流形（消费 IP-13 的位姿 + 协方差）=====
def select_grasp(state, task, Sigma_g):
    cands = grasp_sampler(state.target.mask, state.target.pointcloud)   # 6-DoF 候选
    scored = []
    for g in cands:
        W = task.wrench_cone(task.phase)          # 自重/插入反力/抹拭法向/拧转力矩
        if not subset(W, grasp_wrench_space(g)):  # W_task ⊄ F(g) ⇒ 抓得住也做不成
            continue
        c = certified_basin(g, Sigma_g, task)     # max c: E_c(g) ⊆ B_eps(g)  (L14)
        p = exec_feasible(g, state)               # 可达/接近净空/无碰撞
        if c > 0 and p > 0:
            scored.append((p * chi2_cdf(c, task.dim), c, g))
    scored.sort(key=lambda t: t[0], reverse=True)
    return [g for _, _, g in scored]               # 有序回退集 → IP-02/IP-09
```

```python
# ===== IP-17a: 虚拟力传感（准静态为主体，DOB 补偿动态）=====
def estimate_wrench(s, a_prev, robot, obs):
    q, dq, qdd = s.q, s.dq, s.qdd
    tau_spring = robot.Kp @ (a_prev.q - q) + robot.Kd @ (-dq) + robot.g(q)
    tau_dob = momentum_observer(q, dq, tau_spring, robot.M_nom)   # 补偿惯性/科氏
    if not (obs.recomputed_ee_valid and norm(dq) <= V0 and norm(qdd) <= A0):
        return None                                # 可观测域外：不给力估计（P14）
    tau_hat = tau_spring if norm(qdd) <= A0 else tau_dob
    return pinv(robot.J(q).T) @ tau_hat            # 力旋量 F̂
```

```python
# ===== IP-17b: 相位刚度 + 导纳整形（输出路标命令，不改接口）=====
STIFFNESS = {"approach": K_HIGH, "transport": K_MID,
             "insert": K_LOW_AXIAL, "press": K_LOW_AXIAL,
             "wipe": K_LOW_NORMAL, "release": K_LOW}
def compliant_waypoint(x_des, x, v, phase, Fhat, Md, Dd, dt):
    K_phi = STIFFNESS[phase]
    F = Fhat if Fhat is not None else zeros(6)     # 不可观 ⇒ 0，退回纯位置
    xdd = (F - Dd @ v - K_phi @ (x - x_des)) / Md  # U21 导纳滤波器
    return xdd
```

# ===== IP-14 升级: 摩擦锥力学通道（与视觉 SlipGuard 取或，阈值保守）=====
def friction_slip(Fhat, grasp, mu):
    if Fhat is None:
        return None                                # 无虚拟力 → 只用视觉
    Ft = tangential_component(Fhat, grasp.normal)
    Fn = normal_component(Fhat, grasp.normal)

## 7. 推导（新增引理 L14–L16；L1–L13 沿用第 1–3 轮）

**引理 L14（任务条件抓取的认证成功下界）** 设抓取位姿误差 `δ ~ N(0, Σ_g)`，稳定域 `B_ε(g)` 给定时，令 `c(g) = max{c : E_c(g) ⊆ B_ε(g)}`，`E_c(g) = {δ : δᵀΣ_g⁻¹δ ≤ c}`。则 `P(W_task ⊆ F(g∘δ)) ≥ P(δ ∈ E_{c(g)}) = F_{χ²_d}(c(g))`。故 `argmax_g p_exec(g)·F_{χ²}(c(g))` 最大化**可认证的**下游成功下界；该下界只依赖 `Σ_g` 的白化几何（与 `Σ_g` 各向异性、量纲无关，和 L11 同源）。特例：仅抗重力任务下 `F(g)` 退化为力闭合、`c(g)` 退化为经典 ε 度量。∎

**引理 L15（虚拟力的可观测性与误差界）** 在低层虚拟弹簧模型下，令 `τ_s = K_p(q_cmd−q)+K_d(q̇_cmd−q̇)+g(q)`，`F̂=(Jᵀ)⁺τ_s`。若 `K_p` 有相对误差 `ε_K`、`M_nom` 有误差 `ε_M`、且 `‖q̈‖≤a0`，则接触相 `‖F̂−F_ext‖ ≤ ‖(Jᵀ)⁺‖·(ε_K‖τ_s‖ + ε_M a0 + ‖Δg‖)`；当 `a0→0`（准静态）且 `K_p` 精确时 `F̂→F_ext`。⇒ **接触力只在准静态、刚度已标定时可观**；可观测域 `Q`（U20）之外应关闭柔顺。这正是 P14 的理论依据。∎

**引理 L16（延迟导纳的无源性约束）** 线性化导纳回路（U21）与环境刚度 `K_e` 耦合，块延迟 `Δ` 下，一个保守充分的无源性条件为 `D_d ≥ (K_φ + K_e)Δ/2`；故可用柔顺刚度的上界 `K_φ* ≈ 2D_d/Δ − K_e`。⇒ **延迟越大，能用的柔顺越硬不起来**；块长/低频（U12/E633）直接压缩柔顺预算。该界为保守充分条件，精确常数依赖离散化，需 E637 实测标定。∎
