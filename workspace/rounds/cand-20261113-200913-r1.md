# 第 69 轮（承接第 68 轮「CALM-RAS 标定感知风险自适应闭环」IP-243~252；灵感循环新循环第 1 轮；本轮灵感：「低成本方案」×「力矩传感」）

> 第 68 轮把「标定」从离线常数升级为在线潜变量，用速率限制挡住快变故障、用 canary 挡住坏适配器，回答了「我的测量还准吗」。但它的自陈最大风险暴露了一个**自指循环**：标定是否可信，仍然由**被标定的那套测量**来验证。当慢故障与漂移同频、同签名时，COF 把它「标好」，CFA 把 H_cal 后验推高，CAC 的金标集若不覆盖该模式便放行——**系统越会标定，慢故障越隐形**。

> 本轮两个灵感词恰好给出这个循环的两个出口：
>
> - **力矩传感** 提供一条**物理接地、非学习、外部**的见证通道。视觉/触觉/情绪都是学出来的，可以一起漂；力矩受 Newton–Euler 约束，是「不参与学习」的裁判。更关键的是：**异构力矩估计之差 τ_cur − τ_sea 会把真实力矩整体抵消**，只剩传感器偏置——这就是 R68 缺失的第二个方程。
> - **低成本方案** 把目标从「买更高精度」改成「买**误差机理的多样性** + 用便宜信号**门控**昂贵计算」。精度贵且仍是单点失效；多样性便宜，且能把「看不见的偏置」差分成「看得见的偏置差」。
>
> 核心命题：**用「物理接地的异构廉价冗余 + 力矩按需唤醒」替代「昂贵精密传感」，让 R68 的计量层在低成本身体上仍然可证伪——TORQ-RAS（Torque-anchored, Observation-Redundant, Query-gated Risk-Adaptive System）。**

## 0. 直觉与动机

**灵感 1（力矩传感 → 最便宜的外部见证，且「差」比「值」更可信）**
直觉：R68 的困境不是传感不够多，而是所有证据都能被同一套学习管线解释掉。力矩不一样：它是**物理量**，满足 τ = M(q)q̈ + C(q,q̇)q̇ + g(q) + τ_ext，这条等式不由任何网络「学会」，因而不与视觉/世界模型共谋。工程上更妙的是，我们有两条**误差机理完全不同**的廉价力矩估计：
- τ_cur：无刷电机电流 × 力矩常数（误差来源：电气零漂、温漂、摩擦、齿槽）；
- τ_sea：串联弹性体/关节应变片的挠度（误差来源：机械迟滞、蠕变、装配应力）。
它们的和看真实力矩，但它们的**差** d = τ_cur − τ_sea 把真实力矩整体消掉，只剩两种传感器偏置之差。换句话说：**d 是一个「传感器偏置计」**，不需要知道真值就能读数。R68 的感知残差 a 同时混入「标定漂移 c」与「真实慢故障 f」，单方程两未知量 → 不可辨识；d 提供第二个方程，使 (c, f) 呈**三角可辨识**：先由 d 读出传感侧漂移，再从 a 扣掉它读出植侧故障。这正是对 R68 最大风险的正面修复。

**灵感 2（低成本方案 → 用多样性替代精度，用门控替代算力）**
直觉：单一昂贵传感器只是「单点失效 + 高方差」的另一种写法；它的高精度并不能让偏置变得可观测。真正便宜的是**冗余的异构性**：电机电流本来就是驱动器现成的（近乎零边际成本），关节应变片是消费级器件，二者误差物理不同。它们融合的价值不在「降方差」（偏置不会被平均掉），而在「**让偏置可观测**」——你无法平均掉一个你看不见的偏置，却可以把它差出来。另一方面，闭环里最贵的是感知 + MTM + 认证（毫秒与数百 MB 影子），而力矩前端是亚毫秒、低维、常开的。于是可以做**事件门控级联**：便宜的一直开着做反射，贵的一旦被力矩事件唤醒才跑完整 CALM 路径。安全不再靠「一直算」，而靠「该算时一定被唤醒 + 不唤醒也安全（无源反射）」。

**灵感 3（事件门控 → 便宜常开，昂贵按需，降级仍安全）**
直觉：把力矩反射当作「脊髓」，把 CALM-RAS 当作「大脑」。脊髓常开、低延迟、由无源能量罐保证绝不注入能量；大脑按需唤醒。即使门控漏检（最坏的 α_gate），脊髓仍把能量与接触力关在无源包络内，只是任务性能退化——这是**优雅降级**，而不是安全失效。

**灵感 4（物理即免费标签 → 抗自毒）**
直觉：R68 次级风险里「WM 残差作伪标签在 WM 失效时自毒」是结构性的：伪标签来自被监督对象本身。力矩动力学残差不同——它锚定在**实测力矩 + 已知惯性模型**上，与 WM 漂移无关；唯一能毒它的是力矩自身漂移，而 d 恰好能报警。于是「见证门控的自监督」把自毒回路从「WM 漂移 → 标签漂移」改成「力矩漂移 → 被 d 拦截」，后者是可观测的。

**灵感 5（物理即免费认证 → 让安全可负担）**
直觉：R68 的五关认证里最贵的是「金标回归」，因为它要标签。但物理给了三条**零标签的免费神谕**：静态平衡（静止时 τ_cmd 必须等于重力项）、能量守恒、无源性（不能凭空输出能量）。它们只覆盖「物理可验证子类」，不完整，但**sound（不会把坏的说成好的）**，且极便宜。把昂贵金标关换成物理关 + 少量廉价 canary，就是「低成本认证」。

```python
# IP-253/254 CTA + DRD：异构力矩锚与残差解耦
class CheapTorqueAnchor:
    def observe(self, q, dq, ddq, i_motor, delta_sea):
        tau_cur = self.k_t(self.T) * i_motor - self.fric(dq, self.T)   # 现成驱动信号
        tau_sea = self.k_s * delta_sea                                  # 廉价应变片
        tau_rbd = self.rbd(q, dq, ddq, self.theta_hat)
        a = tau_cur - tau_rbd                     # 植侧残差 + 传感偏置
        d = tau_cur - tau_sea                     # 真实力矩抵消 → 纯偏置差
        return a, d, torch.cat([a, d])            # r_dyn ∈ R^{2n}

# IP-255 HMR：异构计量环 + 可辨识裕度
class HeterogeneousMetrologyRing:
    def identify(self, a, d, J_c, K_c, J_f):
        c_hat = lstsq(K_c, d)                     # 先由 d 读传感侧漂移
        a_prime = a - J_c @ c_hat                 # 再扣掉它读植侧
        S = block([[J_c, J_f], [K_c, 0]]) if False else self.signature(a, d)
        gamma = svdvals(S)[-1]                    # 可辨识裕度
        return c_hat, a_prime, gamma

        M.ppc.clip(tau)                                    # 能量罐闭环，m_p>=0
        return {'mode': 'reflex', 'tau': tau, 'm_p': m_p}

    z, o = M.mtm.forward(obs.pack, M.a_prev, M.ctx)        # 3) 全模式：MTM 一次前向
    c_hat, a_prime, gamma = M.hmr.identify(a, d, *M.sig)
    c, U, thr = M.cof.step(o['cal'], a_prime, sigma_stat(M))   # 4) 先标定后归因（TCA）
    joint = M.cfa(a_prime, o['pi'], c, U)                  #    植侧残差归因
    wm = M.mtm.rollout(z, M.ach.propose_actions(obs.pack, 5))
    wm_drift = kl_div(o['pi'], wm[0]['pi']) > thr['tau_wm']

    k = M.c_ras_wm.certified_prefix(M.ach.propose(obs.x, H=M.vista.H),
                                    joint, min(M.vista.m, M.m_emo), M.alpha_chunk, wm)
    if U > TAU_CAL or gamma < GAMMA_MIN: k = min(k, k_cal_shrink(k, U, gamma))
    lam = max(M.efs.risk_scale(joint), thr['lam_floor'],
              0.8 if (|d| > TAU_D or m_p < M_M0 or wm_drift) else 0.6)
    tau = M.pi_sigma.prefix_dispatch(M.A[:k]) * lam
    M.ppc.clip(tau)                                        # 控制前先过能量关
    M.vqa_t.submit_async(wm, {'torque': (a, d, gamma), 'passivity': m_p})
    M.fca.maybe_commit(M.shadow, M.dt_since_commit, m_p)
    return {'mode': 'full', 'tau': tau, 'lam': lam, 'joint': joint, 'm_p': m_p}
```

## 3. 推导

**引理 16（见证补秩 / 三角可辨识性）** 在定义 295 下，R68 仅有 a 时，若 J_c ∥ J_f 则签名矩阵秩 1 → (c,f) 不可辨识；加入 d 后，若 K_c 列满秩、J_f 在 c 子空间正交补上满秩，则块三角矩阵
S = [[J_c, J_f],[K_c, K_f]] 非奇异，γ_T = σ_min(S) > 0。语义：**d 是「传感偏置计」，它把 c 从 f 中拆出来**；这正是 R68 单通道缺失的一个方程。

**引理 17（慢故障可视性恢复——正面修复 R68 最大风险）** R68 中慢故障 ω_f < ω_cal 被 COF 吸收，稳态检出 → 0。TORQ 中，植侧故障改变真实力矩 τ，而 d = τ_cur − τ_sea 对 τ **恒等抵消**，故植侧故障在 d 上贡献为 0；标定 ĉ 只解释 d 与静态段可解释的部分。于是 a′ = a − J_cĉ 中的 J_f f 不被 ω_cal 抹掉，慢植侧故障检出下界
P_det ≥ 1 − Φ(τ_det / σ_eff)，其中 σ_eff 与 ω_cal 解耦。系：**标定带宽不再是慢故障盲区**；盲区转移到「传感侧慢故障」与「共模」，见风险。

**引理 18（成本–多样性定律）** 在 A95（异构通道偏置源独立）下，N 条异构通道的融合残差偏置满足 ‖b̂ − b‖ ≤ σ/γ_N，γ_N ~ √N；成本线性增长，故 TP$ ∝ ΔRisk/(N·c) 在异构区**超线性**。若存在 r 维共同模（共模秩亏），签名矩阵在该子空间上的奇异值为 0，γ_N 饱和，**任何预算都无法辨识落入共同模零空间的故障**——低成本买到的可观测性有硬上界。

**引理 19（物理接地伪标签的抗自毒界）** PGS 的伪标签锚定实测力矩，其偏差 ≤ |b_cur| + 模型误差。门控 |d| < τ_d ⇒ |b_cur − b_sea| < τ_d，再由应变侧界得 |b_cur| ≤ τ_d + |b_sea|。故伪标签偏差 ≤ 2τ_d + ε_model，**与 WM 漂移无关**；对比 R68 的 WM 伪标签偏差随 WM 漂移无界增长。自毒回路被改道为「力矩漂移 → d 拦截」，后者可观测。

**引理 20（门控实时/能耗界）** 平均时延 E[T] = (1−α)T_reflex + α·T_full + T_gate，能耗同理，α = P(g_t=1)。反射模式由无源罐保证安全不变式在两种模式下均成立；检测延迟 ≤ 驻留 + 门控延迟。取 T_reflex ≈ 0.4 ms、T_full ≈ 2.6 ms、α ≈ 0.15 ⇒ E[T] ≈ 0.73 ms。

**定理 16（TORQ 端到端风险一致性）** 在 A87–A94 与 A95–A97 下：
1. P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + **α_torq + α_gate**；
2. U↑ ∨ |d|↑ ∨ m_p↓ ⇒ λ ≥ 0.8 ∧ 唤醒率↑ ∧ k 收缩——物理/标定不确定永远导向收紧；
3. 慢**植侧**故障检出下界由引理 17 给出，与 ω_cal 无关；
4. m_p ≥ 0 ⇒ 闭环无源，能量注入上界为 0；门控漏检时安全不变式仍成立（仅性能降级，定义 308）；
5. 有害适配器上线概率 ≤ (1 − r_fca)·p_h，r_fca ≥ 0.95。

**定理 17（低成本认证的 soundness 与不完备性）** FCA 的物理关（静态平衡/无源/见证）对「物理可验证故障类」F_phys 满足：P(PASS | 坏适配器 ∧ F_phys) = 0（sound）；但对 F ∖ F_phys 不完备，误认证概率 ≤ P(F∖F_phys)·(1 − r_canary)。故 FCA 用「便宜且 sound 的物理关 + 少量 canary」换取远低于 C_cac 的成本，代价是覆盖类缩小——必须用 J_TORQ 明确记录覆盖证据。

**定理 18（成本下界 / 不可能性）** 要对故障集 F 达到可辨识裕度 γ，需 rank(S) ≥ dim(c) + dim(f)。若可用廉价通道共享 r 维共同模，则可观维 ≤ rank(S) − r；当 F 含共同模零空间分量时，任何预算 B 均无法认证该类慢故障。在 A95 下最小充分配置是「电流 + 应变」异构对（恰覆盖植侧子空间），即 B* 的最小值由异构对给出——这是低成本设计的理论边界，也是本方案的诚实限度。

## 6. 本轮最大风险

**一句话**：TORQ-RAS 的全部修复都押在「异构力矩差 d 与感知故障不共模」这一假设上——**而在真正的最低价配置里，电机电流的温漂与感知链路的温漂来自同一个热场、载荷突变同时改写了感知几何与力矩读数**，共模分量会让签名矩阵秩塌陷（γ_T → 0），d 不再能充当独立见证，R68 的「慢故障被标定吸收」原样复活，且这次连昂贵的第二见证传感器都已被「低成本」裁掉——**省下的每一美元，都是从一个看不见的盲区里借来的**。

**次级风险与缓解**：
1. **惯量/摩擦误辨识**：r_dyn 偏置 → 在线辨识 + 区间界 + E289 覆盖率监控；超界即冻结 c_τ 并降级；
2. **应变片迟滞/蠕变**：d 自身漂移 → 定期自由运动激励重标 + 迟滞模型 + 突变检测（速率限制）；
3. **门控漏检**：事件漏报 → 迟滞/驻留 + 反射无源包络 + τ_evt(U) 随 U 收紧；
4. **无源证书过度保守**：能量罐耗尽致任务失败 → 预算分配 + 双罐切换 + D_g 监控；
5. **FCA 覆盖不足**：物理关只覆盖 F_phys → J_TORQ 显式记录覆盖证据 + 稀疏金标补盲 + canary 轮换；
6. **物理模型失配**（柔性关节/未建模动力学）→ 残差鲁棒界 + 把模型误差并入 f 的先验而非硬判。

## 2. 形式化定义（要点版）

**定义 301（FCA 五关）** 静态平衡 / 无源能量 / 力矩见证 / 廉价 canary / 稀疏金标抽检。物理关对 F_phys **sound（无假 PASS）**，成本 `C_fca ≤ c_0 + c_1 n ≪ C_cac`。

**定义 302（TCA）** 归因顺序：d 与静态段辨识 c_τ → 修正得 a′ = a − J_cĉ → d 平而 a′ 漂判植侧慢故障（修复 R68 盲区）→ d 突变超速率限制判 H_bias^τ（禁标定吸收）。继承 R68 红线。

**定义 303–305（成本前沿 / 风险缩放 / 干扰集）** `TP$ = ΔRisk/ΔB`；A95（异构通道偏置源独立）下 TP$ 超线性，共模秩亏时 γ 饱和为 0；`λ = max(λ_efs, λ_floor(U), λ_floor^τ)`，`λ_floor^τ = max(0.6, 0.8·1[|d|>τ_d ∨ m_p<m_0 ∨ U>τ_cal])`；`ℰ_TORQ = ℰ_CALM × ℰ_torq × ℰ_gate × ℰ_energy`。

**定义 306–308（证书 / 管线 / 降级）** `J_TORQ` Valid ⇔ Valid(J_CALM) ∧ γ_T ≥ γ_min ∧ m_p ≥ 0 ∧（full ⇒ FCA=PASS）∧ 红线未越界；离线零标签惯量/摩擦辨识→PGS→FCA 首提交，在线反射常开+事件全路径+60s 影子；反射模式 τ_cmd ∈ 𝒯_pass，降级度 D_g 可解析上界。

## 3. 关键算法伪代码

```python
# IP-253/254 CTA + DRD：异构力矩锚（零新硬件）+ 残差解耦
class CheapTorqueAnchor:
    def observe(self, q, dq, ddq, i_motor, delta_sea):
        tau_cur = self.k_t(self.T) * i_motor - self.fric(dq, self.T)
        tau_sea = self.k_s * delta_sea
        tau_rbd = self.rbd(q, dq, ddq, self.theta_hat)
        a = tau_cur - tau_rbd                 # 植侧残差 + 传感偏置
        d = tau_cur - tau_sea                 # 真实力矩抵消 → 纯偏置差
        return a, d, torch.cat([a, d])

# IP-255 HMR：先由 d 读 c，再扣掉读 f；给可辨识裕度
class HeterogeneousMetrologyRing:
    def identify(self, a, d, K_c, J_c):
        c_hat = lstsq(K_c, d)
        a_prime = a - J_c @ c_hat
        gamma = svdvals(self.signature(a, d))[-1]
        return c_hat, a_prime, gamma

# IP-256 PGS：见证门控的物理自监督（抗 WM 自毒）
def physics_grounded_ssl(z, d, tau_meas, tau_rbd, tau_pred):
    gate = (d.abs() < TAU_D).float()
    return (L_DYN * (gate * (tau_meas - tau_pred).pow(2)).mean()
            + L_CONS * (tau_rbd - tau_pred).pow(2).mean()
            + L_VIC * vicreg(z))

# IP-257/258 EGC + PPC：反射常开 / 能量关
class EventGatedCascade:
    def step(self, M, a, d, U):
        if self.hysteresis(norm(a, d) > self.tau_evt(U) or d.abs() > TAU_D):
            return {'mode': 'full', **CALM_RAS_round(M, M.obs)}
        tau = self.reflex.control(M.q, M.dq, a)
        return {'mode': 'reflex', 'tau': tau}

class PassivityPowerCertificate:
    def update(self, tau_cmd, dq, dt, p_diss):
        self.E += dt * (float(tau_cmd @ dq) - p_diss)
        self.m_p = min(self.m_p, self.E)
        return self.E, self.m_p          # 证书要求 m_p >= 0

# IP-259 FCA：物理神谕替代昂贵金标
class FrugalCertifiedAdaptation:
    GATES = [static_equilibrium, passivity_energy, torque_witness,
             cheap_canary, sparse_gold_spotcheck]
    def maybe_commit(self, shadow, dt, m_p):
        if dt < self.T_commit or m_p < 0: return 'REJECT'
        ok = all(g(shadow) for g in self.GATES)
        if ok: atomic_swap(self.live_ptr, shadow); return 'PASS'
        log_to_etorq({g.__name__: False for g in self.GATES}); return 'REJECT'

# IP-262 主闭环
def TORQ_RAS_round(M, obs):
    a, d, r_dyn = M.cta.observe(*obs.torque_pack)          # 1) 物理锚（常开）
    E, m_p = M.ppc.update(M.tau_prev, obs.dq, M.dt, M.p_diss)
    if not M.egc.trigger(r_dyn, M.U):                      # 2) 反射模式
        tau = M.reflex.control(obs.q, obs.dq, a); M.ppc.clip(tau)
        return {'mode': 'reflex', 'tau': tau, 'm_p': m_p}

    z, o = M.mtm.forward(obs.pack, M.a_prev, M.ctx)        # 3) 全模式
    c_hat, a_prime, gamma = M.hmr.identify(a, d, *M.sig)   # 4) 三角辨识
    c, U, thr = M.cof.step(o['cal'], a_prime, sigma_stat(M))
    joint = M.cfa(a_prime, o['pi'], c, U)
    wm = M.mtm.rollout(z, M.ach.propose_actions(obs.pack, 5))
    wm_drift = kl_div(o['pi'], wm[0]['pi']) > thr['tau_wm']
    k = M.c_ras_wm.certified_prefix(M.ach.propose(obs.x, H=M.vista.H),
                                    joint, min(M.vista.m, M.m_emo), M.alpha_chunk, wm)
    if U > TAU_CAL or gamma < GAMMA_MIN: k = min(k, k_cal_shrink(k, U, gamma))
    lam = max(M.efs.risk_scale(joint), thr['lam_floor'],
              0.8 if (d.abs() > TAU_D or m_p < M_M0 or wm_drift) else 0.6)
    tau = M.pi_sigma.prefix_dispatch(M.A[:k]) * lam
    M.ppc.clip(tau)                                        # 控制前过能量关
    M.vqa_t.submit_async(wm, {'torque': (a, d, gamma), 'passivity': m_p})
    M.fca.maybe_commit(M.shadow, M.dt_since_commit, m_p)
    return {'mode': 'full', 'tau': tau, 'lam': lam, 'joint': joint, 'm_p': m_p}
```

## 4. 推导

**引理 16（见证补秩 / 三角可辨识性）** R68 仅有 a 时，J_c ∥ J_f ⇒ S 秩 1，(c,f) 不可辨识。加入 d 后 `S = [[J_c,J_f],[K_c,K_f]]`，若 K_c 列满秩、J_f 在 c 正交补满秩，则 S 非奇异、γ_T = σ_min(S) > 0。**d 是传感偏置计，把 c 从 f 中拆出**。

**引理 17（慢故障可视性恢复）** R68 中 ω_f < ω_cal 的故障被吸收，检出 → 0。植侧故障改真实 τ，而 d 对 τ 恒等抵消 ⇒ 故障对 d 贡献 0；标定 ĉ 只能解释 d 与静态段可解释部分，故 a′ = a − J_cĉ 保留 J_f f，检出下界 `P_det ≥ 1 − Φ(τ_det/σ_eff)`，σ_eff 与 ω_cal 解耦。**标定带宽不再是慢植侧故障盲区**。

**引理 18（成本–多样性定律）** A95 下 N 条异构通道 `‖b̂−b‖ ≤ σ/γ_N`，γ_N ~ √N，成本线性 ⇒ TP$ 超线性；共模秩亏 r 时 γ_N 饱和，落入共同模零空间的故障**任何预算都无法辨识**。

**引理 19（物理接地伪标签抗自毒界）** 伪标签偏差 ≤ |b_cur| + ε_model；门控 |d|<τ_d ⇒ |b_cur| ≤ τ_d + |b_sea|，故偏差 ≤ 2τ_d + ε_model，**与 WM 漂移无关**；自毒回路改道为「力矩漂移 → d 拦截」。

**引理 20（门控实时/能耗界）** `E[T] = (1−α)T_reflex + αT_full + T_gate`；无源罐保证两模式安全不变式。T_reflex≈0.4ms、T_full≈2.6ms、α≈0.15 ⇒ E[T]≈0.73ms。

**定理 16（端到端风险一致性）** ①误差项 = R68 全项 + `α_torq + α_gate`；②`U↑ ∨ |d|↑ ∨ m_p↓ ⇒ λ≥0.8 ∧ 唤醒率↑ ∧ k 收缩`；③慢植侧故障检出与 ω_cal 无关（引理 17）；④ m_p ≥ 0 ⇒ 能量注入 0，门控漏检仅性能降级；⑤有害适配器上线 ≤ (1−r_fca)p_h，r_fca ≥ 0.95。

**定理 17（FCA soundness 与不完备性）** 物理关对 F_phys：`P(PASS | 坏适配器 ∧ F_phys)=0`；对 F∖F_phys 误认证 ≤ `P(F∖F_phys)(1−r_canary)`。以覆盖类缩小换成本 ≪ C_cac，覆盖证据必须写入 J_TORQ。

**定理 18（成本下界 / 不可能性）** 达 γ 需 `rank(S) ≥ dim(c)+dim(f)`；共享 r 维共模 ⇒ 可观维 ≤ rank(S)−r；共模零空间内故障任何预算不可认证。A95 下最小充分配置 = 电流+应变异构对，B* 由此给出——低成本设计的理论边界与本方案诚实限度。

## 7. 本轮最大风险

**一句话**：TORQ-RAS 的全部修复都押在「异构力矩差 d 与感知故障不共模」这一假设上——**在真正的最低价配置里，电机电流温漂与感知温漂来自同一热场、载荷突变同时改写感知几何与力矩读数**，共模分量令签名矩阵秩塌陷（γ_T→0），d 不再是独立见证，R68 的「慢故障被标定吸收」原样复活，而昂贵的第二见证传感器已被「低成本」裁掉——**省下的每一美元，都是从看不见的盲区里借来的**。

**次级风险与缓解**：惯量/摩擦误辨识（在线辨识+区间界+超界冻结 c_τ）；应变迟滞/蠕变（自由运动激励重标+迟滞模型+突变检测）；门控漏检（迟滞/驻留+无源反射+τ_evt(U) 收紧）；无源证书过度保守（能量预算分配+双罐+D_g 监控）；FCA 覆盖不足（J_TORQ 显式覆盖证据+稀疏金标+canary 轮换）；模型失配（残差鲁棒界+模型误差并入 f 先验而非硬判）。
