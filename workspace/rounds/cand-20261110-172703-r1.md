# 第 44 轮（新循环第 4 轮） · Plan-Cert × LoRA-Cert：把「运动规划」与「低秩适配」纳入可验证证书闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形边际覆盖 + 多用户契约空集」，但它仍压着两个未言明的单点假设：**(H1) 规划器被当作参数冻结的可信黑盒**——证书只在规划器输出上做单步 CBF 守卫（IP-39），从未证明「搜索策略、代价先验、anytime 提前返回」本身不引入违例；**(H2) 个性化/领域适配被默认为全参数微调或 prompt**——缺乏对「模型改动多少仍安全」的定量预算，于是 PCE 的人格契约只能约束**动作空间**，约束不到**产生动作的模型**。本轮灵感词「运动规划」「LoRA」精确命中这两个假设：**运动规划**把证书从「状态点」抬升到「轨迹 / 同伦类 / 骨架」，暴露换道、死胡同、重规划不连续这些点式守卫看不到的失效；**LoRA** 把「模型改动」变成可计算的低秩扰动界 ΔW=BA，使「适配器是否仍然 sound」第一次成为可被预算化、可被静态审计的问题。二者耦合处是本轮真正的新问题：**低秩适配的规划器，在热切换与多适配器叠加时，能否仍给出轨迹级、可审计的 sound 证书？**

## 0. 直觉与动机

**灵感 1（运动规划 → 证书必须从「点」搬到「轨迹」上）**：v20 守卫的是单步状态边际 m ≥ θ；但真实规划在 receding horizon 里先选同伦类/骨架，再做轨迹优化，anytime 还会提前返回次优解。危险不在「当前状态安全」，而在：所选路径穿过窄通道后没有退路、重规划切换同伦类造成不连续跳变、提前返回的轨迹只在终点被检查。直觉做法是给每条 plan 发一张**体检报告**——`(同伦类 ω, 沿程 clearance profile ρ_π(t), 沿程 margin 函数 m_π(t), 测量时刻 τ, 有效期, adapter 版本)`；并在换道（同伦类变化）时强制重新体检，绝不允许用旧证书续命。

**灵感 2（LoRA → 低秩即「有界的模型改动」，可被证书预算化）**：全参数微调会让任何 soundness 声明立即失效；而 LoRA 的 ΔW = BA（rank r）其谱范数直接控制网络输出的最大扰动。直觉上，**一个 adapter 不是「魔法人格」，而是一笔可计量的「安全预算支出」**：若它的最坏 CBF/value 漂移 D(ΔW) 小于当前 certified margin，它就是可认证的；否则必须缩 rank / 缩 scale，或被拒绝。这把 v20 的「人格契约 Π_u」从「只约束动作」升级为「约束产生动作的权重增量」：人格 = 带证书半径的低秩增量，而不是不可审计的整网微调。

**灵感 3（耦合 → adapter-conditioned planning 与热切换原子性）**：运动规划的代价先验/启发式常被 LoRA 定制（省能人格、赶时间人格、谨慎人格）。但 adapter 热切换会让在途 plan 证书瞬间失效；多 adapter 叠加（persona × environment × task）还会相互干扰且不可交换。直觉契约：**adapter 有租约，plan 有版本**；切换即作废旧 plan、原子重签 plan lease，失败则回退 base planner。多 adapter 冲突与 v20 多用户契约求交同构：给不出认证界，就输出**最小剪枝集**，绝不静默叠加。

**耦合升级**：LCA（低秩适配证书引擎）把 adapter 编译成可计算的安全预算与租约；CMP（认证运动规划器）输出轨迹级、同伦感知、adapter-conditioned 的 plan 证书；AIV（适配器干扰验证器）在仿真中枚举热切换、多 adapter 干扰与对抗性 LoRA，把反例回灌 CKB 与 SCV。四层架构由此从 v8「人格契约 + 并发证书」升级为 v9「+ 低秩适配证书层 + 轨迹级规划证书层」。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（轨迹证书与 plan lease）**：一条 plan π = (a_0..a_{H−1}) 在 receding horizon 上携带证书 c_π = (ω, ρ_π, m_π, τ_π, T_π, v_ad, κ)：ω 为同伦类/骨架标识，ρ_π(t) 为沿程 clearance profile，m_π(t) 为沿程 margin 函数，τ_π 为签发时刻，T_π 为有效期，v_ad 为生成该 plan 的 adapter 版本，κ 为关键级。**plan 守卫判据**：`min_{t∈[0,H]} [m_π(t) − λ(t−τ_π)] ≥ θ` 且 `t − τ_π ≤ T_π` 且 `v_ad` 与当前激活 adapter 一致。**命题（轨迹级强于端点级）**：若 c_π 满足守卫判据，则轨迹上每一点均 sound；反之仅端点 sound 不蕴含轨迹 sound。**推论**：v20 的逐状态守卫是定义 44 的退化情形（H=1、ω 任意、T_π→0），因此轨迹证书严格更强而非替代品。

**定义 45（LoRA 证书扰动界）**：基模型 f_W，低秩增量 ΔW = BA，B∈R^{d×r}，A∈R^{r×k}，rank r。在输入可达集 X 上，若激活 σ 为 L_σ-Lipschitz、输入半径 R_X，则证书函数漂移满足 `D(ΔW) ≜ L_f·‖B‖₂·‖A‖₂·R_X`（对 margin 取同式）。**可认证 adapter 集** `A_cert(θ) = { BA : D(ΔW) ≤ β·θ }`，β∈(0,1) 为预算分配比。**认证半径命题**：存在 `r_cert(W,θ) = sup{ r : ∀rank(ΔW)≤r, D(ΔW)≤βθ }`；rank 与 scale 构成二维预算。**注**：D 是覆盖整个 X 的最坏界，必然保守；在线共形/分位校准给出紧化下界 D̂ ≤ D，仅可在 E96 通过后替换 D（否则只用解析 D 保 sound）。

**定义 46（adapter-conditioned 运动规划证书）**：规划器代价/启发式由 f_{W+ΔW} 产生，轨迹证书需扣减适配漂移：`m_π^ad(t) = m_π^base(t) − D(ΔW) ≥ θ`。**定理（适配规划 soundness）**：若（i）基规划器在 margin θ+D(ΔW) 下轨迹 sound，（ii）adapter 满足定义 45 的界，（iii）plan 守卫使用 m_π^ad，则适配后的 plan sound。**推论（预算守恒）**：adapter 越强（rank/scale 越大），D 越大，可用自由 margin 越少——个性化能力与安全裕度是**同一笔预算的零和分配**，而非免费叠加。

**定义 47（adapter 租约与热切换原子性）**：每个 adapter 携带租约 ℓ_a = (id, ver, r, ‖ΔW‖₂, D, τ_a, exp, κ)。**切换协议**：swap 递增全局 epoch → 作废所有 v_ad 不匹配的 plan 证书 → 新 adapter 通过定义 45/46 校验后重签 plan lease → 才能恢复规划。**定理（无陈旧证书）**：若任何守卫读取都满足「读到的 adapter epoch = 当前 epoch」且切换前后均执行上述协议，则不存在用旧 adapter 证书守卫新 adapter 输出的执行；否则视为陈旧读，必须单调降级到 base planner。

**定义 48（多 adapter 干扰与认证组合）**：k 个 adapter 组合 ΔW_Σ = Σ_i ΔW_i，其可证界 `‖ΔW_Σ‖₂ ≤ Σ_i ‖B_i‖₂‖A_i‖₂ + Σ_{i<j} I_ij`，其中 I_ij 为不可交换/非正交干扰项（`‖A_iB_i·A_jB_j − A_jB_j·A_iB_i‖` 等）。**认证组合集** `C_comp(θ) = { (ΔW_i) : D(ΔW_Σ) ≤ βθ }`。**命题**：三角不等式界 sound 但保守；若 adapter 子空间近似正交（A_i A_jᵀ≈0），I_ij 可显式压小。**协商推论**：当 `C_comp(θ)=∅` 时输出**最小剪枝集**（去掉最少 adapter 使界回到预算内）交操作员确认，绝不静默全量叠加。

**定义 49（同伦一致重规划）**：设旧 plan 同伦类为 ω，重规划得到 π'。**同伦切换守卫**：要么 ω(π')=ω（允许连续修复），要么在认证 waypoint 处显式切换，且 π' 必须持有独立 plan lease 并在切换点满足 `ρ_π'(t_switch) ≥ ρ_min`。**定理（无跳变不连续）**：若重规划只在 guard-ready 的 waypoint 处切换同伦类且新 plan 已重签证书，则轨迹拼接处不产生未认证的 clearance 凹陷。**注**：这直接封堵「anytime 提前返回 + 同伦跳变」这一 v20 点式守卫看不见的失效模式。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 LORA-CERT-ADAPTER（低秩适配证书引擎 LCA）
1. **adapter 编译**：读取 (B, A, r, scale)，计算 ‖B‖₂‖A‖₂、解析漂移界 D(ΔW)，按定义 45 判定是否落入 A_cert(θ)；给出 rank/scale 的可行域。
2. **紧化校准（受控）**：在仿真/影子运行上用分位校准给出 D̂；仅当 E96 的越界率为 0 时才以 D̂ 替换 D，否则保守用解析 D。
3. **adapter 租约与热切换**：签发 ℓ_a，维护 epoch；swap 走定义 47 的原子协议，失败回退 base。
4. **投毒/后门检测**：检查 adapter 在安全关键探针集上的漂移是否超出 D 的预测（界外即拒绝），防止「低秩外壳 + 高影响后门」。

### 2.2 IP-61 CERTIFIED-MOTION-PLANNER（认证运动规划器 CMP）
1. **轨迹证书生成**：沿 plan 采样/区间化计算 ρ_π(t)、m_π(t)，输出 c_π。
2. **adapter-conditioned margin**：`m_π^ad = m_π^base − D(ΔW)`，与 v20 的 persona 上限、租约衰减一起取 min。
3. **同伦类管理**：维护 ω、切换 waypoint、plan lease；换道必须重认证（定义 49）。
4. **anytime 早停守卫**：早停返回的次优 plan 也必须满足定义 44，否则降级到「继续搜索」或「安全停」，绝不把未认证的早停解当可用解。

### 2.3 IP-62 ADAPTER-INTERFERENCE-VALIDATOR（适配器干扰验证器 AIV）
1. **热切换 fuzz**：在规划执行中途随机注入 adapter swap，检测陈旧证书、撕裂读、epoch 竞态。
2. **多 adapter 干扰测量**：经验测量 I_ij 与三角界差距，验证 `C_comp(θ)` 是否过保守或漏项。
3. **对抗 LoRA**：构造低范数高影响 adapter（投毒、触发词、分布外放大），检验 D 界与探针检测的召回。
4. **轨迹级压力测试**：在 Isaac Sim 注入窄通道、死胡同、动态障碍，实测同伦切换与 plan lease 过期下的安全/可用曲线。

## 4. 实验设计（E95–E102 硬门槛，承接 E87–E94）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E95 轨迹证书 soundness | 轨迹级校验 vs 端点级漏报率；窄通道/死胡同违例 | 漏报 0；0 起 |
| E96 LoRA 界紧致性 | 实测漂移 / 解析 D 比值；紧化后越界率 | 比值 ∈ (0,1]；越界 0 |
| E97 adapter 热切换 | 陈旧证书使用次数；epoch 竞态；切换恢复时延 | 0；0；< 100ms |
| E98 多 adapter 干扰 | I_ij 实测 vs 三角界；组合预算越界；剪枝最小性 | 无漏项；0；≥90% |
| E99 对抗 LoRA | 投毒 adapter 检出率；高影响低范数绕过次数 | ≥95%；0 |
| E100 anytime 早停 | 未认证早停解被采用次数；可用性损失 | 0；< 5% |
| E101 同伦一致重规划 | 换道处 clearance 凹陷；拼接违例 | 0；0 |
| E102 长时程规划-适配并发 | 100h 不安全事件；swap 次数；线性一致性违例 | 0 起；1000 次；0 |

回退：E96 界过松 → 只用解析 D 且缩小可用 margin；E97 切换不安全 → 禁止热切换，仅离线适配 + 重启；E98 干扰不可控 → 单活跃 adapter 仲裁，其余排队；E99 检出不足 → 禁用未认证来源 adapter，仅用官方签名适配器；E101 换道风险高 → 限定单同伦类规划（牺牲绕行能力保安全）；任何红线失败 → 熔断回退 v20。

## 5. 本轮最大风险

**一句话**：LoRA 的解析扰动界 D(ΔW)=L_f‖B‖₂‖A‖₂R_X 是覆盖整个输入空间的最坏界，在窄通道等关键区域极可能比真实漂移保守一到两个数量级，从而把可用 margin 吃光、退化成「个性化一开就不可行」；同时多 adapter 的非正交干扰 I_ij 难以静态给出紧界——因此 E96（界紧致性）与 E98（干扰漏项）必须设为红线，且默认保留「base planner + 禁用 adapter」这条永不失去 sound 的底线。

# 第 44 轮产物 · 创新点清单 v21：Plan-Cert × LoRA-Cert（LCA × CMP × AIV）× 可验证适配规划闭环（四层架构 v9）

## 2. 关键算法（伪代码）

### IP-60 LCA：解析界、认证半径、租约与切换
```
def certify_adapter(base, B, A, theta, beta, X_radius):
    rho_B = spectral_norm(B); rho_A = spectral_norm(A)
    D = L_f * rho_B * rho_A * X_radius          # 定义 45，覆盖 X 的最坏界
    ok = (D <= beta * theta)
    r_cert = max_rank_under_budget(base, theta, beta, scale=rho_B*rho_A)
    return AdapterCert(rank=min(rank(A), r_cert), D=D, ok=ok)

def maybe_tighten(D_analytic, shadow_stats, e96_passed):
    # 受控紧化：只有零越界的经验分位才可替换解析界
    if e96_passed and shadow_stats.overflow == 0:
        return shadow_stats.quantile(1 - alpha)          # D̂ <= D，更紧
    return D_analytic                                    # 默认保守，保 sound

def acquire_adapter_lease(cert, now, kappa):
    return AdapterLease(id=cert.id, ver=cert.ver, rank=cert.rank,
                        norm=cert.norm, D=cert.D, tau=now,
                        exp=now + lease_horizon(kappa), kappa=kappa)

def atomic_swap(current_epoch, new_lease, planner):
    # 定义 47：递增 epoch → 作废旧 plan → 校验 → 重签 plan lease
    epoch = current_epoch + 1
    planner.invalidate_plans(lambda p: p.v_ad != new_lease.ver)
    if not lease_valid(new_lease, now()) or not probe_is_clean(new_lease):
        return fallback_base_planner(epoch)              # 回退，绝不用坏 adapter
    planner.resign_plan_leases(epoch, new_lease)
    return epoch

def poison_check(adapter, probes, D):
    # 界外漂移即拒绝：低范数外壳 + 高影响后门
    worst = max(drift(adapter, x) for x in probes)
    return worst <= D                                    # 越界 => 拒绝
```

### IP-61 CMP：轨迹证书、adapter-conditioned margin、同伦切换
```
def certify_plan(plan, base_cert, adapter_cert, theta, tau):
    omega = homotopy_class(plan)                          # 骨架/同伦类
    rho   = clearance_profile(plan)                       # 沿程 clearance
    m_base = margin_profile(plan, base_cert)
    m_ad   = [m - adapter_cert.D for m in m_base]         # 定义 46 扣预算
    T = min(tau + plan_horizon(plan), tau + adapter_cert.exp - tau)
    return PlanCert(omega=omega, rho=rho, m=m_ad, tau=tau, T=T,
                    v_ad=adapter_cert.ver)

def plan_guard_ok(cert, theta, t, active_adapter_ver):
    if cert.v_ad != active_adapter_ver:                   # 定义 47 陈旧
        return False
    if t > cert.T:
        return False
    return min(m - lam * (t - cert.tau) for m in cert.m) >= theta

def replan(old_cert, new_plan, base_cert, adapter_cert, t_switch):
    new_cert = certify_plan(new_plan, base_cert, adapter_cert,
                            theta, now())
    if homotopy_class(new_plan) == old_cert.omega:
        return new_cert                                  # 连续修复，直接拼接
    # 换道：必须在 guard-ready 的 waypoint 且 clearance 足够
    if not at_waypoint(t_switch) or clear(new_cert, t_switch) < rho_min:
        return KeepOldPlan(old_cert)                     # 拒绝未认证换道
    return new_cert                                      # 定义 49

def anytime_guard(candidate_plan, base_cert, adapter_cert, theta, deadline):
    c = certify_plan(candidate_plan, base_cert, adapter_cert, theta, now())
    if plan_guard_ok(c, theta, now(), adapter_cert.ver):
        return c
    if now() < deadline:
        return ContinueSearch()                          # 不把未认证早停解当可用
    return SafeStop()                                    # 到点则安全停
```

### IP-62 AIV：切换 fuzz、干扰测量与组合剪枝
```
def swap_fuzz(executor, plan, adapters, trials):
    bad = []
    for _ in range(trials):
        t = random_switch_time(plan)
        a = random_choice(adapters)
        snap = executor.swap(a)                          # 注入 epoch 竞态
        if executor.used_stale_cert(plan) or not snap.atomic:
            bad.append((t, a, snap))
    return bad                                            # 期望为空

def measure_interference(adapters):
    table = {}
    for (i, ai), (j, aj) in pairs(adapters):
        lhs = norm(ai @ aj - aj @ ai)
        table[(i, j)] = lhs
    return table                                          # 与三角界对比查漏项

def certified_composition(adapters, theta, beta):
    total = sum(a.norm for a in adapters) + sum_interference(adapters)
    if L_f * total * X_radius <= beta * theta:
        return adapters
    # 空集不静默叠加：输出最小剪枝集，交操作员确认
    return Negotiation(minimal_pruning(adapters, theta, beta))
```

### IP-51/57/58 升级：adapter 预算进入守卫与租约
```
def car_transition_guard(e, x, cert_obj, persona, lease, plan_cert,
                         adapter_lease, t):
    theta   = cert_obj.alpha_e[e] * cert_obj.theta_sim[e]
    m_look  = cert_lookup_L0(x).m_lo[e]
    m_lease = lease.m - lease.lam * (t - lease.tau)
    m_pers  = persona_cap[e](persona)
    m_plan  = plan_cert.m_at(e, t)                       # 轨迹级 margin
    m_ad    = adapter_lease.D                            # 低秩预算已扣
    return (min(m_look, m_lease, m_pers, m_plan) - m_ad >= theta
            and lease_valid(lease, theta, t)
            and plan_guard_ok(plan_cert, theta, t, adapter_lease.ver))

def pce_bind_persona_adapter(contract, adapter_cert):
    # 人格契约从「只约束动作」升级为「约束产生动作的权重增量」
    contract.adapter_ver = adapter_cert.ver
    contract.low_rank_budget = (adapter_cert.rank, adapter_cert.norm)
    contract.cert_radius = adapter_cert.r_cert
    return contract
```

## 6. 本轮最大风险

**一句话**：LoRA 的解析扰动界 D(ΔW)=L_f‖B‖₂‖A‖₂R_X 是覆盖整个输入空间的最坏界，在窄通道等关键区域极可能比真实漂移保守一到两个数量级，从而把可用 margin 吃光、退化成「个性化一开就不可行」；同时多 adapter 的非正交干扰 I_ij 难以静态给出紧界——因此 E96（界紧致性）与 E98（干扰漏项）必须设为红线，且默认保留「base planner + 禁用 adapter」这条永不失去 sound 的底线。
