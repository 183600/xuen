# 第 68 轮（承接第 67 轮「SimRAS 仿真增强风险闭环」IP-233~242；灵感循环第 4 轮；本轮灵感：「域随机化」×「应用落地」）

> 第 67 轮 SimRAS 用一个大假设收束了整条研究线：只要 SimEngine 合成的联合轨迹与真实分布足够接近（`TV(P_sim‖P_real) < 0.1`），世界模型的滚动预测与视觉问答审计就能把风险前瞻做对。这个假设在论文里成立，在真实部署里几乎从不成立——真实世界的物理参数、传感器噪声、人的行为与情绪、算力与网络都是**未知且缓慢漂移**的；而“落地”意味着系统必须在一个没有标注、没有真值、无法回滚的开放世界里持续运行。
>
> 本轮把两件事拉进同一个闭环：
>
> 1. **域随机化（Domain Randomization）不是训练技巧，而是认证装置。** 不再追求“匹配唯一真实分布”，而是要求安全证书在**一族参数化环境**上一致成立；随机化的是**证书的适用范围**，不只是策略的鲁棒性。
> 2. **应用落地不是工程收尾，而是研究问题本身。** 控制权限不是二值的“能用/不能用”，而是可以**逐级释放、随时收回**的连续量；每一次释放都必须有**任意时刻有效（anytime-valid）**的统计证据，并计入人机接管、算力、隐私与运维成本。
>
> 于是提出 **LADDER（Landing-Aware Domain-randomized Deployment with Evidence-gated Release）**：用 DR-Engine 构造可审计的环境族与覆盖度量，用 RobustWM / DR-Cert 给出分布鲁棒认证前缀，用 BudgetAllocator 求解“随机化预算 ↔ 可释放权限”的 Pareto 前沿，用部署阶梯 + 证据门控 + 影子标定把证书安全地“落”到真机。LADDER 追问的不再是“当前这步安不安全”，而是：
>
> **在多大的环境不确定性下，我敢把多大的控制权限交给它；证据要累积到什么程度，我才敢再放开一级。**

## 0. 直觉与动机

**灵感 1（域随机化 → 从“匹配一个现实”到“覆盖一族现实”）**
直觉：SimRAS 的 `TV(P_sim‖P_real)<0.1` 是一个**点估计式**假设：它默认存在一个可被逼近的真实分布。域随机化的洞见正相反——与其猜那一个分布，不如把环境参数 `θ`（摩擦、质量、延迟、光照、人脸多样性、故障率……）当作随机变量，在 `θ ~ P_θ` 的一族模拟器里训练与验证。但现有 DR 工作几乎都在随机化**策略**，让动作更鲁棒；很少随机化**证书**。本轮的跃迁是：把“策略在随机化中变鲁棒”升级为“**安全裕度在随机化族上一致非负**”，即 `∀θ ∈ Θ_ε: m_θ(s,a) ≥ 0`。这样 DR 就从“数据增强”变成“**可审计的认证域构造**”。

**灵感 2（应用落地 → 安全是可释放的权限，而不是一次性验收）**
直觉：真实产品不会因为离线指标好就“全量上线”。它走的是阶梯：仿真 → 硬件在环 → 影子模式（只跑不算）→ 受控自主（人可接管、包络很小）→ 限定 ODD 内全自主。每一级只放开一部分权限 `α`（速度、力限、任务多样性、自主时长）。这提示我们：**证书应该输出的是一个“权限–证据”曲线，而不是一个布尔值。** 更关键的是统计陷阱：如果团队每跑几个 episode 就偷看指标决定要不要升一级，传统置信区间会失效；必须使用**任意时刻有效**的置信序列（confidence sequence / e-process），否则“落地”本身就是在做 p-hacking。

**灵感 3（覆盖漏洞是一等故障，而不是数据问题）**
直觉：DR 最危险的失败不是不够随机，而是**随机化先验刚好错了**：真实 `θ*` 落在随机化支撑之外（覆盖漏洞），或落在低概率尾部。此时策略在训练分布上表现完美，证书也“验证通过”，但真机恰好踩在分布外。这与第 65~67 轮的所有故障都不同：它不是几何/传感/模型/情绪/世界模型的故障，而是**“我以为我在覆盖，其实我没覆盖”的元故障**。因此 LADDER 把覆盖漏洞 `H_cover` 提升为显式假设，并用影子残差与 OOD 分数持续检测它。

**灵感 4（人脸/情绪的域随机化 → 落地必须先过公平性这一关）**
直觉：第 66 轮 RAS 把面部表情当作故障维度，隐含假设“表情是可比的”。但表情表达强依赖文化、年龄、性别、光照与遮挡；一个在实验室人脸数据上训练的情绪网关，部署到另一种人群时会系统性误读，从而**把安全权限释放给错误的情绪判断**。因此本轮的随机化轴必须包含“人”的维度，并施加**分组等化覆盖（equalized coverage）**约束：不是只要求平均覆盖，而是要求每个可识别群体的最坏覆盖都不低于阈值。否则 LADDER 的“落地”会放大既有偏见。

**灵感 5（三灵感合流 → LADDER 的六段式）**
LADDER 沿用了 VISTA/RAS/SimRAS 的“证据 → 证书 → 控制”链，但把每一环都换成**分布鲁棒 + 分级释放**版本：
1. **DR-Engine**：参数化环境族、分层/重要性采样、覆盖度量与可复现种子；
2. **RobustWM**：WM 集成（epistemic uncertainty）+ 族一致性损失，输出“预测的预测”；
3. **DR-Cert**：把 `k_wm` 升级为 `k_dr`，在 `Θ_ε` 上取最坏情形安全裕度；
4. **BudgetAllocator**：求随机化预算 `B_dr` 与可释放权限 `α` 的 Pareto，回答“随机化到什么程度才值得落地”；
5. **StageManager + EGR**：L0–L4 部署阶梯与任意时刻有效的证据门控、权限租约、迟滞升降级；
6. **ShadowCal + TakeoverGuard**：影子模式无风险标定真实 `θ*` 后验；人机接管可达性作为最后一道物理兜底。

**与前三轮的差异一句话**：VISTA 解决“坏了归因到哪”，RAS 解决“谁来控制、控制多少”，SimRAS 解决“未来会不会坏”，LADDER 解决“**在未知且漂移的世界里，凭什么敢把权限交给它，以及交多少**”。

## 1. 形式化定义（增量：定义 266–285）

- **定义 266（LADDER 总览）** `LADDER = (DREngine, RobustWM, DRCert, BudgetAlloc, StageManager, EGR, ShadowCal, TakeoverGuard, AIC, JLadder)`。定位：SimRAS 的“仿真增强闭环”升级为“域随机化下可证据化落地的闭环”。不变式：所有随机化与离线训练只在离线段；在线段只做集成推理、证据累积、证书与门控，零在线学习写。
- **定义 267（环境参数与随机化族）** 环境参数 `θ ∈ Θ ⊆ ℝ^d`（摩擦、质量、传动间隙、传感噪声、延迟、光照、人脸域、故障率、人类响应）。模拟器 `M_θ`。随机化先验 `P_θ`，支撑 `Θ_train = supp(P_θ)`，覆盖半径 `ε` 下邻域 `Θ_ε = {θ : d_Θ(θ, Θ_train) ≤ ε}`。
- **定义 268（随机化轴）** `A = A_phys × A_sense × A_human × A_deploy`：物理（质量/摩擦/柔性/磨损）、感知（噪声/延迟/标定漂移/光照/遮挡）、人（表情风格/文化/年龄/注视/接管倾向）、部署（算力降频/时钟抖动/网络/电量）。每个轴给出采样区间与分布。
- **定义 269（DR-Engine）** `DREngine = (Sampler, Stratifier, ImportanceSampler, CoverageEstimator, SeedLedger)`。采样器按轴分层；重要性采样专门放大 `R_emotion` 高与故障率高的稀有域；覆盖估计器给出有效覆盖 `cov(Θ_train; P_real)`；种子账本保证 `D_sim` 可复现与可审计。
- **定义 270（覆盖度量）** 用 1-Wasserstein 度量 `W_1(P_real, P_θ) = inf_{γ∈Γ} ∫ d_Θ(θ,θ') dγ`，并以 `ε_cov` 为阈值；分组覆盖 `cov_g` 对每个群体 `g` 单独计算，要求 `min_g cov_g ≥ 1-δ_cov`。覆盖不仅看均值，还看**最坏分组**。
- **定义 271（分布鲁棒风险泛函）** 对风险函数 `R(π; θ)`，定义
  `R_DR(π) = sup_{P: W_1(P,P_θ) ≤ ε} E_P[R(π; θ)]`，并以 `CVaR_β(θ~P_θ)` 作有限样本近似。若 `R` 关于 `θ` 是 `L`-Lipschitz，则 `R_DR ≤ E_{P_θ}[R] + Lε`。
- **定义 272（集成不确定性与安全下界）** RobustWM 用 `K` 个成员给出 `{(π^k, P(H)^k, m^k)}_{k=1}^K`；安全裕度下界 `m_LB = Quantile_{γ_u}({m^k})`，认知不确定度 `u = Var_k(m^k)`；`u > τ_u` 时禁止放宽权限。
- **定义 273（DR 认证前缀）** `k_dr = max{ k' ≤ k : ∀i≤k', min_{θ∈Θ_train} m_θ(s_i,a_i) + λ_risk·ρ_safe ≥ 0 }`；最终 `k* = min(k_VISTA, k_emo, k_wm, k_dr, m_ras)`。注意 `k_dr` 是**族上最坏**而非点估计。
- **定义 274（随机化预算与代价）** `B_dr = (|Θ_train|, N_traj, V_Θ, K)`；代价 `C_dr(B_dr) = c_sim·N_traj + c_ens·K + c_eng·d + c_label·N_human`。预算越大，覆盖越广、最坏情形越保守，但离线成本与保守性代价上升。
- **定义 275（权限–预算曲线）** 可释放权限 `α(B_dr) = max{α : R_DR,α ≤ R_budget}`，其中 `R_DR,α` 是把权限 `α` 映射为包络（速度/力/任务集）后的鲁棒风险。曲线 `α(B_dr)` 单调不减；其拐点给出“值得落地”的最小预算 `B_min`。
- **定义 276（部署阶梯与 ODD）** 阶段 `s ∈ {L0 仿真, L1 硬件在环, L2 影子, L3 受控自主, L4 ODD 内全自主}`；每级有权限上界 `α_s` 与运行设计域 `O_s`（地形、光照、人密度、任务、速度/力上限）。`α_s` 随级单调不减，`O_s` 单调扩张。
- **定义 277（证据与置信序列）** 每个 episode 记录违规指示 `X_i = 1[违反包络] ∈ {0,1}`。用时间一致置信序列给出 `p_UCB(t)`、`p_LCB(t)`，满足 `P(∀t: p ≤ p_UCB(t)) ≥ 1-α_e`（同理下界）。证据日志 `Ev_t = (X_{1:t}, 场景哈希, 证书哈希, 时间戳)` 不可篡改。
- **定义 278（证据门控释放 EGR）** 升到 `s+1` 当且仅当 `p_UCB(t) ≤ p_promote`、`n_t ≥ n_min`、覆盖无告警、接管可达性通过、权限租约未过期；降到 `s-1` 当 `p_LCB(t) ≥ p_demote` 或任一假设见证失效。`p_promote < p_demote` 构成迟滞带。
- **定义 279（权限租约与非平稳）** 每次释放的权限带租约长度 `T_lease`；到期必须用新证据续租，禁止“陈旧证据永久授权”。漂移模型 `‖θ*_{t+1}-θ*_t‖ ≤ V`；窗口证据用有效样本 `n_eff = W/(1+(W-1)ρ̄)` 折减相关性。
- **定义 280（影子标定）** L2 阶段策略只推理不执行；残差 `r_t = y_real − ŷ_θ(t)` 通过无似然推断更新真实参数后验 `q(θ*)`；仅当后验直径 `diam(q) ≤ τ_θ` 且无覆盖告警时才允许申请 L3。
- **定义 281（接管可达性）** 接管延迟 `T_h ~ P_h`（含告警到人接手）。安全包络需满足：任何检出异常后，状态在 `T_h^{(1-γ_h)}` 分位时间内仍处于**可恢复集** `Rec`。否则权限不得释放。
- **定义 282（AIC-LADDER 干扰集）** `ℰ_LADDER = ℰ_SimRAS × ℰ_dr × ℰ_dep × ℰ_hum × ℰ_ev`：`ℰ_dr` = 覆盖漏洞/先验误设/DR 过拟合/模拟器偏差；`ℰ_dep` = 降频/时钟抖动/热漂移/传感老化/网络；`ℰ_hum` = 接管延迟/误用/弃用/信任错配；`ℰ_ev` = 偷看即停/相关 episode/非平稳/日志篡改。
- **定义 283（J_LADDER 证书）** `J_LADDER = (J_SimRAS, dr_prior_hash, cov_metric, cov_g, stage_s, authority_α, evidence_log_hash, cs_ver, takeover_model_ver, replay_hash, aic_ladder_ver)`。
- **定义 284（证书有效性）** `Valid(J_LADDER) ⇔ Valid(J_SimRAS) ∧ min_g cov_g ≥ 1-δ_cov ∧ p_UCB ≤ p_promote ∧ α ≤ α_s ∧ 接管可达性成立 ∧ 无未处置覆盖告警 ∧ 租约未过期`。
- **定义 285（落地验收指标）** 平均无故障时间 `MTBF`、平均恢复时间 `MTTR`、误停率 `FSR`、人工接管率 `OR`、有效自主时长 `EAT`、覆盖漏洞率 `CHR`、权限利用率 `AU = E[α_used]/α_max`。落地不是“零故障”，而是这些指标的联合可接受域。

```python
# IP-243 DR-Engine：可审计的随机化族构造（离线）
class DREngine:
    def __init__(self, simulator, axes, sampler, coverage, seed_ledger):
        self.sim, self.axes, self.sampler = simulator, axes, sampler
        self.cov, self.seeds = coverage, seed_ledger

    def build(self, N=1_000_000, K=5):
        thetas = self.sampler.stratified(self.axes, N)
        rare = self.sampler.importance_sample(self.axes, n=N // 100)
        D = []
        for theta in thetas + rare:
            traj = self.sim.M_theta(theta).rollout(policy='explore', T=100)
            D.append((theta, traj))
        cov = self.cov.estimate(D, self.seeds.prior_hash())
        return DRDataset(D, cov, self.seeds)


# IP-244 RobustWM：集成 + 族一致性
class RobustWorldModel:
    def __init__(self, members, tau_u=0.15):
        self.members, self.tau_u = members, tau_u   # K 个 INT8 WM

    def rollout(self, obs, act_seq, k=5):
        per = [m.rollout(obs, act_seq, k) for m in self.members]
        out = []
        for i in range(k):
            pis = [p[i]['pi'] for p in per]
            pHs = [p[i]['pH'] for p in per]
            ms  = [p[i]['m'] for p in per]
            out.append({'pi': mean(pis), 'pH': mean(pHs),
                        'm_LB': quantile(ms, 0.1),
                        'u': variance(ms),
                        'certifiable': variance(ms) <= self.tau_u})
        return out


# IP-245 DR-Cert：族上最坏认证前缀
class DRCertificate:
    def __init__(self, eps_cov=0.1, L_lip=1.0, gamma_u=0.9, tau_u=0.15):
        self.eps, self.L, self.gu, self.tau_u = eps_cov, L_lip, gamma_u, tau_u

    def certified_prefix(self, A, wm_preds, lam_risk):
        k = 0
        for i, pred in enumerate(wm_preds):
            robust_margin = pred['m_LB'] - self.L * self.eps   # 覆盖漏洞的代价
            if pred['certifiable'] and robust_margin + lam_risk * pred['rho_safe'] >= 0:
                k = i + 1
            else:
                break
        return k


# IP-246 BudgetAllocator：预算 ↔ 权限 Pareto
def allocate_budget(authority_fn, cost_fn, B_max, R_budget, grid):
    best = None
    for B in grid:                      # 沿随机化轴贪心加预算
        alpha = authority_fn(B)         # 由 DR-Cert 反解
        if alpha is None or alpha <= 0:
            continue
        score = alpha - 1e-6 * cost_fn(B)
        if best is None or score > best[0]:
            best = (score, B, alpha)
    return best[1], best[2]             # B_min 由 alpha>0 的最左点给出


# IP-247/248 StageManager + EGR：证据门控的升降级
class EvidenceGatedRelease:
    def __init__(self, alpha_e=0.05, n_min=200, p_promote=0.01,
                 p_demote=0.05, lease=5000):
        self.alpha_e, self.n_min = alpha_e, n_min
        self.p_prom, self.p_dem, self.lease = p_promote, p_demote, lease
        self.X, self.t = [], 0

    def observe(self, violated):
        self.X.append(1 if violated else 0); self.t += 1

    def p_ucb(self):                     # 时间一致置信序列（方法见推导）
        return time_uniform_ucb(self.X, self.alpha_e)

    def p_lcb(self):
        return time_uniform_lcb(self.X, self.alpha_e)

    def can_promote(self, cov_ok, takeover_ok, lease_ok):
        return (len(self.X) >= self.n_min and self.p_ucb() <= self.p_prom
                and cov_ok and takeover_ok and lease_ok)

    def must_demote(self, cov_alarm, takeover_fail):
        return (self.p_lcb() >= self.p_dem or cov_alarm
                or takeover_fail or self.t >= self.lease)


# IP-249 ShadowCal：影子模式无风险标定
class ShadowCalibrator:
    def __init__(self, prior_q, tau_theta=0.2):
        self.q, self.tau = prior_q, tau_theta

    def update(self, real_obs, wm_pred):
        residual = real_obs - wm_pred
        self.q = likelihood_free_posterior_update(self.q, residual)
        return self.q, posterior_diameter(self.q) <= self.tau


# IP-250 TakeoverGuard：接管可达性
def takeover_reachable(x, v, P_h, Rec, gamma_h=0.95):
    t_h = quantile(P_h, gamma_h)
    worst = reachable_set(x, v, dt=t_h)
    return subset(worst, Rec)


# IP-252 LADDER 在线闭环
def LADDER_round(M, obs, stage, egr):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))
    A = M.vista.ach.propose(x_prime, H=M.vista.H)

    face_gate = M.erg_wm.recognize(img, x_prime, A)
    wm_preds = M.robust_wm.rollout(x_prime, A, k=min(5, len(A)))
    joint_post, _ = M.efs_wm.synthesize(M.fir.signature(M.residual_log), face_gate, x_prime, A)

    lam = M.efs_wm.risk_scale(joint_post)
    k_dr = M.dr_cert.certified_prefix(A, wm_preds, lam)
    k_ras = M.csc_ras_wm.certified_prefix_ras_wm(A, joint_post, M.m_ras, M.alpha_chunk, wm_preds)
    k_star = min(k_ras, k_dr, M.vista.m)

    # 权限门控：未过证据门控则只执行保守基线
    cov_ok = not M.coverage_monitor.alarm()
    tk_ok = takeover_reachable(x_prime, M.robot.v, M.P_h, M.Rec)
    if egr.can_promote(cov_ok, tk_ok, stage.lease_ok()) and stage.s < 4:
        stage.promote()
    elif egr.must_demote(M.coverage_monitor.alarm(), not tk_ok):
        stage.demote()

    if stage.s <= 1:                    # L0/L1：仿真或 HIL，不驱动物理执行器
        return k_star, stage.s, 'sim_or_hil'
    if stage.s == 2:                    # L2：影子，输出但不驱动
        return k_star, stage.s, 'shadow_only'

    tau = M.vista.pi_sigma.prefix_dispatch(A[:k_star]) * lam
    tau = M.ers_wm.shaping(tau, joint_post, wm_preds)
    tau = clamp_to_authority(tau, stage.alpha)     # 权限包络硬裁剪
    M.execute(tau)
    egr.observe(violated=M.monitor.violation(tau, x_prime))
    return k_star, stage.s, tau
```

## 3. 推导

**引理 13（覆盖漏洞到风险的可加代价）** 设 `W_1(P_real, P_θ) ≤ ε` 且 `R(·;θ)` 关于 `θ` 为 `L`-Lipschitz。则
`E_{P_real}[R] ≤ sup_{W_1(P,P_θ)≤ε} E_P[R] ≤ E_{P_θ}[R] + L·ε`。
**含义**：覆盖缺口不会被“平均表现”掩盖，它精确地以 `L·ε` 计入安全裕度；若 `L·ε > R_budget`，任何正权限都不可认证——这就是“随机化地板”。

**引理 14（随机化单调性与边际递减）** `R_DR(Θ)` 关于支撑包含单调不减；因此 `α(B_dr)` 单调不减。若覆盖度量随预算按 `ε(B) = ε_0·B^{-1/d}` 收缩（`d` 为参数维数），则 `α(B) ≈ α_∞ − c·B^{-1/d}`，边际收益 `dα/dB ∝ B^{-(1+1/d)}` 递减。**含义**：盲目扩大随机化会先快速涨权限、后迅速饱和，存在最优预算拐点。

**引理 15（任意时刻有效的证据门控）** 设 `p_UCB(t)` 是 `1-α_e` 时间一致置信上界。EGR 只在 `p_UCB(t) ≤ p_promote` 时升级。则对任意停止时刻 `τ`，
`P(升级时真实违规率 p > p_promote) ≤ α_e`。
配合迟滞 `p_promote < p_demote`，在平稳段期望升降级次数有限，避免门控抖动。

**引理 16（漂移检测延迟与暴露）** 设违规率从 `p_0 < p_promote` 突变为 `p_1 > p_demote`，`D = KL(p_1‖p_0)`。窗口/CUSUM 型证据在阈值 `h = log(1/α_e)` 下的期望检测延迟 `E[τ_d] ≤ h/D + O(1)`，因此额外违规暴露 `E[exposure] ≤ p_1·(h/D + O(1))`。**含义**：权限租约把“非平稳”转换成可计算的短时暴露，而不是无限期风险。

**定理 14（LADDER 分级安全）** 在引理 13–16、接管可达性与证书有效性下，对任一阶段 `s` 与任意停止时刻，发生未受控违规的概率满足
`P(unsafe) ≤ α_dr + α_e + α_h + α_cov`，
其中 `α_dr` 为随机化族未覆盖真实的概率、`α_e` 为证据门控失效、`α_h` 为接管失败、`α_cov` 为分组覆盖告警漏报。**证明要点**：四类失败事件取并集；在四者均不发生的“好事件”上，`k_dr` 的族上最坏裕度非负、权限未超 `α_s`、接管可达，故执行轨迹始终在安全包络内。

**定理 15（预算最优性与落地门槛）** `α(B_dr)` 单调；若沿轴边际收益递减（引理 14），则贪心分配达到 `(1-1/e)` 近似最优。存在 `B_min = inf{B : α(B) > 0}`，当随机化预算低于 `B_min` 时 LADDER 只能停留在 L0–L2，**“落地”在数学上不可行**，而不是工程上不够努力。

**定理 16（非平稳下的权限租约安全）** 设漂移界 `V` 与租约 `T_lease`，则在两次续租之间真实参数偏离先验支撑的距离 `≤ V·T_lease`。若该距离使 `L·(ε + V·T_lease) > R_budget`，EGR 必在租约到期时拒绝续租并降级。故**权限不会建立在陈旧证据上**；把 `T_lease` 取为 `R_budget/(L·V)` 可将漂移风险控制在预算内。

## 6. 本轮最大风险

**一句话**：LADDER 把安全感建立在“随机化族覆盖真实世界”这一先验上，但真实部署最可能的失败恰恰是**覆盖漏洞 + 相关证据**的合谋——真实 `θ*` 长期停在随机化支撑的低概率尾部，而影子残差与 episode 证据又高度相关、迟迟不触发覆盖告警，于是证据门控在“统计上看似有效”的情况下逐级释放权限，把原本只该停留在 L2 的系统推到 L3/L4；这是本轮所有理论依赖的核心假设：**覆盖漏洞可被在线残差检测，且部署证据在非平稳与相关性下仍满足任意时刻有效性。**

**次级风险与缓解**：
1. **DR 过拟合**：随机化轴只覆盖“好调的参数”，忽略未建模的柔性/接触/人因 → 用留出站点与对抗覆盖审计（E282/E287），并把 `H_cover` 作为显式假设进入 AIC。
2. **证据相关性**：同一场景反复跑会高估 `n_eff` → 用有效样本折减与场景哈希去重，强制跨场景/跨时段采样。
3. **权限租约太短**：频繁续租导致可用性下降 → 用迟滞带与租约自适应，按 `V` 调整 `T_lease`。
4. **接管不可达**：人不在环或反应慢 → 释放前强制 `TakeoverGuard`，不满足则只允许 L2。
5. **隐私与合规**：人脸/情绪数据是敏感数据 → 端侧推理、只存 `expression_hash`、不存原始视频，并做分组公平性审计。
6. **算力现实**：集成 WM 在边缘可能超预算 → 蒸馏到单模型 + 方差头，或把 DR-Cert 放到低频监督线程。

## 2. 形式化定义（完整版）

**定义 266（LADDER 总览）**
```
LADDER = (DREngine, RobustWM, DRCert, BudgetAlloc, StageManager,
          EGR, ShadowCal, TakeoverGuard, AIC, JLadder)
```
不变式：随机化、训练、预算搜索、审计全部离线；在线只做集成推理、证据累积、证书检查与门控；实时环路零在线学习写、零原始人脸写。

**定义 267（环境参数与随机化族）** 环境参数 `θ ∈ Θ ⊆ ℝ^d`，模拟器 `M_θ`。随机化先验 `P_θ`，支撑 `Θ_train = supp(P_θ)`，覆盖邻域 `Θ_ε = {θ : d_Θ(θ, Θ_train) ≤ ε}`。`d_Θ` 先按各轴量程归一化再加权，避免“质量 0.1kg”和“延迟 10ms”量纲不可比。

**定义 268（随机化轴）**
```
A = A_phys × A_sense × A_human × A_deploy
A_phys  = {质量, 摩擦, 柔性, 传动间隙, 磨损}
A_sense = {视觉噪声, 深度缺陷, 力噪声, 延迟, 标定漂移, 光照/遮挡}
A_human = {表情风格, 文化, 年龄, 注视, 接管倾向, 负载}
A_deploy= {CPU/GPU 降频, 时钟抖动, 网络丢包, 电量, 传感老化}
```
每个轴给出区间、分布与相关结构；相关性用 copula 显式建模，避免独立采样制造“不可能组合”。

**定义 269（DR-Engine）** `DREngine = (Sampler, Stratifier, ImportanceSampler, CoverageEstimator, SeedLedger)`。分层采样保证每个轴的边缘与联合都被覆盖；重要性采样把稀有高风险域（高故障率、高情绪风险、低摩擦/高惯性）过采样 `π_IS`；`CoverageEstimator` 用两样本检验 + 最近邻距离估计 `W_1` 与 `cov_g`；`SeedLedger` 记录每个域的采样种子、代码版本、物理引擎版本，保证可回放。

**定义 270（覆盖度量）**
```
W_1(P_real, P_θ) = inf_{γ∈Γ(P_real,P_θ)} ∫ d_Θ(θ,θ') dγ(θ,θ')
cov_g = P_{θ~P_real, group=g}(d_Θ(θ, Θ_train) ≤ ε_cov)
```
要求 `min_g cov_g ≥ 1 - δ_cov`。**最坏分组**而非平均覆盖，防止多数群体掩盖少数群体的覆盖漏洞。

**定义 271（分布鲁棒风险）** 对风险 `R(π;θ)`：
```
R_DR(π) = sup_{P : W_1(P,P_θ) ≤ ε} E_P[R(π;θ)]
```
有限样本用 `CVaR_β({R(π;θ_i)}) + L·ε_cov` 近似。若 `R` 关于 `θ` 是 `L`-Lipschitz（由模拟器与证书的平滑性给出），则
```
R_real ≤ R_DR ≤ E_{P_θ}[R] + L·ε_cov
```

**定义 272（集成不确定性）** RobustWM 的 `K` 个成员输出 `{(π^k, P(H)^k, m^k)}_{k=1}^K`：
```
m_LB = Quantile_{γ_u}({m^k}),  u = Var_k(m^k)
safe_certifiable ⇔ u ≤ τ_u
```
当 `u > τ_u`（成员分歧大）时，只允许收紧、不允许放宽权限；这把“我不知道”显式变成保守动作。

**定义 273（DR 认证前缀）**
```
k_dr = max{ k' ≤ k : ∀i≤k', min_{θ∈Θ_train} m_θ(s_i,a_i) + λ_risk·ρ_safe(s_i) ≥ 0 }
k*   = min(k_VISTA, k_emo, k_wm, k_dr, m_ras)
```
与第 67 轮的 `k_wm` 相比，`k_dr` 取的是**族上最坏**，且额外扣减覆盖缺口 `L·ε_cov`。

**定义 274（随机化预算与代价）**
```
B_dr = (|Θ_train|, N_traj, V_Θ, K)
C_dr(B_dr) = c_sim·N_traj + c_ens·K + c_eng·d + c_label·N_human + c_audit·N_audit
```
`V_Θ` 是随机化范围的体积；`N_human` 是人工标注/示范样本数；`N_audit` 是第三方审计样本数。

**定义 275（权限–预算曲线）** 把权限 `α ∈ [0,1]` 映射为包络 `E(α)`（速度、力、任务集、工作空间）：
```
α(B_dr) = max{ α : R_DR,α(B_dr) ≤ R_budget }
```
单调不减；`B_min = inf{B : α(B) > 0}` 是落地门槛；拐点 `B*` 之后权限增益低于成本增益。

**定义 276（部署阶梯与 ODD）**
```
L0 仿真        α=0    O_0 = 全仿真
L1 硬件在环    α=0.1  O_1 = 台架/防护围栏
L2 影子        α=0    O_2 = 真实场地，只推理不执行
L3 受控自主    α=0.5  O_3 = 限定光照/速度/人密度/任务
L4 ODD 内全自主 α=1.0 O_4 = 完整 ODD
```
每次升级同时扩张 `α_s` 与 `O_s`；降级可只降 `α` 或同时收缩 `O`。

**定义 277（证据与置信序列）** 每个 episode 记录 `X_i = 1[违反包络]`。用 e-process 构造时间一致置信序列：
```
E_t(p_0) = ∫_{p} ∏_{i=1}^t [p^{X_i}(1-p)^{1-X_i}] / [p_0^{X_i}(1-p_0)^{1-X_i}] π(dp)
```
对任意真实 `p ≤ p_0`，`E_t(p_0)` 是非负鞅；Ville 不等式给出 `P(∃t: E_t(p_0) ≥ 1/α_e) ≤ α_e`。反演得到 `p_UCB(t)`、`p_LCB(t)`，且对**任意停止时刻**有效。证据日志 `Ev_t` 带哈希链，不可篡改。

**定义 278（证据门控释放 EGR）**
```
promote(s→s+1) ⇔ n_t ≥ n_min ∧ p_UCB(t) ≤ p_promote
                 ∧ cov_alarm = False ∧ TakeoverReachable = True
                 ∧ t − t_last_lease < T_lease
demote(s→s−1)  ⇔ p_LCB(t) ≥ p_demote ∨ cov_alarm
                 ∨ TakeoverReachable = False ∨ t − t_last_lease ≥ T_lease
```
其中 `p_promote < p_demote`。迟滞带防止在阈值附近抖动；租约防止“一次证据永久授权”。

**定义 279（权限租约与非平稳）** 真实参数漂移 `‖θ*_{t+1}−θ*_t‖ ≤ V`。租约 `T_lease` 内最大漂移 `V·T_lease`；取
```
T_lease ≤ (R_budget/L − ε_cov) / V
```
保证租约到期前覆盖缺口仍不超预算。窗口证据的有效样本 `n_eff = W/(1+(W−1)ρ̄)`，`ρ̄` 为 episode 间残差相关。

**定义 280（影子标定）** L2 阶段策略只推理不执行；残差 `r_t = y_real − ŷ_θ(t)`，用无似然推断（ABC / 神经后验估计）更新 `q(θ*)`。仅当 `diam(q) ≤ τ_θ` 且覆盖无告警时，才允许 EGR 申请 L3。影子期的控制风险严格为 0，但其估计误差会以 `diam(q)` 的形式进入 L3 的覆盖半径。

**定义 281（接管可达性）** 接管延迟 `T_h ~ P_h`（含告警→人感知→接手→制动）。权限释放需满足：
```
∀x ∈ 包络边界, ∀t ≤ T_h^{(1−γ_h)}: reachable(x, t) ⊆ Rec
```
`Rec` 是可恢复集（可安全停下或退回包络）。这是“人作为最后执行器”的物理兜底，必须与证书同时验证。

**定义 282（AIC-LADDER 干扰集）**
```
ℰ_LADDER = ℰ_SimRAS × ℰ_dr × ℰ_dep × ℰ_hum × ℰ_ev
ℰ_dr  = {覆盖漏洞, 先验误设, DR 过拟合, 模拟器偏差, 轴相关缺失}
ℰ_dep = {降频, 时钟抖动, 热漂移, 传感老化, 网络丢包, 电量}
ℰ_hum = {接管延迟, 误用, 弃用, 信任错配, 群体差异}
ℰ_ev  = {偷看即停, episode 相关, 非平稳, 日志篡改, 场景重复}
```
每个干扰都要求一个对应的检测器与告警，缺一即 `J_LADDER` 无效。

**定义 283（J_LADDER 证书）**
```
J_LADDER = (J_SimRAS, dr_prior_hash, cov_metric, cov_g, stage_s,
            authority_α, evidence_log_hash, cs_ver, takeover_model_ver,
            replay_hash, aic_ladder_ver)
```
**定义 284（证书有效性）**
```
Valid(J_LADDER) ⇔ Valid(J_SimRAS)
  ∧ min_g cov_g ≥ 1 − δ_cov
  ∧ p_UCB ≤ p_promote
  ∧ α ≤ α_s
  ∧ TakeoverReachable
  ∧ 无未处置覆盖告警
  ∧ 租约未过期
```
任一条件失效即触发降级，而不是“记录后继续”。

**定义 285（落地验收指标）**
```
MTBF, MTTR, FSR(误停率), OR(人工接管率), EAT(有效自主时长),
CHR(覆盖漏洞率), AU = E[α_used]/α_max
```
落地可接受域是这些指标的联合约束（例如 `MTBF ≥ 8h, FSR ≤ 5%, OR ≤ 10%, CHR ≤ 0.1%`），而不是单点指标。

```python
# IP-243 DR-Engine：可审计随机化族
class DREngine:
    def build(self, N=1_000_000, K=5):
        thetas = []
        for axis in self.axes:                       # 分层 + copula 相关
            thetas += self.stratifier.sample(axis, N // len(self.axes))
        rare = self.importance.sample(self.axes, n=N // 100)
        D = [self.sim.M_theta(th).rollout('explore', T=100)
             for th in thetas + rare]
        cov = self.coverage.estimate(D, groups=self.groups)
        self.seed_ledger.record(thetas, seed=self.seed, code_ver=self.ver)
        return DRDataset(thetas, D, cov, self.seed_ledger.hash())


# IP-244 RobustWM：集成 + 方差头
class RobustWorldModel:
    def rollout(self, obs, act_seq, k=5):
        per = [m.rollout(obs, act_seq, k) for m in self.members]   # K × k
        out = []
        for i in range(k):
            ms = [p[i]['m'] for p in per]
            out.append({
                'pi': mean([p[i]['pi'] for p in per]),
                'pH': mean([p[i]['pH'] for p in per]),
                'm_LB': quantile(ms, self.gamma_u),
                'u': variance(ms),
                'certifiable': variance(ms) <= self.tau_u})
        return out


# IP-245 DRCert：族上最坏前缀（含覆盖缺口扣减）
class DRCertificate:
    def certified_prefix(self, A, wm_preds, lam_risk):

        for i, pred in enumerate(wm_preds):
            margin = pred['m_LB'] - self.L * self.eps_cov      # 引理 13
            if pred['certifiable'] and margin + lam_risk * pred['rho_safe'] >= 0:
                k = i + 1
            else:
                break
        return k


# IP-246 BudgetAlloc：Pareto + B_min
def allocate_budget(alpha_fn, cost_fn, B_grid, eps=1e-6):
    feasible = [(B, alpha_fn(B)) for B in B_grid if alpha_fn(B) > 0]
    if not feasible:
        return None, None, 'below_landing_floor'
    best = max(feasible, key=lambda x: x[1] - eps * cost_fn(x[0]))
    B_min = min(B for B, _ in feasible)
    knee = max(feasible, key=lambda x: x[1] / (1e-9 + cost_fn(x[0])))
    return best, B_min, knee

class StageManager:

class EGR:
    def __init__(self, alpha_e=0.05, n_min=200, p_prom=0.01, p_dem=0.05,
                 T_lease=5000):
        self.alpha_e, self.n_min = alpha_e, n_min
        self.p_prom, self.p_dem, self.T_lease = p_prom, p_dem, T_lease
        self.X, self.t, self.t_lease = [], 0, 0

    def observe(self, violated):
        self.X.append(1 if violated else 0)
        self.t += 1

    def p_ucb(self): return cs_upper(self.X, self.alpha_e)   # e-process 反演
    def p_lcb(self): return cs_lower(self.X, self.alpha_e)

                and self.p_ucb() <= self.p_prom
                and cov_ok and takeover_ok
                and self.t - self.t_lease < self.T_lease)

    def must_demote(self, cov_alarm, takeover_ok):
        return (self.p_lcb() >= self.p_dem or cov_alarm
                or (not takeover_ok)
                or self.t - self.t_lease >= self.T_lease)

    def renew_lease(self): self.t_lease = self.t
```

## 4. 推导

**引理 13（覆盖漏洞到风险的可加代价）** 设 `W_1(P_real,P_θ) ≤ ε`，`R(·;θ)` 关于 `θ` 为 `L`-Lipschitz。由 Kantorovich–Rubinstein 对偶，
```
E_{P_real}[R] − E_{P_θ}[R] = sup_{‖f‖_Lip≤L} ∫ f d(P_real−P_θ) ≤ L·W_1(P_real,P_θ) ≤ L·ε
```
故 `R_real ≤ E_{P_θ}[R] + Lε ≤ R_DR`。**推论（随机化地板）**：若 `L·ε + min_θ E[R] > R_budget`，则 `α(B)=0`，任何 L3 以上权限都不可认证。

**引理 14（预算的边际递减）** 设覆盖半径随预算按 `ε(B) = ε_0 B^{-1/d}` 收缩（`d` 为有效参数维数，分层采样下的标准非参数速率）。则
```
α(B) ≈ α_∞ − c·ε_0·B^{-1/d},   dα/dB ∝ B^{-(1+1/d)}
```
故 `α(B)` 单调增、边际递减；存在拐点 `B*`。若某轴的 `L` 更大（对风险更敏感），同样预算下应优先扩该轴——贪心按 `L_j·∂ε_j/∂B_j` 排序，在子模性下达到 `(1−1/e)` 近似。

**引理 15（e-process 门控的任意时刻有效性）** 对候选 `p_0`，定义混合似然比
```
E_t(p_0) = ∫_{p} ∏_{i=1}^t [p^{X_i}(1−p)^{1−X_i}] / [p_0^{X_i}(1−p_0)^{1−X_i}] π(dp)
```
当真实 `p ≤ p_0` 时 `E_t(p_0)` 是非负鞅，`E[E_t] ≤ 1`。Ville 不等式：
```
P(∃t : E_t(p_0) ≥ 1/α_e) ≤ α_e
```
反演得 `p_UCB(t) = inf{p_0 : E_t(p_0) < 1/α_e}`，其对所有停止时刻一致有效。因此 EGR 的任意“偷看后升级”都不会把假释放率推高到 `α_e` 以上。迟滞 `p_promote<p_demote` 在平稳段给出有限期望切换次数（标准两态马尔可夫的漂移分析）。

**引理 16（漂移检测延迟）** 设 `p_0 < p_promote` 突变为 `p_1 > p_demote`，`D = KL(p_1‖p_0)`。对 `E_t(p_promote)` 取对数，其增长率在突变后为 `−D + o(1)`，阈值 `h = log(1/α_e)`，故
```
E[τ_d] ≤ h/D + O(1),   E[exposure] ≤ p_1·(h/D + O(1))
```
租约 `T_lease` 给出兜底：即使检测器迟钝，到期也强制复核。

**定理 14（LADDER 分级安全）** 在引理 13–16、接管可达性与 `Valid(J_LADDER)` 下，对任一阶段 `s` 与任意停止时刻，
```
P(unsafe) ≤ α_dr + α_e + α_h + α_cov
```
其中 `α_dr` 为真实参数不在覆盖邻域的概率，`α_e` 为证据门控失效，`α_h` 为接管失败，`α_cov` 为分组覆盖漏报。**证明**：四类坏事件取并集；在其补集上，`min_{θ∈Θ_train} m_θ ≥ Lε_cov`（引理 13 的裕度扣减）、`α ≤ α_s`（权限硬裁剪）、`p ≤ p_promote`（引理 15）、状态在 `T_h` 内可达 `Rec`（定义 281），故执行轨迹始终留在安全包络内。降级只会缩小包络，不会引入新的越界。

**定理 15（预算最优性与落地门槛）** `α(B)` 单调（引理 14）；沿轴贪心在子模性下达到 `(1−1/e)` 近似；`B_min = inf{B : α(B)>0}` 存在且可由二分求得。低于 `B_min` 时只能停留在 L0–L2——**“落地”失败是数学结论，而非工程努力不足**。

**定理 16（租约安全）** 设漂移界 `V`，租约 `T_lease`。若 `L·(ε_cov + V·T_lease) > R_budget`，则 EGR 在租约到期时必拒绝续租并降级。取 `T_lease = (R_budget/L − ε_cov)/V` 即把漂移风险压在预算内。**含义**：权限永远有一张“到期作废”的票，非平稳世界不能靠一次离线验证永久授权。

**定理 17（安全案例的可证伪性）** `Valid(J_LADDER)` 的每个合取项都有独立见证（覆盖度量、证据哈希、接管测试、回放哈希）。若任一见证过期或与在线观测冲突，证书立即失效并触发降级。因此 LADDER 的“落地”不是一次性验收，而是**持续可证伪的运行态**；这与 VISTA 的“故障可归因”、RAS 的“风险可缩放”构成同一条方法论主线。

## 5. 落地流程与验收（应用落地）

1. **ODD 文档化**：把 `O_s` 写成可执行约束（光照 lux、地面摩擦区间、人密度、速度/力上限、任务集），每个约束对应一个在线监测器与告警。
2. **覆盖审计**：DR-Engine 输出 `W_1`、`cov_g`、稀有域覆盖与种子账本；第三方可用同一账本复现 `D_sim`。
3. **阶梯上线**：L0 仿真回归 → L1 HIL 实时性/时延 → L2 影子（通常 ≥ 2 周、≥ 5000 episode）→ L3 受控自主（人工在场，权限 0.5）→ L4 ODD 内全自主。每级都要过 EGR 与 TakeoverGuard。
4. **权限租约**：L3/L4 的权限默认带 `T_lease`；到期须用新证据续租，禁止“一次调参永久上线”。
5. **隐私与公平**：人脸/情绪端侧推理，只存 `expression_hash`；分组覆盖审计随版本发布，`min_g cov_g` 不达标不得升级。
6. **失效兜底**：覆盖告警、接管不可达、证据租约到期、证书哈希不匹配——四者任一触发“安全停 + 回退 L2/人工”。
7. **可审计交付物**：`J_LADDER` + 回放哈希 + 覆盖报告 + 红队报告 + ODD 说明书，构成可被独立复核的安全案例。

| E283 边缘算力 | 全链路延迟 | Jetson Orin P99 < 5ms，< 25W |
| E284 长时漂移 | 8h 热/老化 | 无陈旧续租，至少一次降级 |
| E285 落地成本 | 单位权限成本 | 曲线可解释、可决策 |
| E286 稀有高风险 | 重要性采样 | 覆盖 > 80% |
| E287 DR 过拟合 | 训练族 vs 留出站点 | 跨站点权限降 < 15% |
| E288 安全案例审计 | 第三方复核 | 通过率 ≥ 90%，可复现 |
| E289 跨站点/跨用户 | 迁移 | `ε_cov` 增长 < 2× |
| E290 红队 | 极端/恶意场景 | 未检出漏洞 ≤ 1 次/千 episode |

## 8. 本轮最大风险

**一句话**：LADDER 把安全感建立在“随机化族覆盖真实世界”这一先验上，但真实部署最可能的失败恰恰是**覆盖漏洞与相关证据的合谋**——真实 `θ*` 长期停在随机化支撑的低概率尾部，而影子残差与 episode 证据又高度相关、迟迟不触发覆盖告警，于是证据门控在“统计上看似有效”的情况下逐级释放权限，把本应停留在 L2 的系统推到 L3/L4；这是本轮所有理论依赖的核心假设：**覆盖漏洞可被在线残差检测，且部署证据在非平稳与相关性下仍满足任意时刻有效性。**
