# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配主动交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「同步定位与建图」×「轻量化设计」）

> R69 教会闭环「问」：把不确定性拆成 aleatoric / epistemic，用流匹配保住动作模态，用看 / 问 / 触主动消解歧义，并用 (r_res, Δa) 双通道盯防缓变故障。但 R69 的「问」有一个隐藏的**时间假设**：歧义是当前观测的性质，答案就在当前帧里，问完、验完、当轮结清。真实世界里大量歧义恰恰**不在当前帧**——「这条走廊是不是来时那条」「这个杯口是不是刚才那个」「我对面的人是同一个人吗」——只有当系统**走过去、再看一次、把新旧证据连起来**才可能回答。R69 没有地图、没有历史、没有回环：它把每一轮当作一张孤立的快照，于是只有两种坏结局——反复问同一个问题（交互疲劳），或把一次过早的猜测冻结成事实（漂移）。
>
> 更要命的是，R69 自陈的最大风险是「流模型的模态分布不可信 → 自信地追问幻影 / 把误导答案盖上已验证的章」。这个风险在时间维度上会被放大：**单条证据可以在当轮被伪造，一组跨时间的证据却可能互相对质**。而这正是 SLAM 的核心武器——**回环闭合**：不是相信一次观测，而是要求新证据与已有轨迹构成一个自洽的环；一个孤立的环闭不上，就不能改写地图。
>
> 但如果我们为了做这件事而维护一张稠密、全历史、全协方差的地图，每帧全局平滑，就会立刻击穿整条研究线（R66–R69）苦心守住的实时预算和「零学习写操作」纪律。于是第二个灵感登场：**轻量化设计**。它不只是「把模型压小」，而是一套带约束的结构设计哲学——**在硬性质量/算力预算下，把材料（证据、锚点、交互）放到承力的地方，把不承力的地方掏空；同时，减重会引入全新的失效模式（屈曲、共振、失稳），必须用安全系数与可观测性证书来兜底。**
>
> 核心命题：**把 R69 的「当轮不确定性」升级为「跨时间的证据地图」：区分局部可解、时间可解、回溯可解三种 epistemic 不确定性；用稀疏因子图上的回环闭合与环一致性纪律做证据认证；用带可观测性约束的拓扑优化式稀疏化把地图压进硬预算；并规定回环校正只能单调收紧、不能静默改写已执行动作。** 命名 **SLIM-RAS**（Sparse Loop-closed Incremental Map for Risk-Adaptive Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我该在什么时候、回到哪里去求证，以及我的记忆本身还能不能承重**」——不确定性不只可以被问出来，也可以被走过去、接起来、再回溯地修正。

## 0. 直觉与动机

**灵感 1（同步定位与建图 → 歧义是跨时间的对象，地图就是信念）**

直觉：R69 的 U_epi 是 `H(M | o_t)`，条件在**一张快照**上。但人判断「这是不是刚才那个房间」从来不靠单帧，而靠**位姿+地标+历史路径的联合一致性**。SLAM 教给我们的第一件事是：定位与建图不可分——你对「自己在哪」的信念和对「世界是什么样」的信念是同一个后验的两个边缘。R69 只保留下游的「动作模态」边缘，把上游的「世界状态 / 地标身份 / 位姿」全丢了。于是它无法表达：同一动作模态可能对应两个不同的世界（杯空 vs 杯满），而这两个世界只在未来某次观测下才分叉。

SLAM 教给我们的第二件事是**回环闭合**：累积的里程计漂移无法靠局部观测消除，只有识别出「我回到了曾经来过的地方」，才能把整条轨迹和整张地图**回溯地**校正。对应到 R69：一个早期被「消解」的歧义，可能在 10 分钟后被新证据证明是错的。没有回环机制，系统要么永远不知道自己错了，要么每轮重问一遍。**回环闭合 = 对过去信念的延迟审计**。

SLAM 教给我们的第三件事是**数据关联可能出错**：把 A 认成 B（感知别名）会产生一个**假回环**，一次假回环足以把整张地图拉坏。R69 的「k 个正交证据源一致」在时间维度上有天然对应物：**环一致性**——一条新证据必须能与已有的多条独立路径闭合成环；单条边（树上的边）不构成任何环，因此**单次交互永远不能单独认证**。这不是新增一条纪律，而是把 R69 的纪律**从计数升级为拓扑**。

**灵感 2（轻量化设计 → 信念地图必须承重，而不是越大越好）**

直觉：把 SLAM 整套搬进来最直接的做法是「全历史 + 全协方差 + 每帧全局优化」。这在这条研究线里是不可接受的：R68 的实时预算、R69 的 <2.6ms 环路、零学习写操作，都会被一个全局因子图击穿。轻量化设计给出的正确姿势不是「少做一点」，而是**结构优化**：先定义载荷（哪些不确定性方向会改变安全集），再定义承力构件（哪些证据边承载这些方向的 Fisher 信息），最后在质量预算下把不承力的材料掏掉——这就是**拓扑优化**。地图的稀疏模式本身成为设计变量。

但轻量化设计还有第二半，而且更重要：**减重会引入新的失效模式**。一根梁不是越细越好，细到某个程度会屈曲；一个稀疏图不是越省越好，省到某个程度会**失去可观测性**——把唯一能区分两种安全解释的那条边删掉，剩下的后验在该方向上是平的，再多数据也救不回来。这种失效是**结构性的、静默的**：系统跑得更快、更省、更自信，直到罕见场景里突然分不清。因此本轮必须同时交付 **可观测性证书**（information load path）和**安全系数**，否则轻量化就是把「诚实的慢」换成「自信的瞎」。

**灵感 3（三种 epistemic → R69 只处理了第一种）**

直觉：R69 的 U_epi 其实混着三种东西，处置方式完全不同：

- **局部可解（U_loc）**：当前信息动作（看/问/触）就能降的熵。R69 的全部机器只管这一种。
- **时间可解（U_tmp）**：只有积累未来观测、重访、回环才能降的熵。现在问是浪费，甚至问不出来；正确动作是**推迟并安排重访**。
- **回溯可解（U_retro）**：关于过去变量（旧地标身份、旧模态）的熵，回环校正能降。它影响的是**尚未完成的承诺**——已经执行的抓取不能撤销，但「继续往哪走」「还要不要松手」可以改。

这三种不确定性的最优动作分别是：**问 / 等与回访 / 回溯修正**。R69 把它们全塞进「问」，于是对第二、三种要么过度交互，要么把猜测固化。本轮的分解不是给 R69 打补丁，而是给它补上**时间轴**：R69 是本轮在「地图退化为单节点、无回环、无推迟」边界上的严格退化。

**灵感 4（回环 ↔ 证据纪律：单源采纳禁令可以被推导出来）**

直觉：R69 规定「单次交互不得单独定案」，这是一条外部纪律。SLAM 给出了它的**结构性理由**：在因子图里，单条边无法形成环；只有至少 k 条独立路径互相印证，才能把一条新边的误差与地图的其余部分对质。也就是说，**证据的独立性 = 环空间的维数**。这不是拍脑袋的 k，而是图论量：`cycle_rank = |E| − |V| + components`。一个树状证据图（无环）**在结构上就无权认证任何回环**。这条洞察把 R69 的「k 个正交源」从经验规则升级为可计算、可审计的拓扑条件，也让「误导性回答」有了更硬的拦截方式：它最多增加一条边，但如果闭不上一个自洽的环，就不能改写地图。

**灵感 5（轻量化的对偶风险 → 减重让失效更隐蔽）**

直觉：稠密地图的失效是**吵闹的**（慢、卡、内存爆），稀疏地图的失效是**安静的**（快、省、看起来一切正常）。一旦为了预算删掉关键约束，系统不会报错，只会在地图的一个不可观测方向上变得过度自信；而 R69 的 resolution bonus 会把这个过度自信转化为**更松的 λ**。所以本轮最大的风险不在「地图太大」，而在「地图太轻」——轻到把唯一的承力边掏空，却仍然出具一张「已验证」的证书。这是轻量化设计里最经典的教训：**失效往往发生在减重之后，而不是之前。**

## 1. 形式化定义（增量：定义 310–324）

**定义 310（SLIM-RAS 总览）** SLIM-RAS = (SEM, LCD, MUD, CSP, ASV, SRS, RCR, RAS-WM†)。四条不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **地图预算硬约束**：活动节点/边数 ≤ B_mem，单步增量更新 ≤ B_ms，回环检测事件触发、不得每帧全局重解；
(iii) **证书纪律**：任何 resolution bonus 仅在 `μ(S) ≥ μ_min`（可观测性裕度）、`cycle_rank ≥ k_cert`（环一致性）、`p(s=1) > τ_s`（回环开关后验）同时满足时授予；
(iv) **回溯单调性**：回环校正只能收紧、不能放松受影响承诺的 λ；已执行动作不得被静默改写，修订必须版本化留痕。

**定义 311（epistemic 因子图）** 变量 `X_t = (x_{0:t}, ℓ_{1:N}, M_t, s)`：位姿轨迹 `x_{0:t}`、持久潜变量/地标 `ℓ_{1:N}`（物体状态、地点身份、模态身份）、当前决策模态 `M_t`、回环开关 `s`。后验

`p(X_t | data) ∝ ∏ f_motion(x_{i−1},x_i) · ∏ f_obs(ℓ_j,x_i) · ∏ f_int(ℓ_j, answer) · ∏ f_loop(x_i,x_j,ℓ; s_ij)`。

R69 是「无持久 ℓ、无回环边、只有当前节点」的退化图：`b(M_t) = p(M_t|o_t)`。

**定义 312（epistemic 的时序分解）** 固定信息顺序（先即时问、再未来重访、再回环校正），由链式法则不重不漏地定义：
- `U_loc = H(M_t|b) − E_{Y_now} H(M_t|b,Y_now)`：最优即时信息动作可降的熵；
- `U_tmp = E H(M_t|b,Y_now) − E H(M_t|b,Y_now,Y_fut)`：只有未来累积/重访可降的熵；
- `U_retro = I(M_{past}; Y_loop | b, Y_now, Y_fut)`：回环校正可降的、关于过去变量的信息。
`U_epi = U_loc + U_tmp + U_retro`（在上述条件下），三者分别触发**问 / 推迟重访 / 回溯修正**。R69 只保留 `U_loc`。

**定义 313（回环假设与开关约束）** 回环候选 `z_ij = (i,j,r_ij,Ω_ij,y_ij)`，含数据关联 `c_ij ∈ {null,1..N}`（感知别名即 c 错）。开关潜变量 `s_ij ∈ {0,1}`：
`f_loop = Bern(s_ij;π_ij) · exp(−½ r_ij^T Ω_ij r_ij)^{s_ij}`。
只有当 `p(s_ij=1|data) > τ_s` 且数据关联置信度 `> τ_c` 时才接受该回环；否则记为伪回环并降权，而不是丢弃证据。

**定义 314（环一致性证据纪律 LCD）** 证据图 `G=(V,E)`，环秩 `r(G)=|E|−|V|+components(G)`。一条交互/回环边 `e` 是**可认证的**，当且仅当加入后 `r(G_e) ≥ k_cert`，且 `e` 至少落在 `k_cert` 个独立基本环中、每个环的残差通过 χ² 检验。树上的单边（r=0）**在结构上不可认证**。这推广 R69 的「k 个正交源」：证据独立性由环空间独立性度量。

**定义 315（可观测性与安全关键方向）** 在 MAP 处线性化，信息矩阵 `J = A^T Ω A`。令 `V_c` 为所有单位方向中，能使**认证安全集或所选模态风险改变超过 δ_safe** 的方向集合。可观测性裕度
`μ(S) = min_{v∈V_c, ‖v‖=1} v^T J_S v`，
其中 `J_S = Σ_{e∈S} J_e` 为活动边集 S 的信息矩阵。要求 `μ(S) ≥ μ_min`。称对 μ 贡献最大的边为**信息承力路径**。

**定义 316（认证稀疏化 = 信息拓扑优化）** 选活动边集 S，满足 `|S| ≤ B_mem`、单步算力 ≤ B_comp、通信/交互 ≤ B_comm，最小化
`R(S) = E[decision risk] + λ_size|S|`
s.t. `μ(S) ≥ μ_min`，且每个安全关键变量至少连到两条独立约束（冗余下限）。采用贪心「安全加权信息贡献」删边（类似按应力删材料），节点仅在可边缘化且当前决策边缘变化 `≤ ε_cons` 时合并/剪除。

**定义 317（主动 SLAM 交互控制器 ASV）** 动作集 `A_+ = A_task × {gaze, probe, ask, revisit, verify_loop, defer}`。信息价值
`VoI_SLIM(g) = ΔH_now + κ1·ΔH_map(V_c) + κ2·ΔH_future(localization) − c(g) − c_maint(g) − c_drift(g)`，
在安全与预算约束下取 `argmax`。`revisit` 是「回到曾观测过的地方以形成回环」；`defer` 是「现在不问，登记未来重访」。若无正收益且未来期权价值高于当前，则选 `defer`。

**定义 318（有界陈旧度调度 SRS）** 持久节点 j 有年龄 `a_j`、证据衰减 `e^{−γ a_j}`、后验尺度 `σ_j`。陈旧风险 `R_stale(j)=L_stale·(1−e^{−γ a_j})·σ_j`。仅当 `R_stale(j)+drift_pred ≤ ε_stale` 且 `a_j ≤ a_max` 时允许推迟；用滞回阈值避免「问—等—再问」振荡。

**定义 319（回溯修正 RCR）** 回环使过去节点 `ℓ_j` 或 `x_i` 的 MAP 改变时，计算受影响的未完成承诺 `C_aff`。规则：
(a) 已执行动作不可改写，只记录其后果；
(b) 对 `C_aff` 中的每个承诺，`λ ← max(λ, λ_floor(U_corrected))`，**撤销该承诺剩余时域上的 resolution bonus**；
(c) 若承诺不可逆（抓取/释放/交接），必须插入 `verify_loop` 或退回 R68 保守；
(d) 受影响窗口的证书标记「暂定无效」，不得静默覆盖。定义**承诺前沿** τ_c：早于 τ_c 的动作只进入状态，不再可改。

**定义 320（轻量化的四类新失效）** 稀疏化可制造：**(F1) 不可辨识**（删掉唯一判别边，后验沿该方向变平）、**(F2) 伪回环盲**（删掉冗余，环检验失去对质能力）、**(F3) 别名放大**（错误合并节点身份）、**(F4) 事件饥饿**（触发阈值过高，回环永不检测）。四者都是稠密图中不存在的**结构性失效**，必须由证书显式覆盖。

**定义 321（证书 J_SLIM）** `J_SLIM = (J_FLUID, map_version, sparse_cert=(S, μ, cycle_rank, ε_cons), loop_log_hash, staleness_max, retro_revision_count, slim_ver)`。Valid ⇔ `Valid(J_FLUID) ∧ μ ≥ μ_min ∧ cycle_rank ≥ k_cert ∧ staleness_max ≤ a_max ∧ 无未解决的回溯冲突`。

**定义 322（威胁模型 ℰ_SLIM）** `ℰ_SLIM = ℰ_FLUID × ℰ_map × ℰ_sparse`。`ℰ_map`：伪回环、感知别名、地图投毒、旧地点重放；`ℰ_sparse`：关键边删除、节点合并别名、可观测性阈值欺骗、事件触发饥饿。

**定义 323（嵌套退避链）** 地图证书失效 / 预算越界 / 回溯冲突未解时，禁用地图级消解，退回 R69 逐轮 FLUID；其 MCG 再失效则退回 R68；安全集异常则退回 R68 纯保守。沿退避链 λ 单调不降。SLIM 在「无持久节点、无回环、无推迟」时逐指令等于 R69。

**定义 324（边缘保持不变式）** 稀疏化/边缘化前后，当前决策节点 `M_t` 的边缘后验变化必须 `≤ ε_cons`（用 Schur 补或 KL 上界度量）；否则该次稀疏化被拒绝。此不变式保证「轻量化不改当前判断，只省不影响判断的结构」。

```python
# IP-264 SEM：稀疏 epistemic 地图（增量、预算内、当前边缘保持）
class SparseEpistemicMap:
    def __init__(self, B_mem, eps_cons):
        self.g = FactorGraph(); self.B_mem, self.eps_cons = B_mem, eps_cons
    def update(self, o, a, answer=None):
        add_pose_and_factors(self.g, o, a)             # 复用 R69 trunk / FMA 似然
        if answer is not None: add_interaction_factor(self.g, answer)
        if self.trigger_loop(o):                        # 事件触发，非每帧
            cands = self.detect_loops(o)                # 描述子索引，候选 ≤ 5
            for z in cands: add_switchable_loop(self.g, z)
        marginalize_preserving(self.g, self.eps_cons)   # 旧节点边缘化 + 不变式检查
        return self.g

# IP-265 LCD：回环检测 + 环一致性认证
def certify_loop(g, e, k_cert, tau_s, tau_c):
    if g.p_switch(e) <= tau_s or g.assoc_conf(e) <= tau_c: return False
    g2 = add_edge(g, e)
    if cycle_rank(g2) < k_cert: return False           # 树上单边无权认证
    cycles = independent_fundamental_cycles(g2, e)
    return len(cycles) >= k_cert and all(chi2_test(c) for c in cycles[:k_cert])

# IP-266 MUD：时序 uncertainty 分解
def decompose_temporal(g, action_set):
    U_loc = entropy(marginal(g, 'M')) - min(expected_post_entropy(g, a) for a in action_set.now)
    U_tmp = expected_post_entropy(g, action_set.now) - expected_post_entropy(g, action_set.future)
    U_retro = mutual_info(g, past_vars, loop_corrections)
    return U_loc, U_tmp, U_retro

# IP-267 CSP：认证稀疏化（信息拓扑优化）
def certified_sparsify(g, B_mem, mu_min):
    S = set(g.edges)
    while len(S) > B_mem:
        e = min(S, key=lambda e: safety_weighted_info(g, e))   # 低承力边先删
        if not redundant(g, e) or observability(g, S - {e}) < mu_min:
            break                                              # 承力边/冗余边不删
        if marginal_shift(g, S - {e}, 'M') > g.eps_cons: continue
        S.remove(e)
    return S, observability(g, S), cycle_rank(g, S)

# IP-268 ASV：主动 SLAM VoI（含 revisit / defer）
def choose_action(g, V_c, budget):
    best = None
    for a in info_candidates(g):                    # gaze/probe/ask/revisit/verify_loop
        if not budget.allow(a) or not c_ras_wm.certify_info(a): continue
        voi = (delta_H_now(g, a) + k1*delta_H_map(g, a, V_c)
               + k2*delta_H_future(g, a) - cost(a) - maint_cost(a) - drift_cost(a))
        if best is None or voi > best.voi: best = (a, voi)
    if best and best.voi > 0: return best[0]
    return 'defer' if option_value(g, 'defer') > hysteresis else None

# IP-269 SRS：有界陈旧度
def may_defer(g, j, eps_stale):
    return stale_risk(g, j) + drift_pred(g, j) <= eps_stale and age(g, j) < g.a_max

# IP-270 RCR：回溯修正（只收紧、只改未来）
def retroactive_revise(g, loop, commitments):
    if not certify_loop(g, loop, k_cert, tau_s, tau_c): return g
    old = g.copy(); apply_loop(g, loop)
    for c in affected(commitments, old, g):
        if c.executed: log_revision(c); continue         # 已执行不可改写
        c.lam = max(c.lam, lam_floor(uncertainty(g, c)))
        c.bonus_revoked = True
        if c.irreversible: c.require(verify_loop_or_R68)
    g.version += 1; g.cert_window.mark_provisional()
    return g

# IP-274 主闭环（继承 R69，插入地图层）
def SLIM_RAS_round(M, obs):
    g = M.sem.update(obs, M.last_action, M.last_answer)
    U_loc, U_tmp, U_retro = M.mud.decompose_temporal(g, M.actions)
    # 1) 伪回环先拦截；地图不可信则不授予任何 bonus
    loop_ok = M.lcd.certify_pending(g)
    map_valid = loop_ok and M.sem.observability(g) >= MU_MIN
    # 2) 局部歧义→问；时间歧义→推迟重访；回溯歧义→先做回环/修正
    g_act = (M.asv.choose_action(g, M.sem.V_c, M.budget)
             if map_valid and (U_loc > TAU_LOC or U_tmp > TAU_TMP or U_retro > TAU_RETRO)
             else None)
    if g_act in ('revisit', 'verify_loop'):
        M.srs.schedule(g, g_act)
    elif g_act not in (None, 'defer'):
        ans = M.cia.execute(g_act); M.sem.update(obs, M.last_action, ans)
    # 3) 回环校正：只收紧未来承诺
    if M.lcd.has_certified_loop(g):
        g = M.rcr.retroactive_revise(g, M.lcd.best_loop(g), M.commitments)
    # 4) 风险缩放：仅当当前决策边缘仍可观测时保留 resolution bonus
    U_floor = U_loc + (U_tmp if not M.srs.is_fresh(g) else 0.0)
    if not map_valid or g.cert_window.provisional:
        U_floor += U_tmp + U_retro                          # 退回 R69 语义
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if not map_valid: lam = max(lam, LAM_R69); k = min(k, M.pi_sigma.k_cap())
    mode = select_mode(g, lam)
    M.vqa_s.submit_async(g, M.sem.sparse_cert(), U_loc, U_tmp, U_retro)
    return k, lam, mode, (U_loc, U_tmp, U_retro)
```

## 3. 推导

**引理 19（推迟的阈值最优性）** 设即时动作净收益 `G_now = VoI(g_now) − c(g_now)`，推迟到 τ 的净收益 `G_fut(τ) = e^{−ρτ}(VoI(g_fut) − c_fut) − R_stale(τ)`。若 `R_stale(τ)` 关于 τ 单调递增、`e^{−ρτ}` 单调递减，则 `G_fut(τ) − G_now` 关于 τ 单调递减，存在唯一阈值 τ*：`τ < τ*` 时立即问最优，`τ > τ*` 时推迟/重访最优。系：**R69 的「当轮必问」只在 τ*=0 的边界成立**；U_tmp 大时，立即问是被支配的策略。

**引理 20（环一致性对伪回环的抑制）** 设每个独立基本环的伪接受概率为 `p_f`，各环检验条件独立。一条伪回环要获得认证，必须同时通过 `k_cert` 个独立环，故伪认证率 `≤ p_f^{k_cert}`；若各环共享相关误差 `ρ<1`，则 `≤ p_f·(ρ + (1−ρ)p_f)^{k_cert−1}`。树状证据图（`r=0`）无环可通过，故伪认证率为 1（任何单边都被拒绝）。系：**R69 的「k 个正交源」正是 `k_cert` 个独立环的特例**；证据独立性不是心理学假设，而是环空间维数。

**引理 21（删边的风险上界）** 删除边 e 使信息矩阵 `J → J − J_e`。对任意安全关键方向 v，由 Sherman–Morrison 公式，
`v^T(J−J_e)^{−1}v ≤ v^T J^{−1}v + (v^T J^{−1}a_e)^2 / (1 − a_e^T J^{−1}a_e)`，
其中 `a_e` 为 e 的雅可比行。故决策风险增量为 `≤ L_risk·sqrt(Δvar)`。系：贪心删边时可用该上界在线筛选，只有风险增量 ≤ 预算的边才可删——这把「拓扑优化」变成可证明的在线算法，而不是凭经验剪枝。

**引理 22（轻量化的无免费午餐 / 隐藏失效）** 存在这样的图：区分两个安全相关模态的唯一约束是一条桥边 b。对任何 `B < |E_min|`（保留 b 所需的最小边数），删掉 b 后两模态在 `V_c` 方向上的 Fisher 信息为 0，后验在该方向恒平；**无论再增加多少观测，都无法恢复可辨识性**。因此这不是实现 bug，而是预算本身的结构性后果；唯一安全的做法是检测到 `μ<μ_min` 并**拒绝授予 resolution bonus**。系：轻量化必须携带安全系数与可观测性证书，否则「更省」等于「更自信地不可辨识」。

**定理 18（SLIM 严格包含 R69）** 在 A99–A102（证书可靠、边缘保持、回环开关校准、退避链单调）下，SLIM 在任意状态的期望风险 ≤ R69；当无持久节点、无回环、推迟禁用（`U_tmp=U_retro=0`）时，两者**逐指令相同**。R69 是 SLIM 在「零时间视野」边界上的退化；SLIM 仅在通过可观测性与环一致性门时获得跨时间的 resolution bonus。

**定理 19（回溯修正的安全单调性与无突变）** 回环校正只作用于未执行承诺；对受影响承诺 λ 单调不降（定义 319-b），已执行动作不被改写；校正通过同一 `λ_floor` 与认证前缀进入控制律，且在开关后验超过 τ_s 时才触发（滞回），故控制律在修订时刻连续；证书版本化，不静默覆盖。因此回溯修正的**安全侧不弱于不修正**，且审计可追溯；重复修订的总收紧量有界 `ΣΔλ ≤ λ_max − λ_min`。

**定理 20（预算约束下的安全价格）** 若 (i) `μ(S) ≥ μ_min`、(ii) 稀疏化保持当前边缘 `≤ ε_cons`、(iii) `cycle_rank ≥ k_cert`，则带 `J_SLIM` 有效证书的决策风险 ≤ R69 决策风险 `+ L_risk·ε_cons + δ_sparse`，其中 `δ_sparse = L_risk/sqrt(μ_min)` 为可观测性松弛。故轻量化有一个**可量化的安全价格**；预算 B 可行当且仅当该价格 ≤ 风险预算。这把「轻」从风格选择变成可审计的工程折中。

## 6. 本轮最大风险

**一句话**：SLIM-RAS 的全部跨时间收益押在「稀疏地图仍然可观测」这一前提上——**轻量化最危险的失效不是地图太大，而是为了进预算删掉了唯一能区分两种安全解释的那条承力边：系统会更快、更省、更自信，却在一个不可观测方向上悄悄变瞎，并凭 R69 的 resolution bonus 把这种盲目转化为更松的 λ；如果那条被删的承力方向从未被写进 V_c（未知未知），连可观测性证书都会盖章放行——减重让失效从「吵闹的慢」变成「安静的错」。**

**次级风险与缓解**：
1. **伪回环/感知别名**（一次假闭环拉坏整图）→ 开关约束 + 环一致性（定义 313–314）+ 引理 20；
2. **回溯修正破坏控制连续性** → 承诺前沿 + λ 单调收紧 + 滞回触发（定义 319、定理 19）；
3. **稀疏化引入不可辨识** → 可观测性证书 + 安全系数 + 引理 22 + E305 失效注入；
4. **事件触发饥饿**（回环永不检测）→ 最小触发频率下界 + 陈旧度上界 + E308；
5. **预算被地图维护击穿** → 增量更新 + 周期稀疏化 + 摊销 P99 预算（第 4 节）。

**定义 310（总览与四不变式）** SLIM-RAS = (SEM, LCD, MUD, CSP, ASV, SRS, RCR, RAS-WM†)；零学习写操作继承；地图预算硬约束（B_mem / B_ms / 事件触发回环）；证书纪律（μ ≥ μ_min ∧ cycle_rank ≥ k_cert ∧ p(s=1) > τ_s 才授予 bonus）；回溯单调性（只收紧、版本化、不改写已执行动作）。

**定义 311–312（因子图与时序分解）** 后验 `p(X_t|data) ∝ ∏f_motion·f_obs·f_int·f_loop`；R69 是无持久 ℓ、无回环、单节点的退化图。按链式法则分解 `U_loc = H(M_t|b)−E H(M_t|b,Y_now)`、`U_tmp = E H(M_t|b,Y_now)−E H(M_t|b,Y_now,Y_fut)`、`U_retro = I(M_past;Y_loop|b,Y_now,Y_fut)`，分别触发问 / 推迟重访 / 回溯修正。

**定义 313–314（回环与环一致性）** 回环候选含数据关联 c（感知别名即 c 错）；开关 s 后验 `> τ_s` 且关联置信 `> τ_c` 才接受。证据边可认证 ⇔ 加入后 `r(G_e) ≥ k_cert` 且落在至少 k_cert 个通过 χ² 的独立基本环中；树上单边（r=0）在结构上不可认证——R69「k 个正交源」是环空间特例。

**定义 315–316（可观测性与认证稀疏化）** 在安全关键方向集 V_c 上定义 `μ(S)=min v^T J_S v`；选活动边集 S 最小化 `E[risk]+λ_size|S|` s.t. `|S|≤B_mem`、`μ(S)≥μ_min`、每个安全关键变量至少两条独立约束。贪心按「安全加权信息贡献」删边，节点仅在可边缘化且边缘漂移 ≤ ε_cons 时合并/剪除（信息拓扑优化）。

**定义 317–318（ASV 与 SRS）** 增广动作集含 `gaze/probe/ask/revisit/verify_loop/defer`；`VoI_SLIM` 同时计入当前决策、地图安全方向、未来定位的熵降，减去交互/维护/漂移成本。推迟需满足 `R_stale(j)+drift_pred ≤ ε_stale` 且 `a_j ≤ a_max`，并用滞回避免振荡。

**定义 319–320（回溯修正与轻量化失效）** 回环翻案时：已执行动作不可改写；未完成承诺 `λ←max(λ, λ_floor(U_corrected))` 且撤销剩余时域 bonus；不可逆承诺必须 verify_loop 或退回 R68；受影响证书标记暂定无效。轻量化四类新失效：F1 不可辨识、F2 伪回环盲、F3 别名放大、F4 事件饥饿。

**定义 321–324（证书/威胁/退避/边缘保持）** J_SLIM 并入稀疏证书与回溯计数；ℰ_SLIM 覆盖伪回环、地图投毒、关键边删除、事件饥饿；证书失效→R69→R68→纯保守，λ 单调不降；稀疏化/边缘化前后当前模态边缘变化 ≤ ε_cons，否则拒绝该次稀疏化。

## 3. 关键算法伪代码

```python
# IP-264 SEM：稀疏 epistemic 地图（增量、预算内、当前边缘保持）
class SparseEpistemicMap:
    def update(self, o, a, answer=None):
        add_pose_and_factors(self.g, o, a)              # 复用 R69 trunk / FMA 似然
        if answer is not None: add_interaction_factor(self.g, answer)
        if self.trigger_loop(o):                         # 事件触发，非每帧
            for z in self.detect_loops(o): add_switchable_loop(self.g, z)
        marginalize_preserving(self.g, self.eps_cons)    # 旧节点边缘化 + 不变式
        return self.g

# IP-265 LCD：回环认证（环秩是证据独立性的度量）
def certify_loop(g, e, k_cert, tau_s, tau_c):
    if g.p_switch(e) <= tau_s or g.assoc_conf(e) <= tau_c: return False
    g2 = add_edge(g, e)
    if cycle_rank(g2) < k_cert: return False              # 树上单边无权认证
    cycles = independent_fundamental_cycles(g2, e)
    return len(cycles) >= k_cert and all(chi2_test(c) for c in cycles[:k_cert])

# IP-266 MUD：时序分解
def decompose_temporal(g, acts):
    U_loc = entropy(marginal(g,'M')) - min(expected_post_entropy(g,a) for a in acts.now)
    U_tmp = expected_post_entropy(g,acts.now) - expected_post_entropy(g,acts.future)
    return U_loc, U_tmp, mutual_info(g, past_vars, loop_corrections)

# IP-267 CSP：认证稀疏化（安全加权信息拓扑优化）
def certified_sparsify(g, B_mem, mu_min):
    S = set(g.edges)
    while len(S) > B_mem:
        e = min(S, key=lambda e: safety_weighted_info(g, e))
        if not redundant(g, e) or observability(g, S-{e}) < mu_min: break
        if marginal_shift(g, S-{e}, 'M') > g.eps_cons: continue
        S.remove(e)
    return S, observability(g, S), cycle_rank(g, S)

# IP-268 ASV：主动 SLAM VoI（含 revisit / defer）
def choose_action(g, V_c, budget):
    best = None
    for a in info_candidates(g):
        if not budget.allow(a) or not c_ras_wm.certify_info(a): continue
        voi = (delta_H_now(g,a) + k1*delta_H_map(g,a,V_c) + k2*delta_H_future(g,a)
               - cost(a) - maint_cost(a) - drift_cost(a))
        if best is None or voi > best.voi: best = (a, voi)
    if best and best.voi > 0: return best[0]
    return 'defer' if option_value(g,'defer') > hysteresis else None

# IP-270 RCR：回溯修正（只收紧、只改未来）
def retroactive_revise(g, loop, commits):
    if not certify_loop(g, loop, k_cert, tau_s, tau_c): return g
    old = g.copy(); apply_loop(g, loop)
    for c in affected(commits, old, g):
        if c.executed: log_revision(c); continue          # 已执行不可改写
        c.lam = max(c.lam, lam_floor(uncertainty(g, c))); c.bonus_revoked = True
        if c.irreversible: c.require(verify_loop_or_R68)
    g.version += 1; g.cert_window.mark_provisional(); return g

# IP-274 主闭环（继承 R69，插入地图层）
def SLIM_RAS_round(M, obs):
    g = M.sem.update(obs, M.last_action, M.last_answer)
    U_loc, U_tmp, U_retro = M.mud.decompose_temporal(g, M.actions)
    loop_ok = M.lcd.certify_pending(g)
    map_valid = loop_ok and M.sem.observability(g) >= MU_MIN
    act = (M.asv.choose_action(g, M.sem.V_c, M.budget)
           if map_valid and max(U_loc,U_tmp,U_retro) > TAU else None)
    if act in ('revisit','verify_loop'): M.srs.schedule(g, act)
    elif act not in (None,'defer'):
        M.sem.update(obs, M.last_action, M.cia.execute(act))
    if M.lcd.has_certified_loop(g):
        g = M.rcr.retroactive_revise(g, M.lcd.best_loop(g), M.commitments)
    U_floor = U_loc + (U_tmp if not M.srs.is_fresh(g) else 0.0)
    if not map_valid or g.cert_window.provisional: U_floor += U_tmp + U_retro
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if not map_valid: lam = max(lam, LAM_R69); k = min(k, M.pi_sigma.k_cap())
    mode = select_mode(g, lam)
    M.vqa_s.submit_async(g, M.sem.sparse_cert(), U_loc, U_tmp, U_retro)
    return k, lam, mode, (U_loc, U_tmp, U_retro)
```

## 4. 推导

**引理 19（推迟阈值最优性）** `G_now = VoI(g_now)−c(g_now)`，`G_fut(τ)=e^{−ρτ}(VoI(g_fut)−c_fut)−R_stale(τ)`。若 `R_stale` 单调增、`e^{−ρτ}` 单调减，则 `G_fut−G_now` 关于 τ 单调减，存在唯一 τ*：τ<τ* 立即问最优，τ>τ* 推迟/重访最优。系：R69 的「当轮必问」只在 τ*=0 边界成立。

**引理 20（环一致性抑制伪回环）** 每个独立基本环伪接受概率 p_f 且条件独立时，伪认证率 ≤ p_f^{k_cert}；相关误差 ρ 下 ≤ p_f·(ρ+(1−ρ)p_f)^{k_cert−1}。树状证据图 r=0，无环可通过，伪认证率为 1（拒绝任何单边）。系：R69 的「k 个正交源」正是 k_cert 个独立环的特例；证据独立性 = 环空间维数。

**引理 21（删边风险上界）** 删边使 `J→J−J_e`，由 Sherman–Morrison，`v^T(J−J_e)^{−1}v ≤ v^T J^{−1}v + (v^T J^{−1}a_e)^2/(1−a_e^T J^{−1}a_e)`；故风险增量 ≤ `L_risk·sqrt(Δvar)`。系：贪心删边可在线计算该上界，只删风险增量在预算内的边——拓扑优化因此可证明而非经验。

**引理 22（轻量化隐藏失效）** 存在这样的图：区分两个安全相关模态的唯一约束是桥边 b。对任何 `B<|E_min|`，删 b 后两模态在 V_c 方向的 Fisher 信息为 0，后验恒平，**增加多少观测都无法恢复可辨识性**。系：这不是实现 bug，而是预算的结构性后果；唯一安全做法是检测 μ<μ_min 并拒绝 bonus。

**定理 18（SLIM 严格包含 R69）** 在 A99–A102 下，SLIM 期望风险 ≤ R69；当无持久节点、无回环、推迟禁用时两者逐指令相同。R69 是 SLIM 在「零时间视野」边界的退化；SLIM 仅通过可观测性与环一致性门获得跨时间 resolution bonus。

**定理 19（回溯修正安全单调、无突变）** 校正只作用于未执行承诺；λ 单调不降；已执行动作不被改写；校正经同一 λ_floor 与认证前缀进入控制律，且开关后验超阈值才触发（滞回），故控制律连续；证书版本化不静默覆盖。安全侧不弱于不修正，重复修订总收紧量有界。

**定理 20（预算约束下的安全价格）** 若 μ(S)≥μ_min、边缘保持 ≤ε_cons、cycle_rank≥k_cert，则带 J_SLIM 证书的决策风险 ≤ R69 风险 `+ L_risk·ε_cons + δ_sparse`，`δ_sparse=L_risk/sqrt(μ_min)`。故轻量化有可量化安全价格；预算 B 可行 ⇔ 该价格 ≤ 风险预算。

## 7. 本轮最大风险

**一句话**：SLIM-RAS 的全部跨时间收益押在「稀疏地图仍然可观测」这一前提上——**轻量化最危险的失效不是地图太大，而是为了进预算删掉了唯一能区分两种安全解释的那条承力边：系统会更快、更省、更自信，却在一个不可观测方向上悄悄变瞎，并凭 R69 的 resolution bonus 把这种盲目转化为更松的 λ；如果那条被删的承力方向从未被写进 V_c（未知未知），连可观测性证书都会盖章放行——减重让失效从「吵闹的慢」变成「安静的错」。**

**次级风险与缓解**：伪回环/感知别名（开关约束 + 环一致性 + 引理 20）；回溯破坏连续性（承诺前沿 + λ 单调收紧 + 滞回 + 定理 19）；稀疏化不可辨识（μ 证书 + 安全系数 + 引理 22 + E305）；事件饥饿（最小触发频率 + 陈旧度上界 + E308）；预算被维护击穿（增量更新 + 周期稀疏化 + 摊销预算）。
