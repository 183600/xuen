### 0.2 本轮增量核实（2026-11-17）

1. **G1 的单臂自由度不是固定的 6/7**：官方 G1 / G1 EDU 基础配置为单臂 **5 DoF**（肩、上臂、肘），G1 EDU 可选 **+2 腕部 DoF** 形成 7 DoF；全身 23–43 DoF。  
   ⇒ 提交前必须从 `metadata` / 数据 action 维度读出实际臂维度；**5 DoF 在数学上无法独立控制 6 维位姿**，这会直接决定旋转类任务（Unlock / Open Pill Bottle）的上限。
2. **Dex1 夹爪内部并不"瞎"**：官方 Dex1-1 规格给出 90 mm 行程、0.1 mm 指尖分辨率、5–120 N 夹持力、内部 1000 Hz 通信与角度 / 速度 / 力矩反馈。但提交接口只暴露 **1 维开合标量**，内部力矩不可用。  
   ⇒ "关节驱动"不是单纯的动作空间选择，而是我们在接口下**唯一可用的力/接触通道**：低层关节控制器把指令跟踪成实际位置，指令与实测之间的差就是负载的痕迹。
3. **腕部相机视场很宽**：Dex1-1 Advanced 的相机为 1080P、H:118° / V:87°；官方数据下采样到 480×640。  
   ⇒ 近距离相对位姿伺服在像素分辨率上"够用"，但绝对单目 6D 位姿仍受尺度与遮挡限制；应做**相对**而非绝对位姿。

### 0.3 与候选 A 的关系：从"把模型做大"转向"把回路做紧"

候选 A 的核心判断——抓握是隐变量、最后对齐/插入是断点、通用能力是技能向量——本候选全部接受。但 A 的主要兑现手段是 MoE 与在线适配，代价是**合规不确定 + 代理评测难以快速验证**。本候选换一条更低风险、更可离线验证的路：

- **不新增策略模型容量**，而是在 VLA 输出与机器人关节之间补两个缺失的反馈回路：
  - **力回路**：`u − q`（指令关节目标 − 实测关节位置）→ 接触 / 卡滞 / 滑移；
  - **位姿回路**：任务相关相对位姿 → 笛卡尔修正 → 微分 IK → 关节目标。
- VLA 负责"提出动作"，伺服负责"完成最后一英寸"；**单模型、单服务、确定性控制器**，避免多专家判违规。
- 抓握确认被吸收为"物体-夹爪相对位姿漂移 = 滑移"，比只看 1 维开合标量更直接。

一句话：**A 试图让模型更聪明；B 试图让回路更紧。**

## 1. 直觉与动机（先直觉，再定义）

### 1.1 灵感 1 ·「关节驱动」：最后一英寸是驱动层问题，不是语言层问题

**直觉**：VLA 输出的不是"把插头送到孔里"的笛卡尔指令，而是一串**关节目标**。关节目标要经过低层 PD / 位置控制器、减速器、摩擦、间隙、限幅和延迟，才变成真实运动。这个过程有三个直接后果：

1. **残差是力传感器**：低层控制器为了让关节跟上目标，会持续输出力矩。准静态下 `K_p(u−q) ≈ τ_ext + τ_g`，所以指令与实测的差 `e = u−q` 里藏着外部接触和重力负载。接口没有力/触觉，但**关节驱动本身就是力通道**。
2. **笛卡尔精度依赖构型**：`δx = J(q) δq`，方向性力权威约为 `1/√(ξᵀ(JJᵀ)⁻¹ξ)`。手臂伸得越直、越接近奇异，某些方向的力权威越差；5 DoF 臂的 `rank(J) ≤ 5`，在 6 维任务里至少有一个方向**根本没有独立权威**。这解释了为什么"看起来对准了，却推不动 / 一碰就偏"。
3. **柔顺不能靠调增益，只能靠整形目标**：低层增益不在我们手里。我们无法把机器人变成阻抗控制器，但可以把目标轨迹做成**限速斜坡、接触回退、微搜索**——这叫目标级导纳（target-level admittance）。

**第一性原理**：插入/旋转任务需要的是**力权威 + 闭环带宽 + 柔顺性**，三者在关节驱动层。把它们当成"模型语义不够强"去堆数据，是把控制问题误诊成感知问题。

### 1.2 灵感 2 ·「位姿估计」：不要估世界位姿，估"还差多少"

**直觉**：评分定义在物体与目标（孔 / 槽 / 瓶口 / 电池仓）的**相对位姿**上，但策略从未收到物体 6D 位姿。直接做绝对 6D 位姿估计会遇到三个硬墙：没有 CAD、没有深度、最后插入时目标恰好被物体/夹爪遮挡。更现实的做法是只估计**任务相关位姿（Task-Relevant Pose, TRP）**：

- 插入类：横向偏移 2 维 + 轴向距离 1 维 + 绕插入轴的偏航 1 维（有旋转对称时对偏航做商）；
- 放置类：支撑面法向 + 横向偏移 + 偏航；
- 旋转类：轴线 + 螺纹/键槽相位。

**关键洞察**：机器人自己的运动就是"位姿尺子"。相邻两帧之间，相机的刚体运动可由正运动学（FK）从关节角精确算出；即使手眼外参未知，已知运动提供的**平移范数**仍能保持度量尺度。于是可以：

- 用 FK 提供的已知相机运动做多视图三角化，恢复目标点的**度量**位置；
- 只用腕部 / 头部图像做相对量测，不需要物体的绝对世界位姿；
- 用在线手眼自标定吸收 N 台机器人相机安装差异；
- 用重投影残差检测"物体被人为移动"——这正是 5 类泛化场景里最危险的一类。

**第一性原理**：位姿估计的目标不是"知道物体在哪"，而是"知道下一步往哪移动几毫米、几度"。把问题降维到任务相关子空间，才可能在无 CAD、无深度的条件下达到亚毫米级。

### 1.3 合成：给 VLA 补上"力"与"位姿"两个缺失的反馈回路

```
语言/图像 ──► VLA（低频、块状）──► 关节目标提案
                                   │
         ┌─────────────────────────┴─────────────────────────┐
         │  事件触发：相位=align/insert 或 残差异常 或 位姿误差小 │
         ▼                                                   ▼
  位姿回路：TRP 估计 ──► 相对误差 ──► 微分 IK ──► 关节修正
  力回路：u−q 残差 ──► 接触/卡滞/滑移 ──► 限速/回退/微搜索
         │                                                   │
         └─────────────────► 伺服执行（短 chunk）◄───────────┘
                                   │
                              审计与降级
```

- **接近 / 搬运**：VLA 长 chunk，低延迟，省调用；
- **对齐 / 插入 / 旋转**：事件触发切到短 chunk 伺服，力回路与位姿回路同时工作；
- **任何一路不可信**：按预设退化链回退，绝不"带病闭环"。

口号：**不要把模型做大，把回路做紧。**

## 2. 瓶颈在哪里（把"最后一英寸"量化）

### 2.1 盲走时间：一个 chunk 足以把可救的失败变成卡死

设控制频率 30 Hz、chunk 长度 `T_a`、接近速度 `v`，则一个 chunk 内的**盲走距离**为 `v·T_a/30`：

| `T_a` | 盲走时间 | v=20 mm/s 时盲走 | v=10 mm/s 时盲走 |
|---:|---:|---:|---:|
| 8 | 267 ms | 5.3 mm | 2.7 mm |
| 4 | 133 ms | 2.7 mm | 1.3 mm |
| 2 | 67 ms | 1.3 mm | 0.7 mm |
| 1 | 33 ms | 0.7 mm | 0.3 mm |

典型插入间隙（以太网口、电池仓、瓶盖螺纹）量级为 **0.5–2 mm**。也就是说：**8 步 chunk 在接触前完全可以盲走完整个间隙并把插头压弯**，而策略要到下一个 chunk 才看见。最后插入相位必须把 chunk 降到 1–2 步，或至少把 chunk 内的目标轨迹做成"限速 + 低刚度"。

### 2.2 精度—成功率：亚毫米不是苛求，是数学

若横向误差 `e ~ N(0, σ²)`、单边间隙 `c/2`，则 `P(success) = erf(c / (2√2 σ))`。取 `c = 1 mm`：

| σ（横向误差标准差） | 成功率 |
|---:|---:|
| 1.0 mm | 38.3% |
| 0.5 mm | 68.3% |
| 0.25 mm | 95.4% |
| 0.2 mm | 98.8% |

结论：**要把插入类任务从 20% 拉到 50% 以上，需要亚毫米级相对精度**。绝对单目 6D 位姿在 20 cm 处通常是数毫米级（待实测），不可能直接达标；但相对位姿伺服只需把误差"归零"，其残余由像素量化、特征噪声和伺服死区决定，可以做到亚毫米。**这就是为什么本候选坚持相对伺服而不是绝对位姿。**

### 2.3 力权威：5 DoF 臂的旋转任务是"物理天花板"

方向性力权威 `m_ξ = 1 / √(ξᵀ(JJᵀ)⁻¹ξ)`。若 `J` 的奇异值为 `σ_max … σ_min`，最弱方向的权威与 `σ_min` 同量级；条件数 `κ = σ_max/σ_min` 可以直接放大 10 倍以上。更严重的是：

- 单臂 5 DoF ⇒ `rank(J) ≤ 5` ⇒ 6 维任务中至少一个方向**零权威**；
- Unlock / Open Pill Bottle 需要绕工具轴的旋转，如果该自由度不在 5 DoF 的臂空间里，只能靠腕部额外 2 DoF、腰部 pivot 或全身姿态补；
- 这不是"模型没见过"能解释的，是**运动学秩**问题。

⇒ 本轮第一个动作不是训练，而是**核实动作维度与自由度配置**；第二个动作是用数据估计经验 Jacobian 并画出"任务方向的权威热图"。

### 2.4 残差可观测性：接触在原理上看得见

准静态 PD 平衡：`K_p(u − q) + τ_g(q) + τ_ext = 0` ⇒ `τ_ext = K_p(q − u) − τ_g(q)`。重力项可由"无接触相位"的数据学出来；于是接触引起的力矩变化可从残差中识别。动态时加入 `M(q)q̈ + C(q,q̇)q̇`，仍可用学习/辨识的观测器白化。**我们不需要精确力值，只需要接触 onset、方向与卡滞/滑移的变化点**——这比绝对力估计容易得多。

## 3. 研究问题（本轮版）

- **Q1（残差可识别性）**：在低层增益、重力、摩擦未知，且评测端可能对动作插值/限幅的前提下，`u−q` 的残差能否被白化成"接触 onset / 卡滞 / 滑移"的可信信号？检测延迟能否压到 ≤2 步？
- **Q2（相对位姿可观测性）**：仅用 4 路 RGB + FK 已知运动，能否在没有 CAD、没有物体位姿标签的条件下，把任务相关相对位姿估到 ≤2 mm / ≤2°，并给出可校准的不确定性？目标被遮挡或被人为移动时能否检测并回退？
- **Q3（事件触发伺服的收益/代价）**：把 chunk 从 8 降到 1–2 只在接触相位发生，能否在不显著增加延迟与调用次数的前提下，提升插入类成功率？伺服稳定性对一步延迟的容忍度是多少？
- **Q4（姿态权威）**：在 7 DoF（含腕）配置下，用零空间姿态偏置最大化插入方向力权威，能否带来可测的精度/成功率收益？在 5 DoF 配置下，是否必须借助腰部 pivot / 基座位置，收益与代价如何？
- **Q5（合规边界）**：辅助的残差观测器、TRP 估计器、经验 Jacobian 属于"感知/状态估计"还是"第二个策略"？最严格的"纯控制器 + 解析方法"形态还剩多少收益？
- **Q6（泛化场景）**：在背景 / 光照 / 干扰物 / 未见物体 / 人为干扰五类偏移下，双回路的失效模式是什么？哪一路先崩？

## 4. 设计原则

- **P1 机制优先**：所有创新必须能写成"缩短盲走时间 / 提高相对精度 / 提高方向力权威 / 降低接触冲量"的因果链。
- **P2 补回路而非堆参数**：优先用机器人已有的本体信号（关节、EE、FK）构造反馈；不把"再训一个大模型"作为第一手段。
- **P3 只估被评分的自由度**：位姿估计降维到任务相关子空间；对称性做商；不追求无用的绝对 6D。
- **P4 事件触发 + 不确定性门控 + 默认回退**：只在"位姿可信 + 相位需要 + 残差支持"时介入；其余时间保持 VLA 原行为。
- **P5 合规优先**：不按任务名硬编码分支；不读取评测侧私有信息；辅助模块尽量用解析式，学习模块打包进同一 checkpoint / 同一服务。
- **P6 单服务、多端口隔离**：共享权重，per-port 独立会话与位姿缓存；`reset()` 不串扰。
- **P7 先探测再使用**：chunk 执行语义、插值、限幅、观测频率未实测前，不把任何"利用未声明行为"的优化放进主线。

## 5. 最小可提交闭环（MVP）与退化链

**MVP = 接口语义探测（E701） + 经验 Jacobian（E702） + 残差接触检测（E703） + TRP 相对位姿（E705） + 事件触发伺服/交接（E707） + 目标级柔顺（E708） + 原有 VLA 基线。**

**严格退化链（任一环节不可信 ⇒ 行为回退，而非漂移）**：

- **Level-0**：TRP 不确定性高或被遮挡 ⇒ 关闭位姿回路，只保留残差 + 限速柔顺；
- **Level-1**：残差不可归因（接触检测置信度低）⇒ 关闭力回路，退回短 chunk + 固定限速；
- **Level-2**：经验 Jacobian 与实测不符 ⇒ 退化到小增益对角 IK / 或直接 `control_space=ee` 让评测端 IK；
- **Level-3**：伺服出现振荡 / 超时 ⇒ 固定 chunk 的 VLA 原策略；
- **Level-4**：整条新链路失效 ⇒ 退回**纯基线提交**（永远保留一份能跑通、可信度合规的安全网）。

安全约束：每步关节修正限幅、关节限位、速度/加速度限幅、伺服最长持续时间、交接滞回（避免 VLA/伺服来回切换）、最大回退次数。

3. **ProprioAnchored TRP**：用机器人自身已知运动做度量锚点，在无 CAD、无物体位姿标签下估计任务相关相对位姿；给出对称性商、不确定性校准与人为移动检测。
4. **事件触发伺服 + 目标级柔顺**：给出一步延迟下的稳定性条件、接触冲量与检测延迟的平方关系，并把它们变成可执行的限速/回退/微搜索策略。
5. **DataJacobian**：从 32 个官方数据集拟合经验 Jacobian 场，用于微分 IK、方向力权威评估与奇异构型预警；不依赖精确 URDF / 手眼外参。
6. **公共基准**：把"残差接触 / TRP 位姿 / 经验 Jacobian / 方向权威"做成可复用的离线基准，后续每轮不必等真机时段。
7. **工程与合规**：joint vs ee 的 A/B、N 端口并发隔离、延迟/jerk/干预率审计；给出"纯解析控制器"合规兜底形态。

## 7. 本轮最大风险

**一句话**：本轮把赌注压在"评测端关节位置控制器近似 PD、其指令—实测残差可观测且可归因于接触"这一前提上，同时又要靠视觉在**插入瞬间最容易被遮挡**的地方估出亚毫米相对位姿；一旦残差被插值/重规划/未知增益污染，或 TRP 在接触点附近失效，双回路就同时退化为"带错误反馈的开环微调"，而这类失败在真机上往往比不做更糟。

## 8. 下一轮迭代计划（深化与修剪）

- **先做零真机、纯离线可完成的三件事**：①从官方数据算 `action − state` 残差，验证接触/相位可分性；②拟合经验 Jacobian 并画方向权威；③用 FK 已知运动做多视图相对位姿，测精度—距离曲线。
- **再做接口探测**：用官方 `run_server.py` / `run_client.py` 复刻评测闭环，测 chunk 语义、插值、限幅、观测频率、延迟分布；这是所有闭环优化的前提。
- **深化**：把残差观测器从"阈值"升级为"带迟滞的变点检测 + 方向投影"；把 TRP 从"单帧回归"升级为"多视图 + 时序滤波 + 不确定性传播"。
- **修剪预案**：
  - 若 TRP 在 5–20 cm 的横向误差 >3 mm ⇒ **砍掉位姿伺服**，只保留残差 + 限速柔顺；
  - 若残差接触检测 AUROC <0.75 ⇒ **砍掉力回路**，只保留短 chunk + 目标整形；
  - 若臂为 5 DoF 且旋转任务无法借腰部/腕部补足 ⇒ **把旋转类任务从主攻改为"保命"**，资源转向插入/放置；
  - 若"辅助感知模块"被判不合规 ⇒ 切换到纯解析兜底（URDF Jacobian + ORB 三角化 + PD 残差），牺牲部分精度换合规。
- **保留项**：接口探测、经验 Jacobian、短 chunk + 限速柔顺三项在任何情况下不砍（它们不依赖新数据，也不需要真机即可验证方向）。

## 2. 创新点详述

### D-01 · DriveResidual：把关节驱动变成力/接触传感器（P0）

- **动机**：接口没有力/触觉，Dex1 内部力矩不可读；但每个控制步我们都能拿到自己的指令 `u` 和观测到的实测关节 `q`。低层控制器为了跟踪目标必须出力，`e = u − q` 就是负载与重力的痕迹。插入失败的两个关键事件——**接触发生**与**卡滞/滑移**——都会改变残差的幅值、方向与频谱。
- **与现有方案的差异**：常见做法是把关节位置当"状态"喂给策略，或假设低层完美跟踪；本方案把**跟踪误差本身**当成一等观测，构造一个与策略解耦的接触观测器。它不需要额外传感器、不需要改接口、不需要真机就能离线验证（官方数据同时有 action 与 state）。
- **技术可行性**：高。官方 32 个数据集含 `action.*_arm`（目标）与 `observation.state.*_arm`（实测），可逐帧算残差；相位标签可用"接近 / 接触 / 插入"的规则 + 变点检测伪标；模型只需 1D/小 MLP/GRU。
- **所需资源**：数据 = 官方 32 数据集；算力 = 单卡数小时；接口 = 无新增字段（纯内部）。
- **落地步骤**：
  1. 对齐时间戳：确认 `action_t` 与 `state_{t+1}` 的执行关系；用互相关估计低层延迟 `ℓ`，得到 `e_t = u_{t−ℓ} − q_t`。
  2. 在"无接触相位"（接近段）拟合基线 `r0(q, q̇, u)`（线性回归或小 MLP），残差白化为 `z_t = e_t − r0`。
  3. 方向投影：用 D-02 的 `J(q)` 把 `z_t` 映到任务系，得到沿插入轴的 `z_ax` 与横向 `z_lat`；用 CUSUM / GRU 检测 onset。
  4. 滑移检测：抓握后物体-夹爪相对位姿应恒定；若 TRP 漂移 + 残差变化同时发生 ⇒ 滑移（D-07）。
  5. 输出三值信号 `{free, contact, jam}` + 置信度，供 D-04/D-05 使用。
- **风险**：①低层控制器可能对动作插值/限幅/重规划，残差不再等于力矩 ⇒ 必须先做 E701 语义探测；②重力/摩擦建模误差 ⇒ 用相位内自校准与变化点检测，不追求绝对力；③数据集与真机控制器不同 ⇒ 只用数据学"形状"，阈值在真机首轮重标定。

### D-02 · DataJacobian：从 32k episodes 学一个可用的局部运动学（P0）

- **动机**：要做微分 IK、方向权威与奇异预警，需要 `J(q)`。解析 URDF 可能拿得到，但工具坐标系、相机外参、关节零位与数据/评测端未必完全一致；从数据直接拟合 `Δx≈J(q)Δq` 可以吸收这些差异。
- **与现有方案的差异**：多数 VLA 把动作空间当黑箱；本方案显式恢复"关节→任务空间"的局部线性映射，并把它用于**控制**（IK / 姿态 / 限幅），而不只是可视化。
- **技术可行性**：高。数据含关节与 EE 位姿；对相邻帧做差分，用 k-NN 局部回归或小 MLP 拟合 `J(q)`；用 URDF 作为先验/正则，用数据残差修正。
- **所需资源**：数据 = 官方 32 数据集；算力 = 单卡数小时；接口 = 无。
- **落地步骤**：
  1. 清洗：只保留 `‖Δq‖` 足够大且无夹爪开合的窗口；对齐 EE 位姿坐标系。
  2. 拟合：`J(q)` 用局部加权回归 / 神经场；损失含 `‖Δx − JΔq‖` 与 URDF 先验 `‖J − J_urdf‖`。
  3. 验证：留出 episode 预测 `Δx`；与有限差分 URDF 比方向余弦；报告按关节构型的误差。
  4. 生产：在线用 `J(q)` 做阻尼最小二乘 IK、方向权威 `m_ξ`、奇异值/条件数预警；把 `m_ξ` 低的任务帧标出来。
- **风险**：①EE 位姿含基座漂移 ⇒ 用相对差分与 IMU/关节一致性检查；②数据动作多为人类遥操，激励不足 ⇒ 对低激励方向用 URDF 先验并标注不确定性；③5 DoF 时 `J` 秩亏 ⇒ 明确只在可达子空间求解，不伪造 6D。

### D-03 · TRP-Pose：无 CAD、无物体位姿标签的任务相关位姿（P0）

- **动机**：最后插入需要亚毫米相对位姿，但接口没有物体 6D 位姿、没有 CAD、最后时刻目标还被物体/夹爪遮挡。绝对 6D 位姿既难又不必要；真正被评分的是**任务相关自由度**。
- **与现有方案的差异**：不做"万物 6D 位姿"，而是：
  - **任务相关位姿（TRP）**：横向偏移 `δ∈R²`、轴向距离 `d`、绕轴偏航 `ψ`（有对称性时取商）；
  - **本体锚定**：用 FK 算出的相机刚体运动作为度量尺，做多视图三角化 / 相对位姿；
  - **在线手眼自标定**：吸收 N 台机器人相机安装差异；
  - **不确定性 + 遮挡/移动检测**：不可信就回退，不硬闭环。
- **技术可行性**：中–高。头部 stereo 提供全局度量深度，腕部相机提供近距离细节；静态目标（插入前的孔/瓶口）可用已知运动三角化；被抓物体与夹爪刚性连接，相对位姿恒定，可用于滑移检测。无需物体 CAD。
- **所需资源**：数据 = 官方数据 + 少量自采标定序列；算力 = 轻量特征/位姿头（单卡）；接口 = 只用已有 4 路图像。
- **落地步骤**：
  1. 手眼自标定：用 FK 已知运动 + 静态场景多视图，最小化重投影误差求 `X`（相机→EE）；每端口首 episode 在线精化。
  2. TRP 参数化：由目标几何（孔/槽/瓶口）定义任务系；对旋转对称物体做 `ψ mod 2π/k` 的商。
  3. 多视图融合：头部 stereo 给全局粗位姿，腕部给局部精位姿；按协方差加权；用时序滤波（常速度模型）平滑。
  4. 不确定性：异方差头 / 小 ensemble；在留出集做可靠性图与 ECE；门控阈值 `σ_max`。
  5. 失效检测：重投影残差突增 / 位姿跳变 ⇒ 判定"目标被人为移动或遮挡"，重置 TRP 或回退 VLA。
- **风险**：①插入瞬间目标被物体遮挡 ⇒ 用头部视角 + 历史位姿外推，并在遮挡期降低增益；②纹理缺失 ⇒ 用边缘/线段/深度 + 学习特征融合；③手眼外参随端口变化 ⇒ 在线自标定；④人为移动目标 ⇒ 必须有重定位与回退。

### D-04 · ServoHandover：事件触发、短 chunk、带滞回的伺服交接（P0）

- **动机**：VLA 长 chunk 在接触相位是"盲走"；但全程短 chunk 会增加延迟与调用次数。正确做法是**只在需要精度的相位切换**。
- **与现有方案的差异**：不是"换一个更强的策略"，而是给同一策略加一个**执行模式**：`APPROACH`（VLA 长 chunk）↔ `SERVO`（短 chunk 闭环）。
- **触发谓词**（全部基于通用信号，不按任务名）：
  - 相位分类器（图像 + 残差 + 夹爪）判为 `align / insert / release`；
  - 或残差出现接触/卡滞特征；
  - 或 TRP 误差进入"可伺服窗口"且不确定性低于阈值；
  - 满足滞回与最小驻留时间才切换，避免抖动。
- **伺服律**：任务系误差 `e_ξ = ξ* − ξ̂`，`Δx = λ·e_ξ + Δx_ff`；`Δq = J⁺Δx + N(q)∇m_ξ`；`u = q_meas + clip(Δq, Δq_max)`；输出 1–2 步。用实测 `q` 作基准，避免绝对目标漂移。
- **稳定性**：一步延迟下，比例伺服误差递推 `e_{k+1}=e_k−λe_{k−1}`，特征方程 `z²−z+λ=0`，稳定域 `0<λ<1`；取 `λ≈0.3` 留裕度（90% 收敛约 7 步 ≈ 0.23 s）。多步延迟/滤波会缩小裕度，故设 `λ≤0.3` + 速率限幅 + 低通。
- **退出**：位姿收敛 + 残差释放 + 到达释放相位 ⇒ 交回 VLA；超时 / 振荡 / 置信度掉 ⇒ 回退。交接用滞回，单 episode 最大交接次数受限。
- **风险**：①chunk=1 的延迟/调用开销 ⇒ 先做 E701/E707，必要时用 chunk=2 + 块内限速；②伺服与 VLA 互相打架 ⇒ 明确所有权（SERVO 时完全覆盖 VLA）；③目标位姿错误导致越修越偏 ⇒ 不确定性门控 + 最大修正量 + 回退。

### D-05 · ComplianceShaper：目标级柔顺（P0）

- **动机**：低层增益不可调，但我们可以让**目标**表现得柔顺。硬位置目标在接触瞬间会产生大冲量；限速/回退/微搜索可以把"撞上去"变成"贴上去"。
- **与现有方案的差异**：不是改机器人控制器，而是在动作块内部整形目标轨迹；与 D-01 的接触信号闭环。
- **机制**：
  - **限速斜坡**：接触相位把目标速度限制在 `v_max`；冲量 `J_imp=½kvd²`，减半速度减半冲量，缩短检测延迟 `d` 则平方级下降。
  - **残差回退**：检测到 `contact/jam` ⇒ 目标沿接触法向回退 `δ_back`，再以更小步长重试；最大回退次数受限。
  - **微搜索**：在横向做小范围螺旋/抖动（幅度 ≤ 间隙量级），只在 `contact` 且 `TRP 不确定性低` 时启用；不按任务名分支。
  - **抗积分饱和**：回退时清空/衰减积分项，避免"越顶越用力"。
- **风险**：①过度柔顺导致插不进去 ⇒ 用残差释放作为"已进入"信号，进入后逐步恢复速度；②微搜索扰动其他物体 ⇒ 限制幅度与作用域；③低层控制器自带平滑 ⇒ 先实测，必要时关闭整形。

### D-06 · AuthorityPosture：把姿态当成精度变量（P1）

- **动机**：`m_ξ` 随构型变化；手臂接近伸直时最弱方向权威急剧下降。G1 单臂基础 5 DoF，EDU 可加 2 腕 DoF；7 DoF 时有冗余空间做姿态优化，5 DoF 时只能借腰部 pivot / 基座位置。
- **与现有方案的差异**：VLA 只模仿人类姿态，不显式优化"插入方向的力权威"；本方案在零空间加一个小偏置，把手臂调到更"有力"的构型。
- **方法**：`q* = q_demo + α·N(q)∇_q m_ξ`，`N=I−J⁺J`；约束关节限位、与 demo 姿态距离、速度/加速度平滑；α 小（避免破坏示范）。5 DoF 时 `N` 维度不足，改为优化腰部 pivot / 基座接近方向。
- **风险**：①姿态偏离示范导致视觉分布外 ⇒ 限制偏移量 + 在线成功率监控；②5 DoF 无可优化空间 ⇒ 如实报告，不硬造收益；③`m_ξ` 估计误差 ⇒ 用留出数据校准，且只在显著提升时启用。

### D-07 · SlipPose：用相对位姿漂移做滑移/抓握确认（P1）

- **动机**：候选 A 已指出抓握是隐变量；只看 1 维开合标量无法区分"夹住了"与"夹空了"。抓握后物体与夹爪应刚性连接，**相对位姿漂移**就是滑移/脱落的直接证据。
- **方法**：抓握瞬间锁定物体在夹爪系的位姿 `T_g^o(0)`；之后每帧估计 `T_g^o(t)`；漂移 `‖log(T_g^o(0)⁻¹T_g^o(t))‖` 超阈值 + 残差变化 ⇒ 滑移。响应：减速、回退、重抓或改用非抓取原语（可继承候选 A 的原语库）。
- **风险**：位姿估计噪声会被误判为滑移 ⇒ 用不确定性加权与持续多帧确认；遮挡期不判。

### D-08 · DriveAudit：可审计执行层（P1）

- **动机**：官方明确会采集 per-step 延迟、波动与动作统计规律性评估可信度。DRIVE 引入了伺服切换、限幅、回退，必须能自证"动作良构、延迟稳定、无异常离群"。
- **内容**：延迟 p50/p99、jerk 分布、残差分布、干预率、交接次数、回退次数、每端口会话隔离自检；导出 JSON/CSV 报告。
- **风险**：过度平滑/限幅压低成功率 ⇒ 平滑只作用于残差与速度，不改变均值；阈值由数据分布定。

### D-09 · DualSpaceProbe：joint 与 ee 的 A/B（P2）

- **动机**：`control_space` 二选一。joint 保留姿态/权威/残差解释；ee 让评测端 IK，可能更稳但失去控制权。
- **方法**：同一 checkpoint、同一感知栈，分别打包 joint 与 ee 两个提交配置；在插入类与长程类任务上比较；选优，不做"两套策略"。
- **风险**：ee 模式下评测端 IK 的限幅/奇异处理未知 ⇒ 先探测；不要假设它会做我们想要的阻尼 IK。

### D-10 · ToleranceBench：任务容差与精度需求基准（P1）

- **动机**：不是所有任务都值得上亚毫米伺服。需要知道每个任务的间隙 `c`、所需精度、接触相位时长，才能排序投入。
- **方法**：从物体几何、任务视频、成功/失败轨迹的末端分布估计 `c` 与 `σ`；用 `P=erf(c/(2√2σ))` 反推所需精度；与 teaser 难度排序做 Spearman 对照（仅结构参考）。
- **风险**：容差估计误差大 ⇒ 给出区间而非点值；只用于排序，不用于硬阈值。

## 3. 符号与定义（D1–D12）

| 符号 | 含义 |
|---|---|
| `q_t` | 实测关节位置（来自 `observation.state.*_arm`） |
| `u_t` | 我们下发的关节目标（`action.*_arm`） |
| `e_t` | 关节驱动残差 `u_{t−ℓ} − q_t`（`ℓ` 为低层延迟） |
| `z_t` | 白化残差 `e_t − r0(q,q̇,u)` |
| `J(q)` | 任务空间→关节的局部 Jacobian（经验估计） |
| `m_ξ(q)` | 沿任务方向 `ξ` 的方向性力权威 |
| `ξ` | 任务相关位姿（TRP）参数向量 |
| `ξ̂, Σ_ξ` | TRP 估计与协方差 |
| `H` | 事件触发交接谓词 |
| `λ` | 伺服增益（任务系比例） |
| `v_max, δ_back` | 限速与回退量 |
| `s_t` | 滑移分数 |

**定义 D1（关节驱动残差）** `e_t = u_{t−ℓ} − q_t`，其中 `ℓ` 由动作与状态互相关估计；所有量在同一关节顺序、同一单位下对齐。

**定义 D2（接触分数）** `z_t = e_t − r0(q_t, q̇_t, u_t)`；`ρ_t = z_tᵀ Σ_z⁻¹ z_t`，`Σ_z` 为无接触相位的残差协方差。`ρ_t` 超阈值并持续 `k` 帧 ⇒ `contact`；伴随残差方向与任务轴一致且幅值不降 ⇒ `jam`。

**定义 D3（经验 Jacobian）** `J(q) = argmin_J E_{Δq}[ ‖Δx − JΔq‖² + μ‖J − J_urdf(q)‖² ]`，`Δx` 为 EE 位姿差分；局部加权或神经场实现。

**定义 D4（方向性力权威）** `m_ξ(q) = 1 / √(ξᵀ (J(q)J(q)ᵀ)⁻¹ ξ)`，`ξ` 为 6D 任务方向（单位 twist）；`m_ξ` 越大，沿该方向可施加的力/刚度越大。

**定义 D5（任务相关位姿 TRP）** `ξ = (δ_x, δ_y, d, ψ)`：`(δ_x,δ_y)` 为横向偏移，`d` 为沿插入轴距离，`ψ` 为绕轴偏航；放置类用 `(δ_x,δ_y,h,ψ)`，旋转类用 `(d,ψ)`。

**定义 D6（TRP 估计）** `(ξ̂_t, Σ_ξ,t) = g_pose(I_t^{head}, I_t^{wrist}, T_{ee}(q_t))`，输出高斯近似；`g_pose` 由多视图几何 + 轻量学习精化组成。

**定义 D7（对称性商）** 若目标在绕轴旋转 `2π/k` 下不变，则 `ψ ~ ψ mod 2π/k`；损失与误差都用商空间距离 `d_S(ψ,ψ̂)=min_j |ψ−ψ̂−2πj/k|`。

**定义 D8（本体锚定约束）** 对静态目标点 `P`，两帧相机位姿 `T_c1, T_c2` 满足 `T_c2 T_c1⁻¹ = X (T_{ee2} T_{ee1}⁻¹) X⁻¹`（`X` 为手眼），因此 `‖t_c2−t_c1‖ = ‖t_ee2−t_ee1‖`；用该度量约束三角化与相对位姿求解。

**定义 D9（伺服律）** `Δx_t = λ·(ξ* − ξ̂_t) + Δx_ff`；`Δq_t = J⁺(q_t)Δx_t + α N(q_t)∇m_ξ`；`u_t = q_t + clip(Δq_t, ±Δq_max)`，并施加关节速度/加速度限幅。

**定义 D10（目标级柔顺）** `u_t^shape = u_t + δ_back·n̂·1[ρ_t>τ_c]`（接触回退）；接近段 `‖u̇‖ ≤ v_max`；`jam` 时按 `δ_back` 递减重试，最多 `N_back` 次。

**定义 D11（事件触发交接）** `H_t = 1` 当且仅当 `(phase∈{align,insert,release} ∨ ρ_t>τ_c) ∧ σ_ξ,t≤σ_max ∧ dwell≥T_dwell`；`H` 用滞回与最大切换次数约束。`H=1` 时进入 SERVO，`H=0` 且满足退出条件时回 VLA。

**定义 D12（滑移分数）** `s_t = ‖log(T_g^o(0)⁻¹ T_g^o(t))‖ / σ_pose(t)`；`s_t>τ_s` 持续多帧 ⇒ slip。`T_g^o(t)` 为物体在夹爪系的位姿。

```python
                "observation.images.cam_right_high": [240, 320],
                "observation.images.cam_left_wrist":  [240, 320],
                "observation.images.cam_right_wrist": [240, 320],
            },

            "token": os.environ["UNIBOT_SUBMISSION_TOKEN"],
        }

    def reset(self, port):
        self.sessions.setdefault(port, Session()).reset()

    def get_action(self, obs, port):
        s = self.sessions[port]
        t0 = time.perf_counter()

        # ---------- 感知与状态 ----------
        q = pack_joints(obs, self.dims)
        e = s.residual(q, s.last_cmd)                 # D1
        z = self.res.whiten(q, e, s.last_cmd)         # D2
        rho, contact, jam = self.res.score(z)         # D2
        xi_hat, Sigma = self.pose.update(obs, q)      # D3/D6
        slip = self.slip.update(obs, q, xi_hat, Sigma)  # D12

        # ---------- 选择执行模式 ----------
        H = self.handover(obs, s, rho, contact, Sigma, slip)  # D11
        s.phase = self.phase_of(obs, rho)             # 通用相位，不用任务名
        if H and self.dims.can_control(self.phase):
            cmd_chunk = self.servo_chunk(obs, q, xi_hat, Sigma, rho, jam, slip, s)  # D9/D10
            mode = "SERVO"
        else:
            cmd_chunk = self.vla.act(obs, chunk_len=self.chunk_len(s.phase))        # VLA
            cmd_chunk = self.smooth_and_limit(cmd_chunk, q)                         # 安全
            mode = "VLA"

        # ---------- 审计 + 打包 ----------
        self.audit.log(port, t0, mode, rho, Sigma, slip, len(cmd_chunk))
        s.last_cmd = cmd_chunk[-1]
        s.handover_count += int(H and mode == "SERVO")
        return self.pack(cmd_chunk, obs)

    # ---------- D-04 / D-05 / D-09 ----------
    def servo_chunk(self, obs, q, xi_hat, Sigma, rho, jam, slip, s):
        if not self.gate(Sigma, xi_hat, s.phase):      # 不确定性门控
            return self.vla.act(obs, chunk_len=2)
        dx = self.servo_law(xi_hat, s.xi_star, lam=0.3)          # D9
        if rho > self.tau_contact:                               # D10
            dx = dx + self.backoff_dir(obs, q) * self.delta_back
        dq = self.jac.dls(q, dx) + self.jac.null_authority(q, self.task_axis(obs))
        dq = clip(dq, -self.dq_max, self.dq_max)
        u = q + dq
        # 兼容 5 DoF：只在可达子空间求解；不可达方向交给腰部/基座或退出伺服
        return self.rate_limit(u, q, v_max=self.v_max, steps=1 if jam else 2)

    def handover(self, obs, s, rho, contact, Sigma, slip):
        want = (s.phase in {"align", "insert", "release"}) or contact
        safe = float(torch.max(torch.diag(Sigma))) <= self.sigma_max
        dwell = (s.steps - s.last_switch) >= self.T_dwell
        if s.mode == "SERVO":
            done = self.converged(obs, s, rho) or (s.steps - s.servo_start) > self.T_servo_max
            return (not done) and safe
        return want and safe and dwell and s.handover_count < self.max_handover

    def pack(self, a, obs):
        out = {
            "meta.token": os.environ["UNIBOT_SUBMISSION_TOKEN"],
            "action.left_arm":  a["left_arm"].astype(np.float32),
            "action.right_arm": a["right_arm"].astype(np.float32),
            "action.left_gripper":  a["left_gripper"][:, None].astype(np.float32),
            "action.right_gripper": a["right_gripper"][:, None].astype(np.float32),
        }
        if "pivot" in a:
            out["action.pivot"] = a["pivot"].astype(np.float32)
        return out
```

```python
# ===== D-01：残差接触观测器（可离线训练/验证）=====
class ResidualObserver:
    def fit_baseline(self, actions, states, qdot, phases):
        # 只用无接触相位拟合 r0(q, qdot, u) ≈ e
        e = align(actions, states)                  # e_t = u_{t-l} - q_t
        self.r0 = LocalLinearModel().fit(states, qdot, actions, e, mask=~phases.contact)
        self.Sigma_z = robust_cov(e[~phases.contact] - self.r0.predict(...))

    def score(self, z):
        rho = float(z.T @ inv(self.Sigma_z) @ z)
        contact = self.cusum.update(rho) > self.tau_c
        jam = contact and (self.slope(rho) >= -self.eps) and (self.residual_axis_align(z) > 0.7)
        return rho, contact, jam
```

```python
class TaskPoseEstimator:
    def update(self, obs, q):
        # 1) 已知相机运动（FK）+ 在线手眼 X

        pts = self.triangulate(feats_head, feats_wrist, dT_cam, self.handeye.X)
        # 3) 只解任务相关子空间，含对称性商
        xi, Sigma = self.solve_trp(pts, self.task_frame(obs.language), symmetric=self.sym)

        xi, Sigma = self.filter.predict_update(xi, Sigma)
        if self.reproj_residual > self.tau_reproj or self.jump(xi) > self.tau_jump:
            self.invalidate()   # 人为移动/遮挡 -> 回退
        return xi, Sigma
```

```python
# ===== D-02：经验 Jacobian 的在线使用 =====
class EmpiricalJacobianField:
    def dls(self, q, dx, lam=1e-3):
        J = self.J(q)
        return J.T @ solve(J @ J.T + lam * np.eye(6), dx)   # 阻尼最小二乘

    def null_authority(self, q, axis):
        J = self.J(q)
        N = np.eye(J.shape[1]) - np.linalg.pinv(J) @ J
        g = self.grad_directional_authority(q, axis)          # ∇_q m_ξ
        return self.alpha * (N @ g)

    def task_axis(self, obs):
        # 由 TRP 任务系给出插入轴；放置类用支撑面法向
        return self.trp_axis
```

## 5. 推导（引理 DL1–DL7）

**DL1（方向性力权威与秩亏）** 设任务 twist 为 `ξ`，关节力矩约束 `‖τ‖≤τ_max`。由 `τ=JᵀF` 与力椭球可得沿 `ξ` 的最大力 `F_max(ξ)=τ_max/m_ξ`，其中 `m_ξ=√(ξᵀ(JJᵀ)⁻¹ξ)⁻¹`。若 `rank(J)=r<6`，则存在非零 `ξ` 使 `JJᵀξ=0`，从而 `m_ξ=0`、`F_max=0`。  
**推论**：单臂 5 DoF 时至少有一个 6D 任务方向零权威；旋转插入必须依赖额外腕部 DoF、腰部 pivot 或基座重定位。∎

**DL2（残差—外力可识别性）** 准静态下低层 PD 平衡满足 `K_p(u−q)+τ_g(q)+τ_ext=0`（符号约定取使残差为正）。于是 `τ_ext=K_p(q−u)−τ_g(q)`。若 `K_p` 与 `τ_g` 可辨识（后者由无接触数据回归），则 `τ_ext` 由 `e=u−q` 唯一确定。动态时 `M(q)q̈+C(q,q̇)q̇+τ_g=K_p e+τ_ext`，惯性/科氏项可由 `q,q̇,q̈` 计算或学习；因此接触 onset 与方向变化是可识别的，绝对力标定只需单调映射。∎

**DL3（本体锚定的度量可观测性）** 设手眼变换 `X` 未知，两帧 EE 位姿 `T_1,T_2` 已知，则相机相对运动为 `X⁻¹(T_2T_1⁻¹)X`，其平移范数等于 `‖t_2−t_1‖`，与 `X` 无关。对静态点 `P`，两视图三角化在已知平移范数下恢复度量深度；`X` 可由 ≥3 组非共线运动的重投影一致性辨识。故无 CAD、无物体位姿标签时，相对位姿仍可度量恢复（唯一假设：两视图间目标静止或与夹爪刚性）。∎

**DL4（一步延迟下的伺服稳定性）** 任务系比例伺服 `x_{k+1}=x_k+λ(ξ*−x_{k−d})`，误差 `e_{k+1}=e_k−λe_{k−d}`。`d=1` 时特征方程 `z²−z+λ=0`，Jury 判据给出 `0<λ<1`。`d=1, λ=0.3` 时误差每步乘约 0.7，90% 收敛约 7 步（30 Hz 下 0.23 s）。`d` 增大时稳定裕度收缩，故设计取 `λ≤0.3` 并对多步延迟加低通/预测。∎

**DL5（柔顺整形的冲量界）** 设接触后目标以速度 `v` 继续推进，低层等效刚度 `k`，检测延迟 `d`。穿透 `δ(t)=vt`，力 `f(t)=kvt`，冲量 `J_imp=∫₀^d kvt dt=½kvd²`。故速度减半冲量减半；检测延迟减半冲量降为 1/4。**缩短检测延迟比单纯减速更有效**。∎

**DL6（不确定性门控的收益条件）** 设触发时"修正方向正确"的概率为 `p`，正确修正收益 `G`，错误修正损失 `L`（`L>G` 时更需谨慎）。期望收益 `E=pG−(1−p)L`；仅当 `p>L/(G+L)` 时介入为正。若门控保证 `p≥p₀`（如 0.8）且 `L/(G+L)<p₀`，则介入不劣于不介入。故 `σ_max` 应按"校准后的正确率"选，而不是按经验阈值拍脑袋。∎

**DL7（容差—成功率）** 横向误差 `e~N(0,σ²)`、单边间隙 `c/2`，则 `P(|e|<c/2)=erf(c/(2√2σ))`。`c=1 mm` 时：`σ=1 mm→38.3%`，`0.5→68.3%`，`0.25→95.4%`，`0.2→98.8%`。因此亚毫米相对精度是插入类任务从 20% 提升到 50%+ 的必要条件；若某任务的 `c<2σ`，应优先提高精度或换策略，而不是加数据。∎

## 9. 风险登记册与剪枝预案

| 风险 | 概率 | 影响 | 对冲 |
|---|---|---|---|
| **残差不可归因**（低层插值/重规划/未知增益） | 中高 | 高（力回路失效） | E701 先行；只用变化点不追求绝对力；不可归因即关回路 |
| **TRP 在接触点被遮挡** | 中高 | 高（位姿回路失效） | 头部 stereo + 历史外推 + 不确定性门控；失效回退 |
| **5 DoF 秩亏使旋转任务无解** | 中 | 高（任务上限） | 先核实自由度；借腕部/腰部/基座；否则任务降级 |
| **伺服振荡/抖动** | 中 | 中高 | λ≤0.3、速率限幅、滞回、最大驻留 |
| **chunk=1 延迟/调用开销** | 中 | 中 | chunk=2 + 块内限速；E707 压测 |
| **相机安装差异 / 手眼漂移** | 中 | 中 | 在线自标定 + 保守门控 |
| **目标被人为移动** | 中 | 中 | 重投影/跳变检测 + 重置 TRP + 回退 |
| **合规被判"第二个策略"** | 中 | 高 | 辅助模块打包同一 checkpoint；纯解析兜底；书面确认 |
| **过拟合 teaser** | 中 | 中 | 只用结构排序，不用数字调参；本地 OOD + 真机 A/B |
| **延迟/jerk 被判不可信** | 中 | 中 | DriveAudit + 稳定预算 + 限幅 + 报告 |

**剪枝预案**：
- **必保**：E701（语义）、D-02（Jacobian）、D-05（限速柔顺）——不依赖新数据、离线可验证。
- **优先**：D-01（残差）> D-03（TRP）> D-04（伺服）> D-06（姿态）。
- **条件**：D-07（滑移）依赖 TRP；D-09（joint/ee）有余量再做。
- **一票否决**：若 E701 显示残差不可观测，或 E705 显示 TRP 在 10 cm 处 >3 mm，则**不要**把闭环写进主线，退回"短 chunk + 限速柔顺 + 基线"。

## 11. 本轮最值得押注的创新点（一句话）

**押注 D-01 + D-03 + D-04 的组合：把"关节驱动残差"当作无力传感器条件下的接触通道，把"FK 锚定的任务相关相对位姿"当作无 CAD 条件下的对齐通道，并只在最后对齐/插入相位用短 chunk 闭环接管——它不需要更大的模型、不需要新数据、不需要改接口，且三条判据（残差可分性、TRP 精度、伺服稳定性）全部可以在真机之前离线否证。**

**本轮最大风险（一句话）**：整套方案的前提是"评测端关节控制器近似 PD、指令—实测残差可观测且可归因于接触"，而这一语义并未被接口承诺；若该前提不成立，或 TRP 在接触点被遮挡，双回路会同时失效，闭环反而比基线更危险。
