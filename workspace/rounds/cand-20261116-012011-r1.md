# 第 12 轮（新灵感循环第 1 轮；本轮灵感：「强化学习」×「抓取」）
> **基线**：第 11 轮 MetricVoiceGauge-GSCF-SRA-JSSE（定义 549–561；引理 92–96；实验 E591–E610）。
> 本轮纪律：**安全权不下放 + 恢复权可学习 + 接触即证据**。v11 用三重守护把「不确定 ⇒ 收缩/中止」做到极致，却留下三笔债：**可用性债**（GSCF 在动态/遮挡/透明反光下虚假低 ⇒ K_eff 长期塌到 1；三守护同时触发的场景只剩急停，没有优雅恢复）、**接触债**（抓取的最终失败是掉落/滑移，v11 的视觉/几何/语义证书没有一条来自接触物理；JSSE 的运动学标定偏差还可能让中止点偏离）、**学习债**（全部阈值靠离线标定，系统无法从日志中变好，且任何「学习」都威胁证书权威）。本轮两个灵感分别从「恢复」与「接触」两侧切入，合起来治理三笔债。铁律不变：新模块失效 ⇒ 注入声明中立元，行为**严格等价**于 v11（SOCR/CGGE/COL 各自失效）或**支配**（选项仅在 v11 可行集内、以 v11 中止为唯一出口）。

## 0. 直觉与动机

**灵感 1（强化学习 → 把「恢复」从固定中止升级为受认证选项上的策略选择）**
直觉：v11 的 P13 是「审查失明即收缩」，安全但把「不确定」一律翻译成「中止」。真实家庭/赛场里，大多数不确定是**可消解的**：退后半步重新看、换个视角重扫、松手重抓、把物体放下再确认——这些都不是新动作，而是**预先认证过的恢复技能**。RL 恰好擅长在「什么时候值得退一步、退哪一步」上做序列决策；但把 RL 直接接进控制回路会摧毁证书权威。核心创新：**屏蔽式选项评论家恢复（Shielded Option-Critic Recovery, SOCR）**——不是让 RL 生成关节指令，而是让它从有限个**已认证恢复选项** O_cert（退避重感知、换视角、重抓、放下、保守搬运、请求人类）中**排序/选择**；每个选项自带入口不变式 I_o、时长上界 T_o、v11 同款证书 κ_o、以及**唯一出口 e_o = v11 认证中止**。关键不是「学习安全」，而是**学习只在安全集合内部改变偏好**：Q 只回答「哪个已允许的选项更可能恢复信任」，从不回答「这个动作安不安全」；证书仍然是唯一的准入权威（权威分离，P16）。这样即使 Q 完全错误、OOD 或对抗注入，最坏也只是选了一个「合法但不够聪明」的恢复选项，或直接回退 v11 中止——安全性对 v11 单调不降，可用性才可能上升。这正面回应 v11 最大风险中的「三重失效无优雅退化」：不是加一层更强的证书，而是给证书的**失败分支**加一个有界、可审计、可回退的恢复阶梯。

**灵感 2（抓取 → 用接触物理给抓取证书落地，并给恢复提供独立信道）**
直觉：v11 的 ĝ_min/γ̂_grasp 终究是「看出来的」抓取，而抓取真正的物理判据是**接触**：力封闭是否成立、切向力是否逼近摩擦锥边界、接触点是否开始滑移、物体是否还听话。透明杯、反光件、快速运动、遮挡——视觉/几何/语义都可能虚假低或虚假高，但触觉/力/力矩是**独立物理测量**。核心创新：**接触接地抓取包络（Contact-Grounded Grasp Envelope, CGGE）**——用抓取矩阵 G 与摩擦锥定义**力封闭余量** m_fc，用触觉剪切/法向比与接触点速度定义**滑移领先指标** s_slip（200Hz，领先视觉 ≥10×），把两者合成**接触证书** Ĉ^contact，并扩展块证书为 Ĉ^{+++}；滑移/失接触不是「等下一次块边界」，而是 200Hz 快通道直接触发**重抓或放下**选项（若规范允许），否则 v11 中止。接触通道还给了 JSSE 一个闭环：中止不只靠 FK，还靠接触状态落地（抓取中/已放下/已脱离），把「任务空间中止等价」升级为「任务-接触联合中止等价」。**透明/反光物体**从此有了第二条证据链：视觉说「几何异常」（可能虚假低）时，接触可以说「抓得稳」（m_fc 足够）——恢复选项因此有据可依，而不是盲目退避。

**灵感 3（横切：认证选项库与权威分离 → 让「学习」不碰安全权）**
直觉：RL 的危险不在算法，而在**权限**。把安全权（哪些动作可执行）与偏好权（在可执行动作里选哪个）分开，学习就变成「建议」而非「许可」。核心创新：**认证选项库（Certified Option Library, COL）**——每个选项是一个带证书的宏动作，版本化、可离线预认证、部署期静态校验资源配额；**权威分离原则（P16）**：Q/评论家只排序可采纳选项，准入由证书与守卫决定；学习侧任何不确定（集成方差大、OOD、对抗输入）⇒ 丢弃 Q，按 v11 固定中止。原则 P17：**恢复有界律**——恢复总时长/次数/资源有硬上界，任何选项组合都必须在 B_rec 内回到 v11 认证态，否则立即中止。原则 P18：**接触独立律**——抓取安全必须至少有一条不依赖视觉/语义的物理证据（力封闭或滑移），否则不得声称「抓取证书有效」。

三者咬合：SOCR 提供「往哪恢复」的偏好，CGGE 提供「接触是否可信」的物理证据，COL/P16–P18 保证二者都装进 v11 的安全壳里。v11 的证书 Ĉ^{++} 升级为 **Ĉ^{+++} = (ĝ_min, ê_max, γ̂_grasp, β_GSCF, n_t, n_t^reason, Q_abort, m_fc, s_slip, n_contact, o_state)**，其中前三项仍由 v11 给出，后四项只**增加证据/收缩**，不放松任何 v11 约束。

## 1. 研究问题（轮次升级版）

- **Q1（学习不越权）**：如何把离线 RL 限制为「认证选项上的排序器」，使得任意策略误差/OOD/对抗注入下，系统物理行为仍严格支配于 v11（不可达新危险态），且失效率可测？
- **Q2（接触可证抓取）**：如何用 200Hz 触觉/力信号构造力封闭余量与滑移领先指标，使透明/反光/动态物体的抓取失效检测延迟 ≤1 个触觉帧（5ms），并把重抓/放下纳入有界恢复而不违反规范？
- **Q3（可用性而不牺牲安全）**：在 GSCF 虚假低、三守护共失效、长尾对象三类场景下，恢复选项能把 K_eff 塌缩/急停率降低多少，同时保证 0 碰撞、掉落率 ≤ v11、台账可审计？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 权威分离律（Authority Separation, SOCR/COL）**
安全准入权只属于证书与守卫；学习得到的 Q/置信度只可对已准入选项排序，不可扩权、不可放宽阈值、不可生成新动作。学习不确定 ⇒ 回退 v11 固定行为。

**P17 恢复有界律（Bounded Recovery, SOCR）**
恢复必须在 B_rec（总时长）、N_rec（选项链长）、M_rec/E_rec（资源）上硬有界；每个选项必须声明入口不变式与「唯一出口 = v11 认证中止」；超界或出口不可用 ⇒ 立即中止。

**P18 接触独立律（Contact Independence, CGGE）**
任何「抓取安全/抓取成功」的声称必须至少有一条独立于视觉/语义的接触物理证据（力封闭余量或滑移指标）；接触证据缺失/失效 ⇒ 不得放宽抓取证书，只能回到 v11 或执行「放下」。

## 3. 与基线的接口（如何退化）

- SOCR 失效/关闭（离线模型损坏、集成发散、OOD 超阈、预算耗尽）⇒ o* = ⊥，直接执行 v11 证书分块/中止：**行为等价 v11**（放弃恢复，保守性回归）；
- CGGE 失效（无触觉、力传感器故障、接触模型标定失效、freshness > T_tac）⇒ 接触证书中性化（m_fc←+∞ 不参与、s_slip←0 不触发），Ĉ^{+++} 退化为 Ĉ^{++}：**等价 v11**，不产生新的抓取放宽；
- COL 缺失/版本不匹配 ⇒ 对应选项不可用；库空 ⇒ 仅 v11 中止；
- v11 的 GSCF/SRA/JSSE/STF/NRB/AC/ID/MW 失效 ⇒ 沿 v11 九级退化链（Level-1…Level-9）原样；SOCR 的恢复不能绕过任何一级（每级守卫仍先于选项）；
- v8 及更早 ⇒ 中立元注入 ⇒ v7 ⇒ v6。

## 4. 预期贡献

1. **恢复的证书化**：提出「认证选项 + 权威分离 + 有界恢复」，证明学习可在不扩权的前提下把 v11 的「一律中止」变成「有界恢复后中止」，安全性对 v11 单调不降（引理 97–99）；
2. **接触接地抓取证书**：力封闭余量 + 200Hz 滑移领先 + 任务-接触联合中止等价，使透明/反光/动态抓取的失手检测从「块级/视觉级」降到「触觉帧级」（引理 100–101）；
3. **可用性/安全解耦的评测协议**：把「安全失败」与「可用性损失」分开报告（0 碰撞/0 掉落 vs K_eff 塌缩率/急停率），避免用可用性指标掩盖安全退化（引理 102 + E611–E630）；
4. **E611–E630** 覆盖选项认证、虚假低恢复、三失效降级、力封闭/滑移标定、透明抓取、对抗 Q、台账、长跑与竞赛。

## 5. 本轮最大风险

**一句话**：恢复选项的证书建立在「已知对象质量/摩擦/动力学 + 接触模型标定」的前提上，遇到未知可变形物体、摩擦突变或触觉被污染时，「已认证选项」可能在被信任的恢复轨迹上逐步耗尽安全边际；而 RL 的排序偏好又天然倾向「再试一次」而非中止，使 v12 的最大风险从「不会恢复」转成「恢复得太久、太自信」。

# 第 12 轮产物 · 创新点清单 v12：**MetricVoiceGauge-SOCR-CGGE**（Metric Voice Gauge with Shielded Option-Critic Recovery & Contact-Grounded Grasp Envelope）

> 背景：第 11 轮 MetricVoiceGauge-GSCF-SRA-JSSE（定义 549–561；引理 92–96；实验 E591–E610）。
> 本轮灵感：「强化学习」×「抓取」
> **继承纪律**：MetricVoiceGauge 九不变式 + v11 三守护（GSCF/SRA/JSSE）与 v10 三模块（STF/NRB/LS）全部保留。新组件为可选增强：SOCR 失效 ⇒ o*←⊥、执行 v11 中止（等价 v11）；CGGE 失效 ⇒ 接触证书中性化、Ĉ^{+++}→Ĉ^{++}（等价 v11）；COL 缺失/空库 ⇒ 仅 v11 中止（等价 v11）；其余失效沿 v11 九级退化链。v11 最大风险（三守护共失效后只能急停、无优雅退化）由 SOCR 的有界恢复阶梯正面拆除（引理 97–98），其代价是引入「恢复前提」新债，由 CGGE 的独立接触证据与 E612/E625/E626 监测（引理 99、102）。

## 0. 直觉与核心 IP

**直觉 1（SOCR）**：v11 的「不确定 ⇒ 中止」是安全的，但把大量**可消解的不确定**误当成不可恢复。RL 不应被允许生成新动作；它只应在**已经认证过的恢复技能**之间做选择。于是学习只改变偏好，不改变权限：Q 只排序可采纳选项，证书与守卫仍决定谁可被采纳。恢复选项全部以 v11 中止为唯一出口，且时长/次数/资源有硬上界——恢复是「有界的绕路」，不是「扩权」。

**直觉 2（CGGE）**：抓取的最终裁判是接触，不是像素。力封闭余量 m_fc 回答「这个抓取在扰动集 W 下是否还夹得住」，滑移指标 s_slip 回答「摩擦锥是否正在被突破」。触觉/力/力矩与视觉/几何/语义失效模式独立，因而透明、反光、遮挡、快速运动下仍能提供第二条证据链；接触失效检测以 200Hz 运行，比 v11 的 50Hz 五检快 ≥4×、比 5Hz 块边界快 ≥40×。

**直觉 3（COL/P16–P18）**：把「安全权」与「偏好权」制度化分离。选项库是可版本化、可离线预认证的数据；在线学习只产生排序建议；任何学习不确定（集成发散、OOD、陈旧、对抗）都退回 v11。这样 RL 的收益是可用性，不是安全豁免。

| B_rec, N_rec | 恢复总时长上界、选项链长上界（P17） |
| G, W, FC(μ) | 抓取矩阵、扰动扳手集、摩擦锥；m_fc 为力封闭余量（μ 单位） |
| s_slip | 滑移领先指标（切向/法向比 ∨ 接触点速度），200Hz |
| Ĉ^contact | 接触证书 (m_fc, s_slip, n_contact)，模式敏感 |
| Ĉ^{+++} | 扩展块证书 (ĝ_min, ê_max, γ̂_grasp, β_GSCF, n_t, n_t^reason, Q_abort, m_fc, s_slip, n_contact, o_state) |
| Q_abort^c | 任务-接触联合中止集：FK(q)=p*±ε_fk ∧ q∈C_q_safe ∧ 接触态安全 |
| R_o(s0) | 从 s0∈I_o 执行 o（≤T_o）的可达状态集（「选项管」） |
| mode | APPROACH / GRASP / TRANSPORT / RELEASED；接触证书仅在 GRASP/TRANSPORT 强制 |
| Λ^rec | 恢复台账扩展：选项事件、Q/集成/OOD、守卫命中、出口、时长、m_fc/s_slip |

**新增定义 562（认证恢复选项）** 选项 o = (π_o, I_o, T_o, κ_o, e_o, ρ_o)：
- π_o 为预定义技能原语（退避重感知、换视角、重抓、放下、保守搬运、请求人类），**执行期不在线学习**；
- I_o ⊆ S 为入口不变式（要求 v11 块证书可用、规范未违反、接触态与模式一致）；
- T_o 为最大执行时长；ρ_o=(M_o,E_o) 为内存/能耗配额；
- κ_o=(ĝ_min^o, ê_max^o, β^o, d_stop^o) 为整条选项管上的 v11 同款间隙/力矩/停车证书；
- e_o:S→𝒫(v11 中止) 为**唯一出口**，返回一个 v11 认证中止目标。
o **已认证** ⇔ 离线验证：∀s0∈I_o，执行 π_o 至多 T_o 的轨迹 R_o(s0)⊆C_q_safe，且 ∀s∈R_o(s0)，e_o(s) 在制动距离 d_stop^o 内可采纳。

**新增定义 563（认证选项库）** O_cert={o_1,…,o_n}，n≤16，带版本哈希 H(O_cert) 与每项资源配额。部署期静态校验：ΣM_o≤M_cap、ΣE_o≤E_cap、每项 e_o 的出口集非空、库哈希在 MW 契约表中登记。运行期只读，不在线增删。

**新增定义 564（运行时可采纳）** 
```
Adm_o(t) = I_o(s_t) ∧ budget.allows(o) ∧ (e_o(s_t) 当前为 v11 认证中止)
           ∧ (模式要求的接触证书可用或该选项不依赖接触)
```
**出口必须始终可采纳**是选项的准入条件，而非运行中才检查；若出口在运行中变得不可采纳，看门狗立即触发急停。

**新增定义 565（屏蔽式选项选择）** 
```
o*(t) = argmax_{o∈Adm(t)} mean_i Q_θi(s_t, o)    若 A(t)=1
      = ⊥                                        否则
```
其中 ⊥ 表示「不恢复」，直接执行 v11 证书分块/中止。**RL 输出只有「选项 id」这一离散量，不输出关节/任务空间连续指令**。

**新增定义 566（学习中立化）** A(t)=1 ⇔ D(s_t)≤δ_Q ∧ OOD(s_t)≤τ_ood ∧ freshness(Q_θ)≤T_Q ∧ 无对抗标记。任一不满足 ⇒ ⊥。δ_Q、τ_ood、T_Q 由 E614 标定。该定义把「学习不确定」显式映射到 v11 固定行为。

**新增定义 567（有界恢复半马尔可夫过程）** 每次选择 o 后，π_o 执行至 {目标达成、守卫失败、T_o 超时}，随后返回 v11 元控制器。恢复预算：
```
Σ_{j=1}^{N_rec} T_{o_j} ≤ B_rec,max,  N_rec ≤ N_max,  Σ M_o ≤ M_rec,  Σ E_o ≤ E_rec
```
任一项越界 ⇒ 立即执行最近 v11 中止。P17 把「恢复可以多试几次」变成硬约束，防止 RL 用恢复逃避中止。

**新增定义 568（力封闭余量与抓取矩阵）** 设接触 i=1..m，抓取矩阵 G=[B_1…B_m]，扰动集 W（重力+惯性+有界外力）。摩擦锥带余量 α：
```
FC_α = { λ | ‖f_t,i‖ ≤ (μ_i−α) f_n,i,  f_n,min ≤ f_n,i ≤ f_n,max }
m_fc = sup{ α∈[0, min_i μ_i] | ∀w∈W, ∃λ∈FC_α: Gλ = −w }
```
m_fc>0 表示对 W 的鲁棒力封闭；m_fc 越大，距摩擦锥边界越远。m_min 由 E616 标定，要求 m_fc≥m_min。

**新增定义 569（滑移领先指标）** 对每个接触：
```
s_i = max( ‖f_t,i‖ / (μ_i f_n,i),  ‖v_t,i‖ / v_slip0 )
s_slip(t) = max_i s_i(t)
```
其中 v_t,i 为触觉估计的接触点切向速度，v_slip0 为标定速度尺度。s_slip≥τ_slip 视为滑移将临，s_slip≥τ_abort（τ_abort≥τ_slip）触发重抓/放下/中止。200Hz 更新，检测延迟 ≤1 帧（5ms）。

**新增定义 570（接触证书）** Ĉ^contact=(m_fc, s_slip, n_contact)，n_contact 为期望接触位图。模式敏感有效：
```
contact_ok = (m_fc ≥ m_min) ∧ (s_slip ≤ τ_slip) ∧ (n_contact = n_expected) ∧ (freshness_tac ≤ T_tac)
```
仅当 mode∈{GRASP,TRANSPORT} 时强制 contact_ok；APPROACH/RELEASED 下接触证书取中性值（不参与证书，但仍监测意外接触）。

**新增定义 571（扩展块证书）** Ĉ_t^{+++}=(ĝ_min, ê_max, γ̂_grasp, β_GSCF, n_t, n_t^reason, Q_abort, m_fc, s_slip, n_contact, o_state)。有效 ⇔ v11 定义 552 条件 ∧ (mode∉{GRASP,TRANSPORT} ∨ contact_ok) ∧ o_state∈{NONE, RUNNING(o), EGRESS(o)}。**接触项只增加证据或触发收缩，绝不放宽 v11 的 ĝ_min/ê_max/β_GSCF**。

**新增定义 572（任务-接触联合中止等价）** 扩展 v11 定义 561：
```
Q_abort^c = { (q,c) | FK(q)=p*±ε_fk, q∈C_q_safe, c∈{PLACED, SECURED, RELEASED} }
```
- PLACED：物体已由支撑面承托，落高≤h_safe、速度≤v_safe；
- SECURED：中止保持时 m_fc≥m_min；
- RELEASED：物体在支撑面上方安全高度/速度释放。
等价性：末端位置误差 ≤ε_fk，物体接触态误差 ≤ε_c（E620 标定）；若目标位置下方有人/无支撑，则接触落地不可采纳，退回 v11 纯任务空间中止。

**新增定义 573（恢复安全不变式）** 对每个 o，离线证明：
```
(i)  R_o(s0) ⊆ C_q_safe
(ii) ∀s∈R_o(s0):  e_o(s) 在 d_stop^o 内可采纳，或 s 已是 v11 认证中止态
```
满足则称 o 为**安全恢复选项**。该不变式是引理 97 的前提，也是部署期静态校验的一部分。

**新增定义 574（权威分离的形式化）** 令 Adm(s) 由 (证书, 守卫, 预算, 出口可采纳性) 唯一决定，不含 Q_θ。则对任意两个评论家 Q,Q′：
```
Adm_Q(s) = Adm_{Q′}(s) = Adm(s),   且   o*(s) ∈ Adm(s) ∪ {⊥}
```
即学习只能改变 Adm 内元素的排序，不能改变 Adm 本身；任何 Q 值（包括 ±∞、对抗注入）都不获得准入权。

**新增定义 575（恢复台账扩展）** Λ^rec 在 v11 哈希链上追加：H(prev ‖ t ‖ o_id ‖ entry_hash ‖ Q向量 ‖ D(s) ‖ OOD(s) ‖ 守卫命中 ‖ egress ‖ 时长 ‖ m_fc ‖ s_slip)。事件驱动写入（选项进入/退出/中止），哈希链 κ_h=256 不变。

**新增定义 576（安全-可用性分离指标）** 
```
SafetyFail = 碰撞 ∨ 掉落 ∨ 规范违反
AvailabilityLoss = K_eff=1 时长占比 ∨ 中止率 ∨ 恢复失败率
```
报告规则：SafetyFail 是硬约束（必须 ≤v11）；AvailabilityLoss 是优化目标（允许 ≤v11）。禁止用可用性提升去补偿安全退化。

## 2. 形式化定义（要点与升级）

**定义 493/495/521/496/531/539/540–561** 继承 v11。δ_trigger 五条件中「Ĉ_t^{++} valid」升级为「Ĉ_t^{+++} valid」（含接触证书与 o_state），块证书失效、单步条件与恢复超界同样触发 M₀ 硬检查。

**升级定义 539（有效块长，v12）**：K_eff 公式**完全沿用 v11 定义 553**，SOCR 不得修改门控。恢复发生在「v11 本应中止」的分支上：选项执行期间，v11 五检与 K_eff 语义仍逐周期评估；若恢复后 U_t^geo 重建，则重新按 v11 公式恢复分块。**K_eff 仍是安全门，不是恢复奖励**。

**升级定义 559（5+1 守卫，v12）**：50Hz 五检（证书有效性、停车不变式、语义创新度、快规范、几何一致性）不变；新增 **200Hz 接触快通道**（滑移/失接触），可在 1 个控制节拍内抢占五检并进入恢复/中止分支。二者关系是「慢检管证书、快检管接触」：快通道不改变五检语义，只在 GRASP/TRANSPORT 模式下增加一条独立的失效源。

**新增定义 577（恢复触发谓词）** 
```
Trigger_rec = (v11 五检失败) ∨ (接触快通道 SLIP/失接触) ∨ (块生成无认证候选)
```
Trigger_rec 且出口可采纳 ⇒ 尝试 SOCR；否则直接 v11 中止。**任何非 Trigger_rec 的正常周期不得进入恢复**，防止恢复成为常态绕路。

```python
from typing import Callable


@dataclass(frozen=True)
class OptionCert:
    g_min: float      # 选项管内 min clearance - β_o
    e_max: float      # 选项管内 max effort + β_o

    T_max: float      # 选项时长上界


@dataclass
class CertifiedOption:
    name: str
    enter: Callable          # I_o(s) -> bool
    skill: Callable          # π_o: state -> macro command / trajectory
    cert: OptionCert

class RecoveryBudget:
    def __init__(self, B_max=1.0, N_max=2, M_cap=4 * 1024**3, E_cap=25.0):
        self.B_max, self.N_max = B_max, N_max
        self.M_cap, self.E_cap = M_cap, E_cap
        self.reset()

    def reset(self):
        self.t_used, self.n_used, self.m_used, self.e_used = 0.0, 0, 0, 0.0

    def allows(self, o):
        return (self.t_used + o.cert.T_max <= self.B_max and
                self.n_used + 1 <= self.N_max and
                self.m_used + o.M <= self.M_cap and
                self.e_used + o.E_mw <= self.E_cap)

    def enter(self, o):
        self.t_used += o.cert.T_max
        self.n_used += 1
        self.m_used += o.M
        self.e_used += o.E_mw


class CertifiedOptionLibrary:
    def __init__(self, options, ledger, max_n=16):
        assert len(options) <= max_n
        self.options = {o.name: o for o in options}
        self.ledger = ledger
        self.lib_hash = sha256_of(sorted((o.name, o.version) for o in options))

    def admissible(self, s, ctx, stf, gscf, cgge, budget, egress_ok):
        out = []
        for o in self.options.values():
            if not o.enter(s):
                continue
            if not egress_ok(o, s):          # 唯一出口当前必须可采纳
                continue
            if not budget.allows(o):
                continue
            # 依赖接触的选项在 CGGE 中性化时不可采纳（但非接触选项仍可用）
            if getattr(o, "needs_contact", False) and not cgge.healthy:
                continue
            out.append(o)
        return out


class ShieldedOptionCritic:
    """Q 只排序，不准入；不确定即 ⊥。"""
    def __init__(self, ensemble, ood_model, ledger,
                 delta_q=0.1, tau_ood=0.9, T_Q=2.0):
        self.ens, self.ood, self.ledger = ensemble, ood_model, ledger
        self.delta_q, self.tau_ood, self.T_Q = delta_q, tau_ood, T_Q
        self.trained_at = 0.0

    def _trustworthy(self, s, now):
        if now - self.trained_at > self.T_Q:
            return False
        d = float(np.std([q(s) for q in self.ens]))
        if d > self.delta_q:
            return False
        if self.ood.score(s) > self.tau_ood:
            return False
        return True

    def select(self, s, admissible, now, budget):
        if not admissible:
            return None, "no-admissible"
        if not self._trustworthy(s, now):
            return None, "neutral"          # ⊥ -> v11 中止
        qvals = [float(np.mean([q(s, o.name) for q in self.ens]))
                 for o in admissible]
        o = admissible[int(np.argmax(qvals))]
        self.ledger.append_recovery_decision(s, [x.name for x in admissible],
                                             qvals, "ok")
        return o, "ok"


class ContactGroundedGraspEnvelope:
    def __init__(self, mu, W, m_min, tau_slip=0.8, tau_abort=0.95,
                 v_slip0=0.01, T_tac=0.05):
        self.mu, self.W, self.m_min = mu, W, m_min
        self.tau_slip, self.tau_abort = tau_slip, tau_abort
        self.v_slip0, self.T_tac = v_slip0, T_tac
        self.healthy = True
        self.m_fc = float("inf")
        self.s_slip = 0.0
        self.contact_ok = True

    def update(self, contacts, tactile, now):
        """200Hz：接触变更时重解小 LP，否则增量更新。"""
        if not tactile.fresh(now, self.T_tac):
            self.healthy = False
            self.m_fc, self.s_slip = float("inf"), 0.0
            self.contact_ok = True         # 中性化：退回 v11
            return
        self.healthy = True
        self.m_fc = self._force_closure_margin(contacts, tactile, self.W)
        self.s_slip = self._slip_indicator(tactile)
        self.contact_ok = (self.m_fc >= self.m_min and
                           self.s_slip <= self.tau_slip and
                           self._contact_set_ok(contacts, tactile))

    def _force_closure_margin(self, contacts, tactile, W):
        """sup α s.t. ∀w∈W ∃λ∈FC_α: Gλ=-w；m≤4，热启动小 LP。"""
        G = build_grasp_matrix(contacts)
        return max_alpha_in_friction_cones(G, W, tactile.normal_forces,
                                           self.mu, warm_start=self._lp_warm)

    def _slip_indicator(self, tactile):
        vals = []
        for c in tactile.contacts:
            ratio = c.ft_norm / (c.mu * max(c.fn, 1e-6))
            speed = c.vt_norm / self.v_slip0
            vals.append(max(ratio, speed))
        return max(vals) if vals else 0.0

    def fast_guard(self, mode):
        if mode not in ("GRASP", "TRANSPORT"):
            return "OK"
        if not self.healthy:
            return "NEUTRAL"               # 接触证书中性化 => v11
        if self.s_slip > self.tau_abort or not self.contact_ok:
            return "SLIP"
        return "OK"


class SixGuardOptionCertifier(TriGuardChunkCertifier):
    def __init__(self, *a, cgge=None, option_lib=None, socr=None,
                 budget=None, **kw):
        super().__init__(*a, **kw)
        self.cgge, self.option_lib = cgge, option_lib
        self.socr, self.budget = socr, budget

    def _v11_five_check_reason(self, chunk, k_exec, live_obs, stf, gscf, nrb):
        """复用 v11 midchunk_guard，但返回原因而非直接中止。"""
        if not chunk.cert_still_valid(live_obs):
            return "cert"
        if (live_obs.nearest_clearance - self.d_brake(live_obs.speed)
                - self.d_safe < chunk.remaining_len(k_exec)):
            return "stop_inv"
        if stf.surprise_near(live_obs.pose) > stf.tau_sem:
            return "semantic"
        if nrb.fast_norms(live_obs).violated:
            return "norm"
        if not gscf.geo_ok_near(live_obs.pose):
            return "geometry"
        return None

    def _v11_abort(self, chunk, k_exec, jsse):
        return ("abort", jsse.map_abort(chunk.nearest_abort_point(k_exec)))

    def _egress_ok(self, o, s, chunk, k_exec, jsse):
        p = o.egress(s) if o is not None else chunk.nearest_abort_point(k_exec)
        return jsse.admissible_abort(jsse.map_abort(p))

    def midchunk_guard(self, chunk, k_exec, live_obs, stf, gscf, nrb,
                       jsse, now):
        reason = self._v11_five_check_reason(chunk, k_exec, live_obs,
                                             stf, gscf, nrb)
        if reason is None:
            ev = self.cgge.fast_guard(live_obs.mode)
            if ev in ("OK", "NEUTRAL"):
                return ("continue", k_exec + 1)
            reason = ev.lower()            # slip / contact_lost
        # 触发恢复，但先确认 v11 中止出口可采纳
        if not self._egress_ok(None, live_obs, chunk, k_exec, jsse):
            return self._v11_abort(chunk, k_exec, jsse)
        adm = self.option_lib.admissible(
            live_obs, self.ctx, stf, gscf, self.cgge, self.budget,
            egress_ok=lambda o, s: self._egress_ok(o, s, chunk, k_exec, jsse))
        o, why = self.socr.select(live_obs, adm, now, self.budget)
        self.ledger.append_recovery_trigger(reason, live_obs, why)
        if o is None:
            return self._v11_abort(chunk, k_exec, jsse)
        return ("recover", o)


def execute_certified_option(o, state, guards, budget, tick):
    """选项管执行：v11 守卫 + 接触快通道逐拍生效；唯一出口是 e_o。"""
    budget.enter(o)
    while not o.done(state):
        if budget.exhausted(o):
            return "egress"
        if guards.any_fail(state):          # 五检 + 接触快通道
            return "egress"
        q_cmd = guards.jsse.project(o.skill(state))   # 1kHz 投影不缺席
        execute_joint(q_cmd)
        tick()
    budget.leave(o)
    return "goal"

        current_chunk, k_exec, live_obs, stf, gscf, nrb, jsse, now)

    if verdict == "continue":
        q_cmd = jsse.project(current_chunk.joint_actions[k_exec])
        execute_joint(q_cmd)
    elif verdict == "recover":
        o = target
        outcome = execute_certified_option(
            o, live_obs, guards=Guards(stf, gscf, nrb, jsse, cgge),
            budget=chunker.budget, tick=control_tick)
        if outcome in ("egress", "timeout"):
            q_abort = jsse.map_abort(o.egress(live_obs))
            jsse.execute_abort_trajectory(q_abort)
        current_chunk = None
    else:  # abort
        jsse.execute_abort_trajectory(target)
        current_chunk = None

    # ---- 1kHz JSSE 投影独立硬实时线程，始终在环 ----
    # q_cmd = jsse.project(ik_solver(task_traj(t)))；选项执行也不绕过它。

    # ---- v11 继承路径 + ID ----
    C, spatial_cert, claims, metrics, rewards = M.inherited_v11_path(ctx)
    distiller.step(cycle_idx, ctx)
    return C, spatial_cert, claims, metrics, rewards
```

## 4. 推导

**引理 97（权威分离与安全单调性）**
设 v11 在状态 s 的认证可执行集为 A_11(s)（认证块 + v11 中止）。若每个 o∈O_cert 满足定义 573 的恢复安全不变式，且出口 e_o(s) 在 R_o 内始终为 v11 认证中止，则对任意评论家 Q（含随机/对抗 Q）：
(i) o*(s)∈Adm(s)∪{⊥}，且 Adm(s) 不含 Q（定义 574）；
(ii) 若 o*≠⊥，执行轨迹在 R_o(s) 内并于 ≤T_o 内终止于 e_o(s)∈A_11(s) 或目标态（目标态仍回到 v11 元控制器）；
(iii) 因此 v12 的任一完整轨迹可分解为「v11 认证段 → 认证选项管 → v11 认证段 → …」，其危险事件集 ⊆ v11 危险事件集；Q 只能改变已安全选项的顺序，不能使不可采纳选项变可采纳。
证明：对轨迹段数归纳。v11 段由 v11 引理 96 保证；选项段由定义 573 保证 R_o⊆C_q_safe 且出口可采纳；出口后回到 v11 段。Adm 的构造不读取 Q（定义 564/574），故 Q 无法扩权。∎

**引理 98（有界恢复的可用性增益与失败回退）**
在 GSCF 虚假低（正常场景 γ̂<γ_min）或三守护共失效导致重复中止的场景，若存在 o=OBSERVE_BACKOFF 满足 I_o，且恢复后 U_t^geo 重建概率 ≥1−ε_rec（E612 标定），则：
(i) 系统在 B_rec,max 内以 ≥1−ε_rec 恢复 v11 分块执行，否则在预算耗尽处执行 v11 中止；
(ii) 由于 P17，恢复时长 ≤B_max、链长 ≤N_max，K_eff 塌缩/急停延迟有界；
(iii) 恢复不改变 K_eff 门控（定义 539-v12 沿用 v11），故安全约束不放松。
结论：v12 把「立即中止」变为「有界恢复后仍可能中止」，可用性↑而安全集不变。∎

**引理 99（触觉独立性与滑移领先）**
设触觉/力测量独立于视觉/语义/几何通道（不同物理传感器、不同失效模式），s_slip 的检测延迟 ≤1 个触觉帧（5ms@200Hz），m_fc 在接触模型标定误差 ε_c 内可靠（E616）。则：
(i) 透明/反光/动态对象下视觉/几何可能虚假低或虚假高，但 m_fc、s_slip 仍给出独立判定；
(ii) s_slip 越过 τ_abort 时，200Hz 快通道先于 50Hz 五检（≥4×）与 5Hz 块边界（≥40×）触发；
(iii) 接触证书只能收缩/中止或选择接触类恢复选项，不能放宽 v11 的 ĝ_min/ê_max/β_GSCF（P18）。
证明：(i) 传感器独立性与定义 568–570；(ii) 频率比较；(iii) 定义 571 明确接触项只增证据。∎

**引理 100（接触落地中止等价）**
设 FK 标定误差 ≤ε_fk（E596），接触状态估计误差 ≤ε_c（E620），中止目标 p* 与 q_abort 满足 FK(q_abort)=p*±ε_fk。则：
(i) 若接触落地条件 c∈{PLACED,SECURED,RELEASED} 在 ε_c 内成立，则任务-接触联合中止等价：末端在 p*±ε_fk 内保持，且物体处于支撑/力封闭保持/安全释放之一，误差 ≤ε_c；
(ii) 若接触落地不可认证（目标下方有人、无支撑、m_fc<m_min），则该模式不可采纳，退回 v11 纯任务空间中止；
(iii) 因此接触落地是可选增强，失效时严格等价 v11。
证明：(i) 由定义 572 与两个误差界三角不等式；(ii) 由 Adm 过滤；(iii) 由 Level-0b。∎

**引理 101（离线 RL 的建议性边界）**
设离线数据由行为策略（含 v11 中止与全部认证选项）覆盖，Q_θ 用保守离线 RL（CQL/IQL）训练，集成方差 D、OOD 分数 O 用于中立化（定义 566）。则：
(i) 对任意 Q_θ 误差（包括无界误差），Adm 不变（定义 574），故安全性不受 Q 影响；
(ii) 当 D>δ_Q 或 O>τ_ood 或陈旧时输出 ⊥，行为退回 v11；
(iii) 保守惩罚只影响选项排序与收益（可用性/性能），不产生准入权；离线未覆盖选项的 Q 下界低，选择概率降低（不保证最优，但安全）。
证明：(i) 引理 97；(ii) 定义 565–566；(iii) CQL 的保守下界 + Adm 的 Q 无关性。∎

**引理 102（v12 联合保证：安全不降、可用性可测）**
条件于：v11 引理 96 的假设（ε_geo、ε_sra、ε_jsse、ε_β）成立，且每个被执行的选项 o 的证书前提（对象质量/摩擦/接触模型/运动学标定）在运行时仍成立（由 E616/E620/E625/E626 监测）。则：
(i) 安全性：P_v12(危险事件) ≤ P_v11(危险事件)（引理 97；新增模块只能收缩或等价）；
(ii) 可用性：A_v12 = 1 − P_v11(中止) + P(有界恢复成功) − P(恢复失败)，在 E612/E613 上报告；
(iii) 安全与可用性分离报告（定义 576），禁止用 A_v12 提升掩盖安全失败。
**注意**：若选项证书前提在监测间隔内突变，则 (i) 的前提失效——这正是本轮最大风险的来源，必须由 E625/E626 的在线前提监测与回退兜底。∎

## 8. 本轮最大风险

**一句话**：恢复选项的证书建立在「已知对象质量/摩擦/动力学 + 接触模型标定」的前提上，遇到未知可变形物体、摩擦突变或触觉被污染时，「已认证选项」可能在被信任的恢复轨迹上逐步耗尽安全边际；而 RL 的排序偏好又天然倾向「再试一次」而非中止，使 v12 的最大风险从「不会恢复」转成「恢复得太久、太自信」。
