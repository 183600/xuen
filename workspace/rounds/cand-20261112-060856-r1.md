# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；灵感循环第 6 轮；本轮灵感：「语义分割」×「用户共创」）

> 第 59 轮解决了「证据承诺如何落到执行层物理」：BUQ 辨识、ERTC 契约、EEIS 编译、CLEP 闭环、PCE+++ 四预算。但它仍默认了两件事：其一，**世界以「离散区域/检查点」为单位**——证据、信念、风险都挂在 `cp.region` 上，区域内部被当成同质整体；其二，**用户只在「同意/拒绝」这一维出现**——用户是安全门的「最后签字人」，而不是语义与风险定义的共同作者。本轮两个灵感精准击穿这两条隐含假设：**语义分割**告诉我们，真实世界的可接触性/可通行性是**逐像素/逐体素的稠密场**，危险往往藏在**边界**上，而不是藏在区域标签里；**用户共创**告诉我们，类别本体、风险偏好、证据门槛本身就是**被人共同定义的**，用户不是被询问的旁观者，而是**会提交、修订、回滚语义契约的共同作者**。本轮核心命题：**「把离散区域证据升级为带共形风险控制的稠密语义证据场；把用户从『签字人』升级为『本体与风险契约的共同作者』，同时用单向安全律钉死共创不得替代物理证据」**。

核心矛盾：
- **H32（离散-稠密鸿沟·边界盲区）**：第 59 轮的证据门以「区域」为最小单位，安全论证是 `region → safe/unsafe` 的离散判定；但语义分割的误差几乎全部集中在**类别边界**——台阶边缘、玻璃与地面交界、软垫与硬地过渡。一个区域 95% 像素正确、5% 边界像素错误，恰好可能是脚掌接触点所在。**「区域准确率」是对安全最不敏感的平均指标**；不做**边界加权 + 区域级风险上界**，稠密感知再强也只是「平均好看」。
- **H33（本体漂移·语义陈旧）**：用户共创让类别、风险标签、证据门槛可持续演化，但过去的探针/承诺证据都被打上了旧本体的语义。若「地毯」被用户从『可通行软表面』改判为『缠绕风险』，昨天所有关于地毯的 `EV-probe*/EV-exec` 的**语义解释**瞬间失效。**证据有物理年龄（第 59 轮 τ_evidence），也有语义版本（τ_sem）**；没有版本钉扎与再接地，系统会拿旧世界的证据为新世界的行动背书。
- **H34（共创越权·价值/事实混淆）**：用户共创最容易犯的错不是「说错类别」，而是**把价值偏好伪装成物理事实**（「这块地我觉得能走」）。若系统把用户标注当作与探针同权的观测，就会用「用户的乐观」抵消「物理的危险」。同时，共创还会引入**责任扩散**与**偏好捕获**：越常参与的用户，其偏好越可能被系统悄悄内化为「安全标准」。必须设计**非对称共创律**：共创可以自由**收紧**约束，但**放松**约束必须由物理证据背书。

## 0. 直觉与动机

**灵感 1（语义分割 → 稠密语义证据场 DSEF）**
直觉：机器人脚下不是「一块名叫地板的物体」，而是一张**逐格标注的可接触性图**：每个格子有类别分布、有可接触/可通行连续分数、有到最近语义边界的距离、有「我到底看清了没有」的认知不确定性。语义分割的三个特性直接改写证据层：**(a) 稠密性**——每个未访问格子也有先验信念（不再是「未观测=未知的黑箱」，而是「有先验+有不确定性的场」）；**(b) 边界敏感**——误差集中在边界，安全裕度必须按到边界距离加权膨胀/收缩；**(c) 开放词表/可提示**——类别不是预训练封闭集，用户可以用文字/点/框提示「新增：融雪盐渍区」「这是不可踩的电缆槽」。于是证据的最小承载单元从 `region` 变为 `cell`，区域证据变成稠密场的**聚合泛函**。

**灵感 2（用户共创 → 共创本体 CO）**
直觉：用户共创不是「多问几个 yes/no」，而是**共同编写系统的语义契约**：用户定义类别、给类别挂风险标签、规定「什么证据才算够」、还能撤销/合并/拆分类别。形式化上，本体 O 是一个**带版本的偏序类别图**，每次共创提交是一次 `commit(ΔO)`，带作者、权限、理由、时戳；证据必须**钉扎到本体版本**。关键区分：**事实性标签**（「这是玻璃」）可被探针证伪，必须物理背书；**偏好性标签**（「我希望你绕开这里」）是约束而非真理，只能让行为更保守。共创因此是一条**单向安全通道**：加约束永远允许，减约束必须过物理证据门。

**灵感 3（语义分割 × 用户共创 → 稠密-共创闭环 DSCL）**
直觉：用户共创与语义分割天然互补——用户最擅长补的恰好是模型最不确定的地方（新类别、边界歧义、价值取舍），而模型最擅长的是把用户的稀疏提示**稠密传播**并给出**校准的不确定性**。于是形成一个三环闭环：**用户 ↔ 本体**（共创提交与再接地）、**稠密场 ↔ 区域证据**（语义提升算子）、**语义 ↔ 执行**（类别先验→环境阻抗先验→EEIS 编译）。用户标注不是「额外数据」，而是**主动学习/主动共创的查询结果**，其价值由语义风险下降与用户注意力成本共同决定。

**灵感 4（共形风险控制 → 区域级语义安全保证 CRCS）**
直觉：逐像素共形预测的联合覆盖率在百万像素上几乎必然失效，且安全并不需要「每个像素都对」。真正需要的是：**安全关键区域的加权误分割面积期望 ≤ α_sem**。用共形风险控制（conformal risk control）校准一个阈值 λ，使 `E[L_safe(S_λ,Y)] ≤ α_sem` 以高概率成立；再用 Markov/尾部界把「期望」提升为「区域级误分割比例上界」，从而让第 59 轮的离散证据门重新获得**可证明的稠密支撑**。边界加权 `w(x)` 让「差一点踩到边缘」的代价显式进入风险预算。

**灵感 5（共创预算与语义债务 → PCE++++）**
直觉：用户注意力是最稀缺的资源，共创不能无限索取。定义 **共创预算 B_co**（提问次数/时长/信任额度）与 **语义债务 D_sem**（被推迟的类别歧义按风险加权的未决量）。VOI 里显式扣除 `attention_cost` 与 `trust_cost`；当 D_sem 超阈值，系统不再「边问边冒险」，而是**把歧义区一律按不安全处理并保守停**。这把「问用户」从免费午餐变成与探针/微调/执行并列的**第四类资源**。

## 1. 形式化定义（增量：定义 153–160）

**定义 153（稠密语义证据场 DSEF）** 直觉：给每个格子一个「是什么 + 能不能碰 + 边界多远 + 有多不确定」的完整描述。形式化：单元集 X（体素/表面片/像素反投影），场 `S = {s_x}_{x∈X}`，`s_x = (p_x ∈ Δ^{C-1}, a_x ∈ [0,1], d_x ∈ ℝ_{≥0}, m_x ∈ {0,1}, u^a_x, u^e_x, prov_x)`：`p_x` 类别分布；`a_x` 可接触/可通行连续分数；`d_x` 到最近语义边界的测地距离；`m_x` 支撑掩码（是否被观测且未被遮挡）；`u^a_x=H(p_x)` 偶然不确定性；`u^e_x` 认知不确定性（深度集成/ MC-dropout 的预测方差或互信息）；`prov_x` 提示来源（用户提示/开放词表模型/历史接触）。**闭世界安全默认**：`m_x=0 ⇒ a_x:=0`（未观测永不判安全）。稠密场的区域聚合 `Λ(S,r) = {s_x : x∈r}` 是后续语义提升算子的输入。

**定义 154（共形风险控制分割 CRCS）** 直觉：不追求逐像素全覆盖，而是控制「安全关键区域内被错分的加权面积」的期望。形式化：对阈值 λ 定义集合预测器 `S_λ(x)={c : p_x(c) ≥ 1−λ}`（或按累计概率取最小集）。安全关键损失
```
L_safe(S_λ,Y) = ( Σ_{x∈X_crit} w(x)·1[Y_x ∉ S_λ(x)] ) / ( Σ_{x∈X_crit} w(x) )
w(x) = 1 + κ_b·exp(−d_x² / (2σ_b²))·1[m_x=1]
```
其中 `X_crit` 是「其标签会改变步态/接触选择」的单元集（由风险模型支撑集给出），`κ_b` 为边界加权强度。在可交换校准集 `D_cal` 上按共形风险控制选
```
λ̂ = inf{ λ : (n/(n+1))·L̂_safe(λ) + B/(n+1) ≤ α_sem }，B=1
```
保证 `P( E[L_safe(S_λ̂,Y)] ≤ α_sem ) ≥ 1−δ_sem`。再由 Markov：`P( L_safe > α_sem/δ_sem ) ≤ δ_sem`，得到**区域级误分割比例上界** `ε_r := α_sem/δ_sem`。开放词表新类别在获得 `n_min` 个校准样本前，一律进入「未校准类别」分支，其 `α_sem` 取最保守类别的上界（不得插值）。

**定义 155（语义提升算子 SLO/Λ↑）** 直觉：把「每个格子的安全」谨慎地折算为「这个区域能不能作为证据门输入」。形式化：对区域 r，令 `A_r={x∈r : a_x ≥ a_min ∧ m_x=1}` 为预测可接触支撑。给定 CRCS 区域界 `ε_r`（定义 154），定义安全面积下界
```
safe_area_lb(r) = (1 − ε_r)·|A_r| / |A_r ∪ U_r|
```
其中 `U_r` 为区域内未观测/不确定超标单元数（`u^e_x>u_max`）。区域证据
```
Λ↑(S,r) = SAFE      if safe_area_lb(r) ≥ 1−α_r ∧ U_r=∅ ∧ 类别已校准
           UNSAFE    if safe_area_lb(r) <  1−α_r ∧ 存在不可接受类别
           AMBIGUOUS otherwise
```
`SAFE` 的语义是「以概率 ≥1−δ_sem，该区域内真实安全可接触面积占比 ≥1−α_r」，而不是「区域标签正确」。`AMBIGUOUS` 只能走「再观测/共创询问/保守绕行」三条路，**不得**直接送入承诺。

**定义 156（共创本体 CO 与语义钉扎）** 直觉：本体像代码仓库，用户的每次改判都是一次带作者与理由的提交；证据必须记住「我当时是按哪版本体解释的」。形式化：`O = (C, ≼, risk: C→RiskTag, req: C→EvReq, kind: C→{factual,preference}, prov)`，`C` 类别集、`≼` 子类偏序、`risk` 风险标签、`req` 证据门槛、`kind` 事实/偏好二分、`prov` 溯源。共创提交 `ΔO = (op∈{add,modify,merge,split,retag,revoke}, c, payload, author, auth, rationale, ts)`，按 DAG 组织、版本号单增、支持回滚。每条证据 `e` 钉扎 `v_e = version(O_e)`。语义年龄 `τ_sem(e) = relevant_change_distance(v_e, v_O)`（沿 DAG 上 risk/req/kind 发生变化的提交数）。再接地算子
```
RG(e, ΔO) ∈ {UNCHANGED, REINTERPRET, INVALIDATE, REPROBE}
```
仅当 `ΔO` 触及 `e` 所属类别或其祖先的 risk/req/kind 时才可能 `≠UNCHANGED`；`kind` 由 factual→preference 时旧证据降级为「仅约束」；`risk` 上调时旧 `SAFE` 证据强制 `REPROBE`。

**定义 157（共创证据 EV-co 与非对称共创律）** 直觉：用户的话要分「事实主张」和「价值主张」，前者要物理背书，后者可以直接变成约束，但不能变成「安全证明」。形式化：
```
EV-co = (commit_id, c, kind, provenance, auth, corrob, value_fact_split, v_O, τ_sem)
```
规则（**共创单向安全律**）：
1. `kind=preference` 的 EV-co **只能添加约束**（禁入/降速/增大裕度），永远不能用于满足 `EV-probe*/EV-xmodal/EV-exec/EV-human` 的佐证要求；
2. `kind=factual` 的 EV-co 只有在被至少一个物理探针/接触结果佐证后，才可从「候选」转为「可用」；未佐证的事实仅在**收紧**方向可用；
3. EV-co 作为第 6 模态只参与**对账分歧** `D⁺⁺` 与**本体投票**，不进入任何「减少探针」的证据门；
4. `auth` 不足或存在利益冲突的提交进入隔离区，不改变 `risk/req`，仅记录为「建议」；
5. 任一 `INVALIDATE/REPROBE` 未完成时，受影响区域视为 `AMBIGUOUS`，安全动作集合收缩。

**定义 158（稠密-共创闭环 DSCL）** 直觉：一次「看—问—定—碰—再标」的完整回合。形式化算子
```
DSCL(M, cp, δ_f^req)：
 ① DSEF: S ← update_field(perception, user_prompts, prior_map); m_x=0 ⇒ a_x=0
 ② CRCS: λ̂, ε_r ← conformal_risk_control(D_cal, α_sem, δ_sem); 新类别走保守分支
 ③ SLO:  r_ev ← Λ↑(S, cp.region)
       if r_ev = UNSAFE: return CONSERVATIVE_STOP
       if r_ev = AMBIGUOUS:
           q* ← argmax_q VOI_co(q; S, B_co)       # 见定义 159
           if q* ≠ ∅: EV-co ← ask_user(q*); O ← commit(EV-co); goto ②
           else: return CONSERVATIVE_STOP

 ⑤ EEIS: Z_env ← class_conditioned_prior(S, fused, b_r)
          K_safe, Cert ← compile_impedance(δ_f^req, fused, ξ_exec, Z_env)
       if K_safe=∅: return CONSERVATIVE_STOP

终止性由 `B_co` 与 `k_probes` 双预算保证；`AMBIGUOUS` 且预算耗尽只能是保守停/绕行，**绝不承诺**。

**定义 159（共创预算 B_co、语义债务 D_sem 与 PCE++++）** 直觉：问用户要花「注意力」和「信任」，未决歧义是一笔会利滚利的债。形式化：
```
B_co = (queries_left, attention_left, trust_left)
D_sem(r) = Σ_{x∈r, m_x=1} u^e_x · risk(x) · 1[类别未校准 ∨ τ_sem>τ_max]
VOI_co(q) = E[ΔD_sem(q) + ΔRisk(q)] − λ_attn·cost_attn(q) − λ_trust·cost_trust(q)

降级：`D_sem > θ_debt` ⇒ 歧义区按 UNSAFE 处理并进入保守停；`trust_left<0` ⇒ 冻结共创提交（只读模式），系统退回纯物理证据策略。

### IP-152 DSEF（稠密语义证据场）

```python
class DenseSemanticField:
    def __init__(self, X, num_classes, open_vocab=True):
        self.X = X                          # 单元索引（体素/表面片）
        self.p = UniformPrior(X, num_classes)   # 类别分布
        self.a = zeros(X)                   # 可接触/可通行分数
        self.d = inf_like(X)                # 到语义边界测地距离
        self.m = zeros(X, dtype=bool)       # 支撑掩码
        self.ua = entropy(self.p)           # 偶然不确定性
        self.ue = ones(X)                   # 认知不确定性
        self.prov = {}                      # 单元 -> 提示/模型来源

    def update_from_perception(self, obs, ensemble):
        # 融合 RGB-D / 触觉 / 先验图；ensemble 给 epistemic
        self.p = bayes_fuse(self.p, obs.label_dist)
        self.ue = ensemble_disagreement(ensemble)          # 互信息/方差
        self.m = obs.visible & ~obs.occluded
        self.d = geodesic_distance_to_boundary(self.p, self.m)
        # 可接触分数：开放词表可提示，但未观测强制为 0
        self.a = support_score(self.p, self.d, self.ue)
        self.a[~self.m] = 0.0
        self.ua = entropy(self.p)

    def apply_user_prompt(self, prompt, mask_proposal, user_id, v_O):
        # 用户文字/点/框提示 → 候选 mask；不直接改真值，只改先验与建议
        for x in mask_proposal.support:
            self.p[x] = bayes_soft_prior(self.p[x], prompt.category_prior, w=PROMPT_W)
            self.prov[x] = ("user_prompt", user_id, prompt.id, v_O)
        self.d = geodesic_distance_to_boundary(self.p, self.m)

    def contact_backproject(self, telemetry, cert):
        # 接触点 = 真实物理标签，强制覆盖局部场并加入校准集
        for x, y_true in telemetry.labelled_contacts:
            self.p[x] = one_hot(y_true)
            self.m[x] = True
            self.ue[x] = 0.0
            self.prov[x] = ("contact", cert.version)
```

### IP-153 CRCS（共形风险控制分割）

```python
def conformal_risk_control(D_cal, alpha_sem, delta_sem, compute_L_safe):
    n = len(D_cal)
    lambdas = sorted({1 - q for q in np.linspace(0, 1, 1001)})
    for lam in lambdas:
        losses = [compute_L_safe(lam, sample) for sample in D_cal]
        R_hat = np.mean(losses)
        # Angelopoulos et al. 共形风险控制上界
        if (n/(n+1)) * R_hat + 1.0/(n+1) <= alpha_sem:
            lam_hat = lam
            break
    else:
        lam_hat = lambdas[-1]
    eps_r = min(1.0, alpha_sem / delta_sem)   # Markov 尾部界
    return lam_hat, eps_r

def compute_L_safe(lam, sample, kappa_b=3.0, sigma_b=0.02):
    p, m, d, Y, X_crit = sample
    S_lam = {c for c, pc in enumerate(p) if pc >= 1 - lam}
    num, den = 0.0, 0.0
    for x in X_crit:
        w = 1.0
        if m[x]:
            w += kappa_b * np.exp(-(d[x]**2) / (2 * sigma_b**2))
        num += w * (1.0 if Y[x] not in S_lam else 0.0)
        den += w
    return num / max(den, 1e-9)
```

### IP-152 DSEF（稠密语义场）

```python
class DenseSemanticField:
    def __init__(self, X, num_classes):
        self.X = X
        self.p = UniformPrior(X, num_classes)
        self.a = zeros(X); self.d = inf_like(X)
        self.m = zeros(X, dtype=bool)
        self.ua = entropy(self.p); self.ue = ones(X)
        self.prov = {}

    def update_from_perception(self, obs, ensemble):
        self.p = bayes_fuse(self.p, obs.label_dist)
        self.ue = ensemble_disagreement(ensemble)
        self.m = obs.visible & ~obs.occluded
        self.d = geodesic_distance_to_boundary(self.p, self.m)
        self.a = support_score(self.p, self.d, self.ue)
        self.a[~self.m] = 0.0                  # 未观测永不安全
        self.ua = entropy(self.p)

    def apply_user_prompt(self, prompt, mask, user_id, v_O):
        for x in mask.support:
            self.p[x] = bayes_soft_prior(self.p[x], prompt.category_prior, w=PROMPT_W)
            self.prov[x] = ("user_prompt", user_id, prompt.id, v_O)
        self.d = geodesic_distance_to_boundary(self.p, self.m)

    def contact_backproject(self, telemetry, cert):
        for x, y_true in telemetry.labelled_contacts:
            self.p[x] = one_hot(y_true); self.m[x] = True
            self.ue[x] = 0.0; self.prov[x] = ("contact", cert.version)
```

### IP-153 CRCS（共形风险控制）

```python
def conformal_risk_control(D_cal, alpha_sem, delta_sem, compute_L_safe):
    n = len(D_cal)
    for lam in np.linspace(0, 1, 1001):
        R_hat = np.mean([compute_L_safe(lam, s) for s in D_cal])
        if (n/(n+1))*R_hat + 1.0/(n+1) <= alpha_sem:
            return lam, min(1.0, alpha_sem/delta_sem)
    return 1.0, min(1.0, alpha_sem/delta_sem)

def compute_L_safe(lam, sample, kappa_b=3.0, sigma_b=0.02):
    p, m, d, Y, X_crit = sample
    S_lam = {c for c, pc in enumerate(p) if pc >= 1 - lam}
    num = den = 0.0
    for x in X_crit:
        w = 1.0 + (kappa_b*np.exp(-d[x]**2/(2*sigma_b**2)) if m[x] else 0.0)
        num += w * (Y[x] not in S_lam); den += w
    return num / max(den, 1e-9)
```

### IP-154 SLO（语义提升）

```python
def semantic_lift(field, region, eps_r, alpha_r, u_max, a_min):
    cells = field.X[region]
    A = [x for x in cells if field.a[x] >= a_min and field.m[x]]
    U = [x for x in cells if (not field.m[x]) or field.ue[x] > u_max]
    if not A:
        return 'UNSAFE'
    safe_lb = (1 - eps_r) * len(A) / max(len(A) + len(U), 1)
    if U:
        return 'AMBIGUOUS'
    if safe_lb >= 1 - alpha_r and all(field.is_calibrated(field.p[x]) for x in A):
        return 'SAFE'
    return 'UNSAFE' if has_unacceptable_class(field, A) else 'AMBIGUOUS'
```

### IP-155 CO（共创本体与再接地）

```python
class CoCreatedOntology:
    def __init__(self):
        self.dag = OntologyDAG(); self.version = 0; self.quarantine = []

    def commit(self, delta, author, auth, rationale):
        if not self.authorized(author, auth, delta) or \
           self.conflicts_with_locked_safety(delta):
            self.quarantine.append((delta, author, "rejected"))
            return self.version
        self.version = self.dag.apply(delta, author, rationale)
        return self.version

    def reground(self, evidence, v_old, v_new):
        touched = self.dag.relevant_changes(v_old, v_new, fields={'risk','req','kind'})
        if not touched & self.ancestors(evidence.category):
            return 'UNCHANGED'
        if evidence.kind == 'factual' and self.kind(evidence.category) == 'preference':
            return 'REINTERPRET'
        if self.risk(evidence.category) > evidence.risk_at_use or \
           self.req_changed(evidence.category):
            return 'REPROBE'
        return 'UNCHANGED'

    def to_constraint(self, ev_co):
        if ev_co.kind != 'preference':
            return None
        return Constraint(region=ev_co.region, forbid=ev_co.forbid,
                          speed_cap=min(1.0, ev_co.speed_cap),
                          margin_inflate=max(0.0, ev_co.margin_inflate))
```

### IP-156 EV-co 与 XMC++（共创仅对账）

```python
def xmodal_fuse_pp(M, region, field, ev_co):
    for m in ['vis','tap','prop','acou','exec']:
        if m in M.b[region]:
            M.b[region][m] = bayes_update(M.b[region][m], M.likelihood[region][m], w=M.rho[m])
    co_lik = co_reconciliation_likelihood(ev_co)     # 极宽 + 价值项
    M.b[region]['co'] = bayes_update(M.b[region]['co'], co_lik, w=M.rho_co)
    fused = Fuse({**M.b[region], 'co': M.b[region]['co']},
                 {**M.rho, 'co': M.rho_co})
    return M, fused, disagreement_pp(M.b[region], M.rho_co, ev_co)

def co_reconciliation_likelihood(ev_co):
    if ev_co is None:
        return Gaussian(mean=0, cov=1e9)
    if ev_co.kind == 'factual' and not ev_co.corroborated:
        return Gaussian(mean=-BIAS_TIGHTEN, cov=1e6)  # 未佐证事实只可收紧
    return Gaussian(mean=0, cov=1e6)                  # 仅对账

def apply_co_constraints(route, ev_co_log):
    for ev in ev_co_log:
        con = Constraint.from_co(ev)
        if con:
            route = restrict(route, con)              # 只会更保守
    return route
```

## 3. 复杂度与正确性

**正确性定理（Dense Semantic Grounding Soundness, DSGS）**
假设 A22–A55 成立；**(A56)** DSEF 校准集可交换，CRCS 得 `P(E[L_safe]≤α_sem)≥1−δ_sem`，未校准新类别走最保守上界；**(A57)** SLO 提升音完备：`SAFE` 必伴随 `U_r=∅`、类别校准、`safe_area_lb≥1−α_r`，未观测单元永不入安全支撑；**(A58)** CO 版本化音完备：证据钉扎本体版本，`RG` 覆盖 risk/req/kind 相关变更，`τ_sem` 有界；**(A59)** 非对称共创律：EV-co 只能添加/收紧约束，未佐证事实不得放松，EV-co 不进任何佐证集，偏好不被内化为物理真值；**(A60)** `B_co`/`D_sem` 单调诚实、超阈值即保守停、`VOI_co` 诚实上界成本。则：

1. **稠密语义校准健全性**：`SAFE` 区域真实安全可接触面积 ≥1−α_r，失败概率 ≤δ_sem+δ_sem_stale+δ_co。
2. **区域级语义风险上界**：证据门接受区域内安全关键加权误分割 ≤α_sem/δ_sem，概率 ≥1−δ_sem（与第 59 轮执行界叠加）。
3. **共创单向安全性**：任意共创提交序列只能收缩 `A_safe`；无物理证据时不存在使 `A_safe` 扩大的序列。
4. **语义钉扎与再接地**：`τ_sem≤τ_max` 的证据才可用；risk 上调后旧 SAFE 证据在 REPROBE 前不被采信，残余风险 ≤δ_sem_stale。
5. **本体-执行一致性**：类别正确时类别条件先验 `Z_env(class)` 覆盖真实环境阻抗，EEIS 健全性（第 59 轮定理 3）继续成立。
6. **终止性**：DSCL 在 `k_co+k_probes+k_cons+k_ft+k_ux+k_exec` 内终止于 `{承诺(Cert∧r_ev=SAFE), 绕行, 降档, L2 协商, 语义不安全停, 语义债务停}`。
7. **部署界**（对检查点取联合界）：
