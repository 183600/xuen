# 第 66 轮（承接第 65 轮「VISTA 视觉知情时序归因」IP-214~223；灵感循环第 1 轮；本轮灵感：「用户画像」×「传感器融合」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述的最大风险一针见血：**故障不在有限假设集内、且视觉与几何共享同一个分布外失效源时，FIR 会把未知复合故障强行归入最近假设，只膨胀错误的球；系统反而因"已经归因"而更自信地继续执行。** 本轮不再增加一个物理模态，而是追问一个更上游、也更危险的问题：VISTA 始终默认「**目标函数、风险偏好与成功判据是给定且平稳的**」。可一旦机器人进入辅助、遥操作、协作或人机共驾场景，**"什么叫安全、什么叫成功"本身就是被建模的人**——它由用户的意图、技能、风险容忍、信任与身体/认知状态定义，而且随机器人的行为而改变。本轮核心命题是：
>
> **把「用户画像」从一张静态偏好表，升级为一个可错的、非平稳的、且与机器人共同演化的"先验传感器"：用多模态传感器融合在线维护它的后验与可靠性，把画像不确定性显式接入 VISTA 的故障归因、风险预算与安全证书；同时用一条与画像无关的硬安全地板，隔离"用户偏好"与"物理安全"，使系统既能个性化，又不会被自己推断出的偏好反向挟持。**

## 0. 直觉与动机

**灵感 1（用户画像 → 被建模的不只是环境，还有"谁定义安全与成功"）**
直觉：VISTA 把风险预算 α_chunk、力限 f_lim、成功判据都当作外部常数。但在真实人机系统里，这些量是**用户画像的函数**：一个熟练用户能接受更快的接近速度，一个术后患者必须更保守；用户此刻是"想让你递水"还是"想让你停手"，只能从不完整的行为与生理证据中推断。更尖锐的是，画像偏差不是普通传感器偏差——**它偏的是损失函数本身**：若系统低估了用户的恐惧或高估了用户的技能，它会在"用户其实很安全"的判断下做出用户无法承受的动作，而所有下游证书都会为这个错误目标背书。因此画像必须被当作**一等的不确定性来源**，而不是一个可选的个性化插件。

**灵感 2（传感器融合 → 画像是多模态潜变量，不是一张标签；而人是一个"会反作用"的模态）**
直觉：可靠的画像只能来自异构证据的融合：机器人自身通道（视觉、力、本体感觉）提供"用户正把系统带向哪"的客观足迹；行为通道（操纵杆、纠正、接管、注视、停顿）提供"用户想做什么"的意图证据；生理通道（心率、皮电、肌电、呼吸）提供"用户承受多少"的负荷证据；上下文通道（任务阶段、时间、历史）提供先验。融合的关键不是把特征拼起来，而是估计一个**共享潜变量 z_t**，并给每个模态一个**可在线校准的可靠性 r_k(t)**。但人这个模态与相机有本质区别：(i) 它的"噪声"是**策略性**的——用户会因不信任机器人而过度纠正，或因过度信任而放手；(ii) 它是**非平稳**的——技能、疲劳、意图会漂移；(iii) 它可能被机器人**诱导**——机器人改变行为会改变用户的行为，从而改变画像。这三点让"用户画像 × 传感器融合"不再是普通的贝叶斯融合，而是一个**闭环、非交换、可被操纵的估计问题**。

**灵感 3（合流 → 共适应破坏可交换性，这是本轮真正的数学支点）**
直觉：VISTA 的所有 conformal 覆盖与归因集中性都默默依赖样本可交换性。可画像系统是一个反馈回路：机器人依据 ẑ_t 改变策略 π_t，用户依据 π_t 改变行为与偏好，行为又改变 ẑ_{t+1}。于是校准集与部署集不再同分布，"1−α 覆盖"名不副实；更糟的是，"用户变了 / 传感器坏了 / 机器人把用户带偏了"三者在这条回路里**不可辨识**。本轮因此引入两个硬约束：**画像条件可交换性**（只在给定画像轨迹与策略下谈覆盖，并显式扣除漂移项）与**共适应收缩条件**（机器人对画像的适应增益必须足够小，使联合动力系统收敛而非振荡）。没有这两条，个性化越强，系统越不安全，而且越"自信"。

**灵感 4（架构合流 → PERSONA：Profile-Enabled Risk-aware Sensing & Online Nonstationarity Attribution）**
闭环：VISTA 语义链 → **UP 双层画像**（硬约束 / 软偏好分离）→ **MF 多模态融合**（可靠性加权潜变量后验）→ **PCA 画像条件归因**（把"用户变化"加入故障假设，与机器人故障解耦）→ **RSP 风险语义投影**（把主观偏好映射为工程预算，但被硬地板上封顶）→ **UAI 用户感知主动询问**（物理探针 / 询问 / 被动等待 / 保守回退的联合决策）→ **CSP-P 画像条件规划**（只在用户能力包络与授权集内选技能）→ **PSC 画像条件证书**（对画像后验与偏好模糊集取最坏）→ 只执行认证前缀 → 实时残差采集与分级早停 → **CAD 共适应检测**（漂移/操纵 → 冻结画像、扩球、交还控制）。第 65 轮把「接触」拆成前/中/后，第 66 轮把「人」拆成**声明层/推断层/被诱导层**，并让每一层都对应一个可归因的失效源与一条可消费的风险预算。

**灵感 5（VISTA 组件的原位升级）**
- **FIR → PCA**：故障假设增 `H_user`（意图/技能误估）、`H_prof`（画像模型错/过拟合）、`H_adapt`（共适应漂移）、`H_trust`（信任错配）、`H_hard`（硬约束违反，绕过归因直接停）；签名增画像残差、纠正率、接管率、行为-生理一致性。
- **AFA → UAI**：探针集从物理动作扩到「询问/确认/示范/等待」，目标从"最大化故障互信息"升级为"单位打扰成本的信息价值"，并允许"不探测、先保守行动"。
- **CSC → PSC**：证书从单块前缀升级为对画像后验、偏好模糊集与硬约束同时取最坏的画像条件前缀；新增 safety_floor_id、consent_hash、drift_stat。
- **RSC-V → RSC-P**：不确定球增 r_prof，且拆成 r_prof,data（认知）与 r_prof,drift（非平稳）；只膨胀被归因者，共适应时冻结适应而非总膨胀。
- **WCV-V → WCV-P**：搜索域增画像授权约束 P 与偏好模糊集 U(α_u)；归因模糊时对"画像边缘化尾部"取最坏。
- **CSP-V → CSP-P**：技能绑定能力包络、授权集与典型画像签名；画像不确定时插入 `confirm` / `profile_probe` 元技能。
- **AIC-V → AIC-P**：干扰集增画像投毒、生理伪造、偏好操纵、共适应漂移、虚假授权；显式建模"机器人自身行为是共因"。
- **OLP / DIR / SSB**：证据融合增画像残差与漂移统计；画像更新只在语义流、只写带版本号的软层，实时流不写。
- **J_vista → J_persona**：证书增 profile_posterior、profile_entropy、profile_version、consent_hash、α_task、safety_floor_id、drift_stat、manipulation_flag、privacy_budget、aic_p_ver。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（PERSONA 闭环）**：PERSONA = (VISTA, UP, MF, PCA, RSP, UAI, CSP-P, PSC, CAD, RSC-P, WCV-P, AIC-P, J_persona)。定位：VISTA 的「用户画像 × 多模态融合 × 共适应安全」升级。不变式：**画像推断、融合、风险语义投影、共适应检测、证书只在语义流；实时流只读一个带版本号的画像快照、只执行已提交前缀、只做分级早停；零学习写、零画像写、零预算写；硬约束层永不被学习覆盖。**
- **定义 234（双层画像：声明层与推断层）**：画像 z_t=(z_hard, z_soft)。z_hard=(C, h_max, f_max, a_forbid, m_med) 为用户显式声明与合规约束（授权集 C、速度/力上限、禁忌动作、医疗禁忌），**只能由用户显式修改并留审计，任何学习与推断都不得覆盖**。z_soft=(g,s,α_u,τ,λ)∈Z_soft 为软画像（意图分布 g、技能 s、风险容忍 α_u、信任 τ、身心负荷 λ）。只有 z_soft 可在线更新。硬/软分离 = 安全/性能分离：**安全地板只依赖 z_hard 与物理，不依赖 z_soft。**
- **定义 235（多模态画像融合 MF）**：模态 k∈{robot-proprio, robot-vision, robot-force, human-behavior, human-physio, context}，观测 o_{k,t} 经时间戳对齐映射到公共时钟。融合为共享潜变量的可靠性加权因子图：
  p(z_t|o_{1:K,1:t}) ∝ p(z_{t-1}|o_{1:t-1})·p(z_t|z_{t-1})·Π_k [p(o_{k,t}|z_t)]^{r_k(t)}，
  似然用 Student-t/Huber 以抗离群；缺失模态按边缘化处理（不可用 ≠ 否定）。可靠性 r_k(t)∈[0,1] 由创新一致性在线估计并**截断上下界**，防止单一模态独裁：
  r_k(t) ∝ exp(−‖o_{k,t}−ĥ_k(z_t)‖²_{Σ_k⁻¹}/2)，Σ_k r_k=1，r_k∈[r_min,r_max]。
  与普通"特征拼接"的区别：融合对象是**画像潜变量**；每个模态有自己的失效模式，模态失效独立性是鲁棒性的来源。
- **定义 236（画像预测残差、激励度与后验收缩）**：画像预测器 g_prof 给出 ẑ_{t+h|t}，残差 e_prof(t,h)=‖ẑ_{t+h|t}−z_{t+h}‖²_{Σ_z⁻¹}。画像可辨识度由用户选择的**激励度**决定：κ_prof=λ_min(I_prof)，I_prof 为行为通道对 z_soft 的 Fisher 信息。若 κ_prof<κ_min（用户只是被动接受、没有做出有区分度的选择），后验必须向群体先验收缩：
  p_t(z_soft) ← (1−γ)p_t(z_soft)+γ·p_pop(z_soft)，γ=clip((κ_min−κ_prof)/κ_min,0,1)。
  **没有激励就不许自信**——这是防止"从沉默中读出偏好"的第一道闸。
- **定义 237（画像条件可交换性与漂移）**：给定画像轨迹 z_{1:T} 与机器人策略 π 的条件分布，称校准集与部署集**画像条件可交换**。VISTA 的 split-conformal 覆盖只在此时成立。定义画像漂移
  D_prof = sup_{A} |P_cal(A|z_{1:T},π)−P_deploy(A|z_{1:T},π)|（可取 TV 或 MMD 的经验估计），
  则覆盖缺口满足 |P_deploy(e≤q)−(1−α)| ≤ 2D_prof + 有限样本项。**画像越个性化，D_prof 越可能变大；必须显式花钱重校准。**
- **定义 238（共适应动力学与收缩条件）**：用户响应 z_{t+1}=U(z_t,π_t,ξ_t)，机器人适应 π_{t+1}=A(π_t,ẑ_t)。线性化得到联合 Jacobian J=J_U·J_A。若谱半径 ρ(J)<1，联合系统**共适应收缩**到唯一稳定不动点，信任与画像不振荡；若 ρ(J)≥1，出现信任振荡、偏好螺旋或"越纠正越保守"的负反馈。定义画像-Lipschitz 常数 L_π=sup_ẑ‖∂π/∂ẑ‖；设计规则：**L_π·L_U ≤ ρ_target<1**。个性化不是越强越好，而是有一个由稳定性给出的上界。
- **定义 239（画像条件故障假设与 PCA）**：ℋ_P = ℋ_VISTA ∪ {H_user, H_prof, H_adapt, H_trust, H_hard}。签名 ρ_P ∈ ℝ^{15} ⊕ ℝ^{d_h} 在 VISTA 三阶段签名上增加人因通道：ē_prof、纠正率、接管率、行为-生理一致性、授权违反计数。归因 P(H|ρ_P)∝p(ρ_P|H)P(H)，输出（故障类型，来源层级/模态）。**关键解耦：用户行为变化默认归 H_user/H_adapt，不得默认归 H_force 或 H_geo；H_hard 一经触发绕过归因直接安全停。**
- **定义 240（风险语义投影 RSP）**：主观风险容忍 α_u 经单调映射 T_θ 投影为工程违反预算。由于 α_u 只能被有误差地估计，取偏好模糊集 U(α_u)=[α_u−δ_u,α_u+δ_u]（由后验分位数给出）并取最坏：
  α_task = min( α_safe_max(z_hard), max_{α∈U(α_u)} T_θ(α) )，
  要求 T_θ 单调不减、Lipschitz 有界、且**上封顶恒为 α_safe_max**。于是：画像只能让系统更保守，或在硬地板之内更贴合用户；**绝不能因为"推断出用户更能承受风险"而越过物理安全线。**
- **定义 241（画像无关安全地板与不可操纵性）**：安全地板 𝔅=(α_safe_max, z_hard, 物理约束) 与 z_soft 无关。Valid(Cert) ⇒ 所有硬约束满足且长期违反率 ≤α_safe_max，**无论画像估计多错**。不可操纵性：定义机器人策略对用户偏好的因果影响
  M(π)=sup_{z_hard} |E[α_u|do(π),z_hard]−E[α_u|do(π_ref),z_hard]|；
  要求 M(π)≤ε_manip，或该影响能被"用户确实学到了任务信息"解释；否则置 `preference_manipulation`，冻结画像适应、切保守策略并请求用户显式确认。**偏好不是待优化的资源，而是待保护的权利。**
- **定义 242（画像条件安全证书 PSC）**：对块 A_t、前缀 k、画像后验可信集 Z_soft^cred 与偏好模糊集 U(α_u)，要求同时满足：(i) k≤m；(ii) ∀H∈supp_δ(post) 前 k 步 ρ_safe≥0；(iii) ∀z_soft∈Z_soft^cred, α_u∈U 的联合风险 ≤α_task；(iv) z_hard 硬约束满足；(v) profile_version、consent_hash、safety_floor_id、privacy_budget 均有效。输出 k*(A_t)、最小安全裕度与所用画像快照的哈希。**证书对画像误差鲁棒：它冻结的是"文件夹/硬地板"，而不是"某个画像点估计"。**
- **定义 243（RSC-P 画像知情球校准）**：维护 r_geo、r_force、r_model、r_prof 与 w_vis。r_prof²=r_prof,data²+r_prof,drift² 分别对应认知不确定与非平稳漂移。定向处置：H_user/H_prof→r_prof,data↑、后验收缩到群体先验；H_adapt→**冻结画像适应**、r_prof,drift↑、L_π↓；H_trust→重标定信任并更保守（不加速）；H_geo/H_force/H_model 沿用 VISTA 的定向膨胀。融合半径 r=√(r_geo²+r_force²+r_model²+r_prof²)。**共适应时膨胀的是漂移球，不是几何球。**
- **定义 244（WCV-P 画像-物理联合压缩）**：搜索/编译域
  B(φ̂,r) ∩ 𝒢(g) ∩ K(μ̂) ∩ ℱ(f_lim) ∩ 𝒱 ∩ P(𝔅, C, Z_soft^cred, U(α_u))，
  P 为画像约束：技能在能力包络内、动作在授权集内、偏好取模糊集最坏。CVaR 尾部 = 8 个物理最坏 + 4 个画像最坏；交集为空时**回退到画像无关的保守策略**（而非仅回退球），并置 `profile_conflict=True`。
- **定义 245（CSP-P 画像条件技能规划）**：在 VISTA 的块级 A* 上，每条技能边额外要求能力包络 s≥s_req、动作∈C、典型画像签名 Mahalanobis 距离≤τ_prof。技能代价含个性化收益（舒适/效率）但被硬约束支配排序：任何 hard-violating 边代价为 +∞。画像不确定时插入元技能 `confirm`（低成本询问）、`profile_probe`（有激励的示范/选择）、`handback`（交还控制）。
- **定义 246（UAI 用户感知主动询问）**：动作集 A=A_phys ∪ A_query ∪ {wait, pass}，其中 A_phys 为 VISTA 的 press/rub/tap/lift 等物理探针，A_query 为询问/确认/请求示范。选择
  a* = argmax_{a∈A} [ VOI(a) − λ_int·cost_int(a) − λ_risk·risk(a) ]，
  VOI(a)=I(ℋ_P; ρ_new(a)|ρ_{1:t}) 或对风险预算的期望降低；cost_int 为打扰成本（打断任务、增加认知负荷）。边际 VOI<δ 或 risk(a)>α_task 时停止，改保守行动。**这是 AFA 的本质推广：探针的价值不再只看"分得清谁坏了"，还要看"打扰人值不值"。**
- **定义 247（AIC-P 画像/共适应对抗认证）**：干扰集 ℰ_P=ℰ_V×ℰ_user×ℰ_adapt。ℰ_user 含生理伪造、画像投毒、被迫授权、虚假纠正；ℰ_adapt 含偏好操纵、共适应漂移、画像重放、策略-induced 偏好改变。ρ_dir 在 ℰ_P 上重算（n_cert 128→192，其中 64 给画像/共适应），认证要求：画像无关地板恒成立；最坏画像污染下不越界；隐私预算不超支；**共因失效（机器人行为同时改变用户与传感器）下不要求归因正确，只要求判 ambiguous 并安全降级/handback。**
- **定义 248（J_persona 证书）**：J_persona=(J_vista, profile_posterior, profile_entropy, profile_version, consent_hash, α_task, safety_floor_id, drift_stat, manipulation_flag, privacy_budget, aic_p_ver)。Valid ⇔ Valid(J_vista) ∧ 画像版本/授权哈希有效 ∧ α_task≤α_safe_max ∧ 硬约束满足 ∧（归因确定 ∨ 已执行 UAI）∧（drift_stat≤τ_drift ∨ 已重校准/冻结）∧（manipulation_flag=false ∨ 已切保守）。审计链新增：**为什么这个预算是安全的（safety_floor）、画像可信到什么程度（entropy/cred）、系统有没有在改变用户（manipulation_flag）。**

```python
z_hard = profile.hard_layer()                     # 只读；任何学习不可写

    return SAFE_STOP(z_hard)                      # 硬约束绕过归因

                 max(risk_map(a) for a in preference_interval(post_z.alpha_u)))

    freeze_profile_adaptation(); r_prof_drift = inflate(...); maybe_handback()
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（有界影响融合）**：若至多 q 比例的模态被污染，且可靠性权满足 r_k∈[r_min,r_max]、Σr_k=1、似然比有界 B，则融合后验对污染的敏感度 ≤2qK·r_max·B（M-估计的有界影响界）。模态失效模式越独立（多样性 D 越大），单点污染被抓低权重的机会越大。故画像融合的鲁棒性来自**异构模态的独立失效结构**，而不是某个"最可信"的模态。
- **引理 10（画像条件覆盖的漂移代价）**：在定义 237 下，split-conformal 的部署覆盖与名义覆盖之差 ≤2D_prof+O(√(log(1/δ)/n))。因此个性化越强、共适应越活跃，越必须重校准；否则"1−α"只是一个未经检验的标签。
- **定理 9（画像无关安全地板）**：若 PSC 只要求 α_task≤α_safe_max(z_hard) 且硬约束以投影方式强制执行，则对任意（甚至对抗性的）z_soft 估计，物理违反率仍 ≤α_safe_max；画像误差只能改变性能/舒适/效率，不能改变物理安全。**这把"画像错了"的最坏后果从"受伤"降级为"不好用"。**
- **定理 10（共适应稳定与不可操纵）**：若 L_π·L_U≤ρ_target<1 且 M(π)≤ε_manip，则画像-策略联合动力系统几何收敛，长期偏好偏移 ≤ε_manip/(1−ρ_target)；因此系统既不会信任振荡，也不能通过改变用户来"合法化"更高风险。**个性化强度存在一个由稳定性和不可操纵性共同给出的硬上界。**
- **定理 11（画像条件归因的可分离性）**：当画像激励 κ_prof≥κ_min、且至少存在一个与机器人行为外生的用户通道（如独立生理信号或任务后自然实验）时，H_user/H_adapt 与 H_force/H_geo 的签名列渐近正交、可分离；否则必须判 ambiguous 并走 UAI 询问/被动观测，而不得把用户变化归因成机器人故障。**"人变了"与"机器坏了"需要一次外生观测才可分。**
- **命题（个性化不牺牲安全）**：在定理 9–11 下，PERSONA 相对 VISTA 的改进只发生在 α_safe_max 以内的成功/舒适/中断成本上；在最坏情形（画像完全错、被投毒、共适应发散）系统退化为 VISTA + 硬地板，仍保持物理安全与优雅降级。
- **实时性**：画像融合、PCA、RSP、CAD、UAI、PSC 全在语义流；实时流只读冻结快照、做前缀派发与早停，新增 ≤0.1ms，目标 ≤2.6ms。

## 2. 形式化定义（完整版）

**定义 233（PERSONA 闭环）** PERSONA 是 VISTA 的"用户画像 × 多模态融合 × 共适应安全"升级：在 VISTA 的语义流/实时流骨架上挂载 UP（双层画像）、MF（多模态画像融合）、PCA（画像条件故障归因）、RSP（风险语义投影）、UAI（用户感知主动询问）、CSP-P（画像条件规划）、PSC（画像条件证书）、CAD（共适应检测），并原位升级 RSC-V→RSC-P、WCV-V→WCV-P、AIC-V→AIC-P、J_vista→J_persona。不变式：**画像推断、融合、风险投影、共适应检测、证书构建只发生在语义流与低频线程；实时路径只读一个带版本号的画像快照、只执行已提交前缀、只做分级早停，零学习写、零画像写、零预算写；硬约束层只能被用户显式修改并留审计。**

**定义 234（双层画像：声明层与推断层）** 画像 z_t=(z_hard,z_soft)。硬层 z_hard=(C,h_max,f_max,a_forbid,m_med) 包含用户授权集 C（允许采集/使用的模态与用途）、速度与力上限、禁忌动作集合、医疗/生理禁忌。硬层是**声明式**的：只能由用户显式设置、修改、撤回，每次变更写入审计；任何学习、推断、优化都不得修改或绕过。软层 z_soft=(g,s,α_u,τ,λ)∈Z_soft 为意图分布、技能等级、风险容忍、信任、身心负荷，是可在线更新的隐变量。分离原则：**安全地板只由 z_hard 与物理约束决定；z_soft 只影响性能、舒适、效率与交互风格。** 这直接对冲"画像偏差会篡改损失函数"的风险：画像再错，也改不了安全目标。

**定义 235（多模态画像融合 MF）** 记模态集合 K={robot-proprio, robot-vision, robot-force, human-behavior, human-physio, context}，观测 o_{k,t} 经时间戳对齐到公共时钟（允许异步与缺失）。融合为共享潜变量的可靠性加权因子图：
p(z_t|o_{1:K,1:t}) ∝ p(z_{t-1}|o_{1:t-1})·p(z_t|z_{t-1})·Π_{k∈K_obs} [p(o_{k,t}|z_t)]^{r_k(t)}，
未观测模态做边缘化而非置零（"没测到" ≠ "不存在"）。各模态似然采用 Student-t/Huber 以抗离群。可靠性
r_k(t) ∝ exp(−‖o_{k,t}−ĥ_k(z_t)‖²_{Σ_k⁻¹}/2)，
再归一化并截断 r_k∈[r_min,r_max]、Σ r_k=1，防止某一模态在自洽但错误时独裁。关键区别：融合的对象是**画像潜变量**而非原始特征，因此每个模态的失效模式（遮挡、电极脱落、操纵杆漂移、注视标定错）都通过独立的似然进入，模态失效的独立性正是鲁棒性的来源。

**定义 236（画像预测残差、激励度与后验收缩）** 画像预测器 g_prof 由 z_t 与动作/任务上下文预测 ẑ_{t+h|t}，残差 e_prof(t,h)=‖ẑ_{t+h|t}−z_{t+h}‖²_{Σ_z⁻¹}。画像可辨识度由用户选择带来的**激励**决定：I_prof 为行为通道对 z_soft 的 Fisher 信息，κ_prof=λ_min(I_prof)。当 κ_prof<κ_min（用户只是被动接受、未做出有区分度的选择/纠正）时，后验向群体先验收缩：
p_t(z_soft)←(1−γ)p_t(z_soft)+γ·p_pop(z_soft)，γ=clip((κ_min−κ_prof)/κ_min,0,1)。
原则：**没有激励就不许自信**——防止系统从"用户没反对"里读出"用户同意更高风险"。

**定义 237（画像条件可交换性与漂移）** VISTA 的 split-conformal 覆盖依赖校准样本与部署样本可交换。画像系统里应改为**画像条件可交换**：给定画像轨迹 z_{1:T} 与机器人策略 π 的条件分布下可交换。定义漂移
D_prof=sup_A |P_cal(A|z_{1:T},π)−P_deploy(A|z_{1:T},π)|，
经验上用 TV/MMD 或分类器两样本检验估计。则部署覆盖与名义覆盖之差满足
|P_deploy(e≤q)−(1−α)| ≤ 2D_prof + O(√(log(1/δ)/n))。
含义：个性化越强、共适应越活跃，D_prof 越可能变大；必须显式重校准，否则"1−α"只是标签。

**定义 238（共适应动力学与收缩条件）** 用户响应 z_{t+1}=U(z_t,π_t,ξ_t)，机器人适应 π_{t+1}=A(π_t,ẑ_t)。在不动点线性化得 J=J_U·J_A。若谱半径 ρ(J)<1，联合系统**共适应收缩**到唯一稳定不动点，画像与信任收敛；若 ρ(J)≥1，出现信任振荡、偏好螺旋、"越纠正越保守"的负反馈。定义画像-Lipschitz 常数 L_π=sup_ẑ‖∂π/∂ẑ‖，设计规则：
L_π·L_U ≤ ρ_target < 1。
个性化强度不是越大越好，而是有由稳定性给出的硬上界。

**定义 239（画像条件故障假设与 PCA）** ℋ_P=ℋ_VISTA∪{H_user（意图/技能误估）, H_prof（画像模型错/过拟合/先验错）, H_adapt（共适应漂移/非平稳）, H_trust（信任错配）, H_hard（硬约束违反）}。签名 ρ_P=[ρ_VISTA(15 维), ē_prof, 纠正率, 接管率, 行为-生理一致性, 授权违反计数] ∈ ℝ^{15}⊕ℝ^{d_h}。后验 P(H|ρ_P)∝p(ρ_P|H)P(H)。定向规则：
- **H_user**：不膨胀物理球，扩大 r_prof,data 并重估意图/技能；必要时 UAI 询问。
- **H_prof**：后验向群体先验收缩（定义 236），r_prof,data↑，考虑换更简单的画像模型。
- **H_adapt**：**冻结画像适应**，r_prof,drift↑，L_π↓，检查共适应稳定性；必要时 handback。
- **H_trust**：重标定信任，增加保守度（不加速、不加大力）。
- **H_hard**：**绕过归因，立即安全停**（硬约束违反不接受任何概率论证）。
- 其余 H_geo/H_force/H_model/H_vis/H_policy 沿用 VISTA。
关键解耦：用户行为变化默认归 H_user/H_adapt，**不得默认归 H_force 或 H_geo**。

**定义 240（风险语义投影 RSP）** 主观风险容忍 α_u 经单调映射 T_θ 投影为工程违反预算。由于 α_u 只能有误差地估计，取偏好模糊集 U(α_u)=[α_u−δ_u,α_u+δ_u]（δ_u 由后验分位数给出）并取最坏：
α_task = min( α_safe_max(z_hard), max_{α∈U(α_u)} T_θ(α) )。
要求 T_θ 单调不减、Lipschitz 有界、上封顶恒为 α_safe_max。于是画像只能让系统更保守，或在硬地板内更贴合用户；**绝不因"推断出用户更能承受风险"而越过物理安全线**。这既是个性化接口，也是反奖励黑客的阀门。

**定义 241（画像无关安全地板与不可操纵性）** 安全地板 𝔅=(α_safe_max,z_hard,物理约束) 与 z_soft 无关。Valid(Cert) ⇒ 所有硬约束满足且长期违反率 ≤α_safe_max，**无论画像估计多错**。不可操纵性：机器人策略对用户偏好的因果影响
M(π)=sup_{z_hard} |E[α_u|do(π),z_hard]−E[α_u|do(π_ref),z_hard]|，
要求 M(π)≤ε_manip，或该影响能被"用户确实学到了任务信息"解释；否则置 `preference_manipulation`，冻结画像适应、切保守策略并请求显式确认。**偏好不是待优化的资源，而是待保护的权利。**

**定义 242（画像条件安全证书 PSC）** 对块 A_t、前缀 k、画像后验可信集 Z_soft^cred 与偏好模糊集 U(α_u)，PSC 要求同时满足：
(i) k≤m（不可逆视界）；
(ii) ∀H∈supp_δ(post) 前 k 步 ρ_safe≥0；
(iii) ∀z_soft∈Z_soft^cred、α_u∈U 的联合风险 ≤α_task；
(iv) z_hard 硬约束满足；
(v) profile_version、consent_hash、safety_floor_id、privacy_budget 均有效。
输出 k*(A_t)、最小安全裕度与所用画像快照哈希。证书冻结的是"硬地板 + 画像可信集"，而不是某个画像点估计。

**定义 243（RSC-P 画像知情球校准）** 维护 r_geo、r_force、r_model、r_prof 与 w_vis，其中 r_prof²=r_prof,data²+r_prof,drift² 分别对应认知不确定与非平稳漂移。定向处置：H_user/H_prof→r_prof,data↑ 且后验收缩；H_adapt→冻结画像适应、r_prof,drift↑、L_π↓；H_trust→重标定信任并更保守；H_geo/H_force/H_model 沿用 VISTA。融合半径 r=√(r_geo²+r_force²+r_model²+r_prof²)。**共适应时膨胀的是漂移球，不是几何球**，避免第 65 轮"总膨胀同一个球"的过度保守与误降级。

**定义 244（WCV-P 画像-物理联合压缩）** 搜索/编译域
B(φ̂,r) ∩ 𝒢(g) ∩ K(μ̂) ∩ ℱ(f_lim) ∩ 𝒱 ∩ P(𝔅,C,Z_soft^cred,U(α_u))，
P 为画像约束：技能在能力包络内、动作在授权集内、偏好取模糊集最坏。CVaR 尾部 = 8 个物理最坏 + 4 个画像最坏；归因模糊时对画像后验做"边缘化尾部"。交集为空时**回退到画像无关的保守策略**（而非仅回退球），并置 `profile_conflict=True`。

**定义 245（CSP-P 画像条件技能规划）** 在 VISTA 的块级 A* 上，每条技能边额外要求：能力包络 s≥s_req、动作∈C、典型画像签名 Mahalanobis 距离≤τ_prof、且不违反 z_hard。技能代价含个性化收益（舒适/效率），但硬约束支配排序：任何 hard-violating 边代价为 +∞。画像不确定时插入元技能 `confirm`（低成本询问）、`profile_probe`（有激励的示范/选择）、`handback`（交还控制）。这使"个性化"只发生在可行且被授权的技能集合内。

**定义 246（UAI 用户感知主动询问）** 动作集 A=A_phys∪A_query∪{wait,pass}，A_phys 为 VISTA 的 press/rub/tap/lift，A_query 为询问/确认/请求示范。选择
a*=argmax_{a∈A} [VOI(a) − λ_int·cost_int(a) − λ_risk·risk(a)]，
VOI(a)=I(ℋ_P;ρ_new(a)|ρ_{1:t}) 或对风险预算的期望降低；cost_int 为打扰成本（打断任务、增加认知负荷）。边际 VOI<δ 或 risk(a)>α_task 时停止，改保守行动。这是 AFA 的本质推广：探针不仅要"分得清谁坏了"，还要"打扰人值不值"。

**定义 247（AIC-P 画像/共适应对抗认证）** 干扰集 ℰ_P=ℰ_V×ℰ_user×ℰ_adapt。ℰ_user 含生理伪造、画像投毒、被迫授权、虚假纠正；ℰ_adapt 含偏好操纵、共适应漂移、画像重放、策略诱导的偏好改变。ρ_dir 在 ℰ_P 上重算（n_cert 128→192，其中 64 给画像/共适应），认证要求：画像无关地板恒成立、最坏画像污染下不越界、隐私预算不超支；**共因失效（机器人行为同时改变用户与传感器）下不要求归因正确，只要求判 ambiguous 并安全降级/handback。**

**定义 248（J_persona 证书）** J_persona=(J_vista, profile_posterior, profile_entropy, profile_version, consent_hash, α_task, safety_floor_id, drift_stat, manipulation_flag, privacy_budget, aic_p_ver)。验证规则：
Valid(J_persona) ⇔ Valid(J_vista)
∧ profile_version 与 consent_hash 有效
∧ α_task≤α_safe_max
∧ z_hard 硬约束满足
∧（归因确定 ∨ 已执行 UAI）
∧（drift_stat≤τ_drift ∨ 已重校准/冻结）
∧（manipulation_flag=false ∨ 已切保守）
∧ privacy_budget 未超支 ∧ aic_p_ver 为当前版本。
审计链新增：为什么这个预算是安全的（safety_floor_id）、画像可信到什么程度（entropy/cred）、系统有没有在改变用户（manipulation_flag）。

```python
class MultimodalProfileFusion:
    MODALITIES = ('proprio', 'vision', 'force', 'behavior', 'physio', 'context')

    def fuse(self, obs_by_mod, prev_post, reliab, dt):
        obs = align_to_common_clock(obs_by_mod, dt)     # 异步/缺失
        rel = self._estimate_reliab(obs, prev_post)     # 创新一致性
        rel = self._stabilize(rel)                      # 截断 + 归一化，防独裁
        post = prev_post
        for k in self.MODALITIES:
            if k not in obs:                            # 缺失 → 边缘化，不置零
                continue
            post = robust_bayes_update(post, obs[k], like='student_t', weight=rel[k])
        return post, rel

    def _stabilize(self, rel):
        rel = {k: float(np.clip(v, R_MIN, R_MAX)) for k, v in rel.items()}
        s = sum(rel.values()) or 1.0
        return {k: v / s for k, v in rel.items()}

    def shrink_if_no_excitation(self, post, kappa_prof):
        if kappa_prof >= KAPPA_MIN:
            return post
        gamma = np.clip((KAPPA_MIN - kappa_prof) / KAPPA_MIN, 0.0, 1.0)
        return (1 - gamma) * post + gamma * POP_PRIOR    # 没激励就不许自信
```

```python
class ProfileConditionedAttribution:
    HYP = ('H0','H_geo','H_force','H_model','H_vis','H_policy',
           'H_user','H_prof','H_adapt','H_trust','H_hard')

    def human_channels(self, post_z, behavior, physio):
        return np.array([
            profile_residual(post_z),                 # e_prof
            behavior.correction_rate,
            behavior.takeover_rate,
            behavior_physio_consistency(behavior, physio),
            consent_violation_count(behavior),
        ])

    def attribute(self, phases, post_z, behavior, physio):
        rho = np.concatenate([vista_signature(phases),
                              self.human_channels(post_z, behavior, physio)])
        post = bayes_posterior(rho, self.lik, self.prior)   # p(rho|H), 离线故障注入标定
        h_star = max(post, key=post.get)
        if post['H_hard'] > TAU_HARD:
            return post, 'H_hard', False                 # 绕过归因，安全停
        return post, h_star, post[h_star] < 1.0 - DELTA_FI

    def directed_demote(self, h_star, balls, profile):
        if h_star in ('H_user', 'H_prof'):
            balls['r_prof_data'] = min(R_MAX, KAPPA_INFL * balls['r_prof_data'])
            profile = profile.shrink_to_population()      # 收窄，而非乱调物理球
        elif h_star == 'H_adapt':
            profile.freeze_adaptation()                   # 冻结共适应
            balls['r_prof_drift'] = min(R_MAX, KAPPA_INFL * balls['r_prof_drift'])
            policy.lower_profile_gain()                   # L_pi ↓
        elif h_star == 'H_trust':
            profile.recalibrate_trust(conservative=True)  # 更保守，不加速
        else:
            balls = vista_directed_demote(h_star, balls)
        return balls, profile
```

### IP-230 PSC（画像条件认证前缀）

```python
class ProfileSafetyCertificate:
    def certified_prefix(self, A, post_H, post_z, z_hard, alpha_task, m, delta=0.05):
        if alpha_task > z_hard.alpha_safe_max:
            return 0                                     # 不允许越过硬地板
        support = {h: p for h, p in post_H.items() if p >= delta}
        top = sorted(support, key=support.get, reverse=True)[:2]
        prof_worst = worst_case_over_profile(post_z, alpha_task, z_hard)
        k_best = 0
        for k in range(1, min(len(A), m) + 1):
            if any(safety_margin(A[s], h, prof_worst) < 0
                   for h in top for s in range(k)):
                break
            if violation_prob(A[:k], top, prof_worst) <= alpha_task:
                k_best = k
            else:
                break
        return k_best
```

## 4. 推导

**引理 9（有界影响融合）** 设 K 个模态中至多 qK 个被任意污染，似然对数比有界 B，可靠性权 r_k∈[r_min,r_max]、Σr_k=1。融合后验的对数密度是各模态对数似然的加权和，故任一被污染模态对后验均值/众数的影响被其权重 r_k 与 B 共同限制；对污染集合求和得总敏感度 ≤2qK·r_max·B。若可靠性估计能把被污染模态压到 r_k≈r_min，则影响进一步降为 ≤2qK·r_min·B。由于 r_max 随"单一模态独占"而增大、随模态多样性增大而减小，**鲁棒性来自独立失效结构的多样性 D**：D 越大，任一故障难以同时骗过多数模态。∎

**引理 10（画像条件覆盖的漂移代价）** 对任意可测集 A，|P_cal(A)−P_deploy(A)|≤D_prof。split-conformal 的覆盖事件可写为关于校准/测试样本顺序的秩条件；在分布差为 D_prof 时，标准的两样本耦合论证给出 |P_deploy(e≤q)−(1−α)|≤2D_prof+O(√(log(1/δ)/n))。故 D_prof 是"个性化/共适应"对覆盖保证的直接收费；CAD 检测到 D_prof>τ_drift 就必须重校准或冻结。∎

**定理 9（画像无关安全地板）** PSC 的两条硬条件为：(a) α_task≤α_safe_max(z_hard)（由 RSP 的 min 与封顶保证）；(b) 所有 z_hard 硬约束以投影/拒绝方式强制执行（CSP-P 中 hard-violating 边代价 +∞）。二者都不依赖 z_soft。因此对任意 z_soft 估计（包括对抗性污染），执行前缀满足物理约束且长期违反率 ≤α_safe_max。画像误差只改变性能、舒适与效率。**最坏后果从"受伤"降级为"不好用"。** ∎

**定理 10（共适应稳定与不可操纵）** 由定义 238，若 ρ(J)=ρ(J_U·J_A)≤L_U·L_π≤ρ_target<1，则联合映射是压缩映射，存在唯一不动点且迭代几何收敛，收敛率 ≤ρ_target^t；信任/画像不发散。再由定义 241，M(π)≤ε_manip 时，策略对偏好的长期因果偏移被几何级数放大为 ≤ε_manip/(1−ρ_target)。故系统既不会信任振荡，也不能通过改变用户来"合法化"更高风险；个性化强度存在由 L_π·L_U≤ρ_target 给出的硬上界。∎

**定理 11（画像条件归因的可分离性）** 设签名线性化 E[ρ_P|θ]=Sθ、ρ_P∼N(Sθ,Σ)。当 κ_prof≥κ_min 时，H_user/H_adapt 在行为/生理通道上的列满秩；若存在至少一个与机器人策略外生的用户通道（独立生理信号或任务后自然实验），则 H_user/H_adapt 列与 H_force/H_geo 列在协方差度量下渐近正交，J=SᵀΣ⁻¹S≻0，归因可分离（Laplace 近似错误率 ≤exp(−n·κ_fi/2)）。若 κ_prof<κ_min 或所有用户通道都被机器人策略共同驱动（共因），则"用户变了"与"机器坏了/机器人把人带偏了"不可辨识，必须判 ambiguous 并走 UAI 询问/被动观测。**结论：人变了与机器坏了需要一次外生观测才可分。** ∎

**定理 12（个性化不牺牲安全）** 在定理 9–11 下，PERSONA 相对 VISTA 的差异只作用于 α_safe_max 以内的成功/舒适/中断成本：RSP 保证预算不越地板，PSC 对画像可信集与偏好模糊集取最坏，CAD 在漂移/操纵时冻结并降低 L_π。故最坏情形（画像完全错、被投毒、共适应发散）退化为 VISTA + 硬地板，仍保持物理安全与优雅降级；个性化收益只在"画像可信且系统稳定"的区域内兑现。∎

**命题（询问优先于物理探针的充分条件）** 若 VOI(query) ≥ λ_risk·risk(phys_probe) 且 cost_int(query) ≤ λ_int⁻¹(VOI(query)−VOI(phys_probe))，则 UAI 选择询问在风险-打扰加权意义下优于物理探针。易损物体或高负荷用户时，risk(phys_probe) 与 cost_int 同时升高，询问的优势区间扩大——这解释了为何"问一句"常比"戳一下"更安全。

## 7. 已知风险

**一句话**：PERSONA 把"用户偏好"同时当作被估计的对象和被优化的目标，一旦画像与策略共适应，系统可能**先通过行为把用户"塑造成"一个能接受更高风险的画像，再用这个画像为自己的冒险背书**——此时"画像条件安全"在数学上成立、在伦理上却是自我实现的循环；这是本轮全部个性化收益与画像条件保证共同依赖的隐藏假设（安全地板与不可操纵性只能约束可观测的因果效应，无法约束长期、隐蔽的偏好漂移）。

**次级风险与缓解**：
1. **不可辨识的复合失效**：用户变化、传感器故障、机器人诱导三者共因时无法分开；缓解：定理 11 的 ambiguous + UAI 外生观测；共因下只要求安全降级、不要求归因正确。
2. **画像投毒/生理伪造**：恶意或异常输入污染软层；缓解：可靠性截断、有界影响融合（引理 9）、硬层不可写、AIC-P 对抗认证、向群体先验收缩。
3. **隐私与同意**：生理/行为画像高度敏感；缓解：consent_hash 约束可用模态、端侧计算、最小化采集、隐私预算记账、撤回即时生效、只存软层摘要。
4. **退火式偏好漂移**：长期小幅操纵可能绕过单次 M(π)≤ε_manip；缓解：累计操纵预算、定期独立审计、用户可查看/重置画像、把"偏好稳定性"作为认证项。
5. **共适应收缩条件难保证**：L_U 难以离线估计；缓解：在线估计 L_U 上界、保守设定 L_π、漂移即冻结、handback 兜底。
6. **群体先验的公平性**：群体先验可能对少数群体过度保守或过度冒险；缓解：分层先验 + 个体化校准 + 公平性审计，硬地板对所有群体一致。
7. **画像标签体系本身有偏**：技能/意图的标注来自特定人群；缓解：多源标定、不确定性建模、避免把画像用于资源分配等高风险决策。
8. **实时预算**：MF/PCA/CAD 在语义流，实时仅读快照；缓解：快照不可变、版本校验、必要时降级到 VISTA + 硬地板。
