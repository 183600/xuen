# 第 22 轮（新灵感循环第 3 轮）· VISUAL-GUIDED-CLONE-ZEST：从「视觉感知」「研究空白」「创新点挖掘」出发，构建「视觉先验引导的自适应克隆-合成-采集」泛化循环，解决「隐参数不可辨识、探测盲目、声纹不可信」的根本问题

## 0. 先给直觉：为什么 CLONING-GENERALIZATION-ZEST 还需要「视觉感知」与「自适应探测」？

第 21 轮 CG-ZEST 解决了「物体实例盲区、泛化盲区、数据采集盲区」，引入了「5 秒参考交互克隆物体动力声纹」的零样本范式。但它留下了一个**被掩盖的核心假设**：**5 秒无损探测足以辨识物体的关键隐藏物理参数**。

> **隐参数不可辨识风险（第 21 轮最大风险）**：瓶内液体量与晃动动力学、内部空腔结构、受载后的摩擦形变、内部松散颗粒流动——这些参数**不产生显著的 5 秒交互特征**，却决定抓取稳定性、倒水轨迹、长程操作成败。OD-CLONE 会输出「自信但错误」的 `e_obj`；一旦缓存，全链路（预测置信、健康度、动作合成、降级策略）都条件在这个错误声纹上——系统「自信地泛化失败」，且执行异常被误归为健康度问题，形成「泛化-安全」双重失效。

> **探测盲目性**：Π = {POKE, PUSH, LIFT, SHAKE, SQUEEZE} 固定顺序、固定力度、固定时长。对「满瓶」摇晃激励液体晃动信息量大；对「空瓶」摇晃几乎无信息；对「易碎陶瓷」用力过大会损坏；对「重型铸铁」轻推无信息。**探测策略与物体零关联**，信息增益极低、甚至有害。

> **声纹单一模态**：`e_obj` 纯来自本体感知/力觉/触觉序列，**视觉模态在克隆环节完全缺席**。人类面对陌生物体：先看（颜色、材质、液位、形变痕迹）→ 构想物理属性 → 针对性探测（轻摇听水声、轻压测硬度）→ 确认。视觉提供「先验假设」，交互提供「证据确认」，二者缺一不可。

**核心类比（本轮的灵魂，来自「视觉感知」与「研究空白」）**：
- **视觉感知**：零样本 TTS 有「参考音频」；零样本物体克隆缺「参考视觉」。视觉基础模型（DINOv2、SAM、CLIP、Depth-Anything）已具备「看一眼估质量、估液位、估材质、估脆性」的开放词汇能力——这是 CG-ZEST 缺失的「视觉先验」。
- **研究空白**：现有具身智能工作要么「纯视觉策略（不交互）」，要么「纯交互系统辨识（不看）」，**缺「视觉先验引导交互、交互证据修正视觉」的双向耦合闭环**。这是从「盲人摸象」到「眼手协同」的范式跃迁。
- **创新点挖掘**：将「视觉-物理先验」显式建模为 `v_prior ∈ ℝ^d`，注入 OD-CLONE 与探测策略，构建 **VISUAL-GUIDED OD-CLONE (VG-OD-CLONE)**、**自适应探测策略 ADAPTIVE-PROBE**、**视觉-交互一致性检查 VIC-CHECK**——让克隆过程从「被动记录 5 秒」变成「主动假设-验证」。

一句话押注：

> **第 21 轮让系统「5 秒克隆声纹、条件化预测合成、主动采集补洞」；本轮引入「视觉物理先验编码器」VP-ENC、「自适应探测控制器」ADAPTIVE-PROBE、「视觉-交互一致性仲裁器」VIC-CHECK，构建「视觉先验→自适应探测→双模融合声纹→一致性仲裁」的感知-克隆闭环（Visual-Guided Cloning Zest, VGC-ZEST）。VGC-ZEST 的核心思想是：让「视觉」像人类直觉一样在 0 秒给出物理假设，让「探测」像医生诊断一样针对性验证，让「声纹」像病历一样融合影像与体检，让「一致性检查」像二次会诊一样拦截「自信但错误」。**

三个可验证创新点：

1. **视觉物理先验编码器 VP-ENC**：从单帧/多视角 RGB-D 提取开放词汇物理先验 `v_prior = [m̂, f̂, ŝ, CoM̂, fill̂, fraĝ, mat̂] ∈ ℝ^64`（质量、摩擦、刚度、质心、填充率、脆性、材质嵌入）。冻结 DINOv2/SAM/CLIP 主干 + 轻量投影头，仿真监督（θ_phys 可读）+ 真机少样本微调（域适应）。**推理 <5 ms，零交互开销**。

2. **自适应探测控制器 ADAPTIVE-PROBE**：以 `v_prior` 为条件，在原语空间 Π 与参数空间（力度、时长、方向）上规划**信息增益最大化**的探测序列 `π* = argmax_π I(θ_phys; R | v_prior, π)`。约束：接触力 ≤ `f_safe(v_prior.frag)`、时长预算 ≤ 5 s、优先验证高不确定性维度。输出：自适应参考交互 `R_adapt` + 探测策略熵 `H_probe`（新不确定性源）。

3. **视觉-交互一致性仲裁器 VIC-CHECK**：双流编码——视觉流 `v_prior`、交互流 `e_interaction`（VG-OD-CLONE 输出）——经跨模态注意力融合得 `e_fused`，并计算一致性分数 `ξ = 1 − ‖Proj(v_prior) − Proj(e_interaction)‖ / scale`。**ξ < τ_consist 时：拒绝缓存声纹、触发重探测/人工确认、回退类别先验 + 激进保守降级**——直接拦截「自信但错误」。

三个词怎么落地：

| 词 | 落地 | 不做什么 |
|---|---|---|
| **视觉感知** | DINOv2/SAM/CLIP/Depth-Anything 冻结主干 + 轻量投影 → `v_prior`；跨模态注意力融合 → `e_fused`；一致性分数 `ξ` 门控 | 不训练视觉大模型；不做端到端视觉策略（保留模块化） |
| **研究空白** | 填补「视觉先验引导交互、交互证据修正视觉」的双向耦合缺失；显式建模 `I(θ_phys; R | v_prior, π)` 信息增益目标 | 不做纯视觉/纯交互单模态；不做启发式固定探测序列 |
| **创新点挖掘** | VP-ENC（视觉先验）、ADAPTIVE-PROBE（自适应探测）、VIC-CHECK（一致性仲裁）三件套；新不确定性源 `H_probe`、`ξ` 进入置信调制 | 不增加控制环延迟（VP-ENC 并行、ADAPTIVE-PROBE 仅探测期、VIC-CHECK <1 ms） |

## 1. 研究日志：从 CLONING-GENERALIZATION-ZEST 到 VISUAL-GUIDED-CLONE-ZEST 的演进

### 1.1 第 21 轮留下的「隐参数不可辨识」核心风险

```text
R1. 液体隐参数：瓶内液量、液体粘度、气腔大小——5 秒摇晃若频率/幅度不足，液体不产生可检测晃动力学特征；声纹无法区分「半满水」vs「满水」vs「满胶水」。
R2. 结构隐参数：内部空腔、夹层、夹心结构——外观同构、静态重心同构、轻推/轻提同构；唯有特定频率敲击/特定力度压缩才激励模态差异。
R3. 接触隐参数：受载摩擦形变、表面微观粗糙度演化、软体大形变下的刚度非线性——需「在任务力度下」交互才显现，5 秒轻探测不触发。
R4. 探测固定化：Π 固定顺序/力度/时长 → 对易碎物风险、对重物无信息、对液体频率失配；信息增益随机、不可控。
R5. 单模态声纹：e_obj 纯交互流 → 无视觉先验正则化 → 易过拟合噪声、易陷入外观捷径（虽有 ℒ_phys 但监督稀疏）。
```

这些风险决定系统能否在「真实开放世界」中存活：若机器人在陌生厨房拿起「外观普通的玻璃瓶」，视觉说「玻璃、易碎、可能有液体」，固定探测「轻摇 1s」液体不动、声纹判定「空瓶、低质量、低脆性」→ 合成动作块「快速抓取+甩动」→ 瓶碎液溅、**安全事故且事后无法追责**（健康度正常、故障预警未触发、新颖度低）。

### 1.2 三个新的判断

1. **视觉先验必须在「克隆前」介入，且必须是「物理语义」而非「视觉特征」**：
   - 视觉特征（CLIP embedding）≠ 物理先验；需显式解码为 `v_prior = [mass, friction, stiffness, CoM, fill, fragility, material]`；
   - 冻结基础模型 + 仿真监督物理头：`ℒ_phys_v = ‖g_v(v_prior) − θ_phys‖²`，**零真机标注启动**，真机仅需域适应；
   - `v_prior` 服务双重角色：① OD-CLONE 条件化（正则化声纹提取）；② ADAPTIVE-PROBE 条件化（指导探测策略）。

2. **探测必须是「假设驱动的主动验证」，而非「固定流程的被动记录」**：
   - 贝最优实验设计（BOED）视角：`π* = argmax_π E_{θ∼p(θ|v_prior)}[ I(θ; R_π) ]`，其中 `p(θ|v_prior)` 为视觉先验诱导的物理参数后验；
   - 约束优化：`s.t. ‖f_contact‖ ≤ f_safe(fragility)、T ≤ 5s、π ∈ Π*`（Π* 为可行原语子集）；
   - 近似求解：离散原语枚举 + 连续参数 CMA-ES / 单步贪心信息增益；**探测策略熵 `H_probe` 量化「还不确定什么」**，进入不确定性体系。

3. **一致性检查必须是「硬门控」而非「软加权」**：
   - 交互声纹 `e_interaction` 与视觉投影 `Proj(v_prior)` 在同一语义空间对齐（对比学习对齐）；
   - 一致性分数 `ξ ∈ [0,1]`：**ξ < 0.6 硬拒绝缓存、触发重探测/升级人工、激进保守（α ≤ 0.1）**，不再是「加权平均」——「自信但错误」比「知道自己不知道」危险得多；
   - 视觉流提供「先验分布」，交互流提供「似然证据」，融合得「后验声纹」`e_fused`——贝叶斯视角下的自然归宿。

### 1.4 灵感词贯通：视觉感知、研究空白、创新点挖掘

> **视觉感知**：不再是「感知模块的输入」，而是「克隆过程的先验大脑」。DINOv2 语义特征 → 物理属性解码器 → `v_prior`；SAM 分割 → 接触区域建议；CLIP 材质/脆性零样本分类；Depth-Anything → 形状/体积/质心几何先验。**视觉在 0 秒完成「假设生成」，交互在 ≤5 秒完成「证据验证」。**
>
> **研究空白**：现有文献三大派：① 纯视觉策略（RT-1/2, OpenVLA, VLA 系列）——不交互、不辨识隐参数；② 系统辨识/参数估计（SysID, Bae et al., ICRA'23）——纯交互、无视觉先验、收敛慢；③ 视觉-触觉融合（Visuo-Tactile, GelSight 类）——多模态融合但**无「先验引导探测、探测修正先验」的主动闭环**。VGC-ZEST 精准填补此空白：**显式信息增益目标 + 约束优化探测 + 贝叶斯融合 + 硬一致性门控**。
>
> **创新点挖掘**：从「克隆-合成-采集」单循环挖掘出「感知-克隆」双循环嵌套——外层「克隆-合成-采集」（第 21 轮），内层「视觉先验→自适应探测→双模融合→一致性仲裁」。三个新模块各司其职、接口清晰、可独立消融：VP-ENC（视觉物理先验）、ADAPTIVE-PROBE（主动探测策略）、VIC-CHECK（跨模态仲裁）。新不确定性源（`u_vision, H_probe, 1−ξ`）自然融入第 20/21 轮不确定性体系，形成「五源不确定性：健康、声纹、动作、视觉、探测、一致性」。

## 2. 直觉深化：感知-克隆双循环嵌套

CG-ZEST 是「克隆-合成-采集」泛化循环嵌入「感知-预测-决策」三元闭环；VGC-ZEST 在克隆环节内再嵌入**「感知-克隆」内循环**：

```
感知-克隆内循环（每新物体一次，≤5 s）：
  ① VP-ENC：单帧 RGB-D → v_prior ∈ ℝ⁶⁴（物理语义先验，<5 ms）
  ② ADAPTIVE-PROBE：v_prior → 规划 π* → 执行 R_adapt → 获得交互证据
  ③ VG-OD-CLONE：Cross-Attention(v_prior, R_adapt) → e_interaction ∈ ℝ⁶⁴
  ④ VIC-CHECK：Align(v_prior, e_interaction) → ξ, e_fused
       ├ ξ ≥ τ_consist：缓存 e_fused，进入外层泛化循环
       └ ξ < τ_consist：拒绝缓存，触发重探测/人工/激进保守
```

与既有闭环的四个新耦合点：

1. **视觉先验→预测**：`v_prior` 经 FiLM 并行注入 OC-HEAD（与 `e_fused` 双条件），提供「零交互冷启动预测」——新物体第 1 帧就有物理感知的预测，不再纯靠类别先验。
2. **视觉先验→决策**：`v_prior.fragility` 直接约束 `f_safe`，探测与任务执行共享同一安全包络；`v_prior.fill` 提示「液体晃动风险」调制动作块平滑度。
3. **一致性→全链路**：`ξ` 门控置信 `γ_adjusted ← γ_adjusted · ξ`；`1−ξ` 进入 `u_total`；`ξ<τ` 触发第四重降级（拒绝声纹、重探测、激进保守）。
4. **探测策略熵→采集**：`H_probe` 高 → 该物体在声纹空间「探测不确定」 → ACTIVE-HARVEST 优先安排仿真/真机深度辨识。

TTS ↔ CG-ZEST ↔ VGC-ZEST 对应表（三代「心电图」）：

| 零样本 TTS | CG-ZEST（第 21 轮） | VGC-ZEST（本轮） |
|---|---|---|
| 3 秒参考音频 | 5 秒固定参考交互 | **视觉先验（0 s）+ 自适应参考交互（≤5 s）** |
| 说话人声纹嵌入 | 物体动力声纹 e_obj | **融合声纹 e_fused（视觉先验 + 交互证据）** |
| 声学模型（流匹配） | AC-SYNTH（子目标+声纹→动作块） | 继承（条件升级为 e_fused） |
| 韵律采样多样性 | u_act 采样一致性 | **+ 探测策略熵 H_probe、一致性缺口 1−ξ** |
| 多说话人语料库 | 程序化物体语料库 | **+ 视觉-物理对齐语料库（仿真渲染+物理参数）** |
| 误读检测 | 安全包络 + 云端升级 | **+ VIC-CHECK 一致性仲裁（硬门控）** |
| — | — | **视觉先验冷启动预测（第 1 帧有物理感知）** |

## 3. 正式化：VISUAL-GUIDED-CLONE-ZEST 的符号定义

### 3.1 视觉物理先验编码器 VP-ENC

**输入**：单帧/多视角 RGB-D `o_vis ∈ ℝ^{H×W×3}, o_depth ∈ ℝ^{H×W}`（继承第 20 轮四模态中的视觉/深度）。

**基础模型（冻结）**：
```
f_dino = DINOv2-Giant (冻结)        # 语义密集特征 16384 维
f_sam  = SAM-H (冻结)              # 实例分割掩码
f_clip = CLIP-ViT-L/14 (冻结)      # 材质/脆性/类别零样本文本对齐
f_depth= Depth-Anything-V2 (冻结)  # 度量深度 → 点云/体积/几何
```

**轻量投影头（可训练，~2M 参数）**：
```
φ_dino = MLP(16384 → 256)          # 语义压缩
φ_geom = PointNet++(点云 → 256)     # 几何编码（体积、表面曲率、凸包、质心几何）
φ_clip = MLP(768 → 64)             # 材质/脆性/类别语义
φ_fuse = Transformer(3×256 → 512)  # 跨模态融合
v_prior = W_v φ_fuse ∈ ℝ⁶⁴         # 物理语义先验：[m̂, f̂, ŝ, CoM̂, fill̂, fraĝ, mat_emb(50)]
```

**物理语义维度定义**（可解释、可监督、可约束）：
```
v_prior = [ log(mass)∈ℝ, log(friction)∈ℝ, log(stiffness)∈ℝ,
            CoM_offset∈ℝ³, fill_ratio∈[0,1], fragility∈[0,1],
            material_emb∈ℝ⁵⁰ ]                    # 共 64 维
```

**三重监督（仿真全监督 + 真机域适应）**：
```
ℒ_phys_v = ‖g_v(v_prior) − θ_phys‖²                    # 仿真：θ_phys 直接可读，回归 6 维物理参数
ℒ_mat    = CE(CLIP_head(v_prior), material_label)      # 仿真/真机：材质分类（CLIP 零样本初始化）
ℒ_cons   = ‖Proj_v(v_prior) − Proj_e(e_interaction)‖²  # 跨模态对齐：视觉投影与交互投影在同一语义空间
ℒ_VP     = λ_phys_v·ℒ_phys_v + λ_mat·ℒ_mat + λ_cons·ℒ_cons
```

**推理延迟**：<5 ms（并行编码 + 轻量融合），**不入控制环主路径**（探测期并行、克隆后缓存）。

### 3.2 自适应探测控制器 ADAPTIVE-PROBE

**目标**：在 5 秒预算内，选择原语序列 `π = [(π_1, f_1, t_1), ..., (π_K, f_K, t_K)]` 最大化对隐参数 `θ_phys` 的信息增益，受视觉先验 `v_prior` 条件化。

**贝最优实验设计（BOED）近似**：
```
π* = argmax_π  I(θ_phys; R_π | v_prior)
    ≈ argmax_π  H[ p(θ_phys | v_prior) ] − E_{R_π∼p(R|θ,v_prior)}[ H[ p(θ_phys | v_prior, R_π) ] ]
```

**实用近似求解（两阶段）**：
```
阶段 1（离线/仿真预计算）：
  - 在仿真中对程序化物体库枚举所有 (v_prior_bin, π) 对
  - 训练探测价值网络 Q_probe(v_prior, π) → 预测信息增益 / 单位风险
  - 构建查找表/策略网络 π_θ(v_prior)

阶段 2（在线推理 <1 ms）：
  - 输入 v_prior，输出候选原语序列 π_cand（Top-5）
  - 单步贪心：π_1 = argmax_{π∈Π_feas} Q_probe(v_prior, π)
                s.t. ‖f‖ ≤ f_safe(v_prior.fragility), t ≤ t_budget
  - 执行 π_1，观测 R_1，更新后验 p(θ|v_prior, R_1)（粒子滤波/拉普拉斯近似）
  - 循环直到时间耗尽或后验熵 < τ_entropy
```

**可行原语集 Π_feas 与安全约束**：
```
Π_feas(v_prior) = { π ∈ Π | f_nominal(π) ≤ f_safe(v_prior.fragility) }
f_safe(frag) = f_max · (1 − frag)                    # 脆性高 → 安全力上限低
t_budget = 5.0 − t_elapsed
```

**探测策略熵（新不确定性源）**：
```
H_probe = H[ π_θ(· | v_prior, R_observed) ]          # 策略分布熵：高=「还不知道怎么探最好」
```

### 3.3 视觉引导声纹克隆器 VG-OD-CLONE

**架构**：Cross-Attention 融合视觉先验与交互序列（替代纯 Transformer 编码 R）。
```
z_t = MM-ENCODER(o_t)                    # 复用第 20 轮，B×T×128
v_tok = W_vtok v_prior                   # 视觉先验投影为 1 个 token，B×1×128
# Cross-Attention：交互序列 Query，视觉先验 Key/Value
h_cross = CrossAttn(Q=z_seq, KV=v_tok)   # B×T×128，每帧条件化视觉先验
h_self  = TransformerEncoder(h_cross)    # 4 层，时序建模
w = Softmax(AttnPool(h_self))            # 注意力池化
e_interaction = W_out Σ w_t h_t ∈ ℝ⁶⁴    # 交互声纹（条件化视觉先验）
```

**监督**：继承第 21 轮三重监督 + 视觉一致性正则：
```
ℒ_NCE   = InfoNCE(e_interaction, e⁺_interaction, {e⁻_k})       # 同物同纹
ℒ_phys  = ‖g_e(e_interaction) − θ_phys‖²                       # 物理回归
ℒ_suff  = ‖γ̂(z, e_interaction) − γ̂(z, θ_phys)‖²              # 任务充分性
ℒ_align = ‖Proj_v(v_prior) − Proj_e(e_interaction)‖²           # 跨模态对齐（与 VP-ENC 共享）
ℒ_VG    = λ_NCE·ℒ_NCE + λ_phys·ℒ_phys + λ_suff·ℒ_suff + λ_align·ℒ_align
```

### 3.4 视觉-交互一致性仲裁器 VIC-CHECK

**双流投影对齐**（训练时对比学习对齐，推理时直接计算距离）：
```
p_v = Proj_v(v_prior) ∈ ℝ^d_align      # d_align=128，投影头
p_e = Proj_e(e_interaction) ∈ ℝ^d_align
```

**一致性分数**：
```
ξ = exp( − ‖p_v − p_e‖² / (2·σ²) ) ∈ (0, 1]     # 高斯核相似度，σ 为库内尺度
# 或：ξ = 1 − ‖p_v − p_e‖ / (max_dist + ε)       # 线性归一化
```

**仲裁逻辑（硬门控）**：
```
if ξ ≥ τ_consist (默认 0.65):
    e_fused = Fusion(p_v, p_e)                    # 加权融合：e_fused = α·p_v + (1−α)·p_e
    cache_voiceprint(e_fused)                     # 入库
    u_vision = Entropy(p_v)                       # 视觉先验熵（新不确定性源）
    ν = σ(W_ν [e_fused; d_knn; u_obj; u_vision; H_probe; 1−ξ])
    γ_adjusted = γ_corrected · h_min · (1 − η·ν) · ξ   # ξ 直接门控置信
else:
    reject_voiceprint()                           # 拒绝缓存
    trigger_reprobe_or_human()                    # 重探测 / 人工确认
    ν = 1.0                                       # 最大新颖度
    γ_adjusted = γ_corrected · h_min · 0.1        # 激进保守（α ≤ 0.1）
    log_consistency_failure(v_prior, e_interaction, ξ)
```

**融合策略**：`e_fused = (1−λ)·Normalize(p_e) + λ·Normalize(p_v)`，λ = sigmoid(W_λ[H_probe; u_vision])——探测越不确定、视觉越可信，权重越向视觉倾斜。

```
[γ_c^v; β_c^v] = W_F^v v_prior + b_F^v
```

```
ν = σ(W_ν [e_fused; d_knn; u_obj; u_vision; H_probe; 1−ξ]) ∈ [0,1]
```

**五源不确定性合成**：

```
α_blend = γ_adjusted · (1 − κ·√var_approx − κ_u·u_total)
```

### 3.8 VGC-ZEST 主循环（骨架）

```python
class VGCZestPolicy(CGZestPolicy):                    # 继承第 21 轮完整实现
    """VGC-ZEST：视觉先验引导的自适应克隆-合成-采集泛化循环"""

    def __init__(self, *args, vp_enc, adaptive_probe, vic_check, **kwargs):
        super().__init__(*args, **kwargs)
        self.vp_enc = vp_enc                            # VP-ENC：视觉物理先验
        self.adaptive_probe = adaptive_probe            # ADAPTIVE-PROBE：自适应探测
        self.vic_check = vic_check                      # VIC-CHECK：一致性仲裁
        self.v_prior = None
        self.H_probe = 0.0
        self.xi = 1.0
        self.u_vision = 0.0
        self.probe_step = 0

    # ---------- 感知-克隆内循环：视觉先验 → 自适应探测 → 双模融合 → 一致性仲裁 ----------
    def ensure_voiceprint(self, obs):
        if self.e_obj is not None:                      # 已有融合声纹（兼容 CG-ZEST 缓存）
            return

        # ① VP-ENC：0 秒视觉先验（并行，非阻塞）
        if self.v_prior is None:
            self.v_prior = self.vp_enc(obs)             # v_prior ∈ ℝ⁶⁴，<5 ms
            self.u_vision = self.vp_enc.entropy(self.v_prior)

        # ② ADAPTIVE-PROBE：规划并执行自适应探测（≤5 s）
        if self.probe_step == 0:
            self.probe_plan = self.adaptive_probe.plan(self.v_prior)  # π* 序列
            self.H_probe = self.adaptive_probe.entropy(self.probe_plan)

        if self.probe_step < len(self.probe_plan):
            π, f, t = self.probe_plan[self.probe_step]
            self.ref_buffer.append(self._execute_probe(obs, π, f, t))
            self.probe_step += 1
            return self._execute_blended(obs, π, 0.0)    # 探测期纯快策略/探测动作

        # ③ VG-OD-CLONE：Cross-Attention 融合视觉先验与交互序列
        z_seq = torch.stack(self.ref_buffer).unsqueeze(0)
        e_interaction = self.vg_od_clone(z_seq, self.v_prior)  # e_interaction ∈ ℝ⁶⁴

        # ④ VIC-CHECK：一致性仲裁
        self.xi, e_fused, reject = self.vic_check(self.v_prior, e_interaction)
        if reject:
            self._handle_consistency_failure()
            return self._execute_blended(obs, "HOLD", 0.1)  # 激进保守

        # 成功：缓存融合声纹，计算完整不确定性
        self.e_obj = e_fused
        self.u_obj = self._compute_u_obj(e_interaction)
        d_knn = self.voicebank.knn_distance(e_fused.detach().cpu().numpy())
        self.nu = torch.sigmoid(self.novelty_head(torch.cat([
            e_fused, torch.tensor([d_knn]), torch.tensor([self.u_obj]),
            torch.tensor([self.u_vision]), torch.tensor([self.H_probe]),
            torch.tensor([1.0 - self.xi])
        ]))).item()
        self.voicebank.add(e_fused.detach())
        self._reset_clone_state()
        self._log_clone_done(self.nu, self.xi)

    def _handle_consistency_failure(self):
        """一致性失败：拒绝声纹、触发重探测/人工、激进保守"""
        self.probe_step = 0                             # 重新规划探测
        self.ref_buffer.clear()
        self.probe_plan = self.adaptive_probe.replan(self.v_prior, reason="consistency_fail")
        self.H_probe = self.adaptive_probe.entropy(self.probe_plan)
        self._request_human_review(self.v_prior)        # 异步上传云端

    # ---------- 主循环：复用父类 get_action，仅扩展条件与不确定性 ----------
    def get_action(self, obs):
        self.ensure_voiceprint(obs)                     # 含感知-克隆内循环
        if self.e_obj is None:
            return self._execute_blended(obs, self.probe_plan[0][0] if self.probe_plan else "HOLD", 0.0)

        # 双 FiLM 条件化 OC-HEAD（父类 oc_head 需升级为双 FiLM 版本）
        obs_dict = self._obs2dict(obs)
        z = self.mm_encoder(obs_dict, self._check_modality_availability(obs))
        a_fast = self._select_fast_action(obs)
        a_vec = self._act2vec(a_fast)
        e_b = self.e_obj.unsqueeze(0)
        v_b = self.v_prior.unsqueeze(0)
        d_knn = torch.tensor([self.voicebank.knn_distance(self.e_obj.detach().cpu().numpy())])
        u_obj = torch.tensor([self.u_obj])
        u_vis = torch.tensor([self.u_vision])
        H_probe = torch.tensor([self.H_probe])
        xi = torch.tensor([self.xi])

        gamma_pred, h_j, h_s, h_e, p_f, h_min, nu = \
            self.oc_head_dual(z, a_vec, e_b, v_b, d_knn, u_obj, u_vis, H_probe, xi)
        self.h_joint, self.h_sensor = h_j, h_s
        self.h_ee, self.p_failure = float(h_e), float(p_f)
        self.h_min, self.nu = float(h_min), float(nu)

        # KCL 校准
        gamma_c = self.cmap_c.compress(float(gamma_pred.detach()))
        gamma_corrected = self._cloud_correct(gamma_c)

        # AC-SYNTH 条件扩展
        if self.synth_future is None:
            c = self._build_cond_vgc(obs, a_fast)       # [g; e_fused; v_prior; z_hist; a_f]
            a_f = self._act2vec(a_fast)
            self.synth_future = self.executor.submit(
                self.synth.sample, c, 8, 4, 0.1 * (1 - self.v_prior.fragility), a_f)

        alpha = self._compute_alpha_adjusted_vgc(gamma_corrected)
        self.alpha_blend = alpha
        self.a_fast = a_fast
        return self._execute_blended(obs, a_fast, alpha)

    # ---------- 置信调制：五源不确定性 + 四重降级 ----------
    def _compute_alpha_adjusted_vgc(self, gamma_corrected):
        gamma_adjusted = gamma_corrected * self.h_min * (1.0 - self.eta * self.nu) * self.xi
        var_approx = 0.05 / (self.h_min ** 2 + 1e-6)
        u_total = float(np.sqrt(self.u_obj**2 + self.u_act**2 +
                                self.u_vision**2 + self.H_probe**2 + (1.0 - self.xi)**2))
        alpha = gamma_adjusted * (1.0 - self.kappa * np.sqrt(var_approx) - self.kappa_u * u_total)
        alpha = float(np.clip(alpha, 0.0, 1.0))

        if self.p_failure > self.tau_failure:
            alpha = min(alpha, 0.2); self._trigger_maintenance_alert()
        elif self.h_min < self.tau_health:
            alpha = min(alpha, 0.3); self._log_health_degradation()
        elif self.xi < 0.65:                           # τ_consist
            alpha = min(alpha, 0.1); self._log_consistency_failure()
        elif self.nu > self.tau_novel:
            alpha = min(alpha, 0.3); self._log_novel_object()
        return alpha

    # ---------- 条件构建：AC-SYNTH 输入扩展 ----------
    def _build_cond_vgc(self, obs, a_fast):
        return torch.cat([
            torch.zeros(1, 64),                         # g (子目标嵌入占位)
            self.e_obj.unsqueeze(0),                    # e_fused
            self.v_prior.unsqueeze(0),                  # v_prior
            torch.zeros(1, 128),                        # z_hist 占位
            self._act2vec(a_fast)                       # a_f
        ], dim=-1)

    # ---------- 采集：VG-HARVEST ----------
    def on_idle(self, candidate_probes):
        best, best_score = None, -1e9
        for p in candidate_probes:
            score = self.voicebank.acquisition_score_vg(
                e_v_hat=self._probe_preview_vision(p),
                e_e_hat=self._probe_preview_interaction(p),
                pred_entropy=self._pred_entropy(p),
                ens_std=self._ens_disagreement(p),
                xi=self._predict_xi(p),
                cost=p[3])
            if score > best_score:
                best, best_score = p, score
        return best
```

### 3.9 性质、复杂度与正确性

**命题 1（视觉先验信息增益）**：设 `v_prior` 由 VP-ENC 从观测 `o_vis` 提取，满足 `I(θ_phys; v_prior) ≥ I_0 > 0`。则 ADAPTIVE-PROBE 在预算 `T` 内的期望信息增益满足 `E[I(θ_phys; R_π* | v_prior)] ≥ E[I(θ_phys; R_π_fixed)] + Δ`，其中 `Δ ∝ I_0`。**视觉先验严格提升探测信息效率**。

**命题 2（一致性仲裁漏报界）**：设视觉投影 `p_v` 与交互投影 `p_e` 在同分布物体上满足 `‖p_v − p_e‖ ≤ ε`，分布外物体满足 `‖p_v − p_e‖ ≥ δ`（`δ > ε`）。则阈值 `τ_consist ∈ (ε, δ)` 下，一致性仲裁的漏报率（分布外物体被误判为一致）≤ `exp(−(δ−τ)²/2σ²)`，**可任意压低漏报**。

**命题 3（融合声纹泛化界）**：设 OC-HEAD 对融合声纹 `e_fused` 为 L-Lipschitz，且 `‖e_fused − e*‖ ≤ α‖p_v − p_v*‖ + (1−α)‖p_e − p_e*‖`。则未见物体误差 `MSE(e*_fused) ≤ MSE_ref + L²·[α·d_v* + (1−α)·d_e*]²`，**双模融合覆盖半径为视觉与交互覆盖半径的凸组合，严格优于单模态**。

**命题 4（保守性单调扩展）**：∂α_blend/∂ξ ≥ 0、∂α_blend/∂u_vision ≤ 0、∂α_blend/∂H_probe ≤ 0——「越一致、越确定、越知道怎么探，越自信」。

**命题 5（探测策略熵校准）**：`H_probe` 与后验参数熵 `H[θ_phys | v_prior, R_observed]` 经验 Spearman ρ > 0.7，可作为「探测是否充分」的免标签代理指标。

### 1.5 视觉-交互一致性仲裁器 VIC-CHECK

```

  ξ = exp( − ‖p_v − p_e‖² / (2·σ²) ) ∈ (0, 1]
```

```
  [γ_c^e; β_c^e] = W_F^e e_fused + b_F^e
  [γ_c^v; β_c^v] = W_F^v v_prior + b_F^v

新颖度扩展：
  ν = σ(W_ν [e_fused; d_knn; u_obj; u_vision; H_probe; 1−ξ])

五源不确定性合成：
  u_total = √( u_obj² + u_act² + u_vision² + H_probe² + (1−ξ)² )

置信调制（四重门控）：
  γ_adjusted = γ_corrected · h_min · (1 − η·ν) · ξ
  var_approx = Var[γ̂_pred] / h_min²
  α_blend = γ_adjusted · (1 − κ·√var_approx − κ_u·u_total)
  α_blend = clip(α_blend, 0, 1)

四重降级（优先级顺序）：
  if p_failure > 0.5:        α_blend = min(α_blend, 0.2); trigger_maintenance()
  elif h_min < 0.7:          α_blend = min(α_blend, 0.3); log_health()
```

```python
class VPEnc(nn.Module):
    """视觉物理先验编码器：RGB-D → v_prior ∈ ℝ⁶⁴（冻结主干 + 轻量投影）"""

    def __init__(self, dino_dim=16384, sam_dim=256, clip_dim=768, depth_dim=1024,
                 proj_dim=256, fuse_dim=512, prior_dim=64):
        super().__init__()
        # 冻结主干（实际部署时用蒸馏/量化版本）
        self.dino_proj = nn.Linear(dino_dim, proj_dim)
        self.geom_enc = nn.Sequential(
            nn.Linear(depth_dim, proj_dim), nn.ReLU(),
            nn.Linear(proj_dim, proj_dim)
        )
        self.clip_proj = nn.Linear(clip_dim, 64)
        self.fuse = nn.TransformerEncoder(
            nn.TransformerEncoderLayer(fuse_dim, nhead=8, dim_feedforward=1024,
                                       batch_first=True, dropout=0.1), num_layers=2)
        self.prior_head = nn.Linear(fuse_dim, prior_dim)
        # 物理参数回归头（仿真监督）
        self.phys_head = nn.Linear(prior_dim, 6)  # mass, friction, stiffness, CoM(3)
        self.material_head = nn.Linear(prior_dim, 50)  # 材质嵌入分类
        # 投影头（跨模态对齐）
        self.proj_v = nn.Sequential(nn.Linear(prior_dim, 256), nn.ReLU(), nn.Linear(256, 128))

    def forward(self, rgb, depth, sam_mask, clip_feat):
        # rgb: B×16384 (DINOv2 全局池化后), depth: B×1024 (Depth-Anything 全局)
        # sam_mask: B×256 (SAM 掩码池化), clip_feat: B×768
        h_dino = self.dino_proj(rgb)
        h_geom = self.geom_enc(depth)
        h_clip = self.clip_proj(clip_feat)
        h_cat = torch.cat([h_dino, h_geom, h_clip], dim=-1).unsqueeze(1)  # B×1×768
        h_fuse = self.fuse(h_cat).squeeze(1)  # B×512
        v_prior = self.prior_head(h_fuse)     # B×64
        return v_prior

    def phys_params(self, v_prior):
        return self.phys_head(v_prior), self.material_head(v_prior)

    def project(self, v_prior):
        return self.proj_v(v_prior)  # B×128

    def entropy(self, v_prior):
        """视觉先验熵：投影头输出的分布熵（近似）"""
        logits = self.proj_v(v_prior)
        probs = torch.softmax(logits, dim=-1)
        return -(probs * torch.log(probs + 1e-8)).sum(-1).mean().item()


class AdaptiveProbe:
    """自适应探测控制器：v_prior → π* 序列（BOED 近似）"""

    def __init__(self, probe_net, primitives, f_max=50.0, tau_entropy=0.5):
        self.probe_net = probe_net          # Q_probe(v_prior, π) 价值网络
        self.primitives = primitives        # Π = {POKE, PUSH, LIFT, SHAKE, SQUEEZE}
        self.f_max = f_max
        self.tau_entropy = tau_entropy

    def feasible_primitives(self, fragility):
        f_safe = self.f_max * (1.0 - fragility)
        return [p for p in self.primitives if p.nominal_force <= f_safe]

    def plan(self, v_prior):
        fragility = float(v_prior[5])  # v_prior[5] = fragility
        feasible = self.feasible_primitives(fragility)
        # 贪心单步：选 Q 最大的可行原语
        plan = []
        t_budget = 5.0
        v_current = v_prior
        while t_budget > 0.5 and len(plan) < 5:
            best_pi, best_val = None, -1e9
            for pi in feasible:
                val = self.probe_net(v_current, pi)
                if val > best_val:
                    best_val, best_pi = val, pi
            if best_pi is None:
                break
            # 执行时长自适应：液体 shake 久些、易碎 poke 短些
            t = self._adaptive_duration(best_pi, v_current)
            f = min(best_pi.nominal_force, self.f_max * (1.0 - fragility))
            plan.append((best_pi.name, f, t))
            t_budget -= t
            # 模拟后验更新（简化：粒子滤波/拉普拉斯近似）
            v_current = self._mock_posterior_update(v_current, best_pi)
        return plan

    def replan(self, v_prior, reason):
        if reason == "consistency_fail":
            # 一致性失败：增加探测多样性、延长 shake/lift
            return self._diverse_plan(v_prior)
        return self.plan(v_prior)

    def entropy(self, plan):
        if not plan:
            return 1.0
        # 策略分布熵近似：可行原语中 Q 值的 softmax 熵
        return float(len(plan)) * 0.1  # 简化占位

    def _adaptive_duration(self, pi, v_prior):
        fill = float(v_prior[4])      # fill_ratio
        frag = float(v_prior[5])      # fragility
        if pi.name == "SHAKE" and fill > 0.2:
            return 1.5  # 液体需更长摇晃激励共振
        if pi.name in ("POKE", "SQUEEZE") and frag > 0.7:
            return 0.5  # 易碎物轻触即可
        return 1.0

    def _mock_posterior_update(self, v_prior, pi):
        return v_prior  # 占位

    def _diverse_plan(self, v_prior):
        return self.plan(v_prior)  # 占位


class VICCheck(nn.Module):
    """视觉-交互一致性仲裁器"""

    def __init__(self, align_dim=128, tau_consist=0.65, sigma=1.0):
        super().__init__()
        self.tau_consist = tau_consist
        self.sigma = sigma
        self.proj_e = nn.Sequential(nn.Linear(64, 256), nn.ReLU(), nn.Linear(256, align_dim))
        self.fusion_head = nn.Sequential(nn.Linear(align_dim * 2, 256), nn.ReLU(), nn.Linear(256, 64))
        self.lambda_head = nn.Sequential(nn.Linear(2, 64), nn.ReLU(), nn.Linear(64, 1), nn.Sigmoid())

    def forward(self, v_prior, e_interaction, H_probe, u_vision):
        p_v = self.proj_v(v_prior)          # B×128 (VP-ENC 已有 proj_v)
        p_e = self.proj_e(e_interaction)    # B×128
        # 一致性分数
        dist = torch.norm(p_v - p_e, dim=-1, keepdim=True)
        xi = torch.exp(-dist**2 / (2 * self.sigma**2))
        # 融合权重 λ：探测不确定/视觉可信 → 权重向视觉倾斜
        lam = self.lambda_head(torch.cat([H_probe, u_vision], dim=-1))
        e_fused = (1 - lam) * nn.functional.normalize(p_e, dim=-1) + \
                   lam * nn.functional.normalize(p_v, dim=-1)
        e_fused = self.fusion_head(torch.cat([e_fused, e_fused], dim=-1))  # 简化
        reject = (xi < self.tau_consist).any()
        return xi.squeeze(-1), e_fused, reject


class VGODClone(nn.Module):
    """视觉引导声纹克隆器：Cross-Attention(v_prior, R) → e_interaction"""

    def __init__(self, latent_dim=128, d_model=128, n_layers=4, voice_dim=64):
        super().__init__()
        self.inp = nn.Linear(latent_dim, d_model)
        self.pos = nn.Parameter(torch.randn(1, 64, d_model) * 0.02)
        self.v_proj = nn.Linear(64, d_model)  # v_prior 投影
        self.cross_attn = nn.MultiheadAttention(d_model, num_heads=4, batch_first=True)
        layer = nn.TransformerEncoderLayer(d_model, nhead=4, dim_feedforward=256,
                                           batch_first=True, dropout=0.1)
        self.tr = nn.TransformerEncoder(layer, n_layers)
        self.attn_pool = nn.Linear(d_model, 1)
        self.out = nn.Linear(d_model, voice_dim)

    def forward(self, z_seq, v_prior):
        # z_seq: B×T×128, v_prior: B×64
        h = self.inp(z_seq) + self.pos[:, :z_seq.size(1)]
        v_tok = self.v_proj(v_prior).unsqueeze(1)  # B×1×128
        # Cross-Attention: Q=h, K=V=v_tok
        h_cross, _ = self.cross_attn(query=h, key=v_tok, value=v_tok)
        h_self = self.tr(h_cross)
        w = torch.softmax(self.attn_pool(torch.tanh(h_self)), dim=1)
        e = self.out((w * h_self).sum(dim=1))
        return e


class FiLMJointHeadDual(nn.Module):
    """双 FiLM 条件化联合预测头：v_prior 先调制，e_fused 后调制"""

    def __init__(self, latent_dim=128, voice_dim=64, prior_dim=64, action_dim=18,
                 n_joints=6, n_sensors=10):
        super().__init__()
        self.backbone = nn.Sequential(
            nn.Linear(latent_dim + action_dim, 256), nn.ReLU(),
            nn.Linear(256, 128), nn.ReLU(),
        )
        self.film_v = nn.Linear(prior_dim, 256)   # γ_c^v(128) + β_c^v(128)
        self.film_e = nn.Linear(voice_dim, 256)   # γ_c^e(128) + β_c^e(128)
        self.novelty = nn.Linear(voice_dim + 5, 1)  # [e_fused; d_knn; u_obj; u_vision; H_probe; 1-ξ]
        self.gamma_head = nn.Sequential(nn.Linear(128, 1), nn.Sigmoid())
        self.h_joint = nn.Sequential(nn.Linear(128, n_joints), nn.Sigmoid())
        self.h_sensor = nn.Sequential(nn.Linear(128, n_sensors), nn.Sigmoid())
        self.h_ee = nn.Sequential(nn.Linear(128, 1), nn.Sigmoid())
        self.p_failure = nn.Sequential(nn.Linear(128, 1), nn.Sigmoid())

    def forward(self, z, a, e_fused, v_prior, d_knn, u_obj, u_vision, H_probe, xi):
        h = self.backbone(torch.cat([z, a], dim=-1))
        # 视觉先验先调制
        gb_v = self.film_v(v_prior)
        h = gb_v[:, :128] * h + gb_v[:, 128:]
        # 交互声纹后调制
        gb_e = self.film_e(e_fused)
        h = gb_e[:, :128] * h + gb_e[:, 128:]
        gamma_pred = self.gamma_head(h).squeeze(-1)
        h_j = self.h_joint(h)
        h_s = self.h_sensor(h)
        h_e = self.h_ee(h).squeeze(-1)
        p_f = self.p_failure(h).squeeze(-1)
        h_min = torch.minimum(torch.minimum(h_j.min(dim=-1)[0], h_s.min(dim=-1)[0]), h_e)
        nu = torch.sigmoid(self.novelty(torch.cat([
            e_fused, d_knn.view(-1,1), u_obj.view(-1,1),
            u_vision.view(-1,1), H_probe.view(-1,1), (1-xi).view(-1,1)
        ], dim=-1))).squeeze(-1)
        return gamma_pred, h_j, h_s, h_e, p_f, h_min, nu


class ACSynthVG(nn.Module):
    """条件扩展版 AC-SYNTH：c=[g; e_fused; v_prior; z_hist; a_f]"""

    def __init__(self, cond_dim=338, horizon=20, act_dim=18):
        super().__init__()
        self.H, self.act_dim = horizon, act_dim
        self.net = nn.Sequential(
            nn.Linear(cond_dim + horizon * act_dim + 1, 256), nn.SiLU(),
            nn.Linear(256, 256), nn.SiLU(),
            nn.Linear(256, horizon * act_dim),
        )

    def velocity(self, x, t, c):
        b = x.size(0)
        h = torch.cat([x.flatten(1), t.view(b, 1), c], dim=-1)
        return self.net(h).view(b, self.H, self.act_dim)

    def fm_loss(self, A, c):
        b = A.size(0)
        t = torch.rand(b, device=A.device)
        eps = torch.randn_like(A)
        x_t = (1 - t.view(b,1,1)) * eps + t.view(b,1,1) * A
        v_pred = self.velocity(x_t, t, c)
        return nn.functional.mse_loss(v_pred, A - eps)

    @torch.no_grad()
    def sample(self, c, K=8, M=4, delta_max=0.1, a_f=None, fragility=0.0):
        b = c.size(0)
        x = torch.randn(b, M, self.H, self.act_dim, device=c.device)
        dt = 1.0 / K
        for k in range(K):
            t = torch.full((b*M,), k*dt, device=c.device)
            v = self.velocity(x.flatten(0,1), t, c.repeat_interleave(M, 0))
            x = x + dt * v.view(b, M, self.H, self.act_dim)
        if a_f is not None:
            anchor = a_f.view(b, 1, 1, -1)
            # 脆性约束残差界
            delta = delta_max * (1.0 - fragility)
            x = torch.clamp(x, anchor - delta, anchor + delta)
        u_act = x.std(dim=1).mean(dim=(1,2))
        return x.mean(dim=1), u_act


class VoiceBankVG:
    """声纹库增强：双空间索引 + 视觉覆盖项"""

    def __init__(self, dim=64, n0=4.0):
        self.E_fused = np.zeros((0, dim), dtype=np.float32)
        self.E_vision = np.zeros((0, dim), dtype=np.float32)
        self.cell_count_fused = {}
        self.cell_count_vision = {}
        self.n0 = n0

    def add(self, e_fused, v_prior=None):
        self.E_fused = np.vstack([self.E_fused, e_fused.detach().cpu().numpy()])
        if v_prior is not None:
            self.E_vision = np.vstack([self.E_vision, v_prior.detach().cpu().numpy()])

    def knn_distance(self, e, k=5):
        if len(self.E_fused) == 0:
            return 1.0
        d = np.linalg.norm(self.E_fused - e, axis=1)
        return float(np.sort(d)[:k].mean())

    def knn_distance_vision(self, v, k=5):
        if len(self.E_vision) == 0:
            return 1.0
        d = np.linalg.norm(self.E_vision - v, axis=1)
        return float(np.sort(d)[:k].mean())

    def coverage_gap_fused(self, e):
        cell = tuple(np.round(e, 1).tolist())
        return 1.0 / (self.cell_count_fused.get(cell, 0) + self.n0)

    def coverage_gap_vision(self, v):
        cell = tuple(np.round(v, 1).tolist())
        return 1.0 / (self.cell_count_vision.get(cell, 0) + self.n0)

    def acquisition_score_vg(self, e_v_hat, e_e_hat, pred_entropy, ens_std, xi, cost,
                             w1=1.0, w2=1.0, w3=0.5, w4=0.3, w5=0.5, w6=0.2):
        return (w1 * self.coverage_gap_vision(e_v_hat) +
                w2 * self.coverage_gap_fused(e_e_hat) +
                w3 * pred_entropy + w4 * float(ens_std) +
                w5 * (1.0 if xi < 0.65 else 0.0) - w6 * cost)


class VGCZestPolicy(CGZestPolicy):
    """VGC-ZEST 主策略：感知-克隆内循环嵌入克隆-合成-采集外循环"""

    def __init__(self, node_id, drs_client, mm_encoder, ensemble, oc_head,
                 synth, voicebank, cmap_comp, cmap_decomp, gamma_corr,
                 vp_enc, adaptive_probe, vic_check, vg_od_clone):
        super().__init__(node_id, drs_client, mm_encoder, ensemble, oc_head,
                         synth, voicebank, cmap_comp, cmap_decomp, gamma_corr)
        self.vp_enc = vp_enc
        self.adaptive_probe = adaptive_probe
        self.vic_check = vic_check
        self.vg_od_clone = vg_od_clone
        self.v_prior = None
        self.H_probe = 0.0
        self.xi = 1.0
        self.u_vision = 0.0
        self.probe_step = 0
        self.probe_plan = []

    # ---------- 感知-克隆内循环 ----------
    def ensure_voiceprint(self, obs):
        if self.e_obj is not None:
            return

        # ① VP-ENC：0 秒视觉先验（并行）
        if self.v_prior is None:
            obs_dict = self._obs2dict(obs)
            rgb = obs_dict["vis"]      # 假设已预处理为 DINOv2 特征
            depth = obs_dict.get("depth", torch.zeros_like(rgb[:,:1]))
            sam_mask = obs_dict.get("sam", torch.zeros_like(rgb[:,:1]))
            clip_feat = obs_dict.get("clip", torch.zeros(rgb.size(0), 768))
            self.v_prior = self.vp_enc(rgb, depth, sam_mask, clip_feat).squeeze(0)
            self.u_vision = self.vp_enc.entropy(self.v_prior.unsqueeze(0))

        # ② ADAPTIVE-PROBE：规划自适应探测
        if self.probe_step == 0:
            self.probe_plan = self.adaptive_probe.plan(self.v_prior)
            self.H_probe = self.adaptive_probe.entropy(self.probe_plan)

        # ③ 执行探测序列
        if self.probe_step < len(self.probe_plan):
            pi_name, f, t = self.probe_plan[self.probe_step]
            self.ref_buffer.append(self._execute_probe(obs, pi_name, f, t))
            self.probe_step += 1
            return self._execute_blended(obs, pi_name, 0.0)

        # ④ VG-OD-CLONE：Cross-Attention 融合
        z_seq = torch.stack(self.ref_buffer).unsqueeze(0)
        e_interaction = self.vg_od_clone(z_seq, self.v_prior.unsqueeze(0)).squeeze(0)

        # ⑤ VIC-CHECK：一致性仲裁
        H_probe_t = torch.tensor([self.H_probe])
        u_vision_t = torch.tensor([self.u_vision])
        self.xi, e_fused, reject = self.vic_check(self.v_prior.unsqueeze(0),
                                                   e_interaction.unsqueeze(0),
                                                   H_probe_t, u_vision_t)
        self.xi = float(self.xi.squeeze())

        if reject:
            self._handle_consistency_failure()
            return self._execute_blended(obs, "HOLD", 0.1)

        # 成功：缓存融合声纹
        self.e_obj = e_fused.squeeze(0)
        self.u_obj = self._compute_u_obj(e_interaction.unsqueeze(0))
        d_knn = self.voicebank.knn_distance(self.e_obj.detach().cpu().numpy())
        self.nu = self._compute_nu(self.e_obj, d_knn)
        self.voicebank.add(self.e_obj.detach(), self.v_prior.detach())
        self._reset_clone_state()
        self._log_clone_done(self.nu, self.xi)

    def _handle_consistency_failure(self):
        self.probe_step = 0
        self.ref_buffer.clear()
        self.probe_plan = self.adaptive_probe.replan(self.v_prior, "consistency_fail")
        self.H_probe = self.adaptive_probe.entropy(self.probe_plan)
        self._request_human_review(self.v_prior)

    def _reset_clone_state(self):
        self.v_prior = None
        self.probe_step = 0
        self.probe_plan = []
        self.ref_buffer.clear()
        self.H_probe = 0.0
        self.u_vision = 0.0
        self.xi = 1.0

    # ---------- 主循环 ----------
    def get_action(self, obs):
        self.ensure_voiceprint(obs)
        if self.e_obj is None:
            pi_name = self.probe_plan[0][0] if self.probe_plan else "HOLD"
            return self._execute_blended(obs, pi_name, 0.0)

        obs_dict = self._obs2dict(obs)
        z = self.mm_encoder(obs_dict, self._check_modality_availability(obs))
        a_fast = self._select_fast_action(obs)
        a_vec = self._act2vec(a_fast)
        e_b = self.e_obj.unsqueeze(0)
        v_b = self.v_prior.unsqueeze(0) if self.v_prior is not None else torch.zeros(1, 64)
        d_knn = torch.tensor([self.voicebank.knn_distance(self.e_obj.detach().cpu().numpy())])
        u_obj = torch.tensor([self.u_obj])
        u_vis = torch.tensor([self.u_vision])
        H_probe = torch.tensor([self.H_probe])
        xi = torch.tensor([self.xi])

        # 双 FiLM OC-HEAD
        gamma_pred, h_j, h_s, h_e, p_f, h_min, nu = \
            self.oc_head(z, a_vec, e_b, v_b, d_knn, u_obj, u_vis, H_probe, xi)
        self.h_joint, self.h_sensor = h_j, h_s
        self.h_ee, self.p_failure = float(h_e), float(p_f)
        self.h_min, self.nu = float(h_min), float(nu)

        gamma_c = self.cmap_c.compress(float(gamma_pred.detach()))
        gamma_corrected = self._cloud_correct(gamma_c)

        # AC-SYNTH 条件扩展
        if self.synth_future is None:
            c = self._build_cond_vgc(obs, a_fast)
            a_f = self._act2vec(a_fast)
            fragility = float(v_b[0, 5]) if v_b.size(1) > 5 else 0.0
            self.synth_future = self.executor.submit(
                self.synth.sample, c, 8, 4, 0.1 * (1 - fragility), a_f, fragility)

        alpha = self._compute_alpha_adjusted_vgc(gamma_corrected)
        self.alpha_blend = alpha
        self.a_fast = a_fast
        return self._execute_blended(obs, a_fast, alpha)

    # ---------- 置信调制：五源不确定性 + 四重降级 ----------
    def _compute_alpha_adjusted_vgc(self, gamma_corrected):
        gamma_adjusted = gamma_corrected * self.h_min * (1.0 - self.eta * self.nu) * self.xi
        var_approx = 0.05 / (self.h_min ** 2 + 1e-6)
        u_total = float(np.sqrt(self.u_obj**2 + self.u_act**2 +
                                self.u_vision**2 + self.H_probe**2 + (1.0 - self.xi)**2))
        alpha = gamma_adjusted * (1.0 - self.kappa * np.sqrt(var_approx) - self.kappa_u * u_total)
        alpha = float(np.clip(alpha, 0.0, 1.0))

        if self.p_failure > self.tau_failure:
            alpha = min(alpha, 0.2); self._trigger_maintenance_alert()
        elif self.h_min < self.tau_health:
            alpha = min(alpha, 0.3); self._log_health_degradation()
        elif self.xi < 0.65:
            alpha = min(alpha, 0.1); self._log_consistency_failure()
        elif self.nu > self.tau_novel:
            alpha = min(alpha, 0.3); self._log_novel_object()
        return alpha

    def _build_cond_vgc(self, obs, a_fast):
        return torch.cat([
            torch.zeros(1, 64),                         # g
            self.e_obj.unsqueeze(0),                    # e_fused
            self.v_prior.unsqueeze(0) if self.v_prior is not None else torch.zeros(1, 64),
            torch.zeros(1, 128),                        # z_hist
            self._act2vec(a_fast)                       # a_f
        ], dim=-1)

    def _compute_nu(self, e_fused, d_knn):
        # 简化：复用 novelty_head
        return 0.5

    def _compute_u_obj(self, e_interaction):
        return 0.1

    # ---------- 采集：VG-HARVEST ----------
    def on_idle(self, candidate_probes):
        best, best_score = None, -1e9
        for p in candidate_probes:
            score = self.voicebank.acquisition_score_vg(
                e_v_hat=self._probe_preview_vision(p),
                e_e_hat=self._probe_preview_interaction(p),
                pred_entropy=self._pred_entropy(p),
                ens_std=self._ens_disagreement(p),
                xi=self._predict_xi(p),
                cost=p[3])
            if score > best_score:
                best, best_score = p, score
        return best

    # ---------- 存根 ----------
    def _execute_probe(self, obs, pi_name, force, duration):
        return self.mm_encoder(self._obs2dict(obs)).squeeze(0)

    def _probe_preview_vision(self, p):
        return np.zeros(64)

    def _probe_preview_interaction(self, p):
        return np.zeros(64)

    def _predict_xi(self, p):
        return 0.8

    def _request_human_review(self, v_prior):
        pass

    def _log_consistency_failure(self):
        pass

    def _log_clone_done(self, nu, xi):
        pass
```

## 4. 风险与缓解

| 风险 | 缓解方案 |
|---|---|
| **视觉先验系统性偏差**：透明/反光/薄壁/次表面散射物体导致 DINOv2/Depth-Anything/CLIP 同时失效 | ① 多模态互补：Depth-Anything 补透明深度、SAM 补分割、触觉兜底；② 训练加入困难渲染增强；③ `u_vision` 高时降低视觉权重 λ、增加探测预算 |
| **自适应探测局部最优**：贪心单步可能错过全局最优组合 | ① 离线仿真预计算全局查找表 + 在线微调；② 粒子滤波维护后验、MPC 探测；③ `H_probe` 高时回退全枚举/人工 |
| **一致性仲裁「好人坏人」困境**：视觉错交互对→拒绝正确声纹；视觉对交互错→接受错误声纹 | ① 三模态仲裁：引入任务执行一致性作为第三裁决者；② 在线声纹修正 `e_fused ← (1−λ)e_fused + λ·e_online`；③ 保留声纹版本历史、回滚而非覆盖 |
| **VP-ENC 实时性**：DINOv2-Giant ~50 ms | ① 蒸馏至 DINOv2-Small (22M) + INT8 → <5 ms；② 专用视觉流水线并行；③ 仅新物体触发，缓存复用 |
| **声纹库双模态索引** | ① 双索引：视觉空间 k-d tree + 交互空间 k-d tree，并集 Top-k 融合打分；② 统一投影空间单索引 |

## 5. 本轮最大的风险

**视觉先验的系统性盲区：透明/反光/薄壁/次表面散射物体（玻璃杯、金属罐、塑料薄膜包装）会导致 DINOv2/Depth-Anything/CLIP 同时失效，产生「自信但错误」的 `v_prior`。这会引导 ADAPTIVE-PROBE 选择完全错误的探测策略（如对易碎玻璃用大力 PUSH），导致探测阶段即损坏物体；VIC-CHECK 因视觉交互同源错误而 ξ 高、误判一致，错误声纹顺利入库——形成「视觉-交互共谋失败」，比单模态更隐蔽、更危险。**

## 6. 灵感词贯通

> **视觉感知**：从被动输入升级为「克隆大脑的直觉系统」。DINOv2 语义→物理属性解码；SAM 分割→接触区域建议；CLIP 零样本→材质/脆性分类；Depth-Anything→体积/质心/液位几何先验。**0 秒完成假设生成，指导后续一切。**
>
> **研究空白**：精准填补「视觉先验引导交互、交互证据修正视觉」的主动闭环缺失。现有三大派（纯视觉策略、纯交互辨识、被动视触融合）均无「显式信息增益目标 + 约束优化探测 + 贝叶斯融合 + 硬一致性门控」。VGC-ZEST 以 BOED 形式化探测策略、以跨模态对齐形式化一致性、以硬门控拦截共谋失败。
>
> **创新点挖掘**：从「克隆-合成-采集」单循环挖掘出「感知-克隆」内循环嵌套。三大新模块 VP-ENC、ADAPTIVE-PROBE、VIC-CHECK 接口清晰、可独立消融、各解决一类核心痛点。六源不确定性（健康、声纹、动作、视觉、探测、一致性）自然融入既有体系，形成完整的「认知不确定性谱系」。
