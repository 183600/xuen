# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互的不确定性二分」IP-253~263；灵感循环新循环第 1 轮；本轮灵感：「云端协同」×「末端位姿」）

> R69 让系统学会了「问」：面对可约歧义，主动去看、去问、去触。但 R69 的「问」隐含三个奢侈假设——**应答者在场（零延迟）、与自己同帧（共享坐标系）、且诚实（最多是 k 源一致）**。真实系统里最强的「问」对象恰恰不是身边的人，而是云端：一个更大、更懂语义、但**更慢、更远、更不可信**的他者。
>
> 本轮两个灵感正好把这个缺口补上：
> - **云端协同**不是「把模型搬上云」的工程问题，而是一种新的认识论结构：云与边缘**持有不同信念、运行在不同时间尺度、拥有不同权限**。云端给的是「意图」，不是「指令」。
> - **末端位姿**是云与边缘之间**唯一真正共享、且可被物理验证的量**。云说「移到物体上方 5cm」，这个「上方 / 5cm」只有在末端位姿的坐标系里才有意义；末端位姿的实测与云端意图之差，是一条新的、跨节点、物理可测的残差通道，也是校准两台机器时钟的「表针」。
>
> 核心命题：**把云-边协同建模为「以末端位姿为契约的异步意图交接」——云只提议、边独执行；信息价值按时延折扣；用（传感器残差, 行为似然, 位姿残差）三通道分离真漂移 / 标定吸收 / 云端漂移 / 时钟偏移 / 帧错位；边界永远保留一票否决。** 命名 **TETHER-RAS**（**T**rust-bounded **E**dge-cloud **T**emporal **H**andoff with **E**nd-effector **R**eferencing）——末端位姿就是云与边之间那根「系绳」：它既传递意图，也随时可以被拉断。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**求证回来的东西还作数吗、在谁的坐标系里作数、它有没有资格替我按下开关**」。

## 0. 直觉与动机

**灵感 1（云端协同 → 求证结构本身是异构、异步、非对称的）**
直觉：R69 把「交互」当成一个同步的、局部的、信息论上干净的动作。但真实的云-边系统里，云端与边缘不是同一个智能体的两个副本，而是**两个信念不同、时钟不同、权限不同的主体**。云端擅长语义、长程、大模型与世界知识（恰好是 R69 的 `U_epi` 最需要的那部分）；边缘擅长实时、反射、安全包络与 aleatoric 噪声（恰好是 R69 的 `U_ale` 与 `λ_floor` 守着的那部分）。把两者混成一个策略既贵又危险；正确姿态是**分工**：云做慢的、语义的、可错的「提议者」，边做快的、几何的、必须对的「处置者」。这就是 *cloud proposes, edge disposes*。

**灵感 2（末端位姿 → 唯一可验证的公共锚点，也是唯一诚实的证词）**
直觉：语言可以撒谎，图像可以伪造，云端的语义判断无法在本地复现；但「云以为末端在 A，边缘实测末端在 B」是一个**可直接测量、无法单方面编造**的事实（B 由本地运动学/视觉给出）。于是末端位姿成为两套信念之间的契约：云端意图必须携带 `(t_c, frame, ξ_c, Σ_c, model_ver)`，边缘用它做三件事——**接受 / 重锚定 / 否决**。位姿同时是「表针」：让机械臂做一个被认证的低风险微动，比较指令位姿与实测位姿在时间轴上的对齐，就能估计云端与边缘的钟差与网络时延（运动学授时）。

**灵感 3（时延 → 「问」变成「问过去」，VoI 必须被打折）**
直觉：答案回来时，世界已经变了。R69 的 VoI 默认 `H(M|o)` 在回答到达那一刻仍然成立；在云-边场景里，这个假设随延迟指数衰减。存在一个**临界时延 Δ\***：超过它，问云的信息价值低于成本，不如直接用边缘的保守兜底。因此 R69 的同步 MINT 是本轮 `AST` 在 `Δ = 0` 时的**边界情形**，而不是被推翻。

**灵感 4（权威分离 → 安全必须是可证明的不变量，不是工程约定）**
直觉：一旦云端能直接写执行器，「云端被投毒 / 幻觉 / 版本降级」就等价于「执行器被远程接管」。所以本轮把「云永远不进执行列」提升为**不变量**：任何执行命令必须由边缘用本地位姿测量过 C-RAS-WM 认证。其推论很硬：**哪怕云端是恶意的，它能到达的不安全集也不比边缘自己认证出来的更大**。这把 R69 的「交互投毒」威胁模型从「人撒谎」扩展到「另一个智能体撒谎」。

**灵感 5（位姿是强锚，也是新的「吸收器」→ 本轮最大风险）**
直觉：R68 的标定层可以吸收传感器慢变故障（`r_res ≈ 0`），让故障隐形；位姿契约有同构的危险——**只要云意图的位姿落在我的「管子」里，我就认为它懂了**。但位姿一致只验证几何，不验证语义：正确位姿 + 错误对象 / 错误抓取姿态 / 错误任务阶段 = 自信地做错事。于是「位姿桥」可能变成「信任洗白桥」：一个未经证实的云端语义结论，因为搭上了本地已验证的末端位姿，就被盖上了「已验证」的章。这正是 R69「问错比不问更危险」在分布式下的升级版。

**灵感 6（对偶通道 → 三张证词，而不是两张）**
直觉：R68 只有「传感器自洽」一张证词；R69 加了「行为似然」第二张。本轮加第三张「跨节点位姿一致」。三者投影不同：真漂移三张一起响；标定吸收只骗过第一张；云端模型漂移骗过前两张但位姿对不上；时钟偏移表现为位姿残差的时间平移；帧错位表现为位姿残差的常量 SE(3) 偏置。**五种故障、三种签名结构**，这是本轮可辨识性的来源。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（TETHER-RAS 总览）** TETHER-RAS = (PCC, AST, PGA, SPLIT, PAM, KTC, BUR, RAS-WM‡)。四条不变量：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；云端训练/回填全部异步，不进实时环）；
(ii) **权威不变量**：云端字节永不直接进入执行器，任何执行命令必须由边缘用**本地位姿测量**通过 C-RAS-WM 前缀认证；
(iii) **位姿溯源不变量**：任何云端意图必须携带 `(t_c, frame, ξ_c, Σ_c, model_ver, nonce)`；缺少合法位姿溯源的「纯语义指令」一律拒收；
(iv) **证据纪律**：云端只是**一个**证据源，单次云端回答不得单独消解 `U_epi`，需本地正交证据（位姿/触觉）或超过高置信 VoI 增益。

**定义 311（位姿契约 Pose Contract）** 云端意图编译为 \(c=(\xi_c(t),\Sigma_c(t),t_c,H_c,F_c,v_{\text{model}},\text{nonce})\)，其中 \(\xi_c:[t_c,t_c+H_c]\to SE(3)\) 是云端假设的末端位姿轨迹（在坐标系 \(F_c\) 下），\(\Sigma_c(t)\in\mathbb{R}^{6\times6}\) 是其位姿协方差（来自云端 flow 多采样/ensemble），\(t_c\) 为签发时刻，\(H_c\) 为意图时域。契约不是动作，而是「云端对位姿的承诺 + 不确定度 + 有效期」。

**定义 312（时延与陈旧度）** 单向网络时延 \(d\)、钟差 \(b\)、总陈旧度 \(\Delta = (t_{\text{now}}-t_c) + d\)。陈旧度折扣因子 \(\rho(\Delta)=e^{-\Delta/\tau_s}\)，\(\tau_s\) 为任务模态变化的特征时间。\(\Delta > H_c\) 时契约**硬过期**，不可执行。

**定义 313（位姿残差通道 PAM）** \(r_{\text{pose}}(t)=\log\!\big(\xi_c(t-t_c)^{-1}\,\xi_{\text{edge}}(t)\big)\in\mathfrak{se}(3)\)，即云端意图位姿与边缘实测末端位姿的相对 twist。它和 R68 的传感器残差 \(r_{\text{res}}\)、R69 的行为似然异常 \(\Delta a\) 构成三条**投影不同**的证词。

**定义 314（五类故障的三通道签名）** 记签名 \(S=(\operatorname{sgn} r_{\text{res}},\operatorname{sgn}\Delta a,\text{时序形态}(r_{\text{pose}}))\)：
- 真漂移：三者同向升高，且 \(r_{\text{pose}}\) 随真实运动平滑变化；
- 标定吸收：\(r_{\text{res}}\approx0,\ \Delta a\uparrow,\ r_{\text{pose}}\uparrow\)（R68 的盲区被第三通道照亮）；
- 云端漂移/幻觉：\(r_{\text{res}}\approx0,\ \Delta a\approx0,\ r_{\text{pose}}\uparrow\) 且与语义/任务阶段相关、非单调；
- 时钟偏移：\(r_{\text{pose}}(t)\approx r_{\text{pose}}(t+\delta)\) 的时间平移，\(r_{\text{res}}\approx0,\ \Delta a\approx0\)；
- 帧错位：\(r_{\text{pose}}\approx g_0\) 为**常量** SE(3) 偏置，与时间/运动无关。
在 A99（五类签名在支撑集上两两可辨）下，映射「故障类 → 签名」在支撑集上单射。

**定义 315（位姿管与接受判据）** 契约的位姿管 \(\mathcal{T}_c(\varepsilon)=\{p: d_{SE(3)}(p,\xi_c(t))\le \varepsilon(\Delta)\}\)，其中时延容差 \(\varepsilon(\Delta)=v_{\max}\Delta+\tfrac12 L\Delta^2\)（A100：末端速度有界、意图对时间 L-Lipschitz）。边缘仅当**预测执行时刻的位姿**落在 \(\mathcal{T}_c(\varepsilon)\cap\mathcal{S}_{\text{safe}}\) 且通过本地认证时才接受。

**定义 316（左不变重锚定）** 当当前位姿偏差超出管子，边缘不盲从，而是以当前实测位姿为新锚重写意图：
\[
\xi'_c(t)=\xi_{\text{edge}}(t_{\text{now}})\circ\big(\xi_c(t_{\text{now}})^{-1}\circ\xi_c(t)\big).
\]
左乘常量保证**相对运动（形状）完全不变**：\((\xi'_c(t))^{-1}\xi'_c(t')=(\xi_c(t))^{-1}\xi_c(t')\)；但重锚定会把整条轨迹平移到新锚，**不保证仍满足绝对工作空间/力包络**，故必须重新认证（定义 315）。

**定义 317（权威路由 CAR）** 决策权矩阵 \(A_{ce}\)：云端列 = {语义目标, 长程航点, 模式选择, `U_epi` 消解}；边缘列 = {执行器指令, 安全包络, `λ_floor`, 一票否决}。**云端在执行器列上的权限恒为空**（权威不变量 ii）。

**定义 318（陈旧度折扣 VoI，AST）** \(\mathrm{VoI}_\Delta(g)=\rho(\Delta)\mathrm{VoI}(g)-c(g)\)；若 \(\max_g \mathrm{VoI}_\Delta(g)\le 0\) 则不发起查询，直接走 R69/R68 兜底。临界时延 \(\Delta^\*=\tau_s\ln(\mathrm{VoI}_0/c)\)。

**定义 319（带宽感知不确定性路由 BUR）** 查询 \(q=(\xi_{\text{anchor}},M,\text{question})\)，字节预算 \(B\)；只上传「可被云端消解 × 对决策有影响」的 `U_epi` 分量，`U_ale` 永不出边（噪声在本地即可表征，上传只会增加延迟与泄露面）。路由三选一：本地消解 / 云消解 / 不消解。

**定义 320（运动学授时 KTC）** 在认证的低风险微动（位移 \(\le\epsilon_g\)）中执行两向授时，估计钟差与时延：
\[
(b^\*,d^\*)=\arg\min_{b,d}\sum_t\big\|\log(\xi_c(t-d-b)^{-1}\xi_{\text{edge}}(t))\big\|^2_{\Sigma^{-1}}.
\]
机械臂在此充当「表针」：位姿轨迹对时间平移的敏感性提供了时钟信息；两向交换用于分离钟差与单向时延（A101：短窗内 \(b,d\) 缓变）。

**定义 321（分裂脑账本 SPLIT）** 同时维护边缘信念 \(B_{\text{edge}}=p(w\mid \text{本地传感}, \text{已执行动作})\) 与云端信念 \(B_{\text{cloud}}=p(w\mid \text{云端上下文})\)；分歧 \(U_{\text{dis}}=D(B_{\text{edge}}\,\|\,B_{\text{cloud}})\)（分布距离）。分歧**不被静默平均**，而是作为显式不确定性并入 R69 的 `U_epi` 通道；只有位姿溯源匹配的跨节点证据才允许降低 \(U_{\text{dis}}\)。

**定义 322（不可信预言机纪律）** 云端证据权重 \(w_{\text{cloud}}=w(\text{model\_ver},\text{位姿有效期},\text{历史校准})\)；云端计为**一个**证据源，不能单独定案（继承定义 293-iii）。云端的错误只能让系统更保守，不能让它更激进：\(\lambda\) 对证据质量单调不增（质量越差 λ 越大）。

**定义 323（威胁模型 ℰ_TETHER）** \(\mathcal{E}_{\text{TETHER}}=\mathcal{E}_{\text{FLUID}}\times\mathcal{E}_{\text{net}}\)，\(\mathcal{E}_{\text{net}}=\) {时延注入, 重放, 钟差攻击, 帧伪造, 云端投毒/幻觉, 模型版本静默降级}。重放由 nonce + 位姿新鲜度拦截；帧伪造由位姿溯源与本地 FK（正运动学）交叉校验拦截。

**定义 324（证书 J_TETHER）** \(J_{\text{TETHER}}=(J_{\text{FLUID}}, r_{\text{pose}}^{p95}, \Delta_{\text{est}}, \delta_{\text{clock}}, \text{authority\_violations}, \text{stale\_accept\_rate}, v_{\text{cloud}}, \text{reanchor\_count}, \text{cloud\_log\_hash})\)。Valid ⇔ Valid(\(J_{\text{FLUID}}\)) ∧ 权威违规 = 0 ∧ 陈旧接受率 ≤ τ_stale ∧ 位姿溯源完整。

**定义 325（严格退化链）** 当 \(d=0\)、\(b=0\)、\(F_c=F_{\text{edge}}\)、云端=边缘时：PCC 退化为 R69 的逐步动作采样，AST 退化为 R69 同步 VoI，PGA 恒接受（偏差=0），SPLIT 无分歧，PAM 残差=0 ⇒ **TETHER-RAS ≡ FLUID-RAS**。再叠加「VoI≤成本」退化为 R68；再叠加「永不交互」退化为 R67。安全侧永不弱于上一层。

**定义 326（无缝交接与单调退化）** 交接时刻以当前实测位姿作左锚（定义 316），故位置连续；重锚定保持相对 twist，故速度连续（无位置/速度跳变）。任何交接失败（超时、过期、被否决、溯源不合法）时，\(\lambda\) **单调不降**地退化为 R69/R68 的保守策略，不出现权威的突变式切换。

```python
# IP-264 PCC：云端把意图编译成「位姿契约」（异步，不在实时环）
@dataclass
class PoseContract:
    t_c: float; H: int; frame: str; model_ver: str
    xi_c: Tensor      # [H, SE3] 云端假设的末端位姿轨迹
    Sig_c: Tensor     # [H, 6, 6] 位姿协方差（云端 flow 采样/ensemble）
    nonce: bytes

def compile_contract(intent, frame, model_ver):
    xi_c, Sig_c = intent.sample_pose_trajectory()        # 云端大模型，异步
    return PoseContract(now(), len(xi_c), frame, model_ver, xi_c, Sig_c, new_nonce())

# IP-265 AST：陈旧度折扣的 VoI（R69 同步 VoI 的时延推广）
def stale_voi(g, delay, tau_s, horizon):
    if delay > horizon: return -INF                         # 硬过期
    return voi(g) * exp(-delay / tau_s) - cost(g)

# IP-266 PGA：边缘仲裁（管子检查 + 重锚定 + 否决）
def arbitrate(contract, xi_edge_now, safe_set, dly):
    delta = se3_log(inv(xi_edge_now) @ contract.xi_c[0])     # 当前位姿偏差
    eps   = v_max * dly + 0.5 * L_intent * dly**2             # 时延放大后的管子
    if norm(delta) <= eps and tube_ok(contract, xi_edge_now, eps) \
       and reanchor(contract, xi_edge_now) in safe_set:
        return ACCEPT
    if reanchor(contract, xi_edge_now) in safe_set:
        return REANCHOR
    return VETO                                               # 退回局部保守

# IP-268 PAM：末端位姿残差通道（第三条独立证词）
def pose_residual(contract, xi_edge, t):
    return se3_log(inv(contract.xi_c[t - contract.t_c]) @ xi_edge)   # 6 维 twist

# IP-268 PAM：三通道故障分类（五类签名，定义 314）
def classify(r_res, delta_a, r_pose_seq):
    if high(r_res) and high(delta_a):           return TRUE_DRIFT
    if low(r_res) and high(delta_a):            return CALIB_ABSORBED
    if low(r_res) and low(delta_a):
        if is_constant_se3(r_pose_seq):         return FRAME_MISALIGN
        if is_time_shift(r_pose_seq):           return CLOCK_SKEW
        return CLOUD_DRIFT
    return UNKNOWN

# IP-269 KTC：机械臂当「表针」的两向时钟/时延标定（仅低风险 dither）
def kinesthetic_clock(cmd_log, pose_log, dither_envelope):
    assert dither_envelope <= EPS_G
    b, d = argmin_{b,d} sum_t ||se3_log(inv(xi_c(t-d-b)) @ xi_edge(t))||^2_Sigma
    return b, d

# IP-274 主闭环：边缘实时；云端异步回填

    # 1) R69 层：歧义分解

    samples = M.fmp.sample(o, K)

    # 2) 三张证词：传感器自洽 / 行为似然 / 跨节点位姿

    r_pose = M.pam.pose_residual(M.last_contract, M.xi_edge, M.t_now)

    # 3) 陈旧度折扣后的「问云」：值不值、来不来得及

    if U_epi > TAU_EPI and fault != CLOUD_DRIFT and not M.slow_fault:

    # 4) 契约仲裁：只有位姿管子里且本地认证通过才可执行
    verdict = M.pga.arbitrate(M.last_contract, M.xi_edge, M.safe_set, M.net.delay)
    if verdict == VETO or fault == CLOUD_DRIFT or M.net.expired(M.last_contract):
        lam = max(M.efs.risk_scale(...), lam_floor(U_ale + U_epi))   # 回 R69/R68 保守
    else:
        lam = max(M.efs.risk_scale(...), lam_floor(U_ale))            # resolution bonus
    # 5) 边缘唯一执行权威：云端字节绝不直接进执行器
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if verdict == REANCHOR:
        A = M.pga.reanchor(M.last_contract, M.xi_edge)
        k = M.c_ras_wm.re_certify(A, M.xi_edge)             # 重锚定必须重新认证
    tau = M.pi_sigma.prefix_dispatch(A[:k]) * lam
    # 6) 分布式审计 + 证书
    M.vqa_d.submit_async(q, verdict, fault, M.last_contract)
    return k, lam, verdict, (U_ale, U_epi)
```

## 3. 推导

**引理 19（陈旧度折扣的信息增益上界）** 设模态身份以速率 \(\kappa\) 变化（A101），云端回答时延 \(\Delta\)。则回答到达时的期望信息增益满足 \(\mathrm{VoI}_\Delta \le e^{-\kappa\Delta}\mathrm{VoI}_0\)；于是查询值得当且仅当 \(\mathrm{VoI}_0e^{-\kappa\Delta}>c\)，临界时延 \(\Delta^\*=\tau_s\ln(\mathrm{VoI}_0/c)\)（令 \(\tau_s=1/\kappa\)）。**要点**：不是「有歧义就问云」，而是「歧义在被问及的那一刻仍然可约时才问」。系：R69 的同步 VoI 是 \(\Delta=0\) 的边界；延迟越大，系统越应该信任边缘的保守兜底——这为定理 18 的严格包含提供了解析依据。

**引理 20（三通道的故障可辨识性）** 在 A99 下，五类故障（真漂移 / 标定吸收 / 云端漂移 / 时钟偏移 / 帧错位）到签名 \(S=(r_{\text{res}},\Delta a,\text{时序形态}(r_{\text{pose}}))\) 的映射在支撑集上单射，且：
- 仅凭 \((r_{\text{res}},\Delta a)\)（R68/R69 的两通道）时，「标定吸收」与「云端漂移」不可分——这正是 R68 的盲区；
- 加入 \(r_{\text{pose}}\) 的**常量 vs 平移 vs 变化**时序结构后，后四类两两可分。
**系**：位姿通道不是「又一条残差」，而是**唯一能区分「我的传感器坏了」与「我的大脑错了」的通道**——因为它必须同时被两边测量，任何单边故障都会在相对量上留下与故障类型对应的结构。

**引理 21（重锚定保持相对几何、不保持可行域）** 左不变重锚定 \(\xi'_c=\xi_{\text{edge}}(t_{\text{now}})\circ\xi_c(t_{\text{now}})^{-1}\circ\xi_c\) 满足 \((\xi'_c(t))^{-1}\xi'_c(t')=(\xi_c(t))^{-1}\xi_c(t')\)，即所有相对运动/形状严格不变；但绝对位姿整体左乘 \(g=\xi_{\text{edge}}(t_{\text{now}})\circ\xi_c(t_{\text{now}})^{-1}\)，故可能移出工作空间、越过力/速包络。锚点位移为 \(d_{SE(3)}(\xi_{\text{edge}}(t_{\text{now}}),\xi_c(t_{\text{now}}))\)。**系**：重锚定是「语义续接」的正确算子，但**绝不能**跳过定义 315 的重新认证，否则它会把一个位姿偏差悄悄放大成物理越界。

**定理 18（严格包含 R69 与 R68）** 在 A99–A102 下，TETHER-RAS 在任意状态上的期望风险 ≤ FLUID-RAS（R69）；当 \(d=b=0\)、同帧、云端=边缘时两者**逐指令相同**（定义 325）。且在 VoI 折扣后 ≤ 成本、云端证据不足、或位姿溯源失效时，TETHER 的每一条执行路径都包含在 R69 的保守路径内。故 R69 是 TETHER 在「零延迟、单节点、同信任域」边界上的严格退化；R68/R67 继续沿退化链成立。

**定理 19（时延有界安全与无缝交接）** 设 A100 成立、管子半径 \(\varepsilon(\Delta)=v_{\max}\Delta+\tfrac12L\Delta^2\)、且边缘只执行落在 \(\mathcal{T}_c(\varepsilon)\cap\mathcal{S}_{\text{safe}}\) 且本地重认证通过的轨迹。则：(a) 执行轨迹始终位于认证安全集内，即使云端意图过期或漂移；(b) 交接时刻以实测位姿左锚，位置连续；左不变重锚定保持相对 twist，速度连续（无跳变）；(c) 任何交接失败使 \(\lambda\) 单调不降地退化为 R69/R68，在线执行器指令连续。（证明要点：管子条件把「陈旧意图误差」吸收进 \(\varepsilon(\Delta)\)；认证把「语义/几何错误」挡在执行器之外；左锚给出交接处的一阶连续性。）

**定理 20（云端是不可信预言机——坏消息只能让我们更慢）** 令证据质量 \(q_e\in[0,1]\)，\(\lambda=\lambda_{\text{floor}}\big(U_{\text{ale}}+\max(0,U_{\text{epi}}-\mathrm{IG}(e))\big)\) 且 \(\mathrm{IG}\) 对 \(q_e\) 单调不减。则 \(\partial\lambda/\partial q_e\le 0\)：云端证据越差，系统只会更保守。结合权威不变量（云端不在执行列），**任意恶意云端可达的不安全集 ⊆ 边缘自身认证可达的不安全集**；worst-case 云端等价于「从不被采纳」，即 R69/R68 的保守路径。**系**：「云提案、边处置」不是工程洁癖，而是把云端投毒从「安全事件」降级为「性能事件」。

## 6. 本轮最大风险

**一句话**：TETHER-RAS 把「位姿一致」当成跨节点信任的桥梁，但**位姿只验证几何、不验证语义**——一个位姿落在管子里、本地认证也通过、却指错了对象/阶段/抓取姿态的云端意图，会被系统盖上「已验证」的章；**位姿桥因此可能变成信任洗白桥：正确的位姿 + 错误的语义 = 自信地做错事**。这正是 R69「问错比不问更危险」在分布式下的升级——而且更隐蔽，因为错误不是来自「回答」，而是来自一条被本地物理量背书的「意图」。

**次级风险与缓解**：
1. **时间/帧错误把正确意图投到错误物体**（小钟差/帧偏置 → 重锚定后打偏）→ KTC 两向授时 + 帧溯源交叉校验 + 定义 315 时延扩管；
2. **陈旧接受**（网络抖动下用了过期契约）→ 定义 312 硬过期 + 定理 19 的 \(\varepsilon(\Delta)\) + E313 断网降级；
3. **重锚定绕过可行域**（引理 21）→ 强制 re-certify，绝不因「语义正确」跳过几何认证；
4. **云端版本静默降级/投毒** → 权威不变量 + 引理 20 的 `v_cloud` 溯源 + 定理 20 的单调保守；
5. **KTC 微动干扰任务** → 只在认证低风险窗口做 dither，位移 \(\le\epsilon_g\)，且收益不足时不做（VoI 框架自洽）。

**当前方案的最大风险（一句话）**：我们能把「云说的是不是在我的坐标系里」验证到毫米与毫秒，却仍然无法验证「云说的那个东西是不是我以为的那个东西」——**位姿桥能防止手走错地方，防不住手去对了一个错的目标**。

**定义 324–326（证书 / 退化链 / 无缝交接）** `J_TETHER` 并入位姿与溯源审计；`d=b=0`、同帧、云端=边缘时 `≡ FLUID-RAS`，再退 R68、R67；交接以实测位姿左锚，位置/速度连续，失败时 λ 单调不降。

```python
# IP-264 PCC：云端编译位姿契约（异步，不在实时环）
@dataclass
class PoseContract:
    t_c: float; H: int; frame: str; model_ver: str
    xi_c: Tensor; Sig_c: Tensor; nonce: bytes

def compile_contract(intent, frame, model_ver):
    xi_c, Sig_c = intent.sample_pose_trajectory()          # 云端大模型
    return PoseContract(now(), len(xi_c), frame, model_ver, xi_c, Sig_c, new_nonce())

# IP-265 AST
def stale_voi(g, delay, tau_s, horizon):
    return -INF if delay > horizon else voi(g) * exp(-delay / tau_s) - cost(g)

# IP-266 PGA：接受 / 重锚定 / 否决
def arbitrate(contract, xi_edge_now, safe_set, dly):
    delta = se3_log(inv(xi_edge_now) @ contract.xi_c[0])
    eps   = v_max * dly + 0.5 * L_intent * dly**2
    if norm(delta) <= eps and tube_ok(contract, xi_edge_now, eps) \
       and reanchor(contract, xi_edge_now) in safe_set: return ACCEPT
    return REANCHOR if reanchor(contract, xi_edge_now) in safe_set else VETO

# IP-268 PAM：位姿残差 + 五类故障分类
def pose_residual(contract, xi_edge, t):
    return se3_log(inv(contract.xi_c[t - contract.t_c]) @ xi_edge)

def classify(r_res, delta_a, r_pose_seq):
    if high(r_res) and high(delta_a): return TRUE_DRIFT
    if low(r_res) and high(delta_a):  return CALIB_ABSORBED
    if low(r_res) and low(delta_a):
        if is_constant_se3(r_pose_seq): return FRAME_MISALIGN
        if is_time_shift(r_pose_seq):   return CLOCK_SKEW
        return CLOUD_DRIFT
    return UNKNOWN

# IP-269 KTC：低风险 dither 中的两向授时
def kinesthetic_clock(cmd_log, pose_log, dither_envelope):
    assert dither_envelope <= EPS_G
    return argmin_{b,d} sum_t ||se3_log(inv(xi_c(t-d-b)) @ xi_edge(t))||^2_Sigma

# IP-274 主闭环（边缘实时 + 云端异步）
def TETHER_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    a_hat  = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_calibrated)
    r_pose = M.pam.pose_residual(M.last_contract, M.xi_edge, M.t_now)
    fault  = M.pam.classify(M.last_r_res, a_hat, M.pam.r_pose_seq)
    q = (M.bur.route(modes, M.budget, M.net)
         if (U_epi > TAU_EPI and fault != CLOUD_DRIFT and not M.slow_fault) else None)
    if q and q.target == CLOUD and \
       M.ast.stale_voi(q, M.net.estimate_delay(q), TAU_S, M.vista.H) > 0:
        M.net.post(q)                                      # 异步，绝不阻塞
    verdict = M.pga.arbitrate(M.last_contract, M.xi_edge, M.safe_set, M.net.delay)
    if verdict == VETO or fault == CLOUD_DRIFT or M.net.expired(M.last_contract):
        lam = max(M.efs.risk_scale(...), lam_floor(U_ale + U_epi))   # 保守
    else:
        lam = max(M.efs.risk_scale(...), lam_floor(U_ale))            # resolution bonus
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)      # 边缘唯一执行权威
    if verdict == REANCHOR:
        A = M.pga.reanchor(M.last_contract, M.xi_edge)
        k = M.c_ras_wm.re_certify(A, M.xi_edge)
    tau = M.pi_sigma.prefix_dispatch(A[:k]) * lam
    M.vqa_d.submit_async(q, verdict, fault, M.last_contract)
    return k, lam, verdict, (U_ale, U_epi)
```

## 4. 推导

**引理 19（陈旧度折扣上界）** 模态以速率 κ 变化、回答时延 Δ，则 `VoI_Δ ≤ e^{−κΔ}VoI_0`；查询值得当且仅当 `VoI_0 e^{−κΔ} > c`，临界时延 `Δ* = τ_s ln(VoI_0/c)`（`τ_s=1/κ`）。系：R69 同步 VoI 是 `Δ=0` 边界；延迟越大越应信任边缘保守兜底。

**引理 20（三通道故障可辨识）** A99 下，五类故障到签名 `(r_res, Δa, 时序形态(r_pose))` 的映射在支撑集上单射。仅用两通道时「标定吸收」与「云端漂移」不可分（正是 R68 盲区）；加入 `r_pose` 的常量/平移/变化时序结构后后四类两两可分。系：`r_pose` 是唯一能区分「我的传感器坏了」与「我的大脑错了」的通道。

**引理 21（重锚定保形不保可行域）** `ξ'_c=ξ_edge∘ξ_c(t_now)^{-1}∘ξ_c` 满足相对 twist 严格不变；但绝对位姿整体左乘常量 g，可能移出工作空间/力包络，锚点位移为 `d_SE3(ξ_edge(t_now), ξ_c(t_now))`。系：重锚定后必须 re-certify。

**定理 18（严格包含 R69/R68）** A99–A102 下 TETHER 期望风险 ≤ FLUID-RAS；当 `d=b=0`、同帧、云端=边缘时逐指令相同（定义 325）。R69 是「零延迟、单节点、同信任域」边界，安全不让步。

**定理 19（时延有界安全 + 无缝交接）** 管子半径 `ε(Δ)=v_maxΔ+½LΔ²`、且只执行 `𝒯_c(ε)∩𝒮_safe` 且本地重认证通过的轨迹 ⇒ (a) 轨迹始终在安全集内；(b) 交接以实测位姿左锚、且重锚定保相对 twist ⇒ 位置/速度连续；(c) 任交接失败使 λ 单调不降地退化为 R69/R68，执行器指令连续。

**定理 20（不可信预言机）** `λ=λ_floor(U_ale+max(0,U_epi−IG(e)))` 对证据质量 `q_e` 单调不增；结合权威不变量，**恶意云端可达的不安全集 ⊆ 边缘自认证可达的不安全集**，worst-case 等价于「从不采纳云端」= R69/R68 保守路径。系：云端投毒从安全事件降级为性能事件。

## 7. 本轮最大风险

**一句话**：TETHER-RAS 把「位姿一致」当成跨节点信任的桥梁，但**位姿只验证几何、不验证语义**——一个位姿落在管子里、本地认证也通过、却指错对象/阶段/抓取姿态的云端意图，会被盖上「已验证」的章；**位姿桥因此可能变成信任洗白桥：正确的位姿 + 错误的语义 = 自信地做错事**。这是 R69「问错比不问更危险」在分布式下的升级，且更隐蔽：错误不是来自「回答」，而来自一条被本地物理量背书的「意图」。

**次级风险与缓解**：时间/帧错误把正确意图投到错误物体（KTC 两向授时 + 帧溯源 + 时延扩管）；陈旧接受（硬过期 + `ε(Δ)` + E313）；重锚定绕过可行域（强制 re-certify）；云端版本静默降级/投毒（权威不变量 + 溯源 + 定理 20 单调保守）；KTC 微动干扰任务（仅认证低风险窗口、位移 ≤ ε_g、收益不足不做）。

**当前方案的最大风险（一句话）**：我们能把「云说的是不是在我的坐标系里」验证到毫米与毫秒，却仍然无法验证「云说的那个东西是不是我以为的那个东西」——**位姿桥能防止手走错地方，防不住手去对了一个错的目标**。
