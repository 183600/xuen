# 第 4 轮（灵感循环第 4 轮；本轮灵感：「创新点提炼」×「模型蒸馏」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。两个新灵感都落在同一条新轴——「压缩」上：一个压缩**机制空间**（哪些模块才是真正的创新点），一个压缩**参数/算力空间**（把贵教师压成快学生）。任一压缩拿不到证书，都必须能一键退回未压缩的 InstructGauge。

## 0. 直觉与动机

**灵感 1（创新点提炼 → 把「贡献」定义成可测的合作博弈量）**
直觉：一个系统的「创新点」不是模块清单，而是**去掉就会让效应消失的最小充分机制集**。人类说「我们的贡献是 X」时，隐含了一个反事实断言：没有 X，效果就不成立。既然如此，「提炼」就不该只是写作问题，而应是**机制空间上的带误差压缩**：在组件集合上定义价值函数 `v(A)`（只启用子集 A 时的任务效用），用 Shapley 值分摊每个组件的边际贡献，再找满足「效用缺口 ≤ ε」的最小充分子集 `K_ε`——这就是**创新核**。它与普通消融的区别是本质的：leave-one-out 只测一阶边际，遇到「CVC 与 Barrier 必须同时在」这类协同项，会把两个组件都误判为无用；Shapley 满足效率性 / 对称性 / 哑元性 / 可加性，是唯一能正确分摊协同效应的归因。于是「创新点」第一次变成一个带 `(ε, δ)` 证书、可被第三方复算的对象，而不是作者自述。

**灵感 2（模型蒸馏 → 把贵教师压成快学生，但安全裁决不能蒸）**
直觉：真正拖慢闭环的是教师（大 VLA/LLM 的规划 + 接地前向）。蒸馏用软标签把教师行为压进小学生，推理成本可降一到两个数量级。但这里存在**安全不对称**：蒸馏目标优化的是平均保真度，而安全关心的是尾部 / 罕见危险状态；学生恰好在这些状态上最自信也最错，而且**错误是静默的**——没有教师在场就无法发现。因此正确做法不是「蒸一个更小的闭环」，而是**「蒸提议、不蒸裁决」**：学生只负责更快地*提议*块与接地，CVC / Barrier / 安全盾 / 能力闭包这些裁决器永远保持精确代码、永不被学习替代；再加一道**保形分歧门**，学生只在「已被证书覆盖的共识区」内被采纳，出界就回查教师。温度缩放顺带解决一个旧问题：第 3 轮的 `κ_sem` 需要 `H(ι|ℓ)`，而校准后的学生熵正好是它的廉价代理。

**灵感 3（两者耦合 → 同一条元原则：压缩必须带证书，且压缩不能碰安全脊柱）**
直觉：核化压缩「机制数」，蒸馏压缩「每次推理的算力」，两者看似无关，其实是同一条元原则的两个实例：**允许压缩，但必须给出压缩前后的偏差证书；拿不出证书就不许压缩**。更关键的结构观察是：两条压缩轴都**不改变能力边界**——核只是从完整组件集里删组件（且安全脊柱被排除在搜索空间外），学生的输出头被结构性 mask 到 `T₀ × M_phys × O_onto`。因此压缩能改变的是**效用与吞吐**，不是**可行域**。这把第 3 轮「语言不改能力」的分离原则推广成「任何压缩都不改能力」，也让风险从「压缩会不会造成新的不安全动作」收窄成更可证伪的问题：「压缩会不会在教师没去过的流形上，把有限预算花在安全但无用的动作上」。

## 1. 研究问题（本轮要回答什么）

- **Q1（可提炼性）**：能否把「创新点」定义成机制空间上的带误差最小充分子集，并给出可复算的 `(ε,δ)` 证书与可审计的主张卡，而不是一段叙事？
- **Q2（安全蒸馏）**：把教师压成学生时，哪些部分可以蒸、哪些必须保持精确？蒸馏引入的额外安全风险，能否被「结构不扩张 + 保形分歧门 + OOD 守卫」压到 0 或 `α`？
- **Q3（压缩复合）**：机制压缩（缺口 ε）与模型压缩（静默偏差 α）叠加时，总缺口是可加的、乘性的，还是会相变？在什么条件下部署压缩版仍保持教师级安全与可接受效用？

## 2. 三条设计原则（雏形，正式化见产物区定义 448–459）

**P4 认证压缩（Certified Compression）**
每一次压缩都必须自带 `(ε, δ)` 证书、**域标签** `D_valid` 与回退开关。核化要 `KernelCert`，蒸馏要 `DistillCert`，组合要 `ComposeCert` 且共享同一评估协议哈希。没有证书 ⇒ 不压缩，直接跑完整 InstructGauge。证书是「压缩的许可证」，不是「压缩的装饰」。

**P5 安全脊柱不可压缩（Non-compressible Safety Spine）**
设 `S_0 = {能力闭包检查, CVC, Barrier, ≻_safe 盾, 分层共形阈值}`。`S_0` **永不进入核搜索空间**、**永不被学生替代**。学生只提议，裁决仍是精确代码；学生预测的 CVC 处置 `ŷ_S` 只用于调度，不具签名权。汞齐一句话：**蒸馏可以买速度，不能买裁决权**。

**P6 分歧即查询（Disagree ⇒ Query）**
学生仅在 `DistillCert` 覆盖域内、且学生侧风险分 `r(x) ≤ τ_r` 时被采纳；OOD 或超阈值 ⇒ 回查教师；教师不可用 / 超时 ⇒ `K=1` 逐步执行。风险分必须**不依赖教师在线计算**（否则省不下查询），故用学生特征上的分歧预测头 + 集成分歧 + OOD 分数，并用 RCPS 校准其条件漏检率。

## 3. 与基线的接口（如何退化）

- 核证书不成立 / 有效组件缺回执 / 协议哈希不一致 ⇒ 全组件 InstructGauge（不做核化）；
- 学生缺失 / ECE 超限 / OOD 守卫触发 / 教师超时 ⇒ 教师 InstructGauge；教师查询也不可用 ⇒ `K=1` 逐步（等价 ToolGauge）；
- 教师本身失效 ⇒ 第 3 轮退化链：ToolGauge ⇒ LeanGauge ⇒ MODGAUGE；
- 两个压缩彼此独立：可只核化不蒸馏、只蒸馏不核化、都不做；三种选择分别退化为对应基线行为（引理 59/61）。

## 4. 预期贡献

1. 把「创新点提炼」形式化为组件合作博弈上的**认证最小充分子集**，给出可复算的 `KernelCert` 与可审计的 `Claim-Card`，把贡献归因从叙事变成测量；
2. 提出「**蒸提议、不蒸裁决**」的安全蒸馏口径，并证明能力闭包与安全裁决在压缩下**结构不扩张**（违规上界不升，缺口只落在效用）；
3. 给出**保形分歧门 + 温度校准桥**：在线判定不需要教师，学生熵可作 `κ_sem` 的廉价代理，静默偏差被显式分解为 `α + β + β_proxy`；
4. 一条可证伪路径 E457–E470，覆盖能力不扩张、核充分性、`K*` 右移而 `K_MAX` 不动、OOD 回退、蒸馏投毒与端到端吞吐/成本。

## 5. 本轮最大风险

**一句话**：两道压缩的证书都只在教师实际访问过的状态流形上有可交换性保证，而「省下查询」恰恰发生在学生替代教师的那些点上；系统可以结构上完全安全（无越权、CVC 照常通过），却在分布外把有限预算花在安全但无用的探测上——因此未覆盖的残余风险是**机会成本 / 效用证书在错误流形上失效**，而不是不安全动作。

## 2. 形式化定义（要点）

**定义 448（教师-学生蒸馏协议）** 教师 `f_T = (π_T^{VLA}, Γ_T^{NLI}, y_T^{CVC})`。对状态 `x` 输出动作/块分布 `p_T`、预测熵 `H_T`、CVC 处置预测 `y_T ∈ {PASS, TRUNCATE, ABORT, ABSTAIN}` 与块提议 `C_T`。蒸馏集
`D_T = {(x, p_T^{(T_d)}, H_T, y_T, C_T)}`
只由**教师实际执行并留下回执**的状态加受限安全增广生成（禁止在未验证状态上自举，防止错误自洽放大）。软目标 `p_T^{(T_d)} = softmax(z_T/T_d)`，`T_d > 1`。

**定义 449（能力闭包学生 `f_S`）**
`f_S: X → Δ(T₀ × M_phys) × Δ(O_onto)`，其 logits 经编译期常量投影 `Mask_{T₀,M_phys}`：`supp(f_S(x)) ⊆ T₀ × M_phys`，接地槽位 `⊆ O_onto`。该投影**不参与训练**。推论：`Im(f_S)` 与训练误差无关地满足能力闭包（引理 59）——蒸馏可以学错，但学不出新工具。

**定义 450（安全保真蒸馏目标）**
`L_D = E_DT[ T_d²·KL(p_T^{(T_d)} ‖ p_S^{(T_d)}) + λ_C·ℓ_chunk(C_S, C_T) + λ_U·(Ĥ_S − H_T)² + λ_A·ℓ_adj(ŷ_S, y_T) + λ_F·ℓ_abstain(ŷ_S, y_T=ABSTAIN) ]`
其中 `ℓ_adj` 对「学生预测 PASS、教师预测 TRUNCATE/ABORT/ABSTAIN」施加**不对称**代价（假阴性 ≫ 假阳性）；`ℓ_abstain` 惩罚该放弃时未放弃。注意 `ŷ_S` **只用于调度**，不进入任何安全判定。

**定义 451（分歧分数、风险分与 D-Gate）** 真实分歧
`d(x) = TV(p_S^{(1)}, p_T^{(1)}) + λ_H|Ĥ_S^{cal}(x) − H_T(x)| + λ_Y·1[ŷ_S(x) ≠ y_T(x)]`
需教师在场，**只在校准集上计算**。在线可算的学生侧风险分
`r(x) = α_1·ŝ_dis(x) + α_2·u_ens(x) + α_3·o(x)`
其中 `ŝ_dis` 是只吃学生特征/输出的分歧预测头，`u_ens` 为学生集成 / MC 分歧。用 `(D_cal, d, r)` 通过 **RCPS / Learn-then-Test** 取 `τ_r`，使条件漏检 `P(d > τ_dis | r ≤ τ_r) ≤ α`（有限样本界）。门策略：

- `o(x) > τ_ood` ⇒ `TEACHER`（证书域外，一律不采信学生）；
- `r(x) ≤ τ_r` ⇒ `STUDENT`；
- 否则：教师可查且在预算内 ⇒ `TEACHER`；否则 ⇒ `STEP`（`K=1`）。

关键工程点：`r` 不依赖教师在线前向，否则「省查询」不成立；代价是必须单独测量代理缺口 `β_proxy`（引理 60、E459）。

**定义 452（蒸馏证书 DistillCert）**
`DistillCert = (hash(f_S), τ_r, τ_ood, α, ECE_cal, D_valid 描述, 到期/失效条件, β_proxy)`。
证书是**域限定**的：只在 `D_valid` 的状态包线内声明静默偏差 `≤ α`；域外一律 `UNKNOWN`，门必须回退教师。任何一项统计量过期（分布漂移、硬件更换、工具集变更）⇒ 证书立即失效。

**定义 453（组件合作博弈与创新核）** 组件全集 `N = {IP-321,…,IP-327}`；安全脊柱
`S_0 = {能力闭包检查, CVC, Barrier, ≻_safe 盾, SC-Cal 阈值}`，
搜索空间 `N_s = N \ S_0`。价值函数 `v: 2^{N_s} → ℝ`，`v(A)` = 在固定评估协议下仅启用 `A ∪ S_0` 的期望任务效用。Shapley 值
`φ_i = Σ_{A⊆N_s\{i}} (|A|!(|N_s|−|A|−1)!/|N_s|!) · (v(A∪{i}) − v(A))`。
创新核
`K_ε = argmin_{A⊆N_s} |A|  s.t.  v(A∪S_0) ≥ v(N_s∪S_0) − ε`。
coalition 采样用**分层 + 对偶（antithetic）**估计，以经验 Bernstein 界给出价值误差 `ε_v` 与置信度 `1−δ`。输出
`KernelCert(K_ε, ε, δ, CI, 采样预算, 评估协议哈希)`。
注意：核搜索的目标是**效用充分**，不含安全约束；安全由「`S_0` 不进搜索空间」结构性保证（定义 454、引理 59）。

**定义 454（核内计划集与非扩张性）** `Plan_{K_ε}(ι)` 为仅用 `K_ε ∪ S_0` 组件产生的计划集。要求
`Plan_{K_ε}(ι) ⊆ Plan(ι)`。
此性质由「脊柱不动 + 非脊柱组件只贡献过滤/重排/解释投影」保证（引理 59），**不是**由核搜索的优化目标保证——因此核搜索不得把脊柱当可删项。

**定义 455（Claim-Card 创新点卡）**
`ClaimCard = (机制 m, 核引用 K_ε∩{m}, 效应量 Δ̂, 置信区间, 证伪实验 E_id, 回执集 R_m)`。
仅当四谓词同时成立才签发：
(i) `m ∈ K_ε`；(ii) `R_m ≠ ∅`；(iii) `E_id` 已预注册；(iv) 效应量与核证书共享同一评估协议哈希。任一失败 ⇒ 剥离（沿用定义 441 的纯投影语义）。Claim-Card 不得声称超出该协议之外的效应；核证书失效时全部卡片降级为 `HYPOTHESIS`，不再携带效应量。

**定义 456（蒸馏摊销成本与块长）** 学生单次提议成本 `c_S`、教师 `c_T`、教师查询率
`ρ = P(r > τ_r ∨ o > τ_ood)`。有效决策成本 `c_d^S = c_S + ρ·c_T`。由第 3 轮引理 53，`K_S*` 以 `c_d^S` 代入；加速比
`S_speed = c_T / (c_S + ρ c_T)`，
正收益条件 `ρ < 1 − c_S/c_T`。

**定义 457（温度校准熵与 κ_sem 桥）** 在留出集上拟合 `(τ_cal, β_vec)`（标量温度 + 可选向量缩放），得 `Ĥ_cal(x) = H(softmax(z_S/τ_cal))`，代入
`κ_sem^S = K·Ĥ_cal`，`K_MAX^S(ι) = ⌊K₀/(1+κ_sem^S)⌋`。
仅当 `ECE ≤ η_cal` 时启用；否则用教师 `H_T`；教师也不可用 ⇒ `K=1`。校准桥是「学生熵能否当语义熵用」的唯一许可证。

**定义 458（压缩组合证书 ComposeCert）**
`ComposeCert = (KernelCert, DistillCert, 继承的 7C/6C 证书, 评估协议哈希)`，声明：在同一协议与同一 `D_valid` 上，部署 `(K_ε, f_S)` 的效用缺口
`≤ ε + α·Δu_max + ε_v`，
且安全裁决仍由脊柱精确执行。两证书协议哈希不一致 ⇒ 拒绝组合（防止「各自合格、组合未测」）。

**定义 459（可交换性守卫 OOD）** `o(x) = max(o_density(x), o_ensemble(x), o_feat(x))`，三分量各自在留出集上做 conformal 校准；`τ_ood` 取目标假阴性率 `β` 的分位。守卫的目标不是判「好坏」，而是**只在能证明可交换时才让证书生效**；其假阴性率 `β` 显式进入引理 60 的偏差分解，不被隐去。

## 3. 关键算法骨架

```python
SAFETY_SPINE = {"capability_closure", "cvc", "barrier", "priority_shield", "sc_cal"}

# IP-328 CIK：组件合作博弈 → Shapley → 认证最小充分子集 K_eps
class CIK:
    def extract(self, value_fn, N, eps, delta, budget):
        N_s = [c for c in N if c not in SAFETY_SPINE]      # 脊柱永不进搜索
        coalitions = stratified_antithetic_sample(N_s, budget)
        v_hat, ci = {}, {}
        for A in coalitions:                               # 只评 A ∪ S_0
            v_hat[frozenset(A)], ci[frozenset(A)] = value_fn(A)
        phi = shapley_from_samples(v_hat, N_s)             # 效率性: sum(phi)=v(N_s)-v({})
        K = greedy_minimal_kernel(phi, v_hat, eps)         # |K| 最小且缺口 <= eps
        return K, KernelCert(K, eps, delta, ci, coalitions,
                             protocol_hash=value_fn.protocol_hash)

# IP-329 SPD：安全保真蒸馏（结构 mask + 温度软标签 + 不对称裁决损失）
class SPD:
    def train(self, teacher, D_T, T_d):
        for x, pT_Td, H_T, y_T, C_T in D_T:
            z = self.f_S(x)
            z = Mask_T0_Mphys(z)                           # 编译期常量，不参与训练
            loss  = T_d**2 * kl_div(log_softmax(z / T_d), pT_Td)
            loss += LAMBDA_C * chunk_regress(z, C_T)
            loss += LAMBDA_U * (entropy(z) - H_T) ** 2
            loss += LAMBDA_A * asymmetric_adj_loss(z, y_T) # PASS 误判代价 >> 反向
            loss += LAMBDA_F * abstain_loss(z, y_T == ABSTAIN)
            update(loss)

    def risk_score(self, x):                               # 在线：不需要教师
        return (ALPHA1 * self.disagree_head(self.feats(x))
                + ALPHA2 * self.ensemble_uncertainty(x)
                + ALPHA3 * self.ood_score(x))

# IP-330 D-Gate：RCPS 校准的学生侧门（教师只在出界时被查询）
class DGate:
    def decide(self, x, budget):
        if self.spd.ood_score(x) > TAU_OOD: return "teacher"   # 证书域外
        if self.spd.risk_score(x) <= TAU_R: return "student"
        if self.can_query_teacher(budget):  return "teacher"
        return "step"                                          # K=1，等价 ToolGauge
    def calibrate(self, D_cal, alpha):                         # 有限样本条件漏检控制
        return rcps_threshold(D_cal.r, D_cal.d, alpha)

# IP-332 KCX：核压缩执行器（脊柱始终精确）
class KCX:
    def propose(self, iota, state, executor):
        if not self.kernel_cert.valid() or self.kernel_cert.expired():
            return self.full_pipeline(iota, state)             # 全组件
        return self.kernel_pipeline(self.K, iota, state)       # 仅 K_eps ∪ S_0

# IP-333 CCG：创新点主张卡（四谓词，失败即剥离）
def make_claim_cards(kernel_cert, receipts, experiments):
    assert kernel_cert.valid()
    cards = []
    for m in mechanism_candidates(kernel_cert):
        ev   = receipts_for(m, receipts)
        test = preregistered_falsifier(m, experiments)
        if (m in kernel_cert.K) and ev and test and same_protocol(kernel_cert, ev):
            cards.append(ClaimCard(m, kernel_cert.K & {m},
                                   effect_size(ev), ci(ev), test, ev))
        # else: 剥离（纯投影，不改变任何数值行为）
    return cards

# IP-334 DistillGauge-8C：propose 准入 + kernel 准入
def distillgauge_8c(M, s, ell):
    mode = M.dgate.decide(M.state(s), M.budget_left(s))    # student / teacher / step
    if mode == "student":
        iota, C = M.spd.propose(M.state(s), ell)           # 学生只提议
    elif mode == "teacher":
        iota, C = M.teacher_propose(s, ell)                # = InstructGauge 提议端
    else:
        iota, C = M.default_iota, M.per_step_chunk(s)      # K=1

    if not capability_closed(iota):                        # 脊柱：精确检查
        iota = M.default_iota
    C = M.kcx.propose(iota, M.state(s), C)                 # K_eps 或 full
    if not M.tcv.verify(C.as_program(), M.budget_left(s))[0]:
        C = M.numeric_fallback(s)
    cert = M.cvc.commit(C, M.env, iota)                    # 脊柱：精确裁决，无学生签名权
    receipts = cert.receipts
    if len(receipts) < n_min(s): return stub_and_red(s, "insufficient")
    mu, Sig = M.apcal.calibrate(receipts, M.hypothesis(s), s)
    if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):
        return stub_and_red(s, "cross_failed")
    new_ec = M.apcal.update_contract(M.dpe, mu, Sig, s)
    if not contract_regression(new_ec):
        return stub_and_red(s, "regression")
    M.mreg.hot_replace_at_quiescence(M.dpe, new_ec, cert.boundary)
    M.ccg.record(make_claim_cards(M.kernel_cert, receipts, M.experiments))
    M.pquar.record(M.apcal.last_gain, realized_gain(receipts))
    return True

# IP-335 主闭环（50Hz 路径不变；门判定 O(1)）
def DistillGauge_round(M, obs, audio, tac, depth, det, ell=None):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s)
            if M.dgate.ood(s) > TAU_OOD:
                M.distill_cert.invalidate()                # 域外 ⇒ 整证书暂停
            submit_async(distillgauge_8c, M, s, ell)
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 4. 推导

**引理 59（安全脊柱与非扩张压缩）** 固定 `S_0` 精确启用，学生只提议且 `supp(f_S) ⊆ T₀×M_phys`，核组件 `K_ε ⊆ N \ S_0`。则：
(i) 任何被采纳的提议仍须通过精确 CVC / Barrier / 盾 / 能力闭包检查，单步安全不变量 `Inv` 的保持条件与教师完全相同；
(ii) `Plan_{K_ε}(ι) ⊆ Plan(ι)`；
(iii) 压缩**不改变**单步安全违规概率的上界，只改变期望效用与吞吐。
*证明骨架*：(i) 裁决器代码未变，且被裁决提议的支撑集未变宽（mask + 脊柱）；(ii) 删除非脊柱组件只删除过滤/重排/解释投影，不新增动作产生式——删 NLI ⇒ 退回默认目标，删 IAC ⇒ `K=1`，删 CVC 等被禁止，删 NCB ⇒ 少一组 claims；脊柱保留保证屏蔽与屏障仍在；(iii) 由 (i)，每个执行动作的安全条件与教师一致，违规只能来自教师也会犯的同类错误，故上界不升。

**引理 60（保形分歧门的静默偏差分解）** 若 `D_cal` 与部署集在 `D_valid` 内可交换、RCPS 给条件漏检 `≤ α`、OOD 守卫假阴性率 `β`、风险分 `r` 与真实分歧 `d` 的代理缺口 `β_proxy`，则被学生静默采纳且与教师实质分歧的概率
`P_silent ≤ α + β + β_proxy`（并集界）。
推论：由引理 59，脊柱裁决精确 ⇒ 静默分歧不转化为不安全动作，只转化为效用损失；若 `β_proxy` 不可忽略（`r` 不是好代理），该界失效，必须以安全相关一致性指标重训 `r`，或直接禁用学生（E459 的预注册处置）。
*证明*：RCPS 控制条件漏检；域外漏检由 `β` 界住；`r` 与 `d` 的差距由 `β_proxy` 显式计入。三者取并集。

**引理 61（核充分性与压缩缺口可加）** 若 `KernelCert(K_ε,ε,δ)` 成立、`DistillCert(α)` 成立且 `ComposeCert` 协议哈希一致，则部署 `(K_ε,f_S)` 的期望效用
`U_deploy ≥ U_full − (ε + α·Δu_max + ε_v)`，以概率 `≥ 1 − (δ + δ_cal)`。
缺口**可加不可乘**；协议不一致则不能得出任何端到端界，必须拒绝部署。
*证明*：三角不等式
`U_full − U_deploy ≤ |U_full − U_{K_ε}| + |U_{K_ε} − U_{K_ε,f_S}|`，
第一项由核证书、第二项由门的分歧分解（安全部分为 0，效用部分 `≤ α·Δu_max`）；协议一致性保证两次测量在同一度量空间，否则三角不等式无意义。

**引理 62（蒸馏右移 K*、不动 K_MAX）** 因 `c_d^S ≤ c_d`，第 3 轮引理 53 的一阶条件给出 `K_S* ≥ K_T*`（等号仅当 `ρ=1` 或 `c_S=c_T`）。但
`K_MAX(ι) = ⌊K₀/(1+K·H(ι|ℓ))⌋`
只依赖语义熵，与实现成本无关，故蒸馏**不抬高安全包线**。
可证伪预测：在固定门与固定 `δ_c` 下，E463 应观察到 `K_S* > K_T*` 而单位步安全违规率不变；若违规率随 `K` 上升，则引理 59 的脊柱假设被破坏（或学生提议越出支撑集），应判设计失败。

**引理 63（温度校准熵误差界）** 设动作/槽位取值数 `m`，校准分布与真实后验的 TV 距离 `≤ η`，则
`|Ĥ_cal − H(ι|ℓ)| ≤ η·log(m−1) + h_b(η)`，`h_b` 为二元熵。
故 `K_MAX^S` 的相对误差 `≤ (η log(m−1)+h_b(η))/H(ι|ℓ)`；当该上界超过 `15%`（与 E444 同门槛）⇒ 回退教师熵，仍不满足 ⇒ `K=1`。
*证明*：标准熵-TV 不等式；支撑集由定义 449 的 mask 限定为 `m`，故界有效。

**引理 64（Claim-Card 的可靠性）** 每条签发的 ClaimCard 满足：(i) 机制属于认证核；(ii) 至少一条真实回执；(iii) 证伪实验已预注册；(iv) 效应量与核证书共享评估协议。故不存在「无证据的贡献主张」；核证书失效时所有卡片降级为 `HYPOTHESIS`。
*证明*：生成器逐条检查四谓词，任一失败即剥离；剥离是纯投影（沿用定义 441），不改变数值路径。这是「创新点提炼」可审计性的保证，也是它与写作式摘要的本质区别。

**引理 65（摊销收益与 50Hz 保全）** 学生提议 `c_S ≪ c_T`，门判定 `O(1)`（风险分 + 阈值比较），教师查询异步且不在 50Hz 关键路径；主循环新增周期 `< 0.05 ms`（门 + 策略选择）。学生推理在主路径上仅当 `r ≤ τ_r` 且 `c_S < budget_slack`。正收益条件由定义 456 给出。继承第 3 轮引理 58 的硬实时结论。

## 7.5 干跑协议与预注册符号（不填造数）

本轮只做设计，不伪造实验结果。干跑时按以下顺序记录。

1. 先用历史 E441–E456 的回执离线跑 CIK，冻结 `K_ε` 与 `protocol_hash`；
2. 用冻结核训练 SPD，`D_T` 只取带回执状态；再在独立 `D_cal` 上拟合 `τ_r, τ_ood, τ_cal`；
3. 冻结三门参数后才允许上线，任何重拟合都必须换新证书并重跑 E459/E464。

预注册**符号**（可被证伪，不依赖具体数值）：
- **S1**：`K_S* > K_T*`，但同时段安全违规率之差 `Δviol = 0`（引理 62）；
- **S2**：实测总缺口落在 `[ε, ε + α·Δu_max + ε_v]` 内，且**不随压缩次数相乘**（引理 61）；
- **S3**：把脊柱偷偷放进核搜索 ⇒ E457 立刻失败（负对照，验证脊柱是承重的）；
- **S4**：OOD 守卫是主导失效模式——把 `τ_ood` 调松，失败集中出现在域外样本（E467），而非域内（引理 60）。

## 8. 本轮最大风险

**一句话**：`KernelCert` 与 `DistillCert` 都是在教师访问过的状态流形上校准的，而「省查询」恰发生在学生替代教师之处；系统可以在结构上完全安全（无越权、脊柱精确、CVC 照常通过），却在分布外把有限预算消耗在安全但无用的探测上，因此未覆盖的残余风险是**机会成本 / 效用证书在错误流形上失效**，而非不安全动作。
