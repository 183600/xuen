# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「SLAM」×「记忆检索」）

> R69 让系统学会了「问」，但它是个**失忆症患者**：每轮从 `o_t` 重新编码，不知道自己三小时前在同一个走廊已经解过同一个歧义，也不知道「走回去再看一眼」是最便宜、最不打扰人的求证。于是它**重复交互**、浪费预算，还把「消歧」几乎等同于「问人」——而人类最常用的消歧其实是「**我记得这里**」和「**我回去确认一下**」。
>
> 更尖锐的是，R69 自陈的最大风险是**模态权重未校准**（rectified flow 幻觉模态 → VoI 在错误信念上计算 → 追问一个幻影）。R69 的 MCG 门需要一个 ECE，但它手里没有可靠的 ECE 估计来源——部署中没有留出校准集。
>
> 本轮两个灵感正好补上这两块：
> - **SLAM** 提供「回访」：位姿图 + 闭环检测让「回到同一地点」成为一条**几何证据通道**，独立于语义模态、独立于人类回答——这是 R69「k 个正交证据源」里最缺的那一源；同时，同一地点跨时间比对是检测**缓变传感器漂移**的经典手段，正好接上 R69 的 FMA。
> - **记忆检索** 提供「先验的来处」：系统每轮都能观察到「我选的模态对不对」，把这些 (情形, 模态分布, 选择, 结果) 存成情景记忆，检索相似案例即可**用自身历史估出 ECE**，把 R69 那个不可测的校准门变成可测的门。
>
> 核心命题：**在「交互消歧」之前插入「记忆消歧」——不确定性先问记忆（回访/检索），记忆不成再问人，问不成再保守；记忆只能提供先验、永不覆盖当前观测；且记忆必须可重验、可溯源、可遗忘。** 命名 **MNEMO-RAS**（Memory-grounded Navigational Epistemic disambiguation with Map-anchored Observations）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我以前是否见过、在哪里见过、那次学到的还作数吗**」——记忆是第一顺位的求证对象，而遗忘是安全属性，不是缺陷。

## 0. 直觉与动机

**灵感 1（SLAM → 回访是一条正交证据通道）**
直觉：R69 的证据纪律要求「k 个正交源一致」，但它能拿到的源（几何残差、同步残差、零速残差、情绪残差、WM 残差）本质都来自**当前这一步**的传感器自洽性，彼此并不真正正交。SLAM 给出一条截然不同的通道：**你此刻的位姿/场景，能否与地图里某个历史关键帧在几何上对齐**。这种对齐不依赖语义模态、不依赖人类回答，攻击者要同时伪造「语义上合理」和「几何上对齐」才可能骗过它。当场景本身歧义（两条走廊雷同），闭环检测直接回答「你其实是回到了 A 点，A 点上次左廊可通」——这是**不打扰任何人的消歧**。

**灵感 2（记忆检索 → 从自身历史校准模态权重）**
直觉：R69 的致命假设是「流模型的模态分布可信」，而可信度要靠 ECE 衡量，可 ECE 需要一个带真值的校准集。具身系统其实一直在免费生产校准数据：每次它选了模态 m、执行、然后在后续观测中看到 m 是否为真（选了左廊，结果发现是死胡同），就得到一条 `(预测权重 ŵ, 实际正确模态 m*)` 样本。把这些样本存成情景记忆，检索与当前情形相似的子集，就能估计 `ECE_mem`。**记忆把「部署时无法校准」变成「部署时持续自校准」**——但前提是检索到的历史与当前可交换（exchangeable），而这恰恰是记忆最会骗人的地方。

**灵感 3（顺序 → 先回忆、再问、后保守）**
直觉：R69 的决策顺序是「不确定 → 算 VoI → 问」。但很多「不确定」根本不需要问：它可能只是**被遗忘的确定**。正确的顺序是三级：**记忆可解的（recall-resolvable）→ 直接定案；记忆不可解的 → 交互消解（R69）；都不行的 → 保守（R68 边界）**。这样交互预算只花在真正新颖的歧义上，R69 不是被替换而是被**前置了一层**：当 SEM 为空，R70 逐指令退化为 R69。这是本轮最重要的理论姿态——**每一层新记忆都必须能证明「没有它时旧系统照常运行」**，否则记忆就成了不可审计的第二套决策系统。

**灵感 4（跨时间比对 → 第三条漂移通道）**
直觉：R69 用 `(r_res↓, Δa↑)` 检测被标定吸收的缓变故障。但 SLAM 还提供一条更硬的通道：**回到同一地点时，当前传感器读数与历史关键帧读数的差 `r_lc`**。传感器慢漂时，即使标定把 `r_res` 抹平、甚至位姿图把它吸收成「地图轻微变形」，`r_lc` 仍会随重访次数累积升高。于是 R70 把 R69 的对偶通道升级为**三通道一致性** `(r_res, Δa, r_lc)`：三者联合可以区分「真漂移」「标定吸收」「地图被闭环错误拉偏」「环境真的变了」。这是对 R69 最脆弱处的再次加固，而且用的是完全不同物理原理的证据。

**灵感 5（记忆是双刃剑 → 自证循环是最危险的失效）**
直觉：一旦系统把过去的结论存成「经验」，就出现了一个 R69 没有的攻击面：**自证循环**。一次单源误答被存进记忆 → 下次遇到相似情形被检索出来 → 被当作「独立证据」→ 与另一次同源误答「一致」→ 通过 k-源纪律 → 盖章「已验证」→ 写回记忆。错误沿着记忆链自我增殖，且**越用越自信**。同理还有：假闭环（感知别名）、检索投毒（注入对抗关键帧）、过期记忆（环境已变）、记忆洪水（灌入大量伪造的「一致」记忆）。所以本轮必须同时交付：**来源 DAG + 根检查**（同一条决策链的记忆不得互为独立证据）、**几何重验**（地点召回必须过 χ²）、**衰减与再固化门**（新验证才允许更新）、以及铁律「召回只是提案，不是证据」。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（MNEMO-RAS 总览）** MNEMO-RAS = (SEM, PRR, MCD, RIG, MHG, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）：控制环内只读记忆，写入一律异步；
(ii) **记忆不覆盖当前观测**：召回只产生先验与提案，任何定案必须通过当前观测的重验（定义 317）；
(iii) **共享预算**：召回与交互共用 R69 的交互预算（定义 293-ii），检索次数亦受限（定义 324）；
(iv) **来源可溯**：每条记忆携带 `prov`（位姿、时间、来源、验证状态、Merkle 链），不可溯源的记忆不得进入「可定案」集合。

**定义 311（空间情景记忆 SEM）** 经验图 `G_e = (V_e, E_e)`。顶点 `e_i = (k_i, t_i, p_i, z_i, W_i, m_i^set, g_i, a_i, r_i, prov_i)`：`k_i` 关键帧描述子、`t_i` 时间、`p_i` SLAM 位姿、`z_i` 潜在编码、`W_i` 当时的模态权重、`m_i^set` 候选模态集、`g_i` 当时执行的信息动作（可空）、`a_i` 任务动作、`r_i ∈ {correct, wrong, unknown}` 事后结果、`prov_i` 来源证明。边 `E_e` 有三类：**空间边**（位姿图邻接/闭环）、**时间边**（同轨迹相邻）、**语义边**（描述子相似）。存储为追加日志 + HNSW 描述子索引 + 位姿图空间索引。

**定义 312（SLAM 地图与闭环证据）** SLAM 后端维护位姿图 `(X, Ω)`；闭环候选 `ℓ=(i,j)` 携带相对位姿测量 `z_ij` 与信息矩阵 `Ω_ij`，仅当 `χ²_ij = e_ij^T Ω_ij e_ij ≤ χ²_thr` 时接受。地图记 `M_s`。**关键性质**：闭环是几何/外观配准，独立于策略的语义模态分布与人类回答，故可作为 R69 证据纪律（定义 293-iii）中一个**真正正交**的证据源。

**定义 313（地点接地检索 PRR）** 查询 `q_t = (z_t, k_t, p_t)`。检索得分
`s(e) = sim(k_t,k_e) + λ_s·𝟙[d_geo(p_t,p_e) ≤ ρ] + λ_t·exp(−|t−t_e|/τ) + λ_v·𝟙[verified(e)]`。
取 top-N 得 `R_t`。区分两类召回：**地点召回**（由闭环/邻域命中，可几何重验）与**情景召回**（由语义相似命中，可能在别处发生，不可几何重验）。二者证据地位不同（定义 317）。

**定义 314（记忆先验与融合）** 记忆先验
`p_mem(M=m_k | o_t) ∝ Σ_{e∈R_t} w_ret(e)·κ(m_k, e.m)·ρ(r_e)`，
其中 `κ` 为模态相似核、`ρ(correct)=1, ρ(wrong)=0, ρ(unknown)=½`。与策略先验融合：
`p_fused ∝ p_θ(M|o_t)^{1−β} · p_mem^{β}`，`β = β(n_eff, verified_ratio, consist)`。支撑不足或不可信时 `β→0`（退回 R69）。

**定义 315（记忆校准 MCD）** 不依赖留出集，直接用召回的 `(ŵ_e, m*_e)` 对估计校准误差：按置信分箱 `B_b`，
`ECE_mem = Σ_b (|B_b|/N_eff)·|acc(B_b) − conf(B_b)|`。
`N_eff` 为按空间/语义距离加权后的有效样本数。`N_eff < N_min` 或 `ECE_mem > τ_ece` ⇒ 触发 R69 的 MCG（定义 306）：**禁用 VoI 与记忆定案，退回 R68 纯保守**。这把 R69 中「无法获得的 ECE」变成了可真测的量。

**定义 316（召回门控交互 RIG）** 三级消歧：
1. **记忆定案**：若 `n_eff ≥ n_min ∧ verified_ratio ≥ ρ_v ∧ H(p_fused) ≤ τ_epi ∧` 重验（定义 317）通过 ⇒ 直接定案，不消耗交互；
2. **交互消解**：否则若 `VoI(g*) > c(g*)` 且预算允许 ⇒ 走 R69 MINT；
3. **保守退避**：否则 ⇒ 走 R69 定义 307 的 `λ_floor`。
⇒ R69 恰为「SEM 为空 / 全部重验失败」边界。

**定义 317（记忆重验）** 一条将用于定案的记忆 `e` 必须同时通过：
(a) **几何一致**：当前与匹配地点的相对位姿对 `z_ij` 的 `χ²` 检验通过；
(b) **感知一致**：当前观测在历史关键帧下的似然 `−log p(o_t | k_e) ≤ τ_perc`（描述子匹配还不够）；
(c) **时相有效**：对非静态属性 `|t − t_e| ≤ T_exp`（几何衰减慢，语义衰减快，分字段设 TTL）；
(d) **来源合格**：`r_e` 必须来自「≥2 正交源一致」的验证交互或独立观测，不能来自单源问答。
任一项失败 ⇒ 该记忆降级为弱先验（`β` 调小），不得定案。**召回是提案，不是证据。**

**定义 318（记忆卫生 MHG）** (i) **来源 DAG 与根检查**：若一条候选证据链的根节点正是当前待判决策本身，判为循环、予以折扣并记 `self_confirm_flag`；(ii) **衰减**：非几何字段 `conf(e) ← conf(e)·exp(−Δt/τ_half)`；(iii) **再固化门**：仅当出现**新的独立验证**时才允许更新记忆（防止错误被反复强化）；(iv) **去重合并**：同源近重复记忆在计数中只算一次（防记忆洪水）。

**定义 319（记忆威胁模型 ℰ_mem）** 假闭环（感知别名）、检索投毒（注入对抗关键帧）、过期记忆（环境已变）、自证循环、记忆洪水（大量伪造的「一致」记忆）、地图被恶意闭环拉偏。并入 AIC：`ℰ_MNEMO = ℰ_FLUID × ℰ_mem`。

**定义 320（记忆证书 J_MNEMO）** `J_MNEMO = (J_FLUID, n_eff, verified_ratio, ECE_mem, recall_precision@N, lc_chi2, provenance_depth, self_confirm_flag, mem_ver)`。
`Valid ⇔ Valid(J_FLUID) ∧ ECE_mem ≤ τ_ece ∧ ¬self_confirm_flag ∧ recall_precision ≥ p_min ∧` 无未处置的地图跳变。

**定义 321（SLAM 增广安全 RAS-WM‡）** 安全包络使用地图一致的位姿信念。**闭环导致全局位姿跳变（map jump）时，已认证前缀必须重认证**；位姿图 χ² 拒绝 ⇒ 视为 WM 漂移的几何类比 ⇒ 保守性单调不降，绝不静默吸收跳变。

**定义 322（有效不确定性与召回 resolution bonus）** 定义召回消解后的残余
`U_epi^res = U_epi · (1 − ρ_recall)`，`ρ_recall = verified_ratio · (1 − H(p_fused)/log K)`。
`λ = λ_floor(U_ale + U_epi^res + U_epi^unverified)`：已重验消解的降保守，未重验的照旧视同 aleatoric。R69 为 `ρ_recall=0` 特例。

**定义 323（三通道漂移检测）** 重访时跨时间残差 `r_lc = ‖o_t ⊖ o_{t_e}‖`（同位姿下的传感器差）。判据：`r_lc↑` 且 `r_res≈0` 且 `Δa↑` ⇒ **传感器被标定+地图共同吸收的漂移**；`r_lc↑` 且 `r_res↑` ⇒ 环境真变；仅 `Δa↑` ⇒ 行为失配但几何一致（多为策略 OOD）。三通道联合分类，独立于 R69 的 FMA。

**定义 324（检索预算与自适应 N）** 常规 `N=8` 单次 HNSW 检索；仅当 `H(p_fused)` 落在不确定带 `[τ_lo, τ_hi]` 时升 `N=32`。检索与交互共享单位时间预算；超预算即按定义 316 第 3 级退避。

**定义 325（记忆写纪律）** 控制环内**只读**；写操作异步，且写入条件为：`r_i ∈ {correct, wrong}` 有事后真值、`prov_i` 完整、通过定义 318-iii 的再固化门。`unknown` 只作为弱负样本，永不参与定案计数。

**定义 326（防伪来源链）** `prov` 为带签名的 Merkle 链：`h_i = H(h_{i−1} ‖ k_i ‖ t_i ‖ p_i ‖ r_i ‖ source_i)`。外部注入的关键帧若无合法签名或链断裂，标记 `untrusted`，只能作弱先验，不能计入 `verified_ratio`。

## 2. 关键算法骨架

```python
# IP-264 SEM：空间情景记忆（追加日志 + HNSW + 位姿图索引；控制环只读）
class SpatialEpisodicMemory:
    def __init__(self, log, hnsw, pose_index, merkle):
        self.log, self.idx, self.pose, self.merkle = log, hnsw, pose_index, merkle

    def retrieve(self, q, N=8):
        cand = self.idx.search(q.k, N) | self.pose.within(q.p, RHO)   # 语义 ∪ 空间
        return rank(cand, key=lambda e: s(e, q))[:N]                 # 定义 313

    def write_async(self, e):                                        # 定义 325
        if e.prov_ok and e.r in ("correct", "wrong") and self.recon_gate(e):
            self.merkle.seal(e); self.log.append(e); self.idx.add(e)

# IP-265 PRR：地点接地检索（区分可几何重验的地点召回 / 不可重验的情景召回）
def place_grounded_recall(sem, q_t, slam):
    R = sem.retrieve(q_t, N=8)
    place = [e for e in R if slam.geodesic(q_t.p, e.p) <= RHO]
    episodic = [e for e in R if e not in place]
    return place, episodic                                       # 证据地位不同（定义 317）

# IP-266 MCD：用召回历史估计 ECE，把 R69 的校准门变成可测的门
def memory_calibration(R):
    if n_eff(R) < N_MIN: return None                             # 交给 R69 MCG
    bins = bin_by_conf(R, key=lambda e: max(e.W))
    return sum(len(B)/n_eff(R) * abs(acc(B) - conf(B)) for B in bins)

# IP-267 重验：召回只是提案，必须过几何/感知/时相/来源四关
def reverify(e, o_t, q_t, slam, now):
    return (slam.chi2(q_t.p, e.p) <= CHI2_THR                       # (a) 几何
            and -loglik(o_t, e.k) <= TAU_PERC                       # (b) 感知
            and all(now - e.t <= ttl(field) for field in DECAYING)  # (c) 时相
            and e.prov.verified_by_independent_source)              # (d) 来源

# IP-268 MHG：来源 DAG 根检查（阻断自证循环）+ 衰减 + 再固化门
def provenance_ok(e, target_decision, dag):
    root = dag.ultimate_root(e)
    if root == target_decision: return False                        # 自证循环（定义 318-i）
    return e.prov.signature_valid and not dag.has_cycle(e) and not e.duplicate

# IP-269 RIG：先回忆、再问、后保守（R69 为 SEM 为空边界）
def recall_gated_interaction(M, o_t, z_t, q_t, decisions):
    place, episodic = place_grounded_recall(M.sem, q_t, M.slam)
    R = [e for e in place if reverify(e, o_t, q_t, M.slam, M.now)]  # 只有地点召回可定案
    ece = memory_calibration(R)
    if ece is not None and ece > TAU_ECE:                           # MCG：不可信 → 纯保守
        return None, 0.0, "mcg_conservative"
    p_mem = memory_prior(R, episodic)                               # 定义 314
    p_fus = fuse(M.fmp.mode_prior(z_t), p_mem, beta(R))             # β 随支撑/一致性
    if H(p_fus) <= TAU_EPI and R and provenance_ok_all(R, decisions, M.dag):
        return "recall", rho_recall(R, p_fus), "resolved_by_memory"
    return None, 0.0, "needs_interaction"

# IP-270 三通道漂移检测：接 R69 的 FMA，补上跨时间几何通道
def drift_triplet(M, o_t, e_match):
    r_res = M.cof.residual()
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_t, M.cof.corrected(o_t))
    r_lc  = cross_time_residual(o_t, e_match) if e_match else 0.0
    return r_res, a_hat, r_lc                                       # 定义 323

# IP-275 主闭环（在 R69 的消歧处置处插入记忆层）
def MNEMO_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)      # R68/R69
    q = query_from(z, o, M.slam.pose)                               # 定义 313
    e_match = M.prr.best_place(q)
    # 1) 记忆优先：能定案就不打扰
    mode_rec, rho_rec, why = recall_gated_interaction(M, o, z, q, M.decisions)
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K=1), z, M.fmp.mode_head)
    if mode_rec == "recall":
        U_epi_res = U_epi * (1.0 - rho_rec)                         # 定义 322
        lam = max(M.efs.risk_scale(...), lam_floor(U_ale + U_epi_res))
        g = None
    else:
        # 2) 记忆不成 → 走 R69 交互（含其 MCG / 证据纪律）
        g = M.mint.choose_interaction(modes, o, M.budget)
        U_epi_res = U_epi if g is None else 0.0
        lam = max(M.efs.risk_scale(...), lam_floor(U_ale + U_epi_res))
    # 3) 三通道漂移 + 地图跳变 → 只收紧
    r_res, a_hat, r_lc = drift_triplet(M, o, e_match)
    drift = classify_drift(r_res, a_hat, r_lc)                      # 定义 323
    if drift != "none" or M.slam.jump_flag:
        lam = max(lam, 0.8); M.c_ras_wm.recertify(M.plan)           # 定义 321
    # 4) 认证、执行、异步写记忆
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    tau = M.pi_sigma.prefix_dispatch(M.mode.a[:k]) * lam
    M.sem.write_async(experience(o, z, modes, g, M.last_action, M.outcome, M.merkle))
    M.vqa_m.submit_async(why, rho_rec, r_res, a_hat, r_lc, M.slam.jump_flag)
    return k, lam, (mode_rec or M.mode), (U_ale, U_epi_res)
```

## 3. 推导

**引理 19（召回对交互次数的压缩）** 设歧义事件中可由记忆定案的比例为 `q`，地点召回精度 `p_r`，则单位事件期望交互次数从 `1` 降至 `1 − q·p_r`；在 A99（`q ≥ 0.5, p_r ≥ 0.9`）下交互预算至少释放 45%，且释放的比例随重访密度单调上升。要点：**记忆把「每次都问」变成「第一次问、之后回访」**——交互成本被摊销到地图生命周期上。

**引理 20（记忆校准的相合性与乐观偏差）** 若召回的 `(ŵ_e, m*_e)` 与当前可交换，则 `ECE_mem` 是部署 ECE 的相合估计，误差 `O(√(log(1/δ)/N_eff))`（Hoeffding/VC），故 MCG 门是可靠门。**但分布漂移时 `ECE_mem` 系统性偏乐观**：检索偏向「与当前相似且当时成功」的记忆，本质是选择偏差。系：`ECE_mem` 只能用来**否决**（越界即退回保守），不能用来**放行**超过 R69 已允许的 VoI 预算。

**引理 21（自证循环的增殖上界）** 设未验证记忆可参与互证，反馈比例 `η`（错误被写入并被再检索的概率），则 k 轮后错误被「验证」的概率上界为 `1 − (1−η)^k → 1`；引入来源 DAG 根检查后，循环被切断，错误自证概率降为 `≤ δ_p·ρ^{k−1}`（回到引理 18 的投毒上界）。**根检查是记忆从「放大器」变回「证据」的开关。**

**定理 18（MNEMO 严格包含 R69）** 在 A99–A101 下，MNEMO 的三级策略期望风险 ≤ R69；且当 SEM 为空、全部重验失败、`ECE_mem > τ_ece` 或 `self_confirm_flag` 为真时，两者**逐指令相同**。故 R69 = 「无记忆」边界；安全侧不让步，交互侧获得摊销收益。

**定理 19（记忆定案的错误上界）** 若地点召回精度 `p_r`、几何重验假接受率 `α`、感知重验假接受率 `β`，且三者独立，则错误定案概率 `≤ (1−p_r) + α·β`。系：**地点召回必须几何可重验**——情景召回（不可几何重验）不得单独定案，因此被排除在 `R` 之外（定义 317-a 的结构性理由）。

**定理 20（地图跳变下的安全保持）** 若闭环被 χ² 拒绝或位姿图发生跳变，RAS-WM‡ 强制重认证已认证前缀且保守性单调不降，则提交/换装不变式（R68 定理 15）保持，控制连续、无突变；错误闭环最多导致一次保守退避，不会导致一次危险执行。

## 6. 本轮最大风险

**一句话**：MNEMO-RAS 把「我以前见过」当作消歧的第一资源，但记忆是唯一一个**会被过去的自己污染**的证据源——一次错误交互、一次假闭环、一次环境变化都会被写成「经验」，在未来被检索出来当作独立证据；于是系统获得一种极具说服力的自欺：**用自己昨天的错误，给今天同样的错误盖章**。更糟的是 R69 的证据纪律在这里会失效，因为那些「一致证据」可能全部源自同一条记忆链。**记错，比不问更危险；遗忘不是缺陷，是安全属性。**

**次级风险与缓解**：
1. **自证循环 / 记忆洪水** → 来源 DAG 根检查 + 去重合并 + 再固化门（定义 318、引理 21）；
2. **假闭环 / 感知别名** → χ² 几何重验 + 感知重验双关，地点召回才可定案（定义 317、定理 19）；
3. **检索投毒** → 签名 Merkle 链，`untrusted` 不入 `verified_ratio`（定义 326、ℰ_mem）；
4. **过期记忆** → 分字段 TTL + 衰减，语义字段强衰减（定义 317-c、318-ii）；
5. **记忆校准的乐观偏差** → ECE_mem 只用于否决、不用于放行（引理 20 系）；
6. **地图跳变破坏安全** → RAS-WM‡ 强制重认证 + 保守性单调不降（定义 321、定理 20）。

---
**本轮最大风险一句话**：记忆能让系统用自己昨天的错误给今天同样的错误盖章——记错比不问更危险，因此记忆必须先可重验、可溯源、可遗忘，才配被称作证据。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** 控制环零学习写（只读记忆）；记忆不覆盖当前观测（召回只产生先验，定案须重验）；召回与交互共享预算；来源可溯（无 `prov` 不得进入可定案集合）。

**定义 311–312（SEM 与闭环证据）** 经验图存 `(k,t,p,z,W,modes,g,a,r,prov)`；闭环 `ℓ=(i,j)` 仅在 `χ²_ij ≤ χ²_thr` 时接受。闭环是几何/外观配准，独立于语义模态与人类回答，是 R69 证据纪律中真正正交的一源。

**定义 313（PRR 检索）** `s(e)=sim(k_t,k_e)+λ_s·𝟙[d_geo≤ρ]+λ_t·exp(−|t−t_e|/τ)+λ_v·𝟙[verified]`；区分地点召回（可几何重验）与情景召回（不可）。

**定义 314（记忆先验与融合）** `p_mem ∝ Σ w_ret·κ(m,e.m)·ρ(r_e)`；`p_fused ∝ p_θ^{1−β}·p_mem^{β}`，`β` 随支撑/一致性，支撑不足 `β→0`。

**定义 315（MCD 校准）** `ECE_mem = Σ_b(|B_b|/N_eff)|acc(B_b)−conf(B_b)|`；`N_eff<N_min` 或 `ECE_mem>τ_ece` ⇒ 触发 R69 MCG，禁用 VoI 与记忆定案。

**定义 316（RIG 三级消歧）** 记忆定案（重验通过）→ 交互消解（R69 MINT）→ 保守退避（`λ_floor`）。R69 = SEM 为空边界。

**定义 317（MRV 重验）** 几何一致（χ²）、感知一致（关键帧似然）、时相有效（分字段 TTL）、来源合格（≥2 正交源或独立观测）四关；任一失败只降为先验。

**定义 318（MHG 卫生）** 来源 DAG 根检查（根=当前决策 ⇒ 循环，折扣）；非几何字段指数衰减；仅新独立验证可再固化；近重复去重。

**定义 319（ℰ_mem）** 假闭环 / 检索投毒 / 过期记忆 / 自证循环 / 记忆洪水 / 地图被恶意闭环拉偏；`ℰ_MNEMO = ℰ_FLUID × ℰ_mem`。

**定义 320（J_MNEMO）** `Valid ⇔ Valid(J_FLUID) ∧ ECE_mem≤τ_ece ∧ ¬self_confirm ∧ recall_precision≥p_min ∧` 无未处置地图跳变。

**定义 321（RAS-WM‡）** 闭环位姿跳变 ⇒ 已认证前缀重认证；χ² 拒绝 ⇒ 保守性单调不降，绝不静默吸收。

**定义 322（resolution bonus）** `U_epi^res=U_epi(1−ρ_recall)`；`λ=λ_floor(U_ale+U_epi^res+U_epi^unverified)`；R69 为 `ρ_recall=0` 特例。

**定义 323（TCD 三通道漂移）** `r_lc↑∧r_res≈0∧Δa↑` ⇒ 标定+地图共同吸收的漂移；`r_lc↑∧r_res↑` ⇒ 环境真变；仅 `Δa↑` ⇒ 策略 OOD。

## 3. 关键算法伪代码

```python
# IP-264 SEM：空间情景记忆（追加日志 + HNSW + 位姿图索引；环内只读）
class SpatialEpisodicMemory:
    def retrieve(self, q, N=8):
        cand = self.idx.search(q.k, N) | self.pose.within(q.p, RHO)   # 语义 ∪ 空间
        return rank(cand, key=lambda e: s(e, q))[:N]                  # 定义 313

    def write_async(self, e):
        if e.prov_ok and e.r in ("correct", "wrong") and self.recon_gate(e):
            self.merkle.seal(e); self.log.append(e); self.idx.add(e)

# IP-265 PRR + IP-267 MRV：只有可几何重验的地点召回能定案
def recall_candidates(sem, q_t, slam):
    R = sem.retrieve(q_t, N=8)
    place   = [e for e in R if slam.geodesic(q_t.p, e.p) <= RHO]
    episodic = [e for e in R if e not in place]
    return place, episodic

def reverify(e, o_t, q_t, slam, now):
    return (slam.chi2(q_t.p, e.p) <= CHI2_THR                       # 几何
            and -loglik(o_t, e.k) <= TAU_PERC                       # 感知
            and all(now - e.t <= ttl(f) for f in DECAYING)          # 时相
            and e.prov.verified_by_independent_source)              # 来源

# IP-266 MCD：用召回历史估 ECE（只用于否决，不用于放行）
def memory_calibration(R):
    if n_eff(R) < N_MIN: return None
    bins = bin_by_conf(R, key=lambda e: max(e.W))
    return sum(len(B)/n_eff(R) * abs(acc(B) - conf(B)) for B in bins)

# IP-268 MHG：根检查阻断自证循环
def provenance_ok(e, target_decision, dag):
    if dag.ultimate_root(e) == target_decision: return False        # 定义 318-i
    return e.prov.signature_valid and not dag.has_cycle(e) and not e.duplicate

# IP-269 RIG：先回忆 → 再问 → 后保守（SEM 为空即 R69）
def recall_gated_interaction(M, o_t, z_t, q_t):
    place, episodic = recall_candidates(M.sem, q_t, M.slam)
    R = [e for e in place if reverify(e, o_t, q_t, M.slam, M.now)]
    ece = memory_calibration(R)
    if ece is not None and ece > TAU_ECE:
        return None, 0.0, "mcg_conservative"                        # 不可信 → R68
    p_fus = fuse(M.fmp.mode_prior(z_t), memory_prior(R, episodic), beta(R))
    if H(p_fus) <= TAU_EPI and R and provenance_ok_all(R, M.decisions, M.dag):
        return "recall", rho_recall(R, p_fus), "resolved_by_memory"
    return None, 0.0, "needs_interaction"                           # 交给 R69 MINT

# IP-270 TCD：三通道漂移（接 R69 FMA）
def drift_triplet(M, o_t, e_match):
    r_res = M.cof.residual()
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_t, M.cof.corrected(o_t))
    r_lc  = cross_time_residual(o_t, e_match) if e_match else 0.0
    return r_res, a_hat, r_lc                                       # 定义 323

# IP-275 主闭环（在 R69 的消歧处置处插入记忆层）
def MNEMO_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    q = query_from(z, o, M.slam.pose)
    e_match = M.prr.best_place(q)
    mode_rec, rho_rec, why = recall_gated_interaction(M, o, z, q)   # 先回忆
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K=1), z, M.fmp.mode_head)
    if mode_rec == "recall":
        U_epi_res = U_epi * (1.0 - rho_rec)                         # 定义 322
        g = None
    else:                                                           # 再问（R69）
        g = M.mint.choose_interaction(modes, o, M.budget)
        U_epi_res = U_epi if g is None else 0.0
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + U_epi_res))
    r_res, a_hat, r_lc = drift_triplet(M, o, e_match)               # 三通道
    if classify_drift(r_res, a_hat, r_lc) != "none" or M.slam.jump_flag:
        lam = max(lam, 0.8); M.c_ras_wm.recertify(M.plan)           # 定义 321
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    tau = M.pi_sigma.prefix_dispatch(M.mode.a[:k]) * lam
    M.sem.write_async(experience(o, z, modes, g, M.last_action, M.outcome, M.merkle))
    M.vqa_m.submit_async(why, rho_rec, r_res, a_hat, r_lc, M.slam.jump_flag)
    return k, lam, (mode_rec or M.mode), (U_ale, U_epi_res)
```

## 4. 推导

**引理 19（召回压缩交互）** 歧义事件中可记忆定案比例 `q`、地点召回精度 `p_r`，期望交互次数从 1 降至 `1−q·p_r`。A99（`q≥0.5,p_r≥0.9`）下预算至少释放 45%，且随重访密度单调上升：交互成本被摊销到地图生命周期。

**引理 20（校准相合性与乐观偏差）** 可交换时 `ECE_mem` 为部署 ECE 的相合估计，误差 `O(√(log(1/δ)/N_eff))`；分布漂移时因「相似且成功」的选择偏差而**系统性乐观**。系：ECE_mem 只用于否决（越界退回保守），不用于放行超额 VoI 预算。

**引理 21（自证循环上界）** 未验证记忆可互证时，`k` 轮后错误被「验证」的概率 `1−(1−η)^k→1`；加入来源 DAG 根检查后循环被切断，自证概率降回 `≤δ_p·ρ^{k−1}`（引理 18 上界）。根检查是记忆从「放大器」变回「证据」的开关。

**定理 18（MNEMO 严格包含 R69）** A99–A101 下，MNEMO 三级策略期望风险 ≤ R69；当 SEM 为空 / 全部重验失败 / `ECE_mem>τ_ece` / `self_confirm_flag` 为真时两者逐指令相同。R69 = 「无记忆」边界；安全不让步，交互获摊销收益。

**定理 19（记忆定案错误上界）** 地点召回精度 `p_r`、几何假接受率 `α`、感知假接受率 `β`，独立时错误定案概率 `≤(1−p_r)+α·β`。系：情景召回不可几何重验，故结构性禁止其单独定案（定义 317-a）。

**定理 20（地图跳变安全保持）** 闭环 χ² 拒绝或位姿跳变时，RAS-WM‡ 强制重认证且保守性单调不降 ⇒ 提交/换装不变式（R68 定理 15）保持；错误闭环最多致一次保守退避，不会致危险执行。

## 7. 本轮最大风险

**一句话**：MNEMO-RAS 把「我以前见过」当作消歧的第一资源，但记忆是唯一一个**会被过去的自己污染**的证据源——一次错误交互、一次假闭环、一次环境变化都会被写成「经验」，在未来被检索出来当作独立证据；于是系统获得一种极具说服力的自欺：**用自己昨天的错误，给今天同样的错误盖章**。更糟的是 R69 的证据纪律在这里会失效，因为那些「一致证据」可能全部源自同一条记忆链。**记错，比不问更危险；遗忘不是缺陷，是安全属性。**

**次级风险与缓解**：自证循环/记忆洪水（来源 DAG 根检查 + 去重 + 再固化门，定义 318、引理 21）；假闭环/感知别名（χ² + 感知双关，定义 317、定理 19）；检索投毒（签名 Merkle，`untrusted` 不入 `verified_ratio`，定义 326）；过期记忆（分字段 TTL + 衰减）；记忆校准乐观偏差（ECE_mem 只用于否决，引理 20 系）；地图跳变（RAS-WM‡ 强制重认证，定理 20）。

---
**本轮最大风险一句话**：记忆能让系统用自己昨天的错误给今天同样的错误盖章——记错比不问更危险，因此记忆必须先可重验、可溯源、可遗忘，才配被称作证据。
