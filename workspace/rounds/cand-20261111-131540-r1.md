# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「最小可行产品」×「数据规模」）

> 第 54 轮把技能组合推进到 **动作空间剖面 × 云边协同 × 动作-鲁棒性双证书**，体系已膨胀到 120 个 IP。本轮用 **MVP 做减法**、用 **数据规模做统计学拷问**：v16+++ 的证书几乎都是有限样本点估计，却被当作确定性谓词使用。核心矛盾：**H22：完整体系的能力层很厚，但部署决策可能只依赖极少数证书，多余 IP 只增加工程与验证成本**；**H23：`α_S`、`ρ`、`compat`、`δ_a` 均为估计量，样本量不足或分布偏移时，证书会系统性高估可用性，产生“统计假阳性”**。

## 0. 直觉与动机

**灵感 1（MVP = 决策充分，而非能力充分）**
直觉：前 54 轮一直在回答“还能加什么能力”，MVP 反过来问“删掉哪一个 IP 会让部署决策改变”。若删掉 IP `i` 后，在任务分布上的部署/拒绝判定几乎不变，则 `i` 不属于 MVP。于是 MVP 不是能力最小集，而是 **证书最小集**：动作剖面 `α_S` 的置信下界 + 鲁棒性谱 `ρ` 的置信下界 + 一个边端验证器 + 一条解释回传通道。技能组合图、云边分层、JTC 都是可插拔扩展，而非首部署前提。

**灵感 2（数据规模 = 置信半径，而非日志吨位）**
直觉：`α_S(a)` 不是真值，而是 `n_a` 次伯努利试验的估计 `α̂_S(a)`。真正可签发的是 Hoeffding 下置信界 `α_S^-(a)=α̂ - sqrt(ln(2/δ_a)/(2n_a))`。样本越少、维度越多、链越长，半径越大；一旦 `α^-` 跌破阈值，正确动作不是“再跑一次仿真取好看结果”，而是 **弃权并主动采样**。这把“数据规模”从工程指标变成了证书自由度。

**灵感 3（三值证书代数 → 从二值谓词到保守三值逻辑）**
直觉：现有定义 `cover(S,A_T)=1`、`ρ≥ρ_min`、`δ_a<Θ_a` 都是二值谓词，隐含“估计=真值”。改为三值 `IN / UND / OUT`：`IN` 要求 **下界** 过阈，`OUT` 要求 **上界** 跌破，其余为 `UND`。组合采用保守代数：`IN⊗IN=IN`；任一 `OUT→OUT`；否则 `UND`。这会自动阻止“样本不足却组合出可部署路径”的虚假证书。

**灵感 4（有效数据规模 `n_eff` → 数据规模墙）**
直觉：数据规模不是标量 `n`，而是 `n_eff = n · coverage`。仿真分布 `P_s` 与部署分布 `P_d` 不一致时，用重要性权重 `w=dP_d/dP_s` 计算有效样本量 `ESS=(Σw)²/Σw²`。**再多的同分布仿真也无法修复覆盖不足**：当 `cov↓`，置信半径 `∝1/sqrt(n_eff)` 会饱和，形成“数据规模墙”。这解释了为什么 v16+++ 的 action-profile 在真实边端常出现“仿真覆盖很好、实机动作错位”。

**灵感 5（证书预算与链长上限 → MVP 必须限制组合长度）**
直觉：组合置信度按 union bound 消耗。一条 `k` 步技能链、每步 `|A_T|` 个动作、`|𝔇_ρ|` 个鲁棒性维度，要维持联合置信 `1-δ`，每步每维可用误差预算按 `δ/(k|A_T||𝔇_ρ|)` 分配。总样本固定时，链越长每步样本越少、半径越大，整条链最终一起变 `UND`。因此 MVP 需要显式的 `k_max(δ,ε)`，而不是无限拼接证书。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（最小证书内核 MCK）**
给定完整体系 `𝕊=(𝕀,𝔻)`，`𝕀` 为 IP 集合，`𝔻` 为任务分布 `𝒯` 上的部署决策函数。子集 `𝕀'⊆𝕀` 是 **ε-决策充分** 的，若
```
Pr_{T~𝒯}[ 𝔻_{𝕀'}(T) ≠ 𝔻_𝕀(T) ] ≤ ε。
```
最小证书内核 `𝕀* = argmin_{𝕀' 为 ε-充分} ( |𝕀'| + λ·cost(𝕀') )`。MVP 即实现 `𝕀*` 的最小工程切片，而非能力全集。

**定义 122（数据规模感知的动作剖面）**
对动作 `a` 做 `n_a` 次伯努利观测 `X_1..X_{n_a}`，`α̂_S(a)= (1/n_a)ΣX_i`。在置信水平 `1-δ_a` 下：
```
α_S^-(a) = max(0, α̂_S(a) - sqrt( ln(2/δ_a) / (2 n_a) ))
α_S^+(a) = min(1, α̂_S(a) + sqrt( ln(2/δ_a) / (2 n_a) ))
```
约定 `n_a=0 ⇒ α^-=0, α^+=1`（完全弃权，凭空不得签发证书）。

**定义 123（三值证书与保守组合）**
证书判定 `τ(c) ∈ {IN, UND, OUT}`：
- `IN` 当 `α_S^-(a) ≥ θ_cov` 且 `ρ^-(d) ≥ ρ_min(d)`，对所有 `a∈A_T, d∈𝔇_ρ`；
- `OUT` 当存在 `a` 使 `α_S^+(a) < θ_cov`，或存在 `d` 使 `ρ^+(d) < ρ_min(d)`；
- 其余为 `UND`。
组合 `⊗` 保守定义：`IN⊗IN=IN`；任一 `OUT⇒OUT`；否则 `UND`。该代数单调且不会把不确定性升级为可用性。

**定义 124（样本复杂度阈值）**
单动作单维度：`n_min(ε,δ)=⌈ln(2/δ)/(2ε²)⌉`。任务动作序列 `A_T` 与维度集 `𝔇_ρ` 下，按 union bound 分配：
```
n_min(ε,δ) = ⌈ |A_T|·|𝔇_ρ| · ln(2|A_T||𝔇_ρ|/δ) / (2ε²) ⌉。
```
当 `n_a < n_min` 时，仅允许 `UND`，不得 `IN`。

**定义 125（有效数据规模与分布覆盖）**
采样分布 `P_s`、部署分布 `P_d`，权重 `w_i=dP_d/dP_s(a_i)`。有效样本量
```
ESS = (Σ_i w_i)² / Σ_i w_i²,     n_eff = min(n, ESS)。
```
置信半径按 `rad ∝ 1/sqrt(n_eff)` 计算，而非 `1/sqrt(n)`。覆盖度 `cov = 1 - TV(P_s,P_d)`；当 `cov < cov_min` 时，MVP 强制输出 `UND`。

**定义 126（MVP 部署契约与边际决策价值）**
MVP 契约 `M=(S, α^-, ρ^-, V, Abs, k_max)`：`S` 为技能集，`V` 为边端验证器，`Abs` 为弃权/主动采样策略，`k_max` 为最大可证书化链长。部署允许 **当且仅当** 三值判定为 `IN` 且链长 `k≤k_max`。
IP `i` 的 **边际决策价值** `MDV(i)=Risk(𝕀\{i}) - Risk(𝕀)`；仅当 `MDV(i)>c_i`（`c_i` 为工程/验证成本）时，`i` 进入 MVP。

## 2. 关键推导

**推导 1（Hoeffding 半径与 n_min）**
对单动作，`P(α̂-α ≥ ε) ≤ exp(-2nε²)`。令其等于 `δ/2` 得 `n ≥ ln(2/δ)/(2ε²)`，与定义 124 一致。半径随 `n` 以 `n^{-1/2}` 衰减，故学习曲线在 log-log 上斜率约为 `-0.5`。

**推导 2（组合的置信预算）**
设链长 `k`、每步 `m=|A_T|` 动作、`D=|𝔇_ρ|` 维度，需联合置信 `1-δ`。对 `k·m·D` 个事件做 union bound，每个事件分配 `δ/(kmD)`：
```
n_total ≥ k·m·D · ln(2kmD/δ) / (2ε²)。
```
因此固定 `n_total` 时 `ε ∝ sqrt(k)`；当半径膨胀到阈值带宽度，整条链变为 `UND`。由此得
```
k_max ≈ max{ k : rad(k) ≤ θ_cov - α̂_min }。
```
**推导 3（数据规模墙）**
若 `n→∞` 但 `cov→0`，则 `ESS→0`，`n_eff` 不随 `n` 增长，`rad` 不下降。即“同分布数据规模”与“分布覆盖”是两个独立轴；只堆前者会在某点后完全失效。

## 6. 本轮最大风险

**一句话**：本轮把证书从“点估计谓词”改成“统计置信三值判定”，并用 MVP 砍到最小内核；但整套 soundness 只成立于**样本可交换且仿真覆盖部署分布**这一前提，一旦发生协变量偏移，`n` 继续增大也无法降低 `ESS`，系统会在高置信外观下给出虚假 `IN`，故 MVP 必须以 **`n_eff`/覆盖度而非样本量作为放行闸门**，宁可弃权，绝不把“大数据规模”误当成“分布正确”。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-MVP-DS（MCE×DSC×TVC×ESS×CBD）

> 承接第 54 轮产物 v31。本轮不继续堆能力，而是用 **MVP（最小可行产品）** 对 120 个 IP 做决策充分性约简，用 **数据规模** 把确定性证书改写为统计置信证书。核心新增：
> - **MCE（Minimal Certificate Extraction）**：以决策一致率为准则提取最小证书内核 `𝕀*`；
> - **DSC（Data-Scale-aware Certifier）**：把 `α_S`、`ρ`、`compat`、`δ_a` 从点估计改为置信界；
> - **TVC（Three-Valued Certificate）**：`IN/UND/OUT` 保守代数，禁止不确定性升级为可用性；

> - **CBD（Certificate Budget Discipline）**：按 union bound 分配置信预算并给出链长上限 `k_max`。
>
> IP 编号：IP-121~IP-126（共 6 个新增）；降级/裁剪 IP-116、IP-117、IP-120 为 MVP 之后的扩展插件。

## 2. 关键算法 伪代码

### IP-122 DSC（Data-Scale-aware Certifier）

```python
import math

def hoeffding_bounds(samples, delta):
    n = len(samples)
    if n == 0:
        return 0.0, 1.0
    mean = sum(samples) / n
    rad = math.sqrt(math.log(2.0 / delta) / (2.0 * n))
    return max(0.0, mean - rad), min(1.0, mean + rad)

def n_min(eps, delta, m_actions, d_dims):
    m = m_actions * d_dims
    return math.ceil(m * math.log(2.0 * m / delta) / (2.0 * eps * eps))

def data_scale_certify(skill, A_T, delta, theta_cov, rho_min, cov, cov_min):
    if cov < cov_min:
        return ('UND', 'low_coverage')
    d_a = delta / max(1, len(A_T))
    for a in A_T:
        lo, hi = hoeffding_bounds(skill.samples[a], d_a)
        if hi < theta_cov:
            return ('OUT', ('action', a, lo, hi))
        if lo < theta_cov:
            return ('UND', ('action', a, lo, hi))
    d_r = delta / max(1, len(skill.rho_dims))
    for d in skill.rho_dims:
        lo, hi = hoeffding_bounds(skill.rho_samples[d], d_r)
        if hi < rho_min[d]:
            return ('OUT', ('rho', d, lo, hi))
        if lo < rho_min[d]:
            return ('UND', ('rho', d, lo, hi))
    return ('IN', None)
```

### IP-124 ESS（Effective Sample Size）

```python
def effective_sample_size(weights):
    s1 = sum(weights)
    s2 = sum(w * w for w in weights)
    return 0.0 if s2 == 0 else (s1 * s1) / s2

def n_effective(n, weights, coverage):
    return min(n, effective_sample_size(weights)) * coverage
```

### IP-121 MCE（Minimal Certificate Extraction）

```python
def extract_mck(ip_set, task_battery, eps, cost, lambda_):
    core = set(ip_set)
    for ip in sorted(ip_set, key=lambda i: cost[i], reverse=True):
        trial = core - {ip}
        if decision_disagreement(trial, ip_set, task_battery) <= eps:
            core = trial
    mck = min((core,), key=lambda c: len(c) + lambda_ * sum(cost[i] for i in c))
    mdv = {i: risk(ip_set - {i}, task_battery) - risk(ip_set, task_battery)
           for i in ip_set}
    return mck, mdv
```

### IP-125 CBD（Certificate Budget Discipline）

```python
def chain_length_cap(delta, eps, slack, per_step_actions, per_step_dims):
    budget = delta
    k = 1
    while True:
        m = (k + 1) * per_step_actions * per_step_dims
        radius = math.sqrt(math.log(2.0 * m / (budget / m)) / (2.0 * per_step_actions))
        if radius > slack:
            return k
        k += 1
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| IP-121 MCE | `O(|𝕀|·B·D)` | `O(|𝕀|)` | 贪心 ε-充分，删除可回滚 |
| IP-122 DSC | `O(|A_T|+|𝔇_ρ|)` | `O(1)` | Hoeffding 界，`n_a=0⇒UND` |
| IP-123 TVC | `O(k)` | `O(1)` | 保守单调，无假 `IN` |
| IP-124 ESS | `O(n)` | `O(1)` | 权重非负，`ESS≤n` |
| IP-125 CBD | `O(k_max)` | `O(1)` | union bound 预算闭合 |

**正确性定理（Data-Scale-Aware Certificate Soundness）**
假设样本在给定动作/维度上可交换，且 `P_s` 对 `P_d` 绝对连续、权重估计无偏。则对任一证书 `c`：
```
Pr[ τ(c)=IN 且真实覆盖/鲁棒性不达标 ] ≤ δ · (1/cov)，
```
当 `cov=1` 时退化为 `≤δ`。对 `k` 步组合，联合假 `IN` 概率 `≤ Σ_{i=1}^{k} δ_i`（TVC 保守代数保证不会产生未经证实的 `IN`）。若 `cov<cov_min`，判定强制为 `UND`，soundness 以“弃权”而非“误放行”方式保持。

**关键推论（链长上限）**：固定总样本 `n_total`，`k` 步链的每步样本为 `n_total/k`，置信半径 `∝sqrt(k)`；当 `sqrt(k)·rad_1 > θ_cov-α̂_min` 时，整条链退化为 `UND`。故 MVP 应限制 `k≤k_max`，而不是无限延长证书链。

```
│
├─ 扩展层（MVP 验证后按 MDV>成本 逐个启用）
│   ├─ L0.5+ 鲁棒性层 (TRO,RXC,RCO,REX,RTA,TRC,RUR) ← v53（默认仅 TRO/REX）
│   ├─ L0.5++ 动作-协同层 (ACS,SCOM,CEC,AEC,JTC) ← v54（降级为插件）
│   └─ L1–L6 其余能力层
│
└─ 安全绊线白名单（MVP 不可删）
```

JCPS 输出增加数据规模字段：
`(v,a,m,q,ι,κ,g,λ,τ,σ,ρ,Explain,RUR_state,α_S,A_cert,γ_ce,δ_a, n_eff, cov, τ_cert, k_max)`

其中新增：
- `n_eff` 有效样本量；
- `cov` 分布覆盖度；
- `τ_cert ∈ {IN,UND,OUT}` 三值证书；
- `k_max` 链长上限。

## 5. 实验设计 E162–E166

| 实验 | 数据集/设置 | 指标 | 目标 |
|---|---|---|---|
| E162 MVP 消融 | 120 IP × 任务电池 | 决策一致率、核心 IP 数、工程 LOC 降幅 | ≥98%、≤8、≥70% |
| E163 置信界校准 | 多动作多维度合成 + 实机 | LCB 覆盖率、虚假 `IN` 率 | ≥1-δ、≤δ |
| E164 三值 vs 二值 | `n` 从 10 到 10^4 | 错误部署率、弃权率 | 错误部署降≥50%，弃权≤10% |
| E165 数据规模律 | 同分布 vs sim-to-real 偏移 | `ε~n^{-α}` 斜率、`ESS` 预测力 | 斜率≈-0.5；AUC≥0.8 |
| E166 链长上限 | `k=1..10` | 证书有效性、实测 `k_max` | 与理论误差≤15% |

**预期结果（待验证）**：
- 当 `n<n_min`，二值方案虚假 `IN` 显著高于三值方案；三值以约 5–10% 弃权换取近一个数量级的错误部署下降；
- 在 sim-to-real 偏移下，`ε` 不随 `n` 继续下降，而 `n_eff` 与失败率强相关（`R²≥0.7`），支持“数据规模墙”假设；
- 贪心消融后核心约 6–8 个 IP，决策一致率 >98%，说明 v16+++ 中大部分 IP 属扩展而非首部署必需。

## 6. 本轮最大风险

**一句话**：本轮把证书从“点估计谓词”改成“统计置信三值判定”，并用 MVP 砍到最小内核；但整套 soundness 只成立于**样本可交换且仿真覆盖部署分布**这一前提，一旦发生协变量偏移，`n` 继续增大也无法降低 `ESS`，系统会在高置信外观下给出虚假 `IN`，故 MVP 必须以 **`n_eff`/覆盖度而非样本量作为放行闸门**，宁可弃权，绝不把“大数据规模”误当成“分布正确”。
