# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「多视角视觉」×「视觉语言模型」）

> R69 把不确定性拆成 aleatoric/epistemic，用流匹配多模态策略显式表达动作歧义，再用「看/问/触」主动消解。它解决的是「**动作该选哪一个模态**」，却把观测 `o_t` 当成一个已经解释好的整体：它从不问「**我看到的，到底是不是同一个东西**」。于是 R69 的最大风险——模态分布不可信、在错误信念上算 VoI、自信地追问一个幻影——其实有一个更靠前的根：**语义解释本身可能错，而 R69 没有任何独立于学习模型的裁决者**。与此同时，R69 的「问」只能问人，从未让**场景自己作证**。
>
> 本轮两个灵感正好补上两块缺失：
> - **多视角视觉**：世界会从不同方向自证。同一 3D 点必须满足极线约束、重投影一致、视差—深度自洽；幻觉、对抗贴片、屏幕里的一张照片，很难在所有视角下同时三角化。这给出一条**非学习的、可几何证伪的**证据通道。
> - **视觉语言模型**：它能把几何说不出名字的东西命名（杯子/把手/湿滑/台阶），但会幻觉、会顺从提示、会被场景文字注入、会对同一物体给出同样自信却互相矛盾的说法。关键不是「用 VLM 判断」，而是**把 VLM 降为提案者（proposer），把裁决权交给几何（verifier）**。
>
> 核心命题：**把 epistemic 的第一性来源从「动作模态」上溯到「语义解释」，用联合熵 `H(S,A)=H(S)+E[H(A|S)]` 显式暴露 R69 系统性忽略的 `H(S)`；用多视角几何把开放词汇假设编译成可证伪谓词并裁决，用共形门控把「接受」变成有覆盖率保证的检验，用主动换视角消解几何可约歧义；只有几何无法裁决（语义别名）时才退回 R69 的交互、再退回 R68 的保守。** 命名 **TRIAD-RAS**（Triangulated Reprojection-verified Instruction-Aligned Disambiguation）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我看到的，是一个物体的多个视角，还是一个视角的多个幻觉——能不能换个角度，让世界自己作证？**」

## 0. 直觉与动机

**灵感 1（多视角视觉 → 几何冗余是一条独立证据通道）**
直觉：R69 的观测是「一只眼睛看到的一张图」，它把不确定性几乎全部归给策略的动作模态。但很多致命歧义发生在**观测层**：遮挡、反光、透明、尺度、单目深度退化。多视角的价值不是「更多像素」，而是**几何冗余**——同一个 3D 点必须在多台相机下满足极线约束、重投影一致、视差与深度自洽；一个假设诱导的 3D 结构若在某个视角下重投影到错误位置、或需要穿模才能解释，它就不是「低置信」，而是**被物理证伪**。伪目标（VLM 幻觉出的物体、对抗贴片、屏幕回放）很难在所有视角、所有基线下同时自洽：**世界会从不同方向自证，幻觉不会**。这给 R69 补上一条它完全没有的、非学习、可几何检验的证据通道。

**灵感 2（视觉语言模型 → 能命名，但置信度不是概率）**
直觉：几何能说「这里有一个满足支撑与包络约束的刚体」，却说不清它是「杯子」还是「花瓶」、能不能「从左侧抓」。VLM 恰好补上开放词汇与语言落地。但 VLM 的 softmax/置信度不是校准概率：它会幻觉出并不存在的指称、会顺着提示附和、会把场景里的文字当成指令、会对同一物体在不同视角给出互相矛盾却同样自信的描述。R69 只让冻结 LLM 解码问句，从未让 VLM 进入感知。R70 的正确用法不是「信 VLM」，而是**让它产生可被检验的假设**：语言负责「可能是什么」，几何负责「是否可能」。

**灵感 3（提案—裁决分离 → 幻觉是可证伪的）**
直觉：R69 最大的风险是「模态分布不可信 → 在错误信念上算 VoI → 自信地追问幻影」。根因不是 VLM 或流模型不够强，而是**没有独立裁决者**：系统只能相信自己的学习模型。TRIAD 的核心纪律是：VLM 提出的每个语义假设，必须被编译成几何/运动学谓词（支撑、包络、可达、碰撞、稳定、自由空间），再用多视角重投影一致性去**尝试证伪**。通过 = 保留为候选；不通过 = **不是「置信度低」，而是被排除**；无法编译成可证伪谓词的假设 = 只能停留在 Level 0，绝不能单独消解 U_epi。这把「信不信 VLM」换成了「这个断言能不能被世界检验」。

**灵感 4（联合熵 → R69 漏掉了 H(S)）**
直觉：R69 把 epistemic 定义为「动作模态之间的熵」。但这默认了观测已经被唯一解释——它把语义变量 S 当成常数。正确的分解是 `H(S,A)=H(S)+E[H(A|S)]`：动作歧义只是条件熵，前面还有一个语义熵。当画面里「那个东西」本身没被认准时，讨论「绕左还是绕右」是在一个未定义的对象上做精确计算。更严重的是：`U_epi^+ ≥ H(A)` 恒成立，**R69 必然低估 epistemic**，而它越低估就越敢降 λ，这正是它最大风险的形式化来源。TRIAD 直接攻击最前面的 `H(S)`；`H(A|S)` 仍交给 R69 的 FMP/AUD。这样新层不是并列替代，而是对 R69 缺失项的补全。

**灵感 5（主动换视角 = 对观测过程做一个自己就能完成的实验）**
直觉：R69 的信息动作是看/问/触（gaze/probe/ask）。多视角补上第四个、也是唯一**不依赖他人**的：换一个视角看（移动、转头、变焦、切换相机）。它的信息价值可以用几何解析地预测：新视角带来的视差与基线如何降低三角化方差、如何解除遮挡。于是 R69 的 VoI 控制器自然升级为 next-best-view。更妙的是：R69 的「问人」是社会证词，可能被撒谎与从众污染；“换个视角”则是**自己做的观测实验**，不需要信任任何人——但它也有代价（运动、时间、暴露），且**并非所有歧义都能被视角消除**（语义别名、远距离小视差），所以必须诚实退避。

**灵感 6（新威胁：几何也会被欺骗）**
直觉：一旦系统把几何当裁判，攻击面就从「骗过 VLM」升级为「骗过物理」。**跨视角共谋**（攻击者布置在所有视角下都一致的可实现假象）、**语义别名**（几何完全相同的杯子和花瓶，视觉无法区分功能）、**反射/透明/屏幕回放**、**场景文字注入**，都能让「几何已验证」变成一个更危险的说法。更根本的是一条不可判定性：如果两个假设诱导的 3D 结构在容差内几何等价、只是任务功能不同，那么**再多的视角也分不开**。因此 TRIAD 必须交付：可证伪谓词库、共形门控、别名鲁棒动作、视角动作安全认证，以及「几何无法裁决就诚实说不知道」的退避纪律。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（TRIAD-RAS 总览）** TRIAD-RAS = (MVG, VLP, PCG, CFG, ACT, SAD, SAA, RAS-WM†)。在 R69 三不变式（实时流零学习写、交互预算硬约束、证据纪律）之上新增四条：
(i) **提案—裁决分离**：VLP 的输出只是假设，任何 VLM 原始分数不得直接进入 λ、动作选择或 U_epi 的消解；
(ii) **证伪优先**：一个语义假设若不能被编译为可证伪的几何/运动学谓词，就只能停留在 Level 0，不得单独消解 U_epi；
(iii) **诚实不可判定**：几何等价但功能不同的假设（语义别名）不得由更多视角强行区分，必须走别名鲁棒动作或交回 R69 交互；
(iv) **视角动作安全**：任何换视角/变焦/选相机动作必须通过与任务动作相同的 C-RAS-WM 认证，并满足感知—运动安全包络。

**定义 311（多视角观测与几何残差）** `o_t = {(I_t^v, K^v, T_t^v)}_{v=1}^V`，`V ≤ 6`。给定假设 `h` 诱导的 3D 结构 `X_h` 与可见性掩码 `Ω_v`，定义重投影、光度、深度、极线残差 `r_rep, r_pho, r_dep, r_epi`；几何证伪分
` s_geo(h,o) = RobustAgg_v( r_rep + λ_pho r_pho + λ_epi r_epi ; Ω_v ) + κ·(1 − coverage) `
其中 `RobustAgg` 取可见对应上的中位数/Huber，`coverage` 为假设区域被至少两个视角共同看到的比例。`s_geo` 低 ⇔ 多视角几何自洽。**自洽是必要条件，不是充分条件**（见定义 317、引理 21）。

**定义 312（VLM 提案器 VLP）** 冻结 VLM `f_VLM: (视图集, 可选语言目标 l) ↦ H = {h_j}`，每个 `h_j = (label, referent, 3D 区域提议, 关系/可供性模板, 视图证据)`。`H` 是开放词汇集合；`f_VLM` 的原始分数记为 `c_j`，**只用于排序候选，绝不当成 `P(h_j 正确)`**。VLP 可对同一组视图做**视角盲化**的独立描述（不告诉它别处的结论），以降低自我一致性偏差。

**定义 313（可证伪谓词编译 PCG）** 编译器 `C` 把 `h_j` 映射为谓词集 `P(h_j)={p_1,…,p_m}`，每个 `p` 带容差与检验方式：支撑 support、包络 extent、可达 reachability、碰撞 collision-free、稳定 stability、自由空间 free-space、关系 relation。若 `C(h_j)=∅`，标记 **unverifiable**（Level 0）。谓词库带版本号并进入审计；**语言到谓词的编译本身也可能错**，故编译结果必须与几何残差联合判决，不得单独作为证据。

**定义 314（几何裁决）** 对每个 `h_j` 计算 `s_j=s_geo(h_j,o)` 与硬谓词违反。三值裁决：
- **accept**：`s_j ≤ τ_j` 且所有硬谓词通过；
- **reject**：任一硬谓词失败或 `s_j > τ_reject`；
- **undetermined**：其余。
`reject` 是对 `h_j` 的**反证**，不是概率；它把该假设从候选集移除，并作为「在当前几何模型下不可能」写入跨视角记忆。

**定义 315（共形证伪门 CFG）** 校准集 `𝒞={(h,o,correct)}`，非一致性分数 `s(h,o)=s_geo`。取 `τ_α` 为 `𝒞` 中正确样本的 `(1−α)` 分位数（split conformal）；对可交换的新样本，`P(correct | accepted) ≥ 1−α`（边际覆盖）。分布漂移时用自适应共形 ACI：`τ_{t+1}=τ_t+γ(α−err_t)`，保证长期平均错误率 `≤ α+O(γ)`。**我们校准的是「检验」，不是 VLM**——这是 R69 定义 306 MCG 的感知版，但对象从模态权重换成几何判决。

**定义 316（语义—动作联合熵；对 R69 的关键修正）** 设 `S` 为语义解释模态（物体身份/可供性/关系），`A` 为动作模态。联合 epistemic 熵
` U_epi^+ = H(S,A) = H(S) + E_{S}[H(A|S)] `。
R69 隐含令 `H(S)=0`（默认观测已被唯一解释），只计算 `H(A)`，因此 **`U_epi^+ ≥ H(A)`，R69 系统性低估 epistemic**。TRIAD 的直接攻击对象是最前面的 `H(S)`；`H(A|S)` 仍交给 R69 的 FMP/AUD。二者**分通道处理，不做标量相加**。退化约定：当 `V=1`、VLP 关闭或无可证伪谓词时，令 `H(S):=0`（`S` 坍缩为唯一感知解释），`U_epi^+ = H(A)`，逐指令回到 R69。

**定义 317（几何可约与语义别名）** 在几何裁决下把候选划分为接受集 `𝒜`、拒绝集 `ℛ`、不可判定集 `𝒰`。定义
`U_sem = H(S | o, 𝒜, ℛ)`（用共形接受频率而非 VLM 分数估计）；
`U_obs` = 三角化协方差/视差不足/遮挡造成的几何不确定（由 `s_geo` 的协方差与 `coverage` 刻画）。
若 `𝒜` 中存在 `h_i,h_j` 诱导的结构在容差内几何等价、但任务相关可供性不同，则称**语义别名**，其不确定性 `U_sem^irr` 在几何商空间下**不可约**（定理 19）。语义别名不是「更多视角能解决」的问题。

**定义 318（主动跨视角三角化 ACT / next-best-view）** 信息动作 `g_view ∈ SE(3)×zoom×{相机子集}`，与 R69 的注视/探针/问句并列。预测信息增益用几何解析式：
` IG(g_view) ≈ ½ log det(I + Σ_X^{1/2} J_g^T Σ_px^{-1} J_g Σ_X^{1/2}) + β·Δcoverage(g) − γ·Δocclusion(g) `。
选择 `g* = argmax [IG − c(motion,time,社交)]`，s.t. `shield.certify_view(g)` 且预算未超、且当前估计的视差确实足以降低深度方差。若 `IG ≤ 成本` 或所有候选视差都过小 → 不移动，交回 R69 的看/问/触。

**定义 319（视角—语言一致性与场景注入）** `r_vl` 为同一组视图在**视角盲化、顺序随机化、中立提示**下的跨视角语义一致度（把定义 312 的独立描述两两比对）。`r_vl` 高只说明 VLM「自洽」，**不说明为真**（连贯幻觉可以自洽），故 `r_vl` 只作为提案可靠性的弱信号，绝不作为 verifier。若 VLM 从场景文字中读出指令性内容，一律视为 `ℰ_inject`，不得进入动作或工具调用。

**定义 320（威胁模型 ℰ_TRIAD）** `ℰ_TRIAD = ℰ_FLUID × ℰ_view × ℰ_sem × ℰ_inject`。
- `ℰ_view`：对抗贴片、反射/透明物体、屏幕回放、可控多视角共谋（所有视角一致地呈现同一假象）、标定漂移；
- `ℰ_sem`：语义别名、可供性误接地、标签分布漂移、开放词汇过度外推；
- `ℰ_inject`：场景文字提示注入、图像越狱、被投毒的 caption/描述。
其中 `ℰ_view` 的「物理可实现假象」是本轮最本质的残余风险。

**定义 321（三级证据与诚实退避）**
- **Level 2**（几何验证 + 共形接受 + 无别名）：可消解 `U_sem`，`λ = λ_floor(U_ale + E[H(A|S)])`（resolution bonus）；
- **Level 1**（接受但边际小 / `r_vl` 不一致 / 仅单视角）：部分消解，`λ = λ_floor(U_ale + E[H(A|S)]) + δ_v`，`δ_v>0`；
- **Level 0**（不可证伪 / 被拒绝 / 别名 / VLP 不可用）：不消解，`λ = λ_floor(U_ale + U_epi^+)`（**不低于** R69 的保守度），再叠加 R69 的 slow_fault 分支。
对任意状态，**没有 Level 2 证据时 TRIAD 不弱于 R69 的保守性**；有 Level 2 证据时才有资格降低 λ。

**定义 322（别名鲁棒动作）** 对别名等价类 `𝒜_eq`，求
` a* = argmax_a min_{h∈𝒜_eq} U(a,h)，s.t. 对所有 h 安全 `。
若最坏情况效用 `≥ τ_robust`，执行 `a*`（不赌某一个解释，而是在所有解释下都安全）；否则 `a*` 不存在，必须走 R69 交互或保守停止。这把「必须选一个标签」换成「选一个对所有可能标签都稳健的动作」。

**定义 323（跨视角感知异常与对偶判据）** 定义 `Δv = |s_geo(o) − s_geo(o_cal)|`（标定前后几何自洽性之差），与 R69 定义 301 的行为似然差 `Δa` 构成对偶：
- `(Δa↑, Δv↓)`：行为异常、几何自洽 → 策略/执行问题，偏 R69 FMA；
- `(Δa↓, Δv↑)`：行为尚可、几何失配 → 感知/标定/欺骗问题，偏 TRIAD MVG；
- `(Δa↑, Δv↑)`：疑似系统性欺骗或严重标定失效 → 最保守。
这是 R69 定义 309 的感知侧镜像。

**定义 324（参与式审计 VQAuditor-P）** 审计：哪个视角是决定性的、VLM 原始分数是否泄漏进 λ（必须为零）、不可证伪假设是否被错误升格、语义别名是否被诚实标记、视角动作是否安全、共形覆盖是否守住。后续获得真值后，accept/reject 记录回流为校准样本，形成闭环。

**定义 325（证书 J_TRIAD）** `J_TRIAD = (J_FLUID, V, view_graph_hash, s_geo_p95, conformal_α, coverage_hat, predicate_lib_ver, aliasing_flag, view_action_log_hash, triad_ver)`。
`Valid ⇔ Valid(J_FLUID) ∧ coverage_hat ≥ 1−α−ε ∧ 无 VLM 分数泄漏 ∧ 视角动作已认证 ∧ 别名被诚实处置（或已交回 R69）`。

**定义 326（严格包含与单调安全）** 当 `V=1` / VLP 关闭 / 无 Level 2 证据时，`H(S):=0`、`accept=∅`，TRIAD 逐指令等于 R69（定义 316 退化约定、定义 321 Level 0）；再令 R69 的 `VoI≤成本` 则等于 R68。对任意状态，未获 Level 2 证据时 `λ_TRIAD ≥ λ_R69`；获 Level 2 证据时 `λ_TRIAD ≤ λ_R69`，但由共形覆盖与几何裁决背书。安全侧不做任何让步。

```python
# IP-264 MVG：多视角几何裁决（非学习，可证伪）
class MultiViewGeometry:
    def __init__(self, V, robust='huber'):
        self.V = V
    def falsification_score(self, h, obs):
        X = h.structure                              # 由语义假设诱导的 3D 结构
        residuals, coverage = [], []
        for v in range(obs.V):
            x_rep = project(X, obs.K[v], obs.T[v])
            mask  = visibility_mask(X, obs, v)       # 遮挡感知
            residuals.append(robust_residual(obs.x[v], x_rep, mask))
            coverage.append(mask.mean())
        return aggregate(residuals) + KAPPA * (1 - mean(coverage))

# IP-265 VLP：冻结 VLM 只做提案，分数不进 lambda
class VisionLanguageProposer:
    def __init__(self, vlm, predicate_compiler):
        self.vlm, self.pc = vlm, predicate_compiler
    def propose(self, views, goal=None):
        hyps = self.vlm.propose(views, goal)         # 开放词汇，可能幻觉
        for h in hyps:
            h.preds = self.pc.compile(h)             # 可证伪谓词集
        return hyps                                  # 仅候选，不做判决

# IP-266 PCG：把语言假设编译成可检验的几何/运动学谓词
class PredicateCompiler:
    def compile(self, h):
        return [support, extent, reachability,
                collision_free, stability, free_space][: relevant(h)]

# IP-267 CFG：共形证伪门（校准“检验”，不是校准 VLM）
class ConformalGate:
    def __init__(self, alpha, calib_scores):
        self.alpha, self.scores = alpha, calib_scores
    def threshold(self):
        return quantile(self.scores, 1 - self.alpha)  # split conformal
    def accept(self, h, obs, mvg):
        s = mvg.falsification_score(h, obs)
        return s <= self.threshold() and all(p(h, obs) for p in h.preds)

# IP-268 ACT：next-best-view（把 R69 的 VoI 扩到视角）
def choose_view(obs, modes, budget, shield):
    best = None
    for g in candidate_views(obs):                   # 有限候选视角/相机/变焦
        if not shield.certify_view(g, obs): continue
        ig = expected_parallax_gain(g, obs) + beta * delta_coverage(g, obs) \
             - gamma * delta_occlusion(g, obs)
        score = ig - budget.cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None  # 无利可图 → 交回 R69

# IP-269 SAD：语义别名检测 + 别名鲁棒动作
def act_under_aliasing(aliased, modes):
    a_robust = argmax_a min(h.utility(a) for h in aliased)   # 对所有解释都安全
    return a_robust if worst_case_utility(a_robust) >= TAU_ROBUST else None

# IP-275 主闭环：TRIAD 层插在 R69 的“不确定性处置”之前，动作层不变
def TRIAD_RAS_round(M, obs, view_budget):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(o)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4            # 继承 R69
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    # 1) VLM 只提案（仅在语义层有歧义时触发）
    hyps = M.vlp.propose(obs.views) if (U_epi > TAU_EPI or M.sem_ambiguous) else []
    # 2) 几何裁决 + 共形门控
    accepted, rejected, unverifiable = [], [], []
    for h in hyps:
        if not h.preds: unverifiable.append(h); continue
        (accepted if M.cfg.accept(h, obs, M.mvg) else rejected).append(h)
    # 3) 语义别名：几何不可分 → 不许“多视角强行定案”
    alias = M.sad.equivalence_classes(accepted)
    if alias and M.sad.task_relevant(alias):
        a_rob = M.sad.act_under_aliasing(alias, modes)
        if a_rob is not None:
            return M.dispatch(a_rob, lam=lam_floor(U_ale))   # 别名鲁棒动作
        resolved = False
    else:
        U_sem = conformance_entropy(accepted, rejected)      # 不用 VLM 分数
        # 4) 几何可约 → 主动换视角（慢环，动作不变）
        if U_sem > TAU_SEM and view_budget.allow():
            g = M.act.choose_view(obs, modes, view_budget, M.shield)
            if g is not None:
                return TRIAD_RAS_round(M, M.execute_view(g), view_budget.spend(g))
        resolved = (len(accepted) > 0) and (U_sem <= TAU_SEM)
    # 5) 退避：无 Level 2 证据就把完整联合熵当作 floor（≥ R69）
    U_epi_joint = U_sem + U_epi if not resolved else U_epi
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + U_epi_joint))
    # 6) 继承 R69 的 FMA / slow_fault / C-RAS-WM 认证与审计
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o, o_cal)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    if slow: lam = max(lam, 0.8)
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    mode = select_mode(modes, 0.0 if resolved else U_epi_joint, lam)
    M.saa.submit(accepted, rejected, unverifiable, alias, M.mvg.last_coverage)
    return k, lam, mode, (U_ale, U_epi_joint, resolved)
```

## 3. 推导

**引理 19（多视角三角化方差与视差）** 对深度 `Z` 处的一点，由 `V` 个标定视角观测，`Σ_X` 为其三角化协方差，`J_v = ∂π_v/∂X`。引入新视角 `g` 后
` Σ_X' = (Σ_X^{-1} + J_g^T Σ_px^{-1} J_g)^{-1} `，
其信息增益 `IG(g)=½ log det(I + Σ_X^{1/2} J_g^T Σ_px^{-1} J_g Σ_X^{1/2})`，随新视角的**视差/基线**与分辨率单调增；单目近似下深度方差 `≈ (Z²/(f·b))² σ_px²`，基线 `b` 翻倍使深度方差降至约 1/4。系：**若所有候选视角相对当前基线的视差都低于阈值（远物、纯前向运动、狭窄空间），换视角无法降低 `U_obs`**，此时应直接承认不可约，转向 R69 的交互或保守，而不是做无效移动。

**引理 20（提案—裁决分离下的一般幻觉可证伪性）** 设 VLM 幻觉出无物理指称的假设 `h`，诱导结构 `X_h`。若场景是分段光滑、非对抗的，且相机基线非退化，则不存在与真实多视角观测在容差内一致的 `X_h`：`s_geo(h)` 随视角数 `V` 与基线增大而趋于超过 `τ`。因此在 `ℰ_view` 之外，**一般 VLM 幻觉是几何可证伪的**。残余风险精确等于「物理可实现假象」——即确实存在某个 3D 结构（打印物、屏幕、反射面、透明体）在所有视角下与真实观测一致，此时几何验证为真，但语义为假。这刻画了本轮安全边界：**几何只能排除不可实现的谎言，不能排除可实现且被故意布置的谎言**。

**引理 21（共形门控的覆盖与条件风险）** 在可交换性下，split conformal 给出边际覆盖 `P(correct | accepted) ≥ 1−α`；但这是**边际**而非**条件**覆盖——对特定类别/场景/光照不保证。分布漂移时交换性失效，ACI 更新 `τ_{t+1}=τ_t+γ(α−err_t)` 只保证长期平均错误率 `≤ α+O(γ)`。故证书必须同时报告 `τ_α` 与实测 `coverage_hat`；当 `coverage_hat < 1−α−ε` 时禁止 Level 2（定义 321），退回 R69。这是对 R69 MCG 的严格化：**模态权重校准被替换为判决阈值校准，且其保证是分布无关但有交换性前提的**。

**定理 18（TRIAD 严格包含 R69 与 R68）** 令 `V=1` 或 VLP 关闭或 `C(h)=∅`（无可证伪谓词），则 `accept=∅`、`H(S):=0`，定义 321 落入 Level 0，`U_epi^+=H(A)`，TRIAD 与 R69 逐指令相同；再令 R69 的 `VoI≤成本`，则与 R68 相同。对任意状态，未获 Level 2 证据时 `λ_TRIAD ≥ λ_R69`，获 Level 2 证据时 `λ_TRIAD ≤ λ_R69` 但由几何裁决与共形覆盖背书。故 TRIAD 是 R69 在「语义层不可表示」边界上的严格退化，并在可获得可证伪证据时提供 resolution bonus。

**定理 19（语义别名的几何不可判定性）** 设 `h_i,h_j` 诱导的 3D 结构与运动学谓词在容差内逐项相等，而任务可供性不同。任何只依赖 `s_geo` 与 `P(h)` 的检验在二者上的输出完全相同，因此 `S` 在其上的后验无法被多视角视觉区分：`U_sem^irr` 对增加视角数 `V` 与分辨率**不变**。故唯一可靠的选择是：(a) 定义 322 的别名鲁棒动作；(b) 交回 R69 的交互（问/触）；(c) R68 的保守停止。**推论：TRIAD 不能替代 R69，因为存在视觉原理上无法裁决、只能靠交互或保守处理的歧义类**——这正是新层必须包含旧层而非取代旧层的根本原因，也直接反驳「更多视角 = 更多真相」的傲慢。

**定理 20（视角动作安全与无突变）** 视角动作 `g_view` 经 C-RAS-WM 前缀认证与感知—运动安全包络（定义 310-iv、318）后，其物理风险 `≤ ε_view`；换视角只改变观测，不改变已提交动作的安全包络；换视角失败/超时/被 `ℰ_view` 欺骗时，`λ` 单调不降地落回 Level 0 的 R69 保守分支；提交/换装不变式（R69 定理 17）保持，故控制连续、无突变。

## 6. 本轮最大风险

**一句话**：TRIAD 的安全性完全押在「几何裁判的模型假设成立」上——一旦场景违反标定/静态/非对抗/朗伯假设（透明、镜面、运动物体、标定漂移，或攻击者布置一个**在所有视角下都物理可实现**的假象），几何就可能把 VLM 的幻觉「验证为真」，而共形覆盖只是**边际**保证、在分布漂移下会失效；**用几何给幻觉盖章，比单纯相信 VLM 更危险，因为它披着「物理自证」的外衣**。

**次级风险与缓解**：
1. **语义别名不可判定** → 定义 322 别名鲁棒动作 + 定理 19 诚实退避 + 交回 R69 交互；
2. **物理可实现假象/跨视角共谋** → `ℰ_view` 对抗训练 + `Δv` 对偶告警 + 多模态（偏振/结构光/触觉）交叉验证 + 证书披露；
3. **标定漂移使几何失准** → 在线标定监测 + 定义 323 `Δv` 门控 + 标定不可信时禁止 Level 2；
4. **共形覆盖在 OOD 失效** → ACI + `coverage_hat` 门控 + 分场景/分类别条件覆盖报告；
5. **VLM 场景注入/越权** → VLM 只提案、不执行；谓词编译白名单；`ℰ_inject` 红队；
6. **实时预算被 VLM 击穿** → VLP/PCG 严格慢环异步、反射环零等待、无 Level 2 证据即抬高 λ。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** TRIAD-RAS 在 R69 三不变式上新增：提案—裁决分离（VLM 分数不进 λ）；证伪优先（不可证伪假设不得消解 U_epi）；诚实不可判定（语义别名不得由更多视角强行区分）；视角动作安全（换视角过 C-RAS-WM 认证）。

**定义 311（多视角几何残差）** `s_geo = RobustAgg_v(r_rep + λ_pho r_pho + λ_epi r_epi; Ω_v) + κ(1−coverage)`；低 `s_geo` 表示多视角自洽，但**自洽只是必要条件**。

**定义 312–313（VLP 与 PCG）** 冻结 VLM `(视图集, l) ↦ H={h_j}`，原始分数只排序、绝不当 `P(correct)`；编译器 `C: h ↦ P(h)`（支撑/包络/可达/碰撞/稳定/自由空间），`P(h)=∅` 记 unverifiable（Level 0）。**编译本身可能错，须与几何残差联合判决**。

**定义 314（几何裁决）** 三值：accept（`s_j≤τ_j` 且硬谓词全过）、reject（硬谓词失败或 `s_j>τ_reject`）、undetermined。`reject` 是反证而非概率。

**定义 315（共形证伪门 CFG）** split conformal 取正确样本 `(1−α)` 分位数 `τ_α`，可交换下 `P(correct|accepted)≥1−α`；漂移用 ACI `τ_{t+1}=τ_t+γ(α−err_t)`，长期错误 `≤α+O(γ)`。**校准的是检验，不是 VLM**。

**定义 316（联合熵修正）** `U_epi^+ = H(S,A) = H(S)+E[H(A|S)] ≥ H(A)`；R69 令 `H(S)=0`，故系统性低估。TRIAD 攻击 `H(S)`，R69 继续负责 `H(A|S)`；二者分通道，不做标量相加。退化约定：`V=1`/VLP 关闭/无谓词时 `H(S):=0`，回到 R69。

**定义 317（可约性与别名）** `U_sem = H(S|o,𝒜,ℛ)`（用共形接受频率估）；`U_obs` 为三角化协方差/遮挡不确定。若 `𝒜` 中两假设几何等价但任务可供性不同，则为**语义别名**，`U_sem^irr` 在几何商空间下不可约（定理 19）。

**定义 318（ACT / next-best-view）** `IG(g) ≈ ½logdet(I+Σ_X^{1/2}J_g^TΣ_px^{-1}J_gΣ_X^{1/2}) + βΔcoverage − γΔocclusion`；`g*=argmax(IG−c)`，须过视角安全认证；`IG≤成本` 或视差不足则不移动。

**定义 319–320（r_vl 与威胁）** `r_vl` 为视角盲化/顺序随机化的跨视角一致度，只作弱信号；场景文字指令一律视为 `ℰ_inject`。`ℰ_TRIAD` 增 `ℰ_view`（可实现假象/回放/共谋/标定漂移）、`ℰ_sem`（别名/误接地/漂移）、`ℰ_inject`。

**定义 321–322（三级退避与别名鲁棒动作）** Level 2：`λ=λ_floor(U_ale+E[H(A|S)])`；Level 1：`+δ_v`；Level 0：`λ=λ_floor(U_ale+U_epi^+)`（≥R69），再叠 slow_fault。别名：`a*=argmax_a min_{h∈𝒜_eq}U(a,h)`，最坏效用不足则交回 R69/保守。

**定义 323–326（对偶/审计/证书/包含）** `Δv` 与 R69 `Δa` 构成感知—行为对偶，用于区分执行异常与感知欺骗。SAA 审计 VLM 分数泄漏、不可证伪升格、别名诚实性、视角安全、覆盖。`J_TRIAD` 并入视角图/`s_geo_p95`/α/覆盖/谓词库版本/别名标志。`V=1` 或 VLP 关闭或 Level 0 时逐指令等于 R69；安全单调。

## 3. 关键算法伪代码

```python
# IP-264 MVG：多视角几何裁决（非学习，可证伪）
class MultiViewGeometry:
    def falsification_score(self, h, obs):
        X = h.structure                              # 假设诱导的 3D 结构
        res, cov = [], []
        for v in range(obs.V):
            x_rep = project(X, obs.K[v], obs.T[v])
            m     = visibility_mask(X, obs, v)       # 遮挡感知
            res.append(robust_residual(obs.x[v], x_rep, m))
            cov.append(m.mean())
        return aggregate(res) + KAPPA * (1 - mean(cov))

# IP-265 VLP：冻结 VLM 只提案，分数不进 lambda
class VisionLanguageProposer:
    def __init__(self, vlm, compiler): self.vlm, self.pc = vlm, compiler
    def propose(self, views, goal=None):
        hyps = self.vlm.propose(views, goal)         # 开放词汇，可能幻觉
        for h in hyps: h.preds = self.pc.compile(h)  # 可证伪谓词集
        return hyps                                  # 仅候选，不做判决

# IP-266 PCG：语言 → 可检验谓词
def compile_predicates(h):
    return [support, extent, reachability,
            collision_free, stability, free_space][: relevant(h)]

# IP-267 CFG：共形证伪门（校准“检验”，不是校准 VLM）
class ConformalGate:
    def __init__(self, alpha, calib): self.alpha, self.scores = alpha, calib
    def threshold(self): return quantile(self.scores, 1 - self.alpha)
    def accept(self, h, obs, mvg):
        s = mvg.falsification_score(h, obs)
        return s <= self.threshold() and all(p(h, obs) for p in h.preds)

# IP-268 ACT：next-best-view（R69 VoI 的视角扩展）
def choose_view(obs, modes, budget, shield):
    best = None
    for g in candidate_views(obs):
        if not shield.certify_view(g, obs): continue
        ig = expected_parallax_gain(g, obs) + beta*delta_coverage(g, obs) \
             - gamma*delta_occlusion(g, obs)
        score = ig - budget.cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None   # 无利可图 → R69

# IP-269 SAD：语义别名 → 别名鲁棒动作
def act_under_aliasing(aliased, modes):
    a = argmax_a min(h.utility(a) for h in aliased)    # 对所有解释都安全
    return a if worst_case_utility(a) >= TAU_ROBUST else None

# IP-275 主闭环：TRIAD 插在 R69 的“不确定性处置”之前
def TRIAD_RAS_round(M, obs, view_budget):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(o)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    hyps = M.vlp.propose(obs.views) if (U_epi > TAU_EPI or M.sem_ambiguous) else []
    acc, rej, unv = [], [], []
    for h in hyps:
        if not h.preds: unv.append(h); continue
        (acc if M.cfg.accept(h, obs, M.mvg) else rej).append(h)
    alias = M.sad.equivalence_classes(acc)
    if alias and M.sad.task_relevant(alias):
        a_rob = M.sad.act_under_aliasing(alias, modes)
        if a_rob is not None:
            return M.dispatch(a_rob, lam=lam_floor(U_ale))
        resolved = False
    else:
        U_sem = conformance_entropy(acc, rej)          # 不用 VLM 分数
        if U_sem > TAU_SEM and view_budget.allow():
            g = M.act.choose_view(obs, modes, view_budget, M.shield)
            if g is not None:
                return TRIAD_RAS_round(M, M.execute_view(g), view_budget.spend(g))
        resolved = len(acc) > 0 and U_sem <= TAU_SEM
    U_joint = U_sem + U_epi if not resolved else U_epi
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + U_joint))
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o, o_cal)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    if slow: lam = max(lam, 0.8)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, H=M.vista.H), ..., wm_preds)
    mode = select_mode(modes, 0.0 if resolved else U_joint, lam)
    M.saa.submit(acc, rej, unv, alias, M.mvg.last_coverage)
    return k, lam, mode, (U_ale, U_joint, resolved)
```

## 4. 推导

**引理 19（三角化方差与视差）** `Σ_X' = (Σ_X^{-1}+J_g^TΣ_px^{-1}J_g)^{-1}`，信息增益 `½logdet(I+Σ_X^{1/2}J_g^TΣ_px^{-1}J_gΣ_X^{1/2})` 随新视角视差/基线/分辨率单调增；单目近似深度方差 `≈(Z²/(fb))²σ_px²`，基线翻倍降至约 1/4。系：低视差场景（远物、纯前向、狭窄空间）换视角无法降低 `U_obs`，应诚实退避而非无效移动。

**引理 20（一般幻觉的几何可证伪性）** 非对抗分段光滑场景下，无物理指称的假说 `h` 不存在与真实多视角观测在容差内一致的 `X_h`，故 `s_geo(h)>τ` 随 `V` 与基线增大而趋于成立。残余风险精确等于 `ℰ_view` 的「物理可实现假象」（打印物/屏幕/反射/透明体）——几何只能排除**不可实现**的谎言。

**引理 21（共形覆盖与条件风险）** split conformal 在可交换下给出边际覆盖 `P(correct|accepted)≥1−α`，非条件覆盖；漂移下 ACI 只保证长期平均错误 `≤α+O(γ)`。故证书须同时报告 `τ_α` 与 `coverage_hat`；后者低于 `1−α−ε` 时禁止 Level 2（MCG-P），退回 R69。

**定理 18（严格包含 R69 与 R68）** `V=1`/VLP 关闭/`P(h)=∅` ⇒ `acc=∅`、`H(S):=0`、Level 0 ⇒ `U_epi^+=H(A)`，与 R69 逐指令相同；再令 `VoI≤成本` 则与 R68 相同。未获 Level 2 时 `λ_TRIAD≥λ_R69`；获 Level 2 时 `λ_TRIAD≤λ_R69` 但由几何裁决与共形覆盖背书。安全不让步，效率获 resolution bonus。

**定理 19（语义别名的几何不可判定性）** 若 `h_i,h_j` 的 3D 结构与运动学谓词在容差内逐项相等而任务可供性不同，则任何只依赖 `s_geo` 与 `P(h)` 的检验在二者上输出相同，`U_sem^irr` 对增加 `V`/分辨率不变。唯一可靠选择：别名鲁棒动作（定义 322）、R69 交互、或 R68 保守停止。**推论：存在视觉原理上不可裁决的歧义类，故 TRIAD 必须包含而非取代 R69。**

**定理 20（视角动作安全与无突变）** `g_view` 过 C-RAS-WM 与感知—运动安全包络后风险 `≤ε_view`；换视角只改观测、不改已提交动作的安全包络；失败/超时/被 `ℰ_view` 欺骗时 `λ` 单调不降回 Level 0 的 R69 分支；提交/换装不变式（R69 定理 17）保持，控制连续无突变。

## 7. 本轮最大风险

**一句话**：TRIAD 的安全性完全押在「几何裁判的模型假设成立」上——一旦场景违反标定/静态/非对抗/朗伯假设（透明、镜面、运动物体、标定漂移，或攻击者布置一个**在所有视角下都物理可实现**的假象），几何就可能把 VLM 的幻觉「验证为真」，而共形覆盖只是**边际**保证、在分布漂移下会失效；**用几何给幻觉盖章，比单纯相信 VLM 更危险，因为它披着「物理自证」的外衣**。

**次级风险与缓解**：语义别名不可判定（定义 322 鲁棒动作 + 定理 19 诚实退避 + 交回 R69）；物理可实现假象/跨视角共谋（`ℰ_view` 对抗训练 + `Δv` 对偶告警 + 偏振/结构光/触觉交叉验证 + 证书披露）；标定漂移（在线标定监测 + `Δv` 门控 + 不可信时禁 Level 2）；共形 OOD 失效（ACI + `coverage_hat` 门控 + 条件覆盖报告）；VLM 注入/越权（只提案不执行 + 谓词白名单 + 红队）；实时预算（VLP/PCG 慢环异步、反射环零等待、无证据即抬 λ）。
