# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；新灵感循环第 1 轮；本轮灵感：「竞赛策略」×「位姿估计」）· ContestPose：可达成 soundness × 位姿预算 × 赛局风险分配

> 第 54 轮把技能组合推进到动作剖面 `α_S`、组合图 `G_S` 与云边联合证书 `J=(ρ,A_cert,γ_ce,δ_a)`。但这些证书仍隐含两个"实验室假设"：**(i) 位姿是已收敛、单峰、与时间无关的输入**；**(ii) 风险是固定阈值 `ρ_min/δ_a`，不随比赛时钟、比分与排名变化**。本轮用两个灵感词正面击穿：**H22（位姿假设）**——真实竞赛中的位姿估计是多峰、任务相关、且在时间预算内未必收敛的过程，用均值/协方差代表对称或遮挡物体的位姿信念，会把"两个都可能"错误压缩成"一个大概"，证书据此签发时形式 sound、实际不可达；**H23（策略-证书失配）**——竞赛策略在任务价值、时间衰减、尝试次数与排名风险态度之间做分配，而证书的 soundness 域是固定的，二者分开计算会让策略系统性选择"证书看起来有效、位姿却在预算内根本达不到"的高价值任务。核心命题：**soundness 不仅要真，还必须"在比赛时钟内可达"（reachable soundness）**；位姿是可以用动作购买的信息资源，策略则是位姿预算与风险预算的联合分配器。

## 0. 直觉与动机

**灵感 1（位姿信念是多峰的，不能坍缩为均值）**
直觉：对称杯子、被遮挡的零件、反光金属件会让位姿估计器输出多个等价/近等价假设。把混合信念平均，会落在"两个杯柄之间"这个物理上不存在的姿态。正确做法是保留混合信念 `b(x)=Σ_h w_h N_h`，并且只在**技能真正敏感的方向**上要求精度——沿旋转对称轴的误差可能完全无害，沿插入方向的毫米级误差却致命。
→ 用对称群 `G_sym` 做任务相关位姿商 `x̄ = x mod G_sym`，把 SE(3) 误差投影到技能任务坐标系，再谈精度。

**灵感 2（位姿误差的"严重性"由下游技能定义）**
直觉：同一个 2cm 位姿误差，对"抓大把手"无所谓，对"插销入孔"是灾难。位姿估计不应独立追求 ATE/RPE，而应与技能容差耦合；位姿模块的验收指标应由下游成功率反推。
→ 定义位姿敏感剖面 `σ_S(e,a)` 与容忍域 `T_S(δ)`，并把位姿信念推过技能坐标系，得到 **信念条件动作剖面** `α_S^b(a)=E_{x~b}[α_S(a|x)]`，直接接入第 54 轮 ACS/SCOM 的 `compat_b`。

**灵感 3（位姿可以被"动作"买来：action-as-sensor）**
直觉：与其等视觉收敛，不如推一下、拨一下、试抓一下，用接触与运动把对称/遮挡假设打掉。动作既是执行也是观测；探针动作本身可能失败，但失败也是信息。
→ 定义探针动作 `a_probe` 的位姿信息价值 `VoI(o|s)=E_{z}[V(s⊕z)]-V(s)-λ·τ(o)`；竞赛策略在"看 / 动 / 等 / 退"之间做四选一。

**灵感 4（竞赛策略 = 位姿预算与风险预算的联合分配）**
直觉：比赛里时间不均匀——早期探索贵、后期保守；落后时该冒险冲高价值任务，领先时该锁定低风险分；尝试次数有限，失败还消耗机会成本。固定的 `ρ_min` 无法表达"此刻我愿意承受 10% 失败率换 +30 分"。
→ 策略 `π_strat` 输出 `(task, δ_task, τ_pose, fallback)`，在 score-rate 目标下做风险敏感、时间衰减的预算分配；排名只改变风险态度 `δ_max(rank)`，不改变证书语义。

**灵感 5（证书必须"可达成"：把位姿采集计划写进证书）**
直觉：证书不应只说"若位姿误差 ≤ ε 则成功"，而应说"用 `τ_pose` 的观测/探针预算，能以 ≥`1-δ_task` 的概率把位姿带进 `T_S`，且在此前提下技能链成功"。这正是可执行证书与"数学上正确但比赛里做不到"的证书的分水岭。
→ 策略条件证书 `SC=(J,P_S,δ_task,τ_pose,fallback)`，有效性要求 `reach(SC)=true`；否则自动降级到 fallback，而不是带着空头证书上场。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（位姿信念与任务相关商）**
位姿信念 `b_t(x)=Σ_{h∈H_t} w_h N(x;μ_h,Σ_h)`，`x∈SE(3)`，`Σ_h w_h=1`；对称群 `G_sym⊆SE(3)`，任务相关位姿 `x̄ = x mod G_sym`。**认证前禁止用单峰代理替换 `b`**：允许在 `G_sym` 商空间上合并等价模态，但不允许跨不等价模态取均值。

**定义 122（位姿敏感剖面与容忍域）**
技能 `S` 的位姿敏感剖面 `σ_S: SE(3) × A → [0,1]`，`σ_S(e,a)=P(success | pose error e, action a)`。容忍域
```
T_S(δ,a) = { e ∈ SE(3) : σ_S(e,a) ≥ 1-δ }
```
在任务坐标系下用敏感矩阵 `s_S = D_task^T e` 投影，使"对称方向无害、插入方向致命"进入定义。

**定义 123（位姿可采纳证书 P-cert）**
`P_S = (b, T_S(δ_p), δ_p)`。可采纳当且仅当
```
mass_b(T_S) = ∫_{x-x̂ ∈ T_S} b(x) dx ≥ 1-δ_p
```
对多峰信念按模态分别积分并报告 **最坏模态覆盖** `worst = min_h mass_{N_h}(T_S)`；只报加权总覆盖会让小权重但高风险的模态被平均掉。

**定义 124（信念条件动作剖面）**
`α_S^b(a) = ∫ α_S(a|x) b(x) dx`，`cover_b(S,A_T)=1 ⇔ ∀a∈A_T, α_S^b(a) ≥ θ_cov`。这把第 54 轮确定位姿的 `α_S` 推广为信念位姿版本，技能兼容性升级为 `compat_b(S_i,S_j)`。

**定义 125（竞赛策略与风险预算）**
竞赛状态 `s=(t_rem, score, rank, b, Q, o)`，其中 `Q` 为任务队列、`o` 为对其他队伍占用/时间的观测（可选）。策略
```
π_strat : s → (task, δ_task, τ_pose, fallback)
```
竞赛得分 `Score = Σ_i v_i·m_i(τ_i) - λ·τ_total + bonus(rank, τ_finish)`，`m_i∈[0,1]` 为完成质量（允许部分分）。优化目标
```
max_π E[Score]  s.t.  Σ_i τ_pose,i ≤ B_obs,  δ_task,i ≤ δ_max(rank)
```
`δ_max(rank)` 随排名变化：落后放大、领先收缩；这只是改变可接受风险，不改变证书的真值条件。

**定义 126（动作信息价值 VoI）**
对观测或动作 `o`：
```
VoI(o|s) = E_{z~P(·|s,o)}[ V_π(s⊕z) ] - V_π(s) - λ·τ(o)
```
其中 `s⊕z` 为贝叶斯信念更新，`V_π` 为策略价值。动作型观测 `a_probe`（推、拨、试抓）与被动观测 `o_reobserve`（换视角、等待收敛）同属候选集。

**定义 127（策略条件证书与可达成谓词）**
`SC = (J, P_S, δ_task, τ_pose, fallback, evidence)`，其中 `J` 为第 54 轮联合证书。定义可达成谓词：
```
reach(SC) ⇔ ∃ observation plan o_{1:k},
             Σ_i τ(o_i) ≤ τ_pose  ∧
             P( mass_{b'}(T_S) ≥ 1-δ_p | o_{1:k} ) ≥ 1-δ_task
```
仅当 `reach(SC)=true ∧ J 有效 ∧ δ_task ≤ δ_max(rank)` 时放行；否则执行 `fallback` 并在证据中记录"证书不可达"的根因，而不是静默签发。

**定义 128（赛局遗憾与可达 soundness）**
`Regret(π)=E[Score(π*)]-E[Score(π)]`，`π*` 为已知真实位姿与真实评分模型的 oracle 策略。称证书 **可达 sound**：若
```
P(success | reach(SC)) ≥ 1 - δ_p - δ_task - β_E
```
即"可达"是 soundness 的显式前提，而不是隐含假设。

## 2. 关键算法 伪代码

### IP-121 PSP（Pose Sensitivity Profiling）

```python
def pose_sensitivity(skill, error_grid, actions, sim, delta):
    grid = {}
    for e in error_grid:                    # 含对称轴/插入轴定向采样
        for a in actions:
            grid[(e, a)] = sim.success_rate(skill, e, a, n=N)
    T = {e for e in error_grid
         if min(grid[(e, a)] for a in actions) >= 1 - delta}
    S_mat = estimate_task_sensitivity(grid) # 投影到任务坐标系
    return SensitivityProfile(grid, T, S_mat)
```

### IP-122 PBC（Pose Belief Certificate）

```python
def pose_certificate(b, T_S, delta_p):
    mode_mass = {h: b.mass_within(h, T_S) for h in b.modes}
    worst = min(mode_mass.values())
    if worst < 1 - delta_p:
        return ('reject', 'ambiguous_mode', argmin(mode_mass))
    return ('ok', PCert(b, T_S, delta_p, worst))
```

### IP-123 SBA（Strategy Budget Allocator）

```python
def allocate(state, tasks, score_model, risk_max):
    order = sorted(tasks, key=lambda t: marginal_score(t, state) / expected_time(t))
    plan, tau_left, delta_left = [], state.t_rem, risk_max(state.rank)
    for t in order:
        need = pose_budget_estimate(t, state.b)       # 由 VoI 前向展开给出
        d_t = delta_task_for(t, state, score_model)   # 风险敏感、时间衰减
        if need <= tau_left and d_t <= delta_left and score_model.viable(t, state):
            plan.append((t, d_t, need))
            tau_left -= need
            delta_left -= d_t
    return plan
```

### IP-124 AVI（Action-Value of Pose Information）

```python
def best_pose_action(state, skill, depth=2):
    cands = ['act', 'reobserve', 'probe', 'fallback']
    def score(o):
        if o == 'fallback':
            return fallback_value(state) - risk_penalty(o, state)
        return VoI(o, state, depth) - risk_penalty(o, state)
    return argmax(cands, key=score)
```

### IP-125 SCC（Strategy-Conditioned Certificate）

```python
def strategy_certificate(skill_seq, state, budget, gamma_ce):
    J = joint_certificate(skill_seq, gamma_ce, budget.delta_a, budget.rho_min)
    P = pose_certificate(state.b, sensitivity(skill_seq), budget.delta_p)
    if P[0] != 'ok' or J[0] != 'ok':
        action = best_pose_action(state, skill_seq)
        if action == 'fallback':
            return ('degrade', fallback_policy(state))
    plan = plan_observation(state, skill_seq, action)   # 观测/探针序列
    if not check_reach(plan, P[1], budget.tau_pose, budget.delta_task):
        return ('degrade', fallback_policy(state))
    return ('ok', StrategyCert(J[1], P[1], budget, fallback_policy(state), plan))
```

### IP-126 CSR（Contest Score Regret）

```python
def contest_regret_bound(plan, score_model, pose_calib_error):
    # 见第 3 节定理；在线用证书覆盖率与预算余量给出可计算上界
    cover = cert_coverage(plan)
    slack = budget_slack(plan)
    return score_model.v_scale * (cover + pose_calib_error) + strategy_gap(plan) - slack_gain(slack)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| PSP | O(\|E\|·\|A\|·N) | O(\|E\|·\|A\|) | 误差网格覆盖对称轴与插入轴 |
| PBC | O(\|H\|·\|T\|) | O(\|T\|) | 模态保持、最坏模态覆盖 |
| SBA | O(\|T\|²·k) | O(\|T\|·k) | 预算外不可选、风险可加 |
| AVI | O(\|O\|·b^k) | O(b^k) | 前向深度有界、信念更新一致 |
| SCC | O(\|S\|·\|A\|+\|H\|·\|T\|) | O(\|S\|+\|T\|) | reach 判定 sound、fallback 全定义 |

**定理 1（Reachable Soundness）**
假设第 54 轮 (A22)–(A28) 成立；新增 **(A29)** 位姿信念 `b` 按模态校准，即真实位姿落入 `T_S` 的频率不低于 `mass_b(T_S)`；**(A30)** `σ_S` 由结构化仿真校准且在任务坐标系上 Lipschitz；**(A31)** 观测计划 `o_{1:k}` 的条件覆盖可由校准器验证；**(A32)** fallback 策略有定义且不劣于放弃该任务。
则对任一任务：
```
P(success | reach(SC)) ≥ 1 - δ_p - δ_task - β_E - P(δ_a > Θ_a)
```

**定理 2（赛局得分下界）**
在定理 1 与评分模型误差 `|Score_model - Score_true| ≤ ε_score` 下：
```
E[Score] ≥ Σ_i v_i·(1 - δ_{p,i} - δ_{task,i} - β_E) - λ·E[τ_total] - R_strategy - R_score
```
其中 `R_strategy` 为预算分配相对 oracle 的次优间隙，`R_score` 由 `ε_score` 与风险态度放大。**关键结论**：证书覆盖率若不能转化为"预算内可达"，下界中的 `δ_{task,i}` 会被人为压低却与真实失败率脱节——这正是空头证书的数学表现。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 位姿信念过自信 / 模态坍缩 | 高 | 模态保持认证 + conformal 校准门 + 反例模态注入 |
| 评分模型错配、规则隐藏 | 高 | 评分歧义集上做鲁棒分配 + 在线估计 + 保守 fallback |
| VoI 短视导致"看而不动" | 中 | 深度 k 前瞻 + rollout 基线 + 观测预算硬上限 |
| 探针动作引入额外碰撞/失败 | 高 | 探针安全包络 + 仅允许可逆探针 + 失败即停 |
| 策略-证书振荡、证书过于复杂不可审计 | 中 | hysteresis + 分层证书摘要 + 关键前提单调化 |

## 6. 本轮最大风险

**一句话**：把 soundness 从"静态为真"推进到"比赛时钟内可达"，并用竞赛策略分配位姿与风险预算，确实填补了第 54 轮"证书正确但不可执行"的空洞；但整套论证 **双重依赖位姿信念的按模态校准与评分模型的正确性**——一旦信念过自信或模态坍缩，策略会把有限的观测预算投给"证书可达而实际不可观测"的任务，若评分规则还被误设，系统会以极高的证书通过率系统性地输掉比赛，故必须以 **模态保持的校准门 + 评分歧义集上的鲁棒分配 + 探针安全包络** 三重护栏，宁可降级到低分 fallback，也绝不把"可达性假象"当成可部署前提。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-ContestPose（PSP×PBC×SBA×AVI×SCC×CSR）

> 承接第 54 轮产物 v31。本轮在动作-鲁棒性双证书体系之上，增加 **位姿信念认证、竞赛策略预算分配、位姿信息价值、可达成证书** 五个新算子：
> - **PSP（Pose Sensitivity Profile）**：把位姿误差的严重性交给下游技能定义；
> - **PBC（Pose Belief Certificate）**：多峰 SE(3) 信念的按模态可采纳证书；
> - **SBA（Strategy Budget Allocator）**：竞赛策略下的位姿预算与风险预算联合分配；
> - **AVI（Action-Value of Pose Information）**：把"推一下/换个视角/试抓"统一为信息获取动作；
> - **SCC（Strategy-Conditioned Certificate）**：带 `reach` 谓词的策略条件证书；
> - **CSR（Contest Score Regret）**：把证书覆盖率与赛局得分下界显式连接。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/116/119/120 以纳入位姿信念与竞赛预算维度。核心口号：**证书不仅要 sound，还要在比赛时钟内 reachable。**

## 1. 符号体系增量（新增定义 121–128）

| 符号 | 含义 |
|---|---|
| `b_t(x)=Σ_h w_h N(μ_h,Σ_h)` | 多峰 SE(3) 位姿信念 |
| `G_sym` / `x mod G_sym` | 物体对称群 / 任务相关位姿商 |
| `σ_S(e,a)` | 技能位姿敏感剖面（成功率 vs 位姿误差） |
| `T_S(δ)` | 位姿容忍域 `{e: σ_S(e,a) ≥ 1-δ}` |
| `mass_b(T_S)` / `worst` | 信念在容忍域上的质量 / 最坏模态覆盖 |
| `α_S^b(a)` | 信念条件动作剖面 `E_{x~b}[α_S(a|x)]` |
| `compat_b(S_i,S_j)` | 信念条件下的技能动作兼容性 |
| `δ_task` | 策略分配的单任务风险预算 |
| `τ_pose` / `B_obs` | 位姿获取时间预算 / 总观测预算 |
| `VoI(o\|s)` | 动作/观测的位姿信息价值 |
| `reach(SC)` | 策略条件证书的可达成谓词 |
| `δ_max(rank)` | 排名相关的可接受风险上界 |
| `Regret(π)` / `R_strategy` / `R_score` | 赛局遗憾 / 分配间隙 / 评分错配项 |

### IP-121 PSP

```python
def pose_sensitivity(skill, error_grid, actions, sim, delta):
    grid = {}
    for e in error_grid:
        for a in actions:
            grid[(e, a)] = sim.success_rate(skill, e, a, n=N)
    T = {e for e in error_grid
         if min(grid[(e, a)] for a in actions) >= 1 - delta}
    S_mat = estimate_task_sensitivity(grid)
    return SensitivityProfile(grid, T, S_mat)
```

### IP-122 PBC

```python
def pose_certificate(b, T_S, delta_p):
    mode_mass = {h: b.mass_within(h, T_S) for h in b.modes}
    worst = min(mode_mass.values())
    if worst < 1 - delta_p:
        return ('reject', 'ambiguous_mode', argmin(mode_mass))
    return ('ok', PCert(b, T_S, delta_p, worst))
```

### IP-123 SBA

```python
def allocate(state, tasks, score_model, risk_max):
    order = sorted(tasks, key=lambda t: marginal_score(t, state) / expected_time(t))
    plan, tau_left, delta_left = [], state.t_rem, risk_max(state.rank)
    for t in order:
        need = pose_budget_estimate(t, state.b)
        d_t = delta_task_for(t, state, score_model)
        if need <= tau_left and d_t <= delta_left and score_model.viable(t, state):
            plan.append((t, d_t, need))
            tau_left -= need
            delta_left -= d_t
    return plan
```

### IP-124 AVI

```python
def best_pose_action(state, skill, depth=2):
    cands = ['act', 'reobserve', 'probe', 'fallback']
    def score(o):
        if o == 'fallback':
            return fallback_value(state) - risk_penalty(o, state)
        return VoI(o, state, depth) - risk_penalty(o, state)
    return argmax(cands, key=score)

def VoI(o, state, depth):
    if depth == 0:
        return 0.0
    exp_val, cost = 0.0, observation_cost(o)
    for z, p in belief_update(state.b, o).outcomes():
        exp_val += p * value(state.with_belief(z), depth - 1)
    return exp_val - value(state, depth - 1) - lam * cost
```

### IP-125 SCC

```python
def strategy_certificate(skill_seq, state, budget, gamma_ce):
    J = joint_certificate(skill_seq, gamma_ce, budget.delta_a, budget.rho_min)
    P = pose_certificate(state.b, sensitivity(skill_seq), budget.delta_p)
    if P[0] != 'ok' or J[0] != 'ok':
        action = best_pose_action(state, skill_seq)
        if action == 'fallback':
            return ('degrade', fallback_policy(state))
    plan = plan_observation(state, skill_seq, action)
    if not check_reach(plan, P[1], budget.tau_pose, budget.delta_task):
        return ('degrade', fallback_policy(state))
    return ('ok', StrategyCert(J[1], P[1], budget, fallback_policy(state), plan))

def check_reach(plan, Pcert, tau_pose, delta_task):
    used = sum(observation_cost(o) for o in plan)
    if used > tau_pose:
        return False
    return Pcert.predicted_coverage_after(plan) >= 1 - delta_task
```

### IP-126 CSR

```python
def contest_regret_bound(plan, score_model, pose_calib_error):
    cover = cert_coverage(plan)
    slack = budget_slack(plan)
    return (score_model.v_scale * (cover + pose_calib_error)
            + strategy_gap(plan) - slack_gain(slack))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PSP | O(\|E\|·\|A\|·N) | O(\|E\|·\|A\|) | 误差网格覆盖对称轴与插入轴 |
| PBC | O(\|H\|·\|T\|) | O(\|T\|) | 模态保持、最坏模态覆盖 sound |
| SBA | O(\|T\|²·k) | O(\|T\|·k) | 预算外不可选、风险预算可加 |
| AVI | O(\|O\|·b^k) | O(b^k) | 前向深度有界、贝叶斯更新一致 |
| SCC | O(\|S\|·\|A\|+\|H\|·\|T\|) | O(\|S\|+\|T\|) | `reach` sound、fallback 全定义 |
| CSR | O(\|plan\|) | O(1) | 覆盖率有界、间隙可计算 |

**定理 1（Reachable Soundness）**
第 54 轮 (A22)–(A28) 成立；新增 **(A29)** 位姿信念按模态校准；**(A30)** `σ_S` 结构化仿真校准且任务坐标系 Lipschitz；**(A31)** 观测计划的条件下覆盖可验证；**(A32)** fallback 有定义且不劣于放弃。则
```
P(success | reach(SC)) ≥ 1 - δ_p - δ_task - β_E - P(δ_a > Θ_a)
```

**定理 2（赛局得分下界）**
在定理 1 与 `|Score_model - Score_true| ≤ ε_score` 下：
```
E[Score] ≥ Σ_i v_i·(1 - δ_{p,i} - δ_{task,i} - β_E) - λ·E[τ_total] - R_strategy - R_score
```
**关键**：若证书覆盖率无法在 `τ_pose` 内达成，定理退化为"空头证书"——`δ_task` 被人为压低，真实失败率却不受控。故 `reach` 是本轮不可省略的承重谓词。

## 6. 本轮最大风险

**一句话**：把 soundness 从"静态为真"推进到"比赛时钟内可达"，并用竞赛策略分配位姿与风险预算，确实填补了第 54 轮"证书正确但不可执行"的空洞；但整套论证 **双重依赖位姿信念的按模态校准与评分模型的正确性**——一旦信念过自信或模态坍缩，策略会把有限的观测预算投给"证书可达而实际不可观测"的任务，若评分规则还被误设，系统会以极高的证书通过率系统性地输掉比赛，故必须以 **模态保持的校准门 + 评分歧义集上的鲁棒分配 + 探针安全包络** 三重护栏，宁可降级到低分 fallback，也绝不把"可达性假象"当成可部署前提。
