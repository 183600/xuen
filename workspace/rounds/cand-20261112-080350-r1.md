# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；灵感循环第 6 轮；本轮灵感：「目标检测」×「指令泛化」）

> 第 59 轮把安全论证一路压到电流环、WCET 与阻抗参数，堵住了「执行器不是理想执行器」的抽象泄漏。但整条证据链仍踩在两个更靠上、从未被审计的隐含前提上：**（i）系统知道「对谁做」——目标检测给出的那个 argmax 框被默认当成被指称对象；（ii）系统知道「在做什么」——自然语言指令被默认解析成唯一正确的任务规范 φ。** 本轮两个灵感精准击中这两点：**目标检测**把「对象」还原为带类别/属性/身份/空间关系/遮挡条件的**指称后验与预测集**，误检、漏检、身份互换、属性绑错都不是 i.i.d. 像素噪声，而是**由指称表达式条件化的结构化不确定性**；**指令泛化**把「任务」还原为组合语法上的**任务规范分布**，真正危险的不是「把 φ 执行错了」，而是「φ̂ ≠ φ 却执行得完美」——**规范错误对执行接地完全不可见**。本轮核心命题：**「把『我在做什么、我对谁做』从隐含前提提升为一等证据对象：建立 指令→指称→执行→结果 的四层接地链，使语义不确定性与指称不确定性可校准、可对账、可主动消歧，并把『相关见证幻觉』从『共识即正确』中剥离」**——从第 59 轮的**执行接地**推进到**任务接地**。

核心矛盾：

- **H35（指称坍缩·检测不是标签而是后验）**：第 53–59 轮的所有探针、承诺、阻抗编译都以「区域 r 对应的物体 o」为原子事实。但检测器输出的是 `(box, class, score)`，下游取 argmax 后把 `P(o | 指称表达式)` 折叠成 one-hot。真实风险是结构化的：漏检让「对谁做」直接落空；误检让机器人对**不存在的物体**做出高置信承诺；同类别多实例导致**身份互换**（左杯/右杯）；属性绑错（红/蓝、开/闭）让「正确的动作作用在错误的对象上」。更致命的是，检测与指称表达式相关——用同一段语言去检索时，模型会**按语言先验去「看见」它想看见的东西**，于是错误高度自洽。
- **H36（指令过泛化·规范错误不可见）**：组合泛化的失败发生在「新属性 × 新关系 × 新物体 × 新动作」的交叉组合上。解析器总能产出一个 φ̂，而且往往高置信；执行层随后忠实地验证「执行是否满足 φ̂」，却从不验证「φ̂ 是否忠实于 u」。于是**一个规范错误会通过所有执行证据门，表现为『完美地做错了任务』**。长程任务还会发生**目标锚定漂移**：内部 φ̂_t 与初始指令逐渐偏离，而每一步的局部证据都自洽。
- **H37（相关见证幻觉·共识不等于独立）**：XMC/XMC+ 的对账有效性依赖模态**条件独立**。但目标检测与指令解析在真实系统里常共享同一 VLM/视觉主干——它们的错误有强公共成分 Z。此时「视觉说红杯、语言也说红杯」可能只是 Z 在自说自话；**增加同源模态不会把失效概率压到 P(Z) 以下**。若不审计独立性，跨模态一致反而会成为**最有说服力的错误证据**。

## 0. 直觉与动机

**灵感 1（目标检测 → 指称检测不确定性量化 RDU）**

直觉：检测器不是「事实提取器」，而是**在指称表达式 ρ 条件下对候选实例打分**。把场景实例记为 o_1..o_n，检测输出框、类别分布、掩码/嵌入与分数；指称后验应在「语言-视觉相似度 × 属性/关系一致性 × 检测置信度」上归一化，而不是取 argmax。真正可交付给证据层的不是「这是杯子」，而是**指称预测集 R_α(ρ)**：以 1−α 概率包含真实被指称实例的候选集合。

关键洞见有三点。其一，**覆盖率必须按层条件化**（属性层、关系层、遮挡桶、实例数桶、开放词表桶）：边际覆盖率会被大量「单实例、无遮挡、常见类」样本刷高，却在「同色双杯 + 部分遮挡 + 新属性词」这类真正危险的层上失效；这正是 Mondrian/群条件共形要解决的问题。其二，**指称证据有鲜度**：检测框随目标运动、机器人自身运动、遮挡变化而迅速过期，必须像第 59 轮的 τ_evidence 一样，用 `τ_det ≤ T_det_valid(motion, occlusion)` 约束可用性。其三，**开放词表的「未知未知」不能靠温度缩放解决**：当指称表达式落在校准支撑之外时，正确动作是**弃权（abstain）并主动消歧**，而不是给一个更保守的 argmax。

输出证据对象 `EV-det` 携带：指称预测集 R_α、条件覆盖证书、分层有效样本量 ESS_z、定位协方差、遮挡分、检测时延/鲜度、开放词表 OOD 标志、弃权原因。

**灵感 2（指令泛化 → 指令泛化不确定性 IGU）**

直觉：自然语言指令不是字符串，而是**组合语法 G 上的任务规范分布**。解析器 P 应输出解析森林（多个 φ），而不是单个 φ̂。危险不在「把 φ 执行错」，而在「φ̂ 与 u 的语义不一致」。所以证据门必须新增一条**规范忠实性检查**：`φ̂ ⊨ u`，其不确定性与执行不确定性正交。

严格化需要三件事。第一，**解释集**：用共形/后验可信集给出 `I_β(u)`，以 1−β 概率包含真实任务规范；对每个检查点，只有当动作 a **鲁棒满足** I_β 中所有 φ 时才允许不可逆承诺。第二，**组合泛化证书**：用组合语法的产生式支撑度与描述长度给出泛化间隙界（PAC-Bayes / 一致收敛），把「这个新组合我们没见过」变成一个可计算、可阈值化的量，而不是事后才知道。第三，**长程锚定**：随时间重新解析并度量 `d_anchor(φ_committed, φ̂_t)`；漂移超阈即回锚或降级。输出 `EV-inst = (I_β, cov_G, ood_score, complexity, τ_inst, clarify_required)`。

**灵感 3（两灵感合流 → 任务接地对账 TGR）**

直觉：第 59 轮是「证据层 ↔ 执行层」的双向契约；本轮补上上方两层——**语义层（指令）与指称层（检测）**，形成四层接地链：`指令 u → 规范 φ → 指称 o → 动作 a → 结果 y`。每一层都要有证据、契约与可检查的一致性边：

- `e1` 指称–指令：被选中的实例是否满足指令中的属性/关系/数量约束？
- `e2` 指称–执行：执行器实际作用的对象是否与指称对象**物理同一**（接触点几何、力签名、质量/柔顺性预期）？
- `e3` 执行–结果：后置条件是否成立？
- `e4` 指令–结果：结果是否真的完成了 u 的语义（而不是完成了某个局部 φ̂）？

把四条边的违背量加权成**接地方差 `D_gnd`**；`D_gnd` 超阈即加宽后验并触发主动消歧。关键立场：**层与层之间不能互相「担保掉」不确定性**——执行成功不能证明指称正确，指称正确不能证明指令解析正确。

**灵感 4（相关见证幻觉 → 相关见证审计 CWA）**

直觉：XMC 的贝叶斯融合隐含「给定真值后各模态条件独立」。若检测与语言共享同一 VLM 主干，则它们的错误可写成 `E_m = Z ⊕ E_m^⊥`（公共失效 Z + 模态特异残差）。此时再多的同源模态也只能把方差压到 `Var(Z)` 的地板，**共识无法证明正确**。于是必须显式估计模态共失败矩阵、计算**有效独立见证数 n_eff**，并对不可逆动作要求**至少一个团外见证**——物理接触、本体感觉、人类确认这些与 VLM 不同的**干预性见证**。

一个重要而精细的边界：第 59 轮规定 EV-exec 不得作为 EV-xmodal 的替代佐证。本轮保留该禁令，但做出**语义-物理的不对称区分**：EV-exec **可以**作为「被作用对象是哪一个」的干预性见证（这是物理事实：接触几何/力签名/质量），**绝不可以**作为「任务语义是否正确」的佐证（这是语义事实）。这一区分既避免自证循环，又让执行证据在指称层发挥不可替代的去相关作用。

**灵感 5（主动消歧与五预算 → ADX + PCE++++）**

直觉：当指称集不唯一或解释集不唯一时，最优动作往往不是「更保守地做」，而是**先花一点代价把不确定性降下来**：换视角、移动底座、轻推物体、问人一句、或做一次低风险物理探针。把这些统一成**接地价值 VOI**：预期风险下降减去执行成本（复用第 59 轮 `cost_exec`）再减去人类成本。第 59 轮已有 B_probe/B_ft/B_ux/B_exec 四预算，本轮新增 **B_ground（接地预算：澄清次数、主动视角时长、移动能量、独立见证校验次数）**，构成 PCE++++。预算耗尽只能退向「鲁棒解释交集 + 更宽共形带 + 安全停」，不能假装不确定性消失了。

## 1. 形式化定义（增量：定义 153–160）

**定义 153（指称检测不确定性 RDU 与指称后验）** 设场景实例集 `O={o_1..o_n}`，检测器 D 输出 `H={(b_i,c_i,s_i,e_i,m_i)}`（框、类别分布、分数、嵌入、掩码），指令指称表达式为 ρ，上下文为 C（空间关系、任务先验、历史）。指称后验
```
q(i | ρ,H,C) = softmax_i [ sim(f_L(ρ), f_V(o_i)) / T
                        + λ_a · 1[attr(o_i) ⊨ attr(ρ)]
                        + λ_r · rel(o_i, C; ρ)
                        + λ_s · log cal(s_i, c_i) ]
```
其中 `cal` 是分层校准后的检测置信度。定义非 conformity 分数 `A_i = 1 − q(i|ρ,H,C)`，用分层校准集 `S_z`（z=(属性桶,关系桶,遮挡桶,实例数桶,词表桶)）构造 **Mondrian 指称预测集**
```
R_α(ρ) = { o_i : p_i > α },   p_i = (1 + #{j∈S_z : A_j ≥ A_i}) / (|S_z|+1)
```
目标覆盖率 `P(o_{i*} ∈ R_α(ρ) | z) ≥ 1−α−δ_shift`，其中 `δ_shift` 由加权共形（似然比权重 w=p_tgt/p_cal）与有效样本量 `ESS_z=(Σw)²/Σw²` 给出；若 `ESS_z < N_min` 或 `R_α=∅` 或 `ρ` 落在词表支撑外，则**弃权** `abstain_ref=true`。指称证据
```
EV-det = (R_α, α, z, ESS_z, Σ_loc, occl, τ_det, ood_ref, abstain_ref)
```
且仅在 `τ_det ≤ T_det_valid(v_rel, occl)` 时可用于承诺（`v_rel` 为目标/机器人相对运动速度，`T_det_valid` 由框速度不确定性传播得到）。

**定义 154（指令泛化不确定性 IGU 与解释集）** 设组合语法 `G=(N,Σ,P,S)` 生成任务规范语言 Φ（STL/行为树/程序），解析器 P 在指令 u 上给出解析森林与后验 `P(φ|u)`。定义解释集
```
I_β(u) = { φ ∈ Φ : p_φ > β },   p_φ = (1 + #{φ'∈S : A_{φ'} ≥ A_φ}) / (|S|+1)
A_φ = −log P(φ|u) + γ·DL(φ)
```
其中 S 为指令校准集，`DL(φ)` 为解析树描述长度。定义**组合覆盖度** `cov_G(u) = min_{r ∈ prod(φ*)}  min(1, n_r / n_min(r))`（`n_r` 为校准集中产生式 r 的经验出现数）。在语法级 PAC-Bayes 界下，以概率 ≥1−δ：
```
err_sem(u) ≤ err_emp(r) + sqrt( (KL(Q||P_0) + ln(2√m/δ)) / (2m) )
```
其中 Q 为解析诱导的产生式后验，P_0 为语法先验，m 为校准指令数。若 `cov_G(u) < cov_min` 或 `err_sem` 上界 > ε_sem，则标 `ood_inst=true` 并要求澄清或鲁棒解释。对长程任务定义**锚定漂移** `d_anchor(t) = 1 − sim_sem(φ_committed, φ̂_t)`，`d_anchor > θ_anchor` 即回锚。输出
```
EV-inst = (I_β, cov_G, err_sem_ub, complexity, ood_inst, τ_inst, clarify_required)
```

**定义 155（任务接地对账 TGR）** 对检查点 cp 构造接地图 `G_gnd=(V,E)`，节点 `V={v_inst, v_ref, v_exec, v_out}` 分别承载 EV-inst、EV-det、EV-exec（第 59 轮）、结果观测；边为接地断言
```
e1: ∀φ∈I_β, ∀o∈R_α: o ⊨ φ                      （指称–指令）
e2: phys_id(a_target, o) = 1                    （指称–执行：接触几何/力签名/质量）
e3: y ⊨ post(φ̂),  φ̂ ∈ I_β                     （执行–结果）
e4: y ⊨ post(φ),  ∀φ∈I_β（鲁棒满足）           （指令–结果）
```
接地方差
```
D_gnd = λ1·viol(e1) + λ2·d_phys(e2) + λ3·viol(e3) + λ4·max_{φ∈I_β} viol_φ(e4)
       + λ5·TV(q_ref, onehot(î)) + λ6·d_anchor
```
规则：`D_gnd > θ_g` ⇒ 加宽后验、触发 ADX；任一 e1/e2/e4 在**不可逆**承诺前被证伪 ⇒ 直接拒绝；e3 通过而 e4 未定义（I_β 不可用）⇒ 不得把 e3 当作任务成功证据。

**定义 156（相关见证审计 CWA 与有效独立见证数）** 对模态 m 的误差建模 `E_m = Z ⊕ E_m^⊥`，Z 为共享失效因子（同源主干/同训练数据/同物理假设），`E_m^⊥` 条件独立。由留出集共失败矩阵估计 `ρ_ij = P(E_i∧E_j)/√(P(E_i)P(E_j))`。对权重 `w=(w_1..w_K)`，有效独立见证数
```
n_eff = (Σ_m w_m)² / ( Σ_m w_m² + 2 Σ_{i<j} w_i w_j ρ_ij )
```
融合协方差满足下界 `Σ_fused ⪰ σ_Z² 1 1ᵀ`，故 `P(共识错误) ≥ P(Z 失效)`，**同源模态数量不改变该地板**。定义见证团 `C_ρ = {m : ρ_ij > ρ_max, i,j∈C_ρ}`。独立性证书
```
EV-ind = (n_eff, C_ρ, ρ_max, interventional_witness_present, witness_types)
```
硬规则：不可逆动作要求 `n_eff ≥ n_min` 且**至少一个团外干预性见证**（haptic/proprio/human/physical-exec）；否则拒绝。EV-exec 仅在 `witness_types=physical` 时可用于指称同一性，永不用于语义正确性。

**定义 157（主动消歧 ADX 与接地价值）** 接地动作集
```
A_gnd = { next_best_view(θ) , move_base(p) , ask_referent(ρ) ,
          ask_instruction(u) , physical_probe(a_exec) , re_detect(z) }
```
每个动作 a 的接地价值
```
VOI_gnd(a) = E_{y~p(y|a)}[ D_gnd(before) − D_gnd(after,y) ]
             − cost_exec(a; ξ_exec, C_rt, K_safe)      # 第 59 轮
             − cost_human(a) − cost_time(a)
```
可行域受 ERTC、EEIS、B_ground 约束。选择 `a* = argmax_{a∈A_gnd} VOI_gnd(a)`；若 `max VOI < θ_voi` 且 `δ_sem+δ_ref > δ_req`，则转人类澄清或安全停。不可逆动作的前置条件为 `δ_sem + δ_ref ≤ δ_irr` 且 CWA 通过。

**定义 158（接地预算 B_ground 与 PCE++++）**
```
B_ground = (N_clarify, T_view, E_move, N_verify)
cost_ground(a) = λ_c·1[ask] + λ_v·T_view(a) + λ_e·E_move(a) + λ_x·N_verify(a)
voi_ground(a) = VOI_gnd(a) − cost_ground(a)
```
PCE++++ 在 `B_probe/B_ft/B_ux/B_exec` 之外新增 B_ground，五预算**单调消耗、互不挪用**。任一子预算耗尽：`N_clarify=0` ⇒ 只允许鲁棒解释交集或停；`T_view=0` ⇒ 不允许 next-best-view，只能弃权/停；`E_move=0` ⇒ 不允许移动消歧；`N_verify=0` ⇒ 不可逆动作一律拒绝。

**定义 159（接地证书 J_ground）**
```
J_ground = (EV-det_chain, EV-inst_chain, G_gnd_snapshot,
            EV-ind_chain, ADX_log, B_ground_snapshot)
```
验证条件：(i) 每个不可逆动作的接地图无环，且每条 e1/e2/e4 边终止于**团外干预性见证**；(ii) EV-det 与 EV-inst 的时间戳早于动作下发（无时间旅行）；(iii) 无见证团以自身成员充当独立性证明；(iv) `D_gnd` 审计可复算、版本化、不可篡改。

**定义 160（任务接地健全性界 TGS）** 对检查点取联合界：
```
P(任务正确 ∧ 安全) ≥ 1 − Σ_cp [ δ_sem + δ_ref + δ_exec + δ_shared + δ_anchor
                              + δ_ood_sem·1[I_β失效] + δ_ood_ref·1[R_α失效] ]
                     − P(接地图结构性错误未检出) − P(ADX失效) − P(人类澄清错误)
```
其中 `δ_shared = P(Z 失效)` 为**不可由同源共识消除**的地板项；`δ_exec` 沿用第 59 轮。该界解释了为什么「多加一个同源 VLM 模态」在数学上不会改善安全：它不进入独立见证计数。

## 2. 关键算法伪代码

### IP-152 RDU（指称检测不确定性量化）

```python
class ReferentialDetectionQuantifier:
    def __init__(self, detector, alpha=0.05, strata=("attr","rel","occl","n_inst","vocab")):
        self.D, self.alpha, self.strata = detector, alpha, strata
        self.cal = defaultdict(list)          # stratum -> nonconformity scores
        self.loc_cal = defaultdict(list)

    def detect(self, rgbd, rho, ctx):
        dets = self.D(rgbd)                   # [(box, cls, score, emb, mask)]
        q = self.referent_posterior(dets, rho, ctx)
        z = self.stratum(rho, dets, ctx)
        if len(self.cal[z]) < N_MIN_STRATUM or self.oov(rho, z):
            return EVdet.abstain(z=z, reason="insufficient_support")
        w = self.shift_weights(z)             # p_tgt / p_cal
        p = weighted_conformal_pvalues(q, self.cal[z], w)
        R = {i for i, pi in enumerate(p) if pi > self.alpha}
        if not R:
            return EVdet.abstain(z=z, reason="empty_referent_set")
        return EVdet(
            R=R, q=q, stratum=z, ess=ess(self.cal[z], w),
            loc_cov=self.loc_cov(dets, R), occl=max(d.occl for d in dets),
            tau_det=now() - dets.timestamp, ood_ref=self.is_ood(rho, z))

    def referent_posterior(self, dets, rho, ctx):
        s = [sim(f_L(rho), d.emb) / T
             + LAMBDA_A * attr_consistent(d, rho)
             + LAMBDA_R * relation_consistent(d, ctx, rho)
             + LAMBDA_S * log(self.calibrated_score(d)) for d in dets]
        return softmax(s)
```

```python
class InstructionGeneralizationParser:
    def __init__(self, parser, grammar, beta=0.05, cov_min=0.6, eps_sem=0.05):
        self.P, self.G = parser, grammar
        self.beta, self.cov_min, self.eps_sem = beta, cov_min, eps_sem

            clarify_required=ood or self.ambiguous(I, forest))
```

```python
class CorrelatedWitnessAuditor:
    def estimate(self, heldout):
        # 留出集上统计两两共失败，收缩估计避免小样本病态
        self.rho = shrink(copath_matrix(heldout), k=K_SHRINK)

    def n_eff(self, w):
        num = sum(w.values()) ** 2
        den = sum(x*x for x in w.values())
        den += 2*sum(w[i]*w[j]*self.rho[i][j]
                     for i in w for j in w if i < j)
        return num / max(den, EPS)

    def audit(self, witnesses, irreversible):
        clique = correlated_cliques(self.rho, RHO_MAX)
        interventional = [w for w in witnesses
                          if w.type in {"haptic","proprio","human","physical"}]
        present = any(not any(w.id in c for c in clique) for w in interventional)
        neff = self.n_eff({w.id: w.weight for w in witnesses})
        ok = neff >= N_MIN_EFF and (present or not irreversible)
        return IndependenceCert(ok=ok, n_eff=neff, cliques=clique,
                                interventional_present=present)
```

**正确性定理（Task-Grounded Evidence Soundness, TGES）**
假设 A22–A55（第 53–59 轮）成立；**(A56)** RDU：分层共形在协变量偏移下满足 `P(o_{i*}∈R_α|z) ≥ 1−α−δ_shift`，且 `τ_det > T_det_valid` 时证据被丢弃；弃权不漏报（abstain 是显式保守动作）。**(A57)** IGU：解释集满足 `P(φ*∈I_β) ≥ 1−β`；PAC-Bayes 界诚实；`ood_inst=true` 时禁止不可逆承诺。**(A58)** TGR：四边断言可判定；`D_gnd` 为各边违背量的诚实上界；不可逆动作前 e1/e2/e4 必须成立。**(A59)** CWA：共失败矩阵估计误差 ≤ε_ρ；`n_eff` 与融合协方差下界成立；干预性见证类型与 VLM 共享因子 Z 条件独立。**(A60)** ADX：`VOI_gnd` 为真实风险下降的诚实估计；预算耗尽 ⇒ 保守。**(A61)** PCE++++：五预算单调、互不挪用；B_ground 耗尽 ⇒ 保守而非冒险。则：

1. **指称校准健全性**：对每个分层 z，被承诺指称的正确率 ≥ 1−α−δ_shift−δ_ood_ref；指称错误不会通过 e1/e2 检查进入不可逆承诺。
2. **语义泛化健全性**：被承诺任务的语义错误率 ≤ ε_sem + β + δ_ood_sem；组合覆盖不足的新指令要么被澄清，要么被鲁棒解释交集约束。
3. **链式健全性**：`P(任务正确 ∧ 安全) ≥ 1 − Σ_cp(δ_sem+δ_ref+δ_exec+δ_anchor) − δ_shared`，其中 `δ_shared` 不可通过增加同源模态降低。
4. **相关见证不可自证**：若所有模态同属一个相关团，`n_eff < n_min`，不可逆动作被拒绝；EV-exec 仅可作为物理同一性见证，不可作为语义佐证。
5. **单向性**：EV-det/EV-inst/EV-exec 的一致性只能减少「消歧动作」的必要性到其契约允许的程度，不能绕过 e1/e2/e4 或降低 `δ_shared`；任何新增证据若不能提高 n_eff，则不改善安全界。
6. **终止性**：PCE++++ 在五预算内终止于 {承诺(带 J_ground), 澄清, 绕行, 降档, 安全停, 接地失败停}。

### IP-152 RDU（指称检测不确定性量化）

```python
from dataclasses import dataclass, field
from collections import defaultdict
import numpy as np

@dataclass
class EVdet:
    R: set
    q: np.ndarray
    stratum: tuple
    alpha: float
    ess: float
    loc_cov: float
    occl: float
    tau_det: float
    ood_ref: bool = False
    abstain_ref: bool = False
    reason: str = ""

    @staticmethod
    def abstain(z, reason):
        return EVdet(R=set(), q=np.array([]), stratum=z, alpha=ALPHA_REF,
                     ess=0.0, loc_cov=0.0, occl=1.0, tau_det=0.0,
                     abstain_ref=True, reason=reason)


class ReferentialDetectionQuantifier:
    def __init__(self, detector, alpha=ALPHA_REF):
        self.D = detector
        self.alpha = alpha
        self.cal = defaultdict(list)        # stratum -> nonconformity scores
        self.loc = defaultdict(list)

    def stratum(self, rho, dets, ctx):
        return (attribute_bucket(rho),
                relation_bucket(rho, ctx),
                occlusion_bucket(dets),
                instance_count_bucket(len(dets)),
                vocab_bucket(rho))

    def referent_posterior(self, dets, rho, ctx):
        s = np.array([
            sim(f_L(rho), d.emb) / TEMP
            + LAMBDA_A * attr_consistent(d, rho)
            + LAMBDA_R * relation_consistent(d, ctx, rho)
            + LAMBDA_S * log(self.calibrated_score(d))
            for d in dets])
        return softmax(s)

    def detect(self, rgbd, rho, ctx):
        dets = self.D(rgbd)
        if not dets:
            return EVdet.abstain(self.stratum(rho, [], ctx), "no_detection")
        q = self.referent_posterior(dets, rho, ctx)
        z = self.stratum(rho, dets, ctx)
        scores = self.cal[z]
        if len(scores) < N_MIN_STRATUM or self.oov(rho, z):
            return EVdet.abstain(z, "insufficient_calibration_support")

        # 加权共形：矫正检测语料与当前场景的协变量偏移
        w = self.shift_weights(z)
        p = weighted_conformal_pvalues(q, scores, w)
        R = {i for i, pi in enumerate(p) if pi > self.alpha}
        if not R:
            return EVdet.abstain(z, "empty_referent_set")

        return EVdet(
            R=R, q=q, stratum=z, alpha=self.alpha,
            ess=effective_sample_size(scores, w),
            loc_cov=self.localization_coverage(dets, R, z),
            occl=max(occlusion_score(d) for d in dets),
            tau_det=now() - dets.timestamp,
            ood_ref=self.is_ood(rho, z))

    def usable_for_commit(self, ev, v_rel):
        return (not ev.abstain_ref and ev.tau_det <=
                T_DET_VALID(v_rel, ev.occl) and
                ev.ess >= N_MIN_STRATUM and not ev.ood_ref)
```

**加权共形要点**：校准分数按 `w=p_tgt/p_cal` 加权，`p_i=(Σ_j w_j·1[A_j≥A_i])/(Σ_j w_j)`；当权重方差过大导致 `ESS=(Σw)²/Σw² < N_min` 时，覆盖证书不成立，必须弃权——这是把「校准集与部署分布不同」从隐藏假设变成显式失败模式。

### IP-153 IGU（指令泛化不确定性）

```python
@dataclass
class EView:
    I: set                     # 解释集（task specs）
    cov_G: float
    err_sem_ub: float
    complexity: int
    ood_inst: bool
    tau_inst: float
    clarify_required: bool


class InstructionGeneralizationParser:
    def __init__(self, parser, grammar, beta=BETA_INST,
                 cov_min=COV_MIN, eps_sem=EPS_SEM):
        self.P, self.G = parser, grammar
        self.beta, self.cov_min, self.eps_sem = beta, cov_min, eps_sem
        self.rule_support = defaultdict(int)
        self.cal = []              # (A_phi, true_phi_in_set)

    def parse_set(self, u, scene_ctx):
        forest = self.P.parse_forest(u)
        A = {phi: -log(forest.posterior[phi]) + GAMMA * dl(phi)
             for phi in forest.support}
        # split conformal over parse nonconformity
        p = {phi: (1 + sum(1 for a in self.cal if a >= A[phi])) / (len(self.cal) + 1)
             for phi in A}
        I = {phi for phi in A if p[phi] > self.beta}

        prods = set().union(*(productions(phi) for phi in forest.map))
        cov = min(min(1.0, self.rule_support[r] / N_MIN_RULE) for r in prods) \
              if prods else 0.0
        err_ub = pac_bayes_bound(forest.q, self.G.prior,
                                 m=max(len(self.cal), 1), delta=DELTA_PB)
        ood = (cov < self.cov_min) or (err_ub > self.eps_sem)
        return EView(I=I, cov_G=cov, err_sem_ub=err_ub,
                     complexity=dl(forest.map), ood_inst=ood,
                     tau_inst=now(),
                     clarify_required=ood or len(I) > 1)

    def update_support(self, accepted_phi):
        for r in productions(accepted_phi):
            self.rule_support[r] += 1

    def anchoring_drift(self, phi_committed, u, ctx):
        I = self.parse_set(u, ctx).I
        return 1.0 - max(sim_sem(phi_committed, phi) for phi in I)


def pac_bayes_bound(Q, P0, m, delta):
    # McAllester 型 PAC-Bayes；Q 为解析诱导后验，P0 为语法先验
    kl = kl_divergence(Q, P0)
    return sqrt((kl + log(2 * sqrt(m) / delta)) / (2 * m))
```

### IP-154 TGR（四层任务接地对账）

```python
@dataclass
class GroundingResult:
    D_gnd: float
    edges: tuple
    ind: object
    widen: bool
    block_irreversible: bool


class TaskGroundingReconciler:
    def reconcile(self, inst_ev, ref_ev, exec_ev, outcome, cwa):
        if inst_ev.ood_inst or ref_ev.abstain_ref:
            return GroundingResult(
                D_gnd=INF, edges=(False, False, False, False),
                ind=cwa.audit([], irreversible=True),
                widen=True, block_irreversible=True)

        # e1 指称–指令：所有候选指称必须满足所有可接受解释
        e1 = all(satisfies(o, phi)
                 for phi in inst_ev.I for o in ref_ev.R)

        # e2 指称–执行：物理同一性（EV-exec 只证物理事实）
        e2 = physical_identity(
            exec_ev.contact_geometry, ref_ev, exec_ev.force_signature)

        # e3/e4 执行–结果 / 指令–结果
        e3 = any(holds(outcome, post(phi)) for phi in inst_ev.I)
        e4 = all(holds(outcome, post(phi)) for phi in inst_ev.I)

        D = (L1 * (not e1) + L2 * (1.0 - e2)
             + L3 * (not e3) + L4 * (not e4)
             + L5 * tv(ref_ev.q, onehot(argmax(ref_ev.q)))
             + L6 * inst_ev.anchoring_drift)

        ind = cwa.audit(
            witnesses=[Witness("vis", "physical", ref_ev.weight),
                       Witness("lang", "semantic", inst_ev.weight),
                       Witness("phys", "physical", exec_ev.weight)],
            irreversible=False)

        return GroundingResult(
            D_gnd=D, edges=(e1, e2, e3, e4), ind=ind,
            widen=D > THETA_G,
            block_irreversible=(not e1) or (not e2) or (not e4))

    def commit_gate(self, gr, irreversible):
        if not gr.edges[0] or not gr.edges[1]:
            return False
        if irreversible:
            if not gr.edges[3]:
                return False
            if not gr.ind.interventional_present:
                return False
            if gr.ind.n_eff < N_MIN_EFF:
                return False
        return gr.D_gnd <= THETA_G
```

### IP-155 CWA（相关见证审计）

```python
@dataclass
class IndependenceCert:
    ok: bool
    n_eff: float
    cliques: list
    interventional_present: bool
    rho: dict


class CorrelatedWitnessAuditor:
    def __init__(self, rho_max=RHO_MAX, n_min=N_MIN_EFF):
        self.rho_max, self.n_min = rho_max, n_min
        self.rho = {}

    def estimate(self, heldout):
        # 共失败矩阵 + 收缩，避免小样本下 ρ 估计为 ±1
        raw = copath_matrix(heldout)
        self.rho = {k: shrink(v, K_SHRINK) for k, v in raw.items()}

    def n_eff(self, w):
        keys = list(w)
        num = sum(w.values()) ** 2
        den = sum(w[k] ** 2 for k in keys)
        den += 2 * sum(w[i] * w[j] * self.rho.get((i, j), 0.0)
                       for i in keys for j in keys if i < j)
        return num / max(den, EPS)

    def cliques(self):
        return maximal_cliques({(i, j) for (i, j), r in self.rho.items()
                                if r > self.rho_max})

    def audit(self, witnesses, irreversible):
        cls = self.cliques()
        interventional = [w for w in witnesses
                          if w.kind in INTERVENTIONAL_KINDS]  # haptic/proprio/human/physical
        present = any(all(w.id not in c for c in cls) for w in interventional)
        neff = self.n_eff({w.id: w.weight for w in witnesses})
        ok = neff >= self.n_min and (present or not irreversible)
        return IndependenceCert(ok=ok, n_eff=neff, cliques=cls,
                                interventional_present=present, rho=self.rho)
```

**n_eff 推导**：设 `ŷ = Σ w_m y_m / Σ w_m`，`Var(y_m)=σ²`，`Corr(y_i,y_j)=ρ_ij`。则
```
Var(ŷ) = σ² [Σ w_m² + 2Σ_{i<j} w_i w_j ρ_ij] / (Σ w_m)²
```
独立等效样本数为使等权独立平均达到同方差的样本数，即上式方括号的倒数，故 `n_eff=(Σw)²/(Σw²+2Σ_{i<j}w_iw_jρ_ij)`。当所有模态同源 `ρ=1` 时 `n_eff=1`——无论加多少模态，安全界都不能低于单模态的 `P(Z)`。

### IP-158 J_ground（接地证书）

```python
@dataclass
class GroundingCertificate:
    ev_det_chain: list
    ev_inst_chain: list
    grounding_graphs: list
    independence_chain: list
    adx_log: list
    budget_snapshot: object
    version: int
    timestamp: float

    def verify(self):
        # 1. 接地图无环
        if any(not acyclic(g) for g in self.grounding_graphs):
            return False
        # 2. 不可逆动作必须有团外干预性见证
        for g in self.grounding_graphs:
            for e in irreversible_edges(g):
                if not e.terminates_in_interventional_witness():
                    return False
        # 3. 时间戳单调：证据先于动作
        for i, (ev, a) in enumerate(zip(self.ev_det_chain, self.adx_log)):
            if ev.timestamp > a.timestamp:
                return False
        # 4. 无自证团
        if any(c.self_justified() for c in self.independence_chain):
            return False
        # 5. 版本单增
        if any(self.grounding_graphs[i].version <=
               self.grounding_graphs[i-1].version
               for i in range(1, len(self.grounding_graphs))):
            return False
        return True
```

## 3. 风险分解与映射（承接第 59 轮）

第 59 轮把 `δ_f` 编译为执行层硬约束；本轮把 `δ_f` 进一步分解到接地链：
```
δ_f(cp) ≤ δ_sem(cp) + δ_ref(cp) + δ_exec(cp) + δ_anchor(cp) + δ_shared(cp)
```
分配建议（Boole 不等式，具体比例可在线校准）：
```
δ_sem  = ρ_sem · δ_f          # 解释集覆盖缺口 + 组合泛化界
δ_ref  = ρ_ref · δ_f          # 指称预测集覆盖缺口
δ_exec = ρ_exec · δ_f         # 第 59 轮 EEIS/ERTC/BUQ 联合界
δ_anchor = ρ_anchor · δ_f     # 长程回锚失败
δ_shared = P(Z 失效)          # 不可由同源共识消除的地板
```
约束 `ρ_sem+ρ_ref+ρ_exec+ρ_anchor ≤ 1−P(Z)`。若无法满足，唯一合规动作是**提高独立见证数（引入物理/人类）或降级为不可逆禁止**，而不是继续调阈值。

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| RDU | O(\|O\|d + \|S_z\| log\|S_z\|)/帧 | O(\|S_z\|d) | 分层共形覆盖 ≥1−α−δ_shift；ESS 不足即弃权 |
| IGU | O(\|forest\|·DL + \|S\|) | O(\|P\|·\|S\|) | 解释集覆盖 ≥1−β；PAC-Bayes 泛化界 |
| TGR | O(4·\|I_β\|·\|R_α\| + \|E\|) | O(\|V\|+\|E\|) | 四边一致性；不可逆前 e1/e2/e4 硬约束 |
| CWA | O(K²) 估计；O(K³) 团分解（K≤6） | O(K²) | n_eff 下界；δ_shared 地板不可由共识降低 |
| ADX | O(\|A_gnd\|·(VOI+CLEP)) | O(\|A_gnd\|) | 预算内最大 VOI；无动作即澄清/停 |
| PCE++++ | O(\|CP\|·(k_sem+k_ref+k_p+k_ft+k_ux+k_exec)·C) | O(\|V\|+N_hist) | 五预算单调、互不挪用、耗尽即保守 |
| J_ground | O(1)/检查点追加 | O(检查点数) | 无环、时间戳单调、无自证团、版本单增 |

**正确性定理（Task-Grounded Evidence Soundness, TGES）**
假设 A22–A55（第 53–59 轮）成立；**(A56)** RDU：分层共形满足 `P(o_{i*}∈R_α|z) ≥ 1−α−δ_shift`，过期证据被丢弃，弃权为显式保守。**(A57)** IGU：`P(φ*∈I_β) ≥ 1−β`；PAC-Bayes 界诚实；OOD 禁止不可逆承诺。**(A58)** TGR：四边可判定，`D_gnd` 为违背量诚实上界。**(A59)** CWA：共失败矩阵估计误差 ≤ε_ρ；`n_eff` 与融合协方差下界成立；干预性见证与共享因子 Z 条件独立。**(A60)** ADX：`VOI_gnd` 为真实风险下降的诚实估计。**(A61)** PCE++++：五预算单调、互不挪用、耗尽即保守。则：

1. **指称校准健全性**：分层指称正确率 ≥1−α−δ_shift−δ_ood_ref；指称错误不能通过 e1/e2 进入不可逆承诺。
2. **语义泛化健全性**：被承诺任务语义错误率 ≤ε_sem+β+δ_ood_sem；组合覆盖不足的指令被澄清或鲁棒解释交集约束。
3. **链式健全性**：`P(任务正确∧安全) ≥ 1−Σ_cp(δ_sem+δ_ref+δ_exec+δ_anchor)−δ_shared`。
4. **相关见证不可自证**：同团模态 `n_eff<n_min` ⇒ 不可逆动作拒绝；EV-exec 只证物理同一性，不证语义。
5. **单向性**：EV-det/EV-inst/EV-exec 的一致性只能减少消歧需求到契约允许范围，不能绕过 e1/e2/e4，也不能降低 `δ_shared`。
6. **终止性**：PCE++++ 在五预算内终止于 {承诺(带 J_ground), 澄清, 绕行, 降档, 安全停, 接地失败停}。
