# 第 4 轮（继承第 3 轮 InstructGauge；本轮灵感：「通用机器人平台」×「Isaac Sim」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge-6C、第 1 轮 LeanGauge / MODGAUGE 骨架继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。「通用机器人平台」沿**横向可移植**轴升级，「Isaac Sim」沿**纵向可预演**轴升级；任一环节不可用都必须能一键退回 InstructGauge，平台与仿真都是增强项、不是依赖项。

## 0. 直觉与动机

**灵感 1（通用机器人平台 → 本体索引的能力闭包，而不是“万能工具”）**
直觉：所谓通用平台，不是一台机器人拥有所有能力，而是**一套类型化接口**（状态/观测/动作/单位/坐标帧/物理包线）让同一套计量与修复逻辑能跑在异构本体上。上一轮的「能力闭包」是**单本体**的：语言不能命名 `T₀` 之外的工具。到了平台族，真正的漏洞变成「同一条技能在 A 上合法、在 B 上物理意义不同」。因此正确的升级是把闭包**按本体索引**：`tools(ι) ⊆ T₀(E)`、`mag(ι) ⊆ M_phys(E)`，且跨本体只能经由**保持前后置条件的本体态射 φ** 重接地，不能直接复制。语言依旧只做子集选择，只是选择域随本体变化。

**灵感 2（Isaac Sim → 非对称权威的“风洞”，而不是真值 oracle）**
直觉：物理探测昂贵且常不可逆；仿真便宜、可并行、可复现，天然适合“预演”。但仿真是一个**模型**。一旦让仿真**授权**执行，我们就用模型意见替换了物理证据——这正是“看起来真”的认知谬误。正确的接口是**非对称孪生权威（ATA）**：孪生可以**否决**候选块（影子执行违反盾/后置/包线），但**绝不授权**；真正执行仍必须由 CVC 与真实回执放行。这个单向性带来一个极强的好处：**即便仿真器完全错误，甚至被对手控制，它最多造成误否决（活性损失），不能扩大真实执行的动作集**。仿真只在**已认证的保真包线**内参与统计，覆盖保证仍由真实锚点锚定。

**灵感 3（两者耦合 → 双重虚假泛化，必须被“证书隔离”切断）**
直觉：一个“可移植技能” + 一个“高保真仿真” = 两条错误通道相乘：语义漂移 × sim2real 间隙。最危险的情形是：技能在 A 本体仿真里验证通过，被直接搬到 B 本体真机执行，而两处误差恰好同向。解法不是禁用仿真或平台，而是三根结构支柱：**本体态射与可移植性证书**（没有 φ 就必须逐本体重接地）、**保真包线与证书时效**（包线外一律弃权，仿真统计不得外推）、**真实锚点**（合成样本只能紧缩候选与先验，不能单独签发覆盖）。再叠加**否决门**与**并行有效样本量折扣**（相关失败会让 N 个并行环境只值 N_eff 个样本）。

## 1. 研究问题（本轮要回答什么）

- **Q1（平台可移植性）**：一条在 A 本体上成立的修复契约，在什么条件下能**可靠**迁移到 B 本体？可移植性证书需要什么可检验义务？
- **Q2（仿真认识论）**：如何利用高保真仿真而不让**建模误差变成安全误差**？仿真应拥有怎样的权限边界？
- **Q3（耦合的超线性风险）**：可移植性 × 仿真置信度是否产生超线性的虚假自信？能否用结构把它压回可界、可证伪？

## 2. 三条设计原则（雏形，正式化见产物区定义 448–459）

**P4 本体索引闭包与可移植性（Embodiment-Indexed Closure）**
语言与技能只能在**当前本体**的预注册工具/幅值/传感器域内选择；跨本体必须携带 `PortCert = (φ, ρ_cov, G_sim^φ, checks, expiry)`，其中 φ 是保持前后置条件与安全不变量的本体态射。无 φ ⇒ 逐本体重新接地，绝不复制。

**P5 非对称孪生权威（Asymmetric Twin Authority, ATA）**
孪生门 `TwinGate ∈ {pass, veto}`，且 `pass ≠ authorize`。执行授权只能来自 CVC + 真实回执。于是带门执行集 ⊆ 不带门执行集：仿真只能删动作，不能加动作。错误仿真的最坏后果是误否决，不是越权执行。

**P6 回执锚定的统计（Receipt-Anchored Statistics）**
合成样本可以暖启动先验、收缩候选、估计漂移，但覆盖证书必须由真实锚点在**已认证包线**内签发；并行环境的相关性必须用有效样本量 `N_eff` 折扣，禁止把“N 个环境”当成“N 个独立证词”。

## 3. 与基线的接口（如何退化）

- 无可用本体态射 / 可移植性证书过期 ⇒ 逐本体回退 InstructGauge（不跨本体迁移）；
- Isaac Sim 不可用 / 保真证书过期 / 状态出包线 ⇒ **跳过 TwinGate**，纯 InstructGauge；
- 真实锚点不足 ⇒ 回退全局/纯真实共形校准（InstructGauge SC-Cal）；
- 孪生否决 ⇒ 渐进降级：重规划 → 逐步（K=1）→ InstructGauge；
- InstructGauge 失效 ⇒ ToolGauge；ToolGauge 失效 ⇒ LeanGauge；LeanGauge 失效 ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个**本体索引**的能力闭包与可移植性证书，把“跨本体迁移”从口头假设变成可类型检查、可证伪的义务；
2. 一个**否决-only** 的孪生门控，使高保真仿真在**任意模型误差下**都不会扩大真实执行集（引理 59）；
3. 一个**包线 + 锚点 + 有效样本量**的孪生锚定校准，给出 `1−α−L·G_sim` 形式的可降级覆盖界；
4. 一条完整可证伪路径：E457–E472 覆盖平台一致性、跨本体可移植、保真认证、否决安全、并行相关、吞吐摊销与降级等价。

## 5. 本轮最大风险

**一句话**：真正的风险不是仿真不够真，而是我们把 Isaac Sim 的**逼真度误当成认识论权威**，再用“跨本体验证通过”给它加冕——一旦高保真孪生在校准包线外系统性偏乐观，否决门会安静地放行，而系统看起来比上一轮更可信。

## 2. 形式化定义（要点）

**定义 448（通用具身模式 U）** 具身 `E` 是 `U` 的一个实例：状态/观测/动作带单位与坐标帧，动作受 `M_phys(E)` 限幅，观测受 `Γ_obs(E)` 传感器域约束。**类型一致公理**：任何跨域写入必须显式单位/帧转换，缺失即类型错误。METRICS 族（收缩、位姿、力/热）在同一单位规范下可比。

**定义 449（本体态射 φ 与模拟关系）** 部分映射 `φ_{E→E'}: S_E ⇀ S_{E'}`，动作经 `φ_a` 诱导。要求对每个注册动作 `a`：
`φ(Pre_a) ⊆ Pre_{φ(a)}` 且 `φ(Post_a) ⊆ Post_{φ(a)}`，并保持安全不变量 `Inv`：`φ(Inv_E) ⊆ Inv_{E'}`。满足则称 `E'` 模拟 `E`（φ 为模拟关系）。`ρ_cov = P_{s∼D_E}[s ∈ dom φ]` 为可迁移覆盖。

**定义 450（本体索引能力闭包 CC(E)）** `CC(E): tools(ι) ⊆ T₀(E) ∧ mag(ι) ⊆ M_phys(E) ∧ referents(ι) ⊆ Obs(E)`。跨本体指令 `ι' = φ(ι)` 必须重新做 CC(E') 检查；**禁止**把 `ι` 直接执行在 `E'` 上。任一失败 ⇒ ⊥（回退默认目标或逐本体重接地）。

**定义 451（孪生保真证书 FidelityCert）** `F = (E_val, G_sim, n_anchor, δ_conf, t_exp, metric_family)`，其中在包线 `E_val` 上以置信度 `1−δ_conf` 有 `sup_x |m_sim(x) − m_real(x)| ≤ G_sim`，`n_anchor` 为真实锚点回执数。`F` 过期、`n_anchor < n_min` 或状态 `∉ E_val` ⇒ **F 无效**。

**定义 452（非对称孪生权威 TwinGate）**
`TwinGate(C,σ) = veto` 若以下任一成立：`shadow(C,σ)` 违反安全盾/`ψ_post^C`、`σ ∉ E_val`、`F` 无效、`d(C) > G_sim`、影子出现穿透/力/热超界；否则 `pass`。
**权威公理 ATA**：`pass` **不蕴含** authorize；真实执行必须另行通过 CVC 与真实回执。故带门执行集 `A_exec^{gate} ⊆ A_exec^{nogate}`。

**定义 453（影子执行与散度）** 在 Isaac Sim（固定资产哈希、固定种子、隔离进程）中执行 `shadow(C,σ)`，逐步比较预测状态与孪生状态：
`d(C) = max_{t≤K} max( d_pose, d_force, d_thermal, penetration_depth )`，各项按定义 448 的单位规范归一。散度超 `G_sim` 视为“模型不适用”，触发 veto。

**定义 454（孪生锚定校准 TA-Cal）** 每个真实锚点邻域估计密度比 `w(x)=p_real(x)/p_sim(x)`。在包线内对加权分数取共形分位 `q_sim`；若有效权重退化（ESS 低于阈值）或包线覆盖不足，**弃权**并回退纯真实 SC-Cal。覆盖界见引理 60。

**定义 455（并行合成探针与有效样本量）** 并行 `N` 个环境产生样本，但失败事件相关性 `ρ̄` 使独立信息量下降：`N_eff = N / (1 + (N−1) ρ̄)`。仅 `N_eff ≥ n_min` 才允许进入校准；否则加锚点或回退。

**定义 456（可移植性证书 PortCert）** `PortCert(E→E') = (φ, ρ_cov, G_sim^φ, checks, t_exp)`，`checks` 包含注册测试集上的前后置保持、单位/帧一致、`Inv` 保持与安全序 `≻_safe` 保持。`ρ_cov < ρ_min`、任一 check 失败或过期 ⇒ 不可移植。

**定义 457（平台静默点 q_platform）** 全族无在途块、无待处理不可逆动作、无在途影子执行、无未提交契约迁移。共享契约/孪生资产的热替换**只允许**发生在 `q_platform`；否则 drain 或按 `abort` 截断补偿。

**定义 458（孪生门控净效用）** 单次门控的期望净效用
`U_gate = p_fail·c_f − c_sim − p_veto·c_veto`，其中 `p_fail` 为无门时失败概率、`c_f` 失败代价、`c_sim` 影子执行开销、`p_veto` 误否决率、`c_veto` 重规划成本。仅当 `U_gate > 0` 且 `c_sim ≤ budget_slack` 时准入。

**定义 459（严格降级映射 Deg_Omni）** `Deg_Omni` 按序检查：`F` 有效且 `σ∈E_val` 且 `PortCert` 有效 → OmniGauge；`F` 无效/出包线 → InstructGauge（无门）；`PortCert` 无效 → **逐本体** InstructGauge；若 `TwinGate` 连续 veto 超 `v_max` → 关闭门并告警，落回 InstructGauge；后续沿原退化链。

```python
# IP-330 TwinGate：否决-only 影子门（pass ≠ authorize）
class TwinGate:
    def check(self, C, sigma, fidelity, port):
        if not fidelity.valid(sigma):                 # 过期 / 出包线 / 锚点不足
            return "veto"
        if port is not None and not port.valid():
            return "veto"                             # 跨本体但无有效证书
        sh = self.sim.shadow(C, sigma)                # 固定资产哈希 + 固定种子 + 隔离
        if violates_shield(sh) or violates_post(sh, C.psi_post):
            return "veto"
        if sh.divergence > fidelity.G_sim:
            return "veto"                             # 模型不适用，保守否决
        return "pass"                                 # 仅“不反对”，不授权

# IP-332 TA-Cal：合成样本重加权 + 真实锚点校正
class TACal:
    def threshold(self, iota, sim_samples, anchors, fidelity, cal):
        if not fidelity.valid_envelope() or ess(sim_samples, anchors) < ESS_MIN:
            return self.sc_cal.threshold(iota, cal)   # 弃权：纯真实校准

        n_eff = effective_n(sim_samples, rho_hat(sim_samples))

            return self.sc_cal.threshold(iota, cal)
        return weighted_conformal_quantile(sim_samples, w, alpha=ALPHA)

    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s)
            submit_async(omnigauge_8c, M, s, ell, E)
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 4. 推导

**引理 59（否决单调安全性）** 在权威公理 ATA 下，对任意（甚至对手控制的）孪生器：`A_exec^{gate} ⊆ A_exec^{nogate}`。因此加入 TwinGate 不会提高任何真实执行不安全动作的概率；最坏后果是误否决导致的活性/效用损失。
*证明*：`TwinGate` 只输出 `veto` 或 `pass`，且 `pass` 不是授权事件；真实执行仍要求 CVC 与回执同时通过。故门是对执行集的**过滤**，过滤不增集。与仿真正确性无关。

**引理 60（保真包线迁移界）** 设评分函数 `L`-Lipschitz、包线 `E_val` 内逐点度量误差 `≤ G_sim`，则 TA-Cal 的覆盖满足
`P(h*∈H) ≥ 1−α − L·G_sim`（包线内）；包线外**无保证**，必须弃权。
*证明*：误差有界 ⇒ 分数扰动有界 ⇒ 分位扰动 `≤ L·G_sim`；共形覆盖在扰动分数下按此松弛。包线外证书无效，故必须弃权而非外推。

**引理 61（可移植性可靠性）** 若 `φ_{E→E'}` 是保持 `Pre/Post/Inv/≻_safe` 的模拟关系且 `ρ_cov = 1`，则在 `E` 上验证通过的契约在 `E'` 上保持同一不变量；若不存在这样的 φ，则存在反例使迁移失败。
*证明*：对动作序列归纳，用模拟关系的定义逐步搬运前后置与不变量。反向：构造两本体中同名动作的单位/帧/限幅不同，使 `Post` 在 `E'` 不成立。

**引理 62（并行有效样本量与偏差）** 并行 `N` 环境的估计方差按 `1/N_eff` 收缩，但偏差不被并行度消除：
`|coverage − (1−α)| ≤ L·G_sim + O(1/√N_eff)`。相同资产/种子会抬高 `ρ̄`、压低 `N_eff`，制造**虚假统计自信**。
*证明*：相关样本的 Fisher 信息按 `N_eff` 计；合成偏差项由引理 60 给出，且与 `N` 无关。

**引理 63（门控净效用与活性界）** `U_gate = p_fail c_f − c_sim − p_veto c_veto`，关于 `p_fail,c_f` 递增、关于 `c_sim,c_veto,p_veto` 递减；误否决导致的期望重试次数 `≤ 1/(1−p_veto)`（`p_veto<1`）。故门只在 `U_gate>0` 且预算允许时启用。
*证明*：一阶比较静态；重试次数为几何分布期望。

**引理 64（严格退化等价）** 若 `F` 无效或 `σ∉E_val`，`Deg_Omni` 逐指令等于 InstructGauge；若 `PortCert` 无效，则对每个本体分别等于该本体上的 InstructGauge；其余沿既有链。语言、平台、仿真均为增强项。
*证明*：逐分支对照 `omnigauge_8c` 与 `instructgauge_7c`，被跳过的仅为双门检查与合成样本项，剩余调用序列完全一致。

**引理 65（信任边界下的对抗鲁棒性）** 在固定资产哈希、固定种子、进程隔离的孪生信任边界内，对手控制仿真只能产生 `veto`（可用性攻击），不能产生授权；安全性与无门情形相同，异常可通过 veto 率检测。
*证明*：由 ATA 与引理 59；`veto` 只减执行集。监测 `p_veto` 偏离先验即触发降级。

## 8. 本轮最大风险

**一句话**：`TwinGate` 的否决权虽然由引理 59 保证“不会越权”，但 `TA-Cal` 的有效性完全押在**保真证书是否诚实**上——一旦包线划得过宽、锚点过少、或并行样本的相关性被低估，孪生就会以极高置信度给出**偏乐观的覆盖**，而系统表面比 InstructGauge 更可信；真正的残余风险是“高保真孪生的认识论权威被高估”，必须靠 E459/E462/E463/E464/E466 主动证伪。
