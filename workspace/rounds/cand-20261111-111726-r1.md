# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；新灵感循环第 1 轮；本轮灵感：「场景驱动创新」×「大语言模型」）

> 第 54 轮把技能组合推进到动作空间剖面 + 云边闭环 + 动作-鲁棒性联合证书 `J`。本轮换一个“需求侧”视角：**创新不应由内部指标驱动，而应由真实场景分布驱动；LLM 不应被当作场景真值，而应被降格为场景提议器/编译器**。核心矛盾：H22：真实长尾场景难以枚举，LLM 能批量生成语义合理的场景，但其分布 `q` 服从叙事先验而非物理/统计先验，容易把研发预算导向“听起来危险但很少发生”的场景；H23：LLM 能加速“已知-未知”的重组，却不能可靠触达“未知-未知”，若把生成量当作覆盖度，就会制造 **覆盖幻觉（coverage illusion）**。

## 0. 直觉与动机

**灵感 1（场景是第一性输入，证书是场景的函数）**
直觉：第 53/54 轮的 `ρ`、`J` 都隐含“无条件适用”，但任何证书都有作用域。场景驱动创新的第一步不是“造新技能”，而是把证书从 `C` 改写为 `C|scope`：先诚实标定它在哪里成立，再在其外缘寻找高价值盲区。证书因此从“名词”变成“带定义域的谓词”。

**灵感 2（LLM = 场景编译器，不是场景真值）**
直觉：用户说“在拥挤走廊里把药递给坐轮椅的人”，LLM 应把它编译为可执行的 **场景中间表示 SIR**：实体、可供性、时序目标、扰动、动作绑定、成功判据。但 LLM 输出只是草稿，必须通过类型检查、可供性检查、仿真 dry-run 才能入场景库。**LLM 提议，仿真裁决（LLM proposes, simulator disposes）**。

**灵感 3（盲区挖掘，而非随机生成）**
直觉：不要问 LLM“再造 100 个场景”，而要问“已有证书作用域之外，哪些场景既可能发生、又会让系统失败或拒动？”这是 coverage-guided fuzzing 的语义版：**失败（fail）与拒动（abstain）都是盲区信号**，且拒动比失败更隐蔽，因为它披着“安全”的外衣。

**灵感 4（创新价值 = 概率 × 严重度 × 可修复性 / 成本）**
直觉：LLM 天然偏爱戏剧性场景。必须用锚定真实日志的 `p̂` 重新加权，并对语义冗余做 submodular 惩罚；否则会得到“故事很精彩、分布很边缘、修起来还很贵”的创新组合。创新价值的单位应是“每单位验证预算降低的期望失效”，而不是“场景数量”。

**灵感 5（三种补丁，而不是只会加技能）**
直觉：发现盲区后有三种诚实响应：(i) **能力补丁**——新增技能/改参数；(ii) **作用域补丁**——承认做不到，收缩 `scope`，fail-closed；(iii) **表示补丁**——修 SIR/本体/传感器模型。把“加技能”当唯一响应，是场景驱动循环里最隐蔽的过拟合。

**灵感 6（金字塔再叠一层：场景层 Σ）**
直觉：在动作-协同层 `𝔸` 之外叠 **场景层 `Σ`**：`Σ_0` 物理可执行域，`Σ_1` SIR 语义层，`Σ_2` 场景-证书作用域，`Σ_3` 创新投资组合。跨层证书必须携带 `scope` 与 `negative_set`，形成 **场景-动作-鲁棒性三域证书**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（场景、场景空间与双分布）**
场景 `ω = (E, G, φ_T, x_0, Θ, O, Φ, B)`：环境、目标、时序任务约束（STL/LTL）、初态、扰动分布、观测模型、成功判据与预算；`Ω` 为场景空间。真实部署分布 `p` 不可直接观测，由现场日志构造锚定分布 `p̂`；LLM 的提议分布记为 `q`。**核心约定：`q` 只用于搜索，`p̂` 才用于加权，`p` 才有资格谈保证。**

**定义 122（场景中间表示 SIR 与可执行性）**
`SIR(ω) = (V, E, τ, attr, β, φ_T, Θ, Φ, prov)`：带类型场景图、动作绑定 `β : V_action → A_c × A_e`（与第 54 轮动作空间对接）、时序目标、扰动与观测模型、成功判据、来源标注。可执行性 `Exec(ω) ⇔ ∃` 一条仿真 rollout 同时满足 `φ_T` 与物理约束。SIR 类型系统要求：每个可供性引用都有本体依据，每个动作绑定都落在 `A_c × A_e` 的可达域内。

**定义 123（场景落地证书 SGC 与证据阶梯）**
落地证书 `g(ω) = min(f_phys, f_fid, f_plaus, f_rep)`，四项分别为：物理可行性、仿真实真度、锚定分布下的似然、对锚定分布的覆盖贡献。证据阶梯 `T(ω) ∈ {T0 想象, T1 类型通过, T2 仿真闭环, T3 边端回放}`。`g(ω) ≥ γ ∧ T(ω) ≥ T1` 才允许进入场景库；只有 `T ≥ T2` 才允许用于签发作用域证书。

**定义 124（证书作用域、负能力集与盲区）**
`scope(C) ⊆ Ω` 为证书 `C` 的保证成立域；`N(C) ⊆ Ω` 为显式记录的已知失败/拒动场景（**负能力集**，是证书的一部分而非附录）。盲区：
```
B(C, p̂) = { ω ∈ supp(p̂) : (ω ∉ scope(C) ∨ ω ∈ N(C)) ∧ system(ω) ∈ {fail, abstain} }
```
**表观覆盖** `cov_app` 用场景库数量/密度度量；**验证覆盖** `cov_val = p̂(scope(C))`；**覆盖幻觉系数** `κ_ill = cov_app / cov_val`。健康状态要求 `κ_ill ≤ κ_max`。

**定义 125（创新价值与场景组合选择）**
```
IV(ω) = p̂(ω) · sev(ω) · fix(ω) / ( cost(ω) + λ · redundancy(𝒫 ∪ {ω}) )
```
其中 `sev` 为失效严重度，`fix` 为由技能检索 + 仿真估计的可修复性，`redundancy` 为与已选组合的语义/特征冗余。组合选择是带预算与多样性约束的单调 submodular 最大化：
```
𝒫* = argmax_{|𝒫|≤k, cost(𝒫)≤B} Σ_{ω∈𝒫} IV(ω)
```

**定义 126（场景作用域证书 SIC 与 fail-closed 部署）**
```
SIC(C) = (scope, N, tier, g_min, ε_scope, audit)
```
部署判定 `d(C, ω) ∈ {ok, abstain, reject}`：
```
d = reject   if ω ∈ N(C)
  = abstain  if ω ∉ scope(C)
  = ok       otherwise
```
`abstain` 必须显式上报并计入 `abstain_budget`，禁止被静默当作“已安全处理”。

## 2. 关键算法 伪代码

### IP-121 SIR（Scenario Intermediate Representation / Compiler）

```python
def compile_scenario(nl, llm, ontology, sim, theta_id):
    draft = llm.propose_sir(nl)
    errs = typecheck(draft, ontology) + affordance_check(draft, ontology)
    if errs:
        return ('reject', 'type_or_affordance', errs)
    if not action_binding_reachable(draft.beta, A_c, A_e):
        return ('reject', 'action_unreachable')
    roll = sim.dry_run(draft, budget=draft.B)
    if not roll.realizable:
        return ('reject', 'unrealizable', roll.trace)
    id_score = parameter_identifiability(draft, roll, ontology)
    if id_score < theta_id:
        return ('reject', 'unidentifiable', id_score)
    return ('ok', SIR(draft, prov=nl, tier=T1, id_score=id_score))
```

### IP-122 SGC（Scenario Grounding Certificate）

```python
def grounding_certificate(sir, sim, anchor, gamma):
    f_phys  = sim.feasibility(sir)
    f_fid   = sim.realism_score(sir, anchor)
    f_plaus = density_anchor(sir, anchor)
    f_rep   = coverage_gain(sir, anchor, bank)
    g = min(f_phys, f_fid, f_plaus, f_rep)
    tier = T2 if sim.closed_loop_ok(sir) else T1
    if g < gamma:
        return ('reject', 'ungrounded', g, (f_phys, f_fid, f_plaus, f_rep))
    return ('ok', ScenarioCert(g, tier, prov=sir.prov))
```

### IP-123 SBG（Scenario Blind-spot Gap mining）

```python
def blind_spot_mine(cert_bank, candidates, anchor, budget):
    gaps = []
    for omega in weighted_sample(candidates, p_hat=anchor, budget=budget):
        scope_ok, cert = scope_union(cert_bank, omega)
        if not scope_ok:
            res = run_fail_closed_pipeline(omega)
        else:
            res = run_with_certificate(omega, cert)
        if res.status in ('fail', 'abstain'):
            gaps.append(Gap(omega, res.status, res.explain, severity(res)))
    return semantic_dedup(gaps)
```

### IP-124 SVI（Scenario Value of Innovation）

```python
def innovation_value(gap, anchor, skill_lib, sim, selected, lam, costs):
    p   = density_anchor(gap.omega, anchor)
    sev = gap.severity
    fix = estimate_fixability(gap, skill_lib, sim)
    red = redundancy(gap.omega, selected)
    return p * sev * fix / (costs(gap) + lam * red)

def select_portfolio(gaps, anchor, k, budget, skill_lib, sim):
    return submodular_max(
        gaps, k, budget,
        value=lambda g, S: innovation_value(g, anchor, skill_lib, sim, S, LAM, COST))
```

### IP-125 SIL（Scenario-driven Innovation Loop）

```python
def scenario_driven_innovation(goal_nl, cert_bank, bank, llm, sim, anchor, budget):
    while budget > 0:
        batch = llm.propose(goal_nl, seed=bank, diversity=DIVERSITY)
        fresh = []
        for nl in batch:
            st, s = compile_scenario(nl, llm, ONTOLOGY, sim, THETA_ID)
            if st != 'ok':
                continue
            gs, sc = grounding_certificate(s, sim, anchor, GAMMA)
            if gs == 'ok':
                fresh.append(sc)
        gaps = blind_spot_mine(cert_bank, fresh, anchor, SCAN_BUDGET)
        port = select_portfolio(gaps, anchor, K, B, SKILL_LIB, sim)
        for gap in port:
            patch = propose_patch(gap, SKILL_LIB, llm)
            if validate_patch(patch, sim, anchor):
                cert_bank.add(patch.cert)
            else:
                cert_bank.shrink_scope(gap)
        bank.update(fresh)
        budget -= 1
    return cert_bank, audit(cert_bank, anchor)
```

### IP-126 SIC（Scenario-scoped Innovation Certificate）

```python
def issue_scoped_cert(cert, scope, negative_set, tier, g_min, eps_scope, audit):
    if tier < T2 or g_min < GAMMA:
        return ('reject', 'evidence_insufficient')
    if coverage_on_anchor(scope, negative_set, ANCHOR) < 1 - eps_scope:
        return ('reject', 'scope_not_covered')
    return ('ok', SIC(cert, scope, negative_set, tier, g_min, eps_scope, audit))

def deploy_check(sic, omega):
    if belongs(omega, sic.N):
        return 'reject'
    if not sic.scope(omega):
        return 'abstain'
    return 'ok'
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SIR 编译 | O(\|V\|+\|E\|+C_sim) | O(\|SIR\|) | 类型/可供性 sound、动作绑定可达 |
| SGC | O(\|SIR\|+N_anchor) | O(N_anchor) | 四项校准、`min` 保守聚合 |
| SBG | O(\|Ω_cand\|·(\|C\|+\|π\|)) | O(\|gaps\|) | scope 谓词可判定、abstain 计入 |
| SVI | O(\|gaps\|·k·fix) | O(\|gaps\|) | IV 单调 submodular、冗余扣除 |
| SIL | O(iter·(compile+SBG+patch)) | O(bank+cert) | fail-closed、补丁必须验证 |
| SIC | O(\|scope\|) 每次判定 | O(1) | 负能力集 sound、abstain 上报 |

**正确性定理（Scenario-Scoped Soundness, L5）**
承接第 54 轮 (A26)–(A28)，再设：**(A29)** 落地证书 sound：`g ≥ γ ∧ T ≥ T2 ⇒` 仿真-现实失效差 `≤ β_sim`；**(A30)** 负能力集 sound：真实失败场景被错误排除的概率 `≤ β_N`；**(A31)** 锚定集中：`TV(p, p̂) ≤ δ_anc`；**(A32)** `scope(·)` 在 SIR 上可判定。
则对任意经 `deploy_check` 返回 `ok` 的 `ω`：
```
P_fail(ω) ≤ ε_scope + β_sim + β_N + δ_anc
```
**关键推论（提议-保证分离）**：LLM 提议分布 `q` **不出现在该上界中**，只影响发现效率与创新收益。也就是说，LLM 幻觉不会直接破坏安全性，最坏只会浪费验证预算或产生 `abstain`。这是“LLM proposes, simulator disposes”的形式化。

**覆盖债命题**：设 `Δcov_UU(q)` 为仅靠 LLM 提议能获得的未知-未知覆盖增量，则 `Δcov_UU(q) ≤ η(q, ontology)`，且 `δ_UU` 不能仅由 `q` 消除。必须引入 **现场日志、结构化外推、对抗搜索** 三个独立信道；否则 `cov_app` 上涨而 `cov_val` 不涨，`κ_ill` 单调恶化——这就是覆盖幻觉。故本方案把 LLM 定位为“已知-未知的加速器”，而不是“未知-未知的替代品”。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| LLM 叙事先验导致模式坍缩 | 高 | 现场日志锚定 + 多样性约束 + 语义去重 |
| 语义-物理落地失败（幻觉场景） | 高 | SIR 类型系统 + 仿真 dry-run + SGC + 独立 oracle |
| 覆盖幻觉（场景多≠覆盖真） | 高 | 分离 `cov_app/cov_val`、留出真实日志审计、`κ_ill` 监控 |
| fail-closed 导致 abstain 泛滥 | 高 | abstain 预算 + 分级降级 + 人工分诊 |
| LLM 自评自证 | 中 | 禁止同源评分，仲裁用仿真器/独立模型/人工 |
| 场景库与验证成本爆炸 | 中 | 等价类归并 + submodular 组合 + 增量验证 |
| 未知-未知覆盖债 | 高 | 三独立信道：现场日志 / 结构化外推 / 对抗搜索 |

## 6. 本轮最大风险

**一句话**：本方案把 LLM 严格降格为“提议器”、把保证交给“作用域证书 + 落地证书 + 负能力集”，因此 LLM 幻觉主要通过预算浪费与 abstain 显现，而**不直接破坏安全性**；但真正致命的是 **覆盖幻觉与拒动常态化**——LLM 的叙事先验会让场景库在语义上迅速繁荣、却在真实分布上反复探索同一小簇，同时 fail-closed 的作用域收缩会把大量真实长尾转成“看起来安全”的 abstain，一旦团队把 abstain 当作已处理，系统就会在真实部署中系统性拒动或漏检，故必须以 **锚定日志重加权 + 独立覆盖审计 + abstain 预算** 三重护栏，宁可承认覆盖债，也不把“场景很多”误当作“已经覆盖”。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim+++Σ（SIR×SGC×SBG×SVI×SIL×SIC）

> 承接第 54 轮产物 v31。本轮把“场景”从实验设置的配角提升为创新的第一性输入，新增 **场景层 Σ**：
> - **SIR（Scenario Intermediate Representation）**：自然语言 → 带类型、可执行的场景中间表示；
> - **SGC（Scenario Grounding Certificate）**：场景落地证书 + 证据阶梯，阻断 LLM 幻觉场景；
> - **SBG（Scenario Blind-spot Gap mining）**：以证书作用域为边界的盲区挖掘，fail/abstain 双信号；
> - **SVI（Scenario Value of Innovation）**：锚定真实分布 × 严重度 × 可修复性 / 成本；
> - **SIL（Scenario-driven Innovation Loop）**：提议-编译-落地-挖盲区-选组合-打补丁-发证书闭环；
> - **SIC（Scenario-scoped Innovation Certificate）**：带 `scope` 与负能力集的 fail-closed 作用域证书。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/118/120，使动作、联合证书、迁移证书全部携带场景作用域。

| `scope(C)` | 证书 `C` 的保证成立域 |
| `N(C)` | 负能力集：显式记录的已知失败/拒动场景 |
| `B(C,p̂)` | 场景盲区 |
| `cov_app, cov_val, κ_ill` | 表观覆盖 / 验证覆盖 / 覆盖幻觉系数 |
| `IV(ω)` | 场景创新价值 |
| `SIC(C)` | 场景作用域证书 |
| `d(C,ω)∈{ok,abstain,reject}` | fail-closed 部署判定 |

## 3. 关键算法 伪代码

### IP-121 SIR

```python
def compile_scenario(nl, llm, ontology, sim, theta_id):
    draft = llm.propose_sir(nl)
    errs = typecheck(draft, ontology) + affordance_check(draft, ontology)
    if errs:
        return ('reject', 'type_or_affordance', errs)
    if not action_binding_reachable(draft.beta, A_c, A_e):
        return ('reject', 'action_unreachable')
    roll = sim.dry_run(draft, budget=draft.B)
    if not roll.realizable:
        return ('reject', 'unrealizable', roll.trace)
    id_score = parameter_identifiability(draft, roll, ontology)
    if id_score < theta_id:
        return ('reject', 'unidentifiable', id_score)
    return ('ok', SIR(draft, prov=nl, tier=T1, id_score=id_score))
```

### IP-122 SGC

```python
def grounding_certificate(sir, sim, anchor, gamma):
    f_phys  = sim.feasibility(sir)
    f_fid   = sim.realism_score(sir, anchor)
    f_plaus = density_anchor(sir, anchor)
    f_rep   = coverage_gain(sir, anchor, bank)
    g = min(f_phys, f_fid, f_plaus, f_rep)
    tier = T2 if sim.closed_loop_ok(sir) else T1
    if g < gamma:
        return ('reject', 'ungrounded', g, (f_phys, f_fid, f_plaus, f_rep))
    return ('ok', ScenarioCert(g, tier, prov=sir.prov))
```

### IP-123 SBG

```python
def blind_spot_mine(cert_bank, candidates, anchor, budget):
    gaps = []
    for omega in weighted_sample(candidates, p_hat=anchor, budget=budget):
        scope_ok, cert = scope_union(cert_bank, omega)
        if not scope_ok:
            res = run_fail_closed_pipeline(omega)
        else:
            res = run_with_certificate(omega, cert)
        if res.status in ('fail', 'abstain'):
            gaps.append(Gap(omega, res.status, res.explain, severity(res)))
    return semantic_dedup(gaps)
```

### IP-124 SVI

```python
def innovation_value(gap, anchor, skill_lib, sim, selected, lam, costs):
    p   = density_anchor(gap.omega, anchor)
    sev = gap.severity
    fix = estimate_fixability(gap, skill_lib, sim)
    red = redundancy(gap.omega, selected)
    return p * sev * fix / (costs(gap) + lam * red)

def select_portfolio(gaps, anchor, k, budget, skill_lib, sim):
    return submodular_max(
        gaps, k, budget,
        value=lambda g, S: innovation_value(g, anchor, skill_lib, sim, S, LAM, COST))
```

### IP-125 SIL

```python
def scenario_driven_innovation(goal_nl, cert_bank, bank, llm, sim, anchor, budget):
    while budget > 0:
        batch = llm.propose(goal_nl, seed=bank, diversity=DIVERSITY)
        fresh = []
        for nl in batch:
            st, s = compile_scenario(nl, llm, ONTOLOGY, sim, THETA_ID)
            if st != 'ok':
                continue
            gs, sc = grounding_certificate(s, sim, anchor, GAMMA)
            if gs == 'ok':
                fresh.append(sc)
        gaps = blind_spot_mine(cert_bank, fresh, anchor, SCAN_BUDGET)
        port = select_portfolio(gaps, anchor, K, B, SKILL_LIB, sim)
        for gap in port:
            patch = propose_patch(gap, SKILL_LIB, llm)
            if validate_patch(patch, sim, anchor):
                cert_bank.add(patch.cert)
            else:
                cert_bank.shrink_scope(gap)
        bank.update(fresh)
        budget -= 1
    return cert_bank, audit(cert_bank, anchor)
```

### IP-126 SIC

```python
def issue_scoped_cert(cert, scope, negative_set, tier, g_min, eps_scope, audit):
    if tier < T2 or g_min < GAMMA:
        return ('reject', 'evidence_insufficient')
    if coverage_on_anchor(scope, negative_set, ANCHOR) < 1 - eps_scope:
        return ('reject', 'scope_not_covered')
    return ('ok', SIC(cert, scope, negative_set, tier, g_min, eps_scope, audit))

def deploy_check(sic, omega):
    if belongs(omega, sic.N):
        return 'reject'
    if not sic.scope(omega):
        return 'abstain'
    return 'ok'
```

## 4. 三补丁分类（盲区响应不能只会“加技能”）

| 补丁类型 | 动作 | 影响 | 失败时 |
|---|---|---|---|
| 能力补丁 Capability | 新增技能/调参/扩动作域 | `scope` 扩张 | 回滚，转作用域补丁 |
| 作用域补丁 Scope | 收缩 `scope`，写入 `N(C)` | `cov_val` 下降、`abstain` 上升 | 计入 abstain 预算并人工分诊 |
| 表示补丁 Representation | 修 SIR/本体/传感器/扰动模型 | 提升 `g` 与可判定性 | 标记为覆盖债 `δ_UU` |

## 5. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SIR | O(\|V\|+\|E\|+C_sim) | O(\|SIR\|) | 类型/可供性 sound，动作绑定可达 |
| SGC | O(\|SIR\|+N_anchor) | O(N_anchor) | 四项校准，`min` 保守聚合 |
| SBG | O(\|Ω_cand\|·(\|C\|+\|π\|)) | O(\|gaps\|) | scope 谓词可判定，abstain 计入 |
| SVI | O(\|gaps\|·k·fix) | O(\|gaps\|) | IV 单调 submodular，冗余扣除 |
| SIL | O(iter·(compile+SBG+patch)) | O(bank+cert) | fail-closed，补丁必须验证 |
| SIC | O(\|scope\|) 每次判定 | O(1) | 负能力集 sound，abstain 上报 |

**正确性定理（Scenario-Scoped Soundness, L5）**
承接第 54 轮 (A26)–(A28)，再设：**(A29)** 落地证书 sound；**(A30)** 负能力集 sound；**(A31)** 锚定集中 `TV(p,p̂) ≤ δ_anc`；**(A32)** `scope(·)` 可判定。则对任意 `deploy_check` 返回 `ok` 的 `ω`：
```
P_fail(ω) ≤ ε_scope + β_sim + β_N + δ_anc
```
**提议-保证分离**：`q` 不出现在上界中；LLM 幻觉只花预算，不破坏 soundness。但 `δ_UU`（未知-未知覆盖债）不能由 `q` 消除，需现场日志 / 结构化外推 / 对抗搜索三信道。
```
cov_val 增长 ⇔ scope 扩张且经 T2 验证； cov_app 增长 ⇏ cov_val 增长
κ_ill = cov_app / cov_val ↑  ⇒ 覆盖幻觉
```

## 7. 最小可落地切片（UniBot 两周冲刺）

1. **场景源**：3 类赛题场景（动态人群取放、语音改单、故障恢复）+ 现场日志锚定。
2. **编译**：LLM 产出 SIR 草稿 → 类型/可供性/动作绑定/dry-run 四关；只保留 `g≥γ, T≥T2`。
3. **挖盲区**：对现有证书 `scope` 外场景跑 fail-closed pipeline，记录 fail/abstain。
4. **选组合**：按 `IV` 取 top-k，人工审核叙事显著性偏差。
5. **打补丁**：优先表示补丁与作用域补丁，能力补丁需过 `validate_patch`。
6. **验收**：E162–E167；核心看 `cov_val` 提升、`κ_ill`、abstain 率与误接受率。

## 8. 本轮最大风险

**一句话**：本方案把 LLM 严格降格为“提议器”、把保证交给“作用域证书 + 落地证书 + 负能力集”，因此 LLM 幻觉主要通过预算浪费与 abstain 显现，而**不直接破坏安全性**；但真正致命的是 **覆盖幻觉与拒动常态化**——LLM 的叙事先验会让场景库在语义上迅速繁荣、却在真实分布上反复探索同一小簇，同时 fail-closed 的作用域收缩会把大量真实长尾转成“看起来安全”的 abstain，一旦团队把 abstain 当作已处理，系统就会在真实部署中系统性拒动或漏检，故必须以 **锚定日志重加权 + 独立覆盖审计 + abstain 预算** 三重护栏，宁可承认覆盖债，也不把“场景很多”误当作“已经覆盖”。
