# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 1 轮；本轮灵感：「触觉感知」×「论文创新点」）

> 第 60 轮把「场景语义 SSM × 认知意图 CIEC × ROS 因果隔离 EPIR」统一为 SERC 闭环，但仍有**两个未解的根本问题**：
> 1. **触觉被降维成标量**：SSM 只用 force/position telemetry 的统计特征识别场景，把「滑移、纹理、接触起始/断裂、粘滞」等丰富触觉现象压缩成一个力阈值——导致「湿滑误判为粗糙」这类**触觉语义坍缩**，π_scene 可能收敛到错误场景。
> 2. **创新点停留在叙事层**：第 60 轮列了 8 个 IP，但每个 IP 的「创新性」缺少**可证伪、可归因、可区分于基线**的形式化证书——「论文创新点」若不能被证据链自证，就退化为不可检验的主张。
>
> 本轮引入**触觉语义基元 TSP**把接触信号还原为可组合的「触觉词」，用**触觉-阻抗同构映射 TIK**把词直接编译进阻抗，再用**创新点可证伪证书 NFC**把每个 IP 变成「主张-证据-反例-归因」四元组，形成 **TSP-NFL 触觉-创新自证闭环**。

## 0. 直觉与动机

**灵感 1（触觉感知 → 触觉语义基元 TSP）**
直觉：触觉不是「一个力值」，而是**一门有词法和语法的语言**。手指接触物体时，先后经历「接近→接触→粘滞→（滑移）→脱离」，每种接触现象对应一个**触觉词**：PRESS（压入）、STICK（粘滞）、SLIP（滑移）、TEXTURE（纹理谱）、EDGE（边缘）、BREAK（脱离）。按时间顺序拼成**触觉语句** W = ⟨w₁,…,w_k⟩，「湿滑地面」≈ ⟨PRESS, SLIP, BREAK⟩，「粗糙木桌」≈ ⟨PRESS, TEXTURE(high-freq), STICK⟩。关键洞见：**场景的判别信息在触觉词的组合结构里，而不在力的幅值里**——这直接修正第 60 轮 SSM 的语义坍缩。

**灵感 2（触觉 → 阻抗的同构映射 TIK）**
直觉：触觉词天然携带阻抗语义。SLIP → 切向刚度不足，需提高 K_d 与法向力 F_n；TEXTURE 高频能量 → 表面粗糙度 ρ；EDGE → 接触几何突变，需降低 K_p 防过冲；STICK → 稳定接触，可放松约束。于是场景先验从 π_scene(K|z) 升级为**触觉条件先验** π_scene(K|z,W)，让「摸到什么」直接约束「该用多大阻抗」。关键洞见：**触觉是阻抗编译的实时似然，而不是事后诊断**。

**灵感 3（论文创新点 → 可证伪证书 NFC）**
直觉：一个真正的创新点不是一句「我们提出了 X」，而是四件事：**主张（claim）— 证据（evidence）— 反例（falsifier）— 归因（attribution）**。把每个 IP 写成证书 NFC(c) = (scope, metric, threshold, baseline, falsifier, E_c, A_c)，其中 falsifier 明确「观测到什么就否定 c」。关键洞见：**创新点应是一个可被实验杀死的对象**；不可证伪的主张不计入创新点，可证伪但无归因的主张只能算「现象」而非「贡献」。

**灵感 4（创新距离与冗余检测 ND）**
直觉：创新点的价值取决于它离已有工作有多远、与本文其他 IP 有多不重复。用主张向量 embedding 定义**创新距离** d_novel(c, 𝒞_prior) 与 **IP 间冗余度** ρ(c_i,c_j)。若 d_novel < δ_novel 或 ρ > ρ_max，则标记为「增量式/重复式创新」，进入合并池。关键洞见：**创新点的稀缺性可被度量，而不是靠审稿人直觉**。

**灵感 5（合流 → TSP-NFL 触觉-创新自证闭环）**
直觉：TSP 产生细粒度触觉证据 → TIK 把证据注入阻抗先验 → SERC 执行 → EV-exec 携带触觉语句 → NFC 用这些证据检验每个 IP 的主张 → ND 检测创新冗余 → 反哺下一轮 IP 设计。闭环为：**触觉词→阻抗→执行→证据→创新点自证→新假设→新触觉词**。这把「论文创新点」从写作阶段的修辞，变成研究循环中的**可计算对象**。

**灵感 6（PCE+++++ → 五维预算含触觉预算）**
直觉：第 60 轮四维认知预算 B_scene/B_intent/B_ros/B_exec 需加 **B_tactile**（触觉采样率、频谱分析算力、触觉词表更新频率）。若 B_tactile 耗尽 → 退化为「单点力阈值」的标量触觉（即第 60 轮行为）；若 B_scene 耗尽 → 用触觉语句 W 直接查表映射场景，绕过场景识别器，形成**触觉优先**的降级路径。

## 1. 形式化定义（增量：定义 161–169）

**定义 161（触觉语义基元 TSP）** 触觉基元 p = (type, t_on, t_off, a, S, γ)。其中：
- type ∈ {PRESS, STICK, SLIP, TEXTURE, EDGE, BREAK}
- [t_on, t_off] 为持续时间；a 为强度（法向力 / 切向力 / 振动幅值）
- S 为频谱签名（如 20–500Hz 能量分布，按频带归一化）
- γ ∈ [0,1] 为基元置信度
- 提取器 P: 原始触觉流 τ_{0:T} → {p_i}，要求时间对齐误差 ≤ 1 个采样周期。

**定义 162（触觉词法与语法 TWG）** 触觉词序列 W = ⟨w₁,…,w_k⟩，w_i ∈ TSP。触觉语法 G_tac 由产生式给出：
```
GRASP  → PRESS⁺ · STICK · (SLIP)* · BREAK
SLIDE  → PRESS · TEXTURE · (SLIP)? · BREAK
TAP    → PRESS · BREAK
EDGE_OP→ PRESS · EDGE · (STICK)? · BREAK
```
合法语句集合 L(G_tac) 由有限自动机判定；非法语句（如无 PRESS 直接 STICK）触发「触觉幻觉」告警 H_tac=1，并禁止其进入 TIK。

**定义 163（触觉条件场景先验 TSP-SSM）** 在定义 153 的 Γ 上引入触觉似然：
```
π_scene(K|z,W) ∝ π_scene(K|z) · Λ_tac(W|K,z)
Λ_tac(W|K,z) = exp( −λ_type·Σ_i 1[type_i ∉ Allowed(z)]
                    −λ_slip·1[SLIP∈W ∧ K_d < K_d^min(z)]
                    −λ_tex ·D_KL(S_texture ‖ S_ref(z)) )
```
场景后验：P(z|W) ∝ P(z)·P(W|z)，其中 P(W|z) 由语法合法度 × 基元似然给出。**关键性质**：即使场景识别器置信度不足，只要 W 合法且判别性强，后验仍可被触觉证据重新锐化。

**定义 164（接触状态机 CSM）** CSM = (Q, Σ, δ, q₀, Q_f)，Q = {APPROACH, CONTACT, STICK, SLIP, BREAK, LOST}，Σ 为触觉基元事件。关键转移：
- CONTACT --SLIP--> SLIP；SLIP --(K_d↑, F_n↑)--> STICK
- 任意态 --BREAK--> BREAK；超时未接触 → LOST
- SLIP 持续 > τ_slip（默认 30ms）触发「滑移风险」事件，直接写回 ERTC 约束域。

**定义 165（触觉-阻抗同构映射 TIK）** 映射 ψ: TSP → ΔK：
```
ψ(SLIP)        = (+ΔK_d, +ΔF_n, −Δv_max)
ψ(TEXTURE, S)  = (Δρ = f(S), +ΔK_d)
ψ(EDGE)        = (−ΔK_p, +ΔK_d)
ψ(STICK)       = (0, 0, +Δv_max)
ψ(BREAK)       = (保持, 触发重接触策略)
```
触觉条件安全域：K_safe^tac = K_safe^scene ∩ {K | K 满足 ψ(W) 的全部约束}。滑移判据推导：宏观滑移当 f_t ≥ μ_s·f_n；触觉振动能量 E_vib ∝ (f_t − μ_s f_n)²，故
```
s_slip = α·(f_t/f_n − μ̂_s)⁺ + β·E_vib^(20–200Hz)
SLIP 判定：s_slip > τ_slip，μ̂_s 由 TEXTURE 与材料先验估计
```

**定义 166（创新点可证伪证书 NFC）** 对每个创新主张 c：
```
NFC(c) = (scope_c, metric_c, θ_c, baseline_c, falsifier_c, E_c, A_c)
```
- scope_c：适用域（如「湿滑场景」）；metric_c/θ_c：可测指标与阈值；baseline_c：对照方法
- falsifier_c：使 c 为假的可观测条件（如「E192 中 TSP 基元 F1 < 0.85」）
- E_c：支持/反驳证据链（实验、EV-exec、统计检验）
- A_c：归因图（消融实验证明增益来自该组件而非混杂因素）
- **可证伪性** F(c)=1 当且仅当 falsifier_c 可被有限实验观测；F(c)=0 的主张不计入创新点清单。

**定义 167（创新距离与冗余度 ND）** 主张向量 e_c = Embed(scope, mechanism, metric)。
```
d_novel(c) = min_{c'∈𝒞_prior} ‖e_c − e_{c'}‖₂
ρ(c_i,c_j) = cos(e_{c_i}, e_{c_j})
```
合格创新点判定：
```
Eligible(c) ⇔ F(c)=1 ∧ A_c≠∅ ∧ d_novel(c) ≥ δ_novel ∧ ∀j≠i ρ(c_i,c_j) ≤ ρ_max
```
否则标记为「增量/重复」，进入合并池（不得单独列为创新点）。

**定义 168（TSP-NFL 闭环算子）** TSP-NFL(M, z, intent, δ_f_req)：
```
① TSP:   {p_i} ← P(τ_tactile[0:T])
② TWG:   W ← parse(G_tac, {p_i})；若 W∉L(G_tac) → 触觉幻觉告警，跳过 ④
③ TSP-SSM: P(z|W) ← normalize(P(z)·P(W|z))
④ TIK:   K_safe^tac ← EEIS.compile_with_tactile_prior(π_scene(K|z,W), ψ(W), δ_f_req)
⑤ CIEC:  C_intent ← ϕ(intent)；ERTC.lock(C_intent ∪ ψ(W))
⑥ SERC:  执行 → EV-exec(tactile=W)
⑦ EPIR:  append(EV-exec)；因果同步
⑧ NFC:   对每个活跃 IP c: E_c ← E_c ∪ {EV-exec}；更新 F(c), A_c
⑨ ND:    重算 d_novel(c), ρ(c_i,c_j)；标记增量/重复
⑩ Return: (z, K_safe^tac, W, {NFC(c)}, ND)
```

**定义 169（PCE+++++ 五维预算）** B_all = (B_tactile, B_scene, B_intent, B_ros, B_exec)，其中
```
B_tactile = (Sampling_rate, Spectrum_ops, Lexicon_update_rate)
```
VOI 扩展：`voi_cog(π) = VOI_meta_pessimistic(π) − cost_cog(π) − cost_tac(π) − cost_exec(π)`。降级优先级：B_tactile 耗尽 → 标量触觉（第 60 轮行为）；B_scene 耗尽 → 触觉语句直查场景表；B_intent 耗尽 → 默认约束；B_ros 异常 → 本地闭环；B_exec 耗尽 → 原有降级。

### IP-161 TSP 提取器

```python
class TactilePrimitiveExtractor:
    def __init__(self, fs=1000, eps_contact=0.5, eps_break=0.1,
                 tau_slip=0.6, tau_tex=0.3):
        self.fs, self.eps_contact, self.eps_break = fs, eps_contact, eps_break
        self.tau_slip, self.tau_tex = tau_slip, tau_tex
        self.buf = deque(maxlen=fs)       # 1s 窗口
        self.state = 'APPROACH'
        self.prims = []

    def push(self, f_n, f_t, vib):
        self.buf.append((f_n, f_t, vib))
        if self.state == 'APPROACH' and f_n > self.eps_contact:
            self._emit('PRESS', a=f_n); self.state = 'CONTACT'
        elif self.state == 'CONTACT' and f_t / max(f_n, 1e-6) > 0.3:
            self._emit('STICK'); self.state = 'STICK'
        elif self.state == 'STICK':
            s = self._slip_score(f_t, f_n, vib)
            if s > self.tau_slip:
                self._emit('SLIP', a=s); self.state = 'SLIP'
        if self._texture_energy(vib) > self.tau_tex:
            self._emit('TEXTURE', S=self._spectrum(vib))
        if self.state != 'BREAK' and f_n < self.eps_break:
            self._emit('BREAK'); self.state = 'BREAK'
        return self.prims[-1] if self.prims else None

    def _slip_score(self, f_t, f_n, vib):
        mu_hat = self._estimate_friction()          # 由 TEXTURE/材料先验
        ratio_term = max(0.0, f_t / max(f_n, 1e-6) - mu_hat)
        return 0.7 * ratio_term + 0.3 * self._band_energy(vib, 20, 200)

    def _spectrum(self, vib):
        x = np.asarray([v for (_, _, v) in self.buf])
        return np.abs(np.fft.rfft(x))[:256]
```

### IP-162 TWG 解析器（有限自动机）

```python
class TactileGrammar:
    TRANSITIONS = {
        'START':   {'PRESS': 'AFTER_PRESS'},
        'AFTER_PRESS': {'STICK': 'GRASP_OK', 'TEXTURE': 'SLIDE_OK',
                        'EDGE': 'EDGE_OK', 'SLIP': 'SLIP_EARLY'},
        'GRASP_OK': {'SLIP': 'GRASP_OK', 'BREAK': 'ACCEPT'},
        'SLIDE_OK': {'SLIP': 'SLIDE_OK', 'BREAK': 'ACCEPT'},
        'EDGE_OK':  {'STICK': 'EDGE_OK', 'BREAK': 'ACCEPT'},
        'SLIP_EARLY': {'BREAK': 'ACCEPT'},
    }

    def parse(self, prims):
        state, words = 'START', []
        for p in prims:
            nxt = self.TRANSITIONS.get(state, {}).get(p.type)
            if nxt is None:
                return None, True          # 非法语句 → 触觉幻觉
            state = nxt
            words.append(p)
        return words, state != 'ACCEPT'   # 未以 BREAK 收尾也算可疑
```

### IP-164 CSM（接触状态机）

```python
class ContactStateMachine:
    def __init__(self, tau_slip=0.03):
        self.state, self.slip_since, self.tau_slip = 'APPROACH', None, tau_slip

    def on_primitive(self, p, now):
        if p.type == 'SLIP':
            self.slip_since = self.slip_since or now
            self.state = 'SLIP'
        elif p.type == 'STICK':
            self.slip_since, self.state = None, 'STICK'
        elif p.type == 'BREAK':
            self.slip_since, self.state = None, 'BREAK'
        if self.state == 'SLIP' and now - self.slip_since > self.tau_slip:
            return 'SLIP_RISK'               # 写回 ERTC 约束域
        return self.state
```

```python
TIK_TABLE = {
    'SLIP':    {'dKd': +0.5, 'dFn': +0.3, 'dvmax': -0.5},
```

### IP-166 NFC（可证伪证书）

```python
@dataclass
class NFC:
    id: str
    scope: str
    metric: str
    threshold: float
    baseline: str
    falsifier: str
    evidence: list
    attribution: dict

    def falsifiable(self):
        return bool(self.falsifier) and self.threshold is not None

    def falsified(self):
        return any(e[self.metric] < self.threshold for e in self.evidence)

    def supported(self):
        if not self.evidence:
            return False
        m = aggregate(self.evidence, self.metric)
        return (m >= self.threshold
                and self.attribution.get('ablation_gain', 0) > 0
                and self.attribution.get('p_value', 1.0) < 0.05)

    def verdict(self):
        if not self.falsifiable(): return 'UNFALSIFIABLE'
        if self.falsified():       return 'FALSIFIED'
        return 'SUPPORTED' if self.supported() else 'PENDING'
```

### IP-167 ND（创新距离与冗余）

```python
def novelty_report(claims, prior_claims, delta=0.35, rho_max=0.85):
    out = []
    for c in claims:
        d = min((np.linalg.norm(c.emb - p.emb) for p in prior_claims),
                default=float('inf'))
        rho = max((cosine(c.emb, o.emb) for o in claims if o.id != c.id),
                  default=0.0)
        out.append({
            'id': c.id,
            'd_novel': d,
            'max_rho': rho,
            'eligible': (c.nfc.falsifiable() and d >= delta and rho <= rho_max),
        })
    return out
```

```python
def tsp_novelty_falsifiability_loop(M, z, intent, delta_f_req):
    prims = M.tsp.push(M.telem_f_n, M.telem_f_t, M.telem_vib)

        c.nfc.evidence.append(EV_exec.as_metrics())
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TSP | O(fs) / 窗口；频谱 O(fs log fs) | O(fs) | 基元 F1 ≥ 0.92，时间对齐 ≤ 1 采样 |
| TWG | O(k) 解析 | O(k) | 非法语句检出率 100%（有限自动机） |
| TSP-SSM | O(N·|W|) / 更新 | O(N) | 湿滑/粗糙判别准确率 ≥ 90% |
| CSM | O(1) / 事件 | O(1) | 滑移风险检测延迟 ≤ 50ms |
| TIK | O(|W|) | O(1) | 阻抗修正方向正确率 ≥ 95% |
| NFC | O(#evidence) | O(#IP) | 可证伪率 100%，归因 p<0.05 |

## 2. 关键推导

**推导 1（滑移判据）** 宏观滑移条件为切向力超过最大静摩擦：`f_t ≥ μ_s·f_n`。以 μ̂_s 估计 μ_s，定义归一化超限项 `(f_t/f_n − μ̂_s)⁺`；振动能量在 20–200Hz 频带与超限量的平方近似成正比，故
```
s_slip = α·(f_t/f_n − μ̂_s)⁺ + β·E_vib^(20–200Hz),  SLIP ⇔ s_slip > τ_slip
```
该式把「力比」与「频谱」两路证据融合，降低纹理被误判为滑移的概率。

**推导 2（触觉后验锐化）** 设先验 P(z) 在湿滑 z_w 与木桌 z_d 上接近（各 0.5）。湿滑的触觉似然 P(SLIP|z_w)=0.9、P(SLIP|z_d)=0.05，则观测到 SLIP 后
```
P(z_w|SLIP) = 0.5·0.9 / (0.5·0.9 + 0.5·0.05) ≈ 0.947
```
即单次滑移基元即可把判别置信度从 0.5 提升到 ≈0.95，说明触觉词的判别效率高于力幅值特征。

**推导 3（安全域收缩）** 由定义 165，K_safe^tac = K_safe^scene ∩ {K | ψ(W) 约束}，故 `K_safe^tac ⊆ K_safe^scene`。TIK 只可能收缩安全域，不会放大；因此触觉注入不会破坏第 60 轮 EEIS 的安全性证明，只会更保守。

**推导 4（创新点筛选）** 由定义 167，纳入清单需同时满足可证伪、有归因、距离达标、冗余达标。四条件缺一即降级，因此清单规模单调不增、平均创新距离单调不减——创新点集合随轮次收敛而非膨胀。

```python
class TactilePrimitiveExtractor:
    def __init__(self, fs=1000, eps_contact=0.5, eps_break=0.1,
                 tau_slip=0.6, tau_tex=0.3):
        self.fs, self.eps_contact, self.eps_break = fs, eps_contact, eps_break
        self.tau_slip, self.tau_tex = tau_slip, tau_tex
        self.buf = deque(maxlen=fs)
        self.state = 'APPROACH'
        self.prims = []

    def push(self, f_n, f_t, vib):
        self.buf.append((f_n, f_t, vib))
        if self.state == 'APPROACH' and f_n > self.eps_contact:
            self._emit('PRESS', a=f_n); self.state = 'CONTACT'
        elif self.state == 'CONTACT' and f_t / max(f_n, 1e-6) > 0.3:
            self._emit('STICK'); self.state = 'STICK'
        elif self.state == 'STICK':
            s = self._slip_score(f_t, f_n, vib)
            if s > self.tau_slip:
                self._emit('SLIP', a=s); self.state = 'SLIP'
        if self._texture_energy(vib) > self.tau_tex:
            self._emit('TEXTURE', S=self._spectrum(vib))
        if self.state != 'BREAK' and f_n < self.eps_break:
            self._emit('BREAK'); self.state = 'BREAK'
        return self.prims[-1] if self.prims else None

    def _slip_score(self, f_t, f_n, vib):
        mu_hat = self._estimate_friction()
        ratio_term = max(0.0, f_t / max(f_n, 1e-6) - mu_hat)
        return 0.7 * ratio_term + 0.3 * self._band_energy(vib, 20, 200)

    def _spectrum(self, vib):
        x = np.asarray([v for (_, _, v) in self.buf])
        return np.abs(np.fft.rfft(x))[:256]
```

```python
class TactileGrammar:
    TRANSITIONS = {
        'START':   {'PRESS': 'AFTER_PRESS'},
        'AFTER_PRESS': {'STICK': 'GRASP_OK', 'TEXTURE': 'SLIDE_OK',
                        'EDGE': 'EDGE_OK', 'SLIP': 'SLIP_EARLY'},
        'GRASP_OK': {'SLIP': 'GRASP_OK', 'BREAK': 'ACCEPT'},
        'SLIDE_OK': {'SLIP': 'SLIDE_OK', 'BREAK': 'ACCEPT'},
        'EDGE_OK':  {'STICK': 'EDGE_OK', 'BREAK': 'ACCEPT'},
        'SLIP_EARLY': {'BREAK': 'ACCEPT'},
    }

    def parse(self, prims):
        state, words = 'START', []
        for p in prims:
            nxt = self.TRANSITIONS.get(state, {}).get(p.type)
            if nxt is None:
                return None, True
            state = nxt
            words.append(p)
        return words, state != 'ACCEPT'
```

```python
class ContactStateMachine:
    def __init__(self, tau_slip=0.03):
        self.state, self.slip_since, self.tau_slip = 'APPROACH', None, tau_slip

    def on_primitive(self, p, now):
        if p.type == 'SLIP':
            self.slip_since = self.slip_since or now
            self.state = 'SLIP'
        elif p.type == 'STICK':
            self.slip_since, self.state = None, 'STICK'
        elif p.type == 'BREAK':
            self.slip_since, self.state = None, 'BREAK'
        if self.state == 'SLIP' and now - self.slip_since > self.tau_slip:
            return 'SLIP_RISK'
        return self.state
```

```python
@dataclass
class NFC:
    id: str
    scope: str
    metric: str
    threshold: float
    baseline: str
    falsifier: str
    evidence: list
    attribution: dict

    def falsifiable(self):
        return bool(self.falsifier) and self.threshold is not None

    def falsified(self):
        return any(e[self.metric] < self.threshold for e in self.evidence)

    def supported(self):
        if not self.evidence:
            return False
        m = aggregate(self.evidence, self.metric)
        return (m >= self.threshold
                and self.attribution.get('ablation_gain', 0) > 0
                and self.attribution.get('p_value', 1.0) < 0.05)

    def verdict(self):
        if not self.falsifiable(): return 'UNFALSIFIABLE'
        if self.falsified():       return 'FALSIFIED'
        return 'SUPPORTED' if self.supported() else 'PENDING'
```

```python
def novelty_report(claims, prior_claims, delta=0.35, rho_max=0.85):
    out = []
    for c in claims:
        d = min((np.linalg.norm(c.emb - p.emb) for p in prior_claims),
                default=float('inf'))
        rho = max((cosine(c.emb, o.emb) for o in claims if o.id != c.id),
                  default=0.0)
        out.append({
            'id': c.id,
            'd_novel': d,
            'max_rho': rho,
            'eligible': (c.nfc.falsifiable() and d >= delta and rho <= rho_max),
        })
    return out
```
