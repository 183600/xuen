# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「本体感知」×「结构优化」）

> 第 54 轮把技能组合建立在动作空间剖面 `α_S` 与云边联合证书 `J` 上，解决了“动作能否对齐”的可判定性。但证书仍悬浮在**外部任务坐标**里：它知道“动作空间是否覆盖”，却不知道“执行这个动作的身体此刻还是不是那具身体”。本轮引入 **本体感知自模型** 与 **证书结构优化**，把证书从“动作空间证书”推进为“身体接地证书”，并从“手工分层金字塔”推进为“可求解的证书结构图”。核心矛盾：**H22**：本体感知漂移会使外部坐标下成立的证书在执行时失效——自模型残差 `ε_p` 未被纳入证书，证书是“无身体”的；**H23**：证书结构是人工固定的，结构优化目标（降成本、提紧致）与接地约束（可观测、可标定）冲突，无约束优化会诱发**证书博弈**：只保留容易观测的维度，把验证结构优化成“自洽但失真”的空壳。

## 0. 直觉与动机

**灵感 1（本体感知 = 证书的身体坐标系 / grounding map）**
直觉：技能 `S` 的动作剖面 `α_S` 描述“能做什么动作”，但真正执行时，机器人只能通过 `(q, q̇, τ, f_c)` 知道自己“现在是什么姿态、还剩多少力矩余量、负载是否改变”。定义本体感知自模型 `M_p: (q,q̇,τ,f_c) → (B,conf)`，`B` 为身体图式（关节限位、连杆几何、动态参数、接触状态）。用残差 `ε_p = ||M_p(state) - B_measured||` 度量“身体自我认知”与“真实身体”的距离。第 54 轮的联合证书 `J` 必须被抬升为 `J^B=(J,B,ε_p,O,evidence_p)`：**没有本体感知接地的证书，只是关于一个假想身体的证书**。

**灵感 2（本体可观测矩阵 = 哪些证书维度能被“感觉到”）**
直觉：鲁棒性维度 `d`（抗负载、抗关节饱和、抗接触冲击……）并不都能从外感受或演示数据中得到。定义可观测矩阵 `O_{d,p}`：本体信号 `p` 对维度 `d` 的可辨识程度。`Obs(θ_o)={d | max_p O_{d,p} ≥ θ_o}` 是本体能“自证”的维度集合，它给证书划出**可接地域** `G_dom`。可观测维度可在线自证；不可观测维度必须依赖仿真/外部证据，并显式标注证据强度。这把统一格式的证书拆成“自证 / 旁证”两级。

**灵感 3（结构优化 = 证书架构本身成为优化变量，而非手工分层）**
直觉：第 53/54 轮的金字塔 `𝕃`、动作层 `𝔸` 都是人工固定的。把证书体系建模为有向无环超图 `H=(N,E)`：节点是证书/验证算子（各带成本 `c`、紧致度 `t`、脆弱度 `f`），超边是“组合 / 蕴含 / 传递”关系。给定任务所需维度集 `D_T`，求最小代价子结构 `H'⊆H`，使 `H'` 覆盖 `D_T` 且每个被声明维度在本体感知上可接地。这是 Steiner / 子模覆盖型问题，目标 `Cost(H')=Σc + λΣslack + μΣfragility`。**结构优化让证书体系从“设计出来的”变成“求解出来的”**。

**灵感 4（联合优化 = 结构与自模型必须一起标定）**
直觉：结构优化会改变“依赖哪些信号”，而自模型精度又决定“这些信号可不可信”，两者互相塑造。若只优化 `H` 不重标 `M_p`，优化器会漂向“便宜但不可观测”的维度，形成自洽的空证书（证书博弈 / Goodhart）。因此应做交替/双层优化：`H_{k+1}=argmin Cost(H;M_p^k)`，`M_p^{k+1}=calibrate(M_p;H_{k+1})`，并加**接地覆盖下界**与**漂移绊线**约束；收敛判据是接地覆盖率单调不减且结构成本下降停滞。

**灵感 5（结构迁移脆弱性 = 跨本体的结构风险）**
直觉：结构 `H'` 对某些本体信号依赖越深（`depth_H(d)`），该信号在新本体上的漂移越大，迁移越危险。定义 `FT(H')=Σ_d depth_H(d)·ε_p^{tgt}(d)`。跨本体部署时，若 `FT>Θ_F`，即使 `J` 在源本体上全绿也应否决——**结构可迁移性不等于证书可迁移性**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（本体感知自模型）**
`M_p: (q,q̇,τ,f_c) → (B,conf)` 把本体状态映射为身体图式与置信度。残差 `ε_p(s)=||M_p(s)-B_measured(s)||`，有效域 `V_p={s | ε_p(s) ≤ Θ_p}`。`M_p` 只在 `V_p` 上可被证书引用。

**定义 122（本体可观测矩阵）**
`O ∈ [0,1]^{|𝔇_ρ|×|P|}`，`O_{d,p}` 为用本体信号 `p` 辨识鲁棒性维度 `d` 的灵敏度与可辨识度（如 `|∂p/∂d|·SNR` 的归一化）。可观测集 `Obs(θ_o)={d | max_p O_{d,p} ≥ θ_o}`，可接地域 `G_dom=Obs(θ_o)`。

**定义 123（本体接地证书）**
`J^B=(J,B,ε_p,O,evidence_p)`。`grounded(J^B)=1` 当且仅当 `ε_p ≤ Θ_p` 且 `∀d∈supp(J)`，`row_O(d)` 非零。证据分两级：`self_ev`（本体在线自证）与 `cross_ev`（结构化仿真 / 外部测量）。若某维度不可观测，则其证书强度降级为旁证，不得单独用于部署放行。

**定义 124（证书结构超图）**
`H=(N,E)`，节点 `n=(cert_n, c_n, t_n, f_n)`，`c` 为验证成本、`t` 为紧致度、`f` 为结构脆弱度；超边表示组合 / 蕴含 / 传递。覆盖 `cover(H',D_T)=1` 当且仅当 `∀d∈D_T` 在 `H'` 中存在一条以接地节点终止的路径。

**定义 125（结构–自模型联合优化）**
`(H*,M_p*) = argmin_{H⊆H0, M_p} Cost(H;M_p)`
subject to `cover(H,D_T)=1`，`G_dom(H) ⊇ D_T`，`ε_p ≤ Θ_p`。
交替求解：`H_{k+1}=argmin_{H⊆H0} Cost(H;M_p^k)`（带接地下界），`M_p^{k+1}=calibrate(M_p^k;H_{k+1})`（只标定 `H` 实际依赖的信号）。

**定义 126（结构迁移脆弱性）**
`FT(H')=Σ_{d∈D_T} depth_{H'}(d)·ε_p^{tgt}(d)`，其中 `depth` 为从根证书到维度 `d` 的接地依赖深度。跨本体部署条件：`FT(H') ≤ Θ_F` 且 `grounded(J^B)=1`。

## 2. 关键算法 伪代码

### IP-121 PSM（Proprioceptive Self-Model）

```python
def fit_self_model(traj, body_params, theta_p):
    M = init_model(body_params)
    for s in traj:
        pred_B, conf = M(s.q, s.qd, s.tau, s.fc)
        eps = norm(pred_B - s.B_measured)
        M.update(s, eps)
    eps_hat = quantile(M.residuals, 0.95)
    M.valid = (eps_hat <= theta_p)
    return M, eps_hat

def self_model_residual(M, traj, dim=None):
    residuals = [norm(M(s).B - s.B_measured) for s in traj
                 if dim is None or dim in s.loaded_dims]
    return quantile(residuals, 0.95)
```

### IP-122 POM（Proprioceptive Observability Matrix）

```python
def observability_matrix(dims, signals, probe_fn, theta_o=0.6, n=1000):
    O = zeros((len(dims), len(signals)))
    for i, d in enumerate(dims):
        for j, p in enumerate(signals):
            xs = sample_probe(n)
            y = probe_fn(xs, d)          # 注入/扰动维度 d，读本体信号 p
            O[i, j] = identifiability(y) # |SNR|·|∂p/∂d|，裁剪到 [0,1]
    obs = {d for i, d in enumerate(dims) if O[i].max() >= theta_o}
    return O, obs
```

### IP-123 BGC（Body-Grounded Certificate）

```python
def body_ground(J, M_p, O, theta_p, theta_o):
    eps = M_p.residual(J.evidence.state)
    if eps > theta_p:
        return ('reject', 'self_model_drift', eps)
    supp = set(J.rho.keys())
    unobs = {d for d in supp if O[d].max() < theta_o}
    evidence = two_tier_evidence(supp, unobs, J.evidence)
    if not pure_cross_evidence_allowed(unobs):
        return ('reject', 'ungroundable_dims', unobs)
    return ('ok', BodyGroundedCert(J, M_p.schema, eps, O, evidence))
```

### IP-124 SGO（Structural Graph Optimization）

```python
def optimize_structure(H0, D_T, M_p, O, lam, mu, budget, theta_g):
    # Steiner/子模覆盖型问题的贪心近似（1-1/e）
    H = empty_structure()
    while not cover(H, D_T):
        cand = [n for n in H0.nodes if grounded_node(n, M_p, O)]
        if not cand:
            return ('reject', 'no_grounded_cover')
        n = argmax(cand, key=lambda n: marginal_gain(n, H, D_T, lam, mu))
        H.add(n, H0.dependencies(n))
    H = prune(H, budget)                 # 去冗余，保留覆盖与接地
    if grounding_cover(H, M_p) < theta_g:
        return ('reject', 'grounding_below_floor')
    return ('ok', H, structure_cost(H, lam, mu))
```

### IP-125 JSO（Joint Structure–Self-Model Optimization）

```python
def joint_structure_selfmodel(H0, traj, D_T, K=10, tol=1e-3, theta_g=0.9):
    M = fit_self_model(traj, body_params)
    prev = inf
    for k in range(K):
        O = observability_matrix(D_T, signals, probe_fn)
        ok, H, cost = optimize_structure(H0, D_T, M, O, lam, mu, budget, theta_g)
        if ok != 'ok':
            return ('reject', H)
        M = recalibrate(M, traj, H)      # 只标定 H 依赖的信号
        cost = structure_cost(H, lam, mu)
        if abs(prev - cost) < tol and grounding_cover(H, M) >= theta_g:
            break
        prev = cost
    return ('ok', H, M)
```

### IP-126 SFT（Structural Fragility Test）

```python
def transfer_fragility(H, target_traj, M_tgt, Theta_F):
    eps_tgt = {d: self_model_residual(M_tgt, target_traj, d)
               for d in required_dims(H)}
    ft = sum(depth(H, d) * eps_tgt[d] for d in required_dims(H))
    if ft > Theta_F:
        return ('reject', 'structural_transfer_fragility', ft)
    return ('ok', ft)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| PSM | O(T·|P|) | O(|P|) | 残差校准无偏、有效域可判 |
| POM | O(|𝔇_ρ|·|P|·n) | O(|𝔇_ρ|·|P|) | 探针充分、可辨识度不虚高 |
| BGC | O(|𝔇_ρ|+|P|) | O(|𝔇_ρ|+|P|) | 接地判定 sound、证据分级 |
| SGO | O(|N|²·|E|) 贪心 | O(|N|+|E|) | 覆盖下界、接地节点非空 |
| JSO | O(K·(SGO+PSM)) | O(|N|+|P|) | 交替单调、接地下界不退化 |
| SFT | O(|H|·|𝔇_ρ|) | O(|𝔇_ρ|) | 依赖深度与漂移可测 |

**正确性定理（Body-Grounded Structural Certificate Soundness）**
承接第 54 轮 (A26)–(A28)；新增 **(A29)** 部署分布上 `ε_p ≤ Θ_p`；**(A30)** `Obs(θ_o) ⊇ D_T`（所有必需维度本体可接地）；**(A31)** 结构覆盖检查 `cover(H',D_T)` sound 且 `H'` 保留接地下界。则：
```
P_success(J^B | H') ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
                    - P(ε_p>Θ_p) - FT(H')/Θ_F - P(¬cover(H',D_T))
```
关键：**A30 是结构优化不产生“空证书”的前提**；没有接地覆盖下界，优化器会删除难观测维度而提升表面成功率，定理随即失效。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 结构优化诱发证书博弈（只留易观测维度） | 高 | 接地覆盖下界 + 维度分布 KL 约束 + 红队审计 |
| 自模型只在局部有效 / 分布漂移 | 高 | 有效域 `V_p` + 漂移绊线 + 在线重标定 |
| 可观测矩阵误估导致虚假接地 | 高 | 多探针交叉验证 + 留出本体验证 + 置信下界 |
| 结构与自模型联合优化震荡 | 中 | 单调接地覆盖 + 阻尼更新 + 早停 |
| 本体信号噪声/量化/延迟 | 中 | 卡尔曼平滑 + 时间对齐 + 噪声预算入证书 |

## 6. 本轮最大风险

**一句话**：把证书从“动作空间”接地到“本体感知”并用结构优化自动求解验证结构，能同时提升可信度与效率，但结构优化会在接地约束不完备时**系统性删除难观测维度以降低表面成本**，形成自洽却失真的“空证书”，再叠加自模型漂移的静默失效，最终把“身体接地”变成“身体自欺”；因此必须以 **接地覆盖下界 + 漂移绊线 + 跨本体结构脆弱性否决** 三重护栏约束优化器，宁可保留昂贵的可观测证据，也绝不把优化器选出来的“便宜证书”当作部署前提。

```python
        return ('reject', 'ungroundable_dims', unobs)
    return ('ok', BodyGroundedCert(J, M_p.schema, eps, O, evidence))
```

### IP-124 SGO

```python
def optimize_structure(H0, D_T, M_p, O, lam, mu, budget, theta_g):
    # Steiner/子模覆盖型问题的贪心近似（1-1/e）
    H = empty_structure()
    while not cover(H, D_T):
        cand = [n for n in H0.nodes if grounded_node(n, M_p, O)]
        if not cand:
            return ('reject', 'no_grounded_cover')
        n = argmax(cand, key=lambda n: marginal_gain(n, H, D_T, lam, mu))
        H.add(n, H0.dependencies(n))
    H = prune(H, budget)                 # 去冗余，保留覆盖与接地
    if grounding_cover(H, M_p) < theta_g:
        return ('reject', 'grounding_below_floor')
    return ('ok', H, structure_cost(H, lam, mu))
```

### IP-125 JSO

```python
def joint_structure_selfmodel(H0, traj, D_T, K=10, tol=1e-3, theta_g=0.9):
    M = fit_self_model(traj, body_params)
    prev = inf
    for k in range(K):
        O = observability_matrix(D_T, signals, probe_fn)
        ok, H, cost = optimize_structure(H0, D_T, M, O, lam, mu, budget, theta_g)
        if ok != 'ok':
            return ('reject', H)
        M = recalibrate(M, traj, H)      # 只标定 H 依赖的信号
        cost = structure_cost(H, lam, mu)
        if abs(prev - cost) < tol and grounding_cover(H, M) >= theta_g:
            break
        prev = cost
    return ('ok', H, M)
```

```python
def transfer_fragility(H, target_traj, M_tgt, Theta_F):
    eps_tgt = {d: self_model_residual(M_tgt, target_traj, d)
               for d in required_dims(H)}
    ft = sum(depth(H, d) * eps_tgt[d] for d in required_dims(H))
    if ft > Theta_F:
        return ('reject', 'structural_transfer_fragility', ft)
    return ('ok', ft)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PSM | O(T·|P|) | O(|P|) | 残差校准无偏、有效域可判 |
| POM | O(|𝔇_ρ|·|P|·n) | O(|𝔇_ρ|·|P|) | 探针充分、可辨识度不虚高 |
| BGC | O(|𝔇_ρ|+|P|) | O(|𝔇_ρ|+|P|) | 接地判定 sound、证据分级 |
| SGO | O(|N|²·|E|) 贪心 | O(|N|+|E|) | 覆盖下界、接地节点非空 |
| JSO | O(K·(SGO+PSM)) | O(|N|+|P|) | 交替单调、接地下界不退化 |
| SFT | O(|H|·|𝔇_ρ|) | O(|𝔇_ρ|) | 依赖深度与漂移可测 |

**正确性定理（Body-Grounded Structural Certificate Soundness）**
承接第 54 轮 (A26)–(A28)；新增 **(A29)** 部署分布上 `ε_p ≤ Θ_p`；**(A30)** `Obs(θ_o) ⊇ D_T`（所有必需维度本体可接地）；**(A31)** 结构覆盖检查 `cover(H',D_T)` sound 且 `H'` 保留接地下界。则：
```
P_success(J^B | H') ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
                    - P(ε_p>Θ_p) - FT(H')/Θ_F - P(¬cover(H',D_T))
```
关键：**A30 是结构优化不产生“空证书”的前提**；没有接地覆盖下界，优化器会删除难观测维度以提升表面成功率，定理随即失效。

## 6. 本轮最大风险

**一句话**：把证书从“动作空间”接地到“本体感知”并用结构优化自动求解验证结构，能同时提升可信度与效率，但结构优化会在接地约束不完备时**系统性删除难观测维度以降低表面成本**，形成自洽却失真的“空证书”，再叠加自模型漂移的静默失效，最终把“身体接地”变成“身体自欺”；因此必须以 **接地覆盖下界 + 漂移绊线 + 跨本体结构脆弱性否决** 三重护栏约束优化器，宁可保留昂贵的可观测证据，也绝不把优化器选出来的“便宜证书”当作部署前提。
