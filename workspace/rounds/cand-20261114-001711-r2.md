# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 2 轮；本轮灵感：「姿态估计」×「多传感器融合」）

> R69 把不确定性一分为二：aleatoric 收紧，epistemic 靠「流匹配多模态 + 主动交互」去问。但它默认了三件事：**歧义是语义层的、动作模态是几何无约束的、多源证据是彼此独立的**。姿态估计与多传感器融合同时打穿这三条：
> - 大量 epistemic 歧义不是「该往左还是往右」的语义选择，而是**几何不可辨识**：左右肢镜像、深度翻转、自遮挡、对称物体、运动学冗余、手眼/坐标系错位。这些歧义**问不出来**——再问一句「你想让我抓哪个」不会让被遮挡的关节变得可见；只能靠**换视角、加接触、做三角化**。
> - R69 的多模态动作是从流模型直接采样的，可能落在**运动学不可达**的流形外；更糟的是，它会把「镜像姿态」这类几何幻影当成一个真实动作模态，然后认真地追问一个幻影。
> - R69 说「k 个正交证据源一致」，却从未定义**正交**。多传感器融合最容易制造的错觉就是：传感器数量很多，但共享同一个光照、同一次标定误差、同一段网络延迟——它们的误差高度相关，融合后的方差被低估，系统得到「虚假的确定」。
>
> 核心命题：**在 FLUID-RAS 之下再插一层几何可辨识性：先把不可观测的规范（gauge）方向商掉，再把 epistemic 拆成「语义歧义」与「几何歧义」；语义歧义去问，几何歧义去看/触/挪；动作模态先投影到运动学流形上，拒绝幻影；多传感器融合按共同原因与几何正交性而不是传感器数量来计冗余。** 命名 **POSE-RAS**（Pose-Observability and multi-Sensor Epistemic Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这个歧义在几何上可辨识吗？我还有哪只眼睛、哪只手、哪一个视角没用来测它？**」——不确定性不仅有形状，还有几何；有些答案不在语言里，而在视差、接触与闭合约束里。

## 0. 直觉与动机

**灵感 1（姿态估计 → 歧义是结构化的、带运动学约束的）**
直觉：人看一张侧身照片，很难判断手臂是在身前还是身后；看一段对称物体，很容易把正反装反。姿态估计的困难从来不是「像素噪声」这么简单，而是**结构化的多解**：镜像翻转、深度/尺度歧义、自遮挡、关节角冗余。关键点热图的峰值可以很尖，但整体姿态仍可能有两个相距很远的解释。更重要的是，这些解释并非同样「值得处理」：如果两个姿态只在**任务不关心的自由度**上不同（例如肘部略微内旋而手的位置不变），那它们对抓取毫无影响；如果差异落在**任务敏感方向**（例如手腕朝向决定能否插入），那才是真正需要消解的歧义。R69 只问「有几个动作模态」，没问「这些模态差在哪个方向、这个方向对任务可见吗」。

**灵感 2（多传感器融合 → 冗余是有条件的，不是数出来的）**
直觉：RGB、深度、IMU、力矩、触觉、本体感觉、音频，看起来是七个独立证人；但如果深度相机的误差来自与 RGB 相同的光照，IMU 与轮速计共享同一次标定偏移，两个摄像头又接在同一个时延通道上，那么它们只是在**重复同一个证词**。独立同分布假设下，n 个等方差观测把方差降为 1/n；存在相关系数 ρ 时，真实方差是 σ²(1+(n−1)ρ)/n，有效样本量只有 n/(1+(n−1)ρ)，ρ→1 时退化为 1。多传感器融合的第一原则因此不是「多加一个传感器」，而是「**新传感器带来的约束是否与既有约束正交，且故障是否不同源**」。

**灵感 3（规范商 → R69 的幻影模态可以被几何剔除）**
直觉：R69 最大的风险是「问错比不问更危险」——流模型幻觉出一个模态，系统就去追问。姿态估计给出一个不依赖学习密度的硬约束：动作必须落在**运动学可达流形**上，关节角、骨骼长度、接触非穿透、手眼变换都要闭合。一个镜像姿态若违反关节限位或使手穿过桌面，它就不是一个可执行模态；一个只在不可观测方向发散的采样，也不该被当成「第二个选择」。把动作模态先投影到流形、再按**任务敏感的规范方向**聚类，可以在源头上消灭大量幻影，而不是等问完再由证据纪律补救。

**灵感 4（主动几何感知 → 「看/触/挪」比「问」更根本）**
直觉：对于几何歧义，最有效的信息动作不是提问，而是改变观测几何：向侧面挪一步获得视差，转动手腕让被遮挡的关节露出来，用探针轻触一个已知标记做接触定位，或用两个视角做三角化。经典主动感知早已把这件事写成实验设计：选择动作使 Fisher 信息矩阵的行列式最大（D-optimal）或最小特征值最大（E-optimal）。这比 R69 的「熵减」更可算、更贴近几何：**不确定性消不掉时，先问「哪个方向最看不清」，再问「哪个动作最能照亮那个方向」**。

**灵感 5（几何闭包 → 第三条校准不可吸收的通道）**
直觉：R68 只看传感器残差，R69 加了策略动作似然。两者都可能被「聪明的标定」解释掉：把偏差吸收进标定参数，残差就归零；把动作分布调宽，似然就差不大。但姿态估计提供第三类证据：**硬几何不变量**——骨骼长度不变、闭环长度不变、手眼变换一致、接触不穿透、多视角重投影一致。标定参数可以拟合单传感器残差，却很难同时让所有几何闭包闭合，除非它把物理真值也一起改掉。于是 `(r_res↓, Δa↑, r_geom↑)` 的三元模式比 R69 的二元模式更能把「真漂移」与「被标定吸收的缓变故障」分开。

**灵感 6（新攻击面 → 几何感知也会被「摆姿势」欺骗）**
直觉：一旦系统依赖姿态与几何一致性，攻击者就可以「摆一个正确的姿势」：对抗贴片让关键点偏移、用镜面/对称物体制造合法但错误的姿态、让多个传感器同时收到同源伪造信号（共谋）、污染手眼标定使闭包在错误参数下仍然闭合、用主动探测动作本身做侧信道（探测即泄露）。**几何一致性是必要条件，不是充分条件**；多传感器「一致」也可能是被同一只手操纵出来的一致。所以本轮必须同时交付：可辨识性模型的可信度门、共同原因因子、几何证据的独立性审计、以及针对姿态/融合的对抗干扰集。

## 1. 形式化定义（增量：定义 310–329）

**定义 310（POSE-RAS 总览）** POSE-RAS = (PME, OBS, GQ, AGS, CFG, OCE, PMR, GCC, OSM, RAS-WM§)。五不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **先辨识、后交互**：任何 VoI/交互决策之前必须先过几何可辨识门（定义 324），不可辨识方向上的「多模态」不得触发提问；
(iii) **融合一致性**：多传感器融合的协方差不得低于共同原因修正后的下界（定义 318），宁可保守，不得虚假自信；
(iv) **流形可行性**：所有生成/执行的动作模态必须落在运动学可达流形与安全包络内（定义 311、321）；
(v) **证据正交性**：R69 的「k 个正交证据源」升级为「k 个几何约束方向的主角度足够大且故障不同源」（定义 319），单源/共谋源不得定案。

**定义 311（运动学流形与状态）** 世界状态 x = (T_wb, q, {T_wo}, 𝒮_h) ∈ ℳ，其中 T_wb 为基座位姿、q 为关节角、T_wo 为物体位姿、𝒮_h 为人/其他智能体的骨架姿态。ℳ 由约束 C(x)=0 定义：关节限位、骨骼长度、闭环/接触非穿透、支撑面一致。姿态估计器输出流形上的多假设后验 p(x|y) = Σ_j π_j δ_{x_j}（或流形上的混合密度），每个假设带关键点/关节协方差 Σ_j。

**定义 312（多传感器观测模型）** 第 i 个传感器 y_i = h_i(x; T_i, b_i, τ_i) + ν_i，其中 T_i 为外参、b_i 为标定参数、τ_i 为时延、ν_i 为噪声；联合噪声协方差 Σ_y 允许非对角（跨传感器相关）。传感器集合 𝒮 带一个**共同原因分组** 𝒞 = {C_1,…,C_m}（共享光照、共享时延链路、共享标定批次、共享电源/网络等）。

**定义 313（结构化姿态后验与不确定性传播）** 关键点/关节局部协方差 Σ_kp 经运动学雅可比 J_kin 传播：Σ_x = J_kin Σ_kp J_kin^T + Σ_model。姿态后验的熵 H_pose = H({π_j}) + Σ_j π_j H(x|j)。遮挡度 o_occ、对称性 s_sym、深度条件数 κ_depth 作为结构歧义的显式协变量，而不是被网络隐式吸收。

**定义 314（可观测性谱 OBS）** 在当前位形与传感器配置下，Fisher 信息矩阵 F(x) = Σ_i J_i^T Σ_{y,i}^{-1} J_i（跨传感器相关时用 Σ_y^{-1} 的联合形式）。其特征值 λ_1 ≤ … ≤ λ_d 称为**可观测性谱**；有效自由度 d_eff = Σ_i λ_i/(λ_i + ε_obs)；条件数 κ_obs = λ_max/λ_min。谱不是全局常数，而是随位形、视角、接触状态变化的函数 F(x,g)。

**定义 315（规范子空间与商流形 GQ）** 对阈值 ε_obs，定义几何规范子空间 G_ε = span{v : v^T F v ≤ ε_obs}；它对应「当前观测几乎不约束」的自由度（深度翻转、绕对称轴旋转、自遮挡关节、未接触的自由漂浮等）。商流形 ℳ/G_ε 把仅在规范方向上不同的姿态视为同一类。注意 G_ε 是**当前观测条件**下的，不是本体固有的：挪一步、摸一下就可能让某个方向离开 G_ε。

**定义 316（任务条件可辨识性与可行动歧义）** 任务只关心 φ(x)（末端位姿、抓取轴、接触点、人体朝向等），其雅可比 Dφ。方向 v 的**任务敏感度** s_φ(v)=‖Dφ v‖/‖v‖。几何歧义 δ 是**可行动的**（actionable）当且仅当 s_φ(δ) ≥ τ_act 且 δ 不是纯规范方向（δ ∉ G_ε）。若 δ ∈ G_ε 但 s_φ(δ) 很大，说明当前观测不足以约束任务关键方向——这不是「问」能解决的，必须触发 AGS；若 s_φ(δ) ≤ τ_act，则即使 δ 很大也不值得处理（任务不敏感）。这条定义把「模态多」与「模态值得管」彻底分开。

**定义 317（三路不确定性）** U_ale = E[tr Σ_noise]（噪声，继承 R69）；U_epi_sem = R69 的 U_epi（语义/任务模态歧义）；U_epi_geo = E[tr(P_G Σ_x P_G)]（规范方向上的后验弥散，可约但只能靠改变观测几何）。三者分通道：U_ale→λ_floor；U_epi_sem→R69 MINT 提问；U_epi_geo→AGS 主动几何测量。只有当 U_epi_geo 经 AGS 后仍高，才把它按未消解 epistemic 并入 R69 兜底（定义 325）。

**定义 318（相关感知融合与共同原因因子 CFG）** 对每个传感器簇 C_k，用协方差交（covariance intersection）而非朴素逆方差加权：
P_CI^{-1} = Σ_{i∈C_k} w_i P_i^{-1}，Σ_i w_i = 1，
得到对未知相关性保持一致的保守融合。定义共同原因因子 χ = sqrt(λ_max(P_CI^{-1} P_naive))（≥1），其中 P_naive 为假设独立的融合协方差；χ 越大，说明「看到的冗余」越虚假。跨簇再按定义 319 的正交性决定是否允许 resolution bonus。**χ 参与安全裕度与证书，而不是只做诊断。**

**定义 319（有效冗余与正交证据 OCE）** 约束行空间之间的主角度 θ_ij = ∠(row(J_i), row(J_j))。称两个证据源**几何正交**若 θ_ij ≥ θ_orth。有效冗余 r_eff = rank(白化后的堆叠约束) − d_eff(F_base)，即「新证据真正增加的独立约束数」，而不是传感器个数。等方差、两两相关 ρ 时 r_eff ≤ n/(1+(n−1)ρ)（引理 20）。R69 的证据纪律改为：需至少 k 个**两两主角度足够大且不属于同一共同原因簇**的证据源一致。

**定义 320（主动几何感知 AGS）** 信息动作空间扩展为 g = (g_view, g_contact, g_triang, g_ask)，分别表示视角/位姿微调、接触/探针、多视角三角化、语言提问。几何信息动作的目标：
g* = argmax_g [ log det(F(x,g) + F_0) − μ·cost(g) ]（D-optimal）
或 argmax_g [ λ_min(F(x,g)+F_0) − μ·cost(g) ]（E-optimal），
s.t. C-RAS-WM 认证、位移/力/社交预算、时间窗。**语义歧义用 g_ask，几何歧义用 g_view/g_contact/g_triang；两者的 VoI 不能混算。** R69 的 MINT 是 g_contact/g_view 被禁用、只剩 g_ask 的退化。

**定义 321（幻影模态剔除 PMR）** 流模型采样 {ξ_j} 先投影到运动学流形 π_ℳ，拒绝约束残差 ‖C(ξ_j)‖ > τ_c 或越出安全包络的样本；再在商度量 d_G 下聚类（只按任务敏感方向距离加权），得到模态 {m_k}。**幻影模态** = 不可行模态，或仅在 G_ε 内不同、任务敏感度低于 τ_act 的模态。幻影不进入 VoI，不触发提问；若所有模态都不可行，退回 R69 纯保守并报「生成器不可信」。

**定义 322（几何闭包通道 GCC）** 定义四类硬/半硬残差：
r_kin：骨骼长度/闭环/关节限位/接触非穿透；
r_reproj：多视角重投影一致；
r_handeye：手眼/基座-相机变换与本体感觉一致；
r_sync：跨传感器时间戳与运动一致性（扣除已知时延后的残差）。
归一化后 r_geom = (r_kin, r_reproj, r_handeye, r_sync)。**标定一致性约束**：标定更新必须保持闭包不变，即 b 的自由度不得用于解释 r_geom 的变化。

**定义 323（可观测性感知安全裕度 OSM）** 安全包络膨胀量
ε_safe = clip(β·s_φ(Σ_x)/(λ_min(F)+ε_obs) + γ·1[U_epi_geo 未消解], 0, ε_max)。
关键：**纯规范方向不膨胀安全裕度**（任务不敏感），而任务敏感但低可观测的方向必须膨胀并触发 AGS。R69 的「未消解 epistemic 一律当成 aleatoric」在这里被细化为「按任务敏感度定价」，既不过保守也不漏掉真正的不可见风险。

**定义 324（几何可辨识门 IG）** 每轮先算 (F, G_ε, d_eff, 任务敏感度)。三路分流：
- 若 U_epi_geo 中存在任务敏感方向且 s_φ ≥ τ_act：走 AGS，**禁止用 g_ask 冒充几何测量**；
- 若 U_epi_geo 只剩任务不敏感方向：商掉，不动作，任务照常；
- 若 U_epi_sem 占主导（R69 条件）：走 R69 MINT；
- 若 OBS 自身不可信（模型失配、OOD 几何、χ 越界）：不信任商，退回 R69 + 最大保守。

**定义 325（两级退避，严格包含 FLUID-RAS）** 若几何歧义经 AGS 消解且融合一致：λ = λ_floor(U_ale)（几何 resolution bonus，不弱于 R69）；若几何歧义未消解/AGS 越预算/χ 越界/OBS 不可信：λ = λ_floor(U_ale + U_epi_sem + U_epi_geo)，并把安全裕度取定义 323 的上界。**R69 恰为「关闭 AGS、所有几何歧义都当作不可约」的边界**，因此 POSE-RAS 在安全侧不减分，只在可辨识时获得额外效率。

**定义 326（证书 J_POSE）** J_POSE = (J_FLUID, obs_spectrum_p5, d_eff, dim G_ε, r_eff, χ, r_geom_p95, identifiability_gate_log_hash, pose_version, fusion_version)。Valid ⇔ Valid(J_FLUID) ∧ r_eff 纪律满足 ∧ χ ≤ τ_χ ∧ 闭包未被标定吸收 ∧ IG 记录完整。

**定义 327（干扰集 AIC-POSE）** ℰ_POSE = ℰ_FLUID × ℰ_geom × ℰ_fusion，其中 ℰ_geom 含对抗贴片/关键点偏移、镜像/对称物体、遮挡诱导、深度伪造、主动探测侧信道；ℰ_fusion 含同源共谋（多传感器同错）、时延注入、外参/手眼污染、共同原因制造（统一光照/电磁/网络）、传感器选择性失效。

**定义 328（几何 resolution bonus 与预算）** 当且仅当 (i) 几何歧义沿任务敏感方向被 AGS 或正交融合消解，(ii) 融合通过 χ 与 r_eff 检查，(iii) 闭包通道无异常，允许把安全裕度回落到 λ_floor(U_ale)，并把该收益记入证书。AGS 的位移/力/时间预算与 R69 交互预算共享一个硬上限：单位时间几何动作 ≤ 1 次、总位移 ≤ ε_g、总接触冲量 ≤ I_max、总时延不得使任务窗口过期。

**定义 329（辨识-标定对偶门）** OBS 与 GCC 都是模型，模型也会错。用**辨识残差** r_id = 预测可观测谱与实际重投影/接触残差的一致性来监控 OBS 本身；若 r_id 越界，说明「以为看得清」或「以为看不清」的判断不可信，此时禁止使用 GQ 的商、禁止 resolution bonus，退回 R69 最保守。这是对 R70 自身核心假设的反身监控。

    return actionable, gauge_only, irrelevant, U_geo

## 3. 推导

**引理 19（规范商的任务损失界）** 设任务 φ 为 L_φ-Lipschitz，δ 为两姿态之差，若 δ ∈ G_ε 且任务敏感度 s_φ(δ) ≤ τ_act，则商掉 δ 引起的任务代价 ≤ L_φ·τ_act·‖δ‖；若 s_φ(δ) ≥ τ_act，则商掉它的代价至少随 τ_act·‖δ‖ 增长，必须由 AGS 而不是「忽略」处理。要点：**商不是免费的降维，而是有任务条件的**；GQ 的正确性取决于任务雅可比，而非几何本身。系：任务不敏感的方向可以放心商掉，任务敏感的低可观测方向必须测量。

**引理 20（有效冗余上界）** 设 n 个等方差 σ² 的传感器估计，两两相关系数 ρ∈[0,1]。朴素独立融合给出方差 σ²/n，真实方差为 σ²(1+(n−1)ρ)/n，故有效冗余
r_eff = n / (1 + (n−1)ρ) ≤ 1/ρ，
且 ρ→1 时 r_eff→1，ρ=0 时 r_eff=n。要点：**传感器数量不是冗余，相关性才是冗余的倒数**；R69 的「k 个源」若不检查 ρ 与主角度，可能只是同一个源被数了 k 次。

**引理 21（幻影模态剔除下界）** 设流生成器把概率质量 p_ph 放在运动学不可行集 ℳ^c 上，PMR 以约束残差 τ_c 拒绝。则在生成器校准良好的条件下，进入 VoI 的幻影模态比例 ≤ p_ph + P(‖C(ξ)‖≤τ_c | ξ∈ℳ^c)，后者随 τ_c→0 而趋于 0。系：**几何可行性是一道不依赖策略密度的硬门**，它把 R69 的「先问再校验」改成「先剔除再问」，直接降低「问一个幻影」的概率。

**引理 22（闭包残差的标定不可吸收性）** 设标定参数 b 的维数为 d_b，闭包不变量 I(x) 由独立于 b 的传感器（本体感觉/接触/多视角几何）计算；若故障沿闭包敏感方向改变 I 至少 c‖δx‖，则任何只调整 b 使残差 r_res→0 的标定，仍留下
r_geom ≥ c‖δx‖ − ε_geo，
除非 b 同时改变了 I（被定义 322 的标定一致性约束禁止）。故 `(r_res↓, r_geom↑)` 是「标定吸收」的判别模式，与 R69 的 `(r_res↓, Δa↑)` 互为补角。

**定理 18（POSE-RAS 严格包含 FLUID-RAS）** 在 A100–A105 下（流形约束正确、GQ 任务条件成立、融合一致、OBS 可信），任意状态上 POSE-RAS 的期望风险 ≤ R69；且当 AGS 关闭、所有几何歧义视为不可约、或 IG 判定 OBS 不可信时，两者逐指令相同（定义 325）。因此 R69 是 POSE-RAS 在「不测量几何、不信商」边界上的退化：安全侧不减，效率侧只在可辨识时获得 bonus。

**定理 19（主动几何感知的单调收益与安全）** 在线性高斯条件下，F(x,g) 为 PSD 增量，故 λ_min(F0+ΔF) ≥ λ_min(F0)、log det(F0+ΔF) ≥ log det(F0)；E/D-optimal 选择使后验熵 H(x|y,g) 单调不增。若 g 通过 C-RAS-WM 前缀认证（定义 320），其物理风险 ≤ ε_int；几何测量只改变后验与安全裕度，不直接改变已认证的安全包络。系：**看/触/挪的收益可证，但它的安全性必须与任务动作同级认证**。

**定理 20（融合一致性与无虚假自信）** 采用协方差交并按 χ 修正后，融合协方差在 Loewner 序下不低估真实协方差；因此由定义 323 得到的安全裕度不会小于真实所需裕度。若 χ ≤ τ_χ 且 r_eff 纪律满足，则允许几何 resolution bonus，且 bonus 后的裕度仍不低于 U_ale 对应的下界。系：**多传感器融合只有在「共同原因不占主导」时才允许降低保守度**；否则它只是把风险藏进协方差的非对角项。

## 2. 形式化定义（要点版）

**定义 310（总览与五不变式）** 先辨识后交互；融合一致性不得低于共因修正下界；动作必须落在运动学流形；证据需几何正交且故障不同源；实时流零学习写操作。

**定义 311–313（流形状态与结构化后验）** `x∈ℳ`，约束含关节限位、骨骼长度、闭环/接触非穿透；多假设后验带 `π_j, Σ_j`；关键点协方差经 `J_kin` 传播；遮挡/对称/深度条件显式入模。

**定义 314–316（可观测谱、规范商、任务条件可行动性）** `F=ΣJᵀΣ⁻¹J`；`G_ε` 为低特征值方向；方向可行动 ⇔ `s_φ ≥ τ_act` 且 `δ∉G_ε`；若 `δ∈G_ε` 但任务敏感，必须 AGS，不得提问；若任务不敏感，商掉。

**定义 317（三路不确定性）** `U_ale→λ_floor`；`U_epi_sem→R69 MINT`；`U_epi_geo→AGS`；几何残余才并入 R69 兜底。

**定义 318–319（相关感知融合与有效冗余）** 协方差交 `P_CI⁻¹=Σw_iP_i⁻¹`；`χ=√(λ_max(P_CI⁻¹P_naive))`；主角度 `θ_ij` 定义正交；`r_eff` 为新证据真正增加的独立约束数；等方差下 `r_eff≤n/(1+(n−1)ρ)`。

**定义 320（AGS）** `g* = argmax[logdet(F0+ΔF(g)) − μ·cost]` 或 E-optimal；几何动作过 C-RAS-WM 认证；语义与几何 VoI 分账。

**定义 321（PMR 幻影剔除）** 投影到 `ℳ`，拒绝 `‖C(ξ)‖>τ_c`；商度量 `d_G` 下聚类；不可行或仅规范方向不同的模态不进入 VoI。

**定义 322（GCC）** `r_geom=(r_kin,r_reproj,r_handeye,r_sync)`；标定一致性约束要求标定不得解释闭包变化；`(r_res↓,r_geom↑)` 判标定吸收。

**定义 323–325（安全裕度、辨识门、严格包含）** `ε_safe` 按 `s_φ` 与 `λ_min` 定价；IG 四路分流（AGS / 商掉 / R69 提问 / 最保守）；消解成功 `λ=λ_floor(U_ale)`，失败则并入全部未消解 uncertainty；R69 = 关闭 AGS 且不信商的边界。

**定义 326–329（证书、干扰、bonus、对偶门）** `J_POSE` 并入谱/`d_eff`/`dim G`/`r_eff`/`χ`/`r_geom` 与 IG 日志；`ℰ_POSE=ℰ_FLUID×ℰ_geom×ℰ_fusion`；几何 resolution bonus 受 `χ`、`r_eff`、闭包检查三重门控；`r_id` 监控 OBS 自身，越界即禁商、禁 bonus、退回 R69。

# IP-264/265 PME+OBS：流形上的多假设姿态与可观测性谱
class PoseObservability:
    def estimate(self, y, T_ext, b_cal):
        hyps = [project_to_manifold(h, self.kin) for h in self.pose.multi_hypothesis(y)]
        F, Js = fisher_information(hyps, self.sensors, T_ext, b_cal)
        lam, G = observability_spectrum(F, eps_obs=EPS_OBS)
        return hyps, F, lam, G

# IP-266 GQ：任务条件可辨识性；区分可行动 / 规范 / 无关
def gauge_quotient(hyps, F, G, task_jac):
    actionable, gauge_only, irrelevant = [], [], []
    for m in cluster_on_manifold(hyps, metric='task_weighted'):
        s = task_sensitivity(m.delta, task_jac)
        if m.delta in G:
            (gauge_only if s < TAU_ACT else actionable).append(m)
        else:
            (actionable if s >= TAU_ACT else irrelevant).append(m)
    U_geo = sum(trace(project_G(h.Sigma)) for h in hyps)
    return actionable, gauge_only, irrelevant, U_geo

# IP-268/269 CFG+OCE：协方差交 + 共同原因 + 有效冗余 + 主角度
def fusion_guard(sensor_estimates, cc_groups):
    P_ci = {k: covariance_intersection([e.P for e in C]) for k, C in cc_groups.items()}
    chi = sqrt(lambda_max(inv(P_ci) @ independent_fusion(sensor_estimates)))
    r_eff = effective_redundancy(sensor_estimates)     # rank gain, not sensor count
    return P_ci, chi, r_eff

# IP-267 AGS：几何歧义用视角/接触/三角化，不用提问
def active_geometric_sensing(F0, task_jac, budget):
    best = None
    for g in geometric_candidates():
        if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
        Fg = F0 + expected_information(g, task_jac)
        score = logdet(Fg) - COST_MU * cost(g)          # D-optimal
        if best is None or score > best.score: best = (g, score, Fg)
    return best if best and best.score > 0 else None

# IP-270 PMR：幻影模态剔除（流形投影 + 商度量聚类）
def reject_phantom_modes(xi_samples, kin, G, task_jac):
    feasible = [x for x in xi_samples if norm(kin.constraint(x)) <= TAU_C]
    if not feasible: return [], False                    # 生成器不可信 → R69 保守
    return cluster_under_quotient(feasible, G, task_jac), True

# IP-271 GCC：几何闭包第三证词
def geometric_closure(hyps, T_ext, b_cal, streams):
    return norm([kinematic_closure_residual(hyps, kin_model),
                 multi_view_reprojection(hyps, T_ext),
                 hand_eye_consistency(T_ext, proprioception),
                 sync_residual(streams)])

# IP-274 主闭环（继承 R69）
def POSE_RAS_round(M, obs):
    z, o = M.mtm.forward(...)
    hyps, F, lam, G = M.pme.estimate(obs, M.T_ext, M.b_cal)
    act, gauge, irr, U_geo = M.gq.quotient(hyps, F, G, M.task_jac)
    P_ci, chi, r_eff = M.cfg.fusion_guard(obs.sensor_estimates, M.cc_groups)
    obs_ok = (M.ig.identifiability_residual(hyps, obs) < TAU_ID) and (chi <= TAU_CHI)
    xi = M.fmp.sample(o, K=M.adaptive_K(lam))
    xi, gen_ok = M.pmr.reject(xi, M.kin, G, M.task_jac)          # 幻影剔除
    g_geo = M.ags.choose(F, M.task_jac, M.budget) if (gauge and obs_ok) else None
    g_sem = M.mint.choose_interaction(xi, o, M.budget) if (act and obs_ok) else None
    if g_geo is not None: F = M.ags.execute(g_geo)               # 认证后的看/触/挪
    if g_sem is not None: M.cia.update_belief(xi, M.cia.execute(g_sem))
    r_geom = M.gcc.residual(hyps, M.T_ext, M.b_cal, obs.streams)
    slow = (M.last_r_res < TAU_RES) and (M.fma.delta_a > TAU_FMA) and (r_geom > TAU_GEOM)
    resolved = (gen_ok and obs_ok and g_geo is not None and M.ags.improved(F))
    U_floor = M.aud.U_ale + (0.0 if resolved else U_geo) + (M.aud.U_epi if g_sem is None else 0.0)
    lam_risk = max(M.efs.risk_scale(...), lam_floor(U_floor))
    eps_safe = M.osm.margin(U_geo, M.task_jac, lam, resolved)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds, eps_safe)
    if slow or not obs_ok:
        lam_risk = max(lam_risk, 0.8); k = min(k, k_cal_shrink(...))   # 回 R69 最保守
    mode = select_feasible_mode(xi, U_geo, lam_risk)
    M.vqa_g.submit_async(g_geo, g_sem, chi, r_eff, r_geom, U_geo)
    return k, lam_risk, mode, (M.aud.U_ale, M.aud.U_epi, U_geo)

## 4. 推导

**引理 19（规范商的任务损失界）** 任务 φ 为 `L_φ`-Lipschitz；对 `δ∈G_ε` 且 `s_φ(δ)≤τ_act`，商掉 δ 的任务代价 `≤ L_φ·τ_act·‖δ‖`；若 `s_φ(δ)≥τ_act`，商掉它的代价随 `τ_act·‖δ‖` 增长，必须由 AGS 处理。系：商是**任务条件**的，不是纯几何降维；任务不敏感方向可商，任务敏感的低可观测方向必须测。

**引理 20（有效冗余上界）** n 个等方差 `σ²`、两两相关 `ρ` 的估计，朴素融合方差 `σ²/n`，真实方差 `σ²(1+(n−1)ρ)/n`，故 `r_eff = n/(1+(n−1)ρ) ≤ 1/ρ`；`ρ→1` 时 `r_eff→1`。系：**传感器数量不是冗余，相关性才是冗余的倒数**；R69 的 k 源一致必须先过 OCE。

**引理 21（幻影模态剔除下界）** 流生成器在不可行集 `ℳ^c` 上的质量为 `p_ph`；PMR 以 `τ_c` 拒绝后，进入 VoI 的幻影比例 `≤ p_ph + P(‖C(ξ)‖≤τ_c | ξ∈ℳ^c)`，随 `τ_c→0` 趋零。系：几何可行性是一道不依赖策略密度的硬门，把「先问再校验」改为「先剔除再问」。

**引理 22（闭包残差的标定不可吸收性）** 标定 `b` 维数 `d_b`，闭包不变量 `I(x)` 由独立于 b 的传感器计算；故障沿闭包敏感方向改变 `I` 至少 `c‖δx‖`，则任何只调 `b` 使 `r_res→0` 的标定仍留 `r_geom ≥ c‖δx‖ − ε_geo`（标定一致性约束禁止 b 同时改变 I）。故 `(r_res↓,r_geom↑)` 是标定吸收的判别模式，与 R69 的 `(r_res↓,Δa↑)` 互补。

**定理 18（严格包含 FLUID-RAS）** A100–A105 下（流形正确、GQ 任务条件成立、融合一致、OBS 可信），任意状态 POSE-RAS 期望风险 ≤ R69；当 AGS 关闭、所有几何歧义视为不可约、或 OBS 不可信时逐指令相同。R69 = 「不测几何、不信商」边界；安全不减，效率只在可辨识时获 bonus。

**定理 19（主动几何感知单调收益与安全）** 线性高斯下 `F0+ΔF ⪰ F0`，故 `λ_min` 与 `logdet` 单调不减，E/D-optimal 使后验熵单调不增；g 过 C-RAS-WM 认证后物理风险 `≤ ε_int`，几何测量只改后验与安全裕度，不直接改已认证包络。

**定理 20（融合一致性与无虚假自信）** 协方差交 + χ 修正后，融合协方差在 Loewner 序下不低估真实协方差，故由定义 323 得到的安全裕度不小于真实所需；`χ≤τ_χ` 且 `r_eff` 纪律满足时才允许 resolution bonus，且 bonus 后仍不低于 `U_ale` 下界。系：融合只有在共因不占主导时才允许降低保守度。

## 7. 本轮最大风险

**一句话**：POSE-RAS 把安全性押在「可观测性模型自己是对的」这一前提上——**若 OBS/GQ 把一条任务关键但当前观测不足的自由度误判为「纯规范、任务无关」而商掉，系统会以更小的安全裕度、更少的测量、更自信地执行；多传感器融合的共同原因又会把这种错觉包装成「多个来源一致同意」**。R69 的风险是「问错」，R70 的风险是「该看却没看，而且自以为看懂了」——看不见的错，比问错的错更安静。
