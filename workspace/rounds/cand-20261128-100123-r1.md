### 第 6 轮灵感驱动研究记录

**灵感词**：数据标注、长程任务

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）把提议从离散规则升级为条件流匹配、记忆升级为嵌入 + 固化、人因升级为情感调制，并用定理 5/6 保证「提议可换、门不可换」，执行集 Exec_v5 ⊆ Exec_v4。但 v5 留下一个结构性缺口（正是其自认最大风险 R57）：固化只用「自铸证 ∧ 自验证」的片段，闭环缺乏外部真值；同时七门是对单段轨迹的谓词，没有回答「几百步长程任务里证书如何跨段传递、失败如何定位、残差如何不累积」。本轮两个灵感词恰好补这两个缺口，且不是两个独立功能，而是同一条闭环：**长程任务把证书拆成账本 → 账本暴露高残差/高不确定段 → 主动向人类盲标这些段 → 外部真值锚定固化 → 只更新提议器**。形成 CADVS-v6（IP-497~500），主题「认证数据闭环 × 长程证书演算」（Certified Data Loop & Long-Horizon Certificate Calculus, CDL-LHC）。自律不变：**硬门数量不增（七门）、τ^4 冻结、标注只喂提议/校准/评测，永不改门**；执行集 Exec_v6 ⊆ Exec_v5 ⊆ Exec_v4 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **数据标注 → 把「自铸证」换成「带证书的外部真值」，正面拆 R57**。v5 的固化是自指回路：模型在自己铸证、自己判成功的片段上训练，等于用自己的答案当标准答案。直觉上，打破自指唯一干净的办法是引入**不经过系统提议的独立信号**。但「人类抽检」在 v5 里只是一句缓解，没有协议、没有质量、没有成本。本轮把它做成 IP-497 认证主动标注核（CAAB）：(a) **标注即证书**：每条标签携带 y、后验 p(y)、标注者一致性 κ、可靠度 rel、来源链、协议版本、DP 消耗；只有满足 κ≥κ_min、金标探针正确率≥a_min、来源链完整、预算合规的标签才算「有效外部真值」；(b) **盲标协议**：标注者在看不到系统建议的盲态下标注，定义独立外部比 ρ_ext^⊥ = 未接触系统提议的有效标签占比——这比「有人看过」强得多的外部性度量，也是定理 11 唯一认可的记账口径；(c) **预算受限主动查询**：在标注预算 B 下，用子模采集函数选最值得标的片段（认知不确定 + 证书边际贴边 + 长程影响 + 新颖度 + 多样性），贪心 1−1/e。红线：标注只进入固化过滤、FER/不确定度头校准与离线评测，**不进入门、不改 τ^4**——外部真值是「训练信号」，不是「放宽信任边界的理由」。

2. **长程任务 → 把单段证书升级为可组合、可定位、会过期的证书账本**。v5 的七门是对一条候选轨迹的谓词；长程任务里一条 300 步轨迹不可能整段重新认证，且误差/磨损/环境漂移会让早期证书失效。直觉：像工程验收一样，把任务拆成子目标合同，逐段认证，段间只校验**接口**和**残差预算**，整任务证书由段证书「拼接」得到。本轮 IP-498 长程证书账本（LHCL）：(a) 子目标合同 G_i=(pre_i,post_i,h_i,φ_i)；(b) 组合算子 ⊕：c_i⊕c_j 有效当且仅当两段各自有效 ∧ 接口残差 δ(i,j)≤δ_max ∧ 组合边际 min(m_i,m_j)−λ_comp·δ(i,j)≥m_min；(c) **残差预算** Δ_max 防止误差累积；(d) **证书新鲜度** f=exp(−(t−t_i)/τ_fresh)，过期 fail-closed 重认证；(e) 追加式 Merkle 账本，支持审计与**增量重认证**：只有受影响的后缀需要重算，失败定位到具体接口而非整任务。

3. **两词合流 → 一条可审计的数据闭环，而不是两套补丁**。长程任务的结局标签天然延迟、稀疏、信用分配困难，正是最需要标注的地方；而证书账本恰好精确记录了「哪一段边际最低、残差最大、最接近过期」。于是 IP-499 LMEM-v3/ACCG 把二者接起来：**账本驱动主动标注**（把 LHCL 的残差/边际/新鲜度作为采集特征），**标注反哺固化**（只有 ρ_ext^⊥≥ρ_min 的批次才允许固化，否则冻结提议器），**固化仍只改提议器**。这样「经验→记忆→策略」正循环第一次有了外部锚，同时把 R57 从「无法根除只能缓解」降级为「可用外部真值比例定量的有界风险」。

**关键洞见**：v5 回答「任意生成器如何不破坏证书边界」；v6 回答「**证书边界之外的外部真值从哪来、长程上证书如何不退化**」。v6 不新增安全锚：七门与 τ^4 原样冻结；新增的只是数据侧（标注证书、ρ_ext^⊥）与审计侧（证书账本、组合算子、新鲜度），以及软评分 ECS_v6 = ECS_v5 · η_ann · η_lh。执行集收缩由「同门 + 同阈值 + 固化仅在有外部锚时发生 + 长程组合只做交集与残差约束」保证：Exec_v6 ⊆ Exec_v5 ⊆ Exec_v4 ⊆ … ⊆ Exec_v29。

**形式化目标（增量）**：
1. 标注证书 ℓ=(y,p(y),κ,rel,prov,proto,dp)，有效性 V_ℓ=1[κ≥κ_min ∧ gold_acc≥a_min ∧ prov_ok ∧ dp_ok]；独立外部比 ρ_ext^⊥ = 有效盲标标签数 / 批大小。
2. 采集函数 A(q)=αU_epi+βM_cert+γH_imp+δN_nov+ζD_div，预算 B 下贪心批选（子模 1−1/e，引理 45）。
3. 长程任务 τ 分解为 G_{1:n}；段证书 c_i；组合 ⊕ 与残差预算 Δ_max、新鲜度 f、Merkle 账本 L。
4. 定理 9（组合可靠性 / 失败局部化）、定理 10（增量重认证代价界）、定理 11（外部锚偏差界与 ρ_ext^⊥ 单调性）、定理 12（七锚完备性在组合/标注下保持）。
5. EFA-v6：段级七门 + 组合校验 + 新鲜度检查；ECS_v6 = ECS_v5 · η_ann · η_lh。
6. Exec_v6 = {τ : ∀i c_i valid ∧ ⊕c_i valid ∧ f_i ≥ f_min} ⊆ Exec_v5。

**本轮最大风险**：**标注外部性的名存实亡**——若标注者在长程任务中看到系统提议后再打标（确认偏差）、或标注预算耗尽导致后段只剩自铸证、或标注噪声/对抗标注污染，ρ_ext 看似很高但 ρ_ext^⊥ 很低，外部锚退化为「把自指回路外移一层」，固化仍可缓慢博弈证书门；盲标协议 + 金标探针 + 预算预留 + 噪声建模只能把风险定量化，无法证明外部真值永远独立。

class CertifiedActiveAnnotationBroker:

    def annotate_blind(self, q) -> LabelCertificate:
        """盲标：标注者看不到系统提议与当前证书；多标注者 + 金标探针 + 裁决"""
        votes = self.annotator_pool.vote_blind(q)

        ext = [l for s in batch for l in s.labels if self.valid(l)]
        rho_ext = len(ext) / max(len(batch), 1)
        rho_indep = sum(1 for l in ext if l.prov.blind) / max(len(batch), 1)
        return rho_ext, rho_indep       # 定理 11 只认 rho_indep

### IP-498 LHCL：长程证书账本与组合演算（离线校验 + 在线 O(1) 查询）

```python
@dataclass
class LongHorizonCertificateLedger:
    """LHCL：子目标合同 + 证书组合 ⊕ + 残差预算 + 新鲜度 + Merkle 账本。
    定理 9/10：组合可靠、失败局部化、增量重认证"""
    delta_max: float = 0.05
    Delta_max: float = 0.20
    lambda_comp: float = 1.0
    m_min: float = 0.10
    tau_fresh: float = 1.0e4          # 秒
    f_min: float = 0.5
    merkle: Any = None

    def compose(self, cs: list[Cert], interfaces: list[float]) -> Cert | None:
        if any(not c.valid for c in cs):
            return None
        m, rho = min(c.margin for c in cs), 0.0
        for c, d in zip(cs, interfaces):
            if d > self.delta_max:                     # (C2) 接口不兼容
                return None
            rho += d
            m = min(m, c.margin) - self.lambda_comp * d  # (C3) 边际不放大
        if rho > self.Delta_max or m < self.m_min:      # (C4) 残差/边际预算
            return None
        return Cert(valid=True, margin=m, residual=rho,
                    segments=cs, interfaces=interfaces)

    def fresh(self, c: Cert, t_now) -> bool:
        return exp(-(t_now - c.t) / self.tau_fresh) >= self.f_min

    def recertify_suffix(self, k: int, new_seg: Cert, task) -> tuple[Cert | None, int]:
        """定理 10：仅重认证受影响后缀 [k, j]；前缀证书复用。
        post_{k-1} 不变时前缀仍有效；一旦残差恢复预算即可截断"""
        cs = self.prefix(k) + [new_seg]
        for j in range(k + 1, len(task.subgoals)):
            d = interface_residual(cs[-1], self.get(j), task.subgoals[j])
            if d <= self.delta_max and self.residual_within(cs, d):
                cs.append(self.get(j))          # 复用原证书
            else:
                cs.append(self.reforge(j))       # 只重铸受影响段
        return self.compose(cs[:-1], interfaces_of(cs)), len(cs) - k

    def append(self, c: Cert) -> str:
        return self.merkle.append(c.hash)        # 追加式；根校验 O(log|L|)
```

### IP-499 ACCG（LMEM-v3）：账本驱动标注 + 外锚闸门固化（离线，分钟~小时）

```python
@dataclass
class AnnotationGroundedConsolidationGovernor:
    """ACCG：账本暴露薄弱段 → 主动盲标 → 外锚过滤 → 才允许固化。
    红线：ρ_ext^⊥ < ρ_min ⇒ 冻结提议器（宁可不学，也不用自铸证）"""
    caab: CertifiedActiveAnnotationBroker
    lhcl: LongHorizonCertificateLedger
    rho_min: float = 0.5
    n_min: int = 200

    def maybe_consolidate(self, store, fmpp, budget) -> str:
        # 1) 账本暴露薄弱段：低边际 / 高残差 / 临近过期 / 高影响
        weak = self.lhcl.weak_segments(store, k=budget.queries)
        # 2) 主动盲标（预算受限，子模采集）
        batch = self.caab.select_batch(weak, self.lhcl, fmpp, value_model)
        annotated = [self.caab.annotate_blind(q) for q in batch]
        # 3) 外锚闸门（定理 11）：只认独立外部比
        _, rho_indep = self.caab.external_ratio(annotated)
        if rho_indep < self.rho_min or len(annotated) < self.n_min:
            return "FROZEN_NO_EXTERNAL_ANCHOR"        # fail-closed
        # 4) 只取「铸证 ∧ 结局验证成功 ∧ 有效外部标签」片段
        certified = [ep for ep in store
                     if ep.forged and ep.outcome_ok
                     and self.caab.valid(ep.external_label)]
        # 5) 只改提议器：DP-SGD + KL 正则 + 失败回放；门与 τ^4 只读
        update_flow_policy(fmpp, certified, annotated,
                           dp_eps=dp_eps, kl_eps=kl_eps,
                           failure_replay=0.2)
        return "CONSOLIDATED"
```

def theorem_composition_soundness() -> str:
    """

### IP-500 EFA-v6：段级七门 + 长程组合 + 新鲜度（在线准入/10 Hz 预览）

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：段内复用 v5 七门（阈值冻结），段间做组合校验与新鲜度 fail-closed"""
    v5: EvidenceForgingAssemblerV5
    caab: CertifiedActiveAnnotationBroker
    lhcl: LongHorizonCertificateLedger

    def execute_segment(self, i, state, ctx) -> Cert | None:
        ok, x, why = self.v5.select(state, t_now, rule_id, ctx)
        if not ok:
            return None
        c = self.v5.forge_certificate(x, ctx)      # 七门证据（冻结）
        self.lhcl.append(c)
        return c

    def run_task(self, task, ctx) -> tuple[bool, Cert | None, str]:
        cs, ifs, state = [], [], task.initial
        for i, G in enumerate(task.subgoals):
            c = self.execute_segment(i, state, ctx)
            if c is None:
                return False, None, f'SEGMENT_{i}_REJECTED'
            if not self.lhcl.fresh(c, now()):
                return False, None, f'SEGMENT_{i}_STALE'          # fail-closed
            if cs:
                d = interface_residual(cs[-1], c, G)
                if d > self.lhcl.delta_max:
                    return False, None, f'INTERFACE_{i-1}_{i}_VIOLATION'
                ifs.append(d)
            cs.append(c)
            state = G.post(state)
        composed = self.lhcl.compose(cs, ifs)
        if composed is None:
            return False, None, 'COMPOSITION_REJECTED'
        return True, composed, 'FORGED_LONG_HORIZON'

    def ecs_v6(self, *a, n_flow, s_emo, rho_indep, lh_margin) -> float:
        eta_ann = sigmoid((rho_indep - self.caab.rho_min) / 0.1)
        eta_lh = sigmoid((lh_margin - self.lhcl.m_min) / 0.05)
        return self.v5.ecs_v5(*a, n_flow=n_flow, s_emo=s_emo) * eta_ann * eta_lh
```

## 4. 正确性论证（增量更新）

### 引理 45（子模贪心近似）
采集函数 A 若非负、单调、子模，则预算 B 下贪心批选的采集值 ≥ (1−1/e)·OPT。D_div 采用设施选址/覆盖子模项；U_epi、M_cert、H_imp、N_nov 为逐项分，非负线性组合保持子模。∎

### 引理 46（标注可靠度估计误差）
在 Dawid–Skene 模型下，若标注者 j 有 m_j 个金标探针、共 J 名标注者，则可靠度估计误差 |rel̂_j − rel_j| ≤ O(√(log(1/δ)/m_j)) 以概率 1−δ；标签后验误差随 J 与 κ 增大而减小。由此标签证书有效性判定误差有界。∎

### 引理 47（残差三角累积）
接口残差满足 δ(i,k) ≤ δ(i,j)+δ(j,k)+ε_model，故 n 段累计残差 ρ_res ≤ Σ_i δ(i,i+1) + (n−1)·ε_model；令每段 δ≤δ_max 且总预算 Δ_max，可把残差线性控制而非指数放大。∎

### 定理 9（长程组合可靠性与失败局部化）
**陈述**：在 (C1) 每段证书在冻结七门下有效、(C2) 相邻接口 δ≤δ_max、(C3) 组合边际 m_{1:n}≥m_min、(C4) 新鲜度 f_i≥f_min、(C5) 接口模型误差 ≤ε_model 下，整任务证书有效；任何安全违例必落在「未覆盖接口」或「残差预算耗尽点」，不会在已认证段内部静默发生。

**证明**：对段数归纳。基段由 (C1)(C4) 有效。归纳步：前 i 段有效且接口 (i,i+1) 满足 (C2)(C3) 时，第 i+1 段在接口约束下有效；⊕ 只做交集与残差累加，不放大边际。失败定位由 ⊕ 可结合性与引理 47 的三角界给出。∎

**诚实边界**：可靠性条件性依赖接口模型；ε_model 是经验标定量，不是先验保证。

### 定理 10（增量重认证代价界）
**陈述**：若仅第 k 段重规划且 post_{k−1} 不变，则最小重认证后缀为 [k, j]，j 为首个累计残差回到 Δ_max 内或组合边际恢复 ≥m_min 的段；代价 O((j−k+1)·C_cert + log|L|·C_hash)，最坏仍 O(n·C_cert)。

**证明**：残差是可结合累加器（引理 47）；前缀与 k 的接口不变故前缀证书有效；一旦某后缀段重新满足预算，其后各段只依赖该段 post，故可复用原证书。Merkle 账本使前缀根 O(log|L|) 校验。∎

### 定理 11（外部锚偏差界与独立性单调性）
**陈述**：设批外锚比 ρ_ext、盲标独立比 ρ_ext^⊥≤ρ_ext、自铸证系统偏差 β_self、标注噪声偏差上界 η，则固化目标相对真实结局分布的梯度偏差满足

  ‖bias‖ ≤ (1−ρ_ext^⊥)·β_self + ρ_ext^⊥·η。

当 β_self≥η 时偏差关于 ρ_ext^⊥ 单调不增；ρ_ext^⊥=1 时仅剩标注噪声 η。

**证明**：把批梯度写成外锚项与自铸证项的凸组合；自铸证项偏差 ≤β_self，外锚项偏差 ≤η；盲标标签与系统提议独立，故不引入系统偏差。对 ρ_ext^⊥ 求导得 β_self−η。∎

**诚实边界**：η 无法消除；标注者若看到系统提议（非盲），有效独立比下降，必须用 ρ_ext^⊥ 而非 ρ_ext 记账。

### 定理 12（七锚完备性在组合/标注下保持）
**陈述**：v6 不增删安全锚：七锚 {3DCF, MSRG, HICK, EEK, LTEM, VACK, BCK} 不变；CAAB 是数据侧通道、LHCL 是审计侧组合器、ACCG 是固化闸门，均非新锚。段内证书组合只做交集与残差约束，故 v4 定理 4 完备性保持且只强不弱。

**证明**：锚集合不变；⊕ 不新增谓词，只连接既有谓词；标注不改门代码与 τ^4。∎

### 定理 v6（执行集收缩与长程可靠性，总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) 接口模型误差 ≤ε_model、(B9) 标注证书有效性判定误差 ≤ε_ℓ 下：
(i) Exec_v6 ⊆ Exec_v5 ⊆ Exec_v4 ⊆ … ⊆ Exec_v29；
(ii) 长程组合可靠且失败局部化（定理 9）；
(iii) 增量重认证代价有界（定理 10）；
(iv) 固化偏差 ≤ (1−ρ_ext^⊥)·β_self + ρ_ext^⊥·η，且 ρ_ext^⊥<ρ_min 时禁止固化、冻结提议器（定理 11）；
(v) 七锚完备性保持（定理 12）；
(vi) 新鲜度过期、接口越界、组合失败均 fail-closed，不静默降级。

**证明**：逐条由定理 9~12 与 v5 定理 5~8 组合。Exec_v6 在 Exec_v5 上再交「组合有效 ∧ 新鲜度达标」，故只缩不涨。∎

**诚实声明**：(B8)(B9) 是经验界；ρ_ext^⊥ 依赖盲标协议被真正执行；Δ_max/δ_max 需按任务与硬件标定；外锚只能减少而非根除门博弈；长程非平稳下接口模型会漂移，需周期性重标定。

## 7. 本轮最大风险（最终确认）

**一句话**：**标注外部性的名存实亡**——长程任务中若标注者看到系统提议后再打标（确认偏差）、标注预算耗尽使后段只剩自铸证、或标注噪声/对抗投毒污染，则 ρ_ext 看似很高而 ρ_ext^⊥ 很低，外部锚退化为「把自指回路外移一层」，固化仍可缓慢博弈证书门；盲标协议 + 金标探针 + 预算预留 + 噪声建模只能把风险定量化，无法证明外部真值永远独立。
