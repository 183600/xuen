# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「惯性测量单元」×「检索增强生成」）

> 第 57 轮把先验从手工换成跨区域摊销并加共形保底，把证据从单模态换成分账对账，把人从常量换成单向有界的信任状态机；但它的风险自陈指向一个更深的盲点：**"坏先验普遍"的根源不是模型不够大，而是证据被"记住"却没有被"拿出来核对"**。三个未解问题随之浮现：**(a)** 摊销后验把所有历史压进参数，承诺时无法指出"是哪一次到访、哪一条标注、哪一版索引在支撑我"，更无法判断那条旧证据是否已经过期；**(b)** 证据质量只按"内容"评判（校准、跨模态一致），却从不按"获取条件"评判——机器人当前的运动能否让待估参数变得可观测？证据能否在时延内被找到？**(c)** 所有证据都被当作"外部证据"（探针、标注、地图），而机器人自身从不停止的高频本体感知（IMU）要么被当作纯状态估计、要么被当作免费真值——**每一步触地其实都是一次免费物理探针，但漂移与偏置会让它变成自我确认**。本轮两个灵感各补一刀：**检索增强生成**把"证据"从模型权重里重新摊开成可审计、可引用、可弃答的案例库；**惯性测量单元**把"每一步"变成受激励与锚定约束的免费探针。核心命题由"少样本可校准、跨模态可对账、个性化有界"升级为 **"可检索、可激励、可锚定的证据说可信"**——不可检索、不可激励、不可锚定的证据，必须等价于"没有证据"，而不是"证据说安全"。

核心矛盾：
- **H29（检索 vs 证据独立）**：检索回来的 k 个近邻看起来是 k 份独立支持，实际可能同源、同轨迹、同一次失败；相似不等于有效，索引过期与投毒会让错误先验获得漂亮的"引用"，检索能制造**证据通胀**。
- **H30（惯性 vs 可观测）**：IMU 永远在输出数字，因而看起来像免费证据；但偏置、漂移与激励不足会让这些数字几乎不含关于地形的信息——站着不动永远估不出刚度，而 dead-reckoning 的自信随时间增长、误差也随时间增长。
- **H31（自证 vs 外部锚）**：检索库由机器人自己的历史建成，IMU 又积分自己的运动，两者天然自指；缺少外部绝对锚时，系统会拿同一份旧信息反复给自己颁发证据，形成越查越自信的闭环，并把"没找到证据"误读成"证据说安全"。

## 0. 直觉与动机

**灵感 1（检索增强生成 → 检索是一等证据，不是生成的装饰）**
直觉：第 57 轮的摊销先验相当于"把所有经验压进脑子"，RAG 则像老工程师上岗前翻事故台账——**不把历史压没，而是在决策点把相关案例取出来对质**。但 RAG 的失败模式恰好就是证据的失败模式：检索未命中却照样作答（无证据而有结论）、索引陈旧（旧真相当新真相）、知识投毒（敌对证据）、top-k 同源（一份证据穿 k 件马甲）。因此检索必须过**五检**：覆盖（取回案例的有效包络是否盖住当前上下文格）、新鲜（是否在有效期内）、溯源（是否来自事后证伪过的判决而非假设）、冲突（取回案例互相矛盾时必须加宽而非平均）、去相关（按来源/轨迹聚类得到**有效独立样本数 k_eff**，证据贡献按 k_eff 封顶）。再加一条**引用义务**：任何承诺必须附证据 ID 集，无引用不承诺；top-1 相似度低于 τ_ret 或任一硬检查失败，就**弃答**并加宽，而不是让生成器自由发挥。

**灵感 2（惯性测量单元 → 每一步都是免费探针，但只在"被激励且被锚定"时算证据）**
直觉：IMU 是唯一永不下班的传感器，足端冲击、机体振动、打滑、姿态变化都是与地面的连续物理交互；第 57 轮的探针是刻意且昂贵的，IMU 把每个步态周期变成一次**免费探针**。但"免费得到"不等于"含信息"：要观测摩擦/刚度/偏置，轨迹必须激励对应模态——**没有激励就没有可观测性**。于是给惯性证据发一张**激励证书** ξ(τ)，由 Fisher 信息/可观测 Gram 矩阵给出；ξ<θ_ξ 时惯性通道的权重为零（不是负证据，只是无信息）。又因为 IMU 是相对的，每条惯性断言必须在漂移窗口内挂一个**绝对锚**（触地事件、地图地标、回环、零速修正）；无锚的惯性证据只能加宽信念，不能支撑不可逆接触。合起来就是"**免费探针、付费锚定**"。

**灵感 3（RAG × IMU → 双向查询环，但必须防同源共振）**
直觉：检索的查询不该只是"我在哪"，还该是"我正在做什么运动"——IMU 提供高频运动上下文，告诉检索哪一类案例包络才相关；反过来，检索提供的历史偏置/振动签名模板，才让 IMU 残差有意义。但这个互相依赖正是陷阱：若查询上下文与取回模板来自同一条轨迹，它们会互相印证。因此要求**跨源锚定**：检索证据与惯性证据只有在**来源独立**（不同到访/不同传感器）时才可互相加强，且至少一方必须挂在外部绝对锚上。这是把第 57 轮"同一模态问五遍"直接推广为"**同一段历史检索五遍**"与"**同一段运动积分五遍**"。

**灵感 4（证据门从五类到七类、必要证据集不变）**
直觉：新增 **EV-retrieval**（须过五检 + 引用 + k_eff≥k_min）与 **EV-inertial**（须过激励证书 + 锚定 + 时同步）。二者都**不得单独进入不可逆接触的必要证据集**：EV-retrieval 的贡献按 k_eff 封顶，EV-inertial 的贡献按 ξ 与锚新鲜度封顶；不可逆接触必要证据集仍是 {EV-probe* ∨ EV-margin} ∪ 佐证，检索与惯性只能用于**触发更多探询、加宽信念或加速绕行**，不能替代一次实证。这条硬约束保住了"不可逆之前宁可弃答"的不变量。

**灵感 5（PCE++ → 先问记忆、再问世界、随时问身体）**
直觉：花一次探针之前先问记忆（检索），但只有当取回案例落在其有效包络内才可用；若检索弃答，探针的 VOI 应**升高**而非降低（"记忆沉默"说明世界比记忆更陌生）。VOI 再用激励度重加权：不能激励待估参数的探针 VOI 低，能激励的优先。IMU 免费探针几乎零成本，但只在 ξ 过阈值时入账。最后加一个**锚定检查点**：不可逆动作前若 τ_anchor 内没有有效绝对锚，强制一次廉价绝对观测或改道。循环因此有三种查询：问记忆（检索）、问世界（探针）、问身体（惯性自审）；终止性由"检索只触发探针/弃答、不替代探针预算"保证。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（检索落证 RGE）** 证据库 E={(e_i,x_i,v_i,π_i,t_i,src_i)}（案例/上下文向量/判决/溯源/时间戳/来源），检索 R(x)=TopK(sim(x,x_i))，每个案例有有效包络 V_i 与有效期 T_fresh。五检：(C1) 覆盖 ⋃V_i ⊇ cell(x)，否则声明未覆盖；(C2) 新鲜 t_now−t_i≤T_fresh；(C3) 溯源 v_i 必须来自事后证伪过的判决；(C4) 冲突：取回判决不一致 ⇒ 冲突标志并加宽；(C5) 去相关：k_eff=1+Σ_i(1−max_{j<i} corr(e_i,e_j))_+（或按 src/轨迹聚类），检索证据的 log-odds 贡献封顶 k_eff·λ_max。top-1 sim<τ_ret 或硬检查失败 ⇒ 弃答。检索条件校准：ECE_ret(k_eff)≤ε_ret(k_eff)，且 ε_ret 随 k_eff 单调不增。引用义务：承诺必须附带证据 ID 集。

**定义 140（惯性激励证书 IEC）** 运动窗口 τ 内待估参数 θ=(μ,摩擦,刚度,b)，由 IMU 似然得 Fisher 信息 J_τ(θ)。激励度 ξ(τ)=λ_min(J_τ^{1/2}Σ_θ J_τ^{1/2})（或归一化可观测 Gram 的最小特征值）。ξ<θ_ξ ⇒ 惯性证据权重 w_imu=0；否则 w_imu=clip(ξ/θ_ξ,0,1)。免费探针事件 E_fp={足端冲击,打滑尖峰,振动带功率}，每个事件给特征 φ(e) 与由噪声/偏置传播的不确定度；惯性证据只能以似然形式、按 w_imu 入账。

**定义 141（惯性锚定证书 IAC）** 绝对锚集 A={地标观测,回环,零速修正,触地定位}，每锚带时间与协方差；由 Allan 方差与偏置随机游走得漂移界 D(Δt)。惯性断言"已锚定"⇔∃a∈A：t_now−t_a≤τ_anchor 且 D(t_now−t_a)≤D_max。未锚定的惯性证据只可加宽信念，不可支撑承诺；不可逆检查点若无有效锚，强制一次锚定探针或改道（硬规则）。

**定义 142（案例化证据库 CEM）** E 的版本化索引，含有效包络、有效期与插入门（必须有溯源与判决）；不可信来源进**隔离区**（投毒检疫）；事后证伪时反向标记所有依赖该证据的检索条目为 stale 并降权（承接第 57 轮回溯）；索引多副本一致性与过期/删除策略；审计日志。检索同时返回**负证据**（相似上下文下曾经失败的案例）。

**定义 143（检索-激励证据门 FSE++ 与证书 J_r）** 七类：EV-probe*/EV-visit/EV-margin/EV-xmodal/EV-human/EV-retrieval/EV-inertial。EV-retrieval 须过五检+引用+k_eff≥k_min；EV-inertial 须 ξ≥θ_ξ+已锚定+时同步误差≤τ_sync。不可逆接触必要证据集仍为 {EV-probe*∨EV-margin}∪佐证，检索与惯性不得单独入集。J_r 在 J_p 上增 retrieval_log、k_eff、excitation_log、anchor_log、index_version、poisoning_log。

**定义 144（探-诺-演++ 算子 PCE++）** 每检查点：⓪锚定检查（不可逆前若无锚→强制锚定探针/改道）；①检索记忆：若 grounded 则更新信念/形成查询，若 conflict 则加宽，若 abstain 则标记 memory-silent 并抬高探针 VOI；②第 57 轮元推断与跨模态融合；③IMU 免费探针按 w_imu(ξ) 入账；④刻意探针按 VOI_exc=VOI_元悲观·g(ξ) 排序（能激励者优先）；⑤承诺 ⇔ 证据门过 ∧ 已锚定；否则绕行/降档/L2 协商/弃答/安全停。预算为 k_p+k_cons 次探针 + O(log|E|) 检索，四态外增"弃答"终止态。

## 2. 关键算法伪代码（完整版见产物区）

```python
def retrieve_grounded(x, E, idx, conf):            # IP-139/142
    hits = idx.topk(x, k=K_RET)
    if not hits or sim(x, hits[0]) < tau_ret:      # 检索未命中 → 弃答
        return Ground(abstain=True, reason='retrieval_miss')
    hits = [h for h in hits if fresh(h, t_now) and h.v in VERIFIED]
    if not covers(hits, cell(x)):  return Ground(abstain=True, reason='uncovered')
    if conflict(hits):             return Ground(conflict=True, widen=True)
    k_eff = effective_count(hits)                  # 去相关：按来源/轨迹聚类
    return Ground(hits=hits, k_eff=k_eff, eps=eps_ret(k_eff))

def inertial_evidence(imu_win, theta, anchors):    # IP-140/141
    xi = excitation(imu_win, theta)                # Fisher/可观测 Gram 最小特征值
    if xi < theta_xi: return Inertial(w=0.0)       # 无激励 → 无信息，不是负证据
    a = nearest_anchor(anchors, t_now)
    if a is None or t_now - a.t > tau_anchor or drift_bound(t_now - a.t) > D_max:
        return Inertial(w=xi / theta_xi, anchored=False)  # 只可加宽
    return Inertial(w=xi / theta_xi, anchored=True, anchor_id=a.id)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| RGE | O(log\|E\|+K·d) | O(K·d) | 五检诚实、k_eff 不虚增、弃答可触发 |
| IEC | O(d_imu·d_θ) | O(d_θ²) | ξ 不高于真实 Fisher 下界（保守） |
| IAC | O(\|A\|) | O(\|A\|) | 漂移界诚实、锚新鲜度可查 |
| CEM | 插入/失效 O(log\|E\|) | O(\|E\|) | 版本一致、投毒隔离、回溯完整 |
| FSE++ | O(\|σ\|) | O(\|σ\|) | 检索/惯性不入不可逆必要集 |
| PCE++ | O(\|CP\|·(K log\|E\|+k_p·C_VOI)) | O(\|V\|+\|E\|) | 弃答终止、锚定检查先于承诺 |

**正确性定理（REACS 概要）**：在 A33–A40 上新增 (A41) 检索健全：五检诚实、k_eff 不虚增、检索条件 ECE_ret≤ε_ret 且弃答可触发；(A42) 激励证书诚实：ξ(τ) 不高于真实 Fisher 信息下界；(A43) 锚定界诚实：D(Δt) 覆盖真实漂移且锚时间同步误差≤τ_sync；(A44) 检索/惯性接口时延有界。则：(i) 承诺失效率 ≤δ_f+ε_meta(k)+ε_ret(k_eff)+δ_probe+ε_h+δ_ood·α_conf+δ_xm·1[L1]+δ_imu·1[ξ≥θ_ξ]+P(drift>D)；(ii) **不可得即不可承诺**：检索弃答、无激励、无锚三者任一为真时承诺被拒或强制加宽，绝不把"没找到/测不到"转成"安全"；(iii) 检索与惯性只能经"提供可溯源证据""触发更多探询""加宽/改道/弃答"三条通道影响系统，不存在升险路径；(iv) PCE++ 在 k_p+k_cons 次探针与 O(log|E|) 检索内终止于 {承诺,绕行,L2协商,安全停,弃答}。

## 6. 本轮最大风险

**一句话**：本轮把"证据"从内容属性扩展成"可检索/可激励/可锚定"的获取属性，最大风险是**检索库与惯性推算同源自证**——索引由机器人自己的历史建成、IMU 又积分自己的运动，一旦外部绝对锚失效，系统会用同一份旧信息反复给自己颁发证据，越查越自信、越走越偏；必须以 k_eff 去相关、引用义务、ξ 证书与"无锚不得承诺"四条硬护栏，把"没检索到/测不到"一律当作"不可承诺"而非"安全"。

## 2. 关键算法伪代码

### IP-139 RGE（检索落证：五检 + 引用 + 弃答）

```python
def retrieve_grounded(x, E, idx, cell_x):
    hits = idx.topk(x, k=K_RET)
    if not hits or sim(x, hits[0].x) < tau_ret:
        return Ground(abstain=True, reason='retrieval_miss')      # 无命中不回答
    hits = [h for h in hits if fresh(h, t_now) and h.v in VERIFIED]
    if not hits:
        return Ground(abstain=True, reason='stale_or_unverified')
    if not covers(hits, cell_x):                                  # C1 覆盖
        return Ground(abstain=True, reason='uncovered_cell')
    if conflict(hits):                                            # C4 冲突不加权平均
        return Ground(conflict=True, widen=True, hits=hits)
    k_eff = effective_count(hits)                                 # C5 去相关
    logodds = min(k_eff * LAMBDA_MAX, sum(h.weight for h in mmr(hits)))
    return Ground(hits=hits, k_eff=k_eff, logodds=logodds,
                  eps=eps_ret(k_eff), cite=[h.id for h in hits])

def effective_count(hits):                                        # 同源/同轨迹只算一份
    clusters = cluster_by(hits, key=lambda h: (h.src, h.trajectory_id))
    return 1.0 + sum((1.0 - max_corr(h, c)) for c in clusters for h in c[1:])
```

### IP-140 IEC（惯性激励证书 + 免费探针）

```python
def inertial_free_probe(imu_win, theta, imu_model):
    events = detect_events(imu_win)                 # 足端冲击/打滑尖峰/振动带
    J = fisher_information(imu_win, theta, imu_model)
    xi = lambda_min(sqrtm(J) @ Sigma_theta @ sqrtm(J))
    if xi < theta_xi:
        return Inertial(events=events, w=0.0, xi=xi)  # 有读数 ≠ 有信息
    w = min(1.0, xi / theta_xi)
    like = event_likelihood(events, imu_model)        # 带偏置/噪声传播
    return Inertial(events=events, w=w, xi=xi, like=like)
```

### IP-141 IAC（惯性锚定证书）

```python
def inertial_claim(claim, anchors, imu_model):
    a = nearest(anchors, claim.t)
    if a is None:
        return Claim(claim, mode='widen_only', reason='no_anchor')
    dt = claim.t - a.t
    drift = drift_bound(dt, imu_model)               # Allan 方差 + 偏置随机游走
    if dt > tau_anchor or drift > D_max:
        return Claim(claim, mode='widen_only', reason='anchor_stale')
    return Claim(claim, mode='commit_capable', anchor=a.id, drift=drift)
```

def cem_insert(E, idx, e):

```python
def fse_v3_gate(c, M, persona, ood_reg, ret, iner):
    if c.ev == 'EV-retrieval':
        ok = (not ret.abstain) and (not ret.conflict) and \
             ret.k_eff >= K_MIN and covered(ret, c.region) and \
             fresh_all(ret) and all(h.v == 'verified' for h in ret.hits)
        if ret.conflict: return ('reject', 'retrieval_conflict', c)
    elif c.ev == 'EV-inertial':
        ok = iner.xi >= theta_xi and iner.anchored and iner.sync_err <= tau_sync
    elif c.ev == 'EV-probe*':
        ok = (c.inf.cls == 'ID' and c.inf.ece_k <= eps_meta(c.k)) or \
             (c.inf.cls == 'OOD' and c.region in ood_reg.certified)
    elif c.ev == 'EV-xmodal':
        ok = c.level == 'L1' and c.indep_declared and D(c.region) <= theta_D
    elif c.ev == 'EV-human':
        ok = persona[c.op].auth >= 'A1' and c.corrob >= quarantine_exit(persona[c.op].auth)
    elif c.ev in ('EV-visit', 'EV-margin'):
        ok = round57_checks(c, M)
    else:
        return ('reject', 'no_evidence_class', c)
    if not ok:
        return ('reject', 'evidence_insufficient', c)
    return ('ok', c)

def necessary_set_v3(c):
    if c.irreversible and c.ev in ('EV-retrieval', 'EV-inertial'):
        return ('reject', 'access_evidence_not_sufficient', c)   # 硬禁令
    return ('ok', c)
```

### IP-144 PCE++（检索-激励-锚定闭环）

```python
def probe_commit_evolve_plus_plus(x0, M, task, budget, consent, personas, E, idx):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        if not anchored(cp, t_now):                          # ⓪ 锚定检查
            if not spend_anchor_probe(cp, budget):
                route = reroute(M, cp, risk_model) or route
                if route is None: return safe_stop(cp, 'no_anchor')
                continue
        ret = retrieve_grounded(ctx(cp), E, idx, cell(cp))   # ① 先问记忆
        if ret.conflict: M.widen(cp.region, ret)
        memory_silent = ret.abstain
        if not ret.abstain:
            M.update(cp.region, ret.logodds)                 # 可溯源、k_eff 封顶
        inf = meta_few_shot_infer(M, cp.region, M.obs[cp.region], meta)   # ② 第 57 轮
        M.b[cp.region] = inf.post if inf.cls == 'ID' else worst_in(inf.belt)
        iner = inertial_free_probe(cp.imu_win, theta(cp), imu_model)      # ③ 免费探针
        if iner.w > 0:
            M.b[cp.region] = bayes_update(M.b[cp.region], iner.like, w=iner.w)
        sigma = foothold_schedule(x0, cp, M); R = schedule_risk(sigma, M)
        while select_gait(R) == 'halt' and budget.probes_left > 0:
            cands = admissible_probes(cp, M, F_abs)
            if not cands: break
            p = argmax(cands, key=lambda q: voi_exc(q, M, inf, iner) - cost(q))
            if voi_exc(p, M, inf, iner) < theta_voi: break
            M, _, D = xmodal_fuse(M, cp.region, execute_probe(p, cap=F_abs))
            budget.spend(p)
            sigma = reselect_footholds(x0, cp, M); R = schedule_risk(sigma, M)
        g = select_gait(R)
        if g != 'halt' and fse_v3_gate(core_contact(cp), M, personas,
                                       ood_reg, ret, iner)[0] == 'ok' \
           and anchored(cp, t_now):
            sched.append(commit(sigma, g)); log.append(tag(cp, ret, iner)); continue
        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, M)) != 'halt': route = alt; continue
        if memory_silent and budget.exhausted:
            return abstain(cp, 'memory_silent_and_probe_budget_exhausted')
        return negotiate_or_stop(cp, M, sigma, R, consent, tau_int=tau_int(personas.active.auth))
    return sched, log, M

def voi_exc(q, M, inf, iner):
    base = voi_meta_pessimistic(q, M, inf)                   # 第 57 轮悲观元 VOI
    gain = excitation_gain(q, theta(q), iner.xi)             # 该探针能激励多少
    return base * (1.0 + (1.0 - gain))                       # 越不能激励越不值
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| RGE | O(log\|E\|+K·d) | O(K·d) | 五检诚实、k_eff 不虚增、弃答可触发（A41） |
| IEC | O(d_imu·d_θ+d_θ³) | O(d_θ²) | ξ 不高于真实 Fisher 下界（A42） |
| IAC | O(\|A\|) | O(\|A\|) | 漂移界覆盖真实漂移、锚时同步（A43） |
| CEM | 插入/失效 O(log\|E\|) | O(\|E\|) | 版本一致、投毒隔离、回溯完整 |
| FSE++ | O(\|σ\|) | O(\|σ\|) | 检索/惯性不入不可逆必要集 |
| PCE++ | O(\|CP\|·(K log\|E\|+k_p·(C_VOI+d_φ))) | O(\|V\|+\|E\|) | 弃答终止、锚定先于承诺（A44） |

**正确性定理（Retrieval-Excitation-Anchored Calibrated Soundness, REACS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 检索健全：五检诚实、k_eff 不虚增、ECE_ret(k_eff)≤ε_ret(k_eff) 且 ε_ret 随 k_eff 单调不增、弃答可触发；**(A42)** 激励证书诚实：ξ(τ) 不高于真实 Fisher 信息下界；**(A43)** 锚定界诚实：D(Δt) 覆盖真实漂移、锚时间同步误差≤τ_sync；**(A44)** 检索/惯性接口时延有界且时间戳可信。则：

1. **可溯源承诺健全性**：承诺失效率
   ≤ δ_f + ε_meta(k) + ε_ret(k_eff) + δ_probe + ε_h(w_max) + δ_ood·α_conf + δ_xm·1[L1] + δ_imu·1[ξ≥θ_ξ] + P(drift>D)。
2. **不可得即不可承诺**：检索弃答/未覆盖/冲突未解、ξ<θ_ξ、无有效锚三者任一成立时，承诺被拒或强制加宽；系统不会把"没找到/测不到"转成"安全"。形式化地，若证据门通过，则必要集必含一次实证探针或裕度证据，且承诺时至少一个绝对锚有效。
3. **获取条件单调性**：检索与惯性只能经三条通道影响系统——(a) 提供带溯源且 k_eff 封顶的证据；(b) 触发更多探询（memory-silent 抬高 VOI）；(c) 加宽/改道/弃答；不存在升险路径。EV-retrieval/EV-inertial 的硬禁令保证其不能替代不可逆接触的实证。
4. **终止性**：检索为 O(log|E|) 且不消耗探针预算；PCE++ 在 k_p+k_cons 次探针内终止于 {承诺, 绕行, L2 协商, 安全停, 弃答}。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + ε_ret(k_eff) + δ_probe + ε_h
                   + δ_ood·α_conf + δ_xm·1[L1] + δ_imu·1[ξ≥θ_ξ] + P(drift>D))
             − P(索引陈旧未检出) − P(投毒未被隔离) − P(时同步失效)
             − P(锚点缺失未检出) − P(弃答路径失效)
```

关键：**检索给可审计性、k_eff 给独立性、ξ 给可观测性、锚给外部真值**；四者共同把第 57 轮的"坏先验普遍"进一步拆成"坏先验不可检索/不可激励/不可锚定就不可承诺"；检索与惯性都是**获取条件**而非内容质量，因此必须与内容质量（校准、跨模态一致）正交地各设一道门。

## 6. 本轮最大风险

**一句话**：本轮把"证据"从内容属性扩展成"可检索/可激励/可锚定"的获取属性，最大风险是**检索库与惯性推算同源自证**——索引由机器人自己的历史建成、IMU 又积分自己的运动，一旦外部绝对锚失效，系统会用同一份旧信息反复给自己颁发证据，越查越自信、越走越偏；必须以 k_eff 去相关、引用义务、ξ 证书与"无锚不得承诺"四条硬护栏，把"没检索到/测不到"一律当作"不可承诺"而非"安全"。
