# 第 66 轮（承接第 65 轮「VISTA 故障可归因安全时序闭环」IP-214~223；灵感循环第 3 轮；本轮灵感：「用户测试」×「大语言模型」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述的最大风险是：归因依赖**有限假设集**与**失效独立性**；真实故障常是未知类型的组合，透明/镜面/对抗 patch 会让视觉与几何共享同一 OOD 失效源，FIR 会把未知复合故障强行归入最近假设、只膨胀错误的球，系统反而因「已经归因」更自信地继续执行。本轮不再增加第 6 个传感器，而是追问三个更上游的问题：**假设集从哪来？谁有权把一个新故障写进证书？未知时系统敢不敢承认不知道？** 本轮核心命题是：
>
> **把「闭集故障分类」升级为「开放世界故障假设生命周期」：用大语言模型提出可证伪的新假设与判别测试（abduction），用用户测试在物理世界与人类语义中筛选、标注与验收（grounding），系统只对「被物理判别测试确认过的假设」发证书，并保留显式的未知质量 H_unk；未知时只做保守降级，绝不强行归因。**

## 0. 直觉与动机

**灵感 1（大语言模型 → 开放世界的假设提出器，而不是真值）**
直觉：第 65 轮的 ℋ 只有 6 个手写假设。真实世界的新故障——「湿滑杯面 + 软接触模型 + 力漂移」的复合、「线缆缠绕导致接触点歧义」、「用户语义把『轻放』理解成『压紧』」——都不在表里；闭集后验只能把新故障投影到最近的旧假设上。LLM 的真正价值不是当分类器，而是当 **abduction engine（溯因引擎）**：读代码、日志、手册、失败案例和用户抱怨，提出「还有哪种坏法」，并把它写成**可检验的预测**（在哪个阶段、哪个通道、往哪个方向偏）与一个**能把它和现有假设区分开的测试**。但必须诚实：LLM 没有物理接地、会幻觉、会被观测中的文本 prompt injection 欺骗，所以它输出的是 **proposal**，不是 posterior；它不能自我认证，也不能直接驱动执行器。**LLM 扩大「想得到」的集合，但不扩大「已证实」的集合。**

**灵感 2（用户测试 → 把假设钉在物理世界与人类语义上）**
直觉：LLM 可以编出 100 个故障故事，但哪个是真的、哪个测试真的能区分、用户是否看得懂，只有在真实设备上由人回答。用户测试在这里有三个角色：(i) **red-team 发现**——用户故意制造 OOD 条件，贡献系统没想到的故障；(ii) **判别测试的执行与裁决**——用户跑测试、给物理结果贴标签，提供闭集之外的接地数据；(iii) **解释评估与信任校准**——用户判断系统「为什么这么归因」是否可信，暴露过度自信与过度不信任。用户不是廉价标注员，而是开放世界的「人肉传感器」；但用户有偏、会锚定在 LLM 的解释上、覆盖不全，所以用户测试同样只是**可错证据**。

**灵感 3（用户测试 → 测试驱动准入：想得到 ≠ 可认证）**
直觉：第 65 轮允许任何一个 ℋ 里的假设触发定向膨胀。开放世界里这很危险：LLM 新提出的假设若没有判别测试，凭什么让它改变安全策略？于是引入苏格拉底式原则——**知识只能通过「能区分真假的测试」被准入**。一个假设要进入认证集，必须存在一个物理可执行、力/形变安全、结果可由用户核验的测试，使其与现有假设的互信息超过阈值；否则它只能停留在「影子集」，只贡献未知质量，不得触发定向处置。这把「LLM 说得像」与「物理上可分」严格分开。

**灵感 4（未知质量 H_unk → 不强行归因，未知是一等公民）**
直觉：第 65 轮的错误不是「分类器不够准」，而是**没有「以上都不是」这个选项**。本轮把未知显式建模：用 conformal novelty 给每个观测一个「它不像任何已认证假设」的 p 值；p 值足够小或后验不集中时，系统进入 `H_unk` 状态。`H_unk` 不是要「处理」的假设，而是一种**认识论状态**：不定向膨胀任何单一球，改为联合保守膨胀 + 缩短前缀 + safe_idle/compliant retreat + 向用户发起判别测试请求。也就是说，**承认不知道本身是一种安全动作**。

**灵感 5（三灵感合流 → SOCRATES：Semantic Open-world Certification via Reflective Attribution, Test-driven Evidence & user Studies，语义开放世界安全认证闭环）**
闭环：VISTA 现有归因 → LLM 溯因提出新假设与判别测试（LHG）→ 可证伪性/安全/模式过滤 → 影子集 → 测试驱动准入（TDA）→ 用户 red-team 执行与裁决（UTC）→ 假设生命周期（HLC：shadow→candidate→certified→deprecated）→ 开放世界后验与未知门（FIR-O）→ 未知时保守回退与主动查询（RSC-O）→ 证据化解释与信任校准（XAI）→ 证书 J_open。第 65 轮回答「哪一层坏了」；SOCRATES 回答「**我们有没有资格说它坏了、以及我们漏掉了什么**」。

**灵感 6（VISTA / GRIP 组件的原位升级）**
- **FIR → FIR-O**：闭集 6 假设升级为「认证集 + 影子集 + H_unk」；未知时不做定向处置。
- **AFA → UTA**：主动探针不再只由系统选，而是 LLM 提议、用户执行/裁决；判别目标仍是降低假设熵，但证据来自物理测试而非模型想象。
- **RSC-V → RSC-O**：新增 `r_unk` 与未知回退；未知时不膨胀单一球，改为联合膨胀并降低 k*。
- **CSP-V → CSP-O**：规划器可插入 `user_probe`、`red_team_probe`、`shadow_test` 元技能；影子假设不得作为块边。
- **AIC-V → AIC-O**：干扰集增语义注入（观测/日志/用户报告中的对抗文本）与用户偏置（锚定、非代表性、故意破坏）。
- **J_vista → J_open**：证书增 unknown_mass、novelty_pvalue、hypothesis_provenance、test_ids、user_coverage、grounding_conflict、trust_calibration_error、llm_audit_hash。
- **实时流不变**：LLM 与用户测试只在离线/语义环；实时流仍只做阶段化残差采集、安全前缀执行与早停，零学习写、零 LLM 调用、零直接致动。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（SOCRATES 闭环）**：SOCRATES = (VISTA, LHG, UTC, TDA, HLC, FIR-O, UTA, RSC-O, CSP-O, XAI, AIC-O, J_open)。定位：VISTA 的「开放世界假设治理」升级。不变式：**LLM 与用户只能提出假设、测试、解释和标签，不能写入实时安全路径、不能直接致动、不能自我签署证书；只有被物理判别测试准入的假设才能触发定向处置。**
- **定义 234（开放世界故障假设对象）**：H=(id, ℓ_H, s_H, t_H, prov, status)。ℓ_H 为自然语言描述；s_H:(phase,channel)→预测偏差的符号/区间（与第 65 轮 ρ 同为 15 维签名模板）；t_H 为建议的判别测试及 H / ¬H 下的预测结果；prov 为来源（LLM 模型哈希、prompt、检索文档、用户报告 id）；status∈{shadow,candidate,certified,deprecated}。**缺少 s_H 或 t_H 的假设不可入池**——先过滤「不可证伪的漂亮话」。
- **定义 235（LLM 假设生成器 LHG）**：q_LLM(H|C) 在上下文 C=(代码、日志、手册、历史 ℋ、用户报告) 上采样 k 个候选；输出必须通过类型化 schema、可证伪性过滤器与安全过滤器。LLM 只提供 proposal 分布，不提供似然；p(ρ|H) 仍由离线故障注入/用户测试数据拟合。定义幻觉率 ε_LLM 为「被物理测试证伪的提案比例」，作为证书审计量而非可忽略项。
- **定义 236（用户测试协议与用户测试分布）**：一次用户测试 U=(protocol, user, device, execution, observation, label, narrative, confidence)。红队模式下用户主动搜索 OOD 条件；裁决模式下用户执行 t_H 并标注物理结果。用户报告的自然语言 narrative 可由 LLM 转成签名特征，但**标签与物理结果必须来自测量或用户直接观察**。用户测试分布 D_U 是开放世界 OOD 条件的一个有偏采样；用评分者一致性 κ_U 与覆盖估计显式量化其偏差。
- **定义 237（测试驱动准入 TDA）**：对候选 H_i 与认证集 ℋ_cert，选择判别测试
  t* = argmax_t I(H_i; ρ(t) | ℋ_cert)，
  s.t. 预测 f_n≤f_safe、形变≤ε_strain、时长≤T_max、结果可由用户核验、t 不越过不可逆视界 m。准入条件：I*≥δ_disc，且在 n 次物理测试中观测到 H_i 与竞争假设的可分性，并有人类签核。无判别测试的假设只能留在影子集，仅计入 H_unk 质量。
- **定义 238（开放世界后验与未知质量）**：对认证集用校准似然得 P(H|ρ)∝p(ρ|H)P(H)。用 conformal novelty 计算
  p_unk(ρ)=(1+#{i: A_i≥A(ρ)})/(n_cal+1)，
  A 为对认证假设的最大非一致性分数。定义未知质量
  P(H_unk|ρ)=max(p_unk(ρ), 1−Σ_{H∈ℋ_cert}P(H|ρ))，
  再与认证后验重归一化。若 p_unk≤α_nov 或 max_H P(H|ρ)<1−δ_fi，则进入 `H_unk`。**H_unk 永远不能被压成 0，只能因新的物理判别测试而缩小。**
- **定义 239（新颖性分数）**：n(ρ)=σ(w_s·p_unk + w_e·d_sem + w_g·d_ground)，其中 d_sem 为用户报告与已知故障描述的嵌入距离，d_ground 为 LLM 预测签名与用户观测签名的差异。新颖性是一等证据而不是要最小化的残差；n(ρ)≥τ_nov 时禁止定向归因。
- **定义 240（假设生命周期 HLC）**：shadow→candidate 需通过 schema、可证伪性、t_H 安全性；candidate→certified 需 TDA 准入 + n 次物理测试 + 人类签核 + 似然校准 + AIC-O 覆盖；certified→deprecated 由漂移、反例或用户报告触发。**禁止 shadow→certified 直通**；deprecated 保留审计链，不删除历史。
- **定义 241（用户测试覆盖与未发现故障估计）**：把用户测试视为对故障条件类的有偏采样，用 capture-recapture（Chao1）估计未发现类数
  Ŝ_unseen = f₁²/(2f₂)（f₂>0；否则用偏差校正形式），
  覆盖率 cov=|discovered|/(|discovered|+Ŝ_unseen)。当未发现类数的上置信界 <δ_cov 时停止测试战役。这把「用户测不完」从一句免责声明变成一个可报告的统计量。
- **定义 242（LLM-用户接地冲突）**：d_ground(H)=D(s_H, ŝ_user)，ŝ_user 为由用户测试标签与 narrative 构造的经验签名。d_ground>τ_g 时置 `grounding_conflict`：不得自动准入，必须复测或人工复核。该机制同时捕捉 LLM 幻觉与用户误解。
- **定义 243（证据化解释与信任校准）**：解释 E=(posterior, top discriminating evidence, test_ids, provenance, uncertainty, unknown_mass)。每条解释性断言必须引用签名通道、测试 id 或来源，禁止「无出处叙事」。用户研究测量信任 τ_user 与经验正确率的校准误差 CE=|τ_user−acc|；J_open 要求 CE≤ε_trust。**可解释性在本方案里不是装饰，而是防止过度信任导致误用的安全属性。**
- **定义 244（开放世界安全回退）**：H_unk 时不做定向膨胀；维护专用 r_unk，令联合半径 r=√(r_geo²+r_force²+r_model²+r_unk²)，k*←min(k*,k_safe_unknown)，执行 safe_idle 或 compliant retreat，并向用户发起「请执行下一个判别测试」的查询。未知不是故障假设，而是**必须被保守承接的认识论状态**。
- **定义 245（开放世界证书 J_open）**：J_open=(J_vista, unknown_mass, novelty_pvalue, hypothesis_provenance, test_ids, user_coverage, grounding_conflict, trust_calibration_error, llm_audit_hash, aic_o_ver)。Valid ⇔ Valid(J_vista) ∧ (归因到已认证假设 ∨ 显式 H_unk 并已保守回退) ∧ 未用影子假设做定向处置 ∧ 接地冲突已解决或已降级 ∧ LLM 输出 schema 合法且带 provenance ∧ 实时路径无 LLM/用户写入。
- **定义 246（语义防火墙）**：LLM 只能读只读上下文、输出类型化 schema、不能调用致动器、不能改写 ρ/证书/安全阈值；对观测中的文本做 prompt-injection 过滤，并与物理信号交叉校验。所有输出带模型哈希、prompt 哈希与检索来源，写入不可变审计日志。**LLM 可以提问，但不能签字。**
- **定义 247（AIC-O 语义/用户对抗认证）**：ℰ_O=ℰ_V×ℰ_sem×ℰ_user。ℰ_sem 含观测/日志/用户报告中的注入文本、对抗性自然语言、投毒报告；ℰ_user 含锚定、评分者不一致、非代表性采样、故意 red-team。认证指标增「强制归因率」「未知诚实度」「解释校准误差」，并要求共因/未知时只判 unknown、不强行归因。
- **定义 248（SOCRATES 算子）**：离线/语义环 [日志/代码/手册/用户报告→LHG 溯因→schema/可证伪/安全过滤→影子集→TDA 选判别测试→用户执行与裁决→HLC 准入/淘汰→似然校准→AIC-O]；在线语义环 [VISTA 残差与归因→conformal 未知门→认证后验或 H_unk→RSC-O 回退→XAI 解释→J_open]；实时环 [锚点读→阶段残差→CSC 早停→前缀派发→J_open 构建]，**实时环禁止 LLM 与用户写入**。

## 2. 关键算法骨架

```python
# 离线/语义环：LLM 溯因 → 过滤 → 影子集
props = lhg.propose(context=logs + code + manuals + user_reports, k=K)
shadow = [H for H in props if schema_ok(H) and falsifiable(H) and safe_test(H.t_H)]

# TDA：只有能区分真假的假设才可进入认证集
for H in shadow:
    t, ig = tda.best_discriminating_test(H, H_cert, f_safe, m)
    if ig < delta_disc:
        H.status = 'shadow'          # 只计入 H_unk 质量，不得定向处置
        continue
    trials = user_test.run(t, n=n_trials)      # 用户执行 + 物理标签
    if trials.separable and human_signoff(H, trials):
        H.status = 'candidate' -> 'certified'
        H_cert.add(H); calibrate_likelihood(H, trials)

# 在线语义环：开放世界后验
post_cert = {h: lik[h](rho) * prior[h] for h in H_cert}
p_unk = conformal_novelty(rho, cal_scores)
P_unk = max(p_unk, 1 - normalize(post_cert).sum())
if p_unk <= alpha_nov or max(post_cert) < 1 - delta_fi:
    state = 'H_unk'
    balls.r_unk = kappa_unk * max(balls.r_geo, balls.r_force, balls.r_model)
    k_star = min(csc.certified_prefix(A, post_cert, m, alpha_chunk), k_safe_unknown)
    safe_idle_or_retreat(); request_user_probe(lhg.suggest_test(rho))
else:
    directed_demote(argmax(post_cert), balls)

# XAI：解释必须带证据与未知质量
explain = xai.render(post_cert, P_unk, evidence=top_signature_channels,
                     tests=test_ids, provenance=prov, uncertainty=entropy(post_cert))
assert trust_calibration_error(explain, user_study_heldout) <= eps_trust
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（未知门的第一类控制）**：在认证假设内可交换的校准样本上，conformal p 值满足 P(p_unk≤α_nov | H∈ℋ_cert)≤α_nov；因此「把已知误判为未知」的代价可控。对真正的新故障，若其非一致性分数相对已知分布有间隙 Δ>0，则 n_cal 次校准后漏检概率 ≤ exp(−n_cal·Δ²/2)（Hoeffding 型）。未知门不是万能的，但它把「未知检测」从拍脑袋阈值变成有覆盖语义的统计决定。
- **引理 10（TDA 的可分性与样本复杂度）**：若判别测试满足 I(H_i;ρ(t))≥δ_disc，则 n 次独立物理测试后的两两误归因概率 ≤ exp(−n·δ_disc)（Sanov/Chernoff）。故达到 ε 误判需 n≥log(1/ε)/δ_disc。δ_disc 过低会让「准入」失去意义；δ_disc 过高会让太多假设永远留在影子集——这是覆盖率与可用性的显式权衡。
- **定理 9（SOCRATES 端到端开放世界安全）**：在 A94–A98 下，Valid(J_open) ⇒ 要么归因到已认证假设并继承 VISTA 的安全保证，要么进入 H_unk 并执行联合保守回退；强制错误归因概率 ≤ α_nov + exp(−n·κ_fi/2) + ε_cal + ε_ground。第 65 轮的隐藏假设「故障必在有限集内」被替换为可审计的未知质量。
- **定理 10（用户测试的发现上界与停止准则）**：在类可交换、采样有偏但可重复的假设下，Chao1 给出未发现类数的估计 Ŝ_unseen；当其上置信界 <δ_cov 时，继续增加同类用户测试的边际发现率低于阈值。故用户测试的停止不是预算耗尽，而是**统计上「再测也学不到新故障类」**。该界依赖采样模型，不能当作绝对保证。
- **命题（LLM 不能替代测试）**：若 LLM 提案的假阳性率为 ε_LLM>0 且不经物理判别测试就准入，则期望误认证假设数随提案数线性增长；TDA 是恢复 soundness 的必要条件。LLM 能提高 recall，但不能单独提高 precision。
- **实时性**：LLM、用户测试、HLC、TDA、AIC-O 全在离线/语义环；实时环只增未知门查表（<0.01ms）与 J_open 字段写入（<0.01ms），仍 ≤2.5ms（A93 不变）。**开放世界治理不进入实时控制回路。**

## 5. 本轮最大风险

**一句话**：SOCRATES 的最大风险是「LLM 提出假设、用户被 LLM 的解释锚定、系统再用『已测试』给自己发证书」三者形成自我确认回路——它覆盖的是**被想得到且被现有用户群体测得到**的故障，而不是真实开放世界的故障；更糟的是，H_unk 可能被调参压小以维持可用性，或膨胀成永远 safe_idle 的甩锅状态，使「承认不知道」从安全机制退化为认证表演。

## 2. 形式化定义（完整版）

**定义 233（SOCRATES 闭环）** SOCRATES 是 VISTA 的「开放世界假设治理」升级：保留第 65 轮 VISTA 的语义/实时双流骨架与全部安全机制，在其上游挂载 LHG（LLM 溯因）、UTC（用户测试语料）、TDA（测试驱动准入）、HLC（假设生命周期），并把 FIR→FIR-O、AFA→UTA、RSC-V→RSC-O、CSP-V→CSP-O、AIC-V→AIC-O、J_vista→J_open 原位升级。不变式：**LLM 与用户只能提出假设、测试、解释与标签，不能写入实时安全路径、不能直接致动、不能自我签署证书；实时路径零 LLM 调用、零学习写操作、零用户写入。**

**定义 234（开放世界故障假设对象）** 一个假设 H=(id, ℓ_H, s_H, t_H, prov, status)，其中：
- ℓ_H 为自然语言描述（如「湿滑杯面使接触模型从刚性变为低摩擦软接触」）；
- s_H 把每个阶段 p∈{approach,touch,load} 与通道 c∈{e_vis,e_force,e_torque,d_chunk,u_chunk} 映射到预测偏差的符号与区间，即 15 维签名模板；
- t_H 为建议的判别测试，必须同时给出「若 H 为真，ρ(t_H) 落在哪个区域」与「若 H 为假，落在哪个区域」；
- prov 为不可变来源（LLM 模型哈希、prompt 哈希、检索文档 id、用户报告 id）；
- status 为生命周期状态。
**可证伪性要求**：s_H 至少在一个阶段-通道给出方向性预测，且 t_H 必须物理可执行；否则 H 不可入池。该要求直接过滤「听起来合理但无法检验」的 LLM 幻觉。

**定义 235（LLM 假设生成器 LHG）** 给定只读上下文 C=(code, logs, manuals, ℋ_cert, user_reports)，LLM 采样 k 个候选 H~q_LLM(·|C)。LHG 的输出必须：
1. 通过类型化 schema（字段缺失即拒绝）；
2. 通过可证伪性过滤器（定义 234）；
3. 通过安全过滤器（t_H 的预测力/形变不超 f_safe、ε_strain，且不越过不可逆视界 m）；
4. 带 provenance 与置信自评（自评只作排序，不作证据）。
**LLM 不产生 p(ρ|H)、不产生后验、不写证书。** p(ρ|H) 由故障注入 + 用户测试数据离线拟合；LLM 的价值是扩大假设的 support，而非提高单假设的 veracity。定义幻觉率 ε_LLM = |{H: 物理测试证伪 H}| / |{H: 进入物理测试}|，作为 AIC-O 与 J_open 的审计量。

**定义 236（用户测试协议与用户测试分布）** 一次用户测试 U=(protocol, user, device, execution, observation, label, narrative, confidence)：
- protocol 指定任务、初始条件、允许的干预与安全边界；
- user 带经验水平与偏置标签（新手/专家/红队）；
- execution/observation 为设备日志与用户直接观察；
- label 是物理结果（成功/失败/异常类型），**不得只由 LLM 生成**；
- narrative 是用户自然语言描述，可由 LLM 转成经验签名 ŝ_user，但转换结果必须与 label 交叉校验；
- confidence 为用户自评，用于信任校准而非真值。
用户测试分三模式：`red_team`（主动搜索 OOD，贡献新故障类）、`adjudicate`（执行 t_H 并裁决）、`evaluate_explanation`（评估解释与信任）。用户测试分布 D_U 是开放世界 OOD 条件的有偏采样；用 κ_U 量化评分者一致性，用定义 241 量化覆盖偏差。

**定义 237（测试驱动准入 TDA）** 对候选 H_i 与认证集 ℋ_cert，判别测试为
t* = argmax_{t∈𝒯} I(H_i; ρ(t) | ℋ_cert)，
约束：预测 f_n≤f_safe、形变≤ε_strain、时长≤T_max、结果可被用户核验、执行不越过不可逆视界 m。
准入规则：
1. I*≥δ_disc；
2. 在 n 次独立物理测试中，H_i 与 ℋ_cert 中每个竞争假设的两两可分性 D_ij≥δ_sep；
3. 人类签核（用户或领域专家）；
4. 拟合的 p(ρ|H_i) 通过校准检验（ECE≤ε_cal）。
不满足者停留在 shadow，只计入 H_unk 质量，**绝不允许触发定向膨胀或块级处置**。这把「LLM 说得像」与「物理上能区分」严格分开。

**定义 238（开放世界后验与未知质量）** 对认证集 ℋ_cert，后验
P(H|ρ) ∝ p(ρ|H)P(H)。
用认证假设的留出校准样本构造非一致性分数 A(ρ)=max_{H∈ℋ_cert}[log p(ρ|H)+log P(H)]，其经验分布给出 conformal p 值
p_unk(ρ) = (1 + #{i: A_i ≥ A(ρ)}) / (n_cal+1)。
未知质量定义为
P(H_unk|ρ) = max(p_unk(ρ), 1 − Σ_{H∈ℋ_cert} P(H|ρ))，
并与认证后验重归一化。决策规则：
- 若 p_unk(ρ)≤α_nov 或 max_H P(H|ρ)<1−δ_fi → 状态 `H_unk`；
- 否则按认证后验做定向处置。
**关键**：H_unk 不是「第 7 个假设」，而是认识论状态；它不能通过调参被压成 0，只能通过 TDA 准入新的认证假设而缩小。

**定义 239（新颖性分数）** n(ρ)=σ(w_s·p_unk + w_e·d_sem + w_g·d_ground)，其中 d_sem 为用户报告/当前观测与已认证故障描述的嵌入距离，d_ground 为 LLM 预测签名与用户观测签名的差异。n(ρ)≥τ_nov 时禁止定向归因。新颖性进入证据向量，而不是被当作噪声残差最小化；否则系统会系统性地把新故障「解释掉」。

**定义 240（假设生命周期 HLC）** 状态转移与门槛：
- `shadow → candidate`：通过 schema、可证伪性、t_H 安全过滤；
- `candidate → certified`：TDA 准入 + n 次物理测试 + 人类签核 + 似然校准 + AIC-O 覆盖；
- `certified → deprecated`：漂移检测（签名分布偏移）、重复反例、用户报告矛盾、或新假设使其不可辨识；
- `deprecated → shadow`：仅在提供新判别测试与重新标定后允许复活。
**禁止 shadow → certified 直通**；禁止删除历史。生命周期保证「假设库会增长，但不会无证据地膨胀」。

**定义 241（用户测试覆盖与未发现故障估计）** 把用户测试视为对故障条件类的有偏采样。设 f₁ 为只被一个测试者/一次战役发现的故障类数，f₂ 为被恰好两个测试者/两次战役发现的类数，Chao1 估计未发现类数
Ŝ_unseen = f₁²/(2f₂)（f₂>0；f₂=0 时用偏差校正形式），
覆盖率 cov = |discovered| / (|discovered| + Ŝ_unseen)。
停止准则：当 Ŝ_unseen 的上置信界 < δ_cov 时，继续同类用户测试的边际发现率低于阈值，测试战役停止。该估计依赖「类可交换、测试者独立采样」等假设，因此只作为**可报告的不确定性**，不是绝对真值。

**定义 242（LLM-用户接地冲突）** 令 ŝ_user 为由用户 label 与 narrative 构造的经验签名，d_ground(H)=D(s_H, ŝ_user)。若 d_ground>τ_g，置 `grounding_conflict=True`：
- 不得自动准入；
- 必须复测（新 t_H）或人工复核；
- 若冲突持续，降级 H 的 provenance 权重并提高其不确定性。
该机制同时捕捉 LLM 幻觉（预测与物理不符）与用户误解（narrative 与测量不符）；**冲突本身是新颖性的证据，不是要抹平的噪声。**

**定义 243（证据化解释与信任校准）** 解释 E=(posterior, top discriminating evidence, test_ids, provenance, uncertainty, unknown_mass)。约束：
1. 每条解释性断言必须引用签名通道、测试 id 或来源；
2. 必须显式展示 H_unk 质量与最可能的替代假设；
3. 必须区分「已认证」「影子」「未知」三种认识论状态；
4. 禁止用 LLM 生成的无出处叙事替代证据。
用户研究测量信任 τ_user 与经验正确率 acc，定义校准误差 CE=|τ_user−acc|。J_open 要求 CE≤ε_trust。**解释是安全属性**：过度信任会让用户跳过人工复核，过度不信任会让系统被无谓关闭；二者都是失效模式。

**定义 244（开放世界安全回退）** 当状态为 H_unk：
- 不做定向膨胀；维护专用 r_unk，令 r=√(r_geo²+r_force²+r_model²+r_unk²)；
- k*←min(k*,k_safe_unknown)，且 k*≤m；
- 执行 safe_idle 或 compliant retreat（视任务与力状态）；
- 向用户发起主动查询：LLM 提议下一个判别测试，用户执行/裁决；
- 记录 `unknown_episode` 到审计链，供 HLC 与 AIC-O 使用。
**未知时系统不假装知道，但也不简单停机：它把「获取知识」本身当作安全动作。**

**定义 245（开放世界证书 J_open）** J_open=(J_vista, unknown_mass, novelty_pvalue, hypothesis_provenance, test_ids, user_coverage, grounding_conflict, trust_calibration_error, llm_audit_hash, aic_o_ver)。验证规则：
Valid(J_open) ⇔ Valid(J_vista)
∧ (归因到已认证假设 ∨ 显式 H_unk 并已执行定义 244 回退)
∧ 未使用影子假设做定向处置
∧ 接地冲突已解决或已显式降级
∧ LLM 输出 schema 合法且带 provenance（llm_audit_hash 匹配）
∧ 实时路径无 LLM/用户写入
∧ aic_o_ver 为当前版本。
审计链新增：**为什么相信这个假设（test_ids + user sign-off）、为什么认为未知（novelty_pvalue）、漏掉了什么（user_coverage + Ŝ_unseen）、解释是否被正确理解（trust_calibration_error）**。

**定义 246（语义防火墙）** LLM 只能：
- 读只读上下文（代码、日志、手册、历史、用户报告）；
- 输出类型化 schema（假设对象、测试建议、解释草稿）；
- 不能调用致动器、不能改写 ρ/证书/安全阈值、不能访问在线安全存储；
- 对观测中的文本做 prompt-injection 过滤，并与物理信号交叉校验；
- 所有输出带模型哈希、prompt 哈希、检索来源，写入不可变审计日志。
**LLM 可以提问，但不能签字；用户测试可以签字，但不能被 LLM 的解释替代。**

**定义 247（AIC-O 语义/用户对抗认证）** ℰ_O=ℰ_V×ℰ_sem×ℰ_user：
- ℰ_sem：观测/日志/用户报告中的注入文本、对抗性自然语言、投毒报告、LLM 被诱导生成危险测试；
- ℰ_user：锚定（用户相信 LLM 解释）、评分者不一致、非代表性采样、故意 red-team、疲劳；
- 认证指标增：强制归因率、未知诚实度（真实未知被判 unknown 的比例）、解释校准误差、用户测试覆盖。
**共因/未知条件下不要求归因正确，只要求判 unknown 并安全降级。** n_cert 从 128 增至 160，其中 32 给语义/用户对抗。

**定义 248（SOCRATES 算子）** 三环：
- **离线/语义环**：[代码/日志/手册/用户报告 → LHG 溯因 → schema/可证伪/安全过滤 → 影子集 → TDA 选判别测试 → 用户执行与裁决 → HLC 准入/淘汰 → 似然校准 → AIC-O]；
- **在线语义环**：[VISTA 残差与归因 → conformal 未知门 → 认证后验或 H_unk → RSC-O 回退 → XAI 解释 → J_open]；
- **实时环**：[锚点读 → 阶段残差 → CSC 早停 → 前缀派发 → J_open 构建]。
不变式：实时环禁止 LLM 与用户写入；未知门只做查表与阈值比较；开放世界治理不进入实时控制回路。

```python
class LLMHypothesisGenerator:
    """只读上下文 → 可证伪假设 + 判别测试。输出是 proposal，不是 posterior。"""
    def propose(self, code, logs, manuals, H_cert, user_reports, k=16):
        ctx = build_readonly_context(code, logs, manuals, H_cert, user_reports)
        raw = self.llm.sample_typed(ctx, k=k, schema=HYPOTHESIS_SCHEMA)
        out = []
        for H in raw:
            if not schema_ok(H):
                continue
            if not falsifiable(H):          # s_H 有方向性预测 + t_H 可执行
                continue
            if not safe_test(H.t_H):        # f/形变/不可逆视界
                continue
            H.prov = provenance(self.llm, ctx, sources=H.sources)
            out.append(H)
        return out

    def suggest_test(self, rho, H_cert):
        """未知时向用户提议下一个判别测试（仍受安全过滤）。"""
        cands = self.llm.sample_typed(build_context(rho, H_cert),
                                      k=8, schema=TEST_SCHEMA)
        return max((t for t in cands if safe_test(t)),
                   key=lambda t: expected_info_gain(t, rho, H_cert), default=None)
```

### IP-226 TDA（测试驱动准入）

```python
class TestDrivenAdmission:
    def best_discriminating_test(self, H_i, H_cert, f_safe, m):
        best, best_ig = None, -np.inf
        for t in enumerate_safe_tests(H_i, f_safe, m):
            ig = mutual_info(H_i, rho_of(t), conditioned_on=H_cert)
            if ig > best_ig:
                best, best_ig = t, ig
        return best, best_ig

    def admit(self, H_i, H_cert, user_pool, n_trials=12):
        t, ig = self.best_discriminating_test(H_i, H_cert, F_SAFE, M)
        if t is None or ig < DELTA_DISC:
            H_i.status = 'shadow'                 # 只贡献 H_unk，不处置
            return False
        trials = user_pool.run(t, n=n_trials, mode='adjudicate')
        if not trials.separable(DELTA_SEP):
            H_i.status = 'shadow'
            return False
        if not human_signoff(H_i, trials):
            H_i.status = 'candidate'
            return False
        H_i.status = 'certified'
        calibrate_likelihood(H_i, trials)
        return True
```

### IP-227 FIR-O（开放世界后验与未知门）

```python
class OpenWorldFaultIsolation:
    def __init__(self, lik, prior, cal_scores, alpha_nov=0.05, delta_fi=0.15):
        self.lik, self.prior = lik, prior
        self.cal_scores, self.alpha_nov, self.delta_fi = cal_scores, alpha_nov, delta_fi

    def novelty_pvalue(self, rho):
        a = max(np.log(self.lik[h](rho) + 1e-12) + np.log(self.prior[h])
                for h in self.lik)
        return (1 + np.sum(self.cal_scores >= a)) / (len(self.cal_scores) + 1)

    def attribute(self, rho):
        logp = {h: np.log(self.lik[h](rho) + 1e-12) + np.log(self.prior[h])
                for h in self.lik}
        z = np.exp(np.array(list(logp.values())) - max(logp.values()))
        post = {h: float(v / z.sum()) for h, v in zip(logp, z)}
        p_unk = self.novelty_pvalue(rho)
        unknown_mass = max(p_unk, 1.0 - sum(post.values()))
        if p_unk <= self.alpha_nov or max(post.values()) < 1.0 - self.delta_fi:
            return post, 'H_unk', unknown_mass
        return post, max(post, key=post.get), unknown_mass
```

### IP-230 HLC + 覆盖估计

```python
def chao1_unseen(counts):
    f1 = sum(1 for c in counts if c == 1)
    f2 = sum(1 for c in counts if c == 2)
    if f2 == 0:
        return f1 * (f1 - 1) / 2.0          # 偏差校正的保守形式
    return f1 * f1 / (2.0 * f2)

def campaign_stopping(discovered_counts, delta_cov=0.1):
    unseen = chao1_unseen(discovered_counts)
    n = len(discovered_counts)
    cov = n / (n + unseen)
    return unseen_upper_bound(discovered_counts) < delta_cov, cov

def lifecycle_step(H, trials, drift_flag, contradictions):
    if H.status == 'shadow' and H.passes_falsifiable_and_safe():

        H.status = 'certified'
    elif H.status == 'certified' and (drift_flag or contradictions > TAU_CONTRA):
```

## 4. 推导

**引理 9（未知门的第一类控制与检测间隙）** 设认证假设 H∈ℋ_cert 的校准样本与测试样本在 H 下可交换，非一致性分数 A 的 conformal p 值满足 P(p_unk≤α_nov | H∈ℋ_cert)≤α_nov（标准 split-conformal 结论）。因此把已知故障误判为未知的概率被 α_nov 控制。
对真正的新故障 H*，若其 A(ρ) 分布相对认证样本的 A 分布有随机占优间隙 Δ>0（即新故障的非一致性分数系统性更大），则 n_cal 次校准后漏检（p_unk>α_nov）的概率 ≤ exp(−2n_calΔ²)（Hoeffding 型；更紧的界可用 KL 散度）。故未知门不是「拍脑袋阈值」，而是有覆盖语义的统计决定；其检测力取决于「新故障与已知故障的可分程度」，这也解释了为什么 TDA 的判别测试对未知门同样重要。∎

**引理 10（TDA 的可分性与样本复杂度）** 设判别测试 t 满足 I(H_i;ρ(t))≥δ_disc。由 Sanov 定理，n 次独立测试后，H_i 与竞争假设的最大后验误判概率 ≤ exp(−n·δ_disc+o(n))；达到 ε 误判所需样本量 n≥(1/δ_disc)log(1/ε)。若 δ_disc 过低，准入的假设在物理上仍不可分，TDA 退化为形式主义；若 δ_disc 过高，则大量真假设停留在影子集，覆盖率下降、H_unk 长期偏高。因此 δ_disc 是「认证严格性」与「开放世界可用性」的显式旋钮，必须在 AIC-O 中报告。∎

**定理 9（SOCRATES 端到端开放世界安全）** 在 A94–A98 下：
1. **未知不被硬凑**：若 ρ 与所有认证假设的可交换性被破坏（p_unk≤α_nov），系统进入 H_unk；由引理 9，已知被误判为未知的概率 ≤α_nov，新故障被漏检的概率由检测间隙控制。
2. **归因只在可辨识时发生**：若进入认证后验，则第 65 轮引理 7 的三阶段可辨识性仍适用；强制错误归因概率 ≤ α_nov + exp(−n·κ_fi/2) + ε_cal + ε_ground，其中 ε_cal 为似然校准误差，ε_ground 为定义 242 的接地冲突残余。
3. **未知时安全**：H_unk ⇒ 联合膨胀 r_unk、k*≤k_safe_unknown≤m、safe_idle/retreat；由第 65 轮引理 8，块级越界概率仍受 α_chunk+δ_fi+α_vis 控制，且不因未知而放大到不可逆视界之外。
4. **证书闭合**：Valid(J_open) 要求归因到已认证假设或显式 H_unk，且禁止影子假设触发定向处置；因此「LLM 想到但未验证」的假设不能改变安全策略。
5. **开放世界诚实性**：J_open 显式携带 unknown_mass、novelty_pvalue、user_coverage 与 Ŝ_unseen；审计者能区分「系统知道」「系统不知道」与「系统以为自己知道」。
∎

**定理 10（用户测试的发现上界与停止准则）** 在故障类可交换、测试者/战役独立采样、类发现计数满足 Chao1 假设的条件下，未发现类数的期望由 Ŝ_unseen=f₁²/(2f₂) 估计，且其方差可由 bootstrap 给出置信区间。当上置信界 <δ_cov 时，继续同类用户测试的边际发现率低于阈值；因此停止准则是「统计上再测也学不到新类」，而非「预算用完」。该定理依赖采样模型：若用户 red-team 策略高度同质，f₁/f₂ 会低估未发现类，系统必须通过多样化用户池与 LLM 提议的对抗测试缓解。∎

**命题（LLM 不能替代测试）** 设 LLM 提案的假阳性率为 ε_LLM>0，若不经 TDA 就允许提案进入认证集，则每 k 个提案的期望误认证数 ≥k·ε_LLM，且随 k 线性增长；证书的 soundness 无法建立。TDA 通过「物理判别测试 + 人类签核」把准入概率与 ε_LLM 解耦，因此是恢复 soundness 的必要条件。LLM 提高 recall（想到更多故障），但不能单独提高 precision（确认哪个故障为真）。∎

**命题（未知回退的保守性）** H_unk 时 r_unk=κ_unk·max(r_geo,r_force,r_model)，联合半径 r 单调不小于任一单球半径；且 k*≤k_safe_unknown≤m。因此 H_unk 的执行域是已认证情形的子集（更保守），不会引入比 VISTA 更大的风险；代价是任务成功率与效率下降。该代价必须与「强行归因的错误风险」在 AIC-O 中显式权衡。∎

## 7. 已知风险

**一句话**：SOCRATES 的最大风险是「LLM 提出假设、用户被 LLM 的解释锚定、系统再用『已测试』给自己发证书」三者形成自我确认回路——它覆盖的是**被想得到且被现有用户群体测得到**的故障，而不是真实开放世界的故障；更糟的是，H_unk 可能被调参压小以维持可用性，或膨胀成永远 safe_idle 的甩锅状态，使「承认不知道」从安全机制退化为认证表演。

**次级风险与缓解**：
1. **LLM 幻觉污染假设库**：LLM 会生成听起来合理但物理上不可检验的假设，或编造支持证据；缓解：schema + 可证伪性 + 安全过滤 + TDA 准入 + provenance 审计 + ε_LLM 进证书；禁止 LLM 自评作为证据。
2. **用户锚定与确认偏误**：用户看到 LLM 解释后倾向于按解释去观察/标注，导致 d_ground 虚假一致；缓解：盲测（先标注后看解释）、多用户独立裁决、κ_U 门槛、红队与普通用户分离、解释评估与假设准入分离。
3. **用户测试覆盖偏差**：用户池同质、场景有限，Chao1 假设不成立；缓解：多样化用户池、LLM 生成对抗场景、主动采样、报告置信区间而非点估计、把 Ŝ_unseen 作为风险预算而非精确值。
4. **H_unk 调参博弈**：为维持可用性把 α_nov 调小或把 unknown_mass 压小；缓解：α_nov 与 δ_cov 写入 AIC-O 证书、外部审计、禁止在线自适应降低未知预算、未知事件必须留痕。
5. **H_unk 变成永久停机**：未知回退过于保守导致任务不可用；缓解：主动查询 + 快速 TDA 准入 + 分层回退（先降速/降力，再 safe_idle）；把「恢复时间」作为一等指标。
6. **语义注入与工具滥用**：观测/日志/用户报告中的文本诱导 LLM 生成危险测试或泄露安全阈值；缓解：语义防火墙、只读上下文、类型化输出、无致动器访问、物理信号交叉校验、危险测试人工复核。
7. **TDA 组合爆炸与测试成本**：假设×测试×用户试验成本高；缓解：只对 shadow 中信息增益最高的 top-k 做 TDA、复用测试模板、主动学习选测试、缓存判别结果。
8. **生命周期停滞/频繁翻烧饼**：准入过严导致新故障永远进不了认证集，或漂移导致 certified/deprecated 反复切换；缓解：滞回阈值、最小驻留时间、批量重认证、把准入/淘汰审计化。
9. **实时性被离线治理侵蚀**：LLM/用户/HLC 若被误接入实时环会破坏 2.5ms 契约；缓解：硬隔离、实时环禁止网络/LLM 调用、编译期检查、A93 契约回归测试。
10. **证书的「开放性」被误读为「已覆盖开放世界」**：J_open 只能证明「已认证集内的安全 + 未知被诚实标注」，不能证明「没有未知」；缓解：证书文案强制展示 unknown_mass 与 Ŝ_unseen，禁止把 H_unk=0 当作安全声明。
