# 第 12 轮（新灵感循环第 2 轮；本轮灵感：「评测基准」×「抓取位姿估计」）
> **基线**：第 11 轮 MetricVoiceGauge-GSCF-SRA-JSSE（定义 549–561；引理 92–96；实验 E591–E610）。
> 本轮纪律：**可证伪的证书 + 动作级冗余 + 实测联合失效**。两个灵感各治理 v11 一种债：**自证债**——证书声称覆盖误差，但覆盖只在离线 E591–E610 标定一次，部署分布漂移后无人复核；引理 96 还假设三守卫失效"正交"以论并集界，而 v11 自认的最大风险恰是三者**同时失效**。**退化债**——任一守卫失败只能整块中止/急停，无动作级优雅降级。必须保持 v11 铁律：任一新模块失效 ⇒ 声明中立元，行为严格**等价**或**支配**于 v11；新模块只许增加"已单独通过完整证书"的备选动作，绝不许放宽安全集或证书门槛。

## 0. 直觉与动机

**灵感 1（抓取位姿估计 → 把"系统级中止"换成"候选级降级"）**
直觉：v11 的退化语义是二元的——守卫一响，整块作废，JSSE 急停保持。但抓取位姿估计天生的输出形状不是"一个点"，而是**一组带质量的 SE(3) 候选**：每个候选都有成功概率、力闭合裕度、碰撞余量；失败是**候选级、可排序**的，而非系统级全或无。核心创新：**抓取位姿分布场（GraspPoseDistribution, GPD）**——每块 ζ 不再绑定单一 p*，而绑定 G_ζ={g_i,q_i,c_i,m_i} 与冗余度 ρ_ζ；块生成期为前 r 个候选**各自签发完整证书**并预计算中止轨迹。50Hz 守卫失败时，先在同一块内**降级到下一个已认证候选**（动作级优雅降级），全部候选耗尽才走 JSSE。这一刀切中 v11 的"无优雅退化路径"：不是再加一个守卫去"更早发现失败"，而是让失败在动作空间里有**已付费的退路**。
更关键：q_i 的真值——抓取成功/失败——是**可物理实测**的。v11 的证书全靠"自证"（预测误差、几何自洽）；第一次，证书拿到了一个**部署期可闭环观测的外部标签**，这把灵感 2 的"评测"从论文附表变成运行时反馈。

**灵感 2（评测基准 → 从"声明的覆盖"到"被监控的覆盖"）**
直觉：v11 引理 96 的"以 ≥1−ε_β 覆盖非显著误差"是**一次性标定的静态断言**；部署分布一漂移，这个数字就成了没人复核的传说。评测基准的结构恰是：**固定协议 + 留出分布 + 可证伪评分 + 置信区间 + 预注册**——它把断言变成能被数据推翻的过程。核心创新：**在线共形评测基准（AdaptiveConformalBenchmark, ACB）**，三件事：
(i) **把 β 变成被在线维持的量**：用**自适应共形推断（ACI）**在块末 rollout 残差 s_b^(K) 上维护分位数 q̂_b，β_ACB=max(β_GSCF,q̂_b)，每块用 err_b=1[s_b>q̂_b] 更新 q̂←q̂+η(err−α)。交换性下退化为分裂共形，给出有限样本边际覆盖 ≥1−α；漂移下 ACI 维持**长程平均**误覆盖 ≤α+O(1/(ηB))。v11 的假设 A4「误差被 β 覆盖」被换成**被监控的不变式**——这是对最大风险的正面拆除（覆盖不再靠信，靠反馈）。
(ii) **实测联合失效，取代正交公理**：维护守卫失效向量 J_b=(GSCF,SRA,JSSE,NRB,…)，用 Clopper–Pearson 上置信界 Ĵ_UC 估计**联合**失效率；只要 Ĵ_UC/ε_joint 进入 K_eff 的 max，就自动膨胀 β、收缩 K_eff。v11 用并集界+"联合可忽略"（暗含近独立）；v12 用**相关性无关的经验上界**，正交只是它可选的收紧特例。
(iii) 低速率、预注册的**非致动探针**（canary 微扰、留出回放）只测守卫响应时延、误报率与漂移，从不扩权——评测本身不许变成新的攻击面。

**咬合**：GPD 给 ACB 持续产生可观测标签（抓取成败、块末残差）；ACB 反过来给 GPD 的 q_i 做在线接受集校准，并给整个证书做漂移通胀；两者共同把 v11 的静态三重守护证书 Ĉ⁺⁺ 升级为**带实测覆盖与联合失效上界的分布证书** Ĉ⁺⁺⁺。

## 1. 研究问题（轮次升级版）

- **Q1（可证伪覆盖）**：如何把证书覆盖从一次性离线标定的静态断言，升级为部署期在线监控、且分布漂移下长程有效的统计保证（β_ACB），同时守住 1kHz/50Hz/5Hz 预算？
- **Q2（候选级降级）**：如何用 SE(3) 抓取位姿分布的动作级冗余，把"整块中止/急停"降级为"候选级降级"，且每个备选都单独通过完整证书（安全集不扩、门槛不降），只增加可用动作而不新增不安全动作？
- **Q3（联合失效）**：三守卫相关失效如何被**实测**（而非假设正交），并把实测联合失效上界回灌到 β 与 K_eff，使证书在相关性最坏时仍保守？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 证书可证伪律（Falsifiable Certificate, ACB）**
证书中每个概率性断言必须绑定一个部署期可观测评分与预注册的推翻条件；无法被在线数据检验的覆盖声明不许进入证书，只能标注为"离线假设"（显式降级）。覆盖/联合失效必须以置信区间报告，而非点估计。

**P17 动作级冗余优先律（Action-Level Redundancy First, GPD）**
失败的第一响应是**在同一安全集内换一个已认证候选**，而非放大门控或整块中止；备选必须携带与首选**同规格**的完整证书（安全、规范、推理全过），禁止"备选通道放宽门槛"。冗余度 ρ 是证书一等量，不是可选装饰。

**P18 联合失效实测律（Measured Joint Failure, ACB）**
禁止把守卫失效正交当公理。证书的联合失效界必须来自经验联合率的上置信界，且对正相关（同时失效）保守；正交仅可作为上界收紧时的额外假设，并须在台账显式标注。

## 3. 与基线的接口（如何退化）

- GPD 失效（质量网超时/点云不可用）⇒ 单一位姿、ρ←1、无候选梯：等价 v11 的标量 γ̂_grasp 与整块中止语义；
- ACB 失效（共形更新停摆/残差不可得）⇒ β←离线 β_GSCF、K_eff←v11 门控、联合失效退回并集界并显式标注"正交假设"：行为等价 v11（失去漂移监控，声明退回静态）；
- 探针失效 ⇒ 跳过探针，不缩权也不扩权（纯审计面）；
- 其余沿 v11 退化链：GSCF⇒v10 STF；SRA⇒K_eff←2；JSSE⇒v6 急停保持；STF⇒K_eff←1；NRB⇒Π_r；AC⇒K=1；ID⇒归因冻结；MW⇒手写网关；v8⇒中立元注入。

## 4. 预期贡献

1. **动作级优雅降级**：抓取位姿分布 + 逐候选证书 + 预计算中止梯，把 v11"守卫同时失效只能急停"的最坏路径，替换为"候选耗尽才急停"的退化阶梯（引理 97）；
2. **可证伪在线证书**：ACI 把覆盖从静态 A4 变成部署期被维持的不变式，漂移下长程有效（引理 98）；
3. **实测联合失效**：Clopper–Pearson 上界取代"正交/联合可忽略"，相关性最坏时仍保守，并回灌证书通胀（引理 99）；
4. **评测基准一等公民**：预注册任务套件、留出划分、指标置信区间、非致动探针与反泄漏纪律（E611–E630）；
5. 退化链统一为：新模块失效 ⇒ 逐级回落到 v11 的已被验证行为。

## 5. 本轮最大风险

**一句话**：v12 的全部新保证都以"部署期能观测到的标签"为食——一步/块末残差与抓取成败；但最致命的误差（三守卫相关失效、罕见不安全抓取）恰恰是**稀有且只在实际尝试后才产生标签**的事件，于是 ACI 会在容易的分布内数据上把 q̂ 收得很紧、把误覆盖压到 α，而真正杀死系统的尾部从未被探针触达；GPD 的 q_i 也可能在分布外"自信地错"，让候选级降级只是换了一个由同一套 miscalibrated 分数背书的错误备选——**评测基准只能测它能看见的东西，而安全取决于它看不见的尾部，这是本轮方案最大的风险。**

## 2. 形式化定义（要点与升级）

**新增定义 562（抓取位姿分布场 GPD）** 块 ζ 上 GPD 输出
G_ζ={(g_i,q_i,c_i,m_i)}_{i=1}^{M}，g_i∈SE(3)，q_i∈[0,1] 为成功率预测，c_i 为力闭合裕度，m_i=clearance(g_i,Φ(ζ))−β_GSCF。可行候选集 F_ζ={i | q_i^LCB≥q_min ∧ c_i≥c_min ∧ m_i≥d_safe}，按 (q_i^LCB,c_i,m_i) 字典序降序。**关键**：q_i 仅作排序与初筛，安全门槛一律用 ACB 校准后的 q_i^LCB（定义 567）；证书只对 F_ζ 中候选签发。

**新增定义 563（冗余度）** w_i=q_i^LCB·1[i∈F_ζ]；ρ_ζ=(Σ_i w_i)²/Σ_i w_i²（参与率，1≤ρ≤|F_ζ|），归一化 ρ̃=ρ/M。ρ_ζ<ρ_min（如 1.5）时块证书降级为 r=1（等价 v11 单候选），ρ 越大候选梯越深。**ρ 进入证书**（定义 571），不是隐含统计量。

**新增定义 564（动作级候选梯与降级算子）** 块生成期对前 r=min(⌈ρ_ζ⌉,4) 个可行候选**各自**签发与其他候选同规格的完整证书 Ĉ_i（含几何 γ、语义 ν̂、n_t^reason、规范、JSSE 可行性），并预计算中止轨迹 Q_abort(g_i)（逐候选版定义 559）。降级算子
D^act(i,failed)=min{j>i | i∈/耗尽 ∧ Ĉ_j valid ∧ 切换轨迹 ∈C_q_safe}，无则 ⊥（升级 JSSE）。**同规格原则**：备选不得降低任何门槛——备选只是"另一个同样被守卫背书的动作"。

**新增定义 565（非一致度评分）**
- 一步残差（1kHz，标签恒可得）：s_t^(1)=‖x_{t+1}−F̂_q(x_t,u_t)‖_{Σ^{-1}}；
- 块末残差（5Hz，直接对应多步证书）：s_b^(K)=max(‖x_{t+K}−F̂_q^K(x_t,u_{t:t+K})‖_{Σ^{-1}}, (ê_max−ê_realized)_+, (ĉ_pred−d_safe)_+)，Σ 为残差协方差在线估计。s_t^(1) 作**领先指标**（快通道），s_b^(K) 作**滞后但直接**的证书评分。

# IP-365 GraspPoseDistribution：抓取位姿分布场（复用检测/点云/INT8 质量网）
class GraspPoseDistribution:
    def __init__(self, quality_net, sampler, beta_ref, d_safe,
                 M=16, q_min=0.5, c_min=0.3, rho_min=1.5):
        self.net, self.sampler, self.beta = quality_net, sampler, beta_ref
        self.d_safe, self.M = d_safe, M
        self.q_min, self.c_min, self.rho_min = q_min, c_min, rho_min

    def propose(self, chunk, stf, gscf):
        cands = []
        for g in self.sampler.sample(chunk, n=self.M):     # 反贴点 + 学习精修
            q = self.net.predict(g, chunk, stf, gscf)       # P(success|g)，INT8
            c = force_closure_margin(g, chunk)              # 摩擦锥余量
            m = clearance(g, chunk.footprint) - self.beta   # 余量（不含 q 校准）
            if q >= self.q_min and c >= self.c_min and m >= self.d_safe:
                cands.append(Grasp(g, q, c, m))
        cands.sort(key=lambda z: (z.q, z.c, z.m), reverse=True)
        return cands

    def redundancy(self, cands):
        w = np.array([z.q for z in cands])
        return (w.sum() ** 2 / (w ** 2).sum()) if len(w) else 0.0

    def fallback(self, ladder, i, failed_flags):
        # 同规格原则：只跳过已被证伪或证书失效的候选，绝不降门槛
        for j in range(i + 1, len(ladder)):
            if not failed_flags[j] and ladder[j].cert.valid:
                return j
        return None


# IP-366 AdaptiveConformalBenchmark：在线共形评测基准
class AdaptiveConformalBenchmark:
    def __init__(self, alpha=0.01, eta=0.02, beta_offline=0.05,
                 delta=0.01, W=512, eps_joint=1e-3):
        self.alpha, self.eta = alpha, eta
        self.q_hat = beta_offline
        self.delta, self.W, self.eps_joint = delta, W, eps_joint
        self.errs = deque(maxlen=W)
        self.joint = deque(maxlen=W)
        self.joint_vecs = deque(maxlen=W)
        self.stale = False

    def one_step(self, x, u, x_next, Fq, Sigma_inv):
        s = mahalanobis(x_next, Fq.step(x, u), Sigma_inv)
        if s > self.q_hat and s > 1.5 * self.q_hat:   # 快通道领先
            return {'fast_inflate': True, 's': s}
        return {'fast_inflate': False, 's': s}

    def on_block_end(self, x_pred, x_real, margin_violations, guard_vec, Sigma_inv):
        s = max(mahalanobis(x_real, x_pred, Sigma_inv), *margin_violations)
        err = 1.0 if s > self.q_hat else 0.0
        self.errs.append(err)
        self.q_hat = max(0.0, self.q_hat + self.eta * (err - self.alpha))  # ACI
        self.joint.append(any(guard_vec))
        self.joint_vecs.append(guard_vec)
        return self.q_hat, self.joint_ucb(), self.correlation_diagnostics()

    def joint_ucb(self):
        # Clopper-Pearson 上界，不假设独立性
        n, k = len(self.joint), sum(self.joint)
        if n == 0:
            return 1.0
        return clopper_pearson_upper(k, n, 1 - self.delta)

    def correlation_diagnostics(self):
        A = np.array(self.joint_vecs, dtype=float)
        return A.T @ A / max(len(A), 1)     # 仅诊断，不进证书界

    def inflate(self, K, beta_gscf, q_min):
        cap = self.joint_ucb() / self.eps_joint
        K = max(1, int(K * (1 - min(1.0, cap))))
        beta = max(beta_gscf, self.q_hat)
        return K, beta, q_min

class DistributionalChunkCertifier(TriGuardChunkCertifier):

        return ('abort', jsse.map_abort(chunk.ladder[chunk.active].g))  # 才升级 JSSE

        return self._v11_certify(g, state, ctx, stf, gscf, sra, nrb)

## 4. 推导

**引理 97（候选级降级的安全支配性与效率增益）**
设候选梯 L_ζ 每项 g_j 在执行前均通过与首选**同规格**的完整证书（m_j≥d_safe、ê_max≤τ_eff、n_t^reason 全 1、规范通过、γ/Γ 几何一致），且候选切换的中间轨迹逐周期由 JSSE 投影到 C_q_safe。则：
(a) **安全不降（支配性）**：候选梯引入的每条实际动作仍属于 v11 的安全可行集 ∪{JSSE 中止}，即 v12 物理行为集合 ⊆ v11 可行集；
(b) **效率增益**：当 v11 因单候选守卫失败而整块中止时，若 v12 存在另一已认证候选则可继续而不中止；故相同守卫触发序列下 v12 的中止次数 ≤ v11，完成率 ≥ v11，且增益随 ρ_ζ 单调不降；
(c) **可退化**：ρ_ζ<ρ_min 或 GPD 失效时 r=1，候选梯退化为单候选，行为等价 v11。
证明要点：备选不是"绕过守卫"，而是"另一个同样被守卫背书的动作"；切换只改目标不改安全集；JSSE 投影保证中间轨迹安全；(b) 由中止次数的逐事件包含关系与 ρ 对可用候选数的单调性直接得。∎

**引理 98（ACI 覆盖：把 A4 变成被维持的不变式）**
设 (A5) 块末残差有界 |s_b^(K)|≤S_max；(A6) 评分在交换性下可分裂共形。则：
(i) 交换性下，分裂共形分位数 q̂ 给出有限样本边际覆盖 P(s_new≤q̂)≥1−α；
(ii) 任意（含对抗）漂移下，ACI 更新 q̂_{b+1}=q̂_b+η(err_b−α) 满足长程误覆盖 (1/B)Σ_b err_b ≤ α+(q̂_1+S_max)/(ηB)（Gibbs–Candès 型界）；
(iii) 故 β_ACB=max(β_GSCF,q̂_b) 的覆盖不再是静态假设 A4，而是被在线反馈维持的**长程不变式**；v11 的 ε_β 被替换为可观测序列 {err_b} 及其 CI。证明：分裂共形有限样本覆盖 + ACI 标准长程界；max 为单调提升，不破坏覆盖。∎

**引理 99（实测联合失效取代正交并集界）**
设守卫失效向量 J_b，真联合率 p_J=P(∨_k J_b[k]=1)。Clopper–Pearson 上界 Ĵ_UC 满足 P(p_J≤Ĵ_UC)≥1−δ。
(i) 以概率 ≥1−δ，用 Ĵ_UC 的联合失效界**不低估**真实联合失效，且**不依赖任何相关性结构**；
(ii) v11 的"联合失效可忽略/正交"等价于用 ∏_k p_k（或近独立近似）估计 p_J；在正相关（FKG，守卫共享同一场景扰动时典型成立）下 ∏_k p_k ≤ p_J，且可任意低估——正是 v11 自认的最大风险；
(iii) 故 Ĵ_UC 在危险的正相关方向上保守，正交仅作为可选收紧假设并在台账标注。
证明：(i) Clopper–Pearson 覆盖性质对任意 p_J 成立；(ii) FKG 不等式 P(∩A_k)≥∏P(A_k) 对正相关递增事件成立（此处用其补事件形式给 p_J 下界）；(iii) 由 (i)(ii) 直接得。∎

**引理 100（接受集失败率控制）**
对被接受执行的抓取集合维护 Clopper–Pearson 失败率上界 f̂_UC。若 f̂_UC≤α_grasp，则以概率 ≥1−δ 真实接受集失败率 ≤α_grasp，**无论 q_i 的校准质量如何**。故 q_min 的安全性由接受集统计保证，而非由质量网的 ECE 保证；分布外 q_i 失真只会减少接受量，不会放宽接受集失败率上界（上界随观测更新）。∎

**引理 101（审计不破实时、探针不扩权）**
(i) 非致动探针只读、只写台账；致动 canary 满足 ∀t q(t)∈C_q_safe 且不改变任务目标，故探针动作 ⊆ 已安全集；
(ii) ACB 更新 O(1)（一步）/O(W)（块末，W≤512），摊销 ≤0.3ms；GPD M≤16 批量 INT8 ≤0.4ms、r≤4 证书 ≤1.2ms@5Hz 摊销 ≤0.3ms；
(iii) 任何探针/审计失败只置 stale 并回落离线值（等价 v11），不扩权。∎

**引理 102（v12 联合保守性）**
在 v11 引理 96 的假设下，且以 Ĵ_UC 替代"正交"、以 β_ACB 替代静态 β_GSCF，则任一中块危险事件以概率 ≥1−ε_geo−ε_sra−ε_jsse−ε_β(t)−δ 被捕获，且物理行为支配于 v11；其中 ε_β(t) 由 {err_b} 的在线覆盖给出而非离线常数。证明：并集界沿用 v11，但联合项换成实测 Ĵ_UC（引理 99），覆盖项换成 ACI（引理 98），两者均不弱于原假设。∎

## 8. 本轮最大风险

**一句话**：v12 的全部新保证都以"部署期能观测到的标签"为食——一步/块末残差与抓取成败；但最致命的误差（三守卫相关失效、罕见不安全抓取）恰恰是**稀有且只在实际尝试后才产生标签**的事件，于是 ACI 会在容易的分布内数据上把 q̂ 收得很紧、把误覆盖压到 α，而真正杀死系统的尾部从未被探针触达；GPD 的 q_i 也可能在分布外"自信地错"，让候选级降级只是换了一个由同一套 miscalibrated 分数背书的错误备选——**评测基准只能测它能看见的东西，而安全取决于它看不见的尾部，这是本轮方案最大的风险。**
