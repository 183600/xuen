# 第 57 轮（承接第 56 轮「证据地图×主动探询×信任协商」IP-127~132；灵感循环第 1 轮；本轮灵感：「少样本学习」×「应用落地」）

> 第 56 轮把安全赌注从"模型置信"换成"证据承诺"，并用语义地图 𝓜 让证据跨到访积累。但它的风险自陈恰好暴露了部署死穴：证据长寿意味着坏证据也长寿，而证据地图的积累是**按站点从零开始**的——每进一座新楼、每换一种地面，都要重新支付一遍探询、标定与协商的成本。一个能在实验室证明 soundness 的系统，若每次落地都要几百次探针和大量人工标注，它在应用上就是不可部署的。本轮两个灵感正好接上：**少样本学习**回答"如何把过去站点的证据压缩成可迁移的先验，用几次本地测量解压"；**应用落地**回答"如何把这种迁移做成有预算、可预测、可审计、可拒绝的部署契约"。核心命题由"证据说可信"升级为 **"先验带账本地说可信"**——先验不是绕过证据的捷径，而是**带不确定性与溯源的、来自他处的证据**。

核心矛盾：
- **H26（迁移悖论）**：不在站点间迁移，部署成本随站点数线性爆炸，应用不可持续；可一旦迁移，第 56 轮费力消除的"跨域 κ 风险"又以"先验"的形式整体回来了。**迁移因落地而必需，也正是不可靠证据的最大来源。**
- **H27（证据-部署两难）**：第 56 轮的证书要求重证据、保守、慢；落地却要求分钟级上手、快速见效、出事能降级。少给证据则 soundness 崩塌，强要全量证据则没人买。需要的不是"全有全无的信任开关"，而是一份能**给新颖性定价**的证据预算契约。

## 0. 直觉与动机

**灵感 1（少样本学习 → 先验是被压缩的旧证据，少样本是低成本解压）**
直觉：老师傅进一栋新楼，不会从零测摩擦系数；他带着"湿瓷砖滑、地毯稳"的先验，只蹲下摸两三处。少样本学习的本质就是**把多个站点的证据压成一个带不确定性的先验 π_ψ**，落地时用 k 次本地探针把后验"解压"出来。关键不是"少用数据"，而是**说清楚少掉的那些数据从哪来、值多少**：先验必须携带自己的误差 ε_π、适用域 dom(π) 与版本，否则就是把别人的经验当成本地的真相。

**灵感 2（少样本 = 主动挑那"少"的样本，而非被动少采样）**
直觉：同样 5 次探针，选在承重脚/边缘/高差处与随机乱点，信息量差一个量级。第 56 轮的 VOI 只用于"这一脚要不要探"；本轮把它抬到**站点级与任务级**：先选"先教哪块区域、先示范哪个任务、先探哪个物理量"。人类演示也是样本，且是昂贵样本，必须按"降低部署失败概率 / 人类分钟"来挑，而不是按"看起来全面"来挑。

**灵感 3（应用落地 → 自主不是开关，是带证据门槛的阶梯 + 可预测的上手成本）**
直觉：卖"全自主"是 deployment 的反模式。真实落地是一条**自主阶梯**：A0 遥操作 → A1 影子模式（只推理不执行，白拿证据）→ A2 监督自主（保守步态 + 人在环）→ A3 认证自主 → A4 漂移降级/重校准。每一级有证据门槛与可回退路径；安装时先做一次便宜的"站点指纹"（几眼广角视觉 + 一次轻扫），用先验预测"这站要几次探针、多少人类分钟才能到 A3"，把不可见的风险变成**可报价的工期**。系统还应被允许输出一个一等公民结论：**"此站我无法安全部署"**。

**灵感 4（跨站点元整合 → 先验是受治理的共享资产，不是自由流动的真相）**
直觉：每个站点都是证据生产者；舰队把充分统计量汇总成更好的先验，这是 fleet learning。但第 56 轮的"坏证据长寿"在元层面更致命：一个被污染的站点会污染所有后续部署。所以先验更新必须复用同一套纪律：**来源可信权重、隔离区、留一站验证、金丝雀、版本钉住、回滚**。联邦式只传充分统计量而非原始数据，既护隐私又控污染。

**灵感 5（新颖性门 → 先验拥有"拒绝适用"的权利）**
直觉：少样本最危险的失败是**自信外推**：新站点在指纹上"看着眼熟"，却在真正决定成败的物理维度上完全不同。新颖性门在信任先验之前度量"先验-数据冲突" ν；ν 高则给先验降温（tempered prior）、抬高先验方差、要求更多本地探针、降低自主等级。第 56 轮的护盾面对不确定性只有保守/制动，本轮补上第三个动作：**给不确定性定价，并用证据把它买回来**。

## 1. 形式化定义（增量：定义 133–138）

**定义 133（元证据先验 MEP）** 站点/任务对 `τ ~ p(τ)`，隐参数 `θ_τ`（区域接触参数、探针似然、步态风险曲线）。元先验 `π_ψ(θ | c)`，上下文 `c=(c_task, c_site, c_region)` 构成三层可迁移结构；`ψ` 由跨站点元学习得到，满足元校准 `ECE_meta ≤ ε_π`。本地后验 `p(θ | D_r, π_ψ) ∝ π_ψ(θ) ∏_{e∈D_r} L(e|θ)`。**先验是证据而非真值**：以四元组 `(ψ, ε_π, dom(π), ver)` 记账。

**定义 134（新颖性门与温度后验 NGT）** 充分统计 `t(D_r)`，先验预测 `p_π(t)`。非一致性分数 `ν(r) = d_π(t(D_r))²`（Mahalanobis / 能量分）。用留一站集合做 conformal 校准，取 `ν_max = Quantile_{1-α}({ν_s})`。门：仅当 `ν ≤ ν_max` 允许先验主导；否则用温度后验 `p_β(θ|D) ∝ π_ψ(θ)^β · L(D|θ)`，`β = min(1, ν_max/ν) ∈ (0,1]`——冲突越大先验越淡——并要求补探针。

**定义 135（少样本证据预算 FBP）** 目标风险 `δ`、置信 `1-α`。所需样本数 `k*(r) = min{k : UCB_{1-α}(P_fail | D_k, π_ψ) ≤ δ}`。参数化近似 `k* ≈ max(0, C(r)/ε² − κ_π(β))`：先验精度 `κ_π` 直接抵扣所需样本，新颖性经 `β` 抬高 `k*`。**落地上手成本** `Cost(k) = k·c_probe + h(k)·c_human + P_fail(k)·C_fail + T_down·c_down`，取 `k^† = argmin Cost`；若 `k^† > k_budget` 则诚实拒绝部署。

**定义 136（主动少样本查询 AFQ）** 查询 `q ∈ Q_probe ∪ Q_demo`（探针或人类演示），价值 `VOI_D(q) = E[Δ UCB(P_fail)] − c_human(q)/c_ref`，按人类分钟计价，预算 `H_max`；取 `argmax VOI_D`，且查询本身必须非破坏（继承 A34）。

**定义 137（舰队元整合 FMC）** 站点提交 `(t_s, 校准诊断, ν_s, prov_s)`；元更新 `ψ_{t+1} = MetaUpdate(ψ_t, {t_s})`，站点权重 `w_s ≤ w_max^meta` 且随留一站校准衰减（与 A35 同构）。晋升门：留一站验证 `ECE ≤ ε_π`、注入污染站点后先验偏移 `≤ θ_poison`、金丝雀站无回归，方可发布；边端可钉版本、可回滚。

**定义 138（部署/迁移证书 DSC）** `J_d = (ver_ψ, fingerprint, ν, k*, k_actual, autonomy_level, ε_π, ε_adapt, ε_local, drift_monitor, rollback_plan)`；风险分解 `ε_total = ε_π·1[prior] + ε_adapt(k) + ε_local + ε_cal + ε_h`。证书是**自主阶梯的通行证**：`A3 ⇔ k_actual ≥ k* ∧ ν ≤ ν_max ∧ 留一站校准通过 ∧ drift ≤ θ_drift`；任一条失效即降级到 A2/A1，且降级不可被运营方单方面覆盖。

## 2. 关键算法伪代码（完整版见产物区）

### IP-133 MEP（元证据先验）

```python
def meta_train(sites, epochs):
    psi = init_prior()
    for _ in range(epochs):
        loss = 0
        for s in sites:                                # 留一站：s 作测试
            psi_s = inner_adapt(psi, support=s.train, k_shot=K)   # 少样本适应
            loss += nll(psi_s, query=s.val) + calib_penalty(psi_s)
        psi = outer_update(psi, loss)                  # 元梯度 / 分层贝叶斯
    return calibrated_prior(psi, eps_pi=empirical_ece(sites), dom=cover(sites))
```

### IP-134 FBP（少样本证据预算）

```python
def required_shots(r, M, psi, delta, alpha):
    beta = temper(novelty(r, psi), nu_max)             # 见 IP-135
    k = 0
    while ucb_fail(r, M, psi, beta, k, alpha) > delta:
        k += 1
        if k > k_budget: return INF                    # 诚实拒绝部署
    return k

def bootstrap_plan(site_fp, task, psi, budget):
    M = load_prior_map(site_fp, psi)
    plan = {r: required_shots(r, M, psi, delta_goal, alpha)
            for r in reachable_regions(site_fp)}
    return plan, estimate_human_minutes(plan)
```

### IP-135 NGT（新颖性门 + 温度后验）

```python
def novelty(r, psi):
    t = sufficient_stats(r)
    return mahalanobis2(t, psi.prior_predictive)       # 阈值已 conformal 校准

def tempered_posterior(prior, data, nu):
    beta = 1.0 if nu <= nu_max else min(1.0, nu_max / nu)
    return power_posterior(prior, beta) * likelihood(data)
```

### IP-136 AFQ（主动少样本查询）

```python
def active_query(M, psi, budget):
    while budget.human_min > 0:
        cands = [q for q in admissible_queries(M, psi) if q.nondestructive]
        q = argmax(cands, key=lambda x: voi_deploy(x, M, psi)
                   - x.human_min / c_ref)
        if voi_deploy(q, M, psi) < theta_d: break
        M = fuse(M, [execute(q)])
        budget.spend(q)
    return M
```

### IP-137 FMC（舰队元整合）

```python
def fleet_consolidate(psi, submissions):
    subs = [s for s in submissions if s.calibration_ok]
    w = [min(w_max_meta, w0 * s.loso_cal) for s in subs]
    cand = meta_update(psi, subs, w)
    if loso_ece(cand, subs) > eps_pi:        return psi, 'reject_prior'
    if poison_shift(cand, subs) > theta_poison: return psi, 'reject_prior'
    if not canary_ok(cand):                  return psi, 'reject_prior'
    return publish(cand, provenance(subs)), 'promoted'
```

### IP-138 DSC（部署/迁移证书）

```python
def deployment_certificate(M, psi, site, k_actual, autonomy):
    nu = novelty_site(site, psi)
    ks = {r: required_shots(r, M, psi, delta_goal, alpha) for r in M.core}
    if any(k_actual[r] < ks[r] for r in ks): return downgrade('insufficient_shots')
    if nu > nu_max:                          return downgrade('novelty_gate')
    if not loso_calibrated(psi):             return downgrade('prior_uncalibrated')
    if drift(site) > theta_drift:            return downgrade('drift')
    return ('A3', DSC(psi.ver, site.fp, nu, ks, k_actual, eps_pi,
                      eps_adapt(k_actual), eps_local, drift_monitor(site)))
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| MEP | 离线 O(E·S·K·d) | O(|ψ|+d) | 元校准、适用域显式 |
| FBP | O(|R|·k*·C_UCB) | O(|R|) | k* 有限或明确拒绝 |
| NGT | O(|D|·d²) | O(d²) | conformal 有效性 |
| AFQ | O(H_max·(C_VOI+|Q|)) | O(|M|) | 非破坏、按人类分钟终止 |
| FMC | O(S·d+meta) | O(S·d) | 有界权重、晋升门、可回滚 |
| DSC | O(|σ|+|D|) | O(|J_d|) | 风险归因可审计、降级不可覆盖 |

**正确性定理（Transfer-Grounded Deployment Soundness, TGDS）**：在 A33–A36 之上加 **(A37)** 元先验元校准 `ECE_meta ≤ ε_π` 且适用域已声明；**(A38)** 新颖性门 conformal sound（`ν ≤ ν_max ⇒` 先验-数据冲突以 `1-α` 概率有界，无静默负迁移）；**(A39)** 少样本适应保校准且随 k 单调收紧；**(A40)** 舰队先验有晋升门、版本钉住与回滚。则：
1. **部署健全性**：当 `k ≥ k*` 且 `ν ≤ ν_max` 时，`P_fail ≤ δ_f + ε_cal + ε_π·1[prior] + ε_adapt(k) + ε_h`；
2. **自主单调性**：自主等级只在证据增加时上升，任何漂移/新颖性越界立即降级，运营方不可覆盖降级；
3. **上手成本可预测**：`k*(r)` 有限，或系统可在 `k_budget` 内诚实拒绝部署；
4. **负迁移有界**：`ν > ν_max` 时先验权重 `≤ β`，风险回到无先验基线加补探成本。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 先验在关键物理维度上自信地错 | 高 | 物理感知探针、留一站元校准、先验显式 ε_π 与置信区间 |
| 新颖性门盲区：指纹相似但动力学不同 | 高 | 多维物理指纹 + 主动探测最敏感维度 + 门失败即拒绝 |
| 舰队污染 / 数据隐私 | 高 | 有界权重、稳健聚合、联邦充分统计、隔离+金丝雀+回滚 |
| 运营方过度信任证书（自动化自满） | 中 | 证书显示剩余风险与不确定性、定期抽检、降级不可覆盖 |
| 元训练分布不覆盖真实站点（sim-to-real） | 中 | 域随机化 + 真实少样本校准 + 明确 dom(π) 与拒绝域 |
| 证书被 Goodhart 化 | 中 | 证书绑定可复现证据与事后审计、随机复核 |

## 6. 本轮最大风险

**一句话**：整个方案的 soundness 都条件于"先验校准 ∧ 新颖性门能识别偏移"，而最危险的新站点往往在廉价指纹上"眼熟"、却在真正决定成败的物理维度上陌生——于是少样本适应会自信地从先验插值，部署证书又会把先验误差记到"本地证据"账上并据此放行自主；先验因此成为新的单点故障，且压缩得越好，一个错先验能同时授权的部署越多——必须以物理感知的新颖性门、留一站元校准、先验版本/金丝雀/回滚，以及"拒绝部署"这一等公民结论来兜底。

# 第 57 轮产物 · 创新点清单 v33：MetaBoot（元证据先验×少样本引导×新颖性门控×部署证书，MEP×FBP×NGT×AFQ×FMC×DSC）

> 承接第 56 轮 IP-127~132（SMM/PCE/BVK/ISE/TAF/MEC）与 v32 的"证据承诺"体系。本轮把"证据地图"升级为 **"可迁移、可定价、可拒绝的证据资产"**：站点间只迁移**带不确定性的先验**，不迁移**决策**；用少样本本地证据把先验解压为后验；用新颖性门给"不像训练集"的站点降温；用部署证书把"能开多自主"变成一条带证据门槛、可预测工期、可回滚的阶梯。
> IP 编号：IP-133~IP-138（6 个新增），升级 IP-126/132 以纳入舰队先验与部署证书。

## 1. 符号体系增量（定义 133–138）

| 符号 | 含义 |

| `(ψ, ε_π, dom(π), ver)` | 先验记账四元组：参数/元校准误差/适用域/版本 |
| `κ_π(β)` | 先验有效精度（抵扣所需样本数） |
| `t(D_r), ν(r), ν_max` | 充分统计、先验-数据冲突分、conformal 门限 |
| `β = min(1, ν_max/ν)` | 温度后验中先验的保留指数（冲突越大越淡） |
| `k*(r)` | 达到目标风险 δ 所需本地样本数 |
| `Cost(k), k^†` | 上手总成本与最优样本数（含失败代价/停机代价） |
| `VOI_D(q)` | 查询的部署级信息价值（按人类分钟计价） |
| `w_s ≤ w_max^meta` | 站点进入元更新的有界权重 |
| `A0–A4` | 自主阶梯：遥操作/影子/监督/认证/漂移降级 |
| `J_d` | 部署-迁移证书（DSC） |
| `ε_π, ε_adapt(k), ε_local` | 先验误差 / 有限样本误差 / 本地证据误差 |

## 2. 关键算法伪代码

### IP-133 MEP（Meta-Evidence Prior）

```python
def meta_train(sites, epochs, K=5):
    psi = init_prior()
    for _ in range(epochs):
        loss, calib = 0.0, 0.0
        for s in sites:                                  # leave-one-site-out
            psi_s = inner_adapt(psi, s.train, k_shot=K)  # 少样本内循环
            loss  += nll(psi_s, s.val)
            calib += calibration_gap(psi_s, s.val)       # ECE 惩罚
        psi = outer_update(psi, loss + lam_c * calib)
    psi.eps_pi = empirical_ece_meta(psi, sites)
    psi.dom    = cover_region(sites)                     # 适用域声明
    return psi

def adapt_site(psi, site_evidence, k_budget, delta, alpha):
    beta = temper(novelty_site(site_evidence, psi), psi.nu_max)
    post = tempered_posterior(psi, site_evidence, beta)  # IP-135
    k_star = required_shots(post, psi, beta, delta, alpha)
    return post, beta, k_star
```

### IP-134 FBP（Few-shot Bootstrapping Protocol）

```python
def required_shots(post, psi, beta, delta, alpha):
    for k in range(0, k_budget + 1):
        if ucb_fail(post, k, alpha) <= delta:
            return k
    return INF                                           # 本站在预算内不可部署

def bootstrap_plan(site_fp, task, psi, budget):
    M = load_prior_map(site_fp, psi)                     # 先验地图投影到本站
    plan = {r: required_shots(*adapt_site(psi, M.init[r], ...))
            for r in reachable_regions(site_fp, task)}
    k_dagger = argmin_k(total_cost(k, plan, budget))     # 探针+人时+失败+停机
    if k_dagger > budget.k_budget:
        return REFUSE(reason='deployment_not_economically_sound', plan)
    return STAGE_PLAN(plan, k_dagger)

def total_cost(k, plan, budget):
    return (probe_cost(k, budget) + human_cost(k, plan, budget)
            + expected_fail_cost(k, plan) + expected_downtime_cost(k, budget))
```

### IP-135 NGT（Novelty Gate + Tempered Posterior）

```python
def calibrate_gate(psi, heldout_sites, alpha):
    scores = [mahalanobis2(sufficient_stats(s), psi.prior_predictive)
              for s in heldout_sites]
    return quantile(scores, 1 - alpha)                   # ν_max

def novelty_site(site_evidence, psi):
    return mahalanobis2(sufficient_stats(site_evidence), psi.prior_predictive)

def temper(nu, nu_max):
    return 1.0 if nu <= nu_max else min(1.0, nu_max / nu)

def tempered_posterior(prior, data, beta):
    return normalize(power_posterior(prior, beta) * likelihood(data))

def gate_decision(nu, psi, autonomy):
    if nu > psi.nu_max:
        return DROP(autonomy, to='A1'), 'novelty_exceeded', need_probe=True
    return KEEP(autonomy), 'prior_admissible', need_probe=False
```

### IP-136 AFQ（Active Few-shot Query）

```python
def active_query(M, psi, budget, task):
    while budget.human_min > 0 and budget.probes_left > 0:
        cands = [q for q in admissible_queries(M, psi, task)
                 if q.nondestructive]                     # 继承 A34
        if not cands: break
        q = argmax(cands, key=lambda x: voi_deploy(x, M, psi, task)
                   - x.human_min / c_ref)
        if voi_deploy(q, M, psi, task) < theta_d: break
        M = fuse(M, [execute(q)])
        budget.spend(q)
    return M
```

### IP-137 FMC（Fleet Meta-Consolidation，CEB++）

```python
def fleet_consolidate(psi_cur, submissions):
    subs = [s for s in submissions if s.calibration_ok]
    if not subs: return psi_cur, 'no_valid_submission'
    w = [min(w_max_meta, w0 * s.loso_cal) for s in subs]  # 有界 + 校准衰减
    cand = meta_update(psi_cur, subs, w)
    if loso_ece(cand, subs) > eps_pi:          return psi_cur, 'reject_prior'
    if poison_shift(cand, subs) > theta_poison: return psi_cur, 'reject_prior'
    if not canary_ok(cand):                     return psi_cur, 'reject_prior'
    return publish(cand, provenance={s.id: (s.t, s.h, s.nu) for s in subs}), 'promoted'
```

### IP-138 DSC（Deployment Certificate，MEC++）

```python
def deployment_certificate(M, psi, site, k_actual, autonomy):
    nu = novelty_site(site.evidence, psi)
    ks = {r: required_shots(*adapt_site(psi, M[r], ...)) for r in M.core}
    if any(k_actual[r] < ks[r] for r in ks):  return downgrade(autonomy, 'insufficient_shots')
    if nu > psi.nu_max:                       return downgrade(autonomy, 'novelty_gate')
    if not loso_calibrated(psi):              return downgrade(autonomy, 'prior_uncalibrated')
    if drift(site) > theta_drift:             return downgrade(autonomy, 'drift')
    if not all(l2.resolved for l2 in consent_log): return downgrade(autonomy, 'consent_open')
    return ('A3', DSC(ver_psi=psi.ver, fp=site.fp, nu=nu, k_star=ks,
                      k_actual=k_actual, eps_pi=psi.eps_pi,
                      eps_adapt=adapt_bound(k_actual),
                      eps_local=local_bound(M), drift=drift(site),
                      liabilities=evidence_balance_sheet(M, psi, nu),
                      rollback=rollback_plan(psi.ver)))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| MEP | 离线 O(E·S·K·d) | O(\|ψ\|+d) | 元校准（A37）、适用域显式 |
| FBP | O(\|R\|·k*·C_UCB) | O(\|R\|) | `k*` 有限或明确拒绝部署 |
| NGT | O(\|D\|·d²) | O(d²) | conformal 有效性（A38） |
| AFQ | O(H_max·(C_VOI+\|Q\|)) | O(\|M\|) | 非破坏（A34）、人类分钟终止 |
| FMC | O(S·d+meta) | O(S·d) | 有界权重、晋升门、可回滚（A40） |
| DSC | O(\|σ\|+\|D\|) | O(\|J_d\|) | 风险归因可审计、降级不可覆盖 |

**正确性定理（Transfer-Grounded Deployment Soundness, TGDS）**
假设 A33–A36（第 56 轮）成立；**(A37)** 元先验元校准 `ECE_meta ≤ ε_π` 且 `dom(π)` 已声明；**(A38)** 新颖性门由留一站 conformal 校准，`ν ≤ ν_max ⇒` 先验-数据冲突以 `1-α` 概率有界；**(A39)** 少样本适应保校准且后验随 `k` 单调收紧（`ε_adapt(k)↓`）；**(A40)** 舰队先验经留一站/抗污染/金丝雀晋升门，版本钉住且可回滚。则：

1. **部署健全性**：当 `k_actual ≥ k*` 且 `ν ≤ ν_max` 时，
   `P_fail ≤ δ_f + ε_cal + ε_π·1[prior] + ε_adapt(k_actual) + ε_h`；
2. **自主单调性**：自主等级只随证据增加而上升；漂移或新颖性越界立即降级，且运营方不可覆盖降级；
3. **上手成本可预测**：`k*(r)` 有限，否则系统在 `k_budget` 内给出 `REFUSE`，不静默放行；
4. **负迁移有界**：`ν > ν_max` 时先验被降温到 `β ≤ ν_max/ν`，风险退回"无先验基线 + 补探成本"，不会以旧站点经验强行覆盖本地。

**部署界（对新站点按区域取联合界）**：

```
P_safe ≥ 1 − Σ_r (δ_f + ε_cal + ε_π·1[prior] + ε_adapt(k_r) + ε_h)
             − P(ν > ν_max 未检出) − P(prior 版本回滚失败) − P(漂移告警失效)
```

关键：**先验只是被记账的证据**（有误差、有域、有版本），**决策规则固定而先验可换**（迁移不能改安全规则），**降级不可被商业压力覆盖**（运营方只能选更保守，不能选更冒险）。

## 6. 本轮最大风险

**一句话**：MetaBoot 的 soundness 条件于"先验校准 ∧ 新颖性门能识别偏移"，而最危险的新站点恰恰在廉价指纹上像训练集、却在真正决定成败的物理维度上陌生——少样本适应会自信地从先验插值，部署证书又会把先验误差记到"本地证据"账上并据此授权自主；先验由此成为新的单点故障，且压缩得越好，一个错先验能同时授权越多部署——必须以物理感知的新颖性门、留一站元校准、先验版本/金丝雀/回滚，以及"拒绝部署"这一等公民结论兜底。
