# 第 62 轮（承接第 61 轮「具身语义进化闭环」IP-173~182；灵感循环第 1 轮；本轮灵感：「模型蒸馏」×「模型预测控制」）

> 第 61 轮构建了 ESEC：USR 统一语义表征、MEL 多模态具身大模型、DMS 执行接地对话、SRT-Dual 语义-实时双流、PCE+++++ 六维预算。它把系统从「模块拼接」推进到「表征对齐」，但仍有**四个结构性局限**：
> 1. **蒸馏是「模态裁剪」不是「知识迁移」**：MEL 的 `distill`/`cached` 模式只是丢触觉/本体、复用 KV cache，属于输入消融；没有教师-学生监督信号，也没有误差界。一旦 `B_mel` 耗尽而降级，语义嵌入、物理先验、不确定性会**同时失准**，系统却不知道失准了多少。
> 2. **锚点是「点快照」不是「预测轨迹」**：SRT-Dual 只读取当前 `Anchor_t`；语义流延迟时只能 `K_p×0.8, K_d×1.2` 保守扩展。这是「事后降级」，无法补偿 200ms 推理延迟，更无法预判滑移/振动/力超限等**未来事件**。
> 3. **实时环是「反应式」不是「前瞻式」**：EEIS 每周期按当前 `delta_f_req` 编译，没有 receding-horizon 规划；语义意图被压成「当前约束标量」而非「未来 H 步可行轨迹」，导致接触模式切换时的力超调、约束抖动与能耗偏高。
> 4. **快慢流之间缺少「一致性契约」**：版本号 + 投影误差只能检测「语义-控制漂移」，无法约束「学生偏离教师」。蒸馏学生完全可能**自信地外推到教师从未认证的区域**，而系统仍签发证书。

## 0. 直觉与动机

**灵感 1（模型蒸馏 → 三通道语义-物理-不确定性蒸馏 SPUD）**
直觉：真正的蒸馏不是「少看几个模态」，而是「把教师的**决策充分统计量**搬到学生身上」。教师 `T = (MEL_full, MPC_teacher)`；学生 `S = (Enc_S, f_S, π_S, σ_S)`。蒸馏分三通道：
(i) **语义通道**——在 USR 中逐层对齐 `scene_emb / intent_emb / evidence_emb`；
(ii) **物理通道**——对 `φ_phys` 做异方差高斯 NLL，均值与方差一起迁移，让学生学会「不知道自己不知道」；
(iii) **决策通道**——不做全动作 MSE，而用 advantage-weighted regression 只蒸馏教师认为**重要**的近约束动作（高优势样本）。
再加 (iv) **安全通道**——按「离约束边界距离」给样本加权，学生动作必须落在教师认证包络内。
关键洞见：**蒸馏目标不是最小化动作误差，而是最小化「决策遗憾 + 安全违例」**；「看起来像教师」不等于「做得像教师」。

**灵感 2（模型预测控制 → 潜空间语义-物理 MPC LSP-MPC）**
直觉：第 61 轮的实时环是「看到误差再纠偏」的 PID 式反应；MPC 的价值是**在潜空间里先预演 H 步**。把 USR 融合嵌入、`φ_phys`、不确定性、上一帧证据拼成潜状态 `s_t`；学习潜动力学 `f_θ:(s_t,a_t)→s_{t+1}`；滚动优化「任务进度 + 阻抗平滑 + 能耗 + CVaR 风险 − 意图对齐」，约束为力/速度/阻抗/ERTC 周期。教师用完整模型 + 长时域（`H_t≈1s`，MPPI/CEM，~100–200ms）求「远视」轨迹；学生用蒸馏动力学 + 短时域（`H_s≈50–100ms`，热启动 + 1 步梯度，~0.5–1ms）做「近视」局部修正。
关键洞见：**不必让学生「重新规划」，只需让学生「热启动并局部修正」教师轨迹**；学生是「摊销求解器（amortized solver）」，不是「另一个规划器」。

**灵感 3（合流 → 蒸馏预测控制闭环 DPC-ESEC）**
直觉：把 SRT-Dual 的「点锚点」升级为**预测轨迹管（Predictive Trajectory Anchor, PTA）**。教师每 50–200ms 输出
`T_t = {(ŝ_{t+i}, K̂_{t+i}, Σ_{t+i})}_{i=0}^{H_t}`；实时流按当前延迟 `τ` 索引到 `t+⌈τ/Δt⌉`，**用未来点补偿延迟**。学生 MPC 以管中心为参考、以 `Σ` 为 tube 半径做 tube-MPC；一旦预测轨迹跑出管子或 conformal 区间不覆盖，触发教师重规划或预测安全滤波（PSF）。教师查询由 VOI 事件触发：高不确定性 / 师生分歧大 / 预测残差超限 / 分布漂移。
关键洞见：**快慢流一致性从「版本号相等」升级为「轨迹管包含 + 决策遗憾有界」**；一致性从「同一时刻相同」变成「同一未来可行」。

**灵感 4（MPC 反向喂蒸馏 → DAgger-MPC 数据飞轮）**
直觉：离线蒸馏最大的病是**协变量漂移**——学生自己走偏后，遇到的 states 从未被教师标注过。让教师 MPC 成为**反事实数据生成器**：学生先跑，跑出的状态交给教师 MPC 重新规划并标注「如果是我会怎么做」；重点挖掘**近边界硬负样本**（即将滑移、力即将超限、振动发散），迭代 `K` 轮。这样蒸馏分布从「教师演示分布」扩展到「学生错误分布 + 安全边界分布」。
关键洞见：**预测控制不仅消费蒸馏结果，还生产蒸馏数据**——两者构成闭环，而非单向压缩。

**灵感 5（预算 → PCE++++++ 八维预算）**
直觉：新增 `B_distill`（教师查询频率、学生更新迭代、保真度阈值、校准集大小）与 `B_mpc`（教师/学生时域、求解迭代、预测误差容忍、tube 余量）。VOI 统一决定「该问教师、该延长时域、该重蒸馏、还是该信学生」；降级链为「缩时域 → 换学生 → 冻结学生 → 解析兜底」，但**安全约束永不降级**。

**灵感 6（证书 → 预测一致性证书 J_pred）**
直觉：第 61 轮 `J_sem_exec` 证明「语义-执行一致」，但无法证明「学生预测可信」。`J_pred` 增加师生分歧度、conformal 预测覆盖、tube 包含率、蒸馏保真度、MPC 可行性，把「预测」纳入可审计证书。证书不再只回答「刚才做对了吗」，还回答「接下来会不会出事」。

## 1. 形式化定义（增量：定义 173–184）

**定义 173（三通道蒸馏 SPUD, Semantic-Physical-Uncertainty Distillation）**
`SPUD = (T, S, D, L_sem, L_phys, L_dec, L_safe, W)`，其中：
- **教师**：`T = (MEL_full, MPC_teacher)`，可同时给出语义嵌入 `E_T(x)`、物理先验 `(φ_T, σ_T)`、长时域动作 `a_T = π_T(s)` 与优势 `A_T(s,a)`
- **学生**：`S = (Enc_S, f_S, π_S, σ_S)`，轻量编码器 + 潜动力学 + 策略头 + 异方差头
- **四通道损失**：
  - 语义：`L_sem = E_{x∼D}[1 − cos(E_S(x), E_T(x))]`
  - 物理：`L_phys = E[ (φ_T−φ_S)²/(2σ_S²) + ½log σ_S² ]`（异方差 NLL，迁移均值与方差）
  - 决策：`L_dec = E_{s∼D, a∼π_T}[ w(A_T(s,a))·‖π_S(s)−a‖² ]`，`w(A)=softmax(A/β)`，只保留 top-k 优势样本
  - 安全：`L_safe = E_{x∼D}[ w_b(x)·max(0, −h(S(x))) ]`，`w_b = 1+λ_b·exp(−d(x)/δ_b)`，`d(x)` 为到约束边界距离，`h(·)≥0` 为安全集
- **总目标**：`L_SPUD = λ_sem L_sem + λ_phys L_phys + λ_dec L_dec + λ_safe L_safe`
- **决策保真度**：`DF = exp( −(‖π_S−π_T‖₁ + ‖φ_S−φ_T‖₁ + |U_S−U_T|) / σ_df ) ∈ (0,1]`
- **安全保持**：学生输出经 `Proj_{A_feasible}(·)` 投影，故**保真度只影响性能，不影响安全**（定义 180 给出保证）

**定义 174（潜空间语义-物理 MPC，LSP-MPC）**
`LSP-MPC = (S, A, f_θ, c, G, H, V_f)`，其中：
- **潜状态**：`s_t = [z_t; φ_t; U_t; e_t] ∈ ℝ^{d_s}`，`z_t` 为 USR 融合嵌入，`e_t` 为上一帧证据嵌入
- **动作**：`a_t = ΔK_t ∈ ℝ^{d_a}`（刚度/阻尼/力上限的增量）
- **潜动力学**：`s_{t+1} = f_θ(s_t, a_t) + w_t`，`‖w_t‖ ≤ ρ_t`（`ρ_t` 由定义 178 的 conformal 校准给出）
- **滚动优化**：
  ```
  min_{a_{0:H-1}}  J = Σ_{i=0}^{H-1} [ c_task(s_i) + λ_u‖a_i‖² + λ_s‖a_i−a_{i−1}‖²
                      + λ_r·CVaR_α(R(s_i,a_i)) − λ_i·⟨z_i, z_intent⟩ ]
                    + V_f(s_H)
  s.t.  s_{i+1}=f_θ(s_i,a_i),  g(s_i,a_i) ≤ 0,  a_i ∈ A_feasible,
        solve_time ≤ τ_mpc
  ```
- **教师 / 学生分工**：
  - 教师：`H_t ≈ 1s`，MPPI/CEM 采样，`τ_mpc ≈ 100–200ms`，输出长时域轨迹与价值 `V_f`
  - 学生：`H_s ≈ 50–100ms`，以教师轨迹热启动，只做 `n_grad` 步梯度/牛顿修正，`τ_mpc ≤ 1ms`

**定义 175（预测轨迹锚点 PTA, Predictive Trajectory Anchor）**
```
T_t = (version_t, t_0, Δt, H_t, τ_ttl,
       {(ŝ_{t+i}, K̂_{t+i}, Σ_{t+i})}_{i=0}^{H_t}, D_TS_t, q_cover_t)
```
- **管（tube）**：`Tube_i = { s : (s−ŝ_{t+i})ᵀ Σ_{t+i}^{−1} (s−ŝ_{t+i}) ≤ 1 }`
- **延迟索引**：实时流在时刻 `t_now` 读取，取 `i* = min(H_t, ⌈(t_now−t_0+τ_meas)/Δt⌉)`，返回 `(ŝ_{t+i*}, K̂_{t+i*}, Σ_{t+i*})`，实现**预测式延迟补偿**
- **有效性**：`fresh := (t_now−t_0) < τ_ttl`；`contained := s_now ∈ Tube_{i*}`；`cover := C_sem ≥ τ_csem`
- 与第 61 轮 `Anchor_t` 的关系：`Anchor_t = PTA` 在 `H=0` 时的退化特例

**定义 176（蒸馏预测控制闭环 DPC-ESEC）**
双速率级联 `DPC-ESEC = (TeacherLoop, StudentLoop, PTA, PSF, ETTQ)`：
- **教师环** `f_T ≈ 5–20Hz`：MEL 全模态推理 → 长时域 MPC → 写 PTA（含 `Σ`、`D_TS`、`q_cover`）
- **学生环** `f_S ≈ 1–10kHz`：读 PTA → 延迟索引 → 热启动短时域 MPC → PSF 校验 → 派发 `K_safe` → 证据回灌
- **交接契约**：学生状态必须落在 PTA 管内；若 `contained = false` 连续 `n_bad` 次，学生环降级为「跟踪 PTA 中心 + 保守 tube」并请求教师重规划
- **一致性**：`Consistent := contained ∧ (D_TS ≤ ε_div) ∧ (q_cover ≥ 1−α) ∧ (DF ≥ τ_df)`

**定义 177（事件触发教师查询 ETTQ）**
查询谓词 `Query(s) = true` 当且仅当以下任一成立且 `B_distill` 允许：
```
U_epistemic > θ_U                         # 学生认知不确定性高
D_TS > θ_div                              # 师生策略分歧大
r_t > q̂_{1−α}                             # 动力学残差超出 conformal 区间
D_shift > θ_shift                         # 分布漂移检测（USR 嵌入 MMD/能量分数）
(t − t_last_query) > T_refresh            # 定时刷新
```
并满足 VOI 判据：`VOI_teacher = E[ΔRegret] − cost_query > 0`。查询优先级：安全事件 > 残差 > 漂移 > 分歧 > 定时。

**定义 178（Conformal 动力学校准 CD）**
- **残差**：`r_t = ‖s_{t+1} − f_θ(s_t,a_t)‖`
- **静态校准**：在交换性假设下，取校准集 `D_cal` 的 `⌈(1−α)(n+1)⌉` 分位数 `q̂_{1−α}` 作为 tube 半径，得 `P(r_{t+1} ≤ q̂) ≥ 1−α`
- **自适应校准（非平稳接触动力学）**：`α_{t+1} = α_t + γ(α − err_t)`，`err_t = 𝟙[r_t > ρ_t]`，实现长程覆盖率的自适应维持（ACI）；`ρ_t ← q̂_{1−α_t}`
- **回退**：若连续 `W` 个窗口 `err_t > 2α`，判定动力学模型失效，强制教师重规划并冻结学生 MPC

**定义 179（预测安全滤波器 PSF）**
给定学生动作序列 `a_{0:H_s}`：
```
前向仿真：ŝ_{i+1} = f_θ(ŝ_i, a_i), i=0..H_s−1
若 ∃i: g(ŝ_i,a_i) > 0 或 ŝ_i ∉ Tube_i:
    ① 若存在最小修正 δa 使约束满足：a_i ← Proj_{A_feasible}(a_i) + δa
    ② 否则替换为 PTA 中同时间的教师可行段 a^T_{i}
    ③ 仍不可行：冻结学生，切换解析兜底（低刚度 + 高阻尼 + 限力 + 安全撤离）
```
- **保证**：若真实动力学误差满足 `‖w‖≤ρ`（定义 178 覆盖）且教师段可行，则 PSF 输出在 `1−α` 概率下可行；PSF 是**最后一道安全层，独立于蒸馏质量**

**定义 180（安全保持蒸馏 SDS, Safety-preserving Distillation）**
- **认证包络**：`E_cert = { (s,a) : h(s) ≥ 0, g(s,a) ≤ 0 }`（由教师 MPC 与 ERTC 共同定义）
- **学生动作投影**：`a_S^safe = Proj_{A_feasible(s)}(a_S)`
- **安全正则**：`L_safe` 中的 barrier 惩罚使学生在边界附近主动远离
- **保证**：`∀s, a_S^safe ∈ A_feasible(s)` 与蒸馏保真度无关；因此**蒸馏失败最多导致任务性能下降，不导致安全违约**（在 PSF 正常的条件下）

**定义 181（八维认知-语义-预测预算 PCE++++++）**
`B_cog8 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_distill, B_mpc)`，其中：
- `B_distill = (Teacher_query_rate, DAgger_iters, Fidelity_tol, Calib_set_size, Student_update_lr)`
- `B_mpc = (H_t, H_s, Solver_iters, Pred_err_tol, Tube_margin)`
- **扩展成本**：
  ```
  cost_cog8 = cost_cog5
            + λ_distill·(query_rate/Query_budget + (1−DF)/Fidelity_tol + DAgger_iters/Max_iters)
            + λ_mpc·(H_t/H_max + Solver_iters/Max_iters + ρ_t/Pred_err_tol)
  ```
- **VOI 决策**：`voi_cog8 = VOI_meta − cost_cog8 − cost_exec`；选择使 VOI 最大的动作（查询教师 / 延长时域 / 重蒸馏 / 直接执行）
- **降级链**：`H_t↓ → H_s↓ → 学生蒸馏模式 → 冻结学生（仅 PTA 跟踪）→ 解析兜底`；**安全集 `E_cert` 与 PSF 永不降级**

**定义 182（决策遗憾与蒸馏保真界）**
- **遗憾**：`Regret(s) = V^{π_T}(s) − V^{π_S}(s)`
- **保真度-遗憾关系**（可检验假设）：若学生动作误差 `‖π_S−π_T‖ ≤ ε_π` 且价值函数 `L_V`-Lipschitz，则 `Regret(s) ≤ L_V·ε_π`
- **证书条件**：`DF ≥ τ_df` 只保证「像教师」；要保证「做得好」，还需 `Regret ≤ ε_reg` 的在线估计（用教师 `V_f` 对同一状态重评），二者共同进入 `J_pred`

**定义 183（预测一致性证书 J_pred）**
```
J_pred = (J_sem_exec,
          D_TS,             # 师生策略分歧
          q_cover,          # conformal 实际覆盖率
          tube_contain,     # PTA tube 包含率
          DF,               # 蒸馏保真度
          Regret_hat,       # 在线遗憾估计
          mpc_feasible,     # 学生 MPC 可行性
          teacher_version, student_hash)
验证：Valid(J_pred) ⇔ Valid(J_sem_exec) ∧ (D_TS ≤ ε_div) ∧ (q_cover ≥ 1−α)
                    ∧ (tube_contain ≥ 1−α) ∧ (DF ≥ τ_df) ∧ (Regret_hat ≤ ε_reg)
                    ∧ mpc_feasible ∧ teacher_version 单调
```
- 与第 61 轮 `J_sem_exec` 的关系：`J_pred` 是其严格扩展；`J_sem_exec` 回答「过去一致吗」，`J_pred` 回答「未来可行吗」

**定义 184（DPC-ESEC 闭环算子）**
```
DPC-ESEC(M, x_t) =
  # 教师环（异步，5–20Hz）
  (φ_T, z_T, π_T, U_T) ← MEL_full(x_t)
  T_t ← MPC_teacher(z_T, φ_T, U_T, H_t)          # 长时域轨迹 + Σ + V_f
  PTA.commit(T_t)                                 # 版本号单调，CAS 写入
  if ETTQ.Query(state): S ← SPUD.distill(T, D ∪ DAgger(buffer))

  # 学生环（同步，1–10kHz）
  T ← PTA.read(t_now, τ_meas)                     # 延迟索引
  s_now ← USR.encode(x_t)
  a_S ← MPC_student.warm_start(T).solve(H_s, n_grad)
  if PSF.check(s_now, a_S, T) = fail:
      a_S ← PSF.repair(s_now, a_S, T)
  K_safe ← EEIS.compile(a_S, φ_T, T.Σ)
  cert ← ERTC.dispatch(K_safe)
  EV ← wait_contact(); USR.push_evidence(EV)
  J_pred ← build_pred_cert(EV, T, s_now, a_S, DF, q_cover, V_f)
  return K_safe, EV, J_pred
```

## 2. 关键算法伪代码

### IP-183 SPUD（三通道蒸馏）

```python
class SPUD:
    def __init__(self, teacher, student, d_us=256, k_top=8):
        self.T, self.S = teacher, student
        self.k_top = k_top
        self.opt = torch.optim.Adam(student.parameters(), lr=1e-4)
        self.calib = ConformalCalibrator(alpha=0.1)

    def loss(self, batch):
        x, phi_T, z_T, a_T, A_T, d_bound = batch
        z_S = self.S.enc(x)
        # (i) 语义通道
        L_sem = (1 - F.cosine_similarity(z_S, z_T, dim=-1)).mean()
        # (ii) 物理通道：异方差 NLL
        mu_S, log_sig_S = self.S.phys_head(z_S)
        L_phys = (((phi_T - mu_S) ** 2) / (2 * log_sig_S.exp() ** 2)
                  + log_sig_S).mean()
        # (iii) 决策通道：只蒸馏 top-k 优势样本
        pi_S = self.S.policy(z_S)
        w = torch.softmax(A_T / 0.1, dim=-1)
        topk = torch.topk(A_T, self.k_top, dim=-1).indices
        mask = torch.zeros_like(A_T).scatter_(-1, topk, 1.0)
        L_dec = (w * mask * ((pi_S - a_T) ** 2).sum(-1)).mean()
        # (iv) 安全通道：近边界样本加权 + barrier 惩罚
        w_b = 1 + 5.0 * torch.exp(-d_bound / 0.05)
        h = self.S.safety_margin(z_S)          # h>=0 为安全
        L_safe = (w_b * F.relu(-h)).mean()
        return (1.0 * L_sem + 1.0 * L_phys
                + 1.0 * L_dec + 2.0 * L_safe)

    def distill_step(self, batch):
        loss = self.loss(batch)
        self.opt.zero_grad(); loss.backward()
        torch.nn.utils.clip_grad_norm_(self.S.parameters(), 1.0)
        self.opt.step()
        return loss.item()

    def dagger_round(self, env, n_roll=32):
        """学生先跑，教师 MPC 对访问到的状态重新标注（反事实数据）"""
        data = []
        for _ in range(n_roll):
            s = env.reset()
            for t in range(env.horizon):
                a_S = self.S.act(s)
                s_next, _, _ = env.step(a_S)
                # 教师对 s 重新规划，而不是仅回放教师轨迹
                a_T, A_T, V_T = self.T.mpc.plan(s)
                d = env.distance_to_constraint(s)
                data.append((s, self.T.phi(s), self.T.embed(s),
                             a_T, A_T, d))
                s = s_next
        # 硬负样本优先：近边界 + 师生分歧大
        data.sort(key=lambda e: (e[5], -torch.norm(
            self.S.act(e[0]) - e[3])), reverse=False)
        return data[: max(256, len(data) // 2)]
```

### IP-184 LSP-MPC（潜空间语义-物理 MPC）

```python
class LatentSemanticMPC:
    def __init__(self, dynamics, cost, horizon, n_samples=512,
                 n_grad=2, mode='teacher'):
        self.f, self.cost = dynamics, cost
        self.H = horizon
        self.n_samples, self.n_grad = n_samples, n_grad
        self.mode = mode

    def plan(self, s0, intent_emb, Phi, U, warm=None):
        if self.mode == 'teacher':
            return self._mppi(s0, intent_emb, Phi, U)
        return self._warm_started(s0, intent_emb, Phi, U, warm)

    def _mppi(self, s0, z_int, Phi, U):
        """教师：采样式长时域规划，~100-200ms"""
        A = sample_action_sequences(self.H, self.n_samples, Phi)
        S, R = rollout_ensemble(self.f, s0, A, z_int, U)  # 支持不确定性
        J = self.cost(S, A, z_int) + self.risk_cvar(R, alpha=0.1)
        k = torch.argmin(J)
        return Trajectory(states=S[k], actions=A[k],
                          Sigma=self._tube(S), value=J[k])

    def _warm_started(self, s0, z_int, Phi, U, warm):
        """学生：热启动 + n_grad 步局部修正，~0.5-1ms"""
        a = warm.actions.clone().requires_grad_(True)
        for _ in range(self.n_grad):
            S = rollout(self.f, s0, a, z_int)
            J = self.cost(S, a, z_int) + self.risk_cvar(S, 0.1)
            g, = torch.autograd.grad(J, a)
            a = (a - 0.1 * g).detach()
            a = project_feasible(a, Phi)        # 安全投影，见 SDS
        return Trajectory(states=rollout(self.f, s0, a, z_int),
                          actions=a, Sigma=warm.Sigma, value=J.item())

    def _tube(self, S):
        # 用动力学 ensemble 的方差近似 tube 半径
        return S.var(dim=0).diag().sqrt()
```

```python
    def __init__(self, d_s, H=50, dt=0.01, ttl=0.3):

        anchor = PTA(version=self.version, t0=time.time(), dt=self.dt,
                     H=self.H, ttl=self.ttl,
                     states=traj.states, K=traj.K, Sigma=traj.Sigma,
                     D_TS=traj.D_TS, q_cover=traj.q_cover)

    def read(self, t_now, tau_meas):
        a = self.shm.read_latest()
        i = min(a.H, math.ceil((t_now - a.t0 + tau_meas) / a.dt))
        fresh = (t_now - a.t0) < a.ttl
        return a.at(i), fresh


class EventTriggeredTeacherQuery:
    def __init__(self, theta_U=0.7, theta_div=0.3, theta_shift=0.2,
                 T_refresh=1.0):
        self.theta_U, self.theta_div = theta_U, theta_div
        self.theta_shift, self.T_refresh = theta_shift, T_refresh
        self.t_last = -1e9

    def should_query(self, state, residual, q_hat, D_shift, budget, now):
        if not budget.can_query_teacher():
            return False
        hard = (state.U_epistemic > self.theta_U
                or residual > q_hat
                or D_shift > self.theta_shift
                or state.D_TS > self.theta_div)
        refresh = (now - self.t_last) > self.T_refresh
        if hard or refresh:
            self.t_last = now
            return True
        return False
```

```python
class ConformalCalibrator:
    def __init__(self, alpha=0.1, gamma=0.01):
        self.alpha, self.gamma = alpha, gamma
        self.residuals = deque(maxlen=2000)
        self.err_window = deque(maxlen=100)

    def calibrate(self, residuals):
        self.residuals.extend(residuals)
        n = len(self.residuals)
        if n < 30:
            return float('inf')
        k = math.ceil((1 - self.alpha) * (n + 1))
        return sorted(self.residuals)[min(k, n) - 1]

    def update_aci(self, r, rho):
        err = float(r > rho)
        self.err_window.append(err)
        self.alpha = min(0.5, max(0.01,
                          self.alpha + self.gamma * (self.alpha - err)))
        return self.calibrate([r])


class PredictiveSafetyFilter:
    def __init__(self, dynamics, teacher_buffer, tube_margin=1.0):
        self.f = dynamics
        self.buf = teacher_buffer
        self.margin = tube_margin

    def check(self, s0, actions, anchor):
        s = s0
        for i, a in enumerate(actions):
            s = self.f.step(s, a)
            if not feasible(s, a) or not inside_tube(s, anchor, i):
                return False
        return True

    def repair(self, s0, actions, anchor):
        a = actions.clone()
        for i in range(len(a)):

                a[i] = anchor.teacher_actions[i]
        # 最后兜底：解析安全控制
        if not self.check(s0, a, anchor):
            return analytic_safe_policy(s0)
        return a
```

```python
class CognitivePredictiveBudget:
    def __init__(self, cog5, distill=None, mpc=None):
        self.cog5 = cog5
        self.B_distill = distill or DistillBudget(
            query_rate=5, dagger_iters=3, fidelity_tol=0.1, calib_size=500)
        self.B_mpc = mpc or MPCBudget(
            H_t=50, H_s=10, solver_iters=2, pred_err_tol=0.05, tube_margin=1.0)
        self.mode = 'full'   # full, short_H, student, frozen, analytic

    def voi(self, action):
        base = self.cog5.voi_cog5(action)
        cost_distill = (action.query_rate / self.B_distill.query_rate
                        + action.dagger_iters / self.B_distill.dagger_iters
                        + (1 - action.DF) / self.B_distill.fidelity_tol)
        cost_mpc = (action.H_t / self.B_mpc.H_t
                    + action.solver_iters / self.B_mpc.solver_iters
                    + action.rho / self.B_mpc.pred_err_tol)
        return base - 0.1 * cost_distill - 0.1 * cost_mpc

    def degrade(self, status):
        if status.pred_err > 2 * self.B_mpc.pred_err_tol:
            self.mode = 'short_H'
        if status.distill_fidelity < self.B_distill.fidelity_tol:
            self.mode = 'student'
        if status.student_frozen:
            self.mode = 'frozen'
        if status.unsafe:
            self.mode = 'analytic'   # 安全集不降级
        return self.mode
```

1. **预测一致性**：若 `Valid(J_pred)`，则学生未来 `H_s` 步轨迹以 `≥1−α` 概率落在 PTA tube 内，且 `Regret ≤ ε_reg`。

```python
class SPUD:
    def __init__(self, teacher, student, k_top=8):
        self.T, self.S = teacher, student
        self.k_top = k_top
        self.opt = torch.optim.Adam(student.parameters(), lr=1e-4)

    def loss(self, batch):
        x, phi_T, z_T, a_T, A_T, d_bound = batch
        z_S = self.S.enc(x)
        L_sem = (1 - F.cosine_similarity(z_S, z_T, dim=-1)).mean()

        mu_S, log_sig_S = self.S.phys_head(z_S)
        L_phys = (((phi_T - mu_S) ** 2)
                  / (2 * log_sig_S.exp() ** 2) + log_sig_S).mean()

        pi_S = self.S.policy(z_S)
        w = torch.softmax(A_T / 0.1, dim=-1)
        topk = torch.topk(A_T, self.k_top, dim=-1).indices
        mask = torch.zeros_like(A_T).scatter_(-1, topk, 1.0)
        L_dec = (w * mask * ((pi_S - a_T) ** 2).sum(-1)).mean()

        w_b = 1 + 5.0 * torch.exp(-d_bound / 0.05)
        h = self.S.safety_margin(z_S)
        L_safe = (w_b * F.relu(-h)).mean()
        return L_sem + L_phys + L_dec + 2.0 * L_safe

    def dagger_round(self, env, n_roll=32):
        """学生先跑，教师 MPC 对访问到的状态重新标注（反事实数据）"""
        data = []
        for _ in range(n_roll):
            s = env.reset()
            for _ in range(env.horizon):
                a_S = self.S.act(s)
                s_next, _, _ = env.step(a_S)
                a_T, A_T, V_T = self.T.mpc.plan(s)
                data.append((s, self.T.phi(s), self.T.embed(s),
                             a_T, A_T, env.distance_to_constraint(s)))
                s = s_next
        data.sort(key=lambda e: (e[5],
                  -torch.norm(self.S.act(e[0]) - e[3])))
        return data[: max(256, len(data) // 2)]
```

```python
class LatentSemanticMPC:
    def __init__(self, dynamics, cost, horizon, mode='teacher'):
        self.f, self.cost, self.H, self.mode = dynamics, cost, horizon, mode

    def plan(self, s0, z_int, Phi, U, warm=None):
        if self.mode == 'teacher':
            A = sample_action_sequences(self.H, 512, Phi)
            S, R = rollout_ensemble(self.f, s0, A, z_int, U)
            J = self.cost(S, A, z_int) + self.risk_cvar(R, 0.1)
            k = torch.argmin(J)
            return Trajectory(S[k], A[k], self._tube(S), J[k])
        # 学生：热启动 + 2 步梯度，~0.5-1ms
        a = warm.actions.clone().requires_grad_(True)
        for _ in range(2):
            S = rollout(self.f, s0, a, z_int)
            J = self.cost(S, a, z_int) + self.risk_cvar(S, 0.1)
            g, = torch.autograd.grad(J, a)
            a = project_feasible((a - 0.1 * g).detach(), Phi)
        return Trajectory(rollout(self.f, s0, a, z_int), a,
                          warm.Sigma, J.item())


class DPCESEC:
    def __init__(self, mel, teacher_mpc, student_mpc, pta, psf,
                 ettq, usr, budget):
        self.mel, self.mpc_T, self.mpc_S = mel, teacher_mpc, student_mpc
        self.pta, self.psf, self.ettq = pta, psf, ettq
        self.usr, self.budget = usr, budget

    def teacher_loop(self, x):
        phi_T, z_T, pi_T, U_T = self.mel.full_infer(x)
        traj = self.mpc_T.plan(self.usr.fuse(z_T, phi_T, U_T),
                               z_T, phi_T, U_T)
        traj.D_TS = teacher_student_divergence(pi_T, self.mpc_S)
        traj.q_cover = self.psf.calib.coverage()
        self.pta.commit(traj)

    def realtime_step(self, x, tau_meas):
        ref, fresh = self.pta.read(time.time(), tau_meas)
        s_now = self.usr.encode(x)
        if not fresh or self.ettq.should_query(
                s_now, residual=self.psf.last_residual,
                q_hat=self.psf.calib.rho, D_shift=self.usr.shift_score(),
                budget=self.budget, now=time.time()):
            request_teacher_async(x)
        a_S = self.mpc_S.plan(s_now, z_int=ref.z, Phi=ref.phi,
                              U=ref.U, warm=ref)
        if not self.psf.check(s_now, a_S.actions, ref):
            a_S.actions = self.psf.repair(s_now, a_S.actions, ref)
        K_safe = EEIS.compile(a_S.actions, ref.phi, ref.Sigma)
        cert = ERTC.dispatch(K_safe)
        EV = wait_contact()
        J = build_pred_cert(EV, ref, s_now, a_S,
                            DF=self.budget.DF, q_cover=ref.q_cover,
                            V_f=ref.value, V_f_student=a_S.value,
                            teacher_version=ref.version)
        return K_safe, EV, J
```

```python
class PredictiveTrajectoryAnchor:
    def __init__(self, H=50, dt=0.01, ttl=0.3):
        self.H, self.dt, self.ttl = H, dt, ttl
        self.version, self.shm = 0, SharedMemoryTrajectory(H)

    def commit(self, traj):
        self.version += 1
        a = PTA(self.version, time.time(), self.dt, self.H, self.ttl,
                traj.states, traj.K, traj.Sigma, traj.D_TS, traj.q_cover)
        self.shm.write_cas(a)
        return a

    def read(self, t_now, tau_meas):
        a = self.shm.read_latest()
        i = min(a.H, math.ceil((t_now - a.t0 + tau_meas) / a.dt))
        return a.at(i), (t_now - a.t0) < a.ttl


class EventTriggeredTeacherQuery:
    def should_query(self, state, residual, q_hat, D_shift, budget, now):
        if not budget.can_query_teacher():
            return False
        hard = (state.U_epistemic > 0.7 or residual > q_hat
                or D_shift > 0.2 or state.D_TS > 0.3)
        if hard or (now - self.t_last) > 1.0:
            self.t_last = now
            return True
        return False
```

```python
class ConformalCalibrator:
    def __init__(self, alpha=0.1, gamma=0.01):
        self.alpha, self.gamma = alpha, gamma
        self.residuals = deque(maxlen=2000)

    def calibrate(self, residuals):
        self.residuals.extend(residuals)
        n = len(self.residuals)
        if n < 30:
            return float('inf')
        k = math.ceil((1 - self.alpha) * (n + 1))
        return sorted(self.residuals)[min(k, n) - 1]

    def update_aci(self, r, rho):
        err = float(r > rho)
        self.alpha = min(0.5, max(0.01,
                          self.alpha + self.gamma * (self.alpha - err)))
        return self.calibrate([r])


class PredictiveSafetyFilter:
    def check(self, s0, actions, anchor):
        s = s0
        for i, a in enumerate(actions):
            s = self.f.step(s, a)
            if not feasible(s, a) or not inside_tube(s, anchor, i):
                return False
        return True

    def repair(self, s0, actions, anchor):
        a = actions.clone()
        for i in range(len(a)):
            if not feasible(s0, a[i]):
                a[i] = project_feasible(a[i])
            if not feasible(s0, a[i]):
                a[i] = anchor.teacher_actions[i]
        return a if self.check(s0, a, anchor) else analytic_safe_policy(s0)
```

### IP-191/192 PCE++++++ + J_pred

```python
class CognitivePredictiveBudget:
    def __init__(self, cog5, distill, mpc):
        self.cog5, self.B_distill, self.B_mpc = cog5, distill, mpc
        self.mode = 'full'  # full, short_H, student, frozen, analytic

    def voi(self, action):
        base = self.cog5.voi_cog5(action)
        cd = (action.query_rate / self.B_distill.query_rate
              + action.dagger_iters / self.B_distill.dagger_iters
              + (1 - action.DF) / self.B_distill.fidelity_tol)
        cm = (action.H_t / self.B_mpc.H_t
              + action.solver_iters / self.B_mpc.solver_iters
              + action.rho / self.B_mpc.pred_err_tol)
        return base - 0.1 * cd - 0.1 * cm

    def degrade(self, status):
        if status.pred_err > 2 * self.B_mpc.pred_err_tol:
            self.mode = 'short_H'
        if status.distill_fidelity < self.B_distill.fidelity_tol:
            self.mode = 'student'
        if status.student_frozen:
            self.mode = 'frozen'
        if status.unsafe:
            self.mode = 'analytic'   # 安全集永不降级
        return self.mode

        mpc_feasible=anchor.feasible,
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SPUD（离线） | 教师标注 ~200ms/样本；学生 ~1ms | 学生 ~50MB（教师 ~2GB，压缩 ~40×） | 保真度 `DF≥τ_df`；安全违例 0（SDS+PSF） |
| LSP-MPC 教师 | ~100–200ms / 5–20Hz | O(H_t·d_s) | MPPI 可行性；tube 覆盖 1−α |
| LSP-MPC 学生 | ~0.5–1ms / ≥1kHz | O(H_s·d_s) | 热启动 + 投影可行；PSF 兜底 |
| PTA | 读 O(1) 索引 | O(H_t·d_s) 共享内存 | 版本号单调；CAS 无撕裂 |
| PSF | O(H_s) 前向 | O(1) | 模型误差 ≤ρ 时可行（概率 1−α） |
| PCE++++++ | O(1) | O(1) | 降级不降安全 |
| J_pred | O(1) | O(1) | 预测一致性可审计 |

**正确性定理（DPC-ESEC-Complete）**：
假设 A61–A70 及 **(A71)** `‖π_S−π_T‖≤ε_π`，`V` 为 `L_V`-Lipschitz；**(A72)** conformal 覆盖 `P(‖w_t‖≤ρ_t)≥1−α`，ACI 维持长程覆盖；**(A73)** 教师 MPC 在 `E_cert` 内可行，`V_f` 有界估计；**(A74)** PTA 版本单调、CAS 原子、索引在 `H_t` 内；**(A75)** PSF 先于 ERTC，安全集不随预算降级；**(A76)** `Regret ≤ f(D_TS,DF)` 单调可检验。
则：
1. **预测一致性**：`Valid(J_pred) ⇒` 学生未来 `H_s` 步以 `≥1−α` 概率落在 tube 内，且 `Regret ≤ ε_reg`。
2. **延迟补偿**：语义延迟 `τ≤H_t·Δt` 时，PTA 索引把等效延迟从 `τ` 降到 `Δt`。
3. **安全不降级**：即使 `DF→0` 或学生 MPC 发散，PSF + 解析兜底仍保证 `K_safe∈E_cert`（在 A72、A75 下）。
4. **实时性**：学生环 ≤1ms；教师环异步不阻塞；`B_mpc` 缩时域只减不增开销。
5. **预算局部最优**：VOI 贪心在给定预算下不劣于任一固定策略的即时回报。

## 5. 本轮最大风险

**一句话**：安全性依赖 conformal 覆盖与 tube 包含，而接触动力学的粘滑/碰撞/材料突变会破坏交换性，使 `ρ_t` 系统性低估、学生 MPC 在教师未覆盖区域自信外推——此时保真度越高、证书越漂亮反而越危险；必须以「ACI 在线覆盖监控 + 师生分歧硬阈值 + PSF 独立否决 + 漂移即冻结学生」构成不可绕过的安全否决层。
