### 第 1 轮灵感驱动研究记录（承接 CADVS-v5 状态）

**灵感词**：场景落地、抓取位姿估计

**继承关系**：状态文件记录到 CADVS-v5（IP-493~496），其核心是「任意生成器 + 七硬门认证边界」（CGE）：流匹配提议 FMPP、嵌入记忆固化 LMEM-v2、情感调制 FAMK、级联选证 EFA-v5，执行集 Exec_v5 ⊆ Exec_v4 ⊆ … ⊆ Exec_v29，并留下 R53（OOD 幻觉）、R57（固化自指博弈）等未解风险。本轮不推翻 v5，而是补它两个「落地」短板：(a) v5 的候选轨迹是自由形式的 pose/wrench 序列，末端位姿没有任何「这必须是一个可抓取位姿」的结构约束，而真实抓取的成败主要取决于抓取位姿前端；(b) v5 只在 MuJoCo 单机仿真中验证，仿真证书与真实世界之间的鸿沟（接触动力学、标定漂移、传感器退化、ODD 越界）没有被显式建模，也没有「证书何时失效」的概念。两个灵感词统一为主题「可落地的认证抓取」（Certified Grasp Deployment, CGD），形成 CADVS-v6（IP-497~500）。本轮自律：**硬门数量仍不增**（维持七门），把抓取位姿做成「提议重参数化 + 共形支撑集」，把场景落地做成「部署包络 + 单调收紧因子 δ + 证书有效期」，执行集升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ …。

**直觉与动机**：

1. **抓取位姿估计 → 把「自由轨迹提议」改成「抓取位姿 × 轨迹」的两级提议，但证书边界一寸不动**。直觉上，v5 让流策略从噪声直接生成末端轨迹，末端位姿只是轨迹的副产品；真实抓取却要求末端在接触时刻恰好落在一个「对掌/力闭合/可达」的抓取位姿上。解决方案不是加第八道门，而是**重参数化提议空间**：先用一个 SE(3) 等变抓取估计器 π_ψ^G(g|P) 给出抓取假设，再用**共形预测**把它变成带覆盖率保证的集合 C_α(P)（真值抓取以 ≥ 1−α 概率落在集合内）；流策略只在集合中的每个 g 上生成「接近—闭合—抬升」轨迹。因为门谓词一字未改，定理 6（证书不变性）自然推广为**两级提议不变性（定理 9）**：抓取前端换模型只改支撑集，不改认证边界。这一步同时把「抓取位姿估计」的统计不确定性（共形覆盖率）第一次显式接进认证框架。

2. **场景落地 → 用「部署包络 + 单调收紧因子」把 sim-to-real 鸿沟变成可计算的证书收缩，而不是一句免责声明**。直觉上，仿真里通过七门的轨迹，到真机上可能因摩擦系数偏差、相机外参漂移、点云缺失而失效。与其假装没有鸿沟，不如定义**运行设计域 ODD** 与**部署包络**，把可观测的部署不确定性 ξ（标定误差 ε_cal、传感器健康度 h、ODD 余量 m、分布漂移统计 ŝ）映射为对既有阈值的**非对称收紧** δ_i(ξ) ≥ 0：τ_i^6 = (1+δ_i)·τ_i^5。这与 FAMK 的 γ 完全同构（定理 5 的姊妹定理 11）：部署不确定性只能收紧、不能放松；一旦监测器判定 ODD 越界，δ_i → ∞，门不可行，fail-closed 安全停机。核心理论增量是**部署鸿沟定理（定理 10）**：若 p_real 与 p_sim 的总变差距离 ≤ ε_shift、门评分 Lipschitz，则真实违例率 ≤ 仿真违例率 + ε_shift + 标定项——它把「仿真结果能不能信」变成可声明、可审计的界，同时诚实指出 ε_shift 在高维感知下不可直接观测，只能保守上界。

3. **两者结合的关键洞见**：抓取位姿估计解决「提议的语义正确性」，场景落地解决「提议与认证在真实分布下的有效性」。v5 问的是「任意生成器下证书边界是否不变」；v6 问的是「当生成器的输出必须先落在一个统计上可保证的抓取集合里、并且真实分布偏离仿真时，证书还剩下多少、何时失效」。答案由三件事拼成：共形抓取集合（覆盖率）+ 部署包络收紧（单调收缩）+ 证书有效期 H（时间维度上的 fail-closed）。抓手是「把不确定性全部转成阈值收紧，永不放松、永不新增门」。

**形式化目标（增量）**：
1. 抓取位姿空间 G = SE(3) × G_cfg（夹爪构型）× S²（接近方向）；抓取估计器 π_ψ^G(g|P)，SE(3) 等变；共形分数 s_g(g,P)，校准集 D_cal，分位数 q_α，集合 C_α(P) = {g : s_g(g,P) ≥ q_α}。
2. 提升算子 L: (g, τ) ↦ x，使 x(1) 的末端位姿 = g；两级提议 π^two(g,τ|c) = π_ψ^G(g|P)·π_θ^FM(τ|c,g)。
3. 部署上下文 ξ = (ε_cal, h, m, ŝ, ODD 状态)；收紧因子 δ_i(ξ) 单调非减，ODD 越界 → δ_i = ∞。
4. 部署鸿沟：d_TV(p_real, p_sim) ≤ ε_shift；定理 10 给出 V_real ≤ V_sim + ε_shift + 标定项；证书有效期 H = ε_drift / ρ_drift。
5. 定理 9（两级提议不变性/抓取重参数化）、定理 10（部署鸿沟界）、定理 11（部署单调收紧与 ODD 越界 fail-closed）、定理 12（协变量漂移下共形覆盖率退化界）。
6. Exec_CADVS-v6 = {L(g,τ) : g ∈ C_α(P), τ ∈ supp(π_θ^FM(·|c,g)), ∧_i kc_i(L(g,τ); (1+δ_i)τ_i^5)=1} ⊆ Exec_CADVS-v5。

**本轮最大风险**：**仿真证书迁移幻觉**——部署鸿沟界依赖不可观测的 ε_shift，高维感知下只能靠代理量保守上界；当真实分布以监测器未覆盖的方式漂移（透明物体、反光、新型夹爪）时，仿真中「已认证」的轨迹会在真机上静默失效，而 fail-closed 只能抓住它被设计去抓的 ODD 越界，证书因此退化为「仿真自洽」而非「真实有效」。

## 2. 关键算法骨架

### IP-497 GPPK：抓取位姿提议核 + 共形支撑集（准入时域，10–30 Hz，与 1 kHz 环解耦）

```python
@dataclass
class GraspPoseProposalKernel:
    """GPPK：SE(3) 等变抓取估计 + split-conformal 支撑集。
    定理 9：抓取前端只改提议支撑，不改门——两级提议不变性。"""
    net: Any                      # SE(3)-equivariant backbone（等变卷积/注意力）
    q_alpha: float = 0.90         # 共形分位数（目标覆盖率 1-alpha）
    K_g: int = 16                 # 每帧抓取候选数
    score_fn: Any = None          # s_g：对掌/力闭合/碰撞/可达 的标量打分

    def score(self, g: Grasp, P: PointCloud) -> float:
        """仅用于排序与共形分数，不充当硬门（硬门仍是七门）"""
        return self.score_fn(g, P)

    def calibrate(self, D_cal: list[tuple[PointCloud, Grasp]]) -> float:
        """split conformal：q_alpha = Quantile({s_g(g_i,P_i)}_{i=1..n}, ceil((n+1)(1-alpha))/n)
        部署侧：按 ODD 条件分层校准 + 加权共形（定理 12）"""
        scores = sorted(self.score(g, P) for P, g in D_cal)
        n = len(scores)
        k = math.ceil((n + 1) * (1 - self.q_alpha))
        return scores[min(max(k, 1), n) - 1]

    def conformal_set(self, P: PointCloud) -> list[Grasp]:
        """C_alpha(P) = {g : s_g(g,P) >= q_alpha}；返回按分数降序的抓取"""
        cands = self.net.sample(P, self.K_g)          # SE(3) 等变采样
        return sorted((g for g in cands if self.score(g, P) >= self.q_alpha),
                      key=lambda g: self.score(g, P), reverse=True)
```

### IP-498 DEAK：部署包络 + 运行时保障 + 单调收紧（监控 10 Hz；阈值预计算）

```python
@dataclass
class DeploymentEnvelopeAssuranceKernel:
    """DEAK：ODD 规格 + 运行时监控 + 非对称收紧 δ + 证书有效期。
    定理 11：δ>=0 只紧不松；ODD 越界 -> δ=inf -> fail-closed 安全停机。"""
    odd: ODDSpec                  # 光照/杂物密度/人机距离/地面摩擦/物体类别 区间
    monitors: list[Monitor]       # 标定残差、点云完整度、掉帧、特征漂移
    beta: dict                    # 各门灵敏度 β_i（wrench/zmp 高，veto/val 中，ee 低）
    eps_cal_max: float = 0.02     # 标定残差归一化上限
    s_max: float = 3.0            # 漂移统计归一化上限
    delta_max: float = 0.5        # 收紧上限（防执行集塌缩，Δτ<=0.5τ^5）
    rho_drift: float = 0.01       # 漂移率上界 / 小时
    eps_drift: float = 0.08       # 漂移预算

    def context(self, obs) -> DeployCtx:
        eps_cal = self._calib_residual(obs)           # 手眼/相机标定残差
        h = self._sensor_health(obs)                  # 点云完整度/时延/掉帧综合∈[0,1]
        m_odd = self._odd_margin(obs)                 # 距 ODD 边界的归一化余量∈[0,1]
        s_hat = self._shift_stat(obs)                 # MMD/密度比/域分类器打分
        omega = IN_ODD if self.odd.contains(obs) else EXIT
        return DeployCtx(eps_cal, h, m_odd, s_hat, omega)

    def delta(self, xi: DeployCtx) -> dict:
        if xi.omega == EXIT:
            return {i: float('inf') for i in self.beta}    # fail-closed
        z = (xi.eps_cal / self.eps_cal_max
             + (1.0 - xi.h) + (1.0 - xi.m_odd) + xi.s_hat / self.s_max) / 4.0
        z = min(max(z, 0.0), 1.0)
        return {i: min(self.beta[i] * z, self.delta_max) for i in self.beta}

    def validity_horizon(self, xi: DeployCtx, consumed: float) -> float:
        """H = (eps_drift - consumed) / rho_drift；H<=0 必须重认证或安全停机"""
        return (self.eps_drift - consumed) / self.rho_drift
```

### IP-500 EFA-v6：两级提议 + 部署收紧 + 级联选证

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：七硬门不变 + 共形抓取支撑 + 部署收紧阈值 + 级联选证"""
    gppk: GraspPoseProposalKernel
    deak: DeploymentEnvelopeAssuranceKernel
    v5: EvidenceForgingAssemblerV5          # 复用 fmpp/lmem/famk/vack/bck 全套

    def select(self, x0_state, t_now, rule_id, context, obs) -> tuple[bool, Trajectory|None, str]:
        xi = self.deak.context(obs)
        delta = self.deak.delta(xi)                       # ODD 越界 -> inf
        if any(math.isinf(d) for d in delta.values()):
            return False, None, 'ODD_EXIT_SAFE_STOP'      # fail-closed
        if self.deak.validity_horizon(xi, context.consumed) <= 0:
            return False, None, 'CERT_EXPIRED_RECERT'     # 证书过期
        tau6 = {i: (1.0 + delta[i]) * TAU5[i] for i in GATES}

        # 第 0 层：共形抓取支撑集（廉价、SE(3) 等变；覆盖率有保证）
        G = self.gppk.conformal_set(obs.point_cloud)
        if not G:
            return False, None, 'NO_CONFORMAL_GRASP'

        # 第 1 层：抓取条件化的动作基元提议（Top-k 抓取 × K 个基元）
        cands = []
        for g in G[:self._grasp_topk]:
            c_g = build_ctx(context, g, self.v5.lmem)
            cands += [L(g, u) for u in self.v5.fmpp.propose(c_g, self._k_per_grasp)]

        # 第 2~4 层：复用 v5 级联，阈值换成 tau6
        surv = [x for x in cands if self._cheap_gates(x, tau6)]
        if not surv:
            return self._fallback_rule_proposal(tau6)
        surv.sort(key=self._prefilter_score, reverse=True)
        finals = [x for x in surv[:3]
                  if self.v5.vack.kc_val(self.v5.vack.evaluate(x, context, t_now),
                                         tau=tau6['val'])]
        ok = [x for x in finals if self._bck_preview(x, tau6)]
        if not ok:
            return False, None, 'ALL_CANDIDATES_REJECTED'
        return True, max(ok, key=certified_margin), 'FORGED_CGD'

    def ecs_v6(self, ..., n_flow, s_emo, s_g_max, xi) -> float:
        eta_grasp = sigmoid(s_g_max - self.gppk.q_alpha)
        z = min(1.0, (xi.eps_cal / 0.02 + (1 - xi.h) + (1 - xi.m_odd) + xi.s_hat / 3) / 4)
        eta_dep = 1.0 - self.lam_dep * z
        return self.v5.ecs_v5(..., n_flow, s_emo) * eta_grasp * eta_dep
```

## 4. 正确性论证（增量更新）

### 引理 45（split-conformal 抓取覆盖率）

**陈述**：若校准样本 (P_i,g_i*) 与测试样本 (P,g*) 可交换，分数 s_g 对称，则 P(s_g(g*,P) ≥ q_α) ≥ 1−α。∎

**诚实边界**：可交换性在部署侧被协变量漂移破坏，覆盖退化由定理 12 界定；共形保证的是「真值抓取在集合内」的边缘覆盖，不保证集合内每个 g 都可行。

### 引理 46（鸿沟代理上界的估计误差）

**陈述**：以 VC 维 d 的域分类器在 n 个带域标签样本上估计 d_TV(p_sim,p_real)，则 w.p. ≥ 1−δ：ε_shift ≤ ε̂_shift + O(√((d+log(1/δ))/n))。

**诚实边界**：该界只界定「估计误差」，不修复「代理类误设」导致的系统性低估——这是 R60 的根源。∎

### 定理 v6（两级提议 + 部署收紧的总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) 共形交换性、(B9) 域分类器代理可辨识 下：
(i) Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29；
(ii) 两级提议不变性：抓取前端换模型不改门（定理 9）；
(iii) 部署单调：δ ≥ 0 ⇒ Exec_v6(ξ) 随不确定性单调不增；ODD 越界 ⇒ ∅（定理 11）；
(iv) 部署鸿沟：V_real ≤ V_sim + ε_shift + Σ L_i ε_cal（定理 10）；
(v) 共形覆盖在漂移下 ≥ 1−α−ε_shift（定理 12）；
(vi) 证书有效期 H=(ε_drift−c_used)/ρ_drift 之外执行集按定义失效（时间维度 fail-closed）。

**证明**：(i) 同门 + 阈值只紧 + 支撑受限；(ii)~(v) 见定理 9~12；(vi) 由 H 定义与 DEAK 校验。∎

**诚实声明**：(B8) 在真实部署中通常不成立（新物体、新光照），只能靠 ODD 分层校准缓解；(B9) 的域分类器代理在高维感知下可能严重低估 ε_shift；共形覆盖是边缘的，非条件覆盖；δ 的系数 β_i 需人工标定，标定本身有主观性。

## 7. 本轮最大风险（最终确认）

**一句话**：**仿真证书迁移幻觉**——部署鸿沟界依赖不可观测的 ε_shift，高维感知下只能靠代理量保守上界；当真实分布以监测器未覆盖的方式漂移（透明物体、反光、新型夹爪）时，仿真中「已认证」的轨迹会在真机上静默失效，而 fail-closed 只能抓住它被设计去抓的 ODD 越界，证书因此退化为「仿真自洽」而非「真实有效」。
