# 第 3 轮（灵感循环续轮；本轮灵感：「力觉传感」×「迁移学习」）

> **编号说明**：状态文件基线为第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440），其下为第 1 轮 **LeanGauge**（IP-310–314；定义 398–415；引理 42–45；实验 E411–E425）与 **MODGAUGE**。按「在前人基础上改进」的纪律，本轮顺延为**第 3 轮**。
> **本轮纪律**：不造更大的闭环，不替换任何已有数值模块；只补 ToolGauge 的两个结构性缺口：
> （1）**模态缺口**：工具库 `T₀` 六个里五个是非接触的光学/热学工具，`tap.percuss` 只是单次盲敲；对透明/遮挡/形变/摩擦类盲区，接触才是唯一直接真值。更重要的是，MODGAUGE 的「反作用通道完备」不变式此前只被**声明**，未被物理建模——没有摩擦锥、接触刚度、冲量/损伤预算与滑移判据。
> （2）**复用缺口**：`MP-Φ` 只做「预训练→部署」单向迁移，靠 `TV(𝒟_dep,𝒟_env) ≤ η` 兜底；没有来源选择、可迁移性度量、负迁移防护、按源隔离；契约参数 `u_s` 未分解，坏源会同时污染所有盲区。
> MODGAUGE 五不变式、ToolGauge 的 TCV / 双层下注 / AP-Cal / P-Quarantine 全部保留；6C 扩为 **8C**；退化链延长为 `TactiGauge ⇐ ToolGauge ⇐ LeanGauge ⇐ MODGAUGE`。

**核心命题**：`TactiGauge = ToolGauge + C-Box + X-Box`。

- **C-Box** 把接触从「盲敲工具」升级为「带安全包络的接触真值通道」：把反作用通道完备不变式从一句声明变成力/力矩/摩擦锥/冲量/回退可达性的**可验证约束**（定义 433）。
- **X-Box** 把「预训练后整体迁移」升级为「**可迁移性审计 + 技能-残差分解**」：`u_s = B·z_shared + r_s`，仅低维共享技能 `z_shared` 允许迁移，`r_s` 一律本地校准。这直接针对第 2 轮最大风险——把「跨盲区相关偏差」限制在 `d_z` 维子空间，而不是盲区个数维，并支持按源精确切除（定义 436/443）。
- **可迁移性** `T_k` 用目标支撑集上的留出效应量估计加分布差异惩罚，构成可证伪的负迁移闸门；按源隔离把 P-Quarantine 的「全局刹车」升级为「定点切除」。

**三条可检验主张**：

1. 同预算下，C-Box 对透明/遮挡/形变类盲区的解析率比 ToolGauge 光学 + 盲敲基线高 ≥30%，且无计划外力违规为 0（E441/E452）。
2. 坏源注入下，X-Box 负迁移闸门使跨盲区偏差降低 ≥50%，同时保留 ≥80% 正迁移收益（E446/E448）。
3. 无量纲接触表示在声明的硬件差异包络内跨本体迁移，标定误差膨胀 <5%；超出包络时闸门触发率 ≥95%（E449/E450）。

**不变式保持声明**：

- MODGAUGE 五不变式全部保留；8C 新增的 T/X 两段只做**审计与门控**，不直接写数值通道；
- 主张绑定扩展：任何「已修复 / 更通用 / 跨本体有效 / 更高置信」主张必须引用 `TransferCert` 与接触回执，否则在契约序列化时剥离（定义 447）；
- **严格退化链延长**：C-Box 失效（禁止接触 / 不安全 / 传感器故障）⇒ 退回 ToolGauge 光学路径；X-Box 失效（无源过闸 / 证书无效）⇒ `z_shared=0`，退回目标单独 AP-Cal；再失效退回 LeanGauge / MODGAUGE。任何降级必须写 RED 日志与能力声明。

## 0.1 直觉

### 灵感 1（力觉传感 → 接触是盲区的「最后一公里真值」，也是最后一道风险）

直觉：ToolGauge 的探测本质上是「隔空推断」——IR、光照、双目、热漂移都是在不与对象发生力学耦合的前提下收集证据。这对大多数场景足够，但真实盲区里有一整类恰恰是**接触才能回答**的：透明/镜面（光学无回波）、被遮挡（视距不可达）、柔性形变（外观随接触改变）、低纹理/高反光（视觉特征退化）。接触能在局部给出直接证据：有没有碰到、碰在哪、法向/切向力多大、有没有滑、材料多硬。

但接触的代价与光学完全不同：

- (a) 接触会改变对象状态（压痕、划伤、位移），探测本身可能制造新的盲区；
- (b) 接触力必须留在摩擦锥与材料损伤包络内，否则「探测」变「破坏」；
- (c) 力/触觉信号强依赖本体检定（安装位置、胶层、温漂、迟滞），原始信号几乎不可跨硬件复用。

所以力觉传感的启示不是「再加一个传感器」，而是：**把接触当成一条需要安全包络、可辨识性检查与独立回执的一等证据通道**。这正好补上 ToolGauge「反作用通道完备」只声明未建模的缺口。

### 灵感 2（迁移学习 → 先测量「可迁移」，再迁移；只迁移共享的物理，不迁移本体的信号）

直觉：ToolGauge 的 `MP-Φ` 把「预训练→部署」当成单向知识流，用总变差距离 `η` 兜底。但真实迁移不是全有或全无：

- (a) 并非所有源都值得迁移，无关源会**负迁移**；
- (b) 有些参数普适（摩擦系数、接触刚度比、滑移起始规律），有些强绑定本体（力传感器零偏、增益、迟滞、安装柔度）；
- (c) 一旦坏源污染共享先验，所有盲区一起偏——第 2 轮已点名这个风险，但没有结构性防线。

迁移学习的启示是把它变成**可测量、可选择、可撤销**的过程：在目标支撑集上估计每个源的效应量，用负迁移闸门筛源，把参数分解成「共享技能 + 本地残差」，并按源隔离/撤回。于是「迁移」不再是一个信仰开关，而是一个有统计保证的准入决策。

### 灵感 3（耦合 → 迁移「接触物理」，不迁移「接触信号」）

直觉：接触技能天然适合迁移，因为接触物理（库仑摩擦、Hertz 接触、滑移起始）有强普适结构；但接触信号几乎不可迁移，因为传感器安装/胶层/温漂/迟滞都是本体指纹。因此我们定义**无量纲接触表示**

`z_c = (ρ/μ, k_c·δ_ref/F_ref, ω_slip/ω₀, patch 长宽比)`

- 这些量在量纲与增益上被归一，部分抵消传感器差异；
- 只迁移 `z_c` 的低维共享部分，增益/零偏/迟滞作为本地残差 `r_s` 每台机器重新辨识；
- 硬件差异用显式包络 `h(D_k,D_t) ≤ H_env` 约束，超出则只迁移无量纲物理子集并做少样本系统辨识。

这产生一个必须诚实面对的现象——**接触真值的假象**：触觉数据看起来像「地面真值」，但它其实是传感器-对象耦合信号；把共享技能当普适物理，可能让系统「有触觉证据地」集体偏错（见 §6）。

## 1. 形式化定义（增量：定义 432–447）

**定义 432（接触真值通道与接触证据）**
接触工具族 `T_C = {tac.press, tac.slide, tac.tap, ft.wrench, tac.vib}`，每个工具是定义 416 的 MTC 实例，带类型 schema、物理前置、回执谓词、代价、最坏时延与信息增益。一次接触证据

`e_c = (c_state, F_n, F_t, τ, δ, patch, t)`

其中 `c_state ∈ {free, contact, slip, impact}`，`F_n/F_t` 为法向/切向力，`τ` 为力矩，`δ` 为接触形变，`patch` 为触觉阵列接触斑（质心、面积、长宽比）。接触真值变量 `v_c = (contact_mask, material_class, μ, k_c, slip_flag)`，其中 `μ` 为摩擦系数、`k_c = dF_n/dδ` 为接触刚度。接触证据只回答 `v_c`，不进入 VLA 的语言通道（继承定义 429）。

**定义 433（接触安全包络 CSE）**
接触动作 `a` 关于当前快照 `ξ` 可容许，当且仅当：

1. 法向力 `0 ≤ F_n ≤ F_n^max(material) = min(σ_y·A_c/κ_s, F_sensor^max)`（材料屈服与传感器量程的较小者）；
2. 切向力 `|F_t| ≤ μ_s·F_n`（粘着）；若任务显式需要滑移辨识，则 `|F_t| ≤ μ_k·F_n` 且滑移速度 ≤ `v_slip^max`；
3. 力矩与形变 `|τ| ≤ τ_max`，`|δ| ≤ δ_max`；
4. 冲量/损伤预算 `∫|F_n|dt ≤ D_max`，接触时长 `≤ T_c`；
5. 反作用扳量 `W_r` 不使对象/抓取退出支撑多边形裕度 `m_poly ≥ 0`，且抓取扳量仍在摩擦锥内；
6. **回退可达**：存在有界时延动作 `a_retreat`，其前置在 `ξ` 下可满足且 `τ_retreat ≤ τ_safe`。

CSE 把「反作用通道完备」从声明变成可检查的物理约束；软件层不得绕过（定义 445 的硬件力上限）。

**定义 434（接触双层下注，扩展定义 419）**
- **安全门**：`S_c(a,s) = 1 ⇔ CSE(a,ξ) ∧ R_c^+(a,s) ≤ ρ_max`，其中 `R_c^+` 是接触风险模型给出的保守上界（由 `F_n`、摩擦裕度、滑移裕度、材料类别经查表/GP/logistic 得到）；
- **增益注**：`β_c(a,s) = Ĝ_c(a,s) − c_c(a) − λ_R·R_c^+(a,s) ≥ γ_B`，其中 `Ĝ_c` 为对接触真值变量 `v_c` 的期望熵减。
两门同过才执行；任一失败**不产生任何接触**（连轻触都不允许），因此物理副作用严格为零。CSE 判定失败时按定义 418 以完成前缀收尾。

**定义 435（接触-视觉一致性 CVC）**
对盲区 `s` 的视觉假设 `h_v` 与接触证据 `e_c`，定义一致性分数 `κ(h_v,e_c) ∈ [0,1]`（由材质类别、刚度量级、透明度、接触斑形状等预注册规则计算）。要求 `κ ≥ κ_min`。冲突处置：

- 视觉「刚性金属」而接触刚度极低 ⇒ 冲突，置 `VISION_SUSPECT`，但**不**自动信接触；
- 视觉「透明」而接触存在 ⇒ 相容，接触可提升置信；
- 接触可辨识性不足（定义 442）⇒ 接触降格为定性证据，置 `MODAL_CONFLICT`，退回 ToolGauge 光学路径。

CVC 是 SNC（定义 425）的跨模态扩展：SNC 查「语义-数值一致」，CVC 查「视觉-触觉一致」。

**定义 436（迁移源、技能-残差分解）**
源域集合 `D_k = (embodiment, sensor_suite, material_family, task, environment)`，`k=1..K`。契约参数 `u_s ∈ R^{d_u}` 分解为

`u_s = B_s·z_shared + r_s`，`B_s ∈ R^{d_u×d_z}`，`d_z ≪ d_u`，

其中 `z_shared` 是跨盲区/跨任务共享的计量技能（含无量纲接触子向量 `z_c`），`r_s` 是盲区/本体特定的残差。**只有 `B_s z_shared` 允许迁移；`r_s` 永远在目标上本地校准。** 源贡献可加时记 `z_shared = Σ_k z_k`，以便按源撤销。

**定义 437（可迁移性估计与负迁移闸门）**
目标域有留出支撑集 `S_t`（部署前采集、不参与日常校准）。对源 `k`：

`T_k = [L_{t,only}(S_t) − L_{t,k}(S_t)] / max(L_{t,only}(S_t), ε_L)`，

其中 `L_{t,only}` 为目标单独校准损失，`L_{t,k}` 为引入源 `k` 共享先验后的损失；`T_k > 0` 表示正迁移。分布差异 `disc_k = MMD²(φ_c(D_k), φ_c(D_t))`，源可靠度 `q_k`。定义置信下界

`LCB_k = T̂_k − ε_n − c_d·disc_k`，`ε_n = B_L·√(log(2K/δ)/(2n))`。

**负迁移闸门**：仅接受 `LCB_k ≥ τ_T > 0` 且 `q_k ≥ θ_k` 的源。多个源通过时，在 `|S| ≤ K_max` 预算下按边际效应做子模源选择（引理 52）。

**定义 438（迁移证书与按源隔离）**
`TransferCert(s) = (S_used, {T̂_k, disc_k, q_k}, dim(z_shared), r_s_calibrated, effect_size, δ)`，绑定进 EC.claims（定义 447）。

**按源隔离 S-Quarantine**：对每个源维护「其先验预测收缩 vs 实际收缩」的残差符号序列；连续 `≥ q` 次同向且幅度超过 `ε_src`，判定该源出现系统性偏差，执行 `Q_k = isolate`：从所有相关后验中精确减去 `B_s z_k`，重算受影响盲区，冻结/回退引用该源的热替换子图，重新排队受影响盲区。与 P-Quarantine（定义 428）的关系：后者是全局暂停，前者是**按源定点切除 + 其余照常**。

**定义 439（跨本体接触技能迁移与硬件差异包络）**
硬件差异 `h(D_k,D_t) = ||g_k − g_t||_Λ`，`g` 含增益、零偏、迟滞、安装柔度、采样率；包络为 `H_env`。

- 若 `h ≤ H_env`：直接迁移 `z_shared^c`，并允许有界修正 `||Δz|| ≤ κ_h·h`；
- 若 `h > H_env`：只迁移无量纲物理子集 `z_phys ⊂ z_shared`（摩擦比、刚度比、滑移频率比），要求目标上少样本系统辨识 `r_t`；否则不迁移。
误差界 `||u_t − u_t^*|| ≤ ||B||(||Δz|| + κ_h·h) + ||r_t − r_t^*||`。硬件差异被显式建模，而不是被忽略。

**定义 440（TactiGauge 8C 闭环）**
`H → C → E → T → X → C → V → U`：

1. **H**：D-Box/L-Box 生成共形假设集 `H_s`（继承定义 422）；
2. **C**：接触感知编译——VLA 只能在预注册工具内选，接触参数必须落在 CSE；TCV 逐条验证（继承定义 418）；
3. **E**：在显式 `CONTACTING` 状态执行（定义 445），双层下注 + 回执校验；
4. **T**（接触审计）：回执有效性（定义 441）、可辨识性（定义 442）、CVC（定义 435）；失败则退回光学路径；
5. **X**（迁移审计）：源选择、负迁移闸门、生成 `TransferCert`（定义 437/438）；
6. **C**（校准）：TC-Cal 以共享技能 + 本地残差输出后验；
7. **V**（验证）：独立接触回执交叉验证 + 跨模态一致性 + 契约回归（继承定义 421.V）；
8. **U**（更新）：热替换 + 绑定 `TransferCert` 与接触主张（定义 447）。

T 或 X 失败不阻断数值修复，只降级到 ToolGauge 的对应能力；V 失败则夹紧重试一次，再失败 stub + RED。

**定义 441（接触回执与有效性）**
`r_c = (t, args, obs=(F_n,F_t,τ,δ,patch), c_state, sig, ts, seq, q)`。

`valid_c(r_c) ⇔ Schema ∧ Pre_CSE(执行时刻) ∧ Post(力在包络内、无饱和、c_state 与信号一致) ∧ Verify(sig) ∧ seq 单调 ∧ ¬phantom ∧ ¬slip_ambiguous`。

- **幽灵接触**：`c_state=contact` 但 `F_n` 在噪声底内 ⇒ 作废；
- **滑移歧义**：切向振动存在但 `F_t` 低于阈值 ⇒ 标记歧义，只能作定性证据。

无效接触回执一律作废，**永不进入校准样本集**。这是定义 417 的接触扩展。

**定义 442（接触校准可辨识性）**
接触标定参数 `θ_c = (bias, gain, hysteresis, temp_coeff, μ, k_c) ∈ R^{d_c}`。Fisher 信息

`J_c(θ) = Σ_r (∂f_r/∂θ)^T Σ_r^{-1} (∂f_r/∂θ)`。

**可辨识条件**：有效秩 `= d_c`、`λ_min(J_c) ≥ λ_0`、条件数 `≤ κ_c`。若激励只含法向按压而无切向滑动/变载，则 `μ` 与 `k_c` 不可分辨，`rank(J_c) < d_c`。不可辨识 ⇒ 只允许定性接触证据（有/无接触、接触位置），**禁止**量化标定主张与热替换。

**定义 443（共享子空间相关偏差的局部化）**
在定义 436 的分解下，源误差 `δz` 引起的参数误差 `δu_s = B_s δz`。盲区间协方差

`Cov(δu_s, δu_{s'}) = B_s Cov(δz) B_{s'}^T`，秩 `≤ d_z`；

正交补 `(I − B_s B_s^+)δu_s = 0`，即**未迁移的局部参数不受污染**。按源隔离精确减去 `B_s z_k` 后，该源对迁移先验的残余贡献为 0（线性混合）；非线性混合时残余 `≤ L_B·||z_k||`。因此第 2 轮「一次错误先验污染所有盲区」的最坏相关维数由**盲区个数**降为 `d_z`，且可按源切除。

**定义 444（非平稳迁移与在线重估）**
迁移性非平稳（目标漂移、源质量衰减）。对每个源维护效应量 EWMA/CUSUM，每 `N_re` 次修复或漂移告警重估 `T_k`；源权重 `w_k(t) = exp(−λ_T(t−t_k))`。若 `LCB_k` 跌破 `τ_T` ⇒ 去选择；跌破 0 ⇒ 隔离。能力声明随之更新，禁止用过期的迁移证书。

**定义 445（CONTACTING 显式状态，扩展定义 430）**
接触期间系统进入显式 `CONTACTING` 状态：阻抗/柔顺控制、逐轴力上限、力矩硬限制、看门狗 `τ_wd`、回退策略常驻待命、原始力/触觉全录、（人机协作场景）对操作者可见。**力上限由硬件限幅器执行**，软件缺陷不能突破 `F_n^max`。接触控制环以 ≥1kHz 独立运行，50Hz 计量路径只看到状态标志与 O(1) 安全监视器。

**定义 446（退化链与继承）**
未重定义的第 2 轮记号（`T₀`、TCV、`λ/β`、`MP-Φ`、AP-Cal、`H_s`、P-Quarantine、EC、`M_ver` 等）沿用定义 416–431。令 `T_C = ∅`、`X-Box = target-only`（`z_shared ≡ 0`）⇒ `TactiGauge ≡ ToolGauge`。退化链：`TactiGauge ⇐ ToolGauge ⇐ LeanGauge ⇐ MODGAUGE`；每次降级写 RED、能力声明（接触可用？迁移可用？）与原因。

**定义 447（迁移-接触主张绑定，扩展定义 423/444）**
任何「已修复 / 更通用 / 跨本体有效 / 更高置信」主张必须引用 `TransferCert`、接触回执与 `n_eff`、可辨识秩；数值必须逐字引自回执。无有效证书或引用无效回执的主张在契约序列化时**剥离**；剥离是纯投影，不改变任何数值行为。禁止「摸了一下就宣布普适成功」。

## 3. 推导

**引理 51（接触探测的安全-信息联合界）**
设接触力 `F_n = F_n^cmd + ξ`，`ξ` 关于命令值条件亚高斯、参数 `b_F`；滑移起始的切向振动包络有界；CSE 以安全裕度 `Δ_F = F_n^max − F_n^cmd > 0` 执行。则：

- (a) 单次越限概率 `P(F_n > F_n^max) ≤ exp(−Δ_F²/(2b_F²)) + P_slip`，其中 `P_slip ≤ exp(−(μ_s F_n^cmd − |F_t|)²/(2b_t²))`；
- (b) 在可辨识条件（定义 442）成立时，接触观测对 `v_c` 的期望信息增益 `Ĝ_c ≥ ½ log(1 + σ_prior²/σ_obs,c²)`（高斯情形取等）；
- (c) 安全门或增益注任一失败 ⇒ 不产生任何接触 ⇒ 物理副作用严格为零。

系：接触探测把「越限」从不可控风险变成可计算尾概率；硬件力上限（定义 445）保证软件错误不能突破 `F_n^max`。

**引理 52（负迁移闸门的统计保证与源选择）**
设目标支撑集 `S_t` 有 `n` 条留出接触回执，损失有界于 `[0,B_L]`；对源 `k` 的效应量估计满足 `P(|T̂_k − T_k| > ε_n) ≤ δ/K`，`ε_n = B_L√(log(2K/δ)/(2n))`（Hoeffding）。定义 `LCB_k = T̂_k − ε_n − c_d·disc_k`，只接受 `LCB_k ≥ τ_T > 0` 且 `q_k ≥ θ_k` 的源。则：

- (a) 以概率 `≥ 1−δ`，所有被接受源的**真实**效应量 `T_k ≥ T̂_k − ε_n ≥ LCB_k + c_d·disc_k ≥ τ_T + c_d·disc_k > 0`——**不会发生负迁移**；
- (b) 随 `n` 增加，`ε_n = O(n^{-1/2})`，闸门变松，正迁移收益可被更充分地兑现；
- (c) 在源贡献条件独立的假设下，多源选择目标关于源集合单调子模，贪心达 `(1−1/e)`。

证明：`T_k ≥ T̂_k − ε_n` 由估计误差界；代入接受条件即得 (a)；(b) 由 `ε_n` 阶数；(c) 由互信息的次模性与 Lautum–Schapire 源选择框架。

**引理 53（共享子空间相关偏差的局部化与可撤销性）**
设 `u_s = B_s z + r_s`，`rank(B_s) ≤ d_z`，源贡献可加 `z = Σ_k z_k`。

- (a) 任一源误差 `δz_k` 引起的盲区间协方差 `Cov(δu_s, δu_{s'}) = B_s Cov(δz_k) B_{s'}^T`，秩 `≤ d_z`；其正交补为零，即未迁移的局部参数不受污染；
- (b) 按源隔离精确减去 `B_s z_k` 后，该源对迁移先验的残余贡献为 0；非线性混合时残余 `≤ L_B·||z_k||`（`L_B` 为 `B_s z` 的局部 Lipschitz 常数）；
- (c) 因此第 2 轮「一次错误先验污染所有盲区」的最坏相关维数由 `|盲区数|` 降为 `d_z`，且可按源切除。

**注意**：若真实物理不在 `range(B)` 内（模型设定错误），误差仍会沿 `range(B)` 相关传播——这正是 §6 的风险，不能被本引理消除。

**引理 54（接触校准的可辨识性与样本复杂度）**
接触参数 `θ_c ∈ R^{d_c}`，Fisher 信息 `J_c(θ) = Σ_r (∂f_r/∂θ)^T Σ_r^{-1}(∂f_r/∂θ)`。

- (a) 局部可辨识 ⇔ `rank(J_c) = d_c`；若激励只含法向按压（无切向滑动/变载），则 `μ` 与 `k_c` 不可分辨，`rank(J_c) < d_c`；
- (b) 在 `λ_min(J_c) ≥ λ_0 > 0` 且观测噪声上界 `σ_max` 下，`||θ̂ − θ*|| ≤ ε` 需 `n ≥ C·d_c·σ_max²/(ε² λ_0)`；
- (c) 不满足 (a) ⇒ 只允许定性接触证据，**禁止**量化标定主张与热替换。

这把定义 426 的「样本数门槛」推广为「**激励秩 + Fisher 条件数 + 有效样本量**」三重门槛。

**引理 55（无接触、无迁移时的精确退化）**
令 `T_C = ∅`、`X-Box = target-only`（`z_shared ≡ 0`，只保留 `r_s` 本地校准）⇒ 8C 退化为 ToolGauge 6C，定义 432–447 不改变任何数值行为；定义 416–431 与引理 46–50 原样成立。故 TactiGauge 是 ToolGauge 的**保守扩展**，新增风险只来自 C-Box 与 X-Box。

**引理 56（时序、安全与预算保持）**
接触环运行在 50Hz 计量路径之外，处于显式 `CONTACTING` 状态（定义 445）：硬件力/力矩上限、看门狗、冲量预算与有界回退策略共同保证单次接触时长 `≤ T_c`、冲量 `≤ D_max`、回退时延 `≤ τ_safe`。50Hz 路径新增仅状态标志与回执校验 `O(1) < 0.3ms`；迁移审计 `O(K·n_s·d_z + MMD)` 异步 `≤ τ_X`；单盲区总时延 `≤ T_c + τ_X + τ_AP ≤ τ_repair`。预算耗尽或审计失败按 TB-Contract 降级 ⇒ 引理 45/50 的硬实时与预算不变式保持。

> 但它留下两个结构性缺口：
> （1）**模态缺口**：工具库 `T₀` 六个里五个是非接触工具，`tap.percuss` 只是单次盲敲；对透明/遮挡/形变/摩擦类盲区，接触才是直接真值；且「反作用通道完备」不变式只声明、未物理建模。
> （2）**复用缺口**：`MP-Φ` 只做单向「预训练→部署」迁移，靠 `TV ≤ η` 兜底；没有来源选择、可迁移性度量、负迁移闸门、按源隔离；`u_s` 未分解，坏源会同时污染所有盲区。
> 本轮以「力觉传感 × 迁移学习」为灵感，**在 ToolGauge 之上**补这两个缺口，不替换任何数值模块。
>
> **集成链：MODGAUGE ⊃ LeanGauge ⊃ ToolGauge ⊃ TactiGauge**。
> 6C → **8C**：`H(ypothesize) → C(ompile) → E(xecute) → T(actile audit) → X(transfer audit) → C(alibrate) → V(erify) → U(pdate)`。
> IP 编号：IP-321–327（共 7 个）；定义增量 432–447；引理增量 51–56；实验增量 E441–E455。
> 理论姿态：不改变五不变式；新增「接触安全包络」为可审计的物理约束、新增「迁移审计」为可证伪的准入决策；**严格退化链延长**。

## 2. 形式化定义（要点）

**定义 432（接触真值通道）** 接触工具族在预注册 schema/包络内产生 `e_c`；只回答 `v_c`，不进入 VLA 语言通道（继承定义 429）。接触是遮挡/透明/形变类盲区的直接证据。
**定义 433（CSE）** 六条可容许性：法向力 ≤ 材料屈服与传感器量程的较小者；切向力在静/动摩擦锥内；力矩/形变有界；冲量 `∫|F_n|dt ≤ D_max`、时长 `≤ T_c`；反作用扳量保持支撑多边形裕度与抓取摩擦锥；存在有界时延回退动作。软件不得绕过，硬件限幅器兜底（定义 445）。
**定义 434（接触双层下注）** 安全门 `CSE ∧ R_c^+ ≤ ρ_max`；增益注 `Ĝ_c − c_c − λ_R R_c^+ ≥ γ_B`；两门同过才接触，任一失败零副作用。
**定义 435（CVC）** `κ(h_v,e_c) ≥ κ_min`；冲突时置 `VISION_SUSPECT` 或 `MODAL_CONFLICT`；接触不可辨识时不得用接触压过视觉，退回 ToolGauge。
**定义 436（技能-残差分解）** `u_s = B_s z_shared + r_s`，源贡献可加 `z_shared=Σz_k`；只迁移共享技能，残差本地校准。
**定义 437（负迁移闸门）** `T_k=[L_only−L_k]/max(L_only,ε)`；`LCB_k=T̂_k−ε_n−c_d·disc_k`；仅接受 `LCB_k ≥ τ_T>0 ∧ q_k ≥ θ_k`；多源走子模选择（引理 52）。
**定义 438（迁移证书与按源隔离）** 证书绑定主张；某源残差连续 `q` 次同向超阈 ⇒ `isolate`：精确减去 `B_s z_k`、重算受影响后验、冻结引用它的热替换子图、其余照常。
**定义 439（跨本体接触迁移）** `h ≤ H_env` 时迁移 `z_shared^c` 并允许 `||Δz|| ≤ κ_h h`；`h > H_env` 时只迁移无量纲物理子集 + 目标少样本系统辨识；误差界 `||B||(||Δz||+κ_h h)+||r_t−r_t^*||`。
**定义 440（8C）** H（共形假设）→C（接触感知编译+TCV）→E（CONTACTING 执行）→T（有效性/可辨识性/CVC）→X（源选择/负迁移闸门/证书）→C（TC-Cal）→V（独立接触回执 + 跨模态 + 契约回归）→U（热替换 + 绑定证书）；T/X 失败各自降级，V 失败夹紧重试一次再 stub+RED。
**定义 441（接触回执）** `valid_c ⇔ Schema ∧ Pre_CSE ∧ Post(包络内/无饱和/状态一致) ∧ 签名 ∧ seq 单调 ∧ ¬phantom ∧ ¬slip_ambiguous`；作废回执永不进入样本集。
**定义 442（可辨识性）** `rank(J_c)=d_c`、`λ_min(J_c)≥λ_0`、`cond≤κ_c`；仅法向按压时 `μ/k_c` 不可分辨 ⇒ 只允许定性证据，禁止量化标定与热替换。
**定义 443（共享子空间局部化）** 源误差只沿 `B_s` 的 `d_z` 维子空间传播；`Cov` 秩 ≤ `d_z`；正交补为零；按源精确减去 `B_s z_k` 后残余为 0（线性）/`≤L_B||z_k||`（非线性）。第 2 轮「污染所有盲区」的最坏相关维数从盲区数降为 `d_z`。
**定义 444（非平稳迁移）** 每 `N_re` 次修复或漂移告警重估 `T_k`；源权重 `exp(−λ_T(t−t_k))`；`LCB` 跌破 `τ_T` 去选择、跌破 0 隔离；过期证书不得使用。
**定义 445（CONTACTING）** 阻抗/柔顺控制、逐轴力上限、力矩硬限、看门狗、回退常驻、原始数据全录；力上限硬件执行；接触环 ≥1kHz，50Hz 路径只看标志。
**定义 446（退化与继承）** 继承定义 416–431；`T_C=∅` 且 `z_shared=0` ⇒ 精确退化为 ToolGauge；退化链 `TactiGauge⇐ToolGauge⇐LeanGauge⇐MODGAUGE`，每次降级写 RED + 能力声明。
**定义 447（迁移-接触主张绑定）** 「已修复/更通用/跨本体有效/更高置信」必须引用 `TransferCert` + 接触回执 + `n_eff` + 可辨识秩；数值逐字引自回执；否则序列化时剥离（纯投影，不改数值行为）。

```python
# IP-321/322 C-Box：接触真值通道 + 安全包络
class CBox:
    def plan_contact(self, H_s, state):
        cand = [t for t in T_C if CSE.feasible(t, state)]          # 定义 433
        return self.planner.compile(H_s, cand)                     # 送 TCV
    def estimate(self, rs):
        if not identifiable(rs):                                   # 定义 442
            return ContactTruth(mode="qualitative", slip=..., patch=...)
        return ContactTruth(mode="quantitative", F_n=..., mu=...,
                            k_c=..., rank=..., cond=...)

def contact_gate(a, s, H_s, model):                                # 定义 434
    safe = CSE.feasible(a, model.state) and model.risk_upper(a, s) <= RHO_MAX
    gain = model.contact_gain(a, s, H_s) - a.cost - LAM_R * model.risk(a, s)
    return safe and gain >= GAMMA_B

# IP-323 X-Box：可迁移性 + 负迁移闸门 + 子模源选择
class XBox:
    def transferability(self, S_t, src):
        base = self.loss_target_only(S_t)
        with_src = self.loss_target_with_source(S_t, src)
        T = (base - with_src) / max(base, EPS_L)
        disc = self.mmd(self.phi_c(src), self.phi_c(self.target))
        return T, disc, self.reliability(src)
    def select(self, S_t, sources):
        n = max(len(S_t), 1); ok = []
        for k in sources:
            T, disc, q = self.transferability(S_t, k)
            lcb = T - B_L * sqrt(log(2 * K / self.delta) / (2 * n)) - C_D * disc
            if lcb >= TAU_T and q >= THETA_K: ok.append((k, lcb))
        return submodular_source_select(ok, self.K_MAX)            # 引理 52

# IP-324 TC-Cal：技能-残差分解
class TCCal:
    def calibrate(self, receipts, H_s, s, sources):
        z = self.mp_phi.shared(featurize_ctx(receipts, H_s, s))
        r = self.local_residual(receipts, s)                       # 永远本地
        u = self.B[s] @ z + r                                      # 定义 436
        Sig = clamp_min(self.mp_phi.cov(...), KAPPA_PHYS)
        return u, Sig, z, r
    def transfer_prior(self, s, sources):
        z = sum(self.w[k] * self.z[k] for k in sources)
        return self.B[s] @ z, self.shared_cov(sources)

# IP-325 按源隔离
class SourceQuarantine:
    def record(self, k, pred, real): self.resid[k].append(sign(real - pred))
    def triggered(self, k, q=3):
        return (len(self.resid[k]) >= q and len(set(self.resid[k][-q:])) == 1
                and abs(self.mean_resid[k]) >= EPS_SRC)
    def isolate(self, k):
        self.ledger.retract_source(k)                              # 减去 B_s z_k
        self.xbox.remove(k)
        return self.affected_blind_spots(k)

# IP-326 TactiGauge-8C
def tactigauge_8c(M, s):
    H = M.lbox.hypothesize(s, M.dbox.R[s])                         # H
    prog = M.tbox.compile(H, M.cbox.plan_contact(H, M.env.snapshot()))
    prog = M.tcv.verify_then_filter(prog, M.budget_left(s))        # C
    receipts = M.tcv.execute(prog, M.env)                          # E（CONTACTING）
    truth = M.cbox.estimate(receipts)                              # T
    if not receipts_valid(receipts) or not M.cbox.cvc_ok(H, truth):
        return optical_fallback_or_stub(s, "contact_audit")
    srcs = M.xbox.select(M.support(s), M.sources)                  # X
    mu, Sig = M.tccal.calibrate(receipts, H, s, srcs)              # C
    if not M.tccal.cross_validate(mu, Sig, M.independent_contact_receipt(s)):
        return stub_and_red(s, "cross_failed")                     # V
    if not M.claims_ok(H, receipts, truth, srcs):
        return strip_claims_or_stub(s)                             # 定义 447
    new_ec = M.tccal.update_contract(M.dpe, mu, Sig, s)            # U
    if not contract_regression(new_ec): return stub_and_red(s, "regression")
    M.mreg.hot_replace(M.dpe, new_ec)
    M.dbox.update_from_posterior(s, mu, Sig)
    bind_transfer_cert(new_ec, srcs, truth, M.xbox.certs(srcs))
    for k in srcs: M.squar.record(k, M.tccal.pred[k], realized(receipts, k))
    return True

# IP-327 主闭环
def TactiGauge_round(M, obs, audio, tac, depth, det):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s); submit_async(tactigauge_8c, M, s)
    for k in M.squar.triggered_sources(): M.squar.isolate(k)
    if M.xbox.nonstationary(): M.xbox.reestimate()
    if M.pquar.triggered(): M.tccal.pause(); M.use_bpcal_fallback = True
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 4. 推导

**引理 51（接触安全-信息联合界）** 亚高斯力噪声、有界滑移包络、CSE 安全裕度 `Δ_F>0` 下：`P(F_n>F_n^max) ≤ exp(−Δ_F²/2b_F²)+P_slip`；可辨识时 `Ĝ_c ≥ ½log(1+σ_prior²/σ_obs,c²)`；门失败 ⇒ 零接触、零副作用。
**引理 52（负迁移闸门）** `LCB_k=T̂_k−ε_n−c_d disc_k`，`ε_n=B_L√(log(2K/δ)/(2n))`；仅接受 `LCB_k≥τ_T>0` ⇒ 以概率 `1−δ` 真实 `T_k ≥ τ_T + c_d disc_k > 0`，**不发生负迁移**；`ε_n=O(n^{-1/2})` 随目标支撑集增长而收紧；条件独立时多源选择单调子模，贪心 `(1−1/e)`。
**引理 53（共享子空间局部化）** `u_s=B_s z+r_s`，`rank(B_s)≤d_z`；源误差协方差秩 ≤ `d_z`，正交补为零；按源精确减去 `B_s z_k` 后残余为 0（线性）/`≤L_B||z_k||`（非线性）；第 2 轮最坏相关维数由盲区数降为 `d_z`。若真实物理不在 `range(B)` 内则误差仍沿 `range(B)` 传播（§8 风险）。
**引理 54（接触可辨识性与样本复杂度）** `rank(J_c)=d_c` 才可辨识；仅法向按压时 `μ/k_c` 不可分辨；`λ_min(J_c)≥λ_0` 下 `||θ̂−θ*||≤ε` 需 `n ≥ C d_c σ_max²/(ε²λ_0)`；不满足 ⇒ 只允许定性证据。
**引理 55（精确退化）** `T_C=∅`、`z_shared=0` ⇒ 8C ≡ ToolGauge 6C；定义 416–431 与引理 46–50 原样成立；TactiGauge 是保守扩展。
**引理 56（时序安全预算保持）** 接触环独立于 50Hz，CONTACTING 硬件限幅 + 看门狗 + 冲量预算 + 有界回退；50Hz 新增 <0.3ms；单盲区 `≤T_c+τ_X+τ_AP≤τ_repair`；降级按 TB-Contract ⇒ 引理 45/50 保持。

## 7. 与第 2 轮的差异与继承

- **继承**：`R/`盲区判定（定义 398/399）、风险门 `λ`（定义 400）、`M_ver`（401）、热替换定理（引理 44）、IV-Contract/TB-Contract（407/424）、`H_s` 共形假设（422）、AP-Cal/MP-Φ（420）、P-Quarantine（428）、主张绑定（423）、严格退化链。
- **修复（第 2 轮遗留缺口）**：接触模态缺失 → C-Box；反作用通道只声明 → CSE（433）；迁移无源选择/负迁移 → X-Box（437、引理 52）；相关偏差只有全局刹车 → 分解/局部化/按源隔离（436/438/443）；触觉标定过度自信 → 可辨识性（442、引理 54）；`valid` 不识别幽灵接触 → 接触回执（441）；迁移主张不可审计 → `TransferCert` + 447。
- **新增**：接触安全与真值通道（IP-321/322）、迁移审计层（IP-323/324）、按源隔离（IP-325）、8C（IP-326/327）、无量纲接触技能表示（439）。

## 8. 本轮最大风险（一句话）

**一句话**：把「接触 = 真值」与「接触技能 = 可迁移」同时当作先验——一旦共享子空间的接触物理模型设定错误（未建模的粘弹性、迟滞、摩擦各向异性、胶层蠕变），X-Box 会以「有 `TransferCert`、有触觉证据」的方式把同一系统性偏差沿 `d_z` 维子空间注入所有盲区；第 2 轮的相关性风险只是被**降维**而非消除，而且因为「触觉看起来像地面真值」而更难被察觉。

**缓解**：正交接触锚（独立于迁移模型的参考测量）、可辨识性门槛、CVC 跨模态校验、LCB 负迁移闸门、按源隔离与精确撤回、硬件力限与 `CONTACTING` 显式态；P-Quarantine 保留为最后断路器。
