# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 7 轮；本轮灵感：「实时推理」×「结构优化」）

> 第 60 轮用 SSM×CIEC×EPIR×SERC×PCE++++ 把「执行层→证据层」升级为「认知驱动的场景-执行闭环」。但它默认了三个未言明的前提，本轮要正面拆掉：
> 1. **推理只有"精度"没有"时限"**：SSM 的 Kalman 场景后验、CIEC 的意图映射、EEIS 的场景先验编译，都默认"算到收敛为止"。在 1kHz 阻抗控制、几十毫秒级力控窗口里，贝叶斯推断的 O(N) 矩阵求逆、Baum-Welch 迭代没有 WCET 上界；PCE++++ 的 B_scene 只是"够不够"的预算，而非"在 deadline 前如何把算力换成安全"的调度语义。结果是：**越准的推理越可能错过控制窗口，而错过的推理又被当成"没算"直接回退**——精度的收益在实时性面前被整体丢弃。
> 2. **管道结构固定、从未被优化**：SERC 是一条固定的线性管道（SSM→CCM→CIEC→EPIR→XMC++），端到端时延等于所有阶段之和，ROS 每一跳都叠加通信延迟。它从不问：**这条计算"结构"本身是否最优？** 哪些节点能融合以省掉 ROS 跳数、哪些结果能在新鲜度窗口内复用、哪些低临界性分支能剪掉——「结构优化」缺位。
> 3. **新鲜度不在证据里**：EPIR 保证 seq/timestamp 因果有序，但一条"因果连续"的证据可能用的是**已经过期的场景后验**去标注一次执行。因果顺序对、时间有效性错，就会把"陈旧先验下的执行"当成"新鲜认知下的执行"喂回学习，形成**反馈污染**。

## 0. 直觉与动机

**灵感 1（实时推理 → 任意时间推理 ADIN）**
直觉：推理结果不是一个点，而是一条**随计算量单调精化的序列** π^(0) ⊑ π^(1) ⊑ …。真正的实时不是"算得快"，而是"**在任何时刻被打断都能交出当前最好、且合法的答案**"。关键洞见：把场景后验、意图后验、标定后验都实现为**可中断的精化序列**，每一步都有已知代价 c^(k) 与已知误差上界 ε^(k)；调度器只需问"下一单位算力花在哪条序列上，能最大地降低安全风险"——即边际计算价值 MVC。

**灵感 2（结构优化 → 临界性感知推理图 CIG）**
直觉：拓扑优化在"应力大处留材料、应力小处去材料"，以最小重量满足强度约束。把推理/控制管道看成一张**计算结构图**：节点有耗时与"质量"，边有 ROS 延迟，节点带**安全临界性 κ**（κ=2 绝不可剪）。结构优化就是：**在临界路径满足 deadline、κ=2 全部保留的约束下，最小化总计算/通信代价**——该融合的融合、该缓存的缓存、该剪的剪。这样"快"不是靠少算，而是靠**把算力放到真正承重的地方**。注意这是力学拓扑优化的**同构**（应力↔临界性，材料↔计算/通信预算），而非机械结构刚度优化。

**灵感 3（合流 → 时间-空间协同 RTSO）**
直觉：实时推理给出"质量-时延"的可选工作点，结构优化给出"拓扑-模式"的可行域；两者相乘才是完整调度：先由 TVC 算出"还能新鲜多久"（物理给的真实 deadline），再由 CISO 选结构，最后由 TSCS 在剩余 slack 内按 MVC 分配算力。关键洞见：**deadline 不是人定的，是新鲜度物理衰减决定的**——这使实时约束第一次有了物理意义。

**灵感 4（证据 → 实时证据因果时标 RECT）**
直觉：证据要同时回答三个问题：**发生了什么（因果）、什么时候算的（版本）、用的时候还新不新（新鲜度）**。给 EV-exec 加挂 TVC，就能把"陈旧标注"隔离出学习回路，阻断反馈污染。

**灵感 5（预算 → PCE+++++ 六维）**
直觉：第 60 轮四维认知预算缺了"时限"与"结构变更"两类资源。扩为 B_cog+ = (B_scene, B_intent, B_ros, B_exec, B_rt, B_struct)：B_rt 是跨节拍累积的 deadline slack 总量；B_struct 是结构重配置次数（防拓扑抖动）。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（任意时间实时推理 ADIN）** 对查询 q 的一族精化推理 I_q = {π^(0), π^(1), …, π^(m)} 满足：
- (i) **处处合法**：∀k，π^(k) 归一化且支撑一致；
- (ii) **单调精化**：H(π^(k+1)) ≤ H(π^(k)) 且 ε^(k+1) ≤ ε^(k)；
- (iii) **代价可加**：c^(k) = Σ_{i≤k} WCET(refine_i)，且 c^(0) ≤ c^(1) ≤ …；
- (iv) **误差可证**：ε^(k) ≥ sup_{K ∈ cred_α(π^(k))} risk(K)，即对下游阻抗安全的保守超额风险上界。
- **截止算子**：`infer_before(q, T)` 返回 k* = max{k : c^(k) ≤ T}；若连 c^(0) > T 则返回通用先验 π^general 并置 degraded 位。其契约：**时延 ≤ T；返回 π^(k*) 合法；安全风险 ≤ ε^(k*)**。
- **边际计算价值**：MVC_q(c) = −∂ε/∂c；一段额外算力 Δ 的价值为 ∫ MVC dc。

**定义 162（时限有效性证书 TVC）** 推理结果 r 携带 TVC = (t_infer, τ_stale, γ0, γ_min, K_version)：
- **新鲜度衰减**：γ(t) = γ0 · exp(−(t − t_infer)/τ_stale)，其中 γ0 = 1 − ε^(k*)。
- **使用时有效**：valid_at(t_u) ⇔ γ(t_u) ≥ γ_min。
- **有效期与推理 deadline**：T_valid = τ_stale · ln(γ0/γ_min)；若必须在 t_u 使用，则 D_infer = T_valid − (t_u − t_infer)。
- **物理桥接**：设环境参数漂移率上界 ρ_env（如 ‖dK_ideal/dt‖ ≤ ρ_env），则陈旧阻抗的力误差满足 ‖F_err‖ ≤ (ρ_env · (t_u − t_infer) + ε^(k*)) · ‖x‖；给定力误差上限 ε_F 反解得允许最大陈旧时间 Δ_max。于是控制器的**硬 deadline** 为
  `T_deadline = min(T_valid, Δ_max)`。
  这把"实时约束"从工程参数升级为**由新鲜度物理与力误差上界共同导出的量**。

**定义 163（临界性感知推理图 CIG）** 结构图 G = (V, E, M, κ, ℓ)：
- 节点 v ∈ V 为推理/控制算子（场景更新、意图映射、阻抗编译、证据构造、融合……）；
- 多模式 m ∈ M_v 给出 (d_v(m), q_v(m), c_v(m))：耗时、质量、计算代价；
- 边 e=(u,v) ∈ E：ROS 跳延迟 ℓ_e ≥ 0、带宽 b_e、因果依赖；
- 临界性 κ_v ∈ {0,1,2}（0 可剪、1 可降级、2 安全关键不可剪）；
- 源 S（观测）、汇 Z（下发布/证书）；
- **路径质量取最弱环节**：q(path) = min_{v∈path} q_v；κ=2 的汇 z 需 q(path_z) ≥ θ_z 且 γ_z ≥ θ_z^t。

**定义 164（临界性感知结构优化 CISO）** 决策 σ = (mode, F, C, P)：模式赋值、融合边集、缓存节点集、剪枝节点集。求解
```
min_σ  Σ_v c_v(m_v) + λ_F|F| + λ_C|C| + λ_P Σ_{v∈P} pen_v
s.t. (1) makespan(G_σ) ≤ T_deadline − δ_margin
     (2) ∀v: κ_v=2 ⇒ v ∉ P ∧ q_v ≥ θ_v
     (3) ∀κ=2 汇 z: q(path_z) ≥ θ_z ∧ γ_z ≥ θ_z^t
     (4) F 不引入环；C 的复用满足 TVC（陈旧量在有效期内）
     (5) |mode 变更| + |F| + |P| ≤ B_struct（防拓扑抖动）
```
其中 makespan 是带模式时长与 ROS 边延迟的关键路径长度；融合把跨节点边延迟置 0；缓存把节点时长置 0 但引入陈旧 (t − t_cache)。
- **难度**：一般 CIG 上 CISO 以 MRCPSP（多模式资源约束项目调度）为特例，**NP-hard**。
- **可解子类**：若 G 为**串并联（series-parallel）**且时长可加，则对 deadline 约束用 DP 求精确最优（见 IP-164 伪代码），复杂度 O(|V|·T²·|M|)。

**定义 165（时间-空间协同调度 TSCS）** 每个控制节拍，给定剩余 slack T_rem、各推理 TVC、结构可行域 Σ(G)（由 CISO 给出），求解
```
max_{α, σ∈Σ} Σ_i VOI_i(α_i; σ)   s.t. Σ_i c_i(α_i) ≤ T_rem
VOI_i = ∫_0^{α_i} MVC_i dc − λ_stale · P(γ_i(t_use) < θ_i)
```
- **贪心性质**：若各 MVC_i 关于算力单调递减（凹），按 MVC 密度降序填满 slack 的贪心在连续可分时精确、离散时为 (1−1/e) 型近似。
- **结构-时间耦合**：σ 决定哪些 i 存在（剪枝则 VOI_i=0）、哪些复用（缓存则 MVC_i→0 但受 TVC 约束）。

**定义 166（实时证据因果时标 RECT）** EV-rt = (seq, ts_obs, ts_infer, K_version, TVC, γ_use, K_used, hash, parent_hash)。三元校验：
- **因果**：seq/ts 单调、hash 链闭合（EPIR 原职责）；
- **版本**：所用场景/阻抗版本 K_version 必须是对 ts_act 有效的版本；
- **新鲜**：γ_use ≥ θ_use。
若因果通过而新鲜失败，标记 `stale_exec`：**不进入场景/意图的学习回路**（防污染），并立即触发一次 `infer_before` 再推理；若版本错配，标记 `version_exec` 并作废该证据的合规性。

**定义 167（六维预算 PCE+++++）** B_cog+ = (B_scene, B_intent, B_ros, B_exec, B_rt, B_struct)。
- **B_rt**：跨节拍累积的 deadline slack 总量；耗尽 ⇒ 冻结精化，直接使用最近一次合法 π 或保守先验。
- **B_struct**：结构重配置预算；耗尽 ⇒ 锁定上一 σ，禁止融合/剪枝/换模式（防抖动）。
- 价值函数：`voi_rt(π) = VOI_cog(π) − λ_rt·T_rem^{-1} − λ_struct·Δσ − cost_exec`。

**定义 168（RTSO 闭环算子）**
```
① TVC-aware deadline: T_deadline = min(T_valid, Δ_max)
② ADIN: π_scene ← infer_before(scene, T_scene); π_intent ← infer_before(intent, T_intent)
③ CISO: σ ← optimize_structure(G, π.quality, T_deadline, B_struct)
④ TSCS: α ← schedule_mvc(π, T_rem, σ)
⑤ CCM/CIEC: K_safe ← compile_with_scene_prior(π_scene^(k*), σ); ERTC.lock(C_intent)
⑥ Dispatch + Execute
⑦ RECT: EV-rt ← build_and_validate(...); if stale_exec: exclude + re-infer
⑧ XMC++: M, fused, D⁺ ← xmodal_fuse_plus(..., EV-rt)
⑨ Return (π_scene^(k*), K_safe, EV-rt, σ, budgets)
```

## 2. 关键算法伪代码（摘要，完整版见产物区）

- **ADIN**：`refine()` 生成器逐步产出 (π^(k), ε^(k), cost)；`infer_before` 在 slack 内反复拉取下一精化，代价超限即停。
- **TVC**：`validity(t)` 直接算指数衰减；`deadline()` 取 min(有效期, 力误差反解)。
- **CISO**：串并联子类用 DP 表；一般图用「关键路径 + Lagrangian 松弛 + 临界性密度贪心」。
- **TSCS**：按 MVC 密度排序填满 T_rem，剪枝节点 VOI 置零。
- **RECT**：`validate(ev)` 做因果/版本/新鲜三连判，stale 则隔离。

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| ADIN | O(1)/步精化；截止由 T 截断 | O(当前粒子/迭代状态) | 任意中断点均合法，误差上界可证 |
| TVC | O(1) | O(1) | 力误差界覆盖真值（仿真 ≥99%） |
| CIG/CISO | 串并联 O(\|V\|·T²·\|M\|)；一般图为启发式 | O(\|V\|·T) | κ=2 必保留；可行解或安全默认 σ0 |
| TSCS | O(n log n)/节拍 | O(n) | 凹 MVC 下贪心精确/近似 |
| RECT | O(1)/条 | O(window) | 三性校验，反馈污染率 ≤ δ_rect |

**正确性定理（RTSO）**：假设 A66–A70 成立——(A66) ADIN 精化合法且误差上界可证；(A67) 新鲜度衰减模型与 ρ_env 上界成立；(A68) 临界性标注正确且 κ=2 真为安全关键；(A69) CISO 返回可行 σ 或安全默认 σ0 满足 makespan ≤ T；(A70) 六预算单调消耗、耗尽即触发安全回退。则：
1. **时序安全**：T_deadline 由定义 162 导出 ⇒ 每次执行满足 ‖F_err‖ ≤ ε_F 且 γ_use ≥ γ_min。
2. **结构安全**：CISO 约束 (2)(3) 保证所有 κ=2 节点与路径质量/新鲜度不降；剪枝仅作用于 κ≤1 且被默认值替换 ⇒ 结构优化不会降低安全证明的可满足性。
3. **调度最优性（子类）**：串并联 CIG 上 DP 取得精确最优；一般图贪心满足约束并可由 Lagrangian 下界证书 gap。
4. **证据有效**：RECT 三性校验 ⇒ 进入学习回路的 EV-rt 均满足因果、版本、新鲜，反馈污染概率 ≤ δ_rect。
5. **预算安全**：任一 B_cog+ 维度耗尽即冻结/保守/本地闭环，不产生"越优化越不安全"。

## 5. 本轮最大风险

**一句话**：结构优化可能把"关键路径"优化成"看似快、语义上更脆"的图——一旦 κ 标注错误（把安全关键节点误标为可选而剪掉或融合），实时性会以"满足 deadline"的形式**系统性地删掉安全护栏**，造成"延迟达标、语义崩塌"；必须以「κ=2 不可剪 + TVC 新鲜度硬约束 + 剪枝后 SICC 复验 + B_struct 变更上限」四重护栏兜底，并把结构变更本身纳入证据链。

### IP-161 ADIN（任意时间推理）

```python
class AnytimeInference:
    """Any time-valid refinement sequence. refine() yields (posterior, eps, cost)."""
    def __init__(self, query, refiner, eps0=0.5, max_steps=64):
        self.query = query
        self.refiner = refiner            # refiner(k, state) -> (posterior, eps, step_cost, state)
        self.eps0 = eps0
        self.max_steps = max_steps

    def refinements(self):
        state, posterior, eps, cost = None, self._prior(), self.eps0, 0.0
        yield posterior, eps, cost
        for k in range(1, self.max_steps + 1):
            posterior, eps_new, step_cost, state = self.refiner(k, state)
            assert eps_new <= eps + 1e-12          # monotone error bound (A66)
            cost += step_cost
            eps = eps_new
            yield posterior, eps, cost

    def infer_before(self, T):
        best = None
        for posterior, eps, cost in self.refinements():
            if cost > T:
                break
            best = (posterior, eps, cost)
        if best is None:
            return self._general_prior(), 1.0, 0.0, "degraded"
        return (*best, "ok")
```

### IP-162 TVC（时限有效性证书）

```python
import math

class TimeValidityCertificate:
    def __init__(self, t_infer, tau_stale, eps, gamma_min):
        self.t_infer = t_infer
        self.tau = tau_stale
        self.gamma0 = max(0.0, 1.0 - eps)
        self.gamma_min = gamma_min

    def gamma(self, t):
        return self.gamma0 * math.exp(-(t - self.t_infer) / self.tau)

    def valid_at(self, t):
        return self.gamma(t) >= self.gamma_min

    def t_valid(self):
        if self.gamma0 <= self.gamma_min:
            return 0.0
        return self.tau * math.log(self.gamma0 / self.gamma_min)

    def deadline(self, t_use, rho_env, eps_F, x_norm=1.0):
        # physical bound: ||F_err|| <= (rho_env*(t_use-t_infer)+eps)*||x|| <= eps_F
        delta_max = max(0.0, (eps_F / max(x_norm, 1e-9) - self.gamma0 * 0.0) / rho_env
                        - (t_use - self.t_infer))
        return min(self.t_valid(), delta_max)
```

### IP-163/164 CIG + CISO（结构优化）

```python
def makespan(G, sigma):
    # critical path with mode durations and ROS edge latencies (cached edges -> 0)
    return _longest_path(G, durations={v: G.mode_dur(v, sigma.mode[v]) for v in G.V},
                         latencies={e: 0.0 if e in sigma.F else G.lat[e] for e in G.E})

def ciso_series_parallel(G, T_deadline, B_struct, lam):
    """Exact DP on series-parallel CIG. cost_X[t] = min compute to finish X within t."""
    INF = float("inf")

    def leaf(v):
        tab = [INF] * (T_deadline + 1)
        for m in G.modes[v]:
            d, q, c = G.dur(v, m), G.quality(v, m), G.cost(v, m)
            if G.kappa[v] == 2 and q < G.theta[v]:
                continue                       # constraint (2)
            for t in range(d, T_deadline + 1):
                tab[t] = min(tab[t], c)
        return tab

    def series(A, B, ell):
        tab = [INF] * (T_deadline + 1)
        for t in range(T_deadline + 1):
            best = INF
            for s in range(t + 1):
                if s - ell >= 0:
                    best = min(best, A[s - ell] + B[t - s])
            tab[t] = best
        return tab

    def parallel(A, B):
        return [A[t] + B[t] for t in range(T_deadline + 1)]

    tab = _fold_sp_tree(G, leaf, series, parallel)      # O(|V|·T²·|M|)
    if tab[T_deadline] is INF:
        return G.safe_default_sigma()                   # A69
    return _recover_sigma(G, tab, T_deadline, B_struct)
```

```python
def ciso_general_greedy(G, T_deadline, B_struct):
    """General DAG: (1) Lagrangian relax deadline -> price per node; (2) prune by
    criticality-density subject to kappa=2 preservation; (3) certify gap via dual."""
    sigma = G.initial_sigma()
    lambda_ = 1e-3
    for _ in range(32):                                  # dual ascent on makespan
        price = {v: lambda_ * max(0.0, d - T_deadline / len(G.V))
                 for v, d in G.durations(sigma).items()}
        sigma = _mode_select(G, price, sigma)
        gap = makespan(G, sigma) - (T_deadline - G.margin)
        lambda_ = min(1e6, lambda_ * 1.5) if gap > 0 else lambda_ * 0.7
    sigma = _criticality_density_prune(G, sigma, T_deadline)   # never prune kappa=2
    return sigma if makespan(G, sigma) <= T_deadline else G.safe_default_sigma()
```

### IP-165 TSCS（时间-结构协同调度）

```python
def schedule_mvc(infs, T_rem, sigma):
    """infs: list of (name, AnytimeInference, tvc, theta_i)."""
    active = [i for i in infs if not sigma.pruned(i.name)]
    dens = []
    for name, inf, tvc, theta in active:
        mvc = marginal_value(inf)                       # -d eps / d cost at current k
        stale_pen = 0.0 if tvc.valid_at(now() + T_rem) else 1.0
        dens.append((mvc - stale_pen, name, inf, tvc, theta))
    dens.sort(reverse=True)
    budget, alloc = T_rem, {}
    for _, name, inf, tvc, theta in dens:
        next_cost = inf.next_step_cost()
        if next_cost <= budget and mvc_density_positive(inf, tvc):
            alloc[name] = (inf.infer_before(budget), inf.eps, tvc)
            budget -= next_cost
        else:
            alloc[name] = (inf.current_posterior(), inf.eps, tvc)
    return alloc
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| ADIN | O(1)/精化步；截止由 T 截断 | O(状态) | 任意中断点合法；ε^(k) 可证 |
| TVC | O(1) | O(1) | 力误差界覆盖真值（≥99%） |
| CISO 串并联 | O(\|V\|·T²·\|M\|) | O(\|V\|·T) | 精确最优 |
| CISO 一般图 | 启发式（~32 轮对偶 + 剪枝） | O(\|V\|+\|E\|) | κ=2 必保留；可行或 σ0；对偶下界证书 gap |
| TSCS | O(n log n)/节拍 | O(n) | 凹 MVC 下贪心精确/近似 |
| RECT | O(1)/条 | O(window) | 因果/版本/新鲜三性；污染率 ≤ δ_rect |

**正确性定理（RTSO）**：若 A66–A70 成立，则：
1. **时序安全**：T_deadline = min(T_valid, Δ_max) 由物理/新鲜度导出，故每次执行满足 ‖F_err‖ ≤ ε_F 且 γ_use ≥ γ_min。
2. **结构安全**：CISO 的 (2)(3) 约束保证 κ=2 节点不被剪、κ=2 路径质量与新鲜度不降；剪枝仅作用于 κ≤1 且以默认值替换 ⇒ 结构优化不降低安全证明可满足性。
3. **调度最优性**：串并联 CIG 的 DP 精确最优；一般图贪心满足约束，其代价 ≥ Lagrangian 对偶下界，故 gap 可计算、可验收（E194 要求 ≤10%）。
4. **证据有效**：RECT 三性校验 ⇒ 进入学习回路的 EV-rt 同时满足因果、版本、新鲜，反馈污染概率 ≤ δ_rect。
5. **预算安全**：B_cog+ 任一维耗尽即冻结精化 / 锁定结构 / 保守先验 / 本地闭环，不产生"越优化越不安全"。

**证明要点**：(1) 直接由定义 162 的力误差上界与环境漂移界得到；(2) 由最弱环节质量 q(path)=min q_v 与 κ=2 不可剪的单调性得到（剪枝只在 κ≤1，替换默认值 q_default ≥ θ_v 时保持约束）；(3) 串并联 DP 的 Bellman 最优性 + MRCPSP 归约证明一般图 NP-hard；(4) 三性为合取，任一失败即隔离；(5) 预算单调性与安全回退映射为全函数。

## 5. 本轮最大风险

**一句话**：结构优化可能把"关键路径"优化成"看似快、语义上更脆"的图——一旦 κ 标注错误（把安全关键节点误标为可选而剪掉或融合），实时性会以"满足 deadline"的形式**系统性地删掉安全护栏**，造成"延迟达标、语义崩塌"；必须以「κ=2 不可剪 + TVC 新鲜度硬约束 + 剪枝后 SICC 复验 + B_struct 变更上限」四重护栏兜底，并把结构变更本身纳入证据链。
