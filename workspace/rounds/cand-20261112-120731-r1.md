# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；新一轮灵感循环第 1 轮；本轮灵感：「评测基准」×「社会影响」）

> 第 57 轮给出了此前最完整的安全叙事：q_φ 把先验从区域史摊销、证据按模态分账对账、操作者变成单向有界的信任状态机，并用 P_safe ≥ 1−Σ_cp(δ_f+ε_meta+…) 把"证据承诺"折算成一个可写、可审计的部署界。但这个界有两个从未被形式化的**外部前提**。**(a) 那些 δ 是在基准 B 上估出来的，而部署分布 D 不一定等于 B**——基准没覆盖的材质/季节/操作者/受影响人群，不会被 Σ_cp 里的任何一项计数；更糟的是，机制本身是在 B 上调出来的，再在 B 上报数，证书带着选择偏差与污染。**(b) P_safe 是一个把所有人平均掉的标量**——同样的 0.99，可能是"所有人都 1%"，也可能是"99% 的人 0%、1% 的人 100%"。而且第 57 轮的"同意"只覆盖操作者；被机器人经过的旁观者、共享空间的使用者、被搬动物体的所有者，从未出现在授权账本上。本轮两个灵感各补一层：**评测基准**把"分数"升级为"测量仪器的效度"——覆盖、构念、污染、外推、时效；**社会影响**把"平均安全"升级为"分配安全 + 外部性 + 可申诉"——风险按人群分层、非同意者受硬保护、受影响者可提交反证并触发保守回退。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"基准可外推、风险可分配、影响可申诉的证据说可信"**。

核心矛盾：
- **H29（基准效度 vs 证书效度）**：δ 是从有限基准样本估出的；基准的覆盖空洞、构念错位、机制选择偏差与污染，都不在 δ 的置信区间里。证书在 B 上越紧，越可能只是把 B 的盲区写得更自信。
- **H30（平均安全 vs 分配安全）**：标量 P_safe 对风险集中不敏感；基准的分层权重 π_s^B 与部署权重 π_s^D 不同，且"谁会来"在认证时未知。没有最坏分层约束，平均安全可以成为风险转移的许可证。
- **H31（认证 vs 可申诉）**：认证是单向的（系统向人证明），申诉是反向的（受影响者向系统举证）。若反证不能改变证书与行为，评测就退化为合法性剧场；若反证可任意改变证书，又会被投毒与博弈。

## 0. 直觉与动机

**灵感 1（评测基准 → 先问"这把尺子量的是什么"，再问"量得准不准"）**
直觉：基准不是中立的排行榜，而是一台测量仪器。它至少有三层效度：**构念效度**（成功率高是否等于安全？任务是否代表部署中的失败模式）、**覆盖效度**（分层空间里哪些格子根本没有样本）、**外推效度**（在 B 上测得的失败率，离开 B 后还能信多少）。第 57 轮的 δ 只回答了"在 B 上的统计置信"，没回答这三问。于是给每个 δ 配一张**元证书** V(δ)：记录分层样本量、单侧置信上界、构念声明、污染检验、基准年龄、可认证域 dom 与外推半径 τ。**没有元证书的 δ 不许进入部署界；dom 之外的区域，δ 直接取 1（不可认证），而不是取一个好看的数。**"宁可说不知道，也不说一个会被平均掉的安全。"

**灵感 2（外推 → 覆盖空洞是加性的，不是可平均的）**
直觉：部署风险不是"B 覆盖到的区域"的平均，而是"覆盖到的部分 + 没覆盖的部分"。后者的风险上界只能取 1，除非系统在现场补探针。因此证书里必须显式出现**覆盖空洞质量 π_out**：π_out 一大，整张证书作废（不是打折）。这也解释了为什么"再多样本"救不了盲区——样本只在已覆盖的格子里增加精度，不会自动长出没被定义的格子。外推半径 τ_s 也不能手设：它要由独立的配对审计样本估计；没有配对样本时 τ_s=1，等于承认"这条外推没有证据"。

**灵感 3（社会影响 → 安全是一张风险剖面，不是一个数）**
直觉：同一个平均失效率下，风险可以均匀，也可以集中在最没有议价能力的人身上。安全的正确对象是**风险剖面** R(s) 而不是标量：每个分层一个上界，外加两个硬约束——**最坏分层上限** δ_max（不许任何一群人承担超过绝对线的风险）与**分配公平约束**（跨层差异有界，或用 leximin 排序）。更严格地，认证时不知道部署时谁会来，所以要在**部署构成的模糊集**上取最坏：sup_{D'∈𝒫_ε} Σ_s π_s^{D'} R(s) ≤ δ_avg。只在一种人群上测出来的"平均安全"，在模糊集上会立刻破功。

**灵感 4（社会影响 → 同意不完备：操作者不能替非同意者签字）**
直觉：第 57 轮的 auth 是操作者的授权，但操作者只能为自己的暴露签字。机器人经过的旁观者、共享空间的使用者、被搬运物的所有者，是**非同意受影响者**。于是加一条**无风险转移规则**：提高操作者授权（A2）只能加速"操作者自己承担的那部分风险"，绝不能抬高非同意者的风险；对非同意者的外部性有独立预算 δ_ext，且其风险必须低于社会许可阈值 δ_soc，不能由操作者授权"购买"。这把"个性化"从"让人更快相信自己"进一步约束为"让人更快承担**自己的**风险，而不是别人的"。

**灵感 5（合流 → 证书的证书、探针的社会价值、评测的治理）**
直觉：第 57 轮的探针 VOI 只问"这次探针能否降低 P_fail"；本轮要问"它能否降低**证书本身的不可信**"——去覆盖空洞、去估 τ_s、去补最坏分层，其社会价值可能更高。于是探针变成**审计样本**：它既改信念，也改基准（带 provenance，只允许保守方向）。同时，评测基准一旦成为优化目标就会被 Goodhart 化，必须**预注册、留隐藏 holdout、按审计抽签复核、给证书设过期时间**；基准的版本与 hash 进入证书，过期或污染超阈值的基准不能再支撑承诺。第 57 轮"一切判定器走隔离"在本轮推广为"**一切评测（含基准更新）走隔离**"。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（基准效度元证书 BVM）** 对证书中每个参数 δ（δ_f、ε_meta、δ_ood、δ_xm、ε_h 等），元证书
V(δ)=(B,𝒮,{n_s,δ̂_s,U_s}_{s∈𝒮},Con,Leak,age,dom,τ)，
其中 B 为基准版本+hash，𝒮 为分层（材质×季节×坡度×操作者群体×受影响人群），n_s 为分层样本量，U_s 为单侧置信上界（如 Clopper–Pearson，置信 1−α_cert），Con 为构念效度声明（δ 度量的失败模式是否覆盖部署中的失败模式），Leak 为污染/泄漏检验统计量，age 为距上次独立复核的时间，dom={s:n_s≥n_min ∧ 配对审计覆盖} 为可认证域，τ={τ_s} 为外推半径。**有效谓词**
VALID(δ;s) ⇔ s∈dom ∧ Con=1 ∧ Leak≤ε_leak ∧ age≤T_exp ∧ U_s≤δ；
部署可用上界 \bar δ_s=U_s+τ_s（s∈dom），否则 \bar δ_s=1。元证书本身必须可审计：τ_s、Leak 的估计必须使用**独立复核集**，不能与 δ 的调参集重合，否则"证书的证书"可以无限后移；本定义要求回归只允许上升一层，且审计数据由独立进程或随机抽签产生。

**定义 140（分层外推界 STB）** 部署构成权重 π^D，覆盖空洞质量 π_out=Σ_{s∉dom} π_s^D。对 s∈dom，声明并审计外推半径 τ_s 使 |P_D(fail|s)−P_B(fail|s)|≤τ_s；则
\bar R_D = Σ_{s∈dom} π_s^D (U_s+τ_s) + π_out·1。
证书仅在 π_out≤ε_cov ∧ \bar R_D≤δ_avg 时成立；否则输出"**不可认证**"（不是输出一个更大的数）。若 D≪B，可用密度比加权替代：P_D(fail)=E_B[w(z)1_fail]，w=dD/dB 截断于 w_max，偏差 ≤∫(w−w_max)_+dD，并须报告有效样本量 ESS=(Σw)²/Σw²≥n_min；否则退回分层界。**关键**：π^D 本身是认证时的估计，必须放进模糊集 𝒫_ε={D':TV(D',D̂)≤ε_pi} 取最坏，不能把"谁会来"当作已知常数。

**定义 141（分配安全证书 DSC）** 风险剖面 \bar R:𝒮→[0,1]。证书同时要求：
(C1 最坏分层硬帽) ∀s∈dom, \bar R(s)≤δ_max；
(C2 平均预算) sup_{D'∈𝒫_ε} Σ_s π_s^{D'} \bar R(s)≤δ_avg；
(C3 分配约束) max_{s∈dom}\bar R(s)−min_{s∈dom}\bar R(s)≤Δ_eq（或 leximin：任何降低最差层的改动优先）；
(C4 非同意者外部性预算) Σ_{a∈𝒜\𝒞} e_a R_a≤δ_ext。
DSC 是向量证书；**标量 P_safe 只作为 C2 的一个投影，永远不能单独签发**。若某层样本不足，该层 \bar R=1 直接触发 C1 失败——这比"样本少就忽略"更保守，也是本轮想要的行为。

**定义 142（外部性与同意完备性 ECC）** 受影响集 𝒜(x)（操作者、旁观者、共享空间未来使用者、被操作物所有者），暴露 e_a∈[0,1]，同意状态 c_a∈{direct,delegated,none}。授权账本 Auth 只覆盖 direct 集合 𝒞_direct。**无风险转移规则**：∀a∈𝒜\𝒞_direct，∂R_a/∂auth_op=0（操作者升级不改变非同意者风险），且 τ_int 与速度的放宽只能用操作者自身暴露预算兑换。同意完备度 CC=Σ_a e_a 1[c_a≠none]/Σ_a e_a；当 CC<CC_min 时启用更严阈 δ_soc<δ_max，并要求更小的外部性预算 δ_ext。若 ECC 不满足，系统只能降速/降力/缩范围/拒绝，不能以"操作者已授权"为由继续。

**定义 143（可申诉证据通道 CTB）** 申诉 ζ=(claim,trace,provenance,s,t_r)，trace 必须包含基准构念未覆盖的结果（构造缺口），provenance 可验证，禁止无来源断言。受理规则：
(A1) 立即**保守影子**：相关分层 s 的证书临时替换为加宽上界 \bar R^+(s)=min(1,\bar R(s)+Δ_chal)，裁决前生效——"先保守、后裁决"；
(A2) 若 trace 通过构念缺口检验，则**扩充基准**（新增分层/边界案例）并触发再认证，基准更新走第 57 轮隔离区（影子模式，回归不劣化才接管）；
(A3) **单调性**：申诉只能加宽证书或增加分层/样本；收紧证书必须由独立审计者裁决且有界速率，防止投毒与"申诉洗白"；
(A4) 反投毒：单来源影响力有界、k-of-n 独立来源互证、上报者信誉单向（与 PTM 同构）；重复/协同伪造计入审计。可诉性指标：受理时延、保守回退覆盖率、误回退率、投毒影响上界。

**定义 144（基准治理与轮换 BGR）** 基准 B_t=(协议 PR,公开集 B_pub,隐藏 holdout H,轮换周期 T_rot,过期 T_exp,分层纳入理由 IR)。**Goodhart 间隙** G(t)=Perf_{B_pub}(t)−Perf_H(t)；当 G(t)>θ_goodhart 时证书降级（视为部分污染）。**审计抽签**：以概率 q 把部署片段送入隐藏 holdout/人工复核，抽签独立于被评测者。**分层纳入理由 IR** 必须写出"受影响人群→分层"的映射；无代表的群体标记为 under-covered，进入 π_out 或触发补采。证书携带 B_t 的版本与 hash；过期/污染/协议变更后未复核的基准不能支撑承诺。**基准更新走隔离**：新基准先在影子模式跑历史证书，误承诺率不升、覆盖不降才可接管。

## 2. 关键算法伪代码（完整版见产物区）

```python
def certify(delta, s, V):                     # IP-139/140: 先验效度，再谈数值
    if not V.valid(delta, s):                 # dom/构念/污染/时效任一失败
        return None                           # 不可认证，绝不回退到"相信"
    return min(1.0, V.U[delta][s] + V.tau[s])

def deployment_bound(D_hat, certs, eps_pi, eps_cov):   # IP-140/141
    Dset = tv_ball(D_hat, eps_pi)
    pi_out = max(sum(p[s] for s not in certs.dom) for p in Dset)
    if pi_out > eps_cov:
        return 'UNCERTIFIED', pi_out           # 覆盖空洞过大：整张证书作废
    worst = max(sum(p[s] * certs.R(s) for s in certs.dom) for p in Dset)
    if worst > certs.delta_avg or any(certs.R(s) > certs.delta_max for s in certs.dom):
        return 'UNCERTIFIED', worst
    return 'CERTIFIED', worst

def externality_check(auth_op, A, e, R, cons, delta_ext):   # IP-142
    for a in A:
        if a not in cons.direct and auth_op != auth_op0:
            assert R[a] <= R_baseline[a]      # 无风险转移：升权不得抬高非同意者风险
    if sum(e[a] * R[a] for a in A if a not in cons.direct) > delta_ext:
        return 'reduce_speed_force_scope_or_refuse'
    return 'ok'

def challenge_update(zeta, cert, bench, audit):    # IP-143: 先保守，后裁决
    if not admissible(zeta): return cert
    cert = widen(cert, zeta.s, delta_chal)         # A1 立即影子回退
    if construct_gap(zeta.trace):
        bench = bench.augment(zeta.s, zeta.trace)  # A2 扩充分层/边界案例
        cert = recertify_shadow(cert, bench)       # 走隔离区，回归通过才接管
    audit.log(zeta); return cert                   # A3/A4 单调 + 反投毒
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| BVM | O(\|𝒮\|·N_audit) 离线 | O(\|𝒮\|) 元数据 | 独立复核集、τ/Leak 与 δ 的估计分离 |
| STB | O(\|𝒮\|·\|𝒫_ε\|) | O(\|𝒮\|) | π_out 显式、τ_s 无证据取 1 |
| DSC | O(\|𝒮\|·\|𝒫_ε\|) | O(\|𝒮\|+\|𝒜\|) | 向量签发、最坏层硬帽 |
| ECC | O(\|𝒜\|) | O(\|𝒜\|) | 无风险转移、外部性预算 |
| CTB | O(1)+O(H_chal) | O(\|challenges\|) | 先保守后裁决、单调、反投毒 |
| BGR | O(1)+O(T_rot 离线) | O(\|B_t\|) | 隐藏 holdout、过期与 hash 绑定 |

**正确性定理（Distributional Transport & Contestable Soundness, DTCS 概要）**：在 A33–A40 之上加
(A41) 基准效度与外推诚实：dom、U_s、τ_s、Leak、age 可审计，τ_s 来自独立配对审计，π_out 与 𝒫_ε 的计算保守；
(A42) 分配约束 (C1)–(C3) 在部署权重模糊集上成立；
(A43) 同意完备性与无风险转移（C4/ECC）；
(A44) 可申诉单调且反投毒有界，基准更新走隔离。
则：
(i) **条件性部署界**：若 π_out≤ε_cov 且证书签发，则
P_D(fail) ≤ sup_{D'∈𝒫_ε} Σ_{s∈dom} π_s^{D'}(U_s+τ_s) + π_out + δ_ext；
当 π_out>ε_cov 时系统不签发承诺——**dom 之外没有任何安全声称**，这是定义而非近似。
(ii) **分配单调性**：新增探针/证据只能通过"降低某层 U_s 或 τ_s、降低 π_out、或收紧 δ_max"改善 DSC；在 π_out 过大时不能被平均值抵消。申诉只允许加宽或加层，故不会产生"越申诉越松"的升险路径。
(iii) **证书诚实性**：BVM 无效时 δ 不进入部署界，系统落到保守默认，因此不会产生"看似安全的未认证承诺"。
(iv) **终止与时效**：每次申诉吞吐有界，基准更新在隔离区通过回归后生效；证书带过期，过期基准无法支撑承诺。

## 6. 本轮最大风险

**一句话**：本轮把安全的判据从"证据是否可信"推进到"承载证据的评测是否可信"，风险也从"坏先验普遍"变成"**合法性剧场**"——若基准的分层覆盖、构念与外推半径本身无人审计，越漂亮、越精确的 P_safe 越会成为风险转移的许可证，让最没有话语权的受影响者承担被平均值掩盖的尾部风险；必须以覆盖空洞显式化、最坏分层硬帽、非同意者外部性预算、申诉强制保守回退四道闸门，宁可签发"不可认证"，也不签发一张只对测过的世界成立的证书。

```python
def build_validity_meta(bench, deltas, audit_set, alpha_cert):
    S = strata(bench)                          # 材质×季节×坡度×操作者群体×受影响人群
    V = {s: {} for s in S}
    for s in S:
        n_s = len(bench.samples[s])
        for d in deltas:                       # δ_f, ε_meta, δ_ood, δ_xm, ε_h, ...
            d_hat = estimate(d, bench.samples[s])
            U_s = clopper_pearson_upper(d_hat, n_s, alpha_cert)   # 单侧上界
            tau_s = paired_audit_radius(d, bench, audit_set, s)   # 独立配对审计
            if tau_s is None: tau_s = 1.0      # 无配对证据：承认外推不可信
            V[s][d] = MetaCert(n=n_s, d_hat=d_hat, U=U_s, tau=tau_s)
    dom = {s for s in S if min(V[s][d].n for d in deltas) >= N_MIN
           and paired_audit_covered(audit_set, s)}
    return ValidityMeta(B=bench.version_hash, S=S, table=V, dom=dom,
                        Con=construct_validity_decl(bench),
                        Leak=contamination_test(bench.pub, bench.hidden),
                        age=bench.age, tau={s: max(V[s][d].tau for d in deltas)
                                            for s in S})

def meta_valid(V, d, s):                       # 定义 139 的有效谓词
    if s not in V.dom: return False
    if not V.Con.ok or V.Leak > EPS_LEAK or V.age > T_EXP: return False
    return V.table[s][d].U <= declared(d)
```

**要点**：`U_s`、`tau_s`、`Leak` 必须来自与调参集不重合的独立复核集；否则元证书的元证书可以无限后退。工程上以"审计数据只进不出"（只用于估效度，不回流调参）终止递归。

### IP-140 STB（分层外推界）

```python
def stratified_transport_bound(D_hat, V, deltas, eps_pi, eps_cov, delta_avg):
    Dset = tv_ball(D_hat, eps_pi)
    pi_out = max(sum(p[s] for s in V.S if s not in V.dom) for p in Dset)
    if pi_out > eps_cov:
        return Cert(status='UNCERTIFIED', reason='coverage_hole', pi_out=pi_out)
    R = {}
    for s in V.dom:
        # 该层所有进入部署界的参数都取"上界 + 外推半径"
        R[s] = min(1.0, sum(V.table[s][d].U + V.table[s][d].tau for d in deltas))
    worst = max(sum(p[s] * R[s] for s in V.dom) for p in Dset)
    if worst > delta_avg:
        return Cert(status='UNCERTIFIED', reason='avg_budget', worst=worst)
    return Cert(status='CERTIFIED', R=R, pi_out=pi_out, worst=worst,
                dom=V.dom, benchmark=V.B)

def density_ratio_bound(D_hat, bench, eps_pi):
    w = clip(density_ratio(D_hat, bench), 0, W_MAX)       # 截断偏差可界
    ess = (w.sum() ** 2) / (w ** 2).sum()
    if ess < N_MIN:
        return 'fallback_to_stratified'                    # 权重退化：退回分层界
    bias = tail_mass(D_hat, bench, W_MAX)                  # ∫(w-W_MAX)_+ dD
    return weighted_bound(w, bias), ess
```

**要点**：`π_out` 是加性项且取模糊集最坏；`Cert` 只有 `CERTIFIED / UNCERTIFIED` 两态，**没有"差不多安全"这一态**。这直接决定下游 FSE+ 的硬门。

### IP-141 DSC（分配安全证书）

```python
def distributional_certificate(R, D_hat, V, eps_pi,
                               delta_max, delta_avg, delta_eq, delta_ext,
                               A, e, R_a, cons):
    Dset = tv_ball(D_hat, eps_pi)
    # C1 最坏分层硬帽（未认证层 R=1 直接失败）
    if any(R.get(s, 1.0) > delta_max for s in V.S):
        return ('fail', 'C1_worst_stratum')
    # C2 平均预算：部署构成模糊集上取最坏
    if max(sum(p[s] * R.get(s, 1.0) for s in V.S) for p in Dset) > delta_avg:
        return ('fail', 'C2_avg_budget')
    # C3 分配差异
    vals = [R.get(s, 1.0) for s in V.dom]
    if max(vals) - min(vals) > delta_eq:
        return ('fail', 'C3_inequity')
    # C4 非同意者外部性
    if sum(e[a] * R_a[a] for a in A if a not in cons.direct) > delta_ext:
        return ('fail', 'C4_externality')
    return ('pass', RiskProfile(R=R, worst=max(vals),
                                avg=max(sum(p[s]*R.get(s,1.0) for s in V.S)
                                        for p in Dset)))

def sign(cert_p, cert_d, cert_e):
    # 标量 P_safe 只能是 C2 的投影，单独出现时拒绝签发
    if not (cert_p.status == 'CERTIFIED' and cert_d[0] == 'pass'
            and cert_e == 'ok'):
        return 'WITHHOLD'
    return 'SIGN'
```

**要点**：DSC 是向量；当某层样本不足时 `R.get(s,1.0)=1` 直接触发 C1。这条"缺证据即失败"的规则故意比平均更保守，专门对抗"只在好测的人群上测"的激励。

### IP-142 ECC（外部性与同意完备性）

```python
def consent_completeness(A, e, cons):
    tot = sum(e[a] for a in A)
    covered = sum(e[a] for a in A if cons.status[a] != 'none')
    return covered / tot if tot > 0 else 1.0

def externality_gate(auth_op, A, e, R_a, cons, delta_ext, delta_soc,
                     CC_min, delta_max):
    CC = consent_completeness(A, e, cons)
    # 无风险转移：授权升级只能兑换操作者自身暴露，不得抬高非同意者风险
    for a in A:
        if a not in cons.direct and auth_op > auth_op0:
            if R_a[a] > baseline_risk[a] + 1e-12:
                return ('fail', 'risk_transfer_to_nonconsenter', a)
    ext = sum(e[a] * R_a[a] for a in A if a not in cons.direct)
    if ext > delta_ext:
        return ('fail', 'externality_budget', ext)
    if CC < CC_min and max(R_a.values()) > delta_soc:
        return ('fail', 'social_license', CC)
    return ('ok', (CC, ext))

def apply_operator_speedup(auth_op, speed_gain, own_budget):
    # 提速只能花操作者自己的暴露预算
    return min(speed_gain, own_budget.remaining(auth_op))
```

**要点**：`∂R_a/∂auth_op=0`（a 为非同意者）做成运行时断言，而不是文档承诺。这使第 57 轮"授权只参数化佐证数与时延"进一步收紧为"授权也只能参数化**你自己**的风险"。

```python
def challenge_update(zeta, cert, bench, audit):
    if not verifiable_provenance(zeta.provenance):
        return cert, 'reject_provenance'
    if duplicate_or_collusive(zeta, audit):
        return cert, 'reject_collusion'
    # A1：受理即保守影子，裁决前先加宽
    cert = widen(cert, zeta.s, delta_chal)
    # A2：构念缺口 → 扩充基准（走隔离）
    if construct_gap(zeta.trace, bench.construct[zeta.s]):

        if shadow_regression_ok(cert, bench_new):     # 误承诺率不升、覆盖不降

            cert = recertify(cert, bench)
    # A3：单调。收紧只能由独立审计者发起且速率有界
    if zeta.requests_loosening():
        if not independent_auditor(zeta) or not rate_ok(audit, 'loosen'):
            cert = cert  # 不受理收紧
    audit.log(zeta, cert)
    return cert, 'accepted'
```

**要点**：申诉方向与第 57 轮 PTM 同构——**加宽/加层即时，收紧有界**。不同之处在于：这里被保护的是"被评测影响的人"，且其输入可以改写基准本身。

### IP-138+ PCE++（探针的"社会价值"：外推 VOI + 审计样本）

```python
def voi_social(p, M, V, D_hat, dsc):
    # 传统 VOI：降低 P_fail
    voi_p = voi_meta_pessimistic(p, M, inf) - cost(p)
    # 社会 VOI：降低证书不可信（覆盖空洞 / 外推半径 / 最坏层）
    s = p.stratum
    d_cov = 0.0
    if s not in V.dom:
        d_cov = pi_hat(s) * (1.0 - dsc.R.get(s, 1.0))   # 补上层 = 去掉加性 1
    d_tau = V.table[s][p.param].tau - expected_tau_after(p)  # 审计样本缩小 τ
    d_cap = max(0.0, dsc.R.get(s, 0.0) - delta_max)          # 缓解最坏层
    return voi_p + LAMBDA_COV * d_cov + LAMBDA_TAU * d_tau + LAMBDA_CAP * d_cap

def probe_commit_evolve_plus_plus(x0, M, task, budget, consent, personas,
                                  V, bench):
```

| BGR | O(1)+O(T_rot 离线) | O(\|B_t\|) | 隐藏 holdout、版本 + 过期（A44） |
| FSE+ | O(\|σ\|·\|deltas\|) | O(\|σ\|) | 无有效评测即拒、dom 外拒收 |
| PCE++ | O(\|CP\|·(k_p+k_c)·(C_VOI+d_φ)+\|CP\|·A\*) | O(\|V\|+\|σ\|) | 社会 VOI 单调、k_p+k_c 终止 |

**正确性定理（Distributional Transport & Contestable Soundness, DTCS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 基准效度与外推诚实：`dom`、`U_s`、`τ_s`、`Leak`、`age` 可审计，`τ_s` 来自独立配对审计，`π_out` 与 `𝒫_ε` 保守；**(A42)** 分配约束 (C1)–(C3) 在部署权重模糊集上成立；**(A43)** 同意完备性与无风险转移（C4/ECC）在运行时被断言；**(A44)** 可申诉单调且反投毒有界，基准更新走隔离。则：

1. **条件性部署界**：若 `π_out≤ε_cov` 且 `J_p^+` 签发，则
   `P_D(fail) ≤ sup_{D'∈𝒫_ε} Σ_{s∈dom} π_s^{D'}(U_s+τ_s) + π_out + δ_ext`。
   当 `π_out>ε_cov` 时系统 `WITHHOLD`，**dom 之外不存在任何安全声称**——这不是近似，而是签发规则。
2. **分配健全性**：若 DSC 通过，则 `∀s∈dom: \bar R(s)≤δ_max`，且 `sup_{D'∈𝒫_ε} Σ π_s^{D'} \bar R(s)≤δ_avg`；平均安全不再能掩盖最坏层，因为 C1 是独立硬门。
3. **无风险转移**：对非同意者 `a∈𝒜\𝒞_direct`，`∂R_a/∂auth_op=0`；操作者授权升级只能兑换自身暴露预算。因此第 57 轮 PTM 的"单向有界"扩展为"**单向有界且不越界到他人**"。
4. **可诉单调性**：申诉只能加宽证书或增加分层/样本；收紧需独立审计且速率有界。故不存在"越申诉越松"的升险路径，且真实反证在 `Δ_chal` 内立即生效（先保守）。
5. **证书时效性**：过期/污染/未版本化的基准不能进入 `J_s`，`FSE+` 直接拒签；探针作为审计样本只允许缩小 τ 或扩大 dom，不能给基准刷分。
6. **联合界（对检查点）**：
```
P_safe^D ≥ 1 − sup_{D'∈𝒫_ε} Σ_{s∈dom} π_s^{D'} (U_s+τ_s) − π_out
             − δ_ext − P(申诉未在 Δ_chal 内生效) − P(基准过期未检出)
```
   关键：**元先验给效率、共形给保底（第 57 轮）；基准效度给外推许可、分配约束给公平、申诉给纠错（本轮）**。四者串联后，安全不再是"在测过的世界里的高概率"，而是"**对未测世界明确说不知道，并让被影响者能把它变成已知**"。

## 6. 本轮最大风险

**一句话**：本轮把安全的判据从"证据是否可信"推进到"承载证据的评测是否可信"，风险也从"坏先验普遍"变成"**合法性剧场**"——若基准的分层覆盖、构念与外推半径本身无人审计，越漂亮、越精确的 P_safe 越会成为风险转移的许可证，让最没有话语权的受影响者承担被平均值掩盖的尾部风险；必须以覆盖空洞显式化、最坏分层硬帽、非同意者外部性预算、申诉强制保守回退四道闸门，宁可签发"不可认证"，也不签发一张只对测过的世界成立的证书。
