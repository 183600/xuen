# 第 43 轮（新循环第 1 轮） · 指标金字塔 × 桌面操作证书基准：把「指标体系」从仪表盘变成飞轮的方向盘（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR）。第 42 轮自陈最大风险是「仿真偏差累积」与「检索幻觉」导致的**静默失效**——飞轮看似在转，却可能在错误的指标上越跑越偏。本轮灵感词「指标体系」「桌面操作」正好补上两块地基：**指标体系**给飞轮装上「仪表盘 + 控制律」，把此前仅靠单一漂移标量 `S_t > τ` 触发的「盲飞轮」，升级为多维指标驱动、带硬安全约束的「受控飞轮」；**桌面操作**给抽象的证书框架一个接触密集、可复现的真实考场，让抓取/放置/推拉/倾倒/开抽屉这些原语把证书逼到最容易崩的接触切换处。核心命题一句话：**指标不是事后考核，而是在线控制信号**——指标缺口（metric gap）决定仿真预算往哪花、检索哪个模板、边缘跑哪一档、课程升到哪一级。

## 0. 直觉与动机

**灵感 1（指标体系 → 从「仪表盘」到「方向盘」）**：过去两轮把体系做得越来越复杂（CAR/LCS/CMC/SCV/CKB/ECR），但「好坏」仍被压成一两个标量：安全违例率、Nominal 占比、W_1。这有两个病灶。其一，**不可归因**：任务成功率掉了 5pp，到底是仿真偏差、检索错配、量化误差、还是查表插值？没人知道，飞轮只能全量重跑，贵且慢。其二，**古德哈特陷阱**：一旦把多维目标压成可优化的标量奖励，系统会学会「指标漂亮、真实退化」。指标体系的直觉是分层：L0 原子证书指标（margin p01、L_m、量化误差、迁移界）→ L1 复合操作指标（抓取成功率、放置毫米误差、滑移次数、洒漏量）→ L2 任务指标（完成率、节拍、重抓次数）→ L3 竞赛/系统指标（得分、可用性、安全事件、人工干预、COT）。更关键的是**可归因性**：金字塔的每条聚合边都带算子与权重，使 L3 的偏差能反向切分到具体 L0 叶子——指标因此从「记账」变成「诊断 + 分配」的控制信号。

**灵感 2（桌面操作 → 接触密集的证书考场）**：桌面操作不是「导航 + 抓取」的简化版，而是证书最脆弱的地方：接触切换使边际在毫秒内崩塌、遮挡让视觉语义置信骤降、堆叠与可变形物体破坏刚体假设、毫米级放置精度要求把插值误差直接顶到阈值上。直觉是把桌面操作分解为六个可组合原语（pick / place / push / pour / open / stack），每个原语带一张「证书画像」（接触阶段数、遮挡度、可变形性、精度要求）和「指标画像」（该原语最敏感的 L1 指标）。于是抽象证书第一次有了**可测、可复现、可对抗**的落地考场，也让「这个证书到底值不值得多花预算」有了量化答案。

**灵感 3（耦合升级 → 指标金字塔导向的「定向飞轮」）**：把两者焊接起来得到本轮真正的增量——**指标路由**（metric routing）。第 42 轮的飞轮由漂移单点触发、全量重跑；本轮飞轮由「有效指标缺口」驱动：`Δ_eff(m) = gap(m) × 归因权重(m) × 可干预概率(m)`，预算按 `√Δ_eff` 水位填充分配给最值得修的证书维度，并在安全不变量 `I_safe` 的字典序硬约束下选择干预臂。飞轮由此从「抖动式全局重算」变成「外科手术式定点优化」，同时用「反指标孪生 + held-out 安全检验」给指标体系本身装上防作弊机制。

**耦合的另一面（诚实说明）**：桌面操作把状态空间压到桌面尺度，样本效率对仿真友好；但接触动力学恰是仿真最不可靠的区段，因此本轮的桌面基准必须显式包含「接触切换真值对」，否则指标体系会把仿真偏差当成真实改进——这也是本轮最大风险的技术根源。

## 1. 形式化定义（增量：定义 38–44）

**定义 38（指标空间与 Pareto 偏序）**：指标空间 `M = M_cert ⊗ M_task ⊗ M_cost ⊗ M_evol`，每个指标 `m = (name, value, direction, target, tail_stat)`；其中 `direction ∈ {↑, ↓}`，`tail_stat ∈ {mean, p01, p99, min, max}`（安全类指标一律取尾部分位）。定义支配关系 `a ≺ b` 当且仅当 `∀m: m(a) 不劣于 m(b)` 且至少一个严格优。指标体系不预设标量化，只在约束优化时按字典序或 Pareto 前沿比较。

**定义 39（指标金字塔 Py）**：`Py = (V, E, {w_e}, {op_e})` 为有向无环图：`V` 按层级 `L0`（原子证书）/`L1`（操作原语）/`L2`（任务）/`L3`（系统）排列；每条边 `e: u → v` 带聚合算子 `op_e` 与权重 `w_e`。强制语义：**安全类聚合用 `min`/最坏分位（不可补偿）**，时间类用 `sum`，性能类用加权均值，尾部风险类用 CVaR。**命题 A（单调可归因性）**：若所有 `op_e` 单调且各 L0 指标对 L3 的 Lipschitz 敏感度有界，则 L3 任一指标的非零下降必对应至少一个 L0 父节点的非零可归因缺口——因此失败可被局部化，而非只能整体重跑。

**定义 40（指标缺口与有效缺口）**：`gap(m) = max(0, target(m) − value(m))` 按方向归一；**有效缺口** `Δ_eff(m) = gap(m) · a(m) · p(m)`，其中 `a(m)` 为金字塔反向归因权重（L0 叶子对 L3 偏差的边际贡献经 softmax 归一），`p(m) ∈ [0,1]` 为该维度在当前预算下被干预后确实可改善的概率（由 DCB 反事实实验校准）。归因采用「反事实 + Shapley 近似」：`a(leaf) ∝ E[ΔL3 | do(fix leaf)] − E[ΔL3 | do(nothing)]`，在仿真里廉价估计、在 DCB 上抽检审计。

**定义 41（桌面操作证书基准 DCB）**：任务族 `T = T_pick ⊗ T_place ⊗ T_push ⊗ T_pour ⊗ T_open ⊗ T_stack`，每个 episode `ω = (scene, primitive_seq, seed, obj_set)`，配两个画像：**证书画像** `cp(ω) = (n_contact_phase, occlusion, deformability, precision_req, clutter)`，**指标画像** `mp(ω) = argmax_m sensitivity(m | ω)`。DCB 还固化「接触切换真值对」`(sim_traj, real_traj)` 用于估计接触段的局部 Sim-to-Real 偏差 `ε_contact`，并要求跨机、跨 seed 可复现。**覆盖度指标** `Cov_cert = |{e ∈ H.E : e 有 ≥N 条验证轨迹且 margin_p01(e) ≥ θ}| / |H.E|`。

**定义 42（指标路由控制律 π_M）**：飞轮决策是一个带安全盾的约束上下文 Bandit：臂 `a ∈ A = {重仿某维度 d, 检索+补丁模板 t, 重新量化监控器, 调整课程相位, 重新标定 α_e}`，上下文 `s = (Py 状态, 漂移 S_t, 剩余预算)`，奖励 `r = ΔCHI`（见定义 43）。**安全盾**：只有当臂的**认证安全下界**（证书给出，不容许用经验均值）不降低 `I_safe` 时才可执行。预算分配用递减收益水位填充：`b_m ∝ √Δ_eff(m)`，并受总预算 `B` 与冷却期约束。**命题 B（路由安全性）**：在字典序目标（安全 ≻ 性能）与安全盾下，任意轮次真实安全下界单调不降，故指标路由不会为追性能而牺牲认证安全。

**定义 43（证书健康指数 CHI 与安全不变量 I_safe）**：`I_safe = {unsafe_events = 0, margin_p01 ≥ θ_min, Cov_cert ≥ c_min}` 为**字典序最高**的硬不变量；`CHI = Σ_m w_m · normalize(m) `（仅在 `I_safe` 满足时定义，否则 `CHI = −∞`）。CHI 只用于**同安全等级内的排序**，绝不与安全做加权交换。

**定义 44（反指标孪生与指标重审）**：对每个主指标 `m` 设反指标 `m†`（如主指标「任务成功率」配反指标「held-out 场景成功率 / 干预次数 / 能耗」）。维护滚动相关系数 `ρ_t = corr(H_m, H_{m†})`；若 `ρ_t < ρ_min` 或 `m†` 跌破目标，触发**指标重审**：冻结该主指标的优化、用新鲜 DCB 种子做 held-out 复核、必要时改写聚合算子。此即对古德哈特定律的工程化防御。

## 2. 四大产出设计（增量 IP-57/58/59 + 升级 IP-54/55/56/51/52/53/50/45/47）

### 2.1 IP-57 METRIC-PYRAMID ENGINE（指标金字塔引擎 MPE）
1. **指标 DAG 编译**：从任务族自动生成 L0–L3 节点与聚合边，安全类边强制 `min`/CVaR，禁止被平均掩盖。
2. **归因器**：反事实 + Shapley 近似，输出 L0 叶子对 L3 偏差的贡献向量与置信区间；高不确定时回退到「整体重跑」而非盲信归因。
3. **反指标孪生与重审**：每个主指标注册 `m†`、`ρ_min`、held-out 种子池，自动触发指标审计。
4. **CHI 看板**：只做同安全等级内排序；安全违例时输出 `−∞` 与根因叶子，不作「综合得分」粉饰。

### 2.2 IP-58 DESKTOP-CERT-BENCH（桌面操作证书基准 DCB）
1. **原语与组合**：六个原语 + 难度轴（遮挡、堆叠层数、可变形、精度要求、杂物密度），生成可复现 episode。
2. **证书画像标定**：为每个 episode 标注接触阶段边界与遮挡区间，作为 margin 崩塌检测的 ground truth。
3. **Sim-to-Real 真值对**：固定的接触切换片段对，估计 `ε_contact` 并作为迁移界 `α_e` 的接触段修正项（把第 42 轮全局 `W_1` 细化为分段 `W_1^contact`）。
4. **指标画像**：标定每个 episode 的敏感指标，供路由与归因使用；审计集与训练集 seeds 严格隔离。

### 2.3 IP-59 METRIC-ROUTER（指标路由控制器 MR）
1. **有效缺口估计**：`Δ_eff = gap × 归因 × 可干预性`，带置信区间；归因不确定度过高时降权。
2. **安全盾 + 约束 Bandit**：Thompson/UCB 在「安全下界不降」的可行臂集上选择；非平稳漂移用折扣/重启。
3. **水位预算**：`b_m ∝ √Δ_eff`，总预算 `B` 与冷却期 `T_cool` 硬约束，避免抖动式重跑。
4. **干预台账**：每轮记录 (上下文, 臂, 预测 ΔCHI, 实测 ΔCHI)，用于校准 `p(m)` 与后续归因。

```

闭环：DCB 测指标 → MPE 归因 → MR 选臂/分预算 → (SCV/CKB/ECR/课程) 定点修复

回退：E87 不达标 → 锁定 seed 池与物体集，先修基准再谈路由；E88 归因失效 → 关闭定向分配，回退第 42 轮全量重跑；E89 无预算收益 → 固定「每轮全量重跑」；E90 反指标守门失效 → 冻结所有性能类优化，仅保安全不变量；E92 接触覆盖不足 → 接触段一律升到最高档或 SafeStop。

## 5. 本轮最大风险

**一句话**：指标体系最大的风险是**古德哈特定律 + 指标归因错误**——一旦把多维安全/可用性压成可优化的标量奖励，飞轮会学会「指标漂亮、真实安全破产」，而失准的归因又会把预算精准地投到错误维度，让系统在「有仪表盘」的错觉中更快地跑偏；桌面操作基准若与真实 UniBot 任务分布偏离，还会放大这种过拟合。因此安全不变量 `I_safe` 必须做字典序硬约束、反指标孪生 + held-out DCB 必须守门、路由任何一步都不得以降低认证安全下界为代价。

def build_metric_pyramid(task_family):
    L0 = ['margin_p01','L_m_emp','T_hold_cover','quant_err','sim_real_gap',
          'retrieval_recall','lookup_lat']
    L1 = ['grasp_success','place_err_mm','orient_err_deg','slip_events',
          'spill_ml','collision_impulse']
    L2 = ['task_success','cycle_time','regrasp_count']
    L3 = ['score','availability','unsafe_events','human_interventions','COT']
    edges = [
        ('margin_p01','grasp_success', 'min',   1.0),
        ('quant_err','place_err_mm',   'sum',   1.0),
        ('L_m_emp','slip_events',      'cvar',  1.0),
        ('grasp_success','task_success','product',1.0),
        ('cycle_time','score',         'weighted',0.5),
        ('unsafe_events','score',      'lexicographic',inf),  # 安全优先
    ]
    return MetricDAG(L0, L1, L2, L3, edges)

def compute_chi(state, dag, weights, I_safe):
    # 字典序：安全不变量先于一切
    if any(state.safety[k] < I_safe[k] for k in I_safe):
        return float('-inf'), 'SAFETY_BREACH', localize_root_cause(state, dag)
    perf = sum(weights[m] * normalize(state[m]) for m in state.perf)
    return perf, 'OK', []

def attribute_gap(L3_gap, dag, state, fixes, dcb):
    # 反事实：对每个 L0 叶子估计其修复对 L3 偏差的边际贡献
    contrib = {}
    base = dcb.evaluate(state)          # 仿真廉价估计
    for leaf in dag.leaves:
        if leaf not in fixes: continue
        delta = base - dcb.evaluate(fixes[leaf])
        contrib[leaf] = delta * reliability(leaf, dcb)   # 归因置信度加权
    if max_confidence(contrib) < conf_min:
        return None                     # 不可靠 → 回退全量重跑，不盲分预算
    return softmax_normalize(contrib)

def counter_metric_guard(primary, twin, window, rho_min, twin_target):
    rho = rolling_corr(window[primary], window[twin])
    if rho < rho_min or window[twin][-1] < twin_target:
        return trigger_metric_audit(primary, reason=('rho', rho))
    return 'OK'
```

### IP-59 MR：指标路由与预算分配
```
def metric_router(state, dag, KB, SCV, ECR, budget, T_cool):
    if cooldown_active(T_cool): return 'HOLD'
    # 1. 有效缺口 = 缺口 × 归因 × 可干预性
    gaps = estimate_gaps(state, dag)
    attrib = attribute_gap(state.L3_gap, dag, state, state.fixes, DCB)
    if attrib is None: return ('FULL_RESIM', None)   # 归因不可靠的安全回退
    delta_eff = {m: gaps[m] * attrib.get(m, 0) * intervenability(m)
                 for m in gaps}

    # 2. 枚举候选干预臂
    arms = []
    for m, d in top_k(delta_eff, k=8).items():
        arms += candidate_arms(m, d, state, KB, SCV, ECR)

    # 3. 安全盾：认证下界不得降低 I_safe
    feasible = [a for a in arms if safety_lower_bound(a, state) >= I_safe]

    # 4. 约束上下文 Bandit（Thompson）选择臂
    a_star = thompson_select(feasible, budget, prior=ledger_prior(a_star_hist))

    # 5. 预算水位填充：b_m ∝ √Δ_eff
    alloc = water_fill({m: delta_eff[m] for m in affected(a_star)}, budget)
    return a_star, alloc

def water_fill(delta_eff, B):
    # 递减收益：边际收益 ∝ 1/√b，令 b_m ∝ Δ_eff(m)，归一化后截断到 B
    z = {m: math.sqrt(max(delta_eff[m], 0)) for m in delta_eff}
    s = sum(z.values()) or 1.0
    return {m: B * z[m] / s for m in z}

def safety_lower_bound(arm, state):
    # 只用证书给出的保守下界，禁止用经验均值“证明”安全
    return certify_margin_lower_bound(apply_intervention(arm, state))
```

| 风险 | 等级 | 缓解措施 |

## 6. 本轮最大风险

**一句话**：指标体系最大的风险是**古德哈特定律 + 指标归因错误**——一旦把多维安全/可用性压成可优化的标量奖励，飞轮会学会「指标漂亮、真实安全破产」，而失准的归因又会把预算精准地投到错误维度，让系统在「有仪表盘」的错觉中更快地跑偏；桌面操作基准若与真实 UniBot 任务分布偏离，还会放大这种过拟合。因此 `I_safe` 必须做字典序硬约束、反指标孪生 + held-out DCB 必须守门、路由任何一步都不得以降低认证安全下界为代价。
