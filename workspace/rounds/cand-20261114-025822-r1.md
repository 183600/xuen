# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「扩散策略」×「机械臂抓取」）

> R69 把不确定性一分为二，并让系统学会「问」。但它默认了一个前提：**测量动作是独立的、可重复的、便宜的**——看、问、触都是附加在任务动作旁边的 g，有预算、可认证，失败了还能再问一次。真实机械臂抓取恰好相反：**最有信息量的动作就是任务动作本身**。夹爪闭合、加载、抬起，既是执行也是测量；而一旦抬起失败，物体可能已经碎了、掉了、变形了。R69 的 VoI 账本在这里算错了：它把「信息」当免费商品，只收「打扰成本」；接触世界里，信息的标价是**不可逆的状态改变**。
>
> 本轮两个灵感正好补上这一点：
> - **扩散策略**不是又一个动作生成器，而是天然的后验采样器：去噪链从先验退火到后验，接触观测以 guidance 注入，抓取信念在动作执行过程中被物理证据塑形；
> - **机械臂抓取**提供一种不可伪造、但不可撤销的证据：物体会真实地推回来，也会真实地碎掉。抓取前存在一个「最后可逆时刻」（LRM），之后每一步都在用不可逆风险换信息。
>
> 核心命题：**把抓取看成一场在承诺边界前完成的实验：用扩散策略在去噪中维持多模态抓取信念，用接触证据做物理反证，用阻抗/微滑/轻载作为探针设计变量，用不可逆性感知的 VoI 决定「现在问还是永远别问」；当恢复不可行或证据不一致时，退回 FLUID/R68 的保守。** 命名 **TACT-RAS**（Tactile Active Contact Testing for Reversibility-aware Adaptive Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这一下抓下去，是执行还是实验？我愿意为这个答案付多少不可逆的代价？**」

## 0. 直觉与动机

**灵感 1（抓取即实验 → 任务动作本身就是探针）**
直觉：桌上一个不透明杯子，不知道空/满、重/轻、滑/涩、结实/易碎。视觉先验给出两个都合理的抓取模态：抓杯柄，或从上方扣住杯口。R69 的做法是「再采 K 个样、聚类、如果还歧义就去看一眼/问一句」。但真正决定成败的证据不在图像里，而在**接触之后**：腕部力矩告诉你质心偏在哪，微滑起始告诉你摩擦系数，接触刚度告诉你杯壁有多脆。也就是说，**抓取动作本身就是实验**；问题不是「要不要额外做一个信息动作」，而是「怎样设计这次抓取，使它在完成任务的同时也把未知量测出来」。这把 R69 的「任务动作 + 信息动作」二元结构，升级成「带信息产出的单一接触轨迹」。

**灵感 2（扩散去噪即信念退火 → 采样器就是推理机）**
直觉：R69 的流匹配策略是「先采 K 个样本、再离线聚类、再看哪个模态可信」。这仍然是**先行动后验证**：幻影模态要等采样完、甚至执行后才发现。扩散策略可以更彻底：反向去噪链每一步都在从「噪声 + 先验」走向「抓取后验」，而接触观测可以像分类器引导那样，在去噪中间以似然梯度注入。于是「抓取模式是否真实」不是事后统计问题，而是去噪过程中被物理证据逐步筛掉的问题。**去噪步 = 退火步 = 信念更新步**；同一个网络既规划动作，也做后验采样。这正好回应 R69 自陈的最大风险：模态权重不可信时，VoI 会自信地追问一个幻影；接触则提供一个不可伪造的反证——物体不配合，模态就死。

**灵感 3（不可逆性给信息重新定价 → 最后可逆时刻）**
直觉：R69 的 VoI 假设「问一次不够可以再问」，所以只扣一个社交/物理成本。抓取不是这样：抬起是一次性的承诺，掉了就掉了，碎了就碎了。信息在**承诺前**和**承诺后**的价值完全不同：承诺前，信息可以改变「抓哪个、怎么抓、要不要抓」；承诺后，信息最多只能触发 recovery，已经不能改变「已经抬起来」这个事实。因此最优策略不是「边做边看」，而是**把能改变决策的实验尽量安排在最后可逆时刻（LRM）之前**；过了 LRM，任何探索都只能用不可逆风险支付，且决策权限已经收缩。信息不是免费的，它在接触世界里有一个明确的价格：**你愿意让世界变得多不可逆，来换取多少确定性**。

**灵感 4（阻抗是探针旋钮 → 软硬之间的 Fisher 信息）**
直觉：同一个夹爪，夹得越硬越稳，但越「盲」也越容易压坏；夹得越软越能感知物体形状、摩擦、脆性，但越容易滑。这不是简单的「安全 vs 效率」，而是**控制增益同时是实验设计变量**：刚度 K 决定了接触观测对物体属性的敏感度（Fisher 信息），也决定了负载能力与损伤风险。于是存在一条「探针谱」Pareto 前沿：**刚好夹得住的最软设置，往往是信息效率最高的设置**。抓取控制里的阻抗参数，第一次被当成「测量仪器参数」来优化。

**灵感 5（接触是不可伪造的 oracle，但会收费）**
直觉：R69 最大的担忧是「问错比不问更危险」——人会撒谎，语言模型会幻觉，模态权重会漂移。接触提供了一个不同性质的证据：物体不会配合你演戏；预测的接触签名不对，就是不对。这使得接触成为**物理接地（physical grounding）**的 oracle。但 oracle 收费：它可能压碎物体、可能让物体滑落、可能把你要测的证据本身破坏掉。所以本轮必须同时交付：接触一致性门（CCG）过滤幻影模态、恢复认证（RRC）保证可撤销、不可逆预算（IBG†）限制「用损害换信息」的总量、以及「不可逆动作不得单源定案」的证据纪律。

**灵感 6（旧层是边界，不是替代品）**
直觉：如果 B_irr = 0（不允许任何不可逆动作）、或没有接触证据、或 CCG 不可用，TACT 必须逐指令退化为 FLUID；如果 FLUID 的 VoI ≤ 成本，再退化为 CALM/R68。这样 R70 不是又加了一个需要独立信任的黑箱，而是把 R69 的「可逆信息动作」作为自己的零不可逆边界。**安全侧只加约束、不减约束**；效率侧的收益来自「在承诺前把可约不确定性消掉」，而不是来自「敢于冒险」。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（TACT-RAS 总览）** TACT-RAS = (CDP, CEB, IVP, RRC, PSO, SSP, CCG, IBG†, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **不可逆预算硬约束**：单位 episode Σκ(r) ≤ B_irr，不可逆状态转移次数 ≤ n_irr（默认 1，即「抬起」），且每个不可逆转移执行前必须有经 C-RAS-WM 认证的恢复策略 ρ，或明确的人类接管；
(iii) **接触证据纪律**：单次接触事件不得单独定案；不可逆动作需至少两路正交证据（视觉先验 + 触觉/力矩）一致，或显式恢复计划，否则降级为可逆预实验或不动作；
(iv) **接触一致性**：任何被执行的抓取模态必须通过 CCG（定义 314）；否则视为幻影模态，零接触退回 FLUID 保守。

**定义 311（接触轨迹与物体属性）** 抓取计划 ξ = (T^{EE}_{t:t+H}, w_{t:t+H}, K_{t:t+H}, σ_{t:t+H}) ∈ 𝒜_contact：T ∈ SE(3) 为末端轨迹，w 为夹爪开度，K 为阻抗增益（刚度/阻尼），σ 为接触时序与力斜坡。物体属性 θ = (m, c_com, μ_s, μ_k, κ_frag, δ_pose, E_deform)，分别对应质量、质心、静/动摩擦、脆性、位姿偏差、形变模量。接触观测
y_t = (F_t, τ_t, tactile_t, τ_joint_t, slip_t, proprio_t) = h(θ, ξ_{≤t}) + n_t，
其中 slip_t ∈ {0,1} 为滑移事件。接触证据集 ℰ_contact = {y_t}。注意：θ 中只有一部分能在不破坏物体的前提下被识别（定理 20）。

**定义 312（接触扩散策略 CDP）** 归一化抓取块 x_0 = ξ。前向 q(x_s|x_0) = 𝒩(√ᾱ_s x_0, (1−ᾱ_s)I)。反向
p_ψ(x_{s−1}|x_s, o_t, y_{≤t}) = 𝒩(μ_ψ(x_s,s,o_t), Σ_ψ)，
并把接触似然作为引导注入：
x_{s−1} ← x_{s−1} + ζ Σ_ψ ∇_{x_s} log p(y_{≤t}|x_s, θ)。
训练 L_CDP = E‖ε − ε_ψ(x_s,s,o_t)‖² + λ_c L_contact，其中 contact head 预测接触签名（力/触觉/滑移起始）。采样默认用 consistency 蒸馏 1 步，接触惊喜时升 4 步。与 R69-FMP 的区别：FMP 是生成器，CDP 是**后验采样器**；FMP 先采样后聚类，CDP 在去噪中就用接触证据筛模态。

**定义 313（接触证据信念 CEB）** 信念 b_t(θ) ∝ p(θ) Π_{i≤t} p(y_i|θ, ξ_{≤i})。用扩散样本给出的粒子 {θ^{(j)}} 及其权重表示。去噪步 s 对应温度 β_s（β_s ↑），p_s(θ) ∝ p_0(θ) p(y|θ)^{β_s}；每步反向去噪近似一次退火后验更新。接触惊喜度 surprise_t = KL(b_t ‖ b_{t−1}) 或预测对数似然跌幅；超过阈值触发加粒子/加步数。

**定义 314（抓取模态与接触一致性 CCG）** 由 R69-AUD 在 ξ 样本上聚类得模态 {m_k}。每个模态附带预测接触签名 ĉ_m = (F_contact, tactile pattern, slip onset, torque profile)。定义
CCS(m) = exp(−½ ‖ĉ_m − y_obs‖²_{Σ_c})，
其中 Σ_c 为接触签名噪声协方差。m 可执行 ⇔ CCS(m) ≥ τ_cc。若无任何模态通过：发生**物理反证**，判定为幻影模态，零接触后退回 FLUID 保守；若多个通过：保留为后验，不强行合并。

**定义 315（可逆性等级与恢复策略 RRC）** 对状态转移 s→s'，可逆性等级 r(s,s') ∈ {0 可逆, 1 可恢复, 2 不可逆}。恢复策略 ρ: 𝒮→𝒜。称 s→s' 可恢复，若存在 ρ 使系统在有限时域内回到安全集，且 ρ 通过 C-RAS-WM 前缀认证。不可逆成本 κ(0)=0 < κ(1) < κ(2)，损伤风险 d(ξ) ∈ [0,1]。可恢复集 R(s) = {s' : ∃ρ, reach safe set}。r=2 时必须有预先承诺的恢复计划或人类接管，否则禁止执行。

**定义 316（承诺边界与最后可逆时刻 LRM）** τ* = sup{t : R(s_t) ≠ ∅}，即仍存在安全恢复的最后时刻；[0, τ*] 为承诺前窗口，(τ*, T] 为承诺后。LRM = τ*。承诺后可用动作集 𝒜_post ⊆ 𝒜_pre（少了「不承诺」「换抓取」「退回」等选项）。由引理 19，任何承诺后可行的实验在承诺前也可行，故把可改变决策的探针安排在 LRM 之前不会更差。

**定义 317（不可逆性感知的 VoI，I-VoI）** 令 M 为待决策的抓取模态/任务动作。定义
I-VoI(ξ) = E_{y|ξ}[H(M|b) − H(M|b,y)] − λ_irr E[κ(r(ξ))] − λ_dmg E[d(ξ)] − λ_t c_time(ξ)。
选择 ξ* = argmax I-VoI(ξ)，s.t. CCG 通过、RRC 可恢复、C-RAS-WM 安全包络、预算未超。若 max I-VoI ≤ 0：不探索，执行 R69/R68 的最保守动作。注意信息项用的是**决策相关**互信息 IG(M;y|ξ)，不是 θ 的全部熵——不改变抓取选择的「信息」不值钱。

**定义 318（探针谱与 Fisher 信息）** 局部接触模型 y = H(K)θ + n，n ~ 𝒩(0, Σ_n)。Fisher 信息 F(K) = H(K)ᵀ Σ_n⁻¹ H(K)。高斯先验 Σ_0 下，期望信息增益
IG(K) = ½ log det(I + F(K)Σ_0)。
负载能力 C(K) 与损伤风险 D(K) 随 K 单调增，信息敏感度 I(K) 随 K 单调减（软探针更敏感）。可行域 𝒦 = {K : C(K) ≥ C_min(负载裕度), D(K) ≤ ε_dmg}。在 𝒦 的 Pareto 前沿上选 K*；典型解在**下边界 C(K*)=C_min**：刚好夹得住，尽量软地去学。若 C_min 很大（重物），K 被迫很大，信息敏感度坍塌——此时必须先借支撑/桌面做二级接触，或放弃抬起。

**定义 319（安全微滑 SSP）** 滑移裕度 m = μ F_n − F_t。安全探测区域：物体仍由桌面/第二接触支撑，m ∈ [m_min, m_slip]，且位姿在 R(s) 内。对切向力做缓升斜坡 F_t(t) ↑，直到滑移事件或力上限；观测滑移起始给出 μ 的 Bernoulli 似然 p(slip | μ, F_n, F_t)。**滑移是最便宜的摩擦实验，前提是物体不会掉下去**；一旦失去支撑，微滑就退化为不可逆失败。

**定义 320（接触证书 J_TACT）** J_TACT = (J_FLUID, CCS_min, r_class, recovery_hash, slip_margin_min, I_VoI, eta_info, irr_spent, diff_health, tact_ver)。Valid ⇔ Valid(J_FLUID) ∧ CCG 通过 ∧ (r < 2 ∨ recovery 已认证) ∧ irr_spent ≤ B_irr ∧ 扩散采样器健康 ∧ 证据纪律满足。

**定义 321（不可逆预算与证据治理 IBG†）** 在 R69-IBG 的交互频率/位移/社交成本之上，新增：每 episode 的不可逆成本总和 ≤ B_irr；不可逆转移次数 ≤ n_irr（默认 1）；不可逆动作不得基于单一证据源；若只有单源，必须降级为可逆预实验或不动作。所有决策与恢复计划写入审计缓冲。

**定义 322（扩散故障与接触反证 ℰ_diff）** ℰ_diff = {模态幻觉, 引导错配, 采样器发散, 接触签名不匹配, OOD 分数膨胀}；ℰ_contact = {软体/易碎/摩擦歧义物体, 外观欺骗（看着轻其实重）, 滑移}。AIC：ℰ_TACT = ℰ_FLUID × ℰ_diff × ℰ_contact。接触反证是新增的对抗测试：不是「回答得像不像」，而是「物体推回来的力对不对」。

**定义 323（接触-标定对偶的物理版）** 接触残差 r_contact = ŷ(θ̂, ξ) − y。与 R68 的传感器残差 r_res（传感器自洽）和 R69 的 Δa（行为密度）不同，r_contact 由**物体本身**产生，传感器标定无法把它吸收掉，除非物体模型错。三元组 (r_res, Δa, r_contact) 可分离「传感器漂移 / 策略 OOD / 物体模型错误」。这是 R69「标定不可吸收的第二意见」的物理接地版：语言回答可能被伪造，接触签名必须由真实物理状态兑现。

**定义 324（自适应去噪与接触惊喜）** 默认 1 步蒸馏 CDP + K=1；当预测似然骤降、CCS 下降或发生滑移时，升到 4 步 + K=4 并重规划。高频滑移反射（1 kHz）由独立低层控制器执行，不走高层扩散推理。计算预算按 P99 硬约束，不允许「思考时夹爪还在闭合」。

**定义 325（退化边界与严格包含）** 若 B_irr = 0、无接触证据、或 CCG 不可用，则 TACT 逐指令退化为 FLUID；若 FLUID 的 VoI ≤ 成本、ECE 越界或 slow_fault_suspect，则再退化为 CALM/R68。故 **TACT ⊇ FLUID ⊇ CALM**：旧层是边界情形，不是并列替代。

## 2. 关键算法骨架

```python
# IP-264 CDP：接触引导的扩散抓取策略（复用 R68/R69 trunk，蒸馏 1~4 步）
class ContactDiffusionPolicy:
    def __init__(self, trunk, eps_net, contact_head, n_steps=1):
        self.trunk, self.eps = trunk, eps_net       # epsilon_theta(x_s, s, z)
        self.contact_head = contact_head            # xi -> predicted contact signature
        self.n_steps = n_steps                      # 1 distilled / 4 on contact surprise

    def sample(self, o_t, y_hist, K=1, n_steps=None):
        z = self.trunk(o_t)
        x = randn(K, D)
        for s in reversed(range(n_steps or self.n_steps)):
            x = self.denoise(x, s, z)
            if y_hist:                              # contact guidance = likelihood ascent
                x = x + GAMMA * contact_guidance(x, y_hist, z)
        return [self.decode(xi) for xi in x]        # xi = (T, w, K_imp, sigma)

# IP-265 CEB：接触证据的粒子信念
def update_belief(b, xi, y):
    w = b.w * likelihood(y, xi, b.theta)            # p(y | theta, xi)
    return ParticleBelief(b.theta, normalize(w))

# IP-267 RRC：执行前必须回答「能不能反悔」
def certify_recovery(xi, state, wm):
    r = irreversibility_class(state, xi)            # 0 / 1 / 2
    if r == 2:
        return None                                 # 无恢复计划的不可逆动作一律拒绝
    rho = synthesize_recovery(state, xi, wm)        # 放回 / 降下 / 松开
    return (r, rho) if wm.certify_prefix(rho) else None

# IP-270 CCG：用物理接触签名否决幻影模态
def contact_consistency(modes, y_obs):
    ok = []
    for m in modes:
        c_hat = contact_head.predict(m.xi)
        s = ccs(c_hat, y_obs)                       # exp(-||c_hat - y||^2 / 2 Sigma_c)
        if s >= TAU_CC: ok.append((m, s))
    return ok                                      # 空 => 物理反证，退回 FLUID

# IP-274 TACT 主闭环（在 R69 的 FLUID 环上插入接触层）
def TACT_round(M, obs):
    # 0) R69 先跑：给出 aleatoric / epistemic 与候选模态
    U_ale, U_epi, modes = M.fluid.step(obs)
    # 1) 承诺前：扩散规划；默认低刚度 = 探测优先
    xi = M.cdp.sample(obs, M.ceb.history, K=1)
    # 2) 不可逆门：没有恢复策略就不接触
    rc = M.rrc.certify_recovery(xi, M.state, M.wm)
    if rc is None:
        return M.fluid.conservative(obs)             # 退回 R69/R68
    r, rho = rc
    # 3) 探针谱：在 Fisher 信息 / 负载 / 损伤的 Pareto 上选阻抗
    xi = M.pso.choose(xi, M.ceb.belief, M.task.load_estimate)
    # 4) 执行到接触/事件；这个动作同时是任务执行与测量
    y = M.execute_until_contact_or_event(xi)
    M.ceb.update(xi, y)
    # 5) 物理反证：接触签名不对的模态直接否决
    consistent = M.ccg.filter(modes, y)
    if not consistent:
        return M.fluid.conservative(obs)
    # 6) I-VoI：还值不值得再做一次（可逆或微滑）探针？
    probe = M.ivp.choose(consistent, M.ceb.belief, M.budget)
    if probe and M.ibg.allow(probe, r):
        y2 = M.execute(probe)                        # 微滑 / 轻载 / 换抓取
        M.ceb.update(probe, y2)
        consistent = M.ccg.filter(consistent, y2)
    # 7) 风险缩放与安全认证继承 R69/R68
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + (U_epi if not consistent else 0)))
    k = M.cras_wm.certified_prefix(M.ach.propose(...), ..., M.wm_preds)
    # 8) 审计 + 证书；不可逆动作必须有恢复计划哈希
    M.audit.submit(xi, y, probe, r, rho)
    return k, lam, select_mode(consistent), J_TACT(...)
```

## 3. 推导

**A99（承诺前后动作集嵌套）** 对任意 t ≤ τ*，承诺后可行策略集合 𝒫_post ⊆ 𝒫_pre：承诺前多出「不承诺」「换抓取」「退回」等选项。
**A100（局部线性接触模型）** y = H(K)θ + n，H 对 K 可微；C(K)、D(K) 单调增，I(K) 单调减。
**A101（恢复可认证）** 存在可合成且经 C-RAS-WM 认证的恢复策略 ρ，能在有限时域内回到安全集。
**A102（接触签名可分）** 真实模态与幻影模态的预测接触签名间距 Δ_c ≥ 3σ_c。
**A103（激励的不可逆代价）** 每个能有效激励 θ 的接触事件，至少产生 κ_min > 0 的不可逆成本（测摩擦要加载/微滑，测脆性要施力）。

**引理 19（承诺前信息支配）** 在 A99 下，同一实验 y 在承诺前的决策价值 ≥ 承诺后的决策价值。证明：任取承诺后的条件策略 π_post，它在承诺前也可执行；承诺前的动作集更大，故可模仿 π_post 并保留额外选项。系：若某探针的 I-VoI > 0，把它安排在 LRM 之前不会更差；LRM 之后的信息只能改变 recovery 分支，价值受 recovery 选项上界约束。**最值钱的测量发生在点无返回之前。**

**引理 20（探针谱与 Fisher 信息）** 在 A100 下，高斯先验的期望信息增益 IG(K) = ½ log det(I + F(K)Σ_0)，F(K)=H(K)ᵀΣ_n⁻¹H(K)。由于 C(K)、D(K) 随 K 增而 I(K) 随 K 减，可行域 𝒦 上的最优 K* 满足：要么负载约束 C(K)=C_min 起作用，要么边际信息增益等于边际损伤/负载代价。系：常见情形 K* 落在下边界——**刚好夹得住的最软设置，信息效率最高**；重物迫使 K 很大，信息敏感度坍塌，必须先借桌面支撑或两级抓取。推论：不存在「又硬又软」的探针；安全与信息在这里是同一根旋钮的两端。

**引理 21（接触一致性过滤幻影模态）** 在 A102 下，若 CCS = exp(−‖ĉ−c‖²/2σ_c²)，τ_cc 取 3σ 门限，则单个幻影模态误接受概率 ≤ exp(−Δ_c²/2σ_c²) ≤ e^{−4.5} ≈ 0.011；K 个模态的 union bound ≤ K e^{−4.5}。系：**接触是不可伪造的 oracle**——物体不会配合演戏，接触签名必须由真实物理状态兑现；这正面回应 R69 的「问错比不问更危险」，但代价是不可逆（引理 22、定理 20）。注意它防的是「幻影模态」，不是「物体被误感知」；后者要靠多通道证据与 r_contact。

**引理 22（I-VoI 是 VoI 的严格泛化）** I-VoI = VoI − λ_irr Eκ − λ_dmg Ed − λ_t c。当 κ=d=0 且 R 满时 I-VoI = VoI；∂I-VoI/∂κ ≤ 0。若探针不改变最终选择的模态（IG(M;y)=0），则 I-VoI ≤ 0，不应探测。故 R69 的「VoI−成本 ≤ 0 → 不交互」是 TACT 在零不可逆、全可恢复边界上的特例。

**定理 18（严格包含链 TACT ⊇ FLUID ⊇ CALM）** 当 B_irr=0、无接触证据、CCG 关闭时，TACT 的 ξ 退化为 R69 的 (a,g)，I-VoI 退化为 VoI，且所有安全认证包含 R69 的 C-RAS-WM；故逐指令相同。FLUID 在 VoI ≤ 成本、ECE 越界或 slow_fault_suspect 时再退化为 CALM/R68。TACT 只增加约束（不可逆预算、恢复认证、接触一致性），不删除任何旧约束，故安全侧永不弱于 R69。**旧层是边界，不是替代品。**

**定理 19（恢复认证安全与有界损害）** 在 A101 下，每个不可逆转移执行前都有经认证的恢复策略 ρ 与已计入的 κ(r)；若接触一致性失败、预算耗尽或恢复不可行，立即执行 ρ 或冻结在最后可恢复状态。则单 episode 的不可恢复损伤概率 ≤ ε_dmg，且控制连续、无突变（继承 R69 定理 17 的换装不变式）。TACT 的探索是**有界风险探索**，不是把安全赌在扩散模型上。

**定理 20（有限接触实验的可识别性上界）** 在 A100/A103 下，每个 θ-激励事件贡献 Fisher 信息至多 F_max，且至少花费 κ_min。不可逆预算 B_irr 允许的事件数 N ≤ ⌊B_irr/κ_min⌋，故后验协方差满足
Cov(θ) ⪰ (Σ_0⁻¹ + N F_max)⁻¹（Loewner 序）。
若目标精度 ε 满足 ε² < 1/(N F_max)，则在预算内**无法**把 θ_j 认证到 ε。系：存在「认证地平线」——**你不能既要求绝不碰坏，又要求在抬起前知道它有多脆**。对这类物体，TACT 必须借支撑做可逆预实验、降级为保守不抬、或转人类接管。这不是缺陷，而是诚实的能力边界。

## 6. 本轮最大风险

**一句话**：TACT-RAS 把效率收益押在「接触模型足够准」这一前提上——**如果扩散策略预测的接触签名与真实摩擦/形变/脆性失配，I-VoI 会挑出「信息量最大」的那次探针，而那恰好可能就是压碎或跌落的那一次；不可逆性让「用信息换安全」的账永远无法用后悔来偿还**——你不能从一个已经碎掉的物体上学习它有多脆。

**次级风险与缓解**：
1. **接触模型 sim-to-real 失配** → 保守力上限 + 域随机化 + 模型无关的滑移反射 + E313；
2. **扩散幻觉与引导错配** → CCG 物理反证 + 接触签名一致性 + E306；
3. **不可逆预算被 Goodhart** → 硬上限 n_irr=1、审计回灌、不可逆动作不得单源定案；
4. **恢复策略合成失败** → 无认证不接触；失败即冻结在最后可恢复状态（定理 19）；
5. **低层延迟击穿** → 蒸馏 1 步 + 事件触发 4 步 + 1kHz 独立滑移反射；
6. **认证地平线（定理 20）** → 承认有些物体在抬起前不可认证；借支撑预实验、保守不抬或人类接管，而不是假装知道。

**定义 315–316（可逆性、恢复、LRM）** `r∈{0,1,2}`，`κ(0)=0<κ(1)<κ(2)`；`ρ` 须认证；`τ*=sup{t:R(s_t)≠∅}`，`[0,τ*]` 为承诺前；承诺后动作集 `𝒜_post⊆𝒜_pre`，故探针应在 LRM 前。

**定义 317（I-VoI）** `argmax_ξ IG(M;y|ξ) − λ_irr Eκ − λ_dmg Ed − λ_t c`，s.t. CCG/RRC/安全/预算；`≤0` 则不探索、走 R69/R68。R69-VoI 是 κ=d=0、全可恢复的边界。

**定义 318（探针谱）** 局部 `y=H(K)θ+n`；`F(K)=HᵀΣ_n⁻¹H`；`IG=½logdet(I+FΣ_0)`；`C(K)↑, D(K)↑, I(K)↓`；在 `C≥C_min, D≤ε_dmg` 上选 K*；典型在负载下边界——刚好夹得住的最软设置信息效率最高。

**定义 319（安全微滑）** `m=μF_n−F_t`；有支撑、`m≥m_min`、位姿在 R(s) 内才允许切向斜坡；滑移起始给出 μ 的 Bernoulli 似然；失支撑则不可逆。

**定义 320–321（证书与 IBG†）** `J_TACT` 并入 CCS/r/recovery/slip/I-VoI/η/irr/diff；IBG† 新增 `Σκ≤B_irr`、`n_irr=1`、不可逆动作不得单源。

**定义 322–323（ℰ 与物理对偶）** `ℰ_TACT=ℰ_FLUID×ℰ_diff×ℰ_contact`；接触残差 `r_contact=ŷ(θ̂,ξ)−y` 由物体产生，传感器标定吸收不了；三元组 `(r_res, Δa, r_contact)` 分离传感器漂移/策略 OOD/物体模型错。

**定义 324–325（自适应与退化）** 默认 1 步+K=1；惊喜升 4 步+K=4；1kHz 滑移反射独立。`B_irr=0`/无接触/CCG 不可用 ⇒ TACT≡FLUID；FLUID 无利可图 ⇒ CALM/R68。**TACT ⊇ FLUID ⊇ CALM**。

## 3. 关键算法伪代码

```python
# IP-264 CDP：接触引导扩散抓取（蒸馏 1 步；复用 R68/R69 trunk）
class ContactDiffusionPolicy:
    def sample(self, o_t, y_hist, K=1, n_steps=1):
        z, x = self.trunk(o_t), randn(K, D)
        for s in reversed(range(n_steps)):
            x = self.denoise(x, s, z)
            if y_hist:
                x = x + GAMMA * contact_guidance(x, y_hist, z)   # likelihood ascent
        return [self.decode(xi) for xi in x]                     # ξ=(T,w,K,σ)

# IP-265 CEB：接触证据粒子信念
def update_belief(b, xi, y):
    return ParticleBelief(b.theta, normalize(b.w * likelihood(y, xi, b.theta)))

# IP-267 RRC：无恢复不接触
def certify_recovery(xi, state, wm):
    r = irreversibility_class(state, xi)                     # 0/1/2
    if r == 2: return None
    rho = synthesize_recovery(state, xi, wm)                 # 放回/降下/松开
    return (r, rho) if wm.certify_prefix(rho) else None

# IP-270 CCG：物理反证否决幻影模态
def contact_consistency(modes, y_obs):
    return [(m, ccs) for m in modes
            if (ccs := ccs_of(contact_head.predict(m.xi), y_obs)) >= TAU_CC]

# IP-274 主闭环：在 R69 FLUID 环上插入接触层
def TACT_round(M, obs):
    U_ale, U_epi, modes = M.fluid.step(obs)                  # R69 先跑
    xi = M.cdp.sample(obs, M.ceb.history, K=1)               # 承诺前规划
    rc = M.rrc.certify_recovery(xi, M.state, M.wm)
    if rc is None: return M.fluid.conservative(obs)          # 无恢复 => 退 R69/R68
    r, rho = rc
    xi = M.pso.choose(xi, M.ceb.belief, M.task.load_estimate)  # 探针谱选阻抗
    y  = M.execute_until_contact_or_event(xi)                # 执行即测量
    M.ceb.update(xi, y)
    consistent = M.ccg.filter(modes, y)                      # 物理反证
    if not consistent: return M.fluid.conservative(obs)
    probe = M.ivp.choose(consistent, M.ceb.belief, M.budget) # I-VoI
    if probe and M.ibg.allow(probe, r):
        M.ceb.update(probe, M.execute(probe))
        consistent = M.ccg.filter(consistent, y2 := M.last_y)
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + (U_epi if not consistent else 0)))
    k = M.cras_wm.certified_prefix(M.ach.propose(...), ..., M.wm_preds)
    M.audit.submit(xi, y, probe, r, rho)
    return k, lam, select_mode(consistent), J_TACT(...)
```

## 4. 推导

**A99–A103** 承诺前后动作集嵌套；局部线性接触模型与单调 C/D/I；恢复可合成可认证；接触签名可分 `Δ_c≥3σ_c`；θ-激励事件至少花费 `κ_min>0`。

**引理 19（承诺前信息支配）** A99 下，同一实验在承诺前的决策价值 ≥ 承诺后（承诺前动作集更大，可模仿任何承诺后策略）。系：I-VoI>0 的探针安排在 LRM 前不会更差；LRM 后信息只能改变 recovery 分支。**最值钱的测量发生在点无返回之前。**

**引理 20（探针谱与 Fisher 信息）** A100 下 `IG(K)=½logdet(I+F(K)Σ_0)`，`F=HᵀΣ_n⁻¹H`；`C,D↑`、`I↓` 导致最优 K* 在负载下边界或边际信息=边际风险处。系：刚好夹得住的最软设置信息效率最高；重物迫使 K 大、信息敏感度坍塌，需借支撑/两级抓取。**安全与信息是同一根旋钮的两端。**

**引理 21（CCG 过滤幻影模态）** A102 下 3σ 门限的单模态误接受概率 ≤ `e^{−4.5}≈0.011`，K 模态 union bound ≤ `K e^{−4.5}`。系：接触是不可伪造的 oracle，物体不会配合演戏；正面回应 R69 的「问错比不问更危险」，但代价是不可逆。它防幻影模态，不防物体误感知——后者靠多通道与 `r_contact`。

**引理 22（I-VoI 严格泛化 VoI）** `I-VoI=VoI−λ_irrEκ−λ_dmgEd−λ_tc`；κ=d=0 且全可恢复时相等；`∂I-VoI/∂κ≤0`；若探针不改变模态（IG=0）则 `I-VoI≤0`，不探测。R69 的「VoI≤成本→不交互」是零不可逆边界。

**定理 18（严格包含链）** `B_irr=0`、无接触、CCG 关闭时，TACT 逐指令退化为 FLUID；FLUID 无利可图时退化为 CALM/R68。TACT 只加约束（不可逆预算、恢复、CCG），不删旧约束，安全侧永不弱于 R69。

**定理 19（恢复认证安全与有界损害）** A101 下每个不可逆转移都有认证 ρ 与计入的 κ；失败即执行 ρ 或冻结在最后可恢复状态；单 episode 不可恢复损伤概率 ≤ ε_dmg；控制连续、无突变（继承 R69 定理 17）。探索是有界风险探索，不把安全赌在扩散模型上。

**定理 20（有限接触实验的可识别性上界）** A100/A103 下每次 θ-激励至多贡献 `F_max`、至少花费 `κ_min`；`N≤⌊B_irr/κ_min⌋`，`Cov(θ)⪰(Σ_0⁻¹+N F_max)⁻¹`。若 `ε²<1/(N F_max)`，预算内无法认证到 ε。系：存在认证地平线——**不能既要求绝不碰坏，又要求在抬起前知道它有多脆**；此时借支撑做可逆预实验、保守不抬或人类接管。这是能力边界，不是缺陷。

## 7. 本轮最大风险

**一句话**：TACT-RAS 把效率收益押在「接触模型足够准」这一前提上——**如果扩散策略预测的接触签名与真实摩擦/形变/脆性失配，I-VoI 会挑出「信息量最大」的那次探针，而那恰好可能就是压碎或跌落的那一次；不可逆性让「用信息换安全」的账永远无法用后悔来偿还**——你不能从一个已经碎掉的物体上学习它有多脆。

**次级风险与缓解**：接触模型 sim-to-real（保守力上限 + 域随机化 + 模型无关滑移反射 + E313）；扩散幻觉/引导错配（CCG 物理反证 + E306）；不可逆预算 Goodhart（n_irr=1 硬上限 + 审计回灌 + 不可逆动作不得单源）；恢复失败（无认证不接触，失败冻结在最后可恢复状态）；低层延迟（1 步蒸馏 + 事件触发 4 步 + 1kHz 独立反射）；认证地平线（定理 20：借支撑预实验、保守不抬或人类接管，不假装知道）。
