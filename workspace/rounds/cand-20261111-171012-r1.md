# 第 55 轮（承接第 54 轮 v16+++ GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「6D位姿估计」×「可解释性」）

> 第 54 轮把技能组合从“能力匹配”推进到“动作空间剖面 + 云边协同”。本轮把几何感知层真正接入证书体系：**6D 位姿不是 SE(3) 上的一个点，而是对称商上的等价类；可解释性不是热力图，而是“哪些证据在动作相关自由度上钉住了位姿”**。核心矛盾：H22：现有证书把位姿当作裸 SE(3) 输入，忽略对象对称导致的规范自由度，把同一位姿的不同写法误判为不同状态；H23：位姿解释多在坐标相关空间做归因，旋转/对称一换解释就变，无法作为可验证证据；H24：云端全局位姿图与边端局部跟踪各自局部正确，却可能在对称等价类上发生“位姿混叠”，使云边契约静默失效。

## 0. 直觉与动机

**灵感 1（位姿是对称商上的点，不是 SE(3) 上的点）**
直觉：一个圆柱杯子绕自身轴转 180°，几何外观完全相同；位姿估计器可能输出相差 180° 的两个解，但对“从侧面抓取”而言它们可能就是同一个物理状态。现有 6D 位姿评测用 ADD-S 在对象层面对称化，但证书、规划、鲁棒性谱仍用裸 SE(3)，于是把“同一位姿的两种写法”当成两个不同状态，平白浪费安全预算。正确对象应是对象对称商 `P_obj = SE(3)/G_obj`，误差用商度量 `d_P`。这相当于把 ADD-S 从**评测指标**提升为**证书的第一性对象**。

**灵感 2（动作相关对称：并非所有对象对称都对任务等价）**
直觉：`G_obj` 描述“物体看起来一样”，但动作只关心 `G_act(a) ⊆ G_obj`。吸盘抓顶面可能对整圈旋转不敏感；平行夹爪只对 180° 不敏感；键槽插入对任何旋转都敏感。若用 `G_obj` 做商，会把 90° 的错误当等价，**不安全**；若用裸 SE(3)，又会把 180° 的正确解当错误，**过度保守**。正确对象是**动作相关商** `P_a = SE(3)/G_act(a)`。这是本轮最核心的“位姿—动作”接口：位姿的等价性由任务定义，而不是由物体外观单独定义。

**灵感 3（位姿不确定性有方向谱：可观测方向 vs 规范方向）**
直觉：位姿误差不是一个标量，也不是无方向的协方差球。在 `se(3)` 上，沿真实对称群方向的变化是**规范自由度**（gauge），任何观测都无法分辨；其余方向才是**可观测方向**。连续对称（如圆柱绕轴）给出 Fisher 矩阵的零空间；离散对称（如方盒的四重对称）给出多峰后验与模式间隔。把位姿不确定性分解为“规范方向 + 可观测谱”，解释才能说清楚：哪些自由度被证据钉住，哪些本来就自由。

**灵感 4（可解释的位姿 = 证据集 + 对称类 + 反事实脆弱性 + 阶段归因）**
直觉：位姿解释不应是一张 Grad-CAM 热图，而应是可核验的四元组：最小充分证据 `S_ev`（哪些像素/关键点/区域真正支撑了该位姿类）；对称类 `G_act`（解释在哪个商空间成立）；备选假设 `H` 与间隔 `m`（还差多少会翻转）；反事实脆弱性 `φ_cf`（最小遮挡/扰动成本使位姿类翻转）；以及根因阶段 `R_stage`（定位、匹配、PnP、对称误判、遮挡）。解释必须在对称变换下不变，否则一个物理上无关的旋转就会改写归因，解释就不再是证据。

**灵感 5（位姿误差要经动作雅可比回拉到动作空间）**
直觉：位姿误差本身不是终点，动作失败才是。把动作映射 `Φ_a` 在商空间上做水平提升，得到动作对位姿的敏感矩阵 `S_a = ∂Φ_a/∂ξ`；位姿协方差经 `S_a` 回拉为动作空间协方差 `Σ_a`。第 54 轮的 `α_S(a)` 应升级为**位姿条件动作剖面** `α_S(a | [T], ε_pose)`：对商球内所有位姿取下确界。这样“位姿精度”第一次以可证明的方式进入动作证书与鲁棒性谱 `ρ_S(d | ε_pose)`。

**灵感 6（云边共享的是位姿契约，不是位姿点）**
直觉：云端维护全局对象位姿图，边端维护局部跟踪与细化。二者各自局部正确，却可能在对称等价类上分叉：光度残差很小，但商空间距离很大，这就是**位姿混叠**。云边契约不能只交换一个 `T`，而应交换 `(对称类, 假设集, 商距离上界, 回环约束)`。边端把歧义与根因经解释通道回传，云端据此请求新视角或重规划，形成“位姿契约—混叠检测—主动消歧”的闭环。

**灵感 7（解释驱动的主动消歧只解决动作相关不确定性）**
直觉：如果歧义在规范方向上（真实对称），任何视角都无法消除，继续拍只会浪费动作预算；只有可观测方向上的不确定性能被信息增益降低。因此主动消歧应在 `P_a` 上计算期望信息增益 `IG_a`，而不是在裸 SE(3) 上算熵。解释在这里不只是事后说明，而是**控制信号**：当剩余歧义无法在预算内消除时，系统应给出“可证明不可判定”的拒绝，而不是赌一个位姿。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（对象对称群与位姿商）**
对象 `O` 的对象对称群 `G_obj = {g ∈ SE(3) | g·O = O}`，物理位姿空间 `P_obj = SE(3)/G_obj`，投影 `π_obj : SE(3) → P_obj`。商距离
```
d_{P_obj}([T1],[T2]) = min_{g1,g2∈G_obj} ||log((T1 g1)^{-1}(T2 g2))||_se(3)
```
其中 `[T]` 表示等价类。连续对称时 `P_obj` 是轨道空间（可能带奇点），离散对称时是有限覆盖的商流形。**关键约定：证书只在商空间上声明，不依赖代表元选择。**

**定义 122（动作相关对称与动作商）**
对动作类 `a`，令 `Φ_a(T)` 为对象位姿 `T` 下的动作结果（抓取位姿、接触点、成功谓词等）。动作相关对称群
```
G_act(a) = { g ∈ G_obj | Φ_a(T g) = Φ_a(T), ∀ T ∈ SE(3) }
```
动作相关位姿商 `P_a = SE(3)/G_act(a)`，商距离 `d_{P_a}` 同定义 121。**单调性约定：**`G_act(a)` 越大，商越粗、接受集越大，但高估对称会带来不安全；后续正确性只允许 `Ĝ_act(a) ⊆ G_act(a)` 的保守估计。

**定义 123（位姿假设集与商覆盖）**
位姿假设集 `H = {([T_i], w_i)}_{i=1..k}`，`Σ w_i = 1`。歧义间隔
```
m(H) = min_{i≠j} d_{P_a}([T_i],[T_j])
```
在动作类内可交换的校准集上，用非一致性分数 `d_{P_a}` 做分裂保形校准，得到半径 `ε_a`，满足
```
P( d_{P_a}([T_true], H) ≤ ε_a ) ≥ 1 - α_p
```
并称 `B_{ε_a}^{P_a}([T]) = { [T'] : d_{P_a}([T],[T']) ≤ ε_a }` 为**商球**。注意：保形覆盖只对同对称类/同动作类成立，跨对象迁移需重校准。

**定义 124（可观测位姿谱与规范分解）**
在 `[T]` 处取 `se(3)` 的 Fisher/Hessian 信息矩阵 `F`。连续对称时令 `g_a = Lie(G_act(a))` 为规范子空间，取水平补 `o_a = g_a^{⊥}`，将 `F` 限制到 `o_a` 得 `F_o`。特征分解
```
F_o v_i = λ_i v_i,  λ_1 ≥ λ_2 ≥ ... ≥ λ_6
d_eff = #{ i : λ_i ≥ λ_* }
```
`d_eff` 为**有效可辨识维数**。连续规范方向 `λ=0` 表示“不可观测但也不应被当作误差”；离散对称时 `g_a={0}`，改用假设图 `H` 的模式间隔 `m(H)` 与谱间隙描述多峰歧义。**位姿可解释性的第一层含义：说明哪些方向是规范、哪些方向被证据钉住。**

**定义 125（对称等变位姿解释证书）**
解释证书
```
E_pose = ( S_ev, G_act, H, m, A_attr, φ_cf, R_stage )
```
- `S_ev ⊆ Ω`：最小充分证据集（像素/关键点/区域），满足去掉它则位姿类判定的后验改变超过 `δ_suf`；
- `G_act`：解释所依据的动作相关对称群；
- `H, m`：假设集与歧义间隔；
- `A_attr : T_{[T]}P_a × 2^Ω → R`：商切空间上的归因场，要求对称等变 `A_attr(g·[T], g·S) = A_attr([T], S)`；
- `φ_cf`：最小遮挡/扰动成本，使位姿类 `class_{G_act}(T)` 发生翻转，称为**反事实脆弱性**；
- `R_stage ∈ Δ({定位, 匹配, PnP, 对称误判, 遮挡})`：阶段根因分布。

要求五条可核验公理：
```
(X1) 对称不变性: E_pose(g·T, g·Ω) = E_pose(T, Ω), ∀g∈G_act
(X2) 充分性:     class(T | Ω) = class(T | S_ev) 且置信差 ≤ δ_suf
(X3) 必要性:     ∀ S' ⊂ S_ev, 充分性失败
(X4) 反事实忠实: φ_cf 与真实失败率单调相关
(X5) 阶段校准:   R_stage 的 ECE ≤ δ_stage
```

**定义 126（位姿条件动作剖面与位姿条件鲁棒性）**
动作映射 `Φ_a` 在 `P_a` 上的水平雅可比 `S_a = ∂Φ_a/∂ξ`，位姿协方差 `Σ_ξ` 回拉为 `Σ_a = S_a Σ_ξ S_a^T`。位姿条件动作剖面
```
α_S(a | [T], ε) = inf_{ [T'] ∈ B_ε^{P_a}([T]) } α_S(a | [T'])
```
位姿条件鲁棒性谱
```
ρ_S(d | ε_pose) = inf_{ [T'] ∈ B_{ε_pose}^{P_a}([T]) } ρ_S(d; [T'])
```
二者合称**位姿感知动作证书** `PAC = (α_S(·|[T],ε), ρ_S(·|ε_pose), Σ_a, ε_pose)`。**与第 54 轮的接口：**`α_S` 与 `A_cert` 的取值域改为 `P_a` 上的商球，`δ_a` 增加位姿回拉项 `tr(Σ_a)^{1/2}`。

**定义 127（云边位姿契约）**
云边位姿契约
```
C_pose = ( G_c, T_e, Σ_e, δ_pose, Λ_loop )
```
- `G_c`：云端对象位姿图（节点为对象，边为相对位姿与对称类）；
- `T_e, Σ_e`：边端局部位姿与其协方差；
- `δ_pose`：云边商距离上界；
- `Λ_loop`：回环约束集合。
一致性条件：
```
d_{P_a}( [T_c], [γ_ce T_e] ) ≤ δ_pose
```
位姿混叠指示：
```
Alias = 1[ res_e < τ_r  ∧  d_{P_a}([T_c],[γ_ce T_e]) > δ_pose  ∧  m(H) < θ_m ]
```
其中 `res_e` 为边端重投影/光度残差。`Alias=1` 表示“局部看起来都对，但在对称商上已经分叉”。

**定义 128（解释驱动主动消歧）**
给定动作库 `A_dis`、商空间上的信念 `b` 与证据 `E`，商信息增益
```
IG_a(a) = H_{P_a}([T] | E) - E_{o∼P(·|a,E)}[ H_{P_a}([T] | E ∪ {o}) ]
```
主动消歧策略 `π_dis` 在预算 `B` 内选择
```
a* = argmax_{a∈A_dis} IG_a(a) / cost(a)
```
停止条件：`m(H) ≥ θ_m`（可判定）或 `max_a IG_a(a) < θ_ig`（在预算内不可判定）或预算耗尽；后两者输出**可证明不可判定证书** `Undecidable(ε_a, m, R_stage)`。**规范方向不产生正信息增益**，因此 `IG_a` 只在 `o_a` 上计算；这避免了“对着真实对称反复观察”的动作浪费。

### IP-121 SQP（Symmetry-Quotient Pose Certificate）

```python
def action_symmetry_group(action, G_obj, outcome_fn, tol):
    gens = []
    for g in G_obj.generators():
        if is_invariant(action, g, outcome_fn, tol):
            gens.append(g)
    return LieSubgroup(gens)          # 连续时返回李代数基；离散时返回有限元素

def quotient_distance(T1, T2, G):
    if G.is_continuous():
        xi = log(T1.inv() @ T2)
        return norm(xi - project(xi, G.lie_algebra))
    return min(norm(log(T1.inv() @ T2 @ g)) for g in G.elements())

def pose_certificate(T_hat, H, G_act, alpha_p, calib):
    eps = conformal_quantile([quotient_distance(h, T_hat, G_act) for h in calib], alpha_p)
    m = min(quotient_distance(H[i], H[j], G_act) for i < j)
    return PoseCert(T_hat, G_act, H, eps, m)
```

```python
def pose_portfolio(model, obs, G_act, alpha_p, calib):
```

```python
def observable_spectrum(T, obs, model, G_act):
```

### IP-127 ADX（Active Disambiguation eXplanation）

```python
def active_disambiguate(H, A_dis, evidence, budget, G_act):
    while budget > 0:
        if margin(H, G_act) >= theta_m:
            return ('ok', H, explain_pose(H[0], evidence, G_act))
        scored = [(quotient_IG(a, H, evidence, G_act) / a.cost, a) for a in A_dis]
        ig, a = max(scored)
        if ig < theta_ig:
            break
        evidence = execute_and_observe(a)
        H = bayes_update(H, evidence)
        budget -= a.cost
    return ('undecidable', UndecidableCert(H, budget, explain_pose(...)))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SQP | 有限 `G`: `O(|G|·6)`；连续: `O(6^3)` | `O(|G|+6)` | `G_act` 只可低估、商距离三角不等式 |
| CHP | `O(k log k + k·|G| + n log n)` | `O(k+n)` | 类内可交换、代表元规范化 |
| OPS | `O(n·6^2 + 6^3)` | `O(6^2+n)` | 规范子空间估计误差有界、`λ_*` 校准 |
| XPE | `O(k_ev·m·C_model + k_ev^2)` | `O(m)` | 充分/必要/等变/反事实忠实 |
| PAA | `O(m·6 + N_q·m)` | `O(m·N_q)` | 商球覆盖、下确界保守 |
| CEPC | 稀疏 `O((|V|+|E|)·6^3)` | `O(|V|+|E|)` | `γ_ce` 有界、回环闭合 |
| ADX | `O(B·|A_dis|·|H|)` | `O(|H|+|A_dis|)` | 商信息增益单调、停止规则 sound |

**命题 1（动作商不增保守性）**
设 `Ĝ_act ⊆ G_obj`，同一置信水平下商空间保形半径 `ε_a` 与裸空间半径 `ε_full` 满足 `ε_a ≤ ε_full`。若动作映射 `Φ_a` 在 `P_a` 上 `L_a`-Lipschitz，则
```
sup_{T' ∈ B_{ε_a}^{P_a}([T])} d_action(Φ_a(T), Φ_a(T')) ≤ L_a ε_a ≤ L_a ε_full
```
即动作商证书的失败上界不劣于裸 SE(3) 证书；当估计误差在规范方向上有正质量时严格更优。直观上：商化把“同一物理状态的另一种写法”从误差预算中剔除，而不是把预算花在不可观测方向上。

**定理（Pose-Quotient Composition Soundness）**
假设第 54 轮 (A22)–(A28) 成立；**(A29)** 估计的 `Ĝ_act ⊆ G_act^true`（宁可低估对称）；**(A30)** 商空间保形覆盖 `P(d_{P_a}([T_true],H) ≤ ε_a) ≥ 1-α_p`；**(A31)** `Φ_a` 在 `P_a` 上 `L_a`-Lipschitz；**(A32)** 解释通道阶段归因误差 ≤ `β_R` 且回传延迟 ≤ `τ_loop`。则
```
P(success) ≥ 1 - α_p - Σ_d(1 - ρ_min(d | ε_a)) - β_E
             - P(δ_a > Θ_a) - β_R - p_sym
```
其中 `p_sym = P(Ĝ_act ⊄ G_act^true)`；在 A29 下 `p_sym=0`。**关键：**若高估对称（把非对称当对称），商化会把物理上不同的位姿判为等价，上式立即失效；因此对称估计必须是保守子群，而不是最大似然群。

```python
def action_symmetry_group(action, G_obj, outcome_fn, tol):
    """只保留使动作结果不变的对称；返回子群（宁小勿大）。"""
    gens = [g for g in G_obj.generators()
            if max_action_outcome_drift(action, g, outcome_fn) <= tol]
    return LieSubgroup(gens)

def quotient_distance(T1, T2, G):
    if G.is_continuous():
        xi = log(T1.inv() @ T2)
        return norm(xi - project(xi, G.lie_algebra))
    return min(norm(log(T1.inv() @ T2 @ g)) for g in G.elements())

def pose_certificate(T_hat, H, G_act, alpha_p, calib):
    scores = [quotient_distance(T_hat, h, G_act) for h in calib]
    eps = conformal_quantile(scores, alpha_p)
    m = min(quotient_distance(H[i], H[j], G_act)
            for i in range(len(H)) for j in range(i + 1, len(H)))
    return PoseCert(T_hat, G_act, H, eps, m)

def quotient_class(T, G):
    return canonical_representative(T, G)
```

```python
def observable_spectrum(T, obs, model, G_act, lambda_star):
    F = pose_fisher(T, obs, model)            # 6x6，se(3) 局部坐标
    B = gauge_basis(G_act)                    # 连续对称生成元；离散时 B=[]
    if B:
        P = np.eye(6) - B @ np.linalg.pinv(B.T @ B) @ B.T
        F_o = P.T @ F @ P
    else:
        F_o = F
    lam, V = np.linalg.eigh(F_o)
    idx = np.argsort(lam)[::-1]
    lam, V = lam[idx], V[:, idx]
    d_eff = int(np.sum(lam > lambda_star))
    return Spectrum(lam, V, d_eff, gap=float(lam[0] - lam[1]))
```

| 组件 | 时间 | 空间 | 正确性保证 |

**命题 1（动作商不增保守性）**
设 `Ĝ_act ⊆ G_obj`，同一置信水平下 `ε_a ≤ ε_full`。若 `Φ_a` 在 `P_a` 上 `L_a`-Lipschitz，则
```
sup_{T'∈B_{ε_a}^{P_a}([T])} d_action(Φ_a(T),Φ_a(T')) ≤ L_a ε_a ≤ L_a ε_full
```
当估计误差在规范方向上有正质量时，第二个不等号严格成立。**含义：**动作商把“等价写法的差异”从误差预算里移除，因此在不牺牲 soundness 的前提下减少误拒；对象商则可能在动作敏感方向上过度合并，导致不安全。

**定理（Pose-Quotient Composition Soundness）**
承接第 54 轮 (A22)–(A28)，并假设：
- **(A29)** `Ĝ_act ⊆ G_act^true`（只可低估对称）；
- **(A30)** `P(d_{P_a}([T_true],H) ≤ ε_a) ≥ 1-α_p`（同对称类内保形）；
- **(A31)** `Φ_a` 在 `P_a` 上 `L_a`-Lipschitz；
- **(A32)** 解释阶段归因误差 ≤ `β_R`，回传延迟 ≤ `τ_loop`。

则
```
P(success) ≥ 1 - α_p - Σ_d(1 - ρ_min(d|ε_a)) - β_E
             - P(δ_a > Θ_a) - β_R - p_sym
```
其中 `p_sym = P(Ĝ_act ⊄ G_act^true)`，A29 下为 0。**高估对称会使 `p_sym>0` 且上界失效；因此对称群估计必须走保守子群，而不是最大似然。**

## 4. 玩具机制实验 E162（本轮已运行，非 benchmark）

**问题隔离：** 当估计器在物理对称上产生多峰（0 与 π 两种等价写法，外加危险的 π/2 错误模式），裸 SE(3) 证书、对象商证书、动作商证书各自的安全接受率如何？

**协议（`exp/pose_quotient_sim.py`，`exp/pose_quotient_results.json`）：**
- 圆柱 `R=0.05 m`；误差 `ξ=(δt∈R^3, δψ∈R)`；
- 动作：平行夹爪侧抓，成功条件 `||δt|| ≤ 0.015 m` 且 `δψ mod π ≤ 10°`；故 `G_obj=SO(2)`，`G_act={0,π}`；
- 三种度量：裸 `d_raw=sqrt(||δt||^2+(R·wrap_π δψ)^2)`；对象商 `d_obj=||δt||`；动作商 `d_act=sqrt(||δt||^2+(R·dist_π δψ)^2)`；
- 对每种度量取**最坏情况认证半径** `ε`（球内所有位姿都满足成功谓词）；对象商不存在正的安全半径，故用朴素平移半径 `ε=0.015` 作对照；
- 测试分布：yaw 模式 `0` 占 40%、`π` 占 40%、`π/2` 占 20%，各加 `σ=8°` 噪声；平移 `σ=0.004 m`；`N=200000`，`seed=20261111`。

| 证书 | `ε` (m) | 接受率 | 成功中误拒率 | 错误接受率 | 接受且成功率 | 净效用（失败罚 1） |
|---|---:|---:|---:|---:|---:|---:|
| 裸 SE(3) | 0.008125 | 17.35% | 72.38% | 0.00% | 17.35% | 17.35% |
| 对象商（朴素） | 0.015 | 99.72% | 0.00% | 36.89% | 62.82% | 25.93% |
| **动作商** | 0.008125 | **34.62%** | **44.89%** | **0.00%** | **34.62%** | **34.62%** |

测试集总体动作成功率为 62.82%。

**读法：**
1. 裸 SE(3) 证书 sound，但把 40% 的 `π` 等价解全部误拒，成功中误拒率 72.38%；这是“代表元依赖”付出的保守性税。
2. 对象商看似接受率 99.72%，但它把 `π/2` 危险模式也当成对称等价，错误接受率 36.89%；这不是免费收益，而是把失败静默推给下游。
3. 动作商只合并 `{0,π}`，拒绝 `π/2`，在不产生任何错误接受的前提下把安全接受率从 17.35% 提到 34.62%（约 2.0×），并把净效用从 17.35% 提到 34.62%。

**边界：** 这是机制检查，不是 BOP/真实机器人基准；它验证的是“商的选择必须由动作决定”这一结构性结论，而不是估计器精度。下一步 E162b 在 BOP 对称物体上重复，并加入真实抓取成功率。

## 7. 本轮最大风险

**一句话**：把位姿从裸 SE(3) 搬到动作相关对称商能同时减少误拒并堵住“对象级对称化”的不安全漏洞，但其 soundness 完全取决于对称群是否被**低估而非高估**、保形覆盖是否在同对称类内成立、以及解释归因是否真正因果；一旦把非对称误判为对称，商化会把物理上不同的位姿静默合并，系统将以零告警的方式执行错误动作，故必须以“对称群红队审计 + 保守子群 + 反事实解释门禁”为不可协商的三重前提。
