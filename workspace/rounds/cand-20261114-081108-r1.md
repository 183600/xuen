# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；本轮灵感：「语义建图」×「嵌入式系统」）

> R69 教会了系统「问」：看不清就看、拿不准就问、摸不透就触。但它问的是一轮之内的**动作模态**，并在暗处预支了两个假设：
> 1. **记忆上的开环**：不确定性是「当下这一次」的属性。问完、做完、这一轮结束，答案就丢了。下一小时回到同一个货架，它不会记得自己曾把「清洁剂」标成「饮料」，更不会记得那次标注只是猜的。R69 的 κ 个正交证据源只活在一个 episode 里，跨不过时间。
> 2. **算力上的免费**：K 条流采样 + Hutchinson 散度 + 冻结 LLM 解码全塞进 2.6ms，且默认跑在服务器或工控机上。真实具身系统经常是几百 MHz、512KB SRAM、电池供电、会掉电的板子；它面对的不是 P99，而是**最坏执行时间（WCET）**、焦耳与字节。
>
> 本轮两个灵感正好补上这两块：
> - **语义建图**说：不确定性有**地理和持久性**。它不只在「该走左还是右」里，也在「这个位置是什么、我从什么时候开始这么认为、是凭谁说的、现在还值不值得信」里。地图不是贴了标签的点云，而是一份**长期信念账本**。
> - **嵌入式系统**说：记忆与计算都是硬预算。压缩、量化、降级不是免费的——它们会**改变不确定性本身**；掉电、中断、写坏一页 flash，也都是必须被证明不会发生的失败模式。
>
> 核心命题：**把「不确定性」的载体从瞬态动作模态迁移到持久语义地图条目；每条目携带来源、租约与认知债务；在 WCET/能量/内存硬预算下按「单位焦耳的语义 VoI」偿还债务；压缩只准换内存，不准换置信；并用写前日志保证掉电不丢账。** 命名 **LEDGER-RAS**（Long-term Embedded semantic map with epistemic Debt, provenance Guard, Energy-aware Refresh）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我该在什么地方、花多少电、重新相信一次；以及这份记性本身，是不是正在骗我**」——不确定性不只是一脚刹车或一句提问，也可以是一页带来源、会过期、要还债的账。

## 0. 直觉与动机

**灵感 1（语义建图 → 记忆是长期的不确定性载体，而遗忘是一种资源）**
直觉：R69 把「不确定」当成当前动作分布的属性，做完就清零。但真正昂贵的错误往往是**记忆性**的：机器人把「湿滑」标成「干燥」，此后每次路过都用同一套步态；把「出口」标在一个已经改装的门口，此后整晚都在撞墙。语义地图把这些信念**外化、持久化、可查询**，于是不确定性第一次有了地址、年龄和责任人。关键翻转是：**我们不再问「我现在多确定」，而问「这条记忆还配得上它的置信度吗」**。遗忘不是失败，而是把有限的验证预算从低价值条目上收回。

**灵感 2（语义回音室 → 地图会用自己的错误喂养自己）**
直觉：语义地图一旦参与感知先验，就形成闭环：地图说「这里是杯子」→ 分割器更愿意把那个白影切成杯子 → 回写地图→ 下次更确信。R69 用「k 个正交证据源一致」防投毒，可它默认证据彼此独立；**地图自己的历史写入被当成了新证据**。这不是简单的漂移，而是一个正反馈：置信度单调上涨，真实错误率却不动。因此必须把**来源图（provenance）**变成一等公民：地图的历史账不能给自己作证，有效独立源数 κ_eff 必须扣除共享上游。回音室增益 G_echo ≥ 1 时，系统必须**强制外部验证或降级**——这正是「记忆的证据纪律」。

**灵感 3（嵌入式系统 → VoI 要按焦耳计价，实时性要按 WCET 证明）**
直觉：服务器上可以「不确定就多采样」，板子上不行。每一次多采样、每一次回访、每一次问人，都要花毫秒、焦耳与 flash 擦写寿命。于是 R69 的 VoI−成本要升级为 **VoI/焦耳**，并且预算不是平均值而是**确定性上界**：每个阶段的 WCET 必须可加、可调度；一旦剩余时间不够下一阶段，就在**当前时刻**降级，而不是赌「这次应该不会超」。这把实时性从「P99 < 2.6ms」的统计承诺，改成「任何一轮都不超 D」的工程承诺。

**灵感 4（压缩不敢置信 → 量化误差必须进入不确定性，而不是被吞掉）**
直觉：嵌入式第一反应是 int8/int4、稀疏化、分层 LOD。但压缩会改变后验：一个被量化成「0.99 是杯子」的条目，真实可能是 0.8。若下游风险证书仍按 0.99 计算，压缩就**凭空制造了置信**——它省下的是字节，花掉的是安全裕度。正确做法是把量化误差 ε_q 保守地卷积进后验（ℓ̃ = ℓ ⊛ 𝒩(0, ε_q²)），并让证书显式记录 ε_q。**压缩只能买内存，不能买信心**；在固定内存下，要么多还债（更多重访），要么多保守（更大 λ）。

**灵感 5（掉电与投毒 → 账本必须原子，合并必须保守）**
直觉：嵌入式会掉电，而且往往正好在写 flash 时。若一次掉电把「来源 + 债务」写坏一半，系统恢复后可能保留了一个「看起来已验证、其实没有来源」的标签——这比忘记更危险，因为它**记得错且记得理直气壮**。因此地图写入必须走写前日志（WAL + CRC + 单调序号），恢复后状态只能取「旧」或「新」，且债务只能增不能凭空清零。多机/多轮合并同理：标签冲突时不要多数投票覆盖，而要**记账、抬债、触发独立验证**；低质量来源永远不能静默改写高质量来源。这就是 LEDGER 的威胁模型：不是「记不住」，而是「记得太牢、记得太顺、记得没有出处」。

## 1. 形式化定义（增量：定义 310–322）

**定义 310（LEDGER-RAS 总览与三不变式）** LEDGER-RAS = (SML, PDE, EDS, CQM, WAM, SEA, FLUID†, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；地图只做有界读写，不在控制回路里训练）；
(ii) **资源硬约束**：每个阶段有 WCET 上界，单轮总时长 ≤ D（是确定性上界，不是 P99）；能量 ≤ E_max；SRAM/flash ≤ M_max；任一级超界必须**在当前时刻降级**到预算内的认证层级，禁止「偶尔超时」；
(iii) **记忆证据纪律**：地图条目自身历史不计入独立证据；参与高风险决策的条目需 κ_eff ≥ 2 个去相关来源，否则记入 epistemic debt 且不得单独定案。

**定义 311（语义地图账本 SML）** 地图 M = {e_i}，条目 e_i = (x_i 位置/区域, ℓ_i ∈ Δ(𝒴) 语义后验, t_i^ver 最近独立验证时刻, P_i 来源 DAG, τ_i 租约, d_i ≥ 0 认知债务, r_i 风险权重)。写操作只有 upsert / verify / merge / expire / mark，每次写先入 WAL（定义 318）。**读出返回三元组 (ℓ̃_i, d_i, s_i)，而不是单个标签**；地图不是事实库，是带年龄和出处的信念账本。

**定义 312（来源图与有效独立性 PDE）** 来源图 P_i = (V_i, E_i)：叶节点为观测源（相机帧、力序列、人类回答、其他机器人、**地图自身的历史写入**）。两来源 a,b 的共享相关 ρ(a,b) 由共享上游、共享标定/模型、共享人类标注者决定，有效独立度 ι(a,b) = 1 − ρ(a,b)。有效独立源数
κ_eff(e_i) = max{|S| : S ⊆ V_i∖{map_self}, ∀a≠b∈S, ι(a,b) ≥ ι_min}。
**地图自身的历史写入永远被排除**；若唯一下游证据来自回写，则 κ_eff = 0。κ_eff 用贪心近似（O(|V|²)，|V| ≤ 8）。

**定义 313（语义陈旧与认知债务 EDS）** 陈旧度 s_i(t) = 1 − exp(−(t − t_i^ver)/τ_i)。一条信念被用于决策却未被独立验证时，债务累积
d_i ← γ·d_i + r_i·s_i·Δt, γ < 1；
债务有硬上限 D_max，超限条目进入「不可信集合」𝒰，禁止参与高风险动作。**偿还债务的唯一方式是独立验证**（重访、换视角、问人、派侦察体），验证事件清零 d_i 并刷新 t_i^ver。系：在固定能量下，最优刷新顺序是按「债务增速 × 风险权重 / 刷新成本」排序，而不是按时间轮询。

**定义 314（语义回音室增益 SEA）** 设地图先验到感知条件、再到回写后验的雅可比为 J_i。回音增益 G_echo(i) = ρ(P_i) · ρ_spec(J_i)，其中 ρ_spec 为谱半径，ρ(P_i) 为来源共享相关。若 G_echo ≥ 1 − ε 则判定为**非收缩反馈**：置信度会自我强化而误差不衰减。触发动作：强制外部验证、或把条目置为不可信、或降级到 Tier≥2。**高置信 + 低来源多样性 = 回音室/投毒的可判别特征。**

**定义 315（认证量化地图 CQM）** 量化/稀疏化算子 Q 的逐条目误差界 ‖Q(ℓ_i) − ℓ_i‖ ≤ ε_q（由定点位宽、层级分辨率与稀疏阈值给出）。读出必须使用膨胀后验
ℓ̃_i = ℓ_i ⊛ 𝒩(0, ε_q²)（保守卷积），且证书显式记录 ε_q。若 ε_q 未传播，证书作废。**压缩只能换内存，不能换置信**：固定 M_max 下，ε_q 增大必须由更多刷新或更大 λ 补偿。

**定义 316（预算化语义 VoI，EDS 选择器）** 候选刷新动作 g ∈ 𝒜_refresh（重访视角、重观测、问人、派侦察、标 stale）。语义 VoI(g) = H(ℓ_i|M) − E_{y~p(·|g,M)}[H(ℓ_i|M,y)]。单位能量收益
VoI_E(g) = VoI(g) / (E(g) + λ_D·WCET(g))。
选择 g* = argmax_g VoI_E(g)，s.t. WCET 可调度、E 未越界、g 通过 C-RAS-WM 认证（继承 R69 定义 302）。若 max VoI_E ≤ 0：不刷新，按定义 313 记债。

**定义 317（认证降级层级）** Tier 0：FLUID 全量（K=4、FMP、FMA）；Tier 1：K=1、去 FMA、蒸馏策略；Tier 2：仅地图查询 + 表驱动安全策略；Tier 3：安全停/请求人类。层级由剩余 WCET 与能量余量**确定性**选择，且安全动作集单调：𝒮_{Tier k+1} ⊆ 𝒮_{Tier k}。任何时刻若下一阶段 WCET 预估 > 余量，立即降级，绝不先执行再判断。

**定义 318（写前日志与掉电原子性 WAM）** 每个地图写操作先追加到掉电持久 WAL（CRC + 单调序号 + 条目哈希），再原子提交主地图。掉电恢复后地图状态 ∈ {旧, 新}，绝不出现半写条目；**债务 d_i 与来源 P_i 与标签同日志化**，恢复后不丢账、不凭空清零。WAL 空间满时按「已提交最高序号」压实，压实过程本身原子。

**定义 319（保守多源合并 CMM）** 同一条目来自多机/多轮的标签冲突：不采用多数投票覆盖，而按来源质量加权并**记账抬债**。若两来源 κ_eff ≥ 2 且标签冲突，条目置为「多模态/冲突」，抬高 d_i 与 r_i，强制触发一次独立验证；只有独立验证可消解冲突。**低质量来源永远不得静默覆盖高质量来源**（防共谋与 Sybil 污染）。

**定义 320（地图原生信息动作 ASR）** R69 的 (g_gaze, g_probe, g_ask) 在空间记忆上升格为 (revisit(x_i,θ), reobserve(x_i), ask_human(x_i), scout(x_j))；这些动作的返回值不是标签，而是**带 provenance 的验证记录**，同时写地图与更新来源图。R69 的「看—问—做」成为 ASR 在单 episode 内的特例。

**定义 321（语义-物理对偶异常）** 除 r_res（R68）与 Δa（R69）外增加语义通道：a_sem = −log p(观测 | ℓ_i, x_i)，地图自洽度 C_map = 条目间标签一致性。**过度平滑/过度自洽的地图本身可疑**：C_map 异常高 ∧ 来源多样性低 ⇒ 语义投毒或回音室固化。三通道构成 (r_res, Δa, a_sem) 联合判据：物理漂移、行为异常、语义污染各有其指纹。

**定义 322（证书 J_LEDGER）** J_LEDGER = (J_FLUID, wcet_slack, energy_used, κ_eff_min, debt_total, echo_gain_p95, ε_q, map_commit_seq, ledger_ver)。Valid ⇔ Valid(J_FLUID) ∧ WCET 可调度 ∧ 能量未越界 ∧ debt_total ≤ D_max ∧ 所有参与高风险决策的条目 κ_eff ≥ 2 ∧ 压缩误差已传播 ∧ 掉电恢复一致。

## 2. 关键算法骨架

```python
# IP-264 SML：语义地图账本（条目带来源、租约、债务；读出返回信念三元组）
class SemanticLedger:
    def __init__(self, cap_kb, tau, D_max):
        self.cells = SparseHierarchy(cap_kb)          # int8 量化，见 CQM
        self.tau, self.D_max = tau, D_max

    def read(self, x):
        e = self.cells.query(x)                       # O(log N)
        if e is None: return None
        s = 1.0 - exp(-(now() - e.t_ver) / e.tau)     # 陈旧度
        l = inflate(e.l, e.eps_q)                     # 压缩误差必须传播
        return Belief(l, e.debt, s, e.prov)

# IP-265 PDE：来源图去相关，地图自身历史不算证据
def kappa_eff(entry):
    srcs = [v for v in entry.prov.leaves() if v is not MAP_SELF]
    S = []
    for a in sorted(srcs, key=quality, reverse=True):
        if all(1.0 - shared_corr(a, b) >= IOTA_MIN for b in S):
            S.append(a)                               # 贪心最大独立集近似
    return len(S)

# IP-266/270 EDS+ASR：按单位焦耳语义 VoI 刷新，偿还债务
def schedule_refresh(entry, budget):
    best = None
    for g in asr_candidates(entry):                   # revisit/reobserve/ask/scout
        if not c_ras_wm.certify_info(g):              continue
        if wcet(g) > budget.slack:                    continue
        voi = entropy(entry.l) - expected_entropy(entry.l, g)
        score = voi / (energy(g) + LAM_D * wcet(g))
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None  # 无利可图 → 记债

# IP-269 SEA：回音室增益（来源相关 × 先验→后验谱半径）
def echo_gain(entry, perception_jacobian):
    return source_corr(entry.prov) * spectral_radius(perception_jacobian)

# IP-268 WAM：写前日志 + 原子提交 + 掉电恢复
def commit(ledger, entry):
    wal.append(crc(entry) + seq() + entry)            # 先落日志
    ledger.apply(entry)                               # 再改主地图
    wal.checkpoint_if_needed()                        # 原子压实

# IP-274 主闭环（继承 R69，插入「预算→账本→刷新→降级」）
def LEDGER_RAS_round(M, obs):
    # 0) 先按剩余预算定层级，绝不先跑再超时
    tier = M.eds.choose_tier(M.wcet.slack_d, M.energy.left)
    # 1) 读账本，而不是把原始观测当事实
    e = M.sml.read(obs.pose)
    if e is None:
        e = M.sml.upsert(obs.pose, obs.semantic, prov={obs.src})
    # 2) 记忆证据纪律：回音室 + 有效独立源
    echo  = M.sea.echo_gain(e, M.perception.jacobian)
    k_eff = M.pde.kappa_eff(e)
    if echo >= 1.0 - EPS or k_eff < 2:
        e.debt = min(M.sml.D_max, e.debt + e.r * e.staleness * DT)
    # 3) 预算内刷新（单位焦耳语义 VoI）
    g = M.eds.schedule_refresh(e, M.budget) if tier <= 1 else None
    if g is not None:
        y = M.asr.execute(g)                          # 重访/重观测/问人/派侦察
        M.sml.verify(e, y, source=g.src)              # 写验证事件 + provenance
        e.debt = 0.0
    # 4) 只有可信条目才允许塑造动作；否则保守/降级
    trusted = (e.debt <= M.sml.D_max and k_eff >= 2 and echo < 1.0)
    if tier == 0 and trusted:
        k, lam, mode, U = FLUID_RAS_round(M, obs)     # R69 原样
    elif tier == 2:
        k, lam, mode, U = M.table_policy(obs, e)      # 表驱动、可认证
    else:
        k, lam, mode, U = M.safe_stop(obs)            # 安全停/请求人类
    # 5) 原子提交 + 证书
    M.wam.commit(M.sml.snapshot(e))
    return k, lam, mode, M.cert.issue(e, tier, echo, k_eff)
```

## 3. 推导

**引理 19（记忆自确认的误差不衰减）** 设条目误差 e_k，回写先验权重 β、新鲜独立证据权重 α。若把地图自身历史算作证据，则有效更新 e_{k+1} = (β/α)·e_k + ρ·e_k + ξ_k；当 (β/α + ρ) ≥ 1 时 E|e_k| ≥ |e_0|，**误差不收缩，但报告置信度单调趋于 1**。若每轮以概率 μ 注入独立验证（权重 α_audit），收缩因子 λ(μ) = (1−μ)(β/α+ρ) + μ·λ_audit < 1 ⇔ μ > (β/α+ρ−1)/(β/α+ρ−λ_audit)。系：**刷新预算必须至少覆盖债务增速**，否则系统会「越用越自信」而不是「越用越准」——这正是回音室的可测定义。

**引理 20（压缩不敢置信）** 设量化误差 ‖Q(ℓ)−ℓ‖ ≤ ε_q，下游损失对后验是 L_q-Lipschitz。若把 Q(ℓ) 当精确值，则基于 ℓ 的认证风险界被低估至少 L_q·ε_q；改用膨胀后验 ℓ̃ = ℓ ⊛ 𝒩(0, ε_q²) 可恢复原界。系：固定内存 M_max 下，ε_q↑ ⇒ 要么刷新率↑、要么 λ↑；**压缩不是免费的，它把内存债转成认知债**。

**定理 18（LEDGER 严格包含 R69）** 在「零陈旧（所有条目刚验证）+ 无限预算 + κ_eff ≥ 2 + ε_q = 0」边界上，地图读出退化为当前观测，LEDGER 逐指令等价于 R69 FLUID。预算有限时，LEDGER 通过认证层级选择安全动作的子集，故任意状态期望风险 ≤ R69；当刷新预算耗尽或回音室告警时，退化为 R68/R69 的纯保守边界。**安全侧不让步，长期侧用「记忆」换「重复观测」。**

**引理 21（掉电原子性与债务不灭）** WAL 采用 CRC + 单调序号 + 原子提交，则掉电恢复后地图状态 ∈ {S_old, S_new}，不存在「标签已提交、来源/债务未提交」的半条目；且债务 d_i 跨掉电单调不减（除非有已日志化的验证事件）。系：**掉电不能抹掉认知债务**——这保证了系统重启后仍然「记得自己哪里没验证」，而不是把不确定重启成确定。

**定理 19（WCET 可调度与降级安全）** 若各层级 WCET 上界满足 W_0 ≤ D 且 W_{k+1} < W_k，则在每轮开始前按余量选层可保证零 deadline miss（确定性，而非统计），且安全动作集随层级单调收缩 ⇒ 控制连续、无安全回退。对比：R69 的 P99 < 2.6ms 在带中断、cache 抖动与 flash 写入的 MCU 上不是上界，LEDGER 用 WCET 把它变成可证明的工程约束。

## 6. 本轮最大风险

**一句话**：LEDGER-RAS 的全部长期收益押在「来源账本是完整且不可伪造的」这一前提上——一旦来源被截断（固件日志容量有限）、被量化（来源 ID 哈希碰撞）或被伪造（对手污染某个人类标注源/Sybil 节点），系统就会把同一份错误反复记账成多个「独立」证据，回音室告警与债务调度同时失灵，**它不是忘不掉，而是坚信自己记得对**。

**次级风险与缓解**：
1. **provenance 图本身超预算**（PDE 的 O(|V|²) 在中断密集时抖动）→ 来源数硬上限 |V|≤8 + 增量贪心 + WCET 预算内截断；

# IP-264 SML：语义地图账本（条目带来源、租约、债务）
class SemanticLedger:
    def read(self, x):
        e = self.cells.query(x)                       # O(log N)
        s = 1.0 - exp(-(now() - e.t_ver) / e.tau)     # 陈旧度
        return Belief(inflate(e.l, e.eps_q), e.debt, s, e.prov)

# IP-265 PDE：来源图去相关，地图自身历史不算证据
def kappa_eff(entry):
    srcs = [v for v in entry.prov.leaves() if v is not MAP_SELF]
    S = []
    for a in sorted(srcs, key=quality, reverse=True):
        if all(1.0 - shared_corr(a, b) >= IOTA_MIN for b in S):
            S.append(a)                               # 贪心最大独立集近似
    return len(S)

# IP-266/270 EDS+ASR：按单位焦耳语义 VoI 刷新，偿还债务
def schedule_refresh(entry, budget):
    best = None
    for g in asr_candidates(entry):                   # revisit/reobserve/ask/scout
        if not c_ras_wm.certify_info(g) or wcet(g) > budget.slack: continue
        voi   = entropy(entry.l) - expected_entropy(entry.l, g)
        score = voi / (energy(g) + LAM_D * wcet(g))
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None  # 无利可图 → 记债

# IP-269 SEA：回音室增益（来源相关 × 先验→后验谱半径）
def echo_gain(entry, perception_jacobian):
    return source_corr(entry.prov) * spectral_radius(perception_jacobian)

# IP-268 WAM：写前日志 + 原子提交
def commit(ledger, entry):
    wal.append(crc(entry) + seq() + entry)            # 先落日志
    ledger.apply(entry)                               # 再改主地图
    wal.checkpoint_if_needed()                        # 原子压实

# IP-274 主闭环（继承 R69，插入「预算→账本→刷新→降级」）
def LEDGER_RAS_round(M, obs):
    tier = M.eds.choose_tier(M.wcet.slack_d, M.energy.left)   # 先定层
    e = M.sml.read(obs.pose) or M.sml.upsert(obs.pose, obs.semantic, {obs.src})

    k_eff = M.pde.kappa_eff(e)
    if echo >= 1.0 - EPS or k_eff < 2:

    g = M.eds.schedule_refresh(e, M.budget) if tier <= 1 else None
    if g is not None:

    trusted = (e.debt <= M.sml.D_max and k_eff >= 2 and echo < 1.0)
    if tier == 0 and trusted:
        k, lam, mode, U = FLUID_RAS_round(M, obs)     # R69 原样
    elif tier == 2:
        k, lam, mode, U = M.table_policy(obs, e)
    else:
        k, lam, mode, U = M.safe_stop(obs)
    M.wam.commit(M.sml.snapshot(e))
    return k, lam, mode, M.cert.issue(e, tier, echo, k_eff)

## 4. 推导

**引理 19（记忆自确认的误差不衰减）** 若回写先验被算作证据，`e_{k+1}=(β/α+ρ)e_k+ξ_k`；当 `β/α+ρ ≥ 1` 时误差不收缩而报告置信度趋于 1。以概率 μ 注入独立验证后 `λ(μ)=(1−μ)(β/α+ρ)+μλ_audit<1 ⇔ μ>(β/α+ρ−1)/(β/α+ρ−λ_audit)`。系：**刷新预算必须覆盖债务增速**——这是回音室的可测定义，也是 EDS 存在的理由。

**引理 20（压缩不敢置信）** 量化误差 `ε_q`、损失 `L_q`-Lipschitz 时，不膨胀会低估风险界至少 `L_q·ε_q`；膨胀后验可恢复。系：固定内存下 `ε_q↑ ⇒ 刷新率↑ 或 λ↑`；压缩把内存债转成认知债，不是免费午餐。

**定理 18（LEDGER 严格包含 R69）** 零陈旧 + 无限预算 + `κ_eff≥2` + `ε_q=0` 时逐指令等价 R69；预算有限时经认证层级取安全动作子集，任意状态期望风险 ≤ R69；刷新耗尽/回音室告警时退化为 R68/R69 纯保守边界。安全侧不让步，长期侧用记忆换重复观测。

**引理 21（掉电原子性与债务不灭）** WAL（CRC + 单调序号 + 原子提交）下，恢复态 ∈ {旧,新}，无「标签已提交而来源/债务未提交」的半条目；债务跨掉电单调不减（除非有已日志化验证）。系：**掉电不能把不确定重启成确定**。

**定理 19（WCET 可调度与降级安全）** 若 `W_0≤D` 且 `W_{k+1}<W_k`，每轮开始前按余量选层可保证零 deadline miss（确定性），安全动作集随层级单调收缩 ⇒ 控制连续、无安全回退。对比 R69 的 P99：在带中断/cache 抖动/flash 写的 MCU 上 P99 不是上界，WCET 才是。

## 7. 本轮最大风险

**一句话**：LEDGER-RAS 的全部长期收益押在「来源账本完整且不可伪造」这一前提上——一旦来源被截断（固件日志容量有限）、被量化（来源 ID 哈希碰撞）或被伪造（对手污染某个人类标注源/Sybil 节点），系统就会把同一份错误反复记账成多个「独立」证据，回音室告警与债务调度同时失灵，**它不是忘不掉，而是坚信自己记得对**。

**次级风险与缓解**：provenance 图超预算（|V|≤8 + 增量贪心 + WCET 截断）；WAL 耗尽 flash 寿命（批量提交 + 磨损均衡 + 原子压实，E306）；量化导致假独立（充足来源 ID 空间 + 碰撞进债务，E304/E307）；地图投毒/共谋（CMM 保守合并 + (C_map,a_sem) 对偶 + 𝒰 隔离，E308）；降级掩盖能力退化（J_LEDGER 记录层级占比与 wcet_slack，审计不可静默）。
