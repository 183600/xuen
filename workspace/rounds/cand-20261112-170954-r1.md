# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 1 轮；本轮灵感：「技术路线图」×「跌倒恢复」）

> 第 60 轮把「执行层→证据层」闭环升级为「认知驱动的场景-执行闭环」：SSM 让场景成为阻抗先验、CIEC 让意图锁定实时约束、EPIR 防止 ROS 消息丢失、SERC 统一闭环、PCE++++ 引入认知预算。但**跌倒恢复**这一极限工况同时击穿了它的三条隐含假设：
> 1. **场景语义是准静态的**：SSM 的 Kalman 后验需要若干观测周期才收敛，而跌倒是一个 <500ms 的非平稳相位跃变；等「场景」被识别出来，机器人已经落地。场景层在跌倒时域内**失效**。
> 2. **认知意图是「人来得及下达」的**：CIEC 的 τ_response≈2s 依赖人类在环，但跌倒的物理时域远小于人的反应时延；「认知先行」在跌倒场景反转为「认知来不及」，意图层**失效**。
> 3. **证据源是存活的**：EPIR 只防消息丢失，不防节点因冲击掉电/重启；影子副本本身可能随边端节点一起消失；而「证据必须在冲击前落盘」这一时序要求，第 60 轮的 EPIR 从未考虑。证据层**失效**。

> 本轮用一个新组织原则同时回答三者：把**技术路线图**从「规划文档」改造成**运行时能力回退阶梯**——能力按成熟度分层、按证据门控升阶，灾难来临时不是调用「最强能力」，而是**下撤到当前证据下最可信的能力**。再以**跌倒相位机**把恢复分解为可证据化的相位序列，用**恢复证据哈希链**保证证据在节点重启后仍可验证。

## 0. 直觉与动机

**灵感 1（技术路线图 → 能力路线图图 CRG）**
直觉：技术路线图不是甘特图，而是一张**带证据门的前置依赖 DAG**。跌倒恢复能力天然分层：护头屈膝（保护性跌倒）→ 冲击吸收 → 自主起身 → 任务恢复。你不可能在没有认证「保护性跌倒」之前就认证「自主起身」——每一层都是下一层的物理前提。把每项能力 c 的成熟度 μ(c) ∈ {0,1,2,3,4}（未验证/仿真/实验室/现场/认证），**升阶必须提交证据包 E_c**，且证据包有有效期与失效条件。关键洞见：**路线图的边不是时间，而是证据依赖；路线图的节点状态不是完成度，而是「可被信任的成熟度」。**

**灵感 2（跌倒恢复 → 跌倒相位机 FPM）**
直觉：跌倒不是单一状态，而是 `STABLE→STUMBLE→FALLING→IMPACT→REST→SELF_RIGHT→RESUMED` 的相位跃迁；每个相位对应不同的阻抗日程 κ_t：FALLING 要「低刚度高阻尼」吸收动能，IMPACT 要「力矩限幅」保护关节与结构，SELF_RIGHT 要「高刚度」撑起，SAFE_HOLD 要「最大柔顺」防止二次伤害。关键洞见：**相位转移条件绝不能依赖 SSM 的场景后验（太慢），必须依赖瞬时物理量——捕获度 ξ_cap、支撑多边形余量 m_sup、接触冲量 J_c、质心速度 v_com、姿态角 θ。即「物理证据先于语义」。**

**灵感 3（合流 → 路线图门控的恢复回退 DESCEND）**
直觉：灾难时刻的正确策略不是「能力最大化」，而是「成熟度最大化」。DESCEND：在 CRG 上取**前置闭包已认证、证书在有效期内、与当前相位兼容、且恢复预算足够**的极大能力节点。这把技术路线图从「事前规划」变成**运行时安全回退阶梯**：系统永远知道自己「现在最该信任哪一层」。关键洞见：**降级不是失败，降级是沿着路线图有证据地下降。**

**灵感 4（证据链 → 恢复证据证明 REP）**
直觉：跌倒证据与常规执行证据不同：它必须能在「传感器撞坏、节点重启」后仍可验证。REP 采用**相位级分段哈希链**：每个相位入口先落盘 e_i 的头部（anticipatory persistence），相位结束再封装 outcome 并链接 `h_i = H(e_i‖h_{i-1})`。节点重启后从最后已封装 hash 续链。关键洞见：**证据要在冲击前就落盘，因为冲击后可能根本写不进去。**

**灵感 5（预算 → 路线图预算 B_road 与 PCE+++++）**
直觉：认证、恢复、下撤都要花预算。B_road = (B_cert, B_recover, B_descent)，其中 **B_descent 必须是 O(1) 可判定**（跌倒时没有时间做在线规划）。若 B_descent 不足 → 立即执行静态「护头屈膝」；若 B_recover 不足 → 进 SAFE_HOLD；若 B_cert 不足 → 只允许 μ≤2 的能力参与下撤。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（能力路线图图 CRG）** CRG = (C, E_pre, μ, G_ev, Π)。其中：
- **能力节点集** C = {c₁,…,c_K}，每个节点含名称、相位兼容集、执行代价、失效条件；
- **前置依赖边** E_pre ⊆ C×C，构成 DAG；Cl(c) = {c′ | c′ →* c} 为其前置闭包；
- **成熟度函数** μ：C → {0,1,2,3,4}，分别表示未验证/仿真/实验室/现场/认证；
- **证据门** G_ev：C → {0,1}，G_ev(c)=1 当且仅当证书 J_road(c) 存在、签名有效、未过期、无失效条件被触发；
- **路线图计划** Π：在 DAG 上带预算的调度，Π 决定「下一张该补哪张证据」。
可用能力集合 A = {c ∈ C | G_ev(c)=1 ∧ Cl(c) ⊆ A ∧ μ(c) ≥ μ_min}。

**定义 162（成熟度证书 J_road）** J_road(c) = (μ(c), E_c, T_valid, I_invalidate, σ_c)。其中：
- **证据包** E_c = {试验记录、覆盖的相位集、硬件版本、场景分布、复现脚本哈希}；
- **有效期** T_valid 为证据被视为可信的时间窗；
- **失效条件** I_invalidate 为谓词集合（如硬件更换、固件升级、场景分布漂移超过 KL 阈值）；
- **签名** σ_c 防止证据被篡改。
证书偏序：c ⪯ c′ 当且仅当 μ(c) ≤ μ(c′) 且 Cl(c) ⊆ Cl(c′)。DESCEND 只在偏序的「极大可信节点」中选。

**定义 163（跌倒相位机 FPM）** FPM = (Q, q₀, δ, κ_t, O)。其中：
- **相位集** Q = {STABLE, STUMBLE, FALLING, IMPACT, REST, SELF_RIGHT, RESUMED, SAFE_HOLD}；
- **转移函数** δ：Q × O → Q，观测 O = (ξ_cap, m_sup, J_c, v_com, θ, τ_support)；
- **捕获度** ξ_cap(x) = min_{u∈U_rec} T_capture(x,u)，即最短可捕获时间；若 ξ_cap > τ_fall 则判为不可恢复，直接进入 SAFE_HOLD；
- **相位阻抗日程** κ_t：Q → K_phase = (K_p, K_d, F_max, τ_lim, v_max)；
- 典型转移：`STABLE→STUMBLE` 当 ξ_cap<ξ₁ 或 m_sup<0；`STUMBLE→FALLING` 当 ξ_cap>τ_fall 且 v_com 未收敛；`FALLING→IMPACT` 当 J_c>J_th；`IMPACT→REST` 当 ‖v_com‖<ε_v；`REST→SELF_RIGHT` 当 ξ_cap≥ξ₂；`*→SAFE_HOLD` 当检测到不可恢复或证据预算不足。

**定义 164（路线图门控恢复回退 DESCEND）** 给定相位 q、可用集 A、预算 B_road：
```
c* = argmax_{c ∈ A} [ μ(c) − λ·D_cert(c) ]
     s.t. Cl(c) ⊆ A
          ∧ J_road(c) 可信
          ∧ compat(q, c)            # 能力 c 覆盖当前相位
          ∧ cost(c) ≤ B_recover
若不存在可行 c*：c* = c_safe（静态护头屈膝），q ← SAFE_HOLD
```
`compat(q,c)` 表示 c 的相位覆盖集包含 q；`D_cert(c)` 为认证债务（定义 167）。关键性质：**DESCEND 的选择是「成熟度最高且证据闭合」，而不是「性能最强」。**

**定义 165（恢复证据证明 REP）** REP 为相位级哈希链 `e₁ → e₂ → … → eₙ`：
- e_i = (phase_i, t_i^s, t_i^e, J_c^i, policy_i, outcome_i, h_{i−1}, h_i)，h_i = H(e_i ‖ h_{i−1})；
- **预落盘（anticipatory persistence）**：相位入口先写 e_i 的头部（phase、policy、t^s、h_{i−1}）到非易失影子区，**再**执行相位动作；相位结束再封装 outcome 成 h_i；
- **重启续链**：节点重启从最后已封装的 h_i 继续，未封装相位标记为「未完成证据」而不伪造；
- **完整性**：链必须覆盖从触发到 RESUMED/SAFE_HOLD 的全部相位，任何缺口即为证据链断裂。

**定义 166（路线图预算 B_road 与 PCE+++++）** B_road = (B_cert, B_recover, B_descent)。
```
voi_road(π) = VOI_meta_pessimistic(π) − cost_cog(π) − cost_exec(π) − cost_road(π)
cost_road = λ_cert·Cert_cost + λ_rec·Recovery_cost + λ_desc·Descent_cost
```
降级规则：B_descent<θ_d ⇒ 静态安全策略；B_recover<θ_r ⇒ SAFE_HOLD；B_cert<θ_c ⇒ 下撤仅允许 μ≤2；B_cog 各维耗尽沿用第 60 轮规则。**B_descent 必须在进入跌落后一个控制周期内完成判定。**

**定义 167（认证债务与恢复就绪度）**
- D_cert(System) = Σ_{c∈C_used} w(c)·max(0, μ_target(c) − μ(c))，w(c) 为能力使用频次权重；
- R_ready = 1 − D_cert / D_max，R_ready < θ_ready 时禁止进入高风险任务；
- D_cert 是「系统实际依赖的成熟度」与「已认证成熟度」之间的缺口，是路线图变成运行时护栏的核心可观测指标。

**定义 168（FRAME 路线图驱动恢复闭环）** 算子 FRAME(M, task)：
```
① CRG.ingest(M.rep_log)                         # 证据回灌、刷新 G_ev
② q ← FPM.tick(telemetry)                       # O(1)，物理量触发
③ if q == STABLE: 复用第 60 轮 SERC 正常闭环
④ else:
     c* ← DESCEND(q, A, B_road)                  # 预计算闭包，O(1)~O(log|C|)
     K_phase ← κ_t(q, c*)
     REP.precommit(q, c*)
     execute_recovery(c*, K_phase)
     REP.seal(q, outcome)
     CRG.observe(c*, outcome) → 可能上调/下调 μ(c*)
⑤ J_road ← issue_maturity_certificate(CRG, REP)
⑥ Return (q, c*, K_phase, J_road, REP, D_cert)
```

## 2. 关键算法伪代码

### IP-161/162 CRG 与成熟度证书

```python
class CapabilityRoadmapGraph:
    def __init__(self):
        self.nodes, self.pre, self.certs = {}, {}, {}
        self.closure, self.mu, self.cost = {}, {}, {}
        self.phase_cover, self.invalidate = {}, {}

    def add(self, cid, prereqs, cost, phase_cover, invalidate=()):
        self.nodes[cid] = cid
        self.pre[cid] = set(prereqs)
        self.cost[cid] = cost
        self.phase_cover[cid] = set(phase_cover)
        self.invalidate[cid] = list(invalidate)
        self.mu.setdefault(cid, 0)

    def compute_closure(self):
        order = self._topo_sort()                    # O(|C|+|E|)
        for c in order:
            cl = set(self.pre[c])
            for p in self.pre[c]:
                cl |= self.closure[p]
            self.closure[c] = cl

    def is_trusted(self, cid, now, mu_min=2):
        J = self.certs.get(cid)
        if J is None or not J.verify_sig() or now > J.valid_until:
            return False
        if J.mu < mu_min:
            return False
        return not any(inv() for inv in self.invalidate[cid])

    def available(self, now, mu_min=2):
        A = set()
        changed = True
        while changed:                               # 闭包不动点
            changed = False
            for c in self.nodes:
                if c in A:
                    continue
                if self.is_trusted(c, now, mu_min) and self.pre[c] <= A:
                    A.add(c); changed = True
        return A
```

### IP-163 跌倒相位机

```python
class FallPhaseMachine:
    Q = ['STABLE','STUMBLE','FALLING','IMPACT','REST','SELF_RIGHT','RESUMED','SAFE_HOLD']

    def __init__(self, xi1=0.3, xi2=0.6, J_th=12.0, tau_fall=0.25, eps_v=0.05):
        self.q, self.xi1, self.xi2 = 'STABLE', xi1, xi2
        self.J_th, self.tau_fall, self.eps_v = J_th, tau_fall, eps_v

    def capturability(self, obs):
        return min(self._t_capture(obs, u) for u in obs.recovery_actions)

    def tick(self, obs):
        xi = self.capturability(obs)
        if xi > self.tau_fall and self.q in ('STABLE','STUMBLE','FALLING'):
            self.q = 'SAFE_HOLD'
            return self.q
        if self.q == 'STABLE':
            self.q = 'STUMBLE' if (xi < self.xi1 or obs.m_sup < 0) else 'STABLE'
        elif self.q == 'STUMBLE':
            self.q = 'FALLING' if obs.v_com > obs.v_th else self.q
        elif self.q == 'FALLING':
            self.q = 'IMPACT' if obs.J_c > self.J_th else self.q
        elif self.q == 'IMPACT':
            self.q = 'REST' if obs.v_com_norm < self.eps_v else self.q
        elif self.q == 'REST':
            self.q = 'SELF_RIGHT' if xi >= self.xi2 else 'SAFE_HOLD'
        elif self.q == 'SELF_RIGHT':
            self.q = 'RESUMED' if obs.upright else self.q
        return self.q

    def impedance_schedule(self, q):
        return {
          'STABLE':      dict(K_p=1.0, K_d=1.0, F_max=1.0, tau_lim=1.0),
          'STUMBLE':     dict(K_p=1.3, K_d=1.2, F_max=1.2, tau_lim=1.0),
          'FALLING':     dict(K_p=0.2, K_d=2.5, F_max=0.7, tau_lim=0.8),
          'IMPACT':      dict(K_p=0.1, K_d=3.0, F_max=0.5, tau_lim=0.5),
          'REST':        dict(K_p=0.2, K_d=1.0, F_max=0.6, tau_lim=0.6),
          'SELF_RIGHT':  dict(K_p=1.8, K_d=1.5, F_max=1.5, tau_lim=1.0),
          'RESUMED':     dict(K_p=1.0, K_d=1.0, F_max=1.0, tau_lim=1.0),
          'SAFE_HOLD':   dict(K_p=0.05,K_d=3.0, F_max=0.3, tau_lim=0.4),
        }[q]
```

### IP-164 DESCEND 恢复回退

```python
def descend(q, crg, budget, now, lam=0.5, mu_min=2):
    feasible = []
    for c in crg.nodes:
        if q not in crg.phase_cover[c]:                      continue
        if not crg.is_trusted(c, now, mu_min):               continue
        if not (crg.closure[c] <= crg.available(now, mu_min)):continue
        if crg.cost[c] > budget.B_recover:                   continue
        score = crg.mu[c] - lam * crg.cert_debt(c)
        feasible.append((score, c))
    if not feasible:
        return 'SAFE_HOLD', crg.impedance_schedule('SAFE_HOLD')
    c_star = max(feasible)[1]
    return c_star, crg.impedance_schedule(q, c_star)
```

### IP-165 REP 恢复证据哈希链

```python
class RecoveryEvidenceProof:
    def __init__(self, shadow):
        self.shadow, self.chain = shadow, []
        self.h = shadow.load_last_hash() or '0' * 64

    def precommit(self, phase, policy):
        self.pending = {'phase': phase, 'policy': policy,
                        't_start': time.time(), 'h_prev': self.h}
        self.shadow.persist_before_impact(self.pending)     # 冲击前落盘

    def seal(self, outcome):
        e = {**self.pending, 'outcome': outcome, 't_end': time.time()}
        e['h'] = hashlib.sha256(
            (json.dumps(e, sort_keys=True) + self.h).encode()).hexdigest()
        self.h = e['h']; self.chain.append(e)
        self.shadow.persist(e)                              # 冲击后封装
        return e['h']

    def verify(self):
        h = self.shadow.load_last_hash() or '0' * 64
        for e in self.chain:
            if e['h_prev'] != h: return False
            h = hashlib.sha256(
                (json.dumps({k:v for k,v in e.items() if k!='h'},
                            sort_keys=True) + h).encode()).hexdigest()
            if e['h'] != h: return False
        return True
```

### IP-166/167/168 预算、认证债务与 FRAME

```python
class RoadmapBudget:
    def __init__(self, cert=..., recover=..., descent=...):
        self.B_cert, self.B_recover, self.B_descent = cert, recover, descent

    def descent_mode(self):
        if self.B_descent < THETA_D: return 'static_safe'
        if self.B_recover < THETA_R: return 'safe_hold'
        return 'normal'

def cert_debt(crg, c):
    return max(0, crg.mu_target[c] - crg.mu[c]) * crg.weight[c]

def frame_loop(M, task):
    M.crg.ingest(M.rep_log)
    q = M.fpm.tick(M.telemetry)
    if q == 'STABLE':
        return M.serc(task)
    mode = M.roadmap_budget.descent_mode()
    if mode == 'static_safe':
        c_star, k_phase = 'SAFE_HOLD', M.fpm.impedance_schedule('SAFE_HOLD')
    else:
        c_star, k_phase = descend(q, M.crg, M.roadmap_budget, time.time())
    M.rep.precommit(q, c_star)
    outcome = execute_recovery(c_star, k_phase)
    M.rep.seal(outcome)
    M.crg.observe(c_star, outcome)
    return q, c_star, k_phase, M.rep, cert_debt(M.crg, c_star)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CRG 闭包 | O(|C|+|E|) 一次性 | O(|C|²) | 拓扑序保证 DAG 无环、闭包完备 |
| FPM | O(1)/控制周期 | O(1) | 相位转移全定义，任一状态有对应 κ_t |
| DESCEND | O(|C|) 查询 / 预计算后 O(1) | O(|C|) | 只返回可信且前置闭合的能力，否则 SAFE_HOLD |
| REP | O(1) 追加 | O(n_phases) | 哈希链防篡改、重启可续、冲击前落盘 |
| FRAME | O(闭环)+O(1) | 复用 | 降级与恢复均有证据支撑 |

**正确性定理（FRAME）**：假设 A66–A70 成立：
- **(A66)** CRG 为 DAG，μ 只能沿 G_ev=1 且 J_road 可信的路径单调上升；
- **(A67)** FPM 在任一控制周期内完成一次转移，且每个 q 映射到唯一 κ_t；
- **(A68)** DESCEND 不会返回未认证或前置未闭合的节点；
- **(A69)** REP 的预落盘保证冲击前证据头部已持久化，哈希链可检出任何篡改与缺口；
- **(A70)** B_road 单调消耗，任一维耗尽触发预定义静态安全策略。
则：
1. **下撤安全性**：DESCEND 的输出 c* 必满足 c*∈A 且 Cl(c*)⊆A，或为 SAFE_HOLD；不存在「依赖未认证能力」的恢复路径。

### IP-161/162 CRG 与成熟度证书

```python
class CapabilityRoadmapGraph:
    def __init__(self):
        self.nodes, self.pre, self.certs = {}, {}, {}
        self.closure, self.mu, self.mu_target = {}, {}, {}
        self.cost, self.weight, self.phase_cover, self.invalidate = {}, {}, {}, {}

    def add(self, cid, prereqs, cost, phase_cover, weight=1.0,
            invalidate=()):
        self.nodes[cid] = cid
        self.pre[cid] = set(prereqs)
        self.cost[cid] = cost
        self.weight[cid] = weight
        self.phase_cover[cid] = set(phase_cover)
        self.invalidate[cid] = list(invalidate)
        self.mu.setdefault(cid, 0)

    def compute_closure(self):
        for c in self._topo_sort():                  # O(|C|+|E|)
            cl = set(self.pre[c])
            for p in self.pre[c]:
                cl |= self.closure[p]
            self.closure[c] = cl

    def is_trusted(self, cid, now, mu_min=2):
        J = self.certs.get(cid)
        if J is None or not J.verify_sig() or now > J.valid_until:
            return False
        if J.mu < mu_min:
            return False
        return not any(inv() for inv in self.invalidate[cid])

    def available(self, now, mu_min=2):
        A, changed = set(), True
        while changed:                               # 闭包不动点
            changed = False
            for c in self.nodes:
                if c not in A and self.is_trusted(c, now, mu_min) \
                   and self.pre[c] <= A:
                    A.add(c); changed = True
        return A

    def cert_debt(self, cid):
        return max(0, self.mu_target[cid] - self.mu[cid]) * self.weight[cid]
```

```python
class FallPhaseMachine:
    Q = ['STABLE','STUMBLE','FALLING','IMPACT','REST','SELF_RIGHT',
         'RESUMED','SAFE_HOLD']

                 eps_v=0.05):
        self.q, self.xi1, self.xi2 = 'STABLE', xi1, xi2
        self.J_th, self.tau_fall, self.eps_v = J_th, tau_fall, eps_v

    def capturability(self, obs):
        return min(self._t_capture(obs, u) for u in obs.recovery_actions)

    def tick(self, obs):
        xi = self.capturability(obs)
        if xi > self.tau_fall and self.q in ('STABLE','STUMBLE','FALLING'):
            self.q = 'SAFE_HOLD'; return self.q
        if self.q == 'STABLE':
            self.q = 'STUMBLE' if (xi < self.xi1 or obs.m_sup < 0) else 'STABLE'
        elif self.q == 'STUMBLE':

        elif self.q == 'SELF_RIGHT':
            self.q = 'RESUMED' if obs.upright else self.q
```

### IP-164 DESCEND 恢复回退

```python
def descend(q, crg, budget, now, lam=0.5, mu_min=2):
    A = crg.available(now, mu_min)
    feasible = []
    for c in A:
        if q not in crg.phase_cover[c]:              continue
        if crg.cost[c] > budget.B_recover:           continue
        if not crg.closure[c] <= A:                  continue
        score = crg.mu[c] - lam * crg.cert_debt(c)
        feasible.append((score, c))
    if not feasible:
        return 'SAFE_HOLD', crg.impedance_schedule('SAFE_HOLD')
    c_star = max(feasible)[1]
    return c_star, crg.impedance_schedule(q, c_star)
```

### IP-165 REP 恢复证据哈希链

```python
class RecoveryEvidenceProof:
    def __init__(self, shadow):
        self.shadow, self.chain = shadow, []
        self.h = shadow.load_last_hash() or '0' * 64

    def precommit(self, phase, policy):
        self.pending = {'phase': phase, 'policy': policy,
                        't_start': time.time(), 'h_prev': self.h}
        self.shadow.persist_before_impact(self.pending)   # 冲击前落盘

    def seal(self, outcome):
        e = {**self.pending, 'outcome': outcome, 't_end': time.time()}
        e['h'] = hashlib.sha256(
            (json.dumps(e, sort_keys=True) + self.h).encode()).hexdigest()
        self.h = e['h']; self.chain.append(e)
        self.shadow.persist(e)
        return e['h']

    def verify(self):
        h = self.shadow.load_last_hash() or '0' * 64
        for e in self.chain:
            if e['h_prev'] != h: return False
            body = {k: v for k, v in e.items() if k != 'h'}
            h = hashlib.sha256(
                (json.dumps(body, sort_keys=True) + h).encode()).hexdigest()
            if e['h'] != h: return False
        return True
```

## 3. 关键推导

**推导 1（下撤安全性）** 设 A 为闭包不动点集（`pre[c] ⊆ A ⇒ c ∈ A`）。DESCEND 只在 A 中取 c，故 Cl(c)⊆A 自动成立；又由 `is_trusted` 约束 μ(c)≥μ_min 且证书有效。因此 c* 的每条前置依赖都必须是「已认证且未过期」的节点。反证：若存在未认证前置 p∈Cl(c*)，则 p∉A，与 c*∈A 矛盾。故下撤路径不依赖任何未认证能力。

**推导 2（成熟度单调性）** μ 仅在 `CRG.observe` 且 REP 证据包通过 G_ev 校验时上升；J_road 的签名与失效谓词使「未复现的能力」无法获得高成熟度。于是 μ(c) 是证据的单调函数，而非声明的函数。

**推导 3（证据可恢复性）** 预落盘把 e_i 头部（含 h_{i−1}）在冲击前写入非易失影子区；即使节点在 IMPACT 后重启，也能从最后封装的 h 续链。哈希链 `h_i = H(e_i‖h_{i−1})` 使任意篡改或删除都会破坏后续所有 h，故缺口与篡改可检出。

**推导 4（认证债务上界）** 若系统仅使用 c∈C_used，则 D_cert ≤ Σ_{c∈C_used} w(c)·μ_target(c) ≤ W·μ_max。当 D_cert/D_max > 1−θ_ready 时禁止高风险任务，等价于把「路线图缺口」转化为任务准入约束，避免把未认证能力暴露在跌倒工况。
