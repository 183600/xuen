### 第 2 轮灵感驱动研究记录（力觉传感 · 全身控制）

**灵感词**：力觉传感、全身控制

**直觉与动机**：
上一轮（v24 / USMC）把机器人从「感知-合规-能量」推进到「结构-力学」证书链，但仍把机器人当作「末端执行器 + 单体结构」：它假设接触只发生在末端、结构参数离线固定、平衡由低层控制器隐式维持。真实作业中，机器人以多点接触（手、臂、躯干、足）同时与环境和自身耦合；接触位置、法向力、切向力、是否滑移只能通过力觉传感（关节力矩、腕力、电子皮肤/触觉阵列）间接观测，而动作由全身控制（WBC）在浮动基、多接触、任务层级、摩擦锥与力矩限幅下求解。

核心洞见（直觉）：**力觉传感是「接触的观测证书」，全身控制是「接触的消费证书」；安全不取决于估计得多准，而取决于观测证书是否为真实接触的保守外近似（不漏接触、不低报法向力、不低估摩擦），以及控制证书能否在该外近似下仍然可行。** 感知与控制不是两个并列模块，而是同一条「接触契约」的生产者与消费者：感知证书向外扩张不确定性，控制证书向内收缩可行动作，两者的交叠才是可执行的安全域。

**形式化目标**：
1. 触觉接触证书（TCC）：给出接触集外近似 Ĉ_t ⊇ C_t^true、逐接触力单边区间 [f⁻, f⁺]、摩擦系数下界 μ⁻、滑移概率上界 P(slip) ≤ δ、覆盖率与标定有效性证书；盲区/失效触觉单元一律按最坏接触（幻影接触）补全，保证「宁可多报、绝不漏报」。
2. 跨模态一致性证书（CMCC）：关节力矩测量与「触觉力经 Jacobian 反推 + 刚体动力学」的残差满足 ‖τ_meas − τ_pred‖∞ ≤ ε_τ（ε_τ 含模型误差上界）；用于发现漏检接触与标定漂移，并触发 TCC 扩张。
3. 全身可行证书（WBFC）：在浮动基质心动力学、鲁棒摩擦锥（‖f_t⁺‖ ≤ μ⁻ f_n⁻）、单边法向、关节力矩/位置限幅下，多点接触力与关节力矩的鲁棒 QP 存在可行解且裕度 ≥ ρ_qp。
4. 平衡稳定证书（BSC）：ZMP 与 DCM 落在支撑多边形内且裕度 ≥ ρ_bal，或所需质心扳手严格位于接触扳手锥 CWC 内部（裕度 ρ_cwc）。
5. 统一全身-触觉准入门（WBTG）：HPC-E+ v24 ∪ TCC ∪ CMCC ∪ WBFC ∪ BSC 五证一体，Exec_v25 = Exec_v24 ∩ Fil_tc ∩ Fil_cm ∩ Fil_wb ∩ Fil_bal ⊆ Exec_v24，并证明触觉失效/可行性失效/平衡失效三条退化路径的单调保持。

# ============================================================
# IP-444 Tactile Contact Certificate (TCC) — 触觉接触证书
# ============================================================
@dataclass
class TactileContactCertificate:
    """接触集外近似 + 力区间 + 摩擦/滑移 + 覆盖/标定证书"""
    taxels: Tensor            # [N_s,3] 机身表面触觉单元位置
    coverage: Tensor          # [N_s] bool，标定有效且工作正常
    contact_prob: Tensor      # [N_s] ∈ [0,1] 接触后验概率
    f_lo: Tensor              # [N_s,3] 逐分量力下界
    f_hi: Tensor              # [N_s,3] 逐分量力上界
    mu_lo: Tensor             # [N_s] 摩擦系数下界
    slip_prob: Tensor         # [N_s] 滑移概率上界
    p_thresh: float = 0.5
    delta_slip: float = 1e-3
    t_cal: float = 0.0
    t_cal_expire: float = 60.0

    def contact_set_overapprox(self) -> Tensor:
        """保守外近似：概率超阈值 ∪ 未覆盖/失效单元（幻影接触）"""
        return (self.contact_prob >= self.p_thresh) | (~self.coverage)

    def force_interval(self, i: int) -> tuple[Tensor, Tensor]:
        """盲区/失效单元：f_lo=0, f_hi=硬件量程上界；正常单元用标定区间"""
        if not bool(self.coverage[i]):
            return torch.zeros(3), self._sensor_range_hi(i)
        return self.f_lo[i], self.f_hi[i]

    def verify_coverage(self, required: Tensor) -> bool:
        """任务要求的接触区域必须全部被有效触觉覆盖"""
        return bool((self.coverage | (~required)).all())

    def verify_calibration(self, t: float) -> bool:
        """标定未过期：t − t_cal ≤ T_cal"""
        return (t - self.t_cal) <= self.t_cal_expire

    def verify_slip(self) -> bool:
        """P(slip_i) ≤ δ_slip ∀i"""
        return bool((self.slip_prob <= self.delta_slip).all())

    def verify_robust_friction(self) -> bool:
        """鲁棒摩擦锥：‖f_t⁺‖ ≤ μ⁻ · f_n⁻（最不利区间端点）"""
        for i in range(len(self.taxels)):
            if not bool(self.contact_set_overapprox()[i]):
                continue
            f_lo, f_hi = self.force_interval(i)
            if f_hi[1:].norm() > self.mu_lo[i] * f_lo[0]:
                return False
        return True

    def verify_all(self, required: Tensor, t: float) -> bool:
        return (self.verify_coverage(required) and
                self.verify_calibration(t) and
                self.verify_slip() and
                self.verify_robust_friction())

# IP-445 Cross-Modal Consistency Certificate (CMCC) — 跨模态证书
# ============================================================
@dataclass
class CrossModalConsistencyCertificate:
    """关节力矩 vs 触觉反推力矩的动态一致性证书"""
    tau_meas: Tensor          # [n] 关节力矩测量（力矩传感器/电流估计）
    tau_pred: Tensor          # [n] 由触觉力经 Jᵀ f + 刚体动力学预测
    eps_model: float          # 模型误差上界（摩擦/未建模柔性）
    eps_sensor: float         # 传感噪声上界

    @property
    def eps_tau(self) -> float:
        return self.eps_model + self.eps_sensor

    def residual(self) -> Tensor:
        return (self.tau_meas - self.tau_pred).abs()

    def verify(self) -> bool:
        """‖r_τ‖∞ ≤ ε_τ"""
        return bool(self.residual().max() <= self.eps_tau)

    def detection_threshold(self, J_contact: Tensor) -> float:
        """可检出的最小漏检接触力：‖Jᵀ f_miss‖∞ > ε_τ 即必被检出"""
        return self.eps_tau / J_contact.abs().max().clamp_min(1e-9)

    def expand_contacts(self, tcc: TactileContactCertificate) -> TactileContactCertificate:
        """残差超限 → 将最高后验概率的盲区单元升级为接触，返回扩张后的 TCC"""
        if self.verify():
            return tcc
        blind = ~tcc.coverage
        idx = torch.argmax(torch.where(blind, tcc.contact_prob, -1.0))
        tcc.coverage[idx] = True
        tcc.contact_prob[idx] = 1.0
        tcc.f_lo[idx] = torch.zeros(3)
        tcc.f_hi[idx] = tcc._sensor_range_hi(idx)
        return tcc

class BalanceStabilityCertificate:
    """ZMP / DCM / CWC 三重平衡证书"""

        return signed_distance(self.dcm, self.support_polygon) >= self.rho_bal

        """所需质心扳手在 CWC 内部且包含裕度 ρ_cwc"""
        return cwc.contains(w_req, margin=self.rho_cwc)

    def verify_all(self, w_req: Tensor, cwc: 'ContactWrenchCone') -> bool:
        return (self.verify_zmp() and self.verify_dcm() and
                self.verify_cwc(w_req, cwc))

class WholeBodyTactileGate:

               w_req: Tensor, cwc: 'ContactWrenchCone') -> bool:
        # 1. v24 基础（结构-力学-能量-合规-专利）
        if not self.usmc.admits(plan, x, v, z, E_res, margin_req, modules):
            return False
        # 2. 触觉接触证书（接触集外近似 + 力区间 + 摩擦/滑移 + 覆盖/标定）
        if not self.tcc.verify_all(required_contact, t):
            return False
        # 3. 跨模态一致性（漏检接触/标定漂移检测）
        if not self.cmcc.verify():
            return False
        # 4. 全身鲁棒可行（动力学 + 摩擦锥 + 限幅）
        feasible, _ = self.wbfc.verify_robust()
        if not feasible:
            return False
        # 5. 平衡稳定（ZMP/DCM/CWC）
        if not self.bsc.verify_all(w_req, cwc):
            return False
        return True

## 3. 正确性论证（增量）

**假设 A1（传感器标定模型）**：在标定有效期内，真实接触力落在证书区间内，即 f_i^true ∈ [f_i⁻, f_i⁺]，且真实摩擦系数 μ_i^true ≥ μ_i⁻。这是 TCC 全部结论的唯一物理前提。

### 引理 9（触觉接触证书的保守外近似可靠性）
**陈述**：在 A1 下，若 `TCC.verify_all(required, t) = True`，则
(1) C_t^true ⊆ Ĉ_t（不漏报接触），
(2) f_i^true ∈ [f_i⁻, f_i⁺] 且 μ_i^true ≥ μ_i⁻（力/摩擦不低报），
(3) P(slip_i) ≤ δ_slip，
(4) 任务要求的接触区域全部被有效标定的触觉覆盖。

**证明**：
1. `contact_set_overapprox` 取「后验概率 ≥ p_thresh」与「未覆盖/失效单元」的并集。对任意真实接触 s，若 κ(s)=1 则被触觉观测、后验概率随证据升高而越过阈值；若 κ(s)=0 则被 `~coverage` 强制纳入 Ĉ。故 C_t^true ⊆ Ĉ_t。幻影接触只增加约束，不减少约束，保守方向正确。
2. 由 A1，正常单元区间含真值；盲区单元取 f_lo=0、f_hi=硬件量程，真值必在区间内。摩擦下界 μ⁻ 由 A1 保证不高于真值。
3. 滑移概率由触觉滑移检测器给出，`verify_slip` 直接比对 δ_slip。
4. `verify_coverage` 要求 required ⊆ coverage。
四项独立且合取，故成立。∎

### 引理 10（跨模态证书的漏检接触可检出性）
**陈述**：设模型误差满足 ‖τ_model^true − τ_pred‖∞ ≤ ε_model，传感噪声 ≤ ε_sensor。若存在未被 Ĉ 建模的真实接触，其经 Jacobian 产生的力矩满足 ‖Jᵀ f_miss‖∞ > ε_τ = ε_model + ε_sensor，则 `CMCC.verify() = False`。
**证明**：τ_meas = τ_pred + Jᵀ f_miss + e_model + e_sensor，故 r_τ ≥ ‖Jᵀ f_miss‖∞ − ‖e_model‖∞ − ‖e_sensor‖∞ > ε_τ − ε_τ = 0 的对应分量超过 ε_τ。逆否即得：`verify()=True` 时，任何漏检接触的等效力矩不超过可检阈值 `detection_threshold`。注意这是「阈值以上必检」，不是「全检」，见 R14。∎

### 引理 11（全身可行证书的鲁棒可行性）
**陈述**：若 `WBFC.verify_robust() = (True, f*)`，则对任意满足 f ∈ [f_lo,f_hi] 且落在鲁棒摩擦锥 K^rob 内的真实接触力，存在关节力矩 τ ∈ [τ_min, τ_max] 与之一致地实现期望质心动量变化率 ḣ_des，且可行裕度 ≥ ρ_qp。
**证明**：鲁棒 QP 对 f 的不确定性盒子做区间传播：A f 的上下界、Jᵀ f 的上下界均可由区间算术精确给出（A、J 对 f 线性）。将区间端点代入等式/不等式约束后求解的可行域，包含所有可能的真实 (f, τ) 对应的可行域（因线性映射把盒子映为区间盒，保守但可靠）。若端点问题以裕度 ρ_qp 可行，则盒子内任意点可行。∎

### 引理 12（平衡稳定证书的捕获/倾覆判据）
**陈述**：若 `BSC.verify_all(w_req, cwc) = True`，则 (1) ZMP 在支撑多边形内且距边界 ≥ ρ_bal；(2) DCM 在支撑多边形内且距边界 ≥ ρ_bal，故系统在 DCM 动力学下可捕获；(3) 所需质心扳手在 CWC 内且裕度 ≥ ρ_cwc，故存在满足摩擦锥与单边约束的接触力实现该扳手，不会发生支撑面倾覆。
**证明**：(1)(2) 由带符号距离定义直接得；(2) 结合线性倒立摆 DCM 动力学 ξ̇ = ω(ξ − z_zmp)，DCM 位于支撑多边形内意味着存在使 ξ 收敛的 ZMP 序列（capture point 判据）。(3) CWC 是各接触摩擦锥扳手的 Minkowski 和，w_req 严格内点 + 裕度意味着可分解为满足 K_i 的接触力；由对偶锥理论，内点判据等价于所有面法向约束以正裕度满足。∎

### 引理 13（五证一体单调退化链延伸）
**陈述**：任意单点/组合失效下，`Exec_v25 ⊆ Exec_v24 ⊆ … ⊆ Exec_v18` 恒成立。
**证明**：在引理 8 基础上增加四条退化路径：
- 触觉覆盖丢失/标定过期/滑移超限 → `TCC.verify_all=false` → WBTG 拒证 → 退回 `Exec_v24`（改用本体感知 + 幻影接触全表面保守模型，降低速度/接触力）。
- 跨模态残差超限且无法通过接触扩张消除 → `CMCC.verify=false` → WBTG 拒证 → 退回 `Exec_v24`（触觉不可信，仅用关节力矩/本体感知）。
- 全身鲁棒 QP 不可行 → `WBFC.verify_robust=false` → WBTG 拒证 → 退回 `Exec_v24`（冻结接触构型，退回单末端/准静态计划）。
- 平衡裕度不足 → `BSC.verify_all=false` → WBTG 拒证 → 触发安全停止/坐下（Exec 退化为 ∅ 或预定义安全动作集）。
- 组合失效取交集，单调性保持。∎

### 定理（WBTG 五证准入门的安全性-可部署性-接触一致性）
**陈述**：对任意计划 π，`WBTG.admits(π) = True` ⟺ π 同时满足：
(1) v24 的结构-力学-能量-合规-专利完备性（定理 v24 的 7 条），
(2) 触觉接触集外近似、力区间、摩擦/滑移、覆盖/标定达标，
(3) 跨模态残差在 ε_τ 内（阈值以上漏检接触必被检出），
(4) 全身多接触鲁棒动力学可行且裕度 ≥ ρ_qp，
(5) ZMP/DCM/CWC 三重平衡裕度达标。
**证明**：由 `WBTG.admits` 的五个连言条件与引理 9–12 直接得。必要性：任一条件缺失即拒证，对应触觉漏报、漏检接触、动力学不可行、平衡失稳四类风险之一未缓解。充分性：五条件全满足时，感知证书是真实接触的保守外近似，控制证书在该外近似下可行且平衡，二者构成「感知-控制接触契约」的闭环；再由引理 13 保证退化链单调。∎

## 6. 本轮最大风险（最终确认）

**一句话**：**TCC 的保守外近似依赖标定假设 A1，CMCC 的可检出性依赖模型误差界 ε_model，WBFC 的可靠性依赖区间算术的保守性——当触觉标定漂移、模型误差被低估、接触集在高频冲击下突变三者同时发生时，证书链可能把「未观测到的真实接触」误当作「不存在」，从而在物理接触已越出摩擦锥/平衡域后仍给出可行见证，破坏 WBTG 的「不漏报即安全」前提。**
