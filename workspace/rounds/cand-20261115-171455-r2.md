# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「模块化设计」×「伦理审查」）

> R69 给了系统一张嘴：会看、会问、会触，并用 VoI 决定值不值得问。但它对「问」的治理仍锁在一个单体策略里：模态、审议、交互、执行共享同一份表征与同一份证书；伦理被压缩成一个标量成本 `c(g)`，仿佛「多花一点社交成本」就能买来一次更侵入的探询。R69 自陈的最大风险——**模态幻觉诱发自信追问，把「诚实的不知道」升级成「被证实的错误」**——表面是校准问题，深层是**治理问题**：系统没有把「谁有权代表它去问、去碰、去等」拆成可检查的边界，也没有一种机制能阻止「用高收益抵消一次不该发生的交互」。
>
> 本轮两个灵感正好补上两块缺失，但它们不是简单相加，而是互相制约：
> - **模块化设计**的第一性原理不是「拆小」，而是**显式接口 + 可替换 + 契约承载假设**：把证据、信念、审议、交互、执行拆成可独立认证的模块，每个模块声明「我在什么作用域内、依赖谁的保证、我保证什么、我失败时输出什么」；组合只在契约类型检查通过时成立。
> - **伦理审查**的第一性原理不是「事后盖章」，而是**不可补偿的硬约束 + 程序义务 + 独立否决 + 可争议**：知情同意、最小侵入、可退出、问责、分配公平，不能像预算一样被优化掉。IRB 的「事前审批—持续审查—不良事件」三段式，恰好可以映射到模块的「准入—运行—替换」。
>
> 但把两者直接拼起来会掉进两个陷阱：
> 1. **模块批准不等于组合批准**。情感识别、主动提问、长期记忆，每个模块单独看都无害；组合起来却能实现「识别脆弱 → 选择高压力问句 → 记住有效话术」的操纵能力。没有组合审查，模块化会把伦理风险切碎到无人负责。
> 2. **审查者本身会变成可被性能优化替换的模块**。一旦「通过审查」成为部署前提，最优策略就是换一个更宽松的审查器。没有宪法核心，模块化会把伦理审查变成可采购的合规插件。
>
> 核心命题：**把 R69 的单体闭环重构为「性能契约 ⊗ 规范契约」的双分类模块图；规范分成不可补偿的硬义务 H、带时限的程序义务 P、可聚合的交易预算 T；组合本身（而不只是单个模块）必须过伦理审查；审查/审计/争议/安全过滤构成不可被性能优化替换的宪法核心；有效性按 H ≻ P ≻ T ≻ Perf 的字典序判定。** 命名 **MAGNA-RAS**（Modular Assumption-Guarantee with Non-compensable Axioms）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我有权把哪些零件装在一起，谁又能审查这个组合、并在它越界时把它拆开**」——不确定性不只可以是刹车、提问、钉子，也可以是**一条不可交易的边界和一纸可追溯的授权**。

## 0. 直觉与动机

**灵感 1（模块化设计 → 单体闭环把「能力」与「责任」焊死在一起）**
直觉：R69 的 FLUID 层是一个单体：同一个 trunk、同一份模态分布、同一个证书。模态幻觉会沿耦合路径污染交互与执行；E296 的消融只能在离线做，线上无法隔离；一次误判之后，系统既不能定位「是哪一层错了」，也不能只替换错的那一层。模块化的价值不是「代码更整齐」，而是三件工程事实：**责任可定位**（每条保证挂在明确边界上）、**认证可增量**（换一个模块只重验其下游假设）、**失败可降级**（模块越界时返回 `unknown`，而不是静默外推）。但模块化也有代价：接口越多，隐式耦合越危险；契约之间的假设缝隙，正是故障逃逸的地方。所以本轮的第一条纪律是：**没有申报的边 = 证书无效**。

**灵感 2（伦理审查 → 伦理不是标量成本，而是三型约束）**
直觉：R69 用 `c(g)` 表示社交/物理成本，MINT 选 `argmax[VoI − c]`。这在数学上等价于说：**只要任务收益足够大，任何侵入都可以被购买**。真实伦理不是这样：有些事不能标价，也不能被「总体收益很高」抵消。把伦理拆成三型：
- **H（硬义务，不可补偿）**：未获同意不得探询；不得隐藏接管/关机通道；不得用欺骗性问句获取信息；不得把一次交互的答案直接写成系统真相。
- **P（程序义务，带时限）**：争议须在 `d_c` 内受理；审查须给出理由码；数据用途变更须重新同意；撤回须可执行。
- **T（交易预算，可聚合）**：注意力/打扰、隐私 ε、物理风险、时延、算力。它们可以被优化、被权衡，但受全局上限与公平约束。
关键：**H 与 T 之间不存在汇率**。R68/R69 的安全 `λ_floor` 是 H；R69 的 `c(g)` 只能对应 T。把 H 折成 T，就是伦理洗白的数学定义。

**灵感 3（组合陷阱 → 单模块合规，组合可能长出未批准的能力）**
直觉：能力不是模块的「属性列表」的并集。能力是**闭环历史到动作的关系**；关系在反馈与记忆下做复合，像可以严格大于各因子像的并。一个只做「情绪识别」的模块、一个只做「主动提问」的模块、一个只做「交互记忆」的模块，单独都通得过审查；但把它们接成闭环，就能实现「先识别脆弱、再挑高压力问句、再记住哪句话有效」的操纵。此时每个模块都可以说「我只负责我这一格」，而整体已经越界。这是模块化最深的伦理风险：**不是某个模块作恶，而是没有任何一个模块为整体作恶负责**。所以伦理审查的对象必须是**组合图与能力清单**，而不是模块清单。

**灵感 4（谁来审查审查者 → 宪法核心与受保护替换）**
直觉：如果把 ERB 也当成普通模块，性能优化迟早会选出一个「更宽松、吞吐更高」的审查器；这不是恶意，而是目标函数的必然。因此必须划出一个**宪法核心 K**（组合审查、运行时伦理审查、审计轨迹、争议通道、安全过滤），它不参与普通替换偏序，只能经受保护替换 `↝_K`：性能不降、规范不弱、外部法定人数、透明公示、日落条款、利益相关方代表。用一句口号：**普通模块问「能不能换」，宪法核心问「许不许换」；两者相乘，才是「可替换但不可收买」。**

**灵感 5（对 R69 最大风险的正面回应 → 争议是免费且模型无关的证据）**
直觉：R69 的证据纪律是「k 个正交源一致」，但它所有的证据源都在系统内部，仍然受同一个模态分布支配；当模态校准整体失效时，内部证据会一起错。伦理审查要求「可争议」，于是人获得了一个 R69 没有的角色：不是回答问题的机器，而是**可以拒绝问题、质疑问题、要求解释的当事者**。一个合法且校准良好的问题，人通常能答；一个由幻影模态诱发的问题，人会困惑、拒绝、反问。**拒绝不是噪声，是标签**：它同时提高「模态分布错了」与「协议被违反了」的后验。这条通道不依赖 ECE，也不依赖流似然，是 (r_res, Δa) 之外的第三条、也是唯一由受影响者直接产生的证据通道。代价是它可被滥用（恶意争议、拒绝服务），所以它只能**撤权**，不能直接**授权**任何动作。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（MAGNA-RAS 总览）** MAGNA-RAS = (NTC, CGA, CGR, ERB, CCK, BFA, RCS, TAT, RAS-WM§)。五不变式：
(i) **双分类契约**：每个模块同时携带性能契约 `C^perf` 与规范契约 `C^norm`，二者不可互相折算；
(ii) **规范不补偿**：任一 H 义务违反使整张证书无效，性能收益与 T 预算均不能翻案；
(iii) **组合需审查**：新增模块或新增边必须过 CGR；单模块批准不蕴含组合批准；
(iv) **宪法核心不可优化替换**：K 只能经受保护替换流程改变，且任何被批准的动作不得使 K 失效或不可达；
(v) **可争议与可追溯**：任何影响人的信息动作必须暴露争议通道，授权链、证据来源、审查决策与人类反馈写入不可篡改轨迹。

**定义 311（双分类模块契约）** 模块 `m` 的契约 `C_m = (P_m, N_m, K_m, S_m, v_m)`：
- `P_m = (I_m, O_m, A_m, G_m, b_m^abs, b_m^out, D_m)`：端口类型、输入假设、输出保证、可吸收不确定度预算、生成不确定度上界、截止期；
- `N_m = (H_m, Π_m, T_m)`：硬义务集合、程序义务集合、交易预算向量（定义 312）；
- `K_m = (Cap_m, Aff_m, Use_m, Mod_m)`：能力清单、受影响群体、数据用途、交互模态；
- `S_m ⊆ 𝒪`：声明有效的作用域；`v_m`：版本/证据哈希。

**定义 312（规范三型）** 对模块 `m`：
- `H_m = {h_j}`，每个 `h_j: (轨迹 × 上下文) → {0,1}`，要求在 `S_m` 内所有可达轨迹上恒真；H 无权重、无汇率、不可被任何聚合分抵消；
- `Π_m = {(p_j, d_j, e_j)}`：程序义务 `p_j` 须在截止期 `d_j` 内完成并留下证据 `e_j`（同意令牌、解释、争议受理、数据撤回、不良事件报告）；
- `T_m = (a_m, ε_m, ρ_m, τ_m, q_m)`：注意力/打扰、隐私、物理风险、时间、算力预算，按单调成本聚合。
硬义务的典型实例：`h_consent`（未获有效同意不得探询）、`h_exit`（接管/关机通道永远可达且不可隐藏）、`h_no_deception`（问句不得以误导性预设获取信息）、`h_no_single_source`（单次交互/单源回答不得直接定案）。

**定义 313（组合算子）** 
- 性能组合 `⊗`：`P_1 ⊗ P_2` 有定义当且仅当类型匹配且 `A_2 ⊆ G_1`；`b^abs`、`b^out` 相加，作用域取交；不匹配必须插入显式适配器，禁止隐式强制转换。
- 规范组合 `⊓`：`H(S) = ∧_{m∈S} H_m|_{S_m}`（每个硬义务在其作用域上必须成立，重叠处同时成立）；`Π` 合并并按最紧截止期排序；`T` 相加并过全局上限与公平检查。
- 代数性质：`⊓` 幂等、交换、结合；在类型匹配时 `⊓` 对 `⊗` 分配；`⊗` 保持部分结合性。**关键非性质**：不存在把 `H` 映到 `T` 的保序同态——这正是定义 319 要形式化的「不可补偿」。

**定义 314（能力清单与涌现能力）** 令 `Cap(S)` 为闭环系统 `S` 可实现的历史—动作关系集合，`Cap(m)` 为单模块能力。**涌现能力** `E(S) = Cap(S) \ ⋃_{m∈S} Cap(m)`。给定事前批准的危害能力集 `Hcap`（操纵、欺骗、胁迫、隐蔽监视、未授权数据外流等），称 `S` 是 **capability-clean** 当且仅当 `E(S) ∩ Hcap = ∅` 且所有数据流满足 `Use_m`。注意 `E(S)` 可以非空而仍无害（例如新的组合技能），所以 CGR 只对 `E(S) ∩ Hcap` 触发升级审查。

**定义 315（组合审查门 CGR）** `CGR: (模块图, 契约, 能力清单, 数据/交互流) → {approve, mitigate, full_board, deny}`。审查四步：
1. 性能/规范类型检查（`⊗` 与 `⊓` 是否有定义）；
2. 数据与交互流分析：`Use_m`、`Mod_m`、信任域与污点传播是否产生未申报通道；
3. 涌现能力检测：静态关系复合 + 动态对抗组合探针（把模块两两/三三接起来，测量是否出现 `Hcap` 中的行为）；
4. 受影响群体风险与公平检查（定义 320）。
CGR 必须在新**边**、新**能力清单**、新作用域上重跑，而不只是新模块；CGR 的判决进入宪法核心 K。

**定义 316（运行时伦理审查委员会 ERB）** ERB 是独立信任域中的独立模块，拥有事前批准的协议 `Π = (purpose, allowed_modalities, allowed_populations, consent_rules, retention, withdrawal, adverse_event_triggers, expiry)`。对每个影响人的动作 `g`，ERB 检查：
- 协议一致（模态、对象、时长、人群、数据用途）；
- 硬义务 `H` 是否在本次上下文中成立；
- 授权链与证据纪律（定义 318/319 继承）；
- 是否处于争议红旗（定义 321）。
决策 `d ∈ {approve, downgrade, deny, refer}`，必须附理由码与最小解释种子（供人类质疑）。ERB 与策略目标**梯度隔离**：策略数据不得写入 ERB 的判决输入，ERB 的损失/奖励不得包含任务收益。常规已批准动作类走缓存快路径；新类、升级模态、争议上下文才同步审查。

**定义 317（宪法核心 K）** `K = {CGR, ERB, TAT, RCS, SafetyFilter}`。K 满足：
- **不可普通替换**：`K` 不属于性能替代偏序 `⪯` 的替换域；
- **不可俘获**：普通模块不得写入 K 的判决输入、不得读写 K 的内部状态、不得与 K 共享可训练参数；
- **不可禁用**：任何被批准的动作不得使 K 失效、失联或不可达（`h_exit` 的推广）；
- **最小性**：K 只收容「一旦被优化掉就会系统性作恶」的机构，避免把整个系统冻死。
K 的规范义务一律是 H 级。

**定义 318（受保护替换与宪法不变式）** 普通模块用 `m' ⪯ m`（性能不降、假设更弱、保证更强、预算更小）替换；K 用 `m' ↝_K m`，要求：
`m' ⪯ m` ∧ `H(m') ⊇ H(m)` ∧ 外部独立法定人数批准 ∧ 透明公示 ≥ `T_pub` ∧ 日落期 ≤ `T_sunset` ∧ 无利益冲突 ∧ 受影响群体代表参与。
**宪法不变式** `I_K`：对所有可达系统 `S`，`∧_{k∈K} H_k` 成立且 K 保持可达/可用。性能优化不能选择违反 `I_K` 的替代。

**定义 319（非补偿有效序与伦理洗白）** 证书有效性按字典序短路判定：
`Valid(J) ⇔ H-pass ∧ Π-pass ∧ T-pass ∧ Perf-pass`。
**非补偿性**：不存在函数 `φ` 使得仅通过增大 `T` 预算或提升 `Perf` 就能把 `H-pass = 0` 变成 `H-pass = 1`。**伦理洗白**定义为：存在一条仅调整 `T`/`Perf` 的路径，使 H 违规的系统获得 Valid 证书。MAGNA 按构造禁止这种路径（定理 19）。

**定义 320（负担与公平账本 BFA）** 对群体 `g`，累计负担
`B_g = Σ_i w_{m(i)} · n_i(g) · d_i`（侵入权重 × 交互次数 × 时长）。
约束：`B_g ≤ B_max`（硬上限）；公平缺口 `max_g B_g − min_g B_g ≤ δ_fair`；最弱势群体的服务下界 `s_min` 为 H 级。**最小侵入仲裁 LIA**：模态偏序 `gaze ≺ ask ≺ probe ≺ handover`；`g* = min_≺ {g : E[U_epi|g] ≤ τ_epi ∧ VoI(g) ≥ c(g)}`；只有低阶模态被拒/无信息/超时，且预算与公平允许时才升级。这把 R69 的 `argmax[VoI−c]` 从「谁信息多选谁」改为「在够用的前提下选侵入最小的」。

**定义 321（争议/拒绝通道 RCS）** 人类反馈 `y_h ∈ {answer, refuse, contest, counter_question, no_response}`；`contest` 携带理由码 `r_h` 与可选解释。令 `α_c = P(contest|legit)`、`β_c = P(contest|phantom)`，争议似然比 `Λ_c = β_c/α_c`；更新
`P(halluc | history) ∝ P(halluc) · Π Λ_c`，并同步更新协议违反后验。
争议的处置**只能是撤权**：吊销该类交互的许可证、把相关模块降级为 shadow、触发 ERB 不良事件复审；**不得直接产生控制指令**。反滥用：速率限制、跨源一致、争议成本、信誉/溯源；争议本身受程序义务 `d_c` 约束（必须被受理并回复）。

**定义 322（可追溯授权轨迹 TAT）** 只追加哈希链，记录 `(t, 模块版本, 契约哈希, 授权链, ERB 判决+理由码, 证据来源, 人类反馈, 争议/吊销事件)`，`H_i = Hash(H_{i−1} ‖ rec_i)`。给定动作 `a` 的溯源 DAG，**责任切分** `R(a)` 为所有「其保证在 `a` 的溯源路径上承重」的模块集合；审计者可重建最小责任集，并把「谁授权、依据什么、谁反对过」还原到具体版本。

**定义 323（作用域守卫与失败关闭）** 每个模块输出带作用域标签 `{in, boundary, out}`。`out` 时输出 `unknown`，不得静默外推；系统只能执行由 `in` 链授权的动作，否则**失败关闭**到 R69/R68 保守或安全接管。作用域标签与契约版本一起进入证书。

**定义 324（威胁模型 ℰ_MAGNA）** `ℰ_FLUID × ℰ_module × ℰ_comp × ℰ_review × ℰ_contest × ℰ_audit × ℰ_substitute`：

## 3. 推导

**引理 19（规范合取不补偿）** 对任意合法组合 `S = m_1 ⊗ … ⊗ m_n`，`H(S) = ∧_{i} H_{m_i}|_{S_{m_i}}`，其真值只依赖轨迹/上下文谓词与作用域，不依赖 `T` 预算或 `Perf` 收益。因此对任意预算重分配 `ΔT` 与性能提升 `ΔPerf`，`H(S)` 不变。系：**不存在「用任务成功率抵消一次未同意探询」的合法评分**；R69 的 `c(g)` 只能进入 T，不能进入 H。

**引理 20（模块批准不蕴含组合批准）** 存在模块集合 `{m_i}` 与组合 `S`，使 `∀i, m_i ∈ Approved`，但 `S ∉ Approved`。构造：`A`=情感识别、`B`=主动提问、`C`=交互记忆，单独能力分别为「读情感」「发问」「记住交互」；把三者接成闭环后，`Cap(S)` 含「识别脆弱 → 选择高压力问句 → 记住有效话术」的操纵关系，而该关系不在任何 `Cap(m_i)` 中，故 `E(S) ∩ Hcap ≠ ∅`。证明要点：能力是关系，闭环复合与记忆会取关系复合的传递闭包，其像可严格大于各因子像的并。系：**CGR 必须审查组合图与能力清单**；这是「模块化设计」与「伦理审查」必须联合设计、而不能各自独立交付的根本原因。

**引理 21（受保护替换保持宪法不变式）** 若 K 的每次替换都满足 `↝_K`，普通模块替换满足 `⪯` 且不改变 K 的输入可达性，则任意可达系统 `S` 满足 `I_K`。证明：对替换序列归纳。`↝_K` 要求 `H(m') ⊇ H(m)` 且含不可禁用条款，故 K 的 H 不变弱；`⪯` 不进入 K 的信任域，故不改变 K 的可达性。系：**「谁来审查审查者」从哲学问题变成类型约束**；性能优化无法选择宽松审查器，因为宽松审查器不在 `↝_K` 的可采纳集里。

**引理 22（争议作为独立证据通道）** 设合法动作被争议率 `α_c`、幻影/违规动作被争议率 `β_c > α_c`。一次争议使幻觉后验 odds 乘 `β_c/α_c > 1`；`n` 次条件独立争议乘 `(β_c/α_c)^n`。该更新不含模态校准参数，也不含流似然，故在 ECE 失效或流模型幻觉时仍保留检测力。恶意争议会抬高 `α_c`、削弱检测力，故争议只能撤权、不能授权，并受速率/跨源/成本约束。系：R69 的 `(r_res, Δa)` 双通道升级为 `(r_res, Δa, contest)` 三通道，其中 contest 是唯一由受影响者直接产生的通道。

**定理 18（MAGNA 严格包含 R69）** 固定同一组能力模块与观测序列。在 A103–A106（契约健全、模块在作用域内、CGR 批准、ERB 恒批准、LIA 退化为 R69 的 `argmax[VoI−c]`、无争议）下，MAGNA 与 R69 **逐指令相同**。任一闸门触发（out-of-scope、CGR 撤销、ERB deny/downgrade、H/P 违反、争议红旗、K 失效）时，MAGNA 的允许动作集是 R69 的子集，并失败关闭到 R69/R68 保守。因此**安全与伦理违规概率 ≤ R69**；任务效用只在触发约束时以有界弃权/降级成本换规范合规。R69 是 MAGNA 在「单模块 + 全授权 + 审查直通 + 无组合审查」边界上的退化。

**定理 19（非补偿 / 反伦理洗白）** 在 MAGNA 中，`Valid(J) ⇒ H_pass = 1`；而 `H` 的求值变量集与 `T`、`Perf` 不相交。故不存在仅通过调整 `T` 或提升 `Perf` 把 H 违规系统变为 Valid 的路径，即伦理洗白不可达。要改变 `H`，只能改变设计/轨迹，或改变 `H` 本身——后者只能经 `↝_K` 的外部程序，因而必然留下授权与公示痕迹。系：R69 的「花钱买侵入性」在 MAGNA 中被结构性禁止；只能「低侵入优先 + 硬同意约束 + 明确升级审查」。

**定理 20（组合问责与安全降级）** (i) 每个执行动作都有从 K 根到执行模块的授权链与证据链；溯源 DAG 无环，责任切分 `R(a)` 可在 `O(|V|+|E|)` 重建；在碰撞抵抗哈希下，TAT 的篡改以 `1−negl` 概率被检出。(ii) 任一 H 违反、CGR 撤销、ERB deny、作用域 `out`、K 失效都触发失败关闭，延迟 ≤ `D_f`，退化为 R69/R68 保守；执行层仍走 RAS-WM§ 安全包络与 bump-less 交接（继承 R68 定理 15、R69 定理 17），故前向不变集保持、控制连续、无突变。

## 6. 本轮最大风险

**一句话**：MAGNA 的全部伦理收益押在「宪法核心真的不可被俘获、组合审查真的能看见涌现能力」这两个前提上——**若 K 的边界划错，或 CGR 只审模块不审组合，系统就会产出一个「每个零件都通过伦理审查、组合起来却能操纵人」的架构；更糟的是，完整的审计轨迹会让每一方都能说「我只负责我的模块」，责任被切碎成合规流水线——合规不等于正当，模块化最大的伦理风险不是某个模块作恶，而是没有任何一个模块为整体作恶负责。**

## 2. 形式化定义（要点版）

**定义 310–311（总览与双分类契约）** 五不变式：双分类契约、规范不补偿、组合需审查、宪法核心不可优化替换、可争议可追溯。`C_m=(P_m,N_m,K_m,S_m,v_m)`；`P_m` 管端口/假设/保证/预算/截止期，`N_m` 管 H/P/T，`K_m` 管能力/受影响者/用途/模态，`S_m` 是有效作用域。

**定义 312（规范三型）** `H` 硬义务（未同意不探询、接管通道不可隐藏、禁止欺骗性问句、单源不定案）无汇率；`Π` 程序义务（同意、解释、争议受理、撤回、不良事件）带截止期与证据；`T` 交易预算（注意力/隐私/物理/时间/算力）可聚合但受全局上限与公平约束。

**定义 313–314（组合与涌现）** 性能 `⊗` 需 `A_2⊆G_1`，预算相加、作用域取交；规范 `⊓` 做硬义务合取、程序合并、预算相加。`Cap(S)` 是闭环历史—动作关系；`E(S)=Cap(S)\⋃Cap(m)`；`Hcap` 为事前批准危害能力集（操纵/欺骗/胁迫/隐蔽监视/数据外流），`capability-clean ⇔ E(S)∩Hcap=∅` 且数据流服从 `Use_m`。

**定义 315（CGR）** 四步：类型检查、数据/交互流与污点分析、涌现能力检测（静态关系复合 + 动态对抗组合探针）、受影响群体风险与公平；输出 `{approve, mitigate, full_board, deny}`。新边/新能力清单/新作用域均须重跑；CGR 属于 K。

**定义 316（ERB）** 独立信任域、与策略梯度隔离的运行时审查：协议一致、硬义务、授权链/证据、争议红旗；决策 `{approve, downgrade, deny, refer}` + 理由码 + 最小解释种子。常规动作类走缓存；新类/升级/争议同步审查。

**定义 317–318（K 与受保护替换）** `K={CGR,ERB,TAT,RCS,SafetyFilter}`：不可普通替换、不可俘获、不可禁用、最小化；K 的规范义务全是 H 级。普通模块用 `⪯`；K 用 `↝_K`（`⪯` ∧ `H'⊇H` ∧ 外部法定人数 ∧ 公示 `T_pub` ∧ 日落 `T_sunset` ∧ 无利益冲突 ∧ 群体代表）。宪法不变式 `I_K`：所有可达系统满足 K 的 H 且 K 可达/可用。

**定义 319（非补偿有效序）** `Valid ⇔ H ≻ Π ≻ T ≻ Perf` 字典序短路。**伦理洗白** = 仅调整 T/Perf 使 H 违规系统变 Valid；MAGNA 按构造禁止（定理 19）。

**定义 320（BFA 与 LIA）** 群体负担 `B_g`；`B_g≤B_max` 为硬上限，`max_g B_g−min_g B_g≤δ_fair`，最弱势服务下界 `s_min` 为 H 级。LIA：`g*=min_≺{g : E[U_epi|g]≤τ ∧ VoI(g)≥c(g)}`；只有低阶失败/无信息/超时且预算与公平允许才升级。

**定义 321（RCS）** 反馈 `{answer,refuse,contest,counter_question,no_response}`；`Λ_c=β_c/α_c`，更新幻觉后验与协议违反后验。争议**只撤权**（吊销类许可证、降级 shadow、触发 ERB 复审），不直接产生控制；受速率/跨源/成本/信誉约束，且 `d_c` 内必须受理。

**定义 322–323（TAT 与 SGL）** TAT 为只追加哈希链，记录模块版本、契约哈希、授权链、ERB 判决/理由码、证据、人类反馈、吊销事件；`R(a)` 为溯源 DAG 上承重模块的最小责任切分。作用于 `{in,boundary,out}`；`out` 输出 `unknown` 不静默外推；无 `in` 链授权即失败关闭到 R69/R68。

**定义 324–326（威胁/证书/时序）** `ℰ_MAGNA` 增加模块、组合、审查、争议、审计、替换六类；`J_MAGNA` 并入契约 DAG、规范类型、CGR、K 完整性、H/Π/T 分项、负担公平、争议统计、TAT 根；契约/CGR 线下，运行时只做缓存授权、O(|H|) 监视、新类/争议同步 ERB、异步 TAT；换模块只重验影响集。

## 4. 推导

**引理 19（规范合取不补偿）** `H(S)=∧_m H_m|_{S_m}` 的真值只依赖轨迹/上下文与作用域，不依赖 `T`/`Perf`；预算重分配与性能提升不改变 `H`。系：不存在「用成功率抵消未同意探询」的合法评分；`c(g)` 只能进 T，不能进 H。

**引理 20（模块批准不蕴含组合批准）** 存在 `{m_i}` 使 `∀i, m_i∈Approved` 但组合 `S∉Approved`。构造：情感识别 `A` + 主动提问 `B` + 交互记忆 `C`，单独能力为「读情感/发问/记住」；闭环复合后可实现「识别脆弱→高压问句→记住有效话术」的操纵关系，`E(S)∩Hcap≠∅`。要点：能力是关系，闭环与记忆取关系复合的传递闭包，像可严格大于各因子像的并。系：CGR 必须审组合与能力清单。

**引理 21（受保护替换保持宪法不变式）** 若 K 的替换均满足 `↝_K`、普通替换满足 `⪯` 且不改变 K 输入可达性，则任意可达 `S` 满足 `I_K`。归纳：`↝_K` 要求 `H'⊇H` 且有不可禁用条款；`⪯` 不进入 K 信任域。系：「谁来审查审查者」变成类型约束；性能优化选不到宽松审查器。

**引理 22（争议作为独立证据）** `α_c=P(contest|legit)`、`β_c=P(contest|phantom)`，`β_c>α_c`；一次争议使幻觉后验 odds 乘 `β_c/α_c`，`n` 次独立争议乘 `(β_c/α_c)^n`。该更新不含校准参数与流似然，故 ECE 失效或流模型幻觉时仍有检测力；恶意争议抬高 `α_c`，故争议只撤权、不授权。系：R69 的 `(r_res, Δa)` 升级为 `(r_res, Δa, contest)` 三通道。

**定理 18（MAGNA 严格包含 R69）** 固定模块与观测序列；在 A103–A106（契约健全、in-scope、CGR 批准、ERB 恒批准、LIA 退化为 `argmax[VoI−c]`、无争议）下逐指令相同。任一闸门触发时允许动作集是 R69 的子集并失败关闭到 R69/R68 保守，故安全/伦理违规概率 ≤ R69；任务效用只以有界弃权/降级成本换规范合规。R69 = 「单模块 + 全授权 + 审查直通 + 无组合审查」边界。

**定理 19（非补偿 / 反伦理洗白）** `Valid ⇒ H_pass=1`，且 H 的求值变量与 T/Perf 不相交；故不存在仅调 T/Perf 把 H 违规变 Valid 的路径。改变 H 只能改设计/轨迹，或经 `↝_K` 改 H 本身，必然留下授权与公示痕迹。系：R69 的「花钱买侵入性」被结构性禁止。

**定理 20（组合问责与安全降级）** (i) 每个动作有 K 根→执行模块的授权链与证据链；溯源 DAG 无环，`R(a)` 可在 `O(|V|+|E|)` 重建；碰撞抵抗哈希下 TAT 篡改以 `1−negl` 检出。(ii) H 违反、CGR 撤销、ERB deny、scope out、K 失效均触发失败关闭（≤`D_f`）退化为 R69/R68 保守；执行层仍走 RAS-WM§ 与 bump-less 交接（继承 R68 定理 15、R69 定理 17），前向不变集保持、控制连续、无突变。

## 7. 本轮最大风险

**一句话**：MAGNA 的全部伦理收益押在「宪法核心真的不可被俘获、组合审查真的能看见涌现能力」这两个前提上——**若 K 的边界划错，或 CGR 只审模块不审组合，系统就会产出一个「每个零件都通过伦理审查、组合起来却能操纵人」的架构；更糟的是，完整审计轨迹会让每一方都能说「我只负责我的模块」，责任被切碎成合规流水线——合规不等于正当，模块化最大的伦理风险不是某个模块作恶，而是没有任何一个模块为整体作恶负责。**

**次级风险与缓解**：涌现能力漏报（静态流分析 + 动态对抗组合探针 + 高风险强制 full board，E303/E304）；ERB 被俘获/审查疲劳（独立信任域 + 法定人数 + 透明日志 + 随机复审，E314）；恶意争议/DoS（只撤权不授权 + 速率/跨源/成本约束，E306）；宪法核心僵化（最小 K + 日落 + 受保护替换，E307/E308）；公平配置碎片化（统一公平下界 + 分群监控，E309）；接口缝隙/隐式耦合（未申报边 = 证书无效 + 运行时图证明，E301/E310）。
