# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim+++；新灵感循环第 1 轮；本轮灵感：「机器人」×「抓取规划」）

> 第 54 轮已把技能组合推进到动作空间剖面 `α_S`、技能组合图 `G_S`、云边联合证书 `J`。本轮引入「机器人 × 抓取规划」，主张一个更强的命题：**抓取是抽象动作空间与物理世界之间的接地层（grounding layer）**。核心矛盾：H22：动作空间兼容 ≠ 抓取可行——两技能可在同一末端位姿上重叠，却因手型、接触与摩擦约束无法在同一物体上交替；H23：第 54 轮的 `A_cert` 只记录抽象动作占用，没有接触扳手语义，云端几何上「可达」的抓取在边端可能没有力封闭裕度；H24：跨抓取/跨物体的技能组合缺少**受证的交接状态**，位姿切换时的滑移会让组合在真实世界系统性失效。

## 0. 直觉与动机

**灵感 1（抓取 = 动作空间的物理接地）**
直觉：第 54 轮的 `α_S(a)` 回答「这个技能能不能摆到这个末端位姿」，但没有回答「摆到位姿之后，手到底能不能抓住物体」。抓取规划给出的正是后者：一个抓取 `g` 由手相对物体的位姿、手型预成形、接触点集、摩擦系数和抓取映射组成；它把「末端动作」翻译成「物体扳手」。因此应存在一个**接地映射** `β_S : a ↦ {g}`，技能的可行性不是 `α_S(a)=1`，而是 `β_S(a)` 中存在一个**力封闭裕度足够**的抓取。动作空间是投影，接触/扳手空间才是本体。

**灵感 2（兼容性必须从位姿交集下沉到抓取交集）**
直觉：两个技能「动作兼容」只说明它们的末端位姿集合有交集 `A_i ∩ A_j ≠ ∅`。但真正能组合，需要存在同一物体上的 `g_i ∈ β_{S_i}(a)`、`g_j ∈ β_{S_j}(a')` 以及一条受证的过渡。位姿重叠是**必要不充分**：一个平行夹爪的顶部包络抓取与一个侧向捏取，可以共享同一个末端朝下位姿，却无法对同一个粗圆柱完成交接。把兼容性从 `α` 的 Jaccard 下沉到 `β` 上的抓取可行性，是第 54 轮组合图必须补的物理约束。

**灵感 3（组合的真正断点在交接，而不是在技能内部）**
直觉：单技能抓取成功已经很难，但组合失败最常发生在「换手/换抓取」的一瞬间：物体被放下、滑移、滚动，再抓时几何与质心都变了。因此组合是否可行，不应只看相邻技能的动作重叠，而应看**抓取转移图**上是否存在受证的交接：要么是接触连续的**手内重抓**（in-hand regrasp），要么是经过一个**稳定放置 hub** 的「放下—再抓」（place-and-regrasp）。这把组合可判定性问题转化为一张带 hub 的有限图上的路径存在性。

**灵感 4（抓取鲁棒性 = 第 53 轮 ρ 的新维度族）**
直觉：第 53 轮把鲁棒性写成维度谱 `ρ(d)`。抓取天然提供一组新的维度：摩擦 `μ`、位姿误差 `δT`、物体质量/质心 `m_o,c_o`、触觉噪声、表面状态。抓取的「稳」不是单个成功概率，而是在这些维度上的**扳手裕度谱** `ρ_g(d)`；它与第 54 轮的 `ρ` 可拼接成同一个证书，只是把抽象鲁棒性落到了摩擦锥和接触力上。

**灵感 5（云边协同的接触级闭环）**
直觉：云端擅长物体中心几何候选生成（看到物体，枚举抓取位姿），边端擅长力控与触觉（真实摩擦、滑移、接触力）。这时第 54 轮的 `γ_ce : A_c → A_e` 应升级为「抓取候选 → 接触力执行」的映射：云端下发的每个候选必须附**保守扳手裕度** `m_c` 与安全缓冲 `κ_g·δ_g`；边端估计真实 `m_e`，若 `m_e < ε_min`，反向解释信道返回「哪个手指、哪个接触、哪种摩擦假设失败」，云端据此重新接地（regrounding），而不是只重规划动作。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（抓取原语与接触集）**
物体 `O` 上的抓取 `g = (T_g, q_g, C_g, μ_g, G_g)`：`T_g ∈ SE(3)` 为手相对物体的位姿，`q_g ∈ Q` 为手型预成形，`C_g = {(p_i, n_i, f_i)}_{i=1}^{k}` 为接触集（接触点、法向、接触力），`μ_g = (μ_1,…,μ_k)` 为摩擦系数，`G_g ∈ ℝ^{6×3k}` 为抓取映射。物体扳手 `w = G_g f`，`f = (f_1,…,f_k) ∈ ℝ^{3k}`。

**定义 122（力封闭与鲁棒扳手裕度）**
摩擦锥 `FC_i(μ_i) = {f_i : ‖f_{i,t}‖ ≤ μ_i f_{i,n}, f_{i,n} ≥ 0}`，其线性化内接多面体记 `FC_i^ℓ ⊆ FC_i`。可达扳手集 `W_g(μ) = {G_g f : f_i ∈ FC_i^ℓ(μ_i)}`。称 `g` 力封闭当且仅当 `0 ∈ int W_g`。**扳手裕度**取 Ferrari–Canny 型
```
ε(g; μ) = sup { ε ≥ 0 : ε·B_∞^6 ⊆ W_g(μ) }
```
其中 `B_∞^6` 为单位 `L∞` 球。给定不确定性集 `U`（摩擦、位姿、质量、质心、触觉），**鲁棒裕度**
```
m_ρ(g) = inf_{u ∈ U} ε(g; u)          （worst-case）
  或   m_ρ(g) = Quantile_α{ ε(g;u) : u ∼ P_U }（风险敏感）
```
称 `g` 为 `ε_min`-鲁棒当且仅当 `m_ρ(g) ≥ ε_min`。

**定义 123（抓取接地映射与接地覆盖）**
设 `π : 𝒢 → A` 为抓取到末端动作的投影。技能 `S` 在动作 `a` 上的抓取接地集
```
β_S(a) = { g : π(g) = a, g 在 O 上可行, m_ρ(g) ≥ ε_min }。
```
接地剖面 `α^g_S(a) = max_{g ∈ β_S(a)} m_ρ(g) / ε_max`（`β_S(a)=∅` 时取 0）。**接地覆盖**
```
cov_g(S, A_T; O) = 1  ⇔  ∀ a ∈ A_T : α^g_S(a) ≥ θ_g。
```
注意 `α^g_S(a) > 0 ⇒ α_S(a) = 1`，但反向不成立；这正是 H22 的形式化。

**定义 124（动作–抓取兼容性）**
```
compat_g(S_i, S_j; O) = 1 ⇔ ∃ a ∈ A_i, a' ∈ A_j, g_i ∈ β_{S_i}(a), g_j ∈ β_{S_j}(a'),
                            τ(g_i → g_j) 受证（见定义 125）且 c_trans(a,a') ≤ τ_e。
```
**分离引理（action compatibility ⇏ grasp compatibility）**：存在技能对与物体 `O`，使第 54 轮 `compat(S_i,S_j) ≥ θ_a` 而 `compat_g(S_i,S_j;O)=0`。
*构造*：取粗圆柱 `O`（半径大于夹爪最大开度），`S_i` 为顶部包络抓取，`S_j` 为侧向捏取；二者共享同一个末端朝下位姿 `a`（故 `A_i∩A_j` 非空、`compat=1`），但 `β_{S_i}(a) ∩ β_{S_j}(a) = ∅`，且任意 hub 处无法从包络抓取连续过渡到捏取，故 `compat_g=0`。证毕。

**定义 125（受证交接与稳定放置 hub）**
交接 `τ(g_i → g_j)` 合法，当且仅当属于以下之一：
1. **手内重抓**：存在接触连续证书 `(C_cont, m_cont)`，`m_cont = inf_t m_ρ(g(t)) ≥ ε_min`，即过渡轨迹上每一时刻都保持 `ε_min`-鲁棒；
2. **放置–再抓**：存在稳定放置 hub `h = (T_h, SP(h), m_h, q_place)`，支撑多边形 `SP(h)` 满足 CoM 投影落在其内且距离边界 `≥ δ_h`，稳定裕度 `m_h ≥ m_hmin`；`g_i` 能放到 `h`，`g_j` 能从 `h` 抓起，且放置后物体位姿漂移 `≤ δ_h`。

**定义 126（抓取转移图）**
抓取转移图 `G_g = (V_g, E_g)`：`V_g = {(S,g)} ∪ H`（技能–抓取节点与稳定 hub），`E_g` 含执行边、手内重抓边、放置边、拾取边；每条边附交接证书 `C_edge = (type, m_min, c_regrasp, δ_h)`。一次任务动作序列 `A_T` 在 `O` 上可组合，当且仅当 `G_g` 中存在一条覆盖 `A_T` 的路径且所有边证书成立。

**定义 127（不确定性抓取鲁棒谱）**
维度族 `D_g = {μ, δT, m_o, c_o, tactile, surface}`。对 `d ∈ D_g` 定义
```
ρ_g(d) = P_{u_d ∼ P_d}( ε(g; u_d) ≥ ε_min )，
```
并在聚合时取 `ρ_g^min = min_{d∈D_g} ρ_g(d)`。称抓取鲁棒当且仅当 `ρ_g^min ≥ ρ_min`。该谱与第 53 轮 `ρ(d)` 同型，可直接并入统一鲁棒性证书。

**定义 128（接地联合证书）**
```
J_g = (J, G_cert, β_S, κ_g, δ_g, evidence)
G_cert = (g, W_g, m_ρ(g), C_g, μ_prior)
```
一致性条件：
```
(C1) ∀ a ∈ A_core : α^g_S(a) ≥ θ_g                    （动作核心被接地覆盖）
(C2) m_e ≥ ε_min + κ_g·δ_g,  δ_g = |m_c - m_e| / m_c   （云边扳手裕度对齐）
(C3) G_g 上存在覆盖 A_T 的受证路径                       （交接可判定）
```
若 `J` 可部署且 `J_g` 满足 `(C1)–(C3)`，称组合在物体 `O` 上**接地可部署**。

## 2. 关键算法 伪代码

### IP-121 GGP（Grasp Grounding Profile）

```python
def grasp_grounding_profile(skill, A_S, O, epsilon_min, U, n_samples):
    beta = {}
    for a in A_S:
        cands = grasp_sampler.sample(O, project_inverse(a), n=n_samples)
        beta[a] = [g for g in cands if is_force_closure(g) and
                   robust_margin(g, U) >= epsilon_min]
    alpha_g = {a: (max(robust_margin(g,U) for g in beta[a]) / EPS_MAX
                   if beta[a] else 0.0) for a in A_S}
    return alpha_g, beta

def grounded_cover(alpha_g, A_T, theta_g=0.6):
    return all(alpha_g.get(a, 0.0) >= theta_g for a in A_T)
```

### IP-122 WCEM（Wrench Closure Ellipsoid Margin）

```python
def wrench_margin(g, mu, linearize='inscribed'):
    # W_g = G_g · FC^l(mu)；用 LP 求最大内接 L∞ 球半径（Ferrari–Canny 对偶）
    G = g.grasp_map
    FC = build_linearized_friction_cones(g.contacts, mu, linearize)
    # max eps s.t. 对每个 +-e_j 方向存在 f in FC 使 G f = eps e_j
    eps = lp_inscribed_linf_radius(G, FC)
    return eps

def robust_margin(g, U, mode='worst_case', alpha=0.05):
    if mode == 'worst_case':
        return min(wrench_margin(g, u) for u in U.enumerate_vertices())
    samples = [wrench_margin(g, u) for u in U.sample(alpha)]
    return quantile(samples, alpha)
```

### IP-123 GCA（Grasp Compatibility Algebra）

```python
def build_grasp_transition_graph(skills, O, hubs, epsilon_min, tau_e):
    G = nx.DiGraph()
    for s in skills:
        for a, gs in s.beta.items():
            for g in gs:
                G.add_node((s.id, g.id), grasp=g, margin=m_rho(g))
    for u, v in product(G.nodes, G.nodes):
        if u[1] == v[1]:
            continue
        if pi(u.grasp) != pi(v.grasp) and c_trans(u, v) > tau_e:
            continue
        if in_hand_continuous(u.grasp, v.grasp, epsilon_min):
            G.add_edge(u, v, type='in_hand', cert=contact_cert(u, v))
    for h in hubs:
        G.add_node(h.id, hub=h)
        for u in G.nodes:
            if can_place(u.grasp, h) and stable(h) >= M_H_MIN:
                G.add_edge(u, h.id, type='place', cert=place_cert(u, h))
            if can_pick(h, u.grasp) and stable(h) >= M_H_MIN:
                G.add_edge(h.id, u, type='pick', cert=pick_cert(h, u))
    return G
```

### IP-124 GRASP-PLAN（接地组合规划）

```python
def grasp_plan(A_T, G_g, cost_w=(1.0, 1.0, 1.0)):
    # 在 G_g 上找覆盖 A_T 的路径，最小化 时间 + (1-裕度) + 对齐误差
    def cost(u, v, e):
        return (cost_w[0]*e.c_regrasp
                + cost_w[1]*(1 - min_margin(u, v))
                + cost_w[2]*e.alignment_drift)
    return a_star_state_space(G_g, goal=cover_set(A_T), edge_cost=cost)
```

### IP-125 UGR（Uncertainty-aware Grasp Robustness）

```python
def grasp_robustness_spectrum(g, dims, n=2048):
    rho_g = {}
    for d in dims:
        samples = [perturb(g, d, u) for u in sample_uncertainty(d, n)]
        ok = [wrench_margin(gs) >= EPS_MIN for gs in samples]
        rho_g[d] = mean(ok)
    return rho_g  # min over dims compared with rho_min

def calibrate_sim_to_real(g, real_trials, eta_sr_budget):
    gap = abs(real_trials.margin_mean - wrench_margin(g, real_trials.mu))
    if gap > eta_sr_budget:
        return ('reject', 'sim_to_real_gap', gap)
    return ('ok', gap)
```

### IP-126 CGC（Contact-Grounded Cloud-Edge Coordination）

```python
def cloud_grasp_candidates(O_cloud, A_c, epsilon_min, kappa_g, delta_g_budget):
    cands = []
    for a_c in A_c:
        for g_c in geometry_grasp_sampler(O_cloud, a_c):
            m_c = robust_margin(g_c, nominal_uncertainty(O_cloud))
            if m_c >= epsilon_min + kappa_g * delta_g_budget:
                cands.append(GraspCand(g_c, m_c, A_cert(a_c), delta_g_budget))
    return cands

def edge_contact_refine(cands, force_ctrl, sim_model, epsilon_min):
    reports = []
    for c in cands:
        m_e = force_ctrl.estimate_margin(c.g, tactile=True)
        slack = m_e - epsilon_min
        if slack < 0:
            exp = explain_contact_failure(force_ctrl.trace, c.g)
            reports.append(ContactExplain(c, failure='force_closure',
                                          fingers=exp.fingers, mu_drop=exp.mu_drop))
            continue
        if m_e < c.m_c - c.kappa_g * c.delta_g:
            reports.append(ContactExplain(c, failure='margin_mismatch',
                                          m_c=c.m_c, m_e=m_e))
    return reports  # 回传云端触发 regrounding，而非仅重规划动作

def reground(cands, reports):
    failing = {(r.c.g.id): r for r in reports}
    return [c for c in cands if c.g.id not in failing]
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| GGP | `O(|A_S|·n·LP(k))` | `O(|A_S|·n)` | 抓取采样覆盖、`m_ρ` 保守 |
| WCEM | `O(LP(6,3k))` 每次 | `O(3k)` | 摩擦锥内接（偏保守）、裕度定义一致 |
| GCA | `O((|S|·n)^2·T_cont + |H|·|V|)` | `O(|V|^2)` | 交接证书 sound、hub 稳定判定 |
| GRASP-PLAN | `O(|E_g| log |V_g|·C)` | `O(|V_g|+|E_g|)` | 边成本单调、覆盖目标可判定 |
| UGR | `O(|D_g|·n·LP(k))` | `O(|D_g|·n)` | 不确定性集覆盖、分位数校准 |
| CGC | `O(|A_c|·n + |C|·T_est)` | `O(|C|)` | 云端保守下界、回传延迟有界 |

**正确性定理（Grounded Grasp-Composition Soundness）**
承接第 54 轮 `(A26)–(A28)`。新增假设：
- **(A29)** 摩擦锥线性化误差 `≤ η_fc`（采用内接多面体时 `η_fc` 为已知保守量）；
- **(A30)** 仿真–真实接触差距 `|m_real(g) - m_sim(g)| ≤ η_sr`，位姿估计误差 `≤ δ_T`；
- **(A31)** 每条组合过渡要么有手内接触连续证书，要么经过 `m_h ≥ m_hmin` 的稳定 hub。

则真实物体 `O` 上的部署成功概率满足
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - P(δ_a > Θ_a)
              - P(compat_g 误报) - P(m_e < ε_min + κ_g δ_g)
              - β_E - η_fc - η_sr
```
**推导要点（union bound）**：成功需要同时满足 (i) 第 54 轮动作–鲁棒性条件；(ii) 每个 `a ∈ A_core` 有 `ε_min`-鲁棒抓取（`G_cert`）；(iii) 交接路径存在且每条边证书成立（`G_g`）；(iv) 云边扳手裕度对齐 `(C2)`；(v) 执行阶段真实裕度未跌破 `ε_min`。对五个互斥失败事件取并集上界，其中 (ii)(iii) 的失败由 `ρ_g^min` 与 `compat_g` 误报控制，(iv) 由 `κ_g` 缓冲控制，(v) 由 `η_fc+η_sr` 控制。故得上式。`κ_g ≥ 1` 时缓冲吸收最坏对齐漂移，证书 sound 但保守；`κ_g < 1` 时不再 sound。

**关键推论（兼容性下沉的必要性）**：仅用第 54 轮 `compat` 判定的组合，其真实成功率上界被 `1 - P(compat_g 误报)` 截断；当物体使 `compat=1` 而 `compat_g=0` 时，上界退化为 0。故 `G_g` 不是优化项，而是 soundness 的必要条件。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 抓取采样偏差导致 `β_S` 假空/假满 | 高 | 分层采样 + 主动触觉探索 + 覆盖率证书 |
| 摩擦锥线性化过松导致裕度假高 | 高 | 只用内接多面体（保守）+ `η_fc` 计入证书 |

def grasp_grounding_profile(skill, A_S, O, epsilon_min, U, n_samples):
    beta, alpha_g = {}, {}
    for a in A_S:
        cands = grasp_sampler.sample(O, project_inverse(a), n=n_samples)
        beta[a] = [g for g in cands
                   if is_force_closure(g) and robust_margin(g, U) >= epsilon_min]
        alpha_g[a] = (max(robust_margin(g, U) for g in beta[a]) / EPS_MAX
                      if beta[a] else 0.0)
    return alpha_g, beta

def grounded_cover(alpha_g, A_T, theta_g=0.6):
    return all(alpha_g.get(a, 0.0) >= theta_g for a in A_T)

### IP-122 WCEM

```python
def wrench_margin(g, mu, linearize='inscribed'):
    G = g.grasp_map
    FC = build_linearized_friction_cones(g.contacts, mu, linearize)
    # LP 对偶：max eps s.t. 每个 ±e_j 方向存在 f∈FC 达到 eps
    return lp_inscribed_linf_radius(G, FC)

def robust_margin(g, U, mode='worst_case', alpha=0.05):
    if mode == 'worst_case':
        return min(wrench_margin(g, u) for u in U.vertices())
    return quantile([wrench_margin(g, u) for u in U.sample(alpha)], alpha)
```

### IP-123 GCA

```python
def build_grasp_transition_graph(skills, O, hubs, epsilon_min, tau_e):
    G = nx.DiGraph()
    for s in skills:
        for a, gs in s.beta.items():
            for g in gs:
                G.add_node((s.id, g.id), grasp=g, margin=robust_margin(g, U))
    for u, v in product(G.nodes, G.nodes):
        if u[1] == v[1] or c_trans(u, v) > tau_e:
            continue
        if in_hand_continuous(u.grasp, v.grasp, epsilon_min):
            G.add_edge(u, v, type='in_hand', cert=contact_cert(u, v))
    for h in hubs:
        G.add_node(h.id, hub=h)
        for u in G.nodes:
            if can_place(u.grasp, h) and stable_margin(h) >= M_H_MIN:
                G.add_edge(u, h.id, type='place', cert=place_cert(u, h))
            if can_pick(h, u.grasp) and stable_margin(h) >= M_H_MIN:
                G.add_edge(h.id, u, type='pick', cert=pick_cert(h, u))
    return G
```

| CGC | `O(|A_c|·n + |C|·T_est)` | `O(|C|)` | 云端下界 + `κ_g` 缓冲 |

**正确性定理（Grounded Grasp-Composition Soundness）**
承接 `(A26)–(A28)`，新增 `(A29)` 摩擦锥线性化误差 `≤ η_fc`；`(A30)` 仿真–真实差距 `≤ η_sr`、位姿误差 `≤ δ_T`；`(A31)` 每条过渡受证（手内连续或稳定 hub）。
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - P(δ_a>Θ_a)
              - P(compat_g 误报) - P(m_e < ε_min + κ_g δ_g)
              - β_E - η_fc - η_sr
```
**证明概要**：定义失败事件 `F = F_act ∪ F_grasp ∪ F_handoff ∪ F_align ∪ F_exec`。`F_act` 由第 54 轮动作–鲁棒性谱控制；`F_grasp` 由 `ρ_g^min < ρ_min` 控制；`F_handoff` 由 `compat_g` 误报与 hub 失稳控制；`F_align` 由 `m_e` 跌破 `ε_min+κ_gδ_g` 控制；`F_exec` 由 `η_fc+η_sr` 控制。对并集取 union bound，并注意内接锥只会**低估** `W_g`、故 `ε` 不会高估真实裕度（`η_fc` 单侧方向安全），得证。

**分离引理（本轮核心负结果）**：存在 `compat(S_i,S_j)=1` 而 `compat_g(S_i,S_j;O)=0` 的技能对（粗圆柱：顶部包络 vs 侧向捏取）。因此任何仅基于第 54 轮 `α_S` 的组合图，其可部署性上界都不高于 `1 - P(compat_g 误报)`；`compat` 高不代表抓得住，`G_g` 是 soundness 的必要构件而非可选优化。

## 5. 解析推演：两指抓取的裕度–摩擦关系（非实测）

考虑质量 `m_o=0.5 kg`、重力 `g=9.8 m/s²`、双指对置抓取（2 个接触）。设每次抓取的切向承载为 `f_t`，法向夹持力为 `f_n`，则需要 `2 μ f_n ≥ m_o(a+g)`，即
```
f_n ≥ m_o(a+g) / (2μ)。
```
取 `a=1g`（含竖直加速度扰动）：

| `μ` | 所需 `f_n` (N) | 夹爪上限 10 N 时 |
|---:|---:|---|
| 0.5 | 9.80 | 裕度紧张 |
| 0.4 | 12.25 | 不可行 |
| 0.3 | 16.33 | 不可行 |

名义 `μ=0.5` 时 LP 给出的 `ε≈0.08`；当不确定性集 `U={μ∈[0.3,0.6]}` 时，`m_ρ = ε(μ=0.3) < 0`（因所需夹持力超过上限），证书正确判定**非鲁棒**。若沿用"名义 μ 下二值力封闭"判定，则会误判为可行——这正是 H23 的量化体现。该推演用于确定 E163/E165 的扰动范围，**不代表真实硬件测量**。
