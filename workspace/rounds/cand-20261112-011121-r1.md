# 第 58 轮（承接第 57 轮「少样本×多模态×个性化」IP-133~138；灵感循环第 4 轮；本轮灵感：「容错控制」×「长期记忆」）

> 第 57 轮用"摊销先验 + 共形保底 + 跨模态对账 + 个性化有界"把安全的赌注从"证据质量"再往前推了一层，但它有两个未言明的结构假设：**(a)** 它默认机器本身是健康的——OOD 门把"世界变了"与"我坏了"当成同一件事，一个卡死/漂移的传感器和一片真正的新材质在残差空间里长得一模一样；第 57 轮没有任何关于"自身传感/执行/判定链故障"的概念。**(b)** 它把 𝓜 与 𝒟_meta 当成本轮内的持久地图，却没有长期记忆的理论——巩固、遗忘、溯源、投毒、跨会话复用全缺；"坏证据长寿"（第 56 轮）与"坏先验普遍"（第 57 轮）在记忆真正长期化之后会成倍放大：一条被巩固的错误记忆会被未来每一次检索复用，一次投毒会污染整个车队。本轮两个灵感各补一根承重梁：**容错控制**给系统一个"我坏了吗"的自我模型和一条"在收缩的包络里如实继续工作"的路径；**长期记忆**给它一份"能巩固而不放大错误、能遗忘而不抹掉教训、任何信念都能回溯到证据"的记忆。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据承诺"升级为 **"可诊断、可重构、可遗忘、可追溯的证据承诺"**。

核心矛盾：
- **H29（故障 vs 新颖的不可辨识）**：残差同形。把故障误判为新颖 ⇒ 控制器在坏传感器上"适应"出一个幻觉世界；把新颖误判为故障 ⇒ 控制器把真信号当噪声重构掉，自信地开进一个它拒绝看见的世界。容错控制想"继续工作"、安全想"停下"，二者都不能取极端——永远停摧毁可用性，永远适应摧毁安全。
- **H30（记忆是资产也是负债）**：巩固是放大器，巩固什么就放大什么；遗忘是必要的，但忘掉近失（near-miss）会致命；静默覆盖（干扰）会让一条自信的错误新记忆替换掉正确的旧记忆，且无人察觉。
- **H31（优雅降级 vs 沉默能力丧失）**：一个悄悄以额定速度运行的降级控制器，比一个明确停下的控制器更危险；但过早宣告降级会摧毁可用性。降级必须**如实且被宣告**，且宣告的包络必须真正包住实际工作点。

## 0. 直觉与动机

**灵感 1（容错控制 → 故障-新颖性联合诊断 + 解析冗余）**
直觉：系统需要一个"我坏了吗"的自我模型。工程上的容错控制靠**解析冗余**：同一物理量用相互独立的通道估计，看残差指向哪个通道坏了。但机器人现场真正的歧义是：单传感器卡死与"世界真的变了"产生同样的残差。判别钥匙在于**故障是通道局部的、新颖是通道全局且物理自洽的**——一个通道离群、其余通道彼此一致 ⇒ 更像故障；所有通道一致偏离、但彼此仍落在物理自洽的"世界变化流形"上 ⇒ 更像新世界。第 57 轮的跨模态分歧在这里换了用途：它不再只是"不确定性下限"，而是**故障/新颖的判别器**。而且必须允许第三种回答"我分不清"（⊥）；此时取故障与新颖两种解释下安全包络的**交集**——弃权的代价是保守，不是冒险。

**灵感 2（容错控制 → 可重构能力包络，而不是二值停/走）**
直觉：传统安全是"停/走"二值；容错控制给的是**连续的、可声明降级的能力包络** 𝓔=(限速, 可用步态集, 接触力上限, 自主级, 允许接触等级)。故障 ⇒ 包络单向收缩；恢复 ⇒ 需证据门 + 驻留时间 + 有界速率扩张。控制器只在**已认证包络** 𝓔_cert 内运行，且必须向人**如实宣告**当前包络——降级可以说出口，不能悄悄装作没降。

**灵感 3（长期记忆 → 分层记忆 + 凭证巩固 + 安全钉住）**
直觉：记忆不是一块黑板，而是**工作/情景/语义/元**四层，越往上寿命越长、影响越广。**巩固是放大器**：一条坏 episodic 一旦升为 semantic，就会被未来所有检索复用。所以晋升必须过"巩固凭证"（独立证据足够、无未决证伪、校准稳定、溯源完整、非仅来自可疑通道）。遗忘按层有界 TTL + 效用驱逐，但**安全钉住类**（近失、证伪事件、同意记录）永不遗忘——"忘掉日常，绝不忘记近失"。

**灵感 4（长期记忆 → 溯源-污染传播，禁止记忆洗白）**
直觉：每条语义记忆保留指向其情景证据的依赖边。一旦某条证据被证伪，污染沿图**向后代传播**：所有由它派生的记忆一起降级/隔离。这堵住"记忆洗白"——一条坏记忆换个推导路径重新出现。第 57 轮的"事后证伪回溯"从单模态升级为整张记忆图。

**灵感 5（合流 → 健康记忆 + 容错检索 + 诊断探针）**
直觉：系统用长期记忆记自己的病：故障史、包络轨迹、恢复事件、金标核对结果 ⇒ 复发预测与如实降级宣告。检索在故障时**改道健康通道**（视觉坏了就只取触觉验证过的记忆），全通道失效则返回"不可用"而非陈旧默认。PCE++ 的探针获得双重价值：既降信念不确定性，也能**主动隔离故障**（主动容错）；并保留少量"金标探针"预算，专门用来区分"世界变难了"与"我变差了"。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（故障-新颖性判别 FND）** 通道残差 z_m=standardize(o_m−ĥ_m)，故障库 ℱ={f_1..f_K}，新颖模型 𝒩。一致性核 a(z_m,z_{m'})∈[0,1] 度量两通道偏移落在物理"世界变化流形"上的程度。局部离群 L(r)=max_m(1−max_{m'≠m} a(z_m,z_{m'}))；全局一致 G(r)=min_m max_{m'≠m} a(z_m,z_{m'})。后验 p_f(k|r), p_n(r), p_⊥=1−max。判别：`f_k` 若 argmax 为故障 ∧ L 高 ∧ 该通道偏移不在 𝒩 流形上；`novelty` 若 G 高 ∧ 整体偏移离开名义模型；否则 `⊥`。校准契约：P(diag=novelty|真故障)≤δ_fn（危险方向），P(diag=fault|真新颖)≤δ_nf（可用性方向）。各标签附包络候选：故障⇒𝓔_cert(f_k)，新颖⇒𝓔_cert(𝒩)，⊥⇒两者交集。

**定义 140（可认证包络自适应 CEA）** 能力包络 𝓔=(v_max,Gait,F_max,Auto,L_set)，名义 𝓔_nom，认证 𝓔_cert(diag)⊆𝓔_nom。**运行不变量**：任意时刻实际指令 u∈𝓔_cert。收缩：任一非名义诊断 ⇒ 单调收缩（不可逆于同一会话，除非证据门通过）。扩张：需 J_d 证据门 ∧ 驻留 T_dwell ∧ 速率 ≤Δ_env。**诚实不变量**：面向人宣告的包络 𝓔_ann 满足 u∈𝓔_ann⊆𝓔_cert，且 𝓔_ann 变化必须记入健康账本并可见。

**定义 141（分层长期记忆 HML）** 层级 L0 工作（会话）/L1 情景（TTL_1）/L2 语义·图式（TTL_2）/L3 元先验（部署期）。钉住集 𝒫（近失、证伪事件、同意记录、安全边界）永不驱逐。巩固凭证 κ_cons(e)：①独立证据数 ≥n_c；②e 的溯源上无未决证伪；③窗口内校准稳定；④溯源完整（无缺失边）；⑤非仅来自可疑通道。冲突处理：节点带版本，新版本只有在证据门不弱于旧版本时才覆盖，否则两版并存并标记 `conflict`（禁止静默覆盖）。

**定义 142（溯源-污染图 PTG）** 溯源 DAG G_mem=(V,E)，边由记忆指向其证据/父记忆。污染度 τ(v)∈[0,1]；证伪源置 τ=1，按 τ(v)=min(1, max_{u→v}(τ(u)·decay(depth)) ) 向后代传播。**禁止洗白**：重新推导不得把 τ 降到继承值以下，除非引入全新的、独立且未污染的证据。τ>θ_taint 的节点降级/隔离并从检索中排除。

**定义 143（健康记忆 SHR）** 健康状态 h_t=(fault_history, envelope_trajectory, recovery_events, gold_outcomes, recurrence_stats)。复发模型按上下文（区域/季节/传感器）预测故障；复发后验高 ⇒ 预测性收缩。**金标核对**：预算 k_gold，经一条**不被当前故障假设牵涉**的通道做可确认/否认"世界 vs 自身"的核对。漂移检测：持续 OOD 且连续 W 个会话无金标确认 ⇒ 把 novelty 重分类为 suspected fault，并隔离/降级由该可疑通道派生的记忆。

**定义 144（容错证据门 FTE+ 与诊断证书 J_d）** 在第 57 轮证据门上追加三项：①**通道健康证明**（证据来源不在故障集中）；②**检索改道**（记忆只经健康通道取回）；③**无污染记忆**（所用记忆 τ≤θ_taint）。J_d=(diag, env_cert, health_snapshot, prov_snapshot, taint_log, gold_log, reroute_log)。硬规则：`diag=⊥` 或未诊断时，仅允许 EV-probe\*/EV-margin，EV-xmodal 与 EV-human 降级（跨模态一致性恰是故障最先污染的东西；人也可能在看一块坏显示屏）。

## 2. 关键算法伪代码（完整版见产物区）

```python
def diagnose(M, r, obs, model, fault_bank, health):   # IP-139: 故障 vs 新颖
    z = {m: standardize(residual(obs[m], model[m])) for m in obs}
    L = max((1 - max(agree(z[m], z[mm], manifold=model.W) for mm in z if mm != m))
            for m in z)
    G = min(max(agree(z[m], z[mm], manifold=model.W) for mm in z if mm != m)
            for m in z)
    pf = max(post_fault(f, z) for f in fault_bank)
    pn = post_novelty(z, model)
    if max(pf, pn) < theta_diag:
        return Diag('unknown', env=intersect(env_cert(fault_bank), env_cert_novelty()))  # 弃权→交集
    if pf >= pn and L > delta_loc and not on_manifold(z, model.W):
        return Diag(argmax_fault(fault_bank, z), env=env_cert(f))
    return Diag('novelty', env=env_cert_novelty(health, gold=health.gold_outcomes))

def reconfigure_envelope(env, diag, ev):               # IP-140: 只缩不冒进
    if diag.label != 'nominal':
        env = shrink(env, diag.env)                    # 非名义→单调收缩
    if ev.certified and diag.label == 'nominal' and env.dwell >= T_DWELL:
        env = expand_bounded(env, rate=DELTA_ENV, gate=evidence_gate)  # 恢复有据有界
    announce(env)                                      # 诚实不变量：u∈E_ann⊆E_cert
    return env
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| FND | O(\|ℳ\|²·d) / 检查点 | O(\|ℱ\|) | δ_fn/δ_nf 声明诚实、⊥ 走最保守交集 |
| CEA | O(1)/指令 | O(1) | 运行不变量 u∈𝓔_cert、诚实不变量 |
| HML | O(log\|V\|)/读写 | O(\|V\|·d) | 巩固凭证完备、钉住集永不驱逐 |
| PTG | O(\|V\|+\|E\|) 增量传播 | O(\|V\|+\|E\|) | 污染传播完备、禁止洗白 |
| SHR | O(1)+O(H) | O(\|操作者\|+\|会话\|) | 复发预测保守、金标独立 |
| FTE+ | O(\|σ\|+\|V\|) | O(\|σ\|+\|V\|) | 无健康证明即拒、⊥ 降级 xmodal/human |

**正确性定理（FTAM：Fault-Tolerant Accountable Memory，概要）**：在 A33–A40 上加 (A41) 故障库覆盖且判别混淆有界（真故障漏判为新颖 ≤δ_fn，真新颖误判为故障 ≤δ_nf）；(A42) 巩固健全（坏记忆被晋升概率 ≤δ_cons；钉住集永不驱逐；污染传播完备）；(A43) 包络单调与诚实（不确定下只缩；扩张有据有界；宣告包络包住实际工作点）；(A44) 检索改道诚实（全通道失效返回"不可用"而非陈旧默认）。则：(i) **故障-新颖健全性**：把故障当新颖继续承诺的概率 ≤δ_fn+δ_diag，把新颖当故障的可用性损失 ≤δ_nf（不是安全损失）；(ii) **记忆不放大**：坏记忆经巩固被放大的概率 ≤δ_cons，且证伪沿溯源图不可洗白地传播；(iii) **降级诚实**：不存在"悄悄超出认证包络运行"的路径，降级必被宣告；(iv) **优雅终止**：歧义在 k_probes+k_diag+k_gold 内未消解 ⇒ 最小包络 → 安全停。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 故障被记忆正常化（适应到坏传感器上） | 高 | 金标核对 + 持续 OOD 重分类 + 可疑通道记忆隔离、不巩固 |
| 故障库盲区 ⇒ 真实故障落进 ⊥ 或被当新颖 | 高 | ⊥ 取最保守交集 + 未知故障默认收缩 + 主动诊断探针 |
| 污染传播不完整 / 记忆洗白 | 高 | 溯源图强制完整、重推不得降 τ、隔离检索 |
| 遗忘误删关键教训 | 中 | 安全钉住集 + 分层 TTL + 遗忘审计 |
| 包络宣告与实际不一致 | 中 | 诚实不变量 + 宣告审计 + 不一致即安全停 |
| 车队记忆交叉污染 | 中 | 记忆过隔离区 + 接收端本地再认证后才采纳 |

## 6. 本轮最大风险

**一句话**：容错控制让系统"在降级中继续工作"、长期记忆让系统"把经验固化下来"，两者合流会制造一种新的系统性失效——**故障被记忆正常化**：一个持续故障先被误判为"新世界"，再被巩固成语义记忆、扩散到后续会话乃至整个车队，系统于是在一个越来越小的包络里稳定运行，并把"我变差了"记成"世界变难了"；必须以独立金标探针持续区分"世界 vs 自身"、把可疑通道派生的记忆钉住隔离且禁止巩固、并让污染沿溯源图不可洗白地传播，否则容错机制本身就成了把故障洗成长期信念的机器。

# 第 58 轮产物 · 创新点清单 v34：FaultTolerant-Memory（故障-新颖判别×可认证包络×分层记忆×溯源污染，FND×CEA×HML×PTG×SHR×FTE+）

> 承接第 57 轮 IP-133~138（MFSL/XMC/PTM/MXI/FSE/PCE+）、第 56 轮 IP-127~132（SMM/PCE/BVK/ISE/TAF/MEC）与第 55 轮 IP-121~126（SCG/WBV/SSF/SCC/SRS/CEB）。本轮把部署前提从"少样本可校准、跨模态可对账、个性化有界的证据承诺"升级为 **"可诊断、可重构、可遗忘、可追溯的证据承诺"**：系统首次拥有对**自身故障**的模型（区分"世界变了"与"我坏了"）、首次拥有**可声明降级的能力包络**（在收缩中如实继续工作）、首次拥有**长期记忆的巩固/遗忘/溯源/隔离理论**（巩固不放大错误、遗忘不抹掉教训、污染不可洗白）。第 57 轮"一切判定器走隔离"在本轮推广为"**一切判定器与一切记忆写入走隔离**"。

## 0. 核心 IP 设计

| 编号 | 名称 | 类型 | 关键改进 |

### IP-139 FND（故障-新颖性判别）

```python
def fault_novelty_diagnose(M, r, obs, model, fault_bank, health):
    z = {m: standardize(residual(obs[m], model[m])) for m in obs}
    # 局部离群：某通道与其余所有通道都不一致
    L = max(1 - max(agree(z[m], z[mm], manifold=model.W)
                    for mm in z if mm != m) for m in z)
    # 全局一致：每个通道都至少有一个物理自洽的伙伴
    G = min(max(agree(z[m], z[mm], manifold=model.W)
                for mm in z if mm != m) for m in z)
    pf = max(post_fault(f, z) for f in fault_bank)      # 故障解释的证据
    pn = post_novelty(z, model)                         # 新世界解释的证据
    if max(pf, pn) < theta_diag:                        # 弃权 → 最保守交集
        env = intersect(env_cert(fault_bank), env_cert_novelty(health))
        return Diag('unknown', env=env, margin=max(pf, pn))
    if pf >= pn and L > delta_loc and not on_manifold(z, model.W):
        f = argmax_fault(fault_bank, z)                 # 单通道离群 + 非流形
        return Diag(f, env=env_cert(f))
    return Diag('novelty', env=env_cert_novelty(health))# 多通道自洽偏移
```

def reconfigure_envelope(env, diag, ev, health):

def memory_write(mem, e, prov):

            and mem.calibration_stable(e)

### IP-142 PTG（溯源-污染传播，禁止洗白）

```python
def taint_propagate(mem, falsified):
    mem.taint[falsified] = 1.0
    for v in mem.prov.descendants(falsified):            # 污染向后代传播
        inherited = max(mem.taint[u] * decay(depth(u, v))
                        for u in mem.prov.ancestors(v))
        fresh = mem.prov.independent_fresh_evidence(v)   # 仅全新独立证据可降 τ
        mem.taint[v] = min(mem.taint[v], inherited) if fresh else inherited
        if mem.taint[v] > theta_taint:
            mem.demote(v); mem.quarantine(v)             # 降级 + 隔离 + 排除检索
    mem.audit.log('taint', falsified, t_now)
```

def probe_commit_evolve_plus_plus(x0, M, task, budget, consent, personas, health):

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| FND | O(\|ℳ\|²·d)/检查点 | O(\|ℱ\|) | δ_fn/δ_nf 声明诚实、⊥ 走最保守交集（A41） |
| CEA | O(1)/指令 | O(1) | 运行不变量 u∈𝓔_cert、诚实不变量（A43） |
| HML | O(log\|V\|)/读写 | O(\|V\|·d) | 巩固凭证完备、钉住永不驱逐（A42） |
| PTG | O(\|V\|+\|E\|) 增量 | O(\|V\|+\|E\|) | 污染传播完备、禁止洗白（A42） |
| SHR | O(1)+O(H) | O(\|操作者\|+\|会话\|) | 复发保守、金标独立（A41/A44） |
| FTE+ | O(\|σ\|+\|V\|) | O(\|σ\|+\|V\|) | 无健康证明即拒、⊥ 降级（A44） |
| PCE++ | O(\|CP\|·(k_p+k_d+k_g)·(C_VOI+d)) | O(\|V\|+\|σ\|+\|V_mem\|) | 双价值 VOI、预算终止、四态完备 |

**正确性定理（Fault-Tolerant Accountable Memory, FTAM）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 故障库覆盖且判别混淆有界：真故障被判为新颖 ≤δ_fn、真新颖被判为故障 ≤δ_nf，判别自身误差 ≤δ_diag，金标通道独立于当前故障假设；**(A42)** 记忆健全：坏记忆被巩固晋升概率 ≤δ_cons，钉住集 𝒫 永不驱逐，污染沿溯源图传播完备且重推不可降 τ；**(A43)** 包络单调与诚实：不确定下只缩，扩张需证据门 + 驻留 + 有界速率，宣告包络始终包住实际工作点；**(A44)** 检索改道诚实：全通道失效返回"不可用"而非陈旧默认。则：

1. **故障-新颖健全性**：把持续故障当作新世界并继续承诺的概率 ≤δ_fn+δ_diag+δ_f；把真新颖误判为故障只造成可用性损失 ≤δ_nf，不产生额外安全损失；⊥ 路径因取交集而不弱于任一单假设。
2. **记忆不放大**：坏记忆被巩固放大 ≤δ_cons；证伪沿 G_mem 不可洗白地传播；隔离节点不进入检索，因而不会被后续决策复用。
3. **降级诚实**：不存在"超出认证包络运行而未宣告"的路径；任何收缩/扩张都进入健康账本且对外可见。
4. **优雅终止与联合界**：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta + δ_probe + ε_h + δ_diag + δ_fn + δ_cons)
             − P(𝓔_ann 与实际不一致) − P(污染传播不完整) − P(金标不可用)
```

关键：**容错控制的"继续工作"被限制在可认证、可宣告的收缩包络内**（安全与可用性解耦）；**长期记忆的"经验复用"被限制在过凭证、可溯源、抗污染的节点上**（效率与安全解耦）；**故障与新颖必须被显式区分且允许弃权**（不让系统被迫把一种错误解释成另一种）；三个新机制都只能经"诊断更准"或"动作更保守"两个安全通道起作用。

## 6. 本轮最大风险

**一句话**：容错控制让系统"在降级中继续工作"、长期记忆让系统"把经验固化下来"，两者合流会制造一种新的系统性失效——**故障被记忆正常化**：一个持续故障先被误判为"新世界"，再被巩固成语义记忆、扩散到后续会话乃至整个车队，系统于是在一个越来越小的包络里稳定运行，并把"我变差了"记成"世界变难了"；必须以独立金标探针持续区分"世界 vs 自身"、把可疑通道派生的记忆钉住隔离且禁止巩固、并让污染沿溯源图不可洗白地传播，否则容错机制本身就成了把故障洗成长期信念的机器。
