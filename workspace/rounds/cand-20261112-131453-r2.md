# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 2 轮；本轮灵感：「交互设计」×「多端口部署」）

> 第 57 轮把安全的赌注从"证据质量"再推进到"元先验质量 + 跨模态一致性 + 个性化信任"，并用 OOD 门 + 共形保底试图让"坏先验"只造成慢、不造成错。但它的风险自陈暴露了两个本轮必须正面处理的盲点：**(a）交互仍被当成"取数的通道"**——MXI 只按理解概率选渲染模态，PTM 只按错误率与偏置给人加权；它默认"问得清楚 = 答得正确"，看不见"理解了再同意"与"没听懂却点了同意"在日志上长得一模一样。更危险的是，第 57 轮为了效率给高授权者"加速激活"，等于让一个**被设计得很顺滑的界面**替系统生产授权——这是从"获取证据"滑向"制造同意"。**(b）所有证据都被默认可在同一部署内自由流通**——第 57 轮的元先验 k\*、模态可靠性 ρ、操作者授权都在单一站点内跨区域摊销；可真实部署是**多端口**的：不同场地/硬件批次/操作者池/法域/网络时延，彼此非独立同分布。把 A 端口的证据搬去 B 端口，可能带来正迁移，也可能带来负迁移、端口特异的盲区被均值掩盖、以及一次坏更新同时污染所有端口的相关失效。本轮两个灵感各补一层：**交互设计**把接口升级为有契约、可修复、可验证共同理解的协议，并明确"交互只能校准信任，不能生产授权"；**多端口部署**把"一份证据账本"拆成"端口域账本 + 持证迁移 + 联邦共识 + 金丝雀发布"，并规定**端口支撑地板只能由本端口的世界侧证据写**。核心命题升级为 **"交互可共同建构、端口可隔离、迁移可持证的安全证据承诺"**。

核心矛盾：
- **H29（交互设计 vs 制造同意）**：越顺滑的界面越容易让人"没想就同意"；越强的个性化渲染越能提高"理解率"的指标，却也可能提高**过度信任**与自动化偏置。交互能锐化共同理解，也能生产看起来合法的授权——而两者在单次确认日志里不可区分。
- **H30（多端口 vs 迁移）**：按端口完全隔离，则第 57 轮"从历史语料摊销先验"的全部效率红利归零，每个新端口重回冷启动；跨端口自由合并，则打破 i.i.d. 假设，负迁移、端口特异盲区与相关失效会一起被平均掉。样本效率与端口独立性之间存在真实兑换率。
- **H31（交互契约的跨端口可移植 vs 个性化）**：在一个端口被验证"高参与、低偏置"的交互格式（语言、图形、力回放习惯、确认节奏），到另一个端口可能完全失效甚至诱导；把一个端口的操作者画像当全局默认，等于用 A 的文化给 B 制造同意。

## 0. 直觉与动机

**灵感 1（交互设计 → 从"渲染通道"到"交互契约 + 修复闭环"）**
直觉：人和机器人的一次确认不是"读一个标签"，而是一段有来有回的对话。可靠的交互设计不是把内容渲染得更漂亮，而是明确四件事：**你能做什么（affordance）、要你花多少力气（effort）、我会在什么时候反馈什么（feedback promise）、以及做错了能不能撤（undo）**。把这几件事写成显式**交互契约** C_int，机器人才能把"理解"当成一个可测状态 g 而不是一次点击：g 低就**修复**——复述（read-back）、反教（teach-back）、渐进披露更多依据、换模态，最后才升级到 L2。误解因此从"一次性错误率"变成"一个可被检测和修复的过程"。

**灵感 2（交互设计 → 共同建构证据门与非操纵地板）**
直觉：同意不等于理解。"人类确认"要成为证据，必须先证明**共同理解真的发生了**：能复述、能指出依据、没有"秒点同意/零检查"的过度信任标记，且"我不确定/我没看懂"是一个**非惩罚性、随时可用**的弃权通道。交互设计可以提高理解、校准信任，但绝不能把授权抬到证据之上——这是第 57 轮"交互不能写支撑地板"在人类侧的对偶：**交互不能写授权上限**。

**灵感 3（多端口部署 → 端口域账本与迁移许可证）**
直觉：把每个部署端口 p 当成一等公民，给它独立画像 π_p（地形分布、硬件批次、操作者池、法域、时延）与独立、追加写的证据账本 L_p。任何一条证据都带**来源端口**；跨端口使用不是默认权利，而是需要**迁移许可证** TL(p→q)：声明它迁移的是"校准先验"还是"安全结构"，并附有效期与验证样本。于是"借来的样本效率"变成"有借有还、要验资的贷款"，而不是"悄悄把 A 的数据当 B 的真相"。

**灵感 4（多端口部署 → 负迁移门、单端口否决与金丝雀）**
直觉：迁移有正有负。用捐赠端口 p 的元先验去预测目标端口 q 前，必须先在 q 的本地留出集上做**影子校准**；ECE 或覆盖率不达标就拒绝迁移，退回 q 自己的共形带。全局声明（例如一次策略/阈值更新）不能靠"多数端口平均安全"，而要**任一端口可否决**：一个端口的反例足以隔离全局声明；发布走**金丝雀端口 → 持证端口 → 全量**，失败即回滚。安全是各端口的**下界**，不是平均值。

**灵感 5（合流 → 两个不可互相透支的账户与 PCE++）**
直觉：安全现在有两个账户：**端口侧不可约风险**（每个端口的支撑地板 r_sup^p，只能由世界证据写）与**人侧可约不确定性**（交互修复、共同理解带来的集内收缩）。交互可以付清第二个账户，迁移可以借来第一个账户的效率，但二者都不能把任何端口的支撑地板按下去。第 57 轮的非操纵地板由此扩成两句话：**交互不能降低端口支撑地板，跨端口迁移也不能降低端口支撑地板**。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（端口域证据账本 PSEL）** 端口集 𝒫，端口画像 π_p=(地形分布, 硬件批次, 操作者池, 法域/同意规则, 通信时延, 软件版本)。证据 e=(观测, 证据类, 时间, 来源端口 p, 版本) 追加写入端口账本 L_p（哈希链、只增不改）。端口距离 d_P(p,q) 由画像的加权距离给出，并按法域与硬件批次设硬不相容位。证据分迁移域：`LOCAL`（不得出端口）/`CALIB`（可作校准先验，带验证样本与有效期）/`STRUCT`（安全结构不变量，需更强证书）。**不变量**：端口 q 的承诺只能引用满足 TL(p→q,e) 有效的他端口证据；无许可证即视为 `LOCAL`。

**定义 140（持证迁移元先验 TLMP，升级 IP-133）** 元先验改为端口条件 q_φ(θ|o,z_r,π_p)。捐赠端口集 D 的样本按权重 w(p→q)=sim(π_p,π_q)·1[TL 有效]·exp(−age/τ_T) 加权摊销，输出 k\*_q(w\*)。**负迁移门**：在 q 的本地验证集 V_q 上，要求 ECE_donor ≤ ECE_local+ε_nt、覆盖率 ≥1−α−ε_cov；否则拒迁并退回端口本地共形带 C_cf^q。迁移证书 TC(p→q)={域, 权重, 验证样本量 k_v, ECE 差, 到期时间}。**规则**：迁移只能缩小集内不确定性，任何迁移都不得修改 r_sup^q 与 α_sup^q（端口支撑地板）。

**定义 141（交互契约与修复闭环 ICRL，升级 IP-136）** 交互契约 C_int=(A,E,F,U,X)：可行动集 A、预期投入 E、反馈承诺 F（何时报告什么）、撤销窗口 U、升级路径 X。一次交互是有状态协议，共同理解置信 g_t=P(人已正确理解当前主张|交互史)。修复算子 Repair：g_t<θ_g ⇒ 依次尝试 read-back、teach-back、渐进披露（增加依据粒度）、换渲染模态；仍不达标 ⇒ 弃权或升级 L2。交互终止于 {共同理解, 弃权, 升级}，不得以"超时默认同意"结束。

**定义 142（共同建构证据门 GGE，升级 IP-137）** EV-human 只有在**共同建构证书**下才计数：GC=(复述/反教一致、依据被检查、无过度信任标记、弃权通道可用)。过度信任标记包括：确认时延<τ_think(q)、零查询/零撤销、连续同向确认率异常。只有 GC 成立且 auth≥A1、佐证≥corrob\*(auth) 的确认，才可作为不可逆接触的佐证；**未共同建构的确认即使数量再多也只算"信号"，不算证据**。弃权永不扣分（非惩罚性），且弃权本身触发渐进披露或降档。

**定义 143（校准信任与渐进披露 CTP，升级 IP-135）** 信任状态扩展为 (cal,vig,auth,ot,ut,D_int)：ot 过度信任度（依赖行为 vs 实际可靠性的正偏）、ut 不足信任度、D_int 交互债务（累积未验证确认与未兑现反馈承诺）。目标不是"最大化信任"而是**校准**（依赖率≈可靠性）。规则：(C1) ot 超阈 ⇒ 对高风险动作强制挑战摩擦（要求检查依据、二次确认、强制延迟），而不是更快放行；(C2) D_int 超阈 ⇒ 强制偿还（补解释/回放/复核），期间授权不升；(C3) 渐进披露级别 d 随风险与 ut 上升，但 d 只作用于"理解"，不改变证据门阈值；(C4) 升级仍须有界速率且只由世界侧证实驱动，界面设计不能直接增加 auth。

**定义 144（联邦端口共识与 PCE++，升级 IP-138）** 全局声明/策略更新 g 的接受条件是**联邦共识**：各端口以权重投票聚合，但每个端口对其自身域持**否决权**——若任一端口出现无法解释的反例（沿用第 57 轮 G>θ_gap 或本地证伪），g 立即被隔离（Quarantine），进入回滚或重新持证。发布生命周期：canary 端口（小流量、强监控）→ licensed 端口（持证迁移 + 本地验证）→ 全量。**端口感知 VOI**：探针价值不仅含本地信息增益，还含可迁移性（该证据能否取得 STRUCT/CALIB 许可）；跨端口迁移的期望收益按负迁移概率折价。PCE++ 每检查点：①端口域元推断（TLMP）；②交互修复到共同理解或弃权；③承诺用本端口 R_wc 与 GGE；④全局更新走 FPC + 金丝雀；⑤终止于 {承诺, 绕行, L2 协商, 安全停, 端口隔离}。

## 2. 关键算法伪代码（完整版见产物区）

```python
def port_infer(M, q, obs, meta, ledger_q):        # IP-139/140 合流
    donors = [p for p in ledger_q.ports()
              if valid_license(p, q, evidence='CALIB')]
    P = meta.weighted_prior(obs, ctx(q), donors, w=sim_pi(p, q))
    if not negative_transfer_gate(P, holdout=ledger_q.local_val):
        P = conformal_belt(ledger_q.residuals)     # 拒迁：回本地保底
    return P, never_write(ledger_q.r_sup, ledger_q.alpha_sup)  # 地板不可写

def grounded_human_gate(e, s, contract):           # IP-141/142
    if e.kind != 'confirm': return False
    gc = (teachback_ok(e) and basis_inspected(e)
          and not over_trust_marker(e, s) and contract.abstain_available)
    if not gc:
        repair(contract, level='progressive')      # 修复，不默认同意
        return False
    return s.auth >= 'A1' and e.corrob >= corrob_star(s.auth)

def federated_accept(g, ports, canary):            # IP-144
    if any(port.veto(g) for port in ports):        # 单端口否决
        return quarantine(g)
    if not canary.holds(g) or not canary.monitored_ok:
        return rollback(g)
    return accept(g, lifecycle='licensed')
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| PSEL | O(1)/证据追加；O(\|D\|) 查许可 | O(Σ\|L_p\|) | 溯源完备、无证不迁 |
| TLMP | O(d_φ·\|D\|)/端口 | O(\|𝒟_meta\|) | 负迁移门、地板不可写 |
| ICRL | O(\|Repair\|·d_g)/交互 | O(\|协议\|) | 修复有界、无超时默认同意 |
| GGE | O(1)/确认 | O(\|GC\|) | 未共同建构不计数、弃权非惩罚 |
| CTP | O(1)+O(H_op) | O(\|操作者\|) | 信任只校准不通胀 |
| FPC/PCE++ | O(\|𝒫\|·\|CP\|·(k_p+k_e)(C_VOI+d_φ)) | O(\|𝒫\|·\|V\|) | 单端口否决、金丝雀、k_p+k_e 终止 |

**正确性定理（Port-Scoped Grounded Soundness, PSGS 概要）**：在 A33–A40 上加 (A41) 端口隔离与溯源完备、账本只增；(A42) 迁移证书健全，负迁移门失败即拒迁；(A43) 共同建构证书误差 ≤δ_g，未过门的人类确认不计数；(A44) 交互只校准不通胀，auth 上限由世界侧证据决定；(A45) 联邦共识 + 单端口否决 + 金丝雀回滚。则：(i) 端口 p 的承诺失效率 ≤δ_f+ε_meta(k)+ε_nt(有效迁移)+δ_probe+δ_g(人类证据)+δ_xm·1[L1]；(ii) 多端口安全是各端口下界而非均值，P(任一端口失效) 按端口联合界计，且相关失效由单端口否决与金丝雀先行隔离；(iii) 交互单调性延伸：交互只能使信念更准或动作更保守，不能写 r_sup^p、不能抬高 auth 上限；(iv) PCE++ 在每检查点 k_p+k_e 内终止。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |

## 6. 本轮最大风险

**一句话**：本轮最大的风险是把"多端口迁移"与"交互设计"变成坏真相的放大器——一次错设的端口相似度或一个被游戏化的"共同建构"确认，会让某个端口的局部错误披着"持证迁移 + 已理解同意"的外衣迅速复制到所有端口；因此必须以端口支撑地板不可被迁移/交互写、负迁移门与单端口否决、金丝雀发布三重护栏，宁可让每个端口退回又慢又保守的本地共形带，也不让"借来的效率"或"顺滑的同意"越过任何端口的安全下界。

### IP-139 PSEL（端口域证据账本）

```python
def ledger_append(L, p, e, version):
    assert e.port == p and version == current_version(p)
    e.hash = H(prev_hash(L[p]), canon(e))          # 哈希链、只增不改

def evidence_usable(L, q, e, purpose):
    if e.port == q: return True                    # 本端口证据无证可用
    lic = L.license(e.port, q, e)                  # TL(p->q,e)
    if not lic or lic.expired(): return False      # 无证即视作 LOCAL
    if purpose == 'irreversible' and lic.domain != 'STRUCT':
        return False                               # 不可逆接触只认结构证据
    return lic.domain in ('CALIB', 'STRUCT')
```

### IP-140 TLMP（持证迁移元先验 + 负迁移门）

```python
def transfer_meta_prior(M, q, obs, meta, L):
    donors = [p for p in L.ports()
              if evidence_usable(L, q, sample_e(p), 'calib')]
    w = {p: sim_pi(pi[p], pi[q]) * lic_weight(p, q, t) for p in donors}
    P = meta.q_phi(obs, z=ctx(q), ports=donors, weights=w)   # 端口条件摊销
    if not negative_transfer_gate(P, holdout=L[q].local_val,
                                  eps_nt=EPS_NT, eps_cov=EPS_COV):
        P = conformal_belt(L[q].residuals, alpha=alpha_conf)  # 拒迁：本地保底
        audit.log(('transfer_rejected', donors, q))
    kstar = meta.sample_cert(P, w_target)
    assert not touches(L[q].r_sup, L[q].alpha_sup)            # 地板不可写
    return P, kstar, TC(domain='CALIB', weights=w, k_v=len(L[q].local_val))

def negative_transfer_gate(P, holdout, eps_nt, eps_cov):
    ece_d = expected_calibration_error(P, holdout)
    ece_l = expected_calibration_error(local_prior(holdout), holdout)
    cov_d = empirical_coverage(P, holdout)
    return ece_d <= ece_l + eps_nt and cov_d >= 1 - alpha_conf - eps_cov
```

### IP-141 ICRL（交互契约与修复闭环）

```python
def interaction_contract(risk_level, s_op):
    return C_int(
        A = allowed_actions(risk_level, s_op),        # 能问什么/能改什么
        E = effort_budget(risk_level, s_op),          # 预期投入（时间/步骤）
        F = feedback_promise(risk_level),             # 何时机/报告什么
        U = undo_window(risk_level),                  # 可逆层才给 undo
        X = escalation_path(risk_level))              # L2/人工/安全停

def grounded_dialogue(exp, C, s_op, timeout):
    g = init_grounding(exp, s_op)
    while g < THETA_G and time_left(timeout) and C.U.allows():
        act = choose_repair(g, C)                     # read-back/teach-back/披露/换模态
        g = update_grounding(g, act, response(act))
        if act == 'progressive': C.detail = min(C.detail + 1, D_MAX)
    if g < THETA_G:
        return 'abstain_or_escalate'                  # 绝不“超时默认同意”
    return 'grounded'
```

### IP-142 GGE（共同建构证据门）

```python
def grounded_human_evidence(e, s_op, C, M):
    if e.kind != 'confirm': return ('signal_only', e)
    gc = GroundingCert(
        teachback = teachback_consistent(e, C),
        inspected = basis_inspected(e, M),
        unbiased  = not over_trust_marker(e, s_op, C),
        abstain_ok= C.abstain_available)
    if not gc.all():
        repair(C, level='progressive')                # 触发修复而非默认通过
        return ('not_grounded', e)                    # 再多也只是信号
    if s_op.auth < 'A1' or e.corrob < corrob_star(s_op.auth):
        return ('insufficient_auth', e)
    return ('ok', gc)

def over_trust_marker(e, s_op, C):
    return (e.latency < TAU_THINK[e.format] or
            e.queries == 0 and e.undos == 0 or
            run_rate(e.op, same_direction=True) > P_OT)
```

### IP-143 CTP（校准信任与渐进披露）

```python
def calibrate_trust(s, e, audit):
    s.cal = proper_score_update(s.cal, e)
    s.ot  = update_over_trust(s.ot, reliance(e), reliability(s), e)
    s.ut  = update_under_trust(s.ut, reliance(e), reliability(s), e)
    s.D_int = decay(s.D_int) + (1 if e.unverified else 0) - repaid(e)
    if s.ot > THETA_OT:                              # 过度信任 → 加挑战，不加速
        s.mode = 'challenge'; s.auth = min(s.auth, 'A1')
    if s.D_int > THETA_DEBT:
        s.mode = 'repay'; s.auth_frozen = True       # 债务未偿不得升级
    s.detail = disclosure_level(risk(e), s.ut)       # 只影响理解，不改证据阈值
    s.w_h = min(W_MAX_GLOBAL, w0 * s.cal)            # 全局硬界不变
    audit.log(s); return s
```

### IP-144 FPC（联邦端口共识）+ PCE++ 主循环

```python
def federated_consensus(g, ports, canary, window):
    vetoes = [p for p in ports if p.veto(g)]          # 单端口反例即否决
    if vetoes:
        quarantine(g); audit.log(('veto', vetoes)); return 'quarantine'
    if not canary.holds(g): return 'rollback'
    if not canary.monitor_ok(window): return 'rollback'
    return accept(g, lifecycle='licensed')            # canary -> licensed -> general

def probe_commit_evolve_pp(x0, M, task, budget, consent, personas, L):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for p in route.ports:                             # 端口域执行
        for cp in route.checkpoints(p):               # 端口域检查点
            P, kstar, tc = transfer_meta_prior(M, p, M.obs[p][cp], meta, L)
            M.b[p][cp] = P
            sigma = foothold_schedule(x0, cp, M); R = schedule_risk(sigma, M)
            while select_gait(R) == 'halt' and budget.left(p) > 0:
                cands = admissible_probes(cp, M, F_abs)
                if not cands: break
                # 端口感知 VOI：本地增益 + 可迁移性折价
                pbest = argmax(cands, key=lambda q:
                               voi_local(q, M, P) + transfer_value(q, p, L)
                               - neg_transfer_risk(q, p) - cost(q))
                if voi_local(pbest, M, P) < theta_voi: break
                M, fused, D = xmodal_fuse(M, p, execute_probe(pbest, cap=F_abs))
                budget.spend(pbest)
                sigma = reselect_footholds(x0, cp, M); R = schedule_risk(sigma, M)
            C = interaction_contract(contact_level(cp), personas.active)
            if contact_level(cp) in ('L1', 'L2'):
                gstate = grounded_dialogue(core_explanation(cp, M), C,
                                           personas.active, tau_int(personas.active.auth))
                if gstate != 'grounded':
                    sigma = downgrade_or_reroute(sigma, M)
            ev_ok = few_shot_evidence_gate(core_contact(cp), M, personas, L, p)[0] == 'ok'
            if select_gait(R) != 'halt' and ev_ok:
                sched.append(commit(sigma, select_gait(R))); log.append(ev_ok); continue
            alt = reroute(M, cp, risk_model)
            if alt and select_gait(schedule_risk(alt, M)) != 'halt': route = alt; continue
            return negotiate_or_stop(cp, M, sigma, R, consent,
                                     tau_int(personas.active.auth))
    return sched, log, M
```

### IP-137→FSE-P（端口化少样本证据门）

```python
def few_shot_evidence_gate(c, M, personas, L, p):
    if c.ev == 'EV-probe*':
        ok = (c.inf.cls == 'ID' and c.inf.ece_k <= eps_meta(c.k)) or \
             (c.inf.cls == 'OOD' and L[p].ood_certified(c.region))
    elif c.ev == 'EV-xmodal':
        ok = c.level == 'L1' and c.indep_declared and D(p, c.region) <= theta_D
    elif c.ev == 'EV-human':
        st, _ = grounded_human_evidence(c.confirm, personas[c.op], c.contract, M)
        ok = (st == 'ok')                            # 无共同建构证书不计数
    elif c.ev in ('EV-visit', 'EV-margin'):
        ok = round56_checks(c, M)
    else:
        return ('reject', 'no_evidence_class', c)
    if not ok: return ('reject', 'evidence_insufficient', c)
    if c.irreversible and c.ev == 'EV-xmodal':
        return ('reject', 'xmodal_on_irreversible', c)
    if not evidence_usable(L, p, c.e, 'irreversible') and c.irreversible:
        return ('reject', 'unlicensed_cross_port', c)   # 越域证据不可用于不可逆
    return ('ok', c)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PSEL | O(1)/追加；O(\|D\|) 查许可 | O(Σ\|L_p\|) | 溯源完备、无证不迁（A41） |
| TLMP | O(d_φ·\|D\|)/端口 | O(\|𝒟_meta\|) | 负迁移门、地板不可写（A42） |
| ICRL | O(\|Repair\|·d_g)/交互 | O(\|协议\|) | 修复有界、无超时默认同意（A43） |
| GGE | O(1)/确认 | O(\|GC\|) | 未共同建构不计数、弃权非惩罚（A43） |
| CTP | O(1)+O(H_op) | O(\|操作者\|) | 信任只校准不通胀（A44） |
| FPC/PCE++ | O(\|𝒫\|·\|CP\|·(k_p+k_e)(C_VOI+d_φ)) | O(\|𝒫\|·\|V\|) | 单端口否决、金丝雀、k_p+k_e 终止（A45） |

**正确性定理（Port-Scoped Grounded Soundness, PSGS）**
假设 A22–A32（第 53–55 轮）、A33–A36（第 56 轮）、A37–A40（第 57 轮）成立；**(A41)** 端口隔离与溯源：每条证据恰属一个端口，账本只增，许可证不可伪造，无证证据视作 LOCAL；**(A42)** 迁移健全：迁移证书诚实，负迁移门失败即拒迁，被拒迁移对目标端口承诺贡献为 0；**(A43)** 共同建构：GC 误差 ≤δ_g，未过 GC 的人类确认不计数，弃权非惩罚且可触发保守动作；**(A44)** 交互只校准不通胀：auth 上限由世界侧证据决定，界面设计不能直接提升 auth，全局硬界与决策规则本体不变；**(A45)** 联邦共识：全局声明接受前须无任何端口否决且通过金丝雀监控，隔离/回滚时延有界。则：

1. **端口域承诺健全性**：端口 p 的承诺失效率 ≤ δ_f + ε_meta(k) + ε_nt(有效迁移) + δ_probe + δ_g(人类证据) + δ_xm·1[L1]。
2. **多端口安全下界**：系统安全 = min_p 安全，而非平均；P(任一端口失效) 按端口联合界计，相关失效由单端口否决 + 金丝雀先行隔离，全局更新不得以"多数安全"覆盖"任一端点不安全"。
3. **交互单调性延伸**：交互与迁移只能经 (a) 信念更准/共同理解更可靠 或 (b) 动作更保守（降档、加挑战、延期、弃权、升级）影响系统；二者都不能写 r_sup^p、不能抬高 auth 上限、不能绕开证据门。
4. **终止性**：每检查点修复步数 ≤|Repair|、交互预算 k_e，探针预算 k_p+k_e，PCE++ 终止于 {承诺, 绕行, L2 协商, 安全停, 端口隔离}。
5. **部署界**（对端口与检查点取联合界）：

```
P_safe ≥ 1 − Σ_p Σ_cp (δ_f + ε_meta + ε_nt + δ_probe + δ_g + δ_xm·1[L1])
             − P(端口画像漂移未检出) − P(迁移证书失效未回收)
             − P(单端口否决失败) − P(金丝雀逃逸) − P(交互修复失效 ∧ 安全停失效)
```

关键：**交互给理解、不给授权**（共同建构只让"人说的"更可信，不让系统更敢赌）；**端口给效率、不给越界**（迁移借来的样本效率必须过负迁移门，且写不动端口支撑地板）；**全局给协同、不给平均**（单端口否决使安全取 min 而非 mean）。第 57 轮"一切判定器走隔离"在本轮再推广为"**一切跨端口知识与交互授权走持证隔离**"。

## 6. 本轮最大风险

**一句话**：本轮最大的风险是把"多端口迁移"与"交互设计"变成坏真相的放大器——一次错设的端口相似度或一个被游戏化的"共同建构"确认，会让某个端口的局部错误披着"持证迁移 + 已理解同意"的外衣迅速复制到所有端口；因此必须以端口支撑地板不可被迁移/交互写、负迁移门与单端口否决、金丝雀发布三重护栏，宁可让每个端口退回又慢又保守的本地共形带，也不让"借来的效率"或"顺滑的同意"越过任何端口的安全下界。
