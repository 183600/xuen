# 第 10 轮（新灵感循环第 1 轮；本轮灵感：「轻量化设计」×「需求洞察」）

> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570；IP-340–356）。
> 本轮纪律：**轻量不弱证 + 需求可证 + 联合裁剪**。两个灵感分别治理 v9 的两种债：**部署债**（AC 的 64 候选 LSTM-MPC 前向模型、MW 的 16 条契约、ID 的消融回合，在边缘 25W/50Hz 上已接近预算上限，任何再增长都会把 p99 推过 20ms）与**需求债**（18 个 IP 的保留依据是“任务进展 − 安全罚”的代理指标，而非操作者与评估者的真实需求；ID 的贡献归因可能优化了一个自我指涉的指标）。新模块一律为可选增强：失效即注入证书侧/需求侧中立元，严格等价退回 v9（引理 87–92），而非行为漂移。

## 0. 直觉与动机

**灵感 1（轻量化设计 → 证书的分级早退，而非模型的粗暴裁剪）**
直觉：轻量化最危险的做法是“把前向模型剪小，然后继续沿用旧的误差界”——参数少了，误差界却没人重新证明。正确做法是把“轻”与“证”解耦：证书做成**分级级联**，T0 用 Lipschitz/区间包络给出微秒级保守界；T1 用蒸馏+量化的小代理，但误差界由**保形预测**在部署分布上给出有限样本覆盖；只有前两级“含糊”时才升级到 T2（v9 的完整 LSTM-MPC）。任一级只有在“给出有效界”时才允许接受，否则弃权 → K_eff=1 或安全停驻。再叠加**安全原语代数**：把重复出现的原语/状态桶的证书缓存，并用 Minkowski/区间运算组合，摊销证书成本。核心创新：**证书级联（CC）**＋**保形代理证书（CSC）**＋**安全原语代数（SPA）**。轻量化因此不是“更弱的模型”，而是“更早的弃权”。附带地，T0/T1 的弃权机制是对 v9 最大风险（Δ_dom 滑窗滞后、大块仍被信任）的补丁：即使 K_eff 仍取大值，只要无法给出有效界，级联就拒绝该块。

**灵感 2（需求洞察 → 需求证据图与可逆探针）**
直觉：v9 的 ID 回答“这个模块对任务进展贡献多少”，但没有回答“谁需要它、在什么场景需要、需求有多硬”。需求洞察的核心不是发问卷，而是把**操作者的隐式行为**变成证据：接管、纠错、放弃、停留、语音情感、任务重试，都是需求的影子。核心创新：**需求证据图（REG）**：需求节点 N 与模块 M 的二部图，A_{jm} 是覆盖强度，w_j 是需求权重，按 Kano 分为 must/performance/delight 三类；must 需求有覆盖地板 ρ_j=1。**需求探针（RPI）**：在非安全交互参数上做有界、可逆、带冷却的微扰（提示时机、措辞、建议强度），用安全 contextual bandit 估计接受度梯度，从而发现“操作者说不出口的”潜在需求。关键纪律：探针绝不触碰 M₀/安全动作，且受**观察者效应预算**约束——测量需求不能把需求本身改变掉。

**灵感 3（两者耦合 → 精益-需求联合裁剪）**
直觉：轻量化决定“能跑多少”，需求洞察决定“值不值得跑”。两者必须一起优化，否则 ID 会把算力省给一个没人需要的模块，或者需求侧会把预算全花在一个可被更轻实现覆盖的需求上。核心创新：**精益-需求联合选择器（LNS）**：在安全地板（φ^elig=false 模块固定保留）与 must 需求覆盖地板下，选择模块子集与证书层级，最大化需求加权覆盖减算力成本。覆盖函数单调子模，故可用贪心/ILP 求解并给出近似保证。裁剪的每一条都必须同时通过“低贡献”与“低需求覆盖”两票——**需求不可静默丢失**。

## 1. 研究问题（轮次升级版）

- **Q1（轻量证书的健全性）**：分级证书在“任一级不弃权即给出有效界”的前提下，能否保证与 v9 单级证书相同的安全性？保形覆盖在非交换/域偏移下如何失效，Δ_dom 门控是否足以恢复保证？
- **Q2（需求的可证表示）**：隐式行为证据如何映射为需求权重与覆盖强度，且不被操作者对系统的适应（Goodhart/观察者效应）污染？可逆探针的收益-干扰比如何界定？
- **Q3（联合裁剪的边界）**：在安全地板与 must 需求地板下，联合选择能否保证“不静默丢失需求、不触碰安全不变式”？需求漂移下的后悔与重选延迟如何界定？

## 2. 设计原则（在 P10–P12 基础上新增 P16–P18）

**P16 轻量不弱证律（Lightweight-Not-Weaker, LNW）**
任何轻量替代必须携带覆盖 ≥1−α 的证书，或在无法证明时弃权并升级；禁止“剪小模型但沿用旧误差界”。级联的 T2 必须是 v9 原证书；任一级失效 ⇒ 退化为下一级/弃权，不改变安全语义。证书可以更便宜，但不能更不可信。

**P17 需求可证律（Need-Evidenced, NE）**
每个保留模块必须追溯到至少一个已测量需求或安全不变式；每个被裁模块必须同时满足低贡献与低需求覆盖。must 需求覆盖地板 ρ_j=1 不可由优化器交易。探针必须有界、可逆、带冷却、绝不触碰安全动作，并计入观察者效应预算。

**P18 联合裁剪律（Joint Lean-Need Selection, JLN）**
模块子集与证书层级联合选择；安全地板（M₀、SpatialCert、FaultCert、MW、AC 证书检查、LNS 自身）固定；must 需求地板不可违反；预算约束下最大化需求加权覆盖。优化失败 ⇒ 完整保留 v9 模块集，不部分裁剪。

## 3. 与基线的接口（如何退化）

- CC/CSC 失效（T2 超时 / 保形校准失效 / 偏移越阈）⇒ 使用 v9 的静态 β 与完整前向模型；仍失败 ⇒ K_eff=1，等价 v9 AC；
- SPA 失效 ⇒ 关闭缓存与组合，逐块完整 rollout，等价 v9；
- REG 失效 ⇒ 需求权重取均匀 r^⊥，覆盖矩阵取静态默认，LNS 不裁剪；
- RPI 失效 ⇒ 停止探针，仅用被动证据，需求图冻结；
- LNS 失效 ⇒ 模块选择完全交回 v9 ID，全模块保留；
- v9 的 AC/MW/ID 任一失效 ⇒ 按 v9 五级链继续退化至 v8/v7。

## 4. 预期贡献

1. **分级轻量证书**：T0 区间包络 / T1 保形蒸馏代理 / T2 完整模型，anytime soundness + 早退，把证书成本从“每次 12ms”降到“典型 T0/T1”；
2. **需求证据图**：把操作者隐式行为变成可追溯的需求权重与覆盖矩阵，must/performance/delight 分层；
3. **可逆需求探针**：在非安全交互参数上做有界主动学习，带观察者效应预算；
4. **精益-需求联合裁剪**：安全地板 + 需求地板 + 预算下的子模选择，给出“不静默丢失”的保证；
5. **实验 E571–E590**：级联成本/覆盖、偏移失效、缓存健全性、需求图信度、探针可逆性、联合裁剪、漂移重选、边缘功耗与端到端。

## 5. 本轮最大风险

**一句话**：轻量证书的覆盖可由保形统计在交换性假设下证明，但需求权重只能从有限、非平稳、且会被探针本身扰动的操作者样本中估计——联合裁剪可能以“需求不覆盖”为由裁掉一个罕见但致命的模块，把可证的算力债换成不可证的需求误判债，而后者只在长尾/多操作者场景暴露。

## 1. 符号体系增量（定义 540–548）

**新增定义 540（分级证书级联 CertificateCascade）** 对状态 s 与候选块 ζ，级联按成本递增调用 T0、T1、T2，返回三元判定：
```
V(s,ζ) ∈ { accept(Ĉ, τ, c_τ), reject, abstain }
```
- T0：用 Lipschitz 常数 L_F 与区间算术对 F 做保守包络，若块内间隙下界 ≥ d_safe 且努力上界 ≤ τ_eff 则接受；若间隙上界 < d_safe 则拒绝；否则弃权；
- T1：蒸馏/量化小代理 F̂₁，误差界 β₁ 由定义 541 的保形校准给出；
- T2：v9 的完整前向模型与静态 β₂，信任域 U_t 内健全；
- **anytime soundness 契约**：任一层级返回 accept 时，其 Ĉ 必须是该层可证明的有效界；全部弃权 ⇒ K_eff ← 1 或安全停驻，禁止“无证书执行”。

**新增定义 541（保形代理证书 ConformalSurrogateCertificate）** 校准集 D_cal = {(s_i, ζ_i, e_i)}_{i=1..n}，其中 e_i = max_k |F(s_i,ζ_i)_k − F̂₁(s_i,ζ_i)_k|。取非一致性分数 s_i = e_i / β̂（β̂ 为误差尺度），有限样本分位数
```
q = Quantile_{⌈(n+1)(1−α)⌉/n}({s_i})
```
证书余量 β₁ = q·β̂。在可交换性下 P(e_{n+1} ≤ β₁) ≥ 1−α。若 q 计算超出样本范围（⌈(n+1)(1−α)⌉ > n），则 q = ∞，T1 必须弃权。域偏移时保形覆盖不再成立：以 Δ_dom 为门控，Δ_dom ≥ τ_dom ⇒ T1 直接弃权并升级 T2 或 K_eff=1。

**新增定义 542（安全原语代数 SafePrimitiveAlgebra）** 每个原语 p 携带认证安全集 S_p ⊆ State 与指标区间 I_p；块 ζ = p_1…p_K 的组合证书由保守算子 ⊕ 给出：
```
S_ζ = ⋂_{k=1..K} Pre^{k−1}(S_{p_k}),    I_ζ = ⊕_{k=1..K} I_{p_k}
```
缓存键 κ=(p,b) 存储 Entry(κ)=(E_κ, Ĉ_κ)，其中 E_κ 是使 Ĉ_κ 成立的认证入口集。命中条件：s ∈ E_κ 且桶 b 在 p 下前向不变；满足则直接返回 Ĉ_κ，不满足则回退完整 rollout 并保守更新条目。缓存只改变成本，不改变正确性。

**新增定义 543（需求证据图 RequirementEvidenceGraph）** 二部图 G=(N,M,A,w,D)：
- N 为需求节点，按 Kano 分为 must / performance / delight；must 需求覆盖地板 ρ_j=1；
- A_{jm} ∈ [0,1] 为模块 m 对需求 j 的覆盖强度（0 表示无覆盖）；
- w_j(t) 为需求权重，由显式证据（操作者指令、评估表）与隐式证据（接管、纠错、放弃、停留、语音情感、任务重试）经 EMA 更新；
- D 为需求依赖（如“安全放置”依赖“力闭合”），用于覆盖传播；
- 模块需求必要性 n_m = Σ_j w_j A_{jm}；需求覆盖 cov_j(x) = min(1, Σ_m A_{jm} x_m)。

**新增定义 544（需求探针 RequirementProbeInterpreter）** 探针是作用在**非安全交互参数**上的微扰 δ ∈ P_probe（提示时机、措辞、建议强度、语音节奏），满足：
```
|δ| ≤ ε_p,   duration(δ) ≤ T_p,   探针间隔 ≥ T_c
```
每个 δ 携带可逆映射 R_δ（在 T_p 内恢复原参数），且探针集合 P_probe 与安全动作集不相交。观测量为操作者接受/拒绝/接管；用安全 contextual bandit 估计接受度对 δ 的梯度。探针价值 = 期望信息增益 / 干扰代价；总预算 B_p，累计观察者效应 E_obs 超过阈值即冻结探针，退回被动证据。

**新增定义 545（需求覆盖与后悔 RequirementCoverage & Regret）**
```
cov_j(x) = min(1, Σ_m A_{jm} x_m)
R_req(x) = Σ_j w_j · (1 − cov_j(x))
```
需求后悔是所选模块集相对“覆盖预言机”的加权缺口。ID 的贡献向量 c_m 与需求必要性 n_m 是两个正交信号：前者是“任务进展贡献”，后者是“需求覆盖贡献”。

**新增定义 546（精益-需求联合选择 LeanNeedSelection）** 选择 x、y 以最大化
```
U(x,y) = Σ_j w_j · cov_j(x) − λ · Σ_m c_m(y_m)
s.t.   x_m = 1  ∀m ∈ S_fixed（安全地板）
       Σ_m c_m(y_m) ≤ B_dec（决策预算）
       cov_j(x) ≥ ρ_j  ∀j ∈ must（must 需求地板）
```
其中 S_fixed 含 M₀ 硬检查、SpatialCert、FaultCert、MW、AC 证书检查、LNS 自身。覆盖函数对 x 单调子模；|M|≤20 时用 ILP 精确求解，否则用代价-收益贪心。无可行解 ⇒ 返回 v9 全模块集，不部分裁剪。

**新增定义 547（需求漂移检测 RequirementDrift）** 对 w、A、接受率序列做滑窗变点检测；漂移统计量超过阈值或 must 需求覆盖跌破 ρ_j 时触发重选。检测延迟记为 d_detect；重选必须重新校验安全地板与 must 地板，校验失败即回退全保留。

**新增定义 548（观察者效应预算 ObserverEffectBudget）** 探针引起的操作者行为改变量以对照窗口估计：
```
E_obs = Σ_{probes} dose(δ_i) · |Δacceptance_i|
```
E_obs ≥ B_p 时冻结主动探针，仅保留被动证据；该预算把“测量需求”从无限实验变成有界干预，避免把操作者训练成系统的镜像。

## 2. 形式化定义（要点与升级）

**定义 532（动作块）升级** ζ_t = (a^{1:K}, Ĉ_t, P_t, τ_t, y_t)：新增证书层级 τ_t 与所选层级 y_t；K_eff 由 v9 定义 539 给出，但 CC 弃权可强制 K_eff=1。
**定义 533（块证书）升级** Ĉ_t 的有效性不再只依赖单一 β，而是依赖“当前层级 τ_t 的覆盖契约”：T0 为确定性区间界，T1 为保形覆盖，T2 为 v9 静态 β。
**定义 535（中间件契约）升级** κ_m 增加 `tier_m`（可用层级集）与 `need_cover_m`（该模块覆盖的需求集合）；MW 在调度时按层级选择最便宜的可用证书，超时仍注入 v^⊥。
**定义 536（中立元表）升级** 新增需求侧中立元 r^⊥：REG/RPI/LNS 失效时 w_j ← 均匀、A ← 静态默认、x_m ← 1（全保留），与 v9 ID-only 行为等价。
**定义 538（提炼状态机）升级** dormant 迁移增加需求否决：若 n_m 高于 must 覆盖所需，则禁止 dormant；ID 的低贡献不能单独裁掉一个 must 覆盖模块。
**定义 496/531（软证书与软硬衔接）升级** δ_trigger 增加 `V(s,ζ)=accept` 与 `must_ok(x)` 两个条件；证书弃权或 must 需求未覆盖均直接进入 M₀ 硬检查/安全停驻，无“优化器已裁剪但安全层不知道”的空洞。

# IP-357 CertificateCascade：分级证书级联
class CertificateCascade:
    def __init__(self, T0, T1, T2, alpha=0.01):
        self.T0, self.T1, self.T2, self.alpha = T0, T1, T2, alpha

    def certify(self, s, chunk):
        for tau in (self.T0, self.T1, self.T2):
            v = tau.certify(s, chunk)
            if v.status == "accept":
                return v                       # anytime sound: v.cert 有效
            if v.status == "error":
                break                          # 本级实现故障 → v9 兜底
        return Verdict.abstain("all_tiers", fallback="K_eff=1")


class IntervalEnvelope:                        # T0：µs 级
    def __init__(self, L, d_safe, tau_eff):
        self.L, self.d_safe, self.tau_eff = L, d_safe, tau_eff

    def certify(self, s, chunk):
        g_lo, g_hi, e_lo, e_hi = self._interval_rollout(s, chunk.actions)
        if g_lo >= self.d_safe and e_hi <= self.tau_eff:
            return Verdict.accept(Cert(g_lo, e_hi), tier="T0")
        if g_hi < self.d_safe or e_lo > self.tau_eff:
            return Verdict.reject("t0_unsafe")
        return Verdict.abstain("t0_ambiguous")


class ConformalSurrogate:                      # T1：保形蒸馏代理
    def fit(self, cal):
        self.beta_hat = max(e for _, _, e in cal) or 1.0
        self.scores = sorted(e / self.beta_hat for _, _, e in cal)
        n = len(self.scores)
        k = math.ceil((n + 1) * (1 - self.alpha))
        self.q = self.scores[k - 1] if k <= n else float("inf")

    def certify(self, s, chunk):
        if s.delta_dom >= s.tau_dom:            # 偏移越阈：保形覆盖失效
            return Verdict.abstain("shift")
        if not math.isfinite(self.q):
            return Verdict.abstain("insufficient_calibration")
        pred = self.net(s, chunk.actions)
        beta = self.q * self.beta_hat
        if pred.min_clearance - beta < self.d_safe:
            return Verdict.reject("t1_unsafe")
        return Verdict.accept(Cert(pred.min_clearance - beta,
                                   pred.max_effort + beta), tier="T1")


# IP-358 SafePrimitiveAlgebra：原语缓存（只省成本，不改正确性）
class SafePrimitiveCache:

# IP-359 RequirementEvidenceGraph：需求证据图
class RequirementEvidenceGraph:
    def __init__(self, needs, modules, kano, rho, deps=None):
        self.N, self.M = needs, modules
        self.kano, self.rho = kano, rho
        self.w = {j: 1.0 for j in needs}
        self.A = {(j, m): 0.0 for j in needs for m in modules}
        self.deps = deps or {}

    def observe(self, ev):
        for j in ev.affected_needs:             # 显式 + 隐式证据
            self.w[j] = ema(self.w[j], ev.strength, 0.95)
            for m in ev.affected_modules:
                self.A[(j, m)] = ema(self.A[(j, m)], ev.coverage, 0.95)

    def necessity(self):
        return {m: sum(self.w[j] * self.A[(j, m)] for j in self.N)
                for m in self.M}

    def cov(self, x):
        return {j: min(1.0, sum(self.A[(j, m)] * x[m] for m in self.M))
                for j in self.N}

    def must_ok(self, x):
        c = self.cov(x)
        return all(c[j] >= self.rho[j] for j in self.N
                   if self.kano[j] == "must")


# IP-360 RequirementProbeInterpreter：可逆需求探针
class RequirementProbeInterpreter:
    def __init__(self, bandit, eps=0.05, T_p=3, T_c=50, B_p=20.0):
        self.bandit, self.eps, self.T_p = bandit, eps, T_p
        self.T_c, self.B_p, self.E_obs = T_c, B_p, 0.0
        self.last_probe = -10**9

    def propose(self, ctx):
        if ctx.safety_active or ctx.delta_dom >= ctx.tau_dom:
            return None
        if self.E_obs >= self.B_p or ctx.cycle - self.last_probe < self.T_c:
            return None
        arm = self.bandit.select(ctx)
        self.last_probe = ctx.cycle
        return Probe(arm, revert=arm.revert, eps=self.eps, max_steps=self.T_p)

    def observe(self, probe, accepted, effort):
        self.bandit.update(probe.arm, accepted, effort)
        self.E_obs += probe.dose() * abs(accepted - 0.5) * 2.0


# IP-361 LeanNeedSelector：联合裁剪
class LeanNeedSelector:
    def __init__(self, lam=1.0):
        self.lam = lam

    def select(self, G, contracts, budget):
        pinned = [m for m in contracts if not contracts[m].distill_eligible]
        x = {m: 1 for m in pinned}
        while True:
            best, best_score = None, 0.0
            for m in contracts:
                if x[m]:
                    continue
                gain = self._marginal_need(G, x, m)
                cost = max(contracts[m].wcet, 1e-9)
                score = gain / cost
                if score > best_score:
                    best, best_score = m, score
            if best is None or self._cost(x, contracts) + contracts[best].wcet > budget:
                break
            x[best] = 1
        if not G.must_ok(x) or self._cost(x, contracts) > budget:
            return {m: 1 for m in contracts}    # 失败即全保留（v9）
        return x

    def _marginal_need(self, G, x, m):
        before = sum(G.w[j] * G.cov(x)[j] for j in G.N)
        x2 = dict(x); x2[m] = 1
        after = sum(G.w[j] * G.cov(x2)[j] for j in G.N)
        return max(0.0, after - before)

## 4. 推导

**引理 87（级联健全性与成本支配）** 设每级 τ 在不弃权时返回有效界，T2 在信任域 U_t 上健全。则级联的任一 accept 判定健全；全弃权时系统进入 K_eff=1 或安全停驻，等价 v9 兜底。期望成本
```
E[c] = c₀ + p₀·c₁ + p₀·p₁·c₂
```
其中 p₀、p₁ 为 T0、T1 的弃权率。故当 T0 接受率 ≥1−δ 时 E[c] ≤ c₀ + δ(c₁+c₂)，早退收益由弃权率直接控制；最坏情况成本不超过 c₀+c₁+c₂，且任何情况下健全性不弱于 T2。证明：对级联深度归纳；accept 只可能来自已验证层级；全弃权路径按定义 540 回落。∎

**引理 88（保形覆盖与偏移失效）** 在可交换性下，定义 541 的 T1 证书满足 P(e ≤ q·β̂) ≥ 1−α。若校准分布与部署分布的总变差距离 ≤ ε，则覆盖至少为 1−α−ε。若二者不可交换（域偏移、操作者改变策略、传感器换代），覆盖可任意变差；因此 Δ_dom ≥ τ_dom 时必须弃权并升级 T2 或 K_eff=1。证明：split conformal 的有限样本覆盖 + 总变差传输不等式；偏移下反例由构造两个不重叠分布给出。∎

**引理 89（原语组合与缓存健全性）** 若每个原语证书 (S_p, I_p) 健全，组合算子 ⊕ 对交集/Minkowski/区间运算保守，则块证书 (S_ζ, I_ζ) 健全。缓存命中条件 s ∈ Entry(κ) 且桶在 p 下前向不变，保证 Ĉ_κ 对当前 s 仍成立；因此 SPA 只改变成本，不改变正确性。证明：对 K 归纳；每一步的保守算子包含真实可达集；缓存命中是组合健全性的特例。∎

**引理 90（联合选择的近似与地板可行性）** 覆盖函数 f(x)=Σ_j w_j·min(1,Σ_m A_{jm}x_m) 对 x 单调子模。基数预算下贪心给出 (1−1/e) 近似；带成本背包下代价-收益贪心给出 (1/2)(1−1/e) 近似；|M|≤20 时 ILP 精确。安全地板与 must 地板是硬约束；若不存在可行解，LNS 返回 v9 全模块集（在 v9 可行的前提下可行），故地板不会被优化器交易。∎

**引理 91（探针可逆性与无 Zeno）** 探针 δ 在 T_p 内由 R_δ 恢复，且不作用于安全动作集；累计观察者效应 E_obs ≤ B_p。冷却期 T_c 保证任意两次探针间隔 ≥ T_c，有限时间内探针次数有限，无 Zeno。接受度估计的偏差由 E_obs 上界控制，故探针不会把需求估计推向无界漂移。证明：由定义 544/548 的直接计数与可逆性；有界扰动 + 冷却 ⇒ 有限次。∎

**引理 92（需求漂移的后悔界与不静默丢失）** 设需求权重/覆盖矩阵的单步漂移速率 ≤ L，漂移检测延迟 ≤ d_detect。则所选集合的需求后悔满足
```
R_req(x_sel) ≤ (1−1/e)·R_req(x*) + L·d_detect + ε_greedy
```
每次重选都重新校验安全地板与 must 地板；违反者被拒绝并回退全保留。因此不存在“优化器已裁剪、安全层却不知道”的静默丢失，最坏情况退化为 v9 全模块集。证明：子模近似界 + 漂移的 Lipschitz 累积 + 地板校验的失败安全路径。∎
