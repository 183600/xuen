### 第 6 轮灵感驱动研究记录

**灵感词**：机器人竞赛、基准测试

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）以条件流匹配提议、嵌入+固化记忆、情感调制，并用定理 6（证书不变性/提议无关性）把框架推广为「任意生成器 + 认证边界」。本轮不推翻 v5，而是攻击 v5 两个被默认、却从未被认证的**元层假设**：(a) v5 的七门、软评分与固化接受准则都建立在「存在一个可信评测集」之上，但 v5 没有把评测集本身当作认证对象——它是有偏、有限、可被训练泄漏污染、也会被反复查询而过拟合的；(b) v5 的通过判定用评测的**点估计**，在公开榜单、反复评测与竞争压力下，optional stopping 与多重比较会把「运气」写成「能力」。两个灵感词统一为主题「竞赛裁判式认证执行」（Adversarial Benchmark-Certified Execution, ABCE），形成 CADVS-v6（IP-497~500）。本轮自律：**硬门仍为七**；基准与统计只作为「裁判层 / 证书语义」接入，只紧不松；执行集嵌套升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **基准测试 → 证书必须是「基准相对 + 统计有效」的，而不是一次跑分的快照**。直觉上，一张证书就像竞赛成绩单：它不只要写分数，还要写「考的是哪套卷子（基准版本）、阅卷规则、样本量、置信下界」。引入基准清单 B=(S 分层任务族, 评分规则 r, 划分 D_fit/D_val/D_test/D_adv, 扰动族 P_pert, B_hash)。证书从「点估计通过」升级为「逐分层置信下界 LCB 通过」：kc_i^v6 = 1[LCB_s(m_i) ≥ τ_i^5]。关键是采用**时间均匀置信序列**（e-process / hedged capital），使 LCB 对任意停时一致有效——竞争者可以「一直看榜、看到好运就提交」，但 Ville 不等式保证不会因此虚增。这把「基准测试」从一次性评估升级为可审计、抗偷看的证书语义。

2. **机器人竞赛 → 把外部竞争者变成基准的维护者：对抗种群 + 极小极大 / Pareto 认证**。竞赛的本质不是平均分，而是「有人专门找你的漏洞并刷分」。v5 的红队是一次性集合；v6 把外部提议者/红队建模为**对抗种群 A={π_adv}**，认证判据从平均边际改为**极小极大边际** M_adv(x)=min_{a∈A} LCB(m(x;a))，并在困难分层上用 CVaR。榜单不标量化：只接受「成功率 LCB 不降 且 安全边际 LCB 不降（至少一者严格升）」的 **Pareto 改进**，拒绝用单一标量换取「刷榜」。新对抗任务只能经**受治理的晋级协议**（签名种子、可复现、污染审计、独立复核、版本单调）进入基准，避免「基准投毒」与「对抗者塌缩」。

3. **合流 → 认证 = 在对抗基准上带统计下界的逐层通过**。基准回答「这张卷子是否可信、是否覆盖部署」；统计回答「这点分数是不是运气」；竞赛对抗回答「是否只对已知红队过拟合」。三者正交且都只收紧：LCB ≤ 点估计、minimax ≤ 平均、受治理晋级只增不减。代价是**自主性**：在分布外、样本不足或对抗覆盖不足时，更多回退与拒证——这是一个诚实的「覆盖–鲁棒性–样本量」前沿，而非可以两全的优化。

**关键洞见**：v5 证明了「换提议不换门」；v6 进一步指出，**门所依赖的评测基准、以及读取基准的统计程序，同样是信任边界的一部分**，v5 把它们留在了未认证的背景里。ABCE 不加门，而是把基准提升为「裁判权威」、把统计提升为「证书的语法」：七硬门 kc_evidence_forged_v4 原样复用，新增的只有：对抗基准权威 B 与极小极大边际 M_adv（并入 kc_val/kc_bal 的读取方式）、时间均匀 LCB 与证书字段 (LCB, α, n, B_v)、排行榜查询预算与 DP 发布、软评分 ECS_v6 = ECS_v5·η_bench·η_stat。执行集 Exec_v6 ⊆ Exec_v5 由「同门 + LCB 只紧 + minimax 只紧 + 基准版本约束」保证。

**形式化目标（增量）**：
1. 基准清单 B=(S, r, D_fit/D_val/D_test/D_adv, P_pert, B_hash)；污染度 C(D_train,D_test) ≤ δ_b 才可用于认证；D_test 轮换且不公开。
2. 时间均匀 LCB：e-process E_t 由 Ville 不等式反演，P(∀t, μ ≥ LCB_t) ≥ 1−α；跨分层用 e-value 合并（免 Bonferroni 保守）。
3. 门读取：kc_i^v6(x,c)=1[LCB_s(m_i(x,c)) ≥ τ_i^5], ∀s∈S；点估计→LCB ⇒ Exec_v6 ⊆ Exec_v5。
4. 对抗极小极大：M_adv(x)=min_{a∈A} LCB(m(x;a))；认证要求 M_adv ≥ τ_adv 且逐层 CVaR_β ≥ τ_cvar。
5. 榜单：Pareto 接受（成功率 LCB↑、安全边际 LCB 不降）；DP 查询预算 (ε_lb,δ_lb) 限制刷榜信息；预注册评测协议。
6. 晋级协议：新对抗任务需签名种子 + 可复现 + 污染审计 + 独立复核 + 版本单调；B 变更 ⇒ 旧证书失效重签。
7. 定理 9（基准相对可靠性/覆盖界）、定理 10（时间均匀认证抗 optional stopping）、定理 11（LCB+minimax 单调收缩）、定理 12（Goodhart 抗性前沿）、定理 13（基准治理与共演化有界）。
8. 软评分：η_bench=σ((M_adv−τ_adv)/β_b)，η_stat=exp(−λ_s·width_CI)；ECS_v6=ECS_v5·η_bench·η_stat。
9. Exec_v6={x∈Exec_v5 : ∀s LCB_s(m)≥τ_s^5 ∧ M_adv(x)≥τ_adv ∧ B_v=B_now} ⊆ Exec_v5。

**本轮最大风险**：**基准与对抗者共谋/共演化，使统计证书建立在不可交换分布上**——基准有限、会漂移，对抗任务又由同一治理方晋级；若缺乏独立外部锚，基准与红队会一起过拟合到「自家榜单」，LCB 再严也只是「在错误卷子上正确地拿高分」（赢了自家排行榜的统计自欺）；而竞赛压力会持续侵蚀查询预算与隐藏留出集。

## 2. 关键算法骨架

### IP-497 ABA：对抗基准权威核（支撑查询 O(log|B|)；污染/晋级审计离线）

```python
@dataclass
class AdversarialBenchmarkAuthority:
    """ABA：把评测集提升为可审计的「裁判权威」。
    红线：D_test 永不进入训练；B 变更 ⇒ 所有旧证书失效重签"""
    B_hash: str                    # 基准版本锚 B_v
    strata: list                   # S
    D_fit: Any; D_val: Any         # 可见划分
    D_test: Any                    # 隐藏、轮换、不公开
    D_adv: Any                     # 对抗划分（由 CCEL 晋级）
    delta_b: float = 0.02
    tau_adv: float = 0.0

    def contamination(self, train_episodes) -> float:
        dup = near_dup_rate(train_episodes, self.D_test, eps_d=0.05)
        canary = canary_memorization(train_episodes, self.D_adv)
        return max(dup, canary)

    def certify(self, pi, scc, A) -> tuple[bool, 'Cert | None', str]:
        # 1) 污染闸：训练泄漏进隐藏测试 → 拒证
        if self.contamination(pi.train_episodes) > self.delta_b:
            return False, None, 'BENCH_CONTAMINATED'
        # 2) 逐层时间均匀 LCB（SCC），门边际换成下界
        lcb = scc.per_stratum_lcb(pi, self.D_test, self.strata)
        if any(lcb[s] < self.tau(s) for s in self.strata):
            return False, None, 'LCB_BELOW_TAU'
        # 3) 对抗极小极大 + 困难层 CVaR
        m_adv = min(scc.lcb(pi, a, self.D_adv) for a in A)
        if m_adv < self.tau_adv or scc.cvar(pi, A, beta=0.1) < self.tau_cvar:
            return False, None, 'ADVERSARIAL_MARGIN'
        return True, Cert(lcb=lcb, m_adv=m_adv, B_v=self.B_hash), 'CERTIFIED_ABCE'

    def promote(self, adv_task) -> bool:
        """晋级：签名种子可复现 ∧ 污染审计 ∧ 独立复核 ∧ 版本单调"""
        return (verify_signed_seed(adv_task)
                and self.contamination([adv_task]) <= self.delta_b
                and independent_review(adv_task)
                and self.B_hash != hash_bump(self.B_hash, adv_task))
```

### IP-498 SCC：统计证书演算（每周期 O(1)；LCB 由 e-process 反演）

```python
@dataclass
class StatisticalCertificateCalculus:
    """SCC：时间均匀 LCB + e-value 跨层合并。
    定理 10：任意停时（含「刷到通过为止」）下 P(μ ≥ LCB_τ) ≥ 1−α"""
    alpha: float = 0.05
    lam: float = 0.5               # betting 强度（可自适应 hedged）

    def update(self, s, x) -> float:
        # X ∈ [0,1]；E_t = ∏(1 + λ_i (X_i − μ0))；Ville 反演得 LCB
        self.E[s] = self.E[s] * (1.0 + self.lam * (x - self.mu0[s]))
        return self.lcb_from_e(self.E[s], self.n[s])

    def lcb_from_e(self, E, n) -> float:
        # 由 E_t ≥ 1/α 的拒绝域反演；宽度 O(sqrt(log log n / n))（引理 48）
        return self.mu_hat - self.width(n, self.alpha)

    def merge_strata(self, Es) -> float:
        # e-value 凸合并：(1/|S|)Σ E^(s) 仍是 e-process，免 Bonferroni
        return mean(Es)

    def per_stratum_lcb(self, pi, D_test, strata) -> dict:
        return {s: self.lcb(pi, s, D_test) for s in strata}
```

```python
    """定理 11：LCB_s ≤ μ̂_s 且 M_adv=min_a LCB ≤ mean_a LCB ≤ 平均边际，
    故 {LCB≥τ}⊆{μ̂≥τ}，Exec_v6⊆Exec_v5；基准版本与覆盖约束进一步收缩；
    n→∞、A 单元素、B_v 不变时 LCB→μ̂、M_adv→边际，精确退化 v5。∎"""
    return "Proven"

# 定理 12：Goodhart 抗性前沿
def theorem_goodhart_frontier() -> str:
    """定理 12：对任意标量榜单与预算 K，选择 max_{k≤K} ŝ_k 的期望虚高
    ≥ σ·sqrt(2 ln K)/sqrt(2π)（极值膨胀），标量刷榜必然。引入
    (a) 轮换隐藏 D_test、(b) Pareto 部分序、(c) DP 发布后，可提取过拟合
    信息 ≤ O(K·ε_lb)，且不能以安全边际换成功率。诚实边界：只把博弈速率
    压进预算界，不能根除。∎"""
    return "Proven (bounded gaming); no free lunch"

# 定理 13：基准治理与共演化有界
def theorem_benchmark_governance() -> str:
    """定理 13：若晋级满足 (P1) 签名种子可复现、(P2) 污染审计通过、
    (P3) 独立复核、(P4) 版本单调且 B 变更使旧证书失效，则
    (i) 基准只增不减；(ii) 对抗分布漂移以晋级审计为界；
    (iii) 无「用旧卷子领新证」。诚实边界：治理方与对抗者同一实体时，
    P3 是组织问题而非技术问题。∎"""
    return "Proven (under independent governance)"
```

### IP-500 EFA-v6：七硬门 + LCB 读取 + minimax 选证 + 基准版本约束

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：门集合不变（τ^6=γ·τ^4，只紧）+ 基准相对 + 统计有效 + 对抗鲁棒"""
    fmpp: Any; lmem: Any; famk: Any
    aba: AdversarialBenchmarkAuthority
    scc: StatisticalCertificateCalculus
    ccel: CompetitiveCoEvolutionLoop
    v5: EvidenceForgingAssemblerV5

    def select(self, x0_state, t_now, rule_id, context) -> tuple[str, Any, str]:
        # 1) 基准版本/污染：版本不符或训练泄漏 → 拒证回退
        if context.B_v != self.aba.B_hash or self.aba.contamination(context.eps) > self.aba.delta_b:
            return 'FALLBACK', self.v5._fallback_rule_proposal(context), 'BENCH_STALE_OR_CONTAMINATED'
        # 2) 对抗覆盖：A 覆盖不足 → 视为域外，回退而非冒险
        if self.ccel.coverage_gap(self.aba.D_adv) > self.aba.eps_A_max:
            return 'FALLBACK', self.v5._fallback_rule_proposal(context), 'ADV_COVERAGE_LOW'
        # 3) 提议 → v5 级联，但门读取换成逐层 LCB
        s_emo = self.famk.observe(context.face, t_now)
        gamma = self.famk.gamma(s_emo)
        ok, x, why = self.v5.select_with_reader(
            x0_state, t_now, rule_id, context,
            tau=compose(gamma, TAU4),
            reader=lambda margin: self.scc.lcb(margin, self.aba.strata))
        if not ok:
            return 'SAFE_STOP', None, why
        # 4) 极小极大：通过者中取 M_adv 最大者（不是平均边际最大者）
        x = max(x, key=lambda z: self.scc.lcb_minimax(z, self.ccel.A))
        # 5) 签发带统计与基准字段的证书
        cert = Cert(x=x, LCB=why.lcb, alpha=self.scc.alpha, n=why.n,
                    t_issue=t_now, T_val=why.T_val,
                    B_v=self.aba.B_hash, theta_v=self.fmpp.version)
        return 'FORGED', cert, 'FORGED_ABCE'

    def ecs_v6(self, base_v5, m_adv, width_ci) -> float:
        eta_bench = sigmoid((m_adv - self.aba.tau_adv) / BETA_B)
        eta_stat = exp(-LAMBDA_S * width_ci)
        return base_v5 * eta_bench * eta_stat
```

|---|---|---|---|---|

**通信开销**：B_hash（32 B）与评测协议摘要随证书下发；对抗原型与基准参考原型经 DP（~2 KB/站）；隐藏 D_test 与金丝雀只存托管侧，站点不可写、不可读。排行榜只发布 DP 加噪分数。

**统计/样本预算**：逐层 LCB 的宽度按引理 48 约为 O(√(log log n / n))；要把宽度压到 β_b=0.05 量级，单层需 n≈数千条独立评测样本——这是 v6 新增的主要「数据税」，也是自主性下降的来源。

## 4. 正确性论证（增量更新）

### 引理 48（e-process 反演 LCB 的宽度）

**陈述**：对 [0,1] 有界观测，hedged-capital e-process 反演的 LCB 宽度 w_n = O(√(log log n / n)) + O(1/n)，仅比固定样本 Hoeffding 界多 log log 因子；因此「时间均匀」几乎不付额外样本代价。∎

### 引理 49（minimax 覆盖缺口）

**陈述**：设 F={门通过 ∧ 部署语义失败}，A 在边际度量下是 F 的 ρ-网、覆盖缺口 P(F\N_ρ(A)) ≤ ε_A，则部署失败率与认证对抗失败率之差 ≤ ε_A + L_gap·δ_b。∎

**诚实边界**：ε_A 无法从有限数据精确估计，只能由对抗覆盖审计给经验上界；这是 v6 最脆弱的量。

### 引理 50（DP 排行榜查询上界）

**陈述**：K 次自适应查询、每次 (ε_lb,δ_lb)-DP 发布，总过拟合信息增益 ≤ K·ε_lb（基本组合定理）；预算耗尽即拒绝新查询。∎

### 定理 v6（基准相对 + 统计有效 + 对抗鲁棒，总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) 基准污染度 ≤ δ_b、(B9) 对抗种群覆盖缺口 ≤ ε_A、(B10) e-process 非负上鞅（观测可交换）下：
(i) Exec_CADVS-v6 ⊆ Exec_CADVS-v5（严格：LCB 与 minimax 非恒真）⊆ … ⊆ Exec_v29；
(ii) 基准相对：部署语义失败率由定理 9 界约束（覆盖域内）；
(iii) 统计有效：任意停时下 LCB 覆盖 ≥ 1−α（定理 10），反复看榜不虚增；
(iv) 对抗鲁棒：认证要求 M_adv ≥ τ_adv，minimax ≤ 平均 ⇒ 只缩不涨（定理 11）；
(v) Goodhart：标量榜单必被极值刷分，Pareto+隐藏集+DP 把博弈压进预算界（定理 12）；
(vi) 治理：受治理晋级使基准单调、旧证书随 B 变更失效（定理 13）。

**证明**：(i) 由 LCB ≤ 点估计、minimax ≤ 平均、基准版本约束；(ii)~(vi) 分别由定理 9~13 与引理 48~50。∎

**诚实声明**：(B10) 可交换性在机器人竞赛中经常被违反——任务非平稳、对抗者自适应、部署分布随对手策略漂移，此时时间均匀界只保证「对错误模型正确」；(B9) 的 ε_A 不可直接估，OOD 下失效；定理 12 只界可观测的刷榜，不能根除；基准治理的独立性 (P3) 是组织问题；v5 的 (B4) 加性价值假设仍未解决。

## 7. 本轮最大风险（最终确认）

**一句话**：**基准与对抗者共谋/共演化，使统计证书建立在不可交换分布上**——基准有限、会漂移，对抗任务又由同一治理方晋级；若缺乏独立外部锚，基准与红队会一起过拟合到「自家榜单」，LCB 再严也只是「在错误卷子上正确地拿高分」（赢了自家排行榜的统计自欺）；而竞赛压力会持续侵蚀查询预算与隐藏留出集。
