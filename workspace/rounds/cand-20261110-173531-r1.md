# 第 47 轮（新一轮第 1 轮；承接第 46 轮产物 v23；本轮灵感：多模态交互 × 创新点） · XMI-Cert：跨模态意图证书与可证伪创新账本（五层架构 v11）

> 承接 v23 Memory-Safety-Voice。v23 把语音、记忆检索与安全绑定串成闭环，但隐含假设 H5：**用户意图可由单一语音通道可信还原，且"创新点"只需被声称、无需被证伪**。本轮两个灵感词精确命中 H5：**多模态交互**意味着意图证据天然来自语音/手势/注视/触控/表情多源、异步、甚至互相冲突，单通道置信会被系统性高估；**创新点**本身应当被视为一条可证伪的差值命题（相对最近先验工作的增益 + 一个能被实验推翻的预言），而不是写作时的修辞。于是新问题变为：**如何在通道异步、冲突、可被欺骗的条件下，签发一个带覆盖保证的意图证书 Ĩ_t，并把每个 IP 的新颖性也纳入同一套证书账本，使"多模态交互"与"创新声明"二者都不再是静默假设**。

## 0. 直觉与动机

**灵感 1（多模态交互 → 意图是集合，不是点）**
直觉：说"那个"时手指的方向、视线落点、身体朝向共同限定了"那个"指谁；任何单一通道都只是对意图假设空间 H 的一次带噪投票。与其输出一个 argmax 意图，不如输出一个**在标定覆盖率下必然包含真实意图的集合** Ĩ_t。多模态的价值不在于把置信从 0.8 抬到 0.9，而在于**在相同覆盖率下缩小集合宽度**——这才是可度量的交互收益。

**灵感 2（通道冲突与异步 → 仲裁与主动消歧）**
直觉：当语音说"左"而手指向右、或注视仍停留在上一个物体时，系统不该平均一下蒙混过关；冲突本身是信息，它要么触发一次**主动消歧提问**，要么触发**保守安全盒**。异步则要求每个通道带时间戳与新鲜度 τ_k，过期通道降权甚至失效，否则会把"上一刻的注视"当成"此刻的意图"。

**灵感 3（创新点 → 可证伪的差值命题）**
直觉：一个"创新点"若不能写出"它比谁好、好多少、在什么条件下会被证伪"，它就只是命名。把每个 IP 编码为 claim γ=(指标 μ, 基线 b, 门限 ε, 最接近先验工作集合 A(γ), 证伪实验 F)：新颖 = 相对 A(γ) 的差值下界 > ε 且 F 未被观测到。这样创新声明与姿态证书共享同一种工程纪律：**先给覆盖，再给结论**。

**耦合升级**：在 v10/v23 四层上插入 **L2.5 交互意图层**（XMI/XCA），并新增离线的 **创新账本回路**（IIL）。五层 v11：根信任层（姿态租约 ℓ_p + 能量租约 ℓ_e）→ L1 几何层（PSE/分层半径）→ L2 上下文预测层（C_t）→ **L2.5 跨模态意图证书层（Ĩ_t）** → L3 安全运行时（CAR/SAB，用 Ĩ_t 做最坏情况绑定）→ L4 采集闭环（DCL，含消歧查询与证伪实验）。MVR 的记忆键从"语音向量"升级为"意图证书 + 上下文"。

## 1. 形式化定义（增量：定义 59–64）

**定义 59（多模态证据流与新鲜度）**
通道集合 K={voice, gesture, gaze, touch, expression}。第 k 通道在时刻 t 的观测 o_k(t_k)。对齐误差 δ_k=|t-t_k|，新鲜度权重
ν_k(t)=exp(-δ_k/τ_k)·1[δ_k≤W]，
其中 W 为对齐窗口、τ_k 为通道时间常数。**可达通道集** K_t={k: ν_k(t)>0}。若 |K_t| 低于下限则意图证书直接失效并触发保守模式。

**定义 60（通道似然、有效独立性与冲突度）**
对意图假设 h∈H，通道 k 的标定似然 L_k(h)=P_k(h|o_k(t))。融合后验
P(h|o_{K_t}) ∝ P(h)·∏_{k∈K_t} L_k(h)^{w_k},
其中 w_k=ρ_k(c_t,ω_t)·ν_k(t)·g_k，g_k 为有效独立性修正（用通道对间互信息 I(k,k') 估计，避免把高度相关的语音-文本重复计数）。冲突度
C_t=mean_{k<k'} JS( L_k ‖ L_{k'} ) ∈ [0,1]，
并定义**分歧集中度** C_t^max=max_{h≠h'} |L_k(h)-L_{k'}(h)| 用于定位歧义假设对。

**定义 61（跨模态意图证书）**
Ĩ_t 为 H 上最小（按基数、同基数按后验质量）子集，满足共形标定
P( h*∈Ĩ_t | K_t, c_t, ω_t ) ≥ 1-α_i。
宽度 w_t=|Ĩ_t|，歧义熵 H_t=H(P(·|o_{K_t}))。**通道降级下的 soundness**：若某通道失效，必须用缩减后的 K_t 重新标定，禁止沿用全通道 α_i 覆盖率。

**定义 62（交互-安全联合证书）**
J_t=(Ĩ_t, P_t, ℓ_p, ℓ_e, m_t, a_t)。动作 a_t 可执行当且仅当
B_wc(a_t, Ĩ_t, P_t)=min_{h∈Ĩ_t} B(a_t; h, P_t) ≥ θ_safe
且姿态租约与能量租约同时有效。**关键点**：绑定取**最坏意图**而非期望意图，因为证书承诺的是"真实意图落在集合内"，不是"最可能意图正确"。

**定义 63（创新声明证书 ICC）**
声明 γ=(μ, b, ε, A(γ), F)，μ 为指标、b 为基线、ε 为最小可声称增益、A(γ) 为最近先验工作覆盖集、F 为证伪实验。经验差值 δ̂ 及配对 bootstrap 区间 [δ_lo, δ_hi]。
**认证判据**：\(\text{ICC}(\gamma)=\mathbb{1}[\delta_{lo}>\varepsilon]\cdot\mathbb{1}[A(\gamma)=\varnothing \lor \delta_{lo}>\mathrm{gap}(A(\gamma))]\cdot\mathbb{1}[F\ \text{未观测到}]\)。
未通过者只能标为"假设"，不得进入产物区主表。

**定义 64（主动消歧策略）**
候选查询 q∈Q（复问、指向确认、注视引导、触控候选）。信息增益
IG(q)=H_t − E_{r~q}[H(P(·|o_{K_t∪r}))]，
交互成本 cost_q 含时间、能量、用户负担。当 C_t>C_conf 或 w_t>w_max 时，若
IG(q)/cost_q > λ_q 且 Risk_ambig(Ĩ_t) > Risk_query(q)，
则发起查询；否则返回保守盒并拒答。

## 2. 新增产出与既有 IP 升级

**IP-69 XMI（Cross-Modal Intent Certifier）**
- 多通道时间对齐 + 新鲜度门控
- 独立性修正的贝叶斯融合与共形意图集合标定
- 通道缺失/降级时的重标定，保证覆盖率不静默衰减

**IP-70 XCA（Conflict-Arbitration & Active-Disambiguation）**
- 冲突检测（JS 散度 + 分歧集中度）与通道欺骗嫌疑标记
- 主动消歧查询选择（信息增益/成本）
- 保守盒回退与用户二次确认

**IP-71 IIL（Innovation Ledger，创新账本）**
- 把每个 IP 登记为可证伪 claim γ，附最接近先验工作与证伪实验
- 自动复跑证伪实验，跟踪 δ̂ 的置信区间与先验覆盖集变化
- 生成"新颖性审计轨迹"，纳入 CCA 审计

**既有 IP 升级**
- IP-66 MVR：记忆键由 encode(v_t) 改为 (Ĩ_t, c_t, ω_t, B_t)，检索到冲突意图时屏蔽
- IP-67 VAD：降为 XMI 的一个通道，不再单独决定执行
- IP-68 SAB：绑定由期望意图改为最坏意图 B_wc，队列元素携带 Ĩ_t 快照
- IP-61 DCL：采集任务加入消歧查询与 ICC 证伪实验，计入能量租约
- IP-62 CCA：新增通道欺骗红队、意图证书覆盖率审计、创新声明复现审计
- IP-51 CAR：守卫加入 |K_t| 下限与冲突否决
- IP-45 总线：新增 intent-cert / conflict / disambiguation / claim-ledger 话题

## 3. 算法骨架

每个交互控制周期：
1. 收集 K_t，计算 ν_k(t) 与对齐；剔除过期/欺骗嫌疑通道
2. 计算 L_k、w_k（独立性修正），融合得 P(h|o_{K_t})
3. 共形标定得 Ĩ_t、w_t、C_t；检查 |K_t| 下限
4. 若 C_t>C_conf 或 w_t>w_max → XCA 选查询 q 或进入保守盒
5. 对每个候选动作 a，用 B_wc(a,Ĩ_t,P_t) 过滤，再叠加 ℓ_p/ℓ_e 可行性
6. CAR 用 J_t 守卫；SAB 执行或入安全队列
7. 本周期日志写入 IIL/DCL：证书、冲突、查询、结果
离线：IIL 定期对每个 claim 复跑 F，只有当 δ_lo>ε 且无先验覆盖时才保留"创新点"标签。

## 4. 本轮最大风险

**一句话**：多通道高度相关或多通道被同一扰动同时欺骗时，独立性修正会失效、融合后验会给出"又窄又稳"的假置信，意图证书 Ĩ_t 在最坏意图绑定下仍可能漏掉真实意图，使系统以极低感知成本执行了错误动作；因此必须以独立审计集做逐通道与联合覆盖率校准，并在冲突度或通道冗余度超阈时强制降级为主动消歧或保守盒，绝不让"多模态"变成"多重同源错误的放大器"。

## 2. 关键算法伪代码

### IP-69 XMI：对齐、融合与共形意图集合
```python
def align(streams, t, W, tau):
    K_t, ev = [], {}
    for k, obs in streams.items():
        near = [o for o in obs if abs(t - o.t) <= W]
        if not near:
            continue
        o = max(near, key=lambda x: x.t)          # 取最新
        nu = exp(-abs(t - o.t) / tau[k])
        if nu > NU_MIN and not o.spoof_suspect:
            K_t.append(k); ev[k] = (o, nu)
    return K_t, ev

def effective_weight(k, ev, rho, mi):
    # g_k = 1 / (1 + sum_{k'} I(k,k'))：抑制同源通道重复计数
    g = 1.0 / (1.0 + sum(mi[(k, kk)] for kk in ev if kk != k))
    return rho * ev[k][1] * g

def fused_posterior(ev, c_t, omega_t, prior, calib, mi):
    logp = log(prior + EPS)
    for k, (o, nu) in ev.items():
        rho = calib.rho[(k, omega_t, c_t.bucket)]   # 分层标定可靠性
        w = effective_weight(k, ev, rho, mi)
        logp += w * log(clamp(calib.channel_post(k, o), EPS, 1 - EPS))
    return softmax(logp)

def certify_intent(K_t, ev, c_t, omega_t, prior, calib, mi, alpha_i):
    p = fused_posterior(ev, c_t, omega_t, prior, calib, mi)
    # 共形分位数 q_hat 由独立审计集按 (通道数, omega_t) 分层校准
    q_hat = calib.conformal_q(len(K_t), omega_t, alpha_i)
    order = argsort(p)[::-1]
    I = [h for h in order if p[h] >= 1 - q_hat]     # 最小高概率集
    if not I:
        I = [order[0]]
    return I, len(I), entropy(p), p
```

### IP-70 XCA：冲突判断与主动消歧
```python
def conflict_score(posts):
    vals = [mean_pairwise_js(posts[k1], posts[k2])
            for i, k1 in enumerate(posts) for k2 in list(posts)[i+1:]]
    return mean(vals) if vals else 0.0

def arbitrate(ev, c_t, omega_t, prior, calib, mi, alpha_i,
              theta_conf=0.35, w_max=4, lambda_q=0.1):
    posts = {k: calib.channel_post(k, o) for k, (o, _) in ev.items()}
    C = conflict_score(posts)
    I, w, H, p = certify_intent(list(ev), ev, c_t, omega_t, prior, calib, mi, alpha_i)
    if C > theta_conf or w > w_max:
        best_q, best_ratio = None, -inf
        for q in allowed_queries(c_t, I):
            H_after = expected_entropy_after(q, p, calib)
            ratio = (H - H_after) / max(q.cost, EPS)
            if ratio > best_ratio:
                best_q, best_ratio = q, ratio
        if best_ratio > lambda_q and Risk_ambig(I, C) > Risk_query(best_q):
            return ('query', best_q, I, C)
        return ('conservative', safe_box(I), I, C)   # 拒答 / 收窄
    return ('certified', I, I, C)
```

### IP-71 IIL：创新声明认证
```python
def certify_claim(gamma, corpus, exp_runner):
    A = nearest_prior_art(gamma, corpus, top_k=20)
    covered = any(covers(a, gamma) for a in A)          # 先验是否已覆盖该增益
    cover_gap = min_gap(A, gamma)                        # 最近先验的增益上界
    delta, lo, hi = paired_bootstrap(exp_runner(gamma), gamma.metric, n=5000)
    falsifier_hit = run_falsifier(gamma.F, exp_runner)   # True 表示预言被推翻
    certified = (lo > gamma.epsilon) and \
                (not covered or lo > cover_gap) and \
                (not falsifier_hit)
    return {
        'claim': gamma, 'prior_art': A, 'delta': (delta, lo, hi),
        'certified': certified,
        'audit': build_trace(A, delta, lo, hi, falsifier_hit),
    }

def refresh_ledger(L, corpus, exp_runner, cycle_hours=168):
    return [certify_claim(g, corpus, exp_runner)
            for g in L if g.last_audit + cycle_hours <= now()]
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| XMI 对齐+融合 | O(\|K\|·\|H\|) 每周期 | O(\|H\|+\|K\|) | 分层共形标定 ⇒ P(h*∈Ĩ_t)≥1-α_i（在标定分布内） |
| XCA 冲突检测 | O(\|K\|²·\|H\|) | O(\|K\|·\|H\|) | C_t 超阈 ⇒ 拒答或消歧，不发无证书动作 |
| 主动消歧选择 | O(\|Q\|·\|H\|) | O(\|H\|) | IG/cost 单调收益，仅在有正收益时提问 |
| SAB 最坏绑定 | O(\|Ĩ_t\|) | O(1) | B_wc≥θ_safe ⇒ 所有证书内意图均安全 |
| IIL 认证 | O(\|A\|·d + n·B) | O(\|A\|·d) | 认证仅当 δ_lo>ε 且先验未覆盖且证伪未命中 |
| 全局决策 Π | O(\|K\|²\|H\|+\|M\|·d) | O(\|Q_safe\|·\|H\|) | 通道不足/冲突/证书宽 ⇒ 保守或 fail-closed |

**定理 1（意图证书的通道降级 soundness）**：若对每个可达通道子集 S 都用独立审计集按 (|S|, ω_t) 分层标定共形分位数 q̂_S，且 Ĩ_t 由该分位数构造，则在可交换性假设下 P(h*∈Ĩ_t | K_t=S) ≥ 1-α_i，与通道缺失无关；若沿用全通道 q̂ 则覆盖率按 \|S\| 单调下降，故必须重标定。

**定理 2（最坏意图绑定的安全性）**：若真实意图 h*∈Ĩ_t 且 B_wc(a,Ĩ_t,P_t)≥θ_safe，则对任意 h∈Ĩ_t 有 B(a;h,P_t)≥θ_safe，从而 h* 的动作-安全绑定满足阈值。该定理只保证"证书内"安全，其有效性完全依赖定理 1 的覆盖率与 B 的校准。

**定理 3（创新声明的可证伪性）**：IIL 认证的 claim 必带一个可执行证伪实验 F；若 F 在复跑中被观测到，则 ICC 由 1 翻为 0。因此不存在"永真"的创新点，只有"尚未被证伪且差值下界超过门限"的创新点。

## 4. 实验设计 E115–E120

| 实验 | 指标 | 门槛 |
|---|---|---|
| E115 意图证书覆盖率 | 经验覆盖率 vs 1-α_i；平均宽度 w_t | \|cov-(1-α_i)\|≤0.03；w_t≤3（语音+手势+注视） |
| E116 通道冲突仲裁 | 冲突检出率；误报率；仲裁延迟 | 检出≥95%；误报≤5%；延迟≤120ms |
| E117 主动消歧收益 | IG/cost；用户负担（提问次数） | 平均 IG/cost≥0.5；每任务提问≤1.5 次 |
| E118 交互-动作绑定安全 | B_wc 达标率；误执行率 | 安全率≥99.5%；误执行 0 起（100h） |
| E119 创新账本复现 | claim 认证率；证伪命中率；先验覆盖准确率 | 认证率≥70%；证伪命中≤10%；覆盖误判≤5% |
| E120 100h 五层闭环 | 交互成功率；能量消耗；fail-closed 次数 | 成功率≥95%；能耗≤v23 基线+8%；fail-closed≤1/班 |

**回退策略**：
- E115 覆盖率偏差 >0.05 → 增大共形分位数、按通道组合更细分层重标定；
- E116 误报 >10% → 提高 θ_conf，并禁用 JS 冲突项，改用分歧集中度；
- E117 提问过多 → 提高 λ_q，优先保守盒；
- E118 出现误执行 → 立即下调 θ_safe 容忍、强制二次确认，并冻结 XMI 自动执行；
- E119 证伪命中 >20% → 将对应 claim 全部降级为"假设"，禁止进入主表。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 多通道同源相关导致假置信 | 高 | 独立性修正 g_k + 冗余度阈值；冗余过高强制降级 |
| 通道被同步欺骗（伪造语音+手势） | 高 | 欺骗嫌疑标记 + 跨时段一致性检查 + CCA 红队 |
| 共形标定分布漂移 | 高 | 按 (通道组合, ω_t) 分层；在线覆盖率监控触发重标定 |
| 主动提问打断任务 | 中 | IG/cost 门限 + 每任务提问预算 + 安全队列 |
| 创新账本自我欺骗（挑选有利基线） | 高 | 固定基线协议 + 预注册证伪实验 + 第三方语料复跑 |
| 最坏意图绑定过保守导致不可用 | 中 | 主动消歧缩小 Ĩ_t；仅在证书过宽时收窄安全盒 |

## 6. 本轮结论

多模态交互的正确用法不是"融合出更高置信"，而是"在标定覆盖率下缩小意图集合，并让动作安全绑定取最坏意图"；同时把"创新点"降格为带先验覆盖集与证伪实验的差值命题，二者都从修辞变成可审计证书。五层 v11 因此把 L2.5 意图证书层与离线创新账本接入原有的姿态/能量/记忆/安全闭环。

## 7. 本轮最大风险

**一句话**：多通道同源相关或被同步欺骗时，独立性修正和融合后验会制造"又窄又稳"的假置信，Ĩ_t 可能漏掉真实意图，而最坏意图绑定也无法挽救一个错的证书；因此必须以独立审计集做逐通道组合的覆盖率校准、在冗余度或冲突度超阈时强制消歧或保守盒，并让 IIL 对每个"创新点"持续复跑证伪实验，否则"多模态"与"创新"都只会变成更精致的静默假设。
