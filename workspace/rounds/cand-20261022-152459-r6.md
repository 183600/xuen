# 想法区 · 第 9 轮：从 X-DUB/TQ* 到 X-DUB/EC*

**灵感词**：np-hardness / 并查集 / 重叠子问题  
**起点**：v0.6「X-DUB/TQ*」。它已经有 TENT 强制段打包、阈值二分、Q-DOM 势商、focal + guide、证明 DAG。本轮不推翻它；本轮做的是**先诊断、再决定还要不要造证书**。

## 一句话直觉：最后一格不是"更难的容量"，而是"NP-hard 本身"；既然核是全局的，就别再近似它，去把精确判定做便宜

v0.6 用了一整轮把窗口证书从"完全被迫"升级到"帐篷的部分强制段"，根下界从 691 提到 697，30 个困难实例里 29 个在根上闭合。剩下的 k=29 差 1：`L_TENT=34`，`OPT=35`。v0.6 的结论是"需要更强的顺序/机器耦合证书"。

我这一轮先没有设计算法，而是问了一个诊断问题：**把 `H=OPT-1` 处的不可行性当成一个 NP-hard 判定问题，它的最小不可行核有多大？**

做法：定义核证书族 `KS(K)`——只对 `K⊆R` 精确判定（保留 `K` 内的优先约束、release=`est`、deadline=`H-q`、`m` 台机器），把其余任务全丢掉。丢任务只会放松约束，所以 `KS(K)=NO ⇒ H` 不可行；`K=R` 时它就是原问题。然后从 `K=R` 出发贪心删任务，得到最小不可行核（MUS）。

结果很不客气：

```text
11 个状态级 gap：|R|=5–8，MUS=3–8，均值比例 0.90；6/11 的 MUS 就是整个 R
pool30[29] 根：  |R|=10，MUS=8
```

也就是说，**在 `H=OPT-1` 处，不可行性不是少数几个任务造成的**。任何"找到小的不可行子集、对它精确求解"的核化路线，在这批实例上都没有出路。这是第一个负结果，但它把方向定死了：不要再去近似那个不可行区域，它本来就是全局的。

## 第二个诊断：空集定理——"被完全迫的任务"在最难的一档必然为空

v0.5 的 THRESH、v0.6 的零松弛收缩、我原本想做的"并查集固定块"，都建立在同一件事上：`sl_i = (H-q_i-p_i)-est_i = 0` 的任务被钉死在 `[est_i, est_i+p_i)`。

但这里有一个一句话的定理：

```text
若 L0(σ) ≤ H-1，则 {i : sl_i(σ,H)=0} = ∅。
```

因为 `sl_i=0` 等价于 `est_i+p_i+q_i=H`，而 `L0 ≥ est_i+p_i+q_i`。取 `H=OPT-1`，就得到：

```text
OPT(σ) - L0(σ) ≥ 2  ⇒  H=OPT-1 处没有任何任务被钉死。
```

这条推论一次性解释了整条证书路线的困境：**gap≥2 时，forced set 是空的**。v0.5 的 THRESH 收集"完全被迫"的任务，空转；fixed-block 收缩，空转；并查集块，空转。它也解释了 v0.6 的一个实验事实——真正有用的是"部分 item"：`e_i` 在 `sl_i>0` 时仍为正，所以 TENT 还能工作；但部分 item 只能给出松弛，给不出最后一格。

实测完全吻合：12 个 gap 案例在 `H=OPT-1` 处 `|B|=0`；只有 `H=U-1`（`U` 还松）时才有 16 个任务可收缩。

这就是本轮对**并查集**的第一个交代：我设计了三种收缩（零松弛块、静态自同构类、优先分量），其中两种被空集定理/稀有性判了"无用"。这是结论，不是遗憾——它说明在这一档上不存在"被迫结构"可以利用。

## 第三个观察：v0.6 的能量界只用在了根上

`L0` 里的 `⌈Σ_R p/m⌉` 是能量界，但它把机器已经占用的时间 `ΣA` 扔掉了。正确的逐节点版本是

```text
E(R,A) = ⌈( Σ_{i∈R} p_i + Σ_k A_k ) / m ⌉.
```

它显然可采纳：机器 `k` 在 `[A_k,C)` 内最多贡献 `C-A_k` 的工时，所以 `Σp ≤ mC-ΣA`。v0.6 只在搜索节点的顶端用它（而且用的是丢掉 `ΣA` 的弱化版），判定 DFS 的每个节点都没有用。

我把它放进判定 DFS 的**每一个节点**，就这一件事：

```text
30 个 pool 根的精确判定节点数
  无能量剪枝        367,704
  有能量剪枝          5,483      （67×）
  上一轮独立精确 DFS  2,220,019  （405×）
```

这比 v0.6 一整轮的证书工程都大。它不是什么新松弛，而是把一个已知界放到正确的位置。

## 于是算法转向：证书不是松弛，是"便宜的精确判定"

既然核是全局的，就不要再用松弛去近似它。**精确判定本身就是最强的证书**：它精确，所以任何可靠证书能证的它都能证（定理：TENT/THRESH/AVAIL 报警 ⇒ `DEC=NO`）。问题只剩一个：怎么让精确判定便宜。

答案是三件套：

1. **逐节点能量界** `E(R,A)`（主角，67×）；
2. **截止期界** `est_i+p_i+q_i≤H`（经典，但和能量界一起用才够紧）；
3. **重叠子问题的 transposition memo**：键 `(R,A,est_R)`，存的是**阈值** `h` 而不是布尔值——"在 `h` 处证否"自动覆盖所有 `h'≤h`。

`DEC` 是精确的（active 调度完备性：任一可行调度按开始时间排序后逐个左移，仍在枚举范围内）。于是

```text
EC-SOLVE: U ← min(CP,LPT,MWKR)
          while L < U:
              r ← DEC(σ0, U-1)
              if r=NO:      return U        # U 已最优
              if r=YES(π):  U ← makespan(π) # 严格下降
```

**每一次 NO 都把 U 变成 OPT**；每一次 YES 都严格改进 U。整数性保证终止。

## 形式化骨架（细节在产物区）

状态 `σ=(R,A,est)`；`q_i` 是剩余尾长。对 horizon `H` 定义松弛与两个集合：

```text
sl_i(σ,H) = (H - q_i - p_i) - est_i           # 时间松弛
B(σ,H)    = { i∈R : sl_i = 0 }                # 被钉死的任务
E(R,A)    = ⌈( Σ_{i∈R} p_i + Σ_k A_k ) / m⌉   # 逐节点能量界
```

**判定问题** `DEC(σ,H)`：是否存在从 `σ` 出发、`Cmax≤H` 的完成？它返回 `NO / YES(π) / ?`（预算耗尽）。三个剪枝都是必要条件：

```text
(D1) ∀i∈R: est_i + p_i + q_i ≤ H
(D2) E(R,A) ≤ H
(D3) bad[(R,A,est_R)] < H        # 阈值 memo
```

四条要用的命题：

```text
引理 1 (能量)   E(R,A) ≤ Cmax，对任意完成成立。
引理 2 (memo)   bad[key]=h ⇒ 对所有 h'≤h，DEC(key,h')=NO。
引理 3 (完备)   任一 H-可行调度可左移成一条被 DEC 枚举的 active 调度。
定理 1 (空集)   L0(σ) ≤ H-1 ⇒ B(σ,H)=∅；取 H=OPT-1 得"gap≥2 ⇒ 无被钉死任务"。
定理 2 (求解)   DEC(σ,U-1)=NO ⇒ U=OPT(σ)。
定理 6 (上确界) L0>H ∨ L_A>H ∨ TENT 报警 ∨ AVAIL 报警 ⇒ DEC(σ,H)=NO。
```

所以证书的偏序是

```text
L0  ≤  THRESH  ≤  TENT  ≤  DEC（精确）
```

前三个是 `DEC` 的必要条件子集；`DEC` 是格的上确界，代价是指数。算法要做的不是再找一个中间层，而是把上确界做得足够便宜。

## 结果：根上 30/30，扩展 139→0，时间 0.147→0.015 秒

在 v0.6 的 pool30 上（同一 harness）：

| 变体 | 扩展 | 时间 | 根 `L=OPT` |
|---|---:|---:|---:|
| v0.6 TENT（base） | 139 | 0.147 s | 29/30 |
| +EC 根（只在 `L<U` 时跑） | **0** | **0.015 s** | **30/30** |
| +EC 小残差（`|R|≤8`） | 38 | 0.032 s | 29/30 |
| +EC 临界带（`U-f≤2`） | 50 | 0.046 s | 29/30 |

11 个状态级 gap 全部闭合（2–469 个判定节点，0.0–1.3 ms），包括两个 `L_TENT=33`、`OPT=35`（差 2 个单位）的状态；k=29 的根用 1,580 个节点、4.7 ms 闭合。

60 个新鲜实例上 60/60 正确；base 144 扩展 / 0.201 s，EC 0 扩展 / 0.0075 s（18 胜 42 平 0 负）。所以这不是 pool 的选择偏差。

## 诚实的部分：并查集与重叠子问题都没有兑现成"节点数"

- **并查集**：零松弛块（空集定理，最难一档恒空）、静态自同构类（30 个根里只有 6 个任务落在非平凡类，消融 0 收益）、优先分量（只是成本分摊）。三次出场，两次空转。它的价值是空集定理本身。
- **重叠子问题**：同一 `H` 内的 transposition 命中 24.7%（1354/5483），有效；**跨 `H` 的阈值复用只有 1 次**。原因是 `EC-SOLVE` 每轮 `U` 下降后根是新的（上一轮是 YES，不存 `bad`），被剪掉的深层状态在更小的 `H` 下根本不会再被访问。阈值 memo 的理论是对的，工程收益接近零。
- **`L_A`**：`max_i(min_k max(A_k,est_i)+p_i+q_i)`，`L0` 的逐点加强，52 个状态上 16 个严格更好、总增益 80、最大 +12、0 违反可采纳性；但 pool30 的根 `A=0`，根上 0 收益。它是免费的正确性补丁，不是卖点。
- **EC 逐节点用反而更慢**：D8 38 扩展 / 0.032 s，R 0 扩展 / 0.015 s。节点数不是免费指标，证书要调度。

## 与 v0.6 的关系：不是推翻，是"上确界"

v0.6 的证书层次是 `L0 ≤ THRESH ≤ TENT ≤ DEC(精确)`。`DEC` 精确，所以它是这个格的上确界；但它的代价是指数的。正确的结构是分层：大 `n` 用 TENT 做 anytime，小 `n` 或临界点用 `DEC` 一次性闭合；两层共享同一个 `U` 和 `L`。v0.6 的 focal、Q-DOM、guide 在 `DEC` 可负担时是纯开销，但在 `DEC` 不可负担时仍是唯一的搜索骨架。所以它们保留，只是不再是主角。

## 本轮的一句话最大风险

**所有收益都建立在"n≤13、`U0` 已接近 OPT、优先约束足够密"的测试族上；一旦实例变成分区型（优先稀疏、`p_i≈OPT/2`），逐节点能量界退化为平凡界，`EC-SOLVE` 就退回指数搜索，而 v0.6 的分层证书反而是唯一可负担的 anytime 手段。**

## 0. 版本关系与本轮增量

v0.6（X-DUB/TQ*）的资产全部保留：

- `(R,A,est)` 势商状态、Q-DOM、focal + guide、路径最大下界 `F`、证明 DAG 的局部检查规则；
- TENT 强制段打包阈值证书、THRESH、AVAIL 点测试、`L0`；
- 证明模拟引理与 `(1+ε)` 近似支配的设计。

v0.7 只加三样东西，并且**不删** v0.6 的任何开关：

1. **EC-CERT（全局精确证书）**：在状态 `σ`、上界 `U` 处，用带**逐节点能量界**、截止期剪枝、紧急度排序和 transposition memo 的 DFS，精确回答"是否存在 `Cmax ≤ U-1` 的完成"。答案是 NO ⇒ `OPT(σ)=U`；答案是 YES ⇒ 得到一条更好的可行调度，`U` 严格下降。
2. **L_A（A-HEAD 界）**：`L_A(σ)=max_i [ min_k max(A_k,est_i) + p_i + q_i ]`。它是 `L0` 的逐点加强（`L_A ≥ L0`），`O(n)` 计算，可采纳，补上 v0.6 的 `L0` 完全忽略机器可用时间这一缺口。
3. **诊断层（本轮的主要科学产出）**：证明"不可行核是全局的"与"零松弛集在最难的一档上必然为空"两个结构性结论，从而解释为什么 v0.6 的证书路线走到了尽头，以及为什么"精确判定"是唯一还能闭合最后一格的证书。

关系：

```text
关闭 EC + L_A            → v0.6 的 X-DUB/TQ*（TENT + Q-DOM + focal）
只开 L_A                → 仍是 v0.6 搜索，只是每点下界略强
只开 EC（根/临界带）      → 精确判定作为证书；其余完全不变
全部打开                → v0.7 的 X-DUB/EC*
```

组合下界：

```text
L_X7(σ) = max( L0, L_D, L_AV, L_TH, L_TENT, L_A, L_EC )
L_EC(σ) = U       若 DEC(σ,U-1) = NO
        = L0(σ)   否则（未证明）
F(σ)    = 路径上所有 L_X7 的最大值
f(σ)    = max( C(σ), F(σ) )
```

因为 `L_A ≥ L0`、`L_EC ≥ L0`，所以 `L_X7 ≥ L_X6`；关闭 EC/L_A 后逐字回到 v0.6。

## 1. 符号（本轮新增）

| 符号 | 含义 |
|---|---|
| `R = V\S` | 未调度任务（位掩码） |
| `A=(A_1≤…≤A_m)` | 排序后的机器可用时间 |
| `est_i` | 从 `σ` 出发任务 `i` 的最早开始（heads） |
| `q_i` | `i` 之后剩余最长路径（tails） |
| `C(σ)=max_k A_k` | 已提交 makespan |
| `L0(σ)` | `max(C, max_i(est_i+p_i+q_i), ⌈Σ_{R}p/m⌉)` |

| `sl_i(σ,H)` | `(H-q_i-p_i)-est_i`，任务 `i` 在 horizon `H` 下的时间松弛 |

| `E(R,A)` | `⌈(Σ_{i∈R}p_i + Σ_k A_k)/m⌉`，**能量界** |

| `N_ec` | DEC 的节点预算 |
| `bad[(R,A,est_R)]=h` | 阈值 memo：该状态对所有 `h'≤h` 都不可行 |
| `T_EC` | 允许运行 EC 的触发条件（根 gap / 临界带 / 小残差） |

## 2. 诊断：最后一格到底在哪里

### 2.1 观察一：把 gap 当作 NP-hard 判定问题，它的最小核几乎是全体

固定状态 `σ` 与 horizon `H=OPT(σ)-1`。定义**核证书族**：

```text
KS(K) : 只对 K⊆R 精确判定（release=est_i，deadline=H-q_i，
        保留 K 内优先约束与 m 台机器），其余任务全部丢掉。
```

丢掉任务只会放松约束，所以 `KS(K)=NO ⇒ H` 不可行（可靠性）；`K=R` 时 `KS` 就是原判定问题（完备性）。它是一个**单调族**：`K⊆K'` 且 `KS(K)=NO ⇒ KS(K')=NO`（大核把被丢掉的约束加回来，只会更难）。实现上还把零松弛集 `B(σ,H)` 一并钉死（§4.1）；在 `gap≥2` 的案例中 `B=∅`（定理 1），所以不影响下表的 MUS 数值。

如果"不可行性"是局部的，就应存在很小的 `K` 使 `KS(K)=NO`。实验做了**最小不可行核（MUS）**：从 `K=R` 出发，逐个尝试删任务，只要仍 `NO` 就删。

| 案例 | `|R|` | MUS 大小 | 比例 |
|---|---:|---:|---:|
| 11 个状态级 gap | 5–8 | 3–8 | 0.50–1.00（均值 0.90） |
| `pool30[29]` 根 | 10 | 8 | 0.80 |

11 个状态里 6 个的 MUS 就是整个 `R`。结论：**在 `H=OPT-1` 处，不可行性不是少数几个任务造成的；它是全局的。** 子集核化（把"小的不可行核"找出来精确求解）在这批实例上没有出路。

### 2.2 观察二：空集定理——零松弛集在最难的一档必然为空

**定理 1（零松弛空集）**：若 `L0(σ) ≤ H-1`，则 `B(σ,H)=∅`。

**证明**：若 `i∈B`，则 `est_i+p_i+q_i = H`，于是 `L0(σ) ≥ est_i+p_i+q_i = H`，与 `L0 ≤ H-1` 矛盾。证毕。

**推论 1**：若 `OPT(σ)-L0(σ) ≥ 2`，则 `H=OPT-1` 处没有任务被钉死，`B(σ,OPT-1)=∅`。

这条推论解释了整条证书路线的困境：

- v0.5 的 THRESH 收集"完全被迫"的任务（窗口内的 `e_i=p_i`），在 `gap≥2` 时这个集合为空；
- v0.6 的 fixed-block / 零松弛收缩，在 `gap≥2` 时为空；
- 本轮设计的 UF-CONTRACT（零松弛链并查集收缩），同样为空。

它同时解释了 v0.6 的一个实验事实：**真正有用的是"部分 item"**。部分强制量 `e_i` 在 `sl_i>0` 时仍然为正，所以 TENT 能在空集定理之外继续工作；但部分 item 只能给出松弛，给不出"最后一格"。

**实测**：12 个 gap 案例（11 状态 + 根 29）在 `H=OPT-1` 处 `|B|=0`；30 个根在 `H=U-1`（较松）处共有 16 个零松弛任务，在 `H=OPT-1` 处共 9 个（且都出现在 `L0=OPT-1` 的实例上，即 gap 已经只有 1）。

### 2.3 观察三：v0.6 的能量界只用在了根上

`L0` 里的 `⌈Σ_R p/m⌉` 是能量界，但它把机器已占用的时间 `ΣA` 扔掉了。正确的逐节点能量界是：

```text
E(R,A) = ⌈( Σ_{i∈R} p_i + Σ_k A_k ) / m ⌉.
```

**引理 1（能量界）**：任意从 `σ=(R,A,est)` 出发、makespan 为 `C` 的完成满足 `E(R,A) ≤ C`。

**证明**：机器 `k` 在 `[A_k,C)` 内最多贡献 `C-A_k` 的工时，故 `Σ_{i∈R}p_i ≤ Σ_k(C-A_k) = mC - Σ_k A_k`，即 `C ≥ (Σp+ΣA)/m`。取整得证。证毕。

`E(R,A)` 是 `L0` 中 `⌈Σp/m⌉` 的严格加强（当 `ΣA>0`），且是 `L_A` 之外另一条被 v0.6 忽略的、每节点都成立的信息。

**本轮的核心发现**：把 `E(R,A)` 放进**判定 DFS 的每一个节点**，而不是只放在搜索节点顶端，会让"精确判定"从不可负担变成可负担。30 个 pool 根（无条件在每个根上运行判定）的总节点数：

```text
无能量剪枝       367,704
有能量剪枝         5,483     （67×）
上一轮独立精确 DFS  2,220,019  （405×）
```

这不是一个新的松弛，而是把一个已知界放到正确的位置；它的效果比 v0.6 一整轮的证书工程都大。

### 2.4 三个灵感词的分工

- **np-hardness**：`DEC` 本身就是 NP-hard 的判定问题，本轮不再试图用多项式松弛去完整替代它，而是**精确地解它、并把它的代价压到可负担**；同时用 MUS 实验证明"局部化"这条捷径不存在。
- **并查集**：用来定义并证明三种收缩（零松弛块、静态自同构类、优先分量）。本轮对它的诚实结论是**空集定理**：零松弛块在最难的一档必然为空；自同构类存在但收益为 0。并查集在本轮的价值是"证明自己用不上"，而不是"剪掉了多少节点"。
- **重叠子问题**：判定 DFS 的 transposition memo（同一 `(R,A,est_R)` 只解一次）命中 24.7%；H-阈值 memo 让"在 `h` 处证否"自动覆盖所有 `h'≤h`。跨调用的阈值复用在实验里几乎没兑现（见 §8.6），这是一个诚实的负结果。

## 3. EC-CERT：全局精确判定证书

### 3.1 定义

对状态 `σ=(R,A,est)` 与 horizon `H`：

```text
DEC(σ,H) ∈ { NO, YES(π), ? }
```

- `NO`：不存在从 `σ` 出发、`Cmax≤H` 的完成；
- `YES(π)`：给出一条完成 `π`，其 makespan `≤H`；
- `?`：节点预算耗尽，未决。

**注意 `DEC` 不是松弛**：它是原判定问题的精确算法。因此 `DEC=NO` 是**最强可能的证书**，任何可靠证书能证的它都能证；代价是它可能指数时间。

### 3.2 逐节点剪枝

在 DFS 的每个节点 `(R',A',est')`：

```text
(D1) 截止期： ∀i∈R':  est'_i + p_i + q_i ≤ H
(D2) 能量：   E(R',A') = ⌈(Σ_{i∈R'}p_i + Σ_k A'_k)/m⌉ ≤ H
(D3) 阈值 memo： bad[(R',A',est'_R')] < H
```

三条都是**必要条件**，只删不可能的分支，不删可行解。

`(D2)` 是本轮的关键。它在根节点退化为 v0.6 的 `⌈Σp/m⌉`，在深层节点则把"机器已经被占掉多少"算进去。对 `m=2`、`A=(a_1,a_2)` 的深层节点，它经常比 `L0` 高 1–3 个单位，恰好是闭合最后一格所需的量。

### 3.3 分支与序

- **分支对象**：`ready = {i∈R' : pred(i)∩R'=∅}` × 机器 `k∈[m]`，开始时间取 `t=max(A'_k,est'_i)`。
- **为什么只取最早开始**：任一可行调度按开始时间排序后，把每个任务在其机器上左移到最早可行时刻，仍是可行调度（优先约束由 ready 保证，机器由 `A'_k` 保证，截止期只会更松）。所以"每个 (任务,机器) 只在最早时刻开始"的 DFS 枚举了所有 active 调度，是完备的。
- **序**：按 `(H-q_i-p_i)-est_i` 升序（最紧急的先试），确定性 tie-break 用任务下标。
- **对称类**：静态自同构类（`p_i` 相同、`pred(i)` 与 `succ(i)` 作为集合相同）内只试最小代表。由"交换两个自同构任务得到同构调度"可得完备性（§4.2）。

### 3.4 阈值 memo 与重叠子问题

`DEC` 的未来只依赖 `(R,A,est_R)`（v0.6 引理 1 的势商），所以 memo 的键就是这个三元组。

**引理 2（阈值 memo 可靠性）**：若 `bad[key]=h`，则对任意 `h'≤h`，`DEC(R,A,est,h')=NO`。

**证明**：`H` 变小只会让截止期 `H-q_i` 变小、`(D1)(D2)` 更难满足，可行集单调缩小；在 `h` 处不可行 ⇒ 在 `h'≤h` 处不可行。证毕。

这条引理让 memo 从布尔值升级为**阈值**：一次 `NO` 覆盖一整个 `H` 区间。它也是 v0.6 的 `H*(a,b)` 思想在状态层的推广——v0.6 对固定窗口把"不可行"扩成 `H` 区间，本轮对固定状态做同一件事。

但实验（§8.6）显示：在一次 `EC-SOLVE` 里 `U` 只下降几次，每次 `DEC` 的根都是新的（上一次是 YES，没有存 `bad`），所以**跨调用的阈值复用只有个位数**；真正兑现的是同一 `H` 内的 transposition（24.7% 命中）。

### 3.5 EC-SOLVE：把判定当作求解器

```text
EC-SOLVE(σ0)
1  U ← min(CP, LPT, MWKR)              # 三条表调度的可行上界
2  L ← max(L0, L_A, L_TENT)            # 便宜下界
3  memo ← ∅
4  while L < U:
5      r ← DEC(σ0, U-1, memo, N_ec)
6      if r = NO:  return (U, L=U)     # U 已最优
7      if r = YES(π): U ← makespan(π);  continue
8      break                            # 预算耗尽 → 回退 v0.6 搜索
9  return 回退结果
```

**定理 2（EC-SOLVE 正确）**：若第 6 行返回，则 `U=OPT(σ0)`。

**证明**：`U` 始终是可行调度的 makespan，故 `OPT≤U`。`DEC(U-1)=NO` 说明不存在 `Cmax≤U-1` 的完成，故 `OPT≥U`。两者夹逼。证毕。

**终止性**：每次走到第 7 行，`U` 严格下降（整数），且 `U≥L0`，所以最多 `U0-L0+1` 轮。

**与 v0.6 的关系**：`EC-SOLVE` 不取代 v0.6；第 8 行预算耗尽就回退到 v0.6 的 focal 搜索，用当前 `L` 继续。`T_EC` 控制何时运行 EC：根（`L_X6<U`）、临界带（`U-f(v)≤Δ`）、小残差（`|R|≤κ`）。

## 4. 并查集：三种收缩与一个空集定理

### 4.1 零松弛块收缩（UF-CONTRACT）

对 horizon `H`，`B(σ,H)={i:sl_i=0}` 中的任务在任意 `Cmax≤H` 的完成里都**必须**在 `est_i` 开始、`est_i+p_i` 完成（因为 `s_i≥est_i` 且 `s_i≤H-q_i-p_i=est_i`）。

于是可以：

1. 把 `B` 中的任务从分支中拿掉，按固定区间占位；
2. 若 `i→j` 且 `i,j∈B` 且 `est_j=est_i+p_i`，用并查集把它们并成一个**固定块**；块内任务必须首尾相接；
3. 固定块占用的机器时间作为点态容量扣减（`occ(t)+bg(t)≤m`）。

**定理 3（零松弛块可靠性）**：上述收缩不改变 `DEC` 的答案。

**证明**：`sl_i=0 ⇒ s_i=est_i` 是任意 `H`-可行调度的必要条件；固定块内 `est_j=est_i+p_i` 使相邻关系也被钉死。收缩只是把"必然"提前执行，不删可行解；容量扣减是必要条件的显式化。证毕。

**但**：由定理 1，当 `OPT-L0≥2` 时 `B(σ,OPT-1)=∅`，所以这个收缩在最难的一档上**必然空转**。实测 12 个 gap 案例 `|B|=0`；只有在 `H=U-1`（`U` 还松）时才有 16 个任务可收缩。

### 4.2 静态自同构类（UF-SYM）

把 `R` 中满足

```text
p_i=p_j,  pred(i)=pred(j),  succ(i)=succ(j)   （作为全集上的集合）
```

的任务并成一类。交换 `i,j` 是实例的一个自同构，把任一调度中的 `i,j` 标签互换得到同构调度，故可在每类中只试最小下标代表。

**定理 4（对称类可靠性）**：只对每类最小代表分支不丢失最优解。

**证明**：取任一 `H`-可行调度，若某类中下标较大的任务先于最小代表被调度，交换两者标签；由于 `pred/succ/p` 完全相同，交换后仍是可行调度，且 makespan 不变。归纳得到一条"类内按下标顺序"的调度。证毕。

**实测**：30 个 pool 根里只有 6 个任务落在非平凡类中；消融显示开关对称类对判定节点数**没有任何影响**（5483 vs 5483）。这是一个干净的负结果。

### 4.3 优先分量（UF-COMP）

把 `R` 的诱导 DAG 按弱连通分量分解。每个分量单独判定是原问题的一个松弛（丢掉其它分量的容量耦合），因此任一分量 `NO ⇒` 整体 `NO`；但反之不成立（容量是全局共享的）。它的价值只是**成本分摊**：先判下界最大的分量，尽早失败。本轮没有把它作为主剪枝，实测也没有单独报告收益。

### 4.4 一句话

并查集在本轮的三次出场，两次被空集定理/稀有性判了"无用"，一次只是成本分摊。**这是结论，不是遗憾**：它说明在 `H=OPT-1` 处没有"被迫结构"可以利用，任何以 forced set 为核心的证书（包括 v0.5 的 THRESH）在这一档上都必然空转。

## 5. 主循环 X-DUB/EC*

```text
算法 X-DUB/EC*(G,p,m,N_ec,T_EC)
────────────────────────────────────────────
1  L0, q ← PRECOMPUTE(G,p,m)
2  U, π ← MIN-GREEDY                       # CP/LPT/MWKR 取 min
3  L ← max(L0, L_A, L_TENT(root))          # 便宜证书
4  if T_EC(root) and L < U:
5      memo ← ∅
6      while L < U:
7          r ← DEC(root, U-1, memo, N_ec)
8          if r=NO:  L ← U; break
9          if r=YES(π): U ← makespan(π)
10         else: break                    # 预算耗尽
11 if L ≥ U: return (U, L, PROOF=EC)
12 回退 v0.6：
13   root.F ← L; Open ← {root}; Dom ← …
14   while Open ≠ ∅ and steps < N_max:
15       … v0.6 的 focal + Q-DOM + AVAIL + TENT-POINT …
16       if T_EC(v) and L < U: 用 DEC(v,U-1) 剪枝/改 U
17   return (U, max(L, min f), PROOF)
```

确定性：`MIN-GREEDY` 的规则次序固定；`DEC` 的 ready 排序与 tie-break 固定；memo 只影响速度不影响答案；没有随机数、没有学习、没有哈希顺序依赖。

`T_EC` 的三个触发条件（本轮实验都测了）：

| 策略 | 触发条件 | 30 实例扩展数 | 总时间 | 根 `L=OPT` |
|---|---|---:|---:|---:|
| base | 无 EC | 139 | 0.147 s | 29/30 |
| D8 | `|R|≤8` 的子节点 | 38 | 0.032 s | 29/30 |
| D9 | `|R|≤9` 的子节点 | 27 | 0.030 s | 29/30 |
| F | `U-f(v)≤2` | 50 | 0.046 s | 29/30 |
| **R** | **根，且 `L<U`** | **0** | **0.015 s** | **30/30** |

结论：**EC 的最佳用法是"根上一次性判定"，不是"每个节点都判"**。逐节点判定把搜索节点换成了判定节点，总工作量反而上升；根上判定则直接把整个搜索替代掉。

### 引理 1（能量界）
已证于 §2.3。

### 引理 2（阈值 memo）
已证于 §3.4。

### 引理 3（active 调度完备）
任一 `H`-可行调度可左移成一条被 `DEC` 枚举的 active 调度。已证于 §3.3。

### 定理 1（零松弛空集）
已证于 §2.2。

### 定理 2（EC-SOLVE 正确）
已证于 §3.5。

### 定理 3（零松弛块可靠）
已证于 §4.1。

### 定理 4（对称类可靠）
已证于 §4.2。

### 定理 5（L_A 可采纳）
`L_A(σ) ≤ OPT(σ)`。

**证明**：设最优完成中 `i` 在机器 `k(i)` 上，开始 `s_i ≥ max(A_{k(i)},est_i)`，则 `OPT ≥ s_i+p_i+q_i ≥ max(A_{k(i)},est_i)+p_i+q_i ≥ min_k max(A_k,est_i)+p_i+q_i`。对 `i` 取 max。证毕。

### 定理 6（EC 包含 v0.6 的全部证书）
若 `L0(σ)>H` 或 `L_A(σ)>H` 或 `TENT` 在 `H` 处报警或 `AVAIL` 在 `H` 处报警，则 `DEC(σ,H)=NO`。

**证明**：这些证书都是 `H`-可行性的必要条件，而 `DEC` 精确判定 `H`-可行性；必要条件被违反 ⇒ 不可行。证毕。

（这条定理是"包含"而非"更强"：`DEC` 精确，所以它在每个 `H` 上的判定都不弱于任何可靠证书；代价是时间。）

### 定理 7（任意时刻区间）
在 X-DUB/EC* 的任意时刻 `L ≤ OPT ≤ U`。`U` 来自可行调度；`L` 是 `L0/L_A/L_TENT/L_EC` 与前沿 `min f` 的最大值，每一项都可采纳（定理 5、v0.6 的 TENT 可采纳、`f` 的路径继承）。证毕。

### 定理 8（终止即最优）
若算法在 `L≥U` 处返回，则 `U=OPT`。若 `L≥U` 由 `DEC` 的 `NO` 给出，由定理 2；若由前沿耗尽给出，由 v0.6 的定理 8。证毕。

## 7. 复杂度

### 7.1 单次 DEC

设 `N_dec` 为判定树节点数，`S_dec` 为不同 `(R,A,est_R)` 状态数。

```text
时间: O( N_dec · ( |R| + m·|R|·H ) )      # 每节点：截止期 O(|R|)、能量 O(|R|+m)、
                                          # 每个分支 O(|R|) 更新 est
空间: O( S_dec · (m+|R|) )                # memo
```

最坏情况 `N_dec = O((m·n)^n)`（active 调度数）；能量界与截止期界把它在实际实例上压到 `10^2–10^3`。

### 7.2 EC-SOLVE

```text
时间: O( (U0-L0+1) · N_dec · (n + m·n·H) )
空间: O( S_dec · (m+n) )
```

`U0-L0` 在 pool30 上是 1–7；每轮 `U` 严格下降。

### 7.3 与 v0.6 的对比

| 对象 | 最坏复杂度 | 实测（30 个 n=10 根） |
|---|---|---:|
| v0.6 TENT 根证书 | `O(n² log U · T_BP)` | ~0.02 s |
| 上一轮精确 DFS（无 memo/能量） | 指数 | 2,220,019 节点 |
| EC 根判定（有能量） | 指数 | 5,483 节点 |
| v0.6 focal 搜索 | 指数 | 139 扩展 / 0.147 s |

EC 没有改变最坏复杂度；它改变的是常数与"什么被算进证书"。

| 变体（30 个 pool 根，无条件运行判定） | 总节点 | 相对 |

| EC（能量 + 对称 + memo） | 5,483 | 1× |
| 去掉能量界 | 367,704 | **67×** |
| 去掉对称类 | 5,483 | 1.00× |
| 上一轮独立精确 DFS | 2,220,019 | 405× |

- 能量界是唯一真正改变规模的因子；
- 对称类在 30 个根上 0 收益（尽管有 6 个任务落在非平凡类中）；
- `L_A` 在 pool30 根上 0 收益（根 `A=0`），但在 52 个随机状态上 16 个严格更好，总增益 80，最大单点 +12，0 个违反可采纳性（`L_A ≤ OPT(state)`）。

### 8.6 重叠子问题：memo 的真实命中率

- 30 个 pool 根判定：内部 transposition 命中 **1,354 / 5,483 = 24.7%**；
- `pool30[29]` 根：231 / 1,580 = 14.6%；
- 跨 `DEC` 调用的 H-阈值复用：**1 次**（root29）。

诚实解读：**同一 `H` 内的 transposition 是有效的（约 1/4 的节点被 memo 省掉）；跨 `H` 的阈值复用没有兑现**。原因是 `EC-SOLVE` 每轮 `U` 下降后，`DEC` 的根是新的（上一轮是 YES，不存 `bad`），而被剪掉的深层状态大多在更小的 `H` 下根本不会再被访问到。阈值 memo 的**理论**是对的（引理 2），但**工程收益接近零**；如果未来把搜索也改成同一张 memo 的 DFS，才可能兑现。

### 8.7 规模探针（n=11–13）

| n | 判定节点（4 个实例） | 时间 |
|---:|---|---:|
| 11 | 2843 / 46 / 1 / 587 | ≤9 ms |
| 12 | 1 / 20 / 365 / 1 | ≤1 ms |
| 13 | 357 / 495 / 1 / 64 | ≤2 ms |

这些随机实例的 `U0` 往往已经等于 `OPT`，所以判定很浅；它们不能代表"分区型"难例。**没有观察到指数墙不等于没有指数墙**（见 §10）。

### 8.8 可靠性验证

- **31 个 `NO` 声明**：全部用独立验证器确认 `H` 不可行，0 个假阳性；
- **13 个 `YES(π)` 见证**：全部从零重放通过（优先、机器、截止期），0 个坏见证；
- **全部 30 + 60 个实例**：`U=OPT`，与独立求解一致；
- 验证过程中抓到一个真实 bug：`DEC` 早先把 `A` 排序后返回调度，导致见证里的机器编号在排序后错位（两个任务被记录在同一台机器的同一时刻）。独立重放器立刻发现；修复为"保留机器身份、不排序"后 0 坏见证。这条写在 §11 的风险里。

## 9. 与 v0.6 的关系：不是推翻，是"上确界"

v0.6 的证书层次是：

```text
L0  ≤  THRESH  ≤  TENT  ≤  DEC（精确）
```

- `DEC` 精确，所以它在每个 `H` 上都不弱于 TENT/THRESH/AVAIL（定理 6）；
- 但 `DEC` 的代价是指数的，TENT 是 `O(n² log U · T_BP)`；
- 因此正确的结构是**分层**：大 `n` 用 TENT 做 anytime，小 `n` 或临界点用 `DEC` 一次性闭合；两层共享同一个 `U` 和同一个 `L`。

v0.6 的 Q-DOM、focal、guide 在 `DEC` 可负担时是纯开销；但在 `DEC` 不可负担时（大 `n`、预算耗尽）仍是唯一的搜索骨架。所以它们保留，只是不再是主角。

## 10. 负结果与边界

1. **核化失败**：MUS 大小 ≈ `|R|`（均值 0.90），11 个状态里 7 个的 MUS 就是全体。子集核化没有出路。
2. **零松弛空集**：`gap≥2` 时 `B(σ,OPT-1)=∅`（定理 1）。所有 forced-set 证书在这一档必然空转。
3. **并查集三次出场**：零松弛块空转、自同构类 0 收益、优先分量只是成本分摊。
4. **跨 H 的阈值复用 ≈ 0**（1 次）。重叠子问题的收益全部来自同一 H 内的 transposition（24.7%）。
5. **EC 逐节点使用反而更慢**：D8 38 扩展 / 0.032 s，R 0 扩展 / 0.015 s。节点数不是免费指标。
6. **`L_A` 在根上 0 收益**（`A=0`），只在有机器负载的状态上有用（16/52）。
7. **规模探针不代表难例**：n=11–13 的随机实例 `U0` 常等于 `OPT`，判定很浅；真正的分区型难例没有构造。

## 11. 已知风险

1. **基准的"难"是架构相关的**：pool30 是按"A* 扩展数 ≥40"筛出来的，但它们对"DFS + 能量界"只有 ~170 个节点。本轮的 10× 加速很可能主要是"换了一个更适合这批实例的算法"，而不是"实例本身变简单了"。需要在一组**对 DFS 也难**的实例（分区型、低优先密度、`p_i≈OPT/2`）上重测。
2. **能量界是经典工具**：`E(R,A)` 本质是 energetic reasoning / Carlier 界的一个特例。本轮的贡献是"逐节点化 + 与精确判定结合"，不是新界。不要把它写成新下界。
3. **最坏情况仍是指数**：`DEC` 枚举 active 调度；一旦能量界变平凡（例如 `p_i` 都很小、机器负载很轻），节点数会爆炸。`N_ec` 预算与 v0.6 回退是必需的，不是可选的。
4. **没有 m>2**：所有实验 `m=2`。`m>2` 时 `DEC` 的分支因子是 `m` 倍，能量界更松，结论可能反转。
5. **`L_A` 的收益很小**：16/52 状态、总增益 80、根上 0。它是"免费的正确性补丁"，不是卖点。
6. **并查集没有正面结果**：三个用法两个空转、一个 0 收益。如果下一轮需要"并查集"的正面故事，必须换场景（例如 `m>2` 的机器对称类，或 release date 的区间合并）。
7. **memo 跨 H 复用未兑现**：阈值 memo 的理论正确，但 `EC-SOLVE` 的调用序列让它的命中率接近 0。要兑现，必须让搜索与判定共用同一张 memo（需要把搜索改成 DFS）。
8. **见证的机器身份**：`DEC` 若对 `A` 排序再返回调度，机器编号会错位（本轮已踩中并修复）。任何"返回调度"的精确搜索都必须保留机器身份，或者返回后再做一次重映射。
9. **验证样本小**：31 个 `NO` + 13 个 `YES` 的独立验证是抽样，不是全量证明检查；没有 proof-DAG checker。
10. **时间测量**：纯 Python 单次，pool30 的总时间在 0.015–0.15 s 量级，容易受实现细节影响；不应把 10× 当作稳定的算法优势。
11. **`U0` 依赖**：`EC-SOLVE` 的轮数与 `U0-L0` 成正比；如果 `MIN-GREEDY` 给出很松的 `U0`，判定会多跑几轮（每轮都是一次完整判定）。
12. **没有 PSPLIB / n≥14**：不能外推到 benchmark 规模。

---

## 12. 一句话最大风险

**本轮的全部收益都建立在"n≤13、`U0` 已接近 `OPT`、优先约束足够密"的测试族上；一旦实例变成分区型（优先稀疏、`p_i≈OPT/2`），逐节点能量界退化为平凡界，`EC-SOLVE` 就退回指数搜索，而 v0.6 的分层证书反而是唯一可负担的 anytime 手段。**
