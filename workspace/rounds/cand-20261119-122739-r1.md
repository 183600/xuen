# 第 1 轮（本轮灵感：「能耗优化」×「可靠性」；技术基线延续 v15）

> **基线**：第 13 轮 MetricVoiceGauge-NCD-HUTDH v15（技能扩散版：SCD/DSD/DCA/EDC，定义 607–626；引理 125–130；实验 E661–E670）。
> 本轮纪律：**把能耗从软成本升格为可证资源，把可靠性从静态假设改写为累积损伤证书**。不推倒 v15：v15 的 SCD/DSD/DCA/EDC、v13 的 AIO/CPD/DGC/DDL/RTCR、v12 的 USG/TGC/BAA/GAGP/UC、v11 的 HAS/HCC/HATD/HDT、v10 的 NGE/DSL/CC/CWM/CAE/NCP、v9 的 AC/MW/ID、v8 的 DA/SPR/Cal 与九不变式全部保留。五个新组件——ERC（能耗储备证书）、TBSE（热—电状态估计）、CDC/RMI（累积损伤证书与余量膨胀）、ERDL（能耗—可靠性退化阶梯）、JERR（关节级联合路由）——一律以**收缩算子**接入：只收缩授权集、只增加安全余量；失效即严格退回 v15（引理 140），再沿 v15→v14→…→v6 退化链退回。本轮只做三件事：给"电够不够安全停下"一个逐帧证书、给"关节还能用多久"一个路径相关的损伤账本、把二者与时间/技能合成一个多维资源阶梯。

## 0. 直觉与动机

**灵感 1（能耗优化 → 能量是第二个截止期）**
直觉：v15 已经把毫秒当成货币，却默认焦耳免费。真实机器人里，能量会耗尽、会发热、会让母线电压塌陷；更麻烦的是，剩余电量下降不只减少"能做的动作"，还同时缩小"能安全停下"的可行域。于是能量应当被当作第二个截止期：每一帧都要证明"执行完这个候选动作后，仍留有一份认证过的能量完成紧急停止与重校准"。核心创新：**能耗储备证书（Energy-Reserve Certificate, ERC）+ 热—电状态估计（Thermal–Battery State Estimator, TBSE）**。ERC 在动作空间上定义能量可行集 `Acc_E(x,t)`，并把一份储备 `E_res` 永久锁定、任何性能优化不可动用。反直觉点：能耗优化不应以最小化瞬时功率为目标，而应以最大化"单位剩余能量换来的可安全完成任务量"为目标——一次过深放电会让后续所有帧的执行域整体收缩，短期省电可能换来长期能力塌陷。

**灵感 2（可靠性 → 累积损伤是路径相关的证书）**
直觉：v15 的 HCC 把电机/关节参数当准静态；长时间运行后谐波减速器磨损、齿隙增大、绕组温升、电池内阻上升，会让同一动作的实际效果缓慢漂移，而证书仍按"新机器"给余量。可靠性不是"不坏的概率"这种静态标签，而是"已经累积了多少不可逆损伤、它如何吃掉安全余量"。核心创新：**累积损伤证书（Cumulative Damage Certificate, CDC）+ 可靠性余量膨胀（Reliability Margin Inflation, RMI）**。CDC 按关节记账（Miner 线性损伤 + 雨流计数 + 热循环项），给出路径相关的剩余寿命 `R_j(t)=1−D_j(t)`；RMI 用磨损量反向膨胀识别误差与证书余量：关节越旧，同一动作需要越大的安全边界。反直觉点：能耗最优常把负载集中在最顺手的关节上，短期省电却在制造单点磨损与相关失效；可靠性加权会把负载"摊平"，牺牲一点电耗换取寿命与证书有效性。

**灵感 3（能耗×可靠性 → 取交的退化阶梯与锁定储备）**
直觉：既然能量与损伤都单调恶化，就应把运行模式排成两条单调退化轴——剩余能量轴与累积损伤轴——再与 v15 的时间/技能轴合成一个多维阶梯。每一维只允许向更保守方向移动，合成的档位取各维的 meet（最保守者），运行时**关节级能量—可靠性路由（Joint Energy–Reliability Router, JERR）**只在所有维都负担得起时选最高档；任一维告急就沿该维下降，且带滞回，禁止在门槛附近抖动。核心创新：**能耗—可靠性退化阶梯（Energy–Reliability Degradation Ladder, ERDL）**。它把"还剩多少电、关节还剩多少寿命、还剩多少毫秒、技能还能组合到第几档"统一成一个可执行的档位选择，并把 `E_res` 在所有档位中锁定给安全停止。反直觉点：最省电的档不一定是第 0 档——第 0 档若频繁触发 `a_ask` 与重规划，反而更耗电；因此阶梯的排序变量应是"单位安全进度能耗"，而不是瞬时功率。

**三者如何统一**
统一为 **v15 语义层之上的资源实现层**：v15 回答"在时间与技能约束下允许什么"（`Exec_v15`），v16 回答"在剩余能量与剩余寿命约束下，这些允许的动作里还能安全实现多少"（`Exec_v16`）。ERC 把能量变成逐帧证书；CDC/RMI 把磨损变成路径相关、单调收缩的证书；ERDL/JERR 把两类证书与时间/技能阶梯合成一个取交的档位。共享状态 `ζ_er=(B_E, E_res, SoC, V_bus, T_j, δ_T, D_j, σ_j(D), i*_E, i*_D, mode, hysteresis)`。**ERC 回答"电够不够安全停"，CDC 回答"关节还能撑多久、证书该多保守"，ERDL/JERR 回答"这一帧到底该跑到哪一档"**。三者不是三个节能补丁，而是"预算—损伤—路由"的资源链。

## 1. 研究问题（轮次升级版）

- **Q1（能量证书的可证语义）**：如何定义"执行后仍有认证停止能量"才使任意中断都安全？`E_stop` 的上界如何在未知未来轨迹上保持 sound？电池老化、内阻上升、母线电压塌陷如何进入 `E_usable` 而不使证书过度保守？储备 `E_res` 如何与 v15 的 `B_safe`/RTIC 衔接？
- **Q2（损伤证书与余量膨胀）**：如何用可观测信号（电流、温度、编码器跟踪误差、齿隙估计）在线更新 `D_j` 而不累积不可检出的漂移？RMI 的膨胀系数如何校准才不把"磨损"误判成"外扰"？损伤预算在关节间如何分配才既不制造单点又不过度保守？
- **Q3（多维阶梯与路由）**：时间、技能、能量、损伤四轴的单调阶梯如何取交才保持嵌套与无抖振？"单位安全进度能耗"能否成为可在线估计的选档目标？锁定储备与滞回会不会让系统卡在低档、损失活动性？
- **Q4（兼容、退化与活性）**：四轴同时退化时是否会出现"每轴都合规、合成后却无动作可用"的空集？CDC 的保守性会不会把可用寿命过早耗尽？新增模块能否守住 50Hz/p99≤22ms 与能耗预算，并严格退回 v15？

## 2. 设计原则（在 P22–P24 基础上新增 P25–P27）

**P25 能量即第二截止期律（Energy as Second Deadline）**
不存在"平均省电"。每个被执行的动作必须携带能量储备证书：执行后剩余可用能量 ≥ `E_res`，且 `E_res` 足以覆盖一次认证停止与重校准。安全关键路径必须**先扣除停止能量再做优化**；若任何候选都不能同时满足任务与储备，只能执行认证停止或 `a_ask`，**不得为省电而透支储备**。

**P26 可靠性只收缩不扩张律（Reliability Shrinks, Never Expands）**
损伤必须按关节、路径相关地记账；证书余量对累积损伤单调非增：`m'(a,x,D) = m(a,x) − Σ_j κ_j(σ_j(D_j)−σ_{j,0}) ≤ m(a,x)`。能耗优化不得用"消耗可靠性预算"换取任何新增授权；`Acc_ER = Acc_E ∩ Acc_D ∩ Acc_v15 ⊆ Acc_v15`。任何损伤模型不确定处一律取保守侧。

**P27 多维阶梯取交律（Multidimensional Ladder Meet）**
时间、技能、能量、损伤四轴的档位必须各自单调嵌套，合成档位取 meet：`k* = min(k_time, k_skill, k_E, k_D)`。剩余资源收缩时只能沿至少一轴向更保守方向移动，禁止跨轴跳到未认证档；检测到热失控、电压塌陷或损伤异常时必须**安全塌缩**到第 0 档并触发重校准，而不是继续用旧档"赌一把"。

## 3. 与基线的接口（如何退化）

- ERC 失效 ⇒ 注入无约束中立元：`Acc_E≡ActionSpace`、`E_res≡0`，只保留 v15 路径，**等价 v15**；
- TBSE 失效 ⇒ 使用最保守的常量电池/热模型（满电、常温、最大内阻），证书只会更保守，**不新增授权**；
- CDC/RMI 失效 ⇒ `D_j≡0`、`σ_j≡σ_{j,0}`、无余量膨胀，**等价 v15 证书路径**；
- ERDL 失效 ⇒ 单档运行 + v15 的 DDL/SCD 阶梯，无能量/损伤轴，**等价 v15 调度**；
- JERR 失效 ⇒ 由 v15 路由器按固定顺序选档，能量/损伤仅作事后检查，**等价 v15**；
- 五者全失效 ⇒ MetricVoiceGauge-NCD-HUTDH v15，再沿 v15→v14→…→v6 退化链退回；
- **安全继承**：ERC 只做能量取交，CDC/RMI 只做余量相减，ERDL/JERR 只做 meet 与单调降档。所有端口均不能新增授权或放宽阈值；`Exec_v16⊆Exec_v15` 由引理 139 与引理 140 保证。

## 4. 预期贡献

1. **能量储备证书**：把能耗从软目标改写为逐帧、可中断、带锁定停止储备的语义，解决"省电策略悄悄侵蚀安全停止能力"的结构性隐患；
2. **累积损伤证书与余量膨胀**：把可靠性从静态故障率改写为路径相关、可在线更新的损伤账本，并让磨损单调地收紧安全证书，填补"磨损后证书仍按新机器"的空白；
3. **多维资源退化阶梯**：把时间、技能、能量、损伤合成一个取交、单调、带滞回的档位选择，使系统在电量与寿命同时下降时优雅降级而非突然失效；
4. **资源层—语义层分离**：v15 管"允许什么"，v16 管"在剩余能量与寿命内还能实现多少、代价多少"，用 `Exec_v16⊆Exec_v15` 把节能与安全解耦；E671–E690 覆盖储备安全、损伤标定、余量膨胀、阶梯单调、长时耐久与端到端消融。

## 5. 本轮最大风险

**一句话**：能量与损伤证书都建立在对电池内阻、热模型与磨损模型的外推信任上，而在最需要它们的极端工况（高负载、深放电、连续热循环）下，模型误差与真实退化会同向叠加，系统可能在"每一帧都满足能耗与可靠性证书"的表象下，把最后的安全储备耗在一个已经失效的执行器上——即**省电的、寿命自洽的、却绝对错误的安全决定**。

## 1. 关键算法骨架

# IP-403 Thermal–Battery State Estimator：热—电状态估计
class ThermalBatteryStateEstimator:
    def __init__(self, battery_model, thermal_model, calib):
        self.bat = battery_model          # OCV(SoC), R_int(SoC,T), 容量
        self.th = thermal_model           # 一阶热模型 C_th, h, Q_loss
        self.calib = calib                # 共形校准集（SoC/温度/内阻）
        self.state = calib.nominal_state()

    def update(self, obs, dt):
        # 库仑计数 + 开路电压/内阻联合估计，抑制长期漂移
        soc_pred = self.state.SoC - obs.current * dt / (self.bat.C_nom * self.bat.eta)
        self.state.SoC = self._fuse(self.state.SoC, soc_pred, obs.v_bus, obs.current)
        self.state.R_int = self.bat.R(self.state.SoC, self.state.T)
        # 母线电压塌陷：用内阻与瞬时电流预测，取保守下界
        self.state.V_bus = self.bat.ocv(self.state.SoC) - obs.current * self.state.R_int
        self.state.T = self.th.step(self.state.T, obs.tau, obs.omega, dt)
        self.state.delta_T = self._derating(self.state.T, self.calib.T_ref)
        return self.state

    def _fuse(self, prior, pred, v_bus, current):
        # 贝叶斯/卡尔曼融合；外推不确定时向保守侧收缩 SoC
        return min(prior, pred) if self.calib.coverage_gap() else (prior + pred) / 2

    def _derating(self, T, T_ref):
        # 温度越高，可用转矩上限越低；取校准曲线下包络
        return clip(self.calib.derating_lower(T, T_ref), 0.0, 1.0)


# IP-402 Energy-Reserve Certificate：能量储备证书
class EnergyReserveCertificate:
    def __init__(self, tbse, stop_policy, e_res, safety=1.15):
        self.tbse = tbse
        self.stop_policy = stop_policy     # 认证停止能量模型
        self.e_res = e_res                 # 锁定储备
        self.safety = safety               # E_stop 的保守放大系数

    def usable_energy(self, st):
        return max(0.0, st.SoC * self.stop_policy.C_nom * self.stop_policy.eta
                   * (1 - self.stop_policy.age_loss) - self.stop_policy.sag(st))

    def stop_energy_upper(self, x):
        # 对未来轨迹取上界：最坏减速/制动 + 保持姿态
        return self.safety * self.stop_policy.energy_upper_bound(x)

    def feasible_set(self, x, candidates, st):
        e_avail = self.usable_energy(st) - self.e_res
        return [a for a in candidates
                if self.action_energy(a, x, st) + self.stop_energy_upper(self.transition(x, a))
                <= e_avail]

    def action_energy(self, a, x, st, dt):
        # 电功率 = 铜耗 + 机械功 + 电子/传感/计算，取保守上界
        p_loss = sum(tau[j] ** 2 * st.R_int / k_t[j] ** 2 for j in joints(a))
        p_mech = sum(tau[j] * omega[j] for j in joints(a))
        return (p_loss + p_mech + self.stop_policy.p_elec) * dt

    def certificate(self, a, x, st, dt):
        e_after = self.usable_energy(st) - self.action_energy(a, x, st, dt)
        m_stop = e_after - self.e_res - self.stop_energy_upper(self.transition(x, a))
        return EnergyCert(ok=(m_stop >= 0), e_after=e_after, m_stop=m_stop)


# IP-404 Cumulative Damage Certificate：累积损伤证书
class CumulativeDamageCertificate:
    def __init__(self, d_budget, exponent=3.0, alpha_fair=0.5):
        self.D = {j: 0.0 for j in d_budget}     # 归一化损伤
        self.budget = d_budget                  # 每个关节的生命周期预算
        self.m = exponent                       # 疲劳指数（轴承≈3，谐波柔轮更高）
        self.alpha_fair = alpha_fair            # 公平份额：单关节最多占已用预算比例

    def update(self, tau, temp, delta_theta, dt):
        # 雨流计数后的等效循环 + 热循环项；Miner 线性累积
        for j in self.D:
            d_mech = self._mech_increment(j, tau[j], delta_theta[j])
            d_therm = self._thermal_increment(j, temp[j], dt)
            self.D[j] = min(1.0, self.D[j] + d_mech + d_therm)
        return self.D

    def _mech_increment(self, j, tau, dtheta):
        return (abs(tau) / self.budget[j].tau_rated) ** self.m * abs(dtheta) / self.budget[j].theta_life

    def _thermal_increment(self, j, temp, dt):
        return max(0.0, temp - self.budget[j].T_ref) / self.budget[j].T_life * dt

    def feasible_set(self, candidates, x, tau_pred, dtheta_pred):
        ok = []
        for a in candidates:
            d = {j: self._mech_increment(j, tau_pred[a][j], dtheta_pred[a][j])
                 + self._thermal_increment(j, x.temp[j], x.dt) for j in self.D}
            if all(self.D[j] + d[j] <= self.budget[j] for j in self.D) \
               and all(d[j] <= self.alpha_fair * (self.budget[j] - self.D[j]) for j in self.D):
                ok.append(a)
        return ok

    def remaining_life(self):
        return {j: 1.0 - self.D[j] for j in self.D}


# IP-405 Reliability Margin Inflation：磨损引起的余量膨胀
class ReliabilityMarginInflation:
    def __init__(self, sigma0, c, kappa):
        self.sigma0 = sigma0      # 新机器识别不确定度
        self.c = c                # 磨损放大系数
        self.kappa = kappa        # 证书保守系数 >= 1

    def sigma(self, D):
        return {j: sqrt(self.sigma0[j] ** 2 + self.c[j] * D[j]) for j in D}

    def adjusted_margin(self, m, D):
        # 只扣减"相对新机器新增的"不确定度，避免重复保守
        s = self.sigma(D)
        return m - sum(self.kappa[j] * (s[j] - self.sigma0[j]) for j in D)


# IP-406 Energy-Reliability Degradation Ladder：能耗—可靠性退化阶梯
class EnergyReliabilityLadder:
    def __init__(self, modes, e_res, cdc):
        # modes[0] 最保守（认证停止），index 增大能力增强
        self.modes = modes
        self.e_res = e_res
        self.cdc = cdc

    def rung_energy(self, st, erc):
        usable = erc.usable_energy(st)
        k = 0
        for i, M in enumerate(self.modes):
            if M.power * M.dt <= usable - self.e_res:
                k = i
        return k

    def rung_damage(self):
        k = 0
        for i, M in enumerate(self.modes):
            if all(self.cdc.D[j] + M.damage[j] <= self.cdc.budget[j] for j in self.cdc.D):
                k = i
        return k

    def rung(self, st, erc):
        return min(self.rung_energy(st, erc), self.rung_damage())


# IP-407 Joint Energy–Reliability Router：四轴取交路由
class JointEnergyReliabilityRouter:
    def __init__(self, ladder, v15_router, hyst, lambda_e, lambda_d):
        self.ladder = ladder
        self.v15 = v15_router
        self.hyst = hyst
        self.lam = (lambda_e, lambda_d)

    def select(self, k_time, k_skill, st, erc, cdc, prev_k):
        k_er = self.ladder.rung(st, erc)
        k = min(k_time, k_skill, k_er)          # P27：多维取交

        # 滞回：向上换档必须重新认证，向下换档立即生效
        if k > prev_k and not self._recertified(st, cdc):
            k = prev_k
        if self._collapse(st, cdc):
            k = 0                                # 热失控/电压塌陷/损伤异常
        return k

    def _collapse(self, st, cdc):
        return (st.T.max() >= self.ladder.modes[0].T_trip
                or st.V_bus <= self.ladder.modes[0].V_trip
                or max(cdc.D.values()) >= self.ladder.modes[0].D_trip)

    def _recertified(self, st, cdc):
        return st.thermal_settled and cdc.fresh and st.coverage_ok

    def reliability_weighted_cost(self, a, x, st, erc, cdc):
        # 可靠性加权：短期省电不得以单点磨损为代价
        e = erc.action_energy(a, x, st, x.dt)
        d = sum(cdc.predicted_increment(a, x).values())
        return self.lam[0] * e + self.lam[1] * d

    def pick_balanced(self, candidates, x, st, erc, cdc):
        return min(candidates, key=lambda a: self.reliability_weighted_cost(a, x, st, erc, cdc))

## 3. 推导

**引理 131（能量储备不变式 ⇒ 认证停止始终可用）**
设每步执行的动作 `a_t` 满足 `E(a_t,x_t)+E_stop(x_{t+1}) ≤ E_usable(t)−E_res`，且 `E_stop` 是认证停止能量的上界。则对任意 `t`，都有 `E_usable(t+1) ≥ E_res + E_stop(x_{t+1})`；因此从任何可达状态都能在不侵占储备的前提下执行认证停止。
证明：由 `E_usable(t+1)=E_usable(t)−E(a_t,x_t)` 与约束直接得 `E_usable(t+1) ≥ E_res+E_stop(x_{t+1})`。对 `t` 归纳即得全时成立。∎ 推论：**能量耗尽只会导致任务中止，不会导致失控**；ERC 把"省电"与"失能"解耦。

**引理 132（能量的单调收缩）**
若 `SoC' ≤ SoC` 且 `T' ≥ T`（从而 `δ_T' ≤ δ_T`），则对任意 `x`，`Acc_E(x,SoC',T') ⊆ Acc_E(x,SoC,T)`。
证明：`E_usable` 关于 `SoC` 单调非减；`E_stop` 与动作能耗关于可用转矩单调，而可用转矩随温度升高按 `δ_T` 下降，故同一约束在 `(SoC',T')` 下更难满足。于是可行集只会缩小。∎ 推论：**电池与热状态的恶化只会收紧授权**；不存在"越热越能跑"的边际。

**引理 133（RMI 的可靠性修正 soundness）**
设新机器下识别误差满足 `|e_j|≤σ_{j,0}` 时名义余量 `m` 足以保证安全；磨损后真实误差界变为 `σ_j(D_j)` 且 `σ_j(D_j)≥σ_{j,0}`。定义 `m'=m−Σ_jκ_j(σ_j(D_j)−σ_{j,0})`，`κ_j≥1`。若 `m'≥0`，则磨损后动作仍满足同一安全判据。
证明：最坏情况下新增误差为 `σ_j(D_j)−σ_{j,0}`，按 `κ_j≥1` 保守放大后从余量中扣除；`m'≥0` 意味着扣除后仍有非负余量，故原安全不等式成立。∎ 推论：**RMI 只扣"新增"不确定度，避免对新机器重复保守**；磨损只会让授权单调收缩（对应 P26）。

**引理 134（无免费可靠性：损伤指数的凸性交换）**
设关节 `j` 的机械损伤率为 `D_j ∝ τ_j^{m}`（`m>2`），电损耗为 `E_j ∝ τ_j^{2}`，且需满足 `Σ_j τ_j = T_req`。则可靠性加权代价 `Σ_j(λ_E τ_j²+λ_D τ_j^{m})` 的唯一最小点在负载摊平处；任何"把负载从高损伤关节转移到低损伤关节以省电、却使某关节集中受力"的方案，都会使 `max_j D_j` 严格增加。
证明：`m>2` 时 `τ↦λ_Eτ²+λ_Dτ^m` 严格凸，拉格朗日条件给出唯一内点；若某关节份额趋于集中，由严格凸性代价上升；`max_j D_j` 随该关节 `τ_j` 单调增加。∎ 推论：**逐帧最优能耗不等于全寿命最优**；必须用 `λ_D` 显式给可靠性定价，否则会制造单点磨损。

**引理 135（多维阶梯取交的单调性与无越级）**
若时间、技能、能量、损伤四轴档位各自单调嵌套，则 `k*=min(k_time,k_skill,k_E,k_D)` 关于四轴资源坐标单调非增；且任何 `k*` 都同时不超过每一轴的已证档位，故不存在跨轴跳到未认证档。加滞回后，向上换档只在重新认证通过时发生，因而不会在门槛附近抖振。
证明：`min` 对每个分量单调；`k*≤k_axis` 对所有轴成立；滞回只阻止向上跳变，向下仍立即生效。∎ 推论：**退化在安全方向上单调，但活性可能单调变差**；必须为第 0 档预留非空停止/`a_ask` 集。

**引理 136（热降额与电压塌陷下的能量安全）**
若 `E(a,x)` 用降额后的转矩上限 `δ_T·τ_max` 计算，`E_stop` 用 `V_bus` 的下界计算，则实际执行能耗不超过证书估计；当 `V_bus` 或 `T` 越过安全阈值时，ERDL 的第 0 档仍能在 `E_res` 内完成认证停止。
证明：能耗关于转矩与电压的单调性保证保守估计；第 0 档由物理构造只包含停止/柔顺/`a_ask`，且 `E_res` 按其最坏能耗预留。∎ 推论：**热与电压的极端值必须进入能量证书，而不是留给事后保护**。

**引理 137（能耗—可靠性—活性三难下界）**
设任务共 `N` 步，其中 `A` 步为生产性动作（其余为回退/停止），生产性动作的最小能耗为 `e_min`、最小损伤为 `d_min`，回退能耗为 `e_fb`。则任何满足 P25/P26 的策略都满足
```
A ≤ min( (B_E − E_res·N − N·e_fb)/(e_min − e_fb),  B_D/d_min ) ，
```
其中 `B_D = min_j D_j^max` 为最紧关节预算。因此"满活性 + 零能量开销 + 零损伤"不可能同时成立。
证明：总能耗至少为 `A·e_min+(N−A)·e_fb+E_res·N`，总损伤至少为 `A·d_min`；分别不超过 `B_E` 与 `B_D`，解出 `A` 的上界。∎ 推论：**必须显式声明牺牲哪一项**；`λ_E/λ_D` 只改变前沿上的位置，不改变前沿本身。

**引理 138（热/压/损伤异常下的塌缩与活性损失界）**
当 TBSE 触发电压塌陷、热失控前兆或 CDC 触发损伤异常时，JERR 强制 `k*=0`；碰撞/失控等物理硬违规概率不高于 v15 的对应停靠。活性损失满足
```
P(无生产性认证动作) ≤ P(模型覆盖缺口) + P(电压/热异常) + P(损伤异常) + P(预算耗尽) 。
```
证明：四类事件之并覆盖所有导致第 0 档的情形；第 0 档由物理构造保证安全并预留 `E_res`。∎ 推论：**异常时不是用更高档去赌，而是用最保守档买重校准时间**。

**引理 139（模型不跨工况传递）**
若电池内阻、热模型或磨损模型的校准工况与当前工况不同（温度、倍率、负载谱、老化阶段），则基于旧模型的证书 `(κ_E,σ_j,D_j)` 对新工况无效；在声明安全前必须重校准并重新计算 `ρ_E,ρ_T,ρ_D` 与 `ε`。
证明：`R_int(SoC,T)`、热参数与疲劳指数都依赖工况；模型参数偏移会直接改变 `E_usable`、`E_stop` 与 `ΔD_j`，使原证书的支撑集不再覆盖真实分布。∎ 推论：**"上次标定过"不能作为本次证书的依据**；工况变更必须触发 `k*=0` 或重校准。

**引理 140（全失效严格退回 v15）**
令 ERC 取 `Acc_E=ActionSpace, E_res=0`，TBSE 取满电常温常量，CDC/RMI 取 `D_j=0, κ=1`，ERDL 取单档，JERR 取 `k*=min(k_time,k_skill)`，则 v16 主路径与 v15 逐模块等价，即
```
Exec_v16|_{失效} = Exec_v15 ，且一般地 Exec_v16 ⊆ Exec_v15 。
```
证明：空约束/常量模型不新增也不放宽任何动作；ERDL/JERR 只做 `min` 与筛选，不产生 v15 之外的动作；主闭环末尾的 `inherited_v15_path` 与 v15 完全一致。一般包含关系由 ERC 取交、CDC 取交、RMI 相减与 JERR 取交共同给出。∎ 推论：**新组件不引入不可回退的耦合**，v16 始终可沿 v15→…→v6 退化链退回。

## 7. 已知风险与失效模式

1. **电池模型外推失效**：低温/大倍率下 `R_int` 与可用容量非线性变化，`E_usable` 被高估。缓解：分温度/倍率标定、内阻在线辨识、保守下包络、`E_res` 留裕量。
2. **热模型时滞**：绕组温度估计滞后于真实温升，降额不足。缓解：多时间常数热模型、直接测温/热成像、预测式降额、提前塌缩。
3. **损伤模型误标定**：Miner 线性累积与雨流计数对复杂负载谱近似，疲劳指数偏差导致寿命高估。缓解：加速寿命试验分层标定、在线跟踪误差/齿隙作为损伤代理、保守指数。
4. **RMI 双重保守或不足**：把外扰误当磨损会过度收紧，把磨损误当外扰会低估余量。缓解：区分慢漂移与快扰动、磨损专项校准、`κ` 分关节标定。
5. **负载摊平牺牲任务进度**：为平衡损伤而选择低效动作，端到端完成率下降。缓解：`λ_D` 可调但只影响选择不影响证书、把摊平代价计入任务预算。
6. **锁定储备导致活动性塌缩**：`E_res` 过大时几乎每帧都触发停止。缓解：按任务时长自适应 `E_res`、分层储备、把 `a_ask` 计入预算。
7. **多维取交产生空集**：四轴各自可行但交集为空，系统频繁 `a_ask`。缓解：空集时优先释放损伤轴（若远未到寿命）、保证第 0 档非空、显式记录空集原因。
8. **滞回造成卡在低档**：异常恢复后仍停在保守档，错过任务窗口。缓解：重校准后允许一次性向上复核、设置最大滞回时长、关键任务显式请求重证。
9. **工况变更沿用旧证书**：换电池、换环境温度、换负载谱后仍用旧模型。缓解：工况指纹检测、变更即 `k*=0`、强制重校准（引理 139）。
10. **能量与可靠性误差同向叠加**：深放电使电压塌陷、内阻发热、损伤加速，三者在极端工况下同时恶化。缓解：联合保守界、双重检测、任一异常即最低档、保留纯 v15 影子路径。
11. **共享执行器单点失效**：所有档位依赖同一批关节，磨损相关失效会同时击穿多个证书。缓解：异构冗余、关键动作多关节分担、故障注入与影子抽查。

## 8. 本轮最大风险

**一句话**：能量与损伤证书都建立在对电池内阻、热模型与磨损模型的外推信任上，而在最需要它们的极端工况（高负载、深放电、连续热循环）下，模型误差与真实退化会同向叠加，系统可能在"每一帧都满足能耗与可靠性证书"的表象下，把最后的安全储备耗在一个已经失效的执行器上——即**省电的、寿命自洽的、却绝对错误的安全决定**。
