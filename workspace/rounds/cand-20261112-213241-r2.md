# 第 62 轮（承接第 61 轮「具身语义进化闭环 ESEC」IP-173~182；新一轮灵感循环第 2 轮；本轮灵感：「任务分解」×「视觉伺服」）

> 第 61 轮用 USR×MEL×DMS×SRT-Dual×PCE+++++ 把场景、意图、阻抗、证据统一到共享嵌入空间 ℝ^d_us，并以「语义流（10–100Hz）—实时流（1–10kHz）」解耦大模型推理与实时控制。但回看其「任务」与「视觉」两环，仍有六个根本性缺口：
> 1. **任务是一整块**：MEL/DMS 只产出「意图→约束」，没有把长程操作显式分解为**子任务、依赖、前置/后置条件、终止谓词**；一旦中途失败，只能全局重来，无法定位是哪一步、哪个条件坏了。
> 2. **约束是全局一次性编译**：EEIS 一次编译整段 K_safe，没有「子任务级约束信封」与**继承/收紧**语义；子任务之间的安全边界靠人工约定，组合安全性无法证明。
> 3. **视觉只用于「理解」不用于「闭环」**：第 61 轮的视觉被 ViT 编码成 scene_emb，**没有图像特征误差、没有交互矩阵、没有视场（FOV）/遮挡约束**——它能说「这是什么」，却不能把「把手中心对准夹爪中心」这个误差收敛到零。
> 4. **视觉与力/阻抗没有交接协议**：接近靠视觉、接触靠力，但**何时切换、如何防抖、滑移后如何重新伺服**没有定义；视觉与力各自闭环，中间是断的。
> 5. **时间尺度只有两级**：语义流与实时流之间缺一个「任务流（~1–10Hz）」和一个「视觉伺服流（~30–200Hz）」；任务分解与图像误差无处安放，只能被硬塞进语义流。
> 6. **失败不可归因**：视觉伺服发散、特征丢失、约束不可行、外部扰动在最终证书里混成一个「失败」，无法支撑局部重分解与安全审计。

## 0. 直觉与动机

**灵感 1（任务分解 → 分层可验证任务代数 HTA）**
直觉：让大模型「直接吐一个任务计划」是不可靠的——它会漏前置条件、编造不存在的物体、给出无法判定的成功条件。真正可用的任务分解应像**带类型的程序**：每个子任务声明「我需要什么（前置）、我保证什么（后置）、我绝不破坏什么（不变式）、我用什么接口执行（契约）」。构建 **分层任务代数 HTA**：任务是一棵 AND/OR 图，AND 节点要求所有子任务完成，OR 节点允许任一可行分支；大模型只负责「提出分解」，一个**形式化验证器**在场景图/可供性场上检查前置可满足、后置可蕴含、不变式只收紧不放宽。关键洞见：**任务分解不是提示词，而是一份可被证明的证书**。

**灵感 2（任务分解 → 任务-约束编译 TCC）**
直觉：第 61 轮的 EEIS 是「一次性编译器」，本轮把它改成「**按子任务编译**」：每个子任务携带一个阻抗/力信封，父任务把安全信封**下发**给子任务，子任务只能在信封内收紧、不能放宽（单调安全）；预算也随分解下发，未用完的回收。这样「每个叶子安全 + 组合规则可靠 ⇒ 整棵树安全」成为可归纳证明的命题，而不是工程约定。

**灵感 3（视觉伺服 → 特征-阻抗双空间控制 FIDC）**
直觉：视觉的价值不只是「给一个 embedding」，而是**在图像特征空间里闭环**。设图像特征 s、期望 s*，误差 e_s=s*−s，交互矩阵 L_s，则视觉阻抗为 L_e = L_sᵀK_v e_s − D_v ṡ；它与笛卡尔阻抗通过一个随交接状态变化的混合系数 β 融合，并由零空间保持姿态/避障。相机未标定时用 Broyden 在线估计 L̂ 并传播协方差；视场边界用控制屏障函数（CBF）硬约束，避免「误差还没收敛，特征先跑出画面」。关键洞见：**视觉伺服是任务契约在图像空间的连续实现，不是另一个感知模块**。

**灵感 4（视觉伺服 → 视觉伺服契约 VSC）**
直觉：子任务与控制器之间需要一个**可组合、可验证的接口**。定义 **视觉伺服契约 VSC**：特征集合、期望特征轨迹、收敛容差、特征速度上限、视场裕度、交互矩阵条件数裕度、深度/可见性裕度、遮挡回退策略、交接谓词。VSC 给出一个标量**可伺服度 μ_vs**；μ_vs 低于阈值就说明「这个子任务在当前视角下根本没法可靠地视觉伺服」，应在分解阶段就被拒绝，而不是执行到一半才发现。关键洞见：**把「能不能伺服」变成任务分解的一等约束**。

**灵感 5（耦合 → 视觉-触觉交接与重伺服 VTHR）**
直觉：人类做插入任务时是「看着靠近 → 碰到后靠手感 → 歪了就退回来重新看」。构建 **VTHR**：交接谓词 H =（接触证据出现）∧（视觉对齐误差 ≤ ε_align）∧（相对速度 ≤ v_contact），并用**迟滞**防止视觉/力来回抖；接触后仍用 eye-in-hand 跟踪特征，检测切向滑移与错位；一旦滑移/力超限/对齐误差反弹，触发**重伺服**：退到安全站位→重新捕获特征→重新接近，重试 R 次仍失败才交给 DMS 发起澄清。关键洞见：**视觉与力不是二选一，而是有证书的接力**。

**灵感 6（合流 → 任务-视觉-执行三流闭环 TVE-Tri）**
直觉：第 61 轮是双流，本轮补上两个时钟：**任务流（1–10Hz）**做分解/验证/约束编译，**视觉流（30–200Hz）**做特征提取/伺服，**实时流（1–10kHz）**做阻抗/力控。三流通过**带版本号的任务锚点与视觉锚点**同步：实时流只消费「子任务信封 + 当前特征误差 + 可伺服度」，任一慢流超时都按预设安全链回退（任务停→保持当前子任务；视觉停→守卫式力控；实时流永不依赖慢流）。关键洞见：**把「任务分解—视觉伺服—力控」放进同一个可审计的时序契约**。

**灵感 7（失败归因 → 局部重分解 FARD）**
直觉：失败不是终点，而是**归因信号**。把失败分解到「前置条件违反 / VSC 不可伺服 / 约束不可行 / 外部扰动 / 感知失败」五类，用视觉残差、力证据、时序证据做贝叶斯归因，然后只替换失败子树、保留祖先与兄弟节点，重新验证后继续。关键洞见：**长程任务的鲁棒性来自局部修复，而不是全局重规划**。

**灵感 8（预算与证书 → PCE+++++++ / J_tve）**
直觉：分解深度、重规划次数、验证器调用属于**任务预算**；特征帧率、伺服迭代、FOV 检查、Broyden 更新属于**视觉伺服预算**。把二者加入第 61 轮认知预算，得到 PCE+++++++；证书 J_tve 在 J_sem_exec 之上增加「分解有效、VSC 可伺服、交接有效、预算未越界」四项证明。

## 1. 形式化定义（增量：定义 173–184）

**定义 173（分层任务代数 HTA）** 任务代数 T = (N, E, ρ, Pre, Post, Inv, Ω)。其中：
- **节点** n ∈ N：复合节点（AND/OR）或本原节点（叶子，可直接映射到控制器）；ρ: N → {AND, OR, LEAF}。
- **前置** Pre_n：定义在场景图 G、可供性场 A、对话信念 b_intent、几何不确定度 u_geo 上的谓词；
- **后置** Post_n：子任务完成时应成立的谓词（含视觉对齐、接触状态、物体位姿变化）；
- **不变式** Inv_n：执行全过程必须保持的安全谓词（力/阻抗信封、碰撞自由、视场约束）；
- **边** E：AND 节点表示有序/偏序子任务（用 E 上的先后约束表达），OR 节点表示备选分解；
- **分解** D: N_compound → 2^N 的子节点集合，满足类型良好（子任务契约可被父契约包含）；
- **执行迹** τ = (n_0, a_0, o_0, n_1, …)；**有效分解** Valid(D, G, A) 当且仅当：
  1. Pre_root 在当前 (G, A, b_intent) 下可满足；
  2. 对每个 AND 子任务，其 Pre 在前驱 Post 的合取下可满足；
  3. 对每个子任务 n，Inv_n ⇒ Inv_parent(n)（不变式只收紧）；
  4. 叶子 Post 的合取蕴含 Post_root；
  5. 每个叶子存在满足其契约的控制器。
- **分解证书** Cert_D = (D, 前提见证, 蕴含证明链, 契约包含检查, 场景版本)。

**定义 174（子任务能力契约 SCC）** 每个节点 n 的契约 C_n = (Req_n, Guar_n, K_n^env, F_n^env, VSC_n, Term_n, Cost_n)：
- Req_n：所需观测/条件（特征可见、位姿协方差 ≤ τ_pose、传感器可用）；
- Guar_n：若 Req_n 成立且控制器遵守契约，则执行后 Guar_n 成立（与 Post_n 相容）；
- K_n^env = [K_min, K_max]：允许的阻抗信封；F_n^env = [0, F_max]：允许的力信封；
- VSC_n：视觉伺服契约（定义 175）；
- Term_n：终止谓词（视觉收敛 ∧ 接触状态 ∧ 相对速度）；
- Cost_n：期望时延/能耗/风险估计。
- **契约包含** C_child ⪯ C_parent ⇔ Req_parent ⊆ Req_child ∧ Guar_child ⇒ Guar_parent ∧ K_child^env ⊆ K_parent^env ∧ F_child^max ≤ F_parent^max ∧ VSC_child 的特征集可由 VSC_parent 的观测覆盖。

**定义 175（视觉伺服契约 VSC）** VSC = (S, s*(t), L, ε_s, v_max, m_fov, m_cond, m_vis, O, H)。其中：
- **特征** S：图像点/线/矩/位姿特征，s ∈ ℝ^k（k ≤ 12 以保证实时）；
- **期望轨迹** s*(t)：由子任务几何目标生成（如「把手中心到夹爪中心」）；
- **交互矩阵** L(s) ∈ ℝ^{k×6}（或 L̂ 在线估计）；
- **收敛** ‖e_s‖ ≤ ε_s；**速度界** ‖ṡ‖ ≤ v_max；
- **裕度**：m_fov = 特征到视场边界的最小归一化距离；m_cond = 1/cond(L)；m_vis = 可见性/深度不确定度裕度；
- **可伺服度** μ_vs = min(m_fov, m_cond, m_vis)；
- **遮挡回退** O ∈ {reobserve, probe, ask_user, abort}；
- **交接谓词** H（定义 178）。
- **可伺服判定** Servoable(VSC, G, A) ⇔ rank(L)=k ∧ μ_vs ≥ τ_vs ∧ S 在当前场景图中可观测。**不可伺服 ⇒ 该分解无效**。

**定义 176（任务-约束编译 TCC）** 编译算子 Ξ: (T, G, A, B) → (𝒞_leaf, 约束程序, 预算账本)：
- **下发**：对 n 的每个子任务 c，K_c^env ← K_n^env，F_c^env ← F_n^env，B_c ← alloc(B_n, children)；
- **收紧**：子任务可执行 K_c ← K_c ⊓ K_c^local，其中区间交 ⊓ 只允许收缩；若 K_c = ∅ 或 F_c^max < F_min,op ⇒ **约束不可行**，拒绝该分解；
- **组合安全**：父不变式 Inv_n 在子任务执行期间由「子不变式 ∧ 组合规则」保持；
- **预算回收**：子任务完成后剩余 B_c 归还父节点，供后续兄弟节点使用。
- **单调性**：∀c, K_c^env ⊆ K_n^env ∧ F_c^max ≤ F_n^max；编译不会放宽任何安全边界。

**定义 177（特征-阻抗双空间控制 FIDC）** 给定特征误差 e_s = s* − s、视觉增益 K_v ≻ 0、阻尼 D_v ≻ 0、笛卡尔阻抗 (K_p, K_d)：
```
视觉阻抗：  L_e = L_sᵀ (K_v e_s − D_v ṡ)
笛卡尔阻抗：F_c = K_p (x* − x) + K_d (ẋ* − ẋ) + F_ff
混合控制：  τ = Jᵀ [ (1−β)·F_c + β·L_e ] + N(q)·τ_null
β = σ( handover_state ) ∈ [0,1]     # 接近 β→1，接触 β→0
```
- **未标定**：L̂ 用 Broyden 更新 L̂_{k+1} = L̂_k + α(Δs − L̂_k Δq)Δqᵀ/‖Δq‖²，协方差 Σ_L 递推；Σ_L 大时降低 K_v。
- **视场安全**：定义屏障 h(s) = m_fov(s) − δ_fov，用 QP 求最小修正 Δτ 使 ḣ + γh ≥ 0；不可行则触发 O（回退）。
- **深度/尺度**：优先 2.5D 特征；深度不确定度高时按 1/(1+κ·u_depth) 缩放 K_v。
- **奇异性**：cond(L) > κ_max 时冻结视觉通道、切到位姿伺服或守卫式力控。

**定义 178（视觉-触觉交接与重伺服 VTHR）** VTHR = (H, 迟滞, 重伺服触发, 重试预算 R)：
- **交接谓词** H = contact_detected ∧ ‖e_s‖ ≤ ε_align ∧ ‖ẋ_rel‖ ≤ v_contact；
- **迟滞**：连续 τ_on 满足 H 才进入接触（β: 1→0）；连续 τ_off 满足 force < F_off 才退出（β: 0→1），防止抖振；
- **接触期视觉监控**：eye-in-hand 跟踪 s，比较特征运动与指令运动，估计切向滑移 δ_slip；
- **重伺服触发**：δ_slip > δ_slip,max ∨ 接触后 ‖e_s‖ 反弹 > ε_rebound ∨ F > F_max；
- **重伺服动作**：退到安全站位 x_standoff → 重新捕获特征（O）→ 重新接近；最多 R 次；
- **失败升级**：R 次失败 ⇒ 交 DMS（ask_clarify / propose_constraint）或 abort；
- **交接证书** Cert_H = (e_s, contact_evidence, 相对位姿不确定度, β 时间表, 迟滞计数)。

**定义 179（任务-视觉-执行三流架构 TVE-Tri）** 三条异步流水线：
- **任务流** f_T ∈ [1,10]Hz：HTA.propose（MEL/LLM）→ Verify（场景图/契约/可伺服）→ TCC.compile → 发布 TaskAnchor；
- **视觉流** f_V ∈ [30,200]Hz：特征提取 → VSC 跟踪 → FIDC 计算 → 发布 VisualAnchor（含 e_s, L̂, μ_vs, FOV 状态）；
- **实时流** f_R ∈ [1,10]kHz：读取两锚点 → EEIS 按子任务信封编译 K_safe → ERTC.dispatch → EV_exec；
- **截止期与回退**：D_T（默认 200ms）、D_V（默认 10ms）。任务流超时→保持当前子任务并冻结重分解；视觉流超时→用上一有效特征 + 守卫式力控（降速、降力）；实时流从不阻塞等待慢流；
- **切换**：子任务切换时 TaskAnchor.version++ 并使 VisualAnchor 失效，视觉流重置特征与 L̂。

**定义 180（任务-视觉一致性协议 TVCP）** 保证三流「任务-视觉-执行」一致：
- **TaskAnchor** = (task_id, subtask_id, VSC, K^env, F^env, B_ledger, G_ver, A_ver, ts, ver, checksum)；
- **VisualAnchor** = (subtask_id, S, s, s*, L̂, Σ_L, μ_vs, FOV_state, ts, ver, checksum)；
- **读取规则**：实时流检查 subtask_id 匹配、版本单调、新鲜度 (now−ts) < τ_fresh；
- **失配**：subtask_id 不匹配 ⇒ 拒绝 VisualAnchor，退回纯保守编译；
- **语义-任务对账**：VSC 的特征集必须能由当前 GSSG/AOF 观测覆盖，否则 TaskAnchor 无效（防止「计划里的把手在场景里根本看不见」）。

**定义 181（八维认知-任务-视觉预算 PCE+++++++ / B_cog8）** 在第 61 轮六项预算上新增 B_task、B_vs：
```
B_cog8 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_task, B_vs)
B_task = (MaxDepth, MaxNodes, Replans, VerifierCalls, LLMCalls)
B_vs   = (FeatureRate, MaxIters, FOVChecks, BroydenUpdates, ReacquireBudget)
cost_task = λ_d·Depth/MaxDepth + λ_n·Nodes/MaxNodes + λ_r·Replans/MaxReplans
          + λ_v·VerifierCalls/MaxVerifierCalls
cost_vs   = λ_f·FeatureRate/FeatureRate_max + λ_i·Iters/MaxIters
          + λ_c·FOVChecks/FOVChecks_max + λ_b·BroydenUpdates/MaxUpdates
voi_cog8 = VOI_meta − cost_mel − cost_usr − cost_task − cost_vs − cost_exec
```
- **降级链**（安全项永不降级）：任务深度超限→退化为「单步分解 + 逐步验证」；重规划超限→冻结当前子树并请求 DMS；视觉帧率超限→降采样特征；伺服迭代超限→切位姿伺服；Broyden 预算耗尽→冻结 L̂ 并放大保守裕度；特征重捕获超限→守卫式力控/abort。
- **预算下发**：父任务按子任务 Cost 比例分配，未用完回收（与 TCC 同一账本）。

**定义 182（失败归因与局部重分解 FARD）** 失败事件 e 的归因空间 𝒜 = {pre_violation, vsc_unservoable, constraint_infeasible, external_disturbance, perception_failure}：
- **证据**：视觉残差序列、力/滑移证据、时序超时、约束可行性、特征可见性；
- **归因后验** P(a|e) ∝ P(e|a)P(a)，取 argmax 及置信度；
- **局部修复**：若 a ∈ {pre_violation, vsc_unservoable, constraint_infeasible}，替换失败叶子/子树（OR 分支或重分解），保留祖先与兄弟；若 a = external_disturbance，重试当前叶子（受限次数）；若 perception_failure，触发 A3P 式主动感知或 DMS；
- **重新验证**：修复后必须重新通过 Valid(D) 与 Servoable(VSC)；
- **预算**：重分解次数受 B_task.Replans 约束，超限则安全回退。

**定义 183（任务-视觉-执行联合证书 J_tve）** 在第 61 轮 J_sem_exec 上增加任务与视觉证明：
```
J_tve = (J_sem_exec, task_version, Cert_D, μ_vs_min, Cert_H,
         budget_ledger, attribution, task_ver, visual_ver)
Valid(J_tve) ⇔ Valid(J_sem_exec)
             ∧ Valid(Cert_D)
             ∧ μ_vs_min ≥ τ_vs
             ∧ Valid(Cert_H)
             ∧ 所有叶子 Inv 成立
             ∧ budget_ledger 未越界
```

```python
class HierarchicalTaskAlgebra:
    def __init__(self, mel, scene_graph, aof, verifier):
        self.mel = mel
        self.G = scene_graph
        self.A = aof
        self.verifier = verifier

    def propose(self, task_spec, belief, budget):
        """大模型只负责提出候选分解，不负责保证正确。"""
        raw = self.mel.propose_decomposition(task_spec, self.G.summary(),
                                             belief, max_depth=budget.MaxDepth)
        return self.parse_to_graph(raw)          # -> T = (N, E, ρ, Pre, Post, Inv)

    def verify(self, T, budget):
        """Valid(D) 的五条检查，任何一条失败即拒绝分解。"""
        if not self.sat(T.Pre_root, self.G, self.A, belief):
            return False, "pre_root_unsatisfiable"
        for n in T.nodes:
            for c in T.children(n):
                if not self.entails(T.Post_pred(n), c.Pre):
                    return False, f"pre_unsat:{c.id}"
                if not self.inv_tightens(c.Inv, n.Inv):
                    return False, f"inv_loosened:{c.id}"
                if not (c.K_env <= n.K_env and c.F_max <= n.F_max):
                    return False, f"contract_not_subsumed:{c.id}"
                if not Servoable(c.VSC, self.G, self.A):
                    return False, f"vsc_unservoable:{c.id}"
            if n.is_leaf and not self.has_controller(n):
                return False, f"no_controller:{n.id}"
        if not self.entails(And([leaf.Post for leaf in T.leaves()]), T.Post_root):
            return False, "post_not_entailed"
        return True, Cert_D(T, witnesses=self.collect_witnesses(T))

    def repair(self, T, failed_node, cause):
        """FARD：只替换失败子树，保留祖先与兄弟。"""
        if cause in ("pre_violation", "vsc_unservoable", "constraint_infeasible"):
            alt = self.propose_local(failed_node, self.G, self.A)
            if alt is None:
                return None
            T2 = T.replace_subtree(failed_node, alt)
        elif cause == "disturbance":
            T2 = T.retry(failed_node)            # 受限重试
        else:                                    # perception_failure
            T2 = T.insert_active_perception(failed_node)
        ok, cert = self.verify(T2, budget)
        return (T2, cert) if ok else None
```

```python
class VisualServoContract:
    def __init__(self, S, s_star, L, eps=0.01, v_max=0.5,
                 tau_vs=0.3, fov_margin=0.15):
        self.S, self.s_star, self.L = S, s_star, L
        self.eps, self.v_max, self.tau_vs = eps, v_max, tau_vs
        self.fov_margin = fov_margin

    def servoability(self, s, fov_state, depth_unc):
        m_fov  = fov_state.min_distance_to_border(s)
        m_cond = 1.0 / max(cond(self.L), 1e-9)
        m_vis  = 1.0 / (1.0 + depth_unc)
        return min(m_fov, m_cond, m_vis)

    def feasible(self, s, fov_state, depth_unc):
        return (np.linalg.matrix_rank(self.L) == len(self.S)
                and self.servoability(s, fov_state, depth_unc) >= self.tau_vs)


class TaskConstraintCompiler:
    def __init__(self, eeis, ertc):
        self.eeis, self.ertc = eeis, ertc

    def compile(self, T, budget):
        ledger = BudgetLedger()
        leaves = []
        for n in T.postorder():
            if n.is_leaf:
                K = n.K_env
                F = n.F_env
                if n.K_local is not None:                 # 只允许收紧
                    K = intersect(K, n.K_local)
                if K is None or F[1] < F_MIN_OP:
                    return None, f"infeasible:{n.id}"     # 拒绝分解
                leaves.append((n.id, K, F, n.VSC))
                ledger.allocate(n.id, budget.for_subtask(n))
            else:
                for c in n.children:
                    c.K_env = intersect(c.K_env, n.K_env)  # 下发父信封
                    c.F_env = (0, min(c.F_env[1], n.F_env[1]))
        return leaves, ledger

    def build_contract(self, leaves):
        """把叶子信封编译为 ERTC 契约；父不变式由子不变式合取保持。"""
        return [self.ertc.make_contract(k, f, vsc) for (_, k, f, vsc) in leaves]
```

### IP-187 FIDC（特征-阻抗双空间控制）

```python
class FeatureImpedanceController:
    def __init__(self, Kv, Dv, Kp, Kd, beta_gain=8.0):
        self.Kv, self.Dv = Kv, Dv
        self.Kp, self.Kd = Kp, Kd
        self.beta_gain = beta_gain
        self.L_hat = None
        self.Sigma_L = 1e-2 * np.eye(6)

    def update_interaction(self, dq, ds):
        """Broyden 在线估计 L，并递推协方差。"""
        if self.L_hat is None:
            self.L_hat = np.zeros((len(ds), len(dq)))
        denom = dq @ dq + 1e-9
        self.L_hat += 0.1 * np.outer(ds - self.L_hat @ dq, dq) / denom
        self.Sigma_L = 0.99 * self.Sigma_L + 0.01 * np.outer(ds, ds) / denom

    def compute(self, s, s_star, s_dot, x, x_star, x_dot, J, N, tau_null,
                handover_state, fov_state):
        e_s = s_star - s
        L = self.L_hat if self.L_hat is not None else self.L_s
        K_v = self.Kv / (1.0 + 5.0 * float(np.trace(self.Sigma_L)))
        L_e = L.T @ (K_v @ e_s - self.Dv @ s_dot)

        F_c = self.Kp @ (x_star - x) + self.Kd @ (x_dot_star - x_dot)
        beta = 1.0 / (1.0 + np.exp(-self.beta_gain * (handover_state - 0.5)))
        tau = J.T @ ((1 - beta) * F_c + beta * L_e) + N @ tau_null

        # FOV 控制屏障：h = m_fov - delta，强制 h_dot + gamma*h >= 0
        h = fov_state.margin(s) - fov_state.delta
        if h < fov_state.warn and fov_state.hdot(s, s_dot) + 2.0 * h < 0:
            tau = self.fov_qp_correction(tau, s, s_dot, fov_state)
            if tau is None:
                return None, "fov_infeasible"      # 触发 VSC.O 回退
        if cond(L) > 1e3:
            return None, "singularity"            # 冻结视觉通道
        return tau, "ok"
```

### IP-188 VTHR（视觉-触觉交接与重伺服）

```python
class VisualTactileHandover:
    def __init__(self, tau_on=0.02, tau_off=0.05, eps_align=0.01,
                 v_contact=0.02, max_retries=3):
        self.tau_on, self.tau_off = tau_on, tau_off
        self.eps_align, self.v_contact = eps_align, v_contact
        self.max_retries = max_retries
        self.state = "approach"      # approach -> contact -> re_servo
        self.on_cnt = self.off_cnt = 0
        self.retries = 0

    def step(self, e_s_norm, x_dot_rel, force, slip, f_max, dt):
        contact = force > F_CONTACT
        aligned = e_s_norm <= self.eps_align and x_dot_rel <= self.v_contact

        if self.state == "approach":
            self.on_cnt = self.on_cnt + dt if (contact and aligned) else 0.0
            if self.on_cnt >= self.tau_on:
                self.state, self.off_cnt = "contact", 0.0
                return "enter_contact", Cert_H(e_s_norm, force, "handover")
        elif self.state == "contact":
            if force < F_OFF:
                self.off_cnt += dt
                if self.off_cnt >= self.tau_off:
                    self.state, self.on_cnt = "approach", 0.0
                    return "exit_contact", None
            if slip > SLIP_MAX or e_s_norm > EPS_REBOUND or force > f_max:
                if self.retries >= self.max_retries:
                    return "escalate_dms", None
                self.retries += 1
                self.state = "re_servo"
                return "re_servo", None
        elif self.state == "re_servo":
            return "retract_and_reacquire", None
        return "hold", None
```

```python
class TaskVisualExecutionTripleFlow:
    def __init__(self, hta, tcc, fidc, vthr, usr, eeis, ertc, budget):
        self.hta, self.tcc, self.fidc, self.vthr = hta, tcc, fidc, vthr
        self.usr, self.eeis, self.ertc, self.budget = usr, eeis, ertc, budget
        self.task_anchor = None
        self.visual_anchor = None
        self.task_ver = self.visual_ver = 0

    def task_flow(self, task_spec, belief):
        """1-10Hz：分解→验证→编译→发布 TaskAnchor。"""
        T = self.hta.propose(task_spec, belief, self.budget.B_task)
        ok, cert = self.hta.verify(T, self.budget.B_task)
        if not ok:
            return self.hta.repair(T, self.current_subtask, cert_reason(ok))
        leaves, ledger = self.tcc.compile(T, self.budget)
        if leaves is None:
            return self.hta.repair(T, self.current_subtask, ledger)
        self.task_ver += 1
        self.task_anchor = TaskAnchor(
            task_id=T.id, subtask_id=self.next_subtask(leaves),
            VSC=self.current_vsc(leaves), K_env=..., F_env=...,
            ledger=ledger, G_ver=self.hta.G.version, A_ver=self.hta.A.version,
            ts=time.time(), ver=self.task_ver, checksum=hash(T))
        self.visual_ver += 1                       # 使旧 VisualAnchor 失效
        return self.task_anchor

    def visual_flow(self, image, fov_state, depth_unc):
        """30-200Hz：特征→VSC 可伺服判定→FIDC→发布 VisualAnchor。"""
        if self.task_anchor is None:
            return None
        s = extract_features(image, self.task_anchor.VSC.S)
        vsc = self.task_anchor.VSC
        if not vsc.feasible(s, fov_state, depth_unc):
            self.visual_anchor = VisualAnchor(self.task_anchor.subtask_id, s,
                                              mu_vs=vsc.servoability(s, fov_state, depth_unc),
                                              valid=False, ts=time.time(), ver=self.visual_ver)
            return self.visual_anchor
        s_star = vsc.s_star(time.time())
        tau, status = self.fidc.compute(s, s_star, ..., fov_state=fov_state)
        self.visual_ver += 1
        self.visual_anchor = VisualAnchor(
            self.task_anchor.subtask_id, s, s_star, self.fidc.L_hat,
            self.fidc.Sigma_L, vsc.servoability(s, fov_state, depth_unc),
            fov_state, ts=time.time(), ver=self.visual_ver, valid=(status == "ok"))
        return self.visual_anchor

    def realtime_step(self, delta_f_req, fused, xi_exec, Z_env):
        """1-10kHz：只消费新鲜锚点；慢流超时按安全链回退。"""
        ta, va = self.task_anchor, self.visual_anchor
        fresh_task = ta and (time.time() - ta.ts) < TAU_TASK
        fresh_vis = va and (time.time() - va.ts) < TAU_VIS and va.valid
        if not fresh_task:
            K_safe = self.eeis.compile(delta_f_req, fused, xi_exec, Z_env)
        elif not fresh_vis:
            K_safe = self.eeis.compile_guarded(delta_f_req, fused, xi_exec, Z_env,
                                               ta.K_env, ta.F_env)
        elif va.subtask_id != ta.subtask_id:
            K_safe = self.eeis.compile_guarded(delta_f_req, fused, xi_exec, Z_env,
                                               ta.K_env, ta.F_env)
        else:
            K_safe = self.eeis.compile_with_vsc(delta_f_req, fused, xi_exec, Z_env,
                                                ta.K_env, ta.F_env, va)
        cert = self.ertc.dispatch(K_safe)
        EV_exec = wait_contact_and_build_evidence()
        self.usr.push_evidence(EV_exec)
        return K_safe, EV_exec, cert
```

```python
class FailureAttributor:
    def attribute(self, event, evidence):
        logp = {
            "pre_violation":        evidence.pre_margin < 0,
            "vsc_unservoable":      evidence.mu_vs < TAU_VS,
```

| TCC 编译 | O(|N|·|𝒞|) 区间交 | O(|N|) | 单调收紧：K_child ⊆ K_parent，F_child ≤ F_parent |
| VSC 可伺服 | O(k³) 秩/条件数 | O(k²) | rank(L)=k ∧ μ_vs ≥ τ_vs 才允许进入伺服 |
| FIDC | O(k³+n) / 周期（k≤12，~0.05ms） | O(k²) | 无约束区 e_s → ε_s；FOV-CBF 保证不越界；奇异时冻结 |
| VTHR | O(1) / 周期 | O(1) | 迟滞防抖；F ≤ F_max；R 次失败升级 DMS |
| TVE-Tri | 任务 1–10Hz / 视觉 30–200Hz / 实时 1–10kHz | 共享内存 ~10MB | 实时流不阻塞；任一慢流超时走安全回退 |
| FARD | O(|subtree|) 归因+替换 | O(|N|) | 归因五类覆盖；局部修复保留祖先不变式并重验证 |
| PCE+++++++ | O(1) 预算检查 | O(1) | 任一预算耗尽触发对应降级，安全项不降级 |

**正确性定理（TVE-Complete）**：假设 A61–A70 及
**(A71)** HTA 验证器可靠：Valid(D) ⇒ 前置可满足、后置被叶子蕴含、不变式只收紧；
**(A72)** TCC 单调：∀c, K_c^env ⊆ K_n^env ∧ F_c^max ≤ F_n^max，且区间交为空时拒绝分解；
**(A73)** FIDC：在无遮挡、无奇异、FOV 可行区域内，K_v,D_v ≻ 0，L 有界且估计误差 ‖L̂−L‖ ≤ δ_L，则 ‖e_s‖ 指数收敛到 ε_s + O(δ_L)；
**(A74)** VSC：μ_vs ≥ τ_vs ⇒ 特征 Jacobian 满秩且 FOV 可行；
**(A75)** VTHR：迟滞时间常数满足 τ_on,τ_off > 控制周期，交接期间 F ≤ F_max，重试次数 ≤ R；
**(A76)** TVE-Tri：锚点读写原子、版本单调；任务/视觉流超时触发安全回退，实时流周期 ≤ 1ms；
**(A77)** PCE+++++++：预算单调消耗，降级链保证安全约束不放松；
**(A78)** FARD：归因空间覆盖全部失败模式，局部修复后重新验证。

则：
1. **组合安全性**：若每个叶子满足 Inv 且组合规则可靠，则根任务在整个执行迹上满足 Inv_root（对 AND/OR 结构归纳）。
2. **视觉伺服收敛性**：在 A73/A74 成立时，FIDC 使图像误差收敛到 ε_s 邻域；FOV-CBF 保证特征不越界。
3. **交接安全性**：VTHR 的迟滞避免视觉/力抖振；交接与接触期间力不超过 F_max；滑移可被检测并触发重伺服。
4. **实时性**：实时流不依赖任务/视觉流的完成，最坏情况下退化为保守编译，周期 ≤ 1ms。
5. **失败可修复性**：FARD 在 B_task.Replans 内找到通过 Valid(D) 与 Servoable(VSC) 的局部修复，否则安全 abort。
6. **预算安全性**：任一 B_cog8 维度耗尽触发对应安全降级，不违反 ERTC 契约。

## 5. 本轮最大风险

**一句话**：若 HTA 的「验证通过」只证明了符号层面的前置/后置自洽，而 VSC 的特征在当前视角下不可辨识、或发生感知混叠（相似纹理/重复结构），FIDC 会以极小残差收敛到**错误但图像自洽**的位姿，VTHR 随后在错误位置施加接触力——即「伺服一致、任务错误」的**特征幻觉**；必须以「VSC 可伺服度硬门控 + 特征可辨识性/多假设跟踪 + 交接证书 + 守卫式力限 + FARD 归因回退」构建任务-视觉安全护栏，确保视觉收敛永不等于任务正确。
