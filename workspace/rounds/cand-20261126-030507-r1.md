灵感驱动研究循环·第 1 轮（迁移学习 × 上下文理解）

> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v23+IP-431–439（云边同步 CESC / 少样本有效 FSVC / 知识产权认证 IPAM / HPC-E+ 四证准入门；其上承 v22 分层 PGEV + 机械臂 ACSC + 深度 conformal DCSC、v21 语义-规范层 SDC/CAC/DCL/GIC + HPC+、v20 联邦感知 PCA/CTS/CFC/HPC/CFCtrl）。
> 本轮纪律：**迁移是带负迁移风险的"知识复用"、上下文是证书的"解释框架"**。不推倒 v23：CESC/FSVC/IPAM/HPC-E+/HDL/ACSC/DCSC/CFC+++ 全部保留。本轮只做一件事：**把 v23 的"无上下文证书"升级为"上下文索引证书"，并把"知识迁移"变成一张可审计、可证伪、带负迁移上界的迁移证书；顺手用上下文分层堵住 v23 的最大风险（全局 conformal 覆盖在混合漂移下的共振崩塌）**。

## 0. 直觉与动机

**灵感 1（迁移学习 → 迁移是知识复用，但负迁移是新的失效面）**
直觉：v23 的 FSVC 已经在做"云端骨干 + 边端 K-shot"的迁移，但它把迁移当成"总是有益的"：只要原型漂移受限、覆盖达标就上线。真实世界里迁移可能是**负迁移**——源域（云端/别的医院/别的工厂）的先验在目标域反而有害（例如云端在成人数据上训练的"人体先验"迁到儿科病房，会把儿童系统性地判成"背景"）。更本质地：迁移的"源→目标"适用关系本身需要一个**可审计的适用性证明**，而不是一个手工阈值。核心创新：**迁移证书 (Transferability Certificate, TLC)**——用域差异界（domain discrepancy bound）+ 任务相关度（ideal joint error）+ 目标域留出集的负迁移检验，给出"迁移后风险 ≤ ρ"的高概率上界；并区分**参数迁移**（骨干/原型）、**校准迁移**（conformal 分位数）、**规则迁移**（DCL 义务规则）三种粒度，分别有各自的适用条件。关键反直觉点：**"不迁移"不是失败，而是一个有明确语义的安全回退**——拒迁即退化为上下文局部（context-local）的保守先验，执行集只缩不扩。

**灵感 2（上下文理解 → 证书的意义依赖解释框架）**
直觉：v23 的证书是"无上下文"的——同一段传感器读数，在"仓库"和"儿科病房"里含义不同；同一个人站着不动，在"交接中"是等待接收，在"禁入区"是违规闯入；同一只手举起，在"交接"语境是"给我"，在"通行"语境是"停下"。证书若脱离上下文，就是**形式正确、事实错误**。核心创新：**上下文框架证书 (Context Frame Certificate, CXF)**：把上下文 κ（场景类型、角色配置、任务阶段、环境条件、时间相位）作为一等公民，用 conformal 得到上下文预测集 K_α(o)，并对所有下游证书采用 **∀κ ∈ K_α 的鲁棒语义**。关键反直觉点：**上下文识别的正确做法不是"先猜对再执行"，而是"对所有可能上下文都成立才执行"**——上下文猜错只会让执行集收缩，绝不会让危险被放行；而 K_α 的覆盖保证把"猜错"这件事本身也纳入了概率界。

**灵感 3（两者交汇 → 迁移只在某个上下文内才有意义）**
直觉：单看迁移，"这段知识能不能用"是伪问题；单看上下文，"这个上下文该用什么知识"也是伪问题。真正的对象是三元组 (知识, 源上下文, 目标上下文)。**迁移的适用域就是上下文的等价类**。核心创新：**上下文索引迁移 (Context-Indexed Transfer)**：规则库从"全局规则表"升级为"上下文索引规则库 (CIRL)"——一条义务规则 R 只有在"触发条件在 κ_s 与 κ_t 下逻辑等价"时才可迁移；手势意图从"全局 conformal 预测集 Γ"升级为"上下文条件预测集 Γ|κ"，并用上下文一致性消解"伸手 = 交接 vs 伸手 = 阻挡"的语用歧义。副产品：**上下文分层 conformal**（每个上下文单独校准）天然抵抗"混合漂移"（上下文比例变化）——这正是 v23 全局覆盖崩塌的解药。

**三者如何统一**
统一为 v23 之上的"**上下文-迁移层**"：CXF 回答"此刻可能处于哪些上下文"，TLC 回答"哪些知识可以跨上下文安全复用"，CIRL/CID 回答"在该上下文下规范与意图如何被正确解释"。共享状态 ζ_v23 扩展为 **ζ_v24 = ζ_v23 ∪ (K_α, κ̂, transfer_certs, CIRL_index, Γ|κ, phase)**。统一准入门：**HPC-X = HPC-E+ ∩ CXF ∩ TLC**——只有"v23 四证 ∧ 上下文鲁棒成立（∀κ∈K_α）∧ 所用迁移被证书化"才进入执行；任一缺失退回上下文局部知识，再退回 v23 的保守默认。核心定理方向：`Exec_v24 = Exec_v23 ∩ Fil_cx ∩ Fil_tl ⊆ Exec_v23`，且当 K_α = K（上下文完全不可辨）时 `Exec_v24 → ⋂_κ Exec_κ`（最保守，可空 → SafeStop）。

## 2. 设计原则（在 P37–P42 基础上新增 P43–P46）

**P43 上下文鲁棒律（Context-Robust Certification）**
所有下游证书谓词 P 在上下文集上取全称：`P^∀(o) ≜ ∀κ∈K_α(o): P_κ(o)`。仅当 `P^∀` 成立才签发证书。故 `P(安全) ≥ P(κ*∈K_α) ≥ 1-α`，且上下文误判只导致执行集收缩（K_α 越大，交集越小）。`K_α=K` 时退化为最保守全域交集 `⋂_κ P_κ`。

**P44 迁移可证伪律（Transfer Falsifiability）**
任何跨上下文知识复用 `K_s→K_t` 必须携带迁移证书 `TLC = (域差异上界, 任务相关度下界, 目标留出负迁移检验, 适用上下文对 (κ_s,κ_t))`。未证书化的迁移一律拒绝，退化为 context-local 先验。TLC 失效 ⇒ 执行集 ⊆ 不迁移时的执行集。

**P45 规则迁移等价律（Rule Transfer Equivalence）**
义务规则 R 可从 κ_s 迁到 κ_t 仅当 `Trigger(R)|κ_s ≡ Trigger(R)|κ_t`（触发条件在上下文约束下逻辑等价）且动作语义不变。禁止"部分迁移"（迁移触发但改写动作）——那会破坏 `Exec ⊆ v23`。规则迁移只允许整体搬移或整体拒绝。

**P46 上下文分层校准律（Context-Stratified Calibration）**
conformal 分位数按上下文分层：`q̂_α(·; D_calib, κ)`。细粒度上下文样本不足时，向父上下文做**收缩估计**（hierarchical shrinkage），并保留收缩的覆盖修正项。上下文比例漂移不改变层内条件覆盖（仅改变层间混合），故分层校准对 mixture shift 免疫；层内漂移由层内覆盖监控触发重校准。

## 3. 与基线的接口（如何退化）

- CXF 失效（上下文不可推断）⇒ `K_α=K` ⇒ 对所有上下文求交 ⇒ 最保守（可能 SafeStop）；
- TLC 失效（迁移不可证）⇒ 只用 context-local 知识 ⇒ 等价"不迁移"的 v23 子集；
- CIRL 失效（规则迁移判定失败）⇒ 只用本上下文原生规则 ⇒ 子集；
- CID 失效 ⇒ 意图回落 v21 全局非对称门槛（更保守，许可更难）⇒ 子集；
- CSCal 失效 ⇒ 用全局更宽分位数 ⇒ 覆盖更保守；
- 全部失效 ⇒ 完全回退 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`。
- **安全继承**：∀κ 只会取交（收缩）；迁移拒绝只会退化；分层校准只影响分位数宽度且失效时向更宽退化；OSCG 只在"开集未知"时把 K_α 强制为 K（最保守）。

## 4. 预期贡献

1. **上下文框架证书**：上下文集 conformal + ∀κ 鲁棒语义，把"上下文误判"从致命错误变成安全收缩；
2. **迁移证书**：域差异 / 任务相关度 / 负迁移检验三件套，三种迁移粒度分别可证伪，给出显式负迁移风险上界；
3. **上下文索引规则库**：规则迁移的逻辑等价判定（SMT 可判定片段），把义务逻辑从全局升级为上下文相对；
4. **上下文条件意图**：语用消歧 + 时间相位一致性，直接压低 v21 最危险的假许可；
5. **上下文分层校准**：对 mixture shift 免疫，封堵 v23 全局覆盖在混合漂移下的崩塌；
6. **HPC-X 五证一体**：HPC-E+ ∩ CXF ∩ TLC，`Exec_v24 ⊆ Exec_v23` 闭环。

## 5. 本轮最大风险

**一句话**：∀κ 鲁棒语义把安全性押在"K_α 覆盖真实上下文"上，若上下文编码器遭遇**训练中从未见过的上下文（open-set 上下文）**且错误地给出小 K_α（过度自信），则所有上下文条件证书会"在错误框架内一致地成立"——机器人会**可审计地、按错误规范地、安全地执行错误的事**（上下文错框幻觉 / contextual misframing）。

## 1. 关键算法骨架（在 IP-431–439 骨架上扩展）

```python
# ============================================================
# IP-440 Context Frame Certificate (CXF) — 上下文集 + ∀κ 鲁棒语义
# ============================================================
@dataclass
class ContextFrameCertificate:
    encoder: ContextEncoder            # g_ψ: o -> logits over K ∪ {⊥}
    calib: ContextCalibrator           # 上下文非一致性分数校准
    alpha_ctx: float = 0.01
    oscg: 'OpenSetContextGuard' = None

    def context_set(self, o) -> frozenset:
        """conformal 上下文集：包含所有分数不超过 (1-alpha) 分位数的上下文。"""
        scores = {k: self.encoder.score(o, k) for k in self.encoder.known_contexts}
        qhat = self.calib.quantile(self.alpha_ctx)
        Kset = frozenset(k for k, s in scores.items() if s <= qhat)
        # 开集护栏：若全部上下文都"不像"，强制 K_α = K（最保守），并注入 ⊥
        if self.oscg is not None and self.oscg.is_open_set(o, scores, qhat):
            return frozenset(self.encoder.known_contexts) | {BOTTOM}
        return Kset

    def robust(self, o, predicate: Callable[[object, object], bool]) -> bool:
        """P^∀(o) = forall k in K_α(o): P_k(o)。空集或含 ⊥ 一律拒绝。"""
        Kset = self.context_set(o)
        if not Kset or BOTTOM in Kset:
            return False
        return all(predicate(o, k) for k in Kset)

    def certify(self, o, predicates: dict) -> dict:
        Kset = self.context_set(o)
        if not Kset or BOTTOM in Kset:
            return {name: False for name in predicates}
        return {name: all(p(o, k) for k in Kset) for name, p in predicates.items()}


# ============================================================
# IP-441 Transferability Certificate (TLC) — 可证伪的迁移
# ============================================================
@dataclass
class TransferCert:
    rho: float                 # 目标风险上界
    kappa_s: object
    kappa_t: object
    granularity: str           # 'param' | 'calib' | 'rule'
    nt_passed: bool
    bound_valid: bool

class TransferabilityCertificate:
    def __init__(self, eps_max: float, delta: float = 1e-3):
        self.eps_max = eps_max
        self.delta = delta

    def domain_discrepancy(self, D_s, D_t, H) -> tuple[float, float]:
        """估计 d_HΔH：训练域判别器，返回 (经验值, 有限样本上界)。"""
        disc = train_domain_discriminator(D_s, D_t, H)
        emp = 2.0 * (1.0 - 2.0 * disc.error())
        n = min(len(D_s), len(D_t))
        slack = math.sqrt(math.log(2 / self.delta) / (2 * n))
        return emp, emp + slack

    def ideal_joint_error(self, D_s, D_t, H) -> tuple[float, float]:
        """估计 λ_κ：用联合训练的最优假设近似，给出保守上界。"""
        h_joint = train_joint(D_s, D_t, H)
        lam = risk(h_joint, D_s) + risk(h_joint, D_t)
        return lam, lam + math.sqrt(math.log(2 / self.delta) / (2 * min(len(D_s), len(D_t))))

    def negative_transfer_test(self, h_T, h_local, D_t_val) -> bool:
        """目标留出集配对检验：迁移模型不劣于局部基线（超过 margin 即拒绝）。"""
        if h_local is None:
            return True                      # 无局部基线时由绝对上界把关
        diff = [loss(h_T, x, y) - loss(h_local, x, y) for x, y in D_t_val]
        return paired_upper_bound(diff, self.delta) <= self.margin

    def certify(self, kappa_s, kappa_t, h_T, D_s, D_t, D_t_val,
                h_local=None, granularity="param") -> Optional[TransferCert]:
        eps_s = risk(h_T, D_s)
        _, d_hi = self.domain_discrepancy(D_s, D_t, H)
        _, lam_hi = self.ideal_joint_error(D_s, D_t, H)
        rho = eps_s + 0.5 * d_hi + lam_hi
        bound_valid = rho <= self.eps_max
        nt_passed = self.negative_transfer_test(h_T, h_local, D_t_val)
        if not (bound_valid and nt_passed):
            return None                      # 拒迁 -> context-local 保守回退
        return TransferCert(rho, kappa_s, kappa_t, granularity, nt_passed, bound_valid)


# ============================================================
# IP-442 Context-Indexed Rule Library (CIRL) — 规则迁移等价
# ============================================================
class ContextIndexedRuleLibrary:
    def __init__(self, solver):
        self.rules: dict = {}              # context -> list[Rule]
        self.solver = solver               # SMT solver（可判定片段）
        self.transfer_cache: dict = {}

    def trigger_equivalent(self, R, k_s, k_t) -> bool:
        """Trigger(R)|k_s ≡ Trigger(R)|k_t 的可满足性判定（双向蕴含有效）。"""
        f = Implies(And(R.trigger, Ctx(k_s)), And(R.trigger, Ctx(k_t)))
        g = Implies(And(R.trigger, Ctx(k_t)), And(R.trigger, Ctx(k_s)))
        return self.solver.is_valid(f) and self.solver.is_valid(g)

    def transfer(self, R, k_s, k_t) -> Optional[Rule]:
        """只允许整体搬移或整体拒绝；禁止改写动作（P45）。"""
        key = (id(R), k_s, k_t)
        if key in self.transfer_cache:
            return self.transfer_cache[key]
        ok = self.trigger_equivalent(R, k_s, k_t) and R.action_invariant()
        out = R.instantiate(k_t) if ok else None
        self.transfer_cache[key] = out
        return out

    def effective_rules(self, k, transfer_certs: dict) -> list:
        """本上下文原生规则 + 被 TLC 证书化且等价迁移进来的规则。"""
        native = list(self.rules.get(k, []))
        for (k_s, R, k_t), cert in transfer_certs.items():
            if k_t == k and cert is not None and cert.bound_valid:
                tr = self.transfer(R, k_s, k_t)
                if tr is not None:
                    native.append(tr)
        return native

    def compile(self, k, transfer_certs: dict) -> list:
        return [r.to_constraint() for r in self.effective_rules(k, transfer_certs)]


# ============================================================
# IP-443 Contextual Intent Disambiguator (CID) — 语用消歧 + 相位一致性
# ============================================================
class ContextualIntentDisambiguator:
    def __init__(self, intent_encoder, calibrators: dict, phase_model):
        self.enc = intent_encoder
        self.cal = calibrators             # context -> conformal calibrator
        self.phase = phase_model           # 半马尔可夫相位模型

    def intent_set(self, o, k) -> frozenset:
        """上下文条件 conformal 意图集 Γ|k。"""
        return self.cal[k].conformal_set(self.enc.score(o), alpha=self.cal[k].alpha)

    def phase_consistent(self, intent, phase, k) -> bool:
        return self.phase.allows(phase, intent, k)   # 只允许沿 →_Φ

    def robust_permission(self, o, intent, K_alpha, phase, modalities) -> bool:
        """高门槛许可：∀κ∈K_α 意图集为单例 {intent} ∧ 相位一致 ∧ 模态≥2。"""
        if len(modalities) < 2:
            return False
        for k in K_alpha:
            if self.intent_set(o, k) != frozenset({intent}):
                return False
            if not self.phase_consistent(intent, phase, k):
                return False
        return True

    def low_threshold_trigger(self, o, danger_intents, K_alpha) -> bool:
        """低门槛义务/急停：任一 κ 的 Γ|κ 命中危险意图即触发（fail-safe）。"""
        return any(self.intent_set(o, k) & danger_intents for k in K_alpha)


# ============================================================
# IP-444 Context-Stratified Calibrator (CSCal) — 分层 conformal
# ============================================================
class ContextStratifiedCalibrator:
    def __init__(self, alpha: float = 0.01, min_n: int = 30):
        self.alpha = alpha
        self.min_n = min_n
        self.D_calib: dict = {}            # context -> [(score, err)]
        self.parent: dict = {}             # 细粒度 -> 父上下文

    def update(self, k, score, err):
        self.D_calib.setdefault(k, []).append((score, err))
        if len(self.D_calib[k]) > 5000:
            self.D_calib[k].pop(0)

    def quantile(self, score, k) -> float:
        """样本充足用层内分位数；不足则向父上下文层级收缩（保留覆盖修正项）。"""
        if len(self.D_calib.get(k, [])) >= self.min_n:
            return empirical_quantile(self.D_calib[k], score, self.alpha)
        # 层级收缩：合并父上下文样本，收缩系数 n/(n+n0)
        chain = self._ancestors(k)
        pool = [e for c in chain for (_, e) in self.D_calib.get(c, [])]
        if not pool:
            return float('inf')            # 无数据 -> 最宽（最保守）
        n_k = len(self.D_calib.get(k, []))
        n0 = self.min_n
        w = n_k / (n_k + n0)
        return w * empirical_quantile(self.D_calib[k], score, self.alpha) + \
               (1 - w) * empirical_quantile(pool, score, self.alpha)

    def _ancestors(self, k):
        out, cur = [], k
        while cur in self.parent:
            cur = self.parent[cur]
            out.append(cur)
        return out

# IP-445 Open-Set Context Guard (OSCG) — 开集护栏
# ============================================================
class OpenSetContextGuard:
    def __init__(self, ood_detector, tau_ood: float = 0.5):
        self.ood = ood_detector
        self.tau_ood = tau_ood

    def is_open_set(self, o, scores, qhat) -> bool:
        """观测落在所有已知上下文之外（OOD）-> 强制最保守 K_α=K。"""
        if not scores:
            return True
        best = min(scores.values())
        return best > qhat and self.ood.score(o) > self.tau_ood

# IP-446 HPC-X 五证一体统一准入门
# ============================================================
@dataclass
class HPCX:
    hpc_e_plus: 'HPCEPlus'             # v23 四证（HPC-E + CESC + FSVC + IPAM）
    cxf: ContextFrameCertificate
    tlc: TransferabilityCertificate
    cirl: ContextIndexedRuleLibrary
    cid: ContextualIntentDisambiguator
    cscal: ContextStratifiedCalibrator

    def admits(self, plan, o, v, z, E_res, margin_req, modules, intent, phase, modalities) -> bool:
        Kset = self.cxf.context_set(o)
        if not Kset or BOTTOM in Kset:
            return False                       # 开集/空集 -> 拒绝（最保守）
        # 只需求值 K_α 的"最严上下文"（Pareto 前沿），其余上下文由支配关系保证
        for k in pareto_strictest(Kset):
            # (1) 迁移证书：该上下文所用知识必须被证书化
            if not self._knowledge_certified(k):
                return False
            # (2) v23 四证在该上下文下成立
            if not self.hpc_e_plus.admits(plan, o, v, z, E_res, margin_req,
                                          modules, context=k):
                return False
            # (3) 上下文条件意图许可（高门槛）
            if not self.cid.robust_permission(o, intent, Kset, phase, modalities):
                return False
        return True

    def _knowledge_certified(self, k) -> bool:
        return all(c is None or c.bound_valid for c in self._certs_for(k))


# ============================================================
# 端到端：上下文 -> 迁移 -> 分层校准 -> 五证准入
# ============================================================
class ContextTransferPipeline:
    def __init__(self, cfg):
        self.cxf = ContextFrameCertificate(cfg['ctx_encoder'], cfg['ctx_calib'],
                                           cfg['alpha_ctx'], cfg['oscg'])
        self.tlc = TransferabilityCertificate(cfg['eps_max'], cfg['delta'])
        self.cscal = ContextStratifiedCalibrator(cfg['alpha'], cfg['min_n'])
        self.cirl = ContextIndexedRuleLibrary(cfg['smt'])
        self.cid = ContextualIntentDisambiguator(cfg['intent_encoder'],
                                                 cfg['intent_calibs'], cfg['phase'])
        self.hpcx = HPCX(cfg['hpc_e_plus'], self.cxf, self.tlc,
                         self.cirl, self.cid, self.cscal)

    def step(self, o, sensors, intent, phase, modalities):
        Kset = self.cxf.context_set(o)
        # 上下文分层重校准（后台，非阻塞）
        for k in Kset:
            self.cscal.update(k, sensors['score'], sensors['err'])
        # 迁移证书按需签发（离线/异步），此处只查询
        admitted = self.hpcx.admits(sensors['plan'], o, sensors['v'], sensors['z'],
                                    sensors['E_res'], sensors['margin_req'],
                                    sensors['modules'], intent, phase, modalities)
        return admitted, {'K_alpha': Kset, 'phase': phase}
```

## 2. 复杂度分析

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| CXF 上下文集 | O(\|K\|·d) | O(\|K\|) | \|K\|≤20, d=256 |

## 3. 正确性论证

### 引理 1（上下文鲁棒可靠性）
**陈述**：若 `P^∀(o)` 成立且 `κ* ∈ K_α(o)`，则真实上下文下的 `P_{κ*}(o)` 成立；由 conformal 覆盖，`P(P_{κ*}(o) 成立) ≥ 1-α`。

**证明**：`P^∀(o) = ∀κ∈K_α(o): P_κ(o)` 直接蕴含 `P_{κ*}(o)`。再由 `P(κ* ∈ K_α(o)) ≥ 1-α`（conformal 覆盖）得 `P(P_{κ*}(o)) ≥ 1-α`。注意此结论**不依赖 κ 推断是否等于 κ\***——只要覆盖成立，即使 MAP 猜错也不影响安全性。∎

### 引理 2（迁移风险的高概率上界）
**陈述**：对迁移假设 h_T，以概率 ≥ 1-δ 有 `ε_t(h_T) ≤ ε_s(h_T) + ½ d_HΔH(D_s,D_t) + λ_κ + slack(δ)`。TLC 仅在 `ρ ≤ ε_max ∧ NT-test 通过` 时签发。

**证明**：由 Ben-David 等域适应界，`ε_t(h) ≤ ε_s(h) + ½ d_HΔH(D_s,D_t) + λ_κ` 对任意 h 成立。将 `ε_s(h_T)`（源标注可得）与 `d_HΔH`、`λ_κ` 的有限样本估计分别代入 Hoeffding/VC 型集中不等式，三项误差以 union bound 合并为 `slack(δ)`，即得高概率上界。TLC 的 `bound_valid` 检查该上界是否 ≤ ε_max，`NT-test` 额外用目标留出集排除"迁移劣于局部基线"的情形。两者皆过才签发。∎

### 引理 3（规则迁移不放大执行集）
**陈述**：若 `Trigger(R)|κ_s ≡ Trigger(R)|κ_t` 且动作不变，则把 R 从 κ_s 迁到 κ_t 后 `Exec` 不变；若拒迁，则 `Exec` 只可能收缩。故 `Exec_v24(规则层) ⊆ Exec_v23(规则层)`。

**证明**：触发条件在上下文约束下逻辑等价，意味着 R 在 κ_t 下触发的状态集合与在 κ_s 下完全相同，故诱导的约束集合相同，`Exec` 不变。拒迁时 κ_t 只保留原生规则，约束集合是原集合的子集，`Exec` 收缩。禁止改写动作排除了"迁移触发但放宽动作"导致执行集扩大的可能。∎

### 引理 4（上下文分层校准对混合漂移免疫）
**陈述**：若漂移仅改变上下文比例 `P(κ)` 而不改变层内条件分布 `P(err|κ)`，则对任意 κ，`q̂_α(·;D_calib,κ)` 不变，层内条件覆盖 `P(err ≤ q̂_α | κ) ≥ 1-α` 保持。

**证明**：分层分位数只依赖层内样本 `D_calib(κ)`，其分布仅由 `P(err|κ)` 决定；mixture shift 只改变层间权重，不改变层内经验分布，故分位数与层内覆盖不变。全局（不分层）分位数则会被比例变化拉偏——这正是 v23 全局覆盖崩塌的机制。∎

### 引理 5（上下文-迁移单调退化链）
**陈述**：任意单点/组合失效下，`Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ ... ⊆ Exec_v18` 恒成立。

**证明**：
- CXF 失效 ⇒ `K_α=K`（或含 ⊥）⇒ ∀κ 取全域交集，或直接拒绝 ⇒ 最保守；
- TLC 失效/拒迁 ⇒ 只用 context-local 规则与先验 ⇒ 引理 3 得子集；
- CID 失效 ⇒ 意图回落 v21 全局非对称门槛（许可更难）⇒ 子集；
- CSCal 失效 ⇒ 用更宽（全局）分位数 ⇒ 检测更保守 ⇒ 子集；
- OSCG 触发 ⇒ `K_α←K∪{⊥}` ⇒ 拒绝或最保守；
- 全失效 ⇒ 完全回退 v23。各层均只取交/收缩，单调性沿链传递。∎

### 定理（HPC-X 五证准入门的安全-规范-可迁移完备性）
**陈述**：对任意计划 π，`HPCX.admits(π)=True` 蕴含：以概率 ≥ 1-α，π 在真实上下文 κ* 下同时满足
(1) v23 物理-规范-负信息-能量安全（HPC-E+），
(2) 所用跨上下文知识已被迁移证书界定（`ε_t ≤ ε_max`），
(3) 上下文条件意图许可为单例且相位一致（假许可概率 ≤ α_intent）。

**证明**：`admits` 对 `κ∈K_α` 逐项检查 v23 四证、迁移证书与意图许可。由引理 1，真实 κ*∈K_α 时这些检查在 κ* 下成立；由引理 2，迁移知识的目标风险有高概率上界；由引理 3–4，规则与校准不放大执行集。三者在同一 (1-α) 事件上交，故结论成立。∎
