# 第 1 轮想法区 · 机器人 × 结构优化

## 1. 直觉：结构是所有证书里"看不见的常数项"

先看一个具体场景。一台机械臂为了减重被做了拓扑优化：连杆内部挖成晶格，壁厚从 4mm 减到 2.4mm，整机质量降了 18%。感知证书 SDC/CAC/DCSC 没变，云端版本 CESC 没变，专利标记 IPAttest 也没变，于是系统"看起来"全部通过。但 PGEV 里的能耗积分用的是旧的质量/惯量矩阵，ACSC 里的配空间障碍膨胀用的是旧的刚度假设，控制器的带宽也是按旧的一阶模态调的。减重之后惯量变了，一阶固有频率可能从 45Hz 抬到 70Hz，恰好撞上控制环的激励谐波；柔性增大了，末端在加减速时的弹性位移不再能被刚体模型吸收。

也就是说：**结构不是证书的一个输入，而是证书的"隐藏前提"（hidden premise）。** 现有证书都默认结构固定；一旦结构被优化，证书不会自动报错，而是继续签发——这正是最危险的地方：证书的失效是"静默"的。

一句话直觉：**结构优化改变的不是某个参数，而是证书赖以成立的那个"模型世界"本身。**

## 2. 从直觉到研究问题

现有 v23 的证书链（SDC/CAC/DCL/GIC/PGEV/ACSC/DCSC/CESC/FSVC/IPAM/HPC-E+）里，结构只以两种方式出现：

1. 作为 ACSC 的运动学/几何常量（连杆长度、关节限位、配空间障碍）；
2. 作为 PGEV 能量积分里的质量/惯量常数。

但"结构优化"恰恰是在改这些量，而且往往**先优化、后补证**，甚至**优化完忘了重证**。这不是工程疏忽，而是证书体系的结构性缺口：证书的语义是"在给定结构 S 下成立"，但没有任何机制把 S 绑定进证书，也没有机制约束"结构改动多大范围内证书仍然成立"。

于是本轮的问题不是"如何做拓扑优化"（成熟领域），而是：

> **能否把结构优化重新定义为一个"保证书变换"（certificate-preserving transformation），使得每一次结构迭代都可机械判定"旧证书是否仍然有效"，并在证书即将失效前强制重证或回滚？**

## 3. 关键洞察：结构设计空间里的"可信赖半径"

设结构状态 $S=(\rho,a,k,E,m)$（密度场、截面、关节刚度、材料模量、质量）。结构相关动力学映射

$$
D(S)=(M(q;S),\,C(q,\dot q;S),\,g(q;S),\,K(S),\,\omega_n(S),\,\zeta(S))
$$

给出惯量、科氏、重力、刚度、固有频率与阻尼比。把每张证书的"余量"写成一个标量 $m_i(S)\ge 0$：

- 能量余量 $m_E(S)$：PGEV 能耗预算的剩余；
- 刚度余量 $m_K(S)$：末端刚度超出任务要求的量；
- 共振余量 $m_R(S)$：固有频率与控制频带/激励谐波的最小间隔；
- 模型有效余量 $m_\Delta(S)$：真实动力学与证书所用模型的偏差还剩多少；
- 专利余量 $m_{IP}(S)$：结构特征是否仍被权利要求覆盖。

若每个 $m_i$ 在结构度量 $d_S$ 下局部 $L_i$-Lipschitz，则对扰动 $\Delta S$：

$$
m_i(S+\Delta S)\;\ge\; m_i(S)-L_i(S)\,\|\Delta S\|_S .
$$

所以只要

$$
\|\Delta S\|_S < r^*(S):=\min_i \frac{m_i(S)}{L_i(S)},
$$

就有 $SC(S+\Delta S)$ 成立。这就是本轮的"结构可信赖半径"：**在 $r^*(S)$ 以内，优化器可以放心走；一旦要跨出去，就必须停下来重证。** 这把"结构优化"和"证书"从两个割裂的流程，变成一个带安全带的迭代。

但这里有一条必须正面处理的裂缝：Lipschitz 常数只在**光滑**区域有效。拓扑优化里最要命的变化恰恰是不光滑的——密度趋零导致刚度矩阵奇异、特征值穿越导致模态交换、接触/摩擦引入非光滑。在穿越点附近 $L_i$ 可能无界，$r^*$ 会塌缩到 0。这不是 bug，而是一个**正确的信号**：它告诉系统"此处不能再靠局部界外推，必须全局重证"。所以方案里要显式加入"谱间隙守卫"：当模态间隔低于阈值或发生穿越时，强制 $r^*\to 0$ 并触发完整重证，而不是继续信任旧的 $L_i$。

## 4. 方案轮廓（对应产物区）

在 v23 外层加一个"结构层"，不替换原有四证：

1. **IP-440 SSC（结构状态证书）**：把 $S$ 与 $D(S)$ 纳入证书，定义 $SC(S)\triangleq\bigwedge_i m_i(S)\ge 0$。
2. **IP-441 SBC（结构灵敏度证书）**：用伴随/区间方法估 $L_i$，给出 $r^*(S)$ 与谱间隙守卫；越界即触发重证。
3. **IP-442 CSIC（控制—结构耦合证书）**：保证柔性模态不把能量"漏"进闭环（共振/溢出/失稳）。
4. **IP-443 SCEV（结构耦合能量证书）**：把 PGEV 的能量积分升级为结构相关（惯量、重力、弹性能、执行器损耗）。
5. **IP-444 CPTO（保证书拓扑优化器）**：带信赖域的 SIMP/水平集优化，每一步可证、越界即重证。
6. **IP-445 SVMC（结构版本迁移证书）**：把结构版本 $v_{\text{struct}}$ 并入 CESC 版本元组，结构切换原子化、可回滚。
7. **IP-446 SPA（结构专利认证）**：结构特征标记与安全变体（如换一种晶格）保持 $SC$。
8. **IP-447 CFC+S（结构化共识）**：跨机器人/跨模态的结构证书一致性仲裁。
9. **IP-448 HPC-E+S（统一结构准入门）**：$\mathrm{Exec}_{v24}=\mathrm{Exec}_{v23}\cap\mathrm{Fil}_{\text{struct}}\cap\mathrm{Fil}_{\text{sens}}\subseteq\mathrm{Exec}_{v23}$。

## 5. 与 v23 的关系

v24 不推翻 v23，而是把 v23 的"隐藏前提"显式化：v23 回答"在结构 $S$ 固定时计划是否安全"，v24 回答"当 $S$ 可以变化时，哪些变化仍使 v23 的结论成立，以及如何只在结论仍成立时改变 $S$"。形式上是外层交集，语义上是把"结构"从一个自由变量变成一个受证书约束的变量。

$$
\mathrm{Exec}_{v24}
=\mathrm{Exec}_{v23}\cap\{\pi:\ SC(S_\pi)\wedge SBC(S_\pi)\wedge CSIC(S_\pi)\wedge SCEV(S_\pi)\}
\subseteq\mathrm{Exec}_{v23}.
$$

## 6. 需要警惕的假设

- Lipschitz 界的**局部性**：它只在一个邻域内成立，不能跨模态穿越外推。
- 模态基截断（只取前 $r$ 阶）可能漏掉高频局部模态，晶格结构尤其危险。
- 结构优化目标（减重）与安全余量天然对抗，Pareto 前沿可能很窄。
- 结构专利变体的"功能等价"很难机械证明，容易退化成人工审核。

**本轮最大风险**：证书保真的核心依赖"局部 Lipschitz 界 + 谱间隙守卫"，但拓扑优化最关键的设计跃迁（密度趋零、模态穿越、接触非线性）恰好落在该界失效的非光滑区；若守卫阈值过松或 $L_i$ 被低估，优化器会在"已认证"的假象下跨过真正的失效边界，使结构优化与证书链在最需要保护的时刻失同步。

# ============================================================
# 公共数据结构
# ============================================================
@dataclass
class StructuralState:
    rho: np.ndarray              # 密度场 (N_e,)
    section: np.ndarray          # 连杆截面 (N_l,)
    joint_stiffness: np.ndarray  # 关节刚度 (N_j,)
    E_modulus: float
    mass: float
    version: int                 # v_struct

@dataclass
class Dynamics:
    M: np.ndarray                # 惯量矩阵
    C: np.ndarray                # 科氏/离心
    g: np.ndarray                # 重力项
    K: np.ndarray                # 结构刚度
    omega: np.ndarray            # 固有频率（升序）
    zeta: np.ndarray             # 阻尼比
    Phi: np.ndarray              # 模态振型

@dataclass
class Margins:
    m_energy: float
    m_stiffness: float
    m_resonance: float
    m_model: float
    m_patent: float

    def as_list(self):
        return [self.m_energy, self.m_stiffness,
                self.m_resonance, self.m_model, self.m_patent]

    def min_margin(self) -> float:
        return min(self.as_list())


# ============================================================
# IP-440 Structural State Certificate (SSC)
# ============================================================
class StructuralDynamics:
    """有限元 + 模态求解封装（可离线预计算、在线查表）。"""
    def __init__(self, fe_solver, modal_solver, r: int = 12):
        self.fe = fe_solver
        self.modal = modal_solver
        self.r = r

    def assemble(self, S: StructuralState) -> Dynamics:
        K = self.fe.stiffness(S.rho, S.section, S.E_modulus)
        M = self.fe.mass(S.rho, S.section)
        omega, zeta, Phi = self.modal.solve(K, M, r=self.r)
        return Dynamics(M=M, C=None, g=None, K=K,
                        omega=omega, zeta=zeta, Phi=Phi)


class StructuralStateCertificate:
    def __init__(self, dyn: StructuralDynamics, E_res: float,
                 omega_c: float, excitations: list[float],
                 delta_guard: float = 2.0, beta_model: float = 0.02):
        self.dyn = dyn
        self.E_res = E_res
        self.omega_c = omega_c
        self.excitations = excitations
        self.delta_guard = delta_guard
        self.beta_model = beta_model
        self._cache = {}          # version -> (Dynamics, Margins)

    # ---- 五项余量 ----
    def _energy_margin(self, S, D, q_traj, u_traj) -> float:
        # 结构相关能量：动能 + 重力势能 + 弹性能 + 执行器损耗
        E_hat = 0.0
        for q, qd, u in zip(q_traj["q"], q_traj["qd"], u_traj):
            kinetic = 0.5 * qd @ D.M @ qd
            elastic = 0.5 * q @ D.K @ q
            gravity = float(D.g @ q) if D.g is not None else 0.0
            E_hat += (kinetic + elastic + gravity + self._actuator_loss(u))
        return self.E_res - E_hat - self.beta_model

    def _stiffness_margin(self, S, D) -> float:
        # 末端刚度 = 关节刚度经雅可比映射；取任务要求方向上的最小富余
        K_task = self._task_stiffness(S, D)
        return float(np.min(K_task - self.K_required))

    def _resonance_margin(self, D) -> float:
        targets = np.array(self.excitations + [self.omega_c])
        gaps = [np.min(np.abs(D.omega - w)) for w in targets]
        return float(min(gaps)) - self.delta_guard

    def _model_margin(self, S, D) -> float:
        # 证书所用刚体模型与实际结构的偏差（惯量/刚度相对误差）
        return 1.0 - self._relative_model_error(S, D)

    def _patent_margin(self, S) -> float:
        return self._structural_ip_coverage(S)   # 由 SPA 提供 [0,1]

    def margins(self, S, q_traj=None, u_traj=None) -> Margins:
        D = self.dyn.assemble(S)
        return Margins(
            m_energy=self._energy_margin(S, D, q_traj, u_traj),
            m_stiffness=self._stiffness_margin(S, D),
            m_resonance=self._resonance_margin(D),
            m_model=self._model_margin(S, D),
            m_patent=self._patent_margin(S),
        )

    def certify(self, S, q_traj=None, u_traj=None) -> tuple[bool, Margins]:
        M = self.margins(S, q_traj, u_traj)
        return M.min_margin() >= 0.0, M

# IP-441 Structural Sensitivity Certificate (SBC)
# ============================================================
class StructuralSensitivityCertificate:
    def __init__(self, ssc: StructuralStateCertificate,
                 gap_min: float = 5.0, eta: float = 0.5,
                 r_min: float = 1e-3):
        self.ssc = ssc
        self.gap_min = gap_min
        self.eta = eta
        self.r_min = r_min

    def spectral_gap(self, D: Dynamics) -> float:
        if len(D.omega) < 2:
            return math.inf
        return float(np.min(np.diff(np.sort(D.omega))))

    def lipschitz(self, S, M: Margins, D: Dynamics) -> dict[str, float]:
        """各余量对结构设计变量的局部 Lipschitz 常数。

        光滑项（能量/刚度/共振）用伴随灵敏度 + 灵敏度过滤；
        模型项用区间/全局界，避免在非光滑处低估。
        """
        g_rho = self._adjoint_grad(S, D, targets=["energy", "stiffness"])
        L_E = float(np.linalg.norm(g_rho["energy"], ord=np.inf))
        L_K = float(np.linalg.norm(g_rho["stiffness"], ord=np.inf))
        L_R = self._eigenvalue_sensitivity_bound(D)      # dω_n/dS 的上界
        L_D = self._model_error_bound(S, D)              # 全局界，非局部线性化
        L_IP = self._ip_feature_sensitivity(S)
        return {"energy": L_E, "stiffness": L_K,
                "resonance": L_R, "model": L_D, "patent": L_IP}

    def trusted_radius(self, S, q_traj=None, u_traj=None):
        ok, M = self.ssc.certify(S, q_traj, u_traj)
        if not ok:
            return 0.0, {"reason": "not_certified", "margins": M}
        D = self.ssc.dyn.assemble(S)
        gap = self.spectral_gap(D)
        if gap < self.gap_min:
            # 谱间隙过小：局部界不可信，禁止外推，强制全局重证
            return 0.0, {"reason": "spectral_gap", "gap": gap,
                         "gap_min": self.gap_min}
        L = self.lipschitz(S, M, D)
        radii = {}
        for name, m in zip(["energy", "stiffness", "resonance",
                            "model", "patent"], M.as_list()):
            Li = L[name]
            radii[name] = math.inf if Li <= 1e-12 else m / Li
        r = min(radii.values())
        return r, {"radii": radii, "L": L, "gap": gap}

    def guard_ok(self, S) -> bool:
        D = self.ssc.dyn.assemble(S)
        return self.spectral_gap(D) >= self.gap_min

                 spillover_budget: float = 1e-3):
        self.omega_c = omega_c
        self.excitations = excitations
        self.delta_guard = delta_guard
        self.zeta_min = zeta_min
        self.spillover_budget = spillover_budget

    def resonance_margin(self, D: Dynamics) -> float:
        targets = np.array(self.excitations + [self.omega_c])
        return float(min(np.min(np.abs(D.omega - w)) for w in targets)) \
            - self.delta_guard

    def spillover_bound(self, D: Dynamics, Bf, Cf, u_max: float) -> float:
        """被截断高频模态的残余能量上界（保守二阶界）。"""
        bound = 0.0
        for wn, z in zip(D.omega, D.zeta):
            if z <= 0:
                return math.inf
            bound += (np.linalg.norm(Bf) * np.linalg.norm(Cf)
                      / (4.0 * z * wn)) * u_max ** 2
        return bound

    def certify(self, D: Dynamics, Bf, Cf, u_max: float,
                controller_passive: bool) -> tuple[bool, dict]:
        m_res = self.resonance_margin(D)
        z_ok = bool(np.all(D.zeta >= self.zeta_min))
        spill = self.spillover_bound(D, Bf, Cf, u_max)
        spill_ok = spill <= self.spillover_budget
        passive_ok = controller_passive
        info = {"m_resonance": m_res, "zeta_ok": z_ok,
                "spillover": spill, "spillover_ok": spill_ok,
                "passive_ok": passive_ok}
        return (m_res >= 0.0 and z_ok and spill_ok and passive_ok), info

# IP-443 Structure-Coupled Energy Viability (SCEV)
# ============================================================
class StructureCoupledEnergyViability:
    def __init__(self, E_res: float, beta_model: float = 0.02):
        self.E_res = E_res
        self.beta_model = beta_model

    def energy_integral(self, D: Dynamics, q_traj, qd_traj, u_traj) -> float:
        E = 0.0
        for q, qd, u in zip(q_traj, qd_traj, u_traj):
            kinetic = 0.5 * qd @ D.M @ qd
            elastic = 0.5 * q @ D.K @ q
            gravity = float(D.g @ q) if D.g is not None else 0.0
            E += kinetic + elastic + gravity + self._actuator_loss(u)
        return E

    def certify(self, D, q_traj, qd_traj, u_traj) -> tuple[bool, float]:
        E_hat = self.energy_integral(D, q_traj, qd_traj, u_traj)
        m_E = self.E_res - E_hat - self.beta_model
        return m_E >= 0.0, m_E

# IP-444 Certificate-Preserving Topology Optimizer (CPTO)
# ============================================================
class CertificatePreservingTopologyOptimizer:
    def __init__(self, ssc, sbc, csic, scev,
                 eta: float = 0.5, r_min: float = 1e-3, max_iter: int = 100):
        self.ssc, self.sbc = ssc, sbc
        self.csic, self.scev = csic, scev
        self.eta = eta
        self.r_min = r_min
        self.max_iter = max_iter

    def optimize(self, S0, objective, q_traj, u_traj, Bf, Cf, u_max,
                 controller_passive=True):
        S = copy.deepcopy(S0)
        history = []
        for k in range(self.max_iter):
            r, info = self.sbc.trusted_radius(S, q_traj, u_traj)
            if r <= self.r_min:
                # 局部界失效：停止外推，做一次完整重证
                ok, M = self.ssc.certify(S, q_traj, u_traj)
                if not ok:
                    history.append({"iter": k, "event": "recert_fail"})
                    break
                r = self.r_min          # 极小步长 + 下一步重新估界
            g = objective.gradient(S)   # 含约束的投影梯度
            dS = self._project(g, S)
            step = min(self.eta * r, np.linalg.norm(dS))
            if np.linalg.norm(dS) > 1e-12:
                dS = dS / np.linalg.norm(dS) * step
            S_new = self._apply(S, dS)

            ok_s, M_new = self.ssc.certify(S_new, q_traj, u_traj)
            D_new = self.ssc.dyn.assemble(S_new)
            ok_c, info_c = self.csic.certify(D_new, Bf, Cf, u_max,
                                             controller_passive)
            ok_e, m_E = self.scev.certify(D_new, q_traj["q"], q_traj["qd"],
                                          u_traj)
            if ok_s and ok_c and ok_e:
                S = S_new
                history.append({"iter": k, "r": r, "margin": M_new.min_margin(),
                                "csic": info_c, "m_E": m_E, "accepted": True})
            else:
                history.append({"iter": k, "r": r, "accepted": False,
                                "reason": self._reject_reason(ok_s, ok_c, ok_e)})
                # 拒绝后收缩：等价于把 r 减半再试（下一轮自然更小）
                self._shrink = True
        return S, history

    def _reject_reason(self, ok_s, ok_c, ok_e):
        return ("structural" if not ok_s else
                "csi" if not ok_c else "energy")

# IP-445 Structural Version Migration Certificate (SVMC)
# ============================================================
class StructuralVersionMigrationCertificate:
    def __init__(self, ssc, sbc, csic, scev, spa):
        self.ssc, self.sbc = ssc, sbc
        self.csic, self.scev = csic, scev
        self.spa = spa
        self.active: StructuralState = None
        self.pending: StructuralState = None

    def predicate(self, V, S: StructuralState) -> bool:
        # v_struct 必须与动力学/证书消费方一致，且专利版本覆盖结构特征
        if V is None or S is None:
            return False
        if V.v_struct != S.version:
            return False
        if V.v_patent < S.version:
            return False
        return True

    def stage(self, S_new: StructuralState, q_traj, u_traj,
              Bf, Cf, u_max, controller_passive=True) -> bool:
        ok_s, M = self.ssc.certify(S_new, q_traj, u_traj)
        if not ok_s:
            return False
        D = self.ssc.dyn.assemble(S_new)
        ok_c, _ = self.csic.certify(D, Bf, Cf, u_max, controller_passive)
        ok_e, _ = self.scev.certify(D, q_traj["q"], q_traj["qd"], u_traj)
        ok_ip = self.spa.verify(S_new, modules=["structure"])
        if not (ok_c and ok_e and ok_ip):
            return False
        self.pending = S_new
        return True

    def commit(self) -> bool:
        if self.pending is None:
            return False
        self.active = self.pending
        self.pending = None
        return True

    def rollback(self):
        # pending 丢弃，active 不变，证书链连续
        self.pending = None

# IP-446 Structural Patent Attestation (SPA)
# ============================================================
class StructuralPatentAttestation:
    def __init__(self):
        self.feature_map = {}   # ip_tag -> {structural_feature}
        self.safe_variants = {}

    def register(self, ip_tag: str, features: set[str]):
        self.feature_map[ip_tag] = set(features)

    def coverage(self, S: StructuralState) -> float:
        feats = self._extract_features(S)      # 晶格类型/桁架拓扑/刚度剖面
        covered = 0
        for ip, req in self.feature_map.items():
            if req <= feats:
                covered += 1
        return covered / max(len(self.feature_map), 1)

    def safe_variant(self, risky_ip: str, S: StructuralState):
        """返回功能等价、实现不同的结构变体；必须由 CPTO 重新通过 SC。"""
        variant_fn = self.safe_variants.get(risky_ip)
        return variant_fn(S) if variant_fn else None

    def verify(self, S, modules) -> bool:
        if "structure" not in modules:
            return True
        return self.coverage(S) >= 1.0

# IP-448 HPC-E+S：统一结构准入门
# ============================================================
@dataclass
class HPCEPlusS:
    hpc_e_plus: HPCEPlus
    ssc: StructuralStateCertificate
    sbc: StructuralSensitivityCertificate
    csic: ControlStructureInteractionCertificate
    scev: StructureCoupledEnergyViability
    svmc: StructuralVersionMigrationCertificate
    spa: StructuralPatentAttestation

    def admits(self, plan, S, V, q_traj, u_traj, Bf, Cf, u_max,
               modules, controller_passive=True) -> tuple[bool, dict]:
        # 1. v23 四证（含云边/少样本/IP）
        if not self.hpc_e_plus.admits(plan, *self._v23_args(plan)):
            return False, {"reason": "hpc_e_plus"}
        # 2. 结构版本一致性
        if not self.svmc.predicate(V, S):
            return False, {"reason": "svmc_version"}
        # 3. 结构状态证书
        ok_s, M = self.ssc.certify(S, q_traj, u_traj)
        if not ok_s:
            return False, {"reason": "ssc", "margins": M}
        # 4. 灵敏度守卫：不接受 r*=0 的结构（局部界不可信）
        r, info = self.sbc.trusted_radius(S, q_traj, u_traj)
        if r <= 0.0:
            return False, {"reason": "sbc", **info}
        # 5. 控制—结构耦合
        D = self.ssc.dyn.assemble(S)
        ok_c, info_c = self.csic.certify(D, Bf, Cf, u_max, controller_passive)
        if not ok_c:
            return False, {"reason": "csic", **info_c}
        # 6. 结构耦合能量
        ok_e, m_E = self.scev.certify(D, q_traj["q"], q_traj["qd"], u_traj)
        if not ok_e:
            return False, {"reason": "scev", "m_E": m_E}
        # 7. 结构专利
        if not self.spa.verify(S, modules):
            return False, {"reason": "spa"}
        return True, {"margins": M, "r_star": r,
                      "csic": info_c, "m_E": m_E}

# 端到端：结构层流水线（在 v23 基础上加结构门）
# ============================================================
class StructuralCertificatePipeline:
    def __init__(self, v23_pipeline, cfg):
        self.p23 = v23_pipeline
        self.dyn = StructuralDynamics(cfg["fe"], cfg["modal"], cfg["r"])
        self.ssc = StructuralStateCertificate(
            self.dyn, cfg["E_res"], cfg["omega_c"], cfg["excitations"])

        self.csic = ControlStructureInteractionCertificate(
            cfg["omega_c"], cfg["excitations"])

        self.spa = StructuralPatentAttestation()
        self.svmc = StructuralVersionMigrationCertificate(
            self.ssc, self.sbc, self.csic, self.scev, self.spa)
        self.gate = HPCEPlusS(self.p23.hpc_e_plus, self.ssc, self.sbc,
                              self.csic, self.scev, self.svmc, self.spa)
        self.S_active = cfg["S0"]
        self.svmc.active = self.S_active

    def step(self, sensor, structural_update=None):
        # 1. 结构更新（低频、设计期/换构型时）：影子槽重证 + 原子提交
        if structural_update is not None:
            staged = self.svmc.stage(
                structural_update["S"], sensor["q_traj"], sensor["u_traj"],
                sensor["Bf"], sensor["Cf"], sensor["u_max"],
                sensor["controller_passive"])
            if staged and self.svmc.commit():
                self.S_active = self.svmc.active
            else:
                self.svmc.rollback()      # 失败继续用旧结构，执行集单调

        # 2. v23 感知 + 四证
        admitted23, info = self.p23.step(sensor)

            info["plan"], self.S_active, info["version"],
            sensor["q_traj"], sensor["u_traj"],
            sensor["Bf"], sensor["Cf"], sensor["u_max"],
            modules=info["modules"], controller_passive=sensor["controller_passive"])

        admitted = admitted23 and admitted_s
        return admitted, {
            "plan": info["plan"] if admitted else None,
            "v23": info,
            "structural": s_info,
            "v_struct": self.S_active.version,
        }

## 3. 正确性论证

### 引理 1（证书保持信赖域）
**陈述**：设 $SC(S_k)$ 成立，且单步满足 $\|\Delta S\|_S<r^*(S_k)=\min_i m_i(S_k)/L_i(S_k)$，则 $SC(S_k+\Delta S)$ 成立。

**证明**：对每个余量，由局部 Lipschitz 性
$$m_i(S_k+\Delta S)\ge m_i(S_k)-L_i(S_k)\|\Delta S\|_S>m_i(S_k)-m_i(S_k)=0.$$
五项均严格大于 0，故 $\bigwedge_i m_i\ge0$ 成立。∎

**推论**：CPTO 取步长 $\|\Delta S\|_S\le\eta\,r^*(S_k)$（$\eta<1$）时，每一步迭代都保持 $SC$，无需每步做全局重证。

### 引理 2（谱间隙守卫阻止盲目穿越）
**陈述**：若 $\mathrm{gap}(S_k)<g_{\min}$，则 SBC 令 $r^*(S_k)=0$，CPTO 不接受任何有限步，改为全局重证或拒绝。因此优化器不会在模态穿越处用旧的 $L_i$ 外推。

**证明**：模态穿越意味着 $\omega_n(S)$ 非光滑、$\partial\omega_n/\partial S$ 无界，局部 Lipschitz 常数不存在。SBC 在 `trusted_radius` 中先检查 `spectral_gap`，低于阈值直接返回 0，使任何 $\|\Delta S\|>0$ 都无法满足引理 1 的前提。CPTO 的 `r<=r_min` 分支因此触发完整重证而非局部步进。∎

### 引理 3（控制—结构耦合不放大能量）
**陈述**：若 CSIC 通过，即 $m_R\ge0$、$\zeta\ge\zeta_{\min}$、$\Pi_{\text{spill}}\le\Pi_{\text{budget}}$、控制器无源，则闭环在柔性模态上的注入能量有界，不会因 spillover 失稳。

**证明**：$m_R\ge0$ 保证固有频率与控制带宽/激励谐波保持 $\Delta_{\text{guard}}$ 间隔，避免主共振；$\zeta\ge\zeta_{\min}>0$ 使每个模态耗散；截断高频模态的残余能量由二阶界 $\Pi_{\text{spill}}=\sum_n \|B_f\|\|C_f\|/(4\zeta_n\omega_n)\cdot u_{\max}^2$ 控制，$\Pi_{\text{spill}}\le\Pi_{\text{budget}}$ 保证未建模模态不会吸收超过预算的能量；控制器无源则闭环总能量不增。四者合起来给出柔性模态能量上界。∎

### 引理 4（结构耦合能量可靠性）
**陈述**：若 SCEV 通过（$m_E\ge0$），则计划在真实结构 $S$ 下的能耗不超过 $E_{\text{res}}$，扣除模型误差 $\beta_{\text{model}}$ 后仍成立。

**证明**：SCEV 用结构相关 $D(S)$ 计算动能 $\tfrac12\dot q^\top M(S)\dot q$、弹性能 $\tfrac12q^\top K(S)q$、重力势能 $g(q;S)^\top q$ 与执行器损耗，较 v23 的常质量积分更接近真实。$m_E=E_{\text{res}}-\hat E-\beta_{\text{model}}\ge0$ 即 $\hat E+\beta_{\text{model}}\le E_{\text{res}}$；$\beta_{\text{model}}$ 吸收未建模项，故真实能耗在预算内。∎

### 引理 5（结构迁移单调性）
**陈述**：SVMC 仅在影子槽完成 SSC/CSIC/SCEV/SPA 全部重证后原子提交；失败回滚到旧结构。因此 $\mathrm{Exec}_{v24}$ 在结构切换前后单调不增。

**证明**：提交条件为四项重证全过，等价于新结构满足 $SC\wedge CSIC\wedge SCEV\wedge SPA$；失败时 `active` 不变，仅丢弃 `pending`，旧证书继续有效。执行集只在新结构也通过全部过滤器时才可能保留，否则收缩，故单调。∎

### 定理（结构共设计可靠性）
**陈述**：若 CPTO 输出 $S^*$ 且 $\mathrm{HPCEPlusS.admits}$ 对计划 $\pi$ 返回真，则：(1) $\pi$ 在真实结构 $S^*$ 下满足 v23 的全部安全/合规/专利条件；(2) $\pi$ 的能耗、刚度、共振与控制—结构耦合均在证书界内；(3) CPTO 迭代过程中所有被接受的中间结构 $S_k$ 均可证；(4) 任何结构切换失败都不会放宽执行集。

**证明**：(1) 由 `admits` 第一项调用 v23 的 HPC-E+，直接继承其定理；(2)(3) 由引理 1（每步保持 $SC$）、引理 3（CSIC）、引理 4（SCEV）与 SSC 五项余量非负给出；(4) 由引理 5 给出。综合即得。∎

| R3 | 结构目标（减重）与安全余量天然对抗，Pareto 前沿窄甚至为空 | 高 | 1) 多目标 CPTO 输出 Pareto 集而非单点；2) 余量下限 $\varepsilon_m>0$ 而非 0；3) 允许放宽非关键余量换取关键余量 | 极端轻量化需求下可能无可行结构，任务不可达 |
| R4 | 结构专利变体"功能等价"难机械证明，退化为人工审核 | 中 | 1) 变体必须重新过 CPTO 的 $SC$ 与性能界；2) 特征标签与权利要求双向映射；3) 变体差异自动 diff + 人工签核 | 等价性证明依赖领域专家，难以规模化 |
| R5 | 结构切换与云边版本切换叠加，出现"结构—模型"双版本错配 | 中 | 1) $v_{\text{struct}}$ 并入 CESC 六元组强制同代；2) SVMC 与 CESC 共用影子槽协议；3) 任一版本不一致即拒证 | 双切换窗口重叠时，回滚顺序需严格定序，否则可能短暂错配 |

## 5. 实验设计（验证指标）

| 指标 | 基线 (v23) | 目标 (v24) | 测试协议 |
|---|---|---|---|
| 结构优化后证书静默失效检出率 | 未检测（假安全） | 100% 检出 | 对同一机械臂做 20 组拓扑优化，逐组对比 v23 与 v24 的准入结果 |
| 减重 vs 安全余量 Pareto 前沿 | N/A | 减重 15% 时最小余量仍 $\ge0$ | CPTO 在 5 个任务刚度/能耗约束下扫描，画前沿 |
| 证书保持信赖域有效性 | N/A | 被接受迭代中 0 次 $SC$ 违反 | 记录每步真实 $SC$（全阶 FE）与预测 $SC$ 的一致性 |
| 谱间隙守卫召回率 | N/A | ≥95% | 构造 50 组模态穿越/近穿越结构，检验守卫是否触发 |
| CSIC 溢出预测误差 | N/A | 上界不低真实值 | 与全阶时域仿真对比柔性模态能量 |

**关键对照实验**：同一减重目标下比较（a）v23 + 优化后不重证、（b）v23 + 优化后人工重证一次、（c）v24 CPTO 带信赖域。预期 (a) 在减重 >10% 后出现证书失效但系统仍放行（假安全），(b) 在迭代中途失效且无法定位，(c) 全程可证但减重上限略低——用来量化"结构自由度"与"可证安全"的交换比。

## 6. 本轮最大风险（最终确认）

**一句话**：证书保真的核心依赖"局部 Lipschitz 界 + 谱间隙守卫"，但拓扑优化最关键的设计跃迁（密度趋零、模态穿越、接触非线性）恰好落在该界失效的非光滑区；若守卫阈值过松或 $L_i$ 被低估，优化器会在"已认证"的假象下跨过真正的失效边界，使结构优化与证书链在最需要保护的时刻失同步。
