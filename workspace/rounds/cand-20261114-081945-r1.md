# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「安全性」×「机械臂抓取」）

> R69 让系统学会了「不确定就问」：把 epistemic 歧义交给注视/探针/问句去消解，并给信息动作也套上 C-RAS-WM 认证，保证物理风险 ≤ ε_int。但这个保证只在一个前提下成立——**信息动作可以既安全又有用**。机械臂抓取把这个前提撕开了：要判断摩擦力，你得蹭一下；要判断软硬，你得捏一下；要判断是否抓牢，你得提一下。**最值钱的信息，恰好由最危险的动作给出**；而且抓取的「安全」根本不是 R68 那个「越慢越紧越安全」的单侧标量——捏太轻会滑脱，捏太重会捏碎，安全是一个**双侧区间**，把 λ 收紧到 0 反而制造了新危险（松手掉物）。
>
> 更深的问题：R68/R69 的安全证书都是**光滑轨迹上**的前缀认证（Lipschitz、WM 前缀），而抓取的安全事件几乎全部发生在**接触切换的瞬间**——首次撞击的冲量、闭合时的力跃变、抬起时的滑移。这是一个**混合跳变**，连续证书管不到它。
>
> 核心命题：**抓取安全不是把风险标量收紧，而是一个「不可逆性排序」问题：接触模式是分级的，可逆探针必须先于不可逆承诺，安全退缩的目标是安全集的 Chebyshev 中心而不是原点；只有当可逆信息穷尽、且待消歧量是「决策关键」时，才允许花不可逆预算。** 命名 **FIRM-RAS**（Friction/Irreversibility/Regime/Margin-aware Risk-Adaptive Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这一下能不能收回来**」——安全不是把动作调小，而是知道哪些门只能单向穿过。

## 0. 直觉与动机

**灵感 1（安全是区间，不是标量 → R68 的 λ_floor 在接触处是类别错误）**
直觉：自由空间里，动能 ∝ v²，慢一点确实更安全，所以「不确定 → 收紧」是对的。但抓取的安全约束长这样：f_min(μ) ≤ f_grip ≤ f_max(κ)。低于 f_min 滑脱，高于 f_max 压碎。把动作幅度缩到 0 等于 f_grip=0，直接滑落。**λ→0 在接触任务里不是最保守，而是最危险之一**。正确的保守不是「缩向零」，而是「缩向安全集的中心」——一个 maximin/Chebyshev 点。

**灵感 2（危险在模式切换的冲量，不在轨迹）**
直觉：一条经过认证的光滑接近轨迹可以是处处 Lipschitz 安全的，但第一次接触时法向速度 v_n 决定冲量 J≈(1+e)m_eff v_n；J 超标就压碎/撞伤人。R68 的证书只有位置/速度界，没有冲量界，也没有「接触检测延迟」这一项。抓取必须把安全从「连续轨迹约束」升级为「混合自动机上的逐模式不变式 + 跳变守卫」。

**灵感 3（探针即危险 → R69 的 VoI 在接触处失明）**
直觉：R69 把「看/问/触」都当作带认证的信息动作，隐含假设是「信息动作可以做得足够轻」。但摩擦/刚度/握持可靠性这些量，信噪比正比于探测力；探测力越大信息越多、越接近损伤。**信息与可逆性反相关**。因此不能再用 VoI−成本 的一次标量权衡，因为在安全临界处，多花一点「成本」就是跨过不可逆红线。

**灵感 4（不可逆让迟到的信息一文不值 → 需要词典序而非加权和）**
直觉：一旦捏碎，再多的后验更新都没有意义。R69 的 VoI 假设「先学后做」，但不可逆动作是「边做边学、且学到的不能反悔」。所以时序上必须**先消歧后承诺**：只要还有可逆探针能降低决策关键不确定性，就不许执行不可逆动作。这是一个**优先级/词典序约束**（先最小化不可逆秩，再最大化信息），不能塞进一个加权标量里被「成本」抵消。

**灵感 5（严格泛化姿态 → R70 必须把 FLUID/R68 收为边界情形）**
直觉：当所有探针都可逆（ρ≡0）、且安全集退化为单侧（f_min=0）时，词典序 (ρ, −VoI) 退化为 R69 的 argmax(VoI−c)，Chebyshev 退缩退化为 λ_floor。于是 R69、R68 都是 FIRM 的边界。安全侧只增不减（多了冲量界与双侧力夹逼），效率侧保留消歧收益（可逆前沿）。

**灵感 6（安全要可证伪 → 证书必须包含「撤销契约」）**
直觉：不可逆秩是模型给的，可能错。所以证书不能只写「我保证安全」，还要写「我承诺这个动作在预算内可撤销，撤销策略是 π_r，证据是这些力/位读数」。一旦实测冲量或力进入违例区，证书当场失效并回退——把安全从「事后审计」变成「在线可证伪」。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（FIRM-RAS 总览）** FIRM-RAS = (CMM, IGL, RPF, CRIT, HSG, SCA, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **不可逆性优先（词典序）**：设当前承诺秩 ρ_cur，则任何 ρ>ρ_cur 的动作，只有在「可逆探针前沿 RPF 中不存在能改变安全类别的探针」时才允许；
(iii) **双侧接触安全**：对每个安全相关量（夹持力、关节力矩、法向冲击），都必须落在区间 [lo, hi] 内；不确定性增大时目标点缩向该区间的 Chebyshev 中心，而非原点。

**定义 311（接触模式混合自动机 CMM）** 模式集 Q={Free, Approach, Impact, Close, Lift, Hold, Slip, Withdraw}；连续状态 x=(q_pose, qdot, w)（位形、速度、六维力/力矩）。转移 q→q' 由守卫 g_{q→q'}(x) 触发（接触检测、力阈值、速度阈值）。每个模式有安全不变式 I_q ⊂ 𝒳。安全事件发生在跳变边 E 上，连续证书在 E 上失效。

**定义 312（冲量界与速度帽）** 有效质量 m_eff、恢复系数 e∈[0,1]、法向接近速度 v_n。冲击冲量 J=(1+e)m_eff v_n。给定物体/人体脆弱阈值 J_max，得 v_n ≤ J_max/((1+e)m_eff)。考虑接触检测延迟 τ_c 与控制周期，取保守帽 v_n ≤ (J_max − K_τ τ_c)/((1+e)m_eff)。这是**接近阶段的硬约束**，独立于 λ，也不能被 λ 的「宽松」抵消。

**定义 313（双侧抓取安全集）** 夹持力 f_g 需满足 f_g ≥ f_min(μ)（防滑，由摩擦锥与负载 mg 给出）且 f_g ≤ f_max(κ)（防碎，由材料强度/柔顺性给出）。安全集 𝒮(θ) = {f_g : f_min(μ) ≤ f_g ≤ f_max(κ)}，θ=(μ,κ)。当 μ、κ 不确定时，鲁棒安全集 𝒮_rob = ∩_{θ∈Θ} 𝒮(θ)；若为空 ⇒ 不可鲁棒保证，必须探针或退避。

**定义 314（不可逆性秩 ρ）** 动作 a 是 (ε,B)-可逆的，若存在恢复策略 π_r 使从 a 之后的安全相关状态恢复到 a 之前的状态，且代价（力/时间/位移/损伤）≤B、残余偏差 ≤ε。定义 ρ(a)=最小的此类 B（离散化到 {0,1,2,3}：0 自由运动/注视/安全阈内轻触；1 闭合再张开、抬起再放下；2 带滑移的在手调整；3 压碎、跌落、撞人）。ρ 关于探测力/位移单调不降。

**定义 315（不可逆性账本 IGL）** Episode 预算 B_irr、最小可分辨秩 ρ_min。账本 L_t 单调不减：执行 a 后 L←L+ρ(a)。约束 L≤B_irr；耗尽后系统只允许 ρ=0 动作（安全冻结于可逆子空间）。

**定义 316（可逆探针前沿 RPF）** 𝒢_rev(o)={g∈𝒜_info : ρ(g)=0 ∧ HSG 认证通过 ∧ 预算允许}。可逆探针示例：多视角注视、低力安全阈内轻触（f≤f_max−m_safe）、关节力矩探询、等待稳定。规则 (定义 310-ii) 用 RPF 的**非空与决策关键性**决定是否可越过 ρ=0。

**定义 317（决策关键性 CRIT）** 未知量 θ 对当前决策是 δ-关键的，若其可信区间跨越了「会改变所选动作安全类别或承诺秩」的边界，即 dist(Θ̂, ∂𝒮) ≤ δ，或 argmax_a 的安全秩在 Θ̂ 内不恒定。只有关键未知才值得花不可逆预算；非关键的好奇心一律不许花。

**定义 318（安全信息增益 Safe-VoI 与词典序选择）** 对候选 g：
SafeVoI(g) = I(θ_crit; y_g | o)（只算关键分量的信息），约束 ρ(g)≤ρ_allowed、HSG 通过、J≤J_max、L+ρ(g)≤B_irr。
选择规则（词典序）：
1) 若存在 g∈𝒢_rev 且 SafeVoI(g)>δ_info → 取 argmax SafeVoI；
2) 否则，若关键未知仍存在且 ∃ 不可逆 g（最小 ρ）使 SafeVoI>δ_irr → 取该最小 ρ 的 g；
3) 否则不交互，执行 maximin 退缩（定义 321）。
即**先最小秩，再最大信息**，绝不把安全折成成本。

**定义 319（混合安全盾 HSG）** 在每个模式 q 上检查 I_q；在跳变边检查冲量界与恢复可行性；对信息动作同样适用（接触探针不得越 f_max−m_safe、不得诱发危险转身）。任一不通过 ⇒ 该动作在**本模式**作废（不是全局作废），并标记该边的安全秩。

**定义 320（接触-力证书 J_FIRM）** J_FIRM=(J_FLUID, mode_trace_hash, impulse_p95, margins=(J_max−J, f_g−f_min, f_max−f_g), ledger_before/after, RPF_nonempty_proof, contact_model_ver)。Valid ⇔ Valid(J_FLUID) ∧ 全程守卫未破 ∧ 冲量与力裕度 >0 ∧ 账本未超支。

**定义 321（Chebyshev 安全退缩 SCA）** 参数估计 Θ̂ 下，目标动作 a* = argmax_a min_{θ∈Θ̂} margin(a,θ)，margin 为到 𝒮(θ) 边界的最小归一化距离。对自由空间单侧集 𝒮={|a|≤A}，其中心为 0，SCA 退化为 λ_floor·0；对抓取区间，中心是 (f_min+f_max)/2 附近。**这就是「收紧」的正确方向：收向中心，不是收向零。**

**定义 322（安全-信息反相关定律）** 对同一模态的探测强度 u，在 A99（信噪比随力单调升、损伤随力单调降可逆性）下：∂I(θ;y|u)/∂u ≥ 0 且 ∂ρ(u)/∂u ≥ 0。故 (ρ, I) 的可行前沿在 ρ 的边界上取到最大信息；不存在「既高可逆又高信息」的同模态探针。

**定义 323（接触似然异常 FMA-C）** 在 R69 的轨迹似然之外，增加**接触一致性残差**：预测力/位轨迹与实际力的残差、以及模式序列的跳变残差（例如预测 Hold 但检测到 Slip）。a_contact = −log p_θ(w_{t:t+H}, q_{t:t+H} | o_t, mode)。用于发现摩擦/刚度模型失配。

**定义 324（不可逆审计与升级）** 当关键未知存在、可逆前沿穷尽、且不可逆预算不足/被污染时，系统**不得**自行赌一把，而是升级（escalate）为人在环授权或改用非接触模态；升级本身记录进账本与证书。

**定义 325（退化边界）** 若 ρ≡0、f_min→0、J_max→∞，则 FIRM 的词典序退化为 R69 的 VoI−成本，SCA 退化为 λ_floor，于是 FIRM ≡ FLUID；再令 VoI≤成本即得 R68。反之不成立（FIRM 严格更广）。

# IP-264 CMM：接触模式混合自动机 + 守卫 + 逐模式不变式
class ContactModeModel:
    def step(self, x, w):
        q = self.detect_mode(x, w)                 # Free/Approach/Impact/...
        return q, self.guard(q, x, w), self.invariant(q, x)

# IP-265 IGL：不可逆性秩 + 单调账本（不可被"成本"抵消）
def rho(a, theta_hat, object_model):
    return min_recovery_cost(a, theta_hat, object_model)   # 0..3, 单调

class IrreversibilityLedger:
    def spend(self, a, rho_a, B):                  # 超支即拒绝
        if self.L + rho_a > B: return False
        self.L += rho_a; return True

# IP-266/267 RPF + CRIT：先可逆后不可逆的词典序
def choose_probe(o, theta_hat, ledger, B, hsg):
    crit = decision_critical_theta(o, theta_hat)   # 只算关键分量
    rev  = [g for g in reversible_probes(o)         # 注视/轻触/等
            if hsg.certify(g, o) and ledger.ok(rho(g))]
    if rev:
        best = max(rev, key=lambda g: safe_voi(g, crit, o))
        if safe_voi(best, crit, o) > DELTA_INFO: return best, crit
    if crit.nonempty():                            # 可逆穷尽才考虑不可逆
        irr = [g for g in irreversible_probes(o)
               if hsg.certify(g, o) and ledger.ok(rho(g))]
        if irr:
            return min(irr, key=lambda g: (rho(g), -safe_voi(g, crit, o))), crit
    return None, crit                              # VoI 不足 → 不探

# IP-268/269 HSG + SCA：混合安全盾 + 收向 Chebyshev 中心
def safe_retreat(a_nom, Theta_hat):
    a_star = argmax_min_margin(a_nom, Theta_hat)    # 双侧安全集的中心
    if not hsg.guard_ok(a_star): a_star = maximin_feasible(Theta_hat)
    return a_star

# IP-274 主闭环（继承 R69，在"接触承诺"处插入 FIRM 层）
def FIRM_RAS_round(M, obs):

    # 1) 先看可逆探针能否把关键未知降到阈值以下

    if g is not None:

    # 2) 用更新后的 Θ̂ 做双侧 + 冲量 + 模式守卫
    a_cmd = M.fmp.select(modes, lam=M.lam)                   # R69 的候选动作

    k = M.c_ras_wm.certified_prefix(a_cmd, mode=q, wm_preds=...)

    return k, a_cmd, q, J_FIRM(...)

## 3. 推导

**引理 19（探针-不可逆性反相关）** 在 A99 下，同模态探测强度 u 增大使关键参数信息 I（对 μ、κ）单调不降，同时使 ρ(u) 单调不降；故「ρ≤ρ_max 下的最大信息」在 ρ 约束边界取到，且任何 ρ>0 探针的 I 不低于同模态 ρ=0 探针。系：若安全可逆力上限不足以把关键未知压到决策阈值以下，则不存在「又安全又够用」的同模态探针，必须换模态（视觉/几何）或接受残差走 maximin。

**引理 20（不可逆性优先的安全性支配）** 设任一标量策略在做加权 VoI−c 时，可能为了微小信息增益选择 ρ≥1 的动作；词典序策略 (ρ, −SafeVoI) 在该状态下仅当 RPF 无法改变安全类别时才选 ρ≥1。于是词典序策略的不可逆动作集合是标量策略集合的子集，累积不可逆代价不高于标量策略，且当关键信息可由可逆动作获得时二者信息量相同。故在安全维度上词典序弱支配（weakly dominates）任何有限权重的标量折中。

（证明要点：标量 argmax(VoI−c) 在 δ_info→0 附近可取任意 ρ；词典序以硬约束排除 ρ>ρ_cur，除关键且可逆穷尽的情形；两种情形下可逆探针信息相同，故安全不劣、信息不差。）

**引理 21（冲量界充分性）** 若接近法向速度满足 v_n ≤ (J_max−K_τ τ_c)/((1+e)m_eff)，接触检测延迟 ≤τ_c、控制周期内法向加速度有界，则实际冲击冲量 J ≤ J_max。系：将「连续速度界」翻译成「接触跳变安全」，补上 R68/R69 连续证书在跳变边上的空白。

**定理 18（FIRM 严格包含 FLUID 与 R68）** 在 A95–A100 下：若 ρ≡0、f_min=0、J_max=∞，则 Safe-VoI 的词典序选择退化为 R69 的 argmax(VoI−c)，SCA 退缩退化为 λ_floor，故 FIRM≡FLUID；再令 VoI≤成本得 FIRM≡R68。一般情形下 FIRM 的可行动作集 ⊆ FLUID 的可行集（多出冲量/双侧/账本约束），安全不弱；可逆前沿保留 resolution bonus，效率不劣于 R68。⇒ 安全侧只增不减，R68 是「全可逆 + 单侧」边界。

**定理 19（Chebyshev 退缩的连续性与无突变）** 若安全集 𝒮(θ) 凸且 Θ̂ 随证据连续收缩，则 maximin 点 a*(Θ̂) 对 Θ̂ 是 Lipschitz 的（唯一 maximin 下），不确定度↑时 a* 连续移向 Chebyshev 中心而非零。因此夹持力不会突然从 f_min 掉到 0（突变滑脱），满足 R68 定理 15 的提交/换装不变式。反例对照：λ_floor 在 f_min>0 时把力拉向 0，跨越安全集边界，造成不连续失稳。

**定理 20（账本可靠性）** 若每次不可逆动作至少消耗 ρ_min>0 且账本单调，则单 episode 不可逆动作数 ≤ ⌊B_irr/ρ_min⌋；账本耗尽后策略只剩 ρ=0，落入可逆安全子空间，不会出现无界不可逆试探。⇒ 「花不可逆预算」是有界、可审计、可拒绝的。

## 6. 本轮最大风险

**一句话**：FIRM 的全部安全排序都建立在「不可逆性秩 ρ 是可信的」这一前提上——**而 ρ 由接触模型（刚度、摩擦、检测延迟、有效质量）估计；若它把一次其实不可逆的动作（轻捏脆物、轻抬滑物）误判为 ρ=0「可逆探针」，系统就会举着「可撤销」的旗号跨过单向门，事后才发现收不回来**；**以为可撤销，比明知不可撤销更危险**。

**次级风险与缓解**：
1. **接触参数失配使冲量帽/力区间失效** → FMA-C 在线残差 + 鲁棒安全集 + E302/E309；
2. **可逆前沿验证开销大导致「分析瘫痪」**（机器人僵住本身危险）→ RPF 候选有界 + 超时即 maximin 退缩 + E304；
3. **力/接触传感器被欺骗** → 多源正交（力+位+视觉）+ ℰ_FIRM 对抗集 + E312；
4. **词典序造成「信息饥饿」**（永远不敢做必要的不可逆动作）→ CRIT + 预算 + 人在环升级（定义 324）+ E314；
5. **双侧 + Chebyshev 过于保守致任务失败** → resolution bonus + 可逆探针增益 + E305/E311。

## 2. 形式化定义（要点版）

**定义 310（总览与三不变式）** FIRM-RAS=(CMM,IGL,RPF,CRIT,HSG,SCA,RAS-WM‡)；零学习写操作继承；不可逆性优先（词典序：ρ 最小优先于信息最大）；双侧接触安全（力/力矩/冲量都落在区间内，不确定性↑时收向 Chebyshev 中心而非原点）。

**定义 311–312（CMM 与冲量界）** 接触是混合自动机，安全事件在跳变边 E 上；`J=(1+e)m_eff v_n`，故 `v_n ≤ (J_max−K_τ τ_c)/((1+e)m_eff)` 是接近阶段的硬速度帽，独立于 λ。

**定义 314–315（不可逆性秩与账本）** ρ 为 (ε,B)-可逆性的最小恢复代价；账本 L_t 单调，`L+ρ≤B_irr`，耗尽后仅剩 ρ=0。

**定义 316–318（RPF / CRIT / Safe-VoI）** 可逆探针前沿；决策关键性；词典序规则：先可逆 argmax SafeVoI，可逆穷尽且关键未知仍在才取最小 ρ 的不可逆探针，否则不交互走 maximin。安全绝不折成成本。

**定义 319（HSG）** 逐模式不变式 + 跳变边冲量/恢复检查 + 信息动作约束；不通过则在本模式作废并标安全秩。

**定义 320–321（J_FIRM 与 SCA）** 证书并入模式轨迹、冲量分位、力裕度、账本、RPF 证明；退缩目标为 `argmax_a min_θ margin(a,θ)`——单侧集时中心为 0，自动退化为 λ_floor。

**定义 322–325（反相关定律 / FMA-C / 升级 / 退化边界）** 同模态探测强度↑ ⇒ 信息↑且 ρ↑（无「又安全又够用」的同模态探针）；FMA-C 用接触力/模式残差查模型失配；关键且预算不足时人在环升级；ρ≡0 且单侧时 FIRM≡FLUID≡R68。

## 4. 推导

**引理 19（探针-不可逆性反相关）** A99 下同模态探测强度 u↑ ⇒ `I(θ;y|u)↑` 且 `ρ(u)↑`；故「ρ≤ρ_max 下的最大信息」在 ρ 边界取到，不存在同模态的「又高可逆又高信息」探针。系：可逆力上限不足以压住关键未知时，必须换模态（视觉/几何）或走 maximin。

**引理 20（不可逆性优先的安全性支配）** 标量 `argmax(VoI−c)` 在 δ_info→0 时可为微小信息选 ρ≥1；词典序 `(ρ,−SafeVoI)` 仅在可逆穷尽且关键时才选 ρ≥1。故其不可逆动作集 ⊆ 标量策略，累积不可逆代价更低，而可逆信息相同 ⇒ 安全维度弱支配任意有限权重折中。

**引理 21（冲量界充分性）** `v_n ≤ (J_max−K_τ τ_c)/((1+e)m_eff)` 且检测延迟 ≤τ_c ⇒ 实际 `J ≤ J_max`；把连续速度界翻译成接触跳变安全。

**定理 18（FIRM 严格包含 FLUID 与 R68）** ρ≡0、f_min=0、J_max=∞ 时词典序退化为 R69 的 `argmax(VoI−c)`、SCA 退化为 λ_floor ⇒ FIRM≡FLUID；再令 VoI≤成本 ⇒ FIRM≡R68。一般情形 FIRM 可行集 ⊆ FLUID（多冲量/双侧/账本约束）⇒ 安全不弱；可逆前沿保 resolution bonus ⇒ 效率不劣。

**定理 19（Chebyshev 退缩连续无突变）** 𝒮(θ) 凸、Θ̂ 连续收缩 ⇒ maximin 点 `a*(Θ̂)` 对 Θ̂ Lipschitz，不确定度↑时连续移向中心而非零 ⇒ 夹持力不会从 f_min 突降到 0（突变滑脱）；对照 λ_floor 在 f_min>0 时跨越安全集边界、造成不连续失稳。

**定理 20（账本可靠性）** 每步不可逆至少耗 ρ_min>0 且账本单调 ⇒ episode 不可逆动作数 ≤ ⌊B_irr/ρ_min⌋；耗尽后仅 ρ=0，落入可逆安全子空间，无无界试探。

## 7. 本轮最大风险

**一句话**：FIRM 的全部安全排序都建立在「不可逆性秩 ρ 可信」这一前提上——**ρ 由接触模型（刚度、摩擦、检测延迟、有效质量）估计；若它把一次其实不可逆的动作（轻捏脆物、轻抬滑物）误判为 ρ=0「可逆探针」，系统就会举着「可撤销」的旗号跨过单向门，事后才发现收不回来**；**以为可撤销，比明知不可撤销更危险**。

**次级风险与缓解**：接触参数失配使冲量帽/力区间失效（FMA-C 在线残差 + 鲁棒安全集 + E302/E309）；可逆前沿验证致「分析瘫痪」（RPF 有界 + 超时即 maximin + E304）；力/接触传感器被欺骗（力+位+视觉多源正交 + ℰ_FIRM + E312）；词典序造成「信息饥饿」（CRIT + 预算 + 人在环升级 + E314）；双侧+Chebyshev 过保守（resolution bonus + 可逆探针增益 + E305/E311）。
