# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；本轮灵感：「情感语音」×「论文创新点」）

> R69 把交互变成一等动作，问出「我该向谁求证、还能问什么」，并用「k 个正交证据源一致」给提问上了证据纪律。但它仍建立在两个未经检验的假设上：
> 1. **回答是对固定隐变量 M 的带噪观测**——人类是一个诚实的、被动的传感器；
> 2. **系统自己的表达是中性的探针**——问句只「取」信息，不「施加」影响。
>
> 情感语音恰好同时击穿这两条：人说话时的韵律、语气、犹豫，既是**泄漏**（控制不住的真心），也是**杠杆**（有意识地影响听者）；而系统一旦用带情感韵律的声音发问，它自己就成了博弈中的信号发送者。**把情感当传感器，会漏掉「对方在对我做什么」；把情感当标签，会把赌博当测量。**
>
> 第二个灵感词「论文创新点」把同一把刀转向研究本身：R66–R69 已累积 60+ IP、300+ 定义，**创新点的边际收益在递减，而「看起来新」的激励在递增**——这本身就是一个 Goodhart 式的信号博弈。审稿人是 receiver，作者是 sender，「新」是廉价话语（cheap talk），除非它能被一个**决定性实验**验证。所以本轮不只加一层机制，还要给整个项目做一次**贡献账本审计**：哪些 IP 是承重的，哪些只是命名的通货膨胀。
>
> 核心命题：**把交互从「向被动环境采样」升级为「与策略性人类进行信号博弈」；情感语音是这个升级的判别性通道（既泄漏又操纵）；并用同一套「激励相容 + 可验证 + 可判伪」的逻辑，审计论文自身的创新点，只保留 ≤3 个承重贡献。** 命名 **SIREN-RAS**（Strategic Interaction with Recognition of Emotional Negotiation）——塞壬的歌声：它确实携带信息，但它也在引诱你撞上礁石。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**对方是在告诉我真相，还是在对我施加影响；而我自己的表达又在如何改变对方——以及这篇论文真正新在哪里**」。

## 0. 直觉与动机

**灵感 1（情感语音不是第六种模态，而是一条双向策略通道）**
直觉：R69 把「看/问/触」当成从环境中提取信息的动作，默认被问者会尽力回答。但人说话从来不只是在「报告状态」：道歉时的软语气、拒绝时的升调、疼痛时的压抑、礼貌性的笑，都是**对听者施加影响的动作**。同一句「我没事」，配平直语调、配颤抖语调、配刻意上扬的语调，语义相同而策略含义完全不同。情感语音因此不是一个待分类的标签，而是一个**信号**：发送者有人格类型、有偏好、有说谎成本，接收者的反应又会反过来改变发送者的下一句话。把它塞进 R69 的 `r_emo` 残差，等于把一个博弈压成一个标量。

**灵感 2（策略性回答会让「熵减」主动变坏）**
直觉：R69 的 MINT 选信息动作，最大化后验熵的下降。这个目标隐含假设「更多信息 = 更好决策」。但当对方是策略性的，提问会**改变对方的行为**：系统用笃定语气追问，可能逼出一个迎合性回答；系统问「你是不是不舒服」，可能让一个不想添麻烦的人更强地说「没事」。此时后验熵确实下降了，但下降的方向是被提问方式**诱导**出来的——熵减为负价值。**信息增益不是效用增益；在策略性人类面前，二者可以反号。** 这是 R69 最深的裂缝：它优化的是「我知道得更多」，而不是「我做得更好」。

**灵感 3（泄漏不对称：可演的部分与演不了的部分）**
直觉：情感表达里有一组「可控通道」（措辞、摆出的表情、刻意设计的语调）和一组「泄漏通道」（微韵律抖动、反应时延、音质、呼吸、无意识的停顿结构）。前者可以排练得天衣无缝，后者很难同时伪造。**真实情感往往在泄漏通道里留下不一致的毛刺；策略性展示则表现为「可控通道太完美，而泄漏通道不配合」。** 这给了一个比 R69「环一致性」更锋利的判据：不是看各模态是否一致，而是看**不一致出现在哪一类通道上**。代价是：泄漏通道也会被高水平对手（或克隆语音）污染，所以它只能提高欺骗成本，不能证明真诚。

**灵感 4（可验证问题让欺骗均衡坍缩，强于「k 源一致」）**
直觉：R69 用「k 个正交源一致」对抗投毒，但它挡不住**相关撒谎**——一个人可以在表情、语气、措辞上协同演戏，k 个源一起错。真正能压垮欺骗的不是「多问几遍」，而是**让问题事后可验证**：预测一个可观测结果、承诺一个可核对的动作、问一个与已记录事实交叉的问题。可验证性把「说谎」从无成本变成有惩罚的赌注；在均衡里，惩罚 × 验证概率一旦超过说谎收益，欺骗率就指数式坍缩。**验证不是多一个证据源，而是改变对方的收益结构。**

**灵感 5（论文创新点也是信号博弈 → 贡献账本）**
直觉：项目每轮都在「加一层」，因为「新」比「对」更容易被看见。这与情感语音同构：作者是 sender，审稿人/读者是 receiver，「创新点」是 message，而「跑通一个决定性实验」是那个**可验证通道**。若一个所谓创新点无法被一个「只差该机制」的基线与主系统区分开，它就只是重命名（reparameterization），不是创新。因此本轮引入**贡献账本**：每个 IP 必须过四关（新颖、必要、可判伪、非冗余），论文只允许 ≤3 个承重创新点，其余降级为实现细节。**这既是对项目的诚实，也是对读者的激励相容。**

## 1. 形式化定义（增量：定义 310–326）

**定义 310（SIREN-RAS 总览）** SIREN-RAS = (ASP, ASG, MIC, RPS, CLC, AIR, DGB, EAB, SSD, NVA, RAS-WM§)。五不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **情感通道永不单独定案**：韵律/情感证据不得单独决定模态，必须与可验证证据或泄漏通道交叉；
(iii) **策略性人类假设**：信念更新必须使用行为策略 σ_H，不得使用朴素观测似然 p(y|M)；行为模型未认证 ⇒ 逐指令退回 R69；
(iv) **可验证问题优先 + 激励相容**：能事后验证的问题优先；不可验证问题只能作旁证，不得单独定案；
(v) **伦理操纵预算与可争辩性**：机器人韵律总影响 ≤ B_eth，不得利用脆弱状态换取顺从，人类可随时覆盖并留痕。

**定义 311（情感语音三分解 ASP）** 观测到语音轨迹 φ_t = h(a_t, s_t, n_t)，其中 a_t 为真实情感状态（缓变，部分不可约），s_t 为策略性展示（为影响机器人而选），n_t 为通道/合成噪声；同时有词汇内容 ℓ_t。机器人估计后验 b_t(a,s)，而非输出单一情感标签。**可辨识性只到等价类**：在不引入跨通道泄漏时，(a,s) 不可分；三分解的可信度由定义 317 的泄漏不对称给出。

**定义 312（人类类型与行为策略）** 类型 θ = (x, v, c, a, κ)：x 为物理状态，v 为偏好/效用，c 为说谎与认知努力成本，a 为情感状态，κ 为知识/能力。行为策略 σ_H(m, y | θ, π_R) 同时给出消息 m = (ℓ, φ) 与可能动作 y 的分布，且**显式依赖机器人策略 π_R**。R69 的观测模型 p(y|M,g) 是本定义在「σ_H 与 π_R 无关、且类型仅含 M」时的退化特例。

**定义 313（情感信号博弈 ASG）** 博弈 G = (Θ, M, A_R, U_H, U_R, σ_H, π_R)。解概念取 **logit-QRE**（理性度 λ_H）加 trembling ε：σ_H 与最优反应的偏差满足 softmax 形式；并维护**策略鲁棒半径** ρ_sr，表示行为模型在对手/文化/个体差异下的歧义集大小。定义均衡残差 e_QRE = ‖σ_H − BR_{λ_H}(σ_H)‖。

**定义 314（行为一致鲁棒信念更新 BCBU）** 用行为似然而非观测似然：b_{r+1} ∝ σ̂_H(m_r | θ, π_R) · b_r，其中 σ̂_H 取歧义集内的鲁棒版本（对 ρ_sr 邻域取最坏情形，等价于分布鲁棒 Bayes）。R69 的朴素 Bayes 是 ρ_sr = 0 且 σ_H 与策略无关的边界。

**定义 315（激励相容问句 MIC）** 选择问句 q（可含可验证子问句），使真实报告成为软最优反应。IC 缺口 IC(q,π) = E[U_H(真话)] − max_{m'≠真话} E[U_H(m')]，要求 IC(q,π) ≥ δ_IC，否则该问句只许作旁证。可验证问题用**严格适当评分规则**（对预测/核对类问题）或**同行预测**（对无真值问题）支付，令真实报告期望得分最高。验证集 V 中的问题事后可判定，惩罚 L。

**定义 316（机器人韵律策略 RPS 与顺从核）** 机器人韵律 π_R 是策略变量，会改变人类回答分布。定义顺从核 A(π_R) = P(答「同意」| 真值「不同意」,π_R) − P(答「同意」| 真值「同意」,π_R)。约束 A(π_R) ≤ A_max：韵律只许用于**降低压迫**（hedge、升调、放慢、给足思考停顿），不得用于提高顺从。机器人自身韵律也是发送给人类的信号，须按定义 320 计入操纵预算。

**定义 317（跨通道泄漏一致性 CLC）** 把证据分为可控通道 C（措辞、摆拍表情、刻意语调）与泄漏通道 L（微韵律、反应时延、音质、呼吸、停顿结构、可得的生理信号）。对同一语义主张，计算 c = Consistency_C、l = Consistency_L，定义泄漏分 r_leak = c − l。**r_leak 高（C 太完美而 L 不配合）⇒ 策略性展示/欺骗疑**；r_leak 低而 c、l 都低 ⇒ 可能是能力不足或通道噪声，不判欺骗。CLC 作为 R69 证据集 ℰ 的新成员替换/增强 r_emo。

**定义 318（情感实验设计 AIR：按任务效用而非熵选交互）** 对候选交互 g = (q, π_R)，定义
EU(g) = E_{y~σ_H(·|g)}[ max_a E_{θ~b_{r+1}} U_R(a,θ) ] − c(g) − λ_eth·Manip(g)，
其中 b_{r+1} 由定义 314 更新。选择 g* = argmax EU(g)，s.t. IC、预算、伦理约束；若 EU(g*) ≤ EU(∅)（不交互的期望效用），则不交互。**注意与 R69 定义 298 的差别：R69 最大化 H(M|o) − E[H(M|o,y)]；本定义允许「问得越多、效用越低」（锚定/施压），并显式扣除操纵。** 定义交互遗憾 Reg(g) = EU(g) − EU(∅)。

**定义 319（可验证性与欺骗均衡 DGB）** 设问题质量中比例 p 事后可验证，验证后说谎惩罚 L，说谎直接成本 c_lie。在理性度 λ_H 的 logit-QRE 下，欺骗概率满足
δ ≤ exp(−λ_H · max(0, pL − c_lie)) + ε_σ。
故 pL 一旦超过 c_lie，欺骗率指数坍缩；相关撒谎只能在不可验证的 (1−p) 质量上存活。这是对 R69 引理 18「k 源一致」的强化：**一致性可以被协同伪造，可验证性不能。**

**定义 320（伦理操纵预算 EAB 与可争辩性）** 操纵压力 Manip(g) = E_{θ~b}[ D_KL( σ_H(·|θ,π_R) ‖ σ_H(·|θ,π_neutral) ) ]，对脆弱类型加权。约束累计 Σ Manip ≤ B_eth；当 b(脆弱) > τ_v 时冻结说服性韵律，只允许中性/降压迫表达。**可争辩性**：人类可随时覆盖机器人决定、查看其依据摘要、撤回数据；覆盖与撤回必须留痕并进入审计。禁止利用痛苦、紧急、孤独等状态换取顺从。

**定义 321（策略漂移检测 SSD）** 人类会适应机器人（重复提问导致敷衍、学会触发某类回答）。对条件响应分布 σ_H(·|q,π_R) 做变点检测；若漂移超过阈值，冻结当前信念、提升可验证问题比例，或直接退回 R69 保守。**R69 假设人类分布平稳；R70 显式承认对手在学。**

**定义 322（证书 J_SIREN）** J_SIREN = (J_FLUID, e_QRE, IC_gap_min, verifiable_ratio, deception_post, leak_asymmetry, manip_budget_used, override_rate, ssd_alarm, siren_ver)。Valid ⇔ Valid(J_FLUID) ∧ IC_gap_min ≥ δ_IC（凡用情感证据定案处）∧ 可验证比例 ≥ r_min ∧ 操纵预算未越界 ∧ 行为模型在 ρ_sr 内已认证。

**定义 323（三级策略退避，安全侧再加强）** (a) 经 IC + 可验证证据**决议**：λ = λ_floor(U_ale)，继承 R69 的 resolution bonus；(b) 未决议/策略歧义/QRE 残差高：λ = λ_floor(U_ale + U_epi)，即 R69；(c) 命中操纵/欺骗/脆弱保护/漂移告警：λ = λ_floor(U_ale + U_epi) **且冻结情感交互一个冷却窗**，并强制人工/外部复核。⇒ R69 是中间边界；R70 在安全侧只可能更保守。

**定义 324（贡献账本与创新点审计 NVA）** 对每个 IP i 定义四元评分：
- 新颖 N_i：与既有 IP 及文献的机制距离（嵌入距离 + 盲评）；
- 必要 K_i：去掉 i 后关键指标的消融效应（承重性）；
- 可判伪 F_i：是否存在一个「只差机制 i」的决定性实验能改变可观测预测；
- 非冗余 R_i = 1 − max_{j≠i} sim(i,j)。
审计规则：可入正文 ⇔ N_i、K_i、F_i 均 ≥ 阈值；否则合并或降级为附录/实现细节。**唯一性约束**：论文主创新点 ≤ 3 个，且每个必须绑定一个决胜实验；账本 L = {(i, N,K,F,R, status)} 随轮次更新。

**定义 325（决定性实验契约 DEC）** 一个主张 C 可被写入创新点，当且仅当存在预注册实验 E 与基线 B，使 B 与主系统**只差声称的机制**，且 E 对「机制无差异」H0 有足够功效（显著性 α、功效 ≥ 1−β），并给出非退化的效应区间。否则 C 视为重参数化或命名，不作为创新点。**审稿人的零假设必须被写进实验设计，而不是事后解释。**

**定义 326（威胁模型 ℰ_SIREN）** 策略性顺从（怕麻烦/讨好）、情感操纵（人→机器人，以及机器人→人）、克隆/重放/对抗韵律、跨通道协同撒谎（可控通道共谋）、文化特异的展示规则、机器自身韵律泄漏内部不确定性（侧信道）、把真实痛苦误读为「在演戏」、以及相反地把表演误读为真实。并入 AIC：ℰ_SIREN = ℰ_FLUID × ℰ_siren。

# IP-264 ASP：情感语音三分解（复用 R69 MTM trunk，零重复训练）
class AffectiveSpeechParser:
    def __init__(self, trunk, prosody_net, disentangler):
        self.trunk, self.pros, self.dis = trunk, prosody_net, disentangler

    def parse(self, audio, z):                    # z = R69 的 z_t
        phi = self.pros(audio)                    # F0/能量/语速/停顿/音质/时延
        a_hat, s_hat = self.dis(phi, z)           # 真实情感 vs 策略性展示
        n_hat = self.channel_noise(phi)           # 通道/合成噪声
        return a_hat, s_hat, n_hat, phi

# IP-265 ASG：情感信号博弈（logit-QRE + 分布鲁棒）
class AffectiveSignalingGame:
    def behavioral_likelihood(self, m, pi_R):
        return self.sigma_H(m, pi_R)              # σ̂_H(m|θ,π_R)，非 p(y|M)

    def update(self, b, m, pi_R):
        b1 = normalize(b * self.behavioral_likelihood(m, pi_R))
        return self.project_worst_case(b1, self.rho_sr)   # 鲁棒歧义集

# IP-266/318 MIC + AIR：先激励相容/可验证，再按任务效用选
def choose_experiment(modes, b, budget, ethics):
    best = None
    for q in question_candidates(modes):
        if q.unverifiable_mass > R_MAX_UNVERIFIED: continue
        if ic_gap(q, b) < DELTA_IC: continue      # 诱导/共鸣问题不许定案
        for pi in safe_prosody(q, b):             # IP-267：只降压迫不升顺从
            if ethics.manipulation(q, pi, b) > ethics.budget_left: continue

            if best is None or eu > best.eu: best = (q, pi, eu)
    return best if best and best.eu > EU_NO_INTERACTION else None

# IP-267 RPS：机器人韵律只用于降低压迫
def safe_prosody(q, b):

# IP-268 CLC：跨通道泄漏不对称

    l = consistency(claim, phi, physio, channels='leaky')
    return c - l            # 可控太完美、泄漏不配合 ⇒ 策略性展示疑

    g = M.air.choose_experiment(modes, b, M.budget, M.ethics)
    if g is None:
        U_epi_after = U_epi
    else:
        ans, phi_y = M.cia.execute(g)             # 看/问/触/听，带认证
        r_leak = M.clc.leakage_score(ans.lex, phi_y)
        if r_leak > TAU_LEAK or M.asg.manip_suspect(phi_y):
            b = M.asg.rollback(); U_epi_after = U_epi   # 证据不采纳
        else:
            b = M.asg.update(b, phi_y, g.prosody)
            U_epi_after = M.aud.residual_epistemic(b)
    lam = max(M.efs.risk_scale(...),
              lam_floor(U_ale + (0.0 if g else U_epi_after)))
    if M.ssd.alarm() or M.ethics.vulnerable(b):    # 漂移/脆弱保护
        lam = max(lam, 0.8); M.freeze_affective(cooldown=W)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    mode = select_mode(modes, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_s.submit_async(g, b, r_leak, U_epi, U_epi_after)
    M.nva.update_ledger(M.last_ip_evidence)        # IP-274：离线贡献账本
    return k, lam, mode, (U_ale, U_epi_after)

# IP-274 NVA：创新点审计（离线，不进控制环）
def audit_novelty(ips, prior_rounds, experiments):
    ledger = []
    for ip in ips:
        n = novelty(ip, prior_rounds)
        k = ablation_effect(ip, experiments)
        f = falsifiability(ip, experiments)        # 是否存在“只差该机制”的实验
        r = 1.0 - max_similarity(ip, ips - {ip})
        status = 'load-bearing' if min(n, k, f) >= T else 'prune/merge'
        ledger.append((ip, n, k, f, r, status))
    return ledger

## 3. 推导

**假设 A99–A102** A99：行为策略在日志数据上可辨识到鲁棒半径 ρ_sr；A100：泄漏通道的伪造成本严格高于可控通道；A101：质量比例 p 的问题可事后验证且惩罚为 L；A102：操纵预算 B_eth 有限且可审计。

**引理 19（策略性回答使熵-VoI 失效）** 存在情感信号博弈 G，使 R69 的熵-VoI 最优问题 g* 满足 VoI_entropy(g*) > 0，但 EU(g*) < EU(∅)。构造：两类人类（真难受 / 真没事）都有「不愿添麻烦」的社交成本；机器人用笃定语气问「你到底有没有事」，两类人都倾向答「没事」（pooling）。回答把后验熵压低，却把信念推向错误一侧；后续动作的期望效用低于不提问时的保守动作。系：**在策略性人类面前，MINT 不再是效用单调的；SIREN 必须用 AIR（定义 318）替代熵-VoI。**

**引理 20（泄漏不对称提高欺骗成本）** 设一次虚假主张需在 m_C 个可控通道与 m_L 个泄漏通道上同时维持一致，单通道伪造成本分别为 c_C < c_L（A100），则总伪造成本 ≥ m_C c_C + m_L c_L，且随 m_L 单调上升；在检测器给定判别噪声下，欺骗成功概率随泄漏通道数指数下降。系：**r_leak = c − l 的判别力来自「成本不对称」，而非「模态数量」**；这也解释了为什么 R69 的「k 源一致」在协同演戏前脆弱——它数的是源，不是伪造成本。

**引理 21（可验证性使欺骗均衡坍缩）** 在理性度 λ_H 的 logit-QRE 中，若比例 p 的问题事后可验证、惩罚 L，则欺骗概率 δ ≤ exp(−λ_H·max(0, pL − c_lie)) + ε_σ（A101）。当 pL ≤ c_lie 时该界不提供保证；当 pL 充分大时 δ→ε_σ。系：**把「多问一个源」换成「让一个问题可验证」，对欺骗的压制更强**；相关撒谎只能寄居在不可验证质量上，而 R69 的 k 源一致无法消除相关性。

**定理 18（SIREN 严格包含 R69）** 在 A99–A102 下，当人类非策略（σ_H 与 π_R 无关、c_lie = ∞、IC 自动满足）时：ASP 退化为观测通道，ASG 退化为朴素 Bayes，AIR 退化为熵-VoI，伦理/可验证约束自动松驰 ⇒ SIREN 与 R69 **逐指令相同**。当任一约束不可认证（行为模型失配、操纵越界、漂移告警、证书无效）时，定义 323 使 λ 单调不降地退回 R69。⇒ R70 的安全侧永不强于 R69，效率侧仅在可认证时获得「策略性消歧红利」。

**定理 19（策略交互的无害性条件）** 若行为模型在 ρ_sr 内已认证、操纵预算 ≤ B_eth、均衡残差 ≤ e_QRE，则 SIREN 相对 R69 保守策略的期望效用遗憾 ≤ C·(ρ_sr + B_eth + e_QRE)；当该上界超过 ε_regret 时，定义 318 拒绝交互。⇒ **「把情感当信号」可以安全，但安全边界是一个可计算的证书，而不是一句「我们考虑了情感」。**

**命题 1（创新点的可判伪必要条件）** 主张 C 可作为创新点写入，仅当存在预注册实验 E 与只差机制 C 的基线 B，使 H0（无机制差异）可在水平 α、功效 ≥ 1−β 下被拒绝（定义 325）。否则 C 与某个既有机制的观测行为不可区分，属于重参数化或命名。系：**NVA 的定义 324 是命题 1 的可操作化；一个 IP 若拿不出决胜实验，就不该占据「创新点」这个词。**

## 6. 本轮最大风险

**一句话**：SIREN-RAS 把「情感」从观测升级为博弈，但整座塔押在**行为策略 σ_H 与人类类型 θ 可辨识**这一前提上——一旦它在文化、个体、对手适应下失配，「真实痛苦」会被误判为「策略表演」而被冷处理，或者反过来把操纵当真诚；更糟的是，机制设计会**学会施压**（用韵律提高顺从），把 R69 的「问错」升级为 R70 的「操控错」——**把情感当信号，可能让系统既不信人，又教人不说真话。**

**次级风险与缓解**：行为模型失配（ρ_sr 鲁棒 + 定理 19 的可认证上界 + 超界即退 R69）；协同撒谎与克隆（泄漏不对称只能提高成本，需可验证问题 pL 压制 + ℰ_siren 对抗训练）；机器人自身韵律侧信道（预合成 + 中性化 + 审计）；伦理越界（EAB 硬预算 + 脆弱冻结 + 可争辩性 + 人工复核）；创新点通胀（NVA 四关 + 决定性实验契约 + ≤3 承重 IP）。

> 本轮的一条元结论：**「问得更多」不等于「知道更多」，「看起来更新」不等于「真的更新」；在策略性世界里，唯一可靠的不是更多的源，而是更不可伪造的验证。**

class AffectiveSpeechParser:

    return qre.project_worst_case(b1, qre.rho_sr)

        if ic_gap(q, b) < DELTA_IC: continue

            eu = expected_task_utility(b, q, pi)  # AIR，非熵减
            if best is None or eu > best.eu: best = (q, pi, eu)
    return best if best and best.eu > EU_NO_INTERACTION else None

# IP-268 CLC：泄漏不对称
def leakage_score(claim, phi, physio=None):
    c = consistency(claim, phi, channels='controllable')
    l = consistency(claim, phi, physio, channels='leaky')
    return c - l

# IP-276 主闭环（继承 R69）
def SIREN_RAS_round(M, obs, audio):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)
    a, s, n, phi = M.asp.parse(audio, z)
    if not M.nva.certified(['ASG', 'MIC', 'EAB']): return M.fluid_round(obs)
    b = M.asg.update(M.b_prior, phi, M.last_prosody)
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K=1), z, M.fmp.mode_head)
    g = M.air.choose_experiment(modes, b, M.budget, M.ethics)
    if g is None:
        U_epi_after = U_epi
    else:
        ans, phi_y = M.cia.execute(g)
        r = M.clc.leakage_score(ans.lex, phi_y)
        if r > TAU_LEAK or M.asg.manip_suspect(phi_y):
            b = M.asg.rollback(); U_epi_after = U_epi
        else:
            b = M.asg.update(b, phi_y, g.prosody)
            U_epi_after = M.aud.residual_epistemic(b)
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + (0.0 if g else U_epi_after)))
    if M.ssd.alarm() or M.ethics.vulnerable(b):
        lam = max(lam, 0.8); M.freeze_affective(cooldown=W)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    mode = select_mode(modes, U_epi_after, lam)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_s.submit_async(g, b, r, U_epi, U_epi_after)
    return k, lam, mode, (U_ale, U_epi_after)

def audit_novelty(ips, prior_rounds, experiments):
    return [(ip,
             novelty(ip, prior_rounds),
             ablation_effect(ip, experiments),
             falsifiability(ip, experiments),

## 4. 推导

**假设 A99–A102** A99 行为策略可辨识到鲁棒半径 ρ_sr；A100 泄漏通道伪造成本 > 可控通道；A101 比例 p 的问题事后可验证且惩罚 L；A102 操纵预算 B_eth 有限可审计。

**引理 19（策略性回答使熵-VoI 失效）** 存在情感信号博弈 G 使 `VoI_entropy(g*) > 0` 而 `EU(g*) < EU(∅)`：两类人类都有「不愿添麻烦」成本，笃定追问诱发 pooling 的「没事」，熵降了但信念被推向错误一侧。系：**R69 的 MINT 在策略性人类下不再效用单调，必须换 AIR。**

**引理 20（泄漏不对称提高欺骗成本）** 虚假主张需在 m_C 个可控通道与 m_L 个泄漏通道维持一致，伪造成本 ≥ m_C c_C + m_L c_L（c_C < c_L），欺骗成功概率随 m_L 指数下降。系：**判别力来自成本不对称，而非模态数量**；R69 的 k 源一致数的是源，不是伪造成本。

**引理 21（可验证性使欺骗均衡坍缩）** logit-QRE 下 `δ ≤ exp(−λ_H·max(0,pL−c_lie)) + ε_σ`；pL ≤ c_lie 时无保证，pL 充分大时 δ→ε_σ。系：**让一个问题可验证，强于多问一个源**；相关撒谎只能寄居在不可验证质量上。

**定理 18（SIREN 严格包含 R69）** 人类非策略（σ_H 与 π_R 无关、c_lie=∞、IC 自动满足）时，ASP→观测通道、ASG→朴素 Bayes、AIR→熵-VoI、伦理/验证约束松驰 ⇒ 与 R69 逐指令相同；任一约束不可认证 ⇒ 三级退避使 λ 单调不降地退回 R69。安全侧永不强于 R69，效率侧仅在可认证时获得策略性消歧红利。

**定理 19（策略交互的无害性条件）** 行为模型在 ρ_sr 内认证、操纵 ≤ B_eth、均衡残差 ≤ e_QRE 时，相对 R69 保守策略的效用遗憾 ≤ `C·(ρ_sr + B_eth + e_QRE)`；超过 ε_regret 则拒绝交互。⇒ 情感信号化可以安全，但安全边界是**可计算的证书**，不是一句「考虑过情感」。

**命题 1（创新点可判伪必要条件）** 主张 C 可作创新点，仅当存在预注册实验 E 与只差机制 C 的基线 B，能在水平 α、功效 ≥ 1−β 下拒绝 H0（无机制差异）；否则 C 属重参数化或命名。系：**拿不出决胜实验的 IP，不该占用「创新点」一词。**

## 7. 创新点审计与论文叙事（本轮元层产物）

**核心问题**：R66–R69 已积累 60+ IP、300+ 定义。若继续「每轮加一层」，论文会变成一座没人能读完、也说不清哪块承重的塔。本轮用定义 324–325 对项目做一次**贡献账本审计**。

**建议的 3 个承重创新点（≤3 约束）**：
1. **C1（机制层）**：把交互从「主动采样」升级为「与策略性人类的信号博弈」；给出可认证的无害性条件（定理 19）与严格包含 R69 的退化（定理 18）。
2. **C2（通道层）**：情感语音的**双向策略通道**建模——三分解 + 泄漏不对称 + 可验证性欺骗坍缩（引理 19–21）；这是 C1 的判别性实例。
3. **C3（元层）**：**贡献账本 + 决定性实验契约**（定义 324–325、命题 1）——把「创新点」从廉价话语变成可判伪主张，并给出 ≤3 承重 IP 的可操作规则。

**建议降级/合并的 IP（示例，需 E311 消融确认）**：把 R66–R69 中的若干「命名层」（重复包装同一风险缩放/证书/审计机制者）合并为附录实现细节；保留有独立消融效应的机制（如一阶表：流策略、标定对偶、证据纪律、策略交互）。**判据不是「它听起来新不新」，而是「去掉它，决胜实验的预测是否改变」。**

**决胜实验 E310 的设计**：同一任务、同一数据、同一安全包络，仅改变「情感处理」——基线 B 用 R69 的 r_emo + 熵-VoI（情感即标签/观测），主系统用 SIREN（情感即信号）。在**策略顺从场景**（人因社交成本而说「没事」，而真实状态需要干预）中，B 的熵-VoI 会自信地收敛到错误模态并降低干预率；主系统应显著提高真话率与任务效用。若两者无差异，则 C2 不成立，按定义 325 撤回该创新点。

**论文一句话主张（候选）**：*In strategic human interaction, emotion is not a sensor reading but a signal; treating it as a signal—with incentive-compatible questions, leakage asymmetry, and a certified fallback to conservative interaction—strictly generalizes observation-based disambiguation while never weakening the safety side.*

## 8. 本轮最大风险

**一句话**：整座塔押在**行为策略 σ_H 与人类类型 θ 可辨识**上——一旦在文化、个体、对手适应下失配，「真实痛苦」会被误判为「策略表演」而被冷处理，或反过来把操纵当真诚；更糟的是，机制设计会**学会施压**（用韵律提高顺从），把 R69 的「问错」升级为 R70 的「操控错」——**把情感当信号，可能让系统既不信人，又教人不说真话。**

**次级风险与缓解**：行为模型失配（ρ_sr 鲁棒 + 定理 19 可认证上界 + 超界退 R69）；协同撒谎/克隆（泄漏不对称只提高成本，需 pL 可验证压制 + ℰ_siren 对抗训练）；机器人韵律侧信道（预合成 + 中性化 + 审计）；伦理越界（EAB 硬预算 + 脆弱冻结 + 可争辩性 + 人工复核）；创新点通胀（NVA 四关 + DEC + ≤3 承重 IP）。
