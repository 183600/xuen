# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；新一轮灵感循环第 1 轮；本轮灵感：「具身智能」×「技能学习」）

> 第 54 轮把技能组合推进到动作-鲁棒性双证书：`α_S` 回答「动作空间是否覆盖」，`J` 回答「云边是否对齐」。但这套证书隐含两个未言明的前提：**身体是固定坐标系，技能是已完成的学习结果**。本轮用「具身智能」和「技能学习」拆掉这两个前提：技能不是抽象动作集，而是特定身体在感知-动作闭环中习得的能力；「会」不是布尔值，而是经验有限、身体可变、可供性可能被虚假相关劫持的统计命题。核心矛盾：**H22 具身缺口**——源身体上覆盖良好的技能，在目标身体的关节限位/力矩/延迟下覆盖集收缩，而 `Λ_S·Δ_B` 未被旧证书计价；**H23 能力幻觉**——点估计成功率高不等于置信下界高，少量成功被误读为「学会」；**H24 可供性幻觉**——技能可能依赖颜色/纹理等虚假相关而非真实可供性，分布外物体上断崖；**H25 干扰累积**——技能库越大，顺序学习带来的遗忘与负迁移越强，组合证书不闭合。

## 0. 直觉与动机

**灵感 1（具身智能 → 身体不是坐标系，而是能力的边界条件）**
直觉：同一个「抓取」技能在人形灵巧手、二指夹爪、三指欠驱动手上，可行动作集完全不同。第 54 轮的 `α_S : A→[0,1]` 把身体隐式固定，导致「仿真覆盖率 95%」在真机上可能只剩 60%：动作仍然「可执行」，但成功概率已经塌了。具身智能要求把身体参数 β 显式提进证书——`α_S(a|β)`——并给出身体变化下的敏感度 `Λ_S` 与迁移差距 `d_emb`。技能由此从点集变成 **以身体为参数的能力族**。关键区分：`α_S` 度量的是 **可执行性（feasibility）**，不是 **能力（competence）**；旧证书把前者误当成了后者。

**灵感 2（技能学习 → 「会」是一个带置信区间的统计量）**
直觉：技能从 N 次交互中学到，成功率点估计 `\hat c` 天然过乐观，尤其在「小样本 + 目标身体与训练身体不同分布 + 环境非平稳」时。技能学习不是「训练完就拥有」，而是 **经验 → 能力曲面的估计**。因此部署前必须用置信下界 `c^-` 而不是均值，并显式计入经验覆盖系数 `C(D)`：数据没覆盖到的身体/物体区域，LCB 自动变低。这把「技能学习」从一次训练事件变成一份 **可持续更新的统计证书**。

**灵感 3（可供性接地 → 区分「真会」与「碰巧会」）**
直觉：一个策略在训练物体上成功，可能因为它抓住了「红色=可抓」的虚假相关，而非「形状/质量/摩擦允许抓」。只优化任务成功率的技能学习会系统性奖励虚假相关。引入可供性谓词 `Φ` 与反事实测试：对同一物体做 `do(φ=1)` 与 `do(φ=0)`，真实技能的成功率应随可供性单调变化。接地残差 `r_aff` 与反事实一致性 `κ_cf` 是「真会」的可证伪证据，而不只是又一层分数。

**灵感 4（技能干扰 → 组合证书必须对遗忘闭合）**
直觉：顺序学习技能 B 会覆盖或漂移技能 A 的表征，产生灾难性遗忘；A、B 单独都可部署，不代表 `A⊗B` 可部署。用干扰矩阵 `I_{i←j}` 度量「学 j 后 i 掉了多少」，并要求次可加预算 `Σ I ≤ Θ_I`。这把组合从「两两兼容」升级为 **库级保持**：技能库越大，越要证明没有互相踩踏。

**灵感 5（主动具身标定 → 用信息增益买置信，而不是用更多数据碰运气）**
直觉：与其被动堆数据，不如让边端主动选择最能区分身体参数、最能降低能力方差的探针动作。采集函数取互信息与方差缩减的组合，把有限真机预算花在证书最不确定的方向上。这是「技能学习」从被动拟合转向 **主动实验** 的转折；也解释了为什么具身智能的样本效率本质上来自「会设计实验」。

**灵感 6（云边闭环 → 具身反例回传与可部署域重规划）**
直觉：第 54 轮是「云端粗规划-边端细校验-Explain 回传」。本轮把回传内容升级为 **具身反例三元组 `(β*, o*, φ*)`**：哪个身体参数、哪个物体、哪个可供性假设导致失败。云端据此重选技能或收缩可部署域 `Dom_S`；边端用主动探针更新 `c^-` 与 `r_aff`。闭环目标不是「一次规划成功」，而是 **可部署域与经验不确定性的单调收敛**。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（具身包络与具身条件剖面）**
身体参数 `β ∈ B ⊆ R^d`（关节限位、力矩上限、连杆长度、传感噪声、控制延迟）。技能 `S` 的具身包络
```
Emb(S) = {(a,β) | feas_S(a,β)=1},   α_S(a|β) = P(a 可执行 | β, S)
```
具身敏感度 `Λ_S = sup_{β≠β'} ||α_S(·|β) − α_S(·|β')||_TV / d_B(β,β')`，具身迁移差距 `d_emb(S,β_s,β_t) = sup_a |α_S(a|β_s) − α_S(a|β_t)|`。在 Lipschitz 包络假设下有 `d_emb ≤ Λ_S·d_B(β_s,β_t)`。**注意**：`Emb` 只刻画「做不做得到」，不刻画「做得好不好」。

**定义 122（经验集、能力曲面与置信下界）**
技能学习经验 `D_S = {(β_i, o_i, a_{0:T}^{(i)}, y_i)}_{i=1}^N`，`y_i∈{0,1}` 为任务成功。能力曲面 `c_S(β,o) = E[y | β,o,S]`。经验覆盖系数 `C(D_S) = sup_{β,o} dP_target(β,o)/dP_{D_S}(β,o)`。以重要性权重 `w_i = dP_target/dP_{D_S}(β_i,o_i)` 定义有效样本量 `N_eff = (Σw_i)² / Σw_i²`，置信下界
```
c_S^-(β,o) = \hat c_S(β,o) − rad(δ, N_eff) − ε_model,
rad(δ,N_eff) = sqrt( ln(2/δ) / (2·N_eff) )
```
`ε_model` 为能力曲面模型误配项。`c_S^-` 是部署门槛，`\hat c_S` 不是。

**定义 123（可供性接地残差与反事实一致性）**
可供性谓词集 `Φ`（可抓、可支撑、可开、可推）。技能诱导的隐式可供性 `φ_S : O×Φ → [0,1]`，环境真值 `φ* : O×Φ → {0,1}`（由物理验证器给出）。接地残差
```
r_aff(S,o) = sup_{φ∈Φ} | φ_S(o;φ) − φ*(o;φ) |
```
反事实一致性 `κ_cf(S,o) = min_{φ∈Φ} [ (P(y|do(φ=1)) − P(y|do(φ=0))) · (2φ*(o,φ)−1) ]`。`κ_cf ≥ 0` 表示技能响应可供性的方向正确；`κ_cf < 0` 是虚假相关的直接证据（技能看到 φ 消失反而更成功）。

**定义 124（技能干扰矩阵与库级保持）**
对技能库 `L` 与学习顺序 `σ`，学 `S_j` 后 `S_i` 的能力退化 `I_{i←j} = max(0, c_{S_i}^{before} − c_{S_i}^{after})`。组合干扰满足次可加假设 `I(A) ≤ Σ_{i,j∈A} I_{i←j}`。库级保持度 `R(L) = min_i c_{S_i}`，干扰预算 `Θ_I`。

**定义 125（具身技能可部署域与证书）**
```
Dom_S = { (β,o) : d_B(β,β_s) ≤ Δ_B ∧ c_S^-(β,o) ≥ 1−ε ∧ r_aff(S,o) ≤ ρ_aff
               ∧ κ_cf(S,o) ≥ 0 ∧ Σ I ≤ Θ_I }
J_E(S) = (Emb(S), α_S(·|β), c_S^-, r_aff, κ_cf, I_{·←·}, Dom_S, evidence)
```
`evidence` 至少含：主动探针日志、能力 LCB 校准记录、反事实可供性测试回放、干扰矩阵测量轨迹。`J_E` 与第 54 轮 `J` 的关系是 **合取**：`J` 管「动作/云边对齐」，`J_E` 管「身体/经验/可供性接地」。

**定义 126（主动具身标定采集函数）**
探针策略 `π_p` 在预算 `N_p` 下选择 `(a,β)` 最大化
```
A(a,β) = I(β; y | a,β) + λ_var·Var[c_S(β,·)] + λ_info·H[φ* | o,β]
```
第一项降低身体参数后验熵，第二项降低能力估计方差，第三项降低可供性真值的不确定性。在平滑性假设下，后验方差以 `O(1/N_p)` 速率下降。

**定义 127（具身技能组合规划）**
给定任务物体 `o_T`、任务动作序列 `A_T` 与目标身体 `β_t`，在技能组合图 `G_S`（第 54 轮定义 117）上求
```
σ* = argmin_σ  w_e·d_emb + w_c·(1−c^-) + w_aff·r_aff + w_I·ΣI + w_54·cost_align
s.t.  ∀S_i∈σ: β_t∈Dom_S,  compat(S_i,S_{i+1}) ≥ θ_a,  ΣI ≤ Θ_I
```
输出带 `J_E(σ) = (J_E(S_1),…,J_E(S_k); I(σ), D_σ)` 的组合证书。

**定义 128（具身-经验闭环）**
云边闭环 `L_E = (P_c, Check_E, Probe, Replan)`：云端计划 `P_c`；边端检查 `Dom_S`；失败时回传具身反例 `(β*,o*,φ*)`；边端在 `(β*,o*,φ*)` 附近主动探针；云端按反例收缩 `Dom_S` 或替换技能。若 `N_p` 有界且 `c^-`、`r_aff` 的估计器一致，则 `Dom_S` 单调收缩并在有限步内稳定。

## 2. 关键算法 伪代码

### IP-121 EEC（Embodiment Envelope Calibration）

```python
def embodiment_envelope(skill, beta_grid, probe_fn, budget):
    alpha, probes = {}, []
    for beta in beta_grid:
        for a in probe_fn(beta, budget // len(beta_grid)):
            y = embodied_rollout(skill, a, beta)
            alpha[(a, beta)] = y.executable
            probes.append((a, beta, y))
    Lambda = estimate_lipschitz(alpha, beta_grid, metric=d_B)
    d_emb = lambda bt: max(abs(alpha.get((a,bs),0)-alpha.get((a,bt),0))
                           for a in action_grid)
    return EmbProfile(alpha, Lambda, d_emb, probes)
```

### IP-122 CLC（Competence LCB Certificate）

```python
def competence_lcb(D_S, beta_t, o_t, delta=0.05):
    w = [importance_weight(beta_i, o_i, beta_t, o_t)
         for (beta_i, o_i, _, _) in D_S]
    N_eff = sum(w)**2 / max(sum(wi*wi for wi in w), 1e-12)
    c_hat = weighted_mean([y for *_, y in D_S], w)
    rad = sqrt(log(2/delta) / (2*N_eff))
    return c_hat - rad - model_misspecification(D_S, beta_t, o_t)
```

### IP-123 AGC（Affordance Grounding Check）

```python
def affordance_grounding(skill, objects, verifier, rollouts):
    r_aff, kappa = 0.0, +inf
    for o in objects:
        for phi in PHI:
            p1 = success_rate(skill, o, do(phi, 1), rollouts)
            p0 = success_rate(skill, o, do(phi, 0), rollouts)
            truth = verifier(o, phi)              # phi* ∈ {0,1}
            r_aff = max(r_aff, abs(induce_phi(skill, o, phi) - truth))
            kappa = min(kappa, (p1 - p0) * (2*truth - 1))
    return r_aff, kappa
```

### IP-124 SIM（Skill Interference Matrix）

```python
def interference_matrix(skills, order, eval_fn):
    C = {s.id: eval_fn(s) for s in skills}
    I = {}
    for j in order:
        learn(skills[j])
        for i in skills:
            if i.id == j: continue
            c_new = eval_fn(i)
            I[(i.id, j)] = max(0.0, C[i.id] - c_new)
            C[i.id] = c_new
    return I, min(C.values())          # 干扰矩阵 + 库级保持度 R
```

### IP-125 ESA（Embodied Skill Assembly）

```python
def embodied_skill_assembly(task, G, beta_t, budgets):
    best = None
    for path in k_shortest_paths(G, task.goal, k=K):
        if not all(beta_t in Dom_S[s] for s in path):      continue
        if any(compat(s1, s2) < theta_a
               for s1, s2 in zip(path, path[1:])):         continue
        if sum(I[(s1.id, s2.id)] for s1, s2 in pairs(path)) > budgets.Theta_I:
            continue
        cost = sum(cost_emb(s, beta_t) for s in path) + handoff_cost(path)
        if best is None or cost < best[0]:
            best = (cost, path)
    return best
```

### IP-126 APB（Active Probing Budget）

```python
def active_probe(skill, B, N_p, posterior):
    D = []
    for t in range(N_p):
        (a, beta) = argmax((a, beta)
            for a in action_grid for beta in B
            if mutual_info(beta, y, a, posterior)
               + lam_var * competence_var(beta, posterior)
               + lam_info * affordance_entropy(beta, posterior))
        y = embodied_rollout(skill, a, beta)
        posterior.update(a, beta, y); D.append((a, beta, y))
    return D
```

### IP-127 ESLC（Embodied Skill Learning Certificate）

```python
def embodied_skill_certificate(skill, beta_t, D_S, budgets):
    emb = embodiment_envelope(skill, local_grid(beta_t), probe_fn, budgets.N_p)
    if d_emb(emb, beta_t) > budgets.Delta_B:        return reject('embodiment_gap')
    lcb = competence_lcb(D_S, beta_t, o=task_object)
    if lcb < 1 - budgets.eps:                       return reject('competence_lcb')
    r_aff, kappa = affordance_grounding(skill, budgets.objects, verifier, budgets.R)
    if r_aff > budgets.rho_aff or kappa < 0:        return reject('affordance_grounding')
    if interference(skill) > budgets.Theta_I:       return reject('interference')
    return accept(J_E(emb, lcb, r_aff, kappa, D_S, beta_t))
```

### IP-128 ELC（Embodied Loop Closure）

```python
def embodied_loop(P_c, beta_t, budgets):
    while not budgets.exhausted():
        verdict, certs = edge_check(P_c, beta_t)       # 逐技能检查 J_E
        if verdict == 'ok':      return ('ok', certs)
        beta_s, o_s, phi_s = verdict.counterexample     # 具身反例三元组
        D_probe = active_probe(nearest_skill(P_c), nbhd(beta_s), budgets.N_p)
        Dom_S = shrink_domain_monotone(Dom_S, beta_s, o_s, phi_s)
        D_S.update(D_probe)
        P_c = cloud_replan(P_c, Dom_S, counterexample=(beta_s, o_s, phi_s))
    return ('reject', 'budget_exhausted')
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| EEC | `O(|B|·|A|·T_roll)` | `O(|B|·|A|)` | 探针覆盖、`Λ_S` 估计上下界 |
| CLC | `O(N·d)` | `O(N)` | 覆盖系数有限、权重可算、LCB 覆盖 |
| AGC | `O(|O|·|Φ|·R·T_roll)` | `O(|O|·|Φ|)` | 反事实可干预、验证器可靠 |
| SIM | `O(|L|²·T_eval)` | `O(|L|²)` | 学习顺序可复现、干扰次可加 |
| ESA | `O(K·|V| log|V| + |L|²)` | `O(|V|+|E|)` | 路径枚举完备、预算闭合 |
| APB | `O(N_p·|A|·|B|·T_roll)` | `O(N_p)` | 采集函数可算、后验校准 |
| ELC | `O(N_loop·(T_check+N_p·T_roll))` | `O(|D_S|+|Dom_S|)` | `Dom_S` 收缩单调、反例有界 |

**命题（覆盖-能力分离）**
存在技能 `S` 与目标身体 `β_t`，使第 54 轮证书通过（`cover(S,A_T) ≥ θ_cov`、`compat ≥ θ_a`、`δ_a ≤ Θ_a`），但 `c_S^-(β_t,o) < 1−ε`。构造：令技能的成功依赖源身体特有的力矩/延迟补偿；目标身体的这些参数落在包络外，动作仍「可执行」（`α_S` 不变）但成功率下降。因此 **`α_S` 是可行域，`c_S` 是能力域，二者在具身条件下解耦**，旧证书不能推出新证书。

**正确性定理（Embodied Skill Deployability Soundness）**
承接第 54 轮 (A22)–(A28)；新增：
**(A29)** 目标身体 `β_t` 满足 `d_B(β_t,β_s) ≤ Δ_B`，且 `Λ_S` 为包络的真实 Lipschitz 上界；
**(A30)** 能力 LCB 在覆盖系数 `C(D_S) ≤ C_max` 下以 `1−δ` 覆盖真值；
**(A31)** 可供性验证器 `φ*` 可靠，反事实干预满足单调性；
**(A32)** 技能干扰次可加，`I(A) ≤ Σ I_{i←j}`；
**(A33)** 第 54 轮组合兼容与云边对齐成立。
则组合部署失败概率满足
```
P_fail ≤ (1 − c_S^-) + Λ_S·Δ_B + r_aff + max(0, −κ_cf) + Σ I_{i←j} + β_E + δ
```
其中 `β_E` 为第 54 轮残余。若右端 `≤ ε_tot`，则 `J_E` 签发的组合达到目标成功率 `1−ε_tot`。关键：**旧证书的 `α_S` 只保证「可执行」，新证书的 `c^-` 才保证「会」；身体、经验、可供性三项必须同向闭合。**

## 4. 实验设计 E162–E168

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 具身包络准确度 | 预测可行集 vs 真机可行集 IoU；`Λ_S` 误差 | IoU ≥ 0.90，Λ 误差 ≤ 15% |
| E163 能力 LCB 校准 | 名义 95% 区间的经验覆盖率、ECE | 覆盖率 ∈ [92%, 98%]，ECE ≤ 0.03 |
| E164 可供性接地 | `r_aff` 与 OOD 成功率的秩相关；反事实检出率 | `|ρ_Spearman| ≥ 0.6`，虚假技能检出 ≥ 85% |
| E165 干扰矩阵 | 顺序学习后库级保持度 `R(L)`；组合成功率 vs `ΣI` | `R` 下降可被 `ΣI` 解释 `R² ≥ 0.8` |
| E166 主动标定效率 | 达到 `c^- ≥ 1−ε` 所需真机样本数 | 较随机采样减少 ≥ 40% |
| E167 覆盖-能力分离验证 | 旧证书通过但新证书拒绝的技能对，真机失败率 | 旧证书组失败率高出 ≥ 2× |
| E168 云边具身闭环 | 反例回传后 `Dom_S` 收缩速度、震荡次数 | 收缩单调率 ≥ 90%，震荡 ≤ 2 次/任务 |

**关键消融**：E167 是本轮的核心证伪实验。若旧证书通过的技能对在新证书下被拒、且真机失败率显著更高，则「覆盖-能力分离」成立；若两者失败率无差异，则本轮新增的具身/经验/可供性维度是冗余的，应回退到第 54 轮。

## 6. 本轮最大风险

**一句话**：本轮把「会不会」拆成具身包络、经验置信与可供性接地三层，但三者共用同一份有限且非平稳的交互经验；最大风险是身体参数漂移与经验分布漂移同时发生时，`Λ_S·Δ_B`、`c^-` 与 `r_aff` 会一起过度自信，把「在旧身体上学会的偶然成功」误证成「在新身体上可部署的技能」——因此必须用在线漂移检测、探针预算硬约束和「旧证书通过但新证书拒绝」的绊线作为总闸，宁可少签发，不可把具身幻觉当成部署前提。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（EEC×CLC×AGC×SIM×ESA×APB×ESLC×ELC）

> 承接第 54 轮产物 v31（GroundEdge-GenSim+++）。第 54 轮用 `α_S` 解决「动作空间覆盖」、用 `J` 解决「云边对齐」，但仍把身体当固定坐标系、把技能当已完成的学习结果。本轮引入 **具身智能 × 技能学习**，把证书从「动作-鲁棒性双证书」升级为 **体-经验-可供性三证书**：

### IP-121 EEC

```python
def embodiment_envelope(skill, beta_grid, probe_fn, budget):
    alpha, probes = {}, []
    for beta in beta_grid:
        for a in probe_fn(beta, budget // len(beta_grid)):
            y = embodied_rollout(skill, a, beta)   # 真机/高保真仿真
            alpha[(a, beta)] = 1.0 if y.executable else 0.0
            probes.append((a, beta, y))
    Lambda = estimate_lipschitz(alpha, beta_grid, metric=d_B)
    # 用区间上界避免欠采样低估敏感度
    Lambda_ub = upper_confidence_lipschitz(alpha, beta_grid, delta=0.05)
    return EmbProfile(alpha, Lambda_ub, probes)
```

### IP-122 CLC

```python
def competence_lcb(D_S, beta_t, o_t, delta=0.05):
    w = [density_ratio(beta_i, o_i, beta_t, o_t)
         for (beta_i, o_i, _, _) in D_S]
    N_eff = sum(w) ** 2 / max(sum(wi * wi for wi in w), 1e-12)
    c_hat = sum(wi * y for wi, (_, _, _, y) in zip(w, D_S)) / max(sum(w), 1e-12)
    rad = sqrt(log(2 / delta) / (2 * N_eff))
    return c_hat - rad - model_misspecification(D_S, beta_t, o_t)
```

### IP-123 AGC

```python
def affordance_grounding(skill, objects, verifier, rollouts):
    r_aff, kappa = 0.0, float('inf')
    for o in objects:
        for phi in PHI:
            p1 = success_rate(skill, o, do(phi, 1), rollouts)
            p0 = success_rate(skill, o, do(phi, 0), rollouts)
            truth = int(verifier(o, phi))
            r_aff = max(r_aff, abs(induce_phi(skill, o, phi) - truth))
            kappa = min(kappa, (p1 - p0) * (2 * truth - 1))
    return r_aff, kappa
```

### IP-124 SIM

```python
def interference_matrix(skills, order, eval_fn):
    C = {s.id: eval_fn(s) for s in skills}
    I, R = {}, float('inf')
    for j in order:
        learn(skills[j])
        for i in skills:
            if i.id == j: continue
            c_new = eval_fn(i)
            I[(i.id, j.id)] = max(0.0, C[i.id] - c_new)
            C[i.id] = c_new
        R = min(R, min(C.values()))
    return I, R
```

```python
def embodied_skill_assembly(task, G, beta_t, budgets):
    best = None
    for path in k_shortest_paths(G, task.goal, k=budgets.K):
        if not all(beta_t in Dom[s] for s in path):                    continue
        if any(compat(s1, s2) < theta_a
               for s1, s2 in zip(path, path[1:])):                     continue
        if sum(I.get((s1.id, s2.id), 0.0)
               for s1, s2 in pairs(path)) > budgets.Theta_I:           continue
        cost = (sum(cost_emb(s, beta_t) for s in path)
                + handoff_cost(path) + budgets.w_54 * align_cost(path))
        if best is None or cost < best[0]:
            best = (cost, path)
    return best
```

def active_probe(skill, B, N_p, posterior):
    D = []
    for _ in range(N_p):
        a, beta = max(((a, beta)
                      for a in action_grid for beta in B),
                      key=lambda x: mutual_info(x, posterior)
                                    + lam_var * competence_var(x, posterior)

### IP-127 ESLC

```python
def embodied_skill_certificate(skill, beta_t, D_S, budgets):
    emb = embodiment_envelope(skill, nbhd(beta_t), probe_fn, budgets.N_p)
    if d_emb(emb, beta_t) > budgets.Delta_B:            return reject('embodiment_gap')
    lcb = competence_lcb(D_S, beta_t, budgets.task_object)
    if lcb < 1 - budgets.eps:                           return reject('competence_lcb')
    r_aff, kappa = affordance_grounding(skill, budgets.objects,
                                        budgets.verifier, budgets.R)
    if r_aff > budgets.rho_aff or kappa < 0:            return reject('affordance_grounding')
    if interference_bound(skill) > budgets.Theta_I:     return reject('interference')
    return accept(J_E(emb, lcb, r_aff, kappa, D_S, beta_t, budgets.evidence))
```

def embodied_loop(P_c, beta_t, budgets):
    seen = set()
    while not budgets.exhausted():
        verdict, certs = edge_check(P_c, beta_t)        # 逐技能 J_E

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| EEC | `O(|B|·|A|·T_roll)` | `O(|B|·|A|)` | 探针覆盖 ≥ 95%，`Λ_S` 取上界 |
| CLC | `O(N·d)` | `O(N)` | 覆盖系数有限，LCB 经验覆盖 ≥ 1−δ |
| AGC | `O(|O|·|Φ|·R·T_roll)` | `O(|O|·|Φ|)` | 反事实可干预，`κ_cf` 符号可判 |
| SIM | `O(|L|²·T_eval)` | `O(|L|²)` | 学习顺序可复现，干扰次可加 |
| ESA | `O(K·|V|log|V| + |L|²)` | `O(|V|+|E|)` | 路径枚举 + 预算闭合 |
| APB | `O(N_p·|A|·|B|·T_roll)` | `O(N_p)` | 采集函数可算，后验方差单调降 |
| ESLC | `O(EEC+CLC+AGC+SIM)` | `O(|A|+|D_S|+|L|²)` | 四道门全过才签发 |
| ELC | `O(N_loop·(T_check+N_p·T_roll))` | `O(|D_S|+|Dom_S|)` | `Dom_S` 单调收缩，反例去重防震荡 |

**命题（覆盖-能力分离，可证伪）**
存在技能 `S` 与目标身体 `β_t`，使 v31 的 `J` 通过（`cover ≥ θ_cov`、`compat ≥ θ_a`、`δ_a ≤ Θ_a`），但 `c_S^-(β_t,o) < 1−ε`。直觉构造：技能成功依赖源身体特有补偿；目标身体参数改变后动作仍「可执行」，但成功率下降。故 **v31 的 `α_S` 是可行域，v32 的 `c^-` 才是能力域**，旧证书不能推出新证书。这是 E167 的直接检验对象。

**正确性定理（Embodied Skill Deployability Soundness）**
假设 (A22)–(A28) 承接第 54 轮；新增：
**(A29)** `d_B(β_t,β_s) ≤ Δ_B` 且 `Λ_S` 为真实 Lipschitz 上界；
**(A30)** 在 `C(D_S) ≤ C_max` 下 `c_S^-` 以 `1−δ` 覆盖真值；
**(A31)** 可供性验证器可靠且反事实单调；
**(A32)** 干扰次可加 `I(A) ≤ Σ I_{i←j}`；
**(A33)** 第 54 轮组合兼容与云边对齐成立。
则
```
P_fail ≤ (1 − c_S^-) + Λ_S·Δ_B + r_aff + max(0, −κ_cf) + Σ I_{i←j} + β_E + δ
```
若右端 `≤ ε_tot`，则 `J_E` 签发的组合达到成功率 `1−ε_tot`。**证略**：对五个失败事件取并集界；EEC 给出 `d_emb ≤ Λ_S Δ_B`，CLC 给出能力事件，AGC 给出可供性事件，SIM 给出干扰事件，`β_E` 承接第 54 轮残余。

**单调性引理（ELC 收敛）**
若 `shrink_domain_monotone` 只按反例收缩且反例去重，则 `Dom_0 ⊇ Dom_1 ⊇ …`，在有限技能库与有限反例空间上必在 `≤ |Dom_0|` 步内稳定；若稳定时仍被拒，则返回 `reject` 而非继续震荡。
