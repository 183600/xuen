# 灵感驱动研究循环·新灵感第 1 轮；本轮灵感：「多模态融合」×「抓取规划」

> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v23 + IP-431–439（HDL / ACSC / DCSC / HPC-E / CFC++ / CESC / FSVC / IPAM / HPC-E+），上承 v22 分层 PGEV（P37 / P41 / P42）、v21 语义-规范层（SDC / CAC / DCL / GIC）、v20 联邦感知（PCA / CTS / CFC / HPC / CFCtrl）、v19（DCM / OGCC / CCV / DRS / OGC）与 v17（CLP / S2C / HCG / PSV / APS / AMC）。
> **本轮纪律**：**融合的可信度永远不超过其证据源的独立性；抓取不是取消碰撞约束，而是把"接触"变成一种有预算、可撤销、可审计的资源**。不推倒 v23：所有证书与单调链 `Exec_v23 ⊆ … ⊆ Exec_v18` 原样保留。本轮只做一件事：**把 v23 的"多模态计数共识"升级为"独立证据配额共识"，并把 v23 的"避碰安全"升级为"接触安全"——新增接触感知多模态融合层 CMFL，使"看见更多模态"不再等于"拥有更多证据"，使"伸手去抓"不再等于"打开自由空间"。**

## 0. 直觉与动机

### 灵感 1（多模态融合 → 融合的价值不是"更多模态"，而是"更多独立证据"）

**直觉。** v23 的 CFC+++ 把共识条件写成"模态数 ≥ 2 ∧ 计数 ≥ N-F"。这默认了"两个模态 = 两份独立证据"。但现实里两个模态经常**一起错**：同一块图像传感器同时供可见光与深度、同一份标定文件同时约束相机与手眼变换、同一个训练集让视觉与触觉分类器学到同一种偏置、同一条电源/时钟让它们同时掉线。此时"多模态一致"不是独立佐证，而是**相关错误的合唱**——投票数越多，越自信地错。多模态融合的第一性原理不是平均或投票，而是**独立佐证 (independent corroboration)**：只有当两份证据的**共同原因**被排除，它们的一致才真正降低后验风险。

**严谨定义（共同原因图与独立性配额）。** 设证据源集合 `S = {1,…,M}`，每个源对命题 φ 给出带校准误报界的布尔票 `s_i`：`P(s_i=1 ∧ ¬φ) ≤ α_i`。定义**共同原因图** `G_cc = (S, E_cc)`：`(i,j) ∈ E_cc` 当且仅当 i,j 共享一个已声明的故障原因（同传感器裸片、同标定文件哈希、同模型权重、同训练集版本、同电源/时钟、同通信链路、同物理共位）。`G_cc` 的**连通分量**构成**相关证据组**；组内按并集界 `α_g = min(1, Σ_{i∈g} α_i)` 折叠成**一个**超级证据源（组内相关，绝不重复计数）；组间只有在独立性声明成立时才视为**独立组**。定义**有效独立数** `k_eff = #独立组`。**独立性配额融合 (IQF)** 接受命题 φ 当且仅当：

```
IQF(φ) ≜ (∀ 独立组 g: 组内一致) ∧ (∀ 独立组 g,g': 组间一致)   # 结构：独立组全体同意
        ∧ (Σ_g α_g ≤ α_target)                               # 数值：跨组并集界（对任意相关都成立）
        ∧ (k_eff ≥ k_min)                                    # 配额：独立证据组数达标
```

**关键定理式观察。** 数值保证**永远只用并集界** `1 - Σ_g α_g`，它对任意（甚至完全相关的）组间依赖都成立；独立性只用来**决定"谁算一张票"（结构）**，从不用来把并集界换成更乐观的乘积界。于是：**独立性声明错了，最坏也只是把本可更乐观的置信度保持在保守值，而不会产生虚假的高置信**——这与 v21/v23"失效向保守"的纪律同构。独立性真正买到的是**可检测性**：两个独立组若不一致，则至少一组错，这是一个相关组永远给不出的**错误信号**；因此 IQF 把"不一致"本身当作一等证据，触发**冲突弃权**。

**反直觉点。** 直觉是"多加一个模态总不亏"。但在相关结构下，多加一个**同源**模态会同时抬高表观票数、压低真实独立数、并可能把多数票推向错误方向——**更多的模态可能比更少但独立的模态更危险**。因此 CFC+++ 的"模态数 ≥ 2"必须替换为"**有效独立数 ≥ k_min**"。

### 灵感 2（抓取规划 → 抓取不是"取消避碰"，而是"为接触申请有预算的许可"）

**直觉。** 导航把接触当作失败，所以 v20–v23 的所有证书都在说"别碰"。抓取把接触当作**目标**：不碰就抓不起来。于是最诱人的错误做法是"抓取时把目标物体从障碍集里删掉"——这会**凭空创造自由空间**，直接击穿 `Exec_v24 ⊆ Exec_v23`。正确的做法是：**不删除障碍，而是给末端执行器申请一张"接触许可证"**——只在认证过的**接触流形**上、以有限的**穿透深度 / 接触力 / 滑移量**、在有限的**接触预算**内，允许末端进入物体边界；机器人其余连杆、底盘仍严格服从 v23。接触不是被释放的自由空间，而是被**消耗的、可撤销的资源**。

**严谨定义（接触许可证书 CPC 与接触预算）。** 物体 o 的位姿由 v21 SDC 给出认证集 `P_o = CertBox_o`（以 ≥1-δ 概率包含真位姿）。抓取 `g` 在物体表面指定**接触流形** `C_g(o) ⊆ ∂P_o`（如平行夹爪的两片对跖接触面）。定义**接触预算**（控制屏障式风险账户）：

```
B(t) = B_0 - ∫_0^t [ w_p·(pen(s)-ε_pen)_+ + w_f·(F(s)-F_max(c,R))_+ + w_s·|v_slip(s)|·1_slip + w_c ] ds
```

`B` 在一次抓取回合内**单调不增**，仅在退回认证的无接触态后重置为 `B_0`。**接触许可谓词**：

```
CPC(g,t) ≜ (EE_t ∩ Obs_t ⊆ inflate(C_g, ε_pen))       # 只碰认证接触面
         ∧ (pen(t) ≤ ε_pen)                           # 穿透有界
         ∧ (∀ 连杆 ℓ≠EE: ℓ_t ∩ Obs_t = ∅)             # 其余连杆仍避碰
         ∧ (F(t) ≤ F_max(class(o), 接触区))           # 语义力上限（来自 DCL 规则表）
         ∧ (B(t) ≥ B_min ≥ 0)                         # 预算未耗尽
```

**反直觉点。** 抓取的安全性不来自"绕开碰撞"，而来自"**把碰撞记进账本**"。把接触建模成**单调消耗的预算**，就得到一个 Lyapunov 式的安全裕度：任何穿透 / 超力 / 滑移都在扣预算，预算见底即**强制退回 v23 的纯运动计划**。于是"接触"永远是**可撤销**的——这正是把"新能力"接进"单调安全链"而不破坏它的钥匙。

### 灵感 3（统一：接触感知多模态融合层 CMFL）

**直觉。** 多模态融合与抓取规划在**接触点**上天然咬合：抓取恰恰是视觉（物体位姿 / 遮挡）、触觉（接触位置 / 压力）、力 / 力矩（抓取力 / 滑移）、本体感知（手指位形 / 电流）必须同时工作的地方；而接触又是**融合错误最不可挽回**的地方——导航里一次误判只多绕一圈，抓取里一次误判就是捏碎、掉落或打滑。两者的对偶关系是：**融合回答"接触状态是什么"，抓取回答"在这个接触状态下该做什么"**；前者决定后者的许可，后者的失败又反过来给前者提供标注。

**严谨定义（CMFL 与 HPC-C）。** 在 v23 之上新增**接触感知多模态融合层**，共享状态

```
ζ_cmf = ζ_v23 ∪ (G_cc, groups, k_eff, {α_g}, C_g, B(t), F_max, ε_r, ε_pen, slip_est, c_t, grasp_phase)
```

统一准入门 **HPC-C**：

```
HPC-C = HPC-E+
      ∧ IQF(关键接触命题：物体在位 ∧ 接触稳定 ∧ 位姿在 CertBox)
      ∧ CPC(g,t)
      ∧ RFC(g)                 # 认证位姿集上的 ε-鲁棒力封闭
      ∧ CSC(g)                 # 滑移探测时延 / 滑移位移有界
```

其中 `RFC` 要求抓取在**整个 CertBox** 上都保持力封闭裕度 ≥ ε_r（用 Lipschitz 界把位姿不确定性折成保守裕度）；`CSC` 要求滑移一旦发生，其**探测 + 反应窗口内的位移**不超过 `ε_slip` 且不触发附带碰撞。**安全继承按计划类分别成立**：纯运动计划 `Exec_v24^{motion} = Exec_v23^{motion} ∩ Fil_iqf ⊆ Exec_v23^{motion}`；抓取计划是新计划类，只有 `CPC ∧ RFC ∧ CSC` 全过才准入，且**任一失败即退回 v23 运动计划**（abort ∈ Exec_v23^{motion}）。自由空间投影上 `Free_v24 = Free_v23`：**接触没有增加任何自由空间，只增加了一条可撤销的约束**。

## 1. 研究问题（轮次升级版）

- **Q12（独立性的可认证性）**：共同原因图 `G_cc` 如何由设计期 FMEA（共享模型哈希 / 标定 / 训练集 / 电源 / 链路）与运行期残差相关发现共同构造？未建模的潜在共同原因如何用"保守并集界 + 动态加边"兜底？`k_min` 如何随任务风险等级自适应？
- **Q13（IQF 与 v23 的叠加）**：IQF 的组内折叠与组间并集界如何与 v23 CFC+++ 的 `N-F` 计数、v21 GIC 的 conformal α、APS 新鲜度阶梯叠加而不重复计票或互相抵消？冲突弃权如何映射为 DCL 的 O/F/P 状态迁移？
- **Q14（鲁棒力封闭的可计算性）**：如何在 `CertBox_o` 上认证 `min_p margin(g,p) ≥ ε_r`？Lipschitz 常数 L 如何由物体几何与接触雅可比给出可计算上界？采样 / 区间分析在什么条件下足以替代精确 min？
- **Q15（滑移与多速率融合）**：触觉 / 力 / 视觉 / 本体四路以不同频率与延迟到达，如何在不破坏 50Hz 控制环的前提下做接触状态融合？滑移探测时延 `τ_det` 的 conformal 上界如何校准？滑移位移 `Δ_slip` 如何与抓取高度 / 速度联动？
- **Q16（接触预算与单调安全）**：`B(t)` 的权重 `(w_p,w_f,w_s,w_c)` 如何标定使"正常抓取不误耗预算、异常接触快速见底"？预算耗尽 → 退回 v23 的切换如何避免振荡？语义力上限如何从 DCL 规则库版本化继承？

## 2. 设计原则（在 P37/P41/P42 基础上新增 P43–P46）

**P43 独立性配额融合律（Independence-Quorum Fusion）**
证据按共同原因图折叠为相关组；组内按并集界折叠为一张票，组间一致性才构成独立佐证。数值保证**只用跨组并集界** `1-Σ_g α_g`（对任意相关成立），独立性只用于**计票结构**与**冲突可检测性**。`k_eff < k_min` ⇒ 拒绝融合、退回保守单源 / 全不确定。故 CFC+++ 的"模态数 ≥ 2"升级为"**有效独立组数 ≥ k_min**"。

**P44 接触即预算律（Contact-as-Budget）**
抓取不删除任何障碍。接触许可只在认证接触流形 `C_g` 上、在 `pen ≤ ε_pen ∧ F ≤ F_max ∧ B(t) ≥ B_min` 下成立；`B(t)` 回合内单调不增，耗尽即退回 v23 纯运动计划。自由空间投影 `Free_v24 = Free_v23`，接触是**被消耗、可撤销**的资源而非新增自由空间。

**P45 认证位姿上的鲁棒力封闭律（Robust Force Closure over CertBox）**
抓取 `g` 必须对**整个** `CertBox_o` 满足力封闭裕度 `≥ ε_r`，用 Lipschitz 界 `margin(p) ≥ margin(p̂) - L·r_o` 把位姿不确定性折成保守裕度；无法认证则拒绝抓取或降级为"先重观测再抓"。语义力上限 `F_max(c,R)` 由 DCL 规则库给出，冲突取最严。

**P46 冲突即弃权律（Conflict ⇒ Abstention）**
两个**独立组**对关键接触命题不一致 ⇒ 至少一组错 ⇒ 立即弃权：不抬升、保持夹持力、请求重观测 / 重校准；弃权是 O-规则（有期限的存在性过滤：≤τ 内进入"安全保持"态），不是静默死锁。弃权状态机事件化接入 v17 APS 新鲜度阶梯，控制路径仅 O(1) 查询。

## 3. 与基线的接口（如何退化）

- 无共同原因图 / 独立性不可认证 ⇒ 全部源折叠为一个相关组 ⇒ 只有单源认证可靠时才可继续，否则弃权 ⇒ 等价 / 更保守于 v23；
- `k_eff < k_min` ⇒ IQF 拒证 ⇒ 退回 v23 CFC+++ 的计数共识（或更保守）⇒ 子集；
- CPC 失败（接触面越界 / 穿透超限 / 力超限 / 预算耗尽）⇒ 撤销接触许可，退回 v23 纯运动计划 ⇒ `Exec_v24^{motion} ⊆ Exec_v23^{motion}`；
- RFC 失败（CertBox 上力封闭裕度不足）⇒ 拒绝抓取或先重观测 ⇒ 不执行；
- CSC 失败（滑移时延 / 位移无界）⇒ 降速 / 降高度或拒绝抬升 ⇒ 不执行；
- IQF 冲突 ⇒ 弃权保持 ⇒ 不抬升；
- 全部失效 ⇒ 完全回退 v23 ⇒ `Exec_v24^{motion} ⊆ Exec_v23^{motion} ⊆ … ⊆ Exec_v18`。
- **安全继承**：融合只改"证据计票结构"不改"数值保证方向"；接触只增约束不增自由空间；任一失效向保守退化。DCL / GIC / IQF 状态机均以事件方式接入 v17 APS 新鲜度阶梯。

## 4. 预期贡献

1. **独立性配额融合**：首次把"多模态"从**模态计数**升级为**独立证据组计数**，给出对任意相关都成立的并集界与"冲突即可检测"的结构性论证，直接封堵 v23"相关模态合唱伪造共识"的风险面；
2. **接触预算证书**：把抓取接触形式化为单调消耗、可撤销的风险预算，证明 `Free_v24 = Free_v23` 且失败必退回 v23，使"接触"这一新能力接入单调安全链而不击穿它；
3. **CertBox 上的鲁棒力封闭**：给出位姿不确定集上的力封闭裕度认证与可计算 Lipschitz 界，把"抓得稳"从经验阈值变成带误差界的证书；
4. **滑移位移界**：给出探测时延 + 反应时延下的滑移位移上界，并与抓取高度 / 速度联动，使"掉了"也成为可审计的有界事件；
5. **接触感知多模态融合**：视觉 / 触觉 / 力 / 本体四路多速率融合 + 冲突弃权，把融合错误最不可挽回的接触环节变成"宁可不动"的 fail-closed 环节；
6. **HPC-C 统一准入门**：`HPC-E+ ∧ IQF ∧ CPC ∧ RFC ∧ CSC`，按计划类保持单调链与可撤销回退。

## 5. 本轮最大风险

**一句话**：共同原因图终究是人手声明的抽象，任何**未建模的共享故障源**（共享训练集偏置、同源对抗光照、共享标定漂移）都会把"独立组"重新耦合成相关合唱，使 IQF 的并集界与冲突检测同时失效——机器人会以"多路独立佐证"的自信，在一个系统性错误的接触状态上签发抓取许可。

## 0. 新增核心模块（在 IP-431–439 基础上扩展）

| 编号 | 名称 | 类型 | 关键改进（相对 MetricVoiceGauge-NCD-HUTDH-v23） |
|---|---|---|---|
| IP-440 | Common-Cause Certificate (CCC) | 独立性认证 | 由设计期 FMEA + 运行期残差相关共同构造共同原因图 `G_cc`，输出相关组与有效独立数 `k_eff`；组内折叠、组间独立 |
| IP-441 | Independence-Quorum Fusion (IQF) | 共识协议升级 | 用"独立组全体一致 + 跨组并集界 + `k_eff ≥ k_min`"替代 CFC+++ 的模态计数；冲突即弃权 |
| IP-442 | Contact Permission Certificate (CPC) | 接触许可 | 认证接触流形 `C_g` + 穿透 / 力 / 连杆 / 预算四约束；接触预算 `B(t)` 单调消耗、可撤销 |
| IP-443 | Robust Force Closure Certificate (RFC) | 抓取稳定性 | `CertBox_o` 上的 ε-鲁棒力封闭 + Lipschitz 保守界 + 语义力上限 `F_max(c,R)` |
| IP-444 | Contact-State Certificate (CSC) | 接触状态 / 滑移 | 视觉 / 触觉 / 力 / 本体多速率融合；滑移探测时延与位移上界；冲突弃权 |
| IP-445 | HPC-C (Contact-aware Unified Gate) | 统一准入门 | `HPC-E+ ∧ IQF ∧ CPC ∧ RFC ∧ CSC`；按计划类单调回退，抓取失败必退回 v23 运动计划 |

## 1. 关键算法骨架（在 IP-431–439 骨架上扩展）

```python
# ============================================================
# IP-440 Common-Cause Certificate (CCC) — 共同原因图与独立性认证
# ============================================================
from dataclasses import dataclass, field
from collections import defaultdict
import numpy as np

@dataclass
class EvidenceSource:
    sid: str
    modality: str
    alpha: float
    model_hash: str
    calib_hash: str
    dataset_hash: str
    power_rail: str
    clock_domain: str
    link: str
    location: tuple

class CommonCauseCertificate:
    """设计期 FMEA 声明 + 运行期残差相关发现，输出相关组与 k_eff。"""

    def __init__(self, sources: list[EvidenceSource], k_min: int = 2,
                 rho_dep: float = 0.8, window: int = 64):
        self.sources = {s.sid: s for s in sources}
        self.k_min = k_min
        self.rho_dep = rho_dep          # 残差相关超过该阈值即判为同源
        self.window = window
        self.adj: dict[str, set[str]] = defaultdict(set)
        self.residual_buf: dict[str, list[float]] = defaultdict(list)
        self._build_static_edges()

    def _build_static_edges(self):
        """共享模型/标定/训练集/电源/时钟/链路/共位 ⇒ 静态相关边。"""
        keys = ("model_hash", "calib_hash", "dataset_hash",
                "power_rail", "clock_domain", "link", "location")
        for key in keys:
            buckets = defaultdict(list)
            for s in self.sources.values():
                buckets[getattr(s, key)].append(s.sid)
            for ids in buckets.values():
                for i in range(len(ids)):
                    for j in range(i + 1, len(ids)):
                        self._add_edge(ids[i], ids[j])

    def _add_edge(self, a: str, b: str):
        self.adj[a].add(b)
        self.adj[b].add(a)

    def discover_online(self, residuals: dict[str, float]):
        """运行期：残差高度相关 ⇒ 发现未声明共同原因，动态加边（只会更保守）。"""
        for sid, r in residuals.items():
            buf = self.residual_buf[sid]
            buf.append(r)
            if len(buf) > self.window:
                buf.pop(0)
        ready = [sid for sid, b in self.residual_buf.items()
                 if len(b) == self.window]
        for i in range(len(ready)):
            for j in range(i + 1, len(ready)):
                a, b = ready[i], ready[j]
                rho = abs(np.corrcoef(self.residual_buf[a],
                                      self.residual_buf[b])[0, 1])
                if rho >= self.rho_dep:
                    self._add_edge(a, b)     # 只加不减：单调保守

    def groups(self) -> list[list[str]]:
        seen, out = set(), []
        for sid in self.sources:
            if sid in seen:
                continue
            comp, stack = [], [sid]
            seen.add(sid)
            while stack:
                u = stack.pop()
                comp.append(u)
                for v in self.adj[u]:
                    if v not in seen:
                        seen.add(v)
                        stack.append(v)
            out.append(sorted(comp))
        return out

    def group_alpha(self, group: list[str]) -> float:
        return min(1.0, sum(self.sources[s].alpha for s in group))

    def effective_independence(self) -> int:
        return len(self.groups())


# ============================================================
# IP-441 Independence-Quorum Fusion (IQF) — 独立证据配额共识
# ============================================================
class IndependenceQuorumFusion:
    def __init__(self, ccc: CommonCauseCertificate, alpha_target: float):
        self.ccc = ccc
        self.alpha_target = alpha_target

    def _fold_group(self, group, votes) -> tuple[bool | None, float]:
        """组内折叠：组内不一致 ⇒ 该组不确定；α_g 用组内并集界。"""
        alpha_g = self.ccc.group_alpha(group)
        vals = [votes[s] for s in group if s in votes]
        if not vals:
            return None, alpha_g
        if all(v == vals[0] for v in vals):
            return bool(vals[0]), alpha_g
        return None, alpha_g            # 组内冲突 ⇒ 不确定

    def fuse(self, per_source_votes: dict[str, bool]) -> dict:
        groups = self.ccc.groups()
        k_eff = len(groups)
        if k_eff < self.ccc.k_min:
            return {"verdict": "ABSTAIN", "reason": "insufficient_independence",
                    "k_eff": k_eff}

        folded, alphas = [], []
        for g in groups:
            claim, alpha_g = self._fold_group(g, per_source_votes)
            folded.append(claim)
            alphas.append(alpha_g)

        if any(c is None for c in folded):
            return {"verdict": "ABSTAIN", "reason": "intra_group_conflict",
                    "k_eff": k_eff}
        if len(set(folded)) > 1:
            # 独立组不一致 ⇒ 至少一组错 ⇒ 可检测冲突，弃权
            return {"verdict": "ABSTAIN", "reason": "cross_group_conflict",
                    "k_eff": k_eff}

        risk = sum(alphas)
        if risk > self.alpha_target:
            return {"verdict": "ABSTAIN", "reason": "risk_budget_exceeded",
                    "risk": risk, "k_eff": k_eff}
        # 数值保证只用并集界，对任意组间相关都成立
        return {"verdict": "ACCEPT" if folded[0] else "REJECT",
                "claim": folded[0], "risk": risk, "k_eff": k_eff}


# ============================================================
# IP-442 Contact Permission Certificate (CPC) — 接触许可与接触预算
# ============================================================
class ContactBudget:
    def __init__(self, B0: float, Bmin: float,
                 w=(1.0, 1.0, 1.0, 1e-3), eps_pen=0.002):
        self.B0, self.B, self.Bmin = B0, B0, Bmin
        self.w_p, self.w_f, self.w_s, self.w_c = w
        self.eps_pen = eps_pen

    def step(self, dt, pen, F, Fmax, v_slip, slip_flag):
        excess = (self.w_p * max(0.0, pen - self.eps_pen)
                  + self.w_f * max(0.0, F - Fmax)
                  + self.w_s * abs(v_slip) * (1.0 if slip_flag else 0.0)
                  + self.w_c)
        self.B -= excess * dt          # 回合内单调不增
        return self.B

    def ok(self) -> bool:
        return self.B >= self.Bmin

    def reset_on_retreat(self, no_contact: bool):
        if no_contact:                 # 仅退回认证无接触态才重置
            self.B = self.B0

class ContactPermissionCertificate:
    def __init__(self, budget: ContactBudget, eps_pen=0.002):
        self.budget = budget
        self.eps_pen = eps_pen

    def certify(self, ee_region, obs, contact_manifold, links, pen, F,
                Fmax, v_slip, slip_flag, dt) -> bool:
        from shapely.geometry import Polygon   # 示意：几何后端可替换
        allowed = contact_manifold.buffer(self.eps_pen)
        if not ee_region.difference(allowed).intersection(obs).is_empty:
            return False                       # 只允许碰认证接触面
        if pen > self.eps_pen:
            return False
        for link in links:                     # 其余连杆严格避碰
            if not link.intersection(obs).is_empty:
                return False
        if F > Fmax:
            return False
        self.budget.step(dt, pen, F, Fmax, v_slip, slip_flag)
        return self.budget.ok()

# IP-443 Robust Force Closure Certificate (RFC)
# ============================================================
class RobustForceClosure:
    def __init__(self, eps_r: float, lipschitz_L: float):
        self.eps_r = eps_r
        self.L = lipschitz_L

    def margin(self, grasp, pose) -> float:
        """原语力旋量 {w_j=(n_j, c_j×n_j)} 凸包到 0 的距离（示意）。"""
        wrenches = grasp.primitive_wrenches(pose)
        return convex_hull_distance_to_origin(wrenches)

    def certify(self, grasp, certbox) -> dict:
        p_hat, r_o = certbox.center, certbox.radius
        m0 = self.margin(grasp, p_hat)
        # Lipschitz 保守界：整个 CertBox 上的最坏裕度下界
        m_lb = m0 - self.L * r_o
        return {"admissible": m_lb >= self.eps_r,
                "margin_nominal": m0, "margin_lower_bound": m_lb,
                "radius": r_o}


# ============================================================
# IP-444 Contact-State Certificate (CSC) — 多速率融合与滑移界
# ============================================================
class ContactStateCertificate:
    def __init__(self, iqf: IndependenceQuorumFusion, tau_det: float,
                 eps_slip: float, v_max: float, a_max: float):
        self.iqf = iqf
        self.tau_det = tau_det          # conformal 1-β 上界
        self.eps_slip = eps_slip
        self.v_max, self.a_max = v_max, a_max

    def slip_displacement_bound(self, tau_react: float) -> float:
        T = self.tau_det + tau_react
        return self.v_max * T + 0.5 * self.a_max * T * T

    def fuse_contact_state(self, votes: dict[str, bool]) -> dict:
        return self.iqf.fuse(votes)     # 关键接触命题走独立配额融合

    def certify(self, grasp, contact_state: str, tau_react: float) -> bool:
        if contact_state == "uncertain":
            return False                # 弃权：不抬升
        if contact_state == "slipping":
            return False                # 滑移中不抬升，转 regrasp/abort
        bound = self.slip_displacement_bound(tau_react)
        return bound <= self.eps_slip


# ============================================================
# IP-445 HPC-C 接触感知统一准入门
# ============================================================
@dataclass
class HPCC:
    hpc_e_plus: "HPCEPlus"          # v23 四证门
    iqf: IndependenceQuorumFusion
    cpc: ContactPermissionCertificate
    rfc: RobustForceClosure
    csc: ContactStateCertificate

    def admits_motion(self, plan, *hpc_args) -> bool:
        if not self.hpc_e_plus.admits(plan, *hpc_args):
            return False
        return self.iqf.fuse(plan.critical_votes)["verdict"] == "ACCEPT"

    def admits_grasp(self, grasp_plan, *hpc_args) -> bool:
        if not self.hpc_e_plus.admits(grasp_plan, *hpc_args):
            return False
        if self.iqf.fuse(grasp_plan.critical_votes)["verdict"] != "ACCEPT":
            return False
        if not self.cpc.certify(grasp_plan.ee_region, grasp_plan.obs,
                                grasp_plan.contact_manifold, grasp_plan.links,
                                grasp_plan.pen, grasp_plan.F, grasp_plan.Fmax,
                                grasp_plan.v_slip, grasp_plan.slip_flag,
                                grasp_plan.dt):
            return False
        if not self.rfc.certify(grasp_plan.grasp, grasp_plan.certbox)["admissible"]:
            return False
        return self.csc.certify(grasp_plan.grasp, grasp_plan.contact_state,
                                grasp_plan.tau_react)


# ============================================================
# 端到端流水线：感知 → 融合 → 接触许可 → 执行
# ============================================================
class ContactAwarePipeline:
    def __init__(self, config):
        self.ccc = CommonCauseCertificate(config["sources"], config["k_min"])
        self.iqf = IndependenceQuorumFusion(self.ccc, config["alpha_target"])
        self.budget = ContactBudget(config["B0"], config["Bmin"])
        self.cpc = ContactPermissionCertificate(self.budget)
        self.rfc = RobustForceClosure(config["eps_r"], config["L"])
        self.csc = ContactStateCertificate(
            self.iqf, config["tau_det"], config["eps_slip"],
            config["v_max"], config["a_max"])
        self.hpc_c = HPCC(config["hpc_e_plus"], self.iqf,
                          self.cpc, self.rfc, self.csc)

    def step(self, sensor_data, plan):
        # 1. 运行期依赖发现：残差相关 ⇒ 动态加边（单调保守）
        self.ccc.discover_online(sensor_data["residuals"])

        # 2. 接触状态多速率融合（关键命题走 IQF）
        fused = self.csc.fuse_contact_state(sensor_data["contact_votes"])
        plan.contact_state = ("uncertain" if fused["verdict"] == "ABSTAIN"
                              else sensor_data["contact_state"])

        # 3. 按计划类准入
        if plan.kind == "motion":
            admitted = self.hpc_c.admits_motion(plan, *sensor_data["hpc_args"])
        else:
            admitted = self.hpc_c.admits_grasp(plan, *sensor_data["hpc_args"])

        # 4. 失败即退回 v23 运动计划（abort ∈ Exec_v23^{motion}）
        if not admitted and plan.kind == "grasp":
            self.budget.reset_on_retreat(no_contact=True)
            return False, {"fallback": "v23_motion_abort", "fused": fused}

        return admitted, {"fused": fused, "budget": self.budget.B,
                          "k_eff": self.ccc.effective_independence()}
```

## 3. 正确性论证

### 引理 5（IQF 在任意相关下的并集界可靠性）
**陈述**：对任意组间依赖结构，`IQF(φ)` 返回 ACCEPT 时 `P(ACCEPT ∧ ¬φ) ≤ Σ_g α_g`。

**证明**：
1. ACCEPT 要求每个独立组 g 折叠出 `s_g = 1`。若 `¬φ` 为真且仍 ACCEPT，则至少存在一个组 g 的组内票为假阳性（其"正确"意味着票与真值一致）。
2. 由测度的次可加性（并集界），`P(∃g 假阳性) ≤ Σ_g P(g 假阳性) = Σ_g α_g`，**无需任何独立性假设**。
3. `α_g = min(1, Σ_{i∈g} α_i)` 本身是组内并集界，对组内任意相关成立。
4. 故 `P(ACCEPT ∧ ¬φ) ≤ Σ_g α_g`；IQF 再要求 `Σ_g α_g ≤ α_target`。∎

> 关键：独立性从不进入数值界，只进入"组如何划分"和"冲突是否可检测"，因此对独立性声明的误判不会制造虚假高置信，最多损失乐观度。

### 引理 6（相关模态不能伪造配额）
**陈述**：若一组 m 个源共享任一已声明或已发现共同原因，则它们落在同一连通分量内，`k_eff` 不随 m 增大而增大；因此增加相关模态无法满足更高配额。

**证明**：共享原因 ⇒ 边相连 ⇒ 同一连通分量 ⇒ 折叠为一张票；`k_eff = #连通分量` 与分量内部源数无关。若运行期残差相关超阈，`discover_online` 只会**加边**，分量只会合并，`k_eff` 单调不增。∎

### 引理 7（冲突是可靠的错误指示）
**陈述**：若两个独立组对同一命题给出相反票，则至少一组错；因此冲突弃权不会在"全对"时误触发。

**证明**：若两组都正确，则二者票都等于真值，必相同；与相反矛盾。故相反 ⇒ 至少一组假阳性或假阴性。∎

### 引理 8（接触不创造自由空间，且失败必回退）
**陈述**：在 CPC 成立期间，除认证接触流形 `C_g` 外，机器人所有连杆与 v23 的自由空间约束一致；`Free_v24 = Free_v23`。当 CPC / 预算失败时，abort 计划属于 `Exec_v23^{motion}`。

**证明**：
1. CPC 要求 `∀ 连杆 ℓ≠EE: ℓ_t ∩ Obs_t = ∅`，与 v23 相同；EE 仅被允许进入 `inflate(C_g, ε_pen)`，且 `pen ≤ ε_pen`，未释放任何非接触自由空间。
2. 因此自由空间投影不变：`Free_v24 = Free_v23`；接触是附加约束而非删除障碍。
3. 预算 `B(t)` 回合内单调不增；`B < B_min` 时许可撤销，执行"退回无接触态"的 abort 计划，该计划不接触任何障碍，属于 v23 运动计划集。∎

### 引理 9（CertBox 上鲁棒力封闭的可靠性）
**陈述**：若 `margin(g,p̂) - L·r_o ≥ ε_r` 且真位姿 `p* ∈ P_o`（以 ≥1-δ 概率），则 `margin(g,p*) ≥ ε_r`（以 ≥1-δ 概率）。

**证明**：由 L-Lipschitz，`|margin(g,p*) - margin(g,p̂)| ≤ L·||p*-p̂|| ≤ L·r_o`，故 `margin(g,p*) ≥ margin(g,p̂) - L·r_o ≥ ε_r`。概率由 `p* ∈ P_o` 的 ≥1-δ 保证继承。∎

### 引理 10（滑移位移有界）
**陈述**：设滑移在 `t_s` 开始，探测 + 反应窗口 `T = τ_det + τ_react`，则窗口内物体位移 `Δ_slip ≤ v_max·T + ½·a_max·T²`；当该上界 ≤ `ε_slip` 且被持物仍位于安全保持区时，无附带碰撞。

**证明**：对速度 `v(t) ≤ v_max + a_max(t-t_s)` 在 `[t_s, t_s+T]` 上积分得上界；`τ_det` 由 conformal 给出 1-β 上界，故以 ≥1-β 概率窗口不超时。若位移上界 ≤ ε_slip 且持物轨迹仍在安全保持区，则碰撞谓词恒假。∎

### 定理（HPC-C 的安全—稳定—可撤销完备性）
**陈述**：设各证书覆盖事件分别为 `E_iqf (1-α_target)`、`E_pose (1-δ)`、`E_det (1-β)`。若 `HPCC.admits_grasp(π)=True`，则以至少 `1-(α_target+δ+β)` 的概率同时满足：(1) 无**非认证**碰撞（引理 8）；(2) 全 CertBox 上 ε-鲁棒力封闭（引理 9）；(3) 滑移位移有界（引理 10）。且任一证书失败时 `abort(π) ∈ Exec_v23^{motion}`。

**证明**：由 `admits_grasp` 的五个连言条件与引理 5–10；概率由并集界合并三个覆盖事件。必要性：任一条件缺失即拒证，对应一类未被缓解的风险。充分性：五条件全满足时，接触仅发生在 `C_g`、抓取在全 CertBox 稳定、滑移有界，且失败路径回退 v23，构成闭环。∎

### 引理 11（按计划类的单调链）
**陈述**：`Exec_v24^{motion} = Exec_v23^{motion} ∩ Fil_iqf ⊆ Exec_v23^{motion}`；抓取计划为新类，`Exec_v24^{grasp} = GraspSafe_v24`，且 `abort(Exec_v24^{grasp}) ⊆ Exec_v23^{motion}`。故全局执行不会因引入抓取而击穿 v23 的运动安全。

**证明**：运动类多了一层 IQF 过滤，取交集必为子集；抓取类不是 v23 的子集（v23 不允许接触），因此不宣称其子集性，而由引理 8 证明其"不创造自由空间"并由定理保证其安全性；abort 为无接触运动计划，属于 v23。∎

## 6. 本轮最大风险（最终确认）

**一句话**：共同原因图终究是人手声明的抽象，任何**未建模的共享故障源**（共享训练集偏置、同源对抗光照、共享标定漂移）都会把"独立组"重新耦合成相关合唱，使 IQF 的并集界与冲突检测同时失效——机器人会以"多路独立佐证"的自信，在一个系统性错误的接触状态上签发抓取许可。
