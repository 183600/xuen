# 第 41 轮 · 两灵感落地 v8：证书缺口主动数据采集 × 深度见证几何 × 可认证数据资产（四层架构 v6）

> 承接第 40 轮（v17：可认证流匹配执行 × 度量语义几何锚定 × 证书驱动课程引擎，四层架构 v5）。本轮灵感词「数据采集、深度相机」并不指向又一个新模型，而指向 v17 最大软肋：**证书紧致性不是算出来的，是采出来的**。v17 的 L_v、κ、B_t、h_min 全部是有限数据上的估计；若采集与证书目标脱节，证书会永久松弛。本轮把数据采集升级为「以证书赤字为目标的实验设计」，把深度相机升级为「可自证的几何见证与近场数据源」，把数据集升级为「带覆盖与标签证书的资产」。

## 0. 直觉与动机

**灵感 1（数据采集 → 从数据管道到实验设计）**：第 40 轮把证书写成了活文档，但活文档需要持续的证据输入。随机采集或按任务均匀采集有一个隐蔽缺陷：大部分样本落在证书已经成立的“容易主体”上，而证书的紧致性由**接近违约边界的约束**决定。采一万条安全样本，不会让 h_min 的置信下界更紧；只有采到边界附近、且能区分“真安全”与“估计安全”的样本，才会。因此正确的问题不是“采多少数据”，而是“哪个观测最能缩小当前证书置信集在最紧约束上的宽度”。这是 Bayesian experimental design（最优实验设计），不是数据工程。它与第 40 轮课程引擎互补：课程选择“练什么任务”，主动采集选择“为证书补哪块证据”。

**灵感 2（深度相机 → 便宜、稠密、可自检的见证）**：LiDAR 给全局度量几何，但在操作近场（<1.5 m）稀疏、易被机械臂自遮挡，而这正是抓取/接触/避障最需要精度的地方。深度相机提供三件 LiDAR 难以替代的东西：a) 近场稠密深度 → 高分辨率 TSDF/ESDF，直接给 CBF 更真实的 clearance；b) RGB-D 示教的自动几何标注 → 从深度反投影与多视角一致性直接得到物体位姿、接触状态、间隙，减少人工标注；c) 跨模态见证 → 把 LiDAR 点投影到深度帧，残差超界说明至少一路在说谎，可在线证伪漂移或标定失效。但必须强调：**深度是见证者，不是神谕**。一致不能证明正确（玻璃/反光/粉尘可让两路同源失效），只有不一致能高置信地证伪；因此深度本身也要被标定、被 conformal 校准、被纳入证书。

**灵感 3（三者耦合 → 证书的证据闭环）**：主动采集决定“采什么证据”，深度相机提供“便宜且稠密的证据 + 运行时见证”，可认证数据资产让“证据可复用、可审计、可失效”。闭环是：IP-46 证书暴露当前最宽约束 → IP-51 计算 CIG 并选择采集动作 → IP-52 用深度做近场采集、自标注与跨模态见证 → IP-53 给数据分片发覆盖/标签证书 → IP-46 重颁证书 → 若见证冲突则触发主动视角或重采。这条闭环不是给 v17 再加一层，而是直接给 v17 的“证书紧致性”命门供血：不是用更好的数学硬证，而是用更对的证据把证书收紧。

**一句话直觉**：第 40 轮证明了“怎么执行、在哪执行、如何进化”；本轮补上“凭什么相信这些证明”——相信来自有针对性的证据，而证据本身也必须被认证。

## 1. 形式化定义

**定义 27（证书证据模型与认证赤字）**：设证书参数向量 θ = (L_v, κ, B_t, h_min, μ_max, ε_ode) ∈ Θ。给定证据集 D，维护 (1−δ) 置信集 Θ_δ(D)（bootstrap、Laplace 后验或 conformal 均可，只要满足 P(θ*∈Θ_δ(D)) ≥ 1−δ）。对第 i 条证书约束，定义认证边际与归一化赤字：

- m_i^cert(D) = inf_{θ∈Θ_δ(D)} m_i(θ)；
- d_i(D) = max(0, 1 − m_i^cert(D)/c_i)；
- 证书紧致度 T_w(D) = Σ_i w_i·d_i(D)（或 max_i w_i d_i）。

注意 T_w 是**数据质量的函数**，不是策略权重的函数；本轮优化对象从训练损失转为 T_w。

**定义 28（证书信息增益 CIG 与采集策略）**：采集动作 a（去哪、看哪个视角、执行哪个技能、施加哪种扰动/故障注入）有成本 c(a)>0，观测 y ~ P_a(·|θ*)。定义

- 信息型 CIG：CIG_info(a|D) = I(θ; y | D) / c(a)；
- 证书型 CIG：CIG_cert(a|D) = E_y[ T_w(D) − T_w(D∪{(a,y)}) ] / c(a)。

采集策略 π_acq 在预算 B、安全约束与课程带 τ∈[D_lo,D_hi] 下最大化 Σ CIG_cert，实际用 CIG_info 作可计算代理（线性高斯下二者由后验协方差单调关联）。**关键约束**：采集集与审计集必须分离——审计集不得参与 CIG 计算，否则会重演“用训练集证明训练集”的自证循环。

**定义 29（深度见证类型 C_dw 与见证残差）**：深度测量 z(u)=r(u)+e(u)，e(u)~N(0, σ_d²(r))（异方差，随距离增长）；反投影得 p_d(u)，与 LiDAR 地图在同一射线上的点 p_l(u) 比较，见证残差 ρ(u)=‖p_d(u)−p_l(u)‖。用独立标定集做 split-conformal，得阈值 τ_δ 使 P(ρ>τ_δ | 两路均有效) ≤ δ。定义

- C_dw = (φ_sem^depth, ESDF_near, ρ, τ_δ, V_d)，其中 V_d 为深度有效域（FOV、量程、反射率/透明度门控）；
- 见证状态 w(u)=consistent 当 ρ≤τ_δ，否则 conflict；
- 语义：consistent **不证明**正确，conflict 则以至少 1−δ 的置信证伪至少一路，必须触发降级或重采。

近场 clearance 证书采用见证门控规则：一致时用逆方差融合并减去 conformal 裕度；冲突时取两路单侧下界的较小者并标记冲突，触发 IP-51 主动视角。

**定义 30（可认证数据资产 DataCert）**：数据分片 X={x_j} 携带五元组

DataCert(X) = (Cov_ε, η_label, Rel, Prov, Audit)，

其中 Cov_ε 是任务相关条件空间上的 ε-覆盖证书（不是原始高维像素空间），η_label 是标签误差上界（conformal / 审计得到），Rel 是“该分片对哪些证书约束有收紧作用”的相关性映射（用影响函数或 Fisher 信息估计），Prov 是传感器标定与采集过程溯源，Audit 是独立审计记录。数据选择问题：在预算与覆盖约束下选子集，使 Σ Rel·CIG 最大且 Cov_ε ≤ ε。

**定义 31（采集-课程联合调度）**：第 t 轮选择 (τ, a) 解

max_{τ∈[D_lo,D_hi], a∈A(τ)} CIG_cert(a | τ, D_t) / c(a)
s.t. safe(a)（CBF/监护人约束）, Cov_ε(D_t ∪ a) 满足覆盖目标。

课程带给出“任务先验”，CIG 决定“任务内的证据动作”；两者不是竞争关系，而是“练什么”与“凭什么证”的分解。

**定理 6（预算采集的贪心近似）**：若给定 θ 后各次观测条件独立，则 I(θ; y_A) 关于观测集合 A 单调子模；预算约束下的贪心采集至少达到最优的 (1−1/e)/2，单位成本情形达到 (1−1/e)。证明要点：互信息的子模性 + 预算子模最大化的经典近似界。

**定理 7（深度见证的有限样本假警报控制与不可验证性）**：在标定集与运行数据可交换的假设下，split-conformal 阈值满足 P(ρ>τ_δ | 两路有效) ≤ δ；若深度偏差超过 τ_δ，冲突概率随样本数趋于 1。但即使 ρ≤τ_δ，也不能推出两路同时正确——共同失效（玻璃、镜面、粉尘）不在该检验的备择假设内。证明要点：conformal 的秩检验 + 反例构造。

**定理 8（覆盖与标签误差到证书的传播）**：若 X 是条件空间在任务相关度量下的 ε-覆盖，标签误差 ≤η，且 T_w 关于条件分布满足 L_T-Lipschitz（Wasserstein-1），则 |T_w(D_X) − T_w(D)| ≤ L_T(ε+η) + O(√(log(1/δ)/n))。证明要点：覆盖集上的 Lipschitz 延拓 + 标签误差三角不等式 + 有限样本集中。

## 2. 三大产出设计

### 2.1 IP-51 CERT-GAP-ACTIVE-ACQUISITION（证书缺口主动采集）
1. **证书置信集**：对六类边际分别维护 bootstrap/Laplace 后验；每次重颁证书时重新计算 m_i^cert 与 d_i，输出“当前最宽约束”给采集器。
2. **动作空间**：任务参数扰动、物体位姿/材质/光照、相机视角、接触模式、技能选择、受控故障注入；每个动作带时间/风险/人工成本，全部经过安全监护人过滤。
3. **CIG 估计**：线性层用 Fisher 信息闭式；非线性层用 ensemble 方差或影响函数；用加权 D-optimal（对角加权）把“证书相关性”注入信息矩阵。
4. **预算贪心 + 懒求值**：每步选 CIG 最高的安全动作；每采一批即更新置信集并检查课程带是否需要重定心。
5. **自证防护**：审计集冻结、不参与采集；每 K 轮用独立无偏通道复核最紧约束；检测到采集收益异常升高（典型 Goodhart 信号）即冻结该通道并降权。

### 2.2 IP-52 DEPTH-WITNESS-GEOMETRY（深度见证几何）
1. **深度噪声模型**：按传感器类型（ToF/结构光/双目）标定异方差 σ_d(r)；多帧/多视角平均降噪；对透明/镜面/低纹理像素输出无效标记，而不是硬猜深度。
2. **近场度量几何**：深度反投影 → TSDF/ESDF，在操作近场提供高分辨率 clearance；与 LiDAR 全局 ESDF 做“近场细、远场稳”的分层融合，避免全局地图被近场噪声污染。
3. **跨模态见证**：LiDAR 点投影到深度帧，计算 ρ；split-conformal 校准 τ_δ；冲突像素触发 IP-51 主动视角（换角度/换曝光/换模态），并把冲突区域从 ValidRegion 中暂时剔除。
4. **深度自标注**：多视角 RGB-D + 分割 → 物体 6D 位姿、接触/间隙、pre/post 几何谓词；用重投影一致性、物理可行性、跨视角一致性做三重过滤；不确定样本进入小规模人工审计队列。
5. **见证证书**：C_dw 随技能契约上报 Registry；路由/熔断增加“见证冲突”与“深度有效域”两个条件，扩展 IP-45 的触发器。

### 2.3 IP-53 CERTIFIED-DATA-ASSET（可认证数据资产）
1. **分片证书**：每个数据分片记录 Cov_ε、η_label、Rel、Prov、Audit；证书与策略证书通过 DataCert ID 绑定。
2. **任务相关覆盖**：只在低维任务流形（物体位姿、可抓取性、光照、遮挡、接触模式）上做 ε-net / 核覆盖；高维像素空间不做覆盖声明，避免“维度诅咒式假证书”。
3. **标签风险控制**：深度自标注给初值，conformal 给标签误差上界；人工审计只花在高不确定性/高证书相关性的样本上。
4. **数据选择与回放**：训练/蒸馏/回放权重 = Rel × CIG × 覆盖增益 / 成本；与 IP-50 课程带联合调度，避免“课程只挑难样本、却采不到能收紧证书的证据”。
5. **失效与重采**：标定漂移、分布漂移、见证冲突率上升 → DataCert 过期 → 策略证书降级 → 触发 IP-51 重采；形成“数据-证书”同生命周期。

## 3. 四层架构 v6

```
L0 证据层: IP-51 主动采集 + IP-52 深度见证/自标注 + IP-53 DataCert
           → 证书赤字 → CIG → 采集 → 审计 → 分片证书
L1: TRI-FUSE + LiDAR/深度语义融合 → 度量语义图 C_ms + 漂移界 B_t + 见证类型 C_dw
L2: CTC + VLM + IP-35 仲裁 → R_φ(w₁~w₆) + 几何残差证书 + 深度见证冲突标记
L3: IP-47 任务代数（C_ms/C_dw 类型检查）→ IP-39 规划（近场深度 ESDF/CBF）
    → IP-45 总线（区域化证书路由/见证冲突熔断）→ IP-48 认证流匹配执行
    → RCA 监控（流证书 + 几何证书 + 数据证书）
L4: IP-44 蒸馏 + IP-50 课程 + IP-51/53 数据闭环 → RCA 重颁证书 → 契约热更新
运行期: 证书赤字估计 + CIG 调度 + 深度近场 ESDF + 跨模态见证 + DataCert 版本/失效
```

## 4. 实验设计（E73-E78 硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E73 主动采集效率 | 达到同一证书紧致度所需样本/成本 vs 随机/不确定性采样 | 节省≥30%；达标率≥90% |
| E74 深度见证有效性 | 同覆盖率下 witness-gated 裕度 vs LiDAR-only；假警报率；粗差检出 | 裕度≤0.75×；假警报≤2%；检出≥45% |
| E75 深度自标注质量 | clearance MAE、pre/post 精确率/召回率、下游成功率增益 | ≤2 cm；≥95%/≥90%；≥5pp |
| E76 DataCert 覆盖有效性 | 留出条件网格实际覆盖、标签误差违约、漂移检测 AUROC | ≥95%；<1%；≥0.90 |
| E77 证书紧致性回归 | L_v/实测 Lip、N*、ValidRegion 非空率、B_t 界内率 | ≤3；≤8；≥90%；≥99% |
| E78 端到端 | 零样本合成/执行成功率、证书违约率、采集成本 | ≥85%/≥80%；<0.5%；-30% |

**本轮合成机制仿真（非基准，仅验证量级）**：seed=20261110，六类证书边际、8 类采集动作、对角高斯证据模型；深度见证部分用 2 万标定 + 4 万测试样本、split-conformal 校准。

| 检查 | 结果 |
|---|---|
| E73 预算 160 时达标率（cert_gap vs random） | 96.5% vs 81.0% |
| E73 达标中位样本（cert_gap vs random / uncertainty） | 37.0 vs 54.4 / 48.2（节省 32% / 23%） |
| E74 witness-gated 裕度（1/2/4 视角） | 0.172 / 0.141 / 0.116 m，较 LiDAR-only 0.239 m 收紧 28% / 41% / 50% |
| E74 粗差检出 / 假警报 | 48%–55% / 0.5%–0.6% |
| E74 朴素逆方差融合（4 视角） | 5% 分位裕度塌到 1.05 cm，覆盖率降到 96.5%（尾风险） |
| Goodhart 压力（50% 通道带偏置） | 证书覆盖率 95% → 42%，朴素在线审计未能恢复 |

**回退路径**：E73 或 E74 不达标 → 回退第 40 轮 v5 配置；深度仅作离线审计通道，IP-51 只用于验证集构造，不进入训练/蒸馏闭环。

## 5. 本轮最大风险

**一句话**：本轮最大风险是「证据模型自证」——若 CIG 建立在错误、且与采集同源的证书模型上，主动采集会精准放大模型盲区（合成压力测试中 50% 偏差通道使覆盖率从 95% 跌到 42%，在线审计也未能救回），深度与 LiDAR 还可能在玻璃/反光/粉尘下同源失效，最终得到一份更紧、更自信、却系统性错误的证书；因此 E73/E74 必须用完全不参与采集的独立审计集与分布漂移检测来守门。

# 第 41 轮产物 · 创新点清单 v18：证书缺口主动数据采集 × 深度见证几何 × 可认证数据资产（四层架构 v6）

> 承接第 40 轮产物 v17（IP-48/49/50 三大新增 + IP-36~47 升级）。本轮在其上**增量插入** IP-51/52/53，并升级 IP-49/50/44/46/36/39/48/45；不推倒任何既有层级。核心判断：v17 的证书紧致性由证据质量决定，而证据必须被主动设计、被深度相机见证、被数据证书审计。

## 1. 符号体系（承接定义 27-31）

| 符号 | 含义 | 定义 |
|---|---|---|
| θ | 证书参数向量 | (L_v, κ, B_t, h_min, μ_max, ε_ode) |
| Θ_δ(D) | (1−δ) 证书置信集 | 由 bootstrap/Laplace/conformal 从证据 D 构造 |
| m_i^cert | 认证边际 | inf_{θ∈Θ_δ} m_i(θ) |

## 2. 关键算法

### IP-51 证书缺口主动采集（伪代码）
```
def acquire(D, audit_set, budget, band):
    conf = certificate_confidence(D)                # Theta_delta, d_i, T_w
    while cost_used < budget:
        # 1) 课程先验选任务带，CIG 选证据动作
        cand = []
        for tau in sample_tasks(band, conf):        # IP-50 band prior
            for a in action_space(tau):
                if not safe(a): continue            # CBF / guardian
                J = fisher_or_influence(a, conf)    # linearized certificate model
                cig = weighted_logdet_gain(J, conf, weights=1/d_i)
                cand.append((cig / cost(a), a))
        a_star = argmax(cand)
        # 2) 采集并更新；审计集永不参与 CIG
        y = execute_safe(a_star)
        D.add(a_star, y); conf = update(D)
        # 3) Goodhart 防护：收益异常升高 -> 冻结该通道
        if cig_anomaly(conf.history): freeze_channel(a_star.source)
        # 4) 课程带随“最紧约束”重定心
        if binding_changed(conf): band.retarget(conf.binding)
    return D, DataCert.build(D, audit_set), conf

def certificate_confidence(D):
    post = bootstrap_or_laplace(D)                  # theta samples
    m_cert = [quantile_lower(post.m_i, delta=0.05) for i in constraints]
    d = [max(0, 1 - m/c) for m, c in zip(m_cert, C)]
    return Conf(theta=post, d=d, T=weighted_sum(d), binding=argmax(d))
```

### IP-52 深度见证几何（伪代码）
```
def depth_witness(rgbd, lidar_map, calib, rho_calib):
    z, valid = calibrate_depth(rgbd, calib)          # heteroscedastic sigma_d(r)
    p_d = backproject(z, valid)
    p_l = project_to_depth(lidar_map, rgbd.pose, calib)
    rho = residual(p_d, p_l)
    tau = conformal_quantile(rho_calib, delta=0.05)
    conflict = valid & (rho > tau)
    # 近场 ESDF：仅用有效深度像素，透明/镜面/低纹理置为 unknown
    esdf_near = tsdf_esdf(z, mask=valid & ~reflectance_bad)
    C_dw = WitnessType(phi_sem_from_depth(rgbd, z), esdf_near,
                       rho, tau, conflict)
    if conflict.any():
        IP51.request_active_view(conflict.pixels)   # 换视角/曝光/模态
    return C_dw

def auto_label_demo(rgbd_seq, seg):
    poses = multi_view_pose(rgbd_seq, seg)          # depth ICP + bundle adjust
    labels = infer_geometric_predicates(rgbd_seq, poses)
    keep = consistency_filter(labels,       # reprojection + cross-view
                              physics_filter(labels))  # contact/clearance
    audit_queue += ~keep
    return labels[keep], audit_queue

### IP-53 可认证数据资产（伪代码）

def build_datacert(D, condition_space, cert):
    cov = epsilon_net_coverage(D, condition_space, metric=task_metric)
    eta = conformal_label_bound(D.audit)            # independent audit
    rel = influence_weight(D, cert)                 # per shard -> constraint
    return DataCert(Cov_eps=cov, eta_label=eta, Rel=rel,
                    Prov=provenance(D), Audit=D.audit)

def select_training_set(pool, cert, budget):
    # 预算下最大化 覆盖增益 + Rel*CIG - 成本；子模贪心
    S = []
    while cost(S) < budget:
        x = argmax_{x in pool\S} (coverage_gain(S∪x) + rel(x)*cig(x)) / cost(x)
        if cov_radius(S∪x) <= eps_target: S.append(x)
    return S, build_datacert(S, pool.condition_space, cert)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 正确性保证 |
|---|---|---|
| 证书置信集更新 | 增量 O(d²)，bootstrap O(B·d²) | P(θ*∈Θ_δ)≥1−δ（按所选构造） |
| CIG/Fisher | O(|A|·d³)，懒贪心 O(|A| log|A|) | 子模性 + 预算贪心 ≥(1−1/e)/2 |
| 深度近场 ESDF | 每帧 O(P log P)，增量 O(Δ体素) | 深度有效域外显式 unknown，不冒充已知 |
| 跨模态见证 | O(P) 残差 + O(1) 阈值查询 | conformal 假警报 ≤δ；一致不构成验证 |
| 自标注 | O(P·V)（V 视角） | 三重一致性过滤 + 审计兜底 |
| DataCert 构造 | O(|D| log|D|) 近似 ε-覆盖 | Cov_ε 与 η_label 显式可审计 |
| 证书重颁 | 分钟级，复用 IP-46 | 新证据可收紧 N*，并热更新契约 |

**定理 6（预算采集近似）**：条件独立观测下 I(θ;y_A) 单调子模，预算贪心达 (1−1/e)/2；单位成本达 (1−1/e)。

**定理 7（见证的有限样本保证）**：可交换假设下 split-conformal 满足 P(ρ>τ_δ|两路有效)≤δ；偏差超过 τ_δ 时冲突概率趋于 1。**一致不证明正确**：共同失效不在检验的备择假设内，必须靠主动视角/多模态/人工审计补洞。

**定理 8（覆盖+标签→证书）**：若 X 为 ε-覆盖、标签误差≤η，且 T_w 为 L_T-Lipschitz，则 |T_w(D_X)−T_w(D)| ≤ L_T(ε+η)+O(√(log(1/δ)/n))。因此 DataCert 的 Cov_ε 与 η_label 是证书紧致性的可审计上界来源。

### 4.1 本轮合成机制仿真（非基准，仅量级验证）

设置：六类证书边际、8 类采集动作（不同敏感度与成本）、对角高斯证据模型、seed=20261110；深度见证部分 2 万标定 + 4 万测试，split-conformal 95%。

| 检查 | 结果 | 解读 |
|---|---|---|
| E73 预算 160 达标率 | cert_gap 96.5% / random 81.0% / uncertainty 89.0% | 主动采集显著更可靠 |
| E73 中位达标样本 | cert_gap 37.0 / random 54.4 / uncertainty 48.2 | 相对 random 节省 32% |
| E73 最终归一化宽度 | cert_gap 0.428 / random 0.594 | 同预算下更紧 |

结论：合成实验支持 E73/E74 的量级，但**不构成真实基准证据**；真实门槛需在 UniBot 场景与真机上复核。

## 5. 风险与缓解

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| CIG 自证：采集与证书模型同源偏差 → 过度自信 | 高 | 冻结独立审计集；conformal 重校准；通道级影响上限；收益异常检测；E73 第一守门 |
| 深度共同失效（玻璃/镜面/粉尘/低纹理） | 高 | 反射率门控 + 多模态（ToF/结构光/双目）+ 主动视角 + 冲突区降级；E74 守门 |
| ε-覆盖维度诅咒 → DataCert 空证书 | 高 | 只在任务相关低维流形上覆盖；分层覆盖 + 学习度量；显式报告覆盖半径 |
| 在线采集带来物理风险 | 中 | CBF/监护人过滤；先仿真后真机；不可恢复动作人工确认 |
| 深度自标注噪声进入训练 | 中 | 三重一致性过滤 + conformal 标签界 + 审计队列；高相关样本优先审计 |
| 数据/证书生命周期不一致 | 中 | DataCert 过期→证书降级→重采；版本号绑定策略与数据 |
| 课程与采集目标冲突 | 低 | 双轴调度：课程带定任务先验，CIG 定任务内证据；联合目标显式加权 |
| 计算开销（CIG+bootstrap） | 低 | 线性层闭式 + 懒贪心；证书重颁分钟级，离线异步 |

## 6. 本轮最大风险

**一句话**：本轮最大风险是「证据模型自证」——若 CIG 建立在错误、且与采集同源的证书模型上，主动采集会精准放大模型盲区（合成压力测试中 50% 偏差通道使覆盖率从 95% 跌到 42%，在线审计也未能救回），深度与 LiDAR 还可能在玻璃/反光/粉尘下同源失效，最终得到一份更紧、更自信、却系统性错误的证书；因此 E73/E74 必须用完全不参与采集的独立审计集与分布漂移检测来守门。
