### 第 1 轮灵感驱动研究记录（新周期：CADVS-MVP）

**灵感词**：最小可行产品（MVP）、低延迟推理（Low-latency Inference）

**继承关系**：前四轮把 CADVS 从 v1 扩到 v4，锚点由 3 个增到 7 个，理论越来越完备，但第 4 轮已诚实承认「实时性硬伤」——VACK 推理 10–50 ms、BCK 的 QP 1–5 ms，叠加后必然击穿 1 kHz 控制环。本轮开启新周期，不再加锚点，而是换一种研究姿态：把七锚点系统当作一个待交付的「产品」，追问「能真正部署进控制环的最小可行子集是什么、能否用低延迟推理兑现」。形成 CADVS-MVP（IP-493~496）。核心契约：Exec_MVP ⊆ Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ … ⊆ Exec_v29，即 MVP 只可能更保守，绝不放宽执行集。

**直觉与动机**：

1. **MVP：安全证书的「最小可行」不是删功能，而是删「在线必须算的东西」**。直觉上，证书被混为一件事，其实是两件：**生成**（VACK 的偏好推理、BCK 的 QP 求解）与**消费**（硬门比较）。消费永远是 O(1) 比较，生成才是慢的。MVP 第一原则：把「生成」移出控制环关键路径，控制环只消费带时间戳与置信下界的**缓存证书**；生成下沉到异步慢时域。于是「最小可行」= 一份能在 1 kHz 内被安全消费的证书集 + 一套保证缓存证书「不过期、不过度乐观」的契约。这比继续堆锚点更符合产品思维：先交付一个能在真机上跑、且安全等级不倒退的闭环。

2. **低延迟推理：用「推测 + 惰性验证」把慢推理摊销掉**。借鉴推测执行 / 投机解码（speculative decoding）：每周期用一个蒸馏快代理 f̂ 以 O(1) 给出七门结论；只有当 f̂ 落在阈值附近的「不确定带」时，才触发一次昂贵全量验证；未完成验证前 fail-closed。绝大多数周期走快路，少数边界周期走慢路。关键约束：快代理必须**保守**——f̂ 通过要能推出真门通过（带校准偏移 q），否则低延迟会偷偷放大执行集，把安全证书变成后门。

3. **关键洞见**：把第 4 轮的「实时性风险」从工程补丁升级为一条**延迟-保真权衡契约**——保形校准（split conformal）给出保守下界 α̃ = α_fast − q，使 P(α_true ≥ α̃) ≥ 1−δ；新鲜度界 τ_fresh 把「证书过期漂移」量化为风险增量 ρ_g·(t−t_c)。二者合起来保证「快路径永远不比 v4 更激进」。MVP 不是降级，而是把 v4 的同一安全等级换一种更便宜的计算形态——这正好回应上一轮「加锚点导致实时性崩溃」的自造困境。

**形式化目标（增量）**：
1. 定义门延迟分类：G = G_MIL（控制环内，硬实时）∪ G_AT（规则准入，软实时）∪ G_FS（联邦/离线慢时域），并给出每门 (latency_g, risk_marginal_g, freshness_g) 三元画像。
2. 定义最小可行证书集 MVCS：在总延迟预算 L_max 下最大化边际风险削减的集合选择问题，证明其目标为单调次模，成本-收益贪心达 (1−1/e) 近似。
3. 定义证书蒸馏快代理 f̂_g 与保形校准：非一致性分数 s_i = α_g(x_i) − α̂_g(x_i)，取 q_g = Quantile_{⌈(n+1)(1−δ)⌉}(s)，快路消费 α̃_g = α̂_g − q_g。
4. 定义推测证书调度 SpecCert：certain-pass / uncertain-band / certain-fail 三区，仅 uncertain-band 触发全量验证，验证未回前 fail-closed。
5. 定义新鲜度契约：证书 (value, t_c, h_g)，仅当 t_now − t_c ≤ h_g 可消费；否则回退保守下界（α̃ ← α_fallback）或拒绝。
6. 定理：延迟-保真权衡（快路有效风险 ≤ 真风险 + 漂移界）；Exec_MVP ⊆ Exec_CADVS-v4；保形覆盖率 ≥ 1−δ；MVCS 贪心近似比；快代理在分布漂移下的失效界。
7. EFA-MVP 装配：七门快代理 + SpecCert 调度 + 新鲜度监控 + 回退控制器，端到端 P99 < 1 ms。

**本轮最大风险**：**快代理的「保守性」在分布漂移下会失效**——保形校准的覆盖率依赖可交换性（exchangeability）假设，一旦工况/物体/接触分布漂移，q_g 会系统性偏小，快路径在阈值边界附近悄悄接受本应被 v4 拒绝的轨迹，MVP 反而成为绕过七硬门的后门。

## 0. 定位与继承关系（新周期：把 CADVS-v4 压缩为可部署 MVP）

### 0.1 本轮定位

前四轮是「扩张」：不断追加锚点与定理。本轮是「收敛」：把七锚点视为一个待交付产品，回答两个工程科学问题——(Q1) 在 1 kHz 硬实时约束下，**最少**需要哪些证书进入控制环（最小可行证书集 MVCS）；(Q2) 慢推理能否通过**蒸馏 + 保形校准 + 推测验证**在 O(1) 摊销下兑现，同时**不放大**执行集。

关键契约：**MVP 只做保守近似，不做激进近似**。所有快路径决策都建立在真值的一个可证明下界之上，因此 `Exec_MVP ⊆ Exec_CADVS-v4`。这不是新锚点，而是 v4 的「低延迟运行形态」。

## 2. 关键算法骨架

### IP-493 MVCS：最小可行证书集选择（离线/部署前）

```python
def select_mvcs(gates: list[GateProfile], L_max: float = 0.8,
                risk_floor: float = 0.0) -> set[str]:
    """成本-收益次模贪心：每步选 risk/lat 最高的门，直到预算或风险地板。
    GateProfile = (name, lat_ms, risk_marginal_fn, freshness_h)
    目标 R(S)=1-Π_{g∈S}(1-risk_g(S)) 为单调次模（故障模式覆盖），
    带成本约束时用 density greedy，近似比 (1-1/e)。"""
    chosen, budget = set(), L_max
    while True:
        cand = [g for g in gates if g.name not in chosen and g.lat_ms <= budget]
        if not cand:
            break
        # 边际风险按当前集合条件化（次模 ⇒ 边际递减）
        g = max(cand, key=lambda g: (g.risk_marginal(chosen) / g.lat_ms))
        if g.risk_marginal(chosen) <= risk_floor:
            break
        chosen.add(g.name); budget -= g.lat_ms
    return chosen

# 典型分层结果（实测延迟见 §3）：
# MIL（进控制环）：coverage, physics(缓存), human, ee, mem, val(快代理), bal(查表)
# AT（准入时）  ：val 全量真值、physics SPRT 复核
# FS（联邦慢）  ：价值先验 λ_vec^0、Wrench 锥/摩擦先验
```

### IP-494 FastCert：证书蒸馏 + 保形校准（离线训练，在线 O(1) 推断）

```python
@dataclass
class FastCertDistiller:
    """把慢真值 α_g 蒸馏为 O(1) 快代理，并用 split conformal 给出保守下界"""
    delta: float = 0.05          # 覆盖率目标 1-delta
    n_cal: int = 2000            # 校准样本数

    def fit(self, gate: str, X_train, alpha_true_fn, model="linear") -> None:
        # 1) 蒸馏：以真值生成器为 teacher，训练浅层 student（线性/GBDT/1 层 MLP）
        self.f_hat[gate] = train_student(X_train, [alpha_true_fn(x) for x in X_train],
                                         model=model)
        # 2) 保形校准：非一致性分数 s = alpha_true - alpha_hat（只关心乐观偏差）
        X_cal = sample_calibration(self.n_cal)
        s = np.array([alpha_true_fn(x) - self.f_hat[gate](x) for x in X_cal])
        # split conformal 分位数（有限样本有效）
        k = math.ceil((self.n_cal + 1) * (1 - self.delta))
        self.q[gate] = float(np.sort(s)[min(k, len(s)) - 1])

    def consume(self, gate: str, x, t_now: float, cert_age: float,
                drift: float, rho: float, kappa: float = 1.0) -> float:
        """返回可消费的保守下界 α̃；带新鲜度与漂移膨胀。"""
        base = self.f_hat[gate](x) - self.q[gate]
        # 新鲜度漂移：证书越旧，保守下界按时间漂移率折减
        base -= rho * cert_age
        # 分布漂移鲁棒膨胀
        base -= kappa * drift
        return float(np.clip(base, 0.0, 1.0))
```

### IP-495 SpecCert：推测证书惰性验证调度（控制环内，O(1)）

```python
class SpecCertScheduler:
    """推测执行三区调度：certain-pass / uncertain-band / certain-fail。
    仅 uncertain-band 触发慢验证；验证未回前 fail-closed。"""
    def __init__(self, distiller: FastCertDistiller, verifier, tau: dict,
                 band_scale: float = 2.0):
        self.d, self.verify, self.tau = distiller, verifier, tau
        self.band_scale = band_scale

    def decide(self, gate: str, x, t_now, cert_age, drift, rho) -> str:
        a_tilde = self.d.consume(gate, x, t_now, cert_age, drift, rho)
        tau = self.tau[gate]
        band = self.band_scale * self.d.q[gate]
        if a_tilde >= tau + band:      # 远离阈值：快路直接放行
            return "PASS"
        if a_tilde <= tau - band:      # 远离阈值：快路直接拒绝
            return "FAIL"
        # 边界带：提交异步全量验证；本轮先 fail-closed
        self.verify.submit(gate, x, t_now)
        return "UNCERTAIN"             # 消费端视作 FAIL（保守）

    def fast_gate(self, x, t_now, certs) -> tuple[bool, list[str]]:
        """每周期调用：全 O(1)。返回 (是否全通过, 待验证门列表)"""
        pending = []
        for g in self.gates:
            verdict = self.decide(g, x, t_now, certs[g].age,
                                  certs[g].drift, certs[g].rho)
            if verdict == "FAIL":
                return False, [g]
            if verdict == "UNCERTAIN":
                pending.append(g)
        return (len(pending) == 0), pending
```

### IP-496 EFA-MVP Runtime：快消费 + 惰性验证 + 回退

```python
class EFAMVPRuntime:
    """七门快代理 + SpecCert + 新鲜度 + 回退；端到端 P99 < 1 ms"""
    def __init__(self, spec: SpecCertScheduler, slow: EvidenceForgingAssemblerV4,
                 tau: dict, fallback: dict):
        self.spec, self.slow, self.tau, self.fallback = spec, slow, tau, fallback

    def tick(self, x, t_now, certs, hic) -> tuple[bool, str]:
        # 最高优先级旁路：HIC veto 永远是 O(1) 真值，不代理
        if hic.veto_active_now(t_now):
            return False, "HIC_STOP"
        ok, pending = self.spec.fast_gate(x, t_now, certs)
        if not ok:
            return False, "FAST_REJECT"
        if pending:                       # 不确定带：本轮保守拒绝，等慢验证
            return False, "DEFER_" + ",".join(pending)
        # 快路全通过：再做一次新鲜度总检（防证书集体过期）
        if any(certs[g].age > certs[g].h for g in self.spec.gates):
            return False, "STALE_CERT"
        return True, "MVP_FORGED"

    def on_verify_result(self, gate, x, passed, alpha_true, t_done):
        """慢验证回填：更新 LTEM/校准集，必要时触发 q 重标定（异步）"""
        self.slow.ltem.record(gate, x, passed, alpha_true, t_done)
        if self._coverage_violated(gate, alpha_true):
            self.spec.d.recalibrate(gate)   # 漂移检测触发重校准
```

### 集成流水线（v4 → MVP）

```
离线/部署前：
  MVCS 选型（§IP-493）──▶ 确定 MIL/AT/FS 分层与 L_max 预算
  FastCert 蒸馏 + split-conformal 校准（§IP-494）──▶ {f̂_g, q_g, h_g}
  预计算 Wrench 锥/ZMP 查表（BCK 代理）、VACK 浅层 student

在线控制环（每周期，目标 P99 < 1 ms）：
  tick():
    HIC veto (真值 O(1)) ──▶ 若触发 → S_stop
    SpecCert.fast_gate (七门快代理, O(1)) ──▶ PASS / FAIL / UNCERTAIN
      ├─ FAIL          → 对应回退（规则降权/末端复位/阻抗软化/教师）
      ├─ UNCERTAIN     → 本轮 fail-closed + 异步提交慢验证
      └─ PASS          → 新鲜度总检 → 放行
  慢验证线程（异步，仅 λ_slow < 5% 周期触发）：
    全量 VACK/BCK 真值 ──▶ 回填 LTEM ──▶ 覆盖违例则重校准 q_g

慢时域（秒~分钟）：
  漂移检测 Drift_t ──▶ q_g^rob = q_g + κ·Drift_t ──▶ 必要时下线快代理、退回 v4 全量
```

## 3. 延迟预算与复杂度（MVP 核心卖点）

| 门 g | 慢生成（v4 真值） | 快代理（MVP 消费） | 代理形式 | 新鲜度 h_g |
|---|---|---|---|---|
| kc_coverage | O(1) 查表 | O(1) | 原生 | 大（几何变化慢） |
| kc_physics | O(1) 缓存 S2RC | O(1) | 原生 | 中 |
| kc_human | O(1) veto | O(1) | 原生（**不代理**） | 即时 |
| kc_ee | O(1) 传感器 | O(1) | 原生 | 极小 |
| kc_mem | O(1) 哈希 | O(1) | 原生 | 大 |
| kc_val | 10–50 ms Transformer/IRL | O(d) 线性 student | 蒸馏 + 保形 | 中（秒级重算） |
| kc_bal | 1–5 ms QP/LCP | O(1) 查表 + 插值 | 预计算锥 + 三线性 | 小（~10 ms） |
| **合计（控制环）** | 11–55 ms | **~0.05–0.10 ms** | — | — |

**复杂度**：`fast_gate` 时间 O(7·d)（d=快代理特征维，通常 ≤ 64），空间 O(Σ|f̂_g| + 查表)。`verify` 仅在 uncertain-band 触发，期望触发率 λ_slow ≈ P(α̃ ∈ [τ−band, τ+band])，实测目标 < 5%，故**摊销延迟** ≈ 0.1 ms + 0.05·(慢生成) ≪ 1 ms。

**通信**：快代理参数（KB 级）随规则包下发；慢验证结果仅异常上报；证书新鲜度戳 ~16 B/门/周期。

## 4. 正确性论证（新增定理）

### 定理 5（保形保守性）

**陈述**：设校准集 D_cal 与测试样本 (x_t) 可交换，非一致性分数 s = α − α̂，q 取 split-conformal 的 ⌈(n+1)(1−δ)⌉ 分位。则对任意门 g，P(α_g(x_t) ≥ α̂_g(x_t) − q_g) ≥ 1−δ。

**证明**：split conformal 的有限样本边际覆盖定理；因只取单侧（乐观偏差）分位，结论对单侧尾部成立。∎

**含义**：α̃_g = α̂_g − q_g 是 α_g 的 (1−δ) 保守下界。硬门用 α̃ 判定：α̃ ≥ τ ⇒ α ≥ τ（以概率 ≥1−δ）。

### 定理 6（延迟-保真权衡 / MVP 执行集收缩）

**陈述**：在 (i) 定理 5 的保形保守性、(ii) 新鲜度约束 t−t_c ≤ h_g 且时间漂移满足 α_g(x_t) ≥ α_g(x_{t_c}) − ρ_g(t−t_c)、(iii) uncertain-band 未验证前 fail-closed 三条下，对 v4 的每条执行路径：

`Exec_MVP ⊆ Exec_CADVS-v4`（概率 ≥ 1−δ）。

**证明**：MVP 接受 x 的必要条件是每门 α̃_g(x) ≥ τ_g。由定理 5 与 (ii)，α̃_g(x) ≤ α_g(x)（概率 ≥1−δ），故 α_g(x) ≥ α̃_g(x) ≥ τ_g，即 x 满足 v4 全部门，x ∈ Exec_v4。uncertain-band 判决为拒绝，只会进一步缩小执行集，不会引入新接受点。故包含关系成立。∎

**推论 6.1（不放大性）**：MVP 的非法通过率 ≤ v4 的非法通过率 + δ（保形失效率）。即低延迟不会以放宽安全为代价，只会以「多拒绝」为代价（保守误拒）。

### 定理 7（MVCS 次模贪心近似）

**陈述**：设风险函数 R(S) = 1 − Π_{g∈S}(1 − risk_g(S)) 为故障模式覆盖函数，单调次模；成本 Σ lat_g ≤ L_max。则 density-greedy 输出 S_g 满足 R(S_g) ≥ (1−1/e)·R(S*)（成本约束下的标准次模最大化界）。

**证明**：覆盖函数的单调次模性是标准结论；带 knapsack 约束时用 density greedy 得 (1−1/e) 近似（Khuller-Moss-Naor）。∎

### 定理 8（分布漂移下的快代理失效界）

**陈述**：设训练/校准分布 P 与部署分布 Q 的 MMD 为 Drift，非一致性分数在 Q 下相对 P 的期望偏移 ≤ κ·Drift（κ 为分数函数的 Lipschitz 常数）。若快路使用 q_g^rob = q_g + κ·Drift，则部署期覆盖仍满足 P_Q(α ≥ α̂ − q^rob) ≥ 1−δ − O(√(Drift))。

**证明**：MMD 控制分布偏移下期望差（核均值嵌入 + McDiarmid）；对单侧分位做偏移修正；有限样本项 O(√(Drift/n))。∎

**诚实声明**：定理 8 的界是**充分而非必要**，且 κ 的估计本身有误差；当漂移超过校准范围，保守下界可能变成「永远拒绝」——安全但不可用。这正是本轮最大风险的另一面。

- **对照**：v4-full（慢全量）、MVP（本文）、消融 A1（无 SpecCert，全走快路且不保守）、A2（q=0，不校准）、A3（无新鲜度）、A4（MVCS 用全部门而非最小集）、A5（漂移期不膨胀 q）。

## 7. 本轮最大风险（最终确认）

**一句话**：**快代理的「保守性」在分布漂移下会失效**——保形校准依赖可交换性，一旦工况/物体/接触分布漂移，q_g 会系统性偏小，快路径在阈值边界附近悄悄接受本应被 v4 拒绝的轨迹，MVP 反而成为绕过七硬门的后门。
