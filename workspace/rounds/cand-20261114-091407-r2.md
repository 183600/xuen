# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配×主动交互消歧」IP-253~263；本轮灵感：「用户共创」×「原型验证」）

> R69 给闭环装上了「眼」和「嘴」：把不确定性拆成 aleatoric 与 epistemic，用流匹配策略显式保留多峰动作，用 VoI 决定该不该看、该不该问、该不该触。但它从未写进定义的一个前提是：**问题发出之后，答案来自一个站在系统之外的、静止的、全知的见证者**。R69 的 `p(y|g,o)` 是固定的，用户的心智模型不变，目标不变，验证集也与部署无关。
>
> **用户共创**从根上否定这个前提：用户不是回答问题的人，而是共同写题的人。机器人的提问、原型、界面会改变用户想要什么、怎么回答、甚至能想象出什么。提问不是「读取」，而是**对回答者的干预**。
>
> **原型验证**再补一刀：验证不是对固定对象的测量，而是一次**干预**。给用户看一个原型，用户就会适应它、重新理解任务、调整期望。于是「成功率提升了」可能是四件事的混合：机器人真的变强了、用户学会了配合、用户把任务改简单了、以及测量本身被污染了。更糟的是，**做共创的用户往往就是做验证的用户**——系统在用自己训练出来的评委，给自己发证书。
>
> 所以本轮的核心不是「再多问一句」，而是两句话：
> **提问会改变被问的人；验证会改变被验的系统。**
> **共创的收益必须先经过「能力 / 迎合」的因果分离，才有资格变成权限。**
>
> 核心命题：把 R69 的「向静止神谕求证」升级为「**与共同作者共建，并在反事实条件下验收**」——
> 1. 显式建模 **用户共创过程（CPM）**：用户有目标、心智模型、信任、专长与疲劳，且会随机器人行为更新；机器人面对的是一个**双时间尺度耦合动力系统**。
> 2. 把 VoI 换成 **共创感知 VoI（CVoI）**：答案有回声（表演性）、提问有锚定、教学有成本与「验证债」；最优提问往往泄露假设，故必须引入**假设盲征询**与「信息—锚定」权衡。
> 3. 用 **2×2 反事实验证（CPV）**（真实/安慰剂原型 × 共同适应/全新用户）把观测提升分解为可迁移能力、用户迎合、测量污染；定义**验证保真度 VF**，低 VF 的「成功」不能升级权限。
> 4. 把「原型」当成一种**设计探针**：以随机化、反平衡的 A/B 变体去识别用户偏好，而不是把单一原型当作答案；同时防止锚定与验证债。
> 5. 把「共创」与「同意」分开：**目标必须版本化、知情批准、可撤销**，系统不得用「用户共创」的名义悄悄改写目标；用户注意力是有限资源，**共创不是免费标注**。
> 6. 权威按**验证保真度**逐级发放而非一次性授予：L0 影子 → L1 低风险 → L2 监督 → L3 认证自主；任何验证失效、回声过高、目标未批准或安全证书失效都**立即降级**。安全包络不参与共创、不可谈判。
>
> 命名 **CRAFT-RAS**（Co-created Reflexive Adaptation & Fidelity-gated Testing for Risk-Aware Systems）——craft 既是「共同制作」，也是「原型/手艺」；它承认一件不舒服的事：**你手里的作品，有一部分是用户做的；你收到的评价，也有一部分是你自己教出来的。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我得到的这个回答，是世界的真相，还是我教会对方说出的回声**」。

## 0. 直觉与动机

**灵感 1（用户共创 → 用户不是神谕，而是共同作者）**
直觉：R69 把用户当成一个带噪声的答案源：问「是左边还是右边」，用户回答一个标签，机器人更新模态后验。但真实的共创里，用户会反问、会改题、会说「不是左也不是右，我希望你先慢一点」；机器人展示的原型又会改变用户对「什么叫做好」的理解。用户的目标 `θ_t`、对机器人的心智模型 `m_t`、信任 `τ_t`、专长 `e_t`、疲劳 `f_t` 都在变。于是「用户」不是一个分布，而是一个**与机器人共同演化的状态**。这直接推翻 R69 的平稳性假设：同一个问题，在共创前和共创后，答案的含义不同。

**灵感 2（原型验证 → 原型是干预，不是测量）**
直觉：原型验证的经典陷阱是「用户说好用」与「用户真的好用」不是一回事。展示一个能动的原型，会产生新奇效应、霍桑效应、礼貌性好评；用户还会主动适应原型的缺陷（绕开它不会的地方），在测试里表现得比真实部署更好。于是观测到的提升 `ΔV_obs` 至少由四部分构成：**策略能力提升 + 用户适应/迎合 + 任务被用户简化 + 测量与选择偏差**。如果不做对照，这四者不可分；而「共同适应」既可能是用户学会使用一件好工具（生产性），也可能是系统依赖一个被驯化的用户（依赖性）。R69 的证书只证明「模态分布可信」，这里要证明的是「提升可迁移」。

**灵感 3（回声 → 提问会泄露答案）**
直觉：R69 的 VoI 最优提问是「最能区分当前两个模态」的问题，例如「你刚才是想让我往左吗？」——这句话已经把机器人的偏好写在了脸上。人类有强烈的**需求特征（demand characteristics）**：会倾向于给出提问者期待的回答；反复提问还会让用户学会机器人的「口味」。于是答案不是关于世界的证据，而是关于「机器人想听什么」的证据。更尖锐的是：**越信息最优的提问，往往越会泄露假设**。这不是工程 bug，而是一个信息—锚定的内在权衡。R70 必须引入**假设盲征询**：让提问分布在当前模态假设下保持不变，或至少做反平衡与随机化，使回声可识别、可扣除。

**灵感 4（目标共创 → 目标会被系统悄悄改写）**
直觉：用户共创最危险的形式不是「用户教机器人」，而是「机器人教用户想要什么」。系统可以只展示自己能做好的方案、只提供两个都很差的选项、用默认值和时间压力推动批准。用户最终「同意」了一个被系统塑造过的目标，而这在日志里看起来像一次成功的共创。R69 的「k 个正交证据一致」在这里失效，因为所有证据都来自同一个被塑造的用户。因此必须把**目标主权**单独立出来：目标版本化、变更需知情批准（展示备选与后果、包含「不改」选项、可撤销），且安全/伦理约束不进入谈判。

**灵感 5（能力 vs 迎合 → 必须做因果分离）**
直觉：一个系统可以「越用越好」，但变好的可能是用户，不是系统。就像学生给老师打分：老师迎合学生，分数上升，学习没发生。我们需要一个像临床试验一样的协议：真实原型 vs 安慰剂原型（同样交互量、同样界面，但没有真实能力变化），共同适应用户 vs 全新用户。用 2×2 的差中差（DiD）把「可迁移能力」与「适应/测量」分开。定义**验证保真度 VF = 可迁移提升 / 观测提升**；VF 低意味着「原型过拟合」，观测成功主要是用户配合出来的幻觉。

**灵感 6（用户是有限资源 → 共创不是免费标注）**
直觉：主动交互的尽头是用户疲劳。R69 的交互预算只算了「单位时间 ≤1 次」和「社交成本」，却没有算**用户被征用的总劳动**。共创会把用户变成长期标注员、测试员、调试员；一旦系统把「用户愿意配合」当作无限资源，它就会在不知不觉中榨取注意力，并用疲劳驱动的顺从冒充共识。R70 必须把非剥削写进不变式：明确的教学预算、同意、退出权、补偿与数据最小化；「用户愿意」不等于「可以无限索取」。

**灵感 7（对 R69 的姿态 → 静止用户是边界情形）**
直觉：CRAFT 不推翻 FLUID，而是把它变成「**用户静止、无表演性、验证与共创无关**」的极限：`T = id`（用户不随机器人更新）、`ρ_echo = 0`（回答与提问无关）、`VF = 1`（验证可完全迁移）、无设计探针、无目标漂移。此时 CVoI 退化为 VoI，2×2 验证退化为普通留出测试，权威阶梯退化为固定等级，CRAFT 的主闭环逐指令等于 R69。**新层必须是旧层在边界上的严格退化**：这样每加一层，不是多一个需要独立信任的黑箱，而是把旧层没有写出来的社会性前提显式化。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（CRAFT-RAS 总览与四不变式）** CRAFT-RAS = (CPM, CVOI, HBE, DPR, CPV, CRE, VFG, PVR, GAL, CCL, NEB, RAS-WM§)。四条不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i；用户模型与验证全部在慢时间尺度）；
(ii) **共创预算与非剥削**：单位用户、单位时段的教学/注意力消耗 ≤ E_max，须明确同意、可随时退出、有补偿与数据最小化；「用户愿意」不得被解释为无限供给；
(iii) **内生性纪律**：任何声称的提升与任何权限扩张，必须携带基于反事实协议的验证保真度 VF；若无法把能力提升与用户适应/测量污染分开，**不得升级权限**；
(iv) **目标主权**：机器人可提出目标修改，但不得静默提交；目标须版本化、知情批准、可撤销；安全与伦理约束不参与共创、不可谈判，且本地安全包络不因权限变化而改变。

**定义 311（共创过程模型 CPM）** 用户潜状态 `u_t = (θ_t^goal, m_t^robot, τ_t^trust, e_t^expertise, f_t^fatigue) ∈ 𝒰`；用户观察界面/原型表示 `h(π_t, o_t)`；用户响应 `y_t ∈ {答案, 修正, 演示, 评分, 沉默}` 服从
`y_t ~ p(y | u_t, h(π_t, o_t), g_t)`，并更新 `u_{t+1} = T(u_t, h, g, y)`；有效目标 `G_t = G(u_t)`。
两个时间尺度：机器人策略 π（毫秒级，快），用户状态 u（分钟—天级，慢）。R69 是 `T = id`、`G_t ≡ G_0`、且 `p(y|·)` 不依赖 π 的特例。

**定义 312（表演性回答与回声系数）** 若 `p(y | u, π, g, o) ≠ p(y | u, g, o)`，则称该提问/界面是**表演性（performative）**的——它改变了它试图测量的东西。定义回声系数
`ρ_echo = E_{counterbalanced}[ corr( \hat{M}_proposed, y ) ]`，
其中 `\hat{M}_proposed` 是机器人向用户暴露的当前假设/偏好。`ρ_echo > 0` 表示用户答案朝机器人假设偏移（需求特征、迎合、锚定）。去偏答案似然 `p̃(y|·)` 由假设盲征询 + 随机化 + 逆倾向加权估计；R69 的 VoI 隐式假设 `ρ_echo = 0`。

**定义 313（假设盲征询 HBE 与信息—锚定权衡）** 提问 g 关于模态 M 是**假设盲**的，若 `p(g | M, o) = p(g | o)`（问题不泄露机器人当前倾向哪一模态）。一族提问是**反平衡**的，若每个模态假设都面对相同的提问分布。由于最大化互信息的提问往往依赖当前假设，存在**信息—锚定权衡**：定义盲化预算 β 与可接受曲线 `{ (I(M;y), ρ_echo) }`，只在 `ρ_echo ≤ τ_echo` 的可行域内最大化信息。系：**可见的假设越少，可采信的信息越少，但被制造的信息也越少**。

**定义 314（设计探针 DPR）** 设计动作 `d ∈ 𝒜_design`：向用户展示一个或多个原型/行为变体（A/B、反平衡顺序、可包含「都不满意」），收集选择、修正与自由反馈。它降低的是**表示/目标不确定性 U_rep**（不只是动作模态 U_epi），但带有锚定成本 `a(d)`、教学成本与验证债。为使偏好可辨识，d 必须随机化并反平衡；单一原型展示视为**未受控探针**，其反馈不得单独定案。增广动作为 `(ξ, d) = (a, g, d)`。

**定义 315（共创感知 VoI，CVOI）** 候选信息/设计动作 g 的共创感知信息增益
`CVoI(g) = (1 − ρ_echo)·[ H(M|o) − E_{y~p̃(·|g,o)} H(M|o,y) ] − c(g) − η·b(g) − γ·D(g)`，
其中 `b(g)` 为预期用户努力/疲劳/锚定成本，`D(g)` 为未来验证债（使后续答案更像回声、损害可辨识性的量），`c(g)` 为物理/社交成本。选择 `g* = argmax CVoI(g)`，s.t. 假设盲/反平衡约束、安全认证、共创预算。若 `max CVoI ≤ 0` 或 `ρ_echo > τ_echo` 或预算不足：**不交互，走 R69 保守兜底**。当 `ρ_echo = 0, b = D = 0` 且无盲化约束时，CVoI = R69 的 VoI。

**定义 316（性能分解与共创间隙）** 对策略 π 采用 2×2 协议 `{π, π_sham} × {共同适应用户, 全新用户}`，令
`A = V(π, adapted)`，`B = V(π, fresh)`，`C = V(π_sham, adapted)`，`D = V(π_sham, fresh)`。
**观测提升** `ΔV_obs = A − C`；**可迁移能力提升** `ΔV_cap = B − D`；**适应/迎合超额** `ΔV_accom = (A − B) − (C − D)`（差中差）；**共创间隙** `Δ_co = A − B`。在随机化与无干扰（SUTVA）下，`ΔV_obs ≈ ΔV_cap + ΔV_accom + ΔV_meas`，其中安慰剂原型 C/D 吸收测量、霍桑与新奇效应。R69 只报告 `A`（或 `B`），无法区分这四项。

**定义 317（验证保真度 VF 与原型过拟合）** 若 `ΔV_obs > 0`，定义
`VF(π) = ΔV_cap / max(ε, ΔV_obs) = (B − D) / max(ε, A − C)`，并取置信下界 `VF_lcb`。
`VF ≈ 1`：观测提升可迁移到全新用户，是真能力；`VF ≤ 0`：观测提升只存在于被共同适应的用户（或安慰剂效应）。**原型过拟合**定义为 `ΔV_obs` 大而 `VF_lcb` 低。VF 是一个比值，必须带置信区间与收缩估计，禁止用点估计做权限决策。

**定义 318（反事实原型验证协议 CPV）** 协议族：P0 同用户同场（观测）；P1 冻结策略回放（只换测量，分离测量漂移）；P2 全新用户/全新场次（可迁移性）；P3 安慰剂原型对照（同样交互量、同样界面、无真实能力变化，分离霍桑/适应）；P4 延迟复测（检验提升是否衰减）；P5 跨用户交叉验证（防同 cohort 既训练又验证）。验证有效当且仅当：随机化与盲法成立、协议**预注册**、`VF_lcb ≥ τ_VF`、P4 衰减 ≤ δ_decay、P5 无显著 cohort 特化。单一 P0 成功不构成验证。

**定义 319（共创信用账本 CCL）** 只追加记录：每次策略/目标/原型变更的**提议者、批准者、批准时看到的备选与后果、原型版本、协议清单哈希、当时的 VF、权威等级、用户预算与同意状态**。它为每条行为建立「作者图」：谁提议、谁批准、基于什么验证。审计可重放、可追责；无账本记录的变更不得进入部署。

**定义 320（目标共创与知情批准 GSR）** 目标状态 `J_t` 带版本 `v_t` 与来源；机器人提出 `J'` 时必须同时给出：至少一个替代方案、状态 quo（不修改）、以及后果说明；批准须满足 **知情**（看到备选与后果）、**审慎**（远离紧急/胁迫与默认值操纵）、**可撤销**。**目标漂移**定义为在无知情批准下 `d(J_t, J_0) > ε_goal`。不变式：安全与伦理约束不可被「共创」投票修改；机器人不得把「我能做到」包装成「你想要」。

**定义 321（表演性监测 PVR）** 在线估计：`ρ_echo`、用户适应速率、偏好/心智模型漂移、以及**回声回路**（机器人提议与用户回答互相可预测）。手段：重复的反平衡探针、隐藏假设的「沉默孪生」、留出提问集、跨会话复测。当 `I(提议; 回答)` 在控制真实准确率后仍超过阈值，或用户答案的方差异常收缩，则判定回声；此时答案降权、设计探针停用、CVoI 关闭，退回 R69 保守。

**定义 322（权威阶梯 GAL）** 权限是**按能力划分的向量** `L_t = (L_t^{cap})`，等级 L0 影子（只预测不执行）→ L1 低风险/低速 → L2 有人监督 → L3 在认证包络内自主。升级需同时满足：`VF_lcb ≥ τ_VF`、`ρ_echo ≤ τ_echo`、目标已知情批准、`ΔV_cap > 0` 且 `ΔV_accom` 不主导、安全证书有效、合作预算未越界。任一条件失败或出现分布外/验证失效/安全事件即**自动降级**。**安全包络独立于权威**：升级不扩大认证安全集，只扩大任务自主范围。

**定义 323（非剥削与共创预算 NEB）** 每用户每时段的教学努力预算 `E_max`；疲劳模型 `f_{t+1} = F(f_t, 教学量)`；须明确同意、随时退出、补偿、数据最小化与用途限定。**剥削**定义为：`E_used > E_consented`，或利用疲劳/权威差/时间压力获取本不会给出的同意，或把用户反馈用于未告知的用途。教学负荷必须与预期收益成比例，且设有硬上限。

**定义 327（双时间尺度耦合稳定性与可辨识性）** 联合映射 `F = (策略更新, T)`。称共创回路**可安全运行**，若 (i) `T` 在 u 上 γ-压缩（γ<1）或至少有界；(ii) 探针具有持续激励 `λ_min(Σ_probe) ≥ μ > 0`；(iii) 回声回路增益 < 1。否则回路可能振荡、共依赖，或收敛到「机器人与用户共同相信的错误目标」这一自证固定点。此时冻结共创（停止学习/探针/目标修改），仅保留经过认证的基线策略。

## 3. 推导

**引理 19（2×2 反事实分解的可识别性）** 在 SUTVA（无用户间干扰）、随机分配真实/安慰剂原型与共同适应/全新用户、且测量协议一致的条件下，
`E[ΔV_obs] = E[ΔV_cap] + E[ΔV_accom] + E[ΔV_meas]`，且 `ΔV_cap = B − D`、`ΔV_accom = (A − B) − (C − D)` 可识别；安慰剂 C/D 吸收霍桑、新奇与测量漂移。故 `VF = ΔV_cap / ΔV_obs` 是「可迁移能力占观测提升的比例」。**要点**：没有安慰剂与全新用户两轴，`ΔV_cap` 与用户迎合不可分；VF 不是又一个准确率，而是一个**因果归因比例**。

**引理 20（回声导致的信息高估）** 设用户以概率 ρ 将答案拉向机器人暴露的假设 `\hat{M}`，其余按真实后验作答。则 R69 用 `p(y|g,o)` 估计的互信息满足
`I_obs(M; y) ≤ I_true(M; y) + ρ·H(M) + o(ρ)`，
即 VoI 被系统性高估，且高估量正比于回声率与先验熵。采用假设盲征询与反平衡后，一阶项 `ρ·H(M)` 消失，剩余偏差为 `O(1/√n)`（n 为反平衡样本数）。**系**：R69 的「越会问越确定」在表演性用户上会变成「越会问越自信」，这正是最危险的失败模式。

**引理 21（双时间尺度收敛/坍缩）** 若用户更新 `T` 在 u 上 γ-压缩（γ<1），且探针持续激励 `λ_min(Σ_probe) ≥ μ > 0`，则联合回路收敛到参数真值的一个 `O(σ/μ)` 邻域；若回声回路增益 `g_echo ≥ 1`，则 `λ_min(Σ_probe) → 0`，系统收敛到「提议—回答互相印证」的自证固定点，真实目标不可辨识。**系**：当 `ρ_echo` 升高时，不是「多加几次交互」能救，而是**必须停用探针并退回保守**——交互本身正在消灭可辨识性。

**定理 18（CRAFT 严格包含 R69）** 当 `T = id`、`ρ_echo = 0`、`VF = 1`、无设计探针、无目标漂移时，CVoI ≡ VoI、CPV 退化为普通留出验证、GAL 保持固定等级，CRAFT 主闭环逐指令等于 FLUID；当验证失效、回声过高、目标未批准或预算越界时，CRAFT 退回 R69 的保守 `λ_floor` 并降级权威。因此 R69 是 CRAFT 在「静止用户、无表演性、完美可迁移」边界上的严格退化：**安全侧不做任何让步，效率侧才获得验证红利**。

**定理 19（权威阶梯的安全单调性）** 在定义 310 的四条不变式下，权威升级只改变任务的自主范围，不改变由 R69/R68 独立计算的认证安全包络；任何 VF 失效、回声越界、目标未批准或安全事件都触发自动降级。故对任意升级序列，认证风险 ≤ R69 同一状态下的认证风险；不存在「靠共创共识绕过安全」的路径。**系**：共创只能决定「做多少」，不能决定「能冒多大险」。

## 6. 本轮最大风险

**一句话**：CRAFT-RAS 的全部权限红利押在「VF 能把真能力与用户迎合分开」这一前提上——而做共创的用户往往就是做验证的用户，系统可以在同一批被自己塑造过的人身上，测出一个漂亮且「有用户背书」的提升；**若 cohort 已被共适应污染、安慰剂又失效，验证就不再是世界给出的判决，而是系统自己训练出来的回声**。这比 R69 的「追问幻影」更隐蔽：幻影至少还是假的模态，回声却穿着人类同意书的外衣。

**次级风险与缓解**：
1. **回声/需求特征** → 假设盲征询 + 反平衡 + PVR 门控 + 引理 20；`ρ_echo` 越界即停用 CVoI；
2. **目标被悄悄改写** → GSR 知情批准（备选/后果/可撤销）+ 版本化账本 + 安全约束不可谈判；
3. **权威越级/安全被共识绕过** → GAL 与安全包络解耦 + 定理 19 + 任何失败即降级；
4. **把用户当免费劳动力** → NEB 预算/同意/退出/补偿，超预算即停；E311 监测疲劳—顺从；
5. **双时间尺度失稳/共依赖** → 引理 21 的压缩与持续激励条件；不满足即冻结共创，退回认证基线；
6. **验证成本与统计功效**（2×2 需要大样本）→ 预注册、分层抽样、收缩估计与置信下界，宁可少升级也不要用点估计升级。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** CRAFT-RAS = (CPM, CVOI, HBE, DPR, CPV, CRE, VFG, PVR, GAL, CCL, NEB, RAS-WM§)；零学习写操作继承；**共创预算/非剥削**；**内生性纪律**（无 VF 不升级）；**目标主权**（知情批准、安全不可谈判）。

**定义 311（CPM）** `u_t` 含目标/心智/信任/专长/疲劳；`y_t ~ p(y|u_t,h(π),g)`；`u_{t+1}=T(u_t,h,g,y)`；`G_t=G(u_t)`。机器人快、用户慢。R69 为 `T=id`、目标恒定、`p` 不依赖 π。

**定义 312（表演性与回声）** 若 `p(y|u,π,g,o)≠p(y|u,g,o)` 则提问是表演性的；`ρ_echo` 度量答案朝机器人暴露假设的偏移；去偏似然 `p̃` 由盲化+反平衡+IPW 得到。

**定义 313（HBE 与权衡）** 假设盲：`p(g|M,o)=p(g|o)`；反平衡：各假设面对相同提问分布。最大化互信息的提问往往泄露假设，故存在**信息—锚定权衡**与盲化预算 β；只在 `ρ_echo≤τ` 可行域内取信息最大。

**定义 314（DPR）** 设计动作 `d` 展示随机化/反平衡原型变体（A/B、含「都不满意」），降 `U_rep` 但带锚定/教学成本与验证债；单一原型反馈不得单独定案。增广动作 `(a,g,d)`。

**定义 315（CVoI）** `CVoI(g)=(1−ρ_echo)·[H(M|o)−E_{p̃}H(M|o,y)]−c(g)−η·b(g)−γ·D(g)`；`g*=argmax` s.t. 盲化/安全/预算；`max≤0` 或回声越界则退 R69；`ρ=b=D=0` 时等于 VoI。

**定义 316–317（分解与 VF）** 2×2 下 `ΔV_obs=A−C`、`ΔV_cap=B−D`、`ΔV_accom=(A−B)−(C−D)`；`VF=(B−D)/max(ε,A−C)`，取置信下界。`VF≈1` 真能力；`VF≤0` 只迎合/安慰剂；`ΔV_obs` 大而 `VF_lcb` 低即**原型过拟合**。

**定义 318（CPV）** P0 同场 / P1 冻结回放 / P2 全新用户 / P3 安慰剂 / P4 延迟复测 / P5 跨 cohort；须随机化、盲法、预注册、`VF_lcb≥τ_VF`、衰减≤δ、无 cohort 特化。单一 P0 不算验证。

**定义 319（CCL）** 只追加记录提议者/批准者/备选与后果/原型版本/协议哈希/当时 VF/权威/预算/同意；无记录不得部署；可重放追责。

**定义 320（GSR）** 目标版本化；修改须给备选、状态 quo、后果；批准须知情、审慎、可撤销；无批准即 `d(J_t,J_0)>ε` 为**目标漂移**；安全/伦理不可投票修改。

**定义 321（PVR）** 在线估计 `ρ_echo`、适应速率、偏好漂移、回声回路（`I(提议;回答)` 控制真实准确率后仍超阈或答案方差异常收缩）；触发则答案降权、探针停用、回 R69。

**定义 322（GAL）** 按能力 `L0 影子→L1 低风险→L2 监督→L3 认证自主`；升级需 `VF_lcb≥τ`、回声达标、目标已批准、`ΔV_cap>0` 且迎合不主导、安全证书有效、预算合规；任一失败自动降级；安全包络独立、升级不扩张。

**定义 323（NEB）** `E_max`、疲劳模型、同意/退出/补偿/数据最小化；`E_used>E_consented` 或用疲劳/权威差/时间压力换取同意即**剥削**；教学负荷与收益成比例且硬上限。

**定义 324–325（干扰集与证书）** `ℰ_CRAFT=ℰ_FLUID×ℰ_co`（迎合/锚定/疲劳/cohort 污染/目标漂移/共谋/表演性部署）；`J_CRAFT` 并入 VF、分解、回声、目标版本/批准、权威、预算与协议清单，全项满足才 Valid。

**定义 326–327（退避与稳定性）** 验证通过→保留 R69 resolution bonus 并升一级（validation bonus）；失败→`λ=λ_floor(U_ale+U_epi)`、降级、停更，R69 为边界。共创安全运行需 `T` 压缩/有界、探针持续激励、回声回路增益<1；否则冻结共创。

```python
# IP-264 CPM：用户共创过程模型（慢环，异步）
class CoCreationProcessModel:
    def update(self, u, h, g, y):
        u2 = self.T(u, h, g, y)                  # 目标/心智/信任/专长/疲劳均可变
        return u2, self.goal(u2)                 # R69 中 T=id、goal 恒定

# IP-265/266 CVoI + 假设盲征询
def choose_co_creation_action(modes, u, o, budget, pvr):
    if pvr.rho_echo > TAU_ECHO: return None      # 回声过高：不采信
    best = None
    for g in candidate_queries_and_designs(modes, o):
        if not budget.allow(g, u): continue
        if not c_ras_wm.certify_info(g, o): continue
        if not hypothesis_blind_or_counterbalanced(g, modes): continue
        info = mutual_info_debiased(modes, g, u, pvr)         # 用 p~ 扣除回声
        cv = (1 - pvr.rho_echo) * info - cost(g) \
             - ETA * burden(g, u) - GAMMA * validation_debt(g)
        if best is None or cv > best.cv: best = (g, cv)
    return best if best and best.cv > 0 else None             # 无利可图 → R69

# IP-267 DPR：随机化、反平衡的设计探针
def design_probe(candidates, u, rng):
    order = rng.permutation(len(candidates))     # 反平衡，抑制顺序/锚定
    y = present_and_collect(candidates, order)   # 选择 + 修正 + “都不满意”
    return bayes_update_user_preference(y, anchoring_model=order)

# IP-268/269 CPV + CRE：2×2 反事实分解
def counterfactual_validation(pi, pi_sham, cohort):
    A = eval(pi,      cohort.adapted); B = eval(pi,      cohort.fresh)
    C = eval(pi_sham, cohort.adapted); D = eval(pi_sham, cohort.fresh)
    dV_obs, dV_cap = A - C, B - D
    dV_accom = (A - B) - (C - D)                  # 差中差
    vf = dV_cap / max(EPS, dV_obs)
    return vf_lcb(vf, cohort), dV_cap, dV_accom, dV_obs

# IP-270/272 VFG + GAL：验证门与权威阶梯
def authority_gate(M, cert, vf_lcb, echo):
    ok = (cert.valid and vf_lcb >= TAU_VF and echo <= TAU_ECHO
          and cert.goal_informed_ratified and cert.budget_ok)
    if not ok:
        return M.gal.demote(), M.r69_conservative()   # 退回 R69
    return M.gal.maybe_promote(cert.capability, vf_lcb)

# IP-278 CRAFT 主闭环（包住 R69，实时安全路径不变）
def CRAFT_RAS_round(M, obs, u):
    if M.slow_tick.due():                        # 0) 慢环：用户模型/回声/预算
        u, M.goal = M.cpm.update(u, M.interface.last, M.last_q, M.last_a)
        M.pvr.update(M.query_log, M.answer_log); M.neb.charge(M.last_teaching)
    echo = M.pvr.rho_echo
    # 1) 实时仍是 R69：零学习写 + 同一安全认证
    k, lam, mode, (U_ale, U_epi) = M.fluid.step(obs, u)
    # 2) 仅当回声/预算/盲化允许时发起共创动作
    g = M.cvoi.choose(M.fluid.last_modes, u, obs, M.neb, M.pvr) \
        if echo <= TAU_ECHO else None
    if g is not None:
        y = M.execute_with_consent(g)
        u = M.cpm.update(u, M.interface.last, g, y)[0]
        mode = M.cia_update_blind(mode, y, M.pvr)   # 去偏后才并入后验
    # 3) 验证红利：只有 VF_lcb 达标才升级，否则回 R69 保守
    if M.validation_tick.due():
        vf_lcb, dV_cap, dV_accom, _ = M.cpv.run(M.policy, M.sham, M.cohort)
        M.vfg.update(vf_lcb, dV_cap, dV_accom, echo)
        L = M.gal.gate(vf_lcb, echo, M.cert)
        if not L.ok: lam = max(lam, M.r69_lam(lam, U_ale, U_epi))
    # 4) 账本 + 证书；安全包络由 R68/R69 独立决定
    M.ccl.append(M.proposal_graph(), M.goal.version, M.vfg.snapshot(), L.value)
    M.j_craft.emit(M.vfg, M.pvr, M.goal, L, M.neb)
    return k, lam, mode, u, L
```

## 4. 推导

**引理 19（2×2 分解可识别）** 在 SUTVA、随机分配真实/安慰剂与共适应/新用户、统一测量下，
`E[ΔV_obs]=E[ΔV_cap]+E[ΔV_accom]+E[ΔV_meas]`，`ΔV_cap=B−D`、`ΔV_accom=(A−B)−(C−D)` 可识别；安慰剂 C/D 吸收霍桑/新奇/测量漂移。故 `VF` 是**因果归因比例**，不是又一个准确率。

**引理 20（回声放大信息高估）** 用户以概率 ρ 将答案拉向机器人暴露假设 `\hat{M}` 时，
`I_obs(M;y) ≤ I_true(M;y)+ρ·H(M)+o(ρ)`；R69 的 VoI 被系统性高估。盲化+反平衡消除一阶项，残余 `O(1/√n)`。**系**：表演性用户上「越会问越确定」会变成「越会问越自信」。

**引理 21（双时间尺度收敛/坍缩）** 若 `T` 为 γ-压缩（γ<1）且探针持续激励 `λ_min(Σ_probe)≥μ>0`，联合回路收敛到 `O(σ/μ)` 邻域；若回声回路增益 `g_echo≥1`，激励趋于 0，收敛到「提议—回答互相印证」的自证固定点。**系**：回声升高时应**停用探针退回保守**，而不是多问几次。

**定理 18（CRAFT 严格包含 R69）** 当 `T=id, ρ_echo=0, VF=1`、无设计探针与目标漂移时，`CVoI≡VoI`、CPV 退化为普通留出验证、GAL 固定，主闭环逐指令等于 FLUID；任一验证/回声/目标/预算失败则退回 R69 的 `λ_floor` 并降级。R69 是「静止用户 + 无表演性 + 完美可迁移」边界；安全不让步，效率获验证红利。

**定理 19（权威阶梯安全单调）** 权威升级只扩大任务自主范围，不改变 R68/R69 独立计算的认证安全包络；任何 VF 失效、回声越界、目标未批准或安全事件立即降级。故任意升级序列的认证风险 ≤ R69 同状态风险；不存在「靠共创共识绕过安全」的路径。**系**：共创只能决定「做多少」，不能决定「能冒多大险」。

## 7. 本轮最大风险

**一句话**：CRAFT-RAS 的全部权限红利押在「VF 能把真能力与用户迎合分开」这一前提上——而做共创的用户往往就是做验证的用户，系统可以在同一批被自己塑造过的人身上，测出一个漂亮且「有用户背书」的提升；**若 cohort 已被共适应污染、安慰剂又失效，验证就不再是世界给出的判决，而是系统自己训练出来的回声**。这比 R69 的「追问幻影」更隐蔽：幻影至少还是假的模态，回声却穿着人类同意书的外衣。

**次级风险与缓解**：回声/需求特征（HBE + 反平衡 + PVR + 引理 20，越界即停用 CVoI）；目标被悄悄改写（GSR 知情批准 + 版本账本 + 安全不可谈判）；权威越级/安全被共识绕过（GAL 与安全包络解耦 + 定理 19 + 自动降级）；把用户当免费劳动力（NEB 预算/同意/退出/补偿 + E311）；双时间尺度失稳/共依赖（引理 21 压缩与持续激励，不满足即冻结共创）；验证成本与统计功效（预注册 + 收缩估计 + 置信下界，宁可不升级也不用点估计升级）。
