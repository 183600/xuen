### 第 1 轮灵感驱动研究记录（v28，承接 v27）

**灵感词**：VLA（Vision-Language-Action）、UniBot-V1（统一具身基础模型）

**直觉解释**：
v27 的 KEMPC-SMC 把常识硬编码为知识库规则，用 KC/DCC/KACG 给出形式化保证。它的短板不在数学，而在「语义来源」：规则是人工枚举的，遇到开放世界的新情景（R19 的「常识闭塞」）既覆盖不到、也难以在线察觉。VLA 模型正好补这一块——它在海量图文-动作数据上训练，能用自然语言理解「别踩水坑」「绕开正在搬运的人」这类开放语义，并对未见场景泛化；但它同时是黑箱，会幻觉、会输出物理不可行动作，无法自证安全。UniBot-V1 则提示一条统一路径：若感知-语言-动作共享同一动作词表与形态嵌入，证书就有可能跨形态复用并再校验。

于是两者互补：VLA 提供「世界懂什么」，证书提供「机器人保证什么」。真正的难点在于两者说的可能不是同一件事——所以还需要第三样东西来对账。

**关键洞见**：不要把 VLA 当控制器直接闭环，而应把它当「语义提议器 + 独立常识 oracle」，把 v27 证书栈当「安全盾」，二者构成**双通道认证**（Dual-Channel Certification）：
- 通道 A（VLA→证书）：VLA 以低频（约 2Hz）输出语言条件下的高层意图 I（子目标、接触时序、可供性），经「语义接地证书 SGC」编译成证书可消费的时序约束 C，再由 KEMPC 在形式约束下精化为可执行轨迹；
- 通道 B（证书→VLA）：证书层把违规残差、不可行约束、OOD 分数结构化回灌给 VLA，令其作为独立常识 oracle 指出「知识库漏了什么」，在线修补 R19；
- 二者之间设一道「对齐证书 AC」：仅当 VLA 提议分布与证书可行域足够接近时才放行，否则降级为纯证书的保守控制。

一句话：**让 VLA 负责「世界懂什么」，让证书负责「机器人保证什么」，对齐证书负责「两者是否在说同一件事」。**

**形式化目标**：
1. 意图抽象 ψ: O×L → I，把观测 o 与指令 ℓ 映射为有限符号子目标集合 I；
2. 语义接地证书 SGC(ℓ, I, C)：ℓ 的每个原子命题可映射为可测谓词，且 C 蕴含 ℓ 的可满足语义；
3. 对齐证书 AC：KL(π_VLA(·|o,ℓ) ‖ π_cert(·|x,C)) ≤ ε_align 且语义残差 r_s ≤ δ_s；
4. 双通道准入 DCCG：admit(Π) ⟺ KACG.admits(Π) ∧ SGC ∧ AC；AC 失败时回退 v27 证书-only 控制；
5. UniBot-V1 形态嵌入 g_m 下的证书迁移 MCCT：跨形态复用证书时做形态条件化实例化与再验证；
6. 语义残差监控 SRM 与 OOD 检测，给出 R19 的可检测性界（保形预测意义下）；
7. 证明 Exec_v28 ⊆ Exec_v27 ⊆ Exec_v26（新增层只做减法），以及 AC 失败降级的安全性。

**本轮最大风险**：VLA 与证书若共享同一批训练/标注偏差，对齐证书会「同错互证」——两个通道给出高度一致的错误答案，AC 反而制造虚假安全感，这比单通道失效更隐蔽、更难在线发现。

## 2. 关键算法骨架

### IP-465 VLA 意图抽象（VIA）

```python
@dataclass
class VLAIntentAbstraction:
    """意图抽象层：把 VLA 的低频输出压缩为证书可消费的符号子目标"""
    vla: Callable                     # π_VLA(a | o, ℓ)，冻结或半冻结
    intent_space: list[str]           # 子目标词表: goto/avoid/grasp/push/...
    parse_head: Callable              # 轻量解析头: latent -> 结构化意图
    freq_hz: float = 2.0              # VLA 低频推理频率（异步线程）
    _cache: object = None
    _ts: float = 0.0

    def abstract(self, obs: Tensor, instr: str) -> 'Intent':
        now = time.time()
        if self._cache is None or now - self._ts > 1.0 / self.freq_hz:
            latent = self.vla.encode(obs, instr)         # 共享 latent
            subgoals = self.parse_head(latent)           # [{type,args,t_start,t_end}]
            self._cache = Intent(instruction=instr, subgoals=subgoals, latent=latent)
            self._ts = now
        return self._cache
```

### IP-466 语义接地证书（SGC）

```python
@dataclass
class SemanticGroundingCertificate:
    """ℓ 的每个原子命题 -> 可测谓词，并验证 C ⊨ ℓ"""
    lexicon: dict                    # 词 -> 谓词模板，如 "wet_floor" -> lambda x: esdf(x) < 0.05
    entailer: Callable               # 轻量符号/区间蕴含检查

    def ground(self, instr: str, intent: 'Intent') -> tuple[bool, list, str]:
        atoms = parse_atoms(instr)                 # 自然语言 -> 原子命题
        preds, phi = [], []
        for a in atoms:
            if a.pred not in self.lexicon:          # 不可接地谓词
                return False, [], f"ungrounded predicate: {a.pred}"
            preds.append(self.lexicon[a.pred])      # 每个原子都必须是可测谓词
            phi.append(a)
        C = compile_to_temporal(preds, intent)      # 生成时序约束 C
        if not self.entailer(C, phi):               # C 是否蕴含指令语义
            return False, preds, "spec does not entail instruction"
        return True, preds, "ok"
```

### IP-467 对齐证书（AC）

```python
@dataclass
class VLAAlignmentCertificate:
    """量化 VLA 提议分布与证书可行域的分歧：KL + 语义残差"""
    eps_align: float = 0.15
    delta_s: float = 0.10
    n_mc: int = 32

    def verify(self, vla, cert_policy, x, instr, obs) -> tuple[bool, dict]:
        kl, rs = 0.0, 0.0
        for _ in range(self.n_mc):
            a = vla.sample(obs, instr)
            lp_v = vla.logprob(a, obs, instr)
            lp_c = cert_policy.logprob(a, x)            # 证书投影后的策略
            kl += (lp_v - lp_c) / self.n_mc             # 重要性近似 KL
            rs += torch.norm(vla.latent_intent(obs, instr)
                             - cert_policy.project_intent(x)) / self.n_mc
        ok = (kl <= self.eps_align) and (rs <= self.delta_s)
        return ok, {"kl": kl.item(), "semantic_residual": rs.item()}
```

### IP-468 双通道控制器（CVLA）

```python
class CertifiedVLAController:
    """VLA 低频提议 + KEMPC 高频精化 + AC 放行/降级"""
    def __init__(self, via, sgc, kempc, ac, srm, csob, v27_gate):
        self.via, self.sgc, self.kempc = via, sgc, kempc
        self.ac, self.srm, self.csob, self.v27_gate = ac, srm, csob, v27_gate
        self._intent = None

    def step(self, obs: Tensor, instr: str, x0: Tensor) -> tuple:
        # 1) 低频 VLA 提议（VIA 内部缓存/异步）
        intent = self.via.abstract(obs, instr)
        ok_g, preds, msg = self.sgc.ground(instr, intent)
        if not ok_g:                                   # 指令不可接地 -> 直接降级
            return self._degrade(x0, reason="SGC_FAIL:" + msg)

        # 2) 证书层精化（50Hz）
        u, kc, dcc = self.kempc.solve(x0, spec=intent.to_spec())

        # 3) 对齐证书：VLA 与证书是否说同一件事
        ok_a, stats = self.ac.verify(self.via.vla, self.kempc.policy, x0, instr, obs)

        # 4) 语义残差 / OOD 监控
        r_ood = self.srm.score(obs, intent)
        if not ok_a or r_ood > self.srm.tau:
            self.csob.report(obs, instr, stats, r_ood)  # 回灌，修补知识库
            reason = "AC_FAIL" if not ok_a else "OOD"
            return self._degrade(x0, reason=reason)

        # 5) v27 八证准入（只做减法，保证单调安全）
        if not self.v27_gate.admits_from(x0, u, kc, dcc):
            return self._degrade(x0, reason="KACG_FAIL")
        return u, {"kc": kc, "dcc": dcc, "ac": stats, "ood": r_ood}

    def _degrade(self, x0: Tensor, reason: str) -> tuple:
        u, kc, dcc = self.kempc.solve(x0)               # 纯证书保守控制（v27）
        return u, {"degraded": reason, "kc": kc, "dcc": dcc}
```

### IP-469 常识 oracle 桥（CSOB，针对 R19）

```python
@dataclass
class CommonSenseOracleBridge:
    """把 VLA 当独立常识 oracle，向 WLKB 提出候选规则（先审核，后注入）"""
    vla: Callable
    wlkb: 'WalkingLocomotionKnowledgeBase'
    pending: list = field(default_factory=list)

    def report(self, obs, instr, align_stats, ood):
        expl = self.vla.explain(obs, instr)             # 自然语言解释
        cand = self._extract_rule(expl, align_stats)    # 解释 -> 候选谓词规则
        if cand and self._novel(cand):
            self.pending.append(cand)                   # 进入审核队列，不直接注入

    def _novel(self, cand) -> bool:
        return not any(r.name == cand.name for r in self.wlkb.rules)
```

### IP-470 跨形态证书迁移（MCCT，UniBot-V1）

```python
@dataclass
class MorphologyConditionedCertTransfer:
    """统一动作词表 + 形态嵌入下的证书迁移；迁移后必须再验证"""
    g_src: Tensor
    g_dst: Tensor
    action_vocab: dict                 # UniBot-V1 统一动作词表

    def transfer(self, cert_src, dynamics_dst) -> 'KnowledgeCertificate':
        pred_dst = self._remap(cert_src.postcond, self.g_src, self.g_dst)
        cert_dst = KnowledgeCertificate(
            cert_src.name + "@dst", cert_src.precond, pred_dst, H=cert_src.H)
        if not cert_dst.verify(dynamics_dst.initial_state, dynamics_dst):
            raise ValueError("cross-morphology certificate re-verification failed")
        return cert_dst
```

### IP-471 双通道准入门（DCCG）

```python
@dataclass
class DualChannelCertificationGate:
    """v27 KACG ∧ VLA 通道；任一失败即拒绝，运行时再降级"""
    kacg: 'KnowledgeAwareCertificationGate'
    via: VLAIntentAbstraction
    sgc: SemanticGroundingCertificate
    ac: VLAAlignmentCertificate

    def admits(self, plan, obs, instr) -> bool:
        if not self.kacg.admits(plan.single_plan, plan.sensor):   # v27 先决
            return False
        intent = self.via.abstract(obs, instr)
        ok_g, _, _ = self.sgc.ground(instr, intent)
        if not ok_g:
            return False
        ok_a, _ = self.ac.verify(self.via.vla, plan.policy,
                                 plan.init_state, instr, obs)
        return ok_a
```

### IP-472 语义残差监控（SRM）

```python
@dataclass
class SemanticResidualMonitor:
    """语义残差 / OOD 在线监控；τ 用保形预测校准"""
    tau: float = 0.3
    memory: list = field(default_factory=list)

    def score(self, obs, intent) -> float:
        z = self.vla.latent(obs)
        if not self.memory:
            self.memory.append(z)
            return 0.0
        d = min(torch.norm(z - m) for m in self.memory)
        self.memory = (self.memory + [z])[-256:]
        return d.item()

    def calibrate(self, calib_scores: list, alpha: float = 0.05) -> None:
        # 保形分位数：保证 P(r_OOD > τ) ≤ alpha（可交换性下）
        self.tau = sorted(calib_scores)[int((1 - alpha) * len(calib_scores))]
```

## 3. 复杂度分析（增量）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |

## 4. 正确性论证（增量）

### 引理 23（SGC 接地的可靠性）

**陈述**：若 `SGC.ground(ℓ,I) = True`，则 ℓ 中每个原子命题都对应一个可测谓词，且编译出的时序约束 C 蕴含 ℓ 的可满足语义。

**证明**：ground 对每个原子 a 强制查表 `lexicon[a.pred]`，缺失即返回 False；所有原子通过后才调用 entailer 检查 C ⊨ φ。故通过时每个原子可测且 C 蕴含 ℓ。∎

### 引理 24（AC 的分歧界）

**陈述**：若 `AC.verify = True`，则 π_VLA 与 π_cert 的总变差距离 TV ≤ √(ε_align/2)，且语义残差 r_s ≤ δ_s。

**证明**：由 Pinsker 不等式 TV ≤ √(KL/2)，AC 通过给出 KL ≤ ε_align，故 TV ≤ √(ε_align/2)；r_s 由 verify 直接检查 ≤ δ_s。∎

### 引理 25（单调安全）

**陈述**：`DCCG.admits(Π) = True` ⟹ `KACG.admits(Π) = True`，故 Exec_v28 ⊆ Exec_v27 ⊆ Exec_v26。

**证明**：DCCG.admits 的第一项即 `kacg.admits`，后接 SGC 与 AC 的合取；新增过滤器只会进一步收缩集合。∎

### 定理（双通道安全与降级）

**陈述**：对任意计划 Π，CVLA 的运行要么输出通过 DCCG 的动作（安全继承 v27），要么在 AC/SGC/OOD/KACG 任一失败时降级为 v27 证书-only 控制；因此 `Exec_v28 ∪ Degraded ⊆ Exec_v27`。

**证明**：CVLA.step 的放行分支显式调用 `v27_gate.admits_from`，通过者必属 Exec_v27；任一失败分支调用 `_degrade`，其输出由 `kempc.solve` 生成，正是 v27 的可行控制。两种情况都不产生 Exec_v27 之外的计划。∎

### 引理 26（R19 的可检测性）

**陈述**：若 SRM 的 τ 由可交换校准集按保形分位数 α 选取，则对新情景漏检概率 ≤ α。

**证明**：保形预测在可交换性假设下给出 `P(r_OOD > τ) ≤ α`；一旦超过 τ 即触发降级与 CSOB 回灌。故「常识闭塞」被漏检的概率受 α 约束。∎

## 5. 实验设计（含预期结果，模拟）

**任务**：T1 语言条件双足导航（「去红门，避开湿地」）；T2 locomanipulation（「把箱子推到桌下，别碰倒杯子」）；T3 OOD 突发（未见滑坡/障碍坍塌，测 R19）；T4 跨形态迁移（双足→轮足，测 MCCT）。

**基线**：OpenVLA/π0 直接控制、KEMPC-only（v27）、CVLA（本文），及 CVLA 去 AC / 去 CSOB / 去 MCCT 三个消融。

| 方法 | 成功率↑ | 安全违规/千步↓ | OOD AUROC↑ | AC 拒绝率 | 控制延迟 |
|---|---|---|---|---|---|
| VLA 直接 | 0.62 | 8.3 | 0.55 | — | 180ms |
| KEMPC-only (v27) | 0.71 | 0.4 | 0.61 | — | 12ms |
| CVLA（本文） | 0.86 | 0.3 | 0.88 | 9% | 190ms(异步) |
| CVLA − AC | 0.80 | 2.1 | 0.86 | 0% | 185ms |
| CVLA − CSOB | 0.79 | 0.4 | 0.66 | 9% | 190ms |
| CVLA − MCCT (T4) | 0.74 | 0.3 | 0.85 | 9% | 190ms |

**结论预期**：AC 主要贡献安全（去掉后违规率升 7 倍）；CSOB 主要贡献 OOD 检测（去掉后 AUROC 从 0.88 跌到 0.66）；MCCT 主要贡献跨形态成功率。三者分工与设计假设一致。

|---|---|---|---|---|
| R22 | VLA 与证书共享偏差导致 AC「同错互证」 | 高 | 1) 训练/标注来源去相关；2) 引入第三独立检查（物理仿真残差）；3) AC 只作否决不作背书 | 相关性偏差下仍可能虚假放行 |
| R23 | VLA 推理延迟破坏 50Hz 实时性 | 中 | 1) 异步线程 + 意图缓存；2) 蒸馏小 VLA；3) 掉帧时沿用旧意图 | 意图突变时缓存滞后 |
| R24 | SGC 词表覆盖不足，指令无法接地 | 中 | 1) 词表持续扩充；2) 不可接地时请求澄清；3) 降级到证书保守控制 | 长尾指令频繁被拒 |
| R25 | MCCT 跨形态负迁移 | 中 | 1) 迁移后强制再验证；2) 形态相似度门槛；3) 失败回退源形态证书 | 形态差异过大时迁移失效 |

## 7. 本轮最大风险（最终确认）

**一句话**：**VLA 与证书若共享同一批训练/标注偏差，对齐证书会「同错互证」——两个通道给出高度一致的错误答案，AC 反而制造虚假安全感，这比单通道失效更隐蔽、更难在线发现，是当前方案最大的安全隐患。**
