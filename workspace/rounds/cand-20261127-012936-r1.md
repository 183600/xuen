灵感驱动研究循环·第 2 轮；本轮灵感：「遥操作」×「开源生态」

> **基线**：第 2 轮产出 MetricVoiceGauge-NCD-HUTDH-v23（云边同步 CESC/FSVC/IPAM + HPC-E+ 四证准入门；其上承 v22 分层 PGEV/ACSC/DCSC/CFC++，v21 语义-规范层 SDC/CAC/DCL/GIC，v20 联邦感知证书 PCA/CTS/CFC/HPC）。
> 本轮纪律：**远程命令是"权威"而非"证据"；开源模块是"被组合的组件"而非"天然独立的证人"**。不推倒 v23：CESC/FSVC/IPAM/HPC-E+ 全部保留。本轮只做一件事：**把 v23 的"版本一致 + 统计覆盖 + 专利完备"扩展为"权威可追溯 + 延迟可无源 + 供应链可复现 + 血统可独立"的可审计信任根，并把 v23 的最大风险（协同故障共振）从"概率问题"重构成"结构问题"**。

## 0. 直觉与动机

**灵感 1（遥操作 → 延迟权威，权威 ≠ 证据）**
直觉：遥操作把一个人放进控制回路，但这个人看到的画面是 `T_rt` 之前的世界，他按下的"前进"在到达机器人时已经过期。最危险的误读是：把人的命令当成安全证据——"人说了可以"并不等于"现在安全"。正确的定位是：**远程命令只是一枚权威令牌（authority token），它只能"许可"执行已经由当前证书证明安全的动作，绝不能"创造"安全**。三个后果：(a) 命令必须带签发时刻与 TTL，过期即失效，链路中断绝不"沿用最后一条命令"（watchdog 到期 → 回落自治证书模式或 SafeStop）；(b) 操作员的态势感知本身也是延迟、有损的，必须单独签发**态势感知证书**，命令只有在"操作员以为的世界"与"机器人此刻的世界"对齐（`σ_SA ≤ ε_SA`）时才有意义；(c) 时延会破坏双边遥操作的无源性（passivity），延迟通道可能向系统注入能量——这条必须并入 v22 的 PGEV 能量账户，而不是当作通信质量问题忽略。核心创新：**远程权威证书 (Remote Authority Certificate, RAC) + 态势感知证书 (Situational Awareness Certificate, ASAC) + 延迟无源性证书 (Delay-Passivity Certificate, DPC)**。关键反直觉点：**引入人并不放宽安全边界，反而多了一层"双时刻交集"——命令必须在"签发时刻的证书"与"执行时刻的证书"下同时安全**，故 `Exec_v24 ⊆ Exec_v23` 依旧成立。副产品的妙处：把"人"正式建模为**有延迟、会误判、但拥有许可权的外部主体**，正是 v21 GIC 意图层缺失的"权威"维度。

**灵感 2（开源生态 → 供应链证书与"血统感知的独立性"）**
直觉：v23 的证书栈已经是由大量模块拼起来的，而真实部署中这些模块来自开源生态：社区检测模型、第三方规则包、fork 出来的遥操作插件。开源带来可审计与可复现的红利，但也带来两个致命错觉。**错觉一：开源 = 可信。** 一段代码是否可信，取决于它的来源、构建是否可复现、依赖闭包有无已知漏洞、许可证是否与部署相容，而不是"它公开"。**错觉二：多份 = 独立。** 十个模块里九个 fork 自同一个上游，它们会共享同一个 bug、同一个 CVE——在共识里它们是**同一个证人投了九票**。这正是 v23 最大风险（相关故障共振）的代码版。核心创新：**供应链血统与许可证证书 (Supply-chain Provenance & License Certificate, SPLC)** 与 **血统感知共识 (Provenance-Aware Consensus, CFC^prov)**：前者把 SBOM、可复现构建哈希、SPDX 许可证相容性、依赖闭包、CVE 状态编译成可机械复核的证书；后者按**血统独立分量**而非模块个数计票。关键反直觉点：**开源生态最有价值的不是"更多实现"，而是"可被第三方独立复现的证书"——可复现性才是独立的度量**。信誉分只能做软先验，绝不能做硬安全门（可被刷分对抗）。

**灵感 3（统一 → 证据血统图 EPG：把"独立"变成可计算的结构）**
直觉：遥操作证据的独立性是**时间维度**的（同一帧过期遥测派生的多条"证据"其实是同一个世界快照）；开源证据的独立性是**代码维度**的（同一上游派生的多个模块其实是同一段逻辑）。二者是同一个问题的两个投影：**一条证据到底"新不新、是不是和别人同源"**。于是定义统一的**证据血统图 (Evidence Provenance Graph, EPG)**：节点是证据，边有两类——代码血统边（共享上游 / 权重 / 构建）与时间快照边（落在同一 TTL 窗口、同一遥测帧）。共识只在 EPG 的**独立连通分量**上计票。关键反直觉点：**v23 的"共振崩塌"不是概率上的小概率事件，而是 EPG 上"所有票连成一个分量"的结构必然**；因此修复它不需要更强的模型，只需要让计票发生在正确的图上。

**三者如何统一**
统一为 **v23 之上的"信任根层"**：RAC/ASAC/DPC 回答"这个远程权威是否新鲜、对齐、无源"，SPLC 回答"这些模块是否可复现、许可证相容、无已知漏洞"，EPG/CFC^prov 回答"这些证据是否真正独立"。共享状态扩展为 **`ζ_trust = ζ_ce ∪ (A_t, SA_t, E_delay, SBOM, lic_expr, lineage_DAG, G_E)`**。统一准入门升级为 **HPC-O（Open-Authority Gate）= HPC-E+ ∧ RAC ∧ DPC ∧ SPLC ∧ (EPG 独立分量 ≥ Q_min)**，即 `Exec_v24 = Exec_v23 ∩ Fil_auth ∩ Fil_passive ∩ Fil_supply ∩ Fil_prov ⊆ Exec_v23`。任一缺失向更保守方向退化。

## 2. 设计原则（在 P37–P42 基础上新增 P43–P46）

**P43 权威不创造安全律（Authority Does Not Create Safety）**
远程命令是过滤器而非证据：`Exec_v24 = Exec_v23 ∩ Safe(t_cmd) ∩ Safe(t_exec) ∩ Fil_auth`。RAC 令牌 `a=(op, cmd, t_issue, t_exp, H(SA), sig)` 仅在 `Fresh(a,t) ∧ SigOK(a) ∧ σ_SA(t) ≤ ε_SA` 时有效；失效 / 过期 / 断链绝不沿用最后命令，而是回落自治证书模式或 SafeStop。故远程权威只能收缩执行集。

**P44 延迟无源律（Delay Passivity）**
遥操作通道必须满足无源观测器 `E_obs(t) ≥ −E_margin`，且延迟注入能量计入 PGEV：`E_res ≥ E_fallback + E_arm + E_delay + E_margin`，其中 `E_delay ≤ P_max · TTL_auth`（保守上界）。任一无源观测失败 → 降级为单向"人在环外"的自治模式，而非继续双边闭环。

**P45 供应链可复现律（Supply-chain Reproducibility）**
计划 π 的依赖闭包 `closure(π)` 中每个模块必须有有效 SPLC：`SPLC(m) ≜ SBOM(m) ∧ Reproducible(m) ∧ Compat(lic_expr(closure)) ∧ ¬∃CVE_unmitigated(m)`。可复现性由 ≥2 个独立构建者的哈希一致定义；许可证相容按部署语境判定；低危 CVE 允许带补偿控制放行（显式记录），高危可利用 CVE 一票否决。

**P46 血统独立计票律（Provenance-Independent Quorum）**
共识在 EPG 的独立连通分量上计票：`CFC^prov` 接受某声明当且仅当支持该声明的独立分量数 `≥ Q_min` 且总分量数 `≥ Q_min + Q_byz`；血统边 = 共享上游 / 权重 / 构建，时间边 = 同一 TTL 快照。元数据缺失或不可验证 → 保守合并为同一分量（只算一票）。信誉分仅作软先验，永不单独放行。

## 3. 与基线的接口（如何退化）

- RAC 失效（链路断 / 令牌过期 / 验签失败）⇒ 撤销远程权威，回落 v23 自治证书模式（更保守）；
- ASAC 失效（态势对齐不可信）⇒ `σ_SA` 取 ∞，权威无效 ⇒ 回落自治；
- DPC 失效（无源观测不可信）⇒ 禁止双边闭环，退化为单向监督 + 自治证书 ⇒ 子集；
- SPLC 失效（SBOM / 构建哈希缺失）⇒ 该模块视为未认证，相关计划退回 v23 已验证模块集 ⇒ 子集；
- EPG 失效（血统元数据不可验证）⇒ 全部证据合并为单一分量，`Q_min` 无法满足 ⇒ 退回 v23 的 CFC+++ 但带更严 quorum ⇒ 子集；
- 四者全失效 ⇒ 完全回退 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ ... ⊆ Exec_v18`（引理 5）。
- **安全继承**：权威只收缩、延迟只计入耗散账户、供应链只排除未认证模块、血统只合并分量；任意失效都向更保守方向退化。RAC/DPC/SPLC 的验证均为离线 / 事件式，控制路径只做 O(1) 令牌新鲜度与分量计数查询，接入 v17 APS 新鲜度阶梯。

## 4. 预期贡献

1. **远程权威证书**：首次把遥操作命令建模为"带 TTL 与态势对齐约束的权威令牌"而非安全证据，给出"双时刻安全集交集"与断链 watchdog 的可审计语义；
2. **延迟无源性并入能量证书**：把时延注入能量 `E_delay` 纳入 PGEV 能量不变量，给出双边遥操作在丢包 / 抖动下的无源上界与降级路径；
3. **供应链与许可证证书**：把 SBOM、可复现构建、SPDX 许可证相容、依赖闭包 CVE 编译成可机械复核的 SPLC，扩展 v23 的专利认证到开源合规；
4. **血统感知共识**：用 EPG 把"独立性"从口号变成可计算的连通分量，按血统独立分量而非模块计数计票，结构性封堵 v23 的相关故障共振；
5. **可复现即独立**：提出"开源生态的价值在于第三方可复现证书"，把可复现构建作为独立性的度量，而非把实现数量当作冗余；
6. **HPC-O 统一信任根**：HPC-E+ ∧ RAC ∧ DPC ∧ SPLC ∧ EPG 五证一体，`Exec_v24 ⊆ Exec_v23` 闭环。

## 5. 本轮最大风险

**一句话**：整套方案把"独立"与"新鲜"押在血统 / 时间元数据上，而 vendored 代码、复制粘贴、同源权重、伪造 SBOM 或 TTL 内重放都能让"独立分量"其实是同一个证人——机器人会在**被血统洗白的伪独立共识**下，执行一条既"可复现"又"可审计"却仍然撞人的命令。

## 1. 关键算法骨架（在 IP-439 骨架上扩展）

```python
# ============================================================
# IP-440/441 Remote Authority + Situational Awareness (RAC/ASAC)
# ============================================================
@dataclass
class AuthorityToken:
    op: str
    cmd: Plan                      # 期望动作（不是安全证据）
    t_issue: float
    t_exp: float
    h_SA: bytes                    # 态势感知证书哈希
    sig_op: bytes                  # 操作员密钥签名
    sig_relay: bytes               # 中继/边端密钥签名（防重放）

    def fresh(self, t: float, ttl: float) -> bool:
        return t <= self.t_exp and (t - self.t_issue) <= ttl

    def verify(self, pk_op, pk_relay, nonce_seen: set) -> bool:
        if not (verify_sig(pk_op, self.digest(), self.sig_op)
                and verify_sig(pk_relay, self.digest(), self.sig_relay)):
            return False
        # 防 TTL 内重放：令牌哈希 + 单调 nonce 只接受一次
        key = blake2b(self.digest() + int(self.t_issue).to_bytes(8, "big")).digest()
        if key in nonce_seen:
            return False
        nonce_seen.add(key)
        return True

class SituationalAwarenessCert:
    """ASAC：给 σ_SA 一个 ≥1-δ 上界，而不是假设操作员全知。"""
    def __init__(self, delta=1e-3, lam_occ=0.4, lam_bw=0.2):
        self.delta, self.lam_occ, self.lam_bw = delta, lam_occ, lam_bw

    def bound(self, n_obs: int, occ_ratio: float, bw_kbps: float) -> float:
        if n_obs <= 0:
            return float("inf")                      # 无遥测 ⇒ 不可对齐
        stat = math.sqrt(math.log(2.0 / self.delta) / (2.0 * n_obs))
        return stat + self.lam_occ * occ_ratio + self.lam_bw / max(bw_kbps, 1e-3)

class RemoteAuthorityGate:
    def __init__(self, ttl_auth=0.3, eps_sa=0.25):
        self.ttl_auth, self.eps_sa = ttl_auth, eps_sa
        self.nonce_seen: set[bytes] = set()
        self.audit: list[dict] = []

    def admit(self, a: AuthorityToken, t: float, asac: SituationalAwarenessCert,

            reasons.append("sig_or_replay")
        if not a.fresh(t, self.ttl_auth):
            reasons.append("stale")                   # 过期绝不沿用
        sigma = asac.bound(n_obs, occ, bw)
        if sigma > self.eps_sa:
            reasons.append(f"sa_diverged:{sigma:.3f}")

        admitted_plan = (a.cmd
                         & safe_now & safe_cmd
                         & {p for p in a.cmd if p in safe_now})
        ok = not reasons and len(admitted_plan) > 0
        self.audit.append({"t": t, "op": a.op, "ok": ok,
                           "reasons": reasons, "sigma": sigma})
        return ok, admitted_plan, reasons

# IP-442 Delay-Passivity Certificate (DPC)
# ============================================================
class DelayPassivityMonitor:
    """波变量 + 无源观测器；把时延注入能量并入 PGEV 储备。"""
    def __init__(self, b=1.0, dt=0.02, E_margin=0.5, P_max=200.0):
        self.b, self.dt, self.E_margin, self.P_max = b, dt, E_margin, P_max
        self.E_obs = 0.0
        self.E_delay_bound = 0.0

    def wave(self, f, v):
        return (f + self.b * v) / math.sqrt(2 * self.b), \
               (f - self.b * v) / math.sqrt(2 * self.b)

    def observe(self, f_m, v_m, f_s, v_s):
        # 端口功率：正=注入系统，负=耗散
        p = float(np.dot(f_m, v_m) + np.dot(f_s, v_s))
        self.E_obs += self.dt * p
        return self.E_obs

    def delay_energy_budget(self, ttl_auth: float) -> float:
        # 过期权威窗口内最大注入能量（保守上界）
        self.E_delay_bound = self.P_max * ttl_auth
        return self.E_delay_bound

    def passive_ok(self, E_res, E_fallback, E_arm) -> bool:
        return (self.E_obs >= -self.E_margin and
                E_res >= E_fallback + E_arm + self.E_delay_bound + self.E_margin)

    def on_link_loss(self):
        # 单侧断链：立即把参考速度置零，账户只允许耗散
        self.E_delay_bound = 0.0
        return "one_side_autonomy"   # 退化为单向监督 + 自治证书

# IP-443 Supply-chain Provenance & License Certificate (SPLC)
# ============================================================
class SupplyChainAttestor:
    def __init__(self, builders_required=2, cve_theta=7.0):
        self.builders_required = builders_required
        self.cve_theta = cve_theta
        self.audit: list[dict] = []

    def closure(self, plan_modules: list[str]) -> set[str]:
        seen, stack = set(), list(plan_modules)
        while stack:
            m = stack.pop()
            if m in seen:
                continue
            seen.add(m)
            stack.extend(self.sbom.get(m, {}).get("deps", []))
        return seen

    def reproducible(self, m: str, build_hashes: dict[str, str]) -> bool:
        if len(build_hashes) < self.builders_required:
            return False
        vals = set(build_hashes.values())
        return len(vals) == 1 and next(iter(vals)) == self.sbom[m]["shipped_hash"]

    def license_compatible(self, closure: set[str], ctx: str) -> bool:
        # SPDX 合取：闭源 ctx 下 strong-copyleft 不可接受；开源 ctx 下均相容
        for m in closure:
            lic = self.sbom[m]["license"]
            if ctx == "closed" and lic in ("GPL-3.0-only", "AGPL-3.0-only"):
                return False
            if not spdx_valid(lic):
                return False
        return True

    def cve_clean(self, closure: set[str], reachable: set[str]) -> bool:
        for m in closure:
            for cve in self.sbom[m].get("cves", []):
                if cve["id"] in reachable and cve["cvss"] * cve["exploitability"] >= self.cve_theta:
                    if not cve.get("mitigated"):
                        return False
        return True

    def verify(self, plan_modules: list[str], build_hashes: dict, ctx: str,
               reachable: set[str]) -> tuple[bool, set[str], list[str]]:
        cl = self.closure(plan_modules)
        reasons = []
        if not all(self.reproducible(m, build_hashes.get(m, {})) for m in cl):
            reasons.append("not_reproducible")
        if not self.license_compatible(cl, ctx):
            reasons.append("license_incompatible")
        if not self.cve_clean(cl, reachable):
            reasons.append("cve_unmitigated")
        ok = not reasons
        self.audit.append({"closure": sorted(cl), "ok": ok, "reasons": reasons})
        return ok, cl, reasons

# IP-444 Evidence Provenance Graph (EPG)
# ============================================================
class EvidenceProvenanceGraph:
    """节点=证据；边=代码血统(共享上游/权重/构建/高相似) 或 时间快照(同TTL/同帧)。"""
    def __init__(self, sim_threshold=0.8, ttl_snapshot=0.3):
        self.parent = {}
        self.sim_threshold, self.ttl_snapshot = sim_threshold, ttl_snapshot

    def add(self, eid):
        self.parent.setdefault(eid, eid)

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra != rb:
            self.parent[rb] = ra

    def add_lineage_edges(self, evidences: list[dict]):
        for i in range(len(evidences)):
            for j in range(i + 1, len(evidences)):
                a, b = evidences[i], evidences[j]
                shared_upstream = bool(set(a["ancestors"]) & set(b["ancestors"]))
                same_weights = a.get("weight_hash") and a["weight_hash"] == b.get("weight_hash")
                same_build = a.get("build_hash") and a["build_hash"] == b.get("build_hash")
                high_sim = jaccard(a["code_shingles"], b["code_shingles"]) >= self.sim_threshold
                if shared_upstream or same_weights or same_build or high_sim:
                    self.union(a["id"], b["id"])

    def add_time_edges(self, evidences: list[dict]):
        for i in range(len(evidences)):
            for j in range(i + 1, len(evidences)):
                a, b = evidences[i], evidences[j]
                same_frame = a.get("frame_id") is not None and a["frame_id"] == b.get("frame_id")
                same_snapshot = abs(a["t"] - b["t"]) <= self.ttl_snapshot
                if same_frame or same_snapshot:
                    self.union(a["id"], b["id"])

    def components(self) -> dict[str, list[str]]:
        comp = defaultdict(list)
        for eid in self.parent:
            comp[self.find(eid)].append(eid)
        return dict(comp)

# IP-445 Provenance-Aware Consensus (CFC^prov)
# ============================================================
class ProvenanceAwareConsensus:
    def __init__(self, Q_min=2, Q_byz=1):
        self.Q_min, self.Q_byz = Q_min, Q_byz

    def consensus_round(self, claim: str, votes: list[dict],
                        epg: EvidenceProvenanceGraph) -> tuple[str, dict]:
        epg.add_lineage_edges(votes)
        epg.add_time_edges(votes)
        comps = epg.components()
        safe_components, unsafe_components, split = 0, 0, 0
        for root, members in comps.items():
            stances = {next(v["stance"] for v in votes if v["id"] == m) for m in members}
            if stances == {"SAFE"}:
                safe_components += 1
            elif stances == {"UNSAFE"}:
                unsafe_components += 1
            else:
                split += 1
        total = len(comps)
        meta = {"components": total, "safe": safe_components,
                "unsafe": unsafe_components, "split": split,
                "independent_witnesses": total}
        if safe_components >= self.Q_min and total >= self.Q_min + self.Q_byz and split == 0:
            return "SAFE", meta
        if unsafe_components >= self.Q_min:
            return "UNSAFE", meta
        return "CI", meta     # 证据不足/分量冲突 ⇒ 保守

# IP-446 HPC-O (Open-Authority Gate)
# ============================================================
@dataclass
class HPCOGate:
    hpc_e_plus: 'HPCEPlus'
    authority: RemoteAuthorityGate
    passivity: DelayPassivityMonitor
    supply: SupplyChainAttestor
    consensus: ProvenanceAwareConsensus

    def admits(self, plan, a: AuthorityToken, t, asac, n_obs, occ, bw,
               safe_now, safe_cmd, E_res, E_fallback, E_arm,
               build_hashes, ctx, reachable, votes, epg, modules):
        # 1) v23 四证
        if not self.hpc_e_plus.admits(plan, *self._hpc_args(plan)):
            return False, "hpc_e_plus"
        # 2) 远程权威（权威≠证据：只收缩）
        ok_auth, cmd_plan, why = self.authority.admit(
            a, t, asac, n_obs, occ, bw, safe_now, safe_cmd)
        if not ok_auth:
            return False, f"authority:{why}"
        plan = plan & cmd_plan
        # 3) 延迟无源
        self.passivity.delay_energy_budget(self.authority.ttl_auth)
        if not self.passivity.passive_ok(E_res, E_fallback, E_arm):
            return False, "passivity"

        if not ok_supply:
            return False, f"supply:{why}"
        # 5) 血统独立共识
        stance, meta = self.consensus.consensus_round("plan", votes, epg)
        if stance != "SAFE":
            return False, f"provenance:{stance}:{meta}"
        return True, "admitted"
```

## 3. 正确性论证

### 引理 5（远程权威只收缩执行集）
**陈述**：对任意令牌 `a`，`Exec_v24(a) ⊆ Exec_v23`，且令牌过期 / 断链时 `Exec_v24 = 自治证书集 ⊆ Exec_v23`。

**证明**：`Exec_v24 = Exec_v23 ∩ Safe(t_cmd) ∩ Safe(t_exec) ∩ Fil_auth ∩ Fil_passive ∩ Fil_supply ∩ Fil_prov`，为 `Exec_v23` 与若干集合之交，故为子集。令牌失效时 `Fil_auth = ∅` 或 watchdog 将 `cmd` 置空，执行退化为自治证书集。命令从不作为证据加入 `Safe`，故不会扩大安全集。∎

### 引理 6（时延无源上界）
**陈述**：若 `E_obs(t) ≥ −E_margin` 且 `E_res ≥ E_fallback + E_arm + P_max·TTL_auth + E_margin`，则双边遥操作闭环在过期权威窗口内无源，延迟最多注入 `P_max·TTL_auth` 能量。

**证明**：端口功率 `p = f_m^T v_m + f_s^T v_s`，无源观测器累积 `E_obs = ∫p dt`。过期窗口长度 ≤ `TTL_auth`，功率上界 `P_max`，故注入能量 ≤ `P_max·TTL_auth`。储备不变量预留该上界后，剩余能量足以覆盖 fallback 与臂能耗，故无源。单侧断链令参考速度为零，账户仅可耗散。∎

### 引理 7（供应链组合可靠性）
**陈述**：若 `∀m ∈ closure(π), SPLC(m)` 成立，则计划 π 的依赖闭包可复现、许可证与部署语境相容、且无可达高危未缓解 CVE。

**证明**：`SPLC` 的四个连言分别由 `Reproducible`（≥2 构建者哈希一致）、`Compat`（SPDX 合取按 ctx 判定）、`CVE_unmitigated`（可达性 × CVSS × 可利用性阈值）保证；`closure` 由 SBOM 依赖边传递闭包得到，故组合层无遗漏。∎

### 引理 8（血统独立计票的共振封堵）
**陈述**：若某声明仅由单一血统分量支持，则 `CFC^prov` 必不接受（因 `#SAFE-components = 1 < Q_min`）；即使模块数任意多，只要它们共享上游，独立分量仍为 1。

**证明**：EPG 的代码血统边连接所有共享上游 / 权重 / 构建 / 高相似代码的节点，时间快照边连接同帧 / 同 TTL 节点；连通分量内的所有票是同一证人的重复。`CFC^prov` 只对分量计票，故 fork 数量与过期快照副本无法制造伪共识。元数据缺失时保守合并为单分量，进一步收紧。∎

### 定理（HPC-O 五证准入门的安全-权威-可复现-独立完备性）
**陈述**：对任意计划 π，`HPCOGate.admits(π) = True` ⟺ π 同时满足：(1) v23 物理接地 / 云边 / 少样本 / 专利四证；(2) 远程权威新鲜且态势对齐；(3) 时延下无源且能量储备充足；(4) 依赖闭包供应链可复现且许可证相容、无高危 CVE；(5) 支持证据在 EPG 上具 ≥Q_min 个独立分量。

**证明**：直接由 `HPCOGate.admits` 的五个连言与引理 5–8 可得。必要性：任一条件缺失即拒证，对应一类未被缓解的风险（过期扩权 / 能量注入 / 供应链污染 / 伪独立共识）。充分性：五条件全满足，由引理 5 保证 `Exec_v24 ⊆ Exec_v23` 单调链，由引理 8 保证共振封堵。∎

```python
class OntologyGraph(nx.DiGraph):
    """轻量本体图：节点为关键部件，边为尺度不变相对位置"""
    def __init__(self, category: str):
        super().__init__()
        self.category = category
        for node in OntologyNode:
            self.add_node(node)
        # 基于类别统计填充边：如 "人" 有头-肩、肩-躯干等边
        self._load_prior(category)
    
    def _load_prior(self, category: str):
        """从类别先验统计加载边：仅在尺度不变子集上有效"""
        prior_path = f"ontology_priors/{category}.json"
        if os.path.exists(prior_path):
            with open(prior_path) as f:
                prior = json.load(f)
            for edge, prob in prior.items():
                if prob > 0.5:  # 只保保留概率高的边
                    parts = edge.split("_")
                    self.add_edge(OntologyNode[parts[0]], OntologyNode[parts[1]], weight=prob)
    
    def consistency_score(self, detected_parts: set[OntologyNode]) -> float:
        """计算检测到的部件集合与本体图的一致性评分"""
        if len(detected_parts) < 2:
            return 0.0
        induced_subgraph = self.subgraph(detected_parts)
        if not nx.is_connected(induced_subgraph):
            return 0.0
        # 评分 = 平均边权 / 期望边权
        edges = list(induced_subgraph.edges(data='weight'))
        if not edges:
            return 0.0
        actual_avg = sum(w for _, _, w in edges) / len(edges)
        expected_avg = sum(self.out_degree(n, weight='weight', default=1.0) for n in induced_subgraph.nodes()) / (2 * len(induced_subgraph.nodes()))
        return min(1.0, actual_avg / max(expected_avg, 1e-3))

class CausalRule:
    """带因果前件的规则：φ = (premise, obligation, deadline, priority)"""
    def __init__(self, rule_id: str, premise: str, obligation: str, 
                 deadline: float, priority: int = 0):
        self.rule_id = rule_id
        self.premise = premise          # 因果前件描述
        self.obligation = obligation    # O/F/P 描述
        self.deadline = deadline        # τ：期限
        self.priority = priority
        self.active_window: tuple[float, float] = None  # (t_start, t_end)
    
    def check_premise(self, state_history: list[RobotState]) -> bool:

        # 简化：检查是否有观测到与 premise 匹配的状态变化
        # 实际实现将使用时间窗口滤波
        return self._match_causal_pattern(state_history)
    
    def _match_causal_pattern(self, state_history: list[RobotState]) -> bool:
        # 因果模式匹配：检查前件在前、义务在后的时序
        # 实际实现使用 LTL 或简化的时间窗口检查
        if len(state_history) < 2:
            return False
        # 简化检查：是否检测到人的移动方向远离机器人
        recent_states = state_history[-10:]  # 最近 10 帧
        approaching = any(
            s.distance_to_robot < s.prev_distance_to_robot 
            for s in recent_states[1:]
        )
        return approaching

class DeonticComplianceLayerHDL:
    """扩展版 HDL：包含因果前件编译与动态激活"""
    def __init__(self, rule_library: list[CausalRule], v20_geom_domain: GeometryDomain):
        self.rule_library = rule_library
        self.geom_domain = v20_geom_domain
        self.active_obligations: set[str] = set()
        self.rule_versions: dict[str, int] = {}  # Merkle 版本追踪
    
    def compile_rules(self, plan: Plan) -> Filters:
        """编译规则为过滤器链：F/O/P + 因果前件"""
        filters = {
            'domain_shrink': set(self.geom_domain),  # 初始为几何域
            'obligation_filters': {},              # O → {plan: φ_rule ∧ τ}
            'permission_unlocks': set()            # P → 解除的 DCL 限制
        }
        
        for rule in self.rule_library:
            # F 规则：域收缩
            filters['domain_shrink'] = filters['domain_shrink'] ∩ rule.domain_shrink()
            
            # O 规则：带因果前件的期限过滤器
            if rule.check_premise(plan.state_history):
                # 前件成立 → 义务激活
                obligation_set = {plan : 
                    ∃t' ≤ τ_rule, state(t') ∈ YieldSet ∧ φ_rule(t')}
                filters['obligation_filters'][rule.rule_id] = obligation_set
                self.active_obligations.add(rule.rule_id)
            else:
                # 前件失败 → 义务自动释放，不参与求交
                pass
            
            # P 规则：仅当高置信意图 ∧ AbsCert ∧ 模态佐证 ∧ φ_rule 成立时解除
            # (由 HPC-E+ 四证准入门协调)
        
        # 冲突消解 = 交（最严者胜）
        all_filters = [filters['domain_shrink']] + list(filters['obligation_filters'].values())
        if all_filters:
            filters['domain_shrink'] = all_filters[0].intersection(*all_filters[1:])
        
        # 记录版本用于 Merkle 审计
        for rule in self.rule_library:
            self.rule_versions[rule.rule_id] = rule.version
        
        return filters
    
    def apply_filters(self, plan: Plan, current_state: RobotState) -> bool:
        """对计划应用过滤器：域收缩 ∧ 激活义务 ∧ 许可检查"""
        # 1. 域收缩
        if current_state not in self.filters['domain_shrink']:
            return False
        
        # 2. 激活义务检查
        for rule_id in list(self.active_obligations):
            rule = next(r for r in self.rule_library if r.rule_id == rule_id)
            if not rule.check_premise(plan.state_history):
                # 因果前件失效 → 自动释放，继续检查下一个
                self.active_obligations.discard(rule_id)
                continue
            # 义务检查：计划必须满足让位条件
            if not self._check_obligation_compliance(plan, rule):
                return False
        
        # 3. 许可检查（由 HPC-E+ 协调）
        # P 规则仅在 AllCert 通过时解除 DCL 限制
        
        return True
    
    def _check_obligation_compliance(self, plan: Plan, rule: CausalRule) -> bool:
        """检查计划是否满足带期限义务"""
        # 简义化：检查计划在 τ_rule 时间窗口内是否包含让位状态
        τ = rule.deadline
        # 检查计划前缀 ≤ τ 是否进入让位状态
        prefix_state = plan.prefix(τ)
        return prefix_state in rule.yield_set

class BudgetReallocationEngine:
    """机构状态到证据预算的双映射引擎"""
    def __init__(self, config_path: str = "budget_config.yaml"):
        with open(config_path) as f:
            config = yaml.safe_load(f)
        self.mapping_fn = config['mapping_fn']  # B_evidence = f(Q_arm)
        self.budget_history: list[float] = []
        self.last_approved_budget: float = config['initial_budget']
    
    def compute_budget(self, Q_arm: Configuration) -> float:
        """根据机构状态计算当前证据预算"""
        try:
            B = self.mapping_fn(Q_arm)
            if B <= 0:
                B = self.last_approved_budget  # 失败回退
            self.budget_history.append(B)
            return B
        except Exception:
            self.budget_history.append(self.last_approved_budget)
            return self.last_approved_budget
    
    def request_reallocation(self, Q_arm_new: Configuration, 
                            Q_arm_old: Configuration) -> tuple[bool, float]:
        """请求预算重分配：机构配置变化时触发"""
        B_new = self.compute_budget(Q_arm_new)
        B_old = self.last_approved_budget
        
        # 预算变化比例
        ratio = B_new / max(B_old, 1e-3)
        
        # 安全边界检查：预算不得意外膨胀
        if ratio > self._max_expansion_factor():
            # 预算过度膨胀 → 拒绝，保持旧预算
            return False, B_old
        
        # 预算重分配通过，更新批准预算
        self.last_approved_budget = B_new
        return True, B_new
    
    def _max_expansion_factor(self) -> float:
        """最大膨胀因子：防止预算意外膨胀"""
        return 1.5  # 最大 50% 膨胀

class BudgetReallocationCertificate:
    """BRC：证据预算证书，随机构状态动态调整"""
    def __init__(self, budget_engine: BudgetReallocationEngine):
        self.budget_engine = budget_engine
        self.current_budget: float = budget_engine.last_approved_budget
    
    def update_with_arm_config(self, Q_arm: Configuration) -> bool:

        success, budget = self.budget_engine.request_reallocation(Q_arm, Q_arm)

            self.current_budget = budget
            return True
        else:

            return False

class CertificateFederatedConsensusQuintuplePlus(CertificateFederatedConsensusPlusPlusHierarchical):
    """CFC++++：在 CFC+++ 基础上增加本体一致性、因果规则一致性、预算重分配一致性"""
    
    def consensus_round(self, timeout=5.0):
        results = {}
        for key, votes in self.votes.items():
            # 基础条件
            count_ok = len(votes) >= self.N - self.F
            modalities = {v.modality for v in votes.values()}
            modality_ok = len(modalities) >= self.M_MIN_MODALITIES
            layer_ok = self._check_layer_consistency(votes)
            
            # CFC+++ 新增三层一致性
            ce_sync_ok = all(v.ce_version == votes[next(iter(votes))].ce_version 
                           for v in votes.values())
            fs_valid_ok = all(v.few_shot_valid for v in votes.values())
            ip_attest_ok = all(v.ip_attested for v in votes.values())
            
            # CFC++++ 新增三层一致性
            ontology_ok = self._check_ontology_consistency(votes)
            causality_ok = self._check_causality_consistency(votes)
            budget_ok = self._check_budget_consistency(votes)
            
            if all([count_ok, modality_ok, layer_ok, ce_sync_ok, fs_valid_ok, 
                    ip_attest_ok, ontology_ok, causality_ok, budget_ok]):
                results[key] = self._majority_with_outlier_filter(votes)
            else:
                results[key] = "CI"
        return results
    
    def _check_ontology_consistency(self, votes: dict) -> bool:
        """检查本体一致性：所有投票者的本体图结构一致"""
        # 简化：检查是否所有投票者都检测到了相同类别的相同部件
        categories = {v.detected_category for v in votes.values()}
        if len(categories) > 1:
            return False  # 类别不一致
        # 检查部件检测一致性
        part_sets = {v.detected_parts for v in votes.values()}
        if len(part_sets) > 1:
            return False  # 部件检测不一致
        return True
    
    def _check_causality_consistency(self, votes: dict) -> bool:
        """检查因果规则一致性：因果前件评估结果一致"""
        premise_results = {v.causal_premise_result for v in votes.values()}
        if len(set(premise_results)) > 1:
            return False  # 因果前件评估不一致
        return True
    
    def _check_budget_consistency(self, votes: dict) -> bool:
        """检查证据预算一致性：预算评估结果一致"""
        budget_estimates = {v.budget_estimate for v in votes.values()}
        # 允许一定误差范围的一致性
        budget_set = set(budget_estimates)
        if len(budget_set) > 3:  # 超过 3 个不同的预算估计值视为不一致
            return False
        return True
```

```python
        """计算检测到的部件集合与本体图的一致性评分"""

        expected_avg = sum(self.out_degree(n, weight='weight', default=1.0) for n in induced_subgraph.nodes()) / (2 * len(induced_subgraph.nodes()))

    """CFC++++：在 CFC+++ 基础上增加本体一致性、因果规则一致性、预算重分配一致性"""
    
    def consensus_round(self, timeout=5.0):
        results = {}
        for key, votes in self.votes.items():
            # 基础条件
            count_ok = len(votes) >= self.N - self.F
            modalities = {v.modality for v in votes.values()}
            modality_ok = len(modalities) >= self.M_MIN_MODALITIES
            layer_ok = self._check_layer_consistency(votes)
            
            # CFC+++ 新增三层一致性
            ce_sync_ok = all(v.ce_version == votes[next(iter(votes))].ce_version 
                           for v in votes.values())
            fs_valid_ok = all(v.few_shot_valid for v in votes.values())
            ip_attest_ok = all(v.ip_attested for v in votes.values())
            
            # CFC++++ 新增三层一致性
            ontology_ok = self._check_ontology_consistency(votes)
            causality_ok = self._check_causality_consistency(votes)
            budget_ok = self._check_budget_consistency(votes)
            
            if all([count_ok, modality_ok, layer_ok, ce_sync_ok, fs_valid_ok, 
                    ip_attest_ok, ontology_ok, causality_ok, budget_ok]):
                results[key] = self._majority_with_outlier_filter(votes)
            else:
                results[key] = "CI"
        return results
    
    def _check_ontology_consistency(self, votes: dict) -> bool:
        """检查本体一致性：所有投票者的本体图结构一致"""
        # 简化：检查是否所有投票者都检测到了相同类别的相同部件
        categories = {v.detected_category for v in votes.values()}
        if len(categories) > 1:
            return False  # 类别不一致
        # 检查部件检测一致性
        part_sets = {v.detected_parts for v in votes.values()}
        if len(part_sets) > 1:
            return False  # 部件检测不一致
        return True
    
    def _check_causality_consistency(self, votes: dict) -> bool:
        """检查因果规则一致性：因果前件评估结果一致"""
        premise_results = {v.causal_premise_result for v in votes.values()}
        if len(set(premise_results)) > 1:
            return False  # 因果前件评估不一致
        return True
    
    def _check_budget_consistency(self, votes: dict) -> bool:
        """检查证据预算一致性：预算评估结果一致"""
        budget_estimates = {v.budget_estimate for v in votes.values()}
        # 允许一定误差范围的一致性
        budget_set = set(budget_estimates)
        if len(budget_set) > 3:  # 超过 3 个不同的预算估计值视为不一致
            return False
        return True

    def step(self, sensor_data: dict, cloud_update: Optional[dict] = None, 
             arm_config: Optional[Configuration] = None) -> tuple[bool, dict]:
        """单步执行：感知 → 六证生成 → 共识 → 六证准入 → 执行决策"""
        # 1. 处理云端更新（异步，非阻塞）
        if cloud_update:
            self.cesc.receive_cloud_update(cloud_update['V'], cloud_update['artifacts'])
        
        # 2. 边端感知 + 六证生成
        certs = self._generate_six_certificates(sensor_data, arm_config)
        
        # 3. 联邦共识（CFC++++）
        consensus = self.cfc.consensus_round()
        
        # 4. 尝试原子切换（若有待验证版本）
        if self.cesc.V_pending:
            self.cesc.atomic_switch()
        
        # 5. HPC-E++ 六证准入
        plan = self._plan_from_consensus(consensus)
        modules_involved = self._modules_in_plan(plan)
        admitted = self.hpc_eplusplus.admits(
            plan, sensor_data['x'], sensor_data['v'], sensor_data['z'],
            sensor_data['E_res'], sensor_data['margin_req'], modules_involved, Q_arm
        )
        
        return admitted, {
            'plan': plan if admitted else None,
            'consensus': consensus,
            'version': self.cesc.current_version(),
            'ontology_consistency': self.oasc.consistency if 'oasc' in dir() else 1.0,
            'causal_active': len(self.cdl.active_obligations),
            'budget': self.brc.current_budget,
            'offline_mode': self.cesc.offline_mode
        }
```
