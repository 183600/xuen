# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；本轮灵感：「视觉感知」×「轨迹优化」）

> 第 59 轮把「执行层物理」接上了地：BLDC 结构化不确定性、实时契约、阻抗安全编译、双向契约闭环——但它仍默默假设了两件更隐蔽的事：**(a) 视觉是一个被动、即时、帧间独立同分布的外感官模态**，在 XMC+ 里只是一个 `vis` 标签；**(b) 轨迹优化是在一张「已知代价图」上求解的路径问题**。本轮两个灵感精准击中这对假设背后的**循环依赖**：**视觉感知是动作条件化的**——能看见什么取决于视角、运动视差、遮挡、曝光与标定；**轨迹既是控制量、又是传感策略**——它决定感知质量，而感知质量又反过来决定轨迹的代价与风险。于是「先感知后规划」的串行架构在最需要它的长尾场景失效：想优化轨迹须先知道环境，想知道环境须先动，而动了就可能已经越界。更尖锐的是第三条：**安全/可达轨迹集合本身限制了可观测性**——某些危险假设在安全动作集内根本不可区分（例如：为了避免靠近悬崖而始终远离，就永远看不到崖边是否塌陷）。此时「多探几次」不是解药，**唯一健全的做法是拒绝不可逆承诺**。本轮核心命题：**「先判定在安全动作集内是否可辨识，再谈轨迹优化与证据承诺；把轨迹当传感策略来联合优化，把视觉当带可见性约束的删失证据来校准。」**

核心矛盾：
- **H32（视觉伪独立·置信度膨胀）**：视觉帧高度时序相关（同一场景、同一相机、相邻视角），把每帧当独立证据做贝叶斯更新，等价于把有效样本量高估 n/n_eff 倍；再叠加「重复纹理/镜面/透明/对称」造成的**感知混叠（perceptual aliasing）**，系统会以极高置信度相信一个错误标签——这不是随机噪声，而是**结构性、可被动作诱发的幻觉**。
- **H33（轨迹的传感性被忽视·可达性界定可辨识性）**：轨迹优化只最小化任务代价，不显式最大化信息；结果轨迹可能系统性地绕过一切能揭示危险假设的视角，形成**信息盲区**。更根本地，**可辨识性受限于安全动作集 Ξ_safe**：若区分 H_i/H_j 所需轨迹必然违反安全/执行契约，则在 Ξ_safe 内二者**不可辨识**，任何「多探几次」的证据协议都无法达到 1−δ 置信——证据门在此必须**拒绝**而非凑置信。
- **H34（感知-规划串行架构的循环依赖）**：代价图来自信念，信念来自观测，观测依赖轨迹，轨迹又依赖代价图。经典「建图→规划→执行」的开环分解在信念与动作强耦合时不一致；必须把轨迹放到**信念空间（information state）**里优化，或至少用信息增益把闭环闭合。
- **H35（外观≠物理·视觉的不可证伪性）**：视觉给出的是**外观（appearance）**，接触给出的是**物理（physics）**；二者不是同权模态。接触可以证伪视觉（看起来可踩，一踩就滑），视觉却不能证伪接触。把视觉与触觉对称融合，会把「看起来很结实」当成独立佐证，直接击穿第 59 轮建立的「执行接地」安全论证。

## 0. 直觉与动机

**灵感 1（视觉感知 → 结构化感知不确定性 PVQ）**
直觉：视觉不是「一张带高斯噪声的图」，而是一个**三源混合、可见性门控、时序相关**的观测通道。三源：**偶然不确定（aleatoric）**——传感器噪声、运动模糊（随角速度与曝光时间增长）、量化；**认知不确定（epistemic）**——模型域偏移、深度集成分歧、相机内外参标定漂移与时间同步误差；**可见性不确定（occlusion）**——目标被遮挡或根本不在视野内，此时「没看到」不等于「不存在」，必须用**删失似然（censored likelihood）**而非高斯似然。再加上帧间相关：独立假设下 n 帧的证据量是 n，实际有效样本量只有 n_eff = n / (1 + 2Σ(1−k/n)ρ_k)。关键洞见：**把感知不确定性显式分解并把 n_eff 送进融合权重，才能让「视觉自信」与「视觉证据量」解耦**——高置信不再自动等于高证据。

**灵感 2（轨迹优化 → 信息-安全联合轨迹优化 JTO）**
直觉：轨迹不是「到达目标的路径」，而是**在信念空间里的一串实验设计（experiment design）**。每一步运动都在选择「看哪里、以什么基线看、看多久」。于是目标函数应同时含四项：任务收益、**信息增益 IG(ξ)**、风险、执行/感知/运动成本。约束除动力学与执行契约外，还要加**感知约束**（关键区域可见性/覆盖率下限）与**可辨识性约束**（对路径上的危险假设，必须存在能区分它们的观测）。完整信念空间优化是 PSPACE-hard 的，因此用**采样式信念空间规划**（belief-RRT / MPPI）加**盲区覆盖**这一**次模（submodular）**信息增益替代——次模性给出贪心 (1−1/e) 近似保证，使在线可解。

**灵感 3（两灵感合流 → 可见性-可信度场 VTM 与可达有界可辨识性 RBI）**
直觉：把「能看见」与「看见了是否可信」分开建模，得到每个区域的**可见性 V(x|v)**、**感知质量 Q(x,v)**（分辨率×基线×入射角×光照×模糊）与**可信度 T(x)=P(correct|V,Q)**；未被任何**安全可达视角**充分覆盖的区域就是**盲区 B(x)**。由此得到本轮的理論核心：**可辨识性不是一个纯统计量，而是「安全动作集」与「观测通道」的联合性质**。定义假设对 (H_i,H_j) 在安全轨迹集 Ξ_safe 内的 Chernoff 信息上界 I* = max_{ξ∈Ξ_safe} D_Chernoff；若 I* < β（不足以在预算内分离到 1−δ），则称该假设对**在安全集内不可辨识**。此时正确的工程动作不是「加大探针预算」，而是三选一：**扩大安全集（改执行器/改契约）、绕行、或拒绝不可逆承诺**。

**灵感 4（视觉-触觉对账 VXR）**
直觉：视觉与接触的关系是**不对称的**。物理接触是对外观的一次**可证伪检验**：若视觉高置信「可踩」而接触打滑，应**乘性降权视觉先验**并把该区域标为混叠易发，而不是把两者平均；反之，视觉「看起来稳」绝不能用来提高接触结论的置信（同一场景，非独立）。更严格：视觉对接触假设的「确认」在信息论上是**重复计数**（同一底层世界状态），故视觉永远不能充当 EV-xmodal 的独立佐证。这条规则是第 59 轮「执行证据不作佐证」的**对偶**：不只是执行证据不能替代独立观测，**外观证据也不能替代物理观测**。

**灵感 5（PCE⁶ → 六预算：探针/微调/解释/执行/感知/运动）**
直觉：第 59 轮已有 B_probe、B_ft、B_ux、B_exec；本轮新增 **B_perc（感知预算：帧数、带宽、感知算力、标定刷新）** 与 **B_motion（运动预算：行走距离、耗时、能量，与执行预算 B_exec 物理耦合但语义不同）**。VOI 中显式扣除感知成本与运动成本：`voi = VOI_meta_pessimistic − cost_exec − cost_perc − cost_motion`。若「多看一处」的感知/运动成本高于其信息价值，系统应**主动不看**并转为保守——**「不感知」本身是一个被定价的决策**。

## 1. 形式化定义（增量：定义 153–161）

**定义 153（感知不确定性量化 PVQ）** 对区域 r、视角 v_t、帧序列 Z_{1:n}，潜世界状态为 W。观测模型 z_t = g(W, v_t) + e_t。三源分解：
```
Σ_vis(r) = Σ_alea(v_t) + Σ_epi(r) + Σ_occ(r|v_t)
Σ_alea = σ_sensor² + (κ·ω_t·t_exp)²      # 运动模糊随角速度×曝光
Σ_epi  = Var_ens[g(W,r)] + Σ_calib_drift  # 深度集成分歧 + 标定漂移
Σ_occ  = ∞（若 V(r|v_t) < τ_vis）          # 不可见 ⇒ 删失，非高斯
```
删失似然：
```
L_vis(z_{1:n}|W,r) = ∏_t [ V(r|v_t)·N(z_t; g(W,v_t), Σ_alea+Σ_epi)
                          + (1−V(r|v_t))·δ_censored ]
```
时序相关修正：ρ_k 为间隔 k 帧的残差自相关，
```
n_eff = n / (1 + 2 Σ_{k=1}^{K} (1 − k/n) ρ_k)
```
融合权重 w_vis = n_eff/(n_eff+κ_prior)，且**后验方差下界** σ²_post ≥ (Σ_alea+Σ_epi)/n_eff。输出结构化视觉证据 `EV-perc = (region, label, n_eff, Σ_vis, aliasing_score, calib_hash)`。

**定义 154（可见性-可信度场 VTM）** 对区域图 𝒢 与安全可达视角集 𝒱_safe(r)：
```
V(r|v)   = Π_{m∈Occluders(r,v)} (1 − α_m)          # 射线投射可见概率
Q(r,v)   = h(res, baseline, cos θ_inc, lux, blur)     # 感知质量
T(r)     = Calib_P(correct | V, Q)                    # 保形/等渗校准
VTM(r)   = (V*(r), T*(r)) = argmax_{v∈𝒱_safe(r)} V(r|v)·T(r)
B(r)     = 1 − V*(r)·T*(r)                            # 盲区场
```
关键：`𝒱_safe(r)` 只含满足动力学、执行契约 C_rt 与风险上界 δ 的视角——**可达性直接进入可见性定义**。

**定义 155（可达有界可辨识性 RBI）** 给定危险假设对 (H_i,H_j)、安全轨迹集 Ξ_safe（满足 C_rt、动力学、风险≤δ、感知覆盖率≥v_min）、观测通道 P(z|W,ξ) 与预算 B。定义
```
I*(H_i,H_j) = max_{ξ∈Ξ_safe} D_Chernoff( P(z|H_i,ξ) ‖ P(z|H_j,ξ) )
δ-可辨识 ⇔ I* ≥ β(δ,B) 且 ∃ξ 在预算内累积证据 ≥ log(1/δ)
```
若 I*<β(δ,B)，称该假设对**在安全集内不可辨识**，记 `Unident(H_i,H_j)`。输出可辨识性证书：
```
Cert_id = (H_i, H_j, I*, ξ_witness 或 ⊥, β, δ, B, coverage_lb, version)
```
其中 coverage_lb 为安全轨迹采样的覆盖率下界（用于把「没找到区分轨迹」与「不存在区分轨迹」区分开）。

**定义 156（信息-安全联合轨迹优化 JTO）** 在信念 b（含 VTM、共形膨胀、危险假设集 ℋ_haz）上求解：
```
ξ* = argmax_{ξ∈Ξ}  E_b[R_task(ξ)]
                 + λ_info · IG(ξ; b)
                 − λ_risk · ρ(ξ; b)
                 − λ_exec · C_exec(ξ) − λ_perc · C_perc(ξ) − λ_mot · C_mot(ξ)
s.t.  ξ 动力学可行；控制 ∈ K_safe 包络；C_rt 契约内
      V_cov(ξ) ≥ v_min                     # 关键区域感知覆盖
      ∀(H_i,H_j)∈ℋ_haz_on_path: ¬Unident(H_i,H_j)   # 可辨识性硬约束
      Pr[contact risk] ≤ δ_route
IG(ξ;b) = H(b) − E_{z~P(·|ξ)}[H(b'|z,ξ)]
```
可解性：完整 IG 用蒙特卡洛信念回放近似；在**盲区覆盖替代** `IG̃(ξ)=Σ_r B(r)·Cov_ξ(r)` 下，IG̃ 对候选集是**次模**的，贪心给出 (1−1/e) 近似；否则退回 MPPI/belief-RRT* 采样。若可行集为空 ⇒ `JTO_INFEASIBLE`，转保守分支。

**定义 157（视觉-触觉不对称对账 VXR）** 视觉信念 b_vis（有效样本 n_eff）与触觉 b_tap：
```
D_vt = TV(b_vis.label, b_tap.label) + |Q_μ_vis(0.99) − Q_μ_tap(0.99)|/μ_scale
```
规则：
- (V1) `D_vt > θ_vt` ⇒ **物理证伪外观**：ρ_vis ← max(ρ_vis^min, γ_demote·ρ_vis)；若 aliasing_score>θ_alias 则标记区域为混叠易发并写入 KG。
- (V2) 一致时**不得**把视觉计入 EV-xmodal 独立佐证（同场景相关）——只允许以 n_eff 修正后参与融合，且不减少物理探针需求。
- (V3) 对不可逆层级 L2 承诺，**纯视觉证据不能单独过门**（`reject: appearance_not_physics`）。

**定义 158（六预算 PCE⁶）** B = (B_probe, B_ft, B_ux, B_exec, B_perc, B_motion)：
```
cost_perc(π) = λ_frame·max(0, Frames(π)−B_perc.frames)
             + λ_flop ·max(0, FLOPs(π)−B_perc.flops)
             + λ_calib·max(0, Recalib(π)−B_perc.calib)
cost_mot(π)  = λ_dist·Dist(π) + λ_time·Time(π) + λ_energy·Energy(π)
voi⁶(π) = VOI_meta_pessimistic(π) − cost_exec(π) − cost_perc(π) − cost_mot(π)
```
六预算单调消耗、互不挪用；任一耗尽 ⇒ 该维度动作被冻结，决策只能更保守。特别地，**B_perc 耗尽 ⇒ 冻结「为了看得更清而多动/多看」的探索轨迹**，仅保留安全停与绕行。

**定义 159（感知/轨迹证据类与证据门扩展）**
```
EV-perc = (n_eff, calib_err, aliasing_flag, coverage, ood_perc)
EV-traj = (Cert_id_list, coverage_ok, ig_realized, risk_bound, xi_witness)
```
证据门新增硬规则：
- (G1) `EV-perc` 仅作一致性/告警，**不可作 EV-xmodal 独立佐证**；
- (G2) 对不可逆承诺，路径上每个危险假设对必须附 `Cert_id` 且 `¬Unident`，否则 `reject: unidentifiable_within_safe_set`；
- (G3) `aliasing_flag` 区域禁止仅凭视觉升级到 L1；
- (G4) `ood_perc`（感知域外）触发共形保底带 + 视觉降权（同 IP-133）。

**定义 160（感知-轨迹证书 J_vt）**
```
J_vt = (ξ_traj, PVQ 参数与 n_eff 轨迹, VTM 快照, IG 曲线, 
        Cert_id 集合, coverage 下界, calib_hash, budget_snapshots, version)
```
可验证：版本单增；每条 L2 承诺的 Cert_id 均 `¬Unident` 且 coverage_lb ≥ v_min；IG 替代值与真实回放 IG 的偏差在界内；证书不可篡改。

**定义 161（视觉-轨迹闭环算子 VTC）** 扩展 CLEP：
```
① PVQ: b_vis ← update_visual(Z, v_t)；n_eff ← ESS(Z)；Σ_vis ← decompose()
② VTM: 依据当前与候选视角刷新 V(r),T(r),B(r)；𝒱_safe ← filter_by_contract(C_rt)
③ RBI: ∀(H_i,H_j)∈ℋ_haz: Cert_id ← identifiability(Ξ_safe, B, δ)
       if Unident(H_i,H_j) 且该假设在候选路径上: 标记不可承诺
④ JTO: ξ* ← 联合轨迹优化(b, ℋ_haz, 六预算)；若不可行 → 保守分支
⑤ Execute: 沿 ξ* 采集视觉+接触，触发 VXR 对账
⑥ Update: 信念/KG/共形集更新；EV-perc, EV-traj 入账；六预算扣减
⑦ Gate: 按 G1–G4 过门；不可辨识 ∧ 不可逆 ⇒ 协商/绕行/安全停
⑧ Return: (b, D⁺, EV-perc, EV-traj, J_vt)
```

## 2. 关键算法伪代码

### IP-152 PVQ（感知不确定性量化）

```python
class PerceptualUncertaintyQuantifier:
    def __init__(self, ensemble, calib, k_prior=8.0, rho_window=32):
        self.ensemble, self.calib = ensemble, calib
        self.k_prior, self.rho_window = k_prior, rho_window

    def effective_sample_size(self, frames):
        n = len(frames)
        if n <= 1: return float(n)
        rho = [self._residual_autocorr(frames, k) for k in range(1, min(n, self.rho_window)+1)]
        denom = 1.0 + 2.0*sum((1.0 - k/n)*rho[k-1] for k in range(1, len(rho)+1))
        return max(1.0, n/denom)

    def decompose(self, region, frames, viewpoint):
        sigma_alea = self._sensor_noise(frames) + (KAPPA_BLUR*viewpoint.omega*viewpoint.exposure)**2
        sigma_epi  = self.ensemble.predict_var(region, frames) + self.calib.drift_var(region)
        V = visibility_field(region, viewpoint, frames)
        if V < TAU_VIS:
            return CensoredLikelihood(mask=V, base_cov=sigma_alea+sigma_epi)  # 不可见=删失
        return Gaussian(mean=self.ensemble.predict_mean(region, frames),
                        cov=sigma_alea+sigma_epi)

    def build_evidence(self, region, frames, viewpoint):
        n_eff = self.effective_sample_size(frames)
        lik = self.decompose(region, frames, viewpoint)
        aliasing = self._aliasing_score(region, frames)  # 重复纹理/镜面/透明/对称
        return PerceptualEvidence(region=region, n_eff=n_eff,
                                  likelihood=lik, sigma_vis=lik.cov,
                                  aliasing_score=aliasing,
                                  calib_hash=self.calib.hash)

    def fuse_weight(self, evidence):
        return evidence.n_eff / (evidence.n_eff + self.k_prior)
```

### IP-153 VTM（可见性-可信度场）

```python
def build_vtm(region_graph, viewpoints_of, contract, calib, risk_bound):
    vtm = {}
    for r in region_graph.nodes:
        best = None
        for v in viewpoints_of(r):
            if not in_safe_reachable_set(v, r, contract, risk_bound):
                continue                       # 可达性进入可见性定义
            V = visibility_field(r, v, region_graph.occluders)
            Q = quality(v, r, calib)           # 分辨率×基线×入射角×光照×模糊
            T = calib.trust(V, Q)              # 校准过的 P(correct|V,Q)
            score = V*T
            if best is None or score > best.score:
                best = TrustCell(V=V, Q=Q, T=T, score=score, viewpoint=v)
        if best is None:
            best = TrustCell(V=0.0, Q=0.0, T=0.0, score=0.0, viewpoint=None)
        best.blind = 1.0 - best.score
        vtm[r] = best
    return vtm
```

### IP-154 RBI（可达有界可辨识性）

```python
def identifiability_certificate(H_i, H_j, xi_safe_sampler, obs_model,
                                beta, delta, budget, coverage_lb):
    best_C, best_xi = -float('inf'), None
    for xi in xi_safe_sampler.sample(budget.n_traj):
        # Chernoff 信息：区分两假设的最优误差指数（保守下界估计）
        C = chernoff_information(obs_model, H_i, H_j, xi)
        if C > best_C:
            best_C, best_xi = C, xi
        if C >= beta and achievable_log_likelihood_ratio(C, budget) >= np.log(1.0/delta):
            return IdentifiabilityCert(H_i, H_j, best_C, xi, beta, delta,
                                       budget, coverage_lb, identifiable=True)
    return IdentifiabilityCert(H_i, H_j, best_C, best_xi, beta, delta,
                               budget, coverage_lb, identifiable=False,
                               reason="unidentifiable_within_safe_set")
```

### IP-155 JTO（信息-安全联合轨迹优化）

```python
def joint_trajectory_optimization(belief, task, budgets, vtm, haz_pairs):
    candidates = sample_safe_trajectories(belief, budgets, n=N_TRAJ)

    def info_gain_surrogate(xi):
        cov = predicted_visibility(xi, vtm)          # 轨迹沿线可见覆盖
        return sum(vtm[r].blind * cov[r] for r in cov)  # 次模盲区覆盖

    feasible = []
    for xi in candidates:
        if coverage(xi, vtm) < V_MIN:                       continue
        if route_risk(xi, belief.conformal_inflate()) > DELTA_ROUTE: continue
        certs = [identifiability_certificate(hi, hj, safe_sampler(xi), belief.obs_model,
                                             BETA, DELTA_ID, budgets, COV_LB)
                 for (hi, hj) in haz_pairs_on_path(xi, haz_pairs)]
        if any(not c.identifiable for c in certs):
            continue                                        # 可辨识性硬约束
        feasible.append((xi, certs))
    if not feasible:
        return None, "JTO_INFEASIBLE"

    def objective(item):
        xi, _ = item
        return (expected_reward(xi, task)
                + LAMBDA_INFO*info_gain_surrogate(xi)
                - LAMBDA_RISK*route_risk(xi, belief.conformal_inflate())
                - LAMBDA_EXEC*exec_cost(xi, budgets)
                - LAMBDA_PERC*perc_cost(xi, budgets)
                - LAMBDA_MOT*motion_cost(xi, budgets))

    best_xi, best_certs = max(feasible, key=objective)
    return TrajectoryPlan(best_xi, best_certs, info_gain_surrogate(best_xi)), "ok"
```

```python
class SixBudget:
    def __init__(self, probe, ft, ux, exec_, perc, motion):
        self.B_probe, self.B_ft, self.B_ux = probe, ft, ux
        self.B_exec, self.B_perc, self.B_motion = exec_, perc, motion

    def voi(self, pi, belief):
        return (voi_meta_pessimistic(pi, belief)
                - self.exec_cost(pi) - self.perc_cost(pi) - self.motion_cost(pi))

    def perc_cost(self, pi):
        return (LAMBDA_FRAME*max(0, pi.frames - self.B_perc.frames)
                + LAMBDA_FLOP*max(0, pi.flops - self.B_perc.flops)
                + LAMBDA_CALIB*max(0, pi.recalib - self.B_perc.calib))

    def motion_cost(self, pi):
        return (LAMBDA_DIST*pi.dist + LAMBDA_TIME*pi.time
                + LAMBDA_ENERGY*pi.energy)

    def can_explore_for_perception(self):
        return self.B_perc.frames > 0 and self.B_perc.flops > 0 and self.B_motion.dist > 0
```

### IP-152 PVQ（感知不确定性量化）

```python
class PerceptualUncertaintyQuantifier:
    def __init__(self, ensemble, calib, k_prior=8.0, rho_window=32,
                 tau_vis=0.15, kappa_blur=1e-3, theta_alias=0.6):
        self.ensemble = ensemble          # 深度集成/多视角几何
        self.calib = calib                # 内参/外参/时间同步漂移模型
        self.k_prior = k_prior
        self.rho_window = rho_window
        self.tau_vis = tau_vis
        self.kappa_blur = kappa_blur
        self.theta_alias = theta_alias

    def effective_sample_size(self, frames):
        n = len(frames)
        if n <= 1:
            return float(n)
        rho = [self._residual_autocorr(frames, k)
               for k in range(1, min(n, self.rho_window) + 1)]
        denom = 1.0 + 2.0 * sum((1.0 - k / n) * rho[k - 1]
                                for k in range(1, len(rho) + 1))
        # 方差下界：n_eff 不得大于 n；且对负相关给出保守截断
        return float(max(1.0, min(n, n / denom)))

    def _residual_autocorr(self, frames, k):
        # 对光流对齐后的残差序列做滞后 k 自相关
        e = np.array([f.residual for f in frames])
        if len(e) <= k:
            return 0.0
        e = e - e.mean()
        denom = np.dot(e, e) + 1e-9
        return float(np.dot(e[:-k], e[k:]) / denom)

    def decompose(self, region, frames, viewpoint):
        sigma_alea = (self._sensor_noise(frames)
                      + (self.kappa_blur * viewpoint.omega * viewpoint.exposure) ** 2)
        sigma_epi = (self.ensemble.predict_var(region, frames)
                     + self.calib.drift_var(region))
        V = visibility_field(region, viewpoint, frames)
        if V < self.tau_vis:
            # 不可见 ⇒ 删失：信息量为零，绝不当成"没有危险"
            return CensoredLikelihood(mask=V, base_cov=sigma_alea + sigma_epi)
        return Gaussian(mean=self.ensemble.predict_mean(region, frames),
                        cov=sigma_alea + sigma_epi)

    def _aliasing_score(self, region, frames):
        # 重复纹理 / 镜面 / 透明 / 对称：多视角一致性越低、单视角置信越高 ⇒ 越可疑
        consistency = self.ensemble.multi_view_consistency(region, frames)
        mono_conf = self.ensemble.single_view_confidence(region, frames)
        return float(np.clip(mono_conf * (1.0 - consistency), 0.0, 1.0))

    def build_evidence(self, region, frames, viewpoint):
        n_eff = self.effective_sample_size(frames)
        lik = self.decompose(region, frames, viewpoint)
        self.calib.assert_in_distribution(region, frames)  # OOD 检查
        return PerceptualEvidence(
            region=region, n_eff=n_eff, likelihood=lik,
            sigma_vis=(lik.cov if not lik.censored else float('inf')),
            aliasing_score=self._aliasing_score(region, frames),
            coverage=float(np.mean([visibility_field(region, v, frames)
                                    for v in frames])),
            calib_hash=self.calib.hash)

    def fuse_weight(self, evidence):
        # 关键：权重由有效样本量决定，不由帧数决定
        return evidence.n_eff / (evidence.n_eff + self.k_prior)

    def posterior_cov_floor(self, evidence):
        # 后验协方差不得低于 Σ_vis / n_eff
        return evidence.sigma_vis / max(1.0, evidence.n_eff)
```

### IP-153 VTM（可见性-可信度场）

```python
def build_vtm(region_graph, viewpoints_of, contract, calib, risk_bound, v_min):
    vtm = {}
    for r in region_graph.nodes:
        best = None
        for v in viewpoints_of(r):
            # 可达性进入可见性定义：不可安全到达的视角不计入
            if not in_safe_reachable_set(v, r, contract, risk_bound):
                continue
            V = visibility_field(r, v, region_graph.occluders)
            Q = quality(v, r, calib)           # 分辨率×基线×入射角×光照×模糊
            T = calib.trust(V, Q)              # 保形/等渗校准的 P(correct|V,Q)
            score = V * T
            if best is None or score > best.score:
                best = TrustCell(V=V, Q=Q, T=T, score=score,
                                 viewpoint=v, reachable=True)
        if best is None:
            best = TrustCell(V=0.0, Q=0.0, T=0.0, score=0.0,
                             viewpoint=None, reachable=False)
        best.blind = 1.0 - best.score
        best.knowable = best.score >= v_min
        vtm[r] = best
    return vtm
```

### IP-154 RBI（可达有界可辨识性）

```python
def identifiability_certificate(H_i, H_j, safe_sampler, obs_model,
                                beta, delta, budget, coverage_lb):
    """在安全轨迹集内求区分两假设的最优 Chernoff 信息。
    返回的 identifiable=False 是『在安全集内不可辨识』，
    而不是『证据不足』——语义差别是 G2 硬门的基础。"""
    if not mutually_exclusive(H_i, H_j):
        return IdentifiabilityCert(H_i, H_j, 0.0, None, beta, delta,
                                   budget, coverage_lb,
                                   identifiable=True, reason="same_hypothesis")

    best_C, best_xi = -np.inf, None
    for xi in safe_sampler.sample(budget.n_traj):
        C = chernoff_information(obs_model, H_i, H_j, xi)  # 保守下界
        if C > best_C:
            best_C, best_xi = C, xi
        needed = np.log(1.0 / delta)
        if C >= beta and achievable_llr(C, budget) >= needed:
            return IdentifiabilityCert(
                H_i, H_j, best_C, xi, beta, delta, budget, coverage_lb,
                identifiable=True, reason="identifiable")
    return IdentifiabilityCert(
        H_i, H_j, best_C, best_xi, beta, delta, budget, coverage_lb,
        identifiable=False, reason="unidentifiable_within_safe_set")
```

### IP-155 JTO（信息-安全联合轨迹优化）

```python
def joint_trajectory_optimization(belief, task, budgets, vtm, haz_pairs):
    candidates = sample_safe_trajectories(belief, budgets, n=N_TRAJ)

    def info_gain_surrogate(xi):
        cov = predicted_visibility(xi, vtm)
        # 次模：对候选视角集合做盲区覆盖的边际收益递减
        return sum(vtm[r].blind * cov[r] for r in cov)

    def risk(xi):
        return route_risk(xi, belief.conformal_inflate())

    feasible = []
    for xi in candidates:
        if coverage(xi, vtm) < V_MIN:
            continue
        if risk(xi) > DELTA_ROUTE:
            continue
        certs = []
        ok = True
        for (hi, hj) in haz_pairs_on_path(xi, haz_pairs):
            c = identifiability_certificate(
                hi, hj, safe_sampler_for(xi, budget=budgets),
                belief.obs_model, BETA, DELTA_ID, budgets, COV_LB)
            certs.append(c)
            if not c.identifiable:
                ok = False
                break
        if ok:
            feasible.append((xi, certs))

    if not feasible:
        return None, "JTO_INFEASIBLE"

    def objective(item):
        xi, _ = item
        return (expected_reward(xi, task)
                + LAMBDA_INFO * info_gain_surrogate(xi)
                - LAMBDA_RISK * risk(xi)
                - LAMBDA_EXEC * exec_cost(xi, budgets)
                - LAMBDA_PERC * perc_cost(xi, budgets)
                - LAMBDA_MOT * motion_cost(xi, budgets))

    best_xi, best_certs = max(feasible, key=objective)
    return TrajectoryPlan(traj=best_xi, cert_ids=best_certs,
                          ig_surrogate=info_gain_surrogate(best_xi)), "ok"

def perc_cost(xi, budgets):
    return (LAMBDA_FRAME * max(0, xi.frames - budgets.B_perc.frames)
            + LAMBDA_FLOP * max(0, xi.flops - budgets.B_perc.flops)
            + LAMBDA_CALIB * max(0, xi.recalib - budgets.B_perc.calib))

def motion_cost(xi, budgets):
    return (LAMBDA_DIST * xi.dist
            + LAMBDA_TIME * xi.time
            + LAMBDA_ENERGY * xi.energy)
```

```python
def visual_tactile_reconcile(b_vis, b_tap, perc_ev, kg, region):
    D = (tv_distance(b_vis.label_dist, b_tap.label_dist)
         + abs(b_vis.quantile(0.99) - b_tap.quantile(0.99)) / MU_SCALE)

    if D > THETA_VT:
        # 物理证伪外观：只降视觉、绝不反向改接触
        b_vis.rho = max(RHO_VIS_MIN, GAMMA_DEMOTE * b_vis.rho)
        aliasing = perc_ev.aliasing_score > THETA_ALIAS
        if aliasing:
            kg.mark_aliasing_prone(region,
                                   evidence=perc_ev, witness=b_tap)
        return (reconcile_asym(b_vis, b_tap),
                D, aliasing, "physics_falsifies_appearance")

    # 一致也不独立：只做相关性校正融合，不抵扣物理探针预算
    fused = fuse_correlation_aware(b_vis, b_tap, n_eff=perc_ev.n_eff)
    return fused, D, False, "consistent_non_independent"

def evidence_gate_vt(ev, M, perc_ev, traj_ev, region, irreversible):
    if ev.ev == "EV-perc":
        ok = (perc_ev.n_eff >= N_EFF_MIN
              and perc_ev.calib_err <= EPS_CALIB
              and not perc_ev.ood_perc)
        if ev.level == "L1" and perc_ev.aliasing_flag:
            return ("reject", "aliasing_visual_only_L1", ev)
        if irreversible:
            # 纯外观永远不能单独过不可逆门
            return ("reject", "appearance_not_physics", ev)
        return (("ok" if ok else "reject"), "perc_check", ev)

    if ev.ev == "EV-traj":
        ok = (traj_ev.coverage_ok
              and all(c.identifiable for c in traj_ev.cert_ids)
              and traj_ev.ig_realized >= traj_ev.ig_bound)
        if not ok:
            return ("reject", "unidentifiable_within_safe_set", ev)
        return ("ok", ev)

    if ev.ev == "EV-xmodal":
        # 视觉不得计入独立佐证：indep 声明必须排除 vis 帧
        indep = ev.indep_declared and not ev.corroborated_by_vis_only
        ok = ev.level == "L1" and indep and ev.D <= THETA_D
        return (("ok" if ok else "reject"), "xmodal_check", ev)

    return ("ok", ev)  # 其余沿用第 59 轮门
```

```python
def visual_trajectory_closed_loop(M, task, budgets, haz_pairs):
    # ① PVQ：更新视觉信念与有效样本量
    for r, frames, v in M.visual_stream.latest():
        ev = M.pvq.build_evidence(r, frames, v)
        M.b_vis[r] = bayes_update(M.b_vis[r], ev.likelihood,
                                  w=M.pvq.fuse_weight(ev))
        M.perc_log.append(ev)

    # ② VTM：刷新可见性/可信度/盲区（可达性已内建）
    M.vtm = build_vtm(M.region_graph, M.viewpoints_of,
                      M.ertc.C_rt, M.calib, DELTA_ROUTE, V_MIN)

    # ③ RBI：对危险假设对求可辨识性证书
    certs = [identifiability_certificate(hi, hj, M.safe_sampler,
                                         M.obs_model, BETA, DELTA_ID,
                                         budgets, COV_LB)
             for (hi, hj) in haz_pairs]

    # ④ JTO：联合轨迹优化（含可辨识性硬约束）
    plan, status = joint_trajectory_optimization(
        M.belief, task, budgets, M.vtm, haz_pairs)
    if status == "JTO_INFEASIBLE":
        return degrade_or_abstain(M, task, "no_identifiable_safe_trajectory")

    # ⑤ 执行并采集视觉+接触
    M.visual_stream, M.telemetry = execute_plan(plan, M.ertc)

    # ⑥ VXR：视觉-触觉不对称对账
    fused, D, aliasing, reason = visual_tactile_reconcile(
        M.b_vis[task.region], M.b_tap[task.region],
        M.perc_log[-1], M.kg, task.region)

    # ⑦ 证据门（含 G1–G4）
    ev_perc = M.perc_log[-1]
    ev_traj = build_traj_evidence(plan, certs)
    gate = evidence_gate_vt(ev_perc, M, ev_perc, ev_traj,
                            task.region, task.irreversible)

    # ⑧ 预算扣减 + 证书
    budgets.spend_perception(plan)
    cert = PerceptionTrajectoryCertificate(
        traj=plan.traj, pvq_params=M.pvq.params(),
        n_eff_traj=[e.n_eff for e in M.perc_log],
        vtm_snapshot=M.vtm, ig_curve=plan.ig_curve,
        cert_ids=certs, coverage_lb=plan.coverage_lb,
        calib_hash=M.calib.hash,
        budget_snapshots=budgets.snapshot(),
        version=M.next_cert_version())
    return M, fused, D, ev_perc, ev_traj, gate, cert
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PVQ | O(n·d) + 自相关 FFT O(n log n)/区域/帧 | O(K·d) | n_eff 已消除相关导致的方差低估；删失似然对不可见区域信息量为零 |
| VTM | O(\|𝒢\|·\|𝒱_safe\|·ray) 增量 | O(\|𝒢\|·\|𝒱\|) | 遮挡几何音完备；trust 保形；可达性内建 |
| RBI | O(N_traj·T·d) 采样 + Chernoff 下界 | O(N_traj·T) | `¬Unident` 有见证轨迹；`Unident` 有覆盖率下界 |
| JTO | O(N_traj·T·(sim+IG))；次模贪心 O(k·N_traj) | O(N_traj·T) | 动力学/契约/风险/覆盖可行；次模替代 ⇒ (1−1/e) |
| VXR | O(\|ℳ\|²·d)/区域 | O(\|ℳ\|·d) | 物理证伪单向；视觉不作独立佐证 |
| PCE⁶ | O(\|π\|·(C_VOI+C_PERC+C_MOT)) | O(\|V\|+N_hist) | 六预算单调、互不挪用、耗尽即保守 |
| J_vt | O(1)/承诺追加 | O(承诺数) | 版本单增、Cert_id 全覆盖、IG 偏差有界 |

**正确性定理（Perception–Trajectory Soundness, PTS）**
假设 A22–A55（第 53–59 轮）成立；**(A56)** PVQ：三源分解诚实覆盖真实视觉误差；n_eff 修正后后验方差不低于真实方差；删失似然对 V<τ_vis 区域信息量为零。**(A57)** VTM：遮挡几何与感知质量模型音完备；trust 校准在分布内保形有效；安全可达视角集与 Ξ_safe 一致。**(A58)** RBI：安全轨迹采样覆盖率 ≥ coverage_lb；Chernoff 信息为保守下界；预算足以执行见证轨迹。**(A59)** JTO：候选轨迹采样覆盖可行域（或给出覆盖下界）；盲区覆盖替代是真实 IG 的单调下界；风险模型上界真实风险。**(A60)** VXR：外观不决定物理（物理证伪单向）；同场景视觉与触觉不独立。**(A61)** PCE⁶：六预算单调、互不挪用；三类成本函数诚实上界真实消耗。**(A62)** J_vt：证书不可篡改、版本化。则：

1. **相关性修正的校准健全性**：融合后 `E[conf] ≤ E[acc] + δ_corr(n_eff, ρ)`；n_eff 低估时结论保守（置信偏低而非偏高）。
2. **可见性删失保守性**：对 V<τ_vis 区域，视觉观测不改变后验（KL=0）；「没看见」不被误当作「安全」。
3. **可辨识性健全性（核心）**：若 (H_i,H_j) 在 Ξ_safe 内 `Unident`，则任何只用安全轨迹的证据协议都无法以两类错误均 ≤δ 区分二者；据此接受不可逆承诺必然不健全。本方案 G2 拒绝 ⇒ 不产生不健全承诺（单向保守）。
4. **轨迹安全-信息折中**：JTO 输出满足动力学、C_rt、风险 ≤δ_route、覆盖 ≥v_min，且路径危险假设对均 `¬Unident`；实现 IG ≥ IG̃。
5. **外观/物理不对称**：视觉至多在一致性时以 n_eff 修正融合、分歧时被证伪降权；永不减少物理探针需求。
6. **终止性**：VTC 在六预算内终止于 {承诺(带 J_vt), 绕行, 降档, L2 协商, 安全停, JTO_INFEASIBLE 停}。
7. **部署界**：
```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                   + δ_ft + δ_kg + δ_ux + δ_exec + δ_ertc + δ_eeis
                   + δ_perc·1[视觉混叠/域外] + δ_corr·1[n_eff 低估]
                   + δ_id·1[Unident 未被拒] + δ_jto·1[采样漏掉见证轨迹])
         − P(𝒢 结构性错误未检出) − P(护盾回退失败) − P(安全停失效) − P(固件回滚失败)
```

关键：**PVQ 让「视觉自信」与「视觉证据量」解耦**（n_eff 而非帧数决定权重）；**VTM 把可达性写进可见性**（看不到 = 不可安全到达的视角也看不到）；**RBI 把「能不能知道」变成安全集上的可判定命题**（不可辨识 ⇒ 拒绝，而非加探针）；**JTO 把轨迹变成实验设计**（信息增益与风险、执行、感知、运动成本同台竞价）；**VXR 把外观/物理的不对称写成硬规则**；**PCE⁶ 给「不感知」定价**。安全单向通道全面加强：**信念更准（相关性/删失）、不确定性更大（盲区/不可辨识）、动作更保守（可辨识性硬约束 + 纯视觉不过不可逆门）**。

## 6. 本轮最大风险

**一句话**：本轮把安全论证的根推进到「在安全动作集内是否可辨识」，但**可辨识性证书本身建立在安全轨迹采样覆盖与观测模型正确性之上**——采样漏掉见证轨迹会假不可辨识（过度保守、机器人寸步难行甚至永远绕行），观测模型高估可区分性会假可辨识（在最需要它的长尾场景给出虚假承诺），两者都直接击穿「先辨识后承诺」的整条论证链；**可辨识性证明正在成为新的单点故障，必须以「Unident 一律拒绝不可逆承诺」+「覆盖下界显式记账」+「见证轨迹可复现审计」三重护栏把它钉死。**
