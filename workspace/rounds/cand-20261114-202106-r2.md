# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配×主动交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「Isaac Sim」×「运动学」）

> R69 给系统装上了嘴和眼睛：它把 epistemic 歧义变成一次注视、一次探询、一次轻触，用 VoI 决定「值不值得问」。但它自陈的最大风险，是把全部效率收益押在「流模型的模态分布可信」上——一旦模型幻觉出一个模态，系统会自信地追问一个幻影；一旦人类给一个误导答案，系统会把它盖上「已验证」的章。**R69 会问，却无力在问之前判断：这个问题在物理世界里是否成立。**
>
> 本轮两个灵感正好提供两种「物理锚」：
> - **Isaac Sim** 提供一座**廉价、并行、物理接地、可光线追踪的替身世界**：在花掉真实安全/社交预算之前，先在数字孪生里把候选模态与候选信息动作**预演**一遍——把「问现实」降级为「先问模型」。
> - **运动学** 提供一条**解析、精确、不可能被幻觉出来的约束通道**：可达性、自碰撞、关节限位、奇异、可操作性椭球、可观测性（视场/遮挡）；更有价值的是**零空间自由度**——一类不改变末端任务、因而任务风险一阶为零的信息动作。
>
> 核心命题：**在「问现实」之前先「在物理接地的替身里预演」，并用精确运动学作为不可幻觉的第三证据通道；仿真不是神谕，而是一个需自身校准、且默认只被允许让系统更保守的证据源。** 命名 **KINESIM-RAS**（KINEmatics-anchored SIMulation-rehearsed Adaptive Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「该向谁问」，R70 问「**在问之前，我能否先在不会受伤的世界里把这个问题排练一遍——并确认我的身体真的做得到**」。

## 0. 直觉与动机

**灵感 1（Isaac Sim → 预演是一种廉价的反事实）**
直觉：R69 的信息动作有真实代价：注视可能诱导危险转身，探针可能越力包络，问句可能冒犯人类。但「这个信息动作到底能消掉多少歧义」在真实执行前是未知的——R69 用 VoI 的**期望**去赌，赌错就是安全/社交事故。Isaac Sim 让我们在真实执行前，用 GPU 并行把 K 个候选模态 × G 个候选信息动作**全部 rollout**：在光线追踪的传感器仿真里，直接测量「看向这里能否让遮挡消失」「探针沿这个方向能否在力包络内触到材质」「这个动作会不会自碰撞」。这把 VoI 从「解析期望」变成「在替身里实测的反事实」。更关键：数字孪生里失败是免费的，现实中失败不是。**能在仿真里犯的错，就不该在现实里犯。**

**灵感 2（运动学 → 一条不可被学习模型幻觉污染的通道）**
直觉：R68 的抗吸收通道是传感器残差 r_res，R69 的行为通道是流似然 Δa——两者都依赖**学出来的模型**，因此都可能与模型一起错。运动学不同：给定关节角与连杆参数，正运动学、可达性、碰撞、奇异都是**确定的、可形式验证的**。一个流模型幻觉出的模态若要求末端到达工作空间外、或穿过自身、或在奇异位形上施加大力，那么它**一定**不可实现——这不是概率判断，是几何事实。于是运动学成为一个「反幻影」的硬过滤器；而它对条件编码的偏置不敏感，因为它是纯几何计算，不与感知标定共享参数。**这正是 R69 最缺的第三意见：不看传感器、不看策略，只看身体。**

**灵感 3（零空间 → 信息可以是「免费」的）**
直觉：R69 的信息动作都要付成本（物理位移、社交打扰），所以 VoI 必须先超过成本。但对**冗余机械臂**，雅可比零空间里存在一族关节运动：末端任务一阶不变，任务风险一阶为零。你可以转动腕部、平移肘部、绕目标做视差运动、在接触面上做切向探索——这些动作改变**可观测性**（视差、遮挡、接触几何），却不改变任务。于是信息价值第一次出现「零任务成本」的一档：VoI 的 Pareto 前沿在 c_task≈0 处获得一个免费区段。这是本轮最优雅的结构性发现：**冗余不只是避障资源，也是「免费的问」。** 但必须警告：零空间对末端任务是自由的，对**碰撞**不是——肘部摆动仍可能撞到障碍，因此「免费」只在任务空间成立，安全仍须全碰撞检查（见风险）。

**灵感 4（把仿真当证据源，而不是神谕 → 避免把 R68/R69 的错法复制到仿真上）**
直觉：最危险的诱惑是把 Isaac Sim 当成「真实世界的答案」。但数字孪生有 sim-to-real gap：未建模的接触、柔性、摩擦、光照、人体行为，都会让仿真**内部自洽却外部错误**。若无条件相信它，预演反而**放大**错误：系统在假世界里排练出一个自信答案，再把这个信心带回现实——R69 的「诚实的不知道」被升级成「在错世界里排练出的确定」。所以本轮的理论姿态必须延续前几轮的铁律：**新层是旧层的严格泛化，且新增的证据源默认只被允许让系统更保守。** 具体地：运动学不可行 ⇒ 必然更保守（硬拒绝）；仿真可行但 sim-gap 未校准 ⇒ 仿真只能**提高** λ，不能**降低** λ（单侧信任）；只有 sim-gap 通过校准门（ECE_sim ≤ τ）时，预演才被允许贡献 resolution bonus。

**灵感 5（三通道 → 正面回应「缓变故障被标定吸收」的残留漏洞）**
直觉：R68 用 r_res 看「传感器自洽」，R69 加 Δa 看「行为自洽」，但一个**机械/本体**故障（关节磨损、连杆热变形、负载变化、编码器零点漂移）可能既不明显改变感知残差，也不立刻把动作推离策略主脊——它改变的是身体本身。数字孪生恰好提供第三条独立通道：把同一执行动作在孪生里前向仿真，比较**孪生预测的本体运动**与**真实测得的本体运动**（关节角、末端位姿），得 r_kin。它测「身体是否还像我以为了解的那个身体」，与感知标定、行为似然三者的盲区互不重叠。**三个通道，三种物理量，任何只吸收其一的标定层都不可能同时骗过它们。**

## 1. 形式化定义（增量：定义 310–326）

**定义 310（KINESIM-RAS 总览）** KINESIM-RAS = (DTP, KFC, NIA, KUD, SRG, TDR, RAS-WM‡)。三不变式：
(i) 实时流零学习写操作（继承 R69 定义 293-i）；
(ii) **预演前置**：任何真实信息动作 g 在获得执行许可前，必须先在 DTP 中完成预演，且预演结论的可信度受 SRG 校准门约束；未通过运动学认证（KFC）的动作不得进入预演之后的真实执行；
(iii) **单侧信任原则**：未校准的仿真证据只可提高保守度（λ 单调不降），不可降低；运动学不可行是硬否证，无概率折扣。

**定义 311（数字孪生预演 DTP）** 孪生世界 𝒮 = (𝒲, ℬ, 𝒪, Φ̂)，𝒲 几何世界、ℬ 本体模型、𝒪 障碍/人体代理、Φ̂ 物理前向算子（含光线追踪传感仿真）。对候选模态集 {m_k} 与信息动作候选 {g}，并行 rollout 得反事实结果 y_sim(k,g) 与预测任务代价 Ĉ_task、安全代价 Ĉ_safe、观测信息量 Î_obs。预演不是单条轨迹，而是 M 次域随机化下的分布 {y_sim^{(m)}}，用以估计**鲁棒性**而非单点可行性。

**定义 312（运动学认证 KFC）** 给定本体运动学模型 K（DH/URDF）、关节限位 q ∈ [q_min, q_max]、障碍距离函数 d(·)，动作（含信息动作）通过认证 iff：
(a) 逆运动学有解且 ‖q‖∞ 在限位内（可达性）；
(b) 沿执行路径最小间隙 d_min > d_safe（碰撞/自碰撞）；
(c) 最小奇异值 σ_min(J(q)) > σ_s（非奇异/可操作性）；
(d) 力/力矩经 J^T 映射后满足 τ ≤ τ_max（静力学可行）。
任一失败 ⇒ 该模态/动作**硬否证**，不进入后续阶段。

**定义 313（可操作性/几何不确定性 KUD）** 可操作性椭球 M(q) = J(q)J(q)^T；几何条件数 κ(q) = σ_max/σ_min。几何不确定性
U_kin(q) = w_κ·φ(κ(q)) + w_r·dist(q, ∂𝒲)⁻¹ + w_s·1[σ_min < σ_s]，
表示「同一任务空间误差映射到关节空间后的放大程度」与「临近工作空间边界/奇异的脆弱性」。U_kin 是**确定可算**的，不含学习参数，故为「不可幻觉」的锚。

**定义 314（零空间信息动作 NIA）** 冗余自由度下 N(J) = {δq : J δq = 0}。信息动作 δq ∈ N(J) 的任务位移一阶为零 ⇒ 任务代价 c_task = O(‖δq‖²)；其信息价值来自可观测性变化：
VoI_free(δq) = I(M; y | g, δq) − I(M; y | g)，其中 y 为传感仿真观测。
选择 δq* = argmax_{δq ∈ N(J) ∩ 𝒞_safe} VoI_free(δq)，𝒞_safe 为**全碰撞**可行集（注意：零空间不保碰撞，见定义 315）。

**定义 315（零空间安全修正）** 因 N(J) 只保末端任务、不保碰撞，定义安全零空间 N_safe(q) = {δq ∈ N(J) : d_min(q+δq) > d_safe ∧ τ(q+δq) ≤ τ_max}。NIA 只在 N_safe 上搜索；若 N_safe 为空，则「免费信息」不存在，退回带成本的 R69 信息动作。

**定义 316（可达 VoI 修正）** R69 的 VoI 是理论上界；本轮用运动学与可观测性折减：
VoI_ach(g) = VoI(g) · ρ_reach(g) · ρ_obs(g)，其中 ρ_reach ∈ [0,1] 由 IK 可达性与关节裕度给出，ρ_obs ∈ [0,1] 由视场/遮挡/传感器仿真信噪给出。MINT 改用 argmax[VoI_ach − c]；**这修正了 R69 会为一个物理上问不出答案的问题付出成本**的缺陷。

**定义 317（仿真可信度校准 SRG）** 在成对数据 {(真实结果, 仿真结果)} 上估计 sim-real gap 的校准误差 ECE_sim 与系统偏差 b_sim。仅当 ECE_sim ≤ τ_sim 且 |b_sim| ≤ b_max 时，仿真证据被允许贡献 resolution bonus；否则进入单侧信任模式（定义 319）。

**定义 318（孪生-现实运动学残差 TDR）** 对真实执行动作 u，测得本体轨迹 q_real，孪生前向 Φ̂ 给出 q_sim；定义
r_kin = W_2(q_real, q_sim)（或关节角 RMS + 末端位姿误差），并归一化得 r̃_kin。r_kin 测「身体是否仍与模型一致」：机械磨损、热变形、负载变化、编码器零点漂移都会抬高它，而感知标定只能吸收 r_res、行为似然只能吸收 Δa，**三者盲区不重叠**。

**定义 319（单侧信任律）** 记 λ 为基础风险缩放。仿真/预演只能通过以下两种方式之一影响 λ：
- 若 SRG 校准通过：λ = max(λ_FLUID, λ_floor(U_ale + U_kin + 未消解 U_epi·ρ_sim))，可用预演消解 U_epi；
- 若未通过：λ = max(λ_FLUID, λ_floor(U_ale + U_kin + U_epi))，仿真**不得降低** λ，只可提高。
即：**不可信的预演只能让你更小心，不能让你更大胆。**

**定义 320（三通道故障分离）** 证据三元组 e = (r_res, Δa, r̃_kin)。
- 真缓慢漂移：三者同向小幅上升；
- 标定吸收型感知故障：r_res↓、Δa↑、r̃_kin 平稳；
- 本体/机械故障：r_res 平稳、Δa 可能↑、r̃_kin↑；
- 孪生模型失配：r̃_kin↑ 但真实任务正常、且 SRG 校准恶化。
据此构造分离器 D(e) → {drift, calib_absorbed, embodiment, twin_mismatch}。

**定义 321（预演-现实一致性证书 SRCC）** 每次真实交互后，记录预演预测 y_sim 与真实结果 y_real 的偏差 δ_y，并回灌 SRG，形成在线 sim-gap 估计；连续超出阈 ⇒ 触发「仿真不再可信」的降级。

**定义 322（KINESIM 干扰集）** ℰ_KINESIM = ℰ_FLUID × ℰ_sim × ℰ_kin，其中 ℰ_sim = {域随机化外的物理/光照/接触失配、孪生几何陈旧、渲染伪影诱导的假可观测性}，ℰ_kin = {连杆参数误标定、编码器漂移、URDF 与实物不符、奇异附近数值放大}。

**定义 323（运动学锚定审计 KAA）** 审计：被 KFC 拒绝的模态中有无真实可行模态（**唯一能证伪锚的事件**）；N_safe 是否被误用为碰撞自由；SRG 校准是否被预演数据自举污染；单侧信任律是否被绕过（仿真暗中降低 λ）。结论回灌 AuditBuf，成为下一轮预演预算与 τ_sim 的先验。

**定义 324（证书 J_KINESIM）** J_KINESIM = (J_FLUID, ece_sim, b_sim, kin_reject_rate, nullspace_voi_gain, r_kin_p95, two_sided_trust_violations, kinesim_ver)。Valid ⇔ Valid(J_FLUID) ∧ ECE_sim ≤ τ_sim（或处于合法单侧模式）∧ 两/三通道分离未报警 ∧ 审计无锚否证。

**定义 325（自适应预演预算）** 预演按需触发：仅当 R69 的 U_epi > TAU_EPI 或 KFC 报告边界（σ_min 接近阈值、d_min 接近 d_safe）时，才执行 M 次域随机化 rollout；默认 M=1 廉价快速预演。保证 P99 实时预算（预演在仿真侧异步、可跨控制周期摊销）。

**定义 326（KINESIM 主闭环语义）** 在 R69 闭环中，把「信息动作选择」与「模态执行」之间插入两级：KFC 硬过滤（几何）→ DTP 预演 + SRG 门控（物理）→ 再做 VoI_ach 决策与 λ 缩放。预演与真实交互的结果共同更新 r_kin 与 SRG，形成「预演—执行—对比—再校准」的次级闭环。

```python
# IP-265 KFC：精确运动学硬过滤（不可幻觉）
def kinematic_certify(K, xi, obstacles):
    q, ok = K.ik(xi.a.target)                                  # 可达性
    if not ok or not K.within_limits(q):               return False
    if K.min_clearance(q, xi.a.path, obstacles) <= D_SAFE: return False  # 碰撞/自碰撞
    if K.sigma_min(q) <= SIGMA_S:                      return False      # 奇异
    if K.static_torque(q, xi.a.wrench) > TAU_MAX:      return False      # 静力学
    return True

# IP-266/267 NIA：零空间免费信息，仅在安全零空间搜索
def nullspace_info(K, q, modes, world):
    best = None
    for dq in sample_nullspace(K.nullspace(q)):                # J dq = 0
        if K.min_clearance(q + dq, world.obstacles) <= D_SAFE: continue   # 不保碰撞！
        if K.torque(q + dq) > TAU_MAX:                        continue
        gain = mutual_info(mode_id, K.gaze_sim(q + dq)) - base
        if best is None or gain > best.gain: best = (dq, gain)
    return best                                                 # None => 无免费信息

# IP-269 AVC：把理论 VoI 折减为可达 VoI
def achievable_voi(g, K, world, sim):
    return g.voi * K.reach_factor(g) * sim.observability_factor(g)   # rho_reach * rho_obs

# IP-270/271/272 SRG+TDR+单侧信任
def rehearse_and_gate(twin, srg, modes, infos, lam_fluid):
    sim = twin.parallel_rollout(modes, infos, M=twin.budget)   # 域随机化预演
    if srg.calibrated() and srg.ece <= TAU_SIM:
        U_epi_after = srg.resolve(modes, sim)                  # 双阶段：可降 U_epi
        lam = max(lam_fluid, lam_floor(U_ale + U_kin + U_epi_after))
    else:
        lam = max(lam_fluid, lam_floor(U_ale + U_kin + U_epi)) # 单侧：只增不减
    return sim, lam

# IP-276 KINESIM 主闭环（在 R69 的 FLUID 层内插入几何 + 预演两级）
def KINESIM_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    samples = M.fmp.sample(o, K=4 if M.fmp.mode_head(z) > TAU_MODE else 1)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    U_kin = M.kud.geometric_uncertainty(M.robot.q)
    # 1) 几何硬否证：不可幻觉的第三意见
    modes = [m for m in modes if M.kfc.certify(M.robot.K, m, M.world.obstacles)]
    if not modes: return M.r68_fallback(...)                   # 全部否证 => 最保守
    # 2) 免费信息优先：安全零空间动作
    g_free = M.nia.choose(modes, M.robot.q, M.world)
    # 3) 有成本信息动作：先做可达 VoI 折减，再比成本
    g_paid = M.mint.choose(modes, o, M.budget, voi=M.avc.correct)
    # 4) 预演 + 单侧信任律
    sim, lam = M.dtp.rehearse_and_gate(M.srg, modes, [g_free, g_paid], M.efs.risk_scale(...))
    # 5) 三通道故障分离
    r_kin = M.tdr.residual(M.robot.q_real, sim.pred_q)
    fault = M.tcf.classify(M.last_r_res, M.last_delta_a, r_kin)
    if fault in ('embodiment', 'twin_mismatch'):
        lam = max(lam, LAM_HARD); modes = kar_shrink(modes, U_cal)
    # 6) 执行仍走 R69/C-RAS-WM 认证；审计 + 证书
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., M.vista.pred)
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.kaa.submit_async(fault, r_kin, M.srg.ece, modes_rejected=...)
    return k, lam, mode, (U_ale, U_kin, U_epi)
```

## 3. 推导

**引理 19（运动学否证的可靠性）** 若本体模型 K 正确且 d/limits/J 精确，则 KFC 拒绝的模态/动作在真实世界中不可实现。因此 KFC 对「几何不可行」子类幻影的拒绝率为 1（无误杀）。反之，KFC 通过只是必要条件，不保证可行（可能漏放几何可行但语义荒谬的模态）。系：KFC 是**可靠但非完备**的反幻影过滤器，只能降低、不能消除 R69 的幻影风险。

**引理 20（零空间免费信息）** 对冗余度 r = n − m > 0，δq ∈ N(J) 时末端位移 ‖δx‖ ≤ ½‖δq‖²·L_curve + O(‖δq‖³)；故任务风险二阶小。若 δq 改变观测 Gramian 使 I(M;y) 增加 ΔI > 0，则获得任务代价 ~O(‖δq‖²) 的信息增益；在 c_task ≈ 0 极限下 VoI/c 趋于无穷（存在免费区段）。系：冗余度把交互预算约束从「必须值得」放松为「尽量免费」。

**引理 21（单侧信任的后悔界）** 若仿真仅有单侧可信（ECE_sim > τ），只允许提高 λ，则相对真值 oracle 的期望风险 ≤ R_FLUID（不劣于 R69），且严格劣于双阶段（因为不能用 sim 降低 λ）；因此单侧信任是以效率换安全正确性的最保守折中。

**定理 18（KINESIM 严格包含 FLUID/R68）** 在 A99–A101（本体模型正确、KFC 可靠、SRG 校准/单侧律成立）下，KINESIM 任意状态期望风险 ≤ FLUID ≤ R68；且当 (i) SRG 未校准且无硬否证、(ii) U_epi ≤ 成本、(iii) 预演预算耗尽 时，与 FLUID 逐指令相同（仿真只作日志）；进一步退化到 R68。安全侧永不弱化。

**定理 19（三通道盲区不交）** 设故障类 F 至少改变 {感知读数、闭环行为、本体运动学} 之一，且三通道分别为其充分统计量。则不存在仅吸收单一通道的标定/模型更新能同时把 (r_res, Δa, r̃_kin) 拉回正常域；故 D(e) 对 F 中任一故障的检出率 > 0，且对「标定吸收型」与「本体型」故障可区分。系：这是对 R68「缓变故障被吸收」与 R69「行为似然被同类模型蒙骗」的双重补洞。

**定理 20（预演降幻影）** 令幻影模态比例 π_ph，其中几何不可行比例 π_geo ⊆ π_ph。经 KFC 后残余幻影比例 ≤ π_ph − π_geo；再经 DTP+SRG 门控，被真实采纳的幻影 ≤ (π_ph − π_geo)·(1 − R_sim)·（R69 的 k-正交一致失败率）。故「问错」概率相对 R69 乘性下降；但当 π_geo → 0（幻影都几何可行）时 KFC 失效，退化到仅靠 SRG 与 R69 证据纪律。**这说明运动学锚只对「身体做不到的错」有效，对「身体做得到但语义荒谬的错」无效——诚实暴露边界。**

**定理 21（预演无突变）** DTP 预演在仿真侧异步进行，不直接产生执行指令；真实执行仍经 R69 的 C-RAS-WM 认证与提交/换装不变式。SRG 降级、KFC 硬拒绝、r_kin 报警只在 λ 上单调不降地作用，故控制连续、无突变；预演超时/失败等价于「未预演」，退回 FLUID。

## 6. 本轮最大风险

**一句话**：KINESIM 把「问错」的赌注从「流模型是否可信」换成了「数字孪生是否可信」——若仿真与现实存在系统性 gap，预演会给出**内部自洽、外部错误**的自信答案，把 R69 的「诚实不知道」升级为「在假世界里排练出的确定」；而运动学锚只锚住了我们**建模过的那部分**现实，未被建模的接触、柔性、摩擦与人体行为恰恰落在它的盲区。

**次级风险与缓解**：
1. **零空间不等于安全**（肘部摆动避开末端障碍却撞到侧向障碍）→ 定义 315 只在 N_safe 上搜索 + E304 零碰撞验证；
2. **仿真自举污染校准**（用仿真数据训练 SRG，再用 SRG 信任仿真）→ 定义 323 审计 + 真值留出集 + 单侧信任默认；
3. **运动学锚否证了真实模态**（URDF 错、连杆标定漂、编码器零点偏）→ KAA 审计「误杀」这一唯一可证伪事件 + 定义 318 的 r_kin 报警；
4. **预演击穿实时预算** → 定义 325 按需触发 + 异步摊销 + 超时等价未预演退回 FLUID；
5. **几何可行但语义荒谬的幻影无法被 KFC 拦截** → 忠实承认其边界，交由 SRG 与 R69 的 k-正交证据纪律兜底。

```python
# IP-265 KFC：精确运动学硬过滤（不可幻觉）
def kinematic_certify(K, xi, obstacles):
    q, ok = K.ik(xi.a.target)
    if not ok or not K.within_limits(q):               return False
    if K.min_clearance(q, xi.a.path, obstacles) <= D_SAFE: return False
    if K.sigma_min(q) <= SIGMA_S:                      return False
    if K.static_torque(q, xi.a.wrench) > TAU_MAX:      return False
    return True

# IP-266/267 NIA：零空间免费信息，仅在安全零空间搜索
def nullspace_info(K, q, modes, world):
    best = None
    for dq in sample_nullspace(K.nullspace(q)):                 # J dq = 0
        if K.min_clearance(q + dq, world.obstacles) <= D_SAFE: continue
        if K.torque(q + dq) > TAU_MAX:                         continue
        gain = mutual_info(mode_id, K.gaze_sim(q + dq)) - base
        if best is None or gain > best.gain: best = (dq, gain)
    return best                                                  # None => 无免费信息

# IP-269 AVC：理论 VoI 折减为可达 VoI
def achievable_voi(g, K, world, sim):
    return g.voi * K.reach_factor(g) * sim.observability_factor(g)

# IP-270/271/272 SRG + TDR + 单侧信任
def rehearse_and_gate(twin, srg, modes, infos, lam_fluid, U_ale, U_kin, U_epi):
    sim = twin.parallel_rollout(modes, infos, M=twin.budget)    # 域随机化预演
    if srg.calibrated() and srg.ece <= TAU_SIM:
        U_epi_after = srg.resolve(modes, sim)                   # 双阶段：可降 U_epi
        lam = max(lam_fluid, lam_floor(U_ale + U_kin + U_epi_after))
    else:
        lam = max(lam_fluid, lam_floor(U_ale + U_kin + U_epi))  # 单侧：只增不减
    return sim, lam

# IP-276 KINESIM 主闭环（在 R69 的 FLUID 层内插入几何 + 预演两级）
def KINESIM_round(M, obs):

    samples = M.fmp.sample(o, K=4 if M.fmp.mode_head(z) > TAU_MODE else 1)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    U_kin = M.kud.geometric_uncertainty(M.robot.q)
    # 1) 几何硬否证：不可幻觉的第三意见
    modes = [m for m in modes if M.kfc.certify(M.robot.K, m, M.world.obstacles)]
    if not modes: return M.r68_fallback(...)                    # 全部否证 => 最保守
    # 2) 免费信息优先：安全零空间动作
    g_free = M.nia.choose(modes, M.robot.q, M.world)
    # 3) 有成本信息动作：先做可达 VoI 折减，再比成本
    g_paid = M.mint.choose(modes, o, M.budget, voi=M.avc.correct)
    # 4) 预演 + 单侧信任律
    sim, lam = M.dtp.rehearse_and_gate(M.srg, modes, [g_free, g_paid],
                                       M.efs.risk_scale(...), U_ale, U_kin, U_epi)

    r_kin = M.tdr.residual(M.robot.q_real, sim.pred_q)
    fault = M.tcf.classify(M.last_r_res, M.last_delta_a, r_kin)
    if fault in ('embodiment', 'twin_mismatch'):
        lam = max(lam, LAM_HARD); modes = kar_shrink(modes, U_cal)
    # 6) 执行仍走 R69/C-RAS-WM 认证；审计 + 证书

    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.kaa.submit_async(fault, r_kin, M.srg.ece, modes_rejected=...)
    return k, lam, mode, (U_ale, U_kin, U_epi)
```

## 4. 推导

**引理 19（运动学否证的可靠性）** 若本体模型 K 正确且 d/limits/J 精确，则 KFC 拒绝的模态/动作在真实世界不可实现 ⇒ 对「几何不可行」子类幻影的拒绝率为 1（无误杀）；但 KFC 通过仅为必要条件。故 KFC 是**可靠但非完备**的反幻影过滤器。

**引理 20（零空间免费信息）** 冗余度 r = n−m>0 时，`δq∈N(J)` 使末端位移 `‖δx‖ ≤ ½‖δq‖²L_curve + O(‖δq‖³)`，任务风险二阶小；若其改变观测 Gramian 使互信息增 ΔI>0，则 `c_task→0` 处 VoI/c→∞，存在免费区段。系：冗余度把交互预算从「必须值得」放松为「尽量免费」。

**引理 21（单侧信任的后悔界）** 未校准仿真只允许提高 λ 时，期望风险 ≤ R_FLUID，且严格劣于双阶段（不能用 sim 降 λ）——这是以效率换安全正确性的最保守折中。

**定理 18（KINESIM 严格包含 FLUID/R68）** A99–A101 下期望风险 ≤ FLUID ≤ R68；当 SRG 未校准且无硬否证、或 U_epi ≤ 成本、或预演预算耗尽 时与 FLUID 逐指令相同（仿真仅作日志），并进一步退化到 R68。安全侧永不弱化。

**定理 19（三通道盲区不交）** 故障至少改变 {感知读数、闭环行为、本体运动学} 之一且三通道为其充分统计量时，任何仅吸收单一通道的标定/模型更新都无法同时把 (r_res, Δa, r̃_kin) 拉回正常域；D(e) 对故障检出率 > 0，且可区分「标定吸收型」与「本体型」。系：同时补 R68 与 R69 的盲区。

**定理 20（预演降幻影）** 幻影比例 π_ph、其中几何不可行比例 π_geo 时，KFC 后残余 ≤ π_ph−π_geo；再经 DTP+SRG 门控，真实采纳幻影 ≤ (π_ph−π_geo)(1−R_sim)·（R69 证据纪律失败率）。当 π_geo→0 时 KFC 失效、退化到 SRG+证据纪律——**锚只对「身体做不到的错」有效，对「做得到但语义荒谬的错」无效**。

**定理 21（预演无突变）** DTP 异步、不直接产生执行指令；真实执行仍经 C-RAS-WM 认证与提交/换装不变式；SRG 降级/KFC 拒绝/r_kin 报警只单调不降地作用于 λ ⇒ 控制连续、无突变；预演超时/失败等价「未预演」，退回 FLUID。

## 7. 本轮最大风险

**一句话**：KINESIM 把「问错」的赌注从「流模型是否可信」换成了「数字孪生是否可信」——若仿真与现实有系统性 gap，预演会给出**内部自洽、外部错误**的自信答案，把 R69 的「诚实不知道」升级为「在假世界里排练出的确定」；运动学锚只锚住我们**建模过的那部分**现实，未建模的接触、柔性、摩擦与人体行为恰落在其盲区。

**次级风险与缓解**：零空间≠安全（定义 315 只在 N_safe 搜索 + E304 零碰撞）；仿真自举污染校准（KAA 审计 + 真值留出集 + 单侧信任默认）；运动学锚误杀真实模态（KAA 审计「误杀」+ r_kin 报警）；预演击穿实时预算（按需触发 + 异步摊销 + 超时退回 FLUID）；几何可行但语义荒谬的幻影无法被 KFC 拦截（忠实承认边界，交由 SRG 与 R69 的 k-正交证据纪律兜底）。
