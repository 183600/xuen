# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 2 轮；本轮灵感：「论文发表」×「仿真训练」）

> 第 57 轮把安全的赌注从"模型置信"换成"证据质量"，并用元少样本摊销、跨模态对账、个性化有界信任给证据加了三道保险；它自己的风险自陈却指出最先崩的仍是**语料**：元先验从历史探针史摊销，而历史只留下"成功的、被采纳的"探针，失败与被放弃的区域根本进不了训练集；OOD 门只能识别它见过的"不像"，识别不出"从未存在"的盲区。本轮两个灵感各补一刀。**论文发表**把证据从"私有观测"升级为"可预注册、可独立复现、全结果登记、可撤稿"的公共知识对象——用科学共同体的纠错制度治理自欺、发表偏倚与 p-hacking；**仿真训练**把最危险的世界先放进数字孪生里跑——仿真不是证据的来源，而是**先证伪器**与**迁移风险的显式度量**，其结论被硬隔离在不可逆接触之外。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据承诺"升级为 **"可预注册、可复现、可撤稿、仿真先证伪的证据承诺"**，一句话：*不能发表的证据不算证据，没在仿真里先被推翻过的先验不许上真机*。

核心矛盾：
- **H29（证据自欺 vs 发表偏倚）**：私有证据只登记成功探针，失败探针被静默丢弃——元先验训练在幸存者样本上，天然过度自信；更糟的是，事后挑阈值、挑区域、挑模态就是 p-hacking。证据数量增加不等于可信度增加，若"发表的"只是有利结果。
- **H30（仿真自洽 vs 现实可信）**：仿真能廉价地把最坏情况跑一万遍，但仿真器只是世界的一个模型，sim-to-real gap 就是"审稿人的误差"；在仿真里通过并在仿真里复现，很可能只是"同一学派的审稿人彼此一致"。仿真越丰富，越容易制造形式合规的错觉。
- **H31（流程严谨 vs 节拍经济）**：预注册、独立复现、全结果登记、撤稿传播都带来开销与延迟；若对一切接触强制，会把第 57 轮省下的探针预算原样花回去（证据官僚化）。必须按接触不可逆程度分级：不可逆接触严格，可逆接触轻量。

## 0. 直觉与动机

**灵感 1（论文发表 → 证据的发表-评审-撤稿生命周期）**
直觉：第 57 轮的证据是"实验室笔记本"——私有、可涂改、只留成功页。科学共同体之所以比笔记本可信，不是因为科学家更诚实，而是因为制度：**预注册**让假设在见数据前就锁死（堵住 p-hacking 与"移动球门"）；**独立复现**让"我测到了"变成"别人也测到了"（堵住单通道系统性误差）；**全结果登记**让阴性结果也入档（校正发表偏倚与幸存者偏差）；**撤稿传播**让一个错误不再被继续引用（沿引用图级联失效）。把这四件事搬到机器人证据上：每一次承诺都必须引用一个**先于观测写入、不可篡改**的注册凭据；关键证据必须有一次**先验声明独立**的复现（换模态/换机器人/换时间/换种子）；探针预算与登记条目对账，缺失率直接扣减证据强度；事后证伪触发撤稿，沿证据依赖 DAG 反向传播，把所有下游承诺降级或重开。证据的可信度不来自"我测到了"，而来自"**别人重放也测到，且失败也被记录，错了还能撤**"。
严谨定义（预告）：定义 139 证据预注册与全结果登记 PRE；定义 140 独立复现与证据强度指数 ESI；定义 141 撤稿与引用传播 RET。

**灵感 2（仿真训练 → 仿真内先证伪 + sim-to-real 缺口入界）**
直觉：仿真是最安全的实验室——可以在数字孪生里把最坏情况跑一万遍而不付不可逆代价。但仿真器本身是"世界的审稿人"，它有自己的偏见（sim-to-real gap）。所以仿真结果不能直接当证据（"仿真里通过"推不出"现实里通过"），只能当两种东西：**(a) 先证伪器**——用域随机化与对抗场景搜索，主动找能推翻元先验的世界（把"语料盲区"变成"仿真里已经见过的失败"），任何一个反例都让元先验降级/加宽；**(b) 迁移风险的显式度量**——用一个有覆盖保证的迁移校准器 g_TR 估计 sim→real 的失败率上界 Δ_SR，把它作为显式项写进部署界，而不是假装 gap 不存在。仿真与真实探针在同一注册测试上分歧超过 θ_SR，就当作"审稿人异议"：强制真实复核并加宽不确定性。硬约束：**仿真证据只可用于 L0/L1，永远不进不可逆接触的必要证据集**。
严谨定义（预告）：定义 142 数字孪生与域随机化 SAM；定义 143 Sim-to-Real 迁移校准 TRC 与分歧检测。

**灵感 3（两灵感合流 → 发表是流程，仿真是预印本实验室）**
直觉：把仿真训练看作"预印本"——快速、廉价、可无限迭代，但没过真实世界的同行评审就不能定论；真实探针+独立复现是"同行评审"；撤稿是纠错。证据强度可分解为四个乘子：**预注册严格性 × 复现独立性 × 全结果完整性 × 迁移校准度**，任一为 0 则总强度为 0——这正是防止"形式合规"的关键：在同一个仿真器里复现一万次，独立性因子不会超过"同源审稿"，总强度上不去。流程因此有明确的层级：仿真（预印本，仅可逆）→ 真实单次探针（投稿）→ 真实独立复现（同行评审）→ 承诺（发表）→ 证伪（撤稿）。
严谨定义（预告）：定义 144 发表-评审-撤稿证据门 PRE-Gate 与证据发表证书 J_q。

**灵感 4（对第 57 轮"坏先验普遍"的直接回应）**
直觉：第 57 轮的 OOD 门只能识别"像不像训练分布"，识别不了"训练分布本身漏了一整类世界"。本轮两条独立防线：**发表偏倚校正**让元语料必须披露登记覆盖率并用逆倾向重加权（不能说"没探过就当没见过"）；**仿真对抗证伪**让域随机化主动生成语料外材质，把盲区在仿真里先撞出来。两者都在"坏先验进入承诺"之前介入，且都不把安全赌在元模型上——一个改数据，一个改流程，最后的否决权仍留给真实探针。

**灵感 5（发表的激励相容 → 奖励校准与复现，而非奖励"过门"）**
直觉：若证据门奖励"通过"，系统就会学会制造容易通过的证据（挑软柿子区域、挑有利模态、挑宽松阈值）——这是机器人版的 publish-or-perish。用"注册报告"式设计切断激励：承诺只能按**预先注册的规则**评估，不允许事后择优；评价指标改为校准误差与复现一致率（proper scoring），而非过门率。元训练/在线更新也只看被复现且未被撤稿的证据。这样"多发证据"不再自动等于"更容易承诺"。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（证据预注册与全结果登记 PRE）** 证据账本 L_ev 为 append-only、hash-chain 结构。对每次将被引用的检验，系统在首次观测前写入注册凭据 ρ_e=(h_e,θ_e,decision_rule,stopping_rule,τ_tol,ctx_e,hash)，承诺必须引用满足 time(ρ_e)<time(first_obs_e) 且 hash 未被篡改的注册项——禁止事后调整阈值/停止规则（反 p-hacking）。全结果登记：所有探针（含阴性/失败/放弃）编号入册；登记覆盖率 κ=#registered/#executed；元训练集 𝒟_meta 按逆报告倾向 w_reg=1/π_reg 重加权，未登记探针权重为 0；κ<κ_min 的时段其证据强度以 κ 线性折减（file-drawer 校正）。承诺若只引用未预注册证据，仅得"预印本级"，最高只支持 L1。

**定义 140（独立复现与证据强度指数 ESI）** 复现关系 Replicate(e,e')⇔ (a) e' 的独立性声明 a priori 成立：通道/单位/时间/种子至少一维正交；(b) 二者按注册的 τ_tol 判定一致。证据强度
ESI(e)=ρ_strict(e)·ι_rep(e)·κ_reg(e)·γ_TR(e)∈[0,1]，
四项分别为预注册严格性、复现独立性、登记完整性、迁移校准度（真实证据取 γ_TR=1）。ι_rep 的设计防"同源注水"：无复现取 ι_0∈(0,1)；仅有同源复现时 ι_rep=ι_0+(ι_same_max−ι_0)(1−e^{−n}) 且封顶 ι_same_max<1；存在先验独立的同源一致复现时方可趋近 1。证据门阈值 ε_ESI(ℓ) 随接触等级单调升：ε_ESI(L0)<ε_ESI(L1)<ε_ESI(L2)。

**定义 141（撤稿与引用传播 RET）** 证据依赖图 G_ev=(V,E)，V=证据工件∪承诺，边 u→v 表 v 引用 u。Retract(e,reason) 将 e 标记为撤回（单调，不可复活，只能被新证据 supersede），并在 G_ev 上取反向可达闭包 Desc(e)；∀v∈Desc(e)：关键证据依赖降级为"预印本级"，已生效承诺置为"待复核/回滚"。承诺 active(v)⇔ v 的全部祖先非撤回；撤回事件 append-only 记账。软传播权重 w_ret(edge) 使非关键引用只加宽不硬删，避免一次撤稿雪崩式推翻全部结论。

**定义 142（数字孪生与域随机化 SAM）** 数字孪生 𝒮_r 由地图 𝓜 与材质/几何参数生成，参数取自域随机化分布 𝒟_dr。对抗证伪搜索
Falsify(q_φ,𝒮_r)=argmax_{s∈𝒟_dr} Div(obs_𝒮(s), q_φ(·|ctx_r))
返回反例集 Φ_r。若 Φ_r≠∅ 且反例似然不可忽略，则元先验"已被仿真证伪"，必须降级或加宽后才可进入真实承诺；仿真产出的证据类记为 EV-sim，仅可服务 L0/L1。

**定义 143（Sim-to-Real 迁移校准 TRC）** 迁移校准器 g_TR 以仿真特征与 gap 特征预测真实失败率，需在留出真实试验上满足覆盖 ≥1−α_TR；Δ_SR(r)=sup 真实−仿真 失败率差的保守上界。对同一注册测试的 sim-real 对 (e_sim,e_real)，若 |fail(e_sim)−fail(e_real)|>θ_SR 则判"迁移分歧"，触发强制真实复探并加宽后验。Δ_SR 作为显式加项进入部署界；仿真证据在错误模型中的贡献不得被抵消为负。

**定义 144（发表-评审-撤稿证据门 PRE-Gate 与证书 J_q）** 证据类扩为 EV-probe*/EV-visit/EV-margin/EV-xmodal/EV-human/EV-sim/EV-repl。规则：(R-a) 任何证据须挂 ESI≥ε_ESI(ℓ)，否则降为预印本级、只可支持 L0/L1；(R-b) 不可逆接触（L2）的必要证据集必须含**至少一次真实独立复现**（EV-repl），EV-sim 与 EV-xmodal 均不得进入；(R-c) 引用被撤回证据的承诺一律拒；(R-d) EV-sim 仅 L0/L1 且须 Δ_SR≤θ_SR。证书 J_q=(J_p, root(L_ev), registrations, replications, registry_coverage κ, retraction_closure, trc_cal_log, sim_falsify_log)。发布式证书链使审计者可从承诺反向验证到原始注册与复现。

## 2. 关键算法伪代码（完整版见产物区）

```python
def register_before_probe(ledger, region, hypothesis, theta, rule, tol):
    assert not ledger.has_observations(region, hypothesis)     # 观测前
    return ledger.append(Registration(region, hypothesis, theta, rule,
                                      tol, ctx=ctx(region), t=now()))

def publish_evidence(e, ledger, G_ev):                         # IP-139/140
    if not ledger.registration_precedes(e): return Tier.PREPRINT
    ledger.register_outcome(e)                                # 阴性也入册
    esi = strict(e) * independence(e) * coverage(ledger) * transfer_cal(e)
    tier = Tier.PUBLISHED if esi >= eps_ESI(e.level) else Tier.PREPRINT
    G_ev.add(e, cites=e.ancestors); return e.with_(esi=esi, tier=tier)

def retract_and_propagate(e, G_ev, commitments):              # IP-141
    G_ev.retract(e)
    for v in reverse_reachable(G_ev, e):
        if v in commitments: commitments[v].reopen_or_rollback(w_ret(v))
        else: v.downgrade_to_preprint()

def sim_falsify_and_calibrate(q_phi, S_r, meta):              # IP-142/143
    Phi = adversarial_search(S_r, dr_dist, target=q_phi)
    if Phi: meta.widen_or_downgrade(Phi)                      # 先证伪
    dSR = g_TR.upper_bound(S_r)                               # 迁移缺口上界
    return meta, Phi, dSR
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| PRE | O(1) 追加 / O(log N) 校验 | O(#reg) 账本 | hash-chain 不可篡改、注册先于观测 |
| ESI | O(#repl·d_ev) | O(#ev) | 独立性前置声明、同源复现封顶 |
| RET | O(\|V\|+\|E\|) 反向闭包 | O(\|V\|+\|E\|) DAG | 闭包完备、单调不可复活 |
| SAM | O(#dr·cost(𝒮)) 离线 | O(#scenarios) | 反例可行、仅 L0/L1 |
| TRC | O(d_g)/查询；训练离线 | O(#real_trials) | 覆盖 ≥1−α_TR、分歧漏检 ≤δ_SR |
| PRE-Gate | O(\|σ\|·(#repl+log N)) | O(\|σ\|+J_q) | 无真实复现不 L2、被撤稿即拒 |

**正确性定理（Publishable-Evidence Soundness, PES 概要）**：在 A33–A40 上新增 (A41) 注册不可篡改且先于观测；(A42) 复现独立性前置声明、登记覆盖率 κ≥κ_min；(A43) 撤稿闭包完备、无孤儿引用；(A44) 仿真证据仅 L0/L1、TRC 覆盖 ≥1−α_TR、分歧漏检 ≤δ_SR。则：(i) 证据强度单调且不可用"同源复现"注水（ι_rep 对同源封顶）；(ii) 发表偏倚残留过度自信 ≤(1−κ)·bias_max；(iii) 撤稿后陈旧承诺残留概率 ≤δ_ret；(iv) L2 承诺对真实复现的硬依赖使仿真系统性误差贡献为 0；(v) 部署界在 CCPS 上追加 −(1−κ)bias_max −δ_ret −(α_TR+δ_SR)·1[sim∈证据链]。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 预注册/复现开销拖垮节拍（证据官僚化） | 高 | 分级：仅 L2 强制全流程；L0/L1 模板化哈希 O(1)；离线批量注册 |

| 仿真器系统性偏差为错误背书（同源审稿） | 高 | EV-sim 硬隔离于 L2 + TRC 覆盖保证 + 域随机化对抗搜索 + sim-real 分歧强制真探 |
| 全结果登记仍被选择性省略（file drawer） | 中 | 预算-登记对账、覆盖率 κ 入 ESI、缺失率惩罚、账本公开可审计 |
| 撤稿级联过度/抖动 | 中 | 依赖边分级权重、软降级优先、人工/元审计复核 |
| 迁移校准器时延 | 中低 | 离线训练+预取+影子模式；可退回第 57 轮路径 |

## 6. 本轮最大风险

**一句话**：本轮给证据套上了预注册、复现、登记、撤稿的全套"学术规范"，最大风险从"坏先验普遍"变为"**形式合规的证据政体**"——当仿真器与迁移校准器本身存在系统性偏差时，预注册的严格、复现的一致、登记的完整反而会给一个"审稿人同源"的错误结论背书；流程越像科学，越可能把"仿真里自洽"误当成"现实里可信"，因此必须把仿真证据硬隔离在不可逆接触之外、把 sim-to-real gap 作为显式上界项、并保留"宁可退回又宽又慢的真实探针"的最后否决权。

## 2. 关键算法伪代码

### IP-139 PRE（预注册 + 全结果登记 + 发表偏倚校正）

```python
def register_before_probe(ledger, region, hypothesis, theta, rule, stop, tol):
    # 注册必须先于观测：账本记录首次观测时间戳，事后注册一律拒
    assert not ledger.has_observations(region, hypothesis)
    reg = Registration(region, hypothesis, theta, rule, stop, tol,
                       ctx=ctx(region), t=now(),
                       hash=hash_chain(ledger.root, payload))
    ledger.append(reg)                        # append-only + hash-chain
    return reg

def register_outcome(ledger, e, outcome):     # 阴性/失败/放弃也必须入册
    ledger.append(Outcome(e.id, outcome, t=now()))

def meta_corpus_reweight(D_meta, ledger, kappa_min):
    kappa = ledger.registry_coverage()        # #registered / #executed
    w = {e: (1.0 / pi_reg(e)) for e in D_meta if ledger.registered(e)}
    for e in D_meta:
        if not ledger.registered(e):
            w[e] = 0.0                        # file-drawer：未登记权重归零
    if kappa < kappa_min:
        D_meta = scale_confidence(D_meta, kappa)   # 残留下调自信
    return reweighted(D_meta, w), kappa
```

**设计要点**：注册凭据锁死 `(hypothesis, θ, decision_rule, stopping_rule, τ_tol)`；承诺评估只允许使用注册规则，不允许"事后择优"（注册报告式 anti-p-hacking）。登记覆盖率 κ 同时进入元语料重加权与 ESI，形成"少登记 ⇒ 低强度"的闭环。

### IP-140 ESI（证据强度指数）

```python
def evidence_strength(e, ledger, G_ev, g_TR):
    rho = 1.0 if ledger.registered_before_obs(e) and ledger.hash_ok(e) else 0.0
    iota = replay_independence(e, G_ev)        # 见下：同源复现封顶
    kappa = ledger.registry_coverage()
    gamma = 1.0 if e.kind != 'sim' else g_TR.calibrated_factor(e)
    return rho * iota * kappa * gamma

def replay_independence(e, G_ev):
    reps = replications_of(e, G_ev)
    if any(r.independent_apriori for r in reps):
        return min(1.0, iota_0 + sum(r.weight for r in reps if r.independent_apriori))
    if reps:                                   # 只有同源复现：注水无效
        return iota_0 + (IOTA_SAME_MAX - iota_0) * (1 - exp(-len(reps)))
    return iota_0                              # 无复现：低于发表阈值
```

**设计要点**：四乘子不可相互补偿——预注册严格但同源复现，总强度仍被 `ι_same_max` 封顶；真实证据 `γ_TR=1`，仿真证据被迁移校准直接折减。ESI 用 proper scoring（校准误差、复现一致率）评价，而非过门率，切断 publish-or-perish 激励。

### IP-141 RET（撤稿与引用传播）

```python
def retract_and_propagate(e, reason, G_ev, commitments, ledger):
    ledger.append(Retraction(e.id, reason, t=now()))   # 单调、不可复活
    G_ev.retract(e)
    for v in reverse_reachable(G_ev, e):               # 反向可达闭包
        if v in commitments:
            w = w_ret(v.dep_edge)                      # 软传播：关键边硬降级
            commitments[v].reopen_or_rollback(weight=w)
        else:
            v.downgrade_to_preprint()
    return G_ev.active_set()                           # active ⇔ 祖先全非撤回

def w_ret(edge):
    return 1.0 if edge.critical else 0.35              # 非关键引用只加宽不硬删

def is_active(commitment, G_ev):
    return all(not a.retracted for a in ancestors(G_ev, commitment))
```

**设计要点**：撤稿是**沿引用图的反向传播**，而非只标记单条证据；`active(v)` 定义使任何引用被撤稿证据的承诺自动失效，避免"坏证据长寿"在第 58 轮以"坏引用长寿"形式复现。软权重避免一次撤稿雪崩式推翻全部结论。

### IP-142 SAM（数字孪生 + 域随机化对抗证伪）

```python
def sim_falsify(q_phi, S_r, dr_dist, budget):
    Phi = []
    for s in sample(dr_dist, budget):          # 材质/摩擦/刚度/几何/光照
        obs = rollout(S_r, s)
        d = divergence(obs, q_phi.predict(ctx_r))   # 与元先验的偏差
        if d > theta_falsify:
            Phi.append((s, d))
    Phi.sort(key=lambda x: -x[1])
    return Phi                                 # 非空 ⇒ 元先验已被仿真证伪

def apply_sim_falsification(meta, Phi):
    if Phi:
        meta = widen_or_downgrade(meta, Phi)   # 降级/加宽，不直接采信
    return meta
```

**设计要点**：仿真的作用是**产生反例**，不是产生"通过"。域随机化把"语料里没有的世界"主动造出来；反例集 Φ_r 直接作用于第 57 轮的 `q_φ`，让"坏先验"在真机之前就被削峰。仿真结论一律打上 `EV-sim`，由 IP-144 硬隔离。

### IP-143 TRC（Sim-to-Real 迁移校准与分歧检测）

```python
def transfer_calibrate(sim_trials, real_trials, alpha_TR):
    g = fit_transfer(sim_trials, real_trials)      # sim 特征+gap 特征 → 真实失败率
    assert conformal_coverage(g, real_trials) >= 1 - alpha_TR
    return g

def sim_real_guard(e_sim, e_real, g_TR):
    dSR = g_TR.upper_bound_gap(e_sim)               # 保守上界
    if abs(e_sim.fail - e_real.fail) > theta_SR:    # 同测试上 sim-real 分歧
        return Guard(trigger_real_reprobe=True, widen=dSR)  # 强制真实复核+加宽
    return Guard(trigger_real_reprobe=False, widen=dSR)
```

**设计要点**：`Δ_SR` 是**显式写进部署界**的项，而不是被吸收进模型误差里；分歧检测等价于"审稿人异议"，触发第 57 轮的强制加宽与真实复探。TRC 覆盖不达标时，仿真证据强度 `γ_TR` 自动下调，形成自我约束。

### IP-144 PRE-Gate（发表-评审-撤稿证据门 + J_q）

```python
def publishable_evidence_gate(c, M, persona, ood_reg, G_ev, ledger, g_TR):
    level = c.level                              # L0/L1/L2
    if not is_active(c, G_ev):
        return ('reject', 'retracted_ancestor', c)          # 撤稿即拒
    e = c.evidence
    esi = evidence_strength(e, ledger, G_ev, g_TR)
    if esi < eps_ESI(level):
        return ('reject', 'ESI_below_threshold', c)         # 预印本级不背书
    if c.ev == 'EV-sim':
        if level == 'L2': return ('reject', 'sim_on_irreversible', c)
        if g_TR.gap(e) > theta_SR: return ('reject', 'sim_real_divergence', c)
    if level == 'L2' and not has_real_independent_replication(c, G_ev):
        return ('reject', 'L2_needs_real_replication', c)   # 硬禁令
    if not round57_gate(c, M, persona, ood_reg):
        return ('reject', 'round57_evidence_insufficient', c)
    return ('ok', J_q(M.core, root(ledger), registrations(c), replications(c),
                      ledger.registry_coverage(), retraction_closure(c),
                      g_TR.log(c), sim_falsify_log(c)))
```

**设计要点**：七类证据统一过 ESI 阈值；`EV-sim` 的两条硬禁令（不 L2、Δ_SR≤θ_SR）；L2 必须含真实独立复现。`J_q` 是 `J_p` 的超集，审计者可从证书反向验证到原始注册与复现。

### IP-138→PCE++（发表式探-诺-演循环）

```python
def probe_commit_evolve_publication(x0, M, task, budget, consent, personas,
                                    ledger, G_ev, S_r, g_TR):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        reg = register_before_probe(ledger, cp.region, hypothesis_of(cp),
                                    theta_of(cp), decision_rule, stop_rule, tau_tol)
        meta, Phi, dSR = sim_falsify_and_calibrate(meta.q_phi, S_r[cp.region], meta)
        inf = meta_few_shot_infer(M, cp.region, M.obs[cp.region], meta)
        if Phi or dSR > theta_SR:
            inf = widen(inf, Phi, dSR)           # 仿真先证伪 / 迁移缺口入界
        sigma = foothold_schedule(x0, cp, M); R = schedule_risk(sigma, M)
        while select_gait(R) == 'halt' and budget.probes_left > 0:
            p = argmax(admissible_probes(cp, M, F_abs),
                       key=lambda q: voi_meta_pessimistic(q, M, inf) - cost(q))
            if voi_meta_pessimistic(p, M, inf) < theta_voi: break
            e = execute_probe(p)
            e = publish_evidence(e, ledger, G_ev)     # 预注册 + 全结果登记 + ESI
            M, fused, D = xmodal_fuse(M, cp.region, e)
            if e.verdict_falsifies_any():
                for old in e.falsified_ancestors:     # 事后证伪 ⇒ 撤稿传播
                    retract_and_propagate(old, 'falsified', G_ev, commitments, ledger)
            sigma = reselect_footholds(x0, cp, M); R = schedule_risk(sigma, M)
            budget.spend(p)
        g = select_gait(R); level = contact_level(cp)
        st = publishable_evidence_gate(tag_evidence_p(sigma, M, level),
                                       M, personas, ood_reg, G_ev, ledger, g_TR)
        if g != 'halt' and st[0] == 'ok':
            sched.append(commit(sigma, g)); log.append(st[1]); continue
        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, M)) != 'halt': route = alt; continue
        return negotiate_or_stop(cp, M, sigma, R, consent,
                                 tau_int=tau_int(personas.active.auth))
    return sched, log, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PRE | O(1) 追加 / O(log N) 校验 | O(#reg) | hash-chain 不可篡改、注册先于观测（A41） |
| ESI | O(#repl·d_ev) | O(#ev) | 独立性前置、同源复现封顶（A42） |
| RET | O(\|V\|+\|E\|) | O(\|V\|+\|E\|) | 闭包完备、单调不可复活（A43） |
| SAM | O(#dr·cost(𝒮)) 离线 | O(#scenarios) | 反例可行、仅 L0/L1（A44） |
| TRC | O(d_g)/查询 | O(#real_trials) | 覆盖 ≥1−α_TR、漏检 ≤δ_SR（A44） |
| PRE-Gate | O(\|σ\|·(#repl+log N)) | O(\|σ\|+J_q) | 无真实复现不 L2、撤稿即拒 |
| PCE++ | O(\|CP\|·k_p·(C_VOI+d_φ+|V|+|E|)) | O(\|V\|+\|σ\|+#reg) | 注册先于探询、撤稿即时传播、有限终止 |

**正确性定理（Publishable-Evidence Soundness, PES）**
假设 A22–A32（第 53–55 轮）、A33–A36（第 56 轮）、A37–A40（第 57 轮）成立；新增 **(A41)** 注册账本不可篡改且注册严格先于首次观测，注册规则在评估时保持不变；**(A42)** 复现独立性在观测前声明、登记覆盖率 κ≥κ_min，未登记探针不进入元训练；**(A43)** 证据依赖 DAG 完整记录引用，撤稿闭包计算精确、无孤儿承诺；**(A44)** 仿真证据仅用于 L0/L1，TRC 在留出真实试验上覆盖 ≥1−α_TR，sim-real 分歧漏检率 ≤δ_SR。则：

1. **证据强度健全性**：ESI 对同源复现单调且封顶（ι_rep≤ι_same_max<1），加"同源复现"不能把证据从预印本推入发表层；任何 ESI<ε_ESI(ℓ) 的证据不能支持等级 ℓ 的承诺。
2. **发表偏倚修正**：经逆倾向重加权后，元先验相对真实分布的过度自信残留上界为 (1−κ)·bias_max；κ→1 时残留→0。
3. **撤稿健全性**：任一 active 承诺的全部祖先非撤回；撤稿后仍被继续引用的陈旧承诺概率 ≤δ_ret（闭包漏检率）。
4. **仿真隔离**：`EV-sim` 对 L2 承诺的失败贡献恒为 0；仿真误差进入系统的唯一通道是 `γ_TR` 折减与 `Δ_SR` 加项，且 `Δ_SR` 随 TRC 覆盖失效而增大。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1])
             − P(𝓜 陈旧未检出) − P(护盾回退失败) − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
             − (1−κ)·bias_max − δ_ret − (α_TR + δ_SR)·1[sim ∈ 证据链]
```

关键：**发表制度给"可信"以流程、仿真给"未知"以预演、迁移校准给"仿真"以边界**。三者与安全的关系是单向的：发表只可能降级（未注册/无复现/被撤稿），仿真只可能否决或加宽（不产生通过），迁移校准只可能增大失败上界（不被吸收为负）。因此本轮不新增升险路径，只新增三个"降低自信/收紧动作"的通道。

`(v,a,m,q,ι,κ,g,λ,τ,σ,ρ,Explain,RUR_state,α_S,A_cert,γ_ce,δ_a, Σ/C+ 结构, 𝓜_core, J_m, probe_log, consent_state, w_h, q_φ/k*, D(r), ρ_ℳ, s_op/auth, m_E, ood_state, J_p, root(L_ev), ESI, registry_coverage κ, retraction_state, Δ_SR, Φ_r, J_q)`

其中新增：`root(L_ev)` 证据账本根哈希；`ESI` 证据强度指数；`registry_coverage κ` 登记覆盖率；`retraction_state` 撤稿闭包状态；`Δ_SR` 迁移失败率上界；`Φ_r` 仿真反例集；`J_q` 发表式证据证书。

云边协议 CEB++ → **CEB+++（Evidence Journal）**：云端维护**全机队共享的可发表证据账本**——每台机器人把探针结果（含阴性）作为"投稿"写入 append-only ledger，其他机器人在自己的通道/时间/本体上做**跨机独立复现**（不同本体天然是最便宜的独立性来源），复现成功方可"引用"；云端元模型只从被复现且未被撤稿的证据训练，元模型更新仍走第 57 轮的影子模式隔离区。任何一台机器人发现某条历史证据被证伪，就在账本上发起撤稿，闭包自动传播到整个机队的所有下游承诺——**把"坏证据长寿"从单机问题升级为可审计的机队级纠错**。

## 6. 本轮最大风险

**一句话**：本轮给证据套上了预注册、复现、登记、撤稿的全套"学术规范"，最大风险从"坏先验普遍"变为"**形式合规的证据政体**"——当仿真器与迁移校准器本身存在系统性偏差时，预注册的严格、复现的一致、登记的完整反而会给一个"审稿人同源"的错误结论背书；流程越像科学，越可能把"仿真里自洽"误当成"现实里可信"，因此必须把仿真证据硬隔离在不可逆接触之外、把 sim-to-real gap 作为显式上界项、并保留"宁可退回又宽又慢的真实探针"的最后否决权。
