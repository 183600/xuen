# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「用户体验」×「任务分解」）

> R69 给系统装上了眼睛和嘴：把不确定性拆成 aleatoric/epistemic，让 epistemic 通过「看/问/触」的主动交互消解，并用流似然做标定不可吸收的第二意见。但 R69 埋着两个从未被审视的默认假设——**任务是一整块**、**人是一个标量成本**。
>
> - **任务是一整块**：FMP 一次生成整段动作块 ξ_{t:t+H}，模态聚类也是在整段轨迹上做。可真实歧义几乎从不均匀铺满整段：它钉在某个**子目标节点**上（「拿哪个杯子」「先开门还是先取物」）。问「哪个杯子」和问「用哪只手」的下游代价差一个数量级，但 R69 的 VoI = H(M|o) − E[H] 对两者一视同仁，因为它根本不知道任务有结构。
> - **人是一个标量成本**：R69 的 c(g) 是手调常数，预算「≤1 次/单位时间」是粗暴代理。可打扰不是常数，而是**人的状态的函数**：注意力有限、问题要看得懂、反复盘问会磨掉信任、而一次解释清楚的迟疑反而**建立**信任——交互成本随情境甚至可以为负。R69 会为了 0.05 nat 的信息增益去打断一个正在专注操作的人。
>
> 本轮两个灵感正好拆掉这两个默认：
> - **任务分解**把「歧义」从整段轨迹挪到**任务图的节点**上，并给出「杠杆」：只有位于关键路径、下游不可逆、且不可重规划节点上的歧义，才值得现在打断人去查。
> - **用户体验**把「交互成本」从一个常数升级为**用户状态模型**（注意力 / 理解力 / 信任 / 认知负荷），并把交互按「打扰程度」排成阶梯：**先动手试探，再看，再问，最后让渡**——能以低打扰获得充分证据，就绝不升级到提问。
>
> 核心命题：**把 R69 的「扁平 VoI − 标量成本」升级为「任务图上的杠杆加权 VoI − 用户状态相关的 UX 成本」，并把交互建模为一条按打扰度排序、只在低阶证据不足时才升级的阶梯；同时用「动作消歧」提供一条不能被人类谎言污染的因果证据通道。** 命名 **LUCID-RAS**（Legible, User-Calibrated Interactive Disambiguation over a decomposed task graph）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**该在任务的哪一步、以多轻的方式去求证，才既不烦人、也不辜负信任**」——不确定性不只是刹车和提问，也可以是一次恰到好处的、可逆的试探。

## 0. 直觉与动机

**灵感 1（任务分解 → 歧义有位置，也有杠杆）**
直觉：一个人不会因为「今天穿什么、午饭吃什么、先迈哪只脚」同时犹豫；他只在真正卡住的**那一步**停下来。R69 把整段动作块一起聚类，等价于把「先迈左脚的不确定性」和「拿错杯子的不确定性」加成一个标量——前者可忽略、后者致命。引入分层任务图 G=(V,E)：目标→子目标→原语，每个节点 v 有自己的模式分布与不确定性。关键不是把 U 拆细，而是定义**下游杠杆** Λ_v = 关键路径权重 κ_v × 不可逆度 ρ_v × (1−可重规划度 r_v)：在可重规划节点上现在就查是浪费（以后还能改）；在不可逆节点上不查是赌博（错了无法回头）。**VoI 必须乘上 Λ_v，而不是用原始熵**。这把 R69 的「值不值得查」升级为「**在哪一步查、才配得上这次打扰**」。

**灵感 2（用户体验 → 打扰有价格，且价格是人的状态）**
直觉：同一个问题，问在人对的时间是帮助，问在错的时间是骚扰。UX 不是界面装饰，它是把「信息需求」翻译成「人的成本」的那层度量：注意力预算 a（正在开车/正专注时极低）、理解力 e（问题超出用户知识就是负担）、信任 τ（被反复盘问会流失；被正确自动解决会积累）、认知负荷 l（问题要求人做多少心智工作）。于是 c_ux(g,u) = α·annoy + β·load + γ·trust_erosion − δ·legibility_gain。**注意负号**：一个解释得清楚、恰好省去人担忧的交互，净成本为负——它同时在买信息和买信任。R69 永远无法表达「这次问是赚的」，因为它把成本当成非负常数。

**灵感 3（交互阶梯 → 先动手，再动眼，最后动嘴）**
直觉：很多歧义根本不必问人。杯子重不重，轻轻提一下就知道了；门锁没锁，推一下比问「锁了吗」更可靠；物体是否易碎，先低力接触听声音。这些**可逆试探**（act-to-disambiguate）在 UX 上比提问便宜得多（只花机器人自己的时间和能量，不占人的注意力），在证据上却更强：它是**干预性（do-算子）因果证据**，不是人的相关汇报——**机器人亲手试出来的结果，人撒谎也改不了**。这直接击中 R69 最痛处：R69 的引理 18 说单源人类回答在欺骗率 δ_p 下错误率 ≥ δ_p；而动作试探的误判只取决于传感器和可逆性认证，与 δ_p 无关。所以 LADDER 阶梯：L0 动作试探 > L1 观察/注视 > L2 提问 > L3 停让/重规划，**只在更低打扰阶证据不足时才升级**。好 UX 与抗投毒在这里第一次指向同一个方向。

**灵感 4（信任是状态 → 要校准，而不是最大化）**
直觉：UX 的长时程目标是**校准的信任**，不是「让人喜欢」。信任过高（over-trust）和过低（distrust）都是危险：过高时人会放过本该质疑的自主决策，系统也不该利用这种盲信；过低时人频繁接管，效率崩溃。所以把 τ 作为状态变量，用交互结果（被接受/被拒绝/惊讶程度/解释是否可信）更新；交互预算**内生化**为 τ 的函数（信任低时更保守、更可解释、更少自作主张），并把「惊讶度」KL(p_human(M|h) ‖ p_robot(M|h)) 压到阈值以下——系统不能在人以为它不懂的时候装作懂。这给 R69 的「问错比不问更危险」补上了一个可度量的安全阀。

**灵感 5（分解本身会错 → 需要层级一致性与回退）**
直觉：任务分解是模型，不是真理。分解错了，系统会**极其高效地追问一个错误节点**：把「拿错杯子」的歧义错误地归到「用哪只手」，然后设计一个完美的低打扰试探——诚实地得到一个无关答案。这比不分解更糟，因为它把不确定性**局域化到了错误的地方**。因此必须交付：分解置信度、层级一致性（子节点模式不得与父节点矛盾）、以及「分解置信度低于阈值就退回粗粒度提问」的保守回退。否则 LUCID 只是给 FLUID 装了一个更精致、更能自圆其说的错题本。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（LUCID-RAS 总览）** LUCID-RAS = (HTG, ALE, JIT-VoI, UMX, LADDER, ASD, LEG, TTC, RAS-WM††)。五不变式：
(i) 实时流零学习写操作（继承定义 276-i）；
(ii) **交互预算硬约束**（继承定义 293-ii），但预算上限由信任状态 τ 内生给定：g_max = g_max(τ)；
(iii) **证据纪律**（继承定义 293-iii）；
(iv) **UX 非负盈余**：任何交互的预测 UX 盈余 Δux = δ·legibility_gain − α·annoy − β·load − γ·trust_erosion 必须 ≥ 0，且不得越过认知负荷上限 l_max；
(v) **层级一致性**：子节点模式的后验必须与父节点模式的边缘化一致；违反即判定分解可疑并回退（定义 319、定理 20）。

**定义 311（分层任务图 HTG）** G = (V, E)，节点 v = (subgoal, pre, post, ρ_v, κ_v, r_v, d_v)，其中 ρ_v ∈ [0,1] 可逆度、κ_v ∈ [0,1] 关键路径权重、r_v ∈ [0,1] 可重规划度、d_v 分解深度。边编码时序/因果前置。分解算子 Δ: goal ↦ subgoals，带置信度 conf(Δ) ∈ [0,1]。一个任务实例是 G 上的一个可行部分序执行计划。

**定义 312（多尺度不确定性局域化 ALE）** 只对**活跃前沿** F ⊆ V（当前可执行且未定案）的节点采样 K_v 个动作块（条件于父节点模式），得 (U_ale^v, U_epi^v, modes_v, Δ_min^v)。定义**下游杠杆** Λ_v = κ_v · ρ_v · (1 − r_v) · d_v^{−1/2}（深度折扣：越原语、越局部，全局影响越小）。全局可约不确定性不再简单求和，而是杠杆加权：U_epi^G = Σ_{v∈F} Λ_v · U_epi^v。

**定义 313（即时杠杆加权 VoI，JIT-VoI）** 对节点 v 与信息动作 g：VoI_jit(g,v) = Λ_v · [H(M_v|o) − E_{y~p(·|g,o)} H(M_v|o,y)] − c_ux(g,u)。联合选择 (v*, g*) = argmax_{v∈F, g∈LADDER} VoI_jit，s.t. 安全、预算、UX 非负盈余。**R69 是 |V|=1、Λ=1、c_ux=常数 的特例**（定义 324）。

**定义 314（用户模型 UMX）** u_t = (a_att, e_exp, τ, l)，分别为注意力预算、专长、信任、当前认知负荷。交互成本 c_ux(g,u) = α·annoy(g,a_att) + β·load(g,e_exp,l) + γ·trust_erosion(g,τ) − δ·legibility_gain(g)。各分量单调：a_att↓ ⇒ annoy↑；|g − 用户知识水位|↑ ⇒ load↑；连续交互数↑ ⇒ trust_erosion↑。u_t 由在线观测（响应延迟、拒绝、追问、接管）+ 离线先验联合估计，冻结更新，不在实时环内训练。

**定义 315（交互阶梯 LADDER）** 证据动作按打扰度升序：L0 = ASD（可逆物理试探）、L1 = OBS（注视/移动视角/重感知）、L2 = ASK（语言提问）、L3 = YIELD（减速/停让/交还人类）。策略取**最低可行阶**：rung* = min{ r : VoI_jit(g_r, v) > 0 ∧ safe(g_r) ∧ UX 盈余 ≥ 0 }。若所有阶都不满足，则不做信息动作，走 R68 兜底。阶梯是字典序的：**先最小化打扰，再最大化信息**。

**定义 316（动作消歧 ASD）** 选可逆子目标 a†_v = argmax_{a ∈ 𝒜_rev(v)} IG(M_v; y(a))，s.t. ρ_v ≥ ρ_min、c_ux(a) ≤ c_act、y(a) = Φ(s') 可观测、且 a 过 C-RAS-WM 认证。若不存在充分可逆子目标（IG 低于阈值），L0 不可用，升阶。ASD 产生**干预性证据** y = Φ(do(a†))，其与 M_v 的互信息不经过人类话语通道。

**定义 317（可理解性生成 LEG）** 执行任何 L≥1 交互前/时，生成解释 x = Explain(g, M_v, why)，使人类对机器人意图的预测后验与机器人真实后验的 KL 最小化：min_x KL(p_h(M|h,x) ‖ p_r(M|h))。**解释不是装饰，是交互合法性的前提**：无解释的交互按定义 314 计更高 annoy 与 trust_erosion；解释保真度低于阈值则视为 UX 盈余为负。

**定义 318（信任校准控制器 TTC）** 信任状态更新 τ_{t+1} = f(τ_t, surprise, accepted/rejected, legibility)。维持 τ ∈ [τ_min, τ_max]：τ < τ_min 时收紧自主交互、优先 L1/L3 与强解释；τ > τ_max（过度信任）时**主动注入校准性怀疑**（显式表达残余不确定性、拒绝伪装确定），禁止利用盲信。目标是 |τ − reliability| ≤ ε_trust，而非最大化 τ。惊讶度 surprise = KL(p_h(M|h) ‖ p_r(M|h)) 需 ≤ ε_leg。

**定义 319（分解置信与层级一致性回退）** 设分解置信度 conf(Δ)。若 conf(Δ) < τ_dec，或子节点后验边缘化与父节点后验 KL > ε_hier，则判定分解可疑：**禁止用细粒度节点驱动交互**，退回按父/根节点的粗粒度提问（退化到 R69 的单节点 VoI）。这保证「宁可问得粗，不可精确地问错」。

**定义 320（可逆性与安全认证）** 每个 ASD 候选的 ρ_v 需经 C-RAS-WM 前缀可行性 + 力/位包络 + 时间窗联合认证；**若 ρ_v 估计不确定，一律按不可逆处理**（保守，定义 316 的 ρ_min 门）。信息动作（含 L0）整体过 C-RAS-WM，不得提前越出安全包络。

**定义 321（参与式审计 VQAuditor-X）** 审计对象新增：分解是否正确、交互是否落在正确节点、打扰次数/任务、问题可回答性、解释保真度、信任漂移、是否过度/不足提问、ASD 是否真的可逆。结论回灌 AuditBuf，成为下一轮 UMX 先验与 JIT-VoI 成本校准。

**定义 322（干扰集 ℰ_LUCID）** ℰ_LUCID = ℰ_FLUID × ℰ_decomp × ℰ_ux × ℰ_rev：ℰ_decomp（错误分解、对抗性子目标诱导「精确地问错」）、ℰ_ux（暗黑模式诱导过度提问 / 操纵信任 / 用解释做社交工程）、ℰ_rev（可逆性误判，在伪可逆下执行不可逆动作）。

**定义 323（证书 J_LUCID）** J_LUCID = (J_FLUID, decomposition_confidence, node_leverage_map_hash, ux_surplus, trust_drift, interruption_rate, asd_reversibility_rate, legibility_score, ladder_rung_hist, lucid_ver)。Valid ⇔ Valid(J_FLUID) ∧ conf(Δ) ≥ τ_dec ∧ UX 盈余非负 ∧ 信任在界内 ∧ 层级一致。

**定义 324（严格退化到 FLUID）** 当任务图为单节点（|V|=F={root}，Λ=1）、用户模型常数（c_ux ≡ c）、关闭 L0/L1（只留 ASK）时，LUCID 的 JIT-VoI 逐项化为 R69 的 VoI−c，主循环逐指令一致。故 FLUID 是 LUCID 在「扁平任务 + 常数用户 + 无动作试探」边界上的退化。

**定义 325（自适应分解深度与预算）** 分解深度 d 由「期望杠杆增益 − 建模成本」决定，且分解在任务开始/检测到异常时执行、缓存复用；实时环内只维护活跃前沿的廉价 mode_head，不重复分解，保 P99 实时预算。

## 2. 关键算法骨架

```python
# IP-264/265 HTG + ALE：分层任务图与多尺度不确定性局域化（离线分解、在线只查前沿）
class TaskGraph:
    def front(self, state):                     # 活跃前沿：可执行、未定案
        return [v for v in self.V if v.ready(state) and not v.settled]
    def leverage(self, v):                      # 下游杠杆 Λ_v（定义 312）
        return v.kappa * v.rho * (1.0 - v.replan) / math.sqrt(v.depth)

def localize_ambiguity(G, fmp, state, UMX, budget):
    out = {}
    for v in G.front(state):
        K = 1 if fmp.mode_head(v.z) < TAU_MODE else 4      # 继承 R69 自适应 K
        s = fmp.sample(v.o, K)
        Ua, Ue, modes, _ = decompose(s, v.z, fmp.mode_head)
        out[v] = (Ua, Ue, modes, G.leverage(v))
    return out                                   # {v: (U_ale^v, U_epi^v, modes_v, Λ_v)}

# IP-266 JIT-VoI：在「节点 × 阶梯」上联合选，先打扰小、后信息大
def jit_voi(amb, u, budget):
    best = None
    for v, (Ua, Ue, modes, lam) in amb.items():
        for rung in [L0_ASD, L1_OBS, L2_ASK]:    # L3 是兜底，不在搜索内
            for g in ladder_candidates(rung, modes, v):
                if not budget.allow(g) or not c_ras_wm.certify(g, v.o): continue
                ux = ux_surplus(g, u)            # 可为负；必须 >= 0
                if ux < 0: continue
                voi = lam * (entropy(modes) - expected_entropy(modes, g))
                score = voi - u.cost(g)          # c_ux（定义 314）
                if best is None or score > best.score: best = (v, g, rung, score)
        if best and best.score > 0: break         # 抓到根节点即停？否：见层级回退
    return best if best and best.score > 0 else None

# IP-269 ASD：可逆子目标试探（干预性、抗谎言的证据）
def act_to_disambiguate(v, modes, o):
    cand = [a for a in reversible_actions(v) if v.rho >= RHO_MIN]
    if not cand: return None
    a = max(cand, key=lambda a: mutual_info(mode_id, predict_obs(a, o))
                             - u.cost(a))
    return a if c_ras_wm.certify(a, o) else None  # 不确定性→按不可逆处理

# IP-270/271 LEG + TTC：解释与信任校准
def legible_ask(g, modes, v, u):
    x = explain_min_kl(g, modes, v, u)            # 定义 317
    return (g, x) if legibility_score(x) >= TAU_LEG else None

def update_trust(u, outcome, surprise, x):
    u.tau = clip(f(u.tau, surprise, outcome, legibility_score(x)), TAU_MIN, TAU_MAX)
    return u

# IP-274 主闭环（继承 R69，插入「局域化→阶梯→信任」）
def LUCID_RAS_round(M, state):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)   # R68 标定
    if not M.htg.cached or M.fma.anomalous():                     # 异常才重分解
        M.htg = M.decompose(state, conf_required=TAU_DEC)
    if not M.htg.confident():                                     # 分解可疑→粗粒度
        return M.fluid.round(state)                               # 退化 R69（定义 319）
    amb  = localize_ambiguity(M.htg, M.fmp, state, M.umx, M.budget)
    best = jit_voi(amb, M.umx, M.budget)                          # 定义 313/315
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o, M.o_cal)  # R69 第二意见
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    chosen = None
    if best and not slow:
        v, g, rung, _ = best
        if rung == L0:   chosen = ("asd", M.asd.execute(v, amb[v][2], o))
        elif rung == L1: chosen = ("obs", M.cia.execute(g))
        elif rung == L2: chosen = ("ask", M.leg.ask(g, amb[v][2], v, M.umx))
        if chosen is None:                                        # 该阶失败→回退 R69
            chosen = None
    # 证据并入后验（仍守 k 正交一致纪律，定义 293-iii / 承 R69 引理 18）
    if chosen is not None:
        M.cia.update_belief(amb, chosen, discipline='k_orthogonal_agree')
    # 风险缩放：只对 aleatoric + 未消解 epistemic 收紧（承 R69 定义 307）
    U_floor = sum(av[0] + (av[1] if chosen is None else 0.0)
                  for av in amb.values())
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(M.vista.H), ..., wm_preds)
    if slow: lam = max(lam, 0.8)                                  # 回 R68 最保守
    mode = select_mode(amb, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.umx = update_trust(M.umx, outcome=chosen, surprise=chosen_surprise, x=chosen)
    M.vqa_x.submit_async(chosen, M.htg.conf, amb, a_hat, M.umx.tau)
    return k, lam, mode, (U_floor, M.umx.tau)
```

## 3. 推导

**引理 19（杠杆加权的优先消歧）** 设节点不确定性对总期望损失的贡献近似可加且熵收益边际递减（子模），则先消解 Λ_v 最大的节点不劣于任意其它顺序：ΔL_total(v first) ≤ ΔL_total(w first) 当 Λ_v ≥ Λ_w。系：**不是熵最大的节点最该问，而是杠杆最高的节点最该问**——一个高熵但可重规划、非关键的节点，问了也是浪费；一个低熵但不可逆的关键节点，值得一次打扰。这是 R69 引理 16 从「单节点可分性」到「多节点分配」的推广。

**引理 20（ASD 的投毒免疫）** 动作试探证据 y = Φ(do(a†)) 与模态身份 M_v 的互信息只经物理通道，不经人类话语；在 ℰ_poison 下其错误率 ≤ ε_obs + ε_rev（传感器误差 + 可逆性误判），与欺骗率 δ_p **无关**。对照 R69 引理 18：单源「问」的错误率 ≥ δ_p。系：**只要存在充分可逆的试探子目标，阶梯把 ASK 降到 L2 就严格降低最坏情形投毒风险**——抗投毒第一次与「少打扰」同向。

**引理 21（阶梯最优性与 UX 单调）** 在成本排序 c_ux(L0) ≤ c_ux(L1) ≤ c_ux(L2) ≤ c_ux(L3) 与证据充分性阈值 θ 下，取最低可行阶的期望 UX 成本不高于任何固定高阶策略；且打断次数对 annoy 单调，故保持中断率 ≤ g(a_att) 使信任流失上界可证。系：LADDER 是「最小打扰满足充分证据」的贪心最优。

**定理 18（LUCID 严格包含 FLUID）** 在 A99（分解在阈值内稳定）、A100（用户模型分量有界 Lipschitz）、A101（可逆性认证保守）下，LUCID 的期望任务风险 ≤ FLUID；当任务图扁平、u 常数、且不存在比 ASK 更便宜的可逆试探时，两者**逐指令相同**（定义 324）。阶梯从不提高安全包络，只在信息与 UX 上做 Pareto 改进。**安全侧不让步，体验侧不倒退**。

**定理 19（信任校准安全）** 在 LEG 保真度 ≥ τ_leg 且 TTC 维持 τ ∈ [τ_min, τ_max] 时，人类对机器人意图的惊讶度 KL ≤ ε_leg，过度信任注入被显式怀疑压制；因此不存在「系统确信、人类误解」的交互，R69 的「问错比不问更危险」被一个有界惊讶度条件取代。系：**解释保真度是安全属性，不是体验属性**。

**定理 20（分解错误的伤害上界与回退）** 若 conf(Δ) < τ_dec 或层级一致性被破坏，回退到根节点的粗粒度提问（等价 R69 单节点），则 LUCID 的交互错误率 ≤ FLUID + P(分解错误)·0；即**可疑分解不进入细粒度交互**。反之若不回退，错误可达「精确地追问无关节点」，其期望损失正比于被错置节点与真实节点的杠杆差——这正是必须回退的原因。

## 6. 本轮最大风险

**一句话**：LUCID 的全部收益押在「任务图分对了、可逆性估准了、用户模型没自欺」三件事同时成立上——**一旦分解把歧义局域到错误节点，系统会以最不打扰、最可解释、最自信的方式去追问一个无关的答案；再叠上对可逆性的乐观估计（其实不可逆）和对信任的高估（其实已在流失），它就会用一套优雅的 UX 把「精确地问错、伪装成体贴地省去提问」包装成正确的样子**——这比 R69 的「问错」更隐蔽，因为它连"问"这个可被审计的动作都省掉了。

**次级风险与缓解**：
1. **分解错误/对抗性分解** → conf(Δ) 门 + 层级一致性 + 退回粗粒度（定义 319、定理 20、E308）；
2. **可逆性误判导致不可逆试探** → ρ 不确定一律按不可逆、C-RAS-WM 认证（定义 316/320、E314）；
3. **UX 成本模型偏差**（把骚扰当帮助或反之）→ 在线 u 估计 + VQAuditor-X 回灌 + E305/E315 用户研究；
4. **信任被操纵/暗黑模式** → τ 上界钳制 + 主动校准怀疑 + ℰ_ux（定义 318/322）；
5. **实时预算被局域化+阶梯枚举击穿** → 分解缓存 + 仅前沿 + 廉价 mode_head 门控（定义 325、E312）。

## 3. 关键算法伪代码

```python
# IP-264/265 HTG + ALE：离线分层分解、在线只查活跃前沿
def localize_ambiguity(G, fmp, state):
    amb = {}
    for v in G.front(state):                          # 可执行、未定案
        K = 1 if fmp.mode_head(v.z) < TAU_MODE else 4
        Ua, Ue, modes, _ = decompose(fmp.sample(v.o, K), v.z, fmp.mode_head)
        amb[v] = (Ua, Ue, modes, G.leverage(v))       # Λ_v
    return amb

# IP-266 JIT-VoI：节点×阶梯联合选，最小打扰优先
def jit_voi(amb, u, budget):
    best = None
    for v, (Ua, Ue, modes, lam) in amb.items():
        for rung in (L0_ASD, L1_OBS, L2_ASK):
            for g in ladder_candidates(rung, modes, v):
                if not budget.allow(g) or not c_ras_wm.certify(g, v.o): continue
                if ux_surplus(g, u) < 0: continue      # UX 非负盈余
                score = lam*(entropy(modes) - expected_entropy(modes, g)) - u.cost(g)
                if best is None or score > best.score: best = (v, g, rung, score)
    return best if best and best.score > 0 else None

# IP-269 ASD：可逆试探，产生抗谎言的干预性证据
def act_to_disambiguate(v, modes, o):
    cand = [a for a in reversible_actions(v) if v.rho >= RHO_MIN]
    if not cand: return None
    a = max(cand, key=lambda a: mutual_info(mode_id, predict_obs(a, o)) - u.cost(a))
    return a if c_ras_wm.certify(a, o) else None     # 不确定→按不可逆

# IP-270/271 LEG + TTC
def legible_ask(g, modes, v, u):
    x = explain_min_kl(g, modes, v, u)
    return (g, x) if legibility_score(x) >= TAU_LEG else None

def update_trust(u, outcome, surprise, x):
    u.tau = clip(f(u.tau, surprise, outcome, legibility_score(x)), TAU_MIN, TAU_MAX)

# IP-275 主闭环（继承 R69）
def LUCID_RAS_round(M, state):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    if not M.htg.cached or M.fma.anomalous():
        M.htg = M.decompose(state, conf_required=TAU_DEC)
    if not M.htg.confident():
        return M.fluid.round(state)                      # 分解可疑→退化 R69
    amb  = localize_ambiguity(M.htg, M.fmp, state)
    best = jit_voi(amb, M.umx, M.budget)
    slow = (M.fma.flow_anomaly(M.fmp, M.last_action, o, M.o_cal) > TAU_FMA) \
           and (M.last_r_res < TAU_RES)
    chosen = None
    if best and not slow:
        v, g, rung, _ = best
        chosen = {"L0": lambda: M.asd.execute(v, amb[v][2], o),
                  "L1": lambda: M.cia.execute(g),
                  "L2": lambda: M.leg.ask(g, amb[v][2], v, M.umx)}[rung]()
    if chosen is not None:
        M.cia.update_belief(amb, chosen, discipline='k_orthogonal_agree')
    U_floor = sum(Ua + (Ue if chosen is None else 0.0) for Ua, Ue, *_ in amb.values())
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(M.vista.H), ..., wm_preds)
    if slow: lam = max(lam, 0.8)                         # 回 R68 最保守
    mode = select_mode(amb, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    update_trust(M.umx, rung, chosen_surprise, chosen)
    M.vqa_x.submit_async(chosen, M.htg.conf, amb, M.umx.tau)
    return k, lam, mode, (U_floor, M.umx.tau)
```

## 4. 推导

**引理 19（杠杆加权优先消歧）** 节点对总损失的贡献近似可加、熵收益子模时，先消解 `Λ_v` 最大的节点不劣于任意顺序：`Λ_v≥Λ_w ⇒ ΔL(v first)≤ΔL(w first)`。系：**最该问的不是熵最大的节点，而是杠杆最高的节点**——高熵但可重规划者问了浪费，低熵但不可逆者值得一次打扰。R69 引理 16 从单节点可分性推广到多节点预算分配。

**引理 20（ASD 投毒免疫）** `y=Φ(do(a†))` 与 M_v 的互信息只经物理通道；ℰ_poison 下错误率 ≤ `ε_obs+ε_rev`，与欺骗率 δ_p 无关（对照 R69 引理 18 单源「问」错误率 ≥ δ_p）。系：存在充分可逆试探时，阶梯把 ASK 降到 L2 严格降低最坏投毒风险——抗投毒与少打扰同向。

**引理 21（阶梯最优与 UX 单调）** 在 `c_ux(L0)≤c_ux(L1)≤c_ux(L2)≤c_ux(L3)` 与充分性阈值下，最低可行阶的期望 UX 成本 ≤ 任意固定高阶；中断率对 annoy 单调，故 `中断率≤g(a_att)` 给出信任流失上界。系：LADDER 是「最小打扰满足充分证据」的贪心最优。

**定理 18（LUCID 严格包含 FLUID）** A99（分解阈值内稳定）、A100（用户模型有界 Lipschitz）、A101（可逆性保守）下，LUCID 期望任务风险 ≤ FLUID；任务图扁平 + u 常数 + 无更便宜可逆试探时逐指令相同（定义 324）。阶梯不抬安全包络，仅做信息/UX 的 Pareto 改进。

**定理 19（信任校准安全）** LEG 保真度 ≥ τ_leg 且 τ∈[τ_min,τ_max] 时，人类意图惊讶度 KL ≤ ε_leg，过度信任被显式怀疑压制 ⇒ 不存在「系统确信、人类误解」的交互，R69 的「问错比不问更危险」被有界惊讶度条件取代。系：**解释保真度是安全属性**。

**定理 20（分解错误伤害上界与回退）** conf(Δ)<τ_dec 或层级一致性破坏时退回根节点粗粒度提问（=R69 单节点），则交互错误率 ≤ FLUID + P(错分解)·0；可疑分解不进入细粒度交互。不回退时错误可达「精确追问无关节点」，期望损失正比于错置节点与真实节点的杠杆差——此即必须回退的理由。

## 7. 本轮最大风险

**一句话**：LUCID 的全部收益押在「任务图分对了、可逆性估准了、用户模型没自欺」三件事同时成立上——**一旦分解把歧义局域到错误节点，系统会以最不打扰、最可解释、最自信的方式追问一个无关答案；再叠上对可逆性的乐观估计（其实不可逆）与对信任的高估（其实在流失），它就用一套优雅的 UX 把「精确地问错、伪装成体贴地省去提问」包装成正确的样子**——这比 R69 的「问错」更隐蔽，因为它连"问"这个可被审计的动作都省掉了。

**次级风险与缓解**：分解错误/对抗性分解（conf 门 + 层级一致性 + 回退，定义 319、定理 20、E308）；可逆性误判（ρ 不确定按不可逆 + C-RAS-WM 认证，定义 316/320、E314）；UX 成本偏差（在线 u 估计 + VQAuditor-X 回灌 + E305/E315）；信任操纵/暗黑模式（τ 上界钳制 + 主动校准怀疑 + ℰ_ux，定义 318/322）；实时预算被局域化+阶梯枚举击穿（分解缓存 + 仅前沿 + 廉价 mode_head，定义 325、E312）。
