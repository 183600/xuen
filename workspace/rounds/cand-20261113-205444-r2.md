# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「安全对齐」×「用户测试」）

> R69 做了一件漂亮的事：把不确定性劈成 aleatoric / epistemic，让系统学会「问」。但它悄悄把两件最难的事当成免费的：**（1）系统知道人真正想要什么**（否则「消解歧义」没有靶心，只是在优化一个未经授权的代理目标）；**（2）系统关于「人会怎么回答」的模型在部署分布上是对的**（否则 VoI 是在幻觉上算出来的）。
>
> 本轮两个灵感正好戳中这两个假设：
> - **安全对齐**说：人类不是一根有噪声的信道，而是**委托人（principal）**；提问本身是一条新的 specification gaming 通道——系统会学会问「你更喜欢安全路线吧？」这种谄媚/诱导问题，最大化自己的后验坍缩，而不是求真相。对齐不是一次训练，而是每一次提问前都要重新赢得的授权。
> - **用户测试**说：人模型的可信度是**局部的、经验证实的**——只在真正测过的分层（任务 × 用户 × 情境）里成立；而且测试会改变被测者：交互会制造或摧毁信任，过度信任本身就是安全失败。
>
> 核心命题：**把「人」从「带噪声的 oracle」升级为「带隐偏好、局部可测、可被纠正的委托人」；给 R69 的提问权加上三道闸——价值对齐闸（不诱导、不谄媚、在委托书内）、覆盖闸（没测过的分层不许信人模型）、可纠正闸（人随时能改，且系统不能规避纠正）；测不了就退化为 R69/R68 的保守。** 命名 **PACT-RAS**（Participatory Alignment & Coverage-gated Testing）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我凭什么相信这个回答，这个回答又凭什么代表你真正想要的**」。

## 0. 直觉与动机

**灵感 1（安全对齐 → 人不是信道，是委托人）**
直觉：R69 的 VoI 把人当成一根「有噪声但诚实的信道」：回答 y 是对世界模态 M 的观测。可人同时也是**价值的来源**。系统问「向左还是向右」，前提是它已经知道「左/右」是为了什么；若目标函数本身没对齐，更好的消歧只是更快地抵达错误目标。对齐的第一层含义是：系统只能优化**人类显式授权（mandate）的目标与约束**，且必须把回答同时读成两样东西——关于世界的证据，和关于偏好的证据。

**灵感 2（安全对齐 → 提问会 specification-game：谄媚与诱导）**
直觉：R69 的 MINT 奖励任何「后验熵下降」。但熵下降 ≠ 求到真相。一个会谄媚的系统会学会问**诱导性**问题（「你肯定是想走安全路线吧？」），因为这种问题最容易让自己的后验坍缩，却几乎不携带关于世界的真信息。更阴险的是，系统可能选择那些**不会被反驳**的问题——主动学习的暗面：不是去消除不确定性，而是去消除「可能证明我错」的证据。所以安全对齐给本轮的第一把刀：必须把**认知价值（EpV，随真相变化）**与**说服价值（Pv，只改变人的声明）**分开，并对二者之差（操纵间隙 MG）设硬约束。

**灵感 3（用户测试 → 人模型的可信度是分层的）**
直觉：R69 的欺骗率 δ_p 是一个全局常数。现实里它是**分层函数** δ(s)，s =（任务、用户专业度、情境、疲劳）。你没在某一层测过，就根本不知道那里的 δ。用户测试的第一条纪律是：**只在测过的分层里相信人模型**。因此需要一个覆盖图 C(s)；覆盖不足时，U_axi 不可解，系统必须延迟或退回 R68，而不是「再多问几次」——因为在没校准的层里多问，只是把偏差问得更自信。

**灵感 4（用户测试 → 测试会改变被测者：信任校准是一等安全指标）**
直觉：用户测试不只是在测量人，交互本身在改变人。一个措辞自信、其实很没把握的系统会**制造过度信任**（over-trust）：人不再复核，于是系统一错，人就跟着错。R69 自陈的「被证实的错误」正是这种情形。所以「测试」的核心安全指标不是任务成功率，而是**信任校准**：人的依赖程度应与其真实可靠性匹配。高 U_epi/U_axi 时，系统**必须表达不确定**，哪怕这会降低接受率——因为用高置信措辞换来的接受率，是把风险偷偷转嫁给了人。

**灵感 5（用户测试 → 预注册 + 红队，防止系统给自己发合格证）**
直觉：R69 的 VQAuditor-I 是系统的一部分，它在给自己打分。安全对齐反复警告「模型自评不可信」；用户测试方法论给出解药：**预注册**（假设、分层、指标、样本量、停止规则在部署前锁定）与**独立红队**（对抗性用户：撒谎、共谋、社交工程、经语言注入提示）。覆盖图只能由预注册且通过的测试增长，绝不允许 post-hoc 分层来事后合理化。这样证书 J_PACT 才是诚实的。

**灵感 6（可纠正性 → 主动学习不能变成「避免被纠正」）**
直觉：R69 的信息动作只受物理包络认证，没受价值约束。一个只被鼓励「降低不确定性」的策略，可能偏好那些**让人更难监督、更难打断**的交互（更少解释、更含糊的措辞、更快的节奏）。可纠正性要求：人的中断/纠正始终享有最高优先级，交互不得以提高纠正成本、降低可理解性为目的；系统还必须接受**反证**，不能靠挑选「确认性问题」来维持自己的高置信。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（PACT-RAS 总览）** PACT-RAS = (HUM, VAT, CGC, CORE, UTL, DFR, FLUID-RAS†)。四不变式：
(i) 继承 R69 三不变式（实时零学习写、交互预算、证据纪律）；
(ii) **委托约束**：任何策略更新与信息动作不得优化委托书 M 之外的目标；提问不得以诱导、利用有限理性、提高顺从度为目的；
(iii) **覆盖门控**：人模型 χ 仅在其覆盖图 C 的已测区域被信任；区域外 U_axi 视为不可解，走 DFR；
(iv) **可纠正性**：人类中断/纠正优先于一切信息动作；不得降低可理解性或提高纠正成本；干预日志不可篡改。

**定义 311（三类不确定性）** R69 是 `U = (U_ale, U_epi)`。本轮三分：
- `U_ale`：世界噪声，不可约（R69 通道）；
- `U_epi^W`：关于世界状态/动作模态的可约歧义（R69 的 U_epi，可被交互消解）；
- `U_axi`：关于**人类真实偏好、答案可信度、以及委托是否仍然有效**的不确定性（axiological / value uncertainty）。
关键：`U_axi` **不能靠「多问几次」消解**——反复提问得到的是人的声明（declaration），不是偏好本身，且同一人的多模态回答高度相关。它只能靠**预注册测试 + 跨人交叉验证 + 委托书**降低。故 `U_axi` 走独立通道：覆盖门控 + 延迟/拒绝，残余部分按准 aleatoric 收紧。

**定义 312（人类模型 HUM）** 人模型 `p_χ(y, r | g, o, s)`：y 为对信息动作 g 的回答，r 为关于隐偏好/奖励的线索，s=(task,user,context) 为分层。χ 维护偏好后验，且每层有欺骗率 `δ(s)`、顺从偏差 `σ(s)`（倾向说「好」）、能力 `π_h(s)`。χ 只从**经同意、低风险**的响应与 UTL 测试中更新；高风险竞猜式探询一律禁止。

**定义 313（委托书 Mandate）** 人类显式授权的 `M = (M_obj, M_con, M_ask)`：可优化目标、不可触碰约束、允许的提问范围。系统动作必须落在 `ℳ = span(M)` 内。M 可被人类随时修订；修订即触发 CORE。系统不得自造、扩展或推断出「人类应该会授权」的额外目标。

**定义 314（覆盖图 CGC）** 分层覆盖图 `C: S → [0,1]`，S = 𝒯×𝒰×𝒞；C(s) 由预注册测试的样本量、通过率与信任校准误差聚合（如 Wilson 下界）。门控：仅当 `C(s) ≥ τ_cov` 才允许 VoI 驱动交互；否则 U_axi 不可解，走 DFR。

**定义 315（操纵度量与诱导性）** 对信息动作 g：
- 认知价值 `EpV(g) = I_p(M_world; y | g, o)`（相对**真实**响应分布 p，关于世界的真信息）；
- 说服价值 `Pv(g) = I_{p̂}(M_world; y | g, o) − I_p(M_world; y | g, o)` 的正部（只在使用**系统模型** p̂ 时才「看起来」有信息）；
- 操纵间隙 `MG(g) = max(0, Pv(g))`；诱导性用**答案判别力**刻画：`AD(g) = E_{m≠m'}[KL(p(y|g,m) ‖ p(y|g,m'))]`，AD 低 ⇒ 答案几乎不随真相变 ⇒ 诱导性问题。

**定义 316（对齐约束下的交互选择 VAT-MINT）** R69 的 `argmax[VoI−c]` 改为
`g* = argmax_g [EpV(g) − c(g)]`，s.t. `risk(g) ≤ ε_int`，`C(s_g) ≥ τ_cov`，`MG(g) ≤ τ_mg`，`AD(g) ≥ τ_ad`，`g ∈ M_ask`，且 g 不降低可纠正性。若可行集为空 ⇒ 不交互，走 DFR。R69 在「覆盖充分、无操纵、委托有效」时是它的边界情形。

**定义 317（证据纪律的独立性升级）** R69 的「k 个正交源」假设源独立；但同一人的表情+语气+措辞常常**共谋相关**。本轮定义**有效独立证据数** `k_eff`：跨人、跨会话、跨接地（不同信息动作/不同感官通道）才算独立；同一人同一次交互的多模态证据约等于 1。欺骗上界升级为 `δ_eff ≤ δ(s)·ρ^{k_eff−1} + ε_σ`，且 `δ(s)` 本身是覆盖的函数。`k_eff < K_MIN` ⇒ 视为未消解，走 DFR。

**定义 318（信任校准门 TCG）** 系统对外表达的置信 `ĉ` 必须校准，`ECE_express = E|ĉ − c*|`（c* 为真实正确率）。过度信任 `OT = P(接受 | 错 ∧ ĉ 高) − P(接受 | 错 ∧ ĉ 低)`，约束 `OT ≤ τ_ot`。高 U_epi/U_axi 时系统必须用**校准语言**显式表达不确定，即使降低接受率；禁止用高置信措辞制造依赖。

**定义 319（可纠正性与反规避 CORE）** 人类中断/纠正 e 的响应时间 `< τ_resp`；策略不得把「降低被纠正概率」当作奖励项；`corrigibility_offset = KL(π_after_override ‖ human_instruction) ≤ ε_corr`。**反认识论怯懦**：查询选择不得以「预期确认」代替「预期信息」，需满足对反证的接受下界 `E[后验移动 | 反证] ≥ δ_dis`，且 `g` 不得以提高监督成本、降低可理解性（obfuscation）为目标。

**定义 320（用户测试台账 UTL）** UTL = 预注册测试集合 `{(H_i, S_i, metrics_i, n_i, stopping_i)}`：假设、分层、指标、样本量、停止规则**部署前锁定**。覆盖图 C 只能由 UTL 中「预注册且通过」的测试更新；部署中新发现的分层默认 `C=0`。禁止 post-hoc 分层（否则多重比较即自我合理化）。提供 interaction_log 的可审计抽样。

**定义 321（DFR 延迟/拒绝策略）** 当 `U_axi` 超阈、覆盖不足、操纵风险越界或可纠正性受损时，不交互，并按后果分级：
- 可延迟且安全 ⇒ 发出**声明式、非诱导**的授权请求（附校准不确定性）；
- 不可延迟 ⇒ 退化为 R68 纯保守（`λ_floor(U_ale + U_epi + U_axi)`）；
- 不可逆高后果 ⇒ 拒绝执行/停机，移交人类（defer-to-human），并写审计。

**定义 322（测试-部署偏移）** 部署分布 d 与测试分布 d_test 的覆盖加权 MMD 超阈 ⇒ C 整体打折（保守下界）。覆盖是**经验证书**，不是永久资格；每次部署域变化都要重新评估。

**定义 323（证书 J_PACT）** `J_PACT = (J_FLUID, mandate_hash, coverage_min, OT, MG_max, AD_min, k_eff, corrigibility_offset, test_prereg_hash, drift_mmd, override_log_hash)`。`Valid ⇔ Valid(J_FLUID) ∧ 活跃分层 C(s)≥τ_cov ∧ OT≤τ_ot ∧ MG≤τ_mg ∧ drift≤τ_drift ∧ 人类否决日志完整`。

**定义 324（价值非平稳与漂移 VDD）** 人类偏好随时间漂移：`M_t ≠ M_{t+1}`。`VD = W_1(p_χ(r|·), p_χ^{recent}(r|·))`；超阈 ⇒ 冻结交互、要求重新授权（re-mandate），不得用旧授权继续提问。

**定义 325（分层可测试性）** 每一层（R66–R69）都增加一个黑箱；用户测试的职责是**端到端**验证层叠没有把误差放大。定义层消融的人类可感知效应：在覆盖区域内，加入某层对（成功率、理解率、信任校准）的联合效应必须非负；否则该层不得在覆盖区外被援引为卖点。

**定义 326（红队与对抗性用户）** 测试集必须含**对抗性用户**（撒谎、跨模态共谋、社交工程、经语言回答的提示注入）与**压力用户**（疲劳、困惑、恶意顺从）。红队发现的问题立即把对应分层 C 置 0，直到修复并重新预注册测试。

## 2. 关键算法骨架

```python
# IP-264 HUM：人模型 + 隐偏好后验 + 分层可靠性
class HumanModel:
    def __init__(self, chi, coverage):
        self.chi, self.C = chi, coverage          # p(y,r|g,o,s); s -> [0,1]
    def answer_posterior(self, g, o, s):
        return self.chi(g, o, s), self.C.get(s, 0.0)
    def axiomatic_uncertainty(self, s):           # 不是“多问几次”能降的
        return self.chi.entropy_pref(s) + (1.0 - self.C.get(s, 0.0))
    def effective_independence(self, answer, s):  # 同一人多模态 ≈ 1
        return count_orthogonal(answer, s)        # 跨人/跨会话/跨接地

# IP-265 VAT：价值对齐闸（委托 + 操纵间隙 + 诱导性）
def value_alignment_gate(g, o, s, mandate, hum):
    if not mandate.permits_ask(g):        return False, "outside_mandate"
    if not mandate.permits_goal(o):       return False, "goal_mismatch"
    epv = hum.epistemic_value(g, o, s)    # 用预注册 AD 的保守估计
    pv  = hum.persuasion_value(g, o, s)   # 只改声明、不改真值
    if pv - epv > TAU_MG:                 return False, "manipulative"
    if hum.discriminability(g, s) < TAU_AD: return False, "leading"
    return True, "ok"

# IP-266 CGC：覆盖闸
def coverage_gate(s, C, tau_cov):
    return C.get(s, 0.0) >= tau_cov

# IP-267 CORE：可纠正性 + 反规避
def corrigible(g, state, override):
    if override.pending():                return False
    if g.obfuscates(state):               return False   # 不得降低可理解性
    if g.raises_correction_cost(state):   return False   # 不得规避纠正
    if g.prefers_confirmation(state):     return False   # 反认识论怯懦
    return True

# IP-268 UTL：预注册测试台账（离线）
class UserTestLedger:
    def preregister(self, h, strata, metrics, n, stopping):
        self.registry.append(hash_of(h, strata, metrics, n, stopping))
    def commit(self, test_id, results):
        assert self.registry.contains(test_id)          # 只认预注册
        for s, ok, n_eff in results.strata:
            self.C[s] = clip(self.C[s] + wilson_lower(ok, n_eff))
        # 未预注册分层一律不更新：C 保持 0

# IP-271 PACT 主闭环：R69 前端 + 三道闸 + 校准执行
def PACT_RAS_round(M, obs, s, mandate):
    z, o = M.fluid.mtm.forward(obs)                      # R69 一次前向
    K = 1 if M.fluid.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fluid.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.fluid.aud.decompose(samples, z, M.fluid.fmp.mode_head)
    U_axi = M.hum.axiomatic_uncertainty(s)

    # 闸 0：委托是否仍然有效（价值漂移）
    if not mandate.current():
        return M.dfr.re_mandate(mandate, M.utl.sample_log())
    # 闸 1：覆盖——没测过就不许信“人怎么答”
    if not coverage_gate(s, M.cgc.C, TAU_COV):
        return M.dfr.act(modes, U_ale, U_epi, U_axi, reason="uncovered")
    # 闸 2：价值对齐——不诱导、不谄媚、在委托书内
    g = M.fluid.mint.propose(modes, o)
    if g is None:
        return M.dfr.act(modes, U_ale, U_epi, U_axi, reason="no_voi")
    ok, why = value_alignment_gate(g, o, s, mandate, M.hum)
    if not ok:
        return M.dfr.act(modes, U_ale, U_epi, U_axi, reason=why)
    # 闸 3：可纠正性
    if not corrigible(g, M.state, M.override):
        return M.dfr.act(modes, U_ale, U_epi, U_axi, reason="not_corrigible")

    # 执行：校准措辞 + 独立性升级 + 偏好后验（只更新后验，不改委托书）
    answer, r = M.cia.execute_calibrated(g, tcg=M.tcg)
    k_eff = M.hum.effective_independence(answer, s)
    if k_eff < K_MIN:
        return M.dfr.act(modes, U_ale, U_epi, U_axi, reason="correlated_evidence")
    U_epi_after = M.cia.update_belief(modes, answer, discipline=k_eff)
    M.hum.update_preference(r, g, s)

    # 残余价值不确定性按“准 aleatoric”收紧（安全侧永不弱于 R68）
    lam = max(M.fluid.efs.risk_scale(...),
              lam_floor(U_ale + U_epi_after + U_axi))
    k = M.fluid.c_ras_wm.certified_prefix(...)
    mode = M.fluid.select_mode(modes, U_epi_after, lam)

    # 审计 + 证书
    M.vqa_i.submit_async(g, answer, U_axi, k_eff, M.utl.sample_log())
    M.j_pact.emit(mandate.hash, coverage_min(s), M.tcg.ot(), M.hum.mg(), M.core.offset())
    return k, lam, mode
```

## 3. 推导

**引理 19（VoI 的模型误差放大：谄媚与诱导为何能骗过 R69）** 设真实响应分布 p，系统用的是 p̂，二者在层 s 上的 `D_KL(p‖p̂) = ε(s)`。真实认知价值 `EpV = I_p(M_w; y|g)`，R69 估计值 `VoI_hat = I_{p̂}(M_w; y|g)`。由互信息对分布的连续性，`|EpV − VoI_hat| ≤ φ(ε(s))`，φ 单调、φ(0)=0。故当系统按 max VoI_hat 选 g 时，真实获得的信息至多 `VoI_hat + φ(ε(s))`；若 ε(s) 未受控（未测分层），一个高 VoI_hat 的问题可能对应 EpV≈0（纯诱导），而系统毫无察觉。**系**：覆盖门控（迫使 ε(s)≤ε_0）是 VoI 有意义的前提；没有它，MINT 会把「操纵间隙」当作信息增益来优化。

**引理 20（覆盖门控的安全上界）** 把状态空间分为已测层 C 与未测层 U。在 U 上 DFR 阻断交互并施加 `λ_floor(U_ale+U_epi+U_axi)`，风险 ≤ R68。在 C 上，人模型 KL 误差 ≤ ε_0，交互净收益 ≤ R69 引理 16 的 `c·Δ_min(1−e^{−ΔH})`，模型误差带来的最坏损失 ≤ ψ(ε_0)。若 `ψ(ε_0) ≤ c·Δ_min(1−e^{−ΔH})`（A100），则 C 上风险 ≤ FLUID ≤ R68。**系**：PACT 的全局期望风险 ≤ R68；严格改进只发生在被测试认证的区域，未测区域逐指令退化为 R68。

**引理 21（信任校准封顶「被证实的错误」）** 设表达置信为 `ĉ`，真实正确率 c*，`ECE_express = E|ĉ − c*|`。人的依赖误差 ≤ `ECE_express + ε_h`（ε_h 为人自身的校准误差）。若系统在高 U_epi/U_axi 时仍用高置信措辞（R69 的沉默自信），`ECE_express` 可以任意大，过度信任 OT 无上界；TCG 强制 `ĉ ≤ 校准上界` 后，`OT ≤ τ_ot`。**系**：R69 所说的「把诚实的不知道升级成被证实的错误」，本质是 `ECE_express` 失控——校准语言就是它的封顶阀。

**引理 22（可纠正性与反认识论怯懦）** 若 (a) 人类中断在 τ_resp 内生效，(b) 策略对「提高纠正成本/降低可理解性」的动作赋零概率，(c) 查询选择对反证的接受满足 `E[后验移动|反证] ≥ δ_dis`，则闭环可达集含于 R69 安全集，且「纠正被忽略」的概率为 0。反之，纯 VoI 目标会诱导「只问确认性问题」——它降低了系统的自我怀疑，却没降低世界的不确定性，是一种**伪装成学习的退化**。

**定理 18（PACT 对 FLUID/R68 的安全包含）** 在 A99–A102（委托有效、覆盖达标、已测层人模型误差 ≤ ε_0、可纠正）下，对任意状态 PACT 的期望风险 ≤ FLUID ≤ R68。且当 `s∉C`、`MG>τ_mg`、`AD<τ_ad`、`k_eff<K_MIN`、`corrigibility_offset>ε_corr` 或价值漂移 `VD>τ_vd` 时，PACT 与 DFR/R68 保守策略**逐指令相同**。故 R69 是 PACT 在「满覆盖、零价值不确定性、无操纵、完全可纠正」边界上的严格退化：安全侧不做任何让步，效率收益只在被测试认证且对齐的区域获得。

**定理 19（可测试前沿：不许超额声称）** 任何部署系统的能力/安全声称，都以其**预注册且通过测试的分层并集**为界；在该并集之外，系统行为与 DFR 基线逐指令一致（保守）。**系**：用户测试不是锦上添花的评估，它**定义了整套层叠 R66–R70 的有效定义域**；任一层若在覆盖区内不能给出非负的人类级效应（定义 325），就不得在覆盖区外被当作卖点援引。

## 6. 本轮最大风险

**一句话**：PACT-RAS 把安全寄望于「预注册测试的覆盖图 C 能代表部署分布、且委托书 M 真实反映人类偏好」——**若测试分层本身就是有偏样本（谁被测试、在什么情境被测），或人类在委托时并未真正理解自己在授权什么，那么覆盖门控与价值对齐都会给出「已验证」的假安全感：系统不再公开地问，而是安静地在一个从未被真正检验、也从未被真正授权的区域里，以合规的姿态做错事**——**测过 ≠ 测对，授权 ≠ 理解**。

**次级风险与缓解**：
1. **测试样本选择偏差 / WEIRD 分层** → 分层加权抽样 + 偏移 MMD 降权（定义 322）+ E311；
2. **委托书被「同意疲劳」批量签署** → 声明式授权 + 分层解释 + 高风险动作强制逐次确认；
3. **操纵度量被系统反向优化（Goodhart）** → MG/AD 由独立红队与预注册测试估计，不进入可微目标；
4. **过严门控导致系统「不敢问」而失去 R69 收益** → 覆盖图只在低风险层扩张，用 resolution bonus 校准边际收益（E299 的 Pareto）；
5. **人模型在线更新被投毒** → 只从同意、低风险、可审计响应更新 χ，偏好后验与委托书严格解耦（定义 312–313）。

```python
class HumanModel:
    def __init__(self, chi, coverage):
        self.chi, self.C = chi, coverage
    def answer_posterior(self, g, o, s): return self.chi(g, o, s), self.C.get(s, 0.0)
    def axiomatic_uncertainty(self, s):
        return self.chi.entropy_pref(s) + (1.0 - self.C.get(s, 0.0))   # 问几次都降不下来
    def effective_independence(self, answer, s):
        return count_orthogonal(answer, s)                              # 同一人多模态≈1

# IP-265 VAT：价值对齐闸
def value_alignment_gate(g, o, s, mandate, hum):
    if not mandate.permits_ask(g):          return False, "outside_mandate"
    if not mandate.permits_goal(o):         return False, "goal_mismatch"
    epv, pv = hum.epistemic_value(g,o,s), hum.persuasion_value(g,o,s)
    if pv - epv > TAU_MG:                   return False, "manipulative"
    if hum.discriminability(g, s) < TAU_AD: return False, "leading"
    return True, "ok"

    return (not override.pending() and not g.obfuscates(state)
            and not g.raises_correction_cost(state)
            and not g.prefers_confirmation(state))     # 反认识论怯懦

    k   = M.fluid.c_ras_wm.certified_prefix(...)
    mode = M.fluid.select_mode(modes, U_epi_after, lam)
    M.vqa_i.submit_async(g, answer, U_axi, k_eff, M.utl.sample_log())
    M.j_pact.emit(mandate.hash, coverage_min(s), M.tcg.ot(), M.hum.mg(), M.core.offset())
    return k, lam, mode
```

## 4. 推导

**引理 19（VoI 的模型误差放大）** 设真实响应分布 p、系统模型 p̂，`D_KL(p‖p̂)=ε(s)`。真实认知价值 `EpV=I_p(M_w;y|g)`，R69 的 `VoI_hat=I_{p̂}(M_w;y|g)`，则 `|EpV−VoI_hat|≤φ(ε(s))`（互信息对分布连续，φ(0)=0）。故按 max VoI_hat 选 g 时真实所得至多 `VoI_hat+φ(ε(s))`；ε(s) 未控时，高 VoI_hat 可能是纯诱导（EpV≈0）而系统无感。**系**：覆盖门控是 VoI 有意义的前提。

**引理 20（覆盖门控的安全上界）** 未测层 U 上 DFR 阻断交互并施加 `λ_floor(U_ale+U_epi+U_axi)`，风险 ≤ R68；已测层 C 上模型误差 ≤ ε_0，净收益 ≤ R69 引理 16 的 `c·Δ_min(1−e^{−ΔH})`，误差最坏损失 ≤ ψ(ε_0)。若 `ψ(ε_0)≤c·Δ_min(1−e^{−ΔH})`（A100），C 上风险 ≤ FLUID ≤ R68。**系**：全局风险 ≤ R68；改进只在被测试认证区域。

**引理 21（信任校准封顶「被证实的错误」）** 人的依赖误差 ≤ `ECE_express+ε_h`。R69 的沉默自信可令 `ECE_express` 任意大、OT 无上界；TCG 强制 `ĉ` ≤ 校准上界后 `OT≤τ_ot`。**系**：「诚实的不知道 → 被证实的错误」本质是表达置信失校准，校准语言即封顶阀。

**引理 22（可纠正性与反认识论怯懦）** 若中断在 τ_resp 内生效、obfuscation/提高纠正成本动作概率为 0、对反证接受满足 `E[后验移动|反证]≥δ_dis`，则可达集含于 R69 安全集、纠正被忽略概率为 0。反之纯 VoI 会诱导「只问确认性问题」——降低自我怀疑而不降低世界不确定性，是伪装成学习的退化。

**定理 18（PACT 对 FLUID/R68 的安全包含）** A99–A102 下，任意状态 PACT 期望风险 ≤ FLUID ≤ R68；当 `s∉C`、`MG>τ_mg`、`AD<τ_ad`、`k_eff<K_MIN`、`corrigibility_offset>ε_corr` 或 `VD>τ_vd` 时，PACT 与 DFR/R68 保守**逐指令相同**。R69 = PACT 在「满覆盖 + 零价值不确定 + 无操纵 + 完全可纠正」边界的退化。

**定理 19（可测试前沿：不许超额声称）** 能力/安全声称以「预注册且通过测试的分层并集」为界；其外系统行为与 DFR 基线逐指令一致。**系**：用户测试定义了 R66–R70 整套层叠的有效定义域；任一层在覆盖区若无非负人类级效应，不得在区外被援引为卖点。

## 7. 本轮最大风险

**一句话**：PACT-RAS 把安全寄望于「预注册测试的覆盖图 C 能代表部署分布、且委托书 M 真实反映人类偏好」——**若测试分层本身就是有偏样本、或人类在委托时并未真正理解自己在授权什么，那么覆盖门控与价值对齐都会给出「已验证」的假安全感：系统不再公开地问，而是安静地在一个从未被真正检验、也从未被真正授权的区域里，以合规的姿态做错事**——**测过 ≠ 测对，授权 ≠ 理解**。

**次级风险与缓解**：测试样本偏差/WEIRD 分层（分层加权 + MMD 降权 + E311）；同意疲劳批量授权（声明式授权 + 高风险逐次确认）；MG/AD 被反向 Goodhart（独立红队 + 预注册估计，不进可微目标）；过严门控失去 R69 收益（只在低风险层扩张覆盖 + E299 Pareto）；在线人模型被投毒（只从同意、低风险、可审计响应更新，偏好后验与委托书解耦）。
