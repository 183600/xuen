# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「双足机器人」×「预测性维护」）

> 第 54 轮把技能组合提升为「动作空间 + 鲁棒性」双证书（ACS×SCOM×CEC×AEC），但该体系隐含一个静态假设：能力剖面 α 与鲁棒谱 ρ 在任务期间不变。本轮引入 **健康维度 h 与时间维度 t**，揭示三组新矛盾：
> **H22**：双足机器人是欠驱动、接触富集、平衡临界的系统，关节回差/执行器热衰退/电池 SoH 退化会让 α_S(a) 与 ρ_S(d) 沿健康轨迹**单调收缩**，静态组合证书在任务后半程系统性失效；
> **H23**：预测性维护（PdM）长期被视为独立的“健康管理”外挂层，但维护动作**本身占用动作空间、改变健康状态、并扰动双足平衡**，必须作为一等技能并入组合图；
> **H24**：RUL 预测不确定性会沿组合证书传播，证书必须在 RUL 分布下对**整段任务时域** sound，而非仅在部署时刻成立。

## 0. 直觉与动机

**灵感 1（健康条件剖面 → 从「能不能做」到「此刻还能做多久」）**
直觉：技能 S 不只是一个 α_S(a)，而是 `α_S(a|h)` 与 `ρ_S(d|h)`，其中 h 为健康向量（关节回差、执行器绕组温度、电池 SoH、IMU 漂移）。健康越差，剖面越收缩、鲁棒谱越塌陷。于是组合的第一性问题从“动作是否重叠”升级为“在健康轨迹上动作覆盖还能维持多久”。定义 **鲁棒半衰期 `τ_ρ(S,d)`**：ρ_S(d|h(t)) 首次跌破 ρ_min 的时间。任务可行性 = 能否在 τ_ρ 之前完成，或在 τ_ρ 之前插入维护把“鲁棒时钟”重置。

**灵感 2（维护作为一等技能 → 组合图里的“修复边”）**
直觉：维护不是外挂管理动作，而是改变 h 的算子 `R_M : H→H`（换电池、标定零位、关节润滑/更换）。它在动作空间里同样有剖面 `α_M`（多为稳定站立/双支撑相的低动态动作），有成本 `c_M`、时长 `τ_M` 与 **扰动风险 `r_M`**（双足维护常需单腿支撑或坐下，本身可能破坏平衡）。把维护动作 M 作为图节点、把 `R_M` 作为修复边并入 `G_S`，组合问题就变成 **技能-维护联合调度**：不是“先跑完任务再修”，而是在任务中寻找“何时、在哪个步态相位、以多大平衡代价”插入维护最优。

**灵感 3（预后感知证书 → 让证书在时域上 sound）**
直觉：第 54 轮证书只在部署点验证 `ρ ≥ ρ_min`。现在必须对 `∀t∈[0,T]` 验证 `ρ_S(d|h(t)) ≥ ρ_min(d)`，其中 h(t) 由退化模型 + RUL 分布采样。证书附带 RUL 区间与覆盖率 `δ_R`，只有当预测区间校准良好、且健康轨迹全程落入安全域时才签发。这把“鲁棒性证书”升级为 **预后感知组合证书 PAC**，其 validity 有明确时间窗与覆盖保证，而不是一次性快照。

**灵感 4（双足特性 → 平衡裕度与步态相位相容）**
直觉：双足动作空间是周期性的（支撑相/摆动相/双支撑相），技能拼接不仅要动作重叠，还要 **相位相容 `compat_φ(S_i,S_j)`**：出口相位与入口相位一致，且转换期间平衡裕度 `β(a,h) ≥ β_min`（ZMP/捕获点距支撑多边形边界的归一化距离）。维护窗口天然对齐双支撑相（最安全），于是 PdM 获得一个物理约束：**维护不是随时可做，而是相位可做的稀疏事件**——这正好把“维护计划”与“步态相位规划”耦合起来。

**灵感 5（失效归因扩展 → 从“动作错配”到“预后意外”）**
直觉：失败的根因不再只有动作不兼容，还包括 ρ 退化、RUL 预测失误（prognostic surprise）、维护扰动、平衡越界。PSA 用反事实仿真对观测失败做贝叶斯归因，并把最高后验因子的反例经第 54 轮的反向解释信道回传，分别触发：动作重剖分（动作错配）、保守降级/提前维护（ρ 退化）、退化模型重校准（预后意外）、维护策略重排（维护扰动）、步态重规划（平衡）。**归因错了，护栏就会打错方向**，因此归因本身需要可证伪。

**灵感 6（向金字塔再叠一层）**
直觉：在第 54 轮的动作-协同层 `𝔸` 之上叠加 **健康-预后层 `ℍ`**：`ℍ_0` 物理退化极限，`ℍ_1` 健康条件剖面，`ℍ_2` RUL 预测与区间，`ℍ_3` 维护-任务联合调度。跨层证书需同时携带 `ρ, A_cert, h, [τ_lo,τ_hi], β_traj`，形成 **动作-鲁棒-健康三证书体系**。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（健康条件动作剖面）**
健康状态 `h ∈ H ⊂ R^m`，退化偏序 `≼`。技能动作剖面 `α_S : A × H → [0,1]`，鲁棒谱 `ρ_S : 𝔇_ρ × H → [0,1]`。**退化单调性（A29）**：若 `h ≼ h'`（h 更健康），则 `α_S(a|h) ≥ α_S(a|h')` 且 `ρ_S(d|h) ≥ ρ_S(d|h')`。动作在健康 h 下**可采纳**当且仅当 `α_S(a|h) ≥ θ_cov ∧ β(a,h) ≥ β_min`。

**定义 122（退化动力学与 RUL 分布）**
`h_{t+1} = h_t + g(h_t, a_t) + ξ_t`，`ξ_t ~ D`。失效集 `F ⊂ H`，剩余寿命 `τ = inf{t ≥ 0 : h_t ∈ F}`，RUL 分布 `p(τ | h_t)`。预测区间 `[τ_lo, τ_hi]` 满足 `P(τ ∈ [τ_lo,τ_hi]) ≥ 1 - δ_R`（校准假设 A30）。

**定义 123（维护算子与技能-维护统一图）**
维护动作 `M`，修复算子 `R_M : H → H`（分量不减），成本 `c_M`、时长 `τ_M`、扰动风险 `r_M`、允许相位集 `Φ_M ⊆ {stance, swing, double-support}`。统一图 `G_S^M = (V ∪ M, E ∪ E_M)`，`E_M` 为维护修复边。技能-维护联合计划 `P = ⟨(x_1,t_1),...,(x_k,t_k)⟩`，`x_i ∈ V ∪ M`，健康沿计划演化。

**定义 124（预后鲁棒性裕度与鲁棒半衰期）**
`μ_S(d,h,T) = min_{t∈[0,T]} (ρ_S(d|h(t)) - ρ_min(d))`。**鲁棒半衰期** `τ_ρ(S,d,h) = min{t ≥ 0 : ρ_S(d|h(t)) < ρ_min(d)}`。任务在时域 T 可行当且仅当 `∀d: μ_S(d,h,T) ≥ 0`，或存在维护插入使 `τ_ρ` 被重置到 `T` 之后。

**定义 125（平衡裕度与相位相容）**
`β(a,h)`：归一化 ZMP/捕获点距支撑多边形边界距离。**相位相容** `compat_φ(S_i,S_j) = 1[φ_out(S_i) ∩ φ_in(S_j) ≠ ∅] ∧ 1[β_trans(S_i,S_j,h) ≥ β_min]`。统一图边条件由第 54 轮 `compat` 扩展为 `compat ∧ compat_φ`。

**定义 126（预后感知组合证书 PAC）**
`PAC = (P, {α_S(·|h)}, {ρ_S(·|h)}, [τ_lo,τ_hi], δ_R, A_cert, β_traj, evidence)`。签发条件：`∀t∈[0,T],∀d: ρ_S(d|h(t)) ≥ ρ_min(d)` 且 `∀t: β_traj(t) ≥ β_min` 且校准覆盖 `PICP ≥ 1-δ_R` 且 `δ_a ≤ Θ_a`。`dom(PAC)=in` 表示整段任务时域可部署。

**定义 127（预后意外与失效归因 PSA）**
对观测失败 `e`，反事实归因后验 `P(cause | e) ∝ P(e | cause)·P(cause)`，`cause ∈ {动作错配, ρ 退化, 预后意外, 维护扰动, 平衡越界}`。`prognostic_surprise = 1 - P(τ_real ∈ [τ_lo,τ_hi])`。归因可用于触发对应护栏，且须以反事实可分离性作为可证伪条件。

## 2. 关键算法 伪代码

### IP-121 DAP（Degradation-Aware Profile）

```python
def degradation_profile(skill, health_grid, sampler, calib_set):
    alpha, rho = {}, {}
    for h in health_grid:
        alpha[h] = {}
        for a in sampler.candidates(skill, h):
            feas, conf = sampler.query(skill, a, h)
            alpha[h][a] = conf if feas else 0.0
        rho[h] = robustness_spectrum(skill, health=h)
    # A29 单调性自检：健康变差时不得“变强”
    if not is_monotone_decreasing(alpha, health_grid):
        return ('reject', 'monotonicity_violation', audit(alpha))
    return Profile(alpha, rho, calib_set)
```

### IP-122 HDE（Health Degradation & RUL Estimation）

```python
def health_forecast(h0, usage_plan, deg_model, horizon, n_mc=512):
    traj = []
    for _ in range(n_mc):
        h, path = h0, []
        for a in usage_plan:
            h = deg_model.step(h, a) + deg_model.sample_noise()
            path.append(h)
        traj.append(path)
    tau = [first_hitting_time(p, deg_model.failure_set) for p in traj]
    lo, hi = empirical_quantiles(tau, [0.05, 0.95])
    picp = coverage_check(traj, deg_model.calib_log)
    return HealthForecast(traj, (lo, hi), picp)
```

### IP-123 PMS（Predictive Maintenance Scheduling）

```python
def plan_skill_maintenance(G, h0, T, H_bins, maint_ops):
    # DP over (node, health_bin, t)
    dp = init_dp(G, h0, H_bins)
    for t in range(T):
        for node in G.nodes:
            for hb in H_bins:
                cur = dp.get((node, hb, t))
                if cur is None: continue
                for nxt, e in G.out_edges(node):
                    h2 = degrade_step(hb, e.action)
                    if balance_ok(e.action, h2) and phase_ok(node, nxt, e.action):
                        relax(dp, (nxt, h2, t+1), cur + e.cost)
                # 维护只能在安全步态相位插入
                if at_safe_phase(node):
                    for M in maint_ops:
                        h2 = M.restore(hb)
                        c = M.cost + M.risk_weight * M.r
                        relax(dp, (node, h2, t+M.duration), cur + c)
    return extract_best(dp, T)
```

### IP-124 PAC（Prognostics-Aware Certificate）

```python
def prognostics_certificate(path, forecast, profiles, beta_min, rho_min, delta_a_budget):
    for t, (skill, a, h_samples) in enumerate(path.exposure()):
        for h in h_samples:
            if not cover_check(profiles[skill].alpha[h], a):
                return ('reject', 'coverage', t)
            if min(profiles[skill].rho[h].values()) < rho_min:
                return ('reject', 'rho_decay', t)
            if balance_margin(a, h) < beta_min:
                return ('reject', 'balance', t)
        if alignment_drift(path, t) > delta_a_budget:
            return ('reject', 'action_mismatch', t)
    if forecast.picp < 1 - forecast.delta_R:
        return ('reject', 'prognostic_uncertainty', forecast.picp)
    return ('ok', PrognosticsCert(path, forecast, beta_traj(path)))
```

### IP-125 BAM（Balance-Aware Margin）

```python
def balance_margin(action, health):
    cop = zmp(action, health)
    poly = support_polygon(action)
    d = min_distance_to_boundary(cop, poly)
    return d / support_scale(action)   # 归一化，越界为负
```

### IP-126 PSA（Prognostic Surprise Attribution）

```python
def attribute_failure(obs, sim, profiles, forecast):
    causes = ['action_mismatch', 'rho_decay', 'prognostic_surprise',
              'maint_perturb', 'balance']
    post = {}
    for c in causes:
        cf = sim.counterfactual(obs, neutralize=c)
        post[c] = likelihood(obs, cf) * prior(c)
    post = normalize(post)
    top = max(post, key=post.get)
    # 可证伪：反事实必须显著可分离，否则标记 inconclusive
    if separation_margin(post) < gamma_attr:
        return ('inconclusive', post)
    return ('attributed', top, post)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| DAP | O(\|S\|·\|A\|·\|H_grid\|·q) | O(\|S\|·\|A\|·\|H_grid\|) | 退化单调 (A29)、校准覆盖 |
| HDE | O(N_mc·T·m) | O(N_mc·T·m) | RUL 区间校准 (A30) |
| PMS | O(T·\|V\|·\|H_bins\|·(\|E\|+\|M\|)) | O(T·\|V\|·\|H_bins\|) | DP 最优、相位约束 |
| PAC | O(\|P\|·\|H_samples\|·\|𝔇_ρ\|) | O(\|H_samples\|) | 时域 sound、覆盖校验 |
| BAM | O(\|A\|·m) | O(\|A\|) | 支撑多边形精确、Lipschitz (A32) |
| PSA | O(\|cause\|·T_sim) | O(\|cause\|) | 反事实可分离 |

**正确性定理（Prognostics-Aware Composition Soundness）**
承接第 54 轮 (A26)–(A28)，新增：**(A29)** α/ρ 退化单调且在健康网格上校准误差 ≤ δ_p；**(A30)** RUL 区间覆盖 ≥ 1-δ_R；**(A31)** 维护算子 R_M 与扰动风险 r_M 有界，且仅在安全相位 Φ_M 执行；**(A32)** β 对 h 满足 Lipschitz 常数 L_β。则任务时域成功概率：

```
P_success(T) ≥ 1 - N_cp·Σ_d ε_ρ(d) - δ_p - δ_R - Σ_{M∈P} r_M - ε_β(β_min)
```

其中 `N_cp` 为健康检查点数，`ε_ρ(d)` 为单检查点 ρ 越限概率，`ε_β` 为 Lipschitz 外推导致的平衡越界概率。关键：**证书必须在每个健康检查点重新采样 h，而不是复用部署点快照**；维护插入必须同时重置 τ_ρ 与重校准 α/ρ，否则证书立即过期。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 健康状态部分可观测 | 高 | 观测器 + 不确定性膨胀 + POMDP 上界 |
| RUL 模型分布漂移/非平稳磨损 | 高 | 在线重校准 + conformal 预测 + 漂移告警 |
| 维护后剖面失效需重校准 | 高 | 维护-重校准原子化、证书新鲜度门控 |
| DP 状态爆炸（健康分箱×时域） | 中 | 分层/近似 DP、支配剪枝、健康哈希 |
| 步态相位建模误差 | 中 | 相位本体 + 双支撑窗口冗余 + 回滚 |
| 归因错误导致护栏失效 | 高 | 反事实可分离门槛 + inconclusive 安全兜底 |

## 6. 本轮最大风险

**一句话**：把双足机器人的退化与预测性维护并入动作-鲁棒体系，使证书从“部署快照”升级为“时域预后契约”，但其 soundness **四重依赖健康状态可观测、RUL 区间校准、退化单调性、以及维护-重校准的原子性**；一旦健康部分可观测且 RUL 在非平稳磨损下过度自信，PAC 会给出“全程安全”的假象，既可能错过维护窗口、又可能在维护扰动瞬间失去平衡——因此必须以 **conformal RUL + 观测器不确定性膨胀 + 维护后证书强制失效重签** 三道护栏，宁可提前维护，绝不把预后的“平均安全”当作逐时刻的可部署前提。

## 2. 关键算法 伪代码

### IP-121 DAP：健康条件剖面

```python
def degradation_profile(skill, health_grid, sampler, calib_set):
    alpha, rho = {}, {}
    for h in health_grid:
        alpha[h] = {}
        for a in sampler.candidates(skill, h):
            feas, conf = sampler.query(skill, a, h)
            alpha[h][a] = conf if feas else 0.0
        rho[h] = robustness_spectrum(skill, health=h)
    if not is_monotone_decreasing(alpha, health_grid):   # A29
        return ('reject', 'monotonicity_violation', audit(alpha))
    # 健康网格插值器：任意 h 上取保守包络（下界）
    return Profile(interp_lower(alpha), interp_lower(rho), calib_set)
```

### IP-122 HDE：退化预测与 RUL 区间

```python
def health_forecast(h0, usage_plan, deg_model, horizon, n_mc=512):
    traj = []
    for _ in range(n_mc):
        h, path = h0, []
        for a in usage_plan:
            h = deg_model.step(h, a) + deg_model.sample_noise()
            path.append(h)
        traj.append(path)
    tau = [first_hitting_time(p, deg_model.failure_set) for p in traj]
    lo, hi = empirical_quantiles(tau, [0.05, 0.95])
    picp = coverage_check(traj, deg_model.calib_log)   # A30
    return HealthForecast(traj, (lo, hi), picp, delta_R=0.10)
```

### IP-123 PMS：技能-维护联合调度

```python
def plan_skill_maintenance(G, h0, T, H_bins, maint_ops):
    dp = init_dp(G, h0, H_bins)
    for t in range(T):
        for node in G.nodes:
            for hb in H_bins:
                cur = dp.get((node, hb, t))
                if cur is None: continue
                for nxt, e in G.out_edges(node):
                    h2 = degrade_step(hb, e.action)
                    if balance_ok(e.action, h2) and phase_ok(node, nxt, e.action):
                        relax(dp, (nxt, h2, t+1), cur + e.cost)
                if at_safe_phase(node):                 # 仅双支撑相等安全相
                    for M in maint_ops:
                        h2 = M.restore(hb)
                        c = M.cost + M.risk_weight * M.r
                        relax(dp, (node, h2, t+M.duration), cur + c)
    return extract_best(dp, T)
```

### IP-124 PAC：预后感知证书

```python
def prognostics_certificate(path, forecast, profiles, beta_min, rho_min,
                            delta_a_budget):
    beta_traj = []
    for t, (skill, a, h_samples) in enumerate(path.exposure()):
        for h in h_samples:
            if not cover_check(profiles[skill].alpha[h], a):
                return ('reject', 'coverage', t)
            if min(profiles[skill].rho[h].values()) < rho_min:
                return ('reject', 'rho_decay', t)
            b = balance_margin(a, h)
            beta_traj.append(b)
            if b < beta_min:
                return ('reject', 'balance', t)
        if alignment_drift(path, t) > delta_a_budget:
            return ('reject', 'action_mismatch', t)
    if forecast.picp < 1 - forecast.delta_R:
        return ('reject', 'prognostic_uncertainty', forecast.picp)
    return ('ok', PrognosticsCert(path, forecast, beta_traj))
```

### IP-125 BAM：平衡裕度与相位相容

```python
def balance_margin(action, health):
    cop = zmp(action, health)
    poly = support_polygon(action)
    d = min_distance_to_boundary(cop, poly)
    return d / support_scale(action)          # 归一化；负值表示已越界

def phase_compatible(s_i, s_j, health):
    return (s_i.exit_phase & s_j.entry_phase) != set() \
           and transition_margin(s_i, s_j, health) >= beta_min
```

### IP-126 PSA：预后意外归因

```python
def attribute_failure(obs, sim, profiles, forecast):
    causes = ['action_mismatch', 'rho_decay', 'prognostic_surprise',
              'maint_perturb', 'balance']
    post = {}
    for c in causes:
        cf = sim.counterfactual(obs, neutralize=c)
        post[c] = likelihood(obs, cf) * prior(c)
    post = normalize(post)
    if separation_margin(post) < gamma_attr:
        return ('inconclusive', post)          # 安全兜底，不误触发护栏
    return ('attributed', max(post, key=post.get), post)
```

### IP-127 MRC：维护-重校准原子证书

```python
def maintenance_restorative_cert(h_before, M, profiles):
    h_after = M.restore(h_before)
    if not componentwise_ge(h_after, h_before):
        return ('reject', 'non_restorative')
    # 维护引起健康跃迁：旧剖面证书一律失效，必须重签
    if jump(h_after, h_before) > delta_h:
        re = degradation_profile_all(health_grid=[h_after], recalibrate=True)
        return ('recalibrated', re, h_after)
    return ('fresh', h_after)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DAP | O(\|S\|·\|A\|·\|H_grid\|·q) | O(\|S\|·\|A\|·\|H_grid\|) | 退化单调 A29、校准覆盖 |
| HDE | O(N_mc·T·m) | O(N_mc·T·m) | RUL 区间校准 A30 |
| PMS | O(T·\|V\|·\|H_bins\|·(\|E\|+\|M\|)) | O(T·\|V\|·\|H_bins\|) | DP 最优、相位/平衡约束 |
| PAC | O(\|P\|·\|H_samples\|·\|𝔇_ρ\|) | O(\|H_samples\|) | 时域 sound、覆盖校验 |
| BAM | O(\|A\|·m) | O(\|A\|) | 支撑多边形精确、Lipschitz A32 |
| PSA | O(\|cause\|·T_sim) | O(\|cause\|) | 反事实可分离 |

**正确性定理（Prognostics-Aware Composition Soundness）**
承接第 54 轮 (A26)–(A28)；**(A29)** α/ρ 退化单调且健康网格校准误差 ≤ δ_p；**(A30)** RUL 区间覆盖 ≥ 1-δ_R；**(A31)** R_M 与 r_M 有界且仅在安全相位 Φ_M 执行；**(A32)** β 对 h Lipschitz 常数 L_β。则：

```
P_success(T) ≥ 1 - N_cp·Σ_d ε_ρ(d) - δ_p - δ_R - Σ_{M∈P} r_M - ε_β(β_min)
```

**证明要点**：(1) 由 A29 + 校准，任一检查点真实 ρ 低于阈值的概率 ≤ ε_ρ(d)（把 α/ρ 视为保守下界包络）；(2) PAC 对每个检查点独立验证并以 union bound 累积 N_cp 个检查点；(3) RUL 误覆盖概率 ≤ δ_R，A30 给出区间名义覆盖；(4) 每次维护引入独立扰动风险 r_M，且 A31 保证相位安全窗口；(5) A32 把健康观测误差经 Lipschitz 映射为平衡越界概率 ε_β。**注意**：只要维护后未重签证书（IP-127 未触发），PAC 的时域 sound 即失效——因此“证书新鲜度”是定理的隐含前提。

## 5. 本轮最大风险

**一句话**：把双足退化与预测性维护并入动作-鲁棒体系，使证书从“部署快照”升级为“时域预后契约”，但其 soundness **四重依赖健康状态可观测、RUL 区间校准、退化单调性、以及维护-重校准的原子性**；一旦健康部分可观测且 RUL 在非平稳磨损下过度自信，PAC 会给出“全程安全”的假象，既可能错过维护窗口、又可能在维护扰动瞬间失去平衡——因此必须以 **conformal RUL + 观测器不确定性膨胀 + 维护后证书强制失效重签** 三道护栏，宁可提前维护，绝不把预后的“平均安全”当作逐时刻的可部署前提。
