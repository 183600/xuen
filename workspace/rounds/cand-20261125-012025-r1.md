研究循环·放置-交互 第 1 轮；本轮灵感：「多模态交互」×「放置」

> **基线**：MetricVoiceGauge-NCD-HUTDH-v22 + IP-431–435（HDL/ACSC/DCSC/HPC-E/CFC++），其上承 v21 语义-规范层（SDC/CAC/DCL/GIC）、v20 联邦感知证书（PCA/CTS/CFC/HPC/CFCtrl）、v19（DCM/OGCC/CCV/DRS/OGC）与 v17（CLP/S2C/HCG/PSV/APS/AMC）。不推倒 v22：HDL/ACSC/DCSC/HPC-E/CFC++ 全部保留。
> 本轮纪律：**指代不是"猜一个点"，而是"带覆盖率的集合 + 何时该问"；放置不是"把物体挪过去"，而是"一次不可逆的环境写入"；多模态一致不是"票数更多"，而是"误差独立才算第二票"**。本轮只做一件事：在 v22 的层级物理-能量证书之上加一层 **放置-交互层 (Placement–Interaction Layer, PIL)**，把"人指哪儿、物体放那儿稳不稳、放下去还能不能反悔、几路模态的同意是否独立"全部变成可审计证书，并顺手给 v22 的「配空间能量过度保守导致活性坍缩」开一条**有证可赎回**的口子。

## 0. 直觉与动机

**灵感 1（多模态交互 → 指代是集合值预言，澄清是最安全的动作）**
直觉：人说"放那儿"，同时伸出手指、看向桌面。语言、手势、注视三者都带噪，且可能**共享同一个视觉骨干而相关地错**。"放"这个动作一旦执行就改变世界，因此指代不能像分类那样"取 argmax 后再赌"。多模态交互给出的正确对象是 **指代分布/集合**：系统应输出一个以 ≥1-α_ref 概率包含真实目标区 r* 的集合 Γ_ref，并且只在 **Γ_ref 可操作（并集直径足够小、且对障碍有裕度）** 时才执行；否则**澄清**（问一句）——澄清的代价是一点时间，猜错的代价是一次不可逆的错误放置。核心创新：**指代证书 (Reference Certificate, RefC)**。关键反直觉点：**一个安全的多模态系统不是"融合得更好"，而是"更知道什么时候不该融合"**；模态间的**分歧不是要消除的噪声，而是缩小 Γ_ref 的信息**。

**灵感 2（放置 → 释放是一次不可逆承诺，稳定性与可逆性都要证书）**
直觉：搬运动作可以随时停，但"松手"在任务时域内几乎不可逆：物体可能倒下、滚走、被人拿走、落入不可达处。v22 的证书回答"能不能安全地走到那里、能量够不够"，却不回答"放下去之后它还稳不稳、这个'放'还能不能收回"。放置天然要求两类新证据：**(a) 稳定证书 (StabC)**——支撑多边形、摩擦锥、质心投影在**有界扰动与释放瞬态**下仍有正裕度，并用 conformal 校准仿真-现实差；**(b) 可逆性证书 (RevC)**——在物体变得不可恢复之前，机器人还剩多少"反悔预算" U_undo（重新抓取/轻推/等待人接）。核心创新：**放置承诺三元组 (StabC, RevC, 单调世界更新)**。关键反直觉点：**释放的准入阈值不应只由置信度决定，而应由"置信度 × 可逆性"共同决定**——一个中等置信但可轻松重抓的放置，可以比一个高置信却毫无退路的放置更该被允许。

**灵感 3（交集：承诺门把"人的确认"也当作需要独立佐证的模态）**
直觉：人一句"好，放吧"并不自动等于许可——他可能没看屏幕、可能在回答别的问题、可能没意识到机器人要把杯子放在桌沿。多模态交互里真正可靠的确认是**联合注意 (joint attention)** 下的确认：人看着被提议的放置区/机器人，再给出肯定。于是确认本身也是一路模态，必须与语言/手势/注视的指代**独立**或**被注意力接地**。核心创新：**承诺门 (Commitment Gate, CG)** 与 **模态独立性证书 (Modality Independence Certificate, MIC)**：用校准探针估计模态误差相关矩阵，得到有效模态数 n_eff；只有 n_eff ≥ 2（或经联合注意接地的显式确认）时，"一致同意"才计为共识。关键反直觉点：**多模态"全体同意"在相关失效下恰恰最危险**，应以"有效独立票数"而非"原始票数"计数。

**三者如何统一**
统一为 v22 之上的 **放置-交互层 PIL**：RefC 回答"人指的是哪个集合、能不能动手"，StabC/RevC 回答"放下去稳不稳、错了能不能收回"，MIC/CG 回答"这声'好'值几票"。共享状态扩展为 **ζ_place = ζ_pgev ∪ (Γ_ref, n_eff_ref, stab, U_undo, mic, attn, release_state)**。统一准入门升级为 **HPC-P = (HPC-E, RefOK, StabOK, IndepOK, UndoOK, W=∅)**：几何∧规范∧负信息∧能量（v22）之后，再要求指代可操作、释放稳定、模态独立（或确认接地）、反悔预算足够。任一不满足 → 不释放（保持夹持/退回/请求帮助），退回 v22 的保守模式。故 **Exec_v23P = Exec_v22 ∩ Fil_ref ∩ Fil_stab ∩ Fil_undo ⊆ Exec_v22**。这一层同时缓解 v22 的活性坍缩：只有在"有证"时才允许放置/释放，而不是对所有人形共享区一律停机。

## 1. 研究问题（轮次升级版）

- **Q16（集合值指代的覆盖与可操作性）**：如何从语言+手势+注视构造候选区打分 s_ref，并用分组条件 conformal 得到 `P(r* ∈ Γ_ref) ≥ 1-α_ref`？空间关系（"在桌上/在杯旁/放进盒里"）与可供性（能放/能承重）如何进入候选生成而不把先验错误变成假自由？Γ_ref 的"可操作"判据（直径 d_max、障碍裕度、扫掠体积、可达/能量）如何同时保证不漏真目标且不误放？

- **Q17（释放瞬态与尾部稳定性）**：静态稳定（支撑多边形、摩擦锥、质心）如何升级为包含**释放瞬态**与**有界扰动**的鲁棒裕度 m_stab？如何用少量真机试验 + 物理仿真做 conformal 校准，使 `P(m_stab ≥ 0) ≥ 1-δ_stab` 在**软/滑/斜面/可变形支撑**的尾部仍然可信？部分可观测支撑（被遮挡的桌沿）如何保守补全？

- **Q18（模态独立性与联合注意确认）**：如何用共享探针集估计模态误差相关矩阵并给出 n_eff 的置信下界，使 CFC++ 的"计数"改为"有效独立票数"？如何判定"确认"是**联合注意下**的确认（人看着提议区/机器人）而非对别的问题的应答？当 n_eff < 2 时，系统应在什么条件下接受显式人工确认、否则退回澄清？

- **Q19（不可逆承诺与安全继承）**：如何定义反悔预算 U_undo（重新抓取/轻推/等待人接）并把它与 v22 的能量/层级约束叠加？"置信度×可逆性"的释放阈值如何由代价模型导出而非拍脑袋？放置后的物体如何**单调**写入 Obs_t/支撑集（只增障碍，不用支撑扩大机器人自由空间），从而保持 Exec_v23P ⊆ Exec_v22？

## 2. 设计原则（在 P41–P42 基础上新增 P46–P49）

**P46 指代集合律（Reference-Set Law）**
指代输出为集合 `Γ_ref`，须以 ≥1-α_ref 覆盖真实目标区；仅当其并集直径 ≤ d_max、对当前 `Obs_t` 的扫掠裕度 ≥ margin_place、且可达/能量可行时，才称"可操作"。不可操作 ⇒ 只允许**澄清**或**保持**，禁止按 argmax 猜测执行。分组条件校准（用户/任务类）样本不足 ⇒ 弃权。**推论**：指代失效只会把执行退回 v22 的"不放置"保守态。

**P47 放置承诺律（Placement Commitment Law）**
释放（松手）是独立动作，须同时满足：(i) StabC 在**释放瞬态 ∪ 扰动集**上鲁棒裕度 ≥ 0 且经 conformal 校正后 ≥ margin_req；(ii) 支撑有效（高度/坡度不确定度在界内，遮挡处按已知接触点保守估计）；(iii) 若稳定裕度处于边缘或不可逆，则 RevC 要求 `U_undo ≥ τ_commit`，否则禁止释放或降级为"放置-保持-请求帮助"。释放后物体以 `CertBox_place` **单调加入** `Obs_t`；支撑信息只用于未来放置，**不得**用于扩大机器人自身自由空间。任何失效 ⇒ 保持夹持/退回。

**P48 模态独立律（Modality Independence Law）**
多模态一致只有在**有效独立模态数** `n_eff ≥ 2` 或"联合注意接地的显式确认"成立时才计为共识；否则视为单模态，必须弃权/澄清。`n_eff` 由校准探针上的误差相关矩阵参与率给出，并取置信下界。**分歧**不丢弃：它用于收紧 `Γ_ref` 并触发澄清。

**P49 可逆性优先律（Reversibility-First Law）**
释放阈值由代价模型决定：`release ⇔ E[cost | evidence] < C_ask`，其中错误不可逆放置的代价 `C_bad` 被 `(1 - P(recover | U_undo))` 折减。故所需置信度随 `U_undo` 减小而单调升高；同等证据下优先选择"可反悔的放置"（更慢释放/靠近边缘内/可重抓位姿）。

## 3. 与基线的接口（如何退化）

- RefC 失效（样本不足/域外/Γ 不可操作）⇒ 不放置、请求澄清 ⇒ 比 v22 更保守；
- StabC 失效（支撑被遮挡/软滑面/仿真外）⇒ 保持夹持或请求人接 ⇒ 不退化为"盲目放"；
- RevC 失效（U_undo < τ_commit）⇒ 禁止释放，转放置-保持 ⇒ 子集；
- MIC 失效（n_eff < 2 且无接地确认）⇒ 单模态处理，回到 v22 的保守确认门槛 ⇒ 子集；
- CG 失效 ⇒ 不执行释放，保持 v22 的运动/能量约束 ⇒ 子集；
- 全部失效 ⇒ 完全回退 v22 ⇒ `Exec_v23P ⊆ Exec_v22 ⊆ Exec_v21 ⊆ …`（引理 166）。
- **安全继承**：RefC/StabC/RevC/MIC 均为准入谓词的合取项；放置的世界更新只增障碍；不满足时不释放（保持夹持本身是 v22 可行态）。因此执行域单调收缩。

## 4. 预期贡献

1. **指代证书化**：把"人指哪儿"从 argmax 猜测升级为带覆盖率的集合 + 可操作判据 + 显式澄清，给出"分歧即信息"的使用方式；
2. **释放瞬态稳定证书**：首次把放置稳定性扩展到释放过程与有界扰动，并用 conformal 显式处理仿真-现实尾部差；
3. **可逆性/反悔预算**：把"不可逆"变成可量化证书，导出"置信度×可逆性"的释放阈值，缓解 v22 的活性坍缩；
4. **模态独立性证书**：用误差相关矩阵的有效模态数替代原始票数，封堵"相关多模态一致"的假共识；
5. **联合注意确认**：把确认本身当作需接地的模态，防止对"别的问题"的 yes 被误当许可；
6. **HPC-P 统一门与单调世界更新**：`Exec_v23P ⊆ Exec_v22` 闭环，放置只增障碍、不用支撑扩自由空间。

## 5. 本轮最大风险

**一句话**：StabC 的 conformal 覆盖建立在"支撑面物理保真 + 扰动分布可采样"之上，而软/滑/斜面、释放瞬时的人为碰撞、以及被遮挡的桌沿恰是校准集里最稀缺的尾部；同时多模态若共享视觉骨干，MIC 估出的独立性也会被同源误差高估——机器人可能以"统计合规"的方式，把物体放到它以为稳、实际会倒的位置，即**释放瞬态的尾部幻觉与相关模态的假独立**。

## 1. 关键算法骨架（在 IP-431–435 骨架上扩展）

```python
# IP-436 指代证书：集合值 conformal + 可操作判据 + 显式澄清
class ReferenceCertificate:
    def __init__(self, encoder, calibrator, alpha_ref=0.01,
                 d_max=0.15, margin_place=0.02, n_min=200):
        self.encoder = encoder          # 语言+手势+注视联合打分器
        self.calib = calibrator        # 分组条件 split conformal
        self.alpha_ref = alpha_ref
        self.d_max = d_max
        self.margin_place = margin_place
        self.n_min = n_min

    def candidate_regions(self, utterance, scene):
        # 支撑面 × 空间关系 × 可供性；先验只生成候选，不做自由空间扩张
        regions = scene.support_regions()
        return [r for r in regions
                if scene.relation_ok(utterance, r) and scene.affordance_ok(r)]

    def predict_set(self, utterance, gesture, gaze, scene):
        cands = self.candidate_regions(utterance, scene)
        if not cands:
            return RefSet(gamma=set(), actionable=False, reason="NO_CANDIDATE")
        scores = {r: self.encoder.score(utterance, gesture, gaze, r)
                  for r in cands}
        group = self.calib.group_of(utterance)          # 用户/任务类
        if self.calib.n[group] < self.n_min:
            return RefSet(gamma=set(cands), actionable=False,
                          reason="LOW_GROUP_SAMPLES")
        q = self.calib.quantile(group, self.alpha_ref)
        gamma = {r for r, s in scores.items() if s <= q}
        if not gamma:                                   # 空集 => 全域保守
            gamma = set(cands)
        # 可操作：并集直径 <= d_max 且扫掠裕度足够；否则只能澄清
        action_ok = (diameter(union(gamma)) <= self.d_max and
                     scene.swept_clearance(gamma) >= self.margin_place)
        reason = "OK" if action_ok else "AMBIGUOUS_OR_TIGHT"
        return RefSet(gamma=gamma, actionable=action_ok, reason=reason)

# IP-437 模态独立性证书：有效独立票数，而非原始票数
class ModalityIndependenceCertificate:
    def __init__(self, probes, alpha_mic=0.05, n_eff_min=2.0):
        self.probes = probes            # 共享探针集（含真实指代/意图）
        self.alpha_mic = alpha_mic
        self.n_eff_min = n_eff_min

    def estimate(self, live_preds):
        # 各模态在同一探针集上的残差（而非单次输出）估计相关结构
        resid = {m: self.probes.residuals(m) for m in live_preds}
        R = correlation_matrix(resid)
        lam = eigvalsh(R)
        n_eff = (lam.sum() ** 2) / (lam ** 2).sum()
        n_lcb = bootstrap_lcb(n_eff, resid, self.alpha_mic)
        return MIC(n_eff=n_lcb, rho=R,
                   independent=(n_lcb >= self.n_eff_min))

# IP-438 放置稳定证书：静态 + 释放瞬态 + 有界扰动
class PlacementStabilityCertificate:
    def __init__(self, sim, calibrator, delta_stab=0.01,
                 margin_req=0.01, perturb_set=None):
        self.sim = sim
        self.calib = calibrator        # 仿真-现实稳定残差 conformal
        self.delta_stab = delta_stab
        self.margin_req = margin_req
        self.D = perturb_set or default_perturbations()

    def support_from_cloud(self, cloud, region):
        plane = fit_plane(cloud, region)
        eps_h = plane.height_uncertainty      # 高度不确定度
        theta = plane.slope
        if eps_h > EPS_H_MAX or theta > THETA_MAX:
            return None                       # 支撑不可信 => 不释放
        # 只取已知接触点；被遮挡处不臆测为支撑
        return SupportPolygon(plane, contact_points=cloud.known_contacts(region))

    def static_margin(self, obj, pose, support, mu):
        contact = contact_points(obj, pose, support)
        poly = convex_hull(contact)
        m_s = signed_distance(obj.com_projection(pose), poly)   # 内正外负
        m_f = mu - required_friction(obj, pose, support)
        return min(m_s, m_f)

    def robust_margin(self, obj, pose, support, release_traj, mu):
        # 释放瞬态 + 扰动集上的最坏裕度；任一时刻失稳即失败
        worst = float("inf")
        for p in release_traj.sample_states():
            for delta in self.D.sample(p):
                m = self.static_margin(obj, p.perturb(delta), support, mu)
                worst = min(worst, m)
        return worst

    def certify(self, obj, pose, support, mu, release_traj):
        if support is None:
            return StabCert(ok=False, margin=-float("inf"),
                            reason="SUPPORT_UNTRUSTED")
        m = self.robust_margin(obj, pose, support, release_traj, mu)
        # 用仿真-现实稳定残差分位校正；支撑类样本不足则视为不可证
        corr = self.calib.residual_quantile(support.cls, self.delta_stab)
        if corr is None:
            return StabCert(ok=False, margin=m, reason="TAIL_NO_SAMPLES")
        m_hat = m - corr
        ok = m_hat >= self.margin_req
        return StabCert(ok=ok, margin=m_hat,
                        reason="OK" if ok else "UNSTABLE")

# IP-439 可逆性证书：反悔预算
class ReversibilityCertificate:
    def __init__(self, reach, dynamics, tau_commit=2.0):
        self.reach = reach
        self.dyn = dynamics
        self.tau_commit = tau_commit

    def undo_budget(self, obj, pose, stab):
        # 物体可能先失稳（t_fall）或先落到不可达/被遮挡（t_lost）
        t_fall = self.dyn.time_to_instability(stab.margin, self.dyn.D)
        t_lost = self.dyn.time_to_unreachable(pose, obj)
        t_regrasp = self.reach.time_to_regrasp(pose)
        return max(0.0, min(t_fall, t_lost) - t_regrasp)

    def certify(self, obj, pose, stab):
        u = self.undo_budget(obj, pose, stab)
        ok = u >= self.tau_commit
        return RevCert(ok=ok, undo=u, irreversible=(not ok))

# IP-440 HPC-P 统一准入门（v22 的 HPC-E 原样保留，只加合取项）
@dataclass
class HPCP:
    hpc_e: HPCE
    ref: ReferenceCertificate
    mic: ModalityIndependenceCertificate
    stab: PlacementStabilityCertificate
    rev: ReversibilityCertificate

    def admits_release(self, cmd, plan, scene, confirm, t):
        # 1) 指代：不可操作 => 只能澄清/保持，绝不按 argmax 放
        refset = self.ref.predict_set(cmd.u, cmd.g, cmd.z, scene)
        ref_ok = refset.actionable
        # 2) 模态独立：独立票数 >= 2 或联合注意接地确认
        mic = self.mic.estimate(cmd.preds)
        confirm_ok = (confirm.valid and confirm.attended
                      and (t - confirm.t) <= TTL_CONFIRM)
        indep_ok = mic.independent or confirm_ok
        # 3) 稳定性：释放瞬态 + 扰动
        support = self.stab.support_from_cloud(scene.cloud, refset)
        sc = self.stab.certify(cmd.obj, cmd.pose, support, scene.mu,
                               plan.release_traj)
        # 4) 可逆性：不可逆时提高稳定要求并要反悔预算
        rc = self.rev.certify(cmd.obj, cmd.pose, sc)
        if rc.irreversible:
            undo_ok = sc.ok and sc.margin >= STAB_IRREV and rc.undo >= self.rev.tau_commit
        else:
            undo_ok = True
        # 5) v22 能量/几何/规范门原样保留
        base = self.hpc_e.admits(plan, plan.x, plan.v, plan.z,
                                 plan.E_res, margin_req=MARGIN)
        ok = base and ref_ok and sc.ok and indep_ok and undo_ok
        return ok, {"ref": refset, "mic": mic, "stab": sc, "rev": rc,
                    "confirm_grounded": confirm_ok}

# IP-441 单调世界更新：释放 = 只增障碍，支撑不扩自由空间
def release_update(obs_t, support_t, obj, pose, refset, t):
    # 用真实目标集合的保守外包生成释放物体的可靠包围盒
```

## 2. 形式推导

**引理 166（v23P 的安全继承）**
若 (i) HPC-P 的每个新证书谓词都以**合取**方式进入准入；(ii) 任一证书失效时的默认动作是"保持夹持/不释放"，而保持夹持属于 v22 的可行态；(iii) 放置的世界更新为 `Obs_t ← Obs_t ∪ {CertBox_place}` 且支撑信息不用于扩大机器人自由空间；则对任意计划 `π`：
`π ∈ Exec_v23P ⇒ π ∈ Exec_v22`，即 `Exec_v23P ⊆ Exec_v22`。
证明：新层只增加合取项（缩小可行集）；PAMWU 只增加障碍（v22 的几何证书在更大障碍集上单调更保守）；RevC 只删除"释放"这个动作，从不加入；任一失效都退化为"保持/退回"，仍落在 v22 内。∎

**引理 167（指代覆盖与"可操作"的含义）**
在组内可交换性下，RefC 满足 `P(r* ∈ Γ_ref) ≥ 1-α_ref`。若 `Γ_ref` 可操作（并集直径 ≤ d_max，且扫掠裕度 ≥ margin_place），则任取 `r ∈ Γ_ref` 执行，所选区与真实目标区距离 ≤ d_max，且当前 `Obs_t` 下不碰撞。
**但必须看清边界**：该保证只覆盖 `r* ∈ Γ_ref` 的分支；以概率 `α_ref`，`r*` 根本不在集合内，而系统无从知道，于是可能"合规地"放错位置——`α_ref` 是不可消除的指代风险下界，不是工程疏漏。∎

**命题 168（释放风险分解与相关模态的假独立）**
设释放失败的事件归因为：
- `R1`：`r* ∉ Γ_ref`（指代覆盖失败）；
- `R2`：StabC 成立但物体仍失稳（稳定尾部失败）；
- `R3`：相关模态被误估为独立，导致错误的"一致确认"；
- `R4`：物体在 `U_undo` 内已不可恢复；
- `R5`：仿真-现实残差落在校准支撑之外。
则
`P(unsafe) ≤ α_ref + p_R2 + p_R3 + p_R4 + ρ_simreal`（并集界），
更精确地，`R1` 与 `R3` 往往正相关（共享视觉骨干时，指代与确认会一起错），令
`γ_mm = P(R1∩R3)/(P(R1)P(R3))`，则
`P(R1∪R3) = α_ref + p_R3 - γ_mm·α_ref·p_R3`。
当 `γ_mm → 1` 时，两路保护退化为一路：Raw-vote 的 CFC++ 会以接近 `α_ref` 的概率把"两票"当成共识。MIC 的作用不是假设 `γ_mm = 0`，而是**在线估计 `n_eff` 并在 `n_eff < 2` 时拒绝把一致计为共识**。∎

**引理 170（有效模态数）**
设模态误差相关矩阵 `Σ_M` 的特征值为 `λ_1 ≥ … ≥ λ_k ≥ 0`。定义参与率 `n_eff = (Σλ_i)² / Σλ_i²`。则 `1 ≤ n_eff ≤ k`；全独立时 `λ_i` 相等，`n_eff = k`；全相关（秩 1）时 `n_eff = 1`。由于有限探针的估计有方差，实际使用 `n_eff^LCB`（bootstrap 下界）并设 `n_eff_min = 2`，使"两个相关模态"不被误计为两票。∎

**命题 169（可逆性阈值）**
令 `p = P(成功 | evidence)`。设澄清代价 `C_ask`，错误不可逆放置代价 `C_bad`，窗口内恢复概率 `P(recover | U_undo)`，恢复动作代价 `C_rec`。则释放的期望代价为
`(1-p)·[1 - P(recover|U)]·C_bad + (1-p)·P(recover|U)·C_rec`。
释放当且仅当该值 `< C_ask`，即
`p > 1 - C_ask / C_bad^eff`，其中 `C_bad^eff = (1 - P(recover|U))·C_bad + P(recover|U)·C_rec`。
由于 `C_bad^eff` 随 `U_undo` 单调下降，**所需置信度随反悔预算增大而单调下降**。推论：一个中等置信但 `U_undo` 很大的放置可以合法执行，而一个高置信但 `U_undo ≈ 0` 的放置必须要求近 1 的置信度或联合注意确认。这正是"置信度 × 可逆性"的门，而非固定的 α。∎

## 3. 实验设计（预注册）

**E1 指代解析（多用户 + 空间关系）**
构造 ≥30 名用户、跨「这里/那里/桌上/杯旁/盒里」五类指代，配抬手/指向/注视。指标：`r*` 覆盖率、弃权率、错误区执行率、澄清次数与耗时。分组条件 conformal 按用户与任务类分层。预注册：held-out 用户上覆盖 ≥ 1-α_ref=0.99；可操作集合上的错误区执行率 < 1%；含糊指代的弃权率显著高于清晰指代（弃权是特性不是缺陷）。

**E2 释放稳定性与尾部（合成 + 真机）**
物体：马克杯/瓶子/纸盒/水果/软袋；支撑：木/玻璃/金属/0–15° 斜面/软泡沫；扰动：释放瞬间 0–5 Ns 随机方向冲量 + 桌面振动；释放轨迹：慢放-张开-回撤。指标：**假稳率**（预测稳但 5 s 内倒）、假不稳率、分位覆盖、最坏 1% 尾部误差。关键约束：假稳率须以单侧置信上界 ≤ δ_stab=0.01；支撑类样本不足时报告"不可证"而非默认稳。预注册：仅仿真会高估软/滑面稳定性；conformal 校正降低假稳但提高弃权；尾部仍是主要误差来源。

**E3 相关多模态对抗（假独立压力测试）**
令手势与语言共用同一视觉骨干，在视觉域做定向扰动，使两路一起指向同一错误区；同时改变光照/遮挡/口音制造部分独立错误。指标：实际联合错误率、`n_eff` 估计与其置信下界、Raw-vote CFC++ 与 MIC-gated 的错误释放率。预注册：共享骨干下 `n_eff` 估计应接近 1，MIC-gated 弃权率上升而错误释放显著下降；Raw-vote 会把相关错误计为共识。

**E4 可逆性与"置信度×可逆性"**
用受控释放-重抓测量 `U_undo`，扫物体/支撑/可达性。比较三种门：仅置信度（固定 α）、置信度+反悔预算、仅反悔预算。指标：不可逆错误放置数、活性（成功放置率）、恢复次数、澄清次数。预注册：置信度+反悔预算在相近活性下取得更低的不可逆错误（Pareto 改进）；大 `U_undo` 场景活性显著高于固定 α。

**E5 联合注意确认**
Wizard-of-Oz：人说"好"可能是在回答放置提议，也可能是在回答无关问题；分「看着提议区/机器人」与「未看」两条件。指标：误释放率、确认接受率、额外澄清数。预注册：联合注意接地显著降低误释放；代价是更多澄清，但澄清代价远小于错误释放。

**E6 安全继承、消融与时延**
变体：v22 / +RefC / +StabC / +RevC / +MIC / full v23P。指标：不安全释放数（应随模块增加单调不增）、活性、准入率、50Hz 控制环 p99 延迟（交互状态机 10Hz 异步注入，控制路径只做 O(1) 查询）。

| 变体 | 不安全释放（期望） | 活性（期望） | 关键观察 |
|---|---|---|---|
| v22 | 基线 | 100% | 能走能放，但不证指代/稳定/可逆 |
| +RefC | ↓ | ↓ | 防猜错，但澄清增多 |
| +StabC | ↓↓ | ↓↓ | 防失稳，软滑面弃权 |
| +RevC | ↓↓ | ↓ | 禁不可逆释放，保持夹持 |
| +MIC | ↓↓ | ↓ | 拒绝相关假共识 |
| full v23P | 预期最低 | 预期 55–75% | 需 E3/E5 验证独立性与接地是否真有效 |

**预注册假设（待验证，非真实测量）**
- H1：full v23P 在 E1–E5 任一场景的"不安全释放"不高于 v22（安全单调性）；
- H2：E2 的仅仿真假稳率在最坏 1% 尾部明显高于真机校准后的上界，支撑类样本不足时必须"不可证"；
- H3：E3 中共享骨干下 `n_eff` 的置信下界 < 2，MIC 能把假共识挡在门外，而 Raw-vote 会放行；
- H4：E4 的"置信度×可逆性"门在相近活性下降低不可逆错误，验证命题 169；
- H5：E5 的联合注意接地显著降低"对别的问题说 yes"导致的误释放；E6 中交互状态机不进入 50Hz 热路径。

## 4. 产物小结

本轮的产物是把 v22 的**运动-能量证书**扩展为 **v23P 的放置-交互承诺层**：`Exec_v23P = Exec_v22 ∩ Fil_ref ∩ Fil_stab ∩ Fil_undo`。新增六个可机械复核的构件（RefC/MIC/StabC/RevC/HPC-P/PAMWU）、五条形式结论（安全继承、指代覆盖边界、释放风险分解、有效模态数、可逆性阈值），以及把"相关多模态假独立"与"释放尾部稳定性"作为一等公民测量的实验 E2/E3/E5。方案不追求"更会猜人指哪儿"，而是把"指代/稳定/可逆/独立"变成**不可被平行打折的合取证据**，让释放只在"有证且可反悔"时发生。

**本轮最大风险**：StabC 的 conformal 覆盖建立在"支撑面物理保真 + 扰动分布可采样"之上，而软/滑/斜面、释放瞬时的人为碰撞、以及被遮挡的桌沿恰是校准集里最稀缺的尾部；同时多模态若共享视觉骨干，MIC 估出的独立性也会被同源误差高估——机器人可能以"统计合规"的方式，把物体放到它以为稳、实际会倒的位置，即**释放瞬态的尾部幻觉与相关模态的假独立**。
