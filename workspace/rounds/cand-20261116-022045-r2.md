# 第 12 轮（新灵感循环第 2 轮；本轮灵感：「原型验证」×「运动规划」）

> **基线**：第 11 轮 MetricVoiceGauge-GSCF-SRA-JSSE（定义 549–561；引理 92–96；实验 E591–E610）。
> 本轮纪律：**验证先于晋升 + 动力学可达中止**。v11 把安全拆进语义场、任务空间、关节空间三重守护，但有两个从未被检验的前提：(a) 所有阈值（τ_sem、γ_min、τ_sra、ε_fk）都是"一次性标定"的常数，其证据来自单一版本、单一数据配比，从未经过一次可审计的"上岗考试"；(b) 中止只是在关节空间做几何插值，FK 到 p* 的期末等价不能保证这条插值在速度/加速度/力矩/ZMP 约束下真的可达。前者是**证据债**（谁批准了这个版本？），后者是**执行债**（这条逃生路线真的跑得通吗？）。两个灵感正好各治一债：「原型验证」把证据变成任意时有效、可撤销的晋升门；「运动规划」把中止从"点到点插值"升级为"带证书的动力学可行管"。铁律不变：任一新模块失效 ⇒ 注入声明中立元 ⇒ 行为严格**等价**或**支配**于 v11，绝不出现新物理行为。

## 0. 直觉与动机

**灵感 1（原型验证 → 双义原型：既是被验证的对象，也是验证的标尺）**
直觉："原型"在本轮有两义，且必须同时用。其一是**工程原型**：候选版本 θ（新权重、重标定阈值、新运动基元库、甚至一行代码）在上线前要离线回放、影子跑、受限 canary、再全量；危险在于研究员会反复偷看指标、提前停、按结果调参，经典显著性检验在这种"偷看"下失效。其二是**类别原型**：用特征空间里的原型点（语义嵌入 + 几何签名 + 动力学签名）作标尺，把"这个场景是不是我验证过的那类场景"变成分布无关的共形检验。核心创新 **原型覆盖证书（PCC）** 用类别原型给出条件覆盖与新颖性 p 值；**时序晋升门（SPG）** 用 e-process + Ville 不等式给出"无论看多少次、何时停，误晋升 ≤ α"的任意时有效门。二者合起来回答 v11 从未回答的问题：**这张证书，是哪个版本、在哪类场景原型上、由哪次验证签发的？** 场景不被任何已签名原型覆盖时，证书不是"置信度低"，而是**无效**——直接收缩，而不是继续用旧余量。

**灵感 2（运动规划 → 中止不是终点，是可执行的管）**
直觉：v11 的中止是"找一个 q_abort 让 FK(q_abort)≈p*，再关节插值过去"。这在运动学上像中止，在动力学上可能根本做不到：插值轨迹可能超速度/加速度/力矩限、破坏 ZMP、穿过自碰撞，或跟踪误差把真实状态带出安全集。运动规划的直觉是：安全不是"目标点"，而是**从当前状态到中止集的一整条可行管**。核心创新 **应急运动管（CMT）**：离线/在线用轨迹优化或动力学采样生成一组**认证运动基元**，每个基元带动力学可行裕度与到 Q_abort 的可达性证书；在线 5Hz 为当前块配一条**应急管**（nominal 轨迹 + escape 策略），50Hz 只检查真实状态是否仍在管内。这把 v11 的中止等价性从"期末位姿相等"升级为"任意时刻的扰动都被困在安全管内、且能在 T_stop 内到达中止集"。

**灵感 3（合流：管是原型的见证，原型是管的适用域）**
直觉：两个灵感不是并列补丁，而是同一张证书的两面。一个原型若声称"这类场景我们验证过"，其验证证据里必须包含**从该类场景任意可达状态到中止集的认证管**；反过来，一条运动基元只允许用在其原型已验证的适用域内。核心原则 **原型-管对偶（Prototype–Tube Duality）** 写作：`场景被覆盖 ⇔ 存在为该原型签名且包含当前状态的认证管`。这让 v11 的三重守护第一次有了共同的**版本坐标**与**可达性锚点**，也把"三守护同时失效"从"只能急停"改造成一条分级响应链：**收缩 → 重规划 → 受控停止**。

三者咬合：PCC 给条件覆盖与版本索引，SPG 给晋升/撤销的统计门，CMT 给动力学可达的逃生管；v11 的块证书 Ĉ⁺⁺ 升级为**验证-可达证书 Ĉ^✶ = (ĝ_min, ê_max, γ̂_grasp, β_GSCF, n_t, n_t^reason, Q_abort, p_t^proto, cov_t, θ*, A_t, G_t)**。

## 1. 研究问题（轮次升级版）

- **Q1（版本可问责）**：如何把"哪个候选版本可以上岗"形式化为预注册的、任意时有效的时序检验，使误晋升率 ≤α、canary 暴露有硬上界、且回归可被自动撤销，同时不改变运行期控制语义？
- **Q2（原型条件覆盖）**：如何用轻量类别原型给出分布无关的条件覆盖证书 p_t^proto 与覆盖位 cov_t，使未覆盖场景一律收缩（绝不扩权），且在 ε-污染/域漂移下覆盖损失有显式上界？
- **Q3（动力学可达中止）**：如何用认证运动基元与应急管，把中止从 FK 端点等价升级为"管包含 + T_stop 内可达"，并在 5Hz/50Hz/1kHz 与 25W 预算内完成规划、检查与退化？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 验证先于晋升律（Validation-before-Promotion, SPG）**
任何版本、阈值、基元库、配比的变更，未通过预注册的任意时有效门（e-process + Ville）不得晋升；晋升与撤销都入台账；门失效 ⇒ 冻结在当前已签名版本，永不"默认接受新版本"。

**P17 原型条件律（Prototype-Conditional Coverage, PCC）**
每张证书都以场景原型覆盖为条件：cov=0 ⇒ 收缩到 Π_r（K_eff≤2），不许用未验证的余量；原型是**数据**不是代码，会衰减、要再验证；未覆盖 ≠ 低置信，而是**证书无效**。

**P18 动力学可达律（Dynamically-Reachable Abort, CMT）**
每个被接受的块必须携带一条认证的动力学可行逃生管到 Q_abort；运动学端点相等不构成中止保证；出管 ⇒ 重规划，重规划失败 ⇒ 受控停止；管只会剪枝、不产生新动作。

## 3. 与基线的接口（如何退化）

- **PCC 失效**（原型库不可用/特征提取超时/共形校准缺失）⇒ p_proto←1、cov←1，等价 v11（失去覆盖门，余量与门控原样回退）；
- **SPG 失效**（验证服务不可用/台账缺口）⇒ 冻结在已签名 θ_0、禁止晋升与撤销（运行期控制语义不变，等价 v11；已撤销者保持 Π_r）；
- **CMT 失效**（QP/轨迹优化超时、基元库损坏、跟踪误差界失效）⇒ 回退 v11 关节插值中止 + JSSE 急停保持（v11 Level-3，行为 ⊆ v11）；
- v11 的 GSCF/SRA/JSSE/STF/NRB/AC/ID/MW 失效沿 v11 九级退化链原样保留；所有新增安全门 φ^elig=false，永不消融。

## 4. 预期贡献

1. **可问责的版本晋升**：把 v11"一次性标定即上线"的证据债，升级为任意时有效、可撤销、全留痕的 SPG（引理 98、102）；
2. **原型条件覆盖**：用共形原型把 τ 的经验校准换成分布无关的条件覆盖证书，未覆盖即收缩（引理 97）；
3. **动力学可达中止**：用认证运动基元与应急管替换几何插值，给出带跟踪误差的鲁棒可达保证（引理 99），并给出原型-管对偶下的联合保守性（引理 100–101）；
4. **E611–E630** 覆盖共形校准、偷看下误晋升、canary 暴露、管包含、可达中止、原型-管对偶、联合压测与退化链。

## 5. 本轮最大风险

**一句话**：PCC 的覆盖保证依赖校准集与部署场景在特征空间的可交换性，CMT 的管不变量依赖跟踪误差界 ε_track 与动力学模型——两者又共享同一台机器人、同一批标定数据；一旦系统性标定漂移让"特征位移"与"跟踪误差增长"同向发生，PCC 会认为场景仍被覆盖、CMT 会认为管仍包含真实状态，而 SPG 因历史验证数据同源也无法察觉，系统可能在"已签名版本 + 已覆盖原型 + 已认证管"三重绿灯下执行一条实际不可达的中止轨迹。

**新增定义 563（共形覆盖证书）** 对查询特征 φ(x)，p_t^proto 按定义表中公式计算；cov_t=1 当且仅当 p_t^proto>α_p、φ(x) 落在某个原型适用域内、且该原型的签发版本等于当前门状态 G_t 的签名版本。cov_t=0 ⇒ 证书无效 ⇒ K_eff←2（Π_r），**而非**继续使用 β_GSCF。共形 p 值只要求可交换性，不假设高斯噪声模型（对比 v11 的 γ_min 解析式）。

**新增定义 564（时序晋升门）** 预注册协议 Π_val=(α, δ, 阶梯 L0–L3, 每级最小样本, 停止规则)。晋升在某级用 e-process：若 E_τ(θ‖θ_0)≥1/α 且该级样本量达标，则晋升；任一级可因风险回归而**撤销**。门状态 G_t 驱动定义 563 的签发匹配：G_t 不是 signed_off(θ) ⇒ 依赖 θ 的证书一律无效。

**新增定义 565（验证阶梯与 canary 暴露）** L0 离线回放（无执行）；L1 影子（观测但不 actuate）；L2 canary（在 Π_r 受限剖面下执行，暴露预算 H_c 步或 H_c 次任务）；L3 全量。L2 的所有执行都走 CMT 应急管，且 NRB 的 Π_r 强制开启，故 canary 的最坏物理行为 ⊆ v11 Π_r。

**新增定义 566（认证运动基元）** 基元由离线轨迹优化/动力学采样生成，必须通过：位置/速度/加速度/jerk 限、力矩限、自碰撞、ZMP∈support_polygon、以及终止于 Q_abort（或可续接到另一基元）。每个基元记录 m_i 与适用原型集 proto(π_i)。

**新增定义 567（应急管规划）** 在 5Hz 块生成期，给定当前状态 x_t、候选块 ζ 与最近中止集 Q_abort，规划器返回 π_nom（执行块）与 π_escape（到 q_abort∈Q_abort 的认证基元拼接），并构造 T^ε 与 A_t。**规划失败或超预算 ⇒ 不生成块**，直接进入受控停止，而非带病执行。

**新增定义 569（原型-管对偶）** 对任意原型 j 与基元 π_i：π_i 可用于 j 当且仅当 proto(π_i)∋j ∧ dom(π_i)⊇dom_j。对偶性要求：若 cov_t=1 由原型 j 签发，则 A_t 必须由 proto(π_i)∋j 的基元构造；否则证书 Ĉ^✶ 无效（宁可收缩，不许借用无关基元）。

# IP-365 PrototypeCoverageCertifier：原型覆盖证书器
class PrototypeCoverageCertifier:
    def __init__(self, bank, calib_distances, alpha_p=0.05, drift_alpha=0.01):
        self.bank = bank                      # [(mu, Sigma_inv, n, dom, theta_sign)]
        self.calib = sorted(calib_distances)  # 校准原型距离（共形）
        self.alpha_p = alpha_p
        self.drift_eprocess = EProcess(alpha=drift_alpha)

    def features(self, obs, gscf, dyn):
        return concat(obs.semantic_embedding_int8,   # ≤32d
                      gscf.geo_signature(obs),        # ≤16d
                      dyn.signature(obs))             # ≤16d (v, load, contact)

    def distance(self, phi):
        d = min(math.sqrt((phi - mu) @ Sinv @ (phi - mu))
                for (mu, Sinv, _, _, _) in self.bank)
        return d

    def certify(self, phi, theta_sign):
        d = self.distance(phi)
        p = (1 + sum(1 for c in self.calib if c >= d)) / (len(self.calib) + 1)
        j = self._nearest_covered(phi, p)     # 最近且 dom 包含 phi
        cov = int(p > self.alpha_p and j is not None
                  and self.bank[j].theta_sign == theta_sign)
        self.drift_eprocess.observe(d)
        return ProtoCert(p=p, cov=cov, j=j, theta_sign=theta_sign)

    def drift_alarm(self):
        return self.drift_eprocess.rejected()  # ⇒ 定义 575 撤销签名


# IP-366 SequentialPromotionGate：时序晋升门（e-process + Ville）
class SequentialPromotionGate:
    def __init__(self, alpha=0.05, delta=0.01, delta_min=0.01, protocol=None):
        self.alpha, self.delta, self.delta_min = alpha, delta, delta_min
        self.protocol = protocol or default_ladder()   # L0..L3, min_n, stop rule
        self.E = 1.0
        self.n = 0
        self.state = 'signed_off'

    def observe_pair(self, loss_incumbent, loss_candidate, lam):
        # λ_s 可预测且 ∈[0,1/(1+δ)]；H0: E[ℓ_0−ℓ] ≤ δ
        self.E *= (1 + lam * (loss_incumbent - loss_candidate - self.delta))
        self.n += 1

    def can_promote(self):
        stage = self.protocol.current_stage
        return (stage.min_n <= self.n) and (self.E >= 1 / self.alpha)

    def promote(self, theta):
        if not self.can_promote():
            return False
        if robust_improvement(theta) < self.delta_min:
            return False                      # 定义 577：无差异不晋升
        self.state = ('signed_off', theta)
        return True

    def revoke(self, theta):
        self.state = ('revoking', theta)      # ⇒ 定义 564/575


# IP-367 ContingentMotionTube：应急运动管（5Hz 规划 + 50Hz 检）
class ContingentMotionTube:
    def __init__(self, primitives, dyn, C_q_safe, Q_abort,
                 epsilon_track, gamma_min_tube=0.02, T_stop=0.8):
        self.lib = primitives                  # [(pi, m_i, proto_set, end_q)]
        self.dyn, self.safe, self.Q_abort = dyn, C_q_safe, Q_abort
        self.eps, self.gamma_min, self.T_stop = epsilon_track, gamma_min_tube, T_stop
        self.healthy = True

    def plan(self, x, chunk, proto_j):
        if not self.healthy:
            return None                        # ⇒ Level-C：v11 插值 + 急停
        # 1) 只允许用于当前原型 j 的基元
        cands = [p for p in self.lib if proto_j in p.proto_set]
        # 2) 验收：T^ε ⊆ C_q_safe，且可从管内到达 Q_abort
        tube = self._certified_tube(x, chunk, cands)
        if tube is None:
            return None                        # 不生成块，进入受控停止
        return tube                            # (pi_nom, pi_escape, A_t, T_i^eps)

    def _certified_tube(self, x, chunk, cands):
        best = None
        for pi in cands:
            T = self._tube(pi, self.eps)
            if not self._subset_safe(T):
                continue
            if not self._can_reach(T, self.Q_abort, self.T_stop):
                continue
            A = self._escape_certificate(pi, T, self.T_stop)
            if best is None or A.gamma_tube > best.gamma_tube:
                best = (pi, A)
        return best

    def tube_ok(self, x):
        if not self.healthy:
            return False
        return (self._in_tube(x)
                and self._tube_margin(x) >= self.gamma_min
                and self._reach_margin(x) >= 0)

    def replan_or_stop(self, x):
        tube = self.plan(x, chunk=None, proto_j=self.current_proto)
        if tube is None:
            return ('stop', self._controlled_stop(x))   # R3
        return ('replan', tube)                           # R2


# IP-354（升级）：验证-可达证书分块执行器
class CertifiedChunkExecutor(StructuredChunkCertifier):
    def generate_chunk(self, state, ctx, stf, gscf, sra, nrb, pcc, spg, cmt):
        K = self.effective_K(ctx, stf, gscf, pcc, spg)     # 定义 539 v12
        if K == 1:
            return self._single_step_fallback(state)
        best = None
        for cand in self.policy.sample_sequences(state, K, n=64):
            pred = self.Fq.rollout(state, cand)
            beta_gs = self.beta_base + self.lam * gscf.field_on_footprint(pred.corridor)
            g_min = pred.min_clearance - beta_gs
            e_max = pred.max_effort + beta_gs
            if g_min < self.d_safe or e_max > state.tau_eff:
                continue
            # PCC：覆盖与版本签名
            pc = pcc.certify(pcc.features(ctx.obs, gscf, state.dyn), spg.signature)
            if pc.cov == 0:
                continue                                   # 未覆盖 ⇒ 不生成候选
            # CMT：为本块配认证应急管
            tube = cmt.plan(state.x, cand, pc.j)
            if tube is None:
                continue
            pts = self._abort_points(state, cand, pred)
            chunk = Chunk(cand, Cert(g_min, e_max, beta_gs, pts, pc, tube), pts)
            chunk, _ = nrb.review_chunk(chunk, stf, ctx)   # v11 继承
            if chunk is None:
                continue
            n_reason, _ = sra.reason_on_chunk(chunk, stf, gscf, ctx)
            chunk.cert.n_reason = n_reason
            if not all(n_reason):
                continue
            chunk.cert.A_t = tube.A
            chunk.cert.Q_abort = {p: cmt.map_abort(p) for p in pts}
            best = self._argmax(best, chunk)
        return best or self._single_step_fallback(state)

    def midchunk_guard(self, chunk, k_exec, live, stf, gscf, nrb, jsse, pcc, cmt):
        """50Hz 七检 ≤0.7ms；返回 continue/R1/R2/R3"""
        if not chunk.cert_still_valid(live):
            return self._abort(chunk, k_exec, jsse)                 # i
        if live.nearest_clearance - self.d_brake(live.speed) - self.d_safe \
                < chunk.remaining_len(k_exec):
            return self._abort(chunk, k_exec, jsse)                 # ii
        if stf.surprise_near(live.pose) > stf.tau_sem:
            return self._abort(chunk, k_exec, jsse)                 # iii
        if nrb.fast_norms(live).violated:
            return self._abort(chunk, k_exec, jsse)                 # iv
        if not gscf.geo_ok_near(live.pose):
            return self._abort(chunk, k_exec, jsse)                 # v
        pc = pcc.certify(pcc.features(live, gscf, chunk.state.dyn),
                         chunk.cert.theta)
        if pc.cov == 0:
            return ('R1', 2)                                        # vi 收缩
        if not cmt.tube_ok(live):
            verdict, tube = cmt.replan_or_stop(live)
            return (verdict, tube)                                  # vii
        return ('continue', k_exec + 1)

    def _abort(self, chunk, k_exec, jsse):
        p_star = chunk.nearest_abort_point(k_exec)
        return ('abort', jsse.map_abort(p_star))

## 4. 推导

**引理 97（共形原型覆盖的有效性与漂移敏感性）**
设 (A1) 校准特征与部署查询在同一原型域内可交换；(A2) 共形 p 值按定义 563 构造，评分函数固定。则对任意 α_p，P(p_t^proto≤α_p)≤α_p；等价地，覆盖率的期望 ≥1−α_p（分布无关，不假设高斯噪声）。(A3) 若部署分布相对校准分布的总变差 ≤ε_TV，则由耦合论证，任意事件概率差 ≤ε_TV，故 P(误判新颖)≤α_p+ε_TV、覆盖 ≥1−α_p−ε_TV。证明：共形 p 值的秩均匀性在可交换性下成立（标准结论）；TV 敏感性由最优耦合直接给出。**对比 v11**：γ_min 的解析下界依赖噪声模型（A1 of Lemma 92），PCC 只依赖可交换性；模型错时 v11 的 ε_geo 失效，而 PCC 的保证只随 ε_TV 线性退化。∎

**引理 98（时序晋升门的任意时有效性）**
设配对损失 ℓ_t(θ)∈[0,1]，λ_t 为可预测赌注且 λ_t∈[0,1/(1+δ)]。定义 E_t=∏_{s≤t}(1+λ_s(ℓ_s(θ_0)−ℓ_s(θ)−δ))。在 H0：E[ℓ_s(θ_0)−ℓ_s(θ)]≤δ 下，E_t 是非负上鞅且 E_0=1。由 Ville 不等式，对**任意**停止时间 τ（含"边看边停"），P_{H0}(∃t:E_t≥1/α)≤α。因此 SPG 只在 E_τ≥1/α 时晋升，则误晋升率 ≤α，与偷看次数、提前停无关。canary 全程运行在 Π_r 且走 CMT 管，最坏物理行为 ⊆ v11 Π_r，故暴露被限制在受限剖面内；晋升事件的错误概率 ≤α 直接给出暴露风险的期望上界。∎

**引理 99（应急管的包含性与鲁棒可达中止）**
设 (B1) 跟踪误差 ‖x_t−x_t^nom‖≤ε_track 以概率 ≥1−δ_t 成立（E619 标定）；(B2) 认证管满足 T_i^{ε}⊆C_q_safe；(B3) 对任意 x∈T_i^{ε}，存在认证 escape 轨迹在 T_stop 内到达 Q_abort；(B4) 规划器在时限内返回或显式失败。则从 x_0∈T_i^{ε} 出发执行应急管：∀t≤T_stop，x_t∈C_q_safe；且以概率 ≥1−δ_t−δ_plan 在 T_stop 内到达 Q_abort 的 ε_fk 邻域。证明：对 t 归纳。基准 x_0∈T_i^{ε}。若真实误差满足 B1，则 x_t∈T_i^{ε}，由 B2 在安全集内；一旦任一检失败，切换到 escape 基元，由 B3 在 T_stop 内可达；B4 保证不会无限等待。失败概率由 B1 与规划失败的并集界给出。**对比 v11**：v11 只保证 FK(q_abort)=p*±ε_fk（期末位置），不保证动力学可行、不保证途中不越界、不覆盖跟踪误差；引理 99 三点全包。∎

**引理 100（原型-管对偶的支配性与退化等价）**
(i) CMT 只在满足 C_q_safe 的基元中选择并加管约束，动作集合 ⊆ v11 可行集；(ii) CMT 失效 ⇒ 回退 v11 插值中止 + JSSE 急停（v11 Level-3）；(iii) PCC 与 SPG 是**门**，只能拒绝/收缩/撤销，不能扩权，故运行期可行集 ⊆ v11；(iv) SPG 失效 ⇒ 冻结 θ_0、禁止晋升，运行期行为与 v11 相同；(v) 所有新增安全门 φ^elig=false。因此 v12 的物理行为集合 ⊆ v11（支配），且任一模块失效均有声明退化路径。∎

**引理 101（联合保守性与 v11 三守护同时失效风险的拆除）**
把危险事件按 (cov_t, V_t^tube) 二分为四格。cov=0 ⇒ K_eff←2（Π_r），危险率由 v11 Π_r 兜底；V_t^tube=0 ⇒ R2/R3（重规划/受控停止），不执行原块；cov=1∧V=1 ⇒ 仍受 v11 三重守护与 Ĉ^✶ 约束。因此危险事件要求：v11 三守护失效（概率 ≤ε_joint，引理 96）∨ 覆盖虚假为 1（≤α_p+ε_TV，引理 97）∨ 管虚假有效（≤δ_t+δ_plan，引理 99）。并集界：
```
P(danger) ≤ ε_joint + α_p + ε_TV + δ_t + δ_plan.
```
**要点**：v11 的风险是"遮挡+动态+标定漂移同时发生 ⇒ 无优雅路径，只能急停"；v12 把这三类失效拆到独立通道（统计覆盖、版本签名、动力学可达），并给出 R1→R2→R3 的分级响应，使系统在部分通道失效时仍能**先收缩、再重规划、最后才停**。∎

**引理 102（验证的样本复杂度与"无免费晋升"）**
对风险差 δ、置信 α、功效 1−β，任何检验区分 H0:risk(θ)≥risk(θ_0) 与 H1:risk(θ)≤risk(θ_0)−δ 都需要 N=Ω(δ^{-2}·log(1/(αβ))) 个样本（Le Cam/信息论下界）。因此 SPG 设定最小可分辨差 δ_min：当实测改进 <δ_min 时一律判"不晋升"（定义 577），避免用有限数据宣称微小改进。**含义**：验证延迟与数据预算是显式成本，不是可以省略的工程细节；v12 明确把"证据不够"变成"维持基线"，而不是"糊弄上线"。∎

**引理 103（预算与复杂度守恒）** PCC 每观测 O(M d)（M≤512, d≤64）≤0.15ms；SPG 运行监控 O(1)≤0.1ms；CMT 规划 5Hz ≤6ms（摊销 ≤1.2ms）、50Hz 管检查 O(#constraints)≤0.05ms；七检合计 ≤0.7ms；新增内存 ≤1.1MB、功耗 ≤150mW，均落在 v11 预留的 25W/4GB 内（E622/E602）。**无 O(n²) 新瓶颈**：原型距离与基元选择均为线性扫描，可进一步用 KD-tree/量化索引，但当前规模无需。∎

## 8. 本轮最大风险

**一句话**：PCC 的覆盖保证依赖校准集与部署场景在特征空间的可交换性，CMT 的管不变量依赖跟踪误差界 ε_track 与动力学模型——两者又共享同一台机器人、同一批标定数据；一旦系统性标定漂移让"特征位移"与"跟踪误差增长"同向发生，PCC 会认为场景仍被覆盖、CMT 会认为管仍包含真实状态，而 SPG 因历史验证数据同源也无法察觉，系统可能在"已签名版本 + 已覆盖原型 + 已认证管"三重绿灯下执行一条实际不可达的中止轨迹。
