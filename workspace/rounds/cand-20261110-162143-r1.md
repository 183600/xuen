# 第 46 轮（承接第 46 轮产物 v23；本轮灵感：通用机器人平台 × 边缘计算） · Edge-Cert Fabric：时效租约驱动的跨本体证书迁移与边缘记忆账本（五层架构 v11）

> 承接第 46 轮产物 v23（MVR × VAD × SAB 记忆-语音-安全闭环）。v23 已让机器人能在记忆命中时复用历史感知决策、并用语音-姿态绑定守住执行安全，但隐含假设 H5：**所有感知、校准与决策都在同一台机器人本地完成，且数据“即刻可用”**。通用机器人平台意味着同一套技能要在异构本体（不同自由度、传感器布置、动力学参数）间复用；边缘计算意味着把 VLM、共形校准、记忆库下沉到边缘节点，以换取算力与共享，但引入了网络抖动、排队时延、分区与数据陈旧。两个灵感词精确命中 H5：**通用机器人平台**把“证书是否可跨本体迁移”变成一等公民；**边缘计算**把“证书所依赖的数据有多新”变成可失效的租约。二者耦合出新问题：**当一条记忆/证书从本体 A 迁移到本体 B、且由边缘节点在若干百毫秒前生成的数据支撑时，姿态证书的 soundness 会在没有任何报错的情况下被悄悄破坏**。

## 0. 直觉与动机

**灵感 1（通用机器人平台 → 证书不是普适真理，而是带本体指纹的局部断言）**
直觉：同一张姿态证书在 A 机器人上覆盖 99%，换到自由度更少、相机外参不同的 B 上可能只有 80%。证书必须携带“本体指纹” e=(运动学结构、传感器布置、动力学参数)，跨本体复用要么按距离膨胀半径，要么重新校准。平台化的价值不是“一次训练处处运行”，而是“**可证明地知道哪里能运行、膨胀多少**”。

**灵感 2（边缘计算 → 新鲜度是第三种会过期的根信任）**
直觉：边缘推理再准，若结果基于 300ms 前的帧，也只是一张“关于过去的证书”。v10 已有姿态租约 ℓ_p 与能量租约 ℓ_e 两条根信任；边缘化后必须新增**时效租约 ℓ_τ**（信息年龄 AoI）。三条租约任一过期，依赖它的证书立即失效，形成 fail-closed 的三脚架。卸载决策因此不是“哪里算得快”，而是“**在可接受时效内，哪个算力层级能给出最窄且仍可覆盖的证书**”。

**灵感 3（二者耦合 → 边缘证书织物与记忆账本）**
直觉：边缘节点天然适合做“全机队的共形校准中心 + 共享记忆账本”。但共享即污染面：一条 A 本体上成功、却因姿态不稳而代价很高的记忆，被 B 本体按语义相似度检索到，就会发生“证书洗白”。因此账本条目必须带**本体指纹、时效戳、证书哈希、provenance**，准入时做三方校验：本体距离够近、时效够新、证书哈希在当前条件下可复算。

**架构升级**：在 v10 四层（根信任/L1 几何/L2 上下文/L3 CAR 守卫/L4 采集）上，把根信任层扩为**三租约（姿态 ℓ_p、能量 ℓ_e、时效 ℓ_τ）+ 本体指纹 e**，并新增**边缘证书织物层（Edge-Cert Fabric, ECF）**统一编排卸载、联邦校准与账本准入。五层 v11：L0 三租约与本体指纹；L1 几何层按 (m,o,e) 条件化半径；L2 上下文层并入网络状态与机队校准缺口；L3 CAR 守卫加入 ℓ_τ 与 d_E；L4 DCL 采集任务按“校准缺口 × 本体覆盖”排序。

## 1. 形式化定义（增量：定义 59–64）

**定义 59（时效租约与信息年龄）**
设帧生成时刻 τ_gen，本地/决策端接收时刻 t。信息年龄 Δ(t)=t-τ_gen。时效租约
ℓ_τ=(τ_gen, Δ_max(φ,m,e), ε_τ, λ_s)，
其中 Δ_max 为任务 φ、模态 m、本体 e 允许的最大年龄，λ_s 为抖动放大系数。预测年龄 Δ(t+δ)=Δ(t)+δ+λ_s·ĵ。租约有效当且仅当
Δ(t+δ) ≤ Δ_max(φ,m,e) 且 P(Δ(t+δ)>Δ_max | 历史抖动) ≤ ε_τ。
失效时所有以该帧为证据的姿态证书暂停签发，CAR 退化为保守姿态盒或 fail-closed。

**定义 60（本体指纹与可迁移距离）**
e=(D_H, S, Θ)：D_H 为运动学结构编码（自由度/关节类型/连杆），S 为传感器配置（内外参、视场、基线），Θ 为动力学参数。距离
d_E(e_A,e_B)=w_1‖D_H^A-D_H^B‖ + w_2·J_S(S_A,S_B) + w_3‖Θ^A-Θ^B‖。
**迁移膨胀假设**：若 A 的证书半径为 r_ω^A，则迁移到 B 的保守半径为
r_ω^B ≤ r_ω^A·(1+κ·d_E) + L_E·d_E。
仅当 d_E ≤ d_E^max(φ) 且历史 outcome=success 且时效租约有效时，允许“免校准迁移”；否则强制本地重校准。

**定义 61（边缘卸载决策）**
卸载选项 o∈{local, edge, split}。端到端时延
L_o=L_comp(o)+L_net(o)+L_queue(o)，
其分布由网络探针与队列长度在线估计。卸载策略
o^* = argmin_{o} [ r̄_ω(m,o,e) + λ_τ·P(Δ>Δ_max|o)·Risk_safe + λ_e·E_o ] / [ q_o·Coverage_gain ]
s.t. L_o(t) ≤ L_budget(φ)，E(t+δ|o) ≥ E_min。
其中 r̄_ω 为期望证书半径，q_o 为模型容量带来的分层可观测性增益。**关键**：更大的边缘模型可能给出更窄半径，但若 P(Δ>Δ_max) 抬头，则安全惩罚项会否决卸载。

**定义 62（五元联合证书）**
J_t=(P_t, ℓ_p, ℓ_e, ℓ_τ, e, m_t, o_t)。**联合 soundness**：
P( X_t∈P_t | ω_t, m_t, o_t, e, ℓ_p,ℓ_e,ℓ_τ 全部有效 ) ≥ 1-α_p。
**跨本体-时效边际转移**：
m_true ≥ m̂ - L_φ·rad(P_t) - L_e·(B_min-E(t))_+ - L_τ·(Δ(t)-Δ_max)_+ - L_E·d_E(e,e_ref)。
任一项非零都只能使界更保守；三项租约任一失效则 J_t 作废。

**定义 63（分层联邦共形校准）**
校准组 g=(本体簇, ω 层, 模态 m)。本地非一致性分数 s_i，机队先验池。加权分位数
Q_{1-α}(Σ_i w_i δ_{s_i})，w_i=softmax(-d_E(e_i,e_target)/τ_E)。
在组内可交换性下，组条件覆盖率满足
P(Y∈C_g) ≥ 1-α - O(√(log(1/δ)/n_g))；
跨本体时覆盖损失上界为 O(L_s·d_E)，L_s 为非一致性分数对本体的 Lipschitz 常数。**因此联邦校准只负责“借先验”，最终覆盖率必须由目标本体的独立审计集复核**。

**定义 64（边缘记忆账本与准入）**
账本条目 L_i=(e_i, c_i, ω_i, B_i, m_i, o_i, outcome_i, cert_hash_i, τ_i, provenance_i)。
准入分数
A(L_i; e,c,B,t) = sim(c,c_i) - λ_E·d_E(e,e_i) - λ_τ·(t-τ_i) - λ_b·|B-B_i|。
仅当 A ≥ τ_hit 且 d_E(e,e_i) ≤ d_E^max 且 cert_hash_i 在当前 (e,m,o) 下可复算且 ℓ_τ 有效时，允许复用；否则进入“本地重认证”队列。**禁止**仅凭语义相似度直接复用。

## 2. 新增产出与既有 IP 升级

**IP-69 ECF（Edge-Cert Fabric Orchestrator）**
- 三租约联合跟踪：ℓ_p、ℓ_e、ℓ_τ 的状态机与级联失效
- 卸载编排：每控制周期求解 o^*，向边缘下发 perception job 与 deadline
- 证书路由：把 P_t 与其证据链（帧时间戳、模态、本体指纹、校准组）绑定
- 分区降级：网络分区时冻结账本写入，退化到本地保守校准

**IP-70 FTA（Fleet Transfer Adapter）**
- 本体指纹提取与注册（运动学/传感器/动力学）
- 迁移膨胀计算：r_ω^B = r_ω^A(1+κd_E)+L_E d_E
- 迁移门控：d_E>d_E^max 或审计覆盖不足 → 拒绝迁移、触发本地重校准
- 迁移审计：在目标本体上抽检覆盖率，回流校准中心

**IP-71 AOL（Age-of-Information Lease & Offload Scheduler）**
- AoI 在线估计：帧时间戳 + 网络探针 + 队列长度
- 时效租约预测与失效预警
- 卸载 Pareto 求解：时延/精度/能耗/时效风险
- 抖动红队：注入延迟尖峰与分区，验证 fail-closed

**IP-72 FCC（Federated Conformal Calibrator）**
- 分层加权共形校准（按本体簇 × ω 层 × 模态）
- 组覆盖缺口检测：n_g 不足或覆盖低于阈值 → 生成采集任务
- 联邦先验与本地复核双轨：先验只用于初始化，最终以本地审计为准
- 漂移检测：按本体与时间窗监控非一致性分数分布

**既有 IP 升级**
IP-66 MVR：记忆检索从本地库升为边缘账本，检索键加入本体距离与时效项
IP-63 ECPS：模态决策与卸载决策联合求解，输出 (m_t^*, o_t^*)
IP-61 DCL：采集效用加入“校准缺口 × 本体覆盖”，优先补最薄弱组
IP-62 CCA：新增网络分区、延迟尖峰、本体指纹伪造、账本投毒红队
IP-51 CAR：守卫加入 ℓ_τ 有效性与 d_E≤d_E^max
IP-45 总线：新增 freshness-lease / offload-decision / embodiment-fingerprint / ledger-provenance 话题

## 3. 算法骨架

ECF 每控制周期：
1. 读 (B_t, ℓ_e, ℓ_p, τ_gen, e, c_t, ω_t, 网络状态)
2. 估计 Δ(t) 与抖动，更新 ℓ_τ；若 ℓ_τ 失效 → 禁止边缘证书，走本地保守路径
3. 对每个 o 估计 L_o、r̄_ω(m,o,e)、P(Δ>Δ_max|o)
4. 在能量与时效约束下求解 o^* 与 m_t^*
5. 若走账本复用，执行三元准入（本体距离、时效、证书哈希复算）
6. 签发五元联合证书 J_t；CAR 用 (ℓ_p,ℓ_e,ℓ_τ,e) 四重守卫
7. 网络分区/抖动超限 → 冻结账本、降级本地校准、必要时 fail-closed

## 4. 本轮最大风险

**一句话**：边缘账本与联邦校准会把“在 A 本体、某个时刻成功”的证书先验扩散到 B 本体与更晚时刻，若本体距离被低估或时效租约估计偏乐观，就会发生跨本体、跨时间的证书洗白，姿态证书在无告警的情况下静默失去覆盖保证；因此必须把 d_E 与 AoI 作为准入硬门（而非软惩罚），并强制目标本体的独立审计复核，任何一项不可验证就退回本地重认证或 fail-closed。

### IP-71 AOL：AoI 与卸载求解
```
def update_aoi(now, tau_gen, hist_jitter, lam_s=1.2):
    aoi = now - tau_gen
    j_hat = p90(hist_jitter)          # 近期抖动上分位
    aoi_pred = aoi + DELTA + lam_s * j_hat
    return aoi, aoi_pred

def freshness_lease_valid(aoi_pred, delta_max, eps_tau, tail_prob):
    return aoi_pred <= delta_max and tail_prob <= eps_tau

def offload_solve(m, e, B_t, net, calib, phi):
    best = None
    for o in ('local','edge','split'):
        L_o   = net.latency(o) + net.queue(o) + compute(o, m)
        p_late= net.tail_prob(o, delta_max(phi, m, e))
        r_bar = calib.expected_radius(m, o, e)   # 分层查表
        gain  = calib.coverage_gain(m, o, e)
        E_o   = power(m, o) * L_o
        if L_o > L_budget(phi):            continue
        if not energy_ok(B_t, E_o, t+DELTA): continue
        score = (r_bar + lam_tau*p_late*RISK_SAFE + lam_e*E_o) / max(gain, 1e-6)
        if best is None or score < best.score:
            best = Option(o, score, r_bar, p_late, L_o)
    if best is None:
        return None                        # 无时效/能量可行解 -> fail-closed
    return best
```

### IP-70 FTA：本体指纹与迁移膨胀
```
def embodiment_distance(eA, eB, w=(0.4,0.3,0.3)):
    return (w[0]*norm(eA.D_H - eB.D_H)
            + w[1]*sensor_jaccard(eA.S, eB.S)
            + w[2]*norm(eA.Theta - eB.Theta))

def transfer_radius(r_A, eA, eB, kappa, L_E):
    dE = embodiment_distance(eA, eB)
    return r_A*(1 + kappa*dE) + L_E*dE, dE

def admit_transfer(r_A, eA, eB, phi, audit):
    r_B, dE = transfer_radius(r_A, eA, eB, KAPPA, L_E)
    if dE > D_E_MAX[phi]:
        return None, dE, 'reject_local_recal'
    if not audit.has_target_coverage(eB, phi):   # 目标本体必须有审计样本
        return None, dE, 'need_audit'
    return r_B, dE, 'admit'
```

### IP-72 FCC：分层联邦共形校准
```
def federated_quantile(g, e_target, L, alpha, tau_E=0.5):
    items = [x for x in L if group(x) == g]
    if not items:
        return None
    w = softmax([-embodiment_distance(x.e, e_target)/tau_E for x in items])
    s = [x.score for x in items]
    order = argsort(s)
    cum = cumsum([w[i] for i in order])
    idx = searchsorted(cum, 1 - alpha)
    return s[order[min(idx, len(s)-1)]]

def coverage_gap(g, target=1-alpha, eps=0.02):
    # 组样本量不足或经验覆盖低于阈值 -> 生成采集任务
    if n_g[g] < N_MIN[g] or cover_emp[g] < target - eps:
        return True
    return False
```

```
def ledger_admit(L_i, e, c, B_t, now, ray_cert):
    dE = embodiment_distance(e, L_i.e)
    if dE > D_E_MAX[current_task]:
        return False, 'embodiment'
    if not freshness_lease_valid(now - L_i.tau_i + DELTA,
                                 delta_max(task, L_i.m, e),
                                 EPS_TAU, tail_prob_est):
        return False, 'stale'
    if not ray_cert.recomputable(L_i.hash, e, L_i.m, L_i.o):
        return False, 'hash_mismatch'
    A = cosine(c, L_i.c) - lam_E*dE - lam_tau*(now-L_i.tau_i) - lam_b*abs(B_t-L_i.B)
    return A >= TAU_HIT, 'score'
```

### IP-69 ECF 全局循环

```
def ecf_cycle(B_t, leases, tau_gen, e, c_t, omega_t, net):
    aoi, aoi_pred = update_aoi(now, tau_gen, net.jitter_hist)
    leases.tau = (tau_gen, delta_max(task, m_prev, e), EPS_TAU, LAM_S)
    if not freshness_lease_valid(aoi_pred, leases.tau.delta_max,
                                 EPS_TAU, net.tail_prob(aoi_pred)):
        # 时效失效：禁止边缘证书，退本地保守
        m, o = conservative_local(omega_t, B_t)
        return issue_cert(m, o, leases, e), 'tau_failclosed'

    o_star = offload_solve(m_prev, e, B_t, net, calib, task)
    m_star = ecps.mode_select(c_t, omega_t, B_t, o_star)
    if o_star is None:
        return None, 'no_feasible_offload'

    hit = ledger.query(c_t, e, B_t, now)
    if hit and ledger_admit(hit, e, c_t, B_t, now, ray_cert):
        J = issue_cert_from_ledger(hit, leases, e)
    else:
        J = issue_cert(m_star, o_star.o, leases, e)
    return J, 'ok'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| AOL AoI/抖动估计 | O(k) 滑窗 | O(k) | Δ 超限即 ℓ_τ 失效，依赖证书作废 |
| 卸载求解 | O(|O|·|m|) | O(|O|) | 仅返回满足时延+能量+时效约束的解 |
| FTA 迁移 | O(d_e) | O(1) | d_E>d_E^max 或目标无审计 → 拒绝直迁 |
| FCC 共形 | O(n_g log n_g) | O(n_g) | 组内可交换时覆盖≥1-α-O(√(log(1/δ)/n_g)) |
| 账本准入 | O(|L|·d) 检索，O(1) 校验 | O(|L|·d) | 三硬门（d_E/ℓ_τ/hash）全过才复用 |
| ECF 全局 | O(|L|d+|O||m|) | O(|L|d) | 任一租约失效 → fail-closed |

**正确性定理（跨本体-时效版）**
设目标本体 e、任务 φ，账本条目来自 e_i。若 (i) d_E(e,e_i)≤d_E^max(φ)；(ii) ℓ_τ 预测年龄 Δ(t+δ)≤Δ_max 且尾部概率≤ε_τ；(iii) 证书哈希在当前 (e,m,o) 可复算；(iv) 目标本体在其校准组上的经验覆盖≥1-α-ε，则五元联合证书 J_t 满足
P(X_t∈P_t) ≥ 1-α - L_φ·rad(P_t) - L_E·d_E - L_τ·(Δ-Δ_max)_+ - O(√(log(1/δ)/n_g))。
若任一前提不成立，ECF 不签发跨本体证书，退回本地重校准或 fail-closed，因此错误只能表现为“可用性下降”，不能表现为“静默安全违例”。

**推导要点**：跨本体误差由定义 60 的 Lipschitz 膨胀界控制；时效误差由定义 59 的 AoI 尾部界控制；两者与几何层半径误差可加（三角不等式）。联邦校准的组内项由共形分位数给出，跨组项由 d_E Lipschitz 给出，故必须把“联邦先验”与“目标本体审计”分离，前者不能单独提供覆盖保证。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 本体距离低估导致迁移覆盖失真 | 高 | d_E 作为硬门；目标本体必须独立审计；抽检覆盖率不达标即撤销迁移 |
| AoI 尾部估计偏乐观 | 高 | 用 p90/p99 抖动分位而非均值；ε_τ 保守；尾部违约触发 fail-closed |
| 账本被投毒/证书洗白 | 高 | cert_hash 复算 + provenance 链 + outcome 失败条目屏蔽 + 分区期禁写 |
| 联邦校准组样本不足 | 中 | 覆盖缺口检测驱动 DCL 采集；先验只做初始化，本地复核为准 |
| 网络分区导致机队不一致 | 中 | 分区期冻结账本、本地保守校准、恢复后按时间戳合并而非覆盖 |
| 边缘能耗/热约束 | 中 | 与 v10 能量租约联合求解；卸载收益按焦耳归一 |

## 6. 本轮最大风险

**一句话**：通用机器人平台的“共享”与边缘计算的“复用”会诱导系统把 A 本体、过去时刻的证书当成普适真理，若本体距离或信息年龄被低估，就会发生无告警的跨本体/跨时间证书洗白，使姿态证书静默失去覆盖；因此 d_E 与 AoI 必须是准入硬门而非软惩罚，且目标本体的独立审计与证书哈希复算缺一不可，任何不可验证情形都应退回本地重认证或 fail-closed。
