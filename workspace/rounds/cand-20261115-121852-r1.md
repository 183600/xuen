# 第 1 轮（新灵感循环；基线：第 5 轮 InstructGauge-RTDI v5）

> **基线**：第 5 轮 InstructGauge-RTDI（IP-334–339；定义 468–492；引理 63–68；实验 E473–E492）。WR / InstructGauge v3 / ToolGauge / LeanGauge / MODGAUGE 全部继承。
> 本轮灵感：「价值对齐」×「迁移学习」。
> 本轮纪律：**价值只约束选择、不创造能力；迁移只提供先验、不转移责任**。任何新增模块失效都必须退化为 RTDI v5 或保守价值档案 V₀，且退化可逐项验证。

## 0. 直觉与动机

### 灵感 1：价值对齐不是「更大的奖励函数」，而是「可审计的价值偏序 + 弃权」

直觉：把人类价值压成一个标量奖励，等于把多维、上下文相关、部分可比的偏好压成一条可被优化的代理。代理一旦被优化，就必然出现「奖励很高但价值被违背」的行为。RTDI v5 已经做了一个正确的分层：安全是硬约束，任务进度是软目标；本轮把这条分层从「安全 vs 任务」推广为**预注册的价值档案**：硬价值维度（安全裕度、隐私泄露、法律/伦理禁令）不可交易；软价值维度（任务进度、轻柔程度、人类负担、延迟、能耗）按**字典序**比较。机器人只能在档案允许的维度与参数盒内选择或排序，不能发明新的价值维度，不能把安全降级为可补偿的软目标；当偏序或权重不确定时，它必须**弃权或提问**，而不是猜一个看似合理的答案。

更关键的是区分两件事：**价值序**（什么比什么更重要）与**价值操作化**（怎样测量、阈值是多少）。价值序相对稳定，可跨任务复用；操作化依赖具体本体、负载、传感器与任务，天然不可直接搬。多数「对齐事故」不是不知道「安全优先」，而是把源域的「轻柔 = 5 N」当成目标域的「轻柔」，而目标域可能需要「轻柔 = 慢速接近」。因此本轮把价值对齐做成**可审计证书**，而不是一个分数：每个提交的块都带保守价值区间、硬约束可行性、鲁棒遗憾、可信权重集、证据来源与有效期。

### 灵感 2：迁移学习不是免费复用，而是「带失效域的先验假设」

直觉：数据稀缺时，复用源任务/源机器人的校准、原语、恢复预案与价值序非常诱人；但源域与目标域在动力学、传感器、人类群体、任务分布上都可能不同。迁移来的东西不是事实，而是一个**有有效域、有有效期、有负迁移护栏的假设**。本轮的迁移只允许发生在**带类型的对象**上：原语类型、价值序、故障签名、契约模板、校准先验；不允许直接搬原始策略或未校验的数值阈值。每个迁移对象携带迁移证书：源集合、源-目标差异、目标验证样本量、收益下置信界、价值兼容性、有效域与过期时间。

三类护栏缺一不可：
1. **分层贝叶斯先验**：源后验作为目标先验，但对「先验-目标」的 KL 散度设信任域预算 ρ，防止源先验过度自信；
2. **加权共形校准**：协变量偏移下用密度比加权，并裁剪极端权重，避免少数源样本主导覆盖；
3. **目标验证 + 负迁移护栏**：只在收益的 `1-α` 下置信界大于 0、差异有界、价值兼容、类型兼容时接受迁移；否则退回目标域单独校准。负迁移因此不是「事后才发现」，而是提交前可拒绝的假设。

### 灵感 3：两者耦合 → 最危险的是「价值代理迁移」

直觉：价值序恰恰是最想迁移、也最危险迁移的东西。若把价值序与操作化一起迁移，源域的代理阈值会变成目标域的「价值本身」；而目标验证若复用同一套代理特征，就**检测不到**这种错位。系统会变得**自信地错位**：证书全绿、任务成功率很高，但人类审计的价值被违背。更糟的是，迁移会让代理偏差从随机误差变成**跨任务共享的系统性偏差**，目标域的验证集越大，反而越确认这个错误。

结构性的解法不是再加一个统计检验，而是把两者拆开：
- **价值闭包**：语言只能实例化预注册维度与参数盒，不能造新维度，不能越过硬约束；
- **默认只迁移价值序，不迁移数值阈值**：阈值与特征提取器必须在目标域重校准，除非目标验证明确通过；
- **独立人类审计与对齐债务**：证书只证明「对代理特征的对齐」；代理与人类判断的差距要单独记账，超过预算就冻结软优化与迁移；
- **弃权**：偏好可信集太宽、或候选在字典序下不可比时，宁可提问/退回保守档案，不执行「看似最优」的动作；
- **退化**：价值模块失效退回 V₀，迁移模块失效退回目标域单独校准，两者都失效精确退回 RTDI v5。

一句话：迁移放大能力，也放大代理；价值对齐必须能审计「被放大的到底是价值还是代理」。

## 1. 研究问题（本轮要回答什么）

- **Q1（价值可证性）**：能否把价值对齐从标量奖励升级为「预注册价值偏序 + 硬约束 + 鲁棒遗憾 + 弃权」的可审计证书，使「已对齐」成为一个可证伪主张，而不是一个训练目标？
- **Q2（迁移的净收益条件）**：在什么源-目标差异、目标样本量与价值兼容条件下，迁移的收益下置信界严格为正？负迁移能否在提交前被拒绝，并把已接受迁移的潜在损害压到有界？
- **Q3（价值代理隔离）**：如何保证迁移的是「价值序」而不是「价值操作化的数值代理」？当目标验证与源验证共享代理时，如何用独立审计识别「证书全绿但人类价值被违背」？
- **Q4（严格退化）**：价值模块、偏好反馈、迁移模块、审计模块分别失效时，系统如何逐级退回 V₀ / 目标域单独校准 / RTDI v5，且行为可逐项验证？

## 2. 设计原则（雏形，正式化见产物区定义 493–513）

**P1 价值闭包（Value Closure）**
语言与偏好学习只能在预注册价值维度 `D` 内改变软权重/阈值，且参数必须落在允许盒 `B` 内；硬价值维度 `D_H` 的阈值只能在不放松安全的方向上调整。任何越权请求输出 ⊥，退回默认档案 V₀。价值闭包是能力闭包在目标空间上的对偶：工具不能扩权，价值也不能扩维。

**P2 硬约束不可补偿（Non-compensability）**
硬价值是可行性约束，不是可交易项；软价值的任何收益都不能补偿硬价值的违背。字典序只在可行集内部使用。这条把「安全优先」从口号变成选择器的前置条件。

**P3 价值序与操作化分离（Order/Operationalization Split）**
默认迁移价值序 `(D, ≻_V)`；数值阈值、特征提取器、恢复策略属于操作化，必须在目标域重校准或通过独立验证。没有目标验证的阈值迁移一律视为不可靠。

**P4 对齐证书（Alignment Certificate）**
每个提交块都带 `AC`：保守价值区间、硬约束可行性、可信权重集上的鲁棒遗憾、证据来源、有效期、审计状态。证书不是分数，而是可复核的审计对象；`proxy_only` 证书不得用于软价值优化。

**P5 迁移即假设（Transfer as Hypothesis）**
每个迁移先验/原语/恢复预案/价值序都带 `TransferCert`：源集合、源-目标差异、目标验证量、收益下置信界、有效域、过期时间、价值兼容与类型兼容。迁移证书过期或漂移即撤销，不得「默认仍然有效」。

**P6 负迁移护栏（Negative-Transfer Guard）**
只有收益的 `1-α` 下置信界严格大于 0、源-目标差异有界、价值/类型兼容时才接受迁移；否则退回目标域单独校准。已接受迁移还要受 KL 信任域 ρ 与迁移债务预算约束。

**P7 独立审计与对齐债务（Independent Audit / Alignment Debt）**
代理特征上的证书不能自证价值正确。用独立于代理特征的人类审计样本估计人类遗憾，累计对齐债务 `D_align`；超过预算 `B_align` 就冻结软优化、撤销迁移证书并重新征求偏好。没有独立审计时，系统只能使用硬约束 + 默认价值序，不得声称「已对齐」。

## 3. 与基线的接口（如何退化）

- 价值指令不可接地 / 越权 / 歧义 ⇒ 使用默认保守档案 V₀，等价于 RTDI v5 的固定安全优先；
- 偏好可信集过宽 / 候选不可比 / 独立审计不可用 ⇒ 只做硬约束过滤 + 默认字典序，禁用软价值优化；
- 迁移证书缺失 / 过期 / 收益下置信界 ≤ 0 / 价值不兼容 ⇒ 目标域单独校准，等价于 RTDI v5 的校准路径；
- 价值漂移或对齐债务超预算 ⇒ 冻结软优化与迁移，退回 V₀ 并触发重新征求偏好；
- 价值模块整体失效 ⇒ V₀ + 硬约束；迁移模块整体失效 ⇒ 目标域单独校准；两者皆失效 ⇒ 精确退化为 RTDI v5；
- RTDI v5 自身失效 ⇒ 仍按原链退回 InstructGauge-WR / InstructGauge v3 / ToolGauge / LeanGauge / MODGAUGE。

## 4. 预期贡献

1. 一个「价值只约束选择、不创造能力」的价值闭包口径，把语言/偏好注入面压到可类型检查、可审计的范围内；
2. 一个带硬约束、鲁棒字典序、可信权重集与弃权机制的**对齐证书**，把「已对齐」从训练目标变成可证伪主张；
3. 一个把**价值序**与**价值操作化**分离的迁移协议，默认只迁移序、不迁移阈值，并用目标验证与独立审计防止「价值代理迁移」；
4. 一套负迁移护栏与迁移债务/对齐债务预算，使迁移的潜在损害在提交前有界、在运行中可撤销；
5. 一条完整可证伪路径：E493–E514 覆盖价值区间覆盖、证书可靠性、鲁棒遗憾、偏好查询效率、对齐税、漂移检测、跨任务/跨机器人/跨价值迁移、负迁移、恢复预案迁移、原语迁移、对抗价值注入、50Hz 时序与严格退化。

## 5. 本轮最大风险

**一句话**：对齐证书只能证明「对已注册代理特征的对齐」，而迁移会把源域的代理偏差系统性地带入目标域；当目标验证复用同一套代理时，系统会以越来越高的置信度执行「证书全绿但人类价值被违背」的行为——最大的风险不是单次误对齐，而是一个可自我确认的「代理-价值」闭环，它让能力越强、验证越多，错得越稳定。

## 2. 形式化定义（要点）

**定义 493（价值档案 ValueProfile）**
价值不是标量，而是一个带硬约束与软序的预注册结构：
```
V = (D, D_H, ≻_V, B, Θ, Pred_V, α_V, ε_regret, B_align)
D = D_H ⊔ D_S,  |D| = m
D_H = {safety_margin, privacy_leak, legal_ethics}       // 不可交易
D_S = {task_progress, gentleness, human_effort, latency, energy}
≻_V : D_S 上的全预序（实现为字典序）
B = ∏_{d∈D_S} [l_d, u_d]                                 // 软权重/阈值允许盒
Θ = {θ_d}_{d∈D_H}                                        // 硬阈值
Pred_V : (task, embodiment, human) → {0,1}               // 档案有效域
```
只有满足 `Pred_V=1` 且 `D_H` 覆盖安全/隐私/法律伦理的档案才可注册。`V₀` 是默认档案：硬阈值按安全裕度收紧，软序固定，不接受语言覆盖。

**定义 494（价值特征区间证书）**
对候选结果 `y`（块、轨迹或计划），价值特征映射输出带证据的保守区间：
```
ψ_d(y) = s_d · φ_d(y),  s_d = +1（越大越好）或 -1（越小越好）
Interval_V(y) = { [ψ_d⁻(y), ψ_d⁺(y)], prov_d }_{d∈D}
P( ψ_d(y) ∈ [ψ_d⁻, ψ_d⁺] ) ≥ 1 - α_V
prov_d = (sensor, model, calib_id, transfer_cert_id, timestamp)
```
区间必须来自可追溯的校准/模型，不允许用点估计冒充证书。成本型维度统一取向后，后续只处理「越大越好」。

**定义 495（硬价值可行性）**
```
F_V(y) ⇔ ∀ d ∈ D_H : ψ_d⁻(y) ≥ θ_d        // 取保守下界，宁可误拒
```
硬价值是可行性约束而非可补偿项：软价值的任何收益都不能把不可行候选变成可行。

**定义 496（鲁棒字典序支配与遗憾）**
对候选 `a,b`，令 `d*` 为 `≻_V` 中首个区间可分离的软维度：
```
a ≻_rob b ⇔ (∀ d ≺_V d*: [ψ_a⁻,ψ_a⁺] ∩ [ψ_b⁻,ψ_b⁺] ≠ ∅)
            ∧ ψ_a⁻(d*) > ψ_b⁺(d*)
```
若不存在可分离维度，则 `a,b` 不可比，不得用点估计强行排序。对可信集 `W_α`，定义鲁棒遗憾：
```
Reg_W(a) = max_{w∈W_α} max_{b∈F_V} Σ_{d∈D_S} w_d · (ψ_b^mid(d) - ψ_a^mid(d))
ψ^mid = (ψ⁻ + ψ⁺)/2
```
选择 `a* = argmin_{a∈F_V} Reg_W(a)`；若 `Reg_W(a*) > ε_regret` 或存在不可比候选且最坏遗憾超界，则弃权/提问，而不是执行。

**定义 497（对齐证书 AlignmentCert）**
```
AC = (id, V_id, y, Interval_V(y), W_α, Reg_W(y), hard_ok,
      provenance, expiry, audit_status)
hard_ok = F_V(y)
audit_status ∈ {proxy_only, human_audited}
```
`AC` 的语义是：在 `1-α_V` 区间覆盖与 `1-α_w` 可信集覆盖同时成立时，`y` 的硬约束满足、真实遗憾不超过 `Reg_W + ε_approx`。`proxy_only` 证书只允许用于硬约束过滤，不得用于软价值优化。

**定义 498（价值指令规格与价值闭包）**
```
Γ_val(ℓ) → spec = { (d, Δw_d, Δθ_d) }_{d∈D}
约束：
  d ∈ D
  w_d + Δw_d ∈ B_d
  Δθ_d ≠ 0 仅当 d ∈ D_H 且 θ_d + Δθ_d ∈ [θ_d^safe_min, θ_d^safe_max]
```
违反任一约束 ⇒ `Γ_val(ℓ)=⊥`，退回 V₀。没有自由文本直达执行器，也没有「新价值维度」通道。于是价值闭包成立：`dom(Γ_val) ⊆ D`，语言不能扩维、不能把硬约束软化为可交易项。

**定义 499（偏好模型与可信集）**
成对反馈 `Y = {a_i ≻ b_i}` 用 Bradley-Terry 似然建模软权重：
```
P(a ≻ b | w) = σ( w · (ψ_a^mid - ψ_b^mid) )
p(w | Y) ∝ p(w) ∏_i P(y_i | w)
W_α = { w : log p(w|Y) ≥ max_w log p(w|Y) - κ_α }
```
若 `W_α` 过宽、或反馈相互冲突导致可信集不连通，则不得声称软价值最优；只执行硬约束 + 默认字典序，或发起主动查询。

**定义 500（价值漂移与对齐债务）**
```
D_drift(t) = MMD( p_t(ψ, Y), p_0(ψ, Y) ) + λ · |Reg_human(t) - Reg_cert(t)|
D_align(T) = Σ_{t=1}^T max( 0, Reg_human(audit_t) - Reg_cert(t) )
```
`D_drift > ε_drift` 或 `D_align > B_align` ⇒ 冻结软优化与迁移，退回 V₀，并触发重新征求偏好。`Reg_human` 只能来自独立于代理特征的人类审计；若审计也基于同一代理，则对齐债务不可识别，证书必须标记 `proxy_only`。

**定义 501（任务/机器人/人类描述符）**
```
e = (task_family, embodiment, sensor_suite, env_stats,
     Π_e, V_e, dynamics_sig, human_pop)
```
描述符用于选择源集合与判断迁移有效域；`V_e` 只携带价值序与档案元数据，不携带未校验的数值阈值。

**定义 502（迁移证书 TransferCert）**
```
TC = ( S, θ_{S→t}, δ_ST, n_t, Δ̂_{S→t}, LCB_{1-α}(Δ),
       value_compat, type_compat, validity, expiry, ρ )
```
`S` 为源集合，`θ_{S→t}` 为迁移后的先验/参数，`δ_ST` 为源-目标差异，`n_t` 为目标验证样本量，`Δ̂` 为收益估计，`LCB` 为下置信界。`validity` 是描述符上的有效域谓词，`expiry` 是时间/轮次上限。

**定义 503（迁移可接受性与负迁移护栏）**
```
Accept(TC) ⇔ LCB_{1-α}(Δ) > 0
            ∧ δ_ST ≤ δ_max
            ∧ value_compat = true
            ∧ type_compat = true
            ∧ n_t ≥ n_min
```
拒绝迁移 ⇒ 目标域单独校准。接受迁移还要满足 `KL(p(θ_t) || p(θ_s)) ≤ ρ`；`ρ` 是信任域预算，限制源先验对目标后验的影响。迁移债务：
```
D_transfer(T) = Σ_t max( 0, L_target(θ_transfer,t) - L_target(θ_target_only,t) )
```
`D_transfer > B_transfer` ⇒ 撤销迁移证书，回到目标域单独校准。

**定义 504（分层迁移校准）**
```
p(θ_t | D_t, D_s) ∝ p(D_t | θ_t) ∫ p(θ_t | θ_s) p(θ_s | D_s) dθ_s
s.t. KL( p(θ_t) || p(θ_s) ) ≤ ρ
```
共形校准在协变量偏移下使用密度比加权：
```
r(x) = clip( p_t(x) / p_s(x), r_min, r_max )
α_weighted(x_i) = r(x_i) / Σ_j r(x_j)
```
权重裁剪是必要的：极端密度比会让少数源样本主导覆盖，制造「覆盖很高但目标域失效」的假象。

**定义 505（价值迁移证书 VTC）**
价值迁移必须把「序」与「操作化」分开认证：
```
VTC = ( V_{s→t}, order_ok, op_ok, P_V, τ_Kendall, audit_sample )
order_ok ⇔ 在价值关键探针 P_V 上，目标反馈与源价值序的 Kendall τ ≥ τ_min
op_ok    ⇔ 目标域重校准后的阈值/特征覆盖 ≥ 1 - α_V
```
迁移规则：
- `order_ok` ⇒ 可迁移 `(D, ≻_V)`；
- `op_ok` ⇒ 可迁移阈值/特征提取器；
- `order_ok ∧ ¬op_ok` ⇒ **只迁移序，阈值必须在目标域重校准**；
- `¬order_ok` ⇒ 不迁移价值档案，目标域重新征求偏好并使用 V₀ 兜底。
数值阈值未经目标校准一律不得迁移；这不是保守偏好，而是因为同一词语在不同本体/负载下对应不同的物理量。

**定义 506（可迁移恢复预案与可迁移原语）**
```
RP_{s→t} 可接受 ⇔ cause_compat
                 ∧ tools(τ_rec^t) ⊆ T_0^t
                 ∧ contract_compat(ψ_post^s, ψ_post^t)
                 ∧ WCET_static(τ_rec^t) ≤ 2 · T_cycle^t
π_{s→t} 可接受 ⇔ type_compat
                ∧ pre/post 在目标域验证通过
                ∧ d_dyn(π_s, π_t) ≤ δ_Π
```
恢复预案的 WCET 必须按目标硬件重新分析；原语的类型签名可迁移，但前置/后置条件必须在目标域重新验证，否则退化为 stub 或目标域专用实现。

**定义 507（VT-9C 闭环）**
```
W: 感知
R: 推理（Γ_parse + Γ_val）
T: 迁移（TransferCert + 分层校准）
C: 契约规划（候选生成 + AlignmentCert + RT-CVC）
E: 执行（rt-chunk + ValueMonitor）
S: 空间验证（SpatialCert）
D: 诊断-恢复（FaultCert + RecoveryRegistry）
V: 证书融合（Spatial ∧ Align ∧ Fault ∧ Transfer）
U: 更新（偏好后验 + 对齐债务 + 迁移债务 + 注册表）
```
与 RTDI-7C 相比，新增 `T`（迁移选择/校准）与 `R` 中的 `Γ_val`，并把 `AC` 纳入 `C` 与 `V`；执行阶段增加硬价值监控与漂移触发。

**定义 508（统一提交条件与回退顺序）**
```
Commit(C) ⇔ SpatialCert.ok
          ∧ AC.hard_ok
          ∧ AC.Reg_W ≤ ε_regret
          ∧ (无未恢复的 FaultCert)
          ∧ (TC 为空 ∨ TC.valid)
          ∧ ValueMonitor.ok
```
回退顺序（只退一层，不跨层跳）：
1. `AC` 歧义/遗憾超界 ⇒ 提问/弃权；若不可提问 ⇒ 默认字典序 + 硬约束；
2. `TC` 无效/过期/负迁移 ⇒ 目标域单独校准；
3. 价值漂移/对齐债务超预算 ⇒ 冻结软优化与迁移，使用 V₀；
4. 所有增强关闭 ⇒ 精确 RTDI v5。

**定义 509（严格退化等价）**
关闭价值模块与迁移模块，并令 `V=V₀`（其硬约束恰为 RTDI v5 的 CVC/SpatialCert 约束，软序不产生额外过滤），`TC=∅`，`calibrate=target_only`，`PreferenceElicitor` 不更新，则 VT-9C 的执行动作序列、证书与 RTDI v5 逐项相同（diff=0）。这是后续 E511 的判据。

**定义 510（价值关键探针集 P_V）**
预注册一组价值冲突/边界场景：
```
P_V = { (scenario_i, expected_order_i, hard_constraints_i) }
```
至少覆盖：安全 vs 进度、隐私 vs 观测、轻柔 vs 速度、人类负担 vs 成功率、以及「同一词语在不同本体下不同操作化」的对照。`P_V` 用于价值序迁移测试，不用于训练代理特征。

**定义 511（独立审计协议）**
审计样本 `A_t` 由未接触代理特征的评估者给出成对判断，估计 `Reg_human`。只有 `|A_t| ≥ n_audit` 且评估者间一致性 ≥ `κ_min` 时，`audit_status=human_audited`；否则为 `proxy_only`，系统不得进行软价值优化。若审计本身也由同一代理生成，则对齐债务不可识别，必须显式记录该限制。

**定义 512（迁移债务与撤销）**
```
D_transfer(T) = Σ_t max(0, L_target(θ_transfer,t) - L_target(θ_target_only,t))
```
每接受一次迁移，就把其目标验证损失与「目标域单独校准」的反事实损失比较；差值正部累计。超过 `B_transfer` 即撤销全部迁移证书，回退目标域单独校准。迁移债务与对齐债务独立记账：前者是性能/安全债，后者是价值债。

**定义 513（对齐税）**
```
Tax_align = ( U_task(V₀) - U_task(V) ) / U_task(V₀)
```
`U_task` 为任务效用（成功率/吞吐/耗时综合），对齐税衡量价值约束与迁移护栏带来的性能代价。预注册要求 `Tax_align ≤ 10%`，否则需要重新设计价值操作化或迁移策略。

```python
class ValueProfile:
    def __init__(self, dims, hard, order, box, theta, pred,
                 alpha=0.05, eps_regret=0.05, budget_align=1.0):
        self.D, self.D_H, self.order = dims, hard, order
        self.B, self.Theta, self.Pred = box, theta, pred
        self.alpha, self.eps_regret = alpha, eps_regret
        self.B_align = budget_align

    def oriented(self, phi):
        # phi: {d: (lo, hi)}；成本型维度翻转符号，统一为越大越好
        return {d: (self.s[d] * lo, self.s[d] * hi) for d, (lo, hi) in phi.items()}

    def hard_feasible(self, psi):
        return all(psi[d][0] >= self.Theta[d] for d in self.D_H)

    def instantiate(self, spec):
        # 价值闭包：只允许已注册维度与允许盒内的参数
        for d, dw, dtheta in spec:
            if d not in self.D:
                raise ValueError("unregistered value dimension")
            if not (self.B[d][0] <= self.w[d] + dw <= self.B[d][1]):
                raise ValueError("weight outside admissible box")
            if dtheta and not self.safe_hard_adjustment(d, dtheta):
                raise ValueError("unsafe hard-threshold adjustment")
        return self.with_spec(spec)


class ValueAligner:
    def __init__(self, V0, features, pref, audit):
        self.V, self.features, self.pref, self.audit = V0, features, pref, audit

    def parse(self, ell):
        spec = parse_value_instruction(ell, self.V.D, self.V.B, self.V.Theta)
        return self.V if spec is None else self.V.instantiate(spec)

    def certify(self, candidates, ctx):
        feasible = []
        for c in candidates:
            psi = self.V.oriented(self.features.interval(c, ctx, self.V.alpha))
            if self.V.hard_feasible(psi):
                feasible.append((c, psi))
        if not feasible:
            return None, AlignmentCert.abstain("no hard-feasible candidate")

        W = self.pref.credible_set(self.V.alpha)
        best, regret = robust_lex_argmin(feasible, W, self.V.order)
        if regret > self.V.eps_regret:
            q = self.pref.best_query(feasible, W, self.V)
            return None, AlignmentCert.query(q, feasible, W)

        audit_ok = self.audit.available(self.V)
        if not audit_ok:
            # 无独立审计：只允许硬约束 + 默认字典序，禁止软价值优化
            best = default_lex_argmin(feasible, self.V.order)
            return best, AlignmentCert.proxy_only(best, feasible, W)

        return best, AlignmentCert(best, feasible, W, regret, audit=True)


class PreferenceElicitor:
    def credible_set(self, alpha):
        # Laplace / 变分后验；返回权重的 1-alpha 水平集（椭球或多面体）
        post = self.posterior()
        return post.credible_region(alpha)

    def best_query(self, feasible, W, V):
        # 在安全且低成本的候选对中选择期望遗憾下降最大者
        pairs = safe_query_pairs(feasible, V)
        return max(pairs, key=lambda p: expected_regret_reduction(p, W))


class TransferManager:
    def __init__(self, source_pool, alpha, delta_max, rho, r_min, r_max):
        self.sources, self.alpha = source_pool, alpha
        self.delta_max, self.rho = delta_max, rho
        self.r_min, self.r_max = r_min, r_max

    def select(self, target, sources=None):
        accepted = []
        for s in (sources or self.sources):
            delta = discrepancy(s.stats, target.stats)
            vtc = value_compat(s.V, target.V, target.probes)
            if delta > self.delta_max or not vtc.order_ok:
                continue
            gain = paired_gain(s.validation_on_target, target.holdout)
            lcb = lower_confidence_bound(gain, self.alpha)
            if lcb > 0:
                accepted.append(TransferCert(
                    sources={s.id}, theta=s.prior, delta_ST=delta,
                    n_t=len(target.holdout), lcb=lcb, value_compat=vtc,
                    type_compat=type_compat(s.Pi, target.Pi),
                    validity=target.validity, expiry=target.expiry,
                    rho=self.rho, r_min=self.r_min, r_max=self.r_max))
        return max(accepted, key=lambda tc: tc.lcb) if accepted else None

    def calibrate(self, target, tc):
        if tc is None:
            return target_only_calibration(target)
        prior = hierarchical_prior(tc.sources, rho=tc.rho)
        post = bayes_update(prior, target.data)
        cal = weighted_conformal(post, target.data,
                                 clip=(tc.r_min, tc.r_max))
        if not coverage_ok(cal, target.holdout, target.alpha):
            return target_only_calibration(target)
        return cal


def instructgauge_vt(M, s, ell=None):
    # 1. 价值闭包：语言只实例化预注册价值维度
    V = M.aligner.parse(ell) if ell else M.V0

    # 2. 迁移证书 + 目标域校准（可选增强）
    desc = M.descriptor(s)
    tc = M.transfer.select(desc)
    cal = M.transfer.calibrate(desc, tc)

    # 3. 原语图接地（迁移只影响预注册原语/先验，不扩权）
    iota_seq = M.pgraph.parse_instantiate(ell, cal.primitives)
    if not M.pgraph.verify_capability_closure(iota_seq):
        iota_seq = [M.default_iota]

    # 4. 候选生成 + 对齐证书
    candidates = M.iac.plan_candidates(
        iota_seq[0], M.lbox.hypothesize(s, M.dbox.R[s], iota_seq[0]),
        M.tools, M.budget_left(s), M.drift_bound(s))
    C, ac = M.aligner.certify(candidates, s)
    if C is None:
        if ac.kind == "query":
            return ASK_HUMAN(ac.query)
        return fallback_v0(M, s, ell)

    # 5. RT-CVC 与空间预检（继承 RTDI v5）
    tau_C = M.rt_model.make_task(C, M.env.time())
    if not M.rta.verify({tau_C}):
        C = M.rt_model.generate_fallback(C)
        tau_C = M.rt_model.make_task(C, M.env.time())
    tf_seq = M.wristcam.get_spatial_trajectory(
        M.env.time(), M.env.time() + C.duration())
    pre_spatial = generate_spatial_cert(C, tf_seq, M.epsilon_vis)
    if not pre_spatial.is_consistent:
        C = M.rt_model.generate_fallback(C)
        tau_C = M.rt_model.make_task(C, M.env.time())

    # 6. 执行：硬价值监控 + 诊断恢复（继承 RTDI v5）
    for t, action in enumerate(C.actions):
        if not M.value_monitor.hard_ok(action, C, V):
            C = C.truncate(t)
            break
        if not M.cvc.joint_pre(action) or not still_grounded(iota_seq[0], M.env):
            break
        M.env.apply(action)
        current_tf = M.wristcam.get_latest_tf()
        if current_tf and not M.ros_cvc.verify_tf_consistency(
                current_tf, C.psi_post):
            violation = SpatialViolation(t, tf_residual(current_tf), "spatial")
            fault = M.diagnoser.diagnose(violation, C, tf_seq, iota_seq[0])
            plan = M.recovery_registry.get_plan(fault.rpid)
            if plan and plan.wcet <= 2 * M.T_cycle:
                M.scheduler.schedule_recovery(plan, fault)
                if not plan.success:
                    C = C.truncate(t)
                    break
            else:
                C = C.truncate(t)
                break

    # 7. 漂移与债务：超预算则冻结软优化/迁移
    receipts = M.tcv.get_receipts()
    if M.value_monitor.detected_drift(C, V, receipts):
        M.transfer.revoke(tc)
        V = M.V0
        C, ac = M.aligner.certify([C], s)
    M.debt.update(ac, M.audit.sample())

    # 8. 证书融合与更新
    spatial_cert = generate_spatial_cert(C, tf_seq, M.epsilon_vis)
    M.ros_cvc.publish_cvc(C.id, len(C.actions), C.actions,
                          C.pre_conditions, C.post_conditions,
                          [spatial_cert, ac])
    M.pref.update(receipts.feedback)
    M.transfer.update(desc, tc, receipts)
    claims = bind_claims(C, iota_seq[0], receipts, alignment=ac)
    return C, ac, spatial_cert, claims
```

## 4. 推导

**引理 69（价值闭包）** 若 `Γ_val` 只输出已注册维度 `d∈D`、参数落在 `B` 内、硬阈值调整只在安全方向，则对任意指令 `ℓ`，诱导的目标函数都属于预注册族 `{V(w): w∈B}`，不会出现新维度或无界权重。证明：对 `Γ_val` 的语法树做结构归纳；基例是单个维度参数，归纳步是参数增量与约束交集；任何越权分支输出 ⊥ 并退回 V₀。因此价值闭包与能力闭包（引理 66）对偶成立：语言既不能扩工具集，也不能扩价值维度。

**引理 70（硬价值不可补偿）** 若选择器只在 `F_V` 内选择，且 `F_V` 用保守下界检查 `ψ_d⁻ ≥ θ_d`，则任何被提交的 `C` 都满足所有硬价值约束；软价值的任何收益都不能把不可行候选变成可行。证明：`F_V` 是选择的前置过滤；鲁棒字典序只在 `F_V` 内部比较，软序不参与可行性判定。故硬约束违背率为 0（在区间覆盖成立的前提下）。

**引理 71（对齐证书可靠性）** 若 (i) 价值区间以概率 `≥1-α_V` 覆盖真实 `ψ`，(ii) 硬约束用下界检查，(iii) 可信集 `W_α` 以概率 `≥1-α_w` 包含真实权重，则对 `AC` 证明的提交候选 `C`，有 `P(hard_ok(C) ∧ Reg_{w*}(C) ≤ Reg_W(C) + ε_approx) ≥ 1 - α_V - α_w`。证明：由联合界，区间覆盖与可信集覆盖同时成立的概率至少 `1-α_V-α_w`；在此事件上，区间算术保证硬约束，`max_{w∈W_α}` 保证真实 `w*` 的遗憾不超过鲁棒遗憾，数值求解误差为 `ε_approx`。

**引理 72（鲁棒字典序遗憾界）** 若 `C* = argmin_{C∈F_V} Reg_W(C)` 且 `Reg_W(C*) ≤ ε_regret`，则对任意 `w∈W_α`，`Reg_w(C*) ≤ ε_regret`。证明：`Reg_W` 定义为 `W_α` 上的逐点最大，故 `Reg_w(C*) ≤ Reg_W(C*)`；再由选择条件得界。若 `W_α` 不包含真实权重，则证书不成立——这正是需要独立审计与漂移检测的原因。

**引理 73（负迁移护栏的假接受界）** 设目标验证收益估计 `Δ̂` 为有界差分的配对样本均值，`LCB_{1-α}(Δ)` 为经验 Bernstein 下界。若真实期望收益 `E[Δ] ≤ 0`，则 `P(LCB > 0) ≤ α`；因此接受迁移的概率不超过 `α`。进一步，在 KL 信任域 `KL(p(θ_t)||p(θ_s)) ≤ ρ` 与有界损失 `L_max` 下，迁移后验相对目标后验的预测损失差满足 `E_t[ℓ(θ_transfer)] - E_t[ℓ(θ_target)] ≤ L_max·sqrt(ρ/2) + L_Lip·δ_ST`（Pinsker + 域适应界）。证明：第一项由下置信界的定义与经验 Bernstein 不等式；第二项由 Pinsker 不等式与损失 Lipschitz 性。该界是保守的，但足以把「已接受迁移」的潜在损害限制在 `ρ, δ_ST` 预算内。

**引理 74（价值序/操作化分离的必要性）** 仅迁移价值序并在目标域重校准阈值，可在目标覆盖成立时保持硬约束；反之，直接迁移源域数值阈值一般不安全。构造反例：源本体质量 `m_s`、目标本体质量 `m_t > m_s`，同一「轻柔」阈值 `τ` 在源域对应加速度 `a_s=τ/m_s`，在目标域对应 `a_t=τ/m_t`；若目标硬约束要求 `a ≤ a_max` 且 `a_s ≤ a_max < a_t`，则源阈值在目标域违反安全约束。故没有目标校准的阈值迁移不存在一般可靠性保证；序迁移 + 目标阈值重校准是必要的结构条件。

**引理 75（严格退化等价）** 在定义 509 的关闭条件下，VT-9C 的转移关系与 RTDI v5 逐项相同。证明：`Γ_val` 恒等返回 V₀；`TransferManager.select` 返回空，`calibrate` 等于 `target_only`；`ValueAligner.certify` 在 `proxy_only` 模式下只做硬约束过滤 + 固定字典序，而 V₀ 的硬约束恰为 CVC/SpatialCert 约束、软序不产生额外过滤；`ValueMonitor` 只检查已被 CVC 覆盖的硬约束；`PreferenceElicitor`/债务/迁移注册表不更新。因此动作序列、证书与 RTDI v5 相同，diff=0。

## 8. 本轮最大风险

**一句话**：对齐证书只对「已注册的代理特征」负责，而迁移会让源域的代理偏差跨任务共享并系统化；如果目标验证、偏好查询与人类审计都复用同一套代理，系统就会形成一个自我确认的闭环——能力越强、验证样本越多，越会稳定地执行「证书全绿但人类价值被违背」的行为，而真正的价值错位恰恰无法被这个闭环内部识别。
