# 第 64 轮（承接第 63 轮「LIRO 几何-技能-干扰联合闭环」IP-193~203；灵感循环 II 第 3 轮；本轮灵感：「通信延迟」×「力控」）

> 第 63 轮的 LIRO 已经把几何（LSF）、技能（USL/CSP）与干扰（DIR/AIC）接进 ROSE，并把实时路径压进约 1ms。但它仍然默认了一个**从未被证明的隐含假设**：语义快照、几何嵌入、阻抗参数与力反馈是**同一时刻、同步、零延迟**到达的。
> 1. **时间没有进入状态**：LSF 缓存 `g_cache`、OLP 锚点、WCV 球心 φ̂ 都没有时间戳与有效期；当通信延迟、抖动、丢包或时钟漂移出现时，实时路径可能用「过去 100ms 的几何 + 过去 50ms 的力」去编译「当前」的 K_safe，而 J_liro 无法表达「这个证书只对某个时间窗口有效」。
> 2. **力控闭环没有被认证**：WCV/AIC 认证的是 φ 球与几何/感知扰动，没有认证**接触力闭环在延迟下的稳定性**。力控内环（1–10kHz）若依赖语义外环（10–100Hz）的阻抗参数，延迟会直接破坏无源性；而第 63 轮把「通讯延迟抖动」只当作 η_act 的一个范数项，既没有相位模型，也没有能量论证。
> 3. **延迟被误当作纯 nuisance**：DIR 的目标是让表征对干扰不变。但力控要做的是**估计并补偿延迟**，而不是把延迟信息洗掉；对延迟完全不敏感等于放弃预测，对延迟完全敏感又会被抖动欺骗。正确的分解是「对噪声不变、对延迟等变、对任务充分」。
>
> 本轮把「通信延迟」与「力控」作为一对**时间-能量**对偶引入：延迟决定**何时**可以相信一个阻抗，力决定**是否**还有能量余量维持接触稳定。合流后，LIRO 的「几何-技能-干扰」闭环升级为 **DAFCO：Delay-Aware Force-Certified Operations（时延感知力控认证闭环）**——**LIRO 让几何、技能与干扰进入闭环，DAFCO 让时间与力进入闭环**。

## 0. 直觉与动机

**灵感 1（通信延迟 → TSA + DCP：时间戳锚点与延迟后验预测）**
直觉：通信延迟不是一条「噪声」，而是一个**可观测、可预测、可攻击的隐状态**。与其问「延迟会不会让系统坏掉」，不如把每个观测写成 `o_i = (内容, 采集时刻 τ_i^s, 到达时刻 τ_i^a)`，把有效延迟 `δ_eff = δ_sens + δ_comm + δ_act + δ_comp` 显式建模。
- **TSA（Time-Stamped Anchor）**：每次语义流提交锚点时，附带时间戳、有效窗口 `[τ, τ+Δ_max]` 与新鲜度 `Δ(t)=t−τ`；实时路径读锚点时必须先检查 `Δ(t) ≤ Δ_max(σ)`，否则进入局部降级，而不是继续消费过期参数。
- **DCP（Delay Conformal Predictor）**：用历史延迟轨迹拟合条件分布 `q_t(δ | 最近窗口、链路、负载、力残差)`，再用 **自适应保形预测（ACI）** 给出有限样本/长程覆盖上界 `δ_α`：`P(δ_eff ≤ δ_α) ≥ 1−α`（非平稳时用 ACI 的长期覆盖与 CUSUM 漂移检测兜底）。预测值不是给用户看的数字，而是直接进入 WCV 的不确定集与 Shield 的时间预算。

**灵感 2（力控 → FRO + PFC：力残差观测器与无源力编译器）**
直觉：力是延迟的「物理时钟」。命令速度与实测接触力之间的**互相关滞后**可以直接估计有效延迟；而接触力残差又能反过来暴露 φ̂ 与几何的错误。于是：
- **FRO（Force-Residual Observer）**：用接触模型 `F = K_e(x−x_e) + D_e v + F_ext`，在延迟窗口上做滑动互相关，估计 `δ_eff`、接触刚度 `K_e` 与外力 `F_ext`；把力残差 `r_F = F_meas − F_pred(φ̂, K)` 同时喂给 DCP（校验延迟估计）与 WCV（修正 φ 球）。
- **PFC（Passivity-preserving Force Compiler）**：阻抗不是一组静态 K/D，而是**以延迟为条件的无源族** `Z(δ) = (K(δ), D(δ))`。用波变量/散射变换把力-速度环变成无源二端口，配合能量罐（energy tank）记录注入/耗散能量；当 `E_tank` 接近下界或延迟超过当前认证半径时，自动增加阻尼、削减刚度，必要时切换到局部被动保持（passive hold）。这样，**力控内环不必等待语义外环重新规划**，也能在延迟抖动下保持接触稳定。

**灵感 3（双灵感合流 → DAFCO：时延感知力控认证闭环）**
三者咬合：**TSA 定义时间合约**（什么时候的数据可以用于哪个技能），**DCP 给出延迟的统计上界**，**FRO 用力的物理证据校正延迟与 φ**，**PFC 在延迟覆盖范围内编译无源阻抗**，**WCV-T 在「φ 球 × 延迟区间」的联合不确定集上做 CVaR 最坏搜索**，**Shield-T 在过期/超界时切换到局部兜底**，**AIC-T 把延迟覆盖与能量余量写进证书**。闭环：时间戳观测 → 延迟后验 → 力残差校验 → 联合鲁棒编译 → 无源展开 → 力/能量反馈 → 场景银行记账（延迟指纹）→ 证书更新。
**第 63 轮 LIRO 是「几何、技能、干扰三层联合」；DAFCO 是「时间、能量、力三层联合」**——前者回答「看见什么、做什么」，后者回答「何时相信、还有多少能量可以相信」。

**灵感 4（LIRO 组件的原位升级）**
- **OLP-Geo → OLP-T**：在线投影的梯度若来自延迟观测，会引入 stale-gradient 偏差；OLP-T 维护「时间对齐的梯度缓冲」，按延迟后验重加权，并给出延迟导致的额外遗憾项（定义 215）。
- **WCV-Geo → WCV-T**：不确定集从 `B(φ̂,r)` 扩为 `B(φ̂,r) × Δ(δ̂,δ_α)`；最坏搜索联合采样 φ 与 δ，输出的是**阻抗调度** `K_safe(δ)` 而非单个 K；几何约束 𝒢(g) 仍在，但增加「时间有效性」约束。
- **USL/CSP → TSP（Temporal Skill Planner）**：技能前置/后置条件增加时间谓词（deadline、freshness、min-slack、force-profile），CSP 在时间自动机上搜索带 slack 的技能序列，实时只展开首技能的**当前时刻切片**。
- **DIR → DIR-T**：从「对一切干扰不变」改为「**选择性不变 + 延迟等变**」：对传感器噪声/纹理攻击不变，对延迟/力动态保留并显式预测；表征分解为 `Z_task ⊕ Z_delay ⊕ Z_nuisance`。
- **SSB → DSB（Delay Scenario Bank）**：场景签名增加延迟指纹 `fp_delay`（分位数、抖动、丢包模式、时钟偏移）与力指纹 `fp_force`（接触刚度、力残差频谱、无源事件）；变异算子增加延迟尖峰、延迟斜坡、重放/丢包突发、接触刚度漂移。
- **Shield-Skill → Shield-T**：在技能前置投影之外增加**时间投影**；若 `Δ(t)>Δ_max` 或 `ρ_pass<0`，不输出不可信 K，而是降级为局部 passive hold，并写入 `stale_flag`。
- **OCB-Skill → OCB-T**：臂空间增加「延迟应对模式」与「力控模式」，奖励显式扣除延迟导致的失稳/切换代价，让系统在「预测补偿 / 保守阻尼 / 局部保持」之间按场景调度预算。

**灵感 5（本轮的可证伪核心）**
本轮不试图证明「延迟越大越鲁棒」，而是给出三个可被实验直接推翻的断言：
1. 未建模延迟会在 RSC 残差中产生**一阶偏差** `O(δ)`，使 φ 球被错误放大/缩小；延迟条件化可把该偏差压到 `O(δ²)`（引理 5）。
2. 在 DCP 的覆盖半径 `δ_α` 内，波变量 + 能量罐的力控闭环保持无源，且接触稳定裕度可由 `E_tank` 与 `δ_α` 下界给出（引理 6）。
3. 时间戳 + 延迟后验 + 能量证书三者缺一不可：去掉任一项，延迟攻击或抖动下的证书覆盖率都会显著下降（E224/E230 的消融）。

## 1. 形式化定义（增量：定义 201–214）

- **定义 201（DAFCO 闭环）**：DAFCO = (LIRO, TSA, DCP, FRO, PFC, WCV-T, TSP, DIR-T, DSB, Shield-T, OCB-T, J_dafco)。定位：LIRO 的「时间 × 力 × 能量」升级；不改变几何/技能/干扰接口，只在其上增加**时间戳、延迟状态、力残差与无源约束**。
- **定义 202（时间戳观测与新鲜度）**：观测 `o_i = (V_i,T_i,P_i,L_i,P_cloud_i, τ_i^s, τ_i^a)`；有效延迟 `δ_i = τ_i^a − τ_i^s`；锚点 `a = (x', φ̂, r, τ_a)` 的新鲜度 `Δ(t)=t−τ_a`；技能 σ 的时间合约 `𝒯_σ = (Δ_max(σ), δ_max(σ), deadline(σ), min_slack(σ))`。
- **定义 203（延迟状态与保形上界）**：延迟状态 `d_t = (δ_eff, jitter, loss, clock_offset)`；DCP 维护条件分位数 `Q_t(α)=inf{δ: P(δ_eff≤δ | history)≥1−α}`，并用 ACI 更新 `α_t`，输出 `δ_α=Q_t(α_t)`；若 CUSUM 检测到延迟分布漂移，则 `α_t` 自适应收紧并触发 DSB 记录。
- **定义 204（延迟条件阻抗族）**：`Z(δ;φ) = (K(δ;φ), D(δ;φ))`，其中 `K(δ;φ)=K_0(φ)+ΔK_δ`、`D(δ;φ)=D_0(φ)+β·δ·K̂_e`；`ΔK_δ` 由无源编译器给出，保证对 `δ∈[0,δ_α]` 的采样族满足能量不等式。实时路径按当前 `δ_eff` 选择 `Z(δ_eff)`，而不是使用固定 K。
- **定义 205（无源裕度与能量罐）**：波变量 `u=(F+b v)/√(2b)`、`w=(F−b v)/√(2b)`，二端口功率 `P=u²−w²`；能量罐 `E_{t+1}=clip(E_t + ΔE_in − ΔE_out, 0, E_max)`。无源裕度 `ρ_pass = min_t E_t − E_min`；若 `ρ_pass<E_margin`，PFC 注入阻尼并削减 K，直至恢复。
- **定义 206（力残差观测器 FRO）**：给定候选延迟 `δ` 与接触模型，`F_pred(t;δ,φ̂,K)=K̂_e(x(t−δ)−x̂_e)+D̂_e v(t−δ)`；`δ̂ = argmax_δ corr(F_meas(t), F_pred(t;δ))`；`r_F(t)=F_meas(t)−F_pred(t;δ̂,φ̂,K)`。FRO 输出 `(δ̂, K̂_e, r_F, confidence)`，其中 `confidence` 由力残差谱与互相关峰值共同给出。
- **定义 207（WCV-T 联合鲁棒编译）**：在联合不确定集 `𝒰 = B(φ̂,r) × Δ(δ̂,δ_α)` 上求
  `K_safe(·) = argmin_{Z∈𝒵_pass} CVaR_ε[ max_{(φ,δ)∈𝒰} execution_loss(Z,φ,δ) ]`，
  约束 `∀(φ,δ)∈𝒰: margin(Z,φ,δ) ≥ 0`、`ρ_pass(Z,δ_α)≥0`、`π_σ∈𝒫_feas(φ̂,r)`；输出阻抗调度 `K_safe(δ)` 与几何冲突标志 `geo_conflict`、时间冲突标志 `time_conflict`。
- **定义 208（时间谓词技能）**：技能 `σ=(name, pre, eff, π_σ, cost, 𝒫_feas, 𝒯_σ)`；`pre` 增加 `fresh(Δ≤Δ_max)`、`delay(δ_eff≤δ_max)`、`force_capacity(F_limit)`；`eff` 增加 `within_deadline`、`force_profile(±ε_F)`、`contact_stable(ρ_pass≥0)`。时间谓词可取布尔或连续 slack。
- **定义 209（TSP 时间技能规划）**：给定目标 G 与时间预算 `(T_deadline, Δ_max)`，搜索 `τ=[σ_1,...,σ_H]` 与绑定 `θ_bind`，使 `eff_{σ_i} ⊨ pre_{σ_{i+1}}`、`eff_{σ_H} ⊨ G`、`Σ cost ≤ budget`，并最大化最小时间 slack：
  `slack(τ) = min_i (deadline(σ_i) − E[finish_i] − κ_δ·δ_α)`；求解器为时间自动机上的层级 A*，软时间谓词转 hinge 代价；实时仅展开首技能在 `[t, t+Δ_slice]` 的切片。
- **定义 210（DIR-T 选择性不变表征）**：`E_dirT: 𝒪 → Z_task ⊕ Z_delay ⊕ Z_nuisance`；目标为 `min I(Z_nuisance; η_nui | task)`、`max I(Z_delay; δ_eff)`、`max I(Z_task; task)`；损失 `ℒ_dirT = ℒ_con(nuisance) + λ_δ·ℒ_pred(δ_eff, force_dynamics) + λ_task·ℒ_task − λ_red·ℒ_redundancy`。延迟不是 nuisance，而是需要保留并预测的**控制变量**。
- **定义 211（DSB 延迟场景银行）**：场景签名 `scene_sig = (V_sig,T_sig,fp_cloud,fp_delay,fp_force,φ_sig,dyn_annot)`；`fp_delay = (Q_50,Q_95,Q_99,jitter,loss_burst,clock_offset)`，`fp_force = (K̂_e, r_F 频谱, passivity_event_count)`；Mine 以 `fp_delay` 与 `fp_force` 的联合距离检索；Mut 增加延迟尖峰（+5σ）、延迟斜坡、重放攻击、丢包突发与接触刚度漂移。
- **定义 212（Shield-T 时间安全屏蔽）**：若 `Δ(t)>Δ_max(σ)` 或 `δ_eff>δ_max(σ)` 或 `ρ_pass<0`，则拒绝当前 K，输出 `passive_hold`（局部阻尼保持/柔顺回撤）并置 `stale_flag=True`；否则对技能参数 θ 做时间-力联合投影 `θ* = argmin_{θ'∈Θ_pre∩Θ_time∩Θ_force} ‖θ'−θ‖`。
- **定义 213（OCB-T 时延-力预算老虎机）**：臂 = `{延迟模式: predictive, wave, conservative, hold} × {力控模式: impedance, admittance, hybrid} × {预测视界: 0, 1, 3} × {USL 模式}`，聚合为 K=24；奖励 `r_t = progress + λ_F·force_tracking − κ·compute − κ_s·switch − κ_d·instability_event`。
- **定义 214（J_dafco 时延-力证书）**：`J_dafco = (J_liro, δ_α, δ̂, ρ_pass, ρ_force, ρ_delay, E_min, Δ_max, stale_flag, fp_delay, cert_hash)`；验证规则：
  `Valid(J_dafco) ⇔ Valid(J_liro) ∧ (δ_eff≤δ_α ∨ stale_flag) ∧ ρ_pass≥0 ∧ ρ_force≥0 ∧ ρ_delay≥0 ∧ (Δ(t)≤Δ_max ∨ J_hold 有效)`。
  其中 `ρ_delay = δ_α − δ_eff` 是延迟余量，`J_hold` 是局部被动保持的降级证书；证书必须同时记录「用哪一帧观测、在什么延迟界下、还剩多少能量」。

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 5（延迟混叠的一阶偏差）**：若 RSC 使用延迟为 δ 的力残差而模型未显式含 δ，则 φ 估计的一阶偏差 `‖φ̂−φ*‖_δ ≤ L_res·δ + O(δ²)`，其中 `L_res` 为接触力对状态/参数的 Lipschitz 常数；未建模延迟会把该偏差误判为参数不确定，导致球半径膨胀约 `L_res·δ`。WCV-T 用 `K(δ)` 与预测残差扣除一阶项，剩余偏差为 `O(δ² + jitter)`。
- **引理 6（延迟下的无源性）**：在波变量散射变换与能量罐下，若 `δ(t)≤δ_α` 且 `|δ̇(t)|≤ρ<1`，能量罐初值 `E_0≥E_margin`，则 `ρ_pass≥0` 蕴含接触二端口无源；若 `ρ_pass<0`，PFC 的阻尼注入与刚度削减在有限步内使能量回到安全域（假设执行器力/速度饱和可测）。
- **定理 4（时延-力联合安全认证）**：若 DCP 覆盖 `P(δ_eff≤δ_α)≥1−α`，WCV-T 对 `∀(φ,δ)∈𝒰` 给出 `margin≥0` 且 `ρ_pass≥0`，Shield-T 在过期/超界时切换到 `J_hold`，则真实延迟与参数下的接触安全概率至少为 `1−α−α_est−α_hold`，其中 `α_est` 为力观测器估计误差、`α_hold` 为降级保持的失效概率。
- **定理 5（时间技能的成功率下界）**：若每个技能的完成时间满足 `T_i ≤ μ_i + L_i·δ_α`，TSP 选择最小 slack 最大的序列，则截止期满足概率至少 `1−Σ_i P(δ_eff>δ_α) − P(force_profile 越界)`；时间 slack 是延迟尾部与力跟踪误差的显式函数。
- **实时性**：PFC 波变换 O(1)，FRO 互相关窗口 O(W)（W≤16，查表/滑窗），`K(δ)` 查表 O(1)，Shield-T O(1)，总计 <0.15ms；DCP/TSP/DIR-T 仅在语义流（10–100Hz）运行。
- **可证伪性**：若去掉时间戳（TSA）而保留 DCP，延迟尖峰时 `stale_flag` 无法触发；若去掉能量罐（PFC）而保留 WCV-T，延迟抖动下会出现力振荡；若去掉 FRO，`δ̂` 只能靠网络统计，无法识破重放/延迟攻击——三者分别对应 E224/E225/E230 的消融。

## 2. 形式化定义（完整版）

**定义 201（DAFCO 闭环）** DAFCO 在 LIRO 的「语义流 ∘ 实时流」上增加三类状态：时间状态（时间戳、延迟后验、新鲜度）、力状态（力残差、接触刚度、外扰）、能量状态（能量罐、无源裕度）。语义流负责时间规划、延迟预测、联合鲁棒编译与场景记账；实时流只做 TSA 读、FRO 滑窗、PFC 选阻抗、Shield-T 检查与 ERTC 派发。不变式：**任何被实时路径消费的 K 都必须携带「观测时间戳 + 延迟上界 + 无源裕度」三元标签**；无标签的 K 只能用于局部 passive hold。

**定义 202（时间戳观测与新鲜度）** 观测 `o_i` 的采集时间为传感器本地单调时钟 `τ_i^s`，到达时间为接收端本地单调时钟 `τ_i^a`；跨设备只比较差值，不直接比较绝对时钟，避免时钟偏移污染新鲜度。锚点 `a=(x',φ̂,r,τ_a,seq)` 的提交时间 `τ_a` 取语义流完成时刻；新鲜度 `Δ(t)=t−τ_a`。技能 σ 的时间合约 `𝒯_σ=(Δ_max,δ_max,deadline,min_slack)` 由技能库声明，TSP 可收紧但不可放宽安全上界。

**定义 203（延迟状态与保形上界）** 延迟状态 `d_t=(δ_eff,jitter,loss,clock_offset)`。DCP 以最近 W_d 个延迟样本与上下文特征 `c_t`（链路类型、负载、包大小、最近力残差、丢包率）拟合条件分位数 `q_t(α,c)`；对校准集计算非一致性分数 `s_i=δ_i−q_t(α,c_i)`，取 `δ_α=q_t(α,c_t)+Quantile_{1−α_t}({s_i})`。ACI 更新：
`α_{t+1}=clip(α_t+γ(α−err_t), α_min, α_max)`，`err_t=1[δ_t>δ_α]`。
当 CUSUM 统计量超过阈值时，判定延迟分布漂移：提高 `α_t` 的保守度、缩短窗口、触发 DSB 记录；在漂移后的前 N_recover 步使用保守上界 `δ_α←max(δ_α, δ_base)`。DCP 不承诺任意对抗序列下的有限样本覆盖；它承诺在可检测的平稳段内覆盖，并将不可检测的漂移交给 FRO 的物理校验与 Shield-T 的兜底。

**定义 204（延迟条件阻抗族）** `Z(δ;φ)=(K(δ;φ),D(δ;φ))`：
- `K(δ;φ)=K_0(φ)+ΔK_δ`，`ΔK_δ` 由 WCV-T 在延迟网格 `{0, δ_α/4, δ_α/2, 3δ_α/4, δ_α}` 上求出并按 δ 线性插值；
- `D(δ;φ)=D_0(φ)+β·δ·K̂_e`，`β∈[0.5,2.0]` 为阻尼注入系数，`K̂_e` 来自 FRO；
- 对每个 δ 网格点，PFC 验证能量不等式 `E_{t+1}≥E_min`（采样 H_pass 步）；不满足则增大 D 或削减 K，直到满足。
实时路径按 `δ_eff` 选择 `Z(δ_eff)`；若 `δ_eff` 落在网格之间，用保无源的单调插值（D 向上取整、K 向下取整）。

**定义 205（无源裕度与能量罐）** 波变量变换 `u=(F+bv)/√(2b)`、`w=(F−bv)/√(2b)`，二端口瞬时功率 `P=u²−w²`。离散能量罐：
`E_{t+1}=clip(E_t + η_in·max(u_t²,0)Δt − η_out·max(w_t²,0)Δt, 0, E_max)`。
无源裕度 `ρ_pass=min_t E_t−E_min`。当 `ρ_pass<E_margin` 时，PFC 依次执行：① 增大 D(δ)（阻尼注入）；② 将 K(δ) 乘以 `γ_K∈(0,1)`；③ 若仍不足，进入 passive hold（保持当前关节位置/速度阻尼，不跟踪力）。能量罐参数 `η_in,η_out,E_margin` 由离线接触稳定性实验标定，并作为证书字段写入 J_dafco。

**定义 206（力残差观测器 FRO）** 候选延迟集合 `L={0,Δt,...,L_max}`（L_max=200ms，步长 Δt=2ms 或 5ms）。接触模型 `F_pred(t;δ,φ̂,K)=K̂_e(x(t−δ)−x̂_e)+D̂_e v(t−δ)`。延迟估计：
`δ̂=argmax_{δ∈L} ρ_corr(F_meas(t−W_F:t), F_pred(t−W_F:t;δ,φ̂,K))`，
其中 `ρ_corr` 为归一化互相关；若峰值低于阈值 `ρ_min` 或力残差谱出现异常高频能量，则 `confidence='low'`，DCP 不采用该 δ̂，Shield-T 提高保守度。给定 δ̂ 后，用最小二乘更新 `(K̂_e,x̂_e,F̂_ext)`：
`min_{K_e,x_e,F_ext} Σ_{j=t−W_F}^{t} ‖F_meas(j)−K_e(x(j−δ̂)−x_e)−F_ext‖² + λ‖K_e−K_e^prior‖²`。
输出 `(δ̂,K̂_e,r_F,confidence)`；`r_F` 同时作为延迟混叠与 φ 偏差的证据。

**定义 207（WCV-T 联合鲁棒编译）** 联合不确定集 `𝒰=B(φ̂,r)×Δ(δ̂,δ_α)`。WCV-T 求
`K_safe(·)=argmin_{Z∈𝒵_pass} CVaR_ε[ max_{(φ,δ)∈𝒰} execution_loss(Z,φ,δ) ]`，
约束：
1. `∀(φ,δ)∈𝒰: margin(Z,φ,δ)≥0`（力/力矩/接触安全）；
2. `ρ_pass(Z,δ_α)≥0`（无源裕度）；
3. `π_σ∈𝒫_feas(φ̂,r)`（技能鲁棒可行，继承定义 200）；
4. `∀δ∈[0,δ_α]: Z(δ) 在网格点上通过能量验证`。
采样：φ 从 B(φ̂,r) 采 n_φ=16，δ 从 Δ 采 n_δ=8，共 128 组；按 `execution_loss` 排序取尾部 `⌈ε·N⌉=8` 组做 CVaR。几何约束 `𝒢(g)` 仍用于剪枝，但增加时间约束：若某候选 φ 需要 δ>δ_α 才能安全，则判为 `time_conflict`。输出 `(K_schedule, ρ_rob, ρ_pass, geo_conflict, time_conflict)`。

**定义 208（时间谓词技能）** 技能 `σ=(name,pre,eff,π_σ,cost,𝒫_feas,𝒯_σ)`。时间谓词：
- `fresh(Δ≤Δ_max)`：锚点仍在有效窗口；
- `delay(δ_eff≤δ_max)`：当前延迟不超过技能声明的安全延迟；
- `force_capacity(|F|≤F_limit·(1−ε_F))`：执行器与接触力留有余量；
- `within_deadline(t_finish≤deadline)`：完成时刻约束；
- `force_profile(|F(t)−F_ref(t)|≤ε_F·|F_ref|)`：力跟踪带；
- `contact_stable(ρ_pass≥0)`：能量罐未越界。
每个谓词可返回布尔值或连续 slack；CSP 用 hinge 代价软化。

**定义 209（TSP 时间技能规划）** 时间自动机状态 `(skill, t_lower, t_upper, slack_so_far, force_state)`。转移满足：
- `eff_{σ_i}⊨pre_{σ_{i+1}}`（符号蕴含）；
- `t_lower_{i+1} ≥ t_upper_i + travel_time(σ_i,σ_{i+1})`；
- `t_upper_i ≤ deadline_i − κ_δ·δ_α`（延迟保守余量）；
- `Σ cost ≤ budget`。
目标：在可行序列中最大化 `slack(τ)=min_i(deadline_i−E[finish_i]−κ_δδ_α)`，同时惩罚技能切换。求解：高层在技能图上做 A*，启发式用「剩余技能的最小代价 + 剩余 deadline 的最大松弛」；低层对候选序列用 L-BFGS 优化 θ_bind，将时间与力谓词转为 hinge。实时仅展开首技能在 `[t, t+Δ_slice]` 的阻抗/力指令切片，`Δ_slice` 不超过 `min(Δ_max, δ_max)`。

**定义 210（DIR-T 选择性不变表征）** 编码器 `E_dirT: 𝒪→Z_task⊕Z_delay⊕Z_nuisance`（维度 64+32+32）。目标：
- 对 nuisance（传感器噪声、纹理攻击、光照、非接触扰动）不变：`min I(Z_nuisance;η_nui|task)`；
- 对延迟等变/可预测：`max I(Z_delay;δ_eff)`，并用 `Z_delay` 回归延迟参数与力动态；
- 对任务充分：`max I(Z_task;task)`；
- 三者尽量不冗余：`min I(Z_task;Z_delay)`。
损失：
`ℒ_dirT = ℒ_con(nuisance) + λ_δ·(ℒ_reg(δ_eff)+ℒ_pred(F_{t+1:t+H}|Z_delay)) + λ_task·ℒ_task − λ_red·ℒ_red`。
与 DIR 的关键差别：**不把延迟当 nuisance 洗掉**。DIR 的对比学习只作用于 nuisance 分支；延迟分支用监督/自监督预测训练，保留补偿所需信息。

**定义 211（DSB 延迟场景银行）** 场景签名 `scene_sig=(V_sig,T_sig,fp_cloud,fp_delay,fp_force,φ_sig,dyn_annot)`：
- `fp_delay=(Q50,Q95,Q99,jitter,loss_burst,clock_offset)`，由最近 W_d 个延迟样本计算；
- `fp_force=(K̂_e,r_F 频谱,passivity_event_count)`，由 FRO 与 PFC 事件计算；
- `Mine`：延迟指纹与力指纹的联合距离 `d=‖fp_delay−fp_delay'‖_1/6 + ‖fp_force−fp_force'‖_1/4`，`d<τ_fp` 视为同场景；若遇险情且无匹配，则创建新场景；
- `Mut`：继承 SSB 的几何变异，新增 ① 延迟尖峰（`δ←δ+5σ_δ`，持续 50–200ms）；② 延迟斜坡（0→δ_α，斜率 2δ_α/s）；③ 重放攻击（旧观测重复注入）；④ 丢包突发（20% 连续丢包 100ms）；⑤ 接触刚度漂移（`K_e←1.5K_e` 或 `0.6K_e`）。
簇数 C≤64，Hedge 权重低于 0.01 的簇合并/淘汰。

**定义 212（Shield-T 时间安全屏蔽）** 给定提案 θ 与技能 σ：
1. 时间检查：`Δ(t)>Δ_max(σ)` 或 `δ_eff>δ_max(σ)` 或 `ρ_pass<0` → 返回 `passive_hold`（保持当前位置/速度阻尼，力参考设为 0 或柔顺回撤），置 `stale_flag=True`；
2. 参数投影：`θ*=argmin_{θ'∈Θ_pre∩Θ_time∩Θ_force}‖θ'−θ‖`，其中 `Θ_time` 为时间谓词的凸松弛（deadline 线性、freshness 线性、force_profile 二次），`Θ_force` 为力/力矩限幅的盒约束；
3. 若 `‖θ*−θ‖_∞>δ_skill`，降级 `ask_clarify_skill` 或 `passive_hold`，并记录 `violated_preds`。
通过 Shield-T 的 θ* 才进入 TSP 参数绑定与 ERTC 展开。

**定义 213（OCB-T 时延-力预算老虎机）** 臂空间：
`{延迟模式: predictive, wave, conservative, hold} × {力控模式: impedance, admittance, hybrid} × {预测视界: 0, 1, 3} × {USL 模式: full_seq, single_skill, cached_seq, frozen}`，
聚合为 K=24（保持 EXP3 效率）。奖励：
`r_t = clip(progress_t + λ_F·(1−|F−F_ref|/F_ref) − κ·compute_t − κ_s·switch_t − κ_d·1[instability_event], 0, 1)`。
重要性加权更新 `w_a←w_a·exp(η·r̂_t)`；硬降级规则：hold 模式始终可用；若 EXP3 选择 predictive 但 `δ_α` 超阈值，强制切 conservative/hold。技能切换惩罚与延迟模式切换惩罚分开计。

**定义 214（J_dafco 时延-力证书）** `J_dafco=(J_liro,δ_α,δ̂,ρ_pass,ρ_force,ρ_delay,E_min,Δ_max,stale_flag,fp_delay,cert_hash)`。
- `ρ_force=min_t(F_limit−|F_t|, τ_limit−|τ_t|, contact_margin_t)`；
- `ρ_delay=δ_α−δ_eff`；
- `ρ_pass=min_{t∈[0,H]}E_t−E_min`；
- `Valid(J_dafco)⇔Valid(J_liro) ∧ (δ_eff≤δ_α) ∧ ρ_pass≥0 ∧ ρ_force≥0 ∧ ρ_delay≥0 ∧ (Δ(t)≤Δ_max ∨ J_hold 有效)`。
若 `stale_flag=True`，则 `J_liro` 被替换为 `J_hold`（局部 passive hold 的力/位置/能量证书），并且 `Valid` 只主张保持阶段的安全，不主张任务完成。`cert_hash=hash(δ_α,δ̂,ρ_pass,ρ_force,τ_a,skill_seq_hash,fp_delay)` 用于审计「证书用了哪一帧、在什么延迟界下、剩多少能量」。

```python
        self.seq = 0
```

```python
class DelayConformalPredictor:
    def __init__(self, alpha=0.05, gamma=0.01, window=256,
                 alpha_min=0.005, alpha_max=0.2):
        self.alpha_t = alpha
        self.gamma = gamma
        self.window = window
        self.alpha_min, self.alpha_max = alpha_min, alpha_max
        self.scores = deque(maxlen=window)
        self.q_model = QuantileRegressor()   # q_t(alpha, context)
        self.cusum_pos = self.cusum_neg = 0.0
        self.delta_alpha = 0.05

    def update(self, delta_obs, context):
        q = self.q_model.predict(self.alpha_t, context)
        self.scores.append(delta_obs - q)
        level = min(1.0, 1.0 - self.alpha_t)
        conformal_q = np.quantile(np.asarray(self.scores), level, method='higher')
        self.delta_alpha = max(0.0, q + conformal_q)
        miss = float(delta_obs > self.delta_alpha)
        # ACI: increase alpha (less conservative) when miss rate low
        self.alpha_t = np.clip(
            self.alpha_t + self.gamma * (0.05 - miss),
            self.alpha_min, self.alpha_max)
        # CUSUM drift detection
        self.cusum_pos = max(0.0, self.cusum_pos + miss - 0.05)
        self.cusum_neg = max(0.0, self.cusum_neg - miss + 0.05)
        drift = max(self.cusum_pos, self.cusum_neg) > 5.0
        if drift:
            self.delta_alpha = max(self.delta_alpha, 0.10)
            self.scores.clear()
            self.cusum_pos = self.cusum_neg = 0.0
        return self.delta_alpha, drift
```

```python
class ForceResidualObserver:
    def __init__(self, lags_ms=(0, 2, 4, ..., 200), w_force=64,
                 rho_min=0.3):
        self.lags = [int(x * 0.001 / DT) for x in lags_ms]
        self.w_force = w_force
        self.rho_min = rho_min
        self.buffer_F = deque(maxlen=w_force + max(self.lags))
        self.buffer_x = deque(maxlen=w_force + max(self.lags))
        self.buffer_v = deque(maxlen=w_force + max(self.lags))

    def observe(self, F_meas, x, v, phi_hat, K_cmd):
        self.buffer_F.append(F_meas)
        self.buffer_x.append(x)
        self.buffer_v.append(v)
        if len(self.buffer_F) < self.w_force + max(self.lags):
            return None
        F = np.asarray(self.buffer_F)
        best = None
        for lag in self.lags:
            x_d = np.asarray(self.buffer_x)[-self.w_force-lag:-lag or None]
            v_d = np.asarray(self.buffer_v)[-self.w_force-lag:-lag or None]
            F_pred = self.contact_model(x_d, v_d, phi_hat, K_cmd)
            rho = np.corrcoef(F[-self.w_force:], F_pred)[0, 1]
            if best is None or rho > best[1]:
                best = (lag, rho, F_pred)
        lag, rho, F_pred = best
        confidence = 'high' if rho >= self.rho_min else 'low'
        # least-squares contact stiffness update
        Ke_hat, xe_hat, F_ext = self.ls_fit(F[-self.w_force:], x, v, lag)
        r_F = F[-self.w_force:] - F_pred
```

### IP-207 PFC（无源力编译器）

```python
class PassivityForceCompiler:
    def __init__(self, b=50.0, E_max=1.0, E_min=0.15, E_margin=0.05):
        self.b, self.E_max, self.E_min, self.E_margin = b, E_max, E_min, E_margin
        self.E = 0.5

    def wave(self, F, v):
        u = (F + self.b * v) / np.sqrt(2 * self.b)
        w = (F - self.b * v) / np.sqrt(2 * self.b)
        return u, w

    def update_tank(self, F, v, dt, eta_in=0.9, eta_out=0.9):
        u, w = self.wave(F, v)
        dE = eta_in * max(u * u, 0) * dt - eta_out * max(w * w, 0) * dt
        self.E = np.clip(self.E + dE, 0, self.E_max)
        return self.E

    def select(self, K_schedule, delta):
        Z = K_schedule.at(delta)          # D monotone-up, K monotone-down
        if self.E - self.E_min < self.E_margin:
            Z = K_schedule.inject_damping(Z, delta, factor=1.5)
            Z = K_schedule.scale_stiffness(Z, factor=0.7)
        if self.E <= self.E_min:
            return K_schedule.passive_hold(), 'hold'
        return Z, 'nominal'

    def passive_hold(self, q, v):
        # local joint-space damping; no force tracking, no remote dependency
        return {"mode": "hold", "tau": -D_HOLD * v, "q_ref": q}
```

```python
def wcv_t_compile(olp_t, x_prime, eeis, phi_hat, r, g, delta_hat,
                  delta_alpha, eps=0.1, n_phi=16, n_delta=8,
                  kappa_phi=KAPPA_PHI):

    Deltas = np.linspace(0.0, delta_alpha, n_delta)
    U = [(p, d) for p in Phi for d in Deltas]

    candidates = []
    for p, d in U:
        K0 = olp_t.project(x_prime)                     # x' already geometry-fused
        Z = compile_delay_family(K0, p, d, Ke_hat=fro.Ke_hat)
        if not passivity_check(Z, d, tank=EnergyTank()):
            continue

        margin = safety_margin(K_c, p)
        loss_i = execution_loss_estimate(K_c, p, d)
        candidates.append((p, d, Z, K_c, margin, loss_i))

    if not candidates:
        return None, -1.0, -1.0, True, True

    candidates.sort(key=lambda z: z[5], reverse=True)
    tail = candidates[:max(1, int(eps * len(candidates)))]
    # build schedule over delta grid; CVaR over worst phi at each delta
    grid = np.linspace(0.0, delta_alpha, 5)
    K_schedule = DelaySchedule(grid)
    for d in grid:
        at_d = [c for c in tail if abs(c[1] - d) <= delta_alpha / 8]
        if not at_d:
            at_d = sorted(tail, key=lambda c: abs(c[1] - d))[:4]
        K_schedule.set(d, intersect_shrink([c[3] for c in at_d]))
    rho_rob = min(c[4] for c in tail)
    rho_pass = min(passivity_margin(c[2], c[1]) for c in tail)
    geo_conflict = (len(geo_constraint_set(g)) == 0)
    time_conflict = (rho_rob < 0) or (rho_pass < 0)
    return K_schedule, rho_rob, rho_pass, geo_conflict, time_conflict


class DelaySchedule:
    def at(self, delta):
        # monotone-safe interpolation: D up, K down
        return self._interpolate(delta, K_round='down', D_round='up')

    def inject_damping(self, Z, delta, factor):
        return Z.with_damping(Z.D + factor * self.beta * delta * self.Ke_hat)

    def scale_stiffness(self, Z, factor):
        return Z.with_stiffness(factor * Z.K)
```

```python
class TemporalSkillPlanner:
    def __init__(self, usl, max_horizon=5, kappa_delta=1.0):
        self.usl, self.max_horizon = usl, max_horizon
        self.kappa_delta = kappa_delta

    def plan(self, goal, x_prime, phi_hat, r, delta_alpha,
             deadline, budget=100.0):
        feasible = self.usl.get_feasible(phi_hat, r, x_prime)
        # state: (current_skill, seq, t_lower, t_upper, slack_so_far, cost)
        start = ('start', [], 0.0, 0.0, float('inf'), 0.0)
        open_set = [start]
        best = None
        while open_set:
            curr, seq, t_lo, t_hi, slack, cost = heapq.heappop(open_set)
            if seq and goal.holds(seq[-1].eff, phi_hat, x_prime):
                slack = min(slack,
                            deadline - t_hi - self.kappa_delta * delta_alpha)
                if best is None or slack > best[0]:
                    theta_bind = self._optimize_params(
                        seq, x_prime, phi_hat, r, delta_alpha)
                    best = (slack, seq, theta_bind)
            if len(seq) >= self.max_horizon:
                continue
            for nxt in self.usl.skill_graph.successors(curr):
                if nxt not in feasible:
                    continue
                tr = travel_time(curr, nxt)
                lo = t_hi + tr
                hi = lo + nxt.time_contract.duration_max
                slack_n = min(slack,
                              nxt.time_contract.deadline - hi
                              - self.kappa_delta * delta_alpha)
                if slack_n < nxt.time_contract.min_slack:
                    continue
                cost_n = cost + nxt.cost + switch_penalty(seq, nxt)
                if cost_n > budget:
                    continue
                heapq.heappush(open_set,
                               (nxt, seq + [nxt], lo, hi, slack_n, cost_n))
        if best is None:
            return [self.usl.skills['safe_idle']], [None], -1.0
        return best[1], best[2], best[0]
```

```python
class DelaySelectiveRepresentation:
    def __init__(self, d_obs=512, d_task=64, d_delay=32, d_nuis=32,
                 tau=0.1):
        self.enc = MLP(d_obs, [256, 256], d_task + d_delay + d_nuis)

        self.head_delay = MLP(d_delay, [64], 3)      # delta quantiles
        self.head_force = MLP(d_delay, [64, 64], 16) # force horizon
        self.tau = tau

    def forward(self, O):
        z = self.enc(O)
        return (z[:self.d_task],
                z[self.d_task:self.d_task + self.d_delay],
                z[self.d_task + self.d_delay:])

    def loss(self, batch_O, delta_labels, force_targets, tasks):
        zt, zd, zn = zip(*[self.forward(O) for O in batch_O])
        zt, zd, zn = torch.stack(zt), torch.stack(zd), torch.stack(zn)
        # nuisance contrastive: positive is same task under nuisance augmentation
        zn_pos = torch.stack([self.forward(aug_nuisance(O))[2] for O in batch_O])
        L_con = contrastive(zn, zn_pos, tau=self.tau)
        # delay is equivariant/predictive, not invariant
        L_delay = F.mse_loss(self.head_delay(zd), delta_labels) \
                  + F.mse_loss(self.head_force(zd), force_targets)
        L_task = F.cross_entropy(self.head_task(zt), tasks)
        L_red = redundancy(zt, zd) + redundancy(zt, zn)
        return L_con + 1.0 * L_delay + 1.0 * L_task - 0.1 * L_red
```

```python
class DelayForceBudgetBandit:
    ARMS = [(dm, fm, h, usl)
            for dm in ('predictive', 'wave', 'conservative', 'hold')
            for fm in ('impedance', 'admittance', 'hybrid')
            for h in (0, 1, 3)
            for usl in ('full_seq', 'single_skill')
            if (h == 0) or (dm == 'predictive')]   # 24 arms
    def __init__(self, eta=0.3):
        self.w = np.ones(len(self.ARMS)) / len(self.ARMS)
        self.eta = eta

    def choose(self):
        return np.random.choice(len(self.ARMS), p=self.w)

    def update(self, idx, progress, force_error, compute, switch,
               instability):
        reward = np.clip(progress + 1.0 * (1 - force_error)
                         - 0.2 * compute - 0.1 * switch
                         - 0.5 * instability, 0, 1)
        r_hat = reward / max(self.w[idx], 1e-6) / len(self.ARMS)
        self.w[idx] *= np.exp(self.eta * r_hat / len(self.ARMS))
        self.w /= self.w.sum()
```

## 4. 推导

**引理 5（延迟混叠的一阶偏差）** 设接触力映射 `F=Φ(x,φ)` 对状态与参数分别 Lipschitz：`‖Φ(x,φ)−Φ(x',φ)‖≤L_x‖x−x'‖`、`‖Φ(x,φ)−Φ(x,φ')‖≤L_φ‖φ−φ'‖`。RSC 使用延迟 δ 的残差 `e_t=F_meas(t)−F_pred(t)=Φ(x_t,φ*)+n_t−Φ(x_{t−δ},φ̂)`。展开：
`e_t ≈ J_x(x_t−x_{t−δ}) + J_φ(φ*−φ̂) + n_t`。
因为 `‖x_t−x_{t−δ}‖≤v_maxδ`，若把延迟项误当作参数偏差，则参数估计误差满足
`‖φ̂−φ*‖_δ ≤ ‖J_φ⁺‖(L_x v_max δ + ‖n‖) + O(δ²) = L_res δ + O(δ²)`。
其中 `L_res=‖J_φ⁺‖L_x v_max`。未建模延迟把该项注入 RSC 的残差，导致球半径膨胀 `≈L_resδ`；WCV-T 在预测残差中显式使用 `x(t−δ̂)`，扣除一阶项，剩余为 `O(δ²)+O(|δ−δ̂|)`。当 `δ̂` 由 FRO 的互相关给出且误差 ≤ε_δ 时，剩余偏差 ≤`L_res(δ²/δ_α+ε_δ)`。∎

**引理 6（延迟下的无源性）** 采用波变量散射变换后，力-速度二端口的能量流可写为 `P=u²−w²`；对任意**常数**延迟 δ，散射变换满足 `∫(u²−w²)dt≥−E_0`（标准波变量无源性）。对**时变**延迟 δ(t)，若 `δ(t)≤δ_α` 且 `|δ̇(t)|≤ρ<1`，则延迟算子 `T_δ` 的增益不超过 `1/(1−ρ)`；能量罐通过 `E_{t+1}=clip(E_t+ΔE_in−ΔE_out,0,E_max)` 吸收离散化、饱和与参数切换造成的能量不一致。若 `E_t≥E_min` 对所有 t 成立，则 `E_t−E_min≥0`，即 `ρ_pass≥0`，二端口无源。若 `ρ_pass<0`，PFC 的阻尼注入使 `D(δ)` 增大、刚度乘 `γ_K<1`，单步耗散增加 `ΔE_diss≥c_D(γ_K,β)Δt`；在力/速度饱和可测的假设下，有限步内使 `E_t` 回到 `E_min+E_margin`。∎

**定理 4（时延-力联合安全认证）** 设事件：
- `A`：`δ_eff≤δ_α`，由 DCP 覆盖假设 `P(A)≥1−α`；
- `B`：WCV-T 对 `∀(φ,δ)∈𝒰` 给出 `margin≥0` 且 `ρ_pass≥0`；
- `C`：Shield-T 在 `Δ>Δ_max` 或 `δ_eff>δ_α` 或 `ρ_pass<0` 时切换到 `J_hold`，且 `J_hold` 在保持阶段的安全概率 ≥`1−α_hold`；
- `D`：FRO 的 `δ̂,K̂_e` 估计误差满足 `α_est` 上界。
在 `B` 确定成立、`A∩C∩D` 发生时，真实延迟与参数下的接触力/力矩/位置满足 WCV-T 的 margin，故安全。由联合界：
`P(safe) ≥ 1−P(A^c)−P(C^c)−P(D^c) ≥ 1−α−α_hold−α_est`。
若 `stale_flag=True`，J_dafco 只主张 `J_hold` 的保持安全，不主张任务完成；因此证书不会把「降级」误写成「任务成功」。∎

**定理 5（时间技能的成功率下界）** 设技能 i 的完成时间 `T_i≤μ_i+L_iδ_α`（在延迟上界内），TSP 选择的序列满足 `slack(τ)≥0`，其中 `slack=min_i(deadline_i−E[finish_i]−κ_δδ_α)`。若延迟尾部事件 `δ_eff>δ_α` 不发生，则每个 `finish_i≤E[finish_i]+L_i(δ_eff−δ_α)≤deadline_i−κ_δδ_α+L_i(δ_eff−δ_α)`。取 `κ_δ≥max_iL_i`，则 `finish_i≤deadline_i`。对 H 个技能用联合界，截止期满足概率 ≥`1−H·P(δ_eff>δ_α)−P(force_profile 越界)`。该下界对 H 线性，因此 TSP 的 `max_horizon=5` 是有意的保守设计。∎

**命题 5.1（延迟条件化的收益）** 在引理 5 的设定下，未建模延迟的最坏参数偏差为 `L_resδ_α+O(δ_α²)`；WCV-T 的联合搜索把 `δ` 作为显式变量，最坏偏差降为 `O(δ_α²)+L_resε_δ`。若 `δ_α≤L_res/2` 且 `ε_δ≤δ_α/2`，则误差至少减半。该命题给出 E222 的可检验预测：`φ` 误差曲线应随 δ 呈线性（LIRO）vs 二次（DAFCO）分离。∎

**命题 5.2（力残差作为延迟证据）** 若接触模型在窗口内近似线性且噪声与命令速度不相关，则 `δ̂` 的互相关峰值位置是 `δ_eff` 的相合估计；其方差随窗口长度 `W_F` 与信噪比增加而下降。若观测被重放/延迟注入攻击，`F_meas` 与当前命令速度的互相关峰值会偏离 `δ_eff`，FRO 的 `confidence` 下降，触发 Shield-T。该命题说明 FRO 不只是「估计器」，也是**延迟完整性检测器**。∎

## 5. 实验设计（E221–E230）

### E221 延迟回放：力控内环稳定性

- **平台**：7-DoF 机械臂 + 1-DoF 线性接触台；网络仿真用 `tc netem` 注入延迟/抖动/丢包。
- **条件**：固定延迟 `{0,20,50,100,150,200}ms` × 抖动 `{0,10,25,50}ms`；丢包 `{0,1,5}%`；接触刚度 `{500,2000,10000}N/m`。
- **基线**：LIRO 固定 K；LIRO + Smith 预测；DAFCO 无 PFC；DAFCO 完整。
- **指标**：接触力 RMS 误差、超调、振荡次数、失稳率（力/速度发散或触发安全停止）、`ρ_pass` 覆盖率。
- **目标**：0–200ms、抖动 ≤50ms 下失稳率 <1%；力跟踪误差 ≤5%；比固定 K 基线提升 ≥40%。

### E222 延迟混叠：φ 估计是否被污染

- **条件**：同一接触任务，人为在 RSC 输入加 `{0,10,30,60,100}ms` 延迟；分别用 LIRO 与 WCV-T。
- **指标**：`‖φ̂−φ*‖`、WCV 球半径 r、覆盖率（真实 φ 是否在球内）、`ρ_rob`。
- **预测**：LIRO 误差随 δ 线性增长；WCV-T 近似二次/平坦；LIRO 球半径被延迟“撑大”，覆盖率虚高但 `ρ_rob` 虚低。
- **目标**：WCV-T 的 φ 误差 ≤10%，球半径不因延迟增加而膨胀 >15%。

### E223 无源认证：ρ_pass 是否覆盖真实失稳

- **条件**：随机延迟轨迹 500 条（含尖峰、斜坡、抖动），每条 30s；记录 `ρ_pass` 与真实失稳标签。
- **指标**：ROC-AUC、覆盖率（`ρ_pass≥0` 时实际稳定的比例）、误报率、平均能量罐水平。
- **目标**：覆盖率 ≥95%，误报 ≤5%，AUC ≥0.9；能量罐在 90% 时间内 ≥`E_min+E_margin`。

### E224 时间规划：TSP vs 无时间 CSP

- **任务**：抓取-搬运-插入-交接的长程任务，给每个子任务 deadline；网络延迟分布从 DSB 采样。
- **基线**：LIRO CSP（无时间谓词）、TSP 无 slack、TSP 完整。
- **指标**：截止期满足率、平均 slack、规划时间、重规划次数、任务完成率。
- **目标**：截止期满足率 +30%，平均 slack +25%，规划时间 <50ms（H=5）。

### E225 黑障降级：通信中断 2s

- **条件**：在接触/插入/交接三个阶段分别切断通信 0.5s/1s/2s；观察是否进入 passive hold。
- **指标**：过力事件数、碰撞数、位置漂移、恢复时间、`stale_flag` 正确率。
- **目标**：100% 进入 hold；过力/碰撞 =0；恢复时间 <200ms；无误发证书。

### E226 力观测器：δ 与 K_e 估计

- **条件**：已知真值延迟与接触刚度；注入力噪声、量化、饱和；对比互相关、相位差、学习式延迟估计。
- **指标**：`|δ̂−δ*|`、`K̂_e` 相对误差、`confidence` 校准（低置信时是否真的差）。
- **目标**：δ 误差 ≤10ms（0–200ms 范围），K_e 误差 ≤15%，低置信样本的误差显著高于高置信。

### E227 DIR-T：选择性不变

- **条件**：四类噪声（光照、纹理、触觉噪声、点云杂波）+ 延迟变化；对比 DIR（全不变）、DIR-T、无延迟分支。
- **指标**：延迟预测 R²、力动态预测误差、任务头在噪声下的漂移、延迟补偿后的力跟踪。
- **目标**：延迟预测 R²≥0.85；噪声不变性不劣于 DIR；力跟踪误差比 DIR 低 ≥20%。

### E228 DSB：延迟指纹检索

- **条件**：训练/测试场景来自不同链路（WiFi/5G/有线）与不同负载；新场景为未见延迟分布。
- **指标**：场景检索 F1、新场景识别率、Hedge 权重收敛、迁移到新延迟分布后的任务成功率。
- **目标**：F1 +25%；新场景识别后 5 次交互内成功率恢复 ≥80%。

### E229 端到端：DAFCO vs LIRO

- **条件**：综合场景（几何 OOD + 技能组合 + 四类干扰 + 网络抖动 + 接触力约束）。
- **指标**：任务成功率、过力/碰撞、截止期满足、证书有效率、平均 `ρ_pass`。
- **目标**：网络抖动场景成功率 +30%；过力事件 =0；证书误发率 <1%。

### E230 延迟攻击：重放/延迟注入/时钟漂移

- **攻击**：① 重放旧观测 100–500ms；② 逐步延迟注入（+10ms/step）；③ 时钟漂移 50–200ppm；④ 力反馈欺骗（叠加低频假力）。
- **指标**：攻击检出率、误报率、证书是否在攻击下被错误签发、hold 触发率。
- **目标**：检出率 ≥90%，误报 ≤5%，攻击下危险证书签发 =0。

## 7. 与 prior art 的差异

| 方向 | 已有工作 | 本轮差异 |
|---|---|---|
| 网络化控制/延迟补偿 | Smith 预测、延迟补偿器、波变量遥操作 | 把延迟上界做成**保形覆盖 + 力残差校验**的运行时证书，并与技能规划/场景银行耦合 |
| 无源力控 | 波变量、能量罐、time-domain passivity control | 把 `ρ_pass` 作为**证书字段**，与 WCV 的 CVaR、Shield 的降级、OCB 的预算共同决策 |
| 延迟感知 MPC/规划 | 鲁棒 MPC、delay-aware scheduling | 技能级时间谓词 + 最小 slack + 实时切片，不是单一连续控制器 |
| 保形预测 | 分布无关覆盖、ACI | 用于**延迟上界**并进入安全证书；同时用 FRO 物理证据检测分布漂移/重放 |
| 力/接触估计 | 力观测器、扰动观测器 | 用互相关同时估计延迟与接触刚度，并把 `r_F` 作为延迟混叠与 φ 偏差的证据 |
| 云/边缘机器人 | 云端规划、边缘推理 | 明确「语义流可延迟、力控内环不可延迟」的时间合约与降级证书 |
| 不变表征 | 域不变/因果表征 | **选择性不变 + 延迟等变**：延迟不是 nuisance，而是需要保留的控制变量 |

本轮的新颖性不在单个组件，而在**把「延迟覆盖、无源裕度、力安全裕度、时间 slack」组合成一个可验证、可降级、可审计的证书**，并让技能规划、鲁棒编译与预算调度都消费同一组时间-力状态。

## 8. 已知风险与缓解

1. **保形覆盖的非平稳失效**：ACI 只给长期覆盖，遇到对抗性延迟/时钟漂移可能短期失效。缓解：CUSUM + FRO 物理校验 + Shield-T 保守兜底；证书显式记录 `δ_α` 与 `stale_flag`。
2. **波变量/能量罐的保守性**：为了保证无源，阻尼注入可能降低力跟踪性能。缓解：只在 `ρ_pass` 接近阈值时注入；用 OCB-T 在 predictive/wave/conservative 之间调度；实验中报告性能-安全 Pareto。
3. **接触模型失配**：FRO 假设线性接触，真实接触可能非线性/摩擦。缓解：只用 FRO 做延迟与刚度的**粗估计**，把残差交给 WCV-T 的 φ 球；高残差时降低置信度并扩大球。
4. **时间谓词过紧**：TSP 的 deadline/slack 可能使规划不可行。缓解：软时间谓词 + 明确的 `time_infeasible` 澄清；降级到 safe_idle，而不是强行执行。
5. **切换抖动**：Shield-T 在边界附近可能频繁 hold/resume。缓解：滞回 + 最小保持时间 + OCB-T 的切换惩罚；hold 恢复需连续 N 步满足 `ρ_pass≥E_margin`。
6. **延迟攻击/重放**：FRO 的互相关可被伪造力欺骗。缓解：多通道时间戳一致性、随机挑战信号、力/速度物理一致性检查；E230 专门测试。

**本轮最大风险**：若 DCP 的保形延迟上界在非平稳或对抗性延迟（延迟注入、时钟漂移、重放）下失效，而 FRO 又被伪造的力残差欺骗，WCV-T 会在「自以为覆盖」的延迟区间内编译出无源裕度虚高的阻抗，证书 J_dafco 从「时间安全保证」退化为「时间幻觉保证」——这是本轮所有时间-力联合论证共同依赖的单点假设。
