# 第 68 轮（承接第 67 轮「SimRAS 仿真增强闭环」IP-233~242；灵感循环新周期第 1 轮；本轮灵感：「腕部相机」×「可靠性」）

> 第 65 轮 VISTA 问「哪一层坏了」，第 66 轮 RAS 问「谁在控制、控制多少」，第 67 轮 SimRAS 问「未来怎么演化、怎么被审计」。三轮都在为**动作**签发证书，却共同默认了一件事：**证据本身是可靠的**。SimRAS 尤其把世界模型与视觉问答当作黑箱审计员，而它们恰恰在分布偏移处最可能「自信地错」。真实机器人上，唯一贴着接触面、又能随机械臂主动移动的传感器，是腕部相机（eye-in-hand）。
>
> 本轮的核心命题：
>
> **把「安全证书」升级为「带可靠度下限的证据证书」：腕部相机不只是一个「看得更近」的相机，它是唯一使感知可靠性成为控制变量的传感器——因为它长在手上，动就是看、看就要动。RelRAS（Reliability-augmented RAS）不再只问「状态是否安全」，而是问「我们是否有足够可靠的观测，去证明它安全」。可靠性不是事后统计出来的指标，而是沿轨迹被主动消耗、探测、刷新与签发的预算。**

## 0. 直觉与动机

**灵感 1（腕部相机 → 内生可靠性）**
直觉：固定相机的可靠性是「外生」的——它坏了你只能停机更换，可靠性是环境给的常数。腕部相机的位姿由控制决定，于是**可靠性成了控制策略的函数**：机械臂加速→运动模糊；贴近物体→被夹爪/物体自遮挡；长任务→镜头污染与手眼标定漂移。控制器一边消耗可靠度、一边又有能力把它挣回来。这把「可靠性」从被动的事后统计，变成在线可优化、可调度的控制资源。

**灵感 2（可靠性 → 从「有故障吗」到「看得到吗」）**
直觉：可靠性工程最朴素的一条是 detection probability 与 coverage——**没报警不等于没问题，可能只是没看见**。前三轮把「未检出故障」当成「安全」，正是典型的「absence of evidence ≠ evidence of absence」。腕部相机 + 可靠性迫使我们显式拆成两个正交维度：
- 安全维：状态是否真安全（`ρ_safe`）；
- 观测维：我们是否可靠地看到了它（`r_t`）。
证书必须同时签这两个维度；只签安全维的证书，在观测不可靠时是**空头支票**。

**灵感 3（主动探测 → 用视差换可靠度）**
直觉：腕部相机可以「多看一眼」。小幅平移/绕行（micro-motion）产生视差，多视角三角化能压低接触位姿与滑移的不确定度。但探测本身要动，动就模糊、还可能扰动接触，所以存在一个**最佳探测速度/驻留时间**：太慢视差基线不够，太快模糊吃掉信息。可靠度对速度是单峰的——这给了我们一个可解析的 `v*`。

**灵感 4（可靠性工程 → 浴盆曲线与预防性「再观测」）**
直觉：腕部相机的可靠性天然服从浴盆曲线：任务开头的「婴儿期」（手眼标定未收敛）、中段「有用寿命」、长任务尾部的「耗损期」（镜头污染、热漂移、线缆疲劳、夹爪遮挡累积）。既然耗损可预测，就能像设备维护一样**排程预防性再标定/再观测块**，把可靠度刷新回目标值——这就是「可靠性预算」的收支平衡：探测是收入，运动与污染是支出，证书只在余额高于下限时才生效。

**灵感 5（见证冗余 → 给 SimRAS 双黑箱上物理见证）**
直觉：SimRAS 最大的风险是世界模型/VQA 在分布外「自信地错」，从而过度放宽容差。腕部相机是一个廉价的**物理见证者**：它看到的滑移或接触丢失，能直接证伪 WM 的「一切正常」。当腕部、固定相机、力/触觉三路见证不一致时，我们不平均、不投票放行，而是**下调 `r_t` 并否决任何 `λ_risk > 1` 的放宽**。这恰好把上一轮的最大风险变成一道可计算的闸门。

**灵感 6（六者合流 → RelRAS）**
`RelRAS = (WOP, RCM, RDF, AVP, RVW, C-RAS-R, RHSP, RelSim)`：
1. **WOP Wrist Observation Provider**：从腕部 RGB-D + 正运动学得到观测量与位姿；
2. **RCM Reliability Calibration Model**：把模糊/遮挡/标定/纹理四因子折成观测质量 `q_t`，再用信息矩阵递推得到 `r_t`；
3. **RDF Reliability Dynamics Field**：建模可靠度的衰减-刷新动力学与「可靠性场」`R(q,v,scene)`；
4. **AVP Active Viewpoint Prober**：在安全微动包络内选探测视点，最大化单位代价信息增益；
5. **RVW Redundancy Witness Voter**：三路见证交叉校验、传感器故障隔离，输出一致性 `A_t`；
6. **C-RAS-R Reliability-Certified Prefix**：把「可认证前缀」扩展为「可观测前缀」，`k_rel` 与 `k_VISTA, k_emo, k_wm` 取交；
7. **RHSP Reliability-Horizon Scheduling**：预测可靠度视界 `τ_unrel`，提前插入再观测/再标定块；
8. **RelSim Reliability Simulation**：在 SimEngine 上加 eye-in-hand 渲染与退化模型（模糊、污损、漂移、自遮挡），离线拟合浴盆失效率与可靠性场。

## 1. 形式化定义（定义 266–280）

- **定义 266（RelRAS 总览）**：`RelRAS = (WOP, RCM, RDF, AVP, RVW, C-RAS-R, RHSP, RelSim)`。定位：把 RAS/SimRAS 的「安全证书」升级为「安全×可观测性」的联合证书。不变式：`Ω` 更新、可靠性场拟合、RelSim 生成只在语义流/离线；实时流只读取 `q_t, r_t, τ_unrel` 与门控标志，零学习写操作。
- **定义 267（腕部相机观测量）**：由正运动学 `T_t^{wc} = FK(q_t) · T_{ce}` 得腕部相机位姿；观测 `y_t = (I_t^{RGB}, D_t^{D})`，末端速度 `v_t`、曝光 `T_exp`。观测量包含接触位姿、滑移旋量、法向力估计的特征 `y_t ∈ ℝ^{d_y}`。
- **定义 268（观测质量分解）**：`q_t = q_t^{blur} · q_t^{occ} · q_t^{cal} · q_t^{tex} ∈ [0,1]`，其中
  - `q_t^{blur} = exp(-(‖v_t‖·T_exp/ρ_blur)²)`（运动模糊）；
  - `q_t^{occ} = 1 - A_occ/A_roi`（夹爪/物体/自遮挡面积比）；
  - `q_t^{cal} = exp(-‖Δξ_t^{he}‖²/σ_cal²)`（手眼标定残差）；
  - `q_t^{tex} = clip(mean‖∇I_t‖/τ_tex, 0, 1)`（纹理/光照可用度）。
- **定义 269（接触状态后验与信息矩阵）**：接触状态 `g_t = (pose, slip_twist, f_n, μ)`；观测模型 `y_t = H_t g_t + n_t`，`n_t ~ N(0, R/q_t)`。后验精度 `Ω_t = Σ_t^{-1}`，按信息滤波递推：
  `Ω_t = γ·Ω_{t-1} + q_t·H_t^T R^{-1} H_t`，`γ ∈ (0,1)` 为遗忘因子（应对非平稳世界）。
- **定义 270（观测可靠性）**：`r_t = 1 - exp(-tr(Ω_t)/τ_Ω) ∈ [0,1)`。含义：在当前信息量下，接触状态估计落在容差内的概率下界（Gaussian 后验下可由 `tr(Σ_t)` 直接换算）。
- **定义 271（可靠性动力学）**：给定动作序列，可靠度按 `Ω_{t+i} = γ^i Ω_t + Σ_{j≤i} q_{t+j}·H_{t+j}^T R^{-1} H_{t+j}` 演化；无新观测时 `Ω` 以 `γ` 指数衰减，故 `r_{t+i}` 单调下降。探测/驻留通过增大 `q` 与新增独立 `H_u` 刷新 `Ω`。
- **定义 272（可靠性场）**：`R(q, v, scene) → [0,1]` 为腕部位姿 `q`、末端速度 `v` 下可达的观测质量期望。由 RelSim 离线拟合 + 在线残差校正；它把「看得清」变成位姿空间上的一个可查询场。
- **定义 273（主动视点探测 AVP）**：探测动作 `u_t ∈ U_safe`（保持接触的微动包络），选取
  `u* = argmax_{u∈U_safe} [ ΔI(Ω_t; u) - c_task(u) - c_safe(u) ]`，
  其中 `ΔI(Ω;u) = logdet(Ω + q(u)H_u^T R^{-1}H_u) - logdet(Ω)`。
- **定义 274（可靠性裕度/预算）**：`τ_unrel(t) = min{k : r̂_{t+k} < r_min}`，即「还能维持可靠观测多少步」。证书要求 `τ_unrel(t) ≥ k* + t_repair`，其中 `t_repair` 是一次再观测/再标定块的耗时；等价的预算 `B_t = τ_unrel(t) - t_repair` 必须非负。
- **定义 275（见证冗余与一致性）**：三路见证 `y^w`（腕部）、`y^f`（固定相机）、`y^τ`（力/触觉）；一致性
  `A_t = exp(-⅓ Σ_{pairs} ‖y^i - y^j‖²_{S_{ij}}) ∈ (0,1]`，`S_{ij}` 为按各自可靠度缩放的白化矩阵。`A_t` 越低，说明至少一路在说谎。
- **定义 276（可靠性认证前缀）**：`k_rel = max{k : ∀i≤k, r̂_{t+i} ≥ r_min ∧ λ_risk_{t+i}·ρ_safe_{t+i} ≥ 0}`；最终 `k*RelRAS = min(k_VISTA, k_emo, k_wm, k_rel, m)`。
- **定义 277（可靠性修复块 RHSP）**：当 `τ_unrel(t) < k_chunk + t_repair` 或 `A_t < τ_w` 时，在执行下一个块前插入修复块：以 `v*` 做驻留-扫描再观测，必要时再标定；修复后要求 `r ≥ r_target`。
- **定义 278（RelSim 可靠性仿真）**：在 SimEngine 上加 eye-in-hand 渲染器与退化模型（运动模糊、镜头污损、标定漂移、自遮挡、光照），采样 `(q, v, scene) → q_t` 与浴盆失效率，离线输出可靠性场与 `τ_unrel` 标定表。
- **定义 279（失效率与浴盆曲线）**：危害率 `h(t)`，生存函数 `R_surv(t) = exp(-∫_0^t h)`；平均不可靠观测时间 `MTUO = ∫_0^∞ R_surv(t)dt`。三阶段：婴儿期（标定未收敛）、有用寿命（近似常数 `h`）、耗损期（`h` 单调上升）；在 `h(t) > h*` 前安排预防性再标定。
- **定义 280（J_RelRAS 证书）**：`J_RelRAS = (J_SimRAS, r_t, τ_unrel, A_t, MTUO_est, recalib_log, rcm_ver)`。Valid ⇔ `Valid(J_SimRAS) ∧ r_t ≥ r_min ∧ τ_unrel ≥ k* + t_repair ∧ (A_t ≥ τ_w ∨ λ_risk ≤ 1)`。

## 2. 关键算法骨架

```python
# WOP：腕部观测提供者
class WristObservationProvider:
    def __init__(self, kin, T_ce, rho_blur=2.0, sigma_cal=0.01, tau_tex=0.1):
        self.kin, self.T_ce = kin, T_ce
        self.rho_blur, self.sigma_cal, self.tau_tex = rho_blur, sigma_cal, tau_tex

    def observe(self, rgb, depth, q_joint, v_ee, T_exp):
        T_wc = self.kin.fk(q_joint) @ self.T_ce
        blur = (np.linalg.norm(v_ee) * T_exp) / self.rho_blur
        q_blur = math.exp(-blur ** 2)
        q_occ  = 1.0 - self.gripper_occlusion(rgb)
        q_cal  = math.exp(-(self.handeye_residual() ** 2) / self.sigma_cal ** 2)
        q_tex  = min(1.0, self.texture_score(rgb) / self.tau_tex)
        q = q_blur * q_occ * q_cal * q_tex
        y = self.extract_contact_features(rgb, depth)
        return {'y': y, 'q': q, 'T_wc': T_wc, 'blur': blur}


# RCM：可靠度递推
class ReliabilityModel:
    def __init__(self, H, R, gamma=0.98, tau_Omega=1.0, r_min=0.7):
        self.H, self.R = H, R
        self.gamma, self.tau_Omega, self.r_min = gamma, tau_Omega, r_min
        self.Omega = np.eye(H.shape[1]) * 1e-3

    def update(self, q, H=None):
        H = self.H if H is None else H
        self.Omega = self.gamma * self.Omega + q * H.T @ np.linalg.inv(self.R) @ H
        return self.Omega

    def reliability(self, Omega=None):
        Omega = self.Omega if Omega is None else Omega
        return 1.0 - math.exp(-np.trace(Omega) / self.tau_Omega)

    def horizon(self, actions, q_next=1.0):
        Om, k = self.Omega.copy(), 0
        while k < len(actions):
            Om = self.gamma * Om  # 无新观测 → 衰减
            if 1.0 - math.exp(-np.trace(Om) / self.tau_Omega) < self.r_min:
                break
            k += 1
        return k


# AVP：主动视点探测（子模贪心）
class ActiveViewpointProber:
    def __init__(self, H_fn, R, v_max=0.2, dt=0.05, tau=2.0, c_safe=1.0):
        self.H_fn, self.R, self.v_max, self.dt = H_fn, R, v_max, dt
        self.tau, self.c_safe = tau, c_safe

    def info_gain(self, Omega, v):
        H = self.H_fn(v * self.dt)          # 视差基线 b = v·dt
        q = math.exp(-(v / self.tau) ** 2)  # 速度带来的模糊
        return (np.linalg.slogdet(Omega + q * H.T @ np.linalg.inv(self.R) @ H)[1]
                - np.linalg.slogdet(Omega)[1])

    def choose(self, Omega):
        best, best_val = None, -1e18
        for v in np.linspace(0.0, self.v_max, 9):
            val = self.info_gain(Omega, v) - self.c_safe * v
            if val > best_val:
                best, best_val = v, val
        return best


# RVW：见证冗余投票 + 故障隔离
def witness_consistency(y_w, y_f, y_t, Sw, Sf, St):
    pairs = [(y_w, y_f, Sw, Sf), (y_w, y_t, Sw, St), (y_f, y_t, Sf, St)]
    d = np.mean([np.sum((a - b) ** 2 / (Sa + Sb)) for a, b, Sa, Sb in pairs])
    return math.exp(-d), d


# C-RAS-R：可观测认证前缀
def certified_prefix_rel(A_chunk, joint_post, rel_model, m, r_min, k_wm):
    Om, k = rel_model.Omega.copy(), 0
    for i in range(min(len(A_chunk), m)):
        Om = rel_model.gamma * Om
        r_i = rel_model.reliability(Om)
        if r_i < r_min:
            break
        safe = all(_safety_with_risk(A_chunk[i], h, e, p)
                   for (h, e), p in sorted(joint_post.items(),
                                           key=lambda x: x[1], reverse=True)[:3])
        if not safe:
            break
        k = i + 1
    return min(k, k_wm)


# RelRAS：一轮闭环
def RelRAS_round(M, obs):
    rgb, depth, q_joint, v_ee, T_exp = obs
    # 1) 腕部观测 + 质量
    wrist = M.wop.observe(rgb, depth, q_joint, v_ee, T_exp)
    # 2) 可靠度更新
    M.rcm.update(wrist['q'])
    r_t = M.rcm.reliability()
    # 3) 见证冗余
    A_t, _ = witness_consistency(wrist['y'], M.fixed_y, M.force_y,
                                 M.Sw, M.Sf, M.St)
    # 4) 低可靠/不一致 → 先探针或修复
    if A_t < M.tau_w or r_t < M.r_min:
        v = M.avp.choose(M.rcm.Omega)
        M.execute_micro_scan(v, dwell=M.t_dwell)
        M.rcm.update(M.wop.current_quality_after_scan())
        r_t = M.rcm.reliability()
    # 5) 预测可靠度视界，必要时插修复块
    tau_unrel = M.rcm.horizon(M.chunk_actions)
    if tau_unrel < M.k_chunk + M.t_repair:
        M.insert_repair_block()
    # 6) 认证前缀（安全 × 可观测）
    k_rel = certified_prefix_rel(M.chunk_actions, M.joint_post, M.rcm,
                                 M.m, M.r_min, M.k_wm)
    # 7) 见证否决：不一致时禁止放宽
    lambda_cap = 1.0 if A_t < M.tau_w else 1.2
    lambda_risk = min(M.efs_wm.risk_scale(M.joint_post), lambda_cap)
    tau_cmd = M.ers_wm.shaping(M.vista.dispatch(M.chunk_actions[:k_rel]),
                               M.joint_post)
    tau_cmd = tau_cmd * lambda_risk
    return k_rel, r_t, tau_unrel, A_t, lambda_risk
```

## 3. 推导

**引理 13（可靠性衰减界与可观测视界）** 若一个块内不插入新观测，则 `Ω_{t+k} = γ^k Ω_t`，于是 `r_{t+k} = 1 - exp(-γ^k·tr(Ω_t)/τ_Ω)`。令 `r_{t+k} ≥ r_min`，解得可观测视界
`k_decay ≤ ln(tr(Ω_t)/(τ_Ω·ln(1/(1-r_min)))) / ln(1/γ)`。
这给出一个可离线预计算的 `τ_unrel` 下界：遗忘越快（`γ` 越小）、要求越严（`r_min` 越高），可认证前缀越短。

**引理 14（探测信息的子模性与贪心近似）** 对线性高斯模型，集合函数 `f(S) = logdet(Ω_0 + Σ_{u∈S} q_u H_u^T R^{-1}H_u)` 是单调子模的。故用贪心依次选择探测视点，其总信息增益不少于最优集合的 `(1 - 1/e)`；且任意两次探测的边际增益随 `|S|` 递减（收益递减），从而探测次数存在经济上限 `N*`。

**定理 14（可靠性-安全联合证书的健全性）** 在 A87–A91 与定义 268–276 下，若 `J_RelRAS` 有效，则
`P(已认证前缀内执行了真实不安全状态) ≤ α_chunk + δ_fi + (1 - r_min)·δ_hidden`，
其中 `δ_hidden` 是「真实不安全但当前观测不可见」的条件概率。直观：即便有未观测到的不安全，其被漏掉的概率被 `r_min` 压住；当 `r_t < r_min` 时证书直接失效（`k*=0`），退化为纯 VISTA 的保守模式。于是「未检出」不再被当作「安全」。

**定理 15（最优探测速度与可认证视界）** 设单次探测信息增益近似 `ΔI(v) ≈ c·q(v)·b(v)²/(b(v)²+σ_d²)`，其中 `q(v)=exp(-(v/τ)²)`、视差基线 `b(v)=v·Δt`。在小基线下 `ΔI(v) ∝ v²·exp(-(v/τ)²)`，对 `v` 求极值得
`v* = τ`（即 `ρ_blur/T_exp` 量纲下的最佳探测速度），此时单次探测信息增益最大。由于可靠度视界 `τ_unrel` 随累计信息单调增，采用 `v*` 的驻留-扫描策略在「模糊 vs 视差」之间取得最优，最大化可认证前缀。

**定理 16（见证否决抑制 SimRAS 过度放宽）** 设 SimRAS 在 WM/VQA 错误但自信时的放宽事件为 `E_relax = {λ_risk > 1}`。RelRAS 加入否决规则 `A_t < τ_w ⇒ λ_risk ≤ 1 ∧ k_rel ≤ k_witness`，于是
`P(E_relax) ≤ P(A_t ≥ τ_w | WM 错误) ≤ ε_false_agree`，
其中 `ε_false_agree` 是三路见证在 WM 错误时仍一致（共谋误判）的概率。由于腕部相机是独立的物理观测通道，`ε_false_agree` 远小于单靠 WM/VQA 自洽的置信度，故上一轮「过度放宽」的最大风险被显著压低。

```python
# IP-243 WOP
class WristObservationProvider:
    def __init__(self, kin, T_ce, rho_blur=2.0, sigma_cal=0.01, tau_tex=0.1):
        self.kin, self.T_ce = kin, T_ce
        self.rho_blur, self.sigma_cal, self.tau_tex = rho_blur, sigma_cal, tau_tex

    def observe(self, rgb, depth, q_joint, v_ee, T_exp):
        T_wc = self.kin.fk(q_joint) @ self.T_ce
        blur = (np.linalg.norm(v_ee) * T_exp) / self.rho_blur
        q_blur = math.exp(-blur ** 2)
        q_occ  = 1.0 - self.gripper_occlusion(rgb)
        q_cal  = math.exp(-(self.handeye_residual() ** 2) / self.sigma_cal ** 2)
        q_tex  = min(1.0, self.texture_score(rgb) / self.tau_tex)
        q = q_blur * q_occ * q_cal * q_tex
        return {'y': self.extract_contact_features(rgb, depth),
                'q': q, 'T_wc': T_wc, 'blur': blur}


# IP-244 RCM
class ReliabilityModel:
    def __init__(self, H, R, gamma=0.98, tau_Omega=1.0, r_min=0.7):
        self.H, self.R = H, R
        self.gamma, self.tau_Omega, self.r_min = gamma, tau_Omega, r_min
        self.Omega = np.eye(H.shape[1]) * 1e-3

    def update(self, q, H=None):
        H = self.H if H is None else H
        self.Omega = self.gamma * self.Omega + q * H.T @ np.linalg.inv(self.R) @ H

    def reliability(self, Omega=None):
        Omega = self.Omega if Omega is None else Omega
        return 1.0 - math.exp(-np.trace(Omega) / self.tau_Omega)

    def horizon(self, n_steps):
        Om, k = self.Omega.copy(), 0
        while k < n_steps:
            Om = self.gamma * Om
            if self.reliability(Om) < self.r_min:
                break
            k += 1
        return k


# IP-246 AVP
class ActiveViewpointProber:
    def __init__(self, H_fn, R, v_max=0.2, dt=0.05, tau=2.0, c_safe=1.0):
        self.H_fn, self.R, self.v_max, self.dt = H_fn, R, v_max, dt
        self.tau, self.c_safe = tau, c_safe

    def info_gain(self, Omega, v):
        H = self.H_fn(v * self.dt)
        q = math.exp(-(v / self.tau) ** 2)
        A = q * H.T @ np.linalg.inv(self.R) @ H
        return (np.linalg.slogdet(Omega + A)[1] - np.linalg.slogdet(Omega)[1])

    def choose(self, Omega):
        vals = [(self.info_gain(Omega, v) - self.c_safe * v, v)
                for v in np.linspace(0.0, self.v_max, 9)]
        return max(vals)[1]


# IP-247 RVW
def witness_consistency(y_w, y_f, y_t, Sw, Sf, St):
    pairs = [(y_w, y_f, Sw, Sf), (y_w, y_t, Sw, St), (y_f, y_t, Sf, St)]
    d = np.mean([np.sum((a - b) ** 2 / (Sa + Sb)) for a, b, Sa, Sb in pairs])
    return math.exp(-d), d


# IP-248 C-RAS-R
def certified_prefix_rel(A_chunk, joint_post, rel_model, m, r_min, k_wm):
    Om, k = rel_model.Omega.copy(), 0
    for i in range(min(len(A_chunk), m)):
        Om = rel_model.gamma * Om
        if rel_model.reliability(Om) < r_min:
            break
        top = sorted(joint_post.items(), key=lambda x: x[1], reverse=True)[:3]
        if not all(_safety_with_risk(A_chunk[i], h, e, p) for (h, e), p in top):
            break
        k = i + 1
    return min(k, k_wm)


# IP-252 RelRAS 闭环
def RelRAS_round(M, obs):
    rgb, depth, q_joint, v_ee, T_exp = obs
    wrist = M.wop.observe(rgb, depth, q_joint, v_ee, T_exp)
    M.rcm.update(wrist['q'])
    r_t = M.rcm.reliability()

    A_t, _ = witness_consistency(wrist['y'], M.fixed_y, M.force_y,
                                 M.Sw, M.Sf, M.St)

    if A_t < M.tau_w or r_t < M.r_min:
        v = M.avp.choose(M.rcm.Omega)
        M.execute_micro_scan(v, dwell=M.t_dwell)
        M.rcm.update(M.wop.current_quality_after_scan())
        r_t = M.rcm.reliability()

    tau_unrel = M.rcm.horizon(len(M.chunk_actions))
    if tau_unrel < M.k_chunk + M.t_repair:
        M.insert_repair_block()

    k_rel = certified_prefix_rel(M.chunk_actions, M.joint_post, M.rcm,
                                 M.m, M.r_min, M.k_wm)
    lambda_cap = 1.0 if A_t < M.tau_w else 1.2
    lambda_risk = min(M.efs_wm.risk_scale(M.joint_post), lambda_cap)

    tau_cmd = M.ers_wm.shaping(M.vista.dispatch(M.chunk_actions[:k_rel]),

    tau_cmd = tau_cmd * lambda_risk

    return k_rel, r_t, tau_unrel, A_t, lambda_risk
```

## 4. 推导

**引理 13（可靠性衰减界与可观测视界）** 块内不插入新观测时 `Ω_{t+k}=γ^kΩ_t`，故 `r_{t+k}=1-exp(-γ^k·tr(Ω_t)/τ_Ω)`。由 `r_{t+k} ≥ r_min` 得
```
k_decay ≤ ln( tr(Ω_t) / (τ_Ω·ln(1/(1-r_min))) ) / ln(1/γ)
```
遗忘越快、要求越严，可认证前缀越短。

**引理 14（探测信息的子模性）** `f(S)=logdet(Ω_0 + Σ_{u∈S} q_u H_u^T R^{-1}H_u)` 单调子模；贪心选择的总信息增益 ≥ 最优的 `(1-1/e)`，且边际增益随 `|S|` 递减，探测次数存在经济上限 `N*`。

**定理 14（可靠性-安全联合证书健全性）** 在 A87–A91 与定义 268–276 下，若 `J_RelRAS` 有效，
```
P(已认证前缀内执行真实不安全状态) ≤ α_chunk + δ_fi + (1 - r_min)·δ_hidden
```
其中 `δ_hidden = P(真实不安全 | 观测不可见)`。当 `r_t < r_min` 时证书失效（`k*=0`），退化为纯 VISTA 保守模式：未检出不再等于安全。

**定理 15（最优探测速度）** 单次探测增益近似 `ΔI(v) ≈ c·q(v)·b(v)²/(b(v)²+σ_d²)`，`q(v)=exp(-(v/τ)²)`、`b(v)=v·Δt`。小基线下 `ΔI(v) ∝ v²exp(-(v/τ)²)`，求极值得 `v* = τ`（量纲上即 `ρ_blur/T_exp`），此速度下模糊与视差折中、单次信息增益最大，可观测视界随之最大。

**定理 16（见证否决抑制过度放宽）** 令 `E_relax={λ_risk>1}`。RelRAS 规则 `A_t<τ_w ⇒ λ_risk≤1 ∧ k_rel≤k_witness` 给出
```
P(E_relax) ≤ P(A_t ≥ τ_w | WM 错误) ≤ ε_false_agree
```
`ε_false_agree` 为三路见证在 WM 错误时仍一致的共谋概率；由于腕部相机是独立物理通道，该值远小于 WM/VQA 自洽置信度，故第 67 轮的最大风险被显著压低。

## 7. 本轮最大风险

**一句话**：RelRAS 用腕部相机自己的观测去估计腕部相机的可靠性，形成自指循环——当遮挡、镜头污染与标定漂移是**系统性**而非随机误差时，可靠度会被系统性高估，「可靠度下限」沦为纸面保证，反而为 SimRAS 的过度放宽提供伪合法依据，这是本方案全部安全声明的核心假设：**腕部观测的质量因子可被自身与冗余见证无偏估计**。
