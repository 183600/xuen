### 第 2 轮灵感驱动研究记录（VLA × 场景落地，承接 v25）

**灵感词**：场景落地、VLA

**直觉与动机**：
SRC-USC v25 已把证书链扩展到「结构-力控-语义-重构-协同」七证一体，但其语义层仍是**地图级**的（实体覆盖、几何一致、开放词汇检索），缺少从**自然语言指令**到**可执行动作**的形式化桥接。VLA（Vision-Language-Action）恰好提供了这条桥：它把指令 ℓ 与观测 o 联合映射为动作块 a_{t:t+H}，但其输出是**随机、黑箱、开放世界**的，天然携带四类失效——指令歧义、指代幻觉、动作越界、分布漂移。受「场景落地」启发，证书链还必须补上**部署侧**的统计保证：ODD 场景覆盖、sim2real 差距界、现场成功率下置信界；否则 v25 只在「已知场景的离线回放」里成立。核心洞见：**VLA 提出候选动作，证书链负责裁决；语言接地把「任务意图」编译为可监控规约，场景落地证书把「实验室保证」换算为「现场保证」**。

**形式化目标**：
1. 定义指令接地证书（IGC）：ℓ ↦ (φ_ℓ, R_ℓ)，要求指代接地 ℙ(referent correct) ≥ 1-α_g、解析歧义熵 H(parse|ℓ) ≤ h_max、规约-安全一致性 SAT(φ_ℓ ∧ Inv_safe) 成立。
2. 定义 VLA 动作一致性证书（VACC）：动作块 conformal 覆盖 ℙ(a_true ∈ C_a(o,ℓ)) ≥ 1-α_a；安全屏蔽 a_safe = Proj_{A_adm}(a_VLA) 且 ‖a_VLA − a_safe‖ ≤ δ_shield；屏蔽后 STL 鲁棒度 ρ(φ_ℓ, τ_shield) ≥ 0。
3. 定义场景落地证书（SLC）：ODD 场景格覆盖 cov ≥ 1-γ；sim2real 差距 |R_sim − R_real| ≤ Δ_max（置信 1−δ）；现场成功率下界 P_success ≥ 1−ε（Clopper–Pearson）。
4. 构建 VLA 部署统一准入门（VDUC）：Exec_v26 = Exec_v25 ∩ Fil_lang ∩ Fil_vla ∩ Fil_scene ⊆ Exec_v25。
5. 证明三条新增退化路径（接地失败→几何回退、动作越界→经典控制回退、场景 OOD→保守降额）下单调退化链保持。

## 1. 关键算法骨架（在 IP-444–447 骨架上扩展）

```python
# ============================================================
# IP-448 Instruction Grounding Certificate (IGC) — 指令接地证书
# ============================================================
@dataclass
class InstructionGroundingCertificate:
    """自然语言 → STL 规约 + 指代接地 + 歧义控制 + 安全一致性"""
    instruction: str
    compiler: 'GrammarConstrainedSTLCompiler'   # 语法约束、可枚举候选解析
    semantic_map: 'SemanticMappingCertificate'  # 复用 IP-444 的语义实体集
    referent_calibrator: 'ConformalCalibrator'  # 指代 conformal 校准器
    safety_invariants: 'STLFormula' = None      # Inv_safe（由 USMC/RMC/MCC 编译）
    alpha_g: float = 0.05                       # 指代接地风险
    h_max: float = 0.5                          # 解析歧义熵阈值 (nats)
    max_parses: int = 64

    def ground(self) -> tuple['STLFormula', list['SemanticEntity'], float]:
        """ℓ ↦ (φ_ℓ, R_ℓ, H)；歧义超阈抛异常而非静默选一个"""
        parses = self.compiler.enumerate(self.instruction, limit=self.max_parses)
        if not parses:
            raise UngroundableInstruction(self.instruction)
        logits = torch.tensor([p.logp for p in parses])
        probs = torch.softmax(logits, dim=0)
        entropy = float(-(probs * torch.log(probs + 1e-12)).sum())
        if entropy > self.h_max:
            raise AmbiguousInstruction(self.instruction, entropy)
        best = parses[int(torch.argmax(probs))]
        return best.phi, best.refs, entropy

    def verify_referential_grounding(self, refs: list['RefExpr']) -> bool:
        """每个指代必须命中语义地图实体，且落入 conformal 候选集"""
        for ref in refs:
            cand_ids = self.referent_calibrator.predict_set(ref)   # 覆盖≥1-α_g
            if not any(e.entity_id in cand_ids for e in self.semantic_map.entities):
                return False
        return True

    def verify_spec_safety_consistency(self, phi: 'STLFormula') -> bool:
        """φ_ℓ 与安全不变式不矛盾，且在当前可达域上可满足"""
        if self.safety_invariants is None:
            return False
        return stl_sat(phi_and(phi, self.safety_invariants))  # 有界时域可判定

    def verify_all(self) -> bool:
        try:
            phi, refs, _ = self.ground()
        except (UngroundableInstruction, AmbiguousInstruction):
            return False
        return (self.verify_referential_grounding(refs) and
                self.verify_spec_safety_consistency(phi))


# ============================================================
# IP-449 VLA Action Conformance Certificate (VACC) — 动作一致性证书
# ============================================================
@dataclass
class VLAActionConformanceCertificate:
    """VLA 动作块的 conformal 覆盖 + 安全屏蔽 + STL 任务鲁棒性"""
    policy: 'VLAPolicy'
    action_calibrator: 'ConformalCalibrator'
    adm_set: 'AdmissibleActionSet'      # A_adm：由 USMC/RMC/MCC 约束构造
    stl_monitor: 'STLMonitor' = None
    alpha_a: float = 0.05               # 动作覆盖风险
    delta_shield: float = 0.15          # 原动作↔屏蔽动作最大偏差
    delta_jerk: float = 0.5             # 动作块 jerk 上限
    horizon: int = 8

    def conformal_action_set(self, obs: Tensor, ell: str) -> Tensor:
        """返回动作块预测集，边际覆盖 ℙ(a_true∈C_a)≥1-α_a"""
        return self.action_calibrator.predict_set(obs, ell)

    def shield(self, a_vla: Tensor) -> Tensor:
        """最小偏差投影：凸松弛 A_adm^cv ⊇ A_adm ⇒ 只多拒、不漏放"""
        return self.adm_set.project_convex(a_vla)

    def verify_conformance(self, obs: Tensor, ell: str, a_vla: Tensor) -> bool:
        a_safe = self.shield(a_vla)
        if torch.norm(a_safe - a_vla) > self.delta_shield:
            return False                          # 离可行域太远，拒证回退
        if not self._jerk_ok(a_safe):
            return False                          # 动作块不连续
        if not self.adm_set.contains(a_safe):     # 投影后仍须在真实可行集
            return False
        if not self._in_conformal_set(a_safe, obs, ell):
            return False                          # 防止黑箱分布外跳变
        return True

    def verify_task_robustness(self, a_safe: Tensor,
                               phi_ell: 'STLFormula',
                               rollout: 'Trajectory') -> bool:
        """屏蔽后仍满足语言规约：ρ(φ_ℓ, τ_shield) ≥ 0"""
        if self.stl_monitor is None:
            return False
        return self.stl_monitor.robustness(phi_ell, rollout) >= 0.0

    def _jerk_ok(self, a: Tensor) -> bool:
        if a.shape[0] < 3:
            return True
        j = a[2:] - 2 * a[1:-1] + a[:-2]
        return torch.norm(j, dim=-1).max().item() <= self.delta_jerk

    def _in_conformal_set(self, a_safe, obs, ell) -> bool:
        C = self.conformal_action_set(obs, ell)
        return bool((torch.norm(a_safe[..., None, :] - C, dim=-1).min() <= 1e-6))


# ============================================================
# IP-450 Scenario Landing Certificate (SLC) — 场景落地证书
# ============================================================
@dataclass
class ScenarioLandingCertificate:
    """ODD 覆盖 + sim2real 差距 + 现场成功率下置信界 + 在线 OOD"""
    odd: 'ODDSpec'                              # (E_env,T_task,B_body,H_human)
    scenario_taxonomy: list['ScenarioCell']
    coverage: dict['ScenarioCell', int]
    sim_real_pairs: list[tuple[float, float]]   # (sim_success, real_success)
    ood_detector: 'OODDetector' = None
    gamma: float = 0.05                         # 覆盖风险
    delta: float = 0.05                         # 差距置信水平
    Delta_max: float = 0.10                     # 允许 sim2real 成功率差
    epsilon: float = 0.10                       # 现场成功率风险

    def verify_odd_coverage(self) -> bool:
        total = sum(self.odd.weight(c) for c in self.scenario_taxonomy)
        covered = sum(self.odd.weight(c) for c in self.scenario_taxonomy
                      if self.coverage.get(c, 0) >= self.odd.n_min(c))
        return total > 0 and covered / total >= 1.0 - self.gamma

    def verify_sim2real_gap(self) -> bool:
        """配对差的 conformal 上分位数 ≤ Δ_max（有限样本、分布无关）"""
        if not self.sim_real_pairs:
            return False
        diffs = torch.tensor([abs(r - s) for s, r in self.sim_real_pairs])
        q = conformal_quantile(diffs, 1.0 - self.delta)
        return float(q) <= self.Delta_max

    def verify_field_readiness(self, successes: int, trials: int) -> bool:
        """现场成功率单侧下界 ≥ 1-ε（Clopper–Pearson 精确二项界）"""
        if trials <= 0:
            return False
        lower = clopper_pearson_lower(successes, trials, 1.0 - self.epsilon)
        return lower >= 1.0 - self.epsilon

    def verify_deployment_ood(self, obs: Tensor, ell: str) -> bool:
        """在线 OOD 检测：落入未校准流形即转保守降额"""
        if self.ood_detector is None:
            return False
        return not self.ood_detector.is_ood(obs, ell)

    def verify_all(self, successes: int, trials: int,
                   obs: Tensor, ell: str) -> bool:
        return (self.verify_odd_coverage() and
                self.verify_sim2real_gap() and
                self.verify_field_readiness(successes, trials) and
                self.verify_deployment_ood(obs, ell))


# ============================================================
# IP-451 VDUC — VLA 部署统一准入门
# ============================================================
@dataclass
class VLADeploymentUnifiedCertificate:
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'  # v25 七证
    igc: InstructionGroundingCertificate
    vacc: VLAActionConformanceCertificate
    slc: ScenarioLandingCertificate

    def admits(self, multi_plan: 'MultiRobotPlan',
               sensor_data: dict,
               instruction: str,
               vla_action: Tensor,
               field_stats: tuple[int, int],
               gt_entities=None, queries=None, retrieved=None) -> bool:
        # 1. v25 七证（单机 USMC + SMC + RMC + MCC）
        if not self.src_usc.admits(multi_plan, sensor_data,
                                   gt_entities, queries, retrieved):
            return False
        # 2. 语言接地
        if not self.igc.verify_all():
            return False
        phi_ell, _, _ = self.igc.ground()
        # 3. VLA 动作一致性 + 屏蔽
        if not self.vacc.verify_conformance(sensor_data['obs'], instruction, vla_action):
            return False
        a_safe = self.vacc.shield(vla_action)
        rollout = multi_plan.rollout(a_safe)
        if not self.vacc.verify_task_robustness(a_safe, phi_ell, rollout):
            return False
        # 4. 场景落地
        successes, trials = field_stats
        if not self.slc.verify_all(successes, trials,
                                   sensor_data['obs'], instruction):
            return False
        return True


# ============================================================
# 扩展：VLA 部署流水线（VLA 提案 → 证书裁决 → 屏蔽执行）
# ============================================================
class VLADeploymentPipeline:
    def __init__(self, config: dict):
        self.vduc = VLADeploymentUnifiedCertificate(
            src_usc=config['src_usc'],
            igc=InstructionGroundingCertificate(
                instruction=config.get('instruction', ''),
                compiler=config['compiler'],
                semantic_map=config['src_usc'].smc,
                referent_calibrator=config['referent_calibrator'],
                safety_invariants=config['safety_invariants'],
                alpha_g=config['alpha_g'], h_max=config['h_max']),
            vacc=VLAActionConformanceCertificate(
                policy=config['vla_policy'],
                action_calibrator=config['action_calibrator'],
                adm_set=config['adm_set'],
                stl_monitor=config['stl_monitor'],
                alpha_a=config['alpha_a'],
                delta_shield=config['delta_shield'],
                delta_jerk=config['delta_jerk']),
            slc=ScenarioLandingCertificate(
                odd=config['odd'],
                scenario_taxonomy=config['scenario_taxonomy'],
                coverage=config['coverage'],
                sim_real_pairs=config['sim_real_pairs'],
                ood_detector=config['ood_detector'],
                gamma=config['gamma'], delta=config['delta'],
                Delta_max=config['Delta_max'], epsilon=config['epsilon']))
        self.ipam.register_module("igc", ["IP-448"],
            ["instruction_grounding", "conformal_referent", "parse_entropy",
             "spec_safety_consistency"])
        self.ipam.register_module("vacc", ["IP-449"],
            ["conformal_action_set", "safety_shield_projection",
             "stl_task_robustness", "jerk_continuity"])
        self.ipam.register_module("slc", ["IP-450"],
            ["odd_coverage", "sim2real_gap_bound", "field_success_lcb",
             "deployment_ood"])
        self.ipam.register_module("vduc", ["IP-451"],
            ["thirteen_condition_gate", "vla_deployment_monotonic_chain"])

    def step(self, multi_sensor_data: dict, instruction: str,
             field_stats: tuple[int, int]) -> tuple[bool, dict]:
        # 1. VLA 黑箱提案
        a_vla = self.vduc.vacc.policy.act(multi_sensor_data['obs'], instruction)
        # 2. v25 + 语言 + 动作 + 场景联合准入
        multi_plan = self._plan_from_consensus(multi_sensor_data)
        admitted = self.vduc.admits(multi_plan, multi_sensor_data,
                                    instruction, a_vla, field_stats)
        if not admitted:
            # 3. 分级回退（见引理 16）
            return False, self._degrade(multi_sensor_data, instruction)
        # 4. 屏蔽后执行，绝不直接执行 VLA 原动作
        a_safe = self.vduc.vacc.shield(a_vla)
        return True, {'action': a_safe, 'vla_raw': a_vla,
                      'shield_delta': torch.norm(a_safe - a_vla).item(),
                      'multi_plan': multi_plan}

    def _degrade(self, sensor_data: dict, instruction: str) -> dict:
        """按失败层回退：lang→几何规划；vla→经典控制；scene→保守降额"""
        if not self.vduc.igc.verify_all():
            return {'mode': 'geometric_fallback', 'reason': 'IGC_reject'}
        if not self.vduc.slc.verify_deployment_ood(sensor_data['obs'], instruction):
            return {'mode': 'conservative_derated', 'reason': 'SLC_ood'}
        return {'mode': 'classical_control_fallback', 'reason': 'VACC_reject'}


# 辅助
def stl_sat(phi) -> bool:
    """有界时域 STL 可满足性（编码为 SMT/区间算术）"""
    return phi.is_satisfiable(bounded=True)

def conformal_quantile(x: Tensor, level: float) -> Tensor:
    n = x.numel()
    k = min(n, int(torch.ceil(torch.tensor((n + 1) * level)).item()))
    return torch.kthvalue(x, k).values

def clopper_pearson_lower(k: int, n: int, conf: float) -> float:
    from scipy.stats import beta
    if k == 0:
        return 0.0
    return float(beta.ppf(1.0 - conf, k, n - k + 1))
```

**实时性保证**：IGC 只在指令到达时触发（事件驱动，非每帧）；VACC 的 conformal 集离线预计算、屏蔽投影在 50Hz 控制环内为毫秒级凸投影；SLC 的覆盖/差距/成功率离线批算，在线仅跑 OOD 检测 O(d_emb)。关键路径增量 <8ms，满足 VLA 动作块（H=8，约 10–20Hz）与底层 50Hz 安全环的分层异步。

## 3. 正确性论证（增量）

### 引理 13（指令接地的指代-歧义-一致性三重保证）
**陈述**：`IGC.verify_all() = True` ⟺ 指令同时满足：
(1) 指代接地：∀ref∈R_ℓ，候选实体落入 conformal 集 C_ref，边际覆盖 ≥1-α_g；
(2) 歧义受控：解析后验熵 H(parse|ℓ) ≤ h_max；
(3) 规约-安全一致：SAT(φ_ℓ ∧ Inv_safe) 成立（有界时域可判定）。

**证明**：
1. 语法约束编译器只产生文法可导的有限候选集（|parses|≤64），故后验归一、熵可计算；熵阈拒绝多义指令，避免「静默选错解析」。
2. conformal 指代校准器给出候选集 C_ref，由 split-conformal 的边际覆盖定理（Vovk 2005）保证 ℙ(referent∈C_ref)≥1-α_g；未命中任一语义实体即拒证。
3. φ_ℓ 与 Inv_safe 的合取在有界时域 STL 上编码为 SMT/区间约束，可判定；不可满足说明指令要求与安全不变式冲突（如「穿过承重墙」），拒证。
4. 三者分别对应「指对对象、听清意思、不与安全打架」，缺一不可。∎

### 引理 14（VLA 动作的覆盖-屏蔽-鲁棒三重保证，及屏蔽安全性）
**陈述**：若 `VACC.verify_conformance(...)=True` 且 `verify_task_robustness(...)=True`，则屏蔽执行 a_safe 同时满足：
(1) 安全：a_safe∈A_adm，且 A_adm⊆Safe（由 USMC∧RMC∧MCC 约束构造）；
(2) 任务：ρ(φ_ℓ,τ_shield)≥0，屏蔽未破坏语言规约；
(3) 偏差受控：‖a_safe−a_VLA‖≤δ_shield，且 a_safe∈C_a（未跳出 conformal 集）。
特别地，投影到凸松弛 A_adm^cv⊇A_adm 只会多拒、不会漏放。

**证明**：
1. 屏蔽定义为 a_safe=Proj_{A_adm^cv}(a_VLA)。凸集上的欧氏投影非扩张，且 A_adm^cv⊇A_adm；`contains` 再做一次真实可行集校验，故 a_safe∈A_adm⊆Safe。
2. 任务鲁棒度由 STL 监视器在屏蔽后轨迹上计算，ρ≥0 即满足 φ_ℓ；若不满足则拒证而非执行。
3. 偏差由 δ_shield 硬约束，conformal 集成员检查阻止黑箱动作跳到未校准区域。
4. 注意：安全与任务可同时成立，但**二者都不保证「φ_ℓ 是用户真正想要的」**——该语义风险由引理 13 的接地层与 R16 承担。∎

### 引理 15（场景落地的覆盖-差距-就绪三重保证）
**陈述**：`SLC.verify_all(...) = True` ⟺ 部署同时满足：
(1) ODD 覆盖：加权场景格覆盖 cov≥1-γ；
(2) sim2real 差距：配对差 conformal 上分位数 ≤Δ_max（置信 1−δ）；
(3) 现场就绪：成功率 Clopper–Pearson 单侧下界 ≥1−ε；
(4) 在线非 OOD：当前 (o,ℓ) 未落入未校准流形。

**证明**：
1. 覆盖按场景格权重与最小样本数计算，保证每个被声明支持的格有足够统计量，避免「平均成功率高但长尾场景零样本」。
2. 配对 sim-real 差的经验分位数经 conformal 校正（秩 (n+1)(1−δ)），给出分布无关的有限样本上界；Δ_max 是任务可接受的成功率落差。
3. 二项成功率用 Clopper–Pearson 精确下界，避免正态近似的欠覆盖；trials 不足则下界低、自动拒证。
4. 在线 OOD 是「部署时」而非「离线时」的守门，弥补 1–3 只覆盖已知场景的盲区。∎

### 引理 16（十三条件单调退化链：Exec_v26 ⊆ Exec_v25 ⊆ … ⊆ Exec_v18）
**陈述**：任意单点/组合失效下，`Exec_v26 ⊆ Exec_v25` 恒成立；且各层回退计划仍落在 Exec_v25 内。

**证明**：Exec_v26 = Exec_v25 ∩ Fil_lang ∩ Fil_vla ∩ Fil_scene，交集定义直接给出子集关系。三条退化路径：
- **接地失败**（Ungroundable/Ambiguous/指代未命中/SAT 失败）→ 拒证，回退几何规划：使用 v25 的 SMC 几何目标，不含语言规约，仍在 Exec_v25。
- **动作失败**（越界/投影超 δ_shield/jerk 超限/STL 鲁棒度<0/跳出 conformal 集）→ 拒证，回退经典控制器：动作投影到 A_adm，仍在 v25 可行集。
- **场景失败**（覆盖不足/差距超界/成功率下界不足/在线 OOD）→ 拒证，保守降额：降速、扩膨胀半径、缩小包络，执行 v25 已验证的保守计划。
- 组合失效取交集；回退计划均不引入 v25 之外的新动作，故单调链与「事前拦截」保持。∎

### 定理（VDUC 十三条件完备性：安全-合规-可部署-可保护-结构-语义-重构-协同-接地-动作-场景）
**陈述**：对任意 VLA 部署计划 Π=(π_1..π_N, a, ℓ)，`VDUC.admits(Π)=True` ⟺ Π 同时满足：
(1)–(10) v25 的十组条件（物理接地/云边一致/少样本覆盖/专利保护/结构/力控/轻量化/语义/重构/协同）；
(11) 语言接地（指代/歧义/规约-安全一致）；
(12) VLA 动作一致（conformal 覆盖/屏蔽安全/STL 任务鲁棒/jerk 连续）；
(13) 场景落地（ODD 覆盖/sim2real 差距/现场成功率下界/在线非 OOD）。

**证明**：由 `VDUC.admits` 的连言结构与引理 1–3、5–7、9–11、13–15 直接可得。必要性：任一条件缺失即拒证，对应一类未被缓解的风险。充分性：十三条件全满足时，引理 4、8、12、16 保证执行集单调链与统计覆盖，构成「现场场景→语言意图→动作候选→物理执行」的完整闭环。∎

## 6. 本轮最大风险（最终确认）

**一句话**：**VLA 的指令接地只在「解析正确」前提下成立——自然语言歧义与开放世界指代错误会让 STL 规约成为「错误任务的正确形式化」，此时屏蔽层只保证「安全地执行错任务」；而场景落地的 OOD 检测又可能因 sim2real 共因漂移而失效，使 VDUC 在语义层「正确但错误」、场景层「覆盖但过时」的双重盲区中仍然通过，打破「事前拦截」的终极承诺。**
