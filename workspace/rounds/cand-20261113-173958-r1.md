# 第 68 轮（承接第 67 轮「SimRAS 仿真增强风险闭环」IP-233~242；灵感循环第 1 轮；本轮灵感：「开源硬件」×「容错控制」）

> 第 67 轮 SimRAS 把闭环从「在线反应」推进到「离线仿真预训练 + 在线世界模型推演 + 视觉问答审计」，但它有一个被默认掉的前提：**硬件是给定的、不变的、同质的**。所有关于「故障归因、风险缩放、认证前缀、世界模型」的推理，都建立在一个抽象的 `M` 上；而这个 `M` 的本体——传感器、执行器、控制器、固件——在真实世界里恰恰是最容易变、最容易换、也最容易“同源一起坏”的部分。
>
> 本轮灵感的核心命题是：
>
> **把「仿真增强的风险闭环」升级为「硬件契约驱动的可重构容错闭环」：让每一个开源硬件模块携带可验证的机器可读“故障契约”，用溯源图谱刻画冗余的独立性，用契约违背检测替代粗糙的故障阈值，用控制分配实现“换件而不只是降级”，并在每次重构后做增量重认证。**
>
> 这就是 **FABRIC**（Fault-tolerant, Attested, Build-provenance, Reconfigurable Interoperable Control）：一张由开源硬件模块、契约、溯源与证书编织成的可修复安全织物。它问的不再是「故障该去哪儿」，而是「**这块硬件承诺了什么，它兑现了吗，坏了还能换谁，换完之后证书还成立吗**」。

## 0. 直觉与动机

**灵感 1（开源硬件 → 控制器可以“读硬件的源代码”）**
直觉：闭源硬件的控制器只能看到一个黑箱的输入输出，于是故障诊断只能靠残差和统计阈值。开源硬件把 schematic、BOM、固件、标定参数、测试用例都暴露出来，这意味着控制器可以在运行时读取每个模块的**设计身份与性能包络**。换句话说，VISTA 的「先验可证伪」第一次有了硬件版本：**硬件清单本身就是一个可被运行数据证伪的先验**。当实测残差超出清单承诺的包络，我们得到的不是一个模糊的“异常”，而是一条明确的「契约违背」——这比任何黑箱阈值都更有解释力。

**灵感 2（容错控制 → 从“检测故障”升级为“兑现/证伪契约”）**
直觉：经典容错控制把系统状态二分为「正常 / 故障」，但真实硬件的退化是连续的：标定漂移、温漂、齿隙增大、采样抖动，它们既不是正常，也还没到“故障”。开源硬件给出的 `E_m`（包络）与 `F_m`（声明失效模式）恰好提供了第三种状态：**out-of-contract but not failed（失约但未失效）**。于是 FDI 不再是“阈值越界”，而是三分类：契约内（GREEN）、契约漂移（AMBER）、契约违背（RED）、清单不可信（QUARANTINE）。这把容错控制从「事后降级」推进到「事前按契约留余量、事中按违背程度分级」。

**灵感 3（开源生态 → 冗余不等于独立）**
直觉：开源硬件最大的诱惑是“便宜、可换、到处都有”，于是很容易误以为装两个同款模块就有了冗余。但同款模块共享同一个设计祖先、同一版固件、同一条供应链——它们的失效是**同源共因**的。两个同源执行器一起被同一个固件 bug 打死，并不比一个更安全。因此 FABRIC 的核心不是“数模块个数”，而是**数独立失效域**：用溯源图 `G_P` 计算模块间的同源关系，再用独立性矩阵 `K_S` 的有效秩/最小特征值定义有效冗余 `r_eff(S)`。冗余必须“来源不同、失效机制不同”才算数。

**灵感 4（可重构 → 容错不只是降级，而是换件）**
直觉：RAS/SimRAS 的容错动作主要是“缩小认证前缀、收紧力限、降低速度”——这是**退化式**容错。开源硬件的模块化与可替换性提供了另一条路：**重构式**容错。当一路执行器契约违背，控制器不必立刻降级，而可以在块边界把任务重新分配到另一路经过验证的模块上。但换件会改变被控对象动力学，切换瞬间还可能产生力矩跳变，因此需要：控制分配（RRA）、无扰切换（bumpless transfer）、驻留时间（dwell time）、以及换件后的**增量重认证**。容错的目标从“安全地变差”变成“安全地换一个继续好”。

**灵感 5（与 SimRAS 合流 → FABRIC）**
直觉：SimRAS 的世界模型可以预演“未来风险怎么演化”，但它不知道“未来硬件会变成什么配置”。FABRIC 把硬件配置 `c_t` 作为世界模型的条件变量：`WM_θ(z_t, c_t)`。这样，开源硬件提供的精确物理参数、标定与失效模式，既能缩小 Sim2Real 差距，又能在换件后只做“配置迁移”而不是从头重训。更进一步，FABRIC 把“契约违背”作为新的故障维度接入 EFS，把“有效冗余”作为认证前缀的新约束接入 C-RAS，把“重配置瞬态”作为新的干扰源接入 AIC，把“增量重认证”作为证书 `J_FABRIC` 的新语义。

**灵感 6（开源的另一面 → 攻击面也随之开源）**
直觉：清单越可信，攻击者越有动机去伪造清单；溯源越重要，攻击者越有动机去污染溯源。一个带有合法签名、但失效模式声明不完整（或故意隐瞒同源关系）的模块，会让控制器把共因故障误当成独立冗余，从而在“换件”时换进一个与故障件同源的件。FABRIC 必须把「清单完整性」和「溯源真实性」本身当作可攻击对象，纳入 AIC-FABRIC 的干扰集，并用社区交叉验证 + 行为反证来兜底。

## 1. 形式化定义（增量：定义 266–284）

- **定义 266（FABRIC 总览）**：FABRIC = (HMC, PGU, CVD, RRA, CWM, CHC, CFL, SimRAS-HW)。定位：SimRAS 的「硬件契约层 + 可重构层」。不变式：清单解析、溯源计算、增量重认证只在语义流/离线流；实时流只做契约残差包络检查、控制分配切换与认证前缀派发，零学习写操作。
- **定义 267（硬件清单契约 HMC）**：模块 m 的清单 `M_m = (id, design_id, ver, bom_hash, fw_hash, calib, E_m, F_m, r_class, v_m, σ_m)`。其中 `E_m = {c_j : |x_j - μ_j| ≤ ε_j}` 是运行包络；`F_m = {(f, P(f), sig_f)}` 是声明失效模式、先验与可检测签名；`r_class ∈ {hot, cold, solder}` 是可替换等级；`v_m` 是溯源图节点；`σ_m` 是厂商/社区维护者签名。
- **定义 268（契约残差）**：对每条契约断言 `c_j`，定义归一化残差 `r_j(t) = |x_j(t) - μ_j| / ε_j`。`in_contract(t) ⇔ max_j r_j(t) ≤ 1`；`r_HW(t) = (r_1,...,r_J)`。
- **定义 269（契约违背检测 CVD）**：在残差序列上做 CUSUM/GLR 序贯检验，假设 `H0`（契约内）、`H_drift`（失约但可恢复）、`H_fault`（硬违背或命中声明失效签名）、`H_unattested`（签名/清单不一致）。输出健康等级 `g_HW ∈ {GREEN, AMBER, RED, QUARANTINE}` 与告警时刻 `τ_d`。
- **定义 270（溯源图 PGU）**：`G_P = (V, E_P)` 是有向无环图，节点是设计/固件/厂商/批次，边表示 derived-from / shares-code / shares-supply-chain。模块 m 映射到 `v_m`。若两模块在深度 d 内共享祖先，则称**溯源相关**。
- **定义 271（失效独立性与有效冗余）**：独立性矩阵 `K_S ∈ [0,1]^{|S|×|S|}`，`K_ii=1`，`K_ij = 1 - c_ij`，`c_ij` 为 i,j 的共因相关系数（由溯源祖先、共享失效模式、共享批次估计）。有效冗余 `r_eff(S) = |S|·λ_min(K_S)`；溯源多样性 `D_p(S) = 1 - mean_{i<j} c_ij`。`r_eff` 才是可被证书消费的冗余量。
- **定义 272（配置嵌入）**：`c_t = Φ(S_t, {M_m}_{m∈S_t}) ∈ ℝ^{d_c}`，拼接活动模块集合、设计/固件哈希嵌入、标定参数、包络宽度与溯源多样性。换件即 `c_t` 跳变。
- **定义 273（配置条件世界模型 CWM）**：`WM_θ(z_t, c_t)`，三头输出 `(z_{t+1}, π_{t+1}, P(H_{t+1}))`。训练时对配置做 dropout 与一致性正则，使其对 `c` 的 Lipschitz 常数 `L_c` 可控。
- **定义 274（可重构控制分配 RRA）**：给定期望 wrench `w_d`、可用模块集 `S`、上一时刻分配 `u_prev`，求解 `min_u ||B_S u - w_d||_Q^2 + γ_s||u-u_prev||^2 + γ_p/D_p(S) + γ_c·cost(S)`，s.t. `u ∈ U_S`、契约包络、安全裕度、无扰约束。`|S|≤6`，可枚举子集求 QP。
- **定义 275（无扰切换与驻留时间）**：切换时刻 `t_s` 需满足 `|u_new(t_s) - u_old(t_s)| ≤ δ_bumpless`，且 `t - t_s ≥ T_d` 才允许下一次切换；切换期间指令限制在「旧安全集 ∩ 新安全集」。
- **定义 276（契约感知故障假设集）**：`ℋ_FABRIC = ℋ_RAS ∪ F_HW ∪ {H_unattested, H_rc_transient}`，其中 `F_HW = ∪_m F_m`，`H_rc_transient` 表示切换瞬态而非硬件失效。
- **定义 277（EFS-HW 联合后验）**：`P(H,E,f | ρ,face,r_HW,M) ∝ p(ρ|H)·p(face|E)·p(r_HW|f)·P(f|M)·P(H,E)`。清单中的 `P(f)` 作为先验，CVD 的残差作为似然，“失约但未失效”作为 `H_drift` 的软证据。
- **定义 278（C-RAS-HW 认证前缀）**：`k*FABRIC = min(k_VISTA, k_emo, k_wm, m_ras)`，且要求对 `∀s≤k`：①契约残差在包络内；②`r_eff(S_s) ≥ r_min`；③`KL(π_{t+s}^{WM,c} || π_{t+s}^{ERG}) < τ_c`；④重配置安全包络成立。
- **定义 279（增量重认证切片）**：`Dep(m)` 为溯源图中所有可能因 m 变更而改变真值的断言集合。若 `Dep` 是因果影响的可靠过近似，则只重推 `Dep(m)` 即可得到与全量重推等价的证书。
- **定义 280（配置感知健康证书 CHC / J_FABRIC）**：`J_FABRIC = (J_SimRAS, hw_config_hash, {hmc_hash_m}, provenance_proof, r_eff_min, reconfig_log, cwm_cond_hash)`。Valid ⇔ `Valid(J_SimRAS) ∧ 所有 σ_m 验签通过 ∧ r_eff(S) ≥ r_min ∧ 重配置瞬态满足定义 275`。
- **定义 281（社区故障库 CFL）**：联邦键值库 `CFL[(design_id, ver, f)] = (sig_f, counterfactual, fix, trust_w)`。`trust_w` 由溯源距离、复现次数与维护者信誉聚合；用于初始化 `P(f)` 与扩充 CVD 签名模板。
- **定义 282（AIC-FABRIC 干扰集）**：`ℰ_FABRIC = ℰ_SimRAS × ℰ_manifest × ℰ_provenance × ℰ_reconfig × ℰ_community`，其中 `ℰ_manifest` = 清单伪造/漏报/过期，`ℰ_provenance` = 隐藏同源/溯源投毒，`ℰ_reconfig` = 切换瞬态/无扰违背，`ℰ_community` = 恶意故障报告/错误修复。
- **定义 283（清单证伪证书）**：当 `r_HW` 持续越界且无法由 `H_rc_transient` 解释时，输出 `FalsifyCert = (m, 违约断言, 残差见证, 复现条件, 建议隔离)`，用于隔离模块并向 CFL 提交反例。
- **定义 284（三级运行时不变式）**：实时环（<1ms）只含包络检查、CVD 增量、RRA 查表/QP、前缀派发；语义环（<10ms）含 EFS-HW、C-RAS-HW、CWM 滚动；离线/异步环含 G_P 更新、增量重认证、CFL 同步。

```python
# HMC：清单验签与包络残差
class HardwareManifestContract:
    def __init__(self, manifest):
        self.m = manifest
        assert verify_signature(manifest, manifest.sig)

    def residual(self, x):
        return max(abs(x[j] - c['mu']) / c['eps']
                   for j, c in self.m.envelope.items())

    def in_contract(self, x, tol=1.0):
        return self.residual(x) <= tol


# CVD：契约违背检测（CUSUM + 分级）
class ContractViolationDetector:
    def __init__(self, J, k=0.5, h=5.0, drift_h=2.0):
        self.S = [0.0] * J
        self.k, self.h, self.drift_h = k, h, drift_h

    def step(self, r_vec, manifest):
        grade = 'GREEN'
        for j, r in enumerate(r_vec):
            self.S[j] = max(0.0, self.S[j] + r - self.k)
            if self.S[j] > self.h:
                grade = 'RED' if r > 2.0 else 'AMBER'
            elif self.S[j] > self.drift_h:
                grade = max(grade, 'AMBER', key=ORDER.get)
        if not verify_signature(manifest, manifest.sig):
            grade = 'QUARANTINE'
        return grade, list(self.S)


# PGU：溯源独立性 + 有效冗余
class ProvenanceGraph:
    def __init__(self, dag):
        self.dag = dag

    def common_ancestor_depth(self, a, b, max_d=3):
        return len(set(self.ancestors(a, max_d)) & set(self.ancestors(b, max_d)))

    def independence_matrix(self, S, max_d=3):
        n = len(S)
        K = [[1.0] * n for _ in range(n)]
        for i in range(n):
            for j in range(i + 1, n):
                shared = self.common_ancestor_depth(S[i].v, S[j].v, max_d)
                c = 1.0 - math.exp(-shared)
                c = max(c, self.shared_failure_mode_corr(S[i], S[j]))
                K[i][j] = K[j][i] = 1.0 - c
        return K

    def effective_redundancy(self, S):
        K = self.independence_matrix(S)
        return len(S) * min_eigenvalue(K)

    def diversity(self, S):
        K = self.independence_matrix(S)
        n = len(S)
        return 1.0 - sum(1.0 - K[i][j] for i in range(n)
                         for j in range(i + 1, n)) / max(1, n * (n - 1) / 2)


# CWM：配置条件世界模型
class ConfigConditionedWorldModel:
    def __init__(self, enc, dyn, emo, fault):
        self.enc, self.dyn, self.emo, self.fault = enc, dyn, emo, fault

    def rollout(self, obs_t, act_seq, config_c, k=5):
        z = self.enc(obs_t, config_c)
        preds = []
        for a in act_seq[:k]:
            z = self.dyn(z, a, config_c)
            preds.append({'pi': self.emo(z), 'pH': self.fault(z)})
        return preds


# RRA：可重构控制分配（枚举子集 + QP）
class ReconfigurationAllocator:
    def __init__(self, pg, gamma_s=0.1, gamma_p=0.5):
        self.pg, self.gs, self.gp = pg, gamma_s, gamma_p

    def allocate(self, w_d, S, u_prev, cfg):
        best = None
        for subset in power_set(S):
            if not subset:
                continue
            K = self.pg.independence_matrix(subset)
            r_eff = len(subset) * min_eigenvalue(K)
            if r_eff < cfg.r_min:
                continue
            u = solve_allocation_qp(w_d, subset, u_prev,
                                    gamma_s=self.gs,
                                    gamma_p=self.gp / (self.pg.diversity(subset) + 1e-6))
            if best is None or u.cost < best.cost:
                best = u
        return best


# FABRIC：在线闭环（在 SimRAS 上插入硬件契约层）
def FABRIC_round(M, obs, modules):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    M.lsf.update_geometry(P_cloud)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))

    # 1) 清单与契约：验签 + 残差 + CVD
    hw_state = {}
    for m in modules:
        res = m.hmc.residual(m.telemetry)
        hw_state[m.id] = {'grade': M.cvd.step(m.residual_vec(), m.manifest),
                          'in_contract': res <= 1.0}

    # 2) 配置嵌入 + 有效冗余
    S = [m for m in modules if hw_state[m.id]['grade'] != 'QUARANTINE']
    c_t = M.cfg_encoder.encode(S, [m.manifest for m in S])
    r_eff = M.pgu.effective_redundancy(S)

    # 3) 情绪 + SimRAS 前向
    act_seq = M.vista.ach.propose_actions(x_prime, H=M.vista.H, steps=5)
    face_gate = M.erg_wm.recognize(img, x_prime, act_seq)
    A = M.vista.ach.propose(x_prime, H=M.vista.H)
    wm_preds = M.cwm.rollout(x_prime, act_seq, c_t, k=min(5, len(A)))

    # 4) EFS-HW：契约残差作为新似然
    rho = M.vista.fir.signature(M.vista.stage.split(M.vista.residual_log))
    joint_post, _ = M.efs_hw.synthesize(rho, face_gate, hw_state, c_t)

    # 5) RRA：若存在 RED/AMBER，尝试换件而非直接降级
    if any(h['grade'] in ('RED', 'AMBER') for h in hw_state.values()):
        alloc = M.rra.allocate(M.vista.pi_sigma.desired_wrench(A), S,
                               M.last_alloc, cfg=M.cfg)
        if alloc is not None and M.rc_guard.bumpless_ok(alloc, M.last_alloc):
            M.apply_allocation(alloc)          # 块边界切换 + 驻留时间
            c_t = M.cfg_encoder.encode(alloc.S, [m.manifest for m in alloc.S])
            wm_preds = M.cwm.rollout(x_prime, act_seq, c_t, k=min(5, len(A)))

    # 6) C-RAS-HW：认证前缀 + 契约/冗余约束
    m_ras = min(M.vista.m, M.er.max_m_emotion)
    k_ras = M.csc_hw.certified_prefix_hw(A, joint_post, m_ras, M.alpha_chunk,
                                         hw_state, r_eff, wm_preds)

    # 7) ERS + 控制派发
    tau_cmd = M.vista.pi_sigma.prefix_dispatch(A[:k_ras])
    tau_cmd = M.efs_hw.risk_scale(tau_cmd, joint_post, hw_state)
    tau_cmd = M.ers_wm.shaping(tau_cmd, joint_post, wm_preds)

    # 8) 异步：增量重认证 + 可能的社区上报
    M.chc.submit_incremental(modules, hw_state, c_t)
    return k_ras, r_eff, joint_post, face_gate, hw_state
```

## 3. 推导

**引理 13（契约包络的误报—检测延迟权衡）** 设模块输出 `x = μ + n`，噪声 `n` 为 σ-次高斯。取包络阈值 `ε_j = ε_j^design + κσ`，则单条断言的误报率 `α_j ≤ 2exp(-κ²/2)`；对幅值为 Δ 的突变故障，CUSUM 的期望检测延迟 `E[τ_d] ≲ (h + 1)/(Δ/ε_j - k)`。因此清单给出的 `ε_j^design` 不是装饰，而是把“设计允许的漂移”从“故障”中扣除，直接降低误报。

**引理 14（有效冗余的共因修正）** 若把 S 按溯源失效域分解为 `S = ⊔_d S_d`，域内相关系数为 `c_d`，域间独立，则 `λ_min(K_S) = min_d (1 - c_d)`（块对角情形），故 `r_eff(S) = |S|·min_d(1 - c_d)`。当所有模块同源（`c_d → 1`）时 `r_eff → 0`：这形式化了“两个同款不等于两个冗余”。只有当 `r_eff(S) ≥ r_min` 时，C-RAS-HW 才允许把“换件”当作容错动作。

**引理 15（社区先验的抗污染界）** 设 CFL 中恶意/错误报告比例为 `ε_bad`，用 median-of-means 聚合 `N` 条报告，则失效率先验估计的偏差满足 `|P̂(f) - P(f)| ≤ O(σ√(log(1/δ)/N)) + ε_bad·B`，其中 B 为报告取值上界。故 CFL 可以加速冷启动，但必须先做鲁棒聚合，不能直接取均值。

**定理 14（重配置瞬态安全）** 若 ①切换前旧前缀已认证；②切换发生在块边界；③无扰约束 `|u_new - u_old| ≤ δ_bumpless` 成立；④驻留时间 `T_d` 大于切换瞬态收敛时间；⑤新配置满足 `r_eff(S_new) ≥ r_min` 且 CWM 配置迁移误差在安全裕度内，则闭环在切换窗口内的风险满足 `P(unsafe) ≤ α_chunk + α_HW + α_rc`，且不会出现“旧件已卸、新件未稳”的空窗。证明思路：把窗口拆为切换前/切换中/切换后三段；切换前由旧证书覆盖，切换中被旧∩新安全集约束，切换后由新配置证书覆盖；无扰与驻留条件保证三段可拼接。

**定理 15（增量重认证的可靠性）** 若 `Dep(m)` 是“m 变更后真值可能改变”的断言集合的可靠过近似，且证书是这些断言及其耦合约束的合取，则 `J_{FABRIC|Dep(m)} ∧ (未变更断言) ⇔ J_{FABRIC|full}`，在签名/哈希无碰撞的前提下成立。因此换件后只需重推依赖切片，重认证时间可从全量 `O(|J|)` 降到 `O(|Dep(m)|)`，而正确性不打折。

**定理 16（配置迁移下的世界模型误差）** 若 `WM_θ(z,c)` 对 c 满足 L_c-Lipschitz，且换件导致 `||c' - c|| ≤ δ_c`，则 `E[||π̂_{t+k}(c') - π_{t+k}||] ≤ ε_rollout(c) + L_c·δ_c`。当 `L_c·δ_c` 小于 C-RAS-HW 的安全裕度时，允许“免重训、仅重认证”地热切换；否则必须触发离线微调或降级。这把“换件后世界模型还准不准”变成一个可计算的门槛。

## 6. 本轮最大风险

**一句话**：FABRIC 的全部安全性建立在「开源硬件清单是真实、完整、可验证的」这一假设上，但在一个可自由 fork、可仿冒、可投毒的开放生态里，一个签名合法却**故意漏报失效模式或隐瞒同源祖先**的模块，会让控制器把共因故障误当成独立冗余，从而在“换件容错”时换进一个与故障件同源的件——**开放性同时放大了透明度和攻击面，而证书只能证明“被签过”，不能证明“是真的”**。

**次级风险与缓解**：
1. **清单漏报**：用运行残差做行为反证，持续越界但清单未声明 → 自动生成 `FalsifyCert` 并隔离；
2. **溯源投毒**：交叉验证多源 attestation + 社区复现，单一签名不足以提升 `trust_w`；
3. **换件瞬态**：强制块边界 + 无扰 + 驻留时间，瞬态期间指令限制在旧∩新安全集；
4. **社区毒化**：CFL 采用 median-of-means / 截尾均值，恶意报告不能直接改先验；
5. **重认证开销**：只重推 `Dep(m)` 切片，后台异步执行，未完成前禁止提升 `k*FABRIC`；
6. **开源碎片化**：清单模式版本化，缺失字段按“最保守包络”处理，而不是按“默认正常”处理。

## 2. 形式化定义（完整版）

**定义 266（FABRIC 总览）** FABRIC 是 SimRAS 的「硬件契约层 + 可重构层」：
```
FABRIC = (HMC, PGU, CVD, RRA, CWM, CHC, CFL, SimRAS-HW)
```
不变式：清单解析、溯源计算、增量重认证只在语义流/离线流；实时流只做契约残差包络检查、控制分配切换与认证前缀派发，零学习写操作。三级运行时见定义 284。

**定义 267（硬件清单契约 HMC）** 模块 m 的清单为
```
M_m = (id, design_id, ver, bom_hash, fw_hash, calib, E_m, F_m, r_class, v_m, σ_m)
```
其中 `E_m` 是运行包络 `{(x_j, μ_j, ε_j)}`；`F_m` 是声明失效模式集合，每条含先验 `P(f)` 与可检测签名 `sig_f`；`r_class ∈ {hot, cold, solder}` 是可替换等级；`v_m` 是溯源图节点；`σ_m` 是厂商或社区维护者的签名。清单必须版本化；缺失字段按最保守包络处理，而不是按“默认正常”处理。

**定义 268（契约残差）** 对每条契约断言 `c_j`：
```
r_j(t) = |x_j(t) - μ_j| / ε_j
in_contract(t) ⇔ max_j r_j(t) ≤ 1
r_HW(t) = (r_1(t), ..., r_J(t))
```
`ε_j` 由设计容差 `ε_j^design` 与噪声裕度 `κσ_j` 组成，见引理 13。

**定义 269（契约违背检测 CVD）** 在 `r_HW` 上做 CUSUM/GLR 序贯检验，假设集为 `{H0, H_drift, H_fault, H_unattested}`：
- `H0`：所有断言在包络内；
- `H_drift`：失约但可恢复（温漂、齿隙、标定漂移）；
- `H_fault`：硬违背或命中 `F_m` 中的失效签名；
- `H_unattested`：签名失效、清单版本不匹配或字段缺失。
输出 `g_HW ∈ {GREEN, AMBER, RED, QUARANTINE}` 与告警时刻 `τ_d`。`QUARANTINE` 模块不参与 RRA 分配。

**定义 270（溯源图 PGU）** `G_P = (V, E_P)` 是有向无环图，节点是设计、固件、厂商、批次，边表示 `derived-from`、`shares-code`、`shares-supply-chain`。模块 m 映射到 `v_m`。若两模块在深度 d 内共享祖先，则称溯源相关；共享祖先越多、越近，共因相关系数 `c_ij` 越大。

**定义 271（失效独立性与有效冗余）** 独立性矩阵
```
K_S ∈ [0,1]^{|S|×|S|},  K_ii = 1,  K_ij = 1 - c_ij
c_ij = max( provenance_common_cause(i,j), shared_failure_mode_corr(i,j) )
r_eff(S) = |S| · λ_min(K_S)
D_p(S) = 1 - (1 / C(|S|,2)) · Σ_{i<j} c_ij
```
`r_eff` 才是证书可消费的冗余量；`|S|` 只是名义冗余。

**定义 272（配置嵌入）**
```
c_t = Φ(S_t, {M_m}_{m∈S_t}) ∈ ℝ^{d_c}
```
拼接活动模块集合的 one-hot、设计/固件哈希嵌入、标定参数、包络宽度、`r_eff` 与 `D_p`。换件、重新标定、固件升级都会导致 `c_t` 跳变。

**定义 273（配置条件世界模型 CWM）** `WM_θ(z_t, c_t)`，编码器与三头均以 `c_t` 为条件：
```
z_{t+1} = dyn_θ(z_t, a_t, c_t)
π_{t+1} = emo_θ(z_t, c_t)
P(H_{t+1}) = fault_θ(z_t, c_t)
```
训练损失 `L = L_recon + λ_emo L_emo + λ_fault L_fault + λ_cfg L_cfg`，其中 `L_cfg` 对配置做 dropout 与一致性正则，以压低 `L_c = Lip_c(WM_θ)`。

**定义 274（可重构控制分配 RRA）** 给定期望 wrench `w_d`、可用模块集 `S`、上一分配 `u_prev`：
```
min_{u, S'⊆S}  ||B_{S'} u - w_d||_Q^2 + γ_s||u - u_prev||^2 + γ_p / D_p(S') + γ_c·cost(S')
s.t.  u ∈ U_{S'},  r_HW(u) ≤ 1,  safety_margin(u) ≥ 0,  r_eff(S') ≥ r_min
```
`|S| ≤ 6`，可枚举子集并在每个子集上解 QP。`cost(S')` 含切换时间、磨损、不可逆代价。

**定义 275（无扰切换与驻留时间）** 切换时刻 `t_s` 必须满足
```
|u_new(t_s) - u_old(t_s)| ≤ δ_bumpless
t - t_s ≥ T_d   （下一次切换前）
```
切换窗口内指令限制在「旧安全集 ∩ 新安全集」。对 `r_class = solder` 的不可逆模块，只允许在块边界调度切换。

**定义 276（契约感知故障假设集）**
```
ℋ_FABRIC = ℋ_RAS ∪ F_HW ∪ {H_unattested, H_rc_transient}
F_HW = ∪_m F_m
```
`H_rc_transient` 表示切换瞬态而非硬件失效，避免把“换件抖动”误判为“新件坏了”。

**定义 277（EFS-HW 联合后验）**
```
P(H,E,f | ρ,face,r_HW,M) ∝ p(ρ|H) · p(face|E) · p(r_HW|f) · P(f|M) · P(H,E)
```
其中 `P(f|M)` 来自清单先验并经 CFL 校正，`p(r_HW|f)` 由 CVD 的残差模型给出。`H_drift` 作为“失约但未失效”的软证据，降低 `H_fault` 后验而不直接触发降级。

**定义 278（C-RAS-HW 认证前缀）**
```
k*FABRIC = min(k_VISTA, k_emo, k_wm, m_ras)
```
且对 `∀s ≤ k*FABRIC` 需同时满足：
1. 契约包络：`max_j r_j(t+s) ≤ 1`；
2. 有效冗余：`r_eff(S_{t+s}) ≥ r_min`；
3. 配置一致性：`KL(π_{t+s}^{WM,c} || π_{t+s}^{ERG}) < τ_c`；
4. 重配置安全：定义 275 的无扰与驻留条件成立。

**定义 279（增量重认证切片）** `Dep(m)` 是溯源图中所有“m 变更后真值可能改变”的断言集合。若 `Dep(m)` 是因果影响的可靠过近似，则只重推 `Dep(m)` 即可得到与全量重推等价的证书：
```
J_FABRIC(updated m) = ReDerive(Dep(m)) ∧ (J_FABRIC \ Dep(m))
```
证明见定理 15。

**定义 280（配置感知健康证书 CHC / J_FABRIC）**
```
J_FABRIC = (J_SimRAS, hw_config_hash, {hmc_hash_m}, provenance_proof,
            r_eff_min, reconfig_log, cwm_cond_hash)
```
`Valid ⇔ Valid(J_SimRAS) ∧ 所有 σ_m 验签通过 ∧ r_eff(S) ≥ r_min ∧ 重配置瞬态满足定义 275 ∧ cwm_cond_hash 与当前 c_t 一致`。

**定义 281（社区故障库 CFL）** 联邦键值库
```
CFL[(design_id, ver, f)] = (sig_f, counterfactual, fix, trust_w)
```
`trust_w` 由溯源距离、独立复现次数、维护者信誉聚合。CFL 用于初始化 `P(f)`、扩充 CVD 签名模板、提供反事实修复建议。必须先做鲁棒聚合（median-of-means / 截尾均值），不能直接取均值。

**定义 282（AIC-FABRIC 干扰集）**
```
ℰ_FABRIC = ℰ_SimRAS × ℰ_manifest × ℰ_provenance × ℰ_reconfig × ℰ_community
```
- `ℰ_manifest`：清单伪造、失效模式漏报、版本过期、字段缺失；
- `ℰ_provenance`：隐藏同源、伪造祖先、溯源投毒；
- `ℰ_reconfig`：切换瞬态、无扰违背、驻留不足、分配振荡；
- `ℰ_community`：恶意故障报告、错误修复、信誉操纵。
另建共因注入 `ℰ_common_fabric`：同一设计祖先导致几何/传感器/执行器同时退化，用于检验 `r_eff` 是否真的下降。

**定义 283（清单证伪证书）** 当 `r_HW` 持续越界且无法由 `H_rc_transient` 解释时，输出
```
FalsifyCert = (m, 违约断言, 残差见证, 复现条件, 建议隔离)
```
用于隔离模块、冻结其 `trust_w`、向 CFL 提交反例。证伪证书是“开源硬件先验可证伪”的落地物。

**定义 284（三级运行时不变式）**
- 实时环（<1ms）：包络检查、CVD 增量、RRA 查表/QP、前缀派发；
- 语义环（<10ms）：EFS-HW、C-RAS-HW、CWM 滚动、ERG-WM；
- 离线/异步环：`G_P` 更新、增量重认证、CFL 同步、清单重新验签。
实时环不写任何学习参数；所有重构决策必须在语义环完成并经 CHC 签发。

```python
# IP-243 HMC：清单验签与包络残差
class HardwareManifestContract:
    def __init__(self, manifest):
        self.m = manifest
        if not verify_signature(manifest, manifest.sig):
            raise AttestationError(manifest.id)

    def residual(self, x):
        return max(abs(x[j] - c['mu']) / c['eps']
                   for j, c in self.m.envelope.items())

    def in_contract(self, x, tol=1.0):
        return self.residual(x) <= tol


# IP-244 CVD：契约违背检测（CUSUM + 四级健康度）
class ContractViolationDetector:
    ORDER = {'GREEN': 0, 'AMBER': 1, 'RED': 2, 'QUARANTINE': 3}

    def __init__(self, J, k=0.5, h=5.0, drift_h=2.0):
        self.S = [0.0] * J
        self.k, self.h, self.drift_h = k, h, drift_h

    def step(self, r_vec, manifest):
        grade = 'GREEN'
        for j, r in enumerate(r_vec):
            self.S[j] = max(0.0, self.S[j] + r - self.k)
            if self.S[j] > self.h:
                grade = max(grade, 'RED' if r > 2.0 else 'AMBER',
                            key=self.ORDER.get)
            elif self.S[j] > self.drift_h:
                grade = max(grade, 'AMBER', key=self.ORDER.get)
        if not manifest.verified or manifest.version_mismatch:
            grade = 'QUARANTINE'
        return grade, list(self.S)


# IP-245 PGU：溯源独立性 + 有效冗余
class ProvenanceGraph:
    def __init__(self, dag):
        self.dag = dag

    def ancestors(self, v, max_d):
        seen, frontier = set(), {v}
        for _ in range(max_d):
            frontier = {p for n in frontier for p in self.dag.predecessors(n)}
            seen |= frontier
        return seen

    def common_ancestor_depth(self, a, b, max_d=3):
        return len(self.ancestors(a, max_d) & self.ancestors(b, max_d))

    def independence_matrix(self, S, max_d=3):
        n = len(S)
        K = [[1.0] * n for _ in range(n)]
        for i in range(n):
            for j in range(i + 1, n):
                shared = self.common_ancestor_depth(S[i].v, S[j].v, max_d)
                c = 1.0 - math.exp(-shared)
                c = max(c, self.shared_failure_mode_corr(S[i], S[j]))
                K[i][j] = K[j][i] = 1.0 - c
        return K

    def effective_redundancy(self, S):
        return len(S) * min_eigenvalue(self.independence_matrix(S))

    def diversity(self, S):
        K = self.independence_matrix(S)
        n = len(S)
        pairs = max(1, n * (n - 1) / 2)
        return 1.0 - sum(1.0 - K[i][j] for i in range(n)
                         for j in range(i + 1, n)) / pairs


# IP-247 CWM：配置条件世界模型
class ConfigConditionedWorldModel:
    def __init__(self, enc, dyn, emo, fault):
        self.enc, self.dyn, self.emo, self.fault = enc, dyn, emo, fault

    def rollout(self, obs_t, act_seq, config_c, k=5):
        z = self.enc(obs_t, config_c)
        preds = []
        for a in act_seq[:k]:
            z = self.dyn(z, a, config_c)
            preds.append({'pi': self.emo(z, config_c),
                          'pH': self.fault(z, config_c)})
        return preds


# IP-246 RRA：可重构控制分配（子集枚举 + QP）
class ReconfigurationAllocator:
    def __init__(self, pg, gamma_s=0.1, gamma_p=0.5, gamma_c=0.2):
        self.pg, self.gs, self.gp, self.gc = pg, gamma_s, gamma_p, gamma_c

    def allocate(self, w_d, S, u_prev, cfg):
        best = None
        for subset in power_set(S):
            if not subset:
                continue
            r_eff = self.pg.effective_redundancy(subset)
            if r_eff < cfg.r_min:
                continue
            diversity = self.pg.diversity(subset)
            u = solve_allocation_qp(
                w_d, subset, u_prev,
                gamma_s=self.gs,
                gamma_p=self.gp / (diversity + 1e-6),
                gamma_c=self.gc * switch_cost(subset, u_prev))
            if u is not None and (best is None or u.cost < best.cost):
                best = u
        return best


# IP-248 CHC：增量重认证
class ConfigurationHealthCertificate:
    def __init__(self, full_certifier):
        self.certify_full = full_certifier

    def submit_incremental(self, modules, hw_state, config_c):
        changed = [m for m in modules
                   if hw_state[m.id]['grade'] != 'GREEN']
        dep = set()
        for m in changed:
            dep |= dependency_slice(m, modules)   # Dep(m) 的可靠过近似
        # 只重推依赖切片；其余断言沿用旧的已证部分
        delta = self.certify_full(modules, hw_state, config_c, only=dep)
        return merge_certificate(self.prev_cert, delta, dep)


# IP-250/251/252 FABRIC：在线闭环（在 SimRAS 上插入硬件契约层）
def FABRIC_round(M, obs, modules):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    M.lsf.update_geometry(P_cloud)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))

    # 1) 清单与契约：验签 + 残差 + CVD
    hw_state = {}
    for m in modules:
        r_vec = [m.hmc.residual(m.telemetry)]  # 实际为逐断言向量
        grade, cusum = M.cvd.step(r_vec, m.manifest)
        hw_state[m.id] = {'grade': grade, 'cusum': cusum,
                          'in_contract': m.hmc.in_contract(m.telemetry)}

    # 2) 配置嵌入 + 有效冗余
    S = [m for m in modules if hw_state[m.id]['grade'] != 'QUARANTINE']
    c_t = M.cfg_encoder.encode(S, [m.manifest for m in S])
    r_eff = M.pgu.effective_redundancy(S)

    # 3) 情绪 + SimRAS 前向
    act_seq = M.vista.ach.propose_actions(x_prime, H=M.vista.H, steps=5)
    face_gate = M.erg_wm.recognize(img, x_prime, act_seq)
    A = M.vista.ach.propose(x_prime, H=M.vista.H)
    wm_preds = M.cwm.rollout(x_prime, act_seq, c_t, k=min(5, len(A)))

    # 4) EFS-HW：契约残差作为新似然
    rho = M.vista.fir.signature(M.vista.stage.split(M.vista.residual_log))
    joint_post, _ = M.efs_hw.synthesize(rho, face_gate, hw_state, c_t)

    # 5) RRA：若存在 RED/AMBER，尝试换件而非直接降级
    if any(h['grade'] in ('RED', 'AMBER') for h in hw_state.values()):
        alloc = M.rra.allocate(M.vista.pi_sigma.desired_wrench(A), S,
                               M.last_alloc, cfg=M.cfg)
        if alloc is not None and M.rc_guard.bumpless_ok(alloc, M.last_alloc):
            M.rc_guard.schedule_at_chunk_boundary(alloc)   # 块边界 + 驻留
            M.apply_allocation(alloc)
            c_t = M.cfg_encoder.encode(alloc.S,
                                       [m.manifest for m in alloc.S])
            wm_preds = M.cwm.rollout(x_prime, act_seq, c_t,
                                     k=min(5, len(A)))

    # 6) C-RAS-HW：认证前缀 + 契约/冗余约束
    m_ras = min(M.vista.m, M.er.max_m_emotion)
    k_ras = M.csc_hw.certified_prefix_hw(
        A, joint_post, m_ras, M.alpha_chunk,
        hw_state, r_eff, wm_preds, c_t)

    # 7) ERS + 控制派发
    tau_cmd = M.vista.pi_sigma.prefix_dispatch(A[:k_ras])
    tau_cmd = M.efs_hw.risk_scale(tau_cmd, joint_post, hw_state)
    tau_cmd = M.ers_wm.shaping(tau_cmd, joint_post, wm_preds)

    # 8) 异步：增量重认证 + 可能的上报
    M.chc.submit_incremental(modules, hw_state, c_t)
    for m in modules:
        if hw_state[m.id]['grade'] == 'RED':
            M.cfl.report(FalsifyCert.from_residual(m, hw_state[m.id]))
    return k_ras, r_eff, joint_post, face_gate, hw_state
```

## 4. 推导

**引理 13（契约包络的误报—检测延迟权衡）** 设模块输出 `x = μ + n`，噪声 `n` 为 σ-次高斯。取 `ε_j = ε_j^design + κσ`，则单条断言误报率 `α_j ≤ 2exp(-κ²/2)`。对幅值 Δ 的突变故障，CUSUM 的期望检测延迟满足
```
E[τ_d] ≲ (h + 1) / (Δ/ε_j - k)
```
因此清单中的 `ε_j^design` 把“设计允许的漂移”从“故障”中扣除，直接降低误报；而 `κσ` 是可标定的灵敏度旋钮。

**引理 14（有效冗余的共因修正）** 若 `S = ⊔_d S_d` 按溯源失效域分解，域内相关系数为 `c_d`，域间独立，则 `K_S` 块对角，`λ_min(K_S) = min_d(1 - c_d)`，于是
```
r_eff(S) = |S| · min_d(1 - c_d)
```
当所有模块同源（`c_d → 1`）时 `r_eff → 0`；当模块来自互不相关的设计/固件/供应链（`c_d → 0`）时 `r_eff → |S|`。这形式化了“两个同款不等于两个冗余”，也为 C-RAS-HW 的 `r_eff ≥ r_min` 提供依据。

**引理 15（社区先验的抗污染界）** 设 CFL 中恶意/错误报告比例为 `ε_bad`，报告取值上界为 B。用 median-of-means 聚合 N 条报告，则失效率先验估计的偏差满足
```
|P̂(f) - P(f)| ≤ O(σ·sqrt(log(1/δ)/N)) + ε_bad·B
```
故 CFL 能加速冷启动，但必须先做鲁棒聚合；直接取均值会被少量恶意报告拉偏。

**定理 14（重配置瞬态安全）** 若 ①切换前旧前缀已认证；②切换发生在块边界；③无扰约束 `|u_new - u_old| ≤ δ_bumpless` 成立；④驻留时间 `T_d` 大于切换瞬态收敛时间；⑤新配置满足 `r_eff(S_new) ≥ r_min` 且 CWM 配置迁移误差在安全裕度内，则闭环在切换窗口内的风险满足
```
P(unsafe) ≤ α_chunk + α_HW + α_rc
```
且不存在“旧件已卸、新件未稳”的空窗。证明思路：把窗口拆为切换前、切换中、切换后三段；切换前由旧证书覆盖；切换中指令限制在旧∩新安全集；切换后由新配置证书覆盖；无扰与驻留条件保证三段可拼接。

**定理 15（增量重认证的可靠性）** 若 `Dep(m)` 是“m 变更后真值可能改变”的断言集合的可靠过近似，且证书是这些断言及其耦合约束的合取，则
```
J_{FABRIC|Dep(m)} ∧ (未变更断言) ⇔ J_{FABRIC|full}
```
在签名/哈希无碰撞的前提下成立。因此换件后只需重推依赖切片，重认证时间从 `O(|J|)` 降到 `O(|Dep(m)|)`，而正确性不打折。

**定理 16（配置迁移下的世界模型误差）** 若 `WM_θ(z,c)` 对 c 满足 `L_c`-Lipschitz，且换件导致 `||c' - c|| ≤ δ_c`，则
```
E[||π̂_{t+k}(c') - π_{t+k}||] ≤ ε_rollout(c) + L_c·δ_c
```
当 `L_c·δ_c` 小于 C-RAS-HW 的安全裕度时，允许“免重训、仅重认证”地热切换；否则必须触发离线微调或降级。这把“换件后世界模型还准不准”变成一个可计算的门槛。

## 7. 本轮最大风险

**一句话**：FABRIC 的全部安全性建立在「开源硬件清单是真实、完整、可验证的」这一假设上，但在一个可自由 fork、可仿冒、可投毒的开放生态里，一个签名合法却**故意漏报失效模式或隐瞒同源祖先**的模块，会让控制器把共因故障误当成独立冗余，从而在“换件容错”时换进一个与故障件同源的件——**开放性同时放大了透明度和攻击面，而证书只能证明“被签过”，不能证明“是真的”**。
