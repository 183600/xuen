# 第 3 轮（灵感循环第 3 轮；本轮灵感：「大语言模型」×「关节空间控制」）

> **基线**：继承第 2 轮 ToolGauge（IP-315–320；定义 416–431；引理 46–50；实验 E426–E439）。
> 本轮纪律：**完整设计**——把「外部工具探测」推进到「本体关节空间自激励计量」，并给出可证伪的规范-可辨识性框架。
> 关键词：anchor-and-self-motion metrology、gauge fixing、null-space excitation、risk-budgeted D-optimal design。

## 0. 直觉与动机

### 灵感 1（关节空间控制 → 机器人就是自己的计量台）

前两轮仍把盲区修复寄托于外部工具：ir.probe、tap.percuss、illum.sweep、stereo.baseline。它们有效，但代价高、部署重，而且忽略了一个事实——**很多盲区不是「传感器看不到」，而是「当前构型下看不清」**：末端遮挡、连杆自遮挡、工作空间边缘、关节回差与传动间隙、接触刚度随姿态变化。与其搬一台外部仪器，不如让机器人用自身的冗余自由度在**关节空间**做一次受控自运动，把传感器带到信息量最大的构型。关节空间控制提供了全部执行要素：位置/速度/力矩闭环、零空间投影、阻抗控制、接触力反馈、关节限位与力矩硬限。

### 灵感 2（冗余零空间 → 不打扰任务的“安全激励”）

当机器人有冗余自由度时，存在一族不改变任务（末端位姿、接触点）的关节运动，即零空间。零空间运动对任务是**一阶零扰动**的：它可以让关节来回“抖”以激励编码器偏置、回差、摩擦、传动刚度，而不移动手中的物体。这把“探测”从“外部工具动作”变成“本体自运动”，副作用理论上可压到二阶。注意这只是**一阶**结论：二阶泄漏、接触模型误差与轨迹跟踪误差仍会把激励漏进任务空间，必须定量约束。

### 灵感 3（大语言模型 → 从语义上下文到可编译的激励程序）

该激励哪个关节、选哪种锚定方式、在什么任务间隙执行，依赖大量语义上下文（维护日志、异常描述、任务日程、夹具可用性、历史残差指纹）。LLM 擅长把这类上下文转成“假设 + 激励模板”，但不擅长保证物理安全。正确的分工是：**LLM 只提出候选假设与模板，编译成受限 DSL，由契约、可辨识性门与安全滤波器裁决**。LLM 是提案器，不是执行器；它的错误只能浪费预算，不能穿越安全边界。

### 本轮的核心转折：Gauge 不再是隐喻

前两轮的 “Gauge” 主要还是工程隐喻。本轮把它变成可计算量：关节零位偏置中存在**规范自由度**（gauge freedom）。仅靠本体感受与一个未知位置的点锚点，基座关节零位不可辨识——它等价于未知的基座朝向。必须用锚点/外部参考**固定规范**（gauge fixing）。这给出一个硬结论：**没有外部参考，就不可能标定绝对运动学；只能标定相对量**。LLM 的语义先验再强，也不能创造信息。这也是对第 2 轮“VLA 是增强项”的进一步收紧：**语义是提案的先验，不是可辨识性的来源**。

## 1. 形式化定义

### 定义 432（参数空间盲区）

设校准参数 θ ∈ ℝ^d，观测模型 y = h(q, θ) + ε。对方向 u ∈ ℝ^d，若后验方差 uᵀΣu > τ_Σ 且 Fisher 信息 uᵀF u < τ_F，则称 u 为一个**参数空间盲区**。图像空间盲区 s 经校准雅可比 ∂θ/∂s 提升为参数空间方向；D-Box 的 4CV 扫描仍是入口，本轮的修复对象从“像素区域”变成“参数方向”。

### 定义 433（关节空间激励程序 J-DSL）

激励程序 ξ = (a₁, …, a_L) 是受限文法上的类型化序列。原语 `a = (type, joints, amp, freq/duration, anchor_mode, Schema, Pre, Post, cost, risk, Ĝ)`，类型包括：

- `null_dither`：沿保守零空间注入小幅周期激励；
- `slow_sweep`：在关节限位内慢扫，激励摩擦/回差的方向依赖；
- `gravity_load`：利用重力方向改变关节负载，辨识传动刚度；
- `anchor_push`：在已知夹具/接触点上施加受控法向力；
- `contact_tap`：短时接触敲击，激励接触刚度与手眼外参；
- `loop_closure`：在锚点约束下取多个自运动构型，形成闭环约束。

编译器的四查继承 TCV：schema、前置、预算、循环；另加 **J-Safe 查**：关节位置/速度/力矩/接触力/自碰撞/平衡裕度。

### 定义 434（接触感知容许运动集与保守零空间）

任务约束 J_task(q) δq = 0，接触约束 J_c(q) δq = 0（由力/触觉估计）。**保守零空间**：

N(q) = null([J_task(q); Ĵ_c(q); J_balance(q)])，

其中 Ĵ_c 用接触不确定集 𝒞 的上界雅可比，J_balance 是支撑多边形/零力矩点约束。若 N(q) = {0}（非冗余、双手约束、接触锁死），则不存在一阶零扰动方向，必须离开零空间或降级。

### 定义 435（锚点、规范群与规范轨道）

锚点集 A = {a₁, …, a_k}，每个锚点给出额外观测（点夹具、面接触、抓取物、外部视觉、基座朝向）。**规范群**

G = {g : h(q, g·θ) = h(q, θ) 对所有自由空间构型 q 成立}。

对关节零位偏置，若基座朝向未被观测，则基座关节零位偏移属于 G（等价于基座朝向的规范自由度）；平面 3R 的 dim G = 1，空间串联臂通常为 1–3。**规范轨道**为 θ + Lie(G)。规范自由度上的 CRLB 为无穷大——这不是算法不够好，而是信息不存在。

### 定义 436（可辨识性与规范固定证书）

锚点集 A 的 Fisher 信息 F_A。**规范固定证书**是可审计元组

Cert_gauge = (A, F_A, rank(F_A), cond(F_A), CRLB_diag, gauge_basis)，

要求 rank(F_A) = d 且 cond(F_A) ≤ κ_max；否则只更新可辨识子空间（伪逆 + 规范投影），绝不沿 ker(F_A) 漂移。

### 定义 437（校准参数三分）

- θ_prop：编码器偏置、回差、摩擦、力矩常数——由“指令 vs 实测”的本体感受可观测，零空间激励即可；
- θ_kin：连杆长度、关节零位、工具外参——必须有外部锚点或任务空间观测，**零空间本身不产生绝对信息**；
- θ_env：接触位姿、接触刚度——需要力/触觉观测。

三分决定了激励原语与锚点模式的最小组合；LLM 的假设必须落在某一类上，不能含糊地说“关节有问题”。

### 定义 438（风险预算 D-最优激励设计）

信息矩阵 F(ξ; θ) = Σ_t Φ_tᵀ Σ⁻¹ Φ_t，Φ_t = ∂h/∂θ。设计问题：

max_ξ  log det(F_prior + F(ξ; θ))
s.t.   R(ξ) ≤ ρ,  E(ξ) ≤ B,  ξ ∈ Ξ_safe,

其中 R(ξ) 是接触力、任务偏差、力矩裕度、平衡裕度的加权最大值。连续幅度松弛下 F 对设计权重仿射、log det 在 PSD 锥上凹，故是凸问题；离散原语用 Frank–Wolfe + Carathéodory 稀疏化，或在与子模性经检验成立时用贪心 (1−1/e)。

### 定义 439（LLM 激励合成器与 SNC-J）

LLM 在受限文法上解码，输出 (假设 h, 激励模板 ξ, 锚点模式, 目标参数类)。**SNC-J（语义-数值一致性）**要求假设必须被残差指纹支持（例如“关节 4 回差”必须伴随 q̇ 换向处的滞后签名；“摩擦”必须伴随力矩-速度曲线的库仑项）。无指纹支持的假设被剔除；全被剔除则退回预注册原语库 Ξ₀。

### 定义 440（部署信任域与影子验证）

校准更新 Δθ 是**全局**的：它改变整条运动学链，而不是 ToolGauge 的局部子图。定义信任域步长 α ∈ (0,1]，在运行包络 Q_op 上要求

||Δx(q)|| ≤ ||J_kin(q)|| · α||Δθ|| ≤ ε_deploy  ∀q ∈ Q_op。

热替换前还必须通过**影子验证**：旧/新校准并行跑一条验证轨迹，比较末端位姿、接触力与力矩；超界则回滚。

### 定义 441（J-Quarantine 全局校准隔离）

最近 K 次更新的（预测残差, 实测残差）连续 q 次同向偏置，或跨锚点残差相关性超过阈值，则冻结校准更新，回退到 ToolGauge 的局部修复路径。它对应 ToolGauge 的 P-Quarantine，但监控对象从“先验偏差”变成“全局规范漂移”。

> 定义 442–449（JB 预算契约、主张-激励绑定、PROBING-J、规范等变热替换、锚点可信度、退化谓词、因子图后验、信息-风险 Pareto 证书）在产物区展开；本区的算法骨架与复杂度表按下述编号引用。

## 2. 关键算法骨架

```python
# JointGauge：锚定自运动计量（6C+ 扩展）
def jointgauge_6c(M, s):
    # H: LLM 语义假设 + SNC-J 指纹过滤
    H = M.llm.hypothesize(s, M.context, grammar=J_DSL)
    H = [h for h in H if snc_j(h, M.fingerprints)] or [UNKNOWN]
    if H == [UNKNOWN]:
        return M.toolgauge_6c(s)          # 退化：外部工具路径

    # A: 选锚点，算规范秩与可辨识子空间
    anchor = M.abox.select(H, M.available_anchors)
    cert_g = M.abox.gauge_certificate(anchor, H.theta_class)
    if cert_g.rank < cert_g.d:
        active = M.abox.identifiable_subspace(cert_g)   # 只更新该子空间
    else:
        active = None

    # C: 风险预算 D-最优激励设计 + J-Safe 编译
    xi = M.obox.design(H, anchor, budget=M.budget_left(s),
                       risk_budget=M.rho, prior=M.F_prior)
    if not M.nbox.check(xi, M.env.snapshot()):
        xi = M.obox.library_fallback(H, anchor)       # 预注册原语库
    if not xi:
        return M.toolgauge_6c(s)                      # 无可行零空间激励

    # E: 关节空间执行（阻抗 + 锚点力反馈 + 看门狗）
    receipts = M.nbox.execute(xi, M.env)              # PROBING-J 显式态
    if len(receipts) < n_min(s):
        return stub_and_red(s, "insufficient")

    # C: 因子图校准 + 规范投影
    dtheta, F_A, Sigma = M.fbox.calibrate(receipts, anchor, active)
    if not M.fbox.crlb_ok(F_A, active):
        return stub_and_red(s, "unidentifiable")

    # V: 影子验证 + 部署信任域
    alpha = M.pbox.trust_region(dtheta, M.envelope, eps_deploy)
    if not M.pbox.shadow_validate(dtheta * alpha, M.validation_set):
        return stub_and_red(s, "shadow_failed")
    if not M.pbox.contract_regression(dtheta * alpha):
        return stub_and_red(s, "regression")

    # U: 规范等变热替换 + 证书绑定 + 隔离监控
    M.pbox.gauge_equivariant_update(dtheta * alpha, active)
    bind_claims(M.pbox.current_cert, H, xi, receipts)
    M.jquar.record(M.fbox.last_pred, M.fbox.realized)
    return True
```

## 4. 推导

**引理 51（零空间二阶不变性与泄漏界）** 若 δq = N(q) z 且 J_task δq = 0、J_c δq = 0，则任务位姿与接触点的一阶变化为零，二阶变化满足

||Δx|| ≤ ½ M_x ||δq||² + ε_model ||δq||，

其中 M_x 是 FK/接触映射的 Hessian 上界，ε_model 是接触/运动学模型误差。**证明**：Taylor 展开，一阶项为零；模型误差项来自 Ĵ_c 与真实 J_c 的差。注意第二项是线性的——它会在小步长下主导，这正是“零风险”不能无条件成立的原因。

**引理 52（规范自由度与可辨识性下界）** 若 dim G = r，则对任意激励 ξ，rank(F(ξ; θ)) ≤ d − r，且 ker(F) 包含 Lie(G) 的非零方向；沿该方向的 CRLB 为 +∞。**证明**：G 的定义给出 h(q, θ+δ) = h(q, θ) 对 δ ∈ Lie(G)，故 ∂h/∂θ · δ = 0，Fisher 信息为零。推论：点锚点只能固定平移/位置相关的规范分量；要固定基座朝向，必须增加朝向参考或已知位置的锚点。

**引理 53（CRLB 与 D-最优性）** 对无偏估计，E[(θ̂−θ)(θ̂−θ)ᵀ] ≽ F⁻¹，故 E||θ̂−θ||² ≥ tr(F⁻¹)，且 D-最优（min det F⁻¹ = max log det F）在椭球置信域意义下最小化最坏方向方差。对单方向、线性化观测，最大化 uᵀF u / (zᵀRz) 的最优 z 是广义特征对 (BᵀNᵀΣ⁻¹NB, R) 的主特征向量。**证明**：Lagrange 乘子 + Rayleigh 商。

**引理 54（慢-小定律）** 固定自运动范围 Δq（从而固定 Jacobian 沿路径的变化量，也就是弱方向信息的来源），把步长 a 细化、样本数 N=Δq/a 增大。每步二阶泄漏为 ½κa²；若每步用锚点力反馈重新投影，峰值修正力 ~ c₁κa² + c₂ε_model a。Fisher 信息是 N 个样本之和，固定 Δq 时弱方向信息随 N 单调增（独立噪声下近似线性），因此“单位信息所需泄漏力”随 a 变小而改善，直到时间/漂移/编码器分辨率下界；该下界由模型误差 ε_model 与低频漂移决定，而不是由信息量决定。**证明**：二阶漂移 ½κa²；固定 Δq 时 N=Δq/a，弱方向信息来自 J(q_i) 的离散变化，随 N 增；按峰值泄漏/信息计得 C₁a² + C₂aε_model，按累计泄漏/路径长度计得 C₁a + C₂ε_model，两者都随 a 改善。**可证伪预测**：单步泄漏-步长 log-log 斜率 = 2；固定 Δq 下弱方向最小特征值随 N 增；a→0 时单位信息泄漏趋于模型误差下界。

**引理 55（风险预算设计的凸性与稀疏化）** 连续松弛下 F(w) = F_prior + Σ w_i A_i 对 w 仿射，log det 在 PSD 锥上凹，可行集 {w ≥ 0, Σw_i ≤ B, R(w) ≤ ρ} 为凸（R 为凸风险模型），故全局最优可由凸优化得到；Carathéodory 给出至多 d(d+1)/2 个支撑点的最优设计；离散化用 Frank–Wolfe/pipage 舍入，误差可控。若风险约束非凸（如离散接触模式），则退回枚举 + 贪心，并明确失去全局最优保证。

**引理 56（LLM 提案安全分离）** 设接受集 P = {ξ : Schema ∧ Pre ∧ Post ∧ J-Safe ∧ R(ξ) ≤ ρ}。对任意 LLM 输出 ξ，若 ξ ∈ P，则执行它不会违反关节/速度/力矩/接触/平衡约束；LLM 只能影响“选哪个安全程序”和预算效率，不能影响安全性。**证明**：安全性是 P 的定义，与生成器无关。覆盖率由预注册库 Ξ₀ 保证：LLM 完全失效时仍覆盖每个参数类的最小激励。

**引理 57（部署信任域界）** 对运行包络 Q_op 上的任意 q，

||Δx(q)|| ≤ J_max · α||Δθ|| + O(||Δθ||²)，

其中 J_max = sup_{q∈Q_op} ||J_kin(q)||。取 α ≤ ε_deploy / (J_max ||Δθ||) 即可保证一阶任务偏差 ≤ ε_deploy。**证明**：一阶 Taylor + 范数不等式。这是对“全局耦合风险”的定量约束：它把热替换从“信任估计器”变成“信任证书 + 信任域”。

**引理 58（信息守恒 / 安全-可辨识性权衡）** 对零空间激励 δq ∈ N(q)，若参数方向 u 只通过任务映射影响观测，则 J_task N = 0 ⇒ 该方向的任务空间 Fisher 信息为零。更一般地，F_N = BᵀP_NᵀΣ⁻¹P_NB，rank(F_N) ≤ rank(P_NB)；ker(P_NB) 中的方向不可辨识。**证明**：投影算子的秩不等式。**推论**：零空间越“安全”（N 越小），可获得的运动学信息越少；要辨识 θ_kin 的某个方向，必须允许该方向出现在观测雅可比的像空间里，并通过锚点把绝对参考引进来。这是本轮的“没有免费午餐”定理。

**引理 59（时序与退化链）** JointGauge 的异步部分不进入 50 Hz 路径；零空间投影与 J-Safe 检查可在增量更新下保持 < 0.2 ms；任一前置失败（无锚点、零空间为空、LLM/库均无可行程序、CRLB 不合格、影子验证失败）⇒ 严格退化到 ToolGauge ⇒ LeanGauge ⇒ MODGAUGE，五不变式与 4CV 骨架不变。**证明**：与 ToolGauge 引理 50 同构；新增的退化边逐条对应失败谓词的否定。

## 6. 与 ToolGauge 的关系

JointGauge 不是替换 ToolGauge，而是给它增加一个**本体激励工具类** T_joint。外部工具仍然处理“本体够不到/锚点不可用/接触锁死”的盲区；关节空间激励处理“构型相关、可在零空间内安全激励”的盲区。退化链：

```text
JointGauge（本体零空间 + 锚点）
  ⇐ 无可用锚点 / 零空间为空 / CRLB 不合格 ⇒ ToolGauge（外部工具）
  ⇐ VLA/LLM 不可用 / H_s={UNKNOWN} ⇒ LeanGauge（纯数值）
  ⇐ LeanGauge 失效 ⇒ MODGAUGE（原样）
```

关键不变量：**LLM 不在数值路径上；规范自由度不被强行“标定”；任何全局更新必须过信任域与影子验证。**

## 7. 本轮最大风险

**一句话**：零空间证书只保证“激励过程”的一阶安全，而关节空间校准更新是**全局**的——一次错误的规范固定或信任域越界会同时污染整条运动学链，且接触模型误差会在小步长下以线性项泄漏进任务空间，使“本体自激励零风险”的前提失效；以锚点交叉验证、影子控制器、信任域证书与 J-Quarantine 四重兜底，并把无锚点情形强制降级到 ToolGauge 外部工具。

## 2. 形式化定义（要点）

**定义 432（参数空间盲区）** 对 u ∈ ℝ^d，若 `uᵀΣu > τ_Σ` 且 `uᵀFu < τ_F`，称 u 为参数空间盲区。图像盲区 s 经 `∂θ/∂s` 提升为参数方向；D-Box 仍是入口，修复对象从像素区域变成参数方向。

**定义 433（J-DSL）** 文法：

```text
program   ::= step+
step      ::= primitive '(' args ')'
primitive ::= null_dither | slow_sweep | gravity_load
            | anchor_push | contact_tap | loop_closure
```

每个原语携带契约 `(Schema, Pre, Post, c, τ, Ĝ, r)`；编译器做 schema/前置/预算/循环四查，再加 J-Safe 五查（关节位置、速度、力矩、接触力、平衡裕度）。J-Safe 是硬约束，任何一项不满足 ⇒ 拒绝编译，而不是运行时试探。

**定义 434（保守零空间）** `N(q)=null([J_task; Ĵ_c; J_bal])`。`Ĵ_c` 由接触不确定集 𝒞 导出：法向在锥角 δ 内、摩擦系数在 [μ_min, μ_max]、接触点在工作空间盒内；取最坏方向。`N(q)={0}` ⇒ 本体激励不可行，直接降级。

**定义 435（锚点与规范群）** 五类锚点：`A_pt`（已知点位置，噪声 σ_p）、`A_surf`（已知平面）、`A_obj`（已知/带 nuisance 的抓取物）、`A_vis`（外部视觉位姿）、`A_base`（基座朝向/IMU/磁力计）。规范群

`G = {g : h(q, g·θ) = h(q, θ) 对所有自由空间 q 成立}`。

对关节零位，点锚点固定平移但不固定基座朝向；平面 3R 的 `dim G=1`（基座关节零位），空间串联臂通常 1–3。规范方向上的 CRLB 为 +∞。

**定义 436（规范固定证书）** `Cert_gauge=(A, F_A, rank(F_A), cond(F_A), CRLB_diag, gauge_basis)`。要求 `rank(F_A)=d` 且 `cond(F_A)≤κ_max`；否则只更新可辨识子空间，并在证书中显式标注“绝对运动学不可辨识”。

**定义 437（参数三分与可观测前提）**

| 类 | 例子 | 观测通道 | 锚点 | 风险 | 可观测前提 |
|---|---|---|---|---|---|
| θ_prop | 编码器偏置、回差、摩擦、力矩常数 | 指令 vs 实测 q、τ | 无（需独立指令参考） | 零空间，~0 | 激励频段高于编码器环带宽，或开环/双环测试；否则偏置被控制器吸收 |
| θ_kin | 连杆长度、关节零位、工具外参 | 任务位姿/接触点 | 必须 | 零空间 + 锚点，二阶 | 锚点位置或朝向已知，或作为 nuisance 被多构型消去 |
| θ_env | 接触位姿、接触刚度 | 力/触觉 | 接触 | 接触相关 | 接触模式可辨识；软/硬接触需分开建模 |

**定义 438（风险预算 D-最优设计）**

```text
max_ξ  log det(F_prior + Σ_t Φ_tᵀ Σ⁻¹ Φ_t)
s.t.   R(ξ) = max_t [ w_f||f(t)||/f_max + w_x||Δx(t)||/x_max
                    + w_τ max_i|τ_i(t)|/τ_max + w_b(1−margin_bal(t)) ] ≤ ρ
       E(ξ) ≤ B_joint,  ξ ∈ Ξ_safe
```

连续幅度松弛下 `F(w)=F_prior+Σ w_i A_i` 对 w 仿射，`log det` 在 PSD 锥上凹，R 取凸风险模型（零空间项二次、模型误差项线性，均凸），可行集凸 ⇒ 凸问题。离散原语用 Frank–Wolfe + Carathéodory 稀疏化（至多 `d(d+1)/2` 个支撑点）；若接触模式离散且非凸，则枚举模式 + 模式内凸优化，并明确失去全局最优保证。

**定义 439（LLM 合成器与 SNC-J）** 输入是结构化记录：任务图、维护日志（结构化字段）、残差指纹、可用锚点、安全包络、当前校准。输出是类型化假设 `h=(θ_class, suspect_joint/link, anchor_mode, template)` + J-DSL 程序。语法由 grammar-constrained decoding 保证；SNC-J 要求 h 被至少一个残差指纹支持：回差 ⇒ q̇ 换向滞后；摩擦 ⇒ τ–q̇ 库仑项；运动学偏置 ⇒ 区域一致的末端偏置；接触 ⇒ 力-位移滞回。无指纹支持 ⇒ 剔除；全剔除 ⇒ 用 Ξ₀。

**定义 440（部署信任域与影子验证）** 对运行包络 Q_op：

`||Δx(q)|| ≤ ||J_kin(q)||·α||Δθ|| ≤ ε_deploy`。

取 `α ≤ ε_deploy/(J_max||Δθ||)`，其中 `J_max = sup_{q∈Q_op}||J_kin(q)||`。热替换前，旧/新校准并行跑 Q_val，比较末端位姿、接触力、力矩；任一超界 ⇒ 回滚。影子验证不通过 ⇒ 不热替换，不是“再调参试试”。

**定义 441（J-Quarantine）** 最近 K 次更新的（预测残差, 实测残差）连续 q 次同向偏置，或跨锚点残差相关矩阵的最大特征值 > ρ_q ⇒ 冻结更新、回退到 ToolGauge 的 BP-Cal/局部修复。它捕获的是“所有局部残差都好看，但全局规范在漂移”的故障。

**定义 442（关节激励预算契约 JB）** `JB=(B_joint, L_max, τ_dither, recovery)`：能量/时间/力矩/接触力预算；超预算 ⇒ 中止 + 记录 + 降级。激励必须在 PROBING-J（定义 444）中执行，不把激励藏在普通任务控制里。

**定义 443（主张-激励绑定）** 语言主张必须引用有效回执/锚点/证书；无引用的主张在序列化时剥离。剥离是纯投影，不改变数值行为（继承 IP-323/引理 49）。

**定义 444（PROBING-J）** 进入激励状态后：任务控制器切到零空间/暂停，速度上限降低，力矩硬限生效，接触力看门狗 armed，任何超限在 1 个控制周期内退出。

**定义 445（规范等变热替换）** `θ ← θ + α P_gauge Δθ`，`P_gauge=F_A⁺F_A`。规范分量恒为零；基座朝向/全局参考不被“标定”改写。

**定义 446（锚点可信度与对抗锚点）** 每个锚点有 trust level；锚点之间做一致性交叉检查（点-面-视觉）。若某锚点与其余锚点系统性冲突，隔离该锚点，不用它做规范固定。防止“移动过的夹具”把规范固定到错误位置。

**定义 447（退化谓词）** `no_anchor ∨ empty_nullspace ∨ no_feasible_program ∨ crlb_fail ∨ shadow_fail ∨ contact_leak ∨ budget_exhausted` ⇒ 按序降级；每个谓词都有独立的检测器与日志字段。

**定义 448（因子图后验）** 因子：本体感受（指令-实测）、锚点（点/面/视觉/朝向）、先验（MP-Φ/历史校准）。MAP 用 Gauss–Newton/Levenberg–Marquardt；Hessian 即 F_A；可观子空间用伪逆，规范方向不更新。后验协方差在可辨识子空间上为 `(P_gauge F_A P_gauge)⁺`。

**定义 449（信息-风险 Pareto 证书）** `Cert_info=(F_A, CRLB, R(ξ), E(ξ), A, gauge_basis, leakage_bound)`。它把“安全”拆成可审计的三项：激励过程风险、部署任务误差、规范/可辨识性。没有这三项，不允许声称“零风险自校准”。

## 3. 关键算法骨架

# IP-321/439：LLM 只在文法内提案；SNC-J 只认指纹
def jbox_hypothesize(ctx, fp_lib, grammar):
    raw = llm.decode(ctx, grammar=grammar, temperature=0.2, max_tokens=512)
    H = parse_typed(raw)                         # 语法/类型已由 grammar 保证
    H = [h for h in H if schema_ok(h) and snc_j(h, fp_lib)]
    return H or [UNKNOWN]

# IP-322/435/436：锚点选择 + 规范证书
def abox_fix_gauge(H, anchors, theta_class):
    candidates = [A for A in anchors if compatible(A, theta_class)]
    best = None
    for A in candidates:
        F_A, gauge_basis = fisher_and_gauge(A, theta_class)
        rank = numerical_rank(F_A)
        cond = cond_number(F_A) if rank == d else float('inf')
        score = (rank == d, -cond, anchor_cost(A))
        if best is None or score > best.score:
            best = (A, F_A, gauge_basis, rank, cond, score)
    A, F_A, gb, rank, cond, _ = best
    active = None if rank == d and cond <= KAPPA_MAX else row_space(F_A)
    return Cert_gauge(A, F_A, rank, cond, crlb_diag(F_A), gb), active

# IP-325/438：风险预算 D-最优（连续松弛 + FW 稀疏化）
def obox_design(H, cert, budget, rho, prior):
    prims = instantiate(H, cert.A)               # J-DSL 候选原语
    prims = [p for p in prims if jsafe(p) and p.risk <= rho]
    if not prims: return None
    w = frank_wolfe(
        f=lambda w: logdet(prior + sum(w[i]*prims[i].info for i in range(len(prims)))),
        grad=lambda w: grad_logdet(...),
        constraints=[sum(w) <= budget, w >= 0,
                     risk_model(w, prims) <= rho],
        max_iter=200)
    xi = sparsify(w, prims)                      # Carathéodory / pipage
    return xi if jsafe(xi) else None

# IP-323/434/444：保守零空间 + J-Safe + 执行
class NBox:
    def conservative_nullspace(self, q, env):
        Jt = task_jac(q); Jc = conservative_contact_jac(q, env.contact_uncertainty)
        Jb = balance_jac(q, env.support_polygon)
        return null_space(np.vstack([Jt, Jc, Jb]))

    def check(self, xi, snap):
        return (joint_limits(xi, snap) and velocity_limits(xi, snap)
                and torque_limits(xi, snap) and contact_force_limits(xi, snap)
                and balance_margin(xi, snap) >= B_MIN
                and not self_collision(xi, snap))

    def execute(self, xi, env):
        enter_state("PROBING-J")
        receipts = []
        try:
            for a in xi:
                if not self.check(a, env.snapshot()): break
                cmd = project_to_nullspace(a, env.snapshot())
                r = env.joint_impedance(cmd, force_feedback=env.anchor_force)
                if not watchdog_ok(r): break
                receipts.append(make_receipt(a, r))
        finally:
            leave_state("PROBING-J")
        return receipts

# IP-324/448：因子图校准 + 规范投影
def fbox_calibrate(receipts, cert, active):
    theta, F = factor_graph_map(receipts, cert.A, prior=MP_PHI)
    if active is not None:
        theta = project_rows(theta, active)      # 只更新可辨识子空间
        F = project_psd(F, active)
    return theta, F, inv_on_subspace(F, active)

# IP-326/440/445：部署门
def pbox_deploy(dtheta, cert, env, envelope, eps_deploy):
    P_gauge = pseudo_inverse(cert.F_A) @ cert.F_A
    dtheta = P_gauge @ dtheta
    Jmax = worst_case_jac_norm(envelope)
    alpha = min(1.0, eps_deploy / max(Jmax * norm(dtheta), 1e-12))
    if not shadow_validate(dtheta * alpha, env.validation_set, eps_deploy):
        return "shadow_failed"
    if not contract_regression(dtheta * alpha):
        return "regression"
    gauge_equivariant_update(dtheta * alpha, P_gauge)
    return "ok"

# IP-328/329：6C+ 主闭环
def jointgauge_6c(M, s):

## 4. 推导（引理 51–59）

**引理 51（零空间二阶不变性与泄漏界）** 若 `δq=N(q)z` 且 `J_task δq=0`、`J_c δq=0`，则任务位姿与接触点一阶变化为零，且

`||Δx|| ≤ ½M_x||δq||² + ε_model||δq||`。

**证明**：Taylor 展开，一阶项 `J_task N z=0`；二阶项由 FK/接触映射 Hessian 界定；`ε_model` 来自 `Ĵ_c` 与真实 `J_c`、运动学标称模型与真值的差。第二项是线性的：它在小步长下主导，是“零风险”不能无条件成立的根本原因。

**引理 52（规范自由度与可辨识性下界）** 若 `dim G=r`，则任意 ξ 的 `rank(F(ξ;θ)) ≤ d−r`，且 `ker(F)` 包含 `Lie(G)` 的非零方向；沿该方向 CRLB=+∞。**证明**：`g∈G` ⇒ `h(q,gθ)=h(q,θ)` ⇒ `∂h/∂θ·δ=0`（δ∈Lie(G)）⇒ Fisher 信息为零；秩-零化度给出上界。**推论**：点锚点固定平移但不固定基座朝向；`A_base` 或已知位置的 `A_pt` 才能固定基座关节零位。pilot 中相对锚点的零特征向量正是 `[1,0,0]`（基座关节偏置）。

**引理 53（CRLB 与 D-最优性）** 无偏估计满足 `E[(θ̂−θ)(θ̂−θ)ᵀ] ≽ F⁻¹`，故 `E||θ̂−θ||² ≥ tr(F⁻¹)`；D-最优等价于 `max log det F`。对单方向线性化观测，最大化 `uᵀFu/(zᵀRz)` 的最优 z 是 `(BᵀNᵀΣ⁻¹NB, R)` 的主广义特征向量。**证明**：Lagrange 乘子 + Rayleigh 商；`F=Σ Φ_tᵀΣ⁻¹Φ_t`。

**引理 54（慢-小定律）** 固定自运动范围 Δq（从而固定 Jacobian 沿路径的变化量，也就是弱方向信息的来源），把步长 a 细化、样本数 N=Δq/a 增大。每步二阶泄漏为 `½κa²`；若每步用锚点力反馈重新投影，峰值修正力 ~ `c₁κa² + c₂ε_model a`。Fisher 信息是 N 个样本之和，固定 Δq 时弱方向信息随 N 单调增（独立噪声下近似线性），因此“单位信息所需泄漏力”随 a 变小而改善，直到时间/漂移/编码器分辨率下界；该下界由模型误差 `ε_model` 与低频漂移决定，而不是由信息量决定。故按峰值泄漏/信息计为

`单位信息泄漏 ~ C₁a² + C₂aε_model`，

按累计泄漏/路径长度计为 `C₁a + C₂ε_model`；两者都随 a 改善，并趋于模型误差下界。**证明**：二阶漂移 `½κa²`；固定 Δq 时 N=Δq/a，弱方向信息来自 J(q_i) 的离散变化，随 N 增。**可证伪预测**：单步泄漏-步长 log-log 斜率 = 2；固定 Δq 下弱方向最小特征值随 N 增；a→0 时单位信息泄漏趋于模型误差下界而非 0。

**引理 55（风险预算设计的凸性与稀疏化）** 连续松弛下 `F(w)=F_prior+Σw_iA_i` 仿射，`log det` 在 PSD 锥上凹，`R(w)≤ρ` 为凸（零空间项二次、模型误差项线性），可行集凸 ⇒ 全局最优可由凸优化得到。Carathéodory 给出至多 `d(d+1)/2` 个支撑点的最优设计；Frank–Wolfe/pipage 舍入误差可控。若接触模式离散且非凸，枚举模式 + 模式内凸优化，并显式记录“无全局最优保证”。

**引理 56（LLM 提案安全分离）** 设接受集 `P={ξ : Schema ∧ Pre ∧ Post ∧ J-Safe ∧ R(ξ)≤ρ}`。对任意 LLM 输出 ξ，`ξ∈P` ⇒ 执行不违反关节/速度/力矩/接触/平衡约束；LLM 只影响“选哪个安全程序”和预算效率。**证明**：安全性是 P 的定义，与生成器无关。覆盖率由 `Ξ₀` 保证：LLM 完全失效时仍覆盖每个参数类的最小激励。

**引理 57（部署信任域界）** 对 `q∈Q_op`，

`||Δx(q)|| ≤ J_max·α||Δθ|| + O(||Δθ||²)`。

取 `α≤ε_deploy/(J_max||Δθ||)` 即保证一阶任务偏差 ≤ `ε_deploy`。**证明**：一阶 Taylor + 范数不等式。这是对“全局耦合风险”的定量约束：把热替换从“信任估计器”变成“信任证书 + 信任域 + 影子验证”。

**引理 58（信息守恒 / 安全-可辨识性权衡）** 对零空间激励 `δq∈N(q)`，若参数方向 u 只通过任务映射影响观测，则 `J_task N=0` ⇒ 该方向的任务空间 Fisher 信息为零。更一般地，`F_N=BᵀP_NᵀΣ⁻¹P_NB`，`rank(F_N) ≤ rank(P_NB)`；`ker(P_NB)` 中的方向不可辨识。**证明**：投影算子的秩不等式。**推论**：零空间越“安全”（N 越小），可获得的运动学信息越少；要辨识 θ_kin 的某个方向，必须允许该方向出现在观测雅可比的像空间里，并通过锚点把绝对参考引进来。这是本轮的“没有免费午餐”定理。

**引理 59（时序与退化链）** JointGauge 的异步部分不进入 50 Hz 路径；零空间投影与 J-Safe 检查在增量更新下保持 <0.2 ms；任一退化谓词成立 ⇒ 严格降级到 ToolGauge ⇒ LeanGauge ⇒ MODGAUGE，五不变式、IV-Joint 与 4CV 骨架不变。**证明**：与 ToolGauge 引理 50 同构；新增退化边逐条对应定义 447 的谓词否定。

### 7.1 规范秩（引理 52）

| 锚点设置 | rank(F_A) | 特征值（降序） | 零方向 | cond |

| 已知点位置 | 3 | 29.52, 0.424, 0.0688 | — | 429 |

**读法**：D-最优把设计点推向自运动流形的两端（`q₃≈±0.7, ±0.56, ±0.42`），因为那里 Jacobian 变化最大；均匀设计在中间浪费了信息。增益是“温和但真实”的：在 1 维自运动流形上，可操作空间本来就有限；更高冗余度的手臂应给出更大增益。这也说明“关节空间激励”不是魔法，它受流形几何约束。

### 7.4 固定范围下细化步长（引理 54）

固定 `q₃∈[−0.7,0.7]`，只改变采样数 N（步长 a=1.4/(N−1)）：

| N | a（rad） | 最小非零特征值（已知锚点） | trace（已知锚点） | 最小非零特征值（相对锚点） |
|---:|---:|---:|---:|---:|
| 5 | 0.3500 | 0.01162 | 3.643 | 0.002981 |
| 17 | 0.0875 | 0.03041 | 12.434 | 0.008755 |
| 65 | 0.0219 | 0.1072 | 47.589 | 0.03195 |

**读法**：固定自运动范围时，细化步长（N 增大）不会减少弱方向信息，反而使其单调增；同时单步二阶泄漏按 a² 下降。这两条合起来支持“慢-小”设计律：在时间/能量预算内，更多、更小的步长优于更少、更大的步长。pilot 未模拟低频漂移与相关噪声；它们会给出 a 的下界，也是引理 54 中 `ε_model` 项的来源。

### 7.5 Pilot 的边界

- 只有平面 3R、只有运动学偏置、只有几何/统计检查；
- 未验证接触丰富零空间、LLM 提案、D-最优的离散风险约束、部署信任域、50 Hz 时序；
- 41 个构型/T=1000 的 Monte Carlo 只用于 sanity check，不构成统计显著性结论；
- 所有数字是可复现的 pilot 结果，不是论文级实验。

## 9. 本轮最大风险

**一句话**：零空间证书只覆盖“激励过程”的一阶安全，而关节空间校准更新是**全局**的——一次错误的规范固定或信任域越界会同时污染整条运动学链，且接触模型误差会在小步长下以**线性项**泄漏进任务空间，使“本体自激励零风险”的前提失效；以规范固定证书、影子控制器、信任域界与 J-Quarantine 四重兜底，并把无锚点/零空间为空的情形强制降级到 ToolGauge 外部工具。
