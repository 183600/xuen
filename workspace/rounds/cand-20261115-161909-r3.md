# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「大语言模型」×「数据配比」）

> R69 让系统学会了「问」，并把效率押在一个未经审视的前提上：**流模型的模态分布是可信的**。但模态权重不是网络架构的属性，它是训练数据配比在策略上投下的影子。部署分布一旦偏离训练配比，权重就系统性失真：稀有但致命的模态被"坍缩"掉，常见情形被"幻觉"出过高置信；R69 的 MCG 校准门只能**发现并关掉**交互，不能**修复**根因。更尴尬的是，R69 的主动交互恰恰在生产最稀缺的那类数据（问句的回答、探针的响应），却没有任何受治理的通路把它送回模型：直接在线更新会违反 R68「实时流零学习写操作」的铁律，而无脑递归自训练又会引发模型坍缩。
>
> 本轮两个灵感正好补上：
> - **数据配比**：模型能力是配比 w 的一个低维、光滑（常为对数线性/指数）函数；存在可预测的最优配比，且可用小规模代理实验拟合「配比律」。这意味着"该吃什么"是一个可以被**控制、预测、审计**的低维变量，而不是碰运气。
> - **大语言模型**：语言给了域与配比一个组合式的规格接口（"雨夜、遮挡行人、低照度：15%"），LLM 还能做数据归因、标注、甚至预测配比收益；但 LLM 自己的偏好正是它训练配比的产物——**配比师也要被配比**。
>
> 核心命题：**把数据配比 w 提升为闭环的慢回路控制变量，与快回路的 λ 形成对偶：λ 决定"这一刻做多保守"，w 决定"长期该长成什么样"。运行时 epistemic 不确定性是误差信号；营养归因把它投影到"可由数据修复"的子空间，配比控制器在信任域、锚定下限、合成数据上限与证据无环约束下求解一个签名的配比差分；经金丝雀验证与原子换装后，才产生新的已认证配比。** 命名 **DIET-RAS**（Data-mIxture Epistemic Training for Risk-adaptive Systems；diet = 长期的数据食谱）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我的常识从哪来、下一口该吃什么、吃错了能不能吐出来**」——不确定性不只是刹车与提问，也可以是一次被审计的饮食调整。

## 0. 直觉与动机

**灵感 1（数据配比 → 模态分布是数据配比的影子）**
直觉：R69 把歧义看作策略输出的形状。但"策略愿意给出哪几个模态、各自多重"不是天生的，而是训练语料里各域出现频率、难度与覆盖度的函数。训练里 90% 是白天直行，模型就会把"雨夜遮挡"压成一个低权重的尾模态，甚至压没；这不是标定能救的，因为**标定只校正在给定支撑集上的置信，不创造被数据抹掉的支撑**。配比律告诉我们：能力对配比是连续可预测的，所以在选定训练规模前就能**预演**不同配比下模态会怎样——于是"补哪一口"可以算，不必试错。

**灵感 2（大语言模型 → 语言规格化 + 归因 + 但配比师有偏）**
直觉：域与配比天然是语言的：安全工程师说的是"夜间、雨天、逆光、有儿童"，不是张量索引。冻结 LLM 可以把这类规格编译成域切分与候选配比，把交互日志归因到语义域，甚至预测"再加 5% 近失事件能救回哪个模态"。但 LLM 的判断被它自己的预训练配比塑形：它对英语网页里常见的东西过度自信，对具身、稀有、非英语的域系统性低估。**让 LLM 当配比师，就必须同时校准配比师**，否则它会把你带向"它熟悉的常识"，而不是"你需要的常识"。

**灵感 3（对偶 → w 是 λ 的慢时间尺度镜像）**
直觉：λ 是一个标量、逐指令、只能收紧；w 是一个单纯形上的向量、跨训练周期、可增可减。二者结构上对偶：λ 处理"此刻的不可约噪声"，w 处理"跨代的可约缺失"。R69 只有 λ 这一条"降级"通道；R70 补上 w 这条"升级"通道，但升级必须比降级更慢、更可审计、更可回滚。安全系统的默认方向永远是降级；升级是一次**需要举证的例外**。

**灵感 4（三分 → 不是所有"可约"都能靠吃数据解决）**
直觉：R69 把 epistemic 当作"可约"。但可约分两种：一种是"我没见过/见得太少"，多吃这类数据能修；另一种是"这个世界在当前传感器、执行器与任务表征下本来就分不清"（真正的感知别名、不可观测参数、任务规格自相矛盾），再多的同类数据也修不了。把后者误当营养缺乏，会陷入**越吃越自信地错**。因此必须把 U_epi 再投影成 U_epi^data（落在配比律可及子空间）与 U_epi^struct（正交补），只有前者进配比控制器，后者永远走 R69 交互 / R68 保守。这是本轮的理论底线：**新层必须是旧层的严格泛化，而不是用一个会学习的嘴巴替换刹车**。

**灵感 5（递归自训练 → 吃自己会坍缩，证据图必须无环）**
直觉：R69 的交互数据零标注成本，看起来是免费午餐。但只要模型开始用自己的输出训练自己，尾部就会逐代消失（模型坍缩），而且最危险的是——**它会在自己的指标上越变越好**。因此需要一个比"合成比例上限"更强的约束：**证据图无环**——一个生成样本不能同时充当验证它自己的证据；验证关系必须构成 DAG。否则系统会用自己幻觉出的"确认"给自己盖章，这正是 R69 最大风险在时间维度上的展开。

## 1. 形式化定义（增量：定义 310–322）

**定义 310（DIET-RAS 总览与四不变式）** DIET-RAS = (LEDGER, DPL, MIXLAW, NUTRI, STRAT, CMD, ANCHOR, COLLAPSE-GUARD, CMIX, SLOWGATE, RAS-WM‡)。四不变式：
(i) **快回路零学习写**（继承 R68 定义 276-i）：运行时只读已认证的 (θ, w_cert)，任何梯度/权重/配比写操作不得发生在实时回路内；
(ii) **慢回路签名与审计**：每次配比变更产出签名差分 Δw、账本根哈希与 J_DIET，未签名不得生效；
(iii) **信任域 + 锚定下限**：‖w−w_cert‖_∞ ≤ ε_w 且安全锚定域 w_d ≥ w_min；
(iv) **来源与无环**：每样本可溯源到域/来源类型/时间；合成比例 ≤ w_syn_max；验证关系图无环。

**定义 311（数据账本 LEDGER）** 域集合 𝒟={1..D}。样本 x 的溯源 prov(x)=(d, src(x), t, h(x))，src ∈ {real, interaction, synthetic, anchor}。账本 L 是只追加的 Merkle 日志；配比 w ∈ Δ^{D−1} 由各域计数归一化得到。**一个"食谱"是 (w, 计数, 根哈希)**；相同 w 不同来源构成视为不同食谱（因为来源影响坍缩风险）。

**定义 312（配比条件策略族 DPL）** π_θ(·|o; e_w)，e_w=Emb(w) 经 FiLM 注入 mode_head 与速度场；训练时对 w 做配比课程/丢弃，使策略对 w 局部 Lipschitz（A99：‖π(·;w)−π(·;w′)‖ ≤ L_w‖w−w′‖）。**运行时 w 是常量**，e_w 预计算，故快回路零额外成本；这使"配比→模态"成为可微、可审计的映射，而非每换配比就重训一个黑箱。

**定义 313（配比-模态响应代理 MIXLAW）** 代理 M: w ↦ (ŵ_k(w), ECE(w), cov(w), phantom(w))，拟合自小规模配比扫描（代理规模）。A100：M 在 w_cert 邻域光滑（典型为对数线性/指数），其雅可比 J(w)=∂(ECE, phantom, cov)/∂w 有界。M 只用于**排序与预测**，不替代金丝雀实测（定义 318）。

**定义 314（营养归因 NUTRI）** 给定窗口内运行时证据 E（逐模态 ECE、幻影追问率、交互回答与先验的矛盾率、弃权率），拟合残差 r=E−M(w_cert)，在可辨识子空间内反解域亏缺：def = J^+ r，仅当 J 的秩/条件数满足可辨识门（定义 315）才采纳；否则标为"不可归因"。

**定义 315（三分不确定性与可辨识投影 STRAT）** U_epi = U_epi^data + U_epi^struct，其中 U_epi^data = ‖P_J U_epi‖（P_J 为到 J 列空间的正交投影），U_epi^struct = ‖(I−P_J)U_epi‖。若 rank(J) < D 或 cond(J) > κ_max，则存在配比零空间——**同一模态症状可由不同域亏缺解释**，不可归因部分一律计入 U_epi^struct。只有 U_epi^data 进 NUTRI；U_epi^struct 永远走 R69 交互 / R68 保守。

**定义 316（数据价值 DIET-VoI）** 对候选采集/加权动作 d：VoI_data(d) = E[Δ(ECE + λ_p·phantom + λ_c·collapse_risk)] − (c_ann(d)+c_comp(d)+c_forget(d))，在预算 B 与来源约束下取子集；R69 交互数据 c_ann=0 但 src=interaction，受定义 320 无环与合成上限约束。**"免费数据"不是免费的**。

**定义 317（认证配比差分 CMD）** 求解 min_w L(w)=ECE_pred(w)+λ_p·phantom_pred(w)，s.t. ‖w−w_cert‖_∞ ≤ ε_w，w_d ≥ w_min (d∈A)，w_syn ≤ w_syn_max，Σw=1，w ∈ W_safe（域相容约束）。输出签名 Δw 与预测增量 (ΔECE, Δphantom, Δcov)。L 使用 MIXLAW，最终由 SLOWGATE 实测裁决。

**定义 318（金丝雀与原子换装 SLOWGATE）** Δw 先在代理规模金丝雀训练与评测，须同时满足：(i) 实测 ECE ≤ 当前 + τ_up（不回退），(ii) 锚定保留 R_A ≥ 1−ε_forget，(iii) 安全测试零回归，(iv) 配比律残差 ‖实测−预测‖ ≤ τ_law（否则 MIXLAW 失效，整批作废）。全过则以一次原子指针交换 (θ,w)→(θ′,w′)，并保留回滚指针；任一不过则回滚且该 Δw 记入负样本账本。

**定义 319（安全锚定与遗忘地板 ANCHOR）** A ⊂ 𝒟 为安全关键域（近失、稀有危险、标定探针、产生安全相关回答的交互轨迹）；w_d ≥ w_min 是数据侧的 λ_floor 镜像。遗忘以锚定保留率 R_A 度量；容量干扰用域干扰矩阵 I_{dd′} 计入 L(w)，避免"补 A 塌 B"。

**定义 320（坍缩与污染守卫 COLLAPSE-GUARD）** 合成/自生成比例 ≤ w_syn_max；生成数据多样性熵 H_gen ≥ H_min；且**证据图无环**：若样本 x 由模型版本 v 生成，则 x 不得作为评估 v 或其后代的唯一/主要证据；验证关系必须构成 DAG（每个评估边指向严格更早的生成层）。违反则样本降权或整批隔离。

**定义 321（LLM 配比师与配比师校准 CMIX）** 冻结 LLM 产出域模式、候选配比 w_llm 与能力预测。其提案只是**候选**，须过 MIXLAW 一致性、来源、预算、无环四道检查。定义配比师校准误差 ECE_mix（预测提升 vs 实测提升）；ECE_mix > τ_mix 时，LLM 提案权重下调，退回纯律优化。**配比师自己也要被配比。**

**定义 322（证书 J_DIET 与快慢防火墙）** J_DIET = (J_FLUID, ledger_root, w_before, w_after, ΔECE_pred/real, R_A, w_syn, ε_w, law_residual, ident_rank, canary_verdict, rollback_ptr, diet_ver)。Valid ⇔ Valid(J_FLUID) ∧ ECE_mix ≤ τ_mix ∧ 四不变式成立。**快慢防火墙**：运行时到慢回路的唯一耦合是经账本聚合的**潜证据**（统计量，不是梯度/权重）；快回路是已认证 (θ,w) 的纯函数。这保证 R68 的实时安全与可审计性在时间维度上依然成立。

```python
# IP-264 LEDGER / IP-265 DPL / IP-266 MIXLAW
class DietLedger:                       # append-only Merkle log
    def append(self, batch, prov): ...
    def root(self): ...
    def mixture(self, domains): ...     # -> w, counts, src breakdown

class DietPolicy:                       # 快回路：配方是常量，零额外成本
    def __init__(self, trunk, mode_head, velocity_net, embed_w):
        self.trunk, self.head, self.v, self.embed = ...
        self.e_w = self.embed(w_cert)    # 预计算
    def sample(self, o_t, K): ...       # 与 R69 完全相同，条件额外拼 e_w

# IP-267 NUTRI：把运行时症状投影到"可被数据修复"的子空间
def nutritional_attribution(evidence, J, ident_gate):
    if not ident_gate(J):               # rank / cond 不过
        return None, 'unidentifiable'   # 全部计入 U_epi^struct
    r = evidence - mixlaw.predict(w_cert)
    return pinv(J) @ r                  # def_d

# IP-268 STRAT：三分
def split_uncertainty(U_epi, J):
    P = projector(J)
    return norm(P @ U_epi), norm((I - P) @ U_epi)   # data / struct

# IP-269/270 CMD：约束下的配比差分
def propose_diet(defc, w_cert, law, budget):
    w = solve_argmin(law.loss, x0=w_cert,
                     cons=[trust_region(eps_w), anchor_floor(A, w_min),
                           synth_cap(w_syn_max), simplex()])
    return signed_diff(w_cert, w), law.predict_delta(w_cert, w)

# IP-268~275 慢回路主流程（离线，违反预算即不动）
def DIET_slow_round(runtime_stats, ledger, w_cert):
    ev = aggregate(runtime_stats)                  # 潜证据，无梯度
    U_ale, U_epi = ev.U_ale, ev.U_epi
    J  = mixlaw.jacobian(w_cert)
    U_data, U_struct = split_uncertainty(U_epi, J)
    if U_data < TAU_NUTRI:                         # 无营养缺乏 -> 不动
        return w_cert, 'no-change'
    defc = nutritional_attribution(ev, J, ident_gate)
    if defc is None or defc.max() < TAU_DEF:
        return w_cert, 'unidentifiable->R69/R68'
    cand = select_by_VoI(defc, budget, provenance_ok=True)
    dw, pred = propose_diet(defc, w_cert, mixlaw, budget)
    if not egraph.acyclic(cand, ledger):           # IP-274
        return w_cert, 'cycle->quarantine'
    verdict = slowgate.canary(dw, pred)            # IP-275: train+eval on proxy
    if verdict.reject or verdict.law_residual > TAU_LAW:
        return w_cert, 'rollback'
    ledger.commit(dw, verdict)                     # signed, atomic swap
    return verdict.w_new, 'promoted'
```

## 3. 推导

**引理 19（配比→模态的可辨识性）** 设 M 在 w_cert 邻域可微，J=∂m/∂w（m 为可观测模态统计）。模态症状 r 能被唯一归因到域亏缺 def 当且仅当 r ∈ col(J)；若 rank(J)<D，则存在配比零空间 𝒩(J)，其上的域调整对模态统计一阶不可见——此时任何"归因"都是欠定的，必须计入 U_epi^struct。**系**：可辨识度 rank(J) 是"营养学"能否成立的前提；域高度共线（如同源采集的日/夜数据）会让配比律退化为不可归因。

**引理 20（数据侧 resolution bonus 的安全单调性）** 在 A99–A100 与认证配比下，若 Δw 使 U_epi^data 下降且通过 SLOWGATE，则 ECE 与 phantom 期望不升、U_epi^struct 不变，故 DIET 的保守下限不弱于 FLUID；当 U_data < τ 或不可归因或预算为 0 时，DIET 与 FLUID 逐指令相同。**系**：分辨率收益只来自"确实能被数据修复"的那部分，绝不来自把结构歧义误当营养缺乏。

**引理 21（递归自训练的尾部消失下界）** 设每代以比例 w_syn 使用自生成数据、稀有模态每次递归的存活因子为 (1−κ)，则 G 代后尾模态质量 ≥ m_0(1−w_syn κ)^G；给定安全检测阈值 m_min 与 horizon G，存在硬上限 w_syn_max = (1−(m_min/m_0)^{1/G})/κ。叠加无环约束（定义 320）后，自生成样本不能作为自身证据，坍缩只可能发生在**未被独立思考的维度**上。

**引理 22（LLM 配比师的偏置）** LLM 的配比提案在与其预训练配比接近的域上系统性高估收益、在稀有具身域上系统性低估。若不做 ECE_mix 校准，提案提升的期望偏差 ≥ b·‖w_llm−w_pretrain‖，且该偏差不会被金丝雀发现（金丝雀与 LLM 共享同一语义先验时更甚）。故 CMIX 门控不可省。

**定理 18（DIET 严格包含 FLUID）** 在 A99–A100 与定义 310 四不变式下，DIET 任意运行的期望风险 ≤ FLUID；当配比控制器关闭、U_epi^data=0、或 CMIX/可辨识门未过时两者逐指令相同。R69 是 DIET 在"永不改食谱"边界上的退化：安全侧不让步，效率侧获得营养 resolution bonus。

**定理 19（慢回路无突变与认证原子性）** 快回路只读冻结的 (θ,w_cert)，故 R68 定理 15 的提交/换装不变式与 R69 定理 17 的控制连续性保持；配比换装是原子指针交换并带回滚，系统不存在"半认证食谱"的中间态。**系**：R70 把"安全"从单步动作扩展到模型演化本身——演化也被关进证书里。

# 第 70 轮产物 · 创新点清单 v1：DIET-RAS（Data-mIxture Epistemic Training for Risk-adaptive Systems：大语言模型配比师 × 数据配比律的慢回路营养闭环；LEDGER×DPL×MIXLAW×NUTRI×STRAT×CMD×ANCHOR×COLLAPSE-GUARD×CMIX×SLOWGATE）

> 承接第 69 轮 IP-253~263（FLUID-RAS）。R69 让系统学会了「问」，但其效率全押在「流模型的模态分布可信」这一前提上。而模态权重不是架构属性，是**训练数据配比**投下的影子：部署分布偏离训练配比 → 稀有模态被压没、常见情形被幻觉出高置信。R69 的 MCG 校准门只能发现并关掉交互，**不能修根因**；而 R69 的主动交互恰恰在生产最稀缺的数据，却没有受治理的回流通道（在线更新违反 R68「实时流零学习写」，无脑自训练又会模型坍缩）。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** DIET-RAS 见符号表；四不变式：快回路零学习写（继承 276-i）；慢回路签名+账本；信任域 ‖w−w_cert‖_∞≤ε_w 且锚定 w_d≥w_min；来源可溯 + 合成≤w_syn_max + 验证图无环。

**定义 311–312（账本与 DPL）** 只追加 Merkle 账本得 `(w,计数,根哈希)`；`π(·|o;e_w)` 对 w 局部 Lipschitz（A99 `L_w`），运行时 w 为常量、e_w 预计算 → 快回路零成本。

**定义 313–314（MIXLAW 与 NUTRI）** `M: w→(ŵ_k,ECE,cov,phantom)`，A100 光滑、J 有界；残差 `r=E−M(w_cert)`，`def=J⁺r` 仅在秩/条件数过门时采纳。

**定义 315（三分 STRAT）** `U_epi^data=‖P_J U_epi‖`，`U_epi^struct=‖(I−P_J)U_epi‖`；`rank(J)<D` 或 `cond(J)>κ_max` 时不可归因部分全计入 struct。只有 data 进配比，struct 走 R69/R68。

**定义 316–317（DIET-VoI 与 CMD）** `VoI_data` 扣标注/算力/遗忘成本后选集；`min L(w)` 受信任域、锚定、合成上限、单纯形、域相容约束，输出签名 Δw 与预测增量。

**定义 318–319（SLOWGATE 与 ANCHOR）** 金丝雀须四过：ECE 不回退、`R_A≥1−ε_forget`、安全零回归、`law_residual≤τ_law`；全过则原子换装 + 回滚指针。安全域 `w_d≥w_min`，域干扰 `I` 入损失。

**定义 320（COLLAPSE-GUARD）** `w_syn≤w_syn_max`、`H_gen≥H_min`，且 **证据图无环**：生成样本不得作为评估其生成者/后代的唯一或主要证据。

**定义 321（CMIX）** LLM 提案仅候选，过律一致/来源/预算/无环四检；`ECE_mix>τ_mix` 即降权并退纯律优化。

**定义 322（J_DIET 与 TFS）** Valid ⇔ Valid(J_FLUID) ∧ ECE_mix≤τ_mix ∧ 四不变式；运行时→慢回路只传统计潜证据，快回路为 `(θ,w_cert)` 纯函数。

## 3. 关键算法伪代码

```python
# IP-264/265/266：账本、配比条件策略、配比律代理
class DietLedger:
    def append(self, batch, prov): ...          # Merkle，只追加
    def mixture(self): ...                      # -> w, counts, src breakdown

class DietPolicy:                               # 快回路，零额外成本
    def __init__(self, trunk, head, v, embed, w_cert):
        self.e_w = embed(w_cert)                # 预计算
    def sample(self, o_t, K): ...               # 同 R69，额外拼 e_w

# IP-267/268：归因与三分
def nutritional_attribution(ev, J, gate):
    if not gate(J): return None, 'unidentifiable'
    return pinv(J) @ (ev - mixlaw.predict(w_cert))

def split_uncertainty(U_epi, J):
    P = J @ pinv(J)
    return norm(P @ U_epi), norm((I - P) @ U_epi)   # data / struct

# IP-269/270：VoI 选集 + 约束配比差分
def propose_diet(defc, w_cert, law, budget):
    w = solve_argmin(law.loss, x0=w_cert,
                     cons=[trust_region(eps_w), anchor_floor(A, w_min),
                           synth_cap(w_syn_max), simplex(), domain_compat()])
    return signed_diff(w_cert, w), law.predict_delta(w_cert, w)

# IP-277：慢回路主流程（离线；任一门不过即维持 w_cert）
def DIET_slow_round(runtime_stats, ledger, w_cert):
    ev = aggregate(runtime_stats)                   # TFS：潜证据，无梯度
    J  = mixlaw.jacobian(w_cert)
    U_data, U_struct = split_uncertainty(ev.U_epi, J)
    if U_data < TAU_NUTRI: return w_cert, 'no-change'
    defc = nutritional_attribution(ev, J, ident_gate)
    if defc is None or defc.max() < TAU_DEF:
        return w_cert, 'unidentifiable->R69/R68'
    cand = select_by_VoI(defc, budget)
    dw, pred = propose_diet(defc, w_cert, mixlaw, budget)
    if not egraph.acyclic(cand, ledger):            # IP-274
        return w_cert, 'cycle->quarantine'
    verdict = slowgate.canary(dw, pred)             # IP-275
    if verdict.reject or verdict.law_residual > TAU_LAW:
        return w_cert, 'rollback'
    ledger.commit(dw, verdict)                      # 签名 + 原子换装
    return verdict.w_new, 'promoted'
```

## 4. 推导

**引理 19（配比→模态的可辨识性）** 症状 r 可唯一归因当且仅当 `r ∈ col(J)`；`rank(J)<D` 时存在配比零空间，其上的域调整对模态统计一阶不可见，必须计入 U_epi^struct。**系**：域高度共线会让「营养学」退化为不可归因。

**引理 20（数据侧 resolution bonus 的安全单调性）** A99–A100 与认证配比下，若 Δw 降 U_epi^data 且过 SLOWGATE，则 ECE/phantom 不升、U_epi^struct 不变 ⇒ DIET 保守下限不弱于 FLUID；U_data<τ / 不可归因 / 预算 0 时逐指令相同。

**引理 21（递归自训练的尾部消失下界）** G 代后尾模态质量 `≥ m_0(1−w_syn κ)^G`，给定 `m_min` 与 horizon G 得硬上限 `w_syn_max=(1−(m_min/m_0)^{1/G})/κ`；无环约束保证坍缩只发生在未被独立思考的维度。

**引理 22（LLM 配比师偏置）** 同预训练配比域高估、稀有具身域低估；不校准则期望偏差 `≥ b‖w_llm−w_pretrain‖`，且共享语义先验的金丝雀难以发现 ⇒ CMIX 门控不可省。

**定理 18（DIET 严格包含 FLUID）** A99–A100 与四不变式下，DIET 期望风险 ≤ FLUID；配比控制器关闭、U_epi^data=0、CMIX/可辨识门未过时逐指令相同。R69 = 「永不改食谱」边界。

**定理 19（慢回路无突变与认证原子性）** 快回路只读冻结 `(θ,w_cert)` ⇒ R68 定理 15 与 R69 定理 17 保持；换装为原子指针交换且可回滚，不存在半认证食谱中间态。**系**：演化本身也被关进证书。
