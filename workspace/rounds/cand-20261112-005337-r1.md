# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「人形机器人」×「位姿估计」）

> 第 54 轮把技能组合建立在动作空间剖面 α_S 与云边协同 γ_ce 之上。本轮把视角下沉到 **浮基人形机器人的位姿估计**：人形的一切动作都以基座位姿 ξ 为根，位姿误差会沿运动学树放大并污染动作空间证书。核心矛盾：H22：位姿不确定度未被条件化进 α_S，导致「动作覆盖」在真实漂移下系统性失真；H23：云边位姿校正以跳变形式到达边端，全局正确的位姿在动作空间里不可连续执行；H24：位姿估计的置信度与真实误差脱钩（过度自信），使证书建立在虚假可信之上。

## 0. 直觉与动机

**灵感 1（位姿条件化的动作剖面 → 把「能不能做」变成「在这个位姿信念下能不能做」）**
直觉：第 54 轮的 `α_S(a)` 隐含假设基座位姿精确。人形是浮基系统，动作 a 的可行性依赖当前位姿信念 `b(ξ)=N(μ,Σ)`：抓取需要基座位置误差 < 2cm，动态行走需要姿态角误差 < 3°。因此技能应携带 **位姿需求 `ε_S`**，其动作剖面变为 `α_S(a | b)`，只有当位姿落在可行包络 `Ξ_S(ε_S)` 内且概率足够高时，动作才被判定为覆盖。位姿不确定度由此成为**动作空间的第一性约束**，而不是事后误差条。

**灵感 2（接触一致的位姿估计 → 把「滑移」和「漂移」拆开）**
直觉：人形腿式里程计用「支撑脚在世界中不动」推基座位移。但脚打滑与基座漂移产生**完全相同的接触残差** `r_contact`。若接触数 ≥3 且非共线，基座位姿误差 δξ 与滑移 s 可分离；若接触退化（单脚、共线、腾空），该方向不可观测，位姿估计应**显式标记 ambiguous** 而不是假装准确。位姿估计器必须输出「我此刻可信吗」，而不只是「我此刻在哪」。

**灵感 3（位姿可信度证书 PTC → 置信度必须被外部证据校准）**
直觉：协方差 Σ 是估计器的自我声明，可能系统性低估误差。可信度不能只看 Σ，必须联合 **NEES 一致性检验（检测过度自信）+ 接触一致残差 + 可见性/遮挡 + sim-to-real 校准证据**。PTC 是位姿的「体检报告」：`PTC=(Σ, NEES, r_contact, vis, calib)`。只有 PTC 通过，位姿条件化可行性才被允许进入组合规划。

**灵感 4（主动位姿感知 → 动作同时买到任务进度和位姿信息）**
直觉：人形可以转头、转身、迈步来改善位姿估计。于是动作价值是双目标的：`V(a)=task_reward(a)+λ·I(a)`，其中 `I(a)` 是动作带来的位姿熵下降。主动位姿感知把「探测」纳入技能组合图 G_S 的边权：有些动作任务收益低但能把位姿信念拉回可行包络，从而解锁后续高价值技能。这把第 54 轮的最短路径搜索升级为**带信念约束的信息-任务联合规划**。

**灵感 5（跳变安全的云边位姿校正 → 全局正确不等于可连续执行）**
直觉：云端位姿图优化/重定位给出的修正常是「瞬移」。边端控制器在旧参考系里积分，位姿瞬移会让期望轨迹断裂。正确做法是把修正拆成**有界速率的平滑校正序列** `μ ← μ ⊕ γ(t)Δξ`，`||dγ/dt|| ≤ v_max`，且每步校验控制器跟踪稳定性。定义 **位姿跳变预算 `J_max`**：超过预算的修正必须多步下发，否则否决。这把第 54 轮 CEC 的「反向解释回传」扩展为「位姿校正信道」。

**灵感 6（位姿误差注入的 sim-to-real 证书 → 别让仿真真值喂出虚假 soundness）**
直觉：仿真里位姿是真值，证书在完美位姿下必然 sound，一上真机就崩。必须在仿真回放中注入**位姿误差过程**：随机游走漂移、重尾滑移突发、遮挡离群。证书只对误差模型支撑集内的最坏位姿误差成立。这把第 54 轮的联合证书 J 升级为 **位姿鲁棒证书 PRT**。

**灵感 7（位姿-形态联合自模型 → 位姿异常也是本体异常）**
直觉：人形同时估计「我在哪」和「我的身体是什么样」。若运动学位姿与视觉/接触位姿持续不一致，且无法用滑移解释，则很可能是**本体形变/损伤**（关节零位漂移、连杆变形）。位姿残差因此成为自模型一致性的探针，把位姿估计接入第 54 轮的能力格与形态层。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（位姿信念状态）**
浮基位姿 `ξ ∈ SE(3)`，位姿信念 `b(ξ) = N(μ, Σ)`（在 `se(3)` 切空间上参数化）。位姿误差 `e = Log(ξ̂^{-1}ξ*)`。信念传播 `b' = f(b, a)` 由动作 a 的运动学与观测信息共同决定。

**定义 122（位姿条件化动作剖面与可行包络）**
技能 S 携带位姿需求 `ε_S`，其可行位姿包络
```
Ξ_S(ε_S) = { ξ : ||Log(ξ^{-1} ξ*)||_{Σ} ≤ ε_S }
```
位姿条件化剖面 `α_S(a | b) = feas_S(a) · 1[ Pr_{b}(ξ ∈ Ξ_S) ≥ 1 - δ ]`。动作 a 在信念 b 下可行，当且仅当 `feas_S(a)=1` 且 `Pr_b(Ξ_S) ≥ 1-δ`。

**定义 123（接触一致残差与滑移-漂移可辨识性）**
支撑接触集 `C = {(link_i, p_i^ref)}`。接触残差
```
r_i = FK(q, ξ, link_i) - p_i^ref
```
对残差线性化 `r = H_ξ δξ + H_s s + ν`，`s` 为滑移。可辨识性矩阵 `M = [H_ξ | H_s]`。若 `rank(M) = 6 + dim(s)` 且最小奇异值 `σ_min ≥ σ_0`，则 δξ 与 s **可分离**；否则存在不可观测方向 `U_amb`，估计器必须输出 `ambiguous` 标记而非点估计。

**定义 124（位姿可信度证书 PTC）**
```
PTC = (Σ, NEES, r_contact, vis, calib)
```
- `NEES = e^T Σ^{-1} e / dof`，落在卡方区间 `[χ²_lo, χ²_hi]` 内才通过（上越界 = 过度自信）；
- `r_contact` 为接触一致残差范数；
- `vis` 为视觉可见性/遮挡评分；
- `calib` 为 sim-to-real 位姿误差覆盖率校准。
`PTC.pass = 1` 当且仅当 NEES 一致 ∧ `r_contact ≤ ρ_c` ∧ (`vis ≥ v_min` ∨ `rank(M) ≥ 6`) ∧ `calib ≤ γ_cal`。

**定义 125（位姿信息动作价值）**
位姿信念熵 `H(b)`。动作 a 的位姿信息增益 `I(a) = H(b) - E_{o}[H(b' | a, o)]`。主动位姿感知组合目标：
```
max_{π}  E[ Σ_{(S,a)∈π} task_reward(S,a) + λ·I(a) ]
s.t.     ∀ (S,a)∈π : α_S(a | b_t) = 1,  b_{t+1}=f(b_t,a)
```

**定义 126（跳变安全位姿校正契约与位姿鲁棒迁移证书）**
校正契约 `C_jump = (Δξ, J_max, v_max, smooth_γ)`：云端修正 `Δξ` 拆为 `k = ⌈||Δξ||/J_max⌉` 步，每步 `μ ← μ ⊕ clamp(v_max·dt, γ_i Δξ)`，且每步 `controller.tracking_stable(μ)=1`。位姿鲁棒迁移证书
```
PRT = (error_model, ε_S, worst_case_e, evidence)
```
要求在误差模型支撑集内 `∀ e : success(sim_rollout ⊕ e) ≥ 1 - β_pose`。

## 2. 关键算法 伪代码

### IP-121 PCS（Pose-Conditioned Skill feasibility）

```python
def pose_envelope(skill, eps_S):
    return lambda xi: mahalanobis(xi, skill.xi_ref, skill.Sigma_ref) <= eps_S

def pose_conditioned_profile(skill, A, belief, delta=1e-3):
    alpha = {}
    Xi = pose_envelope(skill, skill.eps_S)
    p_ok = prob_within(belief, Xi)
    for a in A:
        feas = skill.can_execute(a)
        alpha[a] = feas * (1.0 if p_ok >= 1 - delta else p_ok)
    return alpha

def pose_conditioned_feasible(skill, a, belief, delta=1e-3):
    if not skill.can_execute(a):
        return False
    return prob_within(belief, pose_envelope(skill, skill.eps_S)) >= 1 - delta
```

### IP-122 CCE（Contact-Consistent Estimator）

```python
def contact_consistent_update(prior, q, contacts, imu, vision):
    pred = imu_preintegrate(prior, imu) ⊕ leg_odometry(q, contacts)
    r = [FK(q, pred.mu, c.link) - c.ref for c in contacts]
    H_xi, H_s = contact_jacobian(q, pred.mu, contacts)
    rank, sigma_min, U_amb = identifiability(H_xi, H_s)
    if rank >= 6 and sigma_min >= sigma_0:
        s = solve_slip(r, H_xi, H_s)          # 基座误差与滑移可分离
        xi = correct(pred.mu, r - H_s @ s)
        ambiguous = False
    else:
        s = None
        xi = pred.mu
        ambiguous = True                       # 不可观测，显式标记
    if vision.ok and not vision.outlier:
        xi = fuse_vision(xi, vision)
    belief = PoseBelief(xi, cov(pred, r, vision))
    return belief, ContactResidual(r, s, rank, sigma_min, U_amb, ambiguous)
```

### IP-123 PTC（Pose Trust Certificate）

```python
def pose_trust_certificate(belief, contact, vision, calib):
    nees = mahalanobis(belief.err, belief.Sigma) / dof
    consistent = chi2_lo <= nees <= chi2_hi        # 上越界 = 过度自信
    contact_ok = norm(contact.r) <= rho_c and not contact.ambiguous
    vis_ok = vision.visibility >= v_min or contact.rank >= 6
    calib_ok = calib.coverage_error <= gamma_cal
    passed = consistent and contact_ok and vis_ok and calib_ok
    return PoseTrust(belief.Sigma, nees, consistent, contact,
                     vis_ok, calib_ok, passed, evidence=[vision.log, calib.log])
```

### IP-124 APA（Active Pose-Aware planning）

```python
def active_pose_plan(skills, G, belief, task, lam, delta):
    best = None
    for path in candidate_paths(G, task):
        b, ok, gain = belief, True, 0.0
        for (sid, a) in path:
            s = skills[sid]
            b_next = predict_belief(b, s, a)     # 动作带来观测 → 位姿熵下降
            if not pose_conditioned_feasible(s, a, b_next, delta):
                ok = False
                break
            gain += info_gain(b, b_next)
            b = b_next
        if ok:
            score = task_reward(path) + lam * gain
            best = path if best is None or score > best.score else best
    return best
```

### IP-125 JSC（Jump-Safe Correction）

```python
def jump_safe_correct(mu, delta_xi, J_max, v_max, dt, controller):
    k = ceil(norm(delta_xi) / J_max) if norm(delta_xi) > J_max else 1
    for i in range(k):
        step = clamp_rate(split(delta_xi, k)[i], v_max * dt)
        mu = mu ⊕ step
        if not controller.tracking_stable(mu):
            return ('reject', 'control_discontinuity', i)
        yield mu
    return ('ok', mu)
```

### IP-126 PRT（Pose-Robust Transfer）

```python
def pose_robust_certify(sim_rollout, error_model, eps_S, budget, N):
    worst = None
    for e in error_model.worstcase(N):          # 漂移/滑移突发/遮挡离群
        traj = sim_rollout.with_pose_error(e)
        if success_metric(traj) < 1 - budget:
            worst = e if worst is None else max_err(worst, e)
    if worst is not None:
        return ('reject', 'pose_error_sensitive', worst)
    return ('ok', PoseRobustCert(error_model.radius, eps_S, evidence=error_model.log))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| PCS | O(|A|·|Ξ|) | O(|A|) | 包络可判定、概率下界可靠 |
| CCE | O(|C|·n²) 每次更新 | O(n²) | 可辨识性判定、滑移模型有界 |
| PTC | O(n²) | O(n²) | NEES 双侧检验、校准覆盖 |
| APA | O(|P|·|A|·H) | O(|V|+|E|) | 信念传播可组合、信息增益单调 |
| JSC | O(k·n) | O(k) | 跳变预算闭合、跟踪稳定性 |
| PRT | O(N·T) | O(T) | 误差模型覆盖真实漂移 |

**正确性定理（Pose-Conditioned Composition Soundness）**
假设第 54 轮 (A22)–(A28) 成立；新增 **(A29)** 位姿估计器在可辨识区满足 NEES 一致性，且 `PTC.pass ⇒ 真实误差 ≤ ε_S`（校准有效）；**(A30)** 接触退化时 `ambiguous` 被正确上报，不进入组合；**(A31)** 云端修正满足跳变预算 `||Δξ|| ≤ J_max·k` 且每步跟踪稳定；**(A32)** 位姿误差模型覆盖真实漂移/滑移/遮挡支撑集。
则：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
             - P(pose_err > ε_S | PTC.pass) - P(PTC overconfident) - P(error_model miss)
```
关键：**位姿可信才允许动作可行**，**接触退化必须显式降级**，**校正必须连续可执行**，**证书必须对位姿误差过程鲁棒**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 位姿估计器过度自信（Σ 低估） | 高 | NEES 双侧检验 + 外部接触/视觉证据 + 在线校准 |
| 滑移与漂移不可辨识被误当可辨识 | 高 | 可辨识性矩阵 + σ_min 门限 + ambiguous 显式降级 |
| 云端位姿跳变破坏控制 | 高 | 跳变预算 + 平滑校正 + 逐步跟踪校验 |
| 主动感知导致任务停滞（信息贪心） | 中 | 信息增益折扣 + 任务-信息 Pareto 约束 |
| 位姿误差模型不覆盖真实漂移 | 高 | 红队误差注入 + 重尾/突变建模 + 真机回归 |
| 位姿-形态耦合误诊（把损伤当漂移） | 中 | 滑移解释优先 + 本体自模型残差分离 |

## 6. 本轮最大风险

**一句话**：把位姿估计提升为动作可行性的第一性约束，能让「动作覆盖」在真实漂移下保持 sound，但整条链路把 **PTC 的校准有效性**变成了单点信任根——一旦估计器系统性过度自信或接触退化未被识别，位姿条件化会把虚假可信放大成「看似可行」的组合路径，真机上以位姿漂移引发系统性动作错位与失稳，故必须以 **NEES 双侧检验 + 可辨识性显式降级 + 位姿误差注入回归** 三重护栏，宁可判定不可行，也绝不把「位姿自我声明」当作部署前提。

```python
    p_ok = prob_within(belief, Xi)
    for a in A:
        alpha[a] = skill.can_execute(a) * (1.0 if p_ok >= 1 - delta else p_ok)
    return alpha

def pose_conditioned_feasible(skill, a, belief, delta=1e-3):
    return (skill.can_execute(a)
            and prob_within(belief, pose_envelope(skill, skill.eps_S)) >= 1 - delta)
```

```python
def contact_consistent_update(prior, q, contacts, imu, vision):

    if vision.ok and not vision.outlier:
        xi = fuse_vision(xi, vision)
```

```python
def pose_trust_certificate(belief, contact, vision, calib):
    nees = mahalanobis(belief.err, belief.Sigma) / dof
    consistent = chi2_lo <= nees <= chi2_hi
```

### IP-124 APA

```python
def active_pose_plan(skills, G, belief, task, lam, delta):
    best = None
    for path in candidate_paths(G, task):
        b, ok, gain = belief, True, 0.0
        for sid, a in path:
            s = skills[sid]
            b_next = predict_belief(b, s, a)
            if not pose_conditioned_feasible(s, a, b_next, delta):
                ok = False; break
            gain += info_gain(b, b_next)
            b = b_next
        if ok:
            score = task_reward(path) + lam * gain
            if best is None or score > best.score:
                best = Plan(path, score, gain)
    return best
```

### IP-125 JSC

```python
def jump_safe_correct(mu, delta_xi, J_max, v_max, dt, controller):
    k = max(1, ceil(norm(delta_xi) / J_max))
    for i in range(k):
        step = clamp_rate(split(delta_xi, k)[i], v_max * dt)
        mu = mu ⊕ step
        if not controller.tracking_stable(mu):
            return ('reject', 'control_discontinuity', i)
        yield mu
    return ('ok', mu)
```

```python
def pose_robust_certify(sim_rollout, error_model, eps_S, budget, N):
    worst = None
    for e in error_model.worstcase(N):
        traj = sim_rollout.with_pose_error(e)
        if success_metric(traj) < 1 - budget:
            worst = e if worst is None else max_err(worst, e)
    if worst is not None:
        return ('reject', 'pose_error_sensitive', worst)
    return ('ok', PoseRobustCert(error_model.radius, eps_S,
                                 evidence=error_model.log))
```

| 组件 | 时间 | 空间 | 正确性保证 |

| PRT | O(N·T) | O(T) | 误差模型覆盖真实漂移 |

**正确性定理（Pose-Conditioned Composition Soundness）**
假设第 54 轮 (A22)–(A28) 成立；新增 **(A29)** `PTC.pass ⇒ 真实位姿误差 ≤ ε_S`（校准有效）；**(A30)** 接触退化时 `ambiguous` 正确上报、不进入组合；**(A31)** 云端修正满足 `||Δξ|| ≤ J_max·k` 且每步跟踪稳定；**(A32)** 位姿误差模型覆盖真实漂移/滑移/遮挡支撑集。
则：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
             - P(pose_err > ε_S | PTC.pass) - P(PTC overconfident) - P(error_model miss)
```
关键：**位姿可信才允许动作可行**，**接触退化显式降级**，**校正连续可执行**，**证书对位姿误差过程鲁棒**。

## 6. 本轮最大风险

**一句话**：把位姿估计提升为动作可行性的第一性约束，能让「动作覆盖」在真实漂移下保持 sound，但整条链路把 **PTC 的校准有效性**变成了单点信任根——一旦估计器系统性过度自信或接触退化未被识别，位姿条件化会把虚假可信放大成「看似可行」的组合路径，真机上以位姿漂移引发系统性动作错位与失稳，故必须以 **NEES 双侧检验 + 可辨识性显式降级 + 位姿误差注入回归** 三重护栏，宁可判定不可行，也绝不把「位姿自我声明」当作部署前提。
