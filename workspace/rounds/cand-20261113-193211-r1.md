# 第 69 轮（承接第 68 轮「CALM-RAS 标定感知自监督闭环」IP-243~252；灵感循环第 2 轮；本轮灵感：「模型预测控制」×「可解释性」）

> 第 68 轮把「测量可信度」补成了一等公民，却把两笔更深的债留在了账上。**债一：安全靠纪律，不靠证明。** R66–R68 的保守性全部写在 λ_floor、τ 重参数化、k_cal 收缩这些「不确定就收紧」的启发式里——它们能保证「不确定不会放宽」，却不能保证「收紧之后仍然安全」，更无法回答「为什么恰好收紧这么多」。**债二：解释靠旁观，不靠构造。** VQAuditor 是事后第三人称审判，模型本身仍是黑箱；而 R68 自陈的最大风险恰恰是「缓变故障被标定吸收」——一个**连审计者都看不见**的失效，因为审计的对象（残差）已经被标定层抹平了。
>
> 本轮的两个灵感正好是这两笔债的对症药：**MPC 把「不确定就收紧」升级为「在约束下显式求解，并用终端安全集与递归可行性给出前瞻安全证明」；可解释性把「事后审计」升级为「决策必须经由可读概念、并携带反事实证书」**。
>
> 核心命题：**不再执着于把「漂移 vs 缓变故障」分对——而是让两者的后果被同一个上界锁住。** 用概念瓶颈把潜状态翻译成人可读的 κ，用管式 MPC 在 κ 空间以 U 为扰集求可行安全前缀，用 STL 鲁棒度把「约束为何收紧」变成可读解释，用反事实见证把「结论有多脆」变成可度量证据。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**这个决定凭什么、有多脆、能不能被证伪**」。名字：**CIM-RAS（Concept-Interpretable Model-Predictive RAS）**。

## 0. 直觉与动机

**灵感 1（模型预测控制 → 从「收紧纪律」到「约束下的可行性证明」）**
直觉：R68 的 λ_floor 与 k_cal 收缩是开环、无模型、拍脑袋的保守映射；MPC 则把控制写成「在 H 步上最小化代价、满足约束、终点落入安全集」的显式优化。它带来 R66–R68 从未拥有的东西：**递归可行性（recursive feasibility）**——只要 t 时刻存在可行解，在扰动属于已知管 W 时 t+1 仍有可行解。于是「安全」不再依赖「我猜一个更保守的 λ」，而依赖「我证明了这个前缀存在」。**不确定性的正确用法不是把旋钮拧紧，而是进入约束内缩项（tube tightening）与终端集。**
- 关键转译：R68 的标定不确定 U = tr Σ_c 与 WM 残差包络，正是 MPC 扰集 W 的物理来源；「测量有多不准」直接变成「鲁棒约束要内缩多少」。

**灵感 2（可解释性 → 不是解释黑箱，而是让决策流经可读概念）**
直觉：事后解释（saliency / 像素级 Shapley）既不可验证也易被 Goodhart。概念瓶颈模型（CBM）换了个方向：让 z 先解码成一组**人类可命名、方向单调、可独立测量**的概念 κ（抓取余量、力零偏、同步误差、情绪唤醒度、标定可信度……），安全关键输出**只允许读 κ**。这样解释不是附加物，而是**信息通道本身**：你看得见决策用到的每一个量。再往上一层，把约束写成信号时序逻辑（STL）公式——**规格即解释**：某次减速的解释就是「力余量子公式的鲁棒度为 −0.02，是它把动作压住的」。
- 可解释性在这里承担的不是「让用户安心」，而是**可证伪性**：反事实见证 δ*（最小的概念改动让结论翻转）给出决策脆弱度；证不出脆弱点，就等于证不了「这个决定不是碰巧」。

**灵感 3（两者合流 → 用「上界」关掉 R68 的原罪）**
直觉：R68 的最大风险是缓变故障被标定吃进去。硬要把「漂移 vs 缓变故障」在任意带宽下分对，是信息论上做不到的（同一观测、同一慢尺度）。CIM-RAS 的破局不是更强的分类器，而是**换问题**：
1. 若缓变故障速度落在物理漂移先验 𝒱_phys 之内、且标定量仍在红线内 ⇒ **不必区分**：其测量误差已被 U 上界，管式 MPC 用该 U 内缩约束，**后果被锁住**；
2. 若速度越出 𝒱_phys，或外推出「撞红线时间 T_red < 预测时域」⇒ 概念漂移视界（CDH）给出**趋势级**早警，这条通道与 R68 的残差通道正交，专抓被吸收的缓变故障；
3. 两种情形下，解释证书都显式记录「我按多大的测量误差上界做了内缩」——**安全不再依赖分类正确，而依赖上界正确**。

**灵感 4（两大灵感合流 → CIM-RAS 七组件）**
1. **CB-MTM**：在 R68 的 MTM trunk 上加概念解码头，安全头只读 κ；概念带「语义契约」（量纲、方向、单调性、可测量探针）。
2. **CSD**：概念空间低维动力学 κ_{t+1} = f_κ(κ_t, a_t) + w，w ∈ W；W 由 U 与 WM 残差包络外定界，f_κ 带 Lipschitz 证书。
3. **CP-MPC**：鲁棒管式 MPC，约束在 κ 空间用 STL 写、按 W 内缩、终点落入鲁棒不变终端集 Ω。
4. **STL-Spec + CFX**：规格即解释；反事实见证给出决策脆弱度与「翻转所需最小概念改动」。
5. **ExCert**：每个控制输出必须携带三元证书（归因 A / 见证 W / 约束余量 C），**无证书不放行**（沿用 R67「实时流零学习写操作」，新增「实时流零无证决策」）。
6. **CDH + CAU**：概念漂移视界监视器（治 R68 缓变吸收）+ 概念充分性/完备性审计（治概念泄漏，保证解释忠实）。

**灵感 5（对 R68 风险的对症下药）**
- R68「缓变故障被标定吸收」→ CDH 速度通道 + 后果上界（MPC 用 U 内缩）双保险；
- R68「黑箱前瞻」→ WM 不再是独立黑箱，前瞻在 κ 空间滚动，预测路径逐步可读；
- R68「过度放宽通道」→ 保守性由 MPC 主动约束与对偶价格**解释**，而非 λ_floor 硬编码；λ 从「纪律」降级为「对偶变量」，可审计；
- R66/R67 的保守回退纪律保留为**兜底**：当 ExCert 无法生成（完备性审计失败 / 见证求解超时）时，退回 R68 的 λ_floor 与 k 收缩。

## 1. 形式化定义（增量：定义 293–309）

**定义 293（CIM-RAS 总览）** CIM-RAS = (CB-MTM, CSD, CP-MPC, STL-Spec, CFX/ExCert, CDH, CAU)，构建在 RAS-WM† 之上。四条不变式：
(i) 实时流零学习写操作（继承 R68）；
(ii) **零无证决策**：任何 τ_cmd 输出必须附带有效 ExCert，否则退化为最小安全动作（k = 0）；
(iii) **解释忠实**：安全头对 z 的残余信息 ≤ ε_c（定义 303 完备性），否则证书无效；
(iv) **后果上界优先于归因正确**：安全论证条件于测量误差上界 U，而非条件于 H_cal / H_sensor 判别正确。

**定义 294（概念瓶颈与概念集）** 在 MTM trunk 输出 z_t 上接概念头 g_κ: z_t → κ_t ∈ ℝ^K，K = 12：
κ = (抓取余量 m_g, 力零偏 b̂_F, 同步误差 Δ̂t, 情绪唤醒 a_e, 情绪效价 v_e, 面部质量 q_f, 标定可信度 u_c, 前瞻可信度 u_w, 任务进度 p, 几何冲突 c_g, 情绪风险 r_e, 故障风险 r_f)。
安全关键头（fault / risk / calibration gating）**只允许读 κ_t，禁止旁路 z_t**（结构约束，而非训练偏好）。

**定义 295（概念语义契约）** 每个概念 κ_i 携带契约 𝒮_i = (量纲, 取值域, 方向 σ_i ∈ {+1, −1}, 单调风险关系, 独立探针 P_i)。契约要求：
- **可测量性**：存在独立探针 P_i 在标注子集上重估 κ_i，一致性 ρ(P_i, κ_i) ≥ 0.8；
- **方向单调**：∂risk/∂κ_i 的符号与 σ_i 一致（干预测试，定义 303）；
- **可读上界**：κ_i 的安全阈值是区间而非点，允许操作者用自然语言复核。

**定义 296（概念空间动力学与扰集）** κ_{t+1} = f_κ(κ_t, a_t) + w_t，w_t ∈ W_t。f_κ 为低维 LPV 模型（局部线性 + 调度变量），附 Lipschitz 证书 ‖f_κ(κ, a) − f_κ(κ′, a)‖ ≤ L_κ‖κ − κ′‖（谱范数界）。扰集
W_t = W_cal(U_t) ⊕ W_wm(ε_wm) ⊕ W_model(L_κ, e_lin)，
其中 W_cal 由标定协方差 Σ_c 经灵敏度 J_c = ∂κ/∂c 线性传播，W_wm 由 WM 残差包络给出，W_model 含线性化误差。**这是 R68 的 U 第一次有了正确去处：从阈值旋钮变成扰集半径。**

**定义 297（CP-MPC 优化）** 每步求解
min_{a_{t:t+H−1}} Σ_{j=0}^{H−1} ℓ(κ̄_{t+j}, a_{t+j}) + V_f(κ̄_{t+H})
s.t. κ̄_{j+1} = f_κ(κ̄_j, a_j), κ̄_j ∈ 𝒦_j ⊖ S_j（tube 内缩）, κ̄_{t+H} ∈ Ω（鲁棒不变终端集）, a_j ∈ 𝒜。
其中 ℓ = 任务代价 + 风险代价；𝒦_j 为 STL 约束对应的概念安全域；S_j 为鲁棒正不变管截面；Ω 满足标准终端三条件（Ω ⊂ 𝒦 ⊖ S、在终端控制器下不变、V_f 为 Lyapunov 下界）。H = 10，K = 12，求解为小规模 QP（< 0.8 ms）。

**定义 298（STL 规格即解释）** 安全规格 φ 为 κ 轨迹上的信号时序逻辑公式：
φ = □_{[0,H]}(m_g ≥ 0.15) ∧ □(b̂_F ≤ 0.04 FS) ∧ □(u_c ≥ 0.5 ⇒ r_f ≤ τ_r) ∧ ◇(p 单调增) ∧ …
鲁棒度 ρ_φ(κ) 用标准 min/max 语义，ρ ≥ 0 ⇔ 满足。**解释即绑定子公式**：ξ_t = argmin_{ψ ∈ sub(φ)} ρ_ψ(κ_{t:t+H})，即鲁棒度最负（最紧）的子公式；动作的保守性由 ξ_t 命名。

**定义 299（解释三元组 ExCert）** 每个输出附带 E_t = (A_t, W_t, C_t)：
- A_t：概念组上的可加归因（对代价/动作的 Shapley，组数 g ≤ 6 ⇒ 2^g ≤ 64 次精确求值）；
- W_t：反事实见证 δ*_t = argmin_{δ} ‖δ‖₁ s.t. π(a* | κ + δ) ≠ a* 或风险判决翻转，附证书边距 m_t；
- C_t：活跃约束集 {ξ_t} 及各自余量 {ρ_ψ}，即「为什么这么保守」。
ExCert 有效 ⇔ A 之和 ≈ 代价变化（误差 ≤ 10⁻²）∧ m_t 可复算 ∧ C_t 覆盖所有活跃约束。

**定义 300（反事实见证与决策脆弱度）** 局部决策边距 m_t = min_{‖δ‖₁ ≤ γ} [logit_{a*} − max_{a ≠ a*} logit_a](κ + δ)。脆弱度 frag_t = ‖δ*_t‖₁ / γ_max；frag 高 = 决策贴近翻转边界 = 需要更保守。**这给「不确定就收紧」一个逐决策、可度量的触发量，而不是全局一刀切。**

**定义 301（概念漂移视界 CDH，治缓变吸收）** 由 R68 COF 得 ĉ 轨迹，概念速度 v_c = dĉ/dt。物理漂移先验 𝒱_phys（热时间常数、蠕变律、老化界）。定义
- 越界统计量 CUSUM(v_c − v_max)，超阈 ⇒ H_sensor^trans 早警；
- 撞线时间 T_red = min_i (c_i^red − ĉ_i) / v_{c,i}，若 T_red < H_slow ⇒ 预警并逐级收紧。
**关键**：CDH 工作在「速度/趋势」通道，R68 归因工作在「残差/瞬时」通道；被标定吸收的缓变故障在残差通道消失，却在速度通道留下与 𝒱_phys 不符的轨迹。

**定义 302（物理可行标定轨迹，反吸收的形式化）** 残差 r 可被标定解释，当且仅当存在标定轨迹 c(·) 使得
r ≈ r_cal(c(t)) ∧ ∀s ∈ [t−T, t]: c(s) ∈ 𝒞_red ∧ ‖ċ(s)‖_∞ ≤ v_max ∧ c(t) 由 c(t−T) 可达。
若只能用一个「跳变到 c*」的点解释（所需速度 > v_max 或越红线），则拒绝标定解释、判 H_sensor^trans。这把 R68 的「点可解释」升级为「轨迹可解释」——**吸收必须在物理上说得通**。

**定义 303（概念充分性与完备性审计 CAU）** 充分性：仅用 κ 重训安全头，精度衰减 ≤ 1%（决策确实由概念决定）。完备性：I(y; z | κ) ≤ ε_c（概念之外无决策泄漏）。
- 干预测试：对每个 κ_i 施加受控扰动，验证 risk 单调方向与契约一致；
- 泄漏测试：在给定 κ 上用条件探针对 z 预测 y，AUC ≤ 0.5 + ε。
任一不过 ⇒ ExCert 失效、退回 R68 兜底纪律。**这是「解释不是装饰」的硬保证。**

**定义 304（可解释的保守性）** R68 的 λ_floor 被替换为 MPC 对偶：λ_t = 1 − σ(Σ_{ξ∈active} μ_ξ·ρ_ξ)，μ_ξ 为约束对偶价格。语义：保守性 = 活跃约束的影子价格之和；「为什么减速」= 列出 ξ 与 ρ_ξ。兜底 λ_floor 仅在 ExCert 失效时启用（定义 293-ii）。

**定义 305（CIM 安全证书）** 递归可行性证书 Γ_t = (κ_t, W_t, κ̄_{t:t+H}, Ω, feasible_flag, ρ_φ)。Valid(Γ_t) ⇔ QP 可行 ∧ κ̄_H ∈ Ω ∧ ρ_φ(κ̄) ≥ 0 ∧ W_t 是真实扰动的外定界。输出 τ_cmd 仅当 Valid(Γ_t)。

**定义 306（AIC-CIM 干扰集）** ℰ_CIM = ℰ_CALM × ℰ_concept × ℰ_explain × ℰ_mpc；ℰ_concept = {概念泄漏, 概念漂移误报, 语义契约违约}；ℰ_explain = {伪归因, 见证不可复算, Goodhart 化证书}；ℰ_mpc = {扰集外扰动, 线性化失效, QP 不可行竞态}。

**定义 307（J-CIM 证书）** J_CIM = (J_CALM, concept_hash, W_t, Γ_t, ExCert_hash, CDH_score, cim_ver)。Valid ⇔ Valid(J_CALM) ∧ Valid(Γ_t) ∧ ExCert 有效 ∧ CAU 通过 ∧ 红线未越界。

**定义 308（管线）** 离线：κ 概念标注/探针 → CB-MTM 微调 → LPV f_κ 辨识 + Lipschitz 证书 → STL 规格编译 → 管式 MPC 调参。在线：每步 CP-MPC（< 0.8 ms）→ ExCert（< 0.6 ms）→ CDH 异步 → CAU 周期审计（每 10 min）→ 全部落 AuditBuf。

**定义 309（与 R68 的接口）** CB-MTM 替换 MTM 的 head 读取路径；COF 的 (ĉ, U) 同时喂 W_cal 与 CDH；CFA 的 H_sensor 判别被定义 302 的轨迹可解释性增强；λ 由定义 304 给出，失效时兜底回退 R68。

# IP-253 CB-MTM：概念瓶颈，安全头只读 κ（结构约束）
class ConceptBottleneckMTM:
    def forward(self, obs, a_prev, ctx):
        z = self.trunk(obs, a_prev, ctx)
        kappa = self.concept_head(z)                  # κ ∈ ℝ¹²，绑定语义契约
        # 安全关键路径禁止旁路 z
        return z, kappa, {
            'fault': self.fault_head(kappa),
            'risk':  self.risk_head(kappa),
            'cal':   self.cal_head(kappa),
        }


# IP-254/255 CSD + CP-MPC：概念空间管式 MPC
class ConceptMPC:
    def __init__(self, f_kappa, stl_spec, H=10, Omega=OMEGA, L_kappa=L_K):
        self.f, self.spec, self.H, self.Omega = f_kappa, stl_spec, H, Omega

    def solve(self, kappa, U, eps_wm):
        W = compose_disturbance(U, eps_wm, self.L_kappa)    # 定义 296
        S = robust_invariant_tube(self.f, W)                # 管截面
        K = stl_safe_domain(self.spec)                      # 定义 298
        qp = build_tube_qp(self.f, kappa, W, S, K, self.Omega, H=self.H)
        a_seq, duals, feasible = solve_qp(qp)               # < 0.8 ms
        xi = active_subformula(self.spec, rollout(self.f, kappa, a_seq))
        return a_seq, duals, xi, feasible, W


# IP-256/257/258 STL + CFX + ExCert：无证书不放行
class ExplanationCertificate:
    def emit(self, model, kappa, a_star, a_seq, duals, xi, gamma=0.15):
        A = exact_shapley(model, kappa, groups=6)           # 2^6 次精确
        delta = min_l1_counterfactual(model, kappa, a_star, radius=gamma)
        m = decision_margin(model, kappa, a_star)
        C = [(psi, robustness(self.spec, psi, kappa)) for psi in xi]
        ok = verify_additivity(A) and m > 0 and covers_active(C)
        return ExCert(A=A, W=delta, margin=m, C=C, valid=ok)


# IP-259 CDH：概念漂移视界（治 R68 缓变吸收）
class ConceptDriftHorizon:
    def update(self, c_hat, c_red, v_phys):
        v = finite_diff(c_hat)
        alarm_speed = cusum(v - v_phys.v_max) > H_CUSUM      # 速度通道
        T_red = min((c_red - c_hat) / np.maximum(v, 1e-6))
        alarm_horizon = T_red < H_SLOW                       # 撞线视界
        return (alarm_speed or alarm_horizon), T_red

    a_seq, duals, xi, feas, W = M.mpc.solve(kappa, U, M.eps_wm)   # 2) 管式 MPC
    if not feas:                                                  # 3) 不可行→兜底
        return safe_fallback(M, kappa)                            #    k=0 / λ_floor

    cert = M.excert.emit(M.cb_mtm, kappa, a_seq[0], a_seq, duals, xi)  # 4) 证书
    if not cert.valid:                                            # 5) 无证→兜底
        return safe_fallback(M, kappa)

    # 6) 保守性 = 活跃约束对偶价格（可解释，替代 λ_floor）
    lam = 1 - sigmoid(sum(mu * rho for mu, (_, rho) in zip(duals, cert.C)))

    cdh_alarm, T_red = M.cdh.update(c, M.c_red, M.v_phys)         # 7) 缓变早警
    if cdh_alarm:
        a_seq = tighten_prefix(a_seq, T_red)

    tau = M.pi_sigma.prefix_dispatch(a_seq[:M.k]) * lam           # 8) 下发
    M.audit.submit(z, kappa, cert, {'W': W, 'cdh': T_red, 'feas': feas})
    return tau, lam, cert, cdh_alarm
```

## 3. 推导（假设 A95–A100）

A95：W_t 是真实扰动的外定界（W_cal 由 U 正确传播、W_wm 覆盖 WM 残差、W_model 覆盖线性化误差）；A96：CAU 通过（ε_c ≤ 0.05）；A97：STL 规格 φ 覆盖任务真实安全集；A98：f_κ 的 Lipschitz 证书成立；A99：物理漂移先验 𝒱_phys 正确；A100：QP 与证书在实时预算内可解。

**引理 16（递归可行性）** 在 A95、A98 下，若定义 297 在 t 可行，则对所有 w ∈ W_t，t+1 的移位候选解可行；进而 κ_t ∈ 𝒦_t 对所有 t 成立。
*证明要点*：标准 tube-MPC 论证——终端控制器使 Ω 鲁棒正不变，约束已按 S_j 内缩，故移位名义轨迹在任意 w ∈ W 下仍满足 κ̄_j ∈ 𝒦_j ⊖ S_j 且终点回 Ω。

**引理 17（解释忠实界）** 在 A96 下，对任意概念组 i，|A_i − φ_i| ≤ ε_c·L_risk + ε_shap，其中 φ_i 为真实决策贡献、L_risk 为风险头 Lipschitz 常数、ε_shap 为 Shapley 求值误差。
*证明要点*：完备性 I(y; z | κ) ≤ ε_c ⇒ 决策分布（在 TV 距离上）仅通过 κ 依赖 z；对一个 ε_c-接近「只依赖 κ」的函数，其可加归因误差被 ε_c·L_risk 控制。

**引理 18（缓变故障的后果有界性——直接回应 R68 原罪）** 若被标定吸收的测量误差 e_c 满足 ‖e_c‖ ≤ √(tr Σ_c) 且 W_cal 为其外定界，则在 A95、A98 下，CIM-MPC 输出轨迹的真实约束违反为 0（鲁棒不变性），**与 H_cal/H_sensor 归因是否正确无关**。
*证明要点*：概念扰动 J_c·e_c ∈ W_cal ⊆ W；管式约束内缩保证任意 w ∈ W 下真实 κ 仍在 𝒦。归因错误只影响「是否报警」，不影响「是否越界」。**这是「后果上界优先于归因正确」的形式化。**

**引理 19（CDH 检出延迟）** 对均值漂移 Δ = v_f − v_max > 0 的 CUSUM，期望检出延迟 ≈ h/Δ（h 为判决阈），虚警率随 h 指数下降；被吸收的缓变故障若 v_f > v_max，则被速度通道检出，与残差通道的带宽限制无关。
*证明要点*：CUSUM 对数似然比在漂移下的标准游走论证；关键是 CDH 的统计量是 v_c 而非残差 r，故不受 R68 速率限制器的吸收影响。

**定理 16（CIM-RAS 端到端安全与可解释性）** 在 A95–A100 下：
1. **递归安全**：κ_t ∈ 𝒦_t 对所有 t（引理 16）；
2. **零无证决策**：每个 τ_cmd 或带有效 ExCert，或退化为 k = 0 的最小安全动作；
3. **后果有界**：任何满足 ‖e_c‖ ≤ √(tr Σ_c) 的缓变吸收（无论是否被识别）不导致约束违反（引理 18）；
4. **缓变早警**：v_f > v_max 的缓变故障在 O(h/Δ) 内被 CDH 检出（引理 19）；
5. **解释忠实**：|A_i − φ_i| ≤ ε_c·L_risk + ε_shap（引理 17）。

**定理 17（零无证决策的可靠性）** ExCert 有效 ⇒ 该动作的约束满足被显式验证（活跃子公式鲁棒度 ≥ 0 且边距 m_t > 0）——证书不是「看起来安全」，而是**对本次动作的可复核证据**；若证书失效则系统行为严格退回 R68 的保守纪律，故不会比 R68 更不安全。

## 6. 本轮最大风险

**一句话**：CIM-RAS 把安全从「启发式收紧」升级为「模型内可证」，但**证明的力量完全依赖扰集 W、概念完备性 ε_c 与 STL 规格 φ 三者同时为真**；一旦真实扰动逃出 W（未建模非线性、概念泄漏造成的隐藏耦合、或规格本身漏掉真实危险），系统会带着一份「看起来无懈可击」的证书继续违规——**形式化外壳包装的错误证明，比 R68 的朴素保守更危险，因为它取消了人的怀疑。**

**次级风险与缓解**：
1. **概念泄漏/不完备**：κ 之外的决策信息使解释失效 → CAU 硬门 + 条件探针 + 不过则退回 R68 兜底；
2. **规格不完整（spec gaming）**：STL 没写到的危险等于没防 → 安全案例评审 + 独立影子监视器 + 规格版本纳入 J_CIM；
3. **证书 Goodhart 化**：优化「见证」而非「决策」→ 独立第三方见证搜索 + 对抗性 E296；
4. **MPC 不可行/超时**：大 U 下 QP 崩溃 → 可行性率监控 + 不可行即 k=0 兜底 + warm-start 缓存；
5. **线性化失效**：LPV 局部模型漂出有效域 → Lipschitz 证书 + 局部重辨识 + W_model 保守放大；
6. **实时预算**：MPC + Shapley + 反事实叠加 → K=12、组 Shapley 2⁶、解析边距、并行求值，2.3 ms 封顶。

# IP-256/257/258 ExCert：归因 + 反事实 + 约束余量
class ExplanationCertificate:
    def emit(self, model, kappa, a_star, duals, xi, gamma=0.15):
        A = exact_shapley(model, kappa, groups=6)        # 2^6 精确
        delta = min_l1_counterfactual(model, kappa, a_star, radius=gamma)
        m = decision_margin(model, kappa, a_star)
        C = [(psi, robustness(self.spec, psi, kappa)) for psi in xi]
        return ExCert(A, delta, m, C,
                      valid=verify_additivity(A) and m > 0 and covers_active(C))

# IP-259 CDH：速度通道，抓被吸收的缓变故障
def concept_drift_horizon(c_hat, c_red, v_phys):
    v = finite_diff(c_hat)
    alarm = cusum(v - v_phys.v_max) > H_CUSUM
    T_red = min((c_red - c_hat) / np.maximum(v, 1e-6))
    return alarm or (T_red < H_SLOW), T_red

# IP-262 主闭环
def CIM_RAS_round(M, obs):
    z, kappa, safety = M.cb_mtm.forward(*obs)                     # 1) 概念瓶颈
    c, U, _ = M.cof.step(safety['cal'], residuals(kappa, M.wm_res), sigma_stat(M))
    a_seq, duals, xi, feas, W = M.mpc.solve(kappa, U, M.eps_wm)   # 2) 管式 MPC
    if not feas: return safe_fallback(M, kappa)                   #    不可行即兜底
    cert = M.excert.emit(M.cb_mtm, kappa, a_seq[0], duals, xi)    # 3) 证书
    if not cert.valid: return safe_fallback(M, kappa)             #    无证即兜底
    lam = 1 - sigmoid(sum(mu*rho for mu,(_,rho) in zip(duals, cert.C)))  # 4) 对偶解释
    alarm, T_red = concept_drift_horizon(c, M.c_red, M.v_phys)    # 5) 缓变早警
    if alarm: a_seq = tighten_prefix(a_seq, T_red)
    tau = M.pi_sigma.prefix_dispatch(a_seq[:M.k]) * lam          # 6) 下发
    M.audit.submit(z, kappa, cert, {'W': W, 'cdh': T_red, 'feas': feas})
    return tau, lam, cert, alarm

def safe_fallback(M, kappa):          # 严格退回 R68：k=0 / λ_floor
    return M.pi_sigma.zero_prefix() * M.r68.lam_floor(M.cof.U), None
```

## 4. 推导（假设 A95–A100）

A95：W 是真实扰动外定界；A96：CAU 通过（ε_c ≤ 0.05）；A97：STL φ 覆盖真实安全集；A98：Lipschitz 证书成立；A99：物理漂移先验 𝒱_phys 正确；A100：QP/证书满足实时预算。

**引理 16（递归可行性）** A95、A98 下，t 可行 ⇒ t+1 移位候选解可行（∀w∈W）；故 κ_t∈𝒦_t 全时成立。标准 tube-MPC 论证：Ω 鲁棒正不变 + 约束按 S_j 内缩。

**引理 17（解释忠实界）** A96 下 `|A_i − φ_i| ≤ ε_c·L_risk + ε_shap`。完备性 ⇒ 决策仅通过 κ 依赖 z（至多 ε_c）；ε_c-接近「只依赖 κ」的函数，其可加归因误差被 ε_c·L_risk 控制。

**引理 18（缓变故障的后果有界性——回应 R68 原罪）** 若吸收误差 `‖e_c‖ ≤ √(tr Σ_c)` 且 W_cal 为其外定界，则 A95、A98 下真实约束违反 = 0，**与归因是否把缓变故障判成漂移无关**。概念扰动 `J_c e_c ∈ W_cal ⊆ W`，管式内缩保证真实 κ 仍在 𝒦；归因错误只影响「是否报警」，不影响「是否越界」。

**引理 19（CDH 检出延迟）** 对漂移 `Δ = v_f − v_max > 0`，CUSUM 期望检出延迟 ≈ h/Δ，虚警率随 h 指数降。统计量是 `v_c` 而非残差 r，故不受 R68 速率限制器吸收的影响——**速度通道与残差通道正交**。

**定理 16（端到端安全与可解释性）** A95–A100 下：
1. 递归安全：`κ_t ∈ 𝒦_t`（引理 16）；
2. 零无证决策：每个 τ_cmd 或带有效 ExCert，或退为 k=0；
3. 后果有界：`‖e_c‖ ≤ √(tr Σ_c)` 的缓变吸收（无论是否识别）不导致约束违反（引理 18）；
4. 缓变早警：`v_f > v_max` 在 O(h/Δ) 内被 CDH 检出（引理 19）；
5. 解释忠实：`|A_i − φ_i| ≤ ε_c·L_risk + ε_shap`（引理 17）。

**定理 17（零无证决策的可靠性）** ExCert 有效 ⇒ 本次动作的约束满足被显式验证（活跃子公式 ρ≥0 且 m_t>0）；证书失效 ⇒ 严格退回 R68 保守纪律，故不会比 R68 更不安全。

## 7. 本轮最大风险

**一句话**：CIM-RAS 把安全从「启发式收紧」升级为「模型内可证」，但**证明的力量完全依赖扰集 W、概念完备性 ε_c 与 STL 规格 φ 三者同时为真**；一旦真实扰动逃出 W（未建模非线性、概念泄漏造成的隐藏耦合、或规格本身漏掉真实危险），系统会带着一份「看起来无懈可击」的证书继续违规——**形式化外壳包装的错误证明，比 R68 的朴素保守更危险，因为它取消了人的怀疑。**

**次级风险与缓解**：概念泄漏/不完备（CAU 硬门 + 条件探针 + 不过退回 R68）；规格不完整 / spec gaming（安全案例评审 + 独立影子监视器 + 规格入版本链）；证书 Goodhart 化（独立第三方见证搜索 + E296 对抗测试）；MPC 不可行/超时（可行性率监控 + k=0 兜底 + warm-start）；线性化失效（Lipschitz 证书 + 局部重辨识 + W_model 保守放大）；实时预算（K=12、组 Shapley 2⁶、解析边距、并行求值，2.3 ms 封顶）。
