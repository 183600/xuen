# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「研究空白」×「差异化定位」）

> 前 54 轮一直在“加层”：鲁棒性谱、反向解释、动作剖面、云边契约……v31 已有 120 条定义、120 个 IP、161 个实验。本轮不增加新的物理能力，而是对研究纲领做一次**反身审计**：本研究真正的空白在哪里？哪些 IP 是承重的，哪些只是证书通胀？对外应如何做可证伪的差异化定位？核心矛盾：H24：证书层数与科学价值不单调——大量 IP 在强基线下相互冗余，形成“证书通胀”；H25：研究空白常被叙事化宣称而非测量，定位不可证伪，导致工作被判为“已被解决”或“不可区分”。

## 0. 直觉与动机

**灵感 1（研究空白 = 需求 × 基线低覆盖 × 我们可达，而非“别人没做”）**
直觉：很多“空白”是伪空白：没人做是因为没人需要，或因为已被别的方法隐式解决。真正的白空间是三者交集：部署需求高 `d(q)`、最强基线覆盖低 `β(q)`、我们的最小核可达 `r(q)`。缺任一维，都不是空白，而是“自嗨”“红海”或“幻想”。这把 gap 从叙事变成可测的三元组。

**灵感 2（差异化定位 = 相对最强基线的可测边际，而不是“我们的系统更完整”）**
直觉：定位不是说“我们有 120 个 IP”，而是“在预先注册的切片 q 上，我们相对最强基线 b\* 的边际 Δ(q) 的置信下界为正”。关键在**预注册切片**：先固定切分与指标，再跑实验，否则就是在 forking paths 上挑一个好看的结果。差异化必须带 falsifier——什么结果会推翻我们的定位。

**灵感 3（证书通胀与承重 IP：用消融必要性替代功能堆叠）**
直觉：v31 的 120 个 IP 里，很多在两两组合时边际收益趋零。定义 IP 的必要性 `nec(i)=v(S)-v(S\{i})`，只有在一个白空间切片上承重的 IP 才进入**最小新颖核**，其余标记为 decorative 并退役。这是对自身研究纲领的奥卡姆剃刀：**先证明非冗余，再宣称新颖**。

**灵感 4（负定位：明确不做什么，才能被清楚比较）**
直觉：一个定位若没有非目标集 `N`，就无法与任何基线区分——因为它隐含地宣称在所有维度都更好。我们明确放弃：通用基座规模、标准 benchmark 的 SOTA 成功率、神经控制器的形式化验证。负定位让审稿人知道“该在哪个切片比较我们”，也让失败有边界。

**灵感 5（把主张变成可执行的定位证明：claim → falsifier → 实验 → 置信区间）**
直觉：每条定位主张都应能被一个“定位证明助手”编译成四元组 `(claim, falsifier, experiment, CI)`；无法编译的主张直接拒绝。这把“研究空白/差异化”从写作技巧变成流水线产物。

**灵感 6（换名与换叙事：从 feature-first 到 predictability-first）**
直觉：v16+++ 的命名是“功能加加加”，对外不可区分。本轮把外显定位改为 **ComposeCert**：不是更强的操作策略，而是**部分信息下可组合、可证伪、可审计的证书运行时**。同一套内部代码，叙事从“我们有什么层”转为“我们能预测什么、能拒绝什么”。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（需求-方法-证据空间）**
`𝔾 = Q × M × E`。`Q` 为部署需求维度（接触丰富、长程恢复、跨本体、低时延、部分可观测、工具使用等）；`M` 为方法族（端到端 VLA、RL、扩散策略、TAMP、经典控制、证书方法）；`E = {E0 轶事 < E1 单任务 < E2 多任务 < E3 跨本体 < E4 对抗/部署审计}`。每个格 `g=(q,m,e)` 的覆盖度 `cov(g)∈[0,1]` 由文献先验与内部实验后验估计。

**定义 122（研究空白证书 GapCert）**
对需求 q：
- 需求强度 `d(q) ∈ [0,1]`：部署频率 × 失败代价归一化；
- 最强基线覆盖 `β(q) = max_{m≠ours} cap(m,q)`；
- 我们的可达性 `r(q) = cap(ours, q)` 在预算 B 下的估计；
- 证据等级 `e(q)`。

`GapCert(q) = (d, β, r, e)`。称 q 为**白空间**当且仅当
`d(q) ≥ d_min ∧ β(q) ≤ β_max ∧ r(q) ≥ r_min ∧ e(q) < e_target`。
称 q 为**红海**当 `β(q) ≥ β_high`；称 q 为**伪空白**当 `d(q) < d_min`。

**定义 123（差异化边际与定位证书 DiffCert）**
`Δ(q) = U_ours(q) − max_{b∈B} U_b(q)`，`U` 为切片效用（成功率、负迁移率、证书可靠性等的加权）。定位证书
`DiffCert(q) = (slice_id, Δ, CI_{1−α}, effect_size, falsifier, prereg_hash)`。
主张可采纳当且仅当 `CI_low(Δ) > δ_min ∧ effect_size ≥ d_min`，且切片在实验前已注册（`prereg_hash` 一致）。切片搜索预算 `K_slice` 固定并计入多重比较校正。

**定义 124（IP 必要性与承重性）**
对 IP 集合 S，效用 `v(S) = Σ_{q∈Q_white} w(q)·min(Δ_S(q), δ_max)`。IP i 的留一必要性
`nec(i) = v(S) − v(S\{i})`，Shapley 值 `φ_i`。称 i **承重**当 `∃ q, nec_q(i) ≥ ν_min`；否则称 **装饰性（decorative）**。

**定义 125（最小新颖核）**
`K* = argmin_{K⊆S} |K| s.t. ∀q∈Q_white: Δ_K(q) ≥ δ_min ∧ Sound(K,q) ≥ s_min`。`K*` 是“最小可发表主张集”；不在 `K*` 中的 IP 默认退役或降级为工程实现细节。

**定义 126（非目标集与负定位）**
`N = {n_k}`，每个 `n_k = (claim, boundary_test)`。定位 `P` well-formed 当 `P.claims ∩ N = ∅` 且 `N` 中每条边界可测。负定位不是免责声明，而是**可比较性的前提**。

**定义 127（证书感知基准 CAB）**
任务族 `D_CAB = {(q, shift, depth)}`，指标：
- `DP-AUROC`：证书“可部署”预测实际成功的 AUROC；
- `Comp-Soundness = P(fail | cert=deployable)`；
- `NTR = P(Δ<0 | composition accepted)`（负迁移率）；
- `CertCost = (latency, bytes)/composition`；
- `ZST`：零重训跨本体迁移成功率。

CAB 的设计目标是让我们的主张可被证伪，而不是让我们赢。

**定义 128（定位稳健性）**
盲评一致度 `κ_claim`：独立评审对“该切片上是否存在差异化”的判断与 `DiffCert` 的一致度。定位稳健当 `κ_claim ≥ κ_min` 且 `CI_low(Δ) > δ_min` 在留出切片的复现实验中仍成立。

## 2. 关键算法伪代码

### IP-121 GSM（Gap Space Mapping）

```python
def build_gap_map(Q, M, literature, internal_logs, prior):
    cov = {}
    for q in Q:
        for m in M:
            cov[(q, m)] = posterior_coverage(q, m, literature, internal_logs, prior)
    gaps = {}
    for q in Q:
        d = demand(q)
        beta = max(cov[(q, m)] for m in M if m != 'ours')
        r = reachability(q, budget=B)
        e = evidence_level(q)
        gaps[q] = GapCert(
            d, beta, r, e,
            white=(d >= D_MIN and beta <= BETA_MAX
                   and r >= R_MIN and e < E_TARGET))
    return gaps
```

### IP-122 DAN（Differentiation Audit）

```python
def differentiation_audit(claims, baselines, slices, alpha=0.05):
    assert preregistered(slices)                       # 切片必须先注册
    results = []
    for q in slices:
        u_ours = evaluate(ours, q)
        u_base = {b: evaluate(b, q) for b in baselines}
        delta = u_ours - max(u_base.values())
        lo, hi = bootstrap_ci(delta, n=10000, alpha=alpha)
        results.append(DiffCert(q, delta, (lo, hi),
                                effect_size(delta), falsifier(q)))
    return holm_bonferroni(results, m=len(slices))     # 控制 FWER
```

### IP-123 NKC（Necessity & Kernel Compression）

```python
def compress_kernel(IPs, white_Qs, v, delta_min, s_min):
    phi = monte_carlo_shapley(v, IPs, n_perm=2000)
    nec = {i: leave_one_out(v, IPs, i) for i in IPs}
    load_bearing = {i for i in IPs
                    if any(nec_q(i) >= NU_MIN for q in white_Qs)}
    K = greedy_min_size(load_bearing, white_Qs, delta_min, s_min)
    retired = set(IPs) - K
    return K, retired, nec, phi
```

### IP-124 NFG（Negative Frontier Guard）

```python
def validate_position(claims, non_goals):
    for c in claims:
        if overlaps(c, non_goals):       # 主张侵入非目标集 → 拒绝
            return reject(c, 'negative_frontier')
        if not has_falsifier(c):         # 无可证伪器 → 拒绝
            return reject(c, 'unfalsifiable')
        if not preregistered(c.slice):   # 事后切片 → 拒绝
            return reject(c, 'post_hoc_slice')
    return accept(claims)
```

### IP-125 CABA（Certificate-Aware Benchmark & Audit）

```python
def cab_audit(policy, cert, tasks):
    rows = []
    for q, shift, depth in tasks:
        plan, c = policy.compose(q, cert)
        ok = cert.says_deployable(c)
        real = deploy(plan, shift, depth).success
        rows.append((q, ok, real, c.cost, delta_vs_baseline(plan, q)))
    return {
        'DP_AUROC': auroc([r.ok for r in rows], [r.real for r in rows]),
        'Comp_Soundness': p_fail_given_ok(rows),
        'NTR': neg_transfer_rate(rows),
        'CertCost': pareto(rows, x='cost', y='delta'),
    }
```

### IP-126 PPL（Positioning Proof Linter）

```python
def compile_claim(claim):
    return Claim(
        text=claim.text,
        slice=claim.slice_id,
        falsifier=claim.falsifier,
        experiment=claim.experiment_id,
        ci=claim.ci,
        prereg=claim.prereg_hash)
# 编译失败的主张不允许进入论文/答辩材料
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| GSM | O(|Q|·|M|) | O(|Q|·|M|) | 覆盖后验校准、文献去重 |
| DAN | O(|B|·|Q_slice|·N_eval) | O(|Q_slice|) | 预注册、多重比较校正 |
| NKC | Shapley 采样 O(n_perm·|S|·|Q|·N_eval) + 贪心 | O(|S|) | 效用单调次模、贪心近似保证 |
| NFG | O(|claims|·|N|) | O(|N|) | 边界可测、falsifier 完备 |
| CABA | O(|D_CAB|·cost(deploy)) | O(|D_CAB|) | 留出切片、盲评 |
| PPL | O(|claims|) | O(1) | 编译即拒绝不可证伪主张 |

**定理（最小核近似与定位误报控制）**
假设 (A29) `v` 在 IP 集合上单调次模；**(A30)** 覆盖后验校准（reliability diagram `ECE ≤ ε_cal`）；**(A31)** 切片预注册且效应量用 Holm–Bonferroni 校正。
则：
1. 贪心最小核满足 `v(K_greedy) ≥ (1−1/e)·max_{|K|≤k} v(K)`，其最小覆盖版本有 `ln|Q_white|` 近似；
2. 在白空间上报告 `CI_low(Δ)>δ_min` 的定位主张族，其 FWER ≤ α；
3. 若 `κ_claim ≥ κ_min`，则定位主张在留出切片上复现失败的概率 ≤ α + (1−κ_min)。

**推论（证书通胀判据）**
若某 IP 在所有白空间切片上 `nec_q(i) < ν_min`，则它不进入 `K*`；继续保留它只增加 `CertCost`，不增加可测差异。故“更多证书”不是新颖性，**非冗余**才是。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 空白图自证（用我们的证据证明我们空白） | 高 | 外部文献先验 + 专家盲评 + 留出切片 |
| 最小核退化为“显然基线” | 高 | 强基线复现 + 负迁移切片 + 盲评 κ |
| 预注册切片仍被隐性调参 | 高 | 代码级 prereg hash + 时间戳 + 第三方复跑 |
| CAB 被我们自己的指标过拟合 | 中 | 隐藏测试切片 + 多中心评测 |
| 负定位过窄，失去贡献 | 中 | 每轮复核非目标集边界 |
| 审稿人不接受“预测性”而非“性能性”贡献 | 中 | 同时报告纠错价值（拒绝错误组合的收益） |

## 6. 本轮最大风险

**一句话**：本轮把“加层”改为“证明非冗余 + 可证伪定位”，方向正确，但最大风险是 **白空间与差异化边际可能只是我们自建 gap map 与 CAB 的自证幻觉**——若覆盖估计、切片选择和基线复现都来自同一研究闭环，那么最小核会坍缩成“显然基线”，ComposeCert 也就只是换了叙事的 v31；必须以 **外部预注册、第三方基线复跑、盲评 κ 与留出切片** 四重外部性护栏，宁可承认“没有空白”，也不把自我评估的镜像当作差异化。

# 第 55 轮产物 · 定位清单 v32：ComposeCert（GSM×DAN×NKC×NFG×CABA×PPL）

> 承接第 54 轮 v31。本轮不是再叠一层能力，而是对 v31 的 120 个 IP 做**反身审计**：哪些是承重的、空白在哪里、对外如何做可证伪的差异化定位。产物核心是一个**最小新颖核** + **一套证书感知基准** + **一页对外定位**。IP 编号 IP-121~IP-126（新增 6 个）。

## 0. 对外定位（一页版）

**一句话**：ComposeCert 不是更强的操作策略，而是让不同来源的技能在**部分信息**下可组合、可证伪、可审计的证书运行时。

**我们主张**（每条均带 falsifier）：

| # | 主张 | Falsifier（什么结果会推翻） |
|---|---|---|
| C1 | 接触丰富与长程恢复两类白空间切片上，证书组合相对最强基线的部署成功率边际 ≥ 8% | 留出切片上 `CI_low(Δ) ≤ 0` |
| C2 | 证书携带的“可部署”判断能预测真实部署（`DP-AUROC ≥ 0.85`） | `DP-AUROC ≤ 0.70` |
| C3 | 最小核（≤15 个 IP）与 120 IP 全套的差异化等价 | 留一消融显示第 16 个 IP 仍承重，或 Δ 差 > 2% |
| C4 | 跨本体零重训迁移在 E3 证据等级下可行 | `ZST` 相对最强基线无显著提升 |

**我们明确不做**（负定位 `N`）：

- 不追求标准 manipulation benchmark 的 SOTA 成功率；
- 不宣称通用基座模型能力；
- 不宣称神经控制器的形式化验证，只提供经验证书 + 可执行 falsifier；
- 不宣称未指定硬件下的硬实时保证。

**与最强基线的关系**：VLA/扩散策略强在单技能泛化但缺组合可审计性；TAMP 强在符号组合但缺接触/鲁棒性证书；RL 强在单任务但无跨本体契约。ComposeCert 只占“部分信息下的可组合可审计”这一格。

## 4. 最小新颖核（假设性审计结果，待 E163 验证）

对齐 v31 的 120 个 IP，首轮离线留一 / Shapley **假设**如下（**非实测，仅用于设计实验，不得作为结论引用**）：

| 类别 | 假设数量 | 代表 IP | 处置 |
|---|---|---|---|
| 承重 | ~11 | ρ 谱、Explain、`A_cert`、SCOM 兼容性、CEC 闭环、AEC、JTC、TRO、REX、`PSM_cert`、`γ_ce` | 进入 `K*` |
| 边缘 | ~23 | 细粒度分层证书、部分金字塔层 | 降级为实现细节 |
| 装饰 | ~86 | 重复定义、可被基线隐式覆盖的层 | 退役 / 合并 |

**判据**：若某 IP 在所有白空间切片上 `nec_q(i) < ν_min`，则不进入 `K*`。E163 的目标是把 120 压缩到 ≤ 15，且 `K*` 与全套在 4 个预注册切片上的 `Δ` 差 ≤ 2%。

**风险提示**：上表的数量是待验假设，不是结果。若实测承重集与假设偏差 > 30%，说明我们对自身框架的直觉不可靠，需重做 GapMap 而非调参。

## 5. 关键算法伪代码

### IP-121 GSM

```python
def build_gap_map(Q, M, literature, internal_logs, prior):
    cov = {(q, m): posterior_coverage(q, m, literature, internal_logs, prior)
           for q in Q for m in M}
    gaps = {}
    for q in Q:
        d, e = demand(q), evidence_level(q)
        beta = max(cov[(q, m)] for m in M if m != 'ours')
        r = reachability(q, budget=B)
        gaps[q] = GapCert(d, beta, r, e,
                          white=(d >= D_MIN and beta <= BETA_MAX
                                 and r >= R_MIN and e < E_TARGET))
    return gaps
```

### IP-122 DAN + IP-123 NKC

```python
def differentiation_audit(claims, baselines, slices, alpha=0.05):
    assert preregistered(slices)
    out = []
    for q in slices:
        delta = evaluate(ours, q) - max(evaluate(b, q) for b in baselines)
        lo, hi = bootstrap_ci(delta, n=10000, alpha=alpha)
        out.append(DiffCert(q, delta, (lo, hi),
                            effect_size(delta), falsifier(q)))
    return holm_bonferroni(out, m=len(slices))

def compress_kernel(IPs, white_Qs, v, delta_min, s_min):
    phi = monte_carlo_shapley(v, IPs, n_perm=2000)
    nec = {i: leave_one_out(v, IPs, i) for i in IPs}
    load_bearing = {i for i in IPs
                    if any(nec_q(i) >= NU_MIN for q in white_Qs)}
    K = greedy_min_size(load_bearing, white_Qs, delta_min, s_min)
    return K, set(IPs) - K, nec, phi
```

def compile_claim(claim):

### IP-125 CABA

```python
def cab_audit(policy, cert, tasks):
    rows = []
    for q, shift, depth in tasks:
        plan, c = policy.compose(q, cert)
        ok = cert.says_deployable(c)
        real = deploy(plan, shift, depth).success
        rows.append((q, ok, real, c.cost, delta_vs_baseline(plan, q)))
    return {
        'DP_AUROC': auroc([r.ok for r in rows], [r.real for r in rows]),
        'Comp_Soundness': p_fail_given_ok(rows),
        'NTR': neg_transfer_rate(rows),
        'CertCost': pareto(rows, x='cost', y='delta'),
    }
```

## 6. CAB 基准与评测协议

**任务族**（每个任务带 `(q, shift, depth)`）：

1. 接触丰富装配（间隙、摩擦、柔顺要求漂移）；
2. 长程失败恢复（插入失败 → 重抓 → 重规划）；
3. 跨本体工具使用（夹爪/灵巧手/吸附，零重训）；
4. 部分可观测抓取（遮挡、未知负载）。

**指标与验收线**：

| 指标 | 定义 | 验收线 |
|---|---|---|
| DP-AUROC | 证书可部署判断 → 实际成功的排序能力 | ≥ 0.85 |
| Comp-Soundness | `P(fail | cert=deployable)` | ≤ 5% |
| NTR | `P(Δ<0 | composition accepted)` | ≤ 5% |
| CertCost | 每次组合的时延 / 字节开销 | P95 ≤ 50ms |
| ZST | 零重训跨本体迁移成功率 | 相对基线显著提升 |

**评测协议**（外部性四件套）：外部预注册（时间戳 + hash）→ 第三方基线复跑 → 盲评 `κ_claim` → 留出切片复现。四者缺一，定位降级为“假设”。

## 7. 实验 E162–E168 与预期结果

> 下表“预期”列为设计目标，不是实测结论；E163 的核大小尤其可能显著偏离。

| 实验 | 指标 | 预期（目标） | 反证条件 |
|---|---|---|---|
| E162 空白图校准 | 与专家盲评 κ / Spearman | κ ≈ 0.68 | κ < 0.5 → GapMap 不可信 |
| E163 承重性消融 | 承重 IP 数 / Shapley 集中度 | 11 / 120（假设） | > 30 或 Δ 差 > 2% |
| E164 差异化边际 | 4 切片 Δ（95% CI, Holm） | 接触 12.4% [8.1,16.7]；长程 9.8% [6.2,13.4] | 任一 `CI_low ≤ 0` |
| E165 CAB 预测力 | DP-AUROC / Soundness / NTR | 0.87 / 4.1% / 3.6% | AUROC ≤ 0.70 |
| E166 成本-收益 | CertCost P95 vs Δ | 38ms @ Δ 10.2% | P95 > 50ms 且 Δ < 8% |
| E167 定位盲评 | κ_claim / 留出复现率 | 0.64 / 84% | κ < 0.5 或复现 < 70% |
| E168 合规审计 | 事后切片 / p-hacking 痕迹 | 0 / 无 | 出现任一事后切片即作废 |

**预期结论（若全部通过）**：v31 的 120 IP 中约 11 个承重；ComposeCert 的差异化集中在“接触丰富组合 / 长程恢复”两格；证书成本可压到 50ms 内；定位在盲评下可复现。

**预期结论（若 E162/E164 失败）**：应诚实收缩为“v31 是工程集成而非科学差异化”，并把论文定位改为系统/基准贡献，而不是方法贡献。

## 8. 体系更新：v31 → v32

```
v32 ComposeCert = v31 承重核 K* + 定位/审计层
│
├─ 研究审计层 (GSM, DAN, NKC, NFG, PPL)        ← 本轮
├─ 证据层 (CABA, prereg, 第三方复跑, 盲评)     ← 本轮
└─ 能力层 (v31 承重核：ρ, Explain, A_cert,
           SCOM, CEC, AEC, JTC, TRO, REX, PSM_cert, γ_ce)
```

**JCPS 输出扩展**：
`(..., ρ, Explain, A_cert, γ_ce, δ_a, GapCert, DiffCert, K_star, κ_claim, CertCost)`

其中新增：
- `GapCert`：该技能/组合所服务需求的白空间证据；
- `DiffCert`：相对最强基线的边际与置信区间；
- `K_star`：当前最小新颖核；
- `κ_claim`：定位的盲评稳健性；
- `CertCost`：证书运行时开销。

**叙事变化**：从“我们有 L0–L6 + 120 IP 的完整体系”改为“我们能在部分信息下预测哪些技能组合可部署、并给出可证伪的拒绝理由”。前者不可比较，后者可被单一实验杀死。

## 9. 本轮最大风险

**一句话**：本轮把“加层”改为“证明非冗余 + 可证伪定位”，方向正确，但最大风险是 **白空间与差异化边际可能只是我们自建 gap map 与 CAB 的自证幻觉**——若覆盖估计、切片选择和基线复现都来自同一研究闭环，那么最小核会坍缩成“显然基线”，ComposeCert 也就只是换了叙事的 v31；必须以 **外部预注册、第三方基线复跑、盲评 κ 与留出切片** 四重外部性护栏，宁可承认“没有空白”，也不把自我评估的镜像当作差异化。
