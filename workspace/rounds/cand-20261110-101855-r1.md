# 第 43 轮（新循环第 3 轮） · UX-as-Certificate：把「体感」编译进安全证书，用「证书投影运动控制」兑现既安全又好用（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR）。第 42 轮把证书做成「仿真验证 → 知识沉淀 → 边缘低成本 → 持续进化」的飞轮，但其验收标准仍是一个粗糙代理——**Nominal 占比**。系统可能一直「安全地」运行在 Nominal，却让人感到突兀、难以预测、不敢托付；这种「安全但难用」的失败不会触发任何安全告警，却会以接管率、弃用率、信任崩塌的形式慢性死亡。本轮灵感词「用户体验」「运动控制」正好补上这条被忽视的失效链：**运动控制是证书翻译成「身体语言」的最后一公里，用户体验是证书飞轮的真正验收面**。为此提出 **UX-as-Certificate（体验即证书）**：把体验拆成与安全同构、可测量、可证伪的证书维度，并把控制器重写为**证书投影 + 可读性塑造 + 平滑降权**三段式——安全裕度不再只能靠「停车」兑现，而能靠「更优雅地运动」兑现。

## 0. 直觉与动机

**灵感 1（用户体验 → 把「感受」变成可证伪的体验证书）**：第 42 轮把可用性简化为「不滞留 Degraded/SafeStop」。但用户体验的经验事实是：**峰值决定记忆**（peak-end rule）——一次突兀的急刹、一次意图不明的变向，就足以摧毁整段交互积累的信任。因此体验不能被平均指标掩盖，必须同时约束**峰值**（L∞）与**累积**（L2）。直觉上把体验拆成五条可测轴：平滑（jerk）、舒适（加速度/加加速度峰值）、可读（人类多快看懂意图）、响应（从指令到可见动作的时延）、体面降级（模式切换是否连续可解释）。其中前两条是**体验硬底线**（溢出、晕动、机械冲击，不可协商），后三条更多是**软偏好**（果断/保守、快/稳，因人而异）。硬底线可以做成证书，软偏好只能做 Pareto；二者混为一谈是上一代「舒适性调参」失败的根本原因。

**灵感 2（运动控制 → 证书投影、可读性塑造、预认证基元库）**：安全屏障（CBF）通常用**最小范数修正**把控制拉回安全集，代价是修正方向与时机都很突兀，jerk 爆炸——等于用最难看的方式消费安全裕度。运动控制的直觉是把它改成**带 jerk 正则的证书投影**：在安全约束内尽量贴近「体验最优名义控制」，并显式区分**可花费裕度 σ** 与**不可动用的鲁棒储备**。更进一步：大量运动本可**离线预认证**为「运动基元」（同伦类的抓取接近、绕行、对齐、交接），每个基元携带安全管 + 体验证书；运行时只做「选基元 + 定点平滑混合」，比在线解 QP 便宜得多，天然贴合第 42 轮的边缘低成本路线。最后，运动本身承载意图：**可读性塑造**（早承诺、适度夸张、速度剖面编码意图）让人类更快看懂机器人要做什么，从源头减少误解型接管。

**灵感 3（体验 × 运动控制 → 人机闭环的体验飞轮与信任校准）**：体验不是静态参数，而是**在线被校准**的。人的评分、接管、干预都是传感器：接管是「体验边界」的天然标注，评分是偏好梯度的噪声观测。但偏好学习若自由漂移，会悄悄把安全裕度吃光——所以必须约束在**安全偏好域 W_safe** 内（任何 w∈W_safe 都不动用鲁棒储备）。同时，第 42 轮的 RAG 解释存在幻觉风险；本轮的解法是**证书接地解释**：每一句「为什么降级」都必须引用真实的 margin / θ / 原因码字段，禁止自由生成。这样体验飞轮既收集人的反馈，又反过来压制上一轮的检索幻觉失效链。

**耦合升级**：证书从「安全 × 成本」二维升级为「安全 × 成本 × 体验」三维。运动控制是体验的执行器，人是体验的传感器，仿真（IP-54）额外承担「人体舒适模型/可读性回放」的验证。四层架构由 v7 的「证书飞轮」升级为 v8 的「可感知、可解释、可协商的证书飞轮」。

## 1. 形式化定义（增量：定义 38–44）

**定义 38（体验证书 EXP-CERT）**：对运动片段 ξ=(x(t),u(t))、终端位置 p(t)，定义五元体验量 E(ξ) = (J₃, A∞, Leg, R, G)。其中 J₃=∫‖p⁽³⁾(t)‖²dt 为累积 jerk，A∞=max_t‖a(t)‖ 为峰值加速度，Leg 为可读性（定义 41），R 为指令到可见运动的时延，G 为模式切换处的峰值 jerk。给定体验档案 w=(w_s,w_c,w_l,w_r,w_e) 与硬底线 (J_max,A_max,G_max,R_max)，称 ξ 满足 **EXP-CERT(ξ;w)** 当且仅当
- 硬底线：J₃≤J_max ∧ A∞≤A_max ∧ G≤G_max ∧ R≤R_max；
- 软偏好：U_w(ξ)=w_s·S(J₃)+w_c·C(A∞)+w_l·Leg−w_r·R−w_e·Energy ≥ U_min(w)。
   硬底线是证书（不可越），U_w 是排序（可协商）。**命题**：EXP-CERT 对轨迹拼接不封闭，但对同伦类内的凸混合封闭（jerk 与加速度峰值的凸性）。

**定义 39（安全裕度预算与体验-安全联合可接受集）**：设 L0/L1 查表给出边际下界 m(x) 与守卫阈值 θ。定义**可花费裕度** σ(x)=m(x)−θ−ρ_reserve，其中 ρ_reserve 为抵御最坏扰动与模型误差的**不可动用鲁棒储备**（由 W_1 迁移界与 B_t 定出）。联合可接受集
A_joint(w) = {ξ : m_min(ξ) ≥ θ+ρ_reserve（安全） ∧ EXP-CERT(ξ;w)}。
体验优化的本质是**在 σ(x) 的预算内购买平滑与果断**；σ<0 时必须冻结体验优化并转入降权。定义体验-安全 **Pareto 前沿** P={ (m_min, U_w) 非支配 }，向操作者暴露「果断度旋钮」ρ∈[0,1]，θ_eff(ρ)=θ+ρ·ρ_reserve，但**任何 ρ 都不得使 σ<0**。

**定义 40（证书投影控制器 CPC）**：给定体验最优名义控制 u_nom 与上一拍控制 u_prev，求解
u\* = argmin_u ‖u−u_nom‖²_W + λ_j‖u−u_prev‖²
 s.t. L_f h + L_g h·u + α h ≥ 0（CBF 安全约束），‖u‖≤u_max，
其中 h(x)=m(x)−θ−ρ_reserve 为可花费裕度。称 **感知失真** D(ξ)=∫‖u\*−u_nom‖²dt。**命题（失真-裕度界）**：若名义轨迹与安全集边界距离为 d，则 D ≤ κ·d²；且投影引入的附加 jerk 满足 ΔJ ≤ c·∫‖u\*−u_nom‖²dt。即「越贴近边界，越难保持体面」——这正是必须保留 ρ_reserve 的原因。

**定义 41（可读性证书 Leg-CERT 与意图披露时间）**：给定人类目标假设集 G 与人类运动模型 p(ξ_{0:t}|g)，可读性
Leg(ξ_{0:t}) = log [ p(ξ_{0:t}|g\*) / Σ_{g'≠g\*} p(ξ_{0:t}|g') ]。
**意图披露时间** T_leg = min{ t : P(g\*|ξ_{0:t}) ≥ 1−δ }。要求 Leg-CERT：在关键决策点 Leg≥ℓ_min，且 T_leg≤T_max。可读性不是装饰，而是**误解型接管的因果上游**；它通过速度剖面、早承诺与同伦类选择塑造，且必须服从 A_joint。

**定义 42（平滑降权与舒适停车 Graded Authority）**：把 CAR 的离散模式换成连续权柄 β∈[0,1]（1=全自主，0=安全停）。参考调节器在 jerk/加加速度受限下驱动 β→β_cmd：|β̇|≤ρ_β，|β̈|≤ρ̈_β。**舒适停车时间** T_stop 为满足 a≤a_comfort、jerk≤J_max 的最短制动时长，显著长于急停但体感可接受。**命题（降级体面性）**：若安全包络要求 β≤β_safe(t)，则调节器以有界滞后 δτ 跟踪，且 δτ 内由 ρ_reserve 吸收；只要 σ≥0，降级全程保持 EXP-CERT 的 G≤G_max。

**定义 43（安全偏好自适应 Safe Preference Adaptation）**：偏好 w 从反馈中学习，但约束在**安全偏好域**
W_safe = { w : ∀ξ∈A_joint(w), σ(ξ)≥0 }。
更新规则 w_{t+1}=Proj_{W_safe}(w_t+η·ĝ_t)，ĝ_t 为偏好梯度估计。**命题**：若 w_t∈W_safe，则对任意后续更新 w_{t+1}∈W_safe，A_joint 非空且鲁棒储备不被动用；体验可随偏好变化，但**安全性质对 w 一致成立**。

**定义 44（体验感知总成本与验收 U-COT）**：U-COT = COT + C_feedback·N_query + C_intervention·N_int + C_explain·N_exp。其中干预成本既是被优化的体验负债，也是飞轮的标注来源。验收不只比成本，还在 (COT, 安全违例率, 体感评分, 接管率) 四维上给 Pareto。

## 2. 四大产出设计（增量 IP-57/58/59/60 + 升级 IP-39/43/45/48/50/51/52/53/54/55）

### 2.1 IP-57 UX-CERT-ENGINE（体验证书引擎 UCE）
1. **五轴测量**：从状态-控制流直接算 J₃、A∞、G；可读性用贝叶斯人类模型在线估 Leg 与 T_leg；时延 R 由总线时间戳端到端测得。
2. **双层判定**：硬底线（峰值+累积）作为证书；软偏好 U_w 作为 Pareto 排序。硬底线同时约束**平均**与**峰值**，防止「均值漂亮、单点毁信任」。
3. **裕度预算核算**：实时输出 σ(x)=m−θ−ρ_reserve，作为 CPC 与规划的共同预算信号；σ<0 立即冻结体验优化。
4. **体验档案**：w 可版本化、按用户/场景检索（入 CKB），但任何 w 必须通过 W_safe 校验。

### 2.2 IP-58 CERTIFIED-PROJECTION-CONTROLLER（证书投影运动控制器 CPC）
1. **Jerk 正则投影 QP**：在 CBF 约束内最小化「偏离名义 + 控制变化率」，用上一拍热启动；只在基元库无法覆盖或 σ 骤降时在线求解。
2. **裕度预算闸门**：σ<0 时关闭体验项（λ_j→0、冻结名义更新），转入权柄降级；σ≥0 才允许「花裕度买平滑」。
3. **权柄调节器**：用 jerk/加加速度受限的参考调节器驱动连续 β，取代离散跳变；急停只在 σ<0 且不可恢复时触发。
4. **可行性兜底**：QP 不可行 → 舒适停车基元 + 证书接地解释，绝不输出未认证控制。

### 2.3 IP-59 CERTIFIED-MOTION-PRIMITIVE-LIBRARY（证书化运动基元库 CMP-LIB）
1. **同伦类组织**：抓取接近、绕行、对齐、交接、避让等按同伦类索引；每类预存安全管与体验证书（J₃、A∞、Leg、T_leg）。
2. **质量多样性预计算**：离线用 IP-54 仿真 + 人体模型回放，生成「快/稳/可读」多档基元，填满 Pareto 前沿；运行时只查表。
3. **选基元 + 定点平滑混合**：按 U_w 与剩余裕度选基元，用 smoothstep 在认证凸包内混合当前基元与安全停基元，避免切换 jerk 尖峰。
4. **可读性塑造**：在安全与体验约束内选择早承诺的同伦类与速度剖面，最小化 T_leg。

### 2.4 IP-60 UX-FLYWHEEL（体验飞轮与信任校准）
1. **反馈即传感器**：评分、接管、干预三类信号；干预样本标注为「体验边界」或「不适」入 CKB。
2. **安全偏好自适应**：在 W_safe 内做受约束贝叶斯优化/投影梯度，收敛后冻结版本；越界即回退群体保守档案。
3. **证书接地解释**：解释模板只允许填充真实证书字段（margin、θ、T_hold、原因码），并做「条款-字段」一致性校验，禁止自由生成，直接压制第 42 轮 RAG 幻觉。
4. **信任校准**：把系统自报置信度与实测裕度对齐，输出 ECE 指标；高置信低裕度即报警。

## 5. 本轮最大风险

**一句话**：本轮把「体感」转成可消费的安全裕度——若可读性的人体模型失配或偏好自适应把 σ 侵蚀到临界，系统会以「更顺滑、更自信」的假象逼近不可恢复的边界；因此「σ≥0 且 ρ_reserve 绝不被动用」必须作为立项红线，E88（投影期间安全违例）与 E92（偏好越界）任一不达标即冻结体验优化、回退固定保守裕度。

## 2. 关键算法（伪代码）

### IP-57 UCE：体验证书与裕度预算
```
def experience_certificate(xi, profile_w, cert):
    J3 = integrate(norm(third_derivative(xi.p))**2, xi.t)
    Ainf = max(norm(second_derivative(xi.p)), over=xi.t)
    G = max_switch_jerk(xi)                      # 模式/基元切换处峰值
    Leg, T_leg = bayes_legibility(xi, goal_set, human_model)
    R = end_to_end_latency(xi)
    hard_ok = (J3 <= J_max) and (Ainf <= A_max) and (G <= G_max) and (R <= R_max)
    U = (w.s*S(J3) + w.c*C(Ainf) + w.l*Leg
         - w.r*R - w.e*energy(xi))
    sigma = cert.margin(xi.x) - cert.theta - cert.rho_reserve
    return ExpCert(ok=hard_ok and U >= U_min[w], J3=J3, Ainf=Ainf,
                   Leg=Leg, T_leg=T_leg, G=G, U=U, sigma=sigma)

def spendable_margin(cert):
    sigma = cert.margin - cert.theta - cert.rho_reserve
    return max(0.0, sigma)   # 只允许花 >=0 的部分；<0 触发冻结
```

### IP-58 CPC：证书投影与平滑降权
```
def certified_projection_control(x, u_nom, u_prev, cert, dt):
    h = cert.margin(x) - cert.theta - cert.rho_reserve
    sigma = h
    if sigma < 0:                        # 预算越界：冻结体验优化
        return authority_governor(x, beta_cmd=0.0, comfort=True)
    # jerk 正则 + CBF 安全约束，热启动上拍解
    u_star = solve_qp(
        cost = ||u - u_nom||_W^2 + lam_j*||u - u_prev||^2,
        cons = [ Lf_h + Lg_h @ u + alpha*h >= 0,
                 norm(u) <= u_max ],
        warm_start = u_prev)
    if not feasible(u_star):             # 不可行兜底：舒适停车
        return comfort_stop_primitive(x), explain('qp_infeasible', cert)
    return u_star

def authority_governor(x, beta_cmd, comfort=True):
    # 参考调节器：受限速率/加速度，把离散模式换成连续 beta
    beta = rate_limit(beta_cmd, beta_prev,
                      db_max=rho_beta, ddb_max=rho_ddbeta, dt=dt)
    v_ref = beta * v_nom
    if comfort:
        a_ref = jerk_limited_profile(v, v_ref, a_comfort, J_max)
    else:
        a_ref = emergency_profile(v, v_ref)
    return apply(v_ref, a_ref), beta
```

### IP-59 CMP-LIB：同伦类基元选择与平滑混合
```
def select_and_blend(x, goal, ctx, lib, w, cert):
    sigma = spendable_margin(cert)
    # 按同伦类检索候选（预认证：安全管 + 体验证书）
    cands = lib.query(x, goal, homotopy=ctx.homotopy)
    cands = [c for c in cands if c.tube.contains(x) and c.sigma_req <= sigma]
    if not cands:
        return lib.safe_stop(x), 'fallback'
    score = lambda c: (w.s*S(c.J3) + w.c*C(c.Ainf) + w.l*c.Leg
                       - w.t*c.T_leg - w.e*c.energy)
    best = argmax(cands, key=score)
    # 在认证凸包内平滑混合，避免切换 jerk 尖峰
    alpha = smoothstep(clip(sigma / best.sigma_req, 0, 1))
    u = alpha*ctrl(best) + (1-alpha)*ctrl(lib.safe_stop)
    return u, best.id

def shape_legible(xi_plan, goal_set, human_model, cert):
    # 早承诺 + 适度夸张 + 速度剖面编码意图，最小化 T_leg
    for c in decision_points(xi_plan):
        eta = choose_exaggeration(c, goal_set, human_model)
        xi_plan = apply_exaggeration(xi_plan, c, eta)
        if not satisfies(xi_plan, cert, A_joint_bounds):
            xi_plan = revert(xi_plan, c)   # 越界即回退，可读性让位安全
    return xi_plan
```

### IP-60 UXF：安全偏好自适应与证书接地解释

def safe_preference_update(w, feedback_batch, A_joint, W_safe, eta):
    g_hat = estimate_preference_gradient(feedback_batch)   # 评分/接管/干预
    w_new = project_simplex(w + eta*g_hat)
    if w_new not in W_safe:
        return w, 'frozen'        # 越界即冻结，回退群体保守档案
    return w_new, 'updated'

def on_human_intervention(segment, reason, cert):
    # 干预即标注：接管是最珍贵的体验边界样本
    if reason == 'fear':
        KB.add_counterexample(segment, label='ux_boundary', cert=cert)
        recalibrate_reserve(segment)
    elif reason == 'discomfort':
        update_comfort_model(segment)
    return 'logged'

def grounded_explanation(mode, cert):
    # 只允许引用真实证书字段，禁止自由生成（压制 RAG 幻觉）

# CAR：连续权柄 + sigma 守卫
def car_authority_step(x, cert):
    sigma = spendable_margin(cert)

    if cert.margin - cert.theta > 0:
        return 'Degraded', beta=smooth_beta(sigma)   # 平滑降权

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 用体感「消费」安全裕度：σ 被偏好学习逐步侵蚀至临界 | 高 | ρ_reserve 硬隔离不可消费；σ<0 立即冻结体验优化并降权；E88/E92 红线 |
| 可读性人体模型失配：塑造出的「可读」动作实际更费解 | 高 | 人类模型在线校准 + 干预即标注；E90 人类预测准确率硬门槛；越界回退 |
| 舒适模型个体差异大：群体阈值对某些人不适 | 中-高 | 体验档案按人分群；W_safe 内个性化；硬底线取保守分位而非均值 |
| 解释幻觉：LLM 生成证书中不存在的理由 | 中 | 模板填充 + 条款-字段一致性校验；禁止模板外自由生成；E93 审计 |
| QP 在紧裕度下不可行 → 兜底时产生 jerk | 中 | 预认证舒适停车基元 + smoothstep 混合；不可行即解释并记录 |
| 偏好学习中的人类反馈被误读/对抗 | 中 | 反馈置信度加权；W_safe 投影；多用户一致性检查；异常冻结 |
| 降级滞后 δτ 与扰动赛跑 | 中 | ρ_reserve 吸收 δτ 内最坏增量；β 速率上限与σ监控联动 |
| 基元库覆盖盲区：新场景无预认证基元 | 中 | 覆盖率指标 E89≥90%；盲区自动升级仿真并补库；同时保 QP 兜底 |

## 6. 本轮最大风险

**一句话**：本轮把「体感」转成可消费的安全裕度——若可读性的人体模型失配或偏好自适应把 σ 侵蚀到临界，系统会以「更顺滑、更自信」的假象逼近不可恢复的边界；因此「σ≥0 且 ρ_reserve 绝不被动用」必须作为立项红线，E88（投影期间安全违例）与 E92（偏好越界）任一不达标即冻结体验优化、回退固定保守裕度。
