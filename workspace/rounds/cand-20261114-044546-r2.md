# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 2 轮；本轮灵感：「零样本泛化」×「面部表情识别」）

> R69 把不确定性做成了有形状的对象，并把「问」变成动作。但它默认了两个隐藏前提：**（P1）我认得的标签集合及其语义是固定的**；**（P2）aleatoric / epistemic 的边界是内在的**。本轮两个灵感恰好把这两个前提同时击穿：
> - **零样本泛化**说：机器人会遇到训练集中从未出现过的表情/情绪/任务类别，「名字」可以由语言给出，但「名字到长相」的**语义桥**可能根本不成立；
> - **面部表情识别**说：表情标签从来不是一个点，而是标注者分布——受文化、主体、情境调制；更关键的是，**被观察者本人拥有对自己状态的优先访问权**。同一份标注分歧，对被监督学习是 aleatoric 噪声，对能开口问的机器人却是 epistemic 歧义。
>
> 核心命题：**把「语义桥」提升为一等、可认证、可询问的对象；把 aleatoric / epistemic 的划分从「内在属性」改为「相对可询问动作集 Θ 的属性」；并给情感推断一种只踩刹车、不踩油门的非对称权威。** 命名 **ZEBRA-RAS**（Zero-shot Expression-Bridge Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我用来求证的那套语义，本身可信吗**」——零样本的危险不是「不认识」，而是「用错的字典自信地认识」。

## 0. 直觉与动机

**灵感 1（零样本泛化 → 瓶颈不是分类器，而是桥）**
直觉：零样本识别常被讲成「用属性/词向量把未见类映射到视觉空间」。但真正决定成败的是那座**从语义到视觉的桥**：如果未见类在语义上离已见类很近、视觉上却离得很远（典型如「礼貌的微笑」与「紧张的微笑」），桥会把新类硬拽到最近的已见原型上——这就是 hubness / 投影坍缩。此时分类器可以给出 99% 置信度，而它错得离谱。所以零样本的第一性输出不应只是标签，而应是一份**关于桥是否成立的证书**。

**灵感 2（面部表情识别 → 标签是分布，主体是特权信息源）**
直觉：同一张脸，两个标注者可以一个写「开心」一个写「紧张」；跨文化差异更大（微笑的社会含义、眼神接触的礼貌性）。监督学习把这种分歧记成 aleatoric 噪声并「不可约」。但如果机器人可以问本人「你现在感觉如何」，这份分歧就可约。**同一不确定性，在 Θ=∅ 时是 aleatoric，在 Θ 含「问本人」时是 epistemic。** 这直接挑战 R69 对 aleatoric 的「永不可约」假设。

**灵感 3（查询相对分解 → R68/R69 是同一族的两端）**
直觉：把「可询问动作集」Θ 显式化。Θ=∅ 时，任何不确定性都无法通过交互消除，全部落入 aleatoric——这正是 R68「任何不确定 → 只收紧」的哲学。Θ 只含状态询问（看/问/触）时，得到 R69。Θ 再并入**概念询问**（问「这个表情是什么意思」、索取定义/示例、重新 grounding）时，才得到 R70。于是三层不是替代关系，而是 **Θ 增长链上的严格泛化**：R68 ⊂ R69 ⊂ R70。这是本轮最重要的理论姿态。

**灵感 4（两类询问正交 → 概念询问是摊销的）**
直觉：状态询问（「你疼吗」）只解决**此刻这个人**；概念询问（「在你们的语境里这个表情意味着什么」）解决的是**一整类未来的相遇**，收益随时间摊销。二者不可互相替代：问本人一百次也修不好一座错位的语义桥；反过来，把「疼痛」的定义学得再准，也不知道眼前这个人此刻是否真的疼。因此 VoI 必须分两层：episodic state VoI 与 amortized concept VoI。

**灵感 5（非对称情感权威 → 错读只许更慢，不许更快）**
直觉：人机交互中最危险的不是「把中性误读成痛苦」（顶多过度谨慎），而是「把痛苦误读成开心」（机器人继续靠近、加大动作）。所以给情感推断一种**非对称权威**：情感只能把社会风险系数 σ 从 1 往上推（更慢、更远、更轻），永远不许往下压（更快、更近、更猛）。这样一个对抗性的错误标签，最坏也只是让机器人更保守；它**不可能使物理风险超过已认证的基线**。

**灵感 6（认证的伦理陷阱 → 弃权必须触发「关怀默认」）**
直觉：保形预测会给出空集（弃权）。如果「弃权 = 按基线继续」，那么一份「覆盖率达标的证书」反而为「忽视痛苦」背书——我们称之为**认证洗白（certification laundering）**。因此弃权绝不能等价于中性：它必须触发一个低成本的**谨慎默认**（停下、退到安全距离、轻声询问「你还好吗」），除非任务时间窗不允许，此时取最大社会谨慎并记录伦理例外。零样本的失败模式因此从「更危险」被改写成「更冷漠」，而后者必须用制度而不是概率去兜底。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（ZEBRA-RAS 总览）** ZEBRA-RAS = (ZCB, QRD, BVA, SCG, ACQ, EMC, Q-MINT, CPvD, RAS-WM-A†)。六不变式：
(i) 继承 R69 定义 276-i 的**实时流零学习写操作**；
(ii) 继承 R69 的**交互预算与证据纪律**（单位时间交互 ≤1 次、单源不得定案）；
(iii) **情感非权威**：零样本情感输出不得直接生成或修改任何运动指令，只能调制有界社会风险系数 σ∈[1, σ_max] 与非安全关键的社交行为（速度/距离/注视/语气）；
(iv) **先认证后使用**：未见类标签仅在 SCG 给出非空保形集且 BVA 通过时进入策略；否则标签视为「缺席」，而非「错误标签」；
(v) **概念-状态分离预算**：概念询问与状态询问分别记账，前者以摊销 VoI 论证，后者以瞬时 VoI 论证；
(vi) **弃权即关怀**：弃权不得回落到基线行为，必须触发 CPvD 的谨慎默认或记录伦理例外。

**定义 311（表情观测与开放类别空间）** 观测 x_t = (I_{t−T:t}, u_t, v_t, b_t, κ_t)：面部图像序列、AU 强度、语音韵律、姿态/身体线索、上下文。已见类别 𝒞_s、未见类别 𝒞_u，二者不交。多源语义嵌入 φ_s(c)∈ℝ^d，s∈𝒮={AU, LLM-text, human-def, retrieved-exemplar}；视觉嵌入 ψ(x)；兼容度 f(x,c)=⟨ψ(x), φ̄(c)⟩/T（或独立学习头）。开放类别意味着 𝒞_u 在部署期持续增长，**标签集合本身是可变的**。

**定义 312（零样本概念桥 ZCB）** φ̄(c)=Σ_s α_s φ_s(c)，α 由源可靠度与源一致性决定。视觉锚集 𝒜(c)=Synth(φ̄(c)) ∪ Retrieve(φ̄(c)) ∪ AU-Decompose(φ(c))。桥 b_c: φ̄(c)↦p(ψ|c)，由锚集估计其视觉原型与协方差。零样本后验 p(c|x)∝exp(f(x,c))。关键是 ZCB 同时输出**桥的来源、锚的数量与分歧**，供 BVA 审计——标签与标签的「来路」必须一起交付。

**定义 313（桥有效性审计 BVA）**
- 语义可达裕度 m_sem(c)=d(φ̄(c), conv{φ̄(c_s): c_s∈𝒞_s})/σ_φ；
- 视觉锚裕度 m_vis(c)=kNN-dist(𝒜(c), ℳ_s)/σ_vis（ℳ_s 为已见视觉流形）；
- 桥一致性比 ρ(c)=m_vis(c)/(L_g·m_sem(c)+ε)——ρ≫1 表示「视觉上很新、语义上却离得近」，即 hubness 风险；
- 源一致性 A(c)=1−平均成对语义分歧；
- 桥风险 r_bridge(c)=w₁·ς(ρ−τ_ρ)+w₂·ς(m_vis−τ_v)+w₃·(1−A)（ς 为 logistic）；
- 桥有效 ⇔ r_bridge≤τ_bridge。BVA 输出**原因码**（可达性/锚支撑/源分歧/文化漂移），供审计与询问策略选择。

**定义 314（查询相对不确定性 QRD）** 令 Λ 为所有可采纳信息动作序列，Θ⊆Λ。
- U_total^Θ(x)=H(C|x)；
- U_ale^Θ(x)=H(C | x, g^{Θ}_{1:∞})，g^{Θ}_{1:∞} 为 Θ 内无限预算下的最优自适应询问序列（oracle 残余熵）；
- U_epi^Θ=U_total^Θ−U_ale^Θ；
- **单调性**：Θ₁⊆Θ₂ ⇒ U_ale^{Θ₂}≤U_ale^{Θ₁}，U_epi^{Θ₂}≥U_epi^{Θ₁}；
- 边界：Θ=∅ ⇒ U_ale=U_total、U_epi=0（R68 的「全不可约」）；Θ=Θ_state ⇒ R69；Θ=Θ_state∪Θ_concept ⇒ R70。
这一定义把「什么是 aleatoric」从一个哲学判断变成了**对动作集 Θ 的显式函数**。

**定义 315（概念-状态可加分解）** 按「先 grounding 概念、再询问状态」的决策序做 telescoping：
- U_bridge = H(C|x) − H(C | x, g^{Θ_c}_{1:∞})；
- U_state  = H(C | x, g^{Θ_c}_{1:∞}) − H(C | x, g^{Θ_c∪Θ_s}_{1:∞})；
- U_ale    = H(C | x, g^{Θ_c∪Θ_s}_{1:∞})；
则 **U_total = U_bridge + U_state + U_ale**（精确加和）。加和依赖决策顺序不是缺陷，而是**信息预算的排序建议**：先修桥，再问状态。R69 的 U_ale+U_epi 是 U_bridge≡0 的切片。

**定义 316（语义保形门 SCG）** 非一致性分数 s(x,c)=1−f(x,c)+β·r_bridge(c)。在已见类校准集上取 q̂=Quantile_{1−α}({s(x_i,c_i)})。未见类预测集 C_α(x)={c∈𝒞_u : s(x,c)≤q̂}。
- 桥覆盖差 δ_bridge=sup_{c∈𝒞_u}|P(Y∈C_α|unseen)−(1−α)|，用模拟未见类/留出文化域估其上界 δ̄；
- 实用置信 α'=α−δ̄；若 α'≤0 则门失效（不可认证，弃权）；
- |C_α|=0 ⇒ 弃权；=1 ⇒ 认证标签；>1 ⇒ 模糊集，交给 Q-MINT 做状态询问；
- 协变量偏移下用加权保形（密度比 w）修正，**先报告覆盖率缺口，再决定是否敢用**。

**定义 317（主动概念询问 ACQ）** 概念动作 g_c∈Θ_c：索取未见类 c 的定义/示例、检索 grounded 样本、请人示范、或让 LLM 给出可核验的属性分解。**摊销 VoI**：
VoI_amort(g_c)=Σ_{τ=1}^{N_h} γ^τ E[U_bridge,τ − U_bridge,τ(g_c)] − c(g_c) − λ_risk·risk(g_c)。
只有当 VoI_amort>0 且 c 属高风险类（疼痛/恐惧/不适）时才发起；结果写入 ConceptLedger，供后续轮次复用。概念询问不是「多问一句」，而是**给系统补一节词典**。

**定义 318（表情多模态一致性 EMC）** 证据通道 e={face, voice, posture, context, self-report}；一致性 κ(x)=1−归一化分歧，加时序合理性（AU 共现、微表情 onset/offset）。r_consist=1−κ(x)。EMC 只**抬高** r_bridge 或 U_state，绝不「纠正」标签——因为掩饰（masking）真实存在，不一致既可能是模型错，也可能是人在藏。**把「不一致」当成纠正信号，是表情识别里最常见的过度自信。**

**定义 319（两级控制器 Q-MINT）** 决策序：
1. BVA：r_bridge>τ_bridge ⇒ 概念分支；
2. SCG：α'≤0 或 |C_α|=0 ⇒ 弃权分支（触发 CPvD）；
3. |C_α|=1 ⇒ 认证标签；
4. |C_α|>1 ⇒ 以集合值信念调用 R69 MINT 做状态询问；无正 VoI 则弃权。
当 𝒞_u=∅、桥平凡有效时退化为 R69 MINT——**新层包含旧层，而不是并列替代旧层**。

**定义 320（非对称情感权威 RAS-WM-A†）** 认证情感 a_emo 映射为 σ(a_emo)∈[1, σ_max]：中性/积极→1，疼痛/恐惧/不适→>1。λ_exec=λ_base(U_ale^Θ+未消解 U_state)·σ(a_emo)。σ≥1 恒成立；情感不得修改认证前缀 k、不得扩张动作包络、不得降低 λ_base。非安全关键的「参与度」通道可单独调制，但被裁剪且永不触及安全包络。**情感有投票权，没有方向盘。**

**定义 321（谨慎默认 CPvD）** 弃权（|C_α|=0 或桥无效且不值得概念询问）时，不得回落到基线行为。调用有界检查动作 g_ck∈Θ_s（停下/退到安全距离/轻声确认），满足 cost(g_ck)≤c_ck、risk(g_ck)≤ε_ck。若任务时间窗不允许 g_ck，则取 σ=σ_max 并写入伦理例外日志（可审计）。**「不知道」必须是一个动作，而不是什么都不做。**

**定义 322（语义漂移与文化适应）** φ_t(c) 随文化/主体/情境漂移；D_t=W₂(φ_t(c), φ_ref(c)) 或跨源分歧。D_t>τ_drift ⇒ 桥失效、触发再 grounding；允许经同意的个体化表情风格校准，但原始情感数据不出端、不长期留存。

**定义 323（参与式审计 VQAuditor-Z）** 审计：桥证书来源、SCG 在影子未见类上的覆盖率、概念询问的摊销理由、情感权威轨迹（必须 σ≥1）、弃权→CPvD 合规率、隐私与同意记录。结论回灌 AuditBuf 与 ConceptLedger，成为下一轮 BVA 阈值与 ACQ 成本的先验。

**定义 324（对抗/漂移干扰集 AIC-ZEBRA）** ℰ_ZEBRA=ℰ_FLUID × ℰ_sem（投毒属性/LLM 描述）× ℰ_camouflage（掩饰/共谋欺骗）× ℰ_hub（投影坍缩/hubness）× ℰ_culture（文化语义漂移）× ℰ_priv（情感推断隐私泄漏）。其中多数是自然漂移而非攻击，但均按对抗标准建模——**因为对安全而言，自然漂移和攻击无法区分**。

**定义 325（证书 J_ZEBRA）** J_ZEBRA=(J_FLUID, bridge_margin, source_agreement, conformal_set_size, coverage_gap_upper, alpha_used, concept_ledger_hash, affect_authority_trace, abstention_action, zebra_ver)。Valid ⇔ Valid(J_FLUID) ∧ (桥有效 ∨ 已发起概念询问 ∨ 已弃权) ∧ coverage_gap_upper<α ∧ σ≥1 轨迹合法 ∧ (弃权 ⇒ 已 CPvD 或已记录例外)。

**定义 326（严格包含阶梯）**
- Θ=∅, 𝒞_u=∅, σ≡1 ⇒ R68 CALM；
- Θ=Θ_state, 桥平凡有效, 𝒞_u=∅ ⇒ R69 FLUID；
- 完整 Θ ⇒ R70 ZEBRA。
安全侧风险沿阶梯单调不增；关怀侧（对痛苦的响应）由 CPvD 严格改善。

## 2. 关键算法骨架

```python
# IP-264 ZCB：多源语义 → 三类正交视觉锚
class ZeroShotBridge:
    def __init__(self, enc, sources, synth, retrieve, au_decomp):
        self.enc, self.src = enc, sources
        self.synth, self.retrieve, self.au = synth, retrieve, au_decomp

    def build(self, c):                       # 每个未见类预计算并缓存
        phis = {s: self.src[s].encode(c) for s in self.src}
        phi  = reliability_weighted_mean(phis)
        anchors = (self.synth(phi) + self.retrieve(phi)
                   + self.au(c))              # LLM 合成 / 检索 / AU 分解
        return phi, anchors, phis

# IP-265 QRD：查询相对三分（telescoping，精确加和）
def query_relative_split(p, x, oracle, Th_s, Th_c):
    H    = entropy(p(x))
    H_c  = entropy(oracle(x, Th_c))           # 概念询问后的残余熵
    H_cs = entropy(oracle(x, Th_c + Th_s))    # 再叠加状态询问
    return H - H_c, H_c - H_cs, H_cs          # U_bridge, U_state, U_ale

# IP-266 BVA：桥有效性 + 原因码
def bridge_risk(c, m_sem, m_vis, src_phis, L_g):
    rho = m_vis / (L_g * m_sem + EPS)         # 视觉新而语义近 ⇒ hubness
    A   = source_agreement(src_phis)
    r   = w1*sigmoid(rho - TAU_RHO) + w2*sigmoid(m_vis - TAU_V) + w3*(1 - A)
    return r, reason_code(rho, m_vis, A)

# IP-267 SCG：语义保形门（先打折覆盖率，再决定敢不敢用）
def semantic_conformal(x, C_u, calib, alpha, beta):
    q = quantile([1 - f(xi, ci) + beta*r_bridge[ci] for xi, ci in calib],
                 1 - alpha)
    S = [c for c in C_u if 1 - f(x, c) + beta*r_bridge[c] <= q]
    return S, alpha - delta_bridge_upper      # alpha' <= 0 即门失效

# IP-268 ACQ：摊销概念 VoI（补词典，不是补一句问答）
def concept_voi(c, horizon, budget):
    gain = sum(gamma**t * expected_bridge_reduction(c) for t in horizon)
    return gain - budget.concept_cost(c) - LAMBDA * risk(c)

# IP-269 EMC：跨模态一致性（只抬高不确定，不纠正标签）
def consistency(x):
    kappa = cross_modal_agreement(x)          # face/voice/posture/context/self
    temp  = au_dynamics_plausibility(x)       # 微表情 onset/offset
    return 1 - (W_KAPPA*kappa + (1-W_KAPPA)*temp)

# IP-319 Q-MINT：先桥后状态；无证书即弃权即关怀
def decide_affect(c, x, M):
    r, why = M.bva(c, x)
    if r > TAU_BRIDGE:
        if M.acq.concept_voi(c, M.forecast) > 0 and M.budget.allow_concept(c):
            return ConceptQuery(c, why)
        return Abstain(why, g_ck=M.cpvd.checkin(x))
    S, a_eff = M.scg(x, M.C_u, M.calib, M.alpha)
    if a_eff <= 0 or len(S) == 0:
        return Abstain('no_certified_label', g_ck=M.cpvd.checkin(x))
    if len(S) == 1:
        return CertifiedLabel(S[0], r, a_eff)
    return StateQuery(S, via=M.mint)          # 集合值信念，交 R69 MINT

# IP-276 主闭环（继承 R69；情感分支并行、只读、只刹车）
def ZEBRA_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    # --- R70 情感分支：可弃权、非权威 ---
    affect = M.q_mint.decide_affect(obs.expression, M)
    if isinstance(affect, CertifiedLabel):
        sigma, U_bridge = asymmetric_authority(affect.label), 0.0   # sigma >= 1
    elif isinstance(affect, StateQuery):
        affect = M.cia.execute_state(affect)
        sigma, U_bridge = asymmetric_authority(affect), 0.0
    else:                                                           # Abstain
        sigma, U_bridge = 1.0, affect.U_bridge
        M.cpvd.maybe_checkin(affect)                                # 弃权即关怀
    # --- 安全侧：情感只能放大 lam，绝不改 k / 包络 ---
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + U_epi + U_bridge)) * sigma
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)               # affect 不参与 k
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_z.submit_async(affect, U_bridge, sigma, k, lam)
    return k, lam, mode, (U_ale, U_epi, U_bridge, sigma)
```

## 3. 推导

**引理 19（查询相对单调性与可加分解）** 因信息可被忽略，Θ₁⊆Θ₂ ⇒ U_ale^{Θ₂}≤U_ale^{Θ₁}、U_epi^{Θ₂}≥U_epi^{Θ₁}。定义 315 的 telescoping 给出 U_total=U_bridge+U_state+U_ale 的精确分解。R69 是 U_bridge≡0 的切片；R68 是 Θ=∅ 使 U_ale=U_total 的端点。⇒ 三层属于同一族，新层是旧层的严格泛化而非并列替代。

**引理 20（桥的可识别性下界 / hubness 判据）** 设桥 b 在语义空间 L_g-Lipschitz（A99），未见类的真实视觉原型与最近已见原型距离 Δ_u。若 Δ_u > L_g·m_sem(c)+δ（视觉新而语义近），则任何由该桥诱导的分类器在 c 上的错误率 ≥ 1−exp(−((Δ_u−L_g·m_sem)^+)^2/(2σ_vis²))。系：ρ(c)=m_vis/(L_g·m_sem) 是零样本可迁移性的**必要条件量**；ρ≫1 时必须判桥无效，而不是提高分类器置信度。

**引理 21（桥偏移下的保形覆盖）** 在加权可交换性下（A100：密度比 sup w≤e^{ε_w}），加权保形集满足 P(Y∈C_α)≥1−α−ε_w。以 δ̄ 表示桥覆盖差的可得上界，则取 α'=α−δ̄ 恢复 ≥1−α；若 δ̄≥α 则不存在有效门，只能弃权。此即「诚实弃权」的形式化：**宁可不认证，不可假认证**。

**定理 18（非对称情感权威不增险）** 因 σ≥1 且情感不参与 k、不扩张包络，对任意情感结果（含对抗性错误）有 Risk(π_{λ·σ})≤Risk(π_{λ_base})。系：FER 错误的最坏后果被结构性限制为**漏报（omission）**，而非**妄动（commission）**；风险因此从「更危险」迁移到「更冷漠 / 更少关怀」。这不是把问题消灭，而是把它搬到一个必须用制度处理的坐标上。

**定理 19（阶梯包含）** 令 Θ=Θ_state、𝒞_u=∅、σ≡1，则 ZEBRA 逐指令退化为 FLUID（R69）；再令所有 VoI≤成本、ECE 越界，则退化为 CALM（R68）。故 R68⊆R69⊆R70，安全侧期望风险沿阶梯单调不增；R70 仅在证书通过时增加能力。

**定理 20（认证诚实性 + 谨慎默认）** 若 δ̄ 为有效上界，认证标签覆盖率≥1−α；弃权时 CPvD 提供 risk≤ε_ck≤ε_int 的检查动作，故证书不会把关怀降到「检查」以下。结合定理 18，残余风险仅在 CPvD 被时间窗禁止时出现，此时取 σ_max 并写伦理例外——把「认证洗白」转成**显式、可审计的例外**。

## 6. 本轮最大风险

**一句话**：ZEBRA-RAS 用「非对称权威 + 保形认证 + 谨慎默认」把零样本表情错误从「更危险」改写成「更冷漠」，但这也意味着它最大的失败不再是撞到人，而是**在证书的保护下系统性地忽视未被见过、或被掩饰的痛苦**——当未见类的语义桥悄悄塌缩、或保形门因覆盖缺口估计偏低而给出「认证中性」时，机器人会带着覆盖率≥1−α 的合法证书，对一个正在疼痛的人保持基线行为；此时**认证不是错误的反面，而是冷漠的许可证**。

**次级风险与缓解**：
1. **桥覆盖差 δ̄ 本身估不准**（在已见类上估的迁移缺口，恰好在未见类上失效）→ 用多文化留出域 + 影子未见类模拟估上界，δ̄ 取保守分位数，宁可弃权；
2. **概念询问的语义污染**（错误定义被写进词典、长期污染）→ ConceptLedger 版本化 + 多源一致 + 可撤销；
3. **隐私与同意**（表情/情绪属于敏感数据）→ 端侧处理、不长期留存、可审计同意记录；
4. **奖励/信任的负反馈**（频繁弃权让用户烦躁）→ CPvD 成本上界 + 个性化交互频率 + 用户研究 E315；
5. **文化漂移使证书过期** → D_t 漂移检测 + 定期再 grounding + 证书带有效期。

## 3. 关键算法伪代码

# IP-264 ZCB：多源语义 → 三类正交视觉锚
class ZeroShotBridge:
    def build(self, c):
        phis = {s: self.src[s].encode(c) for s in self.src}
        phi  = reliability_weighted_mean(phis)
        anchors = self.synth(phi) + self.retrieve(phi) + self.au(c)
        return phi, anchors, phis

# IP-265 QRD：查询相对三分（精确加和）
def query_relative_split(p, x, oracle, Th_s, Th_c):
    H, H_c, H_cs = entropy(p(x)), entropy(oracle(x, Th_c)), entropy(oracle(x, Th_c+Th_s))
    return H - H_c, H_c - H_cs, H_cs          # U_bridge, U_state, U_ale

# IP-266 BVA：桥有效性 + 原因码
def bridge_risk(c, m_sem, m_vis, src_phis, L_g):
    rho = m_vis / (L_g * m_sem + EPS)
    A   = source_agreement(src_phis)
    r   = w1*sigmoid(rho-TAU_RHO) + w2*sigmoid(m_vis-TAU_V) + w3*(1-A)
    return r, reason_code(rho, m_vis, A)

# IP-267 SCG：桥感知保形门
def semantic_conformal(x, C_u, calib, alpha, beta):
    q = quantile([1 - f(xi,ci) + beta*r_bridge[ci] for xi,ci in calib], 1-alpha)
    S = [c for c in C_u if 1 - f(x,c) + beta*r_bridge[c] <= q]
    return S, alpha - delta_bridge_upper       # alpha' <= 0 即不可认证

# IP-268 ACQ：摊销概念 VoI
def concept_voi(c, horizon, budget):
    gain = sum(gamma**t * expected_bridge_reduction(c) for t in horizon)
    return gain - budget.concept_cost(c) - LAMBDA * risk(c)

# IP-319 Q-MINT：先桥后状态；弃权即关怀
def decide_affect(c, x, M):
    r, why = M.bva(c, x)
    if r > TAU_BRIDGE:
        if M.acq.concept_voi(c, M.forecast) > 0 and M.budget.allow_concept(c):
            return ConceptQuery(c, why)
        return Abstain(why, g_ck=M.cpvd.checkin(x))
    S, a_eff = M.scg(x, M.C_u, M.calib, M.alpha)
    if a_eff <= 0 or len(S) == 0:
        return Abstain('no_certified_label', g_ck=M.cpvd.checkin(x))
    if len(S) == 1:
        return CertifiedLabel(S[0], r, a_eff)
    return StateQuery(S, via=M.mint)

# IP-276 主闭环（继承 R69；情感只读、只刹车）
def ZEBRA_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    affect = M.q_mint.decide_affect(obs.expression, M)
    if isinstance(affect, (CertifiedLabel, StateQuery)):
        if isinstance(affect, StateQuery): affect = M.cia.execute_state(affect)
        sigma, U_bridge = asymmetric_authority(affect), 0.0      # sigma >= 1
    else:
        sigma, U_bridge = 1.0, affect.U_bridge
        M.cpvd.maybe_checkin(affect)                             # 弃权即关怀
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + U_epi + U_bridge)) * sigma
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)            # affect 不参与 k
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_z.submit_async(affect, U_bridge, sigma, k, lam)
    return k, lam, mode, (U_ale, U_epi, U_bridge, sigma)

## 4. 推导

**引理 19（查询相对单调性与可加分解）** 信息可忽略 ⇒ Θ₁⊆Θ₂ 时 U_ale^{Θ₂}≤U_ale^{Θ₁}、U_epi^{Θ₂}≥U_epi^{Θ₁}。telescoping 给出 `U_total=U_bridge+U_state+U_ale`；R69 是 `U_bridge≡0` 的切片，R68 是 Θ=∅ 端点。⇒ 三层同族、严格包含。

**引理 20（桥可识别性下界 / hubness 判据）** A99（桥 L_g-Lipschitz）下，若 `Δ_u > L_g·m_sem+δ`（视觉新而语义近），则任意由该桥诱导的分类器在 c 上错误率 ≥ `1−exp(−((Δ_u−L_g m_sem)^+)^2/(2σ_vis²))`。系：ρ 是零样本可迁移性的必要条件量，ρ≫1 必须判桥无效而非加置信。

**引理 21（桥偏移下的保形覆盖）** 加权可交换性（A100，密度比 ≤ e^{ε_w}）下 `P(Y∈C_α) ≥ 1−α−ε_w`；以 δ̄ 为上界取 `α'=α−δ̄` 恢复 ≥1−α；δ̄≥α 则门失效、只能弃权——「宁可不认证，不可假认证」。

**定理 18（非对称情感权威不增险）** σ≥1 且情感不改 k、不扩张包络 ⇒ 对任意情感结果（含对抗错误）`Risk(π_{λ·σ}) ≤ Risk(π_{λ_base})`。系：FER 错误的最坏后果被限制为**漏报**而非**妄动**，风险从「更危险」迁移到「更冷漠」。

**定理 19（阶梯包含）** Θ=Θ_state、𝒞_u=∅、σ≡1 ⇒ 逐指令退化为 FLUID；再令 VoI≤成本、ECE 越界 ⇒ 退化为 CALM。故 R68⊆R69⊆R70，安全侧风险单调不增。

**定理 20（认证诚实性 + 谨慎默认）** δ̄ 有效时认证标签覆盖≥1−α；弃权时 CPvD 提供 risk≤ε_ck 的检查动作，故证书不把关怀降到「检查」以下；CPvD 被时间窗禁止时取 σ_max 并写伦理例外——把「认证洗白」转成显式可审计例外。

## 7. 预期结果与判据

若方案成立，应看到三条互相独立的证据链同时成立：
1. **桥层**：BVA 的 r_bridge 在未见类上先于分类错误升高（E302 AUROC≥0.88），且语义桥投毒被拒（E311≥95%）；
2. **认证层**：保形覆盖在影子未见类与跨文化留出域上维持名义水平，覆盖缺口被 δ̄ 保守覆盖（E303），专骗 SCG 的构造类假认证 ≤2%（E312）；
3. **关怀层**：弃权→基线忽视率为 0、CPvD 触发 ≥95%（E309），且对抗错误标签不增加物理风险（E308，定理 18）。
任一链断裂即判定本轮失败——**尤其是第三条**：若「安全」以「冷漠」为代价且未被 CPvD 兜住，则方案在伦理上不成立。

## 8. 本轮最大风险

**一句话**：ZEBRA-RAS 用「非对称权威 + 保形认证 + 谨慎默认」把零样本表情错误从「更危险」改写成「更冷漠」，但这也意味着它最大的失败不再是撞到人，而是**在证书的保护下系统性地忽视未被见过、或被掩饰的痛苦**——当未见类的语义桥悄悄塌缩、或保形门因覆盖缺口估计偏低而给出「认证中性」时，机器人会带着覆盖率≥1−α 的合法证书，对一个正在疼痛的人保持基线行为；此时**认证不是错误的反面，而是冷漠的许可证**。

**次级风险与缓解**：δ̄ 估不准（多文化留出域 + 影子未见类 + 保守分位数，宁可弃权）；概念询问语义污染（ConceptLedger 版本化 + 多源一致 + 可撤销）；情感隐私（端侧处理、不长期留存、可审计同意）；频繁弃权引发用户烦躁（CPvD 成本上界 + 个性化频率 + E315）；文化漂移使证书过期（D_t 检测 + 定期再 grounding + 证书有效期）。
