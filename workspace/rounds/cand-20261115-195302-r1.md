# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「多传感器融合」×「双臂协作」）

> R69 把不确定性拆成 aleatoric / epistemic，并让系统学会了「开口问」。但它的整个证据纪律压在一句从未被检验的公理上——**「k 个正交证据源一致 ⇒ 可信」**（定义 293-iii、引理 18）。这里的「正交」是**被假设的，不是被测量的**。真实的多传感器系统里，传感器通过共同病因强相关：共用标定、共用光照与反射、共用时钟、共用同一个预训练 trunk、甚至共用同一个恶意的世界。于是「k 个独立意见」很可能只是**一个意见戴了 k 顶帽子**。
>
> 「多传感器融合」×「双臂协作」恰好把这条公理的病灶同时放大、也同时提供了药：
> - **多传感器融合**的经典教训是：融合的全部收益来自**误差独立**，一旦存在共同模式（common mode），融合会给出一个**既自信又错误**的估计——方差被虚假地压小，而均值被共模一起拖走；
> - **双臂协作**第一次给了系统一个**主动去相关的杠杆**：两个身体可以独立移动（异基线视差）、独立接触（触觉 vs 视觉）、错时采样、互为标定基准；但双臂同时引入了**新的共模耦合**——共享躯干/基座、共享感知 trunk、共享被握持的物体、共享闭链（一只手的误差经物体会传到另一只手）。
>
> 核心命题：**把「一致性」从证据降格为待检验的假设；在 R69 的两轴不确定性之外，加入一条关于证据基本身质量的二阶轴——独立性亏空 U_ind（我表面上的 k 个源，真实独立信息量 n_eff 是多少）；用双臂/多传感器动作去主动扰动共同病因、诱发可观测的分歧，从而把「真共识」与「共模错觉」分开；当共同病因落在所有可行动作的零空间里时，承认 n_eff 不可辨识，并把一致一律按单源处理、退回 R68 保守。** 命名 **TANDEM-RAS**（Two-arm Active N-source DEcorrelation & evidence Multiplexing for Risk-Adaptive Systems；tandem 本义即「前后双座/双人协作」）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我请来的这些‘证人’，真的是彼此独立的证人，还是同一个声音的多次回声？**」——一致不是证据；**误差独立的一致才是证据**。

## 0. 直觉与动机

**灵感 1（多传感器融合 → 融合的收益全在「误差独立」这个前提上）**
直觉：把两个传感器平均，能降方差，靠的是「一个高、一个低」能互相抵消；如果两个会**一起高、一起低**，平均只是把同一个错误抄了两遍。工程上这叫共同模式/共模故障：雨雾同时糊住两台相机、同一次标定漂移同时污染两套外参、同一个训练分布让两个模型幻觉出同一把「不存在的椅子」。最要命的是——**共模故障在「大家都同意」时最安静**：没有分歧可供采样，融合器看到的就是「零方差、高一致」，于是给出一个自信的错值。R69 的 VoI、证据纪律全部建立在「一致 = 信息」上，正好在这一点上失明。

**灵感 2（双臂协作 → 既是去相关杠杆，也是新的共模源）**
直觉：两只手可以做的事，一只手的多个传感器做不到——**改变基线**。同一个目标，从两个相隔 30cm 的视点看，其视差随距离变化，这能拆穿「画在墙上的一幅画」伪装成的立体物；用一只手触、另一只手看，能拆穿「看起来是玻璃、其实是亚克力」；错时采样能拆穿「只在一帧里出现的幻影」。但双臂也把新的共模塞进来：共用躯干的抖动、共用同一套感知权重、共握同一个物体（物体一滑，两臂同时错）、闭链里一臂的位姿误差会经物体变成另一臂的「观测」。**杠杆与病灶是同一根杆的两端**——所以必须把「去相关」和「识别新的共模」当作同一个问题的两面。

**灵感 3（二阶轴 → U_ind 不是又一个标量，而是对证据基质量的怀疑）**
直觉：R68 的 U_cal 问「测量准不准」，R69 的 U_epi 问「该选哪个模态」，二者都默认「我手里这叠证据牌是彼此独立的」。U_ind 质疑的正是这副牌本身：**它们是 k 张牌，还是同一张牌印了 k 次？** 它不描述世界，描述「我用来描述世界的证据值多少」。这决定了理论姿态：**新轴必须是旧轴的前置闸门**——先证证据基有效独立（U_ind），再谈消歧（U_epi），最后谈噪声（U_ale）。在错误的相关基底上做再多 VoI，等于反复聆听同一个回声。

**灵感 4（可行动作 → 去相关是「故意制造可观测的分歧」，不是「再确认一次」）**
直觉：你无法直接「测量」相关性，因为共模故障的签名恰恰是「无分歧」。唯一可靠的办法是**主动扰动共同病因**，把隐藏的共享潜变量推到会显形的区域：换基线/换模态/错时/换身体/物理固定一臂当基准。同一个视角再看一百眼（不改变任何共同病因），独立性增益**严格为零**——这正是 R69「重复采样零增益」在多源世界的推广。于是本轮的技能是：把「看/问/触」升级为「**主动去相关探针**」，其价值用「n_eff 的期望提升」而非熵减来计量。

**灵感 5（双刃剑 → 「共识投毒」是一类全新的攻击面）**
直觉：一旦系统用「多源一致」当证据，攻击的性价比彻底改变——攻击者**不必**骗过每一个传感器，只需让它们**一致地错**：一块镜面让两台相机看到同一个幻影；一次共享先验投毒让两臂幻觉同一物体；一次协同的人类欺骗让「表情+语气+说法」同时撒谎。更阴险的是闭链可以被**伪一致**骗过：错误的相对标定能让环闭合残差看起来完美（一致性 ≠ 正确性）。所以本轮必须同时交付：独立性证书、共模检测、去相关计划、闭链通道的校准前提、相关风险下的联合退避、以及「共同病因不可辨识时一律按单源」的诚实边界。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（TANDEM-RAS 总览与三不变式）** TANDEM-RAS = (EIS, ICE, CMD, DAP, LCC, JRC, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；相关模型、标定先验、共模检测器全部冻结或只读）；
(ii) **独立性先行**：任何融合置信度必须报告有效证据数 n_eff 并携带独立性证书；未认证独立的「一致」按单源计，不得作为 k 源证据；
(iii) **耦合安全**：双臂动作必须联合认证（共享包络 + 闭链相容）；一旦判共模可疑，两臂**同时**退避，禁止单臂抢跑（split-brain 禁止）。

**定义 311（证据集与相关模型）** 证据集 E = {(e_i, Σ_i, c_i)}，i=1..k，c_i ∈ {sensor, arm, contact, prior} 为来源类别。设共同模式潜变量 z_cm，线性观测模型 e_i = μ + A_i z_cm + ε_i，ε_i 独立。由样本协方差得相关矩阵 R（对角为 1），并分解出共模载荷 A。融合估计 μ̂(E) 与其协方差 Σ_f 必须在**估计到的 R** 下给出，而非在 R=I 下给出。

**定义 312（有效证据数 n_eff）** n_eff = k² / (1ᵀ R 1)。等相时 n_eff = k / (1 + (k−1)ρ̄) ∈ [1, k]。它是「这些证据真实包含几个独立意见」的度量；一致所携带的置信度按 n_eff 而非 k 计价（引理 19–20）。

**定义 313（独立性亏空 U_ind）** U_ind = 1 − n_eff/k ∈ [0, 1−1/k]。它是**二阶不确定性**：不描述世界状态，描述「用来推断世界状态的证据基有多可信」。R69 隐含假设 U_ind ≡ 0；R70 把它显式化并作为前置闸门。

**定义 314（共同病因与可辨识性）** 共同病因 z_cm ∈ 𝒵 影响至少两个来源。称 z_cm 在允许动作集 𝒜_dec 下**可辨识**，当且仅当存在 g ∈ 𝒜_dec 使来源间的期望分歧对 z_cm 的灵敏度 η(g) = ∂D(g)/∂z_cm ≠ 0（D 为诱导出的分歧统计量）。若对所有 g ∈ 𝒜_dec 都有 η(g)=0，称 z_cm **不可辨识**；此时任何仅用这些观测的证书都无权声称独立，必须令 n_eff := 1（定理 20）。

**定义 315（去相关动作空间 DAP）** 𝒜_dec = { g_baseline（移动第二臂/第二眼改变基线→视差）, g_modality（触觉 vs 视觉 vs 力）, g_stagger（错时采样）, g_body（改用另一臂的传感器）, g_brace（物理固定一臂作基准，使另一臂误差显形）, g_external（求一个位于本 trunk 之外的独立源）}。每个动作有灵敏度 η(g)、成本 c(g)、安全约束（继承 R69 定义 302 的 C-RAS-WM 认证）。

**定义 316（独立性信息增益 VoI_ind）** VoI_ind(g) = E_{y~p(·|g)}[H(z_cm|E) − H(z_cm|E,y)]，即对共同病因信念的期望熵减；等价地（小增益近似）用期望 Δn_eff 计量。选择 g* = argmax_g [VoI_ind(g) − c(g)] s.t. 安全与预算。**零增益引理**：η(g)=0 ⇒ VoI_ind(g)=0（同因重看严格无用，引理 21）。

**定义 317（独立性证书 ICE）** ICE = (n_eff, CI_{1−α}, ρ̄, identifiability_flag, calib_ece)。Valid ⇔ n_eff 区间的经验覆盖率 ≥ 1−α ∧ identifiability_flag = true ∧ calib_ece ≤ τ_ece。若不可辨识或未校准，强制 n_eff := 1 并标注降级。

**定义 318（闭链通道 LCC）** 双臂共持刚体时，闭环残差 ξ = log(T_A^{-1} T_{AB} T_B^{-1})（T_{AB} 为相对变换估计）。ξ 提供一条**独立于单臂感知**的几何第二意见；但其有效性**条件于一个外生的相对标定先验**（标准差 σ_cal）。一致性 ≠ 正确性：ξ≈0 是必要非充分（引理 22）。σ_cal 大时 LCC 检测真错的 AUC→0.5，不得计入证据。

**定义 319（联合风险耦合 JRC）** 两臂控制 λ_A, λ_B 经由共享扰动 z_cm（共模定位误差、共享物体滑移、共享基座抖动）而相关。定义联合风险 P(unsafe_A ∨ unsafe_B | z_cm) 与联合 λ_J；要求存在联合安全包络（两臂已认证前缀在共享工作空间/闭链下互相相容）。相关尾部满足 P(unsafe_A ∧ unsafe_B) ≥ P_A·P_B + Cov_risk，故必须用联合门控，不能各自打折后简单相与。

**定义 320（共模可疑与相关保守）** 若 CMD 报 z_cm 可疑（诱导分歧异常）或 ICE 判不可辨识，则两臂**同时**退避：λ_A = λ_B = λ_floor(U_ale + U_epi + U_ind)，并启用联合门控；禁止非对称抢跑（否则一个共模错误会让两臂一致地撞上同一个障碍）。

**定义 321（协调感知的 resolution bonus）** 若 DAP 把 n_eff 提升到 k（独立认证通过）且 LCC 在标定先验下通过，则可放宽回 R69 路径（resolution bonus），并允许双臂并发执行；反之按定义 320 降级。

**定义 322（证据预算与自适应）** 每轮独立性探针 ≤ b_ind（默认 0，仅在 U_ind 超阈或 ICE 未认证时升 1）；常规路径与 R69 P99 持平；只有共模可疑才展开完整去相关集。保证不会因「无限求证」瘫痪。

**定义 323（证书 J_TANDEM）** J_TANDEM = (J_FLUID, n_eff, CI, ρ̄, identifiability, loop_residual, calib_prior, decorrelation_log_hash, joint_risk_margin, tandem_ver)。Valid ⇔ Valid(J_FLUID) ∧ (ICE 有效或已正确降级) ∧ (LCC 有效或已正确忽略) ∧ 联合包络满足。

**定义 324（共模威胁模型 ℰ_tandem）** ℰ_tandem = ℰ_FLUID × ℰ_common × ℰ_chain，其中 ℰ_common = {共模投毒（让 k 源一致地错）, 共识注入, 共享先验投毒（污染 trunk 使两臂幻觉同一物）, 协同人类欺骗（表情+语气+说法同时撒谎）, 共享环境攻击（一块镜面/一片雨雾同时骗过所有相机）}，ℰ_chain = {伪一致闭链（错误相对标定让环闭合）, 共享物体滑移}。

**定义 325（双臂协同一致性）** 定义角色分配 (leader, follower, brace, probe) 与共享资源占用表；协调证书要求：两臂指令在共享包络内相容、不重复占用同一物理资源、闭链内力在限内。一次共模误差会让两臂**一致地**移动并相撞——这是单臂检查看不见、只有联合检查看得见的失效。

**定义 326（严格包含与退避）** n_eff = k（独立）⇒ 逐指令等于 R69（FLUID）；n_eff = 1（不可辨识/强共模）⇒ 逐指令等于 R68（CALM）；中间取插值式保守。安全侧对 n_eff 单调不增：n_eff 越低越保守，永不低于 R68。

```python
# IP-264 EIS：证据集与相关模型（在估计到的 R 下融合，而非假设 R=I）
class EvidenceIndependenceSubstrate:
    def __init__(self, corr_model, cm_prior):
        self.R_model, self.cm = corr_model, cm_prior      # 冻结
    def fuse(self, evidence):                              # evidence: [(e_i, Sigma_i, class_i)]
        R    = self.R_model.estimate_under_common_mode(evidence)
        neff = (len(evidence) ** 2) / float(ones @ R @ ones)
        mu, Sf = gls_fuse(evidence, R)                     # 用 R 加权，而非单位阵
        return mu, Sf, neff, R
    def common_mode_loadings(self, evidence):
        return self.cm.loadings(evidence)                  # A_i，供 CMD 与 DAP 使用

# IP-265 ICE：独立性证书（含不可辨识时的诚实降级）
def independence_certificate(neff, R, evidence, ident_flag, calib_ece, alpha=0.05):
    if (not ident_flag) or calib_ece > TAU_ECE:
        return dict(n_eff=1.0, valid=False, reason='unidentifiable_or_uncalibrated')
    ci = bootstrap_ci(neff, evidence, alpha)               # n_eff 的经验区间
    return dict(n_eff=neff, CI=ci, rho_bar=mean_offdiag(R),
                valid=(ci.covers(neff) and ident_flag), reason='ok')

# IP-266 CMD：共模检测（借主动扰动诱发可观测分歧）
def detect_common_mode(E, D, baseline_signal):
    # D 是 DAP 在 g 下诱导出的分歧统计量；共模故障的签名是"无分歧 + 高一致"
    uplift = D.induced - D.baseline
    z_cm   = cm_estimator.invert(uplift, calib_prior=...)
    return dict(z_suspect=(abs(z_cm) > TAU_CM), z_hat=z_cm,
                conflates=(uplift ~ 0 and baseline_signal ~ 0))   # 无分歧也无异常 = 不可辨识信号

# IP-267 DAP：去相关动作选择（同因动作零增益）
def choose_decorrelation(E, cm, budget):
    best = None
    for g in decor_candidates(cm):                         # baseline/modality/stagger/body/brace/external
        if not budget.allow(g) or not c_ras_wm.certify_info(g, E): continue
        eta = sensitivity_of_disagreement(g, cm)           # eta(g)=0 => 同因
        if eta <= 0:                                       # 零增益引理：跳过
            continue
        gain  = eta * cm_posterior_entropy(E) - cost(g)
        if best is None or gain > best.gain: best = (g, gain)
    return best if best and best.gain > 0 else None        # 无利可图 → 不探，按保守

# IP-268 LCC：闭链第二意见（条件于外生标定先验）
def loop_closure(E_arms, T_AB, sigma_cal):
    xi = logm(inv(T_A) @ T_AB @ inv(T_B))
    valid = sigma_cal <= SIGMA_CAL_MAX                 # 标定先验不够强 => AUC→0.5，不得计入
    return dict(residual=xi, valid=valid)

# IP-269 JRC + 主闭环（继承 R69，前置插入独立性层）
def TANDEM_RAS_round(M, obs):
    E = M.eis.collect(M.arms, obs)                     # 多传感器 + 两臂证据
    mu, Sf, neff, R = M.eis.fuse(E)
    ICE = M.ice.certify(neff, R, E)                    # 不可辨识 => neff:=1
    zcm = M.cmd.detect(E, M.dap, M.last_signal)
    # 1) 二阶闸门：先证证据基独立，再谈消歧
    if zcm['z_suspect'] or not ICE['valid']:
        g_dec = M.dap.choose_decorrelation(E, zcm, M.budget_ind)
        if g_dec is not None:
            E = M.eis.collect_after(M.arms, obs, g_dec)
            mu, Sf, neff, R = M.eis.fuse(E)
            ICE = M.ice.certify(neff, R, E)
        else:
            neff = 1.0                                 # 去不动 => 一致按单源（诚实边界）
    # 2) 接 R69：模态分解与消歧（证据置信度用 n_eff 计价）
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_calibrated)
    # 3) 证据纪律升级：k 源一致只有在 ICE 认证独立后才计入
    allow_evidence = (ICE['valid'] and ICE['n_eff'] >= K_MIN)
    g = (M.mint.choose_interaction(modes, o, M.budget)
         if (allow_evidence and U_epi > TAU_EPI) else None)
    # 4) 闭链通道 + 联合风险耦合（双臂）
    lcc = M.lcc.loop_closure(E, M.T_AB, M.cal_prior.sigma)
    lamA, lamB = M.jrc.coupled_scale(U_ale, U_epi, U_ind=1-neff/len(E), lcc=lcc)
    # 5) 共模可疑 / 不可辨识 => 相关保守 + 联合门控（禁止抢跑）
    if zcm['z_suspect'] or not ICE['valid']:
        lamA = lamB = max(lamA, lam_floor(U_ale + U_epi + (1 - neff/len(E))))
        M.jrc.enable_joint_gate(True)
    # 6) 双臂各自选模态、但通过联合包络认证
    modeA, modeB = select_modes(modes, lamA, lamB)
    kA, kB = M.jrc.joint_certified_prefix(modeA, modeB, M.arms, wm_preds)
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = min(M.c_ras_wm.certified_prefix(A, ..., wm_preds), min(kA, kB))
    # 7) 审计 + 证书
    M.vqa_t.submit_async(neff, ICE, zcm, lcc, g, g_dec if 'g_dec' in dir() else None)
    return k, (lamA, lamB), (modeA, modeB), (neff, ICE['valid'], 1-neff/len(E))
```

## 3. 推导

**引理 19（共识膨胀 / 伪佐证）** 设 k 个源共享共模份额 ρ，各自独立噪声。则「全体一致」条件下「一致值错误」的概率 P(wrong | agree) 随 k **不下降**当 ρ→1（趋于常数），只有当 ρ<1 且 k 增大、n_eff 随之上升时才下降。系：**R69 的「k 一致」只有在 n_eff 随 k 增长时才是证据；共模下 k 只是重复次数，不是证据量。**（机制检验见 tandem_results.json：ρ=0.99 时 P(wrong|agree) 在 k=2,3,5 下恒约 0.61–0.62；ρ=0 时由 0.48 降到 0.31。）

**引理 20（n_eff 置信校准）** 融合均值的标准误应为 1/√n_eff，而非 1/√k。二者之比 √(k/n_eff) 即朴素法的过度自信倍数；当 ρ=0.9, k=5 时约 2.2×。用 n_eff 计价的置信区间经验覆盖率恢复到 1−α（机制检验：n_eff 预测的标准误与经验标准误误差 < 0.007）。

**引理 21（去相关零增益与单调性）** 对动作 g，独立性增益 VoI_ind(g) ∝ η(g)；η(g)=0（不改变任何共同病因：同视角/同模态/同时刻/同身体）⇒ 增益严格为 0。且增益对去相关效力 γ 单调增（n_eff = k/(1+(k−1)ρ(1−γ))）。系：**「再看一眼」不是去相关；只有改变共同病因结构才算。**（机制检验：γ=0 时增益恒 0；γ=1 时 n_eff 由 1.05 升到 2.0。）

**引理 22（闭链一致性 ≠ 正确性）** 环闭合残差 ξ ≈ d_obj − d_cal + ν（小误差线性化）。在标定先验 σ_cal 下检测真对象误差 d_obj 的 AUC 随 d_obj/σ_cal 单调；σ_cal→∞ 时 AUC→0.5。故 LCC 只有在 σ_cal 足够小时才是有效独立证据，否则必须被忽略而非计入。（机制检验：σ_cal 从 0.01 升到 1.0，AUC 由 1.00 降到 0.54。）

**定理 18（TANDEM 严格包含 R69 与 R68）** A99–A102 下：n_eff=k 时各决策逐指令等于 FLUID-RAS；n_eff=1 时逐指令等于 CALM-RAS；中间保守插值。故对任意状态期望风险随 n_eff 单调不增，安全侧永不弱于 R68，效率侧只在独立性被认证后兑现 bonus。

**定理 19（共模下的联合安全）** 若每臂独立认证忽略共享扰动 z_cm，联合失效概率至少含相关协方差项 Cov_risk ≥ 0，可能突破单臂界；采用 JRC 联合门控后联合界恢复；定义 320 的相关保守消除「两臂一致撞同一障碍」的 split-brain 失效。

**定理 20（可辨识边界 / 诚实不可能性）** 若 z_cm 落在所有允许去相关动作 𝒜_dec 的零空间（对所有 g 有 η(g)=0），则仅凭这些观测的**任何**方案都无法认证独立性；因此任何合法证书必须输出 n_eff=1。这不是算法缺陷，而是信息论边界：**当共同病因无法被任何可行动作扰动时，「一致」在原理上不可与「真共识」区分**，唯一安全的选择是承认不知道。

## 6. 本轮最大风险

**一句话**：TANDEM 把整个安全论证押在「我能够**观测或扰动**共同的病因」这一前提上——但共模故障最阴险的签名恰恰是**「无分歧」**：当共同病因无法被任何允许的去相关动作扰动（落在 𝒜_dec 的零空间），系统看到的仍是「零方差、高一致」，ICE 若因估计误差误判为可辨识，就会给一批**同源回声**签发「独立证据」证书；于是 R69 的「问错比不问更危险」升级为更隐蔽的版本——**系统拿着一份‘已认证独立’的证书，自信地执行一个所有传感器共同犯下的错误**。

**次级风险与缓解**：伪一致闭链（LCC 条件于外生标定先验，σ_cal 大时强制忽略，定义 318/引理 22）；共模投毒与共享环境攻击（ℰ_tandem 对抗训练 + CMD 主动扰动，定义 324/引理 19）；去相关动作本身越界（C-RAS-WM 认证 + 预算 b_ind，定义 315/322）；双臂一致撞障碍（JRC 联合门控 + split-brain 禁止，定义 319–320/定理 19）；无限求证瘫痪（b_ind 硬约束 + 零增益剪枝，定义 322/引理 21）。

# 第 70 轮产物 · 创新点清单 v1：TANDEM-RAS（Two-arm Active N-source DEcorrelation & evidence Multiplexing for Risk-Adaptive Systems：多传感器融合 × 双臂协作的有效证据数闭环；EIS×ICE×CMD×DAP×LCC×JRC×RAS-WM‡）

```python
# IP-264 EIS：按估计到的 R 融合，输出有效证据数
def fuse(self, evidence):
    R    = self.R_model.estimate_under_common_mode(evidence)
    neff = (len(evidence)**2) / float(ones @ R @ ones)
    mu, Sf = gls_fuse(evidence, R)                    # 不是单位阵加权
    return mu, Sf, neff, R

# IP-265 ICE：不可辨识/未校准 ⇒ 诚实降级为单源
def independence_certificate(neff, R, evidence, ident_flag, ece, alpha=0.05):
    if (not ident_flag) or ece > TAU_ECE:
        return dict(n_eff=1.0, valid=False, reason='unidentifiable_or_uncalibrated')
    ci = bootstrap_ci(neff, evidence, alpha)
    return dict(n_eff=neff, CI=ci, rho_bar=mean_offdiag(R), valid=ci.covers(neff))

# IP-267 DAP：只选真能改变共同病因的动作（η=0 跳过）
def choose_decorrelation(E, cm, budget):
    best = None
    for g in decor_candidates(cm):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, E): continue
        if sensitivity_of_disagreement(g, cm) <= 0: continue      # 零增益
        gain = sensitivity_of_disagreement(g, cm)*cm_posterior_entropy(E) - cost(g)
        if best is None or gain > best.gain: best = (g, gain)
    return best if best and best.gain > 0 else None

# IP-268 LCC：闭链有效性的前提是标定先验够强
def loop_closure(E_arms, T_AB, sigma_cal):
    xi = logm(inv(T_A) @ T_AB @ inv(T_B))
    return dict(residual=xi, valid=(sigma_cal <= SIGMA_CAL_MAX))

    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    allow = ICE['valid'] and ICE['n_eff'] >= K_MIN
    g = M.mint.choose_interaction(modes, o, M.budget) if (allow and U_epi > TAU_EPI) else None
    # 3) 闭链 + 联合风险
    lcc = M.lcc.loop_closure(E, M.T_AB, M.cal_prior.sigma)
    lamA, lamB = M.jrc.coupled_scale(U_ale, U_epi, U_ind=1-neff/len(E), lcc=lcc)
    if zcm['z_suspect'] or not ICE['valid']:
        lamA = lamB = max(lamA, lam_floor(U_ale+U_epi+(1-neff/len(E))))
        M.jrc.enable_joint_gate(True)
    # 4) 双臂各自选模态但联合认证（捕两臂一致相撞）
    modeA, modeB = select_modes(modes, lamA, lamB)
    kA, kB = M.jrc.joint_certified_prefix(modeA, modeB, M.arms, wm_preds)
    k = min(M.c_ras_wm.certified_prefix(A, ..., wm_preds), kA, kB)
    M.vqa_t.submit_async(neff, ICE, zcm, lcc, g)
    return k, (lamA, lamB), (modeA, modeB), (neff, ICE['valid'])
```

## 4. 推导

**引理 19（共识膨胀）** k 源共享共模份额 ρ 时，`P(wrong|agree)` 随 k 不下降（ρ→1 趋常），只有 n_eff 随 k 增长时才下降。系：共模下 k 只是重复次数，不是证据量。

**引理 20（n_eff 置信校准）** 融合均值标准误应为 1/√n_eff 而非 1/√k；朴素法过度自信 √(k/n_eff) 倍；用 n_eff 计价可恢复 1−α 覆盖率。

**引理 21（零增益与单调）** `VoI_ind(g)∝η(g)`；η=0 ⇒ 严格零增益；增益对去相关效力 γ 单调（`n_eff=k/(1+(k−1)ρ(1−γ))`）。系：再看一眼不是去相关。

**引理 22（一致性≠正确性）** `ξ≈d_obj−d_cal+ν`；LCC 检测真对象的 AUC 随 `d_obj/σ_cal` 单调，σ_cal→∞ 时→0.5；故 σ_cal 大时必须忽略 LCC。

**定理 18（严格包含 R69/R68）** n_eff=k ⇒ 逐指令等于 FLUID；n_eff=1 ⇒ 逐指令等于 CALM；中间保守插值，风险随 n_eff 单调不增。

**定理 19（共模联合安全）** 独立认证忽略共享扰动时联合失效含协方差项可破单臂界；JRC 联合门控恢复；相关保守消除两臂一致撞同一障碍。

**定理 20（可辨识边界）** 若 z_cm 落在所有 𝒜_dec 的零空间（∀g, η(g)=0），则任何仅用这些观测的方案都无法认证独立，合法证书必须 n_eff=1——这是信息论边界，不是算法缺陷。

## 8. 本轮最大风险

**一句话**：TANDEM 的安全论证押在「共同病因可被观测或扰动」上——但共模故障的签名恰是「无分歧」；当共同病因落在所有去相关动作的零空间、ICE 又因估计误差误判可辨识，系统会给一批**同源回声**签发「独立证据」证书，从而自信地执行一个所有传感器共同犯下的错误——把 R69 的「问错比不问更危险」升级为「**拿着一份‘已认证独立’的证书，集体犯错**」。

**次级风险与缓解**：伪一致闭链（LCC 条件于外生标定先验，σ_cal 大强制忽略，定义 318/引理 22）；共模投毒/共享环境攻击（ℰ_tandem 对抗训练 + CMD 主动扰动，定义 324/引理 19）；去相关越界（C-RAS-WM 认证 + b_ind，定义 315/322）；两臂一致撞障碍（JRC 联合门控 + split-brain 禁止，定义 319–320/定理 19）；无限求证瘫痪（b_ind 硬约束 + 零增益剪枝，定义 322/引理 21）。
