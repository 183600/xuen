# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「全身控制」×「视觉定位」）

> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**身体落地 + 帧落地 + 证书传播**。v9 把"决策"做成了带证书的动作块，但有两笔从未入账的隐藏前提：其一，**身体债**——块证书在任务空间成立，却默认存在一个能把它变成关节力矩的执行器；任务空间安全 ≠ 动力学可行，CoM 可以越出支撑多边形、力矩可以饱和、接触可以打滑。其二，**帧债**——所有几何证书都默认基座位姿 ξ_t 已知；但视觉定位提醒我们，帧本身是被推断出来的随机变量，会多峰、会漂移、会在重复纹理场景"高置信地错"。两个灵感分别治这两种债，并用**定位-身体耦合证书**把二者合成一个可退化回 v9 的机制。

## 0. 直觉与动机

### 灵感 1（全身控制 → 决策证书必须穿过身体动力学）

**直觉**：v9 的 ActionChunkCertifier 像一位只看图纸的工程师：它检查末端的净空、抓取姿态、能耗，然后签发块证书。但图纸安全不等于房子能盖起来——同一条末端轨迹，放进"浮动基座 + 躯干 + 双臂 + 接触约束"的全身系统，可能要求 CoM 越出脚底支撑、要求某个关节力矩超过电机上限、或要求手部接触力落到摩擦锥外。全身控制（WBC）正是"任务空间意图 → 关节力矩"的实现算子：它在一组严格任务优先级下求解分层 QP，把 M₀ 安全写成硬约束、把 M₁–M₃ 任务写成软目标。核心创新：**全身任务栈（WholeBodyTaskStack, WBTS）**，并把块证书升级为**全身块证书** Ĉ_t^W：除 v9 的净空/能耗/抓取外，额外携带接触力锥裕度、力矩裕度、CoM 捕获点裕度与关节限位裕度。关键纪律 **P13 身体可行性前置律**：不可行的块在生成阶段就被拒绝，而不是执行到一半才发现"身体做不到"。

**严谨化**：v9 的安全论证只到任务空间证书；v10 必须补上"证书 → 动力学 → 力矩"这一段。若分层 QP 的硬约束集合非空，则任何满足 M₀ 的解都不会违反安全；若集合为空，WBTS 返回不可行标志，AC 必须否决该候选或降为 K_eff=1 的逐步模式。这样"块证书有效"第一次意味着"存在一条满足安全硬约束的力矩序列"，而不只是"末端轨迹看起来安全"。

### 灵感 2（视觉定位 → 帧是隐藏状态变量）

**直觉**：v9 的 SpatialCert 与 SPR 都活在地图坐标系里，仿佛机器人确切知道自己站在哪。真实系统里，基座位姿由视觉惯性定位/重定位给出：它带协方差，可能在两条相似走廊之间多峰，可能在"被搬走"（kidnapped）后整片失效。最危险的不是"定位不准"，而是**高置信地错**——系统以为自己在 A 房间，于是 SpatialCert 为一条实际上会撞墙的轨迹签发了证书。核心创新：**视觉定位信念（VisualLocalizationBelief, VLB）** 把位姿表示为加权多假设混合 b_t(ξ)={(ξ_i,w_i,Σ_i)}，并显式输出别名分数 α_t 与重定位标志；**定位感知证书器（LocalizationAwareCertifier, LAC）** 用置信椭球/机会约束把 Σ 膨胀进几何证书，并用任务雅可比把位姿协方差传播到末端/CoM 空间。纪律 **P14 帧不确定度传播律**：任何进入证书的几何量都必须带一个 1−ε 置信半径；**P15 多假设最坏情形律**：证书必须对权重超过 w_min 的所有假设同时成立，尾部质量超过 ε_tail 就禁止运动、转重定位，而不是挑"最像"的那个假设赌一把。

**严谨化**：把位姿误差 e=ξ̂−ξ 看成零均值随机向量（高斯或同协方差的次高斯），几何净空对 e 满足 Lipschitz 界。于是"用 ξ_i 估计的净空 ĝ_i 减去置信半径 r_i(ε)"构成真实净空的下界，失败概率 ≤ε；对混合信念取加权最坏情形，碰撞概率 ≤ε+ε_tail。定位从"一个必须正确的输入"变成"一个可计入证书的概率预算"。

### 灵感 3（二者耦合 → 可信赖可达性，以及"用身体去定位"）

**直觉**：身体与帧不是两个独立补丁，它们在雅可比里相乘。位姿协方差沿接触/末端雅可比放大成任务空间误差；反过来，全身系统又是**能动的传感器**——转头、转身、换个视角可以降低定位熵。核心创新：**主动定位调度器（ActiveLocalizationScheduler, ALS）** 把"看哪里/往哪转"建模成 WBC 的一个任务，优先级严格低于 M₀，只在**已认证的可采集集** A_loc 内最大化信息增益/风险比。纪律 **P16 主动定位不越权律**：定位机动本身必须通过全身证书；信息增益再大，也不能以安全为代价；M₀ 一触发，主动定位任务立即被抢占。

**严谨化**：主动定位动作 a_loc 必须属于 A_loc={a : C^W(a) 有效且 R(a)≤R_max}；其任务优先级置于 M₀ 硬约束之下，故分层 QP 的可行性保证不会被它破坏。信息增益按互信息 IG(a)=H(b_t)−E[H(b_{t+1}|a)] 计算，只有 IG(a)≥IG_min 的动作才被考虑，从而排除"原地反复看"的 Zeno 循环。

**一句话综合**：v9 管"该做什么、算力怎么分"；v10 管"身体做不做得到、我站在哪个世界里"。任务证书、身体证书、帧证书构成一条**可组合的可信执行链**，且每一环失效都能以中立元退回 v9。

## 1. 研究问题（轮次升级版）

- **Q1（身体证书可靠性）**：如何让任务空间的块证书与全身 QP 的硬约束在数学上对齐，使"块证书有效 ⇒ 存在满足 M₀ 的力矩序列"？在接触模式切换、摩擦锥、力矩饱和与关节限位下，证书裕度如何定义才既保守又可实现？
- **Q2（帧证书可靠性）**：如何在多峰、非高斯、重复纹理的视觉定位下构造几何证书，既不漏掉真实碰撞风险，又不因过度膨胀而永久停摆？别名导致的"高置信错误"如何被检测，而不是被加权平均掉？
- **Q3（耦合与退化边界）**：主动定位何时可以扰动全身运动而不抢占安全任务？如何证明 WBTS/VLB/LAC/ALS 的中立元配置逐位等价退回 v9，且单模块失效不产生 v9 认证动作集之外的新动作？

## 2. 设计原则（在 P7–P12 基础上新增 P13–P16）

**P13 身体可行性前置律（Whole-Body Feasibility First, WBTS）**
动作块在进入执行前必须由分层全身 QP 验证：存在接触调度 σ^{1:K}、力矩序列 τ^{1:K}、接触力 λ^{1:K}，使动力学方程、摩擦锥、力矩/关节限位、自碰撞与 CoM 捕获点约束同时成立。验证失败 ⇒ 该块不可执行，退回候选选择或 K_eff=1；绝不"先执行再说"。

**P14 帧不确定度传播律（Frame-Uncertainty Propagation, VLB+LAC）**
任何进入几何证书的位姿量都写成信念 b_t(ξ) 而非点估计，并按置信水平 1−ε 取半径 r(Σ,ε)；任务空间误差由 Σ_i^task=J_iΣ_ξJ_i^T+J_iΣ_modelJ_i^T 传播。证书只接受"估计净空 − 置信半径 ≥ d_safe"的块；置信半径不可被学习型模块调到 0。

**P15 多假设最坏情形律（Multi-Hypothesis Worst-Case, LAC）**
证书必须对所有权重 w_i≥w_min 的定位假设同时成立；被排除的尾部质量 Σ_{w_i<w_min}w_i 必须 ≤ε_tail，否则禁止任务运动并请求重定位。别名检测用跨模态一致性（视觉地点 vs 激光/本体里程计）与时间一致性，而不是只取最大后验假设。

**P16 主动定位不越权律（Certified Active Localization, ALS）**
主动定位是 WBC 任务栈中的最低安全优先级任务，动作必须取自已认证可采集集 A_loc；IG(a)≥IG_min、R(a)≤R_max；M₀ 硬约束或自保包络触发时无条件抢占。主动定位只能"在已证明安全的动作里选信息量最大的"，不能"为了看得更清楚而先冒险"。

## 3. 与基线的接口（如何退化）

v10 采用**依赖闭包退化**：新模块之间不是并列的，而是有依赖的；失效沿依赖边级联，保证每一级都落到一个明确的 v9 行为：

- **WBTS 失效**（QP 不可行或自身超时）⇒ 执行器直通 `v9_Executor`：v9 的动作块按原控制律展开，证书退回 v9 Ĉ_t；
- **VLB 失效** ⇒ 单假设、Σ≡0、位姿取 v9 SLAM 输出；LAC 与 ALS 因依赖 VLB 一并中立 ⇒ 证书退回 v9 SpatialCert；
- **LAC 失效** ⇒ 证书退回 v9 SpatialCert；WBTS 因失去身体门控一并退回 `v9_Executor`（依赖闭包）；
- **ALS 失效** ⇒ 仅关闭主动定位任务，证书与执行不变；由于 ALS 只可能添加"已认证动作"，它的缺席仍在 v9 认证动作集内，故安全；
- **四者全失效** ⇒ 逐位等价 v9 MetricVoiceGauge-ACMD（引理 91），可继续沿 v9→v8→v7→v6 退化；
- **真实定位退化**（Σ_loc>τ_loc 或尾部质量>ε_tail）不视为"模块失效"，而进入 **M₀ 自保包络**：零任务速度、扩大支撑、受控减速停驻，并请求重定位（定义 549）。这是 v10 明确新增的安全行为，必须单独实验（E576），不能伪装成 v9；
- **v9 的 AC/MW/ID 任一失效** ⇒ 按 v9 链接回 v8；v9 的 DA/SPR/Cal 失效 ⇒ 中立元注入，按 v9 链接回 v7。

## 4. 预期贡献

1. **全身可行性证书**：把 v9 的任务空间块证书扩展为"净空 + 接触锥 + 力矩 + CoM 捕获 + 关节限位"的联合证书，使块级安全第一次穿过浮动基动力学；给出硬约束不变性与不可行即拒绝的证明。
2. **帧不确定度演算**：多假设视觉定位信念 + 机会约束几何膨胀 + 任务雅可比协方差传播，把"位姿可能错"变成可计算的概率预算；多假设最坏证书正面处理重复纹理下的"高置信地错"。
3. **认证主动定位**：把转头/转身/换视角建模为受证书约束的 WBC 任务，以信息增益/风险比调度，并证明其永不抢占 M₀ 安全任务。
4. **可组合退化代数**：依赖闭包 + 中立元表，使 WBTS/VLB/LAC/ALS 全失效时逐位退回 v9，单模块失效不产生 v9 之外的新动作；新增自保包络与 v9 退化明确分账。
5. **实验闭环 E571–E590**：覆盖全身任务成功率、接触滑移、力矩饱和、定位协方差校准、别名注入、 kidnapped 重定位、机会约束碰撞率、主动定位非干扰、仿真到实机与 8h 长跑。

## 5. 本轮最大风险

**一句话**：视觉定位的多峰、非高斯与重尾特性，使"置信椭球 + 权重阈值 w_min"在最需要全身精度的重复纹理、镜面与对称场景里恰恰最不可靠——若别名假设的权重被系统性低估到 w_min 以下，系统会在"高置信地错"的帧里为一条全身动作签发假证书，即**帧证书在最需要它的时候最脆弱**。

**新增定义 540（浮动基全身状态与接触模式）**
全身位形 q=(ξ_b,q_j)∈SE(3)×R^{n_j}，广义速度 ν=(v_b,q̇_j)。接触模式 σ∈{0,1}^{n_c}，接触集 C(σ)。运动方程与约束：

```
M(q)ν̇ + h(q,ν) = S^T τ + Σ_{c∈C(σ)} J_c^T λ_c
λ_c ∈ K_c(μ) = {λ : λ_n≥0, ||λ_t|| ≤ μ λ_n}
τ ∈ [τ^-, τ^+],  q ∈ Q,  d_self(q) ≥ 0
```

v9 的动作块 a^{1:K} 在 v10 中解释为任务空间参考轨迹 (J_i, ẍ_i^des)；WBTS 负责把它解成力矩序列 τ^{1:K}。任务空间安全与力矩安全由此第一次被显式连接。

**新增定义 541（全身任务栈与分层 QP）**
任务栈 T={T_i=(J_i,ẍ_i^des,ρ_i,φ_i)}_{i=0..L}，优先级严格递减。M₀ 任务（ρ=hard）包括：末端/身体碰撞距离、CoM 捕获点、接触摩擦锥、力矩/关节限位、自碰撞、接触调度可达性；M₁–M₃ 为软任务（操作精度、姿态、能耗、可操作性）。对每个块内步 k，WBTS 求解：

```
τ^k = argmin_{ν̇,τ,λ}  Σ_{i∈soft} ||J_i ν̇ − a_i^des||²_{W_i}
s.t.  定义 540 的动力学与全部等式/不等式约束
      m_capture(ν̇) = d_capture(ν̇) − d_safe ≥ 0
      低优先级任务只能在 std 高优先级约束的可行域内优化
```

输出 τ^{1:K}、σ^{1:K} 与逐步裕度向量 m(k)=(m_wrench,m_torque,m_capture,m_joint,m_self)(k)。若任一 k 的硬约束集为空，返回 `infeasible`，不产生力矩。

**新增定义 542（全身块证书 WholeBodyChunkCertificate）**
```
Ĉ_t^W = ( Ĉ_t^{v9}, σ^{1:K},
          m_min = min_k min(m_wrench,m_torque,m_capture,m_joint,m_self)(k),
          ρ_τ   = max_k ||τ^k|| / τ_max,
          σ_reach )
```
证书有效 ⇔ Ĉ_t^{v9}.valid ∧ m_min ≥ 0 ∧ ρ_τ ≤ 1−δ_τ ∧ σ_reach=true。其中 σ_reach 由接触调度器验证：相邻接触模式可在剩余时间内建立/解除，且切换过程不产生碰撞或失稳。m_capture 使用线性倒立摆捕获点：
```
d_capture(ν̇) = dist(ξ_CoM + v_CoM/ω₀, ∂P_support) − d_safe,  ω₀=√(g/z_CoM)
```

**新增定义 543（视觉定位信念 VisualLocalizationBelief）**
```
b_t(ξ) = Σ_{i=1}^{H} w_i · N(ξ; ξ_i, Σ_i),   Σ_i w_i = 1, H ≤ H_max
α_t = 1 − max_i w_i,   H_t = −Σ_i w_i log w_i
w_tail(t) = Σ_{i: w_i < w_min} w_i
```
更新由视觉惯性因子图给出各假设的局部后验；地点识别可**新生**假设（重定位/绑架检测），跨模态一致性（视觉地点描述子 vs 激光/本体里程计）与时间一致性负责**合并/剪枝**。每个假设带年龄 a_i；仅当 w_i<w_prune 且 a_i>T_prune 时才删除。VLB 不输出单一"最佳位姿"，而输出带权混合、别名分数与尾部质量。

**新增定义 544（定位感知净空与机会约束）**
设净空 g 对位姿误差满足 Lipschitz 界：|g(ξ_i)−g(ξ_true)| ≤ L_g||ξ_i−ξ_true||。取
```
r_i(ε) = L_g · sqrt( χ²_{d,1−ε} · λ_max(Σ_i) ) + r_map
g_i(k) = dist(proj_{ξ_i}(s_k), O) − r_i(ε) − d_safe
g_loc(k) = min_{i: w_i ≥ w_min} g_i(k)
```
若 g_loc(k)≥0，则在信念校准且真实位姿落在 1−ε 置信椭球内的条件下，第 k 步真实净空 ≥d_safe 的概率至少 1−ε−w_tail。这里 r_map 是地图/标定误差的固定膨胀，不允许被学习型模块自适应压到 0。

**新增定义 545（任务不确定度预算 UncertaintyBudget）**
任务 i 在方向 u 上的任务空间协方差与预算：
```
Σ_i^task = J_i^ξ Σ_ξ J_i^{ξT} + J_i^q Σ_model J_i^{qT}
β_i(u) = z_{1−ε} · sqrt( u^T Σ_i^task u )
```
规则：M₀ 任务若 β_0(u)>β_0^max(u) ⇒ 直接 veto（进入自保包络或 K_eff=1）；软任务若 β_i>β_i^max ⇒ 降级/松弛该任务（例如把精确抓取改为护持式触觉搜索），不得反过来放松 M₀。全体任务预算满足 Σ_i β_i(u_i) ≤ B_unc（优先级加权分配）。

**新增定义 546（主动定位与可采集集 CertifiedActiveLocalization）**
主动定位动作 a_loc=(目光方向, 基座偏航/微位移, 观察驻留) 属于离散/连续混合集合。可采集集与评分：
```
A_loc = { a : C^W(a).valid ∧ R(a) ≤ R_max }
IG(a) = H(b_t) − E[ H(b_{t+1} | a) ]              （互信息）
score(a) = IG(a) / (R(a) + η)
```

**新增定义 547（多假设最坏证书与别名门 MultiHypothesisCertificate）**

C_t^W.valid ⇔ ( ∀i: w_i ≥ w_min ⇒ C_{t,i}^W.valid )

# IP-357 WholeBodyTaskStack：浮动基分层 QP 与全身块证书
class WholeBodyTaskStack:
    def __init__(self, n_j, mu=0.6, dt=0.02, tau_max=None,
                 delta_tau=0.05, d_safe=0.02):
        self.n_j, self.mu, self.dt = n_j, mu, dt
        self.tau_max, self.delta_tau, self.d_safe = tau_max, delta_tau, d_safe

    def solve(self, q, nu, task_stack, contact_schedule):
        """返回 TorqueTrajectory(tau, sigma, margins) 或 Infeasible"""
        tau_seq, margins = [], []
        for k, sigma in enumerate(contact_schedule):
            qk, nuk = self._predict(q, nu, tau_seq, sigma)
            # M0 硬约束：碰撞、CoM 捕获、摩擦锥、力矩、关节、自碰撞
            hard = self._hard_constraints(qk, nuk, sigma)
            if not hard.feasible:
                return Infeasible(reason=hard.reason, k=k, sigma=sigma)
            # 严格优先级：软任务只在硬约束零空间内优化
            tau_k, nu_dot_k, lam_k = self._hierarchical_qp(
                qk, nuk, sigma, task_stack, hard)
            m = self._margins(qk, nuk, tau_k, lam_k, sigma)
            tau_seq.append(tau_k); margins.append(m)
        if min(min(m.values()) for m in margins) < 0.0:
            return Infeasible(reason="margin", margins=margins)
        return TorqueTrajectory(tau_seq, contact_schedule, margins)

    def _margins(self, q, nu, tau, lam, sigma):
        return {
            "wrench":  min(1.0 - abs(l[1:]).sum() / (self.mu * l[0] + 1e-9)
                           for l in lam),          # 摩擦锥归一化裕度
            "torque":  min(1.0 - abs(t) / self.tau_max[j]
                           for j, t in enumerate(tau)),
            "capture": (self._capture_dist(q, nu) - self.d_safe),
            "joint":   min(min(q[j] - lo, hi - q[j]) for j, (lo, hi)
                           in enumerate(self.joint_limits)),
            "self":    self._self_collision_dist(q) - self.d_safe,
        }

# IP-359 LocalizationAwareCertifier：定位感知 + 多假设最坏证书
class LocalizationAwareCertifier:
    def __init__(self, L_g=1.0, r_map=0.01, eps=0.01,
                 w_min=0.15, eps_tail=0.02, alpha_max=0.75):
        self.L_g, self.r_map, self.eps = L_g, r_map, eps
        self.w_min, self.eps_tail, self.alpha_max = w_min, eps_tail, alpha_max

    def radius(self, Sigma):
        return (self.L_g * math.sqrt(chi2_ppf(1 - self.eps)
                                     * max_eig(Sigma)) + self.r_map)

    def certify(self, b, wbc_cert, geometry):
        if b.alpha > self.alpha_max or b.tail > self.eps_tail:
            return Cert.invalid("aliasing")
        for mode in b.modes:
            if mode.w < self.w_min:
                continue
            r = self.radius(mode.Sigma)
            g = geometry.min_clearance(mode.xi, inflate=r) - self.d_safe
            if g < 0 or not self._task_budget_ok(mode, wbc_cert):
                return Cert.invalid(f"mode_{mode.id}")
        return Cert(valid=True, worst_clearance=g,
                    task_budget=self._budget(wbc_cert), modes=b.modes)


# IP-360 ActiveLocalizationScheduler：认证主动定位
class ActiveLocalizationScheduler:
    def __init__(self, R_max=0.1, IG_min=0.05, T_dwell=5, eta=1e-3):
        self.R_max, self.IG_min, self.T_dwell, self.eta = R_max, IG_min, T_dwell, eta
        self.last_action, self.dwell = None, 0

    def plan(self, belief, cert, candidates):
        feasible = [a for a in candidates
                    if cert.valid(cert.reevaluate(a)) and a.risk <= self.R_max]
        if not feasible:
            return None
        scored = [(self.info_gain(belief, a) / (a.risk + self.eta), a)
                  for a in feasible]
        score, best = max(scored, key=lambda x: x[0])
        if score < self.IG_min or best == self.last_action and self.dwell < self.T_dwell:
            return None
        self.last_action, self.dwell = best, 0
        return best

## 4. 推导

**引理 87（分层 QP 的硬约束不变性）**
设每个块内步 k 的 M₀ 硬约束集为 H_k，分层 QP 对优先级 p=0,1,...,L 依次求解，且优先级 p 的约束/最优解集作为优先级 p+1 的可行域。若 H_k 非空，则 (i) 任何输出 τ^k 满足全部 M₀ 硬约束；(ii) 任一软任务不可行只会导致该任务被松弛，不会改变 H_k 的可行性；(iii) 若 H_k 为空，WBTS 返回 `infeasible` 且不产生力矩。

证明：由构造，优先级 p+1 的可行域 F_{p+1}⊆F_p，归纳得 F_L⊆F_0=H_k；软任务只出现在目标函数中，不参与约束删除。接触调度 σ^{1:K} 的可达性由 σ_reach 另行验证；若不可达则整个块被拒绝。故 τ^k∈H_k，且不可行时无输出。∎

**引理 88（定位感知净空的机会约束可靠性）**
设真实位姿 ξ_true 与假设 ξ_i 的误差 e_i=ξ_i−ξ_true 满足 e_i^TΣ_i^{-1}e_i≤χ²_{d,1−ε}（高斯假设或同协方差次高斯界），净空对位姿误差满足 Lipschitz 界 L_g。取 r_i(ε)=L_g√(χ²_{d,1−ε}λ_max(Σ_i))+r_map、g_i=dist(proj_{ξ_i}(s),O)−r_i−d_safe。若 g_i≥0，则真实净空 g_true≥d_safe；失败概率 ≤ε。

证明：由椭球约束，||e_i||≤√(χ²_{d,1−ε}λ_max(Σ_i))。Lipschitz 性给出 |g_true−ĝ_i|≤L_g||e_i||。于是 g_true≥ĝ_i−L_g||e_i||−r_map≥ĝ_i−r_i+d_safe−r_map≥d_safe。对混合信念，真实假设的失败概率按权重加权：Pr(fail)≤Σ_i w_iε_i+w_tail≤ε+w_tail。∎

**引理 89（多假设最坏证书的别名安全界）**
若 LAC 对每个 w_i≥w_min 的假设要求 C_{t,i}^W 有效，且 w_tail≤ε_tail，则在信念校准的前提下，任意 v10 认证块的真实碰撞概率 ≤ε+ε_tail；若存在高权重错误假设，最坏证书会因该假设的几何/任务预算失败而拒绝该块（而非取最大后验赌一把）。

证明：由引理 88，对真实假设 i*，若 w_{i*}≥w_min，则失败概率 ≤ε；若 w_{i*}<w_min，则其总概率质量 ≤w_tail≤ε_tail。对所有高权重假设取合取只会降低接受概率、不会提高真实失败概率上界。别名门 d_alias>τ_alias 时禁止运动并重定位，将"高置信错误"转为可观测事件；其漏检风险由 ε_tail 与 w_min 的标定实验（E575）度量。∎

**引理 90（主动定位不抢占安全 / 无 Zeno）**
ALS 只向 WBC 任务栈追加一个优先级严格低于所有 M₀ 硬约束的任务，且只从 A_loc（先经 C^W 认证）中选择。由引理 87，M₀ 可行性与硬约束不变性不受影响；M₀ 或自保包络触发时该任务被 O(1) 抢占。若 IG(a)<IG_min 或 A_loc 为空，ALS 返回被动；结合最短驻留 T_dwell 与切换代价，接受的主动定位动作数在有限时域内有界，不会形成无限抖振。

证明：分层 QP 中低优先级任务位于高优先级约束的零空间，不能改变 H_k；A_loc 的定义要求每个候选动作的 C^W 有效，故不引入未认证动作。每次接受的动作用 IG≥IG_min 且驻留≥T_dwell，有限动作集与有限时域给出有限次切换；若不存在可行动作则被动，排除 Zeno。∎

**引理 91（中立元退化与 v9 逐位等价）**
按定义 548 将 WBTS/VLB/LAC/ALS 替换为中立元并执行依赖闭包，则 v10 每个函数与 v9 对应函数在同输入下同输出；四者全中立时主闭环逐位等价于 v9 MetricVoiceGauge-ACMD。

证明：ALS 中立 ⇒ 不追加任务；LAC 中立 ⇒ 返回 v9 SpatialCert；VLB 中立 ⇒ ξ=ξ_v9、Σ=0、单假设、α=w_tail=0，故 LAC（即使未中立）的膨胀半径为 0 且最坏情形退化为单点几何；WBTS 中立 ⇒ τ=v9_Executor(chunk)，不做动力学门控。逐项代入后，AC、MW、ID 及 v8/v7 继承路径均未改动，输入相同、输出相同，日志逐位一致。单模块失效时依赖闭包先级联其中立化依赖者，再套用上述替换，故仍落到 v9。∎

**引理 92（v10 严格包含 v9，且继承 v9 安全性）**
(i) 当 Σ_loc=0、忽略身体裕度门（m_min 阈值取 −∞）且接触调度固定为 v9 的标称步态时，Ĉ_t^W 退化为 Ĉ_t^{v9}；(ii) 对任意 v10 认证块，Ĉ_t^W.valid ⇒ Ĉ_t^{v9}.valid，故 v9 的引理 80–86 对其继续成立。

证明：(i) 逐项对照定义 542 与 v9 定义 533 即得；(ii) 定义 542 的 valid 是 Ĉ_t^{v9}.valid 与其他条件的合取，故蕴含关系成立。v10 只是在 v9 证书上叠加身体与帧条件，而不替换它；因此 v9 的安全传递链完整保留，v10 新增的是更保守的拒绝域。∎

**推论 92.1（自保包络与退化分账）**
定义 549 的自保包络不满足引理 91 的"中立元"前提，故不声称等价 v9；它只在定位真实退化时触发，且行为是安全停驻的子集。v10 的安全主张因此分两层：模块失效 ⇒ v9 等价退化；定位退化 ⇒ 自保包络 + 重定位请求。二者必须分别由 E583 与 E576 验证。∎

## 8. 本轮最大风险

**一句话**：视觉定位的多峰、非高斯与重尾特性，使"置信椭球 + 权重阈值 w_min"在最需要全身精度的重复纹理、镜面与对称场景里恰恰最不可靠——若别名假设的权重被系统性低估到 w_min 以下，系统会在"高置信地错"的帧里为一条全身动作签发假证书，即**帧证书在最需要它的时候最脆弱**。
