# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配×主动交互不确定性二分闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「抓取规划」×「通用机器人平台」）

> R69 让闭环第一次学会「问」：把 epistemic 歧义交给看/问/触，用 VoI 判断值不值得问，并以「k 个正交证据一致」防止单源定案。但它的动作空间是**扁平且默认可逆**的：注视、探针、问句都隐含「问了还能反悔」，于是 VoI 只需减掉社交/物理成本。真实机器人里最关键的交互恰恰**不可逆**——**抓取**。手指闭合的一刻，系统同时完成了测量（摩擦、质量、顺从性）与承诺（接触构型、负载路径），并把一部分 epistemic 事后永久转成 aleatoric；抓错了不是「再问一次」，而是掉落、损坏、或错过任务。R69 的 `VoI−c` 没有给这份不可逆性定价，也没有给「被放弃的更好抓法」这一期权损失定价。
>
> 第二个缺口来自 R69 的雄心：**通用机器人平台**要在长尾任务间复用同一套抓取技能与同一套校准。R69 的 MCG 只在「当前模型、当前任务」上守门，它回答不了平台最贵的问题：**我在任务 A / 物体 A 上校准出的模态权重与安全证书，凭什么信到任务 B / 物体 B？** 一个通用平台若把「已校准」当成全局属性，就会把 R69 的「问错」放大成「在错误的任务上盖已验证的章」。
>
> 核心命题（PACT-RAS）：**把抓取视为承诺谱系上的「不可逆提问」，用期权价值为不可逆性定价（CVO）；把通用平台视为「局部校准的联邦」而非全局校准，用可迁移校准账本（TCL）、证书覆盖域（CCF）与有效独立源（k_eff）把复用变成可验证的断言；同时把任务意图当作免费的模态先验，剪掉 R69 最怕的幻影模态。** 当谱系只允许「看」、平台只剩单任务、覆盖域退化为全空间时，PACT 严格退化为 FLUID-RAS。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「测量还准吗」，R69 问「该向谁求证」，R70 问「**这次求证会把什么永久押上去，且这个答案能不能带到下一个任务**」——不确定性不仅可以是提问，也可以是一次**不可撤回的签字**。

## 0. 直觉与动机

**灵感 1（抓取 = 不可逆的提问：动作与测量的同一性）**
直觉：看/问/触都可以「试探后撤回」，抓取不行。闭合夹爪既是感知动作也是承诺动作：它给你摩擦与质量的读数，同时把你锁进一个接触构型。形式上，抓取是一个**带泄漏的测量通道** K_ℓ：它把一部分 epistemic 转成不可约的接触 aleatoric（姿态不确定性变成摩擦/接触不确定性），且一次只测一个分支、关掉其他分支的期权。R69 的 VoI 只优化「问完是否更确定」，PACT 还要优化「这种问法是否值得押上不可逆成本与被放弃的期权」。

**灵感 2（通用平台 = 校准的联邦，而非全局真理）**
直觉：平台越大，越诱人做「一次校准、处处复用」。但抓取校准高度依赖物体分布、末端执行器与场景几何。可迁移性不是布尔值，而是**带证明的断言**：源域 ECE + 分布距离 × Lipschitz 常数 ≤ 阈值，才允许迁移；否则在覆盖域外必须重校准或退回保守。平台的正确形态是**局部校准联邦**，每个「技能 × 物体类 × 末端执行器」组合一张账本，复用走「证据签证」而非「口碑」。

**灵感 3（任务意图 = 免费的模态先验 → 正面还击 R69 最大风险）**
直觉：R69 最怕流模型幻觉出不存在的模态、驱动无效追问。抓取规划给出一个此前没有的约束：**并非所有抓取模态都服务于当前任务**。能以 0.99 权重稳稳抓住杯子、却无法把水倒出来的抓法，对「倒水」不是有效模态。用任务可负担性 A(m,τ) 给模态权重乘一个软先验，幻影模态（高几何权重、零任务可负担性）在进入 VoI 之前就被剪掉。这把 R69 的「模态分布是否可信」从**纯生成问题**变成**生成 × 任务可行性**的联合问题，风险面显著变窄。

**灵感 4（承诺谱系 = 把扁平动作空间变成有序、可认证的等级）**
直觉：人类抓取不是一步到位，而是「看→伸手悬停→轻触→合拢→提起」，每级都在买信息、卖可逆性。把 R69 的扁平 𝒜_info 替换为有序谱系 ℓ=0..5，使「值不值得升级承诺」成为一个**最优停时**问题：当期权价值高于承诺收益时，停在可逆级继续看；只有当消歧收益压过不可逆成本与期权损失时才升级。R69 正是 ℓ=0 的边界。

**灵感 5（平台级证据纪律：从「数来源」到「数有效独立度」）**
直觉：R69 的「k 个正交源一致」在平台上会退化成「凑两个都来自同一基础模型的源」。PACT 用有效独立源 k_eff 取代计数：`k_eff=(Σw)²/(Σw²+Σ_{i≠j}ρ_ij w_i w_j)`。共享幻觉或共谋使 ρ→1、k_eff→1，自动作废「伪正交」；证书还必须可溯源、可撤回——一旦发现某源漂移，撤销它签发的所有结论。

**灵感 6（承诺与迁移必须同层，否则会互相掩盖）**
直觉：单看承诺，系统会为了省一次抓取而冒险跳级；单看迁移，系统会为了复用证书而忽略当前接触风险。两者真正的关系是：**承诺产生新证据，证据更新账本，账本决定下一次承诺能否复用**。若把「承诺」与「迁移」做成两个独立模块，故障会互相掩盖——不可逆失误被记成「分布外」，迁移误差被记成「接触噪声」。PACT 强制二者共享同一套证据池与审计轨迹。

## 1. 形式化定义（增量：定义 310–325）

**假设**：A99（模态密度在 τ_ece 内已校准）；A100（可负担性 A(m,τ) 对模态原型 Lipschitz，常数 L_A）；A101（接触转换算子 ‖K_ℓ‖≤1，测量不增信息）；A102（校准误差对域偏移 Lipschitz，常数 L_cal）；A103（欺骗源相关 ρ_ij<1、有界）；A104（每级承诺存在控制屏障函数 h_ℓ，安全集前向不变）。

**定义 310（PACT-RAS 总览）** PACT-RAS = (GCL, TMS, CVO, TCL, CCF, EAP, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **承诺单调与不可逆预算**：承诺等级只能沿谱系逐级提升，ℓ≥3 的不可逆承诺单位时间 ≤1 次且必须通过 C-RAS-WM‡；不得跳级；回退只能在安全包络内执行；
(iii) **迁移显式性**：任何跨任务/跨物体复用校准或证书，必须提交覆盖域证明与迁移界；不满足则回落到当前情境的单任务保守校准（强化 R69 的 MCG，而不替换它）；
(iv) **证据纪律 ∧ 承诺纪律**：不可逆级信息动作不得单独定案，需 `k_eff ≥ 2` 或后验熵降至阈值下；只有在可逆级已耗尽、或承诺的期望价值严格超过期权价值时才升级。

**定义 311（抓取承诺谱系 GCL）** 等级 `ℓ ∈ {0,…,5}`：ℓ0 观察（gaze）、ℓ1 悬停/预抓取（align）、ℓ2 轻触探针（probe，力 ≤ f_touch）、ℓ3 闭合夹持（未提起）、ℓ4 提起/负载（lift）、ℓ5 换手/放置（handoff/place）。每级带可逆性 `ρ_ℓ∈[0,1]`（1 为完全可逆）、不可逆成本 `c_irr(ℓ)`（损坏/掉落/超时）、信息产出 `y_ℓ`、动作 `ξ^ℓ=(a^ℓ,g^ℓ)`。关键：**ℓ≥3 是 committed information action——动作即测量，测量即承诺**。状态为（模态后验 b，当前等级 ℓ）。

**定义 312（接触转换算子）** 承诺到 ℓ 后，信念按两部分更新：
`U_epi(ℓ⁺) = (I−K_ℓ) U_epi(ℓ⁻) + U_amb^τ`，
`U_ale(ℓ⁺) = U_ale(ℓ⁻) + tr(K_ℓᵀ U_epi(ℓ⁻) K_ℓ) + U_contact(ℓ)`。
`K_ℓ` 是抓取对模态不确定性的**吸收矩阵**：被接触"测掉"的 epistemic 有 `‖K_ℓ‖` 的比例变为不可约的接触噪声（摩擦/顺从性/微滑），不再能用任何提问消除。A101 保证 `‖K_ℓ‖≤1`；`U_amb^τ` 是任务语义本身残余的歧义。R69 只在 ℓ0 更新（`K_0=0`），故看不到这种「测量反而制造噪声」的代价。

**定义 313（承诺感知信息价值 CVO）** 定义升级到 ℓ 的净价值
`CVO(ℓ) = VoI(g^ℓ) + E[V_info(y_ℓ)] − c_phys − c_social − c_irr(ℓ) − ΔOV(ℓ)`，
其中期权损失 `ΔOV(ℓ) = OV(ℓ−1) − E[OV(ℓ)]`，
`OV(ℓ) = E_b[ max{ 0, max_{ℓ'>ℓ} CVO(ℓ') } ]` 为「保留继续选择权」的价值（最优停时/Bellman 备份）。选择 `ℓ* = argmax_ℓ CVO(ℓ)`，当且仅当 `CVO(ℓ*)>0` 才升级；否则停在当前可逆级继续观察。R69 的 `argmax_g[VoI−c]` 是 `L=0、ΔOV=0、c_irr=0` 的退化。

**定义 314（任务条件模态后验）** 流匹配给出几何模态 `{m_k, ŵ_k}`；引入任务 τ 的可负担性 `A(m_k,τ)=P(下游任务 τ 成功 | 以 m_k 抓取)`（由技能库的回放/仿真与少量实机标定给出）。任务条件后验
`p(m_k | o,τ) ∝ ŵ_k · A(m_k,τ) · L(o | m_k)`。
**只有任务相关的模态熵计入可约不确定性**：
`U_epi^τ = H(M | o,τ) · g(Δ_min^τ)`，其中 `Δ_min^τ` 只在 `A>ε_a` 的模态间取最小距离。
关键语义：**与任务无关的模态分裂（抓左/抓右对任务无差别）不是 epistemic，不值得花预算去问**。

**定义 315（目的论模态选择 TMS）** 模态得分 `s_k = ŵ_k · A(m_k,τ)`。剪枝：`A(m_k,τ) < ε_a` 的模态不进入 CVO 候选；若某模态 `ŵ_k` 高、支撑低、且与所有 `A>ε_a` 模态的 W₂ 距离 ≥ Δ_min，判为**任务不相容幻影**（phantom），记录但禁用。这是对 R69 定义 306（MCG）的前置补充：MCG 事后禁用不可信权重，TMS 事前剪掉语义上不可能的模态。

**定义 316（可迁移校准账本 TCL）** 平台维护追加式账本 `Ledger`，条目以 `(技能, 物体类, 末端执行器, 场景族)` 为键，记录 `(ECE, n, 分布指纹 P_c, 平台配置哈希, 时间戳, 证书号)`。账本只追加、可版本化回滚；任何复用必须引用具体条目，不接受「全局已校准」这种无来源断言。

**定义 317（迁移核与迁移门 TKB）** 源域 c 到目标域 c′ 的可用性由
`ECE_c' ≤ ECE_c + L_cal·W₁(P_c,P_c') + √(log(2/δ)/(2n))`
判定（A102）。记右端为 `B(c→c')`；仅当 `B ≤ τ_ece` 才允许迁移校准，否则强制在 c′ 上重校准或退回保守。`W₁` 用分布指纹上的切片 Wasserstein 近似，常数 `L_cal` 由账本中的历史迁移残差在线估计并给保守上界。

**定义 318（证书覆盖域 CCF）** 证书 J 的覆盖域 `Cov(J) ⊆ 物体类 × 任务 × 末端执行器 × 环境`，由**反例集/压力测试**经验确定，而非声明式。复用 J 到情境 s 当且仅当 `s∈Cov(J)` 且 `B(c→c')≤τ_ece`。定义覆盖缺口 `G = P_{s∼D_platform}[s∉Cov(J) | 请求复用]`；`G>τ_gap` 时平台级禁用跨任务复用（全局退回单任务保守）。

**定义 319（平台证据池与有效独立源 EAP）** 证据 `E_pool` 带来源、可追溯哈希、相关性估计。定义
`k_eff = (Σ_i w_i)² / (Σ_i w_i² + Σ_{i≠j} ρ_ij w_i w_j)`。
`ρ_ij→0` 时为参与率，`ρ_ij→1` 时为 1。定案条件从 R69 的「k≥2 个源」升级为「`k_eff≥2`」；并支持**撤回**：某源被审计判定漂移，则删除其贡献并重算结论与证书。

**定义 320（承诺屏障与安全）** 每级动作过 C-RAS-WM‡：力/位包络、物体脆弱性、人体邻近、可达性与时序窗。存在屏障 `h_ℓ(s)≥0` 使安全集在升级/回退控制下前向不变（A104）。承诺失败（滑落、超力、碰撞预警）触发**降载不瞬移**回退：先降到 ℓ2 轻触，再按屏障允许的速率张开，绝不跳过认证路径。

**定义 321（跨任务校准遗忘）** 平台持续学习时，新任务微调可能破坏旧任务校准。定义
`CF = max_c (ECE_c^{new} − ECE_c^{old})`。
`CF>τ_cf` 时冻结/回滚相关技能校准，并把账本条目标记为「需复检」。这把「灾难性遗忘」从权重空间搬到**校准空间**，与平台的多任务现实对齐。

**定义 322（PACT 证书 J_PACT）** `J_PACT = (J_FLUID, commitment_log, max_rung, c_irr_spent, transfer_proof_hash, coverage_id, k_eff_min, CF, pact_ver)`。Valid ⇔ Valid(J_FLUID) ∧ 承诺预算不越界 ∧ 迁移界与覆盖域证明通过 ∧ `k_eff_min≥2` ∧ `CF≤τ_cf`。

**定义 323（自适应承诺深度与实时预算）** 默认 K=1、N_step=2、承诺深度 L=1（只做一次前瞻）。仅当 `mode_head` 报歧义且 `CVO` 在候选级上符号不稳定时，才把候选级扩到 L=3 并升 K=4。承诺深度是**预算与停机价值的折中**，保证常规 P99 实时；只有等级切换允许一次性预算超支。

**定义 324（平台任务分布与覆盖缺口）** 平台任务分布 `D_platform` 为技能-任务混合。覆盖缺口 `G` 是平台级「诚实的不知道」：`G` 大表示平台被要求在大量未认证情境上复用。平台据此在**复用带来的样本效率**与**分布偏移带来的偏差**之间选择池化半径，而不是默认全局池化。

**定义 325（对 FLUID-RAS 的严格包含）** 当 `L=0`（只允许观察）、单任务（`D_platform={τ}`）、`Cov=全空间`、`A≡1`、`k_eff=k` 且 `c_irr=ΔOV=0` 时，PACT 的决策与 FLUID-RAS 逐指令相同；一般情形下 PACT 的期望风险不高于 R69 在同一等级截断下的策略，且在 `CVO≤0`、迁移界越界、`G>τ_gap` 或 `CF>τ_cf` 时退化为 R69 最保守。**新层是旧层的严格泛化，而非并列替代。**

```python
# IP-264 GCL：承诺谱系（等级、可逆性、不可逆成本、动作约束）
class CommitmentLadder:
    RUNGS = [  # l, name, rho, c_irr, info_yield
        (0, "gaze",   1.00, 0.00, "pose/identity"),
        (1, "align",  0.95, 0.01, "reachability"),
        (2, "probe",  0.85, 0.03, "compliance/friction"),
        (3, "close",  0.40, 0.15, "contact geometry"),
        (4, "lift",   0.15, 0.35, "mass/slip"),
        (5, "handoff",0.00, 0.60, "task feasibility"),
    ]
    def certified_next(self, l, s, wm):        # 逐级、不跳级、过屏障
        l2 = min(l + 1, len(self.RUNGS) - 1)
        return l2 if wm.certify_rung(l2, s) else l   # 不过则停在原级

# IP-265 TMS：任务条件后验 + 幻影剪枝（直接回应 R69 最大风险）
def teleological_modes(modes, w, tau, afford, eps_a):
    s = {k: w[k] * afford(modes[k], tau) for k in modes}
    valid = [k for k in modes if s[k] >= eps_a]
    phantoms = [k for k in modes if k not in valid
                and w[k] > TAU_W and support(modes[k]) < TAU_SUP]
    return normalize({k: s[k] for k in valid}), phantoms

# IP-266 CVO：承诺感知信息价值（含期权损失）
def commitment_value(belief, l, tau, budget, wm):
    best = None
    for l2 in range(l, min(l + DEPTH, LADDER_MAX) + 1):
        if l2 > l and not wm.certify_rung(l2, belief.state): continue
        voi   = info_gain(belief, l2, tau)                  # = H(M|o) - E[H(M|o,y)]
        vinfo = expected_info_side_value(l2)                # 抓取顺带测到的质量/摩擦
        c     = phys_cost(l2) + social_cost(l2) + LADDER.c_irr[l2]
        d_ov  = option_loss(belief, l, l2)                  # OV(l) - E[OV(l2)]
        score = voi + vinfo - c - d_ov
        if best is None or score > best.score: best = (l2, score)
    return best if best and best[1] > 0 else (l, 0.0)       # 不值则停在可逆级

# IP-267 TKB：迁移门（迁移界 + 覆盖域，双门）
def transfer_gate(ledger, src, dst, s, delta=0.05):
    entry = ledger.get(src)
    if entry is None: return False, "no_source"
    bound = entry.ece + L_CAL * wasserstein1(entry.fp, fingerprint(dst)) \
            + sqrt(log(2 / delta) / (2 * entry.n))
    if bound > TAU_ECE:            return False, "transfer_bound"
    if not coverage_contains(entry.cert_id, s): return False, "coverage"
    return True, bound

# IP-268 EAP：有效独立源（替代 R69 的源计数）
def effective_sources(evidence):
    w  = [e.weight for e in evidence]
    sw = sum(w)
    denom = sum(x * x for x in w)
    for i, a in enumerate(evidence):
        for j, b in enumerate(evidence):
            if i < j:
                denom += 2 * corr(a, b) * w[i] * w[j]
    return (sw * sw) / max(denom, 1e-9)                    # rho=1 -> 1, rho=0 -> participation ratio

# IP-270 主闭环（继承 R69，在动作生成处插入承诺谱系与迁移门）
def PACT_RAS_round(M, obs, tau, s):

    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4

    # 平台迁移门：只有覆盖域 + 迁移界都过，才允许复用跨任务校准
    ok, why = M.tkb.transfer_gate(M.ledger, M.skill_key, M.task_key, s) \
              if M.platform_mode else (True, "single_task")
    if not ok: M.mcg.disable_reuse(why)                    # 退回单任务保守校准
    # 承诺谱系：逐级认证、CVO 决定是否升级（不可逆动作不单独定案）
    l2, cv = M.cvo.commitment_value((modes, U_ale, U_epi), M.rung, tau, M.budget, M.c_ras_wm)

    if slow: lam = max(lam, 0.8); k = min(k, k_cal_shrink(A, U_cal))
    mode = select_mode(modes, U_epi, lam)
    M.vqa_p.submit_async(l2, cv, phantoms, why, a_hat)     # 审计：承诺+迁移同层记账
    return k, lam, mode, (U_ale, U_epi, l2, why)
```

## 3. 推导

**引理 19（承诺增益分解与最优等级）** 在 A99–A101 下，从 ℓ 升级到 ℓ′ 的期望净收益为
`Gain(ℓ→ℓ′) = c·Δ_min^τ·(1 − e^{−ΔH}) + E[V_info] − c_irr(ℓ′) − ΔOV(ℓ→ℓ′) − o(‖K‖)`。
要点：消歧收益随模态间距与后验熵降幅增长，而不可逆成本与期权损失随等级单调上升，故存在有限最优等级 ℓ*；当 `c_irr` 或 `ΔOV` 增大时 ℓ* 单调下降。系：**「先悬停/轻触，再决定是否闭合」不是工程洁癖，而是 CVO 最优**——低成本可逆级用少量信息把高成本承诺的期望损失压下去。

**引理 20（任务条件剪枝抑制幻影模态）** 设幻影 m_h 满足 `A(m_h,τ)≤ε_a`，且与所有可负担模态的 W₂ 距离 ≥ Δ_min^τ。则 TMS 剪枝后，因幻影触发的无效追问率 ≤ `δ_flow·ε_a / Σ_k ŵ_k A_k + ε_σ`；相比 R69 无任务先验的追问率，至少下降因子 `ε_a / A_max`。系：**任务意图是免费的模态先验**——它把 R69 最脆弱的「生成可信度」问题，转成一个更易验证的「任务可负担性」问题。

**引理 21（迁移校准的 ECE 界）** 在 A102 下，源域 c 到目标 c′ 的校准误差满足定义 317 的界（whp 1−δ）。系：**迁移不是信仰，是可计算的预算**；`B(c→c′)` 随样本数下降、随分布距离上升，故平台存在一个有限的「可信复用半径」。

**引理 22（有效独立源的投毒上界）** 在 A103 下，若各源按 k_eff 有效独立，则多数一致的错误采纳率 ≤ `δ_p·ρ^{k_eff−1} + ε_σ`。当两个源共享基础模型/幻觉时 `ρ→1` 且 `k_eff→1`，R69 的「k=2 定案」失效；k_eff 门自动拒绝定案。系：**证据纪律的正确对象不是来源个数，而是有效独立度**。

**定理 18（PACT 严格包含 FLUID-RAS）** 在 A99–A104 下，PACT 的期望风险 ≤ R69 在同一等级截断下的策略；且在定义 325 的退化条件下两者逐指令相同。直观：承诺谱系把 R69 的扁平动作空间嵌入为 ℓ0 切片，CVO 在 `c_irr=ΔOV=0` 时化为 `VoI−c`，TMS 在 `A≡1` 时化为恒等，迁移门在覆盖域全空间且单任务时化为恒等。安全侧不让步，效率侧获得「分级承诺 + 任务剪枝 + 局部化复用」三重 bonus。

**定理 19（承诺序的安全与无突变）** 每级动作经 C-RAS-WM‡ 认证且存在屏障 h_ℓ（A104），升级/回退在屏障内连续；不可逆成本显式进入 CVO，故最优策略不会在可逆信息不足时跳级。失败触发「降载不瞬移」回退，换装/提交不变式（R68 定理 15）保持 ⇒ 控制连续、无突变。

**定理 20（局部池化优于全局池化）** 平台在半径 d 内池化证据时，校准方差 ~ `σ²/n_eff(d)` 下降，偏差 ~ `L_cal·d` 上升，故复用净收益在有限 d* 处最大：
`d* = argmax_d [ c₁·n_eff(d)/n − c₂·L_cal·d ]`。
系：**通用平台的正确形态是局部校准联邦**——全局池化会把「平台越大越准」变成「平台越大越自信地错」。这直接约束定义 324 的池化半径与 `τ_gap` 的设定。

## 6. 本轮最大风险

**一句话**：PACT 的全部收益押在「**任务可负担性 A 与迁移界的 Lipschitz 常数都是可信的**」上——若 A 估错，任务先验会**静默剪掉唯一正确的抓法**；若 `L_cal` 被低估，平台就会把局部失校准的证书当成可迁移真理，在覆盖域外盖章。于是 PACT 把 R69 的「问错」升级成「**带着可迁移证明的错**」——最危险的不是不知道覆盖域，而是**覆盖域本身被高估**。

**次级风险与缓解**：
1. **A 的闭环自证**（用同一策略的成功率估计可负担性，形成自我确认偏差）→ A 只用离线回放/仿真 + 独立标定集估计，并保留「反事实抓取」审计样本；E303/E314 监测误剪率。
2. **迁移界保守性不足**（`L_cal` 在线估计漂移）→ 取在线残差的分位数上界，覆盖域外强制重校准；定理 20 的有限池化半径 + `τ_gap` 全局熔断。
3. **承诺谱系被跳级优化**（CVO 为了省时跳过可逆级）→ 定义 310-ii 的不可跳级硬约束 + 定理 19 屏障；审计记录每次等级跃迁。
4. **k_eff 的相关性估计被操纵** → 相关性用多源独立探针估计，证据来源哈希可追溯、可撤回；E306 专测共谋。
5. **跨任务校准遗忘**（新任务冲掉旧校准）→ 定义 321 的 CF 熔断与账本回滚；E310 长时程验证。

**定义 312（CTR 接触转换）** `U_epi(ℓ⁺)=(I−K_ℓ)U_epi(ℓ⁻)+U_amb^τ`，`U_ale(ℓ⁺)=U_ale(ℓ⁻)+tr(K_ℓᵀU_epi K_ℓ)+U_contact(ℓ)`。K_ℓ 刻画「被接触测掉的 epistemic 有多少比例变成不可约接触噪声」。R69 只在 ℓ0（K_0=0）更新，看不到「测量制造噪声」的代价。

**定义 313（CVO）** `CVO(ℓ)=VoI(g^ℓ)+E[V_info(y_ℓ)]−c_phys−c_social−c_irr(ℓ)−ΔOV(ℓ)`；`OV(ℓ)=E_b[max{0,max_{ℓ'>ℓ}CVO(ℓ')}]`；`ℓ*=argmax_ℓ CVO(ℓ)`，仅当 `CVO(ℓ*)>0` 升级。R69 的 `argmax_g[VoI−c]` 为 `L=0, ΔOV=0, c_irr=0` 的退化。

**定义 314（任务条件模态后验）** `p(m_k|o,τ) ∝ ŵ_k A(m_k,τ) L(o|m_k)`；`U_epi^τ=H(M|o,τ)·g(Δ_min^τ)`，`Δ_min^τ` 只在 `A>ε_a` 的模态间取。**与任务无关的模态分裂不是 epistemic，不值得花预算消解。**

**定义 315（TMS）** `s_k=ŵ_k A(m_k,τ)`；剪掉 `A<ε_a` 的模态；`ŵ` 高、支撑低、且与所有可负担模态 W₂ 距离 ≥ Δ_min 者判为**任务不相容幻影**，记录但禁用。MCG（R69 定义 306）事后禁用不可信权重，TMS 事前剪掉语义不可能模态。

**定义 316（TCL）** 追加式账本，键 `(技能,物体类,末端执行器,场景族)`，值 `(ECE,n,P_c,配置哈希,时间戳,证书号)`；只追加、可版本化回滚；复用必须引用具体条目。

**定义 317（TKB）** 迁移门 `B(c→c')≤τ_ece`（A102），`W₁` 用分布指纹的切片 Wasserstein 近似；`L_cal` 由历史迁移残差在线估计并取保守上界。

**定义 318（CCF）** `Cov(J)` 由反例/压力测试经验确定；复用需 `s∈Cov(J)` 且 `B≤τ_ece`；覆盖缺口 `G=P[s∉Cov|请求复用]`，`G>τ_gap` 时平台级禁用跨任务复用。

**定义 319（EAP）** 证据带来源哈希与相关性；`k_eff=(Σw)²/(Σw²+Σ_{i≠j}ρ_ij w_i w_j)`；定案需 `k_eff≥2`；来源被审计判漂移时可撤回其贡献并重算证书。

**定义 320（承诺屏障）** 每级过 C-RAS-WM‡（力/位包络、脆弱性、人体邻近、可达性、时序）；存在屏障 `h_ℓ≥0`（A104）；失败触发「降载不瞬移」回退，绝不跳过认证路径。

**定义 321（校准遗忘）** `CF=max_c(ECE_c^new−ECE_c^old)`；`CF>τ_cf` 冻结/回滚相关技能校准并标记需复检。

**定义 322（J_PACT）** 见符号表；Valid ⇔ Valid(J_FLUID) ∧ 承诺预算合规 ∧ 迁移/覆盖证明通过 ∧ `k_eff_min≥2` ∧ `CF≤τ_cf`。

**定义 323（自适应深度）** 默认 K=1、N_step=2、承诺深度 L=1；仅当歧义且 CVO 符号不稳定时扩到 L=3、K=4；等级切换允许一次性预算超支。

**定义 324（平台覆盖缺口）** `G` 是平台级「诚实的不知道」，用于选择池化半径，避免默认全局池化。

**定义 325（严格包含）** `L=0 ∧ 单任务 ∧ Cov=全空间 ∧ A≡1 ∧ k_eff=k ∧ c_irr=ΔOV=0` ⇒ 与 FLUID-RAS 逐指令相同；一般情形风险不高于 R69 的同等级截断，退化条件成立时退化为 R69 最保守。

## 3. 关键算法伪代码

```python
# IP-264 GCL：承诺谱系（不可跳级、逐级认证）
class CommitmentLadder:
    RUNGS = [(0,"gaze",1.00,0.00),(1,"align",0.95,0.01),(2,"probe",0.85,0.03),
             (3,"close",0.40,0.15),(4,"lift",0.15,0.35),(5,"handoff",0.00,0.60)]
    def next_rung(self, l, s, wm):
        l2 = min(l + 1, len(self.RUNGS) - 1)
        return l2 if wm.certify_rung(l2, s) else l         # 不过则停原级

# IP-265 TMS：任务条件后验 + 幻影剪枝
def teleological_modes(modes, w, tau, afford, eps_a):
    s = {k: w[k] * afford(modes[k], tau) for k in modes}
    valid = [k for k in modes if s[k] >= eps_a]
    phantoms = [k for k in modes if k not in valid
                and w[k] > TAU_W and support(modes[k]) < TAU_SUP]
    return normalize({k: s[k] for k in valid}), phantoms

# IP-266 CVO：承诺感知信息价值（含期权损失与接触转换）
def commitment_value(belief, l, tau, budget, wm):
    best = None
    for l2 in range(l, min(l + DEPTH, LADDER_MAX) + 1):
        if l2 > l and not wm.certify_rung(l2, belief.state): continue
        voi   = info_gain(belief, l2, tau)                 # H(M|o)-E[H(M|o,y)]
        vinfo = expected_info_side_value(l2)               # 抓取顺带测质量/摩擦
        c     = phys_cost(l2) + social_cost(l2) + c_irr[l2]
        d_ov  = option_loss(belief, l, l2)                 # OV(l)-E[OV(l2)]
        score = voi + vinfo - c - d_ov
        if best is None or score > best.score: best = (l2, score)
    return best if best and best[1] > 0 else (l, 0.0)      # 不值则停在可逆级

# IP-269 TKB：迁移门（迁移界 + 覆盖域双门）
def transfer_gate(ledger, src, dst, s, delta=0.05):
    e = ledger.get(src)
    if e is None: return False, "no_source"
    bound = e.ece + L_CAL * wasserstein1(e.fp, fingerprint(dst)) \
            + sqrt(log(2/delta) / (2*e.n))
    if bound > TAU_ECE:            return False, "transfer_bound"
    if not coverage_contains(e.cert_id, s): return False, "coverage"
    return True, bound

# IP-271 EAP：有效独立源
def effective_sources(evidence):
    w = [e.weight for e in evidence]; sw = sum(w); denom = sum(x*x for x in w)
    for i, a in enumerate(evidence):
        for j, b in enumerate(evidence):
            if i < j: denom += 2 * corr(a, b) * w[i] * w[j]
    return (sw*sw) / max(denom, 1e-9)                       # rho=1 -> 1

# IP-272 主闭环（继承 R69）
def PACT_RAS_round(M, obs, tau, s):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    modes, w = unpack(M.fmp.sample(o, K))
    w_tau, phantoms = M.tms.teleological_modes(modes, w, tau, M.afford, EPS_A)
    U_ale, U_epi = decompose_task_aware(modes, w_tau)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_calibrated)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    ok, why = M.tkb.transfer_gate(M.ledger, M.skill_key, M.task_key, s) \
              if M.platform_mode else (True, "single_task")
    if not ok: M.mcg.disable_reuse(why)                    # 退单任务保守校准
    l2, cv = M.cvo.commitment_value((modes, U_ale, U_epi), M.rung, tau, M.budget, M.c_ras_wm)
    if slow or (U_epi > TAU_EPI and not M.eap.ok(M.evidence, k_eff_min=2)):
        l2 = min(l2, 2)                                    # 证据不足不得入不可逆级
    U_floor = U_ale + (U_epi if l2 < 3 else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    A   = M.ach.propose(x_prime, H=M.vista.H)
    k   = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if slow: lam = max(lam, 0.8); k = min(k, k_cal_shrink(A, U_cal))
    mode = select_mode(modes, U_epi, lam)
    M.vqa_p.submit_async(l2, cv, phantoms, why, a_hat)     # 承诺+迁移同层记账
    return k, lam, mode, (U_ale, U_epi, l2, why)
```

## 4. 推导

**引理 19（承诺增益分解与最优等级）** A99–A101 下，
`Gain(ℓ→ℓ')=c·Δ_min^τ·(1−e^{−ΔH})+E[V_info]−c_irr(ℓ')−ΔOV(ℓ→ℓ')−o(‖K‖)`。
消歧收益随间距与熵降增长，不可逆成本与期权损失随等级单调上升 ⇒ 存在有限 ℓ*；`c_irr`/`ΔOV` 增大时 ℓ* 单调下降。系：**「先悬停/轻触，再决定闭合」是 CVO 最优**，不是工程洁癖。

**引理 20（任务剪枝抑制幻影）** 若幻影 `A≤ε_a` 且与可负担模态距离 ≥ Δ_min^τ，则剪枝后无效追问率 ≤ `δ_flow·ε_a/ΣŵA + ε_σ`，较 R69 至少降 `ε_a/A_max`。系：**任务意图是免费模态先验**，把「生成可信度」问题转成更易验证的「任务可负担性」问题。

**引理 21（迁移校准 ECE 界）** A102 下 `ECE_c' ≤ ECE_c + L_cal·W₁(P_c,P_c') + √(log(2/δ)/2n)` whp。系：**迁移是可计算的预算**；存在有限的「可信复用半径」。

**引理 22（有效独立源投毒上界）** A103 下多数一致错误率 ≤ `δ_p·ρ^{k_eff−1}+ε_σ`；共享幻觉使 ρ→1、k_eff→1，R69 的「k=2 定案」自动失效。系：**证据纪律的对象是有效独立度，不是来源个数**。

**定理 18（PACT 严格包含 FLUID-RAS）** A99–A104 下 PACT 风险 ≤ R69 同等级截断策略；定义 325 退化条件下逐指令相同。承诺谱系把 R69 扁平空间嵌入为 ℓ0 切片，CVO 在无不可逆成本时化为 `VoI−c`，TMS 在 `A≡1` 时化为恒等，迁移门在单任务/全空间时化为恒等。安全不让步，效率获「分级承诺 + 任务剪枝 + 局部化复用」三重 bonus。

**定理 19（承诺序安全无突变）** 每级经 C-RAS-WM‡ 认证且存在屏障 h_ℓ，升级/回退在屏障内连续；不可逆成本显式进入 CVO ⇒ 不会在可逆信息不足时跳级；失败「降载不瞬移」回退，换装/提交不变式（R68 定理 15）保持 ⇒ 控制连续无突变。

**定理 20（局部池化优于全局池化）** 半径 d 内池化使方差 ~`σ²/n_eff(d)` 降、偏差 ~`L_cal·d` 升，净收益在有限 `d*` 最大：`d*=argmax_d[c₁·n_eff(d)/n − c₂·L_cal·d]`。系：**通用平台是局部校准联邦**——全局池化会把「平台越大越准」变成「平台越大越自信地错」，直接约束定义 324 与 `τ_gap`。

## 7. 本轮最大风险

**一句话**：PACT 的全部收益押在「**任务可负担性 A 与迁移界 Lipschitz 常数可信**」上——若 A 估错，任务先验会静默剪掉唯一正确的抓法；若 `L_cal` 被低估，平台会把局部失校准的证书当成可迁移真理，在覆盖域外盖章。PACT 把 R69 的「问错」升级成「**带着可迁移证明的错**」——最危险的不是不知道覆盖域，而是**覆盖域本身被高估**。

**次级风险与缓解**：A 的闭环自证 → 独立标定集 + 反事实抓取审计 + 监测误剪率；迁移界保守性不足 → 在线残差分位数上界 + 覆盖外强制重校准 + 定理 20 有限池化半径；承诺被跳级 → 定义 310-ii 硬约束 + 屏障 + 跃迁审计；k_eff 相关性被操纵 → 独立探针估计 + 证据可撤回 + E306；跨任务校准遗忘 → CF 熔断与账本回滚 + E310。
