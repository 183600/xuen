# 第 12 轮（新灵感循环第 2 轮；本轮灵感：「大语言模型」×「预训练」）

> **基线**：第 11 轮 MetricVoiceGauge-GSCF-SRA-JSSE（定义 549–560；引理 92–96；实验 E591–E610）。
> 本轮纪律：**先验只准入分数、不准入结论；有效性来自共形，锐度来自预训练；LLM 只写"拒绝"，不写"许可"**。两个灵感分别治理 v11 的两种债：**有效性债**（τ_sem/γ_min/λ/τ_sra 四个经验阈值 + 引理 96 把"通道正交"当作联合失效可忽略的依据——共同原因漂移下四个边缘 ε_i 会同时膨胀，分通道平稳标定失效）、**样本债**（安全需要"危险分布"做标定，而真实危险样本稀缺、手写规范覆盖有限）。必须保持 v11 铁律：任一新模块失效 ⇒ 行为**等价**或**支配**于 v11，不得行为漂移。

## 0. 直觉与动机

**灵感 1（预训练 → 不是更强的保证，而是更锐的分数）**
直觉：v11 把安全性押在四个手调阈值上。阈值调紧则频繁中止、系统退化为逐步模式（v11 自认最大风险之一）；调松则漏检。更糟的是，引理 96 用"三重守护失效正交 + 并集界"论证联合失效可忽略——并集界本身成立，但它的输入是**分通道、平稳、边缘**的 ε_i；一次共同原因漂移（强遮挡+动态+标定漂移）会让所有 ε_i 同时膨胀，此时 Σε_i 已不再是漂移前那个数，而 v11 没有任何机制感知这件事。预训练能提供的，不是"更准的结论"，而是**更敏感的非一致性分数**：一个在车队日志上自监督预训练的残差/新颖性编码器，能把"正常 vs 危险"的分数分布拉得更开。但分数再好也不自动带来保证——**预训练只改善共形集的锐度（效率），不改善覆盖的有效性**（本轮引理 97 明确划界）。核心创新：**预训练共形三联（Pretrained Conformal Triage, PCT）**——用联合非一致性分数 + 上下文分层 + 双共形阈值（q^safe、q^flag）+ 带延迟标签的自适应共形推断（ACI），把"接受 / 弃权 / 中止"三态决策做成**分布无关、无需任何通道独立性假设**的风险控制。v11 的"阈值经验校准 + 正交论证"被替换为"共形有效性 + 相关失效联合标定 + 漂移自适应"。预训练只负责把弃权带压窄。

**灵感 2（大语言模型 → 编译规范与危险分布，而非在线决策）**
直觉：LLM 放进 50Hz/1kHz 控制回路是灾难——幻觉、延迟、不可解释都不可接受。但 LLM 有两个不可替代的**离线**用途：(i) 把政策文本、事故报告、人类纠正编译成运行时规范谓词；(ii) 合成"危险样本"，为 PCT 的 q^safe 提供稀缺的危险分布。核心创新：**LLM 规范编译器（LLM Spec Compiler, LSC）**——受限的 **deny-only DSL**（只许写"拒绝"，语法上根本不存在授权原语）+ 三级验证闸门（类型/预算、结构性单调收缩、场景与性质测试）+ 证明携带规范（provenance 哈希、模型版本、提示哈希、验证记录、双人签署）入哈希链台账。关键性质：**LLM 的幻觉在结构上只能导致"过度收缩"（安全侧），不能导致"越权放行"**（引理 100）。同时 LSC 生成的危险样本不是"安全证据"，而是"抬高阈值 / 增加弃权的证据"——方向被 P18 锁死。

**灵感 3（合流 → 把阈值退役，把复杂度搬到编译期）**
直觉：v11 的净复杂度已经很高（STF+GSCF+SRA+NRB+JSSE+台账）。v12 不再加"在线重模型"，而是**减阈值、加保证**：四个静态阈值从主路径退役（保留为失效外包络），在线只增加 O(1) 的共形标定层（≤0.25ms、≤90KB、≤9mW）；LLM 与预训练都在编译期/离线完成。这正好兑现 v10 的 P15"轻量有据律"：把复杂度搬到有证据的地方（离线编译、离线标定），而不是删掉安全机制。

三者咬合：PCT 把"安全"从"信任某个阈值"改成"接受一个可陈述的风险水平 α"；LSC 供给 PCT 最缺的危险标签与规范数据；预训练供给更锐的分数但被 P16 禁止越权。

## 1. 研究问题（轮次升级版）

- **Q1（有效性）**：如何用联合共形风险控制替代 v11 的四个经验阈值与"失效正交"论证，使危险漏放率 ≤ α 且**不需要通道独立性**，并在非交换、分布漂移、标签延迟下仍有可陈述的保证？
- **Q2（锐度）**：预训练在不动有效性的前提下，能把弃权带（q^flag−q^safe）压窄多少？锐度增益如何与 α、样本量、分层粒度定量挂钩？
- **Q3（规范与样本）**：LLM 如何把自然语言规范/事故报告编译为 deny-only 可验证谓词与危险标定样本，做到**零扩权**、来源可追溯、可撤销，且在线成本为零？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 先验只准入分数律（Prior-as-Score, PCT）**
预训练模型 / LLM 的输出只可作为非一致性分数或 deny-only 谓词进入系统，**不得作为判决、许可或放行依据**；有效性来自共形标定，不来自先验强度。先验越强只允许弃权带越窄。

**P17 三态不越权律（Triage Non-Expansion, PCT）**
决策三态：accept / abstain / abort。abstain 与 abort 只许收缩（K_eff←1 或 Π_r），不许产生新物理行为；accept 必须在共形阈值内且证书有效。静态阈值仅作失效外包络，**主路径不得回退到经验调参**。

**P18 危险分布可造但方向锁定律（Synthesized-Danger, LSC）**
LLM/仿真合成的危险样本只能用于**抬高 q^safe、扩大弃权、增加中止**；不得作为"已安全"的证据去降低阈值或扩大动作空间。每条危险标签必须带 provenance 与验证记录，否则不得进入标定流。

## 3. 与基线的接口（如何退化）

- PCT 失效（标定流污染、延迟标签断流 > T_lag、ACI 发散）⇒ 冻结 q̂，α_eff←α/2，并与 v11 静态阈值取**更保守外侧**包络 ⇒ 行为 ⊆ v11；
- LSC 失效 ⇒ 回退上一版已验证规范表（v11 手写表）⇒ 等价 v11；
- GSCF/SRA/JSSE 失效 ⇒ 沿 v11 Level-1/2/3 原样；
- STF/NRB/AC/ID/MW/v8 失效 ⇒ 沿 v11 Level-4…9 原样；
- 安全守卫 PCT/LSC 一律 φ^elig=false 永不消融，仅"分数模型维护"可蒸馏。

## 4. 预期贡献

1. **共形三联证书**：联合分数 + 上下文分层 + 双阈值 + 延迟 ACI，把 v11 的四个经验阈值与不可靠的独立性论证一并拆除（引理 97–99）；
2. **先验-有效性分离**：证明预训练只影响锐度/效率，不影响覆盖有效性，给基础模型一个可辩护的、非"信任其正确性"的角色（引理 97）；
3. **LLM 证明携带规范**：deny-only DSL + 三级闸门 + provenance 台账，使 LLM 幻觉在结构上只能过度收缩（引理 100–101）；
4. **E611–E630** 覆盖漂移覆盖、相关失效、危险合成、规范挖掘、延迟标签、退役回归、长跑与竞赛。

## 5. 本轮最大风险

**一句话**：共形保证只对**标定流覆盖到的分布**成立——若部署或对手系统性地避开、污染某个危险分层（LLM 合成的危险样本又继承语料盲区），ACI 会在"平均覆盖 α"的名义下让该关键分层长期未被覆盖；联合 max 分数与弃权带还可能被诱导成"永久弃权"（可用性 DoS），此时系统安全但事实上不可用。

**新增定义 561（联合非一致性分数）** 对每个决策样本，从 v11 已有通道取原始异常量：语义 ν̂_ℓ（定义 550）、几何 1−γ_ℓ（定义 549）、动力学残差 r_dyn = ‖F̂_q(s,a)−s'‖/‖s'‖、推理不确定性 1−min_j conf_j（定义 554–555）。按预注册尺度 σ 归一化后取 max：s_t = max_i (raw_i/σ_i) ∈ [0,1]。取 max 而非加权和，是为让"任一通道异常即可触发"的保守语义保留，同时**避免对通道相关性建模**——相关性由联合标定消化，而不是由独立性假设消化。

**新增定义 562（上下文分层 / Mondrian 共形）** z_t 为预注册的粗粒度上下文：visibility∈{好,中,差}、occlusion∈{无,部分,重}、speed∈{慢,中,快} 的笛卡尔子集（≤36）。每个分层独立维护标定样本；样本数 < n_min(=200) 的格子向父层回退（层次化 Mondrian）。**作用**：v11 的 γ 在强遮挡下"虚假低"只会抬高该分层阈值，不会全局把 K_eff 压到 1——直接降低 v11 自认的最大风险（可用性崩塌）而不牺牲该分层内的安全性。

**新增定义 563（双共形阈值）** q^safe_{z} 由**危险标签**集 D_z 上的共形风险控制给出：取最小 q 使 \hat{R}_D(q) = (1/|D_z|)Σ_{i∈D_z} 1{s_i ≤ q} ≤ α（即"危险样本被误接受"的经验率 ≤ α）；q^flag_{z} 由**正常流**上的 ACI 给出，控制误报率 ≤ α_flag。强制 q^safe ≤ q^flag；二者之间为**弃权带**。

**新增定义 564（带延迟标签的自适应共形）** 报警阈值按 ACI 更新：q^flag_{t+1} = clip(q^flag_t + η(α_flag − 1{s_t > q^flag_t}), 0, 1)。接受阈值按延迟 ACI 更新：当 t−d 时刻的标签 L_{t−d} 到达（d ≤ T_lag）时，q^safe_{t+1} = clip(q^safe_t + η(α − L_{t−d}·1{s_{t−d} ≤ q^safe_t}), 0, 1)。**导入定理**（Gibbs–Candès ACI 的延迟反馈变体）：在 s_t 有界、η 固定、延迟 d ≤ T_lag 下，长程平均漏放率 ≤ α + O(η·T_lag)。证明略（引用并做界适配），本轮只要求"可陈述、可监测"，不假装得到逐样本条件保证。

**新增定义 565（三态决策）**
```
Δ_t = accept   若 s_t ≤ q^safe_{z,t} 且 Ĉ_t^{++} 其余字段有效
    = abort    若 s_t >  q^flag_{z,t}
    = abstain  否则（弃权带内）
```
accept 才允许按 v11 块证书执行；abstain ⇒ K_eff←1（或 NRB 的 Π_r，二者取更严）；abort ⇒ 走 v11 中止/JSSE 路径。**abstain 与 abort 只收缩，不产生新动作**。

**新增定义 566（危险标签与 provenance）** 标签来源三类：(a) 仿真回放中已知的危险注入；(b) 事故/纠正日志的事后标注；(c) LSC 合成并经 V3 验证的危险场景。每条标签带 (来源哈希, 生成模型版本, 验证记录哈希, 时间戳)；缺任一字段即不入标定流。标签流断流 > T_lag ⇒ PCT 进入冻结态（Level-1）。

**新增定义 567（共形三联块证书）** Ĉ_t^{+++} = (v11 的 Ĉ_t^{++}; s_t, z_t, q^safe, q^flag, Δ_t, û_t)。有效 ⇔ v11 定义 552 条件 ∧ Δ_t = accept ∧ û_t 在预注册容差内 ∧（若处于冻结态则静态外包络也通过）。

**新增定义 568（deny-only 规范 DSL）** 文法只允许：原子谓词（距离/可见性/人体在场/物品归属/语义类别/几何残差/关节状态）、合取、全称量化于场景对象、以及"拒绝动作"结论。**不存在** allow/permit/grant/else-执行 等授权原语。任意可编译谓词 φ 的运行时语义是约束集 C_φ(s)，且 C_φ(s) ⊆ C_base(s)。这条结构性限制是引理 100 的全部基础：LLM 写不出"许可"。

**新增定义 569（LLM 规范编译映射）** 输入：规范语料 D_norm（政策文本、事故报告、人类纠正）、现有已验证表 N。LLM 输出候选集 {(φ_j, p_j, T_j)}：φ_j 为 DSL_deny 程序，p_j 为自然语言来源与理由，T_j 为测试义务（正例/负例/边界例、变形测试）。LLM 只提案，不入运行时。

**新增定义 570（三级验证闸门）**
- V1 类型/预算：φ_j 仅引用声明输入，最坏求值 ≤ D_m（50Hz 守卫内），无递归/无无界循环；
- V2 结构性单调：解析器 + 类型系统证明 φ_j 只含拒绝原语 ⇒ 对任意状态 C_{N∪φ}(s) ⊆ C_N(s)（不是"测试通过"，是"语法保证"）；
- V3 经验一致性：在场景套件与性质测试上，φ_j 不与九不变式冲突；误拒率 ≤ β_norm；危险漏拒在标注危险集上为 0（**注意方向：只查"该拒未拒"，不把"多拒"当失败**）。
V1–V3 全过才准入；高风险规范另需双人签署（two-person rule）。

**新增定义 571（证明携带规范 PCN）** PCN_j = (φ_j, h(p_j), model_version, prompt_hash, V1–V3 记录, signer, t)。写入哈希链 Λ（扩展记录 H(prev‖t‖PCN_j)）。支持**撤销**：追加撤销记录，运行时回退到不含该 φ 的表。审计可复现：给定 model_version + prompt_hash + seed + V 记录，可重放编译与验证。

**新增定义 572（阈值退役与静态外包络）** 主路径上，τ_sem、γ_min、λ、τ_sra 的判决角色由 q^safe/q^flag 取代（N_retired 仅保存其静态值）。PCT 失效时，使用**保守化静态副本** N_retired^-（v11 阈值再收紧一个预注册 margin），并令 accept 条件取两者交集 ⇒ accept 集 ⊆ v11 accept 集。**净效果**：正常态获得共形保证；失效态严格支配 v11；在线常量个数减少 4 个。

## 2. 形式化定义（要点与升级）

- **定义 552/553（块证书与有效块长）升级**：Ĉ_t^{++} 的所有"阈值比较"改为三态判定；U_t 增加"PCT 未冻结"合取项；定义 553 的 K_eff 门控改由 Δ_t 驱动（abstain/abort 时的收缩规则不变）。
- **定义 559（五检守卫）升级**：五检保留，但第 (iii)/(v) 检的阈值比较改为分层共形阈值；新增第 (vi) 检"联合分数 s_t ≤ q^flag"（或直接以 Δ_t≠abort 表达）。总预算仍 ≤0.6ms（PCT 增量 ≤0.15ms，其余复用）。
- **定义 560（台账）升级**：新增 PCN 记录、规范撤销记录、PCT 冻结/恢复记录、延迟标签回灌记录。
- **引理 96 的处置**：不宣称其"错误"，而是**接管其适用域**——并集界在数学上成立，但输入 ε_i 是分通道平稳边缘估计；PCT 改用联合事件 + ACI 跟踪，不再需要"失效正交"这一额外论证。v11 的 ε 估计退化为 PCT 的一个特例（静态、不分层、无漂移跟踪）。

# IP-365 PretrainedConformalTriage：预训练共形三联（在线 O(1)，不变更感知/控制栈）
class PretrainedConformalTriage:
    def __init__(self, score_model, strata, alpha=0.01, alpha_flag=0.05,
                 eta=0.01, T_lag=2.0, n_min=200):
        self.score_model = score_model          # 预训练残差/新颖性编码器：只出分数
        self.strata = strata                    # 预注册分层函数 z_t
        self.alpha, self.alpha_flag = alpha, alpha_flag
        self.eta, self.T_lag, self.n_min = eta, T_lag, n_min
        self.q_safe = HierarchicalQuantiles(default=1.0)   # 每层一个
        self.q_flag = HierarchicalQuantiles(default=0.0)
        self.label_queue = []                   # (t, s_t, z_t) 待标签
        self.frozen = False

    def score(self, obs, pred, sra):
        raw = {
            'sem':  obs.nu_hat / self.sigma['sem'],
            'geo':  (1.0 - obs.gamma_bar) / self.sigma['geo'],
            'dyn':  pred.residual_norm / self.sigma['dyn'],
            'rea':  (1.0 - min(sra.conf)) / self.sigma['rea'],
        }
        return min(1.0, max(raw.values()))        # 定义 561：max 保留保守语义

    def update_flag(self, s_t, z_t):              # 定义 564：正常流 ACI
        q = self.q_flag.get(z_t)
        q = q + self.eta * (self.alpha_flag - (1.0 if s_t > q else 0.0))
        self.q_flag.set(z_t, min(1.0, max(0.0, q)))

    def ingest_label(self, t, dangerous, z_t):
        """延迟标签回灌；标签缺 provenance 由上游拒绝（P18）。"""
        if self.frozen or dangerous is None:
            return
        s_t = self._score_at[t]
        q = self.q_safe.get(z_t)
        loss = 1.0 if (dangerous and s_t <= q) else 0.0   # 漏放
        q = q + self.eta * (self.alpha - loss)
        self.q_safe.set(z_t, min(1.0, max(0.0, q)))

    def triage(self, s_t, z_t):                    # 定义 565
        if self.frozen:
            return self._static_envelope_triage(s_t, z_t)   # Level-1：保守外包络
        if s_t > self.q_flag.get(z_t):
            return 'abort'
        if s_t <= self.q_safe.get(z_t):
            return 'accept'
        return 'abstain'

    def freeze(self):
        self.frozen = True                         # 标签断流/污染/发散
        self.alpha_eff = self.alpha / 2.0


# IP-366 LLMSpecCompiler：deny-only 规范编译（离线；在线零模型）
class LLMSpecCompiler:
    def __init__(self, llm, dsl, scenario_suite, verifier, ledger):

# IP-354（升级）：三态共形分块执行器
class ConformalChunkCertifier(TriGuardChunkCertifier):
    def __init__(self, *a, pct=None, **kw):
        super().__init__(*a, **kw)
        self.pct = pct

    def generate_chunk(self, state, ctx):
        s_t = self.pct.score(state.obs, state.pred, self.sra)
        z_t = self.pct.strata(state.obs)
        delta = self.pct.triage(s_t, z_t)
        if delta == 'abort':
            return self._abort_to_jsse_current(state)      # 只收缩
        if delta == 'abstain':
            return self._single_step_fallback(state)       # K_eff←1 / Π_r
        # delta == accept：沿用 v11 块生成；静态阈值不再参与判决
        return super().generate_chunk(state, ctx)

    def midchunk_guard(self, chunk, k_exec, live_obs):
        s_t = self.pct.score(live_obs, chunk.pred_at(k_exec), self.sra)
        delta = self.pct.triage(s_t, self.pct.strata(live_obs))
        if delta != 'accept':
            return self._abort_to_jsse(chunk, k_exec, self.jsse)
        return super().midchunk_guard(chunk, k_exec, live_obs)

## 4. 推导

**引理 97（先验—有效性分离：预训练只买锐度，不买保证）**
设分数 s(·) 任意可测，标定样本与部署样本可交换，则共形分位数 q 满足 P(s(X_new) ≤ q) ≥ 1−α，该式**不依赖 s 的任何质量**。故预训练/更强的编码器不能提高有效性（覆盖率由构造保证），只能改变锐度。定义弃权带宽度 M = q^flag_{α_flag} − q^safe_{α_safe}；若分数 s' 相对 s 在正常/危险两类上一阶随机占优更分（F_nom^{s'} 更小、F_danger^{s'} 更大），则固定 α 下 M' ≤ M。证明：共形分位数是经验分布泛函，有效性由分位数定义直接得到、与 s 无关；锐度由两类分布的分位点差随分布分离度单调下降。∎ **含义**：基础模型的正确用法是"提供更分的分数"，而非"提供更可信的判决"（P16）；任何"因为模型很大所以更安全"的论证在本框架中无效。

**引理 98（联合共形对共同原因漂移的支配）**
v11 的联合失效率写作 Σ_i ε_i（并集界）并要求"通道正交"以论证可忽略。并集界成立，但 ε_i 是分通道、平稳、边缘的经验量；设存在共同原因漂移使所有通道的漏检率同时乘以因子 κ>1，则真实 Σ_i ε_i(κ) = κΣ_i ε_i，而 v11 的静态标定仍报告 Σ_i ε_i——**低估**。PCT 直接在联合事件上标定：s_t = max_i s_i，q^safe 使 P(s ≤ q^safe | danger) ≤ α；由 max 的定义，{s ≤ q} = ∩_i {s_i ≤ q}，故对任意相关结构，联合接受事件都被控制，无需 ε_i 分解、也无需独立性。ACI 再用实现损失 L_t 更新 q^safe，使 κ 漂移被在线吸收。∎ **含义**：把"假设不相关"换成"直接标定相关整体"；代价是分层样本需求（定义 562 的回退机制兜底）。

**引理 99（三态支配与失效退化）**
(i) 结构性：abstain/abort 分别映射到 K_eff←1/Π_r 与中止，动作集只减不增，故不产生 v11 之外的新物理行为。(ii) 失效态：PCT 冻结后使用 N_retired^-（v11 阈值再收紧 margin）且与共形阈值取交集，故 accept 集 ⊆ v11 accept 集，行为 ⊆ v11。(iii) 正常态：accept 集由 α 风险控制约束，可能比 v11 更宽或更窄，但任何"更宽"都在 α 的显式风险预算内，且不来自 LLM/规范变更（P18 将规范只导向收缩）。∎

**引理 100（LLM 零扩权：deny-only 的结构性保证）**
设基础可行族 A_N(s) = {a : a 满足 N 中全部 φ 的约束}。DSL_deny 生成的每个 φ 对应约束集 C_φ(s)，其运行语义为 A_{N∪{φ}}(s) = A_N(s) ∩ C_φ(s) ⊆ A_N(s)。由于文法无授权原语，任何"放行"企图无法通过 V1 类型检查（无对应构造子）；V2 再做一次语法级单调性证明。由归纳，任意有限次准入后 A_{N_final}(s) ⊆ A_{N_v11}(s)。若 φ 幻觉出过宽条件，结果只会是**过度收缩**（误拒），而 V3 的误拒率上限 β_norm 控制可用性损失。∎ **含义**：LLM 幻觉的最坏后果从"放行危险动作"降为"系统更保守"，方向被结构性锁死。

**引理 101（PCN 的可审计性与可撤销性）**
每条 PCN 含 φ、来源哈希、模型版本、提示哈希、V1–V3 记录与签署；写入哈希链后，任意篡改使链校验失败（碰撞阻力）。给定 (model_version, prompt_hash, seed, V 记录) 可重放编译—验证过程，故"当时为何准入"可复现；撤销以追加记录实现，运行时重建表即可回退。∎

**引理 102（在线预算与净复杂度）**
PCT 每周期为常数次比较/更新：分数更新 O(1)（复用 v11 已有量）、分层查表 O(1)、ACI 两次标量更新。时间 ≤0.15ms@50Hz，空间 ≤26KB 队列 + 表；LSC 全程离线，运行期仅 64KB 规范表与启动校验 0.5ms。相对 v11，主路径**减少** 4 个阈值常量与相应调参分支；在线新增 ≤0.25ms、≤90KB、≤9mW，仍远低于 50Hz/25W/4GB 预算。∎

## 8. 本轮最大风险

**一句话**：共形保证只对**标定流覆盖到的分层**成立——若部署或对手系统性地避开、污染某危险分层（LLM 合成的危险样本又继承语料盲区），ACI 会在"平均覆盖 α"的名义下让该分层长期未被覆盖；同时联合 max 分数与弃权带可被诱导成"永久弃权"（可用性 DoS），系统虽然安全却事实上不可用。
