# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「持续学习」×「深度相机」）

> 第 54 轮把技能组合与云边部署钉在动作剖面 `α_S` 与联合证书 `J` 上，但隐含两个静态假设：**技能是冻结的**（证书一旦签发就永远有效）、**感知是度量无关的**（只要看得见，动作就等价）。持续学习让技能在部署中不断被新任务改写，深度相机把“看见”变成带量纲、带距离相关噪声的 3D 测量。本轮的核心矛盾：**H22**：一次在线微调可以不改证书文件、却改变证书所承诺的行为，形成“证书仍在、能力已移”的静默失效；**H23**：立体深度轴向噪声近似随距离平方增长，且对透明/反光/遮挡敏感，使在近距良好材质上标定的证书在远距或特殊材质上系统性失效。于是把静态证书 `J` 升级为 **带时效与深度条件的证书链** `J_i(t)`, `J_i(t)|_{q_d≥θ_d}`，并引入 **证书保持的持续学习**。

## 0. 直觉与动机

**灵感 1（持续学习把证书从“空间对象”变成“时空对象”）**
直觉：第 54 轮的 `J` 是对动作空间某个区域的承诺。但技能参数 `θ` 每更新一次，同一动作区域上的行为分布就漂移。证书若不带版本与时效，就会出现“证书未变、策略已变”的静默失效。关键转变：**证书必须绑定技能版本 `v_i(t)` 与遗忘监测状态**；签发不是终点，而是一份需要持续证明的租约。

**灵感 2（证书保持的持续学习：回放“证书的边界”，而不是数据的平均）**
直觉：经典回放按任务/样本均匀采样，目标是平均准确率不降。但证书只关心它承诺的核心域 `C_i`（抓取稳定姿态带、插入容差带、已知失败邻域）。平均准确率保持 95% 完全可能对应 `C_i` 上 30% 的行为翻转。于是回放缓冲应 **按证书关键集选择**：向 `C_i` 的边界、失败模式、稀有状态过采样，并把锚定损失只加在 `C_i` 上。这把“抗遗忘”从平均指标变成 **证书域上的 worst-case 保持**。

**灵感 3（深度相机：可观测性有量纲，噪声随距离平方增长）**
直觉：RGB 相机“看见”即可；深度相机给出米制点云，但立体视觉的轴向噪声近似 `σ_z ≈ z²/(f·b)·σ_d`，ToF 还有多径误差，透明/反光/深色表面直接丢深度。于是“能执行”不等于“能测准”：插入、避障、接触依赖的是 3D 量，而不是像素。需要 **深度质量场 `q_d(p)`**，并以支撑区的分位数（而非均值）作为证书的又一硬条件。

**灵感 4（深度噪声沿着动作空间传播：从测不准到做不准）**
直觉：位姿估计误差 `J_pose·σ_z` 会直接变成末端执行误差。若动作 `a` 落在证书域的边界上，仅一个深度的轴向误差就能把 `a` 推出可认证域。因此深度质量不只是感知指标，它必须折算成 **动作域的安全裕度**：`dist(a, ∂A^cert) ≥ κ·σ_z(z)`。这把 H23 从“图像质量”提升为“动作空间边界条件”。

**灵感 5（深度分层重认证：近距学会、远距失效）**
直觉：在线更新多在近距、良好光照与不透明物体上采样，而部署会外推到远距或有遮挡。由于深度噪声随距离非线性增长，一次更新在近距证书域内 sound，在远距是 **分布外 + 噪声放大** 的双重外推。重认证必须 **按距离 × 材质分层**，不能用全局成功率掩盖最差层。

**灵感 6（遗忘债务与稳定性-可塑性-可认证性三角）**
直觉：借鉴定标定债，把“更新后未在 `C_i` 上复验”的暴露量化为 **遗忘债务 `D_forget`**：每做一次未经复验的在线更新，债务按关键集漂移与暴露时长累积；超阈值即把相关证书降级为 `conditional`。经典权衡是稳定性-可塑性，可认证系统还有第三极 **可认证性**：更新越猛可塑性越好、证书域越难保持。提出 **适应预算 (adapt budget)**：预算内改写旧技能，超预算则 **新建技能分支**。三角不是二选一，而是用新分支买可塑性、用关键集回放买稳定性、用预算买可认证性。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（技能版本、证书时效与行为漂移）**
技能 `S_i` 在时刻 `t` 的参数为 `θ_i(t)`、版本为 `v_i(t)`。时刻 `t0` 签发的证书 `J_i(t0)` 绑定 `(v_i(t0), C_i)`，`C_i` 为证书关键集。部署时刻 `t` 的行为漂移
```
δ_beh(t0,t) = sup_{(s,a)∈C_i} D( π_{θ_i(t)}(·|s,a) ‖ π_{θ_i(t0)}(·|s,a) )
```
其中 `D` 为对称散度（如 Jensen-Shannon）。若 `δ_beh(t0,t) > δ_max`，则 `J_i(t0)` 立即失效，**无论证书文件是否存在**。

**定义 122（证书关键集、覆盖与证书保持回放）**
`C_i = C_i^core ∪ C_i^edge ∪ C_i^fail`：核心成功域、边界带、已知失败模式邻域。回放缓冲 `M` 的覆盖
```
cov(M,C_i) = Pr_{x~U(C_i)}[ ∃ m∈M : d(x,m) ≤ r ]
```
证书保持回放的训练目标
```
L = L_new(D_new) + λ_c·E_{(s,a)∈C_i}[ KL(π_θ(·|s,a) ‖ π_{θ_ref}(·|s,a)) ]
                  + λ_r·L_replay(M),     cov(M,C_i) ≥ 1-ε_c
```
第二项只在 `C_i` 上取期望——这是它与 EWC/普通 replay 的本质区别：**约束的是证书域，不是参数全局**。

**定义 123（深度质量场与深度质量）**
对深度观测 `Z_d`，像素/区域 `p` 上的质量
```
q_d(p) = exp(-σ_z(p)/σ_0) · 1[valid(p)] · (1-χ_reflect(p)) · (1-χ_transp(p))
σ_z(p) ≈ z(p)²/(f·b)·σ_d(p)  +  σ_0^tof      (按传感器类型取项)
```
任务相关支撑区 `Ω_T(S,a)` 的深度质量取**低分位**：
```
q_depth(S,a,b) = Quantile_{α_q}( { q_d(p) : p∈Ω_T(S,a) } ),   常取 α_q=0.1
```
用分位数而非均值，因为证书关心最坏支撑点——一个坏点即可让插入失败。

**定义 124（深度条件化可认证域与动作裕度）**
```
A^cert_{S,b} = { a∈A_S : α_{S,b}(a) ≥ θ_cov
                          ∧ ρ_{S,b}(a) ≥ ρ_min
                          ∧ q_depth(S,a,b) ≥ θ_d
                          ∧ dist(a, ∂A^cert) ≥ κ·σ_z(z) }
E_d = (z_min, z_max, reflectance_class, transparency_class)
```
其中 `κ·σ_z(z)` 是深度轴向误差经位姿雅可比 `J_pose` 折算后的动作裕度。证书声明 **深度包络 `E_d`**；部署超出 `E_d` 即自动 `conditional`。

**定义 125（遗忘债务）**
```
D_forget(t) = ∫_0^t u_f(τ)·1[ δ_beh(τ_last_cert,τ) > δ_warn ∨ depth_unverified(τ) ] dτ
```
`u_f` 为未复验更新的暴露权重。当 `D_forget > D_forget^max` 时，所有 `C_i` 相关证书降级为 `conditional`，触发 **分层重认证**（距离 × 材质 × 任务）。

**定义 126（时序-深度联合证书链）**
```
J_i(t) = ( v_i(t), ρ, α, q_depth, E_d, C_i,
           δ_beh(t), D_forget(t), δ_a, evidence )
```
部署条件：
```
dom_{J_i(t)}(T)=in ∧ δ_beh ≤ δ_max ∧ q_depth ≥ θ_d
                  ∧ (z,材质) ∈ E_d ∧ D_forget ≤ D_forget^max
```
`evidence` 至少包含：关键集回放验证、按深度层/材质层的 conformal 残差、更新前后行为漂移审计日志。

## 2. 关键算法 伪代码

### IP-121 CLC（Certificate-preserving Continual Learning）

```python
def certificate_aware_replay(agent, C_i, buffer, new_data, delta_max):
    M = stratified_fill(buffer, C_i, cover_target=1 - EPS_C,
                        oversample={'edge': 3, 'fail': 5})      # 按证书关键集补缓冲
    ref = agent.snapshot
    for batch in new_data:
        L  = task_loss(agent, batch)
        L += LAMBDA_C * anchor_kl(agent, C_i, theta_ref=ref)    # 只锚定 C_i
        L += LAMBDA_R * replay_loss(agent, sample(M))
        agent.step(L)
    drift = max_behavior_drift(agent, ref, C_i)
    if drift > delta_max:                                       # 硬门控
        agent.restore(ref)
        return ('reject', 'behavior_drift', drift)              # 要求走新分支
    return ('ok', agent, drift, coverage(M, C_i))
```

### IP-122 FDL（Forgetting Debt Ledger）

```python
def forgetting_ledger(skill, cert, now, rates):
    drift = behavior_drift(skill.theta, cert.theta_ref, cert.C_i)
    exposure = now - cert.last_verified
    if drift > rates.delta_warn or not depth_recently_verified(cert):
        cert.debt += rates.u_f * exposure * max(drift, rates.floor)
    if cert.debt > rates.max_debt:
        demote(cert, 'conditional')
        schedule_stratified_recertification(cert, layers=['z', 'material', 'task'])
    return cert.debt, cert.status
```

### IP-123 DQP（Depth Quality Profiling）

```python
def depth_quality(Z_d, K, baseline, sensor, support_region, alpha_q=0.1):
    z = Z_d.depth
    sigma_z = axial_noise(z, K.f, baseline, sensor)   # 立体 z^2/(f b) sigma_d；ToF 多径
    valid   = Z_d.valid & (z > Z_D.min) & (z < Z_D.max)
    reflect, transp = classify_reflective_transparent(Z_d.rgb, Z_d.conf)
    q = np.exp(-sigma_z / SIGMA_0) * valid * (1 - reflect) * (1 - transp)
    return {'q_field': q,
            'q_depth': np.quantile(q[support_region], alpha_q),  # 最坏支撑点
            'sigma_z': sigma_z,
            'ece_mat': material_uncertainty(transp, reflect)}
```

### IP-124 DCC（Depth-Conditioned Certificate）

```python
def depth_conditioned_certificate(skill, A, depth_model, layers, theta_d, rho_min, kappa):
    certs = []
    for (z_bin, mat) in layers:                       # 距离 x 材质分层
        A_cert = [a for a in A
                  if skill.alpha(a) >= THETA_COV
                  and skill.rho(a) >= rho_min
                  and depth_model.q_depth(a, z_bin, mat) >= theta_d
                  and margin(a, A) >= kappa * depth_model.sigma_z(z_bin)]
        if not A_cert:
            return ('reject', 'no_certifiable_action', z_bin, mat)
        certs.append((z_bin, mat, A_cert,
                      conformal_residual(depth_model, z_bin, mat)))
    return ('ok', DCC(certs, envelope=layers, theta_d=theta_d))
```

### IP-125 ASB（Adapt-Stability Budget）

```python
def adapt_step(skill, new_task, J, adapt_budget, drift_budget):
    need = estimated_update_norm(skill, new_task)
    if need > adapt_budget.remaining:
        branch = fork_skill(skill, new_task)          # 不改写旧技能，保留旧证书
        return ('fork', branch, adapt_budget)
    candidate = train_with_anchors(skill, new_task, J.C_i)
    drift = max_behavior_drift(candidate, skill.snapshot, J.C_i)
    if drift > drift_budget:
        return ('reject_need_recert', drift)
    adapt_budget.remaining -= need
    return ('update', candidate, adapt_budget)
```

### IP-126 TVJ（Temporal Validity Joint Certificate）

```python
def temporal_joint_certificate(skill, J_prev, now, depth_layers, rerun):
    drift = behavior_drift(skill.theta, J_prev.theta_ref, J_prev.C_i)
    debt  = update_forgetting_debt(J_prev, drift, now)
    if drift > DELTA_MAX or debt > MAX_DEBT:
        return ('reject', 'certificate_expired', drift, debt)
    if not all(depth_check(skill, l) for l in depth_layers):
        return ('reject', 'depth_envelope_exceeded')
    ok, new_cert = rerun(J_prev.C_i, depth_layers)     # 分层重认证
    return ('ok', new_cert) if ok else ('reject', 'recertification_failed')
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CLC | O(|C_i|·|M| + N·|C_i|) | O(|C_i|+|M|) | 关键集覆盖、锚定只在 C_i |
| FDL | O(|C_i|·|π|) / 次审计 | O(1) | 漂移可测、暴露可积 |
| DQP | O(|Ω|·c_depth) | O(|Ω|) | 噪声模型标定、材质分类校准 |
| DCC | O(L·|A|·c_q) | O(L·|A|) | 分层完备、conformal 覆盖 |
| ASB | O(N·|C_i|) | O(|θ|) | 预算单调、分支隔离 |
| TVJ | O(|C_i|·|π| + L·c_q) | O(|C_i|) | 时效 sound、分层复验 |

**正确性定理（Temporal-Depth-Conditioned Composition Soundness）**
承接第 54 轮 (A22)–(A28)，新增：**(A29)** `C_i` 在部署分布上以 margin `γ` 覆盖证书承诺域（关键集是 sound 代理）；**(A30)** `cov(M,C_i) ≥ 1-ε_c`，且锚定标签来自同一 `θ_ref`；**(A31)** 深度噪声模型在声明包络 `(z,材质)` 内标定，`q̂` 误差 ≤ `ε_q`；**(A32)** 所有更新经 ASB 门控，`δ_beh` 用同一散度度量。则对部署时刻 `t` 与证书 `J_i(t0)`：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
            - P(δ_beh>δ_max) - P(q_depth<θ_d)
            - P(D_forget>D_max) - ε_q
```
**关键**：每一项都对应一个可执行的拒绝/降级条件；若 (A29) 失效（`C_i` 不是承诺域的 sound 代理），右侧会出现 **不可界项**——这正是本轮最大风险。

## 4. 实验设计 E162–E166

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 证书保持回放 vs 随机回放 | `C_i` 上 `δ_beh` / 平均准确率 | `δ_beh` ≤ 0.05，平均准确率降幅 ≤ 2% |
| E163 深度质量估计校准 | `q̂` 的 ECE / 失效区 AUROC | ECE ≤ 0.05，AUROC ≥ 0.90 |
| E164 深度条件证书误接受 | 透明/反光/远距上的 false-accept | ≤ 3% |
| E165 20 任务持续更新 | 部署成功率衰减（CLC vs EWC vs naive） | 衰减 ≤ 5%，优于 EWC ≥ 10% |
| E166 遗忘债务预警 | `D_forget` 与实际失效的 lead time / AUC | AUC ≥ 0.85，提前 ≥ 3 次更新 |

**本轮初步探针（真实可复现，脚本 `exp/cl_depth_probe.py`；纯 numpy 合成实验，非机器人基准）**
- 持续学习（12 个共享结构任务，`d=20`，`C_i` 取高杠杆 top-20%）：`C_i` 上行为漂移 naive 0.273 → random replay 0.202 → cert replay **0.153**；旧任务 MSE 0.313 → 0.216 → **0.166**。cert replay 相对 random 把关键集漂移降 24%，但绝对值仍 **高于 `δ_max=0.05`**——说明该设置下硬门控会拒绝更新，必须走 `fork`/分层重认证，而非继续改写旧技能。
- 深度（立体 `f=400px, b=0.05m, σ_d=0.2px`，`θ_d=0.6`）：在 5 个估计器漏采的隐藏支撑点、0–25% 透明/反光失效率下，**均值**质量的 false-accept 为 **10.4%**，`α_q=0.1` 分位数为 **2.3%**；理论可认证距离仅 **0.2–0.71 m**。这直接说明：均值会掩盖尾部坏点，证书必须以低分位数 + 深度包络表述。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| `C_i` 定义不完整 → 证书保持只是 replay 的别名 | 高 | 红队边界采样 + 形式化承诺域 + 覆盖率审计 |
| 深度质量在透明/反光/远距上被高估 | 高 | 立体 + ToF 交叉、主动探测、材质分类 conformal |
| 过度锚定导致可塑性塌缩（新任务学不会） | 高 | 超预算即 `fork` 新分支 + 适应预算 + 新任务成功率绊线 |
| 记忆回放成本 / 数据隐私 | 中 | 关键集原型压缩 + 合成回放 |
| 深度内参/外参缓慢漂移 | 中 | 在线标定监测 + 分层残差告警 |

## 6. 本轮最大风险

**一句话**：证书保持的持续学习把抗遗忘从“平均准确率”改成“证书关键集上的 worst-case 保持”，但它 soundness 的根在 `C_i` 必须是证书承诺域的 **忠实闭包**，而深度质量又必须在透明/反光/远距处不被均值掩盖；一旦 `C_i` 欠定义、回放只是覆盖了一个假的代理集，策略会在证书之外静默漂移，同时 `q_depth` 的尾部坏点让系统“绿灯运行”，最终在远距/特殊材质上同时踩中失忆与测不准——故必须以 **红队边界采样定义 `C_i` + 深度分层低分位 conformal + 超预算即分支的硬门控** 三重护栏，宁可拒绝更新，也不把“关键集覆盖”当成“能力未变”的证明。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（CLC×FDL×DQP×DCC×ASB×TVJ）

> 承接第 54 轮产物 v31。本轮把「动作-鲁棒性双证书 `J`」推进到「**带时效与深度条件的证书链 `J_i(t)`**」，并给出可落地的持续学习与深度感知算子：
> - **CLC（Certificate-preserving Continual Learning）**：按证书关键集回放 + 只在 `C_i` 上锚定；
> - **FDL（Forgetting Debt Ledger）**：未复验更新记成可计息的遗忘债务 `D_forget`；
> - **DQP（Depth Quality Profiling）**：深度质量场 `q_d(p)` 与低分位深度质量 `q_depth`；
> - **DCC（Depth-Conditioned Certificate）**：距离×材质分层的深度条件化可认证域；
> - **ASB（Adapt-Stability Budget）**：稳定性-可塑性-可认证性三角下的适应预算与技能分支；
> - **TVJ（Temporal Validity Joint Certificate）**：时序-深度联合证书链与分层重认证。
>
> IP 编号：IP-121~IP-126（共 6 个新增）；升级 IP-115/116/118/120，把静态 `J` 扩为 `J_i(t)`，把感知维度扩为 `α, ρ, q_depth` 三维。核心转向：**从「动作-鲁棒性双证书」改为「证书关键集保持的持续学习 + 深度包络条件化证书」**。

## 0. 核心 IP 设计

| 编号 | 名称 | 类型 | 关键改进 |
|---|---|---|---|
| IP-121 | CLC Certificate-preserving Continual Learning | 新增 | 关键集回放 `cov(M,C_i)` + `C_i` 上 KL 锚定，worst-case 保持 |
| IP-122 | FDL Forgetting Debt Ledger | 新增 | 遗忘债务 `D_forget`，超阈值自动降级 `conditional` |
| IP-123 | DQP Depth Quality Profiling | 新增 | `q_d(p)` 融合轴向噪声/失效/材质，`q_depth` 取低分位 |
| IP-124 | DCC Depth-Conditioned Certificate | 新增 | 距离×材质分层 `A^cert`，深度包络 `E_d`，动作裕度 `κ·σ_z` |
| IP-125 | ASB Adapt-Stability Budget | 新增 | 适应预算 + 超预算 `fork`，避免改写破坏旧证书 |
| IP-126 | TVJ Temporal Validity Joint Certificate | 新增 | `J_i(t)=(v,ρ,α,q_depth,E_d,C_i,δ_beh,D_forget,δ_a,evidence)` |

**升级既有 IP**
- **IP-115 ACS**：动作剖面 `α_S` 增补感知条件，证书域由 `α` 单元升级为 `(α, ρ, q_depth)` 三元可行域；
- **IP-116 SCOM**：组合图的边判定加入 `q_depth(S_i⊗S_j) ≥ θ_d` 与深度包络一致性；
- **IP-118 AEC**：联合证书 `J` 增补 `v_i(t), C_i, δ_beh, D_forget, q_depth, E_d`；
- **IP-120 JTC**：跨域迁移额外要求源/目标深度包络 `E_d` 兼容，且迁移后重新核对 `δ_beh`。

## 1. 符号体系增量（新增定义 121–126）

| 符号 | 含义 |
|---|---|
| `θ_i(t), v_i(t)` | 技能参数 / 版本（时间函数） |
| `C_i = C_i^core ∪ C_i^edge ∪ C_i^fail` | 证书关键集：核心域 / 边界带 / 失败邻域 |
| `δ_beh(t0,t)` | `C_i` 上的最坏行为漂移（对称散度上确界） |
| `cov(M,C_i)` | 回放缓冲对关键集的覆盖 |
| `L_cert` | 证书保持回放损失（新任务 + C_i 锚定 + 回放） |
| `q_d(p), q_depth` | 像素深度质量场 / 支撑区低分位深度质量 |
| `σ_z ≈ z²/(f·b)·σ_d` | 立体轴向噪声模型 |
| `E_d=(z_min,z_max,reflectance,transparency)` | 深度包络 |
| `A^cert_{S,b}` | 深度条件化可认证动作域（含 `κ·σ_z` 动作裕度） |
| `D_forget, u_f` | 遗忘债务 / 未复验更新暴露权重 |
| `adapt_budget` | 每次更新可消耗的证书预算 |
| `J_i(t)` | 时序-深度联合证书链 |

## 2. 关键算法 伪代码

### IP-121 CLC

```python
def stratified_fill(buffer, C_i, cover_target, oversample):
    M = list(buffer)
    need = {k: int(oversample.get(k, 1) * len(getattr(C_i, k))) for k in ['edge', 'fail']}
    for region, k in need.items():
        M += sample_region(getattr(C_i, region), k)      # 边界/失败邻域过采样
    while coverage(M, C_i) < cover_target:
        M.append(active_query(C_i, M))                   # 主动补最不覆盖处
    return dedup(M)


def certificate_aware_replay(agent, C_i, buffer, new_data, delta_max):
    M = stratified_fill(buffer, C_i, 1 - EPS_C, {'edge': 3, 'fail': 5})
    ref = agent.snapshot
    for batch in new_data:
        L  = task_loss(agent, batch)
        L += LAMBDA_C * anchor_kl(agent, C_i, theta_ref=ref)   # 只锚定 C_i
        L += LAMBDA_R * replay_loss(agent, sample(M))
        agent.step(L)
    drift = max_behavior_drift(agent, ref, C_i)
    if drift > delta_max:
        agent.restore(ref)
        return ('reject', 'behavior_drift', drift)             # 要求 fork
    return ('ok', agent, drift, coverage(M, C_i))
```

### IP-122 FDL

```python
def forgetting_ledger(skill, cert, now, rates):
    drift    = behavior_drift(skill.theta, cert.theta_ref, cert.C_i)
    exposure = now - cert.last_verified
    if drift > rates.delta_warn or not depth_recently_verified(cert):
        cert.debt += rates.u_f * exposure * max(drift, rates.floor)
    if cert.debt > rates.max_debt:
        demote(cert, 'conditional')
        schedule_stratified_recertification(cert, layers=['z', 'material', 'task'])
    return cert.debt, cert.status
```

### IP-123 DQP

```python
def axial_noise(z, f, b, sensor):
    if sensor == 'stereo':
        return z * z * SENSOR.sigma_d / (f * b)     # z^2 增长
    if sensor == 'tof':
        return np.sqrt((z * z * SENSOR.sigma_phase) ** 2 + SENSOR.multipath ** 2)
    raise ValueError(sensor)


def depth_quality(Z_d, K, baseline, sensor, support_region, alpha_q=0.1):
    z = Z_d.depth
    sigma_z = axial_noise(z, K.f, baseline, sensor)
    valid   = Z_d.valid & (z > Z_D.min) & (z < Z_D.max)
    reflect, transp = classify_reflective_transparent(Z_d.rgb, Z_d.conf)
    q = np.exp(-sigma_z / SIGMA_0) * valid * (1 - reflect) * (1 - transp)
    return {'q_field': q,
            'q_depth': np.quantile(q[support_region], alpha_q),  # 最坏支撑点
            'sigma_z': sigma_z,
            'ece_mat': material_uncertainty(transp, reflect)}
```

### IP-124 DCC

```python
def depth_conditioned_certificate(skill, A, depth_model, layers,
                                  theta_d, rho_min, kappa):
    certs = []
    for (z_bin, mat) in layers:                      # 距离 x 材质分层
        A_cert = [a for a in A
                  if skill.alpha(a)   >= THETA_COV
                  and skill.rho(a)    >= rho_min
                  and depth_model.q_depth(a, z_bin, mat) >= theta_d
                  and margin(a, A)    >= kappa * depth_model.sigma_z(z_bin)]
        if not A_cert:
            return ('reject', 'no_certifiable_action', z_bin, mat)
        certs.append((z_bin, mat, A_cert,
                      conformal_residual(depth_model, z_bin, mat)))
    return ('ok', DCC(certs, envelope=layers, theta_d=theta_d))
```

### IP-125 ASB

```python
def adapt_step(skill, new_task, J, adapt_budget, drift_budget):
    need = estimated_update_norm(skill, new_task)
    if need > adapt_budget.remaining:
        branch = fork_skill(skill, new_task)          # 分支买可塑性，旧证书不动
        return ('fork', branch, adapt_budget)
    candidate = train_with_anchors(skill, new_task, J.C_i)
    drift = max_behavior_drift(candidate, skill.snapshot, J.C_i)
    if drift > drift_budget:
        return ('reject_need_recert', drift)
    adapt_budget.remaining -= need
    return ('update', candidate, adapt_budget)
```

### IP-126 TVJ

```python
def temporal_joint_certificate(skill, J_prev, now, depth_layers, rerun):
    drift = behavior_drift(skill.theta, J_prev.theta_ref, J_prev.C_i)
    debt  = update_forgetting_debt(J_prev, drift, now)
    if drift > DELTA_MAX or debt > MAX_DEBT:
        return ('reject', 'certificate_expired', drift, debt)
    if not all(depth_check(skill, l) for l in depth_layers):
        return ('reject', 'depth_envelope_exceeded')
    ok, new_cert = rerun(J_prev.C_i, depth_layers)    # 分层重认证
    return ('ok', new_cert) if ok else ('reject', 'recertification_failed')
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CLC | O(\|C_i\|·\|M\| + N·\|C_i\|) | O(\|C_i\|+\|M\|) | 关键集覆盖、锚定只在 `C_i` |
| FDL | O(\|C_i\|·\|π\|) / 审计 | O(1) | 漂移可测、暴露可积 |
| DQP | O(\|Ω\|·c_depth) | O(\|Ω\|) | 噪声模型标定、材质分类校准 |
| DCC | O(L·\|A\|·c_q) | O(L·\|A\|) | 分层完备、conformal 覆盖 |
| ASB | O(N·\|C_i\|) | O(\|θ\|) | 预算单调、分支隔离 |
| TVJ | O(\|C_i\|·\|π\| + L·c_q) | O(\|C_i\|) | 时效 sound、分层复验 |

**定理（Temporal-Depth-Conditioned Composition Soundness）**
承接第 54 轮 (A22)–(A28)，新增 **(A29)** `C_i` 以 margin `γ` 覆盖证书承诺域；**(A30)** `cov(M,C_i) ≥ 1-ε_c` 且锚定标签同源于 `θ_ref`；**(A31)** 深度噪声模型在 `(z,材质)` 包络内标定，`q̂` 误差 ≤ `ε_q`；**(A32)** 所有更新经 ASB 门控且 `δ_beh` 度量一致。则
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
            - P(δ_beh>δ_max) - P(q_depth<θ_d)
            - P(D_forget>D_max) - ε_q
```
**证明要点**：(i) 由 (A29)(A30)，`δ_beh ≤ δ_max` 保证 `C_i` 上行为未漂移，证书在承诺域内 sound；(ii) 由 (A31) 与定义 124 的动作裕度，`q_depth ≥ θ_d ⇒ dist(a,∂A^cert) ≥ κσ_z`，深度误差不会把动作推出域；(iii) 由 (A32)，`D_forget` 只在未复验暴露上累积，超阈值即降级，故右侧各失败事件互不掩盖；(iv) 若 (A29) 失效，`C_i` 外行为无约束，`P_success` 出现 **不可界项**。∎

### 5.2 本轮初步探针（真实运行，`exp/cl_depth_probe.py`，纯 numpy 合成实验）

**持续学习**（12 个共享结构任务，`d=20`，`C_i`=高杠杆 top-20%，buffer=240）：

| 策略 | `C_i` 行为漂移 `δ_beh` | 全空间漂移 | 旧任务 MSE |
|---|---|---|---|
| naive 顺序微调 | 0.273 | 0.597 | 0.3133 |
| random replay | 0.202 | 0.442 | 0.2158 |
| **cert replay（本轮）** | **0.153** | **0.313** | **0.1658** |

结论：cert replay 相对 random 把关键集漂移降 **24%**、旧任务 MSE 降 **23%**；但绝对漂移仍 **大于 `δ_max=0.05`**，说明本设置下硬门控会拒绝更新——应触发 `fork`/分层重认证，而不是继续改写旧技能。这正好验证了 ASB 的“超预算即分支”设计。

**深度质量**（立体 `f=400px, b=0.05m, σ_d=0.2px`，`θ_d=0.6`，含 5 个估计器漏采隐藏支撑点、0–25% 透明/反光失效率）：

| 估计量 | false-accept（真实最坏点低于阈值却判通过） |
|---|---|
| 均值 `mean(q_d)` | 10.4% |
| 低分位 `q_depth=Quantile_{0.1}` | **2.3%** |

且按 `σ_z=z²σ_d/(fb)`，在 `θ_d=0.6` 时理论可认证距离仅 **0.2–0.71 m**：远距必须显式降级，不能复用近距证书。均值掩盖尾部坏点，是本轮选择“低分位 + 深度包络”的直接证据。

## 6. 本轮最大风险

**一句话**：证书保持的持续学习把抗遗忘从“平均准确率”改成“证书关键集 worst-case 保持”，但其 soundness 的根在 `C_i` 必须是证书承诺域的 **忠实闭包**，而深度质量必须在透明/反光/远距处不被均值掩盖；一旦 `C_i` 欠定义、回放只覆盖了一个假的代理集，策略会在证书之外静默漂移，同时 `q_depth` 的尾部坏点让系统“绿灯运行”，最终在远距/特殊材质上同时踩中失忆与测不准——故必须以 **红队边界采样定义 `C_i` + 深度分层低分位 conformal + 超预算即分支的硬门控** 三重护栏，宁可拒绝更新，也不把“关键集覆盖”当成“能力未变”的证明。
