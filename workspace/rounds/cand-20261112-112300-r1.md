# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 4 轮；本轮灵感：「轻量化结构」×「腕部相机」）

> 第 57 轮把"证据质量"交给跨区域摊销的元推断器，并用 OOD 门 + 共形带兜底；但它默认了一个从未被检验的前提：**测量仪器是稳定且已知的**。视觉、触探、本体、声学四条证据流被当作"对世界的读数"，所有残差都被归因给世界或先验。真实四足不是这样：轻量化结构（碳纤维/串联弹性腿）靠形变换取力信息，代价是磨损、裂纹、温漂让柔度矩阵与模态指纹缓慢改变；腕部相机贴着足端看接触斑，代价是窄视野、运动模糊、自遮挡，且它的外参直接耦合在会形变的腿上。于是第 58 轮面对一个第 57 轮无法提出的问题：**当证据变了，是世界变了，还是我变了？** 二者在观测上同残差、可混淆。本轮把"证据说可信"升级为 **"仪器可溯源、漂移可辨识、本体自校准的证据说可信"**：轻量化结构提供内嵌的低质量基准（每次落脚即一次结构"敲击测试"），腕部相机提供接触近端的双向观测（既看世界也看自己的足），两者组成互校准闭环；但闭环存在不可自观测的 gauge 自由度，必须显式锚定与声明。

核心矛盾：
- **H29（漂移 vs 变化不可辨识）**：世界变化 δ_w 与仪器漂移 δ_i 经同一雅可比映射到同一残差；没有物理独立的世界不变参考，二者不可分离。第 57 轮的 OOD 门会把"我老了"误判为"世界新了"，或反之把"世界变了"藏进"我老了"。
- **H30（轻量化 vs 基准质量）**：轻量化结构既是接触信息最丰富的传感器（柔度编码力），又是最不稳定的基准（振动、温漂、磨损）。越省质量、越贴身的参考，越容易被环境共模污染——基准不是免费的。
- **H31（近端视野 vs 循环校准）**：腕部相机解决最后一寸的接触几何，却窄视野、易模糊、易自遮挡，且"越近越可信"的直觉会让它被过度信任；更麻烦的是，它的标定依赖它要检验的本体，构成循环。

## 0. 直觉与动机

**灵感 1（轻量化结构 → 本体即基准、落脚即自检）**
直觉：轻量化腿是"会说话的弹簧"——形变里有力，振动里有健康。碳纤维/串联弹性结构的模态指纹（固有频率、阻尼、阶次）会随裂纹、松动、温漂、载荷缓慢漂移，因此**每次落脚后的余振都是一次免费的敲击测试**：不需要额外传感器，本体自己报告"我还是不是标定时那个我"。但这份报告本身是相对的、带噪的、且随环境（风、地面耦合、温度）变化——它给的是"可检测的漂移"，不是"绝对的真值"。

**灵感 2（腕部相机 → 接触近端的双向观测）**
直觉：贴在踝/足端的相机把感知推到接触斑上，解决了全局相机"看得见却看不清最后一寸"的问题。关键不在"近"，而在**双向**：同一颗相机既可 world-facing 看接触斑（几何/纹理/湿度），又可 self-facing 看自己的足端 fiducial 与形变。于是"会被世界骗的眼睛"可以随时被"看自己的眼睛"对账，反之亦然。但近端观测有明确的认识论地平线：超出 d_c / 模糊超阈 / 自遮挡过高，它就只是弱证据，不能冒充强证据。

**灵感 3（合流 → 漂移-变化可辨识性与仪器条件化证据）**
直觉：第 57 轮把证据当"世界的函数"；本轮把证据当"世界与本体的联合函数" o=g(θ_w,θ_i)。于是安全问题的形态变了：不再是"如何更准地估计世界"，而是"**沿哪个方向我能把世界的改变与我的改变分开**"。做法是把各通道的雅可比与一组"世界不变的参考通道"（肢体模态指纹、重力方向、已知标尺尺寸）堆成元测量可观测矩阵；满秩方向才允许证据提升置信，秩亏方向只能"混淆加宽"，绝不制造虚假精度。

**灵感 4（互校准闭环 → 结构校相机、相机校结构）**
直觉：结构与相机互相校准——已知肢体几何/标尺把相机外参与尺度钉住，相机看足端形变反演柔度与磨损。闭环让标定从"停机维护"变成"持续在线"，但闭环有一个不可自观测的 gauge 子空间（全局尺度、全局位姿、时间偏移）：你无法用自己校准自己来消除共模漂移。所以必须锚定一个慢变外部不变量并**声明 gauge 漂移界 δ_g**——诚实地说"这一部分我测不到，只能界住"。

**灵感 5（D-PCE → 自检探针与事后重解释）**
直觉：把"自检"加入探询预算（k_self，非破坏性）：足端轻击已知基准读模态指纹、小幅摆腿读柔度、腕相机看自身足端。检出漂移后，不假装能撤销已发生的动作，而是对上次标定以来的证据做**事后重解释**（按 δ̂_i 反演似然、加宽信念），把窗口内已承诺接触标记为"事后风险"入审计；不可逆接触前若仪器健康低于阈值，强制重标定或降档/绕行/安全停。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（本体-仪器状态 EIS）** 仪器状态 θ_i(t)=(K_b(t) 柔度矩阵, f_mode(t) 模态指纹, w_t 磨损/裂纹指标, T_c(t) 腕相机外参, ξ_c(t) 镜头与标定健康, m_t 载荷)；世界状态 θ_w；观测 o_t=g(θ_w,θ_i)+ε_t。仪器健康 h(t)=(h_struct,h_cam)∈[0,1]²，h=1−‖θ_i(t)−θ_i(t_cal)‖/δ_i,max，漂移上界 δ_i(Δt) 随标定纪元单调增。信念条件化为 b_r=P(θ_w | o, θ_i, h)。

**定义 140（元测量可辨识分解 MID）** 联合雅可比 J=[J_w|J_i]=[∂g/∂θ_w|∂g/∂θ_i]；参考通道集 ℛ，元测量可观测矩阵 O=[J; R]。若 O 在决策相关方向满秩，则解出 (δ̂_w,δ̂_i)；若存在 v∈null(O) 且 v_w≠0，称该方向**漂移混淆**，其证据不得提升置信，只触发**混淆加宽** P(θ_w)←P(θ_w)⊛N(0,Σ_v)，Σ_v=α·v_w v_w^T。参考通道须满足世界不变性 ‖∂h_ref/∂θ_w‖≤ε_ref：模态指纹（结构）、重力/IMU（位姿）、已知标尺（尺度）。

**定义 141（腕部近端感知 WCP）** 相机位姿 T_c(θ_i) 与肢体形变耦合，视野 Ω_c 窄；观测分 world-facing o_c^W（接触斑几何/纹理/湿度）与 self-facing o_c^S（足端/肢体 fiducial）。**认识论地平线**：仅当距离 d≤d_c、模糊 blur≤β_c、自遮挡率 occ≤ω_c 时为有效强观测，否则降级为弱证据。误差模型 p(o_c|θ_w,θ_i,T_c) 显式含运动模糊与自遮挡。

**定义 142（互校准闭环 MCL）** 因子图 F(θ_i,T_c;{o_c^S,足底力/形变,f_mode})，交替优化：结构→相机（已知肢体几何/标尺定 T_c 与尺度），相机→结构（足端形变反演 K_b、磨损）。Gauge 自由度 g=(尺度,位姿,时间偏移) 不可自观测，须锚定外部不变量 a_ext 并声明 gauge 漂移界 δ_g；收敛判据为残差下降且 gauge 固定。

**定义 143（仪器健康证据门 IHG 与证书 J_q）** 每条证据 e 附溯源链 τ(e)=(仪器 id/版本, 采集时 h, 标定纪元, 所用参考通道, 漂移界 δ_i)。强证据条件：h≥h_min ∧ 标定纪元未过期 ∧ e 的信息方向不在 null(O) 内；否则降级为弱/相对证据，不得充当 EV-probe\*/EV-xmodal 的强证据，不得进入不可逆接触必要证据集。J_q=J_p∪(trace_log,health_log,identifiability_log,gauge_log,recal_log)。第 57 轮"一切判定器走隔离"推广为"**一切测量仪器（含本体）走溯源**"。

**定义 144（漂移感知探-诺-演 D-PCE）** 每检查点插入自检探针（k_self，非破坏性）；检出漂移 δ̂_i 后对 [t_cal,t] 证据**事后重解释**（反演似然、加宽、审计标记），不可逆接触前 h<h_min ⇒ 强制 MCL 重标定，仍不达标则降档/绕行/安全停。承诺仍继承第 57 轮证据门，但额外要求 IHG 通过且决策方向非混淆。

## 2. 关键算法伪代码（完整版见产物区）

```python
def instrument_state_update(obs_self, prev):            # IP-139
    K_b = estimate_compliance(obs_self); f_mode = modal_fingerprint(obs_self)
    T_c = estimate_extrinsic(obs_self)
    return Theta_i(K_b, f_mode, wear=f_mode.drift, T_c=T_c,
                   h=health_score(K_b, f_mode, T_c, prev))

def identifiability_decompose(o, theta_i, refs):        # IP-140
    O = vstack([jacobian_world_instrument(o, theta_i), refs.jacobian()])
    if rank_deficient(O, decision_dir(o)):
        v = null_vector(O)                              # 漂移混淆方向
        return Decomp(confounded=True, widen=alpha*outer(v.w, v.w))
    dw, di = solve_weighted(O, o - g(theta_i, refs))
    return Decomp(dw=dw, di=di, confounded=False)

def traceable_evidence_gate(e, theta_i, ident):         # IP-143
    tau = (theta_i.id, theta_i.h, theta_i.cal_epoch, e.ref, theta_i.drift_bound)
    if theta_i.h < H_MIN or stale(theta_i.cal_epoch):
        return ('downgrade', 'instrument_unhealthy', tau)
    if ident.confounded and informs(e, ident.null_dir):
        return ('downgrade', 'drift_confounded', tau)   # 不制造虚假精度
    return ('ok', tau)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| EIS | O(d_i)/自检 | O(d_i) | 漂移界 δ_i 诚实、健康分可审计 |

| D-PCE | 第57轮 + O(k_self·\|CP\|) | O(\|V\|+\|σ\|) | k_self 终止、四态完备 |

**正确性定理（MGS 概要）**：在 A33–A40 上加 (A41) 仪器健康与漂移界诚实；(A42) 元测量可观测矩阵在决策方向满秩，否则判混淆并加宽，参考通道世界不变性 ≤ε_ref；(A43) WCP 地平线误差模型诚实；(A44) MCL 的 gauge 已锚定、δ_g 有界；(A45) 事后重解释的漂移反演误差 ≤ε_drift。则：(i) 仪器条件化承诺失效率 ≤ δ_f+ε_meta(k)+δ_probe+ε_h(w_max)+δ_i·1[未标定]+ε_drift；(ii) 可辨识单调性：混淆方向只能加宽、不能收窄，不存在"漂移驱动的虚假精度"；(iii) 无免费午餐：自校准降低 θ_i 方差，但不消除 gauge 零空间，共模漂移只能被界住、不能被测掉；(iv) D-PCE 在 k_probes+k_cons+k_self 内终止。

## 6. 本轮最大风险

**一句话**：本轮试图把"世界变了还是我变了"分开，但参考链的底部是一个无法被自校准验证的 gauge 锚点——若某类共模漂移同时作用于结构基准与 world-facing 相机（如整机缓慢热变形让腿的模态与相机外参朝同向漂移），它在 null(O) 里不可辨识，系统会把自身的衰老自信地归因给世界（或把真实的世界变化藏进"我老了"），而溯源证书反而让这个错误承诺看起来更严谨。

```python
    f_mode = modal_fingerprint(obs_self)             # 落脚余振 = 免费敲击测试
```

### IP-140 MID（漂移-变化可辨识分解）

```python
def identifiability_decompose(o, theta_i, refs):
    J = jacobian_world_instrument(o, theta_i)        # [J_w | J_i]
    O = vstack([J, refs.jacobian()])                 # 模态指纹/重力/已知标尺
    v = project(null_space(O), decision_dir(o))      # 决策方向上的零空间分量
    if norm(v.w) > EPS_CONF:                         # 世界分量不可辨识
        return Decomp(confounded=True, null_dir=v,
                      widen=alpha * outer(v.w, v.w))  # 只加宽，不提升置信
    dw, di = weighted_lstsq(O, o - g(theta_i, refs))
    return Decomp(dw=dw, di=di, confounded=False)

def apply_decomp(b_r, dec):
    if dec.confounded:
        return inflate(b_r, dec.widen)               # 混淆加宽
    return condition_on(b_r, dec.dw, dec.di)         # 仪器条件化更新
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| EIS | O(d_i)/自检 | O(d_i) | 漂移界 δ_i 诚实、健康分可审计（A41） |
| MID | O((d_w+d_i)^3)/检查点（小维） | O(d_w+d_i) | 满秩才置信、秩亏只加宽（A42） |
| WCP | O(res)/帧 | O(Ω_c) | 地平线误差模型诚实（A43） |
| MCL | O(iters·\|F\|)，周期触发 | O(\|F\|) | gauge 锚定、δ_g 有界（A44） |
| IHG | O(\|σ\|) | O(\|σ\|) | 无溯源即降级、混淆方向不提升置信 |
| D-PCE | O(\|CP\|·(k_p+k_c+k_s)·(C_VOI+d_φ)) | O(\|V\|+\|σ\|) | k_self 终止、四态完备 |

**正确性定理（Metrologically Grounded Soundness, MGS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 仪器健康与漂移界诚实：h 的计算可复核，实际漂移 ‖θ_i(t)−θ_i(t_cal)‖≤δ_i(t−t_cal)；**(A42)** 元测量可辨识性：O 在决策相关方向满秩，否则系统判混淆并加宽；参考通道世界不变性 ‖∂h_ref/∂θ_w‖≤ε_ref；**(A43)** WCP 地平线误差模型诚实（模糊/遮挡/距离超阈时正确降级）；**(A44)** MCL 的 gauge 已由外部不变量锚定，gauge 漂移 ≤δ_g；**(A45)** 事后重解释的漂移反演误差 ≤ε_drift。则：

1. **仪器条件化承诺健全性**：P(fail) ≤ δ_f + ε_meta(k) + δ_probe + ε_h(w_max) + δ_i·1[未标定] + ε_drift + δ_xm·1[L1]。
2. **可辨识单调性**：在 null(O) 的决策方向上，任何证据只能加宽后验、不能收窄；即不存在"漂移驱动的虚假精度"。这是第 57 轮交互单调性在计量维度的延伸。
3. **无免费午餐**：MCL 降低 θ_i 的可估方差，但不消除 gauge 零空间；共模漂移与全局尺度只能被锚定并界住，不能被"自校准测掉"。因此证书必须显式声明 δ_g，不得声称绝对基准。
4. **终止性**：每检查点自检 ≤k_self、共识探针 ≤k_cons、探针 ≤k_probes，D-PCE 终止于 {承诺, 绕行, L2 协商, 安全停}。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                  + δ_i·1[未标定] + ε_drift + δ_g)
             − P(𝓜 陈旧未检出) − P(护盾回退失败)
             − P(自检漏检 ∧ 共模漂移)
```

关键：**本体即基准、落脚即自检**（轻量化结构的余振是免费的结构健康信号）；**近端双向观测**（同一腕相机既看世界又看自己，地平线外即降级）；**可辨识才置信、混淆只加宽**（把"世界变了还是我变了"变成秩条件而非口号）；**gauge 不可自测，只能锚定与声明**（诚实地承认测不到的部分）。

## 6. 本轮最大风险

**一句话**：本轮试图把"世界变了还是我变了"分开，但参考链的底部是一个无法被自校准验证的 gauge 锚点——若某类共模漂移同时作用于结构基准与 world-facing 相机（如整机缓慢热变形让腿的模态与相机外参朝同向漂移），它在 null(O) 里不可辨识，系统会把自身的衰老自信地归因给世界（或把真实的世界变化藏进"我老了"），而溯源证书反而让这个错误承诺看起来更严谨。
