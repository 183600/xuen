# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 2 轮；本轮灵感：「灵巧操作」×「末端位姿」）

> 第 54 轮把技能组合建立在动作空间剖面 `α_S`、兼容性图 `G_S` 与云边映射 `γ_ce` 上。本轮把“动作空间”推进到“末端位姿流形 `SE(3)`”，把“能力”推进到“接触约束下的灵巧度场 `D_S`”。核心矛盾：**H22**：末端位姿可达、甚至位姿跟踪成功，并不等于在该位姿上具备灵巧操作能力——纯位姿证书会在接触富集任务中系统性失效；**H23**：云端以粗位姿路点规划，边端以细位姿 + 接触调节执行，位姿容差与接触相位切换在两层间不同步，导致“位姿到了但抓不住、转不动”。

## 0. 直觉与动机

**灵感 1（末端位姿是“管”而不是“点”）**
直觉：机器人真正承诺给下一位姿的，不是一个精确点 `p∈SE(3)`，而是一个**允许误差的位姿管** `T(p_0; r)`。因为运动学标定、伺服延迟、接触力扰动都会让实际位姿落在 `p_0` 附近。若只在中心点验证灵巧度，边界上的位姿可能已经滑出摩擦锥。把位姿从点升级为管，才可能让证书覆盖真实执行误差。

**灵感 2（灵巧度是位姿与接触构型的函数）**
直觉：同一末端位姿，手指构型不同、接触点不同，可操作度与可施加力旋量完全不同。因此灵巧度不是技能常量，而是场 `D_S : SE(3) × C → R^4_{\ge 0}`，至少包含四维：速度可操作度、力旋量可操作度、摩擦锥裕度、抓取矩阵最小奇异值。技能 S 的能力 = 它在位姿-接触空间中的**高灵巧度区域**，而不是一个位姿点集合。

**灵感 3（接触相位才是灵巧操作真正的动作不连续点）**
直觉：灵巧操作的动作连续性不在位姿上，而在**接触相位** `φ`（接近→建立接触→抓取→手内操作→释放）上。相位切换时接触集合改变，雅可比与摩擦锥离散跳变，灵巧度场可能瞬间塌陷。组合两个灵巧技能时，真正危险的是相位边界，而不是位姿插值本身。因此位姿管必须携带相位标签，组合必须做“相位对齐”。

**灵感 4（灵巧组合 = 位姿管串联 + 沿测地线灵巧度不塌陷）**
直觉：技能 `S_i` 的出口位姿管与 `S_j` 的入口位姿管相交还不够，还要保证从出口到入口的 `SE(3)` 测地线上，灵巧度场始终不低于阈值 `δ`。否则会出现“两端都行、中间塌陷”的组合假象——例如从侧抓翻转到顶抓时经过一个无法施力的奇异位形。

**灵感 5（云边协同 = 位姿路点契约 + 接触回传）**
直觉：云端负责粗位姿路点 `{p_k^c}` 与灵巧度包络，边端负责细位姿伺服与接触调节。云端承诺的位姿容差必须被边端的实际跟踪误差 `δ_p` 收缩覆盖；边端一旦检测到摩擦裕度跌破阈值，就通过“接触回传”把滑移根因送回云端，触发位姿路点重规划与灵巧度场重采样。这把第 54 轮的 `Explain_loop` 从动作层下沉到接触层。

**灵感 6（金字塔再加“灵巧层”）**
直觉：在第 54 轮动作-协同层 `𝔸` 之上叠加灵巧层 `𝔻`：`𝔻_0` 关节/摩擦物理极限，`𝔻_1` 灵巧度场，`𝔻_2` 位姿管与接触相位，`𝔻_3` 云边位姿契约。跨层证书同时携带 `ρ`、`A_cert`、`T_pose`、`D_min`、`φ`，形成**动作-鲁棒性-灵巧三重证书**。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（末端位姿流形与加权度量）**
末端位姿 `p=(R,t)∈SE(3)`，相对位姿误差 `ξ = log(p_a^{-1}p_b)∈se(3)`，`ξ=(ω,v)`。加权范数
```
||ξ||_W^2 = ω^T W_R ω + v^T W_t v,   W_R,W_t ≻ 0
```
位姿距离 `d_W(p_a,p_b)=||log(p_a^{-1}p_b)||_W`。`W` 用于统一“弧度”和“米”的量纲，并允许按任务调节旋转/平移容差。

**定义 122（位姿管）**
以 `p_0` 为中心、半径 `r` 的位姿管
```
T(p_0; r) = { p∈SE(3) | d_W(p_0,p) ≤ r }
```
位姿管是可执行误差集合的过近似；后续所有灵巧证书都在管上而非点上成立。

**定义 123（灵巧度场）**
接触构型 `c∈C`（含接触点、法向、摩擦系数、手指分配），技能 S 的灵巧度场
```
D_S(p,c) = ( μ_v(p,c)/μ_ref,  μ_w(p,c)/μ_ref,  m_f(p,c),  m_c(p,c) ) ∈ R^4_{\ge 0}
```
其中 `μ_v=sqrt(det(J_h J_h^T))` 为速度可操作度，`μ_w=sqrt(det(G G^T))` 为力旋量可操作度，`m_f = min_i dist(f_i, ∂FC_i)/||f_i||` 为归一化摩擦锥裕度，`m_c = σ_min(G)` 为抓取稳定裕度。各分量记作 `D_{S,k}`。

**定义 124（δ-灵巧可达域）**
```
R_S(δ) = { (p,c) | ∀k∈{1..4}: D_{S,k}(p,c) ≥ δ_k }
```
`R_S(δ)` 是运动学可达域的子集：位姿可达只是必要条件，灵巧可行才是部署条件。

**定义 125（位姿管证书）**
技能 S 的位姿管证书 `P_cert = (p_0, r, δ, c, evidence)`。称其 **sound**，当且仅当
```
T(p_0;r) × {c} ⊆ R_S(δ)
```
且 `evidence` 含边界位姿采样与摩擦锥红队反例。sound 性由定义 127 的 Lipschitz 引理从中心点提升到整管。

**定义 126（接触相位与相变代价）**
接触相位 `φ∈Φ={approach, make, grasp, in-hand, release}`。相变 `τ=(φ_a→φ_b)` 附带位姿连续容差 `ε_φ` 与相变代价 `c_φ`。相变合法当且仅当
```
max_t d_W(p_t,p_{t^-}) ≤ ε_φ  ∧  FC(c_t) ≠ ∅  ∧  c_φ ≤ τ_φ
```
手内操作相 `in-hand` 额外要求物体相对手掌的位姿 `p_o` 连续，且接触集合不被清空。

**定义 127（灵巧组合图）**
灵巧组合图 `G_D=(V_D,E_D)`，节点为带入口/出口位姿管与相位的技能，边 `(S_i,S_j)` 存在当且仅当
```
T_i^exit ∩ T_j^entry ≠ ∅
∧ phase_compatible(φ_i^exit, φ_j^entry)
∧ min_{p∈geodesic(p_i^exit,p_j^entry)} D_{S_i⊗S_j,k}(p,c) ≥ δ_k  ∀k
```
边证书 `C_comp^D = (T_i^exit∩T_j^entry, τ_φ, D_min, evidence)`。

**定义 128（云边位姿契约与联合灵巧证书）**
云边位姿契约 `C_ce^pose = ({p_k^c,W_k^c}, γ_ce^pose, κ, η, Explain_contact)`：
- `{p_k^c,W_k^c}` 为云端粗位姿路点及其容差管；
- `γ_ce^pose` 把粗路点映射为边端细位姿参考；
- 跟踪误差 `e_t = log((p_t^c)^{-1}p_t^e)` 满足收缩 `||e_{t+1}||_W ≤ κ||e_t||_W + η`，`κ<1`；
- `Explain_contact` 回传滑移/摩擦锥根因。

联合灵巧证书
```
J_D = (ρ, T_pose, D_min, φ_schedule, γ_ce^pose, δ_p, evidence)
```
部署条件：`D_min ≥ δ_min`、`δ_p ≤ Θ_p`、所有相变合法、接触滑移概率 ≤ 预算。`ρ` 沿用第 53–54 轮鲁棒性谱，`T_pose` 为串联位姿管。

## 2. 关键算法 伪代码

### IP-121 DFP（Dexterity Field Profiling）

```python
def dexterity_field(skill, poses, contacts, sampler, mu_ref):
    D = {}
    for p in poses:
        for c in contacts:
            J = skill.hand_jacobian(p, c)
            G = skill.grasp_matrix(p, c)
            mu_v = sqrt(det(J @ J.T))
            mu_w = sqrt(det(G @ G.T))
            m_f  = min_friction_margin(skill.contact_wrenches(p, c))
            m_c  = min_singular_value(G)
            D[(p, c)] = (mu_v/mu_ref, mu_w/mu_ref, m_f, m_c)
    return active_refine(D, sampler, boundary="contact_mode")
```

`active_refine` 在接触模式边界与灵巧度梯度最大处加密采样，避免“内部很准、边界全错”。

### IP-122 PTC（Pose Tube Certificate，Lipschitz 提升）

```python
def pose_tube_certificate(skill, p0, r, delta, lipschitz):
    # lipschitz[k] 为 D_{S,k} 在 d_W 下的局部 Lipschitz 常数上界
    D0 = dexterity_field(skill, [p0], contacts=skill.contacts_at(p0), ...)
    r_safe = min((D0[k] - delta[k]) / lipschitz[k] for k in D0)
    if r > r_safe:
        return ('shrink', min(r, r_safe))
    return ('ok', PoseCert(p0, r, delta, skill.contacts_at(p0)))
```

核心是引理：`D(p) ≥ D(p0) - L·d_W(p,p0)`，因此中心点留出 `L·r` 余量即可保证整管 sound。

### IP-123 CCM（Contact Composition Morphism）

```python
def compose_dexterous(Si, Sj, delta, kappa_phase):
    T = intersect_tubes(Si.exit_tube, Sj.entry_tube)
    if T is None:
        return ('reject', 'pose_tube_disjoint')
    if not phase_compatible(Si.exit_phase, Sj.entry_phase):
        return ('reject', 'phase_mismatch')
    path = geodesic(Si.exit_pose, Sj.entry_pose)
    Dmin = min_along_path(dexterity_field_compose(Si, Sj), path)
    if any(Dmin[k] < delta[k] for k in Dmin):
        return ('reject', 'dexterity_dip', Dmin)
    return ('ok', ComposeCert(T, phase_transition_cert(Si, Sj), Dmin))
```

### IP-124 PEC（Pose-Edge Consistency）

```python
def edge_pose_refine(P_c, gamma_pose, controller, kappa, eta, Theta_p, delta_f):
    e = zero_twist()
    for k, (p_c, W_c) in enumerate(P_c):
        p_ref = gamma_pose(p_c)
        p_e = controller.servo(p_ref)
        e = pose_log(inverse(p_ref) @ p_e)
        if norm_W(e) > Theta_p:
            return ('reject', 'pose_drift', explain_contact(p_e))
        if min_friction_margin(controller.contacts()) < delta_f:
            return ('reject', 'contact_slip', explain_contact(p_e))
        if not contractive(e, kappa, eta):
            return ('reject', 'non_contractive', e)
    return ('ok', TrackCert(P_c, e, controller.phase_schedule()))
```

### IP-125 JDC（Joint Dexterity Certificate）

```python
def joint_dexterity_certificate(skill_seq, gamma_pose, delta, Theta_p):
    T_pose = chain_pose_tubes([s.exit_tube for s in skill_seq])
    D_min = min_chain_dexterity(skill_seq)
    delta_p = max_pose_drift(gamma_pose, skill_seq)
    phases = check_phase_schedule(skill_seq)
    if any(D_min[k] < delta[k] for k in D_min):
        return ('reject', 'dexterity_budget', D_min)
    if delta_p > Theta_p:
        return ('reject', 'pose_budget', delta_p)
    if not phases.valid:
        return ('reject', 'phase_invalid', phases.counterexample)
    rho = compose_robustness_chain([s.rho for s in skill_seq], K)
    return ('ok', JDC(rho, T_pose, D_min, phases, gamma_pose, delta_p))
```

### IP-126 DSR（Dexterity-Safe Replanning）

```python
def dexterity_safe_replan(failure, G_D, delta):
    if failure.kind not in ('contact_slip', 'dexterity_dip', 'pose_drift'):
        return ('escalate', failure)
    root = explain_contact(failure.sim_trace)          # 接触层反向解释
    region = root.contact_region
    delta_local = tighten_delta(delta, root.margin_loss)  # 局部收紧阈值
    G_D = reprofile(G_D, region, delta_local)             # 重采样边界
    return ('replan', a_star(G_D, goal=failure.task, edge_cost=dexterity_cost))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| DFP | `O(|P|·|C|·n^3)` | `O(|P|·|C|)` | 接触边界覆盖、Lipschitz 估计上界 |
| PTC | `O(|P|·|C|·n^3)` + `O(1)` 管检查 | `O(|P|·|C|)` | `r_safe` 由 Lipschitz 上界保守给出 |
| CCM | `O(|path|·|C|·n^3)` | `O(|path|·|C|)` | 测地线采样密度、相变合法 |
| PEC | `O(|P_c|·(n + |contacts|))` | `O(|P_c|)` | 收缩 `κ<1`、回传延迟有界 |
| JDC | `O(Σ_i |T_i|·n^3)` | `O(Σ_i |T_i|)` | 管串联 sound、预算闭合 |

**引理 1（位姿管灵巧度 soundness）**
若对每个 `k` 有 `D_{S,k}(p_0,c) ≥ δ_k + L_k·r`，且 `D_{S,k}` 在 `T(p_0;r)` 上关于 `d_W` 以 `L_k` Lipschitz，则 `∀p∈T(p_0;r)` 有 `D_{S,k}(p,c) ≥ δ_k`。证明：`D(p) ≥ D(p_0) - L_k d_W(p,p_0) ≥ δ_k + L_k r - L_k r = δ_k`。

**引理 2（相变接触保持）**
若相变期间位姿跳变 `≤ ε_φ`，且摩擦裕度满足 `m_f ≥ L_f·ε_φ + m_f^{min}`，则相变不破坏接触（`FC(c_t)≠∅` 且滑移概率 ≤ β_c）。

**正确性定理（Pose-Dexterity Composition Soundness）**
在 (A22)–(A28) 之外增加：**(A29)** `D_{S,k}` 在 `SE(3)` 上局部 `L_k`-Lipschitz，且 δ-覆盖采样误差 `≤ ε_D`；**(A30)** 位姿管传播 sound，实际跟踪误差始终落在 `T(p_ref; r_track)` 且 `r_track ≤ Θ_p`；**(A31)** 每次相变滑移概率 `≤ β_c`，共 `N_φ` 次；**(A32)** 云边位姿误差收缩 `κ<1`、`η` 有界，`Explain_contact` 延迟 `≤ τ_loop`。则
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_p>Θ_p) - N_φ·β_c - P(sampling gap)
```
关键：**灵巧度从点提升到管**、**相变是显式可判定事件**、**云边位姿误差必须收缩**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| `SE(3)` 六维灵巧度场欠采样 | 高 | 主动采样 + 接触边界加密 + 贝叶斯优化 |
| 接触模式边界处 `D_S` 非 Lipschitz | 高 | 分段局部 Lipschitz + 边界独立证书 + 保守回退 |
| 位姿管度量的各向异性 | 中 | 任务自适应 `W` + 标定 + 保守膨胀 |
| 云端路点与边端接触节拍不同步 | 高 | 收缩契约 `κ<1` + 接触回传 + 相位锁 |
| 仿真摩擦系数与真机偏差 | 高 | 摩擦锥红队 + 域随机化 + 在线辨识 |

## 6. 本轮最大风险

**一句话**：把“点上的灵巧度”通过局部 Lipschitz 界提升为“位姿管上的灵巧证书”，在数学上干净，但其最大风险是把**接触模式边界误当作光滑区域**——一旦在接触集合切换处欠采样，`D_S` 的剧烈跳变会让管证书给出“位姿可达且灵巧可行”的虚假安全结论，真机随即滑移或失稳；因此必须以 **接触边界独立采样 + 分段局部 Lipschitz 上界 + 摩擦锥红队绊线** 三重护栏，宁可缩小位姿管，也不把边界外推当成本轮方法的胜利。

## 2. 关键算法 伪代码

### IP-121 DFP

```python
def dexterity_field(skill, poses, contacts, sampler, mu_ref):
    D = {}
    for p in poses:
        for c in contacts:
            J = skill.hand_jacobian(p, c)
            G = skill.grasp_matrix(p, c)
            mu_v = sqrt(det(J @ J.T))
            mu_w = sqrt(det(G @ G.T))
            m_f  = min_friction_margin(skill.contact_wrenches(p, c))
            m_c  = min_singular_value(G)
            D[(p, c)] = (mu_v/mu_ref, mu_w/mu_ref, m_f, m_c)
    # 边界加密：接触集合切换处梯度可能发散
    return active_refine(D, sampler, boundary="contact_mode", budget=B)
```

### IP-122 PTC

```python
def pose_tube_certificate(skill, p0, r, delta, lipschitz):
    D0 = dexterity_field(skill, [p0], skill.contacts_at(p0), sampler, mu_ref)
    r_safe = min((D0[k] - delta[k]) / lipschitz[k] for k in D0)
    if r > r_safe:
        return ('shrink', PoseCert(p0, max(0.0, r_safe), delta,
                                   skill.contacts_at(p0)))
    return ('ok', PoseCert(p0, r, delta, skill.contacts_at(p0)))

# 引理：D(p) >= D(p0) - L*d_W(p,p0)，故中心留 L*r 余量可保证整管 sound
```

### IP-123 CCM

```python
def compose_dexterous(Si, Sj, delta, tau_phi):
    T = intersect_tubes(Si.exit_tube, Sj.entry_tube)
    if T is None:
        return ('reject', 'pose_tube_disjoint')
    tau = phase_transition(Si.exit_phase, Sj.entry_phase)
    if tau is None or tau.cost > tau_phi:
        return ('reject', 'phase_mismatch')
    path = geodesic(Si.exit_pose, Sj.entry_pose)
    Dmin = min_along_path(dexterity_field_compose(Si, Sj), path)
    if any(Dmin[k] < delta[k] for k in Dmin):
        return ('reject', 'dexterity_dip', Dmin)
    return ('ok', ComposeCert(T, tau, Dmin))
```

### IP-124 PEC

```python
def edge_pose_refine(P_c, gamma_pose, controller, kappa, eta,
                     Theta_p, delta_f):
    e = zero_twist()
    for p_c, W_c in P_c:
        p_ref = gamma_pose(p_c)
        p_e = controller.servo(p_ref)
        e = pose_log(inverse(p_ref) @ p_e)
        if norm_W(e) > Theta_p:
            return ('reject', 'pose_drift', explain_contact(p_e))
        if min_friction_margin(controller.contacts()) < delta_f:
            return ('reject', 'contact_slip', explain_contact(p_e))
        if not contractive(e, kappa, eta):
            return ('reject', 'non_contractive', e)
    return ('ok', TrackCert(P_c, e, controller.phase_schedule()))
```

### IP-125 JDC

```python
def joint_dexterity_certificate(skill_seq, gamma_pose, delta, Theta_p):
    T_pose = chain_pose_tubes([s.exit_tube for s in skill_seq])
    D_min = min_chain_dexterity(skill_seq)
    delta_p = max_pose_drift(gamma_pose, skill_seq)
    phases = check_phase_schedule(skill_seq)
    if any(D_min[k] < delta[k] for k in D_min):
        return ('reject', 'dexterity_budget', D_min)
    if delta_p > Theta_p:
        return ('reject', 'pose_budget', delta_p)
    if not phases.valid:
        return ('reject', 'phase_invalid', phases.counterexample)
    rho = compose_robustness_chain([s.rho for s in skill_seq], K)
    return ('ok', JDC(rho, T_pose, D_min, phases,
                      gamma_pose, delta_p))
```

### IP-126 DSR

```python
def dexterity_safe_replan(failure, G_D, delta):
    if failure.kind not in ('contact_slip', 'dexterity_dip', 'pose_drift'):
        return ('escalate', failure)
    root = explain_contact(failure.sim_trace)        # 接触层反向解释
    delta_local = tighten_delta(delta, root.margin_loss)
    G_D = reprofile(G_D, root.contact_region, delta_local)
    path = a_star(G_D, goal=failure.task, edge_cost=dexterity_cost)
    if path is None:
        return ('reject', 'no_dexterity_safe_path', root)
    return ('replan', path, root)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DFP | `O(|P|·|C|·n^3)` + 主动采样 `O(B)` | `O(|P|·|C|)` | 接触边界覆盖、Lipschitz 上界 |
| PTC | `O(|P|·|C|·n^3)` + `O(1)` | `O(|P|·|C|)` | `r_safe` 保守、整管 sound |
| CCM | `O(|path|·|C|·n^3 + |V| log|V|)` | `O(|path|·|C|)` | 管串联、相位合法、测地线不塌陷 |
| PEC | `O(|P_c|·(n+|contacts|))` | `O(|P_c|)` | `κ<1`、回传延迟 ≤ τ_loop |
| JDC | `O(Σ_i|T_i|·n^3)` | `O(Σ_i|T_i|)` | 三重预算闭合、证书 sound |
| DSR | `O(|V| log|V| + |E| + reprofile)` | `O(|V|+|E|)` | 根因可解释、重采样收敛 |

**引理 1（位姿管灵巧度 soundness）**
若 `∀k: D_{S,k}(p_0,c) ≥ δ_k + L_k r` 且 `D_{S,k}` 在 `T(p_0;r)` 上 `L_k`-Lipschitz，则 `∀p∈T(p_0;r): D_{S,k}(p,c) ≥ δ_k`。

**引理 2（相变接触保持）**
若相变位姿跳变 `≤ ε_φ` 且 `m_f ≥ L_f ε_φ + m_f^{min}`，则 `FC(c_t)≠∅` 且滑移概率 `≤ β_c`。

**正确性定理（Pose-Dexterity Composition Soundness）**
在 (A22)–(A28) 成立之外，增加 **(A29)** 灵巧度场局部 Lipschitz 且 δ-覆盖采样误差 `≤ ε_D`；**(A30)** 位姿管传播 sound，跟踪误差始终落在 `T(p_ref; r_track)` 且 `r_track ≤ Θ_p`；**(A31)** 每次相变滑移概率 `≤ β_c`，共 `N_φ` 次；**(A32)** 云边位姿误差收缩 `κ<1`、`η` 有界、`Explain_contact` 延迟 `≤ τ_loop`。则
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E
            - P(δ_p > Θ_p) - N_φ·β_c - P(sampling gap)
```

## 6. 本轮最大风险

**一句话**：把“点上的灵巧度”通过局部 Lipschitz 界提升为“位姿管上的灵巧证书”，在数学上干净，但其最大风险是把**接触模式边界误当作光滑区域**——一旦在接触集合切换处欠采样，`D_S` 的剧烈跳变会让管证书给出“位姿可达且灵巧可行”的虚假安全结论，真机随即滑移或失稳；因此必须以 **接触边界独立采样 + 分段局部 Lipschitz 上界 + 摩擦锥红队绊线** 三重护栏，宁可缩小位姿管，也不把边界外推当成本轮方法的胜利。
