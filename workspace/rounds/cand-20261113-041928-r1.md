# 第 65 轮（承接第 64 轮「GRIP 接触接地四层闭环」IP-204~213；灵感循环 II 第 4 轮；本轮灵感：「研究空白」×「嵌入式系统」）

> 第 64 轮用接触接地把几何先验变成可证伪假设、把安全从「不撞」扩到「不滑、不压伤」，但其自述最大风险一针见血：**力/触觉的偏置、漂移、饱和与接触模型错误会被 CGG 误判为几何幻觉，力觉从接地真值反变为新的单点故障与物理伤害源**，且实时路径已逼近 2ms。若继续「再加一层统计检验」，只会让整个体系更深地依赖一个前 64 轮从未审视的前提——**所有保证都写在「实数、无限精度、确定性时序、无限内存、离线已知传感器」的理想计算基底上**。本轮从「研究空白」出发，明确指认并填补这道空白：
>
> **把证书从「数学上成立」推进到「嵌入式上可执行、时序可认证、精度可预算、漂移可观测」——鲁棒性的下一个前沿不是更强的先验，而是「可实现性（realizability）」。**

## 0. 直觉与动机

**灵感 1（研究空白 → Realizability Gap：定理与部署之间的空白）**
直觉：一个在 GPU + float64 + 离线标定 + 无干扰时钟上验证通过的 ρ_rob，搬到 Cortex-M7 + INT8 + 电池供电 + CAN 总线抖动的控制器上，可能根本不成立。文献里「鲁棒机器人 / 学习控制」与「嵌入式安全（WCET、混合关键级、量化误差、锁步冗余）」几乎是两个不相交的社区：前者证明「给定无穷精度则安全」，后者证明「给定正确算法则按时执行」，**却极少有人把两者接起来证明「给定有限精度与硬实时约束，鲁棒性证书仍然成立」**。这就是本轮要填的研究空白：**realizability gap**——鲁棒性证书的可实现性、可时序认证性与可审计性。直觉上，证书不该只是一串实数裕度，而应携带「它凭什么在目标硬件上成立」的证据向量；一个没有证据等级的证书，只是一句愿望。

**灵感 2（嵌入式系统 → 有限精度：QAC 量化感知认证）**
直觉：定点/INT8 下每个算子都引入舍入误差，这些误差会顺着 χ² 统计量、Fisher 信息、WCV 采样与 CVaR 一路传播，最终悄悄吃掉 ρ 的安全余量。**关键洞见**：量化误差不是「实现细节」，而是必须进入证书的**额外噪声源**——把 Σ_w 换成 Σ_w + Σ_q、把 χ² 阈值按有效噪声重新标定、把整数域算出的 ρ 向下打一个可证明的折扣 Δ_q。只要保证 `ρ_exact ≥ Δ_q`，整数实现仍然安全；反之必须升位宽或降级。这把「精度」从工程参数变成安全参数。

**灵感 3（嵌入式系统 → 硬实时与混合关键级：TAC + SAD + CSD）**
直觉：2ms 契约不能靠「在我笔记本上测出来」，而要靠目标板上的 WCET / 概率 WCET。安全关键任务（力残差、滑移、力限、急停）必须无条件先跑；性能任务（OLP-F 更新、CGG 长窗口、主动探测）在超载时先被牺牲。**关键洞见**：编译也必须「任意时间（anytime）且证书单调」——deadline 到时返回「最后一个已认证的可行解」，而不是「一个没算完的更好解」。降级本身要变成**有 WCET 上界、有滞回、只允许单调下降、恢复需证据门控**的状态格，否则降级过程自身就是一段无认证的危险窗口。

**灵感 4（研究空白 → 残余解耦：RDD 把「错误」分成四种）**
直觉：第 64 轮最大风险的本质是 **CGG 只会说「模型与观测不符」，却不会说「哪里不符」**。残留 e_t 其实是四类来源的叠加：几何幻觉 δ_geo、传感器偏置/漂移 b、接触模型误差 δ_model、量化噪声 q（外加普通噪声 η）。它们有可区分的签名：b 在**自由空间无接触时也出现**且与载荷无关；δ_model **随接触力幅值成比例增长**；δ_geo **随接触集/几何解释切换而跳变**且落在接触雅可比张成的子空间；q 的幅值被 u·range 界住。于是 CGG 的「降级几何」应改成**条件化诊断**：先分类再动作——几何错才降几何，偏置错就去标定，模型错就换模型/膨胀模型不确定度，量化错就升位宽。这是对第 64 轮最大风险的正面回答，而不是继续把所有不符都推给几何。

**灵感 5（研究空白 × 嵌入式合流 → EMBER + 研究空白账本）**
直觉：EMBER（EMBedded-cErtified Executable Robustness）不是新算法堆叠，而是给 GRIP 补上「可实现性」这一层：GAP-L 把每条假设映射到证据等级；QAC/TAC/SAD/ODC/RDD/CSD/CRC/EMB-Q 分别填精度、时序、任意时间、漂移、诊断、降级、元认证、模型预算八个空白；J_ember 在 J_grip 上加 realizability 向量与 gap_ledger_hash。**前 64 轮在证明「如果世界符合假设则安全」，本轮第一次明确回答「哪些假设在目标硬件上被证实、以什么证据、还差多少」**。

## 1. 形式化定义（增量：定义 217–232）

- **定义 217（EMBER 闭环）**：EMBER = (GRIP, GAP-L, QAC, TAC, SAD, ODC, RDD, CSD, CRC, EMB-Q, J_ember)。定位：GRIP 的「可实现性」升级，不改变 GRIP 的语义/实时两流划分，而是在实时流内插入量化数值路径、WCET 预算、任意时间编译、诊断与降级格，在低频线程插入漂移观测与空白账本维护。不变式：**安全关键前向路径永不等待学习/优化；`J_ember` 的有效性永远以其声明的可实现性等级为条件**。

- **定义 218（研究空白账本 GAP-L 与可实现性等级）**：账本 G = {(g_k, A_k, e_k, L_k, w_k)}，其中 A_k 为一条可陈述假设（如「偏置有界」「实时路径 ≤2ms」「float 与 int 证书一致」），e_k 为证据产物（证明/仿真/HIL/目标板实测/第三方审计），L_k ∈ {0 未验证, 1 仅仿真, 2 理论+仿真, 3 HIL, 4 目标硬件+审计} 为证据等级，w_k 为影响权重。**可实现性等级** L(J) = min_{k: w_k ≥ w_min} L_k。规则：**证书只能在不超过 L(J) 的等级上被声明**；任何被声明为 L 级的保证，必须列出支撑它的全部账本条目。

- **定义 219（有限精度误差模型）**：定点数 b 位、单位舍入 u = 2^{−(b−1)}；每个算术算子满足 fl(x∘y) = (x∘y)(1+δ)，|δ| ≤ u。以仿射形式 x̂ = x₀ + Σ_i ξ_i ε_i（ε_i ∈ [−1,1]）跟踪一阶误差，区间界 Q(x̂) = x₀ ± Σ_i|ξ_i|。范围 R_X 上的量化噪声近似 σ_qX ≈ u·R_X/√12。

- **定义 220（QAC 量化感知证书）**：量化噪声协方差 Σ_q = diag(σ_qF²I₃, σ_qτ²I₃)，有效噪声 Σ_w^q = Σ_w + Σ_q。所有检验与统计量改用 Σ_w^q：T̂_t = e_tᵀ(Σ_w^q)⁻¹e_t（因 Σ_w^q ⪰ Σ_w，检验更保守）；量化 Fisher Ĵ = Σ_t (∂Ŵ/∂φ)ᵀ(Σ_w^q)⁻¹(∂Ŵ/∂φ) ⪯ J，故 Σ̂_post ⪰ Σ_post，**不确定度只会被高估、不会被低估**。证书折扣 Δ_q = sup_{沿编译路径} Q(ρ̂ − ρ)（仿射传播上界）。**整数实现有效当且仅当 ρ_safe ≥ Δ_q**，此时定义 ρ̂_int = ρ_safe − Δ_q。

- **定义 221（时序模型与 WCET 证书）**：实时任务集 {τ_i}，每个任务有 WCET w_i、周期/截止期 D_i、关键级；关键路径 C_crit = Σ_{i∈critical} w_i。采用概率 WCET（EVT 拟合）给出 pWCET 分布，超限概率 ε_t。时序证书：`C_crit ≤ D` 且 `P[C_crit > D] ≤ ε_t`。非关键任务只能在测得 slack 内调度。

- **定义 222（混合关键级任务集与降级优先序）**：关键级 {safety, performance}。HI 模式下 performance 任务被丢弃；降级优先序固定为 OLP-F 在线更新 ≺ CGG 长窗口 ≺ APP 探测 ≺ TSL 微调，且 safety 任务（CGG 残差、SLD、FCS、急停）永不被降级。每模式给出 WCET 上界 w_i^{mode}。

- **定义 223（SAD 任意时间证书单调编译）**：任意时间算子 A 迭代产出候选 (K_m, ρ_m^{lb}, valid_m)，其中 ρ_m^{lb} 为对 ρ(K_m) 的**可证明下界**，且 ρ_m^{lb} 随 m 单调不减。deadline 到达时返回当前最优已认证候选；性质：**返回的 ρ_lb 永不高于真实 ρ**（宁保守、不冒进），且被抢占后仍可续算。

- **定义 224（ODC 漂移观测器与时变偏置界）**：偏置模型 b(t) = b₀ + a·(T(t) − T₀) + w(t)，|w| 缓慢。观测器利用三类标定事件（自由空间零偏、已知质量提升、已知参考位姿接触）估计 b̂ 与协方差；时变界 ε_b(t) = ‖b̂‖ + k_σ σ_cal + r_drift·(t − t_cal)。力限裕度改用时变有效力：ρ_force(t) = F_lim − (F_max + ε_b(t))。若 ε_b(t) > ε_b,max → 触发重标定或降级。

- **定义 225（RDD 残留源解耦）**：e_t = δ_geo + b + δ_model(f_t) + q_t + η_t。特征向量 φ_t = (自由空间偏移统计, 载荷相关性, 接触集切换对齐度, 幅值/u·range)。四类假设检验：
  - H_b：无接触时 ‖E[e]‖ > τ_b（偏置在自由空间可见、与载荷无关）；
  - H_model：corr(‖e_t‖, ‖f_t‖) > τ_m 且残差随加载速率呈滞回；
  - H_geo：e_t 落在 col(G(C)) 内且系数超噪，并与接触集切换点对齐；
  - H_q：‖e_t‖_∞ ≤ u·R + 噪声且高频零均值。
  输出诊断类 + 置信度；动作映射：H_geo→降几何；H_b→重标定/膨胀 ε_b；H_model→切换模型或降低探针力/膨胀模型不确定度；H_q→升位宽/加折扣。**歧义时取动作并集（标定 + 膨胀），但绝不静默降几何**。

- **定义 226（CSD 认证安全降级格）**：状态格 FULL_GRIP → FORCE_LED → GEOM_LED → COMPLIANT_RETREAT → SAFE_IDLE（能力单调下降、安全单调上升）。每个转移有 WCET 上界 τ_trans 与预计算安全控制；转移需事件触发 + 滞回时长 h；**故障时状态索引只增不减**，恢复需连续 n_rec 窗证据且 J_ember 在所需等级上有效。

- **定义 227（CRC 多样化运行时证书检查器）**：独立整数/定点实现，采用与主路径**不同算法**（区间 vs 仿射、直接重算 vs 查表）重推 J_ember 中的 ρ 界与哈希；配 CRC/ECC 内存与看门狗。不一致、校验失败或超时 → 立即进入 SAFE_IDLE。定位：降低共模故障概率的**多样化冗余**，明确不构成形式证明。

- **定义 228（EMB-Q 嵌入式量化模型与预算）**：OLP-F 头与 TSL π_σ 量化为 INT8（或混合精度），逐层量化误差经仿射传播映射为 L_force 增量与遗憾界退化；预算 B_emb = (内存 M, 算力 P, 时延 t)。超预算时回退更小模型（带其自身认证界）或缓存投影（OCB-Skill）。

- **定义 229（ρ_ember 可实现性安全裕度）**：ρ_ember = ρ_safe − Δ_q，其中 ρ_safe = min(ρ_rob, ρ_dir, ρ_slip, ρ_force(t))。有效性额外要求时序证书成立且 `ρ_safe ≥ Δ_q`。ρ_ember 是「在目标硬件、当前位宽、当前漂移与当前时序下仍然成立的」安全裕度。

- **定义 230（J_ember 扩展证书）**：J_ember = (J_grip, r = (L_prec, L_time, L_calib, L_model, L_diag), Δ_q, ε_b(t_cal), pWCET_C_crit, ε_t, gap_ledger_hash, crc_ver)。Valid(J_ember @ L) ⇔ Valid(J_grip) ∧ ρ_ember ≥ 0 ∧ 时序证书成立 ∧ CRC 一致 ∧ 所有 w_k ≥ w_min 的账本条目 L_k ≥ L。

- **定义 231（空白闭合度与证据等级）**：闭合度 C = Σ_k w_k·L_k / Σ_k w_k·4；「已闭合空白」定义为 L_k ≥ 3 且 e_k 可复现；「开放空白」为 L_k ≤ 1。每个实验必须同时报告 ΔC，使「研究空白」从修辞变成可度量的状态变量。

- **定义 232（EMBER 闭环算子）**：语义流 [GRIP 语义流 → RDD 诊断 → GAP-L 更新 → WCV-F/CSP-F（按当前可实现性等级）→ SAD 规划]；实时流 [锚点读 → 量化 CGG 残差 → SLD → FCS（含 ε_b(t)）→ SAD 任意时间编译 → CSD 状态机 → CRC 校验 → π_σ1 派发 → J_ember]；低频流 [ODC 漂移观测 → 重标定 → EMB-Q 重预算 → GAP-L 证据回填]。

## 2. 关键算法骨架

# QAC：把量化噪声并入统计量与证书
Sigma_q = quant_noise_cov(bit_width, ranges)          # 定义 219/220
Sigma_wq = Sigma_w + Sigma_q
T = e.T @ inv(Sigma_wq) @ e
rho_int = rho_float - delta_q_affine(compile_trace)   # 仿射传播折扣

# RDD：先诊断，再决定降级谁（不再无脑降几何）
diag = rdd.classify(e_hist, f_hist, contact_switch_times, bit_width, ranges)
if diag == 'geo_hallucination':   cgg.demote_geometry()
elif diag == 'sensor_bias':       odc.recalibrate(); inflate_eps_b()
elif diag == 'contact_model':     model.expand_uncertainty(); app.lower_probe_force()
elif diag == 'quantization':      qac.raise_bit_width_or_pad()
else:                             conservative_union()      # 歧义：标定+膨胀，不降几何

# TAC / SAD：任意时间 + 证书单调
deadline = t_now + D - w_crit_path
best = None
while time_left() > 0 and not converged:
    K, rho_lb = anytime_refine()                          # rho_lb 是下界
    if best is None or rho_lb >= best.rho_lb: best = (K, rho_lb)
if deadline_exceeded_predicted(): return best             # 绝不返回未认证解

# CSD：单调降级 + 证据门控恢复
state = csd.step(fault, evidence, dwell_ok, j_ember_valid)

# CRC：多样化整数检查器
ok = crc.verify(J_ember)                                  # 不同算法重算
if not ok: state = SAFE_IDLE
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 7（有限精度证书失真）**：设证书计算是长度 L 的直线程序，单位舍入 u，路径条件数 κ_P，则 |ρ̂ − ρ| ≤ κ_P·u·ρ_scale（一阶）。故 Δ_q = κ_P·u·ρ_scale，整数证书安全当且仅当 ρ_safe ≥ Δ_q。用 Σ_w^q 检验使统计量期望增加 tr(Σ_w⁻¹Σ_q)（更保守）；量化 Fisher Ĵ ⪯ J ⇒ Σ̂_post ⪰ Σ_post，**不确定度只会被高估**。
- **引理 8（残留源可辨识性）**：若四类签名线性独立，最小主角 θ_min > 0，则分类错误率 ≤ exp(−c·SNR·sin²θ_min)。因此「几何幻觉 vs 传感器偏置 vs 模型误差 vs 量化」在信噪比足够时可分离；分离不开时取保守并集，代价是暂时性能下降而非错误归因。
- **定理 7（时序认证安全）**：若 C_crit 的 WCET ≤ D、pWCET 超限概率 ≤ ε_t、每次 CSD 转移 ≤ τ_trans，则任意故障后系统在 τ_detect + τ_trans 内到达安全降级态，概率 ≥ 1 − ε_t − α_diag；安全关键路径永不因性能任务超载而错过截止期。
- **定理 8（可实现性健全证书）**：若 Valid(J_ember @ L)，则所有所需假设账本等级 ≥ L 的 GRIP 保证在目标硬件上成立，其裕度仅按 Δ_q + ε_b(t) 收缩；反之若关键空白等级 < L，则不得在该等级声明证书。即**健全性从理想域传递到嵌入式域**，并杜绝「越级认证」。
- **命题（可实现性的无免费午餐 / Pareto 前沿）**：给定嵌入式预算（位宽 b、主频、内存），可认证的 ρ_ember 存在上界；在位宽/模型规模（→ Δ_q↓、WCET↑）与能耗/时延之间存在 Pareto 前沿。提高安全裕度只能靠更高精度/更多算力，或缩小可认证运行包络——二者不可兼得。
- **实时性**：量化 CGG 残差 + 定点 SLD + FCS（含 ε_b）+ SAD 首解 + CSD + CRC 的关键路径在 Cortex-M7 上目标 ≤ 2ms（含 20% 余量），由 TAC 证书而非桌面测量保证。

## 2. 形式化定义（完整版）

**定义 217（EMBER 闭环）** EMBER 是 GRIP 的「可实现性」升级，保持第 64 轮「语义流 ∘ 实时流」不变式，新增三条约束：
1. **精度约束**：所有进入证书的实数运算，其有限精度失真被 Δ_q 显式吸收（定义 220、229）；
2. **时序约束**：实时关键路径满足目标板 WCET 证书，非关键任务按关键级降级（定义 221、222）；
3. **证据约束**：证书有效性与账本可实现性等级 L(J) 绑定（定义 218、230）。
EMBER 新增低频流用于漂移观测、重标定、量化预算与账本回填；**实时流仍零学习写操作**。

**定义 218（研究空白账本 GAP-L 与可实现性等级）** 账本 G = {(g_k, A_k, e_k, L_k, w_k)}：
- A_k 是可被证伪的陈述（例：「F/T 偏置在 t 内 ≤ ε_b」「实时路径在目标板上 ≤ D」）；
- e_k 是证据产物（定理编号、仿真配置、HIL 日志、目标板 WCET 报告、第三方审计）；
- L_k 为证据等级（0–4）；w_k ∈ (0,1] 为影响权重。
可实现性等级 L(J) = min_{k: w_k ≥ w_min} L_k。**认证规则**：证书只能声明 ≤ L(J) 的等级；声明等级 L 时必须输出支撑它的全部 {(g_k, e_k, L_k)}。这把「研究空白」从论文里的 future work 段落变成**运行时强制的一等对象**。

**定义 219（有限精度误差模型）** 定时/定点 b 位，u = 2^{−(b−1)}。对每个算子 fl(x∘y) = (x∘y)(1+δ)，|δ| ≤ u；非线性算子按局部 Lipschitz 常数线性化。用仿射算术跟踪：x̂ = x₀ + Σ_i ξ_i ε_i，ε_i ∈ [−1,1]，区间界 Q(x̂) = [x₀ − Σ|ξ_i|, x₀ + Σ|ξ_i|]。舍入噪声视为在范围 R_X 上近均匀，σ_qX ≈ u·R_X/√12（上界取 u·R_X/2）。

**定义 220（QAC 量化感知证书）** 量化使测量模型变为 Ŵ = W + q，q ~ N(0, Σ_q)。定义有效噪声
Σ_w^q = Σ_w + Σ_q，T̂_t = e_tᵀ(Σ_w^q)⁻¹e_t。
因 Σ_w^q ⪰ Σ_w，(Σ_w^q)⁻¹ ⪯ Σ_w⁻¹，故在相同阈值下拒绝更少（偏保守）。量化 Fisher Ĵ = Σ_t (∂Ŵ/∂φ)ᵀ(Σ_w^q)⁻¹(∂Ŵ/∂φ) ⪯ J，进而 Σ̂_post = (J_geo + Ĵ)⁻¹ ⪰ (J_geo + J)⁻¹ = Σ_post，**后验不确定度只会被高估**。证书折扣由仿射传播给出 Δ_q = sup Q(ρ̂ − ρ)（一阶，见引理 7）。整数实现的有效性判据：
`ρ_safe ≥ Δ_q`，且此时可安全声明 ρ̂_int = ρ_safe − Δ_q。
若 `ρ_safe < Δ_q`：升位宽、缩小 R_X、或进入 CSD 降级——**不允许用 float 计算出的 ρ 冒充整数域的 ρ**。

**定义 221（TAC 时序模型与 WCET 证书）** 实时任务 τ_i 具有 WCET w_i（目标板、含中断/缓存/总线干扰的最坏测量或静态分析上界）、截止期 D_i、关键级 c_i。关键路径 C_crit = Σ_{i∈critical} w_i。用极值理论（EVT）对重复测量拟合 pWCET，给出超限概率 ε_t = P[C_crit > D]。**时序证书** = (C_crit ≤ D, ε_t ≤ ε_t,max)。测量必须在**目标编译器 + 目标 RTOS + 真实负载**下完成；桌面/仿真数据只记为账本等级 ≤1。

**定义 222（混合关键级任务集与降级优先序）** 关键级 {safety, performance}。safety = {CGG 残差, SLD, FCS, CSD, CRC, 急停}；performance = {OLP-F 更新, CGG 长窗, APP 探测, TSL 微调, EMB-Q 重预算}。HI 模式下 performance 全部挂起，safety 使用 HI 模式 WCET 上界。降级优先序固定为
`OLP-F 更新 ≺ CGG 长窗 ≺ APP 探测 ≺ TSL 微调`。
形式化：模式切换本身必须有 WCET 上界 τ_mode，且切换过程不进入未认证控制律。

**定义 223（SAD 任意时间证书单调编译）** 编译算子 A 在第 m 次迭代产出候选 (K_m, ρ_m^{lb}, valid_m)：
- **下界性**：ρ_m^{lb} ≤ ρ(K_m)（返回的是可证明保守值，绝不冒进）；
- **单调性**：ρ_{m+1}^{lb} ≥ ρ_m^{lb}（改进只增不减，可安全中断）；
- **deadline 规则**：当预测剩余时间 < 一次迭代 WCET 时停止，返回 argmax_m ρ_m^{lb}。
若被抢占，保存 (K_m, ρ_m^{lb}) 供下一拍续算。**性质**：任意时刻返回的 ρ 都是真实值的下界，因此「超时」只损失最优性，不损失安全性。

**定义 224（ODC 漂移观测器与时变偏置界）** 偏置模型
b(t) = b₀ + a·(T(t) − T₀) + w(t)，其中 a 为温漂系数、w 为慢随机游走。
标定事件 E_cal = {自由空间零偏, 已知质量提升, 已知参考位姿轻触}，由观测得到 b̂ 与协方差 Σ_b。定义
ε_b(t) = ‖b̂‖ + k_σ·√(tr Σ_b) + r_drift·(t − t_cal)，
其中 r_drift 由历史漂移率的置信上界给出。力限裕度改为
ρ_force(t) = F_lim − (F_max + ε_b(t))。
若 ε_b(t) > ε_b,max → 触发重标定；重标定失败 → CSD 降级。**这把第 64 轮 A83（偏置有界）从静态假设变成可观测、可失效的时变量。**

**定义 225（RDD 残留源解耦）** 残留分解
e_t = δ_geo(t) + b + δ_model(f_t) + q_t + η_t。
特征与判别：
- **H_b（偏置）**：自由空间（无接触）时 ‖E[e]‖ > τ_b；与载荷幅值无关；在 wrench 空间近似常向量。
- **H_model（模型误差）**：corr(‖e_t‖, ‖f_t‖) > τ_m；随加载速率呈滞回（软接触/未建模阻尼）；仅在接触段出现。
- **H_geo（几何幻觉）**：e_t ∈ col(G(C)) 的系数显著大于噪声；在接触集 C 切换时刻出现跳变；与载荷无关但方向随 C 变。
- **H_q（量化）**：‖e_t‖_∞ ≤ u·R + 3σ_η 且高频零均值；随位宽 b 增大而缩小。
分类器输出 (class, confidence)。动作映射：
`H_geo → demote_geometry`；`H_b → recalibrate + inflate ε_b`；`H_model → expand_model_uncertainty + lower_probe_force`；`H_q → raise_bit_width / pad Δ_q`；歧义 → 动作并集（标定 + 膨胀），**绝不静默降几何**。

**定义 226（CSD 认证安全降级格）** 状态集
S = {FULL_GRIP, FORCE_LED, GEOM_LED, COMPLIANT_RETREAT, SAFE_IDLE}
按能力降序、安全升序排列。每个状态 s 绑定：(i) 唯一的预计算安全控制律 K_s；(ii) 进入 s 的 WCET 上界 τ_trans(s)；(iii) 退出条件。转移规则：
1. **故障单调**：任一 fault 事件使索引不减（只能更保守）；
2. **滞回**：同一故障需持续 h 时长才转移，防止抖动；
3. **证据门控恢复**：降级后至少 n_rec 个窗满足「故障消失 + 传输证据 + J_ember 在所需等级有效」才可恢复；
4. **转移有界**：所有转移 τ_trans ≤ τ_trans,max，转移期间使用目标态的安全控制律。

**定义 227（CRC 多样化运行时证书检查器）** 独立实现（不同语言/编译器/算法）：
- 主路径用仿射算术算 Δ_q 与 ρ，CRC 用区间算术 + 直接重算；
- 两者用不同的数据布局与哈希（CRC32/ECC 内存）；
- 看门狗计时器监控主路径心跳。
校验内容：J_ember 各字段一致性、ρ 重推结果落在主路径声明区间内、gap_ledger_hash 与当前账本一致。不一致/超时 → SAFE_IDLE。**定位诚实**：多样化冗余降低共模故障，但不等价于形式证明；账本等级封顶为 3，除非第三方独立审计。

**定义 228（EMB-Q 嵌入式量化模型与预算）** 对 OLP-F 头 h(x'') 与 TSL π_σ 做 INT8 量化（可选逐通道、混合精度）。逐层误差经仿射传播得到 L_force 增量 ΔL_force，进而乐观遗憾界退化
G̃_force^q = G̃_force·(1 + ΔL_force/L_force)。
预算 B_emb = (M, P, t)。超预算策略：① 减层/减宽（用其自身认证界替换）；② 缓存投影（OCB-Skill）；③ 将 OLP-F 降为纯前向缓存模式（不再在线更新）。

**定义 229（ρ_ember 可实现性安全裕度）** 
ρ_ember = ρ_safe − Δ_q，ρ_safe = min(ρ_rob, ρ_dir, ρ_slip, ρ_force(t))。
有效性额外要求：
(a) `ρ_safe ≥ Δ_q`；(b) 时序证书成立 `(C_crit ≤ D, ε_t ≤ ε_t,max)`；(c) ε_b(t) ≤ ε_b,max；(d) 关键账本条目 L_k ≥ 声明等级。

**定义 230（J_ember 扩展证书）** 
J_ember = (J_grip, r, Δ_q, ε_b(t_cal), pWCET_C_crit, ε_t, gap_ledger_hash, crc_ver)，
其中 r = (L_prec, L_time, L_calib, L_model, L_diag)。
验证规则：
Valid(J_ember @ L) ⇔ Valid(J_grip) ∧ ρ_ember ≥ 0 ∧ (C_crit ≤ D) ∧ (ε_t ≤ ε_t,max) ∧ (ε_b ≤ ε_b,max) ∧ CRC 一致 ∧ (∀k: w_k ≥ w_min ⇒ L_k ≥ L)。
审计链：J_grip 追溯几何/接触/干扰，Δ_q/ε_b/pWCET 追溯精度/漂移/时序，gap_ledger_hash 追溯「哪条假设靠什么证据成立」。

**定义 231（空白闭合度与证据等级）** 闭合度
C = Σ_k w_k·L_k / (4·Σ_k w_k)。
「已闭合空白」：L_k ≥ 3 且 e_k 可复现；「开放空白」：L_k ≤ 1。每个实验报告 ΔC 与新增开放空白，使研究空白成为**可度量、可回归检测**的状态量；轮次间 ΔC < 0 视为「用新假设掩盖旧空白」的告警。

**定义 232（EMBER 闭环算子）** 
- **语义流（10–100Hz）**：GRIP 语义流 → RDD 诊断 → GAP-L 更新 → 按当前 L(J) 选择 WCV-F/CSP-F 约束强度 → SAD 规划。
- **实时流**：锚点读 → 量化 CGG 残差 → 定点 SLD → FCS（含 ε_b(t)）→ SAD 任意时间编译 → CSD 状态机 → CRC 校验 → π_σ1 派发 → J_ember 构建。
- **低频流（0.1–1Hz）**：ODC 漂移观测 → 重标定 → EMB-Q 重预算 → 账本证据回填 → Δ_q 重算。
不变式：实时流不写学习参数；账本更新与 Δ_q 重算只在低频流。

### IP-214/219 GAP-L + RDD（研究空白账本与残差解耦）

class GapLedger:
    def __init__(self, w_min=0.2):
        self.gaps = {}          # k -> dict(A, evidence, level, weight)
        self.w_min = w_min

    def level(self, required_weight=None):
        req = self.w_min if required_weight is None else required_weight
        return min((g['level'] for g in self.gaps.values()
                    if g['weight'] >= req), default=0)

    def declare_valid(self, level):
        return all(g['level'] >= level for g in self.gaps.values()
                   if g['weight'] >= self.w_min)

    def closure(self):
        den = 4 * sum(g['weight'] for g in self.gaps.values()) + 1e-12
        return sum(g['weight'] * g['level'] for g in self.gaps.values()) / den


class ResidualSourceDiagnoser:
    """把 CGG 的'不符'细分为 geo / bias / model / quant。"""
    def classify(self, e_hist, f_hist, contact_switch_times,
                 bit_width, ranges, Sigma_w):
        R = max(ranges)
        fs_mask = (np.linalg.norm(f_hist, axis=1) < 1e-3)   # 自由空间样本
        fs_offset = np.linalg.norm(np.mean(e_hist[fs_mask], axis=0)) \
                    if fs_mask.any() else 0.0
        load_corr = abs(np.corrcoef(np.linalg.norm(e_hist, axis=1),
                                    np.linalg.norm(f_hist, axis=1))[0, 1]) \
                    if len(e_hist) > 3 else 0.0
        switch_align = self._jump_alignment(e_hist, contact_switch_times)
        q_bound = 2 ** (-(bit_width - 1)) * R
        mag = np.percentile(np.linalg.norm(e_hist, axis=1), 95)

        if mag <= q_bound + 3 * np.sqrt(np.trace(Sigma_w)) and fs_offset < q_bound:
            return 'quantization', 0.9
        if fs_offset > 5 * np.sqrt(np.trace(Sigma_w)):
            return 'sensor_bias', 0.9
        if load_corr > 0.7 and not fs_mask.all():
            return 'contact_model', 0.8
        if switch_align > 0.6:
            return 'geo_hallucination', 0.85
        return 'ambiguous', 0.5

    def _jump_alignment(self, e_hist, switches):
        if not len(switches):
            return 0.0
        jumps = np.linalg.norm(np.diff(e_hist, axis=0), axis=1)
        score = 0.0
        for s in switches:
            lo, hi = max(0, s - 2), min(len(jumps), s + 3)
            score = max(score, jumps[lo:hi].max() / (jumps.mean() + 1e-9))
        return min(1.0, score / 5.0)


def apply_diagnosis(diag, cgg, odc, model, app, qac):
    if diag == 'geo_hallucination':
        cgg.demote_geometry()
    elif diag == 'sensor_bias':
        odc.recalibrate(); qac.inflate_eps_b()
    elif diag == 'contact_model':
        model.expand_uncertainty(); app.lower_probe_force()
    elif diag == 'quantization':
        qac.raise_bit_width_or_pad()
    else:                              # 歧义：并集，绝不静默降几何
        odc.recalibrate(); model.expand_uncertainty()
```

### IP-215 QAC（量化感知证书预算）

```python
class QuantCert:
    def __init__(self, bit_width, ranges):
        self.u = 2.0 ** (-(bit_width - 1))
        self.ranges = ranges

    def noise_cov(self, Sigma_w):
        sigma_q = [self.u * r / np.sqrt(12) for r in self.ranges]   # 6 维 wrench
        return Sigma_w + np.diag([s**2 for s in sigma_q])

    def delta_q(self, compile_trace, rho_scale):
        # 仿射传播：每个算子累加一阶误差半径
        radius, cond = 0.0, 0.0
        for op in compile_trace:
            radius = op.local_error(self.u) + op.lipschitz * radius
            cond += op.condition
        return cond * self.u * rho_scale + radius

    def certify(self, rho_safe, delta_q):
        if rho_safe < delta_q:
            return None, False          # 必须升位宽 / 降级
        return rho_safe - delta_q, True
```

class SafeAnytimeCompiler:
    def __init__(self, iter_wcet, deadline_slack):
        self.iter_wcet = iter_wcet
        self.slack = deadline_slack

    def compile(self, refine_step, t_deadline):
        best_K, best_lb = None, -np.inf
        while t_deadline - now() > self.iter_wcet + self.slack:
            K, rho_lb = refine_step()      # rho_lb 是真实 rho 的可证下界

                best_K, best_lb = K, rho_lb

                break
        return best_K, best_lb, best_K is not None

### IP-218 ODC（漂移观测与时变偏置界）

```python
class DriftObserver:
    def __init__(self, k_sigma=3.0, r_drift=0.002, eps_max=0.5):
        self.k_sigma, self.r_drift, self.eps_max = k_sigma, r_drift, eps_max
        self.b_hat, self.Sigma_b, self.t_cal = np.zeros(6), np.eye(6), now()

    def observe(self, calibration_events, temp):
        for kind, meas in calibration_events:
            H = self._observation_matrix(kind)          # 零偏/已知质量/参考位姿
            K = self.Sigma_b @ H.T @ np.linalg.inv(H @ self.Sigma_b @ H.T + R_CAL)
            self.b_hat = self.b_hat + K @ (meas - H @ self.b_hat)
            self.Sigma_b = (np.eye(6) - K @ H) @ self.Sigma_b
        self.t_cal = now()

    def eps_b(self, temp):
        drift = self.r_drift * (now() - self.t_cal)
        return np.linalg.norm(self.b_hat) + \
               self.k_sigma * np.sqrt(np.trace(self.Sigma_b)) + drift

    def valid(self, temp):
        return self.eps_b(temp) <= self.eps_max
```

CSD_ORDER = ['FULL_GRIP', 'FORCE_LED', 'GEOM_LED',
             'COMPLIANT_RETREAT', 'SAFE_IDLE']

class CertifiedDegradation:
    def __init__(self, dwell=0.2, n_rec=5):
        self.idx = 0
        self.dwell, self.n_rec = dwell, n_rec
        self.cand, self.cand_since, self.good = None, None, 0

    def step(self, fault, recover_evidence, j_ember_valid, now):
        if fault:
            self.good = 0
            target = self._target_for(fault)            # 故障类型 → 目标态索引
            if target > self.idx:
                if self.cand != target:
                    self.cand, self.cand_since = target, now
                elif now - self.cand_since >= self.dwell:
                    self.idx, self.cand = target, None  # 单调下降
        else:
            self.cand = None
            if self.idx > 0 and recover_evidence and j_ember_valid:
                self.good += 1
                if self.good >= self.n_rec:
                    self.idx, self.good = self.idx - 1, 0   # 证据门控恢复
        return CSD_ORDER[self.idx]

    def _target_for(self, fault):
        return min(len(CSD_ORDER) - 1,
                   {'timing': 1, 'bias': 2, 'model': 2,
                    'geometry': 2, 'crc': 4, 'power': 3}[fault])

## 4. 推导

**引理 7（有限精度证书失真）** 设证书计算为长度 L 的直线程序，每步满足 fl(x∘y) = (x∘y)(1+δ), |δ|≤u。一阶误差传播给出
ρ̂ = ρ + Σ_{i=1}^{L} c_i u ρ + O(u²)，
其中 c_i 为第 i 步的局部条件数，κ_P = Σ_i c_i。故
|ρ̂ − ρ| ≤ κ_P·u·ρ_scale + O(u²) =: Δ_q。
对 χ² 检验，量化使 E[T̂] = 6 + tr(Σ_w⁻¹Σ_q) ≥ 6（拒绝阈值不变时更保守）。对 Fisher，Ĵ = J − J_q ⪯ J，故 Σ̂_post = (J_geo + Ĵ)⁻¹ ⪰ (J_geo + J)⁻¹，后验不确定度只会被高估。因此整数实现的唯一失败模式是「裕度被折扣吃掉」：当且仅当 `ρ_safe < Δ_q` 时才不安全；此时升位宽使 u 减半即可恢复。∎

**引理 8（残留源可辨识性）** 把四类签名写成矩阵 Φ = [s_geo, s_b, s_model, s_q]（每列为单位化签名方向），观测 e = Φα + η。若最小主角 θ_min = min_{i≠j} ∠(s_i, s_j) > 0，则最小二乘分类的误差指数满足
P[错分] ≤ exp(−(SNR·sin²θ_min)/8)，
其中 SNR = ‖α‖²/σ_η²。直观上：偏置在自由空间可见（提供额外样本）、模型误差与载荷相关（提供第二维）、几何幻觉与接触集切换对齐（提供时间结构）、量化被 u·R 界住（提供幅值先验），四者提供了互补的判别维度。当 θ_min → 0（如偏置方向恰好落在 col(G) 中且无自由空间样本）时不可分，此时 RDD 输出 ambiguous，动作并集保证「不错误归因」，代价是暂时更保守。∎

**定理 7（时序认证安全）** 假设 (i) 关键路径 C_crit 的 WCET ≤ D，pWCET 超限概率 ≤ ε_t；(ii) 每次 CSD 转移的 WCET ≤ τ_trans；(iii) RDD 在 τ_detect 内给出诊断（含 ambiguous 视为故障）。则任意单个故障发生后，系统在 τ_detect + τ_trans 内进入更保守状态 w.p. ≥ 1 − ε_t − α_diag。又因 safety 任务在混合关键级 HI 模式下不被降级，其截止期违约概率 ≤ ε_t。故安全关键路径不会因性能任务超载而失效。∎

**定理 8（可实现性健全证书）** 设 J_ember 在等级 L 上有效，即 ∀k: w_k ≥ w_min ⇒ L_k ≥ L，且 ρ_ember = ρ_safe − Δ_q ≥ 0、时序证书成立、CRC 一致。对每个等级 ≥ L 的账本假设 A_k，其在目标硬件上成立（由证据等级定义：HIL 或目标板实测/审计）。第 64 轮定理 6 的证明只用到 A77–A87 这些假设；把它们替换为「账本等级 ≥ L 的已验证版本」，并在所有裕度上减去 Δ_q + ε_b(t)，则定理 6 的全部结论在嵌入式域成立。反之，若某关键 L_k < L，则 A_k 未被验证，证书不能在该等级声明——**从规则上杜绝越级认证**。∎

**命题（可实现性的无免费午餐 / Pareto 前沿）** 给定嵌入式预算 (b, f_clk, M)，Δ_q = κ_P·2^{−(b−1)}·ρ_scale 随 b 指数下降，而 WCET 随 b 与模型规模上升。可认证裕度
ρ_ember(b, model) = ρ_safe(model) − Δ_q(b)，
且 ρ_safe 受模型规模（信息量）与 WCET 预算（可迭代次数）共同约束。于是存在 Pareto 前沿：在固定功耗/时延下，提高 ρ_ember 只能换取更小的可认证运行包络（更小 r_max、更低探针力），或反之。该前沿把「安全」与「算力/能耗」的取舍显式化，供硬件选型与任务分配使用。∎

## 7. 已知风险

**一句话**：我们用一组本身未经嵌入式实测穷尽验证的「量化有界 / WCET 有界 / 漂移有界」假设去认证证书自己，一旦这些界在罕见尾事件（热失控、总线风暴、静默位翻转、DVFS 降频）下失效，realizability 层就会把第 64 轮的「自信地错」升级为「经认证地错」——用元认证的确定性掩盖元假设的脆弱性。

**次级风险与缓解**：
1. **WCET 过度悲观 → 系统几乎总是降级**：静态 WCET 分析常悲观数倍。缓解：pWCET（EVT）替代硬上界 + 分级预算；把「最坏模式」与「典型模式」分开认证；用 slack 回收执行优化任务。
2. **EVT 拟合外推不可靠**：尾模型选错会让 ε_t 失真。缓解：多尾模型交叉验证 + 留出极端样本 + 账本等级封顶；ε_t 取模型集合最大值。
3. **RDD 在低 SNR / 特征共线时不可分**：偏置方向落在 col(G) 且无自由空间样本时，几何与偏置不可辨。缓解：主动插入自由空间零偏采样（轻抬离面）；歧义时动作并集；在 J_ember 标注 `diag_ambiguous`。
4. **多样化检查器共享同源缺陷**：同团队/同规格书实现仍可能共模。缓解：异构工具链 + 形式化区间库 + 第三方审计；账本等级不因「双份实现」自动升到 4。
5. **量化感知 Fisher 过保守 → 收缩不足**：用 Σ_w^q 会低估信息。缓解：只在证书声明用保守 Fisher，规划内部仍可用 float Fisher 并以 Δ_q 兜底；两者分离审计。
6. **漂移模型在突变下失效**（如碰撞后偏置跳变）：缓解：残差突变检测触发即时重标定；重标定失败立即 CSD 降级；ε_b(t) 设硬上限。
7. **INT8 模型对触觉高频特征的破坏**：量化可能抹掉粘-滑特征。缓解：SLD 关键频带保留 FP/定点高精度；仅对 OLP-F 头与 π_σ 量化；做逐层敏感度分析。
8. **账本沦为形式主义**：把等级填高而不给可复现证据会制造虚假确定性。缓解：L_k ≥ 3 必须附可复现脚本与原始日志哈希；E240 盲复现作为唯一升等级通道；ΔC < 0 告警。
9. **实时预算仍超**：CRC + SAD 把路径推到 1.9ms。缓解：CRC 与 SAD 分时（CRC 每 k 拍校验一次，k 由风险调节）；关键路径只保留 FCS/SLD/CSD；必要时降低 SAD 迭代上限（有下界保证）。
10. **研究空白被新假设掩盖**：本轮引入的「有界量化/时序/漂移」本身可能成为新的未验证单点。缓解：把它们全部登记为开放账本条目（当前等级 2–3，非 4），并在风险与实验中显式跟踪——**承认元假设，是避免元层面重蹈覆辙的唯一办法**。
