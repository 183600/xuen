# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「情感语音」×「语义分割」）

> R69 把不确定性拆成 aleatoric / epistemic，并用「流匹配多模态策略 + 主动多模态交互」去消解后者。但 R69 有两个**从未写进定义的隐含假设**：
> - **(A) 证据的分辨率是均匀的**：U_epi 是动作模态上的一个标量/向量，好像「哪里模糊」不重要，只要知道「有几种走法」就够了；
> - **(B) 证词的可信度是单位 1**：一旦系统去「问」，人的回答就被当作一条干净观测并入后验，只靠「k 个源一致」防投毒。
>
> 本轮两个灵感正好各击穿一个假设：
> - **语义分割**说：世界是一张**像素/区域级的标签场**，不确定不是「一个数」，而是一个**有支撑集的空间场**；最危险的不确定恰好堆积在物体边界、遮挡边界、接触边界上——也就是安全最在意的地方。证据有「空间分辨率」。
> - **情感语音**说：人回答时，**说了什么**（内容）和**怎么说**（韵律、停顿、气息、音高走向）是两条通道；后者携带自信/犹豫/紧张/被迫/反讽，也携带「这句话值几分信任」。更关键的是，机器人自己问句的韵律会**改变**人怎么回答（诱导性、社会压力）——情感语音既是观测通道，也是干预通道。证据有「可信度分辨率」。
>
> 核心命题：**把 R69 的「有形状的不确定性」再升一维——从「动作模态分布」升级为「证据尺度空间」U(x, r, κ)：在哪儿（x）、看多细（r）、信几分（κ）。交互不再只是「问不问」，而是「用哪一格分辨率、哪一种证据源去把安全相关的那一小块不确定性压到阈值以下」。** 命名 **SIREN-RAS**（Semantic-boundary, Interactive Resolution-aware, prosodic-Evidence-Normalized Risk-Adaptive Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**该用多高的分辨率看、该信这个证人几分**」。

## 0. 直觉与动机

**灵感 1（语义分割 → 不确定性有支撑集，而且边界最危险）**
直觉：R69 的模态是「绕左 / 绕右」这种整体级歧义；但机器人真正出事故，往往不是选错整体策略，而是**在某个局部把「桌面」和「桌面边缘」、把「人的手」和「背景」分错了几个像素**——抓取点偏了、安全距离算少了、碰撞包络画错了。语义分割把观测变成稠密标签场 p(S|o)，于是不确定性第一次可以写成 **U(x)**：不是「我拿不准要不要抓」，而是「我拿不准 x 处这块像素是不是可抓表面」。而 U(x) 的最大值几乎总在**边界 ∂S** 上，边界又正好是 clearance / 接触 / 遮挡最关键的位置。⇒ 交互预算应该像聚光灯一样，打在「又模糊又危险」的边界上，而不是均匀地做一次全局决策。

**灵感 2（情感语音 → 证词有可信度，而且问句会污染答案）**
直觉：R69 的 g_ask 只生成问句**内容**，没说「用什么语气问」。但人回答同一句话，在被平静询问、被催促、被质问时的韵律完全不同；系统若用带压力的语气提问，得到的「好」可能只是服从，而不是事实。反过来，人答「好」时的犹豫、气息、音高回落，又能提示「他自己也不确定 / 他在撒谎 / 他被迫」。⇒ 情感语音同时是：
1. **证词的副通道**（content vs prosody，二者不一致 = 语义-韵律不一致 SPI）；
2. **机器人自身的干预变量**（问句韵律改变答案分布 = 观察者效应）；
3. **可信度的校准对象**（κ = 该证人这句话可信几分，需要 ECE 校准，正如 R69 对模态权重做 MCG）。

**灵感 3（统一：证据尺度空间 + 条件证书）**
直觉：把「空间分辨率 r」和「社会/认识论可信度 κ」看成同一件事的两个轴——它们都是**证据的分辨率**：r 决定「看多细」，κ 决定「信多深」。于是 R69 的标量 U 变成一张三维场 **U(x, r, κ)**；一个信息动作就是在这个尺度空间里选一个**格子**去测量。证书不再是一个绝对结论，而是**条件证书 J(r, κ)**：「在分辨率 r、可信度 κ 下，这个判断是安全的」。这一招正面拆解 R69 的最大风险：**证词永远只能拿到低 κ 条件下的证书，无法被"洗"成绝对真理**——系统可以「在 0.7 可信度下接受这个答案并保持保守」，但不能把它盖章为「已验证事实」。

**灵感 4（原则：观测优先于证词，情感只可否决）**
直觉：R69 说「单源不得定案，要 k 个正交源一致」。但内容和韵律可以被同一个骗子**共同伪造**（K 源并不正交），而「再问一遍」也可能只是把同一个偏见问了两遍。真正与证词正交的，是**观测**（重新分割/换视角/探针）与**后果**（做一个可逆小动作看世界怎么回应）。所以本轮立两条铁律：
- **观测优先（Observation-Before-Testimony）**：同等成本下，优先用观测而非提问；高风险决策必须至少有一条 O（观测）或 C（后果）证据。
- **情感只可否决（Veto-Only Prosody）**：韵律可以**下调**可信度、触发进一步核实，但在没有独立观测时**不得单独上调**到「可定案」。宁可不信一个诚实的人，也不把一句好听的谎话盖章。

**灵感 5（退化关系：R69 是"分辨率无穷粗、可信度恒为 1"的特例）**
直觉：把 r 固定为「整物体级」、κ 固定为 1、且禁用证词，SIREN 就逐指令退化成 FLUID-RAS；再令「永不交互」，就是 CALM-RAS；再关掉一切自适应，就是基线。新层必须是旧层的**严格泛化**：只有当分割校准与韵律校准都通过时，才允许使用更细的分辨率与证词通道；任一校准失守，就沿**分辨率退化阶梯**退回 R69/R68，而不是带着不可信的尺子硬测。

**灵感 6（新威胁与伦理：更细的尺子也是有偏置的尺子）**
直觉：语义分割会在**遮挡边界、透明/反光表面、域外纹理**上系统性出错；情感语音的可信度判断会被**文化、口音、方言、神经多样性、抑郁/焦虑、听力/语言障碍**系统性误读。若把这两把尺子当作客观真理，SIREN 会把偏见**局部化**（"我对这块区域特别确定"）并把该被倾听的人**降权**（"他听起来不可信"）。所以本轮必须同时交付：边界校准与对抗分割、韵律跨群体公平性审计、情感隐私与同意、机器人自身情感表达的非操纵约束，以及条件证书的**不可洗白性**（定理 20）。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（SIREN-RAS 总览）** SIREN-RAS = (DUF, RAI, PRC, TCI, AVP, OBT, ACS, SGC, RAS-WM‡)。五不变式：
(i) 实时流零学习写操作（继承 R68 定义 276-i）；
(ii) **证据尺度化**：任何结论都绑定一个分辨率 r 与可信度 κ，写成条件证书 J(r, κ)；
(iii) **观测优先**：高风险结论须由至少一条观测 O 或后果 C 支撑，证词 T 不得单独定案；
(iv) **情感否决权**：韵律只能下调 κ / 触发核实，不得在无独立观测时单独上调至可定案；
(v) **情感非操纵与校准**：机器人自身韵律须校准（表达置信 ≈ 真实可靠度）且不得以说服/操纵为目标。

**定义 311（证据尺度空间）** 尺度坐标 s = (x, r, κ)，x ∈ Ω（区域/像素），r ∈ {0: 物体级, 1: 边界级, 2: 像素级}，κ ∈ [0,1]（证据源可信度）。定义**可信度分辨的不确定性场** U(s) = U(x, r, κ)：在该位置、该分辨率、该可信度下，与安全相关决策的后验熵（或对风险的期望损失）。R69 的标量 U 对应 U 在 (x=全局, r=0, κ=1) 处的一个退化切片。交互 = 选择尺度空间中的一个**格子**去测量。

**定义 312（稠密语义场 DUF）** 分割后验 q(S|o)，S: Ω→𝒴；超像素/区域 R 的边际 q_R(S_R|o)。边界集 ∂S = {x : ∃y∼x, S_x ≠ S_y}；边界不确定度 U_∂(x) = H(1[S_x≠S_y] | o) 在邻居上平均。仿射图 A = φ(S, 几何)，仿射熵 H(A_x|o)。三类歧义分治：**是什么**（物体级）、**边界在哪**（边界级）、**能不能碰**（仿射级）。

**定义 313（风险加权空间场）** 由 C-RAS-WM 的碰撞/接触包络导出安全权重 w_safe(x) ∈ [0,1]，越靠近 clearance / 遮挡 / 接触边界越大。定义风险加权不确定质量 M(R, r) = ∫_R w_safe(x) U(x, r) dx。交互配置目标是压低 M 而不是压低平均熵。

**定义 314（分辨率感知信息动作 RAI）** 信息动作 g = (g_type, R, r, g_gaze, g_probe, g_ask)，g_type ∈ {O: 重观测/换视角/变焦, C: 可逆后果探针, T: 提问}。成本 c(g) 随 r、|R|、g_type 递增（T 的社会成本另计）。所有 g 仍须过 C-RAS-WM 前缀认证（继承 R69 定义 302）。

**定义 315（风险加权 VoI）** VoI(g) = ∫_R w_safe(x)[H_before(x) − E_{y|g} H_after(x|y)] dx − c(g)。选择 g* = argmax VoI(g)，s.t. 预算、风险 ≤ ε_int、证据纪律。若 max VoI ≤ 0：不交互，沿退化阶梯调用 R69/R68。R69 的定义 298 是 w_safe≡1、r=0 的特例。

**定义 316（证词双通道）** 人类回答 y = (y_txt, y_pros)：y_txt 为文本/语义内容；y_pros 为韵律特征（F0 走向、能量、语速、停顿、jitter/shimmer、气声）。文本 → 语义蕴含的置信/情感分布 p(e|y_txt)；韵律 → p(e|y_pros)，e ∈ {自信, 犹豫, 紧张, 被迫, 反讽, 平静, …}。

**定义 317（韵律可信度 PRC）** κ(y) = P(内容正确且诚实 | y_pros, 历史交互, 语境) ∈ [0,1]，并须做**可信度校准**：可靠图单调、ECE_κ ≤ τ_κ。κ 只由数据/校准给出，不由「听起来真诚」直接给高分。

**定义 318（语义-韵律不一致 SPI）** I_inc(y) = D(p(e|y_txt) ‖ p(e|y_pros))（或 Wasserstein）。关键认识：I_inc 高既可能是**说谎/被迫**，也可能是**反讽、文化差异、非典型韵律、模型错误**——它是**歧义的证据**，不是「欺骗」的判决。故 I_inc > τ_I 时只允许**触发核实**（升级为 O/C），不得直接判为欺骗。

**定义 319（非对称证词更新 AVP）** κ_eff = min(κ_cap, κ·(1−I_inc))，其中 κ_cap < 1 为单独证词可达到的可信度上限。证词对模态后验的**上调**权重被此上限截断；**下调**不受此限（可任意降权、乃至弃用）。形式：p(M|o,y) ∝ p(M|o)·LR(y|M)，log LR 的正部被截断于 log(κ_cap/(1−κ_cap))，负部不截断。⇒ 情感语音是**否决权**，不是**确认权**。

**定义 320（观测优先仲裁 OBT）** 证据类型 O / C / T。认证规则：模态 m 可执行 ⇔
(a) 至少一条 O 或 C 支持 m；或
(b) 至少 k≥2 条**因果独立**的 T 一致，且 κ_eff 均 ≥ κ_min，且决策风险 < 高风险阈值。
高风险（risk ≥ ρ_high）时只接受 (a)。「因果独立」按证据生成机制判定（不同传感器 / 不同物理后果 / 不同信息源），不按模型数量判定。

**定义 321（条件证书 J_SIREN(r, κ)）** J_SIREN = (J_FLUID, r, κ, seg_ece, boundary_auc, κ_ece, i_inc_p95, evidence_mix, aff_ece, privacy_ok, siren_ver)。语义：**「在分辨率 r、可信度 κ 下，该结论安全」**；证书按 (r, κ) 偏序，低分辨率/低可信度证书**不可**推出高分辨率/高可信度结论（禁止证书洗白，定理 20）。

**定义 322（情感校准与非操纵 ACS）** 机器人表达情感/置信 e_expr 与其真实可靠度 rel 须满足 |e_expr − rel| ≤ τ_aff，统计上 ECE_aff ≤ τ_a。问句韵律 g_ask 必须**中性且校准**（避免诱导性、催促性、情绪施压），且目标函数中不得含「使对方顺从/情绪转向」的项。理由有二：伦理（不操纵）与**测量效度**（问句韵律会改变答案分布，是观察者效应；被污染的问句使证词失去可比性）。审计记录 g_ask 韵律作为潜在混杂因子。

**定义 323（韵律隐私与同意 PPC）** 情感推断须**目的限定、知情同意、最短保留**；不得由韵律推断受保护属性（种族/健康/性取向等）；审计前做**韵律脱敏**（只保留任务相关、非识别性统计量），隐私预算 ε_p 纳入证书。情感状态不作为长期画像存储。

**定义 324（威胁模型 AIC-SIREN）** ℰ_SIREN = ℰ_FLUID × ℰ_SEG × ℰ_PROS。ℰ_SEG：纹理/光照对抗补丁翻转边界标签、透明反光表面、域外材质；ℰ_PROS：策略性伪造自信/伪装犹豫、跨模态共谋（内容与韵律一起演）、以提问为名的社交工程、非典型韵律被误读为不可信。并入 AIC。

**定义 325（分辨率退化阶梯 RDL）** 五级：L0 = 完整 SIREN（分割与韵律均校准）；L1 = 分割未过校准 → 边界膨胀、仅在物体级决策、禁用边界级信任；L2 = 韵律未过校准 → 禁用证词，T 一律改 O；L3 = 流策略/尺度空间不可信 → 退回 R69 FLUID；L4 = R69 失效 → 退回 R68 CALM。每一级的安全侧风险单调不增（越往下越保守），切换不产生控制突变。

**定义 326（语义-几何一致性第三意见 SGC）** r_seg = 稠密标签场与几何/仿射预测之间的不一致度（边界处标签预测的深度/法向/可达性是否自洽）。低维标定（光度/运动学）只能吸收低维残差，无法同时抹平高维标签-几何不一致；故 **(r_res↓, Δa↑, r_seg↑)** 构成三重对偶证据，比 R69 的双通道更难被标定层整体骗过。

    def infer(self, o):
        qS   = self.seg(o)                       # p(S|o), 逐像素标签场

        # 把 R69 的模态歧义投影到空间：每个模态假设一个物体/边界归属

def choose_cell(field, w_safe, budget, c_ras_wm):

    for (R, r, g_type) in candidate_cells(field):          # O / C / T × 区域 × 分辨率

    # D) 风险加权 VoI：选尺度空间格子；不可信/无利可图则退化
    cell = M.rai.choose_cell(U_field, M.safety.w_safe, M.budget, M.c_ras_wm)
    if cell is None or slow:
        return M.rdl.degrade(level=3 if not slow else 4, modes, U_ale, U_epi)
    # E) 执行证据动作；不一致则升级为观测（不判决欺骗）
    ev = M.rai.execute(cell)
    kappa = 1.0
    if ev.kind == "T":
        kappa, i_inc = M.prc.testimony(ev.txt, ev.pros, M.history)
        if i_inc > TAU_INC:
            M.vqa_i.flag_incongruence(ev, i_inc)          # 审计：仅标记
            ev = M.rai.escalate_to_observation(cell)       # 去证实，不判罪
    # F) 非对称更新 + 观测优先仲裁
    resolved = M.avp.certify(ev, M.risk_level, kappa) and \
               M.obt.certify(ev, M.risk_level, kappa)
    U_epi_after = M.avp.update(modes, ev, kappa, i_inc)[1] if resolved else U_epi
    # G) 风险缩放 + 分辨率退化（继承 R69/R68）
    U_floor = U_ale + (0.0 if resolved else U_epi_after)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if M.acs.should_speak(lam):
        M.acs.speak_calibrated(rel=1.0 - lam, affect="uncertain")  # 不夸大置信
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_mode(modes, U_epi_after, lam)
    # H) 条件证书 + 参与式审计
    M.vqa_i.submit(cell, ev, kappa, i_inc, U_epi, U_epi_after)
    return ConditionedCert(J_FLUID=..., r=cell.r, kappa=kappa)
```

## 3. 推导

**引理 19（分辨率增益与边界配置）** 对区域 R 与分辨率 r，一次证据动作的期望风险加权增益 ≤ M(R, r)，且当后验更新近似高斯时增益 ≈ ∫_R w_safe(x)·I(S_x; y|g,R,r) dx。于是固定预算下最优配置满足：预算密度 ∝ w_safe(x)·U_∂(x)·（边界长度/|R|）。系：**交互预算应集中在"又危险又模糊的边界"上**；对物体内部大片低风险、低不确定区域做高分辨率观测是浪费。

**引理 20（否决权的不对称性）** 在 AVP（定义 319）下，若证词内容错误率为 δ_T、韵律可信度上限为 κ_cap，则仅凭证词定案的错误率 ≤ κ_cap·δ_T；若要求一条 O/C 证据（定义 320），则错误率 ≤ ε_perc + ε_res，且**与 δ_T 无关**。故「情感只可否决」把 R69 的「问错」风险从"随欺骗率线性放大"降为"被观测证据封顶"。

**引理 21（SPI 的可检测性与不可判定性）** 当内容与韵律由不同生成过程产生且相关 ρ<1 时，I_inc 对无意错误/犹豫的检测功效随样本长度上升；但当被评估者能策略性地同时控制内容与韵律（欺骗相关 ρ→1）时，I_inc 的对数似然比可任意接近 0（不可判定）。故 SPI 只能作**核实触发器**，不能作欺骗判决器——否则会把「文化/非典型韵律」误判为「不诚实」，产生系统性歧视。

**引理 22（语义-几何第三意见的抗标定吸收）** 设标定模型维度为 d_cal，语义-几何不一致 r_seg 的有效维度为 d_seg ≫ d_cal。低维标定只能拟合残差的 d_cal 维子空间，故 E[r_seg] 中至少有 d_seg − d_cal 维分量不被吸收；因此 (r_res↓, Δa↑, r_seg↑) 对缓变故障的判别力严格强于 R69 的双通道（在 d_cal 有界、A98 成立的条件下）。

**定理 18（SIREN 严格包含 FLUID / CALM）** 在 A95–A99 下，固定 r=r_ref、κ=κ_ref、禁用 T，SIREN 逐指令退化为 FLUID-RAS；再令「永不交互」，退化为 CALM-RAS。任意状态下，SIREN 的期望风险 ≤ R69 ≤ R68（安全侧）；仅当分割校准、韵律校准、观测优先三者同时满足时，才获得分辨率红利与可信度红利（效率侧）。任何校准失守都沿 RDL 单调退化。

**定理 19（观测优先的安全封顶）** 若认证遵守 OBT（定义 320），则高风险决策的错误认证率 ≤ ε_perc + ε_res，且对任意证词欺骗率 δ_T、任意共谋强度 ρ 均不变；非高风险决策的错误率 ≤ κ_cap·δ_T + ε_perc。即「信谁」不再能突破「看见什么」的上界。

**定理 20（条件证书的单调性与不可洗白）** J(r, κ) 在 r、κ 上单调：J(r,κ) 可推出 J(r'≤r, κ'≤κ)，但**不可**推出 J(r'≥r, κ'≥κ)。因此基于低分辨率观测或低可信度证词得到的结论，永远无法被表述为高分辨率/高可信度结论；与 J_CALM 组合后整体安全仍单调。系：R69 的「被证实的错误」在 SIREN 中被结构性禁止——证词最多得到一张写明 κ 的条件证书。

    for (R, r, g_type) in candidate_cells(field):      # O / C / T × 区域 × 分辨率

    loglr = content_log_likelihood(modes, ev.txt)
    loglr = min(loglr, log(kappa_cap / (1 - kappa_cap)))  # 正部截断
    if i_inc > TAU_INC:
        return modes, False, k_eff                         # 只触发核实，不判决
    return bayes_update(modes, loglr), True, k_eff

# IP-269 OBT：观测优先仲裁
def certify(ev, risk, k_eff):
    if ev.kind in ("O", "C"): return True
    if risk >= RHO_HIGH:      return False                # 高风险拒纯证词
    return ev.independent_count >= 2 and k_eff >= KAPPA_MIN

# IP-275 主闭环（继承 R69）
def SIREN_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)
    field = M.duf.infer(o)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    modes = M.fmp.sample(o, K)
    U_ale, U_epi, modes = M.aud.decompose(modes, z)
    U_field = M.duf.lift(U_epi, modes, M.safety.w_safe)
    slow = ((M.fma.flow_anomaly(M.fmp, M.last_action, o, o_cal) > TAU_FMA)
            and M.last_r_res < TAU_RES) or \
           (M.sgc.residual(field, o) > TAU_SEG and U_cal > TAU_CAL)
    cell = M.rai.choose_cell(U_field, M.safety.w_safe, M.budget, M.c_ras_wm)
    if cell is None or slow:
        return M.rdl.degrade(level=3 if not slow else 4, modes, U_ale, U_epi)
    ev = M.rai.execute(cell); kappa = 1.0
    if ev.kind == "T":
        kappa, i_inc = M.prc.testimony(ev.txt, ev.pros, M.history)
        if i_inc > TAU_INC:
            M.vqa_i.flag_incongruence(ev, i_inc)          # 仅标记，不判罪
            ev = M.rai.escalate_to_observation(cell)       # 升级为观测
    resolved = (M.avp.certify(ev, M.risk_level, kappa)
                and M.obt.certify(ev, M.risk_level, kappa))
    U_epi_after = M.avp.update(modes, ev, kappa, i_inc)[1] if resolved else U_epi
    U_floor = U_ale + (0.0 if resolved else U_epi_after)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if M.acs.should_speak(lam):
        M.acs.speak_calibrated(rel=1.0 - lam, affect="uncertain")  # 不夸大置信
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_mode(modes, U_epi_after, lam)
    M.vqa_i.submit(cell, ev, kappa, i_inc, U_epi, U_epi_after)
    return ConditionedCert(J_FLUID=..., r=cell.r, kappa=kappa)
```

## 4. 推导

**引理 19（分辨率增益与边界配置）** 一次证据动作的期望风险加权增益 ≤ `M(R,r)`；高斯近似下增益 ≈ `∫_R w_safe·I(S_x;y|g,R,r) dx`。固定预算下最优预算密度 ∝ `w_safe(x)·U_∂(x)·(边界长度/|R|)`。系：**预算集中在"又危险又模糊的边界"**；对物体内部低风险低不确定区做高分辨率观测是浪费。

**引理 20（否决权的不对称性）** AVP 下，仅凭证词定案的错误率 ≤ `κ_cap·δ_T`；若要求一条 O/C，则错误率 ≤ `ε_perc+ε_res` 且**与 δ_T 无关**。系：情感否决权把 R69 的「问错」从"随欺骗率线性放大"降为"被观测封顶"。

**引理 21（SPI 可检测但不可判定）** 内容与韵律生成过程相关 ρ<1 时，`I_inc` 对无意错误/犹豫有检测功效；当被评估者能策略性共控内容与韵律（ρ→1）时，对数似然比可任意接近 0。故 SPI 只能作核实触发器；作判决器会把文化/非典型韵律误判为不诚实，产生系统性歧视。

**引理 22（语义-几何第三意见的抗标定吸收）** 标定维度 `d_cal` 有界，语义-几何不一致有效维度 `d_seg ≫ d_cal`；低维标定最多吸收 `d_cal` 维，故 `E[r_seg]` 至少有 `d_seg−d_cal` 维不被吸收。因此 `(r_res↓, Δa↑, r_seg↑)` 的缓变故障判别力严格强于 R69 双通道（A98 条件下）。

**定理 18（SIREN 严格包含 FLUID / CALM）** A95–A99 下，固定 `r=r_ref, κ=κ_ref`、禁用 T，SIREN 逐指令退化为 FLUID-RAS；再令永不交互退化为 CALM-RAS。任意状态期望风险 `SIREN ≤ FLUID ≤ CALM`（安全侧）；仅在分割校准、韵律校准、观测优先同时满足时获分辨率/可信度红利；任一校准失守沿 RDL 单调退化。

**定理 19（观测优先的安全封顶）** 遵守 OBT 时，高风险错误认证率 ≤ `ε_perc+ε_res`，对任意欺骗率 δ_T 与共谋强度 ρ 不变；非高风险错误率 ≤ `κ_cap·δ_T+ε_perc`。即「信谁」不能突破「看见什么」的上界。

**定理 20（条件证书单调且不可洗白）** `J(r,κ)` 在 r、κ 上单调：可推出 `J(r'≤r, κ'≤κ)`，不可推出 `J(r'≥r, κ'≥κ)`。故低分辨率观测或低可信度证词得到的结论永远无法被表述为高分辨率/高可信度结论；与 `J_CALM` 组合后整体安全仍单调。系：R69 的「被证实的错误」被结构性禁止——证词最多得到一张写明 κ 的条件证书。

## 7. 本轮最大风险

**一句话**：SIREN 把不确定性拆成「哪里不确定」与「该不该信这个证人」，但这两把新尺子都是有系统偏置的尺子——语义分割在最需精确的接触/遮挡边界最不可靠，韵律可信度又会被文化、口音与神经多样性系统性误读；一旦校准失守，它不会退回「诚实的不知道」，而会把偏见局部化成「这里我很确定」、把该被倾听的人降权成「不可信」——这是比 R69「问错」更隐蔽、更带歧视性的「信错」。
