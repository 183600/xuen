# 第 56 轮（承接第 55 轮 GroundEdge-GenSim++++ 放置-泛化层；灵感循环第 2 轮；本轮灵感：「结构优化」×「失败恢复」）

> 第 55 轮把放置与场景泛化做成可度量、可弃权的证书覆盖。但此前所有证书都建立在"给定结构"之上：技能图 `G_S` 的拓扑、抽象层级、切片划分、校准预算被当作固定输入，失败恢复则被当作执行后的补丁。本轮聚焦 **结构即设计变量、可恢复性作为结构约束、失败驱动的单调结构更新**。核心矛盾：H24：证书体系是静态结构，结构本身未被优化，导致仿真/算力/安全裕度在低价值边上浪费、在高风险切片上不足，"能覆盖"不等于"以最小代价覆盖"；H25：失败恢复不是事后补丁，若结构未预留恢复路径（冗余边、安全态、替代技能），一次失败会沿单点结构滚成不可逆灾难，"平均成功率高"的拓扑可能恰恰是最脆弱的。

## 0. 直觉与动机

**灵感 1（结构即设计变量：从"在图上算证书"到"优化承载证书的结构"）**
直觉：前几轮我们把技能图 `G_S`、切片格 `𝔾`、证书层级 `𝕃` 当作给定舞台，只在上面评估证书。但真正决定"能否在预算内既覆盖任务又可恢复"的，是结构本身：保留哪些边、在哪些节点上抽象/细化、切片怎么划分、把有限的仿真校准预算 `b` 分配到哪些边和切片。把结构记作 `𝕊=(H,ℓ,P_𝔾,b)`，优化目标不再是单点成功率，而是**最差切片上"成功 + 可恢复"的联合下界减去结构成本**。结构从背景变成一等决策变量。

**灵感 2（拓扑优化类比：载荷工况 = 扰动切片，材料体积 = 校准/算力预算，应力约束 = 证书 soundness）**
直觉：结构力学里的拓扑优化是在给定材料体积下，寻找在全部载荷工况都不失效的最轻结构，冗余传力路径天然提供失效后的备用载荷路径。这里把任务分布当载荷、扰动切片当工况、证书当应力约束、预算 `B` 当材料体积：我们要找的是**在所有已覆盖切片下证书不失效、且单边失效后仍有备用路径的最小结构**。技能图的冗余边不是浪费，而是恢复能力的物理载体。

**灵感 3（失败恢复 = 结构约束，而非执行后补丁）**
直觉：可靠系统不是"不出错"，而是"错了能回来"。对失败状态 `x`，恢复算子 `r` 把它送回某个已认证态 `x'`，代价 `c_rec(r)` 必须在 `τ_rec` 内。可恢复率 `Rec(g)` 是结构的函数：冗余度、替代路径数、安全态可达性。若优化目标只看成功率，会选出"高效但单点"的脆弱拓扑；必须把 `Rec` 作为结构设计的一等约束，与成功率联合优化。

**灵感 4（证书最小割 → k-可恢复性，把"冗余"变成可判定量）**
直觉：在只保留证书 sound 的边的子图上，任务源汇对的最小割 `λ_J(T)` 恰好是"最多能承受多少条边同时失效而仍有认证路径"。于是结构脆弱性有了严格度量：`min_T λ_J(T)`。若要求 `λ_J(T) ≥ k`，则任意 `k−1` 条边失效后任务仍可沿认证路径恢复（Menger 定理）。这把"多留几条边"的直觉升级为 **k-可恢复性**，并让结构调整有明确目标：不是盲目加边，而是抬高每个任务的证书最小割。

**灵感 5（失败驱动的单调结构更新：失败日志是结构的梯度）**
直觉：每次失败给出哪条边、哪个切片、哪种恢复失效。用 Beta 后验维护边可靠度下界 `r_e^LB`，剪掉不可信边、对高风险切片追加校准预算，再重跑结构优化。但更新必须**证书保持且目标单调不降**，否则会震荡、并让旧证书悄悄失效；因此更新带结构版本号与回滚，失败恢复的"教训"只在通过证书审计后才写回结构。

**灵感 6（结构条件化证书与运行时恢复守卫）**
直觉：证书只对生成它的结构 `𝕊` 有效。把 `structure_id` 写进证书，结构一变旧证书即失效（防止"结构改了、证书还挂着"的静默错误）。运行时若检测到偏离认证域，先尝试在 `τ_rec` 内沿认证替代路径恢复，超时则弃权并把失败写回结构更新通道。恢复不是兜底，而是结构承诺的一部分。

## 1. 形式化定义（增量：定义 128–134）

**定义 128（证书支撑结构）**
证书支撑结构 `𝕊 = (H, ℓ, P_𝔾, b)`：
- `H ⊆ G_S` 为保留的技能子图（含边集 `E_H`、节点集 `V_H`）；
- `ℓ: V_H → {0,1,2,...}` 为每个节点的抽象层级（0 最粗，越大越细）；
- `P_𝔾` 为场景切片划分（第 55 轮 `𝔾` 的合并/细化）；
- `b: E_H × 𝔾 → ℝ≥0` 为校准/验证预算分配。
可行结构族
```
𝒮(B) = { 𝕊 : Σ_{e∈E_H} Σ_{g∈𝔾} b(e,g) ≤ B, H 覆盖任务族 𝒯 的前置技能 }
```
`B` 为总预算（仿真算力 + 推理时延 + 存储）。

**定义 129（结构-恢复联合目标）**
对已覆盖切片 `g ∈ 𝔾_cov`：
```
S_𝕊(g)   = P(success | g, 𝕊)
Rec_𝕊(g) = P(∃ r : c_rec(r) ≤ τ_rec, r(x) ∈ X_cert | fail, g, 𝕊)
J(𝕊)     = min_{g∈𝔾_cov} [ S_𝕊(g) + λ·Rec_𝕊(g) ] − μ·cost(𝕊)
```
其中 `λ∈[0,1]` 权衡成功与恢复，`cost(𝕊)` 含校准算力、推理时延、存储。结构优化的目标是 `max_{𝕊∈𝒮(B)} J(𝕊)`。用最差切片而非均值，延续第 55 轮"最差切片优先"原则。

**定义 130（恢复算子与恢复域）**
恢复算子 `r: X_fail → X_cert ∪ {abstain}`，成本 `c_rec(r)`（含重规划、重抓取、退避、换技能）。恢复域
```
RecBasin_𝕊(x) = { x : ∃ r, r(x) ∈ X_cert, c_rec(r) ≤ τ_rec }
Rec_𝕊(g) = P_{x∼Fail(g)}[ x ∈ RecBasin_𝕊 ]
```
`r` 必须落在结构 `𝕊` 的认证边/安全态上，否则不算认证恢复。

**定义 131（失败感知边可靠度）**
边 `e` 的成功/失败计数 `(α_e, β_e)` 由失败日志累积，可靠度下界
```
r_e^LB = α_e/(α_e+β_e) − κ·sqrt( α_e β_e / ((α_e+β_e)²(α_e+β_e+1)) )
```
仅当 `r_e^LB ≥ r_min` 的边进入证书支撑子图 `H_cert`。`κ` 为保守度系数。

**定义 132（k-可恢复结构与证书最小割）**
对任务 `T=(src,dst)`，令
```
H_cert(ρ_min) = { e∈E_H : r_e^LB ≥ r_min 且边证书 sound }
λ_J(T) = mincut_{H_cert}(src, dst)
```
结构对 `𝒯` 是 **k-可恢复** 的，当且仅当 `∀ T∈𝒯, λ_J(T) ≥ k`。由 Menger 定理，任意 `k−1` 条边失效后 `src→dst` 仍存在认证路径；若该路径可在 `τ_rec` 内被恢复算子执行，则任务可恢复。定义结构脆弱度 `λ_J = min_{T∈𝒯} λ_J(T)`。

**定义 133（可恢复证书）**
```
R_cert = (structure_id, λ_J, RecBasin, τ_rec, alt_slack, fallback_set, evidence)
```
- `structure_id` 绑定生成它的结构版本；
- `λ_J` 结构最小割下界；
- `alt_slack` 为失效后替代路径的最小证书裕度；
- `fallback_set` 为可退避的安全技能/安全态；
- `evidence` 至少含故障注入日志、恢复演练记录、最小割审计。
部署条件：
```
S_𝕊(g) ≥ s_min ∧ Rec_𝕊(g) ≥ ρ_rec ∧ λ_J ≥ k_target ∧ δ_a ≤ Θ_a
```

**定义 134（证书保持的结构更新）**
更新算子 `U: (𝕊_t, log_t) → 𝕊_{t+1}`，若
```
J(𝕊_{t+1}) ≥ J(𝕊_t)  且  ∀ c∈Certs(𝕊_t): valid(c, 𝕊_{t+1})
```
则接受并递增 `structure_id`（旧证书重签）；否则回滚到 `𝕊_t`。单调性保证有限预算下不震荡，并防止更新悄悄改写已部署证书的语义。

## 2. 关键算法 伪代码

### IP-128 SSO（Structure Search Optimization）

```python
def optimize_structure(G, slices, B, lam=0.5, k_target=2):
    S = init_structure(G)               # 全图、粗层级、均匀预算
    while budget_used(S) < B:
        gains = []
        for mv in candidate_moves(S):   # add_edge / refine_node / split_slice / alloc_budget
            S2 = apply(S, mv)
            if budget_used(S2) > B or not cert_preserved(S, S2):
                continue
            gains.append((J(S2, slices, lam) - J(S, slices, lam), mv))
        if not gains or max(g for g, _ in gains) <= 0:
            break
        S = apply(S, max(gains)[1])
    S = local_search(S, slices, B, lam)          # swap / remove / realloc
    return S, cert_min_cut_all(S, k_target)

def J(S, slices, lam):
    worst = min(S_success(S, g) + lam * S_recover(S, g) for g in slices)
    return worst - mu * cost(S)
```

### IP-129 CMA（Certificate Min-cut Analysis）

```python
def cert_min_cut_all(S, k_target):
    Hc = certified_subgraph(S)      # r_e^LB >= r_min 且边证书 sound
    report = {}
    for T in S.tasks:
        lam = nx.edge_connectivity(Hc, T.src, T.dst)
        cut = nx.minimum_edge_cut(Hc, T.src, T.dst)
        report[T.id] = (lam, cut)
    fragile = [t for t, (lam, _) in report.items() if lam < k_target]
    return report, fragile
```

### IP-130 RRC（Recovery Router）

```python
def recovery_router(S, x_fail, tau_rec, rho_min):
    exp = explain_failure(x_fail)                       # 复用第 53 轮 Explain
    paths = k_shortest_cert_paths(S.H, x_fail.state, S.safe_states, k=3)
    for P in paths:
        r = build_recovery_op(x_fail, P)                # 重规划 + 重抓/退避/换技能
        if cert_sound(P, rho_min) and c_rec(r) <= tau_rec:
            return ('recover', r, P)
    return ('abstain', exp)                             # 无认证恢复路径或超时
```

### IP-131 FDE（Failure-Driven Edge update）

```python
def failure_driven_update(S, failure_log, kappa=2.0, r_min=0.9):
    for e in S.H.edges:
        a = prior_a[e] + count_success(failure_log, e)
        b = prior_b[e] + count_failure(failure_log, e)
        mean = a / (a + b)
        std = sqrt(a * b / ((a + b) ** 2 * (a + b + 1)))
        r_lb[e] = mean - kappa * std
    S.H = prune_edges(S.H, lambda e: r_lb[e] >= r_min)
    for g in high_fail_slices(failure_log):
        S.b = realloc_budget(S.b, g, mode='explore')
    return S
```

### IP-132 RCG（Recovery Certificate Guard）

```python
def recovery_guard(state, S, R_cert, rho_min):
    if state.certified and rho(state) >= rho_min:
        return ('continue', None)
    if R_cert.lambda_J >= 2 and R_cert.alt_slack > 0:
        r = R_cert.recovery_op(state)
        return ('recover', r)
    if state.time_in_fail > R_cert.tau_rec:
        return ('abstain', 'recovery_timeout')
    return ('monitor', None)
```

### IP-133 PSU（Preserving Structure Update）

```python
def preserving_structure_update(S_old, S_new, certs):
    if J(S_new) < J(S_old):
        return S_old, 'reject_regress'
    if not all(cert_valid(c, S_new) for c in certs):
        return S_old, 'cert_invalidation'
    S_new.id = next_structure_id()
    for c in certs:
        c.structure_id = S_new.id       # 旧证书失效，必须重签
    return S_new, 'ok'
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SSO | O(R·\|Moves\|·T_eval) | O(\|V\|+\|E\|) | 贪心次模性或局部搜索下界、预算可行 |
| CMA | O(\|𝒯\|·\|E\|·√\|V\|) | O(\|V\|+\|E\|) | 最小割精确、证书边子图 sound |
| RRC | O(k·(\|E\|+\|V\|log\|V\|)) | O(k\|V\|) | k 短路认证、τ_rec 可达 |
| FDE | O(\|E\|+Σ log) | O(\|E\|) | 后验下界一致、剪枝保守 |
| RCG | O(1) | O(1) | 守卫优先恢复、超时即弃权 |
| PSU | O(\|Certs\|·\|V\|) | O(1) | 单调不降、证书保持、版本绑定 |

**正确性定理（Structure-Recovery Soundness）**
承接第 55 轮 (A29)–(A31)；新增：
**(A32)** 单一故障类下同时失效边数 `|F| ≤ k−1`，且不同故障类之间不共因；
**(A33)** 恢复算子在 `τ_rec` 内可执行且恢复成功可观测；
**(A34)** 边可靠度下界与真实可靠度偏差 ≤ `β_R`。
则在 `deploy` 条件（定义 133）下，对任意任务 `T`：
```
P(success ∨ recovered | deploy)
  ≥ 1 − α_g − L_p·R_gen − β_P − P(|F| ≥ k) − Σ_{e∈F}(1 − r_e^LB) − P(c_rec > τ_rec)
```
灾难性未恢复概率
```
P(catastrophic) ≤ P(uncovered) + α_g + L_p·R_gen + β_P + P(|F| ≥ k) + P(τ_rec timeout)
```
关键：**结构先验 k-可恢复**，**恢复路径有认证最小割下界**，**结构更新证书保持且单调**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 结构目标在仿真里可恢复、真实里不可恢复（sim-to-real gap） | 高 | 随机故障注入 + 保守裕度 + 实机恢复演练 |
| 故障相关性/共因失效破坏 k-边连通假设 | 高 | 故障类相关性建模 + 共因最小割 + 最坏簇分析 |
| 贪心次模性不成立，近似保证失效 | 中 | 经验验证次模性 + 局部搜索 + 对偶界 |
| 结构更新震荡或让旧证书静默失效 | 高 | 单调更新 + 证书保持审计 + structure_id 回滚 |
| 恢复算子在 τ_rec 内不可达 | 中 | 运行时超时弃权 + 安全态预置 + 恢复预算预留 |

## 6. 本轮最大风险

**一句话**：结构-恢复联合优化把"技能图 + 证书"从给定结构升级为"可优化、可恢复、可审计"的证书支撑结构，但其 soundness **双重依赖故障独立且同时失效数有界、以及仿真标定的可恢复率能迁移到真实系统**；一旦出现共因失效或 sim-to-real 漂移，`k`-可恢复性与证书最小割会变成虚假包络，优化器反而会选中"看起来冗余、实则共因同崩"的脆弱拓扑，故必须以 **故障相关性建模 + 证书最小割审计 + 实机恢复演练 + 超时弃权** 四重护栏，宁可保守不优化，绝不把"结构上可恢复"当成"现实中能恢复"。

# 第 56 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（放置-泛化层 × 结构-恢复层）

> 承接 v31（第 54 轮动作-协同层）。本清单同时固化第 55 轮 **放置-泛化层**（IP-121~126）并把第 56 轮升级为 **结构-恢复层**（IP-128~133）：

> - **PSU（Preserving Structure Update）**：证书保持 + 目标单调的结构更新。

## 2. 关键算法 伪代码

### IP-128 SSO

```python
def optimize_structure(G, slices, B, lam=0.5, k_target=2):
    S = init_structure(G)               # 全图、粗层级、均匀预算
    while budget_used(S) < B:
        gains = []
        for mv in candidate_moves(S):   # add_edge / refine_node / split_slice / alloc_budget
            S2 = apply(S, mv)
            if budget_used(S2) > B or not cert_preserved(S, S2):
                continue
            gains.append((J(S2, slices, lam) - J(S, slices, lam), mv))
        if not gains or max(g for g, _ in gains) <= 0:
            break
        S = apply(S, max(gains)[1])
    S = local_search(S, slices, B, lam)
    return S, cert_min_cut_all(S, k_target)

def J(S, slices, lam):
    worst = min(S_success(S, g) + lam * S_recover(S, g) for g in slices)
    return worst - mu * cost(S)
```

### IP-129 CMA

```python
def cert_min_cut_all(S, k_target):
    Hc = certified_subgraph(S)      # r_e^LB >= r_min 且边证书 sound
    report = {}
    for T in S.tasks:
        lam = nx.edge_connectivity(Hc, T.src, T.dst)
        cut = nx.minimum_edge_cut(Hc, T.src, T.dst)
        report[T.id] = (lam, cut)
    fragile = [t for t, (lam, _) in report.items() if lam < k_target]
    return report, fragile
```

### IP-130 RRC

```python
def recovery_router(S, x_fail, tau_rec, rho_min):
    exp = explain_failure(x_fail)                       # 复用第 53 轮 Explain
    paths = k_shortest_cert_paths(S.H, x_fail.state, S.safe_states, k=3)
    for P in paths:
```

### IP-131 FDE

```python
def failure_driven_update(S, failure_log, kappa=2.0, r_min=0.9):
    for e in S.H.edges:
        a = prior_a[e] + count_success(failure_log, e)
        b = prior_b[e] + count_failure(failure_log, e)
        mean = a / (a + b)
        std = sqrt(a * b / ((a + b) ** 2 * (a + b + 1)))
        r_lb[e] = mean - kappa * std
    S.H = prune_edges(S.H, lambda e: r_lb[e] >= r_min)
    for g in high_fail_slices(failure_log):
        S.b = realloc_budget(S.b, g, mode='explore')
    return S
```

### IP-132 RCG

```python
def recovery_guard(state, S, R_cert, rho_min):
    if state.certified and rho(state) >= rho_min:
        return ('continue', None)
    if R_cert.lambda_J >= 2 and R_cert.alt_slack > 0:
        return ('recover', R_cert.recovery_op(state))
    if state.time_in_fail > R_cert.tau_rec:
        return ('abstain', 'recovery_timeout')
    return ('monitor', None)
```

```python
def preserving_structure_update(S_old, S_new, certs):
    if J(S_new) < J(S_old):
        return S_old, 'reject_regress'
    if not all(cert_valid(c, S_new) for c in certs):
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SSO | O(R·\|Moves\|·T_eval) | O(\|V\|+\|E\|) | 贪心/局部搜索下界、预算可行 |
| CMA | O(\|𝒯\|·\|E\|·√\|V\|) | O(\|V\|+\|E\|) | 最小割精确、证书边子图 sound |
| RRC | O(k·(\|E\|+\|V\|log\|V\|)) | O(k\|V\|) | k 短路认证、τ_rec 可达 |
| FDE | O(\|E\|+Σlog) | O(\|E\|) | 后验下界一致、剪枝保守 |
| RCG | O(1) | O(1) | 恢复优先、超时弃权 |
| PSU | O(\|Certs\|·\|V\|) | O(1) | 单调不降、证书保持、版本绑定 |

**正确性定理（Structure-Recovery Soundness）**
承接 (A29)–(A31)；新增 **(A32)** 单一故障类下 `|F| ≤ k−1` 且无共因；**(A33)** 恢复算子在 `τ_rec` 内可执行且可观测；**(A34)** 可靠度下界偏差 ≤ `β_R`。则在 `deploy` 条件下：
```
P(success ∨ recovered | deploy)
  ≥ 1 − α_g − L_p·R_gen − β_P − P(|F| ≥ k) − Σ_{e∈F}(1 − r_e^LB) − P(c_rec > τ_rec)
P(catastrophic) ≤ P(uncovered) + α_g + L_p·R_gen + β_P + P(|F| ≥ k) + P(τ_rec timeout)
```
关键：**结构先验 k-可恢复**，**恢复路径有认证最小割下界**，**结构更新证书保持且单调**。

## 5. 本轮最大风险

**一句话**：结构-恢复联合优化把"技能图 + 证书"从给定结构升级为"可优化、可恢复、可审计"的证书支撑结构，但其 soundness **双重依赖故障独立且同时失效数有界、以及仿真标定的可恢复率能迁移到真实系统**；一旦出现共因失效或 sim-to-real 漂移，`k`-可恢复性与证书最小割会变成虚假包络，优化器反而会选中"看起来冗余、实则共因同崩"的脆弱拓扑，故必须以 **故障相关性建模 + 证书最小割审计 + 实机恢复演练 + 超时弃权** 四重护栏，宁可保守不优化，绝不把"结构上可恢复"当成"现实中能恢复"。
