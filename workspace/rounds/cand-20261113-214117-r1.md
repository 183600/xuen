## 0. 直觉与动机

**灵感 1（运动学 → 骨架是唯一不会说谎的第三人）**
直觉：学习模型会漂，传感器会老化，标定参数会蠕变，但「这条机械臂在当前关节角下，末端**按定义**应该在哪」是一个解析恒等式。它不需要训练、不需要标签、不会因为分布偏移而改变语义。R68 的问题是标定和故障都藏在「学习出来的残差」里互相冒充；运动学锚点把其中一个嫌疑人（身体几何）用物理恒等式固定住，于是残差不再是黑箱里的赌注，而是可以被**几何分解**的量。关键不是精度更高，而是**误差来源的正交化**。

**灵感 2（Jacobian / 零空间 → 免费的故障见证器）**
直觉：task-space 残差 r 对关节运动的可解释部分恰好落在 Jacobian 的列空间 range(J) 里；对运动学参数的可解释部分落在标定回归子 Y 的列空间里。把 r 投影到 [J Y] 的正交补，剩下的 r_⊥ 是「无论怎么动关节、怎么调零偏都解释不了」的分量——它只能来自世界变化、接触、结构变形或真实故障。更妙的是：在冗余机器人上，沿 null(J) 做**自运动**可以在末端几乎不动的情况下激励 Y，得到安全的持续激励数据——这就是「零空间资格赛」，把主动辨识从「危险地动」变成「安全地动」。

**灵感 3（可辨识性 → 标定只能合法吸收落在回归子空间里的残差）**
直觉：标定不是万能橡皮擦。一个缓变故障想冒充标定，必须在**所有被访问过的构型**上都近似满足 f(q) ≈ Y(q)δπ；换句话说，它必须落在由构型多样性张成的标定回归子空间里，并且参数位移不能超过物理漂移预算。构型越丰富、回归矩阵条件数越好，能冒充的空间越小；超出预算的位移则直接判为故障。于是「标定能力越强 → 故障越隐形」被反过来：**标定越可辨识，故障越无处可藏**。

**灵感 4（机器人竞赛 → 资格赛 / 联赛 / 裁判 / 红队 / 让分）**
直觉：工程上的 canary 是静态的、由人想出来的、会过时的；而竞赛是动态的、对抗的、会自动加难的。把每个解释（cal / kin / sens / world / model）当作一名选手：
- **资格赛**（QGA）：在安全壳内主动选择最能区分选手的机动，谁能在没见过的赛道上预测准，谁晋级；
- **联赛表**（EL）：用 held-out 预测对数分数 + Elo/Glicko 评级，处理非平稳与选手更替；
- **裁判**（REF）：闭环一致性、刚体距离守恒、非完整约束、接触锥——这些硬不变量不容许任何选手「解释掉」，犯规即红牌；
- **红队 / 自博弈**：专门生成让当前冠军翻车的故障场景，自动刷新 canary；
- **让分 / 工资帽**（KBP）：标定选手每移动一单位参数都要交复杂度税，且不能超过物理漂移预算——防止「参数多所以什么都能拟合」；
- **权限跟随名次**（AUF）：冠军才拿到标定吸收权，故障/世界选手得票越高，λ 越低、前缀 k 越短。

**灵感 5（合流 → KART-RAS 七组件 + 一个纪律）**
1. **KAC Kinematic Anchor Channel**：解析 FK/Jacobian + 多链闭环 + 非完整约束，产出运动学残差与见证；
2. **RSA Residual-Subspace Analyzer**：range/null 分解、可辨识指数 κ_id、标定锥 C_π、泄漏率 L；
3. **EL Explanation League**：五选手的序贯对数分数联赛 + MDL 让分 + 折扣证据 + Elo 评级；
4. **QGA Qualifying Gauntlet**：安全约束下的 D-最优/判别最优主动机动，零空间自运动是核心武器；
5. **REF Referee Invariants**：硬不变量裁判，犯规即否决；
6. **AUF Authority Follower**：权限（λ, k, ω_absorb）是联赛后验与裁判的单调函数；
7. **CAC-K**：R68 五关认证升级，加入运动学 canary、对抗回放与歧义标记；RAS-WM† 继承核不变。
统一纪律：**歧义只导向收紧，绝不导向放行**——R66/R67/R68 的「不确定性→保守」在此升级为「解释歧义→保守」。

## 1. 形式化定义（增量：定义 293–310）

**定义 293（KART-RAS 总览）** KART-RAS = (KAC, RSA, EL, QGA, REF, AUF, CAC-K, RAS-WM†)。三条不变式：
(i) **解析锚定不变式**：运动学模型 f 的参数 π 只允许在物理漂移预算内、通过可辨识性检验后更新；任何学习模型不得写入锚点；
(ii) **解释权限不变式**：控制权限 (λ_risk, k_prefix, ω_absorb) 是联赛后验与裁判否决的单调函数——故障/世界后验越高、歧义越大、犯规越多，权限只减不增；
(iii) **激励安全不变式**：一切主动辨识机动必须先投影到安全壳 Ξ_safe（关节限位、速度/加速度、接触稳定、无碰撞、任务位姿漂移界）；安全壳否决 ⇒ 信息增益记为 0 ⇒ 回到保守，而非强行激励。

**定义 294（KAC 运动学锚点通道）** 设关节构型 q_t ∈ Q ⊂ ℝ^n，task-space 位姿 x_t ∈ SE(3)（由视觉/触觉/标记给出测量 x̂_t）。解析映射
f: Q × Π → SE(3),  (q, π) ↦ T_{base→task}(q, π)，
π ∈ ℝ^p 为运动学参数（连杆长度、关节零位、工具/相机外参、轮半径与轮距）。运动学残差
r^K_t = log_{SE(3)}( f(q̂_t, π̂_t)^{−1} x̂_t ) ∈ ℝ^6，
多链/多机情形再拼接闭环残差 r_loop = log(f_1(q)^{-1} f_2(q)) 与非完整约束残差 r_nh = v_y（轮式底盘侧滑速度）。KAC 是**解析计算**，不含任何学习参数。

**定义 295（RSA 残差子空间分解与可辨识指数）** 局部线性化
r_t ≈ J_t δq_t + Y_t δπ_t + ε_t,  J_t = ∂f/∂q, Y_t = ∂f/∂π.
记 Stacked 回归矩阵 A_N = [J_1; Y_1; …; J_N; Y_N]（N 个构型），P_A 为到 range(A_N) 的正交投影，P_⊥ = I − P_A。分解
r = r_J + r_π + r_⊥,  r_J = P_J r,  r_π = P_{Y|J} r,  r_⊥ = P_⊥ r.
定义：
- 关节解释比例 ρ_J = ‖r_J‖/‖r‖，标定解释比例 ρ_π = ‖r_π‖/‖r‖，**故障见证** w = r_⊥；
- **可辨识指数** κ_id = σ_min(W^{1/2} A_N) / √N（W 为噪声白化矩阵），度量「当前构型窗口能把标定参数约束到多紧」；
- **标定锥** C_π(τ) = {Y δπ : ‖δπ‖_{Σ_π^{−1}} ≤ τ}，τ 由物理漂移预算给出；
- **泄漏率** L = ‖P_A f‖/‖f‖：一段故障残差 f 最多有多少比例能被关节+标定联合解释掉。

**定义 296（观测等价类与歧义度）** 对假设 h，其观测等价类 E_h = {θ_h : A_N θ_h = r}。若 E_h ∩ E_{h′} ≠ ∅，则在该数据下 h 与 h′ 不可区分。定义歧义度
U_amb = −log Σ_h exp(β S_h) 的熵形式（即联赛后验的有效熵），或等价的成对最小可分性 min_{h≠h′} D(h,h′)，其中 D 为期望对数似然比。**显式不可判定原则**：若 r_fault 在所有可达安全构型上恒属于 range(A_N) 且参数位移在漂移预算内，则不猜测、只标记 U_amb 升高并收紧权限。

**定义 297（EL 解释联赛）** 选手集 H = {h_cal, h_kin, h_sens, h_world, h_model}。每个选手是一个前瞻预测器
p_h(r_{t+1} | q_{t+1}, D_{1:t})，其序贯评分为
S_h(t) = Σ_{s≤t} γ^{t−s} [ log p_h(r_s | q_s, D_{<s}) − λ_MDL · c(h) ]，
γ ∈ (0,1] 为折扣因子（跟踪非平稳），c(h) 为有效复杂度/描述长度。评级 R_h 用 Elo/Glicko 由成对分数差更新；权限先验 α_h = softmax_β(R_h)。冠军 = argmax_h R_h。与 R68 的区别：R68 是固定先验下的单滤波器；EL 是**held-out、前瞻、带复杂度让分、可更替选手**的竞赛。

**定义 298（KBP 漂移预算与复杂度让分）** 物理漂移预算
Π_drift(t) = {π : ‖π − π_0‖_{Σ_π^{−1}} ≤ v_drift·t + b_0}，
v_drift 由热膨胀/蠕变/磨损的物理上界标定。标定选手必须为参数移动支付
c(h_cal) = ½‖δπ‖²_{Σ_π^{−1}} + MDL(π)，
即「工资帽 + 让分税」：参数移动越大、模型越复杂，证据分数扣得越多；超出 Π_drift(t) 的参数位移一票判为故障。**这是对 R68 缓变故障吸收的第一道正面封堵。**

**定义 299（QGA 资格赛与主动竞技场）** 在每个认证窗口选择机动序列 ξ = (q_{1:T}, 接触调度)：
ξ* = argmax_{ξ ∈ Ξ_safe} [ I(H; r_{1:T}(ξ)) + λ_disc · min_{h≠h′} D(h,h′; ξ) ]
≈ argmax_{ξ ∈ Ξ_safe} [ σ_min(W^{1/2} A_N(ξ)) + λ_disc · 判别项 ]，
s.t. 关节限位、速度/加速度、接触稳定、无碰撞、任务位姿漂移 ≤ δ_task。
核心机制：**零空间自运动激励**——当 n > dim(task) 时，沿 null(J) 移动 q 可保持末端位姿近似不变，同时激励 Y 的原本不可观方向，得到「末端不动、参数可观」的安全持续激励。资格赛是难度递增的课程；「一对一比赛」挑选当前最接近的两名选手，专门设计把它们分开的机动。

**定义 300（REF 裁判不变量）** 一组解析硬约束，任何解释都不得违反：
- 闭环一致性 ‖log(f_1(q)^{-1} f_2(q))‖ ≤ ε_loop（多链/多机）；
- 刚体距离/形状守恒：视觉/触觉测得的标记间距离与运动学预测一致；
- 非完整约束：轮式底盘侧滑 v_y ≈ 0（或已知滑移模型内）；
- 接触一致性：接触力在摩擦锥内、无穿透、支撑多边形内；
- 动量/能量上界（可选，针对浮动基座）。
违反即「犯规」，立即触发保守回退，并取消当前冠军的标定吸收权直到重新通过资格赛。裁判是解析的、版本化的，纳入证书。

**定义 301（AUF 权限跟随）** 权限三元组 a_t = (λ_risk, k_prefix, ω_absorb)。
λ_t = max( λ_RAS, λ_floor, g_fault(Σ_{h∈{sens,world,model}} α_h), g_foul(REF) )；
k_t = min( k_RAS, k_max·(1 − Σ_{fault/world} α_h), k_cal(κ_id) )；
ω_absorb = ω_cal · 1[ κ_id ≥ κ_min ∧ REF = PASS ∧ (h_cal = champion) ]。
语义：**标定吸收权不再无条件**；它必须同时赢得联赛、通过可辨识性、且不犯规。R68 的「标定带宽吸收」在此被三重门控。

**定义 302（红队与自博弈课程）** 红队 R_φ 生成物理可实现且安全的故障/工况 φ，目标是最大化联赛混淆：
φ* = argmax_φ H(H | D, ξ(φ))，s.t. φ 物理可实现、不越安全壳。
蓝队（KART）把 φ* 加入资格赛课程并重训选手；课程难度按红队胜率自动上调。这替代了 R68 的静态 canary：**canary 由对抗生成、自动保鲜**。

**定义 303（奇异掩蔽与可观测椭球）** 可操作度 μ(q) = √det(JJ^T)，可观测椭球 O(q) = {J δq}。在奇异位形附近 J 降秩，某些故障方向落入 N(J)，形成**奇异掩蔽**。规则：RSA 对近奇异构型的证据按 μ(q) 降权（等价于增大局部 R）；QGA 除非特意探测柔性/变形，否则避开奇异掩蔽区；EL 记录每名选手在奇异区的历史表现并分域评级。

**定义 304（多链/多机共识，扩展）** 若存在多条运动链或多台机器人共享标记/相对位姿，则每条链给出独立锚点；跨链闭环与跨机相对观测给出额外方程。单通道故障无法同时满足所有链的闭环——故障可被定位到具体链/机。这同时是「机器人竞赛」的字面读法：多机同场竞技时，每台机器人的「声称」都被其他机器人的运动学交叉检验。

**定义 305（AIC-K 干扰集）** ℰ_KART = ℰ_CALM × ℰ_kin × ℰ_league × ℰ_probe，其中
ℰ_kin = {运动学参数漂移、关节编码器偏置、链间失配、奇异掩蔽、柔性变形}；
ℰ_league = {竞技场过拟合、冠军博弈、红队合谋、非平稳评分、Elo 漂移}；
ℰ_probe = {危险激励、激励诱发磨损、接触扰动、探测诱发故障}。

**定义 306（J_KART 证书）** J_KART = (J_CALM, anchor_hash(π̂), κ_id, U_amb, league_standings_hash, referee_verdict, gauntlet_hash, kart_ver)。Valid ⇔ Valid(J_CALM) ∧ (κ_id ≥ κ_min ∨ U_amb 已显式标记) ∧ referee_verdict = PASS ∧ 探测安全 ∧ 红线未越界。

**定义 307（KART 管线）** 离线：建立解析运动学模型 → 出厂资格赛辨识 π → 预训五名选手。在线：每控制周期跑 KAC/RSA/REF 并更新 EL 的即时分数；每 T_league 更新评级与权限；每 T_cert 在影子流跑 QGA（仅在安全且信息增益 > 0 时）→ CAC-K 五关 → 原子换装；权限由 AUF 逐周期输出。

**定义 308（安全-信息两难）** 对机动 ξ 定义探测风险 R_probe(ξ)（越界概率、磨损增量、接触扰动）与信息增益 I(ξ)。可行域 Ξ_safe = {ξ : R_probe(ξ) ≤ R_max}。若 Ξ_safe 内不存在有信息量的机动（I* = 0），则 U_amb 保持高位、ω_absorb = 0、权限取保守下界；系统显式报告「不可辨识」，而非假装辨识成功。

**定义 309（与 CALM 的向后兼容）** 当只有单链、无冗余、且不允许任何激励时，A_N 退化、κ_id → 0，于是 ω_absorb = 0：KART **严格关闭**了 R68 的标定吸收通道，退化为比 CALM 更保守的安全子集。当 κ_id 高且联赛判定 cal 为冠军时，KART 恢复 CALM 的全部收益。故 KART 是 CALM 的严格安全泛化：**默认更保守，证据充分才解锁**。

**定义 310（术语边界：何为「不可判定」）** 若一段残差同时满足 (a) r_⊥ 在噪声界内，(b) 所需参数位移在物理漂移预算内，(c) 在所有可达安全构型上等价类不空，则称其**运动学不可判定**。KART 对不可判定情形不输出「故障」或「漂移」的硬判断，而输出三值结论 {cal, fault, UNDECIDABLE} 及 U_amb；UNDECIDABLE 一律走保守权限。**把「不知道」变成一等公民，是 R69 对 R68 最重要的纪律升级。**

## 2. 关键算法骨架

# IP-253/254 KAC + RSA：解析锚点与子空间分解
class KinematicAnchorAnalyzer:
    def __init__(self, model, chains, sigma_eps, kappa_min):
        self.f, self.chains = model, chains          # 解析 FK + 多链
        self.sigma_eps, self.kappa_min = sigma_eps, kappa_min

    def residual(self, q_hat, x_hat, pi_hat):
        r_ee  = logSE3(inv(self.f(q_hat, pi_hat)) @ x_hat)   # 6 维 twist
        r_loop = [logSE3(inv(fi(q_hat)) @ fj(q_hat)) for fi, fj in self.chains]
        return vstack([r_ee] + r_loop)

    def decompose(self, r, q, window):
        A = stack_regressor(self.f, q, window)        # [J | Y] over window
        P_A, P_perp = projector(A)
        r_pi = P_A @ r                                # 关节+标定可解释
        w    = P_perp @ r                             # 故障见证（正交补）
        kappa_id = smin(self.sigma_eps**-0.5 * A) / sqrt(len(window))
        return {'r_pi': r_pi, 'w': w, 'kappa_id': kappa_id,
                'leak': norm(P_A @ r) / max(norm(r), 1e-9)}


# IP-255/298 EL：带让分税与漂移预算的解释联赛
class ExplanationLeague:
    def __init__(self, contestants, gamma=0.98, lam_mdl=0.05):
        self.h, self.gamma, self.lam = contestants, gamma, lam_mdl
        self.S = {k: 0.0 for k in contestants}        # 序贯对数分数
        self.R = {k: 1200.0 for k in contestants}     # Elo 评级

    def update(self, r_next, q_next, ctx, pi_move):
        scores = {}
        for k, c in self.h.items():
            ll = c.logpdf(r_next, q_next, ctx)
            scores[k] = ll - self.lam * c.complexity(pi_move)
            self.S[k] = self.gamma * self.S[k] + scores[k]
        self.elo_update(scores)                        # 成对评级更新
        return self.posterior(), self.champion()

    def posterior(self):
        z = np.array([self.R[k] for k in self.h]) / 200.0
        return softmax(z)

    def admissible_cal(self, kappa_id, referee_pass, pi_move, drift_budget):
        return (self.champion() == 'cal' and kappa_id >= KAPPA_MIN
                and referee_pass and norm(pi_move) <= drift_budget)


# IP-256 QGA：安全资格赛（含零空间自运动激励）
def design_gauntlet(anchor, league, safety_shell, horizon=8):
    best, best_val = None, -np.inf
    for xi in candidate_maneuvers(safety_shell, horizon):
        xi = safety_shell.project(xi)                  # 安全壳投影
        if xi is None: continue
        A    = stack_regressor(anchor.f, xi.q, xi.window)
        info = smin(whiten(A))                          # D-最优信息
        disc = min_pairwise_divergence(league)          # 当前最接近的两名
        val  = info + LAMBDA_DISC * disc
        if val > best_val: best, best_val = xi, val
    return best if safety_shell.info_gain(best) > 0 else None


# IP-300 REF：硬不变量裁判
def referee(T_ref, r, q, contact, model):
    fouls = []
    if norm(r['loop']) > EPS_LOOP:                 fouls.append('loop_closure')
    if not friction_cone_ok(contact):              fouls.append('contact_cone')

# IP-258 AUF：权限跟随联赛名次 + 裁判
def authority(league, rsa, ref, cal):

    p_bad = post['sens'] + post['world'] + post['model']

    return {'lambda': lam, 'k': k, 'omega_absorb': w_abs,

def KART_RAS_round(M, obs):

## 3. 推导

**引理 16（零空间见证的标定免疫性）** 设 r = Aθ + ε，A = [J Y]，θ 为关节+标定参数，‖ε‖ ≤ ε_max。则 r_⊥ = P_⊥ r = P_⊥ ε，故 H_cal 下 ‖r_⊥‖ ≤ ε_max；若存在不属于 range(A) 的故障分量 f，则 r_⊥ = P_⊥ f + P_⊥ ε，故 ‖r_⊥‖ ≥ ‖P_⊥ f‖ − ε_max。取阈值 τ_w = 2ε_max：H_cal 下零误报（有界噪声），故障满足 ‖P_⊥f‖ ≥ 3ε_max 时必检。随机噪声下 r_⊥ ~ 𝒩(0, σ²P_⊥)，用自由度 rk(P_⊥) = 6N − rk(A) 的 χ² 检验，误报率 α 由 χ² 分位数控制，检出由非中心参数 ‖P_⊥f‖²/σ² 给出。**系：故障见证分量对任何关节/标定解释免疫——这是 R68 最缺的那把尺。**

**引理 17（可辨识缺口与双重逃逸封堵）** 把窗口内故障向量 f 分解为 f = f_A + f_⊥，f_A ∈ range(A_N)。标定最多吸收 f_A，所需参数位移 δπ = Y^+ f_A（扣除关节项），残余见证 ‖f_⊥‖。于是缓变故障只有两条逃逸路径：
(1) 零空间逃逸：‖f_⊥‖ 小 ⇔ 故障在所有访问构型上都在 range(A_N) 内——要求 f(q) ≈ Y(q)δπ 全构型成立，这是极强的结构约束；
(2) 预算逃逸：‖δπ‖ ≤ B_drift(t) ⇔ 故障等效参数位移不超物理漂移预算。
两条都封住时，故障必被检出或必被预算否决；两条都满足时，故障与标定在运动学通道内**信息论不可分**（定义 310），KART 报 UNDECIDABLE 并收紧权限。检测非中心参数 = N(1−ρ_f²)‖f‖²/σ²，其中 ρ_f = cos∠(f, range(A_N))；构型多样性提升 N 与降低 ρ_f，使检测概率指数上升。**系：标定越可辨识，故障越难伪装——与 R68 的直觉正好相反。**

**引理 18（漂移预算的反吸收界与「歧义→保守」转换）** 设故障的等效参数速度为 v_f。若 v_f > v_drift + margin/T，则 δπ 终将越出 Π_drift(t)，H_cal 被拒，接受 H_cal 的概率 ≤ exp(−T·I_budget)。若 v_f ≤ v_drift 且故障落在 range(A_N) 内，则运动学通道不可判定；此时 U_amb 升高、ω_absorb = 0、λ 抬升。**关键性质：R68 的失败模式是「缓变故障→误判标定→错误放宽」；KART 把它转换为「缓变故障→显式歧义→保守性能损失」。安全失败被换成了性能代价，而非相反——这是本方案最重要的安全性论证。**

**引理 19（联赛评分的 properness 与 regret）** 对数分数是严格 proper scoring rule：若真实假设 h* ∈ H 且其预测分布正确，则 E[S_{h*}] 唯一最大。指数权重聚合的遗憾 ≤ log|H|/η；带折扣 γ 的稳态超额风险 ≤ O(1/(1−γ)) 乘以单步误差。MDL 让分等价于参数先验，抑制过拟合。**系：当 H 覆盖真值且竞技场分布代表真实工况时，联赛不会系统性偏向错误解释。** 但该保证在 H 未覆盖（misspecification）或竞技场分布偏移时失效——这正是定理 17 与本轮风险的来源。

**引理 20（权限单调性）** AUF 中 λ 对 p_bad = Σ_{fault/world/model} α_h 与犯规数单调不减，k 对 p_bad 单调不增，ω_absorb 对 κ_id、裁判通过、冠军身份单调不减。故任何「故障/世界/歧义/犯规增加」的变化都不会提高系统放行度。**系：把 R66 的 face_unobservable、R67 的 wm_drift、R68 的 U(ĉ) 与 R69 的 U_amb 统一为同一条「只收紧」纪律。**

**定理 16（KART-RAS 端到端风险一致性）** 在 A87–A94 与新增 A95（漂移慢变量与 v_drift 界）、A96（噪声有界/次高斯）、A97（联赛选手覆盖）下：
1. P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + **α_kin + α_league**，其中 α_kin ≤ exp(−N·I_kin) + 1[不可判定]·1（后者由引理 18 转为保守而非放行）；
2. 若 κ_id < κ_min 或裁判犯规，则 ω_absorb = 0，系统退化为不弱于 R68 的保守子集（向后兼容，定义 309）；
3. 不可判定情形下 λ ≥ λ_floor、k ≤ k_cal、吸收权为零——「不知道」只收紧；
4. 主动资格赛只在 Ξ_safe 内执行，故不引入超出安全壳的额外违规（定理 17）。

**定理 17（安全-辨识 Pareto 与零空间激励的信息增益）** 在安全壳 Ξ_safe 内，主动资格赛的期望误归因概率满足 Fano/Chernoff 型下界降低：P_err ≥ H(H|D)/(log|H|)，信息增益 I(ξ) 越大，下界可压得越低。最大可达增益 I* = max_{ξ∈Ξ_safe} I(ξ)；若 I* = 0，则 U_amb 不变、系统维持最小权限。对冗余机器人（n > dim task），存在沿 null(J) 的自运动 ξ_null 使 task-space 位姿一阶不变（δx = J δq = 0）而 Y δπ ≠ 0，因此 I(ξ_null) > 0 且 R_probe 仅来自关节运动/磨损——**安全性与可辨识性在零空间里不冲突**。反之，若安全壳冻结了所有激励，则接受不可判定，绝不假装辨识。

## 6. 本轮最大风险

**一句话**：KART-RAS 把控制权限交给「解释联赛」的冠军，等于把安全押在「**冠军是在预测世界，而不是在拟合竞技场**」这一个假设上；一旦真实故障不在选手库/资格赛分布覆盖内（或红队与蓝队共同演化出盲区），联赛会稳定选出一个**在竞技场上最会预测、却在世界中最错**的解释，而 AUF 会让这个错误解释获得最大的标定吸收权——即「越擅长赢得比赛，越危险」（Goodhart / performative risk）。

**次级风险与缓解**：
1. **安全-信息两难**：真实辨识需要激励，激励可能诱发磨损/接触扰动 → 安全壳投影 + 零空间自运动 + 风险预算 R_probe；宁可 UNDECIDABLE 也不危险探测；
2. **锚点自身的标定悖论**：运动学参数 π 也需初始标定，且可能随磨损漂移 → 出厂计量溯源 + 漂移预算 + π 纳入 J_KART 版本链；不把 π 当作绝对真值，只当作有预算的慢变量；
3. **竞技场过拟合 / 红蓝共谋盲区** → 保留独立第三方 benchmark、分布外挑战集、U_amb 必须显式上报，不允许「冠军置信度高」掩盖覆盖缺口；
4. **奇异掩蔽**：近奇异位形让部分故障方向不可见 → μ(q) 证据降权 + 资格赛避开奇异区 + 在证书中记录奇异暴露；
5. **Elo/评分非平稳漂移** → 折扣因子与滑动窗口 + 定期重赛 + 评级不确定性（Glicko RD）进入权限映射；
6. **多机对抗性欺骗**：他机可能故意提供错误相对位姿 → 跨机共识需鲁棒聚合（中位数/截尾）+ 裁判独立复核。

## 2. 形式化定义（要点版）

**定义 293（总览与三不变式）** 解析锚定（学习模型不得写 π，π 只在漂移预算内、经可辨识检验更新）；解释权限（权限是联赛后验与裁判的单调函数，歧义只收紧）；激励安全（主动机动先过安全壳，否决则信息增益记 0 并保守）。

**定义 294（KAC）** `r^K = log(f(q̂,π̂)^{-1} x̂) ∈ ℝ^6`；多链补 `r_loop = log(f_1(q)^{-1} f_2(q))`，轮式补 `r_nh = v_y`。解析、无学习参数。

**定义 295（RSA）** `r ≈ Jδq + Yδπ + ε`；`r = r_J + r_π + r_⊥`；`w = P_⊥ r`；`κ_id = σ_min(W^{1/2}A_N)/√N`；`C_π(τ) = {Yδπ: ‖δπ‖_{Σ^{-1}}≤τ}`；`L = ‖P_A f‖/‖f‖`。

**定义 296（观测等价类 / 歧义）** `E_h = {θ_h: A_Nθ_h=r}`；`E_h∩E_{h'}≠∅` 即不可区分；`U_amb` 为联赛后验有效熵；不可判定不硬判，报 `UNDECIDABLE` 并收紧。

**定义 297（EL）** `S_h(t)=Σ_{s≤t} γ^{t-s}[log p_h(r_s|q_s,D_{<s}) − λ_MDL·c(h)]`；Elo/Glicko 更新 `R_h`；`α_h=softmax_β(R_h)`；冠军 `argmax R_h`。

**定义 298（KBP）** 漂移预算 `Π_drift(t)`；让分税 `c(h_cal)=½‖δπ‖²_{Σ^{-1}} + MDL(π)`；超预算一票判故障。

**定义 299（QGA）** `ξ* = argmax_{ξ∈Ξ_safe}[I(H;r(ξ)) + λ_disc·min_{h≠h'}D(h,h';ξ)]`；零空间自运动 `δx=Jδq=0` 而 `Yδπ≠0`，安全持续激励。

**定义 300（REF）** 闭环 `‖log(f_1^{-1}f_2)‖≤ε_loop`；刚体距离守恒；非完整 `v_y≈0`；接触锥/无穿透/支撑多边形；违反即犯规、取消吸收权。

**定义 301（AUF）** `λ=max(λ_RAS,λ_floor,g_fault(Σp_bad),g_foul)`；`k=min(k_RAS,k_max(1−Σp_bad),k_cal(κ_id))`；`ω_absorb=ω_cal·1[κ_id≥κ_min ∧ REF=PASS ∧ h_cal=champion]`。

**定义 302（红队/自博弈）** `φ*=argmax_φ H(H|D,ξ(φ))`，物理可实现且不越安全壳；新场景加入资格赛课程，自动刷新 canary。

**定义 303（奇异掩蔽）** `μ(q)=√det(JJ^T)`，可观测椭球 `O(q)={Jδq}`；近奇异证据按 μ 降权，QGA 默认避奇异，EL 分域评级。

**定义 304（多链/多机共识）** 每条链独立锚点 + 跨链/跨机闭环；单通道故障无法同时满足所有闭环，可定位到链/机；鲁棒聚合防他机欺骗。

**定义 305（AIC-K）** `ℰ_KART=ℰ_CALM×ℰ_kin×ℰ_league×ℰ_probe`；ℰ_kin={参数漂移,编码器偏置,链失配,奇异掩蔽,柔性变形}；ℰ_league={竞技场过拟合,冠军博弈,红队合谋,非平稳评分,Elo 漂移}；ℰ_probe={危险激励,激励磨损,接触扰动,探测诱发故障}。

**定义 306（J_KART）** Valid ⇔ Valid(J_CALM) ∧ (κ_id≥κ_min ∨ U_amb 显式标记) ∧ REF=PASS ∧ 探测安全 ∧ 红线未越界。

**定义 307（管线）** 离线解析建模 + 出厂资格赛辨识 π → 预训五选手；在线每周期 KAC/RSA/REF/EL，每 T_league 更新评级与权限，每 T_cert 跑 QGA→CAC-K→原子换装。

**定义 308（安全-信息两难）** `R_probe(ξ)` 与 `I(ξ)`；若 `I*=max_{Ξ_safe}I=0`，则 U_amb 不变、ω_absorb=0、权限取保守下界，显式报告「不可辨识」。

**定义 309（向后兼容）** 单链无冗余无激励 ⇒ κ_id→0 ⇒ ω_absorb=0，严格关闭 R68 吸收通道，退化为比 CALM 更保守的安全子集；κ_id 高且 cal 夺冠时恢复 CALM 收益。**默认更保守，证据充分才解锁。**

**定义 310（不可判定边界）** 同时满足 (a) ‖r_⊥‖ 在噪声界内、(b) 等效参数位移在漂移预算内、(c) 所有可达安全构型上等价类不空 ⇒ 运动学不可判定；输出 {cal, fault, UNDECIDABLE} 及 U_amb，UNDECIDABLE 一律保守。

# IP-253/254 KAC + RSA：解析锚点与正交子空间分解
class KinematicAnchorAnalyzer:
    def residual(self, q_hat, x_hat, pi_hat):
        r_ee   = logSE3(inv(self.f(q_hat, pi_hat)) @ x_hat)
        r_loop = [logSE3(inv(fi(q_hat)) @ fj(q_hat)) for fi, fj in self.chains]
        return vstack([r_ee] + r_loop)

    def decompose(self, r, q, window):
        A = stack_regressor(self.f, q, window)          # [J | Y]
        P_A, P_perp = projector(A)
        return {'r_pi': P_A @ r, 'w': P_perp @ r,
                'kappa_id': smin(whiten(A)) / sqrt(len(window)),
                'leak': norm(P_A @ r) / max(norm(r), 1e-9)}

# IP-255/298 EL：让分税 + 漂移预算的解释联赛
class ExplanationLeague:
    def update(self, r_next, q_next, ctx, pi_move):
        scores = {k: c.logpdf(r_next, q_next, ctx)
                     - self.lam * c.complexity(pi_move)
                  for k, c in self.h.items()}
        for k in self.h:
            self.S[k] = self.gamma * self.S[k] + scores[k]
        self.elo_update(scores)
        return self.posterior(), self.champion()

    def admissible_cal(self, kappa_id, referee_pass, pi_move, drift_budget):
        return (self.champion() == 'cal' and kappa_id >= KAPPA_MIN
                and referee_pass and norm(pi_move) <= drift_budget)

# IP-256 QGA：安全资格赛（零空间自运动是核心）
def design_gauntlet(anchor, league, safety_shell, horizon=8):
    best = max(((xi, smin(whiten(stack_regressor(anchor.f, xi.q, xi.window)))
                   + LAMBDA_DISC * min_pairwise_divergence(league))
                for xi in map(safety_shell.project,
                              candidate_maneuvers(safety_shell, horizon))
                if xi is not None), key=lambda t: t[1], default=(None, -np.inf))
    return best[0] if safety_shell.info_gain(best[0]) > 0 else None

# IP-300 REF：硬不变量裁判
def referee(T_ref, dec, q, contact, model):
    fouls = []
    if norm(dec['loop']) > EPS_LOOP:              fouls.append('loop_closure')
    if not friction_cone_ok(contact):             fouls.append('contact_cone')
    if not rigid_distance_ok(T_ref, model):       fouls.append('rigidity')
    if abs(lateral_slip(q, model)) > EPS_SLIP:    fouls.append('nonholonomic')
    return {'pass': not fouls, 'fouls': fouls}

# IP-258 AUF：权限跟随联赛名次 + 裁判
def authority(league, rsa, ref, cal):
    post  = league.posterior()
    p_bad = post['sens'] + post['world'] + post['model']
    lam   = max(LAM_RAS, LAM_FLOOR, lam_from_bad(p_bad),
                0.98 if not ref['pass'] else 0.6)
    k     = min(K_RAS, int(K_MAX * (1 - p_bad)), k_from_kappa(rsa['kappa_id']))
    w_abs = OMEGA_CAL if league.admissible_cal(
                rsa['kappa_id'], ref['pass'], cal['pi_move'], cal['budget']) else 0.0
    return {'lambda': lam, 'k': k, 'omega_absorb': w_abs, 'U_amb': entropy(post)}

# IP-262 主闭环
def KART_RAS_round(M, obs):
    x_prime = M.lsf.fuse(M.usr.fuse(*obs[:4]))
    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)
    rK  = M.kac.residual(M.q_hat, x_prime.pose, M.pi_hat)
    dec = M.rsa.decompose(rK, M.q_hat, M.window)
    ref = referee(M.T_ref, dec, M.q_hat, M.contact, M.kac.f)
    post, champ = M.el.update(dec, M.q_hat, M.ctx, M.cal.delta_pi)
    c, U, thr = M.cof.step(o['cal'], rK, sigma_stat(M))          # R68 继承
    joint_post = M.cfa(rK, o['pi'], c, U)
    auth = authority(M.el, dec, ref, M.cal)
    lam  = max(M.efs.risk_scale(joint_post), auth['lambda'],
               0.8 if (o['qual']['face'] < 0.8 or U > TAU_CAL) else 0.6)
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = min(auth['k'], M.c_ras_wm.certified_prefix(
                A, joint_post, min(M.vista.m, M.m_emo), M.alpha_chunk))
    tau = emotion_response_shaping_wm(
        M.pi_sigma.prefix_dispatch(A[:k]) * lam, joint_post, M.wm_preds)
    xi = design_gauntlet(M.kac, M.el, M.safety_shell) if M.time_to_cert else None
    M.cac_k.maybe_commit(M.shadow, M.time_since_commit, xi, dec, ref)
    M.vqa_k.submit_async({'xi': xi, 'kart': (dec, post, auth)})
    return k, lam, joint_post, (c, U), auth

## 4. 推导

**引理 16（零空间见证的标定免疫性）** `r=Aθ+ε` ⇒ `r_⊥=P_⊥ε`，H_cal 下 `‖r_⊥‖≤ε_max`；含故障 f 时 `‖r_⊥‖≥‖P_⊥f‖−ε_max`。阈值 `τ_w=2ε_max`：H_cal 零误报，`‖P_⊥f‖≥3ε_max` 必检；随机情形用自由度 `6N−rk(A)` 的 χ² 检验，非中心参数 `‖P_⊥f‖²/σ²`。**故障见证对任何关节/标定解释免疫。**

**引理 17（可辨识缺口与双重逃逸封堵）** 分解 `f=f_A+f_⊥`：标定最多吸收 `f_A`（需参数位移 `δπ=Y^+f_A`），残余 `‖f_⊥‖`。缓变故障只有两条逃逸路径：零空间逃逸（要求全构型 `f(q)≈Y(q)δπ`，极强结构约束）与预算逃逸（`‖δπ‖≤B_drift`）。两条都封住 ⇒ 必检出或必否决；两条都满足 ⇒ 运动学不可分，报 UNDECIDABLE。检测非中心参数 `N(1−ρ_f²)‖f‖²/σ²`，`ρ_f=cos∠(f,range(A_N))`。**系：标定越可辨识，故障越难伪装，与 R68 直觉相反。**

**引理 18（反吸收界与「歧义→保守」转换）** `v_f>v_drift+margin/T` ⇒ 参数位移终将越出 Π_drift，接受 H_cal 概率 ≤ `exp(−T·I_budget)`；`v_f≤v_drift` 且落在 range(A_N) ⇒ 不可判定，U_amb 升高、ω_absorb=0、λ 抬升。**R68 的「缓变故障→误判标定→错误放宽」被转换为「缓变故障→显式歧义→保守性能损失」：安全失败变性能代价，而非相反。**

**引理 19（联赛 properness 与 regret）** 对数分数是严格 proper scoring rule；真实假设 h*∈H 时 `E[S_{h*}]` 唯一最大。指数权重遗憾 ≤ `log|H|/η`；折扣 γ 的稳态超额风险 ≤ `O(1/(1−γ))`×单步误差；MDL 让分等价参数先验。**系：H 覆盖真值且竞技场代表真实工况时，联赛不系统偏向错误解释；misspecification/分布偏移时保证失效（定理 17 与风险来源）。**

**引理 20（权限单调性）** λ 对 `p_bad` 与犯规数单调不减；k 对 `p_bad` 单调不增；ω_absorb 对 κ_id、裁判通过、cal 冠军单调不减。任何「故障/世界/歧义/犯规增加」都不提高放行度。**系：R66 face_unobservable、R67 wm_drift、R68 U(ĉ)、R69 U_amb 统一为同一条「只收紧」纪律。**

**定理 16（端到端风险一致性）** A87–A94 + A95（v_drift 界）/A96（次高斯噪声）/A97（选手覆盖）下：
1. `P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+α_kin+α_league`，`α_kin ≤ exp(−N·I_kin) + 1[不可判定]·1`（后者转保守）；
2. `κ_id<κ_min ∨ 犯规 ⇒ ω_absorb=0`，退化为不弱于 R68 的保守子集（定义 309）；
3. 不可判定 ⇒ `λ≥λ_floor ∧ k≤k_cal ∧ ω_absorb=0`；
4. 主动资格赛只在 Ξ_safe 内，故不引入额外越界违规（定理 17）。

**定理 17（安全-辨识 Pareto 与零空间激励）** Fano/Chernoff 型：`P_err ≥ H(H|D)/log|H|`，信息增益 I(ξ) 越大下界可压越低；`I*=max_{Ξ_safe}I`，`I*=0` ⇒ U_amb 不变、权限最小。冗余机器人（n>dim task）存在 `ξ_null` 使 `δx=Jδq=0` 而 `Yδπ≠0`，故 `I(ξ_null)>0`、风险仅来自关节运动/磨损——**安全与可辨识在零空间不冲突**；安全壳冻结所有激励时接受不可判定，绝不假装辨识。

## 7. 本轮最大风险

**一句话**：KART-RAS 把控制权限交给「解释联赛」的冠军，等于把安全押在「**冠军是在预测世界，而不是在拟合竞技场**」这一个假设上；一旦真实故障不在选手库/资格赛分布覆盖内（或红蓝共同演化出盲区），联赛会稳定选出一个在竞技场上最会预测、却在世界中最错的解释，而 AUF 会让它获得最大的标定吸收权——**越擅长赢得比赛，越危险**（Goodhart / performative risk）。

**次级风险与缓解**：
1. 安全-信息两难（激励诱发磨损/接触扰动）→ 安全壳投影 + 零空间自运动 + 风险预算 R_probe；宁可 UNDECIDABLE 也不危险探测；
2. 锚点标定悖论（π 也需初始标定且会漂移）→ 出厂计量溯源 + 漂移预算 + π 纳入 J_KART 版本链，不把 π 当绝对真值；
3. 竞技场过拟合/红蓝共谋盲区 → 独立第三方 benchmark + 分布外挑战集 + U_amb 强制上报，不允许用高置信冠军掩盖覆盖缺口；
4. 奇异掩蔽 → μ(q) 证据降权 + 资格赛避奇异 + 证书记录奇异暴露；
5. Elo/评分非平稳漂移 → 折扣 + 滑窗 + 定期重赛 + Glicko RD 进入权限映射；
6. 多机对抗性欺骗 → 跨机鲁棒聚合（中位数/截尾）+ 裁判独立复核。
