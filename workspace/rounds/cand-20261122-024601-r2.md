# 第 2 轮（新灵感循环第 2 轮；本轮灵感：「演示数据」×「持续学习」；基线 v20）

> **基线**：第 1 轮/上一循环产出 MetricVoiceGauge-NCD-HUTDH-v20 + IP-420–424（PCA/CTS/CFC/HPC/CFCtrl）。
> 本轮纪律：**演示是安全证言，不是行为模板；持续学习是不遗忘危险，而非记住一切**。不推倒 v20：PCA/CTS/CFC/HPC/CFCtrl 与 v19 的 DCM/OGCC/CCV/DRS/OGC、v17 的 CLP/S2C/HCG/PSV/APS/AMC 全部保留。本轮只做一件事：**把人类演示轨迹中的"通过间隙"转化为可证明的安全球，并让证书在时间流中安全生长而不发生灾难性遗忘**。

## 0. 直觉与动机

**灵感 1（演示数据 → 演示是"安全证言"，不是"行为模板"）**
直觉：一条人类演示轨迹，是"人把机器人带过一段路且没撞"的时间序列。常规做法把它当行为克隆的训练集，学"人怎么动"。但对碰撞证书而言，真正有价值的是每个时刻的**剩余间隙**：人在 θ_t 时离障碍还有 φ_t。若间隙函数对参数足够光滑（Lipschitz），那么 θ_t 周围一个半径与 φ_t 成正比的球都必然安全。**从容的演示认证一个球，贴着障碍的演示认证几乎为零（近失不产证言）**。关键反直觉点：**演示不是越多越好、越像越好，而是"越有余量越能作证"**——我们把演示当**正证据**开采，而不是当**策略**模仿；并且**绝不在两球之间的空隙做插值**，因为安全集非凸，插值会穿过障碍。

严谨化：令有符号间隙 `φ(n,o,θ)`（SDF，φ>0 为安全），在度量 d 下满足 `|φ(θ)-φ(θ')| ≤ L·d(θ,θ')`。用标定集得到保守上界 `L_hi ≥ L`。演示点 `(θ_t, φ_t)` 认证球 `B_t = {θ : d(θ,θ_t) < φ_t / L_hi}`，则可证 `B_t ⊆ {φ>0}`。演示证书域 `Θ_demo = ∪_t B_t` 是真实安全集的**可靠下近似**。

**灵感 2（持续学习 → 证书的灾难性遗忘是"忘记危险"，不是"忘记技能"）**
直觉：随着新物体、新演示、新感知不断到来，证书必须更新。朴素覆盖会把一条旧 UNSAFE 区域改写成 SAFE——这就是"**证书的灾难性遗忘**"，后果是真实的碰撞。反过来，忘掉一片已知安全区只是损失活性，不致命。于是确立**非对称遗忘**：危险的记忆永久冻结（除非出现更高保真的反证），安全的记忆可以弹性收缩甚至丢弃。关键反直觉点：**好的持续学习不是"记住一切"，而是"只记危险、其余可忘"**——记忆容量与计算都花在安全临界面上，而不是均匀地记住所有安全。

严谨化：证书记忆 `M = {(R, ℓ, conf, prov, λ, last_verified)}`，`ℓ ∈ {SAFE, UNSAFE}`。定义**虚假遗忘** `FF`（旧 UNSAFE 体积被新证书改成非 UNSAFE 的比例）与**保守遗忘** `CF`（旧 SAFE 体积被收缩/丢弃的比例）。更新算子硬约束 `FF = 0`，软约束 `CF ≤ budget_cf`。巩固权重 `λ(R)` 对 UNSAFE 取 `λ_max`；对 SAFE 取 `λ_max·(1 - margin(R)/margin_max)`（薄边高巩固、胖边低巩固），对应 EWC 式正则 `L = L_new + Σ_i (λ_i/2)(w_i - w_i*)²`，但作用在**证书边界参数**而非模型权重。

**灵感 3（二者如何统一 → 证据侧 × 时间侧）**
DCS（演示证书播种器）是**证据侧**：把演示开采为带证明的安全球，回答"这个安全域凭什么可信"。CCL（证书持续学习）是**时间侧**：把证书记忆在流式更新下维护，回答"旧结论会不会被新数据错误抹掉"。SCC（安全临界巩固）是**塑性侧**：回答"哪些边界能动、哪些必须冻住"。Forgetting Guard 是**审计侧**：回答"这次更新是否悄悄忘了危险"。Ledger 是**谱系侧**：回答"每次更新能否被机械复核"。

统一为 **v20 证书体系之上的证据—时间层**：v20 回答"给定当前几何与分布式感知，节点 n 在 θ 下是否零碰撞"；v21 回答"这些安全结论中，哪些有演示级证明、哪些必须在时间流中被永久保留"。共享状态 `ζ_cont = (demo_anchors, cert_memory, L_hi, λ_weights, forgetting_ledger, replay_coreset, mode_cont)`。统一接口：**若某 θ 被演示球或 v20 证书可靠认证，且不与 UNSAFE 记忆冲突，则判 SAFE；若证据冲突或校准失效，则退回 v20 的保守收缩；若 CCL 关闭，则等价 v20 快照。**

## 1. 研究问题（轮次升级版）

- **Q1（演示证言的可靠性）**：如何从有限的扰动标定数据得到**保守的** `L_hi`，使演示球绝不越界？如何在 v20 的 UNSAFE 记忆与演示球冲突时，坚持"危险优先"并给出可审计的冲突裁决？近失演示、跨物体演示、跨本体演示应如何被识别并拒绝？

- **Q2（非对称遗忘的强制）**：如何在流式、含噪、可能过时的更新下**机器可验证地保证 FF=0**？当反证（更高保真 SDF）确实推翻了旧 UNSAFE 时，如何安全地"解冻"并留下完整证据链？CF 预算如何随活性需求自适应？

- **Q3（回放与巩固的选样）**：如何选取回放 coreset（landmark 演示）使其覆盖证书安全临界面的 ε-网，从而以最小内存抑制遗忘？巩固权重 λ 如何同时依赖间隙、访问频次与来源可信度？EWC 式正则与"只收缩"硬约束如何叠加而不冲突？

- **Q4（时效与物体漂移）**：演示证书基于某一时刻的 φ，若物体磨损/变形（对应 v20 CTS 的谱系失效），旧球如何被及时作废？演示证书的 TTL 如何与 v20 的 APS/CFCtrl 新鲜度阶梯耦合，使"未复核的旧球"自动降级为 v20 保守路径？

## 2. 设计原则（在 P31–P33 基础上新增 P34–P36）

**P34 演示证言律（Demonstration Witness Law）**
演示点 `(θ_t, φ_t, o_t)` 仅在 `φ_t > δ_min` 时认证球 `B_t = B(θ_t, φ_t / L_hi)`，且 `radius(B_t) ≤ r_max`。**绝不在球间空隙插值**（安全集非凸）；`φ_t ≤ δ_min` 的近失演示认证空集。每个球必须携带证明对象 `(θ_t, φ_t, L_hi, calib_version, provenance)`。**演示只能在其证言球内授权，不能外推**。

**P35 非对称遗忘律（Asymmetric Forgetting Law）**
证书更新算子 `U(M, E) → M'` 必须满足：
1. **危险不可删**：若 `R` 在 M 中标为 UNSAFE 且无 `counter_witness`，则 `M'` 中不得存在任何 θ∈R 被标为 SAFE（即 `FF = 0`）；
2. **安全可弹性**：SAFE 区域可被收缩或丢弃，但 `CF ≤ budget_cf`，且每次收缩/丢弃记入账本；
3. **解冻需反证**：UNSAFE 只能在 `counter_witness`（更高保真 SDF 复核 + 双源确认）下解冻，并永久留痕。
巩固权重 `λ(UNSAFE)=λ_max`，`λ(SAFE)=λ_max·(1-margin/margin_max)`。

**P36 可证明扩张律（Provable Expansion Law）**
v21 **允许**在 v20 安全域之外扩张，但每一次扩张都必须携带可靠证明：或为演示球 `B_t`（引理 157），或为 v20 CCV/PCA 的重新验证。扩张候选必须通过 `B_t ∩ UNSAFE_Memory = ∅` 与球心 CCV 复核；任一失败则收缩或拒绝。**没有证明对象的安全断言一律不允许进入执行集**。由此本轮的纪律从"只收缩"升级为"**收缩，或带着证明扩张**"，安全链变为 `Exec_v20 ⊆ Exec_v21 ⊆ TrueSafe`（条件于 `L_hi` 可靠），而非 `Exec_v21 ⊆ Exec_v20`。

## 3. 与基线的接口（如何退化）

- DCS 失效（无演示/演示全部近失/校准失败）⇒ `Θ_demo = ∅` ⇒ 等价 v20；
- CCL 失效（无法维护记忆）⇒ 使用 v20 的静态证书快照 ⇒ 等价 v20（无持续增益，也无额外风险）；
- SCC/Guard 失效 ⇒ 禁止一切非收缩更新 ⇒ 等价 v20 的保守收缩；
- 三者全失效 ⇒ 完全回退 v20 的 PCA/CTS/CFC/CCV 路径；
- **安全链**：`Exec_v21 ⊆ TrueSafe`（条件于 `L_hi ≥ L_true` 与 v20 域可靠）；无演示时 `Exec_v21 = Exec_v20`。注意本轮**刻意放宽**了"只收缩"纪律：`Exec_v21` 可能真包含 v20，但每个新增点都携带 Lipschitz 证明对象，因此仍是**有条件的可靠扩张**，而非无据外推。

## 4. 预期贡献

1. **演示即证言**：首次把演示数据从"行为克隆训练集"改写为"带 Lipschitz 证明的安全球集合"，使演示在不模仿策略的前提下直接为碰撞证书提供**可证明的**安全覆盖；
2. **非对称持续学习**：提出"只记危险、安全可忘"的证书持续学习范式，给出 FF=0 的机器可验证强制机制与 CF 预算，避免灾难性遗忘在安全系统中的致命后果；
3. **安全临界巩固**：把 EWC 式正则搬到证书边界参数上，使塑性集中在胖边、刚性集中在薄边与 UNSAFE 邻域；
4. **可证明扩张**：给出从"只收缩"到"收缩或带证扩张"的纪律升级，并显式暴露其唯一依赖——Lipschitz 上界的可靠性；
5. **证据谱系账本**：用 Merkle 谱系链把每次演示认证、每次更新、每次解冻串成可机械复核的审计轨迹，接续 v20 的 HPC 证明体系。

## 5. 本轮最大风险

**一句话**：本轮全部可靠扩张都条件于校准得到的 Lipschitz 上界 `L_hi`；若演示来自**不同本体/不同标定**或间隙场存在系统性偏差，使 `L_hi` **低估**了真实敏感度，则演示球会系统性偏大，而持续学习又会用回放与"安全可弹性"把这类**不可靠的球反复重新认证并固化**，最终形成"**证据固化、越学越自信的安全幻觉**"——形式上每步都有证明、账本完整，实际上证书在稳定地远离真实安全集。

```python
# IP-425 Demonstration Certificate Seeder
class DemonstrationCertificateSeeder:
    def __init__(self, sdf, lipschitz_hi, r_max=0.05, min_clearance=0.005):
        self.sdf = sdf
        self.L_hi = lipschitz_hi        # 标定上界，L_hi >= L_true
        self.r_max = r_max
        self.min_clearance = min_clearance
        self.calib_version = None

    def calibrate_lipschitz(self, calib_pairs, safety_factor=1.25):
        """calib_pairs: [(theta, theta', dphi, d)]，返回保守上界"""
        ratios = [abs(dphi) / max(d, 1e-9) for (_, _, dphi, d) in calib_pairs]
        self.L_hi = safety_factor * max(ratios)
        self.calib_version = hash(tuple(calib_pairs))
        return self.L_hi

    def mine(self, demo, node, obj):
        """演示轨迹 -> 带证明的安全球；只接受同节点/同物体"""
        balls = []
        for theta_t, phi_t, o_t in demo.samples:
            if o_t != obj:
                continue                       # 跨物体留给 v20 CTS，不在本轮外推
            if phi_t <= self.min_clearance:
                continue                       # 近失演示不产证言
            r = min(self.r_max, phi_t / self.L_hi)
            balls.append(CertBall(
                center=theta_t, radius=r, clearance=phi_t,
                L_hi=self.L_hi, calib_version=self.calib_version,
                provenance=demo.id))
        return DemoCertificate(balls=balls, L_hi=self.L_hi,
                               calib_version=self.calib_version)

    def admit(self, demo_cert, unsafe_memory, ccv):
        """与 UNSAFE 记忆冲突时危险优先；球心 CCV 复核防投毒/漂移"""
        admitted = []
        for b in demo_cert.balls:
            if b.intersects(unsafe_memory):
                b = b.shrink_to_avoid(unsafe_memory)
                if b is None:
                    continue                   # 收缩到空则拒绝
            if not ccv.verify(b.center):
                continue                       # 中心点复核失败 -> 拒绝
            admitted.append(b)
        return admitted


# IP-426 Certificate Continual Learning
class CertificateContinualLearning:
    def __init__(self, scc, guard, replay, budget_cf=0.02):
        self.scc = scc
        self.guard = guard
        self.replay = replay
        self.budget_cf = budget_cf
        self.memory = CertificateMemory()

    def update(self, new_evidence, node):
        """流式更新：只收缩 SAFE，绝不无证扩入 UNSAFE"""
        candidate = self.memory.clone()
        candidate.apply(new_evidence)          # 硬规则：收缩 / 有证扩张

        # 1) 非对称：旧 UNSAFE 不得被遗忘（除非有反证）
        if not self.scc.preserves_unsafe(self.memory, candidate):
            return self.memory, "REJECT_UNSAFE_FORGOTTEN"

        # 2) 遗忘守卫：在回放集 + 验证网格上审计
        ff, cf = self.guard.audit(self.memory, candidate, self.replay)
        if ff > 0.0:
            return self.memory, "REJECT_FALSE_FORGETTING"
        if cf > self.budget_cf:
            return self.memory, "NEED_REVIEW"

        # 3) 提交并记账
        self.memory = candidate
        return self.memory, "OK"


# IP-427 Safety-Critical Consolidation
class SafetyCriticalConsolidation:
    def __init__(self, lambda_max=1.0, margin_max=0.1):
        self.lambda_max = lambda_max
        self.margin_max = margin_max

    def weight(self, region):
        if region.label == "UNSAFE":
            return self.lambda_max                     # 危险永久高权重
        m = min(region.margin, self.margin_max)
        return self.lambda_max * (1.0 - m / self.margin_max)  # 薄边高巩固

    def ewc_loss(self, new_loss, boundary_params, anchor_params):
        """EWC 式：证书边界参数向锚点收敛，权重来自 λ(R)"""
        reg = 0.0
        for w, w0, lam in zip(boundary_params, anchor_params,
                              self.weights_by_index()):
            reg += 0.5 * lam * (w - w0) ** 2
        return new_loss + reg

    def preserves_unsafe(self, old, new):
        for r in old.unsafe_regions():
            if r.counter_witness is None and not new.is_unsafe(r):
                return False
        return True


# IP-428 Forgetting Guard
class ForgettingGuard:
    def __init__(self, resolution, replay_set):
        self.resolution = resolution
        self.replay_set = replay_set

    def audit(self, old, new, replay):
        """在回放集 + 验证网格上估算 FF/CF"""
        ff, cf = 0.0, 0.0
        for theta in self.validation_points(replay):
            lo, ln = old.label(theta), new.label(theta)
            w = self.volume_weight(theta)
            if lo == "UNSAFE" and ln != "UNSAFE":
                ff += w                      # 忘了危险
            elif lo == "SAFE" and ln != "SAFE":
                cf += w                      # 保守遗忘
        return ff, cf

    def validation_points(self, replay):
        pts = list(self.grid_points(self.resolution))
        pts += [b.center for b in replay.balls]   # 回放 landmark 强制覆盖
        return pts

    def volume_weight(self, theta):
        return self.resolution ** len(theta)

            calib_version=calib_version)
        self.entries.append(entry)
        self.root = merkle_hash(self.root, update_hash,
                                audit.ff, audit.cf, audit.mode)
        return self.root

    def verify_lineage(self, expected_root):
        """从 genesis 重放所有条目，校验 root 与 calib 版本链"""
        root = GENESIS_ROOT
        for e in self.entries:
            root = merkle_hash(root, e.update_hash, e.ff, e.cf, e.mode)
        return root == expected_root
```

## 2. 推导

**引理 157（演示球可靠性）** 设 `L_hi ≥ L_true`，且演示点满足 `|φ(θ)-φ(θ_t)| ≤ L_true·d(θ,θ_t)`。则对任意 `θ ∈ B_t = {θ : d(θ,θ_t) < φ_t/L_hi}`：
`φ(θ) ≥ φ_t - L_true·d(θ,θ_t) > φ_t - L_true·(φ_t/L_hi) = φ_t(1 - L_true/L_hi) ≥ 0`。
故 `B_t ⊆ {φ>0} = TrueSafe`。∎ 推论：近失（φ_t→0）球半径→0，不产生虚假覆盖。

**引理 158（并集不产生假安全）** `Θ_safe^v21 = Θ_safe^v20 ∪ (∪_{admitted} B_t)`。由 v20 的域可靠性（引理 151–156）与引理 157，每个被接纳的球与 v20 域都 ⊆ TrueSafe；admit 又强制 `B_t ∩ UNSAFE_Memory = ∅` 且球心 CCV 复核，故并集 ⊆ TrueSafe。∎

**引理 159（非对称遗忘）** 更新算子 `U` 在 `preserves_unsafe` 失败或 `FF>0` 时返回旧记忆，故提交后的 `M'` 满足：任意无 `counter_witness` 的旧 UNSAFE 区域仍为 UNSAFE，即 `FF = 0`。UNSAFE 标签在无更强反证下单调保持。CF 由预算截断。∎

**引理 160（持续更新的逐轮安全性）** 每次 `U` 只有两类改动：收缩（SAFE→更小 SAFE 或 UNSAFE）与带证扩张（引理 157/158 的球）。收缩不会引入假安全；带证扩张逐球可证。故任意一轮提交后 `Θ_safe ⊆ TrueSafe`。回放 coreset 的作用是**防遗忘**（保证 FF 可被检出），而非放行扩张。∎

**引理 161（v21 条件安全与退化）** 若 `L_hi ≥ L_true` 且标定有效，则 `Exec_v21 ⊆ TrueSafe`；若无演示或 CCL 关闭，则 `Θ_safe^v21 = Θ_safe^v20`，`Exec_v21 = Exec_v20`。注意：本轮允许**有证扩张**，故一般 `Exec_v20 ⊆ Exec_v21 ⊆ TrueSafe`，而**非** `Exec_v21 ⊆ Exec_v20`——这是相对前几轮"只收缩"纪律的显式升级，其代价是把可靠性完全押在 `L_hi` 上。∎

**引理 162（谱系可审计）** Ledger 的 `root` 由 `(prev_root, update_hash, FF, CF, mode, calib_version)` 逐轮哈希得到，任何认证/更新/解冻都被记录。独立验证器可从 genesis 重放并核对 `expected_root`，故证书的每一次演化可机械复核。∎

## 6. 已知风险与失效模式

1. **Lipschitz 低估（首要）**：`L_hi` 若低于真实敏感度，演示球会越界；这是本轮全部可靠扩张的唯一依赖。缓解：多扰动标定、safety_factor、`r_max` 上限、留出集零假安全准入。
2. **跨本体/跨标定演示污染**：演示若来自不同本体或不同传感器标定，间隙场不可迁移，球不可靠。缓解：绑定 embodiment/calib 指纹，异本体一律拒绝（不借 v20 CTS 外推）。
3. **物体漂移导致旧球过时**：磨损/变形使旧 φ 失效，旧球变成假安全。缓解：TTL + calib_version 失效 + v20 CTS 谱系变更触发重认证。
4. **验证网格漏检薄危险片**：FG 在离散网格上审计，可能漏掉细长 UNSAFE 区。缓解：临界面临近加密采样、回放 landmark 强制覆盖、解析边界审计。
5. **回放 coreset 偏差**：coreset 若遗漏危险邻域，遗忘检测会漏报。缓解：危险邻域强制入 coreset、k-center + 风险加权。
6. **投毒演示**：恶意大间隙演示可注入假球。缓解：球心 CCV 复核、来源签名、与 v20 CFC 的拜占庭过滤联动。
7. **过度保守导致活性塌陷**：`L_hi` 取过大或 `r_max` 过小，演示球趋零，v21 退化且无增益。缓解：分层 r_max、按物体尺度自适应。

## 7. 本轮最大风险

**一句话**：本轮把全部可靠扩张押在校准得到的 Lipschitz 上界 `L_hi` 上；一旦演示来自不同本体/不同标定或间隙场存在系统性偏差使 `L_hi` **低估**，演示球会系统性偏大，而持续学习又通过回放与"安全可弹性"把这些**不可靠的球反复重新认证并固化**，最终形成"每步都有证明、账本完整、越学越自信"的**证据固化型安全幻觉**——证书在形式上完美可审计，实际上却在稳定地远离真实安全集。
