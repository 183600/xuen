# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互的不确定性二分闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「任务规划」×「上下文理解」）

> R69 给系统装上了一张嘴（主动问）和一只鼻子（流似然第二意见），并把不确定性一分为二。但它仍默认两件从未被检验的事：
>
> 1. **决策是一次性的、无计划的。** R69 每一步都问「这个动作该选哪个模态」，却从不问「这个不确定性会不会改变**整条计划**」。于是一方面把预算花在**改了也不影响计划**的歧义上（虚荣消歧），另一方面漏掉**一改就重排整条任务**的事实（致命盲区）。VoI 被定义成熵的下降，而不是计划代价的下降——这是 R69 最贵的一处错配。
> 2. **上下文只是一帧 z_t。** R69 的「上下文」是编码器输出，是一个快照，没有出处、没有有效期、没有「人我共同知道什么」。它可以在一条「前提早已悄悄失效」的计划里，执行一个被完美认证的动作——证书证明「这一步安全」，却没人证明「这条计划还站在地上」。
>
> 本轮两个灵感正好切开这两个盲点：
> - **任务规划**告诉我们：计划不是消歧之后的产物，而是消歧的**载体**。带前置条件/效果的算子图，天然给出「决策相关性」的严格定义——一个事实值不值得查，取决于它**会改变最优计划的多少代价**，而不取决于它有多模糊。
> - **上下文理解**告诉我们：上下文就是计划**脚下踩着的那组前提命题**，每一条都有出处、有效期和人我共同基础状态；理解上下文＝维护一个校准过的信念，并在「脚下的地动了」时察觉。
>
> 核心命题：**把「带条件的任务计划」当作决策单元，把「上下文」当作计划的前提假设；只消解对计划敏感（会改变最优计划）的不确定性（计划条件 VoI）；计划带有效期承诺，前提一旦失效就再接地（re-grounding）而非硬撑；当计划退化为单步时，整套机制逐指令退化为 R69。** 命名 **PACT-RAS**（Plan-Anchored Context Tracking：计划锚定的上下文跟踪）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我的计划究竟踩在哪些假设上，那块地还在吗**」——不确定性可以是刹车、是提问，也可以是把整条计划重新钉回地面。

## 0. 直觉与动机

**灵感 1（任务规划 → 计划是消歧的载体，不是消歧的产物）**
直觉：R69 的世界里，策略吐出一个动作块，消歧就是「在几个动作模态里挑一个」。但真实任务是有结构的：先找到杯子、确认它是空的、再决定倒水还是先清洗；每一步都挂着前提（杯子可抓、路径可达、人确实想喝咖啡）。同一个「杯子是不是空的」的不确定性，在某些计划里改了也白改（反正两条分支都要洗杯子），在另一些计划里一改就整条重排（直接倒 vs 先洗）。R69 按熵排优先级，会把这两者一视同仁；计划视角则给出一个干净的判据：**一个事实的信息价值＝消解它之后最优计划代价的期望下降**。这把 VoI 从「关于信念的」改成「关于决策的」，也是「任务规划」给本轮最锋利的一刀。
严格地说，计划是带前置/效果的算子图（HTN/PDDL 风格）；给定上下文信念 b，计划求解是一个在信念上的最优控制/最短路问题，其值函数 V(π|b) 就是「计划代价」。计划相关性不是模糊的直觉，而是 V 对某个事实的**有限差分灵敏度**。

**灵感 2（上下文理解 → 上下文是计划的前提，不是编码器的快照）**
直觉：人执行计划时，脑子里始终挂着一张「我在假设什么」的清单：门没锁、对方想让我把杯子放桌上、走廊能过人。这张清单会被**持续核对**：听到门锁咔哒、看到对方皱眉、撞上临时堆的箱子——任何一条被推翻，人不会「慢一点继续走」，而是**停下来改计划**。R69 缺的正是这张清单。上下文理解因此不是「再编码一帧」，而是维护一组**带出处、带有效期、带共同基础标记**的命题信念，并把它作为计划的前提假设来核对。
严格地说，上下文命题 C 是任务相关的地面化谓词（「杯子为空」「人想要咖啡」「门未锁」「通道可通行」）；每条有来源 s_i、时间戳、有效期 τ_i、共同基础位 κ_i、校准信念 b_i(t)。上下文理解的质量用 ECE_ctx 度量。

**灵感 3（两条灵感的乘积 → 计划条件 VoI 与「决策无关性剪枝」）**
直觉：把灵感 1 和 2 相乘，得到一个既省又准的机制：先算每条上下文事实对当前计划的灵敏度 σ_i，只对 σ_i 大的事实做消解/提问；σ_i≈0 的事实**明确允许不查**，且不因「不知道」而被 λ 惩罚。这与 R69「任何高熵模态都要么查要么收紧」形成鲜明对比：**不知道一件与决策无关的事，是安全的**。这一步同时把交互预算花在刀刃上，也缩小了攻击面（少问就少被骗）。
严格地说，在计划值函数 V 关于事实取值 L_V-Lipschitz 的假设下，只消解 σ_i>ε 的事实，相对全消解的期望计划代价损失 ≤ |C|·ε（引理 19）。于是「决策无关性剪枝」是可证明无损的（至 ε）。

**灵感 4（上下文会过期/漂移 → 承诺、再接地与计划级第二意见）**
直觉：计划一旦承诺就要执行一段，否则会抖；但上下文会漂移（人改主意、物体被移动、环境规则变化）。所以需要**承诺语义**：计划带有效期窗口，窗口内除非前提被证伪或继续执行的期望代价超过改计划的代价（含迟滞），否则不改。检测「地动了」有三条通道：(a) 感知与已承诺前提矛盾；(b) **执行效果与计划预测不符**（计划级残差）；(c) 人的陈述与前提矛盾。其中 (b) 尤其重要：它是 R69 流似然（动作级第二意见）在**计划级**的镜像——**动作可以很自然，但计划的效果预测在骗你**。这正是 R68「标定吸收」、R69「模态未校准」之后，同一类「安全层自欺」的第三次化身：这次是**计划层**。
严格地说，上下文漂移下执行到失效前提的概率 ≤ 漂移率 × 检测延迟；检测延迟由监测频率与效果残差可观测性界定，于是给出有效期窗口的设计规则 τ ≤ 安全裕度 / 漂移率（引理 21）。

**灵感 5（双刃剑 → 上下文投毒、共同基础操纵与本体缺口）**
直觉：一旦系统依赖「上下文」和「计划前提」，就有了新的攻击面。环境可以伪造前提（假门、贴错标签的物体、循环播放的旧场景），人可以操纵共同基础（「你早就知道我要 X 了」——其实机器人从不知道），更阴险的是**本体缺口**：真实的致命前提根本没被建模进 C（比如「梯子横杆承重」这条谓词压根不存在）。此时计划条件 VoI 在**错误的决策相关性结构**上计算，系统会自信地执行一条「真失败模式从未被表示」的计划。**计划越详细，遗漏越有说服力**——这是本轮必须正面交付的风险，而不是脚注。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（PACT-RAS 总览）** PACT-RAS = (PG, CCB, PSV, ARG, CRD, CGR, CGQ, PIC, RAS-WM††)。三不变式：
(i) **计划显式且可审计**：每个执行动作都能追溯到一条计划算子、一组前提假设及其有效期；无假设来源的动作不得执行。
(ii) **只消解决策相关的不确定性**：对灵敏度 σ_i ≤ ε 的事实，禁止发起交互/收紧（省预算、缩攻击面）；对 σ_i > ε 的事实，按计划条件 VoI 排序。
(iii) **承诺纪律**：计划带承诺视界 H_c 与迟滞 h；仅在前提失效或代价交叉时再接地；再接地必须过与任务动作相同的 C-RAS-WM 认证，且不得抬高安全包络。

**定义 311（带条件计划图 PG）** 计划 π = (V, E, pre, eff, cost) 为算子 DAG/HTN；每个算子 o ∈ V 有前提 pre(o) ⊆ C、效果 eff(o)、代价 cost(o)。上下文赋值 c ∈ {0,1}^{|C|} 下 π **可行** ⇔ 按拓扑序执行时每个 pre(o) 均满足（含前序效果）。信念 b_t 下的计划为 π_t = Plan(b_t)，可为名义计划或带监测前提的开放环骨架 + 修复策略。

**定义 312（上下文信念册 CCB）** 上下文命题集 C = {c_i}，每条带来源 s_i、时间戳、有效期 τ_i、共同基础位 κ_i ∈ {0,1}、校准信念 b_i(t) ∈ [0,1] 及联合/因子结构。上下文理解＝维护 b_t 与校准误差 ECE_ctx。命题按层级分：物体级 / 任务级（目标）/ 会话级（用户偏好）/ 世界级（环境规则），各自衰减率不同（定义 325）。

**定义 313（计划灵敏度与决策相关性）** 对事实 c_i 与当前计划 π_t，灵敏度 σ_i = |V(π_t | c_i=1) − V(π_t | c_i=0)| / C_scale，其中 V 为最优期望计划代价。决策相关集 D_ε = {i : σ_i > ε}；σ_i ≤ ε 者称**决策无关**，允许不消解且不施加 λ 惩罚。

**定义 314（计划条件 VoI）** VoI_π(g) = E[V(π_t | b_t) − V(π_t | b_t^{(g)})]，即执行信息动作 g 后最优计划代价的期望下降。选 g* = argmax_{g ∈ 𝒢(D_ε)} [VoI_π(g) − c(g)]，其中 𝒢(D_ε) 只含针对决策相关、且不在共同基础中的事实的合法信息动作。边界：计划视界=1 且 C=当前观测模态时，VoI_π 退化为 R69 的熵型 VoI（定理 18）。

**定义 315（假设集与有效期）** 每个已承诺算子 o 携带假设集 A(o) ⊆ C 与有效期窗口 [t, t+τ_o]。执行步 o **已接地** ⇔ 所有 A(o) 当前信念 > 1−δ。计划接地水平 G(π) = min_{o∈即将执行} P(∧_{c∈A(o)} c 成立)。

**定义 316（上下文漂移检测 ARG）** 三通道监测：(a) 感知与已承诺前提矛盾（b_i 跌破阈值）；(b) **执行效果残差**：观测到的 eff 与计划预测 eff 不符（计划级残差，对应 R69 动作级流似然）；(c) 人的陈述与前提矛盾。当「已承诺前提为假」的联合概率 > δ_shift 时触发**上下文漂移事件**。

**定义 317（承诺与再规划纪律 CRD）** 承诺视界 H_c；仅在 (i) 漂移事件触发，或 (ii) 继续执行的期望代价 > 再规划代价 + 迟滞 h 时再规划。单位时间再规划次数有上界；每次再规划必须过认证且不提高风险。

**定义 318（上下文接地再规划 CGR）** 修复＝对计划图做最小编辑（算子替换 / 插入上下文获取算子 / 重排）以最小代价恢复接地；用 D* 式增量搜索复用缓存骨架。预算内无解 ⇒ 退回**安全种子计划**（R69 保守路径）。

**定义 319（共同基础提问 CGQ）** 仅对人提问同时满足的事实：(a) 决策相关；(b) 不在共同基础 κ 中；(c) 人是可靠来源；(d) 答案会改变计划。问句＝针对某条上下文命题的定向探询；答案带出处更新 CCB，且须满足 k 个正交证据源一致的纪律方可承诺。

**定义 320（计划完整性证书 PIC / J_PACT）** J_PACT = (J_FLUID, plan_id/hash, assumption_set_hash, G_min, ECE_ctx, decision_relevant_resolved_ratio, replan_count, shift_events, validity_margin, ontology_coverage_est, pact_ver)。Valid ⇔ Valid(J_FLUID) ∧ G_min ≥ G_req ∧ 有效期未越界 ∧ 决策相关集已按 VoI 处置 ∧ 本体覆盖估计 ≥ κ_min（否则必须带未建模风险储备）。

**定义 321（上下文干扰集 ℰ_ctx）** 环境伪造前提（假门/错标签/重放旧场景）、过期上下文重放、共同基础社交工程（「你早知道我要 X」）、规划器幻觉算子、以及**本体缺口**（真实前提未被建模）。并入 AIC：ℰ_PACT = ℰ_FLUID × ℰ_ctx × ℰ_plan（计划图故障 / 再规划发散 / 假设集错配）。

**定义 322（本体缺口与未知的未知）** 系统未建模的上下文命题集 C^⊥。本体覆盖率 κ_cov = 被表示的真实前提比例（可估下界）。PACT 的安全性只能达到其本体完备性的程度；证书必须报告 κ_cov 估计，并在低覆盖区施加**未知-未知储备**（额外安全裕度）。这是对「计划越详细越有说服力」的直接对冲。

**定义 323（计划-上下文耦合稳定性）** 再规划阈值带迟滞 ⇒ 再规划次数有界；计划值函数 L_V-Lipschitz ⇒ 信念小扰动只引起计划小变化——**除决策边界外**；而决策边界恰是灵敏度 σ_i 最大处，也正是计划条件 VoI 最高处，二者自洽。

**定义 324（时间有效性与过期）** 上下文事实会过期；过期事实的信念向先验衰减。**禁止在过期事实上执行**；这是「上下文陈旧」守卫（类比 R69 的交互预算，但管的是时间而非次数）。

**定义 325（层级上下文）** 上下文分物体级/任务级/会话级/世界级，衰减率与来源不同；计划灵敏度按层计算，避免为全局事实过度消解、也避免用会话级偏好掩盖物体级危险。

**定义 326（对 R69 的退化）** 当计划视界=1 且 C=当前观测模态时，σ_i 退化为模态熵权重，VoI_π 退化为熵型 VoI，无假设跟踪、无再规划 ⇒ PACT ≡ FLUID。故 R69 是 PACT 在「无计划、无上下文」边界上的严格退化。

## 2. 关键算法骨架

```python
# IP-264 PGM：带条件计划图（算子模型复用 R69 trunk 学到的前向/效果模型）
class PlanGraph:
    def build(self, goal, b_t):                 # 信念上的条件计划
        return search_operators(goal, b_t, cache=self.skeleton_cache)
    def value(self, pi, b):                     # V(pi|b)：最优期望计划代价
        return expected_cost(pi, b, effects=self.effect_model)
    def sensitivity(self, pi, b, c_i):          # 定义 313 有限差分
        return abs(self.value(pi, b|c_i=1) - self.value(pi, b|c_i=0)) / C_scale

# IP-265 CCB：上下文信念册（出处 + 有效期 + 共同基础）
class ContextBook:
    def update(self, prop, obs, source, t):     # 贝叶斯 + 来源可信度
        self.b[prop] = bayes(self.b[prop], obs, source.reliability)
        self.src[prop].append((source, t))
    def grounded(self, prop, t, delta):         # 定义 315/324：未过期且够信
        return (t - self.t[prop] <= self.tau[prop]) and self.b[prop] > 1 - delta

# IP-266 PSV：计划条件 VoI（只对决策相关、非共同基础的事实）
def plan_voi(pg, ccb, pi, budget):
    b = ccb.belief()
    D = [i for i in ccb.props() if pg.sensitivity(pi, b, i) > EPS]
    best = None
    for g in info_actions(D, ccb.common_ground()):
        if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
        voi = pg.value(pi, b) - expected_value(pg, pi, b, g)
        score = voi - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None      # 无利可图 → 不查

# IP-267 ARG：三通道上下文漂移检测（含计划级效果残差）
def shift_detected(pg, ccb, exec_log, human_utt, t):
    a = any(not ccb.grounded(c, t, DELTA) for o in pg.committed() for c in o.assumptions)
    b = effect_residual(exec_log, pg.predicted_effects()) > TAU_EFF
    c = contradicts(human_utt, pg.committed_assumptions())
    return (a or b or c) and joint_false_prob(pg, ccb) > DELTA_SHIFT

# IP-268/269 CRD + CGR：承诺纪律 + 最小编辑再接地
def replan_if_needed(pg, ccb, t, budget):
    if not shift_detected(...) and not cost_crossover(pg, ccb, H_c, h):
        return pg                                    # 承诺期内不改
    repair = min_edit_repair(pg, ccb, budget)        # D* 增量
    if repair is None: return safe_seed_plan(ccb)    # 退回 R69 保守
    assert c_ras_wm.certify_plan(repair)             # 再接地也要认证
    return repair

# IP-274 PACT 主闭环（继承 R69，仅在决策单元与前提处插入 PACT 层）
def PACT_RAS_round(M, obs, goal):
    z, o = M.mtm.forward(obs); M.cof.step(...)       # R69 一次前向 + 标定
    M.ccb.update_from(o, obs); pi = M.pg.build(goal, M.ccb.belief())
    # 1) 只对决策相关事实做计划条件 VoI
    g = M.psv.plan_voi(M.pg, M.ccb, pi, M.budget)
    if g is not None: M.cia.execute(g); M.ccb.absorb_answer(g)
    # 2) 承诺与接地检查；失效则最小编辑再接地
    if M.arg.shift_detected(M.pg, M.ccb, M.exec_log, M.human_utt, M.t):
        pi = M.crd.replan_if_needed(M.pg, M.ccb, M.t, M.budget)
    # 3) 执行当前算子；沿用 R69 的动作级不确定性处置
    op = pi.next()
    k, lam, mode = M.fluid_step(op, o)               # R69 的 FLUID 闭环
    # 4) 计划级证书 + 参与式审计
    M.pic.submit_async(pi, op, M.ccb, M.arg.last_residual)
    return k, lam, mode, pi
```

## 3. 推导

**引理 19（决策相关性剪枝至 ε 无损）** 设计划值函数 V 关于事实取值 L_V-Lipschitz，|C| 条事实，灵敏度阈值 ε。只消解 D_ε 中的事实、其余置为当前信念，相对全消解的期望计划代价损失 ≤ |C|·ε。要点：**不知道一件决策无关的事是安全的**；这把 R69「高熵必查或必收紧」的预算约束解开，且可证不损安全裕度（仅损失 ε 的计划质量）。

**引理 20（计划条件 VoI 与熵型 VoI 的分离）** 存在上下文使某事实熵很高（H 大）但 σ_i=0：此时熵型 VoI 把它排在首位，计划条件 VoI 给 0；反之存在低熵但 σ_i 极大的事实（一票否决前提）。故熵型排序可任意误导，计划条件 VoI 才对齐真实目标。系：R69 在高熵低相关场景下会做「虚荣消歧」，R70 将其剪掉。

**引理 21（漂移检测延迟与有效期设计）** 若前提以速率 ρ 漂移、监测周期 Δt、效果残差可观测性 β，则执行到失效前提的概率 ≤ ρ·(Δt/β + τ_proc)。为使风险 ≤ 安全裕度 m，须 τ_o ≤ m/(ρ·(1/β+…))。要点：**有效期不是随便定的数，而是漂移率与可观测性的函数**。

**定理 18（PACT 严格包含 R69）** 当计划视界=1 且 C=当前观测模态时，灵敏度退化为模态熵权重、VoI_π 退化为熵型 VoI、无假设跟踪与再规划，PACT 与 FLUID 逐指令相同；一般情形下安全侧不弱于 R69（再接地必须过同一认证、失效即退回安全种子），效率侧因决策无关剪枝获得增益。故 R69 = PACT 的「无计划、无上下文」边界。

**定理 19（再规划稳定性/无抖振）** 在迟滞 h 与承诺视界 H_c 下，单位时间再规划次数 ≤ 值漂移总量/h + 漂移事件数；每次再接地从当前安全状态出发且须过认证，故计划切换处控制连续、无突变。系：迟滞不是保守，而是**防止「地一动就重排」造成的抖振**这一独立失效模式。

**定理 20（上下文投毒与本体缺口上界）** 在 k 个正交证据源（欺骗相关 ρ<1）+ 共同基础核验下，错误上下文承诺率 ≤ δ_ctx·ρ^{k−1}+ε_σ；对本体缺口，若证书强制报告 κ_cov 并在低覆盖区施加储备 r(κ_cov)，则实际风险 ≤ 名义风险 + (1−κ_cov)·r_max，且 r 随 κ_cov 下降单调上升。系：**PACT 不能承诺「没想到的前提」的安全，但能承诺「对没想到这件事保持诚实并留出储备」**。

## 6. 本轮最大风险

**一句话**：PACT-RAS 的全部严谨性都建立在「计划的**本体**已把真实前提建模进来」这一前提上——**若某条致命前提根本不在 C 里（梯子承重、地面结冰、对方其实在敷衍），计划条件 VoI 就会在一个错误的决策相关性结构上计算，系统会以「每一步都有前提、每张证书都合格」的确定性，执行一条真失败模式从未被表示的计划；计划越详细，遗漏越有说服力**——**你无法对一条你从未建模的前提提问**。

**次级风险与缓解**：
1. **本体缺口（最深的洞）** → 定义 322：强制报告 κ_cov 估计 + 低覆盖区未知-未知储备 r(κ_cov)，E307/E314 专门压测；

3. **再规划抖振** → 迟滞 h + 承诺视界 H_c + 定理 19 上界；
4. **计划层实时性** → 灵敏度缓存 + D* 增量 + 再接地移出控制环；
5. **规划器幻觉算子/效果模型错** → 计划级效果残差（定义 316-b）+ 再接地必须过同一 C-RAS-WM 认证。

## 4. 推导

**引理 19（决策相关性剪枝至 ε 无损）** V 关于事实取值 L_V-Lipschitz 时，只消解 σ_i>ε 的事实、其余置为当前信念，相对全消解的期望计划代价损失 ≤ |C|·ε。系：**不知道一件决策无关的事是安全的**，R69「高熵必查或必收紧」可被合法放宽。

**引理 20（计划条件 VoI 与熵型 VoI 的分离）** 存在高熵但 σ_i=0（熵型排首位、计划条件给 0）与低熵但 σ_i 极大（一票否决前提）两类上下文，故熵型排序可任意误导，计划条件 VoI 才对齐目标。系：R69 的「虚荣消歧」被剪掉。

**引理 21（漂移检测延迟与有效期设计）** 漂移率 ρ、监测周期 Δt、效果残差可观测性 β 下，执行到失效前提的概率 ≤ ρ·(Δt/β+τ_proc)；故有效期 τ_o 是 ρ、β 与安全裕度的函数，不是拍脑袋的数。

**定理 18（PACT 严格包含 R69）** 计划视界=1 且 C=观测模态时，灵敏度退化为模态熵权重、VoI_π 退化为熵型 VoI、无假设跟踪与再规划，PACT 与 FLUID 逐指令相同；一般情形安全侧不弱（再接地须过同一认证、失效即退回安全种子），效率侧因剪枝增益。R69 = PACT 的「无计划、无上下文」边界。

**定理 19（再规划稳定性/无抖振）** 迟滞 h 与承诺视界 H_c 下，单位时间再规划次数 ≤ 值漂移/h + 漂移事件数；再接地从当前安全状态出发且须过认证 ⇒ 切换处控制连续、无突变。

**定理 20（上下文投毒与本体缺口上界）** k 个正交证据源（欺骗相关 ρ<1）+ 共同基础核验下，错误承诺率 ≤ δ_ctx·ρ^{k−1}+ε_σ；本体缺口下，若强制报告 κ_cov 并施加储备 r(κ_cov)，实际风险 ≤ 名义风险 + (1−κ_cov)·r_max。系：**不能承诺「没想到的前提」的安全，但能承诺「对没想到保持诚实并留储备」**。

## 7. 本轮最大风险

**一句话**：PACT-RAS 的严谨性全押在「计划的**本体**已把真实前提建模进来」上——**若某条致命前提根本不在 C 里（梯子承重、地面结冰、对方其实在敷衍），计划条件 VoI 就会在错误的决策相关性结构上计算，系统会以「每步都有前提、每张证书都合格」的确定性执行一条真失败模式从未被表示的计划；计划越详细，遗漏越有说服力**——**你无法对一条你从未建模的前提提问**。

**次级风险与缓解**：本体缺口（定义 322 报告 κ_cov + 未知-未知储备，E307/E314）；上下文投毒/共同基础操纵（k 正交证据 + 共同基础核验 + ℰ_ctx 对抗训练，引理 20/定理 20）；再规划抖振（迟滞 + 承诺视界，定理 19）；计划层实时性（灵敏度缓存 + D* + 再接地移出控制环）；规划器幻觉算子/效果模型错（计划级效果残差 + 再接地须过同一 C-RAS-WM 认证）。
