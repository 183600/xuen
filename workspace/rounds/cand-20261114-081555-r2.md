# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；本轮灵感：「技能组合」×「用户共创」）

> R69 把人类从「被融合的模态」升级成「被询问的证人」：面对多峰歧义，系统会看、会问、会触，用一次信息动作消解一个可约的 epistemic。但这条协议仍隐含三个「一次性」假设：**回答是一次性的、能力是单体的、责任是无主的**。真实协作恰好相反——用户交付的不是一次回答，而是可复用的能力；系统执行的不是单个技能，而是技能的组合；而组合失败时，每个技能作者都可以说「我的技能在我的假设下是对的」。R69 的「问」解决不了这三件事。
>
> 本轮两个灵感正好对应两个跃迁：
> - **技能组合**把「单个动作块」升级为「可组合的局部能力」：技能不再是黑箱策略，而是带能力域、接口契约、来源的**局部认证截面**；组合是这些截面在重叠处的**粘合**，其失败由一层可计算的**缝阻碍**刻画。
> - **用户共创**把「询问」升级为「署名授权」：用户是技能与缝的共同作者，贡献带来源、可追责、可撤回；而用户最有价值的知识往往不在技能内部，而在**技能交接的缝上**——怎么从「搬运」切到「放置」、什么算「接稳了」、失败时先救谁。
>
> 核心命题：**把技能组合建模为能力层上的粘合问题，显式引入第三类不确定性 U_comp（缝阻碍 = 契约缺口 + 上闭链缺陷 + 覆盖洞 + 交互超出）；把用户共创定向到缝——用 S-VoI 选择最值钱的缝示范，而不是泛泛收集数据；只有当缝阻碍在预算内闭合、且缝证书通过反缝审计时才允许组合执行，否则退化为最大已认证子覆盖，再退化为 R69/R68。** 命名 **SEAM-RAS**（Sheaf-theoretic Embodied Assembly with Mutual co-creation）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这些能力能不能粘在一起、缝是谁教的、粘坏了算谁的**」——不确定性不再只是刹车、提问，也可以是一块**未被覆盖的缝**、一次**定向的示范请求**、一条**能追到作者的信用**。

## 0. 直觉与动机

**灵感 1（用户共创 → 人类从「证人」变成「作者」）**
直觉：R69 的「问」是一次性取证——得到一个回答、更新一次后验、随即丢弃。用户共创说的是另一件事：用户把判断**沉淀为系统的一部分**——示范一段动作、标注一次偏好、纠正一次失败、甚至提交一个新技能。贡献由此跨 episode 存活，带来两个 R69 没有的问题：其一，一个错误会被反复调用（R69 的错误只污染一帧）；其二，贡献有作者，信任与责任必须落到来源上，不能像 R69 那样把所有回答加成一个匿名后验。

**灵感 2（技能组合 → 风险发生在缝上，而非技能内部）**
直觉：一个技能单独安全，不代表和另一个技能拼起来安全。想想「加速通过」与「贴近观察」：前者假设前方足够空，后者为了看清会把机体压到障碍附近；单独各有安全包络，拼起来却可能在「既快又近」的联合状态里越界。**组合风险不是各技能风险的加和或最大值，而是它们相互作用的产物**——它只存在于两个能力域的**重叠与邻接**处。组合不是免费的模块化红利，它制造了任何单个作者都未验证过的**缝**。

**灵感 3（层论 → 让组合可被推理，而非靠穷举测试）**
直觉：若技能是黑箱，要保证 n 个技能所有组合安全，就得测试指数多条链——不可能。但若每个技能是**带能力域的局部认证截面**（在它被验证过的地方给出行为与证书），组合就能用**粘合**来推理：两个截面在重叠处是否一致、交接函数在三个技能的交叠处是否满足上闭链条件、任务区域是否被覆盖。组合安全于是从「测试问题」变成**阻碍是否消失的问题**。层论给的正是这套语言：局部数据能粘成整体，当且仅当重叠相容且上闭链无阻碍；粘不上的部分，就是我们必须显式计量的东西。

**灵感 4（三分 → 现有二分看不见缝）**
直觉：R69 的 U_ale 是模态内噪声、U_epi 是模态间歧义（问一句可约）。但缝残余既不在单个技能的模态内，也不在「选哪个模态」之间——它是**技能之间的关系**：契约缺口（上游保证没覆盖下游假设）、上闭链缺陷（A→B→C 的交接与 A→C 的交接不一致）、覆盖洞（组合轨迹跑到任何能力域之外）、交互超出（联合行为偏离各技能边际的乘积）。更关键的是，**这份不确定性问「选哪个模态」没用**：用户可能只教过单个技能，并不知道两个技能拼起来会怎样；必须问**缝本身**。

**灵感 5（共创的暗面 → 新的威胁模型与归责难题）**
直觉：一旦能力可被多方贡献、可被组合，攻击面与责任结构同时变化。可以提交一个**特洛伊技能**：隔离测试完全正常，只在特定组合里作恶；可以提交一个**只覆盖缝的良性部分**的示范，让缝看起来闭合、危险部分却被留在覆盖洞；可以伪造来源冒领高信任；可以多人共谋让「多源一致」失效；系统也可能因为「这是用户教的」而谄媚地过度信任。最阴险的是**责任缺口**：组合失败时没有任何单技能的接口契约被违反——每个作者都能说「我的技能在我的假设下是对的」，于是没人负责、纠正回路永不触发。

**灵感 6（为什么共创要定向到缝 → 用户的比较优势在交接处）**
直觉：技能内部已被作者演示、被证书覆盖，用户再演示一遍的边际信息很小；而缝是**未被任何单个作者完整看到**的区域，恰恰最需要「懂这个任务的人」来补。于是「问什么」有了新答案：不是问「这个物体是什么」，而是问「从搬运切换到放置的那一下，你希望它先减速还是先对准？」——问的是**交接函数**与**边界条件**。这把共创从「收集更多数据」变成「购买最贵的缺失信息」，也正是 S-VoI 要优化的对象。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（SEAM-RAS 总览）** SEAM-RAS = (SKG, SCT, CSU, SVC, SCI, SPA, SAV, SCF, CRA, RAS-WM§)。五不变式：
(i) **继承 R69** 实时流零学习写操作（定义 276-i）、证据纪律（定义 293-iii）与 R68/R69 保守下界；
(ii) **截面纪律**：任何可执行技能或组合必须携带机器可检查的局部截面（能力域 + 接口契约 + 来源）；无契约或匿名截面不得执行、更不得组合；
(iii) **缝闭合**：仅当缝阻碍 U_comp ≤ τ_comp 且缝证书有效时才执行组合；否则退化为最大已认证子覆盖或最高信任单技能；
(iv) **定向共创**：每次示范请求必须通过 S-VoI > 成本与覆盖证书检查，禁止「钓鱼式」泛采；
(v) **可归责**：每次执行与失败记录来源图与缝信用向量；不可归因失败必须登记为「接口级故障」，不得静默归零。

**定义 311（技能即局部截面）** 技能 S = (π_S, D_S, ∂_S, τ_S, ρ_S, θ_S, J_S)。其中 D_S ⊆ B 为被验证的能力域（开集，B = 𝒳×𝒞 为状态×上下文基空间）；π_S: D_S → Δ(𝒜) 为行为；∂_S 为边界契约（在 ∂D_S 上的 Pre/Post/Inv）；τ_S 为可选的接口交接函数；ρ_S 为来源图（作者集合 A_S、贡献类型、父技能、缝父节点）；θ_S 为来源条件化信任；J_S 为继承的 R68/R69 证书。**技能是能力层 ℱ 在 D_S 上的一个局部截面，策略只是截面的一侧。**

**定义 312（能力层与限制映射）** 令 ℱ 把基空间的开集映为「已认证行为场」的集合。对 V ⊆ U，限制映射 ρ_{UV}: ℱ(U) → ℱ(V) 把整体证书限制到子区域（学习实现中为条件化/边缘化）。技能 i 给出局部截面 s_i ∈ ℱ(D_i)；组合 C 是覆盖 𝒰 = {D_i} 上的粘合截面 s_C ∈ ℱ(∪_i D_i)，存在当且仅当重叠相容且上闭链条件成立（定义 315–316）。

**定义 313（共创贡献与摄取）** 贡献 c = (type, content, a, x, τ)，type ∈ {demo, preference, correction, new_skill, seam_demo, constraint}，a 为作者，x 为上下文，τ 为时间戳。**seam_demo 是本轮新增的一等类型**：在被指定缝区域 O_target 内的一段示范或交接参数。摄取算子 ⊕ 将 c 转为：(a) 既有截面的**带来源证据**；(b) 候选局部截面（new_skill）；(c) 新增/精化**交接函数** τ_{ij}（seam_demo）；(d) 对 Pre/Inv 的**约束精化**（constraint）。贡献必须署名、版本化、可撤回；仅当通过覆盖证书（定义 320）与信任门（定义 314）后才进入能力库。

**定义 314（来源条件化信任与反谄媚）** 信任 θ(a, κ) 按作者 a 与上下文类 κ 估计，来自已验证结果的可靠图与 ECE_a。技能信任取关键贡献者的**最小值** θ_S = min_{a∈A_S^{critical}} θ(a, κ)（避免平均稀释）。**反谄媚门**：θ(a, κ) ≤ g(n_a^{indep})，n_a^{indep} 为独立验证过的贡献数；同一作者的自证与重复提交不计入独立源（继承 R69 定义 293-iii）。缝信任 θ(τ_{ij}) = min(θ_{S_i}^{crit}, θ_{S_j}^{crit}, θ_{seam authors})。直觉：再受欢迎的作者，其信任也不能跑在独立证据前面。

**定义 315（组合、覆盖与接口）** 组合 C = (S_1, …, S_n; E; τ) 定义在任务区域 B_task ⊆ B 上，E ⊆ {(i,j)} 为接口边，重叠 O_{ij} = (D_i ∩ D_j) ∩ I_{ij}（I_{ij} 为接口子空间，如「已抓稳 + 位姿 + 速度」）。三重重叠 O_{ijk} = O_{ij} ∩ O_{jk} ∩ O_{ik} 用于上闭链检验。覆盖 𝒰 = ∪_i D_i；覆盖洞为 B_task \ 𝒰。

**定义 316（缝阻碍与组合不确定性 U_comp）** 组合的缝阻碍由四项组成：
- **契约缺口** δ(C) = max_{ij} [1 − P(ρ_{ij}s_i = ρ_{ji}s_j | O_{ij})]（学习契约的概率相容度）；
- **上闭链缺陷** γ(C) = max_{ijk} d(τ_{ij}∘τ_{jk}, τ_{ik} | O_{ijk})；
- **覆盖洞** h(C) = μ(B_task \ 𝒰) / μ(B_task)，μ 为任务相关测度；
- **交互超出** I_ex(C) = D_KL( P(ξ_C) ‖ glue(⊗_i P(ξ_{S_i})) )，联合行为相对各截面边际粘合结果的偏离。
定义阻碍范数 ‖𝔬(C)‖ = w_δ δ + w_γ γ + w_h h + w_I I_ex（权重经 E303 校准），U_comp = Calib(‖𝔬(C)‖)。**U_comp 与 U_ale、U_epi 正交**：它不在任一技能内部，也不在「选哪个模态」之间；问单个模态消不掉它，只能靠缝数据、交接约束或覆盖扩展消解。

**定义 317（组合兼容图与可达组合）** 建图 G_comp：节点为技能，边 (i,j) 存在当且仅当接口契约相容且 θ(τ_{ij}) ≥ τ_trust。**可达组合** = G_comp 中深度 ≤ L、当前任务下状态流可实现、且覆盖与 B_task 相交的链。契约剪枝避免指数枚举；只对可达链做按需认证（定义 318）。

**定义 318（惰性缝装配认证 SAV）** 规划时只认证当前候选组合，不预枚举全库。证书代数：子截面证书可限制复用；组合证书 combine(cert(i), cert(j)) **结合但不交换**（顺序敏感）；缓存键为（覆盖、接口、上下文类）。认证复杂度从 O(|G_comp|^L) 降到每个规划 O(L·cost(SCT))。

**定义 319（缝信息价值 S-VoI 与定向共创）** 候选示范请求 d = (O_target, demo_type, granularity)。其期望阻碍下降：
S-VoI(d) = E_{z ~ p(·|d)}[ ‖𝔬(C)‖ − ‖𝔬(C | z)‖ ] − c_user(d) − λ·risk(d)。
选择 d* = argmax_d S-VoI(d)，s.t. 用户负担预算、示范动作安全认证（继承定义 302）、覆盖证书可得。若 max S-VoI ≤ 0：不请求，走定义 321 退避。**关键约束**：O_target 必须是缝（重叠或覆盖洞）；对技能内部的示范因该处已认证，S-VoI ≈ 0，系统不得浪费用户预算。

**定义 320（覆盖证书与反缝审计）** 一段缝示范 z 声称覆盖 O_z ⊆ O_target。覆盖证书 = (覆盖测度 μ(O_z ∩ O_target)/μ(O_target)、残余区域 O_target \ O_z、留出的反缝探针集)。若覆盖 < 1 − ε_cov，则缝仍部分开放，**未覆盖部分不得被默认为安全**。**反缝探针**：在 O_target \ O_z 上做定向影子/孪生 rollout 与对抗扰动，检测「只演示良性部分」的缝投毒（定义 323）。单次示范只是似然，须与契约推理或第二次正交探针一致才可定案。

**定义 321（已认证子覆盖退避 SCF）** 若 U_comp > τ_comp、相容性失败、示范不可信或超预算：取组合的**最大已认证子覆盖** C′ ⊆ C（阻碍 ≤ τ_comp 且与当前状态连通）；若无，取最高信任的**单技能**；若连单技能都不满足，回到 R68 的纯保守停止。残余不确定性按 R69 定义 307 进入 λ_floor。**组合只在「有缝证书」时存在，否则不存在。**

**定义 322（缝责任归因 CRA）** 对结果 y（任务效用或负风险）：先限制全局轨迹到各 D_i——若某局部截面被违反，按技能级 Shapley 归责给该技能作者；若**没有**任何局部截面被违反、但全局 Post_C 失败，判为**缝失败**，在交接函数/接口不变式集合上计算 Seam-Shapley：φ_e = Σ_{T⊆E∖{e}} (|T|!(|E|−|T|−1)!/|E|!)·[v(T∪{e}) − v(T)]，信用路由给该缝的共同作者。若连缝级归因都不可识别（交互不可分离），判为**系统性接口故障**，必须走接口不变式修订（新增/收紧/删除边），而非重训任何单技能；此时责任缺口 R_gap = 1。

**定义 323（共创-组合威胁模型 ℰ_SEAM）** ℰ_co-create：特洛伊技能（隔离正常、特定组合作恶）、来源伪造、作者共谋（相关错误绕过 k 源）、谄媚过度信任、自证纠正、偏好漂移、契约遗漏（作者隐瞒前置条件）、示范疲劳/敷衍。ℰ_compose：缝投毒（只演示良性部分）、覆盖幻觉、接口契约伪造、特洛伊截面（重叠处一致、域外作恶）、反缝规避、孪生污染。合并 ℰ_SEAM = ℰ_FLUID × ℰ_co-create × ℰ_compose。

**定义 324（信任不洗白与单调性）** 组合信任 θ(C) ≤ min_i θ(S_i)，且 ≤ min_e θ(τ_e)；组合证书可信度不高于最弱环；任一关键来源 θ < τ_trust ⇒ 缝证书无效。**推论：低信任缝无法借道高信任技能洗白。** 同时 U_comp ≥ 0，组合证书不能强于任何单项的保守下界。

**定义 325（参与式缝审计 VQAuditor-S 与证书 J_SEAM）** 在 R69 VQAuditor-I 上扩展：贡献是否被正确署名与记分、缝示范是否真的覆盖目标缝、低信任缝是否被组合、不可归因失败是否被登记并路由到接口修复、特洛伊截面是否被反缝探针捕获、用户负担是否越界。J_SEAM = (J_FLUID, cover_hash, seam_graph_hash, U_comp_before/after, (δ, γ, h, I_ex), svoi_log_hash, coverage_cert, credit_vector, R_gap, θ_min, seam_ver)。Valid ⇔ Valid(J_FLUID) ∧ (缝闭合 ∨ 已走 SCF) ∧ θ_min ≥ τ_trust ∧ 覆盖证书有效 ∧ 信用已记录 ∧ 无匿名技能 ∧ 无被静默忽略的不可归因失败。

**定义 326（退化边界）** n = 1 且禁用共创摄取 ⇒ 逐指令等于 FLUID-RAS（R69）：单技能截面退化为 R69 证书，SCF 退化为定义 307；再令 VoI ≤ 成本（定义 298）⇒ 逐指令等于 CALM-RAS（R68）。安全侧因缝闭合与 SCF 而单调不弱于 R69。

## 2. 关键算法骨架

```python
# IP-264 SKG：技能即局部截面（能力域 + 边界契约 + 交接函数 + 来源 + 信任）
@dataclass
class Skill:
    pi: Policy                     # 可执行的 FMP 子策略（R69）
    D: Region                      # 能力域（被验证的开集）
    boundary: Contract             # Pre/Post/Inv on ∂D
    tau: Optional[TransitionFn]    # 与相邻技能的交接函数
    provenance: ProvenanceGraph    # 作者 / 贡献类型 / 父技能 / 缝父节点
    theta: dict                    # 来源条件化信任（取关键贡献者最小值）
    J: Certificate                 # 继承 R68/R69 证书

# IP-265 SCT：缝相容 + 三重叠上闭链（概率契约 + 交接一致性）
def seam_test(chain, x0, ctx):
    if not chain[0].boundary.Pre(x0, ctx): return False, 1.0
    delta, gamma = 0.0, 0.0
    for a, b in zip(chain, chain[1:]):
        O = overlap(a.D, b.D, interface(a, b, ctx))
        delta = max(delta, 1.0 - prob_sections_agree(a, b, O, ctx))
        if delta > DELTA_MAX: return False, delta
    for a, b, c in triples(chain):
        gamma = max(gamma, transition_defect(a, b, c, ctx))   # τ_ab∘τ_bc vs τ_ac
        if gamma > GAMMA_MAX: return False, gamma
    return chain[-1].boundary.Post(x0, ctx), max(delta, gamma)

# IP-266 CSU：缝阻碍 = 契约缺口 + 上闭链缺陷 + 覆盖洞 + 交互超出
def compose_uncertainty(chain, ctx):
    delta, gamma = seam_defects(chain, ctx)                   # 定义 316
    h   = 1.0 - coverage(chain, ctx.task_region)
    i_ex = interaction_excess(chain, ctx)                     # 联合 vs 边际粘合
    obs = W_D*delta + W_G*gamma + W_H*h + W_I*i_ex
    return Calib(obs), (delta, gamma, h, i_ex)

# IP-267 SVC：S-VoI 定向共创（只问缝，不问内部；无利可图即不问）
def choose_seam_demo(chain, obs, ctx, budget):
    best = None
    for d in seam_demo_candidates(chain, ctx):                # O_target ⊆ 缝
        if not budget.allow(d) or not certify_demo(d, ctx):   # 示范本身须安全
            continue
        gain  = expected_obstruction_drop(chain, d, ctx)      # E[‖𝔬‖−‖𝔬|z‖]
        score = gain - user_cost(d) - LAMBDA_RISK*risk(d)
        if best is None or score > best.score: best = (d, score)
    return best if best and best.score > 0 else None          # S-VoI≤0 → 不问

# IP-268 SCI：共创摄取（署名、版本化、覆盖证书、反缝审计）
def ingest(demo, claimant, ctx):
    if not verify_signature(demo, claimant): return REJECT      # 来源伪造
    cov = coverage_certificate(demo, demo.O_target)             # 定义 320
    if cov.ratio < 1.0 - EPS_COV:
        return PENDING(cov.residual)                            # 缝仍部分开放
    if not counter_seam_probe(demo, cov.residual, ctx):         # 缝投毒
        return REJECT
    if not trust_gate(claimant, demo, ctx):                     # 反谄媚 / k 源
        return PENDING("low_trust")
    return Skill.from_demo(demo, provenance=sign(demo, claimant))

# IP-269 SPA：反缝探针（世界/孪生是受访者；补集上对抗检验）
def counter_seam_probe(demo, residual, twin):
    if not twin.reliable(): return False                        # 孪生污染 → 作废
    for x in adversarial_samples(residual, demo.O_target):
        if twin.risk(demo.apply(x)) > EPS_PROBE: return False
    return True

# IP-270 SAV：惰性缝装配认证（证书代数，顺序敏感，可缓存）
def certify_assembly(chain, ctx):
    key = (cover_of(chain), interfaces_of(chain), ctx.cls)
    if key in cert_cache: return cert_cache[key]
    ok, defect = seam_test(chain, ctx.x0, ctx)
    cert = CombineCert([s.J for s in chain], order=chain,
                       defect=defect, cover=cover_of(chain))
    cert_cache[key] = (ok, cert)
    return ok, cert

# IP-271 SCF：退避：最大已认证子覆盖 → 单技能 → R68
def fallback(chain, ctx, tau_comp):
    for sub in maximal_certified_subcovers(chain, ctx, tau_comp):
        if connected_to_state(sub, ctx.x0): return sub
    singles = [s for s in chain if s.theta_min >= TAU_TRUST]
    return [max(singles, key=lambda s: s.theta_min)] if singles else []

# IP-272 CRA：限制优先，缝失败再算 Seam-Shapley；不可分离 → 接口故障
def attribute(chain, outcome, ctx):
    for s in chain:
        if violates(s.boundary, restriction(outcome, s.D)):
            return blame_skill(s, outcome)                      # 技能级归责
    phi = sampled_shapley(chain.edges, v=lambda T: value(T, outcome))
    if not identifiable(chain.edges, outcome):
        return SYSTEMIC_INTERFACE_FAULT, R_gap=1.0              # 责任缺口
    return route_to_seam_authors(phi, chain.provenance)

# IP-276 主闭环（继承 R69，只在「组合」处插入 SEAM 层）
def SEAM_round(M, obs, task):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    # 1) 契约剪枝规划可达组合，惰性认证
    chain = M.sav.plan(task, M.skg, ctx=o, depth=L)
    ok, cert = M.sav.certify_assembly(chain, ctx=o)
    # 2) 缝阻碍 + 是否需要定向共创
    U_comp, parts = M.csu.compose_uncertainty(chain, ctx=o)
    if ok and U_comp > TAU_COMP:
        d = M.svc.choose_seam_demo(chain, U_comp, o, M.budget)
        if d is not None:
            demo = M.sci.execute(d)                             # 请求/接收缝示范
            ingested = M.sci.ingest(demo, demo.author, o)
            if ingested is not REJECT:
                chain, U_comp = M.sav.reassemble(chain, ingested, o)
                ok, cert = M.sav.certify_assembly(chain, o)
    # 3) 退避：组合不可信 → 最大已认证子覆盖 → 单技能 → R68
    if (not ok) or (U_comp > TAU_COMP):
        chain = M.scf.fallback(chain, o, TAU_COMP)
        ok = len(chain) > 0
    # 4) 执行；内层仍用 R69 的 λ_floor / C-RAS-WM（信息动作也须认证）
    lam = max(M.efs.risk_scale(...),
              lam_floor(U_ale + U_epi_unresolved + (U_comp if not ok else 0.0)))
    A = M.ach.propose_chain(chain, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    # 5) 归责 + 证书 + 参与式缝审计
    phi = M.cra.attribute(chain, M.last_outcome, o)
    M.vqa_s.submit_async(chain, parts, cert, phi, R_gap=M.last_r_gap)
    return k, lam, chain, phi, (U_comp, parts)
```

## 3. 推导

**引理 19（组合严格放大风险）** 存在两个技能 S_1、S_2，各自在其能力域内风险 ≤ ε，但组合 C = S_1∘S_2 的风险 sup risk(C) > ε，且不能由 max_i risk(S_i) 或 Σ_i risk(S_i) 界定。构造：标量系统中 S_1「提速」在假设「距离 > d_0」下安全；S_2「贴近观察」在假设「速度 ≤ v_0」下安全；组合同时提速并贴近，进入 (v > v_0 ∧ d < d_0) 的联合区——该区不在任何一个 D_i 内。故组合风险是**联合分布上的新事件**，不是边际的最大或线性函数。系：任何只按单项风险做保守缩放的机制（含 R68 的 λ_floor、R69 的模态后验）都无法覆盖 U_comp。

**引理 20（粘合充分性）** 若每条接口边 P(ρ_{ij}s_i = ρ_{ji}s_j) ≥ 1 − δ、每个三重叠满足 d(τ_{ij}∘τ_{jk}, τ_{ik}) ≤ γ、初态满足 Pre_1、且 B_task ⊆ 𝒰，则组合以概率 ≥ 1 − nδ − n²γ 满足终态 Post_n 并全程保持 ∩Inv_i。证明：对 n 条边与 O(n²) 个三重叠用 union bound；在无缺陷处，截面由层公理唯一粘合。注意这是**充分非必要**且**条件化于截面诚实**——契约遗漏不在保证范围内，这正是责任缺口的根源（定理 21）。

**引理 21（缝的可探测性与样本复杂度）** 若缝上存在交互超出 I_ex(C) ≥ ι，则反缝探针用长度 T 的 rollout 可由 Pinsker 不等式以概率 ≥ 1 − η 区分「存在交互」与「独立粘合」，所需 T = O(ι^{-2} log(1/η))。系：可分的缝能在有限预算内被探针确认或证伪；I_ex 极小的缝无法在预算内确认，此时必须走 SCF，而不是「探了等于没探」。

**引理 22（信任不洗白）** 由定义 324，组合信任取最小，任何组合的信任不超过最低信任组件；把低信任/特洛伊截面接到高信任技能之后，既不能提升其可信度，也不能借组合证书绕过 τ_trust。系：共创带来的「作者声望」不能被用来为未经独立验证的缝背书。

**定理 18（SEAM 严格包含 R69/R68）** 在 A99（截面诚实）、A100（能力域覆盖）与 A101（来源完整性）下，任意状态上 SEAM 在已认证集合内的期望风险 ≤ R69；当 n = 1、禁用共创、U_comp = 0 时两者逐指令相同；再令 VoI ≤ 成本即逐指令等于 R68。证明要点：单技能时截面退化为 R69 证书，SCF 与定义 307 相同；组合时只在缝闭合且 U_comp ≤ τ_comp 时执行，否则退回 R69 可执行的子覆盖，故风险不增。安全侧不让步，效率侧获得「组合复用 + 定向共创」收益。

**定理 19（缝归因的一致性与收敛）** 采样 Seam-Shapley 以 O(1/√m) 收敛到真值；若接口交互可分离，则信用向量与真实缝作者贡献一致，按信用路由的纠正使被纠正缝的重复失败率单调不增。若交互不可分离，则存在非可归因失败使所有单技能边际为零（与定理 21 一致），此时归责必须上移到接口——这正是「缝责任」与「技能责任」必须分开记账的原因。

**定理 20（特洛伊截面的隔离不可判定性）** 存在技能对 (S_b, S_t)：对所有隔离测试分布 D_iso，二者行为 ε-不可区分（总变差 < ε），但存在一条可达组合 C 使二者在安全意义上显著不同。故任何只做「隔离测试 + 单技能证书」的认证器错误率下界 ≥ 1 − ε。**结论：缝认证与反缝探针不是可选项，而是可组合性本身强制的。** 这解释了为什么 R69 的逐技能证据纪律不足以保障组合。

**定理 21（责任缺口的存在性与接口修复必要性）** 存在组合 C，其失败时所有单技能 Inv_i 均未被违反（故逐技能 Shapley 边际为零，逐技能重训无法改变结果），但通过新增/收紧接口不变式或删除边可消除该失败。故责任缺口是**结构性**的：不能由更努力的单技能验证消除，只能由接口级契约修订消除。系：共创系统的纠正回路必须包含「缝作者/接口作者」角色，否则无人对组合失败负责。

## 6. 本轮最大风险

**一句话**：SEAM-RAS 的安全论证全部押在「局部截面是诚实的、缝示范真的覆盖了缝」这一前提上——**一旦用户共创只覆盖了缝的良性部分（缝投毒），或能力域声明本身是遗漏/伪造的，阻碍就会被算小、缝会「看起来闭合」，系统便自信地把两个从未在危险重叠处被验证过的技能粘在一起执行**；此时共创不但没消解组合风险，反而用「有人教过」给一个未闭合的缝盖了章——**假闭合的缝，比明知的缺口更危险**。

**次级风险与缓解**：
1. **缝投毒/覆盖幻觉** → 覆盖证书 + 反缝探针 + 留出补集审计（定义 320、E306–E307）；
2. **特洛伊截面/来源伪造/共谋** → 缝认证 + 信任取最小 + k 正交源 + ℰ_SEAM 对抗训练（定义 314、323–324、定理 20）；
3. **责任缺口被静默** → CRA 的「限制优先、缝级其次、系统性接口故障兜底」三段式归责 + R_gap 单列（定义 322、定理 21）；
4. **用户负担与示范疲劳** → S-VoI 硬门 + 只问缝 + 预算硬约束 + 版本化撤回（定义 319、313）；
5. **组合爆炸击穿实时预算** → 契约剪枝 + 惰性认证 + 证书代数 + 离线摄取（定义 317–318、复杂度表）；
6. **谄媚导致过度信任** → 反谄媚门 θ ≤ g(n_indep) + 信任不洗白（定义 314、324）。

## 2. 形式化定义（要点版）

**定义 310（总览与五不变式）** SEAM-RAS = (SKG, SCT, CSU, SVC, SCI, SPA, SAV, SCF, CRA, RAS-WM§)。继承 R69 零学习写操作、证据纪律与 R68/R69 保守下界；截面纪律（无契约/匿名不得执行或组合）；缝闭合（U_comp ≤ τ_comp 且缝证书有效才执行组合）；定向共创（S-VoI > 成本 + 覆盖证书，禁止钓鱼）；可归责（来源图 + 缝信用；不可归因失败登记为接口级故障）。

**定义 311–312（技能即局部截面 / 能力层）** `S=(π_S,D_S,∂_S,τ_S,ρ_S,θ_S,J_S)`；技能是能力层 ℱ 在 D_S 上的局部截面，组合是覆盖 𝒰 上的粘合截面，存在当且仅当重叠相容且上闭链成立。

**定义 313（共创贡献与摄取）** `c=(type,content,a,x,τ)`，新增一等类型 `seam_demo`；摄取 ⊕ 产生带来源证据、候选截面、交接函数或约束精化；必须署名、版本化、可撤回，过覆盖证书与信任门后入库。

**定义 314（来源信任与反谄媚）** `θ_S=min` 关键贡献者；`θ(τ_ij)=min(θ_Si, θ_Sj, θ_seam authors)`；`θ(a,κ) ≤ g(n_indep)`，自证/重复不计独立源。

**定义 315（组合、覆盖与接口）** `C=(S_1,…,S_n;E;τ)`，`O_ij=(D_i∩D_j)∩I_ij`，三重重叠用于上闭链；覆盖 `𝒰=∪D_i`，覆盖洞 `B_task\𝒰`。

**定义 316（缝阻碍与 U_comp）** `U_comp = Calib(w_δδ + w_γγ + w_hh + w_II_ex)`；四个分量分别对应契约、交接、覆盖、交互；与 U_ale/U_epi 正交，问单个模态消不掉，只能靠缝数据/交接约束/覆盖扩展消解。

**定义 317–318（兼容图与惰性认证）** G_comp 按契约相容与信任建边；只认证可达链（深度 ≤ L）；证书代数结合不交换、可缓存，避免指数枚举。

**定义 319（S-VoI 与定向共创）** `d* = argmax [E(阻碍下降) − 用户成本 − λ风险]`，s.t. 安全认证与预算；`O_target` 必须是缝；S-VoI ≤ 0 则不请求。

**定义 320（覆盖证书与反缝审计）** 覆盖测度 + 残余区域 + 留出探针；未覆盖部分不得默认为安全；反缝探针在补集上对抗检验，识别缝投毒。

**定义 321（已认证子覆盖退避 SCF）** 阻碍超阈/不相容/不可信 → 最大已认证子覆盖 → 最高信任单技能 → R68；残余 U_comp 进入 R69 λ_floor。

**定义 322（缝责任归因 CRA）** 限制优先：局部截面违反 → 技能级 Shapley；否则全局失败而无局部违反 → 缝失败，算 Seam-Shapley 并把信用路由给缝作者；交互不可分离 → 系统性接口故障，`R_gap=1`，走接口不变式修订。

**定义 323–324（威胁模型与不洗白）** `ℰ_SEAM = ℰ_FLUID × ℰ_co-create × ℰ_compose`（缝投毒、特洛伊截面、来源伪造、共谋、谄媚、示范疲劳、覆盖幻觉、孪生污染）；`θ(C) ≤ min_i θ(S_i)` 且 `≤ min_e θ(τ_e)`，低信任缝不能借高信任技能洗白。

**定义 325–326（审计/证书与退化边界）** VQAuditor-S 审缝示范覆盖、署名、低信任组合、不可归因失败、特洛伊截面、用户负担；J_SEAM 并入阻碍前后、S-VoI、覆盖证书、信用、R_gap、θ_min。n=1 且禁用共创 ⇒ 逐指令等于 R69；再令 VoI ≤ 成本 ⇒ 逐指令等于 R68。

## 3. 关键算法伪代码

```python
# IP-264 SKG：技能 = 局部截面（能力域 + 边界契约 + 交接函数 + 来源 + 信任）
@dataclass
class Skill:
    pi: Policy; D: Region; boundary: Contract
    tau: Optional[TransitionFn]; provenance: ProvenanceGraph
    theta: dict; J: Certificate

# IP-265 SCT：重叠相容 + 三重叠上闭链
def seam_test(chain, x0, ctx):
    if not chain[0].boundary.Pre(x0, ctx): return False, 1.0
    delta = max((1 - prob_sections_agree(a, b, overlap(a, b, ctx), ctx)
                 for a, b in pairs(chain)), default=0.0)
    gamma = max((transition_defect(a, b, c, ctx)
                 for a, b, c in triples(chain)), default=0.0)
    if delta > DELTA_MAX or gamma > GAMMA_MAX: return False, max(delta, gamma)
    return chain[-1].boundary.Post(x0, ctx), max(delta, gamma)

# IP-266 CSU：缝阻碍 = 契约缺口 + 上闭链缺陷 + 覆盖洞 + 交互超出
def compose_uncertainty(chain, ctx):
    delta, gamma = seam_defects(chain, ctx)
    h    = 1 - coverage(chain, ctx.task_region)
    i_ex = interaction_excess(chain, ctx)          # 联合 vs 边际粘合
    obs  = W_D*delta + W_G*gamma + W_H*h + W_I*i_ex
    return Calib(obs), (delta, gamma, h, i_ex)

# IP-267 SVC：S-VoI 只问缝；无利可图即不问
def choose_seam_demo(chain, obs, ctx, budget):
    best = None
    for d in seam_demo_candidates(chain, ctx):      # O_target ⊆ 缝
        if not budget.allow(d) or not certify_demo(d, ctx): continue
        score = expected_obstruction_drop(chain, d, ctx) - user_cost(d) \
                - LAMBDA_RISK*risk(d)
        if best is None or score > best.score: best = (d, score)
    return best if best and best.score > 0 else None

# IP-268 SCI：署名 + 覆盖证书 + 反缝审计后摄取
def ingest(demo, claimant, ctx):
    if not verify_signature(demo, claimant): return REJECT
    cov = coverage_certificate(demo, demo.O_target)
    if cov.ratio < 1 - EPS_COV: return PENDING(cov.residual)
    if not counter_seam_probe(demo, cov.residual, ctx.twin): return REJECT
    if not trust_gate(claimant, demo, ctx): return PENDING("low_trust")
    return Skill.from_demo(demo, provenance=sign(demo, claimant))

# IP-269 SPA：补集上的反缝探针
def counter_seam_probe(demo, residual, twin):
    if not twin.reliable(): return False            # 孪生污染 → 作废
    return all(twin.risk(demo.apply(x)) <= EPS_PROBE
               for x in adversarial_samples(residual, demo.O_target))

# IP-270 SAV：惰性装配认证（顺序敏感、可缓存）
def certify_assembly(chain, ctx):
    key = (cover_of(chain), interfaces_of(chain), ctx.cls)
    if key in cert_cache: return cert_cache[key]
    ok, defect = seam_test(chain, ctx.x0, ctx)
    cert = CombineCert([s.J for s in chain], order=chain,
                       defect=defect, cover=cover_of(chain))
    cert_cache[key] = (ok, cert); return ok, cert

# IP-271 SCF：最大已认证子覆盖 → 单技能 → R68
def fallback(chain, ctx, tau_comp):
    for sub in maximal_certified_subcovers(chain, ctx, tau_comp):
        if connected_to_state(sub, ctx.x0): return sub
    singles = [s for s in chain if s.theta_min >= TAU_TRUST]
    return [max(singles, key=lambda s: s.theta_min)] if singles else []

# IP-272 CRA：限制优先 → Seam-Shapley → 系统性接口故障
def attribute(chain, outcome, ctx):
    for s in chain:
        if violates(s.boundary, restriction(outcome, s.D)):
            return blame_skill(s, outcome)
    phi = sampled_shapley(chain.edges, v=lambda T: value(T, outcome))
    if not identifiable(chain.edges, outcome):
        return SYSTEMIC_INTERFACE_FAULT, R_gap=1.0
    return route_to_seam_authors(phi, chain.provenance)

# IP-276 主闭环（继承 R69）
def SEAM_round(M, obs, task):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    chain = M.sav.plan(task, M.skg, ctx=o, depth=L)
    ok, cert = M.sav.certify_assembly(chain, ctx=o)
    U_comp, parts = M.csu.compose_uncertainty(chain, ctx=o)
    if ok and U_comp > TAU_COMP:
        d = M.svc.choose_seam_demo(chain, U_comp, o, M.budget)
        if d is not None:
            demo = M.sci.execute(d)
            ingested = M.sci.ingest(demo, demo.author, o)
            if ingested is not REJECT:
                chain, U_comp = M.sav.reassemble(chain, ingested, o)
                ok, cert = M.sav.certify_assembly(chain, o)
    if (not ok) or (U_comp > TAU_COMP):
        chain = M.scf.fallback(chain, o, TAU_COMP); ok = len(chain) > 0
    lam = max(M.efs.risk_scale(...),
              lam_floor(U_ale + U_epi_unresolved + (U_comp if not ok else 0.0)))
    k = M.c_ras_wm.certified_prefix(M.ach.propose_chain(chain, M.vista.H), ..., wm_preds)
    phi = M.cra.attribute(chain, M.last_outcome, o)
    M.vqa_s.submit_async(chain, parts, cert, phi, R_gap=M.last_r_gap)
    return k, lam, chain, phi, (U_comp, parts)
```

## 4. 推导

**引理 19（组合严格放大风险）** 存在各自风险 ≤ ε 的技能 S_1、S_2，其组合风险 > ε，且不能由 max_i risk(S_i) 或 Σ_i risk(S_i) 界定。构造：S_1「提速」假设距离 > d_0，S_2「贴近观察」假设速度 ≤ v_0；组合同时提速贴近，进入 (v > v_0 ∧ d < d_0) 的联合区，不在任何 D_i 内。系：只按单项风险缩放的机制（R68 λ_floor、R69 模态后验）覆盖不了 U_comp。

**引理 20（粘合充分性）** 若每边 P(ρ_ij s_i = ρ_ji s_j) ≥ 1−δ、每个三重叠 d(τ_ij∘τ_jk, τ_ik) ≤ γ、初态满足 Pre_1、B_task ⊆ 𝒰，则组合以概率 ≥ 1 − nδ − n²γ 满足 Post_n 并保持 ∩Inv_i。证明：对 n 条边与 O(n²) 个三重叠用 union bound；无缺陷处由层公理唯一粘合。注意充分非必要且条件化于截面诚实——契约遗漏正是责任缺口根源（定理 21）。

**引理 21（缝可探测性）** 若 I_ex(C) ≥ ι，反缝探针用长度 T 的 rollout 可由 Pinsker 不等式以概率 ≥ 1−η 区分「存在交互」与「独立粘合」，T = O(ι^{-2} log(1/η))。系：可分的缝能在有限预算内确认/证伪；I_ex 极小的缝应走 SCF，而非「探了等于没探」。

**引理 22（信任不洗白）** 组合信任取最小，故低信任/特洛伊截面接到高信任技能后不能提升可信度，也不能借组合证书绕过 τ_trust。

**定理 18（严格包含 R69/R68）** 在 A99（截面诚实）、A100（能力域覆盖）、A101（来源完整性）下，SEAM 在已认证集合内的期望风险 ≤ R69；n=1、禁用共创、U_comp=0 时逐指令相同；再令 VoI ≤ 成本即逐指令等于 R68。单技能退化为 R69 证书，SCF 退化为定义 307；组合只在缝闭合时执行，否则退回 R69 可执行子覆盖，风险不增。

**定理 19（缝归因一致性与收敛）** 采样 Seam-Shapley 以 O(1/√m) 收敛；接口交互可分离时信用向量与真实缝贡献一致，按信用纠正使重复失败率单调不增；不可分离时单技能边际为零，归责必须上移到接口。

**定理 20（特洛伊截面的隔离不可判定性）** 存在技能对 (S_b, S_t) 对所有隔离测试分布 ε-不可区分，但存在可达组合使其安全意义显著不同。故只做「隔离测试 + 单技能证书」的认证器错误率下界 ≥ 1−ε；缝认证与反缝探针由可组合性本身强制。

**定理 21（责任缺口的结构性与接口修复必要性）** 存在组合 C：失败时所有单技能 Inv_i 均未违反（逐技能 Shapley 边际为零、逐技能重训无效），但新增/收紧接口不变式或删边可消除失败。故责任缺口不能由更努力的单项验证消除，只能由接口级契约修订消除；共创纠正回路必须包含「缝作者/接口作者」角色。

## 7. 本轮最大风险

**一句话**：SEAM-RAS 的安全论证全部押在「局部截面是诚实的、缝示范真的覆盖了缝」这一前提上——**一旦用户共创只覆盖了缝的良性部分（缝投毒），或能力域声明本身是遗漏/伪造的，阻碍就会被算小、缝会「看起来闭合」，系统便自信地把两个从未在危险重叠处被验证过的技能粘在一起执行**；此时共创不但没消解组合风险，反而用「有人教过」给一个未闭合的缝盖了章——**假闭合的缝，比明知的缺口更危险**。

**次级风险与缓解**：缝投毒/覆盖幻觉（覆盖证书 + 反缝探针 + 补集审计，E306–E307）；特洛伊截面/来源伪造/共谋（缝认证 + 信任取最小 + k 正交源 + 对抗训练，定理 20）；责任缺口被静默（限制优先 → Seam-Shapley → 系统性接口故障三段式 + R_gap 单列，定理 21）；用户负担与示范疲劳（S-VoI 硬门 + 只问缝 + 预算硬约束 + 可撤回，定义 319/313）；组合爆炸击穿实时预算（契约剪枝 + 惰性认证 + 证书代数 + 离线摄取）；谄媚导致过度信任（反谄媚门 + 信任不洗白，定义 314/324）。
