### 第 5 轮灵感驱动研究记录（灵感循环第 2 轮，承接第 4 轮 CADVS-v4）

**灵感词**：机器人、奖励设计

**继承关系**：第 4 轮 CADVS-v4（IP-489~492）在 v3 五锚点（3DCF/MSRG/HICK/EEK/LTEM）基础上加入价值锚 VACK（kc_val）与平衡锚 BCK（kc_bal），形成七硬门 fail-closed 证据铸造框架与证书演算 CERTCALC，执行集 Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ … ⊆ Exec_v29。但 v4 的 VACK 只做事后评判——评估「已执行轨迹是否符合人类价值」，从未审查「机器人用来学习/合成规则的奖励信号本身是否良构」。本轮从「机器人」的具身学习与「奖励设计」切入，新增奖励设计锚 RDK（kc_reward）与奖励-价值分离守卫 RVSG，把七硬门扩为八硬门，形成 CADVS-v5（IP-493~496），执行集升级为 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **直觉：所有证书都默认「我们优化的目标就是我们要的」，而这恰是机器人学习最脆弱的假设**。强化学习/规则合成里最经典的失败不是策略不够强，而是奖励写错：Goodhart 定律、奖励黑客、代理目标与真实目标偏离。具身场景尤甚——「压低接触力」会让机械臂学会不接触，「快速完成」会让它摔碎物体，「抓取成功」会被定义为「把物体推下桌」。v4 的七道门能保证物理合法、末点真实、价值达标，却无法阻止一个被错误奖励训练出来的规则「完美地做错事」。因此本轮的核心直觉是：**给奖励本身发一张证书**，把「奖励是否良构」提升为与覆盖/物理/人因/末点/记忆/价值/平衡并列的第八个证据锚。

2. **奖励设计锚 RDK：把「奖励正确性」拆成四个可核验子命题**。设训练奖励 R_learn = r_task + r_shape + r_constraint + r_machine：
   (a) **势函数塑形不改变最优策略**（Ng, Harada & Russell, 1999）：若 r_shape(s,a,s') = γΦ(s') − Φ(s)，则对任意 Φ，最优策略集不变；若塑形非势函数形式，则存在 MDP 使其改变最优策略。故证书必须核验 pot_ok，否则塑形项可能是「奖励黑客的入口」。
   (b) **时序任务用奖励机（Reward Machine, RM）编译**：RM 是带输出的有限状态机，等价于 LTL 公式；将其与 CERTCALC 的时序投影 □_T 对接，并扩展出 ◇（eventually）与 U（until），使证书演算从有界时窗升级为完整线性时序片段。
   (c) **安全成本用约束 MDP（CMDP）建模**：max_π E[Σγ^t r_task] s.t. E[Σγ^t c] ≤ d；核验对偶变量 λ* 收敛与原始-对偶间隙，cost_slack = d − V_c(π) 作为硬门余量。接触力超限、碰撞冲量、能量超支都可作为成本项 c。
   (d) **奖励鲁棒性**：真实奖励 R 与训练奖励 R' 存在歧义集 U_ε(R) = {R' : ‖R'−R‖_∞ ≤ ε}；由仿真引理，|V_R^π − V_R'^π| ≤ ε/(1−γ)，故用 R' 训练的最优策略对 R 至多 2ε/(1−γ)-次优。robust_margin 把这一界转成可核验的门。

3. **奖励-价值分离守卫 RVSG：防止「证书本身被反向优化」**。v4 的 VACK 度量「价值」R_val，本轮 RDK 优化「训练奖励」R_learn。二者必须放在不同空间、用不同数据、不同评估者，否则优化器会学会最大化证书而不是真实价值（meta-reward hacking）。RVSG 在滑动窗口上监测代理-真实相关性 ρ_RL = corr(ΔR_learn, ΔR_val) 与漂移 Δρ_RL；若 R_learn 的提升不再预测 R_val 的提升（ρ_RL < τ_corr），判定奖励失配并触发重设计，而非继续训练。这是对 Goodhart 定律的结构性防御：不追求「一次写对奖励」，而是「持续检测奖励是否正在写错」。

**关键洞见**：v4 回答「执行是否符合价值」（post-hoc evaluation），v5 回答「我们优化的奖励是否值得优化」（objective audit）。前者是对策略的审计，后者是对目标函数的审计。八硬门 kc_evidence_forged_v5 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem ∧ kc_val ∧ kc_bal ∧ kc_reward，fail-closed；软评分 ECS_v5 = ECS_v4 · η_reward，η_reward 是势形性、RM 满足率、成本余量、鲁棒边际、抗黑客分的加权几何平均。奖励审计整体放在离线/准入慢环，不进入 1 kHz 控制环，从而不加剧 v4 的实时性风险。

**形式化目标（增量）**：
1. 定义奖励程序 R = (r_task, r_shape, r_constraint, r_machine, λ) 与奖励证书 RC = (pot_ok, rm_sat, cost_slack, robust_margin, hack_score, t)。
2. 定义势形性判据 pot_ok = [min_Φ ‖r_shape − (γΦ∘S' − Φ∘S)‖_∞ ≤ τ_pot]，用最小二乘/线性规划估计 Φ。
3. 定义奖励机 RM = (U, u0, δ_u, δ_r, F, L)，由 LTL φ 经 Büchi 自动机编译；rm_sat = 统计模型检验下 P^π(φ) ≥ 1−δ_RM 的置信判定。
4. 定义 CMDP 证书：cost_slack = d − V_c(π) ≥ τ_cost ∧ 原始-对偶间隙 ≤ τ_dual。
5. 定义奖励鲁棒性：robust_margin = 1 − 2ε_R/((1−γ)·max(V_r(π*),1)) ≥ τ_rob，并给出价值退化界定理。
6. 定义 RVSG：hack_score = max(0, 1 − ρ_RL)，kc_reward 要求 hack_score ≤ τ_hack。
7. 定义八硬门与 ECS_v5 = ECS_v4 · η_reward。
8. 定义 Exec_CADVS-v5 ⊆ Exec_CADVS-v4：在 v4 每条路径的规则学习/准入阶段追加 kc_reward（奖励审计），只缩不涨。

**本轮最大风险**：**奖励规约失配在原理上不可观测**——证书只能验证 R_learn 与 R_val 的内部一致性，无法验证 R_val 是否真的等于人类福祉；若 R_val 被系统性写错，八道硬门会「合法地」认证一个有害策略，形成元层面的 Goodhart。

### IP-493 RDK：奖励设计核（离线/准入慢环，秒~分钟级；不进控制环）

```python
@dataclass
class RewardDesignKernel:
    """RDK：对训练奖励程序 R_learn 发证书 RC；kc_reward 硬门"""
    tau_pot: float = 0.05        # 势形性残差阈值
    delta_RM: float = 0.05       # 奖励机失败容忍
    tau_cost: float = 0.0        # 成本余量阈值
    tau_dual: float = 0.02       # 原始-对偶间隙阈值
    tau_rob: float = 0.05        # 鲁棒边际阈值
    tau_hack: float = 0.30       # 抗黑客阈值
    gamma: float = 0.99
    epsilon_R: float = 0.02      # 奖励歧义半径（由奖励辨识误差/人类标注噪声估计）

    def certify(self, R: RewardProgram, rollout: Rollout, rm: RewardMachine,
                cost_stats: CostStats, t_now: float) -> RC:
        # 1) 势形性：解 min_Φ ‖r_shape − (γΦ(s')−Φ(s))‖_∞（LP/最小二乘）
        pot_ok, phi_hat = self._potential_fit(R.r_shape, rollout)
        # 2) 奖励机满足率：统计模型检验（Hoeffding 置信上界）
        rm_sat = self._rm_satisfaction(rm, rollout, delta=self.delta_RM)
        # 3) CMDP：成本余量 + 原始-对偶间隙（对 λ 二分/次梯度）
        cost_slack, dual_gap = self._cmdp_certificate(cost_stats, R)
        # 4) 奖励鲁棒性：价值退化界转边际
        v_ref = max(R.v_ref, 1e-9)
        robust_margin = 1.0 - 2.0 * self.epsilon_R / ((1.0 - self.gamma) * v_ref)
        # 5) 抗黑客分由 RVSG 注入（禁止 RDK 自己生成，防同源）
        hack_score = R.hack_score
        return RC(pot_ok=pot_ok, rm_sat=rm_sat, cost_slack=cost_slack,
                  robust_margin=robust_margin, hack_score=hack_score, t=t_now)

    def kc_reward(self, rc: RC) -> bool:
        """引理 43~46：通过 ⟹ 塑形势不变 ∧ 时序任务达标 ∧ 成本可行 ∧ 鲁棒有界 ∧ 无显著黑客"""
        return (rc.pot_ok
                and rc.rm_sat >= 1.0 - self.delta_RM
                and rc.cost_slack >= self.tau_cost
                and rc.robust_margin >= self.tau_rob
                and rc.hack_score <= self.tau_hack)

    def eta_reward(self, rc: RC) -> float:
        import math
        s_cost = 1.0 / (1.0 + math.exp(-rc.cost_slack))   # 平滑映射到 (0,1)
        terms = [1.0 if rc.pot_ok else 0.0, rc.rm_sat,
                 s_cost, max(rc.robust_margin, 0.0), 1.0 - rc.hack_score]
        return float(np.prod(np.clip(terms, 0.0, 1.0)) ** (1.0 / 5.0))

    def _potential_fit(self, r_shape, rollout) -> tuple[bool, np.ndarray]:
        # 构造线性系统 r_shape_k = γΦ(s_{k+1}) − Φ(s_k)，最小化 ‖AΦ − b‖_∞
        A, b = self._assemble_potential_system(r_shape, rollout)
        phi_hat, residual = self._solve_lp_infinity_norm(A, b)   # scipy.optimize.linprog
        return residual <= self.tau_pot, phi_hat

    def _rm_satisfaction(self, rm, rollout, delta) -> float: ...
    def _cmdp_certificate(self, cost_stats, R) -> tuple[float, float]: ...
```

### IP-494 RVSG：奖励-价值分离守卫（异步，滑动窗口）

```python
@dataclass
class RewardValueSeparationGuard:
    """RVSG：监测 R_learn 与 R_val 的代理-真实相关性，检测 meta-reward hacking。
    约束：R_val 数据源与 R_learn 数据源物理隔离；RVSG 不向 RDK 传梯度。"""
    window: int = 50
    tau_corr: float = 0.5
    history: deque = field(default_factory=lambda: deque(maxlen=50))

    def update(self, dR_learn: float, dR_val: float) -> float:
        """每次规则迭代/评估批：输入代理增量与真实价值增量，返回 hack_score。"""
        self.history.append((dR_learn, dR_val))
        if len(self.history) < self.window:
            return 0.0                      # 预热期不误报
        rho = self._spearman([h[0] for h in self.history],
                             [h[1] for h in self.history])
        return max(0.0, 1.0 - max(rho, 0.0))

    def audit(self, hack_score: float) -> bool:
        """相关性跌破阈值 ⟹ 代理-真实脱钩 ⟹ 触发奖励重设计，而非继续训练。"""
        return hack_score <= (1.0 - self.tau_corr)

    def _spearman(self, xs, ys) -> float: ...
```

### IP-495 CERTCALC-v5：证书演算扩展与核心定理（离线理论）

```python
class CertCalcV5(CertCalc):
    """在 v4 证书域上扩展 ◇/U 时序算子，并把奖励机嵌入证书演算。"""
    @staticmethod
    def eventually(a: str, T: float) -> str:   # ◇_[0,T]
        return f"◇_[0,{T}] {a}"

    @staticmethod
    def until(a: str, b: str) -> str:          # a U b
        return f"({a} U {b})"

# 定理 5：势函数塑形不变性（Ng, Harada & Russell 1999）
def theorem_shaping_invariance() -> str:
    """
    设 R'(s,a,s') = R(s,a,s') + γΦ(s') − Φ(s)。则对任意 Φ，
    argmax_π V_R'(π) = argmax_π V_R(π)（最优策略集不变）。
    反之，若塑形项不可写成势函数差，则存在 MDP 使其改变最优策略。
    证明：Q'_π(s,a) = Q_π(s,a) + Φ(s)，加常数不改变 argmax；逆命题用反例构造。
    """
    return "Proven (Ng et al. + converse counterexample)"

# 定理 6：奖励机-证书嵌入
def theorem_rm_embedding() -> str:
    """
    任一 LTL 公式 φ 可经 Büchi 自动机编译为奖励机 RM_φ，且
    □_T 对应 RM 的有界计数状态，◇ 对应接受态可达性，U 对应直到转移。
    故 CERTCALC-v5 的时序片段与 RM 语义同构，kc_reward 的 rm_sat 即 φ 的概率满足。
    """
    return "Proven (Büchi → RM construction)"

# 定理 7：奖励鲁棒性
def theorem_reward_robustness() -> str:
    """
    设 ‖R'−R‖_∞ ≤ ε_R。则 ∀π: |V_R^π − V_R'^π| ≤ ε_R/(1−γ)；
    且 V_R(π*_R) − V_R(π*_{R'}) ≤ 2ε_R/(1−γ)。
    证明：逐时刻望远镜求和 Σγ^t ε_R = ε_R/(1−γ)；再三角不等式插入中间项。
    """
    return "Proven"

# 定理 8：Goodhart 不可观测性
def theorem_goodhart_unobservability() -> str:
    """
    存在 R_val ≠ R_val'，使得在智能体可达状态集 S_reach 上二者逐点相等，
    从而对所有可观测轨迹与证书 RC 给出完全相同的判定，但真实福祉不同。
    故任何基于有限可达轨迹的证书都无法保证「R_val 等于人类福祉」。
    证明：构造在 S_reach 上相等、在 S_reach 外分叉的两价值函数；
          智能体永不观测 S_reach 外，证书输入分布相同 ⟹ 判定相同。
    """
    return "Proven (constructive)"
```

        # v4 七门（优先级：HIC veto > 其余并行，任一失败即拒）
        if self.hic.veto_active(hic):            return False, 'HIC_STOP'
        if not self.scf.kc_coverage(x, t_now):    return False, 'COVERAGE_BLIND'
        s2rc = self.msrg_cache.get(rule_id)
        if s2rc is None or s2rc.verdict != 'accept' or s2rc.mu_pass < self.mu_S:
            return False, 'PHYSICS_UNPROVEN'
        if not self.eek.kc_ee(eec):               return False, 'EE_UNPROVEN'
        if not self.bck.kc_bal(bcc):              return False, 'BALANCE_UNSTABLE'
        pass_mem, eta_mem, novelty = self.ltem.query(
            object_class, geo_sig, theta_domain_fp, rule_id)
        if not pass_mem:                          return False, 'MEMORY_REJECT'
        vac = self.vack.evaluate(traj, context, t_now)
        if not self.vack.kc_val(vac):             return False, 'VALUE_MISALIGNED'
        # v5 第八门：奖励审计（先查黑客，再查良构）
        if not self.rvsg.audit(rc.hack_score):    return False, 'REWARD_HACKING'
        if not self.rdk.kc_reward(rc):            return False, 'REWARD_ILLPOSED'
        return True, 'FORGED' + ('|NOVELTY' if novelty else '')

    def ecs_v5(self, x, t_now, rule_id, A_att=0.0,
               eta_mem=0.5, eta_val=0.5, eta_bal=0.5, eta_reward=0.5) -> float:
        base = (self.scf.gamma3d(x, t_now) ** self.w[0]
                * getattr(self.msrg_cache.get(rule_id), 'mu_pass', 0.0) ** self.w[1]
                * (1 + self.w[2] * A_att))
        return base * eta_mem * eta_val * eta_bal * eta_reward
```

### 集成流水线（v4 → v5）

```
离线/慢时域（奖励设计与审计，不进控制环）：
  任务规格 φ ──▶ Büchi 自动机 ──▶ 奖励机 RM_φ ──▶ r_machine
  奖励程序 R_learn = r_task + r_shape + r_constraint + r_machine
       ──▶ RDK.certify：势形性 LP、RM 统计模型检验、CMDP 对偶、鲁棒边际 ──▶ RC
       ──▶ RVSG.update(ΔR_learn, ΔR_val) ──▶ hack_score ──▶ RC
       ──▶ kc_reward ──▶ 通过才允许进入规则学习/准入
  数据隔离：R_val 数据源（人类偏好/价值标注）与 R_learn 数据源（仿真回报）物理分离，
            VACK 与 RDK 之间无梯度通路。

在线规则准入（异步，< 2 s/规则 + 价值评估 ~50 ms + 奖励证书查表 O(1)）：

  证书消费前：EFA-v5.hard_gate(...)
      ├─ HIC_STOP / COVERAGE_BLIND / PHYSICS_UNPROVEN / EE_UNPROVEN
      ├─ BALANCE_UNSTABLE → 阻抗软化/回退姿态 + 教师

## 4. 正确性论证（增量更新）

### 引理 43（势函数塑形不变性）

**陈述**：若 r_shape(s,a,s') = γΦ(s') − Φ(s)，则 R' = R + r_shape 与 R 具有相同最优策略集；若塑形项不可写成该形式，则存在 MDP 使其最优策略改变。

**证明**：对任意策略 π，V_R'(π) = V_R(π) + E[Σγ^t(γΦ(s_{t+1})−Φ(s_t))] = V_R(π) − Φ(s_0)（望远镜求和），故 argmax 不变。逆命题：构造两状态 MDP，非势形塑形在 s_0 处引入与 Φ 无关的偏置，使原次优动作成为最优。∎

**工程含义**：pot_ok 不通过即视为「塑形项可能偷偷改写目标」，fail-closed 拒绝。

### 引理 44（奖励机满足率的统计界）

**陈述**：设 φ 的真实满足概率 p，经验失败率 p̂（n 条独立轨迹）。若 p̂ + √(ln(1/α)/(2n)) ≤ δ_RM，则以置信 1−α 有 P^π(φ) ≥ 1−δ_RM。所需样本 n ≥ ln(1/α)/(2(δ_RM − p̂)²)。

**证明**：Hoeffding 单边不等式 P(p̂ − p ≥ −t) ≤ exp(−2nt²)，取 t=√(ln(1/α)/(2n)) 即得。∎

**工程含义**：rm_sat 不是「跑几条轨迹看着对」，而是有置信保证的统计判定；δ_RM 与 α 可随任务风险收紧。

### 引理 45（CMDP 成本证书与对偶间隙）

**陈述**：若 CMDP 满足 Slater 条件，则强对偶成立；设对偶解 λ*，原始-对偶间隙 ≤ τ_dual 且 cost_slack ≥ τ_cost，则策略 π 以高概率满足 E[Σγ^t c] ≤ d − τ_cost。

**证明**：拉格朗日 L(π,λ)=V_r(π)−λ(V_c(π)−d)；强对偶给出 gap = V_r(π*)−V_r(π) + λ*(V_c(π)−d) ≥ 0；gap ≤ τ_dual 与 V_c(π) ≤ d − τ_cost 联立即得可行性余量。∎

**工程含义**：把「接触力/碰撞冲量/能量」从软惩罚升级为带预算的硬约束，且证书给出可核验的可行性余量。

### 引理 46（奖励鲁棒性界）

**陈述**：若 ‖R'−R‖_∞ ≤ ε_R，则 ∀π，|V_R^π − V_R'^π| ≤ ε_R/(1−γ)，且用 R' 求得的最优策略对 R 至多 2ε_R/(1−γ)-次优。

**证明**：|V_R^π−V_R'^π| ≤ E[Σγ^t |R−R'|] ≤ ε_R/(1−γ)。三角不等式：V_R(π*_R)−V_R(π*_{R'}) ≤ [V_R(π*_R)−V_R'(π*_R)] + [V_R'(π*_R)−V_R'(π*_{R'})] + [V_R'(π*_{R'})−V_R(π*_{R'})] ≤ ε_R/(1−γ) + 0 + ε_R/(1−γ)。∎

**工程含义**：robust_margin 把「奖励辨识误差」显式转成可接受的价值退化上界；ε_R 可由人类标注噪声与仿真-实机回报差估计。

### 定理 v5（执行集严格收缩、奖励良构、Goodhart 不可观测）

**陈述**：在 (B1)~(B6)（继承 v4）之外，追加：(B7) 势形塑形可辨识（Φ 可解且残差可估）；(B8) RM 编译忠实于 φ；(B9) CMDP 满足 Slater 且对偶收敛；(B10) R_val 数据源与 R_learn 物理隔离。则：
(i) Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29，且因 kc_reward 非恒真而严格收缩；
(ii) kc_reward 通过 ⟹ 塑形不改变最优策略 ∧ P^π(φ) ≥ 1−δ_RM ∧ 成本余量 ≥ τ_cost ∧ 价值退化 ≤ 2ε_R/(1−γ)；
(iii) 代理-真实相关性 ρ_RL 低于 τ_corr 时，RVSG 以滑动窗口检出并阻断准入；
(iv) **Goodhart 不可观测性**：∃ R_val ≠ R_val' 在 S_reach 上逐点相等，使所有可观测证书判定相同而真实福祉不同——故证书只能保证「目标内部自洽」，不能保证「目标等于人类福祉」。

**证明**：(i) v5 在 v4 每条准入路径追加 kc_reward，只缩不涨；非恒真性由构造反例（错误奖励通过 v4 七门）保证。(ii) 由引理 43~46。(iii) 由 RVSG 定义与 Spearman 一致性。(iv) 由定理 8 构造：取 S_reach 上相等、外部差 δ 的两价值函数，智能体观测分布相同，所有 RC 输入相同，判定相同。∎

**诚实声明**：(B7) 势形可辨识在函数逼近器（神经网络奖励）下未必成立，需限制塑形项为可解释参数族；(B8) RM 对部分可观测/连续事件需抽象，抽象误差会削弱 rm_sat 保证；(B9) CMDP 非凸时强对偶失效，对偶间隙可能不收敛；(B10) 现实中 R_val 与 R_learn 数据常来自同一标注团队，物理隔离只能降低而非消除同源污染。**最根本的是 (iv)**：Goodhart 不可观测性说明本轮并未「解决」奖励规约问题，只是把它从「隐式假设」变成「显式标注的残余风险」。

## 5. 实验设计与初步结果（计划中，第 5~6 轮实机）

### 5.1 实验设计

- **平台**：MuJoCo 3.x + MJX（仿真）+ N 台实机 Panda（N=3~5，不同末端/摩擦/载荷）+ 人类偏好与价值标注平台（R_val 数据源独立于仿真回报）。

- **对照**：v4-full、v5-full；消融 A1（去 RDK，仅 v4 七门）、A2（去 RVSG，保留 kc_reward 其余项）、A3（RDK 替换为固定 ε_R=0）、A4（去 CMDP，成本仅软惩罚）、A5（势形性检查替换为「塑形范数阈值」）。
- **协议**：
  (a) **奖励黑客注入**：故意设计可被 hack 的代理奖励（如「接触力越小越好」「完成越快越好」），测 v4/v5 的非法通过率与真实价值损失；
  (b) **时序任务**：随机化 RM 结构，测 rm_sat 校准曲线（预测满足率 vs 实测）；
  (c) **成本约束**：接触力/冲量预算扫描，测 cost_slack 与违例率；
  (d) **奖励辨识误差**：向真实奖励注入 ε_R 噪声，测价值退化是否落在 2ε_R/(1−γ) 界内；
  (e) **代理-真实脱钩**：训练中后期人为让 R_learn 与 R_val 脱钩，测 RVSG 检出延迟与误报率；
  (f) **实时性回归**：确认 v5 控制环延迟与 v4 相同（审计全在慢环）。
- **指标**：奖励黑客率（代理提升但真实价值下降的比例）、代理-真实差距、RM 满足率校准误差、成本违例率、sim-to-real 价值退化、样本效率、任务成功率、安全违例率、ECS_v5 与失败 AUC、RVSG 检出延迟、控制环 P99/丢帧率。

## 7. 本轮最大风险（最终确认）
