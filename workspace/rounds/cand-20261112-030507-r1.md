# 第 59 轮（承接第 58 轮「KG-SFT-UX」IP-139~144；时空证据循环第 1 轮；本轮灵感：「任务规划」×「通信延迟」）

> 第 58 轮把安全支柱立成"结构化记忆守护的自适应"——知识图谱同时驱动检索/OOD/微调/证据合成/心智预测；但它的风险自陈点出一个被此前所有轮次默许的隐藏假设：**证据一旦通过门，就永远有效**。机器人不是在静止照片上行动，而是在流动的时间里行动：**(a)** 任务不是一串孤立接触，而是一张有先后、有截止期、有共享资源的计划网络，单点安全不能自动合成计划安全——十个各自 0.5% 的接触若共享同一个记忆子图/操作者/传感器/网络，计划风险可能被共模抬到 6%，而逐点门永远看不见这个数；**(b)** 云边、多机、人环三条链路都有延迟，等证据到手、等操作者点头、等同伴确认时世界已经变了——门在"观测时刻"是开的，在"承诺执行时刻"可能已经关了。本轮两个灵感各补一条时间维度：**任务规划**把承诺从"单点门"升级为"带风险预算与承诺视界的计划契约"；**通信延迟**把证据从"点值"升级为"带保质期与在途延迟的时变过程"。核心命题由"结构化记忆守护的证据说可信"升级为 **"证据在承诺成熟时仍然可信——时效可证、计划可算、延迟可退"**。

核心矛盾：
- **H29（单点安全 vs 计划安全）**：每个接触都过门，不等于整条计划安全。风险共用同一张 KG、同一个操作者、同一路传感器、同一段网络，是正相关的；逐点门按独立失效计算，系统性低估计划风险，且计划越长、共模占比越高。
- **H30（证据新鲜 vs 通信延迟）**：证据价值随时间衰减、随在途延迟折价；"观测时合格"与"执行时合格"之间隔着 Δ_comm + Δ_decision。把陈旧证据当新鲜用，比没有证据更危险；但过度要求实时证据，会让机器人在延迟中寸步难行，任务永远开不了工。
- **H31（长期承诺 vs 局部纠错）**：计划越长越省协调开销，但延迟/变化发生时纠错越晚；计划越短越灵活，但频繁重协商带来抖动与死锁。承诺视界 h_c 与租约长度 T_lease 是同一枚硬币的两面，必须同时定标。

## 0. 直觉与动机

**灵感 1（任务规划 → 计划即契约，风险即预算）**
直觉：以前把"安全"记在每一个脚印上；真实任务要的是"整段行程不翻车、且按时到"。登山时每一步踩稳并不保证路线安全，因为天气、体力、同伴是共享的。于是承诺升级为**计划契约**：计划携带风险预算 B_plan，每次承诺花掉一部分，只有被事后证实的新证据能补充；风险聚合显式包含**共模项**（同一记忆子图/操作者/传感器/网络路径/季节），而不是把每步风险当独立事件相加。计划还携带**承诺视界** h_c：只在"视界内每一步的证据在它真正执行时仍新鲜"时才承诺这一段，否则缩短视界、插入刷新屏障、或改道。

**灵感 2（通信延迟 → 证据有保质期，承诺有成熟时刻）**
直觉：证据不是永久通行证，而是一盒会过期的牛奶。它有三个时间戳：观测 t_obs、送达 t_arrive=t_obs+Δ_c、执行 t_exec=t_commit+Δ_plan。真正该问的不是"观测时准不准"，而是"执行时还准不准"。给每类证据一个**保守存活函数** φ_c(ℓ)（真实世界在 ℓ 时间内保持未变的概率下界，由危险率上界 λ̄_c 得到），门改成**时效门**：在预测执行时刻的**有效年龄** â = t_exec − t_obs + Δ̂_c + ε_clk 下，φ_c(â)·rel(e) ≥ 1−δ_e 才放行。**陈旧等于缺失，绝不等价于否定**：过期证据只允许降低置信、不允许增加置信，也不允许把"没更新"读成"没变化"。

**灵感 3（延迟下的分布式承诺 → 租约而不是共识）**
直觉：多机共享地形与任务时，等待"全网共识"在延迟下等于永远不动作。改用**时间租约**：谁在某个区域/任务上持有带起止时间与版本的 lease，谁才能做不可逆接触；租约长度必须大于最大往返延迟加两倍时钟偏斜，否则两个同伴会在"都以为自己拥有"的窗口里同时下脚。租约过期不是故障而是**安全信号**——立即退回预注册的保守局部片（只探不碰、走 fallback、等重新协调），而不是按旧计划硬走。

**灵感 4（两灵感合流 → 三时钟算子与两级证据门）**
直觉：给机器人装三个时钟：**世界钟**（任务截止期）、**证据钟**（每条证据的年龄）、**通信钟**（在途延迟与时钟偏斜）。每个检查点先对齐三钟，再决定刷新哪些证据、还能承诺多长视界、租约是否仍有效、人是否要重新点头。证据门从"六类"升级为**时效化六类**，并新增**计划级门**：整段视界证据新鲜 ∧ 风险预算不超支 ∧ 视界末端 fallback 可达。

**灵感 5（VOI 也要看截止期 → 先算提前量再探）**
直觉：探针不是免费的，也不是随时都来得及用——探完还要送回、还要决策。**时效 VOI** 把"探针必须在截止期减去在途延迟之前完成"写成硬约束；错过提前量的探针价值记为零。探询因此从"临门一脚再探"变成**带 lead time 的逆向排程**：要么提前规划、提前探，要么提前降档/绕行，绝不在截止期前做来不及回传的赌。

## 1. 形式化定义（增量：定义 145–150）

**定义 145（时效证据 TAPE）** 证据 e=(值, t_obs, 源, 类, 新鲜度模型)；对类 c 给定**保守存活函数** φ_c(ℓ)（不减、φ_c(0)=1、lim_{ℓ→∞}φ_c(ℓ)=0，由危险率上界 λ̄_c 得 φ_c(ℓ)=exp(−∫_0^ℓ λ̄_c(s)ds)，故 φ_c 是真实存活概率的下界）与最大可用年龄 τ_max(c)。在决策/执行时刻 t，有效年龄 â = t − t_obs + Δ̂_c + ε_clk（Δ̂_c 为预测在途延迟，ε_clk 为时钟偏斜上界）。**时效门**：e 在 t 可用 ⇔ â ≤ τ_max(c) 且 φ_c(â)·rel(e) ≥ 1−δ_e。决策时刻取最坏执行时刻 t_exec = t_commit + ĥ_c（视界末端）。**陈旧即缺失**：过期证据不产生负证据，只从可用集移除；不得据"无更新"推断"无变化"。

**定义 146（计划级承诺 PLCP）** 计划 π=(任务 DAG 𝒯, 优先级, 截止期 D_i, 共享资源 ℛ, 回退映射 fallback)。任务 i 的承诺风险 r_i，共享失效源集合 𝒮（同一 KG 子图/操作者/传感器/网络路径/季节）。**共模分解**：失效事件 ⊆ (∪_i A_i) ∪ (∪_{s∈𝒮} C_s)，A_i 特异、C_s 共模，得保守上界
  R_π := Σ_i r_i + Σ_{s∈𝒮} r^{cm}_s，
其中 r^{cm}_s 由源 s 的历史证伪率与其覆盖任务数给出（完全独立退化为 Σ r_i；完全共模由一次 max 控制而非重复相加；故该式对正相关风险是上界）。**承诺规则**：令视界 h_c 覆盖接下来任务前缀，承诺该前缀 ⇔ (i) 前缀内每个不可逆接触所需证据在其**各自预测执行时刻**满足定义 145；(ii) R_π(前缀)+ 已花预算 ≤ B_plan；(iii) 视界末端存在可达且已验证的 fallback。不可承诺则 h_c ← h_c−1；h_c=0 则改道或安全停。B_plan 只被事后证实按有界速率 ν 补充，计划内单调不借支（B_left ≥ 0 恒成立）。

**定义 147（延迟容忍租约 DRP）** 分布式任务分配用租约 L=(agent, resource, t_start, t_end, ver)。部分同步假设：往返延迟 ≤ Δ_c^max、时钟偏斜 ≤ ε_clk。**互斥条件**：T_lease=t_end−t_start > Δ_c^max+2ε_clk，且只在续约确认后延长、续约留 guard 时间。持有有效租约才可做不可逆接触；租约丢失/过期 ⇒ 立即切**保守局部片**（probe-only、无不可逆接触、沿预注册 fallback）并发起重协商。死锁规避：租约到期 + 静态优先级抢占，任何等待有上界；搬迁时旧租约作废、新租约版本单增。

**定义 148（时效分层记忆 TSM）** KG 升级为时序图：边 e 带 [t_from, t_until)、溯源 src、版本 ver 与衰减 w_e(t)=w0·exp(−λ_e(t−t_from))。检索按**预测执行时刻**过滤：只有 t_exec∈[t_from,t_until) 且 w_e(t_exec)≥w_min 的边可进入证据合成；过期边进隔离区、不参与不可逆必要集。第 58 轮证伪回溯扩展为**时间区间回溯**：证伪一个模态/来源，则作废该来源在该时间窗内的全部边。

**定义 149（延迟感知同意 LAC）** 人的同意是**意图租约**而非持久状态：意图 I=(op, 内容哈希, t_grant, t_expire, 视界)。执行前若世界/计划/证据摘要变化量 Δ_state>θ_change、或 t>t_expire、或往返延迟使确认无法在 D−Δ_h 前完成，则意图作废并**必须重新确认**；沉默、超时、丢包一律记为"未同意"，不得默认同意。τ_expire 随 μ_mis 与 Δ_state 单减、随 auth 单增但不超过 τ_max；**安全停永远可用且不依赖通信**。

**定义 150（三时钟算子 TPCX / PCE+++）** 状态含 (t_world, {â_e}, Δ̂_c, ε_clk, h_c, B_plan, leases, intents)。检查点顺序：①三钟对齐并预测各证据在执行时刻的有效年龄；②刷新：把 â>τ_max 或 φ·rel<1−δ 的证据列入刷新集，按 lead time 逆向排程（须在 t_exec−Δ_c−t_probe 前完成，否则不计入）；③计划风险重算（含共模）并核对预算；④租约检查/续约/抢占；⑤同意检查（意图是否仍有效、Δ_state 是否越阈）；⑥承诺 h_c 内全部门过 ⇒ 承诺，否则缩 h_c → 改道 → 降档 → 重协商 → 安全停；⑦时序 KG 写入/过期与审计。任一时钟异常（延迟尖峰、分区、时钟失步）⇒ h_c 收缩、转保守局部片、迟滞恢复。

## 2. 关键算法伪代码（完整版见产物区）

```python
def tp_commit(plan, M, t, clocks):
    # ① 三钟对齐：预测每条证据在其执行时刻的有效年龄
    for e in plan.needed_evidence:
        t_exec = t + clocks.plan_horizon(e)
        e.age = t_exec - e.t_obs + clocks.delta_c_hat + clocks.eps_clk
        e.admissible = (e.age <= tau_max(e.cls)) and \
                       (phi(e.cls, e.age) * rel(e) >= 1 - delta_e)
    # ② 按提前量逆向调度刷新，错过截止期者价值记 0
    refresh = schedule_probes_by_leadtime(plan, t, clocks.delta_c_hat)
    # ③ 计划级风险（特异 + 共模）与预算
    R = sum(x.r for x in plan.prefix) + common_mode_risk(plan.shared_sources)
    # ④⑤ 租约与意图
    if not leases_valid(plan, t) or not intents_valid(plan, t):
        return degrade_or_stop(plan, "lease_or_consent_expired")
    # ⑥ 承诺视界：不满足则收缩
    while plan.horizon > 0 and not (R <= plan.B_left and all_admissible(plan, plan.horizon)):
        plan.horizon -= 1
        R = replan_risk(plan, plan.horizon)
    if plan.horizon == 0:
        return reroute_or_safe_stop(plan)
    return commit(plan, plan.horizon, R)      # 陈旧即缺失，绝不亮绿灯
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| TAPE | O(\|E\|) 评估/检查点 | O(\|E\|) | φ 为存活下界、时钟偏斜上界诚实、陈旧即缺失 |
| PLCP | O(\|𝒯\|+\|𝒮\|²) 每视界 | O(\|𝒯\|) | 共模源完备、R_π 为上界、预算不借支 |
| DRP | O(1)/租约操作 + O(\|ℛ\|) 抢占扫描 | O(\|agent\|·\|ℛ\|) | T_lease>Δ_max+2ε、版本单增、过期即退 |
| TSM | O(\|𝒢_v\|) 检索 | O(\|ℰ\|+\|ℛ\|) | 按执行时刻过滤、隔离区不进必要集 |
| LAC | O(1) 校验 + O(1) 变化检测 | O(\|操作者\|) | 沉默非同意、τ_expire 上界、安全停通信无关 |
| TPCX | O(\|CP\|·(k_p+k_r)·(C_VOI+d_GNN)) | O(\|V\|+\|σ\|+\|𝒢\|) | 三钟单调、提前量硬约束、四态完备 |

**正确性定理（TACT 概要）**：在 A41–A45 上加 (A46) 新鲜度模型诚实（φ_c 为真实存活下界，hazard 上界，执行时刻预测误差 ≤ε_plan，时钟偏斜 ≤ε_clk）；(A47) 共模分解覆盖全部共享失效源且 R_π 为上界；(A48) 租约在部分同步下满足 T_lease>Δ_c^max+2ε_clk、续约 guard、版本单增；(A49) 意图过期与 Δ_state 重确认被强制执行、沉默/超时非同意、安全停通信无关；(A50) 时序 KG 按执行时刻检索、过期边隔离、时间窗证伪回溯完整且不进不可逆必要集。则：
(i) **时效承诺健全性**：P(计划失效) ≤ R_π + Σ_e(1−φ_c(â_e))·1[e 被用] + δ_lease + δ_consent + δ_mem，其中 A48/A49 下 δ_lease=δ_consent=0；
(ii) **延迟单调性**：承诺集随延迟非增，Δ1≤Δ2 ⇒ CommitSet(Δ1) ⊇ CommitSet(Δ2)——延迟只会让系统更保守，绝不把不安全承诺放进来；
(iii) **新鲜度单调性**：同一证据的可采性随年龄非增；陈旧证据绝不被读成负证据，也绝不增加置信；
(iv) **租约互斥性**：A48 下同一资源不会出现两个同时有效的不可逆承诺；
(v) **带 fallback 的终止性**：TPCX 在承诺/改道/重协商/安全停四态内终止，所有等待被租约到期或 τ_expire 上界，探针不晚于其 lead-time 截止期。

| 风险 | 等级 | 缓解 |

## 6. 本轮最大风险

**一句话**：本轮把安全承诺从"证据是否可信"改为"证据在承诺执行时是否仍然可信"，并把计划级风险当作可加预算；最大风险是**时效模型与共模风险估计的系统性错误**——若世界变化的危险率被低估、或共享失效源被漏算，系统会在"证据看着新鲜、每步风险都低于阈值"的假象下，把一个长计划整体推入不可逆区域，而延迟恰好让纠错信息来迟；必须以危险率上界、陈旧即缺失、租约互斥、计划风险上界与安全停默认值五重护栏，宁可在延迟中短视保守，也不在陈旧证据上长远乐观。

## 2. 关键算法伪代码

### IP-145 TAPE（时效证据与时效门）

```python
def fresh_lower_bound(cls, age):
    # 危险率上界积分；返回真实存活概率的下界（保守）
    return math.exp(-cls.hazard_upper.integral(0, age))

def t_exec_worst(t_commit, horizon, clocks):
    return t_commit + clocks.plan_duration(horizon) + clocks.delta_c_hat + clocks.eps_clk

def tape_admissible(e, t_exec):
    age = t_exec - e.t_obs
    if age > e.cls.tau_max:
        return False, age, 'too_old'
    if fresh_lower_bound(e.cls, age) * e.rel < 1 - e.delta:
        return False, age, 'freshness_below_bound'
    return True, age, 'ok'

def tag_evidence_time(sigma, M, t_exec):
    for e in sigma.evidence:
        ok, age, why = tape_admissible(e, t_exec)
        # 陈旧只移除，不产生负证据；也不把沉默读成“没变化”
        e.state = ('fresh' if ok else 'missing')
        e.age, e.reason = age, why
    return sigma
```

### IP-146 PLCP（计划级承诺：共模风险 + 风险预算 + 承诺视界）

```python
def common_mode_risk(shared_sources, M):
    # 共模源按“历史证伪率 × 覆盖任务数”给出的上界，每个源只计一次
    return sum(src.cm_rate_upper(M.history) for src in shared_sources)

def plan_risk(prefix, shared_sources, M):
    return sum(t.r for t in prefix) + common_mode_risk(shared_sources, M)

def plcp_commit(plan, M, t, clocks):
    h = plan.h_max
    while h > 0:
        prefix = plan.prefix(h)
        t_exec = t_exec_worst(t, h, clocks)
        # (i) 视界内每个不可逆接触的证据在其执行时刻仍新鲜
        fresh_ok = all(
            tape_admissible(e, e.t_exec_pred)[0]
            for task in prefix for e in task.irreversible_evidence
        )
        # (ii) 计划级风险不超预算
        R = plan_risk(prefix, plan.shared_sources, M)
        budget_ok = (R <= plan.B_left)
        # (iii) 视界末端有可达且已验证的 fallback
        fallback_ok = plan.fallback_reachable_and_verified(prefix)
        if fresh_ok and budget_ok and fallback_ok:
            plan.spend(R)
            return commit(prefix, R, h)
        h -= 1
    return reroute_or_safe_stop(plan, reason='no_admissible_horizon')

def replenish_budget(plan, verified_evidence, dt):
    # 只由事后证实补充，且补充速率有界；从不借支未来
    plan.B_left = min(plan.B_plan,
                      plan.B_left + min(verified_evidence.gain, plan.nu * dt))
```

### IP-147 DRP（延迟容忍租约与重规划）

```python
def acquire_lease(agent, res, now, clocks):
    T = clocks.delta_c_max + 2 * clocks.eps_clk + clocks.guard
    # 先观察旧租约释放或确认其已过期，再发起
    if not known_released_or_expired(res, now, clocks):
        return None
    return Lease(agent, res, t_start=now + clocks.guard,
                 t_end=now + clocks.guard + T, ver=next_ver(res))

def leases_valid(plan, now, clocks):
    for task in plan.prefix(plan.horizon):
        L = plan.lease_of(task.resource)
        if L is None or not (L.t_start + clocks.eps_clk <= now <= L.t_end - clocks.eps_clk):
            return False
    return True

def on_lease_lost(plan, task):
    # 过期/丢失不是错误，是安全信号：立即退回预注册保守局部片
    fallback = plan.fallback_of(task)
    return ConservativeLocalFragment(
        probe_only=True, irreversible=False,
        route=fallback.route, renegotiate=True)
```

### IP-148 TSM（时序 KG：按执行时刻检索、时间窗回溯）

```python
def temporal_retrieve(G, seed, t_exec, k=2):
    Gv = khop_subgraph(G, seed, k=k)
    valid_edges = [
        e for e in Gv.edges
        if e.t_from <= t_exec < e.t_until
        and e.w0 * math.exp(-e.lam * (t_exec - e.t_from)) >= G.w_min
    ]
    stale_edges = [e for e in Gv.edges if e not in valid_edges]
    return TemporalSubgraph(Gv.nodes, valid_edges), stale_edges

def falsify_retract_window(G, src, modality, t_lo, t_hi):
    # 第 58 轮证伪回溯的时间区间版本：作废该来源在该时间窗内的全部边
    for e in G.edges_with(src=src):
        if e.modality == modality and overlaps(e.validity, (t_lo, t_hi)):
            G.quarantine(e, reason='falsified_window', window=(t_lo, t_hi))
```

### IP-149 LAC（延迟感知同意：意图租约）

```python
def grant_intent(op, plan, now, clocks, mental):
    horizon = plan.horizon
    base = {'A0': 0, 'A1': 20, 'A2': 10}[op.auth]   # A0 无意图，必须逐步确认
    if base == 0:
        return Intent(op, H_state=state_hash(plan), t_grant=now,
                      t_expire=now, horizon=horizon)   # 立即过期 = 必须逐步确认
    tau = min(clocks.tau_max,
              base / (1 + 2 * mental.mu_mis) / (1 + clocks.delta_c_hat))
    return Intent(op, H_state=state_hash(plan), t_grant=now,
                  t_expire=now + tau, horizon=horizon)

def intent_valid(I, plan, now):
    if I is None or now > I.t_expire:
        return False, 'expired'              # 超时 = 未同意
    if state_delta(I.H_state, state_hash(plan)) > THETA_CHANGE:
        return False, 'state_changed'        # 必须重新确认
    return True, 'ok'

def consent_or_stop(I, plan, now, clocks):
    ok, why = intent_valid(I, plan, now)
    if not ok:
        # 安全停永远可用且不依赖通信；绝不把沉默/丢包当默认同意
        return safe_stop(plan, why)
    return proceed(plan)
```

### IP-150 TPCX（三时钟探-诺-演++）

```python
def tpce_plus_plus(x0, M, plan, clocks, operators):
    route, log = plan_on_map(M, plan.task, risk_model)
    while route.checkpoints:
        cp = route.next()
        # ① 三钟对齐 + 视界预测

                    eps_clk=clock_skew_bound())

        decision = plcp_commit(plan, M, now(), clocks)
        if decision.kind == 'commit':
            # ⑥⑦ 租约/意图复核后执行

                commit(decision.prefix, decision.R, decision.h)
                continue
            decision = degrade_or_stop(plan, 'late_lease_or_consent')
        # 四态：改道 / 降档 / 重协商 / 安全停
        if decision.kind == 'reroute':
            route = reroute(M, cp, risk_model); continue
        if decision.kind == 'renegotiate':
            return renegotiate_or_stop(plan, M, clocks, tau_int=plan.tau_int)
        return safe_stop(plan, decision.reason)
    return route, log, M

def schedule_probes_by_leadtime(plan, now, delta_c):
    out = []
    for e in plan.upcoming_evidence:
        deadline = e.t_deadline - delta_c - e.probe_duration
        if now + e.probe_duration <= deadline:
            out.append(ProbeTask(e, latest_start=deadline - e.probe_duration))
        # else: 该探针已来不及，价值记 0，转入提前降档/绕行
    return sorted(out, key=lambda p: p.latest_start)

def voi_time_aware(pi, plan, inf, now, clocks):
    e = plan.evidence_of(pi)
    if now + e.probe_duration + clocks.delta_c_hat > e.t_deadline:
        return 0.0                                  # 错过提前量，价值归零
    return voi_meta_pessimistic(pi, plan, inf) * fresh_lower_bound(e.cls, e.age)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TAPE | O(\|E\|) 评估/检查点 | O(\|E\|) | φ 为存活下界、偏斜上界诚实、陈旧即缺失、无负证据 |
| PLCP | O(\|𝒯\|+\|𝒮\|²) 每视界 | O(\|𝒯\|) | 共模源完备、R_π 为上界、B_left≥0、视界单调收缩 |
| DRP | O(1)/操作 + O(\|ℛ\|) 抢占扫描 | O(\|agent\|·\|ℛ\|) | T_lease>Δ_max+2ε、版本单增、过期即退、等待有界 |
| TSM | O(\|𝒢_v\|) 检索 | O(\|ℰ\|+\|ℛ\|) | 按执行时刻过滤、过期隔离、区间回溯完整 |
| LAC | O(1) 校验 | O(\|操作者\|) | 沉默/超时非同意、τ_expire≤τ_max、安全停通信无关 |
| TPCX | O(\|CP\|·(k_p+k_r)·(C_VOI+d_GNN)+\|CP\|·A\*) | O(\|V\|+\|σ\|+\|𝒢\|) | 三钟单调、提前量硬约束、四态完备 |

**正确性定理（Time-Aware Commitment soundness, TACT）**
假设 A41–A45（第 58 轮）成立；并新增：
- **(A46) 新鲜度诚实**：对每类证据，φ_c(ℓ)=exp(−∫₀^ℓ λ̄_c) 是真实存活概率的下界（λ̄_c≥λ_c），执行时刻预测误差 ≤ε_plan，时钟偏斜 ≤ε_clk；τ_max 为硬上界。
- **(A47) 共模完备**：共享失效源集合 𝒮 覆盖所有跨任务共享的失效来源，r_i、r_s^cm 为保守上界，故 R_π=Σr_i+Σr_s^cm ≥ 真实计划失效概率。
- **(A48) 租约互斥**：部分同步下 Δ_c≤Δ_c^max、偏斜≤ε_clk、T_lease>Δ_c^max+2ε_clk、续约留 guard、版本单增；过期租约不得继续使用。
- **(A49) 同意时效**：意图在 t_expire 或 Δ_state>θ_change 时强制作废并重确认；沉默/超时/丢包一律记为未同意；安全停不依赖通信。
- **(A50) 时序记忆**：检索按预测执行时刻过滤、过期边进隔离区、时间窗证伪回溯完整、过期边不进不可逆必要集。

则：
1. **时效承诺健全性**：
   `P(计划失效) ≤ R_π + Σ_e (1−φ_c(â_e))·1[e 被使用] + δ_lease + δ_consent + δ_mem`，
   在 A48/A49 下 `δ_lease=δ_consent=0`；A46/A50 下陈旧证据的贡献被 `(1−φ_c(â_e))` 显式计入而非忽略。
2. **延迟单调性**：设 `CommitSet(Δ)` 为延迟参数 Δ 下可承诺的视界集合，则 `Δ1≤Δ2 ⇒ CommitSet(Δ1)⊇CommitSet(Δ2)`。因为 â 随 Δ 单增、φ_c 非增、h_c 随证据剩余寿命单减，延迟只能收缩承诺集，绝不新增不安全承诺。
3. **新鲜度单调性**：同一证据的可采性随年龄非增（φ_c 非增、τ_max 硬截断）；陈旧证据只从可用集移除，不被读成负证据，也不增加置信——保证"沉默不是好消息"。
4. **租约互斥性**：A48 下同一资源不存在两个同时有效的租约，故不存在两个代理对同一资源同时做不可逆接触（无重复承诺）。
5. **风险预算健全性**：`B_left(t)=B_plan−spent(t)+replenish(t) ≥ 0` 恒成立；`R_π(已承诺前缀) ≤ B_plan`；补充速率 ≤ν，计划内不借支未来。
6. **带 fallback 的终止性**：TPCX 在 {承诺, 改道, 降档, 重协商, 安全停} 内终止；所有等待被租约到期或 τ_expire 上界；每枚探针满足 `now+probe_duration+Δ_c ≤ t_deadline`，否则其价值记 0 并转入提前降档，故不存在"探针晚于截止期"的死循环。
7. **部署界**（对检查点取联合界）：
```
P_safe ≥ 1 − Σ_cp (R_π/cp + δ_fresh + δ_lease + δ_consent + δ_mem + δ_ft·1[回滚窗口]
                   + δ_kg·1[检索失败] + δ_ux·1[μ_mis>θ_mis] + δ_ood·α_conf)
         − P(共模源漏算) − P(时钟失步未被检出) − P(fallback 不可达)
```

**三条安全单向通道（强化第 57/58 轮交互单调性）**：本轮所有新机制只能通过"证据更少（陈旧即缺失）/ 视界更短 / 风险更保守 / 动作更慢（重确认）/ 退到 fallback"影响系统；没有任何新机制能让系统在延迟或陈旧证据下"更敢赌"。

## 6. 本轮最大风险

**一句话**：本轮把安全承诺从"证据是否可信"改为"证据在承诺执行时是否仍然可信"，并把计划级风险当作可加预算；最大风险是**时效模型与共模风险估计的系统性错误**——若世界变化的危险率被低估、或共享失效源被漏算，系统会在"证据看着新鲜、每步风险都低于阈值"的假象下，把一个长计划整体推入不可逆区域，而延迟恰好让纠错信息来迟；必须以危险率上界、陈旧即缺失、租约互斥、计划风险上界与安全停默认值五重护栏，宁可在延迟中短视保守，也不在陈旧证据上长远乐观。
