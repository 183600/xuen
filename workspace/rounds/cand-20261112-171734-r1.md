# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 7 轮；本轮灵感：「模型预测控制」×「失败恢复」）

> 第 60 轮的 SGEC 把反馈闭环从「执行层→证据层」升级为「场景→意图→阻抗→执行→证据→场景」，但仍留三个根本缺口：
> 1. **反应式适应的前瞻缺失**：SSM 用 Kalman 滤波对当前遥测做后验更新，π_scene(K|z) 是静态场景先验，没有对未来 H 步的接触力/轨迹/场景切换做 rollout；所谓「先认知后执行」仍是单步先验，场景切换只能被观测到之后才收敛——仍是「先发生、再适应」。
> 2. **静态护栏的恢复缺失**：第 60 轮的四重护栏（置信度回退、意图超时、EPIR 双保险、SIC 校验）是彼此独立的静态 fallback，没有失败分类、没有恢复轨迹、没有恢复时限保证；一个层级失败会向另一层传播（场景误判→约束错误→证据链污染），缺少「检测-隔离-重构-恢复」的闭环。
> 3. **认知乐观的鲁棒缺失**：SIC 用固定阈值 τ_scene=0.7 判定有效性，缺乏「认知误差有界 ⇒ 执行约束仍满足」的形式化保证；一旦认知偏差超过阈值却未触发回退，就会重演「证据层高度确定、执行层灾难性失效」的抽象泄漏。

## 0. 直觉与动机

**灵感 1（模型预测控制 → 预测-恢复 MPC，PR-MPC）**
直觉：第 60 轮把 K_safe 当作「一个安全集合」，只问「当前该选哪个 K」。MPC 的洞见是：**安全不是一个点，而是一条在 H 步时域上满足约束的轨迹**。于是把 K 从标量/向量升级为阻抗序列 K_{t:t+H-1}，用滚动时域优化：
- predict：给定候选阻抗序列，预测未来接触力 f̂_{t+k}、轨迹 x̂_{t+k}、场景信念 b_{t+k}；
- optimize：在约束收紧后的可行域内最小化「任务误差 + 场景切换代价 + 意图偏离 + 证据成本 + 恢复风险」；
- act：只执行第一步 K_{t|t}；
- replan：下一拍用真实遥测重算，形成「预测-执行-再预测」的前瞻闭环。
关键洞见：**「先认知后执行」应升级为「先预测后收敛」**——K 的边界不是在场景发生后收窄，而是在预测到场景即将发生时沿时域平滑收窄。

**灵感 2（失败恢复 → 失败分类 + 预置备份计划 BCP）**
直觉：真正的恢复不是「出事后回退」，而是**在每一步都保留一条已经验证可行的备份轨迹**。把失败分为场景/意图/接触/证据/预算/时限六类；每类有检测器（残差、CUSUM、超时、seq 间隙）与隔离层；恢复不是单一 fallback，而是分级策略 R0 重规划 → R1 切备份 → R2 保守降级 → R3 安全停机。关键洞见：**MPC 的递归可行性天然给出「恢复可行性」**——只要每步都维护一条通向终端不变集 S_inv 的备份轨迹，任何时刻切换都有界时间 T_rec 内可达安全，且 T_rec ≤ T_safe（违约前剩余时间）。

**灵感 3（鲁棒 MPC → 认知管状安全包络 TSE）**
直觉：认知误差（场景误判、意图误解）不是噪声，而是**有界扰动 w ∈ W**。用 tube MPC 把标称预测轨迹 x̄ 外包一条管 Z(ρ)，实际状态被约束在 x̄ ⊕ Z 内；约束按 Z 收紧。关键洞见：**置信度越低，管越粗，约束越紧**：ρ_scene = ρ0 + α(1 - scene_conf)，ρ_intent = ρ0 + β(1 - intent_conf)。这样「认知先行」的激进程度被自动兑换成「执行安全」的保守裕度——认知越不确定，K 越保守，从形式上杜绝「认知超过执行安全」。

**灵感 4（合流 → 预测-恢复闭环 PRCL）**
直觉：PR-MPC 给出预测轨迹与当前最优 K；BCP 给出任意时刻可切的备份轨迹；FRP 在残差越界时触发分级恢复；TSE 保证恢复期间约束不破；EPIR 把恢复证书 J_rec 接入证据链。形成外层「预测→优化→执行→观测→恢复→更新」闭环，内层「检测→隔离→重构→恢复→复盘」闭环。

**灵感 5（PCE+++++ → 预测-恢复预算）**
直觉：第 60 轮四维认知预算需再叠加两维：B_pred（H 步 rollout 的算力、OCP 求解次数、模型更新频率）与 B_rec（备份轨迹重校验次数、恢复重试、降级层级）。关键洞见：**时域长度 H 本身是预算变量**：B_pred 充足 ⇒ 长 H + 细粒度管；B_pred 紧张 ⇒ 短 H + 粗管 + 提前切备份；B_rec 耗尽 ⇒ 直接降级到 R3 安全停机，而不是继续乐观预测。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（预测-恢复 MPC，PR-MPC）** 六元组 Π = (f, H, X, U, W, J)。在时刻 t 求解有限时域最优控制问题：
```
min_{U_t} J_t = Σ_{k=0}^{H-1} ℓ(x_{t+k|t}, u_{t+k|t}, b_{t+k|t}) + V_f(x_{t+H|t}) + λ_ρ·ρ_t
s.t.  x_{t+k+1|t} = f(x_{t+k|t}, u_{t+k|t}) + w_k,  w_k ∈ W(ρ_t)
      x_{t+k|t} ∈ X_{k,t} = X ⊖ Z_k(ρ_t)          (管状收紧约束)
      u_{t+k|t} ∈ U
      b_{t+k+1|t} = T(b_{t+k|t}, u_{t+k|t})        (场景信念转移)
      ∃ Π_b(x_{t+k|t}) 在 T_safe - (k+1)Δt 内到达 S_inv   (备份可行性)
      x_{t+H|t} ∈ X_f                              (终端不变集)
```
执行 u_{t|t} = K_{t|t}，下一拍以新观测重建 OCP，构成滚动时域。ℓ = ℓ_task + λ_s·ℓ_scene_switch + λ_i·ℓ_intent_dev + λ_e·ℓ_evidence + λ_r·R_recovery。

**定义 162（场景转移预测 PSE）** 场景预测模型 Φ = (T, O, b_0, H_s)。其中：
- **信念转移**：b_{t+1} = T(b_t, u_t)，T_{ij} = P(z_{t+1}=z_j | z_t=z_i, u_t) 由离线示范 + 在线观测更新；
- **观测模型**：o_t ~ O(·|z_t)，用于贝叶斯更新 b_t ← η·O(o_t|z_t)·(T^T b_{t-1})；
- **预测场景先验**：π̂_scene(K|t) = Σ_{k=0}^{H_s} γ^k Σ_z b_{t+k|t}(z)·π_scene(K|z)，γ∈(0,1] 为时域折扣；
- **前瞻探针准则**：VOI_H = E[J_t | 不探测] - E[J_t | 探测] - cost_probe；VOI_H > 0 才消耗 B_scene 主动探测。

**定义 163（失败分类与恢复策略 FRP）** 失败空间 F = {F_scene, F_intent, F_contact, F_ros, F_budget, F_deadline}，恢复策略 ρ = (D, I, R, T_rec)：
- **检测** D：残差 r_t = ||y_t - ŷ_{t|t-1}||，CUSUM g_t = max(0, g_{t-1} + r_t - ν)，g_t > h 判失败；
- **隔离** I：故障签名矩阵 M_{F×L} 把残差/超时/seq 间隙映射到失败类，只隔离受影响层；
- **恢复动作集** R = {R0 重规划, R1 切备份 Π_b, R2 保守降级（降 K_p、限 v_max、缩 H）, R3 安全停机}；
- **恢复时限** T_rec(f) = t_recover - t_detect，要求 T_rec(f) ≤ T_safe(f)，否则强制升级到 R3。

**定义 164（认知管状安全包络 TSE）** 给定认知扰动集 W(ρ) = {w : ||w||_∞ ≤ ρ}，标称轨迹 x̄_{0:H}，管截面 Z_0={0}，Z_{k+1} = A Z_k ⊕ W(ρ)（非线性时用可达集近似）。自适应半径：
```
ρ_t = ρ_0 + α·(1 - scene_conf_t) + β·(1 - intent_conf_t) + δ·model_mismatch_t
```
约束收紧 X_{k,t} = X ⊖ Z_k(ρ_t)。**安全不变式**：若 x_t ∈ x̄_t ⊕ Z_t 且后续控制按标称策略，则 ∀k: x_{t+k} ∈ x̄_{t+k} ⊕ Z_{t+k} ⊆ X。若 X_{k,t} = ∅ ⇒ 触发 FRP（管过粗，认知不可用）。

**定义 165（备份恢复计划 BCP）** 备份计划 Π_b = (u^b_{0:H_b-1}, S_inv, T_safe) 满足：
- **可达性**：从任意 x ∈ x̄_t ⊕ Z_t 出发，沿 Π_b 在 H_b·Δt ≤ T_safe 内进入 S_inv；
- **不变性**：S_inv 对 u^b 正不变且满足全部执行约束；
- **保值性**：每个控制周期重校验一次；若校验失败，立即在旧计划失效前重算，否则升级 R2/R3；
- **切换代价**：switch_cost(Π, Π_b) = ||u_{t|t} - u^b_0||_Q ≤ ε_switch，避免恢复瞬间冲击。

**定义 166（预测-恢复闭环 PRCL）** 算子 PRCL(M, scene, intent, delta_f_req)：
```
① R_scene.update(obs) → b_t, z_t
② PSE.rollout(b_t, H) → {b_{t+k|t}}, π̂_scene
③ TSE.compute_radius(scene_conf, intent_conf, mismatch) → ρ_t, X_{k,t}
④ PR-MPC.solve(π̂_scene, X_{k,t}, Π_b) → U*_t, backup_feasible
⑤ if not backup_feasible: FRP.trigger(F_contact) → R1/R2
⑥ execute(K_{t|t}); EPIR.append(EV_exec); telemetry ← wait_contact()
⑦ if FRP.detect(residual, seq_gap, timeout): FRP.isolate → FRP.recover → J_rec
⑧ XMC++/CLEP: update belief, scene_conf, intent_conf, model_mismatch
⑨ if B_pred or B_rec exhausted: shrink H / escalate R2
⑩ Return (K_{t|t}, b_t, J_rec, Π_b.status, S_local.status)
```

**定义 167（预测-恢复预算 PCE+++++）** B_pr = (B_pred, B_rec, B_cog)，其中 B_cog=(B_scene,B_intent,B_ros,B_exec) 沿用第 60 轮：
- **B_pred** = (OCP_solves_per_sec, Horizon_H_max, Model_update_rate)；
- **B_rec** = (Backup_revalidations, Recovery_retries, Degrade_levels)；
- **预算-时域耦合**：H_t = clip(H_max·B_pred^remain/B_pred^total, H_min, H_max)；B_rec 剩余越少，恢复策略越早升级（R2→R3）。

**定义 168（恢复证书 J_rec）** J_rec = (f_class, t_detect, t_isolate, t_recover, Δx_rec, margin_min, hash_chain, success)。验证条件：
```
J_rec.valid ⇔ t_recover - t_detect ≤ T_safe(f_class)
             ∧ margin_min ≥ 0
             ∧ hash_chain ≡ EPIR.verify(seq_id 区间)
             ∧ success ∈ {R0,R1,R2,R3}
```
J_rec 由 EPIR 持久化并上传云端，使「恢复合规性」成为可审计证据，与第 60 轮 EV-exec 链同源。

### IP-161 PR-MPC（预测-恢复滚动优化）

```python
class PredictiveRecoveryMPC:
    def __init__(self, f, H=10, dt=0.05, horizon_min=3):
        self.f, self.H, self.dt, self.H_min = f, H, dt, horizon_min
        self.backup = BackupPlanManager(f, dt)
        self.tube = TubeSafetyEnvelope()

    def solve(self, x0, scene_belief, K_prev, budget):
        H = budget.adapt_horizon(self.H, self.H_min)
        rho = self.tube.radius(scene_belief)
        X_tight = self.tube.tighten_constraints(H, rho)
        if X_tight is None:
            return None, False                      # 管过粗 → 触发 FRP
        U = warm_start(K_prev, H)
        for _ in range(self.max_iter):
            traj = self.rollout(x0, U, scene_belief, H)
            U = self.optimize(traj, X_tight, budget)
        feasible = self.backup.verify(x0, traj, H, rho)
        return U[0], feasible

    def rollout(self, x, U, b, H):
        xs, bs = [x], [b]
        for k in range(H):
            b = self.pse.transition(b, U[k])
            x = self.f(x, U[k])
            xs.append(x); bs.append(b)
        return xs, bs
```

### IP-162 PSE（场景转移预测）

```python
class PredictiveSceneEvolution:
    def __init__(self, scenes, transitions, gamma=0.9):
        self.scenes, self.T, self.gamma = scenes, transitions, gamma

    def rollout(self, b0, H):
        bs = [b0]
        for _ in range(H):
            bs.append(self.T.T @ bs[-1])
        return bs

    def predictive_prior(self, bs, scene_priors):
        w = sum(self.gamma**k * b for k, b in enumerate(bs))
        w /= w.sum()
        return sum(w[i] * scene_priors[s] for i, s in enumerate(self.scenes))

    def should_probe(self, J_no_probe, J_with_probe, cost_probe):
        return (J_no_probe - J_with_probe - cost_probe) > 0
```

```python
class FailureRecoveryPolicy:
    def __init__(self, T_safe):
        self.T_safe = T_safe
        self.cusum = {f: 0.0 for f in FAILURES}
        self.level = 0                               # R0..R3

    def detect(self, residual, seq_gap, elapsed, budget_left):

        hits = []
        if self.cusum['F_contact'] > H_TH: hits.append('F_contact')
        if seq_gap > 1: hits.append('F_ros')
        if elapsed > TAU_INTENT: hits.append('F_intent')
        if budget_left <= 0: hits.append('F_budget')

        if f_class == 'F_intent':   return R_DEFAULT_CONSTRAINT
        if f_class == 'F_budget':   return R_DEGRADE
        if backup.feasible(state):  return R_SWITCH_BACKUP
        return R_SAFE_STOP

        if predicted_T_rec(f_class) > self.T_safe[f_class]:
```

### IP-164 TSE（自适应管状包络）与 IP-165 BCP（备份计划）

```python
class TubeSafetyEnvelope:
    def radius(self, scene_belief):
        return RHO0 + ALPHA*(1-scene_belief.conf) \
               + BETA*(1-scene_belief.intent_conf) \
               + DELTA*scene_belief.model_mismatch

    def tube_sets(self, A, W, H):
        Z = [np.zeros(A.shape[0])]
        for _ in range(H):
            Z.append(A @ Z[-1] + W)
        return Z

    def tighten_constraints(self, X, Z):
        if np.any(Z > X): return None
        return X - Z


class BackupPlanManager:
    def __init__(self, f, dt, T_safe=0.5):
        self.f, self.dt, self.T_safe = f, dt, T_safe
        self.plan = None

    def verify(self, x, traj, H, rho):
        if self.plan is None: return False
        reachable = self.simulate(self.plan.u, x, self.plan.H_b)
        return self.in_invariant(reachable[-1]) and \
               self.within_time(self.plan.H_b*self.dt) and \
               self.constraints_ok(reachable) and \
               self.switch_cost_ok(traj[0], self.plan.u[0])

    def revalidate_or_escalate(self, x, budget):
        if self.verify(x, None, 0, 0):
            budget.B_rec -= 1
            return self.plan
        return None                                  # 交由 FRP 升级 R2/R3
```

### IP-166 PRCL（预测-恢复闭环）与 IP-168 J_rec

```python
def predictive_recovery_loop(M, scene, intent, delta_f_req):
    b = M.scene_model.update(M.telem_force, M.telem_pos)
    bs = M.pse.rollout(b, M.H)
    prior = M.pse.predictive_prior(bs, M.scene_priors)

    U, feasible = M.prmpc.solve(M.state, b, M.current_K, M.budget)
    if not feasible:
        M.frp.recover('F_contact', M.state, M.prmpc.backup)
        U = M.prmpc.backup.plan.u
    K_cmd = U if np.ndim(U) else U[0]
    M = M.execute(K_cmd)
    ev = build_exec_evidence(M.telemetry, rho, K_cmd)
    M.epir.append(ev)
    hits = M.frp.detect(M.residual, M.seq_gap, M.intent_elapsed, M.budget.B_rec)

        M.epir.append(M.jrec.__dict__)
    M.scene_conf = update_confidence(M.scene_conf, ev)
```

### IP-167 PCE+++++（预测-恢复预算）

```python
class PredictiveRecoveryBudget:
    def __init__(self, B_pred=20, B_rec=5, cog=None):
        self.B_pred, self.B_rec = B_pred, B_rec
        self.cog = cog or CognitiveBudget()

    def adapt_horizon(self, H_max, H_min):
        if self.cog.is_scene_budget_exhausted(): return H_min
        load = min(1.0, self.B_pred / max(self.B_pred_total, 1))
        return int(np.clip(H_max * load, H_min, H_max))

    def can_recover(self):
        return self.B_rec > 0
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PR-MPC | O(Iter·H·n³) 求解 | O(H·n) | 递归可行 ⇒ 每拍存在可行控制 |
| PSE | O(N² + N·H) / 周期 | O(N·H) | 预测场景置信度收敛，VOI 判定不劣于盲目探测 |
| FRP | O(|F|) 检测 / O(1) 隔离 | O(|F|) | 六类失败全覆盖，T_rec ≤ T_safe |
| TSE | O(H·n²) 管传播 | O(H·n) | 有界认知扰动下约束满足 |
| BCP | O(H_b·n²) 重校验 | O(H_b·n) | 任意时刻存在备份轨迹 |
| PRCL | O(PR-MPC) / 周期 | 复用 | 预测-恢复闭环收敛 |

**正确性定理（PRISM）**：
设 A66–A71 成立：**(A66)** 动力学 f 在有界扰动 W 下 Lipschitz 连续；**(A67)** OCP 在 t=0 可行且终端集 X_f 为控制不变集；**(A68)** 管路 Z_k 为 W 的 k 步可达集上界；**(A69)** 失败检测器 D 对 F 的漏检率 ≤ ε_det；**(A70)** 备份计划 Π_b 每周期重校验；**(A71)** B_pred/B_rec 单调消耗且可观测。则：
1. **递归可行性**：若 PR-MPC 在 t 可行，则在 t+1 仍可行（tube + 终端不变集），不会因预测更新而失稳；
2. **管状安全性**：∀w_k ∈ W(ρ_t)，实际轨迹满足 x_{t+k} ∈ x̄_{t+k} ⊕ Z_k ⊆ X，即认知误差有界 ⇒ 执行约束不被突破；
3. **恢复有界性**：任一 f ∈ F，若 T_rec(f) > T_safe(f) 则强制 R3，故恢复过程必不晚于违约前完成；
4. **证据连续性**：J_rec 经 EPIR 的 seq_id+hash 校验加入证据链，恢复事件可审计、不丢失；
5. **预算安全性**：B_pred/B_rec 任一耗尽，H 缩短或恢复升级，预测不会在预算之外无限乐观。

### IP-161 PR-MPC（预测-恢复滚动优化）

```python
class PredictiveRecoveryMPC:
    def __init__(self, f, H=10, dt=0.05, horizon_min=3):
        self.f, self.H, self.dt, self.H_min = f, H, dt, horizon_min
        self.backup = BackupPlanManager(f, dt)
        self.tube = TubeSafetyEnvelope()

    def solve(self, x0, scene_belief, K_prev, budget):
        H = budget.adapt_horizon(self.H, self.H_min)
        rho = self.tube.radius(scene_belief)
        X_tight = self.tube.tighten_constraints(H, rho)
        if X_tight is None:
            return None, False                      # 管过粗 → 触发 FRP
        U = warm_start(K_prev, H)
        for _ in range(self.max_iter):
            traj = self.rollout(x0, U, scene_belief, H)
            U = self.optimize(traj, X_tight, budget)
        feasible = self.backup.verify(x0, traj, H, rho)
        return U[0], feasible

    def rollout(self, x, U, b, H):
        xs, bs = [x], [b]
        for k in range(H):
            b = self.pse.transition(b, U[k])
            x = self.f(x, U[k])
            xs.append(x); bs.append(b)
        return xs, bs
```

### IP-162 PSE（场景转移预测）

```python
class PredictiveSceneEvolution:
    def __init__(self, scenes, transitions, gamma=0.9):
        self.scenes, self.T, self.gamma = scenes, transitions, gamma

    def rollout(self, b0, H):
        bs = [b0]
        for _ in range(H):
            bs.append(self.T.T @ bs[-1])
        return bs

    def predictive_prior(self, bs, scene_priors):
        w = sum(self.gamma**k * b for k, b in enumerate(bs))
        w /= w.sum()
        return sum(w[i] * scene_priors[s] for i, s in enumerate(self.scenes))

    def should_probe(self, J_no_probe, J_with_probe, cost_probe):
        return (J_no_probe - J_with_probe - cost_probe) > 0
```

### IP-164 TSE（自适应管状安全包络）

```python
class TubeSafetyEnvelope:
    def radius(self, scene_belief):
        return RHO0 + ALPHA*(1-scene_belief.conf) \
               + BETA*(1-scene_belief.intent_conf) \
               + DELTA*scene_belief.model_mismatch

    def tube_sets(self, A, W, H):
        Z = [np.zeros(A.shape[0])]
        for _ in range(H):
            Z.append(A @ Z[-1] + W)
        return Z

    def tighten_constraints(self, X, Z):
        if np.any(Z > X): return None
        return X - Z
```

### IP-165 BCP（备份恢复计划）

```python
class BackupPlanManager:
    def __init__(self, f, dt, T_safe=0.5):
        self.f, self.dt, self.T_safe = f, dt, T_safe
        self.plan = None

    def verify(self, x, traj, H, rho):
        if self.plan is None: return False
        reachable = self.simulate(self.plan.u, x, self.plan.H_b)
        return self.in_invariant(reachable[-1]) and \
               self.within_time(self.plan.H_b*self.dt) and \
               self.constraints_ok(reachable) and \
               self.switch_cost_ok(traj[0], self.plan.u[0])

    def revalidate_or_escalate(self, x, budget):
        if self.verify(x, None, 0, 0):
            budget.B_rec -= 1
            return self.plan
        return None                                  # 交由 FRP 升级 R2/R3
```

```python
def predictive_recovery_loop(M, scene, intent, delta_f_req):
```

### IP-167 PCE+++++（预测-恢复预算）

```python
class PredictiveRecoveryBudget:
    def __init__(self, B_pred=20, B_rec=5, cog=None):
        self.B_pred, self.B_rec = B_pred, B_rec
        self.cog = cog or CognitiveBudget()

    def adapt_horizon(self, H_max, H_min):
        if self.cog.is_scene_budget_exhausted(): return H_min
        load = min(1.0, self.B_pred / max(self.B_pred_total, 1))
        return int(np.clip(H_max * load, H_min, H_max))

    def can_recover(self):
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
