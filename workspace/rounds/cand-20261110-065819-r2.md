# 第 42 轮（新循环第 2 轮） · 泛化能力 × 传感器融合：给证书装上「有效域」，让融合既收紧界又不掩盖域外新颖性（四层架构 v7）

> 承接第 41 轮 v18（IP-51/52/53：CAR × LCS × CMC）。第 41 轮把证书从「文档」变成「运行时守卫」，却留下一个更深的窟窿：**所有证书都只在标定分布与当前度量语义图上成立**。换个场景、换批标定、掉一个模态，守卫的 `m≥θ` 就可能从「证明」退化成「猜测」。第 41 轮自陈最大风险是「可用性崩塌」，但那是*已知的保守代价*；本轮要堵的是*未知的过自信*：融合让估计变紧，却可能把「域外」误当成「域内」，使证书在未见环境里静默失效。灵感词「泛化能力」「传感器融合」正好是同一枚硬币的两面——泛化要求证书携带**有效域**，融合既提供收紧界的冗余、也提供判断「是否还在域内」的新颖性信号。

## 0. 直觉与动机

**灵感 1（泛化能力 → 证书必须回答「在哪里成立」，而不是只说「成立」）**：第 41 轮的每条界都是分布内陈述：`m(x)≥θ` 只在 x 取自标定分布 P_cal 时被认证。部署分布 P_dep 一变，界就可能失效，而且失效是**静默**的——守卫照常判 `safe`，因为证书根本不知道自己在域外。泛化的直觉不是「要求界对全世界成立」（不可能），而是三个更弱但可证的要求：
1. **有效域 D**：证书附带一个由数据学出的上下文集合，明确「在 φ(x)∈D 内，我才担保」；φ 由融合一致性、语义图新颖性等可在线计算的特征构成。
2. **带罚的迁移界**：域内也不是原界照搬，而是扣掉一个由保形分位数（split/weighted conformal）给出的**泛化间隙 G_epi**；部署时用 `m_gen = m̂ − B_alea − G_epi` 而非 `m̂`。
3. **域外单调保守**：φ(x)∉D 或间隙吃光余量时，守卫只能判 unknown 并转向保守制度，绝不默认 safe。自适应保形（ACI）让 q 随时间更新，从而在持续漂移下维持*长程*覆盖，而不是一次性覆盖。
关键洞见：**泛化间隙沿组合可加**（union bound），技能越深、组合越多，可用 margin 越薄；这解释了为什么「可认证的组合泛化」必须与任务代数（IP-47）一起设计，而不能事后补。

**灵感 2（传感器融合 → 收紧的是 aleatoric，掩盖的是 epistemic）**：融合的直觉优势是冗余降噪：多模态互证能把状态不确定集缩小，从而把 B_t 收紧、把 ValidRegion 放大。但融合有两个陷阱：
- **共同模态误差不可被冗余消除**：所有模态共享的标定漂移/时间同步误差/地图错位，是相关性为 1 的误差；融合再紧也压不过一个**共模半径 ρ_cm**。
- **融合会「洗掉」新颖性**：一个在训练分布内拟合良好的学习型融合器，在域外仍可能输出低方差、高置信的错误估计；此时 aleatoric 很小、epistemic 却很大，总不确定度被系统性低估——**这恰恰是证书最危险的过自信来源**。
因此本轮的核心设计原则是**不确定性分解与分别扣减**：融合可以收紧 `B_alea`（且受 ρ_cm 地板约束），但**绝不能降低 `G_epi`**；而融合的跨模态一致性 κ 正好是「这帧是否还在域内」的非一致性分数，一举两得。

**耦合**：融合（IP-55）同时产出「更紧的 aleatoric 界」与「迁移所需的非一致性信号 κ」；泛化证书（IP-54）用 κ 构造有效域 D 与间隙 G_epi；迁移编排器（IP-56）用 `m_gen` 与 D 决定「信任迁移 / 在线重认证 / 域内有界采集 / 降级」。第 41 轮 CAR 的不变式因此升级为 **Inv(q) ⊆ {ValidRegion ∩ m_gen≥θ ∩ φ(x)∈D_q}**——「分布有效性」第一次被写成不变式，而不再靠部署者自觉。

## 1. 形式化定义

**定义 32（泛化证书对象 GC）**：证书由七元组 C=(m̂,B_alea,G_epi,L_m,t₀,δ,D) 表示，其中 m̂ 为标定得到的边际估计，B_alea 为融合给出的**偶然不确定**半径，G_epi 为**泛化间隙**（认识不确定的下界罚），L_m、t₀ 沿用第 41 轮保持时间，δ 为置信水平，D 为有效域（定义 33）。部署用**认证边际** m_gen(x)=m̂(x)−B_alea(x)−G_epi(x)；C 在 x 处**有效**当且仅当 m_gen(x)≥θ 且 φ(x)∈D。注意 B_alea 与 G_epi 分开扣减，禁止用融合的低 B_alea 抵消高 G_epi。

**定义 33（分布有效域 D 与自适应保形）**：取非一致性分数 s(φ(x))（融合一致性、语义图新颖度、表征到标定流形的距离等的合成）。在可交换标定集上取 split-conformal 分位数 q_{1−δ}，令 D={φ(x): s(φ(x))≤q_{1−δ}}；覆盖率满足 P_{P_cal}(φ∈D)≥1−δ。部署存在漂移时改用自适应保形（ACI）：q_{t+1}=clip(q_t+γ(α−err_t),q_min,q_max)，err_t 为本拍覆盖违约指示，α=δ；此式只保证**长程平均覆盖**，不保证逐拍覆盖（见风险）。存在协变量漂移且密度比 w 有界时，采用加权保形 q^{w}，把融合新颖度作为协变量以收窄区间。

**定义 34（融合认证估计 FCE 与偶然/认识分解）**：模态 j 输出 (x̂_j,β_j)，融合输出 (x̂,U_alea,κ)。在**不假设模态独立**的前提下，令 U_ind 为各模态误差球的 Minkowski 和（对任意相关结构 sound），并令共模半径 ρ_cm 为融合精度地板，取 B_alea=max{radius(U_ind),ρ_cm}。**命题（融合地板）**：任何融合器的偶然不确定半径不可能小于共模半径 ρ_cm；故 B_alea 可被多模态收紧，但存在不可约下界。一致性 κ(x)=max_j d(x̂_j,x̂)/β_j，同时作为定义 33 的非一致性信号；κ 大表示模态分歧或域外，必须抬高 G_epi，而不是压低 B_alea。

**定义 35（泛化感知三值守卫）**：守卫 g_e 输出 {safe,unsafe,unknown}：m_gen≥θ 且 φ∈D 为 safe；m_gen≤θ−h 为 unsafe；其余为 unknown。unknown 一律按单调保守性转向更保守制度（Degraded/SafeStop），绝不进入 Nominal。迁移仅当 φ∈D 且 G_epi≤margin slack 时被允许。

**定义 36（证书迁移保证与组合间隙）**：对部署分布 P_dep，应有 P_{P_dep}(m_true≥m_gen)≥1−δ−ε_shift，其中 ε_shift 由 ACI 的长程偏差或加权保形的密度比界控制。对技能组合 A⊗B（IP-47 乘积自动机），有 G_epi(A⊗B)≤G_epi(A)+G_epi(B)+G_int，其中 G_int 为交互项；即**泛化间隙按组合深度近线性累加**，深度 d 的组合至少需要 ΣG_epi 的 margin 预算。

**设计约束（分布单调保守性，扩展第 41 轮）**：不确定 ⇒ 更保守的规则现在包含三类来源——界过松、保持时间过期、**分布有效性不足（φ∉D 或 G_epi 超预算）**。该约束把「泛化失败」转化为可用性下降，而非漏报警；但允许在 Inv 内启用**有界校准子模式**（见 IP-56）安全地采集数据以扩张 D，从而把纯保守的死循环改造成「保守→采集→扩张→恢复」的闭环。

## 2. 三大产出设计

### 2.1 IP-54 CERT-GENERALIZATION（泛化证书 CG）
1. 保形校准管线：split-conformal 给出 q_{1−δ}；协变量漂移用融合新颖度做加权保形；持续漂移用 ACI 更新 q，附覆盖诊断曲线。
2. 有效域 D：由 κ、语义图新颖度、表征距离合成 φ，D 为分位数水平集；离线性价比优先用低维 φ，避免维数灾难。
3. 间隙模型与组合代数：G_epi 为上下文条件分位数；组合按定义 36 求和并给出深度预算；与 IP-47 类型检查联动。
4. 重认证触发：覆盖违约、κ 持续偏高、地图更新、标定漂移检测——任一触发即局部重校准或收缩 D。
5. 主动校准接口：把「哪些 φ 区域覆盖不足」输出给 IP-50 课程引擎，做覆盖导向采样（curriculum for coverage）。

### 2.2 IP-55 FUSION-CERTIFIED-ESTIMATION（融合认证估计 FCE）
1. 偶然/认识分解：TRI-FUSE 只负责 B_alea，认识项显式移交 IP-54，禁止融合内部「吸收」新颖性。
2. 相关稳健界：不假设模态独立，用 Minkowski 和给 sound 上界，并以共模半径 ρ_cm 作融合精度地板；模态 dropout 时 B_alea 单调增。
3. 一致性分数 κ：跨模态对齐残差/边界球归一化，作为新颖性与非一致性双重信号。
4. 语义图新颖度：度量语义图（IP-36）上到标定观测流形的距离，贡献认识项。
5. 输出契约：`(x̂,U_alea,κ,ρ_cm,δ)` 直接进 IP-54 / IP-56，不再输出「单一总不确定度」，从接口上杜绝混淆。

### 2.3 IP-56 TRANSFER-ORCHESTRATOR（迁移编排器 XTO）
1. 四路决策：信任迁移（φ∈D 且 m_gen≥θ）/ 在线重认证（边界带）/ 域内有界校准（覆盖缺口且可安全采集）/ 降级（不可采集或间隙超预算）。
2. 有界校准：仅在 Inv 与几何 CBF 约束的安全包络内规划探测轨迹，保证 Calibrate 子模式不破坏第 41 轮安全不变式。
3. 与 CAR/LCS 联动：CAR 守卫读 m_gen 与 D；LCS 新增 T_g 档——仅做有效域与间隙查询（近零成本），只有守卫未定时才升级到 T0–T3。
4. 预算：把校准/探索算力纳入每拍预算 Γ，避免「为了泛化把在线算力吃光」。
5. 看门狗：CMC 增加新颖性 trip——κ 或 G_epi 越界即 warn/trip，trip 强制 SafeStop 并记录用于后续校准。

## 4. 实验设计（E79–E84 硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E79 泛化覆盖有效性 | 未见场景上 m_gen 违约率；G_epi 尺度；D 覆盖部署样本比例；OOD AUROC | 违约率≤5%（δ=0.05）；G_epi median≤0.3×margin；D 覆盖≥90%；AUROC≥0.9 |
| E80 融合界可靠性 | 状态包含率（标称/单模态 dropout/标定漂移/共模误差）；B_alea 单调性 | 四场景≥1−δ；共模下不失效；dropout 后 B_alea 单调增 |
| E81 过自信检测 | 静默过自信率（接受证书却违约）；κ 与违约相关性；告警提前量 | <0.1%；相关≥0.8；提前≥5 拍 |
| E82 迁移守卫安全-可用 | 接受证书实测有效率；不安全事件；Nominal 占比；恢复时间 | ≥99%；0 起；≥65%；<2s |
| E83 组合泛化 | 深度≤3 组合覆盖；未见场景组合成功率；margin 开销 | 保持≥1−δ；≥80%；≤线性模型 1.5× |
| E84 有界校准效率 | 漂移后覆盖恢复所需 episodes/时间；校准算力占比；校准期安全 | ≤20 episodes 且≤60s；≤10%；0 事故 |

回退：E79 不通过（覆盖不达标或 G_epi 过松）→ 关闭跨场景迁移，改为逐场景重标定并收紧 δ；E80 不通过（相关稳健界失效）→ 只用最强单模态 + 最大化 ρ_cm；E81 不通过（检测不到过自信）→ 禁用融合收紧，仅保留 κ 作新颖性；E82 可用性不达标 → 放宽 Nominal 阈值/增设中间档；E83 不通过 → 限制组合深度并要求共享校准；E84 不通过 → 退回纯保守不采集（接受可用性损失）。

## 5. 本轮最大风险

**一句话**：保形覆盖是**平均意义**的，平均覆盖达标并不能保证那个真正致命的稀有尾事件也被覆盖；而把间隙做保守又会把有效域 D 压到只剩标定环境，使「可泛化证书」反而把系统锁死——因此必须同时以「安全关键尾事件的失效率」与「有效域覆盖率 / Nominal 占比」为守门指标，平均覆盖数字本身不能当护身符。

## 1. 符号体系（承接定义 32–36）

| G_epi | 泛化间隙 | 上下文条件保形分位数；φ∉D 时视为 +∞ |
| ρ_cm | 共模半径 | 全模态共享误差下界（相关性=1），融合不可约地板 |
| κ | 跨模态一致性/非一致性 | max_j d(x̂_j,x̂)/β_j；大 κ ⇒ 抬高 G_epi |
| D | 分布有效域 | {φ: s(φ)≤q_{1−δ}}；漂移下由 ACI 更新 q |
| U_ind | 相关稳健误差集 | 各模态误差球 Minkowski 和，sound 于任意相关结构 |
| ε_shift | 交换性违约界 | 由 ACI 长程偏差或加权保形密度比界控制 |
| G_int | 组合交互间隙 | G_epi(A⊗B) 中不可加部分 |
| T_g | 近零成本泛化档 | 只查 D 与 G_epi，守卫未定不升级 |

## 2. 关键算法（伪代码）

### IP-54 CG：保形校准 + 自适应覆盖
```
def fit_generalization(cal, alpha):
    scores = []
    for (x, m_true) in cal:
        m_hat, B_alea, phi = predict(x)
        scores.append(abs(m_true - (m_hat - B_alea)))   # 边际误差的非一致性
    q = quantile(scores, 1 - alpha)                      # split conformal
    return Cert(m_hat=..., G_epi=q, D=support(scores), delta=alpha)

def aci_update(q, err_t, alpha, gamma):
    return clip(q + gamma * (alpha - err_t), q_min, q_max)  # 长程平均覆盖

def in_domain(phi, D):
    return nonconformity(phi) <= D.q
```

### IP-55 FCE：相关稳健融合界 + 一致性
```
def fusion_certificate(mods, rho_cm, delta):
    x_f = weighted_fuse(mods)
    U_ind = minkowski_sum([ball(m.x_hat, m.beta) for m in mods])  # 不假设独立
    B = max(radius(U_ind), rho_cm)                  # 共模地板不可突破
    kappa = max(dist(m.x_hat, x_f) / m.beta for m in mods)
    return FusionCert(x_f, B, kappa, rho_cm, delta)

def on_modality_dropout(mods):
    return fusion_certificate(mods, rho_cm)          # B 必须单调不减
```

### IP-56 XTO：三值迁移守卫 + 有界校准
```
def transfer_guard(x, cert, guards, budget):
    m_gen = cert.m_hat - cert.B_alea - cert.G_epi
    phi = context(x)
    if not in_domain(phi, cert.D):
        return safe_calibrate_or_degrade(x, cert, phi, budget)
    if m_gen >= theta:      return SAFE
    if m_gen <= theta - h:  return UNSAFE
    return UNKNOWN -> conservative        # 单调保守

def safe_calibrate_or_degrade(x, cert, phi, budget):
    probe = coverage_directed_probe(phi, budget)
    if barrier_safe(probe, Inv) and budget_ok(probe, Gamma):
        return CALIBRATE(probe)           # 只在安全包络内采集以扩张 D
    return DEGRADE
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 正确性保证 |
|---|---|---|
| IP-54 保形拟合 | O(n_cal·cost(predict))，离线一次 | 可交换下 P(φ∈D)≥1−δ；ACI 给长程平均覆盖 |
| IP-54 在线查询 | O(1)+ACI 更新 | 域外 ⇒ unknown ⇒ 保守；不产生静默 safe |
| IP-55 融合界 | O(k·dim)，k 模态数 | U_ind 对任意相关结构 sound；B_alea≥ρ_cm |
| IP-55 一致性 | O(k) | κ 大 ⇒ 抬 G_epi，禁止反向下压 B |
| IP-56 迁移守卫 | 每拍 O(|Guard|)，通常 T_g | 三值单调；域外/超预算 ⇒ 保守或降级 |
| IP-56 有界校准 | 受 Γ 与 Inv/CBF 约束 | 校准轨迹不离开安全不变式；可随时中止 |
| IP-47 组合间隙 | O(|Q₁|·|Q₂|) | G_epi(A⊗B)≤ΣG_epi+G_int；深度预算可检查 |
| IP-50 覆盖课程 | 摊销 O(1)/步 | 覆盖缺口单调收敛（启发式，非硬保证） |

## 5. 风险与缓解

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 平均覆盖≠尾事件覆盖（最危险） | 高 | 条件/尾感知保形、CVaR 型风险、对安全关键守卫单独收紧 δ；尾事件回归测试 |
| 泛化间隙过松/有效域过窄 → 可用性崩塌 | 高 | 加权保形 + 融合协变量收窄；覆盖导向课程扩张 D；E82 以 Nominal 占比守门 |
| 共模误差超出 ρ_cm → 融合界失效 | 高 | ρ_cm 由标定漂移/时间同步上界保守给出；在线相关检测；超界即关融合 |
| 漂移过快 ACI 追不上 | 中 | 变点检测 + 提高 γ + 重置 D；漂移期强制降级 |
| 校准集与部署非交换 | 中 | 加权保形要求密度比有界；无界时退回 ACI + 增大 G_epi |
| 组合间隙线性累加 → 深技能不可用 | 中 | 共享校准池、assume-guarantee 分解、限制深度 |
| 有界校准反而不安全 | 中 | 严格 Inv+CBF 包络；校准预算与回退；CMC 看门狗随时 trip |
| 语义图新颖度误判（假新/false-OOD） | 低-中 | 多信号合成 + 滞回；假新只降可用，不降安全 |

## 6. 本轮最大风险

**一句话**：保形覆盖是平均意义的，平均覆盖达标并不保证那个真正致命的稀有尾事件被覆盖；而把间隙做保守又会把有效域 D 压到只剩标定环境，使「可泛化证书」反成「锁死证书」——因此必须同时以「安全关键尾事件失效率」与「有效域覆盖率 / Nominal 占比」为守门指标，平均覆盖数字不能当护身符。
