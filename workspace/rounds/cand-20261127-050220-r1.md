### 第 1 轮灵感驱动研究记录

**灵感词**：分布外泛化、数字孪生

**直觉与动机**：
现有 USMC（IP-440–443）把 SOC / FCC / LSC 三张证书叠成 v24 准入门，但它默认了一个从未写进类型的前提：**证书只在标定工况下成立**。SOC 的 FEM 用名义材料、几何与载荷；FCC 的无源性在录制的一段 F/v 历史上验证；LSC 的 C^hom 表按名义晶格拓扑离线构建——三者都是「点证书」（point certificate），不携带「对哪个工况分布有效」的字段。部署中一旦出现新负载、新地形、温升、关节磨损或结构损伤，证书哈希不变，结论却已失效。这就是「分布外泛化」对本框架的精确含义：**OOD 不是一个检测精度问题，而是证书缺少一个分布域自变量**。

「数字孪生」给了我们一条诱人的出路：既然真实工况难以穷举，就在孪生体 M̂_τ 里「预演」任意工况 θ 下的 SOC / FCC / LSC。但孪生体与物理本体之间存在 sim-to-real gap；更棘手的是，**gap 本身也只在标定分布上被校准过**。用孪生体去证明 OOD 安全，等于拿一个「仅在 ID 上可信的误差界」去外推 OOD——这是一个证书塔的递归问题。

核心洞见：**证书不是真值，而是「工况 θ ↦ 真值」的偏函数；数字孪生是一个带误差界的外推预言机，但它的误差界本身也是一张有分布域的证书。安全 = 这座证书塔的基域始终覆盖当前 θ，否则 fail-closed。** 我们不问「孪生体能否泛化到 OOD」，而问「孪生体的 gap 证书在 θ 处是否仍然有效、失效前能否安全降级」。因此本轮不是给 v24 再加一条更严的约束，而是给每张证书补上它一直隐含的自变量——**分布域**——并让孪生体成为在域边界外唯一合法的外推仪器。

**形式化目标**：
1. 定义工况向量 θ 与分布域证书（DDC）：给 SOC / FCC / LSC 每张证书附上有效域 D_cert 与覆盖下界 1−α_cov；组合时分布域取交、覆盖按 union bound 退化；无域字段的证书不可入图（「无分布域不入图」）。
2. 定义孪生保真证书（TFC）：在配对标定集上用 split conformal 取残差分位 q_δ、用残差回归 ĝ(θ) 建模系统偏差、用残差差商估计 Lipschitz 常数 L_g，得到随 θ 变化的 gap 上界 η(θ)=|ĝ(θ)|+q_δ+L_g·dist(θ,D_cal)，以及孪生有效域 D_twin={θ: η(θ)≤η_max}。
3. 定义孪生接地外推（TGE）：对 θ∈D_twin∖D_cert，用孪生预测 q̂ 膨胀 η(θ) 后复核 SOC / FCC / LSC，得到保守「外推证书」；θ∉D_twin 一律 fail-closed。并用分布无关的硬物理包络（能量守恒、强度上界、质量守恒）兜底 gap 界被低估的情形。
4. 构建 v25 准入门 USMC-T = USMC ∩ DDC ∩ (TFC∘TGE)，证明 Exec_v25 ⊆ Exec_v24^naive ⊆ Exec_v23（相对 v24 的乐观点证书集），且域内 Exec_v25 = Exec_v24；域外则满足 Exec_v24^failclosed ⊆ Exec_v25。
5. 给出「无免费泛化」引理：组合只能收窄分布域，孪生仿真不能扩张受信域，只有真实配对标定（且 fit/audit 分离）能扩张 D_twin；任何「组合后泛化更好」的主张都必须记账到新数据上。

## 1. 关键算法骨架（在 IP-443 骨架上扩展）

```python
# ============================================================
# IP-444 Twin Fidelity Certificate (TFC) — 孪生保真证书
# ============================================================
@dataclass
class TwinFidelityCertificate:
    twin: 'DigitalTwin'                 # M̂_τ，含版本号 τ 与训练谱系
    calib_theta: Tensor                 # [N_c, d] 配对标定工况
    calib_residual: Tensor              # [N_c, m] r_i = q_real - q̂
    delta: float = 0.05                 # 覆盖失败概率上界
    eta_max: float = 0.10               # 保真阈值（归一化 QoI）
    kappa: float = 1.5                  # Lipschitz 保守系数
    tau: str = 'twin-v0'
    prov: dict = field(default_factory=dict)

    def calibrate(self) -> None:
        """只在 fit 集上做残差回归与 conformal 分位；audit 集封存"""
        self.g_hat = fit_regressor(self.calib_theta, self.calib_residual)
        centered = self.calib_residual - self.g_hat(self.calib_theta)
        self.q_delta = conformal_upper_quantile(centered.abs(), self.delta)
        self.L_g = self.kappa * lipschitz_from_differences(
            self.calib_theta, centered)
        self._tree = build_kdtree(self.calib_theta)

    def gap_bound(self, theta: Tensor) -> Tensor:
        """η(θ) = |ĝ(θ)| + q_δ + L_g · dist(θ, D_cal)，逐 QoI"""
        d = self._tree.distance(theta)          # 到最近标定点的距离
        d = self._cover_corrected_distance(d)   # 稀疏区按 k-NN 半径放大
        return self.g_hat(theta).abs() + self.q_delta + self.L_g * d

    def in_domain(self, theta: Tensor) -> bool:
        return bool((self.gap_bound(theta) <= self.eta_max).all())

    def verify(self, theta: Tensor, q_real: Tensor = None,
               e_value: float = None) -> bool:
        # 1) 孪生受信域：η(θ) ≤ η_max，否则 fail-closed
        if not self.in_domain(theta):
            return False
        # 2) anytime-valid 漂移监测：e-value 超阈即拒绝可交换性
        if e_value is not None and e_value > 1.0 / self.delta:
            return False
        # 3) 在线抽查：真实-孪生残差必须落在 gap 界内
        if q_real is not None:
            r = (q_real - self.twin.predict(theta)).abs()
            return bool((r <= self.gap_bound(theta)).all())
        return True

    def on_twin_update(self, new_tau: str) -> None:
        """孪生版本一变，旧 gap 证书立即失效，必须重标定"""
        if new_tau != self.tau:
            self.tau = new_tau
            self.calibrate()


# ============================================================
# IP-445 Distributional Domain Certificate (DDC) — 分布域证书
# ============================================================
@dataclass
class DistributionalDomainCertificate:
    D_cert: 'Domain'                    # 有效域
    P_cert: str                         # 分布族标识
    alpha_cov: float = 0.05             # 域内覆盖失败上界
    ttl: float = 60.0                   # 强制再标定周期（秒）
    last_calib: float = 0.0
    e_proc: 'EProcess' = None           # 可交换性 e-process
    prov: dict = field(default_factory=dict)

    def admits(self, theta: Tensor, t_now: float) -> bool:
        # TTL 与检测解耦：检测只加速停机，TTL 才是保证
        if t_now - self.last_calib > self.ttl:
            return False
        if self.e_proc is not None and \
           self.e_proc.e_value() > 1.0 / self.alpha_cov:
            return False
        return self.D_cert.contains(theta)

    def compose(self, other: 'DistributionalDomainCertificate'):
        """组合只能收窄域、降低覆盖；绝不扩张"""
        return DistributionalDomainCertificate(
            D_cert=self.D_cert.intersect(other.D_cert),
            P_cert=f'({self.P_cert}) ∩ ({other.P_cert})',
            alpha_cov=min(1.0, self.alpha_cov + other.alpha_cov),  # union bound
            ttl=min(self.ttl, other.ttl),
            last_calib=max(self.last_calib, other.last_calib),
            e_proc=self.e_proc,
        )


# ============================================================
# IP-446 Twin-Grounded Extrapolator (TGE) — 孪生接地外推器
# ============================================================
@dataclass
class TwinGroundedExtrapolator:
    tfc: TwinFidelityCertificate
    hard_env: 'HardPhysicalEnvelope'    # 分布无关硬边界 H(θ,π)
    epsilon_hard: float = 1e-6

    def robust_verify(self, q_hat: Tensor, eta: Tensor,
                      spec: 'Spec') -> bool:
        """上界量加 gap，下界量减 gap；双侧量取绝对值加 gap"""
        upper_ok = (q_hat.upper + eta <= spec.upper + self.epsilon_hard).all()
        lower_ok = (q_hat.lower - eta >= spec.lower - self.epsilon_hard).all()
        return bool(upper_ok and lower_ok)

    def certify(self, plan, theta: Tensor, base_certs: dict) -> tuple[bool, str]:
        # 0) 硬物理包络：与分布无关，任何 θ 下都必须成立（兜底）
        if not self.hard_env.satisfiable(theta, plan):
            return False, 'hard_envelope_violation'
        # 1) 域内：直接用 v24 点证书（此时 gap 已被实测覆盖）
        if all(c.ddc.D_cert.contains(theta) for c in base_certs.values()):
            return base_certs_verify(base_certs, theta), 'in_domain'
        # 2) 域外但孪生受信：外推 + gap 膨胀
        if self.tfc.in_domain(theta):
            q_hat = self.tfc.twin.predict(theta, plan)      # 逐 QoI 区间
            eta = self.tfc.gap_bound(theta)
            ok = all(self.robust_verify(q_hat[k], eta[k], base_certs[k].spec)
                     for k in base_certs)
            return ok, 'twin_extrapolated'
        # 3) 孪生也不受信：fail-closed
        return False, 'out_of_twin_domain'


# ============================================================
# IP-447 Unified Twin-Structural Gate (USMC-T) — v25 准入门
# ============================================================
@dataclass
class UnifiedTwinStructuralGate:
    usmc: 'UnifiedStructuralMechanicalCertificate'   # v24 四证
    ddcs: dict                          # 每张证书的 DDC
    tfc: TwinFidelityCertificate
    tge: TwinGroundedExtrapolator
    fallback: str = 'conservative_static'

    def admits(self, plan, theta, t_now, sensor, e_value=None) -> bool:
        # 1) v24 基础结构-力学证书（名义工况点验证）
        if not self.usmc.admits(plan, sensor.x, sensor.v, sensor.z,
                                sensor.E_res, sensor.margin_req,
                                sensor.modules):
            return False
        # 2) 分布域：所有证书的域必须同时覆盖 θ
        in_domain = all(ddc.admits(theta, t_now)
                        for ddc in self.ddcs.values())
        if in_domain and self.tfc.verify(theta, e_value=e_value):
            return True
        # 3) 域外：孪生接地外推
        ok, reason = self.tge.certify(plan, theta, self.usmc.certs)
        if ok:
            return True
        # 4) 外推失败：保守静态模式（冻结结构、位置控制），仍是 v24 子集
        if self.fallback == 'conservative_static':
            return self._conservative_static_mode(plan)
        return False

    def _conservative_static_mode(self, plan) -> bool:
        """冻结结构参数、禁用新增力控模式、按实体结构保守运行"""
        return (plan.mode == 'position_control' and
                plan.structure_frozen and
                self.hard_env_safe(plan))


# ============================================================
# 端到端流水线：加入孪生-分布证书链
# ============================================================
class PerceptionComplianceEnergyPipeline:
    def step(self, sensor_data: dict, cloud_update=None) -> tuple[bool, dict]:
        # ... 现有步骤 1-5 ...
        # 6. 结构-力学证书更新（v24）
        self._update_structural_certificates(sensor_data)
        # 7. 孪生同步：仅在版本一致时复用 gap 证书
        self._sync_twin(sensor_data)
        # 8. 分布域 + 孪生接地准入
        theta = self._condition_vector(sensor_data)
        admitted = self.usmct.admits(
            plan, theta, sensor_data['t'], sensor_data,
            e_value=self._e_process.e_value())
        return admitted, {
            'plan': plan if admitted else None,
            'twin_version': self.usmct.tfc.tau,
            'gap_bound': self.usmct.tfc.gap_bound(theta).tolist(),
            'in_twin_domain': self.usmct.tfc.in_domain(theta),
            'in_cert_domain': all(d.admits(theta, sensor_data['t'])
                                  for d in self.usmct.ddcs.values()),
            'admission_mode': self._last_mode,
        }

    def _sync_twin(self, sensor_data):
        # 孪生更新即版本变更；旧 TFC 必须重标定，禁止「用新孪生+旧 gap」
        if sensor_data.get('twin_update') is not None:
            self.usmct.tfc.on_twin_update(sensor_data['twin_update'].tau)
        # 在线残差喂给 e-process 与 TFC 抽查
        if 'q_real' in sensor_data:
            r = sensor_data['q_real'] - self.usmct.tfc.twin.predict(
                self._condition_vector(sensor_data))
            self._e_process.update(r / self.usmct.tfc.gap_bound(
                self._condition_vector(sensor_data)))
```

## 3. 正确性论证（增量）

### 假设 A1（残差局部 Lipschitz / gap-growth）
存在常数 L_g，使得对任意 θ,θ'∈Θ，中心化残差满足
‖(r−ĝ)(θ) − (r−ĝ)(θ')‖ ≤ L_g‖θ−θ'‖。
**说明**：A1 是本轮全部外推保证的唯一非统计前提。它在标定支撑内可用差商估计并被保守系数 κ 放大；在支撑外它是**建模假设而非被验证事实**——这正是本轮最大风险的来源（见第 6 节）。

### 引理 9（TFC 的 gap 覆盖）
**陈述**：若 A1 成立、标定点 θ_i 与残差可交换、q_δ 为 |r−ĝ| 的 split conformal (1−δ) 上分位，则对任意 θ∈D_twin，以概率 ≥1−δ：
‖r(θ)‖ ≤ η(θ) = |ĝ(θ)| + q_δ + L_g·d(θ,D_cal)。

**证明**：令 θ* 为距 θ 最近的标定点。由三角不等式
|r(θ)| ≤ |ĝ(θ)| + |(r−ĝ)(θ)|
≤ |ĝ(θ)| + |(r−ĝ)(θ*) − (r−ĝ)(θ)| + |(r−ĝ)(θ*)|
≤ |ĝ(θ)| + L_g‖θ−θ*‖ + |(r−ĝ)(θ*)|
≤ |ĝ(θ)| + L_g·d(θ,D_cal) + q_δ = η(θ)。
最后一式以概率 ≥1−δ 成立，来自 split conformal 对中心化残差上分位的定义。∎
**注**：θ* 是标定点，其中心化残差属于标定集；对固定标定点，q_δ 覆盖是构造性的。真正需要外推的是「θ 与 θ* 的差」这一项，由 A1 承担。

### 引理 10（DDC 组合只收窄、不扩张）
**陈述**：若 A、B 的分布域证书分别为 (D_A, α_A)、(D_B, α_B)，则组合证书 (D_A∩D_B, min(1,α_A+α_B)) 满足：
D_A∩D_B ⊆ D_A 且 ⊆ D_B；覆盖下界 1−(α_A+α_B) ≤ min(1−α_A, 1−α_B)。
**证明**：交集定义直接给出域包含。设失败事件 E_A、E_B，则 P(E_A∪E_B) ≤ P(E_A)+P(E_B) ≤ α_A+α_B，故覆盖 ≥1−(α_A+α_B)。∎
**推论（无免费泛化）**：任何串联/并联/否决组合都只能取域交、按 union bound 损失覆盖；孪生仿真本身不扩张 D_twin，因为 D_twin 由 gap 界定义、而 gap 界需要真实配对标定。**扩张受信域的唯一货币是真实数据**（且 fit/audit 必须分离，见 R12）。

### 引理 11（TGE 外推的可靠性）
**陈述**：若引理 9 的 gap 界在 θ 处成立，且 TGE 的鲁棒复核通过（上界量 q̂_upper+η ≤ spec_upper，下界量 q̂_lower−η ≥ spec_lower），则真实量以概率 ≥1−δ 落在规格内。
**证明**：对上界量，q_real ≤ q̂ + |r| ≤ q̂ + η ≤ spec_upper；对下界量同理 q_real ≥ q̂ − η ≥ spec_lower。两式同时成立的概率 ≥1−δ。∎
**注**：证明只用三角不等式与引理 9，不依赖孪生体「正确」，只依赖 gap 界「有效」。因此孪生可以错，但误差必须被 η 包住。

### 引理 12（v25 的夹逼与单调链）
**陈述**：记 Exec_v24^naive 为 v24 信任点证书/孪生预测而不做 gap 膨胀的准入集，Exec_v24^failclosed 为 θ∉D_cert 即拒绝的保守准入集，则
Exec_v24^failclosed ⊆ Exec_v25 ⊆ Exec_v24^naive ⊆ Exec_v23 ⊆ … ⊆ Exec_v18。
且域内（θ∈⋂D_cert 且 TFC 受信）Exec_v25 与 Exec_v24 完全一致。
**证明**：
- 上界：Exec_v25 在 Exec_v24^naive 之上额外要求 DDC 域覆盖与 TFC 受信（以及 gap 膨胀的鲁棒复核），任何被 v25 接受的计划都必先被 v24 接受，故 ⊆。
- 下界：域内 v25 直接复用处内点证书，与 v24^failclosed 的接受行为一致；域外 v25 可能通过孪生外推额外接受一些 v24^failclosed 拒绝的计划，故 ⊇。
- 域内相等：域内 Fil_ddc 恒真，且证书用实测/名义点值，gap 不参与判定，故 v25 = v24。
- 链尾：由归纳假设 Exec_v24^naive ⊆ Exec_v23 ⊆ … ⊆ Exec_v18。∎
**解释**：v25 不是靠放宽 v24 来「获得」OOD 能力，而是先把 v24 中那些**沉默地忽略分布漂移**的乐观准入（v24^naive）显式化，再用 gap 膨胀把它们收缩到可证的子集；同时对 v24^failclosed 误杀的安全外推予以回收。两端都不越过 v24 的乐观集。

### 定理（USMC-T 的安全-分布-孪生完备性）
**陈述**：对任意计划 π 与工况 θ，`USMC-T.admits(π,θ)=True` 当且仅当：
(1)–(7) 满足 v24 的七项（物理接地、云边一致、conformal 覆盖、专利完备、结构三重、力控三重、轻量化三重）；
(8) 每张 SOC/FCC/LSC 证书的 DDC 覆盖 θ，或 θ∈D_twin 且 TGE 鲁棒复核通过；
(9) TFC 在 θ 处受信（η(θ)≤η_max、e-value 未超阈、TTL 未过期、孪生版本一致）；
(10) 分布无关硬物理包络 H(θ,π) 成立。
**证明**：必要性由 `admits` 的逐条连言直接得到；充分性由引理 9–11 保证 (8)(9) 给出的外推证书在真实本体上成立，由 (10) 保证统计 gap 界被低估时仍有物理兜底，由引理 12 保证执行集单调链不被破坏。∎

## 6. 本轮最大风险（最终确认）

**一句话**：**孪生保真证书（TFC）的 gap 上界本身只在标定分布内被验证，把它按线性/Lipschitz 假设外推进 OOD 是一个未经证实的建模假设；一旦真实 sim-to-real gap 在未建模物理（新接触、脆断、塑性屈曲）下增长快于 A1，孪生就会「自信地」为物理本体无法承受的域外计划签发外推证书——即证书塔的基域是假设出来的而非证出来的，这是本轮方案唯一的、也可能是致命的自指风险。**
