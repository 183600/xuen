# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；本轮灵感：「成本控制」×「技能组合」）

> R69 给不确定性装上了「嘴」：看不清就问、就凑近、就等。但它有两个未经审视的经济学假设：
> 1. **交互是便宜的、成本是一个已知标量**：仿佛问一句只扣一点预算，且预算永远够用；现实中信息有固定开销、尾部延迟、社交代价、机会成本，且成本本身会被环境、对手或供应商扭曲。
> 2. **技能是原子的、策略是单体的**：R69 的流匹配策略为每个任务生成一条轨迹，却不会复用「已经验证过的抓取/开门/递物」；每遇新任务就重新采样、重新验证，**验证成本无法摊销**。
>
> 本轮两个灵感正好咬合：
> - **成本控制**把「不确定性消解」从信息论问题变成**预算约束下的投资问题**：每一次注视、探针、问句、验证、换装都是一笔支出，应该按「每单位成本带来的风险调整后任务价值」排序，而不是按熵减排序；预算吃紧时应该**降低任务野心**，而不是降低安全。
> - **技能组合**把策略从「单体流模型」升级为**带契约的可复用技能资产组合**：技能有前置/后置条件、不变量、有效域、证书与成本画像；组合通过 assume-guarantee 接口继承证书，复用把验证成本摊薄，但陈旧证书会积累「验证债务」。
>
> 核心命题：**把 epistemic 消解与技能使用统一成一个预算约束下的资产组合问题：用可组合技能契约表示「能做什么」，用成本证书与摊销账本表示「花多少」，用决策论 VoI/成本比表示「先买哪条信息」，并用不可挪用的安全预算把「省钱」与「保命」硬隔离；当预算不足时，系统削减任务范围（shed tasks），而不是削减 λ_floor。** 命名 **THRIFT-RAS**（Task-aware Hierarchical Reuse & Information-Frugal Trade-offs）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这点预算花在哪、哪些技能能复用、省到哪一步必须停**」——不确定性不只有形状，还有价格；技能不只是动作，还是资产。

## 0. 直觉与动机

**灵感 1（成本不是标量，而是一条随时间和状态变化的成本曲线）**
直觉：R69 的 c(g) 是一个常数，最多加一个 c_max。但真实的成本有五种 R69 没区分的东西：
- **固定成本**（setup）：停下来问一句话、换一次工具、重新标定一次，先付一笔与问题大小无关的开销；
- **可变成本**（execution）：走得越远、看得越久、采样越多，边际成本越高；
- **尾部成本**（tail）：平均 2ms 不够，P99 可能是 50ms；实时系统的预算约束是尾部的，不是均值的；
- **验证成本**（verification）：技能/证书不是免费的，越安全越贵；
- **机会成本**（opportunity）：花了 3 秒问路，就少了 3 秒做任务；在竞赛/产线上，这就是任务价值损失。

更关键的是，**成本本身是不确定的、非平稳的、可被对手影响的**：地面摩擦、负载、通信、人的配合度都会让同一个技能的耗时/能耗变化；对手可以故意制造歧义来消耗你的交互预算（**歧义洪泛 / budget DoS**），也可以把一个未认证的「便宜」技能伪装成低成本选项（**成本投毒**）。所以成本必须像风险一样被**认证**：用保守上界（UCB/CVaR）而不是点估计，用多源遥测而不是自报，用审计而不是信任。

**灵感 2（技能组合：策略不是单体网络，而是证书资产组合）**
直觉：R69 的流匹配策略很强，但它是「每个任务重新生成」的。人不是这样工作的：人会复用「开门」「抓杯子」「递东西」这些**技能**，只在接口处做少量适配。技能组合带来三个 R69 没有的好处：
- **组合泛化**：有限的技能库可以组合出指数级的新任务；
- **成本摊销**：技能验证一次，可以复用很多次；复用次数越多，单次任务的验证成本越低；
- **可解释的失败定位**：组合失败可以归因到某个技能的契约或某个接口，而不是「网络输出了一条坏轨迹」。

但组合不是免费的：
- **接口风险**：前一个技能的后置条件不满足后一个技能的前置条件（抓完杯子，杯子是横的还是竖的？），组合就会在接缝处失败；
- **证书继承问题**：两个各自安全的技能，组合起来不一定安全（资源竞争、动力学耦合、时序冲突）；
- **组合爆炸**：技能库越大，候选组合越多，规划/验证成本越高；
- **陈旧证书**：去年验证过的技能，今年换了地面/负载/传感器，证书可能已经失效——**复用旧证据是一种负债**。

**灵感 3（耦合：信息动作也是技能，证据也是资产）**
直觉：R69 的「看/问/触」其实就是**信息技能**，也应该有自己的契约、成本和有效域。更重要的是，**证据是可以复用的资产**：今天为了选抓取方式而标定的一次手眼关系，明天抓同类物体时还能用；一次探针获得的材质信息，可能同时降低「抓多重」「用多大力」「是否需要再问」三个技能的不确定性。于是信息获取不再是 R69 的一次性动作，而是**带共享覆盖（shared coverage）的投资**：一条证据如果同时服务于多个技能，它的性价比就更高。这就把「技能组合」和「成本控制」真正焊在一起：**组合决定了证据的共享覆盖，成本决定了共享覆盖值不值得买。**

**灵感 4（安全预算不可挪用：省钱的边界）**
直觉：成本控制最危险的失败模式不是「花多了」，而是**为了省钱而偷偷降低安全**：少做一次验证、跳过一条证据纪律、用更便宜的近似模型、复用一张过期证书。因此本轮最重要的制度设计是**双层预算**：
- **安全预算 B_safe**：只用于强制验证、兜底、急停、证书刷新，**不可挪用到任务/信息/探索**；
- **可支配预算 B_disc**：用于任务执行、可选信息获取、技能合成、批处理调度。

风险缩放 λ_floor 由不确定性决定，**与 B_disc 无关**；预算不足时，系统只能削减任务范围（少做几个任务、用更粗的动作、延后非关键任务），不能削减 λ_floor。这条不变式把「成本控制」从「可能害死人的优化」变成「只在安全裕度之上做文章」。

**灵感 5（成本控制的正确计量单位：每次成功任务成本 CST）**
直觉：如果只优化「每步成本」，系统会学会「便宜地失败」：用最便宜但最不可靠的技能，失败后再重试，账面很好看，实际总成本更高。正确的指标是 **CST（Cost per Successful Task）**：把执行、验证、信息、重试、兜底、切换全部计入分子，把成功率放进分母。这样「省验证费」只有在它不显著降低成功率时才划算；一旦验证能把成功率从 0.8 提到 0.95，省下的验证费很可能被失败重试吃回去。**成本控制必须与成功率联合优化，否则就是虚假节约（false economy）。**

## 1. 形式化定义（增量：定义 310–330）

**定义 310（THRIFT-RAS 总览）** THRIFT-RAS = (SPL, SCC, CBA, BIP, CAP, ALR, SFB, TCG, SBS, CIG, RAS-WM§)。六条不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **安全预算不可挪用**：B_safe 与 B_disc 分账，λ_floor 的计算不读取 B_disc；B_safe 不足时只允许最小风险停机（fail-safe）并削减任务；
(iii) **无证书不执行**：任何技能/组合/信息动作必须在当前有效域内持有效证书，且证书新鲜度不过期；否则视为不可用（成本 = ∞）；
(iv) **成本诚实**：进入决策的成本必须是带来源的保守上界 C⁺_β，未经验证的成本按 ∞ 处理；
(v) **证据纪律继承**：单次交互/单源回答不得单独定案；组合接口必须通过 assume-guarantee 检查；
(vi) **预算不足时削减任务野心，不削减安全裕度**（定义 323）。

**定义 311（技能契约）** 技能 s = (Pre_s, Post_s, Inv_s, V_s, Cert_s, κ_s)，其中 Pre_s/Post_s 为前置/后置状态集，Inv_s 为执行期不变量，V_s ⊆ 𝒳 为有效域（标定有效、光照/地形/负载/通信在范围内），Cert_s 为证书（版本/哈希/签发时间/有效期），κ_s 为成本画像（定义 314）。执行语义：从 x ∈ Pre_s ∩ V_s 出发，以概率 ≥ 1−δ_s 保持 Inv_s 并终止于 Post_s；风险 ≤ ρ_s。**技能可以是运动原语、学习策略、R69 的信息动作（gaze/probe/ask），或一个已经组合好的宏技能。**

**定义 312（技能组合代数）** 组合算子：
- 串行 s₁;s₂：要求 Post_{s₁} ∧ V_{s₂} ⊨ Pre_{s₂}（带接口裕度，定义 313）；
- 并行 s₁‖s₂：要求资源（工作空间、负载、计算、通信）不相交，且耦合风险有界；
- 选择 s₁ | s₂：要求 Pre 的并集覆盖当前状态，且两支的证书都在有效域内；
- 回退 s₁ ▷ s_fallback：s₁ 失败/超时/证书失效时切换到 s_fallback，回退成本计入 CST。
组合的结果仍是一个技能契约 s_π，其成本/风险由 CBA 记账，其证书由 SCC 继承或重新验证。

**定义 313（接口裕度与组合风险）** 对串行接口 i，定义裕度 Δ_i = margin(Post_{s_i} ⇒ Pre_{s_{i+1}} | Inv)，即后置条件满足前置条件的鲁棒距离（在约束/状态空间中的最小安全余量）。组合风险上界：
ρ(s₁;…;s_n) ≤ Σ_i ρ_{s_i} + Σ_i ρ_int(Δ_i)，其中 ρ_int(Δ) 随 Δ 增大而减小，Δ < 0 时组合**不可认证**（必须插入适配技能或重新验证）。**证书继承的条件**：所有 Δ_i ≥ 0 且各技能证书在有效域内；此时验证成本从 O(d_state) 降为 O(Σ d_interface)。

**定义 314（成本画像与保守成本）** 技能/动作的成本是一个向量
κ = (c_exec, c_setup, c_switch, c_verify, c_info, c_energy, c_tail)，
其中 c_tail 为 CVaR_α 尾部成本（实时/能耗/社交）。在预算约束下用对偶价格 μ 标量化：C_μ(κ) = ⟨w_μ, κ⟩。**成本不是点估计**：定义保守上界 C⁺_β(s) = min{c : P(C(s) ≤ c) ≥ 1−β}，由多源遥测（执行日志、能耗计、延迟、力矩/电流）经验估计并加有限样本修正（Hoeffding/Bennett 或共形分位）。**未经验证的成本 = ∞，不得参与优化。**

**定义 315（成本证书与摊销账本）** 每次执行/验证产生一条账本记录 ℓ = (s, 版本, 时间, 有效域, 成本实测, 证据哈希, 复用次数)。成本证书绑定技能版本与有效域；有效域变化或版本升级即失效。账本用于：(a) 估计 C⁺；(b) 计算复用收益；(c) 计算验证债务（定义 319）；(d) 审计成本声明。

**定义 316（双层预算与影子价格）** 预算 B = (B_safe, B_disc)，满足
C_safe(π) ≤ B_safe，C_disc(π) ≤ B_disc，
且 **B_safe 不可转入 B_disc**（反向也不自动允许；安全预算只可由审计追加）。B_disc 的影子价格 μ ≥ 0 由对偶/二分法求得：预算越紧，μ 越大，系统越倾向便宜方案；B_safe 的影子价格为 +∞（安全验证不打折）。**λ_floor 不读取 μ。**

**定义 317（决策论信息价值 DVoI）** 对信息动作/证据获取 g，定义
DVoI(g | b) = E_{y~p(·|g,b)}[V(π*_{b_y})] − V(π*_b) − λ_R·(Risk(π*_{b_y}) − Risk(π*_b)) − μ·C⁺_β(g)，
其中 V 为任务价值（成功率、完成时间、步骤分的加权），λ_R 为风险-价值换算系数，π*_b 为当前信念下的最优认证组合。**只有 DVoI > 0 且通过安全/预算认证才购买。** 与 R69 的熵 VoI 相比，DVoI 用**任务价值**而不是熵计价：一个熵减很大但决策无关的歧义（Δ_min 小、两个模态后果相同）DVoI ≈ 0，不应该花钱；一个熵减很小但恰好决定「抓还是放」的歧义可能 DVoI 很高。系：**熵 VoI 是 DVoI 的乐观上界，按熵花钱会系统性超支。**

**定义 318（预算化信息规划 BIP）** 给定候选证据获取集合 A、成本 c(a)、共享覆盖 Cov(a) = {s : a 降低 s 的不确定性}，选择 A' ⊆ A 最大化
Σ_{s∈∪Cov(a)} w_s·DVoI_s(A') − μ·Σ_{a∈A'} c(a)，s.t. Σ c(a) ≤ B_info。
在条件独立与单调性假设 A99 下，集合函数 f(A') 是单调子模的；**成本效益贪心**（每次选 DVoI/成本比最大者）在背包约束下给出 1/2(1−1/e) 近似，带 3 元素枚举的改进贪心给出 (1−1/e) 近似。**若 MNAR/非平稳破坏子模性，则用保守上界 f⁺ ≥ f 规划，或退回逐项 DVoI>0 的局部检查。**

**定义 319（摊销、验证债务与复用盈亏平衡）** 技能 s 的验证成本 C_ver(s)、复用成本 C_reuse(s)、重新合成成本 C_syn(s)。若 C_syn > C_reuse，复用盈亏平衡次数
k*(s) = ⌈C_ver(s) / (C_syn(s) − C_reuse(s))⌉。
复用次数 k ≥ k* 时，复用优于重新合成。**验证债务** D_t = Σ_s w_s·1[t − t_cert(s) > τ_s]·ρ_s·V_s，其中 τ_s 为证书有效期；D_t 超过阈值或执行高风险任务前必须刷新证书，刷新成本计入 C_safe（若是安全关键）或 C_disc。**复用旧证书不是免费午餐，而是在借债。**

**定义 320（复用 vs 合成 vs 回退）** 对当前任务/状态，候选包括：
(a) 复用已认证技能/组合（成本 C_reuse，风险 ρ_reuse）；
(b) 用 R69 的 FMP 合成/修复技能并认证（成本 C_syn + C_ver，风险 ρ_syn，需过 SCC/CIG）；
(c) 回退到 R69 的保守单技能（成本 C_69，风险 ρ_69）。
选择使期望 CST（定义 322）最小且满足安全/预算约束者；无可行者则进入任务削减（定义 323）。

**定义 321（成本感知组合选择 CAP）** 在候选认证组合 Π_cert 上求解
π* = argmax_{π∈Π_cert} [ E[V(π)] − μ·C⁺_{disc}(π) ]
s.t. Risk_α(π) ≤ ε_safe，C⁺_{safe}(π) ≤ B_safe，C⁺_{disc}(π) ≤ B_disc，证书新鲜。
这是带风险约束的预算化组合优化；技能库小时可枚举，大时用分支定界/成本效益贪心/有限深度 MCTS。**R69 的单技能策略是 Π_cert 的一个元素；因此 CAP 永远可以选择 R69 的动作。**

**定义 322（每次成功任务成本 CST）** 
CST(π) = E[C_total(π)] / P_success(π) = C_attempt / p_success（几何重试近似），
其中 C_total 包含执行、验证、信息、切换、重试、回退、能耗的**全部**成本。主目标是在安全约束下最小化 CST，而不是最小化单步成本。**系：任何降低单步成本但提高失败率的改动，只有在 CST 不升时才被采纳。**

**定义 323（任务野心调节器 TCG 与优雅降级）** 任务范围 z ∈ Z 带价值 V(z)、成本 C(z)、风险 R(z)，且 z 越大约贵。当无可行 π 满足预算时，选择最大价值的 z 使存在可行 π(z)；若仍不可行，执行最小风险停机并报告。**单调性：B_disc 下降 ⇒ 交付任务价值不升、成本不升、λ_floor 不变。** 不允许用「降低安全验证」来换取任务范围。

**定义 324（成本感知批处理调度 SBS）** 若多个任务共享技能，固定 setup/switch 成本可以通过批处理摊薄：将任务按技能分组，在截止期约束下最小化 Σ setup + Σ exec，允许插入信息动作。调度器输出任务顺序与技能批次；批处理收益计入 CST。**批处理不得跨越证书有效期，也不得为凑批而延迟安全关键任务。**

**定义 325（成本完整性守卫 CIG）** 对成本声明做多源一致性检查与异常检测：
- **通胀攻击**（把某技能报贵，诱导系统选错）：交叉核对遥测，检测成本分布漂移；
- **通缩攻击**（把未认证/高风险技能报便宜）：版本/证书/遥测不一致即隔离；
- **歧义洪泛 / 预算 DoS**（故意制造歧义耗尽 B_info）：检测单位时间歧义率异常，启用**信息预算防火墙**（非关键信息最多使用 η 比例，保留关键信息储备），并按关键性加权 DVoI；
- **证书重放/陈旧**（拿旧证据冒充新证据）：检查时间戳、有效域哈希、环境指纹。
CIG 的结论写入账本并调整 C⁺；无法验证的成本按 ∞ 处理。

class SkillContract:
    def __init__(self, pre, post, inv, valid_region, cert, cost_profile):

def compose(skills):

    for nxt in skills[1:]:
        d = interface_margin(plan.post, nxt.pre, plan.inv)   # 定义 313
        if d < 0:

# IP-266 CBA：保守成本上界 + 账本
class CostAccountant:
    def ucb(self, skill, beta):
        samples = self.ledger.samples(skill, valid_region=skill.V)
        return conformal_quantile(samples, 1 - beta)          # 或 Hoeffding/Bennett
    def record(self, skill, measured, provenance):
        self.ledger.append(skill, measured, provenance)      # 多源遥测

# IP-267 BIP：预算化决策论信息规划（成本效益贪心）
def plan_information(candidates, b, budget, mu):
    chosen, spent = [], 0.0
    while True:
        best = None
        for a in candidates - set(chosen):
            c = accountant.ucb(a, beta)
            gain = portfolio_dvoi(a, b, chosen)               # 共享覆盖 + 任务价值
            if c <= 0 or gain / c <= 0: continue
            if spent + c > budget.info: continue
            if best is None or gain / c > best.ratio:
                best = (a, gain, c)
        if best is None: break
        chosen.append(best[0]); spent += best[2]
        b = expected_posterior(b, best[0])                    # 期望更新，供下一步贪心
    return chosen

# IP-268/270 CAP + SFB：风险约束下的组合选择；安全预算分账
def select_plan(task, b, budgets, mu):
    feasible = []
    for plan in certified_compositions(task, b):              # 含 R69 单技能
        if not plan.cert.fresh(): continue
        c_safe = plan.safe_cost_ucb()                         # 验证/兜底/刷新

        if c_safe > budgets.safe or c_disc > budgets.disc: continue
        if plan.risk_cvar > EPS_SAFE: continue
        feasible.append((plan, plan.value - mu * c_disc))
    if not feasible:
        return task_shedding(task, budgets)                   # IP-271 TCG：降野心，不降安全
    return max(feasible, key=lambda t: t[1])[0]

# IP-269 ALR：复用/合成/回退的盈亏平衡
def reuse_or_synthesize(skill, task, horizon):
    k = expected_reuse_count(skill, horizon)
    if skill.cert.fresh() and k >= skill.k_star:
        return reuse(skill)
    if synthesize_cost(skill) + verify_cost(skill) < reuse_cost(skill, k):
        return synthesize_and_certify(skill)                  # FMP 合成，必须过 SCC/CIG
    return fallback_r69(task)

# IP-273 CIG：成本完整性 + 歧义洪泛防护
def cost_guard(claim, telemetry, budget):
    if claim.version != telemetry.version: return INF          # 版本/证书不一致
    if distribution_shift(claim, telemetry) > TAU_DRIFT: return INF
    if ambiguity_rate(telemetry) > TAU_FLOOD:
        budget.info = min(budget.info, budget.info_reserve)   # 防火墙：保留关键信息预算
    return conservative_ucb(claim, telemetry)

# IP-275 主闭环：R69 之后插入经济层
def THRIFT_round(M, obs, task):

    plan = M.cap.select_plan(task, M.belief, M.budget, mu=M.mu)
    # 4) 安全预算分账：λ 不读取 B_disc
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + unresolved(U_epi)))
    if M.sfb.balance() < 0 or not plan.cert.fresh():
        return M.sfb.fail_safe(task)                          # 只停机，不降安全
    # 5) 执行 + 记账 + 审计
    result = M.execute(plan, info_plan)
    M.cba.record(plan, result.measured, result.telemetry)

## 3. 推导

假设 A99（证据条件独立、价值函数单调，保证子模性）与 A100（Π_cert 包含 R69 动作；B_safe 足以覆盖 R69 的强制验证/兜底；所有组合通过 SCC）为新增假设，A95–A98 继承 R69。

**引理 19（组合证书继承）** 设技能 s₁,…,s_n 各自在有效域内持有效证书，且所有串行接口裕度 Δ_i ≥ 0。则组合 s₁;…;s_n 可在不重新验证内部状态空间的情况下认证，风险满足 ρ ≤ Σρ_i + Σρ_int(Δ_i)，验证成本从 O(Σ d_state_i) 降为 O(Σ d_interface_i)。证明要点：assume-guarantee 归纳；每个技能的 Inv 只通过接口与外界耦合，接口裕度保证后继前置条件在扰动下仍成立；组合风险由局部风险与接口风险相加。系：**技能越多，接口越便宜；但接口裕度为负时，组合必须插入适配器或重验，成本立即回升——这正是「组合不是免费」的定量表述。**

**引理 20（DVoI 的决策相关性）** 对任意决策问题，熵减 ΔH > 0 不蕴含 DVoI > 0；反之 DVoI > 0 蕴含存在一个观测结果使最优动作改变。因此按熵分配信息预算会系统性超支：它会给「熵大但两个模态后果相同」的歧义付费。证明要点：DVoI 是价值函数对后验的期望改进，若所有模态的 V(π*) 相同，则任何观测都不改变价值；熵却可以很大（例如两个对称但同样安全的动作）。**系：R69 的熵 VoI 应替换为 DVoI；在 R69 的 A95（Δ_min ≥ 3σ_in）下，DVoI 与 Δ_min 成正比，与引理 16 一致。**

**引理 21（验证/复用的 CST 盈亏平衡）** 设不验证时成功率 p₀、验证后 p₁ > p₀，单次基础成本 C_base，验证成本 C_v，失败重试成本 C_r。几何重试下
CST₀ = (C_base + (1−p₀)C_r) / p₀，CST₁ = (C_base + C_v + (1−p₁)C_r) / p₁。
验证值得做当且仅当 C_v < (p₁/p₀ − 1)(C_base + C_r)。简化 C_r=0 时：**C_v < C_base(p₁/p₀ − 1)**。系：当 p₁/p₀ < 1 + C_v/C_base 时，省验证费反而提高 CST——这就是「虚假节约」。复用盈亏平衡 k* = ⌈C_ver/(C_syn − C_reuse)⌉ 同理。

**引理 22（成本投毒下的预算安全）** 若每个成本估计使用有效的 (1−β) 上界 C⁺（即 P(C ≤ C⁺) ≥ 1−β），且规划满足 Σ C⁺ ≤ B_disc，则真实成本 ≤ B_disc 的概率 ≥ 1−β（单次决策；T 步用 union bound 得 1−Tβ）。若成本被通缩攻击低估 δ 且未被 CIG 检出，则真实超支比例 ≤ δ/(1−δ)；CIG 的多源一致性检查把未检出概率压到 (1−p_detect)^m（m 个独立遥测源）。**系：成本安全不是「估得准」，而是「用上界 + 多源 + 审计」三件事同时成立。**

**定理 18（严格包含 R69 与安全预算非挪用）** 在 A95–A100 下，THRIFT 在任意状态的期望风险 ≤ R69；且当 DVoI ≤ 0、无更便宜认证组合、预算充足、证书新鲜时，两者逐指令相同。若 B_disc 不足，THRIFT 只削减任务范围（TCG），λ_floor 不变；若 B_safe 不足，THRIFT 只执行 fail-safe 停机，绝不降 λ。**因此 R69 是「无限可支配预算 + 单技能」边界，R68 是「无信息 + 单技能」边界；成本层只在安全裕度之上做再分配。**

**定理 19（预算单调性与优雅降级）** 设任务范围 z 的价值 V(z) 与成本 C(z) 随 z 单调不减，且可行域随 B_disc 单调收缩。则 THRIFT 交付的 V 随 B_disc 下降而单调不增，成本单调不增，安全裕度 λ_floor 恒定；若用成本效益贪心近似，V 至少达到离线最优的 1/2(1−1/e)（或 (1−1/e)，取决于是否枚举）。**系：预算越紧，系统越「少做」而不是「冒险做」；这就是成本控制的优雅降级。**

## 6. 本轮最大风险

**一句话**：THRIFT-RAS 的全部经济学都押在「成本上界可信、证书新鲜、B_safe 真的不可挪用」这三件事上——**一旦成本被系统性低估（成本投毒/遥测被篡改）或一张「便宜」技能的证书已经陈旧，优化器就会以漂亮的 CST 曲线自信地买入最便宜的组合，把省下的钱从安全裕度里偷偷扣走；更糟的是，系统被奖励「省」，于是它有动机少报成本、多用旧证据、把失败藏进任务削减里——成本控制由此从效率工具退化为安全套利，省错比不省更危险。**

**次级风险与缓解**：
1. **组合接口失效**（两个安全技能拼出不安全组合）→ SCC assume-guarantee + 接口裕度 + 引理 19；裕度为负强制重验；
2. **成本投毒/歧义洪泛** → CIG 多源遥测 + UCB + 信息预算防火墙 + 引理 22；
3. **验证债务累积**（复用旧证书）→ ALR 新鲜度检查 + 强制刷新 + E305；
4. **安全预算被挪用** → SFB 硬分账 + 审计 + 定理 18；λ_floor 不读取 B_disc；
5. **为省钱而便宜地失败** → 以 CST 而非单步成本为主指标 + 引理 21 + E312；
6. **组合爆炸/实时性** → 技能库分层 + 缓存认证组合 + 成本效益剪枝 + E315。

## 2. 形式化定义（要点版）

**定义 310（总览与六不变式）** `THRIFT-RAS`；零学习写操作；安全预算不可挪用（B_safe/B_disc 分账，λ_floor 不读 B_disc）；无证书不执行；成本诚实（只用带来源的 UCB，未知=∞）；证据纪律与接口认证继承；预算不足削减任务而非安全。

**定义 311–313（技能、组合、接口）** 技能 `s` 带 Pre/Post/Inv/有效域/证书/成本；组合子为串行/并行/选择/回退；串行有效当且仅当 `Post_i ∧ V_{i+1} ⊨ Pre_{i+1}` 且接口裕度 `Δ_i≥0`。组合风险 `ρ ≤ Σρ_i + Σρ_int(Δ_i)`；证书继承使验证成本从 O(d_state) 降到 O(d_int)。

**定义 314–315（成本画像与成本证书）** 成本是向量（执行/装配/切换/验证/信息/能耗/尾部）；用对偶价格 μ 标量化；每笔成本必须由多源遥测给出保守上界 `C⁺_β`，未验证成本按 ∞；账本记录版本/有效域/时间/复用次数/证据哈希，用于 UCB、摊销与审计。

**定义 316（双层预算）** `C_safe(π) ≤ B_safe`，`C_disc(π) ≤ B_disc`，B_safe 不可转为 B_disc；μ 只作用于 B_disc；`λ_floor` 与 μ 无关。

**定义 317–318（DVoI 与 BIP）** `DVoI` 用任务价值而非熵计价；熵 VoI 是其乐观上界，按熵花钱会超支。预算化信息规划在共享覆盖 `Cov(a)` 上最大化 `Σw_s·DVoI_s − μΣc`，条件独立/单调下为子模背包，成本效益贪心给 `1/2(1−1/e)`，带枚举给 `(1−1/e)`。

**定义 319–320（摊销与复用决策）** 复用盈亏平衡 `k*`；验证债务 `D_t` 超阈值或高风险任务前强制刷新；复用/合成/回退三者按 CST 与安全/预算约束选择；合成技能必须过 SCC/CIG 认证。

**定义 321–323（组合选择、CST、优雅降级）** 在认证组合上最大化 `E[V]−μC⁺_disc`，s.t. 风险 ≤ ε_safe、双预算、证书新鲜；主指标 `CST=C_total/P_success`；无可行计划时 TCG 选最大可行任务范围，仍不可行则 fail-safe；`B_disc↓ ⇒ 任务价值/成本单调不增，λ_floor 恒定`。

**定义 324–326（批处理、成本完整性、审计）** SBS 在截止期与证书有效期内批处理共享技能以摊薄 setup；CIG 用多源遥测检测成本通胀/通缩、歧义洪泛/预算 DoS、证书重放，未验证成本=∞，并启用信息预算防火墙；VQAuditor-E 审计成本声明、预算挪用、旧证书复用与任务削减合法性。

**定义 327–330（证书、威胁、严格包含、经济模态）** `J_THRIFT` 并入 cost_ece/UCB 覆盖/预算违约/复用命中/验证债务/接口裕度/安全余额/CST；`ℰ_THRIFT=ℰ_FLUID×ℰ_econ×ℰ_comp×ℰ_stale`；THRIFT 严格包含 R69（Π_cert 含 R69 动作，λ≥λ_69，退化时逐指令相同）；经济模态 `(m_k, π_k, κ_k, ρ_k)` 给出 `CostAmb` 与 `CoC`，预算优先给 `CostAmb×P(选错)` 最大者。

# IP-264/265 SPL+SCC
def compose(skills):
    plan = skills[0]
    for nxt in skills[1:]:
        d = interface_margin(plan.post, nxt.pre, plan.inv)
        if d < 0: return None                       # 接口不可认证，需适配/重验
        plan = Plan(plan, nxt, margin=min(plan.margin, d))
    return plan                                     # 证书继承，成本入账

# IP-266/267 CBA+BIP
def plan_information(cands, b, budget, mu):
    chosen, spent = [], 0.0
    while True:
        best = None
        for a in cands - set(chosen):
            c = ucb(a, beta); gain = portfolio_dvoi(a, b, chosen)
            if c <= 0 or gain <= 0 or spent + c > budget.info: continue
            if best is None or gain / c > best[0]: best = (gain / c, a, gain, c)
        if best is None: break
        chosen.append(best[1]); spent += best[3]
        b = expected_posterior(b, best[1])
    return chosen

# IP-268/270 CAP+SFB
def select_plan(task, b, budgets, mu):
    feasible = []
    for p in certified_compositions(task, b):       # 含 R69 单技能
        if not p.cert.fresh(): continue
        if p.safe_cost_ucb() > budgets.safe: continue
        if p.disc_cost_ucb() > budgets.disc: continue
        if p.risk_cvar > EPS_SAFE: continue
        feasible.append((p, p.value - mu * p.disc_cost_ucb()))
    return max(feasible, key=lambda t: t[1])[0] if feasible else task_shedding(task, budgets)

# IP-269 ALR
def reuse_or_synthesize(skill, horizon):
    k = expected_reuse_count(skill, horizon)
    if skill.cert.fresh() and k >= skill.k_star: return reuse(skill)
    if synth_cost(skill) + verify_cost(skill) < reuse_cost(skill, k):
        return synthesize_and_certify(skill)         # FMP 合成，必须过 SCC/CIG
    return fallback_r69()

# IP-273 CIG
def cost_guard(claim, telemetry, budget):
    if claim.version != telemetry.version: return INF
    if distribution_shift(claim, telemetry) > TAU_DRIFT: return INF
    if ambiguity_rate(telemetry) > TAU_FLOOD:
        budget.info = min(budget.info, budget.info_reserve)   # 信息预算防火墙
    return conservative_ucb(claim, telemetry)

# IP-275 THRIFT 主闭环
def THRIFT_round(M, obs, task):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(o)
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, adaptive_k(z)), z)

    plan  = M.cap.select_plan(task, M.belief, M.budget, M.mu)

## 4. 推导

假设 A99（证据条件独立、价值函数单调，保证子模性）与 A100（Π_cert 包含 R69 动作；B_safe 足以覆盖 R69 的强制验证/兜底；所有组合通过 SCC）为新增假设，A95–A98 继承 R69。

**引理 19（组合证书继承）** 有效证书 + 所有接口裕度 `Δ_i≥0` ⇒ 组合可认证，`ρ ≤ Σρ_i + Σρ_int(Δ_i)`，验证成本 `O(Σd_int)`；`Δ_i<0` 必须适配/重验。系：技能越多接口越便宜，但负裕度会立刻抬升成本。

**引理 20（DVoI 的决策相关性）** 熵减不蕴含 DVoI>0；DVoI>0 蕴含存在观测使最优动作改变。故按熵分配预算会为「熵大但后果相同」的歧义超支；R69 的 A95 下 DVoI 与 Δ_min 成正比（与引理 16 一致）。

**引理 21（CST 盈亏平衡）** 不验证/验证的 CST 分别为 `(C_base+(1−p₀)C_r)/p₀` 与 `(C_base+C_v+(1−p₁)C_r)/p₁`；验证值得做当且仅当 `C_v < (p₁/p₀−1)(C_base+C_r)`，`C_r=0` 时即 `C_v < C_base(p₁/p₀−1)`。复用盈亏平衡 `k* = ⌈C_ver/(C_syn−C_reuse)⌉`。系：省验证费若使 p 下降过多，CST 反而上升（虚假节约）。

**引理 22（成本投毒下的预算安全）** 有效 (1−β) UCB + 规划满足 `ΣC⁺≤B_disc` ⇒ 真实成本 ≤ B_disc 的概率 ≥ 1−β；T 步用 union bound。若通缩 δ 未检出，超支 ≤ δ/(1−δ)；m 个独立遥测源把未检出概率压到 `(1−p_detect)^m`。

**定理 18（严格包含 R69 + 安全预算非挪用）** A95–A100 下，THRIFT 任意状态期望风险 ≤ R69；`DVoI≤0`、无更便宜认证组合、预算充足、证书新鲜时逐指令相同。B_disc 不足只削减任务（TCG），B_safe 不足只 fail-safe；`λ_floor` 永不因成本下降。R69=「无限 B_disc+单技能」边界，R68=「无信息+单技能」边界。

**定理 19（预算单调性与优雅降级）** 价值/成本随任务范围单调、可行域随 B_disc 单调收缩 ⇒ 交付价值与成本随 B_disc 单调不增，λ_floor 恒定；贪心近似至少达到离线最优的 1/2(1−1/e)（或 (1−1/e)，取决于是否枚举）。系：预算越紧，系统越「少做」而非「冒险做」。

## 7. 本轮最大风险

**一句话**：THRIFT-RAS 的全部经济学都押在「成本上界可信、证书新鲜、B_safe 真的不可挪用」这三件事上——**一旦成本被系统性低估（成本投毒/遥测被篡改）或一张「便宜」技能的证书已经陈旧，优化器就会以漂亮的 CST 曲线自信地买入最便宜的组合，把省下的钱从安全裕度里偷偷扣走；更糟的是，系统被奖励「省」，于是它有动机少报成本、多用旧证据、把失败藏进任务削减里——成本控制由此从效率工具退化为安全套利，省错比不省更危险。**

**次级风险与缓解**：组合接口失效（SCC assume-guarantee + 接口裕度 + 引理 19）；成本投毒/歧义洪泛（CIG 多源遥测 + UCB + 信息预算防火墙 + 引理 22）；验证债务累积（ALR 新鲜度检查 + 强制刷新 + E305）；安全预算被挪用（SFB 硬分账 + 审计 + 定理 18）；为省钱而便宜地失败（以 CST 而非单步成本为主指标 + 引理 21 + E312）；组合爆炸/实时性（技能库分层 + 缓存认证组合 + 成本效益剪枝 + E315）。
