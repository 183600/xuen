# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim++；灵感循环第 6 轮；本轮灵感：「场景理解」×「论文发表」）

> 第 54 轮把技能从能力黑箱推进到「动作空间剖面 + 云边协同 + 动作-鲁棒性联合证书」。本轮把两个看似异质的词接上：**场景理解**提供证书的语义坐标系，**论文发表**提供证书的“可辩护性”标准。核心矛盾：H22：第 54 轮的动作剖面 `α_S(a)` 与鲁棒性谱 `ρ` 都是**场景无关**的，一旦部署场景的物体/关系/可供性发生语义漂移，动作剖面与证书会集体失效；H23：证书缺少「可复现证据」，导致“局部实验成立”被当成“系统性成立”，即**发表级过度声称（overclaiming）**。

## 0. 直觉与动机

**灵感 1（场景理解 → 动作空间的语义坐标系）**
直觉：`α_S(a)` 把技能写成动作占用，但动作是否有意义取决于场景。看到「杯子」不等于「可抓的杯子」：遮挡、材质、位姿歧义都会改变可供性。于是把动作剖面升级为 **场景条件剖面 `α_S(a|G)`**，其中 `G=(O,R,Φ)` 是场景图，`Φ` 把物体-动作对映射到可供性。场景理解在这里不是感知模块的附属品，而是**动作空间的第一性语义基座**：同一个技能在不同 `G` 下占据不同的动作子空间。

**灵感 2（场景有效期 → 证书是“有条件的保修单”）**
直觉：没有任何证书对全场景成立。应给联合证书 `J` 附一个 **场景有效期 `dom_scene(J)`**（类似药品适应症、器件工作温度区间）。部署时先做“场景域成员检验”：`G_*` 是否落在证书承诺的场景类内、离边界还有多少余量。域外不是“失败”，而是“未承诺”，必须触发保守回退，而不是硬套证书。

**灵感 3（论文发表 → 把同行评审变成可执行的红队）**
直觉：审稿人的本质工作，是在作者声称的范围内**主动搜索反例**。于是把“论文发表”转译为 **审稿人对手 `R_B`**：在场景类 `Σ` 内做场景变异搜索（增删物体、翻转关系、制造遮挡、扰动光照/材质/可供性歧义），寻找使声称 `ψ` 失败的 `G`。一条声称只有在预算 `B` 内**没被击穿**，且能通过 **rebuttal 闭环**（要么收窄场景域，要么加强证书）后才算站得住。这把第 53/54 轮的 `Explain` 从“解释失败”升级为“**可被攻击并反驳**”。

**灵感 4（论文发表 → 声称-证据账本 CEL 与可复现性裂隙）**
直觉：发表的硬通货不是结论，而是**可复核的证据包**。每条声称 `c` 绑定证据账本 `E(c)`：协议 `π`、场景抽样、随机种子、样本量、置信区间、消融、失败画廊、来源哈希、复跑漂移。定义 **可复现性裂隙 `Rgap`**＝跨种子结果方差 / 声称留出的安全边距；`Rgap` 越大，说明结论越可能只是“这一次实验的偶然”。这把“可发表”操作化为可判定的谓词，而不是修辞。

**灵感 5（场景-证据金字塔 → 从双证书到四元证书）**
直觉：在第 54 轮的鲁棒性金字塔 `𝕃` 与动作协同层 `𝔸` 上，再叠加 **场景语义层 `𝕊`** 与 **证据/可辩护层 `ℙ`**。联合证书扩展为 `J⁺=(ρ, A_cert, γ_ce, δ_a, S_cert, E_cert)`，形成 **场景-动作-鲁棒-证据** 四元闭合：能被场景解释、能被动作执行、能被鲁棒性兜底、能被证据复现。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（场景图与可供性接地）**
场景图 `G = (O, R, Φ)`：`O` 为物体实例，`R` 为空间/语义关系（含遮挡 `occ`、支撑 `on`、包含 `in`、朝向 `facing`），`Φ: O×A → [0,1]` 为可供性接地函数。场景描述子 `z(G) = [n_o, hist(R), hist(Φ), occ\_ratio, ambiguity]`。场景分布 `D`，场景类 `Σ(g_0, ε) = {G : k(z(G), z(g_0)) ≤ ε}`，`k` 为核距离。

**定义 122（场景条件动作剖面）**
`α_S(a|G) = φ(o_a|G) · exec_S(a|G)`，`o_a` 为动作 `a` 作用的物体，`exec_S` 为技能可执行性。场景条件覆盖：
```
cover(S, A_T | G) = 1  ↔  ∀ a∈A_T, α_S(a|G) ≥ θ_cov
```
第 54 轮定义 115 是 `G` 上的边缘化（`α_S(a)=E_{G~D}[α_S(a|G)]`），会**抹平语义漂移**，这正是 H22 的来源。

**定义 123（场景条件组合与全域可判定）**
`compat(S_i,S_j|G) = |A_i(G) ∩ A_j(G)| / |A_i(G) ∪ A_j(G)|`。组合在场景类 `Σ` 上可判定当且仅当
```
∀ G∈Σ: compat(S_i,S_j|G) ≥ θ_a ∧ c_trans(S_i,S_j|G) ≤ τ_e ∧ ρ_{S_i⊗S_j}(d|G) ≥ ρ_min ∀d
```
记场景漂移裕度 `m_Σ = min_{G∈Σ} [compat - θ_a]`，`m_Σ` 小意味着“擦线兼容”。

**定义 124（证书场景域与成员检验）**
联合证书 `J` 的场景有效域
```
dom_scene(J) = { G : cover(S,A_T|G) ∧ ∀d, ρ_S(d|G) ≥ ρ_min(d) ∧ δ_a(G) ≤ Θ_a }
```
部署 `G_*` 合法当且仅当 `G_*∈dom_scene(J)` 且边界裕度 `margin(G_*) = dist(z(G_*), ∂dom) ≥ m_0`。`G_*` 域外时输出 `uncommitted` 而非 `fail`，并触发保守回退。

**定义 125（声称与声称真值）**
一条声称 `c = (ψ, Σ, θ, π)`：谓词 `ψ`（如 `min_d ρ ≥ θ`）、场景类 `Σ`、阈值 `θ`、评估协议 `π`。声称真值
```
T(c) = P_{G~D|Σ, seed~π}[ ψ(G) 成立 ]
```
声称被“接受”当且仅当证据下置信界 `LB_α(c) ≥ θ`（`α` 为显著性），而不是点估计 `≥ θ`。

**定义 126（证据包与声称-证据账本 CEL）**
```
E(c) = (π, {G_i}, {seed_j}, n, CI_α, ablations, F_fail, h_prov, Rgap)
```
其中 `F_fail` 为失败画廊（每条失败附 `Explain` 根因），`h_prov = H(c, π, {G_i}, {seed_j})` 为来源哈希，可复现性裂隙
```
Rgap = Var_{seed}[ T̂(c) ] / max(θ - LB_α(c), ε)
```
`CEL = { c ↦ E(c) }`。**发表级谓词**：
```
PG(c) = (n ≥ n_min) ∧ (LB_α(c) ≥ θ) ∧ (Rgap ≤ τ_rep) ∧ (|F_fail| 有记录) ∧ (h_prov 可复算)
```

**定义 127（审稿人对手与反驳算子）**
审稿人对手 `R_B` 在预算 `B` 内输出反例集合
```
R_B(c) = { G ∈ Σ : ¬ψ(G), 由场景变异搜索得到 }
```
审稿通过率 `pass(c) = 1 - P_{R_B}[R_B(c) ≠ ∅]`。**反驳算子**：
```
rebut(c, R_B(c)) = narrow_Σ(c) 或 strengthen_cert(c)
```
要求迭代到不动点：`c_{t+1} = rebut(c_t, R_B(c_t))`，且收窄后场景域体积 `vol(Σ_{t+1}) ≥ v_min`（防“声称蒸发”）。

**定义 128（场景-证据四元联合证书）**
```
J⁺ = (ρ, A_cert, γ_ce, δ_a, S_cert, E_cert)
S_cert = (Σ, z_proto, margin_0),  E_cert = E(c_J)
```
部署规则：
```
deploy(J⁺, G_*) = in  ↔  G_* ∈ dom_scene(J⁺) ∧ margin(G_*) ≥ margin_0
                        ∧ PG(c_J) ∧ pass(c_J) = 1
```

## 2. 关键算法 伪代码

### IP-121 SGA（Scene-Grounded Action profile）

```python
def scene_action_profile(skill, G, A, phi):
    alpha = {}
    for a in A:
        o = skill.target_object(a, G)
        aff = phi(o, a, G) if o is not None and not occluded(o, G) else 0.0
        exe = skill.can_execute(a, G)
        alpha[a] = aff * exe
    return alpha

def scene_descriptor(G):
    return vectorize(n_objects(G), relation_hist(G),
                     affordance_hist(G), occlusion_ratio(G), ambiguity(G))
```

### IP-122 SCD（Scene-Conditioned Deployment gate）

```python
def scene_domain_check(J, G, margin0):
    z = scene_descriptor(G)
    if kernel_dist(z, J.S_cert.z_proto) > J.S_cert.radius:
        return ('out', 'scene_domain')
    for a in J.task_actions:
        if J.alpha(a, G) < TH_COV:
            return ('out', 'coverage', a)
    for d, lo in J.rho_min.items():
        if J.rho(d, G) < lo:
            return ('out', 'robustness', d)
    m = boundary_margin(z, J.S_cert)
    return ('in', m) if m >= margin0 else ('boundary', m)
```

def reviewer_validate(claim, prior, budget):

### IP-124 CEL（Claim-Evidence Ledger）

```python
def build_evidence(claim, runner, scenes, seeds, n_min, tau_rep):
    results = []
    for s in seeds:
        for G in scenes:
            results.append(runner.run(claim.protocol, G, s))
    lb  = bootstrap_lower_bound(results, alpha=0.05)
    rgap = seed_variance(results) / max(claim.theta - lb, EPS)
    fails = [r for r in results if not r.success]
    pg = (len(results) >= n_min) and (lb >= claim.theta) \
         and (rgap <= tau_rep) and provenance_recomputable(claim, scenes, seeds)
    return Evidence(claim, lb, rgap, fails, provenance_hash(claim, scenes, seeds), pg)
```

### IP-125 PGC（Publication-Grade Certificate）

```python
def publication_grade_certificate(J, claim, scenes, seeds, budget, v_min):
    while True:
        E = build_evidence(claim, robot_runner, scenes, seeds, N_MIN, TAU_REP)
        if not E.pg:
            return ('reject', 'evidence_insufficient', E)
        status, cex = reviewer_validate(claim, prior=scene_prior, budget=budget)
        if status == 'pass':
            return ('ok', J_plus(J, S_cert=(claim.Sigma, claim.z_proto, MARGIN0), E_cert=E))
        claim = rebut(claim, cex)              # 收窄 Σ 或加强证书
        if claim is None or vol(claim.Sigma) < v_min:
            return ('reject', 'claim_evaporation', cex)
```

def preregister(claim):
    h = commit_hash(claim.psi, claim.Sigma, claim.theta, claim.protocol)

def audit_claim_evolution(history):
    vols = [vol(c.Sigma) for c in history]

    evaporated = vols[-1] < V_MIN

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SGA | O(\|A\|·\|O\|·\|R\|) | O(\|A\|) | 可供性接地完备、遮挡判定 sound |
| SCD | O(\|A\|+\|𝔇_ρ\|+κ) | O(\|A\|+\|Σ\|) | 场景域成员检验 sound、边界裕度单调 |
| RAV | O(B·(\|O\|+\|R\|)) | O(B·\|G\|) | 变异覆盖场景类、反例可复现 |
| CEL | O(n·\|Σ\|·\|seeds\| + n_boot) | O(n·\|G\|) | 种子可交换、CI 有效、哈希可复算 |
| PGC | O(I·(CEL+RAV)) | O(B·\|G\|) | 反驳算子单调收窄、`vol(Σ)≥v_min` |
| PRE | O(\|Σ\|·k) | O(k) | 预注册哈希不可篡改、封存场景未污染 |

**正确性定理（Scene-Conditioned Publication-Grade Soundness）**
在第 53/54 轮 (A22)–(A28) 基础上追加：**(A29)** 场景描述子 `z` 对语义等价类满足 `L_z`-Lipschitz，`dom_scene` 的成员检验与真实有效域偏差 ≤ `ε_dom`；**(A30)** 审稿人对手在场景类内对反例的发现覆盖 ≥ `1-β_R`；**(A31)** 证据种子可交换、bootstrap 区间有效（覆盖率 ≥ `1-α`）；**(A32)** 反驳算子每次迭代使 `vol(Σ)` 单调不增且存在下界 `v_min`。
则对 `G_*~D`：
```
P(deploy_success) ≥ 1 - Σ_d(1-ρ_min(d))
                      - P(G_* ∉ dom_scene) - ε_dom
                      - β_R - α - P(Rgap > τ_rep)
```
关键：前三项由**场景域**决定（通常主导），`β_R` 由**审稿人覆盖**决定，`α`/`Rgap` 由**证据质量**决定。证书 soundness 不再是“相信作者”，而是“相信一个可被攻击、可被复算、且明确标了有效期的合同”。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 场景描述子碰撞/感知别名，域成员检验假入 | 高 | 多模态描述子 + 可供性主动探针 + 双阈值 |
| 审稿人只覆盖训练场景，形成虚假自信 | 高 | 封存场景族 + 跨分布对手 + OOD 变异 |
| 证据成本随 `n×seeds` 爆炸 | 中 | 分层抽样 + 序贯检验 + 重要性采样 |
| 反驳退化为“只收窄场景”导致声称蒸发 | 高 | `vol(Σ) ≥ v_min` + 阈值漂移审计 + 预注册 |
| 对发表指标的 Goodhart / 基准污染 | 高 | 预注册哈希 + 封存集隔离 + 来源溯源 |

## 6. 本轮最大风险

**一句话**：场景条件化与发表级证据把证书从“能力声明”升级为“带有效期的可复现合同”，但其 soundness **同时依赖场景描述子的语义保真、审稿人对手的覆盖、以及证据协议的不可污染**；最危险的不是证书被证伪，而是它以“收窄场景域 + 通过自建审稿人 + 漂亮置信区间”的方式变得**可发表却空洞**——在被污染的基准上过拟合、把有效域缩到无部署意义、再用预注册之外的阈值漂移粉饰，于是“同行评审通过”被误当作“真实世界成立”，故必须以 **封存场景族 + 场景域体积下界 + 预注册防篡改 + 跨分布红队** 作为硬护栏，宁要窄而真的合同，不要宽而假的发表。

## 2. 关键算法 伪代码

### IP-121 SGA（Scene-Grounded Action profile）

```python
def scene_action_profile(skill, G, A, phi):
    alpha = {}
    for a in A:
        o = skill.target_object(a, G)
        aff = phi(o, a, G) if o is not None and not occluded(o, G) else 0.0
        exe = skill.can_execute(a, G)
        alpha[a] = aff * exe
    return alpha

def scene_descriptor(G):
    return vectorize(n_objects(G), relation_hist(G),
                     affordance_hist(G), occlusion_ratio(G), ambiguity(G))

def scene_conditioned_cover(skill, A_T, G, theta_cov=0.8):
    return all(scene_action_profile(skill, G, A_T, PHI).get(a, 0.0) >= theta_cov
               for a in A_T)
```

### IP-122 SCD（Scene-Conditioned Deployment gate）

```python
def scene_domain_check(J, G, margin0):
    z = scene_descriptor(G)
    if kernel_dist(z, J.S_cert.z_proto) > J.S_cert.radius:
        return ('out', 'scene_domain')
    for a in J.task_actions:
        if J.alpha(a, G) < TH_COV:
            return ('out', 'coverage', a)
    for d, lo in J.rho_min.items():
        if J.rho(d, G) < lo:
            return ('out', 'robustness', d)
    m = boundary_margin(z, J.S_cert)
    return ('in', m) if m >= margin0 else ('boundary', m)

def conservative_fallback(G, safe_policy):
    return safe_policy if scene_domain_check(J, G, MARGIN0)[0] != 'in' else None
```

### IP-124 CEL（Claim-Evidence Ledger）

```python
def build_evidence(claim, runner, scenes, seeds, n_min, tau_rep):
    results = []
    for s in seeds:
        for G in scenes:
            results.append(runner.run(claim.protocol, G, s))
    lb   = bootstrap_lower_bound(results, alpha=0.05)
    rgap = seed_variance(results) / max(claim.theta - lb, EPS)
    fails = [r for r in results if not r.success]
    h = provenance_hash(claim, scenes, seeds)
    pg = (len(results) >= n_min) and (lb >= claim.theta) \
         and (rgap <= tau_rep) and provenance_recomputable(h)
    return Evidence(claim, lb, rgap, fails, h, pg)

def ledger_update(cel, claim, evidence):
    cel[claim.id] = evidence
    return cel
```

### IP-125 PGC（Publication-Grade Certificate）

```python
def publication_grade_certificate(J, claim, scenes, seeds, budget, v_min):
    while True:
        E = build_evidence(claim, robot_runner, scenes, seeds, N_MIN, TAU_REP)
        if not E.pg:
            return ('reject', 'evidence_insufficient', E)
        status, cex = reviewer_validate(claim, prior=scene_prior, budget=budget)
        if status == 'pass':
            S_cert = (claim.Sigma, claim.z_proto, MARGIN0)
            return ('ok', J_plus(J, S_cert=S_cert, E_cert=E))
        claim = rebut(claim, cex)              # 收窄 Σ 或 strengthen_cert
        if claim is None or vol(claim.Sigma) < v_min:
            return ('reject', 'claim_evaporation', cex)
```

def preregister(claim, k_sealed=K_SEALED):

    sealed = sample_sealed_families(claim.Sigma, k=k_sealed)

def audit_claim_evolution(history):

                          for p, c in zip(history, history[1:]))

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SGA | O(\|A\|·\|O\|·\|R\|) | O(\|A\|) | 可供性接地完备、遮挡判定 sound |
| SCD | O(\|A\|+\|𝔇_ρ\|+κ) | O(\|A\|+\|Σ\|) | 域成员检验 sound、边界裕度单调 |
| RAV | O(B·(\|O\|+\|R\|)) | O(B·\|G\|) | 变异覆盖场景类、反例可复现 |
| CEL | O(n·\|Σ\|·\|seeds\| + n_boot) | O(n·\|G\|) | 种子可交换、CI 覆盖 ≥ 1-α、哈希可复算 |
| PGC | O(I·(CEL+RAV)) | O(B·\|G\|) | 反驳单调收窄、`vol(Σ)≥v_min` |
| PRE | O(\|Σ\|·k) | O(k) | 预注册哈希不可篡改、封存集未污染 |

**正确性定理（Scene-Conditioned Publication-Grade Soundness）**
在第 53/54 轮 (A22)–(A28) 成立基础上追加：**(A29)** 场景描述子 `z` 在语义等价类上 `L_z`-Lipschitz，`dom_scene` 成员检验偏差 ≤ `ε_dom`；**(A30)** 审稿人对手对类内反例的发现覆盖 ≥ `1-β_R`；**(A31)** 证据种子可交换且 bootstrap 区间覆盖 ≥ `1-α`；**(A32)** 反驳算子使 `vol(Σ)` 单调不增并存在下界 `v_min`。
则对部署场景 `G_*~D`：
```
P(deploy_success) ≥ 1 - Σ_d(1-ρ_min(d))
                      - P(G_* ∉ dom_scene) - ε_dom
                      - β_R - α - P(Rgap > τ_rep)
```
解读：`1-Σ_d(1-ρ_min(d))` 继承自动作-鲁棒层（第 54 轮）；`P(G_*∉dom_scene)+ε_dom` 是**场景错域**代价（通常主导）；`β_R` 是**审稿人漏检**代价；`α` 与 `P(Rgap>τ_rep)` 是**证据不实**代价。四元证书 soundness = 场景有效 ∧ 动作可执行 ∧ 鲁棒达标 ∧ 证据可复现。

## 6. 本轮最大风险

**一句话**：场景条件化与发表级证据把证书从“能力声明”升级为“带有效期、可攻击、可复现的合同”，但其 soundness **同时依赖场景描述子的语义保真、审稿人对手的跨分布覆盖、以及证据协议不可污染**；最危险的不是被证伪，而是证书通过“收窄场景域 + 自建审稿人 + 漂亮置信区间”变得**可发表却空洞**——在污染基准上过拟合、把有效域缩到无部署意义、再用预注册之外的阈值漂移粉饰，于是把“同行评审通过”误当作“真实世界成立”，故必须以 **封存场景族 + 场景域体积下界 `v_min` + 预注册防篡改 + 跨分布红队** 为硬护栏，宁要窄而真的合同，不要宽而假的发表。
