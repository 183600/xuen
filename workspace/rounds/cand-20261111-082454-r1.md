# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++ / v31；灵感循环第 6 轮；本轮灵感：「排行榜」×「数据标注」）

> 第 54 轮把技能组合建立在动作空间剖面 α_S、组合图 G_S、云边映射 γ_ce 与联合证书 J 之上。但 α_S 与 ρ 的“真值”并不来自系统内部，而来自两个更上游、更社会化的过程：**排行榜**决定“哪个技能更强”，**数据标注**决定“什么算成功/失败”。本轮把评估过程本身对象化。核心矛盾：H22：排行榜是被选择性优化的目标，一旦证书以榜单分数为依据，系统会优化“可排名性”而非真实能力（Goodhart）；H23：标注是带来源、噪声与激励的人工产物，标注误差沿 `α_S → ρ → G_S → J` 逐层放大，并被排行榜反向选择，形成自证循环。

## 0. 直觉与动机

**灵感 1（排行榜 → 把名次从标量变成区间与证书）**
直觉：排行榜不是真值，而是一个**带方差的估计器**。`S_i ≻ S_j` 应读作偏好概率，而非事实。证书不应写 `rank(S)=3`，而应写 `rank_ε(S)=[r_lo, r_hi]` 并附 `R_cert=(CI, coverage, eval_hash, annotator_mix)`。只有当区间**不跨越任何决策阈值**时，才允许按名次做部署决策。榜单是“测量仪”，不是“判决书”。

**灵感 2（数据标注 → 标注溯源与噪声传播）**
直觉：每个标签 ℓ 都应携带 provenance：谁标的、用什么协议、与谁一致、何时标、工具链版本。用混淆矩阵 `Λ_{y,ℓ}` 建模噪声，把能力量变成**标注条件化**版本 `ρ_S(d|Λ)`、`α_S(a|Λ)`，并给出最坏情况界 `ρ^L_S(d)=min_{Λ:||Λ−Λ0||≤ε_L} ρ_S(d;Λ)`。标注误差因此从“隐藏假设”变成“证书里的显式维度”。

**灵感 3（排行榜 × 标注的耦合 → 自证循环与 Goodhart 绊线）**
直觉：最危险的不是单点噪声，而是闭环：榜单偏好某类技能 → 标注预算向它们倾斜 → 它们的标注更干净/更多 → 榜单进一步偏好它们。定义 `gaming gap G = E[score] − E[true utility]`，用**私有留出集 + provenance shift 检验**检测。排行榜必须“可审计”，而不是“可优化”；公开榜与私有榜必须在数据与标注者上双重隔离。

**灵感 4（评估金字塔 𝔼 → 证书升级的前置条件）**
直觉：在第 54 轮的鲁棒性-动作金字塔之上叠加评估层 `𝔼`：`𝔼0` 原始标签，`𝔼1` 标注溯源，`𝔼2` 排行榜区间，`𝔼3` 部署决策。跨层传递证书需同时携带 `ρ`、`A_cert`、`E_cert`；任一层 provenance 不完备或 rank 区间跨越阈值，就**禁止向上一层升级**。这把“证据质量”变成可判定的门禁。

**灵感 5（主动标注路由 → 把标注预算当在线资源）**
直觉：不是所有标签都值得标。按 `证书敏感度 × 不确定度 × 决策影响力` 排序，把预算投向“会改变 rank 区间或把 ρ 拉回 ρ_min 以上”的动作与维度。标注从一次性数据工程，变成证书闭环里的**在线控制变量**；这同时抑制自证循环（预算按信息增益分配，而非按当前排名分配）。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（标注溯源与完备度）**
标签 ℓ 的溯源 `Prov(ℓ) = (annotator, protocol, κ, t, tool, seed)`，其中 κ 为标注者间一致性（Krippendorff α / Cohen κ）。标签集 D 的溯源完备度 `CP(D) = |{ℓ : Prov(ℓ) 完整}| / |D|`。

**定义 122（标注噪声模型与标注条件化能力）**
真值 y、观测 ℓ，混淆矩阵 `Λ_{y,ℓ}=P(ℓ|y)`，噪声半径 `ε_L = ||Λ − I||_∞`。标注条件化鲁棒性
```
ρ^L_S(d) = min_{Λ : ||Λ−Λ0||_∞ ≤ ε_L} ρ_S(d; Λ)
α^L_S(a) = min_{Λ : ||Λ−Λ0||_∞ ≤ ε_L} α_S(a; Λ)
```
组合与证书均以 `ρ^L, α^L` 取代原来的 `ρ, α`。

**定义 123（排行榜估计器与名次区间）**
`L : 技能集 → 名次`；成对偏好 `P(S_i ≻ S_j) = σ(β_i − β_j)`。名次证书
`R_cert = (CI_{1−δ}, coverage, hash(D_eval), annotator_mix)`，稳健名次 `rank_ε(S) = [r_lo, r_hi]` 由 bootstrap 重采样与标签扰动（在 `ε_L` 球内）联合取包络。

**定义 124（排行榜有效性与 gaming gap）**
`Val(L) = 1 − P(rank reversal | distribution shift)`；`G = E[score] − E[true utility]`。可部署条件：
```
G ≤ γ_g  ∧  Val(L) ≥ v_min  ∧  rank_ε(S) 不跨越决策阈值
```

**定义 125（评估契约）**
`E_contract = (D_public, D_private, Λ0, ε_L, Protocol, Provenance, ShiftTest)`：
- `D_public ∩ D_private = ∅`，且两组标注者集合尽量不重叠；
- 标注协议冻结（协议变更须重新校准 `Λ0`）；
- provenance 为必填字段，缺省即判 `dom_E(T)=out`；
- `ShiftTest` 为公开榜与私有榜的分布漂移检验。

**定义 126（标注-排行榜联合证书）**
`E_cert = (Prov, Λ, ε_L, rank_ε, R_cert, Val, G, evidence)`。部署门禁：
```
dom_E(T)=in  ∧  δ_a < Θ_a  ∧  G ≤ γ_g  ∧  CP(D_eval) ≥ c_min
⇒ 允许 J 升级为可部署证书
```
`evidence` 至少包含：私有留出集结果、标注协议版本、名次 bootstrap 分布、provenance shift 报告。

## 2. 关键算法 伪代码

### IP-121 APT（Annotation Provenance Tracker）

```python
def annotate_with_provenance(items, annotators, protocol):
    labels = []
    for x in items:
        votes = [a.label(x, protocol) for a in annotators]
        y_hat, kappa = consensus(votes)          # 多数/加权共识 + 一致性
        labels.append(Label(x, y_hat, prov=Prov(
            annotator=[a.id for a in annotators], protocol=protocol.version,
            kappa=kappa, t=now(), tool=protocol.tool, seed=protocol.seed)))
    return LabelSet(labels)
```

### IP-122 LNR（Label-Noise Robust calibration）

```python
def noise_robust_profile(skill, labels, anchors, eps_L):
    # 用锚点（已知真值的少量样本）估计混淆矩阵
    Lambda0 = estimate_confusion(labels, anchors)
    Lambda_worst = worst_case_confusion(Lambda0, eps_L)   # ||Λ-Λ0||∞ ≤ eps_L
    alpha_L = {a: min_profile(skill, a, Lambda) 
               for a in skill.actions for Lambda in Lambda_worst}
    rho_L   = {d: min_robustness(skill, d, Lambda)
               for d in skill.dims for Lambda in Lambda_worst}
    return alpha_L, rho_L, Lambda0
```

### IP-123 BTR（Bradley-Terry Ranking with intervals）

```python
def ranking_with_certificate(skills, D_eval, eps_L, n_boot=1000, delta=0.05):
    scores = []
    for _ in range(n_boot):
        D_b = perturb_labels(resample(D_eval), eps_L)
        beta = fit_bradley_terry(skills, D_b)
        scores.append(rank_from_beta(beta))
    lo = percentile(scores, 100 * delta / 2)
    hi = percentile(scores, 100 * (1 - delta / 2))
    return RankInterval(lo, hi), R_cert(CI=(lo,hi), coverage=1-delta,
                                        eval_hash=hash(D_eval))
```

### IP-124 GST（Gaming / Goodhart Tripwire）

```python
def goodhart_tripwire(L_public, D_private, skills, gamma_g, v_min):
    score_pub = L_public.score(skills)
    util_priv = evaluate_true_utility(skills, D_private)
    G = mean(score_pub) - mean(util_priv)
    reversal = rank_reversal_rate(L_public, D_private, skills)
    Val = 1.0 - reversal
    if G > gamma_g or Val < v_min:
        return ('block', G, Val, 'private_holdout_disagrees')
    return ('ok', G, Val)
```

### IP-125 EAC（Evaluation Audit Certificate）

```python
def evaluation_certificate(skills, label_set, L_public, D_private, cfg):
    cp = provenance_completeness(label_set)
    if cp < cfg.c_min:
        return ('reject', 'provenance_incomplete', cp)
    alpha_L, rho_L, Lambda0 = noise_robust_profile_set(skills, label_set, cfg)
    if not probeset_covers(rho_L, alpha_L, cfg.dims, cfg.actions):
        return ('reject', 'uncertainty_unbounded', cp)
    rank_eps, R = ranking_with_certificate(skills, label_set, cfg.eps_L)
    status, G, Val = goodhart_tripwire(L_public, D_private, skills, cfg.gamma_g, cfg.v_min)
    if status == 'block':
        return ('reject', 'goodhart_risk', G, Val)
    return ('ok', E_cert(Prov, Lambda0, cfg.eps_L, rank_eps, R, Val, G, evidence))
```

### IP-126 ALR（Active Labeling Router）

```python
def active_label_router(candidates, certificates, budget):
    chosen = []
    while budget > 0:
        x = max(candidates, key=lambda c:
                cert_sensitivity(c, certificates)
                * uncertainty(c) * decision_impact(c))
        chosen.append(x)
        budget -= label_cost(x)
        candidates.remove(x)
    return chosen   # 标注结果回灌 IP-121/122，刷新 E_cert
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| APT | O(|D|·|A_ann|) | O(|D|) | 共识一致、provenance 字段完整 |
| LNR | O(|A|·|Λ|·|𝔇_ρ|) | O(|A|+|𝔇_ρ|) | 锚点可辨识 Λ0、最坏界 sound |
| BTR | O(n_boot·(|S|+|D|)) | O(n_boot·|S|) | bootstrap 覆盖名义置信度 |
| GST | O(|S|·|D_private|) | O(|D_private|) | 公私隔离、shift 检验有效 |
| EAC | O(|S|·|A| + n_boot·|D|) | O(|A|+|S|) | 门禁单调、缺 provenance 即否决 |
| ALR | O(budget·|C|) | O(|C|) | 信息增益估计无偏、预算闭合 |

**正确性定理（Label–Ranking Aware Certificate Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 真实混淆矩阵落在 `ε_L` 球内，锚点集足以辨识 `Λ0`；**(A30)** 公开榜与私有留出集在数据与标注者上均可交换（或 shift 已被 `Val` 计入）；**(A31)** 名次 bootstrap 的经验覆盖率收敛到 `1−δ`。
则部署成功概率满足
```
P_success ≥ 1 − Σ_d (1 − ρ^L_min(d)) − β_E − P(δ_a > Θ_a)
            − P(G > γ_g) − P(rank_ε 跨越阈值) − L_ρ·ε_L
```
其中 `L_ρ` 为鲁棒性谱对标签噪声的 Lipschitz 常数。关键：**证书先验标注噪声**、**名次以区间进入决策**、**公开榜不得与私有留出集同源**。

## 4. 实验设计 E162–E166

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 标注溯源对证书误差的影响 | 溯源完备度 `CP` vs 下游证书错误率 | 高 `CP` 组错误率下降 ≥ 30% |
| E163 标注噪声鲁棒性 | `ε_L` 增大时的性能衰减 | 在 `ε_L=0.1` 处衰减 ≤ 8% |
| E164 名次区间覆盖率 | 经验覆盖率 vs 名义 `1−δ` | 偏差 ≤ 3% |
| E165 Goodhart 绊线 | gaming gap 检出 AUC / 假阳性 | AUC ≥ 0.85，FPR ≤ 10% |
| E166 主动标注预算效率 | 达同等证书有效性所需标注量 | 节省 ≥ 40% |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 自证循环（榜单↔标注） | 高 | 公私双榜隔离 + 标注者去重 + provenance shift 检验 |
| 最坏情况 `ρ^L` 过于保守 | 高 | 锚点校准 + 分层 `ε_L`（按维度/标注者） |
| 名次区间过宽导致不可决策 | 中 | 主动标注路由 + 增加判别性评测样本 |
| provenance 元数据本身可伪造 | 高 | 签名/时间戳 + 第三方抽检 + 协议冻结 |
| 私有集泄漏或反复使用 | 中 | 一次性/轮换留出集 + 访问审计 |

## 6. 本轮最大风险

**一句话**：把排行榜与数据标注纳入证书，等于承认“证据本身带激励与噪声”，但二者闭环会互相污染形成自证循环——榜单偏好决定标注投向、标注投向又反过来确认榜单；若没有真正独立的私有留出集、去重标注者与 provenance 审计，证书只会把“被优化出来的分数”当作“真实能力”，因此宁可让名次区间保守到无法决策，也绝不把公开榜当作可信真值。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-EvalAudit（APT×LNR×BTR×GST×EAC×ALR）

> 承接第 54 轮产物 v31（GroundEdge-GenSim+++）。本轮把**评估过程本身**对象化，在动作-鲁棒性双证书之上增加**标注溯源、标注噪声传播、排行榜区间化、Goodhart 绊线**四个算子：
> - **APT（Annotation Provenance Tracker）**：标签携带溯源与一致性，缺 provenance 即否决；
> - **LNR（Label-Noise Robust calibration）**：混淆矩阵 + 最坏界，得到 `ρ^L, α^L`；
> - **BTR（Bradley-Terry Ranking with intervals）**：名次由标量变为 `rank_ε=[r_lo,r_hi]` + `R_cert`；
> - **GST（Goodhart / Gaming Tripwire）**：私有留出集 + shift 检验，检测 `gaming gap G`；
> - **EAC（Evaluation Audit Certificate）**：标注-排行榜联合证书，作为 `J` 升级门禁；
> - **ALR（Active Labeling Router）**：按证书敏感度分配标注预算，抑制自证循环。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/116/118/120 以纳入评估不确定性。

def joint_transfer_certify_v2(J_source, L_target, phi, E_cert, budgets):
    if E_cert is None or E_cert.G > budgets.gamma_g:
        return ('reject', 'evaluation_unreliable', E_cert)
    rho_target = coupling_correction(J_source.rho, K, phi)
    delta_rho = {d: max(0, J_source.rho[d] - rho_target[d]) for d in J_source.rho}
    delta_a = alignment_drift(J_source.gamma_ce, phi)
    delta_rho_total = sum(delta_rho.values()) + budgets.L_rho * E_cert.eps_L
    if delta_rho_total > budgets.delta_rho or delta_a > budgets.delta_a:
        return ('reject', 'budget_exceeded', delta_rho_total, delta_a)
    if domain_check_robust(J_source.R, compute_action_domain(J_source, phi, L_target)) != 'in':
        return ('reject', 'domain_mismatch')
    return ('ok', TRC_Joint_v2(J_source, L_target, E_cert,

**正确性定理（Label–Ranking Aware Certificate Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 真实混淆矩阵落在 `ε_L` 球内且锚点可辨识 `Λ0`；**(A30)** 公开榜与私有留出集在数据/标注者上可交换，或漂移已被 `Val(L)` 计入；**(A31)** 名次 bootstrap 的经验覆盖率收敛到 `1−δ`。
则
```
P_success ≥ 1 − Σ_d(1 − ρ^L_min(d)) − β_E − P(δ_a > Θ_a)
            − P(G > γ_g) − P(rank_ε 跨越阈值) − L_ρ·ε_L
```
关键：**组合前提先验标注噪声**、**名次以区间进入决策**、**公开榜与私有留出集严格异源**、**provenance 缺省即拒绝**。

## 6. 本轮最大风险

**一句话**：把排行榜与数据标注纳入证书，等于承认“证据本身带激励与噪声”，但二者闭环会互相污染形成自证循环——榜单偏好决定标注投向、标注投向又反过来确认榜单；若没有真正独立的私有留出集、去重标注者与 provenance 审计，证书只会把“被优化出来的分数”当作“真实能力”，因此宁可让名次区间保守到无法决策，也绝不把公开榜当作可信真值。
