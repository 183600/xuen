# 第 56 轮（承接第 55 轮语义-接触层 IP-121–126；灵感循环第 2 轮；本轮灵感：「行为树」×「人机协作」）

> 第 55 轮把“接触在语义上是否可信”写进了全身生存核 `K(Σ)`，解决了单机器人“感知不确定 → 接触约束 → 动力学可行”的闭环。本轮把视角从**单个机器人的可行动集**抬到**任务结构与共享权威**。核心矛盾：**H24**：行为树的组合安全性隐含“同步 tick、叶子动作原子、前置条件在 tick 内不被外部改写”，而人类介入是异步的，会在 tick 中途改掉前置条件，局部正确的子树组合起来并不全局安全；**H25**：人机协作里真正的隐藏状态不只是“人的意图”，还有**权威**——模式混淆与不可逆的权限交接，比单纯的意图误判更致命；**H26**：只优化机器人自身的可读性（legibility）会让动作变慢、过度可预测，却仍可能因为读不懂人而失败，必须把“人读懂机器人”和“机器人读懂人”做成**双向裕度**并写进证书。

## 0. 直觉与动机

**灵感 1（行为树 → 契约携带节点，而非仅控制流）**
直觉：行为树最诱人的地方是“子树可复用、fallback 可反应”，但标准 BT 只规定了**什么时候 tick 谁**，没有规定**这次 tick 必须兑现什么**。把每个节点升级为携带契约 `(P,Q,I,A,J)` 的 **契约行为树 CBT**：`P` 前置条件、`Q` 后置条件、`I` 不变量、`A` 权威范围、`J` 第 54/55 轮的动作-接触证书。于是 BT 的组合性从“语义直觉”变成“**证明义务能否被消解**”：sequence 要求 `Q_i ⇒ P_{i+1}`，fallback 要求 `¬Q_i ⇒ P_j`，parallel 要求不变量可同时满足且权威范围不冲突。

**灵感 2（人机协作 → 权威是一等状态，不是附加标签）**
直觉：协作失败最常见的不是“机器人没看见人”，而是“机器人以为人知道它要干什么”。把**权威** `α∈{人类主导, 共享, 机器人主导}` 提升为一等状态，交接必须走“宣告 → 确认 → 宽限 → 提交”的显式协议。关键约束是 **可逆性**：任何一次权威转移，都必须在 `τ_rev` 内存在一条让人重新接管、且不违反协同不变量的路径；不可逆动作必须经过**提交门控**，在人的确认或显式宽限之后才允许执行。

**灵感 3（双向可读性 → 两个方向的不确定性都要有裕度）**
直觉：机器人可读性（legibility）解决“人能不能预测机器人下一步”，人的可预测性（predictability）解决“机器人能不能预测人下一步”。只做前者会得到“动作很慢、很好猜，但机器人仍不知道人要什么”的假协作。于是定义两个赤字：`d_leg`（机器人动作对人的意外度）与 `d_pred`（机器人对人类意图/行为的不确定度），两者都必须有非负裕度，并共享一个**意外预算**；预算耗尽时，机器人应主动询问、放慢或退回安全姿态，而不是硬猜。

**灵感 4（人机协同生存核 → 不只避人，还要保留人的退路）**
直觉：第 55 轮的 `K(Σ)` 只问“机器人有没有可行动作”，人机协作还要问“人有没有退路”。把生存核扩成 `K_H`：除动力学、接触、平衡外，额外要求 `Esc(x',α',τ_h)=1`——在人的反应时间 `τ_h` 内，人始终存在一条到达自身安全集的路径，且机器人能在这条走廊外完成制动。机器人不是“自己不撞人”就安全，而是**不能把人的逃离通道堵死**。

**灵感 5（契约失败 → 解释—协商—制动，而非静默 fallback）**
直觉：BT 的 fallback 常被当成“换一个动作继续干”。在协作场景里，契约失败往往意味着“人对当前模式的理解与机器人不一致”。因此 fallback 的第一职责不是继续任务，而是**把失败变成可沟通的证据**：用反事实解释“如果刚才人做了 X，我会走另一条分支”，并请求重新协商权威或目标。安全制动是最后兜底，不是默认选项。

**灵感 6（行为树鲁棒谱 → 在人的扰动球里评估整棵树）**
直觉：单节点鲁棒不等于整树鲁棒。人的意图标签会错、响应会延迟、行为会抖动。定义 BT 鲁棒谱 `ρ_BT`：在意图误分类、人的行为噪声、通信/响应延迟的联合扰动球内，整棵树**契约保持且协同不变量不破**的最坏概率。它把第 53 轮的维度谱、第 55 轮的语义谱，统一到任务结构层。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（契约行为树 CBT）**
行为树 `T = (V, E, r, κ)`，`r` 为根，节点类型 `κ(v) ∈ {Seq, Fall, Par, Dec, Leaf}`。每个节点携带契约
`C_v = (P_v, Q_v, I_v, A_v, J_v, τ_v)`：
- `P_v/Q_v/I_v`：状态与人类信念上的前置/后置/不变量谓词；
- `A_v ⊆ 𝒜`：该节点允许使用的权威范围；
- `J_v`：叶子技能在第 54/55 轮得到的动作-接触证书，控制节点为组合证书；
- `τ_v`：tick 截止期。
叶子 `v=(skill s)` 取 `P_v ⊆ dom(J_s)`、`Q_v = post(J_s)`、`J_v = J_s`；控制节点契约由子节点合成。

**定义 128（契约复合与可部署性）**
记 `{P} v {Q}` 为节点契约成立。复合规则：
- **Seq**：`{P} v_1 {Q_1}`、`{Q_1 ∧ I} v_2 {Q_2}`，义务 `Q_1 ⇒ P_{v_2}`；
- **Fall**：`{P} v_1 {Q_1}`、`{P ∧ ¬Q_1} v_2 {Q_2}`，输出 `Q_1 ∨ Q_2`；
- **Par**：`I_{v_1} ∧ I_{v_2}` 可满足，且 `A_{v_1} ∩ A_{v_2} = ∅` 或存在权威偏序；
- **Dec**：重试/超时装饰器必须保持 `I` 不变。
令 `Obl(T)` 为全部局部义务。`discharge(T) ⇔ ∀o∈Obl(T), o 可满足 ∧ 所有叶子 J_v 有效 ∧ 协同不变量 I_h 成立`。
`deployable(T) ⇔ discharge(T) ∧ authority_consistent(T) ∧ ρ_BT ≥ ρ_min`。

**定义 129（共享权威与可逆交接）**
权威状态 `α ∈ 𝒜 = {H, S, R}`（人类主导/共享/机器人主导），交接关系 `H ⊆ 𝒜×𝒜`。模式宣告 `μ_t` 为机器人广播的当前权威，人的权威信念 `b_h(α_t)`，模式混淆
`mc_t = 1 - b_h(α_t)`。
交接 `α→α'` **可逆**当且仅当存在人的动作序列在 `τ_rev` 内回到 `α`，且全程满足 `I_h`：
`Rev(α→α') = 1 ⇔ ∃ σ_h, |σ_h|≤τ_rev : α --σ_h--> α ∧ I_h 恒成立`。
不可逆动作集 `A_irr` 必须通过提交门控：`b_h(α') ≥ θ_ack ∧ m_leg ≥ θ_commit` 才允许执行。

**定义 130（双向意图裕度）**
人类潜在意图 `ι ∈ ℐ`，机器人信念 `b_t(ι)`，机器人策略 `π_r`，人对机器人下一动作的预测 `q_h(a|x)`。
- 可读性赤字 `d_leg(a|x) = -log q_h(a|x)`（机器人动作给人的意外度）；
- 可预测性赤字 `d_pred(x) = H(b_t(ι)) + E_{ι~b_t}[d(ι, ι̂_t)]`（意图熵 + 意图估计误差）。
裕度 `m_leg = θ_leg - d_leg`、`m_pred = θ_pred - d_pred`，并要求累计意外预算
`Σ_t d_leg(a_t|x_t) ≤ Δ_leg`。
`viable_comm(x,a) = 1 ⇔ m_leg(a) ≥ 0 ∧ m_pred(x) ≥ 0 ∧ 预算未超`。

**定义 131（人机协同生存核）**
`K_H(Σ, b_t) = { (x,α) | ∃u,λ : f(x,u,λ)=ẋ ∧ supp(λ)⊆C^+(Σ) ∧ x'∈𝒳_safe ∧ m_b(x')≥θ_b ∧ Esc(x',α',τ_h)=1 ∧ viable_comm(x,u)=1 }`。
其中 `Esc(x',α',τ_h)=1` 表示在反应时间 `τ_h` 内，人存在到达 `𝒳_{h,safe}` 的路径，且机器人能在该走廊之外制动。`K_H ⊆ K(Σ)`，是把第 55 轮生存核按“人的退路”做的进一步内收缩。

**定义 132（协同行为证书与 BT 鲁棒谱）**
`J_H = (J_s^{core}, O_discharge, α_{0:T}, d_leg^{max}, d_pred^{max}, δ_h, ρ_BT, evidence)`：
- `O_discharge`：全部契约义务的消解记录；
- `α_{0:T}`：权威轨迹，要求每步可逆或走提交门控；
- `δ_h = sup_t ||b_t - b̂_t||`：人类模型扰动实测量；
- `ρ_BT(ε_h,ε_i,ε_τ) = inf_{||Δb||≤ε_h, ||Δι||≤ε_i, ||Δτ||≤ε_τ} P( ∧_v (P_v⇒Q_v) ∧ I_h )`：联合扰动球内契约保持的最坏概率。
若 `discharge(T)`、权威轨迹可逆、`d_leg^{max}≤Θ_leg`、`d_pred^{max}≤Θ_pred`、`δ_h≤Θ_h` 且 `ρ_BT≥ρ_min`，则协同行为可部署。

## 2. 关键算法 伪代码

### IP-127 CBT（Contract-Carrying Behavior Tree）

```python
def compile_cbt(root, skill_lib, human_inv):
    for v in postorder(root):
        if v.kind == 'leaf':
            s = skill_lib[v.skill]
            v.contract = Contract(P=s.pre, Q=s.post, I=s.inv,
                                  A=v.authority, J=s.certificate,
                                  tau=v.deadline)
        else:
            v.contract = synthesize_contract(
                [c.contract for c in v.children], v.kind, human_inv)
    return CBT(root, obligations=extract_obligations(root))
```

### IP-128 CCV（Contract Composition Verifier）

```python
def verify_cbt(T, human_inv, alpha_checker, solver):
    obligations = []
    for v in postorder(T.root):
        obligations += local_obligations(v)
        if not solver.implies(v.contract.P, v.contract.Q, human_inv):
            obligations.append(('node_unsat', v.id))
    unsat = [o for o in obligations if not solver.check(o, human_inv)]
    if unsat:
        return ('reject', 'contract_unsat', unsat)
    if not alpha_checker.consistent(T):
        return ('reject', 'authority_conflict', alpha_checker.conflicts(T))
    return ('ok', CertificatePlan(obligations, T))
```

### IP-129 AHP（Authority Handover Protocol）

```python
def handover(alpha, target, b_h, m_leg, tau_rev, tau_ann):
    broadcast_mode(target)                      # 模式宣告
    if target in IRREVERSIBLE:
        if b_h[target] < theta_ack or m_leg < theta_commit:
            return ('block', 'commit_gate', target)
    if not reversible_path(alpha, target, tau_rev):
        return ('block', 'irreversible_handover', target)
    ack = wait_ack(target, tau_ann)
    if not ack:
        return ('renegotiate', alpha, 'no_ack')
    return ('ok', target, 'committed')
```

### IP-130 BLM（Bidirectional Legibility Margin）

```python
def legibility_filter(plans, x, b_h, b_t, thresholds, budget):
    feasible = []
    for a in plans:
        d_leg = -log(q_h(a, x) + eps)
        d_pred = entropy(b_t) + human_model_error(b_t)
        if (d_leg <= thresholds.leg and d_pred <= thresholds.pred
                and budget.remaining(x) >= d_leg):
            feasible.append((a, d_leg, d_pred))
    if not feasible:
        return ('ask_or_slow', explain_intent(b_t))
    return ('ok', argmin(feasible, key=lambda z:
            task_cost(z[0]) + lambda_leg*z[1] + lambda_pred*z[2]))
```

### IP-131 CHS（Collaborative Human Shield）

```python
def collaborative_shield(u_nom, x, alpha, K_H, C_plus, human_pred, W):
    u = qp_solve(
        H=W, g=-W @ u_nom,
        constraints=[
            viability_constraint(x, u, K_H.K_in),
            contact_constraint(u, C_plus),
            friction_cone_constraint(u, mu),
            escape_corridor_constraint(x, u, human_pred.escape_set, tau_h),
            authority_scope_constraint(u, alpha),
        ],
    )
    if u is None or projection_gap(u, u_nom) > Delta_u:
        return safe_retreat(x, human_pred), 'shield_infeasible'
    return u, 'ok'
```

### IP-132 CBC（Collaborative Behavior Certificate）

```python
def collaborative_certificate(T, traj, b_t, budgets, sampler):
    plan = verify_cbt(T, human_inv, alpha_checker, solver)
    if plan[0] != 'ok':
        return ('reject', 'contract_unsat', plan)
    alpha_tr = authority_trajectory(traj)
    if not all(reversible_path(alpha_tr[i], alpha_tr[i+1], tau_rev)
               for i in range(len(alpha_tr)-1)):
        return ('reject', 'irreversible_handover')
    d_leg = max(legibility_deficit(a, x, b_h) for a, x in traj)
    d_pred = max(prediction_deficit(b_t) for _ in traj)
    delta_h = human_model_discrepancy(traj, b_t)
    rho = bt_robustness_spectrum(T, sampler, budgets.eps_h,
                                 budgets.eps_i, budgets.eps_tau)
    if (d_leg > budgets.leg or d_pred > budgets.pred
            or delta_h > budgets.h or rho < budgets.rho_min):
        return ('reject', 'collaborative_budget_exceeded',
                d_leg, d_pred, delta_h, rho)
    return ('ok', CollabCert(plan, alpha_tr, d_leg, d_pred, delta_h, rho))

def bt_robustness_spectrum(T, sampler, eps_h, eps_i, eps_tau):
    worst = 1.0
    for pert in sampler.human_ball(eps_h, eps_i, eps_tau, worst_case=True):
        p = empirical_contract_preservation(T, pert, sampler.states)
        worst = min(worst, p)
    return worst
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CBT | O(|V|·cost(synth)) | O(|V|) | 叶子契约与 J_s 一致、合成规则 sound |
| CCV | O(|V|·|Obl|·SMT) | O(|V|+|Obl|) | 义务不可漏、人类不变量显式建模 |
| AHP | O(|𝒜|²·τ_rev) | O(|𝒜|²) | 可逆性判定完整、提交门控不可绕过 |
| BLM | O(|Π|) 每 tick | O(|ℐ|) | 人类信念校准、意外预算闭合 |
| CHS | O(QP) 每次 | O(|A_WB|+|𝒳_h|) | 逃离走廊约束 sound、QP 不可行即退 |
| CBC | O(|V|+|Obl|+N_pert·|X|) | O(|X|) | ρ_BT 最坏情形可复现、δ_h 预算闭合 |

**正确性定理（Collaborative Contract Soundness）**
假设第 54 轮 (A26)–(A28)、第 55 轮 (A29)–(A32) 成立；并新增：
**(A33)** 所有叶子证书 `J_s` sound，且契约合成规则在 `I_h` 下保序；
**(A34)** 每个 tick 落在单一权威 epoch 内，人类中途介入要么在 `τ_d` 内被监控器检出、要么只发生在提交边界；
**(A35)** 人类意图信念经温度/分位数校准，ECE ≤ ε_cal，反应时间 ≤ τ_h；
**(A36)** 权威交接可逆且模式宣告在 `τ_ann` 内被观察到，不可逆动作必经提交门控；
**(A37)** 协同护盾不可行时回退 `safe_retreat ∈ K_H`，且人的逃离走廊不被侵占。
则部署后单步协同安全概率：
```
P_safe ≥ 1 - P(契约义务违反) - P(意图扰动超出 ε_i) - P(人类模型漂移 > ε_h)
          - P(权威交接竞态) - P(护盾不可行) - P(人类违反逃离假设)
```
关键：**契约把任务结构变成可消解的证明义务，权威把协作模式变成可逆的显式状态，双向裕度把“谁读不懂谁”变成可预算的量，护盾把人的退路当作硬约束**。四者任一层失守，都不允许把“行为树结构看起来正确”当作“人机协作已经安全”。

## 6. 本轮最大风险

**一句话**：契约行为树把任务结构变成可验证的证明义务，协同证书把权威、双向可读性与人的退路一起闭合，但其 soundness **根本依赖人类模型在部署域内的校准与“人会利用逃离走廊”这一假设**；一旦意图信念系统偏移、或人做出与模型相反的避让/接管行为，BT 会在一组“自认为已消解”的契约上运行，组合证明反而为错误模式提供了虚假保证——因此必须以 **校准的人类模型 + 可逆权威 + 协同护盾 + 主动询问降级** 四重护栏，宁可停下来问，绝不把契约的“已证明”当作人的“已理解”。

# 第 56 轮产物 · 创新点清单 v32：GroundEdge-HRC+++（CBT×CCV×AHP×BLM×CHS×CBC）

> 承接 v31（IP-115–120 动作-协同层）与第 55 轮语义-接触层（IP-121–126）。本轮新增**人机协同契约层**，把“行为树的任务分解”与“人机共享权威”升级为**可组合验证、可逆交接、双向可读、带人类模型预算的协同证书**：
> - **CBT（Contract-Carrying Behavior Tree）**：节点携带 `(P,Q,I,A,J)` 契约；
> - **CCV（Contract Composition Verifier）**：Hoare 式复合规则 + 证明义务消解；
> - **AHP（Authority Handover Protocol）**：宣告-确认-宽限-提交，权威可逆；
> - **BLM（Bidirectional Legibility Margin）**：`d_leg` 与 `d_pred` 双向赤字与意外预算；
> - **CHS（Collaborative Human Shield）**：含人的逃离走廊约束的协作生存核护盾；
> - **CBC（Collaborative Behavior Certificate）**：契约消解、权威轨迹、双向裕度、人类模型扰动与 BT 鲁棒谱一次闭合。
>
> IP 编号：IP-127~IP-132（共 6 个新增）。

```python
def compile_cbt(root, skill_lib, human_inv):
    for v in postorder(root):
        if v.kind == 'leaf':
            s = skill_lib[v.skill]
            v.contract = Contract(P=s.pre, Q=s.post, I=s.inv,
                                  A=v.authority, J=s.certificate,
                                  tau=v.deadline)
        else:
            v.contract = synthesize_contract(
                [c.contract for c in v.children], v.kind, human_inv)
    return CBT(root, obligations=extract_obligations(root))
```

### IP-128 CCV

```python
def verify_cbt(T, human_inv, alpha_checker, solver):
    obligations = []
    for v in postorder(T.root):
        obligations += local_obligations(v)
        if not solver.implies(v.contract.P, v.contract.Q, human_inv):
            obligations.append(('node_unsat', v.id))
    unsat = [o for o in obligations if not solver.check(o, human_inv)]
    if unsat:
        return ('reject', 'contract_unsat', unsat)
    if not alpha_checker.consistent(T):
        return ('reject', 'authority_conflict', alpha_checker.conflicts(T))
    return ('ok', CertificatePlan(obligations, T))
```

### IP-129 AHP

```python
def handover(alpha, target, b_h, m_leg, tau_rev, tau_ann):
    broadcast_mode(target)                      # 模式宣告
    if target in IRREVERSIBLE:
        if b_h[target] < theta_ack or m_leg < theta_commit:
            return ('block', 'commit_gate', target)
    if not reversible_path(alpha, target, tau_rev):
        return ('block', 'irreversible_handover', target)
    ack = wait_ack(target, tau_ann)
    if not ack:
        return ('renegotiate', alpha, 'no_ack')
    return ('ok', target, 'committed')
```

### IP-130 BLM

```python
def legibility_filter(plans, x, b_h, b_t, thresholds, budget):
    feasible = []
    for a in plans:
        d_leg = -log(q_h(a, x) + eps)
        d_pred = entropy(b_t) + human_model_error(b_t)
        if (d_leg <= thresholds.leg and d_pred <= thresholds.pred
                and budget.remaining(x) >= d_leg):
            feasible.append((a, d_leg, d_pred))
    if not feasible:
        return ('ask_or_slow', explain_intent(b_t))
    return ('ok', argmin(feasible, key=lambda z:
            task_cost(z[0]) + lambda_leg*z[1] + lambda_pred*z[2]))
```

### IP-132 CBC

```python
def collaborative_certificate(T, traj, b_t, budgets, sampler):
    plan = verify_cbt(T, human_inv, alpha_checker, solver)
    if plan[0] != 'ok':
        return ('reject', 'contract_unsat', plan)
    alpha_tr = authority_trajectory(traj)
    if not all(reversible_path(alpha_tr[i], alpha_tr[i+1], tau_rev)
               for i in range(len(alpha_tr)-1)):
        return ('reject', 'irreversible_handover')
    d_leg = max(legibility_deficit(a, x, b_h) for a, x in traj)
    d_pred = max(prediction_deficit(b_t) for _ in traj)
    delta_h = human_model_discrepancy(traj, b_t)
    rho = bt_robustness_spectrum(T, sampler, budgets.eps_h,
                                 budgets.eps_i, budgets.eps_tau)
    if (d_leg > budgets.leg or d_pred > budgets.pred
            or delta_h > budgets.h or rho < budgets.rho_min):
        return ('reject', 'collaborative_budget_exceeded',
                d_leg, d_pred, delta_h, rho)
    return ('ok', CollabCert(plan, alpha_tr, d_leg, d_pred, delta_h, rho))

def bt_robustness_spectrum(T, sampler, eps_h, eps_i, eps_tau):
    worst = 1.0
    for pert in sampler.human_ball(eps_h, eps_i, eps_tau, worst_case=True):
        p = empirical_contract_preservation(T, pert, sampler.states)
        worst = min(worst, p)
    return worst
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CBT | O(|V|·cost(synth)) | O(|V|) | 叶子契约继承 J_s，合成规则保序 |
| CCV | O(|V|·|Obl|·SMT) | O(|V|+|Obl|) | 义务完整、`I_h` 显式进入求解 |
| AHP | O(|𝒜|²·τ_rev) | O(|𝒜|²) | 可逆性判定完整、提交门控不可绕过 |
| BLM | O(|Π|) 每 tick | O(|ℐ|) | 人类信念校准、意外预算闭合 |
| CHS | O(QP) 每次 | O(|A_WB|+|𝒳_h|) | 逃离走廊 sound、不可行即退 |
| CBC | O(|V|+|Obl|+N_pert·|X|) | O(|X|) | ρ_BT 最坏可复现、δ_h 预算闭合 |

**正确性定理（Collaborative Contract Soundness）**
假设第 54 轮 (A26)–(A28)、第 55 轮 (A29)–(A32) 成立；新增
**(A33)** 叶子证书 sound 且契约合成保序；
**(A34)** tick 落在单一权威 epoch，人类中途介入在 `τ_d` 内被检出或只发生于提交边界；
**(A35)** 人类意图信念已校准（ECE ≤ ε_cal），反应时间 ≤ `τ_h`；
**(A36)** 权威交接可逆、模式宣告在 `τ_ann` 内被观察、不可逆动作必经提交门控；
**(A37)** 护盾不可行时回退 `safe_retreat ∈ K_H`，且不侵占人的逃离走廊。
则部署成功概率：
```
P_safe ≥ 1 - P(契约义务违反) - P(意图扰动 > ε_i) - P(人类模型漂移 > ε_h)
          - P(权威交接竞态) - P(护盾不可行) - P(人类违反逃离假设)
```
关键：**任务结构可验证、权威可逆、双向可读、人的退路是硬约束**；任何一层失守都不允许用“结构正确”替代“协作已证实”。

## 6. 本轮最大风险

**一句话**：CBT/CCV/AHP/BLM/CHS/CBC 把人机协作从“行为树调参”升级为“契约消解 + 可逆权威 + 双向可读 + 人类模型预算”的联合证书，但其 soundness **根本依赖人类模型在部署域的校准、以及“人会利用逃离走廊”的假设**；一旦意图信念系统偏移或人做出与模型相反的避让/接管，组合证明会在一组“自认为已消解”的契约上给出虚假保证，故必须以 **校准人类模型 + 可逆权威 + 协同护盾 + 主动询问降级** 四重护栏，宁可停下来问，绝不把契约的“已证明”当作人的“已理解”。
