# 第 58 轮（承接第 57 轮「MFSL×XMC×PTM」IP-133~138；灵感循环第 1 轮；本轮灵感：「多机评测」×「可解释性」）

> 第 57 轮把安全赌注改押在"少样本可校准、跨模态可对账、个性化有界的证据承诺"上，并以共形带、EV-xmodal 限 L1、授权单向有界三重护栏兜底。它的风险自陈留下两个更深的缺口：**(a)** 元先验所谓"分布内"其实只是"这一族机器的分布内"——换一台不同标定、不同磨损、不同传感器批次的机器，整个校准契约可能整体失效，而跨模态对账无法识别"全模态共享同一感知栈"的共因错误；**(b)** 解释仍是被渲染给人看的旁路，不参与承诺判定，无法保证它说出的理由就是决策真正的理由；一个流利但失真的解释比没有解释更危险，因为第 57 轮的 PTM 恰好允许信任换授权。本轮两个灵感各补一条腿：**多机评测**把"证据独立"从模态维度推广到机器维度——用来源谱系与相关上界折算有效独立度 n_eff，识别"同一祖先的 N 台机器"这种伪复现；并用留一机元评估（LOMO）把"坏先验普遍"变成可测量的机器级泛化缺口。**可解释性**把解释从旁路提升为**承诺前置的忠实性证书**——只有通过必要性/充分性反事实检验、且置信不超过证据认证下界的解释才允许外显；每条外显解释还必须附带可被探针反驳的预测，由探询闭环检验。核心命题升级为 **"多机可独立、解释可证伪、评测不反身的证据说可信"**。

核心矛盾：
- **H29（多机共谋）**：N 机一致 ≠ N 条独立证据。同谱系机器的误差由共享模型、共享标定、共享语料诱导而高度相关；朴素"多机投票"只是把第 57 轮的"同一模态问五遍"升级成"同一祖先问五遍"，n_eff≪N 时共识只是伪复现。
- **H30（解释悖论）**：解释要安全相关就必须忠实，而忠实性检验需要反事实干预（删除/替换证据），恰是系统试图避免的高成本动作；更麻烦的是，不忠实但流畅的解释会通胀信任，而信任会换授权——解释因此是新的攻击面。
- **H31（评测反身性）**：多机评测是发现机器级盲区的唯一手段，但一旦成为目标，机队会向基准同质化，测量本身摧毁了它要测的"独立性"；评测数据若回流训练，元先验将自我确认。

## 0. 直觉与动机

**灵感 1（多机评测 → 来源谱系与有效独立度）**
直觉：机队里的"重复"有两种。五台不同工厂、不同传感器、不同标定的机器都探到冰面滑，这是复现；同一批次、同一模型哈希、同一天标定的五台机器一起错，这是一条证据的五次回声。把它们同权投票，等于给"共因错误"发五份证书。做法：给每条证据挂来源谱系（模型哈希、标定版本、传感器 SKU、训练语料 id、维护批次），用共因核给出机器间相关上界 C_ij，把复现数从"台数 N"换成**有效独立度 n_eff=(Σw)²/Σ_{ij} w_i w_j C_ij**；同一共谋簇内的重复只计一条，并合并其权重。

**灵感 2（多机评测 → 留一机元评估 LOMO）**
直觉：第 57 轮的元先验在"见过的机器/区域"上摊销，真正的部署问题是"换一台没见过的机器还准不准"。留一机元评估：每次把目标机器及其同谱系簇整簇留出，只用其余机器训练元模型，再在这台机器上测校准、OOD 检出与共形覆盖；报告最差机器而非平均值。于是"坏先验普遍"从一句风险自陈变成一个可测量的数：机器间不可迁移缺口。共形带按机器簇分层（Mondrian），保证"每族机器"而非"平均机器"的覆盖。

**灵感 3（可解释性 → 忠实解释证书）**
直觉：解释最容易犯的错不是"说错细节"，而是"说的理由根本不是决策的理由"——删掉它引用的证据，决策照旧。把解释当证书来验：归因 a 选出摘要集 S，做两次反事实重算——**必要性**（删 S 决策翻转）与**充分性**（只留 S 决策保持）；再要求解释传达的置信不超过证据门认证下界（解释不得比证据更自信）。三项全过才外显，否则诚实弃权 "⊥：我解释不了，因此请不要据此信任"，并自动提出一次探询。解释不再是承诺之后的装饰，而是承诺之前的检查。

**灵感 4（可解释性 → 解释即探询）**
直觉：一个真解释必然蕴含可证伪的预测——"若这面真是干冰，则下一次触探的刚度应上升"。把每条解释附带的预测集交给 PCE 闭环：选信息增益最大的探针去检验解释本身。被反驳的解释立即降级，并回溯其依赖的证据与元先验；无法生成任何可证伪预测的解释，本身就是一个 OOD 信号（系统对该区域没有可操作的世界模型）。

**灵感 5（两灵感合流 → 证据门六类与防反身评测）**
直觉：第 57 轮证据门五类在本轮各获一个维度：EV-probe* 增加"机器簇共形覆盖"、EV-xmodal 增加"跨模态不共谋"、新增 **EV-fleet**（多机独立复现，仅限 L1）、EV-human 增加"解释置信上限"约束。多机评测同时是攻击面：用密封/轮换的隐藏机器、LOMO 隔离、评测数据隔离与证据膨胀检测，保证"评测者本身不被评测对象优化"。安全纵深从五层到七层：元先验错 ∧ OOD 门漏检 ∧ 模态共谋 ∧ 机队共谋 ∧ 解释不忠实 ∧ 无裕度 ∧ 人也错。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（多机来源谱系与有效独立度 MSP）** 机队 ℱ={r_1,…,r_N}，证据源 e 携带谱系 ℓ(e)=(模型哈希,标定版本,传感器SKU,语料id,维护批次)。共因核给出相关上界 C_ij≥Corr(err_i,err_j)，C_ii=1；共谋簇为 C 的 c_0-连通分量。有效独立度 n_eff(E)=(Σ_i w_i)²/(Σ_{i,j} w_i w_j C_ij)∈[1,N]。独立复现判据是 **n_eff(E)≥N_rep**，而非 |E|≥N_rep；同簇内多源只按一条证据计并合并其 w。C 只允许用"上界"（对真实相关取保守高估），因为低估相关会系统性放大 n_eff。

**定义 140（留一机元评估 LOMO）** 对目标机器 r，元训练集 𝒟_meta^{(-r)}=𝒟_meta∖Clust(r)（整簇留出，防同谱系泄漏）。机器级契约：∀r，ECE_k(q_φ^{(-r)})≤ε_meta^m(k)，OOD 漏检≤δ_ood^m，Mondrian 共形带 C_cf^m(r) 对每簇覆盖≥1−α_conf（按簇数做 union bound，宁可保守）。评测报告强制含逐机最差值、n_eff 与簇数，禁止只报均值；评测数据进入"密封区"，不得参与元训练、超参选择或早停。

**定义 141（忠实解释证书 FEX）** 决策 d=δ(E)∈{commit_j, abstain, probe}，归因 a:E→[0,1]，摘要 S=top-k(a)。必要性 𝖭(S)：δ(E∖S)≠commit 或风险上升越过阈值；充分性 𝖲(S)：δ(S)=commit 且接触等级不变；置信上限：c_exp≤c_cert(E)（证据门认证下界）。忠实度 F=𝖭∧𝖲∧(c_exp≤c_cert)。仅 F=1 允许外显；否则返回 ⊥ 并生成探询建议。解释本身永不提高授权，也不得替代 EV-human 的佐证。

**定义 142（可证伪解释 EPX）** 每条外显解释附带预测集 P_exp={p_j}，p_j 为"若解释成立，则探针 q_j 的观测应落在区间 I_j"。PCE 在预算内选 q*=argmax_j I(p_j;观测)−cost(q_j) 检验；出现反驳则解释降级，依赖该解释的元先验/证据被回溯标记；P_exp=∅ 触发解释-OOD（EOD）信号，区域按 OOD 处理并退回共形带。

**定义 143（多机证据门 MEG 与六类证据）** 证据类 {EV-probe*, EV-visit, EV-margin, EV-xmodal, EV-fleet, EV-human}。EV-fleet ⇔ 来源跨≥2 个共谋簇 ∧ n_eff≥N_rep ∧ 各源校准/ρ 声明 ∧ 与融合同侧 ∧ 等级=L1；它与 EV-xmodal 合计最多占据"单次 L1 佐证"的一个槽位（防相关证据重复计数）。不可逆接触必要证据集仍为 {EV-probe*∨EV-margin}∪human 佐证，EV-fleet/EV-xmodal 一律不得进入。OOD 区域在机器簇共形带建立前禁 EV-fleet。

**定义 144（抗反身评测 AGE）** 评测协议 Π=(密封隐藏机队 ℱ_hidden, 轮换周期 T_rot, LOMO 划分, 隐藏区域, 隔离训练区, 膨胀检测器, 谱系熵监测)。指标下界取逐机最差；证据膨胀 Δ_inf=报告成功率−审计实测成功率，Δ_inf>θ_inf ⇒ 该来源整体降权并回溯；谱系熵 H_lin 低于 θ_H ⇒ 触发"机队单一化"告警（独立性被评测本身侵蚀）。Π 的评测目标与部署目标分离，评测者不参与被评测对象的优化回路。

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| MSP | O(\|E\|²)/证据门 | O(N²) 相关阵 | C 取上界、n_eff 只低估 |
| LOMO | 离线 O(\|ℱ\|·T_meta) | O(\|ℱ\|·\|𝒟_meta\|) | 整簇留出、评测密封 |
| FEX | \|E\|≤K_EXP 精确 O(2^{\|E\|})，否则 MC O(m·\|E\|) | O(\|E\|) | 必要性/充分性可重算 |
| EPX | O(k_expl·C_VOI)/检查点 | O(\|P_exp\|) | 反驳即回溯 |
| MEG | O(\|σ\|+\|E\|²) | O(\|σ\|) | 六类证据、单槽防重复 |
| AGE | 离线 O(\|ℱ_hidden\|·T_eval) | O(评测集) | 密封、轮换、隔离训练 |

**正确性定理（FEAT 概要）**：在 A33–A40 上加 (A41) 相关上界诚实（C_ij≥真相关，n_eff 只会低估）；(A42) LOMO 无泄漏且评测数据隔离；(A43) 解释检验健全（决策可确定性重算、归因覆盖证据集）；(A44) 解释置信不超认证下界；(A45) 抗反身评测协议密封且膨胀检测诚实。则：
(i) **多机证据健全性**：EV-fleet 的假复现失效率 ≤ δ_rep+ε_eff(n_eff)+ε_meta^m，且随相关上界收紧单调不增；
(ii) **解释门保守性**：F≠1 时只弃权或探询；任何解释路径只能经"减少承诺/触发探询/维持不变"影响系统，不提高承诺风险，解释亦不提高授权；
(iii) **LOMO 泛化界**：未见机器失效率以 1−α 概率不超过逐机最差经验值加共形松弛，密封评测下报告无偏；
(iv) **终止性**：每检查点在 k_probes+k_cons+k_expl 内终止；
(v) **部署界**：按检查点联合界，并含 δ_ood^m、δ_fleet、δ_leak。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 相关阵低估 → n_eff 虚高 → 伪独立 | 高 | 只取上界 + 谱系审计 + 同簇合并 + 事后证伪回溯 |
| 忠实性检验不可判定或被对抗操纵 | 高 | 多重随机消融 + 独立审计 + 无法证明即弃权 |
| 评测反身/机队单一化 | 高 | 密封隐藏机队 + 轮换 + 评测数据隔离 + 谱系熵告警 |
| 解释通胀信任 → 换授权 | 中高 | 置信上限 c_exp≤c_cert + 解释不参与授权 + 审计 |
| 反事实重算开销 | 中 | 仅承诺检查点 + top-k 小集 + MC 近似 + 缓存 |

## 6. 本轮最大风险

**一句话**：本轮把安全赌注押在"解释忠实度"与"多机独立度"的可审计性上，但二者都由系统自身的反事实重算与相关模型定义——一旦整支机队共享同一个错误世界模型，它会得到自洽而"忠实"的错误解释，并因"多机一致"被误当作独立复现；而多机评测的基准压力又会把机队训练成同质单一种群，亲手摧毁它赖以生存的独立性——必须以相关上界保守化、忠实性弃权默认、EV-fleet 仅限 L1、评测密封与谱系熵告警四重护栏，宁可接受"看起来不准也不合群"的异质机队，也不要一个自洽而错误的单一文化。

### IP-139 MSP（来源谱系与有效独立度）

```python
def provenance_graph(fleet):
    for r in fleet:
        r.lineage = (r.model_hash, r.calib_ver, r.sensor_sku,
                     r.corpus_id, r.maint_batch)
    C = {}
    for a, b in pairs(fleet):
        C[a][b] = C[b][a] = correlation_upper_bound(a.lineage, b.lineage)
    clusters = connected_components(C, threshold=c_0)
    return C, clusters

def fleet_ess(sources, C):
    # 相关越强 → n_eff 越低；独立等权时退化为 |sources|
    W = sum(s.w for s in sources)
    denom = sum(si.w * sj.w * C[si.robot][sj.robot]
                for si in sources for sj in sources)
    return W * W / denom

def merge_same_cluster(sources, clusters):
    # 同一共谋簇内的多源只计一条证据（权重合并，不计数）
    out = {}
    for s in sources:
        k = cluster_of(s.robot, clusters)
        out[k] = out.get(k, 0.0) + s.w
    return out
```

### IP-140 LOMO（留一机元评估与簇分层共形）

```python
def lomo_meta_eval(fleet, M, k_max):
    report = []
    for r in fleet:
        train = [j for j in fleet if cluster_of(j) != cluster_of(r)]
        q_phi = train_amortized_posterior(train, z=region_context)   # 整簇留出

        belt = mondrian_conformal(train, group=cluster_of(r),
                                  alpha=alpha_conf / n_clusters)     # union bound
        report.append((r.id, worst_case(ece), ood, coverage(belt, r)))
    assert not eval_leakage(report, sealed_zone)
    return worst_per_machine(report), report   # 禁止只报均值

def machine_aware_infer(M, r, obs, meta):
    inf = meta_few_shot_infer(M, r, obs, meta)
    if inf.cls == 'ID' and meta.machine_shift(r) > theta_shift:
        return conformal_belt(meta.residuals, group=cluster_of(r),
                              alpha=alpha_conf / n_clusters)  # 机器漂移 → 回退
```

### IP-141 FEX（忠实解释证书）

```python
def faithful_explain(d, E, gate, persona, M):
    a = attribution(E, M)                       # 证据归因（LOO 影响或 Shapley 采样）
    S = topk(a, K_EXP)
    nec = (decide(E - S, M) != d.commit)        # 必要性：删掉就翻转
    suf = (decide(S, M) == d.commit and
           level(S, M) == level(E, M))          # 充分性：只留它仍成立
    c_cert = gate.cert_lower(confidence(E, M))
    if not (nec and suf):
        return EXPLAIN_ABSTAIN, propose_probe(S, E, M)
    text = render(S, persona)
    if render_conf(text, persona) > c_cert:     # 解释不得比证据更自信
        return EXPLAIN_ABSTAIN, propose_probe(S, E, M)
    return text, falsifiable_predictions(S, E, M)

def explanation_never_promotes(persona, ev):
    # 解释与授权完全解耦：只有事后实测 verdict 能改 auth
    return ev != 'explanation' or persona.auth_unchanged()
```

### IP-142 EPX（解释即探询）

```python
def falsifiable_predictions(S, E, M):
    P = []
    for e in S:
        for q in admissible_probes(region_of(e), M):
            if counterfactual_flip(E, e, q, M):       # 若去掉 e 且 q 改变结果
                P.append(Prediction(q, interval=expected_obs(q, S, M),
                                    flip_if=outside))
    return P                                     # 空集 → EOD 信号

def explanation_probe_loop(M, cp, P_exp, budget):
    while P_exp and budget.left:
        q = argmax(P_exp, key=lambda p: mutual_info(p, M) - cost(p.q))
        obs = execute_probe(q.q, cap=F_abs)
        M = xmodal_fuse(M, cp.region, obs)
        for p in list(P_exp):
            if p.refuted_by(obs):
                demote_explanation(p, M)             # 解释降级
                M = backtrack_evidence(p.S, M)       # 回溯依赖证据/元先验
                P_exp.remove(p)
        budget.spend(q.q)
    if not P_exp and explanation_unfalsifiable(cp):
        M = mark_eod(cp.region, M)                   # 解释-OOD → 退回共形带
    return M
```

### IP-138→PCE++（探-诺-演++：元推断 × 对账 × 忠实解释 × 解释探询）

```python
def probe_commit_evolve_pp(x0, M, task, budget, consent, personas, meta, evalreg):
    route = plan_on_map(M, task, risk_model)

    for cp in route.checkpoints:

            p = argmax(admissible_probes(cp, M, F_abs),
                       key=lambda q: voi_meta_pessimistic(q, M, inf) - cost(q))
            if voi_meta_pessimistic(p, M, inf) < theta_voi: break
            M, _, D = xmodal_fuse(M, cp.region, execute_probe(p, cap=F_abs))
            if D > theta_D and 'consensus' not in cp.done:
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| MSP | O(\|E\|²)/证据门 | O(N²) | C 取上界、n_eff 只低估（A41） |
| LOMO | 离线 O(\|ℱ\|·T_meta)；推理不变 | O(\|ℱ\|·\|𝒟_meta\|) | 整簇留出、评测密封（A42） |
| FEX | 精确 O(2^{\|E\|})（\|E\|≤K_EXP）或 MC O(m·\|E\|) | O(\|E\|) | 必要性/充分性可重算（A43）、c_exp≤c_cert（A44） |
| EPX | O(k_expl·C_VOI)/检查点 | O(\|P_exp\|) | 反驳即回溯、空预测→EOD |
| MEG | O(\|σ\|+\|E\|²) | O(\|σ\|) | 六类证据、EV-fleet 限 L1、单槽防重复 |
| AGE | 离线 O(\|ℱ_hidden\|·T_eval) | O(评测集) | 密封、轮换、隔离、膨胀检测（A45） |
| PCE++ | O(\|CP\|·(k_p+k_c+k_expl)·(C_VOI+d_φ)) | O(\|V\|+\|σ\|) | 三预算终止、四态完备 |

**正确性定理（Fleet-Explain Audited Trust, FEAT）**
假设 A22–A40 成立；**(A41)** 相关上界诚实：C_ij≥真相关，n_eff 只低估、不虚高，共谋簇覆盖所有 c_0 以上相关链；**(A42)** LOMO 无泄漏：目标机器整簇移出元训练，评测数据密封且不进训练/选型；**(A43)** 解释检验健全：决策 δ(·) 可确定性重算、归因覆盖证据集、反事实干预不被旁路；**(A44)** 解释置信不超认证下界，且解释与授权完全解耦；**(A45)** 抗反身评测：隐藏机队密封轮换、膨胀检测与谱系熵监测诚实。则：

1. **多机证据健全性**：EV-fleet 假复现失效率 ≤ δ_rep + ε_eff(n_eff) + ε_meta^m；同簇重复不增加 n_eff，相关上界收紧时失效率单调不增；EV-fleet 不进入不可逆接触必要证据集。
2. **解释门保守性**：仅 F=1 且无反驳的解释外显；F≠1 只能弃权或转探询。解释路径只经 (a) 减少/撤回承诺、(b) 触发探询、(c) 维持不变影响系统；不存在"解释→更高承诺/更高授权"的升险路径。
3. **LOMO 泛化界**：未见机器失效率以概率 ≥1−α 不超过逐机最差经验值 + 共形松弛；密封隔离下报告无偏，泄漏概率 ≤δ_leak。
4. **终止性**：每检查点在 k_probes+k_cons+k_expl 内终止于 {承诺, 绕行, L2 协商, 安全停}。
5. **部署界**：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta^m(k) + δ_probe + ε_h + δ_ood^m·α_conf
                   + δ_xm·1[L1] + δ_fleet·1[L1] + δ_expl_audit)
             − P(𝓜 陈旧未检出) − P(相关阵低估未审计) − P(评测泄漏)
             − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
```

关键：**独立度按 n_eff 记账而不是按台数记账**（把"同一祖先问五遍"挡在门外）；**解释先自证再示人，证不了就弃权并转探询**（把可解释性从说服工具变成安全门）；**评测密封且逐机最差**（让测量不摧毁被测量的独立性）。

## 6. 本轮最大风险

**一句话**：本轮把安全赌注押在"解释忠实度"与"多机独立度"的可审计性上，但忠实度由系统自身的反事实重算定义、独立度由系统自身的相关模型定义——一旦整支机队共享同一个错误世界模型，它会得到自洽而"忠实"的错误解释，并因"多机一致"被误当作独立复现；多机评测的基准压力又会把机队训练成同质单一种群，亲手摧毁它赖以生存的独立性。必须以相关上界保守化、忠实性弃权默认、EV-fleet 仅限 L1、评测密封与谱系熵告警四重护栏兜底，宁可接受"看起来不准也不合群"的异质机队，也不要一个自洽而错误的单一文化。
