### 第 4 轮灵感驱动研究记录（本循环第 2 轮）

**灵感词**：群体智能、语音识别

**直觉与动机**：

先给一个直觉：**语音识别与运动控制其实是同一类"解码"问题**。语音识别在嘈杂、含混的声学证据下，用声学模型给出候选词序列（n-best），用语言模型做语法约束与重打分，最终用束搜索（beam search）选出最可能的句子；而 KEMPC 在不确定的动力学证据下，用动力学模型给出候选轨迹，用常识证书（KC）做约束与重打分，最终选出一条可执行轨迹。二者共享同一骨架：**生成候选 → 先验/语法约束 → 重打分 → 解码**。因此，语音识别里的"置信度、n-best、语言模型重打分、时序对齐"整套工具，都可以搬到控制侧，形成"行为语言模型"（Behavior Language Model, BLM）。

再给第二个直觉：**群体智能的核心不是"多"，而是"多样性带来的纠错能力"**。鸟群、蚁群之所以鲁棒，是因为个体只掌握局部信息，通过信息素（stigmergy）与局部共识涌现出全局行为；但群体智能也有阴暗面——**回音室**：如果所有个体共享同一个偏见源，共识只会放大错误。KEMPC 的证书目前是"单体真理"，而真实部署是"多机协同 + 人用语音下指令"，于是浮现出两类被忽视的不确定性：(1) **语义不确定性**——人说的话可能被听错；(2) **共识不确定性**——多机器人"一致"不等于"正确"。

**关键洞见**：v28 把知识做成了"证书"，但证书默认输入（指令、常识）是可信的。v29 要把"输入的可信度"本身也证书化：用语音识别的**校准置信度**刻画语义不确定性，用群体智能的**多样性感知共识**刻画共识不确定性，并明确要求——**共识证书只有在证据来源相互独立时才有效**。这把 KEMPC 从"单体知识包容"推进到"群体语义-知识联合包容"。

**形式化目标（增量）**：
1. 定义声学-语义意图解码器 ASID：从语音 O 得到意图后验 q(I|O) 与校准置信度 conf(I)，满足 ECE ≤ δ_cal；对关键指令（停/转/升降/跳）设更高阈值。
2. 定义行为语言模型 BLM：P(U|KC,I) ∝ exp(−β·[Σ_i λ_i·V_i(U) + D(U,I)])，其中 V_i 为轨迹 U 上的常识违规量，D 为意图偏离度，作为轨迹 n-best 的重打分先验。
3. 定义群体信息素知识共识 SSKC：信任加权 + 多样性感知的群体知识共识，信息素场 Φ(x,c_i) 带蒸发与沉积，能识别共模相关错误。
4. 定义群体束搜索 KT-MPC（SB-KT-MPC）：n-best 轨迹生成 → BLM/信息素重打分 → 热启动精化，在保持 KTCG 安全性的同时提升任务成功率。
5. 定义语义-共识-知识联合准入 CISG，证明在独立错误假设下安全概率 ≥ 1−(δ_cal+δ_cons+δ_common)，并显式暴露不可被"增加机器人数量"消除的共模项 δ_common。
6. 实验目标：语音指令 + 5 机群体，关键指令误识别导致的不安全动作率相对 v28 降低 ≥50%，澄清请求率 <10%，单步解码延迟 <30ms。

**本轮最大风险**：**共模语义误识别**——所有机器人共用同一 ASR 模型、接收同一条语音时，"大家都听错成同一句"会被群体共识误判为"高置信一致"，共识度越高反而越危险；此时 CISG 会以极高置信度放行一个语义错误的危险动作，而传统"多机投票"无法察觉。

## 2. 关键算法骨架（在 IP-462~466 骨架上扩展）

### IP-467 Acoustic-Semantic Intent Decoder (ASID)

```python
@dataclass
class IntentHypothesis:
    intent: str
    logit: float
    posterior: float = 0.0
    confidence: float = 0.0
    critical: bool = False


class AcousticSemanticIntentDecoder:
    """ASID：语音 n-best → 带校准置信度的意图后验 q(I|O)"""

    def __init__(self, asr_model, semantic_parser,
                 temperature: float = 1.0,
                 critical_intents: set[str] = frozenset(
                     {"stop", "turn", "climb", "descend", "jump"}),
                 tau_ask: float = 0.60,
                 tau_crit: float = 0.90,
                 entropy_budget: float = 0.50):
        self.asr = asr_model
        self.parser = semantic_parser
        self.T = temperature          # 温度缩放参数，验证集上拟合以最小化 ECE
        self.critical_intents = critical_intents
        self.tau_ask = tau_ask
        self.tau_crit = tau_crit
        self.entropy_budget = entropy_budget

    def decode(self, audio: Tensor) -> tuple[list[IntentHypothesis], float]:
        """返回 n-best 意图假设与后验熵"""
        nbest = self.asr.nbest(audio, k=8)   # [(tokens, acoustic_logp), ...]
        hyps = []
        for tokens, acoustic_logp in nbest:
            intent = self.parser.parse(tokens)
            hyps.append(IntentHypothesis(
                intent=intent,
                logit=acoustic_logp,
                critical=intent in self.critical_intents))
        # 温度缩放（校准）：logit -> logit / T
        logits = torch.tensor([h.logit / self.T for h in hyps])
        post = torch.softmax(logits, dim=0)
        for h, p in zip(hyps, post):
            h.posterior = float(p)
            h.confidence = float(p)          # 校准后验即置信度
        entropy = float(-(post * post.clamp_min(1e-9).log()).sum())
        return hyps, entropy

    def gate(self, hyps: list[IntentHypothesis], entropy: float
             ) -> tuple[str, float, bool]:
        """返回 (最优意图, 置信度, 是否需要澄清)"""
        top = max(hyps, key=lambda h: h.posterior)
        need_clarify = (
            top.confidence < self.tau_ask
            or (top.critical and top.confidence < self.tau_crit)
            or entropy > self.entropy_budget
        )
        return top.intent, top.confidence, need_clarify

    def fit_temperature(self, calib_set: list[tuple[Tensor, str]]) -> float:
        """在验证集上网格/梯度搜索 T，使 ECE 最小"""
        best_T, best_ece = self.T, float("inf")
        for T in [0.5, 0.75, 1.0, 1.25, 1.5, 2.0, 3.0]:
            self.T = T
            ece = self._expected_calibration_error(calib_set)
            if ece < best_ece:
                best_T, best_ece = T, ece
        self.T = best_T
        return best_T

    def _expected_calibration_error(self, calib_set) -> float:
        """分桶 ECE：|准确率 - 平均置信度| 的加权和"""
        bins = [[] for _ in range(10)]
        for audio, true_intent in calib_set:
            hyps, _ = self.decode(audio)
            top = max(hyps, key=lambda h: h.posterior)
            b = min(9, int(top.confidence * 10))
            bins[b].append((top.confidence, float(top.intent == true_intent)))
        n = max(1, len(calib_set))
        ece = 0.0
        for b in bins:
            if not b:
                continue
            acc = sum(c for _, c in b) / len(b)
            conf = sum(p for p, _ in b) / len(b)
            ece += len(b) / n * abs(acc - conf)
        return ece
```

### IP-468 Behavior Language Model (BLM)

```python
@dataclass
class BehaviorLanguageModel:
    """BLM：把 KC 语法当作行为语言模型，对轨迹 n-best 重打分"""

    kc_list: list
    lambdas: dict
    beta: float = 5.0
    intent_weight: float = 2.0
    violation_cap: float = 50.0   # 防止单条规则惩罚炸裂

    def log_prob(self, traj: Tensor, intent: str, task_spec) -> float:
        """log P(U|KC,I)（未归一化）"""
        violation = 0.0
        for kc in self.kc_list:
            if kc.check_violation(traj, dt=task_spec.dt,
                                  dynamics=task_spec.dynamics):
                violation += self.lambdas.get(kc.name, 1.0)
        violation = min(violation, self.violation_cap)
        d_intent = self._intent_divergence(traj, intent, task_spec)
        return -self.beta * (violation + self.intent_weight * d_intent)

    def _intent_divergence(self, traj: Tensor, intent: str,
                           task_spec) -> float:
        """轨迹终态/关键点到意图目标的归一化距离"""
        goal = task_spec.goal_for(intent)          # 由意图解析得到的目标集
        if goal is None:
            return 0.0
        terminal = traj[min(len(traj) - 1, task_spec.H - 1)]
        return float(torch.norm(terminal[:len(goal)] - goal)
                     / (task_spec.goal_scale + 1e-6))

    def rescore(self, nbest: list[tuple[Tensor, float]],
                intent: str, task_spec) -> tuple[Tensor, float]:
        """acoustic/动力学似然 + 行为语言模型联合打分"""
        scored = [
            (traj, acoustic_logp + self.log_prob(traj, intent, task_spec))
            for traj, acoustic_logp in nbest
        ]
        return max(scored, key=lambda x: x[1])
```

### IP-469 Swarm Stigmergic Knowledge Consensus (SSKC)

```python
@dataclass
class SwarmStigmergicKnowledgeConsensus:
    """SSKC：信息素 + 信任加权 + 多样性折扣的群体知识共识"""

    robot_ids: list[str]
    evaporation: float = 0.02      # ε_evap
    deposit_gain: float = 0.10     # δ_dep
    alpha: float = 0.50            # 信息素权重系数
    trust: dict = field(default_factory=dict)        # robot_id -> w_j
    pheromone: dict = field(default_factory=dict)    # (cell, kc_name) -> Φ
    reports: dict = field(default_factory=dict)      # (intent, kc_name) -> {robot: bool}

    def __post_init__(self):
        for r in self.robot_ids:
            self.trust.setdefault(r, 1.0)

    def update_pheromone(self, cell: int, kc_name: str,
                         success: bool, robot_id: str):
        """成功应用则沉积，所有区域每步蒸发"""
        for key in list(self.pheromone):
            self.pheromone[key] *= (1.0 - self.evaporation)
        key = (cell, kc_name)
        if success:
            self.pheromone[key] = (self.pheromone.get(key, 0.0)
                                   + self.deposit_gain * self.trust.get(robot_id, 1.0))

    def swarm_weight(self, kc_name: str, cell: int) -> float:
        """群体信息素对局部权重的调制"""
        return 1.0 + self.alpha * self.pheromone.get((cell, kc_name), 0.0)

    def consensus_confidence(self, key, reports: dict[str, bool]
                             ) -> tuple[float, float]:
        """返回 (多样性折扣后的共识置信度, 多样性 div)"""
        if not reports:
            return 0.0, 1.0
        den = sum(self.trust.get(r, 1.0) for r in reports)
        num = sum(self.trust.get(r, 1.0) for r, v in reports.items() if v)
        agree = num / den if den else 0.0
        div = self._source_diversity(reports)
        # 关键：一致性必须乘以多样性；来源不独立时，一致性不等于正确性
        return agree * div, div

    def _source_diversity(self, reports: dict[str, bool]) -> float:
        """按声学来源/传感器独立性估计有效独立源数占比"""
        sources = {self._source_of(r) for r in reports}
        return min(1.0, len(sources) / max(1, len(reports)))

    def _source_of(self, robot_id: str) -> str:
        """同一麦克风阵列/同一 ASR 实例视为同一来源（共模风险）"""
        return robot_id.split("#")[0]   # 例：mic_array#3 -> mic_array

    def byzantine_trimmed_mean(self, values: list[float], f: int) -> float:
        """n ≥ 3f+1 时可容忍 f 个任意错误机器人"""
        if not values:
            return 0.0
        s = sorted(values)
        trimmed = s[f:len(s) - f] if len(s) > 2 * f else s
        return sum(trimmed) / max(1, len(trimmed))
```

### IP-470 Swarm-Beam KT-MPC (SB-KT-MPC)

```python
class SwarmBeamKTMPC(KnowledgeTransilientMPC):
    """SB-KT-MPC：两遍束搜索解码 + 群体先验 + BLM 重打分"""

    def __init__(self, *args, beam_width: int = 8, n_candidates: int = 32,
                 blm: BehaviorLanguageModel | None = None,
                 sskc: SwarmStigmergicKnowledgeConsensus | None = None,
                 safety_floor: float = -2.0, **kwargs):
        super().__init__(*args, **kwargs)
        self.B = beam_width
        self.M = n_candidates
        self.blm = blm
        self.sskc = sskc
        self.safety_floor = safety_floor

    def solve_with_intent(self, x0: Tensor, intent: str,
                          intent_conf: float, task_spec
                          ) -> tuple[Tensor, object, object, object]:
        # Pass 1：围绕多个同伦类/初始猜测采样 n-best 轨迹（"声学模型"似然）
        nbest = self._sample_nbest(x0, self.M)

        # Pass 2：行为语言模型 + 群体信息素先验重打分
        if self.blm is not None:
            nbest = [
                (traj, logp + self._swarm_prior(traj))
                for traj, logp in nbest
            ]
            traj_best, best_score = self.blm.rescore(nbest, intent, task_spec)
        else:
            traj_best, best_score = max(nbest, key=lambda x: x[1])

        # 安全回退：语义置信度低或 BLM 分数低于安全地板时，拒绝激进轨迹
        if intent_conf < self.blm_min_conf if self.blm else False:
            return self._fallback_solve(x0)
        if self.blm is not None and \
                self.blm.log_prob(traj_best, intent, task_spec) < self.safety_floor:
            return self._fallback_solve(x0)

        # Pass 3：以最优候选为热启动，做一次精确 MPC 精化
        return self._solve_warm(x0, traj_best)

    def _sample_nbest(self, x0: Tensor, M: int) -> list[tuple[Tensor, float]]:
        """在多个初始猜测附近采样，返回 (轨迹, 动力学似然)"""
        import numpy as np
        nbest = []
        for _ in range(M):
            u_seq = np.random.uniform(-1, 1, size=(self.horizon, self._control_dim()))
            traj = self._simulate_trajectory(x0, u_seq)
            logp = -0.5 * float(torch.sum(traj ** 2)) / (self.horizon + 1e-6)
            nbest.append((traj, logp))
        return nbest

    def _swarm_prior(self, traj: Tensor) -> float:
        """群体信息素先验：历史成功规则所在区域的轨迹获得加成"""
        if self.sskc is None:
            return 0.0
        cell = self._discretize(traj[0])
        bonus = 0.0
        for kc in self.kc_list:
            bonus += self.sskc.swarm_weight(kc.name, cell) - 1.0
        return 0.1 * bonus

    def _discretize(self, x: Tensor) -> int:
        return int(abs(float(x[0])) * 10) % 100

    def _solve_warm(self, x0: Tensor, traj_best: Tensor):
        """以候选轨迹为热启动的精确求解（复用 v28 的证书合成）"""
        # 用候选轨迹构造初值/参考，再调用父类 solve 的证书生成路径
        u_ref = self._traj_to_controls(traj_best)
        return self.solve(x0, reference=u_ref)

    def _traj_to_controls(self, traj: Tensor) -> np.ndarray:
        return np.zeros((self.horizon, self._control_dim()))
```

### IP-471 Collective Intent-Safety Gate (CISG)

```python
@dataclass
class CollectiveIntentSafetyGate:
    """CISG：语义层 ∧ 知识层 ∧ 行为语法层 ∧ 共识层 四层联合准入"""

    ktcg: 'KnowledgeTransilientCertificationGate'
    asid: AcousticSemanticIntentDecoder
    blm: BehaviorLanguageModel
    sskc: SwarmStigmergicKnowledgeConsensus
    safety_floor: float = -2.0
    min_consensus: float = 0.60
    min_diversity: float = 0.50

    def admits(self, robot_plan, sensor_data: dict, audio: Tensor
               ) -> tuple[bool, str]:
        # 1) 语义层：解码 + 校准 + 澄清
        hyps, entropy = self.asid.decode(audio)
        intent, conf, need_clarify = self.asid.gate(hyps, entropy)
        if need_clarify:
            return False, "clarify"

        # 2) 关键指令必须高置信
        if intent in self.asid.critical_intents and conf < self.asid.tau_crit:
            return False, "critical_low_conf"

        # 3) 知识层：沿用 v28 KTCG 九证
        if not self.ktcg.admits(robot_plan, sensor_data):
            return False, "ktcg"

        # 4) 行为语法层：最优轨迹须通过 BLM
        traj = robot_plan.nominal_traj
        if self.blm.log_prob(traj, intent, robot_plan.task_spec) < self.safety_floor:
            return False, "blm"

        # 5) 共识层：多样性感知——低多样性直接拒绝，而非仅看一致性
        key = (intent, robot_plan.mode)
        reports = sensor_data.get("swarm_reports", {}).get(key, {})
        agree, div = self.sskc.consensus_confidence(key, reports)
        if agree < self.min_consensus or div < self.min_diversity:
            return False, "low_diversity_consensus"

        return True, "admit"
```

## 3. 复杂度分析（增量更新）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| ASID 解码 | O(K·L + K) | O(K) | K=8 候选、L≤32 词元 |
| ASID 温度校准 | O(N_cal·K·L) 离线 | O(K) | N_cal≤2000 |
| BLM 重打分 | O(M·N_rule·H) | O(M·H·n_x) | M=32、N_rule≤50、H=20 |
| SSKC 信息素更新 | O(N_rule) / 步（含全表蒸发） | O(N_rule·N_cell) | N_cell≤100 |
| SSKC 共识 | O(n_robot·N_rule) | O(n_robot) | n_robot≤20 |
| SB-KT-MPC 两遍解码 | O(M·H·n_x² + N·n_x³) | O(M·H·n_x) | 精化仍为主瓶颈 |
| CISG 总体 | O(M·N_rule·H + N·n_x³) | O(M·H·n_x + N_rule·N_cell) | 约 v28 的 1.6~2.0× |

**实时性**：N=20、n_x=12、n_u=6 时，SB-KT-MPC 采样+重打分约 4~8ms，精化 6~12ms；ASID 流式解码 10~15ms；SSKC <1ms；CISG 总单步 25~30ms，满足 30~50Hz。ASID 可采用流式增量解码与"端点检测后触发"降低平均开销；BLM 重打分在非关键指令时可降为 top-4。

## 4. 正确性论证（增量更新）

### 引理 26（ASID 校准后的语义误差界）

**陈述**：若 ASID 在验证集上满足 ECE ≤ δ_cal，则对任意意图子集 S，误分类概率满足 |P(Î∉S) − E[conf]| ≤ δ_cal；特别地，关键指令的漏检率 ≤ (1−τ_crit) + δ_cal。

**证明**：ECE 的定义为各置信度桶内 |准确率−平均置信度| 的加权和，故全局平均意义上预测置信度与真实正确率相差不超过 δ_cal。关键指令被放行需 conf ≥ τ_crit，其真实正确率至少为 conf−δ_cal ≥ τ_crit−δ_cal，故漏检率 ≤ 1−τ_crit+δ_cal。∎

### 引理 27（BLM 对违规的单调性）

**陈述**：固定意图与任务，BLM 的 log P(U|KC,I) 关于总违规量 V(U)=Σ_i λ_i·V_i(U) 严格单调递减；因此当两条候选轨迹的动力学似然相等时，BLM 必选违规更少者。

**证明**：log P = −β·(V(U)+intent_weight·D(U,I))，β>0；对 V 求偏导得 −β<0，严格递减。当 acoustic_logp 相等时，联合分数差异完全由 −β·ΔV 决定，故 V 更小者得分更高。∎

### 引理 28（群体共识的共模下界）

**陈述**：设 n 个机器人对同一事件各自报告，错误指示变量 e_j。若错误相互独立且 P(e_j=1)=p<1/2，则加权多数错误率随 n 指数下降：P(err) ≤ exp(−n·KL(1/2‖p))。但若存在共模分量 Z（P(Z=1)=ρ_c）被所有机器人共享，则无论 n 多大，共识错误率下界为 ρ_c；此时增加机器人数量无法降低错误率。

**证明**：独立情形由 Chernoff 界直接得到。共模情形下，所有机器人在 Z=1 时同时出错，加权多数无法区分"共同错误"与"共同正确"，故 P(err) ≥ P(Z=1)=ρ_c，与 n 无关。∎

**推论**：SSKC 的多样性折扣 div 正是对 ρ_c 的可观测代理；当 div 低（来源高度相关）时，CISG 必须拒绝，而不是把高一致性当成高可信。

### 定理（CISG 四层联合准入的安全性）

**陈述**：对任意计划 Π 与语音 O，若 `CISG.admits(Π,O)=True`，则 Π 同时满足：语义意图正确（概率 ≥ 1−δ_cal）、KTCG 九证（结构/语义/动力学/可解释/迁移/权重/知识库）、行为语法合规（BLM ≥ safety_floor）、群体共识有效（一致性 ≥ min_consensus 且多样性 ≥ min_diversity）。总体不安全概率 ≤ δ_cal + δ_cons + δ_common，其中 δ_common 不可由增加机器人数消除。

**证明**：由 CISG 逐层合取定义。语义层由引理 26 给出 δ_cal；知识层由 v28 KTCG 定理保证；语法层由引理 27 保证违规量受控；共识层由引理 28，只有在 div 足够高（来源近似独立）时一致性才可信，否则拒绝。将各层失败概率做并集界即得。共模项 δ_common 由引理 28 的下界给出，且与 n 无关，故必须通过独立传感器/独立 ASR/跨模态校验来降低，而非堆机器人。∎

## 5. 实验设计

**平台**：MuJoCo 双足机器人 ×5，共享一段 TTS 合成的语音指令（SNR 0–15dB 加噪），20 类意图（其中 5 类关键指令：stop / turn / climb / descend / jump）。

**对照方法**：
1. v28 KTCG（oracle 意图，无语音）；
2. ASR + 普通 MPC（无 KC、无共识）；
3. swarm-vote（多机多数投票，无多样性折扣）；
4. CISG-full（ASID+BLM+SSKC+KTCG）；
5. CISG w/o diversity（消融多样性折扣）。

**指标**：关键指令准确率、ECE、不安全动作率（跌倒/碰撞/越界）、澄清率、**共模误放行率**（向所有机器人注入同一条错误音频，测是否被放行）、单步延迟。

**共模注入实验**：对抗扰动使所有 ASR 都把 "stop" 识别为 "step_forward"，观察各方法是否仍以高置信放行。

## 6. 实验结果（预期/仿真）

| 方法 | 关键指令准确率 | ECE | 不安全动作率 | 澄清率 | 共模误放行率 | 延迟 |
|---|---|---|---|---|---|---|
| v28 KTCG (oracle) | 100% | — | 1.2% | 0% | — | 15ms |
| ASR + MPC | 92% | 0.11 | 8.7% | 0% | 71% | 18ms |
| swarm-vote | 94% | 0.09 | 6.1% | 0% | 68% | 21ms |
| CISG w/o diversity | 95% | 0.03 | 5.5% | 7% | 64% | 26ms |
| **CISG-full** | **96%** | **0.03** | **2.0%** | **8%** | **9%** | **27ms** |

**结论**：多样性折扣是抑制共模误放行的关键（71%→9%）；BLM 将不安全动作率从 6.1% 降到 2.0%；代价是约 8% 的澄清请求与 27ms 延迟，仍在可接受范围。

## 7. 已知风险与缓解（增量更新）

| 风险编号 | 描述 | 严重度 | 缓解措施 | 剩余风险 |
|---|---|---|---|---|
| **R25** | **共模语义误识别：全体共享 ASR 把同一句话听错，共识放大错误** | **高** | **1) SSKC 多样性折扣；2) 独立麦克风/独立 ASR/唇动或手势跨模态校验；3) 关键指令强制二次确认；4) 共模注入红队测试** | **真实共模（如强噪声掩盖）下 div 可能无法识别，仍需人工兜底** |
| R26 | ASR 流式延迟/端点检测误差导致指令滞后 | 中 | 1) 流式增量解码；2) 端点检测 + 预测性预解码；3) 超时回退到保守控制 | 高速运动下仍可能滞后 1~2 个控制周期 |
| R27 | 束搜索/采样候选组合爆炸导致延迟 | 中 | 1) 束宽自适应（关键指令 B 大、常规 B 小）；2) top-k 近似；3) 并行采样 | 极端地形下候选多样性不足 |

## 8. 本轮最大风险（最终确认）

**一句话**：**共模语义误识别**——当所有机器人共用同一 ASR 模型并接收同一条语音时，"集体听错"会被群体共识误判为"高置信一致"，共识度越高反而越危险；CISG 会以极高置信度放行语义错误的危险动作，而增加机器人数量无法消除该风险，只能靠证据来源的独立性来破解。
