### IP-497 PSMVK：本体感知自模型有效性核（200–1000 Hz，与模型同频；证书 20–50 Hz）

```python
@dataclass
class ProprioceptiveSelfModelValidityKernel:
    """PSMVK：用本体预测残差给身体模型发证书。
    红线：valid 是模型级合取项，不是第八道轨迹门；只能收缩执行集"""
    model: BodyModel              # M_t = (K, Θ_in, μ, A, C)
    Sigma_r: Any                  # 分层残差协方差
    W: int = 20                   # 残差窗口（200 Hz 下 ~100 ms）
    delta: float = 1e-3           # 误报率
    trust_region: Any = None      # 参数信任域 T_trust

    def update(self, z_t, u_prev, dt) -> ModelCert:
        zhat = self.model.predict(u_prev, dt)            # ẑ_t = h(M_t, u)
        r = z_t - zhat
        d2 = r.T @ inv(self.Sigma_r) @ r                  # 马氏距离²
        self.win.append(d2)
        stat_ok = sum(self.win[-self.W:]) <= chi2.ppf(
            1 - self.delta, self.model.d_z * self.W)
        param_ok = self.model.theta in self.trust_region
        valid = stat_ok and param_ok
        return ModelCert(valid=valid, eps=self.model_error_radius(self.win),
                         version=self.model.version)

    def model_error_radius(self, win) -> float:
        """由残差统计反推参数误差半径 ε：集合成员辨识 + 置信上界（引理 45）。
        保守取残差功率的单调上界；不做无根据的点估计"""

    def identify(self, z_hist, u_hist) -> None:
```

### IP-498 WBBC：浮动基全身平衡与接触核（kc_BCK 内部细化，不新增门）

```python
@dataclass
class WholeBodyBalanceContactKernel:
    """WBBC：把 kc_BCK 从固定基单臂语义细化为浮动基全身语义。
    输入浮动基状态估计（本体感知）与接触集合 C；输出平衡证书"""
    robot: FloatingBaseModel
    mu_foot: float = 0.6
    mu_hand: float = 0.5
    temp_derate: Any = None       # T_temp → τ_max

    def kc_bck_wb(self, x, M_t, base_est, C) -> BalanceCert:
        h = centroidal_momentum(self.robot, x, base_est)
        hdot = finite_diff(h)
        w_des = hdot - gravity_bias(self.robot)            # 期望质心扳手
        # 1) 多接触扳手可行：∃ w_c ∈ ⊕_{c∈C} K_c(μ)  s.t. Σ_c J_c^T w_c = w_des
        w_ok, m_w = solve_contact_wrench_polytope(self.robot, x, C, w_des)
        # 2) ZMP/CMP 落在支撑多边形内
        zmp = zmp_from_centroidal(h, hdot, self.robot)
        m_zmp = signed_distance_to_polygon(zmp, P_support(C))
        # 3) 执行器力矩/热可行
        tau = inverse_dynamics(self.robot, x, base_est)
        m_tau = min(tau_max(T_temp) - abs(tau))
        ok = w_ok and m_zmp >= 0 and m_tau >= 0
        return BalanceCert(ok=ok, margin=min(m_w, m_zmp, m_tau),
                           eps_used=M_t.eps)
```

### IP-499 PRT：本体感知冗余与信任（10–50 Hz）

```python
@dataclass
class ProprioceptiveRedundancyTrust:
    """PRT：跨通道一致性 + 物理不变量 + FDI。
    报警 → EFA-v6 直接走 SafeEnv；η_prop 仅作软评分"""
    lam_p: float = 2.0
    mu_energy: float = 1e-3

    def trust(self, z_t, base_est, vision_landmarks, hist) -> TrustCert:
        # 跨通道：IMU 积分 vs 腿部里程计 vs 视觉地标（三源交叉）
        cons = cross_channel_consistency(z_t, base_est, vision_landmarks)
        # 物理不变量：动量守恒（无外冲时）、接触一致性、能量不增
        inv = physics_invariants(z_t, hist, self.mu_energy)
        faults = fdi_test(cons, inv)                  # 故障集（可观测部分）
        eta = exp(-self.lam_p * max(0.0, risk(faults)))
        return TrustCert(eta_prop=eta, alarm=bool(faults), faults=faults)
```

### IP-500 EFA-v6：模型级合取 + 模型相对七门 + SafeEnv 兜底

```python
@dataclass
class EvidenceForgingAssemblerV6:
    psmvk: ProprioceptiveSelfModelValidityKernel
    wbbc: WholeBodyBalanceContactKernel
    prt: ProprioceptiveRedundancyTrust
    v5: EvidenceForgingAssemblerV5
    safe_env: ModelFreeSafeEnvelope

    def select(self, z_t, u_prev, t_now, context):
        cert_M = self.psmvk.update(z_t, u_prev, dt)
        tr = self.prt.trust(z_t, context.base_est, context.vision, context.hist)
        # 模型不可信：不回退 v5 门（门依赖 M_t），回退模型无关安全包络
        if (not cert_M.valid) or tr.alarm:
            return self.safe_env.select(z_t, context), 'SAFE_ENVELOPE'
        M = self.psmvk.model
        gamma = self.v5.famk.gamma(self.v5.famk.observe(context.face, t_now))
        c = build_ctx_v6(context, cert_M, M, self.v5.lmem)   # 条件含 M 摘要/valid
        cands = self.v5.fmpp.propose(c, self.v5.fmpp.K)
        surv = [x for x in cands if self._cheap_gates(x, M, gamma)]
        if not surv:
            return self.safe_env.select(z_t, context), 'SAFE_ENVELOPE'
        surv.sort(key=lambda x: self._prefilter_score(x), reverse=True)
        finals = []
        for x in surv[:3]:
            bal = self.wbbc.kc_bck_wb(x, M, context.base_est, context.C)
            if not bal.ok:
                continue                                  # 平衡/执行器可行性拒绝
            vac = self.v5.v4.vack.evaluate(x, ctx_M(M), t_now)
            if self.v5.v4.vack.kc_val(vac, tau=gamma['val'] * TAU_VAL4):
                finals.append((x, bal))
        if not finals:
            return self.safe_env.select(z_t, context), 'SAFE_ENVELOPE'
        best, bal = max(finals, key=lambda xb: certified_margin(xb[0], xb[1]))
        return True, best, 'FORGED_PCSM'

    def ecs_v6(self, ..., n_flow, s_emo, eta_prop) -> float:
        return self.v5.ecs_v5(..., n_flow, s_emo) * eta_prop
```

### 集成流水线（v5 → v6）

```
模型层（与本体同频）：
  PSMVK.update：残差检验 + 信任域辨识 ──▶ ModelCert(valid, ε, version)
  PRT.trust：跨通道一致性 + 物理不变量 + FDI ──▶ TrustCert(eta_prop, alarm)
       └─ valid=0 ∨ alarm ──▶ SafeEnv（模型无关兜底，旁路所有依赖 M_t 的门）

在线准入（异步，秒级）：
  valid(M_t)=1 ──▶ FMPP.propose(K=8) ──▶ 廉价门（模型相对）──▶ WBBC 平衡/执行器
       ──▶ VACK（调制 τ_val）──▶ 取边际最大者 ──▶ 缓存证书(绑定 M 版本)
       全灭/无可信模型 ──▶ SafeEnv

在线控制环（目标 < 0.7 ms）：
  每周期：EEK(kc_ee) + WBBC（事件触发：接触集合/支撑多边形不变 → 缓存证书内插）
  证书消费：证书带 M 版本号；PSMVK 版本变更 ⇒ 缓存立即失效 ⇒ SafeEnv
```

## 3. 复杂度分析（增量更新）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 | 实时性指标 |
|---|---|---|---|---|
| PSMVK.update | O(d_z² + W) 残差检验 | O(W + d_z²) | W=20, d_z~60 | < 0.05 ms，200–1000 Hz |
| PSMVK.identify | O(n_basis³) 约束最小二乘（低频） | O(n_basis²) | 每 0.5–2 s | 1–5 ms，异步 |
| PRT.trust | O(n_chan + n_inv) | O(1) | 3 通道 | < 0.1 ms，10–50 Hz |
| WBBC.kc_bck_wb | 触发时 O(n_dof³ + |C|·n_c³)，否则 O(1) 内插 | O(n_dof²) | n_dof~30, |C|≤6 | 触发 P99 ~0.62 ms |
| SafeEnv.select | O(n_dof) | O(1) | — | < 0.05 ms |
| EFA-v6 硬门 | O(1)（阈值预计算） | O(1) | — | < 0.03 ms |
| 端到端在线增量 | ~0.65 ms（控制环）+ 异步准入 | — | — | **较 v5 的 0.55 ms 增加 ~0.1 ms（平衡门细化）** |

**通信开销**：仅上传模型版本号、valid 标志、ε 摘要、η_prop 分位数（DP）；原始本体时序与身体参数留在站内。模型版本作为证书的一等公民参与联邦聚合签名。

**实时性权衡**：WBBC 比 v5 的 BCK 多了质心动力学与多接触扳手多面体，控制环 P99 从 0.55 ms 升至约 0.65 ms；通过「接触集合/支撑多边形不变即缓存内插」把全量 QP 触发率压到 ~10%。SafeEnv 旁路极轻，保证模型失效时仍满足 1 kHz 时限。

## 4. 正确性论证（增量更新）

### 引理 45（残差检验 → 参数误差半径）

**陈述**：设噪声有界且持续激励（PE）阶数 ≥ 参数维数，PSMVK 的窗口马氏残差检验在置信 1−δ 下给出参数误差半径 ε，使真参数 Θ* 以概率 ≥ 1−δ 落在 B_ε(Θ_t) 内。∎

**证明**：集合成员辨识 + 残差功率的单调上界；PE 保证回归矩阵满秩，置信半径由 χ² 分位数与噪声上界给出。

### 引理 46（平衡/执行器边际对模型参数的 Lipschitz 性）

**陈述**：在紧参数域上，多接触扳手可行边际 m_w、ZMP 边际 m_zmp、力矩边际 m_tau 对 Θ 均为 L_M-Lipschitz。∎

**证明**：margins 是质心动力学与逆动力学的连续（分段光滑）函数，紧域上有界梯度；接触多面体的 Hausdorff 连续性给出 m_w 的 Lipschitz 性。

### 引理 47（SafeEnv 的模型无关不变性）

**陈述**：SafeEnv 在准静态、限速、限矩、不新增接触的约束下，其能量与动量变化上界仅由测量与执行器物理限幅决定，不依赖 Θ_in/μ 的正确性。∎

**证明**：准静态使惯性项可忽略；限速限矩直接约束输入功率；不新增接触避免未建模冲量。

### 定理 9（模型相对可靠性 / 证书迁移）

**陈述**：若 valid(M_t)=1 且真参数 Θ*∈B_ε(Θ_t)，门在 M_t 上的边际为 s_i，则由引理 46，真身体上的边际 ≥ s_i − L_M·ε。故选择 τ_i^6 = τ_i^5 + L_M·ε 的安全缓冲即可保证迁移后的门仍然成立。∎

**工程含义**：证书不是二值的「真/假」，而是带 ε 的「有多真」；ε 直接进入阈值缓冲，模型越不确定越保守。

### 定理 10（模型失效 fail-closed 且不扩张）

**陈述**：(i) 若 valid(M_t)=0 或 PRT 报警，则 Exec_v6 = SafeEnv，且 SafeEnv 由引理 47 模型无关担保；(ii) 任何模型失效都不可能使可执行集大于模型无关包络，即不存在「坏模型 → 更大证书集」的路径；(iii) 当 valid≡1 且 M_t=M_0 时 Exec_v6 ⊆ Exec_v5（同门 + WBBC 只收紧 + 模型合取）。∎

**证明**：(i) EFA-v6 分支直接返回 SafeEnv；(ii) SafeEnv 是唯一不依赖 M_t 的可执行集，其余分支均以 valid=1 为前提；(iii) 合取项与门细化的单调收缩。

### 定理 11（本体故障下的自模型误接受界）

**陈述**：设 k 个冗余通道独立，FDI 对单通道故障的检出功效为 β，则接受被污染模型的概率 ≤ (1−β)^k + P_common，其中 P_common 为共模不可观测故障项。∎

**诚实边界**：P_common 在仅有本体感知时原理上不可界；只有引入外部锚（视觉地标、已知接触、人类确认）才能压低。**因此 PCSM 的安全性上界由「外部锚的可获得性」而非算法本身决定。**

### 定理 12（七锚完备性在模型相对化下保持）

**陈述**：v6 不增删锚点：七锚 {3DCF, MSRG, HICK, EEK, LTEM, VACK, BCK} 完备性（v4 定理 4）保持；PSMVK 是模型级合取项（非新轨迹锚），WBBC 是 kc_BCK 的内部细化，PRT 是软因子 + 兜底开关。证明：锚集合不变 + 细化只紧（定理 10(iii)）⇒ 覆盖链不变且只强不弱。∎

### 定理 v6（总装：模型相对收缩与信任迁移）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8)「valid(M_t)=1 时 Θ*∈B_ε(Θ_t) 以概率 ≥1−δ」下：
(i) Exec_v6 ⊆ Exec_v5 ⊆ … ⊆ Exec_v29；
(ii) 证书迁移：真身体边际 ≥ 模型边际 − L_M·ε（定理 9）；
(iii) 模型失效 fail-closed 且不扩张（定理 10）；
(iv) 本体故障误接受由定理 11 界，共模项不可界（诚实）；
(v) 七锚完备性保持（定理 12）。

**证明**：综合引理 45~47 与定理 9~12。∎

**诚实声明**：(B8) 依赖持续激励与噪声有界，实际接触切换/打滑会破坏 PE，使 ε 短时不可靠——此时必须降级 SafeEnv；(ii) 共模故障在无外部锚时不可检测，安全上界受外部参考限制；(iii) SafeEnv 牺牲性能换安全，长时间触发等价于任务失败，需人工介入；(iv) 质心动力学模型仍忽略柔性/间隙，Lipschitz 常数在极端冲击下可能失效。

## 7. 本轮最大风险（最终确认）

**一句话**：**本体感知共模故障/欺骗导致的自模型自洽失真**——校验身体模型与估计身体状态共用同一批本体传感器，一旦发生共模漂移或对抗性注入（编码器偏置、IMU 漂移、力矩传感器欺骗），valid(M_t) 会在「错模型 + 错观测」下互相印证为真，机器人带着虚假的模型证书进入高动量/多接触动作；冗余、物理不变量与 FDI 只能检测可观测的不一致，无法根除不可观测的共模故障，安全上界最终由外部锚（视觉/已知接触/人类）而非算法本身决定。

### 第 6 轮灵感驱动研究记录

**灵感词**：本体感知、人形机器人

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）在 v4 七硬门上做了「提议升级 + 阈值调制 + 软因子扩充」：条件流匹配提议 π_FM、LMEM-v2 记忆固化、FAMK 情感调制，并用定理 6（证书不变性）把框架推广为「任意生成器 + 认证边界」。v5 的执行集 Exec_v5 = {x ∈ supp(π_FM) : ∧ kc_i(x; γ·τ^4)=1}。但 v5 有一个从未被触碰的隐含前提：**七门全部定义在一个「名义身体模型」M_0 上**——连杆质量、运动学、摩擦、执行器极限、接触集合都被当作已知常量。本轮不推翻 v5，而是补三个结构性短板：(a) 人形机器人是浮动基、高自由度、欠驱动、多接触的整体，v5 的 BCK 仍是固定基/单臂语义；(b) 真实身体会漂移（负载、磨损、标定、温升、接触变化），对 M_0 铸出的证书可能只是「对幻肢的证书」；(c) 本体感知既能用来校验身体模型，本身又可能故障/被欺骗，形成新的信任循环。两个灵感词统一为主题「**本体感知认证的自模型**」（Proprioceptively-Certified Self-Model, PCSM），形成 CADVS-v6（IP-497~500）。本轮自律：**硬门数量仍不增**（维持七门）——本体感知不是第八道门，而是**门所依赖的身体模型之上的「模型级合取项」**，只在模型层收缩、且收缩到模型无关的安全包络；BCK 在内部细化为浮动基全身平衡 + 执行器可行性，仍是同一道门。

**直觉与动机**：

1. **本体感知 → 用「预测残差」给身体模型发证书，而不是再加一道轨迹门**。直觉：人闭眼也知道自己手臂在哪、使了多大劲；如果实际关节反馈长期和「按身体模型预测的反馈」对不上，人立刻知道「我的身体/模型出问题了」，会马上变保守。严谨化：设身体模型 M_t=(K,Θ_in,μ,A,C)，本体观测量 z_t=(q,q̇,τ_meas,IMU,接触力,电流,温度)，一步预测 ẑ_t=h(M_t,u_{t−1})，残差 r_t=z_t−ẑ_t。定义模型有效谓词 valid(M_t)=1[近 W 步残差马氏距离和 ≤ χ² 阈值 ∧ 辨识参数在信任域内]。于是引入**模型相对门** kc_i(x;M_t)，执行集改为 Exec_v6={x : valid(M_t) ∧ ∧_i kc_i(x;M_t)=1}。关键：valid 是**模型层合取项**，不是新的轨迹谓词；它只能让执行集变小，绝不新增可执行轨迹。

2. **人形机器人 → BCK 从固定基单臂细化为浮动基全身平衡 + 执行器可行性（仍在同一道门内）**。直觉：人形机器人不是「一条会动的胳膊」，而是「一个会摔倒的整体」；它同时用手、脚、甚至躯干接触，质心动力学、ZMP/CMP、多接触力分配、关节力矩/热限幅全都耦合在一起。严谨化：质心动力学 ḣ=[m g; p×m g]+Σ_c J_c^T w_c，多接触扳手 w_c 需落在摩擦锥交集内并合成期望质心扳手；ZMP/CMP 由质心加速度导出；执行器可行性 τ∈[τ_min, τ_max(T_temp)]。这些作为 kc_BCK 的**内部谓词扩展**（浮动基平衡证书 + 执行器可行性证书），门数不变。本体感知（IMU + 腿部运动学 + 接触）提供浮动基状态估计，是平衡证书的输入——于是「本体感知」既校验模型、又被平衡门消费，闭环但分层。

3. **本体感知的可信度 → 用冗余 + 物理不变量做故障隔离，失败则退到模型无关安全包络**。直觉：如果身体模型的校验和身体状态的估计共用同一批传感器，传感器一旦共模故障/被欺骗，模型证书会「自洽但失真」。严谨化：引入 PRT（本体感知冗余与信任）：跨通道一致性（IMU vs 腿部里程计 vs 视觉地标）、物理不变量（动量守恒、接触一致性、能量不增）、故障检测与隔离（FDI）。当 valid(M_t)=0 或 PRT 报警时，**不回退到 v5 的门**（因为门依赖的 M_t 已不可信），而是回退到**模型无关安全包络** SafeEnv（准静态、低动量、限速限矩、支撑接触/阻尼制动），由守恒律而非身体模型担保。这是与 v5 回退语义的关键区别：v5 回退换的是「提议」，v6 回退换的是「信任基础」。

**关键洞见**：v4 问「提议=规则时七门是否够」；v5 问「提议=任意生成器、记忆反哺、人因含情感时证书边界是否保持」；v6 问「**当门所依赖的身体模型本身可能错、且校验它的本体感知也可能错时，证书还剩下什么意义**」。答案是：证书必须**模型相对化**，并显式携带模型有效半径 ε；v6 不增加轨迹门，而是加一个模型级合取项 valid(M_t) 与一个模型无关兜底 SafeEnv，使「对幻肢的证书」在结构上无法被当成真证书使用。七硬门 kc_evidence_forged_v4 记号原样复用，BCK 内部细化，新增的只有：模型相对门 kc_i(·;M_t)、模型证书 valid(M_t)、本体信任软因子 η_prop、SafeEnv 兜底。执行集嵌套 Exec_v6 ⊆ Exec_v5 ⊆ … ⊆ Exec_v29（当 M_t=M_0、valid≡1 时精确退化 v5）。

**形式化目标（增量）**：
1. 身体模型 M_t=(K,Θ_in,μ,A,C)；本体残差 r_t=z_t−h(M_t,u_{t−1})；模型有效谓词 valid(M_t)=1[∧_{s=t−W+1}^t r_s^TΣ_r^{-1}r_s ≤ χ²_{d·W,1−δ} ∧ Θ_t∈T_trust]。
2. 模型相对门 kc_i(x;M_t)；执行集 Exec_v6={x : valid(M_t) ∧ ∧_i kc_i(x;M_t)=1}；SafeEnv 模型无关兜底。
3. WBBC：质心动力学 + ZMP/CMP + 多接触扳手多面体 + 执行器 τ/T 可行性，作为 kc_BCK 内部细化。
4. PRT：跨通道一致性 + 物理不变量 + FDI；η_prop∈[0,1]；报警即 fail-closed 到 SafeEnv。
5. 定理 9（模型相对可靠性/证书迁移）、定理 10（模型失效 fail-closed 不扩张）、定理 11（本体故障下的自模型误接受界）、定理 12（七锚完备性保持）。
6. ECS_v6 = ECS_v5 · η_prop；级联选择器与 v5 一致，仅在模型层前置 valid 检查。

**本轮最大风险**：**本体感知共模故障/欺骗导致的自模型自洽失真**——校验身体模型与估计身体状态共用同一批本体传感器，一旦发生共模漂移或对抗性注入（编码器偏置、IMU 漂移、力矩传感器欺骗），valid(M_t) 会在「错模型 + 错观测」下互相印证为真，机器人带着虚假的模型证书进入高动量/多接触动作；冗余、物理不变量与 FDI 只能检测可观测的不一致，无法根除不可观测的共模故障。

### IP-493 FMPP：流匹配提议策略核（准入/10 Hz 预览时域，不在 1 kHz 环）

```python
@dataclass
class FlowMatchingProposalPolicyKernel:
    """FMPP：条件流匹配提议器。
    定理 6（证书不变性）：提议可换，门不可换——门是信任边界"""
    net: Any                      # v_θ：DiT/Transformer，条件 cross-attn
    S: int = 10                   # 蒸馏后 ODE 步数
    K: int = 8                    # 候选数
    margin_head: Any = None       # BCK 边际蒸馏头（可行性先验，回应 v4-R49）

    def train_loss(self, batch) -> float:
        # rectified flow：x_t = (1-t)x0 + t·x1，目标场 = x1 - x0
        x0 = randn_like(batch.x1)
        t = rand(batch.B, 1)
        x_t = (1 - t) * x0 + t * batch.x1
        return mse(self.net(x_t, t, batch.c), batch.x1 - x0)

    def distill_margin_prior(self, bck_margin_samples) -> None:
        """离线：沿 BCK 采样的可行/不可行轨迹训练辅助边际头，
        让提议先验偏好高 ξ_wrench/ξ_zmp 区域，降低在线拒绝率"""
        ...

    def propose(self, c: Context, k: int = None) -> list[Trajectory]:
        """从 N(0,I) 积分 ODE 至 t=1，K 个候选；准入时域/10 Hz 预览"""
        xs = randn(k or self.K, d_x)
        for s in range(self.S):
            xs = xs + (1.0 / self.S) * self.net(xs, s / self.S, c)
        return decode(xs)

    def log_lik(self, x: Trajectory, n_probe: int = 4) -> float:
        """概率流 ODE + Hutchinson 迹估计 → log p(x)，供新颇度 n_flow（引理 43）"""
```

### IP-494 LMEM-v2：嵌入记忆与固化核（检索 O(log|M|)；固化离线）

```python
@dataclass
class LongTermMemoryEmbeddingConsolidation:
    """LMEM-v2：嵌入检索 + 流条件 + 铸证固化 + 密度新颖度。
    红线：固化只改提议器 θ_FM，永不改门（门代码与 τ^4 冻结只读）"""
    emb: Any                      # e_τ 编码器
    faiss_idx: Any
    tau_novel: float = 8.0        # 归一化 n_flow 阈值

    def query(self, obj, geo_sig, theta_fp, rule_id, x: Trajectory) -> QueryResult:
        m_topk = self._retr(self.emb(x), k=4)            # Top-k 记忆 token → 流条件
        n_flow = -self.fmpp.log_lik(x) / d_x             # 密度新颖度
        novel = (n_flow > self.tau_novel) or count_stat_reject(obj, geo_sig, theta_fp, rule_id)
        return QueryResult(pass_mem=not novel, eta_mem=..., novelty=novel,
                           m_topk=m_topk, n_flow=n_flow)
```

### IP-496 EFA-v5：七硬门 + 调制阈值 + 级联采样选证

```python
@dataclass
class EvidenceForgingAssemblerV5:
    """EFA-v5：七硬门不变（阈值可调制、只紧不松）+ 级联采样选证"""
    fmpp: FlowMatchingProposalPolicyKernel
    lmem: LongTermMemoryEmbeddingConsolidation
    famk: FacialAffectModulationKernel
    v4: EvidenceForgingAssemblerV4        # 复用 scf/msrg/hic/eek/vack/bck 全套

    def select(self, x0_state, t_now, rule_id, context) -> tuple[bool, Trajectory | None, str]:
        s_emo = self.famk.observe(context.face, t_now)
        gamma = self.famk.gamma(s_emo)                   # 全 1.0 = 精确退化 v4
        c = build_ctx(context, s_emo, self.lmem)         # 含 Top-k 记忆 token
        cands = self.fmpp.propose(c, self.fmpp.K)        # K=8，~5–20 ms，异步准入时域
        # 级联第 1 层：廉价门（coverage/physics/memory/novelty，O(1)~O(log|M|)）
        surv = [x for x in cands if self._cheap_gates(x, gamma)]
        if not surv:
            return self._fallback_rule_proposal(gamma)   # fail-closed：回退 v4 规则提议
        # 级联第 2 层：VACK 仅评估 ≤3 幸存者（~50 ms 级，异步；预筛省 ~60% 昂贵调用）
        surv.sort(key=lambda x: self._prefilter_score(x), reverse=True)
        finals = []
        for x in surv[:3]:
            vac = self.v4.vack.evaluate(x, context_with(s_emo), t_now)
            if self.v4.vack.kc_val(vac, tau=gamma['val'] * TAU_VAL4):
                finals.append(x)
        # 级联第 3 层：BCK 轨迹预览（事件触发 QP + 缓存证书内插）
        ok = [x for x in finals if self._bck_preview(x, gamma)]
        if not ok:
            return False, None, 'ALL_CANDIDATES_REJECTED'
        best = max(ok, key=certified_margin)             # 通过者中取边际最大者
        return True, best, 'FORGED_CGE'

    def ecs_v5(self, ..., n_flow: float, s_emo: SHomo | None) -> float:
        eta_flow = sigmoid(n_flow_to_ll(n_flow) - b_flow)
        eta_emo = (1.0 - self.famk.lam_emo * s_emo.p_distress
                   if s_emo is not None and s_emo.sigma <= self.famk.sigma_max else 1.0)
        return self.v4.ecs_v4(...) * eta_flow * eta_emo
```
