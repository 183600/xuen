# 第 66 轮（承接第 65 轮「VISTA 视觉知情安全时序归因闭环」IP-214~223；灵感循环第 3 轮；本轮灵感：「模型预测控制」×「机器人竞赛」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述的最大风险一针见血：归因依赖「故障属于有限假设集、且各模态失效相互独立」，真实复合/未知故障会被强行归入最近假设，系统因「已经归因」而更自信地继续执行。第 66 轮不再问「哪一层坏了」，而问一个只有赛场才会逼出的问题：**当比赛时钟在走、对手在动、分数就是目标时，能否让安全完全不依赖「归因是否正确」，而让不确定性只影响得分、不影响安全？** 核心命题：
>
> **把安全从「归因正确」改挂到「credal 覆盖」；把归因从「行动的前置条件」降级为「只影响得分的后验」；用非预期场景经济 MPC 在比赛时钟内做「可逆就试探、不可逆才求解、永远留后手」的滚动决策。**

## 0. 直觉与动机

**灵感 1（模型预测控制 → 安全不靠「猜对」，靠「对所有没排除的可能都安全」）**
直觉：MPC 的核心从来不是「预测得准」，而是「在约束下滚动地只承诺第一步」。它天然把不确定性当集合处理：tube MPC 用不确定集、scenario MPC 用未来树、economic MPC 用收益当目标。VISTA 的毛病是「先 argmax 归因、再定向膨胀」——把安全押在一个离散判断上。MPC 的改法是：维护一个 **credal 故障集**（还没被证据排除的所有模式，含「未知」），安全动作集定义为「对集合里每个模式都安全的动作之交」。归因只用来**收缩**这个集合；即使收缩错了，只要真实模式还在集合里，安全不受影响。安全因此从「归因正确率」问题变成「覆盖概率」问题，而覆盖可以用 conformal/credal 给出分布无关保证。

**灵感 2（模型预测控制 → 非预期性 = 「长预测、短执行」的严格版本）**
直觉：VISTA 的「长预测、短执行」只是工程启发。MPC 给了它严格名字：**非预期性（non-anticipativity）**。故障模式未知时，未来动作本就应依赖未来观测；因此把整条长轨迹一次承诺在信息论上就是错的，唯一可承诺的是「第一步/前 k* 步」。于是「长视界 H 只用于评估、执行前缀 k* 只到不可逆点」不是近似，而是**信息结构强制的**。再叠加 terminal invariant set 与 fallback，就得到递归可行性：只要终端集在可行核内，滚动优化永远有解、永远安全。

**灵感 3（机器人竞赛 → 停下来 = 输；不确定性必须「定价」）**
直觉：VISTA 在归因模糊时走 safe_idle / 最保守联合膨胀。单次任务里这叫稳健；比赛里这叫弃权。比赛是**有分数、有时钟、有对手、有规则**的环境：安全是硬约束（规则/物理），得分是软目标（economic MPC 的经济代价），时间是稀缺资源（anytime）。所以「该不该探测 / 该不该停」不该由固定阈值 δ_fi 决定，而该由**信息在剩余时钟内能换回多少分**决定——这就是 clock-aware value of information（VOI-C）。落后时要敢冒险、领先时要护分，但硬规则永不放松——rank-aware risk scheduling（RRS）。

**灵感 4（机器人竞赛 → 对手就是「最坏情况」，共因故障不必归因）**
直觉：VISTA 最怕视觉与几何共因失效。竞赛提供了新视角：共因失效往往不是随机巧合，而是**对手的选择**（遮挡、反光、对抗 patch、推挤、时序欺骗）。把对手建模为有自己目标的博弈者，安全就变成**零和动态博弈的可行核**：不要求知道「是视觉坏了还是几何坏了」，只要求「对对手的任一合法/非法策略都留在可行核内」。这直接绕开 VISTA 的归因假设——**归因可以错，安全不能错**。

**灵感 5（合流 → ARENA：Adversarial Robust Economic Non-anticipative Adaptation，竞技场式对抗鲁棒经济非预期自适应）**
ARENA 把 VISTA 的「归因-膨胀-承诺」换成「**信念-场景-滚动**」：credal 故障信念（CFB）→ 分数增广的比赛 MDP → 非预期场景经济 MPC（NSE-MPC）→ 安全单调盾（SMS）→ 时钟感知信息价值（VOI-C）→ 名次感知风险调度（RRS）→ 对抗比赛博弈（AMG）→ anytime 备份监督（ABS）→ 局间学习（EBL）→ 对抗竞赛认证（AIC-A）→ J_arena。一句话：**归因决定你打得多好，credal 集合决定你有多安全。**

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（ARENA 闭环）**：ARENA = (VISTA, CFB, NSE-MPC, SMS, VOI-C, RRS, AMG, ABS, EBL, AIC-A, J_arena)。定位：VISTA 的「安全来源」重构——从「归因后定向膨胀」改为「credal 集上最坏情况 + 比赛时钟内滚动」。不变式：**硬安全包络、credal 集更新、盾过滤、前缀派发在实时流；场景 MPC、对手博弈、VOI-C、认证与局间学习在语义流；比赛进行中零参数写入。**
- **定义 234（分数增广比赛 MDP）**：M=(𝒳,𝒜,𝒲,f,r,𝒳_rule,𝒜_rule,T_match,Δt)。状态含机器人、物体、任务变量、剩余时钟 τ、当前得分 S。经济奖励 r_t=ΔS_t−λ_rule·penalty_t；规则约束 x_t∈𝒳_rule、a_t∈𝒜_rule 为**硬约束**，得分只进目标。事故/失分与「安全」分离：安全是可行性，分数是优化。
- **定义 235（credal 故障信念 CFB）**：以 ε-污染 credal 集表示故障不确定性：ℬ_t=(1−ε_t)·b_t+ε_t·U，其中 b_t 是 ℳ∪{∅ 未知} 上的后验。surprise 通道：若残差 e_t>q(α_vis)（第 65 轮 conformal 界），令 ε_t←(1−β_s)ε_t+β_s、b_t(∅) 上调，**主动把未知质量加回来**。更新 b_{t+1}(m)∝p(y_{t+1}|m,b_t)b_t(m)。VISTA 的 FIR 只保留为「给 b_t 排序的似然器」，不再直接决定球。
- **定义 236（credal 覆盖）**：称 ℬ_t 具 δ_cred 覆盖，若对整场比赛 P[∀t≤T_match: m*_t∈supp(ℬ_t)]≥1−δ_cred。用在线 split-conformal / 块状可交换校准估计 ε_t，并在漂移检测（残差分位漂移、对手策略突变）时上调 ε_t。**这是 ARENA 唯一的统计假设。**
- **定义 237（非预期策略类）**：Π_N={π=(π_0,…,π_{N−1}): π_s 关于 (y_{0:s},a_{0:s−1}) 可测}。π_0 对所有场景相同，后续动作随观测分支——这就是场景树；它把「长预测、短执行」变成非预期性的直接推论。
- **定义 238（非预期场景经济 MPC，NSE-MPC）**：在 ℬ_t 上求解
  max_{π∈Π_N} min_{m∈ℬ_t} min_{w∈𝒲} Σ_{s=0}^{N−1} γ^s r(x_s,a_s) + V_f(x_N)
  s.t. x_{s+1}=f(x_s,a_s,w_s;m)，x_s∈𝒳_rule，a_s∈𝒜_rule，x_N∈𝒳_f(ℬ_t)。
  只执行首动作 a_0（或不可逆视界内的 move-blocking 前缀 k*≤m_irr），随后以新观测重解——滚动时域。N 尽量长（方差/前瞻），承诺尽量短（安全/信息）。
- **定义 239（credal 安全集与安全单调性）**：Safe(ℬ)=∩_{m∈ℬ} Safe_m，Safe_m={a: Q_m^safe(x,a)≥0}。**引理 9**：ℬ₁⊆ℬ₂ ⇒ Safe(ℬ₂)⊆Safe(ℬ₁)。另设**模型无关硬包络** 𝒮₀（关节/力/工作空间/规则），不依赖任何 m，作为最终兜底。
- **定义 240（不可逆度与承诺门）**：ι(x,a)=1−max_π P^π[在 m_irr 步内回到可恢复集 R | x,a]。ι≤ι_max 的动作走**场景 recourse**（可逆、可用期望得分）；ι>ι_max 的动作必须在**全 credal 集最坏情况**下安全且落在 𝒮₀ 内才允许执行。是否「现在」做不可逆动作，交由 VOI-C 与 RRS 定价，**不交由 argmax 归因**。
- **定义 241（终端可行集与递归可行性）**：𝒳_f(ℬ)⊆K(ℬ) 为对 ∀m∈ℬ、∀w∈𝒲 的鲁棒控制不变集；K(ℬ) 为规则约束下博弈的可行核。若终端集与约束收紧匹配，NSE-MPC 递归可行；ℬ 扩张时由 ABS 切换到 𝒮₀ 内备份策略，安全性不依赖扩张后的 ℬ。
- **定义 242（名次感知风险调度 RRS）**：风险预算 α_t=clip(α_0+κ_g·(S_ref−S_t)/S_scale+κ_τ·τ/τ_0, α_min, α_max)。落后（S_t<S_ref）→ α_t↑，敢冒险追分；领先 → α_t↓，护分。α_t 只作用于**软目标/软约束**；𝒳_rule、𝒜_rule、𝒮₀ 永不随 α 放松。
- **定义 243（时钟感知信息价值 VOI-C）**：对可行动作 a，
  VOI-C(a)=E_{z∼O(·|a,m)}[V_rob(x′,ℬ′)]−V_rob(x,ℬ)−c_score(a)−λ_τ/τ−c_risk(a)，
  仅当 VOI-C(a)>0 且 a∈Safe(ℬ) 时执行探测；否则用当前鲁棒计划。它把第 65 轮 AFA 的「降假设熵」升级为「**在剩余时钟内能换回多少分**」——熵减只是 VOI-C 在「分数对信息线性、时钟无限」时的特例。
- **定义 244（对抗比赛博弈 AMG）**：对手策略 q 定义零和/Stackelberg 博弈，扰动模糊集 𝒲(ε_W) 为对手策略的 Wasserstein 球；robust value 取 min_{q∈𝒲(ε_W)}。共因故障（对手同时骗视觉/力/几何）由 ℰ_common 显式进入**认证**，但**不要求归因**：只要最坏情况下安全即可。对手模型局间更新，局内冻结。
- **定义 245（anytime 备份监督 ABS）**：始终保留 (i) 最近一个可行规划作为 incumbent，(ii) 𝒮₀ 内的备份策略 π_b。若 MPC 在控制截止前返回且改进 incumbent，用之；超时用 incumbent；incumbent 失效则 π_b。保证「优化失败 ≠ 系统失安」，把计算不确定性与安全性解耦。
- **定义 246（局间情景学习 EBL）**：仅在比赛间隙（reset 后）更新故障库 ℳ、先验、终端集、对手模型与 conformal 校准；局内只做信念更新与滚动优化，**零参数写入**。这既符合第 65 轮语义/实时流分离，也避免局内学习造成的审计不可复现。
- **定义 247（AIC-A 对抗竞赛认证）**：干扰集 ℰ_A=ℰ_V×ℰ_opponent×ℰ_clock×ℰ_rank。ℰ_opponent 含遮挡/推挤/对抗 patch/传感器欺骗/共因；ℰ_clock 含抖动、截止压缩、延迟；ℰ_rank 含计分噪声与名次操纵。ρ_dir 在 ℰ_A 上重算（n_cert 128→160），证书增 credal_coverage_ver、viability_ver、scenario_hash、voi_audit、deadline_met、opponent_model_ver、match_score_cert。
- **定义 248（ARENA 证书与算子 J_arena）**：J_arena=(J_vista, credal_belief_hash, credal_coverage_ver, viability_ver, scenario_hash, voi_audit, deadline_met, opponent_model_ver, match_score_cert, aic_a_ver)。Valid(J_arena) ⇔ Valid(J_vista) ∧ 覆盖在有效期 ∧ 首动作∈Safe(ℬ)∩𝒮₀ ∧ 不可逆动作满足最坏情况门 ∧ 截止前返回或已切 ABS ∧ 局内无参数写入。语义流：[CFB→NSE-MPC→VOI-C/RRS→AMG→SMS→ABS→派发 a_0/k*→E_exec→EBL 记账→AIC-A]；实时流：[读 credal 集→盾过滤→硬包络→前缀派发→早停→J_arena 组装]。

## 2. 关键算法骨架

```python
# CFB：点归因 → credal 集（含 unknown 与 surprise）
b = cfb.update(y, residuals)                 # 语义流：似然只用于排序
eps = cfb.surprise(residuals, q_vis)         # e > q_vis ⇒ 上调未知质量
B = cfb.credal_set(b, eps, delta=cov_delta)  # {m: b[m] >= delta} ∪ unknown

# NSE-MPC：非预期场景 + 最坏 credal + 经济得分；只承诺首动作
plan, a0, k_star = nse_mpc.solve(x, B, clock=tau, N=N_long)
plan = abs.ensure_incumbent(plan)            # anytime：无解也有得用

# SMS：安全单调盾；归因错也挡得住
if not sms.safe(a0, B):                      # a0 ∉ ∩_{m∈B} Safe_m
    a0 = abs.backup(x)                       # 模型无关硬包络内兜底

# VOI-C：探测只在「信息能换分」时发生
if voi_c.best(plan, B, tau) > 0 and not irrev(a0):
    a0 = voi_c.probe(B, plan)                # 可逆探针，保持选项
rrs.set_budget(score_gap, tau)               # 落后敢冒险，领先护分；规则不松
dispatch_prefix(plan, k_star=min(k_star, m_irr))
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（归因免疫 / 安全单调性）**：Safe(ℬ) 对 ℬ 单调反变；若 m*∈ℬ_t 对整场成立，则任何 a∈Safe(ℬ_t) 对真实故障安全。故安全界**只含 δ_cred+δ_surprise+ε_shield+ε₀，不含误归因概率**。VISTA 的 `Safe({m̂})` 可能比 `Safe(ℬ)` 大，m̂≠m* 时会选到不安全动作；ARENA 从不把点估计用于安全。
- **引理 10（带盾递归可行性）**：终端集鲁棒控制不变 + 约束收紧匹配 + ABS 备份落在 𝒮₀ ⇒ 每个控制步要么 NSE-MPC 给出 Safe 首动作，要么切备份；状态永不走出 𝒳_rule∩𝒮₀。ℬ 扩张不破坏该结论，因为兜底不依赖 ℬ。
- **定理 9（ARENA 端到端安全）**：在 A94–A99 下，对任意复合/未知故障与任意对手策略，Valid(J_arena) ⇒ 以概率 ≥1−(δ_cred+δ_surprise+ε_shield+ε₀) 永不离开规则可行集，**且与 argmax 归因是否正确无关**。这把 VISTA 的「归因单点故障」从安全证明中彻底移除。
- **定理 10（时钟感知竞争力 / 后悔界）**：将探测选择视为以故障模式为隐变量、以得分为奖励的信息导向 bandit。若信息比有界为 ρ，剩余时钟 T，则 VOI-C 的名次后悔 R(T)≤O(√(ρ|ℳ|T log|ℳ|))+T·κ_cons；且存在阈值 T*，当 T<T* 时不探测严格占优——VOI-C 通过 c_time=λ_τ/τ 自动恢复该阈值。RRS 在单调名次模型下最大化晋级概率。
- **命题（为什么竞赛改变最优策略）**：VISTA 的 safe_idle 得分率为 0；若存在可逆探针 a∈Safe(ℬ) 且 E[score|a]>0、不可逆风险为 0，则等待被严格占优。这形式化了「停下来 = 输」。
- **命题（对 VISTA 的弱支配）**：复合故障下，若 VISTA 的点估计落在 credal 集外，则 `Safe_VISTA ⊄ Safe(ℬ)`；固定 δ_cred 时 ARENA 的违规界不含归因错误项，安全上弱支配 VISTA；当 VISTA 触发 safe_idle 而存在正分机会时，ARENA 得分更高。
- **实时性**：硬包络、盾过滤、CFB 更新、前缀派发在实时流（目标 <0.5ms 增量）；NSE-MPC/AMG/VOI-C/AIC-A 在语义流（10–30Hz）；MPC 超时由 ABS 的 incumbent/备份接管，实时契约仍 ≤2.5ms（A99）。

## 5. 本轮最大风险

**一句话**：ARENA 把安全的根基从「归因正确」换成了「真实故障始终落在 credal 集内」，而机器人竞赛恰恰是对抗、非可交换、规则可被利用的环境——对手可以用一个从未进过故障库、且同时欺骗视觉/力/几何的 OOD 手段，让 credal 集漏掉真实模式；此时最坏情况优化是在**错误集合**上做的乐观规划，系统会同时拿到「安全证书有效」和「真实世界失稳/失分」，即 VISTA 的归因单点故障被升级为**覆盖假设单点故障**。

# 第 66 轮产物 · 创新点清单 v3：ARENA（Adversarial Robust Economic Non-anticipative Adaptation：模型预测控制 × 机器人竞赛下的「credal 安全 + 经济得分 + 非预期滚动」；CFB×NSE-MPC×SMS×VOI-C×RRS×AMG×ABS×EBL×AIC-A×J_arena）

## 2. 形式化定义（完整版）

**定义 233（ARENA 闭环）** ARENA 是 VISTA 的「安全来源重构」：把「先归因、再定向膨胀、再认证前缀」替换为「维护 credal 故障集 → 非预期场景经济 MPC → 安全单调盾 → 时钟感知探测 → 名次感知风险调度 → 对抗博弈 → anytime 备份」。不变式：**硬安全包络、credal 集更新、盾过滤与短前缀派发在实时流；场景 MPC、对手博弈、VOI-C、认证与局间学习在语义流；比赛进行中零参数写入。** 与 VISTA 的关系不是替代，而是**把 VISTA 的 FIR 从「安全判定器」降级为「信念排序器」**。

**定义 234（分数增广比赛 MDP）** M=(𝒳,𝒜,𝒲,f,r,𝒳_rule,𝒜_rule,T_match,Δt)。x_t 含机器人状态、物体状态、任务进度、剩余时钟 τ_t、当前得分 S_t。经济奖励
r_t = ΔS_t − λ_rule·penalty_t，
其中 ΔS_t 为任务得分增量（进球、完成子任务、名次分），penalty_t 为规则/碰撞扣分。硬约束 x_t∈𝒳_rule、a_t∈𝒜_rule（力限、场地边界、时间、不得违规接触）。**安全 = 硬约束可行性；竞争力 = 经济目标；二者不混在一个标量里。**

**定义 235（credal 故障信念 CFB）** 以 ε-污染 credal 集表示故障不确定性：
ℬ_t = (1−ε_t)·b_t + ε_t·U，
b_t 定义在 ℳ∪{∅} 上。更新
b_{t+1}(m) ∝ p(y_{t+1} | m, b_t)·b_t(m)。
surprise 通道：若第 65 轮 conformal 残差 e_t > q_vis(α_vis)，则
ε_t ← (1−β_s)ε_t + β_s，b_t(∅) ← b_t(∅) + β_s，
即**主动把未知质量加回来**，防止「未知故障被强行归入最近模式」。FIR 的似然 p(ρ|H) 仍用于给 b_t 排序，但**不再触发任何定向球膨胀作为安全依据**；定向膨胀只作为「得分/效率」启发式（可选）。

**定义 236（credal 覆盖）** 称 ℬ_t 具 δ_cred 覆盖，若对整场比赛
P[∀t≤T_match: m*_t ∈ supp(ℬ_t)] ≥ 1−δ_cred。
ε_t 由在线 split-conformal / 块状可交换校准给出；漂移检测（残差分位漂移、对手策略突变、遮挡率突变）触发 ε_t 上调。**这是 ARENA 唯一的统计假设**，也是本轮最大风险的所在（见第 7 节）。

**定义 237（非预期策略类）** Π_N={π=(π_0,…,π_{N−1}) : π_s 关于 (y_{0:s},a_{0:s−1}) 可测}。π_0 对所有场景相同，π_{s>0} 随观测分支。场景树 T_N 的每个根到叶路径是一次「故障 + 扰动」实现；非预期性即「同信息集的动作相同」。

**定义 238（非预期场景经济 MPC，NSE-MPC）** 在 ℬ_t 与当前状态 x_t 上求解
max_{π∈Π_N} min_{m∈ℬ_t} min_{w∈𝒲} Σ_{s=0}^{N−1} γ^s r(x_s,a_s) + V_f(x_N)
s.t. x_{s+1}=f(x_s,a_s,w_s;m)，
      x_s∈𝒳_rule，a_s∈𝒜_rule，
      x_N∈𝒳_f(ℬ_t)。
执行 a_0（必要时 move-blocking 到 k*≤m_irr），然后以新观测重解。N 尽量长（方差缩减、前瞻一致性），承诺尽量短（信息结构 + 安全）。**这是「长预测、短执行」的严格版本：短执行不是近似，而是非预期性的必然。**

**定义 239（credal 安全集与安全单调性）** 
Safe(ℬ) = ∩_{m∈ℬ} Safe_m，Safe_m={a : Q_m^safe(x,a) ≥ 0}。
**引理 9**：ℬ₁⊆ℬ₂ ⇒ Safe(ℬ₂)⊆Safe(ℬ₁)。证明：交集随集合增大而变小。另设模型无关硬包络 𝒮₀（关节限、力限、工作空间、规则），不依赖任何 m，作为最终兜底。安全动作集 = Safe(ℬ)∩𝒮₀。

**定义 240（不可逆度与承诺门）** 
ι(x,a)=1−max_π P^π[在 m_irr 步内回到可恢复集 R | x,a]。
- ι≤ι_max（可逆）：允许场景 recourse，可用期望得分，可用探针；
- ι>ι_max（不可逆）：动作必须对**全 credal 集最坏情况**安全且 ∈𝒮₀，才允许执行。
「现在是否做不可逆动作」由 VOI-C 与 RRS 定价，**不由 argmax 归因判定**。这样即使归因完全错误，不可逆动作也不会因为「误以为自己是健康的」而被放行。

**定义 241（终端可行集与递归可行性）** 𝒳_f(ℬ)⊆K(ℬ)，K(ℬ) 为规则约束下对抗博弈的可行核（viability kernel）：从 K(ℬ) 内出发存在策略使 ∀m∈ℬ、∀w∈𝒲 永远留在 𝒳_rule。若终端集鲁棒控制不变且约束收紧与场景树深度匹配，则 NSE-MPC 递归可行。ℬ 扩张可能使 𝒳_f(ℬ) 变空；此时 ABS 切到 𝒮₀ 内备份策略 π_b，**安全性不依赖扩张后的 ℬ**。

**定义 242（名次感知风险调度 RRS）** 
α_t = clip( α_0 + κ_g·(S_ref−S_t)/S_scale + κ_τ·τ_t/τ_0, α_min, α_max )。
落后（S_t<S_ref）→ α_t↑，允许更高风险的软目标（更激进的追分动作）；领先 → α_t↓，护分。α_t 只作用于**软目标/软约束/机会约束**；𝒳_rule、𝒜_rule、𝒮₀ **永不随 α 放松**。在单调名次模型（分数越高晋级概率越大）下，RRS 最大化晋级概率而非单场期望分。

**定义 243（时钟感知信息价值 VOI-C）** 对可行动作 a，
VOI-C(a) = E_{z∼O(·|a,m)}[ V_rob(x′,ℬ′) ] − V_rob(x,ℬ) − c_score(a) − λ_τ/τ − c_risk(a)，
其中 V_rob 为当前 credal 集下的鲁棒值，c_score 为执行探针让出的得分机会，λ_τ/τ 为时钟成本，c_risk 为不可逆风险。选择
a* = argmax_{a∈Safe(ℬ)∩𝒜_probe} VOI-C(a)，
仅当 VOI-C(a*)>0 时探测，否则执行当前鲁棒计划。**它把第 65 轮 AFA 的「降低故障假设熵」升级为「在剩余时钟内能换回多少分」**；熵减只是分数对信息线性、时钟无限时的特例。VOI-C<0 即「不值得探测」，无需手调 δ_fi。

**定义 244（对抗比赛博弈 AMG）** 对手策略 q 定义零和/Stackelberg 博弈，扰动模糊集
𝒲(ε_W) = { q : W_1(q, q̂) ≤ ε_W }，
robust value 取 min_{q∈𝒲(ε_W)}。对手可选择遮挡、推挤、对抗 patch、传感器欺骗、时序错位；共因故障（同一手段同时骗视觉/力/几何）由 ℰ_common 显式进入**认证**，但**不要求归因**：只要最坏情况下留在 K(ℬ) 内即可。对手模型局间由 EBL 更新，局内冻结。

**定义 245（anytime 备份监督 ABS）** 始终保留 (i) 最近可行规划 incumbent，(ii) 𝒮₀ 内模型无关备份 π_b。规则：MPC 截止前返回且严格改进 → 用新解；超时 → 用 incumbent；incumbent 失效（例如观测突变使其首动作不再安全）→ π_b。由此
P[安全失效 | 计算超时] = 0（在 𝒮₀ 有效的前提下），把**计算不确定性**与**安全性**解耦。

**定义 246（局间情景学习 EBL）** 仅在 reset 后更新故障库 ℳ、先验 b_0、终端集 𝒳_f、对手模型 q̂、conformal 校准与 ε_t 基线；局内只做信念更新与滚动优化，**零参数写入**。这与第 65 轮「语义流写、实时流不写」一致，并进一步要求「局内语义流也不写」，保证比赛可复现、可审计。

**定义 247（AIC-A 对抗竞赛认证）** 干扰集
ℰ_A = ℰ_V × ℰ_opponent × ℰ_clock × ℰ_rank。
ℰ_opponent 含遮挡、推挤、对抗 patch、传感器欺骗、共因；ℰ_clock 含控制抖动、截止压缩、通信延迟；ℰ_rank 含计分噪声与名次操纵。ρ_dir 在 ℰ_A 上重算（n_cert 128→160，其中 32 用于对手/时钟/名次），ρ_force 在最坏偏置与最坏遮挡下取最坏。J_dir 增 credal_coverage_ver、viability_ver、scenario_hash、voi_audit、deadline_met、opponent_model_ver。

**定义 248（ARENA 证书 J_arena 与算子）** 
J_arena=(J_vista, credal_belief_hash, credal_coverage_ver, viability_ver, scenario_hash, voi_audit, deadline_met, opponent_model_ver, match_score_cert, aic_a_ver)。
Valid(J_arena) ⇔ Valid(J_vista)
∧ 覆盖在有效期（δ_cred 未超预算）
∧ 首动作 ∈ Safe(ℬ)∩𝒮₀
∧ 不可逆动作满足全 credal 最坏情况门
∧ 截止前返回或已切 ABS
∧ 局内无参数写入。
算子：语义流 [CFB→NSE-MPC→VOI-C/RRS→AMG→SMS→ABS→派发 a_0/k*→E_exec→EBL 记账→AIC-A]；实时流 [读 credal 集→盾过滤→硬包络→前缀派发→早停→J_arena 组装]。

### IP-224 CFB（credal 故障信念）

```python
class CredalFaultBelief:
    """点后验只用于排序；安全读 credal 集，不读 argmax。"""
    def __init__(self, modes, eps0=0.05, beta_s=0.2, delta=0.05):
        self.modes = list(modes) + [None]          # None = 未知
        self.eps0, self.beta_s, self.delta = eps0, beta_s, delta
        self.eps = eps0
        self.b = {m: 1.0 / len(self.modes) for m in self.modes}

    def update(self, y, lik):
        z = {m: lik[m](y) * self.b[m] for m in self.modes}
        tot = sum(z.values()) + 1e-12
        self.b = {m: v / tot for m, v in z.items()}
        return self.b

    def surprise(self, residual, q_vis):
        if residual > q_vis:                       # 分布外，主动加回未知质量
            self.eps = (1 - self.beta_s) * self.eps + self.beta_s
            self.b[None] += self.beta_s
            self._renorm()
        return self.eps

    def credal_set(self):
        # supp + 未知；delta 是 credal 阈值，不是归因阈值
        B = {m for m, p in self.b.items() if p >= self.delta}
        if self.eps > 0:
            B.add(None)
        return B
```

### IP-225 NSE-MPC（非预期场景经济 MPC）

```python
class NSEMPC:
    def solve(self, x, B, tau, N=N_long, n_scen=64):
        # 1) 场景采样：故障模式 × 对手扰动（覆盖 credal 集，不只取 argmax）
        scen = sample_credal_scenarios(B, n_scen, opponent_belief=self.q_hat)
        # 2) 非预期场景树：根动作共享，深层动作可观测定制
        tree = build_nonanticipative_tree(scen, depth=N)
        # 3) 经济目标 + 硬规则；终端集鲁棒不变
        prob = ScenarioMPC(tree, cost=economic_reward, hard=rule_constraints)
        prob.add_terminal_set(self.Xf[B_hash(B)], robust=True)
        plan, val = prob.solve_anytime(deadline=tau - reserve_ms)
        if plan is None:
            return self.incumbent, None, 0
        a0 = plan.first_action()
        k_star = min(self.move_block(plan), self.m_irr)   # 长预测、短执行
        return plan, a0, k_star
```

### IP-226 SMS（安全单调盾）

```python
class SafetyMonotoneShield:
    def safe(self, a, B, x):
        # 关键：对所有未排除模式取最坏，而不是对 argmax
        for m in B:
            if m is None:
                if not self.envelope_ok(a, x):        # 未知模式交给硬包络
                    return False
            elif not self.q_safe(m, x, a) >= 0:
                return False
        return True

    def filter(self, a, B, x, backup):
        if self.safe(a, B, x):
            return a, 'mpc'
        return backup(x), 'backup'                     # 归因错也挡得住
```

### IP-227 VOI-C（时钟感知信息价值）

```python
class ClockAwareVOI:
    def choose(self, plan, B, tau, score_gap):
        best, best_v = None, 0.0
        for a in probe_set(plan, B):
            if not shield.safe(a, B, plan.x):
                continue
            gain = expected_robust_value(plan, a, B) - plan.value
            cost = (forgone_score(a) + self.lam_tau / max(tau, 1e-3)
                    + irreversibility_risk(a, plan.x))
            v = gain - cost
            if v > best_v:
                best, best_v = a, v
        return best, best_v          # None ⇒ 不探测，直接执行鲁棒计划
```

### IP-229/230 AMG + ABS（对抗博弈与 anytime 兜底）

```python
class AnytimeBackupSupervisor:
    def ensure_incumbent(self, plan):
        if plan is not None and plan.feasible:
            self.incumbent = plan
        return self.incumbent

    def dispatch(self, plan, a0, x, B, deadline):
        if time_left() < deadline:                     # 超时
            return self.incumbent.first_action() if self.incumbent else self.pi_b(x)
        a, src = shield.filter(a0, B, x, self.pi_b)
        return a
```

### IP-233 ARENA 闭环算子

```python
def ARENA_round(M, obs, tau, score):
    x, y, residual = obs
    # ———— 语义流 ————
    M.cfb.update(y, M.lik)
    eps = M.cfb.surprise(residual, M.q_vis)
    B = M.cfb.credal_set()
    if M.ebl.drift_detected(residual, y):
        M.cfb.eps = min(1.0, M.cfb.eps + M.beta_s)     # 漂移 ⇒ 加回未知

    plan, a0, k_star = M.nse_mpc.solve(x, B, tau)
    M.abs.ensure_incumbent(plan)
    M.rrs.set_budget(score.gap, tau)
    a_probe, v = M.voi_c.choose(plan, B, tau, score.gap)
    if a_probe is not None and v > 0:
        a0 = a_probe                                   # 可逆探针，保持选项
    if M.irrev(a0, x):
        assert M.sms.safe(a0, B, x) and M.sms.envelope_ok(a0, x)

    # ———— 实时流 ————
    a_exec = M.abs.dispatch(plan, a0, x, B, M.deadline)
    dispatch_prefix(plan, a_exec, k_star)
    J = build_j_arena(M.j_vista, M.cfb, B, M.nse_mpc, M.voi_c,
                      deadline_met=M.abs.met, M.aic_a)
    return J
```

## 4. 推导

**引理 9（归因免疫 / 安全单调性）** 由 Safe(ℬ)=∩_{m∈ℬ}Safe_m 直接得：若 ℬ₁⊆ℬ₂，则 Safe(ℬ₂)=∩_{m∈ℬ₂}Safe_m ⊆ ∩_{m∈ℬ₁}Safe_m=Safe(ℬ₁)。设真实模式 m* 满足 m*∈ℬ_t（覆盖），则任意 a∈Safe(ℬ_t) 有 a∈Safe_{m*}，即对真实故障安全。对 t 取联合界，安全失效概率 ≤ P[∃t: m*∉ℬ_t] + P[surprise 失效] + P[盾/包络失效] = δ_cred+δ_surprise+ε_shield+ε₀。**该式不含 argmax 归因错误项。** 反观 VISTA：其定向处置用 Safe({m̂})。由于 {m̂}⊆ℬ_t，有 Safe({m̂})⊇Safe(ℬ_t)，即 VISTA 的安全集**更大**；当 m̂≠m* 时可能选到 a∉Safe_{m*}。这正是「归因错误的复合故障」的形式化。∎

**引理 10（带盾递归可行性）** 归纳。t=0：𝒮₀ 非空且 π_b 存在。设 x_t∈𝒳_rule∩𝒮₀。若 NSE-MPC 在截止前返回可行 plan，terminal set 鲁棒控制不变 + 约束收紧匹配保证 x_{t+1} 仍在可行域，且首动作经 SMS 过滤后 ∈Safe(ℬ_t)∩𝒮₀；若超时或不可行，ABS 用 incumbent 或 π_b，二者均在 𝒮₀ 内。故 x_{t+1}∈𝒳_rule∩𝒮₀。ℬ 扩张不破坏结论：π_b 不依赖 ℬ，SMS 对未知模式走 envelope_ok。∎

**引理 11（VOI-C 与熵准则的关系）** 令得分对信息的价值为线性 β，时钟无限（λ_τ=0），且探针不消耗得分（c_score=0），则 VOI-C(a)=β·I(ℳ;z|a)−c_risk(a)。当 c_risk=0 时 argmax VOI-C = argmax 互信息，即第 65 轮 AFA。故 AFA 是 VOI-C 的极限特例；当 τ 有限或 c_score>0 时，熵最大的探针未必是最优探针——**AFA 会过度探测**。∎

**定理 9（ARENA 端到端安全）** 在 A94–A99 下：对任意复合/未知故障序列与任意对手策略，若 Valid(J_arena)，则
P[∃t: x_t∉𝒳_rule 或 a_t∉𝒜_rule] ≤ δ_cred + δ_surprise + ε_shield + ε₀，
**且该界与 argmax 归因是否正确无关**。证明：引理 9 把安全化为覆盖事件；引理 10 保证每步落回 𝒮₀；ABS 保证计算失败不破坏该链；AIC-A 保证认证在最坏对手/时钟下重算。∎
与 VISTA 定理 7 对比：VISTA 的界含 δ_fi（归因确定阈值），依赖「归因正确」；ARENA 用 δ_cred 替换 δ_fi，把**离散决定的正确性**换成**集合覆盖的统计性**。

**定理 10（时钟感知竞争力 / 后悔界）** 把探测选择视为以故障模式为隐变量、以得分为奖励的信息导向 bandit。设信息比（每单位后悔获得的信息）有界为 ρ，剩余时钟 T，|ℳ|=M。由信息导向采样的标准界，
R(T) ≤ O(√(ρ M T log M)) + T·κ_cons，
其中 κ_cons 为 credal 安全集相对点估计安全集的每步保守性损失。VOI-C 的 c_time=λ_τ/τ 使探测只在 T 足够大时发生；存在阈值 T*，T<T* 时「不探测、执行鲁棒计划」严格占优，VOI-C 自动恢复该阈值。∎

**命题（为什么竞赛改变最优策略）** VISTA 在 ambiguous 时执行 safe_idle，得分率 0。若存在可逆探针 a∈Safe(ℬ) 且 E[score|a]>0、c_risk(a)=0，则对任意正剩余时钟有 VOI-C(a)>0，执行 a 严格优于 safe_idle。故「停下来 = 输」：**比赛把 VISTA 的保守停止从稳健变成被支配。** ∎

**命题（RRS 提升晋级概率）** 设晋级概率 P_adv 是最终得分 S 的单调不减函数。RRS 在落后时提高软目标风险预算，使得分分布右移（均值↑、方差↑）；在领先时降低风险，使分布左尾变短。在单调 P_adv 下，分段策略的 P_adv 不低于固定 α 策略（一阶随机占优的充分条件：同均值下方差有效转移）。硬规则不受 α 影响，故不引入额外违规。∎

**命题（对 VISTA 的弱支配）** 固定 δ_cred≤δ_fi。复合故障下若 m̂∉ℬ_t，则 Safe_VISTA=Safe({m̂}) 与 Safe(ℬ_t) 不可比，但存在 a∈Safe_VISTA∖Safe(ℬ_t)（在错误集合上乐观）。ARENA 不会选该 a，故其违规概率不含归因错误项，安全上弱支配 VISTA。得分上，当 VISTA 触发 safe_idle 而存在正分机会时，ARENA 由上一命题得分更高。∎

**锦标赛协议（E249 细则，避免「只在一个场景过拟合」）**：
1. **盲测池**：留出 20% 故障模式、20% 对手策略、20% 物体/场景，仅在决赛使用；
2. **多 seed**：每个配置 ≥10 seed，报告名次分布而非单次最好；
3. **红队轮**：独立团队仅看证书 J_arena 与规则，尝试构造覆盖漏检/时序/计分攻击；
4. **算力预算对齐**：所有方法同一控制截止与算力预算，禁止用离线大模型偷跑实时决策；
5. **可复现审计**：J_arena 的 scenario_hash / credal_coverage_ver / deadline_met 必须可离线复算。

## 7. 已知风险

**一句话**：ARENA 把安全的根基从「归因正确」换成了「真实故障始终落在 credal 集内」，而机器人竞赛恰恰是对抗、非可交换、规则可被利用的环境——对手可以用一个从未进过故障库、且同时欺骗视觉/力/几何的 OOD 手段，让 credal 集漏掉真实模式；此时最坏情况优化是在**错误集合**上做的乐观规划，系统会同时拿到「安全证书有效」和「真实世界失稳/失分」，即 VISTA 的归因单点故障被升级为**覆盖假设单点故障**。

**次级风险与缓解**：
1. **credal 覆盖在非可交换/对抗下失效**：conformal 的可交换性正是竞赛要打破的；缓解：在线漂移检测 + ε_t 上调 + **硬包络 𝒮₀ 不依赖覆盖**兜底；把覆盖失效当成「性能降级」而非「安全失效」。
2. **未知模式没有动力学，最坏情况无定义**：缓解：unknown 桶只用模型无关包络与可逆动作；不可逆动作在存在显著未知质量时一律拒绝或推迟。
3. **最坏情况过度保守，输给简单基线**：缓解：只在不可逆动作上用全 credal 最坏，可逆动作用场景 recourse；RRS 动态调风险；报告「保守性代价 κ_cons」。
4. **高维可行核不可算**：缓解：近似/学习终端集 + 在线验证其不变性；证书只在可验证的终端集上有效，否则降级到 𝒮₀。
5. **场景树组合爆炸**：缓解：场景采样 + move blocking + 重要性采样保持 credal 覆盖；不按 argmax 剪枝（那会重新引入归因依赖）。
6. **anytime 截止压力**：缓解：incumbent + π_b + 预留 reserve_ms；把世界模型全部留在语义流。
7. **RRS 鼓励危险行为**：缓解：α 只作用于软目标，硬规则与 𝒮₀ 不可放松；对「冒险动作」额外做最坏情况门。
8. **局间学习过拟合对手/规则**：缓解：盲测池、留出对手、红队、正则化到「最不易被利用」策略（近似 Nash / least-exploitable）；证书记录 opponent_model_ver。
9. **计分噪声/名次操纵**：缓解：AIC-A 的 ℰ_rank；只把计分当软信号，安全与规则不读分数。
