# 想法区 · 第 4 轮：把「枚举」升成「割」——BFS 前缀树、双侧证书，以及「穷举」本身的下界

**灵感词**：复杂度下界 / 广度优先搜索 / 伪代码
**起点**：v2.2「X-DUB/PACE-ΠA-CP*」。它在第 3 轮用 5 个残例的根闭换来了 held-out 229→50，但收官风险仍然是一句话：

> CPS 用「枚举一条链的所有 placement + 精确 residual 回溯」换来了 5 个残例的根闭，但它的完备性只覆盖 `S≤4`、`n≤16`、全资格且 residual 未撞 cap 的紧状态；一旦 residual 变大或资格异构，它只能退回 unknown，最坏情况仍是 `d!`。

这句话里其实混着两个不同的东西：一个是**覆盖门**（`S≤4`、`n≤16` 这些参数），另一个是**证书本身的形状**。第 3 轮改的是前者——把「块」换成「链」，让紧凑状态有一个可枚举的粗变量。它没有碰后者：CPS 的证书永远是**叶子表**，一个 placement 一个叶子，叶子之上没有信息。于是：

- 它没有「部分进展」：要么枚举完所有 placement，要么 UNKNOWN；
- 它回答不了「这 106 个 placement 里有多少是真必要的」；
- 它更回答不了「换一个更强的检查能省多少」。

本轮不推倒 v2.2。我想把证书的形状从**叶子集**改成**割**。

## 一、直觉：前缀也是全称对象

一条链 `P=(i_1≺…≺i_L)` 的 placement 树：第 `t` 层是前 `t` 个链任务的起点 `(s_1,…,s_t)`，第 `L` 层是完整 placement。每个完整 placement 是根到叶的一条路径。

关键的一句话：

> **前缀也是全称对象**。每个完整 placement 唯一地穿过每一层的一个前缀；如果一个前缀已经和某个必要条件矛盾，那么它下面的整棵子树都不可能是可行排程。

所以证 NO 不必等到叶子。任何一个**割**（antichain：每条根—叶路径恰好碰一个节点）都是证书。v2.2 只是把割限制在了叶子层；而「限制在叶子层」正是它撞 `d!` 的原因。

两个实测的例子（详见产物区）：

```text
held-out idx 42：56 个 placement，BFS 割 38 个节点（只省 32%）
held-out idx 40：210 个 placement，BFS 割 47 个节点（省 4.5 倍，2.31×）
held-out idx 1 ：84 个 placement，BFS 割 41 个节点（省 2.0 倍，2.19×）
```

差别不在 BFS，而在**深度 1 的测试能不能看见矛盾**。

## 二、为什么是 BFS，而不是 DFS

DFS 也能剪枝，而且通常更省内存。选 BFS 有三个具体理由，都和下界有关：

**（1）层结束时的 frontier 是一个可检查的下界。** 第 `t` 层结束时，frontier 里每个「活」前缀（还能补成合法链 placement）都至少有一条完整延拓。任何割必须在这棵子树里放一个节点，而且不能是它自己（它通过了测试）。于是

```text
|任何 T-割| ≥ |活 frontier|，   割的深度 ≥ t+2 .
```

这把「跑不动了」从失败变成了**结果**：预算截断时返回的不是一句 UNKNOWN，而是一个可检查的下界。

**（2）证书变成双侧的。** 上界 = 找到的割，下界 = 活 frontier，gap 就是测试类 `T` 的不完备度。若 gap=0（割=placement 数），说明在这条链上、这个 `T` 下，任何算法都不可能更小——这是**实例级的复杂度下界**，不是渐近口号。

**（3）层级并行/anytime。** 第 `t` 层的节点互不依赖，可以整层并行；预算按层切，代价可预测。v2.2 的并行单位是 placement，被最慢的那个 residual 卡住（4 核只有 1.98×）；BFS 的并行单位是整层，Amdahl 项从「最慢 placement」变成「最宽层」。

## 三、复杂度下界的正确用法

我不想假装证明 P≠NP。能证明的是三件事：

- **上界**：任何 `T`-割 ≤ placement 数 `N`；`T=∅` 时 BFS-PC 逐字退化成 v2.2（割=叶子集）。
- **下界（实例级）**：活 frontier 数 ≤ 任何 `T`-割。所以当 frontier 一直活到叶子层时，割=`N`，BFS-PC 的证书在该 `T` 下**最优**。
- **barrier（族级）**：只要 `T` 在叶子之上的每个前缀都通过，割就必然等于 `N`。**held-out 的 49 个 NO 例里，30 个恰好如此**（cut=placement 数、零内部剪枝）。这不是构造出来的病态例子，是多数派。

这条结论解释了本轮一个不太好听的实测：49 个共同 NO 例上，精确 residual 的调用从 947 降到 585（−38%），residual 节点 4.83M→3.13M（−35%），但几何平均加速只有 **1.032×**（中位数 1.061×）。因为在 61% 的实例上，v2.2 的枚举**已经是这个证书族的最优解**；剩下的 39% 里省下的叶子，并不总是最贵的那些——总时间能到 1.47×，主要靠 case 40（210→47 个叶子，19.5→8.4 s）和 case 1（84→41，1.6→0.73 s）这几个大头。

它同时给出了下一轮的方向：**想再快，只能加强 `T`，不能改遍历顺序**。本轮顺手做了一个对照：给 `T` 加一个 clique 测试（窗口落在 `[a,b)` 内、`p>(b−a)/2` 的任务两两重叠，必须占不同机器），在构造的 barrier 族上把割从 10 压到 1；但在 held-out 上只从 505 压到 501（−0.8%）。加强测试是有方向的，但不是免费的。

## 四、伪代码：把 `T` 做成接口

整个框架只有一个可插拔的东西：`TEST(prefix)`。正确性只依赖它的**可靠性**（fail ⇒ 无延拓），不依赖它的强度。于是伪代码可以写成（完整版见产物区）：

```text
BFS-PC(σ, P, B):
    frontier ← {ε};  cut ← ∅
    for t = 0,1,… while frontier ≠ ∅ and budget > 0:
        for x in frontier:                     # 整层，可并行
            if |x| = L:
                if RESIDUAL(x) = NO: cut ← cut ∪ {x}
            else:
                for y in CHILDREN(x):
                    if TEST(y) = fail: cut ← cut ∪ {y}
                    else:             next ← next ∪ {y}
        frontier ← next
    return NO  if frontier = ∅ and no UNKNOWN
           UNKNOWN(cut, frontier, LB)  otherwise
```

这段伪代码的好处是：`TEST` 换成 `∅` 就是 v2.2；换成 window+ER 就是本轮；换成 window+ER+clique 就是更强的版本。所有定理对任意可靠的 `TEST` 成立。换句话说，**v2.2 是 v2.3 的一个特例**，而「加强测试」是一个可以逐格推进的实验轴。

## 五、形式化（简版；完整定义、证明与实现见产物区）

**定义 1（placement 树）**。节点是合法前缀 `x=(s_1,…,s_t)`；`y=x·(s_{t+1})` 是子节点当 `s_{t+1} ≥ s_t+p_{i_t}` 且 `s_{t+1}+p_{i_{t+1}} ≤ h−q_{i_{t+1}}`。叶子是完整 placement。

**定义 2（活前缀）**。前缀 `x` 是活的，若从 `x` 出发按最早优先能把链补完（贪心，链上无其它约束，所以贪心最优）。

**定义 3（T-割）**。`C` 是 `T`-割，若 (i) 每条根—叶路径有且仅有一个节点在 `C`；(ii) 每个 `c∈C` 被 `T` 判 fail（叶子则被 exact residual 判 NO）。`T` 可靠：fail ⇒ 该节点无可行延拓。

**定义 4（BFS-PC 的三值语义）**。`NO` 若割覆盖全部叶子且无 UNKNOWN；`YES` 若找到一条可行叶（全资格 + exact residual 时是构造性证明）；`UNKNOWN` 若预算/cap 截断。

**定理 1（可靠性）**。`T` 可靠 ⇒ `BFS-PC=NO` ⇒ `σ` 不可行。

**定理 2（包含 v2.2）**。`T=∅` 时，BFS-PC 的割 = CPS 的叶子集；两者判决相同。

**定理 3（双侧下界）**。第 `t` 层结束时的活 frontier `L_t` 满足：任何 `T`-割 `|C| ≥ |L_t|`，且 `C` 含一个深度 `> t+1` 的节点。

**定理 4（barrier 与最优性）**。若 `σ` 不可行且 `T` 在所有内部前缀通过，则割恰为全部 `N` 个叶子；此时 BFS-PC 的证书在该 `T` 下最优，且任何同 `T` 算法至少要跑 `N` 次叶判定。

**定理 5（并行/anytime）**。层内节点独立；预算截断返回 `(cut, L_t)` 双侧证书。

## 六、本轮要交付什么

- **v2.3 = v2.2 + BFS-PC（tier 0.15）**：`CPS` 成为 `TEST=∅` 的特例，`BFS-PC` 是它的割版本。
- **双侧证书**：割（上界）+ 活 frontier（下界），都带独立检查器。
- **实测**：held-out 50 的 49 个共同 NO 例，精确 residual 调用 947→585（−38%），residual 节点 4.83M→3.13M（−35%），总时间 80.2→54.4 s，几何平均 1.032×，30/49 例割=placement 数（barrier 见证）；5 个残例割 7/12/21/38/7 vs placement 7/15/21/56/7；随机 60 状态 0 假 NO/0 假 YES；S≥5 合成 10 例在 v2.2 门外、BFS-PC 在根节点 1 步闭（ER off 时是 126 个叶子）。
- **负结果**：clique 在 held-out 上几乎无效；临界路径可能退化成 `L=1`（单个大任务），这时 BFS 没有内部结构可剪；barrier 只对 `TEST=window+ER` 成立。

## 七、一句话最大风险

**本轮最大的风险不是「BFS 没用」，而是把 30/49 的 barrier 误读成「证书族已经到顶」：barrier 只对 `TEST=window+ER` 成立，换一个测试就可能塌掉；而「加强测试」这件事目前没有理论指导，只能一个个试。**

## 0. 版本关系与本轮增量

v2.2 的资产全部保留：`MAP`、`DHD`、`DCD`、`ODOM`、`HPACK`、`PACK-front`、`MINT`、`PACK-SET`、`SOP`、`CPS` 的窗口/容量/精确 residual 内核、carry 定理、tier 0.10/0.15/0.20/0.30 的排序。

本轮增量只有一条核心规则和四组围绕它的扩展：

1. **`BFS-PC`（tier 0.15，替代 `CPS`）**：在 placement 树上逐层 BFS。内部节点用单调测试 `TEST` 剪枝；叶子仍用 v2.2 的精确 residual。概念上 `TEST=∅`（不做任何内部测试、只保留树的合法性）时逐字退回 v2.2 的 CPS；实现里的最弱配置是 `TEST=win`（窗口前瞻），它已经严格强于 CPS。
2. **`T-割` 证书**：NO 的证据是一个 antichain（每条根—叶路径恰好碰一个节点），不是叶子表。证书可重放：每个节点必须被 `TEST` 判 fail（叶子则被 exact residual 判 NO）。
3. **双侧证书**：预算截断时返回「活 frontier」，它给出任何同测试类 `T` 的割的**下界**（大小与深度）。于是算法同时输出上界与下界，gap 是测试类不完备度的可检查度量。
4. **barrier 定理**：若 `TEST` 在所有内部前缀通过，则割恰为全部 `N` 个叶子；此时 BFS-PC 的证书在该 `T` 下**最优**。实测 held-out 49 个 NO 例里 **30 个**属于此类——这不是病态构造，是多数派。
5. **实验**：held-out 49 个共同 NO 例，exact residual 调用 947→585（−38.2%），residual 节点 4,833,257→3,127,270（−35.3%），总时间 80.2→54.4 s（1.47×），几何平均 1.032×，中位数 1.061×；case 40 从 210 个叶子降到 47 个（2.3×）；5 个残例的割 7/12/21/38/7（placement 7/15/21/56/7）。
6. **负结果**：clique 测试在 held-out 上只把割从 505 压到 501；临界路径会退化成 `L=1`（单个大任务），这时 BFS 没有内部结构；case 4 在 20 s 内仍未解；barrier 只对 `TEST=window+ER` 成立。

退化关系：

```text
TEST=∅（概念极限，无内部测试）          → 逐字回到 v2.2 的叶子枚举
TEST=win（实现的最弱配置）              → 已比 CPS 强：前缀窗口前瞻会剪枝
BFS-PC 关掉                           → 逐字回到 v2.2 的 38/8/50/781
预算 B=∞、TEST=∅                      → 割=全部合法 placement，判决与 CPS 相同
预算 B 截断                            → UNKNOWN + 可检查的 (cut, frontier, LB)
clique on                             → 只改变割的大小，不改变三值语义
异资格                                 → 不适用：容量模型是松弛，NO 可靠、YES 只是 unknown（沿用 v2.2 §4.2 反例）
```

## 2. 形式定义

### 2.1 placement 树

**定义 1（节点/前缀）**。`x=(s_1,…,s_t)` 是链 `P` 的前缀，若

```text
s_1 ≥ est_{i_1},
s_{u+1} ≥ s_u + p_{i_u}                 (1 ≤ u < t),
s_u + p_{i_u} ≤ h − q_{i_u}             (1 ≤ u ≤ t).
```

`depth(x)=t`，`x=()` 是根。`x` 是完整 placement 当 `t=L`。

**定义 2（子节点/叶）**。`y=x·(s_{t+1})` 是 `x` 的子节点，若 `s_{t+1} ≥ s_t+p_{i_t}` 且 `s_{t+1}+p_{i_{t+1}} ≤ h−q_{i_{t+1}}`。深度 `L` 的节点是叶。

**事实 1**。每个合法完整 placement 唯一对应一条根—叶路径；反之每条根—叶路径是一个合法 placement。

### 2.2 测试类

**定义 3（可靠测试）**。`T` 把每个节点映射到 `pass/fail`。称 `T` **可靠**，若对任意节点 `x`：

```text
T(x)=fail  ⇒  不存在从 x 延拓出的合法完整 placement .
```

本轮实现的三种 `T`（可任意组合）：

```text
win     : 固定 x 后做前向 release / 后向 deadline 传播，检查 r_j+p_j ≤ d_j 与边一致。
ER      : 对每个区间 [a,b)，mandatory(x,a,b) = Σ_j max(0, p_j − max(0,a−r_j) − max(0,d_j−b))
          ≤ Σ_{t∈[a,b)} c_x(t) ，其中 c_x 是剩余容量（m 减去 x 的占用）。
clique  : 对每个区间 [a,b)，{j : r_j≥a, d_j≤b, p_j>(b−a)/2} 两两重叠，必须 |·| ≤ m。
```

三者都是**必要**条件，因此可靠；三者都不完备。`ER` 的区间端点只取窗口端点（`r_j,d_j`）与 `0,h`，被 `max_intervals=400` 截断；截断只会让测试更弱，不影响可靠性。

### 2.3 割

**定义 4（`T`-割）**。`C` 是 `𝒯`-割，若

1. **覆盖**：每条根—叶路径恰有一个节点在 `C` 中；
2. **失败**：每个 `c∈C` 满足：`depth(c)<L` 且 `T(c)=fail`，或 `depth(c)=L` 且 `RESIDUAL(c)=NO`。

**引理 1（割 ⇒ NO）**。若 `T` 可靠且存在 `𝒯`-割，则 `σ` 不可行。

**证明**。反设存在可行排程。由事实 1，它给出一个合法完整 placement `ℓ`；由覆盖性，路径上有 `c∈C`。若 `c` 是内部节点，`T(c)=fail` 与可靠性矛盾（`ℓ` 是 `c` 的可行延拓）；若 `c` 是叶，`RESIDUAL(c)=NO` 与 `ℓ` 是该 residual 的可行解矛盾。∎

### 2.4 活前缀与 frontier 下界

**定义 5（活前缀）**。`x` 是活的，若存在合法完整 placement 以 `x` 为前缀。判定用贪心：从 `x` 的末端开始，把链的剩余任务按最早时刻依次排下，检查每个 `s_u+p_{i_u} ≤ h−q_{i_u}`。因为链上只有先后约束、没有资源约束，最早排法最优。

**定义 6（frontier）**。处理完第 `t` 层后，`F_t` 是深度 `t+1` 且所有祖先（含自身）都通过 `T` 的节点集合。`L_t = {x∈F_t : x 活}`。

### 2.5 三值语义

**定义 7（BFS-PC）**。

```text
NO       若 frontier 变空（无 UNKNOWN），且每个被丢弃的节点都是
         内部 T-fail 或叶子 RESIDUAL=NO；
YES      若某条叶子的 RESIDUAL=YES（全资格 + 精确 residual 时是构造性证明）；
UNKNOWN  若预算 B 耗尽、或某叶子 residual 撞 Ncap、或 `S(σ)<0` 以外的截断。
```

### 2.6 双侧证书

**定义 8（双侧证书）**。`(C, L_t, t)` 中 `C` 是 `𝒯`-割（上界），`L_t` 是第 `t` 层的活 frontier（下界），断言：

```text
|L_t| ≤ |C'|   对任何 𝒯-割 C';
C' 至少有一个节点深度 ≥ t+2 .
```

检查器重放每个 `c∈C` 的失败判定、每个 `x∈L_t` 的祖先测试与贪心补全。

## 3. 算法

### 3.1 BFS-PC 主循环

```text
BFS-PC(σ, P, B, 𝒯):
    q ← TAILS(σ);  cp ← max_i(est_i+p_i+q_i);  S ← h−cp
    if S < 0: return NO
    cut ← ∅;  frontier ← {()};  nodes ← 0
    if TEST(()) = fail: return NO(cut={()})
    while frontier ≠ ∅:
        if nodes + |frontier| > B:
            return UNKNOWN(cut, frontier, LB(frontier), depth)
        next ← ∅
        for x in frontier:                       # 整层，可并行
            for y in CHILDREN(x):
                nodes ← nodes + 1
                if TEST(y) = fail: cut ← cut ∪ {y}
                else if depth(y) = L:
                    if RESIDUAL(y) = NO: cut ← cut ∪ {y}
                    else: return YES
                else: next ← next ∪ {y}
        frontier ← next;  depth ← depth + 1
    return NO(cut)                                # 割覆盖全部叶子
```

**不变量**：

```text
(I1) cut 是 antichain；
(I2) 每个被丢弃的节点 y 都有 T(y)=fail，或 depth(y)=L 且 RESIDUAL(y)=NO；
(I3) frontier 中每个节点都通过 T，且其所有祖先也通过 T；
(I4) 每条根—叶路径要么已经碰到 cut，要么穿过 frontier。
```

`(I4)` 在循环结束时给出覆盖性；`(I2)` 给出失败性；`(I1)` 给出割的合法性。

### 3.2 测试的实现

```text
TEST(y):
    if WINDOWS(y) = ⊥: return fail            # 窗口/边矛盾
    if ER and not ER_OK(y): return fail
    if CLIQUE and not CLIQUE_OK(y): return fail
    return pass
```

`WINDOWS` 是两遍拓扑最长路（v2.2 §2.3），`ER_OK`/`CLIQUE_OK` 见定义 3。三者都只依赖 `y` 的窗口与容量，不依赖搜索树，因此检查器可以独立重放。

### 3.3 叶判定

叶子 `y` 调用 v2.2 的 `_residual_feasible`：窗口传播 → 容量 profile → 精确回溯（minopts + 升序 + memo + energy 剪枝）。`Ncap` 命中返回 `unknown`，不是 `NO`。

### 3.4 证书检查

```text
CHECK-CUT(inst, P, C, 𝒯):
    for c in C:
        if depth(c) < L:
            if WINDOWS(c)=⊥: continue
            if ER/CLIQUE 判 fail: continue
            return reject('node passes')
        else:
            if RESIDUAL(c)=NO: continue
            return reject('leaf not NO')
    if not COVERS(inst, P, C): return reject('not covering')
    return accept
```

`COVERS` 用独立枚举所有合法 placement 检查每条路径都碰到 `C`；只在小实例上做（`N≤5000`）。大实例上退化为「按构造保证覆盖」+ 抽样。

### 3.5 下界提取

```text
LB(frontier):                       # frontier 的深度为 depth
    live ← [x for x in frontier if GREEDY-LIVE(x)]
    return (|live|, depth+1, live)  # 任何割都要在 live 的严格后代里放节点
```

**用途**：预算截断时返回 `(cut, live, depth)`，检查器验证 `live` 中每个节点通过全部祖先测试且贪心可补全，即证明「任何 `𝒯`-割 ≥ |live|」。

### 3.6 接进 PACE-ΠA

```text
PACE-ΠA-BC(σ,h):
  1..11  与 v2.2 相同（DEAD/NORM/window/MAP/DHD/DCD）
 12  if BC-gate(σ) and |ready\drop| > 0:
         v ← BFS-PC(σ, critical_path(σ), B, 𝒯)
         if v = NO: return NO(BC)
 13  for i in K=ready\drop: ...                  # v2.2 不变
 14  F_sub.insert(...); return NO
```

与 v2.2 的差异只有第 12 步：`CPS` 换成 `BFS-PC`；`T=∅` 时两者逐字相同（概念极限）。门 `BC-gate` 沿用 `cps_gate`（`|R|≤16, S≤cps_tau`），但**语义变了**：`S≤4` 不再是「placement 数可枚举」的门，而是「割足够小」的经验门；更大的 `S` 若深度 1 大量剪枝也可跑。原型没有接进搜索树，第 12 步是设计稿。

### 3.7 复杂度

设第 `t` 层 frontier 大小 `F_t`、内部节点总数 `Σ_t F_t`、叶判定次数 `N_leaf`、单次叶判定代价 `T_res`。

```text
每节点 TEST:   O(n^3)（ER 的 O(n^2) 区间 × O(n) 任务；clique 同阶）
总时间:        O((Σ_t F_t)·n^3 + N_leaf·T_res)
内存:          O(max_t F_t + h)                # BFS 存整层
最坏:          F_t = C(S+t,t)，ΣF_t ≈ N·L，N=C(S+L,L)
```

对比 v2.2：`O(N·(n+h) + N·T_res)`，且没有内部节点。所以 BFS-PC 在**无剪枝**时比 v2.2 慢（多付前缀开销），只有 `剪掉的叶子 × T_res > 新增前缀 × n^3` 时才赚。实测正是这个形状：总时间 1.47×，但几何平均只有 1.032×，小实例被 ER 开销拖慢。

### 3.8 并行与 anytime

层内节点独立：第 `t` 层可切给 `P` 个 worker，OR/AND 合并；早停只在 `YES`。层同步 makespan 下界：

```text
C_max ≈ Σ_t max(1, ⌈F_t / P⌉) .
```

`W=Σ_t F_t`、`D=max_t F_t` 时上界 `W/P + D`。实测 held-out 的 `W=1220`、`max F_t=35`：`P=4` 时 `Σ⌈F_t/4⌉=500`，而 `W/4=305`，效率 61%；`P≥16` 时层宽不够，并行无意义。本轮**没有**并行原型，这只是由层宽算出的上界。

## 4. 定理与证明

### 4.1 单调性

**引理 2（测试单调）**。若 `y` 是 `x` 的子节点，则 `y` 的 residual 可行解集 ⊆ `x` 的 residual 可行解集。

**证明**。固定 `x` 后，剩余任务（含未固定的链后缀）的窗口由 `est/q` 与已固定链任务的最长路给出；固定更多链任务只会让 release 不减、deadline 不增、容量不增。所以 `y` 的约束是 `x` 的约束的超集。∎

**推论**。`T` 在 `x` 上 fail ⇒ `T` 在 `y` 上也 fail（对任何可靠 `T`）；但算法不需要这个性质——它在 `x` 处剪枝后根本不访问 `y`。

### 4.2 可靠性

**定理 1**。若 `T` 可靠，`BFS-PC=NO` ⇒ `σ` 不可行。

**证明**。循环结束时 `frontier=∅` 且无 `UNKNOWN`。由 `(I4)`，每条根—叶路径都碰到 `cut`；由 `(I2)`，每个割节点都失败（`T`-fail 或叶 `RESIDUAL=NO`）。引理 1 给出不可行。∎

### 4.3 包含 v2.2

**定理 2**。`T=∅`（不做任何内部测试，只保留树的合法性）时，BFS-PC 的割恰为全部 `RESIDUAL=NO` 的叶子，判决与 v2.2 的 CPS 相同。

**证明**。`T=∅` 时所有内部节点 pass，`frontier` 逐层展开到全部叶；割只收集 `RESIDUAL=NO` 的叶。v2.2 枚举全部合法 placement 并对每个跑同一 residual；两者叶集相同。`YES` 的早停也相同（存在一个 residual 可行）。∎

**注**：这正是「v2.2 是 v2.3 的抽象特例」的精确含义。实现里的最弱配置是 `T=win`（窗口前瞻），它已经能在内部剪枝，所以实测的 `T=win` 严格强于 CPS（base 配置已经在内部剪枝）。本轮的所有收益都来自内部测试，而不是 BFS 顺序。

### 4.4 双侧下界

**定理 3**。设处理完第 `t` 层后 frontier 为 `F_t`（深度 `t+1`，全部通过 `T`），`L_t` 是其中活前缀。则任何 `𝒯`-割 `C'` 满足

```text
|C'| ≥ |L_t| ,   且 C' 至少有一个节点深度 ≥ t+2 .
```

**证明**。设 `t+1<L`。取 `u∈L_t`，由活性存在合法完整 placement `ℓ` 以 `u` 为前缀。`C'` 覆盖 `ℓ`，故某个 `c∈C'` 是 `ℓ` 的前缀。若 `depth(c) ≤ t+1`，则 `c` 是 `u` 或 `u` 的祖先；由 `u∈F_t`，这些节点全部通过 `T`，且它们的深度 `<L`。但割的内部节点必须 `T`-fail，矛盾。所以 `c` 是 `u` 的严格后代，`depth(c) ≥ t+2`。不同的 `u` 子树不相交，故 `|C'| ≥ |L_t|`。∎

**注（叶子层）**：若 `t+1=L`，`L_t` 是活叶子；割节点可以是叶子本身（`RESIDUAL=NO`），此时深度下界退化为 `≥L`。代码里 `LB` 只在 `depth<L` 时报告深度下界。

**系（gap）**。`|L_t| ≤ |C|` 对算法自己找到的割也成立；`gap = |C| − |L_t|` 是测试类在「从 `t+1` 层往下」这段的不完备度的可检查下界。

### 4.5 barrier 与最优性

**定理 4（barrier）**。若 `T` 在所有内部节点（`depth<L`）通过，则 BFS-PC 的割恰为全部 `N` 个合法叶；任何同 `T` 的割也至少含 `N` 个节点，且算法至少做 `N` 次叶判定。

**证明**。内部全 pass ⇒ frontier 一路展开到叶层；割 = 全部叶（每个叶 `RESIDUAL` 必须为 `NO`，否则实例可行）。任何 `T`-割不能含内部节点（它们 pass），只能含叶；覆盖要求每条路径一个，故 ≥`N`。∎

**实测**：held-out 49 个 NO 例中 30 个满足 `cut = placement 数`，即零内部剪枝。这些实例上 v2.2 的叶子枚举已经是该证书族的最优解——这是本轮最重要的「下界」结论，也是速度收益有限的原因。

### 4.6 并行/anytime

**定理 5**。层同步并行下，(a) 任一 worker 的 `YES` 可安全早停；(b) 所有 worker 的 `NO` 才能合成 `NO`；(c) 预算截断返回的 `(cut, L_t)` 满足定理 3。

**证明**。(a)(b) 是 `∨/∧` 的标准性质：`YES` 是存在句，`NO` 是全称句；层划分不重不漏。(c) 由定理 3。∎

### 4.7 集成

**定理 6**。把 BFS-PC 作为第 12 步的剪枝层，PACE-ΠA-BC 的 YES 仍可行、NO 仍可靠；其余步骤逐字是 v2.2。

**证明**。第 12 步只在 `BFS-PC=NO` 时返回，定理 1 给出该子树无解；未被剪的分支覆盖 v2.2 的全部分支。∎

### 4.8 NP-hard 不变

**命题 1**。BFS-PC 没有打破 NP-hard：`m=2`、无优先、全资格时 residual 仍是 `P||Cmax` 的判定；`T` 是多项式测试，割的构造不改变问题的判定复杂度。指数被搬到了 `N=C(S+L,L)` 与 residual 回溯上。∎

### 4.9 异资格边界

**命题 2**。`ER`/`clique` 与 `RESIDUAL` 都只看聚合容量，不看具体机器。异资格下 `T`-fail 仍可靠（必要条件），但 `YES` 不是可行性证明；v2.2 §4.2 的反例（`m=2, A=(6,0)`，链任务只上机器 0、后继只上机器 1）同样适用。原型只跑全资格根状态。∎

| 测试 | 规模 | 结果 |
|---|---|---|
| 随机对拍（30 实例 × {OPT−1, OPT}） | 60 状态 | **0 假 NO / 0 假 YES**；所有精确引擎调用未撞 2M cap |

| 重放检查器（每个割节点独立重判） | 7 例 | 全部 `accept` |

「0 假 NO」的定义：同一实例、同一 h，BFS-PC 返回 `NO` 而精确引擎（v2.1，`cps_on=False`，nodecap 2M）返回可行。所有 `decide` 调用都检查 `st['timeout']`，撞 cap 的状态直接跳过，不参与比较。

### 5.7 barrier 统计与链退化

- **barrier 多数派**：49 个 NO 例中 30 个 `cut = placement`，零内部剪枝；其中 5 残例里的 5/32/47 也是。
- **链退化**：构造 `m=2`、3 个 `>h/2` 的大任务 + 一条单位链的实例。`critical_path` 选中的是**单个大任务**（`L=1`），不是单位链；于是 BFS 没有内部结构，割 = `S+1`（10 或 11 个叶子）。给 `TEST` 加 `clique` 后，根节点直接判 fail，割 = 1。
  - 教训：BFS-PC 的收益随 `L` 增长；**链选择的目标从「最小化 placement 数」变成「最大化可剪深度 × 宽度」**。v2.2 的链 portfolio 在这里仍然有用，但选择准则要改。

### 5.8 并行潜力

由 held-out 的层宽直接计算（无并行原型）：

```text
W = Σ_t F_t = 1220,  max F_t = 35
P=4 :  Σ_t ⌈F_t/4⌉ = 500  （vs W/4 = 305，效率 61%）
P=16:  层宽不够，⌈35/16⌉ 的并行度只有 3
```

BFS 的并行单位是「整层」，Amdahl 项是「最宽层」而不是「最慢 residual」；但层宽只有 35，P>8 没有意义。这与 v2.2 的 placement 级并行（4 核 1.98×）是两种不同的瓶颈，不能直接比较。

## 6. 负结果与陷阱

### 6.1 BFS 本身不带来加速

`T=∅` 时 BFS-PC 与 CPS 的叶集相同，但 BFS 多付内部节点开销；实现里的最弱配置 `T=win` 已经会剪枝（base 消融的割小于 placement 数），所以它并不比 CPS 慢，只是收益来自窗口前瞻而不是 BFS。小实例上 ER 的 `O(n^3)` 开销明显（case 13/46/19/25/22 慢 2%–38%）。**如果只想复现 v2.2，直接用 CPS。**

### 6.2 barrier 是多数派

30/49 的 held-out NO 例零内部剪枝。这说明「前缀级矛盾」在这些实例上不存在；想再快只能加强 `TEST`，而加强 `TEST` 没有理论指导。clique 是一个例子：它在 held-out 上 505→501，在构造族上 10→1——收益完全取决于实例结构。

### 6.3 clique 不是免费的

- 它需要 `p_j > (b−a)/2` 的两两重叠论证，只对「大任务」有效；
- 区间端点是窗口端点，`max_intervals` 截断会漏掉长区间；
- 它不改变 `YES` 的语义，但会增加每节点 `O(n^3)` 的常数。

### 6.4 临界路径可能退化

见 §5.7：`critical_path` 可能选到单个大任务（`L=1`），BFS 没有内部节点可剪。更一般地，BFS-PC 喜欢「长链」（层数多、剪枝机会多），而 v2.2 的 CPS 喜欢「短链」（placement 少）。**链选择的目标函数变了**，这是下一轮要修的第一件事。

### 6.5 内存

BFS 存整层。最坏 `F_t = C(S+t,t)`，`S=10, t=10` 时一层就 184,756 个前缀；每个前缀是一个 tuple + 窗口。v2.2 的 DFS 只需 O(L) 栈。BFS 的 anytime 是用内存换的。

### 6.6 预算口径

`nodes` 计的是「创建的节点」，包括被剪掉的；`cut` 只计失败节点。两者不能混用。`B` 是创建节点上限，不是叶判定上限；一个 `B` 很大的实例可能只做很少的叶判定（好事），也可能做很多（坏事）。

### 6.7 `LB` 不是绝对下界

`LB` 只对「同一 `TEST` 类」的割成立；不同 `TEST` 的 `LB` 不可比（更强的测试能更早剪枝，割可以更小，但它面对的是另一个证书族）。它不是「任何算法」的下界，不能拿它去反驳「换一个分解会更好」。

### 6.8 根状态原型的边界

`windows_prefix` 里非固定任务的 release 从 `est` 起；原型只跑 `est=0, A=0`。接进搜索树需要把 `est/A` 传进来，并在 `RESIDUAL` 里用真实的 `A`。这是机械改动，但本轮没有做，也没有测非根状态。

### 6.9 异资格

沿用 v2.2：`RESIDUAL` 不看 eligibility，`CPS=YES` 在异资格下只是 unknown。BFS-PC 的 `ER`/`clique` 同样只看聚合容量；异资格下 `NO` 可靠、`YES` 不可靠。原型只跑全资格。

### 6.10 没有形式化验证

60 状态对拍 + 7 例重放 + 50 个 `h=OPT` 的 0 假 NO + 5 残例，是强证据，不是 Coq/Lean。定理 1–6 是纸面证明。

| 项 | v2.2 | v2.3 |
|---|---|---|

## 8. 已知风险

1. **根状态原型**：只跑 `A=0, est=0`，未接进搜索树；第 12 步的集成是设计稿，不是实测。
2. **barrier 多数派**：30/49 的 held-out NO 例零内部剪枝；在这些实例上 BFS-PC 不优于 v2.2（只多付 ER 开销）。
3. **收益集中**：总时间 1.47× 主要来自 case 40（2.3×）和 case 1（2.2×）；几何平均只有 1.032×，小实例普遍变慢。
4. **ER 不完备**：`max_intervals=400` 截断、只取窗口端点、只做 mandatory 能量；更强的 ER（左/右移、flow）未实现。
5. **clique 依赖结构**：held-out 上 505→501；只对「大任务」有效，不能当作通用加强。
6. **链选择**：临界路径可能退化成 `L=1`；BFS 喜欢长链，CPS 喜欢短链，目标函数冲突。portfolio 的准则要重写。
7. **内存**：BFS 存整层，最坏 `C(S+t,t)`；没有内存上限保护。
8. **case 4**：20 s 内仍未解（`Ncap` 命中/超时），v2.2 与 v2.3 都一样。
9. **异资格**：只保证 NO；`YES` 只是 unknown；原型只跑全资格。
10. **没有并行原型**：§5.8 是层宽算出的上界，不是实测。
11. **`LB` 的适用范围**：只对同一 `TEST` 类成立，不是绝对下界。
12. **没有形式化验证**：纸面证明 + 对拍 + 重放。
13. **预算口径**：`B` 计创建节点，不是叶判定；不同实例的 `B` 不可直接比较。

---

## 9. 一句话最大风险

**BFS-PC 把 NO 证书从叶子表升级成前缀割，并用活 frontier 给出同测试类的下界；但它在 30/49 的 held-out NO 例上割=叶子数（barrier 是多数派），所以本轮真正的贡献是「证书形状 + 下界」而不是速度——一旦把 1.47× 的总时间当成普遍加速，就会误判这条路线已经解决了 CPS 的 `d!` 风险。**
