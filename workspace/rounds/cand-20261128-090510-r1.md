### 第 8 轮灵感驱动研究记录

**灵感词**：数据增强、抓取

**继承关系**：第 7 轮 CADVS-v7（IP-501~IP-504）以 DIM/DRC/DAC 建立「需求-意图-一致性三角桥」，EFA-v7 在七硬门之上叠加六软因子链 η_g·η_topo·η_interp·η_cmd·η_demand·η_affect。本轮严格保持「执行硬门不增」：不新增任何执行门，转而聚焦「**抓取数据增强的证书化**」——把「数据增强」从训练技巧提升为「受证书约束的提议分布扩展」。用「抓取数据增强器」(GDA)、「证书约束准入」(CCA) 与「增强覆盖度量」(ACM) 缓解第 7 轮遗留的 R60（GGC 离线原型不足）与分布外抓取泛化问题。

**直觉与动机**：

1. **数据增强 → 从「离线训练技巧」到「在线提议分布扩展」**。传统数据增强只服务于训练集，训练完即被丢弃；但抓取问题的瓶颈往往不在「模型容量」而在「提议分布覆盖不足」——FMPP 只在其见过的抓取流形邻域内可靠。关键洞见是：**增强应发生在提议阶段而非仅训练阶段**——把 GDA 生成的、带证书的增广抓取原型注入 LMEM，让 FMPP 的提议分布覆盖更多可行抓取，而硬门过滤链路完全不变。

2. **抓取 → 从「几何可行」到「可行且覆盖」**。GGC 回答「这个抓取是否几何/力学可行」，但它对「没见过但可行」的抓取会保守拒绝。抓取的结构（接触点、法向、摩擦锥、抓取矩阵）天然支持**保结构增强**：对物体与夹爪施加同一 SE(3) 变换，接触几何与力闭合不变；在摩擦锥内扰动接触力，力闭合保持。关键洞见是：**抓取的物理结构给出了「增强不变量」**——这正是把增强做得可证明的抓手。

3. **证书 → 从「执行门」到「数据门」**。第 7 轮把新增检验塞进执行硬门，带来「硬门膨胀」与阈值漂移风险。本轮反转：**把证书放在数据入口而非执行出口**。CCA 用与硬门共享的实现判定每个增广样本 a_cert(x')，只有通过者才允许进入 D_aug；执行时仍是原封不动的硬门。这样增强可以任意激进，却无法把一个不可行抓取「洗」进执行集。

**关键洞见**：第 7 轮回答「如何主动推导用户需求」；第 8 轮回答「如何在不让执行集膨胀的前提下，用数据增强扩大可行抓取的覆盖」。七硬门 kc_evidence_forged_v5 记号原样复用，执行硬门谓词集合与 v7 完全一致（本轮不新增任何执行门）；本轮新增的只有：
- IP-505 GDA（抓取数据增强器，保结构变换 + 摩擦锥扰动 + 有界形变），
- IP-506 CCA（证书约束准入，数据门而非执行门），
- IP-507 ACM（增强覆盖度量，软因子 η_aug），
- IP-508 EFA-v8（硬门不变 + 软因子链延伸 η_aug）。

**形式化目标（增量）**：

1. **GDA（Grasp Data Augmentation）**：<br>
   - 保接触刚体变换：x' = T_g ⊙ x，T_g ∈ SE(3) 同时作用于物体点云与夹爪位姿，接触集 C 与接触法向随动；<br>
   - 摩擦锥内扰动：对接触力 f_i = n_i + t_i 施加 ||t_i|| ≤ μ||n_i|| 的切向扰动；<br>
   - 有界形变：对物体做 Hausdorff 距离 d_H(∂O, ∂O') ≤ Λ_dist 的形状扰动；<br>
   - 增广集 D_aug = {A(x) | x ∈ D, a_cert(A(x)) = 1}。

2. **CCA（Certificate-Constrained Admission）**：<br>
   - a_cert(x') = GGC(x') ∧ MCTM(x') ∧ FC(x') ∧ ¬Ψ_novel(x')，与 v7 硬门**共享同一实现与版本号 v_gate**；<br>
   - 仅 a_cert=1 的样本进入 D_aug；a_cert 是**训练数据准入门**，不是执行门；<br>
   - 版本绑定：若硬门实现版本变化，D_aug 自动失效并重签（防证书漂移）。

3. **ACM（Augmentation Coverage Metric）**：<br>
   - 覆盖度 Cov(D) 用抓取流形上的 ε-覆盖数（或 k-NN 半径）估计；<br>
   - η_aug = 1 + λ·(Cov(D ∪ D_aug) − Cov(D)) / Cov(D)，裁剪到 [1, 1+ε_aug]，ε_aug = 0.2；<br>
   - η_aug 只调提议广度 K_aug = ⌈K·η_aug⌉ 与软阈值，不改变硬门谓词。

4. **EFA-v8（硬门不变 + 七软因子链）**：<br>
   - ECS_v8 = ECS_v7 · η_aug；<br>
   - τ_i^v8 = γ_i·τ_i^v7·Π_aug，Π_aug = η_aug ∈ [1, 1+ε_aug]，总设计上限 Π_total = Π_factor_i·η_aug ∈ [1, 1.5]；<br>
   - K_aug = ⌈K·η_aug⌉ 扩展候选数，但候选仍须逐条通过硬门；<br>
   - **不新增执行硬门**，执行集只可能收缩：Exec_v8 ⊆ Exec_v7 ⊆ Exec_v6。

5. **形式化定义**：给定真实原型集 D、增广算子 A、当前提议上下文 c：<br>
   - D_aug = CCA(A(D))；<br>
   - η_aug = ACM(D, D_aug)；<br>
   - K_aug = ⌈K·η_aug⌉；<br>
   - cands = FMPP.propose(c, K=K_aug)；<br>
   - surv = {x ∈ cands | ⋀_{i=1}^7 G_i(x) ∧ ECS_v8(x) ≥ τ^v8}。

**本轮最大风险**：**增强分布漂移与证书盲区**——证书只保证增广样本落在硬门可行域内（可行性不变），却不保证其与真实任务分布一致；一旦合成几何主导提议模型，系统可能在高覆盖率下悄然过拟合合成伪影，而 fail-closed 边界对此完全无感。

## 2. 关键算法骨架

### IP-505 GDA：抓取数据增强器

```python
@dataclass
class GraspDataAugmentation:
    """GDA：保结构抓取增广。所有变换都尽量保持物理可行性不变量。"""
    mu: float = 0.5
    lambda_dist: float = 0.005   # 5 mm
    n_variants: int = 16

    def contact_preserving_se3(self, x: Grasp, rng) -> Grasp:
        """物体与夹爪施加同一 T_g，接触集与法向随动"""
        T_g = sample_se3(rng)                    # 小邻域刚体变换
        obj = transform_points(x.obj, T_g)
        gripper = T_g @ x.gripper
        C = [(T_g @ p, T_g.R @ n) for p, n in x.contacts]
        return replace(x, obj=obj, gripper=gripper, contacts=C)

    def friction_cone_perturb(self, x: Grasp, rng) -> Grasp:
        """切向扰动保持在摩擦锥内，力闭合不变"""
        new_c = []
        for p, n, f in x.contacts:
            t = sample_tangent(rng, n)
            t = t / (norm(t) + 1e-9) * rng.uniform(0, self.mu * norm(f))
            new_c.append((p, n, f + t))
        return replace(x, contacts=new_c)

    def bounded_morph(self, x: Grasp, rng) -> Grasp:
        """有界形变：d_H(∂O, ∂O') <= lambda_dist"""
        obj2 = shape_morph(x.obj, rng, max_hausdorff=self.lambda_dist)
        return replace(x, obj=obj2)

    def augment(self, D: list[Grasp], rng) -> list[Grasp]:
        out = []
        for x in D:
            for _ in range(self.n_variants):
                y = self.contact_preserving_se3(x, rng)
                y = self.friction_cone_perturb(y, rng)
                y = self.bounded_morph(y, rng)
                out.append(y)
        return out
```

### IP-506 CCA：证书约束准入（数据门）

```python
@dataclass
class CertificateConstrainedAdmission:
    """CCA：只允许通过硬门（共享实现）的增广样本进入 D_aug。
    注意：这是数据准入门，不是执行门；执行链路仍是 v7 硬门。"""
    ggc: GraspGeometryCutter
    mctm: MobileChassisTopologyMap
    gate_version: str            # v_gate，与执行硬门同一版本

    def certificate(self, x: Grasp, pose) -> bool:
        return (self.ggc.feasible(x)
                and self.mctm.feasible(x, pose)
                and force_closure(x, mu=self.ggc.mu)
                and not psi_novel(x))

    def admit(self, D_aug: list[Grasp], pose) -> list[Grasp]:
        return [x for x in D_aug if self.certificate(x, pose)]

    def check_version(self, current_gate_version: str) -> bool:
        """证书漂移防护：硬门实现变版本，旧 D_aug 全部失效"""
        return self.gate_version == current_gate_version
```

### IP-507 ACM：增强覆盖度量

```python
@dataclass
class AugmentationCoverageMetric:
    """ACM：覆盖度增益 → η_aug ∈ [1, 1+eps_aug]"""
    eps_aug: float = 0.2
    lam: float = 1.0

    def coverage(self, D: list[Grasp], manifold, eps: float = 0.02) -> float:
        """ε-覆盖度：流形上被 D 的 eps-球覆盖的比例（或用 k-NN 半径近似）"""
        return eps_cover_fraction(D, manifold, eps)

    def eta_aug(self, D, D_aug, manifold) -> float:
        cov0 = self.coverage(D, manifold)
        cov1 = self.coverage(D + D_aug, manifold)
        gain = (cov1 - cov0) / max(cov0, 1e-9)
        return float(min(1.0 + self.eps_aug, 1.0 + self.lam * gain))

    def proposal_budget(self, K: int, eta_aug: float) -> int:
        return math.ceil(K * eta_aug)
```

### IP-508 EFA-v8：硬门不变 + 七软因子链

```python
@dataclass
class EvidenceForgingAssemblerV8:
    """EFA-v8：执行硬门与 v7 完全一致；仅扩展提议广度并追加 η_aug。"""
    v7: EvidenceForgingAssemblerV7
    acm: AugmentationCoverageMetric
    lmem: LongTermMemoryEmbeddingConsolidation
    fmpp: FlowMatchingProposalPolicyKernel

    def select(self, L, t_now, context, D_aug, manifold):
        # 1. 覆盖软因子（只影响提议广度与软阈值）
        eta_aug = self.acm.eta_aug(D=self.lmem.real_protos(),
                                   D_aug=D_aug, manifold=manifold)
        K_aug = self.acm.proposal_budget(self.fmpp.K, eta_aug)

        # 2. 提议：候选数扩展，硬门不变
        c = build_ctx_v7(context)
        cands = self.fmpp.propose(c, K=K_aug)

        # 3. 硬门过滤：原样调用 v7，谓词与版本完全不变
        surv = []
        for x in cands:
            ok, best, tag = self.v7._gate_and_score(x, c, t_now, eta_aug=eta_aug)
            if ok:
                surv.append((best, tag))

        if not surv:
            return self.v7.select(L, t_now, context)  # 回退 v7，不降级硬门
        best, tag = max(surv, key=lambda z: self.v7._margin(z[0]))
        return True, best, 'FORGED_CGE_V8'

    def ecs_v8(self, x, n_flow, s_emo, eta_factors):
        """ECS_v8 = ECS_v7 · η_aug"""
        return self.v7.ecs_v7(x, n_flow, s_emo, eta_factors) * eta_factors['aug']

    def tau_v8(self, gamma_i, tau_v7, eta_aug):
        """τ_i^v8 = γ_i·τ_i^v7·η_aug，η_aug ≥ 1 ⇒ 只收紧"""
        return gamma_i * tau_v7 * eta_aug
```

### 集成流水线（v7 → v8）

```
离线/慢时域：
  D 真实原型（1k）──▶ GDA.augment(×N) ──▶ 候选增广池
  候选增广池 ──▶ CCA.admit（硬门共享实现 + v_gate 绑定）──▶ D_aug
  D_aug 按证书版本分区写入 LMEM（旧版本自动失效）
  ACM 估计 Cov(D), Cov(D∪D_aug) ──▶ η_aug

在线准入（亚秒级）：
  η_aug 与 K_aug 预计算（每次 D_aug 更新时刷新）
  FMPP.propose(c, K=K_aug) ──▶ 候选
  硬门（v7 原样）逐条过滤 ──▶ 通过者按 ECS_v8 排序
  若全灭 ──▶ 回退 v7.select（不降级任何硬门）

在线控制环（目标 < 0.9 ms）：
  K_aug ≤ ⌈K·1.2⌉，额外候选仅增加常数级前向；
  硬门调用链路与 v7 完全一致（缓存复用）。
```

## 4. 正确性论证（增量更新）

### 定理 13（保接触变换的可行性不变性）

**陈述**：设 T_g ∈ SE(3) 同时作用于物体与夹爪，接触集 C 与接触法向按 T_g 随动。则力闭合与 GGC 几何可行性在变换下不变：
FC(T_g ⊙ x) = FC(x)，GGC(T_g ⊙ x) = GGC(x)。

**证明**：SE(3) 保距、保角，接触点相对位置与法向夹角不变；力平衡在旋转下协变，摩擦锥随接触坐标系整体旋转，故 Σ f_i = 0 与 f_i ∈ K_μ 同时保持；GGC 的几何谓词只依赖相对几何量，故不变。∎

### 定理 14（增强不扩张执行集）

**陈述**：EFA-v8 的执行集满足 Exec_v8 ⊆ Exec_v7 ⊆ Exec_v6。

**证明**：η_aug ≥ 1 ⇒ Π_aug ≥ 1 ⇒ τ_i^v8 ≥ τ_i^v7，软阈值单调收紧。数据增强只改变提议分布 P_prop 与候选数 K_aug，不改变任何硬门谓词 G_i；任一 x ∈ Exec_v8 必先通过硬门 G_i(x) 与更严阈值，故 x ∈ Exec_v7。∎

### 定理 15（证书声音性 / 无标签泄漏）

**陈述**：D_aug 中每个样本都满足与执行硬门相同的谓词；因此在 D_aug 上训练/检索不会把不可行抓取当作可行正例，提议模型即使过拟合也只能在可行域内偏移。

**证明**：CCA 的 a_cert 复用 v7 硬门实现与版本 v_gate，仅 a_cert=1 入集；版本变化时 D_aug 失效。故 D_aug ⊆ {x | ⋀_i G_i(x)}，训练目标不可能把 ¬G_i 的样本标为正例。∎

### 诚实声明

- 定理 13 只对保接触刚体变换与摩擦锥扰动成立；有界形变（Λ_dist>0）会破坏精确不变性，只能以 Hausdorff 界近似；
- 证书声音性保证「可行」，不保证「任务相关」：合成样本可能可行却无意义，从而偏置提议分布；
- ε-覆盖度是流形覆盖的粗估，可能高估增益，η_aug 需用留出集校准；
- 若 D_aug 规模过大，LMEM 检索会被合成样本淹没（合成-真实比例需设上限 ρ_syn）。

## 5. 实验设计与验证计划（仿真 → 实机）

### 5.1 实验设计（MuJoCo 3.x + MJX）

- **平台**：UR10e（6DOF）+ 移动底盘（2DOF）+ 深度相机；与 v6/v7 同一套硬门实现。
- **数据集**：

  - 增广倍率：×10、×50；合成-真实上限 ρ_syn ∈ {0.3, 0.5, 0.8}；
  - 留出集：200 个未见物体实例用于覆盖度与迁移评估。
- **对照**：v7-full、v8-full、A21（无 GDA）、A22（无 CCA，无约束增强）、A23（关闭形变，仅 SE(3)+摩擦锥）、A24（η_aug 恒为 1）、A25（K_aug 不扩展）。
- **场景**：
  - (a) 覆盖增益：相同真实原型，比较 v7 与 v8 对未见物体的可行抓取覆盖率；
  - (b) 证书拦截：故意注入 10% 不可行增广样本，检验 CCA 全部拦截且 D_aug 不含 ¬G_i；
  - (c) 执行集不膨胀：统计 Exec 集大小，验证 v8 ≤ v7；
  - (d) 合成污染：提高 ρ_syn 至 0.8，观察提议成功率是否先升后降，定位过拟合拐点；
  - (e) 版本漂移：升级 v_gate 后旧 D_aug 是否自动失效。
- **指标**：
  - GGC 覆盖增益、增广样本力闭合有效率、提议成功率、硬门通过率、执行集大小、合成-真实迁移 gap、控制环 P99、证书拦截率/误拦率。

## 7. 本轮最大风险（最终确认）

**一句话**：**增强分布漂移与证书盲区**——证书只保证增广样本落在硬门可行域内（可行性不变），却不保证其与真实任务分布一致；一旦合成几何主导提议模型，系统可能在高覆盖率下悄然过拟合合成伪影，而 fail-closed 边界对此完全无感。
