# 第 41 轮 · 双灵感落地 v8：可证混杂步态 × 步到步收缩代数 × 对照实验证伪引擎（四层架构 v6）

> 承接第 40 轮（v17：可认证流匹配执行 × 度量语义几何锚定 × 证书驱动课程引擎，四层架构 v5）。本轮灵感词「步态规划、对比实验」驱动设计聚焦于**证书体系的两处此前被默认掉的边界**：时间上的**离散接触事件**（混杂系统）与统计上的**可证伪性**（对照实验）。第 40 轮的证书是「连续时间、单次评估」的；本轮把接触瞬间纳入证书的证明链，并把「证书是否成立」升级为预注册、有功效、可随时停止仍有效的对照实验。

## 0. 直觉与动机

**灵感 1（步态规划 → 证书必须在接触瞬间「续命」）**：第 40 轮的收缩证书依赖光滑 ODE：误差按 e^{−κT} 指数衰减。但双足/四足的行走由**离散接触事件**切分：支撑相、摆动相、触地冲击、离地。每次触地，速度发生跳变（重置映射 R），上一模式的收缩成果可能被瞬时放大。步态规划给出的正是这套**离散骨架**——接触时序 σ(τ)、落脚点 F、相位 φ——于是证书可以「分模式成立、跨模式合成」：每个模式内部仍有 κ_m 收缩，跨模式的增益是重置地图的 Lipschitz 常数 L_R。把二者相乘，得到**步到步收缩因子** ρ = ∏ L_{R,i} e^{−κ_i T_i}；ρ<1 才真正等价于「步态周期轨道指数稳定」。这不是给 v17 打补丁，而是把它从「连续流证书」严格提升为「混杂流证书」：能走 ≠ 能证明能走，差距就在接触瞬间。

**灵感 2（对比实验 → 证书必须可被证伪）**：v17 的最大自省是「装饰性证书」。但每一轮都在宣称「延迟降低 2x」「安全提升 50%」，如果没有**预注册的假设、配对设计、多重检验校正、可选停止校正**，研究循环本身会退化为 p-hacking 的放大器。对照实验的科学内核有三条可直接搬进证书体系：a) **配对/共同随机数（CRN）**把同一初始状态、同一随机种子、同一相位的两条轨迹相减，方差骤降、功效上升；b) **anytime-valid e-process** 允许「边跑边看、随时停止」而不膨胀 Type-I 错误；c) **功效分析**给出「要多少样本才能判定」——样本不足的结论应被标为 UNDERPOWERED 并**拒绝进入证书包**。于是「证书」不再是一句声明，而是一个带 α、带样本量、带效应量置信序列的**统计对象**。

**灵感 3（两灵感的耦合 → 步是天然的配对单元）**：步态给对照实验提供了物理上同分布的配对节拍：第 k 步对第 k 步、同相位、同落脚点分布；对照实验给混杂证书提供了**裁决器**：CertHybrid 的每个不等式（ρ<1、guard 覆盖、B_t 覆盖）都变成一条可证伪假设。更进一步，课程引擎（IP-50）的采样准则从「成功率赤字」升级为「**证书不确定性/信息增益**」：把试验预算投向「结论最接近翻转、且样本最不足」的地带，这使研究循环本身具备统计意义上的自我纠错。

## 1. 形式化定义

**定义 27（相位条件混杂流策略）**：步态规划给出三元组 g_gait = (σ, F, φ)，σ(τ) ∈ {0,1}^{n_c} 为接触时序（分段常值），F={p_i} 为落脚点序列，φ ∈ [0,1) 为相位。策略执行定义为分段光滑混杂系统：
- 模式内：dx/dτ = v_θ(x, τ; c, s, g, σ(τ), φ)，x ∈ R^{d_a·H}，模式 m ∈ M 内速度场光滑；
- 守卫/重置：当 x ∈ G_{m→m'}（g_{m,m'}(x)=0 且 ġ>0）时，x⁺ = R_{m→m'}(x⁻)。
动作块经全身控制器投影到接触约束 A_c 的可行流形；相位 φ 与韵律 s 共同决定速度场的调度（「韵律即步态节拍」）。

**定义 28（混杂流证书 CertHybrid）**：CertHybrid = { (CertFlow_m, γ_m, L_{R,m}) }_{m∈M}，其中 CertFlow_m=(L_{v,m}, κ_m, ε_ode,m) 为第 40 轮定义 24 在模式不变集 X_m 上的限制；γ_m 为守卫裕度；L_{R,m} 为重置映射 R_m 在度量 M 下的 Lipschitz 常数（L_{R,m}² = λ_max(DRᵀ M DR / M)）。跨模式收缩 η_m = L_{R,prev}·e^{−κ_m T_m}，周期收缩因子 ρ = ∏_{i=1}^{n_cycle} η_i。
- **定理（步到步收缩与轨道稳定性）**：若每个模式认证成立且 ρ<1，则庞加莱/步到步映射 P 满足 ‖P(x)−P(x*)‖ ≤ ρ‖x−x*‖，周期轨道 x* 存在且指数稳定；第 k 步误差满足 E_k ≤ ρ^k E_0 + ε_hyb/(1−ρ)，其中 ε_hyb = Σ_m ε_ode,m + Σ_i L_{R,i}·v_max·δt_guard + ε_impact，δt_guard 为守卫检测时延，ε_impact 为冲击模型误差。
- **推论（输入-状态稳定）**：存在有界扰动 w（地形、推挤）时，E_k ≤ ρ^k E_0 + (ε_hyb + L_w sup‖w‖)/(1−ρ)。ρ→1 时证书退化，解释「临界步态不可认证」。

**定义 29（证书假设与对照实验）**：一条证书主张是一个可证伪假设 H = (ψ, θ₀, 方向)，ψ 为可测泛函（如 ρ 的实测谱半径、漂移界覆盖、成功率、延迟 p99 比），θ₀ 为门槛。配对单元 i 固定 (x₀ⁱ, 随机种子, σⁱ, φⁱ, 步序 k)，两臂 A/B 为待比配置，配对差 d_i = ψ_i^A − ψ_i^B。采用 anytime-valid e-process：
E_t = ∏_{i≤t} exp(λ_i d_i − λ_i² σ_d²/2)（子高斯情形，λ_i 可预测），
Ville 不等式保证 P_{H₀}(∃t: E_t ≥ 1/α) ≤ α。裁决 verdict ∈ {SUPPORTED, REFUTED, UNDERPOWERED}；所需样本量 n*(Δ, σ_d, α, β) = ((z_{1−α}+z_{1−β})·σ_d/Δ)²，若 n* > 预算则强制 UNDERPOWERED，不得进入 CertBundle。

**定义 30（对照证书代数与信息增益课程）**：ContrastCert = { (H_j, verdict_j, E_j, n_j, α_j, δ_j, CS_j) }，CS_j 为置信序列。族有效性用 e-Bonferroni（E_j ≥ J/α）或 e-BH 控制 FWER/FDR；复合主张（如「v18 优于 v17」）仅在全部子主张同时成立且通过层级校正时 SUPPORTED。课程（升级定义 26）采样改为信息增益驱动：I(τ) = Var(ρ̂|τ)⁻¹ 或期望 e-value 的对数增长率，P(τ) ∝ exp(−(D(τ)−D_center)²/2σ²)·I(τ)^ω·replay_weight(τ)，把预算投向「最接近结论翻转且最欠采样」的任务。

## 2. 三大产出设计

### 2.1 IP-51 GAIT-SCHEDULED-HYBRID-POLICY（步态调度驱动的混杂执行）
1. 步态规划器：相位驱动 + 质心/ALIP 模型预测 + 落脚点优化；ESDF-CBF（IP-49）约束落脚可达与碰撞，输出 (σ, F, φ)。
2. 执行骨干：模式嵌入（支撑/摆动/双支撑）共享流匹配主干，条件扩展为 (c, s, g, σ(τ), φ)；相位与接触时序作为速度场调度变量。
3. 事件一致采样：每个模式独立求 N*_m，守卫事件处显式切换到 R_m；块间重叠窗口跨模式保持连续性（边界一致性损失）。
4. 守卫与冲击：触地采用带恢复系数 e 的冲击模型；守卫裕度 γ_m 与冲击冲量上界写入证书。
5. 重认证触发：相位漂移、守卫裕度不足、冲击超界 → RCA 重颁 → 契约热更新（复用 IP-45/IP-46）。

### 2.2 IP-52 HYBRID-CONTRACTION-CERT（混杂收缩证书代数）
1. 模式内认证：把 IP-48 的 L_v、κ 限制到各模式不变集 X_m，得 CertFlow_m。
2. 重置认证：冲击雅可比 + 谱界给 L_{R,m}；对恢复系数与摩擦不确定性加鲁棒裕度。
3. 步到步合成：计算 ρ = ∏ L_R e^{−κT}，输出步误差界 E_k 与 ISS 增益；ρ≥1 判定不可认证。
4. 组合代数升级（IP-47）：模式内用 κ_comp = min κ_i，跨模式用 L_R,comp = ∏ L_R,i；混杂契约类型检查 C_hyb。
5. 守卫安全：h_guard ≥ γ_g + B_t（含 LIO 漂移球），Farkas/对偶给出冲击时刻的可行控制约束。
6. 降级路径：ρ 认证失败 → 缩短步长/降速的安全步态，或切 IP-38 跌倒恢复。

### 2.3 IP-53 CONTRAST-CERT-ENGINE（对照实验驱动的证书证伪引擎）
1. 主张注册表：每条证书指标预注册为 (ψ, θ₀, 方向, α, 预算)，写入不可篡改日志。
2. 配对实验编排：CRN 同种子、同初始状态、同相位/步序；分层（模式×相位×地形）配对；控制变量（共同随机数、对偶变量）降方差。
3. anytime-valid 推断：e-process/置信序列，支持可选停止与组序贯，报告停止时的有效置信区间。
4. 功效与预算分配：n* 公式 + 序贯膨胀因子；按信息增益把预算分给边缘主张（与 IP-50 联动）。
5. 多重检验：e-Bonferroni / e-BH；层级复合主张；每轮研究循环的「家族」整体 FWER 控制。
6. 裁决闸门：仅 SUPPORTED 且功效充足的指标进入 CertBundle；REFUTED 触发回滚；UNDERPOWERED 显式标注为「未证实」。
7. 自动消融：2^{k} 因子/分式因子设计，配对估计各 IP 的平均处理效应与交互，输出归因证书，防止「多重改进互相冒名」。

## 5. 本轮最大风险

**一句话**：混杂证书的乘积界在接触瞬间最容易「爆炸」——每个模式的 κ 与冲击重置增益只要稍松，认证出的步到步收缩因子 ρ 就可能 ≥1，证书便只能覆盖短步长、低速度的退化步态；届时「可证步态」会退化为「保守到无法行走的空证书」，故必须以 E73（ρ 紧致性）与 E76（功效/Type-I）为本轮第一守门实验。

## 2. 关键算法

### IP-51 步态调度混杂执行（伪代码）
```
def hybrid_rollout(v_theta, c, s, g, eps_tol, budget):
    sigma, F, phi = gait_planner(g, c)       # 质心/ALIP + ESDF-CBF 落脚优化
    mode = sigma(0); x = prior_sample(p0)
    for k in range(n_steps):
        # 模式内：复用 IP-48 闭式步数
        N_m = min N s.t. C_p*(1/N)**p/kappa[mode]*(1-exp(-kappa[mode]*T_m)) <= eps_tol
        x = integrate(v_theta, x, mode, F, phi, N=N_m)
        if guard_crossed(x, mode, gamma[mode]):
            if guard_margin(x, mode) < gamma_min + B_t: return SAFE_ABORT()
            x = reset_map(x, mode, next_mode, e=impact_model)  # 冲击重置
            mode = next_mode
        if finalized(x, overlap=H//2): yield emit(x_tail)
        phi = advance_phase(phi, sigma)
```

### IP-52 混杂证书合成（伪代码）

def certify_hybrid(v_theta, modes, delta=0.01):
    certs = {m: certify_velocity_field_restricted(v_theta, X_m) for m in modes}
    L_R   = {m: reset_lipschitz_bound(impact_jacobian(m), e, mu, delta) for m in modes}
    rho   = 1.0
    for m, T_m in cycle_dwells(modes):
        rho *= L_R[prev(m)] * exp(-certs[m].kappa * T_m)
    eps_hyb = sum(c.eps_ode for c in certs.values()) \
              + sum(L_R[m]*v_max*dt_guard for m in modes) + eps_impact
    if rho >= 1.0:
        return INADMISSIBLE(reason="vacuous_step_contraction", rho=rho)
    return CertHybrid(certs, L_R, rho, eps_hyb, E_k_bound=eps_hyb/(1-rho))

def guard_margin_cert(x_hat, mode, B_t):

### IP-53 对照实验证伪引擎（伪代码）
```
def test_claim(H, budget, alpha=0.05):
    n_star = ((z(1-alpha)+z(1-beta))*sigma_d/Delta)**2   # 先验功效
    if n_star > budget: return UNDERPOWERED(n_star, budget)
    E, CS, t = 1.0, ConfidenceSequence(alpha), 0
    while t < budget:
        x0, seed, sigma_sched, phi = paired_unit(t)       # CRN 配对单元
        d = metric(arm_A(x0,seed,sigma_sched,phi)) - metric(arm_B(x0,seed,sigma_sched,phi))
        lam = predictable_lambda(CS, sigma_d)
        E *= exp(lam*d - lam*lam*sigma_d**2/2)            # anytime-valid e-process
        CS.update(d); t += 1
        if E >= 1/alpha: return SUPPORTED(E, CS, t)       # 可随时停止
    return REFUTED(E, CS, t) if CS.excludes(0) else UNDERPOWERED(n_star, t)

def gate_and_curriculum(claims, alphaj):
    for Hj in claims:
        Hj.verdict = test_claim(Hj, Hj.budget, alphaj)    # e-Bonferroni 权重
    Registry.publish([H for H in claims if H.verdict==SUPPORTED and H.powered])
    band.sample(P ~ exp(-(D-Dc)^2/2sigma^2) * InfoGain(H;tau)^omega * replay_w)
    if any(H.verdict==REFUTED for H in claims): RCA.rollback(H)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 正确性保证 |
|---|---|---|
| 模式内 L_v/κ | 同 IP-48：O(K·Σn_l d_l²) | 上界可证，限制到 X_m 后更紧 |
| 重置 L_R | 每转移一次雅可比谱 O(d³)，模式数有限 | 谱界 + 鲁棒裕度，δ 置信 |
| 步到步合成 | O(|M| + |transitions|) | **定理**：ρ<1 ⟹ 周期轨道指数稳定；E_k≤ρ^kE_0+ε_hyb/(1−ρ) |
| 守卫覆盖 | ESDF 增量 O(Δ体素) | h_guard≥γ_g+B_t ⟹ 真实守卫安全 |
| 相位条件采样 | Σ_m N*_m 次前向，N*_m≤8 | 模式内 ε_ode 有界；边界误差并入 ε_hyb |
| 对照实验 | 每主张 O(n*) 次 rollout；e-process O(1)/样本 | Ville 不等式 ∀t：P_{H0}(∃E_t≥1/α)≤α；e-BH 控 FDR |
| 多重检验/复合 | O(J log J) | 层级 e-Bonferroni 控 FWER；复合仅全子主张成立时支持 |
| 自动消融 | 2^k 或分式因子设计，配对估计 | 平均处理效应无偏（在配对交换性下） |

## 5. 风险与缓解

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 乘积界空洞化：认证 ρ≥1，证书只覆盖退化步态 | 高 | 仅在周期轨道邻域严证；用实测谱半径做紧致性校准；E73 第一守门 |
| 刚性接触/恢复系数失配 → L_R 低估 | 高 | 鲁棒重置界（e, μ 区间）+ 冲量上界 + 20% 工程裕度；硬件验证 |
| 模式切换破坏流匹配连续性、多模态坍缩 | 中 | 模式嵌入 + 边界一致性损失 + 跨模式重叠采样 + 守卫前重规划 |
| CRN/配对在非平稳策略下失效 | 中 | 分块冻结策略，分块随机化；分层模型报告方差缩减 |
| 可选停止/多重比较导致假发现 | 中 | 预注册 + anytime-valid e-process + e-BH；研究循环级家族校正 |
| 步态/规划耦合带来延迟 | 低 | 相位前瞻调度、步态缓存、事件级流式发射 |
| 自动消融组合爆炸 | 低 | 分式因子设计 + 每轮限制 2^k（k≤4） |

## 6. 本轮最大风险

**一句话**：混杂证书的乘积界在接触瞬间最容易失效——模式内 κ 与冲击重置增益的认证偏差会被逐周期相乘，任何「稍松」都可能让 ρ 被认证为 ≥1，从而使证书只能覆盖短步长、低速度的退化步态；因此 E73（ρ 紧致性）与 E76/E77（统计有效性）是本轮不可让渡的守门实验。
