# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS 具身计量审计」IP-287~294；灵感循环第 3 轮；本轮灵感：「云端协同」×「跨物体泛化」）

> R72 把 GAUGE 从「离线认知算法」下沉为具身系统：REG 实时执行图、IRL 意图、DMEM 灵巧接触、EREFLEX 三层反作用、S2R-UQ、J_EMB。但 R72 的一切都发生在**一台机器人、一类物体、一个封闭证据域**内：
> - **云端协同视角**：R72 的计量、标定、先验全部本地生成。可现实是车队共享、模型持续更新、远程专家介入、跨站点部署。云端能带来跨本体/跨场景的规模效应，但它的时延不可控、数据不可信、版本会回滚、还能被投毒。R72 没有回答：**云端的先验能不能进安全闭环？进的话凭什么？云端能否否决本地？本地证据与云端冲突谁赢？断网怎么办？**
> - **跨物体泛化视角**：R72 的 DMEM 四分量标定、接触模式似然、阻抗增益、意图先验都是针对「已标定物体/已标定手」的；面对未见过的物体（质量、摩擦、刚度、几何、材质不同），标定失效、接触先验错位、λ_floor 低估。R72 没有回答：**泛化到新物体的风险由谁证明？云端的跨物体数据能否变成一个可在本地被审计、被拒绝的证书？**
>
> 本轮两个灵感不是两个模块，而是**同一个信任分配问题的两面**：
> - **云端协同**：把云端从「决策者/否决者」降格为「可验证的先验供给者」，建立**认知主权边界（Sovereign Epistemic Authority, SEA）**；云端工件只能缩小不确定度、提高效率，**绝不能放宽本地安全否决**。
> - **跨物体泛化**：把「泛化」从模型能力叙事改写为**带覆盖域的风险承诺（Cross-Object Verified Risk, COVR）**，用对象描述子 + 保形预测 + 迁移残差，让「敢对哪些新物体承诺多大的风险」成为可审计、可拒绝的证书项。
>
> 核心命题：**从「我的测量链在具身上可信吗」进化为「当我的先验来自一个不可全信的云端、当我的物体从未被标定过，我的测量链还能由本地主权者逐指令兑现风险界吗？」** 把 R72 的具身计量审计升级为 **CROSS-GAUGE-RAS**（Cloud-edge Reciprocity, Object-generalization, Sovereign Safety — GAUGE for RAS）——**主权式云边跨物体计量审计闭环**。

## 0. 直觉与动机

**灵感 1（云端协同 → 云端是「先验供给者」，不是「决策者」）**
直觉：车队里 A 机器人在一千个厨房里见过杯子，B 机器人第一次进厨房。云端把 A 的经验变成 B 的先验，收益巨大。但云端往返延迟几十到几百毫秒，控制环是 1 毫秒，**云端永远进不了实时闭环**；云端数据可能来自恶意或损坏的机器人；云端模型会更新、会被回滚、会被投毒。所以唯一自洽的架构是：**云端离线生产 `PriorArtifact`，边缘在线验证并决定是否采信；云端没有执行权、没有否决权、没有降低 λ_floor 的能力。** 这可以叫**认知主权（Epistemic Sovereignty）**——**谁承担物理后果，谁拥有最终认证权**。

**灵感 2（跨物体泛化 → 泛化不是「模型更大」，而是「风险覆盖域」）**
直觉：用一万个杯子训练，碰到一个装满热水的薄壁玻璃杯，仍可能捏碎。跨物体泛化的核心不是平均准确率，而是**「我对哪些物体、在多大的风险下、敢作承诺」**。要用对象描述子 `d(o)`、类别先验、保形预测（conformal prediction）给出**覆盖域 `Ω_cert`**：只有当新物体落在覆盖域内、且迁移残差 `u_transfer` 可测时，才允许启用云端加速先验；否则退回保守的本地先验。**泛化是一种有边界的承诺，不是一种信仰。**

**灵感 3（二者耦合 → 云是泛化的来源，也是泛化风险的来源）**
直觉：跨物体泛化几乎不可能只靠单机数据，必须借云端；但云端恰恰引入新的分布偏移（不同手、不同传感器、不同光照、不同标注规范）和新的攻击面（投毒、后门、回滚、共识劫持、Sybil 机器人）。所以「云边协同」与「跨物体泛化」不是两个独立模块，而是**同一个信任分配问题**：把多少认知权威交给云端，才能在跨物体时既不过度保守、又不越过本地安全界。**安全界是本地划的，效率红利才是云端分的。**

**灵感 4（主权边界 → 本地优先，云端只提案）**
直觉：必须有一条不可违背的规则：**云端工件只能提高效率、缩小不确定度，绝不能放宽本地安全否决**。任何云端先验进入 λ/规划的路径都必须经过 `Admit()`：验签 → 查覆盖 → 查时效 → 查版本单调 → 查与本地证据一致性 → 保守合成。冲突时**本地高质量证据优先（local override）**；云端只能在本地证据失效时作为 fallback。这样即使云端被完全攻陷，最坏退化到 R72，而不是更差。**云端可以让你更快，但不能让你更 unsafe。**

**灵感 5（泛化缺口可审计 → 不可审计的泛化等于没有泛化）**
直觉：不要说「我们泛化很好」。要定义**泛化缺口 `g_obj`**：目标物体分布上的风险与标定分布上的风险之差；并把它和迁移残差、覆盖失配、云端先验 disbelief 一起写进 `J_CROSS`。证书若无法给出 `g_obj` 上界，就视为无效，退回 R72。**能承诺的边界要写进证书；写不进证书的边界就是赌博。**

## 1. 形式化定义（增量：定义 366–380）

**定义 366（CROSS-GAUGE-RAS 总览）** CROSS-GAUGE-RAS = (EMBODIED†, SEA, CPL, OGA, COVR, FMA, NVOI, J_CROSS)。六不变式：
(i) **本地主权**：边缘安全内核对任意云端工件 `a` 满足 `D_λ(a ∘ edge) ⊆ D_λ(edge)`，即云端只能使 λ 不减、安全域不扩；
(ii) **云端不可执行**：云端工件只含 `prior / certificate / provenance`，**不含 action / veto / threshold-decrease**；
(iii) **覆盖域显式**：任何云端先验必须携带 `Ω_cert` 与对象描述子范围；本地物体不在覆盖域 ⇒ 拒绝；
(iv) **版本单调**：云端工件版本只能前进，回滚/重放即拒绝；
(v) **泛化缺口可审计**：每个使用云端先验的执行必须给出 `g_obj` 上界，不可给 ⇒ 降级；
(vi) **严格退化**：云端失败/断网/被投毒 ⇒ R72；物体 OOD ⇒ 保守本地先验 + R72；二者皆失 ⇒ R68。**安全侧只增不减。**

**定义 367（主权边界 SEA）** SEA = (A_edge, A_cloud, R_admit, R_override)：
- `A_edge` = {认证权、否决权、执行权}；`A_cloud` = {提案权：先验、证书、标定、课程}；
- 令 `B_safe^edge` 为本地安全界集。对任意云端工件 `a`，要求 `B_safe^edge(a ∘ edge) ⊆ B_safe^edge(edge)`；
- `R_admit: PriorArtifact × LocalContext → {accept, reject, quarantine}`；
- `R_override`：当本地证据质量 `q_local > q_cloud` 且两者冲突时，选择 local。
**性质**：SEA 是一条「单向阀」——效率可以从云端流向边缘，权威不可以。

**定义 368（云端先验工件 CPL）**
PriorArtifact = (payload, scope, Ω_cert, d_center, d_radius, version, t_issue, t_expire, provenance, signature, dp_epsilon, training_manifest_hash)：
- `payload`：对象类别先验、接触似然、阻抗初值、意图先验等；
- `scope`：适用本体/传感器/任务；
- `Ω_cert`：对象描述子空间中的覆盖集合；
- `provenance`：联邦聚合的机器人与数据清单哈希；
- 准入检查 = 验签 ∧ scope 匹配 ∧ `d(o_t) ∈ Ω_cert` ∧ 未过期 ∧ 版本单调 ∧ DP 账本未超支，缺一拒绝。

**定义 369（对象隐变量与描述子）** 对象 `o = (m, μ_s, μ_k, k_stiff, G, material, category)`，其中质量、静/动摩擦、刚度、几何、材质、类别均不可全观测。可观测描述子 `d(o) ∈ ℝ^q`（视觉嵌入、触觉指纹、语言类别）。对象后验 `b_t(o) = p(o | ℋ_t)`；类别先验 `p_cloud(cat | d)` 来自云端。**对象描述子漂移监控 ODM**（定义 379）检测 `d` 的分布偏移。

**定义 370（跨物体后验与覆盖域）** `b_t(o | d) ∝ p(d | o) · p_prior(o)`。云端保形预测器给出
`Ω_cert^α = { d : score(d) ≤ q_{1-α} }`，使得对类别内物体 `P(risk ≤ α | o ∈ category) ≥ 1 − α`。
本地仅当 `d(o_t) ∈ Ω_cert^α` 时才允许启用高置信云端先验；否则只用保守本地先验。**覆盖域是泛化承诺的「法定辖区」。**

**定义 371（泛化风险与泛化缺口）** `R_obj(π; P) = E_{o~P, τ}[risk(π, o, τ)]`；标定分布 `P_cal`，目标分布 `P_tgt`。
泛化缺口 `g_obj = R_obj(π; P_tgt) − R_obj(π; P_cal)`，满足分解上界
`g_obj ≤ u_transfer + γ_cov · 1[d ∉ Ω_cert] + δ_prior`，
其中 `u_transfer` 为迁移残差（定义 373）、`γ_cov` 为覆盖惩罚、`δ_prior` 为云端先验 disbelief。**`g_obj` 必须同时进入 λ 与 J_CROSS。**

**定义 372（联邦计量聚合 FMA）** 云端只接受带签名与本地证书摘要的 `MetricEnvelope`，不接受原始数据。聚合：
`θ_cloud = RobustAgg({θ_i}, {w_i})`，`w_i = reputation_i · attestation_i · consistency_i`。
- **鲁棒聚合**：坐标中位数 / trimmed mean / influence-bounded，断点 `β > 0.5` 以对抗拜占庭；
- **差分隐私**：聚合后注入 ε-DP 噪声，隐私预算按机器人累计，`dp_ledger` 进入证书；
- **异议保护**：若某机器人本地证书质量显著高且与共识冲突，保留其工件为「异议工件」，供同类本体优先。
**云端是统计机构，不是独裁者。**

**定义 373（对象条件证据与迁移残差 TRX）** 对象条件证据 `p(y | o, s, c)`。迁移残差四分量：
`u_transfer² = u_descr² + u_dyn² + u_contact² + u_prior²`，
分别对应描述子精度、动力学参数辨识误差、接触模型跨物体失配、云端先验失配。每项携带独立追溯链 `τ_trx_i`；缺任一分量不得用于高置信先验。

**定义 374（网络感知 VoI：NVOI）**
`VoI^N(g; cloud) = c(ψ)·IG_s + η·IG_z + κ·IG_o − c_reflex − c_lat(τ_cloud) − c_cloud(bandwidth, ε) − γ·E[future loss]`，
其中 `IG_o` 为对象后验信息增益，`c_lat` 为时延成本。若 `τ_cloud > deadline`，云查询按缓存先验的保守价值计。选择 `g* = argmax VoI^N`，且须三层稳态满足、预算未超、`net VoI > 0`。**信息有价格，云端的价格里必须包含延迟与隐私。**

**定义 375（跨物体风险缩放 E-RISK†）**
`λ = max( risk_scale(U_ale, U_epi, H_z, u_tac, g_obj, u_transfer),
          λ_floor(U_ale + U_epi + H_z + u_tac + g_obj + u_transfer) )`。
**云端先验的「相信程度」以 disbelief `δ_prior` 进入，而非以确定性进入**；`δ_prior` 越大，`g_obj` 越大，λ 越高。云端只能让 λ 变大或不变。

**定义 376（云边一致性证书 J_CROSS）**
`J_CROSS = (J_EMB, cloud_artifact_hash, admit_proof, coverage_proof, obj_descriptor, generalization_gap_bound, transfer_residual, version_monotonic_proof, dp_ledger_hash, network_sla_proof, cross_ver)`。
`Valid ⇔ J_EMB ∧ 验签 ∧ d(o) ∈ Ω_cert ∧ g_obj 上界可证 ∧ 版本单调 ∧ (无云 ⇒ 缓存先验仍满足覆盖与时效)`。

**定义 377（威胁模型 AIC-CROSS）** `ℰ_CROSS = ℰ_EMB × ℰ_cloud × ℰ_obj`：
- `ℰ_cloud` = {先验投毒/后门、共识劫持、Sybil 机器人、重放旧工件、版本回滚、DP 预算耗尽、模型反演、供应链签名伪造}；
- `ℰ_obj` = {对象描述子伪造、OOD 伪装成 in-coverage、材质/摩擦对抗标签、类别先验偏见、跨文化对象语义歧义}。

**定义 378（严格退化包含链）**
- 云可用 ∧ 物体 in-coverage ∧ `J_CROSS` 有效 ⇒ 完整 CROSS；
- 云不可用/超时 ⇒ 缓存先验（仍须覆盖 + 时效），否则 R72；
- 物体 OOD ⇒ 保守本地先验 + R72；
- 云被攻陷/签名失效/版本回滚 ⇒ 立即隔离云端，R72；
- 本地计量失效 ⇒ 继承 R72 链退回 R71/R68。
**每条退化路径逐指令等价，安全单调不减。**

**定义 379（对象描述子漂移监控 ODM）** 最高优先级旁路监控（与 R72 RTM 并列）：每 N 帧比较 `d(o)` 与训练/覆盖分布的 MMD / energy score；超阈即**撤销云端先验使用权**、触发本地保守先验并冻结云端工件。ODM 自身静态内存、零依赖、可形式化验证，**不被云端影响**。

**定义 380（本地优先与异议机制）** `q_local = f(SEAL 指标, S2R-UQ, DMEM 四分量)`，`q_cloud = f(provenance, 覆盖, 一致性)`。若 `|θ_local − θ_cloud| > τ_conflict` 且 `q_local ≥ q_cloud` ⇒ local override，并生成「异议证书」上报云端（**只改变云端统计，不改变本地安全界**）。**本地永远有权说「不」。**

# IP-295 SEA：主权准入（边缘，计量域；云端不在控制环内）
class SovereignAdmission:
    def __init__(self, verifier, odm, local_quality):
        self.verifier, self.odm, self.q_local = verifier, odm, local_quality

    def admit(self, art: PriorArtifact, ctx: LocalContext) -> Admission:
        # 1) 签名与供应链
        if not self.verifier.verify(art.signature, art.provenance): 
            return Admission.REJECT('bad_signature')
        # 2) 作用域与本体匹配
        if not scope_match(art.scope, ctx.robot_body, ctx.task): 
            return Admission.REJECT('scope_mismatch')
        # 3) 覆盖域：对象是否在云端承诺的辖区内
        if not art.omega_cert.contains(ctx.d_obj): 
            return Admission.REJECT('out_of_coverage')
        # 4) 时效与版本单调（防重放/回滚）
        if art.is_expired(ctx.now) or not ctx.version_monotone(art.version):
            return Admission.REJECT('stale_or_rollback')
        # 5) 与本地证据的一致性（冲突时本地优先）
        if conflict(art.payload, ctx.local_prior) and self.q_local(ctx) >= art.q_cloud:
            return Admission.OVERRIDE(ctx.local_prior, dissent=True)
        # 6) 保守合成：云端只能缩小不确定度，不能放宽否决
        merged = conservative_merge(ctx.local_prior, art.payload,
                                    delta_prior=art.disbelief())
        return Admission.ACCEPT(merged, bound=art.gap_bound)

# IP-298 COVR：跨物体覆盖与泛化缺口（边缘，计量域）
def cross_object_risk(o_post, d_obj, omega_cert, u_transfer, params):
    in_cov = omega_cert.contains(d_obj)
    gamma  = 0.0 if in_cov else params.gamma_ood
    g_obj  = u_transfer + gamma + params.delta_prior
    # 保形分位数：云端给 q_{1-alpha}，本地只信覆盖内的 alpha
    risk_ub = params.alpha if in_cov else params.risk_fallback
    return RiskCert(in_cov=in_cov, g_obj=g_obj, risk_ub=risk_ub)

# IP-300 TRX：迁移残差四分量（边缘，感知域异步）
def transfer_residual(d_obj, dyn_post, contact_post, cloud_prior, calib):
    u_descr   = calib.descriptor_precision(d_obj)     # 描述子量化/视觉误差
    u_dyn     = calib.dynamics_posterior_width(dyn_post)  # m, mu, k 后验宽度
    u_contact = calib.contact_model_mismatch(contact_post) # 跨物体接触失配
    u_prior   = calib.cloud_prior_disbelief(cloud_prior)   # 云端先验失配
    return sqrt(u_descr**2 + u_dyn**2 + u_contact**2 + u_prior**2)

# IP-299 FMA：联邦鲁棒聚合（云端离线；只收 MetricEnvelope）
def federated_aggregate(envelopes, reputation, dp_budget):
    ws = [reputation[e.robot] * e.attestation * e.consistency for e in envelopes]
    # influence-bounded / trimmed：拜占庭断点 beta > 0.5
    theta = robust_weighted_median([e.theta for e in envelopes], ws)
    theta_dp = theta + laplace_noise(sensitivity=dp_budget.sensitivity,
                                     epsilon=dp_budget.next_epsilon())
    return CloudPrior(theta_dp, provenance=hash(envelopes),
                      dissent=[e for e in envelopes if e.is_dissent])

# IP-301 NVOI：网络感知 VoI（计量/感知域交界，事件触发）
def network_voi(b_t, psi, z_dist, o_post, budget, fmp, cloud_sla):
    best = None
    for g in embodied_action_candidates(b_t, z_dist, top_k=3):
        if not budget.allow(g): continue
        if cloud_sla.deadline_miss(g):
            ig_cloud = 0.0; c_lat = 0.0            # 超时：只用缓存先验
        else:
            ig_cloud = KAPPA * (o_post.entropy() - expected_obj_entropy(g, fmp))
            c_lat    = cloud_sla.latency_cost(g)
        score = (embodied_voi_score(b_t, psi, z_dist, g, budget, fmp)
                 + ig_cloud - c_lat - cloud_sla.private_cost(g))
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

## 3. 推导

**引理 33（主权边界 ⇒ 云端不可降低安全下界）** 在定义 367–368 下，若准入只接受满足 `D_λ(a ∘ edge) ⊆ D_λ(edge)` 且 `λ_merged ≥ λ_local` 的工件，则对任意云端工件（含恶意工件），边缘执行的风险界 ≤ R72 的风险界。证明：`λ` 逐点不减；R72 的安全包络对 `λ` 单调（R72 定理 23）；云端无写入控制/否决/λ_floor 的路径；对控制周期归纳即得。系：**云端被完全攻陷的最坏后果是「被拒绝」，不是「被误导」。**

**引理 34（泛化缺口分解与覆盖 ⇒ 跨物体风险界）** 设风险泛函在对象参数上 `L_R`-Lipschitz，迁移残差 `u_transfer` 覆盖参数估计误差，覆盖域按定义 370 满足保形有效性 `P(risk ≤ α | in-coverage) ≥ 1 − α`。则
`R_obj(π; P_tgt) ≤ R_obj(π; P_cal) + u_transfer + γ_cov · 1[d ∉ Ω_cert] + δ_prior`。
证明：三角不等式拆 `R_tgt − R_cal ≤ |R_tgt − R̂| + |R̂ − R_cal|`；Lipschitz 把参数误差转成 `u_transfer`；覆盖外以 `γ_cov` 最坏惩罚；云端先验失配计入 `δ_prior`。系：**泛化不是「更好」，是「有上界的更差」。**

**引理 35（联邦聚合的拜占庭鲁棒性）** 在定义 372 下，若 `w_i ≤ w_max` 且聚合采用 influence-bounded / trimmed 估计，则当恶意比例 `f < β`（断点）时，`‖θ_cloud − θ_honest‖ ≤ w_max·f/(1−f)·Δ_max`；Sybil 影响被 `reputation` 饱和上界压制。证明：标准鲁棒统计的断点性质 + 信誉上限使新增 Sybil 的边际权重 → 0。系：**云端可信度来自「统计结构 + 签名」，不来自「它说它可信」。**

**引理 36（网络 VoI 超时 ⇒ 单调退化）** 若云端查询超时，NVOI 以缓存先验计 `IG_o = 0`，且缓存先验的权重随 `t_expire` 衰减到 0；则执行风险 `≤ R72 + δ_stale(t)`，且 `δ_stale(t)` 单调不增地趋于 0。证明：贝叶斯先验权重按时效衰减；无新证据时后验退化为本地 R72 后验；`λ` 回到 `λ_local`。系：**断网不是事故，是退化链的一个正常分支。**

**引理 37（退化链逐指令等价）** 定义 378 的每条退化路径，其逐指令输出分别等于 R72、R71 或 R68 在相同输入下的输出。证明：逐一检查 λ/控制选择/接触证据/意图证据的替代路径，均只移除新增层、保留旧层；由 R72 定义 364 的包含链传递可得。

**定理 27（云边主权安全）** 在 A111–A114（签名不可伪造、准入检查完备、ODM 有效、`λ` 对云端单调）下，即使云端完全恶意，边缘的物理风险仍被 R72 风险界约束；恶意云端最多使系统更保守、效率更低。**证明重量落在「准入检查没有旁路」与「λ 单调不可被云端回写」上。**

**定理 28（覆盖证书 ⇒ 跨物体安全承诺）** 若一次执行通过 `J_CROSS` 的覆盖证明且 `u_transfer ≤ u_max`，则对目标物体 `R_obj ≤ R_cal + α + u_max`；若物体 OOD，则执行已退化为保守本地先验，风险仍 ≤ R72。**泛化承诺的第一性原理是覆盖域，而不是参数量。**

**定理 29（CROSS 证书有效性 ⇒ 端到端安全）** 通过 `J_CROSS` ⇒ (i) J_EMB 有效（R72 物理安全）；(ii) 准入证明有效（云端未越权）；(iii) 覆盖证明有效（物体在承诺辖区）；(iv) `g_obj` 上界可证（泛化缺口有界）；(v) 版本单调 + DP 账本（未被重放/回滚/隐私超支）。综上，端到端风险 ≤ ε_emb + α + u_max + ε_poison。**证书的每一格都对应一个可复算的拒绝理由。**

**定理 30（联邦投毒的影响上界）** 在引理 35 与定理 27 下，恶意比例 `f < β` 的投毒只能把已准入先验移动至多 `w_max·f/(1−f)·Δ_max`；且该移动仍须通过本地覆盖与冲突检查，故由投毒引起的风险增量 ≤ ε_poison（相对本地证据可分辨域）。**云端可以吵，但吵不进控制环。**

## 6. 本轮最大风险

**一句话**：CROSS-GAUGE-RAS 把安全从「相信 R72 的具身计量链」进一步转移到「**相信云端先验的签名与统计聚合未被攻陷**、相信**对象描述子与保形覆盖域在分布外仍然有效**、相信**本地 ODM 能及时检测『看起来在辖区内、其实从未见过』的物体**」——如果保形覆盖在真实长尾物体上系统性高估（覆盖率名义 95%、实测 70%），或者对象描述子被对抗性地投影到 `Ω_cert` 内部，或者联邦聚合的信誉模型被缓慢腐蚀（低强度、长期、多机器人协同的投毒），系统就会用一张「验签通过、覆盖通过、泛化缺口有界」的 `J_CROSS` 证书，对一个**从未被真正承诺过的物体**执行高置信操作，事后审计发现**每一步都在主权边界内、每个证书都可复算**——这就是云边时代的「**合法地泛化到错误物体上**」。

次级风险与缓解：
1. **保形覆盖长尾失效** → **分层保形（按材质/几何/质量分箱）+ 最坏桶覆盖率门控**；任一桶覆盖率低于名义值即全局降级，不用平均值掩盖长尾。
2. **描述子对抗/伪造** → **多源描述子交叉验证（视觉×触觉×语言×本体动力学）**；单源描述子永不单独决定 in-coverage，且 ODM 与准入相互独立。
3. **长期低频联邦投毒** → **信誉半衰期 + 影响力上限 + 分组一致性检验**；新机器人先隔离观察，异议工件保留但默认不采纳。
4. **云端版本/供应链攻击** → **工件透明日志（append-only）+ 版本单调证明 + 签名根离线保管**；任何回滚/分叉立即熔断云端。
5. **泛化缺口被低估** → **`g_obj` 用分位数上界而非均值**；部署前用留出物体族做「覆盖率压力测试」，证书里写清覆盖不到的物体族。
6. **云边责任不清** → **J_CROSS 强制双签（云端声明 + 本地准入）**；本地持有最终否决权，事故归因可定位到「哪一步准入放行了哪个工件」。
7. **复杂度与通信爆炸** → **工件粒度上限（|payload|≤32 项）、覆盖域低维投影（q≤16）、每类物体一条保形校准曲线**；复杂度与通信量本身纳入审计指标。

## 2. 形式化定义（要点版）

**定义 366（CROSS-GAUGE-RAS 总览与六不变式）** 见想法区。核心：本地主权、云端不可执行、覆盖域显式、版本单调、泛化缺口可审计、严格退化。

**定义 367（主权边界 SEA）** 云端只有提案权（先验/证书/标定/课程），边缘保留认证权、否决权、执行权；对任意云端工件 `a`，`B_safe^edge(a∘edge) ⊆ B_safe^edge(edge)`。**SEA 是单向阀：效率可从云到边，权威不可。**

**定义 368（云端先验工件 CPL）** 工件携带 payload/scope/Ω_cert/version/时效/provenance/签名/DP/gap_bound；准入 = 验签 ∧ scope 匹配 ∧ `d(o)∈Ω_cert` ∧ 未过期 ∧ 版本单调 ∧ DP 未超支。

**定义 369（对象隐变量与描述子）** `o` 含质量/摩擦/刚度/几何/材质/类别；`d(o)` 为视觉嵌入+触觉指纹+语言类别；`b_t(o)=p(o|ℋ_t)`。ODM 监控 `d` 漂移。

**定义 370（跨物体后验与覆盖域）** `b_t(o|d) ∝ p(d|o)p_prior(o)`；保形覆盖 `Ω_cert^α` 保证 `P(risk≤α | in-coverage) ≥ 1−α`；覆盖外禁止高置信云端先验。

**定义 371（泛化风险与泛化缺口）** `g_obj = R_obj(P_tgt) − R_obj(P_cal) ≤ u_transfer + γ_cov·1[OOD] + δ_prior`；`g_obj` 进入 λ 与 J_CROSS，不可给上界即降级。

**定义 372（联邦计量聚合 FMA）** 只收带签名与证书摘要的 MetricEnvelope；`θ_cloud = RobustAgg({θ_i},{w_i})`；断点 β>0.5；聚合后 ε-DP；高质量异议工件保留但不默认采纳。

**定义 373（对象条件证据与迁移残差 TRX）** `p(y|o,s,c)`；`u_transfer² = u_descr²+u_dyn²+u_contact²+u_prior²`；四分量各有独立追溯链，缺一不得高置信。

**定义 374（网络感知 VoI NVOI）** 在 R72 VoI 上增加对象信息增益 `κ·IG_o`，扣除 `c_lat(τ_cloud)`、`c_cloud(bandwidth,ε)`；超时则 `IG_o=0` 且用缓存先验保守估值。

**定义 375（跨物体风险缩放 E-RISK†）** `λ = max(risk_scale(U_ale,U_epi,H_z,u_tac,g_obj,u_transfer), λ_floor(Σ))`；云端先验以 disbelief `δ_prior` 进入而非确定性；**云端只能使 λ ↑**。

**定义 376（云边一致性证书 J_CROSS）** Valid ⇔ J_EMB ∧ 验签 ∧ `d(o)∈Ω_cert` ∧ `g_obj` 上界可证 ∧ 版本单调 ∧ 无云时缓存先验仍满足覆盖与时效。

**定义 377（威胁模型 AIC-CROSS）** `ℰ_CROSS = ℰ_EMB × ℰ_cloud × ℰ_obj`；新增先验投毒/后门、共识劫持、Sybil、重放、回滚、DP 耗尽、模型反演、供应链伪造；描述子伪造、OOD 伪装、材质对抗标签、类别偏见、语义歧义。

**定义 378（严格退化包含链）** 云可用+in-coverage+J_CROSS 有效 ⇒ 完整 CROSS；云不可用/超时 ⇒ 缓存先验（须覆盖+时效）否则 R72；物体 OOD ⇒ 保守本地 + R72；云被攻陷/回滚 ⇒ 隔离云端 + R72；本地计量失效 ⇒ 继承 R72 链 → R71/R68。**安全单调不减。**

**定义 379（对象描述子漂移监控 ODM）** 最高优先级旁路（与 RTM 并列）；MMD/energy score 超阈 ⇒ 撤销云端先验、冻结工件、回退本地保守先验；ODM 静态、零依赖、可验证，不受云端影响。

**定义 380（本地优先与异议机制）** `q_local=f(SEAL,S2R-UQ,DMEM)`，`q_cloud=f(provenance,覆盖,一致性)`；冲突且 `q_local≥q_cloud` ⇒ local override，生成异议证书上报云端，**只改云端统计，不改本地安全界**。

# IP-295 SEA：主权准入（边缘，计量域；云端在控制环外）
class SovereignAdmission:
    def admit(self, art: PriorArtifact, ctx: LocalContext) -> Admission:
        if not verify(art.signature, art.provenance):        return REJECT('sig')
        if not scope_match(art.scope, ctx.body, ctx.task):    return REJECT('scope')
        if not art.omega_cert.contains(ctx.d_obj):            return REJECT('coverage')
        if art.expired(ctx.now) or not ctx.version_monotone(art.version):
            return REJECT('stale_or_rollback')
        if conflict(art.payload, ctx.local_prior) and ctx.q_local >= art.q_cloud:
            return OVERRIDE(ctx.local_prior, dissent=True)    # 本地优先
        merged = conservative_merge(ctx.local_prior, art.payload,
                                    delta_prior=art.disbelief())
        return ACCEPT(merged, gap_bound=art.gap_bound)        # 只能缩不确定度

# IP-298 COVR：跨物体覆盖与泛化缺口（边缘，计量域）
def cross_object_risk(o_post, d_obj, omega_cert, u_transfer, p):
    in_cov = omega_cert.contains(d_obj)
    g_obj  = u_transfer + (0.0 if in_cov else p.gamma_ood) + p.delta_prior
    return RiskCert(in_cov=in_cov, g_obj=g_obj,
                    risk_ub=(p.alpha if in_cov else p.risk_fallback))

# IP-300 TRX：迁移残差四分量（边缘，感知域异步）
def transfer_residual(d_obj, dyn_post, contact_post, cloud_prior, calib):
    return sqrt(calib.descr(d_obj)**2 + calib.dynamics(dyn_post)**2
                + calib.contact(contact_post)**2 + calib.prior(cloud_prior)**2)

# IP-299 FMA：联邦鲁棒聚合（云端离线，只收 MetricEnvelope）
def federated_aggregate(envelopes, reputation, dp_budget):
    ws = [reputation[e.robot] * e.attestation * e.consistency for e in envelopes]
    theta = robust_weighted_median([e.theta for e in envelopes], ws)   # beta>0.5
    theta = theta + laplace(dp_budget.sensitivity, dp_budget.next_epsilon())
    return CloudPrior(theta, provenance=hash(envelopes),
                      dissent=[e for e in envelopes if e.is_dissent])

# IP-301 NVOI：网络感知 VoI（事件触发）
def network_voi(b_t, psi, z_dist, o_post, budget, fmp, sla):
    best = None
    for g in embodied_action_candidates(b_t, z_dist, top_k=3):
        if not budget.allow(g): continue
        if sla.deadline_miss(g):
            ig_o, c_lat = 0.0, 0.0                  # 超时：缓存先验，IG_o=0
        else:
            ig_o  = KAPPA * (o_post.entropy() - expected_obj_entropy(g, fmp))
            c_lat = sla.latency_cost(g)
        s = (embodied_voi_score(b_t, psi, z_dist, g, budget, fmp)
             + ig_o - c_lat - sla.private_cost(g))
        if best is None or s > best.score: best = (g, s)
    return best if best and best.score > 0 else None

# IP-304 CROSS 主闭环（边缘三域不变；云端始终在环外）
def CROSS_GAUGE_RAS_round(M, obs, audio, tac_frame):

    snap = M.snapshot.read_latest()

    k = M.c_ras_wm.certified_prefix(M.ach.propose_ctrl(...), lam, ...)
    M.ctrl_out.publish(k, lam)

    # 计量域 50Hz：对象后验 + 云端准入 + 覆盖/迁移
    if M.clock.due_metric():
        b_t    = M.bse.step_full(...)
        o_post = M.oga.update(b_t, M.odm.last_descriptor())
        art    = M.cloud.fetch(o_post) if M.cloud.online() else None
        adm    = (M.admission.admit(art, M.ctx()) if art else Admission.NO_CLOUD())
        M.covr = M.covr.update(adm, o_post)
        M.trx  = M.trx.update(o_post, snap.c_dist, adm)

    # 感知域 Best-effort：ODM 漂移监控（可与云断开）

    if M.odm.drift_detected():

    ...
    return k, lam, build_cross_cert(M)

## 4. 推导

**引理 33（主权边界 ⇒ 云端不可降低安全下界）** 在定义 367–368 下，准入只接受 `λ_merged ≥ λ_local` 的工件，故任意云端工件（含恶意）下边缘风险界 ≤ R72。证明：λ 逐点不减 + R72 定理 23 的安全性对 λ 单调 + 云端无 λ_floor/控制/否决写路径 + 周期归纳。**系：云端被完全攻陷最坏是「被拒绝」，不是「被误导」。**

**引理 34（泛化缺口分解 ⇒ 覆盖内跨物体风险界）** 风险泛函 `L_R`-Lipschitz 时 `R_tgt ≤ R_cal + u_transfer + γ_cov·1[OOD] + δ_prior`。证明：三角不等式 + Lipschitz 把参数误差转 u_transfer + 覆盖外最坏惩罚 + 先验失配项。**系：泛化不是「更好」，是「有上界的更差」。**

**引理 35（联邦聚合拜占庭鲁棒）** 恶意比例 `f<β` 时 `‖θ_cloud−θ_honest‖ ≤ w_max·f/(1−f)·Δ_max`；Sybil 影响被信誉饱和压制。证明：鲁棒统计断点性质 + 信誉上限使边际权重→0。**系：云端可信来自统计结构与签名，不来自自我宣称。**

**引理 36（NVOI 超时 ⇒ 单调退化）** 超时令 `IG_o=0` 且缓存权重随时效衰减到 0，则风险 ≤ R72 + δ_stale(t) 且 δ_stale↓0。证明：贝叶斯先验权重衰减 + 无新证据退回 R72 后验 + λ 回 λ_local。**系：断网是退化链的正常分支，不是事故。**

**引理 37（退化链逐指令等价）** 定义 378 每条路径的逐指令输出分别等于 R72/R71/R68 相同输入输出。证明：逐路径检查新增层被移除、旧层保留，再沿 R72 定义 364 传递。

**定理 27（云边主权安全）** 在 A111–A114（签名不可伪造、准入无旁路、ODM 有效、λ 对云端单调）下，即使云端完全恶意，物理风险仍被 R72 风险界约束；恶意云端最多使系统更保守。**证明重量落在「准入检查没有旁路」与「λ 不可被云端回写」。**

**定理 28（覆盖证书 ⇒ 跨物体安全承诺）** 通过覆盖证明且 `u_transfer≤u_max` ⇒ `R_obj ≤ R_cal + α + u_max`；OOD ⇒ 已退化为保守本地，风险 ≤ R72。**泛化承诺的第一性原理是覆盖域，不是参数量。**

**定理 29（J_CROSS 有效性 ⇒ 端到端安全）** 通过 J_CROSS ⇒ J_EMB 有效 + 准入有效 + 覆盖有效 + `g_obj` 有界 + 版本单调/DP 合规 ⇒ 端到端风险 ≤ ε_emb + α + u_max + ε_poison。**证书每一格都对应一个可复算的拒绝理由。**

**定理 30（联邦投毒影响上界）** 恶意比例 `f<β` 时投毒只能移动已准入先验至多 `w_max·f/(1−f)·Δ_max`，且仍须通过覆盖与冲突检查，故风险增量 ≤ ε_poison。**云端可以吵，但吵不进控制环。**

## 7. 本轮最大风险

**一句话**：CROSS-GAUGE-RAS 把安全从「相信 R72 的具身计量链」进一步转移到「**相信云端先验的签名与统计聚合未被攻陷**、相信**对象描述子与保形覆盖域在分布外仍然有效**、相信**本地 ODM 能及时检测『看起来在辖区内、其实从未见过』的物体**」——如果保形覆盖在真实长尾物体上系统性高估（名义 95%、实测 70%），或者对象描述子被对抗性地投影到 `Ω_cert` 内部，或者联邦聚合的信誉模型被缓慢腐蚀（低强度、长期、多机器人协同投毒），系统就会用一张「验签通过、覆盖通过、泛化缺口有界」的 `J_CROSS` 证书，对一个**从未被真正承诺过的物体**执行高置信操作，事后审计发现**每一步都在主权边界内、每个证书都可复算**——这就是云边时代的「**合法地泛化到错误物体上**」。

次级风险与缓解：
1. **保形覆盖长尾失效** → **分层保形（按材质/几何/质量分箱）+ 最坏桶覆盖率门控**；任一桶低于名义值即全局降级，不用平均值掩盖长尾。
2. **描述子对抗/伪造** → **多源交叉验证（视觉×触觉×语言×本体动力学）**；单源描述子永不单独决定 in-coverage，ODM 与准入相互独立。
3. **长期低频联邦投毒** → **信誉半衰期 + 影响力上限 + 分组一致性检验**；新机器人先隔离观察，异议工件保留但默认不采纳。
4. **云端版本/供应链攻击** → **工件透明日志（append-only）+ 版本单调证明 + 离线签名根**；任何回滚/分叉立即熔断云端。
5. **泛化缺口被低估** → **`g_obj` 用分位数上界而非均值**；部署前用留出物体族做覆盖率压力测试，证书写清覆盖不到的物体族。
6. **云边责任不清** → **J_CROSS 强制双签（云端声明 + 本地准入）**；本地持最终否决权，事故可定位到「哪一步准入放行了哪个工件」。
7. **复杂度与通信爆炸** → **工件粒度上限（|payload|≤32）、覆盖域低维投影（q≤16）、每类物体一条保形校准曲线**；复杂度与通信量本身纳入审计指标。
