# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「长期记忆」×「嵌入式系统」）

> R69 让系统学会了「问」：把 aleatoric 与 epistemic 拆开，用流匹配多模态策略 + 主动多模态交互（看/问/触）消解可约歧义，并用流似然做标定不可吸收的第二意见。但 R69 的记忆是**金鱼式的**：所有花交互代价换来的消解、所有失败过的假设、所有校准好的模态权重，都在一个 episode 结束时被丢弃。下一小时回到同一个岔口、同一个用户、同一种光照，它会把同一个问题**再问一遍**；更糟的是，它会把这次艰难学到的正确先验彻底忘掉，然后在同一个地方犯同样的错。
>
> 本轮两个灵感各补一刀：
> - **长期记忆**说：不确定性不只在「这一次的动作分布」里，也在「**我上一次是怎么解决的、凭什么、现在还作不作数**」里。记忆把一次性的 epistemic 消解变成可复用的先验，也把一次性的错误变成**长期偏置**。记忆不是事实库，而是「会过期的信念 + 出处 + 删除义务」。
> - **嵌入式系统**说：记忆不是免费的日志。写入要耗电、要占 WCET、会磨损 flash、会在掉电时写坏；删除同样有成本，而且**擦除往往比写入更难**。在几百 KB 内存、有限擦写寿命、可能随时断电的板子上，「记住」是一个**不可逆的物理承诺**，不是一次数据库 insert。
>
> 核心命题：**把 R69 的瞬时 epistemic 消解升级为「可摊销的记忆痕迹」；记忆写入是与任务动作、信息动作并列的第三类动作，必须按摊销 VoI 定价、按 WCET/能量/磨损/隐私认证、按跨 episode 证据纪律防投毒、并支持可验证遗忘；当记忆预算为零、磨损耗尽、校准 canary 失败或检出投毒时，系统逐指令退化为 R69。** 命名 **ENGRAM-RAS**（Embedded Non-parametric Grounded Retrieval-Augmented Memory for Risk-Adaptive Systems）——engram 是记忆痕迹：它既是学习，也是承诺，也是负债。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这一次问出来的答案，值不值得我写进再也擦不掉的记忆里；以及我凭什么相信昨天的自己**」——不确定性不只是一脚刹车或一句提问，也可以是一页会磨损、会过期、会被要求删除的痕迹。

## 0. 直觉与动机

**灵感 1（长期记忆 → 不确定性有半衰期，也有复用率）**
直觉：R69 的 VoI 是**短视的**——它只问「这次多看/多问/多触值不值」，问完就把信息扔了。但现实里同样的歧义分两类：**一次性歧义**（这次地上有个反光，下次不再出现）与**复发性歧义**（这位用户说「可以」时总带着犹豫、这个货架的标签总被灯光洗白）。对前者，记忆是负担；对后者，不记忆意味着**永远重复付交互成本**，也就是交互疲劳。长期记忆的第一性原理不是「存得越多越好」，而是：**只为「会复用、且复用时能省下更大代价」的消解付写入代价**。这把 R69 的单步 VoI 升级为**摊销 VoI（amortized VoI）**：写入是否值得，取决于未来复用概率、复用收益与写入/擦除/隐私成本三者的长期积分。

**灵感 2（嵌入式 → 记忆写入是不可逆动作，不是实现细节）**
直觉：服务器上「记一条」是免费的 append；板子上不是。一次 flash 写入要几十微秒到毫秒、要消耗焦耳、要占用总线并可能阻塞控制回路；一次擦除更慢、更耗电，而且每个块只有约 10^4–10^5 次寿命。更麻烦的是掉电：正好在写元数据时断电，恢复后可能得到「有标签、没来源」的半条记忆——这比忘记更危险，因为系统会**记得错且理直气壮**。因此本轮的第二个翻转是：**把 memory write / verify / merge / delete / compact 都视为动作**，与 R69 的 `a`、`g` 一起进入增广动作空间，用同一套认证与预算框架管理；实时控制回路里只允许**有界读**，写入只发生在可调度、可中断、可恢复的 consolidation 窗口。

**灵感 3（三难：持久性 × 可删性 × 可负担性）**
直觉：长期记忆想同时要三样东西——(a) **持久**（跨 episode、跨天、跨年）；(b) **可删**（用户要求忘记、隐私法规、错误信念撤回）；(c) **可负担**（小内存、低能耗、有限磨损）。这三者在嵌入式上不可能同时最优：更持久 → 更多写入与复制 → 更磨损；更可删 → 更多索引/墓碑/密钥管理 → 更多元数据与写放大；更可负担 → 更强压缩/量化 → 置信被扭曲。于是必须有一条显式的**记忆守恒律**：压缩只能换内存、不能换置信；删除必须留可验证证据；任何「省下来的字节/焦耳」都要以更大的保守性或更短的租约偿还。记忆预算因此是一等约束，不是调参。

**灵感 4（跨 episode 校准 → 治 R69 最大的病，也可能把它焊死）**
直觉：R69 自陈的最大风险是「流模型的模态权重未校准，系统会自信地追问一个幻影」。长期记忆恰好是解药：跨 episode 累积的**已独立验证**的消解，可以反过来校准 mode_head，让 R69 的 ECE 随时间下降。但同一机制也是毒药：一条错误或投毒的记忆会进入未来所有相关决策的先验，而「记忆自己的历史写入」又会被下一轮当成证据，形成**跨 episode 的回音室**——置信度单调上涨，真实错误率不动，且因为写在 flash 上，**擦不掉、改不动、会被备份**。所以 CBC 校准必须带三件套：held-out canary（不被优化的独立福利测量）、跨 episode 来源防火墙（排除自证）、可回滚/可隔离（canary 变差或检出投毒就退回 R69 并隔离贡献条目）。这条与 R69 引理 18 同构，但时间维度把「问错一次」升级为「信错一生」。

**灵感 5（严格包含 → 记忆只能做先验的加法，不能动安全包络）**
直觉：新层必须是旧层的严格泛化，否则每加一层就多一个需要独立信任的黑箱。ENGRAM 的记忆只允许做一件很窄的事：在 R69 的模态后验上施加**有界的对数几率平移**（`log w' = log w + β·s(m)`，`β ∈ [0, β_max]`），且必须使用膨胀后的后验参与 C-RAS-WM 认证；它不能提高动作幅度、不能绕过前缀认证、不能改变安全包络。读不到、读晚了、读冲突、磨损耗尽、canary 失败、检出投毒——任一情况都**单调退回** R69。于是「零记忆」就是 R69 的边界，「零交互」再退 R68；安全侧只增约束，不放松。

## 1. 形式化定义（增量：定义 310–323）

**定义 310（ENGRAM-RAS 总览与三不变式）** ENGRAM-RAS = (EMT, HRL, AVC, CPG, WAL/WL, FUG, CBC, MAA, FLUID†, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）：控制回路只做有界记忆读，不训练、不写 flash；
(ii) **有界状态**：常驻记忆 ≤ M_max、累计擦写 ≤ W_max、检索 WCET ≤ T_R、单次 consolidation WCET ≤ T_C 且能量 ≤ E_C；任一超界必须在**当前窗口**降级，禁止「偶尔超时」；
(iii) **记忆证据纪律**：单条记忆、以及记忆自身的历史写入，都不得单独为一个高风险决策定案；高风险条目需 κ_eff ≥ 2 个跨 episode 独立来源，否则只能作为似然、不能作为判决。

**定义 311（认知记忆痕迹 EMT）** 一条记忆痕迹
m = (q, ℓ, P, c, t_w, t_v, ζ, π_priv, n_ver, u)
其中 q 为上下文键（粗离散化嵌入 / 场景-用户-任务三元组），ℓ ∈ Δ(ℳ) 为模态身份或已消解标签的后验，P 为来源 DAG（含「地图/记忆自身历史」节点），c 为校准记录（ECE 分箱、覆盖率），t_w 写入时刻，t_v 最近一次独立验证时刻，ζ 为租约（过期即衰减），π_priv 为隐私级别，n_ver 为独立验证次数，u 为擦除状态/不可用标记。**读出返回 (ℓ̃, c, ζ, u) 的四元组，而不是一个标签**；记忆是带年龄、出处与删除义务的信念，不是事实。

**定义 312（有界分层检索 HRL）** 热存储 H（SRAM，容量 M_H，易失，哈希/LSH，O(1)）与冷存储 C（flash，容量 M_C，磨损受限）。检索 `Ret(q)` 在 H ∪ C 上做**有界扇出 B、有界深度 d** 的近似最近邻，保证 WCET ≤ T_R = O(Bd)。冷存储用日志结构合并（LSM）并做磨损均衡。**保守失配**：最近邻距离 > δ_ctx 视为 miss；多条冲突时返回加权混合，禁止 argmax 单条定案；miss 直接退回 R69 先验。

**定义 313（摊销 VoI 与合并控制器 AVC）** 设上下文重用风险率为 h（每 episode 复现概率），折扣 γ ∈ (0,1)，复用收益 ΔU(m,q') 为「有该记忆 vs 无该记忆」的期望决策改善，写入成本
C_w(m) = E_write + λ_E/η_wear + λ_priv·priv(m) + λ_meta·inc(m)，
其中 η_wear 为剩余擦写寿命比例。摊销价值
AVoI(m) = Σ_{τ=1}^{H} γ^τ · h(1−h)^{τ−1} · E_{q'}ΔU(m,q') − C_w(m)。
仅当 AVoI(m) > 0 且 MAA 认证通过时写入；否则只保留在易失 episodic buffer 或丢弃。若 AVoI > 0 但当前预算/磨损不足，记入**认知债务** d(m) 并排入下一 consolidation 窗口。

**定义 314（跨 episode 来源防火墙 CPG）** 与 R69 引理 18 的内 episode 独立性不同，这里必须排除**时间上的自证**。令 P(m) 的来源 DAG，去掉所有 `memory_self` 节点后，有效独立来源数
κ_eff(m) = max{|S| : S ⊆ P(m)∖{self-history}, ∀a≠b∈S, ι(a,b) ≥ ι_min}。
共享同一 context key、同一条 episode 回写、同一次 LLM 解码或同一人类标注者的来源，相关性按 ρ 折扣。高风险条目要求 κ_eff ≥ 2；κ_eff = 0 的条目进入隔离区，只能作为似然并触发独立验证；**任何由单次交互直接写成的条目不得单独定案**。

**定义 315（崩溃一致写与磨损感知擦除 WAL/WL）** 写路径：WAL 记录 `(seq, crc, payload)` → 提交记录 → 原位索引更新；恢复时取最大有效 seq，状态只能是「旧」或「新」，不允许撕裂。擦除只经日志结构合并并做磨损均衡；每个物理块擦除计数 e_b，要求 max_b e_b ≤ E_max。当剩余寿命低于阈值，进入**只读记忆模式 ROMM**：不再接受新写入，已有记忆仍可读，新歧义全部走 R69。

**定义 316（遗忘与可验证删除 FUG）** 每条记忆带租约 ζ 与隐私级 π_priv。删除义务有两类：(a) 租约过期 → 墓碑 + 置信衰减；(b) 用户「被遗忘权」→ **密码学擦除**：每条记忆独立密钥 k_m，删除密钥 + 墓碑 + 把所有派生条目（lineage 指针）标为失效；删除时间 ≤ T_U。删除本身是可认证动作，产出**删除证书**（证明所有已知副本/派生副本均已失效）。派生条目必须携带 lineage，否则删除会留下「幽灵副本」。

**定义 317（跨 episode canary 校准 CBC）** 仅用「n_ver ≥ 1 且 κ_eff ≥ 2」的已验证记忆更新 R69 的 mode_head 校准：
c_{t+1} = Proj_𝒞(c_t − η∇ECE_canary(c_t))，
其中 canary 是一组**不参与训练/写入选择**的 held-out 福利/校准样本。若 canary ECE 连续 k 个窗口上升，则回滚到 R69 校准并隔离贡献条目。**记忆可以校准先验，但不许为自己打分**。

**定义 318（记忆动作空间与授权 MAA）** 记忆动作 a_mem ∈ {write, verify, merge, delete, compact}。增广动作 ξ = (a, g, a_mem) ∈ 𝒜_task × 𝒜_info × 𝒜_mem。每个 a_mem 必须通过 MAA 认证：WCET ≤ T_mem、能量 ≤ E_mem、磨损影响 ≤ W_mem、隐私合规（π_priv 允许写入/复制）、并且不阻塞控制回路。写入只允许在 consolidation 窗口或安全静止期；控制回路内禁止任何擦除。

**定义 319（记忆-策略耦合与无突变）** 记忆对策略只产生**有界先验平移**：
log w'_k = log w_k + β·s_k(m), β ∈ [0, β_max], ‖s(m)‖_∞ ≤ 1，
随后用膨胀后验（并入 c 中的 ECE 与量化误差）参与 R69 的 VoI 与 C-RAS-WM 认证。检索 miss/迟到/冲突/磨损耗尽时 β = 0，逐指令回到 R69。β 与上下文距离用平滑门控，避免在 δ_ctx 阈值处跳变。

**定义 320（记忆投毒威胁模型 ℰ_mem）** 对手可：植入看似合理的记忆、重放陈旧记忆、用同一来源伪造多条「独立」记忆、利用回音室自证、以强制写入耗尽 flash 寿命（wear-out DoS）、以及规避删除（幽灵副本/备份）。并入 AIC：
ℰ_ENGRAM = ℰ_FLUID × ℰ_mem。

**定义 321（证书 J_ENGRAM）** J_ENGRAM = (J_FLUID, memory_epoch, |M|, wear_remaining, wal_chain_ok, κ_eff_min, AVoI_sum, deletion_obligations, canary_ECE, engram_ver)。Valid ⇔ Valid(J_FLUID) ∧ WAL 链完整 ∧ 记忆/磨损/能量有界 ∧ 无逾期删除义务 ∧ canary ECE ≤ τ_canary ∧ 隔离区为空。

**定义 322（零记忆退化与安全包含）** 当 M_max = 0、所有 AVoI ≤ 0、磨损耗尽（ROMM）、canary 失败、或检出投毒隔离时，ENGRAM 进入 **memory-off 模式**：β = 0、不写、不删，行为与 R69 **逐指令相同**。因此 R69 是 ENGRAM 在「零记忆」边界上的严格退化；R68 又是 R69 在「零交互」上的退化。安全包络不因记忆而扩大。

**定义 323（能量-精度-遗忘守恒）** 固定能量 E 与磨损 W 预算下，持久性、精度、可删性不可同时最优：
E_cons = Σ_{m: AVoI>0} E_write(m) + E_erase(m)，
量化误差 ε_q 增大时，必须由更长租约外的更多刷新或更大 λ 补偿；删除越彻底（lineage 越全、密钥管理越细），元数据写放大 A_del 越大。形式化地给出三选二前沿：在 (Retention, Deletability, Affordability) 上不存在同时严格改进；任何压缩只准换内存，不准换置信。

# IP-266 AVC：摊销 VoI，一次性歧义不写，复发性歧义才写
def amortized_voi(m, hazard, gamma, horizon, dU):
    reuse = sum(gamma**t * hazard * (1-hazard)**(t-1) for t in range(1, horizon+1))
    return reuse * dU - write_cost(m)         # write_cost 含能量/磨损/隐私/元数据

def should_consolidate(m, budget, wear):
    return (amortized_voi(m, m.hazard, GAMMA, H, m.dU) > 0
            and budget.allow(m) and wear.remaining() > W_MIN
            and m.pi_priv.allows_persist())

        for m in M.episodic.candidates():

                M.engram.write_wal(m)                     # 眨眼之间也要原子
        if M.clock.hit_canary_period():
            M.calib = M.cbc.cross_episode_calibrate(M.engram, M.fmp.mode_head, M.canary)
    M.vqa_i.submit_async(g, mem, M.episodic.last(), M.calib)
    return k, lam, mode, (U_ale, U_epi, mem.used)
```

## 3. 推导

**引理 19（摊销 VoI 的写入阈值）** 设上下文复用风险率 h、折扣 γ，忽略租约到期后的复用，则
AVoI > 0 ⇔ ΔU > C_w · (1 − γ(1−h)) / h。
证明：复用次数的期望为几何和 `Σ_{τ≥1} γ^τ h(1−h)^{τ−1} = γh/(1−γ(1−h))`，代入定义 313 即得。系 1：h → 0 时阈值 → ∞，**一次性歧义永不值得写**；h → 1 时阈值 → (1−γ)C_w，**高频复用即便收益小也值得写**。系 2：这正好把 R69 的「反复问同一个问题」变成一次性写入 + 后续有界读，交互疲劳被摊销 VoI 内生化，而不是外挂一个社会成本。

**引理 20（跨 episode 校准的收缩与发散）** 设 canary ECE 为 e_t，参与校准的记忆误差与真实误差的有效相关为 ρ_eff（由共享来源、同一 episode、同一 LLM 解码决定）。则
e_{t+1} ≤ ρ_eff · e_t + ε_σ，
其中 ε_σ 为有限样本噪声。ρ_eff < 1 时 e_t 几何收敛；ρ_eff → 1（回音室/共谋/自证）时无收缩甚至发散。系：**记忆能否治 R69 的模态失准，取决于跨 episode 独立性，而不是记忆条数**；定义 314 的 κ_eff 与定义 317 的 canary 正是把 ρ_eff 压在 1 以下的两道闸。

**引理 21（有界磨损与有界状态）** 设单块擦写寿命 E_max、块数 N、块大小 S、写放大 A_max、平均写入率 R_w，则设备可安全运行的最长时长为
L_max ≤ E_max · N · S / (A_max · R_w)。
超过即进入 ROMM（定义 315），此后不再产生新擦写。结合 WAL 的「旧或新」恢复，任意掉电时刻的记忆状态处于两个合法状态之一，不会出现半写、孤儿索引或无来源标签。**长期运行的状态空间有界，不随时间无界增长。**

**引理 22（跨期投毒持续上界）** 单条投毒记忆在每轮被独立验证并清除的概率为 p_v，跨 episode 证据纪律下其有效独立支撑为 κ_eff、欺骗相关 ρ。则 T 个 consolidation 周期后它仍能主导一次高风险决策的概率
P_persist(T) ≤ (1 − p_v)^T + δ_p · ρ^{κ_eff−1}。
系：删除（FUG）降低第一项，来源防火墙（CPG）降低第二项；只做其中一个都不够——这就是为什么记忆层必须同时有「防写错」与「能删掉」。

**定理 18（ENGRAM 严格包含 R69，且安全侧不让步）** 在定义 310–322 下：(i) 当 memory-off 条件成立时，ENGRAM 与 R69 在任意状态上**逐指令相同**；(ii) 当记忆开启时，记忆只通过定义 319 的有界先验平移影响模态选择，动作幅度、前缀认证与安全包络与 R69 完全一致，故约束违反概率不高于 R69；(iii) 当 AVoI > 0、κ_eff ≥ 2、canary 通过且 ε_poison < E[ΔU] 时，期望任务风险严格低于 R69。因此 R69 = ENGRAM 的「零记忆」边界，R68 = 「零交互」边界，R67 = 「零不确定性」边界；新增层只在旧层之上做严格泛化。

**定理 19（记忆动作安全、无突变与可删除）** 每个 a_mem 经 MAA 认证后 WCET/能量/磨损/隐私均在预算内；控制回路内禁止擦除，写入只发生在可中断窗口，掉电恢复为「旧或新」；记忆对策略的影响被 β_max 与膨胀后验限制，检索 miss/迟到/冲突时 β 平滑归零，故控制连续、无突变。FUG 的密码学擦除 + lineage 闭包在 T_U 内使所有已知派生副本失效，产出删除证书；删除失败（幽灵副本/坏块）会显式进入 J_ENGRAM 的删除义务，触发隔离与降级，而不是静默忽略。

## 6. 本轮最大风险

**一句话**：ENGRAM 把「一次性的相信」变成了「可长期复用的先验」，而嵌入式 flash 的写入/擦除不可逆、寿命有限、且删除比写入更难——**一旦一条错误或投毒的记忆被写进去，又被自己的历史回写当成证据，系统就会在未来几年里自信地、擦不掉地错下去；而为了省电/省磨损去砍掉验证与 canary，恰好会让这个正反馈更难被发现**。忘记只是损失，**把错误的相信焊进记忆才是灾难**。

## 2. 形式化定义（要点版）

**定义 310（总览与三不变式）** 零学习写操作继承 R68；有界状态（M_max、W_max、T_R、T_C/E_C，超界当窗降级）；记忆证据纪律（单条/自证不定案，高风险需 κ_eff ≥ 2）。

**定义 311–312（EMT 与 HRL）** 记忆是带年龄、出处、删除义务的信念；读出返回 `(ℓ̃,c,ζ,u)`。热 SRAM + 冷 flash，有界扇出/深度保证 `WCET ≤ T_R`；距离 > δ_ctx 视为 miss，冲突返回混合，禁止 argmax 单条定案。

**定义 313（摊销 VoI）** `AVoI(m)=Σ γ^τ h(1−h)^{τ−1} E ΔU − C_w`；仅 `AVoI>0` 且 MAA 通过才写；预算不足记认知债务、排下一窗口。一次性歧义（h→0）不写，复发性歧义才写（引理 19）。

**定义 314（跨 episode 来源防火墙）** 来源 DAG 去掉 `self-history` 后取最大两两独立子集得 κ_eff；同 context/同 episode 回写/同 LLM/同标注者按 ρ 折扣；高风险 ≥2；κ_eff=0 进隔离区只作似然。

**定义 315（WAL/WL）** `(seq,crc,payload)`→提交→索引；恢复取最大有效 seq，只能旧或新；磨损均衡使 `max_b e_b ≤ E_max`；寿命不足进 ROMM。

**定义 316（遗忘与可验证删除）** 租约墓碑 + 密码学擦除 + lineage 闭包；删除是认证动作，产出删除证书；派生条目必须带 lineage，防幽灵副本；`T_U` 内完成。

**定义 317（canary 校准）** 仅 `n_ver≥1 ∧ κ_eff≥2` 的记忆进校准集；`c←Proj_𝒞(c−η∇ECE_canary)`；canary 连续 k 窗变差 → 回滚 R69 并隔离贡献条目。记忆不许为自己打分。

**定义 318（记忆动作与授权）** `a_mem∈{write,verify,merge,delete,compact}`；每个动作认证 WCET/能量/磨损/隐私；控制回路只读，擦除只在静止窗口。

**定义 319（记忆-策略耦合）** `log w'=log w+β·s(m)`，`β≤β_max`；膨胀后验参与 VoI 与 C-RAS-WM；miss/迟到/冲突/磨损耗尽 ⇒ β=0；平滑门控防阈值跳变。

**定义 320（威胁模型）** `ℰ_ENGRAM=ℰ_FLUID×ℰ_mem`：植入、重放、共谋伪造、回音自证、wear-out DoS、删除规避。

**定义 321–322（证书与退化）** J_ENGRAM 并入记忆/磨损/WAL/κ_eff/AVoI/删除义务/canary；memory-off 条件成立时与 R69 **逐指令相同**；R69 是零记忆边界，R68 是零交互边界。

**定义 323（守恒）** 固定 E/W 下持久性、精度、可删性三选二；压缩只准换内存不准换置信；删除越彻底元数据写放大越大。给出守恒前沿，禁止「免费的记忆」。

        cand = bounded_ann(self.hot, self.cold, q, B=8, d=3)   # WCET <= T_R

        closure = lineage_closure(key)

def amortized_voi(m, hazard, gamma, horizon, dU):

    return reuse * dU - write_cost(m)          # 能量 + 磨损 + 隐私 + 元数据

            and budget.allow(m) and wear.remaining() > W_MIN
            and m.pi_priv.allows_persist())

    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + (U_epi if g is None else 0)))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)  # 认证不变
    mode = select_mode(modes, U_epi, lam)
    M.episodic.push(make_trace(context_key(o), modes, provenance(o, g), calib=c))
    if M.in_idle_window():                                     # 窗口外、可中断
        for m in M.episodic.candidates():
            if M.avc.should_consolidate(m, M.budget, M.wear):
                M.engram.write_wal(m)
        if M.clock.hit_canary_period():
            M.calib = M.cbc.cross_episode_calibrate(M.engram, M.fmp.mode_head, M.canary)
    M.vqa_i.submit_async(g, mem, M.episodic.last(), M.calib)
    return k, lam, mode, (U_ale, U_epi, mem.used)
```

## 4. 推导

**引理 19（摊销 VoI 写入阈值）** 复用次数期望为 `γh/(1−γ(1−h))`，故
`AVoI>0 ⇔ ΔU > C_w(1−γ(1−h))/h`。
系：h→0 阈值→∞，一次性歧义永不写；h→1 阈值→(1−γ)C_w，高频复用即便收益小也值得写。重复提问被内生化摊销，而非外挂社会成本。

**引理 20（跨 episode 校准收缩/发散）** 设有效误差相关 ρ_eff，则 `e_{t+1} ≤ ρ_eff e_t + ε_σ`。ρ_eff<1 时 ECE 几何收敛；ρ_eff→1（回音室/共谋/自证）时无收缩甚至发散。系：记忆能否治 R69 的模态失准，取决于跨 episode 独立性而非记忆条数；κ_eff + canary 是把 ρ_eff 压在 1 以下的两道闸。

**引理 21（有界磨损与有界状态）** `L_max ≤ E_max·N·S/(A_max·R_w)`；超过即 ROMM，不再产生新擦写。WAL 的「旧或新」恢复保证任意掉电时刻不出现半写、孤儿索引或无来源标签。长期状态空间有界，不随时间无界增长。

**引理 22（跨期投毒持续上界）** `P_persist(T) ≤ (1−p_v)^T + δ_p·ρ^{κ_eff−1}`。系：FUG 降低第一项，CPG 降低第二项；只做其中一个都不够——记忆层必须同时「防写错」与「能删掉」。

**定理 18（严格包含与安全不让步）** memory-off 时与 R69 逐指令相同；开启时记忆只做有界先验平移，动作幅度/前缀认证/安全包络不变，故约束违反 ≤ R69；当 `AVoI>0 ∧ κ_eff≥2 ∧ canary 通过 ∧ ε_poison<E[ΔU]` 时期望任务风险严格低于 R69。R69=零记忆边界，R68=零交互边界，R67=零不确定性边界。

**定理 19（记忆动作安全、无突变、可删除）** MAA 保证 WCET/能量/磨损/隐私在预算内；控制回路禁擦除，写入可中断，掉电「旧或新」；β_max + 膨胀后验限制影响，miss/迟到/冲突平滑归零 ⇒ 控制连续无突变；FUG 的密码学擦除 + lineage 闭包在 T_U 内使所有已知派生副本失效并产出删除证书，失败显式进入删除义务而非静默忽略。

## 7. 本轮最大风险

**一句话**：ENGRAM 把「一次性的相信」变成「可长期复用的先验」，而嵌入式 flash 的写入/擦除不可逆、寿命有限、删除比写入更难——**一旦一条错误或投毒记忆被写进去，又被自己的历史回写当成证据，系统就会在未来几年里自信地、擦不掉地错下去；而为了省电/省磨损砍掉验证与 canary，恰好会让这个正反馈更难被发现**。忘记只是损失，**把错误的相信焊进记忆才是灾难**。

**次级风险与缓解**：跨 episode 回音室 → CPG 排除 self-history + κ_eff 折扣 + E304；投毒后门 → 隔离区 + 引理 22 + E305；掉电撕裂 → WAL/CRC/单调序号 + E306；flash 磨损 → 磨损均衡 + ROMM + 引理 21；删除不彻底 → 密码学擦除 + lineage 闭包 + 删除证书 + E310；能耗/WCET 越界 → 只读回路 + 窗口外合并 + MAA 认证；量化造置信 → ε_q 显式传播 + E309；最坏情况是「为省电砍验证」→ 把验证预算写进 J_ENGRAM，砍掉即证书作废。
