# 第 47 轮（承接第 45 轮 v10 + 第 46 轮 v23；本轮灵感：关节空间控制 × 真机评测） · JointCert-Eval：关节空间证书传播与真机序贯安全评测（五层架构 v11）

> 承接 v10 能量-上下文-深度与 v23 记忆-语音-安全。v10 把感知调度写成能量租约约束下的联合证书，v23 把记忆/语音接入安全队列，但二者共同隐含假设 H5：**姿态证书 P_t 只要在 SE(3) 任务空间 soundness 成立，就等价于机械臂可安全执行，且离线 benchmark 足以签发部署结论**。UniBot 实机由关节空间位置/阻抗控制器驱动：FK 非线性且多解（IK 分支）、奇异位形会放大微小任务空间误差、关节限位/自碰撞/速度加速度约束在任务空间不可见；真机评测又昂贵、不可复现、受标定漂移与磨损影响。两个灵感词精确命中 H5：**关节空间控制**要求把 SE(3) 证书「运输」到关节空间并证明可执行；**真机评测**要求只在硬件租约有效、安全 shield 在线时做 anytime-valid 的序贯覆盖认证。耦合出的新问题：**如何让感知证书穿过非线性 IK/控制器成为可执行关节证书，并让真机评测而非离线 benchmark 成为证书唯一签发依据，且当奇异位形与感知退化同时发生时不静默失效**。

## 0. 直觉与动机

**灵感 1（关节空间控制 → 证书必须被「运输」而非「假设」）**
直觉：任务空间里 5mm 的位姿盒，到了奇异位形附近可能对应几十度的关节转动；IK 还有多个分支，选错分支会让机械臂绕开障碍或撞到自身。因此 `P_t sound ≠ 可执行`。正确做法是求 P_t 的关节空间原像 Q_t，只主张落在 Q_t 内、与上一关节构型同分支、且远离奇异/限位/自碰撞的证书；控制器跟踪误差与标定误差还必须先把 P_t 膨胀再求原像，否则「证书里的位姿」和「真正到达的位姿」不是同一个集合。

**灵感 2（真机评测 → 评测即持续认证，而非一次性 benchmark）**
直觉：真机不能像离线那样跑一万次，也不能用平均成功率冒充安全。评测应被设计成：安全 shield 先于执行拦截一切不在关节证书内的动作（硬约束违反按构造为 0），再用 anytime-valid 的序贯检验（e-process / 置信序列）认证「经验覆盖 ≥ 1-α_p」，可按证据提前停止；并按感知退化分层 Ω 分层报告下置信界，避免总体覆盖高而难层覆盖低的 Simpson 悖论。标定/磨损/碰撞冲击会让证书失效，所以真机评测同时是标定租约的续期过程。

**灵感 3（耦合 → 证书感知的关节-感知联合决策）**
直觉：感知退化（宽 P_t）与关节病态（小 σ_min(J)）会相乘。与其只 fail-closed，不如用冗余自由度/基座位姿/接近方向选一个条件数更好的构型，使宽 P_t 仍可执行；反过来，好的构型不降低感知覆盖要求，但能显著减少关节放大。于是调度目标从「选模态 m」升级为「选 (m, q)」，把关节可行裕度写进能量-记忆-语音的统一效用。

**耦合升级**：在 v10/v23 上新增 **L3 关节证书层 JSC** 与 **L5 真机评测环 RRP**，根信任层增加第三腿标定租约 ℓ_k。五层 v11：根信任（ℓ_p, ℓ_e, ℓ_k）+ L1 几何感知 + L2 上下文/记忆/语音 + L3 关节证书 + L4 CAR/Shield 守卫 + L5 DCL/真机序贯评测。ECPS 升级为 JCPS（联合选模态与构型），DCL 把「关节证书为空/条件数病态」样本列为高价值采集任务，CCA 增加 IK 分支翻转、标定漂移、e-process 作弊红队。

## 1. 形式化定义（增量：定义 59–64）

**定义 59（关节空间可行集与 IK 分支连续性）**
设运动学映射 `FK: Q⊂R^n → SE(3)`，关节可行域
`Q_adm = {q : q_min≤q≤q_max, |q̇|≤v_max, |q̈|≤a_max, self_collision_free(q), σ_min(J(q))≥σ_safe}`。
对姿态证书 `P⊂SE(3)` 与上一构型 `q_{t-1}`，关节原像
`Q_t = {q∈Q_adm : FK(q)∈P, ||q−q_{t-1}||_∞ ≤ δ_branch}`。
用区间分支定界求**声音内近似** `Q̂_t ⊆ Q_t`：盒 B 只有在 `FK_interval(B) ⊆ P` 时才被接受，故每个 `q∈B` 都满足 `FK(q)∈P`；无法判定的盒被丢弃。于是 `Q̂_t=∅` 可能是保守假阴性，但绝不产生假阳性。若 `Q_t=∅` 则 P 不可执行（fail-closed / 升级感知 / 换构型）。

**定义 60（条件数传递与证书半径放大）**
对构型 q，雅可比 `J(q)=∂FK/∂q`（6×n）。局部逆映射 Lipschitz 常数 `L_IK(q)=1/σ_min(J(q))`（方阵满秩；一般情形用伪逆的 Lipschitz 界）。给定跟踪误差界 `e_trk`、标定误差界 `e_cal`、离散化误差 `e_disc`，关节空间所需半径满足
`rad_J(q;P) ≤ L_IK(q)·(rad(P)+e_trk+e_cal) + e_disc`。
定义条件数裕度 `κ(q)=σ_min(J(q))/σ_max(J(q))`、奇异裕度 `s(q)=σ_min(J(q))−σ_safe`。可执行需 `s(q)≥0, κ(q)≥κ_min`。**关键直觉**：奇异附近 `L_IK→∞`，同一 P 证书要求的关节半径无界增长，因此只能「收紧 P（更多感知）」或「换 q（更好构型）」。

**定义 61（关节空间证书与联合 soundness）**
关节证书 `J_t^J=(Q̂_t, q_t^*, rad_J, ℓ_p, ℓ_k)`。联合 soundness（union bound）：
`P( X_{t+Δ} ∈ inflate(P_t, e_trk+e_cal) | q_t^*∈Q̂_t, ℓ_p 有效, ℓ_k 有效 ) ≥ 1−(α_p+α_cal+α_trk)`。
执行可行性（确定性）：`q_t^*∈Q_adm`，路径 `q_{t-1}→q_t^*` 全程留在 `Q_adm` 且 `|q̇|≤v_max`。若 `Q̂_t=∅` 或路径不可行 → 无关节证书 → CAR fail-closed / 重规划 / 换抓取。

**定义 62（运动学标定租约 ℓ_k）**
`ℓ_k=(calib_id, τ_k, Σ_cal, wear_flags, T_k, e_cal,max)`，误差上界
`e_cal(t)=sqrt(χ²_{n,1−α_cal}·tr(Σ_cal)) + ρ_wear·(t−τ_k) + e_impact`。
有效当且仅当 `e_cal(t)≤e_cal,max`、`t−τ_k≤T_k`、无冲击/回差异常标记。失效则所有依赖 FK 的 ℓ_p、ℓ_e 级联失效，必须重新标定。ℓ_k 与 ℓ_p、ℓ_e 并列为根信任的第三条腿。

**定义 63（真机序贯评测与分层覆盖证书）**
安全 shield：`S(a_t, J_t^J)=allow(a_t) ⇔ a_t∈Q̂_t 且路径可行`，否则降级到 `safe_fallback`（hold/retract，仍在 Q_adm）。取真值 `X_t^GT`（外部动捕/夹具），覆盖指示 `C_i=1[X_i^GT∈P_i]`。对坏假设 `H0: coverage ≤ 1−α_p` 构造非负 e-process：以可预测投注 `λ_i∈[0,1/p0]`，`(1+λ_i(C_i−p0))` 在 H0 下为超鞅；Ville 不等式给出 `P_{H0}(∃n: E_n≥1/δ)≤δ`。拒绝 H0 即 anytime-valid 地认证 `coverage>1−α_p`，支持可选停止。对每个感知层 `ω∈Ω` 单独做检验并按 Bonferroni 分配 δ，防止 Simpson 悖论。**真机证书仅在以下同时成立时签发**：所有层下置信界 ≥ 1−α_p、ℓ_k/ℓ_e 全程有效、shield 硬违反数为 0。

**定义 64（证书感知的关节-感知联合效用）**
决策 epoch 选择 `(m,q)`：
`V(m,q)= [E_{X∈P_t(m)} U_task(X)] · min(1, margin_J(Q̂_t(q))/margin_min) / (P_m + c_risk·Risk_e(B_t))`
约束 `Q̂_t(q;P_t(m))≠∅`、`s(q)≥0`、`κ(q)≥κ_min`、`E(t)≥E_min`、`ℓ_k` 有效。其中 `margin_J` 为 `Q̂_t` 到关节限位/碰撞边界的最小关节距离。该式表达耦合：感知越弱（P_t 越宽）就应选条件数/裕度越好的 q；只有在关节裕度支撑得起更宽证书时，才允许选更省电的模态。

## 2. 新增产出与既有 IP 升级

**IP-69 JSC（Joint-Space Certifier）**：区间 IK 内近似、分支连续性、奇异/限位/自碰撞过滤、rad_J 上界。
**IP-70 JCMP（Joint-Certified Motion Planner）**：证书感知的冗余解、基座位姿/接近方向选择、路径可行性与关节行程约束。
**IP-71 KCL（Kinematic Calibration Lease）**：标定协方差→e_cal 上界、漂移/冲击检测、租约续期与级联失效。
**IP-72 RRP（Real-Robot Protocol）**：shield 前置、分层 e-process 序贯覆盖认证、可选停止、预注册场景流。
**IP-73 JCPS（Joint-Context Perception Scheduler）**：在 IP-63 效用中加入 `margin_J`，联合输出 `(m_t^*, q_t^*)`。

**既有 IP 升级**
IP-63 ECPS：门控输出由 `m_t^*` 升级为 `(m_t^*, q_t^*)`，额外查询 JSC 可行性。
IP-64 DEPTH-CERT ADAPTER：深度条件半径先进入 P_t，再经 L_IK 放大为 rad_J，深度帧率失配同时触发 ℓ_k 复核。
IP-60 PSE：签发 P_t 时记录 rad(P_t)，供 JSC 做半径传递。
IP-61 DCL：采集效用加入「关节证书为空」「近奇异且感知退化」两类高价值样本。
IP-62 CCA：新增 IK 分支翻转、标定漂移注入、e-process 提前停止作弊红队。
IP-51 CAR：守卫条件改为「P_t 有效 ∧ Q̂_t≠∅ ∧ 路径可行 ∧ ℓ_k 有效」。
IP-45 总线：新增 joint-cert / calibration-lease / shield-veto / eval-eprocess 话题。
IP-66/67/68：记忆/语音/安全绑定决策必须通过 JSC；安全队列在等待姿态恢复的同时等待构型可行。

## 3. 算法骨架

每个控制周期：
1. 读 `B_t, ℓ_e, ℓ_k, c_t, ω_t, q_{t-1}`；若 ℓ_k 失效则直接 fail-closed 并请求重标定。
2. JCPS 枚举模态 m，用 PSE 得 `P_t(m)`，用 JSC 得 `Q̂_t(m,q)` 与 rad_J。
3. 过滤 `Q̂_t=∅ / κ<κ_min / 路径不可行`，在剩余候选中最大化 V(m,q)。
4. 选中 `(m_t^*, q_t^*)` 后签发 `J_t^J`，发预热/休眠与关节指令；CAR/Shield 复核。
5. 若全部候选不可行 → 触发 JCMP 换基座/接近方向/重抓取，仍不可行则 fail-closed。
6. 真机运行期间 RRP 持续累积分层覆盖 e-process，并监测 ℓ_k 漂移；任一失效即撤销证书。

## 4. 本轮最大风险

**一句话**：区间 IK 内近似过保守会让关节证书频繁为空、系统长期 fail-closed，工程上最可能的「修复」是偷偷退回点 IK 或外近似，从而在奇异位形与标定漂移叠加时让关节证书静默失声；因此内近似判据与 ℓ_k 失效必须做成不可配置的硬约束，并让真机 shield 独立于策略复核。

### IP-69 JSC

def interval_ik_inner(P_t, q_prev, robot, e_trk, e_cal, box_eps=1e-3, deadline_ms=20):
    P_infl = inflate(P_t, e_trk + e_cal)          # 先膨胀，吸收控制/标定误差
    roots = []
    stack = [box_around(q_prev, delta_branch)] + nominal_ik_boxes(P_t)
    while stack and now() < deadline:
        B = stack.pop()
        if not interval_overlaps(B, Q_adm):
            continue
        if interval_disjoint(interval_fk(B), P_infl):
            continue                               # 整盒可安全剪枝
        if interval_subset(interval_fk(B), P_infl):
            roots.append(B)                        # 声音内近似判据：整盒可接受
            continue
        if width(B) <= box_eps:
            continue                               # 无法判定则丢弃（保守）
        stack.extend(split(B, axis=widest_axis(B)))
    Q_hat = select_component(roots, q_prev)        # 保留含 q_prev 的连通分量
    return Q_hat if Q_hat else None

def joint_certify(P_t, q_prev, m_t, ell_k, ell_e):
    if not lease_valid(ell_k) or not energy_valid(ell_e, m_t):
        return None                                # 根信任失效：fail-closed
    e_cal = calibration_bound(ell_k)
    Q_hat = interval_ik_inner(P_t, q_prev, robot, e_trk, e_cal)
    if Q_hat is None:
        return None
    Q_ok = [q for q in Q_hat
            if sigma_min(J(q)) >= sigma_safe
            and kappa(J(q)) >= kappa_min
            and clearance(q) >= c_min]
    if not Q_ok:
        return None                                # 证书存在但不可执行
    q_star = argmin([w1*norm(q - q_prev) + w2*(-clearance(q)) for q in Q_ok])
    if not path_in_adm(q_prev, q_star, v_max, self_collision_free):
        return None
    rad_J = L_IK(q_star) * (rad(P_t) + e_trk + e_cal) + e_disc
    return JointCert(Q_hat=Q_ok, q_star=q_star, rad_J=rad_J,
                     ell_p=pose_lease(P_t), ell_k=ell_k)
```

### IP-70 JCMP
```
def choose_config(P_t, q_candidates, q_prev, ell_k, ell_e):
    feasible = []
    for q in q_candidates:
        if sigma_min(J(q)) < sigma_safe or kappa(J(q)) < kappa_min:
            continue
        Jc = joint_certify(P_t, q, m_t, ell_k, ell_e)
        if Jc is None:
            continue
        feasible.append((q, joint_margin(Jc.Q_hat), kappa(J(q)),
                         max_joint_travel(q_prev, q)))
    if not feasible:
        return None                                # 触发基座位姿调整/换抓取
    # 先保证裕度与条件数达标，再惩罚关节行程（防分支翻转导致大动）
    return max(feasible, key=lambda x: min(x[1]/margin_min, x[2]/kappa_min)
                                      - w3*min(x[3]/travel_max, 1.0))
```

def renew_calibration_lease(ell_k, obs):
    Sigma = kalman_update(ell_k.Sigma_cal, obs.calib_measurement)
    e_impact = impact_monitor(obs.accel, obs.current)

    expired = (obs.t - ell_k.tau) > T_k
    if e_impact > e_impact_max or e_cal > e_cal_max or expired:
        return ell_k.invalidate(reason='calib')    # 级联 ℓ_p / ℓ_e 失效
    return ell_k.renew(Sigma_cal=Sigma, tau=obs.t, e_cal=e_cal)
```

### IP-72 RRP
```
def real_robot_eval(policy, shield, stratified_stream, p0=1-alpha_p, delta=0.05):
    wealth = EProcess(p0)                          # H0: coverage <= p0（坏）
    strata = {w: EProcess(p0) for w in Omega}
    n = 0
    for omega, scen in stratified_stream:          # 预注册分层场景流
        for t in scen:
            a = policy(scen, t)
            if not shield.allow(a):                # 硬约束前置拦截
                log_veto(omega, a)
                a = shield.safe_fallback(scen, t)  # hold/retract，仍在 Q_adm
            x = execute(a)
            gt = measure_ground_truth(scen)
            c = int(gt in policy.certificate(scen, t))
            lam = predictable_bet(wealth.history)  # 可预测投注，保超鞅性
            wealth.update(c, lam)                  # (1 + lam*(c - p0))
            strata[omega].update(c, predictable_bet(strata[omega].history))
            n += 1
            if wealth.reject(delta) and all(s.reject(delta/len(Omega))
                                            for s in strata.values()):
                return wealth.lower_bound(delta), strata, n, 'certified_early'
    lcb = wealth.lower_bound(delta)
    return lcb, {w: s.lower_bound(delta/len(Omega)) for w, s in strata.items()}, n, 'horizon'
```

### IP-73 JCPS
```
def joint_context_schedule(c_t, omega_t, B_t, ell_k, ell_e, q_prev):
    best = None
    for m in MODALITIES:
        P = pose_certificate(c_t, omega_t, m)      # L1 PSE
        if P is None:
            continue
        Jc = joint_certify(P, q_prev, m, ell_k, ell_e)   # L3 JSC
        if Jc is None:
            continue
        val = task_utility(P) \
              * min(1.0, joint_margin(Jc.Q_hat)/margin_min) \
              / (P_m + c_risk*Risk_e(B_t))
        if best is None or val > best[2]:
            best = (m, Jc, val)
    if best is None:
        return ('replan_or_regrasp', None)          # 换基座/接近方向/抓取
    return best
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| JSC 区间 IK | 最坏 O((1/ε)^n·n)，带 deadline 截断 | O(#boxes·n) | `FK_interval(B)⊆P_infl ⇒ Q̂⊆真原像`（sound，不完备） |
| 条件数过滤 | O(|Q̂|·n³)（SVD） | O(n²) | σ_min≥σ_safe、κ≥κ_min、clearance≥c_min |
| KCL | O(n²) | O(n²) | e_cal 为上界，超限/冲击/超期级联失效 |
| RRP | O(N·T + |Ω|) | O(|Ω|) | Ville 保证 type-I ≤ δ，可 anytime 停止 |
| JCPS | O(|M|·cost(JSC)) | O(|M|) | 仅联合可行候选可执行 |

**正确性定理（Union-Bound Joint Soundness）**
假设：(A1) 区间包络 sound，即 `FK(B)⊆FK_interval(B)`；(A2) 仅当 `FK_interval(B)⊆P_infl` 才接受盒，故 `Q̂_t⊆Q_t`；(A3) 跟踪误差与标定误差分别以概率 `1−α_trk`、`1−α_cal` 落在 `e_trk`、`e_cal` 内；(A4) 姿态证书在 `ℓ_p, ℓ_e` 有效时以 `1−α_p` 覆盖真值。则对任意被接受的执行 `q_t^*∈Q̂_t`，
`P(X_{t+Δ}∈inflate(P_t,e_trk+e_cal)) ≥ 1−(α_p+α_cal+α_trk)`；
且由于 `q_t^*∈Q_adm` 且路径可行，关节限位、速度、加速度、自碰撞约束**确定性**满足。Shield 只放行 `Q̂_t` 内动作，故真机评测中硬约束违反数按构造为 0；RRP 的 e-process 在 H0 下为超鞅，故覆盖认证 type-I ≤ δ。若 `Q̂_t=∅` 或路径不可行，则不执行（fail-closed 或升级到重规划）。注意：这不是「完备性」结论——保守丢弃的盒会降低可用性，但不会破坏 soundness。

## 4. 实验设计 E115–E120

| 实验 | 指标 | 门槛 |
|---|---|---|
| E115 区间 IK soundness | 从 Q̂ 采样 q 用真值 FK 检验假接受数；Q̂ 非空率 | 假接受 = 0；标称非空率 ≥ 95%，难层 ≥ 80% |
| E116 条件数传递 | 预测 rad_J vs 实测关节/末端误差；近奇异 vs 常规分组 | 比值 ≤ 1.2×；两组可分离 |
| E117 标定租约 | 漂移检测延迟；误失效率；e_cal 界覆盖 | 延迟 ≤ 10 周期；误失效 ≤ 1%；界覆盖 ≥ 99% |
| E118 真机序贯评测 | type-I error；提前停止样本节省；分层下界 | type-I ≤ δ=0.05；节省 ≥ 40%；每层下界 ≥ 1−α_p |
| E119 Shield 有效性 | 硬约束违反数；干预率；fallback 成功率 | 违反 = 0；干预 ≤ 5%；fallback ≥ 95% |
| E120 100h 真机闭环 | 任务成功率；关节证书塌缩率；证书续期次数 | 成功 ≥ 95%；塌缩 < 2%；续期有记录、零安全违例 |

回退策略：E115 假接受 > 0 → 立即停机，收紧内近似判据/减小 box_eps（绝不放宽为点 IK）；E116 比值 > 1.5× → 增大 e_trk/e_cal 余量或降低 σ_safe；E118 type-I > δ → 改用固定样本 Hoeffding 下界并报告两者；E119 干预 > 10% → 加强 JCMP 构型规划或引入基座自由度；E120 塌缩 ≥ 2% → 强制近奇异场景降速并请求重标定。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 区间 IK 过保守导致可用性崩塌，工程上偷放宽判据 | 高 | 内近似判据做成硬编码不可配置；deadline 内失败则局部 Jacobian 内球回退或升级，绝不点 IK |
| 标定漂移未被检测，证书在失效硬件上继续签发 | 高 | KCL 冲击/回差监测 + 周期夹具重标定 + 保守 e_cal；ℓ_k 失效即全局 fail-closed |
| e-process 依赖独立同分布，时序相关破坏 type-I | 高 | 可预测投注 + 分块构造；同时报告固定样本保守界作为兜底 |
| shield 的 fallback 自身不安全 | 高 | fallback 固定为 Q_adm 内 hold/retract，独立于策略并单独形式化验证 |
| IK 分支翻转造成大关节跳变 | 中 | δ_branch 连续性 + max_joint_travel 惩罚 + 路径可行性检查 |
| 真机评测挑样本/提前停止作弊 | 中 | 预注册分层场景流、记录每次 veto、e-process 财富公开留痕 |
| 关节证书与语义/记忆决策冲突 | 中 | IP-66/67/68 全部经 JSC 复核，冲突时安全队列优先 |

## 6. 本轮最大风险

**一句话**：区间 IK 内近似过保守会让关节证书频繁为空、系统长期 fail-closed，工程上最可能的「修复」是偷偷退回点 IK 或外近似，从而在奇异位形与标定漂移叠加时让关节证书静默失声；因此内近似判据与 ℓ_k 失效必须做成不可配置的硬约束，并让真机 shield 独立于策略复核。
