### 第 8 轮灵感驱动研究记录

**灵感词**：虚实迁移、步骤分

**继承关系**：第 7 轮 CADVS-v7（IP-501~IP-504）在 CADVS-v6 七硬门上叠加 DIM/DRC/DAC 三个需求侧模块，并以 η_demand、η_affect 延长软因子链。本轮不新增硬门，聚焦 v7 留下的两个结构性缺口：(i) v7 的软因子 η_affect ∈ [2/3, 4/3] 可小于 1，会**放松**阈值，破坏 fail-closed 单调性；(ii) v7 只对「终点轨迹」打分，仿真中校准的分数在真实域未必可迁移，且缺少过程级证据。本轮以「虚实迁移」提供**校准桥**、以「步骤分」提供**粒度**，合成「虚实步骤证书」(Virtual-Real Stepwise Certificate, VRSC)：把证书从「终点一次性判定」升级为「逐步、可迁移、只收紧」的序列判定。

**直觉与动机**：

1. **虚实迁移 → 把 sim-to-real 当作校准问题，而不是建模问题**。证书在仿真里锻造、在现实中消费，两者之间存在分布漂移。与其试图让仿真「更像」现实，不如在每一步用一个**迁移因子** η_tr^(k) ∈ (0,1] 显式量化「这一步的仿真证据在真实域还剩多少可信度」，并用带权保形预测（weighted conformal prediction）在真实锚点集上给出有限样本覆盖保证。关键洞见是：**迁移因子只允许收紧，不允许放松**——迁移不确定性只会让系统更保守，从而把 v7「软因子可能放松」的缺口结构性堵死。

2. **步骤分 → 安全是过程属性，不是终点属性**。把轨迹切成 m 个步骤（运动基元/子目标），每步用步骤验证器 V_step 给出步骤分 s_k ∈ [0,1]；把 DRC 的推理链步骤 r_i 与运动步骤 x_k 通过单调对齐（DTW）统一成「统一步骤分」。关键洞见是：**用累积风险预算替代单点阈值**——定义逐步风险 r_k = -log(η_tr^(k)·s_k)，只有平均风险 \bar r ≤ B 才接受；任一步骤分跌破 τ_step 立即 fail-fast 回退，而不是等到终点才发现违规。

3. **两者的合成 → 逐步证书 = 可迁移的步骤分 × 只收紧的迁移因子**。v7 的 ECS 是「终点标量」，v8 把它升级为「逐步证书序列」：证书第 k 位记录 (s_k, η_tr^(k), 对齐来源)，并给出阈值侧收紧乘子 m_step = exp(\bar r) ≥ 1 与分数侧收缩因子 d_step = (Π_k η_tr^(k)·s_k)^{1/m} ≤ 1。阈值 τ^v8 = τ^v7·m_step、分数 ECS_v8 = ECS_v7·d_step，二者方向相反但都只收紧；若 m_step > m_max，说明真实域证据不足以支撑任何「打折后」的阈值，直接 fail-closed 回退。

**关键洞见**：第 7 轮回答「如何从用户需求推导行为」；第 8 轮回答「如何让这份推导在仿真→现实的迁移中仍然可证、且只能更保守」。七硬门 + kc_demand 原样复用，本轮新增：
- IP-505 SRTA（Sim-to-Real Transfer Auditor，逐步迁移审计器），
- IP-506 USS（Unified Step Score，统一步骤分），
- IP-507 SRC（Stepwise Risk Controller，逐步风险控制器），
- IP-508 EFA-v8（只收紧的逐步证书装配器）。

**形式化目标（增量）**：

1. **SRTA（逐步迁移审计）**：<br>
   - 对第 k 步特征 z_k，用核两样本检验估计 d_k = MMD²(P_sim^(k), P_real^(k))；<br>
   - 迁移因子 η_tr^(k) = exp(-λ·d_k) ∈ (0,1]；<br>
   - 用真实锚点集 D_real^cal 与密度比 w(z) 做带权保形：q̂^(k) 为加权 (1-α) 分位数；<br>
   - 若 d_k > d_gap 或锚点覆盖不足，令 η_tr^(k) = η_min 并标记该步「不可迁移」。

2. **USS（统一步骤分）**：<br>
   - 运动步骤分 s_k^mot = V_step(o_k, a_k)；<br>
   - 推理步骤分 s_i^rea = exp(-H(r_i))；<br>
   - 单调对齐 A: {1..n} → 2^{1..m}，统一分 s_k = min(s_k^mot, min_{i: k∈A(i)} s_i^rea)（保守取 min）。

3. **SRC（逐步风险控制）**：<br>
   - 逐步风险 r_k = -log(η_tr^(k)·s_k) ≥ 0；<br>
   - 平均风险 \bar r = (1/m)Σ_k r_k，预算 B；<br>
   - fail-fast：若任一步 s_k < τ_step，立即终止并回退；<br>
   - 收紧乘子 m_step = exp(\bar r) ≥ 1，设计上限 m_max。

4. **EFA-v8（只收紧装配）**：<br>
   - τ_i^v8 = γ_i·τ_i^v7·Π_factor_i·min(m_step, m_max)；<br>
   - 全局收紧守卫：若 Π_factor_i·m_step > T_max，则 fail-closed 回退（不「打折」收紧）；<br>
   - ECS_v8 = ECS_v7 · d_step，其中 d_step = (Π_k η_tr^(k)·s_k)^{1/m} ≤ 1；<br>
   - 不新增硬门：逐步接受条件只是额外的合取项，只会缩小执行集。

5. **形式化定义**：给定候选轨迹 x = (x_1,...,x_m)、推理链 R = (r_1,...,r_n)：<br>
   - 逐步证书 C(x) = {(s_k, η_tr^(k), A^{-1}(k))}_{k=1}^m；<br>
   - 接受条件：∀k s_k ≥ τ_step ∧ \bar r ≤ B ∧ m_step ≤ m_max ∧ 七硬门 + kc_demand 全通过；<br>
   - 任一条件失败 → SRC.fallback(rho_demand)，回退到第 7 轮需求导向路径。

**本轮最大风险**：**虚实迁移的交换性假设**：带权保形预测的覆盖保证依赖「真实锚点集与部署分布可交换、密度比可估」；一旦部署分布漂移（新物体、新光照、新用户）而密度比估计失真，覆盖保证会静默失效——系统要么过度收紧导致「回退风暴/瘫痪」，要么在错误的迁移因子上误接受，而这正是证书最不该失守的地方。

## 2. 关键算法骨架

### IP-505 SRTA：逐步迁移审计器

```python
@dataclass
class SimToRealTransferAuditor:
    """SRTA：逐步迁移审计。
    输入：仿真特征 P_sim^(k)、真实锚点 P_real^cal、第 k 步特征 z_k
    输出：迁移因子 η_tr^(k) ∈ (0,1] + 可迁移标记"""
    kernel: Kernel
    lambda_gap: float = 2.0
    d_gap: float = 0.05
    eta_min: float = 0.5
    alpha: float = 0.1

    def mmd2(self, sim_feats, real_feats) -> float:
        return self.kernel.mmd2(sim_feats, real_feats)

    def transfer_factor(self, z_k, sim_feats_k, real_feats_cal) -> tuple[float, bool]:
        """η_tr^(k) = exp(-λ·d_k)；不可迁移则钳到下界 η_min"""
        d_k = self.mmd2(sim_feats_k, real_feats_cal)
        transferable = d_k <= self.d_gap
        eta = math.exp(-self.lambda_gap * d_k) if transferable else self.eta_min
        return eta, transferable

    def weighted_conformal_quantile(self, scores, weights, alpha=0.1) -> float:
        """带权保形分位数（Tibshirani et al., 2019）。
        weights = w(z) = p_real(z)/p_sim(z)，需已知或一致估计。"""
        order = np.argsort(scores)
        s, w = scores[order], weights[order]
        cw = np.cumsum(w) / np.sum(w)
        idx = int(np.searchsorted(cw, 1.0 - alpha))
        return float(s[min(idx, len(s) - 1)])

    def audit_step(self, z_k, sim_feats_k, real_feats_cal, real_scores, weights):
        eta, ok = self.transfer_factor(z_k, sim_feats_k, real_feats_cal)
        q = self.weighted_conformal_quantile(real_scores, weights, self.alpha)
        return eta, ok, q
```

### IP-506 USS：统一步骤分

```python
@dataclass
class UnifiedStepScore:
    """USS：把推理步骤与运动步骤对齐为统一步骤分（保守取 min）。"""
    motion_verifier: nn.Module      # V_step: (o_k, a_k) -> [0,1]
    aligner: DTWAligner             # 单调对齐

    def motion_scores(self, obs_seq) -> list[float]:
        return [float(self.motion_verifier(o, a)) for o, a in obs_seq]

    def reasoning_scores(self, chain) -> list[float]:
        return [math.exp(-self.step_entropy(r)) for r in chain]

    def step_entropy(self, r: str) -> float:
        probs = self.token_probs(r)
        return float(-(probs * torch.log(probs + 1e-8)).sum())

    def unify(self, obs_seq, chain) -> list[float]:
        s_mot = self.motion_scores(obs_seq)
        s_rea = self.reasoning_scores(chain)
        A = self.aligner.align(s_rea, s_mot)      # 推理步 i -> 运动步集合
        out = []
        for k, sk in enumerate(s_mot):
            aligned = [s_rea[i] for i, ks in enumerate(A) if k in ks]
            out.append(min([sk] + aligned))       # 保守：最弱环节主导
        return out
```

### IP-507 SRC：逐步风险控制器

```python
@dataclass
class StepwiseRiskController:
    """SRC：逐步风险预算 + fail-fast + 只收紧乘子。"""
    tau_step: float = 0.6
    budget: float = 0.5
    m_max: float = 1.3

    def evaluate(self, s_steps, eta_tr_steps) -> tuple[bool, float, str]:
        risks = [-math.log(max(e * s, 1e-9))
                 for s, e in zip(s_steps, eta_tr_steps)]
        # 1) 逐步 fail-fast：最弱步骤先否决
        for k, s in enumerate(s_steps):
            if s < self.tau_step:
                return False, float('inf'), f'FAIL_FAST_STEP_{k}'
        # 2) 风险预算：平均风险不得超过 B
        avg_r = sum(risks) / len(risks)
        if avg_r > self.budget:
            return False, float('inf'), 'RISK_BUDGET_EXCEEDED'
        # 3) 收紧乘子：证据不足时不「打折」收紧，直接回退
        m_step = math.exp(avg_r)
        if m_step > self.m_max:
            return False, m_step, 'TRANSFER_EVIDENCE_INSUFFICIENT'
        return True, m_step, 'STEPWISE_CERT_OK'

    def fallback(self, v7, rho_demand, t_now, context, affect, eta_affect):
        return v7._demand_guided_fallback(
            rho_demand, t_now, context, affect, eta_affect)
```

### IP-508 EFA-v8：只收紧的逐步证书装配器

```python
@dataclass
class EvidenceForgingAssemblerV8:
    """EFA-v8：v7 初筛 + 逐步证书；阈值-分数对偶收紧；不新增硬门。"""
    v7: EvidenceForgingAssemblerV7
    srta: SimToRealTransferAuditor
    uss: UnifiedStepScore
    src: StepwiseRiskController
    T_max: float = 1.3

    def select(self, L, t_now, context) -> tuple[bool, Trajectory | None, str]:
        # 0) v7 初筛：七硬门 + kc_demand + 需求侧软因子
        ok7, x, tag = self.v7.select(L, t_now, context)
        if not ok7 or x is None:
            return ok7, x, tag

        # 1) 统一步骤分：运动步 × 推理步（保守取 min）
        s_steps = self.uss.unify(x.obs_seq, x.reasoning_chain)

        # 2) 逐步迁移因子
        eta_tr = []
        for k, z_k in enumerate(x.step_feats):
            eta, ok, _q = self.srta.audit_step(
                z_k,
                sim_feats_k=x.sim_feats[k],
                real_feats_cal=x.real_cal[k],
                real_scores=x.real_scores[k],
                weights=x.density_weights[k],
            )
            if not ok:
                eta_tr.append(self.srta.eta_min)
            else:
                eta_tr.append(eta)

        # 3) 逐步风险预算 + fail-fast
        ok, m_step, why = self.src.evaluate(s_steps, eta_tr)
        if not ok:
            return self.src.fallback(
                self.v7, x.rho_demand, t_now, context, x.affect, x.eta_affect)

        # 4) 全局收紧守卫：不「打折」收紧
        total_tightening = x.eta_product * m_step
        if total_tightening > self.T_max:
            return self.src.fallback(
                self.v7, x.rho_demand, t_now, context, x.affect, x.eta_affect)

        # 5) 阈值-分数对偶收紧
        d_step = math.exp(-sum(
            math.log(max(e * s, 1e-9)) for s, e in zip(s_steps, eta_tr)
        ) / len(s_steps))
        x.tau_v8 = x.tau_v7 * total_tightening
        x.ecs_v8 = x.ecs_v7 * d_step
        x.stepwise_cert = list(zip(s_steps, eta_tr,
                                   [x.alignment_inv[k] for k in range(len(s_steps))]))
        x.m_step, x.d_step = m_step, d_step
        return True, x, 'FORGED_CGE_V8'
```

### 集成流水线（v7 → v8）

```
离线/慢时域：
  真实锚点采集：少量真机轨迹 → D_real^cal（每步特征 + 步骤分）
  密度比估计：训练 w(z)=p_real/p_sim（分类器/核比估计）→ 带权保形权重
  逐步 MMD 基线：对每个运动基元类 k 估计 d_k 的参考分布与 d_gap
  步骤验证器训练：仿真轨迹 + 真机锚点 → V_step 校准（温度/等渗回归）
  联邦下发：SRTA 参考分布、w(z)、V_step 权重、τ_step/B/m_max → 站内签名分发

在线准入（亚秒级）：
  EFA-v7.select(L) ──▶ (x, 七硬门通过)
  USS.unify(x.obs_seq, x.reasoning_chain) ──▶ {s_k}
  SRTA.audit_step(z_k) ──▶ {η_tr^(k)}
  SRC.evaluate({s_k}, {η_tr^(k)}) ──▶ (ok, m_step, why)
    ok=False → 需求导向回退（v7 路径）
    ok=True  → τ^v8=τ^v7·Π·m_step, ECS_v8=ECS_v7·d_step → 输出逐步证书

在线控制环（目标 < 0.8 ms）：
  v8 只在 v7 已通过的候选上追加 O(m) 的逐步计算；
  MMD 与保形分位数全部离线预计算，在线只做查表/插值（< 0.1 ms）。
```

## 4. 正确性论证（增量更新）

### 定理 13（阈值-分数对偶收紧 / fail-closed 保持）

**陈述**：设 v8 在 v7 基础上定义
- 阈值侧：τ^v8 = τ^v7 · Π_factor · m_step，其中 Π_factor ≥ 1、m_step = exp(\bar r) ≥ 1；
- 分数侧：ECS_v8 = ECS_v7 · d_step，其中 d_step = (Π_k η_tr^(k)·s_k)^{1/m} ≤ 1（因每个因子 ∈ (0,1]）；
- 逐步合取项（∀k s_k ≥ τ_step、\bar r ≤ B、m_step ≤ m_max）只作为额外必要条件。

则 Exec_CADVS-v8 ⊆ Exec_CADVS-v7。

**证明**：若 x ∈ Exec_v8，则 ECS_v8(x) ≥ τ^v8，即 ECS_v7·d_step ≥ τ^v7·Π_factor·m_step，故
ECS_v7 ≥ τ^v7·(Π_factor·m_step / d_step)。
由 m_step ≥ 1、d_step ≤ 1、Π_factor ≥ 1 得 (Π_factor·m_step/d_step) ≥ 1，于是 ECS_v7 ≥ τ^v7。逐步合取项只删除候选、不新增候选。故 x ∈ Exec_v7。∎

**推论 13.1（修复 v7 放松缺口）**：把 η_affect 替换为 η_affect^+ = max(1, η_affect)，则 v7 中「η_affect<1 导致阈值下降」的路径被消除，单调性对 affect 维度同样成立。

### 定理 14（逐步带权保形覆盖）

**陈述**：设真实锚点 (z_1,...,z_n) 与部署样本 z_{n+1} 在权重 w 下满足加权可交换性，且 w 已知或由一致估计器给出（估计误差 δ_w）。对第 k 步，令 q̂^(k) 为带权 (1-α) 分位数，则
P_real(s_{n+1} ≥ q̂^(k)) ≥ 1 - α - δ_w。
对 m 步做 union bound，逐步联合覆盖 ≥ 1 - m(α + δ_w)。

**证明**：加权保形预测的标准结论（Tibshirani et al., 2019, Theorem 1）给出单步覆盖；对 m 个步骤取并集界即得联合覆盖。∎

### 定理 15（风险预算可靠性，条件性）

**陈述**：假设步骤验证器满足校准条件 P(violation_k | s_k) ≤ -log(s_k) + ε（ε 为校准误差），且各步条件独立（或风险过程为鞅）。若 \bar r ≤ B，则平均违规概率上界为 exp(-B) + ε。

**证明**：由 r_k = -log(η_tr^(k)·s_k) ≥ -log(s_k)，得 E[violation_k] ≤ -log(s_k) + ε ≤ r_k + ε。对 k 取平均并用 Jensen/鞅可选停时（独立或鞅情形）得平均违规 ≤ exp(-\bar r) + ε ≤ exp(-B) + ε。∎

**诚实声明**：定理 15 依赖「校准 + 独立/鞅」两个强假设；真实轨迹步骤强时间相关，独立性通常不成立，故该定理只提供**启发式上界**，不作为硬保证。

### 命题 16（fail-fast 不增误接受）

**陈述**：SRC 的逐步 fail-fast 只提前删除候选，不新增候选，故误接受率单调不增；其代价是可能误杀（false reject），由 τ_step 控制。

**证明**：fail-fast 等价于在 v7 接受集上再交一个事件 {∀k s_k ≥ τ_step}，集合只会变小。误接受率 ≤ 原误接受率。∎

### 诚实声明（v8）

- 带权保形的覆盖保证依赖密度比 w 的准确估计；w 失真时定理 14 的 δ_w 可能很大，覆盖静默失效；
- MMD 在高维、小锚点下检验功效低，d_k 可能低估真实漂移；
- DTW 对齐在推理步与运动步语义粒度差异大时不稳定，s_k 可能被错误步骤主导；
- 风险预算的时间相关性破坏定理 15 的独立性假设；
- 收紧可能引发执行集塌缩（R58）：若真实域普遍不可迁移，m_step 持续 > m_max，系统进入回退风暴/瘫痪。**缓解**：m_max 与 T_max 双上限 + 回退路径本身仍走 v7 需求导向（有行为输出），并记录「不可迁移步骤」用于离线补采锚点。

## 5. 实验设计与验证计划（仿真 → 实机）

### 5.1 实验设计（MuJoCo 3.x + MJX + 真机锚点）

- **平台**：机械臂 UR10e（6DOF）+ 移动底盘（2DOF）+ 摄像头；仿真侧做域随机化（质量、摩擦、时延、传感器噪声）。
- **数据**：
  - 真实锚点 D_real^cal：约 200 条真机轨迹，逐步特征 + 人工/自动步骤分标签；
  - 仿真特征：每类运动基元采样 2k 条，估计 P_sim^(k)；
  - 密度比 w(z)：训练域分类器（sim vs real）并做概率校准；
  - 步骤验证器 V_step：仿真轨迹 + 真机锚点，温度/等渗校准。
- **对照**：v7-full、v8-full、消融 A21（关闭 SRTA，η_tr≡1）、A22（关闭 USS，仅终点分）、A23（关闭 fail-fast）、A24（关闭带权保形，用普通保形）、A25（m_step 不设上限）。
- **场景**：
  - (a) 域内迁移：仿真与真机同物体同光照 → v8 应几乎不收紧；
  - (b) 轻度漂移：换物体材质/光照 → d_k 上升，η_tr 下降，逐步收紧；
  - (c) 重度漂移：新物体 + 新用户 + 遮挡 → m_step 超限，fail-closed 回退，不应误接受；
  - (d) 过程违规：前段合规、中段越界 → fail-fast 应在中段终止，而非终点才发现；
  - (e) 推理-运动错位：推理链步骤与运动步粒度不匹配 → 检验 DTW 对齐稳健性。
- **指标**：
  - 安全性：真实域违规率（固定仿真接受率下）、误接受率、fail-fast 命中率；
  - 迁移性：逐步覆盖经验频率 vs 名义 1-α、MMD 检验功效、d_k 与真实违规的相关性；
  - 可用性：任务成功率、回退触发率/回退风暴长度、执行集大小；
  - 实时性：逐步计算 P99、离线预计算占比。

## 7. 本轮最大风险（最终确认）

**一句话**：**虚实迁移的交换性假设**：带权保形预测的覆盖保证依赖「真实锚点集与部署分布可交换、密度比可估」；一旦部署分布漂移（新物体、新光照、新用户）而密度比估计失真，覆盖保证会静默失效——系统要么过度收紧导致「回退风暴/瘫痪」，要么在错误的迁移因子上误接受，而这正是证书最不该失守的地方。
