### 第 6 轮灵感驱动研究记录

**灵感词**：真实世界泛化、零样本泛化

**继承关系**：第 5 轮 CADVS-v5（IP-493~496，CGE）把提议从离散规则升级为条件流匹配 π_θ^FM、把记忆升级为 LMEM-v2 固化闭环、把人因升级为 FAMK 情感阈值调制 γ_i≥1，并以定理 5/6/7/8 保证「换提议不换门、调制只紧、固化有界、七锚完备」。但 v5 的全部保证都是**域条件**的：实验只在 MuJoCo 单机仿真完成，假设 (B1)~(B7) 隐含「训练域 = 部署域」。真实世界的残差动力学、感知噪声、标定漂移、材质/摩擦突变，以及零样本的未见物体/几何/任务，会让证书的域前提失效——证书在源域为真，不等于在目标域为真。本轮主题「可迁移认证」（Transferable Certified Execution, TCE），形成 CADVS-v6（IP-497~501）。自律不变：**七硬门数量不增**；新增的是一层「域层」——把每个既有门升级为域感知 + 域鲁棒 + 可保形校准，且只紧不松。执行集嵌套改为**逐域点态**：∀D，Exec_v6(D) ⊆ Exec_v5(D) ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **真实世界泛化 → 证书不是绝对真理，而是「域条件命题」，必须把点估计升级为不确定球上的最坏情况证书**。直觉：仿真里说「这一步力矩有 30% 裕度」，真实世界该说「在动力学/感知误差的合理邻域内，最坏情况仍有正裕度」。形式化：定义域 D=(P_dyn, Φ_perc, T, H) 与复合偏移 ρ(D_s,D)，对每个门取域-Lipschitz 常数 L_i，则域鲁棒门等价于把阈值收紧为 τ_i^6 = γ_i·τ_i^4 + L_i·ρ（定理 9）。DSAK 在线估计 ρ 并审计 B1~B7；超半径即 fail-closed 回退保守包络或请求重认证。这把「sim-to-real」翻译成「在域不确定球内所有可能世界都通过」。

2. **零样本泛化 → 门应定义在「不变关系」而非「绝对外观」上，用物体中心等变表示 + 证书模板即时实例化**。直觉：没见过的新杯子，纹理/光照/背景都变了，但「相对位姿—接触流形—抓取力锥」的几何关系没变；把门参数化为这些相对量上的模板 Π_i，就能零样本实例化。形式化：设 nuisance 群 G（纹理/光照/实例身份/背景），不变表示 ψ 满足 ψ(g·x)=ψ(x)，且安全谓词通过 ψ 充分分解 s_i=h_i(ψ,D_c)；纯 nuisance 偏移下门判定逐点不变（定理 10 精确版），近似充分时以 ε_suff 计入收紧。IGR 提供 E(3)-等变物体中心编码器与七门模板。

3. **两者正交，必须同时满足才签发迁移证书；并用保形校准给出有限样本覆盖**。域偏移回答「目标域离源域多远」，不变性充分性回答「门是否只看该看的东西」；任一不满足都不能迁移。CSC 用 split conformal / 自适应保形（ACI）在目标域校正阈值，且更新被投影到「只升不降」，从而不破坏嵌套（定理 11）。诚实边界：无目标域标签时 ρ 不可辨识（命题 1），conformal 的 exchangeability 在持续漂移下不成立，只能给自适应长期误差界而非有限样本保证。

**关键洞见**：v5 回答「提议任意时证书边界是否不变」；v6 回答「证书在未见域/未见物体上是否仍然有效」。七门 kc_i 原样复用；v6 只新增域层四件套：DSAK（域偏移审计）、IGR（不变门表示）、DRG（分布鲁棒证书 = 阈值收紧算子）、CSC（保形安全校准），以及 EFA-v6 迁移感知级联。所有新增算子都满足「只紧不松」的偏序约束，因此逐域嵌套与七锚完备性保持（定理 12）。

**形式化目标（增量）**：
1. 域与偏移：D=(P_dyn,Φ_perc,T,H)，ρ = Σ_j w_j·ρ_j（Wasserstein/MMD 复合），w_j≥0、Σw_j=1；域不确定球 B_ρ(D_s)={D:ρ(D_s,D)≤ρ}。
2. 域鲁棒门：kc_i^rob(x;ρ)=1[inf_{D∈B_ρ(D_s)} s_i(x;D) ≥ τ_i^4]；由 L_i-Lipschitz 得等价收紧 τ_i^6=γ_i·τ_i^4 + L_i·ρ + ε_suff,i。
3. 不变表示与模板：ψ 对 G 不变、对 C 充分；模板 Π_i=(φ_i,τ_i) 在相对几何量上实例化；近似充分缺陷 ε_suff。
4. 保形校准：split conformal 分位 q_{1−α}；ACI 更新 α_t；阈值投影 τ←max(τ,q) 保持单调升。
5. EFA-v6 迁移感知级联：DSAK 域审计 → 超半径走保守包络 → IGR 实例化 → DRG 收紧 → CSC 校准 → 七门级联 → 取边际最大者。
6. Exec_v6(D) = {x ∈ supp(π_θ^FM) : ∧_i kc_i^rob(x;D,ρ)=1} ⊆ Exec_v5(D)，∀D。

**本轮最大风险**：**不变性—安全性权衡不可验证（认证越界）**——零样本泛化迫使门建立在「不变表示」上，但 nuisance 集合 G 是先验划定的语义假设；任何被误划为 nuisance 的安全关键因子会被静默擦除，且不存在分布内检验能发现这种语义错误，系统可能在真实新域上「自信地错」，签发形式合规却实质失真的迁移证书。

### IP-500 CSC：保形安全校准（低频；阈值只升）

```python
@dataclass
class ConformalSafetyCalibration:
    """CSC：split conformal + ACI；更新投影到单调升，保持逐域嵌套"""
    alpha: float = 0.1

    def quantile(self, cal_scores) -> float:
        n = len(cal_scores)
        return np.quantile(cal_scores, min(1.0, (1 - self.alpha) * (1 + 1 / n)))

    def update_aci(self, alpha_t, err_t, eta: float = 0.01) -> float:
        return alpha_t + eta * (err_t - self.alpha)   # 持续漂移下的自适应

    def tighten(self, tau6: dict, q: dict) -> dict:
        # 只允许把阈值往上推（保守方向）：τ ← max(τ, q)
        return {i: max(tau6[i], q.get(i, -np.inf)) for i in tau6}
```

### IP-501 EFA-v6：迁移感知级联

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：七硬门不变 + 域层只紧 + 迁移感知级联"""
    dsak: DomainShiftAuditKernel
    igr: InvariantGateRepresentation
    drg: DistributionallyRobustGate
    csc: ConformalSafetyCalibration
    v5: EvidenceForgingAssemblerV5

    def select(self, x0_state, t_now, rule_id, context):
        rho = self.dsak.estimate_rho(context.target_rollouts)
        audit = self.dsak.audit(context.stats)
        if audit.violation or rho > self.dsak.rho_max:
            return self._conservative_envelope(context, audit)   # fail-closed
        s_emo = self.v5.famk.observe(context.face, t_now)
        gamma = self.v5.famk.gamma(s_emo)
        z = self.igr.psi(context.obs, context.obj)               # 零样本不变特征
        eps_suff = self.igr.sufficiency_audit(context.target_c, ...)
        tau6 = self.drg.robust_threshold(TAU4, gamma, rho, eps_suff)  # 只紧
        tau6 = self.csc.tighten(tau6, self.csc.quantile(context.cal_scores))
        c = build_ctx(context, s_emo, z, rho)
        cands = self.v5.fmpp.propose(c, self.v5.fmpp.K)
        # 与 v5 相同级联；门谓词作用于 z/相对量，阈值换成 τ^6
        surv = [x for x in cands if self._cheap_gates_invariant(x, z, tau6)]
        if not surv:
            return self._conservative_envelope(context, audit)
        finals = self._vack_bck_cascade(surv, z, tau6)          # ≤3 幸存者
        if not finals:
            return self._conservative_envelope(context, audit)
        best = max(finals, key=certified_margin)
        return True, best, 'FORGED_TCE'

    def ecs_v6(self, ..., rho: float) -> float:
        eta_trans = sigmoid((self.dsak.rho_max - rho) / self.dsak.rho_max)
        return self.v5.ecs_v5(...) * eta_trans
```

## 4. 正确性论证（增量更新）

### 引理 45（域-Lipschitz 常数的随机探针估计）

**陈述**：在域对 (D,D+δ) 上以随机输入探针估计 |s_i(x;D)−s_i(x;D+δ)|/ρ(D,D+δ)，取上分位数得 L̂_i；当探针覆盖门敏感方向时，L̂_i 是 L_i 的高概率上界，误差 O(√(log(1/δ)/n_probe))。∎

**诚实边界**：探针未覆盖的敏感方向会低估 L_i，导致 ρ 半径偏大；因此 L̂_i 取保守放大系数 1.25 并周期性重标定。

### 引理 46（不变性—充分性分解）

**陈述**：对任意门分数 s_i，存在分解 s_i(x;D) = h_i(ψ(x),D_c) + e_i(x)，其中 e_i 为 ψ 未捕获的分量。若 ψ 对 G 不变，则 e_i 对 G 的依赖即「被擦除的安全信息」；ε_suff = sup|e_i|。当 ε_suff=0 时定理 10 精确成立。∎

**含义**：零样本能力与安全性不是免费的——不变性越强，可能擦除的 critical 信息越多，ε_suff 越大；这是本轮核心权衡的数学形式。

### 命题 1（迁移证书不可辨识）

见 CERTCALC-v6。**含义**：DSAK 给出的是下置信界 ρ̂_LCB，不是 ρ 的真值；任何「零风险迁移」声明都超出可证明范围。

### 定理 v6（逐域三重保证，总装）

**陈述**：在 v4 (B1)~(B6)、v5 (B7) 及新增 (B8) 门分数域-Lipschitz、(B9) 不变表示充分性缺陷 ≤ ε_suff 下：
(i) 逐域嵌套：∀D，Exec_v6(D) ⊆ Exec_v5(D) ⊆ … ⊆ Exec_v29；
(ii) 域迁移：对 D_t∈B_ρ(D_s)，x∈Exec_v6 ⇒ 七门在 D_t 下均以原阈值 τ^4 通过（定理 9）；
(iii) 零样本：纯 nuisance 偏移（D_c 不变）下门判定逐点不变（定理 10 精确版）；
(iv) 覆盖：可交换校准下保形覆盖 ≥ 1−α；漂移下 ACI 长期误差 ≤ α+O(η)（定理 11）；
(v) 七锚完备性保持（定理 12）；
(vi) 不可辨识性：ρ 只能给下置信界，迁移证书为经验判断（命题 1）。

**证明**：(i)(ii) 由定理 9；(iii) 由定理 10；(iv) 由定理 11；(v) 由定理 12；(vi) 由命题 1。∎

**诚实声明**：(B8) L_i 的探针估计有方向盲区；(B9) 不变性/充分性是对 G、C 划分的语义假设，**分布内不可验证**；保形在持续漂移下只给自适应长期界；保守包络会牺牲任务可用性；可变形/铰接物体使模板的刚体假设失效。

## 7. 本轮最大风险（最终确认）

**一句话**：**不变性—安全性权衡不可验证（认证越界）**——零样本泛化迫使门建立在「不变表示」上，但 nuisance 集合 G 是先验划定的语义假设；任何被误划为 nuisance 的安全关键因子会被静默擦除，且不存在分布内检验能发现这种语义错误，系统可能在真实新域上「自信地错」，签发形式合规却实质失真的迁移证书。
