# 第 66 轮（承接第 65 轮「VISTA 视觉知情故障归因」IP-214~223；灵感循环第 1 轮；本轮灵感：「多模态大模型」×「末端位姿」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述最大风险一针见血：**归因依赖「故障属于有限假设集、且视觉与几何失效相互独立」；真实故障常是未知复合类型，透明/镜面/对抗 patch 会让视觉与几何共享同一 OOD 失效源，FIR 于是把未知复合故障强行归入最近假设、只膨胀错误的球——单点故障升级为「归因错误的复合故障」，而且系统因「已经归因」更自信地继续执行（A88）。** 本轮不追加第六个模态，也不要求更细的故障标签，而是换一个更底层的提问：
>
> **如果归因本身可能是错的，安全还能不能成立？能否让多模态大模型在有限故障库之外提出「可证伪」的新假设，同时把安全从「归因正确」中彻底解耦？**
>
> 本轮核心命题：**把「故障可归因」升级为「归因可选、安全必达」——用末端位姿 SE(3) 作为所有模态与所有接触伤害的共同锚点，用多模态大模型作为「语义→可监控位姿约束」的编译器（只提案、不作真值），用归因无关安全包络兜住未知复合故障。**

## 0. 直觉与动机

**灵感 1（多模态大模型 → 语义→约束编译器，而非新的状态估计器）**
直觉：MLLM 的长处是开放词表、跨模态指代、把模糊指令分解成步骤、并对"哪里反常"给出语言解释；短处同样清楚：没有度量精度、进不了实时环、会幻觉、输出非确定、校准很差。因此把它放进实时控制或当作真值，必然重演第 65 轮的单点故障。它真正有生产力的位置是**假设发生器 + 约束编译器**：把"这个场景应该满足什么"与"这次异常可能是什么"写成自然语言，再编译成**可监控的谓词**；编译不出来的句子不算证据、不能进安全集。这样 VISTA 的封闭故障库被打开，但幻觉没有进入安全论证。

**灵感 2（末端位姿 → 接触伤害的共同瓶颈 + 异构模态的共同坐标系）**
直觉：末端位姿 T∈SE(3) 是机器人**唯一被直接写出的量**。无论故障来自几何先验、F/T 偏置、接触模型还是视觉欺骗，要造成接触伤害，最终都得经过末端位姿（及其导数）这一道窄门。它只有 6 个自由度，却是所有模态都能投影进来的公共坐标系：编码器正运动学给 T^fk、视觉 6D 位姿给 T^vis、接触运动学给 T^ct、本体/IMU 给 T^imu。四个估计器的失效结构不同，它们在 SE(3) 里的**不一致模式**本身就是一种不依赖故障库的故障签名。必须诚实：位姿是接触伤害的**必要**通道而非充分条件（连杆/本体碰撞在此外），且若所有估计器**共模同向出错**，一致性判据会失效——这正是最后的硬包络要兜底的地方。

**灵感 3（合流 → SCOPE：Semantic Contract over Pose-space for End-effectors）**
直觉：MLLM 把语义编译成"末端位姿在什么集合里、以什么速度、沿什么法向、离什么至少多远"的**位姿契约**；每个契约都带四个字段：**出处**（哪条语义/哪个模型提出）、**可监控性**（实时/慢/离线）、**证伪记录**（敏感性/特异性/覆盖率）、**逃生动作**（违约时做什么）。位姿多估计器一致性（PCR）为契约提供运行时证据；开集假设（POSE-H）让未被契约覆盖的位姿残差模式以"novel"身份进入系统；证伪账本（FL）决定哪条 MLLM 断言有资格影响安全。第 65 轮是"几何-技能-干扰-接触-归因"五层，SCOPE 在其上再加一层"**契约**"，并把位姿作为贯穿五层的公共坐标。

**灵感 4（关键转折 → 安全与归因解耦：attribution-independent safety）**
直觉：第 65 轮定理 7 的安全结论**依赖归因正确**，于是"归因错误"直接变成"安全失效"。本轮把证书拆成两层：**硬包络 E_hard**（关节/速度/自碰撞/工作空间/力限，由不依赖学习模型的实时控制器强制）与**软包络 E_soft(H)**（由归因后验与契约收紧）。执行前缀必须始终留在 E_hard；对可信集（含 novel 桶）内每个假设验证 E_soft。**归因错了只会让 E_soft 变大、性能变差，不会让执行越出 E_hard**。这把第 65 轮"更自信地错误执行"改成"更保守地安全执行"。

**灵感 5（VISTA 组件的原位升级）**
- **FIR → FIR-O**：假设集变为 ℋ_known ∪ ℋ_novel；未知残差不强行贴标签，而用残差模式参数化。
- **CSC → CSC-P**：认证在位姿契约空间做，k* 同时受 E_hard 与 E_soft 约束。
- **AFA → AFA-S**：探针扩为物理/视觉/语义三类，可主动换视角、定向问 MLLM、必要时问人。
- **RSC-V → RSC-P**：不确定球增 r_pose（多估计器分歧）与 r_sem（语义契约不确定），只膨胀被归因或被判 novel 的分量。
- **WCV-V → WCV-P**：搜索域增位姿契约可行域；novel 时退化为 E_hard。
- **CSP-V → CSP-P**：以契约为边规划；插入 `view_change`、`pose_recalibrate`、`query_human` 元技能。
- **AIC-V → AIC-P**：干扰集增 MLLM 提示注入、位姿欺骗（假 marker/镜面跳变）、共模位姿错误。
- **J_vista → J_scope**：证书增 contract_set、pose_residual、novel_score、semantic_debt、ais_envelope_id。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（SCOPE 闭环）**：SCOPE = (VISTA, EPC, MSC, PCR, POSE-H, FL, AIS, CSC-P, AFA-S, RSC-P/WCV-P/CSP-P, AIC-P, J_scope)。不变式：**MLLM 推理、契约编译、开集扩展、证伪记账只在语义流；实时流只做位姿残差采集、契约监控、认证前缀与硬包络，零学习写操作。**
- **定义 234（末端位姿与多估计器）**：T_t=(R_t,p_t)∈SE(3)，twist ξ_t∈se(3)。估计器集 E={fk,vis,ct,imu}，各给 T_t^e 与协方差 Σ_e；各估计器失效模式不同。
- **定义 235（位姿一致性残差 PCR）**：右不变误差 e^{ab}=log((T^a)^{-1}T^b)∈se(3)，加权残差 ‖e‖_{Σ_ab}；一致性图 G 的**锚点** a*=最大一致子集。残差模式向量 r_pose 作为不依赖故障库的签名。
- **定义 236（位姿契约 EPC）**：C=(g,φ,prov,mon,cert,esc)：g 为位姿轨迹上的约束（位姿管、方向锥、净空、速度、接触流形、力-位姿对齐），prov 为出处，mon∈{realtime,slow,offline}，cert=(sens,spec,cov)，esc 为逃生动作。
- **定义 237（语义→约束编译器 MSC）**：MLLM M 把（指令、场景 token、异常语言、候选故障）映射为断言集；编译函数 κ 把断言映射为 (T,y,ρ) 上的谓词，或返回 ⊥（不可编译）。只有编译成功的断言成为契约；MLLM 的采样非确定性用"约束取并、松弛取交"处理：K 次采样只允许**增加**约束，绝不因单次采样**放宽**安全约束。
- **定义 238（可证伪性与语义债务 FL）**：每条编译断言 i 有 (sens_i,spec_i,cov_i,cost_i,mon_i)；只有 sens≥τ_s、spec≥τ_p 才进入**可信安全集**。语义债务 D_sem=Σ 未验证断言对决策的影响；D_sem≤D_max，否则隔离为"仅供诊断"。不可监控的断言一律拒绝。
- **定义 239（POSE-H 开集假设）**：ℋ=ℋ_known∪ℋ_novel；novel 分数 s_novel 由位姿残差模式对已知签名流形的 conformal p 值给出；p<α_novel 时开 H_new，用**残差模式 θ_new 参数化**。MLLM 可给 H_new 起名/解释，但安全处置只用 θ_new 的最坏包络。
- **定义 240（位姿锚定归因）**：在 ℋ_known 上算后验；novel 概率高时不强行贴最近标签，而用"残差模式条件包络"进入安全层。归因状态 ∈ {attributed, novel, ambiguous}。
- **定义 241（归因无关安全包络 AIS）**：E_hard 由关节/速度/自碰撞/工作空间/力限构成，实时控制器强制，不依赖学习模型；E_soft(H) 由契约与归因收紧；可信集含 novel 桶。执行前缀须在 E_hard 内，且对可信集每个 H 在 E_soft(H) 内。
- **定义 242（位姿契约认证前缀 CSC-P）**：k*_pose=最大 k 使前缀在 E_hard ∧ ∩_{H∈credible}E_soft(H) 内，且越界概率≤α_pose；k*≤m（不可逆视界）。
- **定义 243（语义/信息寻求探针 AFA-S）**：探针集含物理（press/rub/tap/lift）、视觉（换视角/主动光）、语义（定向询问 MLLM、请求人类确认）；目标为最大化对 (known/novel) 的互信息并降低 D_sem，约束为预测位姿/力在 E_hard 内。
- **定义 244（RSC-P / WCV-P）**：不确定半径拆为 r_geo/r_force/r_model/r_pose/r_sem；只膨胀被归因或 novel 的分量；novel 时 E_soft→E_hard，搜索域收缩到硬包络。
- **定义 245（CSP-P 契约级规划）**：以位姿契约为边，每条边需 Valid(J_scope) ∧ k*_pose≥1；契约出处与可监控性入图；可插入 view_change/pose_recalibrate/query_human。
- **定义 246（AIC-P 对抗认证）**：ℰ_P=ℰ_V×ℰ_mllm×ℰ_pose；前者含提示注入、越狱、错误常识；后者含假 marker、镜面跳变、标定漂移、共模位姿错误。证书在最坏情况取并。
- **定义 247（J_scope 证书）**：J_scope=(J_vista, contract_set_hash, contract_provenance, pose_residual, novel_score, semantic_debt, k*_pose, ais_envelope_id, mllm_model_ver, fl_hash, aic_p_ver)。
- **定义 248（SCOPE 算子）**：语义流 [VISTA→MSC 编译契约→PCR→POSE-H/FIR-O→FL→AIS→CSP-P→CSC-P→AFA-S]；实时流 [位姿多估计器读→PCR→契约监控→E_hard/E_soft→认证前缀→派发→违约早停]。

## 2. 关键算法骨架

```python
# MSC：MLLM 只提案，编译失败/未验证的断言不得进安全集
claims = mllm.propose(instruction, scene_tokens, anomaly_text, K=8)
contracts, deferred = [], []
for c in claims:
    pred = compiler.compile(c)                 # 语义 → 位姿谓词
    if pred is None:                           # 不可监控：拒绝
        rejected.append((c, 'unfalsifiable')); continue
    if not ledger.validated(c):                # 未通过证伪账本
        deferred.append(c); continue
    contracts.append(EPC(pred, prov=c, mon=pred.monitor, cert=ledger.stats(c)))

# PCR：位姿锚点 + 残差模式
Ts = {e: estimator[e].read() for e in ('fk', 'vis', 'ct', 'imu')}
anchor, r_pose = pose_consistency.max_consistent(Ts)
novel, p_novel = pose_consistency.novel_score(r_pose, known_manifolds)

# 安全：归因无关
credible = set(post) | ({'H_novel'} if novel else set())
E_hard = hard_envelope(joint_lim, vel_lim, self_collision, workspace, f_lim)
E_soft = {h: contracts.intersect(h) for h in credible}
k_star = csc_p.certified_prefix(A, E_hard, E_soft, m, alpha_pose)
for a in A[:k_star]:
    dispatch(a)
    if monitor.pose_contract_violated() or monitor.pose_residual_jump():
        break                                    # 早停 → 重新归因/重编译
```

## 3. 保证概要与推导要点

- **引理 9（位姿锚定的故障隔离）**：n 个独立位姿估计器中若故障者 < n/2 且误差方向不成共模，则最大一致子集等于健康集；PCR 无需故障库即可隔离估计器故障。
- **引理 10（语义约束的单调安全）**：MLLM 只能增加约束、不能移除安全约束；K 次采样取约束并集 ⇒ 可行集只减不增。幻觉最多造成过度保守，不能造成越界。
- **引理 11（归因无关安全）**：E_hard 由独立实时控制器强制；可信集含 novel 桶。则 P[越界]≤α_pose+α_novel+α_est，与归因是否正确无关；归因错误只改变 E_soft 的大小。
- **定理 9（SCOPE 端到端）**：Valid(J_scope) ⇒ 执行在 E_hard ∧ 可信集 E_soft 内 ∧ 未验证 MLLM 断言未进安全集 ∧ 归因状态为 attributed/novel/ambiguous 之一且处置一致。
- **定理 10（开集扩展的安全-性能分离）**：加入 novel 假设与语义约束使可行集单调收缩、安全不变；性能损失上界由 |ℋ_novel|、D_sem 与 k*_pose 控制；AFA-S（含问人）可降低 D_sem。
- **实时性**：MLLM/编译/POSE-H/FL 全在语义流；实时流只增 PCR（<0.1ms）、契约监控（<0.1ms）、硬包络投影与早停，目标 ≤2.6ms。

## 5. 本轮最大风险

**一句话**：SCOPE 的安全论证依赖「位姿多估计器的错误不共模、且硬包络 E_hard 的物理模型（关节/连杆/力限）本身正确」；一旦发生共模位姿错误（标定漂移与视觉欺骗同向叠加）或硬包络建模遗漏（连杆碰撞、工具形变），所有模态会在同一个错误位姿上"一致"，AIS 会把实际碰撞的位姿认证为安全，而 MLLM 契约只会在此之上更保守而非纠正——这是整个「归因无关安全」所依赖的隐藏假设（A94）。

## 2. 形式化定义（完整版）

**定义 233（SCOPE 闭环）** SCOPE 是 VISTA 的「归因可选、安全必达」升级：在 VISTA 的「语义流 ∘ 实时流」骨架上挂载 EPC（位姿契约）、MSC（语义编译）、PCR（位姿一致性）、POSE-H（开集假设）、FL（证伪账本）、AIS（归因无关安全包络）、CSC-P（位姿契约前缀）、AFA-S（语义探针），并原位升级 RSC-V→RSC-P、WCV-V→WCV-P、CSP-V→CSP-P、AIC-V→AIC-P、J_vista→J_scope。不变式：**MLLM 推理、语义编译、开集扩展、证伪记账、契约生成只发生在语义流与低频线程；实时路径只做多源位姿残差采集、契约监控、硬/软包络投影、认证前缀与早停，零学习写操作。**

**定义 234（末端位姿与多估计器）** 记末端工具/接触坐标系位姿
T_t=(R_t,p_t)∈SE(3)，其李代数 twist 为 ξ_t=(v_t,ω_t)∈se(3)。
位姿估计器集 E={fk,vis,ct,imu}：
- T^fk：关节编码器 + 标定正运动学；
- T^vis：视觉 6D 位姿（marker/深度/点云配准）；
- T^ct：接触运动学（由接触点、法向与力旋量反解）；
- T^imu：本体感觉/IMU 短时积分。
每个估计器给 (T_t^e, Σ_e)，失效模式互不相同（标定漂移、遮挡/反光、接触点歧义、积分漂移）。**位姿是接触操作伤害的必要通道：任何接触伤害事件必然对应一个位姿-接触事件；但非接触连杆碰撞与工具形变不在位姿锚的覆盖内，须由 E_hard 的几何/力模型另行处理。**

**定义 235（位姿一致性残差 PCR）** 对任意两估计器 a,b，定义右不变误差
e^{ab}(t)=log((T_t^a)^{-1}T_t^b)∈se(3)，
加权残差 d^{ab}=‖e^{ab}‖_{Σ_ab^{-1}}，Σ_ab=Σ_a+Σ_b。一致性图 G=(E,{(a,b):d^{ab}≤q_pose})，其中 q_pose 为 split-conformal 阈值。**锚点** a*(t)=G 的最大一致子集（等价于最大团/稳健共识）。残差模式向量
r_pose(t)=[d^{ab}(t)]_{a<b} ⊕ [e^{ab}(t)]_{a<b}
既用于实时监控，也作为不依赖故障库的开集签名。**共模检测**：若 G 在 E 上完全一致但某单通道的物理先验（如视觉重投影残差、编码器电流一致性）单独越界，则记 `common_mode_suspect=True`，AIS 直接退化为 E_hard。

**定义 236（位姿契约 EPC）** 位姿契约
C=(g,φ,prov,mon,cert,esc)
由六元组构成：
1. **约束 g**：作用于 T_{t:t+H} 的可行域，支持以下原子：位姿管 `‖p−p_ref‖≤r_p`、方向锥 `∠(R,R_ref)≤θ_R`、接近方向 `n^T R e_z≤−cosθ_n`、净空 `dist(T,F_forbid)≥d_min`、速度 `‖ξ‖≤v_max`、接触流形 `T∈ℳ_contact`、力-位姿对齐 `∠(f,R n)≤θ_f`。复合契约取交集。
2. **φ**：契约参数（参考位姿、半径、法向、阈值）。
3. **prov**：出处，取自 {instruction, MLLM, geometry, skill, safety}；安全类契约只能由 `safety` 出处生成或由 `MLLM` 提案后经 FL+AIS 双重验证。
4. **mon**：可监控性，`realtime`（位姿管/速度/净空/方向锥）、`slow`（接触流形/形变）、`offline`（语义可用性）。
5. **cert**：证伪记录 (sens,spec,cov)，见定义 238。
6. **esc**：违约逃生动作（`stop`/`retreat`/`compliant_hold`/`query_human`）。
可行域 A(C)={T_{t:t+H}: g(T)≤0}。**安全集只允许由 `mon=realtime` 且 `cert` 达标的契约收紧；slow/offline 契约只进入规划与性能，不进入硬安全论证。**

**定义 237（语义→约束编译器 MSC）** 设多模态大模型 M 接收提示
P_t=(instruction, scene_tokens, anomaly_text, ℋ_known, 当前 ρ, 当前 T^e)
并采样 K 条断言 {c_k}_{k=1}^K（自然语言/结构化混合）。编译函数
κ(c) ∈ {谓词 g_c（含 mon、参数）, ⊥}
把断言映射为定义 236 的可监控原子，或返回 ⊥ 表示不可编译。只有 κ(c)≠⊥ 的断言可成为契约。
**非确定性与安全的合成规则**（本定义的关键）：
- 对**加约束**类断言：安全可行域取所有采样的交集
  A_safe = ⋂_{k: κ(c_k)≠⊥} A(C_k) ⊆ A_base；
- 对**放宽约束**类断言：默认拒绝；仅当 (i) 通过 FL 的敏感性/特异性检验、(ii) 经 AIS 证明放宽后仍不越出 E_hard、(iii) 由 `safety` 出处共同签名，才允许，且一次只允许一条；
- 性能/规划用采样共识（多数/置信加权），安全永远用并集（即最严交集）。
因此 MLLM 的采样随机性**不能扩大**安全可行域。

**定义 238（可证伪性与语义债务 FL）** 每条编译断言 c_i 维护证伪记录
cert_i=(sens_i,spec_i,cov_i,cost_i,mon_i)，
由离线对抗集与在线回放统计得到。可信安全集
𝒯={c_i: sens_i≥τ_s ∧ spec_i≥τ_p ∧ mon_i∈{realtime,slow}}。
**语义债务**定义为未验证断言对决策的加权影响
D_sem=Σ_i w_i·1[c_i∉𝒯]·infl_i，
其中 infl_i 为断言 i 若为假时对可行域/前缀长度的影响。约束 D_sem≤D_max；超限时把影响最大的断言移入**隔离区**（仅日志/诊断，不参与规划与安全）。不可监控断言（κ=⊥ 或 mon=offline 且未获人工确认）永远不计入安全证据。证伪账本支持双向更新：新证据通过则晋升，失败则降级并触发重编译。

**定义 239（POSE-H 开集位姿假设）** 假设集
ℋ=ℋ_known∪ℋ_novel。
对当前残差模式 r_pose，用已知故障签名流形 {ℳ_h}_{h∈ℋ_known} 的 conformal 非一致性分数
s_novel(r_pose)=min_{h∈ℋ_known} dist(r_pose,ℳ_h)，
在标定集上取 p 值 p_novel=(1+Σ 1[s_novel^{(i)}≥s_novel])/(n+1)。若 p_novel<α_novel，则开新假设
H_new = H_new(θ_new)，θ_new = 与 r_pose 一致的最坏残差模式参数集（而非语义标签）。
MLLM 可输出 H_new 的**语言名与解释**（写入审计），但安全处置只使用 θ_new 的最坏包络。**这使系统能在不枚举故障类型的情况下，安全地处理未知故障。**

**定义 240（位姿锚定归因）** 在 ℋ_known 上计算后验 P(H|ρ)（沿用第 65 轮 FIR 的似然）。归因状态为
status ∈ {attributed, novel, ambiguous}：
- attributed：max_{ℋ_known} P(H|ρ)≥1−δ_fi 且 p_novel≥α_novel；
- novel：p_novel<α_novel；
- ambiguous：其余。
**不强行贴最近标签**：novel/ambiguous 时，credible 集显式加入 H_novel 或全部 ℋ_known，安全层使用最坏包络。归因标签只影响 E_soft 的松紧与性能，不影响 E_hard。

**定义 241（归因无关安全包络 AIS）** 定义两层包络：
- **硬包络** E_hard = {T: 关节限位 ∧ 速度/加速度限 ∧ 自碰撞距离 ∧ 工作空间 ∧ 力/力矩限}，由独立的实时安全控制器强制，参数来自标定与机械设计，**不含任何学习模型**；
- **软包络** E_soft(H)=E_hard ∩ A(C(H))，由归因假设 H 与契约集合收紧。
设可信集
credible = supp_δ(P(·|ρ)) ∪ ({H_novel} if status=novel else ∅)。
AIS 要求执行前缀 A_{1:k} 满足
∀s≤k: T_s∈E_hard ∧ ∀H∈credible: T_s∈E_soft(H)。
证书 `ais_envelope_id` 记录 E_hard 版本、credible 集与最坏包络哈希。**核心性质：E_hard 与归因无关，故归因错误不会使执行越出 E_hard；归因错误只使 credible 变大、E_soft 变小，从而表现为性能/效率损失。**

**定义 242（位姿契约认证前缀 CSC-P）** 对动作块 A 与候选前缀 k，定义位姿前向可达集 R_k(A)（由名义模型 + 误差界滚动展开）。选
k*_pose = max{ k≤min(H,m): R_k(A)⊆E_hard ∧ ∀H∈credible, R_k(A)⊆E_soft(H) ∧ P[∃s≤k: 越界]≤α_pose }。
其中越界概率由 PCR 的 conformal 残差界 + 力/滑移界（沿用第 65 轮）联合给出。执行器只执行 k*_pose 步，随后强制重规划、重归因与重编译契约。**k*≤m 保证即使未知故障在块首激活，也能在越过不可逆点前停下。**

**定义 243（语义/信息寻求探针 AFA-S）** 探针集
A = {press, rub, tap, lift, visual_probe, view_change, pose_recalibrate, query_mllm, query_human, null_test}。
选择
a* = argmax_{a∈A} I( (status, θ_new); ρ_{1:3}(a) | ρ_{1:2} ) + λ_d·ΔD_sem(a) − λ_c·cost(a)
s.t. 预测位姿轨迹⊆E_hard、预测力≤f_safe(φ̂,f̂_vis)、预测形变≤ε_strain、视觉可早停。
- 易损物体禁用接触探针，优先 `view_change`/`query_human`；
- 当自主信息增益 <δ_fi 时，`query_mllm`（定向问题）与 `query_human`（停机确认）是合法的**语义探针**，其代价显式计入；
- 探针目的从第 65 轮的"分离已知故障"扩展为"**区分 known/novel 并降低语义债务**"。

**定义 244（RSC-P / WCV-P 位姿锚定校准与鲁棒编译）** 维护五个不确定半径
(r_geo, r_force, r_model, r_pose, r_sem)
与视觉/语义信任权重 (w_vis, w_sem)。RSC-P 只膨胀被归因或被判 novel 的分量：
- H_geo→r_geo↑；H_force→r_force↑ 且零力窗重标定；H_model→r_model↑ 并切柔顺；
- 位姿估计器故障→r_pose↑ 并触发 pose_recalibrate；
- novel→r_pose/r_sem↑，且 E_soft→E_hard（最保守）。
融合半径 r=√(r_geo²+r_force²+r_model²+r_pose²+r_sem²) 进入 WCV-P。搜索域
B(φ̂,r) ∩ 𝒢(g) ∩ K(μ̂) ∩ ℱ(f_lim) ∩ A(C) ∩ 𝒱，
其中 A(C) 为位姿契约可行域，𝒱 为视觉可观测性约束。CVaR 尾部 n_worst=8；归因模糊时按后验加权做归因边缘化尾部；novel 时只用 E_hard 采样；交集为空则回退 E_hard 并置 `attribution_conflict=True`。

**定义 245（CSP-P 契约级规划）** 在 CSP 的层级 A* 上以**契约化块**为边：每条边 e 需
Valid(J_scope) ∧ k*_pose(e)≥1 ∧ 该块位姿签名与技能 σ 的契约签名分布 𝒟_σ 的 Mahalanobis 距离≤τ_contract。
规划器可插入元技能：`view_change`（主动视觉，区分 H_vis/H_geo）、`pose_recalibrate`（重标定位姿锚点）、`query_human`（语义探针，降低 D_sem）、`null_test`、`fi_probe`。软约束代价增
λ_fi·H(P(H|ρ)) + λ_sem·D_sem + λ_k·Σ hinge(k*_pose−k_req)。
契约出处入图：任何由 MLLM 提出但未进 𝒯 的契约只能作为"建议边"，不得用于安全路径。

**定义 246（AIC-P 对抗认证）** 干扰集
ℰ_P = ℰ_V × ℰ_mllm × ℰ_pose，
其中 ℰ_V 沿用第 65 轮（视觉对抗/透明/遮挡/时序错位），新增：
- ℰ_mllm：提示注入、越狱、错误常识、语言歧义、诱导放宽安全约束；

认证在最坏情况下重算：n_cert 128→160（其中 32 给 MLLM，32 给位姿/共模）。J_dir 增 `mllm_prompt_ver`、`pose_estimator_ver`、`common_mode_flag`。**共模下不要求归因正确，只要求 `common_mode_suspect=True` 并退化为 E_hard；若 E_hard 自身被物理建模遗漏击穿，则必须靠外部急停/人。**

J_scope=(J_vista, contract_set_hash, contract_provenance, pose_residual, novel_score, semantic_debt, k*_pose, ais_envelope_id, mllm_model_ver, fl_hash, aic_p_ver)。

### IP-226 PCR（位姿一致性锚定）

```python
class PoseConsistency:
    """四源位姿的右不变一致性；实时只读残差，锚点与开集分数在语义流细化。"""
    def __init__(self, q_pose, q_common=3.0, alpha_novel=0.05):
        self.q_pose, self.q_common, self.alpha_novel = q_pose, q_common, alpha_novel

    def max_consistent(self, Ts):
        names = list(Ts)
        ok = {}
        for i, a in enumerate(names):
            for b in names[i + 1:]:
                e = se3_log(se3_inv(Ts[a]) @ Ts[b])
                d = float(np.sqrt(e @ e))          # 简化：单位协方差
                ok[(a, b)] = d <= self.q_pose
        # 最大一致子集（n≤4，直接枚举）
        best = max(combinations(names, 1),
                   key=lambda S: (all(ok.get((a, b), False)
                                      for a, b in combinations(sorted(S), 2)),
                                  -len(S)))          # 取簇内一致者
        anchor = [S for S in combinations(names, len(best))
                  if all(ok.get((a, b), False) for a, b in combinations(S, 2))]
        anchor = max(anchor, key=len)
        r_pose = np.array([d for (a, b), d in ok.items()], float)
        return anchor, r_pose

    def novel_score(self, r_pose, known_manifolds, calib_scores):
        s = min(dist_to_manifold(r_pose, M) for M in known_manifolds)
        p = (1 + np.sum(calib_scores >= s)) / (len(calib_scores) + 1)
        return p < self.alpha_novel, p

    def common_mode_suspect(self, per_estimator_health):
        # 所有对都一致但单通道物理先验越界 → 可能是共模
        return all(per_estimator_health.values()) is False and \
               sum(not v for v in per_estimator_health.values()) >= 2
```

### IP-225 MSC + IP-228 FL（语义编译与证伪账本）

```python
class SemanticCompiler:
    """MLLM 只提案；编译失败或未验证的断言不得进安全集。"""
    def __init__(self, mllm, k_samp=8):
        self.mllm, self.k_samp = mllm, k_samp

    def compile(self, prompt):
        claims = self.mllm.sample(prompt, K=self.k_samp)   # 非确定采样
        contracts, rejected, deferred = [], [], []
        for c in claims:
            pred = kappa(c)                                # 语义 → 位姿谓词
            if pred is None:
                rejected.append((c, 'unfalsifiable')); continue
            cert = FL.stats(c)
            if not (cert.sens >= TAU_S and cert.spec >= TAU_P):
                deferred.append((c, cert)); continue
            if c.type == 'relax':
                if not (FL.validated(c) and AIS.relax_ok(pred)):
                    rejected.append((c, 'unsafe_relax')); continue
            contracts.append(EPC(pred, prov=c.prov, mon=pred.monitor,
                                 cert=cert, esc=c.escape))
        # 安全取最严交集；性能用共识
        A_safe = intersect([A(C) for C in contracts])
        return contracts, A_safe, rejected, deferred


class FalsificationLedger:
    """证伪记录 + 语义债务；超限则隔离影响最大的断言。"""
    def __init__(self, tau_s=0.9, tau_p=0.85, D_max=0.2):
        self.tau_s, self.tau_p, self.D_max = tau_s, tau_p, D_max
        self.stats = {}

    def validated(self, c):
        s = self.stats.get(c.id)
        return s is not None and s.sens >= self.tau_s and s.spec >= self.tau_p

    def semantic_debt(self, contracts, infl):
        d = sum(0.0 if self.validated(c) else infl[c.id] for c in contracts)
        return d

    def quarantine(self, contracts, infl):
        while self.semantic_debt(contracts, infl) > self.D_max:
            c = max(contracts, key=lambda z: (not self.validated(z)) * infl[z.id])
            contracts.remove(c); self.quarantined.add(c.id)
        return contracts
```

### IP-229 AIS + IP-230 CSC-P（归因无关安全前缀）

```python
class AttributionIndependentSafety:
    """E_hard 不依赖学习模型；归因错误只缩小 E_soft，不越出 E_hard。"""
    def __init__(self, hard, alpha_pose=0.05):
        self.hard, self.alpha_pose = hard, alpha_pose

    def credible(self, post, status, delta=0.05):
        base = {h for h, p in post.items() if p >= delta}
        return base | ({'H_novel'} if status == 'novel' else set())

    def certified_prefix(self, A, contracts, post, status, m):
        cred = self.credible(post, status)
        k_best = 0
        for k in range(1, min(len(A), m) + 1):
            reach = forward_reachable(A[:k])               # 名义 + 误差界
            in_hard = reach.subset(self.hard)
            in_soft = all(reach.subset(contracts.soft_for(h)) for h in cred)
            if not (in_hard and in_soft):
                break
            if violation_prob(A[:k], cred, E_hard=self.hard) <= self.alpha_pose:
                k_best = k
            else:
                break
        return k_best

    def relax_ok(self, pred):
        # MLLM 提议放宽：必须仍在 E_hard 内，且不删除「安全」出处契约
        return A_of(pred).superset_of(self.hard) or False
```

## 4. 推导

**引理 9（位姿锚定的故障隔离）** 设有 n 个位姿估计器，其中故障集 F，|F|<n/2；健康估计器两两误差 ≤q_pose，故障者与健康者的误差 >q_pose，且故障者之间不形成同向共模（即不存在一个错误位姿使所有故障者与 F 内多数一致）。则一致性图 G 的最大一致子集为健康集 E\F，锚点 a*=E\F。
证明：健康估计器两两连边，构成大小 n−|F|>n/2 的团；任何包含故障者的团至多 |F|<n/2 个故障者，且因故障者与健康者不连边，该团大小不超过 |F| 加上它与健康者的共同邻域；由 |F|<n/2 及非共模假设，不存在更大的团。故最大一致子集即健康集。∎
推论：若所有估计器共模同向出错，G 可能仍然是完全图，此时引理不适用，必须由定义 235 的 `common_mode_suspect` 与 E_hard 接管。

**引理 10（语义约束的单调安全）** 设基准安全可行域为 A_base（由 E_hard 与已验证的 safety 契约给出）。MSC 的安全合成规则取所有编译断言的可行域交集：
A_safe = A_base ∩ ⋂_{k} A(C_k)。
则 A_safe⊆A_base，且新增任意断言（即使来自幻觉）只能使 A_safe 进一步收缩。K 次采样的非确定性不改变此单调性：采样集合越大，交集越小。对"放宽"类断言，规则要求 FL 验证 + AIS 证明不越出 E_hard，故合法放宽也不可能越过 A_base。∎
因此，MLLM 的幻觉在安全维度只能造成**过度保守**（可行域过小、k* 过短、任务失败），不能被转化为越界伤害。

**引理 11（归因无关安全）** 设 E_hard 由不依赖学习模型的实时控制器强制；credible 包含归因支持集与 novel 桶；执行前缀由 CSC-P 在 E_hard ∧ ∩_{H∈credible}E_soft(H) 内认证。设 PCR 残差界、力/滑移界与 novel conformal 的覆盖失败概率分别为 α_est、α_force、α_novel，则单块越界概率
P[越界] ≤ α_pose + α_novel + α_est + α_force，
其中 α_pose 为 CSC-P 的块级预算。该界不包含"归因是否正确"这一事件。归因错误只会使 credible 变大、E_soft 变小、k* 变小，因而**降低**越界概率；归因正确只是放松了性能约束。∎
这是本轮与第 65 轮定理 7 的根本区别：第 65 轮的安全蕴含归因正确，本轮的安全与归因解耦。

**定理 9（SCOPE 端到端归因-安全）** 在 A88–A94 下：
1. **安全不依赖归因**：由引理 11，Valid(J_scope) ⇒ 执行在 E_hard 内；即使归因错误或未知故障，也不越出硬包络。
2. **未知可被安全容纳**：由定义 239/240，p_novel<α_novel 时开 H_new，用 θ_new 最坏包络并退到 E_hard；不强行贴最近标签（修正第 65 轮风险 1）。
3. **MLLM 不能使系统更不安全**：由引理 10，MLLM 只能收紧可行域；放宽需 FL+AIS 双重签名；未验证断言被隔离（定义 238）。
4. **位姿锚提供无故障库的隔离**：由引理 9，非共模、少数故障时锚点排除故障估计器；共模时显式降级到 E_hard（定义 235/246）。
5. **优雅降级**：视觉失效→w_vis↓、PCR 用 fk/ct/imu；位姿估计器失效→r_pose↑、pose_recalibrate；MLLM 失效/注入→契约拒绝、退回 VISTA/E_hard；两者同时失效→common_mode_suspect + safe_idle/retreat。
6. **可审计**：J_scope 记录每条契约的出处、可监控性、证伪记录、语义债务与位姿残差，回答"为什么允许执行这 k* 步"。∎

**定理 10（开集扩展的安全-性能分离）** 设加入 novel 假设与 MLLM 契约前的可行域为 A_0，加入后为 A_1。由引理 10，A_1⊆A_0，故安全约束单调变强；设性能损失
ΔJ ≤ c_1·|ℋ_novel| + c_2·D_sem + c_3·(H−k*_pose)，
其中第一项来自 credible 集变大导致的最坏包络，第二项来自未验证断言的保守化，第三项来自前缀缩短。AFA-S 的 `view_change`/`query_human` 可降低 p_novel 与 D_sem，从而把性能损失换回。**因此开集能力不是免费的，但它只花性能，不花安全。** ∎

**命题（位姿是接触操作的伤害瓶颈）** 对以末端执行器接触为唯一外力来源的操作任务，若发生接触伤害事件（力/形变/碰撞超限），则必存在时刻 s 使末端位姿-接触事件 (T_s, f_s) 越过物理安全集；即位姿通道是接触伤害的**必要通道**。反之不成立：连杆/本体碰撞、工具形变、非接触辐射等可在位姿正常时造成伤害，故 E_hard 必须显式包含连杆几何、工具模型与非接触风险；本命题只保证"位姿正常"不能单独推出"安全"，这也是 SCOPE 仍需 E_hard 的原因。∎

## 7. 已知风险

**一句话**：SCOPE 的安全论证依赖「位姿多估计器的错误不共模、且硬包络 E_hard 的物理模型（关节/连杆/力限）本身正确」；一旦发生共模位姿错误（标定漂移与视觉欺骗同向叠加）或硬包络建模遗漏（连杆碰撞、工具形变），所有模态会在同一个错误位姿上"一致"，AIS 会把实际碰撞的位姿认证为安全，而 MLLM 契约只会在此之上更保守而非纠正——这是整个「归因无关安全」所依赖的隐藏假设（A94）。

**次级风险与缓解**：
1. **共模位姿错误**：多个估计器共享同一失效源（同一标定/同一 OOD 物体/同一遮挡）；缓解：`common_mode_suspect` 检测 + 独立物理通道（关节电流/力矩/接触麦克风/外部急停）；AIC-P 显式认证共模场景。
2. **E_hard 物理模型遗漏**：连杆碰撞、工具形变、非接触风险不在位姿锚覆盖内；缓解：E_hard 显式含连杆/工具几何与力限，定期用外部测量（激光跟踪/视觉标定）校验，保留硬件急停。
3. **编译器自身是学习的**：κ 可能把错误语义编译成"看似合理"的谓词；缓解：κ 的输出必须带 mon 与 cert，所有安全谓词需人工/物理回放验证；把编译器纳入 AIC-P。
4. **开集判据的分布漂移**：known 流形与 conformal 阈值在长期运行后失准；缓解：在线重校准、漂移检测、定期重标定位姿锚点。
5. **语义债务溢出**：未验证断言过多导致系统过度保守或隔离失效；缓解：D_max 硬约束、优先隔离高影响断言、用 query_human 快速清债。
6. **位姿残差对慢变故障不敏感**：缓慢标定漂移可能始终落在 q_pose 内；缓解：CUSUM/趋势检测、周期性 pose_recalibrate、外力激励下的多姿态一致性检验。
7. **MLLM 延迟与不可用**：语义流阻塞；缓解：完全异步、缓存契约、超时退回 VISTA/E_hard，安全路径不依赖 MLLM 可用性。
8. **过度保守**：E_hard + 未验证契约使 k* 过短、任务失败；缓解：分视界/分场景标定 q_pose、契约分级、只对高影响安全项采用最坏包络。
9. **契约出处伪造/审计失效**：prov 被错误标注为 safety；缓解：prov 由系统侧签名的可观测来源决定，MLLM 不能自封 safety；J_scope 哈希链审计。
