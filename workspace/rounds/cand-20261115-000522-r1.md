# 第 3 轮（灵感循环：「关节空间控制」×「动作分块」；承接 ToolGauge 基线）

> **基线继承**：前序轮次 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；E426–E440）及其退化底座
> LeanGauge / MODGAUGE 全部保留。集成链：**MODGAUGE ⊃ LeanGauge ⊃ ToolGauge ⊃ ChronoGauge**。
> 本轮纪律：**只把计量从「空间/参数」扩展到「时间/执行」**，不重写数值真值通道与五不变式；
> 三个既有模块各沿一条动作侧灵感升级，并显式修复第 2 轮遗留的执行层盲点（见 §5）。

## 三位一体映射（升级而非重写）

| 灵感词 | 前序对象 | 升级为 | 一句话动机 |
|---|---|---|---|
| 关节空间控制 | ToolGauge 的主动物理探测（IR/敲击/光照，代价 c_t 高、有扰动风险） | **Q-Box 执行即计量 + 零空间探针**：本体感觉回路本身就是高带宽探针；冗余零空间提供任务透明的主动激励 | 最好的探针不是额外加装的工具，而是执行动作本身；最好的主动激励是不改变任务的那一份 |
| 动作分块 | 逐 tick 闭环 + 事件驱动的盲区修复（无显式时间语义） | **H-Box 时间覆盖矩阵 + ACC/CCV 分块契约**：把开环承诺变成带有效期与残差包络的可审计时间契约 | 分块把「每步纠错」换成「对未来的承诺」，承诺必须有到期时间和违约检测 |
| 二者相乘 | 定义 416–431 的「探测—回执—校准—热替换」只发生在感知/参数层 | **时间-空间联合计量**：承诺的失效由关节残差实时见证；校准样本来自执行而非额外动作 | 时间盲区只有被执行的残差才能廉价地持续见证 |

**核心命题**：把 ToolGauge 的「语义假设 → 契约化工具调用 → 摊销校准 → 交叉验证热替换」升级为
「**承诺分块 → 执行残差见证 → 零空间补激励 → 有效期契约校验 → 中止/重规划/热替换**」：
关节空间控制提供零成本的被动回执（执行即计量），动作分块提供显式的时间承诺（可证伪的有效期）；
两者相乘使「世界模型何时开始说谎」第一次成为可在线测量、可契约化、可中止的量。

**不变式保持声明**：
- MODGAUGE 五不变式全部保留；时间契约只在执行层，不进入数值真值通道（引理 54）；
- **严格退化链延长**：ChronoGauge 失效（残差不可信 / 有效期预测失准 / 零空间被占据）⇒ 中止分块退回单步闭环（reactive）⇒ ToolGauge 主动探测 ⇒ LeanGauge ⇒ MODGAUGE；
- 分块是增强项，不是依赖项：令 H=1 且禁用零空间激励，ChronoGauge ≡ ToolGauge（定义 447）。

## 0. 直觉与动机

**灵感 1（关节空间控制 → 控制器本身就是一台计量仪）**
直觉：前两轮把「探测」当成需要额外动作的外部干预（敲击、扫光、IR 补测），代价高且本身扰动世界。
但任何关节空间控制器在每个控制周期都已经产生 (q, q̇, τ) 的高带宽测量——关节编码器与力矩环是**已经装好的探针**。
真正与模型失配相关的量不是原始测量，而是**执行残差**：指令前馈 + 由同一批噪声测量预测的闭环修正，
与实测关节轨迹之差 e_q。它把「世界模型哪里错了」翻译成「我的关节没有走到我预测的位置」，
且天然分解为任务空间残差 e_x = J e_q 与零空间残差 e_n = N e_q：前者是任务失效信号，后者是自运动与模型误差。
**执行即计量（EaM）**：探测从「额外动作」降格为「执行的自然副产品」，边际代价趋近于零。

**灵感 2（关节空间控制的冗余 → 零空间是任务透明的主动激励通道）**
直觉：被动残差只能激励任务实际走到的参数方向；任务没碰到的方向（负载质量、接触刚度、摩擦）
在执行中永远得不到激励（引理 56）。冗余机械臂的零空间 N = I − J⁺J 恰好给出一个**不改变末端位姿**的运动子空间。
在其中注入预注册的多正弦激励 δq = N ξ，可以在任务零扰动（一阶）下辨识这些参数——
这是「免费的主动探测」：它补上被动计量的盲方向，又不产生 ToolGauge 物理探测的任务代价。
关键在于把它做成**任务透明**而非「偷偷抖一下」：激励幅度、力矩、自碰撞都进入契约（定义 436/438）。

**灵感 3（动作分块 → 承诺是有有效期的契约，而不是一次性的开环）**
直觉：ACT / Diffusion Policy 式动作分块用「一次预测 H 步、开环执行」换取推理摊销与动作一致性，
代价是把逐步闭环的鲁棒性换成对世界不变的赌注。分块越长越省算力，但对中途变化的反应越慢——
这是一个此前被当作工程超参的**摊销-承诺权衡**。我们把它显式化：
每个 chunk 携带**承诺有效期** H_valid（在给定残差包络下，承诺仍成立的概率 ≥ 1−δ 的最大步数）
与**回滚点**；执行时由关节残差逐 tick 见证，超出包络即**中止 chunk、安全保持、重规划**。
时间覆盖矩阵 R_τ 记录「哪些区域/模式/时长组合的承诺从未被验证」，构成与空间盲区 R 对偶的**时间盲区**。
于是「分块多长」从一个拍脑袋的量变成**可预测、可证伪、可契约化**的量（引理 53 给出最优 H*）。

**灵感乘法的关键**：动作分块制造承诺，关节空间残差见证承诺，零空间激励补全承诺所需的参数方向；
三者构成一个闭环，使时间盲区与空间盲区在同一套「回执—契约—校准—退化」语言下被统一处理。

## 1. 形式化定义（增量：定义 432–447）

**定义 432（动作分块与承诺）** 动作分块 A = (π_c, H, a_{t+1:t+H})，π_c 为策略，H 为承诺视界。
执行模式 exec(A) ∈ {open-loop, temporal-ensemble, receding-horizon}；承诺度 κ(A) ∈ [0,1] 为开环执行的比例。
约定 H=1 即退化为单步闭环。

**定义 433（时间覆盖矩阵 R_τ 与时间盲区）** R_τ : (区域 g, 任务模式 m, 视界桶 h) ↦ (o_verified, o_max, N_eff, t_last)，
o 为已验证的执行偏差统计量。时间盲区 s_τ = (g,m,h) 当且仅当覆盖未达标或 N_eff < n_min（定义 441）。
R_τ 是空间覆盖矩阵 R（定义 398/399）的时间对偶。

**定义 434（关节空间执行残差）** 给定分块 A 与辨识动力学 f̂：
e_q(t) = q_meas(t) − [ q_ff(t) + q̂_fb(t) ]，
其中 q_ff 为分块前馈，q̂_fb 为用**同一批带噪测量**经模型预测的闭环修正（故 e_q 主要隔离模型误差而非测量噪声）。
任务/零空间分解：e_x = J(q) e_q，e_n = N(q) e_q，N = I − J⁺J。
加权能量 R_q = ‖e_q‖_W，W 按关节对任务的重要性加权。

**定义 435（残差包络与承诺有效期 TVH）** 包络 E_q(t) = μ_env(t) + κ_σ σ_env(t)，由 R_τ 数据或残差 GP 校准。
分块在 t 有效 ⇔ R_q(t) ≤ E_q(t) ∧ ‖e_x(t)‖ ≤ E_x。
承诺有效期 H_valid(A) = sup{ h : P(在 [t, t+h] 上持续有效) ≥ 1−δ }，由 TVH 预测器给出；**它是可证伪的预测**，每 tick 接受检验。

**定义 436（动作分块契约 ACC 与校验器 CCV）** ACC(A) = (A, H, H_valid, E_q, E_x, δ, N_sched, q_rollback, receipts)，
与工具契约 MTC（定义 416）同构但作用于时间。CCV 在分块启动时逐条校验：
① 运动学可行（关节限位/速度/加速度/可操作度 μ ≥ μ_min，不穿越奇异）；
② 视界 H ≤ H_valid；
③ 包络非空且已校准（E_q 不得为「无穷大」的假保证）；
④ 零空间激励在力矩/幅值/自碰撞/人机包络内（定义 438）；
⑤ 回滚点 q_rollback 在 t_safe 内可达；
⑥ 预留重规划算力预算。
任一失败 ⇒ 收缩 H 或退化为单步闭环（定义 440）。

**定义 437（执行即计量 EaM / 被动回执）** 每控制周期产生回执 r_t = (q, q̇, τ, e_q, e_x, e_n, sig, seq)，
valid 需通过传感器合理性（量程/速率/跨通道一致）。被动回执与 ToolGauge 主动回执进入**同一校准池**，
但必须按相关有效样本量计权（定义 441）。

**定义 438（零空间计量探针 NS-Probe）** δq(t) = N(q) ξ(t)，ξ 取预注册多正弦基。
辨识目标：在约束 ‖τ_extra‖∞ ≤ τ_max、‖δq‖∞ ≤ δ_max、关节/自碰撞/人机包络内，
最大化对参数 u（负载质量、接触刚度、摩擦）的 Fisher 信息 det(I(u))。
一阶任务不变性：J δq = J N ξ = 0。任务透明信息增益 Ĝ_null 与激励代价 c_null（仅磨损/能耗，无任务误差）一并入账。

**定义 439（承诺主张绑定）** 关于「本分块可有效 h 步」「残差在 E 内」的语言主张必须引用被动回执与 TVH 版本号；
无可验证引用的主张在序列化时剥离（定义 423 的时间扩展）。

**定义 440（时间-空间联合退化链）** ChronoGauge ⇒ 分块中止退回单步闭环 ⇒ ToolGauge 主动探测 ⇒ LeanGauge ⇒ MODGAUGE。
分块内违约 ⇒ 中止 ⇒ 安全保持 ⇒ 重规划；链条单向、单调。

**定义 441（相关有效样本量）** 被动回执自相关 ρ_k 下 N_eff = N / (1 + 2 Σ_{k=1}^{K} ρ_k)。
校准与 n_min 判定一律用 N_eff；若 N_eff < n_min，被动回执不得单独认证盲区，必须叠加主动探测（定义 439/引理 55）。

**定义 442（激励持久性覆盖 PE）** 参数方向分任务激励子空间 S_task 与零空间激励子空间 S_null；
联合回归量 Σ 须满足 λ_min(Σ) ≥ ε_PE 于窗口 T，否则该参数本分块判为不可辨识，写回 R_τ 的「未覆盖」。

**定义 443（时间预算契约 TTB）** TTB = (H_max, t_det, t_abort, t_safe, recovery)：最大视界、检测时延、中止时延、安全停止时延、恢复条件；
是 TB-Contract（定义 424）的时间细化。

**定义 444（执行-计量一致性 EMC）** 计算 e_q 的模型版本必须与更新契约所用版本严格绑定（版本钉扎），
禁止用「更新后的模型」回溯解释「更新前的残差」，以防把系统性偏差解释成随机噪声。

**定义 445（分块长度决策）** H* = argmin_H C(H)，C(H) = c_inf/H + c_abort·P_stale(H) / H + c_probe(H)，
其中 P_stale 由 TVH 与 R_τ 给出；H* 随监测质量提升而增大（引理 53）。

**定义 446（时间覆盖的验收）** 分块完成且全程未违约 ⇔ 该 (g,m,H) 的一次有效覆盖；中止或违约不计入覆盖，只计入失败指纹库。
与空间盲区一样，**迭代采样不得被误判为已覆盖**（第 2 轮缺陷 4 的时间版）。

**定义 447（继承与退化约定）** 定义 398–431 全部继承；令 H=1、N_sched=∅、且仅保留单步残差，ChronoGauge ≡ ToolGauge。
ChronoGauge 相对 ToolGauge 严格增加：时间盲区、被动回执、零空间激励、时间契约四件套。

## 2. 关键算法骨架

```python
# IP-321 H-Box：时间覆盖矩阵与承诺盲区
class HBox:
    def detect_temporal_blind_spot(self, g, m, H):
        cell = self.R_tau.get((g, m, bucket(H)))
        if cell is None or cell.N_eff < n_min or cell.o_verified > o_max:
            return TemporalBlindSpot(g, m, H)
        return None

# IP-322 Q-Box：执行即计量（被动回执）+ 零空间激励
class QBox:
    def residual(self, q_meas, q_ff, model, qd, tau):
        q_pred = q_ff + model.closed_loop_correction(q_meas, qd, tau)  # 同批噪声
        e_q = q_meas - q_pred
        J = model.jacobian(q_meas); N = nullspace(J)
        return Receipt(e_q=e_q, e_x=J @ e_q, e_n=N @ e_q,
                       q=q_meas, qd=qd, tau=tau, sig=sign(q_meas), seq=self.seq.next())
    def ns_excitation(self, q, u_hat):
        basis = self.exc_basis(q)                        # 预注册多正弦
        Sigma = self.regressor(q, basis)
        if lambda_min(Sigma) < EPS_PE: return None       # 定义 442：不可辨识
        return nullspace(self.J(q)) @ self.solve_fisher(basis, u_hat, TAU_MAX, DELTA_MAX)

# IP-323 ACC/CCV：动作分块契约与校验
class ChunkContract:
    def __init__(self, A, H, H_valid, E_q, E_x, n_sched, q_rollback):
        ...
class CCV:
    def verify(self, acc, robot):
        if not robot.kinematically_feasible(acc.A, mu_min=MU_MIN): return False, "kinematics"
        if acc.H > acc.H_valid:                                    return False, "horizon"
        if not acc.E_q.is_finite_and_calibrated():                 return False, "vacuous_envelope"
        if not robot.excitation_safe(acc.n_sched, TAU_MAX, DELTA_MAX): return False, "excitation"
        if not robot.reachable_in(acc.q_rollback, acc.t_safe):     return False, "rollback"
        return True, "ok"

# IP-324 TVH：残差包络与有效期预测
class TVH:
    def predict(self, A, ctx):
        mu, sig = self.gp_residual(ctx)          # 或 R_tau 经验分位
        E_q = mu + KAPPA_SIGMA * sig
        return HorizonEstimate(H_valid=self.first_passage(A, E_q, delta=DELTA), E_q=E_q)
    def first_passage(self, A, E_q, delta):
        return self.growth_model.invert(E_q, delta)   # 残差增长模型的首达时

# IP-325 ChronoGauge 闭环
def chronogauge_chunk(M, g, m, H):
    if (s_tau := M.hbox.detect_temporal_blind_spot(g, m, H)) is None:
        return M.chunk_controller.execute_reactive(g)       # 无需承诺
    A   = M.chunk_controller.propose(g, H)                  # 动作分块提案
    est = M.tvh.predict(A, M.qbox.ctx(g))                   # 承诺有效期
    exc = M.qbox.ns_excitation(M.robot.q, M.u_hat)          # 零空间补激励（可空）
    acc = ChunkContract(A, H=min(H, est.H_valid), H_valid=est.H_valid,
                        E_q=est.E_q, E_x=est.E_x, n_sched=exc,
                        q_rollback=M.robot.safe_hold_point())
    ok, why = M.ccv.verify(acc, M.robot)
    if not ok:
        return M.degrade(g, why)                            # 收缩 H / 单步闭环
    for k in range(acc.H):
        r = M.qbox.residual(*M.robot.tick(acc.A, k))        # EaM 被动回执
        M.pool.append(r)
        if not acc.within_envelope(r):                      # 承诺违约
            M.robot.abort_to(acc.q_rollback)                # 中止 → 安全保持
            M.fingerprints.add(classify(r))
            return M.replan(g, reason="chunk_stale")
    M.hbox.record_coverage(g, m, acc.H)                     # 定义 446：完成才算覆盖
    M.calibrator.update(M.pool, use_n_eff=True)             # 相关有效样本量计权
    return True

# IP-326 主闭环
def ChronoGauge_round(M, obs, audio, tac, depth, det):
    for (g, m, H) in M.hbox.candidate_horizons():           # 时间盲区枚举
        if (g, m, H) not in M.inflight:
            M.inflight.add((g, m, H)); submit_async(chronogauge_chunk, M, g, m, H)
    return ToolGauge_round(M, obs, audio, tac, depth, det)  # 50Hz 主控不变
```

## 3. 推导

**引理 51（关节残差检测延迟与误报界）** 设 ‖e_q(t)‖ ≤ a + b(t−t0) + ζ，ζ 亚高斯(σ)，阈值 E_max > a。
则检测延迟 τ_det ≤ (E_max − a)/b；且 w.p. ≥ 1−δ，τ_det ≤ (E_max − a)/(b − σ√(2 log(1/δ))/Δ)。
单窗口误报率 ≤ exp(−(E_max − a)²/2σ²)。
系：任务投影 e_x 剔除零空间自运动（其幅度被 δ_max 界定），显著降低「自运动导致的假违约」；
但**任务可补偿的失效**（关节运动掩盖夹爪滑移）不在 e_x 中体现，是本方案的结构性盲点（见 §6）。

**引理 52（零空间探测的任务透明性与 CRB）** 若 N = I − J⁺J 精确，则 J δq = 0（一阶任务不变）。
末端二阶扰动 ‖Δx‖ ≤ ½ ‖∂J/∂q‖ ‖N ξ‖² = O(δ²)，而参数信息量 ∝ δ²/σ²；
故存在最优抖动幅度 δ*，使「单位任务扰动的信息量」最大，且在 δ→δ* 前 CRB 单调改善：
Var(û) ≥ σ² (Σ_k ξ_k ξ_kᵀ)⁻¹。系：零空间探针把 ToolGauge 的「探测扰动代价」压到二阶，而非一阶。

**引理 53（分块摊销-承诺权衡与最优视界）** 设每次中止的期望代价 c_abort、每步推理摊销 c_inf、
失效风险随视界线性增长 P_stale(H) = p0·H（短视界近似），则单位时间代价 C(H) = c_inf/H + c_abort p0 H，
最小化得 **H\* = √( c_inf / (c_abort p0) )**。监测把失效风险降为 p0′ < p0 时 H\* ∝ 1/√p0′：
**廉价监测买到更长的分块**——这是「执行即计量」的直接经济学收益。系：若 p0 无法被监测降低（任务可补偿失效，
引理 51 系），则 H* 不改善，分块退化为保守短视界。

**引理 54（时间契约保持五不变式与热替换等价）** ACC/CCV 仅作用于执行调度与中止；
中止是到安全集 {q_rollback} 的投影，不写数值真值；EMC（定义 444）保证残差与契约版本一致；
故子图数值等价性与 ToolGauge 引理 49 相同，退化链单调、五不变式保持。

**引理 55（执行即计量的有效样本量界）** 被动回执以控制频率 f_c 产生，自相关 ρ_k 下
N_eff = N/(1+2Σρ_k)。相对主动探测（每次 Δ_probe 秒、每次 1 样本），有效样本优势上界为
(f_c·Δ_probe)/(1+2Σρ_k)。当 ρ≈0.99 时优势约 50× 而非 10³×；
故被动计量**不能替代**覆盖任务未激励方向的主动探测（定义 442/引理 56），只能与之互补。

**引理 56（激励覆盖的必要条件与退化链必然性）** 若任务运动对参数方向 v 的回归量恒为零，且未执行零空间激励，
则 v 方向的 Fisher 信息为 0，û 在该方向不可辨识；执行即计量无论采样多久都无法修复。
故必须回到 ToolGauge 主动探测——这从信息论上证明了延长退化链不是保守，而是必要的。

## 6. 本轮最大风险（一句话）

**一句话**：关节空间执行残差只是「任务失效」的**代理信号**，在冗余与柔顺接触场景下存在双向盲区——
大的零空间自运动/任务可补偿运动会造成**误报**，而夹爪滑移、接触失稳等被关节运动悄然补偿的**致命失效会造成漏报**；
一旦漏报，时间契约反而给出「承诺仍在有效期」的虚假保证，使动作分块从「省算力的工程技巧」变成「系统性地掩盖失稳的机制」。

**次级风险与缓解**：
1. **代理信号漏报** → 引入与任务相关的独立见证（末端力/触觉/抓取状态）作为 e_x 的补充通道；把「无法由关节残差见证的失效模式」显式列入 R_τ 的 unobservable 集合，强制走主动探测（引理 56）。
2. **零空间激励的隐式约束违反** → CCV 的力矩/自碰撞/人机包络 + 预注册激励基，禁止在线自由生成。
3. **相关样本高估信息** → N_eff 折扣 + 与主动探测互证；不足 n_min 即拒绝认证。
4. **包络校准漂移** → TVH 残差 GP 在线校准 + 首达时预测的持续可证伪性（每 tick 检验）+ 漂移超限即收缩 H。
5. **中止动力学本身失稳** → 中止轨迹受加速度/力矩限制，q_rollback 预验证可达（定义 436.⑤）。
6. **分块长度决策退化** → 引理 53 的 H* 仅在 p0 可测时可改进；p0 不可测时强制保守短视界。

# 第 3 轮产物 · 创新点清单 v3：**ChronoGauge**（Joint-Space Execution Metrology with Contracted Action Chunks）

> 背景：第 2 轮 ToolGauge（IP-315–320）解决了「盲区发现 / 契约化探测 / 摊销校准」，但探测仍是**外部主动动作**
> （代价高、有任务扰动），且控制层**没有时间语义**：逐 tick 闭环与事件触发的修复无法表达
> 「一次动作分块对未来 H 步的承诺何时失效」。本轮以「关节空间控制 × 动作分块」为灵感，
> 在 ToolGauge 之上把计量从「空间/参数」扩展到「时间/执行」：
>
> **集成链：MODGAUGE ⊃ LeanGauge ⊃ ToolGauge ⊃ ChronoGauge**。
> 关节空间控制让**执行本身成为计量**（执行即计量 EaM，零任务扰动）；
> 冗余零空间让**主动激励任务透明**（NS-Probe，二阶扰动）；
> 动作分块让**承诺成为带有效期与残差包络的可审计契约**（ACC/CCV，中止可回滚）。
> IP 编号：IP-321–326（共 6 个）。定义增量 432–447；引理增量 51–56；实验增量 E441–E455。
> 理论姿态：不改变五不变式；新增「执行层时间契约」与「时间-空间联合退化链」。

## 2. 形式化定义（要点）

**定义 432–433（分块与时间覆盖）** 动作分块是视界 H 上的承诺；R_τ 是空间 R 的时间对偶，时间盲区 = 覆盖不足或 N_eff 不足。
**定义 434–435（执行残差与有效期）** e_q 隔离模型误差；任务/零空间分解区分失效信号与自运动；E_q 包络 + 首达时给出可证伪的 H_valid。
**定义 436（ACC/CCV）** 六项校验：运动学可行、H ≤ H_valid、包络非空、激励安全、回滚可达、预算预留；失败即收缩或退化。
**定义 437–438（EaM / NS-Probe）** 每 tick 产生被动回执；零空间多正弦激励最大化 Fisher 信息且一阶任务不变。
**定义 439–442（主张绑定 / 退化链 / N_eff / PE）** 时间主张须引用回执；退化链单向；被动样本按相关折扣；联合激励须满足持久性。
**定义 443–447（TTB / EMC / 视界决策 / 覆盖验收 / 退化约定）** 时间预算、模型版本钉扎、H* 决策、完成才算覆盖、H=1 退化为 ToolGauge。

## 3. 关键算法骨架

```python
# IP-322 Q-Box：执行即计量 + 零空间探针
class QBox:
    def residual(self, q, qd, tau, q_ff, model):
        q_pred = q_ff + model.closed_loop_correction(q, qd, tau)   # 同批噪声
        e_q = q - q_pred
        J = model.jacobian(q); N = nullspace(J)
        return Receipt(q, qd, tau, e_q=e_q, e_x=J@e_q, e_n=N@e_q,
                       sig=sign(q), seq=self.seq.next())
    def ns_excitation(self, q, u_hat):
        basis = self.exc_basis(q); Sigma = self.regressor(q, basis)
        if lambda_min(Sigma) < EPS_PE: return None                 # 不可辨识
        return nullspace(self.J(q)) @ self.solve_fisher(basis, u_hat, TAU_MAX, DELTA_MAX)

# IP-323/324 ACC/CCV + TVH
class CCV:
    def verify(self, acc, robot):
        if not robot.kinematically_feasible(acc.A, MU_MIN):            return False, "kinematics"
        if acc.H > acc.H_valid:                                       return False, "horizon"
        if not acc.E_q.is_finite_and_calibrated():                    return False, "vacuous_envelope"
        if not robot.excitation_safe(acc.n_sched, TAU_MAX, DELTA_MAX):return False, "excitation"
        if not robot.reachable_in(acc.q_rollback, acc.t_safe):        return False, "rollback"
        return True, "ok"

class TVH:
    def predict(self, A, ctx):
        mu, sig = self.gp_residual(ctx); E_q = mu + KAPPA * sig
        return HorizonEstimate(self.growth_model.first_passage(E_q, DELTA), E_q)

# IP-325 ChronoGauge 闭环
def chronogauge_chunk(M, g, m, H):
    if M.hbox.detect_temporal_blind_spot(g, m, H) is None:
        return M.chunk_controller.execute_reactive(g)
    A   = M.chunk_controller.propose(g, H)
    est = M.tvh.predict(A, M.qbox.ctx(g))
    exc = M.qbox.ns_excitation(M.robot.q, M.u_hat)
    acc = ChunkContract(A, H=min(H, est.H_valid), H_valid=est.H_valid, E_q=est.E_q,
                        E_x=est.E_x, n_sched=exc, q_rollback=M.robot.safe_hold_point())
    ok, why = M.ccv.verify(acc, M.robot)
    if not ok: return M.degrade(g, why)
    for k in range(acc.H):
        r = M.qbox.residual(*M.robot.tick(acc.A, k))
        if not acc.within_envelope(r):
            M.robot.abort_to(acc.q_rollback); M.fingerprints.add(classify(r))
            return M.replan(g, reason="chunk_stale")
    M.hbox.record_coverage(g, m, acc.H); M.calibrator.update(M.pool, use_n_eff=True)
    return True

# IP-326 主闭环
def ChronoGauge_round(M, obs, audio, tac, depth, det):
    for (g, m, H) in M.hbox.candidate_horizons():
        if (g, m, H) not in M.inflight:
            M.inflight.add((g, m, H)); submit_async(chronogauge_chunk, M, g, m, H)
    return ToolGauge_round(M, obs, audio, tac, depth, det)
```

## 4. 推导

**引理 51（检测延迟/误报）** 残差增长 ‖e_q‖ ≤ a + b(t−t0) + 亚高斯 ζ 下，τ_det ≤ (E_max−a)/b；
w.p.≥1−δ 的紧界含 σ√(2log(1/δ))/Δ；误报 ≤ exp(−(E_max−a)²/2σ²)。任务投影剔除自运动假违约，但漏掉任务可补偿失效。
**引理 52（零空间透明性与 CRB）** J N ξ = 0（一阶）；末端二阶扰动 O(δ²)；存在使单位任务扰动信息量最大的 δ*，Var(û) ≥ σ²(Σξξᵀ)⁻¹。
**引理 53（最优视界）** C(H)=c_inf/H + c_abort p0 H ⇒ H*=√(c_inf/(c_abort p0))；监测降 p0 ⇒ H*∝1/√p0′：廉价监测买更长分块。
**引理 54（五不变式/热替换保持）** ACC 只在执行层；中止是安全投影；EMC 版本钉扎 ⇒ 等价性同 ToolGauge 引理 49。
**引理 55（有效样本量）** N_eff=N/(1+2Σρ)；相对主动探测优势上界 (f_cΔ_probe)/(1+2Σρ)；ρ≈0.99 时约 50×，不能替代主动探测。
**引理 56（激励覆盖必要性）** 任务未激励且零空间未激励的方向 Fisher 信息为 0，执行即计量不可修复 ⇒ 必须回退 ToolGauge 主动探测。

- **修复**：探测的外部扰动与高代价 → EaM/NS-Probe；分块无时间语义 → ACC/CCV/TVH；时间维度的「采样即覆盖」误判 → 定义 446；被动观测自相关高估信息 → 定义 441；模型版本漂移自洽化 → EMC。

## 8. 本轮最大风险

**一句话**：关节空间残差是任务失效的代理信号，存在「自运动误报」与「任务可补偿致命失效漏报」的双向盲区；
一旦漏报，时间契约会给出「承诺仍在有效期」的虚假保证，使动作分块系统性地掩盖失稳。
以末端力/触觉独立见证、不可观测失效集合强制主动探测（引理 56）、N_eff 折扣与 E442/E449/E454 证伪兜底。
