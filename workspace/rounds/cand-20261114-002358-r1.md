# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「材料选型」×「机器人基础模型」）

> R69 学会了「问」，但它有一个从未写下的前提：**被问的、被用的、被签字的，始终是同一件、可信的、不会变的工具**。它把不确定性拆成 aleatoric（世界里的噪声）与 epistemic（世界里的歧义），可两者都是「关于世界」的不确定性。它从未问过第三个问题——**我手里这台产生动作的基础模型，还是我以为的那台吗？它被资格认证过吗？它老化了吗？它中途被换过件吗？**
>
> 材料选型给了这把尺子：工程材料从不以「平均强度」被选用，而是以**工况包络（duty-cycle envelope）+ 失效模式专用的设计许用值（design allowables）+ 批次/老化/可追溯性证书**被选用；在这套体系里，**安全不是可以拿性能去换的加权项，而是先行于一切优化的硬约束**。机器人基础模型给了对象：一个由互联网规模数据、底座权重、微调语料、动作头、量化/编译、执行硬件共同构成的**供应链**——它可以被投毒、被换件、被伪造证书，会在长尾方向上「各向异性」地失效，还会随部署漂移而老化。
>
> 核心命题：**把基础模型当作「工程材料」来管。不再问「这一个策略准不准」，而问「在这个工况包络内，这件材料所有失效模式的许用值是否闭合、它的产地与批次是否可追溯、它是否还在资格寿命内」。动作只能由「当前工况下已被准入、且仍在包络内」的材料产生；不满足则换料、复合、或退回本地反射。** 命名 **MATTER-RAS**（Materialized Assurance via Traceable Tested Envelopes & Requalification）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我用的这件工具，还是被检验过的那件吗**」——不确定性不只关于世界，也关于工具本身；安全不是模型表现出来的性能，而是材料在其包络内的许用。

## 0. 直觉与动机

**灵感 1（材料选型 → 选的是「包络内的许用」，不是「平均性能」）**
直觉：材料手册从不只给一个数。它给的是「在 −40~125℃、10⁷ 次循环、腐蚀介质 X 下，屈服/疲劳/蠕变各自的许用值」，并且明确标出**不适用区**。工程师不会拿「平均抗拉强度」去选一个要在低温疲劳工况下工作的零件——那样选出来的材料恰恰是在自己最弱的方向上被使用。R69 对基础模型做的正是这种事：用一整个 checkpoint 的**全局平均**能力，去覆盖一个高度异质的工况分布。材料选型的第一课因此是：**把「一个模型的平均分」换成「一张按工况与失效模式索引的许用表」；选用问题变成「任务工况是否落在某件材料的资格包络内」，而不是「谁的平均分高」。**

**灵感 2（许用值与安全系数 → 安全是约束，不是权重）**
直觉：材料设计里，安全系数按**失效模式**分别取：屈服看延性、疲劳看循环数、蠕变看温度与时间、屈曲看几何。你不会用「一个综合 λ」同时缩放所有失效模式——因为不同失效模式的物理机制、尾部形状与后果完全不同。R69 的 λ_floor 是一个标量，把所有不确定性揉进一根刹车。R70 把它升级为**许用值向量**：每个失效模式 f 有自己的容量 C_f、需求 d_f 与安全系数 SF_f，准入要求 **C_f/(SF_f·d_f) ≥ 1 对所有 f 同时成立**。关键姿态：**安全进入的是「可行域约束」，性能只在可行域内部排序**——绝不允许「性能高所以可以牺牲某个失效模式的余量」。

**灵感 3（溯源与批次 → 基础模型是一条供应链，不是一颗原子）**
直觉：工程材料有炉号、批次、材料试验报告（Mill Test Report）、热处理记录；出了问题能追到是哪一炉、哪道工序。基础模型恰恰缺这套：一个「VLA」背后是底座权重、预训练语料、微调数据、动作头、量化/编译、执行硬件——每一环都可能被替换、被投毒、被过期。R69 的「k 个正交证据源」在这里会失效：如果几个「源」共享同一个被污染的底座，它们只是同一张嘴的多次复读。于是 R70 引入**产地图与污染传播**：派生件继承祖先的污染等级，除非它完成独立的**再资格认证**（相当于重新熔炼、重新出证书）。「证书」必须带签名、可逐级回溯，否则一张伪造的合格证就能让整个闭环裸奔。

**灵感 4（各向异性 → 能力是张量，不是标量；长尾方向才致命）**
直觉：复合材料在纤维方向很强、横向很弱；用「平均模量」去设计横向受载，必然断裂。基础模型同样**各向异性**：在训练分布的主方向上很强，在长尾任务方向（新本体、新光照、罕见指令）上可能急剧塌陷。R69 用 MCG 的全局 ECE 做门控，本质是各向同性的标量判断。R70 要求沿**任务方向 u** 计算**方向许用值** ρ_m^{LCB}(u, ψ)（下置信界，而非均值），并要求沿该方向的余量达标。一个平均很强、但在任务方向上最弱的模型，应被判为**不适用**——这正是材料选型中「性能指数必须沿加载方向定义」的翻版。

**灵感 5（老化/疲劳 → 模型会漂移，资格有寿命）**
直觉：材料会蠕变、疲劳、腐蚀；资格不是永久的，而是有寿命与再认证周期。部署中的基础模型也在老化：世界漂移、量化误差累积、传感器更换、数据分布迁移。R69 的 FMA 只做「瞬时第二意见」，没有**累计暴露—剩余寿命**的概念。R70 引入**资格寿命**：累计工况暴露 e_m 与漂移 drift_m 共同决定剩余资格寿命 RQL_m；一旦超出即自动降级为「未准入」，必须再资格认证才能重新上岗。这把 R68 的慢变故障、R69 的行为似然，统一进「材料的疲劳账本」。

**灵感 6（换料/复合 → 替换有成本、有迟滞、且必须严格包含 R69）**
直觉：换材料不是改一个变量：它要重新设计接口、重新做疲劳试验、可能引出新的失效模式；频繁换料本身就是一种风险（颤振、焊缝疲劳）。R70 因此给替换加**切换成本 + 迟滞带 + 最小驻留时间**，并规定**执行前缀内不得换料**（原子性）。当没有单一材料能同时满足全部许用时，材料工程的答案是**复合/合金**：把不同材料按规则组合，但复合体本身也要重新资格认证（因为界面会引入新的失效模式）。最后，整套机制必须是 R69 的严格泛化：当只有一件干净、新鲜、单失效模式、工况落在包络内的材料时，MATTER 逐指令退化为 FLUID；当连一件合格材料都没有时，退化为本地反射——**安全侧只做加法**。

**灵感 7（本地否决 → 资格可以外包，否决权不能外包）**
直觉：材料的检验报告可以来自第三方实验室，但「装到这台机器上是否安全」必须由本地的、可验证的装配规程来裁决。基础模型可以来自云端、来自第三方、来自开放权重，但**没有任何远端模型有权直接写执行器**。R70 保留一件小而可形式化验证的**本地反射材料**，它零网络、永远在线，拥有对一切基础模型提案的**否决权**。这与 R69「信息动作也要过 C-RAS-WM 认证」是同一条安全拓扑的延伸：证据可分布，否决权必须本地。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（MATTER-RAS 总览）** MATTER-RAS = (POR, DQE, MSEL, QAT, AMS, AGE, SUB, CMF, VETO, FMP†, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **无未资格材料执行**：任何产生执行动作的工件，在执行时刻必须持有有效准入证书，且当前工况在其资格包络内；
(iii) **本地否决不可委托**：本地反射材料 r 对一切基础模型提案拥有一票否决，基础模型永不经由网络直连执行器；
(iv) **全链可追溯**：每个被执行的工件携带产地证书与再资格时钟，缺失即视为未准入。

**定义 311（材料/工件模型）** 一件材料 m = (θ_m, I_m, P_m, E_m, τ_m)：θ_m 为（量化/编译后的）部署权重；I_m 为**接口契约**（观测/动作空间、tokenizer、本体、传感套件、时延上限）；P_m 为**产地图**（数据源、底座祖先、微调语料、工具链、许可证）；E_m 为**工况资格包络**（在任务工况分布 D 上定义的可用域与许用表）；τ_m 为**老化/再资格状态**。材料库 ℳ = {m_1,…,m_N}。**注意**：I_m 与 θ_m 必须描述「部署形态」（量化后、编译后），而非浮点权重——量化与编译是改变失效包络的「材料工艺」。

**定义 312（各向异性能力与方向许用值）** 对任务方向 u（任务/指令嵌入的单位向量）与工况 ψ，材料 m 的属性是 ρ_m(u, ψ)。用能力椭球刻画各向异性：沿 u 的方差 σ_m²(u) = uᵀΣ_m u，各向异性度 A_m = λ_max(Σ_m)/λ_min(Σ_m) ≥ 1。**方向许用值**定义为下置信界 ρ_m^{LCB}(u, ψ; 1−α)，而选型一律使用 ρ^{LCB}，禁止使用均值 ρ̄_m。

**定义 313（产地图与污染传播）** 产地图 P_m 是有向无环图，节点为数据源/底座/语料/工具链，边表示「派生自」。节点污染标签 t(v) ∈ {clean, suspect, tainted}。污染沿边传播：t(child) = max_{parent} t(parent)，除非 child 带有**独立再资格证据**（rc(v)=1，相当于重新熔炼并重新出报告）。有效产地等级 g_prov(m) ∈ [0,1] 是图上 clean 质量沿路径的最小值聚合；`g_prov(m) < g_min ⇒ m 不得准入`，无论其性能多高。

**定义 314（工况资格包络 DQE）** 应用工况是一个三元分布 D = {(ψ, f, w_f)}：工况 ψ、失效模式 f、暴露权重 w_f。材料 m 在 D 上**合格**当且仅当对每个 w_f>0 的失效模式，其（沿任务方向的）可靠度下置信界满足 `LCB_{1−β_f}[R_m(f, ψ)] ≥ R_min(f)` 对所有 ψ ∈ supp(D) 成立。包络 E_m(D) 是用**保形预测 + Weibull 最弱链**估计出的、上述条件成立的工况集合；`ψ ∉ E_m(D) ⇒ 不适用`。R69 的 MCG 全局 ECE 只是 m 在 E_m(D) 内、单一区域、单一失效模式的极端特例。

**定义 315（失效模式专用许用值 AMS）** 失效模式集 F（碰撞、夹持、失稳、超力、超时、语义越界…）。每个 f 有容量 C_f、需求 d_f、安全系数 SF_f（由后果严重度与不确定性定）。材料安全裕度 `μ_m = min_{f∈F} [ C_f / (SF_f · d_f) ]`，准入要求 `μ_m ≥ 1`。R69 的标量 λ_floor 是 |F|=1 的退化情形；R70 用**向量** λ = (λ_f) 替代标量，禁止跨模式「拆东墙补西墙」。

**定义 316（材料选型问题 MSEL）** `m* = argmax_{m∈ℳ} J(m)`，s.t.
(a) 接口兼容 I_m ⊨ 任务（动作空间、本体、传感、时延）；
(b) 合格 `m ∈ E_m(D)` 且 `μ_m ≥ 1`；
(c) `g_prov(m) ≥ g_min`；
(d) 老化未超 `RQL_m > 0`。
性能指数按 Ashby 式定义 `J(m) = η_task(m) / (c_lat(m) · c_risk(m))`（任务收益 / 时延·风险成本），且**仅在可行域内部排序**。若可行集为空 ⇒ 返回 NO_ADMISSIBLE_MATERIAL。

**定义 317（准入抽样 QAT）** 对候选工件做统计验收：在 D 上抽 n 次试验，成功数 X；给定零假设可靠度 p、生产方风险 α_P、使用方风险 α_C，按 (n,c) 抽样方案判收/拒，接受当且仅当 `LCB_{1−α_C}(R) ≥ p_min`（或 Weibull 最弱链 B10 寿命达标）。QAT 让「合格」是一个**频率学保证**，而非一次基准平均；R69 的 ECE 门控并入其特例（校准误差作为 DQE 的一维）。

**定义 318（老化、疲劳与剩余资格寿命）** 累计暴露 `e_m(t) = ∫ w_f(ψ(τ)) dτ`，漂移 `drift_m(t)` 由 R68 的 COF 残差与 R69 的 FMA (Δa) 融合估计。剩余资格寿命 `RQL_m = 1 − max(e_m/e_m^life, drift_m/drift_m^max)`。`RQL_m ≤ 0 ⇒ 立即撤销准入`，须整机再 QAT 才能复岗；局部再资格（仅重验某失效模式）只能恢复对应维度的许用。

**定义 319（替换与再资格治理 SUB）** 换料 m→m' 有成本 c_sub，若 `E_{m'} ≠ E_m` 或 `I_{m'} ≠ I_m` 则必须先 QAT 再切换。**迟滞**：仅当 `J(m') − J(m) > h` 且驻留 `≥ T_dwell` 才切换，避免颤振。**原子性**：C-RAS-WM 认证前缀执行期间禁止换料；跨接口换料（动作空间改变）必须重验整条安全包络。Zeno 无关：h>0 与 T_dwell>0 保证任意时域内切换次数有限。

**定义 320（复合/合金 CMF）** 当单材料可行集为空，构造复合 c = ⊕({m_i}, arb)，arb 为仲裁规则（如「慢思考提议 + 快反射执行」或按失效模式分工）。复合体必须**整体再资格**：其许用由分量许用经 arb 推导，并对**相关失效**（共享底座/数据 ⇒ 相关性 ρ>0）施加混合惩罚；界面引入的新失效模式 f_new 必须显式加入 F。复合材料不是免费的集成，而是一件新工件。

**定义 321（本地反射否决 VETO）** 反射材料 r 是小规模、形式化可验证、零网络、常驻的控制器；基础模型只提出候选，r 逐条检查：(a) 提案落在 r 的已验证安全集内；(b) 对应失效模式许用值 μ≥1；(c) 准入证书未过期；(d) 会话未处于撤销/老化越界。任一不满足 ⇒ 否决并降级。安全责任永远落在 r，而不是任何基础模型。

**定义 322（第三类不确定性 U_qual）** 在 R69 的 (U_ale, U_epi) 之外，定义**资格不确定性** `U_qual = min_{f} [(ρ_m^{LCB}(f,u) − d_f) / spread_f]`，即当前工况点到最近包络边界的「许用单位距离」。U_qual 不是关于世界的不确定性（问世界也问不出来），而是关于**工具是否仍适配当前工况**的不确定性；它只能由再资格/换料/降级来降低。R69 等价于 `U_qual ≡ +∞`（无条件信任单件工具）。

**定义 323（风险缩放合成）** `λ_total = max( λ_floor(U_ale + 未消解 U_epi), λ_mat(U_qual) )`，其中 λ_mat 随 U_qual→0 单调升向 1；若 U_qual ≤ 0（出包络）或 NO_ADMISSIBLE_MATERIAL，则 λ_total=1 并进入反射-only 最小认证动作。安全侧对 R69 单调：`λ_total ≥ λ_floor` 恒成立。

**定义 324（可追溯证书 J_MATTER）** `J_MATTER = (J_FLUID, portfolio_manifest_hash, selected_material_id, g_prov, E_m(D)_hash, μ_m 向量, QAT 记录, RQL_m, substitution_log_hash, matter_ver)`。Valid ⇔ Valid(J_FLUID) ∧ g_prov ≥ g_min ∧ μ_m ≥ 1 ∧ RQL_m > 0 ∧ QAT 未过期 ∧ 证书签名链可验。

**定义 325（供应链对抗干扰集）** 对手可：投毒微调数据（污染传播）、供应链换件（同名不同权重）、伪造材料试验报告（证书伪造）、对基准过拟合（尾部失效规避验收）、诱使老化（分布漂移）、利用接口错配（动作空间静默漂移）。定义 `ℰ_MATTER = ℰ_FLUID × ℰ_supply`，并入 AIC。审计除行为外还须**验证证书链 + 对已准入材料做抽样复测（QAT spot-check，控制使用方风险）**。

**定义 326（优雅降级阶梯）** MATTER → FLUID（R69：单材料、干净、在包络内）→ CALM（R68 纯保守）→ REFLEX-ONLY（仅本地反射）。每一级在能力上是前一级的子集、在安全上是前一级的超集；级间转移由 SUB 的迟滞与 RQL 驱动；任何一级都不得在未闭合许用的情况下向上恢复。

def allowables(m, D, task_dir):
    mu = {}
    for f in D.failure_modes:
        rho = m.directional_lcb(task_dir, f)      # 沿任务方向，禁止用均值
        mu[f] = rho / (m.SF[f] * D.demand[f])     # 组合许用
    return mu, min(mu.values())

# IP-266 MSEL：约束先行、性能后排序（Ashby 式）
def select_material(M, D, task_dir, budget):
    feas = []
    for m in M:
        if not budget.allow(m):                    continue       # 时延/算力
        if not m.iface.compatible():               continue       # 接口兼容
        if m.prov.grade < G_MIN or m.rql <= 0:     continue       # 溯源/老化
        if not m.envelope.contains(D):             continue       # 包络
        mu, worst = allowables(m, D, task_dir)
        if worst < 1.0:                            continue       # 许用闭合
        feas.append((m, mu, performance_index(m, D)))
    if not feas: return None                       # NO_ADMISSIBLE_MATERIAL
    return max(feas, key=lambda x: x[2])           # 仅在可行域内比性能

# IP-267 QAT：统计准入（控制使用方风险）
def acceptance_testens(m, D, n, c, p_min, alpha_C):
    X = run_trials(m, D, n)
    return weibull_lower(X, alpha_C) >= p_min or b10_life(X) >= TARGET

# IP-269 AGE：累计暴露—漂移—剩余资格寿命
def update_aging(m, psi, cof_res, fma_delta, dt):
    m.e += dt * exposure_weight(psi)
    m.drift = fusion(cof_res, fma_delta)           # 复用 R68/R69 通道
    m.rql = 1 - max(m.e / m.e_life, m.drift / m.drift_max)
    if m.rql <= 0: m.revoke()                      # 立即撤销准入

# IP-270 SUB：迟滞 + 原子性的替换治理
def maybe_substitute(cur, cand, dwell, J, h):
    if dwell < T_DWELL: return cur
    if J(cand) - J(cur) <= h: return cur           # 迟滞，防颤振
    if cand.iface != cur.iface: require_full_qat(cand)
    if executing_certified_prefix(): return cur    # 前缀内禁止换料
    return cand

# IP-272 VETO + IP-274 主闭环（继承 R69）
def MATTER_RAS_round(M, obs, task_dir):
    # 0) 资格前置：资格不闭合就没有 VoI，也没有动作
    m = M.msel.select(M.por, D, task_dir, M.budget)
    m = M.sub.maybe_substitute(M.current, m, M.dwell, M.J, H_HYST)
    if m is None:                                  # 无合格材料 → 反射-only
        return M.reflex.minimal_certified_action(obs, lam=1.0)
    # 1) 继承 R69：流匹配多模态 + 不确定性二分
    z, o = M.mtm.forward(m, obs)
    c, U_cal, thr = M.cof.step(o)
    K = 1 if M.fmp.mode_head(z, m) < TAU_MODE else 4
    samples = M.fmp.sample(m, o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z)
    # 2) 资格不确定性：包络余量 + 老化
    mu, worst = allowables(m, D, task_dir)
    U_qual = (worst - 1.0) if worst >= 1.0 else -1.0
    M.age.update_aging(m, obs.psi, M.last_r_res, M.last_dA, M.dt)
    # 3) 只有在包络内、资格有效时才允许 R69 的交互/似然层
    g = None
    if U_qual > TAU_QUAL and U_epi > TAU_EPI:
        g = M.mint.choose_interaction(modes, o, M.budget)
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    # 4) 向量许用 + 标量退避合成（安全侧只增不减）
    lam_vec = M.ams.compose(mu, U_ale, U_epi)
    lam = max(lam_floor(U_ale + (U_epi if g is None else 0.0)),
              lam_mat(U_qual))
    # 5) 提案 → 本地反射否决 → 认证前缀 → 执行
    A = M.ach.propose(modes, m, H=M.vista.H)

    # 6) 证书与审计（含证书链抽样复测）
    M.vqa_i.submit_async(m.id, mu, g, U_qual)
    return k, lam, lam_vec, m, J_MATTER(m, mu, U_qual)

## 3. 推导

**引理 19（方向许用优于各向同性均值）** 设沿任务方向 u 的真实许用为 ρ(u)，各向同性估计用 ρ̄ = mean(ρ)。当能力各向异性度为 A_m 时，存在方向 u* 使 `ρ̄ − ρ(u*) ≥ (1 − 1/√A_m)·(ρ_max − ρ_min)/2`。故仅按均值选型，会在最弱任务方向上**系统性高估**许用，高估量随 A_m 增长。系：材料选型必须沿任务方向取 LCB；R69 的全局 ECE 是 A_m=1 的退化。

**引理 20（包络外推的尾部风险）** 设部署工况分布 D_deploy 与资格工况 D_qual 的 KL 距离为 ε_D。若选择仅在 D_qual 上满足许用，则 D_deploy 上的期望失效概率 ≥ `exp(−ε_D)·P_fail(D_qual) + (1−exp(−ε_D))·P_tail`，其中 P_tail 为资格集合外尾部失效质量。只要 D_deploy ⊄ E_m(D_qual)，任何「在资格集上通过」的证书都不能推出部署安全。这是「证书只在资格分布内有效」的严格版本，也是本轮最大风险的数学化。

**引理 21（污染传播下界）** 若材料的祖先集 A_m 中 tainted 比例为 δ，且未做独立再资格，则其继承污染概率 ≥ `δ·(1−ε_leak)`，且 k 个共享祖先 k_eff 的证据源的有效独立性退化为 `1/k_eff`（R69 引理 18 的 ρ→1 极限）。故 provenance 必须做**祖先闭包**，否则「多源一致」只是复读。

**引理 22（准入抽样的使用方风险）** 对 (n,c) 抽样方案，若接受则真实可靠度 R 满足 `P(R < p_min) ≤ α_C`；等价地，接受的 B10 寿命下界覆盖目标。系：QAT 把「合格」从平均分变成**有置信度的下界**，并且可通过增大 n 收紧 α_C——代价是资格时间，这是一条可显式优化的成本-置信曲线。

**定理 18（MATTER 严格包含 FLUID/R69）** 当 |ℳ|=1、g_prov=g_min=1、D⊆E_m(D)、RQL>0、|F|=1 时，MSEL 仅可能选中该材料，SUB 不触发，VETO 对包络内提案恒通过，λ_mat(U_qual)→0；于是 MATTER 与 R69（FLUID）**逐指令相同**。进一步，任意状态下 `λ_total ≥ λ_floor`，且无合格材料时退化为反射-only，故 MATTER 的期望风险 ≤ R69 ≤ R68。安全侧严格单调，效率侧仅在可行域内获益。

**定理 19（无未资格执行与 Zeno 无关）** 由不变式 310-ii 与本地否决 321，任何出包络/无证书/过期提案在执行前被拦截的概率为 1（在反射已验证意义下）；由 SUB 的原子性与接口重验，认证前缀内不会发生包络越界；由 h>0、T_dwell>0，任意时域内换料次数 ≤ ⌈(J_max−J_min)/h⌉，系统不颤振、不产生 Zeno 切换。

**定理 20（复合体的安全不劣于其分量）** 若复合仲裁 arb 满足「对每个失效模式 f，仲裁输出落在至少一个分量 m_i 的许用域内」，且对相关失效施加 ρ 惩罚、对界面新失效 f_new 追加约束，则复合体 c 的可行域 ⊆ ∪_i 可行域_i，且 `P_fail(c) ≤ max_i P_fail(m_i) + P_interface`。系：复合不是免费午餐，但可以在「单材料无解」时把安全保持在分量上界附近，代价是接口失效项。

## 6. 本轮最大风险

**一句话**：MATTER-RAS 的全部安全性都押在「资格证据是**在正确工况分布上、对部署形态、未被伪造、且仍在寿命内**」这一前提上——**若资格用的工况分布 D_qual 与真实部署 D_deploy 错配（或验收被基准过拟合、证书链被伪造），系统就会为一件只在考场上合格的「材料」签发投产证书**；它会带着完整的证书、漂亮的平均分、却在一个从未被检验的失效模式或长尾方向上断裂——**材料不是因为它差而失效，而是因为它在自己许用包络之外被使用**；这与 R69「问错比不问更危险」同构：**验错，比不验更危险**。

**次级风险与缓解**：
1. **量化/编译改变了包络**（浮点合格、INT8 不合格）→ 定义 311 要求按部署形态资格，E303/E311 复测；
2. **接口静默错配**（动作空间/本体漂移）→ 定义 316-a 接口硬约束 + 换接口强制全量再 QAT（定理 19）；
3. **证书伪造与供应链换件** → 签名证书链 + 抽样复测（定义 325）+ E312；
4. **换料颤振与再资格成本爆炸** → 迟滞 h、驻留 T_dwell、原子性（定义 319、定理 19）+ E306；
5. **复合体的相关失效与界面新失效** → 相关惩罚 + f_new 显式入 F（定义 320、定理 20）+ E308；
6. **资格工况分布漂移**（最根本）→ 在线 D_deploy 与 D_qual 的分布检验 + 触发再资格，且一旦越界即撤销准入（定义 314、318、引理 20）。

**定义 314（DQE）** 对每个 `w_f>0` 的失效模式要求 `LCB_{1−β_f}[R_m(f,ψ)] ≥ R_min(f)`，`∀ψ∈supp(D)`；用保形 + Weibull 最弱链估计 `E_m(D)`，包络外不外推。R69 的全局 ECE = 单区域单模式特例。

**定义 315（AMS）** `μ_m = min_f C_f/(SF_f·d_f)`，准入要求 `μ_m≥1`；用向量 λ 替代标量，禁止跨失效模式腾挪余量。

**定义 316（MSEL）** `m* = argmax_{可行域} J(m)`，`J = η_task/(c_lat·c_risk)`；约束含接口、包络、产地、RQL、许用；可行集空 ⇒ `NO_ADMISSIBLE_MATERIAL`。

**定义 317（QAT）** (n,c) 验收抽样，控制生产方/使用方风险；接受 ⇔ `LCB_{1−α_C}(R) ≥ p_min` 或 B10 寿命达标。「合格」是频率学下界，不是一次基准平均。

**定义 318（AGE）** `RQL_m = 1 − max(e_m/e_life, drift_m/drift_max)`；`RQL≤0` 立即撤销准入，须整机再 QAT；仅局部再验只能恢复对应失效模式。

**定义 319（SUB）** 换料需成本；包络/接口变则先 QAT；迟滞 `J'−J>h` 且驻留 `≥T_dwell`；前缀内禁止换料；跨接口必须重验整条安全包络 ⇒ Zeno 无关。

**定义 320（CMF）** 单材料无解时复合；仲裁须满足逐失效模式落在某分量许用域内；相关失效 ρ 惩罚；界面新失效 `f_new` 入 F；复合体整体再资格。

**定义 321（VETO）** 本地反射 r 逐条检查：安全集、许用 μ≥1、证书未过期、未撤销/未老化越界；任一不满足即否决并降级。责任永远在 r。

**定义 322（U_qual）** 到最近包络边界的许用单位距离；不是「关于世界」的不确定性，问世界问不出来，只能靠再资格/换料/降级降低。R69 等价 `U_qual≡+∞`。

**定义 323（风险合成）** `λ_total = max(λ_floor, λ_mat(U_qual))`；出包络或无合格材料 ⇒ λ=1 + 反射-only 最小认证动作；对 R69 单调不减。

**定义 324（J_MATTER）** `Valid(J_MATTER) ⇔ Valid(J_FLUID) ∧ g_prov≥g_min ∧ μ≥1 ∧ RQL>0 ∧ QAT 未过期 ∧ 证书签名链可验`。

**定义 325–326（供应链对抗与降级阶梯）** `ℰ_MATTER = ℰ_FLUID × ℰ_supply`（投毒/换件/伪造报告/基准过拟合/老化诱导/接口错配）；降级阶梯 MATTER→FLUID→CALM→REFLEX-ONLY，能力递减、安全递增，未闭合许用不得上恢复。

# IP-264 POR + IP-265 DQE：材料库与工况资格包络
class PortfolioRegistry:
    def admissible(self, D, g_min):
        return [m for m in self.M
                if m.iface.ok(task) and m.prov.grade >= g_min
                and m.rql > 0 and m.envelope.contains(D)]

def fit_envelope(runs, D, beta, alpha):              # 保形 + Weibull 最弱链
    lcb = {f: weibull_lcb(runs[f], beta) for f in D.failure_modes}
    return Envelope(D, lcb) if conformal_covers(lcb, D, alpha) else None

# IP-268 AMS：失效模式专用许用值（向量，禁止用均值）
def allowables(m, D, u):
    mu = {f: m.directional_lcb(u, f) / (m.SF[f] * D.demand[f])
          for f in D.failure_modes}
    return mu, min(mu.values())

# IP-266 MSEL：约束先行，性能只在可行域内排序
def select_material(M, D, u, budget):
    feas = []
    for m in M:
        if not (budget.allow(m) and m.iface.compatible()):   continue
        if m.prov.grade < G_MIN or m.rql <= 0:               continue
        if not m.envelope.contains(D):                       continue
        mu, worst = allowables(m, D, u)
        if worst < 1.0:                                      continue
        feas.append((m, mu, performance_index(m, D)))
    return max(feas, key=lambda x: x[2]) if feas else None   # 空 → 反射-only

# IP-267 QAT：统计准入（控使用方风险）
def acceptance_test(m, D, n, p_min, alpha_C):
    R = weibull_lower(run_trials(m, D, n), alpha_C)
    return R >= p_min or b10_life(R) >= TARGET

# IP-269 AGE：暴露—漂移—剩余资格寿命
def update_aging(m, psi, cof_res, fma_delta, dt):
    m.e += dt * exposure_weight(psi)
    m.drift = fusion(cof_res, fma_delta)          # 复用 R68/R69 通道
    m.rql = 1 - max(m.e / m.e_life, m.drift / m.drift_max)
    if m.rql <= 0: m.revoke()

# IP-270 SUB：迟滞 + 原子性
def maybe_substitute(cur, cand, dwell, J, h):
    if dwell < T_DWELL or J(cand) - J(cur) <= h:  return cur
    if executing_certified_prefix():              return cur
    if cand.iface != cur.iface: require_full_qat(cand)
    return cand

# IP-274 主闭环（继承 R69，资格前置）
def MATTER_RAS_round(M, obs, u):
    m = M.msel.select(M.por, D, u, M.budget)
    m = M.sub.maybe_substitute(M.current, m, M.dwell, M.J, H_HYST)
    if m is None:                                  # 无合格材料 → 反射-only
        return M.reflex.minimal_certified_action(obs, lam=1.0)
    z, o = M.mtm.forward(m, obs); c, U_cal, _ = M.cof.step(o)
    K = 1 if M.fmp.mode_head(z, m) < TAU_MODE else 4
    samples = M.fmp.sample(m, o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z)
    mu, worst = allowables(m, D, u)
    U_qual = worst - 1.0
    M.age.update_aging(m, obs.psi, M.last_r_res, M.last_dA, M.dt)
    g = (M.mint.choose_interaction(modes, o, M.budget)
         if (U_qual > TAU_QUAL and U_epi > TAU_EPI) else None)
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    lam_vec = M.ams.compose(mu, U_ale, U_epi)
    lam = max(lam_floor(U_ale + (U_epi if g is None else 0.0)),
              lam_mat(U_qual))
    A = M.veto.filter(M.ach.propose(modes, m, M.vista.H), m, lam_vec)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    M.vqa_i.submit_async(m.id, mu, g, U_qual)
    return k, lam, lam_vec, m, J_MATTER(m, mu, U_qual)

## 4. 推导

**引理 19（方向许用优于各向同性均值）** 各向异性度 A_m 下，存在任务方向使 `ρ̄ − ρ(u*) ≥ (1−1/√A_m)(ρ_max−ρ_min)/2`；按均值选型会在最弱方向系统性高估许用。R69 全局 ECE = A_m=1 退化。

**引理 20（包络外推的尾部风险）** 若 `D_deploy ⊄ E_m(D_qual)`，则「资格集上通过」不能推出部署安全：`P_fail(D_deploy) ≥ e^{−ε_D}P_fail(D_qual) + (1−e^{−ε_D})P_tail`。证书只在资格分布内有效。

**引理 21（污染传播下界）** 祖先 tainted 比例 δ 且未独立再资格 ⇒ 继承污染 ≥ `δ(1−ε_leak)`；k 个共享祖先的证据源有效独立性退化为 `1/k_eff`（R69 引理 18 的 ρ→1 极限）。故 provenance 必须做祖先闭包。

**引理 22（验收抽样的使用方风险）** (n,c) 方案接受时 `P(R<p_min) ≤ α_C`，接受等价 B10 下界覆盖目标。QAT 把「合格」变成有置信度的下界，n 与 α_C 之间是可优化的成本-置信曲线。

**定理 18（MATTER 严格包含 FLUID/R69）** 当 |ℳ|=1、g_prov=1、D⊆E_m(D)、RQL>0、|F|=1 时，MSEL 只可能选中该材料，SUB 不触发，VETO 对包络内提案恒通过，λ_mat→0，MATTER 与 R69 逐指令相同；且恒有 `λ_total ≥ λ_floor`，无合格材料时退化为反射-only，故期望风险 ≤ R69 ≤ R68。安全严格单调。

**定理 19（无未资格执行与 Zeno 无关）** 不变式 310-ii + VETO ⇒ 出包络/无证书/过期提案在执行前拦截概率为 1；前缀原子性与接口重验 ⇒ 前缀内无包络越界；h>0、T_dwell>0 ⇒ 任意时域换料次数 ≤ ⌈(J_max−J_min)/h⌉，不颤振。

**定理 20（复合安全不劣于分量）** 若 arb 对每个 f 输出落在某分量许用域内，且对相关失效加 ρ 惩罚、对界面新失效追加约束，则可行域 ⊆ ∪ 分量可行域，且 `P_fail(c) ≤ max_i P_fail(m_i) + P_interface`。复合不是免费午餐，但能在单材料无解时把安全保持在分量上界附近。

## 7. 本轮最大风险

**一句话**：MATTER-RAS 的全部安全性都押在「资格证据是在**正确工况分布、部署形态、未伪造、仍在寿命内**」这一前提上——**若资格分布 D_qual 与真实部署 D_deploy 错配（或验收被基准过拟合、证书链被伪造），系统就会为一件只在考场上合格的「材料」签发投产证书**，它会带着完整证书、漂亮平均分，在一个从未被检验的失效模式或长尾方向上断裂——**材料不是因为它差而失效，而是因为它在自己许用包络之外被使用**；这与 R69「问错比不问更危险」同构：**验错，比不验更危险**。

**次级风险与缓解**：量化/编译改变包络（按部署形态资格 + E303/E311 复测）；接口静默错配（接口硬约束 + 换接口全量再 QAT）；证书伪造/供应链换件（签名链 + 抽样复测 + E312）；换料颤振/再资格成本（迟滞 + 驻留 + 原子性 + E306）；复合相关失效/界面新失效（相关惩罚 + f_new 入 F + E308）；资格分布漂移（在线 D_deploy 检验 + 越界即撤销准入）。
