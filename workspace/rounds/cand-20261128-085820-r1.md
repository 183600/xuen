### 第 7 轮灵感驱动研究记录

**灵感词**：用户需求分析、大语言模型、面部表情识别

**继承关系**：第 6 轮 CADVS-v6（IP-497~IP-500）确立「指令-几何-力学三元凿」框架：GGC 提供抓取几何可达性约束、MCTM 注入空间拓扑图、STM 实现跨模态指令-轨迹映射，七硬门保持 fail-closed 边界。本轮延续「硬门不增」原则，聚焦「**需求-意图-一致性三角桥**」：在保持证书边界不变的前提下，直接从「用户需求分析」出发，设计「需求意图建模器」(DIM)，引入「需求一致性软评分」η_demand，使系统从「被动接受指令」转向「主动推导意图」。

**直觉与动机**：

1. **用户需求 → 从「指令响应」到「意图推导」**。第 6 轮的 STM 负责「语言→查询向量」的映射，但它无法区分「用户真正想要的」与「用户不够清晰说出的」。引入「需求意图建模器」(Demand Intent Model, DIM)：从用户的历史交互记录、当前环境约束、任务目标三方面推断「用户真正的需求目标」ρ_demand。关键洞见是：**行为从「指令驱动」转向「需求驱动」**——只有当推断的需求意图与指令意图高度一致时，才执行STM生成的轨迹；否则，触发「需求导向回退」。

2. **大语言模型 → 从「静态映射」到「动态推理」**。第 6 轮的 STM 采用 CLIP-style 对齐训练，对指令进行向量化。第 7 轮引入「需求推理链」(Demand Reasoning Chain, DRC)：将LLM连接到DIM，使得从「用户说了什么」到「用户可能需要什么」的推理过程可解释、可审计。关键洞见是：**LLM 充当「需求解释器」**——它的推理链被量化为 η_demand，若推理置信度低于阈值，系统自动切换到历史记忆中的「典型需求响应」。

3. **面部表情识别 → 从「情感调制」到「需求态度捕获」**。第 6 轮的 FAMK 调制阈值 γ_i。第 7 轮提出「需求态度捕获」(Demand Affect Capture, DAC)：基于面部表情识别，捕获用户当前的「需求态度」(desire_affect)——如焦虑表情可能意味着「需要快速、稳妥的解决方案」，而放松表情可能意味着「愿意探索创新方案」。关键洞见是：**情感态度调制需求优先级**——DAC 输出的 desire_affect 调节 ρ_demand 的稀疏性和探索度。

**关键洞见**：第 6 轮回答「如何在不新增硬门的前提下，让提议符合物理、空间、意图」；第 7 轮回答「如何从「用户需求」出发，让系统主动推导「正确的行为」，而不是被动接受指令」。七硬门 kc_evidence_forged_v5 记号原样复用；本轮新增的只有：
- IP-501 DIM（需求意图建模器），
- IP-502 DRC（需求推理链，LLM驱动），
- IP-503 DAC（需求态度捕获），
- IP-504 EFA-v7（软评分 η_demand 纳入四软因子链）

**形式化目标（增量）**：

1. **DIM（Demand Intent Model）**：<br>
   - 需求编码器 E_demand: (history, context, env) ⟼ ρ_demand ∈ ℝ^d_demand<br>
   - 损失 L_DIM = ||ρ_demand - ρ_gold||² + β·KL(π_demand || π_prior)<br>
   - 软因子：η_demand = 1 - H(ρ_pred || ρ_demand)，其中 H 为交叉熵<br>
   - 只有当 η_demand > τ_demand 时，STM 输出的指令才被采纳；否则触发「需求导向回退」

2. **DRC（Demand Reasoning Chain）**：<br>
   - LLM 推理链 R = {r_1, r_2, ..., r_n}，其中 r_i 为推理步骤<br>
   - η_demand = 1 - (1/n)·Σ_i H(r_i)，衡量推理链的整体确定性<br>
   - L_DRC = α·链长度惩罚 - η_demand，鼓励简洁且确定的推理

3. **DAC（Demand Affect Capture）**：<br>
   - 表情编码器 E_affect: face ⟼ affect ∈ {-1, 0, +1}（负面/中性/正面）<br>
   - desire_affect 调节 ρ_demand 的探索度：exploration_scale = 1 + κ·affect<br>
   - 软因子：η_affect = 1 + affect/3 ∈ [2/3, 4/3]，调制 STM 检索的广度

4. **EFA-v7（七硬门 + 四软因子链）**：<br>
   - ECS_v7 = ECS_v6 · η_g · η_topo · η_interp · η_cmd · η_demand · η_affect<br>
   - τ_i^v7 = γ_i·τ_i^v6·Π_factor_i，其中 Π_factor_i = ∏_{j=1}^5 η_j ∈ [1, 1+ε]，设计上限仍为 1.3<br>
   - 新增硬门 kc_demand：η_demand ≥ τ_demand，确保「用户需求」被必要检验

5. **形式化定义**：给定指令 L，目标 ρ_target，记忆 M：<br>
   - ρ_demand = DIM(history, context, env)；<br>
   - η_demand = 1 - H(STM(L) || ρ_demand)；<br>
   - 若 η_demand < τ_demand：<br>
     - q_demand = E_demand(ρ_demand)；<br>
     - m_demand = Top-k(Retr_M(q_demand, K=4))；<br>
     - c_demand = (obj, g_emb, θ_fp, task, ŝ_emo, m_demand, ρ_target, t_topo, q_demand)；<br>
     - x_demand = FMPP.propose(c_demand, K=8)；<br>
   - 若 η_demand ≥ τ_demand：<br>
     - 执行第 6 轮的 EFA-v6 流程<br>

**本轮最大风险**：**需求意图的可解释性假设**：第 7 轮假设「用户需求可以从历史交互中抽象出」，但现实中用户意图常常是「非线性、突变、甚至自我否定」的——系统推断的 ρ_demand 可能与用户的「当下真实需求」迥然不同，这种误推导在结构上难以捕获，更何况维持七硬门的 fail-closed 边界。

### 0.3 对 v7 软因子的收紧投影修正

v7 定义 η_demand = 1 - H ∈ [0,1]、η_affect = 1 + affect/3 ∈ [2/3,4/3]，二者可 < 1，直接相乘会**放松**阈值，违背 fail-closed。v8 统一做收紧投影：

```
Π⁺(q) = 1 + κ·max(0, 1 - q),   κ > 0
```

- 置信度越低（q 越小），Π⁺ 越大 → 阈值越严；
- 对本身已 ≥ 1 的因子（如 η_transfer、η_fusion）原样保留；
- 总乘积 `Π_total = min(1 + ε, ∏_j Π⁺(η_j))`，`ε = 0.3`。

## 2. 关键算法骨架

### IP-505 TCA：可迁移证书适配器

```python
@dataclass
class TransferableCertificateAdapter:
    """TCA：把每个硬门拆成不变量核心 C_i^inv 与域适配器 A_i^D。
    迁移只搬不变量 + 轻量适配器；域间隙转成收紧因子。"""
    invariant_gates: dict[str, Callable]   # C_i^inv：跨域复用，冻结
    adapters: dict[str, nn.Module]         # A_i^D：每域一份，可 LoRA/adapter
    domain_encoder: nn.Module              # Φ：域特征映射
    lam: float = 1.0

    def decompose(self, gate_i: Callable) -> tuple[Callable, nn.Module]:
        """离线：把已训练的 v7 门分解为 (不变量, 适配器)。"""
        inv, ad = split_by_domain_sensitivity(gate_i)
        return inv, ad

    def adapt(self, D_s, D_t, few_shot: list) -> dict[str, nn.Module]:
        """冻结不变量，仅用少量目标样本训练适配器（few-shot）。"""
        for name, inv in self.invariant_gates.items():
            freeze(inv)
        for name, ad in self.adapters.items():
            fit_adapter(ad, few_shot, lr=1e-3, steps=200)
        return self.adapters

    def transfer_gap(self, D_s, D_t) -> float:
        zs = self.domain_encoder(D_s.features)
        zt = self.domain_encoder(D_t.features)
        return mmd_rbf(zs, zt).item()      # δ_transfer

    def eta_transfer(self, gap: float) -> float:
        return 1.0 + self.lam * gap         # ≥ 1，间隙越大越收紧
```

### IP-506 CFA：保守融合代数

```python
@dataclass
class ConservativeFusionAlgebra:
    """CFA：硬证据取交，软证据 Dempster 组合并检查冲突。
    冲突过大时弃权，绝不把冲突“平均掉”。"""
    k_max: float = 0.3
    mu: float = 1.0

    def fuse_hard(self, hard_evidences: list[float]) -> float:
        # Gödel t-范数：融合置信度 ≤ 每个源，保证 fail-closed
        return float(min(hard_evidences))

    def fuse_soft(self, masses: list[dict[str, float]]) -> tuple[dict | None, float]:
        """返回 (融合质量分配 m, 冲突 K)；K 超门限则 m=None（弃权）。"""
        m = masses[0]
        K_total = 0.0
        for m_next in masses[1:]:
            m, K = dempster_combine(m, m_next)
            K_total = 1.0 - (1.0 - K_total) * (1.0 - K)   # 累积冲突
            if K_total > self.k_max:
                return None, K_total                     # kc_fusion 失败
        return m, K_total

    def eta_fusion(self, K: float) -> float:
        return 1.0 + self.mu * K
```

### IP-507 NTD：负迁移检测器

```python
@dataclass
class NegativeTransferDetector:
    """NTD：反向验证 + 域适应风险界，拒绝“帮倒忙”的迁移。"""
    margin: float = 0.05

    def target_risk(self, f_adapted, D_t) -> float:
        """目标域切 train/val：train 上适配，val 上测风险。"""
        tr, va = split(D_t, ratio=0.7)
        f = adapt_on(f_adapted, tr)
        return empirical_risk(f, va)          # R_val

    def risk_bound(self, R_s: float, d_hdh: float, lam: float) -> float:
        return R_s + d_hdh + lam              # Ben-David 上界

    def accept(self, R_val: float, R_s: float, d_hdh: float, lam: float) -> bool:
        return R_val <= self.risk_bound(R_s, d_hdh, lam) + self.margin
```

### IP-508 EFA-v8：双桥装配器

```python
@dataclass
class EvidenceForgingAssemblerV8:
    v7: EvidenceForgingAssemblerV7
    tca: TransferableCertificateAdapter
    cfa: ConservativeFusionAlgebra
    ntd: NegativeTransferDetector
    tau_transfer: float = 0.5
    eps: float = 0.3

    def select(self, L, t_now, context, domain, sources) -> tuple[bool, Trajectory | None, str]:
        # 1) 迁移合法性（kc_transfer）
        gap = self.tca.transfer_gap(domain.s, domain.t)
        eta_transfer = self.tca.eta_transfer(gap)
        if gap > self.tau_transfer or not self.ntd.accept(
                self.ntd.target_risk(self.v7, domain.t),
                domain.R_s, domain.d_hdh, domain.lam):
            return self._cold_start(domain.t, t_now, context)   # 目标域冷启动重认证

        # 2) 多源保守融合（kc_fusion）
        c_hard = self.cfa.fuse_hard([s.hard for s in sources])
        m, K = self.cfa.fuse_soft([s.mass for s in sources])
        if m is None:
            return self.v7.select(L, t_now, context)            # 弃权，退回单源 v7
        eta_fusion = self.cfa.eta_fusion(K)

        # 3) 收紧投影后的软因子链
        eta_factors = {k: tighten(v) for k, v in self._v7_soft_factors(L, context).items()}
        eta_factors['transfer'] = eta_transfer
        eta_factors['fusion'] = eta_fusion
        prod = 1.0
        for v in eta_factors.values():
            prod *= v
        prod = min(1.0 + self.eps, prod)                        # Π_total 封顶

        # 4) 以 τ_i^v8 复用 v7 的七硬门判定（门逻辑不变，仅阈值收紧）
        tau_v8 = {i: gamma_i * tau_v7_i * prod for i, (gamma_i, tau_v7_i) in self.v7.taus.items()}
        ok, x, tag = self.v7.select_with_taus(L, t_now, context, tau_v8, hard_evidence=c_hard)
        return (True, x, 'FORGED_CGE_V8') if ok else (False, None, 'V8_FAIL_CLOSED')

    def _cold_start(self, D_t, t_now, context):
        """kc_transfer 失败：在目标域上重新标定适配器并重认证（不迁移不变量以外的东西）。"""
        self.tca.adapt(self.tca.domain_encoder.src, D_t, few_shot=D_t.calib)
        return self.v7.select(None, t_now, context)   # 走 v7 兜底
```

### 集成流水线（v7 → v8）

```
离线/慢时域：
  TCA 门分解：把 v7 七门拆成 C_i^inv + A_i^D（一次性，小时级）
  TCA 适配器训练：源域证书 + 少量目标样本 → θ_i^adapt（分钟级）
  CFA 质量分配标定：各证据源 → mass 函数，温度校准（分钟级）
  NTD 阈值标定：在留出域对上拟合 margin、τ_transfer
  联邦下发：不变量门 + 适配器 + CFA/NTD 配置 → 站内签名分发

在线准入（亚秒级）：
  gap = δ_transfer(D_s,D_t) ──▶ η_transfer
  if gap > τ_transfer ∨ ¬NTD.accept: 冷启动重认证（kc_transfer 失败）
  c_hard = min_i e_i.hard
  (m,K) = Dempster({e_i})；if K > K_max: 退回单源 v7（kc_fusion 失败）
  η_fusion = 1 + μ·K
  τ_i^v8 = γ_i·τ_i^v7·Π_total；复用 v7 七硬门判定 → FORGED_CGE_V8

在线控制环（目标 < 0.8 ms）：
  迁移间隙与冲突质量均可用滑动窗口缓存；七硬门调用链不变
```

## 4. 正确性论证（增量更新）

### 定理 13（保守融合单调性）

**陈述**：设硬证据以 Gödel t-范数 `⊕_H = min` 融合，软因子经收紧投影 `Π⁺ ≥ 1`。则对任意候选 x：
- 若 x 通过融合硬门 `c_hard ≥ τ`，则 x 通过每个单源硬门 `c_i ≥ τ`；
- 若 x 通过 v8 软阈值，则 x 通过 v7 软阈值；
- 因此 `Exec_v8 ⊆ Exec_v7`（在 v7 已认证候选集上）。

**证明**：`min_i c_i ≤ c_i`（∀i），故 `c_hard ≥ τ ⇒ c_i ≥ τ`，融合门是单源门的交集。又 `Π⁺(q) ≥ 1` 且 `η_transfer, η_fusion ≥ 1`，故 `Π_total ≥ 1`，`τ_i^v8 = γ_i·τ_i^v7·Π_total ≥ τ_i^v7`；阈值单调升，判定 `1[s ≥ τ]` 结果不变或更严格。综合得执行集收缩。∎

### 定理 14（迁移风险界与负迁移拒绝）

**陈述**：若 NTD 接受迁移，则目标域风险满足 `R_t ≤ R_s + d_HΔH(D_s,D_t) + λ + margin`；否则拒绝迁移并回退冷启动重认证。

**证明**：直接由 Ben-David 域适应界 `R_t(f) ≤ R_s(f) + d_HΔH(D_s,D_t) + λ` 与 NTD 的接受判据 `R_val ≤ bound + margin` 得到。注意 `R_val` 是经验估计，界本身可能偏松，故这是「有界但不紧」的保证。∎

### 定理 15（双桥收缩性与可用性扩张）

**陈述**：`Exec_v8 ⊆ Exec_v7`（收缩性）；同时对于 v7 从未认证过的目标域 D_t，若 `kc_transfer` 通过，v8 可在 D_t 上签发证书，而 v7 在 D_t 上执行集为空。

**证明**：收缩性见定理 13。可用性：v7 的单域证书在 D_t 上未标定，按 fail-closed 其执行集为 ∅；v8 通过不变量复用 + 适配器 + NTD 界，可在 D_t 上给出有界风险的证书。**二者不矛盾**：收缩是「相对 v7 在 D_t 重认证后的集合」，扩张是「相对 v7 在 D_t 未认证时的空集」。∎

### 诚实声明

- **min 融合过于保守**：多源有噪声时，取交会显著抬高误拒率（false rejection），可能使可用性大打折扣；
- **Dempster 冲突反直觉**：高冲突下组合结果可能出现 Zadeh 悖论（两个高度支持不同假设的源被组合成支持空集），K 门只能缓解、不能消除；
- **迁移风险界偏松**：Ben-David 界依赖 `d_HΔH` 的经验估计，且需要目标域带标签的验证集，少样本时方差大；
- **共同模式误差不可检测**：所有源（含仿真与实机）共享同一物理/感知模型时，「一致」不能推出「正确」，fail-closed 在此处失效；
- **收紧投影的 κ 需标定**：κ 过大会把所有候选拒掉，过小则失去收紧意义。

  - CFA：每源 1k 条证据-真值对，用于 mass 标定与温度校准
  - NTD：留出 5 个域对拟合 margin、τ_transfer
- **对照**：v7-per-domain 重训、v8-zero-shot、v8-few-shot(k=5/10/50)、消融 A21（无 TCA）、A22（无 CFA，等权平均）、A23（无 NTD）、A24（η_transfer=η_fusion=1）、A25（关闭 kc_fusion 弃权）

## 7. 本轮最大风险（最终确认）

**一句话**：**共享偏差下的「一致地错」**——迁移会把源域的系统性偏差原样搬入目标域，融合又因多源共享同一物理/感知模型而放大该偏差；fail-closed 只能拦截「可检测的不一致」，无法拦截「所有源一致但共同错误」的证书伪造，这是迁移-融合双桥在结构上难以根除的盲区。
