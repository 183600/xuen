# 第 44 轮（新循环第 4 轮） · Peer-Reviewed Diffusion Policy：把「随机提议」与「同行评审」缝合为可复现、可撤回的证书生命周期（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形边际覆盖 + 多用户契约空集」。但它仍压着两个未言明的单点假设：**(H1) 提议空间可被有限枚举并逐支认证**——v20 的 b 路投机分支是离散有限集；若动作来自扩散策略，提议是连续、多峰、随机的分布，有限采样永远无法代表全体，「逐支认证」的 soundness 论证会静默失效；**(H2) 证书一旦签发即永久有效**——v20 有租约衰减却没有「撤回」，若上游证书事后被证伪（感知漂移、评审失误、对抗样本），已签发证书及其下游计划仍被使用，且跨机构无法复现审计。本轮灵感词「扩散策略」「论文发表」恰好命中这两个假设：**扩散策略**要求把「提议」与「认证」彻底解耦——用过滤构造 sound 策略，用去噪时证书换 anytime 早退，用在线风险控制守住长程误收率；**论文发表**要求把证书当作一篇可评审、可复现、可撤稿的论文来治理——安全评审一票否决、工件可重放、依赖可追溯、撤稿可传播。二者耦合处（评审引导采样 × 评审被劫持）是本轮真正的新问题。

## 0. 直觉与动机

**灵感 1（扩散策略 → 提议是分布，不是分支集合；安全性必须从「枚举」搬到「过滤」）**：扩散策略 q_θ(a|o) 通过 K 步去噪从噪声生成动作，天然多峰、随机、可引导。直觉上我们永远无法枚举它所有可能的输出并逐一认证，因此「认证 b 个分支」的旧论证不成立。正确姿势是把「提议」与「认证」分成两个独立职责：**q_θ 只负责提议，验证器 V 只负责把关**，实际部署的是过滤后的策略 π ∝ q_θ·V。只要 V 是 sound 的，π 的支持集就被限制在安全集内，**与扩散模型好坏无关**；扩散模型的质量只决定「接受率 ρ = E_q[V]」（可用性）和任务成功率，而不决定安全性。这一步把不可证的生成模型从安全论证中彻底摘出去，代价是全部安全压力落到 V 上——因此 V 本身需要「验证器的验证器」：用慢速精确 oracle 校准快速 V 的误收率，并用在线保形风险控制（ACRC）在分布漂移下守住长程误收率。

**灵感 2（去噪时证书 → 把「还要去噪多久才能证明安全」变成可计算量）**：去噪是 anytime 的：越接近 k=0，预测的干净动作 â_0^k 越准、剩余随机性越小。若能对「从当前 a^k 出发、任意补全剩余去噪链后，最终动作离 â_0^k 有多远」给出**认证半径 R_k**（由去噪器的区间界传播或复合 Lipschitz 界出），则当 margin(â_0^k) ≥ R_k 时，所有补全终点的动作都仍在安全集内，可以**提前停止去噪并签发租约**。这比「全部去噪完再验」更早拿到新鲜证书，直接复用 v20 的租约新鲜度收益；且它把「anytime」从工程口号升级为一条带收缩界的证书：预算耗尽仍未认证，就拒发并回退，绝不部署未认证动作。

**灵感 3（论文发表 → 证书不是签发，而是评审、复现、撤稿的完整生命周期）**：一篇论文要经过投稿、同行评审、rebuttal、camera-ready、最终可被撤稿；证书也应如此。**(a) 同行评审**：把验证器组织成异构评审团——确定性 CBF 监控器、区间几何证明器、硬件异构 INT8 监控器组成**硬评审（安全否决）**，学习型能力模型与人格/风格模型组成**软评审（只排序）**；硬评审必须全票通过且来源失效域互不重叠（抗共模），软评审即使合谋也无法放行不安全动作。**(b) 可复现**：每个发布动作携带工件（种子、去噪轨迹摘要、代码/校准集哈希、评审签名），第三方可重放并得到同一决策——这正是竞赛评委/监管审计需要的「camera-ready」。**(c) 撤稿**：证书构成依赖 DAG，一旦上游被证伪，撤回沿依赖闭包传播，撤销所有派生租约并原子切换到安全回退——补上 v20 缺失的「证书撤销」语义。**(d) rebuttal**：拒绝时返回最小反例，提议方最小修补后重投，即带预算的 CEGIS。

**耦合升级**：评审不只是「闸门」，还可以是「梯度」——把硬/软评审的 margin 做可微松弛，作为引导势 Φ 注入去噪过程，让采样更常落在可认证区域，从而提高接受率、降低延迟；但引导**永远不能绕过过滤器**。风险也随之升级：引导会朝评审的盲区做奖励黑客，多个评审若共享同一感知骨干则共模失效会让「一票否决」形同虚设。于是 IP-60（DPE，扩散提议 + 去噪时证书 + 在线风险控制）、IP-61（PRP，评审协议 + 可复现工件）、IP-62（CLL，证书生命周期账本 + 撤回传播）共同把 v8 的「人格-并发证书层」升级为 v9 的「生成-评审-撤回」闭环。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（扩散提议、过滤策略与验证器风险控制）**：观测 o 下扩散策略给出提议分布 q_θ(a|o)（a 为动作块 a_{0:H}）。设验证器 V(a,o)∈{0,1}，其 soundness 前提为 V(a,o)=1 ⇒ a∈C_global∩Π_u。定义**过滤策略** π_V(a|o) = q_θ(a|o)·V(a,o) / Z(o)，其中 Z(o)=E_{q_θ}[V] 为**接受率 ρ(o)**。**命题 44.1（过滤即 sound）**：若 V sound，则 P_{π_V}(a∈C_global∩Π_u)=1，与 q_θ 无关；q_θ 仅通过 ρ 与任务成功率影响可用性/性能。**命题 44.2（验证器的验证器）**：设慢速精确 oracle O 满足 O=1 ⇒ a∈C；快速验证器 V_τ 按阈值 τ 接受。定义误收风险 R(τ)=P(V_τ=1 ∧ O=0)。在可交换性下用 split conformal risk control 取 τ̂ 使 P(R(τ̂)≤α)≥1−δ；在分布漂移下用在线 ACRC 更新 τ_{t+1}=τ_t+γ(α−L_t)，L_t=1[V_{τ_t}=1∧O_t=0]，则长程误收率 ≤ α+O(γ)（漂移有界时）。**推论**：我们不对扩散网络作任何正确性假设；安全成本被完全转移到「V sound + V 的误收被校准」这一可审计命题上。

**定义 45（去噪时证书 DTC 与早退 sound 性）**：记第 k 步预测的干净动作为 â_0^k= D(a^k,o,k)。设**认证半径** R_k(a^k,o) 是「从 a^k 出发、对任意剩余噪声实现与有界网络误差，最终 a_0 与 â_0^k 的距离」的上界，可由去噪器区间界传播（IBP）或复合 Lipschitz 界给出。定义 m_k = margin(â_0^k, C_global∩Π_u) − R_k，其中 margin 为到安全集补集的 1-Lipschitz 有符号距离。**命题 45.1（早退 sound）**：若 R_k 是 sound 上界且 margin 1-Lipschitz，则 m_k ≥ 0 ⇒ 所有补全终点 a_0 均满足 margin(a_0) ≥ margin(â_0^k) − ||a_0−â_0^k|| ≥ 0，即 a_0∈C_global∩Π_u。取 k* = max{k : m_k ≥ 0} 为最早可认证步；若不存在则拒发。**推论**：去噪延迟从 K 步降到 K−k* 步，租约更早签发、更新更频繁，按 v20 定义 41 的新鲜度判据可用性严格不降；代价是 R_k 低估会导致假早退，必须设红线实验。

**定义 46（评审团与安全否决聚合）**：评审团 R = S ⊎ C ⊎ P：S 为硬评审（确定性 CBF 监控器、区间几何证明器、硬件异构 INT8 监控器），C 为能力/任务评审，P 为人格/风格评审。每条评审输出 r_i∈{accept,reject,abstain}、置信度与证据哈希。**聚合规则 M**：接受当且仅当 (i) 所有 s∈S 均 accept；(ii) 评审团满足**共模独立性** Ind(S)：对任意单一故障 f∈F，至多一个 s∈S 受 f 影响；(iii) 证书工件可复现（定义 47）。C/P 只参与排序，不参与安全放行。**定理 46.1（一票否决的鲁棒性）**：若每个 s∈S 在无故障时 sound，且 Ind(S) 成立，则在至多一个故障下，M 接受 ⇒ a∈C_global∩Π_u，且与 C/P 是否合谋无关。*证明草图*：全票接受时，至多一个 s 可能 faulty，其余至少一个 sound 且 accept，由 sound 性得 a∈C；若任一 sound 评审 reject，则 M 拒绝。**注**：S 若共享同一感知骨干/训练分布，Ind(S) 被破坏，整个否决机制失效——这是本轮头号风险。

**定义 47（可复现证书工件与发表契约）**：证书工件 A = (h_o, h_a, seed s, H_trace, h_code, h_cal, τ, θ, {r_i}, deps)，其中 h_o/h_a 为观测与动作哈希，H_trace 为去噪轨迹摘要，h_code/h_cal 为代码与校准集哈希，deps 为依赖证书 id。**决策级可复现**：replay(s,h_o,h_code,h_cal) 产生同一 accept/reject 且 margin 区间相交（允许跨硬件浮点差异，不要求逐比特一致）。**发表契约**：动作只有在工件完整且 replay 通过（**camera-ready**）时才可发布；缺工件或 replay 失败为 **desk-reject**。工件入账本后不可篡改（哈希链 + 评审签名），供第三方审计。

**定义 48（证书依赖 DAG 与撤回传播）**：证书集合 C 与依赖边 E 构成 DAG D=(C,E)：c→c′ 表示 c′ 的结论或假设依赖 c。状态 status(c)∈{valid,retracted}。**撤回事件** retract(c,r) 计算**依赖闭包** Closure(c)={c′: c ⤳ c′}，将其中全部证书置为 retracted，撤销由它们派生的所有租约，并要求使用这些证书的守卫在 Δ_retract 内切换到安全回退。**撤回屏障**：账本 epoch 单调递增；守卫在每次决策前检查 epoch 一致性与祖先状态（O(depth) 哈希）。**定理 48.1（撤回 sound）**：若 E 过近似真实依赖（任何实际使用都被一条边表示），则屏障之后不存在守卫使用已撤回证书；守卫的局部 soundness 不被破坏。*证明草图*：维护不变式「被守卫使用的证书及其所有祖先均 valid」；撤回闭包恰好打破该不变式于 Closure(c)，屏障 + 祖先检查恢复之；在飞行中的动作要么在 epoch 前完成，要么被复核。**推论**：撤回来迟界 ≤ 最大守卫周期 + 闭包计算时间；缺口只可能来自「漏声明依赖」，故依赖边应由工具从读写集/假设集自动生成。

**定义 49（评审引导扩散与反驳-CEGIS）**：设评审势 Φ(a,o)=Σ_i w_i·φ_i(a,o)，φ_i 为硬/软评审 margin 的可微松弛。引导去噪步：a^{k−1}=μ_θ(a^k,k)+σ_k z − η∇_aΦ(a^k,o)。**命题 49.1（引导不破坏 sound）**：引导只改变提议分布 q_g，最终仍经定义 44 的过滤器，故 P_{π_{V,g}}(a∈C)=1（当 V sound）；引导的收益仅体现在接受率增益 Δρ 与延迟。**约束**：以失真 D=sup_o TV(q_g(·|o),q(·|o))≤δ 为预算最大化 E[Δρ]；且 R_k 必须把 η·L_{∇Φ} 计入半径，否则假早退。**反驳-CEGIS**：拒绝时评审返回最小反例 a^×；提议方执行最小修补 q←Repair(q,a^×)，并缓存 (o 模式, a^×, 修补增量) 到 CKB；反驳预算 B_r 耗尽则 desk-reject→安全回退。在有限假设类且修补测度单调下降时过程终止。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 DIFFUSION-PROPOSAL-ENGINE（扩散提议引擎 DPE）
1. **并行提议池**：b 条独立 seed 的去噪链并行展开（复用 v20 并发分支池），每条记录 â_0^k 轨迹与 R_k。
2. **去噪时证书早退**：按定义 45 用 IBP/Lipschitz 半径求 k*，最早可认证即停；预算耗尽未认证则拒发。
3. **过滤发布**：只有验证器接受的动作可进入评审；空接受集触发协商或安全停机。
4. **验证器校准**：慢速 oracle 抽样审计 + split conformal / 在线 ACRC 维护阈值 τ，按定义 44 控制误收率。
5. **引导钩子**：暴露 ∇Φ 接口，但半径计算把引导 Lipschitz 计入；引导仅提高接受率，不参与放行。

### 2.2 IP-61 PEER-REVIEW-CERT-PROTOCOL（同行评审协议 PRP）
1. **异构评审团编排**：硬评审 S 至少两个不同失效域（确定性 CBF 监控 + 区间几何证明器 + 硬件异构 INT8 监控任选其二），软评审 C/P 只排序。
2. **安全否决聚合**：实现定义 46 的 M 与 Ind(S) 检查；缺独立性签名直接 desk-reject。
3. **可复现工件**：生成定义 47 的 A，哈希链入账；camera-ready 门控发布。
4. **rebuttal-CEGIS**：最小反例 → 最小修补 → 重投；预算受限，缓存修补增量。
5. **红队审计**：模拟评审合谋、共模注入、置信度投毒，定期抽检评审校准。

### 2.3 IP-62 CERT-LIFECYCLE-LEDGER（证书生命周期账本 CLL）
1. **依赖 DAG**：从读写集/假设集自动生成边，禁止手写（防漏声明）。
2. **撤回事件源**：在线监控违例、审计发现错误、校准漂移、对抗样本、外部 CVE。
3. **闭包传播 + epoch 屏障 + 租约撤销**：实现定义 48；撤回风暴时按关键级限流，防级联雪崩。
4. **审计重放**：按工件哈希重放任意历史决策，输出取证轨迹。
5. **生命周期状态机**：submitted→under_review→accepted(camera-ready)→retracted，全状态可查询。

### IP-60 DPE：提议、去噪时证书、过滤与验证器校准
```
def diffusion_proposal(o, q_theta, b_seeds):
    # b 条独立 seed 去噪链并行；每条记录 â_0^k, IBP 半径, 轨迹摘要
    return parallel_map(lambda s: denoise_trace(q_theta, o, seed=s),
                        range(b_seeds))

def certified_radius(trace, k):
    # 覆盖剩余噪声与 |ε_θ|≤δ；若启用引导，必须计入 η·L_gradPhi
    return trace.ibp_radius[k]        # 定义 45；低估即假早退

def dtc_early_exit(trace, persona):
    for k in range(trace.K, -1, -1):  # 从剩余步最多（最早）处开始
        a_hat = trace.x0_pred[k]
        R     = certified_radius(trace, k)
        if margin(a_hat, C_global, persona) - R >= 0:
            return k, a_hat, R        # 最早可安全早退点
    return None

def filtered_release(o, q_theta, V_fast, persona, budget_us):
    t0 = monotonic_now()
    accepted = []
    for tr in diffusion_proposal(o, q_theta, B_SEEDS):
        if monotonic_now() - t0 > budget_us:
            break                      # anytime 截止：未认证即弃
        ex = dtc_early_exit(tr, persona)
        if ex is None:
            continue
        k, a, R = ex
        if V_fast.accept(a, o, persona):        # 唯一放行入口
            accepted.append(Candidate(a, tr.digest, k, R))
    if not accepted:
        return negotiate_or_safestop()          # 空接受集绝不静默放行
    return accepted

def acrc_update(tau, alpha, gamma, audit):
    loss = 1 if (audit.fast_accept and not audit.exact_accept) else 0
    return clamp(tau + gamma * (alpha - loss), TAU_MIN, TAU_MAX)
```

### IP-61 PRP：硬评审否决、可复现工件与 rebuttal-CEGIS
```
def peer_review(cand, o, panel, ledger):
    hard = panel.soundness
    if not independent(hard):                   # Ind(S)：至多单故障
        return desk_reject("no_independence")
    reviews = parallel_map(lambda s: s.review(cand.a, o), hard)
    if not all(r.accept for r in reviews):      # 硬评审全票否决
        return Reject(reviews)
    soft = parallel_map(lambda r: r.review(cand.a, o),
                        panel.competence + panel.persona)
    artifact = make_artifact(o, cand, reviews, soft)
    if not replay_equal(artifact, ledger):      # camera-ready 门控
        return desk_reject("not_reproducible")
    ledger.append(artifact)                     # 入账即发布
    return Accept(cand.a, artifact, score=aggregate_soft(soft))

def rebuttal_cegis(o, q_theta, panel, ledger, B_r):
    for _ in range(B_r):
        cands = filtered_release(o, q_theta, panel.fast, persona, budget_us)
        if is_accept(cands):
            return cands
        cx = panel.last_counterexample()        # 最小反例
        q_theta = minimal_repair(q_theta, o, cx)
        ckb.put(pattern(o), cx, delta(q_theta)) # 缓存修补增量
    return safeguarded_desk_reject()            # 预算耗尽 => 拒发
```

### IP-62 CLL：撤回闭包、epoch 屏障与守卫祖先检查
```
def retract(cert_id, reason, ledger):
    closure = reachable(ledger.dag, cert_id)    # 依赖闭包（含自身）
    ledger.epoch += 1                           # 撤回屏障
    for c in closure:
        ledger.status[c] = RETRACTED
    revoke_leases(closure)                      # 撤销派生租约
    for g in guards_using(closure):
        g.fallback(reason)                      # 原子切换安全回退
    ledger.log("retract", cert_id, closure, reason, ledger.epoch)
    return closure

def guard_admit(cert, ledger):
    # O(depth) 祖先有效性检查；与 epoch 一致性共同构成撤回屏障
    return (ledger.epoch_consistent()
            and all(ledger.status[a] == VALID
                    for a in ancestors(ledger.dag, cert)))
```

## 6. 本轮最大风险

**一句话**：整套安全性最终压在「硬评审真的 sound 且彼此独立」这一条上——若硬评审与扩散提议共享同一感知骨干、同一训练分布或同一硬件失效域，共模故障会让全票否决形同虚设，而评审引导扩散会精准地朝评审盲区做奖励黑客，产生「工件完全可复现、决策却系统性错误」的静默不安全，因此必须异构硬评审 + 独立校准 + 红队审计，并把「无独立硬评审签字即拒发」设为不可协商的底线。
