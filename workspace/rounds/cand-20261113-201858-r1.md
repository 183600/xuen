# 第 69 轮（承接第 68 轮「CALM-RAS 自标定风险自适应闭环」IP-243~252；灵感循环第 2 轮；本轮灵感：「智能体」×「碰撞检测」×「策略性交互」）

> 第 68 轮把「测量本身的可信度」补进了闭环，并用在线标定把漂移从故障假设里分离出来。但它自陈的最大风险暴露了一个更深的结构性缺口：**系统始终把人类当作「会发信号的被测对象」，把接触当作「要避免的几何事故」，而从未把对方建模为会观察、会适应、甚至会利用机器人策略的智能体**。于是 R68 的「缓变故障被标定吸收」并非滤波器缺陷，而是**缺少一个外生的、非自证的物理锚点**：当所有通道都在同一个漂移模型里自洽时，标定越强，世界越像它自己。
>
> 本轮的灵感恰好提供两块拼图：**智能体**把人类从「标签源」升级为「策略源」（有目标、有风险偏好、会反应、可欺骗）；**碰撞检测**把接触从「事故」升级为「计量事件」（跨模态、脉冲式、因果共享，且天然落在标定带宽之外）。合成命题：
>
> **把接触当作智能体之间共享的、不可被慢标定吸收的物理真值锚，把机器人升级为会在安全包络内主动设计「信息性接触」的计量智能体——ACRA（Agent–Collision Risk Adaptation，智能体–碰撞计量风险自适应闭环）。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**对方是谁、他会怎么利用我，以及我能不能用一次安全的接触把不确定性钉死**」。

## 0. 直觉与动机

**灵感 1（智能体 → 人类不是信号源，而是策略源）**
直觉：R66 的假笑欺骗、R68 的缓变故障不可辨识，本质上是同一个假设在作祟——观测通道的统计特性与智能体的意图无关。但一个智能体会**观察机器人的策略并最优反应**：机器人越保守，人类越敢贴近；机器人越依赖面部线索，人类越有动机管理表情。把人类建成层级 1 的交互式 POMDP（I-POMDP）智能体：类型 θ_h =（目标 g、风险敏感度 ρ、诚实度 σ、对机器人的信念 b_h），情绪 e_t 是一种**有成本的信号动作**，而不是一个被动标签。行为（轨迹、接近速度、接触）是比表情昂贵得多的信号，因而更难伪装。情绪识别从「分类」变成「逆博弈推断」：由行为反推类型，再由类型反推情绪与意图。

**灵感 2（碰撞检测 → 接触是唯一不可自证的物理锚）**
直觉：碰撞检测在图形学里解决的是「离散采样会漏掉高速穿透（tunneling）」，核心工具是扫掠体、连续碰撞检测（CCD）、保守推进（conservative advancement）、GJK/EPA 与可达集。把它搬进风险闭环，得到两个直接收益：(a) **时间隧穿界**——若风险审计的采样间隔 Δt > d_min/v_max，快速逼近的智能体可以在两帧之间穿过安全边界而不被任何一帧发现；CCD 给出避免隧穿所需的最小审计频率；(b) **接触事件是物理真值**——接触瞬间的冲量是宽带的（ω ≫ ω_cal），跨模态同时出现（力/触觉、声音、视觉形变、关节电流），且**因果共享**（双方都感受到同一次接触）。因此它不可能被 R68 的慢标定滤波器吸收，反而能作为外生锚点重置标定协方差。近失（near-miss）更常见，是零成本的几何标签：d_min → 0 时，标定后残差应同步趋零，否则说明标定在自欺。

**灵感 3（合流 → 接触既是威胁也是信息，机器人应主动计量）**
直觉：传统安全把接触一律当失败；但计量学里，「用已知基准去触碰」恰恰是最可靠的校准手段。于是出现一个全新的决策对象：**信息性接触（informative contact）**。在硬安全包络内（低能量、已知几何、可回退、人在可达域外或有知情同意），机器人可以主动发起一次「探针接触」，用已知基准面/基准点去激发一个标定观测，把 R68 里「缓变故障 vs 缓慢漂移」这个不可辨识对分开。目标函数不是「最大化信息」，而是「**单位风险的信息增益**」：IGR = I(θ; y | a_probe) / (ε + CVaR_β(R_col))。探针只在标定不确定度超过阈值、且信息增益足以覆盖风险预算时发起，且必须先过探针认证（PCC），绝不进入 2.6ms 实时安全环。

**灵感 4（对 R65–R68 风险的对症下药）**
- R68「缓变故障被标定吸收」：接触锚是脉冲式外生观测，且要求「无独立锚点的慢漂移一律冻结」，把标定从自证循环里拽出来；
- R66「假笑/情绪欺骗」：新增行为—接触—表情三通道一致性 r_agent，行为与接触比表情更难伪装；
- R67「WM 前瞻在 Sim2Real 偏移下失真」：GRCD 用可达集而非单条轨迹做连续碰撞检测，前瞻不再依赖单点预测；
- 贯穿四轮的「过度放宽」：把责任分配（RSS）与意图不确定度并入 λ_floor，任何「对方不可测」都只导向收紧。

**灵感 5（七组件 ACRA）**
1. **IATM** 交互式智能体理论模型（人类类型后验 + 逆博弈情绪推断）；
2. **GRCD** 博弈风险感知连续碰撞检测（可达集 CCD + 时间隧穿界 + CVaR 风险泛函）；
3. **CEA** 接触事件锚（宽带冲量事件 → 外生标定观测）；
4. **COF+** 事件触发的混合标定滤波（慢滤波 + 有界跳变）；
5. **APA** 主动探针智能体（IGR 目标 + 安全包络约束）；
6. **PCC** 探针认证与章程（五关 + 接触预算 + 知情/可回退）；
7. **XCD** 跨通道欺骗检测（表情 / 行为 / 接触三环）；
8. **RAS-ACRA†** 继承 CALM-RAS；实时环只做 GRCD 保守避撞，探针与标定锚都在慢环。

## 1. 形式化定义（增量：定义 293–310）

**定义 293（ACRA 总览）** ACRA = (IATM, GRCD, CEA, COF+, APA, PCC, XCD, RAS-ACRA†)。不变式三升级：
(i) **接触硬红线优先于信息收益**：任何执行动作（含探针）必须满足 CVaR_β(R_col) ≤ R_budget 且峰值接触冲量 ≤ J_safe；不可逆损伤风险为 ∞ 时一律禁止；
(ii) **实时/慢环分离**：2.6ms 实时环只允许 GRCD 的保守避撞与安全滤波；IATM 更新、CEA 标定跳变、APA 探针规划全部在 ≤1Hz 慢环；
(iii) **无锚不标定**：只有 COF 残差自洽、而无独立接触/近失锚点支撑的慢漂移，一律不得进入标定吸收；无锚时按 R68 最坏情况冻结（U 视为 ∞）。

**定义 294（IATM 交互式智能体类型）** 人类是层级 1 I-POMDP 智能体：类型 θ_h = (g, ρ, σ) ∈ Θ，g 为目标（让路/并行/穿越/求助），ρ 为风险敏感度，σ 为诚实度；策略 π_h(a_h | b_h, θ_h) 是对机器人策略 π_R 的最优/有界理性反应。机器人维护联合后验 b_t(θ_h, b_h)。情绪 e_t ∈ Δ^4 是有成本信号动作；面部观测是 e_t 的含噪信道，行为 a_h 是更昂贵的信号。

**定义 295（逆博弈后验）**
b_t(θ_h) ∝ b_{t-1}(θ_h) · p(a_h^{t} | θ_h, π_R^{t})^κ · p(face_t | e(θ_h))，其中 κ ≥ 1 为行为理性温度；p(a_h | θ_h, π_R) 由 IATM 的最优反应给出。情绪后验 π_t(E) = Σ_{θ_h} b_t(θ_h)·1[E = e(θ_h)]，从而情绪是意图的读出而非独立分类。

**定义 296（连续碰撞检测 GRCD）** 给定机器人认证前缀轨迹 τ_R[0,T] 与信念条件化的人类可达集 ℛ_h(t) = ∪_{θ_h} ℛ_h(t; θ_h)，定义最近距离 d_min = inf_{t∈[0,T]} dist(τ_R(t), ℛ_h(t))、首次接触时标 t* = inf{t: dist ≤ δ}。连续碰撞概率
P_col = P(∃t∈[0,T]: dist(τ_R(t), ℛ_h(t)) ≤ δ | b_t)。
**时间隧穿界**：若审计采样间隔 Δt ≤ d_min / v_max，则不存在「两帧之间穿过安全边界」的漏检；反之必存在隧穿反例。δ 为安全壳厚度。

**定义 297（碰撞风险泛函）** 后果 C(J_c, p_c, vuln_h) 由冲量、接触部位与人类脆弱性给出（对齐 ISO/TS 15066 思路）。风险泛函 R_col = CVaR_β[P_col · C]；硬约束 R_col ≤ R_budget。责任分配 blame ∈ {robot, human, shared} 由 RSS 规则（谁先破坏安全距离 / 谁拥有路权）给出。

**定义 298（接触事件锚 CEA）** 接触事件 e^c = (t_c, p_c, J_c, m)，其中 J_c 为冲量，m 为触发模态集合（力/触觉、音频、视觉形变、关节电流）。检测算子要求至少两个模态在 |Δt| ≤ 5ms 内共现，且冲量谱带宽 B_c > 10·ω_cal。**锚定残差** r_anchor = (p_c^pred(ĉ) − p_c^obs, t_c^pred − t_c^obs, J_c^pred − J_c^obs)。只有满足「已知基准几何 ∧ 责任可判」的接触才可作为标定锚；否则归入 H_fault 或外部障碍。

**定义 299（COF+ 事件触发混合滤波）** COF 连续慢滤波（R68 定义 286）之外，增加事件触发跳变：
ĉ ← ĉ + K_a·r_anchor，Σ ← (I − K_a H_a)Σ，其中跳变幅度受 ‖Δĉ‖ ≤ J_max 约束，且 J_max 由 canary 标定认证。跳变后协方差重置为 Σ_a ≪ Σ，表示「锚点把这一段标定钉死了」。无锚时仍走原速率限制器。

**定义 300（主动探针智能体 APA）** 探针动作 a_p ∈ 𝒜_safe（低速、低能量、已知基准面、可回退）。目标：
a_p* = argmax_{a_p} MI(θ; y | a_p, b_t) / (ε + CVaR_β(R_col(a_p)))，
s.t. R_col(a_p) ≤ R_probe ≪ R_budget，J_c ≤ J_safe。
只在 U(ĉ) > τ_probe 且 IGR ≥ ι_min 时发起；探针后用贝叶斯更新，若信息增益低于预期则记入 ℰ_probe 并降低该类探针的先验价值。

**定义 301（探针认证与章程 PCC）** 五关，先于执行：
1. 基准已知：探针接触几何与基准在 BOM / 计量链中有可溯源定义；
2. 能量界：碰撞能量 ≤ E_safe 且冲量 ≤ J_safe；
3. 撤离保证：存在认证的退避轨迹与最大反应时延界；
4. 人类安全：人类可达集与探针体积在时域上不相交，或已获知情同意；
5. 可逆性：探针不改变被探对象状态（无塑性变形 / 无不可逆位移）。
外加章程：每 24h 接触预算 B_probe、情绪高风险时禁止探针、同一基准的重复探针需间隔 ≥ T_reprobe。

**定义 302（跨通道欺骗检测 XCD）** 三环残差：
r_agent = (KL(π_face ‖ π_ctx), KL(π_behav ‖ π_face), KL(π_contact ‖ π_behav))。
其中 π_behav 由 IATM 行为似然给出，π_contact 由接触/近失事件校正。欺骗分 D_agent = max(r_agent) − median(r_agent)；D_agent > τ_decep ⇒ 视面部为不可观测（沿用 λ ≥ 0.8 纪律）并提高 IATM 的行为权重 κ。

**定义 303（责任敏感安全与 λ 调制）** blame 由 RSS 安全距离与路权规则给出。若 blame = human，则 λ_risk 可适度下调（不因对方主动撞来而惩罚自身任务），但**不得低于** R68 的 λ_floor；若 blame 不可判（U_agent 高），则 λ 上调。**反利用约束**：λ 的下调必须由责任证据的置信下界支撑，防止策略性人类「碰瓷」骗取机器人的永久退让。

**定义 304（风险与接触预算）** 累积约束 Σ_t R_col(t) ≤ B_risk、Σ_t J_c(t) ≤ B_probe（每 24h）。预算用尽即冻结探针与标定跳变，退回 R68 保守模式。

**定义 305（阈值重参数化扩展）** 继承 CAR：τ_temporal、τ_wm、τ_risk = f(U)；新增 τ_col = τ⁰_col·(1 − κ_c·U_agent)（意图越不确定，碰撞阈值越保守），探针阈值 τ_probe = τ⁰_probe·(1 + κ_p·U)（标定越不确定越值得探针）。λ_floor(U, U_agent) = max(0.6, 0.8·1[U > τ_cal ∨ U_agent > τ_agent])。

**定义 306（J_ACRA 证书）** J_ACRA = (J_CALM, intent_post_hash, agent_policy_hash, d_min, R_col, blame, anchor_hash, probe_verdict, acra_ver)。Valid ⇔ Valid(J_CALM) ∧ R_col ≤ R_budget ∧（未探针 ∨ probe_verdict = PASS）∧ 无锚慢漂移未被吸收。

**定义 307（AIC-ACRA 干扰集）** ℰ_ACRA = ℰ_CALM × ℰ_agent × ℰ_col × ℰ_probe。ℰ_agent = {策略适应、行为欺骗、责任碰瓷、目标误推}；ℰ_col = {时间隧穿、可达集低估、接触误归因}；ℰ_probe = {探针致害、信息自欺、探针被利用、探针过频}。

**定义 308（管线）** 离线：交互日志上拟合 IATM 与可达集预测器、认证 GRCD、标定 J_safe/R_probe。在线快环（2.6ms）：RAS-ACRA† + GRCD 保守避撞 + 安全滤波，禁止探针。在线慢环（≤1Hz）：IATM 更新 → XCD 欺骗检测 → CEA 锚定 COF+ → APA 规划探针 → PCC 认证 → 执行/拒绝。异步：VQAuditor-A 审计「这次接触是信息还是事故」。

**定义 309（继承与回退）** 关闭 IATM/APA/PCC 时 ACRA 退化为 CALM-RAS；关闭 CEA 时退化为 R68（无锚标定）。回退路径同构，回退失败即 k=0 全局降级。R68 的「缓变故障隐形」被改写为**覆盖条件**：若锚点间隔 T_anchor 有限，则缓变故障的最坏检出延迟 ≤ T_anchor + τ_det；若 T_anchor = ∞（无锚可用），系统必须冻结慢标定。

**定义 310（策略鲁棒后的安全算子）** 在人类策略模糊集 Π_h^ε 上取最坏情况：τ_col^rob = max_{π_h∈Π_h^ε} τ_col(b_t)，λ^rob = max_{π_h} λ_floor。ε 由 XCD 与长期交互校准；ε 越大越保守，给出「信任」与「安全」的显式旋钮。

```python
# IP-253 IATM：人类类型后验 + 逆博弈情绪
class InteractiveAgentTheoryModel:
    def update(self, a_h, face, robot_policy, b_prev):
        lik = {th: best_response_likelihood(a_h, th, robot_policy) ** KAPPA
                  * face_likelihood(face, th) for th in b_prev}
        b = normalize({th: b_prev[th] * lik[th] for th in b_prev})
        pi_emo = {E: sum(b[th] for th in b if e_of(th) == E) for E in EMOTIONS}
        return b, pi_emo


# IP-254 GRCD：可达集上的连续碰撞检测
def grcd(prefix_traj, belief, horizon=2.0, dt=0.01, delta=0.05):
    reach = reachable_set(belief, horizon)          # 多类型并集，保守膨胀
    dmin, t_star, p_col = inf, None, 0.0
    for t in np.arange(0, horizon, dt):
        d = signed_distance(prefix_traj(t), reach(t))
        if d <= delta and t_star is None:
            t_star = t
        dmin = min(dmin, d)
        p_col = max(p_col, occupancy_prob(prefix_traj(t), reach(t), belief))
    # 时间隧穿界：dt <= dmin / v_max 必须由调用方断言
    assert dt <= dmin / max_speed(belief) + 1e-9
    return {'d_min': dmin, 't_star': t_star,
            'R_col': cvar(P_col * consequence(p_col, belief), beta=BETA)}


# IP-255/256 CEA + COF+：接触事件触发标定跳变
class ContactAnchoredCOF(CalibrationObservationFilter):
    def anchor_step(self, event, c, S):
        if not is_valid_anchor(event):                   # 已知基准 ∧ 责任可判
            return c, S
        r = anchor_residual(event, c)                    # (p, t, J) 三残差
        K = S @ H_a.T @ inv(H_a @ S @ H_a.T + R_anchor)
        dc = clip(K @ r, -J_MAX, J_MAX)                  # 防恶意锚
        return c + dc, (I - K @ H_a) @ S + S_a_reset     # 锚定后协方差重置


# IP-257/258 APA + PCC：单位风险信息增益 + 认证
def plan_probe(belief, U, budget, rng):
    cands = safe_probes(belief, R_probe, J_safe)
    scored = []
    for a_p in cands:
        if not pcc_certify(a_p, belief):                 # 五关
            continue
        igr = mutual_info(belief, a_p) / (EPS + cvar_risk(a_p))
        if igr >= IOTA_MIN and U > TAU_PROBE:
            scored.append((igr, a_p))
    if not scored:
        return None
    return max(scored, key=lambda x: x[0])[1]


# IP-259 XCD：三通道欺骗检测
def deception_score(pi_face, pi_behav, pi_contact):
    r = [kl(pi_face, pi_behav), kl(pi_behav, pi_face),
         kl(pi_contact, pi_behav)]
    return max(r) - median(r)


# IP-263 主闭环：快环保守避撞，慢环锚定/欺骗/探针
def ACRA_round(M, obs):
    x = M.lsf.fuse(M.usr.fuse(*obs[:4]))
    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)

    # 快环：只做避撞与安全滤波（禁止探针、禁止标定跳变）
    b_h, pi_emo = M.iatm.update(obs.a_h, obs.face, M.live_policy, M.b_h)
    prefix = M.c_ras_wm.certified_prefix(
        M.ach.propose(x), M.joint_post, M.alpha_chunk, M.wm_preds)
    col = grcd(M.to_traj(prefix), b_h)
    if col['R_col'] > M.soft_ratio * M.R_budget:
        prefix = M.safety_filter.retract(prefix, col)    # 只收缩，不放宽

    # 慢环：锚定 → 欺骗 → 探针
    if M.slow_due():
        if M.cea.has_event():
            M.c, M.S = M.cof.anchor_step(M.cea.pop(), M.c, M.S)
        D = deception_score(o['pi'], pi_emo, M.cea.last_contact())
        if D > TAU_DECEP:
            M.force_face_unobservable()                  # λ ≥ 0.8，行为权重↑
        if M.cof.U > TAU_PROBE and M.pcc.budget_ok():
            a_p = plan_probe(b_h, M.cof.U, M.pcc.budget, M.rng)
            if a_p is not None:
                M.scheduler.enqueue(a_p)                 # 认证通过才入队

    lam = max(M.efs.risk_scale(M.joint_post),
              M.lam_floor(M.cof.U, M.agent_uncertainty(b_h)),
              M.rss.robust_lambda(b_h, M.epsilon))
    tau = M.pi_sigma.prefix_dispatch(prefix) * lam
    return prefix, tau, col, b_h
```

## 3. 推导

**引理 16（接触锚不可被慢标定吸收）** 设 COF 为带宽 ω_cal 的一阶跟踪器（R68 引理 13）。接触冲量的能量集中在 [10ω_cal, B_c]，且以事件触发跳变（定义 299）注入，跳变增益对慢滤波器不可见。于是：慢漂移分量（ω ≤ ω_cal）仍被 COF 平滑吸收；接触锚对应的快分量不被吸收，而是以有界跳变直接写入 ĉ；「真实缓变故障」若同时改变锚残差，则锚残差与 COF 平滑残差产生**非共模分歧**，该分歧是可检出的。系：锚点把 R68 的不可辨识对降为可辨识对，前提是锚点存在且有效。

**引理 17（单位风险信息增益的阈值最优性）** 在观测模型 L-Lipschitz、单次探针风险上界 R_probe 有界、人类类型空间 Θ 有限的假设下，期望信息增益 MI(θ; y | a_p) 关于 U(ĉ) 单调不减，而探针风险与 U 无关。因此存在阈值 U*，使「U > U* 时探针、否则不探针」在 IGR 意义下最优；并且 N 次有效探针后 E[U_N] ≤ U_0·e^{−cN} + U_floor（U_floor 由基准溯源误差决定）。

**引理 18（策略性接触的不可辨识下界）** 若人类策略集 Π_h 允许在 H_cal 与 H_fault 下产生相同的接触结果分布（例如人类主动规避接触以掩盖机器人的缓变故障，或主动制造接触以伪装校准锚），则对任意检验，
inf_{test} sup_{π_h∈Π_h} (TypeI + TypeII) ≥ 1 − ½·‖P_0 − P_1‖_TV，
且当两分布在 Π_h 上的 TV 距离可任意小时，下界趋于 1。**系：接触不是外生真值，而是双方策略的联合产物；没有「人类非策略/诚实」假设，锚点的可信度本身不可辨识。** 这是 ACRA 的原理性上限，也是本轮最大风险的形式化。

**定理 16（ACRA 端到端风险一致性）** 在 A87–A94 与 A95–A98（策略理性、锚点有效性、探针 L-Lipschitz、TV 有界）下：
1. P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + α_agent + α_col + α_probe；
2. 快环恒满足 CVaR_β(R_col) ≤ R_budget；探针只在 PCC 通过后执行，且 ΣJ_c ≤ B_probe；
3. U(ĉ) > τ_cal 或 U_agent > τ_agent ⇒ λ_risk ≥ 0.8 ∧ τ_col 收紧 ∧ 前缀收缩；
4. 无锚慢漂移不被吸收；有锚时缓变故障检出延迟 ≤ T_anchor + τ_det（定义 309）。
其中 α_agent 由引理 18 给出下界；若人类被验证为诚实（XCD 长期低分），该下界可放松。

**定理 17（探针认证安全性）** 若每次探针满足 PCC 五关与能量/冲量界，则单位时间期望伤害 ≤ ε_probe，且存在认证退避轨迹使探针失败时人类受伤概率 ≤ δ_esc；探针的有益性仅在 U > U* 时成立（引理 17），否则拒绝探针不损失任务性能。**系：ACRA 不会因为「想学习」而系统性增加风险预算。**

**定理 18（策略鲁棒性）** 在人类策略的模糊集 Π_h^ε = {π_h: KL(π_h‖π̂_h) ≤ ε} 内，以 worst-case b(θ_h) 计算的 τ_col 与 λ_floor 给出鲁棒安全界；当 ε → 0 退化为 IATM 点估计。鲁棒代价关于 ε 线性增长，给出「信任人类」与「保守」的可调旋钮。

## 6. 本轮最大风险

**一句话**：ACRA 把接触当作「外生物理真值」，但接触恰恰是**双方策略的联合产物**——一个策略性人类（或被操纵的环境）可以主动制造/规避接触来伪造校准锚点、诱导责任误判，或反向利用探针；更根本地，主动探针的「信息增益」估计本身依赖它想要校准的模型（自指），在漂移最严重时探针最不可信——系统可能在「我在用接触学习」的叙事中，把**交互性风险**系统性地误读为**可学习的信息**，越主动越自信，越自信越危险。

**次级风险与缓解**：
1. **探针致害**：PCC 五关 + 能量/冲量硬界 + 撤离保证 + 接触预算；
2. **策略性碰瓷**：责任证据置信下界 + 反利用约束（λ 下调需下界支撑）+ 长期共适应监控；
3. **信息自欺**：锚点有效性门控（已知基准 ∧ 责任可判）+ 无锚冻结 + 锚点 canary；
4. **可达集低估**：保守膨胀 + 多类型并集 + 最坏情况审计 + TV 鲁棒界；
5. **锚点被伪造**：多模态共现 + 冲量谱带宽 + 锚点哈希入 J_ACRA + 重复锚一致性检验；
6. **实时预算超支**：探针与 IATM 全部慢环，快环只留 GRCD 保守避撞。

**定义 299（COF+）** 在 R68 慢滤波上叠加事件触发跳变 `ĉ ← ĉ + clip(K_a·r_anchor, ±J_max)`，协方差重置为 Σ_a；无锚时仍走速率限制器。

## 3. 关键算法伪代码

```python
# IP-253 IATM：人类类型后验 + 逆博弈情绪
class InteractiveAgentTheoryModel:
    def update(self, a_h, face, robot_policy, b_prev):
        lik = {th: best_response_likelihood(a_h, th, robot_policy) ** KAPPA
                  * face_likelihood(face, th) for th in b_prev}
        b = normalize({th: b_prev[th] * lik[th] for th in b_prev})
        return b, {E: sum(b[th] for th in b if e_of(th) == E) for E in EMOTIONS}

# IP-254 GRCD：可达集连续碰撞检测
def grcd(prefix_traj, belief, horizon=2.0, dt=0.01, delta=0.05):
    reach = reachable_set(belief, horizon)            # 多类型并集，保守膨胀
    dmin, t_star, p_col = inf, None, 0.0
    for t in np.arange(0, horizon, dt):
        d = signed_distance(prefix_traj(t), reach(t))
        if d <= delta and t_star is None: t_star = t
        dmin = min(dmin, d)
        p_col = max(p_col, occupancy_prob(prefix_traj(t), reach(t), belief))
    assert dt <= dmin / max_speed(belief) + 1e-9      # 时间隧穿界
    return {'d_min': dmin, 't_star': t_star,
            'R_col': cvar(P_col * consequence(p_col, belief), beta=BETA)}

# IP-255/256 CEA + COF+：接触触发标定跳变
class ContactAnchoredCOF(CalibrationObservationFilter):
    def anchor_step(self, event, c, S):
        if not is_valid_anchor(event): return c, S   # 已知基准 ∧ 责任可判
        r = anchor_residual(event, c)
        K = S @ H_a.T @ inv(H_a @ S @ H_a.T + R_anchor)
        dc = clip(K @ r, -J_MAX, J_MAX)              # 防恶意锚
        return c + dc, (I - K @ H_a) @ S + S_a_reset

# IP-257/258 APA + PCC：单位风险信息增益 + 认证
def plan_probe(belief, U, budget):
    scored = []
    for a_p in safe_probes(belief, R_probe, J_safe):
        if not pcc_certify(a_p, belief): continue    # 五关
        igr = mutual_info(belief, a_p) / (EPS + cvar_risk(a_p))
        if igr >= IOTA_MIN and U > TAU_PROBE: scored.append((igr, a_p))
    return max(scored, key=lambda x: x[0])[1] if scored else None

# IP-259 XCD：三通道欺骗检测
def deception_score(pi_face, pi_behav, pi_contact):
    r = [kl(pi_face, pi_behav), kl(pi_behav, pi_face), kl(pi_contact, pi_behav)]
    return max(r) - median(r)

# IP-263 主闭环：快环保守避撞，慢环锚定/欺骗/探针
def ACRA_round(M, obs):
    x = M.lsf.fuse(M.usr.fuse(*obs[:4]))
    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)

    b_h, pi_emo = M.iatm.update(obs.a_h, obs.face, M.live_policy, M.b_h)
    prefix = M.c_ras_wm.certified_prefix(
        M.ach.propose(x), M.joint_post, M.alpha_chunk, M.wm_preds)
    col = grcd(M.to_traj(prefix), b_h)
    if col['R_col'] > M.soft_ratio * M.R_budget:
        prefix = M.safety_filter.retract(prefix, col)  # 只收缩，不放宽

    if M.slow_due():
        if M.cea.has_event():
            M.c, M.S = M.cof.anchor_step(M.cea.pop(), M.c, M.S)
        if deception_score(o['pi'], pi_emo, M.cea.last_contact()) > TAU_DECEP:
            M.force_face_unobservable()                # λ ≥ 0.8，行为权重↑
        if M.cof.U > TAU_PROBE and M.pcc.budget_ok():
            a_p = plan_probe(b_h, M.cof.U, M.pcc.budget)
            if a_p is not None: M.scheduler.enqueue(a_p)

    lam = max(M.efs.risk_scale(M.joint_post),
              M.lam_floor(M.cof.U, M.agent_uncertainty(b_h)),
              M.rss.robust_lambda(b_h, M.epsilon))
    return prefix, M.pi_sigma.prefix_dispatch(prefix) * lam, col, b_h
```

## 4. 推导

**引理 16（接触锚不可被慢标定吸收）** COF 为带宽 ω_cal 的一阶跟踪器；接触冲量能量集中于 [10ω_cal, B_c]，以事件跳变注入。慢漂移仍被平滑吸收；锚对应快分量以有界跳变写入 ĉ；缓变故障若改变锚残差，则锚残差与 COF 平滑残差产生**非共模分歧**→可检出。系：锚点把 R68 的不可辨识对降为可辨识对（前提：锚存在且有效）。

**引理 17（探针的阈值最优性）** 观测模型 L-Lipschitz、单次探针风险 R_probe 有界、Θ 有限时，MI(θ;y|a_p) 随 U 单调不减而风险与 U 无关 ⇒ 存在阈值 U*，使「U>U* 探、否则不探」在 IGR 意义下最优；N 次有效探针后 `E[U_N] ≤ U_0·e^{−cN}+U_floor`（U_floor 为基准溯源误差）。

**引理 18（策略性接触的不可辨识下界）** 若 Π_h 允许在 H_cal/H_fault 下产生相同接触分布（人类规避接触以掩盖故障，或制造接触以伪装锚），则任意检验 `inf sup (TypeI+TypeII) ≥ 1 − ½‖P_0−P_1‖_TV`，且 TV 可任意小时下界趋于 1。**系：接触是双方策略的联合产物，不是外生真值；无非策略/诚实假设，锚点可信度不可辨识。** 这是 ACRA 的原理上限。

**定理 16（端到端风险一致性）** A87–A98 下：1) `P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+α_agent+α_col+α_probe`；2) 快环恒满足 CVaR_β(R_col) ≤ R_budget，探针仅在 PCC 通过后执行且 ΣJ_c ≤ B_probe；3) U 或 U_agent 超阈 ⇒ λ ≥ 0.8 ∧ τ_col 收紧 ∧ 前缀收缩；4) 无锚慢漂移不被吸收，有锚时缓变故障检出延迟 ≤ T_anchor+τ_det。α_agent 由引理 18 给出下界。

**定理 17（探针认证安全性）** 每次探针满足 PCC 五关与能量/冲量界 ⇒ 单位时间期望伤害 ≤ ε_probe，认证退避使探针失败时受伤概率 ≤ δ_esc；探针仅在 U>U* 有益，否则拒绝不损任务性能。系：ACRA 不因「想学习」而系统性抬高风险预算。

**定理 18（策略鲁棒性）** 在 Π_h^ε={π_h: KL(π_h‖π̂_h)≤ε} 上取 worst-case 得 τ_col^rob、λ^rob；ε→0 退化为 IATM 点估计；鲁棒代价关于 ε 线性增长，给出「信任—保守」可调旋钮。

## 7. 本轮最大风险

**一句话**：ACRA 把接触当作「外生物理真值」，但接触恰恰是**双方策略的联合产物**——一个策略性人类（或被操纵的环境）可以主动制造/规避接触来伪造校准锚点、诱导责任误判，或反向利用探针；更根本地，主动探针的「信息增益」估计本身依赖它想要校准的模型（自指），在漂移最严重时探针最不可信——系统可能在「我在用接触学习」的叙事中，把**交互性风险**系统性地误读为**可学习的信息**，越主动越自信，越自信越危险。

**次级风险与缓解**：探针致害（PCC 五关 + 能量/冲量硬界 + 撤离保证 + 接触预算）；策略性碰瓷（责任证据置信下界 + 反利用约束 + 长期共适应监控）；信息自欺（锚点有效性门控 + 无锚冻结 + 锚点 canary）；可达集低估（保守膨胀 + 多类型并集 + TV 鲁棒界）；锚点被伪造（多模态共现 + 冲量谱带宽 + 锚点哈希入 J_ACRA + 重复锚一致性检验）；实时预算超支（探针与 IATM 全部慢环，快环只留 GRCD 保守避撞）。
