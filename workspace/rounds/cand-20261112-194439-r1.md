# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 1 轮；本轮灵感：「虚实迁移」×「实时控制」）

> 第 60 轮用 SSM×CIEC×EPIR×SERC 把「场景语义、认知意图、ROS 因果隔离」接进了执行闭环，但它的全部论证都建立在**真实平台**上，且把「实时」当作一个已被 ERTC 解决的调度问题。这留下**三个更深的裂缝**：
> 1. **虚实鸿沟被误当作纯动力学问题**：SSM 的 π_scene、EEIS 的 K_safe 只在真实侧闭环；仿真中「验证过」的参数被直接搬到真机，却默认了仿真时钟理想、无时延、无抖动。**参数迁移了，时间契约没迁移**——而阻抗控制对时延极其敏感，时延会直接吃掉相位裕度。
> 2. **实时控制被误当作「跑得快一点」**：ERTC 只约束了任务优先级与预算，缺少**控制器的 WCET-截止期可调度性证书**。一旦真实抖动超出预算，CLEP 可能整周期错过，出现「阻抗参数正确、施加时刻错误」的隐性失效；更糟的是，错过的那个周期往往正是接触切换的关键周期。
> 3. **迁移是单向、无证书的**：第 60 轮 EV-exec 只把真实证据回传，没有把**真实时序痕迹**反哺仿真，也回答不了「这个策略凭什么能迁移」——缺少可度量、可证伪、可撤销的**迁移证书**。

## 0. 直觉与动机

**灵感 1（虚实迁移 → 迁移的是「时序契约」，不是参数）**
直觉：把仿真策略搬到真机，最危险的不是质量、摩擦差 10%，而是真机的控制回路**慢了几毫秒且抖了几毫秒**。同样一组 (K_p, K_d)，在仿真里 1ms 周期下稳如磐石，在真机 25ms 时延下可能已经越过稳定边界。关键洞见：**可迁移性不是一个准确率数字，而是一个「包络包含」关系**——真实平台的时序参数必须落在策略的「实时保真包络」内；迁移的本质是**从仿真契约到真实契约的保守精化**。

**灵感 2（实时控制 → 在时限内选择「能证明稳定」的最低保真控制器）**
直觉：实时控制不是把最大最准的 MPC 硬塞进每一个周期，而是承认「不是每个周期都配得上全保真控制器」。设计一族按保真度嵌套的控制器 π₀（全 MPC）→π₁（LQR）→π₂（PD 阻抗）→π_safe（保持/停止），每个都有可测的 WCET 与可证的收缩率；每个控制周期**在截止期约束下选保真度最高且可证明稳定的那个**。关键洞见：**实时性是一种「降级权」**——好的实时系统不是永不降级，而是每次降级都可解释、可恢复、可证明不发散。

**灵感 3（虚实双向 → 真实是仿真的「时序测试用例」）**
直觉：第 60 轮的 EPIR 已经沉淀了带时间戳的真实执行轨迹，这些轨迹不该只用于事后审计。把它们**带抖动/丢包/时钟偏斜注入后回放进仿真**（TSP），就能在部署前把「真机可能出现的坏时序」在仿真里先跑一遍。关键洞见：**real→sim 的影子回放与 sim→real 的契约迁移构成同一个闭环的两条腿**；只做单向迁移，等于只用一半证据。

**灵感 4（时延-阻抗稳定域 DISR）**
直觉：EEIS 编译出的 K_safe 原本是「阻抗空间」里的一个集合，但时延会给它加一个**时间维度的切口**：给定 (K_p,K_d)，存在一个最大可容忍时延 L_max；超过它，闭环就失稳。于是「安全阻抗」必须升级为「(K_p,K_d,L) 三元组里的稳定域」。关键洞见：**把时延当作阻抗编译的一等约束，而不是部署后的意外**——这也让「增刚度」和「容忍时延」之间的取舍第一次可计算。

**灵感 5（迁移证书 J_xfer）**
直觉：第 59 轮有 J_exec 证明「这次执行合规」，但缺少一张在**部署前**就能签发的证书：它要同时回答「这个策略在目标平台上是否可调度」「其时序参数是否落在保真包络内」「所依据的孪生标定是否仍然有效」。把这三件事打包成可撤销的 J_xfer，迁移就从「相信工程师的经验」变成「相信可检验的证据」。关键洞见：**证书的价值在于它能被实时撤销**，而不是它被签发过一次。

**灵感 6（合流 → STAR 闭环）**
直觉：TDT 让仿真带上真实时钟；TSP 把真实轨迹灌回仿真；TRI 把「动力学残差」和「时序残差」分开辨识；DISR/RTFE 给出可迁移包络；DAST 签发 J_xfer；ATD 在包络外优雅降级；STCA 保证契约精化不丢证书；B_xfer 给整条迁移链算预算。闭环为：**标定→回放→辨识→包络→证书→任意时限执行→证据回传→再标定**，即 **STAR（Sim-to-real Temporal Assurance & Runtime）**。

## 1. 形式化定义（增量：定义 161–169）

**定义 161（时序数字孪生 TDT）** TDT = (S_sim, Θ_t, Φ_cal, V_twin)。其中：
- S_sim 为仿真状态（动力学状态 + 调度器/队列状态）；
- Θ_t = (τ_clock, L, J, W)：时钟偏置、单向时延、抖动、WCET 剖面；
- Φ_cal：真实遥测序列 {z_k^real} → 后验 p(Θ_t | z)，用带遗忘因子的递推估计 + PTP 时钟同步实现；
- 孪生有效性 V_twin = P(|L−L̂|≤δ_L ∧ |J−Ĵ|≤δ_J ∧ |W−Ŵ|≤δ_W) ≥ 1−α。
TDT 与第 60 轮 EPIR 共用时间戳：EPIR 的 (seq_id, timestamp) 就是 TDT 的标定样本，二者互为因果校验。

**定义 162（时延-阻抗稳定域 DISR 与实时保真包络 RTFE）** 对 m ẍ + b ẋ = u、u(t)=−K_p x(t−L)−K_d ẋ(t−L)，特征方程为
```
m s² + b s + (K_p + K_d s)·e^{−sL} = 0
```
- **DISR**：S(L) = {(K_p,K_d) | 所有根 Re(s_i)<0}，DISR(L)=S(L)∩{K_p≥0,K_d≥0}；
- **时延裕度**：L_margin(K_p,K_d) = sup{L≥0 : (K_p,K_d)∈S(L)}；
- **实时保真包络**：RTFE_π(ε) = {θ_t=(L,J,W,D) : Gap(π;θ_t) ≤ ε}，其中
  Gap(π;θ_t) = E[ℓ_task] + λ·P(safety violation)。
迁移有效当且仅当 θ_real ∈ RTFE_π(ε) 且 (K_p,K_d) ∈ DISR(L_real)。在 A67（Gap 对 L/J/W 单调）下，可用最坏剖面 θ_t^wc=(L̄+kσ_L, kσ_J, W_max) 保守判定，避免对分布尾部的乐观假设。

**定义 163（时序残差辨识 TRI）** 把真实—仿真残差分解为动力学项与时序项：
```
x_{k+1} = f_sim(x_k,u_k) + Δf(x_k,u_k) + B·δ_k + w_k
δ_k ≈ B⁻¹[ f_sim(x_k,u_k) − f_sim(x_k,u_{k−d_k}) ],  d_k = round(L_k/T_s)
```
辨识目标为 (Δf̂, δ̂)。**可分性判据**：δ̂ 与时钟/调度特征相关、跨关节共模、且随 d_k 变化；Δf̂ 与状态/动作相关、跨关节异质。残差界（A68）：‖e_k‖ ≤ ε_f + L_f‖δ_k‖，从而把「虚实差距」拆成可分别建模、分别预算的两部分。

**定义 164（时限感知迁移 DAST 与迁移证书 J_xfer）** DAST = (Ξ_extract, M_measure, Check, Certify)。策略契约与平台剖面：
```
C_π = (D_π, W_π, J_π, ε_π, ρ_π)
θ_real = (D_real, W_real, J_real, L_real)
SchedOK = (W_π + J_π + L_real ≤ D_real)
EnvOK   = (θ_real ∈ RTFE_π(ε_π)) ∧ ((K_p,K_d) ∈ DISR(L_real))
J_xfer  = (h(C_π), θ_real, SchedOK, EnvOK, epoch, σ_sig)
```
J_xfer 有效当且仅当 SchedOK ∧ EnvOK ∧ V_twin。任一条件失效 → 证书拒绝签发并转入 ATD；已签发的 J_xfer 在 TDT 失效或实测包络越界时**立即撤销**。

**定义 165（任意时限降级控制 ATD）** 控制器族 Π = {π₀,…,π_K, π_safe}，保真度 φ₀>…>φ_K>φ_safe，WCET W₀>…>W_K>W_safe。每周期在剩余截止期 D_rem 下选择
```
i* = argmax_i { φ_i : W_i + J_i + L ≤ D_rem }
```
若无 i 满足 → π_safe；若 π_safe 亦不满足 → 停止/交接。切换稳定性：若每个 π_i 有 Lyapunov 函数 V_i 满足 V_i(x_{k+1}) ≤ ρ_i V_i(x_k)，且跨切换 V_j ≤ μ V_i，则驻留时间
```
τ_dwell ≥ ln(μ) / ln(1/ρ_max),  ρ_max = max_i ρ_i < 1
```
即可保证切换系统渐近稳定。ATD 的关键不是「降级」，而是「降级也不发散」有证。

**定义 166（时序影子回放 TSP）** 给定 EPIR 真实轨迹 T={(x_k,u_k,τ_k,L_k,J_k)}，回放算子 R_φ(S_sim,T,φ) 在仿真中注入时序扰动 φ（时延、抖动、时钟偏斜、丢包），产生压力包络
```
RTFE_stress(ε) = RTFE(ε) ∩ { θ_t : gap_replay(θ_t) ≤ ε }
```
TSP 是 real→sim 方向：**真实轨迹是仿真的测试用例，而不是仿真的对照答案**。

**定义 167（虚实契约代数 STCA）** 契约 C=(D,W,J,L,ε,ρ)。覆盖关系（仿真契约比真实契约更「苛刻」）：
```
C_sim ≽ C_real  ⟺  D_sim ≤ D_real ∧ W_sim ≥ W_real ∧ J_sim ≥ J_real
                    ∧ L_sim ≥ L_real ∧ ε_sim ≤ ε_real ∧ ρ_sim ≤ ρ_real
```
串行组合 C₁;C₂ = (min(D₁,D₂)−overhead, W₁+W₂, J₁+J₂, L₁+L₂, ε₁+ε₂, max(ρ₁,ρ₂))；并行冗余 C₁∥C₂ = (max(D₁,D₂), min(W₁,W₂), min(J₁,J₂), min(L₁,L₂), min(ε₁,ε₂), min(ρ₁,ρ₂))。**精化定理**：若 C_sim ≽ C_real 且 π 在 C_sim 下持证，则 π 在 C_real 下同样持证。这把「迁移」变成了一个可组合的代数运算。

**定义 168（迁移预算 PCE+++++ / B_xfer）** B_xfer = (B_calib, B_replay, B_contract, B_fallback)，且
```
cost_xfer(π) = λ_cal·Calib_cost + λ_rep·Replay_cost + λ_con·Contract_cost + λ_fb·Fallback_cost
VOI_xfer(π)  = VOI_cog(π) − cost_xfer(π) − cost_cog(π) − cost_exec(π)
```
耗尽策略：B_calib 耗尽 ⇒ 用规格书最坏时序而非在线标定；B_replay 耗尽 ⇒ 用解析 RTFE 上界；B_contract 耗尽 ⇒ 固定 π_safe；B_fallback 耗尽 ⇒ 停止/交接。任一预算单调消耗，禁止「借明天的预算保今天的迁移」。

**定义 169（STAR 场景—时序迁移闭环）** 算子 STAR(M, π, T, δ_f_req)：
```
① TDT:  tdt.observe(telem); θ_wc ← tdt.worst_case_profile()
② TSP:  rtfe_stress ← temporal_shadow_replay(tdt, T, perturb_grid)
③ TRI:  (Δf̂, δ̂, ε_f) ← identify_residual(telem, sim_rollout)
④ RTFE: rtfe ← estimate_envelope(π, θ_wc, ε_f, rtfe_stress)
⑤ DISR: L_max ← lmax_discrete(π.Kp, π.Kd); env_ok ← θ_wc.L ≤ L_max
⑥ DAST: J_xfer ← certify(π, θ_real, rtfe, tdt); if not valid → ATD
⑦ ATD:  ctrl ← select_fidelity(Π, D_rem, θ_wc.J, θ_wc.L)
⑧ Exec: telemetry ← execute(ctrl, δ_f_req); EV-exec ← build_exec_evidence(...)
⑨ Feed: epir.append(EV-exec); tdt.observe_from_epir(EV-exec); rtfe ← update(rtfe, EV-exec)
⑩ Return (ctrl, J_xfer, rtfe, EV-exec, tdt.V_twin)
```

### IP-161 TDT（时序数字孪生标定）

```python
class TemporalDigitalTwin:
    def __init__(self, alpha=0.1, k_sigma=2.0):
        self.alpha, self.k_sigma = alpha, k_sigma
        self.theta = {'clock_offset': 0.0, 'L': 0.0, 'J': 0.0, 'W': 0.0, 'D': 0.01}
        self.valid = False

    def observe(self, send_ts, recv_ts, exec_time, period):
        L = max(0.0, recv_ts - send_ts)
        self.theta['L'] = (1-self.alpha)*self.theta['L'] + self.alpha*L
        self.theta['J'] = (1-self.alpha)*self.theta['J'] + self.alpha*abs(L-self.theta['L'])
        self.theta['W'] = max((1-self.alpha)*self.theta['W'], exec_time)   # WCET 高水位
        self.theta['D'] = period
        self.theta['clock_offset'] = recv_ts - send_ts - self.theta['L']

    def worst_case_profile(self):
        return {'L': self.theta['L'] + self.k_sigma*self.theta['J'],
                'J': self.k_sigma*self.theta['J'],
                'W': self.theta['W'], 'D': self.theta['D']}

    def validate(self, probe):
        err = {k: abs(probe[k]-self.theta[k]) for k in ('L','J','W')}
        self.valid = (err['L'] < 1e-3 and err['J'] < 5e-4 and err['W'] < 2e-4)
        return self.valid
```

### IP-162 DISR / RTFE（时延-阻抗稳定域与保真包络）

```python
def lmax_discrete(Kp, Kd, m=1.0, b=0.6, Ts=1e-3, dmax=60):
    Ad, Bd = zoh_plant(m, b, Ts)
    def stable(d):
        n = 2*(d+1); A = np.zeros((n, n))
        A[:2, :2] = Ad
        A[:2, 2*d:2*d+2] = -Bd @ np.array([[Kp, Kd]])
        for i in range(1, d+1):
            A[2*i:2*i+2, 2*(i-1):2*(i-1)+2] = np.eye(2)
        return max(abs(np.linalg.eigvals(A))) < 1.0
    if not stable(0):
        return 0.0
    lo, hi = 0, dmax
    if stable(hi):
        return dmax * Ts * 1000
    while hi - lo > 1:
        mid = (lo + hi) // 2
        lo, hi = (mid, hi) if stable(mid) else (lo, mid)
    return lo * Ts * 1000

def estimate_envelope(policy, theta_wc, eps, replay_env):
    Lmax = lmax_discrete(policy.Kp, policy.Kd)
    in_delay = theta_wc['L'] <= Lmax
    in_replay = replay_env.percentile(99) <= eps
    return {'L_max_ms': Lmax, 'in_env': in_delay and in_replay,
            'gap_ub': max(theta_wc['L']/Lmax, replay_env.percentile(99)/eps)}
```

### IP-163 TRI（时序/动力学残差分离）

```python
class TemporalResidualIdentifier:
    def __init__(self, n_state):
        self.theta_f = np.zeros(n_state)
        self.P = np.eye(n_state) * 1e3
        self.timing_gain = 1.0

    def identify(self, x, u, x_next, sim_next, d_k, Ts):
        delta = sim_delay_error(x, u, d_k, Ts)          # 时序折算的等效输入误差
        e = x_next - sim_next - delta
        phi = np.hstack([x, u])                          # 动力学残差回归量
        K = self.P @ phi / (1 + phi @ self.P @ phi)
        self.theta_f += K * (e - phi @ self.theta_f)
        self.P -= np.outer(K, phi @ self.P)
        return self.theta_f, delta, np.linalg.norm(e)
```

### IP-164 DAST（时限感知迁移 + 证书）

```python
def certify_transfer(policy, platform, tdt, rtfe, eps):
    Cp = policy.contract                       # (D, W, J_tol, eps, rho)
    theta = platform.measure()                 # (D, W, J, L)
    sched_ok = (Cp.W + Cp.J_tol + theta.L) <= theta.D
    env_ok = (theta.L <= rtfe['L_max_ms']) and rtfe['in_env'] and tdt.valid
    cert = {'hash': hash_contract(Cp), 'theta': theta,
            'sched_ok': sched_ok, 'env_ok': env_ok,
            'epoch': tdt.epoch, 'valid': sched_ok and env_ok and tdt.valid}
    return cert
```

### IP-165 ATD（任意时限降级控制）

```python
class AnytimeController:
    def __init__(self, family, rho, mu):
        self.family = sorted(family, key=lambda p: p.fidelity, reverse=True)
        self.rho, self.mu = rho, mu
        self.active, self.last_switch = None, -1e9

    def dwell(self):
        return np.log(self.mu) / np.log(1.0 / max(self.rho))

    def select(self, now, D_rem, J, L):
        for p in self.family:
            if p.W + J + L <= D_rem:
                if self.active in (None, p) or (now-self.last_switch) >= self.dwell():
                    self.active, self.last_switch = p, now
                    return p
        self.active = self.family[-1].safe       # π_safe：保持/停止
        return self.active
```

### IP-166 TSP（时序影子回放）

```python
def temporal_shadow_replay(tdt, traces, perturb_grid):
    env = []
    for phi in perturb_grid:                     # (ΔL, J, skew, drop_prob)
        gaps = [replay_gap(tdt.sim, tr, phi) for tr in traces]
        env.append((phi, np.percentile(gaps, 99)))
    return max(env, key=lambda e: e[1])          # 返回最坏时序剖面
```

### IP-168 PCE+++++（迁移预算）

```python
class TransferBudget:
    def __init__(self, calib=20, replay=50, contract=20, fallback=3):
        self.B = {'calib': calib, 'replay': replay, 'contract': contract, 'fallback': fallback}

    def spend(self, kind):
        self.B[kind] -= 1
        if self.B[kind] < 0:
            return {'calib': 'spec_worst_case', 'replay': 'analytic_rtfe',
                    'contract': 'fixed_safe', 'fallback': 'stop_handover'}[kind]
        return None

def voi_xfer(pi, b, voi_cog, cost_cog, cost_exec):
    cost_xfer = 0.05*b.B['calib'] + 0.02*b.B['replay'] + 0.1*b.B['contract'] + 0.3*b.B['fallback']
    return voi_cog(pi) - cost_xfer - cost_cog(pi) - cost_exec(pi)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TDT | O(1)/样本 | O(1) | V_twin ≥ 1−α；时钟偏置可辨识 |
| DISR | O(d³)/检查，可离线查表 | O(d²) | 与特征方程根判据等价 |
| RTFE | O(1)/查询 + 离线包络 | O(grid) | θ_real∈RTFE ⇒ Gap≤ε（A67） |
| TRI | O(n²)/步（RLS） | O(n²) | ‖e‖≤ε_f+L_f‖δ‖（A68） |
| DAST | O(K) | O(1) | J_xfer 有效 ⇔ SchedOK∧EnvOK∧V_twin |
| ATD | O(K)/周期，K≤4 | O(K) | 驻留时间满足 ⇒ 切换渐近稳定 |
| TSP | O(N_trace·T) | O(T) | 压力包络覆盖注入扰动族 |
| STCA | O(1) | O(1) | 契约覆盖保持证书 |
| PCE+++++ | O(1) | O(1) | 预算单调，耗尽即触发安全策略 |

**正确性定理（STAR）**：假设 A66–A72 成立：
- **(A66) TDT 标定**：|L̂−L|≤δ_L、|Ĵ−J|≤δ_J、|Ŵ−W|≤δ_W，V_twin≥1−α；
- **(A67) 包络单调**：Gap 对 L、J、W 单调不减，故最坏剖面判定是保守的；
- **(A68) 残差可分**：‖e‖≤ε_f+L_f‖δ‖，δ 与时钟/调度特征可辨识；
- **(A69) DISR 一致性**：离散谱半径判据与延迟微分方程稳定域在 T_s→0 时一致；
- **(A70) ATD 切换**：各 π_i 有公共 Lyapunov 结构并满足驻留时间条件；
- **(A71) STCA 精化**：C_sim≽C_real 时证书可传递；
- **(A72) 预算单调**：B_xfer 各分量单调消耗，耗尽即降级。

则：
1. **迁移可靠性**：若 J_xfer 有效，则 π 在真实平台上可调度且 Gap≤ε_π；若 C_sim≽C_real，则仿真证书可传递到真实契约。
2. **时限安全性**：ATD 选出的 π_i 满足 W_i+J_i+L≤D_rem，故单周期不超时；若全部不可调度，π_safe 在下一周期接管，切换不发散。
3. **虚实差距可控**：TRI 将总残差分解为 ε_f（动力学）与 L_f‖δ‖（时序），二者分别由系统辨识与 TDT 标定界定，避免把时序误差误归因于动力学。
4. **反哺收敛性**：TSP 的真实轨迹回放使 RTFE_stress 单调收紧（在扰动族不变时），即迁移包络随证据增加而更可信。

### IP-161 TDT（时序数字孪生）

```python
class TemporalDigitalTwin:
    def __init__(self, alpha=0.1, k_sigma=2.0):
        self.alpha, self.k_sigma = alpha, k_sigma
        self.theta = {'clock_offset': 0.0, 'L': 0.0, 'J': 0.0, 'W': 0.0, 'D': 0.01}
        self.valid = False

    def observe(self, send_ts, recv_ts, exec_time, period):
        L = max(0.0, recv_ts - send_ts)
        self.theta['L'] = (1-self.alpha)*self.theta['L'] + self.alpha*L
        self.theta['J'] = (1-self.alpha)*self.theta['J'] + self.alpha*abs(L-self.theta['L'])
        self.theta['W'] = max((1-self.alpha)*self.theta['W'], exec_time)
        self.theta['D'] = period
        self.theta['clock_offset'] = recv_ts - send_ts - self.theta['L']

    def worst_case_profile(self):
        return {'L': self.theta['L'] + self.k_sigma*self.theta['J'],
                'J': self.k_sigma*self.theta['J'],
                'W': self.theta['W'], 'D': self.theta['D']}
```

### IP-162 DISR / RTFE（时延-阻抗稳定域与保真包络）

```python
def lmax_discrete(Kp, Kd, m=1.0, b=0.6, Ts=1e-3, dmax=60):
    Ad, Bd = zoh_plant(m, b, Ts)
    def stable(d):
        n = 2*(d+1); A = np.zeros((n, n))
        A[:2, :2] = Ad
        A[:2, 2*d:2*d+2] = -Bd @ np.array([[Kp, Kd]])
        for i in range(1, d+1):
            A[2*i:2*i+2, 2*(i-1):2*(i-1)+2] = np.eye(2)
        return max(abs(np.linalg.eigvals(A))) < 1.0
    if not stable(0): return 0.0
    lo, hi = 0, dmax
    if stable(hi): return dmax * Ts * 1000
    while hi - lo > 1:
        mid = (lo + hi) // 2
        lo, hi = (mid, hi) if stable(mid) else (lo, mid)
    return lo * Ts * 1000

def estimate_envelope(policy, theta_wc, eps, replay_env):
    Lmax = lmax_discrete(policy.Kp, policy.Kd)
    return {'L_max_ms': Lmax,
            'in_env': theta_wc['L'] <= Lmax and replay_env.p99 <= eps,
            'gap_ub': max(theta_wc['L']/Lmax, replay_env.p99/eps)}
```

### IP-165 ATD（任意时限降级控制）

```python
class AnytimeController:
    def __init__(self, family, rho, mu):
        self.family = sorted(family, key=lambda p: p.fidelity, reverse=True)
        self.rho, self.mu, self.active, self.last_switch = rho, mu, None, -1e9

    def dwell(self):
        return np.log(self.mu) / np.log(1.0 / max(self.rho))

    def select(self, now, D_rem, J, L):
        for p in self.family:
            if p.W + J + L <= D_rem:
                if self.active in (None, p) or (now-self.last_switch) >= self.dwell():
                    self.active, self.last_switch = p, now
                    return p
        self.active = self.family[-1].safe
        return self.active
```
