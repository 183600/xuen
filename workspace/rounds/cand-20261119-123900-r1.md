# 第 14 轮（新灵感循环第 1 轮；本轮灵感：「嵌入式系统」×「阻抗控制」）

> **基线**：产物区最新落地的 MetricVoiceGauge-NCD-HUTDH v15（技能扩散版；IP-378–401；定义 607–626；引理 125–130；实验 E661–E670）。
> 本轮纪律：**把证书从"语义 / 时限"推进到"物理实现"**。v12 认证"哪些动作在语义上允许"，v13 认证"在毫秒内能安全算到哪一档"，v15 认证"多技能如何组合"。本轮补上最后一层：**阻抗控制器在真实嵌入式硬件上是否仍然被动、仍然接触稳定**。三个新组件——QEC（量化—能量证书）、JDPM（抖动—延迟被动裕度）、WLIL（字长—精度阻抗阶梯，含 IRR 路由器与 GSPP 增益调度）——一律以中立元接入，失效即退回 v15，再沿 v15→v14→v13→v12 退化链退回。核心口号：**不是"控制器设计得稳定"，而是"这段控制代码在这块 MCU 上用这些位、这个节拍跑起来可证稳定"**。

## 0. 直觉与动机

**灵感 1（嵌入式系统 → 有限字长不是噪声，而是"凭空造能量"的漏洞）**
直觉：在纸面上，阻抗控制 `τ = M q̈ + D q̇ + K(q−q_d)` 只要 `D≻0、K≻0` 就被动。可一旦塞进 16 位定点 MCU，位置、速度、力矩每一步都被 round-to-nearest 截断：阻尼项计算的微小偏差可能在某个相位上恒为正功，于是系统像被一只看不见的手持续注入能量，出现纸面绝不允许的极限环或低频爬行。关键反直觉点：**量化误差不是零均值白噪声，在闭环与时变增益下它可以系统性偏置成能量源**。因此不能把量化当"精度损失"，必须把它当"能量账本上一笔必须显式记账的支出"。核心创新：**量化—能量证书（Quantized-Energy Certificate, QEC）**，对每个控制步给出量化注入能量的可证上界 `η_q`，并把它从能量罐（energy tank）中预先扣除；只有当"耗散下界 − 量化注入下界 ≥ 0"时，该组阻抗增益才被允许上线。

**灵感 2（阻抗控制 → 变阻抗调度的能量不是免费的）**
直觉：接触任务需要变阻抗——自由空间里硬一些、接触瞬间软一些。工程上常把 `K、D` 直接线性插值或按刚度调度。但能量函数 `V=½ξᵀK(t)ξ`（`ξ=q−q_d`）本身随 `K(t)` 变化，`V̇` 里多出一项 `½ξᵀK̇ξ`；当刚度**上升**时这一项为正，等于边调参边往系统里灌能量。更隐蔽的是，采样抖动 / 通信延迟会把上一拍的阻尼力多保持 `δ` 毫秒，同样注入约 `½‖D‖v²δ` 的能量。核心创新：**抖动—延迟被动裕度（Jitter–Delay Passivity Margin, JDPM）+ 增益调度被动多面体（Gain-Scheduled Passivity Polytope, GSPP）**：把调度速率 `|K̇|` 与抖动 `δ_max` 都折算成能量注入项，与 QEC 合并进同一个被动裕度 `μ`；GSPP 要求调度轨迹始终停留在"已认证端口哈密顿矩阵的凸包"内，并显式限制调度速率，使插值本身不产生净能量。

**灵感 3（嵌入式 × 阻抗控制 → 字长 / 迭代次数就是新的"时限阶梯"）**
直觉：v13 已经证明"时间越紧，授权越保守"；在嵌入式阻抗控制里，与时间并列的还有**算力精度**：可以跑 16 位定点快路径、32 位定点慢路径、或用软件浮点仿真。精度越高，能量账越准、可允许的刚度越高，但 WCET 越大。于是把 v13 的"以毫秒为索引的证书族"升级为**以字长 / 精度为索引的阻抗阶梯**：低精度档配更软、阻尼更大、能量罐更大的保守阻抗；高精度档才允许更硬、更灵敏的接触。核心创新：**字长—精度阻抗阶梯（Word-Length Impedance Ladder, WLIL）+ 阻抗资源路由器（Impedance Resource Router, IRR）**。运行时不"猜"当前场景是否安全，而是看"本帧还剩多少时间、多少电量、抖动多大、能量罐多满"，选负担得起且 `μ≥0` 的最高一档；任何一项变坏就沿阶梯**单调向软**塌缩，绝不跨档使用未认证增益。

**三者如何统一**
统一为 **v15 语义 / 时限层之下的物理实现层**：v15 回答"允许哪些动作、能算到哪一档"，v16 回答"这些动作里，哪一组阻抗增益可以在当前字长、抖动、能量预算下**真正被动地**执行"。QEC 管"量化花掉多少能量"，JDPM 管"抖动 / 延迟花掉多少能量"，WLIL 管"用哪一档精度 / 增益去付这笔账"，IRR 管"本帧选哪一档"，GSPP 管"变阻抗过程中不偷加能量"。共享状态 `ζ_hw = (w, Δ, T_s, δ_max, d_min, η_q, η_j, μ, E_t, λ, mode)`。**QEC 回答"有限字长偷走多少安全"，JDPM 回答"抖动偷走多少安全"，WLIL / IRR 回答"用哪档去补这个洞"，GSPP 回答"边调边跑时洞会不会变大"**。

## 1. 研究问题

- **Q1（量化—被动性）**：如何给出与具体 Q-format、舍入模式、饱和策略相关的单步能量注入上界？该上界在闭环、时变增益、接触切换下是否仍成立？当上界过松导致 `μ<0` 时，如何沿一条可证的"降刚度 / 增阻尼"曲线最快恢复可行？
- **Q2（抖动—延迟）**：采样抖动、总线延迟、ZOH 保持误差对阻尼项的能量注入如何定量？`δ_max` 与被动裕度、接触刚度之间的可证边界是什么？变周期调度是否会破坏 v13 的 RTIC？
- **Q3（字长阶梯与调度）**：如何离线构造一族按精度排序、授权单调嵌套、且每档 `μ≥0` 的阻抗增益？运行时如何在未知抖动 / 剩余电量下选档，使"接触稳定—任务进度—能耗"三目标最优，并保证只向更保守档塌缩？
- **Q4（与基线的兼容与活性）**：QEC / JDPM 的界限是否会与 v15 的 DCA / TGC 误差相加而共同低估风险？能量罐耗尽时频繁退回第 0 档（纯阻尼 / 柔顺停）是否会让任务活性塌缩？新增证书能否在任何情况下严格退回 v15，并守住硬实时？

## 2. 设计原则（P25–P27）

**P25 硬件在环可证律（Certify on the Actual Arithmetic）**
不存在"无限精度的证书"。任何安全判决必须使用实际运行的 Q-format、舍入模式、饱和策略与实测抖动 / 延迟；禁止把浮点离线证书直接搬到定点目标机上。证书必须给出**该实现下**的能量注入上界，而非理想模型下的稳定裕度。

**P26 精度只降不强律（Precision Downshifts Only Weaken Authority）**
降低字长、减少迭代、放宽容差只能**缩小**允许的阻抗权限：`K` 不增、`D` 不减、能量罐不减。任何"用低精度换更激进增益"的做法一律禁止。阶梯必须满足 `Acc_hw(w_0) ⊆ Acc_hw(w_1) ⊆ … ⊆ Acc_hw(w_m) ⊆ Acc_v15`。

**P27 能量账本单调精确律（Exact Monotone Energy Ledger）**
能量罐的收支必须在一个**向外取整的整数 / 区间域**中计算：每一步都必须满足 `E_t^{k+1} ≤ E_t^k + 已知耗散 − 已知注入的上界`；账本精度必须显著细于最小能量量子。若账本本身可能因舍入而"看不见"注入，则禁止使用高于第 0 档的阻抗；检测到账本不确定性即安全塌缩并触发重校准。

## 3. 与基线的接口（如何退化）

- QEC 失效 ⇒ 用离线区间分析给出一个固定、加倍保守的静态能量余量；增益取该余量下的单组硬编码值，**等价 v15 的静态保守阻抗路径**；
- JDPM 失效 ⇒ 令 `δ_max` 取硬件手册最坏值并整体降一档，禁用变周期，**等价"固定周期 + 保守 ZOH"路径**；
- WLIL 失效 ⇒ 单精度档 + 固定增益 + 固定能量罐，**等价"v15 证书 + 单个保守嵌入式阻抗"**；
- IRR 失效 ⇒ 由 v15 静态调度器按固定顺序执行，精度档固定为最保守档，**等价 v15 调度路径**；
- GSPP 失效 ⇒ 禁止在线变阻抗，`K、D` 固定为某一认证点，**等价定阻抗控制**；
- 全失效 ⇒ MetricVoiceGauge-NCD-HUTDH v15，再沿 v15→v14→v13→v12 退化链退回；
- **安全继承**：QEC / JDPM 只做"扣减能量、收紧裕度"，WLIL / GSPP 只做"降低权限、限制调度速率"，IRR 只做"选更保守档"，没有任何端口能新增权限或放宽阈值，`Exec_v16 ⊆ Exec_v15`。

## 4. 预期贡献

1. **量化—能量证书**：把有限字长从"精度指标"改写为"可证能量注入上界"，给出 Q-format / 舍入 / 饱和感知的被动性条件；
2. **抖动—延迟被动裕度与增益调度多面体**：把采样抖动和刚度调度速率纳入同一个被动裕度，给出变阻抗不偷加能量的可证条件；
3. **字长—精度阻抗阶梯**：把 v13 的时间阶梯推广到"算力精度 × 时限 × 能量"三维资源，实现只向软 / 保守方向的单调塌缩；

## 5. 本轮最大风险

**一句话**：能量账本可能由与被认证控制器同一套定点算术计算；一旦账本自身的舍入系统性偏置，它会"看不见"自己造成的量化注入，于是系统报告能量罐充盈、每一档都 `μ≥0`，实机却在持续积累能量并最终失稳——即**用有缺陷的秤去证明自己没超重**。

**定义 627（单步量化注入上界）** 设理想力矩 `τ*`、实现力矩 `τ_w=Q_w(τ*)`，工作域内 `|q̇|≤v_max`、`|ξ|≤ξ_max`。定义

```
η_q(w,x) = T_k · ( v_max·e_τ(w) + ξ_max·e_K(w) + v_max·e_D(w) )
e_τ(w) = C_ops·Δ_τ(w)/2 ,  e_K(w)=L_K Δ_q(w)/2 ,  e_D(w)=L_D Δ_v(w)/2 ,
```

其中 `C_ops` 为力矩计算链的算子数，`L_K、L_D` 为对位置 / 速度的 Lipschitz 常数。`η_q` 是**上界**而非估计：它把每个舍入误差都按最不利符号累加。

**定义 628（单步抖动注入上界）** 对 ZOH 多保持 `δ_k` 的阻尼 / 刚度力，定义

```
η_j(δ_max,x) = ( ‖D‖ v_max² + ‖K‖ ξ_max v_max ) · δ_max .
```

**定义 629（被动裕度）** 在 `x∈X` 上定义

```
μ(x) = d_min‖q̇‖²T_s − η_q(w,x) − η_j(δ_max,x) − ½ρ_K‖ξ‖²T_s .
```

第 `r` 档在 `x` 处可执行当且仅当 `μ(x) ≥ 0` 且 `E_t ≥ E_res`；档位可执行当且仅当 `min_{x∈X} μ(x) ≥ 0`。

**定义 630（精确单调能量账本）** 以能量量子 `ε>0` 计，第 k+1 步更新强制为

```
E_t^{k+1} = E_t^k + ⌊ D_k T_s / ε ⌋ − ⌈ (η_q+η_j+η_sched)/ε ⌉ − ⌊ ρ_K‖ξ_k‖²T_s/(2ε) ⌋ ,
```

所有收入取下整、所有支出取上整；`ε` 由整数域精确表示。

**定义 631（字长—精度阶梯）** `L = (L_0,…,L_m)`，其中 `r<s ⇒ w_r≤w_s`、`K_r⪯K_s`、`D_r⪰D_s`、`E_t^{init}_r≤E_t^{init}_s`、`δ_r≤δ_s`，且每档在 `X_r` 上 `μ_r≥0`。

**定义 632（被动多面体）** 已认证端口哈密顿点 `{(J_i,R_i,H_i)}`，调度输出限制在

```
(J(α),R(α),H) = ( Σ_i α_i J_i , Σ_i α_i R_i , H ) ,  α∈Δ^{m-1},  R_i⪰0 .
```

**定义 633（安全塌缩算子）** `Collapse(ζ_hw, r) = L_0`，即丢弃当前档、回到最保守档并清空非保留能量罐；禁止 `r → r' > r` 的"跳升"。

## 1. 关键算法骨架

```python
# IP-402 QEC：量化能量证书
class QuantizedEnergyCertificate:
    def __init__(self, qfmt, X, lipschitz, ops_count):
        self.qfmt = qfmt                 # {Δ_q, Δ_v, Δ_tau, rounding, sat}
        self.X = X                       # 工作域：v_max, xi_max
        self.L_K, self.L_D = lipschitz
        self.C_ops = ops_count

    def eta_q(self, w):
        d = self.qfmt[w]
        e_tau = self.C_ops * d["d_tau"] / 2
        e_K   = self.L_K * d["d_q"] / 2
        e_D   = self.L_D * d["d_v"] / 2
        Tk    = self.qfmt[w]["T_s"] + self.qfmt[w]["delta_max"]
        return Tk * (self.X.v_max*e_tau + self.X.xi_max*e_K + self.X.v_max*e_D)


# IP-403 JDPM：抖动—延迟被动裕度
class JitterDelayMargin:
    def __init__(self, D_norm, K_norm, X):
        self.Dn, self.Kn, self.X = D_norm, K_norm, X

    def eta_j(self, delta_max):
        return (self.Dn*self.X.v_max**2 + self.Kn*self.X.xi_max*self.X.v_max) * delta_max

    def margin(self, x, w, delta_max, rho_K, qec, damper):
        eta_q = qec.eta_q(w)
        eta_j = self.eta_j(delta_max)
        eta_s = 0.5*rho_K*(x.xi**2)*qec.Ts(w)
        return damper.d_min*(x.dq**2)*qec.Ts(w) - eta_q - eta_j - eta_s


# IP-404 EMEL：向外取整能量账本
class ExactMonotoneLedger:
    def __init__(self, eps, E_init, E_res):
        self.eps = eps                   # 能量量子（整数表示）
        self.E   = E_init // eps         # 整数计数
        self.E_res = -(-E_res // eps)    # 向上取整

    def step(self, dissipation, injection):
        credit = dissipation // self.eps          # 收入下取整
        debit  = -((-injection) // self.eps)      # 支出上取整
        self.E = self.E + credit - debit
        return self.E >= self.E_res

    def collapse(self):
        self.E = self.E_res


# IP-405 WLIL：字长—精度阻抗阶梯
class WordLengthImpedanceLadder:
    def __init__(self, rungs):           # rungs[r] = (w, G, E_init, delta_r, X_r)
        self.rungs = rungs
        for r in range(1, len(rungs)):
            assert self._nested(rungs[r-1], rungs[r])

    def _nested(self, lo, hi):           # 低精度只能是高精度授权子集
        return (lo.K <= hi.K and lo.D >= hi.D
                and lo.E_init <= hi.E_init and lo.delta_r <= hi.delta_r)

    def certified(self, r, margin_fn):
        w, G, E_init, delta_r, X_r = self.rungs[r]
        return min(margin_fn(x, w, delta_r) for x in X_r) >= 0


# IP-406 IRR：阻抗资源路由器
class ImpedanceResourceRouter:
    def __init__(self, ladder, wcet, min_dwell=2):
        self.ladder, self.wcet = ladder, wcet
        self.dwell = 0
        self.current = 0

    def choose(self, T_rem, E_t, delta_hat, margin_fn):
        best = 0
        for r in range(len(self.ladder.rungs)-1, -1, -1):
            if (self.wcet[r] <= T_rem and E_t >= self.ladder.rungs[r].E_init
                    and delta_hat <= self.ladder.rungs[r].delta_r
                    and self.ladder.certified(r, margin_fn)):
                best = r
                break
        if best > self.current and self.dwell < self.min_dwell:
            return self.current, False       # 迟滞，防止抖动导致档位跳变
        self.dwell = self.dwell + 1 if best == self.current else 0
        self.current = best
        return best, (best < self.current)

    def collapse(self):
        self.current, self.dwell = 0, 0
        return 0


# IP-407 GSPP：增益调度被动多面体
class GainScheduledPassivityPolytope:
    def __init__(self, certified_points, rho_K_max, X):
        self.points = certified_points     # (J_i, R_i, H_i)，均 R_i ⪰ 0
        self.rho_K_max = rho_K_max
        self.X = X

    def schedule(self, alpha, alpha_dot):
        assert all(a >= 0 for a in alpha) and abs(sum(alpha)-1) < 1e-9
        Kdot = sum(ad*P.K for ad, P in zip(alpha_dot, self.points))
        if abs(Kdot) > self.rho_K_max:
            return None                    # 拒绝过快调度 → 请求降档
        J = sum(a*P.J for a, P in zip(alpha, self.points))
        R = sum(a*P.R for a, P in zip(alpha, self.points))
        assert self._psd(R)
        return J, R

    def _psd(self, M, tol=1e-9):
        return min(eigvalsh((M+M.T)/2)) >= -tol


# IP-408 EIG：嵌入式阻抗守卫 + v16 主集成
def metricvoicegauge_round_16_embedded_impedance(M, s, obs, hw, ladder, ctx):
    # ---- v15 主路径原样保留 ----
    v15 = M.inherited_v15_path(ctx)

    qec = QuantizedEnergyCertificate(hw.qfmt, hw.X, hw.lipschitz, hw.ops)
    jdm = JitterDelayMargin(hw.D_norm, hw.K_norm, hw.X)
    ledger = ExactMonotoneLedger(hw.eps, hw.E_init, hw.E_res)
    irr = ImpedanceResourceRouter(ladder, hw.wcet)
    gspp = GainScheduledPassivityPolytope(hw.certified_points, hw.rho_K_max, hw.X)

    def margin_fn(x, w, delta_r):
        return jdm.margin(x, w, delta_r, hw.rho_K_max, qec, hw.damper)

    # ---- 选档：只看负担得起且 μ≥0 的最高档 ----
    r, collapsing = irr.choose(
        T_rem=ctx.T_rem, E_t=ledger.E*hw.eps,
        delta_hat=hw.delta_hat, margin_fn=margin_fn)
    if not ladder.certified(r, margin_fn):
        r = irr.collapse()

    if r == 0:
        execute_compliant_stop_or_ask(hw.safe_fallback)
        return v15

    # ---- 变阻抗调度受多面体与速率约束 ----
    alpha, alpha_dot = hw.schedule_for(obs)
    JR = gspp.schedule(alpha, alpha_dot)
    if JR is None:
        r = irr.collapse()                # 调度过快：降档，不赌
        execute_compliant_stop_or_ask(hw.safe_fallback)
        return v15

    # ---- 执行一拍，随后精确记账 ----
    J, R = JR
    tau = apply_impedance(obs, J, R, hw.rungs[r])
    dissipation = float(obs.dq @ hw.damper.D @ obs.dq) * hw.Ts
    injection = qec.eta_q(hw.rungs[r].w) + jdm.eta_j(hw.rungs[r].delta_r) \
                + 0.5*hw.rho_K_max*(obs.xi**2)*hw.Ts
    if not ledger.step(dissipation, injection):
        r = irr.collapse()                # 罐透支：安全塌缩 + 重校准
        execute_compliant_stop_or_ask(hw.safe_fallback)
        hw.request_recalibration()

    execute(tau)
    return v15
```

## 2. 推导

**引理 131（量化能量注入界）** 设力矩计算链的每一步绝对舍入误差不超过 `Δ/2`，算子数为 `C_ops`，且 `τ*` 对 `(q, q̇)` 的 Lipschitz 常数为 `L_K、L_D`。则单步由量化引入的机械能不超过 `η_q(w,x)`（定义 627）。证明：能量增量等于力误差在位移上的功。按三角不等式，力矩误差 `|τ_w−τ*| ≤ C_ops Δ_τ/2 + L_K Δ_q/2 + L_D Δ_v/2`；乘以该步最大位移 `v_max T_k`（刚度项乘 `ξ_max T_k`），再对各项取最不利符号求和即得。高阶 `O(Δ²)` 项被保守并入常数。∎ 推论：**量化不是"高精度模型的近似"，而是一笔随 `Δ` 线性增长的固定能量税**；`T_s` 越长，每步税额越大。

**引理 132（抖动注入界与可用刚度边界）** 在 ZOH 下多保持 `δ_max`，单步抖动注入不超过 `η_j(δ_max,x)= (‖D‖v_max²+‖K‖ξ_max v_max)δ_max`。于是给定 `δ_max`，仍保持 `μ≥0` 的最大刚度满足

```
‖K‖ ≤ [ d_min‖q̇‖²T_s − η_q − ‖D‖v_max²δ_max − ½ρ_K‖ξ‖²T_s ] / ( ξ_max v_max δ_max ) 。
```

证明：多保持 `δ_max` 等价于在名义控制上叠加一段长度 `δ_max`、幅值为阻尼 / 刚度力的常值输入；其做功上界由力范数乘速度乘时间给出。解 `μ≥0` 对 `‖K‖` 线性即得边界。∎ 推论：**抖动越大，控制器必须越软**；这不是调参偏好，而是被动性的硬约束。

**引理 133（嵌入式被动保持定理）** 若某档满足 `min_{x∈X}μ(x)≥0`，能量账本按定义 630 向外取整且 `E_t^0≥E_res`，则对任意满足 `δ_k≤δ_max` 的采样序列，闭环对放大能量罐 `E_t` 被动；在被动环境下接触力有界。证明：逐步能量平衡 `H_{k+1}≤H_k−D_kT_s+η_q+η_j+η_sched+W_supply`。由 `μ≥0` 得 `D_kT_s≥η_q+η_j+η_sched`，故无外部供能时 `H` 单调不增；有外部供能时，超出部分被账本按上界扣减，`E_t` 保持非负即对应罐内可用能量未被透支。对被动环境应用无源性级联定理得接触力有界。∎ 推论：**安全性只依赖"每档 μ 与账本是否 sound"，不依赖控制器在标称点的性能**。

**引理 134（账本自证可靠性）** 若账本与被认证控制器使用同一套 `w` 位、同一套**非向外**舍入，则存在增益与轨迹使真实注入大于账本记录，证书不可靠；若账本在独立区间域中向外取整且 `ε ≤ ε_sys/2^p`，则账本记录是真实可用能量的上界，相对乐观误差不超过 `2^{-p}`。证明：前者构造舍入偏差恒指向"少记支出"的轨迹；后者由区间算术的包含单调性与向外取整的包含性直接得到，`p` 位额外精度给出相对误差界。∎ 推论：**能量账本必须用比控制器更细、且方向保守的算术**；否则会出现"账本充盈、实机发散"的假阴性。

**引理 135（字长阶梯单调性）** 若 `L` 满足定义 631 的嵌套关系，则对任意精度下行序列 `r_k`（只减不增），执行的全部阻抗增益落在 `Acc_hw(w_0) ⊆ … ⊆ Acc_v15` 内；`IRR` 的任何塌缩不会产生越权。证明：由定义 631，`r<s ⇒ K_r⪯K_s、D_r⪰D_s`，故低档授权是高档子集；`IRR` 只在可行档中取最高且失败时递减，故执行点的权限参数 `λ` 单调不增。∎ 推论：**精度与时间一样是"只降不强"的货币**；低精度档永远付出性能而非安全。

**引理 136（变阻抗调度的净能量）** 若 `(J_i,R_i)` 均被动且调度限制在凸包内，调度速率满足 `ρ_K≤ρ_K^max`，则每个调度区间上的净注入不超过 `½ρ_K^max‖ξ‖²T_s`；若该值已计入 `η_sched`，则变阻抗不破坏引理 133。证明：`V=½ξᵀKξ` 的导数含 `½ξᵀK̇ξ`，其上界为 `½‖K̇‖‖ξ‖²`；凸组合保持 `R⪰0`、`K⪰0`，故除该显式项外无额外能量源。∎ 推论：**"变阻抗"不是免费的自适应，而是一条有速度上限的能量预算线**。

**引理 137（精度—刚度—周期的三难下界）** 存在硬件 / 模型族，使任何满足 `μ≥0` 的认证策略都有

```
λ_max ≤ λ_0 − c_1·Δ(w)/(T_s v_max) − c_2·δ_max/T_s ,
且  WCET(w) ≤ T_s  ⇒  w ≤ w_max(T_s) ,
```

其中 `c_1,c_2>0` 由工作域与 Lipschitz 常数决定。证明：由引理 131–132 把 `η_q、η_j` 代入 `μ≥0` 并对 `λ` 求解，得第一式；由实时约束 `WCET(w)≤T_s` 得第二式。两式联立即"不能同时最大化精度、刚度与采样率"。∎ 推论：**"高精度 + 高刚度 + 高频率"在嵌入式阻抗控制里不可能三者兼得**；必须显式用刚度、精度或周期去交换。

## 6. 已知风险与失效模式

1. **上界过松导致长期第 0 档**：`η_q、η_j` 按最坏符号累加，可能比真实注入大一个数量级，`μ<0` 频繁触发，系统退化为纯阻尼、任务活性塌缩。缓解：分区更细的局部 Lipschitz 界、实测误差标定、档位内自适应收紧 `X`。

2. **量化误差的非白噪声偏置**：闭环与时变增益使舍入误差相关，单步上界虽 sound，但累积耦合可能使实际能量路径与逐步界不同。缓解：以完整区间轨迹而非单步界复核关键档、硬件在环长期运行、注入已知扰动做见证测试。

3. **账本与控制器共享算术**：若实现者复用同一套定点库，账本的"向外"可能被编译器优化或饱和静默破坏。缓解：账本放在独立整数域 / 协处理器、单元测试强制检查单调性、编译产物二进制级审计。

4. **抖动界低估**：最坏抖动常由中断风暴、DMA 抢占、缓存未命中造成，手册值不够。缓解：硬件在环压力测试、watchdog、动态测量 `δ̂` 并留足余量、抖动超标即降档。

5. **变阻抗凸包外的"更优"增益**：真正任务最优的刚度可能落在认证凸包外，GSPP 会拒绝，导致性能损失与频繁降档。缓解：扩充认证点、在线安全扩展小步试探并用账本付费、接受保守性作为安全成本。

6. **能量罐语义与物理能量脱节**：罐只是"可注入额度"的抽象，若标定与真实关节 / 电机能量尺度不一致，`E_res` 可能名不副实。缓解：统一到电机侧可测能量、留 2× 保守系数、断电 / 使能切换时重置。

7. **接触环境非被动**：人手推、主动环境、弹性储能都可能使"被动控制器 + 无源环境"假设失效；被动性不足以保证力安全。缓解：叠加力 / 位置硬限幅、接触力上限独立守卫、把环境非被动性作为独立风险预算。

8. **精度档切换的瞬态**：换档瞬间 `K、D` 跳变，若未限制切换速率，瞬态注入可能超过 `η_sched`。缓解：切换也走 GSPP 凸包与 `ρ_K` 限速、换档前插入一拍柔顺过渡、切换期间强制低档。

## 7. 本轮最大风险

**一句话**：整套证书的基石是"能量注入上界 `η_q、η_j` 与账本收支都 sound"，但这两个量都由实现者按自己的硬件 / 编译 / 标定假设给出；一旦假设偏差（量化步长被优化器改变、抖动被低估、能量尺度标错），系统会在"每档 `μ≥0`、每步账本非负"的漂亮日志下持续积累真实能量并失稳——即**用一套自洽但前提错误的账，证明了错误结论**。
