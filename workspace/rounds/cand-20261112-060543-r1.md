# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；灵感循环第 6 轮；本轮灵感：「情感计算」×「主动交互」）

> 第 59 轮把「证据承诺」一路下沉到了关节：BLDC 不确定性量化、实时契约、阻抗安全编译、双向契约闭环——机器人终于能对「我自己的执行是否可信」给出带证书的答案。但整条链条仍有一个未被正视的盲点：**它始终把「人类」当成环境里一个可以被探针测、被轨迹绕、被力限幅保护的对象，而不是一个有私有内心、会因被观测而改变、且拥有「注意力主权」的主体**。本轮两个灵感正好从两侧夹住这个盲点：**情感计算**负责「读」——推断人类的效价/唤醒/参与度/信任/负荷/压力；**主动交互**负责「写」——机器人主动发起帮助、提示、接近、提问。读与写一旦闭环，就暴露出第 59 轮物理契约所没有的三类硬问题：情感**没有 ground-truth 传感器**（不可约辨识缺口）、主动行为**消耗的是别人的注意力**（人类拥有的预算）、机器人的动作**本身就是情感观测的混淆变量**（观察者效应）。本轮核心命题：**把人类建模为「非合作、私有、反应性、拥有注意力主权」的观测对象；把主动交互建模为需要「注意力预算 + 同意 + 信任校准」三重授权的社会承诺；在物理双向契约之外，建立「机器人内部证书 ↔ 人类心智信任」的社会双向契约。**

核心矛盾：
- **H32（情感的不可约辨识缺口·私有状态）**：第 59 轮假设执行状态 ξ_exec 可由遥测辨识，并在 N_id 次接触后收敛到 χ² 置信椭球。但人类的真实情感没有传感器：自报稀疏、延迟，且本身是被问出来的（反应性）；表情/语音/生理受**展示规则（display rules）**与文化脚本调制而系统性掩蔽。于是情感后验的直径存在一个**不可约下界 ε_id>0**——数据再多也不能归零。若把情感当成又一个「会收敛的 ξ」，社会决策就建立在「自洽的过度自信」上。必须用**共形歧义集 A_aff** + **对最坏情况鲁棒的决策**，并在部署界里保留非消失的 ε_id 项。
- **H33（主动交互的注意力外部性·成本不对称且不可观测）**：探针预算 B_probe 是机器人自己的，花超了只是变慢；主动交互预算却是**人类的注意力与善意**——机器人不拥有、不能直接读、花超了会累积成打扰、警报疲劳、信任侵蚀。假阳性（不必要地打断）与假阴性（该帮没帮）代价高度不对称，且假阳性代价随连续打断**超线性**增长。必须引入**人类拥有的介入预算 B_int**、**非对称损失**、以及「预算/同意未知 ⇒ 默认静默」的硬规则。
- **H34（观察者效应·情感-行动因果混淆）**：机器人只在行动时观测情感，于是把「任务压力」与「被机器人盯着/催促的压力」混为一谈；朴素的情感反馈环会导致自激振荡（机器人以为人焦虑 → 退开 → 人因任务更难更焦虑 → 机器人更主动 → 人更烦 → …）。必须用**动作条件化的结构因果模型**做去混淆，估计 do(π) 的因果情感效应 ACE；不可辨识时把效应视为未知并触发保守。
- **H35（信任校准·社会安全的新目标）**：机器人可以物理上完全安全，却在社会上造成伤害——**过度信任**让人放松监督（机器人出错时灾难性），**信任不足**导致弃用。信任是一个**可被机器人影响、部分可观测、非平稳**的隐状态，存在一个目标带；机器人下发的证书 Cert_eeis 与人类心里的「民间证书」（信任）必须对账。于是社会安全的目标从「不伤害身体」扩展为「不让信任偏离真实可靠度」。

## 0. 直觉与动机

**灵感 1（情感计算 → 带辨识缺口的歧义集 APU）**
直觉：情感不是「一个数」，而是**一个受私有性保护、受展示规则掩蔽、个体差异极大的隐变量**。第 59 轮的 BUQ 之所以能收敛，是因为电机参数终究被电压/电流方程约束；情感没有这样的「守恒律」，只有一堆相关但不充分的代理信号（面部动作单元、语音韵律、皮电/心率、行为节律、自报）。关键洞见：**不要把「估计得更准」当成目标，而要把「诚实地说出还剩多少不确定」当成目标**——用共形预测给出覆盖率 ≥1−α 的歧义集 A_aff，并显式估计**不可约辨识下界 ε_id**（由掩蔽、隐私、自报延迟决定）。情感证据 EV-aff 携带的不是一个点估计，而是 (A_aff, ε_id, 模态可靠度 ρ_m, 同意范围)——所有下游社会决策必须对 A_aff 中的**最坏**情感成立。

**灵感 2（主动交互 → 人类拥有的注意力预算 PAB）**
直觉：主动交互是**向人类征税**：每一次「我能帮你吗？」都花掉一点注意力、一点耐心、一点信任。这笔预算的户主是人类，不是机器人。机器人只能通过间接信号（响应延迟、回避、明确拒绝、参与度下降）推断余额，且余额会被**连续打断超线性消耗**、被**正向结局缓慢补充**。于是主动决策不再是「收益 > 0 就做」，而是在**非对称损失**下做：假阳性代价（打扰 + 信任侵蚀）远高于假阴性代价（错过帮助），且当信任信用接近零时，假阳性代价趋于无穷（硬约束）。默认策略必须是**静默优先**。

**灵感 3（观察者效应 → 动作条件化去混淆 ARX）**
直觉：如果机器人只在自己行动时看人脸，它看到的「皱眉」可能来自任务，也可能来自「机器人又在旁边转」。**观测到的情感 = 任务引起的情感 + 机器人动作引起的情感 + 个体基线**，三者混淆。要判断「我这一主动动作会不会让人更舒服」，问的不该是 p(affect | action)（相关），而是 E[affect | do(action)] − E[affect | do(∅)]（因果）。用结构因果模型 + 后门调整估计 ACE；若调整集不存在，用**部分辨识**给出 ACE 上下界；若上下界跨零且宽度大，则标记 reactive_flag，情感证据权重乘性降级。这样能防止「越关心越打扰、越打扰越焦虑」的自激环。

**灵感 4（信任校准 → 机器人证书与人类心智的双向对账 TCC）**
直觉：第 59 轮的 Cert_eeis 是机器人**内部**的证书；人类手里握着一张**民间的**证书——信任 τ。二者若不校准，物理安全成立而社会安全失效。信任可被影响：主动帮助提升 τ，诚实披露不确定性降低过度信任，要求人工复核降低自满。于是把信任当**受控隐状态**，控制目标是把校准误差 |τ̂−R_actual| 压进目标带，且**过度信任的惩罚远大于信任不足**。同时，证书必须被**渲染**成人能懂的校准解释（说「我很确信」时的实际正确率 ≈ 所说的置信度），渲染本身也要过 ECE 审计。

**灵感 5（合流 → 社会双向契约 SAGES）**
直觉：把上述四件事合成一个闭环：**读人类（APU，带 ε_id）→ 去混淆（ARX）→ 校准信任（TCC）→ 过主动门（PAG：同意 ∧ 预算 ∧ 规范默认 ∧ 鲁棒收益）→ 执行（物理部分走第 59 轮 CLEP）→ 观察反应 → 更新预算/信任/歧义集 → 渲染校准解释 → 记入社会证书 J_soc**。这与第 59 轮形成镜像：物理契约是「概率安全界 ↔ 确定性硬约束」，社会契约是「私有内心 ↔ 主动承诺」，两者共享同一个骨架——**证据不能凭空自信；动作只能更保守；证书必须可对账**。

## 1. 形式化定义（增量：定义 153–160）

**定义 153（情感状态与不可约辨识缺口 APU）**
情感状态 ξ_aff=(v, a, e, b, l, s)∈ℝ⁶（效价、唤醒、参与度、信任、认知负荷、压力），个性化参数 θ_p（个体基线、展示规则、文化先验）。模态集 ℳ_aff={face, voice, physio, behav, selfrep}。观测模型 y_m ∼ p(y_m | ξ_aff, θ_p, c, do(π_prev))。共形歧义集：
```
A_aff(c, α) = { ξ : score(ξ, y, c, θ_p) ≤ q̂_{1−α} },   P(ξ_true ∈ A_aff) ≥ 1−α
```
辨识下界：`ε_id(θ_p, c) = lim_{n→∞} inf_{D_n} diam(A_aff)`，并假设 `ε_id ≥ ε_id^min > 0`（掩蔽、隐私、自报延迟导致）。情感证据 `EV-aff=(A_aff, ρ_m, ε_id, θ_p, reactive_flag, consent_scope)`。**与 BUQ 的根本区别**：BUQ 的前提是「收敛」（lim diam→0），APU 的前提是「地板」（lim diam ≥ ε_id）。下游一切社会决策必须对 A_aff 取最坏。

**定义 154（情感反应性排除 ARX）**
结构因果模型 M_cau=(C, π, ξ_aff, Z, U, F)，其中 C=上下文、π=机器人动作、Z=混淆变量（任务难度等同时影响动作与情感）。因果情感效应：
```
ACE(π | c) = E[ξ_aff | do(π), c] − E[ξ_aff | do(¬π), c]
```
若存在有效后门调整集 W，则 `p(ξ|do(π),c)=Σ_w p(ξ|π,c,w)p(w|c)` 可辨识；否则用部分辨识给出界 `ACE∈[L,U]`。反应性标记：
```
reactive_flag = 1[ (U−L) > ε_ace  ∨  (L≤0≤U ∧ U−L > ε_ace) ]
```
当 reactive_flag=1，情感证据权重乘性降级 ρ_aff←ρ_aff·λ_rx（封底 ρ_min），且禁止把观测情感直接归因于人类内在状态。

**定义 155（人类拥有的注意力预算 PAB）**
主动动作 π_pro=(类型, 时机, 模态, 内容, 持续)。注意力代价 c_attn(π_pro | A_aff)=对 A_aff 取最坏的期望打扰代价。人类拥有的预算 B_int=(N_int, K_trust, K_attn)：剩余打断次数、信任信用、注意力信用；只能通过代理信号（响应延迟、回避、明确拒绝、参与度）间接观测。补充规则：仅由**显式同意**或**正向结局**触发、且有界（信任信用慢充、打断次数慢恢复）。非对称损失：
```
L_pro = λ_FP·1[π_pro 不当]·g(N_consec) + λ_FN·1[错过关键帮助],   g 超线性
```
硬约束：K_trust ≤ ε_k ⇒ c_attn = +∞（信任耗尽即禁止主动）。主动价值 `VOI_pro(π)=min_{ξ∈A_aff}[benefit] − max_{ξ∈A_aff}[c_attn] − risk_trust(π)`。

**定义 156（信任校准控制 TCC）**
人类信任 τ 为隐状态，机器人实际可靠度 R 由第 59 轮证书与执行证据的经验成功/校准给出。校准误差 `e_trust=|τ̂−R|`。信任动力学 `τ_{t+1}=g(τ_t, R_t, outcome_t, explanation_quality_t, proactivity_t)`。控制目标：`e_trust ≤ ε_trust`，且过度信任惩罚 λ_over ≫ λ_under（因为过度信任→自满→机器人出错时灾难）。控制输入：主动帮助（↑τ）、诚实不确定性披露（↓过度信任）、强制人工复核（↓自满）。渲染函数 `Rend(Cert_eeis, EV-exec, δ_f)→x_face` 必须满足**解释校准**：`ECE(Rend) ≤ ε_expl`（说「90% 确信」时经验正确率≈90%）。

**定义 157（主动交互证据门 PAG）**
第八类证据 `EV-pro`。主动动作仅在以下条件**全部**满足时放行：
```
(P1) consent_scope ⊇ π_pro 的传感器/动作类型
(P2) min_{ξ∈A_aff} benefit(π_pro,ξ) > max_{ξ∈A_aff} c_attn(π_pro,ξ) + risk_trust
(P3) δ_norm(π_pro | A_aff) ≤ δ_norm^max          # 社会规范不确定性
(P4) B_int.spendable(π_pro) ∧ K_trust > ε_k
(P5) 不处于 DEGRADE_SOC 模式
(P6) π_pro 的物理分量（如有）已通过第 59 轮 CLEP 与七类证据门
```
**静默优先（silence-by-default）**：任一条件未知/不可得即不放行；放行失败时的合法输出是 {静默, 请求同意, 延后}，而不是「试探性打扰」。

### IP-152 APU（情感歧义集与辨识缺口）

```python
class AffectiveProbabilisticUnderstanding:
    def __init__(self, conformal_calibrator, personalizer, alpha=0.1):
        self.cal = conformal_calibrator          # 跨被试/跨情境共形校准集
        self.pers = personalizer                 # 在线个性化 θ_p
        self.rho = {m: 1.0 for m in MODALITIES}  # 模态可靠度
        self.alpha = alpha
        self.consent = None

    def update(self, obs, context, prev_action):
        lik = {m: self.emission(m, obs[m], context, self.pers.theta)
               for m in obs if self.consent.covers(m)}          # 同意范围内
        lik = self.pers.reweight(lik)                            # 个体基线校正
        A = self.cal.ambiguity_set(lik, alpha=self.alpha)        # 覆盖率 ≥1-α
        eps_id = self.cal.identifiability_floor(context, self.pers.theta)
        return AffectEvidence(A=A, eps_id=eps_id, rho=lik,
                              reactive=False, consent=self.consent)

    def worst_case(self, f, A):
        return min(f(xi) for xi in A.grid())                     # 对歧义集取最坏
```

### IP-153 ARX（动作条件化去混淆）

```python
class AffectiveReactivityExclusion:
    def estimate(self, pi, context, data):
        W = self.backdoor_adjustment_set(pi, context)
        if W is not None:                                        # 可辨识
            ace = self.adjust(pi, context, W, data)
            return ace, (ace, ace), True
        L, U = self.partial_identify(pi, context, data)          # 部分辨识
        reactive = (U - L > EPS_ACE) or (L <= 0 <= U and U - L > EPS_ACE)
        return 0.5 * (L + U), (L, U), not reactive

    def degrade(self, rho, lam=0.3, floor=0.05):
        return {m: max(floor, v * lam) for m, v in rho.items()}
```

### IP-154/155/157 PAB + TCC + PAG（注意力预算、信任、主动门）

```python
class ProactiveAttentionBudget:
    def __init__(self, n_int=5, k_trust=1.0, k_attn=1.0):
        self.N_int, self.K_trust, self.K_attn = n_int, k_trust, k_attn
        self.N_consec = 0

    def c_attn(self, pi_pro, A_aff):
        base = worst_case(lambda xi: INTERRUPT_COST(pi_pro, xi), A_aff)
        return base * (1.0 + self.N_consec)                      # 连续打断超线性
    def spendable(self, pi_pro):
        return self.N_int > 0 and self.K_attn > 0 and self.K_trust > EPS_TRUST
    def update(self, response):
        if response.accepted: self.N_consec = 0; self.K_trust = min(1.0, self.K_trust + 0.05)
        elif response.refused: self.N_consec += 1; self.K_trust *= 0.7; self.N_int -= 1
        else: self.N_int -= 1

class TrustCalibrationControl:
    def update(self, history, R):
        self.tau = self.filter.update(history.observations)     # 部分可观测滤波
        return self.tau
    def loss(self, tau_hat, R):
        err = tau_hat - R
        return LAMBDA_OVER * max(0, err) if err > 0 else LAMBDA_UNDER * (-err)
    def render(self, cert, ev, tau_hat, aff):
        q = self.calibrated_confidence(cert, ev)
        return Explanation(claim=self.verbalize(q, tau_hat),
                           stated_conf=q, calibrated=True)

class ProactiveActionGate:
    def allow(self, pi_pro, A_aff, B_int, consent, trust):
        if not consent.covers(pi_pro): return False, "no_consent"
        if trust.K_trust <= EPS_TRUST: return False, "trust_exhausted"
        benefit = min(INTERVENTION_BENEFIT(pi_pro, x) for x in A_aff.grid())
        cost = B_int.c_attn(pi_pro, A_aff)
        if benefit - cost <= 0: return False, "nonpositive_voi"
        if self.norm_uncertainty(pi_pro, A_aff) > DELTA_NORM_MAX:
            return False, "norm_uncertain"                       # 静默优先
        if not B_int.spendable(pi_pro): return False, "budget"
        return True, "ok"
```

### IP-157 SIL（社会闭环算子）

```python
def socially_grounded_interaction_loop(M, context, task):
    aff = M.apu.update(M.obs_aff, context, M.prev_action)        # ① 读（带 ε_id）
    ace, bounds, ident = M.arx.estimate(M.prev_action, context, M.data)  # ② 去混淆
    if not ident:
        aff.rho = M.arx.degrade(aff.rho); aff.reactive = True
    tau_hat = M.tcc.update(M.interaction_history, M.reliability) # ③ 信任估计
    pi_pro = M.proposer.propose(aff.A, tau_hat, task)
    ok, why = M.pag.allow(pi_pro, aff.A, M.B_int, M.consent, tau_hat)    # ④ 主动门
    if not ok:
        M.log_social(pi_pro, why)
        return M, choose(why, SILENT, DEFER, ASK_CONSENT), why
    if pi_pro.has_physical_component:                            # ⑤ 物理分量走第 59 轮 CLEP
        M, fused, D, ev, cert = closed_loop_exec_probe(
            M, pi_pro.cp, M.risk.delta_f(pi_pro.cp), M.budget)
        if ev.degraded_flag:
            return M, DEGRADE_SOC, "exec_degraded"
    else:
        execute_social_action(pi_pro)
    resp = observe_response(pi_pro, timeout=pi_pro.tau_resp)     # ⑥ 观察反应
    M.B_int.update(resp); M.tcc.update_outcome(resp)
    M.apu.update(resp.affect, context, pi_pro)                   # 反应性观测（作为因果数据）
    face = M.tcc.render(M.cert_chain[-1], M.EV_exec_log[-1], tau_hat, aff)  # ⑦ 校准渲染
    M.jsoc.append(build_social_cert(aff, ace, bounds, ident, M.B_int,
```

```python
class AffectiveProbabilisticUnderstanding:
    def __init__(self, conformal_calibrator, personalizer, alpha=0.1):
        self.cal = conformal_calibrator
        self.pers = personalizer
        self.rho = {m: 1.0 for m in MODALITIES}
        self.alpha = alpha
        self.consent = None

    def update(self, obs, context, prev_action):
        lik = {m: self.emission(m, obs[m], context, self.pers.theta)
               for m in obs if self.consent.covers(m)}
        lik = self.pers.reweight(lik)
        A = self.cal.ambiguity_set(lik, alpha=self.alpha)      # coverage >= 1-alpha
        eps_id = self.cal.identifiability_floor(context, self.pers.theta)
        assert eps_id >= EPS_ID_MIN                              # 不可归零，显式断言
        return AffectEvidence(A=A, eps_id=eps_id, rho=lik,
                              reactive=False, consent=self.consent)

    def worst_case(self, f, A):
        return min(f(xi) for xi in A.grid())

    def set_consent(self, consent):
        self.consent = consent                                    # 撤回即 next update 生效
```

```python
        return M, fused, D_plus                          # 情感不参与、只保守
    w_aff = aff_ev.reliability_scalar()                  # 低权重软模态
    # 情感仅加宽 D，不作为 EV-xmodal/EV-human 佐证
    D_pp = D_plus + w_aff * (tv_distance(aff_ev.label_dist, fused.label_dist)
                             + abs(aff_ev.q50 - fused.q50) / MU_SCALE)
    fused = widen_posterior(fused, w_aff)                # 冲突/一致都只加宽
    return M, fused, D_pp
```
