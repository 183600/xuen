# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；新一轮灵感循环第 1 轮；本轮灵感：「联邦学习」×「数据增强」）

> 第 54 轮把技能组合推进到动作-鲁棒性双证书：`α_S` 回答「动作空间是否覆盖」，`J` 回答「云边是否对齐」。但这套证书仍隐含两个更强的前提：**证据是集中可池化的，且样本都是真实交互产生的**。本轮用「联邦学习」与「数据增强」拆掉这两个前提：证据天然分散在各私有边端且非独立同分布；增强样本是合成证据，既能填补覆盖，也能伪造覆盖。核心矛盾：**H22 证书不可加性**——各客户端的局部证书不能通过加权平均合成全局证书，非 IID 下平均会系统性高估；**H23 增强洗证据**——数据增强在缩小方差的同时注入语义偏差，把 `N_eff` 抬高却把真实能力估高；**H24 隐私-证据互斥**——DP 噪声与安全聚合恰好抹掉签发细粒度证书所需的信息；**H25 拜占庭证书投毒**——恶意客户端可同时污染模型与证书统计，而聚合层只看到数字，看不到数据。

## 0. 直觉与动机

**灵感 1（联邦学习 → 证据是分布的，不是池化的）**
直觉：第 54 轮的 `D_S = {(β_i,o_i,a,y)}` 被当成一个可合并的数据池。现实中它分散在 `K` 个边端，每个 `D_k ~ P_k`，而 `P_k` 因地形、负载、传感器老化、任务偏好而显著不同。把各客户端 LCB 加权平均，得到的是「平均客户端的平均能力」，不是「目标部署客户端的置信下界」。联邦学习的第一课因此不是「分布式训练」，而是：**聚合的是统计量，不是证书**。证书的 soundness 必须在客户端分布层重新证明，并显式计入异质性 `d_k = TV(P_k,P_T)`、客户端参与偏差 `β_part` 与联邦有效样本量 `N_eff^fed`。

**灵感 2（数据增强 → 增强是证据合成，必须过有效性闸门）**
直觉：增强能扩大覆盖、降低方差，但它同时是一个 **有偏的证据生成器**。把「红色=可抓」的纹理增强进来，会让策略在增强分布上成功率上升、在真实 OOD 上下降。所以增强样本不能按真实样本计入 `N_eff`：需要有效性谓词 `V(g;x)`、语义/物理保持检验与合成信任折扣 `κ`，并把增强偏差 `B_aug` 从 LCB 中扣除。关键判据：**只有当方差缩减严格大于偏差时，增强才是「证据」；否则只是「证据噪声」**。

**灵感 3（非独立同分布 → 全局证书与个性化证书必须分离）**
直觉：一个全局证书只能承诺「混合分布上平均可部署」，不能承诺「每个客户端都可部署」。引入 **min-客户证书** 与个性化缺口 `g_k = c_G^- − c_k^-`。云端职责从「签发一个全局证书」变成「保证没有客户端掉队（no client left behind）」：对掉队客户端用联邦增强或少量本地真实数据做个性化校准，而不是把它平均掉。

**灵感 4（隐私 → 噪声感知证书与可组合预算）**
直觉：DP 的噪声不是免费的，它直接加宽置信区间；安全聚合让云端看不到单个客户端的 `c_k`，只能看到聚合统计。于是证书必须 **在隐私预算内可签发**：给定 `(ε,δ)`-DP 与聚合机制，LCB 要额外扣除噪声半径 `rad_DP`，并给出隐私-证书宽度 Pareto 前沿。隐私不是证书的对立面，而是证书的一个显式维度——不能为了「让证书好看」偷偷调小 `δ`。

**灵感 5（拜占庭鲁棒 → 证书也要抗投毒）**
直觉：联邦学习里恶意客户端能上传错误梯度；在证书场景里，它可以直接谎报 `c_k^-`、`r_aff`、`D_k` 规模。仅靠安全聚合不够，还需 **证据证明（attestation）** 与 **鲁棒聚合**（截尾均值/中位数/信誉）。证书 soundness 必须含拜占庭项 `B_byz(f)`，且只在 `f < 1/2` 时成立；`ε_attest > 0` 必须显式扣除。

**灵感 6（联邦增强 → 共享增强策略而非共享数据）**
直觉：跨客户端共享原始数据违反隐私，但可以共享 **增强策略/生成器参数 `θ_aug`**。每个客户端在本地验证集上评估增强增益与有效性，只回传统计量；云端做联邦优化，目标不是平均增益，而是 **最差客户端增益最大化（maximin）**。还要注意增强复合性陷阱：两个单独有效的增强 `g1,g2`，其复合 `g1∘g2` 可能破坏物理可行性，必须单独验证并计「增强干扰」预算。

**灵感 7（云边联邦闭环 → 证书收敛而非一次签发）**
直觉：把第 54 轮的「云规划-边校验-解释回传」升级为「云聚合-边证明-反例回传-策略再联邦」。云端维护全局证书 `C_G` 与增强策略 `θ_aug`；边端维护个性化证书 `C_k` 与本地有效性闸门；失败时回传 **联邦反例 `(k*, x*, g*, φ*)`**（哪个客户端、哪个样本、哪个增强、哪个可供性假设失效）。闭环目标不是「一次规划成功」，而是 **最差客户端证书与增强有效性的单调改善**。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（联邦证据与目标混合）**
客户端集合 `K = {1..K}`，客户端 `k` 的私有经验 `D_k ~ P_k`，样本量 `n_k`，客户端权重 `π_k ≥ 0, Σ_k π_k = 1`。目标部署分布 `P_T = Σ_k π_k P_k`（一般地 `P_T` 可不同于该混合）。云端不可见原始样本，仅可见客户端上报的统计量 `s_k = s(D_k)`。异质性 `d_k = TV(P_k, P_T)`，参与率 `q_k = P(k 参与某轮 | k∈K)`，经验参与权重 `\hat π_k`。

**定义 122（局部证书与联邦证书）**
客户端 `k` 的局部证书
```
C_k = (c_k^-, r_{aff,k}, κ_{cf,k}, N_{eff,k}, att_k, evidence_k)
```
其中 `c_k^-` 是第 54 轮 LCB 在本客户端分布 `P_k` 上的版本，`att_k` 为证据证明。全局证书
```
C_G = (c_G^-, {C_k}_{k∈K}, β_het, β_part, B_byz, rad_DP, δ_total)
```
**关键约定**：`C_G` 不是 `{C_k}` 的加权平均，而是满足定义 123 下界的独立对象。

**定义 123（联邦证书下界与异质性代价）**
设成功指示 `y ∈ [0,1]`、`f_k = E_{P_k}[y]`。对任意 `k` 有 `|f_k − f_T| ≤ d_k`（`f_T = E_{P_T}[y]`），故
```
c_G^- = max_k [ c_k^- − d_k ] − β_part − rad_agg − B_byz − rad_DP
rad_agg = sqrt( ln(2/δ_total) / (2 N_eff^fed) )
N_eff^fed = (Σ_k π_k n_k^{eff})² / Σ_k (π_k n_k^{eff})²
```
若 `P_T` 恰为加权混合，可用更紧的
```
c_G^- = Σ_k π_k c_k^- − β_het − rad_agg − B_byz − rad_DP,
β_het = Σ_k π_k d_k
```
两种形式都显式拒绝「对局部 LCB 直接取平均」：直接平均会漏掉 `β_het` 与 `rad_agg`，在非 IID 下系统性高估。

**定义 124（增强算子、有效性与增强证据）**
增强群 `G` 作用于样本 `x = (β,o,a)`。增强 `g∈G` 的有效性谓词
```
V(g;x) = 1 ⟺ ( y(g·x)=y(x) ) ∧ ( feas(g·x)=feas(x) ) ∧ ( φ*(g·x)=φ*(x)  ∀φ∈Φ )
```
有效性率 `v(g) = P_{x~P}(V(g;x)=1)`。复合有效性**不继承**：`V(g1∘g2;x) ≤ min(V(g1;x),V(g2;x))` 一般不成立，必须单独检查 `V(g1∘g2)`。增强证据的标签偏差
```
B_aug = Σ_g p_g (1 − v(g)) · L_g,   L_g = sup_x | E[y|x] − E[y|g·x] |
```
`p_g` 为增强采样概率，`L_g` 为标签漂移上界；`B_aug` 是「增强把 LCB 拉低」的显式代价。

**定义 125（证据来源记账与有效样本量）**
每个样本带来源标记 `src_i ∈ {real, synth, xclient}` 与信任折扣 `κ_i ∈ (0,1]`（`κ=1` 为真实本地样本，`κ=τ_s<1` 为合成样本，跨客户端增强再乘 `τ_c`）。加权有效样本量
```
N_eff = (Σ_i w_i κ_i V_i)² / Σ_i (w_i κ_i V_i)²
```
`w_i` 为重要性权重，`V_i∈{0,1}` 为有效性闸门结果。**经验洗白指数** `Λ_launder = N_eff / max(N_real,1)`，要求 `Λ_launder ≤ Λ_max`，否则视为用合成样本买置信。

**定义 126（增强后 LCB 与增强盈利判据）**
```
c_aug^- = \hat c_aug − rad(δ, N_eff) − B_aug − ε_model
```
**增强盈利条件**
```
Δrad = rad(δ, N_real) − rad(δ, N_eff) > B_aug + Δε_model
```
即方差缩减必须覆盖偏差与模型漂移；否则增强虽降低估计方差，却把真实 LCB 拉低，应被拒绝。该条件把「数据增强是否有效」变成一个可证伪的单侧检验。

**定义 127（隐私感知证书与隐私-证书前沿）**
客户端以 `(ε_k,δ_k)`-DP 上报统计量，敏感度 `Δs`，高斯机制噪声尺度
```
σ_k = Δs · sqrt( 2 ln(1.25/δ_k) ) / ε_k
```
隐私感知 LCB
```
c_{DP,k}^- = c_k^- − z_{1−δ_k} · σ_k / sqrt(n_k^{eff})
```
总预算按 advanced composition 组合为 `(ε_total,δ_total)`。定义隐私-证书前沿 `F(ε) = min` 可达的证书半宽，部署要求 `F(ε_total) ≤ w_max`。达不到时必须增加本地样本或联邦增强，**不能**偷偷调小 `δ`。

**定义 128（鲁棒联邦聚合与证书证明了）**
恶意客户端比例 `f < 1/2`。证书聚合采用坐标截尾均值 `Trim_h`（截去上下各 `h ≈ f` 分位）。拜占庭偏差上界
```
B_byz(f) ≤ (2f)/(1−f) · range(c) + ε_attest,   range(c) = 1
```
客户端上报附证据证明 `att_k = (hash(D_k), signature_k, TEE_quote?)`。云端无法验证内容真实性时只能依赖鲁棒统计，故 `ε_attest > 0` 必须显式扣除。鲁棒证书
```
c_{G,rob}^- = Trim_h( { c_k^- − d_k − z σ_k/sqrt(n_k) } ) − B_byz(f) − β_part
```

## 2. 关键算法 伪代码

### IP-121 FCA（Federated Certificate Aggregation）

```python
def federated_certificate(clients, P_target, delta_total):
    stats = []
    for k in clients:
        c_k = local_certificate(k, P_target)          # 局部 LCB + TV(P_k,P_target)
        stats.append((c_k.lcb - c_k.tv_to_target, k.weight,
                      c_k.n_eff, c_k.attestation))
    n_eff = (sum(w * n for (_, w, n, _) in stats) ** 2
             / max(sum((w * n) ** 2 for (_, w, n, _) in stats), 1e-12))
    rad = sqrt(log(2 / delta_total) / (2 * n_eff))
    beta_part = participation_bias(stats)             # Σ|π_k - \hat π_k|
    c_global = max(c for (c, _, _, _) in stats) - beta_part - rad
    return GlobalCert(c_global, [s[0] for s in stats], beta_part, n_eff)
```

### IP-122 AAG（Augmentation Admissibility Gate）

```python
def admissibility_gate(g, x, verifier):
    gx = g(x)
    label_ok = verifier.label(gx) == verifier.label(x)
    feas_ok  = verifier.feasible(gx) == verifier.feasible(x)
    aff_ok   = all(verifier.affordance(gx, phi) == verifier.affordance(x, phi)
                   for phi in PHI)
    valid = int(label_ok and feas_ok and aff_ok)
    L_g = label_shift_upper_bound(g, x, verifier)
    return GateResult(valid=valid, bias=(1 - valid) * L_g)

def compose_gate(g1, g2, x, verifier):
    return admissibility_gate(lambda z: g1(g2(z)), x, verifier)
```

### IP-123 EPA（Evidence Provenance Accounting）

```python
def effective_evidence(D, weights, kappa, gates):
    wv = [w * kap * int(gate.valid)
          for w, kap, gate in zip(weights, kappa, gates)]
    n_eff = sum(wv) ** 2 / max(sum(v * v for v in wv), 1e-12)
    n_real = sum(1 for src in D.sources if src == 'real')
    launder = n_eff / max(n_real, 1)
    return n_eff, launder

def augmentation_lcb(c_hat_aug, n_real, n_eff, B_aug, eps_model, delta):
    c_aug = c_hat_aug - rad(delta, n_eff) - B_aug - eps_model
    delta_rad = rad(delta, n_real) - rad(delta, n_eff)
    return c_aug, (delta_rad > B_aug + eps_model)   # 盈利判据
```

### IP-124 DPC（DP-aware Certificate）

```python
def dp_certificate(local_lcb, eps_k, delta_k, sens, n_eff):
    sigma = sens * sqrt(2 * log(1.25 / delta_k)) / eps_k
    return local_lcb - norm_ppf(1 - delta_k) * sigma / sqrt(n_eff)

def privacy_frontier(clients, eps_total, delta_total, target_width):
    eps_split = compose_budget(eps_total, len(clients))
    widths = [certificate_width(dp_certificate(k, eps_split, ..., delta_total))
              for k in clients]
    return min(widths) <= target_width
```

### IP-125 RFA（Robust Federated Aggregation）

```python
def robust_certificate_aggregate(reports, f, range_c=1.0):
    vals = sorted([r.lcb - r.tv_to_target for r in reports])
    h = int(f * len(vals))
    trimmed = vals[h:len(vals) - h] if h else vals
    base = mean(trimmed)
    B_byz = (2 * f) / (1 - f) * range_c
    eps_attest = mean([r.attestation_residual for r in reports])
    return base - B_byz - eps_attest
```

### IP-126 FAP（Federated Augmentation Policy）

```python
def federated_augmentation_policy(clients, G, rounds, budget):
    theta = init_policy(G)
    for t in range(rounds):
        reports = []
        for k in clients:
            gain_k  = eval_aug_gain(theta, k.local_val, k.verifier)
            valid_k = aug_validity(theta, k.local_val, k.verifier)
            reports.append((gain_k, valid_k, k.attestation))
        theta = federated_opt(theta, reports, objective='maximin')
        if comm_budget_exceeded(budget, t):
            break
    return theta
```

### IP-127 PFC（Personalized Federated Certificate）

```python
def personalized_certificate(C_global, client, eps_personal):
    gap = C_global.lcb - client.local_lcb
    if gap <= theta_gap:
        return ('ok', C_global)
    D_probe = active_probe(client, budget=eps_personal)   # 少量真实数据
    C_k = local_certificate(client.with(D_probe), P_target=client.P)
    return ('ok', C_k) if C_k.lcb >= 1 - eps_tot else ('reject', gap)
```

### IP-128 FLC（Federated Loop Closure）

```python
def federated_loop(C_G, theta_aug, clients, budgets):
    while not budgets.exhausted():
        reports, counterexamples = [], []
        for k in clients:
            verdict, cert_k, ce = edge_attest(C_G, theta_aug, k)
            reports.append((k, cert_k, ce.attestation))
            if verdict != 'ok':
                counterexamples.append((k, ce.x, ce.g, ce.phi))   # 联邦反例
        C_G = robust_certificate_aggregate(
            [r[1] for r in reports], f=budgets.byz_frac)
        if counterexamples:
            theta_aug = federated_augmentation_policy(
                clients, G, rounds=budgets.R,
                seed_counterexamples=counterexamples)
        worst = min_k(C_G.client_lcb)
        if worst >= 1 - eps_tot:
            return ('ok', C_G, theta_aug)
    return ('reject', 'budget_exhausted', C_G)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| FCA | `O(Σ_k \|D_k\| + K log K)` | `O(K)` | `d_k` 上界有效、参与权重可估 |
| AAG | `O(\|G\|·\|Φ\|·T_verify)` | `O(\|G\|·\|Φ\|)` | 验证器可靠、标签漂移界有效 |
| EPA | `O(N)` | `O(N)` | 来源可追溯、折扣 `κ` 可辩护 |
| DPC | `O(K·d)` | `O(K)` | 敏感度紧、组合预算成立 |
| RFA | `O(K log K)` | `O(K)` | `f<1/2`、截尾比例覆盖恶意者 |
| FAP | `O(R·K·\|G\|·T_eval)` | `O(\|G\|)` | 增益可本地估、maximin 可优化 |
| PFC | `O(K·(N_p·T_roll))` | `O(K·\|D_k\|)` | 个性化缺口可测、探针有界 |
| FLC | `O(N_loop·K·(T_check+N_p·T_roll))` | `O(K·\|D\|)` | 最差客户端单调改善 |

**命题 1（证书平均的反例）**
存在两个客户端 `P_1,P_2`，各自 `c_1^- = c_2^- = 0.95`，但 `P_T = 0.5P_1+0.5P_2` 上真实成功率 `f_T = 0.6`。构造：`P_1` 只覆盖任务前半段、`P_2` 只覆盖后半段，各自在其支持集上成功率高，但混合后两端相接处的状态无人覆盖。加权平均给出 `0.95`，`max_k(c_k^- − d_k)` 给出更低的下界。因此 **局部证书的算术平均不是全局证书**，非 IID 下必须引入 `d_k` 与覆盖缺口。

**命题 2（增强洗白的不可行性）**
若 `v(g) < 1` 且 `L_g > 0`，则存在目标分布 `P_T` 与真实能力 `f_T`，使「用 `g` 扩大 `N_eff` 后」的 LCB 高于真实 `f_T` 的置信上界，即 `c_aug^- > f_T + δ`。构造：令 `g` 在训练支持集上近似保标签、在 `P_T` 的边缘区域改变标签，则方差缩小 `O(1/√N)`，而偏差 `B_aug` 在 `P_T` 上为常数不下沉。故 **未过有效性闸门的增强不能签发 sound 证书**；只有 `Δrad > B_aug` 时增强才净增益。

**正确性定理（Federated Augmented Certificate Soundness）**
承接第 54 轮 (A22)–(A28)；新增：
**(A29)** 客户端权重 `π_k` 已知至 `β_part`，且 `d_k` 有效上界真实差异；
**(A30)** 增强闸门假接受率 `≤ α_g`，`B_aug` 上界真实标签漂移，且 `Λ_launder ≤ Λ_max`；
**(A31)** 各客户端 `(ε_k,δ_k)`-DP 机制敏感度紧、组合预算 `(ε_total,δ_total)` 成立；
**(A32)** 恶意客户端比例 `f < 1/2`，证据证明残差 `≤ ε_attest`；
**(A33)** 个性化缺口 `g_k = max(0, c_G^- − c_k^-)` 有界，且 `P_T` 与混合分布的偏差被 `β_het` 覆盖。
则部署失败概率满足
```
P_fail ≤ max_k[ (1 − c_k^-) + d_k + g_k ] + B_aug + B_byz(f)
         + rad_DP + ε_attest + β_part + β_E + δ_total
```
若右端 `≤ ε_tot`，全局+个性化证书达到目标成功率 `1−ε_tot`。关键：**证据去中心化要付 `d_k` 与 `β_part`，证据合成要付 `B_aug`，隐私要付 `rad_DP`，开放参与要付 `B_byz`**；四笔代价都不能被「多增强一点」抵消。

## 2. 关键算法 伪代码

### IP-121 FCA

```python
def federated_certificate(clients, P_target, delta_total):
    stats = []
    for k in clients:
        c_k = local_certificate(k, P_target)
        stats.append({ 'lcb': c_k.lcb - c_k.tv_to_target,
                       'w': k.weight, 'n': c_k.n_eff,
                       'att': c_k.attestation })
    n_eff = (sum(s['w'] * s['n'] for s in stats) ** 2
             / max(sum((s['w'] * s['n']) ** 2 for s in stats), 1e-12))
    rad = sqrt(log(2 / delta_total) / (2 * n_eff))
    beta_part = sum(abs(pi - pi_hat) for pi, pi_hat in participation(stats))
    c_global = max(s['lcb'] for s in stats) - beta_part - rad
    return GlobalCert(c_global, stats, beta_part, n_eff)
```

### IP-122 AAG

```python
def admissibility_gate(g, x, verifier):
    gx = g(x)
    ok = (verifier.label(gx) == verifier.label(x)
          and verifier.feasible(gx) == verifier.feasible(x)
          and all(verifier.affordance(gx, phi) == verifier.affordance(x, phi)
                  for phi in PHI))
    L_g = label_shift_upper_bound(g, x, verifier)
    return GateResult(valid=int(ok), bias=(0 if ok else 1) * L_g)

def compose_gate(g1, g2, x, verifier):
    # 复合有效性不继承，必须整体重验
    return admissibility_gate(lambda z: g1(g2(z)), x, verifier)

def aug_bias(policy, verifier, sample, n):
    return sum(policy.p_g * admissibility_gate(g, x, verifier).bias
               for g, p_g in policy.weights for x in sample) / n
```

### IP-123 EPA

```python
def effective_evidence(D, weights, kappa, gates):
    wv = [w * kap * int(g.valid)
          for w, kap, g in zip(weights, kappa, gates)]
    n_eff = sum(wv) ** 2 / max(sum(v * v for v in wv), 1e-12)
    n_real = sum(1 for src in D.sources if src == 'real')
    launder = n_eff / max(n_real, 1)
    return n_eff, launder

def augmentation_certificate(c_hat_aug, n_real, n_eff, B_aug, eps_model, delta):
    c_aug = c_hat_aug - rad(delta, n_eff) - B_aug - eps_model
    delta_rad = rad(delta, n_real) - rad(delta, n_eff)
    profitable = delta_rad > B_aug + eps_model
    return c_aug, profitable
```

### IP-125 RFA

```python
def robust_certificate_aggregate(reports, f, range_c=1.0):
    vals = sorted([r.lcb - r.tv_to_target for r in reports])
    h = int(f * len(vals))
    trimmed = vals[h:len(vals) - h] if h else vals
    base = mean(trimmed)
    B_byz = (2 * f) / (1 - f) * range_c
    eps_attest = mean([r.attestation_residual for r in reports])
    return base - B_byz - eps_attest
```

```python
def personalized_certificate(C_global, client, eps_personal, eps_tot):
    gap = max(0.0, C_global.lcb - client.local_lcb)
    if gap <= theta_gap:
        return ('ok', C_global, gap)
    D_probe = active_probe(client, budget=eps_personal)
```

### IP-128 FLC

```python
def federated_loop(C_G, theta_aug, clients, budgets):
    while not budgets.exhausted():
        reports, counterexamples = [], []
        for k in clients:
            verdict, cert_k, ce = edge_attest(C_G, theta_aug, k)
            reports.append(cert_k)
            if verdict != 'ok':
                counterexamples.append((k, ce.x, ce.g, ce.phi))
        C_G = robust_certificate_aggregate(reports, f=budgets.byz_frac)
        if counterexamples:
            theta_aug = federated_augmentation_policy(
                clients, G, rounds=budgets.R,
                seed_counterexamples=counterexamples)
        if min(C_G.client_lcb) >= 1 - eps_tot:
            return ('ok', C_G, theta_aug)
    return ('reject', 'budget_exhausted', C_G)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| FCA | `O(Σ_k\|D_k\| + K log K)` | `O(K)` | `d_k` 上界有效、权重可估、`N_eff^fed` 正确 |
| AAG | `O(\|G\|·\|Φ\|·T_verify)` | `O(\|G\|·\|Φ\|)` | 验证器可靠、`B_aug` 上界、复合独立验证 |
| EPA | `O(N)` | `O(N)` | 来源可追溯、折扣可辩护、`Λ_launder≤Λ_max` |
| DPC | `O(K·d)` | `O(K)` | 敏感度紧、advanced composition 成立 |
| RFA | `O(K log K)` | `O(K)` | `f<1/2`、截尾覆盖恶意者、证明残差有界 |
| FAP | `O(R·K·\|G\|·T_eval)` | `O(\|G\|)` | maximin 可优化、复合有效性受约束 |
| PFC | `O(K·N_p·T_roll)` | `O(K·\|D_k\|)` | 缺口可测、探针有界、个性化不破坏全局 |
| FLC | `O(N_loop·K·(T_check+N_p·T_roll))` | `O(K·\|D\|)` | 最差客户端证书单调不降 |

**命题 1（局部证书平均的反例）**
两个客户端各自 `c_1^-=c_2^-=0.95`，但目标混合 `P_T=0.5P_1+0.5P_2` 上真实成功率仅 `0.6`。构造：`P_1` 只覆盖任务前半段、`P_2` 只覆盖后半段，各自在其支持集成功率高，混合后交接状态无人覆盖。故 `avg(c_k^-)=0.95 > f_T=0.6`，**平均法不 sound**；定义 123 的 `d_k` 与覆盖缺口必须显式扣除。

**命题 2（增强洗白的不可行性）**
若 `v(g)<1` 且 `L_g>0`，则存在目标 `P_T` 使 `c_aug^- > f_T` 的置信上界。构造：`g` 在训练支持集近似保标签、在 `P_T` 边缘区改标签；方差按 `O(1/√N)` 缩小，偏差 `B_aug` 在 `P_T` 上不随 `N` 下沉。故未过闸门的增强不能签发 sound 证书；仅当 `Δrad > B_aug` 时增强才净增益。

**正确性定理（Federated Augmented Certificate Soundness）**
承接第 54 轮 (A22)–(A28)；新增：
**(A29)** `π_k` 已知至 `β_part`，`d_k` 为真实 TV 上界；
**(A30)** 增强闸门假接受率 `≤α_g`，`B_aug` 覆盖真实标签漂移，`Λ_launder≤Λ_max`；
**(A31)** 各客户端 `(ε_k,δ_k)`-DP 敏感度紧、组合预算成立；
**(A32)** `f<1/2`，`ε_attest` 覆盖证明残差；
**(A33)** 个性化缺口 `g_k` 有界，`P_T` 与混合分布偏差被 `β_het` 覆盖。
则
```
P_fail ≤ max_k[(1−c_k^-) + d_k + g_k] + B_aug + B_byz(f)
         + rad_DP + ε_attest + β_part + β_E + δ_total
```
若右端 `≤ε_tot`，则全局+个性化证书达到目标成功率 `1−ε_tot`。四笔代价——**异质性 `d_k`、增强偏差 `B_aug`、隐私噪声 `rad_DP`、拜占庭 `B_byz`**——彼此不可互换，也不能被「多增强」抵消。

2. `C_G` 的全局下界 `c_G^- ≥ 1−ε_tot`；
3. 目标客户端个性化证书 `C_k` 通过（`g_k` 在预算内）；
4. 增强盈利判据 `Δrad > B_aug + Δε_model` 且 `Λ_launder ≤ Λ_max`；
5. 隐私前沿满足 `F(ε_total) ≤ w_max`；
6. 拜占庭假设 `f < 1/2` 且 `B_byz(f) + ε_attest` 已扣除。

任一失败 → 拒绝部署或收缩到「已验证客户端子集」。**宁可窄而真，不可宽而假**。

## 6. 本轮最大风险

**一句话**：联邦聚合与数据增强都让证书看起来更「满」——前者用更多客户端摊薄方差，后者用更多样本缩小半径——但两者共用同一份有限、非 IID、且被同一验证集审计的本地证据；最危险的情形是 `d_k` 被低估、`B_aug` 被低估、`f` 落在截尾盲区三者同时发生，使 `c_G^-` 在所有客户端上集体过度自信，因此必须以「平均法证伪实验 + 增强闸门独立分片 + 拜占庭比例硬上界」作为三道总闸，宁可签发窄而真的证书，也不签发宽而假的证书。
