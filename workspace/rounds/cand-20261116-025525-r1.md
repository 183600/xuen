# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「预测性维护」×「力矩传感」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**预见性退化 + 力矩残差证书 + 多时间尺度分离**。v9 的退化链是事件驱动的：模块超时或域偏移才降级，且安全论证只约束「瞬时几何 + 瞬时力」，隐含假设「机器人不会因累积载荷而损坏」。两个灵感分别治理两种债：**因果债**（只在失效后反应，没有剩余寿命预见）与**模态债**（安全判据缺少最直接的物理通道——关节力矩）。必须通过**共享传感器共模监控**防止「用坏掉的力矩传感器证明自己健康」。

## 0. 直觉与动机

**灵感 1（预测性维护 → 健康状态与剩余寿命驱动的主动退化）**
直觉：v9 的 Level-1..5 退化像保险丝——烧断了才动作。可靠性工程的正统做法是预测性维护：用退化观测量估计剩余使用寿命 RUL，在失效**之前**主动收窄能力包络（降低 K_max、速度、负载、禁用高应力原语），把"故障后的安全停驻"改写成"故障前的有计划降级"。核心创新：**健康状态估计器（HealthStateEstimator, HSE）** 输出健康指数 H_t ∈ [0,1] 与保守 RUL 下界；**预测性维护调度器（PredictiveMaintenanceScheduler, PMS）** 把 (H_t, RUL) 映射为能力包络 C_env 与 v9 退化级的排程。关键安全设计：**P13 预见性退化律**——退化是计划而非反应，且能力集随健康单调收窄（H↓ ⇒ C_env 嵌套缩小）。

**灵感 2（力矩传感 → 力矩残差证书与四类源分解）**
直觉：视觉碰撞检测有遮挡与帧延迟；电流估计受摩擦与温漂污染。关节力矩传感器直接测 τ，配合**广义动量观测器**得残差 r = τ_meas − τ̂；r 的时频签名可区分四类源：瞬时接触（突变、高频、短暂）、外负载（持续、与重力/加速度相干）、磨损（慢漂移、摩擦参数变化）、传感器故障（与电流估计失相干）。核心创新：**力矩残差证书器（TorqueResidualCertifier, TRC）**：|r| ≤ r_contact 作为瞬时硬证书并入 M₀ 硬检查；持续带能量作为累积损伤增量送入 HSE。关键安全设计：**P14 力矩残差证书律**——碰撞判据必须与负载/磨损/传感器故障分离，否则负载变化会制造误停、传感器漂移会掩盖真碰撞。

**灵感 3（多时间尺度融合 → 尺度分离与共模可观测）**
直觉：预测性维护的时间尺度是分钟到天，控制环是 20ms；若慢环阻塞快环，等于"用保养杀死实时安全"。核心纪律：慢环只写契约表、只给**建议包络**，永不阻塞快环；慢环失联则注入**保守非恒等安全元** C_env^⊥（最窄能力集），并升级人工维护请求。更隐蔽的风险是：力矩传感器既是碰撞判据又是健康输入，一次共模漂移会同时让"碰撞证书"和"健康结论"变乐观。核心创新：**P15 尺度分离与共模可观测律** + **力矩冗余监控器（TorqueRedundancyMonitor, TRM）**：用电流估计与冗余传感检查残差的可观测方向。

## 1. 研究问题（轮次升级版）

- **Q1（力矩证书可靠性）**：在关节模型误差 δ 与未知负载下，如何设计残差阈值与四类源分解，使接触检测不漏报、负载变化不误报？单传感器下"慢漂移故障"与"摩擦磨损"的可辨识边界在哪？
- **Q2（预见性退化的安全性）**：如何保证由 RUL 下界驱动的能力包络收窄永远不违反 v9 的九不变式？RUL 估计偏差应转化为保守裕度还是降级排程，才能既安全又不至于过早丧失任务能力？
- **Q3（多时间尺度一致性）**：慢环（健康/维护）与快环（20ms 控制）如何做尺度分离，使慢环故障、GC 停顿或通信滞后不改变快环最坏执行时间与安全语义？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 预见性退化律（Proactive Degradation, PMS）**
维护决策在能力空间而非动作空间进行。健康指数 H_t 与保守 RUL_ε(t) 经查表+迟滞映射为能力包络 C_env(H_t) = (K_max, v_max, τ_max, payload_max, allowed primitives)，且满足单调性：H₁ ≤ H₂ ⇒ C_env(H₁) ⊆ C_env(H₂)。规划器只能在 C_env 内采样；PMS 失效时注入建议中立元（不收窄），退回 v9 反应式退化链。

**P14 力矩残差证书律（Torque-Residual Certificate, TRC）**
以广义动量观测器计算 r_t（避免二阶差分噪声）。接触证书：|r_t| > r_c 连续 n_c 拍 ⇒ 触发 M₀ 硬停；负载/磨损/故障走持续带与相干性判别。阈值随估计负载自适应：r_c = δ_model + 3σ_noise + κ·|τ_load|。TRC 失效时令 r ≡ 0（中立元），碰撞检测退回 v9 的视觉/电流通道。

**P15 尺度分离与共模可观测律（Timescale Separation & Common-Mode Observability）**
三时间尺度契约：快环 20ms（TRC + v9 守卫，只读能力包络的不可变快照）、中环 1s（HSE 更新）、慢环 60s（PMS 排程 + 维护窗口）。慢环超时或陈旧度 > T_stale ⇒ 快环使用预计算的 C_env^⊥；慢环的任何输出都不能进入快环的关键路径。共模：力矩残差与电流力矩估计的差异 d_t = r_t − r_t^I 用于故障可观测性判定；静止保持姿态下增益漂移不可观，必须靠**激励/维护窗口**补足。

## 3. 与基线的接口（如何退化）

- TRC 失效/未标定 ⇒ r ≡ 0（严格中立元），碰撞检测退回 v9 视觉/电流，等价 v9 安全层；
- HSE 失效 ⇒ **非恒等安全元**：H_t 取最后有效值并随陈旧度衰减，T_stale 后强制 C_env^⊥ + 人工维护请求（失败安全，非恒等，单独验证）；
- PMS 失效 ⇒ 建议中立元（不收窄能力），退回 v9 反应式退化链，等价 v9；
- TRM 失效 ⇒ 单传感器模式，收紧 r_c、提高维护窗口频率，能力包络不高于 HSE 建议一档；
- 力矩传感器被判定故障 ⇒ TRC 中立 + HSE 冻结 + C_env^⊥，等价"v9 安全层 + 最保守能力"；
- 以上全部失效 ⇒ 完整退回 MetricVoiceGauge-ACMD v9，再沿 v9→v8→v7→v6 链退化。

## 4. 预期贡献

1. **力矩残差证书**：接触/负载/磨损/故障四分解 + 自适应阈值，把最直接的物理接触通道纳入 M₀，并与 v9 块证书共享同一"证书—中止"语义；
2. **预见性退化框架**：健康指数/RUL 下界 → 单调能力包络 → 契约表排程，使退化从"失效后反应"变成"失效前收窄"，并给出 RUL 偏差→安全裕度的可证转化；
3. **多时间尺度契约**：慢环永不阻塞快环的形式化尺度分离，及"非恒等安全元"的显式建模；
4. **共模失效监控**：力矩/电流/冗余三通道的可观测性条件，暴露单传感器盲区并用维护窗口激励补足；E571–E590 覆盖检测、估计、退化、尺度、共模与端到端。

## 5. 本轮最大风险

**一句话**：力矩传感器既是健康估计的输入，又是碰撞证书的判据；一旦它自身漂移、断线或温漂，共模失效会让 RUL 与力矩证书**同时变乐观**，系统在真正过载/碰撞时"自以为健康"地继续运行——预测性维护把安全性押在一个既参与观测又参与判定、且未被独立冗余覆盖的传感器上。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-TPHM**（Metric Voice Gauge with Torque-augmented Prognostics and Health Management）

> 背景：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮灵感：「预测性维护」×「力矩传感」
> **继承纪律**：MetricVoiceGauge 九不变式（CVC-闭环、SpatialCert、RT-CVC、FaultCert、PrimitiveGraph、严格退化链、OTL、GCT、ER）与 v9 的 AC/MW/ID 全部保留。新组件 TRC/HSE/PMS/TRM 一律为**可选增强**；但与 v9 不同，HSE 的失效语义是**非恒等安全元**（失败安全、能力收窄），必须单独验证，不能声称"等价 v9"。

## 0. 核心 IP 设计

| 编号 | 名称 | 类型 | 关键改进（相对 MetricVoiceGauge-ACMD v9） |
|---|---|---|---|
| IP-340–356 | v9 全部模块（含 AC/MW/ID） | 继承 | 语义不变；能力包络作为 AC 的额外输入门控 K_max/v_max |
| IP-357 | TorqueResidualCertifier 力矩残差证书器 | 新增核心模块 | 广义动量观测器算 r；接触/负载/磨损/故障四分解；\|r\|≤r_c 并入 M₀；超时注入 r≡0 |
| IP-358 | HealthStateEstimator 健康状态估计器 | 新增核心模块 | 摩擦/背隙/增益/热参数递推估计 → 健康指数 H_t 与 RUL 保守下界；中环 1s |
| IP-359 | PredictiveMaintenanceScheduler 预测性维护调度器 | 新增核心模块 | (H,RUL)→单调能力包络 C_env→契约表；维护窗口排程；慢环 60s，仅建议 |
| IP-360 | TorqueRedundancyMonitor 力矩冗余监控器 | 新增核心模块 | 力矩/电流/冗余三通道共模监控 d_t=r−r^I；输出传感器可观测性与故障标志 |

**退化链声明（v10 对 v9 五级的扩展）：**
- Level-0（预见性收窄）：HSE/PMS 正常时，按 C_env(H_t) 收窄能力，系统仍执行任务；不是故障级，但改变可达动作集；
- Level-1：AC 证书失效或信任域破坏 ⇒ K_eff ← 1，逐步执行（v9 不变）；
- Level-2：MW 失效 ⇒ 切换 v9 手写网关（v9 不变）；
- Level-3：ID 失效 ⇒ 全模块 active、归因冻结（v9 不变）；
- Level-4：v8 的 DA/SPR/Cal 任一失效 ⇒ 中立元注入，等价 v7（v9 不变）；
- Level-5：全失效 ⇒ 退回 v9→v8→v7→v6；
- **旁路安全元**：HSE 失效 ⇒ C_env^⊥ + 维护请求（非恒等安全元）；TRC 失效 ⇒ r≡0；TRM 失效 ⇒ 收紧 r_c 且能力不高于 HSE 建议一档。

## 1. 符号体系增量（定义 540–549）

| 符号 | 含义 |
|---|---|
| p = M(q)q̇ | 广义动量 |
| r_t | 力矩残差（动量观测器输出），理想情况下 ≈ τ_ext |
| r_c(τ_load) | 接触阈值：δ_model + 3σ_noise + κ·\|τ_load\| |
| r_t^I = k_t I_t − τ̂_t | 电流力矩估计的独立残差 |
| d_t = r_t − r_t^I | 共模判别差异信号 |
| h_t = (μ_s, μ_v, b, k_g, θ) | 健康状态：库仑摩擦、黏性摩擦、背隙、力矩-电流增益、关节温度 |
| H_t ∈ [0,1] | 健康指数，1 为全新，0 为失效阈 |
| RUL_ε(t) | 剩余寿命的 ε-分位下界（保守，取小分位） |
| C_env(H) | 能力包络 (K_max, v_max, τ_max, payload_max, allowed primitives) |
| C_env^⊥ | 最窄保守包络（失败安全元，非恒等） |
| κ_m^H = (T^scale, D^H, T_stale, C_env^⊥) | 健康契约：时间尺度、截止期、陈旧阈值、降级包络 |
| sig_t = (onset, duration, centroid, coherence) | 残差签名：起始陡度、持续时长、谱质心、与预测力矩相干性 |
| W_maint | 维护窗口（安全位姿下做摩擦/背隙辨识与激励） |

**新增定义 540（力矩残差 TorqueResidual）** 以广义动量观测器避免 q̈ 差分放大噪声：
```
p(t) = M(q)q̇
r(t) = K_O · [ p(t) − ∫_0^t ( τ_meas + Cᵀ(q,q̇)q̇ − g(q) + r(s) ) ds − p(0) ]
```
理想模型下 r → τ_ext；实际分解为 r = τ_ext + e_model + e_fric + e_sensor。所有 M,C,g 使用 v9 已有的辨识参数。

**新增定义 541（力矩证书 TorqueCertificate）** 每拍对每关节计算证书三元组：
```
Tcert_t = ( contact = [ |r_t| > r_c 连续 n_c 拍 ],
            overload = mean_{W_o} |r| ∈ [r_wear, r_c],
            sensor_ok = [ |d_t| < d_max ∨ 激励充分 ] )
```
证书有效 ⇔ contact=false ∧ sensor_ok=true；overload=true 产生累积损伤增量 ΔD 送入 HSE。contact=true 直接触发 M₀ 硬停（升级定义 496/531）。

**新增定义 542（健康状态 HealthState）** h_t=(μ_s,μ_v,b,k_g,θ) 由准静态窗口（|q̇|<v₀, |q̈|<a₀）上的递推最小二乘/EKF 更新：
```
τ_meas,j ≈ g_j(q) + μ_s,j·sgn(q̇_j) + μ_v,j·q̇_j + k_g,j^{-1}·τ_cmd,j
θ̇_j = ( I_j²R_j − (θ_j−θ_amb)/R_th,j ) / C_th,j
```
背隙 b 由方向反转处的 τ–q 迟滞宽度估计；不可观参数保持上一次后验并计入协方差。

**新增定义 543（健康指数 HealthIndex）**
```
H_t = min_j clip( (h_j − h_j^fail) / (h_j^new − h_j^fail), 0, 1 )
```
H 对最差关节取 min（木桶原则），不允许"平均值掩盖单关节失效"。

**新增定义 544（剩余寿命剩余下界 RUL）** 采用带漂移的维纳退化模型 dH = −λ dt + σ dW，首次穿越 H_fail 的剩余时间服从逆高斯；取 ε=0.1 分位：
```
S_t(s) = P(RUL > s | H_t),   RUL_ε(t) = inf{ s : S_t(s) ≤ 1−ε }
```
用 RUL_ε（而非均值）驱动排程，使估计偏差优先转化为保守裕度。

**新增定义 545（能力包络 CapabilityEnvelope）** 单调映射表（带 Schmitt 迟滞，防止边界抖振）：

| H 区间 | K_max | v_max | payload | allowed primitives |
|---|---|---|---|---|
| [0.80,1] | 10 | 1.00 | 1.00 | 全部 |
| [0.50,0.80) | 5 | 0.80 | 0.85 | 除高应力抓取 |
| [0.30,0.50) | 2 | 0.60 | 0.60 | 除高应力/高加速 |
| [0.15,0.30) | 1 | 0.40 | 0.40 | 仅低速搬运 |
| [0,0.15) | 1 | 0.25 | 0.25 | 仅返回维护位；C_env^⊥ |

**新增定义 546（健康契约 HealthContract）** κ_m^H=(T^scale,D^H,T_stale,C_env^⊥)。快环 20ms 只读 C_env 快照；中环 D^H=1s 更新 HSE；慢环 D^H=60s 运行 PMS 与 W_maint。慢环超时或 HSE 陈旧 > T_stale=3s ⇒ 快环切 C_env^⊥。

**新增定义 547（预见性退化级 ProactiveLevel）** 由 (H_t, RUL_ε) 经定义 545 查表得到 Level-0 的收窄动作，并与 v9 的 Level-1..5 组成偏序：C_env^⊥ ≼ C_env(H) ≼ 全能力，且所有 Level-1..5 的退化动作必须落在当前 C_env 内（不得越界放宽）。

**新增定义 548（残差签名分类 ResidualSignature）** sig_t=(onset, duration, centroid, coherence)。判据先验：
- 接触：onset ≥ α（>50 N·m/s）、duration ≤ T_c（<150ms）、centroid 高、coherence 低；
- 负载：duration > T_c、coherence ≥ ρ（与重力/惯性预测相关）、onset 低；
- 磨损：以小时计慢漂移、与 h_t 摩擦参数同向、coherence 中；
- 故障：与 r^I 失相干且不随动作负载缩放（d_t 显著）。
歧义集 A = {慢漂移故障 ∩ 摩擦磨损}：单传感器下不可分，交由 TRM/维护窗口。

**新增定义 549（维护窗口 MaintenanceWindow）** 在 W_maint 内机器人回到安全位姿，执行（i）低速正反向激励以观测背隙/摩擦；（ii）多幅值力矩阶跃以打破"静止保持"的增益盲区；（iii）重标定 r_c。窗口期间任务暂停，但安全不变式照常生效。

## 2. 形式化定义（要点与升级）

**升级定义 496（软证书，v10）**
```
δ_trigger = { σ<τ_safe ∧ γ_grasp valid ∧ Δ_dom<τ_dom ∧ risk_SLAM<τ_SLAM ∧ Ĉ_t valid ∧ Tcert_t valid }
```
六条件同尺度；力矩证书失效与块证书失效同级触发 M₀ 硬检查，无"块内软通过、力矩硬失"空洞。

**升级定义 531（软硬约束衔接）** 任一 Tcert.contact=true ⇒ 立即安全停驻且作废当前动作块（不等块边界）；overload 只累积损伤、不立即停，但若 H 跨阈则按定义 545 收窄。

# IP-357 TorqueResidualCertifier：力矩残差证书器（快环 50Hz）
class TorqueResidualCertifier:
    def __init__(self, model, K_O=40.0, n_c=3, kappa=0.15,
                 delta_model=0.8, sigma_noise=0.1):
        self.mdl = model                     # v9 辨识的 M,C,g
        self.K_O, self.n_c, self.kappa = K_O, n_c, kappa
        self.delta, self.sigma = delta_model, sigma_noise
        self.p = self.r = self.contact_run = 0.0
        self.history = deque(maxlen=32)

    def step(self, q, dq, tau_meas, tau_load_hat, tau_cmd_hat, current):
        # 广义动量观测器（定义 540）
        p = self.mdl.M(q) @ dq
        integ = tau_meas + self.mdl.C(q, dq).T @ dq - self.mdl.g(q) + self.r
        self.r += self.K_O * (p - integ * DT) - self.p
        self.p = p
        r_c = self.delta + 3 * self.sigma + self.kappa * abs(tau_load_hat)

        # 独立电流估计与共模差异（定义 541/360）
        r_I = self.mdl.k_t * current - tau_cmd_hat
        d = self.r - r_I

        contact = abs(self.r) > r_c
        self.contact_run = self.contact_run + 1 if contact else 0
        is_contact = self.contact_run >= self.n_c
        overload = abs(self.r) >= 0.7 * r_c and not is_contact

        self.history.append(self.r)
        sig = self.signature(self.history, tau_load_hat)
        return TorqueCert(contact=is_contact, overload=overload,
                          sensor_ok=abs(d) < D_MAX or self.excited,
                          r=self.r, r_c=r_c, sig=sig, d=d)

class HealthStateEstimator:
    def __init__(self, joints, H_fail=0.15):

        self.P = {j: PriorCov() for j in joints}
        self.H_fail = H_fail

        for j, batch in quasi_static_batch.items():
            if batch.is_excited():                  # 仅激励充分时更新（定义 549）
                self.h[j], self.P[j] = rls_update(self.h[j], self.P[j], batch)
        for j, (theta, I) in thermal_obs.items():
            self.h[j].theta = thermal_step(self.h[j].theta, I, theta)
        self.overload = 0.9 * self.overload + 0.1 * overload_incr
        H = min(clip((self.h[j] - FAIL[j]) / (NEW[j] - FAIL[j]), 0, 1)
                for j in self.h)                    # 定义 543
        RUL = inv_gaussian_quantile(H, self.lam, self.sig, self.H_fail, eps=0.1)
        return H, RUL                              # 定义 544

## 4. 推导

**引理 87（残差接触检测的保守性）** 设模型误差与摩擦失配有界 ‖e_model+e_fric‖ ≤ δ，噪声有界 ‖e_sensor‖ ≤ b_s，则当真实外力矩满足 ‖τ_ext‖ > r_c + δ + b_s 时，动量观测器在收敛后必在 n_c 拍内判 contact。证明：由定义 540 的观测器收敛性 r → τ_ext + e_model + e_fric + e_sensor；三角不等式给出 |r| ≥ ‖τ_ext‖ − δ − b_s > r_c，故连续 n_c 拍超阈。∎

**引理 88（四类源可分离性的边界）** 在定义 548 的特征空间，若接触的 onset ≥ α 且 duration ≤ T_c、负载与预测重力/惯性相干 ≥ ρ、磨损漂移率 ≤ ε 且与摩擦参数同向、传感器故障满足 |d_t| ≥ d_max，则四类两两可分；唯一不可分方向是"慢漂移故障 ≡ 摩擦磨损"（二者都慢、都与 r 同向），单力矩通道下必须借助电流通道或维护窗口激励，否则歧义集 A 非空。∎

**引理 89（预见性退化的安全传递）** 若 H 的估计取保守下界 H_ε ≤ H_true（定义 543 的 min 与 RUL 的 ε-分位共同保证），且 C_env 对 H 单调（定义 545），则任意满足 C_env(H_ε) 的动作/块仍满足 v9 的九不变式在真实健康 H_true 下成立。证明：H_ε ≤ H_true ⇒ C_env(H_ε) ⊆ C_env(H_true)；v9 引理 82–86 保证 C_env(H_true) 内动作的安全性与证书可靠性；子集继承。∎

**引理 90（RUL 偏差→裕度单调性）** 设 RUL 估计的相对误差 |RUL_ε − RUL_true| / RUL_true ≤ ε_R。维护在 RUL_ε ≤ T_MAINT 时触发，则真实剩余寿命至少 max(0, T_MAINT/(1+ε_R) − 0) 且随 ε_R 单调不增；因此偏差表现为"提前维护"而非"漏维护"。证明：由误差界 RUL_true ≥ RUL_ε/(1+ε_R)，在触发点 RUL_true ≥ T_MAINT/(1+ε_R)，单调性显然。∎

**引理 91（尺度分离）** 快环的关键路径只读 C_env 的不可变快照，且 C_env^⊥ 为预计算常量；故慢环的 WCET、GC 停顿、通信延迟均不进入快环最坏执行时间。慢环失联超过 T_stale 时快环切换到 C_env^⊥，额外开销 O(1)。证明：快环无锁、无等待、只读指针交换；分支与 T_stale 比较为常数时间。∎

**引理 92（共模可观测性）** 令故障向量 f 投影到差异测量 d = r − r^I。若 f 在 d 的零空间内（例如静止保持时增益漂移只改变 r 与 r^I 的同一比例且两者用同一标定基准），则 d 不变，故障不可观；充分激励（力矩跨幅变化）使 f 离开零空间后恢复可观。推论：单传感器或共用标定基准时，必须周期进入 W_maint 做多幅值激励；否则 HSE 与 TRC 可被同一漂移同时欺骗。∎

**引理 93（力矩证书与块证书的联合无空洞）** 在 v9 引理 82 的信任域内，若块内每拍的 Tcert_t 都有效，则块证书 Ĉ_t 的几何/力界不被力矩通道推翻；若某拍 Tcert 失效，升级定义 531 立即停驻，故不存在"块证书说安全、力矩说碰撞"却继续执行的区间。∎

## 9. 本轮最大风险

**一句话**：力矩传感器既是健康估计的输入，又是碰撞证书的判据；一旦它自身漂移、断线或温漂，共模失效会让 RUL 与力矩证书**同时变乐观**，系统在真正过载/碰撞时"自以为健康"地继续运行——预测性维护把安全性押在一个既参与观测又参与判定、且未被独立冗余覆盖的传感器上。
