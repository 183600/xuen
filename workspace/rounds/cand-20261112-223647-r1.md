# 第 62 轮（承接第 61 轮「具身语义进化闭环」ESEC；灵感循环第 8 轮；本轮灵感：「域随机化」×「创新点」）

> 第 61 轮用 USR / MEL / DMS / SRT-Dual 把「场景→意图→约束→阻抗→证据」拉进统一语义空间，但它**站在一块外生假设的沙地上**：
> 1. **A67 是一句训练时的咒语**：MEL 的零样本泛化被假定「经域随机化后 sim2real gap ≤ δ」，可训练分布 $p_\xi(\phi_{\text{phys}})$ 一次定死、永不回看现实。真实执行中的「滑移 / 振动 / 力超限」恰恰说明**差距集中在特定物理参数区域**，而离线均匀 DR 对此一无所知。
> 2. **均匀 DR 的均值陷阱**：在宽阔物理域上均匀随机化，会让 MEL 学到「平均摩擦 / 平均刚度」先验——**在最危险的极滑、极脆两端反而最不校准**，并把不确定性压平，使 $U_{\text{epistemic}}$ 系统性乐观。
> 3. **适应 = 遗忘的两难**：若用真实证据在线微调 MEL，会灾难性遗忘既有零样本能力；若不微调，语义先验永远带着同一条 sim2real 鸿沟。
> 4. **创新点的通货膨胀**：每轮新增 8–10 个 IP，多数是既有算子的重新组合，却都被称作「新」。**没有可计算的创新判据，就没有真正的创新管理**——「创新点」本身需要一个形式化定义与审计机制。

## 0. 直觉与动机

**灵感 1（域随机化 → 差距倾斜的域随机化 GADR）**
直觉：域随机化不该是「把整个参数域均匀铺满」，而该是「**把训练火力集中在现实证明仿真出错的地方**」。真实执行是一条免费的「差距探针」：机器人报告滑移，说明真实摩擦低于仿真预测；振动远超预期，说明真实刚度 / 阻尼落在仿真没覆盖的角落。于是把 DR 分布按「仿真惊讶度」做**指数倾斜**：$p_{m+1}(\phi)\propto p_m(\phi)\,e^{\beta\hat G(\phi)}$，让高差距区获得更多采样。像把探照灯从「全景泛光」改成「按失败热力图聚焦」。

**灵感 2（差距场 → 仿真惊讶度地图 S2R-Gap Map）**
直觉：差距不是标量，而是物理参数空间上的**场** $G(\phi)$。我们无法直接测 $L_{\text{real}}$，但能测「仿真能否解释观测」：若在某 $\phi$ 下仿真预测的滑移 / 力曲线与实测偏差大，则 $-\log P_{\text{sim}}(o\mid K,\phi)$ 大，即「仿真惊讶」。用贝叶斯在 $\Phi$ 网格上维护惊讶度后验，得到一张**差距热力图**——它既是 DR 的采样权重，也是安全审计的证据。

**灵感 3（抗遗忘 → 语义不变表征 + 弹性回放 SIRL / ECR）**
直觉：在倾斜后的分布上微调，MEL 会「只记住最近的现实角落」。对策两条腿：① **语义不变表征**——强制同一物理属性在仿真与现实的 USR 嵌入一致（域对抗 + 跨域对比），让学到的不是「某个域的特征」而是「物理本身」；② **弹性回放**——保留覆盖旧场景的语义锚点水库，用 Fisher 加权（EWC）约束重要参数漂移。**可塑性有上限，遗忘有下界。**

**灵感 4（创新点 → 能力空间与创新微积分）**
直觉：「创新」不是形容词，而是**相对已有能力集合的几何关系**。把每个 IP 表示为能力空间中的一个向量（零样本成功率、实时抖动、安全、样本效率、对话效率……），则「是否创新」= 该向量是否落在既有 IP 能力向量**凸包的向下闭包**之外；「创新多少」= 到该可达集的距离。再配一张消融证书，证明增益可因果归因、且不被旧组合吞没。于是「创新点」从口号变成可审计的量。

**灵感 5（三尺度闭环 → MDL-ESEC 与差距探针 VOI）**
直觉：第 61 轮的 SRT-Dual 只有两尺度（语义 10–100Hz、实时 1–10kHz）。域随机化把时间轴拉到**分钟—小时级的元学习尺度**。三尺度共享同一张差距地图：实时流产证据、语义流消费语义、元尺度流更新 DR 分布与 MEL。但探测真实世界有成本，于是用**差距探针 VOI**决定下一个探哪一格：选「后验熵下降最多 / 成本最低」的物理参数区。

## 1. 形式化定义（增量：定义 173–184）

**定义 173（物理参数域与随机化分布）**
物理参数域 $\Phi_{\text{phys}}=\{\phi=(\mu_{\text{fric}},k_{\text{stiff}},\eta_{\text{damp}},\sigma_{\text{brittle}})\in[\mu^-,\mu^+]\times[k^-,k^+]\times[\eta^-,\eta^+]\times[0,1]\}\subset\mathbb{R}^4$ 为紧集。域随机化分布 $p_\xi(\phi)$ 由参数 $\xi$（如 logistic-normal / 高斯 copula 的均值、尺度、相关阵）在 $\Phi_{\text{phys}}$ 上诱导。第 61 轮的 DR 等价于**固定** $\xi=\xi_0$；本轮令 $\xi=\xi_m$ 随元轮次 $m$ 演化。

**定义 174（仿真惊讶差距场与差距地图）**
对一次在指令阻抗 $K$ 下、观测到执行证据 $o$ 的真实执行，定义**仿真惊讶度**
$$G_{\text{surr}}(\phi)=-\log P_{\text{sim}}(o\mid K,\phi)=\mathbb{E}_{o}\big[-\log p_{\text{sim}}(o\mid K,\phi)\big].$$
仿真越解释不了该证据，$G_{\text{surr}}$ 越大。将 $\Phi_{\text{phys}}$ 划分为网格 $\{C_j\}_{j=1}^{M}$，**差距地图** $\mathcal{M}_{\text{gap}}$ 在每个格上维护惊讶度的标量高斯后验 $(\hat G_j,\sigma_j^2)$：
$$\text{更新：}\;\; \frac{1}{\sigma_j^2}\leftarrow\frac{1}{\sigma_j^2}+\frac{w_j}{\beta_{\text{map}}},\qquad \hat G_j\leftarrow\sigma_j^2\Big(\frac{\hat G_j^{(0)}}{(\sigma_j^{(0)})^2}+\frac{w_j\,G_{\text{surr}}(c_j)}{\beta_{\text{map}}}\Big),$$
其中 $w_j=\exp(-\|\phi_{\text{est}}-c_j\|^2/2\sigma_\phi^2)$ 为证据到格心的核归属。差距场 $\hat G(\phi)=\hat G_j$（$\phi\in C_j$）。

**定义 175（差距倾斜域随机化 GADR）**
给定差距场 $\hat G$、基础分布 $p_0$、温度 $\beta>0$，**倾斜目标**为
$$p_\beta^*(\phi)=\frac{p_0(\phi)\,e^{\beta\hat G(\phi)}}{Z_\beta},\qquad Z_\beta=\int p_0(\phi')e^{\beta\hat G(\phi')}d\phi'.$$
在参数族 $\{p_\xi\}$ 内投影（并施加**覆盖下限**防止遗忘与过拟合）：
$$\xi_m=\arg\min_{\xi}\ \mathrm{KL}\big(p_\beta^*\,\|\,p_\xi\big)\quad\text{s.t.}\quad \int_{C_j}p_\xi(\phi)\,d\phi\ge c_{\min}\ \ \forall j,$$
再以步长 $\alpha$ 平滑：$\xi_{m+1}=(1-\alpha)\xi_m+\alpha\,\xi_m^{\text{new}}$。非参数实现直接对覆盖 $\Phi$ 的粒子按权重 $w_j\propto p_0(c_j)e^{\beta\hat G(c_j)}$（数值稳定时减最大指数）重采样，再与均匀分布按 $c_{\min}$ 混合。

**定义 176（语义不变表征学习 SIRL）**
共享语义编码器 $E_{\text{sem}}$，训练损失
$$\mathcal{L}_{\text{SIRL}}=\mathcal{L}_{\text{phys}}+\lambda_c\,\mathcal{L}_{\text{contr}}+\lambda_d\,\mathcal{L}_{\text{dom}},$$
其中 $\mathcal{L}_{\text{phys}}$ 为物理属性监督（仿真有真值 $\phi$，现实用证据弱监督）；$\mathcal{L}_{\text{contr}}$ 为**同 $\phi$ 跨域正样本**的 InfoNCE（正样本对 $=(z_{\text{sim}},z_{\text{real}})$，$\phi$ 由差距地图反演 / 证据支持）；$\mathcal{L}_{\text{dom}}$ 为带梯度反转层（GRL）的域判别交叉熵。目标：域间表征差异 $\mathrm{MMD}(p^{\text{sim}}_{\text{emb}},p^{\text{real}}_{\text{emb}})\le\varepsilon_{\text{dom}}$。

**定义 177（弹性连续回放 ECR）**
维护语义锚点水库 $\mathcal{R}=\{(\phi_i,x_i)\}$，以最远点 / k-center 做空间填充覆盖 $\Phi$。微调损失
$$\mathcal{L}_{\text{ECR}}=\mathcal{L}_{\text{new}}+\frac{\lambda_{\text{ewc}}}{2}\sum_i F_i\,(\theta_i-\theta_i^*)^2+\lambda_r\,\mathcal{L}(\mathcal{R}),$$
其中 $F_i$ 为旧任务的 Fisher 信息，$\theta^*$ 为旧参数。覆盖项 $\mathcal{L}(\mathcal{R})$ 保证旧场景不被倾斜分布挤掉。

**定义 178（能力空间与可达集）**
每个 IP 映射为能力向量 $c(\text{ip})=(c_1,\dots,c_k)\in\mathbb{R}^k$（各轴「越大越好」：零样本成功率、实时抖动倒数、安全裕度、样本效率、对话效率……）。既有能力集 $P=\{c(\text{ip}_i)\}$，其凸包 $H=\mathrm{conv}(P)$。**可达集**（旧组合能免费达到的区域）为向下闭包
$$R(P)=\{x\in\mathbb{R}^k:\ \exists h\in H,\ x\le h\}\quad(\text{逐分量}) .$$

**定义 179（创新度量与创新证书 NC）**
创新度定义为 $c$ 到可达集的距离：
$$\mathrm{nov}(c)=\sqrt{\min_{x\in\mathbb{R}^k,\ h\in H}\ \|c-x\|^2\quad\text{s.t.}\quad x\le h\;(\text{逐分量})}.$$
该问题为**凸 QP**（约束线性、目标凸）；$c\in R(P)$ 时最优值 0（冗余），否则 $\mathrm{nov}>0$（真实帕累托扩展）。**创新证书**
$$\mathrm{NC}(\text{ip})=\big(\mathrm{nov},\ \text{effect}_{95\%},\ \text{attr},\ \text{cost},\ \Delta\text{risk}\big),$$
$$\mathrm{Valid}(\mathrm{NC})\iff \mathrm{nov}\ge\tau_{\text{nov}}\ \wedge\ \operatorname{effect}\ge\delta\ \wedge\ \mathrm{CI}_{95\%}\not\ni0\ \wedge\ \Delta\text{risk}\le0.$$

**定义 180（三尺度闭环 MDL-ESEC）**
系统含三个时间尺度：控制 $\tau_c\sim1$ms（ERTC/EEIS）、语义 $\tau_s\sim10$–100ms（MEL/DMS/USR）、元学习 $\tau_m\sim$ 分钟–小时（GADR/SIRL/ECR）。三者共享状态 $(\text{Anchor},\ \mathcal{M}_{\text{gap}},\ \mathcal{R},\ \text{EV\text{-}buffer})$。元尺度更新对实时尺度**不可见**，除非通过 SRG 并原子切换版本号；定义复合算子
$$\mathrm{MDL\text{-}ESEC}=\mathcal{M}_{\text{meta}}\circ\mathcal{S}_{\text{semantic}}\circ\mathcal{R}_{\text{realtime}}.$$

**定义 181（差距探针 VOI）**
每次元轮次只能做有限次真实探针（预算 $B_{\text{gap}}$）。下一探针格
$$j^*=\arg\max_j\ \frac{\mathbb{E}\big[H(\hat G_j)-H(\hat G_j\mid o)\big]}{\mathrm{cost}_{\text{probe}}(c_j)}\approx\arg\max_j\frac{\tfrac12\log\big(1+\sigma_j^2/\sigma_o^2\big)}{\mathrm{cost}_{\text{probe}}(c_j)},$$
即选「单位成本信息增益最大」的物理参数区。

**定义 182（安全回归守卫 SRG）**
部署任何更新后的 MEL / $\xi$ 前，必须在固定安全基线上通过门控：
$$\text{Pass}\iff \mathrm{ViolationRate}(M_{\text{new}})\le \mathrm{ViolationRate}(M_{\text{old}})+\varepsilon_s\ \wedge\ \bar C_{\text{sem}}(M_{\text{new}})\ge\tau_{\text{csem}}.$$
不通过则**回滚** MEL 参数与本次差距地图更新，保留旧版本并记录审计事件。

**定义 183（IP 登记表与创新剪枝）**
登记表 $\mathcal{I}$ 为带证书的 IP 集合。维护算子
$$\mathrm{Prune}(\mathcal{I})=\{\text{ip}\in\mathcal{I}:\mathrm{NC}(\text{ip}).\mathrm{valid}\ \wedge\ \neg\,\mathrm{redundant}\}\ \cup\ \text{合并同义 IP},$$
凡 $\mathrm{nov}<\tau_{\text{nov}}$ 或 $\mathrm{redundant}$ 的 IP 标记为「组合 / 复述」并合并或退役，防止创新点通货膨胀。

**定义 184（差距-语义联合证书 J_dr_sem）**
扩展第 61 轮的 $J_{\text{sem\_exec}}$：
$$J_{\text{dr\_sem}}=\big(J_{\text{sem\_exec}},\ \mathrm{ver}(\mathcal{M}_{\text{gap}}),\ \mathrm{ver}(\xi),\ \mathrm{hash}(\mathrm{NC}),\ \mathrm{SRG}_{\text{result}},\ \mathrm{nov}\big),$$
$$\mathrm{Valid}(J_{\text{dr\_sem}})\iff \mathrm{Valid}(J_{\text{sem\_exec}})\ \wedge\ \mathrm{SRG}_{\text{pass}}\ \wedge\ \mathrm{ver}(\mathcal{M}_{\text{gap}})\text{ fresh}.$$

### IP-183 GADR（差距倾斜域随机化）

```python
class GapTiltedDR:
    def __init__(self, gap_map, particles, beta=1.0, coverage_floor=0.02, alpha=0.3):
        self.gap = gap_map
        self.particles = particles            # 覆盖 Phi 的物理参数粒子
        self.beta = beta
        self.coverage_floor = coverage_floor  # 每格最低采样占比，防遗忘/过拟合
        self.alpha = alpha

    def tilted_weights(self):
        g = self.gap.field()                  # [M] 每个粒子的差距估计
        w = np.exp(self.beta * (g - g.max())) # 数值稳定的指数倾斜
        w = w / w.sum()
        u = np.ones_like(w) / len(w)          # 均匀兜底
        w = (1 - self.coverage_floor) * w + self.coverage_floor * u
        return w

    def resample(self, n_batch):
        w = self.tilted_weights()
        idx = np.random.choice(len(self.particles), size=n_batch, p=w)
        return self.particles[idx]

    def train_mel(self, sim, mel, reservoir, fisher, theta_star, n_batch=256):
        phis = self.resample(n_batch)
        loss = train_with_sirl_ecr(mel, sim, phis, reservoir, fisher, theta_star)
        return loss
```

### IP-184 S2R-Gap Map（仿真惊讶差距地图）

```python
class Sim2RealGapMap:
    def __init__(self, cells, prior_mean=0.5, prior_var=1.0, beta_map=1.0,
                 sigma_phi=0.15):
        self.cells = cells                       # [M, 4] 格心
        self.mu = np.full(len(cells), prior_mean)
        self.var = np.full(len(cells), prior_var)
        self.beta_map, self.sigma_phi = beta_map, sigma_phi
        self.version = 0

    def _surprise(self, evidence, K, phi):
        return -self.sim.log_likelihood(evidence, K, phi)

    def update(self, K, phi_est, evidence):
        for j, c in enumerate(self.cells):
            w = np.exp(-np.linalg.norm(c - phi_est) ** 2 / (2 * self.sigma_phi ** 2))
            if w < 1e-3:
                continue
            s = self._surprise(evidence, K, c)
            prec0, prec1 = 1.0 / self.var[j], w / self.beta_map
            self.mu[j] = (self.mu[j] * prec0 + s * prec1) / (prec0 + prec1)
            self.var[j] = 1.0 / (prec0 + prec1)
        self.version += 1
        return self.mu

    def field(self):
        return self.mu.copy()

    def entropy(self):
        return 0.5 * np.sum(np.log(2 * np.pi * np.e * self.var))
```

### IP-185/186 SIRL + ECR（语义不变表征 + 弹性回放）

```python
def train_with_sirl_ecr(mel, sim, phis, reservoir, fisher, theta_star,
                        lam_cons=0.5, lam_ewc=1e3, lam_replay=1.0,
                        lam_r=1.0, tau=0.1):
    # 仿真批（有物理真值）+ 现实批（证据弱监督）
    batch_sim = sim.render(phis)
    batch_real = reservoir.recent_real()
    l_phys = mel.phys_loss(batch_sim) + mel.phys_weak_loss(batch_real)

    # 语义不变表征：同 phi 跨域正样本 + 梯度反转域判别
    z_sim = mel.enc_sem(batch_sim.x)
    z_real = mel.enc_sem(batch_real.x)
    l_cons = contrastive_infonce(z_sim, z_real, positives='same_phi', tau=tau)
    l_dom = grl_domain_ce(z_sim, z_real)

    # 弹性回放 + EWC 抗遗忘
    l_replay = mel.task_loss(reservoir.space_filling_sample())
    l_ewc = 0.5 * lam_ewc * sum(
        (fisher[k] * (mel.theta[k] - theta_star[k]) ** 2).sum()
        for k in mel.theta)

    loss = l_phys + lam_cons * (l_cons + l_dom) + lam_replay * l_replay + l_ewc
    mel.optimizer.zero_grad()
    loss.backward()
    mel.optimizer.step()
    return loss.item()
```

### IP-187/188 创新微积分与创新证书

```python
class NoveltyCalculus:
    def __init__(self, prior_caps, tau_nov=0.05):
        self.H = ConvexHull(prior_caps)     # 既有能力凸包
        self.tau_nov = tau_nov

    def novelty(self, c):
        # min_{x,h} ||c-x||^2 s.t. x <= h, h in conv(P)  —— 一个凸 QP
        res = solve_qp_minimize_to_downward_hull(c, self.H)
        return float(np.sqrt(max(res.value, 0.0)))

    def certify(self, ip, c, ablation, risk_delta, delta=0.02):
        nov = self.novelty(c)
        effect, lo, hi = ablation.effect_size(ci=0.95)
        valid = (nov >= self.tau_nov and effect >= delta
                 and lo > 0 and risk_delta <= 0)
        return NoveltyCert(ip=ip, nov=nov, effect=effect, ci=(lo, hi),
                           risk_delta=risk_delta, valid=valid,
                           redundant=(nov == 0.0))


def prune_registry(registry, calculus):
    kept, merged = [], []
    for ip in sorted(registry, key=lambda z: z.nov, reverse=True):
        if ip.redundant or ip.nov < calculus.tau_nov:
            merged.append(ip)              # 组合/复述 -> 合并或退役
        else:
            kept.append(ip)
    return kept, merged
```

### IP-189 MDL-ESEC（三尺度闭环）

```python
def meta_epoch(state, sim, real_exec, gap_map, dr, mel, srg, calculus):
    # ① 差距探针：VOI 选格 -> 真实探测 -> 更新差距地图
    j = voi_probe(gap_map, state.budget)          # 取整为格索引
    evidence, K, phi_est = real_exec.probe(gap_map.cells[j])
    gap_map.update(K, phi_est, evidence)
    state.reservoir.push(phi_est, evidence.features)

    # ② 差距倾斜 DR + SIRL/ECR 训练
    dr.train_mel(sim, mel, state.reservoir, state.fisher, state.theta_star)

    # ③ 安全回归守卫：不过则回滚（MEL + 差距地图）
    if not srg.pass_gate(mel, state.safety_bench):
        mel.rollback()
        gap_map.rollback_update()
        return state

    # ④ 原子发布新 MEL 版本；实时/语义流在下一空窗读取新锚点
    state.publish_new_mel(mel)
    state.registry = prune_registry(state.registry, calculus)  # 顺带剪枝
    return state
```

### IP-190/191 SRG + VOI-Probe

```python
class SafetyRegressionGuard:
    def __init__(self, mel_old, eps_s=0.0, tau_csem=0.9):
        self.mel_old, self.eps_s, self.tau_csem = mel_old, eps_s, tau_csem

    def pass_gate(self, mel_new, bench):
        v_new = bench.violation_rate(mel_new)
        v_old = bench.violation_rate(self.mel_old)
        csem = bench.mean_semantic_consistency(mel_new)
        return v_new <= v_old + self.eps_s and csem >= self.tau_csem


def voi_probe(gap_map, budget, obs_var=1.0):
    best, best_score = 0, -float('inf')
    for j in range(len(gap_map.cells)):
        info_gain = 0.5 * np.log1p(gap_map.var[j] / obs_var)
        score = info_gain / budget.probe_cost(gap_map.cells[j])
        if score > best_score:
            best, best_score = j, score
    return best
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| S2R-Gap Map | O(M·d_φ) / 证据 | O(M) | 差距后验随探针数一致收敛（A72） |
| GADR | O(M + n_batch) 重采样 | O(n_batch) | 高差距区采样质量 ≥ c_min 以上按 $e^{\beta\hat G}$ 倾斜 |

## 2. 关键推导

**(a) 指数倾斜的由来。** 目标为在高差距区多采样同时保留熵：
$$\max_{p}\ \mathbb{E}_{p}[\hat G]+\beta H(p)\quad\text{s.t.}\ p\ll p_0,\ \textstyle\int p=1.$$
拉格朗日乘子 $\Rightarrow\ \delta\big(\int p\hat G-\beta\int p\log(p/p_0)-(\lambda-1)\int p\big)=0\ \Rightarrow\ \hat G-\beta(\log(p/p_0)+1)-(\lambda-1)=0$，解得
$$p^*(\phi)=\frac{p_0(\phi)e^{\beta\hat G(\phi)}}{Z_\beta}.$$
即「高差距 → 高权重」，$\beta\to0$ 退化为原分布，$\beta\to\infty$ 退化为 argmax 差距（需覆盖下限约束兜底）。

**(b) 遗忘的二次上界（EWC / ECR）。** 在旧最优点 $\theta^*$ 附近对旧损失做二阶展开 $L_{\text{old}}(\theta)\approx L_{\text{old}}(\theta^*)+\frac12\sum_iF_i(\theta_i-\theta_i^*)^2$。加入 $\frac{\lambda_{\text{ewc}}}{2}\sum_iF_i(\theta_i-\theta_i^*)^2$ 后，新旧联合目标的最优点满足 $\Delta\theta_i\propto\frac{1}{F_i+\lambda_{\text{ewc}}}$，故高 Fisher（重要）参数几乎不动，旧损失增量 $\le\frac12\sum_i\frac{F_i}{F_i+\lambda_{\text{ewc}}}\cdot O(\Delta^2)$，随 $\lambda_{\text{ewc}}$ 增大而 $\to0$。

**(c) 创新度的凸性。** $\mathrm{nov}(c)^2=\min_{x,h}\|c-x\|^2$ s.t. $h\in H,\ x-h\le0$。目标关于 $(x,h)$ 强凸，约束（$h$ 属于凸包、逐分量线性不等式）均为凸，故为单个凸 QP，全局最优可求；且 $c\in R(P)$ 时取 $x=c$ 可行 ⇒ 最优值 0。geometry：nov 度量的是「既有 IP 凸组合向下闭包之外的最小外扩距离」。

**(d) 覆盖-聚焦权衡。** 倾斜权重与均匀分布按 $c_{\min}$ 混合后，任一格采样占比 $\ge c_{\min}$，保证 ECR 覆盖项 $\mathcal{L}(\mathcal{R})$ 始终有正梯度，从结构上排除了「倾斜分布把旧场景采样概率压到 0」的遗忘死区。

### IP-183 GADR

```python
class GapTiltedDR:
    def __init__(self, gap_map, particles, beta=1.0, coverage_floor=0.02):
        self.gap, self.particles = gap_map, particles
        self.beta, self.coverage_floor = beta, coverage_floor

    def tilted_weights(self):
        g = self.gap.field()
        w = np.exp(self.beta * (g - g.max())); w /= w.sum()
        u = np.ones_like(w) / len(w)
        return (1 - self.coverage_floor) * w + self.coverage_floor * u

    def resample(self, n_batch):
        return np.random.choice(self.particles, size=n_batch, p=self.tilted_weights())
```

### IP-184 S2R-Gap Map

```python
class Sim2RealGapMap:
    def __init__(self, cells, prior_mean=0.5, prior_var=1.0, beta_map=1.0, sigma_phi=0.15):
        self.cells = cells
        self.mu = np.full(len(cells), prior_mean)
        self.var = np.full(len(cells), prior_var)
        self.beta_map, self.sigma_phi, self.version = beta_map, sigma_phi, 0
        self._backup = None

    def update(self, K, phi_est, evidence):
        self._backup = (self.mu.copy(), self.var.copy())
        for j, c in enumerate(self.cells):
            w = np.exp(-np.linalg.norm(c - phi_est) ** 2 / (2 * self.sigma_phi ** 2))
            if w < 1e-3: continue
            s = -self.sim.log_likelihood(evidence, K, c)
            p0, p1 = 1.0 / self.var[j], w / self.beta_map
            self.mu[j] = (self.mu[j] * p0 + s * p1) / (p0 + p1)
            self.var[j] = 1.0 / (p0 + p1)
        self.version += 1
        return self.mu

    def rollback_update(self):
        if self._backup is not None:
            self.mu, self.var = self._backup

    def field(self): return self.mu.copy()
```

```python
def train_with_sirl_ecr(mel, sim, phis, reservoir, fisher, theta_star,
                        lam_cons=0.5, lam_ewc=1e3, lam_replay=1.0, tau=0.1):

    l_phys = mel.phys_loss(b_sim) + mel.phys_weak_loss(b_real)
    z_sim, z_real = mel.enc_sem(b_sim.x), mel.enc_sem(b_real.x)
    l_cons = contrastive_infonce(z_sim, z_real, positives='same_phi', tau=tau)
    l_dom = grl_domain_ce(z_sim, z_real)
    l_replay = mel.task_loss(reservoir.space_filling_sample())
    l_ewc = 0.5 * lam_ewc * sum((fisher[k] * (mel.theta[k] - theta_star[k]) ** 2).sum()
                                for k in mel.theta)
    loss = l_phys + lam_cons * (l_cons + l_dom) + lam_replay * l_replay + l_ewc
    mel.optimizer.zero_grad(); loss.backward(); mel.optimizer.step()
    return loss.item()
```

```python
class NoveltyCalculus:
    def __init__(self, prior_caps, tau_nov=0.05):
        self.H, self.tau_nov = ConvexHull(prior_caps), tau_nov

    def novelty(self, c):
        return float(np.sqrt(max(solve_qp_to_downward_hull(c, self.H).value, 0.0)))

    def certify(self, ip, c, ablation, risk_delta, delta=0.02):
        nov = self.novelty(c)
        effect, lo, hi = ablation.effect_size(ci=0.95)
        valid = nov >= self.tau_nov and effect >= delta and lo > 0 and risk_delta <= 0
        return NoveltyCert(ip, nov, effect, (lo, hi), risk_delta, valid, redundant=(nov == 0.0))

def prune_registry(registry, calculus):
    kept, merged = [], []
    for ip in sorted(registry, key=lambda z: z.nov, reverse=True):
        (merged if (ip.redundant or ip.nov < calculus.tau_nov) else kept).append(ip)
    return kept, merged
```
