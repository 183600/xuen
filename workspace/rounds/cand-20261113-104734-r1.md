# 第 67 轮（承接第 66 轮「RAS 情绪驱动闭环控制」IP-224~233；灵感循环第 4 轮；本轮灵感：「状态机」×「全身控制」）

> 第 66 轮 RAS 把闭环从「被动故障响应」推进到「主动意图感知」，用面部表情捕获风险态度，用 λ_risk 缩放控制量。但它仍隐含一个致命的结构假设：**安全域是单一的、连续的、与任务阶段无关的**。λ_risk 只是乘在同一条控制律上的标量。真实全身控制（WBC）并非如此：机器人在「站立→下蹲→抓取→支撑转移→恢复」等**离散模式**之间跳变；同一故障在不同模式下的严重性天差地别（失去足底接触，坐着时无所谓，站立时是灾难）。RAS 的连续缩放对「模式切换」完全失明——它算得出「该收多少」，却不知道「现在处在哪个模式、下一步会跳到哪个模式」。
>
> 本轮命题：
>
> **用一个离散-连续混合状态机（Hybrid Automaton）来「驯化」全身控制：把模式 q、守卫 G、重置 R 显式建模；把故障归因与认证前缀都条件化到模式信念 b(q) 上；认证前缀必须对「前缀窗口内所有守卫可达的模式」成立，而不是只对当前模式成立。**
>
> 一句话：VISTA 问「哪层坏了」，RAS 问「谁该控制、控制多少」，HYDRA 问「**现在处于哪个模式，接下来可能跳到哪里，跳过去还安全吗**」。

## 0. 直觉与动机

**灵感 1（状态机 → 模式相对安全）**
直觉：「安全」从来不是状态 x 的绝对属性，而是**模式相对的**——(x, q) 才构成完整的安全判据。同一 CoM 高度，在 `stand` 模式下贴着支撑多边形边缘就是危险，在 `squat` 模式下却是正常。把模式显式化，安全域就从一张 Ω 变成一族 {Ω_q}，故障严重性也从 S(H) 升级为 S(H, q)。这是本轮所有形式化的地基。

**灵感 2（全身控制 → 接触模式与分层 QP）**
直觉：WBC 的每种任务阶段本质是一个三元组：**接触集 C_q（脚/手/座面谁在接触）、任务优先级 ≺_q、约束集 Σ_q**。这正是状态机的状态标签。模式内用分层 QP（平衡 → 任务跟踪 → 姿态 → 力矩正则）连续求解；模式之间靠接触建立/断开触发跳变。于是「全身控制」天然就是一个混合系统，只是过去把「模式」当成人工写死的 if-else，没有把它当可推理、可认证的一等公民。

**灵感 3（状态机 × 全身控制 → 守卫鲁棒性与模式不变前缀）**
直觉：RAS/VISTA 的认证前缀假设执行期间模式不变。但在 WBC 中，动作块执行时机器人可能已经踩空、手掌接触、或座面滑移——**模式变了，旧证书当场失效**。补法是：给每个守卫定义有符号裕度 m_g(x)，认证前缀必须保证「在整个前缀窗口内不越过任何守卫」（守卫鲁棒性），或对「所有守卫可达模式」同时满足 Ω_{q'}。这就是 **MIC（Mode-Invariant Certified prefix）**，比 VISTA/RAS 的前缀严格一档。

**灵感 4（RAS 升级 → 风险平移守卫）**
直觉：RAS 的 λ_risk 乘在控制量上，是「事后收紧」。更符合控制直觉的做法是让它**平移守卫**：`G^{risk} = {x : m_g(x) ≤ m_min + β·R_emotion}`。风险越高，系统越早从 `stand` 跳进 `squat/brace/safe`，而不是等到贴近边界才靠缩放救场。这把「连续风险」翻译成「离散模式切换的时刻」，是 RAS 与状态机真正咬合的地方。

**灵感 5（新的故障维度 → 模式混淆故障）**
直觉：模式不可直接观测，需要从本体感受/接触残差推断模式信念 b(q)。危险在于**模式混淆**：足底打滑的残差分布可能与「有意迈步」几乎同分布。此时归因器会把「真实故障 H_slip」误读成「合法模式切换 q_stand→q_step」，从而**不降级、反而放行**。必须以主动消歧（微探针动作、显式切换假设检验）把两者分开，并把别名集 A(H) 纳入证书。

**灵感 6（合流 → HYDRA：混合离散-连续风险自适应全身控制）**
`HYDRA = (Q, q0, F, G, R, B, Π_WBC, MIC, J_H, ERG-RAS)`：
1. **Q / F**：离散模式集与模式内连续流（WBC 分层 QP）；
2. **G / R**：守卫谓词与重置映射（接触建立/断开、滑移、支撑转移）；
3. **B**：模式信念滤波器（IMM/粒子混合滤波），把模式也变成后验对象；
4. **Π_WBC**：模式参数化的分层 QP；
5. **MIC**：模式不变认证前缀（守卫可达性 + 前缀窗口内的 Ω 不变性）；
6. **J_H**：混合证书（在 J_RAS 上增 b_t、q_t、guard_margin_min、mode_reachability_witness）；
7. **ERG-RAS**：沿用第 66 轮的情绪网关与风险缩放，但输出改为**守卫平移量**。

## 1. 形式化定义（增量：定义 251–266）

- **定义 251（HYDRA 总览）**：HYDRA = (Q, q0, F, G, R, B, Π_WBC, MIC, J_H, ERG-RAS)。定位：把 RAS 的「连续风险闭环」升级为「离散-连续混合闭环」。不变式：模式信念更新、守卫可达性分析、混合证书只在语义流；实时流只做模式证据采集、守卫裕度计算、认证前缀早停，零学习写操作。
- **定义 252（WBC 模式）**：一个全身控制模式 `q = (C_q, ≺_q, Σ_q, E_q)`，其中 `C_q ⊆ {L_foot, R_foot, L_hand, R_hand, seat}` 为接触集，`≺_q` 为任务优先级序，`Σ_q` 为激活约束集（摩擦锥、关节限位、力矩上界），`E_q ⊆ E` 为该模式允许的故障-情绪假设子集。参考模式集 `Q = {Q_stand, Q_squat, Q_reach, Q_brace, Q_transfer, Q_recover, Q_safe}`。
- **定义 253（模式流与不变式）**：模式 q 内连续状态 `x ∈ X_q` 满足 `ẋ = f_q(x, τ_cmd)`，`τ_cmd = Π_WBC(q, x, task)`；模式流仅定义在不变式 `Inv_q ⊆ X_q` 内，`Inv_q = {x : 全部激活约束 Σ_q 可行 ∧ CoM(x) ∈ Conv(C_q)}`。
- **定义 254（守卫与重置）**：模式跳变 `q --G_{q→q'}--> q'`，守卫 `G_{q→q'} ⊆ X_q` 为谓词（如「足底法向力 < ε 持续 20ms」），重置映射 `R_{q→q'} : X_q → X_{q'}` 重置接触相关状态。语义：当 x 进入 G 且 Inv_q 仍成立时发生跳变；若 Inv_q 先被破坏再进入 G，则为**非法逃逸**，必须由安全模式兜底。
- **定义 255（模式信念）**：模式不可直接观测，由本体感受与接触残差 ρ 推断。`b_{t+1}(q) ∝ Σ_{q'} b_t(q')·P(q | q')·p(ρ_t | q)`，`P(q|q')` 由守卫先验给出（IMM 转移矩阵）。信念集中度 `κ_mode = 1 - H(b_t)/log|Q|`。
- **定义 256（模式条件故障后验）**：`P(H, E | ρ, face, q) ∝ p(ρ | H, q)·p(face | E)·P(H | q)·P(E | H, q)`；对模式信念边缘化得 `P(H,E | ρ, face) = Σ_q b_t(q)·P(H,E | ρ, face, q)`。严重性升级为模式相对量 `S(H, q)`。
- **定义 257（模式相对安全域）**：`Ω_q = {x : Π_WBC(q, x) 可行 ∧ x ∈ Inv_q ∧ S(H,q) ≤ S_max}`。安全不再是对 x 的单一谓词，而是对 (x, q) 的族谓词 {Ω_q}。
- **定义 258（守卫鲁棒裕度）**：对守卫 `G_{q→q'}` 定义有符号距离 `m_g(x) = dist(x, ∂G_{q→q'})`（正=安全侧，负=已越界）。认证要求 `m_g(x) ≥ m_min`。
- **定义 259（模式不变认证前缀 MIC）**：`k*_MIC = max k`，使得对当前模式 q_t、其守卫可达集 `Reach_k(q_t) = {q' : ∃ 长度 ≤ k 的模式路径 q_t ⇝ q'}`、以及 top-(H,E) 联合假设，前缀 `A[:k]` 满足：`∀s ≤ k, ∀q' ∈ Reach_k(q_t): x_{t+s} ∈ Ω_{q'} 且 m_g(x_{t+s}) ≥ m_min`。MIC 严格强于 VISTA 的 k_VISTA 与 RAS 的 k*RAS。
- **定义 260（风险平移守卫）**：`G^{risk}_{q→q'} = {x : m_g(x) ≤ m_min + β_risk·R_emotion + β_mode·(1 - κ_mode)}`。风险越高或模式越不确定，越早触发保守切换。`R_emotion` 沿用定义 235。
- **定义 261（全身层级 QP）**：`Π_WBC(q, x, task) = argmin_{τ} Σ_l w_l ‖J_l(q)τ - b_l‖²`，按 ≺_q 词典序求解：1) 平衡/接触（CoM、摩擦锥）；2) 任务跟踪；3) 姿态正则；4) 力矩最小。低优先级在上一级零空间内求解。
- **定义 262（安全模式与吸引性）**：`Q_safe` 为宽支撑、低 CoM、双臂支撑的保守模式；要求混合自动机满足**有界吸引性**：`∀q ∈ Q, ∃ 路径 q ⇝ Q_safe，长度 ≤ N_safe`，且沿路径的守卫在最大扰动下可达。
- **定义 263（模式混淆故障与主动消歧）**：对故障 H，定义别名集 `A(H) = {q' : D_KL(p(ρ|H,q) ‖ p(ρ|q→q')) < τ_alias}`。若 `A(H) ≠ ∅`，触发主动消歧：施加微探针动作 `u_probe`（小幅重心转移/轻触），使 `p(ρ|H,q)` 与 `p(ρ|q→q')` 的 KL 距离扩大；消歧成功判据 `D_KL > τ_alias + γ_d`。
- **定义 264（J_H 混合证书）**：`J_H = (J_RAS, b_t, q_t, κ_mode, guard_margin_min, mode_reachability_witness, alias_set, hydra_ver)`。`Valid(J_H) ⇔ Valid(J_RAS) ∧ κ_mode ≥ 0.6 ∧ guard_margin_min ≥ m_min ∧ (A(H) = ∅ ∨ 已消歧) ∧ Q_safe ∈ Reach_{N_safe}(q_t)`。
- **定义 265（模式条件可辨识性）**：混合签名 `S_HYDRA = diag(S_H, S_E, S_Q)`，`κ_HYDRA = min(κ_fi, κ_ri, κ_mode)`。副作用：模式切换会激发新的残差方向（天然「自然实验」），通常**提高**条件可辨识性；但模式混淆会制造别名，必须靠主动消歧补回。
- **定义 266（模式调度与不可逆视界）**：前缀窗口内的模式调度 `σ = q_{t:t+m_H}`；不可逆视界 `m_H = min(m_VISTA, m_emotion, m_mode)`，其中 `m_mode` 为「从当前模式出发、守卫在无干预下不可逆的最短步数」。`k*_MIC ≤ m_H`。

# HYDRA：离散-连续混合状态机驯化的全身控制
class HydraModeBelief:
    def __init__(self, Q, trans_prior):
        self.Q, self.T = Q, trans_prior       # T[q][q'] = P(q|q')
        self.b = {q: 1.0 / len(Q) for q in Q}

    def update(self, rho):
        pred = {q: sum(self.b[p] * self.T[p][q] for p in self.Q) for q in self.Q}
        post = {q: pred[q] * likelihood(rho, q) for q in self.Q}
        z = sum(post.values()) + 1e-12
        self.b = {q: v / z for q, v in post.items()}
        return self.b

    def concentration(self):
        H = -sum(p * log(p + 1e-12) for p in self.b.values())
        return 1 - H / log(len(self.Q))


class HydraModeConditionedAttribution:
    def synthesize(self, rho, face_gate, b, q_now):
        joint = {}
        for q in self.Q:
            if b[q] < 1e-3:
                continue
            post_H = self.fir.attribute(rho, mode=q)     # 模式条件先验 P(H|q)
            post_E = self.emotion_posterior(face_gate, q) # P(E|H,q)
            for h, ph in post_H.items():
                for e, pe in post_E.items():
                    joint[(q, h, e)] = b[q] * ph * pe
        # 模式混淆检测：别名集非空则触发主动消歧
        alias = self.detect_alias(joint, rho, q_now)
        if alias:
            self.request_active_disambiguation(alias)
        return normalize(joint), alias


class ModeInvariantCertificate:
    def __init__(self, guards, m_min=0.05, v_max=2.0, dt=0.02):
        self.guards, self.m_min, self.v_max, self.dt = guards, m_min, v_max, dt

    def reachable_modes(self, q, k):
        # 守卫可达集：BFS 深度 k
        seen, frontier = {q}, {q}
        for _ in range(k):
            nxt = set()
            for p in frontier:
                nxt |= {q2 for (q1, q2) in self.guards if q1 == p}
            frontier = nxt - seen
            seen |= frontier
        return seen

    def certified_prefix_mic(self, A, q_now, joint_post):
        top = sorted(joint_post.items(), key=lambda x: x[1], reverse=True)[:3]
        k_best = 0
        for k in range(1, len(A) + 1):
            modes = self.reachable_modes(q_now, k)
            ok = True
            for s in range(k):
                x_pred = self.predict_state(A[s])
                for q2 in modes:
                    if not self.in_safe_set(x_pred, q2):
                        ok = False
                        break
                    if not self.guard_robust(x_pred, q2, k - s):
                        ok = False
                        break
                if not ok:
                    break
            if not ok:
                break
            # 模式不变性还要求：所有 top 假设在所有可达模式下安全
            if all(self.severity_ok(h, q2, p) for (q2, h, e), p in top
                   for q2 in modes):
                k_best = k
        return k_best

    def guard_robust(self, x, q, remaining):
        # 引理 11：m_g(x) ≥ v_max·dt·remaining + m_min ⇒ 前缀内不越界
        return self.min_guard_margin(x, q) >= self.v_max * self.dt * remaining + self.m_min


class RiskShiftedGuard:
    def __init__(self, beta_risk=0.25, beta_mode=0.15, m_min=0.05):
        self.beta_risk, self.beta_mode, self.m_min = beta_risk, beta_mode, m_min

    def should_switch(self, x, q_to, R_emotion, kappa_mode):
        # 定义 260：风险越高/模式越不确定，越早切保守模式
        thr = self.m_min + self.beta_risk * R_emotion \
              + self.beta_mode * (1 - kappa_mode)
        return self.min_guard_margin(x, q_to) <= thr


def HYDRA_round(M, obs):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    M.lsf.update_geometry(P_cloud)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))
    y_vis = M.f_vis(img, depth, flow)

    # 1) 模式证据采集 + 模式信念
    rho_contact = M.contact_residual(tactile, W_meas)
    b = M.mode_belief.update(rho_contact)
    q_now = max(b, key=b.get)
    kappa_mode = M.mode_belief.concentration()

    # 2) 情绪网关（沿用 RAS）→ 风险
    face_gate = M.er.recognize(img)
    R_emotion = face_gate['risk']

    # 3) 模式条件故障-情绪联合归因 + 模式混淆消歧
    rho = M.vista.fir.signature(M.vista.stage.split(M.vista.residual_log))
    joint_post, alias = M.mcfa.synthesize(rho, face_gate, b, q_now)

    # 4) 风险平移守卫：必要时提前切保守模式
    if M.risk_guard.should_switch(x_prime, q_now, R_emotion, kappa_mode) \
            and Q_safe in M.reachable(q_now, M.N_safe):
        q_now = M.transition_to_safe(q_now)

    # 5) 模式不变认证前缀
    A = M.wbc.propose_chunks(x_prime, q_now)
    m_H = min(M.vista.m, M.er.max_m_emotion, M.mode_horizon(q_now))
    k_mic = M.mic.certified_prefix_mic(A, q_now, joint_post)
    k_mic = min(k_mic, m_H)

    # 6) 模式参数化全身 QP 执行
    tau_cmd = M.wbc.hierarchical_qp(q_now, x_prime, A[:k_mic])
    tau_cmd = M.ras.shaping(tau_cmd, joint_post)   # 沿用 ERS

    return {'q': q_now, 'b': b, 'kappa_mode': kappa_mode, 'k_mic': k_mic,
            'joint_post': joint_post, 'alias': alias, 'tau_cmd': tau_cmd,
            'J_H': M.build_hybrid_certificate(q_now, k_mic, joint_post, b,
                                              face_gate, alias)}

## 3. 推导

**引理 11（守卫鲁棒性 ⇒ 前缀模式不变）** 设模式流速度有界 `‖ẋ‖ ≤ v_max`，离散步长 `dt`，前缀剩余步数 r。若 `m_g(x_t) ≥ v_max·dt·r + m_min`，则对任意 `s ≤ r` 有 `m_g(x_{t+s}) ≥ m_min > 0`，即前缀执行期间不越过该守卫，模式保持为 q。证明：三角不等式逐点累加 `m_g(x_{t+s}) ≥ m_g(x_t) - s·v_max·dt`。这是 MIC 与 VISTA/RAS 前缀的本质差别——后者只证「当前模式内安全」，不证「不会被意外推出当前模式」。

**引理 12（风险平移守卫的单调保守性）** 定义 260 的 `G^{risk}` 阈值随 `R_emotion` 与 `(1-κ_mode)` 单调上升。故风险上升或模式信念发散时，切换发生的状态点到守卫边界的距离单调增大，即**更早**进入保守模式。推论：安全模式可达时间 `T_reach(Q_safe)` 关于 `R_emotion` 非增。这给出了「情绪越紧张、机器人越早蹲防」的可证明版本。

**引理 13（主动消歧的别名抑制）** 设消歧探针 `u_probe` 使 `D_KL(p(ρ|H,q) ‖ p(ρ|q→q'))` 增加 Δ_d ≥ γ_d，则模式混淆导致的错误归因概率按 `exp(-γ_d)` 因子衰减。前提是探针动作本身在所有可达模式的安全域内（由 MIC 保证）。

**定理 11（HYDRA 端到端模式相对安全）** 在定义 259/262 与引理 11–13 下，执行前缀满足
`P(∀s ≤ k*_MIC : x_{t+s} ∈ Ω_{q_{t+s}}) ≥ 1 - (α_chunk + δ_fi + α_emotion + α_mode + δ_flow)`，
其中 `α_mode` 为模式信念误差，`δ_flow` 为速度界失效概率。即：安全保证从「当前模式的一张 Ω」升级为「前缀窗口内每个实际到达模式的 Ω_{q'}」。

**定理 12（跨模式无误放宽）** 若存在守卫可达模式 `q' ∈ Reach_k(q_t)` 与假设 (H,E) 使得 `S(H, q') > S_max`，则 `J_H` 不可能 Valid，无论 H 在当前模式 q_t 下多么良性。形式化：`Valid(J_H) ⇒ ∀q' ∈ Reach_k(q_t): S(H,q') ≤ S_max`。这堵死了 RAS 最危险的失效模式——「当前模式看着安全，就放行」，而在下一个模式里同一条故障是致命的。

**定理 13（模式条件可辨识性不减）** 当模式切换充分激发新残差方向且无混淆时，`κ_HYDRA = min(κ_fi, κ_ri, κ_mode) ≥ min(κ_fi, κ_ri)`；若存在混淆，则仅在主动消歧成功的子集上恢复该下界，未消歧时必须退回 `Q_safe`。

## 6. 本轮最大风险

**一句话**：HYDRA 的全部保证都建立在「混合自动机是封闭的」这一假设上——模式集 Q、守卫 G、重置 R 由人工或有限数据给定，若真实系统逃逸到未建模模式（新接触点、未预料的滑移、软地面下陷），模式不变证书会**真空成立**（vacuously true），而 HYDRA 因为「有状态机背书」会比 RAS 更自信地放行，形成最危险的「模式逃逸」——这是本轮所有理论依赖的核心假设：**模式图覆盖所有可达模式，且守卫被保守指定**。

**次级风险与缓解**：
1. **模式图不完整**：在线异常检测未建模残差簇 → 自动新增候选模式并强制进入 Q_safe，禁止在未认证模式执行动作块；
2. **守卫误配**：学习到的守卫可能过松 → 用守卫鲁棒裕度 m_g 做在线校核，过松即收紧；
3. **模式信念振荡**：接触抖动导致 b(q) 高频跳变 → 加切换迟滞与最小驻留时间（dwell time）；
4. **MIC 过度保守**：可达模式集太大导致 k_MIC 塌缩为 0 → 用模式相关性剪枝，只保留 top-K 可达模式；
5. **模式混淆攻击**：对手可刻意制造「像迈步的打滑」 → 主动消歧 + 生理/力矩冗余信号，消歧失败直接 Q_safe。

---

**本轮结论**：VISTA 归因「哪层坏」，RAS 决定「收多少」，HYDRA 补上「在哪个离散模式、可能跳到哪个模式、跳过去是否仍然安全」——用混合状态机 + 守卫鲁棒 + 模式不变前缀，把全身控制的安全保证从单一模式扩展到整个可达模式图。最大风险一句话：**只要真实系统存在未建模模式，封闭世界假设失效，HYDRA 的证书就会真空成立却表现得比前人更自信。**

# IP-236 模式信念滤波器
class HydraModeBelief:
    def __init__(self, Q, trans_prior):
        self.Q, self.T = Q, trans_prior
        self.b = {q: 1.0 / len(Q) for q in Q}

    def update(self, rho):
        pred = {q: sum(self.b[p] * self.T[p][q] for p in self.Q) for q in self.Q}
        post = {q: pred[q] * likelihood(rho, q) for q in self.Q}
        z = sum(post.values()) + 1e-12
        self.b = {q: v / z for q, v in post.items()}
        return self.b

    def concentration(self):
        H = -sum(p * log(p + 1e-12) for p in self.b.values())
        return 1 - H / log(len(self.Q))

class RiskShiftedGuard:
    def __init__(self, beta_risk=0.25, beta_mode=0.15, m_min=0.05):
        self.beta_risk, self.beta_mode, self.m_min = beta_risk, beta_mode, m_min

# IP-239 模式不变认证前缀
class ModeInvariantCertificate:
    def __init__(self, guards, m_min=0.05, v_max=2.0, dt=0.02):
        self.guards, self.m_min, self.v_max, self.dt = guards, m_min, v_max, dt

    def reachable_modes(self, q, k):
        seen, frontier = {q}, {q}
        for _ in range(k):
            nxt = {q2 for (q1, q2) in self.guards if q1 in frontier}
            frontier = nxt - seen
            seen |= frontier
        return seen

    def certified_prefix_mic(self, A, q_now, joint_post):
        top = sorted(joint_post.items(), key=lambda x: x[1], reverse=True)[:3]
        k_best = 0
        for k in range(1, len(A) + 1):
            modes = self.reachable_modes(q_now, k)
            if all(self._safe_at(A[s], q2, k - s)
                   for s in range(k) for q2 in modes):
                if all(self.severity_ok(h, q2, p)
                       for (q2, h, e), p in top for q2 in modes):
                    k_best = k
                else:
                    break
            else:
                break
        return k_best

    def _safe_at(self, a, q, remaining):
        x = self.predict_state(a)
        return (self.in_safe_set(x, q)
                and self.min_guard_margin(x, q)
                    >= self.v_max * self.dt * remaining + self.m_min)

## 4. 推导

**引理 11（守卫鲁棒性 ⇒ 前缀模式不变）** 若 `m_g(x_t) ≥ v_max·dt·r + m_min`，则 `∀s ≤ r: m_g(x_{t+s}) ≥ m_min > 0`，前缀执行期间不越过守卫，模式保持 q。证明：`m_g(x_{t+s}) ≥ m_g(x_t) - s·v_max·dt`（三角不等式）。

**引理 12（风险平移守卫单调保守）** `G^{risk}` 阈值随 `R_emotion` 与 `(1-κ_mode)` 单调上升 ⇒ 切换点到守卫边界距离单调增大 ⇒ 更早进入保守模式；`T_reach(Q_safe)` 关于 `R_emotion` 非增。

**引理 13（主动消歧抑制别名）** 探针使 `D_KL` 增加 `Δ_d ≥ γ_d`，模式混淆错误归因概率按 `exp(-γ_d)` 衰减；探针动作本身由 MIC 保证在所有可达模式安全域内。

**定理 11（HYDRA 端到端模式相对安全）** 在定义 259/262 与引理 11–13 下：
```
P(∀s ≤ k*_MIC : x_{t+s} ∈ Ω_{q_{t+s}})
  ≥ 1 - (α_chunk + δ_fi + α_emotion + α_mode + δ_flow)
```
安全保证从「当前模式一张 Ω」升级为「前缀窗口内每个实际到达模式的 Ω_{q'}」。

**定理 12（跨模式无误放宽）**
```
Valid(J_H) ⇒ ∀q' ∈ Reach_k(q_t): S(H, q') ≤ S_max
```
即：只要某个守卫可达模式下 H 致命，无论 H 在当前模式多良性，证书不可 Valid。堵死 RAS「当前安全就放行、下一模式致命」的失效模式。

**定理 13（模式条件可辨识性不减）** 无混淆且模式切换充分激发新残差方向时，`κ_HYDRA = min(κ_fi, κ_ri, κ_mode) ≥ min(κ_fi, κ_ri)`；存在混淆时仅在消歧成功子集恢复，未消歧必须退回 `Q_safe`。

## 7. 本轮最大风险

**一句话**：HYDRA 的全部保证都建立在「混合自动机是封闭的」这一假设上——模式集 Q、守卫 G、重置 R 由人工或有限数据给定，若真实系统逃逸到未建模模式（新接触点、未预料的滑移、软地面下陷），模式不变证书会**真空成立**（vacuously true），而 HYDRA 因为「有状态机背书」会比 RAS 更自信地放行，形成最危险的「模式逃逸」——这是本轮所有理论依赖的核心假设：**模式图覆盖所有可达模式，且守卫被保守指定**。

**次级风险与缓解**：
1. **模式图不完整**：在线异常残差簇检测 → 自动新增候选模式并强制进 Q_safe，未认证模式禁止执行动作块；
2. **守卫误配**：学习守卫可能过松 → 用 m_g 在线校核，过松即收紧；
3. **模式信念振荡**：接触抖动导致 b(q) 高频跳变 → 切换迟滞 + 最小驻留时间；
4. **MIC 过度保守**：可达模式集过大使 k_MIC 塌缩 → 相关性剪枝，只保留 top-K 可达模式；
5. **模式混淆攻击**：刻意制造「像迈步的打滑」 → 主动消歧 + 力矩/生理冗余，消歧失败直接 Q_safe。
