# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「预训练」×「材料选型」）

> 第 54 轮把技能组合升级为「动作剖面 α_S + 鲁棒性谱 ρ_S + 云边联合证书 J」，但仍把 α、ρ 当作技能的**固有属性**。本轮引入两个跨学科视角：**预训练 = 冶炼/热处理过程**，**材料选型 = 约束-目标-索引-Pareto-试片**。核心矛盾：H22：证书绑定的是"技能/任务"，而真实性能绑定的是"预训练 checkpoint + 微调工艺"，换 backbone、换数据配比会让旧证书**静默失效（orphaned certificate）**；H23：按排行榜能力单选预训练模型，等价于只看"强度"不看"比强度/耐蚀/焊接性"，会系统性选中**高能力但脆弱、难接合、超时超能耗**的材料，并在异源模块拼接处触发负迁移。

## 0. 直觉与动机

**灵感 1（预训练是"冶炼"，性质是过程产物）**
直觉：同一架构、不同数据配比/ token 预算/ 目标函数/ 微调日程，会得到不同的表征几何，进而得到不同的动作覆盖 α 与鲁棒性谱 ρ。材料学早已有 **过程-结构-性能-表现（PSPP）** 链；迁移到基础模型即 `预训练配方 R → 表征结构 Φ → 可用性质 Π=(α,ρ,L,E,C) → 现场表现 Ψ`。因此 α_S、ρ_S 必须写成**条件性质** `α_{S|P}`、`ρ_{S|P}`：没有护照（P）就没有性质，也没有证书。

**灵感 2（选型不是选最强，而是选"约束内性能指数最高"）**
直觉：Ashby 选材从不只看强度，而是先写约束（必须满足），再写目标（最小化质量/成本），再推导 **材料索引**（如 `E^{1/2}/ρ`），最后在性质图上取 Pareto 前沿。对应到模型：约束是 `cover(S,A_T)`、`ρ≥ρ_min`、`L≤τ_e`、`E≤E_max`、护照有效、接合兼容；目标是"单位时延与能耗下的能力×鲁棒性"；自由变量是模型族、预训练配方、adapter 类型、量化位宽、技能序。选型由此从"排行榜拍脑袋"变成**可复算的约束优化**。

**灵感 3（护照/炉批号：证书必须绑定不可篡改的工艺身份）**
直觉：材料有炉批号与质保书（mill certificate），成分、热处理、力学性能可追溯。模型也应有 **预训练护照** `P_pre`：数据配比、token 数、目标、架构、许可、污染检测、已知失效模式、哈希。关键区分 **可核验字段 V(P)**（哈希、许可、可复现评测日志）与 **自报字段 S(P)**（数据配比、清洗声明）。证书只能引用 V(P)；S(P) 只作为带折扣的先验。这条直接把 H22 变成工程约束：**证书与护照哈希绑定，否则视为孤儿证书**。

**灵感 4（异源模块拼接 = 异种材料焊接）**
直觉：把不同预训练血统的 LoRA/adapter/技能拼在一起，类似异种金属焊接：热膨胀系数失配会在界面产生应力，对应 **表征漂移**；界面开裂对应 **负迁移**。因此组合前要做"焊接工艺评定"：用 CKA/正交对齐测表征失配 `D_rep`，用动作支撑集差异测动作失配 `D_act`，给出接合兼容性 `Jc` 与负迁移预测 `NT_hat`；不达标就**拒绝接合**，而不是等上线后崩。

**灵感 5（试片 → 资格认证 → 量产：先小样本统计认证，再放量）**
直觉：材料不会直接上主承力件，而是先做试片（coupon）→ 资格认证 → 批量生产，并设**有效期**。模型选型同理：从目标分布抽 n 个仿真 episode 做 coupon，用 Clopper-Pearson 下界给出成功率的**悲观估计** `p_LB`，并对每个鲁棒维度给 `ρ_LB(d)`；同时做 coupon 与部署代理分布的双样本漂移检验。只有 `p_LB`、`ρ_LB` 过关且漂移未超阈值才发证书；证书带 `T_valid`，漂移绊线触发即作废。

**灵感 6（材料基因组与逆设计：用结构描述子做廉价预筛）**
直觉：材料基因组用成分/结构描述子预测性质，减少昂贵实验。模型侧可用便宜的 `Φ`（谱衰减、有效秩、各向同性度、协方差条件数、注意力熵）训练 **预训练-动作指纹 PAF**，在昂贵的 α 探测之前先做预筛；更进一步可做"给定资源预算下的预训练配方逆设计"，作为后续轮次的展望。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（预训练护照）**
护照 `P_pre = (h, D_mix, N_tok, L_obj, F_family, θ_arch, lic, c_contam, f_fail)`，其中 `h` 为制品哈希，`D_mix` 为数据配比，`N_tok` 为训练 token 数，`L_obj` 为目标函数，`F_family` 为模型族，`θ_arch` 为架构超参，`lic` 为许可，`c_contam` 为污染检测结论，`f_fail` 为已知失效模式。字段划分为 **可核验集 V(P)** 与 **自报集 S(P)**。任何证书只允许引用 V(P)；S(P) 以折扣因子 `λ_P∈[0,1]` 进入先验。

**定义 122（PSPP 链与条件性质）**
过程 `R_pre=(D_mix,N_tok,L_obj,aug,τ_ft)`，结构 `Φ=(β_spec,r_eff,ι,κ_cov,H_attn)`（谱衰减指数、有效秩、各向同性度、嵌入协方差条件数、注意力熵），性质 `Π=(α_S,ρ_S,L_lat,E_eng,C_cap)`，表现 `Ψ=(p_succ,ρ_field)`。链为
```
R_pre --f_PS--> Φ --f_SP--> Π --f_PP--> Ψ
```
技能不再是裸对象，而是**材料状态** `M_S=(P_pre,S)`；记条件性质 `α_{S|P}`、`ρ_{S|P}`。第 54 轮所有涉及 α、ρ、J 的量在本轮一律视为 `P_pre` 条件下的量。

**定义 123（材料索引与支配关系）**
给定任务约束集
```
C_req = { cover(S,A_T), ρ_{S|P}(d)≥ρ_min(d) ∀d, L_lat≤τ_e, E_eng≤E_max, P 有效, Jc≥θ_j }
```
与目标"最大化单位时延/能耗下的能力×最差维鲁棒性"，定义对数线性 **材料索引**
```
log I_λ(S|P) = log C_cap + β_ρ·log min_d ρ_{S|P}(d) - β_L·log L_lat - β_E·log E_eng
```
其中 `λ=(β_ρ,β_L,β_E)≥0`。**支配**：`S≻S'` 当且仅当 `C≥C'`、`ρ(d)≥ρ'(d) ∀d`、`L≤L'`、`E≤E'`，且至少一项严格。Pareto 前沿记为 `Π*`。

**定义 124（异源接合兼容性）**
对齐后表征失配 `D_rep(S_i,S_j)=1-CKA(Φ_i^align,Φ_j^align)`，动作支撑失配 `D_act=1-|supp α_i ∩ supp α_j|/|supp α_i ∪ supp α_j|`，接合兼容性
```
Jc(S_i,S_j) = exp( -(w_r·D_rep + w_a·D_act) / T )
```
接合证书 `Jc_cert=(D_rep,D_act,Jc,NT_hat,evidence)`，其中 `NT_hat=1-Jc` 为负迁移预测。仅当 `Jc≥θ_j ∧ NT_hat≤ν` 允许拼接。

**定义 125（试片资格认证）**
试片资格 `Q(S|T,n,δ)=(p̂,p_LB,ρ_LB,s_shift)`，其中 `p_LB=CP_lower(p̂,n,δ)`，`ρ_LB(d)=CP_lower(ρ̂(d),n,δ/|D|)` 为 Clopper-Pearson 悲观下界，`s_shift` 为 coupon 与部署代理分布的漂移统计量。通过条件：
```
p_LB ≥ p_min ∧ ∀d ρ_LB(d) ≥ ρ_min(d) ∧ s_shift ≤ ε_s
```
顺序版本用 Beta-Binomial/SPRT 节省预算；资格带有效期 `T_valid`。

**定义 126（预训练-材料-鲁棒性联合证书）**
```
M = ( J, h(P_pre), I_λ, rank_{Π*}, Q, {Jc_cert_e}_{e∈E_path}, provenance_chain, T_valid )
```
其中 `J` 为第 54 轮联合证书。`M` 有效当且仅当：`hash(deployed)=h(P_pre)`、`now≤T_valid`、漂移绊线未触发、路径上所有 `Jc_cert_e` 通过。否则 `J` 成为**孤儿证书**，必须重签。可部署条件：
```
dom_J(T)=in ∧ δ_a<Θ_a ∧ M valid
```

## 2. 关键算法 伪代码

### IP-121 PMS（Pretrain-Material Selector）

```python
def pretrain_material_select(catalog, task, budget, lam):
    cand = []
    for art in catalog:
        if not passport_verify(art.P, task.repro_suite).ok:      # IP-122
            continue
        if not license_ok(art.P.lic, task.deploy_scope):
            continue
        Phi = measure_structure(art)                              # 便宜：结构描述子
        Pi  = predict_props(Phi, art.P) if art.cheap else probe_props(art, task.A_T)
        if not constraints_ok(Pi, task):                          # 定义 123 约束集
            continue
        cand.append(Material(art, Phi, Pi, index(Pi, lam)))
    front = pareto_front(cand)                                    # 非支配筛选
    front = dominance_prune(front)                                # 命题 55.1 保证无损
    front = rank_by_index(front, lam)
    for m in front[:budget.screen_k]:                             # 只对头部做试片
        m.Q = coupon_qualify(m, task, budget.n0, budget.delta)    # IP-123
    front = [m for m in front if m.Q.passed]
    return max(front, key=lambda m: m.index), front
```

### IP-122 PPC（Pretrain Passport Certificate）

```python
def passport_verify(P, repro_suite):
    checks = {
        'hash':       hash_matches(P.h, artifact_of(P)),
        'license':    license_compatible(P.lic, repro_suite.deploy_scope),
        'contam':     contamination_test(P, repro_suite) <= P.c_contam,
        'provenance': provenance_chain_complete(P),
        'declared':   discount(P.S, lam_P),   # 自报字段只降权，不作证据
    }
    return PassportCert(all(checks[k] for k in checks if k != 'declared'),
                        checks, ttl=P.provenance.horizon)
```

### IP-123 CQ（Coupon Qualification）

```python
def coupon_qualify(mat, task, n, delta):
    eps = [simulate(mat, e) for e in sample(task, n)]
    succ = sum(e.success for e in eps)
    p_lb = clopper_pearson_lower(succ, n, delta)
    rho_lb = {d: clopper_pearson_lower(sum(e.rho[d] >= task.rho_min[d] for e in eps),
                                       n, delta / len(task.D))
              for d in task.D}
    s_shift = two_sample_test(eps, task.deploy_proxy)
    passed = (p_lb >= task.p_min and all(rho_lb[d] >= task.rho_min[d] for d in task.D)
              and s_shift <= task.eps_s)
    return Q(passed, p_lb, rho_lb, s_shift, T_valid=now() + task.horizon)
```

### IP-124 JCM（Joinder Compatibility Matrix）

```python
def joinder_matrix(materials, theta_j, nu, T=1.0):
    Jc, allowed = {}, {}
    for i, a in enumerate(materials):
        for j, b in enumerate(materials):
            if i >= j: continue
            d_rep = 1 - cka(orth_align(a.Phi, b.Phi))
            d_act = 1 - jaccard(supp(a.alpha), supp(b.alpha))
            val = exp(-(w_r * d_rep + w_a * d_act) / T)
            Jc[(i, j)] = JcCert(d_rep, d_act, val, 1 - val)
            allowed[(i, j)] = (val >= theta_j and (1 - val) <= nu)
    return Jc, allowed
```

### IP-125 PMJ（Pretrain-Material Joint Certificate）

```python
def material_joint_certificate(J, mat, task, Jc_edges, deployed_hash):
    if deployed_hash != mat.P.h:            return ('reject', 'orphaned_certificate')
    if now() > mat.Q.T_valid:               return ('reject', 'qualification_expired')
    if not mat.Q.passed:                    return ('reject', 'coupon_failed', mat.Q)
    if any(not e.passed for e in Jc_edges): return ('reject', 'joinder_mismatch', Jc_edges)
    if drift_monitor(mat).tripped:          return ('reject', 'distribution_shift')
    return ('ok', MaterialCert(J, mat.P, mat.I, mat.Q, Jc_edges, provenance(mat)))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| PMS | O(|K|·|Φ| + |K|²·|A| + |Π*|·n·sim) | O(|K|²) | 约束 sound、索引单调、Pareto 无损 |
| PPC | O(|P|·|D| + audit) | O(|P|) | 哈希绑定、许可兼容、污染可检 |
| CQ | O(n·cost(sim)) | O(n·|D|) | coupon 可交换、下界覆盖率 |
| JCM | O(|K|²·(d_rep+d_act)) | O(|K|²) | 漂移预测校准、阈值保守 |
| PMJ | O(|S|·|A| + |K|) | O(|K|) | 哈希一致、有效期、绊线 |
| PAF | O(|Φ|) 推理（离线训练） | O(|Φ|) | 单调约束、不确定度校准 |

**命题 55.1（支配剪枝无损性）**
若 `S≻S'`，则对任意 `λ≥0` 有 `I_λ(S)≥I_λ(S')`。故在 `Π*` 上剪除被支配候选，不会删除任何索引最优解。证明：`log I_λ` 关于 `C`、`ρ` 单调递增，关于 `L`、`E` 单调递减；支配定义逐项不劣，故索引不降。

**命题 55.2（选型遗憾界）**
设性质估计误差满足 `|Ĉ-C|≤ε_C`、`|ρ̂-ρ|≤ε_ρ`、`|L̂-L|≤ε_L`、`|Ê-E|≤ε_E`，索引对性质 Lipschitz 常数 `L_I`，则按估计索引选出的 `Ŝ` 相对真实最优 `S*` 的遗憾满足 `I_λ(S*)-I_λ(Ŝ) ≤ 2·L_I·ε`，其中 `ε=max(ε_C,ε_ρ,ε_L,ε_E)`。故 PAF 的不确定度 `σ` 必须进入 `ε`，否则索引排序会被高估的性质"买通"。

**正确性定理（Passport-Bound Material Selection Soundness）**
假设 (A29) 护照哈希与部署制品一一对应且不可伪造；(A30) coupon 与有效期内现场分布可交换；(A31) 接合漂移预测校准误差 ≤ `η`；(A32) 约束 screening 不误删可行材料。则现场成功概率下界：
```
P_field ≥ p_LB - P(s_shift>ε_s) - Σ_{e∈E_path} P(D_rep_e > Δ_e) - P(hash_mismatch_undetected)
```
直观：材料式选型把"希望成功"换成"**可核验护照 + 悲观试片下界 + 保守接合**"三重可审计量。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 护照不可核验/自报造假 | 高 | 第三方 attestation + 复现评测 + 只信 V(P) |
| coupon 与现场分布漂移 | 高 | 漂移绊线 + 有效期 + 悲观下界 + 回滚 |
| 索引 Goodhart/量纲不可比 | 中 | 约束优先 + Pareto 多目标 + 敏感性分析 |
| 异源接合漂移预测失准 | 高 | 保守拒绝 + 在线漂移监控 + 小步拼接 |
| 选型组合爆炸 | 中 | 支配剪枝 + 分层筛选 + 指纹预筛 |
| 许可/合规冲突 | 中 | license checker + 部署域白名单 |

## 6. 本轮最大风险

**一句话**：材料式选型把预训练模型从"排行榜单品"变成"带护照与试片的可审计材料"，但其 soundness **同时依赖护照可核验、coupon 可交换、接合漂移可预测**；一旦护照自报不可信或试片分布与现场漂移，整套流程会退化为"标签选型"，系统性偏好高能力但脆弱、受污染、难接合的 checkpoint，故必须以 **第三方 attestation + 分布漂移绊线 + 悲观置信下界** 三重护栏，宁可少选、晚选，也绝不把自报护照当作合格证。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim+PMP（PMS×PPC×CQ×JCM×PMJ×PAF）

> 承接第 54 轮产物 v31。第 54 轮把技能组合做成「动作剖面 α + 鲁棒性谱 ρ + 云边联合证书 J」，但 α、ρ、J 仍被当成技能固有属性。本轮引入 **预训练（过程）+ 材料选型（方法）** 双视角，新增 **预训练材料层**：
> - **PMS（Pretrain-Material Selector）**：约束-目标-索引-Pareto 的护照驱动选型；
> - **PPC（Pretrain Passport Certificate）**：护照可核验性、污染、许可与哈希绑定；
> - **CQ（Coupon Qualification）**：仿真试片 + 悲观统计下界 + 分布漂移检验；
> - **JCM（Joinder Compatibility Matrix）**：异源预训练模块接合的漂移/负迁移证书；
> - **PMJ（Pretrain-Material Joint Certificate）**：把第 54 轮 J 与护照/资格/接合绑定，识别孤儿证书；
> - **PAF（Pretrain-Action Fingerprint）**：用结构描述子廉价预测动作剖面，做选型预筛。
>
> IP 编号：IP-121~IP-126（共 6 个新增）。核心范式升级：**证书从"技能绑定"变为"技能+护照哈希绑定"**；性能从"固有"变为"过程条件化"。

### IP-121 PMS

```python
def pretrain_material_select(catalog, task, budget, lam):
    cand = []
    for art in catalog:
        pc = passport_verify(art.P, task.repro_suite)            # IP-122
        if not pc.ok or not license_ok(art.P.lic, task.deploy_scope):
            continue
        Phi = measure_structure(art)
        Pi  = (predict_props(Phi, art.P, sigma=True) if art.cheap
               else probe_props(art, task.A_T))
        if not constraints_ok(Pi, task):
            continue
        cand.append(Material(art, Phi, Pi, index(Pi, lam)))
    front = dominance_prune(pareto_front(cand))                   # 命题 55.1
    front = rank_by_index(front, lam)
    for m in front[:budget.screen_k]:
        m.Q = coupon_qualify(m, task, budget.n0, budget.delta)    # IP-123
    front = [m for m in front if m.Q.passed]
    return max(front, key=lambda m: m.index), front
```

### IP-123 CQ

```python
def coupon_qualify(mat, task, n, delta):
    eps = [simulate(mat, e) for e in sample(task, n)]
    p_lb = clopper_pearson_lower(sum(e.success for e in eps), n, delta)
    rho_lb = {d: clopper_pearson_lower(
                  sum(e.rho[d] >= task.rho_min[d] for e in eps),
                  n, delta / len(task.D)) for d in task.D}
    s_shift = two_sample_test(eps, task.deploy_proxy)
    passed = (p_lb >= task.p_min
              and all(rho_lb[d] >= task.rho_min[d] for d in task.D)
              and s_shift <= task.eps_s)
    return Q(passed, p_lb, rho_lb, s_shift, now() + task.horizon)
```

### IP-124 JCM

```python
def joinder_matrix(materials, theta_j, nu, T=1.0):
    Jc, allowed = {}, {}
    for i, a in enumerate(materials):
        for j, b in enumerate(materials):
            if i >= j: continue
            d_rep = 1 - cka(orth_align(a.Phi, b.Phi))
            d_act = 1 - jaccard(supp(a.alpha), supp(b.alpha))
            val = exp(-(w_r * d_rep + w_a * d_act) / T)
            Jc[(i, j)] = JcCert(d_rep, d_act, val, 1 - val)
            allowed[(i, j)] = (val >= theta_j and 1 - val <= nu)
    return Jc, allowed
```

def material_joint_certificate(J, mat, task, Jc_edges, deployed_hash):

## 3. 复杂度、推导与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PMS | O(|K|·|Φ| + |K|²·|A| + |Π*|·n·sim) | O(|K|²) | 约束 sound、索引单调、支配剪枝无损 |
| PPC | O(|P|·|D| + audit) | O(|P|) | 哈希绑定、许可兼容、污染可检 |
| CQ | O(n·cost(sim)) | O(n·|D|) | 下界覆盖率 ≥ 1−δ |
| JCM | O(|K|²·(d_rep+d_act)) | O(|K|²) | 漂移预测校准误差 ≤ η |
| PMJ | O(|S|·|A| + |K|) | O(|K|) | 哈希一致、有效期、孤儿检出 |
| PAF | O(|Φ|) 推理 | O(|Φ|) | 单调约束、σ 校准 |

**命题 55.1（支配剪枝无损）**
若 `S≻S'`，则 `∀λ≥0: I_λ(S)≥I_λ(S')`。因 `log I_λ` 对 `C,ρ` 单调增、对 `L,E` 单调减，支配逐项不劣即可。故剪除被支配候选不删除索引最优。

**命题 55.2（选型遗憾界）**
设 `|Ĉ−C|≤ε_C`、`|ρ̂−ρ|≤ε_ρ`、`|L̂−L|≤ε_L`、`|Ê−E|≤ε_E`，`I_λ` 对这些性质的 Lipschitz 常数为 `L_I`，则按估计索引选出的 `Ŝ` 满足
```
I_λ(S*) − I_λ(Ŝ) ≤ 2·L_I·ε,   ε = max(ε_C,ε_ρ,ε_L,ε_E)
```
因此 PAF 的不确定度 `σ` 必须并入 `ε`；否则高估的性质会把候选"买"进前排（Goodhart 风险）。

**正确性定理（Passport-Bound Material Selection Soundness）**
假设 (A29) `hash(deployed)=h(P)` 且哈希不可伪造；(A30) coupon 在 `T_valid` 内与现场可交换；(A31) 接合漂移预测误差 ≤ `η`；(A32) screening 不误删可行材料。则
```
P_field ≥ p_LB − P(s_shift>ε_s) − Σ_{e∈E_path} P(D_rep_e>Δ_e) − P(hash_mismatch_undetected)
```
与第 54 轮联合证书 `J` 组合后，部署判据为
```
deploy ⇔ dom_J(T)=in ∧ δ_a<Θ_a ∧ PPC.ok ∧ CQ.passed ∧ ∀e Jc_e.passed ∧ hash_match
```
关键新增：**旧 J 在新调色板/新 backbone 下不得复用**——`hash_match` 失败即 `orphaned_certificate`。

## 5. 本轮最大风险

**一句话**：材料式选型把预训练模型从"排行榜单品"变成"带护照与试片的可审计材料"，但其 soundness **同时依赖护照可核验、coupon 可交换、接合漂移可预测**；一旦护照自报不可信或试片分布与现场漂移，整套流程会退化为"标签选型"，系统性偏好高能力但脆弱、受污染、难接合的 checkpoint，故必须以 **第三方 attestation + 分布漂移绊线 + 悲观置信下界** 三重护栏，宁可少选、晚选，也绝不把自报护照当作合格证。
