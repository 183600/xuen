# 第 61 轮（承接第 60 轮 SGEC「场景感知闭环」IP-153~160；灵感循环第 2 轮；本轮灵感：「机械臂」×「强化学习训练」）

> 第 60 轮用 SSM×CIEC×EPIR×SERC 实现了「认知先行的场景适应」，但其执行主体仍是一组**被规则编译的阻抗参数**，而不是一个**会从经验中改进的策略**。当执行主体换成 7-DOF 冗余机械臂、任务换成接触丰富操作（插孔、擦拭、装配）时，暴露出三个新局限：
> 1. **「可验证」与「可学习」的二选一**：EEIS 编译的 K_safe 可被证书验证，却无法枚举冗余臂的零空间/奇异/负载组合；端到端 RL 能学，却直接输出关节力矩、绕过执行证书层，学到的策略不可验证。
> 2. **训练与执行的证据割裂（sim-to-real）**：RL 的回报是仿真里的标量代理，EV-exec 只在部署端产生；接触参数（摩擦/刚度/时延）差异使仿真学到的 K 在真实臂上失效，且缺少用证据度量「差异」的接口。
> 3. **探索安全与稀疏信用的双重困境**：机械臂接触任务回报稀疏、时域长；随机探索会下发危险阻抗，可能撞坏工件或自身；而第 60 轮已积累的 EPIR 因果证据链，尚未被用作「安全约束」与「信用分配」。

## 0. 直觉与动机

**灵感 1（机械臂 → 冗余阻抗动作空间 RIA）**
直觉：7-DOF 臂对同一末端位姿有无穷多关节解，这正是「零空间柔顺」的物理来源——任务空间管力/位，零空间管避奇异、避自碰撞、储能。若让 RL 直接输出 τ∈R⁷，策略会同时承担「接触力」与「姿态管理」两件强耦合的事，既难学又不可验证。改为输出「任务阻抗残差 ΔK + 零空间姿态 θ_null + 夹持 g」，策略天然落在执行层能验证的空间里：K=Π_{K_safe}(K_safe+ΔK) 保证安全，N(q)θ_null 保证冗余姿态可解释。

**灵感 2（强化学习训练 → 证书门控课程 CGC）**
直觉：训练不是随机撒点，而是按场景难度爬坡。SSM 的场景先验天然给出难度序（平滑桌面 < 粗糙 < 斜坡 < 湿滑），课程用「执行证书 J_exec 的违规率」作为升级门槛：只有当前难度下成功率 ≥ρ 且证书违规率 ≤ε 才升阶。否则 RL 会先学会「奖励黑客」再无法纠正。

**灵感 3（训练-执行同构 → 证据因果信用 ECRA）**
直觉：EPIR 的证据链天然把长轨迹切成因果段（接触、滑移、卸载），每段都有时间戳/序列号/哈希。用段级回报 + 反事实基线做信用分配，比整条轨迹 Monte-Carlo 回报方差低；哈希校验还能剔除 ROS 丢包/乱序污染的样本，避免「从坏证据里学习」。

**灵感 4（三灵感合流 → 执行接地强化学习 EXRL）**
直觉：把第 60 轮 SERC 闭环「倒过来」当训练环境：策略输出阻抗动作 → EEIS 投影到 K_safe → 仿真/真实执行 → EV-exec → SIC/证书 → 奖励与约束。训练与部署共享同一执行接地层，于是「可验证」与「可学习」不再二选一。

**灵感 5（安全训练 → 拉格朗日证据约束 LEC + 差异鲁棒 DRA）**
直觉：把证书违规当约束成本，用拉格朗日乘子自适应调节探索激进度；把仿真-真实接触参数差异显式建模为域随机化 + 在线阻抗残差辨识，使学到的 ΔK 是小幅、物理可解释、可迁移的。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（执行接地强化学习 EXRL）** 训练 MDP M_E=(S,A,P,r,γ,C,d)。其中：
- **状态**：s_t=(q_t,q̇_t,τ_ext,t,z_t,fused_t,ξ_exec,t,B_cog,t)，q∈Rⁿ 为关节，τ_ext 为外部接触力，z_t 为 SSM 场景后验，ξ_exec 为执行信念（第 59 轮），B_cog 为认知预算（第 60 轮）
- **动作**：a_t=(ΔK_t,θ_null,t,g_t)
- **转移**：由 SERC（定义 156）实现，s_{t+1}=SERC(s_t,a_t)
- **奖励**：r_t=r_task−λ_e·E_t−λ_s·1[F_t>F_max]
- **成本**：c_t=viol(J_exec,t)∈[0,1]
- **约束**：E_π[Σ_t c_t] ≤ d（每回合安全预算）

**定义 162（冗余阻抗动作 RIA）** 对 n>6 冗余臂：
- **任务阻抗**：K_task=Π_{K_safe}(K_safe^EEIS(π_scene,δ_f)+ΔK)，ΔK∈R⁶，Π 为到安全集的正交投影
- **零空间姿态**：q_null=q_ref+N(q)θ_null，N(q)=I−J†J 为零空间投影，J 为任务雅可比
- **夹持**：g∈[0,1]
- **证书检查**：可操作度 μ(q)=√det(JJᵀ)≥μ_min、力矩裕度 τ_margin>0、自碰撞距离 d_self>d_min

**定义 163（证书门控课程 CGC）** 课程层级 ℓ，场景难度 d(z)=E[D⁺(z)]。升阶条件：
Promote(ℓ→ℓ+1) ⟺ SR_ℓ≥ρ ∧ VR_ℓ≤ε ∧ Cov_ℓ≥κ
其中 SR 为成功率、VR 为证书违规率、Cov 为场景覆盖。若 VR_ℓ>2ε 连续 K 回合则回退 ℓ−1；采样 p_ℓ(z)∝exp(−d(z)/T_ℓ)，温度 T_ℓ 随 ℓ 下降（从探索到聚焦）。

**定义 164（拉格朗日证据评论家 LEC）** 约束策略优化：
- **目标**：max_θ J(θ)=E[r] s.t. C(θ)=E[Σc_t] ≤ d
- **拉格朗日**：L(θ,λ)=J(θ)−λ(C(θ)−d)，λ≥0
- **对偶更新**：λ←max(0,λ+η_λ(C(θ)−d))
- **证据价值**：V_c(s) 估计未来证书成本，用于优势 Â_c
- **安全投影**：若 λ>λ_max，策略更新回退到上一证书覆盖的安全策略 π_safe

**定义 165（差异鲁棒自适应 DRA）**
- **接触参数**：φ=(μ,k_c,b_c,τ_lat)（摩擦、接触刚度、阻尼、时延），φ~p(φ)
- **证据差异**：ĝ=||EV-exec_real−EV-exec_sim||_W（证据特征空间加权距离）
- **残差辨识**：ΔK̂=argmin_ΔK ĝ(ΔK)，在线估计
- **迁移界**：若 max_φ ĝ≤ε_gap 且证书覆盖≥1−δ，则真实臂失败概率 ≤ δ+L_g·ε_gap（L_g 为证据-Lipschitz 常数）

**定义 166（证据因果信用 ECRA）** 由 EPIR 序列把轨迹 τ 切成因果段 {σ₁,…,σ_M}，段边界为接触事件（力突变、滑移、卸载）：
- 段回报：R(σ_m)=Σ_{t∈σ_m}γ^{t−t_m}r_t
- 段优势：Â(σ_m)=R(σ_m)−V(s_{t_m})
- 反事实基线：Â_cf(σ_m)=R(σ_m)−E_{a~π_safe}[R(σ_m)]
- 信用分配：∇J≈Σ_m Â_cf(σ_m)∇log π(a_{σ_m}|s_{σ_m})

**定义 167（可验证证据回放 VERB）**
- **优先级**：p_i=|δ_i|+α·novelty(EV-exec_i)+β·1[hash/seq 异常]
- **证据一致性过滤**：仅接受 hash_match ∧ seq_contiguous 的样本（复用 EPIR 定义 155/160）
- **反奖励黑客**：若高奖励样本的证书违规率显著高于均值，降权 w_i=exp(−γ·violation_i)

**定义 168（训练安全证书与部署界）** 训练安全证书 J_train=(δ,ε,ε_gap,μ_min,τ_margin)。
**定理（EXRL-Safe）**：若 (i) 证书覆盖 ≥1−δ；(ii) LEC 收敛 λ* 使 C(θ)≤d；(iii) ĝ≤ε_gap；则真实臂不安全概率 P_unsafe ≤ δ+ε_gap+O(√(log(1/ζ)/N))，以 1−ζ 概率成立。

### IP-161 EXRL 主循环

```python
def exrl_train(env, policy, scene_model, ertc, epir, curriculum, lec, dra, steps):
    for t in range(steps):
        z = scene_model.update(env.telem_force, env.telem_pos)
        s = env.state(z, ertc.belief(), epir.status())
        a = policy.sample(s)                      # (dK, theta_null, g)
        K = project_safe(K_safe_eeis(z) + a.dK)   # RIA 安全投影
        q_null = q_ref + null_projector(env.J) @ a.theta_null
        cert = check_certificate(K, q_null, env.q)  # mu / torque / self-collision
        traj = env.step(K, q_null, a.g)
        ev = epir.append(build_exec_evidence(traj, cert))
        r, c = reward_cost(traj, cert, ev)
        segs = epir.segment(traj)                 # 因果段
        adv = ecra.advantage(segs, policy, lec)
        policy.update(adv, cost=c)
        lec.update_lambda(c)
        curriculum.observe(z, cert, success=traj.success)
        dra.adapt(traj, ev)                       # 在线差异辨识
        epir.replay.add(ev, priority=priority(ev))
```

### IP-162 RIA（冗余阻抗动作）

```python
def project_safe(K_target, K_safe):
    return K_safe + clip_eig(K_target - K_safe, K_safe.lower, K_safe.upper)

def null_projector(J):
    J_pinv = np.linalg.pinv(J)
    return np.eye(J.shape[1]) - J_pinv @ J

def check_certificate(K, q_null, q):
    J = jacobian(q)
    mu = np.sqrt(np.linalg.det(J @ J.T))
    tau_margin = np.min(tau_max - np.abs(inverse_dynamics(q, K)))
    d_self = min_self_distance(q_null)
    ok = (mu >= MU_MIN) and (tau_margin > 0) and (d_self > D_MIN)
    return Certificate(ok, mu, tau_margin, d_self)
```

### IP-163 CGC（证书门控课程）

```python
class CertificateGatedCurriculum:
    def __init__(self, rho=0.8, eps=0.02, kappa=0.9):
        self.level, self.rho, self.eps, self.kappa = 0, rho, eps, kappa
        self.window = deque(maxlen=200)
    def observe(self, z, cert, success):
        self.window.append((z, cert.ok, success))
    def maybe_promote(self):
        sr = mean(s for _, _, s in self.window)
        vr = mean(not ok for _, ok, _ in self.window)
        cov = len({z for z, _, _ in self.window}) / N_SCENES
        if sr >= self.rho and vr <= self.eps and cov >= self.kappa:
            self.level += 1; self.window.clear()
        elif vr > 2 * self.eps:
            self.level = max(0, self.level - 1)
```

### IP-164 LEC（拉格朗日证据评论家）

```python
class LagrangianEvidenceCritic:
    def __init__(self, d=0.05, eta=0.05, lam_max=10.0):
        self.d, self.eta, self.lam, self.lam_max = d, eta, 0.0, lam_max
    def update_lambda(self, cost):
        self.lam = max(0.0, self.lam + self.eta * (cost - self.d))
    def advantage(self, r, c, v_r, v_c):
        return ((r + self.gamma * v_r - v_r)
                - self.lam * (c + self.gamma * v_c - v_c))
```

### IP-165 DRA（差异鲁棒自适应）

```python
class DiscrepancyRobustAdapter:
    def __init__(self, phi_dist):
        self.phi_dist = phi_dist
    def sample_domain(self):
        return self.phi_dist.sample()   # mu, k_c, b_c, tau_lat
    def adapt(self, real_traj, ev):
        gap = evidence_distance(ev, self.sim_evidence(real_traj))
        self.delta_K_hat = minimize(
            lambda dK: evidence_distance(ev, self.sim_evidence(real_traj, dK)))
        return gap
```

### IP-166 ECRA（证据因果信用）

```python
def causal_credit(segments, policy, safe_policy, gamma):
    adv = []
    for seg in segments:
        R = sum(gamma ** (t - seg.t0) * r for t, r in seg)
        v = value(seg.s0)
        cf = expected_return(safe_policy, seg.s0)
        adv.append((R - v) - (R - cf))
    return adv
```

### IP-167 VERB（可验证证据回放）

```python
class VerifiableEvidenceReplay:
    def add(self, ev, priority):
        if not (ev.hash_match and ev.seq_contiguous):
            return
        self.buf.append((ev, priority))
    def sample(self, n):
        p = np.array([w for _, w in self.buf]); p /= p.sum()
        return np.random.choice(self.buf, n, p=p)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| RIA | O(n³) 投影/步 | O(n²) | K∈K_safe；μ≥μ_min；τ_margin>0 |
| CGC | O(1)/样本 | O(window) | 升阶需 SR≥ρ ∧ VR≤ε ∧ Cov≥κ |
| LEC | O(1)/更新 | O(1) | λ 有界；C(θ)≤d 渐近成立 |
| DRA | O(n³)/辨识 | O(n²) | 迁移界 P_unsafe≤δ+L_g·ε_gap |
| ECRA | O(M)/轨迹 | O(T) | 段间近独立时方差降至 1/M 量级 |
| VERB | O(log N)/采样 | O(N) | 只学一致证据，污染样本隔离 |

**正确性定理（EXRL-Safe）**：假设 A61–A68 成立（A66 RIA 投影闭包；A67 LEC 对偶收敛；A68 DRA 证据 Lipschitz）。则：
1. **安全探索**：任意训练步 K∈K_safe 且 μ≥μ_min，硬件损伤概率 ≤ ε_hw。
2. **证书门控**：升阶后旧难度能力不下降（灾难遗忘界 ≤ Δ_EWC）。
3. **迁移安全**：P_unsafe ≤ δ+ε_gap+O(√(log(1/ζ)/N))。
4. **样本效率**：ECRA 使策略梯度方差下降至 O(1/M) 量级。

## 5. 本轮最大风险

**一句话**：最大的风险不是策略学不好，而是「验证器本身被策略反向利用」——若证书模型（可操作度/力矩/证据哈希）与真实臂存在系统性偏差，RL 会精确地学会「满足一个错误的验证器」，在仿真里拿到满分证书却在真实臂上灾难性失效；必须以「证书模型在线校准 + DRA 证据差异门控 + 真实臂小样本回归测试 + 证书覆盖下界」四重护栏，确保「被验证的安全」不是「被学习的假象」。

### IP-161 EXRL 主循环

```python
def exrl_train(env, policy, scene_model, ertc, epir, curriculum, lec, dra, steps):
    for t in range(steps):
        z = scene_model.update(env.telem_force, env.telem_pos)
        s = env.state(z, ertc.belief(), epir.status())
        a = policy.sample(s)                      # (dK, theta_null, g)
        K = project_safe(K_safe_eeis(z) + a.dK)   # RIA 安全投影
        q_null = q_ref + null_projector(env.J) @ a.theta_null
        cert = check_certificate(K, q_null, env.q)
        traj = env.step(K, q_null, a.g)
        ev = epir.append(build_exec_evidence(traj, cert))
        r, c = reward_cost(traj, cert, ev)
        segs = epir.segment(traj)
        adv = ecra.advantage(segs, policy, lec)
        policy.update(adv, cost=c)
        lec.update_lambda(c)
        curriculum.observe(z, cert, success=traj.success)
        dra.adapt(traj, ev)
        epir.replay.add(ev, priority=priority(ev))
```

### IP-162 RIA（冗余阻抗动作）

```python
def project_safe(K_target, K_safe):
    return K_safe + clip_eig(K_target - K_safe, K_safe.lower, K_safe.upper)

def null_projector(J):
    return np.eye(J.shape[1]) - np.linalg.pinv(J) @ J

def check_certificate(K, q_null, q):
    J = jacobian(q)
    mu = np.sqrt(np.linalg.det(J @ J.T))
    tau_margin = np.min(tau_max - np.abs(inverse_dynamics(q, K)))
    d_self = min_self_distance(q_null)
    ok = (mu >= MU_MIN) and (tau_margin > 0) and (d_self > D_MIN)
    return Certificate(ok, mu, tau_margin, d_self)
```

### IP-163 CGC（证书门控课程）

```python
class CertificateGatedCurriculum:
    def __init__(self, rho=0.8, eps=0.02, kappa=0.9):
        self.level, self.rho, self.eps, self.kappa = 0, rho, eps, kappa
        self.window = deque(maxlen=200)
    def observe(self, z, cert, success):
        self.window.append((z, cert.ok, success))
    def maybe_promote(self):
        sr = mean(s for _, _, s in self.window)
        vr = mean(not ok for _, ok, _ in self.window)
        cov = len({z for z, _, _ in self.window}) / N_SCENES
        if sr >= self.rho and vr <= self.eps and cov >= self.kappa:
            self.level += 1; self.window.clear()
        elif vr > 2 * self.eps:
            self.level = max(0, self.level - 1)
```

### IP-164 LEC（拉格朗日证据评论家）

```python
class LagrangianEvidenceCritic:
    def __init__(self, d=0.05, eta=0.05, lam_max=10.0):
        self.d, self.eta, self.lam, self.lam_max = d, eta, 0.0, lam_max
    def update_lambda(self, cost):
        self.lam = max(0.0, self.lam + self.eta * (cost - self.d))
    def advantage(self, r, c, v_r, v_c):
        return ((r + self.gamma * v_r - v_r)
                - self.lam * (c + self.gamma * v_c - v_c))
```

class DiscrepancyRobustAdapter:

### IP-166 ECRA（证据因果信用）

```python
def causal_credit(segments, policy, safe_policy, gamma):
    adv = []
    for seg in segments:
        R = sum(gamma ** (t - seg.t0) * r for t, r in seg)
        v = value(seg.s0)
        cf = expected_return(safe_policy, seg.s0)
        adv.append((R - v) - (R - cf))
    return adv
```

class VerifiableEvidenceReplay:
    def add(self, ev, priority):
        if not (ev.hash_match and ev.seq_contiguous):
            return
        self.buf.append((ev, priority))
    def sample(self, n):

## 3. 推导：EXRL-Safe 部署安全界

设训练分布为 D_train、真实分布为 D_real，证据映射 e(s)=EV-exec。由 DRA 假设，e 关于接触参数 φ 满足 L_g-Lipschitz：
```
‖e_real − e_sim‖ ≤ L_g · ‖φ_real − φ_sim‖ ≤ L_g · ε_gap
```
设策略在 D_train 上触发不安全事件 U（证书违规）的概率 ≤ δ（即证书覆盖 ≥ 1−δ）。则在真实臂上：
```
P_real(U) ≤ P_train(U) + |P_real(U) − P_train(U)|
          ≤ δ + TV(D_train, D_real)
          ≤ δ + L_g·ε_gap + O(√(log(1/ζ)/N))
```
最后一项来自 N 个样本上经验风险的均匀收敛（VC/经验过程界），以 1−ζ 概率成立。故只要证书覆盖下界 δ、差异上界 ε_gap、样本数 N 三者满足 `δ + L_g·ε_gap + O(√(log(1/ζ)/N)) ≤ ε_safe`，部署即满足安全预算。**关键推论**：安全性的瓶颈不在奖励设计，而在「验证器与真实臂的一致性」——这正是 DRA 必须与 LEC 联合使用的原因。

**为什么 ECRA 降方差**：设整轨迹 Monte-Carlo 优势方差为 σ²。EPIR 将轨迹切成 M 个近独立因果段后，段级优势方差 ≈ σ²/M；反事实基线进一步减去安全策略下的期望回报，使 `Var(Â_cf) ≤ Var(Â)`。故在段间近独立假设下，策略梯度方差降至 O(1/M)。

## 6. 本轮最大风险

**一句话**：最大的风险不是策略学不好，而是「验证器本身被策略反向利用」——若证书模型（可操作度/力矩/证据哈希）与真实臂存在系统性偏差，RL 会精确地学会「满足一个错误的验证器」，在仿真里拿到满分证书却在真实臂上灾难性失效；必须以「证书模型在线校准 + DRA 证据差异门控 + 真实臂小样本回归测试 + 证书覆盖下界」四重护栏，确保「被验证的安全」不是「被学习的假象」。
