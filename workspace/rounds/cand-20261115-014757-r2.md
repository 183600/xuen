# 第 3 轮（灵感循环新循环第 1 轮；承接第 2 轮 ToolGauge；本轮灵感：「演示数据」×「场景泛化」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440），
> 其自身继承第 1 轮 **LeanGauge**（IP-310–314；定义 398–415；引理 42–45；实验 E411–E425）。
> 本轮纪律：**继续在前人基础上改进，而不是推倒重来**——MODGAUGE 五不变式、契约化工具调用（MTC/TCV）、
> 双层下注、AP-Cal 摊销校准、语言-数值隔离、6C 闭环与严格退化链全部保留。
> 本轮只攻击 ToolGauge 的两个未言明假设：
> (i) **证据只能来自系统自己的探测**——忽视了人类演示这一廉价但被选择偏差污染的旁路证据源；
> (ii) **盲区修复默认在同一个场景内完成**——一旦部署场景与校准场景不同，`σ_decl` 与契约都失去意义。
> 一句话：ToolGauge 会「在它被校准的那个世界里正确地工作」；本轮要让它知道**自己正在哪个世界，
> 以及凭什么把一个世界的结论搬到另一个世界**。

## 三位一体映射（升级而非重写）

| 灵感词 | ToolGauge 的隐含假设 | 升级为 | 一句话动机 |
|---|---|---|---|
| 演示数据 | 只有计量回执是证据；人工经验不可用 | **D-Channel + DET + DTL**：演示作为独立**提议通道**，经选择偏差校正后才转为受限证据 | 演示便宜、覆盖广，但「演示者只演示会的」；直接当回执会把幸存者偏差洗成真值 |
| 场景泛化 | 场景不变，或变化由在线漂移监控兜底 | **S-Box + GenCert + SCC**：场景指纹、场景族最坏风险、场景条件共形覆盖 | 在一个场景有效不是泛化；必须给出「在哪个场景族、以多大概率成立」的可证伪证书 |
| 二者交叉 | 演示是离线日志，泛化是连续漂移 | **泛化债（generalization debt）** | 演示给出「哪里有经验」，场景给出「哪里没覆盖」；差额必须用计量回执偿还 |

**核心命题**：把 ToolGauge 的「局部盲区修复」升级为
「**演示提议 / 计量裁决 / 场景取证**」的三通道架构：
演示只在**提议通道**里起作用（去哪里探、先修谁、怎么探），数值真值仍由计量回执独占，
契约则必须携带**场景作用域证书**才能被热替换和外推。
演示提高样本效率，场景证书限制结论半径，两者都不被允许进入数值通道。

**不变式保持与扩展**：
- MODGAUGE 五不变式全部保留（契约完整性、组合单调性、反作用通道完备、主张绑定、严格退化链）；
- **新增证据通道分离不变式 ECS**：固定回执集与场景标签时，任意改变演示集只能改变提议分布与修复次序，
  不能改变任何契约的 `(μ, Σ)`；演示只有在 DET 转换通过后，才以受限权重进入校准；
- **新增场景作用域不变式 SSI**：每个契约携带已认证场景集 `Z_cert`；`z ∉ Z_cert` 时只能使用既有证书契约或 stub，
  禁止隐式外推；
- **新增泛化声明可证伪不变式 GCF**：每条场景泛化主张必须绑定 GenCert（逐组覆盖下界 + OOD 半径 + 到期时间），
  无证书的主张在契约序列化时剥离（定义 441，扩展定义 423）；
- **严格退化链延长**：DemoGauge 失效（无演示 / 演示被隔离 / 场景 OOD / 证书失效）
  ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE。演示与场景模块都是增强项，不是依赖项。

## 0. 直觉与动机

**灵感 1（演示数据 → 便宜的旁路证据，但必须先去偏）**
直觉：人类操作者示范一次「这面墙是镜面，先侧移再打 IR」比系统自己盲试十次更省。
但演示不是随机样本：演示者倾向选择自己擅长的任务、成功的场景、干净的工况，
这就是**选择偏差（selection bias）**；同一演示者的轨迹还高度相关（同一手法、同一环境），
名义样本量 100 条的有效样本量可能只有 5。ToolGauge 的 AP-Cal 假定回执近似 i.i.d.，
若把演示直接塞进去，会以极高置信度学到「演示者世界的规律」。
因此我把演示拆成两种用途：
(a) **提议先验**（policy prior）——学习「哪里值得探、用什么工具、先修哪个格子」，几乎总是安全且有用；
(b) **校准证据**（pseudo-receipt）——只有在来源可验证、选择倾向可估计、权重有界、
有效样本量达标、且不在演示者信任黑名单时，才允许以**方差膨胀**后的受限权重进入后验。
演示永远只能「建议」，不能「裁决」；这把第 1 轮「任何观测都被当证据」的风险推进到「任何经验都被当建议」。

**灵感 2（场景泛化 → 从「全局正确」到「带作用域的正确」）**
直觉：同一套标定参数在实验室成立，搬到逆光、镜面、地毯、不同相机安装高度就可能失效。
场景泛化的关键不是训练一个更大的模型，而是**诚实地界定适用域**：
用物理不变量（几何、反射率统计、脉冲响应）构造场景指纹 `φ(z)`，
把部署分布分成场景族；对每个族做群 DRO 校准与场景条件共形，
于是证书形如「在 `Z_cert` 内、每组覆盖 ≥ 1−α−δ_g、OOD 半径 r」。
族外不是「性能下降」，而是**证书失效**：必须重新探测或退回 stub。
这把泛化从「希望模型稳健」变成「可测量、可拒答、可审计」的工程对象。

**灵感 3（二者交叉 → 泛化债与预算分配）**
直觉：演示告诉你「这类场景常见、这种材质需要敲击」；但它没有告诉你「你在这里真的测准了吗」。
我定义**泛化债** `D_gen(z_g,h)`：在目标场景分布下，某场景组 × 某假设格子尚未被**有效计量回执**覆盖的期望风险质量。
演示可以降低「找哪里」的不确定性，却**不能销债**——只有签名回执能销债。
债图直接驱动探测预算：优先偿还「目标分布质量大 × 任务相关性强 × 单位成本可降风险多」的格子，
这是一个带递减回报的子模覆盖问题，贪心有 `1−1/e` 保证。
于是演示数据第一次有了明确的经济学角色：**它只影响花钱的顺序，不影响账本的真值**。

## 1. 形式化定义（增量：定义 432–446）

**定义 432（场景、场景指纹与场景族）** 场景 `z = (c_mat, c_light, c_occl, c_pose, c_mount, c_task)`，
取值于带度量 `d_Z` 的场景空间 `𝒵`。物理不变量指纹 `φ: 𝒵 → ℝ^k`
（由 BRDF/反射率统计、深度直方图、纹理梯度、声学脉冲响应、相机安装几何等**去光照、去色偏**的量构成）。
场景族 `𝒵_fam` 用两种方式给出：有限组 `G = {g_1,…,g_m}`（每组一个有代表性的 `z_g` 与半径 `r_g`），
或认证球 `B_Z(z_0, r) = {z : d_Z(φ(z), φ(z_0)) ≤ r}`。
部署场景分布记为 `p_dep(z)`；`p_dep` 的估计误差单独记账（定义 441 的到期与失效）。

**定义 433（演示轨迹 DT）** 演示 `τ = (s_{1:T}, a^{dem}_{1:T}, o_{1:T}, z, id_dem, π_sel, ts, consent)`：
- `s, a^{dem}, o`：状态、演示者动作、观测；`o` 只需是**计量兼容量**（可映射到某工具的 `(μ, σ)` 语义）；
- `z`：场景标签（由 `φ` 复核，不信任人工标注）；
- `id_dem, π_sel`：演示者身份与**选择策略**（他/她在什么条件下决定演示）；
- 演示是**策略证据**（policy evidence），默认不是**计量证据**（metrology evidence）。

**定义 434（演示-场景覆盖与泛化债）**
`C_demo[g,h] = Σ_τ w_τ · 1[z_τ ∈ g] · 1[h ∈ H_τ]` 为演示覆盖（加权计数）；
`D_gen[g,h] = p_dep(g) · r(h|g) · 1[(g,h) 在当前纪元无有效计量回执]`，
其中 `r(h|g)` 是任务相关性权重（由意图/任务契约给出）。
**销债规则**：只有 `valid(r)=True` 的计量回执（定义 417）能令 `D_gen[g,h]` 归零；
演示、VLA 假设、语言主张均**不得销债**。这是「演示只影响次序、不影响真值」的账本化表达。

**定义 435（演示证据转换 DET）** 演示 `τ` 只有在同时满足下列条件时才可转为**伪回执** `r̃_τ`：
1. `Verify(provenance(τ))`：来源签名、时间戳、同意范围有效；
2. `z_τ = φ(obs)` 且 `z_τ ∈ 𝒵_fam`（族外演示只允许提议用途）；
3. 选择倾向 `e(z,s) = q_demo(z,s)/p_dep(z,s)` 可估计，且 `e ∈ [e_min, e_max]`（有界重叠假设）；
4. 权重 `w_τ = clamp(p_dep(z,s)/(q_demo(z,s)), 0, w_max)`，且有效样本量
   `n_eff = (Σ w_τ)² / Σ w_τ² ≥ n_min^demo`；
5. `id_dem` 不在 DTL 隔离名单（定义 436）。
通过后：`r̃_τ = (t, args, (μ_τ, σ_τ·√(1+CV_w²)), sig_demo, ts, seq)`，
即**按权重离散度膨胀方差**；`CV_w` 为权重的变异系数。
未通过：`τ` 只能进入提议先验 `q_probe(·|s,z)`，**永不进入校准样本集**。

**定义 436（演示者信任账本 DTL）** 每个演示者维护信任分
`T_d = 1 − clip(disagree_d / (disagree_d + κ), 0, 1)`，
`disagree_d` 为「演示隐含结果」与「独立计量回执」的标准化残差超阈值次数。
影响上限：`λ_demo = n_eff^demo / (n_eff^demo + n_receipts)` 且 `λ_demo ≤ λ_max`（默认 0.3），
全系统 `Σ_d n_eff^demo,d ≤ ρ·n_receipts`（默认 ρ=0.5）。
`T_d < T_min` ⇒ 该演示者全部演示隔离（只保留提议用途），并触发一次账本审计。
DTL 是对「相关性污染」的显式预算：单个演示者再准，也不能垄断证据。

**定义 437（演示蒸馏探测策略 DPD）** 由演示学得提议策略 `π_demo(a|s,z)`（行为克隆 + 保守离线修正），
目标：`min_θ −Σ log π_θ(a^{dem}|s,z) + μ·1[mismatch] `，其中支持约束
`log π_θ(a|s,z) − log π_demo(a|s,z) ≤ ε_sup`。
`π_demo` **只提议**程序 `Π_s`；TCV 的四查与双层闸门仍然全量生效。
支持失配率 `> ε_sup` ⇒ 该程序退回 `numeric_fallback(H_s)`（ToolGauge 数值路径）。
安全性不依赖 `π_demo` 的质量，只依赖 TCV/闸门（引理 54）。

**定义 438（场景不变校准 SIC）** 场景条件摊销后验
`q_θ(u_s | h, ctx, φ(z)) = 𝒩(μ_θ, Σ_θ)`，训练目标
`min_θ sup_{g∈G} E_g[−log p(u*|h,ctx,φ(z))] + β·VR + λ·KL(q_θ ‖ p_phys)`，
其中 `VR` 为同 `φ` 等价类内跨场景风险方差惩罚（抑制对场景 nuisance 的依赖），
`p_phys` 仍为物理先验 KL 锚，`Σ_θ ≽ κ_phys I` 的保守性夹紧继承定义 420。
SIC 与 AP-Cal 的关系：`G={单组}` 且 `φ=const` 时退化为 AP-Cal。

**定义 439（场景条件共形 SCC）** 对每个场景组 `g`，用组内残差 `|y−μ|` 的分位数构造阈值；
小样本组采用层次收缩
`τ_g^sh = (n_g·τ_g + κ·τ_global)/(n_g + κ)`，或以场景核加权的加权共形。
报告**逐组覆盖下界** `L_g = 1 − α − δ_g(n_g, κ)`，并单独报告漂移项：
若 `TV(p_dep(·|g), p_cal(·|g)) ≤ η_g`，则覆盖 `≥ 1 − α − 2η_g`（引理 53）。
SCC 是定义 422 的场景局部化：**边际覆盖不再足够**，因为误差在场景内高度相关。

**定义 440（场景指纹与域外检测 SF-OOD）** 用 `φ(z)` 与原始残差统计构造共形 OOD 分数
`s_OOD(z) = [d_Z(φ(z), nearest(z_g)) / r_g] + [raw_resid(z) / q_95(raw_resid)]`；
在认证场景族上校准阈值 `τ_OOD`。`s_OOD(z) ≤ τ_OOD` ⇔ `z ∈ 𝒵_fam`；
否则：禁止演示迁移、禁止契约外推，只能进入「重新取证」队列。
OOD 检测的误放行率是证书可信度的第一道物理闸门。

**定义 441（泛化证书 GenCert）** `GenCert(s, 𝒵_c) =
(G_c, {n_g}, {L_g}, r_cert, n_eff^demo, λ_demo, R̄_worst, t_exp)`：
认证场景组、逐组样本量、逐组覆盖下界、认证半径、演示有效样本与影响权重、最坏组风险上界、到期时间。
`valid(GenCert)` ⇔ 所有 `L_g ≥ 1−α−δ_g` 且 `R̄_worst ≤ R_max(s)` 且未过期。
证书绑定进 `EC.claims`（扩展定义 423）：无证书或证书失效的场景泛化主张在序列化时**剥离**；
剥离是纯投影，不改变数值行为。

**定义 442（场景作用域契约 SSC）** 每个契约 `κ` 携带作用域 `Z_cert(κ)`（由 GenCert 给出）。
运行时 `z ∈ Z_cert(κ)`：允许使用；
`z ∉ Z_cert(κ)`：只允许（i）使用同场景的旧证书契约，或（ii）stub + RED，**禁止隐式外推**。
热替换仅在 `Z_cert` 内生效；引理 44 的等价性随之被限制到作用域内（引理 55）。

**定义 443（泛化预算分配 GBA）** 给定探测预算 `B`、债图 `D_gen`、工具代价 `c_t` 与预测风险下降 `ΔR`，
求解 `max Σ_{(g,h)} D_gen[g,h]·ΔR(probe)/c_t` s.t. 预算。
在「一次有效回执至多覆盖一个格子、边际收益递减」下目标函数单调子模，贪心达到 `(1−1/e)` 近似（引理 56）。
GBA 把「先修哪个盲区」从 FIFO/经验规则升级为**可证近优的债偿还调度**。

**定义 444（演示中毒与隔离 DPI）** 若演示隐含结果与独立回执不一致：
`|y_demo − μ_rec| > k·√(σ_rec² + σ_demo²)` 连续 `q` 次 ⇒ 隔离该演示者；
被隔离者的演示不得进入 DET，只能进入提议通道（且 DPD 支持约束仍生效）。
DPI 与 P-Quarantine（定义 428）互补：后者防「先验系统性偏差」，前者防「证据源被投毒」。

**定义 445（DemoGauge 八段闭环 8C）** 修复循环 =
`D(istill) → H(ypothesize) → C(ompile) → E(xecute) → C(alibrate) → V(erify) → G(eneralize/取证) → U(pdate)`：
1. **D**：摄入演示，DET 去偏、DTL 记账、更新提议先验与泛化债图；
2. **H**：L-Box 在「数值白名单 + 演示提议先验」下生成共形假设集（定义 422 继承）；
3. **C**：DPD 提议探测程序，TCV 四查（定义 418 继承）；
4. **E**：双层闸门 + 回执校验，产出有效回执流（定义 419/417 继承）；
5. **C**：SIC + 受限 DET 伪回执做场景条件摊销校准；
6. **V**：独立回执交叉验证 + 契约回归（定义 421.V 继承）；
7. **G**：场景条件共形、群 DRO 复核、SF-OOD、生成 GenCert；
8. **U**：**场景作用域内**热替换 + 绑定 GenCert 与语言证书；失败 ⇒ stub + RED。
`D` 与 `G` 全异步；`D` 为空且 `Z_cert=𝒵` 时，8C 退化为 ToolGauge 的 6C。

**定义 446（继承与编号约定）** 未被本轮重定义的第 2 轮记号（`t, r, Π_s, λ, β, MP-Φ, H_s, SNC, RepairCert,
P-Quarantine, n_min` 等）沿用定义 416–431。退化序：
`DemoGauge(VLA=∅, D=∅, 𝒵_fam={单场景}) ≡ ToolGauge ≡ (T₀={被动观测}, MP-Φ=物理 GP) LeanGauge ≡ MODGAUGE`。
任何新模块失效都不改变数值路径的安全下界，只降低效率或收窄证书半径。

## 2. 关键算法骨架

```python
# IP-321 S-Box：场景指纹、场景分组与 OOD
class SBox:
    def fingerprint(self, obs):
        return invariant_feats(obs)          # BRDF 统计/深度直方图/脉冲响应，去光照与色偏

    def assign(self, z):
        g = self.registry.nearest_group(z)
        return g, self.ood_score(z)

    def in_family(self, z):
        return self.ood_score(z) <= self.tau_ood

    def gen_cert(self, s, family):
        groups = family.groups_containing(s)
        L = {g: self.scc.lower_bound(g) for g in groups}
        return GenCert(s, groups, L, family.radius, self.demo_eff, self.lambda_demo,
                       self.worst_group_risk(groups), self.now() + self.ttl)

# IP-322 演示摄入：DET 去偏 + DTL 信任账本
class DemoIngest:
    def ingest(self, tau):
        if not self.provenance_ok(tau):
            return ProposalOnly(tau)
        z = self.sbox.fingerprint(tau.obs)
        if not self.sbox.in_family(z):
            return ProposalOnly(tau)                     # 族外演示只做提议
        if self.dtl.quarantined(tau.id_dem):             # 定义 444
            return ProposalOnly(tau)
        e = self.selection_model(tau)                    # π_sel 估计
        if e is None or not (E_MIN <= e <= E_MAX):
            return ProposalOnly(tau)                     # 重叠假设不成立
        w = clamp(self.p_dep(z, tau.s) / (e * self.q_demo(tau.s)), 0.0, W_MAX)
        n_eff = (w.sum() ** 2) / (w ** 2).sum()
        if n_eff < N_MIN_DEMO:
            return ProposalOnly(tau)                     # 有效样本不足
        var_eff = tau.var * (1.0 + cv(w) ** 2)           # 权重离散 → 方差膨胀
        return PseudoReceipt(tau, w, var_eff, n_eff)

# IP-323 DPD：支持约束下的演示策略蒸馏（只提议，不执行）

# IP-326 8C 主闭环：D 与 G 全异步，50Hz 路径不动
def demogauge_8c(M, s, z):

    M.debt.update(demos.coverage)                           # 演示不销债，只更新次序

        return False
    M.debt.repay(s, z, receipts)                            # 只有回执销债

    return True
```

## 3. 推导

**引理 51（去偏伪回执的偏差界）** 设演示分布 `q`、目标分布 `p`，选择倾向
`e(z,s)=q/p ∈ [e_min,e_max]`，权重 `w=p/q` 有界，`n_eff=(Σw)²/Σw²`。
则自归一化加权估计的偏差满足
`|E_q[w·g] − E_p[g]| ≤ 2·TV(p,q)·sup|g| + sup|g|·(1/√n_eff)`；
若 `e` 只能被估到 `ê` 且 `|e−ê| ≤ ε_e`，再附加 `≤ ε_e·L_g` 的偏差项。
系：DET 的 `λ_demo ≤ λ_max` 与方差膨胀 `σ²(1+CV_w²)` 使后验均值的最坏偏移被 `λ_max·B` 显式封顶；
因此「演示污染」是一个**可配置上限的偏差预算**，而不是不可控风险。

**引理 52（场景族最坏风险界）** 设场景组 `g∈G`、组样本 `n_g`、组风险 `R_g`，
以概率 `≥1−δ`：
`max_g R_g ≤ max_g R̂_g + √(log(2|G|/δ) / (2·min_g n_g))`。
若契约对不变指纹 `φ` 是 `L`-Lipschitz、认证球半径 `r`，则族内任意 `z` 满足
`R(z) ≤ max_g R_g + L·r`。群 DRO（定义 438）最小化右端第一项，`r` 由定义 440 的 OOD 半径控制。
**关键限定**：该界只对 `Z_cert` 成立；`z ∉ Z_cert` 时右端无定义——这正是本轮最大风险所在（§6）。

**引理 53（场景条件共形覆盖）** 组内可交换下，`n_g` 个校准残差给出
`P(y ∈ C_g) ≥ 1 − α − 1/(n_g+1)`；层次收缩以 `κ` 的偏差换方差，覆盖
`≥ 1 − α − δ_g(n_g,κ)`，其中 `δ_g` 随 `n_g/κ` 单调下降。
组内漂移 `TV(p_dep(·|g),p_cal(·|g)) ≤ η_g` 时，覆盖 `≥ 1−α−2η_g`；
以场景核加权的加权共形可把 `2η_g` 改进为 `η_g·L′`。
系：`α=0.1` 且 `η_g ≤ 0.05` ⇒ 组覆盖下界 0.8，作为 GenCert 的硬门槛。

**引理 54（演示质量不影响安全性）** DPD 只产生候选程序；TCV 强制执行 schema/前置/预算/循环四查；
双层闸门强制执行 `σ_pred−σ_decl ≥ γ` 与 `Ĝ−c ≥ γ_B`；
无效/未签名回执永不进入校准（定义 417）。因此对任意演示集（含对抗投毒），
实际执行的物理程序仍属于 `T₀`、前置实测满足、无未验证副作用；
物理安全超界概率由 ToolGauge 的引理 46 界定，**与演示分布无关**。
演示质量只影响提议效率与样本效率，不改变安全下界。

**引理 55（8C 的时序、场景作用域与退化保持）**
`D`（摄入/蒸馏）与 `G`（共形/证书）均在 50Hz 计量路径之外异步执行；
50Hz 周期新增仅为场景查表与作用域判定 `O(1) < 0.1ms`；
单盲区修复时延 `≤ L_max·max τ_t + τ_VLA + τ_AP + τ_cert ≤ τ_repair`（TB-Contract 继承）。
热替换被限制在 `Z_cert` 内，等价性仍是「未涉及子图逐指令 diff = 0」
（`claims/GenCert` 不在数值路径，剥离为纯投影）。
退化：演示不可用 ⇒ 提议先验取均匀；族外 ⇒ 禁止迁移；证书失效 ⇒ stub + RED；预算耗尽 ⇒ 硬降级。
硬实时（引理 45）与预算不变式保持。

**引理 56（债驱动预算的近似最优性）** 在「一次有效回执至多消去一个 `(g,h)` 的债、且收益随预算递减」下，
`F(S)=Σ_{i∈S} D_gen[i]·ΔR_i/c_i` 单调子模；贪心分配满足
`F(S_greedy) ≥ (1−1/e)·F(S*)`。
系：当 `p_dep` 与 `r(h|g)` 估计有误时，用其置信上界 `D̄_gen` 做鲁棒版本，近似比不变、只损失常数因子。

## 6. 本轮最大风险（一句话）

**一句话**：**场景族边界（GenCert 的认证半径）若被设错，
而场景指纹 `φ`、OOD 阈值与 `p_dep` 估计又未能识别真实部署场景落在族外，
系统就会把「族内严格成立」的证书外推到族外——所有不变式仍然成立、证明逐条无误，
但结论整体错误；演示先验还会通过「族内成功经验」强化这种确认偏差，
让系统在最不该自信的新场景里显得最有把握**（E443/E445/E454/E455 为证伪实验，
SF-OOD 拒答、场景作用域契约与演示影响上限为三道在线闸门）。

**次级风险与缓解**：
1. **演示选择偏差估计错误** → 重叠假设检查 `e∈[e_min,e_max]` + 权重截断 + `n_eff` 门槛 + 引理 51 偏差预算；
2. **演示相关性强导致虚假置信** → DTL 有效样本与总影响上限 `ρ`，演示永不能销债；
3. **演示投毒** → DPI 与独立回执交叉验证，连续不一致即隔离并回退 ToolGauge；
4. **场景标签泄漏 / φ 不充分** → φ 只用物理不变量，OOD 用共形阈值，定期用新场景审计误放行率；
5. **群 DRO 对少数场景过拟合** → 层次收缩 SCC + 组样本量门槛 `N_MIN_G`，不足则借力全局并加宽区间；
6. **演示者隐私与同意** → consent 字段、最小化特征、支持本地/端侧蒸馏、到期删除；
7. **GBA 依赖 `p_dep` 与任务相关性估计** → 用置信上界做鲁棒版本（引理 56 系），估计失准时退化为均匀分配；
8. **异步 D/G 与在飞修复的竞态** → 场景纪元号 + 作用域校验，证书失效即取消在飞热替换（stub + RED）；
9. **证书膨胀导致过度拒答** → 证书 TTL 与场景族粒度可调，用 E449/E450 量化「拒答率 vs 风险下降」的帕累托前沿。

| `8C` | `D→H→C→E→C→V→G→U`（定义 445） |

## 2. 形式化定义（要点）

**定义 432（场景/指纹/族）** `z=(c_mat,c_light,c_occl,c_pose,c_mount,c_task)`；
`φ` 只取物理不变量；场景族由有限组 `{z_g,r_g}` 或认证球 `B_Z(z_0,r)` 给出。
**定义 433（演示轨迹）** 演示默认是**策略证据**，不是**计量证据**；`o` 必须可映射到某工具语义。
**定义 434（泛化债）** `D_gen[g,h]=p_dep(g)·r(h|g)·1[无有效回执]`；
**演示不得销债**，只有 `valid(r)` 的计量回执能销债。
**定义 435（DET）** 五条准入：来源可验证、场景在族内、选择倾向有界、`n_eff ≥ n_min^demo`、演示者未隔离；
通过后以 `w_τ` 加权、`σ²(1+CV_w²)` 方差膨胀的伪回执进入校准；否则只进提议先验。
**定义 436（DTL）** 信任分 `T_d` 与影响上限 `λ_demo = n_eff/(n_eff+n_rec) ≤ 0.3`，
总量 `Σ n_eff ≤ ρ·n_rec`；`T_d<T_min` ⇒ 隔离。
**定义 437（DPD）** 行为克隆 + 保守离线修正 + 支持约束；只提议；失配率超阈值退回数值路径。
**定义 438（SIC）** `min_θ sup_g E_g[−log p(u*|h,ctx,φ(z))] + β·VR + λ·KL(q_θ‖p_phys)`；
`Σ_θ ≽ κ_phys I` 继承；单组且 `φ=const` 时退化为 AP-Cal。
**定义 439（SCC）** 层次收缩 `τ_g^sh=(n_g τ_g+κτ_global)/(n_g+κ)`，报告逐组覆盖下界
`L_g=1−α−δ_g`；组内漂移 `η_g` 时 `≥1−α−2η_g`（加权共形可改进）。
**定义 440（SF-OOD）** `s_OOD(z)=d_Z(φ(z),nearest)/r_g + raw_resid/q_95`；`s_OOD≤τ_OOD ⇔ z∈𝒵_fam`。
**定义 441（GenCert）** 证书 = `(G_c,{n_g},{L_g},r_cert,n_eff^demo,λ_demo,R̄_worst,t_exp)`；
`valid` ⇔ 所有 `L_g≥1−α−δ_g` 且 `R̄_worst≤R_max` 且未过期；绑定 `EC.claims`，失效即剥离。
**定义 442（SSC）** 契约携带 `Z_cert(κ)`；`z∉Z_cert` 只允许旧契约或 stub+RED，**禁止隐式外推**。
**定义 443（GBA）** `max Σ D_gen[g,h]·ΔR/c_t` s.t. 预算；单调子模 ⇒ 贪心 `(1−1/e)`。
**定义 444（DPI）** 演示隐含结果与独立回执连续 `q` 次超阈值 ⇒ 隔离该演示者并回退 ToolGauge。
**定义 445（8C）** `D→H→C→E→C→V→G→U`；`D`/`G` 全异步；`D=∅,Z_cert=𝒵` 时退化为 6C。
**定义 446（继承）** 第 2 轮记号沿用定义 416–431；退化序
`DemoGauge ≡ ToolGauge ≡ LeanGauge ≡ MODGAUGE`（对应模块置空）。

## 3. 关键算法骨架

```python
# IP-321 S-Box：场景指纹 / OOD / 证书
class SBox:
    def fingerprint(self, obs):
        return invariant_feats(obs)              # 去光照、去色偏的物理不变量

    def assign(self, z):
        return self.registry.nearest_group(z), self.ood_score(z)

    def in_family(self, z):
        return self.ood_score(z) <= self.tau_ood

    def gen_cert(self, s, family):
        groups = family.groups_containing(s)
        L = {g: self.scc.lower_bound(g) for g in groups}
        return GenCert(s, groups, L, family.radius, self.demo_eff,
                       self.lambda_demo, self.worst_group_risk(groups),
                       self.now() + self.ttl)

# IP-322 DET/DTL：选择偏差重加权 + 有效样本 + 信任账本
class DemoIngest:
    def ingest(self, tau):
        if not self.provenance_ok(tau):
            return ProposalOnly(tau)
        z = self.sbox.fingerprint(tau.obs)
        if not self.sbox.in_family(z) or self.dtl.quarantined(tau.id_dem):
            return ProposalOnly(tau)
        e = self.selection_model(tau)
        if e is None or not (E_MIN <= e <= E_MAX):
            return ProposalOnly(tau)
        w = clamp(self.p_dep(z, tau.s) / (e * self.q_demo(tau.s)), 0.0, W_MAX)
        n_eff = (w.sum() ** 2) / (w ** 2).sum()
        if n_eff < N_MIN_DEMO:
            return ProposalOnly(tau)
        return PseudoReceipt(tau, w, var=tau.var * (1 + cv(w) ** 2), n_eff=n_eff)

# IP-323 DPD：支持约束下的演示策略蒸馏
class DPD:
    def propose(self, H_s, tools, z):
        prog = self.pi_demo(H_s, tools, self.sbox.fingerprint(z))
        if self.support_mismatch(prog) > EPS_SUP:
            prog = self.tbox.numeric_fallback(H_s)
        return prog

# IP-324 SIC + SCC：场景稳健校准
class SceneRobustAPCal(APCal):
    def calibrate(self, receipts, pseudo, H, s, z):
        g = self.sbox.assign(z)
        ctx = featurize_ctx(receipts, pseudo, H, s, self.sbox.fingerprint(z))
        mu, Sig = self.mp_phi_group(g)(ctx)
        return mu, clamp_min(Sig, KAPPA_PHYS)

    def scene_conformal(self, g, residuals):
        n_g = len(residuals[g])
        tau_g = quantile(residuals[g], 1 - ALPHA) if n_g >= N_MIN_G else self.tau_global
        return self.shrink(self.tau_global, tau_g, n_g)

# IP-325 GenCert + 场景作用域热替换
def certify_and_replace(M, s, z, mu, Sig):
    if not M.sbox.in_family(z):
        return stub_and_red(s, "ood_scene")
    cert = M.sbox.gen_cert(s, M.sbox.family_of(z))
    if not cert.valid():
        return stub_and_red(s, "no_scene_cert")
    new_ec = M.srcal.update_contract(M.dpe, mu, Sig, s, scope=cert.scene_set)
    if not contract_regression(new_ec):
        return stub_and_red(s, "regression")
    M.mreg.hot_replace(M.dpe, new_ec, scope=cert.scene_set)
    bind_claims(new_ec, cert, scope=cert.scene_set)
    return True

# IP-326 8C 闭环
def demogauge_8c(M, s, z):
    demos = M.demo_ingest.collect(s, z)                        # D
    M.debt.update(demos.coverage)                              # 演示不销债
    H = M.lbox.hypothesize(s, M.dbox.R[s], demos.proposal_prior)
    prog = M.dpd.propose(H, M.tools, z)                        # C
    if not M.tcv.verify(prog, M.budget_left(s))[0]:
        prog = M.tbox.numeric_fallback(H)
    receipts = M.tcv.execute(prog, M.env)                      # E
    if len(receipts) < n_min(s, z):
        return stub_and_red(s, "insufficient")
    mu, Sig = M.srcal.calibrate(receipts, demos.admissible, H, s, z)   # C
    if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):        # V
        return stub_and_red(s, "cross_failed")
    if not certify_and_replace(M, s, z, mu, Sig):                      # G + U
        return False
    M.debt.repay(s, z, receipts)
    M.pquar.record(M.apcal.last_gain, realized_gain(receipts))
    M.dtl.update_from_validation(demos, receipts)
    return True

# IP-326 主闭环：债驱动调度 + 族外暂停迁移
def DemoGauge_round(M, obs, audio, tac, depth, det):
    z = M.sbox.fingerprint(obs)
    for s in M.debt.priority_queue(z, M.budget):
        if s not in M.inflight:
            M.inflight.add(s)
            submit_async(demogauge_8c, M, s, z)
    if not M.sbox.in_family(z):
        M.transfer_suspended = True
    if M.pquar.triggered():
        M.apcal.pause()
        M.use_bpcal_fallback = True
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 4. 推导

**引理 51（去偏伪回执偏差界）** `|E_q[w·g]−E_p[g]| ≤ 2·TV(p,q)·sup|g| + sup|g|/√n_eff`
（选择倾向估计误差 `ε_e` 另加 `ε_e L_g`）。
系：`λ_demo≤λ_max` 与方差膨胀使后验均值最坏偏移被 `λ_max·B` 显式封顶——演示污染是**有上限的偏差预算**。
**引理 52（场景族最坏风险界）** `max_g R_g ≤ max_g R̂_g + √(log(2|G|/δ)/(2 min_g n_g))`；
`φ`-Lipschitz 且半径 `r` ⇒ 族内 `R(z) ≤ max_g R_g + L·r`。
**关键限定**：只对 `Z_cert` 成立，族外无定义。
**引理 53（场景条件共形）** 组内 `≥1−α−1/(n_g+1)`；层次收缩 `≥1−α−δ_g(n_g,κ)`；
漂移 `η_g` 下 `≥1−α−2η_g`（加权共形改进为 `1−α−η_g L′`）。
**引理 54（安全性不依赖演示质量）** DPD 只提议；TCV 四查 + 双层闸门 + 无效回执丢弃；
对任意演示集（含投毒），物理执行程序仍属 `T₀`、前置满足、无未验证副作用；
安全超界概率由引理 46 界定，**与演示分布无关**。
**引理 55（时序/作用域/退化保持）** `D`、`G` 异步于 50Hz 外；周期新增 `<0.1ms`；
热替换限制在 `Z_cert`，未涉及子图 diff=0；退化链逐级保持；硬实时（引理 45）保持。
**引理 56（债调度近似最优）** 单调子模 + 单位成本收益 ⇒ 贪心 `≥(1−1/e)` 最优；
`p_dep/r(h|g)` 估计有误时用置信上界，比例不变、仅常数损失。
