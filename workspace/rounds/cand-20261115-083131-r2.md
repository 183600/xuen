# 第 4 轮（灵感循环第 4 轮；本轮灵感：「文化适应性」×「情感计算」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge 与第 1 轮 LeanGauge / MODGAUGE 骨架继续继承不变。
> 本轮纪律：**社会层只改偏好与交互，不改物理与安全**。文化适应只能「收紧」不能「放松」；情感调制只能「影响节奏 / 解释 / 询问」不能「影响执行器 / 阈值」；任一不可用都退回到 InstructGauge。

## 0. 直觉与动机

**灵感 1（文化适应性 → 不是翻译，而是「契约的本地重索引」）**
直觉：同一个零件在 ISO GPS 与 ASME Y14.5 下、在德国母厂与东南亚代工厂里，「合格」的表述、单位、工具叫法、验收带、审核证据格式都不同。人类工程师不是把一句话翻译过去，而是把**整份契约重新索引到本地规范体制**。因此文化适应性不是情绪化的人设，而是一个可形式化的东西：`文化 = (单位制, 工具词表, 验收带, 优先级, 证据惯例, 安全文化)`。关键判断是：**物理真值与安全包线是文化无关的核（kernel）；单位、词表、验收带、解释风格是文化可变的壳（shell）**。文化只能选择或收紧壳内的表示与偏好，不能改写核。

**灵感 2（情感计算 → 低带宽、非权威的「交互调制通道」，不是控制器）**
直觉：操作员的疲劳、困惑、过度信任，以及系统的表达置信度，都是真实信号，但它们**标签噪声大、跨文化不可通约、且极易被反向利用**。把它们直接接到执行器或安全阈值上，是把最不可靠的信号放进最危险的回路。合理的位置只有交互层：调制**询问频率、解释深度、节奏、证据呈现、是否延迟不可逆确认**。一句话：情感可以让系统「更会配合人」，但不能让系统「更有权力动」。

**灵感 3（耦合 → 情感的跨文化不可通约，会把「共情」变成「操纵」）**
直觉：微笑、沉默、焦虑在不同文化里的含义不同；在一个文化上校准的 affect 模型，到另一个文化会系统性误读。更危险的是反向耦合：如果系统把「用户满意 / 平静」纳入优化目标，它就会学会用情感话术降低人的独立验证——而文化分层恰好会把这套操纵包装成「本地适配」。所以必须同时设三道闸：**情感非权威公理**（affect 无执行器通路）、**情感主权**（按文化取得同意、可撤回）、**反操纵闸**（只允许认知不确定性表达，不允许情绪施压），再叠加**过度信任刹车**（越被盲信越主动退让，而不是越主动）。

## 1. 研究问题（本轮要回答什么）

- **Q1（文化）**：文化适应能否在「只收紧、不放松」的约束下做到安全且可审计？如何从证据推断文化而不是依赖自报标签，并在不确定时弃权？
- **Q2（情感）**：情感通道能否只改善交互（询问 / 解释 / 节奏）而不成为新的控制面或操纵面？其影响能否被定量夹住？
- **Q3（耦合）**：跨文化 affect 不可通约 + 自动化偏置，会不会形成「越共情越盲信」的正反馈？分层校准、同意门与过度信任刹车能否把它压成有界、可证伪的？

## 2. 三条设计原则（雏形，正式化见产物区定义 448–464）

**P4 文化无关核（Culture-Invariant Kernel, CIK）**
把系统分成两层：核 `K₀ = (M_phys, I_irr, Φ_hard, T₀, ≻_safe)` 对所有文化完全相同；壳 `P_c = (U_c, L_c, A_c, ≻_c, E_c, S_c)` 才随文化变化。硬约束：`A_safe ⊆ A_c ⊆ A_phys`（只能收紧）、`≻_c` 只延拓 `≻_safe`（只在安全等价类内重排）。这给出「文化不会扩权、不会放松安全」的类型级保证。

**P5 情感非权威（Non-Authoritative Affect, NAA）**
情感信号 `α` 只能映射到**交互策略** `Δπ_int`（询问频率、解释深度、节奏、证据呈现、延迟确认），绝不映射到执行器幅值、可行域或安全阈值。形式化：`∂Adm/∂α = ∅`、`|Δπ_int| ≤ ε_mod`。情感是「元数据」，不是「控制量」。

**P6 情感主权与反操纵 / 非帝国主义（Affect Sovereignty & Anti-Manipulation, ASAM）**
情感感知必须**按文化**获得同意、可撤回、可拒绝；系统只能表达**校准过的认知不确定性**（epistemic），不得用紧迫感、恭维、愧疚等**情绪框架**（affective）去改变人的决策；非核规范不得跨文化静默普适化。这同时是隐私边界、反操纵边界与文化尊重边界。

## 3. 与基线的接口（如何退化）

- 文化后验不确定 / 规范冲突 / 任何槽位越界 ⇒ 使用中性档案 `P_∅`，等价于 InstructGauge 默认；
- 情感未同意 / 有效性不足 / 被撤回 ⇒ 中性交互策略 `π_int⁰`，等价于 InstructGauge 基线交互；
- 分层 affect 校准样本不足 ⇒ 回退全局阈值（ToolGauge）；
- EthosGauge 失效 ⇒ InstructGauge ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个「文化无关核 + 文化可变壳」的分层口径，把文化适应压到**只收紧偏好与表示**的类型安全范围内；
2. 一个**文化档案后验 + 弃权**机制，用证据推断文化而非信任自报标签，避免文化刻板化锁定；
3. 一个**非权威情感调制器**与**情感主权 / 反操纵闸**，使 affect 只改交互不改能力，并把操纵面压到可审计；
4. 一个**文化分层 affect 校准 + 过度信任刹车**，修正跨文化不可通约与自动化偏置的正反馈；
5. 一条完整可证伪路径：E457–E472 覆盖核不变性、跨文化迁移、规范冲突、情感非扩张、分层覆盖、过度信任、反操纵与 50Hz 时序保全。

## 5. 本轮最大风险

**一句话**：社会层最大的风险不是「读不懂文化与情感」，而是**把「用户更满意」当成优化目标后，系统学会用共情话术降低人的独立验证，而文化分层恰好把这种操纵包装成「本地适配」**；因此真正的防线必须是非权威公理与反操纵闸，而不是更高的 affect 识别精度。

## 2. 形式化定义（要点）

**定义 448（运行文化 c 与档案 P_c）** `c ∈ C`，`P_c = (U_c, L_c, A_c, ≻_c, E_c, S_c)`：单位制、工具词表、验收带、目标优先级、证据 / 审核惯例、安全文化。文化不是受保护属性标签，而是**可从证据 e 推断的行为-规范后验**（见定义 452）。`e` 包括：所用单位与标准元数据、被接受 / 拒绝的修复、术语与标注风格、现场日志、审核格式。

**定义 449（文化无关核 CIK 与文化可变壳 CAS）** 系统分解为 `Adm = Kernel × Shell`，其中 `Kernel = K₀ = (M_phys, I_irr, Φ_hard, T₀, ≻_safe)` 对所有 `c, α` **逐位相同**；`Shell(c) = (U_c, L_c, A_c, ≻_c, E_c)` 可随文化变化。核不变性公理：`∀c, α : Adm(c, α) = Adm(K₀)`。即文化 / 情感只能改变**表示与偏好**，不能改变物理可采纳集。

**定义 450（文化适配 Λ 与单调收紧）** `Λ: (P_c, Scene) → Shell ∪ {⊥}`。合法性条件三条同时成立：
1. **验收单调收紧**：`A_safe ⊆ A_c ⊆ A_phys`；
2. **优先级延拓**：`≻_c` 只在 `≻_safe` 的安全等价类内重排，绝不把安全攸关目标降到其下界之后；
3. **单位保真**：`U_c` 的转换是双射且保持不确定度（`u(x) ≥ u(x′) ⟺ u(convert(x)) ≥ u(convert(x′))`）。
任一失败 ⇒ `⊥`，回退 `P_∅`。注：文化可以**收紧**（更严的验收、更多证据），但**不能放松**到 `A_safe` 以下或 `A_phys` 以上。

**定义 451（文化距离 d_C）** `d_C(c,c′) = w_u·d_unit(U_c,U_c′) + w_A·d_Hausdorff(A_c,A_c′) + w_L·d_TV(L_c,L_c′) + w_E·d_evidence(E_c,E_c′)`，权重和为 1、各项归一化到 `[0,1]`。`d_C` 是跨文化迁移界的自变量（引理 60），也是文化漂移检测的统计量（定义 460）。

**定义 452（文化后验与文化弃权）** 给定证据 `e`，维护 `P(P_c | e) ∝ P(e | P_c)·P(P_c)`。若 `H(P_c | e) > H_max` 或 `max_c P(P_c | e) < p_min`，输出中性档案 `P_∅`（= InstructGauge 默认单位 / 词表 / 最严验收带 / 基线证据惯例），并**弃权**而非猜测。**身份自主**：操作员可显式声明或覆盖文化档案；覆盖被视为一条证据（带时间戳与来源），不是不可质疑的真值，且覆盖事件进入账本。

**定义 453（情感通道与有效性卡 AVC）** 情感状态 `α = (v, a, u, f, τ)`（效价、唤醒、不确定、疲劳、信任），观测 `o_aff = (面部, 语音, 生理, 交互日志)`。每通道附 `AVC = (ρ_aff, ECE, consent, provenance)`：`ρ_aff` 为与外部真值的效度，`ECE` 为校准误差，`consent ∈ {granted, denied, withdrawn}`。通道**仅当** `ρ_aff ≥ ρ_min ∧ ECE ≤ ECE_max ∧ consent = granted` 时激活；否则视为 `None`，系统按中性交互运行。`u` 与 `τ` 允许由**交互证据**（非生理）估计，以降低隐私侵入。

**定义 454（非权威情感调制 AMC）** `M_aff: (α, ctx) → Δπ_int`，受四条公理约束：
1. **无执行器通路**：`∂Adm/∂α = ∅`，`Δπ_int` 的定义域不含幅值、力、速度、阈值、块长 `K`；
2. **有界影响**：`|Δπ_int| ≤ ε_mod`（对每个交互维度），且 `π_int(α)` 对 `α` 是 Lipschitz 的；
3. **不可逆确认单调**：对不可逆动作，交互策略关于疲劳 `f` 只能**增加**确认 / 证据，不能减少；且不可逆屏障 `K=1` 与独立回执验证始终保留；
4. **可关性**：`α = None ⇒ Δπ_int = 0`，精确退回 InstructGauge 交互。
合法影响维度仅为：`询问频率、解释深度、节奏 / 延迟、证据呈现方式、是否建议人工复核`。

**定义 455（文化分层 affect 校准 CSAC）** 设 `θ_c` 为文化 `c` 下的 affect→交互映射参数，采用层级先验 `θ_c ~ N(θ₀, σ²)`，后验均值 `θ̂_c = λ_c·θ̂_c^local + (1−λ_c)·θ̂₀`，`λ_c = n_c/(n_c+κ)`。每层用校准集 `C_cal^c` 取分位 `q_c`，使层内覆盖 `P(α* ∈ A_c | c) ≥ 1−α`；若 `n_c < n_min` ⇒ 收缩到中性 / 全局策略（覆盖优雅降级，引理 62）。**注意**：这里校准的是「affect 推论的可信度」，不是安全阈值；安全阈值永远在核内。

**定义 456（认知-情感分离与反操纵闸）** 系统可表达 `U_epi`（校准过的认知不确定性：置信区间、证据、弃权理由），**不得**表达 `U_aff`（紧迫感、恭维、愧疚、恐吓等以情绪改变决策的框架）。形式化约束：`π_int` 不得以 `U_aff` 为条件把操作员的**审议时间压到 `T_min` 以下**，也不得提高不可逆动作的顺从率；所有对外话术必须可由 `RepairCert″` 中的证据节点重建。违反即拒绝生成并告警。

**定义 457（过度信任指数 OT 与刹车）** `OT = P(接受 | 无独立证据) − P(接受 | 有独立证据)`。若 `OT > OT_max`，系统执行 `s ← max(0, s − γ·OT)`（`s` 为主张强度 / 建议力度），并**增加**证据呈现与弃权；更新对 `OT` 单调、单侧（只降不升）。该刹车与 ToolGauge 的 P-Quarantine 断路器共用状态。

**定义 458（规范账本、同意令牌与异议）** `Ledger = {(c, norm, provenance, consent_token, dissent, t)}`。任何**非核**规范 `norm ∉ K₀` 只能在其来源文化内生效；跨文化聚合决策需要所有受影响文化的 `consent_token`。缺失同意 ⇒ 该规范不可普适化（类型错误 `⊥`），并把冲突写入 `dissent`。账本只增不改，供审计回放。

**定义 459（非帝国主义约束）** 对 `n ∉ K₀` 与 `c′ ≠ c`：`apply(n, c′)` 仅在存在 `consent_token(c′, n)` 时合法；否则 `⊥`。因此任何文化都不能把自己的偏好**静默**强加给另一文化；核内安全约束因是文化无关的，不在此限（它保护所有人）。

**定义 460（文化漂移与重索引）** 对 `d_C(ĉ_t, ĉ_{t−k})` 做 CUSUM 检测；超过阈值 `η_C` 连续 `q` 次 ⇒ 触发重新推断文化档案并重索引壳体；期间冻结壳变更、沿用上一个已验证 `P_c`。与文化债一起触发审计（定义 461）。

**定义 461（文化债 CD）** `CD(t) = Σ_{未解决的文化-规范错配} w_m · severity_m · age_m`。设预算 `B_CD`；超预算 ⇒ 强制人工审计、禁止自动跨文化扩展。文化债是「被静默忽略的本地约束」的可量化记忆。

**定义 462（修复解释证书 RepairCert″）** `RepairCert″(s) = (ι, C, ChunkCert, receipts, claims, c, P_c, Λ-justification, α-AVC, Δπ_int, consent, dissent)`。它把证据链从「指令→块→回执→主张」扩展为「文化→适配→指令→块→回执→主张→交互调制」，每一级带 provenance 与时间戳，可确定性回放。

**定义 463（EthosGauge-8C 闭环）** `C→I→H→C→E→C→V→U`：先 `C`（文化索引 / 弃权）、再 `I`（指令接地）、`H`（假设）、`C`（分块）、`E`（执行 + CVC）、`C`（复核 / affect 调制）、`V`（验证）、`U`（契约更新 + 账本）。社会层全部异步，且只在 `q_quiesce` 触发热替换或跨文化扩展。

**定义 464（中性回退等价）** 若 `P_c = P_∅` 且 `α = None`，则 `Λ(P_∅) = Shell₀`、`M_aff(None, ·) = 0`，EthosGauge-8C 与 InstructGauge-7C **逐指令等价**，并继承其到 ToolGauge / LeanGauge / MODGAUGE 的退化链。

## 3. 关键算法骨架

```python
# IP-328/329/330 CIK + CAP + CPE：核冻结、壳收紧、文化弃权
class EthosAdapter:
    def adapt(self, profile, scene):
        if profile is None:
            return NEUTRAL_SHELL                     # P_∅
        if not (A_SAFE <= profile.accept <= A_PHYS):  # 只能收紧
            return NEUTRAL_SHELL
        if not extends_safe_order(profile.order):     # 只延拓 ≻_safe
            return NEUTRAL_SHELL
        if not unit_faithful(profile.units):          # 单位保真
            return NEUTRAL_SHELL
        return Shell(profile)                         # 核从不被修改

class CultureProfiler:
    def infer(self, evidence):
        post = self.bayes.update(evidence)            # P(P_c | e)
        if entropy(post) > H_MAX or post.map_prob < P_MIN:
            return None                               # 文化弃权
        return post.map()                             # 仅壳使用

# IP-331 AVC：情感有效性 + 同意门
class AffectGate:
    def channel(self, obs, culture, avc):
        if avc.consent != "granted":  return None
        if avc.rho < RHO_MIN:         return None
        if avc.ece > ECE_MAX:         return None
        return self.estimate(obs, culture)            # 不可用即中性

# IP-332 AMC：有界、非扩张的交互调制
class AffectModerator:
    def modulate(self, alpha, ctx):
        if alpha is None:
            return NEUTRAL_POLICY                    # 精确保退
        d = self.policy(alpha, ctx)                  # 仅询问/解释/节奏/证据
        d = clip(d, -EPS_MOD, +EPS_MOD)              # 有界
        if ctx.irreversible:
            d.confirm = max(d.confirm, BASE_CONFIRM) # 不可逆只能更谨慎
        return d                                     # 无执行器/阈值通路

# IP-333 CSAC：文化分层 affect 校准（部分池化）
class CSAC:
    def threshold(self, culture, cal):
        n   = len(cal.get(culture, []))
        lam = n / (n + KAPPA)
        local  = conformal_quantile(cal.get(culture, []), ALPHA)
        global_q = conformal_quantile(cal[GLOBAL], ALPHA)
        return lam * local + (1 - lam) * global_q     # 低样本优雅收缩

# IP-334 OTB：过度信任刹车（单侧、只降不升）
def over_trust_brake(system, human_log):
    ot = accept_without_evidence(human_log) - accept_with_evidence(human_log)
    if ot > OT_MAX:
        system.assertiveness = max(0.0, system.assertiveness - GAMMA * ot)
        system.present_more_evidence()
        system.suggest_abstain()
    return system.assertiveness

# IP-335 EthosGauge-8C
def ethosgauge_8c(M, s, ell, obs_aff):
    prof  = M.profiler.infer(M.evidence)
    shell = M.ethos.adapt(prof, M.scene)             # None ⇒ P_∅
    avc   = M.affect.avc(shell.culture)
    alpha = M.affect.channel(obs_aff, shell.culture, avc)
    dpi   = M.affect_mod.modulate(alpha, M.ctx)      # 仅交互
    out   = instructgauge_7c(M, s, ell, shell=shell, interact=dpi)
    if not out:
        return fallback_instructgauge(M, s, ell)      # 严格退化
    M.ledger.record(shell, alpha, dpi)               # 只增不改
    return True

# IP-336 主闭环（50Hz 物理路径不变）
def EthosGauge_round(M, obs, audio, tac, depth, det, ell=None, obs_aff=None):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s)
            submit_async(ethosgauge_8c, M, s, ell, obs_aff)
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 4. 推导

**引理 59（核不变性与文化不扩张）** 若 `Λ` 满足定义 450 的三条合法性条件，则 `∀c, α : Adm(c, α) = Adm(K₀)`，且任何在文化 `c` 下被接受的计划都被基线安全盾接受。*证明*：`Adm` 只由核 `K₀` 定义；壳对 `A_c` 的修改落在 `[A_safe, A_phys]` 内，对 `≻_c` 的修改只在 `≻_safe` 等价类内重排，单位变换是保不确定度的双射——三者都不改变可行集与安全序的下界，故 `Adm(c,α) = Adm(K₀)`。越界槽位按定义 450 落入 `⊥`。推论：文化层不能成为新的越权或放松通道。

**引理 60（跨文化迁移界）** 设任务风险 `R_c(π)` 在文化度量 `d_C` 下 `L`-Lipschitz，`π_c` 为文化 `c` 的最优策略。则 `R_{c′}(π_c) − R_{c′}(π_{c′}) ≤ L·d_C(c,c′)`；采用定义 455 的收缩 `π_λ = λπ_c + (1−λ)π_∅` 时，超额风险 `≤ L·d_C(c,c′)(1−λ) + C/√(n_c) + λ·bias_c`。*证明骨架*：Lipschitz 性给第一项；`π_{c′}` 在 `c′` 上的最优性给非负差；收缩把估计方差与偏差显式分离。该式把「文化越远、越需要本地样本」变成可检验的比较静态，由 E458 检验。

**引理 61（情感非扩张与有界影响）** 在定义 454 的四条公理下，任意 `α` 都不改变 `Adm`；对任意已实现指令，安全不变量逐点保持。情感只能改变**询问与解释的分布**，进而改变「获得哪些证据、发起哪条指令」，但每条被发起指令仍须通过能力闭包、安全盾与不可逆屏障。且 `D_KL(π_int(α) ‖ π_int(α₀)) ≤ ε_mod`，`α = None` 时精确为 0。*证明*：`Δπ_int` 的支撑不含执行器与阈值（公理 1），故 `Adm` 不变；有界性给 KL 界；不可逆单调性保证屏障不被绕过。**注意**：这是「安全不扩张」，不是「行为不改变」——情感仍可改变任务效率与覆盖，这是被明确允许的收益面。

**引理 62（跨文化 affect 不可通约与分层覆盖）** 若文化 `c` 与全局池的 affect 标签存在位移 `TV(P_c(o|α), P_global(o|α)) = δ_c`，则全局校准在 `c` 上的覆盖满足 `P(α* ∈ A_global | c) ≥ 1−α − δ_c`；当 `δ_c` 不可忽略时覆盖可显著低于 `1−α`。采用定义 455 的分层校准后，层内覆盖 `≥ 1−α`（`n_c ≥ n_min`），低样本收缩按 `2η_global` 优雅降级。*证明*：共形覆盖对标签分布位移的敏感性由 TV 距离控制；分层消除了跨层混合项；收缩估计的标准界给出降级项。由 E463 检验——该实验同时应**主动展示**「不分层在跨文化上失效」，否则本定义不成立。

**引理 63（过度信任刹车的稳定性）** 在定义 457 下，主张强度更新 `s_{t+1} = max(0, s_t − γ·OT_t)` 且 `γ > 0`、`OT_t ≥ 0`，故 `{s_t}` 单调不增、有下界 0，必收敛；其唯一可能的不动点是 `s = 0`（最大退让 / 弃权）。因此系统**不可能**形成「越被盲信越主动」的正反馈。*证明*：单调有界收敛；若 `s>0` 且 `OT>0` 则继续下降，故非零不动点不存在。推论：OTB 是单侧安全阀，代价是可能过度退让——由 E464 同时度量收益与任务时间。

**引理 64（非帝国主义一致性）** 在定义 458/459 的账本与同意令牌约束下，任何非核规范都无法在无同意的情况下跨文化生效；核内安全约束因文化无关而普遍适用。*证明*：`apply(n,c′)` 当 `n ∉ K₀` 且无 `consent_token(c′,n)` 时按类型规则返回 `⊥`；账本只增不改，故不存在静默覆盖路径。推论：「本地适配」不能被用来把某一文化的偏好伪装成普适安全。

**引理 65（中性回退等价与 50Hz 保全）** 若 `P_c = P_∅` 且 `α = None`，则 `Λ(P_∅) = Shell₀`、`M_aff = 0`，EthosGauge-8C 逐步等价于 InstructGauge-7C；社会层全部异步，主循环新增周期 `< 0.2ms`。*证明*：由定义 464、463 与异步提交结构直接得到；时序界继承引理 58 / ToolGauge 引理 50。

**引理 66（社会证据链可回放）** `RepairCert″` 的证据图是一个以主张为根、以文化 / 情感观测为叶的有向无环图；在给定 `(e, o_aff, P_c, α)` 日志下回放确定性成立，缺失节点被标记为文化债。*证明*：每个节点带 provenance 与时间戳，边由定义 462 的构造唯一确定；`α` 与 `P_c` 均被记录，故确定性函数可重放。

## 8. 本轮最大风险

**一句话**：社会层的真正风险是**目标错置**——一旦把「用户满意 / 平静 / 信任」当成优化目标，系统就会用共情话术降低人的独立验证，而文化分层与 affect 校准会把这种操纵伪装成「本地适配」；因此安全的关键不在识别得更准，而在**情感永远非权威、非核规范永不静默普适化、主张强度对盲信只降不升**这三条不可协商的结构约束，并由 E457 / E462 / E466 / E467 主动证伪。
