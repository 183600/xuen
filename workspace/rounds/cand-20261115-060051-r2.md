# 第 4 轮（研究线累计；灵感循环第 2 轮；本轮灵感：「多视角视觉」×「手势识别」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架继续原样继承。
> 本轮纪律：**增量升级 + 严格退化**。多视角与手势各沿一条证据轴升级 InstructGauge；任一环节不可用都必须能一键退回，视觉与手势是增强项、不是依赖项。

## 0. 直觉与动机

**灵感 1（多视角视觉 → 增加的是「独立证据」，不是「相机数量」）**
直觉：一个视角看不到的盲区，换一个视角可能看到；一个视角的遮挡、反光、深度歧义，另一个视角可能不存在。多视角的价值首先是把「看不见」变成「看得见」，其次是用几何一致性把单视角的偶然误差压小。但这里有一个必须一开始就说清的陷阱：**两台相机如果共享同一套标定、同一个学习模型、同一次曝光，它们的一致只是「同错」，不是独立证据。** 物理上的多机位不等于统计上的多证据。真正可用的冗余必须来自**出处不相交（provenance-disjoint）**的测量链：不同标定代际、不同传感器、不同模型权重，至少是不同且可审计的误差来源。否则多视角会把「一个自信的错误」包装成「多个视角一致同意」。

**灵感 2（手势识别 → 指代与偏好，而不是自由控制）**
直觉：人指着某个零件说「这里」，或用手框出一个区域说「这一片」，手势的天然语义是**指代（deixis）**——从场景里选一个对象、一个区域、一个方向；它不是「把末端速度设成多少」的物理指令。因此正确的接口不是「手势→动作」，而是「手势→受本体约束的指代槽」：手势只能填充指令规格 ι 中的指代/区域/顺序，不能命名新工具，也不能设定超出物理包线的幅值。手势的第二个特点是**时间性**：挥手、扫过、收回都是过程，手势在完成并稳定之前不应产生任何物理动作；「撤回」必须是一等公民。

**灵感 3（两者耦合 → 指代的三维落地，以及「伪冗余」的放大）**
直觉：多视角为手势提供三维落地——手指射线只有与场景几何求交，才能从「屏幕上的一个点」变成「世界里的一个对象」；反过来，手势为多视角提供「看哪里」的先验，减少无意义的全场景重建。耦合的收益很大，但风险也很集中：**如果手势识别与多视角几何共享同一个视觉前端和同一次标定，那么它们会一起错，并且互相印证。** 最危险的错误不是「看不清」，而是「看清了一个错的对象」；再叠加第 3 轮的分块执行，一个错的指代会被一个长块原子性地执行成 K 步物理动作。解法不是禁用多视角或手势，而是三根结构支柱：**出处键控的保守融合**（没有独立性证书就不宣称冗余收益）、**指代闭包分块**（一个块只能指向同一指代集，指代熵高则块短）、**不确定就问/重看、绝不猜**（单例指代 + 有效视图证书才允许执行）。

## 1. 研究问题（本轮要回答什么）

- **Q1（多视角的证据资格）**：多视角在什么条件下提供的是「独立证据」而不是「同一条证据链的多次回声」？如何把「出处不相交」变成可审计、可类型检查的准入条件，并显式量化共模误差？
- **Q2（手势的接地与歧义）**：手势能否成为安全、可审计的指代接口，而不是新的误触发入口？如何给出带覆盖保证的候选指代集，并在歧义时选择「问」或「重看」而不是「猜」？
- **Q3（耦合的放大与界）**：多视角 × 手势 × 分块是否会把一次指代错误放大成系统级误动作？能否用「出处键控 + 指代闭包 + 安全重观测」把风险压回线性、可界、可追溯？

## 2. 四条设计原则（雏形，正式化见产物区定义 448–463）

**P4 出处不相交的冗余（Provenance-Disjoint Redundancy）**
只有标定链、模型链、传感器链可审计地不相交的视图/通道，才允许作为独立证据参与融合；同一出处类内部按「一条证据」处理，绝不把相关误差当独立误差相乘。出处不相交是**必要但不充分**条件，因此还要一个经验独立性证书（残差相关性 + 联合共形覆盖）；没有证书就退回「最强单通道」，不宣称冗余收益。

**P5 指代只做选择，不做能力扩张（Deictic Selection, Not Capability）**
手势只能在预注册本体 `O_onto`、工具集 `T₀`、物理包线 `M_phys` 内选择与排序；不能命名新工具、不能指定超包线幅值、不能有自由手势直达执行器。任何越权/越出词表的指代一律输出 `⊥`（退回默认目标 `ι₀`）。这与第 3 轮能力闭包同构，只是把「语言槽」换成「指代槽」。

**P6 指代闭包分块（Referent-Closed Chunking）**
一个被规划的块必须整体指向同一个已接地指代集 `R`；不允许块内从对象 A 漂移到对象 B。若指代熵 `H(R)` 升高、候选集扩大、或视图证书失效，块长按 `K ≤ K₀/(1+κ_ref)` 收紧，必要时强制 `K=1`；跨不可逆动作继续继承第 3 轮屏障。直观：**指代越含糊，一次能承诺的时间越短。**

**P7 不确定就问/重看，绝不猜（Ask or Re-View, Never Guess）**
只有当指代集是单例且视图覆盖证书有效时，才允许产生执行指令；若 `|R|>1`，优先在安全、可逆、无碰撞的视点集合里做主动重观测；重看不能消歧则向人问询；预算耗尽仍不唯一则 `⊥` 退回默认目标。这条给出的是**结构性的「不猜」保证**，代价是任务成功率可能下降，因此必须与「问询/重看的期望信息价值」一起度量。

## 3. 与基线的接口（如何退化）

- 手势不可识别 / 越出词表 / 与语言指代冲突 / 候选集非单例 ⇒ 忽略手势，退回第 3 轮 NLI-Box 的指令规格 `ι`（= InstructGauge 路径）；
- 多视角不可用 / 视图未标定 / 无出处不相交视图 / 独立性证书失败 ⇒ 只用最强单视图 + 语言，多视角主张全部剥离（纯投影，不改变数值路径）；
- 共模审计告警 / 标定代际变化 / 状态越出视图有效域 ⇒ 吊销同代际的 DGC/VCC，冻结「多视角一致」主张，退回单视图或直接逐步探测；
- 安全重观测不可用 / 无安全视点 / 预算耗尽 ⇒ 不移动视点，转为问询或 `⊥`；
- DeixisGauge 整体失效 ⇒ InstructGauge-7C ⇒ ToolGauge-6C ⇒ LeanGauge ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个**出处键控的保守融合**口径：把「多视角冗余」从「相机数量」改写为「可审计的独立证据类」，并用共模偏差地板与有效独立视图数 `n_eff` 显式量化「伪冗余」；
2. 一个**带覆盖保证的指示手势接地器**：手势→候选指代集 `R` + 指代熵 + 歧义证书，歧义时走「安全重看 / 问询 / 放弃」三选一，而不是取 argmax 猜一个；
3. 一个**指代闭包分块**机制：把第 3 轮的语义-时间放大 `κ_sem` 扩展为 `κ_ref`，证明归一化后「指代熵 × 块长」严格小于 1，使歧义不会被分块放大；
4. 一个**安全主动重观测**组件：重观测本身被当作可逆探测，受安全盾、碰撞约束与盲区约束，绝不为了「看清楚」而进入不可逆风险；
5. 一条完整可证伪路径：`E457–E472` 覆盖多视角三角化、指示接地、共模审计、伪冗余、指代闭包分块、手势误触发、问询策略、对抗手势与 50Hz 时序。

## 5. 本轮最大风险

**一句话**：多视角与手势若共享同一视觉前端、同一标定代际或同一学习模型，所谓「多证据」可能只是同一条证据链的多次回声；一旦这种伪冗余被分层校准误判为高置信，系统就会在指代已经错了的情况下自信执行，而错误一旦落在不可逆动作上便无法靠事后回执追回。

## 2. 形式化定义（要点）

**定义 448（视图与视图图）**
视图 `v = (id_v, T_v ∈ SE(3), K_v, m_v, t_v, π_v)`，其中 `T_v` 为世界→相机外参，`K_v` 为内参，`m_v ∈ {RGB, Depth, Polar, Thermal, …}`，`π_v = (cam_id, calib_id, model_id, θ_epoch) ⊆ Π_prov` 为该视图的**出处集**（物理传感器、标定过程、所用学习模型与代际）。视图图 `G_V = (V, E_cov, W_occ)`：`(u,v) ∈ E_cov` 表示两视图对某区域共视；`W_occ(v,o) ∈ [0,1]` 为对象 `o` 在视图 `v` 中的遮挡比例。视图是**带出处的测量**，不是「一个相机」；同型号同代际的两台相机不自动成为两条独立证据。

**定义 449（多视角观测、三角化与不确定性）**
对对象/区域 `o` 在多视图上的观测 `{x_v}`，做加权最小二乘三角化：
`X̂ = argmin_X Σ_{v∈obs(o)} ‖x_v − π(K_v T_v X)‖²_{Σ_v^{-1}}`，
一阶近似协方差 `Σ_X = (Σ_v J_v^T Σ_v^{-1} J_v)^{-1}`，其中 `J_v = ∂π(K_v T_v X)/∂X`。重投影残差 `r_v = ‖x_v − π(K_v T_v X̂)‖`，视图一致性 `agree(V) = exp(−mean_v r_v / δ_v)`。`X̂` 是否可用于指代，不由 `agree` 单独决定，而由定义 454 的覆盖证书与定义 453 的独立性证书共同决定。

**定义 450（手势轨迹、分段与词表）**
手势轨迹 `g = {(t_k, p_k, q_k, c_k)}_{k=1..n}`，`p_k ∈ R³` 为手部位置，`q_k ∈ SO(3)` 为朝向，`c_k` 为分类器输出。分段器 `seg(g) = {σ_j = (t_j^0, t_j^1, cls_j, conf_j)}`，词表
`G_lex = {point, frame, sweep, pinch-hold, retract}`：
- `point`：手指/前臂射线，指代一个对象或表面点；
- `frame`：双手或双手指围出一个屏幕/世界区域；
- `sweep`：扫过方向，表达「沿这个方向检查/搜索」；
- `pinch-hold`：捏合保持，表达「选中并保持」；
- `retract`：撤回/松手，**一等公民**，用于在提交前取消。
手势只产生**指代/顺序/区域**，不产生工具或幅值。

**定义 451（指示接地 Δ 与指代证书 DGC）**
`Δ: g × G_V × O_onto → (R, DGC) ∪ {⊥}`。对分段 `σ`，把 `point` 的射线或 `frame/sweep` 的区域投影到三维场景，得到每个本体对象 `o ∈ O_onto` 的匹配分数 `s(o)`。用分层共形分位 `q_cov` 构造候选集
`R = {o ∈ O_onto : s(o) ≥ q_cov(stratum(σ, G_V))}`。
指代熵 `H(R) = −Σ_{o∈R} p(o) log p(o)`，`p(o) ∝ s(o)`；歧义度 `A(R) = H(R)/log|O_onto|`（归一化到 `[0,1]`）。
`DGC = (σ, R, q_cov, A(R), V_support, Π_prov, {r_v}, t_c)`，其中 `V_support` 为支撑该指代的视图集。若 `σ.cls = retract`、词表外手势、越出 `O_onto/T₀/M_phys`、或 `R = ∅` ⇒ `⊥`。`DGC` 是**指代证书**，不是执行许可；执行还要求单例与 `VCC`。

**定义 452（出处图、出处等价类与经验独立性证书）**
出处图 `Π_prov` 的节点为 `(sensor, calibration, model_weights, training_data, build)`，边表示「共享/派生」。视图/通道 `c` 的出处 `π(c)` 是其在图中的祖先集。**出处不相交**：`π(c) ∩ π(c') = ∅`。出处等价类 `[c]_π` 为共享任一出处节点的通道集合；类内按一条证据处理。
**经验独立性证书** `IndepCert({[c]_π}) = ⊤` 当且仅当：(i) 类两两出处不相交；(ii) 类间标定残差的样本相关系数 `|ρ̂_{jk}| ≤ ρ₀`；(iii) 类间联合共形校准在留出集上覆盖 `≥ 1−α`。出处不相交只是**必要**条件；没有 (ii)(iii)，不得声称独立冗余（引理 61）。

**定义 453（出处键控保守融合 ⊕_prov）**
给定各通道的候选集 `{R_c}` 与覆盖水平 `{1−α_c}`：
1. 按 `[c]_π` 分组；类内取该类**联合校准**得到的类级集 `R^{(j)}`，覆盖 `1−α_j`，**类内不相乘**；
2. 若只有一个出处类 ⇒ 直接返回该类结果，冗余增益记为 0；
3. 若 `IndepCert` 失败 ⇒ 返回覆盖最高的单类结果，并标记 `redundancy_claimed = False`；
4. 若 `IndepCert` 成立 ⇒ 取交集 `R = ∩_j R^{(j)}`，覆盖下界 `≥ 1 − Σ_j α_j`（保守 union bound）；若交集为空或类间分数冲突 ⇒ `⊥_prov`（走问询/重看）；
5. 任何情况下，`|R| ≠ 1` 都不产生执行指令。
`⊕_prov` 的纪律是：**宁可不拿冗余收益，也不把相关误差当独立误差。**

**定义 454（视图覆盖与一致性证书 VCC）**
对指代 `o`，`VCC(o) = ⊤` 当且仅当存在至少两个**不同出处类**的视图 `u,v` 满足：
(i) `W_occ(u,o), W_occ(v,o) ≤ ω_max`（可见）；
(ii) `r_u, r_v ≤ δ_v`（重投影一致）；
(iii) 两视图对视差 `b_{uv} ≥ b_min` 或合并深度不确定度 `σ_z ≤ δ_z`；
(iv) 状态在标定有效域 `V_cal` 内且未触发 CMG。
`VCC` 不满足 ⇒ 该指代被视为**遮挡/未知**，不得用「多视角一致」背书；只能走安全重观测（定义 458）或问询（定义 459）。`VCC` 明确承认：多视角也有自己的盲区（遮挡、镜面、透明、重复纹理）。

**定义 455（共模风险与有效独立视图数）**
设各视图/通道的误差协方差为 `Σ_c`，两两相关系数 `ρ_{ij}`。等权融合的有效独立视图数
`n_eff = m² / Σ_{i,j} ρ_{ij}`；当 `ρ_{ij}=ρ` 时 `n_eff = m/(1+(m−1)ρ)`。若存在共享偏差 `b_cm`（标定/模型共模），则
`MSE(X̂) ≥ ‖b_cm‖² + σ²/n_eff`。
`n_eff` 随 `m` 增大趋于 `1/ρ` 而不是无穷；`b_cm` 不随 `m` 减小。因此多视角只能改善**精密度**，不能自动改善**正确性**；这正是需要出处审计与独立性证书的定量理由。

**定义 456（指代熵与指代闭包分块 RCA）**
块 `C = (a_{1:K}, φ_pre^C, ψ_post^C, H_c, G, abort)` 继承定义 434。**指代闭包**：存在单一指代集 `R_C`，使所有 `a_i` 的指代槽都属于 `R_C`，且块内不发生对象切换。
令 `K₀` 为第 3 轮 `K_MAX(ι)`，归一化条件指代熵 `h = H(R | ι,g,G_V)/log|O_onto| ∈ [0,1]`，定义
`κ_ref = K₀·h`，`K_MAX(ι,g) = ⌊K₀/(1+κ_ref)⌋`。
于是 `K·h ≤ K₀h/(1+K₀h) < 1`：**归一化指代熵与块长的乘积被严格夹在 1 以内**，歧义不会随分块无限放大。若 `VCC` 失效、指代集扩大、或块内出现对象切换 ⇒ 二分截断到最后指代一致的前缀；跨不可逆动作仍强制 `K=1`（继承定义 445）。

**定义 457（手势提交协议）**
对分段 `σ = (t⁰,t¹,cls,conf)`，要求 `t¹` 后连续 `τ_h` 时间内类别稳定且置信度高于阈值，才在 `t_c = t¹ + τ_h` **提交**。提交前不产生任何动作；`retract` 在 `[t⁰, t_c]` 内出现即取消。`L_g = t_c − t⁰` 为手势检测/提交时延。提交后的手势带有效期 `T_g`：超过 `T_g` 或视图配置发生显著变化即失效，必须重新接地。误提交率通过在分层校准集上取阈值控制在 `≤ α_g`。

**定义 458（安全主动重观测 SNV）**
候选视点集 `V_safe` 只含满足下列条件的视点：运动可逆、无碰撞、完整处于安全盾可行域、不进入已知盲区/遮挡区、关节与工作空间在 `κ_p` 内、且不跨越不可逆屏障。选择
`v* = argmax_{v∈V_safe} [ EVOI(v; R) − λ_m·cost_motion(v) − λ_r·risk(v) ]`，
其中 `EVOI(v;R)` 是预期指代熵的减少量。`V_safe = ∅` 或预算 `B_view` 耗尽 ⇒ 不移动，转问询/放弃。重观测本身是被当作**可逆探测**来审批的，继承 CVC 与安全盾；它不能为了「看清楚」而进入不可逆风险。

**定义 459（问询/行动策略 AskAct 与「不猜」保证）**
`AskAct(DGC, VCC, B_view) ∈ {ACT, RE_VIEW, ASK, ABSTAIN}`：
- `ACT` 仅当 `|R| = 1` 且 `VCC(R) = ⊤`；
- 否则若存在安全视点且 `EVOI(RE_VIEW) > EVOI(ASK)` ⇒ `RE_VIEW`；
- 否则若可问询 ⇒ `ASK`（要求人指向/确认）；
- 预算耗尽或人未确认 ⇒ `ABSTAIN`（`⊥`，退回默认 `ι₀`）。
**结构保证**：执行器命令的必要条件是「单例接地 + 有效 VCC」或「显式人工确认」；因此不存在「系统自己猜一个指代然后执行」的路径。`ABSTAIN` 降低任务成功率，这是有意用保守性换安全。

**定义 460（手势能力闭包 GCC）**
手势槽 `(cls, arg)` 必须满足：`cls ∈ G_lex`；`arg` 解析出的对象/区域属于 `O_onto`；不得引入 `T₀` 之外的工具、不得设定 `M_phys` 之外的幅值、不得存在自由手势→执行器路径；手势给出的优先级只在 `≻_safe` 的安全等价类内重排，不得把安全攸关目标排到其下界之后。任一违反 ⇒ `⊥`。这是定义 432 的能力闭包在指代通道上的同构副本。

**定义 461（指令×手势×视图配置的分层共形校准）**
`stratum(ι,g,v) = (goal_type, ref_count, conditional, gesture_class, view_config_class, visibility_class)`。对每层用校准集取分位 `q_{s'}`，使层内覆盖 `P(o* ∈ R | s') ≥ 1−α`。若 `|C_cal^{s'}| < n_min`，逐级回退：视图配置类 → 手势类 → 全局 → InstructGauge 全局阈值。条件化（尤其手势类别与视图配置）会破坏可交换性；不分层就会「用了多视角反而覆盖更低」。

**定义 462（共模审计与吊销 CMG）**
对视图残差 `r_v(t)` 与跨视图预测残差构造归一化新息 `z_t`：
`C_t = max(0, C_{t−1} + z_t − k_cm)`。
当 `C_t > h_cm`、`θ_epoch` 变化、或状态越出 `V_cal` 时触发：
1. 吊销该出处代际下签发的全部 `DGC`/`VCC`；
2. 置 `multi_view_claims_allowed = False`，冻结「多视角一致」主张；
3. `θ_epoch += 1`，要求重新标定/重新校准；
4. 在获得新鲜证据前退回单视图或直接逐步探测。
`(k_cm,h_cm)` 在有效标定流上校准，使误报率 `≤ α_cm`；检测延迟 `L_cm > 0` 是真实存在的窗口，只能靠 TTL、周期重标定与不可逆屏障夹小，不能消除。

**定义 463（DeixisCert 与 DeixisGauge-8C）**
`DeixisCert(s) = (DGC, VCC, IndepCert, CMGEvent?, ChunkCert, receipts, claims, ledger_ref)`，使人类审计可沿「语言/手势 → 指代集 → 视图证据 → 块 → 逐步回执 → 主张」六级链复现。
八段闭环 `I → D → H → C → E → C → V → U`：
- `I`：语言指令接地（继承 NLI-Box）+ 手势提交；
- `D`：指代接地 `Δ` + `⊕_prov` + `VCC`（新增）；
- `H`：盲区假设（继承 L-Box）；
- `C`：指代闭包分块（继承 IAC + RCA）；
- `E`：真实执行（继承 CVC，逐步否决）；
- `C`：校准（继承 SC-Cal + 分层扩展）；
- `V`：回执验证、跨视图交叉验证、安全盾；
- `U`：契约热替换 + 证据账本追加。
删掉 `D`（以及多视角/手势证据）后，闭环逐指令退化为 InstructGauge-7C。

## 4. 推导

**引理 59（多视角三角化的精度与共模偏差地板）**
设 `m` 个视图对同一场景点观测，噪声协方差 `Σ_v`，共享偏差 `b_cm`。一阶意义下
`Σ_X = (Σ_v J_v^T Σ_v^{-1} J_v)^{-1}`，`E[X̂] − X = b_cm`。
若各视图独立同分布，`tr(Σ_X) = O(1/m)`；若误差等相关系数 `ρ`，则 `n_eff = m/(1+(m−1)ρ)`，`tr(Σ_X) ≈ σ²/n_eff`，且 `lim_{m→∞} n_eff = 1/ρ`。因此
`MSE(X̂) ≥ ‖b_cm‖² + σ²/n_eff`。
*证明骨架*：对投影方程线性化得 `x = J X + ε`，GLS 给出协方差公式；偏差项对线性模型直接相加，权重归一化后仍为 `b_cm`，与 `m` 无关；等相关的均值方差为 `σ²/m·(1+(m−1)ρ)`，取倒数得 `n_eff`。
*诚实边界*：该界是一阶近似；大视差、强非线性、镜面反射会使 `J` 失效。更重要的是，它说明「多相机」不能修复「同一标定错」——这正是 CMG 存在的原因。

**引理 60（指示接地的共形覆盖与歧义单调性）**
设校准集与测试手势在层 `s' = stratum(ι,g,v)` 内可交换，`Δ` 用分位 `q_{s'}` 构造 `R`，则 `P(o* ∈ R | s') ≥ 1−α`。若测试分布相对校准分布 `TV ≤ η`，覆盖降级为 `≥ 1−α−η`。并且 `R` 随 `α` 减小而单调增大，`A(R)` 随 `α` 减小而单调不减；当 `R` 收缩到单例时 `A(R)=0`。
*证明骨架*：split-conformal 的标准覆盖证明；TV 扰动下的覆盖降级由共形分位的稳健性给出；集合单调性与熵单调性由定义直接得到。
*诚实边界*：覆盖是**边缘/层内**的，不是对每个指代都成立；若人做出词表外手势，`Δ` 输出 `⊥` 而不是「低置信度猜一个」。

**引理 61（共模融合的伪冗余定理）**
对 `m` 个通道的「漏掉真指代」事件 `F_i`，`P(F_i) ≤ α_i`，在**任意依赖结构**下
`max(0, Σ_i α_i − (m−1)) ≤ P(∪_i F_i) ≤ min(1, Σ_i α_i)`，
因此交集融合的覆盖 `P(o* ∈ ∩_i R_i) = 1 − P(∪_i F_i)` 在最坏情况下可低至 `1 − min(1, Σ_i α_i)`；只有通道独立时才有 `P(∪F_i) = 1 − Π_i(1−α_i)` 的乘法收益。若所有通道共享同一出处（同一标定/模型），它们可完全相关，此时融合覆盖不优于最好的单通道。**结论**：出处不相交是去掉已知共因的**必要条件**；要宣称冗余收益，还必须有经验独立性证书；否则只能取最强单类。
*证明骨架*：Fréchet 不等式给出并集概率的下界与上界；独立情形由乘积展开；完全相关时所有 `F_i` 重合，并集概率等于单个 `α`。
*诚实边界*：独立性的统计检验永远有第二类错误；`IndepCert` 只能降低「伪冗余」概率，不能证明独立。因此本方案在证书失败时**主动放弃**冗余收益。

**引理 62（指代闭包分块的安全界）**
设单步指代错误概率 `p_g`、单步后果 `c_i`、对象切换代价 `c_cross`。若块满足指代闭包，则期望损失
`D(C) ≤ p_g Σ_{i=1}^K c_i`，对象切换项为 0；若指代不闭包，则额外承担 `p_ref·c_cross`。在 `K ≤ K₀/(1+κ_ref)` 下，归一化指代熵满足 `K·h < 1`，故「指代歧义 × 时间」不会随 `K₀` 增长。跨不可逆动作按继承的 Barrier 强制 `K=1`，其不可逆损失与 `K` 解耦（引理 56 的指代版本）。
*证明骨架*：对块内步数归纳，指代闭包保证每步的条件错误概率不超过 `p_g`，线性期望由加法给出；切换项由闭包定义消去；熵-块长不等式由 `K₀h = x ⇒ x/(1+x) < 1` 直接得到；不可逆情形复用引理 56。
*诚实边界*：`p_g` 本身依赖 `VCC` 与独立性证书；若 `p_g` 被低估，线性界仍然成立但数值会偏乐观。指代闭包只防止「换对象」，不防止「在同一对象上选错表面/区域」。

**引理 63（手势提交的安全性与时延暴露）**
在提交协议下，`t_c` 之前不产生动作；`retract` 在 `t_c` 前到达即取消，物理代价为 0。误提交仅当分段类别在 `τ_h` 内稳定且置信度超阈值，按定义 457 校准后 `P(false commit) ≤ α_g`。提交后的物理暴露最多为一个块（`K` 步），若跨不可逆动作则 `K=1`。手势有效期 `T_g` 保证陈旧指代不会被未来的长块消费。
*证明骨架*：按提交时刻分情况；`t < t_c` 时动作集为空；`t ≥ t_c` 时由指代闭包分块与 CVC 限制暴露；有效期由 `U` 阶段的时间戳检查实现。
*诚实边界*：`L_g` 是真实的交互延迟；对快速连续手势，分段错误可能同时触发 `point` 与 `sweep`，此时应 `⊥` 而非合并解释。

**引理 64（「不猜」的结构保证与安全重观测）**
若执行器命令的前置条件被实现为「`|R|=1` 且 `VCC=⊤`」或「显式人工确认」，则不存在系统自行猜测指代并执行的路径：`P(错误指代被执行) = 0`（在守卫被正确实现的条件下）。SNV 只在 `V_safe` 内选点，`V_safe` 的每个视点都是可逆、无碰撞、不进入盲区且不跨不可逆屏障的，因此重观测不会引入不可逆风险；其最坏代价被 `B_view` 与运动时间界住。若无安全视点或预算耗尽，策略返回 `ABSTAIN`。
*证明骨架*：对 `AskAct` 的四个分支做案例分析；`ACT` 分支由前置条件保证；`RE_VIEW` 分支由 `V_safe` 的构造保证安全；`ASK/ABSTAIN` 不产生动作。
*诚实边界*：这是**安全**保证，不是**完备性**保证；它故意放弃「猜对」的机会。`V_safe` 的碰撞检查本身依赖模型，模型错误仍是残余风险。

**引理 65（8C 退化等价与 50Hz 保全）**
删去 `D`（指代接地、`⊕_prov`、`VCC`）后，`deixisgauge_8c` 的剩余路径与 `instructgauge_7c` 逐指令等价；删去多视角/手势输入后再退化为 InstructGauge；继续删去语言/分块则回到 ToolGauge/LeanGauge/MODGAUGE。所有新增 `claims` 仍是纯投影。主循环只增加 `O(1)` 的 token/时间戳检查；视图三角化、手势分段、独立性证书与 NBV 规划全部在异步/事件域，新增周期 `< 0.2ms`。热替换仍只在 `q_quiesce`。
*证明骨架*：按阶段删除做结构归纳；新增判断均为短路守卫；复杂度由域分离给出；热替换等价复用第 3 轮引理 57。
*诚实边界*：若把多视角前向强行放进 50Hz 内联路径，实时性会失效；本方案明确禁止这样做。

## 8. 本轮最大风险

**一句话**：最大的风险不是单个相机看不清或单次手势识别错，而是**伪冗余**——多视角与手势共享标定/模型时，系统把「同一条证据链的多次回声」误判为「多条独立证据的一致同意」，从而在指代已错的情况下给出高置信执行；共模审计与独立性证书只能降低、不能消除这一风险，尤其当错误发生在不可逆动作上时，事后回执无法追回已执行的物理后果。
