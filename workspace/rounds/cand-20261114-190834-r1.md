# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「运动规划」×「开放词汇」）

> R69 把不确定性一分为二，并让系统学会「问」：看、问、触、等，都是可生成、可认证、可审计的信息动作。但 R69 有两条未言明的前提：**(i) 动作模态只是采样轨迹的聚类簇，从未被运动学/几何可行性认证，也没有把「同伦类」——真正的离散拓扑决策——显式暴露出来；(ii) 语义词表是封闭的，所谓 epistemic 歧义只覆盖「模型已学的几个模态里选哪个」，无法表达「真正的答案根本不在选项里」。**
>
> 本轮的 two inspirations 正好补上这两块：
> - **运动规划**给出「受约束的可行路径 + 同伦类 + 安全走廊 + 重规划」——把 R69 的「模态」从动作簇提升为**带风险证书的拓扑类**；
> - **开放词汇**给出「目标/障碍本身是一个可含 UNK 的信念分布」——把 R69 的「模态权重」提升为**开放词汇标定下的操作等价类后验**。
>
> 核心命题：**先接地（semantic），后规划（topological），最后才在安全走廊内交给 R69 的流策略做局部细化；语义不确定与拓扑不确定必须分开处置，因为规划是在成本场里做的，而成本场本身由标定决定——在错误的世界里做正确的规划，是比 R69 更贵的错误。** 命名 **LEXPLAN-RAS**（Language-EXpanded open-vocabulary Planning with Abstention）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**这句话到底指哪个东西，这个世界又允许我从哪一边走？**」

## 0. 直觉与动机

**灵感 1（运动规划 → 动作不是一次采样，而是一条受约束的可行路径 + 一个同伦类）**
直觉：R69 的 FMP 采样 K 条动作块、聚成模态、算模态熵与间距。问题在于这些「模态」活在原始动作空间里：两个「模态」可能其实是同一个同伦类（都从障碍左侧绕，只是速度不同），而某个看起来最可能的模态可能根本运动学不可行、或穿越了一条窄到容不下误差的缝隙。运动规划贡献三样 R69 缺的东西：**(a) 全局可行性**（能到不等于能安全到）；**(b) 同伦类**作为真正的离散决策变量（绕左/绕右/上翻/下钻是拓扑上不同的选择，不能靠距离聚类区分）；**(c) 安全走廊与风险证书**（给定感知噪声，碰撞概率可被净空半径界定）。于是正确的架构是：**用运动规划枚举并认证同伦类，用 R69 的流策略在选定的「走廊管」内做局部动作细化。** 流策略从「全局提议者」降级为「局部细化器」——这是本轮最重要的结构反转。

**灵感 2（开放词汇 → 目标是一个可含 UNK 的信念分布，不是一个固定标签）**
直觉：R69 的交互假设「答案在已知模态里」。但真实指令是开放词汇的：「把那个透明但摔不碎的容器递给我」「绕开那个像椅子的东西」。开放词汇接地的输出不应是一个标签，而应是一个**credal set（可信集）**：覆盖真实标定、允许 UNK、能说「我认识的概念都不匹配」。关键在于：**不是所有标签歧义都重要**——两个标签若诱导的成本场在可达域内几乎相同，它们就是**操作等价**的；只有操作不等价的歧义才值得花交互预算去消解。这给出一个既省算力又诚实的判据：**用「计划遗憾」而非「标签熵」来度量语义不确定性**。

**灵感 3（对偶 → 语义不确定 × 几何/拓扑不确定必须分两阶段）**
直觉：R69 的所有不确定性都进同一个 λ floor。R70 里它们是**因果串联**的：语义（这是什么、目标在哪）决定成本场 `c(x|w)`，成本场决定同伦类是否可行、代价多少，同伦类决定走廊，走廊决定流策略的局部模态。若语义未定就规划，等于在**一个可能不存在的世界里**求最优路径；此时越精确的规划反而越危险（冲突：R69 的「问错比不问更危险」在 R70 变成「在错世界上规划，比不规划更危险」）。因此纪律是：**先接地并认证语义，再做同伦规划；语义若在预算内不可解，就做「语言无关的安全动作」（退到观察位、保持距离、停），而不是硬套一个最近标签。**

**灵感 4（严格包含 → R69 = 封闭词表 + 单一同伦类的退化）**
直觉：若未知质量 `m_unk=0`、可信集退化为单点（封闭词表且接地确定），且自由空间里只有一个可行同伦类（`U_topo=0`），则「走廊管」就是整个自由空间，LEXPLAN 逐指令退化为 R69；再若交互无利可图，退化为 R68。于是 **R68 ⊆ R69 ⊆ LEXPLAN** 形成严格包含链，每一层只在旧层失效的边界外增加能力。而且 R70 的收益来自「拓扑分辨率」而非「把一条反应式轨迹压得更紧」——这是效率增益的新来源。

**灵感 5（开放词汇 + 规划 = 新攻击面：语义-几何共谋）**
直觉：R69 的威胁是「问错」。R70 多了一个更隐蔽的威胁：**攻击者把物体摆成「错误标签仍然产生一条看起来可执行的路径」**。例如把危险品贴上安全品的标签，而场景几何恰好在错误标签下也给出可行走廊；此时纯几何残差和纯语义相似度都不会报警。防御必须是**语义-几何对偶**：执行中用实测净空/视差去检验「标签预测的几何」；若语义置信高但几何残差大，判为标签过时或被投毒。这与 R69 的流似然第二意见同构，只是从「行为侧」镜像到「成本场侧」。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（LEXPLAN 总览与不变量）** LEXPLAN-RAS = (OVG, OE Q, HCP, TOU, TFP, LGG, ARI, P2P, SGD, RAS-WM‡)。三不变量：
(i) **接地先于规划**：未通过接地门（定义 316）的语义不得用于生成任务轨迹；
(ii) **认证先于提交**：只有带净空证书 `ρ≥ρ_min` 的同伦类可被提交，且提交后允许的切换保持净空单调不降（定义 324）；
(iii) **零在线词表自扩张**：UNK 只能进入受审计的概念缓冲，不得在线加入词表（继承 R68 零学习写操作的精神，防标签投毒/自我确认）。

**定义 311（开放词汇场景信念）** 场景区域 `r∈ℛ`，词表 `V∪{UNK}`，标注 `w:ℛ→V∪{UNK}`。开放词汇接地器在覆盖水平 `1−α` 下输出 credal set `𝒲_α(o,ℓ_q) ⊆ {w}` 与未知质量 `m_unk(o,ℓ_q)=P(UNK | o,ℓ_q, r*)`，`r*` 为查询定位到的指代区域。若 `𝒲_α` 同时含「`r*` 属于某已知概念」与「`r*` 属于 UNK」的世界，则称**不可判定**。

**定义 312（语言条件成本场与操作等价）** 标注 `w` 诱导成本场 `c_φ(x|w)`（障碍、可 fragility、可通行性、接近代价）。定义操作等价 `w ~_εc w' ⇔ sup_{x∈𝒳_reach} |c_φ(x|w) − c_φ(x|w')| ≤ ε_c`；商空间 `[𝒲_α]` 为**操作等价类**。语义不确定性只在其商空间上计算，未改变成本场的标签差异不计入决策。

**定义 313（语义遗憾）** 给定提交标注 `ŵ`，`π_ŵ` 为按其成本场的最优认证计划。语义遗憾 `R_sem(ŵ)=max_{w∈𝒲_α}[ J_w(π_ŵ) − min_{w'} J_w(π_{w'}) ]⁺`。**决策相关** iff `R_sem > τ_sem`。这是「语义歧义是否值得花预算」的唯一判据；`R_sem=0` 的歧义在决策上不存在。

**定义 314（同伦类运动规划 HCP）** 配置空间 `𝒳`，`w` 下的自由空间 `𝒳_free(w)`，起点 `x_0`，接地目标域 `G(w)`。HCP 返回有限集 `{(κ, p_κ, J_κ, ρ_κ, σ(κ))}`：`κ` 为同伦类，`σ(κ)∈π_1(𝒳_free)` 为其自由群词（类签名），`p_κ` 为类内最优认证轨迹，`J_κ` 为代价，`ρ_κ` 为安全走廊净空半径。认证含运动学/动力学可行、走廊内无碰、时间窗有效。

**定义 315（拓扑不确定性）** `U_topo = H(softmax(−J_κ/τ_J)) · g(Δ_J)`，其中 `Δ_J = J_(2) − J_(1)` 为次优与最优类代价差，`g` 随可分性单调减。语义同 R69 的 `U_epi`，但变量从「动作簇」换成「认证同伦类」。

**定义 316（接地门 LGG 与弃答）** 仅当 `m_unk ≤ τ_unk`、`|[𝒲_α]| = 1`（操作等价类唯一）、且接地校准 `ECE_lex ≤ τ_ece` 时允许提交语义。否则进入**弃答分支**：优先指代交互（定义 317），预算不足则执行**语言无关安全计划**（退到观察位/保持距离/停），其代价上界记为 `ε_safe`。

**定义 317（指代交互 ARI）** `g_ref∈{point/gaze, ask, show/parallax, contact-probe}`。执行经 C-RAS-WM‡ 认证；回答更新 `𝒲_α`。**证据纪律升级**：折叠到一个已知标签需**两个正交证据源一致**（例如嵌入相似度 + 视差/接触物理校验），否则保持 UNK。单次问句只降权，不定案（继承 R69 引理 18）。

**定义 318（plan-to-perceive / 拓扑探针）** 信息轨迹 `g_topo = argmax_g [VoI_topo(g) − c_motion(g)]`，s.t. `g` 自身带认证走廊。典型形式：移动到能同时看见两个同伦类「分隔面」的观察位，或在低速/低力约束下试探通道可通行性。它把「看」纳入同一个运动规划器，而非外挂。

**定义 319（两阶段 VoI 与预算）** `VoI_sem` 与 `VoI_topo` 共享硬预算（单位时间信息动作 ≤1、位移 ≤ ε_g、接触 ≤ c_max）。**顺序纪律**：`R_sem>τ_sem` 时先做语义消歧（因为成本场未定时同伦类本身没有定义）；语义解决后若 `U_topo>τ_topo` 再做拓扑探询。若两者皆无利可图且 `m_unk` 高，走定义 316 的弃答。

**定义 320（语义-几何对偶 SGD）** 执行中对已提交计划 `p_κ` 监测几何残差 `r_plan = |ρ_pred(κ) − ρ_meas| + |occ_pred − occ_meas|`（预测净空/占据 vs 实测）。判据：**语义置信高（`conf > τ_conf`）而 `r_plan > τ_geo` ⇒ 标签过时或被投毒**。这是 R69 流似然第二意见在成本场侧的镜像，用于捕捉「错误标签恰好诱导可执行路径」的共谋。

**定义 321（LEX 证书）** `J_LEX = (J_FLUID, ground_coverage, |[𝒲_α]|, R_sem_before/after, U_topo_before/after, m_unk, σ(κ*), ρ_κ*, r_plan_p95, lex_ver)`。Valid ⇔ `Valid(J_FLUID)` ∧ 接地门通过 ∧ 净空证书满足 ∧ 证据纪律满足 ∧ 预算未越界。

**定义 322（开放词汇对抗集 ℰ_lex）** 同音/歧义提示词、投毒标签、**对抗摆放**（错误标签仍诱导可行路径）、新物理概念（外观同已知类但物理不同）、诱饵指代、UNK 洪水（用大量未知迫使系统永久弃答的 DoS）。并入 AIC：`ℰ_LEX = ℰ_FLUID × ℰ_lex`。

**定义 323（保守链）** `LEX → (robust 成本场 minimax) → R69 局部流 → R68 纯收紧`。每退一级风险单调不增。封闭词表 + 单一可行类 + 无利可图交互 ⇒ 逐指令退化为 R69（进而 R68）。

**定义 324（拓扑重规划与净空单调）** 监测执行计划的类签名 `σ(κ)`；若新观测使 `κ` 失效（新障碍、标签更新、通道被闭），重新枚举同伦类，但**只允许切换到净空 ≥ 当前净空的类**（除非先减速到安全停）。提交/换装不变式（R68 定理 15、R69 定理 17）保持。

**定义 325（受审计的词表扩展）** 持续 UNK 的「指代区域 + 上下文 + 证据」写入概念缓冲；只有人工/离线审计后，概念才可加入 `V`。在线系统**绝不**用自身高置信输出扩充词表（阻断自我确认与投毒）。

## 2. 关键算法骨架

# IP-264 OVG：开放词汇接地 → 可信集（含 UNK）与校准
class OpenVocabGrounder:
    def credal(self, o, query, alpha):
        r_star = self.locate_referent(o, query)            # 指代区域
        s      = self.sim(o, r_star, self.vocab)           # 与 V 的相似度
        m_unk  = 1.0 - self.evidence_mass(s)               # 开放集未知质量
        W      = self.conformal_set(s, m_unk, alpha)       # 覆盖 1-alpha
        return r_star, W, m_unk

# IP-265/266 OE Q + HCP：操作等价商 + 同伦类规划（返回多类，非单解）
def operational_quotient(W, reach, eps_c):
    return quotient(W, key=lambda w: cost_field(w), metric=sup_norm, tol=eps_c)

class HomotopyPlanner:
    def plan(self, w, x0, G_w, roadmap):
        out = []
        for kappa in roadmap.homotopy_classes(x0, G_w):    # 自由群词=类签名
            p = self.optimize_in_class(x0, G_w, kappa)     # 走廊内轨迹优化
            if not self.kinodynamic_ok(p):      continue
            out.append((kappa, p, self.cost(p, w),
                        self.clearance(p, w), roadmap.signature(kappa)))
        return sort_by_cost(out)

# IP-269/275 主闭环：接地 → 语义遗憾 → 同伦规划 → 拓扑探询 → 管内流细化
def LEXPLAN_RAS_round(M, obs, query):
    z, o = M.mtm.forward(obs); c, U_cal, _ = M.cof.step(o)
    # 1) 先接地，且允许"未知"
    r, W, m_unk = M.ovg.credal(o, query, M.alpha)
    if m_unk > TAU_UNK or len(operational_quotient(W, o.reach, M.eps_c)) != 1:
        g = M.ari.choose(o, W)
        if g is not None and M.budget.allow(g) and M.c_ras_wm.certify_info(g, o):
            W = M.ari.update(W, M.ari.execute(g))          # 两源正交一致
        else:
            return M.safe_abstain(o)                       # 语言无关安全计划
    # 2) 语义遗憾：只有"决策相关"的歧义才花预算
    plans = {w: M.hcp.plan(w, o.x0, o.goal(w), M.roadmap) for w in W}
    if max_regret(plans, W) > TAU_SEM:
        g = M.ari.choose(o, W, plans)
        if g is not None: W = M.ari.update(W, M.ari.execute(g))
        else:             W = robust_reduce(W)             # minimax 成本场
    # 3) 拓扑歧义：在（稳健）成本场下枚举并认证同伦类
    K = M.hcp.plan(select_cost_field(W), o.x0, o.goal, M.roadmap)
    if topo_entropy(K) > TAU_TOPO:
        g_t = M.topo_probe.choose(K, o)                    # plan-to-perceive
        if g_t and M.c_ras_wm.certify_info(g_t, o):
            M.hcp.replan_with(M.topo_probe.execute(g_t))
            K = M.hcp.plan(select_cost_field(W), o.x0, o.goal, M.roadmap)
    # 4) 选类：净空证书优先，代价次之；绝不为省时选更窄的通道
    kappa, p, J, rho, sig = select_class(K, rho_min=M.rho_min)
    # 5) 类内"管"：R69 的流策略只做局部细化，不越出走廊
    xi = M.fmp.sample_in_tube(o, p, rho, K=1)
    U_ale, U_epi, modes = M.aud.decompose(xi, z, M.fmp.mode_head)
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + U_epi))
    k   = M.c_ras_wm.certified_prefix(xi.a, o, p, rho)
    tau = M.pi_sigma.prefix_dispatch(xi.a[:k]) * lam
    # 6) 语义-几何对偶：高语义置信 + 高几何残差 = 过时/投毒标签
    r_plan = M.sgd.geo_residual(o, p, rho)
    if r_plan > TAU_GEO and M.ovg.confidence(r) > TAU_CONF:
        M.audit.flag_stale_label(r, W)
    M.vqa_i.submit_async(kappa, sig, W, r_plan)
    return kappa, sig, lam, xi, (U_sem, U_topo, U_epi)

## 3. 推导

**引理 19（操作等价压缩语义空间）** 若 `w ~_εc w'`，则对任意 `x_0,G` 有 `|J_w(π) − J_{w'}(π)| ≤ ε_c·L`（`L` 为计划时域/路径长度的成本 Lipschitz 界）。故决策问题只在商空间 `[𝒲_α]` 上非平凡：**开放词汇不会让决策维度爆炸，只有改变成本场的标签差异才是真歧义**。系：可用「成本场哈希 + 可达域抽样」廉价判定等价，避免对每个标签都做规划。

**引理 20（开放集弃答的安全性）** 在 conformal 覆盖 `1−α` 下 `P(w_true∈𝒲_α) ≥ 1−α`；若仅在 `|[𝒲_α]|=1` 且 `m_unk≤ε` 时提交，则错词表接地率 `≤ α+ε`。弃答分支的风险由构造 `≤ ε_safe`。故当 `ε_safe < E[错误接地的代价]` 时，**弃答严格优于强行套最近标签**。系：开放词汇的正确姿势不是「猜得更准」，而是「知道自己不知道时能安全地不做」。

**引理 21（同伦类的净空风险证书）** 设占据感知噪声有界（标准差 σ），类 `κ` 的认证净空为 `ρ_κ`，则按该走廊执行时碰撞概率 `≤ exp(−c ρ_κ²/σ²)`（机会约束/ROC 界）。因此**同伦类提交给出了 R69 聚类模态从未有过的先验风险界**；系：在代价近似的多个类中应选净空最大者，而非代价最小者——安全不是事后 λ 缩放，而是拓扑层的先验选择。

**定理 18（接地先于规划 / 点估计不可替代认证）** 存在场景使：任何仅用单点估计标注 `ŵ`（即便是 MAP）规划的策略，其期望遗憾 `≥ c_0·(sup_{w,w'}‖c_w−c_{w'}‖_{∞})·L`，随成本场发散而任意大；而两阶段（认证 + 稳健/弃答）策略的遗憾被 `max_{w∈𝒲_α} J_w` 界定。故**提高接地精度不能替代「在可信集上做稳健决策」**——这正是开放词汇下最容易被忽视的失败模式。

**定理 19（LEXPLAN 严格包含 R69 与 R68）** 封闭词表（`m_unk=0`、`|[𝒲_α]|=1`）且单一可行同伦类（`U_topo=0`）时，走廊管 = 全自由空间，LEXPLAN 逐指令等于 R69；若再 `VoI≤c`，退化为 R68。且退化顺序 `LEX→robust→R69→R68` 风险单调不增。故安全侧不再让步，效率侧获得「拓扑分辨率」加成。

**定理 20（安全重规划 / 无突变）** 定义 324 的净空单调约束保证切换只在更宽或等宽走廊内发生；结合 R68 定理 15 的提交/换装不变式与 R69 定理 17，语义更新与拓扑重规划均不产生控制不连续。故「接地改变」不会变成「执行抖动」。

class OpenVocabGrounder:
    def credal(self, o, query, alpha):
        r = self.locate_referent(o, query)
        s = self.sim(o, r, self.vocab)
        m_unk = 1.0 - self.evidence_mass(s)
        return r, self.conformal_set(s, m_unk, alpha), m_unk

# IP-266 HCP：同伦类规划（多类 + 证书）
class HomotopyPlanner:
    def plan(self, w, x0, G_w, roadmap):
        out = []
        for kappa in roadmap.homotopy_classes(x0, G_w):     # 自由群词签名
            p = self.optimize_in_class(x0, G_w, kappa)
            if self.kinodynamic_ok(p):

                            self.clearance(p, w), roadmap.signature(kappa)))
        return sort_by_cost(out)

def LEXPLAN_RAS_round(M, obs, query):

## 4. 推导

**引理 19（操作等价压缩语义空间）** `w~_εc w' ⇒ |J_w(π)−J_{w'}(π)| ≤ ε_c·L`。故决策只在商空间 `[𝒲_α]` 上非平凡：开放词汇不会使决策维度爆炸，只有改变成本场的标签差异才是真歧义；可用「成本场哈希 + 可达域抽样」廉价判定。

**引理 20（开放集弃答的安全性）** conformal 覆盖 `1−α` 下 `P(w_true∈𝒲_α)≥1−α`；仅在操作等价类唯一且 `m_unk≤ε` 时提交，则错词表接地率 `≤α+ε`；弃答风险 `≤ε_safe`。故当 `ε_safe < E[错误接地代价]` 时，弃答严格优于强行套最近标签——**开放词汇的正确姿势不是猜得更准，而是知道自己不知道时能安全地不做**。

**引理 21（同伦类的净空风险证书）** 占据噪声标准差 `σ` 时，按净空 `ρ_κ` 的认证走廊执行，碰撞概率 `≤ exp(−cρ_κ²/σ²)`。故同伦类提交给出 R69 聚类模态所没有的先验风险界；系：代价近似的多类中应选净空最大者，而非代价最小者——安全是拓扑层的先验选择，不是事后 λ 缩放。

**定理 18（接地先于规划 / 点估计不可替代认证）** 存在场景使任何仅用单点标注 `ŵ`（即便 MAP）规划的策略遗憾 `≥ c_0·(sup_{w,w'}‖c_w−c_{w'}‖_∞)·L`，随成本场发散任意大；而两阶段（认证+稳健/弃答）遗憾被 `max_{w∈𝒲_α}J_w` 界定。故**提高接地精度不能替代在可信集上做稳健决策**。

**定理 19（严格包含 R69/R68）** 封闭词表（`m_unk=0`、`|[𝒲_α]|=1`）且单一可行同伦类（`U_topo=0`）时，走廊管=全自由空间，LEXPLAN 逐指令等于 R69；再 `VoI≤c` 则退化为 R68。退化链 `LEX→robust→R69→R68` 风险单调不增，安全不让步，效率获「拓扑分辨率」加成。

**定理 20（安全重规划 / 无突变）** 净空单调约束使切换只发生在更宽或等宽走廊；结合 R68 定理 15 与 R69 定理 17，语义更新与拓扑重规划均不产生控制不连续。

## 7. 本轮最大风险

**一句话**：LEXPLAN 的全部安全性押在「开放词汇接地器的可信集是诚实的」这一前提上——**而开放词汇恰恰是接地器最容易过度自信之处：它会给未见概念分配一个高相似度的已知标签（开放集失败），使 `m_unk≈0`、`R_sem≈0`，于是系统在错误的成本场里做出认证良好、几何可行、却指向错误世界的规划——「在错世界里正确规划」比 R69 的「问错」更危险，因为连提问的动机都被校准误差抹掉了。**

**次级风险与缓解**：对抗摆放/标签投毒（SGD 语义-几何对偶 + ℰ_lex 对抗训练）；可信集覆盖被破坏（在线 conformal + E305 + 弃答门）；同伦枚举在复杂场景爆炸（K≤3 + roadmap 摊销 + 优先队列剪枝）；拓扑重规划抖动（净空单调 + 定理 20）；在线词表自我确认（定义 325 零在线自扩张 + 受审计缓冲）。
