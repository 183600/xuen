# 第 3 轮（灵感循环；本轮灵感：「共情表达」×「扩散策略」）

> **承接基线**：产物区 **ToolGauge**（工具契约探测 + 摊销计量 + 受审 VLA 假设）。状态文件里既有产物已是「第 2 轮产物」，为保持编号自洽，本轮记为**第 3 轮**；谱系：LeanGauge → ToolGauge → **ResonaGauge**。
> **本轮纪律**：先给直觉，再给可证伪的严谨定义；每条灵感都必须落到模块、引理与实验。

## 0. 直觉与动机

### 灵感 A：扩散策略 → 从「单点探测程序」到「探测程序分布」

**直觉。** ToolGauge 的 T-Box 让 VLA 一次前向只吐出一个程序 Π_s，等于对 p(Π | s, H_s) 做点估计。遇到歧义盲区（同一误差图既能解释为材质反光、也能解释为深度缺口），点估计必然模式坍缩，且系统无法向人表达「我自己也不知道该怎么探」。扩散策略把动作序列建模为**去噪生成分布**：从高斯噪声 x_T 出发，逐步 x_{t-1} = 去噪(x_t, c)，条件 c = (φ(s), H_s, T₀, B)。它天然多模态、时序连贯、可随时早停。把 Π_s 换成扩散采样，就得到一族候选程序；候选间的分歧本身就是规划器认知不确定性的可读信号。

**为什么不是「再来一个 VLA」。** VLA 负责「可能是什么故障」（判别式/自回归的语义先验，产出 H_s）；扩散策略负责「可以怎么探」（生成式的动作先验，产出 Π_s 的分布）。二者正交，不能相互替代。

**严谨化的关键难点。** 生成分布不等于可执行：采出的程序可能违反 schema / 前置 / 预算 / 循环。因此不能「采完再检查」，而要在**去噪每一步**把样本投影到契约可行集，并用末端安全盾兜底。这给出「可行性保持」引理，但投影会引入分布偏置——必须显式记账，否则会在未见盲区上把偏置误当能力。

### 灵感 B：共情表达 → 把后验翻译成「有分寸的坦诚」

**直觉。** ToolGauge 的「语言修复证书」是**宣称式**的：它说「我修好了」，却不说「我有多不确定、你凭什么信、你要不要帮我」。共情表达不是情绪化措辞，而是**以对方的风险与认知为中心、校准地披露自身认知状态**：不确定时示弱求助（deference），确定时给可核对的最小证据（receipts），危险时先降速/停手再解释。一句话：**共情 = 让「表达的置信」与「计量的置信」同源**。

**严谨化的关键难点。** 「共情」极易滑向「讨好/操纵」。所以必须把共情写成**硬契约**而非软风格：(i) 表达置信不得超过校准置信（禁止过度宣称）；(ii) 高不确定时强制进入求助/降级动作耦合；(iii) 所有披露语句必须回指有效回执，否则序列化时剥离。

**把两个灵感焊在一起的支点。** 沟通动作（reassure / explain / caution / ask_help / defer）本身也是离散动作序列，可用与探测程序**同一个**扩散策略 + 约束去噪 + 审计骨架生成。于是「探什么」与「怎么说」共享一套可验证结构——这是 ResonaGauge 的核心立足点。

## 1. 形式化定义（定义 432–441）

**定义 432（DDPP：条件扩散探测规划器）** 设程序空间 P（token/参数序列，长度 ≤ L_max）。前向加噪 q(x_t | x_0) = N(√ᾱ_t x_0, (1−ᾱ_t)I)，反向 p_θ(x_{t-1} | x_t, c) = N(μ_θ(x_t, c, t), Σ_θ(t))。训练目标 L = E_{t,x_0,ε}[‖ε − ε_θ(x_t, c, t)‖²]，条件 c = (φ(s), H_s, T₀, B)。采样用分类器无关引导：ε̃ = ε_θ(x_t, ∅) + w·(ε_θ(x_t, c) − ε_θ(x_t, ∅))。

**定义 433（契约可行集与投影）** F(s) = { Π ∈ P : TCV.verify(Π, B) 通过 }。定义 Proj_F(x) = argmin_{y∈F(s)} ‖x − y‖²（离散 token 上用逐位局部搜索近似）。**盾式采样**：每步 x_{t-1} ← Proj_F(x_{t-1})；末端若仍不可行则该样本作废。可行性优先于多样性。

**定义 434（随时停止 ↔ 预算）** 在去噪步 k 早停得到 x_k。预算自适应停止 τ(B) = min{ k : Δ_k ≤ δ_stop }，Δ_k 为相邻步 KL 残差（或 score 范数）估计。

**定义 435（集成认知不确定性）** 采样 K 个可行程序 {Π^{(i)}}。U_plan = (1/K) Σ_i dist(Π^{(i)}, Π̄)，或首个工具选择的归一化熵。风险门输入由点估计 σ_pred 扩展为 (σ_pred, U_plan)。

**定义 436（沟通动作）** d = (intent, content, c_exp, urgency_exp, channel)，其中 intent ∈ {reassure, explain, caution, ask_help, defer}。

**定义 437（披露策略 π_E）** π_E : (q(u_s), 受众模型 M_a, 利害 ℓ) → Δ(d)（沟通动作上的分布），同样用条件扩散或轻量策略实现。

**定义 438（共情遗憾与校准契约）** R_emp = E[ α|c_exp − c_cal| + β·𝟙[overclaim]·ℓ + γ·D_KL(Belief′ ‖ q(u_s)) + δ·|urgency_exp − g(risk)| ]；硬约束 c_exp ≤ c_cal + ε_emp。`overclaim` 定义为 c_exp > c_cal + ε_emp。

**定义 439（延迟耦合 deference）** 若 c_cal < τ_defer 或 U_plan > U_max，则 d.intent ∈ {ask_help, defer}，且高利害执行被**硬门**阻断（不是「建议」，而是不可执行）。

**定义 440（受审披露证书 Echo-Cert）** EchoCert(s) = (q(u_s) 摘要, 引用回执集, c_cal, c_exp, 合规位)。序列化时若某句不绑定有效回执，则剥离；剥离是**纯投影**，不改变数值路径。

**定义 441（7C 闭环）** H → C → E → C → V → U → D。新增 D（Disclose）：以 EchoCert 生成沟通动作并审计；D 失败 ⇒ 退化为「最小诚实披露」（只报 c_cal 区间，不做共情调制），**绝不退化为过度宣称**。

## 2. 关键算法骨架

```python
class DDPP:
    def sample(self, c, budget, K, steps=50):
        xs = []
        for _ in range(K):
            x = randn_like_program(L_max)
            for t in reversed(range(steps)):
                x = denoise(x, c, t, guidance_w=GUIDE_W)
                x = Proj_F(x, c.budget)            # 定义 433
                if anytime_stop(t, budget):        # 定义 434
                    break
            if feasible(x, c.budget):
                xs.append(x)
        return xs

class ResonaGauge:
    def round(self, M, s):
        H  = M.lbox.hypothesize(s, M.dbox.R[s])
        Ps = M.ddpp.sample((M.phi(s), H, M.tools, M.budget_left(s)), K=8)
        if not Ps:
            Ps = [M.tbox.vla_single_plan(H)]          # 退化到 ToolGauge
        U    = ensemble_uncertainty(Ps)               # 定义 435
        prog = M.ddpp.select(Ps, M.risk_gate, M.gain_bet, U)
        receipts = M.tcv.execute(prog, M.env)
        if len(receipts) < M.n_min(s):
            return M.disclose(s, intent="defer", cert=M.echo_partial(s))
        mu, Sig = M.apcal.calibrate(receipts, H, s)
        if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):
            return M.disclose(s, intent="ask_help", cert=M.echo_partial(s))
        M.mreg.hot_replace(M.dpe, M.apcal.update_contract(M.dpe, mu, Sig, s))
        cert = M.echo_cert(s, mu, Sig, receipts)
        d = M.pi_e.disclose(cert, M.audience, stakes=s)
        assert d.c_exp <= cert.c_cal + EPS_EMP         # 定义 438 硬约束
        if cert.c_cal < TAU_DEFER or U > U_MAX:
            d = force_intent(d, "ask_help")            # 定义 439 延迟耦合
        M.emit(d); M.log(cert, d)
        return True
```

## 3. 推导（引理 51–57）

**引理 51（可行性保持）** 若 F(s) ≠ ∅ 且 Proj_F 为幂等投影，则盾式采样中被接受的每个样本以概率 1 属于 F(s)。代价是分布偏置：TV(p_shield, p) 受 E[dist(x, F)] 控制；该偏置必须作为一等公民记入证书，否则会把「可行」误读为「最优」。

**引理 52（随时停止的增益缺口）** 在 score 误差 ε_s 与正则条件下，早停于 k 的样本与全步样本的 TV 距离 ≤ 2√(Σ_{t>k}(1−ᾱ_t))·ε_s；若增益泛函 G 对程序分布 1-Lipschitz，则 |G(k) − G(full)| ≤ L_G·TV。故 τ(B) 可按预算反解可容许的增益缺口。

**引理 53（集成分歧的覆盖）** 若 K 个样本可交换且规划遗憾 r(Π) 有界，则 U_plan 的 (1−α) 上分位可给出 r 的共形上界；风险门据此拒绝的是「高遗憾概率」程序，而非单点程序。

**引理 54（共情校准）** 在硬约束 c_exp ≤ c_cal + ε_emp 下，P(overclaim) ≤ P(|c_cal − c_true| > ε_emp)；若 c_cal 本身已校准则 ≤ δ。用户后验向真后验的收敛速度由披露携带的信息量下界给出。

**引理 55（延迟安全）** 在「c_cal < τ_defer 或 U_plan > U_max ⇒ 阻断高利害执行」的耦合下，高不确定时的误动作概率 ≤ P(c_cal ≥ τ_defer ∧ 错误)，由前几轮校准与 V 阶段交叉验证控制。

**引理 56（诚实退化）** 披露失败 ⇒ 最小诚实披露只报 c_cal 区间，其相对 c_cal 的过度宣称概率为 0，且不引入新的失配通道。扩散不可用 ⇒ 退化为 ToolGauge 单点计划；严格退化链 ResonaGauge ⇐ ToolGauge ⇐ LeanGauge ⇐ MODGAUGE 成立。

**引理 57（时序保持）** 扩散采样与披露均在异步修复路径；50Hz 路径只做 O(1) 回执验证，周期新增 < 0.2ms；预算耗尽强制降级；硬实时性质继承 ToolGauge 引理 50。

## 5. 本轮最大风险

**一句话**：共情表达层可能学会「表演共情」而非「校准披露」——语言扩散能生成令人信服却未被校准的安抚；即便硬约束拦住了显式过度宣称，语气、时机与选择性强调仍可放大信任而与真实可靠度脱钩，使「共情」沦为信任操纵面。

## 2. 形式化定义（要点）

**定义 432（DDPP）** 条件去噪扩散在程序空间 P 上：前向 q(x_t|x_0)=N(√ᾱ_t x_0,(1−ᾱ_t)I)，反向 p_θ(x_{t-1}|x_t,c)=N(μ_θ,Σ_θ)；训练 ‖ε−ε_θ(x_t,c,t)‖²；采样用分类器无关引导。

**定义 433（CPS / 盾式采样）** F(s)={Π: TCV 四查通过}；每步投影 Proj_F，末端不可行即作废。可行性优先于多样性，投影偏置必须记入证书。

**定义 434（随时停止）** τ(B)=min{k: Δ_k ≤ δ_stop}；早停的增益缺口由引理 52 界住。

**定义 435（PEP / 规划不确定性）** U_plan 为 K 个可行程序的分歧（距离均值或首工具熵）；风险门输入扩展为 (σ_pred, U_plan)。

**定义 436/437（沟通动作与披露策略）** d 的 intent∈{reassure, explain, caution, ask_help, defer}；π_E 在 d 上生成分布，可用与 DDPP 同构的约束去噪实现。

**定义 438（共情校准契约）** 硬约束 c_exp ≤ c_cal + ε_emp；软目标最小化 R_emp（置信偏差、过度宣称×利害、用户后验 KL、紧迫度错配）。

**定义 439（延迟耦合）** c_cal<τ_defer 或 U_plan>U_max ⇒ intent∈{ask_help,defer}，且高利害执行被硬门阻断。

**定义 440（Echo-Cert）** 披露证书 = (后验摘要, 引用回执, c_cal, c_exp, 合规位)；未绑定回执的语句在序列化时剥离（纯投影）。

**定义 441（7C）** H→C→E→C→V→U→D；D 失败 ⇒ 最小诚实披露（仅 c_cal 区间，无共情调制）。

# IP-322 CPS：可行性保持的投影采样
def Proj_F(x, budget):
    for _ in range(PROJ_ITERS):                 # 离散近似：逐位局部搜索
        if feasible(x, budget): return x
        x = repair_step(x, budget)              # 修 schema/前置/预算/循环
    return x                                    # 若仍不可行，调用方作废该样本

# IP-321/323 DDPP + PEP
class DDPP:
    def sample(self, c, budget, K, steps):
        out = []
        for _ in range(K):
            x = randn_like_program(L_max)
            for t in reversed(range(steps)):
                x = denoise(x, c, t, GUIDE_W)
                x = Proj_F(x, budget)
                if anytime_stop(t, budget): break
            if feasible(x, budget): out.append(x)
        return out
    def select(self, Ps, risk_gate, gain_bet, U):
        ok = [p for p in Ps if risk_gate(p, U) and gain_bet(p)]
        return max(ok, key=lambda p: p.lower_confidence_gain(), default=None)

# IP-324/325 EDL + Echo-Cert

        d = strip_unbound_claims(d, cert.receipts)    # 定义 440
        if cert.c_cal < TAU_DEFER or cert.U_plan > U_MAX:
            d = force_intent(d, "ask_help")           # 定义 439
        return d

    if not contract_regression(new_ec):

    M.mreg.hot_replace(M.dpe, new_ec)
    cert = M.echo_cert(s, mu, Sig, receipts, U)
    return M.emit(M.edl.disclose(cert, M.audience, s))

## 4. 推导（引理 51–57）

**引理 51（可行性保持）** F(s)≠∅ 且 Proj_F 幂等 ⇒ 被接受样本以概率 1 属 F(s)；分布偏置 TV(p_shield,p) 受 E[dist(x,F)] 控制，记入证书。

**引理 52（随时停止增益缺口）** 早停于 k 与全步样本 TV ≤ 2√(Σ_{t>k}(1−ᾱ_t))·ε_s；G 为 1-Lipschitz 时 |G(k)−G(full)| ≤ L_G·TV，可反解 τ(B)。

**引理 53（集成分歧覆盖）** 样本可交换且遗憾有界 ⇒ U_plan 的 (1−α) 上分位给出 r 的共形上界，风险门拒绝高遗憾程序。

**引理 54（共情校准）** c_exp ≤ c_cal+ε_emp ⇒ P(overclaim) ≤ P(|c_cal−c_true|>ε_emp)；c_cal 已校准时 ≤ δ。

**引理 55（延迟安全）** 延迟耦合下高不确定误动作概率 ≤ P(c_cal≥τ_defer ∧ 错误)，由校准与 V 阶段交叉验证控制。

**引理 56（诚实退化）** 披露失败 ⇒ 最小诚实披露相对 c_cal 的过度宣称概率为 0；扩散不可用 ⇒ ToolGauge；严格退化链成立。

**引理 57（时序保持）** 采样/披露均在异步路径，50Hz 仅 O(1) 回执验证，周期新增 < 0.2ms；硬实时继承引理 50。
