>

>
> 本轮的核心翻转是：
>
> **鲁棒性不是一个被认证出来的布尔属性，而是一笔可计量、可花费、可赚取的裕度预算；在线学习不是鲁棒性的敌人，而是它的压力测试。**
>
> 由此把 SimRAS 的「静态认证闭环」升级为「**动态认证不变量**」：
>
> **ORCA（Online Robust Certified Adaptation，在线鲁棒认证自适应闭环）——安全是本金，适应是利息；在线学习只能花利息，不能动本金。**
>
> ORCA 先问「这次学习是否仍在证书保持子空间内」，再问「它花掉了多少鲁棒性预算」，最后问「若验证失败，能否无损回滚」。它把「学习—认证—回滚」做成一个原子事务。

## 0. 直觉与动机

**灵感 1（鲁棒性 → 安全本金 / 适应利息）**
控制论里的鲁棒性从来不是「是否稳定」的二元判断，而是**裕度**：增益裕度、相位裕度、到约束边界的距离。裕度可以被消耗，也可以被新的证据赚回来。若把这一直觉搬到学习系统上，就得到一个非常锋利的会计学隐喻：
- **本金** = 维持硬安全所必需的鲁棒性裕度；
- **利息** = 由新数据、新覆盖、新冗余带来的额外裕度；
- **在线学习** = 用利息去交换性能的支出行为。

直觉结论：只要把「鲁棒性预算」显式记账，并规定任何一次更新不得使预算为负，就能在**不牺牲硬安全**的前提下获得在线适应能力。鲁棒性因此从形容词变成了一等状态量。

**灵感 2（在线学习 → 非平稳世界里的三种暗礁）**
在线学习不是简单地「多训几轮」，它在闭环系统里会撞上三块暗礁：
1. **灾难性遗忘**：模型追新用户的新表情，把旧用户「冻结/疼痛」这些低频但高致命的模式忘掉；长尾恰是安全最需要的部分。
2. **执行性反馈（performative feedback）**：策略改变了环境分布，模型又把「自己造成的结果」当成地面真值学习。例如 ERS 通过控制去安抚用户，ERG 于是学到「用户总是平静」——这是自证式漂移，而非世界变好了。
3. **数据投毒与对抗漂移**：在线数据没有可信标注，恶意样本或系统性偏差能在若干轮内把安全边界慢慢推走。

直觉结论：在线学习必须同时具备**记忆（抗遗忘）**、**因果（抗执行性反馈）**、**鲁棒统计（抗投毒）**三副牙齿。

**灵感 3（合流 → 证书携带更新：学习是一次需要担保的交易）**
把两条灵感对齐：鲁棒性提供了「可花费的预算」，在线学习提供了「需要担保的支出」。于是每一次参数更新都应被当作一次**交易**：
- 交易前：检查当前预算 `B_t ≥ 0`；
- 交易中：把更新投影到**安全关键零空间**，并用鲁棒聚合剔除可疑样本；
- 交易后：由独立验证器重新签发证书 `J_{t+1}`，并写入哈希链；
- 交易失败：**原子回滚**到上一个已认证检查点。

直觉结论：证书保护的不再是权重本身，而是**不确定集上的行为等价类**。只要更新后的策略仍落在同一安全等价类里，参数怎么变都允许；一旦跨类，就必须重新认证或被拒绝。

**灵感 4（架构 → 双速、零空间、残差、硬门）**
- **双速适应（DSA）**：快环调整 `λ_risk / k* / 阈值`，慢环才更新 ERG/EFS/WM 参数。奇异摄动条件保证快环在慢变量漂移前收敛，避免「边学边失控」。
- **安全关键零空间（SCN）**：只沿不改变见证集约束的方向学习，把更新花在证书的「盲区」。
- **残差适应（RA）**：基座策略 `θ_base`（SimRAS 冻结）不动，只学一个小残差 `Δθ_res`，于是基座证书可被扰动界直接继承。
- **ORCA-Gate 硬门**：预算为负、证书失效或存在挂起回滚时，立刻回退到冻结基座 + 保守包络，绝不放行未认证动作。

**灵感 5（机制一览）**
1. **RB 鲁棒性预算**：`B_t = m_R - L_c·r_amb - q_conf - m_min`，把不确定集半径、保形分位数、硬下限统一记账。
2. **DSA 双速适应**：慢变量周期 `T_s`、快变量周期 `T_f`，满足 `δ_s` 奇异摄动条件。
3. **SCN 安全关键零空间**：对见证集雅可比 `G_W` 做正交投影，带信赖域裁剪。
4. **RCC 在线鲁棒保形证书**：自适应分位数 + 截尾分位数，在 `ε`-污染下维持覆盖。
5. **RMA 鲁棒聚合**：坐标截尾均值 + 影响函数过滤，明确击穿点。
6. **SMM 安全记忆**：高致命长尾 coreset + Safety-EWC + 反事实 replay，抵抗遗忘与执行性反馈。
7. **CCU 证书携带更新**：更新、验证、哈希链、回滚是一个原子事务。
8. **ADR 漂移-投毒反射**：CUSUM + MMD 双统计量，触发 CONTRACT / ROLLBACK。
9. **RA 残差适应**：冻结基座 + 有界残差，证书可分解继承。
10. **Gate + 预算水填充**：把有限预算按模块效用做 KKT 水填充，安全关键模块优先。

## 1. 形式化定义（增量：定义 266–285）

- **定义 266（ORCA 总览）**：`ORCA = (RB, DSA, SCN, RCC, RMA, SMM, CCU, ADR, RA, Gate, J_ORCA)`。定位：把 SimRAS 的「静态认证闭环」升级为「动态认证不变量」。不变式：(i) 实时环只做前向推理与证书判定，零梯度写；(ii) 任何参数写入必须经 CCU 验证，否则回滚；(iii) 证书链只追加；(iv) `B_t < 0` 立即冻结并回退。
- **定义 267（鲁棒性裕度与预算）**：对安全约束 `c(θ, ξ) ≥ 0`、不确定集 `ξ ∈ Ξ_t`，定义鲁棒裕度 `m_R(θ_t) = inf_{ξ∈Ξ_t} c(θ_t, ξ)`，鲁棒性预算
  ```
  B_t = m_R(θ_t) - L_c·r_amb(t) - q_conf(t) - m_min
  ```
  其中 `r_amb` 为 DRO 半径，`q_conf` 为保形分位数，`m_min` 为硬安全下限，`L_c` 为约束 Lipschitz 常数。`B_t ≥ 0 ⇔ 当前策略在不确定集内仍保有非负安全裕度`。直觉：`B_t` 是「可以花掉的利息」。
- **定义 268（在线数据流、漂移与执行性反馈）**：数据流 `D_t ~ P_t^{π_{θ_t}}`，分布依赖当前策略（performative prediction）。漂移率 `Δ_t = W_1(P_t, P_{t-1})`；污染率 `ε_t`。执行性敏感度 `L_perf = sup_θ ||∂P^{π_θ}/∂θ||`。若 `η_t·L_perf < 1`，耦合学习过程在不动点附近收缩；否则出现极限环。
- **定义 269（双速适应）**：慢变量 `θ^s`（ERG/EFS/WM 参数）周期 `T_s`、步长 `η_s`；快变量 `θ^f`（`λ_risk`、`k*`、阈值、预算分配）周期 `T_f ≪ T_s`。奇异摄动条件：`sup_t ||θ^s_{t+1} - θ^s_t|| ≤ δ_s`，使快环在慢变量显著漂移前完成收敛。
- **定义 270（安全关键见证集）**：`W_t = {(ξ_j, c_j, w_j)}_{j=1}^{|W|}`，由高风险、稀有故障、约束边界场景构成，`w_j` 为优先级。安全泛函 `J_W(θ) = max_j w_j·(-c(θ, ξ_j))_+`。见证集是动态证书的锚点，规模由 coreset 控制。
- **定义 271（安全关键零空间与证书保持子空间）**：在 `θ_t` 处线性化见证约束，`G_W(θ) = [∇_θ c(θ, ξ_j)]_j`。一阶证书保持子空间 `N_W = {v : G_W v = 0}`；带信赖域 `ρ_t` 的近似子空间 `N_W^ρ = {v : ||G_W v|| ≤ δ_J, ||v|| ≤ ρ_t}`。
- **定义 272（在线鲁棒保形证书）**：非一致性分数 `s_i = -c(θ, ξ_i)`；自适应分位数 `q_{t+1} = q_t + η_q(α - 1[s_{t+1} > q_t])`。在 `ε`-污染数据流上使用截尾分位数 `q_t^{(β)}`，覆盖保证 `P(c(θ,ξ) ≥ 0) ≥ 1 - α - ε/(1-ε)`。
- **定义 273（鲁棒聚合与影响过滤）**：对梯度集 `{g_i}` 使用坐标截尾均值 `A_rob`（或 median-of-means）；以影响函数 `IF_i = -H^{-1}g_i` 过滤 `||IF_i|| > τ_IF` 的样本。击穿点记为 `β_rob`，过滤后污染率 `ε' ≤ ε/β_rob`。
- **定义 274（安全记忆与抗遗忘正则）**：`SMM = (Coreset, Replay, Safety-EWC)`。安全加权 Fisher `F_j = E[(∂ℓ/∂θ_j)^2·1[critical]]`，正则
  ```
  L_reg = (μ/2)·Σ_j F_j(θ_j - θ*_j)^2
  ```
  Coreset 按「距约束边界的距离」与「故障稀有度」优先保留。
- **定义 275（证书携带更新 CCU）**：一次更新是一个原子事务
  ```
  CCU(θ_t, Δθ, D_t) → (θ_{t+1}, J_{t+1}) 或 ⊥（回滚）
  ```
  接受条件：`θ_{t+1} ∈ Θ_cert(B_t - η_t)` ∧ 独立验证通过 ∧ 哈希链连续。证书
  ```
  J_{t+1} = (parent_hash, update_hash, data_hash, B_{t+1}, m_R, q_conf, Δ_t, ε'_t, verifier_sig)
  ```
- **定义 276（在线安全遗憾）**：`R_T = Σ_t [ℓ_t(θ_t) - ℓ_t(θ*)] + κ·Σ_t max(0, -B_t)`。目标：`R_T = o(T)`，且硬门下 `Σ_t max(0, -B_t) = 0`。
- **定义 277（漂移-投毒反射 ADR）**：CUSUM 统计量 `C_t = max(0, C_{t-1} + s_t - ν)`；MMD 统计量 `MMD_t = ||μ̂_t - μ̂_{t-τ}||²`。若 `C_t > h_C` 或 `MMD_t > h_M`，进入 CONTRACT（冻结慢环、提高 `m_min`、优先 replay）；严重时 ROLLBACK 到最近证书检查点。
- **定义 278（ORCA-Gate 运行时硬门）**：动作 `a_t` 可执行当且仅当 `B_t ≥ 0 ∧ J_t 有效 ∧ 无挂起回滚`；否则回退到 SimRAS 冻结基座 + 保守包络。硬保证：若验证器无误判，则不存在未认证执行。
- **定义 279（残差适应）**：`θ = θ_base ⊕ Δθ_res`，`θ_base` 冻结（SimRAS），`||Δθ_res|| ≤ ρ_res`。证书可分解：
  ```
  m_R(θ) ≥ m_R(θ_base) - L_c·ρ_res
  ```
  即「基座保安全、残差学适应」。
- **定义 280（证书行为等价类）**：`θ ~ θ'` 当且仅当在 `Ξ_t` 上 `c(θ,ξ)` 与 `c(θ',ξ)` 同号且裕度差 `≤ δ_eq`。商空间 `Θ/~` 中每个元素共享同一鲁棒证书。在线学习只需留在正确的等价类内，而不必保持参数不变——这是对「冻结权重」的关键放宽。
- **定义 281（预算水填充分配）**：把 `B_t` 分配到各适应模块 `m ∈ {ERG, EFS, WM, λ, k}`：`ΔB_m = argmax Σ_m u_m(ΔB_m)` s.t. `Σ_m ΔB_m ≤ B_t, ΔB_m ≥ 0`。KKT 水填充求解，安全关键模块优先级最高。
- **定义 282（可逆性约束）**：不可逆动作 `I(a) = 1`（造成不可恢复状态）不得作为在线学习探索数据；更新只允许使用 `I(a) = 0` 的转移，或经反事实重要性加权。禁止「用不可撤销的代价换学习」。
- **定义 283（鲁棒-性能 Pareto 前沿）**：`P_t = {(R(θ), m_R(θ))}`。仅当新点不支配当前点且 `m_R` 不下降时接受更新；ORCA 维护非支配存档。
- **定义 284（证书链可靠性）**：`C_T = (J_0, …, J_T)`，`h_t = H(h_{t-1}, Δθ_t, D_t)`。若哈希抗碰撞且验证器单边错误率 `≤ α_v`，则证书链可信概率 `≥ 1 - T·α_v`。
- **定义 285（ORCA 部署不变式）**：实时环 = `SimRAS 前向 + Gate + RCC 查询`，`< 3ms`；慢环异步；任何 `θ` 写入只在慢环发生；预算与证书状态跨进程只读共享。

```python
class RobustnessBudget:
    """RB：鲁棒性预算 = 安全本金 / 适应利息"""
    def __init__(self, m_min=0.2, L_c=1.0):
        self.m_min, self.L_c = m_min, L_c
        self.B = 0.0

    def compute(self, theta, ambiguity, q_conf):
        m_R = min(safety_constraint(theta, xi) for xi in ambiguity.sample())
        self.B = m_R - self.L_c * ambiguity.radius() - q_conf - self.m_min
        return self.B

    def can_spend(self, delta):
        return self.B + delta >= 0.0


class SafetyCriticalNullSpace:
    """SCN：只沿不改写见证集约束的方向学习"""
    def __init__(self, rho=0.05, delta_J=0.01, lam=1e-4):
        self.rho, self.delta_J, self.lam = rho, delta_J, lam

    def project(self, theta, grad, witness):
        G = jacobian_witness(theta, witness)          # |W| x d
        v = grad - G.T @ solve(G @ G.T + self.lam * eye(len(witness)), G @ grad)
        v = clip_norm(v, self.rho)
        if norm(G @ v) > self.delta_J:                # 近似零空间越界
            v = clip_norm(v, self.rho / 2)
        return v


class OnlineRobustConformal:
    """RCC：漂移与污染下的在线保形分位数"""
    def __init__(self, alpha=0.05, eta=0.01, beta=0.1):
        self.alpha, self.eta, self.beta = alpha, eta, beta
        self.q, self.buf = 0.0, []

    def update(self, score):
        self.buf.append(score)
        self.q += self.eta * (self.alpha - float(score > self.q))
        return trimmed_quantile(self.buf[-1000:], self.beta)


class RobustAggregator:
    """RMA：截尾均值 + 影响函数过滤"""
    def __init__(self, trim=0.1, tau_IF=5.0):
        self.trim, self.tau_IF = trim, tau_IF

    def filter(self, grads, influence):
        return [(g, i) for g, i in zip(grads, influence) if i <= self.tau_IF]

    def aggregate(self, grads):
        return coordinatewise_trimmed_mean(grads, self.trim)


class SafetyMemory:
    """SMM：安全 coreset + Safety-EWC + 反事实 replay"""
    def __init__(self, coreset, fisher, theta_star, mu=0.1, nu=0.2):
        self.coreset, self.fisher = coreset, fisher
        self.theta_star, self.mu, self.nu = theta_star, mu, nu

    def loss(self, theta, batch):
        L = task_loss(theta, batch)
        L += 0.5 * self.mu * sum(self.fisher[j] * (theta[j] - self.theta_star[j]) ** 2
                                for j in range(len(theta)))
        for critical in self.coreset.sample(8):
            L += self.nu * task_loss(theta, critical)
        return L


class CertificateCarryingUpdate:
    """CCU：更新 + 验证 + 哈希链 + 回滚的原子事务"""
    def __init__(self):
        self.chain = []

    def apply(self, theta, delta, data, budget, verifier):
        if not budget.can_spend(-delta_budget(delta)):
            return theta, None                        # 拒绝：预算不足
        candidate = theta + delta
        cert = verifier.certify(candidate, data)      # 独立验证
        if cert is None or not cert.safe:
            return theta, None                        # 回滚
        J = make_certificate(self.chain[-1] if self.chain else None,
                             delta, data, cert, budget.B)
        self.chain.append(J)
        return candidate, J


class DriftPoisonReflex:
    """ADR：CUSUM + MMD 双统计量"""
    def __init__(self, nu=0.5, h_C=5.0, h_M=0.1):
        self.nu, self.h_C, self.h_M = nu, h_C, h_M
        self.C, self.prev_mu = 0.0, None

    def update(self, batch):
        score = batch.unexpectedness()
        self.C = max(0.0, self.C + score - self.nu)
        mu = batch.mean_embedding()
        mmd = norm(mu - self.prev_mu) ** 2 if self.prev_mu is not None else 0.0
        self.prev_mu = mu
        if self.C > self.h_C or mmd > self.h_M:
            return 'CONTRACT'
        return 'ADAPT'


class ORCAGate:
    """Gate：无认证，不执行"""
    def allow(self, action, theta, cert, budget):
        if budget.B < 0 or cert is None or not cert.valid:
            return self.fallback(action)              # SimRAS 冻结基座
        return action


def ORCA_slow_loop(M, D_t):
    # 1) 漂移/投毒反射
    mode = M.adr.update(D_t)
    if mode == 'CONTRACT':
        M.dsa.freeze_slow()
        M.budget.m_min *= 1.2
        return M.last_valid_checkpoint

    # 2) 鲁棒聚合 + 影响过滤
    grads, infl = M.rma.compute_gradients(M.theta, D_t)
    grads = [g for g, i in M.rma.filter(grads, infl)]
    g = M.rma.aggregate(grads)

    # 3) 安全记忆损失 + 零空间投影
    g = g + grad_safety_memory(M.smm, M.theta)
    delta = M.scn.project(M.theta, -M.dsa.eta * g, M.witness)

    # 4) 在线保形分位数更新
    q_conf = M.rcc.update(M.eval_score(M.theta))

    # 5) 预算复用：水填充分配
    B = M.budget.compute(M.theta, M.ambiguity, q_conf)
    alloc = water_filling(B, M.modules)

    # 6) 证书携带更新（失败即回滚）
    theta_new, J = M.ccu.apply(M.theta, delta, D_t, M.budget, M.verifier)
    if J is not None:
        M.theta = theta_new
        M.last_valid_checkpoint = theta_new
    return M.theta


def ORCA_round(M, obs):
    # 实时环：与 SimRAS 同构，只多一次 Gate 查询
    k_ras, lambda_risk, joint_post, face_gate, wm_preds = SimRAS_round(M, obs)
    cert = M.ccu.current_certificate()
    action = M.pi_sigma.dispatch(lambda_risk, k_ras)
    action = M.gate.allow(action, M.theta, cert, M.budget)
    M.slow_loop.submit(obs)                           # 异步，不阻塞
    return action, M.budget.B, cert
```

## 3. 推导

**引理 13（鲁棒性预算的守恒与非负性）** 设预算递推 `B_{t+1} = B_t + ΔB_t`，每次更新满足 `ΔB_t ≥ -η_t`，且仅当 `B_{t+1} ≥ 0` 时接受。若 `B_0 ≥ 0`，则对所有 `t` 有 `B_t ≥ 0`，且累计可花费预算满足 `Σ_t (-ΔB_t)_+ ≤ B_0 + Σ_t earned_t`。即：**没有一次更新能凭空创造安全裕度**。

**引理 14（零空间投影的见证保持）** 若见证约束 `c_j` 为 `L_c`-光滑，更新 `Δθ = P_{N_W}(-ηg)` 且 `||Δθ|| ≤ ρ`，则对任意见证 `ξ_j`：
```
|c_j(θ + Δθ) - c_j(θ)| ≤ (L_c/2)·||Δθ||² + O(||Δθ||³)
```
一阶项被零空间投影消去，故见证裕度的退化是二阶小量。取 `ρ ≤ sqrt(2δ_m/L_c)` 可保证退化不超过 `δ_m`。这把「学习不伤害已验证行为」从口号变成了可计算的步长约束。

**引理 15（鲁棒聚合的击穿点）** 对 `ε`-污染样本，坐标截尾均值的估计误差满足 `||θ̂ - θ*|| ≤ O(ε) + O(sqrt(log(1/δ)/n))`，其击穿点 `β_rob ≥ min(trim, 1/2)`。经影响函数过滤后，有效污染率 `ε' ≤ ε/β_rob`。因此只要 `ε < β_rob`，投毒只能造成有界偏移，不能使证书静默翻转。

**定理 14（在线安全遗憾界）** 设损失 `ℓ_t` 凸且 `L`-Lipschitz，更新为投影在线梯度下降，且硬门强制 `B_t ≥ 0`。则
1. 静态遗憾 `R_T ≤ O(sqrt(T)) + O(Σ_t η_t·ε_t)`；
2. 动态遗憾 `R_T^dyn ≤ O(sqrt(T(1 + P_T)))`，`P_T` 为比较器路径长度；
3. 安全违反 `Σ_t max(0, -B_t) = 0`（验证器无误判时），且预算总支出 `≤ B_0 + Σ_t earned_t`。
这说明**适应性（遗憾）与安全性（预算）可以同时亚线性可控**，而非零和折中。

**定理 15（执行性反馈的稳定性条件）** 设 `P_t = P^{π_{θ_t}}` 对 `θ` 为 `L_perf`-Lipschitz，学习迭代 `θ_{t+1} = θ_t - η_t ∇ℓ(θ_t; P^{π_{θ_t}})`。若 `η_t·L_perf < 1`，则迭代在不动点邻域内为压缩映射，收敛到 performative stable point；若 `η_t·L_perf ≥ 1`，可能出现极限环。ORCA 的 ADR 通过检测振荡进入 CONTRACT，等价于在线估计并压低有效学习率，从而把系统拉回稳定域。

**定理 16（证书链可靠性）** 若哈希函数抗碰撞、验证器单边错误率 `≤ α_v`，且每次写入必须携带连续哈希，则长度 `T` 的证书链可信概率 `≥ 1 - T·α_v`；被拒绝的更新不会改变已认证状态，因此系统最多停留在「陈旧但可信」的检查点，而不会进入「新颖但未认证」的状态。

**推论 3（Pareto 不退化）** 由定义 283 与引理 13，ORCA 接受的每次更新都不使 `m_R` 下降；因此其维护的鲁棒-性能前沿是单调非支配的。在线学习扩大可行域，但永不以牺牲已验证鲁棒性为代价。

## 6. 本轮最大风险

**一句话**：ORCA 把安全寄托在「鲁棒性预算可被正确计量」这一前提上——一旦不确定集 `Ξ_t` 与保形分位数在真实非平稳或对抗漂移下被系统性低估，预算就会虚高，系统将把「未经验证的安全」当成可花费的利息，在持续在线学习中把安全本金一点点花光。

**次级风险与缓解**：
1. **预算模型失配**：`m_R` 用采样近似不确定集，极端场景可能漏采 → 用对抗采样 + 形式化区间上界，并设预算硬上限；
2. **零空间过保守**：强约束下可学方向太少，适应停滞 → 用行为等价类（定义 280）放宽到「同证书不同参数」；
3. **保形分位数滞后**：突变漂移下 `q_conf` 追不上 → ADR 触发后冻结学习并重置分位数；
4. **验证器成本与共谋**：独立验证器仍可能与被审计方共享盲点 → 证书链公开、验证器版本冻结、定期人工审计；
5. **执行性反馈的慢漂移**：`η·L_perf` 的在线估计本身有噪声 → 用双速结构把慢环学习率压到保守区，并保留反事实 replay。

```python
# IP-243 RB：鲁棒性预算
class RobustnessBudget:
    def __init__(self, m_min=0.2, L_c=1.0):
        self.m_min, self.L_c, self.B = m_min, L_c, 0.0

    def compute(self, theta, ambiguity, q_conf):
        m_R = min(safety_constraint(theta, xi) for xi in ambiguity.sample())
        self.B = m_R - self.L_c * ambiguity.radius() - q_conf - self.m_min
        return self.B

    def can_spend(self, delta):
        return self.B + delta >= 0.0


# IP-245 SCN：安全关键零空间投影
class SafetyCriticalNullSpace:
    def __init__(self, rho=0.05, delta_J=0.01, lam=1e-4):
        self.rho, self.delta_J, self.lam = rho, delta_J, lam

    def project(self, theta, grad, witness):
        G = jacobian_witness(theta, witness)
        v = grad - G.T @ solve(G @ G.T + self.lam * eye(len(witness)), G @ grad)
        v = clip_norm(v, self.rho)
        if norm(G @ v) > self.delta_J:
            v = clip_norm(v, self.rho / 2)
        return v

        self.coreset, self.fisher = coreset, fisher
        self.theta_star, self.mu, self.nu = theta_star, mu, nu

    def loss(self, theta, batch):
        L = task_loss(theta, batch)
        L += 0.5 * self.mu * sum(self.fisher[j] * (theta[j] - self.theta_star[j]) ** 2
                                for j in range(len(theta)))
        for critical in self.coreset.sample(8):
            L += self.nu * task_loss(theta, critical)
        return L


# IP-249 CCU：证书携带更新
class CertificateCarryingUpdate:
    def __init__(self):
        self.chain = []

    def apply(self, theta, delta, data, budget, verifier):
        if not budget.can_spend(-delta_budget(delta)):
            return theta, None
        candidate = theta + delta
        cert = verifier.certify(candidate, data)
        if cert is None or not cert.safe:
            return theta, None
        J = make_certificate(self.chain[-1] if self.chain else None,
                             delta, data, cert, budget.B)
        self.chain.append(J)
        return candidate, J


# IP-250 ADR：漂移-投毒反射
class DriftPoisonReflex:
    def __init__(self, nu=0.5, h_C=5.0, h_M=0.1):
        self.nu, self.h_C, self.h_M = nu, h_C, h_M
        self.C, self.prev_mu = 0.0, None

    def update(self, batch):
        self.C = max(0.0, self.C + batch.unexpectedness() - self.nu)
        mu = batch.mean_embedding()
        mmd = norm(mu - self.prev_mu) ** 2 if self.prev_mu is not None else 0.0
        self.prev_mu = mu
        return 'CONTRACT' if self.C > self.h_C or mmd > self.h_M else 'ADAPT'


# IP-252 ORCA-Gate：无认证不执行
class ORCAGate:
    def allow(self, action, cert, budget):
        if budget.B < 0 or cert is None or not cert.valid:
            return self.fallback(action)
        return action


# IP-252 ORCA 闭环
def ORCA_round(M, obs):
    # 实时环：与 SimRAS 同构 + 一次 Gate 查询
    k_ras, lambda_risk, joint_post, face_gate, wm_preds = SimRAS_round(M, obs)
    cert = M.ccu.current_certificate()
    action = M.pi_sigma.dispatch(lambda_risk, k_ras)
    action = M.gate.allow(action, cert, M.budget)

    # 慢环：异步提交，不阻塞实时环
    M.slow_loop.submit(obs, face_gate, joint_post)
    return action, M.budget.B, cert


def ORCA_slow_loop(M, D_t):
    # 1) 漂移/投毒反射
    if M.adr.update(D_t) == 'CONTRACT':
        M.dsa.freeze_slow()
        M.budget.m_min *= 1.2
        return M.last_valid_checkpoint

    # 2) 鲁棒聚合
    grads, infl = M.rma.compute_gradients(M.theta, D_t)
    g = M.rma.aggregate([g for g, i in M.rma.filter(grads, infl)])

    # 3) 安全记忆 + 零空间投影
    g = g + grad_safety_memory(M.smm, M.theta)
    delta = M.scn.project(M.theta, -M.dsa.eta * g, M.witness)

    # 4) 在线保形
    q_conf = M.rcc.update(M.eval_score(M.theta))

    # 5) 预算 + 水填充
    B = M.budget.compute(M.theta, M.ambiguity, q_conf)
    water_filling(B, M.modules)

    # 6) 证书携带更新
    theta_new, J = M.ccu.apply(M.theta, delta, D_t, M.budget, M.verifier)
    if J is not None:
        M.theta = theta_new
        M.last_valid_checkpoint = theta_new
    return M.theta
```

## 4. 推导

**引理 13（预算守恒）** 若 `B_{t+1}=B_t+ΔB_t`、`ΔB_t ≥ -η_t`、且仅当 `B_{t+1} ≥ 0` 接受，则 `B_0 ≥ 0 ⇒ ∀t, B_t ≥ 0`，且 `Σ_t(-ΔB_t)_+ ≤ B_0 + Σ_t earned_t`。没有更新能凭空创造安全裕度。

**引理 14（零空间见证保持）** `c_j` 为 `L_c`-光滑时，
```
|c_j(θ+Δθ) - c_j(θ)| ≤ (L_c/2)||Δθ||² + O(||Δθ||³)
```
一阶项被 `N_W` 消去；取 `ρ ≤ sqrt(2δ_m/L_c)` 保证见证退化不超过 `δ_m`。

**引理 15（鲁棒聚合击穿点）** `ε`-污染下截尾均值误差 `≤ O(ε) + O(sqrt(log(1/δ)/n))`，击穿点 `β_rob ≥ min(trim, 1/2)`；影响过滤后 `ε' ≤ ε/β_rob`。

**定理 14（在线安全遗憾界）** 凸 `L`-Lipschitz 损失 + 投影 OGD + 硬门：
1. `R_T ≤ O(sqrt(T)) + O(Σ_t η_t ε_t)`；
2. `R_T^dyn ≤ O(sqrt(T(1+P_T)))`；
3. `Σ_t max(0,-B_t) = 0`（验证器无误判），预算支出 `≤ B_0 + Σ_t earned_t`。

**定理 15（执行性反馈稳定性）** 若 `η_t·L_perf < 1`，迭代在不动点邻域压缩收敛；否则出现极限环，ADR 触发 CONTRACT 压低有效学习率，使系统回到稳定域。

**定理 16（证书链可靠性）** 哈希抗碰撞且验证器单边错误率 `≤ α_v` 时，长度 `T` 的链可信概率 `≥ 1 - T·α_v`；被拒更新不改变已认证状态，系统最多停留在「陈旧但可信」的检查点。

**推论 3（Pareto 不退化）** ORCA 接受的更新均满足 `m_R` 不下降，故其鲁棒-性能前沿单调非支配。

## 7. 本轮最大风险

**一句话**：ORCA 把安全寄托在「鲁棒性预算可被正确计量」这一前提上——一旦不确定集 `Ξ_t` 与保形分位数在真实非平稳或对抗漂移下被系统性低估，预算就会虚高，系统将把「未经验证的安全」当成可花费的利息，在持续在线学习中把安全本金一点点花光。

**次级风险与缓解**：
1. **不确定集漏采**：采样近似会低估 `m_R` → 对抗采样 + 形式化上界 + 预算硬顶；
2. **零空间过保守**：可学方向过少 → 用行为等价类放宽为「同证书不同参数」；
3. **保形滞后**：突变漂移下分位数追不上 → ADR 触发后冻结并重置；
4. **验证器共谋/盲点**：独立验证器仍可能失明 → 链公开、版本冻结、定期人工审计；
5. **执行性反馈的慢漂移**：`L_perf` 在线估计有噪 → 双速结构 + 保守学习率 + 反事实 replay。
