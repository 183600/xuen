# 第 3 轮（灵感循环第 3 轮；本轮灵感：「数据采集」×「角色一致性」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440）。
> 本轮纪律：仍然**只做增量**——TCV / AP-Cal / 6C 骨架不动，在其上补两块此前完全缺失的拼图：
> **数据从哪来（采集设计）**、**凭什么说这些数据在描述同一个东西（实体身份）**。
> 五不变式、TB-Contract、退化链全部保留；同时审计并修复第 2 轮遗留的缺陷（§5）。

## 两轴映射（升级而非重写）

| 灵感词 | 第 2 轮对象 | 升级为 | 一句话动机 |
|---|---|---|---|
| 数据采集 | 定义 417 回执：被动、无来源、收多少算多少 | **DAC + AAC + D-Ledger**：全局采集契约、主动锚集采集、可溯源账本 | ToolGauge 知道自己「缺证据」，却不知道证据**从哪来、够不够、是否同源** |
| 角色一致性 | 定义 421.U：逐子图局部热替换，只保证子图外数值等价 | **ID-Thread + CVCC**：实体身份线程 + 跨视角一致性闸门 | 局部对齐不等于全局是同一个「角色」；两次都正确的修复可能指向两个世界 |
| 两轴交汇 | VLA 只有 schema 约束 | **RCC 角色契约**：角色→输出类型→权限，跨轮人格锁定 | 「角色」的第二个含义：agent 不能在轮次间偷偷换人格、把语言塞回数值通道 |

**核心命题**：从「盲区 → 契约化工具调用 → 摊销校准 → 局部热替换」升级为
「**身份线程 → 主动锚集采集 → 双锚校准 → 跨视角一致性后热替换**」。
一句话：ToolGauge 修的是**格子**；CastGauge 先确认这些格子属于**同一个角色**，才允许被修。
数据采集从「事后收据」变成「事前角色设定集 + 在线补采」；
角色一致性从「子图内数值等价」变成「跨格子、跨模态、跨时间的实体身份不变式」。

**不变式保持声明**：
- MODGAUGE 五不变式全部保留；
- 新增**身份不变式（第六不变式）**：任何被热替换的契约必须携带可机器校验的 IdentityCert，且通过 CVCC；
- **严格退化链延长**：CastGauge 失效（锚集不足 / 身份冲突 / ID-Breaker 触发）⇒ ToolGauge「身份未验证」provisional 模式 ⇒ LeanGauge ⇒ MODGAUGE。身份层是增强项，不是依赖项。

## 0. 直觉与动机

**灵感 1（数据采集 → 从「收据」到「角色设定集」）**
直觉：ToolGauge 的 6C 是**反应式**的——D-Box 发现盲区，才派工具去采。它从不回答三个问题：
(1) 这条回执从哪个视角、哪个模态、什么时刻来的？(2) 同一实体在不同盲区采到的数据是否彼此可比？
(3) 采得够不够，还是把同一次观测换了个时间戳重复了 8 遍？
第 1 轮「迭代采样被误判为已覆盖」的风险，第 2 轮用签名回执堵住了「**伪造**」，却没堵住「**同源复读**」：
8 条签名完全合法、相关系数 0.99 的回执，信息量可能只等于 1 条。
数据采集领域的研究智慧是：**采集设计先于采集本身**（覆盖、去重、来源、预算），再加**主动学习**
（按当前不确定性决定下一次采哪里）。于是引入 DAC（采集契约）、AAC（主动锚集控制器）、D-Ledger（可溯源账本）：
采集不只为修复当前盲区，还为建立与维持**身份**。

**灵感 2（角色一致性 → 实体的「角色设定」必须跨视角成立）**
直觉：生成式视觉里的「角色一致性」要求同一角色在不同角度、表情、光照下仍是同一人——
靠的是**参考设定集 + 身份嵌入 + 跨视角一致性检验**。本系统有一个结构性盲点：
第 2 轮的 U 阶段只验证新子图与旧子图在**未涉及部分**逐指令等价（引理 49），
却从不验证两个**都通过回归测试**的修复是否仍在描述同一个物理实体。
把「角色」落到计量上：每个实体 e 有一条**身份线程**——不变量指纹 κ_e、锚集 A_e（多视角/多模态/跨时间的预注册采集）、
有效期与包络 T_e、以及所有历史「渲染」V_e（修复后的契约）。任何一次热替换都是对 e 的一次渲染，
必须与 κ_e 一致，且必须与 e 的其它活跃渲染彼此一致。

**灵感 3（两轴交汇 → 「角色」的双重含义）**
「角色」还有第二层含义：**VLA 的职责角色**。第 2 轮把 VLA 降格为假设器/编程器/解说器，但只靠 schema 约束输出类型；
同一提示在不同轮次可能让 VLA「换人格」——措辞漂移、对同一数值给出不同主张。
角色一致性在这里意味着**角色契约（RCC）**：角色 → 输出类型 → 权限，跨轮可复现（种子/版本锁定 + 分布漂移检测）。
因此本轮是「实体角色一致性」为主、「agent 角色一致性」为辅的双关升级；两者共享同一形式化骨架：
**一个对象在多次观测/多次生成中必须保持可检验的不变式**，且该不变式必须由**设计过的数据**建立。

## 1. 形式化定义（增量：定义 432–447）

**定义 432（实体身份线程 ID-Thread）** 身份线程 I_e = (κ_e, A_e, T_e, V_e, ν_e)：
- e：实体 id（物体 / 材质区域 / 可动部件），由 D-Box 的格子语义层给候选，**不依赖自由文本**；
- κ_e ∈ ℝ^{d_id}：身份不变量向量，由多模态计量指纹稳健聚合（反射光谱类、几何签名、热响应时间常数、χ_R 符号模式等）；
- A_e ⊆ D-Ledger：锚集（「角色设定集」），须满足 DAC 覆盖约束；
- T_e = [t₀,t₁] × 环境包络 E_e：身份有效期，过期或出包络 ⇒ 身份失效，需重采集；
- V_e：版本化渲染历史 {EC_i}，每条引用 e；
- ν_e：身份版本号，锚集变化即升版。
身份线程是**全局单例**，被所有引用 e 的子图共享；**子图无权私有化 e 的身份**。

**定义 433（身份一致性谓词 cons_e）** 对任意两个身份承载对象 a,b（回执、契约或子图输出）：
cons_e(a,b) ⇔ d_id(φ_id(a), φ_id(b)) ≤ ε_id ∧ ∀j∈J_e: |ψ_j(a) − ψ_j(b)| ≤ δ_j，
其中 φ_id 是身份特征提取器（**只读白名单数值通道**，定义 429 的延伸）；J_e 是守恒量集（质量、尺寸、材质类、χ_R 符号模式），ψ_j 为对应测量。
对集合 S 定义 cons_e(S) ⇔ 与稳健中心一致且两两一致。
注意 cons 不是「相同」，而是「**在预注册容差内不可区分**」——所以它是可证伪的。

**定义 434（数据采集契约 DAC）** DAC = (B_data, k_view, m_mod, Δt_span, ρ_dup, τ_stale, div_prov)：
- B_data：全局采集预算（调用数/总时长/总风险），与 B_tools **分离**，避免建身份预算与修复预算互相挤占；
- 覆盖约束：每个实体至少 k_view 个不同视角、m_mod 个模态、跨度 Δt_span 的锚回执；
- ρ_dup：近重复阈值，近重复回执**不计入覆盖**；
- τ_stale：身份过期时间；div_prov：来源多样性（不同工具/视角/物理通道计数）。
DAC 是 TB-Contract（424）的采集侧细化，二者共享 recovery 语义。

**定义 435（主动锚集采集 AAC）** 设覆盖赤字 D_e 为 DAC 约束的未满足量（结构化集合）。每轮选择采集动作 a∈A：
a* = argmax_{a: c_a ≤ B_data} [ ΔCov(a) + λ_I·I_e(a) − μ·risk(a) ]，并施加近重复惩罚。
ΔCov 为覆盖率增量；I_e(a) 为对 κ_e 的期望信息增益（与 Ĝ_t 同族，可查 MP-Φ）。
关键：**锚集采集发生在修复之前（anchor-first）**；在线补采是维护，不是修复的副产品。
（同时修正第 2 轮定义 419 的量纲问题：增益一律以「每单位共同货币的 nats」计。）

**定义 436（数据采集账本 D-Ledger）** 每条回执入账须附
provenance = (tool_id, view_id, modality, raw_hash, t, env_snapshot_hash, policy_version)；
账本 append-only、Merkle 化；任何修复/校准**只能引用账本内回执**；
支持 replay：给定 policy_version 与 seed 可重放采集序列（审计与事故复盘）。
回执有效性从「签名正确」升级为「签名正确 ∧ 可溯源 ∧ 在账」。

**定义 437（去重与有效样本量）** dedup(r,S) ⇔ min_{s∈S} d_feat(r,s) > ρ_dup ∧ provenance 的视角/模态计数有正增量。
同源复读 = 高相关但签名合法的回执簇。有效样本量
n_eff = (Σλ_i)² / Σλ_i²（λ_i 为回执相关矩阵特征值，独立时 n_eff = n）。
**n_eff 而非回执条数 n 进入样本门槛**——这是对「迭代采样被误判为已覆盖」的统计级修复。

**定义 438（身份锚定校准 IAP-Cal）** q_θ(u_s | receipts_s, I_e) 优化
min_θ E[−log p(u*|ctx)] + β_KL·KL(q_θ‖p_phys) + β_id·ρ(Ψ(q_θ), κ_e)，
Ψ 将后验映射到身份特征空间，ρ 取马氏距离平方或 hinge max(0, d_id − ε_id)；
等价于身份信任域约束 Ψ(q_θ) ∈ B_id(κ_e, ε_id)。
物理先验仍是 KL 锚，身份是**第二锚（双锚）**；保守性夹紧 Σ ≽ κ_phys·I 保留。
直觉：给摊销后验加一个 identity adapter，防止每个盲区各自漂到不同世界。

**定义 439（跨视角一致性检验 CVCC 与身份保留集）** 热替换前对候选 EC* 三查：
(a) **自一致**：EC* 引用的每个 e 满足 cons_e(EC*, κ_e)；
(b) **互一致**：EC* 与 e 的所有当前活跃渲染 V_e 两两 cons_e；
(c) **守恒**：J_e 上守恒量通过。
全过才允许 U；任一失败 ⇒ 不替换，记 identity_conflict，转补采或 stub。
另设身份保留集 H_id ⊂ D-Ledger（cross.modal 的一个子集），**永久禁止进入 Π_s 的拟合集**，V 阶段只用它。
（修复第 2 轮 V 阶段「独立回执无独立性机制」的漏洞。）

**定义 440（身份漂移断路器 ID-Breaker）** 维护 d_id(κ_e^{live}, κ_e^{anchor}) 与（预测,实测）身份残差，
以 CUSUM 统计量做单边检验：H₀ 身份稳定（残差零均值），H₁ 单调漂移或跳变。
CUSUM 越界，或 d_id > ε_id 持续 q 次 ⇒ 冻结所有触及 e 的修复，升版 ν_e 并触发 DAC 重采集；恢复需重新认证。
替代第 2 轮仅看残差符号连跑的 P-Quarantine（修复低信噪比假警报与幅度不敏感）。

**定义 441（角色契约 RCC）** 对每个 VLA 角色 ρ ∈ {Hypothesizer, Programmer, Narrator}：
RoleContract_ρ = (OutputType_ρ, Authority_ρ, SeedPolicy_ρ, Version_ρ)：
- Hypothesizer：输出 ∈ 共形假设集类型；不得输出工具参数或自由文本数值；
- Programmer：输出 ∈ T₀ 上的合法程序；不得输出主张或解释；
- Narrator：输出 ∈ claims 且必须引用回执；不得输出程序或新假设。
跨角色输出 = **角色混淆**，拒绝并计数。
跨轮一致性：同一数值输入下角色输出分布 TV 漂移 > η_role ⇒ 角色重认证（persona lock）。

**定义 442（身份证书 IdentityCert）**
IdentityCert(e) = (ν_e, κ_e, A_e, 覆盖统计 (k_view,m_mod,Δt,div_prov), n_eff, CVCC 结果, DAC 版本)。
绑进 EC（与 RepairCert 并列），机器可校验；**无证书的契约不得进入 U 阶段**（身份不变式）。
证书中每个数值必须来自 D-Ledger（与定义 423 主张-回执绑定同构）。

**定义 443（CastGauge 七段闭环 7C）** I(dentity) → H → C → E → C → V → U：
0. **I（新增第 0 相）**：加载/建立 I_e；覆盖不足 ⇒ 先跑 AAC 补锚，**然后**才进入修复；
1–6 继承 ToolGauge 6C，但：C 阶段程序只许引用账本内、非 H_id 的回执；C 阶段校准用 IAP-Cal（双锚）；
V 阶段追加 CVCC（自一致/互一致/守恒）；U 阶段写 IdentityCert、更新 V_e、喂 ID-Breaker。
失败 ⇒ provisional 模式（定义 445）或 stub + RED。

**定义 444（覆盖-身份联合目标与子模采集）** 采集目标 F(S) = Cov(S) + λ_I·I(S)。
覆盖项是单调子模；信息增益在条件独立近似下子模。预算约束下贪心采集达到 (1−1/e)·OPT。
若 I 不满足子模（信息增益一般既非子模也非超模），**放弃无条件最优声明**，退化为贪心局部保证，
并由 E446 实测 greedy gap。

**定义 445（身份未验证 provisional 模式）** 锚集不足或身份冲突未解、但 ToolGauge 修复仍可用时，允许降级：
provisional 契约只参与**只读推理**，不参与安全关键动作，必须带「未认证」标记与到期时间；
到期仍未认证 ⇒ 自动回退旧版本。这是退化链中间新增的一级：**永不阻塞主路径，也永不假装已认证**。

**定义 446（身份失效 vs 合法身份事件）** 身份不是永恒。实体被替换/破坏/合法变形时 cons_e 必然失败，系统必须区分：
- **身份事件**（真实变化）：多视角、多模态、守恒量**同时**出现一致变化，且旧身份落在 T_e/包络之外；
- **身份漂移**（错误）：仅单一模态或单一视角漂移，或与守恒量矛盾。
前者 ⇒ 升版新身份（保留历史、不删账本）；后者 ⇒ ID-Breaker。
这是防止「一致性」退化为「认知锁定」的关键定义。

**定义 447（继承与编号约定）** 未被本轮重定义的第 1/2 轮记号（R、s、λ、γ、M_ver、N_bl、EC、EC.claims、MReg、Π_s、TB、MP-Φ 等）
沿用定义 398–431。本文所有增量以 ToolGauge 为退化特例：
令 A_e=∅（不做身份）、DAC=∅（无采集设计）、IAP-Cal=AP-Cal ⇒ CastGauge ≡ ToolGauge。

## 2. 关键算法骨架

```python
# IP-321 ID-Thread / IdentityStore：全局身份线程
@dataclass
class IdentityThread:
    e: str
    kappa: np.ndarray                  # κ_e ∈ R^{d_id}
    anchors: set[str]                  # receipt ids（必须是 D-Ledger 内 id）
    T_env: Envelope
    renders: dict[str, "Contract"]     # V_e：活跃渲染
    version: int

class IdentityStore:
    def get(self, e): ...
    def covered(self, e, dac): ...     # 覆盖约束 + n_eff + div_prov
    def certify(self, e, ledger): ...  # 构造 IdentityCert（定义 442）

# IP-322 DAC + AAC：采集契约与主动锚集采集（anchor-first）
class DAC:
    B_data: float; k_view: int; m_mod: int
    dt_span: float; rho_dup: float; tau_stale: float; div_prov: int

class AAC:
    def deficit(self, e, ledger): ...                 # 结构化覆盖赤字
    def plan(self, deficits, budget):                 # 定义 444：预算下贪心
        return greedy_max_coverage(deficits, budget,
                                   gain=lambda a: self.info_gain(a) - self.risk(a))

# IP-323 D-Ledger：来源绑定 + 去重 + 有效样本量
class DLedger:
    def admit(self, r, prov):
        if not self.verify_prov(prov): return False
        if self.near_dup(r, prov):     return False   # 定义 437
        self.append(r, prov); return True
    def n_eff(self, ids):
        lam = self.corr_eigs(ids); return lam.sum()**2 / (lam**2).sum()

# IP-324 IAP-Cal：双锚（物理先验 + 身份锚）摊销校准
class IAPCal(APCal):
    def calibrate(self, receipts, H, e, I_e):
        mu, Sig = super().calibrate(receipts, H, e)           # ToolGauge 后验
        if mahalanobis(Psi(mu), I_e.kappa, I_e.metric) > self.eps_id:
            mu = self.project_to_ball(mu, I_e, self.eps_id)   # 投影，不压方差
        return mu, clamp_min(Sig, KAPPA_PHYS)                 # 夹紧保留

# IP-325 CVCC + ID-Breaker：一致性闸门与漂移断路器
class CVCC:
    def check(self, ec_star, e, I_e):
        if not cons_e(ec_star, I_e.kappa):                return False, "self"
        if not all(cons_e(ec_star, v) for v in I_e.renders.values()):
            return False, "cross"                         # 互一致（定义 439.b）
        if not conserved_ok(ec_star, I_e):               return False, "conservation"
        return True, "ok"

class IDBreaker:
    def update(self, e, d_id, predicted):
        self.cusum[e] = max(0.0, self.cusum[e] + d_id - predicted - self.k)
        return self.cusum[e] > self.h                    # 越界 ⇒ 冻结 + 重采集

# IP-326 CastGauge 7C 闭环
def castgauge_7c(M, e, s):
    I_e = M.idstore.get(e)
    if not M.idstore.covered(e, M.dac):                   # I：anchor-first
        M.aac.acquire(e, M.dac, M.ledger)                 # 主动补采（定义 435）
        if not M.idstore.covered(e, M.dac):
            return provisional_or_stub(s, "identity_uncovered")
    cert = M.idstore.certify(e, M.ledger)                 # 定义 442
    H    = M.lbox.hypothesize(s, M.dbox.R[s])             # H
    prog = M.tbox.select(H, M.tools, M.tcv, M.budget_left(s))
    prog = M.ledger.filter(prog, exclude=M.holdout_id)    # C：排除身份保留集
    receipts = M.tcv.execute(prog, M.env)                 # E
    if M.ledger.n_eff(receipts) < n_min(s):               # 有效样本量门槛（定义 437）
        return provisional_or_stub(s, "insufficient_effective_evidence")
    mu, Sig = M.iapcal.calibrate(receipts, H, e, I_e)     # C：双锚
    ec_star = M.iapcal.update_contract(M.dpe, mu, Sig, s)
    ok, why = M.cvcc.check(ec_star, e, I_e)               # V：自/互/守恒
    if not ok: return provisional_or_stub(s, f"identity_{why}")
    if not M.apcal.cross_validate(mu, Sig, M.holdout(e)): # V：held-out（定义 439）
        return provisional_or_stub(s, "holdout_failed")
    if not contract_regression(ec_star):
        return provisional_or_stub(s, "regression_failed")
    M.mreg.hot_replace(M.dpe, ec_star)                    # U
    M.idstore.commit(e, ec_star, cert)                    # 更新 V_e / IdentityCert
    M.idbreaker.update(e, *identity_residual(ec_star, I_e))
    return True
```

## 3. 推导

**引理 51（身份覆盖的样本复杂度）** 设身份特征在 ℝ^{d_id} 中 σ_id-亚高斯，锚集用稳健聚合估计 κ_e；
要在 1−δ 置信下达到 ‖κ̂_e − κ_e‖₂ ≤ ε_id，需
n_anchor ≥ C·σ_id²·(d_id + log(1/δ)) / ε_id²。
系：d_id 与 ε_id 同时决定采集预算下界——**身份精度不是免费的**，直接进入 DAC 的 B_data 预算。

**引理 52（双锚校准的一致性-风险权衡）** 若真实参数满足 ‖u* − κ_e‖ ≤ ε_id（身份成立），
则 IAP-Cal 超额风险 ≤ ToolGauge 超额风险 + 2β_id·ε_id；
若身份被破坏 ‖u* − κ_e‖ ≥ ε_id + Δ，则投影后残差 ≥ Δ − O(σ/√n_eff)，
CUSUM 的期望检测延迟 ≤ (h + 1)/(Δ − k)（标准 CUSUM 延迟公式）。
系：一致性约束的代价可量化（2β_id ε_id），检测能力也可量化——不是「加了就更好」。

**引理 53（CVCC 的假阳/假阴）** 身份特征 σ_f-亚高斯时，同实体两两距离
P(‖φ(a)−φ(b)‖ ≥ ε_id) ≤ 2·exp(−ε_id²/(8σ_f²))（假阳上界）；
不同实体间隔 Δ_id 时，假阴（误接受）≤ 2·exp(−(Δ_id−ε_id)²/(8σ_f²))。
对 N_render 个渲染取 union bound。系：可用需 Δ_id > ε_id，**阈值不能无限收紧**——
ε_id 太小则合法变化全被拒，太大则异实体被合并；E442 扫描该 ROC。

**引理 54（子模采集的贪心近似）** 若 Cov 单调子模且 I 在条件独立近似下子模，
则预算约束贪心达到 (1−1/e)·OPT。若 I 非子模（一般情形），贪心**无最坏情形保证**；
本文只声称条件结论，并由 E446 报告经验 gap。系：不把「启发式」包装成「最优」。

**引理 55（身份层不破坏热替换等价性）** CVCC 是**替换前闸门**；IdentityCert 字段与 RepairCert/claims 一样不在数值路径上；
V_e 更新是元数据。故通过时子图数值等价性与第 1 轮引理 44、第 2 轮引理 49 相同；
失败时不替换（provisional 仅限制控制面权限，不改数值）⇒ 系统级性质保持。

**引理 56（角色契约的非干扰性）** 在 RCC 下跨角色输出被类型拒绝；数值状态只能由工具经 TCV 写入，
Hypothesizer/Narrator 无法写工具参数 ⇒ 语言与数值之间被类型系统与账本 provenance 双重隔离
（定义 441 + 定义 436，延伸定义 429）。系：提示注入的攻击面收敛为「D-Ledger provenance 校验 + 类型校验」两处。

## 6. 本轮最大风险（一句话）

**一句话**：身份一致性把「与锚集一致」当成「正确」——一旦锚集被投毒或世界发生**合法变化**，
系统会**稳定地**拒绝真相、接受被污染的「角色设定」，一致性从安全护栏退化为**认知锁定**；
而 append-only 的 D-Ledger 会让错误锚既永久可溯源、也永久可复用，把一次采集事故变成长期系统性偏差。

**次级风险与缓解**：
1. **锚集投毒** → div_prov 多源多样性 + 稳健聚合（截尾/中位数）+ 独立 holdout；红队 E447；
2. **合法身份变化被误杀** → 定义 446 区分身份事件 / 身份漂移；E442 ROC + E448 变形组；
3. **过度约束导致拒修率上升、provisional 泛滥** → E441/E450 认证率-修复率曲线，设认证率 SLA；
4. **采集预算与修复预算互相挤占** → B_data 与 B_tools 分离 + 优先级调度（定义 434）；
5. **子模假设不成立** → E446 实测 greedy gap，不宣称无条件最优（引理 54）；
6. **身份特征被对抗优化** → 身份特征只用计量通道与稳健统计，不用可微学习特征；E447；
7. **角色契约过严使 VLA 不可用** → 退化链保留，RCC 失败即退回 ToolGauge/LeanGauge（定义 447）。

## 2. 形式化定义（要点）

**定义 432（ID-Thread）** 每个实体 e 有全局身份线程 I_e（κ_e、锚集 A_e、有效期 T_e、渲染史 V_e、版本 ν_e）；身份被所有引用 e 的子图共享，子图无权私有化。
**定义 433（cons_e）** `d_id(φ_id(a),φ_id(b)) ≤ ε_id ∧ 所有守恒量 |ψ_j(a)−ψ_j(b)| ≤ δ_j`；不是「相同」，而是「预注册容差内不可区分」，因而可证伪。
**定义 434（DAC）** 采集预算 B_data 与修复预算 B_tools 分离；覆盖 = k_view 视角 × m_mod 模态 × Δt_span 时间 × div_prov 来源；近重复不计覆盖。
**定义 435（AAC）** anchor-first：修复前先按 `argmax [ΔCov + λ_I I_e − μ·risk]` 补锚；同时把第 2 轮 β_t 的量纲修正为「每单位共同货币的 nats」。
**定义 436（D-Ledger）** 回执有效性 = 签名正确 ∧ 可溯源 ∧ 在账；append-only + Merkle + policy_version，可 replay。
**定义 437（n_eff）** 同源复读用相关矩阵特征值度量为 n_eff；**n_eff 而非条数 n** 进入样本门槛，统计级修复「迭代采样误判覆盖」。
**定义 438（IAP-Cal）** `min_θ E[−log p(u*|ctx)] + β_KL KL(q_θ‖p_phys) + β_id ρ(Ψ(q_θ),κ_e)`；等价于身份信任域投影；物理夹紧保留（双锚）。
**定义 439（CVCC）** 热替换前三查：自一致（对 κ_e）、互一致（对 V_e 全部活跃渲染）、守恒量；另设 H_id 永久排除出拟合集，V 只用 holdout。
**定义 440（ID-Breaker）** CUSUM 单边检验身份残差；越界或持续漂移 ⇒ 冻结触及 e 的修复、升版、重采集、重新认证。
**定义 441（RCC）** 角色 → 输出类型 → 权限；跨角色输出即角色混淆；跨轮输出分布 TV > η_role ⇒ 重认证（persona lock）。
**定义 442（IdentityCert）** (ν_e, κ_e, A_e, 覆盖统计, n_eff, CVCC 结果, DAC 版本)，绑进 EC；无证书不得 U。
**定义 443（7C）** 新增第 0 相 I（身份建立/补锚），其余继承 6C，但 C 排除 H_id、C 用双锚、V 加 CVCC、U 写证书并喂断路器。
**定义 444（子模采集）** F = Cov + λ_I I；Cov 子模、I 在条件独立近似下子模 ⇒ 贪心 (1−1/e)OPT；否则只报经验 gap，不声称最优。
**定义 445（provisional）** 身份未验证时允许只读、限期、带标记的临时契约；到期回退，永不假装已认证。
**定义 446（身份事件 vs 漂移）** 多视角/多模态/守恒量**同时**一致变化且旧身份出包络 ⇒ 合法身份事件（升版，不删账本）；单模态/单视角漂移 ⇒ 漂移（断路器）。
**定义 447（继承）** 未重定义记号沿用 398–431；令 A_e=∅、DAC=∅、IAP-Cal=AP-Cal ⇒ CastGauge ≡ ToolGauge。

## 3. 关键算法骨架

```python
# IP-323 D-Ledger：只认「在账」回执
class DLedger:
    def admit(self, r, prov):
        if not self.verify_prov(prov): return False
        if self.near_dup(r, prov):     return False     # 同源复读不计覆盖
        self.append(r, prov); return True               # append-only + Merkle
    def n_eff(self, ids):
        lam = self.corr_eigs(ids)
        return lam.sum()**2 / (lam**2).sum()            # 独立时 = n

# IP-324 IAP-Cal：物理锚 + 身份锚
class IAPCal(APCal):
    def calibrate(self, receipts, H, e, I_e):
        mu, Sig = super().calibrate(receipts, H, e)
        if mahalanobis(Psi(mu), I_e.kappa, I_e.metric) > self.eps_id:
            mu = self.project_to_ball(mu, I_e, self.eps_id)   # 投影，不压方差
        return mu, clamp_min(Sig, KAPPA_PHYS)

# IP-325 CVCC + ID-Breaker
class CVCC:
    def check(self, ec_star, e, I_e):
        if not cons_e(ec_star, I_e.kappa):                   return False, "self"
        if not all(cons_e(ec_star, v) for v in I_e.renders.values()):
            return False, "cross"
        if not conserved_ok(ec_star, I_e):                   return False, "conservation"
        return True, "ok"

class IDBreaker:
    def update(self, e, d_id, predicted):
        self.cusum[e] = max(0.0, self.cusum[e] + d_id - predicted - self.k)
        return self.cusum[e] > self.h

# IP-326 CastGauge 7C
def castgauge_7c(M, e, s):
    I_e = M.idstore.get(e)
    if not M.idstore.covered(e, M.dac):                    # I：anchor-first
        M.aac.acquire(e, M.dac, M.ledger)
        if not M.idstore.covered(e, M.dac):
            return provisional_or_stub(s, "identity_uncovered")
    cert = M.idstore.certify(e, M.ledger)                  # IdentityCert
    H    = M.lbox.hypothesize(s, M.dbox.R[s])              # H
    prog = M.tbox.select(H, M.tools, M.tcv, M.budget_left(s))
    prog = M.ledger.filter(prog, exclude=M.holdout_id)     # C：排除 H_id
    receipts = M.tcv.execute(prog, M.env)                  # E
    if M.ledger.n_eff(receipts) < n_min(s):                # 有效样本量
        return provisional_or_stub(s, "insufficient_effective_evidence")
    mu, Sig = M.iapcal.calibrate(receipts, H, e, I_e)      # C：双锚
    ec_star = M.iapcal.update_contract(M.dpe, mu, Sig, s)
    ok, why = M.cvcc.check(ec_star, e, I_e)                # V：自/互/守恒
    if not ok: return provisional_or_stub(s, f"identity_{why}")
    if not M.apcal.cross_validate(mu, Sig, M.holdout(e)):  # V：held-out
        return provisional_or_stub(s, "holdout_failed")
    if not contract_regression(ec_star):
        return provisional_or_stub(s, "regression_failed")
    M.mreg.hot_replace(M.dpe, ec_star)                     # U
    M.idstore.commit(e, ec_star, cert)
    M.idbreaker.update(e, *identity_residual(ec_star, I_e))
    return True
```

## 4. 推导

**引理 51（身份覆盖样本复杂度）** σ_id-亚高斯的 d_id 维身份特征，要 1−δ 置信达到 ‖κ̂−κ‖₂ ≤ ε_id，需
`n_anchor ≥ C·σ_id²(d_id + log(1/δ))/ε_id²`。系：身份精度直接换算成 DAC 的 B_data 下界。
**引理 52（双锚一致性-风险权衡）** 身份成立时超额风险 ≤ ToolGauge + 2β_id ε_id；身份被破坏且间隔 Δ 时，投影残差 ≥ Δ − O(σ/√n_eff)，CUSUM 期望检测延迟 ≤ (h+1)/(Δ−k)。系：约束代价与检测力都可量化。
**引理 53（CVCC 错误率）** 同实体假阳 ≤ 2exp(−ε_id²/8σ_f²)；异实体假阴 ≤ 2exp(−(Δ_id−ε_id)²/8σ_f²)，对 N_render union bound。系：必须 Δ_id > ε_id，阈值不能无限收紧（E442 扫 ROC）。
**引理 54（子模贪心）** Cov 子模、I 条件独立近似子模 ⇒ (1−1/e)OPT；否则无最坏保证，仅报经验 gap（诚实标注）。
**引理 55（身份层不破坏热替换等价性）** CVCC 为替换前闸门，IdentityCert 不在数值路径，V_e 为元数据；通过则等价性同引理 44/49，失败不替换（provisional 只限控制面）⇒ 系统性质保持。
**引理 56（RCC 非干扰性）** 跨角色输出被类型拒绝；数值只能由工具经 TCV 写入 ⇒ 语言/数值经类型系统 + 账本 provenance 双重隔离（延伸定义 429）。

## 8. 本轮最大风险

**一句话**：身份一致性把「与锚集一致」当成「正确」——一旦锚集被投毒或世界发生合法变化，
系统会**稳定地**拒绝真相、接受被污染的「角色设定」，一致性从安全护栏退化为**认知锁定**；
append-only 的 D-Ledger 又让错误锚永久可溯源、也永久可复用，把一次采集事故放大成长期系统性偏差。
以 E447（投毒）、E448（身份事件）、E442（ROC）、引理 53/54（诚实界）为证伪与兜底。
