# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「强化学习训练」×「机械臂抓取」）

> 第 54 轮把技能组合刻画为动作空间剖面 `α_S`、组合图 `G_S` 与云边联合证书 `J`，但把技能视为"已给定"的黑箱。本轮追问两个被悬置的第一性问题：**技能从哪来、如何训练才能被证书接纳**（强化学习训练），以及**接触密集任务中纯运动学动作空间是否足以刻画可抓性**（机械臂抓取）。核心矛盾：H22：证书体系是"事后验收"、RL 是"过程优化"，二者节律不一致，训练出的策略常在最需要鲁棒性的接触边界处证书失效；H23：纯运动学动作剖面无法表达接触模式与力闭合，抓取成功与失败可能发生在 `α_S` 的同一动作点上。

## 0. 直觉与动机

**灵感 1（占用测度即动作剖面 → 把第 54 轮的外部估计变成训练副产品）**
直觉：RL 训练天然产生策略的**状态-动作占用测度 `d^π(s,a)`**。第 54 轮的 `α_S` 不必再用独立采样器暴力探测——它正是 `d^π` 在动作维上的边缘化。于是"动作剖面"从需要主动采样的外部量，变成训练循环的内部副产品，且自带样本量与置信带。覆盖率检查从点估计升级为 **置信下界（LCB）判定**：只有"有统计把握的覆盖"才算覆盖，避免把有限采样下的偶然命中当成能力。

**灵感 2（证书守卫的 RL → 把验收门槛前移进策略更新）**
直觉：与其训练完再被 `J` 否决，不如让 `J` 成为策略更新的**约束集**。定义证书守卫集 `G_τ(J_k)`，每次只接受既不降低证书支配序、又满足覆盖下界与力闭合的策略。这把第 53–54 轮的 soundness 证书从"部署闸门"变成"训练算子"，形成 **证书不回归的策略改进**。奖励负责"想抓什么"，证书负责"允许怎么抓"——两个目标各司其职，而不是在单一标量奖励里互相稀释。

**灵感 3（接触模式剖面 + 力闭合证书 → 抓取专用的动作空间扩展）**
直觉：机械臂抓取的动作 `a=(p,R,g,f)` 只是运动学的一半；真正的分水岭是**接触模式 `m ∈ {approach, contact, stick, slip, detach}`** 与**力闭合（force closure）**。两个技能在纯位姿动作上完全兼容，却可能一个在"接触即滑"、另一个在"接触即锁"。因此动作空间必须扩为 `(a,m)`，并给抓取技能附上 `FC_cert=(W,μ,f,margin)`。抓取可行 = 覆盖下界通过 ∧ 力闭合裕度 ≥ 阈值。这一层无法被第 54 轮的 Jaccard 兼容性吸收，是抓取任务特有的第一性约束。

**灵感 4（选项化技能图 → 第 54 轮的组合图变成可学习对象）**
直觉：第 54 轮的 `G_S` 是手工定义的边。RL 的 **options 框架** `(I_o,π_o,β_o)` 恰好给出边的可学习判据：选项 i 的终止分布是否落入选项 j 的启动集 `I_j`、启动集 Jaccard 兼容性、以及跨选项转换成本。于是组合图从"先验结构"变成"训练得到的结构"，兼容性不再靠猜，而是由真实转移统计检验。这同时缓解了第 54 轮"组合图规模爆炸"的一部分压力——不可达边会被训练直接剪掉。

**灵感 5（域随机化证书 + 奖励骇客检测 → 抓取的 sim-to-real 与目标错位）**
直觉：抓取的物理瓶颈是摩擦、柔顺、延迟与传感噪声，仿真器极易被策略"钻空子"（把物体卡进几何缝隙、利用理想接触不滑）。域随机化不应只是训练技巧，而应升格为**证书**：`DRC` 记录随机化分布 `Ξ`、支撑集覆盖半径 `r_Ξ` 与 Lipschitz 常数，给出真实成功率下界。同时，若"奖励上升而证书下降"，即判定为 **reward hacking / 证书骇客**，进入帕累托 knee 选择而非盲目追奖励。

**灵感 6（金字塔再扩展）**
直觉：在第 53 轮鲁棒性金字塔 `𝕃` 与第 54 轮动作协同层 `𝔸` 之上，叠加 **学习-接触层 `𝕃ℂ`**：`𝕃ℂ_0` 物理接触极限，`𝕃ℂ_1` 占用剖面，`𝕃ℂ_2` 接触模式与力闭合，`𝕃ℂ_3` 域随机化证书，`𝕃ℂ_4` 奖励-证书帕累托。跨层传递证书同时携带 `π` 占用、`β` 接触模式、`FC` 与 `DRC`，形成 **可训练、可验收、可解释** 的三位一体。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（策略占用测度与可估计动作剖面）**
折扣 γ 下策略 π 的占用测度
`d^π(s,a) = (1-γ) Σ_{t≥0} γ^t P(s_t=s, a_t=a | π)`。
技能 S 由策略 `π_S` 实现，其动作剖面定义为占用测度在动作单元上的边缘概率：
```
α_S(a) = Σ_s d^π_S(s,a) / Σ_{a'} Σ_s d^π_S(s,a')
```
即第 54 轮的 `α_S` 是 `d^π` 的可估计投影，满足 `Σ_a α_S(a)=1`，且无需独立的外部剖面采样器。

**定义 122（剖面置信带与覆盖证书）**
以 M 条轨迹估计 `α̂_S`，在动作单元数 `|A|` 上由 DKW/Hoeffding 得一致误差界
```
ε_occ = sqrt(ln(2|A|/δ) / (2M)),   α^-_S = max(0, α̂_S - ε_occ)
```
**覆盖证书** `cover_cert(S,A_T) ⇔ ∀a∈A_T: α^-_S(a) ≥ θ_cov`。仅当覆盖有 `1-δ` 统计置信时才可部署——这是对第 54 轮"点估计覆盖"的 soundness 修补。

**定义 123（接触模式剖面与力闭合证书）**
抓取动作 `a=(p,R,g,f)`（位姿、夹持开口、夹持力），接触模式 `m∈{approach,contact,stick,slip,detach}`。**接触模式剖面** `β_S(a,m)` 为占用测度对 `(a,m)` 的边缘。对接触扳手集 `W={w_i}`、摩擦系数 μ、夹持力 f，**力闭合证书**
```
FC_cert = (W, μ, f, margin),   margin = dist(0, ∂conv(W_μ))
```
其中 `W_μ` 为 μ-摩擦锥生成元。抓取技能可行当且仅当
```
cover_cert(S_g, A_T) ∧ (μ ≥ μ_min) ∧ (f_min ≤ f ≤ f_max) ∧ (margin ≥ margin_min)
```

**定义 124（证书守卫的策略改进 CGRL）**
证书守卫集
```
G_τ(J_k) = { π : J(π) ⪰ J_k ∧ cover_cert(π) ∧ FC_cert(π) ∧ KL(π‖π_k) ≤ τ }
```
CGRL 更新 `π_{k+1} = argmax_{π∈G_τ(J_k)} E_π[R]`，并要求 **证书不回归** `J(π_{k+1}) ⪰ J(π_k)` 且 `E[R]` 不降。`⪰` 为第 53 轮证书的偏序（逐维不劣）。

**定义 125（选项化技能图 SGO）**
选项 `o=(I_o,π_o,β_o)`，`I_o` 启动集、`β_o` 终止函数。学习组合图 `G_S^π=(V,E)`，边 `i→j` 存在当且仅当
```
P(β_{o_i}(s')=1, s'∈I_{o_j}) ≥ 1-η ∧ compat(I_{o_i},I_{o_j}) ≥ θ_a ∧ c_trans(o_i,o_j) ≤ τ_e
```
边证书 `C_comp^learn = (compat, c_trans, ρ_comp, A_overlap)`，与第 54 轮 `C_comp` 对齐但由训练统计而非先验给出。

**定义 126（域随机化证书 DRC）**
接触参数 `ξ=(μ, e, mass, latency, noise) ~ Ξ`。域随机化鲁棒性 `ρ_DR(π)=ess-inf_{ξ~Ξ} success(π,ξ)`，以 `N_ξ` 样本的置信下界 `ρ_DR^-` 估计。若 `success(π,ξ)` 对 ξ 为 `L_ξ`-Lipschitz，且训练支撑集覆盖半径
```
r_Ξ = sup_{ξ∈supp(Ξ)} dist(ξ, Ξ_train)
```
则真实成功率下界 `P_real ≥ ρ_DR^- - L_ξ·r_Ξ`。证书 `DRC=(Ξ, N_ξ, ρ_DR^-, L_ξ, r_Ξ)`。

**定义 127（奖励-证书帕累托与证书骇客分数）**
帕累托前沿 `P = {(E[R](π), J(π))}`。**证书骇客分数**
```
H(π_k, π_{k+1}) = [ΔR>0] · max(0, (ρ_k-ρ_{k+1})/ρ_k) / (ΔR/R_k)
```
当 `H > H_max` 判为 reward hacking，拒绝该更新并回退到前沿 knee 点
`argmax_{p∈P} (E[R] + λ_J·ρ)`，而不是继续追奖励。

## 2. 关键算法 伪代码

### IP-121 OCP（Occupancy-Certified Profile）

```python
def occupancy_profile(policy, env, cells, M, delta):
    counts = zeros(len(cells))
    for _ in range(M):
        for (s, a) in rollout(policy, env):
            counts[idx(a)] += 1
    alpha_hat = counts / counts.sum()
    eps = sqrt(log(2*len(cells)/delta) / (2*M))
    lcb = clip(alpha_hat - eps, 0.0, 1.0)
    return alpha_hat, lcb, eps

def cover_cert(lcb, A_T, theta_cov):
    return all(lcb[idx(a)] >= theta_cov for a in A_T)
```

### IP-122 CGRL（Certificate-Guarded RL）

```python
def cgrl_train(policy, env, J0, tau, budget):
    J_cur = certify(policy, env)            # 第 54 轮联合证书 J
    for k in range(budget):
        cand = ppo_step(policy, env, kl_target=tau)   # 奖励最大化
        J_cand = certify(cand, env)
        feasible = (dominates(J_cand, J_cur)
                    and cover_cert(profile_lcb(cand), A_T)
                    and force_closure_cert(cand))
        if feasible:
            policy, J_cur = cand, J_cand
        else:
            policy = project_to_guard(cand, J_cur, env)  # 约束投影
            J_cur = certify(policy, env)
        log_pareto(J_cur, reward(policy))
    return policy, J_cur
```

### IP-123 CMP（Contact-Mode Profile + Force Closure）

```python
def contact_mode_profile(rollouts):
    beta = defaultdict(float)
    for traj in rollouts:
        for (a, m) in traj:
            beta[(cell(a), m)] += 1
    return normalize(beta)

def force_closure_cert(grasp, mu_min, margin_min, f_min, f_max):
    W = friction_cone_generators(grasp.contacts, grasp.mu)
    margin = distance_to_boundary(convex_hull(W), origin)
    ok = (grasp.mu >= mu_min and f_min <= grasp.f <= f_max
          and margin >= margin_min)
    return ok, Cert(W, grasp.mu, grasp.f, margin)
```

### IP-124 SGO（Skill Graph Options）

```python
def learn_options(skills, env, theta_a, tau_e, eta):
    options = [train_option(s, env) for s in skills]
    G = DiGraph()
    for i, oi in enumerate(options):
        for j, oj in enumerate(options):
            if i == j: continue
            reach = termination_lands_in(oi, oj.I, env)      # P(β_i→I_j)
            compat = jaccard(oi.I, oj.I)
            c_trans = transition_cost(oi, oj, env)
            if reach >= 1-eta and compat >= theta_a and c_trans <= tau_e:
                G.add_edge(i, j, compat=compat, c_trans=c_trans,
                           reach=reach)
    return G
```

### IP-125 DRC（Domain-Randomization Certificate）

```python
def dr_certificate(policy, Xi, N_xi, L_xi, delta):
    samples = [sample(Xi) for _ in range(N_xi)]
    succ = [success(policy, xi) for xi in samples]
    rho_dr = lower_confidence_bound(succ, delta)
    r_xi = coverage_radius(Xi, samples)
    bound = rho_dr - L_xi * r_xi
    return DRC(Xi, N_xi, rho_dr, L_xi, r_xi), bound
```

### IP-126 RHP（Reward-Hack Pareto）

```python
def reward_hack_score(R_prev, R_cur, rho_prev, rho_cur):
    dR = (R_cur - R_prev) / max(abs(R_prev), 1e-9)
    drho = (rho_prev - rho_cur) / max(abs(rho_prev), 1e-9)
    if dR <= 0: return 0.0
    return max(0.0, drho) / dR

def select_knee(pareto, lambda_J):
    return max(pareto, key=lambda p: p.R + lambda_J * p.rho)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| OCP | O(M·T) | O(|A|) | DKW 一致界、轨迹 i.i.d. |
| CGRL | O(K·C_step + K·C_cert) | O(θ_policy + |A|) | Guard 投影正确、证书单调不回归 |
| CMP | O(N·T·|M|) | O(|A|·|M|) | 接触模式标注完备、摩擦锥校准 |
| SGO | O(|S|²·(T+Eval)) | O(|S|²) | 终止落入统计显著、边 sound |
| DRC | O(N_ξ·T) | O(N_ξ) | 支撑覆盖、Lipschitz 界 |
| RHP | O(|P|) | O(|P|) | 帕累托非支配、knee 稳定 |

**正确性定理（Certificate-Guarded RL Deployment Soundness）**
假设第 53–54 轮 (A22)–(A28) 成立，且：
**(A29)** 占用估计一致误差 `sup_a |α̂_S(a)-α_S(a)| ≤ ε_occ` 以概率 `1-δ` 成立；
**(A30)** 接触模式剖面与力闭合证书在摩擦不确定度 `Δμ` 下 sound；
**(A31)** `success(π,ξ)` 对接触参数 `ξ` 为 `L_ξ`-Lipschitz，DR 支撑覆盖半径 `r_Ξ`；
**(A32)** CGRL 单调：`J(π_{k+1}) ⪰ J(π_k)` 且 `E[R]` 不降。
则部署策略满足
```
P_success(π_deployed) ≥ ρ_DR^- - L_ξ·r_Ξ - ε_occ·|A_T| - κ_μ·Δμ - β_E - P(δ_a > Θ_a)
```
其中 `ρ_DR^-` 为域随机化成功率置信下界，`κ_μ` 为摩擦敏感度常数，`β_E` 为 Explain 残差，`δ_a` 为第 54 轮云边动作对齐误差。关键：**训练即验收**，四类误差来源被显式分离并可分别收窄。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 证书骇客 / 策略坍缩到易认证窄域 | 高 | held-out contact set + 证书-奖励梯度解耦 + entropy floor |
| 占用估计在接触模式稀疏边界偏置最大 | 高 | 分层/重要性采样 + 边界主动探索 + 置信带 |
| 力闭合证书对摩擦/柔顺建模误差敏感 | 高 | 区间摩擦锥证书 + 软指接触模型 + 在线参数辨识 |
| CGRL 约束投影每步代价高 | 中 | 拉格朗日对偶 + 稀疏证书更新（每 m 步） |
| DR 支撑覆盖半径高维不可估 | 中 | 自适应 densification + ξ 降维 + 分位数覆盖 |
| 奖励骇客检测误报 | 中 | 多目标帕累托 + knee 选择 + 人工审计回路 |

## 6. 本轮最大风险

**一句话**：把证书守卫前移进 RL 训练循环，能让"训练即验收、占用即剖面"，但其 soundness 的最大威胁是 **证书骇客与接触边界的占用偏置**——策略可能为了通过 `G_τ` 而坍缩到易认证的窄行为域（放弃真实抓取所需的大夹持力/大动作幅值），而 `α_S` 的占用估计恰在接触模式切换的稀疏边界处偏差最大，最终证书 sound、机器人却抓不住；故必须以 **接触模式分层采样 + 证书梯度与奖励梯度解耦 + 真实接触保留集（held-out contact set）** 三重护栏，宁可触发证书失效告警，也绝不让证书变成压制能力的紧箍咒。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（OCP×CGRL×CMP×SGO×DRC×RHP）

> 承接第 54 轮产物 v31。本轮把"技能从哪来、如何训练才能被证书接纳"与"接触密集抓取的可抓性"补齐，增加 **学习-接触层** 六个算子：
> - **OCP（Occupancy-Certified Profile）**：用策略占用测度 `d^π` 估计动作剖面 `α_S`，并给出置信下界；

> - **DRC（Domain-Randomization Certificate）**：把域随机化升格为 sim-to-real 成功率下界证书；
> - **RHP（Reward-Hack Pareto）**：奖励-证书帕累托与证书骇客分数，防目标错位。

## 2. 关键算法 伪代码

### IP-121 OCP

```python
def occupancy_profile(policy, env, cells, M, delta):
    counts = zeros(len(cells))
    for _ in range(M):
        for (s, a) in rollout(policy, env):
            counts[idx(a)] += 1
    alpha_hat = counts / counts.sum()
    eps = sqrt(log(2*len(cells)/delta) / (2*M))
    lcb = clip(alpha_hat - eps, 0.0, 1.0)
    return alpha_hat, lcb, eps

def cover_cert(lcb, A_T, theta_cov=0.8):
    return all(lcb[idx(a)] >= theta_cov for a in A_T)
```

### IP-122 CGRL

```python
def cgrl_train(policy, env, J0, tau, budget, A_T):
    J_cur = certify(policy, env)
    for k in range(budget):
        cand = ppo_step(policy, env, kl_target=tau)
        J_cand = certify(cand, env)
        feasible = (dominates(J_cand, J_cur)
                    and cover_cert(occupancy_profile(cand, env, cells, M, delta)[1], A_T)
                    and force_closure_cert(cand))
        if feasible:
            policy, J_cur = cand, J_cand
        else:
            policy = project_to_guard(cand, J_cur, env)
            J_cur = certify(policy, env)
        log_pareto(J_cur, reward(policy))
    return policy, J_cur
```

### IP-123 CMP

```python
def contact_mode_profile(rollouts):
    beta = defaultdict(float)
    for traj in rollouts:
        for (a, m) in traj:
            beta[(cell(a), m)] += 1
    return normalize(beta)

def force_closure_cert(grasp, mu_min, margin_min, f_min, f_max):
    W = friction_cone_generators(grasp.contacts, grasp.mu)
    margin = distance_to_boundary(convex_hull(W), origin)
    ok = (grasp.mu >= mu_min and f_min <= grasp.f <= f_max
          and margin >= margin_min)
    return ok, Cert(W, grasp.mu, grasp.f, margin)

def grasp_feasible(skill, A_T, beta, grasp):
    return (cover_cert(skill.alpha_lcb, A_T)
            and force_closure_cert(grasp, mu_min, margin_min, f_min, f_max)[0]
            and all(beta.get((a, m), 0) > 0 for a in A_T for m in MODES))
```

### IP-124 SGO

```python
def learn_options(skills, env, theta_a, tau_e, eta):
    options = [train_option(s, env) for s in skills]
    G = DiGraph()
    for i, oi in enumerate(options):
        for j, oj in enumerate(options):
            if i == j: continue
            reach = termination_lands_in(oi, oj.I, env)
            compat = jaccard(oi.I, oj.I)
            c_trans = transition_cost(oi, oj, env)
            if reach >= 1-eta and compat >= theta_a and c_trans <= tau_e:
                G.add_edge(i, j, compat=compat, c_trans=c_trans, reach=reach)
    return G
```

### IP-125 DRC

```python
def dr_certificate(policy, Xi, N_xi, L_xi, delta):
    samples = [sample(Xi) for _ in range(N_xi)]
    succ = [success(policy, xi) for xi in samples]
    rho_dr = lower_confidence_bound(succ, delta)
    r_xi = coverage_radius(Xi, samples)
    bound = rho_dr - L_xi * r_xi
    return DRC(Xi, N_xi, rho_dr, L_xi, r_xi), bound
```

### IP-126 RHP

```python
def reward_hack_score(R_prev, R_cur, rho_prev, rho_cur):
    dR = (R_cur - R_prev) / max(abs(R_prev), 1e-9)
    drho = (rho_prev - rho_cur) / max(abs(rho_prev), 1e-9)
    if dR <= 0: return 0.0
    return max(0.0, drho) / dR

def select_knee(pareto, lambda_J):
    return max(pareto, key=lambda p: p.R + lambda_J * p.rho)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| OCP | O(M·T + |A|) | O(|A|) | DKW 一致界，覆盖率 ≥ 1-δ |
| CGRL | O(K·(C_step+C_cert)) | O(θ_policy+|A|) | 守卫投影正确，`J` 单调不回归 |
| CMP | O(N·T·|M|) | O(|A|·|M|) | 接触模式完备，摩擦锥区间 sound |
| SGO | O(|S|²·(T+Eval)) | O(|S|²) | 终止落入统计显著，边 sound |
| DRC | O(N_ξ·T) | O(N_ξ) | 支撑覆盖 + Lipschitz 界 |
| RHP | O(|P|) | O(|P|) | 帕累托非支配，knee 稳定 |

**正确性定理（Certificate-Guarded RL Deployment Soundness）**
假设第 53–54 轮 (A22)–(A28) 成立；**(A29)** `sup_a|α̂_S(a)-α_S(a)| ≤ ε_occ` 以概率 `1-δ`；**(A30)** 接触模式剖面与力闭合证书在 `Δμ` 下 sound；**(A31)** `success(π,ξ)` 对 ξ 为 `L_ξ`-Lipschitz，DR 支撑覆盖半径 `r_Ξ`；**(A32)** CGRL 满足 `J` 单调不回归且奖励不降。则
```
P_success(π_deployed) ≥ ρ_DR^- - L_ξ·r_Ξ - ε_occ·|A_T| - κ_μ·Δμ - β_E - P(δ_a > Θ_a)
```
关键：**训练即验收**（CGRL 把部署门槛前移）、**占用即剖面**（OCP 消除外部采样偏差）、**接触即可行**（CMP 补上抓取特有的力闭合约束）、**随机化即下界**（DRC 把 sim-to-real gap 变成可计算项）。

## 6. 本轮最大风险

**一句话**：把证书守卫前移进 RL 训练循环，能让"训练即验收、占用即剖面"，但其 soundness 的最大威胁是 **证书骇客与接触边界的占用偏置**——策略可能为了通过 `G_τ` 而坍缩到易认证的窄行为域（放弃真实抓取所需的大夹持力/大动作幅值），而 `α_S` 的占用估计恰在接触模式切换的稀疏边界处偏差最大，最终证书 sound、机器人却抓不住；故必须以 **接触模式分层采样 + 证书梯度与奖励梯度解耦 + 真实接触保留集（held-out contact set）** 三重护栏，宁可触发证书失效告警，也绝不让证书变成压制能力的紧箍咒。
