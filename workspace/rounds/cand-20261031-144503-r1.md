# 第 13 轮（新灵感循环第 1 轮）· ENGRAM：把 33k 演示压成「语言索引的顺应性记忆」，用虚拟力矩在 5 步块内执行

> 检索/复核日期：**2026-10-31（UTC）**。赛事身份不变：宇树 **UniBot 世界挑战赛**（unibot.unitree.com），G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API。本轮承接第 10 轮 **FACT-VLA**、第 11 轮 **GEO-RESIDUAL**、第 12 轮 **CHUNK-SERVO**；三个灵感词是「长期记忆」「力矩控制」「自然语言指令」。本轮不推倒 CHUNK-SERVO 的「30 步规划 + 5 步伺服」，而是补它没有回答的两个问题：**接触应该多硬/多软？目标被挡住或被人移动后，机器人应该记住什么？**

## 0. 先给直觉：三个词不是三个模块，而是三个时间尺度

第一眼看上去，这三个词分别指向三个系统：长期记忆像一个数据库，力矩控制像一个底层控制器，自然语言指令像一个语义前端。把它们做成三个模块，会得到一个典型的拼装式方案：语言解析器 + 记忆检索 + 力矩控制器。问题是：谁来保证三者不打架？语言说“轻轻插”，记忆里却是“用力压”，力矩控制听谁的？

更好的组织方式是把它看成**同一个控制回路的三个时间尺度**：

| 时间尺度 | 灵感词 | 作用 | 典型周期 |
|---|---|---|---|
| 慢 | 长期记忆 | 从 33k 演示和本回合历史中检索「这类接触以前怎么做」 | 离线 / 整回合 |
| 中 | 自然语言指令 | 把任务语义编译成接触契约，决定「这是什么接触」 | 每次 `reset()` |
| 快 | 力矩控制 | 在 5 步块内把位置指令变成柔顺接触，决定「这一下多硬」 | 167 ms |
| 内环 | 底层位置控制 | 30Hz 跟踪位置指令 | 33 ms |

CHUNK-SERVO 已经做了「中 + 快」：VLA 负责 1 秒规划，视觉伺服负责 167ms 修正。但它仍然是**失忆的、纯运动学的**：

- 它只在当前帧里找目标；目标被夹爪或人手挡住 0.5 秒，伺服就退化成 VLA 开环，尽管 0.3 秒前它明明看见过目标。
- 它的伺服增益是固定的；插入时孔位对齐了，但轴向太硬，一推就卡住或弹开；挂杯时横向太软，杯子在杯架边缘蹭过去。
- 它只把语言指令当成任务 ID；但“plug”和“unplug”、“hang”和“stack”、“zip”和“pour”的接触方向、力方向、失败模式完全不同。

所以本轮的一句话是：

> **CHUNK-SERVO 让机器人看得更快；ENGRAM 让机器人记得更久、接触更柔。**

## 1. 动机：三个具体失败，指向同一个缺口

### 1.1 遮挡后的目标漂移

```text
t0: 头双目看见网口在 (x0,y0,z0)，腕部也看见边缘
t0+0.3s: 夹爪伸入，网口被夹爪挡住
t0+0.5s: 视觉伺服失去目标，回退 VLA 开环
t0+0.8s: 夹爪已经偏离 8mm，插入失败
```

CHUNK-SERVO 的 DG-KEYFRAME 解决的是“目标长什么样”，不是“目标在遮挡期间去哪了”。后者需要**回合内的情节记忆**：最后可靠观测 + base 运动 + 夹爪运动，传播目标位姿并膨胀协方差。

### 1.2 接触阶段的“硬度”错配

同一个固定增益，在自由空间和接触阶段都使用：

- 自由空间需要高刚度、高阻尼，才能抗重力和惯性；
- 插入阶段需要**轴向软、横向硬、旋转柔**，才能被动对正；
- 挂杯/叠碗需要**重力方向软、水平方向硬**，才能让杯子落进槽里；
- 拉拉链需要**切向柔、法向硬**，才能跟着拉链轨迹走而不撕扯。

固定增益不可能同时满足。CHUNK-SERVO 的“法向缩幅”是一个好的开始，但它没有回答“缩多少、什么时候缩、缩哪个方向”。这需要**相位相关的阻抗程序**。

### 1.3 语言只被当成任务标签

32 条指令里至少包含这些接触语义：

| 指令 | 接触语义 | 控制器应该做什么 |
|---|---|---|
| Plug the Ethernet cable into the port | 轴向插入 + 横向对齐 | 轴向低刚度、横向高刚度、先对齐后推 |
| Hang the cup on the rack | 重力挂接 + 释放时机 | 重力方向低刚度、水平方向高刚度、到位后慢释放 |
| Zip up the jacket | 切向跟踪 + 法向压紧 | 切向低刚度、法向高刚度、限制侧向力 |
| Pour out the medicine | 腕部旋转 + 瓶口对准 | 旋转柔顺、平移刚性、倾倒角速度限制 |
| Stack the bowls | 竖直叠放 + 接触检测 | 竖直低刚度、水平对中、接触即停 |
| Fold the towel | 变形物体 | 禁用精确阻抗，只用 VLA + 视觉 |

如果语言只作为 VLA 的 prompt，这些差异全部被压进一个黑箱；如果语言被编译成**接触契约**，它就能索引记忆、选择阻抗、设定恢复策略。

## 2. 关键判断：在只有位置接口的 API 上，“力矩控制”必须被重新定义

官方 API 给的是四路 RGB、双臂关节位置、EE 位姿、夹爪开合、下身体、语言；**没有关节力矩、没有力/触觉、没有深度**。动作是位置或 EE 绝对位姿，不是力矩。因此，任何声称“真机力矩闭环”的方案都是不诚实的。

本轮把“力矩控制”降级为三个可实现的部分：

1. **导纳/阻抗控制**：把位置指令看成虚拟弹簧-阻尼器的平衡点，用接触偏移生成柔顺运动。
2. **虚拟 wrench 观测器**：用关节跟踪误差、视觉穿透量、夹爪滞止，估计接触 wrench 的**方向**和**相对大小**，不追求牛顿级标定。
3. **力矩可行性过滤**：用 G1 URDF 逆动力学检查 5 步轨迹所需关节力矩，超限就缩放轨迹，避免底层位置控制器饱和。

我们只声称：**接触柔顺 + 力矩可行性**。不声称：力闭环、力传感、接触力精确调节。这是接口约束下最接近“力矩控制”的形式，也是本轮必须写清楚的边界。

## 3. 形式化核心：语言契约、顺应性 engram、虚拟力矩导纳

### 3.1 语言契约

把指令 `ℓ` 编译成一个结构化契约：

```math
C(\ell) = (v, o, r, \Phi, \Psi, s^*)
```

- `v`：动词/接触模式，取值于 `{pick, place, insert, hang, stack, zip, pour, twist, open, fold, wipe}`；
- `o, r`：被操作物体、受器；
- `\Phi = ((\phi_1,\mu_1,Z_1),\ldots,(\phi_K,\mu_K,Z_K))`：有序阶段 schema，`\mu_k` 是接触模式，`Z_k` 是阻抗模板；
- `\Psi`：约束集合，如 `align_before_push`、`do_not_bend`、`fragile`；
- `s^*`：成功谓词，如 `connector_seated`、`cup_on_hook`、`zipper_closed`。

对 32 条已知指令，`C(\ell)` 是**离线编译、人工核验、冻结成 JSON** 的查表；在线不加载第二个 LLM。未知指令回退到 `C_\emptyset`（保守阻抗 + VLA 开环）。

### 3.2 顺应性 engram

一条 engram 是“某个任务、某个阶段、某类受器”的顺应性记忆：

```math
e = (id, C_e, \phi_e, T_{r\leftarrow e}^*, I_w, Z_e, \delta_e, R_e, q_e)
```

- `T_{r\leftarrow e}^* = T_{b\leftarrow r}^{-1} T_{b\leftarrow e}`：演示关键帧的“受器→夹爪”相对位姿（继承 DG-KEYFRAME）；
- `I_w`：腕部目标图；
- `Z_e = (M_d,D_d,K_d,\sigma_n,\sigma_t,H_c)`：阻抗程序，`\sigma_n,\sigma_t` 是法向/切向刚度缩放，`H_c` 是该阶段建议的执行块长度；
- `\delta_e`：接触阈值（距离、穿透、夹爪滞止）；
- `R_e`：恢复宏（backoff、rotate、re-approach、re-grasp、re-plan）；
- `q_e`：质量分与演示统计。

检索分数：

```math
a(e) = \mathbb{1}[C_e=C] + 0.5\,\mathbb{1}[\phi_e=\phi]
     + 0.3\,e^{-\|T_{r\leftarrow e}^*-T_{r\leftarrow e}(t)\|^2/\sigma_p^2}
     + 0.2\,e^{-d_{\mathrm{img}}(I_w,I_w(t))/\sigma_i}
     + 0.1\,q_e.
```

取 top-k，对阻抗参数做加权中位数；置信度低于阈值就回退 CHUNK-SERVO。**记忆不是第二个模型，是一个带置信度的非参数检索表。**

### 3.3 虚拟 wrench 与导纳

虚拟 wrench：

```math
\hat w = J^{-T}\bigl(K_q e_q + D_q e_{\dot q}\bigr)
       + k_v\,\delta\,n
       + k_g\max(0,g_c-g_m)\,n_g,
```

其中 `e_q = q_c-q` 是关节跟踪误差，`\delta` 是视觉穿透量，`n` 是表面法向，`g_c-g_m` 是夹爪滞止，`k_v,k_g` 由仿真/真机标定。它不是力传感器，只用于判断“有没有接触、法向朝哪、相对多强”。

导纳：

```math
D_d\,\Delta\dot x + K_d\,\Delta x = \hat w,
\qquad
\Delta x_{k+1} = (D_d+\Delta t K_d)^{-1}(D_d\Delta x_k+\Delta t\hat w_k).
```

接触段法向刚度 `K_n\leftarrow\sigma_n K_n`，切向保留 `K_t`；`\sigma_n` 由 engram 给出。输出 `x_{\mathrm{cmd}} = x_{\mathrm{eq}}\circ\exp(\Delta x)`，其中 `x_{\mathrm{eq}}` 是 VLA 前馈 + CHUNK-SERVO 视觉修正后的平衡点。

### 3.4 情节记忆图

回合内维护一个关键帧图：

```math
G_t = (V_t,E_t),\quad
v=(t,\phi,x_{ee},\hat T_{r\leftarrow b},\Sigma,I_w,\text{contact},\text{status}).
```

- 目标可见时，用头双目/腕部更新 `\hat T`，协方差按观测噪声更新；
- 目标遮挡时，用 base 运动传播 `\hat T`，协方差按过程噪声膨胀；
- 人手编辑时，用 GEO-RESIDUAL 的 innovation 检验判定“机器人动作解释不了”，失效旧节点，触发重定位；
- 只保留 ≤256 个节点，按“阶段边界/接触事件/编辑/高不确定性”保留。

## 4. 三个可验证创新点（不是三个宏大名目）

1. **LCE（Language-Conditioned Engram）**：把 32 条指令编译成契约，用契约 + 相位 + 相对位姿 + 腕部图检索 33k 演示的顺应性程序。验证：语言 + 阶段检索是否优于“任务 ID + 固定增益”；G1/G7。
2. **VW-ADM（Virtual-Wrench Admittance）**：无扭矩传感器下的虚拟 wrench + 导纳 + URDF 逆动力学力矩过滤。验证：接触力代理、穿透深度、插入成功率是否优于固定伺服；G2/G3/G7。
3. **EMG（Episodic Memory Graph）**：回合内长期记忆图，处理遮挡、人手编辑和目标移动。验证：重定位时间、恢复率、位置/人为干扰轴是否涨点；G4/G5。

## 5. 与第 10/11/12 轮的关系：保留、升级、剪枝

| 轮次 | 保留 | 本轮升级 |
|---|---|---|
| FACT-VLA | 相位化 BC、CAC 柔顺执行、EGP 证据门控 | 相位成为记忆索引；CAC 从固定柔顺变成 engram 参数化阻抗 |
| GEO-RESIDUAL | 动作条件残差、米制表面距离、编辑检测 | 残差用于失效记忆节点；编辑检测触发情节记忆重定位 |
| CHUNK-SERVO | 30/5 双频、DG-KEYFRAME、单任务通道、竞赛组合 | 固定 5 步 → 相位相关 3/5/8；固定增益 → 记忆检索阻抗；纯运动学 → 导纳 + 力矩可行性 |

**剪枝**：不做真实力矩闭环、不做第二个学习模型、不做在线 LLM、不在正式计分轮使用跨 trial 成功标签、不做 6D 物体位姿网络、不对变形任务启用精确阻抗。

## 6. 为什么现在能做

- 33k 成功演示已经存在，且带四路视频、EE 位姿、任务语言；这是离线 engram 的原料。
- 头双目已标定，腕部可一次性标定；相对位姿和局部几何是现成的。
- 官方 WLA 的 30 步 chunk 和挑战赛 API 的固定 chunk 机制，已经把“双频执行”变成必须面对的问题；CHUNK-SERVO 已经证明了这个方向。
- G1 URDF 和官方 MuJoCo/IsaacLab 仓库，足以做逆动力学力矩过滤和导纳参数标定。
- 单模型规则允许“非参数记忆 + 确定性控制器”，只要不在线加载第二个学习模型。

## 7. 最大的风险

**最大风险是虚拟 wrench 观测器：如果关节跟踪误差与接触力相关性弱，导纳层就会退化成“更慢的伺服”，ENGRAM 的收益只剩记忆检索和相位 chunk。**

# 第 13 轮产物 · ENGRAM 技术报告

> 检索/复核日期：**2026-10-31（UTC）**。对象：宇树 **UniBot 世界挑战赛**（G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API）。本报告是第 13 轮想法区「ENGRAM」的工程化产物；承接第 10 轮 **FACT-VLA**、第 11 轮 **GEO-RESIDUAL**、第 12 轮 **CHUNK-SERVO**。本轮**不新增未经核实的赛事事实**：规则、API、数据、WLA、榜单取证沿用 2026-10-28 的 A 级核验；所有新增机制均标注为 C 级设计假设，并配可执行的否证门。

## 0. 结论与边界

### 0.1 一句话结论

在只有位置接口、没有力矩/力/触觉/深度的远程 API 上，真正的力矩控制不可实现；但可以把 CHUNK-SERVO 的 5 步执行块升级为「**语言索引的顺应性记忆 + 虚拟 wrench 导纳 + 逆动力学力矩可行性过滤**」：用自然语言契约选择接触语义，用 33k 演示的 engram 选择阻抗程序和恢复宏，用回合内情节记忆在遮挡/人手编辑时保持目标，用相位相关 chunk（3/5/8）在反馈频率和稳定性之间折中。它不新增学习模型，不依赖力传感器，也不推翻 CHUNK-SERVO。

### 0.2 本轮增量（相对第 12 轮）

| 维度 | 第 12 轮 CHUNK-SERVO | 第 13 轮 ENGRAM |
|---|---|---|
| 指令 | 任务 ID/语言只进 VLA | 语言编译成契约，索引记忆与阻抗 |
| 目标 | 当前帧 + DG-KEYFRAME | 当前帧 + 回合内情节记忆图（遮挡/编辑） |
| 伺服 | 固定增益运动学修正 | 记忆检索阻抗 + 虚拟 wrench 导纳 |
| 执行块 | 固定 5 步 | 相位相关 3/5/8 步 |
| 接触 | 法向缩幅启发式 | 法向/切向阻抗程序 + 力矩可行性过滤 |
| 恢复 | 检测→停→重定位→重规划 | 检测→失效记忆节点→检索恢复宏→重定位/重规划 |
| 合规 | 确定性伺服 | 非参数记忆 + 确定性控制；离线契约冻结 |

### 0.3 证据等级

| 等级 | 含义 | 本报告中的例子 |
|---|---|---|
| A | 官方文档、提交模板、数据集元数据、排行榜 JSON 直接核实（2026-10-28，沿用） | 规则、API、33,276 eps、WLA `chunk_size=30`、榜单 29.7% |
| B | 我们在公开数据/网页上做的分析，可复现（沿用） | 榜单 `step~success` 回归、跨模型任务相关 |
| C | 本轮新增设计假设，需 G0–G9 验证 | 虚拟 wrench 相关性、engram 检索有效率、导纳稳定域、相位 chunk 收益 |

### 0.4 明确不声称

- **不声称真实力控/力传感**。API 没有 torque/force/tactile；本方案是软件导纳 + 虚拟 wrench 代理。
- **不声称跨 trial 学习在正式计分轮合规**。默认关闭跨 trial 成功标签；只在单任务不计分通道做自适应实验。
- **不声称 engram 一定提升成功率**。所有收益都是 C 级假设，必须过 G1–G9。
- **不声称语言契约覆盖任意指令**。只覆盖 32 条已知指令 + 保守兜底。
- **不声称仿真成功率能预测真机**。仿真只用于稳定域、相对排序和故障注入。

### 1.2 本轮新增的 C 级假设

| 假设 | 内容 | 验证门 | 否证后的动作 |
|---|---|---|---|
| H-A | 关节跟踪误差 + 视觉穿透 + 夹爪滞止，能给出接触 wrench 的方向/相对大小 | G2 | 关闭导纳，只保留记忆检索 + 相位 chunk |
| H-B | 演示相位可稳定分割，engram 检索 top-5 含几何有效目标 ≥80% | G1 | 改为任务级固定阻抗模板 |
| H-C | 32 条语言契约能正确选择接触模式与阻抗模板 | G0 | 改为手工模板 + 仅任务 ID |
| H-D | 回合内情节记忆能降低遮挡/编辑后的重定位时间 | G4/G5 | 关闭 EMG，回退当前帧伺服 |
| H-E | 相位相关 chunk（3/5/8）不增加 p99，且接触段更稳 | G6 | 固定 5 步 |
| H-F | 跨 trial 记忆（若启用）只带来校准收益、不泄露标签 | G9 | 正式计分轮永久关闭 |

### 1.3 早期否证条件

以下任一条成立，本轮方案应停止或降级：

1. G0 契约核验 <32/32，或在线指令匹配失败率 >10%。
2. G1 top-5 几何有效 <60%，或相对位姿误差 >10 mm/4°。
3. G2 导纳在仿真中振荡/发散，或虚拟 wrench 与真实接触力相关性 <0.3。
4. G3 单任务 A/B 中 5 个任务里少于 2 个方向为正，且 FoldTowel 回归 >5pp。
5. G6 p99 增加 >50 ms 或 timeout 率上升。

## 2. 问题形式化

### 2.1 带记忆的 POMDP

把一次任务执行定义为一个带指令和外部记忆的 POMDP：

```math
\mathcal{M} = (\mathcal{S}, \mathcal{A}, \mathcal{O}, T, Z, R, \gamma, \ell, \mathcal{E}),
```

- `\mathcal{S}`：机器人关节/EE、物体位姿、接触模式、相位、人类干预状态；
- `\mathcal{A}`：挑战赛 `ee` 动作（2×6 EE + 2×1 gripper + 7 pivot）或 `joint` 动作；
- `\mathcal{O}`：四路 RGB + 本体 + 语言；
- `T(s'|s,a)`：转移动力学，含接触/摩擦/人手干预；
- `Z(o|s)`：观测模型；
- `R`：任务成功 + 步骤分 - 安全/超时惩罚；
- `\ell`：自然语言指令；
- `\mathcal{E}`：离线 engram 库（只读）。

策略：

```math
a_t \sim \pi\bigl(a_t \mid o_t, \ell, \mathcal{E}, G_t, \theta_t\bigr),
```

其中 `G_t` 是回合内情节记忆图，`\theta_t` 是导纳状态（偏移、速度）。记忆更新：

```math
G_{t+1} = U(G_t, o_t, a_t), \qquad
\theta_{t+1} = \Phi(\theta_t, \hat w_t, Z_t, \Delta t).
```

目标：

```math
\max_{\pi}\ \mathbb{E}\left[\sum_{t=0}^{T}\gamma^t R_t\right]
\quad \text{s.t.}\quad
\text{single-model},\ \text{latency}\le L_{\max},\ \text{no force sensing}.
```

### 2.2 语言契约

定义契约文法：

```math
C(\ell) = (v, o, r, \Phi, \Psi, s^*),
```

```math
\Phi = \bigl((\phi_1,\mu_1,Z_1),\ldots,(\phi_K,\mu_K,Z_K)\bigr),
```

- `v\in\mathcal{V}`：接触动词集合；
- `o,r`：物体/受器类别；
- `\phi_k`：阶段名（reach, grasp, align, contact, insert, transport, release…）；
- `\mu_k\in\{\text{free},\text{approach},\text{grasp},\text{contact},\text{insert},\text{transport},\text{release}\}`；
- `Z_k=(M_k,D_k,K_k,\sigma_{n,k},\sigma_{t,k},H_{c,k})`：第 k 阶段的名义阻抗与建议 chunk；
- `\Psi=\{\psi_j\}`：约束（fragile、align_before_push、no_bend、keep_upright…）；
- `s^*`：成功谓词。

在线映射 `\ell\mapsto C(\ell)` 是确定性查表：

```math
C(\ell)=
\begin{cases}
C_{\mathrm{task}(id)}, & \ell \text{ 命中 32 条冻结指令},\\
C_{\mathrm{kw}}(\ell), & \text{关键词/属性解析成功},\\
C_{\emptyset}, & \text{否则}.
\end{cases}
```

`C_\emptyset` 使用保守阻抗（低刚度、高阻尼、`H_c=5`），不启用任务特定 engram。

### 2.3 顺应性 engram

一条 engram 定义为：

```math
e=(id, C_e, \phi_e, T_{r\leftarrow e}^*, I_w, Z_e, \delta_e, R_e, q_e, n_e).
```

相对目标：

```math
T_{r\leftarrow e}^* = T_{b\leftarrow r}^{-1}(k)\,T_{b\leftarrow e}(k),
```

其中 `k` 是演示关键帧。在线期望夹爪位姿：

```math
T_{b\leftarrow e}^{d}(t)=T_{b\leftarrow r}(t)\,T_{r\leftarrow e}^*.
```

阻抗程序：

```math
Z_e=(M_d,D_d,K_d,\sigma_n,\sigma_t,H_c,\tau_{\max}),
```

- `M_d,D_d,K_d`：笛卡尔惯量/阻尼/刚度；
- `\sigma_n,\sigma_t`：接触段法向/切向缩放；
- `H_c`：该阶段建议的执行块长度（3/5/8）；
- `\tau_{\max}`：逆动力学力矩过滤阈值。

恢复宏集合：

```math
R_e=\{r_1,\ldots,r_m\},\qquad
r\in\{\text{backoff}(d),\text{rotate}(\alpha),\text{re-approach},\text{re-grasp},\text{re-plan}\}.
```

### 2.4 检索与置信度

特征：

```math
f(e)=(\mathbb{1}[C_e=C],\ \mathbb{1}[\phi_e=\phi],\
\|T_{r\leftarrow e}^*-T_{r\leftarrow e}(t)\|,\
d_{\mathrm{img}}(I_w,I_w(t)),\ q_e).
```

分数：

```math
a(e)=\lambda_1 \mathbb{1}[C_e=C]
+\lambda_2 \mathbb{1}[\phi_e=\phi]
+\lambda_3 e^{-\|T^*-T\|^2/\sigma_p^2}
+\lambda_4 e^{-d_{\mathrm{img}}/\sigma_i}
+\lambda_5 q_e,
```

默认 `\lambda=(1.0,0.5,0.3,0.2,0.1)`。

top-k 检索后，对连续参数取加权中位数：

```math
Z^\star=\operatorname{wmedian}\{(Z_e,a(e)):e\in\mathrm{top}_k\}.
```

置信度：

```math
c=\frac{\max_e a(e)}{\sum_j \lambda_j}.
```

若 `c<\theta_c`（默认 0.45），回退到任务级默认 `Z_{\mathrm{task}}`；若仍无，回退 CHUNK-SERVO 固定增益。

### 2.5 记忆增强策略类与合规边界

本方案把策略限制为：

```math
\pi(a_t\mid o_t,\ell,\mathcal{E},G_t)
=
\pi_{\mathrm{VLA}}(a_t^{ff}\mid o_t,\ell)
\ \circ\
\pi_{\mathrm{servo}}(\Delta x_t\mid o_t,C(\ell),e_t,G_t)
\ \circ\
\pi_{\mathrm{adm}}(\Delta x_t^{adm}\mid \hat w_t,Z_t).
```

- `\pi_{\mathrm{VLA}}`：唯一学习模型（官方 WLA/VLA）；
- `\pi_{\mathrm{servo}}`：确定性视觉伺服（继承 CHUNK-SERVO）；
- `\pi_{\mathrm{adm}}`：确定性导纳控制器；
- `\mathcal{E}`：离线构建、只读、非参数；
- `G_t`：回合内状态，不含官方成功标签。

**正式计分模式**（scored mode）：

```text
reset() → 清空 G_t、θ_t、计划缓存、相位信念；
保留：每端口相机外参、RTT 统计、传感器偏置（无任务结果）。
```

**自适应模式**（adaptive mode，仅单任务不计分通道）：

```text
允许跨 trial 更新 engram 统计与阻抗档位；
不得读取官方分数作为标签；
只使用自监督接触结果（滑移、穿透、夹爪滞止、视觉成功谓词）。
```

这样把“长期记忆”的合规风险显式隔离：正式轮用离线/回合内记忆，自适应实验只在不计分通道做。

### 2.6 目标函数与约束

```math
J =
\frac{1}{32}\sum_{t=1}^{32}\frac{1}{10}\sum_{j=1}^{10} y_{t,j}
+\beta\,\frac{1}{32}\sum_{t=1}^{32} s_t
-\lambda_s\,\mathbb{E}[\text{safety}]
-\lambda_l\,\mathbb{E}[\text{latency}],
```

其中 `y_{t,j}\in\{0,1\}` 是成功，`s_t` 是步骤分。约束：

```math
\text{model count}=1,\qquad
p99(\text{get\_action})\le 150\,\mathrm{ms},\qquad
\|\tau_{\mathrm{req}}\|_\infty\le \tau_{\max}.
```

## 3. 系统架构

### 3.1 进程/端口拓扑

```text
                    ┌──────────────────────────────────────────┐
                    │  Evaluator (N ports 8765..8765+N-1)      │
                    └──────────────────┬───────────────────────┘
                                       │ websocket: obs / chunk
                                       ▼
                    ┌──────────────────────────────────────────┐
                    │  Per-port PolicyService (CPU)            │
                    │  ├─ language contract lookup (frozen)    │
                    │  ├─ phase belief + episodic graph G_t    │
                    │  ├─ engram retrieval (shared RO)         │
                    │  ├─ CHUNK-SERVO correction               │
                    │  ├─ virtual wrench + admittance          │
                    │  ├─ torque-feasibility filter            │
                    │  ├─ plan cache (30-step VLA)             │
                    │  └─ action adapter (WLA 54D → API 21D)  │
                    └──────────────────┬───────────────────────┘
                                       │ async, batched
                                       ▼
                    ┌──────────────────────────────────────────┐
                    │  Shared VLA server (GPU)                 │
                    │  UnifoLM-WLA-1.0 / VLA-0, 30-step        │
                    └──────────────────────────────────────────┘
```

- 每端口一个 `PolicyService`，独立 `reset()`、独立 `G_t`、独立导纳状态、独立相位信念。
- engram 库只读共享（copy-on-write / mmap），不随端口复制。
- VLA 请求异步、可批处理；VLA 是唯一学习模型。
- 所有新增计算在 CPU；不抢 GPU。

### 3.2 三个时间尺度

| 层 | 频率/周期 | 输入 | 输出 | 失败回退 |
|---|---|---|---|---|
| 语言/engram | 每次 reset / 阶段边界 | 指令、相位、目标位姿、腕部图 | 契约 `C`、engram `e`、阻抗 `Z`、`H_c` | 任务默认 `Z` |
| VLA 规划 | ~1 s（30 步） | 三路图 + 本体 + 语言 | 30 步前馈计划 | 旧计划 + 伺服 |
| 视觉伺服 | 167 ms（5 步） | 四路图 + 本体 | 6D 修正 `\Delta x_s` | 不修正 |
| 导纳/力矩过滤 | 167 ms（或 100/267 ms） | `\hat w`、`Z`、`x_eq` | 柔顺偏移 `\Delta x_a` | 关闭导纳 |
| 底层位置控制 | 33 ms | 5 步绝对位姿 | 关节位置跟踪 | 机器人自身保护 |

### 3.5 状态机

```text
INIT ──first obs──▶ PLAN ──plan ready──▶ APPROACH
  ▲                   ▲                    │
  │                   │                    ├─ target visible ──▶ ALIGN
  │                   │                    │                     │
  │                   │                    │                     ├─ contact ──▶ CONTACT
  │                   │                    │                     │                │
  │                   │                    │                     │                ├─ insert/place ──▶ RELEASE
  │                   │                    │                     │                │
  │                   │                    │                     │                └─ slip/miss ──▶ RECOVER
  │                   │                    │                     │
  │                   └── replan ◀─────────┴── edit/occlusion ───┘
  │                                                              │
  └──────────────────────── DONE ◀── success/max steps ──────────┘
```

- `APPROACH`：PBVS 主导，导纳刚度较高。
- `ALIGN`：IBVS/PBVS 混合，法向预柔顺。
- `CONTACT`：engram 阻抗；法向软、切向硬；虚拟 wrench 监控。
- `RELEASE`：低刚度、慢速张开；防物体被带起。
- `RECOVER`：按 engram `R_e` 选择宏；最多 3 次。
- `DONE`：清理 `G_t`/`θ_t`，等待 `reset()`。

### 3.6 回退阶梯

```text
ENGRAM（契约 + engram + 导纳 + 力矩过滤）
  ↓ 低置信度/导纳不稳定
CHUNK-SERVO（固定 5 步 + 视觉伺服 + 固定增益）
  ↓ 视觉失效
VLA 开环（旧计划/新计划）
  ↓ VLA 超时
安全 hold（上一组合法 chunk 或零增量）
```

每一层都必须返回合法动作；绝不返回 NaN/错误形状。

### 4.1 离线编译

### 4.4 在线解析与兜底

```python
def parse_contract(obs_language):
    if obs_language in FROZEN_BY_TEXT:
        return FROZEN_BY_TEXT[obs_language], 1.0
    task_id = match_task_id(obs_language)
    if task_id is not None:
        return FROZEN_BY_TASK[task_id], 0.9
    C = keyword_contract(obs_language)   # 动词/物体/介词
    if C is not None:
        return C, 0.6
    return GENERIC_CONTRACT, 0.2
```

关键词解析只使用冻结词表（动词同义词、物体名词、介词），不调用模型。置信度低于 0.5 时，不启用 engram 特定阻抗，只使用 `C_\emptyset`。

### 4.5 契约核验

离线核验三件事：

1. **语义一致**：verb/object/receptacle 与任务元数据一致；不能把“拔网线”解析成“插网线”。
2. **阶段完备**：至少包含 reach/grasp/contact/release；插入任务必须包含 align。
3. **约束可执行**：`align_before_push` 对应“先降低横向误差到阈值，再允许轴向推进”；`stop_on_stall` 对应夹爪滞止/视觉穿透阈值。

核验不通过 → 退回手工模板。

### 4.6 语言到底带来什么

- **消歧**：plug vs unplug 的轴向力方向相反；hang vs stack 的重力方向/释放时机不同。
- **索引**：契约是 engram 的第一过滤键，避免“插网线”检索到“拔网线”的阻抗程序。
- **约束**：`align_before_push` 直接变成阶段门控；不需要 VLA 在动作里隐式学会。
- **恢复**：不同接触模式的失败宏不同；语言契约选择宏集合。

## 5. 顺应性记忆（Engram）

### 5.1 离线管线

```text
for each episode:
    phases = segment(episode)                  # FACT-VLA 相位分割
    for each phase φ:
        k = select_keyframe(φ)                 # 接触前 1-3 帧 / 目标入腕部视野 / 夹爪距离 <5cm
        T_base_target = estimate_target(k)     # 头双目 + 局部 ICP/平面/圆/线
        T_base_ee = episode.state[k].ee_pose
        T_target_ee = inv(T_base_target) @ T_base_ee
        I_w = episode.wrist[k]
        Z = identify_impedance(φ, episode, k)  # 启发式 + 仿真系统辨识
        δ = estimate_contact_thresholds(φ)
        R = mine_recovery_macros(episode, φ)   # 成功演示无恢复段时用几何宏
        q = quality_score(k, I_w, T_base_target)
        index.add(task, φ, T_target_ee, I_w, Z, δ, R, q)
```

### 5.2 关键帧选择

| 任务类型 | 关键帧 | 理由 |
|---|---|---|
| 插入/拔出 | 首次接触前 1–3 帧 + 接触稳定后 1 帧 | 目标可见、夹爪接近、接触模式明确 |
| 挂/叠/放置 | 目标进入腕部视野且夹爪距离 <5 cm | 相对位姿最可靠 |
| 拉链/锁/拧 | 夹爪咬合前 1 帧 | 对齐关系最关键 |
| 倾倒/转移 | 瓶口/针管对准前 1 帧 | 旋转与液面约束 |
| 变形 | 不建精确 engram | 只建相位/语义模板 |

### 5.3 目标位姿估计

- 刚体受器：头双目视差 + 局部 ICP/平面/圆/线拟合；
- 透明/反光：用腕部目标图 + 头双目粗深度；置信度低不建库；
- 目标被夹爪挡住：用演示 EE 位姿反推，或只存腕部目标图；
- 在线：目标位姿由 `G_t` 维护，不依赖离线绝对位姿。

### 5.4 阻抗辨识（诚实版）

演示数据没有关节力矩，因此不能做真正的逆强化学习。我们只做三件事：

1. **从轨迹形状估阻尼/速度**：接近段的减速度、接触前的速度、释放段的张开速度；
2. **从接触几何估刚度比**：插入段的横向/轴向位移比、挂接段的竖直/水平位移比；
3. **从仿真系统辨识绝对增益**：在 MuJoCo/IsaacLab 里扫 `K_p/K_d`，用真实演示的末端轨迹做相对排序，不拟合真实力矩。

```math
Z_e = \operatorname{clip}\bigl(Z_{\mathrm{prior}}(C,\phi)\odot
      g_{\mathrm{demo}}(e),\ Z_{\min}, Z_{\max}\bigr),
```

其中 `Z_{\mathrm{prior}}` 是契约模板，`g_{\mathrm{demo}}` 是从演示轨迹形状得到的缩放因子（0.5–2.0）。这是启发式，不是学习到的策略；在报告中明确标为 C 级。

### 5.5 恢复宏挖掘

- 成功演示通常没有恢复段；从失败/重试片段（如果有）挖掘“backoff → rotate → re-approach”序列；
- 没有数据时，用几何宏：
  - `backoff(d)`：沿插入轴反向 1–2 cm；
  - `rotate(α)`：绕插入轴 ±5°；
  - `re-approach`：重新执行 align；
  - `re-grasp`：张开、后退、重新夹紧；
  - `re-plan`：用新图像请求 VLA。
- 宏的选择由失败签名决定：

```math
\text{fail signature} = (\phi,\mu,\text{visual residual},\text{gripper stall},\text{pose innovation}).
```

### 5.6 检索复杂度与规模

- 33,276 eps；A 档 19 任务约 19k eps；每 eps 1–2 个伺服关键帧 → 20–40k engrams。
- 128×128 JPEG 5–10 KB → 200–400 MB；
- 描述子 256–512 floats → 40–80 MB；
- 索引/元数据 <100 MB；
- 总 <1 GB，可随提交包分发或预加载。
- 检索：任务/阶段过滤后候选通常 <2k；精确重排 O(k·d)，d=128–512；HNSW 只在全局检索时使用。

### 5.7 回合内情节记忆图

节点：

```python
Node = {
    "t": int,
    "phase": str,
    "ee": np.ndarray(7),          # xyz + quat
    "T_rb": np.ndarray(4,4),      # target in base
    "Sigma": np.ndarray(6,6),     # pose covariance
    "I_w": np.ndarray(H,W,3),     # wrist image (compressed)
    "contact": bool,
    "status": "valid" | "stale" | "edited",
}
```

边：

- 时间边 `v_i → v_{i+1}`；
- 对象身份边：同一 target class / 同一视觉 track；
- 因果边：动作节点 → 接触事件节点。

更新规则：

```text
if new observation has target:
    T_obs, Σ_obs = estimate_target(obs)
    T_pred = propagate(T_last, base_motion)
    Σ_pred = Σ_last + Q
    if NIS(T_obs, T_pred, Σ_pred) < χ²_threshold:
        fuse(T_last, T_obs)          # Kalman update
    else:
        if robot_action_explains(innovation) == False:
            mark_edited(); invalidate_stale_nodes()
        else:
            reinitialize_track()
elif target occluded:
    T_pred = propagate(T_last, base_motion)
    Σ_pred = Σ_last + Q
    store_predicted_node()
```

传播：

```math
T_{r\leftarrow b}(t)=T_{b(t)\leftarrow b(t-1)}\,T_{r\leftarrow b}(t-1),
\qquad
\Sigma_t = A\Sigma_{t-1}A^\top+Q.
```

`T_{b(t)\leftarrow b(t-1)}` 由 `lower_body`/腰部关节和 base 运动恢复（第 11 轮已验证）。

剪枝：

```math
u(v)=\mathbb{1}[\text{phase boundary}]
+\mathbb{1}[\text{contact}]
+\mathbb{1}[\text{edit}]
+\mathbb{1}[\Sigma>\Sigma_{\mathrm{hi}}].
```

保留 `u` 最高的 ≤256 个节点；其余压缩为摘要（时间、阶段、目标位姿、协方差）。

### 5.8 人手编辑处理

编辑检测继承第 11 轮：

```math
\text{edit\_score} =
\min\bigl(
\|\text{residual}_{\text{static}}\|,
\|\text{residual}_{\text{grasp}}\|
\bigr).
```

当 `edit_score > θ_e` 连续 K 帧：

1. 停止导纳/伺服推进；
2. 将 `G_t` 中早于最后可靠观测的节点标记 `stale`；
3. 用头双目重定位目标；
4. 若目标可见 → 更新 engram 目标位姿，恢复保守增益；
5. 若不可见 → 请求 VLA 重规划；
6. 超过最大重试 → 安全失败。

## 6. 虚拟 wrench 与导纳控制

### 6.1 接口现实

- 观测：关节位置 `q`、EE 位姿、夹爪开合、四路 RGB；
- 动作：绝对 EE 位姿或关节位置；
- 没有 `q̇`、`τ`、`F/T`、深度。

因此：

```text
真正的力矩控制：τ_cmd = ...        ← 不可用
可实现的替代：x_cmd = x_eq + Δx    ← 导纳/阻抗
```

### 6.2 虚拟 wrench 观测器

```math
\hat w =
J^{-T}\bigl(K_q e_q + D_q e_{\dot q}\bigr)
+ k_v\,\delta\,n
+ k_g\max(0,g_c-g_m)\,n_g.
```

各项含义：

| 项 | 来源 | 物理含义 | 风险 |
|---|---|---|---|
| `J^{-T}(K_q e_q + D_q e_{\dot q})` | 关节跟踪误差 | 底层位置控制器为抵抗外力产生的力矩 | `K_q,D_q` 未知；需标定 |
| `k_v \delta n` | 头双目/腕部视觉穿透 | 接触法向力代理 | 透明/反光/遮挡失效 |
| `k_g(g_c-g_m)n_g` | 夹爪指令 vs 实际开合 | 夹持/阻挡力代理 | 夹爪模型不准则误判 |

`e_{\dot q}` 如果 API 不提供 `q̇`，用有限差分：

```math
\dot q_t \approx \frac{q_t-q_{t-1}}{\Delta t}.
```

融合与置信度：

```math
c_w = \sigma\bigl(a_1 c_{\mathrm{cal}} + a_2 c_{\mathrm{vis}} + a_3 c_{\mathrm{grip}}\bigr),
```

其中 `c_{\mathrm{cal}}` 是标定残差，`c_{\mathrm{vis}}` 是视觉有效像素比例，`c_{\mathrm{grip}}` 是夹爪信号一致性。只有 `c_w>c_{\min}`（默认 0.5）才启用导纳；否则 `\Delta x_a=0`。

低通：

```math
\hat w_t^{f} = \alpha \hat w_t + (1-\alpha)\hat w_{t-1}^{f},
\qquad
\alpha = \frac{\Delta t}{\tau_w+\Delta t}.
```

### 6.3 导纳控制律

连续形式：

```math
M_d\,\Delta\ddot x + D_d\,\Delta\dot x + K_d\,\Delta x = \hat w.
```

默认使用**一阶导纳**（准静态，接触柔顺足够）：

```math
D_d\,\Delta\dot x + K_d\,\Delta x = \hat w.
```

隐式离散（无条件稳定）：

```math
\Delta x_{k+1} = (D_d+\Delta t K_d)^{-1}
\bigl(D_d\,\Delta x_k+\Delta t\,\hat w_k\bigr).
```

姿态用旋转向量：

```math
D_r\,\Delta\dot\theta + K_r\,\Delta\theta = \hat\tau,
\qquad
\Delta\theta_{k+1} = (D_r+\Delta t K_r)^{-1}
\bigl(D_r\,\Delta\theta_k+\Delta t\,\hat\tau_k\bigr).
```

输出：

```math
x_{\mathrm{cmd}} = x_{\mathrm{eq}}\circ\exp(\Delta x),
\qquad
\|\Delta x\|\le\delta_p,\ \|\Delta\theta\|\le\delta_r.
```

默认 `\delta_p=1.5` cm，`\delta_r=0.08` rad；接触段可降到 `0.5` cm / `0.03` rad。

### 6.4 阻抗调度

| 阶段 | `K_t`（切向/横向） | `K_n`（法向/轴向） | `D` | `H_c` | 备注 |
|---|---:|---:|---:|---:|---|
| free / transport | 高 | 高 | 高 | 8 | 抗重力/惯性 |
| approach | 中 | 中 | 中 | 5 | 预接触减速 |
| contact | 高 | `σ_n K_n`（0.2–0.5） | 中 | 3–5 | 法向柔顺 |
| insert | 高 | `σ_n K_n`（0.1–0.3） | 中 | 3 | 轴向被动对正 |
| grasp | 高 | 高 | 高 | 5 | 夹持稳定 |
| release | 低 | 低 | 低 | 5 | 慢速张开 |
| deformable | 低 | 低 | 低 | 5 | 禁用精确阻抗 |

调度来自 engram `Z_e`，不是手写固定值；上表是默认模板。

### 6.5 力矩可行性过滤

给定 5 步 EE 轨迹 `x_{1:H}`，用 IK 得到关节轨迹 `q_{1:H}`，有限差分得到 `\dot q,\ddot q`，逆动力学：

```math
\tau_{\mathrm{req},k} =
M(q_k)\ddot q_k + C(q_k,\dot q_k)\dot q_k + g(q_k)
+ J(q_k)^\top \hat w_k.
```

若 `\|\tau_{\mathrm{req}}\|_\infty>\tau_{\max}`：

```math
\alpha = \min\left(1,\frac{\tau_{\max}}{\|\tau_{\mathrm{req}}\|_\infty}\right),
\qquad
x_k' = x_0 + \alpha(x_k-x_0),
```

重新 IK / 逆动力学，直到可行或 `\alpha<\alpha_{\min}`。若仍不可行，降低 `H_c` 或拒绝导纳修正。

**注意**：这是**可行性过滤**，不是力矩控制。它保证“请求的轨迹在 URDF 模型下不需要超过阈值的关节力矩”，不保证真实接触力安全；真实安全仍靠限速、限幅、最大重试和机器人底层保护。

### 6.6 延迟与稳定域

反馈周期：

```math
T_{\mathrm{fb}} = \frac{H_c}{f_c}+\tau.
```

| 场景 | `H_c` | `f_c` | `\tau` | `T_fb` | 导纳更新率 |
|---|---:|---:|---:|---:|---:|
| 自由运输 | 8 | 30 | 50 ms | 317 ms | 3.75 Hz |
| 默认 | 5 | 30 | 50 ms | 217 ms | 6 Hz |
| 接触/插入 | 3 | 30 | 50 ms | 150 ms | 10 Hz |
| 高 RTT | 3 | 30 | 150 ms | 250 ms | 10 Hz |
| 低控制频率 | 3 | 10 | 50 ms | 350 ms | 3.3 Hz |

一阶导纳的离散稳定性与 `\Delta t` 无关（隐式），但**延迟**会破坏稳定域。简化延迟模型：

```math
\Delta x_{k+1}=A\Delta x_k+B\hat w_{k-d},
\qquad
A=(D+\Delta t K)^{-1}D.
```

`d=\tau/(H_c/f_c)`。由于 `\rho(A)<1`，无延迟时稳定；有延迟时，增益需降档：

```math
K_{\mathrm{eff}} = \frac{K_0}{1+\tau/\tau_0},
\qquad \tau_0=50\,\mathrm{ms}.
```

仿真扫 `\tau\in\{0,50,100,150\}` ms，记录超调/振荡；真机只在稳定域内启用。

### 6.7 接触方向分解

由视觉表面法向 `n` 构造切向基 `t_1,t_2`：

```math
\Delta x = \Delta x_n n + \Delta x_{t_1}t_1 + \Delta x_{t_2}t_2.
```

接触段：

```math
K_n\leftarrow\sigma_n K_n,\qquad
K_{t_i}\leftarrow K_{t_i},
```

`\sigma_n` 来自 engram；若 `\hat w_n` 超过 `\tau_{\max}`，进一步降低 `\sigma_n` 或后退。切向保留是为了不丢失插入方向；法向降低是为了被动对正。

### 6.8 安全包络

- `\|\Delta x\|\le\delta_p`，`\|\Delta\theta\|\le\delta_r`；
- `\|\hat w\|\le w_{\max}` 才启用；超过则后退/停止；
- 连续 3 个块 `\|\Delta x\|>\delta_{\mathrm{persist}}` → 判定目标估计/标定异常，回退；
- 编辑检测触发 → 立即停止推进；
- 最大恢复次数 3；
- 任何异常 → 返回上一组合法 chunk 或安全 hold。

## 7. 与 CHUNK-SERVO 的集成

### 7.1 `get_action` 伪代码

```python
class EngramPolicy:
    def get_action(self, obs):
        self._tick(obs)

        # 1. language + phase + memory
        C, c_C = parse_contract(obs.language)
        phi = self.phase_belief.update(obs, C)
        self.graph.update(obs, C, phi)
        T_hat, Sigma = self.graph.query_target(obs, C)

        # 2. engram retrieval at phase boundary / every N blocks
        if self._need_retrieval(phi):
            e, c_e = self.engram.retrieve(C, phi, T_hat, obs.wrist)
        else:
            e, c_e = self.current_engram, self.current_conf

        # 3. async VLA plan
        self._maybe_request_plan(obs)
        if self.plan is None:
            self.plan = self.vla.predict(obs)   # cold start only
            self.plan_idx = 0

        # 4. choose chunk
        H = self._choose_chunk(e, C, phi, c_e)
        a_ff = self.plan[self.plan_idx:self.plan_idx + H]
        if len(a_ff) < H:
            # 计划尾部不足一个块：先安全保持，再异步请求新计划；
            # 不把旧计划的下一个循环误当成当前块。
            self.plan_idx = 0
            self.plan = None
            a_ff = self._hold(obs, H)

        # 5. CHUNK-SERVO correction
        dx_s, c_s = self.servo.compute(obs, e, phi)
        x_eq = compose(a_ff, dx_s)

        # 6. virtual wrench + admittance
        w_hat, c_w = self.wrench.estimate(obs, x_eq, e)
        if c_w > self.c_min and c_e > self.theta_c:
            dx_a = self.admittance.step(w_hat, e.Z, dt=H / self.fc)
        else:
            dx_a = zeros_like(dx_s)
        x_cmd = compose(x_eq, dx_a)

        # 7. torque feasibility + action adapter
        x_cmd = self.torque_filter.project(x_cmd, obs, e.Z)
        self.plan_idx += H
        return self.adapter.to_api(x_cmd, obs, self.token)
```

### 7.2 相位相关 chunk

```python
def _choose_chunk(self, e, C, phi, c_e):
    if self.dynamic_chunk_supported:
        H = e.Z.H_c if c_e > self.theta_c else C.default_chunk(phi)
        return int(np.clip(H, 3, 8))
    return 5   # API 固定 chunk 时的安全回退
```

如果 API 不允许动态 chunk，则把 `H_c` 的影响转成**导纳带宽/增益调度**：接触段用更低的 `K_n` 和更短的导纳时间常数，自由段用更高的增益。

### 7.3 恢复宏执行

```python
def _recover(self, obs, e, failure_signature):
    for macro in self._rank_macros(e.R_e, failure_signature):
        if macro == "backoff":
            return self._backoff(obs, e, d=0.015)
        if macro == "rotate":
            return self._rotate(obs, e, alpha=0.08)
        if macro == "re-approach":
            return self._realign(obs, e)
        if macro == "re-grasp":
            return self._regrasp(obs, e)
        if macro == "re-plan":
            return self._request_replan(obs)
    return self._hold(obs, H=5)
```

恢复宏也走导纳/力矩过滤；不能直接下发大步长。

### 7.4 计划缓存与异步

- VLA 请求在后台线程/进程；`get_action` 不阻塞（除冷启动）。
- 计划过期（`plan_age > TTL`）时，用旧计划 + 伺服 + 导纳；不返回空。
- 计划索引按**时间**而不是固定索引推进：如果 evaluator 执行慢，旧计划的后半段可能过期；用时间戳裁剪。
- 每端口独立缓存；共享 VLA server 用 session ID 隔离。

### 7.5 回退阶梯的触发条件

| 条件 | 回退 |
|---|---|
| `c_C < 0.5` | 通用契约；不启用 engram 特定阻抗 |
| `c_e < θ_c` | 任务默认阻抗；仍可 CHUNK-SERVO |
| `c_w < c_min` | 关闭导纳；只做 CHUNK-SERVO |
| 导纳连续 3 块超限 | 关闭导纳；检查标定 |
| 视觉失效 | 用 `G_t` 最后可靠位姿；否则 VLA 开环 |
| 编辑检测 | 停止、重定位、恢复宏 |
| VLA 超时 | 旧计划 + 伺服；再超时 → hold |
| 力矩不可行 | 缩放轨迹；仍不可行 → 缩小 chunk/关闭导纳 |

- 总 <1 GB + 每端口 <200 MB。

### 8.5 多端口扩展

- engram 只读共享（mmap/COW），不随 N 线性增长；
- 每端口独立 `G_t`/导纳/相位；
- VLA server 批处理，session ID 隔离；
- CPU 伺服每端口独立线程/进程；N 增大时先加 CPU，再加 GPU。

## 9. 正确性论证

### 9.1 导纳稳定性

**命题 1**：一阶导纳

```math
D\Delta\dot x+K\Delta x=\hat w
```

在隐式离散

```math
\Delta x_{k+1}=(D+\Delta t K)^{-1}(D\Delta x_k+\Delta t\hat w_k)
```

下，对任意 `\Delta t>0`、`D,K\succ0` 是 Schur 稳定的；平衡点 `\Delta x^\star=K^{-1}\hat w` 全局渐近稳定（常值 `\hat w`），且对时变 `\hat w` 是输入-状态稳定（ISS）。

**证明**：令 `A=(D+\Delta t K)^{-1}D`。在 `D^{-1/2}KD^{-1/2}` 的公共特征基下，`A` 的特征值为

```math
\lambda_i=\frac{d_i}{d_i+\Delta t k_i}\in(0,1),
```

故 `\rho(A)<1`。取 Lyapunov 函数 `V_k=(\Delta x_k-\Delta x^\star)^\top K(\Delta x_k-\Delta x^\star)`，有

```math
V_{k+1}\le \rho_{\max}V_k+C\|\hat w_k-\hat w^\star\|^2,
```

其中 `\rho_{\max}=\max_i\lambda_i^2`。因此常值输入下 `\Delta x_k\to\Delta x^\star`；时变输入下 `\|\Delta x_k-\Delta x^\star\|` 有界。证毕。

**延迟**：若观测延迟 `d` 个块，闭环为 `\Delta x_{k+1}=A\Delta x_k+B\hat w_{k-d}`。由于 `A` 稳定，延迟只影响相位裕度；当 `d` 增大时，通过 `K_{\mathrm{eff}}=K_0/(1+\tau/\tau_0)` 降增益。严格稳定域需在仿真中扫参确定，不能只靠解析。

### 9.2 力矩可行性

**命题 2**：若过滤器返回 `\alpha` 使得

```math
\|\tau_{\mathrm{req}}(\alpha)\|_\infty\le\tau_{\max},
```

且底层位置控制器的力矩上限不低于 `\tau_{\max}`，则被执行的 5 步轨迹在 URDF 模型下不需要超过 `\tau_{\max}` 的关节力矩。

**证明**：逆动力学给出所需关节力矩；`\alpha` 缩放轨迹偏差后，重新计算得到 `\tau_{\mathrm{req}}(\alpha)`。由构造，`\|\tau_{\mathrm{req}}(\alpha)\|_\infty\le\tau_{\max}`。若底层控制器上限 `\ge\tau_{\max}`，则不会因该轨迹的逆动力学需求而饱和。证毕。

**边界**：这是模型层面的必要条件，不是真实接触力安全保证；摩擦、负载、模型误差、外部扰动都可能使真实力矩超过模型值。因此仍需限速、限幅、底层保护。

### 9.3 回退安全性

**命题 3**：ENGRAM 的动作空间包含 CHUNK-SERVO 的动作作为回退；当 `c_e<\theta_c` 或 `c_w<c_{\min}` 时，`\Delta x_a=0`，控制器退化为 CHUNK-SERVO。因此 ENGRAM 不会比 CHUNK-SERVO 更“不可用”（在回退逻辑正确的条件下）。

**证明**：由回退阶梯和 `get_action` 伪代码，低置信度分支直接令 `\Delta x_a=0`，`x_{\mathrm{cmd}}=x_{\mathrm{eq}}`，即 CHUNK-SERVO 的输出。动作适配器和安全过滤相同。证毕。

**注意**：这不保证成功率不下降；它只保证回退路径存在。

### 9.4 情节记忆一致性

**命题 4**：若目标静止、base 运动已知、观测噪声为零，则传播 `T_{r\leftarrow b}(t)=T_{b(t)\leftarrow b(t-1)}T_{r\leftarrow b}(t-1)` 精确。若噪声为高斯且模型线性，Kalman 融合是均方最优；归一化 innovation 平方（NIS）服从 `\chi^2` 分布。

**证明**：静止目标在 base 系中的位姿随 base 运动左乘；组合变换链式法则给出精确传播。高斯线性系统的 Kalman 最优性是标准结果；NIS 的 `\chi^2` 分布由新息归一化得到。证毕。

**边界**：人手编辑违反静止假设；NIS 检验只能以一定概率检测，不能保证零漏检。检测阈值需在仿真/真机上标定。

### 9.5 语言契约正确性

**命题 5**：若 32 条指令的契约经过人工核验，且运行时指令命中冻结表，则契约字段（verb/object/receptacle/phases/constraints）正确。未知指令回退 `C_\emptyset`，不保证语义正确。

**证明**：查表命中时返回人工核验过的冻结项，按构造成立。未知指令走兜底，无正确性声明。证毕。

### 9.6 有界偏差

**命题 6**：由于 `\|\Delta x\|\le\delta_p`、`\|\Delta\theta\|\le\delta_r`，ENGRAM 的笛卡尔命令与 CHUNK-SERVO 命令的偏差有界：

```math
\|x_{\mathrm{ENGRAM}}-x_{\mathrm{CHUNKSERVO}}\|\le\delta_p,
\qquad
\angle(R_{\mathrm{ENGRAM}},R_{\mathrm{CHUNKSERVO}})\le\delta_r.
```

**证明**：由 `x_cmd=x_eq\circ\exp(\Delta x_a)` 和 clip 直接得到。证毕。

**意义**：如果 CHUNK-SERVO 的命令在一个安全管形内，ENGRAM 的命令仍在同一管形的 `\delta_p/\delta_r` 邻域内；这给出行为变化的可审计上界，但不保证任务成功。

### 9.7 不能证明什么

- 不能证明 engram 阻抗在真机上提升成功率；
- 不能证明虚拟 wrench 与真实接触力线性相关；
- 不能证明跨机器人迁移；
- 不能证明语言契约覆盖未知指令；
- 不能证明 5 次 A/B 的统计显著性。

这些必须靠 G1–G9 的实验，而不是论文式推导。

## 11. 竞赛策略

### 11.1 任务组合

沿用第 12 轮的 A/B/C 分档，但把 ENGRAM 的边际收益纳入 `q_t`：

```math
priority_t = \frac{q_t \cdot \Delta_t}{cost_t},
```

- `q_t`：失败发生在最后 3 厘米/接触段的比例（先验 + 单任务通道更新）；
- `\Delta_t`：ENGRAM 条件增益（导纳 + 记忆 + 语言契约）；
- `cost_t`：engram/标定/调参成本。

### 11.2 ENGRAM 最可能帮助的任务

| 类型 | 任务 | 机制 |
|---|---|---|
| 插入/拔出 | PlugInEthernet、DisconnectEthernet、PlugCharger、ArrangeTestTubes | 轴向柔顺 + 横向对齐 + 接触检测 |
| 挂/叠/放 | HangCup、StackBowls、PaperCupStacking、StackCups | 重力方向柔顺 + 水平对中 + 慢释放 |
| 拉链/锁/拧 | ZipUp、Unlock、OpenPillBottle | 切向跟随 + 旋转柔顺 + 滞止检测 |
| 倾倒/转移 | PourOutMedicine、SyringeWaterTransfer | 瓶口对准 + 角速度限制 |
| 位置/人为干扰 | 5 类泛化轴 | 情节记忆 + 重定位 + 恢复宏 |

## 15. 一句话押注

**用自然语言把 33k 演示编译成语言索引的顺应性记忆，用虚拟 wrench 导纳在 5 步块内执行，用逆动力学力矩过滤守住可行性——在不新增学习模型、不假设力矩传感器的前提下，把 CHUNK-SERVO 的「看得更快」升级为「记得更久、接触更柔」。**

## 16. 本轮最大风险

**虚拟 wrench 观测器与真实接触力的相关性不足：一旦 G2 相关性 <0.3，导纳层就退化为“更慢的伺服”，ENGRAM 只剩记忆检索和相位 chunk 的收益。**
