# 第 44 轮（新循环第 4 轮） · Energy-Cert × MuJoCo：把「能耗」从软目标升格为可验证资源，用「可微提议—严格认证」闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈的最大风险是「共形条件覆盖被欺骗 + 多用户契约空集」，但它仍压着一个更基础、更少被言明的单点假设：**(H3) 能量只是目标函数里的软项，与安全证书互不约束**——安全证书默认「永远还有足够电去停、去绕、去重规划」，能量最优规划默认「安全边际可以用焦耳来换」。真实机器人上，能量是**单次任务内单调递减的不可再生资源**，其耗尽本身就是安全违例；而最省能的动作往往恰好贴着安全边界。本轮灵感词「MuJoCo」「能耗优化」精确命中 H3：MuJoCo 提供扭矩级、接触感知、可微（MJX）的**能量预言机**；能耗优化迫使我们把能量做成**一等证书维度**——它有自己的储备不变式、自己的仿真-现实误差预算，而且它对「证书栈本身」也收电费。核心口号：**安全此前默认「电无限」，本轮把「电」也证出来；可微物理只负责提议，严格证书只负责否决。**

## 0. 直觉与动机

**灵感 1（能耗优化 → 能量是资源，不是损失项）**：直觉上，「省电」不该只在代价函数里加一个权重，而应像安全一样成为**可行性问题**。机器人必须随时回答一个问题：「以当前剩余电量，我还能安全停下或回到充电位吗？」若答案是「不能」，则任何再优雅的能量最优轨迹都是不安全的。因此定义**能量储备证书**：E_rem(t) ≥ E_stop^robust(x_t) + E_err(t) + E_margin。它与几何/语义证书并列进入守卫。关键结构性好处：能量在无充电时**单调递减**，于是「能量可行内核」可沿能量轴做单向后扫，而不是在 (x, E) 联合空间里暴力枚举——这把一个高维资源约束降成一族状态约束。

**灵感 2（MuJoCo → 可微物理负责「提议」，严格证书负责「否决」）**：MuJoCo 的独特性在于同时提供三样东西：(a) `mj_rne` 级别的逆动力学扭矩，使功率可由 τᵀq̇、铜损 τ²R/k_t² 精确记账；(b) 接触求解器给出碰撞/摩擦耗散，这是纯运动学能耗模型最容易漏掉的部分；(c) MJX 的批量化与可微性，使「一条能量最优轨迹」可以用梯度廉价地**提议**出来。但接触是非光滑的，梯度在最优点附近不可靠，绝不能让可微性冒充可靠性。于是采用**提议—否决（propose–dispose）**：MJX 并行生成 b 条候选，MuJoCo 在参数/扰动集合 Ξ 上做鲁棒 rollout，只有同时通过安全证书与能量证书的候选才进入选择集。可微性只影响「能省多少」，不影响「是否 sound」。

**灵感 3（耦合 → 证书自己也要耗电，且安全边际有「焦耳价格」）**：两个耦合是最有意思的新问题。其一，**认证栈本身耗能**：VLM、几何证书、INT8 监控、b 路并行投机都要电，因此「更勤地刷新证书换取更新鲜的边际」不是免费的；能量预算必须在「想」和「动」之间分配。其二，**保守性有能量价格**：证书阈值 θ 越高，可行动作集 A_cert(θ) 越小，其最小能耗 E_min(θ) 单调不降。定义**每焦耳安全价格 PoS-J(θ)=E_min(θ)−E_min(0)**，把「安全 vs 续航」从口头权衡变成一个可测量、可优化的帕累托前沿。注意 θ 不能为省电而降到 soundness 地板以下——省电只能在地板之上做。

**耦合升级**：EVC（能量证书引擎）把剩余电量编译为储备守卫与能量可行内核；MPD（MuJoCo 提议-否决优化器）在「可微提议 + 鲁棒认证」下做轨迹级省能；EMCL（能量模型校准环）用时间一致共形把仿真功率模型与现实电池/电机/热模型之间的偏差做成**只会收紧、不会放宽**的误差预算。三者与既有 PCE/CCR/ICV 正交叠加，形成 v9 的「安全-人格-并发-能量」四资源闭环。

## 1. 形式化定义（增量：定义 44–50）

**定义 44（能量证书与能量可行内核）**：能量状态 s_e=(x, E_rem, T_m, T_b)，功率上界 P⁺(x,u) 覆盖机械功率、铜损、电子静态功耗与回馈效率。鲁棒停机能量 E_stop^robust(x)=max_{ξ∈Ξ} E_ξ(x→G_stop)，其中 G_stop 为安全停靠/充电集。**能量证书** ℓ_E=(E_rem, R(x,t), valid)，储备 R(x,t)=E_stop^robust(x)+E_err(t)+E_margin(θ)。**能量可行内核** K_E 为满足下式的最大的集合：从任意 (x,E)∈K_E 出发，存在策略 π 使轨迹始终留在 safe∩K_E，且能量在耗尽前到达 G_stop。**单调性命题**：单次任务无充电时 E_rem 单调不增，故 K_E 对 E_rem **上封闭**——(x,E)∈K_E 且 E′≥E ⇒ (x,E′)∈K_E。**定理（储备守卫充分性）**：若守卫强制 E_rem≥R 且控制器保持 K_E，则电池不会在 G_stop 之外耗尽。

**定义 45（MuJoCo 能量模型与时间一致误差预算）**：用 `mj_rne` 得 τ，则单步仿真能耗
E_sim = Σ_t [ τᵀq̇⁺/η − γ·τᵀq̇⁻·η_r + Σ_j (τ_j/k_{t,j})² R_j + P₀ ] Δt，
其中 η 为传动效率、γ 为回馈开关、P₀ 为电子静态功耗。记现实能耗 E_real，残差 r_t=E_real(t)−E_sim(t)。**时间一致上界**：用 e-process/测试鞅给出 q_t，使 P(∀t: E_real(t) ≤ E_sim(t)+q_t) ≥ 1−δ。**累计预算** E_err(t)=q_t。**命题（累计而非线性）**：朴素逐步界给出 E_err=H·ε（随视界线性膨胀，过于保守）；时间一致共形在可交换性下给出 O(√t) 的量级，显著降低 PoS-J。校准按步态/地形/负载做 Mondrian 分层。

**定义 46（可微提议—严格否决的能量优化）**：MJX 并行生成候选
ξ_j = argmin_u E_sim(ξ;u) + λ·J_risk(ξ;u)（梯度下降，仅作提议）。
认证阶段：∀ξ∈Ξ 做 MuJoCo 鲁棒 rollout，要求安全证书与能量证书同时成立；记认证候选集 C={j : cert_safe(ξ_j) ∧ cert_E(ξ_j)}，选择 ξ*=argmin_{j∈C} E⁺(ξ_j)；C=∅ 则返回保守停靠/回充，而非静默放行。**定理（提议质量不影响可靠性）**：只要每个入选候选在 Ξ 上通过认证，则输出 sound；可微性、批大小 b、迭代次数只改变最优性与时延，不破坏可靠性。

**定义 47（安全-能量的帕累托与每焦耳安全价格）**：设 A_cert(θ) 为阈值 θ 下的可行动作集。因 θ 增大只会收缩 A_cert，故 **E_min(θ)=min_{a∈A_cert(θ)} E(a) 单调不降**。定义 **PoS-J(θ)=E_min(θ)−E_min(0)**，安全水平 s(θ)=P(违例)。在硬性地板 θ≥θ_sound 上，选择帕累托前沿上满足续航约束的点。**推论**：降低安全阈值来省电只在 θ<θ_sound 时有收益，而那已越出 sound 域——因此 PoS-J 必须在地板之上用「更好的证书/更好的模型」压缩，而不是用「更松的证书」压缩。

**定义 48（计算-运动联合能耗与能量感知的证据级）**：E_total=E_act+E_comp，E_comp=Σ 证据级成本。证据级 ℓ∈{L0,L1,L2} 有成本 c_ℓ 与可证边际 m_ℓ（c_{L0}<c_{L1}<c_{L2}，m_{L0}≤m_{L1}≤m_{L2}）。**能量感知证据调度**：在 E_rem−E_plan−c_ℓ ≥ R 且 m_ℓ≥θ 的前提下取边际增益/焦耳最大的 ℓ；若任何 ℓ 都不满足，则单调降速/缩短任务，或返回 G_stop，**绝不**用低证据级去换取一个未认证的动作。**soundness 引理**：证据级只影响边际的获取速率；放弃精化只会让可用集更小，不会让守卫接受一个未达 θ 的动作。

**定义 49（热-电耦合资源与联合可行域）**：电机/电池温度满足集总热模型 C_th Ṫ = P_loss − k(T−T_amb)，温度单调累积。热证书要求 T≤T_max 且电池 C-rate≤C_max。**命题（热-电不同步）**：存在轨迹使能量预算充足却因持续高扭矩导致热违例（省能≠不发热，峰值功率与累计能量是不同资源）。故可行域取 K_E ∩ K_T（能量-热联合内核），两者都用上封闭的「资源≥阈值」形式。

**定义 50（能量模型的非平稳与单调再校准）**：电池老化、温度、地面摩擦使 P_sim 漂移，可交换性被破坏。用 ACI/e-process 在线监测；**单调再校准原则**：在线只允许**收紧** E_err 或收缩 K_E；任何放宽必须用新的、可交换的离线标定集 + 影子证书零违例 + A/B 无回归三重闸门（复用 v20 的认证扩张闸门）。**命题（单调性保 sound）**：若在线更新只会增大 E_err，则任何此前 sound 的储备判据在更新后仍 sound；放宽只能走离线通道，故漂移不会静默制造不 sound。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 ENERGY-VIABILITY-CERTIFICATE（能量可行性证书引擎 EVC）
1. **能量记账与储备守卫**：从 `mj_rne` 扭矩、关节速度、电池模型计算 P⁺；维护 E_rem 与鲁棒 E_stop；守卫 m_E←E_rem−R，与几何/语义守卫取 min。
2. **能量可行内核**：按能量轴单向后扫计算 K_E（利用上封闭单调性）；输出「当前状态到最近 G_stop 的最大允许动作集」。
3. **热-电联合约束**：并联 K_T；高扭矩动作先过热约束再入规划。
4. **能量感知证据调度**：在 E_act+E_comp+R≤E_rem 下选证据级；预算不足走单调降速/回充，不用低证据换未认证动作。

### 2.2 IP-61 MUJOCO-PROPOSE-DISPOSE（提议-否决能量优化器 MPD）
1. **MJX 可微提议**：批量化生成 b 条能量最优候选，支持接触/摩擦模型参数化。
2. **鲁棒认证**：在 Ξ（质量、摩擦、执行器增益、电池内阻）上并行 rollout，检查安全证书 + 能量证书；接触非光滑只影响提议。
3. **证书一致选择**：只在认证集内取 E⁺ 最小者；空集返回保守停靠/回充。
4. **PoS-J 前沿导出**：对 θ 扫描给出能量-安全帕累托曲线，供系统级选型。

### 2.3 IP-62 ENERGY-MODEL-CALIBRATION-LOOP（能量模型校准环 EMCL）
1. **分层时间一致共形**：按步态/地形/负载维护残差分布，e-process 给出任意时刻有效上界 q_t。
2. **系统辨识回灌**：把现实残差反演为 MuJoCo 摩擦/阻尼/执行器参数的后验，喂回 MPD。
3. **漂移检测与单调再校准**：老化/温漂触发 E_err 收紧；放宽只走离线三重闸门。
4. **热-电模型校准**：独立共形通道校准 C_th、k、R_int，避免能量正确但热错误。

## 5. 本轮最大风险

**一句话**：电池老化、温漂与接触摩擦使 MuJoCo 能量模型非平稳，而能量误差会沿视界**累积**——一旦时间一致共形上界在漂移下失效，储备守卫会把「电不够」误判为「电够」，这是比单步安全边际更隐蔽、更致命的静默不 sound；因此 E96（时间一致覆盖）与 E102（老化下零松弛）必须设为红线，并保留「物理硬性储备地板 + 回充兜底」这条不依赖任何模型的最后防线。

# 第 44 轮产物 · 创新点清单 v21：Energy-Cert × MuJoCo（EVC × MPD × EMCL）× 安全-能量可验证闭环（四层架构 v9）

## 2. 关键算法（伪代码）

### IP-60 EVC：能量记账、储备守卫与能量可行内核
```
def power_upper(mj_model, mj_data, q, qd, tau, kt, R_arm, eta, gamma, P0):
    mech = dot(tau, qd)
    mech_eff = (mech/eta if mech >= 0 else gamma*mech*eta)  # 回馈按效率打折
    copper = sum((tau[j]/kt[j])**2 * R_arm[j] for j in actuators)
    return mech_eff + copper + P0

def energy_viability_kernel(X, E_grid, P_upper, G_stop, dt, Xi):
    # 无充电时 E 单调不增 => K_E 对 E 上封闭，可从高能到低能单向后扫
    K = {(x,E) for x in G_stop for E in E_grid}
    for E in reversed(E_grid):                 # O(|X||E|)
        for x in X:
            for u in U(x):
                x2 = robust_step(x, u, Xi)
                E2 = E - P_upper(x,u)*dt
                if E2 >= 0 and (x2, E2) in K:
                    K.add((x, E)); break
    return K

def reserve_guard(x, E_rem, E_err, theta, E_margin):
    R = E_stop_robust(x) + E_err + E_margin(theta)
    return E_rem - R, R          # 守卫要求 E_rem >= R

def energy_aware_evidence_level(E_rem, E_plan, R, theta, levels):
    # levels: {L0:(cost,margin), L1:..., L2:...}
    best = None
    for l,(c,m) in levels.items():
        if E_rem - E_plan - c >= R and m >= theta:
            gain_per_joule = (m - theta) / max(c, eps)
            if best is None or gain_per_joule > best[0]:
                best = (gain_per_joule, l)
    return best[1] if best else "RETURN_TO_DOCK"   # 绝不用低证据换未认证动作
```

### IP-61 MPD：MJX 可微提议 + MuJoCo 鲁棒否决
```
def mujoco_propose(goal, x0, mjx_model, K, iters, lam):
    # 仅提议：接触非光滑，梯度不作可靠性依据
    best = mjx_batch_minimize(
        cost=lambda xi: energy_sim(mjx_model, xi) + lam*risk(xi),
        x0=x0, goal=goal, num_candidates=K, iters=iters)
    return best                         # [xi_1..xi_K]

def robust_certify(xi, mj_model, Xi, delta, theta):
    # 在参数/扰动集 Xi 上做最坏 rollout
    E_up = 0.0
    for p in Xi:
        roll = rollout(mj_model, xi, params=p)
        E_up = max(E_up, energy_real_upper(roll))      # mj_rne + 功率模型
        if not safety_cert(roll): return None
    q_t = time_uniform_bound(delta, t=len(xi))          # e-process
    if roll.E_rem < E_stop_robust(roll.end) + q_t + E_margin(theta):
        return None
    if roll.T_max_exceeded(): return None
    return EnergyCert(E_up=E_up+q_t, reserve=..., valid=True)

def propose_dispose(goal, x0, K, iters, Xi, delta, theta):
    cands = mujoco_propose(goal, x0, mjx_model, K, iters, lam)
    certified = [(c, robust_certify(c, mj_model, Xi, delta, theta)) for c in cands]
    certified = [(c,e) for c,e in certified if e is not None]
    if not certified:
        return conservative_return_or_dock(x0)          # 空集绝不静默放行
    return min(certified, key=lambda ce: ce[1].E_up)     # 认证集内最省能
```

### IP-62 EMCL：时间一致共形、漂移与单调再校准
```
def update_energy_bound(residual_stream, delta):
    # e-process / 测试鞅：任意时刻 P(E_real <= E_sim + q_t) >= 1-delta
    q_t = evalue_upper_quantile(residual_stream, delta)
    return max(previous_q, q_t)       # 在线只允许收紧(增大上界)

def monotone_recalibrate(new_residual, drift_score, offline_cert):
    if drift_score < drift_threshold:
        return inflate_E_err(new_residual)          # 收紧
    # 放宽必须离线、可交换、影子证书零违例、A/B 无回归
    if offline_cert.exchangeable() and offline_cert.zero_violation() and offline_cert.no_regression():
        return relax_E_err(new_residual)
    return inflate_E_err(new_residual)              # 未过闸门 -> 继续收紧

def thermal_channel(T_meas, P_loss, dt, Cth, k, Tamb):
    T_pred = T_meas + (P_loss - k*(T_meas-Tamb))*dt/Cth
    return conformal_upper(T_pred)                   # 热通道独立校准
```

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 能量模型非平稳（老化/温漂/摩擦），时间一致上界失效，储备守卫静默不 sound | 高 | E96/E102 红线；e-process + 单调再校准（在线只收紧）；物理储备地板 + 回充兜底 |
| 能量误差沿视界累积（O(t) 最坏），导致 PoS-J 过大、续航过度保守 | 高 | 时间一致共形把界压到 O(√t)；分步态/地形 Mondrian；必要时缩短任务视界 |

| 热-电不同步：省能轨迹持续高扭矩导致热违例 | 中 | K_E∩K_T 联合内核；热通道独立共形；高扭矩区间硬约束 |

## 6. 本轮最大风险

**一句话**：电池老化、温漂与接触摩擦使 MuJoCo 能量模型非平稳，而能量误差会沿视界**累积**——一旦时间一致共形上界在漂移下失效，储备守卫会把「电不够」误判为「电够」，这是比单步安全边际更隐蔽、更致命的静默不 sound；因此 E96（时间一致覆盖）与 E102（老化下零松弛）必须设为红线，并保留「物理硬性储备地板 + 回充兜底」这条不依赖任何模型的最后防线。
