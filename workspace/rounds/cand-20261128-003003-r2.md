## 1. 直觉与动机

### 1.1 单模型多任务：瓶颈不是「装不下」，而是「互相拆台」

直觉：第 2 轮把 110 语料当"更多燃料"；但 32 个任务挤进一个 checkpoint 时，最大的敌人不是容量，而是**梯度冲突**。ZipUp 要把拉链往上拉，Unzip 要往下拉；PlugInEthernet 是插入，DisconnectEthernet 是拔出。第 2 轮把 Unzip 当作 ZipUp 的正孪生（相似度 .9）送进共训，恰恰是**语义相似掩盖了动作极性相反**：最危险的任务不是远任务，而是"看起来很像、动起来相反"的近任务。于是单模型多任务的第一性问题改写为：**在一个共享动作头上，如何预先判断哪对任务会正迁移、哪对会互相抵消，并只在应该共享的地方共享？**

严谨定义：对任务 i,j，令 g_i,g_j 为共享参数上的期望梯度，一阶干扰 I(i,j)=cos(g_i,g_j)；二阶干扰 Δ_i|j = L_i(θ_after j) − L_i(θ_before j)。单模型多任务不是最小化 Σ_t L_t，而是在容量 C 与单步延迟预算 B 下最大化短板：

```
max_θ  min_t S_t(θ)     s.t.  cost(θ) ≤ C,  p99_latency(θ) ≤ B
```

这把优化目标从"平均分"改成"最弱任务分"，与 P1 对齐；也解释了为什么"再堆数据"可能不涨分——负干扰会把新增容量抵消掉。

### 1.2 知识图谱：不是外挂一张图，而是把「任务关系」变成可证伪的先验

直觉：VLA 里 KG 最常见的失败是"图很漂亮，但不改变任何动作"。本轮只保留能改变**训练信号**或**推理条件**的图，且只回答三个问题：(a) 两个任务该不该共享动作参数（由动词关系定符号/极性）；(b) 当前指令在图上对应哪条「技能-物体-可供性」路径，使未见物体能退回"可供性"而不是退回随机；(c) 官方得分点构成什么里程碑 DAG，给进度头与 chunk 目标。**KG 的价值不在节点多，而在每条边都能被一次 L0 消融证伪。**

严谨定义（技能-可供性图 SAG）：G=(V,E,τ,σ,w)。

- V = V_T ∪ V_S ∪ V_O ∪ V_A ∪ V_M：任务、技能（动词）、物体、可供性（grasp/insert/pour/fold/stack/wipe/unlock…）、里程碑。
- τ ∈ {has_skill, acts_on, affords, has_milestone, precedes, transfers_to}；transfer 边带极性 σ∈{+1,−1,0} 与强度 w∈[0,1]。
- 极性规则：同向同技能（StoreCups↔Cup_Storage）σ=+1；逆动词（ZipUp↔Unzip、Plug↔Unplug、Open↔Close、Insert↔Remove）σ=−1；仅共享物体外观而动作无关 σ=0（只共享视觉编码，不共享动作头）。
- 任务签名 s(t) = 从 t 出发的 (skill, object, affordance) 路径多重集；任务相似度只用签名，**不使用任务名/任务 ID**（F22 只给语言，不给 ID）。
- 迁移风险 r(i,j)=σ_ij·w_ij·(1−c_ij)，c_ij 为可供性冲突（同物体、不同接触方式）。σ=−1 的对只允许共享视觉编码 + 动作潜空间对比分离，禁止共享动作头权重。

### 1.3 碰撞：图给单模型多任务提供「该在哪共享」的坐标

三者统一：单模型多任务给出约束（一个 checkpoint、稳定时延、最弱任务优先），知识图谱给出结构（带极性的任务关系 + 可供性退路 + 里程碑 DAG），第 2 轮的数据引擎给出燃料（110 语料 + 合成示教 + 检索）。核心反直觉点：**KG 在这场里不是用来"规划"的，而是用来"决定哪两条示教可以放进同一个梯度"的；单模型多任务的关键不是更大的模型，而是更少的负干扰。**

## 1. 核心形式化

### 1.1 SAG 本体与极性（I10）

**节点**：任务 `T`（32 考题 + 110 共训）、技能 `S`（动词：grasp/place/insert/remove/pour/fold/unfold/zip/unzip/stack/wipe/unlock…）、物体 `O`（cup/zipper/phone/ethernet_port…）、可供性 `A`（grasp/pull_tab/insert/pour/fold/stack…）、里程碑 `M`（官方得分点或模板步骤）。

**边**：

| 类型 τ | 方向 | 含义 |
|---|---|---|
| `has_skill` | T→S | 任务的主技能（可多技能 = 多边） |
| `acts_on` | S→O | 技能作用的物体 |
| `affords` | O→A | 物体允许的接触方式 |
| `has_milestone` | T→M | 任务的得分点 |
| `precedes` | M→M | 得分点 DAG 的先后约束 |
| `transfers_to` | T→T | 带极性 σ、强度 w 的迁移边 |

**极性规则（可闭世界核对）**：

| 情形 | σ | 共享范围 |
|---|---|---|
| 同动词 + 同可供性 + 不同物体（StoreCups↔Cup_Storage） | +1 | 视觉编码 + 动作头 |
| 逆动词 + 同物体（ZipUp↔Unzip、Plug↔Unplug、Insert↔Remove） | −1 | 只共享视觉编码；动作头对比分离/梯度投影 |
| 同物体 + 不同可供性（抓 vs 推） | 0 | 只共享视觉编码，且 c 高 |
| 无共享签名 | 无边 | 不共训（仅防遗忘低权重） |

真实任务名上的边例（名称来自 F23，边为本轮构建）：

```

Unzip     --has_skill--> unzip  --acts_on--> zipper --affords--> pull_tab
```

**构建管线（规则优先，LLM 只提议）**：

```python
def build_sag(tasks_110, tasks_32, wiki_steps):
    V = add_task_nodes(tasks_110 | tasks_32)
    V |= add_lexicon(VERBS) | add_lexicon(OBJECTS) | add_lexicon(AFFORDANCES)
    E = []
    for t in tasks_110 | tasks_32:
        verb, obj = parse_task_name(t)                  # 规则优先
        E += [has_skill(t, verb), acts_on(verb, obj),
              affords(obj, affordance(obj, verb))]
        E += has_milestone_edges(t, wiki_steps.get(t) or TEMPLATE_DAG(t))
    for a, b in candidate_pairs(V_T, bucket_by=("skill", "object")):
        rel   = verb_relation(verb(a), verb(b))         # SAME / INVERSE / OTHER
        sigma = +1 if rel == SAME else -1 if rel == INVERSE else 0
        w     = signature_jaccard(a, b)
        if w >= W_MIN:
            E.append(transfers_to(a, b, sigma, w))
    return audit_closed_world(G=(V, E))                 # 只留能引用证据的边
```

- **候选对**按 skill/object 分桶，避免 32² 全量 LLM 调用。
- **闭世界核对**：每条边至少能由任务名、110 名称或 wiki 文本之一支持；LLM 只做"提议 + 关系分类"，人工抽检 10%。
- **逆动词表**人工维护（zip/unzip、plug/unplug、insert/remove、open/close、stack/unstack、fold/unfold；pick/place 仅在共享物体时视为弱逆）。

### 1.2 干扰预测假设与测量（Q9）

- **H1（符号）**：σ=+1 的边，实测 I(i,j)>0 的概率显著高于 σ=−1 的边。
- **H2（幅度）**：在 σ=+1 内，w 越大 |I(i,j)| 越大。
- **H3（可分离）**：σ=−1 时，共享视觉编码仍有益（Δprog_vision>0），但共享动作头有害（Δprog_action<0）。
- **证伪**：若留出边上的符号准确率 <0.7，SAG 的 transfer 边降级为"仅供参考"，I2 v3 回退到 v1.1 的无符号采样。

```python
def interference_matrix(policy, tasks, probe_batches, params="action_head"):
    G = {t: grad_of_loss(policy, probe_batches[t], params) for t in tasks}
    return {(i, j): cosine(G[i], G[j])
            for i, j in combinations(tasks, 2)}

sign_acc = mean(sign(M[i, j]) == SAG.edge(i, j).sigma
                for (i, j) in heldout_edges if abs(M[i, j]) > NOISE_FLOOR)
```

同时报告 Spearman(|M|, w)，验证 H2；并在共享视觉编码 vs 共享动作头两种参数集上分别计算 M，验证 H3。

### 1.3 单检查点多任务目标（I11）

- 每任务流匹配损失 L_t；用留出 probe 的成功率/进度得 s_t。
- **最弱任务优先**：λ_t = softmax(−s_t/τ)，或对最差 20% 任务做 CVaR 加权。
- 总损失：`L = Σ_t λ_t L_t + β L_graph + γ L_milestone`。
- **L_graph（只作用于动作潜变量 h）**：σ=+1 的对拉近 `||h_i−h_j||²`；σ=−1 的对用 hinge `max(0, m−||h_i−h_j||)²` 推开；σ=0 不加动作项。只在 batch 级计算，成本可忽略。
- **条件化**：不使用任务 ID。`z_t = SAG.encode_path(link(instruction, first_obs))`，用 FiLM 调制共享动作头；FiLM 是 O(d) 确定性运算，无路由抖动，符合 F21/F22。

```python
class SAGConditionedPolicy:
    def __init__(self, sag, shared_head, film):
        self.sag, self.head, self.film = sag, shared_head, film
        self._z = None
    def get_action(self, obs):
        if self._z is None:                                  # reset 后首帧做一次
            path = self.sag.link(obs["observation.language"], obs)
            self._z = self.sag.encode_path(path)             # 确定性
        h = self.film(self.head.encode(obs), self._z)
        return self.head.decode(h)                           # chunk
```

**图感知梯度手术**（替代粗暴的"负边不同 batch"）：

```python
def graph_aware_step(losses, sag):
    g = {t: grad(losses[t], ACTION_PARAMS) for t in losses}
    for (i, j) in sag.negative_edges_present_in(losses):
        if dot(g[i], g[j]) < 0:
            g[i], g[j] = pcgrad_project(g[i], g[j])
    apply(sum(g.values()))
```

### 1.5 I5 v3：里程碑 DAG

- `M_t = {m1…mk}` 来自 wiki 得分点；无 wiki 时用模板 DAG：approach→grasp→transport→place→release→verify。
- 进度头输出 `p(m_k | obs)`；chunk 目标 = 下一个未达成里程碑。
- 接触类里程碑用短 chunk，运输类用长 chunk；合成恢复段只有"推进 DAG"才保留。

```python
def milestone_chunk(policy, obs, dag):
    done   = [m for m in dag if detector(m, obs)]
    target = dag.next(done)
    return policy.propose_chunk(obs, target=target,
                                horizon=SHORT if target.is_contact else LONG)
```
