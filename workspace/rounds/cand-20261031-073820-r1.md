# 第 13 轮（新循环第 1 轮）· MOSAIC：把语义地图做成 VLA 与伺服之间的可查询工作记忆

> 检索/复核日期：**2026-10-31（UTC）**。赛事身份不变：宇树 **UniBot 世界挑战赛**（unibot.unitree.com），G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API。本轮是新灵感循环第 1 轮，技术基线承接第 10 轮 FACT-VLA、第 11 轮 GEO-RESIDUAL、第 12 轮 CHUNK-SERVO。三个灵感词是「多模态交互」「仿真到现实迁移」「语义地图」。本轮不推倒 CHUNK-SERVO 的“30 步规划 + 5 步伺服”，而是补它默认掉的一层：**CHUNK-SERVO 假设“目标已知、场景未变、上一子目标已完成”；MOSAIC 专门回答“目标是谁、在哪、有没有变、这个子目标真的完成了吗”。**

## 0. 先给结论：最后 3 厘米之前，还有“最后 3 个问题”

CHUNK-SERVO 把反馈周期从 1 s 压到 167 ms，解决了“手抖/偏 2 mm”的问题。但 32 个任务里有大量失败不是手抖，而是：

1. **目标身份错**：要挂的是左边杯子还是右边杯子？要插的是网口 3 还是网口 5？VLA 当前帧可能被遮挡、反光、夹爪挡住；检索到的“目标-夹爪相对位姿”如果对错物体，伺服越准越糟。
2. **场景状态错**：人把已经叠好的碗拿走、把拉链拉开、把插头拔掉；机器人还在按原计划做下一步。CHUNK-SERVO 只在最后 3 厘米看新图，看不到“三分钟前完成的子目标已经被撤销”。
3. **任务状态错**：杯子其实没挂上、网线只顶在端口外面、盖子没拧紧。VLA 没有跨 chunk 的持久状态，它不知道“现在到底完成了哪个子目标”，只能继续生成下一段动作。

所以本轮押注 **MOSAIC**：

> **用对象中心语义地图做跨 chunk 的工作记忆；用语言、视觉、本体感觉三路证据维护“哪些谓词为真”；当地图不确定或证据冲突时，花一次有预算的主动观测（移动空闲臂/腕部/躯干，必要时轻探）去查账；用 33k 成功演示检索“子目标地图”，把当前地图对齐到演示子图并给出相对目标；用数字孪生只标定地图的噪声模型、关联门限和主动观测阈值，不训练第二个策略。**

一句话：**CHUNK-SERVO 负责“这 3 厘米怎么走准”；MOSAIC 负责“这 3 厘米该不该走、目标是不是它、走完算不算完成”。**

MOSAIC = **M**ultimodal **O**bject-centric **S**emantic map with **A**ctive **I**nteraction and **C**alibration。

三个可验证创新点：

1. **OSM-WM（Object-centric Semantic Map as Working Memory）**：对象节点 + 关系边 + 谓词信念持久化；跨 chunk 记住“哪些物体被移动、哪些槽位已占用、哪些子目标已完成”，专打 20–38 s 的长程多物体任务。
2. **MAIN（Multimodal Active Interaction）**：语言给谓词先验、视觉给状态、本体给抓持/接触证据；三路 log-odds 冲突或地图熵高时，用确定性 VOI 在有限动作集里选一次主动观测；无学习权重，不违反单模型。
3. **TCM（Twin-Calibrated Map）**：数字孪生只标定“地图观测模型”的深度噪声、遮挡率、关联错误率和人编辑分布，并做分布鲁棒的门限优化；不把仿真成功率当真机预测。

三个灵感词怎么落到方案里：

| 灵感词 | 落到哪里 | 不做什么 |
|---|---|---|
| **语义地图** | 对象节点（位姿/协方差/描述子/角色/状态/置信度）+ 关系边（on/in/near/left-of/support/contain）+ 谓词信念；跨 chunk 持久化；用于目标检索、子目标对齐、编辑检测、长程记忆 | 不做 3D 语义大模型；不在线跑 3DGS/NeRF；不做纯可视化场景图 |
| **多模态交互** | 语言→谓词模板/角色；视觉→对象位姿/关系；本体→抓持/滑移/接触；冲突→主动观测；空闲臂→第二视角；轻探→接触谓词 | 不做对话/LLM planner；不加力/触觉；不把人类当对话者；不训多模态融合网络 |
| **仿真到现实迁移** | G1 URDF + 官方 IsaacLab/MuJoCo 轻量孪生；标定双目深度偏置/方差、遮挡率、关联错误率、人编辑分布；鲁棒门限优化 | 不在仿真里训 6B 策略；不假设 sim 成功率能预测真机；不把孪生当第二个模型 |

## 1. 为什么是这三个词：一条闭环，而不是三顶帽子

### 1.1 语义地图：把“当前帧”变成“可查询的任务状态”

VLA 的输入是当前几帧图像 + 语言；它没有显式的“世界状态”。在 6–38 s 的桌面任务里，这会造成三类错误：

- **遮挡遗忘**：物体被放进盒子/袋子/书架后，当前帧看不见，但任务还没结束；VLA 不知道它已经放过了。
- **槽位遗忘**：工具箱、试管架、笔袋、杯架有多个槽位；当前帧只能看到部分槽位，VLA 可能重复占用同一个槽。
- **人编辑遗忘**：人把已完成的结构破坏后，当前帧可能只显示局部；VLA 仍按原计划继续。

对象中心语义地图正好承载这些状态：

```text
节点 o_i = (id, T_i, Σ_i, f_i, role_i, state_i, conf_i, last_seen_i)
   role  ∈ {target, container, support, slot, distractor, unknown}
   state ∈ {free, grasped, placed, occluded, missing, moved}
边   r_ij ∈ {on, in, near, left_of, right_of, front_of, support, contain}
谓词 φ_j：grasped(o,g), in(o,c), on(o,s), plugged(o,p), zipped(z), stacked(o1,o2), ...
```

地图不是“场景图可视化”，而是 **VLA、检索、伺服、验证四者共享的索引**：

- VLA 通过地图摘要知道“现在有哪些物体、哪些槽位已占用、上一个子目标是什么”；
- 检索通过地图找“当前场景最像哪条演示的哪个子目标”；
- 伺服通过地图拿“目标物/受器的相对位姿”；
- 验证通过地图谓词判断“这个子目标是否真的完成”。

### 1.2 多模态交互：不是“再加一个模态”，而是“让模态互相查账”

在 UniBot 里，模态的角色非常不对称：

- **语言**：32 个任务名 + 少量复述，是封闭集；它最适合提供“这一步应该建立什么谓词/角色”，不适合提供毫米级位姿。
- **视觉**：四路 RGB 能提供对象、关系、遮挡、接触外观；但透明/反光/被夹爪挡住时会说谎；头双目在 0.5 m 处每像素约 15 mm 深度误差，只够“厘米级地图”，不够“毫米级插入”。
- **本体感觉**：EE 位姿、夹爪开度、关节跟踪误差；没有力/触觉，但能提供“抓到/抓空/滑移/顶住”的弱证据。
- **人类**：不是对话伙伴，而是外部状态编辑器；human 轴会撤销已完成子目标。

所以“多模态交互”在本轮不是再接一个 VLM，而是：

```text
语言先验 ─┐
视觉证据 ─┼─► 谓词信念 b_j ─► 冲突分数 κ_j ─► 主动观测 / 降权 / 修复
本体证据 ─┤
人编辑   ─┘
```

每个谓词维护 log-odds；三路证据各自给 log-likelihood ratio；当视觉说“插入了”而本体说“还在自由空间、没有顶住”时，不硬信任何一方，而是把该谓词标成 uncertain，触发一次**主动观测**：移动空闲臂到能看见接触点的位置、转腕、或轻探一下看关节跟踪误差。这比再训一个多模态融合网络便宜、可解释，也不违反单模型。

### 1.3 仿真到现实迁移：只校准地图的观测模型，不训练策略

CHUNK-SERVO 已经用孪生标定相机外参、伺服增益、RTT。MOSAIC 把标定对象往前推一层：**地图的观测模型**。

需要标定的不是“策略在仿真里成功率多少”，而是：

- 双目深度偏置/方差随距离的变化；
- 对象检测/关联在遮挡、 clutter、相似物体下的错误率；
- 透明/反光/变形物体的失败率（用于决定地图是否启用）；
- 人编辑的幅度/频率/延迟分布；
- 主动观测的视角收益（头双目 vs 腕部 vs 空闲臂）。

标定完这些，才能在真机上设置关联门限、冲突阈值、主动观测阈值、地图修正权重。数字孪生是**地图观测模型的风洞**，不是策略训练场。这样 sim-to-real gap 只影响“门限是否保守”，不影响“策略分布”。

## 2. 本轮新核实/修正的事实（只列会改变方案的）

### 2.1 腕部相机：有内参，缺手眼外参

第 12 轮写“腕部没有内参”不准确。本轮 2026-10-31 重新读取 HangCup 的 `meta/info.json`：

```text
wrist_left.color.camera_matrix  = [436.4058, 0, 323.9217; 0, 435.9215, 242.9332; 0, 0, 1]
wrist_right.color.camera_matrix = [435.1151, 0, 319.0249; 0, 434.4995, 240.9933; 0, 0, 1]
wrist_left/right.color.dist_coeffs = inverse_brown_conrady
head_stereo.T = [-58.2526, -0.1675, 0.5786] mm, fx≈282.37/281.87, rectified=true
```

正确结论是：**腕部 color 有完整内参和畸变模型；缺的是腕部到 EE 的手眼外参**。因此：

- 腕部可以做 2D 特征对齐/近距校验，不需要先猜内参；
- 手眼外参仍需一次性标定（棋盘格/已知 EE 运动），重投影 ≤5 px；
- 头双目仍然是地图的主几何；腕部只做局部特写和接触段伺服。

### 2.2 头双目的深度精度只够“任务级地图”

基线 58.2526 mm、`fx≈282.37 px`。视差 1 px 的深度误差：

```text
σ_Z ≈ Z² / (f · b)
Z = 0.5 m → σ_Z ≈ 0.25 / (282.37 × 0.05825) ≈ 15.2 mm
Z = 0.8 m → σ_Z ≈ 39 mm
```

这决定了分工：

- **地图层**：厘米级对象位姿、槽位占用、关系、记忆；头双目足够。
- **伺服层**：最后 1–3 cm 的毫米级插入；必须用腕部特写 + CHUNK-SERVO，不能指望头双目。
- **主动观测**：当地图不确定时，移动空闲臂/腕部形成更大基线或更近视角；不是用头双目硬看 2 mm。

### 2.3 长程任务与泛化轴（继承第 12 轮）

- 32 任务、94 个评分步骤、33,276 episodes / 169.28 h；单任务平均 6.2 s（HangCup）–37.6 s（ToolboxStorage）。
- 5 类泛化各 2 次：位置、干扰物、桌面背景、未见物品、人为干扰；human 轴占 20%。
- 至少 19/32 任务终局需要毫米级对齐；同时有 13/32 任务是长程/多物体/多槽位，VLA 的“无状态”问题更突出。
- API 仍是四路 RGB、无 depth/force/tactile；`action_chunk_size` 固定；单模型规则不变。

### 2.4 榜单（不重新核实）

本轮没有重新抓取榜单；沿用第 12 轮的结论：29.7% 是预览上限/难度信号，不是可复现 SOTA；不从榜单任务排名挖创新点。

## 3. 诊断：CHUNK-SERVO 的三个盲区

把一次失败拆成四层：

```text
任务层：现在该做哪个子目标？上一个子目标真的完成了吗？
目标层：目标物/受器是谁？在哪？被移动了吗？
观测层：哪个视角能看见？看得见的置信度是多少？
执行层：5 步伺服怎么把这 3 厘米走准？
```

CHUNK-SERVO 主要修第四层；FACT-VLA/GEO-RESIDUAL 修了一部分第一/第二层，但仍以“相位/残差”隐式表达。MOSAIC 的判断是：

1. **任务层盲**：VLA 的 30 步 plan 不是可验证的任务状态；失败后只能重规划整段，不能只修复被撤销的子目标。
2. **目标层盲**：DG-KEYFRAME 检索的是“目标-夹爪相对位姿”，但前提是目标身份正确；位置/人为干扰/未见物品会让目标身份和位姿同时变。
3. **观测层盲**：四路图是被动输入；腕部被夹爪挡住、头双目深度粗、目标在视野外时，没有“为了确认这个谓词，我应该把空闲臂放到哪里”的决策。
4. **记忆层盲**：跨 chunk 没有持久状态；长程任务里“已经放过的物体/槽位”只能靠当前图像猜。

三者叠在一起，表现就是：**机器人很努力地执行一个已经错了的计划，而且执行得越来越准。**

## 4. 方法：MOSAIC 的五层结构

```text
┌────────────────────────────────────────────────────────────┐
│ 任务层：谓词信念 + 子目标状态机 + 修复                       │
│   language → predicate templates → b_j → phase / repair     │
└──────────────────────┬─────────────────────────────────────┘
                       │ 查询 / 子目标 / 观察请求
┌──────────────────────▼─────────────────────────────────────┐
│ 地图层：对象中心语义地图 OSM-WM                             │
│   nodes: pose/cov/descriptor/role/state/conf/last_seen      │
│   edges: on/in/near/left_of/support/contain                 │
│   update: prediction + association + Kalman/ICP             │
└──────────────────────┬─────────────────────────────────────┘
                       │ 目标位姿 / 地图残差 / 不确定性
┌──────────────────────▼─────────────────────────────────────┐
│ 交互层：多模态证据 + 主动观测 MAIN                          │
│   language prior + visual evidence + proprio evidence       │
│   conflict/entropy → VOI → free-arm view / wrist / probe    │
└──────────────────────┬─────────────────────────────────────┘
                       │ 地图条件目标
┌──────────────────────▼─────────────────────────────────────┐
│ 执行层：演示子图检索 + CHUNK-SERVO                          │
│   retrieve subgoal map → align → relative goal → 5-step     │
└──────────────────────┬─────────────────────────────────────┘
                       │ 动作 / 结果
┌──────────────────────▼─────────────────────────────────────┐
│ 标定层：数字孪生 TCM                                        │
│   noise model → robust thresholds → sim-to-real gate        │
└────────────────────────────────────────────────────────────┘
```

### 4.1 对象中心语义地图 OSM-WM

**节点**：每个物体/容器/槽位/支撑面一个节点。

```text
o_i = (id_i, T_i, Σ_i, f_i, role_i, state_i, conf_i, last_seen_i)
```

- `T_i ∈ SE(3)`：base 系位姿；透明/反光/变形物体允许只存“2.5D 支撑面 + 置信度”，不强行 6D。
- `Σ_i ∈ R^{6×6}`：位姿协方差；由双目视差、关联不确定性、抓持滑移传播。
- `f_i`：轻量描述子（颜色直方图/形状矩/ORB/局部点云统计）；可选同 checkpoint 的 VLA encoder 特征（C3），默认不用第二个模型。
- `role_i`：由任务语言 + 演示先验给出；目标/容器/支撑/槽位/干扰物/未知。
- `state_i`：free/grasped/placed/occluded/missing/moved。
- `conf_i`：关联 + 位姿 + 描述子融合置信度。

**边**：`on/in/near/left_of/right_of/front_of/support/contain`；每条边有置信度。关系用于语言查询（“左边的杯子”）、子图检索、放置验证。

**谓词**：把 94 个评分步骤编译成谓词模板；每个谓词有几何测试和置信度。谓词不是地图的替代，而是地图的“任务相关投影”。

### 4.2 多模态证据与谓词信念

每个谓词 `φ_j` 维护 log-odds：

```text
L_j(t) = L_j(0) + Σ_τ [ ℓ_vis(z_τ, φ_j) + ℓ_prop(q_τ, g_τ, φ_j) + ℓ_lang(ℓ, φ_j) ]
b_j(t) = σ(L_j(t))
```

- `ℓ_lang`：任务语言 + 演示先验给的初始 log-odds；封闭集任务可用规则模板，不需要 LLM。
- `ℓ_vis`：地图几何测试（距离/包含/堆叠/插入深度/拉链位置）给的 log-likelihood ratio。
- `ℓ_prop`：EE 位姿、夹爪开度、关节跟踪误差、物体随动给的弱证据。
- 三路冲突 `κ_j` 大或 `b_j` 接近 0.5 → uncertain → 触发主动观测/轻探。
- 阈值由 TCM 标定；没有力/触觉，所以 `ℓ_prop` 只做“否证”，不做“确认”。

### 4.3 主动交互 MAIN

有限动作集（不假设能控制头部云台）：

```text
A_info = {
  free_arm_view(p)      # 空闲臂移动到候选视角，腕部相机看目标
  free_wrist_view(p)    # 只转空闲腕，不移动大臂
  torso_view(p)         # 小幅躯干/基座转动（若 pivot 安全）
  gentle_probe(o, δ)    # 任务臂在预接触阶段轻推/轻拉，观察本体响应
}
```

候选视角由目标位姿、当前遮挡、相机几何、关节限位、碰撞风险生成；每个动作有代价（时间、关节运动、扰动风险）。

选择：

```text
a* = argmax_{a ∈ A_info} [ IG(a) − λ_C C(a) ]
s.t. C(a) ≤ B, a 在当前相位安全
```

`IG(a)` 用三部分近似：

- 位姿熵下降：`0.5 log det(Σ_i) / det(Σ_i(a))`；
- 谓词熵下降：`H_b(b_j) − E[H_b(b_j')]`；
- 关联熵下降：候选视角让两个相似物体在图像/深度上分开。

**安全约束**：

- 只在非接触相位、或空闲臂/非任务臂上做主动观测；
- 支撑臂/持物臂不做主动观测；
- 每个 episode 的主动观测预算 `B`（例如 ≤3 次、≤2 s）硬限；
- 轻探只在预接触，幅度 ≤5 mm，最多 2 次；
- 任何主动观测失败 → 不重试，回退 VLA/CHUNK-SERVO。

### 4.4 演示子图检索与地图条件目标

离线：对每个任务/子目标，从成功演示抽关键帧，构建“子目标地图”：

```text
M*_k = {对象/容器/槽位节点, 关系, 谓词, T_target^ee*, 目标图}
```

在线：

```text
1. 用任务/相位过滤候选；
2. 用对象数、角色、关系、相对位置做图匹配（Hungarian + 位姿残差）；
3. top-k 重打分（描述子/几何/图像质量）；
4. 选 M*，用对应节点求 T_align（SVD/Procrustes + robust loss）；
5. 期望夹爪位姿 T_B^E,d = T_align · T_target^ee*；
6. 地图残差 r_map = 对齐残差 + 槽位占用不一致 + 缺失/多余节点惩罚。
```

与 CHUNK-SERVO 的组合：

```text
a_cmd = a_ff ∘ exp( Δ_servo + w_map · Δ_map )
w_map = σ(α(c_map − c_0)) · 1[r_map > τ_r] · phase_gain
```

- `Δ_servo`：R12 的 5 步视觉伺服，负责最后 3 cm 毫米级；
- `Δ_map`：地图级低频修正，负责“目标物/受器整体偏了几厘米/被移动”；
- `w_map`：置信度门控；地图不可信时严格为 0，行为退回 CHUNK-SERVO；
- 接触段 `phase_gain` 降档，避免地图修正压过伺服。

### 4.5 数字孪生标定 TCM

只标定三件事：

1. **观测模型**：双目深度偏置/方差、遮挡率、关联错误率、描述子可分性；
2. **人编辑模型**：移动/拿走/翻转/撤销的幅度、频率、延迟；
3. **主动观测收益**：不同视角/基线/距离对位姿熵和关联熵的实际下降。

方法：

```text
θ_hat = argmin_θ || φ(M_real) − φ(M_sim(θ)) ||²
η_hat = argmax_η min_{θ ∈ U(θ_hat, ε)} E[S(η; θ)]
```

`φ` 是地图统计量（深度误差、位姿误差 CDF、关联 F1、遮挡率、编辑检测延迟）；`η` 是门限（关联门限、冲突阈值、主动观测阈值、`w_map`、编辑阈值）；`U` 是参数不确定球。**不做策略训练；不把 sim 成功率当真机预测。**

### 4.6 状态机

```text
INIT ──first obs──▶ MAP ──map valid──▶ PLAN
  ▲                   │                    │
  │                   │ uncertain          │ plan ready
  │                   ▼                    ▼
  │                OBSERVE ◀── conflict ── SERVO ──d_t<d_c──▶ CONTACT
  │                   │                    │                    │
  │                   └── budget exhausted ─┘                    │
  │                                                             │
  └────────── RECOVER ◀── edit / predicate regression ◀── VERIFY ◀┘
任意状态 ──success / max steps──▶ DONE
```

- `MAP`：初始化/更新地图；置信度低则停在 MAP，不急着执行。
- `OBSERVE`：主动观测；预算耗尽回退。
- `PLAN`：VLA 异步规划；地图作为可选 prompt。
- `SERVO`：CHUNK-SERVO 执行；地图给目标/相位。
- `CONTACT`：最后 3 cm；地图降权，伺服主导。
- `VERIFY`：谓词信念判断子目标是否完成；失败 → 修复/重试。
- `RECOVER`：人编辑/谓词回退 → 停 → 重定位 → 更新地图 → 重规划。

## 5. 形式化定义（简版，详见产物区）

### 5.1 POMDP

```text
状态 s_t：物体位姿/角色/状态、任务相位、人编辑
观测 z_t = (I_HL, I_HR, I_WL, I_WR, q, g, ℓ)
动作 a_t：EE 目标 + 夹爪 + pivot，按 chunk 执行；另有有限信息动作 A_info
奖励：任务成功（0/1）+ 步骤分 − 时间/安全惩罚
信念：语义地图 M_t ≈ b_t(s_t)
```

### 5.2 地图更新

```text
预测：静态物体 T_i^- = T_i；抓持物体 T_i^- = T_B^E(t) · (T_B^E(t_0))^{-1} · T_i(t_0)
协方差：Σ_i^- = Σ_i + Q_i；抓持时 Σ_i^- = J_E Σ_E J_E^T + Σ_slip
关联：A* = argmax Σ A_ij s_ij，s_ij 由位姿马氏距离 + 描述子相似 + 角色兼容组成；Hungarian
校正：T_i = T_i^- · exp(K_i (z_i − h(T_i^-)))，Σ_i = (I − K_i H) Σ_i^-
```

### 5.3 主动观测

```text
U(M) = Σ_i 0.5 log det Σ_i + Σ_j H_b(b_j) + H(A)
a* = argmax_a [ U(M) − E[U(M')] − λ_C C(a) ]，s.t. C(a) ≤ B
```

### 5.4 延迟稳定性

地图修正的 1D 误差动力学：

```text
e_{k+1} = e_k − w_map K H_c e_{k−d}
特征方程：z^{d+1} − z^d + w_map K H_c = 0
```

稳定域（`H_c=1`，数值验证）：`d=0: K<2`；`d=1: K<1`；`d=2: K<0.618`；`d=3: K<0.445`。这解释了为什么地图修正必须低频、限幅、按 RTT 降增益。

### 5.5 数字孪生标定

```text
θ_hat = argmin_θ || φ(M_real) − φ(M_sim(θ)) ||²
η_hat = argmax_η min_{θ ∈ U(θ_hat, ε)} E[S(η; θ)]
```

在 Lipschitz 成功函数假设下，`|E_real S(η) − E_sim S(η)| ≤ L_S · W_1(P_real, P_sim)`；标定降低统计量差异，鲁棒优化覆盖剩余 gap。

## 9. 风险与合规

| 风险 | 影响 | 缓解 |
|---|---|---|
| 地图关联错误 | 自信地追错物体/槽位 | 置信度门控；描述子+几何+角色三重代价；低置信度回退 VLA |
| 双目深度噪声 | 地图位姿漂移 | 地图只做厘米级；最后 3 cm 交给腕部伺服；主动观测补基线 |
| 透明/反光/变形 | 地图节点不稳定 | 只对刚体启用精确节点；变形任务只做粗状态；失败回退 |
| 主动观测扰动任务 | 破坏已完成子目标/超时 | 预算硬限；只用空闲臂/非接触相位；支撑臂不动 |
| 地图作为 VLA prompt 分布外 | VLA 忽略或误用 | 先只做控制器（C2）；prompt 需用演示地图微调后再启用（C3） |
| 单模型解释 | 被判定为第二个模型 | 地图/主动观测无学习权重；不用独立分割器；提交材料写清楚 |
| 孪生过拟合 | 门限在真机失效 | 只用真机标定集调阈值；鲁棒优化；不把 sim 成功率当真机预测 |
| 多端口并发 | 内存/CPU 争抢 | 每端口独立地图；共享只读演示库；CPU 预算隔离 |
| 人编辑太快 | 检测/恢复不及时 | 地图+本体双通道；检测即停；恢复预算；不声称 100% |
| 评测噪声 | +1–2pp 假阳性 | 配对 A/B、bootstrap、重复实验；320 trials SE≈2.4pp |

**合规边界**：MOSAIC 的在线学习模型只有官方 WLA/VLA；地图、关联、谓词、VOI、孪生标定都是确定性算法；描述子优先用经典特征，若用 VLA 同 checkpoint encoder 则归入 C3 并明确说明；离线可用 SAM/GroundingDINO 做标注质检，但不随提交部署。

## 10. 一句话押注

**用对象中心语义地图做跨 chunk 的工作记忆，用语言/视觉/本体证据维护谓词信念，用有预算的主动观测消除地图歧义，用演示子图对齐给 CHUNK-SERVO 正确的相对目标，用数字孪生只标定地图的噪声模型与门限——让最后 3 厘米走在正确的子目标上。**

**本轮最大风险：语义地图的关联/位姿误差会以“自信的错误”方式污染下游目标和谓词；如果 M1 的关联 F1 与位姿误差不过门，MOSAIC 必须整体回退到 CHUNK-SERVO，而不是带着错误地图继续跑。**

# 第 13 轮产物 · MOSAIC 技术报告：语义地图作为工作记忆、主动多模态交互与孪生标定

> 检索/复核日期：**2026-10-31（UTC）**。对象：宇树 **UniBot 世界挑战赛**（unibot.unitree.com），G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API。本报告是第 13 轮（新循环第 1 轮）想法区「MOSAIC」的工程化产物；技术基线承接第 10 轮 FACT-VLA、第 11 轮 GEO-RESIDUAL、第 12 轮 CHUNK-SERVO，不推倒重来。

## 0. 结论与边界

### 0.1 一句话结论

**MOSAIC = Multimodal Object-centric Semantic map with Active Interaction and Calibration。** CHUNK-SERVO 把最后 3 厘米的反馈周期从 1 s 压到 167 ms，但它默认“目标已知、场景未变、上一子目标已完成”。MOSAIC 在它前面加一层**对象中心语义地图**：用语言/视觉/本体三路证据维护对象位姿、关系、状态与谓词信念；当地图不确定或证据冲突时，用有预算的主动观测（空闲臂/腕部/躯干/轻探）去查账；用 33k 成功演示检索“子目标地图”并做场景级对齐，给 CHUNK-SERVO 一个正确的相对目标；用数字孪生只标定地图的噪声模型与门限。结果是把“在错误的计划上做得更准”改成“先确认计划，再把最后 3 厘米做准”。

### 0.2 证据等级

| 等级 | 含义 | 本报告中的例子 |
|---|---|---|
| A | 官方文档、提交模板、数据集元数据直接核实 | 32 任务/94 评分步骤/33,276 eps；四路 RGB；头双目基线 58.2526 mm；腕部 color 有内参；WLA `chunk_size=30` |
| B | 我们在公开数据/合成实验上做的分析，可复现 | 深度误差 15.2 mm@0.5 m；合成地图/关联/编辑检测 toy 结果；延迟稳定域数值 |

### 0.3 本轮不做什么

## 2. 问题形式化

### 2.1 POMDP

定义部分可观测马尔可夫决策过程：

```text
S：物体位姿/角色/状态、容器/槽位占用、任务相位、人编辑
O：z_t = (I_t^HL, I_t^HR, I_t^WL, I_t^WR, q_t, g_t, ℓ)
A：EE 目标位姿 + 夹爪 + pivot，按 H_c 步 chunk 执行；另有有限信息动作 A_info
R：任务成功 1/0 + 步骤分 − 时间/安全惩罚
```

信念 `b_t(s_t)` 用对象中心语义地图 `M_t` 近似。MOSAIC 的设计假设是：**任务相关的状态变量可以压缩到 `M_t` 的对象节点、关系边和谓词信念里**；不需要保留完整历史。

### 2.2 语义地图定义

```text
M_t = (O_t, E_t, B_t)

O_t = {o_i}_{i=1}^{N_t}
o_i = (id_i, T_i, Σ_i, f_i, role_i, state_i, conf_i, last_seen_i, attached_i)

T_i ∈ SE(3)               # base 系位姿；T_B^O
Σ_i ∈ R^{6×6}             # 位姿协方差
f_i ∈ R^d                 # 轻量描述子（颜色/形状/ORB/局部统计）
role_i ∈ {target, container, support, slot, distractor, unknown}
state_i ∈ {free, grasped, placed, occluded, missing, moved}
attached_i ∈ {0,1}        # 是否随 EE 刚体运动
conf_i ∈ [0,1]

E_t = {r_ij}, r_ij ∈ {on, in, near, left_of, right_of, front_of, support, contain}
B_t = {b_j}, b_j = P(φ_j=1 | z_{1:t}, a_{1:t}, ℓ)
```

位姿约定：`T_B^O` 表示物体 O 在 base 系 B 中的位姿；`T_O^E = (T_B^O)^{-1} T_B^E`。地图节点可以用 base 系，也可以用桌面系 `T`；本报告默认 base 系，桌面系只作为检索/对齐的中间量。

### 2.3 观测模型与深度误差

头双目：`Z = f b / d`，`σ_Z ≈ Z² σ_d / (f b)`。取 `f≈282.37 px`、`b≈58.2526 mm`、`σ_d≈1 px`，得到表 1。

| 距离 Z | 深度误差 σ_Z（1 px 视差） |
|---:|---:|
| 0.3 m | 5.5 mm |
| 0.5 m | 15.2 mm |
| 0.8 m | 38.9 mm |
| 1.0 m | 60.8 mm |

腕部：`f≈436 px`、基线≈18 mm（IR 双目），近距 0.1–0.3 m 可到亚毫米–毫米级；但手眼外参需标定。腕部适合最后 3 cm 的局部对齐，不适合全局地图。

**头相机外参**：数据里 `state_d435` 是头相机在 base 系的 6D 位姿；在线 API 给 `lower_body`，可用 waist 关节 + 桌面平面在线恢复（第 11/12 轮路线），或一次性标定。地图节点统一在 base 系；若头相机外参不可信，地图退化到“相机系 + 桌面系”的相对关系，只做物体间相对位姿/槽位占用，不做绝对 base 坐标。

### 2.4 谓词与任务状态

把 94 个评分步骤编译成谓词模板。每个谓词是地图上的几何测试：

```text
φ_j = 1[ g_j(T_{i_1}, ..., T_{i_k}) ≤ τ_j ]
```

例子：

| 谓词 | 几何测试 | 主要证据 |
|---|---|---|
| `grasped(o,g)` | 夹爪宽度 vs 物体宽度；物体随 EE 刚性运动 | 本体 + 视觉 |
| `in(o,c)` | `T_c^{-1} T_o` 的平移落入容器包围盒；开口方向/深度 | 视觉 + 关系 |
| `on(o,s)` | 垂直顺序 + 水平重叠 + 接触距离 | 视觉 |
| `plugged(o,p)` | 插入轴对齐 + 插入深度 + 横向偏差 | 视觉 + 本体（顶住） |
| `zipped(z)` | 拉链头位置 vs 终点；拉链线连续 | 视觉 |
| `stacked(o1,o2)` | 垂直顺序 + 接触 + 水平偏移 | 视觉 |
| `slot_filled(s,o)` | 槽位包围盒内是否有物体 | 视觉 + 记忆 |
| `moved(o)` | 当前位姿 vs 上次稳定位姿 > 阈值 | 地图残差 |
| `clear(r)` | 区域无物体 | 视觉 + 记忆 |

谓词置信度用一阶delta方法近似：

```text
b_j ≈ Φ( (τ_j − g_j(T̂)) / sqrt(J_g Σ J_g^T) )
```

其中 `Φ` 是标准正态 CDF，`J_g` 是几何测试对位姿的雅可比。多物体谓词用联合协方差。这个近似在 `g_j` 局部线性、误差近似高斯时成立；大角度/强非线性时用 sigma points 或采样。

### 2.5 目标

总分：

```text
S = (1/32) Σ_t p_t,  p_t = (1/10) Σ_j y_{t,j},  y ∈ {0,1}
```

320 trials 下 `p≈0.25` 时 `SE(S) ≈ sqrt(0.25×0.75/320) ≈ 2.42pp`。MOSAIC 的收益必须用配对 A/B 的 bootstrap 置信区间报告，不能只看平均值。

### 2.6 分层假设

MOSAIC 采用三层分工：

```text
地图层（厘米级）：对象/容器/槽位位姿、关系、状态、记忆、谓词
伺服层（毫米级）：CHUNK-SERVO 的 5 步腕部视觉伺服
规划层（秒级）：VLA 的 30 步动作意图
```

三层的误差尺度不同，不能互相替代：

- 地图层用头双目，15 mm@0.5 m，够判断“在哪个槽/哪个物体”，不够插入；
- 伺服层用腕部特写，够最后 3 cm，但不知道“该插哪个孔”；
- 规划层用 VLA，够语义意图，但没有持久状态。

MOSAIC 的价值在于把三层的接口显式化：地图给规划层状态、给伺服层目标、给验证层谓词。

## 3. 算法：MOSAIC

### 3.1 总览

```text
                    ┌─────────────────────────────────────┐
                    │  Evaluator (N ports 8765..8765+N-1) │
                    └──────────────┬──────────────────────┘
                                   │ websocket: obs / action chunk
                                   ▼
                    ┌─────────────────────────────────────┐
                    │  Per-port PolicyService (CPU)       │
                    │  ├─ OSM-WM semantic map             │
                    │  ├─ MAIN multimodal evidence/VOI    │
                    │  ├─ demo subgraph retrieval         │
                    │  ├─ map-conditioned goal            │
                    │  ├─ CHUNK-SERVO (R12)               │
                    │  └─ action adapter (WLA 54D → API)  │
                    └──────────────┬──────────────────────┘
                                   │ async, batched
                                   ▼
                    ┌─────────────────────────────────────┐
                    │  Shared VLA server (GPU)            │
                    │  UnifoLM-WLA-1.0 / VLA-0, 30-step   │
                    └─────────────────────────────────────┘
```

- 唯一学习模型：VLA。
- 地图/关联/谓词/VOI/标定：确定性算法，CPU。
- 演示库：只读、共享、按任务/子目标分片；每端口独立地图状态。
- 数字孪生：离线标定/压力测试，不随提交运行。

### 3.2 地图预测

对每个节点：

```text
if attached_i == 0 and state_i != grasped:
    T_i^- = T_i
    Σ_i^- = Σ_i + Q_static
elif attached_i == 1:
    T_i^- = T_B^E(t) · (T_B^E(t_0))^{-1} · T_i(t_0)
    Σ_i^- = J_E Σ_E J_E^T + Σ_slip
else:  # just placed / released
    T_i^- = T_i
    Σ_i^- = Σ_i + Q_place
```

- `Q_static` 很小（例如 `(0.5 mm)²`），防止协方差塌缩后完全不更新。
- `Σ_slip` 表示抓持滑移；用夹爪开度变化、物体随动残差、关节跟踪误差估计。
- 放置后把 `attached_i` 置 0，更新 `on/in/support` 关系；若物体在容器内，继承容器位姿的不确定性。

### 3.3 检测与数据关联

检测：头双目点云去桌面、聚类（5–10 mm）、拟合包围盒/支撑面/圆柱；腕部图像做局部特征/边缘/颜色块。每个检测：

```text
d_j = (T_j^d, Σ_j^d, f_j^d, role_j^d, conf_j^d)
```

关联代价：

```text
c_ij = || log( (T_i^-)^{-1} T_j^d ) ||²_{Σ_i^- + Σ_j^d}
     + λ_f (1 − <f_i, f_j^d>)
     + λ_role 1[role_i 与 role_j^d 不兼容]
     + λ_state 1[state_i 与检测不兼容]
```

求解：

```text
A* = argmax_{A ∈ {0,1}^{N×M}, 一对一} Σ_ij A_ij ( −c_ij )
```

用 Hungarian，`O(N³)`；门限 `c_ij ≤ τ_assoc`。处理：

- **匹配**：Kalman/ICP 校正；
- **未匹配检测**：若描述子与某节点相似但距离 > 门限 → “moved” 假设，重置该节点位姿/协方差；否则新节点（低置信度）；
- **未匹配节点**：协方差增大；超时 → `occluded/missing`；
- **角色冲突**：语言/任务先验优先，但保留低置信度备选；不硬删。

关联不确定性：

```text
H(A) = −Σ_ij P_ij log P_ij
P_ij ∝ exp(−c_ij)
```

用 Sinkhorn 或 Hungarian 的边际近似；地图熵里计入 `H(A)`。

### 3.4 位姿校正

对匹配 `(i,j)`：

```text
δ = log( (T_i^-)^{-1} T_j^d ) ∈ R^6
S = H Σ_i^- H^T + Σ_j^d
K = Σ_i^- H^T S^{-1}
T_i = T_i^- · exp(K δ)
Σ_i = (I − K H) Σ_i^- (I − K H)^T + K Σ_j^d K^T   # Joseph form
```

- `H` 是观测雅可比；对完整 6D 位姿观测，`H=I`。
- 大角度/大位移时先做 ICP/多初值，再 Kalman；避免线性化失败。
- 透明/反光：降低 `conf`，增大 `Σ`，不硬更新；变形物体只更新 2.5D 支撑面/质心。

### 3.5 多模态谓词更新

每个谓词 `φ_j` 维护 log-odds：

```text
L_j(t) = L_j(0) + Σ_{τ=1}^{t} [ ℓ_vis(z_τ, φ_j) + ℓ_prop(q_τ, g_τ, φ_j) + ℓ_lang(ℓ, φ_j) ]
b_j(t) = σ(L_j(t))
```

- `L_j(0)`：任务模板/演示先验；例如 `in(cup,rack)` 初始偏向 false。
- `ℓ_vis`：由 2.4 的几何测试和置信度得到；`ℓ_vis = log p(g_j | φ=1) / p(g_j | φ=0)`。
- `ℓ_prop`：由 EE 位姿、夹爪开度、关节跟踪误差、物体随动得到；例如“夹爪闭合但物体不随动”给 `grasped=false` 正证据。
- `ℓ_lang`：任务语言/角色先验；封闭集用规则模板，不需要 LLM。
- 为防重复计数，`ℓ_vis` 与 `ℓ_prop` 用条件独立性假设；若强相关，用温度/折扣因子 `γ∈(0,1]` 降权。

冲突分数：

```text
κ_j = |ℓ_vis − ℓ_prop| + |ℓ_vis − ℓ_lang| + |ℓ_prop − ℓ_lang|
```

若 `κ_j > τ_c` 或 `b_j ∈ (0.5−ε, 0.5+ε)`，标记 uncertain；触发主动观测/轻探。

### 3.6 主动交互 MAIN

动作集（不假设头部云台）：

```text
A_info = {
  free_arm_view(p)     # 空闲臂移动到候选视角，腕部相机看目标
  free_wrist_view(p)   # 只转空闲腕，不移动大臂
  torso_view(p)        # 小幅躯干/基座转动（若 pivot 安全）
  gentle_probe(o, δ)   # 任务臂在预接触阶段轻推/轻拉，观察本体响应
}
```

候选视角生成：

- 目标节点位置 `T_i`、当前遮挡体、相机内外参；
- 采样候选 `p`（球面/工作空间网格），剔除碰撞/关节限位/不可达；
- 预测可见性 `v(p)`、测量协方差 `R(p)`、运动代价 `C(p)`。

信息增益：

```text
IG(a) = w_p IG_pose(a) + w_b IG_pred(a) + w_a IG_assoc(a)
```

- 位姿：`IG_pose(a) = 0.5 log det(Σ_i) / det(Σ_i(a))`，其中
  `Σ_i(a) = (Σ_i^{-1} + v(a) H_i^T R(a)^{-1} H_i)^{-1}`。
- 谓词：`IG_pred(a) = H_b(b_j) − E[H_b(b_j')]`；用预测观测的似然加权。
- 关联：`IG_assoc(a) = H(p_conf) − H(p_conf(a))`，`p_conf` 是目标与最近相似物体的混淆概率，随视角分离度下降。

代价：

```text
C(a) = α T(a) + β ||Δq||² + γ risk(a)
```

选择：

```text
a* = argmax_{a ∈ A_info} [ IG(a) − λ_C C(a) ]
s.t. C(a) ≤ B, a 在当前相位安全
```

安全约束：

- 只在非接触相位、或空闲臂/非任务臂上做主动观测；
- 支撑臂/持物臂不做主动观测；
- 每 episode 预算 `B`（例如 ≤3 次、≤2 s）；
- 轻探只在预接触，幅度 ≤5 mm，最多 2 次；
- 主动观测失败 → 不重试，回退 VLA/CHUNK-SERVO；
- 任何动作都不能让当前已抓物体掉落或碰撞。

### 3.7 演示子图检索

离线：

```text
for each episode:
    phases = segment(episode)                    # FACT-VLA CPT / GEO-RESIDUAL
    for each phase:
        k = select_keyframe(phase)               # pre-contact / target-in-view / release
        M*_k = build_map(episode, k)             # 节点/关系/谓词
        T_target^ee* = (T_B^target)^{-1} T_B^ee  # 目标-夹爪相对位姿
        I_wrist* = episode.wrist[k]
        index.add(task, phase, M*_k, T_target^ee*, I_wrist*, quality)
```

关键帧选择：

- 接触任务：首次接触前 1–3 帧 + 接触稳定后 1 帧；
- 挂/叠/插入：目标进入腕部视野且夹爪距离 <5 cm；
- 拉链/锁：夹爪咬合前；
- 长程任务：每个子目标完成前/后各 1 帧；
- 变形任务：只存相位/粗状态，不存精确相对位姿。

在线检索：

```text
candidates = index.filter(task=ℓ, phase=p)
candidates = candidates.rerank(role/relation/object-count)
topk = candidates.topk(graph_similarity, k=5)
M* = rerank(topk, descriptor, pose_consistency, image_quality)
if M*.confidence < θ_c: fallback()
```

图相似度：

```text
sim(M_t, M*_k) = Σ_{(i,j)∈match} exp(−||T_i − T_align T_j*||²_Σ)
               + λ_r relation_match
               + λ_c object_count_match
```

先用角色/关系做硬过滤，再用几何做软打分；不要用全局颜色直方图把“插网线”匹配到“拔网线”。

### 3.8 场景对齐与地图条件目标

给定对应节点 `{(i,j)}`，求 `T_align ∈ SE(3)`：

```text
T_align = argmin_{T ∈ SE(3)} Σ_{(i,j)} ρ( || log( T_i^{-1} T T_j* ) ||_{Σ_i+Σ_j*} )
```

- 位置用 Umeyama/SVD 闭式解；旋转用 SVD 投影到 SO(3)；
- 用 Huber/Tukey 鲁棒损失 + RANSAC 剔除错误对应；
- 对应关系由 Hungarian 从角色/描述子/几何代价得到。

期望夹爪位姿：

```text
T_B^E,d = T_align · T_target^ee*
```

地图残差：

```text
r_map = (1/|C|) Σ_{(i,j)} ρ( || log( T_i^{-1} T_align T_j* ) || )
      + λ_s slot_mismatch
      + λ_m missing_or_extra_penalty
```

地图修正：

```text
e_map = log( (T_B^E)^{-1} T_B^E,d )
Δ_map = clip( K_map e_map, ±δ_p, ±δ_r )
w_map = σ(α(c_map − c_0)) · 1[r_map > τ_r] · phase_gain
a_cmd = a_ff ∘ exp( Δ_servo + w_map Δ_map )
```

- `Δ_servo`：R12 的 5 步视觉伺服；
- `Δ_map`：地图级低频修正；只在 chunk 边界算一次；
- `Δ_servo` 与 `Δ_map` 默认都在 **EE 局部系**，右乘到绝对目标；若改用 base 系误差，则左乘。两者不能混帧，否则地图修正会引入系统性旋转偏差；
- `phase_gain`：接近段 0.5–1.0，接触段 0.2–0.4，自由空间 0.5；
- `w_map=0` 时严格退回 CHUNK-SERVO；
- 连续 3 个 chunk `||Δ_map||` 超阈值 → 地图/标定异常，关地图修正。

#### 3.8.1 可选：地图作为 VLA 的紧凑 prompt（C3）

地图修正是 C2 路线；如果 M7 证明“VLA 需要显式状态”而不仅是“控制器需要目标”，可以加 C3 路线：把地图序列化成短文本，作为 VLA 的语言前缀/后缀。序列化只取任务相关节点，控制在 <256 token：

### 3.9 编辑检测与恢复

机器人动作解释不了的场景变化：

```text
e_edit = min_{δ ∈ D_robot} || M_t ⊖ (M_{t−1} ⊕ a_{t−1} ⊕ δ) ||
```

`D_robot` = {grasp, place, push, open, close, stack, insert} 的预期变化。若 `e_edit > θ_e`：

```text
1. 停（hold position）；
2. 重定位目标/容器（头双目 + 主动观测）；
3. 目标可见 → 更新地图/目标，保守增益恢复；
4. 目标不可见/被拿走 → VLA 重规划或搜索；
5. 重试超限 → graceful fail。
```

编辑检测不需要“识别人类”，只需要“场景动了，而且不是我的动作解释的”。

### 3.10 主循环伪代码

```python
class MosaicPolicy:
    def get_action(self, obs):
        self._tick(obs)
        self._predict_map(obs)

        dets = self._detect(obs)
        matches, unmatched_d, unmatched_m = self._associate(dets)
        self._update_map(dets, matches, unmatched_d, unmatched_m)
        self._update_predicates(obs)

        if self._conflict() or self._map_entropy() > self.tau_u:
            a_info = self._select_info_action()
            if a_info is not None and self._budget > 0:
                return self._info_action(a_info)  # bounded; no task-arm change if possible
            # budget exhausted: fall through with map gated off

        self._maybe_request_plan(obs)

        if self.plan is None:
            self.plan = self.vla.predict(obs)  # cold start, sync with timeout
            self.plan_age = 0

        self._retrieve_subgoal()
        self._align_and_make_goal()

        a_ff = self.plan[self.plan_idx : self.plan_idx + self.H_c]
        if self.map_valid():
            delta = self.servo.compute(obs, self.goal) + self.w_map * self.map_correction()
        else:
            delta = self.servo.compute(obs, self.goal)
        a_cmd = compose_relative(a_ff, delta)
        self.plan_idx += self.H_c
        if self.plan_idx >= len(self.plan):
            self.plan_idx, self.plan = 0, None

        self._verify_and_advance()
        if self._edit_detected():
            self._recover()
        return self.adapter.to_api(a_cmd, obs, self.token)
```

`_maybe_request_plan` 与 R12 相同：VLA 异步、不阻塞 `get_action`；plan 过期用旧 plan + 伺服；异常返回上一组合法 chunk 或安全 hold。

## 4. 正确性论证

### 4.1 地图一致性

**命题 1（静态物体）**。假设：(i) 数据关联正确；(ii) 物体静止；(iii) 观测噪声零均值高斯，协方差 `R`；(iv) 地图用 EKF/位姿 Kalman 更新。则位姿估计无偏，协方差由 Riccati 递推给出；在可观测条件下，协方差收敛到有界稳态。

**证明思路**：标准 Kalman 滤波；静态模型 `T^- = T`，观测模型 `z = h(T) + v`；线性化后是线性高斯系统；可观测性由相对位姿观测保证。

**命题 1'（抓持物体）**。若抓持是刚性的（无滑移），且 EE 位姿已知，则预测 `T_i^- = T_B^E(t)(T_B^E(t_0))^{-1} T_i(t_0)` 精确；若存在滑移噪声 `Σ_slip`，协方差增长但有界。

**证明思路**：刚体变换是 EE 位姿的确定性函数；滑移建模为加性噪声，Kalman 预测协方差 `J_E Σ_E J_E^T + Σ_slip` 保持正定有界。

**边界**：关联错误、非高斯遮挡、透明/反光会破坏假设；所以需要置信度门控和回退，不能把命题 1 当无条件保证。

### 4.2 延迟反馈稳定性

考虑 1D 误差动力学（地图修正在 chunk 边界生效，延迟 `d` 个 chunk）：

```text
e_{k+1} = e_k − w_map K H_c e_{k−d}
```

特征方程：

```text
z^{d+1} − z^d + w_map K H_c = 0
```

由 Jury 判据/数值求根：

| 延迟 d | 最大稳定增益 `w_map K H_c` |
|---:|---:|
| 0 | 2.000 |
| 1 | 1.000 |
| 2 | 0.618 |
| 3 | 0.445 |

（合成数值实验：K 网格 0.001–3.0，步长 0.0005；与理论一致。）

**推论**：地图修正必须低频、限幅、按 RTT/延迟降增益；`w_map` 和 `δ_p/δ_r` 是稳定裕度的一部分，不是“调参手感”。如果 `T_fb > 300 ms`，地图修正应关闭或降到 `w_map ≤ 0.3`。

### 4.3 主动感知的熵与近优性

**命题 3（熵不增）**。若观测模型正确、更新是贝叶斯后验，则对任意信息动作 `a`，期望后验熵不超过先验熵：

```text
E_{z|a}[ H(M') ] ≤ H(M)
```

**证明思路**：互信息非负：`H(M) − E[H(M'|z)] = I(M; z|a) ≥ 0`；等号当且仅当观测与状态独立。

**命题 3'（选择近优）**。若 `IG(a)` 是单调子模且代价均匀，贪心选择达到 `1−1/e` 最优；若 `|A_info| ≤ 12`，直接枚举是精确最优。

**安全推论**：如果所有 `IG(a) ≤ λ_C C(a)`，则最优选择是“不观测”，系统继续执行 VLA/CHUNK-SERVO；因此主动观测不会为了“看一眼”而无限消耗时间。

### 4.4 回退安全

**命题 4**。若地图置信度 `c_map < c_0`、关联熵 `H(A) > τ_H`、或对齐残差 `r_map > τ_r`，则设 `w_map = 0`，且主动观测只允许不改变任务臂/已抓物体的动作；此时任务动作等于 CHUNK-SERVO 的动作。

**证明思路**：`a_cmd = a_ff ∘ exp(Δ_servo + 0·Δ_map)`，即 R12 的动作；主动观测若只移动空闲臂/腕部，不改变任务臂的 EE 目标，则任务执行路径不变。唯一代价是时间/可能的视觉输入变化；若 VLA 对图像变化敏感，可在回退时冻结 VLA 输入或使用缓存观测。

**边界**：如果主动观测移动了躯干/基座，可能改变 VLA 图像和任务臂位姿；所以回退时禁止躯干/基座主动观测。

### 4.5 数字孪生标定的误差界

设 `S(η; ξ)` 是门限 `η` 在环境 `ξ` 下的成功率，`ξ` 包括相机噪声、遮挡、关联错误、人编辑分布。假设 `S` 对 `ξ` 是 `L_S`-Lipschitz（在 `W_1` 下）。则：

```text
| E_{P_real} S(η) − E_{P_sim(θ̂)} S(η) | ≤ L_S · W_1(P_real, P_sim(θ̂))
```

由 Kantorovich–Rubinstein 对偶。标定最小化统计量差异 `||φ(M_real) − φ(M_sim(θ))||`；若 `φ` 是充分统计量且映射 Lipschitz，则统计量差异上界 `W_1` 差异。鲁棒优化：

```text
η̂ = argmax_η min_{θ ∈ U(θ̂, ε)} E_{P_sim(θ)} S(η)
```

覆盖剩余 sim-to-real gap。

**边界**：这是设计 justification，不是高维图像分布的严格保证；`L_S` 可能很大，`φ` 可能不充分。所以孪生只用于**相对排序/门限保守化**，不用于预测真机绝对成功率。

### 4.6 记忆充分性

**命题 6（建模假设）**。若地图 `M_t` 包含所有任务相关状态变量（物体位姿/角色/状态、容器/槽位占用、谓词），则 `M_t` 是 POMDP 信念的充分统计量；以 `M_t` 为条件的策略不劣于只以当前观测为条件的策略。

**证明思路**：POMDP 最优策略只依赖信念 `b_t(s_t)`；若 `M_t` 是 `b_t` 的充分统计量，则 `π(a|M_t)` 可以达到 `π(a|b_t)` 的同样性能。这是标准 belief MDP 结论。

**边界**：地图是信念的近似；遗漏变量（人的意图、未观测物体、变形历史）会破坏充分性。所以地图不是万能的；它只覆盖“任务相关、可观测、可几何化”的状态。

### 4.7 什么时候会错（反例）

1. **相似物体关联错**：两个同样的杯子，描述子相同，几何接近；Hungarian 可能交换。缓解：角色/空间关系/演示先验；低置信度不修正。
2. **透明物体深度缺失**：双目视差在透明表面失效；地图节点漂移。缓解：只对刚体启用；透明任务用腕部 2D + VLA。
3. **快速人编辑**：编辑发生在 chunk 内，地图下一次更新才发现；恢复晚。缓解：编辑检测即停；chunk 5 步；human 轴预算。
4. **地图修正与伺服冲突**：地图说左 1 cm，伺服说右 2 mm；两者叠加可能振荡。缓解：分层增益、`w_map` 门控、接触段降权、稳定性界。
5. **主动观测扰动**：移动空闲臂碰到物体/人；或占用时间导致超时。缓解：预算、安全壳、非接触相位、支撑臂不动。
6. **子图检索错**：演示子图与当前场景物体数/布局差异大；对齐错误。缓解：角色/关系硬过滤、RANSAC、置信度回退。


```text
θ̂ = argmin_θ Σ_k w_k || φ_k(M_real) − φ_k(M_sim(θ)) ||²
```

### 5.4 鲁棒门限优化

```text
η = (τ_assoc, τ_c, τ_u, τ_IG, λ_C, w_map, τ_r, θ_e, B)
η̂ = argmax_η min_{θ ∈ U(θ̂, ε)} (1/M) Σ_m S(η; θ_m)
```

`U(θ̂, ε)` 用有限扰动孪生（例如 8–16 个场景）近似；`S` 是仿真任务成功率/步骤分。目标不是找“仿真最高”，而是找“扰动下最稳”的门限。

### 6.2 合成 sanity check（本轮实际运行，非真机）

为了验证公式而不是宣称真机效果，本轮跑了一个 2D 合成 toy：

**设置**：N=8 个静态物体，30 帧；检测率 0.9；位置噪声 σ=10 mm；初始地图先验 σ=30 mm；2 个 clutter/帧；Hungarian + Kalman；50 次重复；第 15 帧把一个物体移动 (12,10) cm。

| 实验 | 结果 | 解释 |
|---|---|---|
| 延迟稳定域（H_c=1） | d=0: K<2.000；d=1: K<1.000；d=2: K<0.618；d=3: K<0.445 | 与特征方程一致；地图修正必须按延迟降增益 |
| 无 clutter | 原始观测中位误差 11.7 mm；地图中位误差 3.7 mm；关联 F1 0.938 | 地图多帧融合显著降噪 |
| 有 clutter | 原始 11.8 mm；地图 4.0 mm；关联 F1 0.824 | clutter 主要伤关联，不伤位姿融合 |
| 编辑检测 | 50/50 次在 ≤1 帧内检出 | 关联 NIS + 未匹配检测的 moved 假设 |
| 主动视角熵下降 | 头双目 1.179 nats；腕部 2.712；空闲臂 4.047 | 视角越好/越近，熵下降越大；支持 VOI 选择 |

**限制**：这是 2D 点观测 toy，不含真实图像、遮挡、透明、手眼标定误差；只能验证地图更新/稳定性/VOI 的数学，不是真机成功率证据。

### 6.3 仿真

| 实验 | 变量 | 指标 | 门 |
|---|---|---|---|
| 地图条件伺服 | 目标移动 ±0/2/5/10 cm | 成功率、收敛时间、超调 | M2 |
| 主动观测 | off/head/free-arm/probe | 关联准确率、恢复率、耗时 | M3 |
| 长程记忆 | 5 个 4+ 子目标任务 | 成功率、步骤分、遗忘错误 | M4 |
| 人编辑 | 移动/拿走/翻转/撤销 | 检测延迟、恢复率 | M3/M4 |
| 延迟 | 0–150 ms | 稳定性、p99 | M2/M6 |
| 消融 | 地图/主动/子图/TCM | 成功率、地图指标 | M7 |

### 6.4 真机单任务

| 项 | 设计 |
|---|---|
| 任务 | ToolboxStorage、PackBag、HangCup、PlugInEthernet、FoldTowel |
| 次数 | 每任务 5 次 A/B（MOSAIC off/on） |

### 6.6 消融

1. 地图 on/off。
2. 主动观测 on/off；head-only vs free-arm vs probe。
3. 子图检索 vs R12 单目标检索。
4. 地图条件目标 vs 纯 CHUNK-SERVO。
5. TCM 鲁棒门限 vs 手调/标称。
6. 描述子：经典 vs 同 checkpoint encoder（C3）。
7. 地图修正频率：每 chunk vs 每 2 chunk vs 每 3 chunk。
8. 编辑检测 on/off。
9. 谓词验证 on/off。
10. map-as-prompt on/off（若启用）。

### 6.7 门 M0–M8

| 门 | 问题 | 通过标准 | 失败动作 |
|---|---|---|---|
| M0 | 相机/手眼标定是否够用？ | 头双目重投影 ≤5 px；腕部手眼 ≤5 px；0.5 m 深度误差 ≤20 mm | 地图只用头双目；腕部只做 2D 粗对齐 |
| M1 | 地图关联/位姿是否可信？ | 关联 F1 ≥0.9（干净）/≥0.8（clutter）；位姿误差 ≤2 cm/5°；槽位占用 ≥90% | 降级为任务级固定槽位；不启用地图修正 |
| M2 | 地图条件伺服是否收敛？ | 目标移动 ±5 cm 后可更新；仿真 +10pp；2 s 内收敛 | 只保留目标检索，不做地图修正 |
| M3 | 主动观测是否有用？ | 熵下降；恢复率 ≥70%；无任务回归 | 关主动观测，只做被动多视角 |
| M4 | 长程记忆是否涨点？ | 5 个长任务 +10pp；步骤分 +5；遗忘错误下降 | 只做单步任务，不做跨 chunk 记忆 |
| M5 | 真机单任务是否涨点？ | 3/5 任务 +10pp；FoldTowel 不回归 >5pp | 不提交 MOSAIC 版本 |
| M6 | 32 任务干跑是否稳定？ | N 端口隔离、reset 干净、内存不涨、p99 ≤150 ms | 回退 CHUNK-SERVO 基线 |
| M7 | 消融是否支持因果？ | 地图/主动/子图/TCM 各自有正贡献 | 保留有效部分，砍无效部分 |
| M8 | 孪生标定是否可迁移？ | 扰动孪生下鲁棒门限优于标称；与真机排序一致 | 只用手调保守门限 |

所有门先在离线回放和单任务不计分通道上过；没有过门，不烧正式提交。

## 7. 竞赛策略

### 7.1 任务分档

| 档 | 任务 | 地图用在哪 | 伺服 |
|---|---|---|---|
| **M：地图/记忆优先** | ToolboxStorage、StoreRacket、SpellRobot、PackPhone、OrganizeTools、StoreEarphones、OrganizeStationery、OpenPillBottle、ArrangePlates、OrganizePencilCase、StackCups、PackDoll、RemovePinnedNote | 槽位占用、已放置物体、子目标进度、长程记忆 | 接触段用 R12 |
| **C：接触优先** | HangCup、PlugInEthernet、ZipUp、Unlock、StackBowls、DisconnectEthernet、PlugCharger、ArrangeTestTubes、PaperCupStacking、SyringeWaterTransfer | 目标物/受器相对位姿、插入轴、接触谓词 | 主力 |
| **D：变形/语义** | FoldTowel、PackBag、FruitSorting、ColorArrangement、PlacePhotoFrame、OrganizeBookshelf、PickOutBatteries、ConveyorSorting、FruitCollection | 粗状态/干扰物/背景关系 | 不启用精确地图修正 |

### 7.2 优先级

```text
priority_t = q_t^state · Δ_t^map / cost_t^map
```

- `q_t^state`：失败发生在状态/记忆/观测层的比例；先验由任务语义给，单任务通道后更新。
- `Δ_t^map`：地图条件增益；先用仿真/离线估计，再用单任务 A/B 更新。
- `cost_t^map`：目标库/标定/调参成本。

先做 M 档中 `q_t^state` 最高、`cost_t^map` 最低的 3–5 个任务；不要一次铺 13 个。

### 7.3 单任务通道协议

1. 选 5 个代表任务：ToolboxStorage（长程记忆）、PackBag（变形+容器）、HangCup（挂）、PlugInEthernet（插入）、FoldTowel（变形防回归）。
2. 每任务 5 次 A/B：MOSAIC off/on；同一初始条件；记录成功、步骤分、耗时、p99、主动观测次数、恢复次数。
3. 通过：≥3/5 任务 +10pp；FoldTowel 不回归 >5pp。
4. 再扫主动观测预算 `B ∈ {0,1,3}`、地图修正频率 `{1,2,3} chunk`、`w_map ∈ {0.3,0.5,0.7}`。
5. 最后才跑 32×10 正式评测。

### 7.4 预算与时间表

| 阶段 | 时间 | 交付 | 退出条件 |
|---|---:|---|---|
| P0 接口/基线 | 1 周 | WLA + API adapter + R12 基线 | 单任务通道 1 任务跑通 |
| P1 地图/标注 | 2 周 | OSM-WM、离线地图、子图库 | M0/M1 |
| P2 主动/孪生 | 2 周 | MAIN、TCM、扰动套件 | M3/M8 |
| P3 集成/单任务 | 2 周 | 地图条件目标、状态机、5 任务 A/B | M2/M5 |
| P4 全量干跑 | 1 周 | 32×10 干跑、N 端口、p99 | M6 |
| P5 提交 | 1 周 | 提交包、合规说明、回滚开关 | M7 + 全部门 |

算力：1×24 GB GPU（WLA 微调/单端口推理）；16–32 CPU 核（地图/检索/回放）；存储 1–2 TB 视频缓存，关键帧/ROI 可降到 <200 GB。

## 8. 风险与合规

### 8.1 单模型合规模式

| 模式 | 做法 | 风险 | 建议 |
|---|---|---|---|
| C1 离线标注 | 地图/谓词只用离线标注生成；线上只有 VLA | 最低 | 保守首选 |
| C2 确定性控制器 | 地图/关联/谓词/VOI 是几何/规则/控制律；VLA 唯一学习模型 | 低；需说明 | 主推 |
| C3 同 checkpoint 特征 | 描述子用 VLA 同 checkpoint encoder，不加载第二个模型 | 低–中；需说明 | 需要强描述子时用 |

禁止：加载第二个学习策略/残差网络/独立分割器/独立 VLM 做在线决策。离线可用 SAM/GroundingDINO 做标注质检，但不随提交部署。

### 8.2 风险表

| 风险 | 影响 | 缓解 |
|---|---|---|
| 地图关联错误 | 自信地追错物体/槽位 | 置信度门控；几何+描述子+角色三重代价；低置信度回退 VLA |
| 双目深度噪声 | 地图位姿漂移 | 地图只做厘米级；最后 3 cm 交给腕部伺服；主动观测补基线 |
| 透明/反光/变形 | 地图节点不稳定 | 只对刚体启用精确节点；变形任务只做粗状态；失败回退 |
| 主动观测扰动任务 | 破坏已完成子目标/超时 | 预算硬限；只用空闲臂/非接触相位；支撑臂不动 |
| 地图作为 VLA prompt 分布外 | VLA 忽略或误用 | 先只做控制器（C2）；prompt 需用演示地图微调后再启用（C3） |
| 单模型解释 | 被判定为第二个模型 | 地图/主动观测无学习权重；不用独立分割器；提交材料写清楚 |
| 孪生过拟合 | 门限在真机失效 | 只用真机标定集调阈值；鲁棒优化；不把 sim 成功率当真机预测 |
| 多端口并发 | 内存/CPU 争抢 | 每端口独立地图；共享只读演示库；CPU 预算隔离 |
| 人编辑太快 | 检测/恢复不及时 | 地图+本体双通道；检测即停；恢复预算；不声称 100% |
| 评测噪声 | +1–2pp 假阳性 | 配对 A/B、bootstrap、重复实验；320 trials SE≈2.4pp |
| 数据泄漏 | 离线指标虚高 | 按 session/物体/背景分组划分；相邻帧不跨 split；演示库 leave-one-session-out |
| `pivot` 语义不一致 | 主动观测/躯干转动被拒 | 先用 `example_env.py`/单任务通道验证；保留零 pivot 回退 |
| 提交次数限制 | 无法多次 A/B | 邮件确认；单任务通道先验证；一次提交则保守 |

## 9. 与历史轮次/候选的关系

### 9.1 保留 / 升级 / 剪枝

**保留**：

- FACT-VLA 的相位化 BC、CAC 柔顺执行、EGP 证据门控；
- GEO-RESIDUAL 的动作条件化残差、米制表面距离、编辑检测；
- CHUNK-SERVO 的 30 步规划 + 5 步伺服、DG-KEYFRAME 相对目标、孪生标定 RTT/增益；
- 官方 WLA 基座、33k 演示、官方 rubric、单任务通道。

**升级**：

- 观测层 → 状态层：相位/残差 → 对象节点 + 关系 + 谓词信念；
- 单目标检索 → 子图检索：目标-夹爪相对位姿 → 整个子目标场景图对齐；
- 被动多视角 → 主动交互：现有四路图 → 空闲臂/腕部/躯干/轻探查账；
- 孪生标定 → 地图观测模型标定：外参/增益/RTT → 深度噪声/遮挡/关联/人编辑分布；
- 控制器 → 记忆：5 步闭环 → 跨 chunk、跨子目标的工作记忆。

**剪枝**：

- 不做从零训 VLA/World Model；
- 不做完整 sim-to-real 策略训练；
- 不做第二个学习模型/残差策略/独立分割器；
- 不做在线 3DGS/NeRF/点云大配准；
- 不做 6D 物体位姿网络；
- 不做力/触觉闭环（API 没有）；
- 不做 32 个任务各一个策略；
- 不把预览榜单当难度表。

### 9.2 与历史候选的区别

| 候选 | 核心 | 与 MOSAIC 的关系 |
|---|---|---|
| **SPARC-GPR** | 离线点云 atlas + 在线 ICP 配准 + 容器系协同控制 | 重几何路线；地图主要解决任务坐标系漂移。MOSAIC 是轻状态路线，地图主要解决任务状态/记忆/观测；最后 3 cm 仍交给 CHUNK-SERVO。可组合，但不同时上线 |
| **WINGMAN** | 谓词任务图 + 主动多视角 + 证据门控 | 共享主动观测；WINGMAN 重点在任务图 DP/观察动作，MOSAIC 重点在地图作为 VLA/控制器共享工作记忆 + 孪生标定地图观测模型。可把 MOSAIC 的谓词信念作为 WINGMAN 任务图的输入 |
| **CHUNK-SERVO** | 30 步规划 + 5 步伺服 + DG-KEYFRAME | MOSAIC 的直接基线；MOSAIC 补“目标是谁/场景变没变/子目标完成没” |

## 11. 一句话押注

**用对象中心语义地图做跨 chunk 的工作记忆，用语言/视觉/本体证据维护谓词信念，用有预算的主动观测消除地图歧义，用演示子图对齐给 CHUNK-SERVO 正确的相对目标，用数字孪生只标定地图的噪声模型与门限——让最后 3 厘米走在正确的子目标上。**

**本轮最大风险：语义地图的关联/位姿误差会以“自信的错误”方式污染下游目标和谓词；如果 M1 的关联 F1 与位姿误差不过门，MOSAIC 必须整体回退到 CHUNK-SERVO，而不是带着错误地图继续跑。**
