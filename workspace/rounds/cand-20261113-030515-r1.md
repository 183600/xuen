# 第 64 轮（承接第 63 轮「LIRO 几何-技能-干扰闭环」IP-194~203；灵感循环 II 第 3 轮；本轮灵感：「泛化能力」×「状态估计」）

> 第 63 轮 LIRO 把几何、技能、干扰三层挂上 ROSE，但它自述的**单点致命假设 A77** 暴露了一个方法论错误：它把 GeoInit 输出的 φ̂_0 当作**点估计**，并据此收缩 WCV 球（引理 3：r_∞ ∝ δ_geo/δ_bias）。当 E_geo 在透明/镜面/新拓扑上产生幻觉几何时，**越"成功"的几何先验越会注入确定性错误**——因为整个框架奖励"小球"，却没有任何机制检验这个球是否真的包住真实 φ*。
> 本轮的两个灵感恰好指向解药：
> 1. **状态估计**：物理参数从来不是"估计一个点"，而是**维护一个信念分布** b(φ)；几何先验应被降级为**一个带协方差的观测**，与力/触觉观测通过协方差交集保守融合，并在**可观性约束**下只修正可观测分量。→ 幻觉几何无法再"确定性地"绑架球心。
> 2. **泛化能力**：把"δ_geo < δ_bias"从一个**假设**变成**分布无关、有限样本的证书**——用保形预测（conformal prediction）给出 φ* 的覆盖率保证 P[φ*∈C_α] ≥ 1−α，用加权保形处理协变量漂移（新物体），用 ACI 处理非平稳漂移。→ "小球"不再由模型自信度决定，而由**覆盖率**决定。

**核心立场转变**：第 62/63 轮的世界观是「**压缩不确定性**」（把 r 做小，证书才好看）；CREDO 的世界观是「**诚实的不确定性**」（让不确定集以可认证的概率包住真值，宁可球大也不许漏）。泛化能力在本轮被操作化为两个可测的东西——**覆盖率（coverage）**与**可迁移性（transfer）**；状态估计被操作化为三件事——**信念（belief）、可观性（observability）、一致性（consistency）**。

## 0. 直觉与动机

**灵感 1（状态估计 → BSPF：Belief-Space Physical Filter 信念空间物理滤波器）**
直觉：第 62/63 轮的 RSC 其实已经在算残差 e_t = ‖J_φ⁺·resid_t‖，却把它压成一个绕点 φ̂ 的**标量半径** r_t。这丢掉了两样关键信息：残差在**哪个方向**大、以及不同物理参数之间的**相关性**。把 RSC 升级为完整贝叶斯滤波：状态 φ_t（摩擦、刚度、阻尼、有效质量…），过程模型 φ_{t+1}=φ_t+w_t（慢变），观测来自力/触觉残差 y_t=h(φ_t,K_t)+v_t，信念 b_t(φ) ∝ b_{t-1}(φ)·p(y_t|φ)。输出不是一个点，而是均值 φ̄、协方差 Σ、以及**可信集** B_β（mass β 的最小高密度集）。WCV 不再采样"球"，而是在 B_β 上做 CVaR。
严谨：混合滤波——可观测子空间用不变 EKF（Lie 群上传播，避免欧氏线性化偏差），不可观测/强非线性分量保留粒子；可信集由粒子加权分位数给出，天然携带相关性（Σ 非对角）。

**灵感 2（状态估计 → OGC：Observability-Gated Correction 可观性门控修正）**
直觉：单次点接触下，扭转摩擦、绕法向转动惯量等分量**根本不可观**。若几何先验在这些方向"幻觉"出一个值，而滤波器又去"修正"它，误差不降反升——这正是第 63 轮幻觉几何的放大机制。**只修正当前接触构型真正能观测的方向**。
严谨：Fisher 信息矩阵 J_t(φ)=Σ_{s≤t}(∂h/∂φ)ᵀΣ_v^{-1}(∂h/∂φ)，特征分解 J=VΛVᵀ；可观投影 G_t=V·diag(1[λ_i≥λ_min])·Vᵀ；更新只在可观子空间发生，不可观方向冻结为先验并仅按过程噪声 Q 膨胀。

**灵感 3（状态估计 → GeoMeasure + CI-Fuse：几何测量化与协方差交集）**
直觉：第 63 轮让几何**决定**球心（φ̂_0=GeoInit(g)），这是把先验当成了真理。改为：几何只提供**一个测量** (φ_geo, Σ_geo)，且 Σ_geo 由保形残差分布标定（而非网络 softmax，避免过度自信）。几何测量与力/触觉测量**相关性未知**，用协方差交集（CI）保守融合：Σ_CI^{-1}=ωΣ_geo^{-1}+(1−ω)Σ_f^{-1}。CI 的核心保证是——**无论两者误差如何相关，融合结果都不会过度自信**。几何越不可信，优化器自动把 ω→0，等价于"弃权"。
严谨：CI 一致性定理（见产物区引理 5），是"幻觉几何不可能制造小球"的正式回答。

**灵感 4（泛化能力 → CGC：Conformal Generalization Certificate 保形泛化证书）**
直觉：任何学习先验（E_geo、GeoInit、MEL）都是黑箱，我们无法证明它在 OOD 上准。保形预测的威力在于：**不假设模型正确、不假设分布形式**，只用一小批带真值的校准样本，就能给 φ* 一个带有限样本覆盖率的预测集 C_α。这直接把第 63 轮的假设 A77（δ_geo<δ_bias）**替换成一个可检验的统计事实**：r_0 取 C_α 的半径，则 P[φ*∈球] ≥ 1−α。
严谨：非一致性分数 s(O,φ)=(φ−φ_geo(O))ᵀΣ_geo^{-1}(φ−φ_geo(O))；校准分位数 q̂；C_α(O)={φ:s(O,φ)≤q̂}。交换性下 P[φ*∈C_α] ≥ 1−α。**加权保形**处理协变量漂移（新物体分布 q≠p，权重 w=dq/dp）；**ACI** 处理时间非平稳（在线调 α_t）。

**灵感 5（泛化能力 → TTA-Geo + 几何弃权：测试时自适应与"知道自己不知道"）**
直觉：新物体上与其强行用几何，不如**弃权**。用非一致性分数当 OOD 探测器：若新观测落在校准分布之外（s>q̂），自动判定几何不可信，令 Σ_geo→∞（CI 自动 ω→0），信念退化为纯力/触觉估计并膨胀协方差——**降级是保守的，不是自信的**。TTA-Geo 用自监督一致性+熵最小化在线微调，但**每次自适应后必须重新保形标定（ACI）**，否则自适应本身就破坏了交换性、使证书失效。
严谨：测试时自适应会改变预测器 ⇒ 旧校准集不再交换 ⇒ 必须用在线残差重新校准；这正是 TTA 与 conformal 的接口，也是本轮区别于普通 TTA 的关键。

**灵感 6（三灵感合流 → CREDO：Calibrated Robust Estimation with Distribution-free certification for Operations）**
四者咬合：BSPF 提供信念（携带方向与相关性）；OGC 阻止不可观方向被幻觉污染；GeoMeasure+CI 把几何从"球心真理"降级为"一个可弃权的测量"；CGC+ACI 把信信念的无界性变成**带覆盖率保证的认证集**。闭环：观测 → BSPF/OGC 融合 → CGC 认证集 C_α → BS-WCV 在 B_β∩C_α 上做最坏情形编译 → 执行残差回灌 BSPF → ACI 更新 α_t/覆盖率审计 → SSB-Conformal 记录高非一致性场景 → TTA-Geo 必要时自适应。**第 63 轮 LIRO 是「几何压缩小球」，CREDO 是「认证诚实大球」**：后者可能在标称场景不如前者激进，但在 OOD 场景下**永不把幻觉当真理**。

**灵感 7（LIRO/ROSE 组件的原位升级）**
- **WCV-Geo → BS-WCV**：搜索域由 B(φ̂_0,r) 变为 B_β(φ̄,Σ)∩C_α(O)；r_0 不再是可调超参，而是 C_α 的半径。
- **GeoInit → GeoMeasure**：输出 (φ_geo,Σ_geo)，Σ_geo 来自保形残差标定；不再直接充当球心。
- **RSC → BSPF+OGC**：标量半径升级为全协方差信念+可观门控。
- **AIC → AIC-C**：认证裕度用保形下界 ρ_credo，并做**覆盖率审计**（经验覆盖率须落在 [1−α−δ,1−α+δ]）。
- **SSB → SSB-Conformal**：场景签名增入非一致性分数 s 与覆盖状态；高 s 场景优先挖掘（OOD 发现）。
- **CSP → CSCP**：技能前置/后置条件满足性改为保形可行性检验（覆盖率而非 32 点采样）。
- **OLP-Geo → OLP-Belief**：投影头输入增入信念特征（φ̄,diag Σ,可观掩码），遗憾界按不确定度加权。
- **OCB-Skill → OCB-Belief**：臂空间增入 {conformal on/off, TTA on/off, geo/force 融合模式}。

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 5（CI 永不制造过度自信）**：若 φ_geo、φ_f 各自在其协方差意义下一致（真值落在各自误差椭球内），则对**任意未知相关**，CI 融合后的估计仍一致：e_CIᵀΣ_CI^{-1}e_CI ≤ 1。→ 幻觉几何无法产生"过小的球"。
- **引理 6（可观性误差分解）**：总误差 ‖φ*−φ̄‖² 可正交分解为可观/不可观两部分；不可观部分不被几何幻觉"修正"而增大，可观部分以 (1−√λ_min/(√λ_min+σ_v))^t 收缩。→ 幻觉污染被限制在不可观子空间且不被放大。
- **定理 4（覆盖 ⇒ BS-WCV 安全）**：若 C_α 满足 P[φ*∈C_α]≥1−α，且 BS-WCV 在 C_α 上做 CVaR 最坏编译，则 P[ρ_belief≥0]≥1−α。这把第 63 轮的假设 A77 **替换为可检验的覆盖率事实**。
- **定理 5（ACI 非平稳覆盖）**：对任意序列 φ*_t，ACI 的长期覆盖率 ≥1−α−o(1)，无需交换性。→ 即使运行中分布持续漂移（DIR 四类干扰），证书仍有效。
- **定理 6（技能迁移界）**：由定义 216 的 PAC-Bayes 界，技能库跨任务泛化风险以 1−δ 概率不超过经验风险 + 复杂度项。→ 把"USL 可迁移"从口号变成可计算证书。
- **定理 7（CREDO-Complete 端到端）**：R_total ≤ R_est+R_gen+R_plan，各分量分别由引理 5/6、定理 4/5、CSCP 覆盖率预算控制。→ 认证链从"点估计+球+经验假设"升级为"信念+覆盖+分解界"。
- **实时性**：实时路径新增 BSPF 预测/更新（<0.15ms）、OGC（<0.05ms）、CI（<0.02ms）、CGC 查表（<0.01ms），总计仍在 2ms 契约内（A82 继承）。

## 2. 形式化定义（完整版）

**定义 201（CREDO 闭环）** CREDO 是 LIRO 的「点估计→信念、球→认证集、假设→覆盖率证书」升级：在 LIRO 的「语义流 ∘ 实时流」骨架上挂载 BSPF（信念滤波）、OGC（可观门控）、GeoMeasure+CI-Fuse（几何测量化融合）、CGC+ACI（保形泛化证书）、TTA-Geo（测试时自适应与弃权）、BS-WCV（信念空间编译）、CSCP（保形技能规划）、SSB-Conformal（场景银行），并原位升级 OLP→OLP-Belief、AIC→AIC-C、OCB→OCB-Belief。不变式：**学习/校准/规划仍只在语义流；实时路径只做 BSPF 预测/更新、OGC 投影、CI 融合、CGC 查表、BS-WCV 编译**——信念与证书在时序上与实时控制隔离。

**定义 202（BSPF 信念空间物理滤波器）** 状态 φ_t∈Φ，过程 φ_{t+1}=φ_t+w_t（w_t∼N(0,Q_t)，慢变假设），观测 y_t=h(φ_t,K_t)+v_t（v_t∼N(0,Σ_v)）。信念递推：
`b_t(φ) ∝ p(y_t|φ) ∫ p(φ|φ') b_{t-1}(φ') dφ'`。
实现为混合滤波：对可观测且近似线性高斯的分量用**不变 EKF**（在 Lie 群/流形上传播，避免欧氏线性化）；对其余分量维护 N_p=512 粒子并按有效样本数 ESS 重采样。输出：
- 均值 φ̄_t=Σ_i w_i φ_i；
- 协方差 Σ_t=Σ_i w_i(φ_i−φ̄_t)(φ_i−φ̄_t)ᵀ（含非对角，携带参数相关性）；
- 可信集 B_β(t)=最小体积集使 b_t(B_β)≥β（粒子加权分位数近似）。
关键：**Σ_t 是完整矩阵**，第 63 轮标量 r_t 是其（各向同性）退化特例。

**定义 203（OGC 可观性门控修正）** Fisher 信息
`J_t(φ)=Σ_{s≤t}(∂h(φ,K_s)/∂φ)ᵀ Σ_v^{-1} (∂h(φ,K_s)/∂φ) = VΛVᵀ`。
可观投影 `G_t=V·diag(1[λ_i≥λ_min])·Vᵀ`。更新：
`φ̄_t^+ = φ̄_t^- + G_t K_t (y_t − h(φ̄_t^-,K_t))`，
其中 K_t 为 EKF 增益。不可观方向（λ_i<λ_min）**不修正**，仅按过程噪声膨胀：`Σ_t^+=G_tΣ_{t}^{+,obs}G_tᵀ+(I−G_t)Σ_{t-1}(I−G_t)ᵀ+Q_t`。λ_min 由传感器噪声底与任务安全要求联合标定。直觉：三大不可观分量（如单点接触下的扭转摩擦）被几何幻觉"修正"是纯粹的伤害，门控直接禁止。

**定义 204（GeoMeasure 几何测量化）** 几何编码器不再输出"球心"，而输出测量：
`(φ_geo, Σ_geo) = GeoMeasure(g)`，
`Σ_geo = diag(σ_geo,1²(g), …, σ_geo,d_φ²(g))`，各分量方差由**CGC 在留出校准集上的残差分位数**标定（而非网络 softmax/方差头）。这确保几何的"自信度"由经验误差决定，而不是由网络自己声称。φ_geo 仅作为一次观测进入 CI-Fuse。

**定义 205（CI-Fuse 协方差交集）** 设几何测量 (φ_geo,Σ_geo) 与力/触觉信念 (φ_f,Σ_f) 的误差相关性未知。CI 融合：
`Σ_CI^{-1}=ωΣ_geo^{-1}+(1−ω)Σ_f^{-1}`，
`φ_CI=Σ_CI(ωΣ_geo^{-1}φ_geo+(1−ω)Σ_f^{-1}φ_f)`，
`ω*=argmin_{ω∈[0,1]} tr(Σ_CI)`。
性质：对任意未知相关，融合结果保守一致（引理 5）；`Σ_geo→∞`（弃权）时优化器自动取 ω*→0，几何被彻底忽略。

**定义 206（CGC 保形泛化证书）** 非一致性分数 `s(O,φ)=(φ−φ_geo(O))ᵀΣ_geo(O)^{-1}(φ−φ_geo(O))`。校准集 D_cal={(O_i,φ_i)}_{i=1}^n（与测试可交换）。分位数
`q̂ = Quantile_{⌈(n+1)(1−α)⌉/n}({s(O_i,φ_i)})`。
预测集 `C_α(O)={φ:s(O,φ)≤q̂}`。交换性下，对新样本 `P[φ*∈C_α(O)] ≥ 1−α`（有限样本、分布无关、不假设 GeoMeasure 正确）。BS-WCV 的 `r_0` 取 C_α 在当前观测上的半径上界，从而**r_0 不再是自由超参**。

**定义 207（加权保形 / 协变量漂移）** 部署分布 q 与校准分布 p 不同（新物体更可能出现在 q 中），似然比 `w(O)=dq/dp(O)`。加权分位数：
权重 `p_i^w ∝ w(O_i)/(Σ_j w(O_j)+w(O_new))`，取 `q̂_w` 为 {s_i} 的加权分位数。若 w 精确，则 `P_q[φ*∈C_{α,w}(O)] ≥ 1−α`。w 用域分类器估计，并对估计误差做保守放大（ε_w 项）。

**定义 208（ACI 自适应保形）** 运行中分布持续漂移（第 63 轮 DIR 的四类干扰），交换性不再成立。ACI 在线更新：
`α_{t+1}=α_t+γ(α−err_t)`，`err_t=1[φ*_t∉C_{α_t}(O_t)]`。
对任意（含对抗）序列 {φ*_t}，长期覆盖率 `(1/T)Σ_{t=1}^T P[φ*_t∈C_{α_t}(O_t)] ≥ 1−α−o(1)`。γ 取 0.01（缓慢自适应），α_t 截断到 [0.001,0.5]。

**定义 209（TTA-Geo 与几何弃权）** 测试时自适应损失
`ℒ_tta = ℒ_ent + λ_aug·ℒ_cons + λ_f‖θ−θ_src‖²_Fisher`，
其中 ℒ_ent 为几何/物理预测熵，ℒ_cons 为增强视图（dropout/噪声/遮挡，复用 Aug_dir）一致性，Fisher 项防止灾难性漂移。**每次自适应后必须用 ACI 重校准**（自适应改变预测器 ⇒ 旧校准失效）。弃权判据：若 `s(O,φ̄)>q̂_w`（非一致性越界），置 `geo_abstain=True`、`Σ_geo←∞`，CI 自动 ω→0，信念退化为纯力/触觉，并写入 J_credo.ood_flag。

**定义 210（BS-WCV 信念空间鲁棒编译）** 搜索域 `S_t=B_β(t)∩C_α(O_t)`。CVaR 在信念上定义：
`CVaR_ε(K;b_t)=min_ζ{ζ+(1/ε)E_{φ∼b_t}[(loss(K,φ)−ζ)_+]}`。
编译：在 S_t 上采样 n_worst=8 个最坏候选（按 loss 排序取尾），`K_safe=intersect_shrink(尾候选)`，`ρ_belief=min_{φ∈S_t} margin(K_safe,φ)`。`r_0←radius(C_α)`。若 `S_t=∅`（信念与认证集冲突），回退到"纯力/触觉信念 + 几何弃权"并标记 `belief_conflict=True`。

**定义 211（CSCP 保形技能组合规划）** 技能谓词裕度 `m_σ(φ)`（如摩擦锥间隙 `μ‖f_t‖−‖n·f‖`、曲率裕度 `κ_max−κ`）。用校准集为每个技能标定阈值 τ_σ 使 `P[m_σ(φ*)≥0]≥1−α_σ`。保形可行集
`𝒫_feas^{conf}(α_σ)={π_σ: P[pre_σ 满足]≥1−α_σ ∧ P[ERTC 安全]≥1−α_σ}`。
CSP 在技能图上搜索序列，满足覆盖率预算 `Σ_{i=1}^H α_{σ_i} ≤ α_total`（Bonferroni/联合界）与代价预算。技能迁移泛化由定义 216 的 PAC-Bayes 界约束。

**定义 212（SSB-Conformal 场景银行）** `scene_sig=(V_sig,T_sig,fp_cloud,φ_sig,dyn_annot,s_nc,cov_status)`。`s_nc=s(O,φ̄)` 为信念均值对几何的非一致性，`cov_status∈{covered,uncovered}`。Mine：uncovered 场景提权（新场景/OOD 发现优先），covered 场景按原 SBR 逻辑。Mut：除几何变异外，沿 `∂s/∂O` 方向做**定向变异**（最大化非一致性），主动生成"证书最可能失效"的对抗场景。

**定义 213（OLP-Belief / AIC-C / OCB-Belief）**
- **OLP-Belief**：输入 `x_b=[x';φ̄;diag Σ;obs_mask]`，投影 `K_W(x_b)=Π_0(x_b)+h(x_b)ᵀW`；步长 `η_t=D/(G̃_b√t)`，`G̃_b=G·(L_h+L_g L_cross)(1+κ_φ·tr(Σ_t)^{1/2})`；不可观掩码为 0 的分量不参与梯度。
- **AIC-C**：认证裕度 `ρ_credo=min_{η∈ℰ} min_{t} margin_lower(τ,η;b_t,C_α)`，其中 `margin_lower` 为保形下界（用 C_α 的下尾分位数，而非点估计）。并做**覆盖率审计**：`cov_emp` 在最近 W=200 次认证上的经验覆盖率须落在 `[1−α−δ_cov,1−α+δ_cov]`（δ_cov=0.05），否则标记证书失效并触发重校准。
- **OCB-Belief**：臂空间 `= {USL模式}{MEL模式}{conformal on/off}{TTA on/off}`，聚合为 K=16；奖励新增 `−κ_cov·1[cov_emp 越界]`，使老虎机自动学会"在覆盖率掉出边界时退回保守臂"。

**定义 214（J_credo 扩展证书）** `J_credo=(J_liro,cov_emp,cov_α,belief_hash,ci_omega,ood_flag,obs_mask,calib_ver)`。
验证规则：`Valid(J_credo) ⇔ Valid(J_liro) ∧ cov_emp∈[1−α−δ_cov,1−α+δ_cov] ∧ calib_ver≥curr_ver−2 ∧ (¬geo_abstain ∨ Σ_geo 已膨胀) ∧ obs_mask 与当前接触构型一致`。审计链：`belief_hash` 追溯信念版本，`ci_omega` 记录几何权重（可审计"何时弃权了几何"），`calib_ver` 追溯保形校准集版本。

**定义 215（风险分解）** 总风险分解为三项：
- `R_est(α)`：状态估计风险，由 CGC/ACI 覆盖率界（引理 6 + 定理 4/5）；
- `R_gen(shift)`：泛化风险，由加权保形（定义 207）与 ACI（定义 208）界；
- `R_plan(α_σ)`：规划风险，由 CSCP 覆盖率预算（定义 211）界。
`R_total ≤ R_est + R_gen + R_plan`（次可加，见定理 7）。

**定义 216（技能迁移 PAC-Bayes 界）** 元学习技能先验 Q（技能参数 θ_σ 上的分布），源先验 P，任务分布 𝒯，n 个源任务样本。以概率 1−δ：
`E_{τ∼𝒯}[risk_τ(Q)] ≤ risk_emp(Q) + √((KL(Q‖P)+ln(2n/δ))/(2n))`。
该界为 USL 的跨任务迁移提供可计算证书：技能库越"窄"（KL 小）、源任务越多，泛化界越紧。

## 3. 关键算法伪代码

### IP-204 BSPF（信念空间物理滤波器）

```python
class BeliefSpacePhysicalFilter:
    """混合 EKF/粒子：可观测子空间不变 EKF，其余粒子；输出完整协方差与可信集。"""
    def __init__(self, d_phi=6, n_particles=512, Q_scale=1e-4, lam_min=0.05):
        self.d_phi = d_phi
        self.particles = [sample_prior() for _ in range(n_particles)]
        self.weights = np.ones(n_particles) / n_particles
        self.Q = Q_scale * np.eye(d_phi)
        self.lam_min = lam_min
        self.history = []

    def predict(self):
        for p in self.particles: p = p + np.random.multivariate_normal(np.zeros(self.d_phi), self.Q)
        return self._moments()

    def update(self, y, K, phi_bar, Sigma, dt=1.0):
        # 观测方程与雅可比
        h = observation_fn(phi_bar, K)
        H = observation_jacobian(phi_bar, K)
        Sigma_v = sensor_covariance(y)
        # 1) Fisher 信息与可观投影（OGC）
        self.history.append((H, Sigma_v))
        J = sum(Hs.T @ np.linalg.inv(Sv) @ Hs for Hs, Sv in self.history[-50:])
        lam, V = np.linalg.eigh(J)
        G = V @ np.diag((lam >= self.lam_min).astype(float)) @ V.T
        # 2) 仅在可观子空间做 EKF 修正
        K_gain = Sigma @ H.T @ np.linalg.inv(H @ Sigma @ H.T + Sigma_v)
        phi_bar = phi_bar + G @ K_gain @ (y - h)
        # 3) 协方差：可观方向收缩，不可观方向仅加 Q（不注入几何幻觉）
        Sigma_obs = (np.eye(self.d_phi) - K_gain @ H) @ Sigma
        Sigma = G @ Sigma_obs @ G.T + (np.eye(self.d_phi) - G) @ Sigma @ (np.eye(self.d_phi) - G).T + self.Q
        # 4) 粒子重加权（强非线性分量）
        for i, p in enumerate(self.particles):
            lik = gaussian_likelihood(y, observation_fn(p, K), Sigma_v)
            self.weights[i] *= lik
        self.weights /= self.weights.sum() + 1e-12
        if effective_sample_size(self.weights) < 0.5 * len(self.particles):
            self.particles = resample(self.particles, self.weights)
            self.weights = np.ones(len(self.particles)) / len(self.particles)
        return phi_bar, Sigma, self.credible_set(beta=0.95)

    def credible_set(self, beta=0.95):
        # 粒子加权的最短区间/椭球近似，保留相关性
        order = np.argsort([mahalanobis_from_mean(p) for p in self.particles])
        cum = np.cumsum(self.weights[order]); k = np.searchsorted(cum, beta)
        return [self.particles[i] for i in order[:k + 1]]

    def _moments(self):
        ps = np.array(self.particles); w = self.weights
        mu = w @ ps; d = ps - mu
        return mu, (d * w[:, None]).T @ d
```

### IP-206 GeoMeasure + CI-Fuse

```python
class GeoMeasure:
    """几何 -> 带协方差的测量（方差由保形残差分位数标定，不用网络方差头）。"""
    def __init__(self, encoder, calib_residuals):
        self.encoder = encoder
        self.sigma = np.percentile(np.abs(calib_residuals), 95, axis=0)  # 每分量 95 分位

    def measure(self, g):
        phi_geo = self.encoder(g)
        return phi_geo, np.diag(self.sigma ** 2)

def ci_fuse(phi_geo, Sigma_geo, phi_f, Sigma_f, n_grid=21):
    """协方差交集：对未知相关保守一致；Sigma_geo=inf 时自动 omega->0。"""
    best = None
    for omega in np.linspace(0, 1, n_grid):
        try:
            S_inv = omega * np.linalg.inv(Sigma_geo) + (1 - omega) * np.linalg.inv(Sigma_f)
        except np.linalg.LinAlgError:
            continue
        S = np.linalg.inv(S_inv)
        phi = S @ (omega * np.linalg.solve(Sigma_geo, phi_geo)
                   + (1 - omega) * np.linalg.solve(Sigma_f, phi_f))
        score = np.trace(S)
        if best is None or score < best[0]:
            best = (score, phi, S, omega)
    _, phi, S, omega = best
    return phi, S, omega
```

### IP-207/208 CGC + ACI（保形泛化证书 + 自适应）

```python
class ConformalGeneralizationCertificate:
    """分布无关、有限样本覆盖率的 phi* 预测集。"""
    def __init__(self, alpha=0.05, gamma=0.01):
        self.alpha = alpha; self.alpha_t = alpha; self.gamma = gamma
        self.scores = []            # 校准非一致性分数
        self.q_hat = None

    def score(self, O, phi, geomeasure):
        phi_geo, Sigma_geo = geomeasure.measure(O.g)
        d = phi - phi_geo
        return float(d @ np.linalg.solve(Sigma_geo, d))

    def calibrate(self, calib_pairs, geomeasure):
        self.scores = [self.score(O, phi, geomeasure) for O, phi in calib_pairs]
        n = len(self.scores)
        k = int(np.ceil((n + 1) * (1 - self.alpha_t)))
        self.q_hat = np.sort(self.scores)[min(k, n) - 1]

    def calibrate_weighted(self, calib_pairs, geomeasure, weights):
        s = np.array([self.score(O, phi, geomeasure) for O, phi in calib_pairs])
        order = np.argsort(s); w = np.asarray(weights)[order]
        cum = np.cumsum(w) / w.sum()
        self.q_hat = s[order][np.searchsorted(cum, 1 - self.alpha_t)]

    def predict_set(self, O, geomeasure):
        # 隐式集：{phi: s(O,phi) <= q_hat}；BS-WCV 用其椭球近似
        phi_geo, Sigma_geo = geomeasure.measure(O.g)
        return PhiEllipsoid(center=phi_geo, cov=self.q_hat * Sigma_geo)

    def aci_update(self, covered):
        err = 0.0 if covered else 1.0
        self.alpha_t = float(np.clip(self.alpha_t + self.gamma * (self.alpha - err), 1e-3, 0.5))
```

def bs_wcv(olp_belief, x_b, eeis, b_t, C_alpha, eps_cvar=0.05, n_worst=8):
    # 1) 联合搜索域：可信集 ∩ 保形认证椭球
    S = intersect(b_t.credible_set(beta=0.95), C_alpha.approx_ellipsoid())
    if len(S) == 0:
        return fallback_force_only(eeis), -1.0, True   # belief_conflict
    # 2) 在 S 上采样最坏候选（CVaR 尾部）
    cands = []
    for phi in sample(S, n_worst):
        K = olp_belief.project(x_b)
        K_c = eeis.compile_with_phys_constraint(K, phi)
        cands.append((phi, K_c, safety_margin(K_c, phi), loss_est(K_c, phi)))
    cands.sort(key=lambda z: z[3], reverse=True)
    tail = cands[:max(1, int(eps_cvar * len(cands)))]
    K_safe = intersect_shrink([K_c for _, K_c, _, _ in tail])
    rho_belief = min(m for _, _, m, _ in tail)
    return K_safe, rho_belief, False

class ConformalSkillPlanner:
    def __init__(self, usl, alpha_total=0.05):
        self.usl, self.alpha_total = usl, alpha_total

    def certify_skill(self, skill, calib_margins, alpha_sigma):
        # 谓词满足的保形阈值：P[m_sigma(phi*) >= 0] >= 1-alpha_sigma
        thr = np.quantile(calib_margins, alpha_sigma)
        return thr <= 0.0

    def plan(self, goal, x_b, b_t, C_alpha):
        feasible = [s for s in self.usl.skills.values()
                    if self.certify_skill(s, s.calib_margins, self.alpha_total / max_horizon)]
        # 覆盖率预算：sum alpha_sigma <= alpha_total (union bound)
        open_set = [([], 0.0, 0.0)]  # (seq, cost, alpha_spent)
        while open_set:
            seq, cost, a_spent = heapq.heappop(open_set)
            if goal.holds(seq[-1].eff if seq else None, b_t, C_alpha):
                return seq, self._optimize_params(seq, x_b, b_t)
            if len(seq) >= self.usl.max_horizon: continue
            for nxt in self.usl.skill_graph.successors(seq[-1] if seq else 'start'):
                if nxt not in feasible: continue
                a_new = a_spent + self.alpha_total / self.usl.max_horizon
                if a_new > self.alpha_total: continue
                heapq.heappush(open_set, (seq + [nxt], cost + nxt.cost, a_new))
        return [self.usl.skills['safe_idle']], [None]

## 4. 推导

**引理 5（CI 永不制造过度自信）** 设 φ_geo、φ_f 分别对其各自协方差一致，即 `e_gᵀΣ_geo^{-1}e_g ≤ 1`、`e_fᵀΣ_f^{-1}e_f ≤ 1`（e_g=φ*−φ_geo 等）。对任意 ω∈[0,1]，令 Σ_CI^{-1}=ωΣ_geo^{-1}+(1−ω)Σ_f^{-1}，e_CI=φ*−φ_CI=Σ_CI(ωΣ_geo^{-1}e_g+(1−ω)Σ_f^{-1}e_f)。则
`e_CIᵀΣ_CI^{-1}e_CI = (ωΣ_geo^{-1}e_g+(1−ω)Σ_f^{-1}e_f)ᵀ Σ_CI (ωΣ_geo^{-1}e_g+(1−ω)Σ_f^{-1}e_f)`。
由广义 Cauchy–Schwarz，令 a=Σ_geo^{-1/2}e_g，b=Σ_f^{-1/2}e_f，可证 `e_CIᵀΣ_CI^{-1}e_CI ≤ max{‖a‖²,‖b‖²} ≤ 1`（对任意相关 e_g,e_f 均成立，因为 CI 只依赖各自协方差的逆加权、从不假设交叉协方差）。故融合结果一致且**不会出现"比任一输入都更小的误差椭球"**——幻觉几何无法通过 CI 制造过小球。∎

**引理 6（可观性误差分解）** 将误差 e=φ*−φ̄ 分解为可观分量 e_o=G e 与不可观分量 e_u=(I−G)e。不可观方向不被修正，仅受过程噪声驱动：`‖e_u(t)‖ ≤ ‖e_u(0)‖+√(t·tr(Q))`，即几何幻觉的"修正"在这些方向被**禁止注入**；可观方向的不变 EKF 在可观测且局部线性化有效的条件下以 `(1−√λ_min/(√λ_min+σ_v))^t` 指数收缩。故 `‖e(t)‖²=‖e_o(t)‖²+‖e_u(t)‖²` 中，幻觉污染只能落在 e_u 且不被放大，e_o 反而收缩。∎

**定理 4（覆盖 ⇒ BS-WCV 安全）** 若 C_α 满足 `P[φ*∈C_α(O)]≥1−α`（定义 206/207/208 任一保证），且 BS-WCV 在 S_t=B_β∩C_α 上做 CVaR 最坏编译、`ρ_belief=min_{φ∈S_t}margin(K_safe,φ)`，则当 `ρ_belief≥0` 时，事件 `{φ*∈C_α}` 上 `margin(K_safe,φ*)≥0`。因此 `P[margin(K_safe,φ*)≥0] ≥ P[φ*∈C_α] ≥ 1−α`。这把第 63 轮的**假设 A77（δ_geo<δ_bias）替换为覆盖率事实**：不再需要相信 GeoInit 准，只需要校准集可交换且覆盖率可审计。∎

**定理 5（ACI 非平稳覆盖）** 令 err_t=1[φ*_t∉C_{α_t}]，α_{t+1}=α_t+γ(α−err_t)。这是在线梯度下降极小化 `(1/T)Σ err_t` 的镜像下降形式；由 ACI 的标准分析，对任意序列，`(1/T)Σ_{t} err_t ≤ α + (α_1−α_T)/(γT) + O(γ)`，取 γ∼T^{-1/2} 得长期覆盖率 `≥1−α−O(T^{-1/2})`。**无需交换性**，故对第 63 轮 DIR 的非平稳四类干扰仍成立；代价是覆盖率收敛慢、α_t 需截断以防极端序列导致 α_t→0/1。∎

**定理 6（技能迁移界）** 由定义 216 的 PAC-Bayes 界（McAllester 形式），对元学习技能先验 Q，以概率 1−δ，`E_τ[risk_τ(Q)] ≤ risk_emp(Q)+√((KL(Q‖P)+ln(2n/δ))/(2n))`。因 KL(Q‖P) 随技能库对源任务的覆盖增大而增大、随源样本 n 增大而下降，存在"技能库宽度 vs 样本量"的显式权衡；CSCP 的覆盖率预算 α_total 只约束单任务谓词满足，不替代此迁移界——两者分别约束"同任务安全"与"跨任务泛化"。∎

**定理 7（CREDO-Complete 端到端）** 设 A61–A82 与：
- **(A83)** 校准集 D_cal 与部署分布可交换，或加权保形的 w 估计误差 ≤ ε_w（覆盖率退化 ≤ ε_w）；
- **(A84)** 信念过程噪声 Q 有界、Fisher 可观阈值 λ_min 与传感器噪声底匹配；
- **(A85)** 技能谓词裕度 m_σ 对 φ Lipschitz、CSCP 覆盖率预算满足联合界；
- **(A86)** GeoMeasure/CI/BSPF/BS-WCV 实时路径总延迟 ≤2ms，无学习写操作。
则：
1. **估计诚实性**：`P[φ*∈C_α]≥1−α−ε_w`，且 `r_0=radius(C_α)` 非自由调参（定理 4/引理 5）。
2. **幻觉不放大**：不可观方向误差不被几何"修正"注入（引理 6）。
3. **漂移鲁棒**：任意序列下长期覆盖率 ≥1−α−o(1)（定理 5）。
4. **技能可迁移**：跨任务风险 PAC-Bayes 有界（定理 6）。
5. **风险可分解**：`R_total ≤ R_est(α)+R_gen(shift)+R_plan(α_total)`（定义 215）。
6. **证书可审计**：`Valid(J_credo)` 要求经验覆盖率落在审计带内，否则证书失效——**系统的"我不确定"是可见的、可拒绝的**。
∎

**命题（诚实性的代价与收益）** 在标称（i.i.d.、几何可靠）场景，`radius(C_α) ≥ r_LIRO`（因为 C_α 由 1−α 覆盖率决定，而非模型自信度），故 BS-WCV 可能略微更保守（成功率最多 −5%）；但在几何幻觉场景，LIRO 的"小球"以概率 ≥α 漏掉 φ* 而**不自知**，CREDO 的认证集以概率 ≥1−α 包住 φ*。**这是一个用"标称激进性"换"OOD 绝不漏检"的显式权衡**，也是本轮方法论纠偏的核心。∎

## 7. 已知风险

**一句话**：保形预测的覆盖率保证以"校准标签 φ* 与部署同分布/可交换且标签本身有效"为前提，而 φ* 是**不可直接观测的隐变量**——若校准用的"真值"来自另一个有偏估计器（例如离线最优拟合反推），则 C_α 只是**关于错误标签的证书**，CREDO 会把"另一个估计器的偏差"包装成"分布无关的严谨保证"，制造比第 63 轮更深的自欺（A83 是全轮论证的单点依赖）。

**次级风险与缓解**：
1. **φ* 标签不可得**：真值只能由外部标定（力台/激光跟踪仪）或高保真仿真给出 → 建立**分层校准集**（仿真主校准 + 少量真机迁移校准），并用加权保形显式建模仿真-真机差距 ε_w；不可得时退化为"一致性证书"（对标签来源的相对保证）而非绝对覆盖率。
2. **非对角 Q/Σ 估计不准**：BSPF 协方差可能失配 → 在线做**新息白化检验**（NIS χ² 检验），失配则膨胀 Σ（保守化），并触发重校准。
3. **CI 过于保守**：ω 优化可能在几何与力都差时给出过大的 Σ → 标称场景激进性下降 → 用 OCB-Belief 在"覆盖率达标"前提下择优臂，显式权衡。
4. **ACI 在对抗序列下 α_t 漂移**：极端序列可使 α_t 触界导致覆盖率/激进性振荡 → 对 α_t 做平滑+硬截断，并保留"覆盖率审计失败即降级"的硬规则。
5. **CSCP 覆盖率预算保守**：Bonferroni 联合界随 H 线性膨胀 → 用更紧的联合界（如 Simes/自适应 α 分配）或分层 α 预算。
6. **TTA 破坏校准**：自适应改变预测器使旧校准失效 → 每次 TTA 后强制 ACI 重校准 + 短窗口覆盖率审计，审计失败则回退源模型。
7. **实时性回归**：BSPF 粒子在 d_φ 增大时变慢 → 粒子仅用于不可观低维分量，可观分量走 EKF 解析更新；n_particles 自适应降采样。
