# 第 1 轮 · 灵感种子：「因果推理」×「LoRA」

## 1. 直觉解释（先讲人话）

v23 的边端适应（FSVC）靠「K-shot 原型均值 + conformal 分位数刷新」。这套东西在**同分布**下很漂亮，但有两个没说破的软肋：

1. **原型是均值，均值会吞掉伪相关。** 新环境里光照、阴影、镜面反射变了，特征均值跟着漂，原型也漂；conformal 覆盖只承诺「平均意义上 1-α 覆盖」，它无法区分「我学到了人」还是「我学到了逆光下人的影子」。
2. **覆盖是相关性的，不是因果的。** 缺席证书 CAC 说「这里没人」，依据是「传感器没看到人」。但如果遮挡物同时导致「看不到人」和「人其实在」，缺席推理就被混杂了——覆盖率再高，也只是把一个错误的相关性拟合得更准。

LoRA 给了一个非常「工程可证书化」的抓手：适应被显式限制为低秩增量

  W = W0 + (α/r)·B·A,   B ∈ ℝ^{d×r}, A ∈ ℝ^{r×k}, r ≪ min(d,k)

于是「适应到底改了多少」有了**谱范数上界**，可以机械复核；这与 v23「能量/见证/差距全链可机械复核」的哲学天然同构。因果推理回答另一个问题：**这份低秩预算该花在哪些方向上**——只花在跨环境不变的因果机制上，而不是环境特有的伪相关上。

一句话直觉：**LoRA 把适应关进低秩笼子，因果把笼子对准不变机制。** 笼子让证书可算，瞄准让证书可信。

## 2. 严谨定义（再把话说死）

### 2.1 结构因果模型与环境
- 结构因果模型 `M = ⟨U, V, F, P(U)⟩`：`U` 为外生变量，`V = {E, C, Φ, Y, X}` 为内生变量；`F` 为结构方程；`P(U)` 为先验。
  - `E ∈ ℰ`：环境/域索引（光照、天气、场景）；
  - `C`：nuisance 混杂因子（如照度、镜面反射）；
  - `Φ`：骨干特征 φ(x)；
  - `Y`：语义/占据标签；
  - `X`：动作或观测干预变量。
- 干预分布：`P(Y | do(X=x), E=e)`，由 `M` 的 `do`-算子（删除指向 X 的入边、固定 X=x）给出。
- **因果不变性**：`∀e,e'∈ℰ: P(Y | do(X), E=e) = P(Y | do(X), E=e')`。满足该式的特征子空间记作 `Φ_c ⊆ Φ`，称为因果特征子空间。

### 2.2 因果特征与伪相关
- 定义不变性度量 `I(Φ_c) = sup_{e,e'} ‖P(Y|Φ_c,e) − P(Y|Φ_c,e')‖_TV`。
- `Φ_c` 是**因果充分**的，当且仅当 `Y ⟂ E | Φ_c`（环境条件独立），且 `Φ_c` 到 `Y` 的路径上不存在未阻断的后门。
- 伪相关方向 `Φ_s = Φ \ Φ_c`：`Y` 与 `E` 通过 `C` 产生相关，但 `do` 后相关消失。

### 2.3 LoRA 适配器与其容量
- 基座权重 `W0 ∈ ℝ^{d×k}`，适配增量 `ΔW = (α/r) B A`。
- **容量预算** `ρ(ΔW) = (α/r)·‖B‖₂·‖A‖₂`，约束 `ρ ≤ ρ_max`。
- 输出扰动界：若 `f_W` 关于权重是 `L_f`-Lipschitz，则 `‖f_W(x) − f_{W0}(x)‖ ≤ L_f·ρ·‖x‖`。
- **因果 LoRA**：把 `ΔW` 的列空间限制在 `Φ_c` 张成的子空间内，即 `col(Aᵀ) ⊆ span(Φ_c)`；记作 `ΔW_c`。等价于在低秩笼子里只允许「不变方向」转动。

### 2.4 因果缺席与反事实安全
- 边际缺席谓词（v23 的做法）：`AbsC_marg(r) ≜ P(occupied(r) | obs) ≤ κ_c`。
- **因果缺席谓词**：`AbsC_causal(r) ≜ P(occupied(r) | do(region visible), do(C ~ nominal)) ≤ κ_c`。
- 后门调整：`P(y | do(x)) = Σ_z P(y | x,z)·P(z)`；存在未观测混杂 `U` 时，用边际敏感性模型参数 `Γ ≥ 1` 给出部分识别区间 `[L(Γ), U(Γ)]`，仅当 `U(Γ) ≤ κ_c` 才签发缺席证书。

### 2.5 本轮核心猜想
- **H1（容量—漂移）**：在 `ρ ≤ ρ_max` 下，LoRA 适应引起的 conformal 分数漂移有界，覆盖下降 `≤ ε(ρ_max)`。
- **H2（不变性—OOD）**：若 `I(Φ_c) ≤ δ_inv`，则适应后的 OOD 风险 `R_ood ≤ R_id + O(δ_inv + ρ_max)`。
- **H3（因果缺席）**：在给定 `Γ` 下，`AbsC_causal` 的漏检率上界严格优于 `AbsC_marg`，差距随 `Γ` 增大而扩大（混杂越强，因果修正收益越大）。

## 3. 为什么这两个词此刻合流

- **LoRA 提供「可证书化的适应算子」**：低秩 ⇒ 参数少、可哈希、可验签、谱范数可界 ⇒ 天然接入 v23 的 `VersionTuple` 与 `CloudEdgeSync`。
- **因果提供「证书该证明什么」**：v23 的证书证明「覆盖达标」，但覆盖可能是伪相关的；因果不变性把「达标」升级为「在干预下仍达标」。
- **二者互补而非叠加**：没有因果，LoRA 只是更省参数的过拟合；没有 LoRA，因果不变性约束难以在边端以有界代价落地（全量微调的漂移不可界）。合流后，适应既是**参数有界**的，又是**机制对准**的。

## 4. 与 v23 的接口（不推倒重来）

- 把 `VersionTuple` 五元组扩为六元组 `V6 = (v_m, v_c, v_p, v_r, v_pt, v_lora)`，LoRA 适配器版本进入云边同步证书链。
- 用「因果 LoRA 适应」替换 FSVC 里「原型均值微调」，保留其 conformal 覆盖硬约束；原型退化为 `Φ_c` 的类中心，仅作冷启动先验。
- CAC 的缺席证书新增因果后门调整与敏感性界，原覆盖图 `CAC_cov_t` 作为因果图的观测证据输入。
- HPC-E+ 升级为 HPC-E++：在四证之上加「因果不变性证」与「LoRA 秩/谱证」。

## 6. 开放问题（留给后续轮次）

1. 因果图从何而来？观测数据只能识别马尔可夫等价类，`Φ_c` 的选取本身带假设——这是本轮最大隐患的来源。
2. `Γ` 的标定：敏感性参数如何从数据/领域知识给出可信上界，而非拍脑袋？
3. 低秩预算 `ρ_max` 与不变性阈值 `δ_inv` 的联合标定：二者存在张力（太紧学不动，太松漂移失控）。
4. 多机器人联邦下，各边端 `Φ_c` 是否一致？不一致时 CFC+++ 的跨层一致性如何仲裁？

**本轮最大风险（一句话）**：整条因果证书链的可信度完全押在因果图/不变性假设的正确性上——一旦因果图误设（漏掉混杂或把碰撞点当因），CIC 与 CAC-X 会「自证成立却实际失真」，这是比 v23 的协同故障更隐蔽的失效。

```python
# ============================================================
# IP-440 CausalLoRA Adapter (CLA) — 低秩 + 因果子空间约束
# ============================================================
class CausalLoRAAdapter:
    def __init__(self, W0, causal_basis: Tensor, r: int = 4,
                 alpha: float = 8.0, rho_max: float = 0.5):
        # causal_basis: Φ_c 的正交基，形状 (k, d_c)，来自 CIC 的环境不变性分解
        self.W0 = W0                      # 冻结基座 (d, k)
        self.Pc = causal_basis            # 因果子空间投影基
        self.r, self.alpha, self.rho_max = r, alpha, rho_max
        self.B = torch.zeros(W0.shape[0], r)
        self.A = torch.zeros(r, W0.shape[1])
        self.rho = 0.0
        self.delta_hash = None

    def adapt(self, support: list[tuple[Tensor, int]], steps: int = 50):
        """K-shot 适应：梯度只沿因果子空间下降，谱范数每步投影回预算内"""
        for _ in range(steps):
            for x, y in support:
                phi = self._features(x)                 # 冻结骨干
                # 关键：把输入特征投影到因果子空间，伪相关方向不参与适应
                phi_c = phi @ self.Pc @ self.Pc.T
                logits = self._forward_with_lora(phi_c)
                loss = F.cross_entropy(logits, y)
                loss.backward()
                with torch.no_grad():
                    self.B -= 1e-3 * self.B.grad
                    self.A -= 1e-3 * self.A.grad
                    self.B.grad.zero_(); self.A.grad.zero_()
                    self._project_to_budget()
        self.delta_hash = sha256(self.B.numpy().tobytes() + self.A.numpy().tobytes())
        return self.rho, self.delta_hash

    def _project_to_budget(self):
        """谱范数预算投影：保证 ρ(ΔW) ≤ ρ_max（机械可复核）"""
        sB = torch.linalg.matrix_norm(self.B, ord=2)
        sA = torch.linalg.matrix_norm(self.A, ord=2)
        rho = (self.alpha / self.r) * sB * sA
        if rho > self.rho_max:
            scale = math.sqrt(self.rho_max / rho)
            self.B *= scale; self.A *= scale
            rho = (self.alpha / self.r) * sB * sA * scale * scale
        self.rho = float(rho)

    def _forward_with_lora(self, phi_c):
        return phi_c @ (self.W0 + (self.alpha / self.r) * (self.B @ self.A)).T

    def _features(self, x):
        return self.backbone.extract_features(x)

# IP-441 Causal Invariance Certificate (CIC) — 多环境不变性
# ============================================================
class CausalInvarianceCertificate:
    def __init__(self, delta_inv: float = 0.05, min_envs: int = 3):
        self.delta_inv = delta_inv
        self.min_envs = min_envs
        self.phi_c_basis = None
        self.I_hat = float('inf')

    def decompose(self, env_data: dict[str, list[tuple[Tensor, int]]]):
        """从多环境数据中分解因果/伪相关子空间（IRM/不变风险最小化）"""
        if len(env_data) < self.min_envs:
            raise ValueError("环境数不足，无法识别不变性")
        # 简化：对每个特征维度估计跨环境风险方差，方差小者入 Φ_c
        feats = {e: torch.stack([f for f, _ in d]) for e, d in env_data.items()}
        # 用环境条件分布的均值差异度量伪相关强度
        risk_var = self._cross_env_risk_variance(feats, env_data)
        causal_dims = (risk_var < self.delta_inv).nonzero().squeeze(-1)
        self.phi_c_basis = self._orthonormal_basis(causal_dims)
        return self.phi_c_basis

    def invariance_measure(self, env_data: dict[str, list[tuple[Tensor, int]]]) -> float:
        """I(Φ_c) = sup_{e,e'} TV(P(Y|Φ_c,e), P(Y|Φ_c,e'))"""
        if self.phi_c_basis is None:
            return float('inf')
        dists = {}
        for e, data in env_data.items():
            z = torch.stack([f for f, _ in data]) @ self.phi_c_basis
            y = torch.tensor([y for _, y in data])
            dists[e] = self._empirical_conditional(z, y)
        return max(self._tv(dists[e], dists[e2])
                   for e in dists for e2 in dists if e != e2)

    def certify(self, env_data) -> bool:
        self.I_hat = self.invariance_measure(env_data)
        return self.I_hat <= self.delta_inv

# IP-442 Counterfactual Absence Certificate (CAC-X)
# ============================================================
class CounterfactualAbsenceCertificate:
    def __init__(self, kappa_c: float = 1e-4, gamma: float = 2.0):
        self.kappa_c = kappa_c          # 缺席幻觉率上限
        self.gamma = gamma              # 敏感性参数 Γ ≥ 1
        self.causal_graph = None

    def set_causal_graph(self, graph):
        """从领域知识/因果发现得到的 DAG，含 C→Φ 与 C→Y 的混杂边"""
        self.causal_graph = graph

    def backdoor_adjust(self, y_prob, c_dist, region) -> float:
        """P(occupied(r) | do(visible)) = Σ_c P(occupied | visible, c) P(c)"""
        if self.causal_graph is None:
            raise RuntimeError("未设定因果图，禁止签发因果缺席证书")
        z_parents = self.causal_graph.backdoor_parents(region)
        return float(sum(y_prob[c] * c_dist[c] for c in z_parents))

    def partial_identification(self, p_obs: float) -> tuple[float, float]:
        """边际敏感性模型：未观测混杂强度 Γ 下的部分识别区间"""
        # 经典 MSS 界：p_obs/Γ ≤ p_true ≤ min(1, Γ·p_obs)
        lo = p_obs / self.gamma
        hi = min(1.0, self.gamma * p_obs)
        return lo, hi

    def certify(self, region, y_prob, c_dist) -> bool:
        p_do = self.backdoor_adjust(y_prob, c_dist, region)
        lo, hi = self.partial_identification(p_do)
        # 只有最坏情况下仍不超幻觉率上限，才签发缺席
        return hi <= self.kappa_c

# IP-443 LoRA Provenance & Rank Certificate (LPRC)
# ============================================================
@dataclass
class LoRAVersion:
    v_lora: int
    r: int
    rho: float
    delta_hash: bytes
    sig_cloud: bytes

class LoRAProvenanceCertificate:
    def __init__(self, pk_cloud, r_max: int = 8, rho_max: float = 0.5):
        self.pk_cloud, self.r_max, self.rho_max = pk_cloud, r_max, rho_max

    def certify(self, adapter: CausalLoRAAdapter, V: LoRAVersion) -> bool:
        # 1. 秩与容量
        if V.r > self.r_max or V.rho > self.rho_max:
            return False
        # 2. 权重哈希一致（防篡改）
        if V.delta_hash != adapter.delta_hash:
            return False
        # 3. 云端签名（来源可信）
        if not verify_signature(self.pk_cloud, V.delta_hash, V.sig_cloud):
            return False
        # 4. 合并精确性：重算 ΔW 与存储一致
        recomputed = (adapter.alpha / adapter.r) * (adapter.B @ adapter.A)
        if not torch.allclose(recomputed, adapter.stored_delta, atol=1e-6):
            return False
        return True

            return False
        # 4. 反事实缺席（若计划涉及"进入空区域"）
        if plan.enters_empty_region and not self.cac_x.certify(region, y_prob, c_dist):
            return False
        return True


# ============================================================
# 端到端接入：v24 pipeline（在 v23 基础上替换 FSVC 的适应路径）
# ============================================================
class CausalPerceptionCompliancePipeline(PerceptionComplianceEnergyPipeline):
    def __init__(self, config):
        super().__init__(config)
        self.cic = CausalInvarianceCertificate(delta_inv=config.get('delta_inv', 0.05))
        self.cla = CausalLoRAAdapter(config['W0'], config['causal_basis'],
                                     r=config.get('r', 4), rho_max=config.get('rho_max', 0.5))
        self.lprc = LoRAProvenanceCertificate(config['pk_cloud'])
        self.cac_x = CounterfactualAbsenceCertificate(gamma=config.get('gamma', 2.0))
        self.hpc_e_plus_plus = HPCEPlusPlus(self.hpc_e_plus, self.cic, self.cac_x, self.lprc)

    def step(self, sensor_data, cloud_update=None):
        # 1. 云端更新：V6 六元组入 CESC
        if cloud_update:
            self.cesc.receive_cloud_update(cloud_update['V6'], cloud_update['artifacts'])
        # 2. 多环境不变性分解（后台低频）
        if 'env_data' in sensor_data:
            self.cic.decompose(sensor_data['env_data'])
        # 3. 因果 LoRA 适应（K-shot）
        if 'support' in sensor_data:
            self.cla.adapt(sensor_data['support'])
        # 4. v23 原流程 + v24 六证准入
        admitted, info = super().step(sensor_data, cloud_update)
        if admitted:
            admitted = self.hpc_e_plus_plus.admits(
                info['plan'], sensor_data['x'], sensor_data['v'], sensor_data['z'],
                sensor_data['E_res'], sensor_data['margin_req'],
                self._modules_in_plan(info['plan']),
                self.cla, sensor_data['V6'], sensor_data['env_data'],
                sensor_data['region'], sensor_data['y_prob'], sensor_data['c_dist'])
        info.update({'I_hat': self.cic.I_hat, 'rho': self.cla.rho,
                     'gamma': self.cac_x.gamma, 'v_lora': sensor_data['V6'].lora.v_lora})
        return admitted, info
```

## 2. 复杂度分析

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| CLA K-shot 适应 | `O(K·steps·(d·k·r))` | `O(d·r + r·k)` | `r≤8, d=256, k=256` |
| CLA 谱投影 | `O(d·r² + r·k²)` 每步 | `O(1)` 增量 | `ρ_max=0.5` |
| CIC 分解 | `O(|ℰ|·n·d)` 离线 | `O(n·d + d·d_c)` | `|ℰ|≥3, δ_inv=0.05` |
| CAC-X 后门调整 | `O(|Pa|·|C|)` | `O(|C|)` | `Γ∈[1,3], κ_c=1e-4` |
| LPRC 验证 | `O(d·k·r)` 重算 + `O(1)` 验签 | `O(d·k)` | `r_max=8` |
| HPC-E++ 准入 | `O(|modules| + |ℰ|·n·d)` | `O(1)` 增量 | 六证连言 |
| 端到端单步 | `O(|det|·d + K·steps·d·k·r)` | `O(d·r + r·k)` | 50Hz 关键路径不含适应（异步） |

**实时性保证**：适应与不变性分解均为**后台低频**；在线关键路径 `LPRC.certify + CAC-X.certify + HPC-E++` 为 `O(d·k·r)` 验算或 `O(|Pa|)` 调整，可在控制环外异步完成，`admitted` 只读取已签发的证书位，保持 <20ms。

## 3. 正确性论证

### 引理 1（容量—覆盖保持）
**陈述**：若基座覆盖 `≥ 1-α+ε(ρ)`，且 `ρ(ΔW_c) ≤ ρ_max`，则适配后覆盖 `≥ 1-α`，其中 `ε(ρ) = L_f·ρ·E‖x‖ / (conformal 分数 Lipschitz)`。

**证明**：
1. 由 Lipschitz 性，`‖f_{W0+ΔW}(x) − f_{W0}(x)‖ ≤ L_f·ρ·‖x‖`。
2. conformal 分数 `s(x)` 关于 logits 连续，故分数漂移 `|s' − s| ≤ L_s·L_f·ρ·‖x‖ =: ε(ρ)`。
3. 覆盖事件 `{err ≤ q̂_α}` 在分数平移 `ε(ρ)` 下的测度损失不超过 `ε(ρ)`（分位数对扰动的稳定性）。
4. 故 `Coverage(θ) ≥ (1-α+ε) − ε = 1-α`。∎

### 引理 2（不变性—OOD 风险界）
**陈述**：若 `I(Φ_c) ≤ δ_inv` 且 `ρ ≤ ρ_max`，则 `R_ood ≤ R_id + c₁·δ_inv + c₂·ρ_max`。

**证明**：
1. 分解 `R_ood − R_id = [R_ood − R_ood(Φ_c)] + [R_ood(Φ_c) − R_id(Φ_c)] + [R_id(Φ_c) − R_id]`。
2. 第一、三项由伪相关方向 `Φ_s` 的贡献界定，因果 LoRA 令 `col(Aᵀ) ⊆ span(Φ_c)` 使适配不放大 `Φ_s`，其贡献 `≤ c₂·ρ_max`。
3. 中间项由不变性定义 `I(Φ_c) ≤ δ_inv` 直接界定为 `c₁·δ_inv`。
4. 合并即得。∎

### 引理 3（反事实缺席的漏检上界）
**陈述**：若 `U(Γ) ≤ κ_c`，则 `AbsC_causal` 的真实漏检率 `FNR ≤ κ_c`。

**证明**：
1. `AbsC_causal` 使用后门调整估计 `P(occupied | do(visible))`，在因果图正确时无偏（后门准则）。
2. 存在未观测混杂时，MSS 部分识别区间 `[L(Γ), U(Γ)]` 覆盖真值（`Γ` 为真实混杂强度上界）。
3. 证书要求 `U(Γ) ≤ κ_c`，即最坏情况真值仍 `≤ κ_c`，故 `FNR ≤ κ_c`。∎

### 引理 4（v24 单调退化链）
**陈述**：`Exec_v24 ⊆ Exec_v23 ⊆ … ⊆ Exec_v18` 恒成立。

**证明**：
- `Exec_v24` 定义为 `Exec_v23` 与 `Fil_inv ∩ Fil_lora ∩ Fil_cf` 的交集，交运算单调。
- 任一新增证书失效 ⇒ 对应过滤器拒绝 ⇒ 退化为 `Exec_v23`，不新增计划。
- 因果图缺失/不变性不可识别 ⇒ `CIC` 抛错或返回 `false` ⇒ 退化为 v23（拒绝而非放宽）。∎

### 定理（HPC-E++ 六证准入门可靠性）
**陈述**：`HPCEPlusPlus.admits(π)=True` ⇒ π 同时满足：(1) v23 物理/云边/少样本/IP 四证；(2) 适应限于不变因果机制且 OOD 风险有界；(3) 适配器秩/谱/来源/合并精确；(4) 涉及空区域的计划在混杂下仍满足缺席幻觉率上限。逆命题在因果图正确且 `Γ` 为有效上界时成立。

**证明**：四个连言分别由 `hpc_e_plus.admits`、引理 2、`LPRC.certify` 的四项检查、引理 3 给出；必要性由任一条件缺失即拒证；充分性需因果图与 `Γ` 假设，故逆命题带前提。∎
