# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「数据规模」×「视觉编码器」）

> R69 让系统学会了「问」。但它把两样最贵的东西当成了免费基础设施：**（1）视觉编码器 Φ 是世界的充分统计量**——于是 U_epi 被默认等于「世界里的歧义」；**（2）训练/标定所用的数据规模与数据分布就是部署时的那个**——于是「ECE 达标」被当成永久事实。两者一旦不成立，R69 最自豪的「不确定性二分」会以最危险的方式出错：**编码器把两个不同的世界压成同一个 z，流策略就只会吐出一个模态，U_epi≈0，系统于是既不去看、也不去问，而是自信地走向其中一个世界。**
>
> 本轮两个灵感正好补上这两块：
> - **视觉编码器**不是一个中立的特征提取器，而是系统的**信息光圈（aperture）**：它决定了哪些歧义在物理上可分辨、哪些噪声会被放大。R69 的 U_epi 是「光圈内的歧义」，光圈外的歧义（盲区 B_Φ）再多交互也消解不了——只能被**识别为不可解**并保守兜底。
> - **数据规模**不是单调的安全保证：更多数据提高信噪比、扩大覆盖，但**扩不了光圈**；而且 R69 的主动交互采集是**被选择过**的数据，raw N 上升时有效规模 N_eff 可能反而下降。存在「数据规模的海市蜃楼」与「数据饱和」：此时正确的动作不是「再采一点」，而是**换编码器或收缩工作域**。
>
> 核心命题：**把「感知资格」变成不确定性通道的前置条件，把「数据规模」从隐含假设变成可记账、可外推、可审计的一等变量。** 具体地：U_epi 只在编码器可辨识（I_Φ 足够、盲区 B_Φ 足够小）时才可解；U_ale 只在编码器不放大滋扰（Nui_Φ 足够小）时才可信；标定误差用缩放律 ECE(n) 外推并取置信上界；raw N 与有效 N_eff、覆盖 C(s) 分开记账；在「采数据 / 升编码器 / 缩域」之间按边际风险下降每成本做元决策；任何编码器更换都触发证书失效与影子重认证。命名 **APERTURE-RAS**（Adequacy of Perception: Encoder-Restricted Trust Under Regime Escalation）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我的感官看得见这个歧义吗，我凭什么相信再多数据就能看见**」——光圈之外的不知道，必须被诚实地命名为不知道，而不是被一个更平滑的置信度掩盖。

## 0. 直觉与动机

**灵感 1（视觉编码器 = 信息光圈 → 歧义有一个「可分辨上限」）**
直觉：人眼分辨不了 0.1mm 的两条刻线，再多看十次也没用；这不是「噪声」，是**孔径极限**。R69 把 U_epi 定义在动作模态熵 H_mode 上，而 H_mode 完全由条件编码 z=Φ(o) 决定。若 Φ 对区分两个世界模态 M 的信息为零，则 z 相同、策略条件分布相同、采样模态只有一个、H_mode=0——R69 会把这个「假零」读成「没有歧义」。信息论上这很干净：H(M)=I(M;Φ(o))+H(M|Φ(o))，**前半是光圈内可解的部分，后半 B_Φ 是光圈盲区**。交互、采样、再多算力都只能作用于前半。所以本轮第一件事：把 B_Φ 显式命名，并规定它不可被 VoI「消解」，只能被识别、收缩或换镜头。

**灵感 2（视觉编码器 = 漏光 → 滋扰被放大成假歧义）**
直觉：光圈的另一个失效方向是**漏光**——背景、光照、纹理、相机抖动这些与任务无关的 N 漏进 z，让同一世界状态在不同视角下给出不同模态，U_epi 虚高，系统去追问一个不存在的分歧（对应 R69 的「幻影模态」）。R68/R69 的标定只能吸收传感器残差，吸收不了「编码器把无关变量当特征」这种**表征级伪相关**。更糟的是：数据规模上升时，如果数据里伪相关占主导（网络数据、跨机器人数据的捷径），编码器会把 Nui_Φ 学得更大——**更多数据可能让光圈更脏**。所以 Nui_Φ 必须与 I_Φ 一起进资格门。

**灵感 3（数据规模 ≠ 有效数据规模 → 海市蜃楼）**
直觉：R69 的主动交互专门挑「不确定」的样本去问，这本身是一种主动学习。主动学习的分布 p_collect 会向高 U 区集中；但部署要的是目标任务分布 p_target 的覆盖。二者的密度比 w=p_target/p_collect 在低 U 区会很大，有效样本量 N_eff=(Σw)²/Σw² 随主动强度上升而**下降**。于是出现最反直觉的一幕：**交互越多、原始数据越多，系统对『我已经见过世界』的信心越足，而它对世界的有效覆盖可能越窄**。本轮必须把 raw N、N_eff、覆盖 C(s) 三者同时记账，并给出「海市蜃楼」判据。

**灵感 4（数据规模 ≠ 标定的保证 → 缩放律与外推）**
直觉：「我们采了 10 倍数据，ECE 应该更好了吧」是一个**未被检验的外推**。标定误差随 n 通常呈幂律下降但有一个不可约地板 c，且会被编码器漏光项抬高。把 ECE(n)=a·n^{−α}+c+b·Nui_Φ 显式拟合，能得到两个关键量：**数据效率 α**（再采多少才划算）与**不可约地板 c**（再采也没用）。当 α→0 或 b 很大时，「继续采数据」的边际收益趋零——这不是工程细节，而是**认识论结论**：瓶颈在镜头，不在光量。

**灵感 5（三种干预 → 把「该做什么」变成可审计的三选一）**
直觉：面对「看不清楚」，人类不会只做一件事。可以（a）多收集数据/多看几眼（collect），（b）换更好的镜头/戴眼镜（upgrade encoder），（c）承认这个场景超出能力、缩小活动范围（restrict domain）。R69 只有「问」和「不问」两个动作；本轮补上**元层面的数据-感知干预**，并按「边际风险下降 / 成本」选最优。关键纪律：**永远不能用「再加点数据」去替代一次真正的镜头升级或一次诚实的域收缩**——那正是数据规模崇拜最典型的失败模式。

**灵感 6（编码器更换即失效 → 影子重认证）**
直觉：R68 有换装不变式、R69 有提交/换装不变式，但它们都假设「感知前端不动」。一旦换编码器（换 backbone、换分辨率、微调、换预训练域），所有用旧 z 标定出来的 ECE、模态权重、λ 全部作废。人类换眼镜后也要重新适应距离感。所以必须规定：**编码器任何变化 = 证书失效 = 进入影子模式**，新编码器只记录不执行，直到在保留审计集上重新通过资格门与标定上界，才允许换装；换装期间回退到最保守的安全参考策略。这样「升级」不会变成「无过渡的危险跃迁」。

**灵感 7（自我认证的盲区 → 需要光圈外的第三意见）**
直觉：R70 的监控器 AIM 若也用 Φ 的特征去测「Φ 看不看得见」，就会犯最致命的循环：**探针与被测对象共享同一盲区**。编码器看不见的东西，基于它的互信息探针也看不见，于是它报告「可辨识」，系统在最该警觉时自我盖章。R69 的 FMA 第二意见（动作似然）同样条件在 z 上，所以对「z 不变的漂移」也会失明。本轮必须补一条**编码器无关的通道**：原始观测层面的反事实一致性、跨传感器冗余、或少量人工抽检，作为光圈外的第三意见。否则 APERTURE 只是把 R69 的盲区包了一层更漂亮的证书。

## 1. 形式化定义（增量：定义 310–321）

**定义 310（APERTURE-RAS 总览）** APERTURE-RAS = (AIM, PAG, SCL, ESS, MAG, REC, DPA, FLUID-RAS†)。四不变式：
(i) **继承** R69 三不变式（实时零学习写、交互预算、证据纪律）与 R68/R69 的换装不变式；
(ii) **感知资格前置**：任何 U_epi / VoI / λ 通道的输出都必须携带资格标签 qual_Φ；资格未过 ⇒ U_epi 标为「不可分辨」，按未消解走 R69 兜底，**不得**用交互去「消解」它；
(iii) **数据记账守恒**：raw N、有效 N_eff、覆盖 C(s) 三者同时记账；N 的增长不得替代 N_eff 与覆盖的验证，任何阈值放松必须由 N_eff 与覆盖而非 raw N 支撑；
(iv) **编码器更换即失效**：编码器参数、预处理、分辨率、预训练域任一变化都使 J_FLUID 与 J_APERTURE 失效并进入影子重认证，不得热切换。

**定义 311（信息光圈与编码器可辨识性）** 编码器 Φ: 𝒪→ℝ^d，世界模态 M（R69 定义 296），滋扰变量 N（背景/光照/视角等与任务无关者）。定义：
- 光圈内信息 `I_Φ = I(M; Φ(o))`；盲区（equivocation）`B_Φ = H(M|Φ(o))`；恒有 `H(M)=I_Φ+B_Φ`；
- 混叠率 `Ali_Φ = B_Φ / H(M)`（不同模态被压到同一表征的比例）；
- 漏光率 `Nui_Φ = I(N; Φ(o)) / H(N)`（无关变量泄入表征的比例）；
- 光圈分辨率 `A_Φ = min_{i≠j} d(Φ(o_i),Φ(o_j)) / σ_Φ`（模态在表征空间的可分性，σ_Φ 为模态内尺度）。
**核心断言（引理 19）**：R69 的 U_epi 无论用多少交互或采样，可解上限不超过 I_Φ；盲区 B_Φ 是对交互「不可约」的部分。

**定义 312（感知资格门 PAG）** `qual_Φ = (I_Φ ≥ τ_I) ∧ (B_Φ ≤ τ_B) ∧ (Nui_Φ ≤ τ_n) ∧ (A_Φ ≥ τ_A)`。三态输出：
- `PASS`：可进入 R69 的 U_epi/VoI 通道；
- `BLIND`（B_Φ 或 A_Φ 不达标）：U_epi 不可解，按 U_ale+U_epi 兜底，并触发 REC/MAG；
- `LEAK`（Nui_Φ 不达标）：禁用 VoI（防幻影追问），退回 R68 纯保守。
资格标签必须带**独立证据**（见定义 320 的第三意见），不能只由 Φ 自身特征给出。

**定义 313（标定缩放律 SCL）** 设有效数据规模 n=N_eff（定义 314），标定误差经验律
`ECE(n) = a·n^{−α} + c + b·Nui_Φ`，
其中 α>0 为数据效率指数，c≥0 为不可约地板，b≥0 为漏光放大系数。用历史分层数据拟合 (a,α,c,b) 并给出**外推置信带**。数据充分判据（保守版）：`ECE 的置信上界(n) ≤ τ_ece`。若成立，才允许 `qual_Φ=PASS` 下的 ECE 门开；否则进入定义 315。
要点：**α≈0 或 b 大意味着「数据饱和 / 编码器瓶颈」**，此时「再采数据」对 ECE 的边际收益趋零。

**定义 314（有效数据规模 ESS 与海市蜃楼）** 采集分布 p_collect 与目标分布 p_target，密度比 `w_i=p_target(o_i)/p_collect(o_i)`（域分类器估计）。`N_eff=(Σ_i w_i)²/Σ_i w_i²`。覆盖图 `C(s)` 按（模态 × 任务 × 域）分层由预注册审计集聚合。**海市蜃楼判据**：若 `N_raw↑` 而 `N_eff/N_raw↓` 或 `C(s)` 不增，判为 `MIRAGE`，此时**禁止**用 raw N 放松任何阈值，且 MAG 的 collect 干预记为零收益。

**定义 315（采集元控制器 MAG）** 干预 `π ∈ {collect(Δn), upgrade(Φ'), restrict(Δdom)}`，成本分别 `c_c·Δn`、`c_u`（含重认证风险）、`Δdom`（可用性损失）。定义各干预的边际风险下降 `MRR(π) = −E[dRisk/dπ]`。选择 `π* = argmax_π MRR(π)/c_π`，约束「干预后证书可恢复」。**优先规则**：若 α<α_min（数据饱和）或 b·Nui_Φ>τ_b（编码器瓶颈），则 `MRR(collect)→0`，MAG **必须**在 upgrade 与 restrict 之间选，不得默认 collect。

**定义 316（影子重认证 REC）** 编码器变更后：新编码器 Φ' 进入**影子模式**（只记录、不执行），旧安全参考策略继续执行；在保留审计集上同时满足（a）PAG 的 PASS、（b）SCL 置信上界 ≤ τ_ece、（c）R69 证据纪律，才允许换装；否则回退并触发 MAG。影子日志哈希入证书，换装不变式（R67 定理 15 的延伸）保持。

**定义 317（数据来源审计 DPA）** 大规模/异构数据（网络、跨机器人、众包、交互回灌）引入标签噪声与伪相关。分层噪声率 `η(s)`、域外比例 `ood(s)`、伪相关强度 `ρ_sp(s)`。审计门：任一层 `η(s)>τ_η` 或 `ρ_sp(s)>τ_ρ` 的数据不得进入编码器/策略训练；主动采集数据必须去选择偏差重加权后才计入 N_eff。数据投毒并入 ℰ_APERTURE。

**定义 318（三通道保守退避，严格包含 R69 与 R68）**
- `PASS ∧ ECE上界达标 ∧ 非 MIRAGE`：`λ = λ_FLUID(U_ale,U_epi)`（**逐指令等于 R69**）；
- `BLIND`：`U_epi` 视为不可解，`λ = λ_floor(U_ale+U_epi)`（R69 未消解兜底），且禁用 VoI；
- `LEAK / ECE越界 / MIRAGE / 重认证中`：`λ = λ_floor(U_ale+U_epi)` 且禁用 VoI 与动作似然第二意见（R68 纯保守）。
⇒ R69 =「PASS ∧ 数据充分 ∧ 无 mirage」边界；R68 =「永不交互」边界。安全侧逐指令不弱于 R69/R68。

**定义 319（证书 J_APERTURE）** `J_APERTURE = (J_FLUID, qual_Φ, I_Φ, B_Φ, Nui_Φ, A_Φ, ECÊ 与置信上界, N_eff/N_raw, C(s), (a,α,c,b), MAG_decision, rec_log_hash, provenance_hash, third_opinion_hash, aperture_ver)`。Valid ⇔ Valid(J_FLUID) ∧ qual_Φ=PASS ∧ SCL 上界达标 ∧ 非 MIRAGE ∧ REC 完成。

**定义 320（光圈外第三意见 TPO）** 编码器无关的三条并行证据：(i) 原始观测反事实一致性 `CV_raw`（只交换编码器本应敏感、但可能混叠的因子）；(ii) 跨传感器/跨视角冗余一致性 `XR`；(iii) 低频人工抽检 `HS`（预算内、分层抽样）。三者构成 `E_indep`，用于**校准 AIM 自身**：若 `qual_Φ=PASS` 但 `E_indep` 报强分歧，则降级为 `BLIND`（对抗自我认证盲区）。

**定义 321（编码器族与尺度轴）** 编码器族 `{Φ_λ}` 沿尺度轴 λ 变化（参数量、输入分辨率、预训练数据域/规模、是否微调）。**A_Φ、Nui_Φ、B_Φ 对 λ 不必单调**：更大的模型可能混叠更少但漏光更多（学到更多语义捷径），分辨率提升可能只减小几何混叠而不减语义混叠。故 MAG 的 upgrade 决策必须基于**实测资格三元组**，不能以参数量或预训练数据量作为代理指标。

## 2. 关键算法骨架

```python
# IP-264 AIM：信息光圈监控（离线估计 + 在线只读）
class ApertureMonitor:
    def __init__(self, encoder, probe_set, domain_clf):
        self.phi = encoder
        self.probe = probe_set              # 带模态标签的保留审计集（分层）
        self.clf = domain_clf               # p_target/p_collect 密度比
        self.cache = None                   # 资格标签缓存（离线更新）

    def estimate(self):
        z = self.phi(self.probe.o)
        I_phi = mutual_info(self.probe.M, z)             # 光圈内模态信息
        B_phi = entropy(self.probe.M) - I_phi            # 盲区（equivocation）
        Nui   = mutual_info(self.probe.N, z) / entropy(self.probe.N)
        A     = min_sep(z, self.probe.M) / within_scale(z, self.probe.M)
        return dict(I=I_phi, B=B_phi, Ali=B_phi/entropy(self.probe.M),
                    Nui=Nui, A=A)

    def gate(self, est, third_opinion):                  # IP-265 PAG
        if third_opinion.disagrees(est):                 # 光圈外证据否决
            return "BLIND"
        if est["I"] < TAU_I or est["B"] > TAU_B or est["A"] < TAU_A:
            return "BLIND"
        if est["Nui"] > TAU_N:
            return "LEAK"
        return "PASS"

# IP-266 SCL：标定缩放律拟合与外推（离线，周级）
def fit_calibration_law(history):
    # history: [(N_eff, ECE, Nui), ...] across past domains
    a, alpha, c, b = robust_fit("ECE = a*n**-alpha + c + b*Nui", history)
    return a, alpha, c, b

def ece_upper_bound(n, law, Nui, conf=0.95):
    a, alpha, c, b = law
    return conformal_upper(a * n**(-alpha) + c + b * Nui, conf)

# IP-267 ESS：有效数据规模与海市蜃楼
def effective_scale(raw_n, weights, coverage):
    w = asarray(weights)
    n_eff = w.sum()**2 / (w**2).sum()
    mirage = (n_eff / raw_n < TAU_EFF) or (coverage.new <= coverage.old)
    return n_eff, mirage

# IP-268 MAG：采数据 / 升编码器 / 缩域 的元决策
def meta_acquisition(law, est, cost):
    a, alpha, c, b = law
    mrr_collect = -marginal_risk_collect(alpha, a, c)        # alpha≈0 ⇒ ≈0
    mrr_upgrade = -expected_risk_upgrade(est, encoder_candidates)
    mrr_restrict = -expected_risk_restrict(est)
    cands = {"collect": (mrr_collect, cost.c_collect),
             "upgrade": (mrr_upgrade, cost.c_upgrade),
             "restrict": (mrr_restrict, cost.c_restrict)}
    # 硬规则：数据饱和/编码器瓶颈时禁用 collect
    if alpha < ALPHA_MIN or b * est["Nui"] > TAU_B:
        cands.pop("collect", None)
    return max(cands, key=lambda k: cands[k][0] / cands[k][1])

# IP-269 REC：影子重认证
def shadow_recertify(phi_new, audit_set, old_policy):
    if not shadow_mode(phi_new):        # 只记录不执行
        return "REJECT"
    est = ApertureMonitor(phi_new, audit_set).estimate()
    if PAG.gate(est, third_opinion(audit_set)) != "PASS":
        return "REJECT"
    if ece_upper_bound(audit_set.n_eff, audit_set.law, est["Nui"]) > TAU_ECE:
        return "REJECT"
    return "ACCEPT"                     # 累计足够审计后才允许换装

# IP-274 主闭环（R69 前加一层只读资格门；常规路径零额外模型）
def APERTURE_RAS_round(M, obs):
    z, o = M.mtm.forward(...)                       # R69 一次前向（不变）
    qual = M.aperture.gate(M.aperture.cache, M.tpo(obs))
    c, U_cal, thr = M.cof.step(...)                 # R68 标定
    # 1) 资格未过：不进入 R69 的交互/似然通道，直接保守兜底
    if qual in ("BLIND", "LEAK") or M.ess.mirage or not M.scl.ok(M.ess.n_eff):
        lam = lam_floor(M.aud.aleatoric(z) + M.aud.epistemic_unresolved(z))
        k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
        M.mag.maybe_schedule()                      # 记录是否需要 collect/upgrade/restrict
        return k, lam, "conservative"
    # 2) PASS：完全走 R69（含 VoI、FMA、resolution bonus）
    k, lam, mode, U = M.fluid.round(M, obs)         # 逐指令等同 R69
    M.vqa_i.submit_async(qual, M.scl.ece_bound, M.ess.n_eff, M.tpo.last)

## 3. 推导

**引理 19（光圈上界）** 设样本轨迹 ξ 由策略以 z=Φ(o) 为条件生成，则 `I(M; ξ|Φ(o)) = 0`，故 `I(M; ξ) ≤ I(M; Φ(o)) = I_Φ`。因此任何基于采样的 U_epi/VoI 所能区分模态的信息量不超过 I_Φ；盲区 `B_Φ = H(M) − I_Φ` 对交互不可约。系：当 `B_Φ` 大时，减小 H_mode 只意味着「编码器看不出的那些模态本来就不会让策略分叉」，而不是「世界没有歧义」。这是 R69「U_epi≈0 ⇒ 无需交互」最危险的误读。

**引理 20（数据海市蜃楼的必然性）** 主动采集使 p_collect 向高不确定区集中，令 `p_collect(o) ∝ p_target(o)·g(U(o))`，g 随 U 递增。则低 U 区 w=p_target/p_collect ∝ 1/g(U) 增大，权重分布重尾化；`N_eff=(Σw)²/Σw²` 随主动强度（g 的陡峭度）单调下降。故存在一个主动强度上限使 N_eff 最大——**过度主动学习会降低有效数据规模**，尽管 raw N 持续上升。

**引理 21（缩放律的域外失效）** SCL 的 (a,α,c,b) 在历史域上拟合。部署域滋扰上升 `ΔNui>0` 时，真实 ECE 至少增加 `b·ΔNui`；若仅用 n 外推而不重估 Nui_Φ，外推置信带不覆盖真实 ECE。故「数据规模」不能单独作为标定保证，必须与 Nui_Φ 和域偏移量联合门控。

**引理 22（盲区漂移对既有通道的不可见性）** 若漂移 δ 落在编码器盲区（`Φ(o+δ)=Φ(o)`），则传感器残差 r_res、动作似然 Δa（R69 FMA）与 U_epi 全部不变——三条通道同时失明。只有编码器无关的第三意见（定义 320，CV_raw/XR/HS）能检出。系：**自我认证的死角只能由外部证据打破**；TPO 不是可选增强，而是 R70 正确性的必要条件。

**定理 18（APERTURE 严格包含 FLUID 与 CALM）** 在 A99–A102 下：当 `qual_Φ=PASS`、SCL 上界达标、非 MIRAGE 时，APERTURE 与 R69 逐指令相同；否则其期望风险 ≤ R69（禁用可疑通道 + 走未消解兜底）。因此 R69 =「资格通过且数据充分」的边界，R68 =「永不交互」的边界；安全侧不做任何让步，效率侧仅在资格成立时保留 R69 的 resolution bonus。

**定理 19（影子重认证的无突变）** 影子模式保证换装前控制律不变；换装仅在（PAG ∧ SCL ∧ 证据纪律）同时成立时发生；换装不变式与安全包络保持 ⇒ 编码器切换期间控制连续、风险不超过新旧编码器保守包络的 max，无突变。

# IP-264 AIM：信息光圈监控（离线估计，在线只读）
class ApertureMonitor:
    def estimate(self):
        z = self.phi(self.probe.o)
        I_phi = mutual_info(self.probe.M, z)
        B_phi = entropy(self.probe.M) - I_phi
        Nui   = mutual_info(self.probe.N, z) / entropy(self.probe.N)
        A     = min_sep(z, self.probe.M) / within_scale(z, self.probe.M)
        return dict(I=I_phi, B=B_phi, Nui=Nui, A=A)

# IP-265 PAG：三态资格门（先让光圈外证据否决）
def gate(est, tpo):
    if tpo.disagrees(est):                          return "BLIND"
    if est["I"] < TAU_I or est["B"] > TAU_B or est["A"] < TAU_A:
        return "BLIND"
    if est["Nui"] > TAU_N:                          return "LEAK"
    return "PASS"

# IP-266 SCL：标定缩放律 + conformal 上界
def ece_upper(n, law, Nui, conf=0.95):
    a, alpha, c, b = law
    return conformal_upper(a * n**(-alpha) + c + b * Nui, conf)

# IP-267 ESS：有效规模与海市蜃楼
def effective_scale(raw_n, weights, coverage):
    w = asarray(weights)
    n_eff = w.sum()**2 / (w**2).sum()
    mirage = (n_eff / raw_n < TAU_EFF) or (coverage.new <= coverage.old)
    return n_eff, mirage

# IP-268 MAG：采数据 / 升编码器 / 缩域
def meta_acquisition(law, est, cost):
    a, alpha, c, b = law
    cands = {"collect":  (-marginal_risk_collect(alpha, a, c), cost.c_collect),
             "upgrade":  (-expected_risk_upgrade(est),        cost.c_upgrade),
             "restrict": (-expected_risk_restrict(est),       cost.c_restrict)}
    if alpha < ALPHA_MIN or b * est["Nui"] > TAU_B:   # 数据饱和/编码器瓶颈
        cands.pop("collect")                         # 禁止「再采点数据」当万能药
    return max(cands, key=lambda k: cands[k][0] / cands[k][1])

        return k, lam, "conservative"
    k, lam, mode, U = M.fluid.round(M, obs)          # 逐指令等同 R69
    M.vqa_i.submit_async(qual, M.scl.ece_bound, M.ess.n_eff, M.tpo.last)
    return k, lam, mode, U
```

## 4. 推导

**引理 19（光圈上界）** 轨迹 ξ 以 z=Φ(o) 为条件生成 ⇒ `I(M;ξ|Φ(o))=0` ⇒ `I(M;ξ) ≤ I(M;Φ(o))=I_Φ`。故基于采样的 U_epi/VoI 可区分模态的信息量不超过 I_Φ；盲区 `B_Φ=H(M)−I_Φ` 对交互不可约。系：`B_Φ` 大时 H_mode 变小只说明「看不出的模态不会让策略分叉」，不等于「世界无歧义」——这是 R69「U_epi≈0⇒免交互」最危险的误读。

**引理 20（数据海市蜃楼的必然性）** 主动采集 `p_collect ∝ p_target·g(U)`（g 随 U 递增）⇒ 低 U 区 `w=p_target/p_collect ∝ 1/g(U)` 重尾化 ⇒ `N_eff=(Σw)²/Σw²` 随主动强度单调下降。存在主动强度上限使 N_eff 最大：**过度主动学习降低有效数据规模**，尽管 raw N 上升。

**引理 21（缩放律域外失效）** (a,α,c,b) 在历史域拟合。部署域 `ΔNui>0` 时真实 ECE 至少增 `b·ΔNui`；仅按 n 外推的置信带不覆盖真实值。故数据规模不能单独作为标定保证，必须与 Nui_Φ、域偏移联合门控。

**引理 22（盲区漂移对既有通道不可见）** 若 δ 落在盲区（`Φ(o+δ)=Φ(o)`），则 r_res、Δa（R69 FMA）、U_epi 全都不变——三条通道同时失明；只有编码器无关的 TPO（CV_raw/XR/HS）能检出。系：**自我认证的死角只能由外部证据打破**，TPO 是 R70 正确性的必要条件而非可选增强。

**定理 18（APERTURE 严格包含 FLUID 与 CALM）** A99–A102 下：`PASS ∧ SCL 上界达标 ∧ 非 MIRAGE` 时与 R69 逐指令相同；否则期望风险 ≤ R69。故 R69 =「资格通过且数据充分」边界，R68 =「永不交互」边界；安全不让步，效率仅在资格成立时保留 resolution bonus。

**定理 19（影子重认证无突变）** 影子期控制律不变；换装仅在 PAG ∧ SCL ∧ 证据纪律同时成立时发生；换装不变式与安全包络保持 ⇒ 切换期控制连续、风险不超过新旧编码器保守包络的 max，无突变。

## 7. 本轮最大风险

**一句话**：APERTURE-RAS 的资格判断依赖「探测器能看见编码器的盲区」，而最省事的探测器恰好吃的是同一个编码器的特征——**探针与被测对象共享盲区，就会在最需要警觉时报告 PASS，把「光圈太小」误诊成「世界没有歧义」，并可能把预算继续投给「再采点数据」这种对光圈完全无效的干预**；自我认证的闭环，会让系统以合规的姿态、带着一张更漂亮的证书，安静地看不见。

**次级风险与缓解**：TPO 成本/覆盖不足（分层抽检 + 仅 F 大时触发 + 引理 22）；缩放律小样本过拟合（分层池化 + conformal 上界 + E304）；密度比重加权方差爆炸（权重裁剪 + 报告有效样本 + 引理 20）；编码器升级被冻结（影子 + 回退 + 定理 19）；MAG 被成本函数 Goodhart（预注册成本 + 审计 + E306）；把 B_Φ 当 aleatoric 导致过度保守（resolution bonus 仅在 PASS 给 + E303 权衡）。
