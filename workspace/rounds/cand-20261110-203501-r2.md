# 第 47 轮（承接第 46 轮 v23；本轮灵感：热管理 × 演示方案） · Thermal-Demo-Cert：热租约与可复现演示证据链支撑的姿态证书（五层架构 v11）

> 承接第 45 轮 v10 能量-上下文-深度与第 46 轮 v23 记忆-安全-语音。二者共同隐含假设 H5：系统工作在热稳态、标定不随温度漂移，且"安全保证"只需数学证明即可，无需可复现地向人/审计者演示。本轮两个灵感词精确命中 H5：**热管理**揭示持续 3-8W 深度感知与边缘算力会让结温上升、触发降频，并因热膨胀改变双目基线与内参，使室温下共形校准的姿态半径 r_ω 在高温下静默失效；**演示方案**则要求把能量-热-姿态-语音-记忆整条信任链做成可复现、可注入故障、可离线验证的证据链，否则"证书 soundness"只是纸面承诺。二者耦合出新问题：热是慢变量、带滞回与记忆，其失效恰恰最难现场演示，必须以时间加速的硬件在环演示 + 热协变量分桶校准 + 签名证据包来联合保证。

## 0. 直觉与动机

**灵感 1（热管理 → 热租约与慢变量证书失效）**
直觉：电池看"还剩多少"，热看"积累了多少"。热量有记忆：结温 T_t 由功耗对时间的积分经热阻/热容低通得到，降到安全线以下存在滞后。持续开深度并跑共形校准，几分钟后触发降频，感知帧率与算力下降，姿态证书的时效 τ_p 被压缩；同时热膨胀让双目基线 b(T) 与内参漂移，深度误差随 ΔT 增大，原本按室温标定的 r_ω 不再覆盖真实误差。于是热租约 ℓ_th 与能量租约 ℓ_e 并列，成为根信任的第三条腿；热不可行时同样 fail-closed，并显式声明降级模态。

**灵感 2（演示方案 → 证据链与可复现演示）**
直觉：不能被演示的安全等于不存在。演示不是拍视频，而是一次受控实验：固定场景分布、按脚本注入热/能量/上下文/语音故障、实时展示三条租约与姿态半径，并把日志哈希成可离线复验的证据包。演示方案 D 定义"应发生什么"的 oracle 谓词；演示通过即为证书 soundness 的经验下界，演示失败则定位到具体租约。

**灵感 3（耦合：热是最难演示的故障）**
直觉：热瞬态以分钟计，现场演示不能等十分钟。需要时间加速的硬件在环（HIL）热注入，用可编程热台/功耗负载把 T_t 拉到阈值附近，同时用热 RC 模型做"真实 vs 演示"一致性校验；否则加速演示会抹掉滞回，给出虚假通过。

**总体升级**：在 v10/v23 之上新增 **热-演示层（Thermal-Demo Layer）**。五层 v11：根信任层（能量租约 ℓ_e + 热租约 ℓ_th + 姿态租约 ℓ_p）、L1 几何层（热协变量分桶半径 r_ω(m,T)）、L2 上下文/记忆层（热状态进入检索键）、L3 安全守卫层（CAR 联合三租约）、L4 采集/演示层（DCL 加能耗，DHB 输出证据包）。

## 1. 形式化定义（增量：定义 59–63）

**定义 59（热状态与热租约）**
设环境温度 T_amb，模态/算力总功耗 P_tot(m,χ)=P_m+P_comp(χ)，热阻 R_th、热容 C_th、降频档 χ∈[0,1]。热 RC 离散演化
T_{t+1}=T_t + (Δt/C_th)·[P_tot(m_t,χ_t) - (T_t-T_amb)/R_th]。
热租约 ℓ_th=(T_t,T_max,R_th,C_th,τ_th,λ_th)。**热可行判据**
T(t+Δ) ≤ T_max - Δ_margin，
其中 T(t+Δ) 由上式的 Δt 步前向积分预测。失效时所有在降频下签发的姿态证书级联失效，并强制进入声明性降级模态。

**定义 60（热致标定漂移与分桶半径）**
热膨胀使基线 b(T)=b_0(1+α_b(T-T_0))、焦距 f(T)=f_0(1+α_f(T-T_0))。深度相对误差近似
ε_d(T) ≈ |b(T)-b_0|/b_0 + |f(T)-f_0|/f_0 + ε_d^0。
将温度划为桶 T∈B_k（如 5℃ 一桶）。条件共形半径
r_ω(m,T)=Q_{1-α}({|e_i| : T_i∈B_k, m_i=m})。
**热覆盖假设 H_th**：部署温度必须落在校准桶并集内；越界桶返回 r_ω=+∞（不可签发）。

**定义 61（三租约联合证书）**
J_t=(P_t,ℓ_p,ℓ_e,ℓ_th,m_t,χ_t)。**联合 soundness**：
Pr(X_t∈P_t | ω_t,m_t,χ_t, ℓ_e,ℓ_th 有效) ≥ 1-α_p，
且 E(t)≥E_min、T(t)≤T_max-Δ_margin、τ_p≤τ_p^max(χ_t)（降频压缩证书时效）。
**热-能量耦合转移界**：m_true ≥ m̂ - L_φ·rad(P_t) - L_e·(B_min-E(t))_+ - L_T·(T(t)-(T_max-Δ_margin))_+。

**定义 62（可复现演示方案与证据包）**
演示方案 D=(S,F,O,Λ)：S 为场景分布（含透明/镜面/弱纹理/快速运动层权重）；F 为故障注入脚本（热负载、电池骤降、上下文扰动、语音歧义、记忆污染）；O 为 oracle 谓词集（安全、失败关闭、租约一致性、证书覆盖）；Λ 为证据编码（时间戳、租约快照、证书、决策、传感器摘要）。
**演示 soundness**：对 s~S，系统声称"证书有效且执行"时真实结果满足 O 的比例 ≥ 1-α_demo。演示通过 ⇒ 证书实际 soundness 的经验下界。

**定义 63（时间加速演示的一致性约束）**
设加速因子 κ_t>1，演示热演化为 T^κ。一致性判据
sup_t |T^κ(t)-T(κ_t·t)| ≤ δ_T 且 sup_t |dT^κ/dt - κ_t·dT/dt| ≤ δ_Ṫ。
不满足则加速演示不具外推效力（滞回被抹平），必须回退实时长演示或标注"仅定性"。

## 2. 三大新增产出与既有 IP 升级

**IP-69 TLM（Thermal Lease Manager）**
- 热 RC 在线辨识（R_th/C_th 递推最小二乘）+ 结温软测量
- 前向热预测与降频档求解：给定 m_t 预测 Δt 内 T，选择最大可行 χ
- 热租约签发/续期/级联失效；热预算与能量预算联合准入

**IP-70 TCA（Thermal-Calibration Cert Adapter）**
- 热协变量分桶共形校准，越界桶 fail-closed（+∞ 半径）
- 在线热漂移检测：用固定标靶/自运动残差估计 ε_d(T)，触发重标定
- 降频-时效耦合：χ 下降 ⇒ τ_p^max 缩短，P_t 提前过期

**IP-71 DHB（Demo Harness & Evidence Binder）**
- 演示编排器：场景 × 故障脚本 × oracle 自动执行
- 时间加速 HIL 热注入与一致性校验（定义 63）
- 证据包哈希链 + 离线复验器（仅凭公钥与证据包即可复验）

**既有 IP 升级**
- IP-63 ECPS：效用 U 增加热惩罚与降频可行性；热不可行时禁止开深度。
- IP-66 MVR：记忆键加入热档位 (c,ω,B,T,m,U,outcome)；跨热档复用需重校验证书。
- IP-62 CCA：新增热漂移红队、越界温度桶注入、演示 oracle 对抗。
- IP-51 CAR：守卫改为 E≥E_min ∧ T≤T_max-Δ_margin ∧ τ_p≤τ_p^max(χ)。
- IP-45 总线：新增 thermal-lease / throttle-level / demo-evidence / oracle-result 话题。

## 3. 算法骨架

**TLM+TCA 每控制周期**
1. 采样 T_t、功耗、帧时延；更新 R̂_th,Ĉ_th。
2. 对候选 m 前向预测 T(t+Δ)，求最大可行 χ_t。
3. 若 T(t+Δ)>T_max-Δ_margin → 降级 m 或 fail-closed，更新 ℓ_th。
4. 按当前热桶取 r_ω(m,T)（越界则 +∞）。
5. 签发 P_t，要求 τ_p≤τ_p^max(χ_t)，更新联合证书 J_t。
6. CAR 用 J_t 守卫；DHB 记录租约快照与 oracle 结果。

**DHB 演示循环**
1. 采样场景 s~S 与故障脚本 f~F。
2. 启动 HIL 热负载与时间加速，校验定义 63。
3. 跑闭环，实时展示三租约与姿态半径。
4. 逐条评估 oracle O，哈希证据 Λ 入链。
5. 输出通过率、失效定位、可离线复验包。

## 4. 本轮最大风险

**一句话**：热失败是分钟级慢变量且强滞回，时间加速的演示极易抹平滞回与热漂移，导致演示通过但真实高温下 r_ω(T) 已不覆盖真实误差、证书静默失效；因此必须以定义 63 的一致性校验把演示限制在可外推区间，用分桶共形校准保证越界即 fail-closed，并让演示证据包明确标注加速因子与覆盖温度域。

## 2. 关键算法 伪代码

### IP-69 TLM
```
def thermal_rc_update(T, P_tot, dt, R_th, C_th, T_amb):
    return T + dt / C_th * (P_tot - (T - T_amb) / R_th)

def predict_T(T0, m, chi, horizon, dt, theta):
    T = T0
    for _ in range(int(horizon / dt)):
        T = thermal_rc_update(T, Pm[m] + Pcomp(chi), dt,
                              theta.R_th, theta.C_th, theta.T_amb)
    return T

def choose_throttle(T0, m, horizon, levels, theta):
    feasible = [x for x in levels
                if predict_T(T0, m, x, horizon, theta.dt, theta)
                   <= theta.T_max - theta.delta_margin]
    return max(feasible) if feasible else None  # None ⇒ 热不可行

def thermal_lease_valid(lease, m_t, horizon, theta):
    chi = choose_throttle(lease.T, m_t, horizon, theta.levels, theta)
    if chi is None:
        return False, None
    return True, chi

def update_thermal_lease(lease, T_meas, P_hist, theta):
    theta.R_th, theta.C_th = rls_fit(T_meas, P_hist)   # 在线辨识
    T_pred = predict_T(lease.T, lease.m, lease.chi, theta.horizon,
                       theta.dt, theta)
    ok = T_pred <= theta.T_max - theta.delta_margin
    return ThermalLease(T_meas, theta.T_max, theta.R_th, theta.C_th,
                        tau_th=theta.tau_th, valid=ok)
```

### IP-70 TCA
```
def bucket(T, width=5.0):
    return int(math.floor(T / width))

def radius_thermal(m, T, calib, alpha_p):
    k = bucket(T)
    if k not in calib[m]:
        return float('inf')             # H_th 越界 ⇒ fail-closed
    return calib[m][k].quantile(1 - alpha_p)

def thermal_drift_detect(residual_ewma, thr, n_min, n):
    return n >= n_min and residual_ewma > thr   # 触发在线重标定

def issue_pose_cert(m, T, chi, calib, P_geom, tau_p, alpha_p):
    r = radius_thermal(m, T, calib, alpha_p)
    if not math.isfinite(r):
        return None                     # 越界桶不可签发
    tau_max = tau_p_max(chi)            # 降频压缩时效
    if tau_p > tau_max:
        return None                     # 必须缩短有效期或重签
    return PoseCert(center=P_geom.center, radius=r,
                    tau=min(tau_p, tau_max), bucket=bucket(T))
```

### IP-71 DHB
```
def demo_run(scenario_sampler, fault_script, oracle, policy, accel):
    ev = EvidenceBuilder()
    s = scenario_sampler()
    f = fault_script(s)
    T0 = read_temp()
    ok_consistency = True
    for t in range(f.steps):
        apply_fault(f, t)
        if accel.enabled:
            ok_consistency &= accel.check(T0, t)   # 定义 63
        obs = sense(s)
        J = policy(obs, read_battery(), read_temp())
        ev.record(t, J, s, f.snapshot(), obs.digest())
        if not oracle.safe(J, obs):
            ev.mark_failure(t, oracle.explain())
            break
    if not ok_consistency:
        ev.annotate('accel_not_extrapolable', accel.factor)
    bundle = ev.seal(pubkey)            # 哈希链 + 签名
    return bundle

def verify_bundle(bundle, pubkey):
    if not (hash_chain_ok(bundle) and signature_ok(bundle, pubkey)):
        return False
    return replay_oracles(bundle).all()  # 无需源码即可离线复验

def accel_check(T0, t, real_log, factor, delta_T, delta_dT):
    T_real = real_log.temp_at(t * factor)
    T_demo = read_temp()
    return (abs(T_demo - T_real) <= delta_T and
            abs(read_temp_rate() - factor * real_log.rate_at(t * factor)) <= delta_dT)
```

### IP-51 CAR 联合守卫
```
def car_guard(J, E, T, chi, m_t, theta):
    if E < theta.E_min:
        return 'fail-closed', 'energy'
    if T > theta.T_max - theta.delta_margin:
        return 'fail-closed', 'thermal'
    if not math.isfinite(J.P_t.radius):
        return 'fail-closed', 'thermal_bucket'
    if J.P_t.tau > tau_p_max(chi):
        return 'fail-closed', 'throttle_tau'
    return 'ok', None
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TLM 热预测/降频求解 | O((H/Δt)·|levels|) 每周期 | O(1) | 前向积分 + 保守裕度 ⇒ 预测可行 |
| TCA 分桶查表 | O(1) | O(|B|·|M|) | 越界桶 +∞ ⇒ fail-closed |
| DHB 演示闭环 | O(N·(T_sense+T_policy)) | O(N) | 证据链签名 + 离线复验 |
| CAR 联合守卫 | O(1) | O(1) | 三租约任一越界 ⇒ fail-closed |

**正确性定理**：设热覆盖假设 H_th 成立（T 落入已校准桶）、ℓ_e 与 ℓ_th 有效、τ_p≤τ_p^max(χ)，且联合证书由 TCA 分桶共形签发。则联合证书 J_t 满足 Pr(X_t∈P_t|ω_t,m_t,χ_t) ≥ 1-α_p，能量与热可行性同时成立；进一步，若 DHB 演示按定义 62 覆盖 S 且定义 63 的一致性成立，则演示通过率 ≥1-α_demo 是证书实际 soundness 的经验下界，证据包可被任意审计者离线复验。反之，任一租约/温度桶/时效越界，CAR 均 fail-closed，不产生未被保证的执行。

| 实验 | 指标 | 门槛 |
|---|---|---|
| E115 热 RC 辨识 | 5min 前向 T 预测误差 | ≤ 1.5℃ |
| E116 分桶半径覆盖 | 各桶覆盖率；越界桶行为 | ≥ 1-α_p；越界 100% fail-closed |
| E117 降频-时效耦合 | τ_p^max(χ) 违约次数；过期一致性 | 违约 0 次；一致性 ≥ 99% |
| E118 证据链可复验 | 离线复验成功率；篡改检出率 | 100%；100% |
| E119 时间加速一致性 | δ_T、δ_Ṫ；不可外推标注 | δ_T ≤1℃；标注正确率 100% |
| E120 100h 热-能量-演示闭环 | 安全违例、热停机、演示通过率、故障定位 | 0 违例；0 误停；≥95%；≥90% |

**回退策略**：E115 预测误差超阈 → 缩小热预测视界并加大 Δ_margin；E116 某桶覆盖不足 → 该桶禁止签发并补采集；E119 一致性失败 → 关闭加速演示，改为长时实时验证；E120 出现热停机误报 → 提高 T_max 裕度并重辨识 R_th/C_th。

## 6. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 热 RC 参数漂移/风道变化 | 高 | 在线辨识 + 结温软测量交叉校验 + 保守裕度 |
| 分桶边界半径不连续 | 中 | 相邻桶取 max 并加滞回 |
| 时间加速掩盖滞回 | 高 | 定义 63 一致性校验；不可外推时标注并长时验证 |
| 演示脚本过拟合（场景/记忆） | 高 | 独立 oracle 审计集 + 随机种子 + 盲测场景 |
| 证据包泄露传感器隐私 | 中 | 只存摘要与哈希，脱敏/差分隐私 |
| 降频导致证书频繁过期 | 中 | 预热降频预测 + 提前续签 |

## 7. 本轮最大风险

**一句话**：热 RC 辨识误差与时间加速演示的一致性偏差会共同放大"预测安全但实际过热"的缝隙，若分桶校准未能覆盖真实温度域，r_ω(T) 会在高温段静默欠覆盖、三租约守卫却仍报 ok；因此必须以独立热审计集校验辨识与分桶覆盖、把定义 63 一致性作为演示放行的硬门槛，并在任何越界/低置信时默认 fail-closed。
