# 第 43 轮（新循环第 3 轮） · Uni-Cert 表征飞轮：单一自监督多任务主干，把「证书」从逐任务手工制品升级为可共享、可自洽、可迁移的潜空间对象（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR）。第 42 轮自陈最大风险是「仿真偏差累积」与「检索幻觉」：飞轮每个环节——指纹嵌入、INT8 监控器、域随机化、模板检索——都是**各自独立训练/标定**的，Sim 与 Real 的表征不共享，检索相似度与监控可靠性都建立在互不相通的「孤岛表示」上。本轮灵感词「单模型多任务」「自监督学习」正好把飞轮从「多模型拼接」改造成「单主干共享」：一个自监督预训练的共享主干同时服务证书边际、有效域、漂移、归因、检索指纹等 K 个头；自监督让 Isaac Sim 与实机的海量无标签轨迹都变成免费监督信号，并给出「证书自洽性」这种无需标签即可审计的证伪手段。核心命题从 v19 的「仿真产数据、检索复用」升级为 **「一次表征、处处证书」**：表征本身成为证书可信度的公共基础设施。

## 0. 直觉与动机

**灵感 1（单模型多任务 → 从「K 个监控器」到「一个主干 + K 个证书头」）**：v19 里，每条转移边、每个技能、每个任务都各自蒸馏一个 INT8 监控器，指纹 φ/ψ 又各自训练一个 GNN/Transformer。直觉上这是「K 个近视专家」：每个只见自己那一小撮数据，参数不共享、存储线性膨胀、彼此无法互相校验。单模型多任务的直觉是：**世界只有一个动力学，安全边际只是同一潜空间的不同切面**。用一个共享主干把 (视觉, 激光, 本体感觉, 语义图, 历史) 编码成统一潜变量 z，再接 K 个轻量头：h_edge(z)→边际下界、h_valid(z)→有效域、h_drift(z)→偏移分、h_attr(z)→反例语义、h_fp(z)→检索指纹。好处有三：(1) **数据效率**——稀有故障场景被所有头共享；(2) **交叉校验**——同一 z 上多个头互相约束（边际头与有效域头不一致即是告警）；(3) **存储/算力摊销**——一个主干 + 极小的多头，比 K 个独立监控器总和更省（IP-59）。

**灵感 2（自监督学习 → 把「无标签轨迹」变成证书的免费监督，并给出可证伪的自洽性）**：现有飞轮要「标签」的地方太多：边际真值要靠高保真仿真、α_e 要靠实机标定、检索模板要靠人工确认。自监督的直觉是：机器人每天产生海量**无标签**轨迹，其时空结构本身就是监督信号——掩码重建（masked trajectory modeling）、时序对比（InfoNCE 预测未来潜变量）、跨模态对齐（图像/点云/本体感觉同一时刻应映射到同一 z）、SE(3) 等变预测。更关键的是一个**证伪视角**：如果证书是对的，那么把状态做刚体变换 g∈SE(3)、把时间做重参数化、把传感器做保边际增广，证书应当**等变/不变**。于是无需任何安全标签，就能用「证书自洽性损失」审计证书与表征：一致性被破坏的地方，恰是证书最可能错的地方（IP-58）。这把第 42 轮「事后人工审计 RAG 模板」变成「在线、无标签、可大规模」的自洽性筛查。

**灵感 3（二者的耦合 → 「表征飞轮」套在「证书飞轮」内层）**：v19 是 Sim→CKB→Edge→Sim 的外层物质飞轮；本轮在其内层加一个 **表征飞轮**：Isaac Sim + 实机无标签流 → SSL 预训练共享主干 → 多任务证书头 → 高「SSL 惊喜」区域（重建误差大/潜密度低/自洽性差）被主动挑出 → 只在这些区域做仿真回放/标定/人工标签 → 回灌预训练。惊喜度同时充当 OOD/漂移探测器，天然替代 v19 中单独训练的 W_1 监控。外层决定「证书存什么」，内层决定「凭什么信」，两层通过同一潜空间 z 对接：检索指纹 φ/ψ 直接复用主干输出，检索从「另一个模型的相似度」变成「同一表征空间里的近邻 + 自洽性复核」。

**耦合升级（一句话）**：单模型多任务提供「共享的形」，自监督提供「免费的证」，二者把 v19 的「多模型拼接的可进化证书」升级为「单一表征支撑的可自证证书」。

## 1. 形式化定义（增量：定义 38–44）

**定义 38（自监督共享主干与多前兆任务）**
*直觉*：让主干先学会「世界怎么动」，再学会「哪里危险」。
*严谨*：编码器 f_θ: O^T → Z（观测序列→潜空间）。无标签数据 D_unlab = D_sim ∪ D_real。预训练目标
L_SSL = λ₁L_mask + λ₂L_tcl + λ₃L_align + λ₄L_equi + λ₅L_reg，
其中 L_mask 为掩码轨迹重建，L_tcl 为时序 InfoNCE（未来潜变量为正样本），L_align 为跨模态对齐（同一时刻不同传感器潜变量一致），L_equi 为 SE(3) 等变预测 ‖f(g·o) − ρ(g)f(o)‖，L_reg 为防坍缩正则（VICReg / stop-gradient）。并要求 f 对保边际传感器增广 σ∈Σ 近似不变：‖f(σo) − f(o)‖ ≤ ε_σ。

**定义 39（证书自洽性 / 无标签证伪泛函）**
*直觉*：正确的证书在对称变换下不该「变脸」。
*严谨*：设证书断言 C(x)（如 m(x) ≥ θ）。对群 G = SE(3) × 时间重参数化 × 保边际传感器增广，定义自洽性缺陷 δ_C(x,g) = |C(x) − C(g·x)|（不变证书）或 |C(x) − C_ρ(g·x)|（等变证书，C_ρ 为 C 的群表示）。自洽性分数 S_C = E_{x∼D_unlab, g∼G}[δ_C]。**命题（证伪性）**：若证书在 D 上 sound 且对 G 等变，则 S_C = 0；若 S_C 显著 > 0，则存在证书错误或表征错误。逆否给出**无需标签**的可疑证书发现手段。注意 S_C = 0 只是必要条件而非充分条件——这正是 CSC 的能力边界，必须靠 E89 量化。

**定义 40（统一多任务证书头与保守下界）**
*直觉*：K 个任务共享一个 z，但每个头只输出「我可保证的下界」，而不是平均预测。
*严谨*：头集合 {h_k}_{k=1..K}，h_k: Z → R（或离散标签）。证书头输出保守下界 m̂_k(z) = μ_k(z) − β_k·σ_k(z)，其中 (μ_k, σ_k) 为头的高斯/分位输出，β_k 由共形校准（定义 41）给出。多任务损失
L_MT = Σ_k w_k L_k + λ_c Σ_k L_cert,k + λ_int L_int，
L_cert,k = E[max(0, θ_k − m̂_k(z))]（强制不低于阈值），w_k 由不确定性加权（Kendall）或梯度归一化（GradNorm）。**soundness 传递条件**：若每个 m̂_k 是以 1−α_k 覆盖真实边际的共形下界，则取 α_k = α/K（Bonferroni）可得全头联合覆盖 ≥ 1−α。

**定义 41（域不变表征与加权共形证书）**
*直觉*：让「仿真里学到的」在实机上仍然「保覆盖」，必须给分布偏移定价。
*严谨*：域判别器 d_ψ(z) 与主干对抗训练，最小化潜空间 W_1(Z_sim, Z_real)（或 MMD/CMD 正则）。记密度比 r(x) = dP_real/dP_sim(x)，并以 B_r 为其上界（可由 v19 的 W_1 与紧支撑界估出）。采用**加权共形预测**（协变量偏移版）：校准样本权重 w(x) = r(x)，对任意新实机点，边际下界满足
P_real(m ≥ m̂) ≥ 1 − α − B_r·TV(P_real, P_sim)。
即权重正确时退化为标准 1−α 覆盖，权重有界误差时覆盖只线性退化。这把 v19 的经验 α_e 升级为**分布无关的共形覆盖保证**，并把「域不变表征」从工程技巧变成覆盖界的必要组件。

**定义 42（多任务干扰与负迁移界）**
*直觉*：共享主干最大的危险是「一个任务把另一个任务带沟里」。
*严谨*：任务 k 的单任务风险 R_k^single 与多任务风险 R_k^MT。定义梯度干扰 I_jk = ⟨∇_z L_j, ∇_z L_k⟩ / (‖∇L_j‖‖∇L_k‖)。在平滑且局部强凸近似下，
R_k^MT − R_k^single ≤ c·Σ_{j≠k} |I_jk|·R_j^* + O(1/√N)。
**证书安全约束**：对每个证书头 k，要求共形覆盖率不因共享而下降；否则对该头执行「主干部分冻结 + 头独立微调」的隔离（surgical fine-tuning）。

**定义 43（单主干量化运行时与多出口早退）**
*直觉*：一个 INT8 主干跑一次，所有头都受益；算力从「K 次前向」变成「1 次前向 + K 次极小头」。
*严谨*：量化后总内存 M = M_backbone + Σ_k M_head,k + M_act_shared，对比 v19 的 M_v19 = Σ_k(M_backbone,k + M_head,k)。多出口早退：在主干第 ℓ 层按头置信度提前输出，WCET 上界 = max_ℓ(ℓ 层累积 + 剩余头)。要求 p99 WCET < 100μs（Orin Nano）/ < 1ms（STM32H7），且早退不得降低共形覆盖（未完成头走单调保守降级兜底）。

**定义 44（SSL 惊喜驱动的主动反例挖掘）**
*直觉*：模型「看不懂」的地方，最值得花仿真/人工预算。
*严谨*：惊喜度 surprise(x) = α‖o − Dec(f(o))‖ + β(−log p̂(z)) + γS_C(x)。每轮选 top-B 高惊喜样本 S_t ⊂ D_unlab，只对其做仿真回放/人工标定/CEGAR，其余继续无监督。**命题（标签效率）**：在 |m − m̂| ≤ c·surprise 的假设下，同样标签预算 B 的误差下降不劣于均匀采样；以 E93 实证检验。

## 2. 四大产出设计（增量 IP-57/58/59 + 升级既有 IP）

### 2.1 IP-57 UNIVERSAL-CERT-BACKBONE（UCB，统一证书主干）
1. **主干架构**：多模态 tokenizer（图像 patch、点云体素、本体感觉 MLP、语义图 GNN）+ 时序 Transformer（因果注意力，支持流式 KV cache）；输出 z_t ∈ R^d（d = 256，边缘版 128）。
2. **三阶段预训练**：Stage-A 纯仿真无标签 SSL（mask + contrastive + equivariance）；Stage-B 仿真 + 实机混合 + 域对抗/MMD；Stage-C 多任务证书头微调（少标签 + 共形校准）。
3. **证书头**：K 个 < 8KB 的 head（线性/2 层 MLP），每头输出 (μ, σ) 双通道用于保守下界；头间加一致性正则（边际头与有效域头应相容）。
4. **共形校准器**：split conformal + 协变量偏移加权，按头/按任务维护校准集，在线监测实际覆盖率。

### 2.2 IP-58 CERT-SELF-CONSISTENCY（CSC，证书自洽性审计）
1. **群作用实现**：SE(3) 刚体变换（状态/点云）、时间缩放/反转（动力学可逆段）、传感器增广（亮度/噪声/遮挡，保边际）。
2. **自洽性检查器**：对每条证书 C 与每个 g∈G 采样，计算 δ_C；聚合为 S_C 与分区域热力图，输出「可疑证书清单」。
3. **无标签回归测试**：把 S_C 的 Top 区域自动生成回归用例入 CKB（与 v19 反例归因合并），形成不需要人工标注的持续测试。
4. **与 RAG 审计结合**：检索模板合并后先过 CSC 再进 E82；CSC 通过可降低人工确认比例，CSC 报警则强制人工。

### 2.3 IP-59 UNIFIED-EDGE-INFERENCE（UEI，单主干边缘推理）
1. **量化**：主干 QAT → INT8，头用 INT8/INT16 混合；共享激活缓冲，避免 K 套内存。
2. **多出口早退**：按头置信度/边际裕度决定出口层；早退时对未算完的头做单调保守降级。
3. **运行时调度**：L0 表命中 → 直接返回；未命中跑主干 + 多头（T0 档）；仍不行则降级 T1/T2。
4. **健康监控**：每头维护覆盖率/误 trip 滑动统计，超阈值上报总线（IP-45），触发重校准或回退 v19 独立监控器。

## 3. 四层架构 v8

```
L1: TRI-FUSE(INT8) + IP-49 LIO → 观测流 o_t
L2: 多模态 tokenizer → 共享主干 f_θ(SSL 预训练) → z_t（域不变）
    CTC + VLM + IP-35 仲裁 → 语义 token → z_t；指纹 φ/ψ = 投影头(z_t)
L3: IP-51 CAR ← 共形下界 m̂_k(z)（per-head α/K）
    IP-52 LCS: L0查表 → T0 单主干前向(多头) → 回退 T1/T2
    IP-47 组合: 头层守卫合取 + 潜接口契约
    IP-39 规划(CBF margin=m̂) → IP-45(表征健康) → IP-48/43 → IP-53(看门狗=UCB头)
L4: IP-54 SCV(surprise 驱动域随机化) → SSL 预训练/增量 → IP-55 CKB(潜近邻+复检)
    IP-58 CSC(无标签自洽性审计) → 可疑证书 → IP-50 课程 → RCA 重颁 → 热更新
运行期: L0(5μs) → 单主干INT8前向(≤100μs, 多出口) → K头 → 共形判定
        健康/惊喜监控 → 主动挖掘 → Sim/标定 → 增量预训练 → 校准更新
```

## 4. 实验设计（E87–E94 硬门槛，承接 E79–E86）

回退：E88/E90 覆盖失效 → 冻结主干并逐头重校准，或回退 v19 逐任务独立监控器；E89 CSC 无信号 → 回到 E82 全人工审计；E92 负迁移超界 → surgical freeze / 头隔离 / stop-grad；E91 超预算 → 只保留早退 + L0 查表。

## 5. 本轮最大风险

**一句话**：单一主干把 v19 的「多模型各自失效」集中成「单点共享失效」——负迁移、表征坍缩或共形校准在 Sim→Real 漂移下失效，会同时污染所有证书头与检索指纹，而且因为共享表征「看起来处处一致」而更难被察觉；因此 E88（逐头共形覆盖）、E90（域不变覆盖）与 E92（负迁移界）必须作为**红线实验**，任一不达标即冻结主干并回退 v19 的逐任务独立监控。

# 第 43 轮产物 · 创新点清单 v20：Uni-Cert 表征飞轮（UCB × CSC × UEI）× 自监督多任务共享表征（四层架构 v8）

## 2. 关键算法（伪代码）

### IP-57 UCB：自监督预训练 + 域不变 + 多任务证书头
```
def ssl_pretrain(backbone, D_unlab, G):
    for batch in D_unlab:
        o, o_aug, o_future = batch.obs, augment(batch.obs), batch.future
        z      = backbone.encode(o)
        z_aug  = backbone.encode(o_aug)
        z_fut  = backbone.encode(o_future)
        L_mask = masked_recon_loss(backbone.decode(mask_tokens(o)), o)
        L_tcl  = info_nce(z, z_fut, negatives=batch.neg)
        L_align= cross_modal_align(z.vision, z.lidar, z.proprio)
        L_equi = equivariance_loss(z, backbone.encode(apply_SE3(batch.g, o)), batch.g)
        L_reg  = vicreg_loss(z)                 # 防表征坍缩
        update(L_mask + L_tcl + L_align + L_equi + L_reg)

def domain_invariant_finetune(backbone, D_sim, D_real, disc):
    z_s, z_r = backbone.encode(D_sim), backbone.encode(D_real)
    L_domain = mmd(z_s, z_r) + adv_loss(disc, z_s, z_r)   # 潜空间 W_1/MMD
    update(L_ssl + lambda_d * L_domain)

def multitask_cert_finetune(backbone, heads, D_labeled, calib):
    for batch in D_labeled:
        z = backbone.encode(batch.obs)
        for k in heads:
            mu, sigma = heads[k](z)
            m_lo = mu - beta[k] * sigma
            L += w[k] * task_loss(heads[k], batch.y[k]) \
               + lambda_c * max(0.0, theta[k] - m_lo)
        L += lambda_int * head_consistency(heads, z)      # 头间交叉校验
        update(L)
    for k in heads:                                       # split conformal + 加权
        calib[k].fit(residuals(z_calib), weights=density_ratio(x_calib))
```

### IP-58 CSC：证书自洽性审计
```
def certificate_self_consistency(cert, backbone, D_unlab, G, n_g=8):
    scores = []
    for o in D_unlab:
        z, c0 = backbone.encode(o), None
        c0 = cert.eval(z)
        for g in sample_group(G, n_g):
            o_g  = apply_group(g, o)
            z_g  = backbone.encode(o_g)
            c_g  = cert.eval(z_g)
            scores.append(discrepancy(c0, cert.group_action(g, c_g)))
    S_C = aggregate(scores)
    hot = region_heatmap(scores)          # top 区域 -> 无标签回归用例
    return S_C, hot

def csc_gate(retrieved_templates, cert_new, cfg):
    S_C, hot = certificate_self_consistency(cert_new, cfg.backbone, cfg.unlab, cfg.G)
    if S_C > cfg.tau_CSC:
        return 'REJECT_OR_HUMAN_AUDIT', hot
    for region in hot:                   # 即便整体通过，热区仍入回归
        cfg.CKB.add_regression_case(region)
    return 'PASS', hot
```

### IP-59 UEI：单主干量化运行时与早退
```
def unified_edge_infer(o_int8, backbone_int8, heads_int8, theta, budget_us):
    key = latent_hash_quant(o_int8)
    if key in L0_table:                     # L0 命中：5μs
        return L0_table[key]
    z, exit_layer = backbone_int8.forward_with_exit(o_int8, budget_us)
    out = {}
    for k, h in heads_int8.items():
        mu, sigma = h(z)
        out[k] = mu - beta[k] * sigma       # INT16 保守下界
    for k in pending_heads(exit_layer):     # 早退未算完的头
        out[k] = downgrade_monotone(out[k]) # 单调保守降级，覆盖不降
    return out

def head_health_monitor(out, theta, calib):
    for k in out:
        calib[k].update_coverage(out[k] >= theta[k])
        if calib[k].coverage < 1 - alpha[k] - eps:
            bus.publish('REPR_HEALTH', k, calib[k].stats)  # 触发重校准/回退
```

### IP-51/52 升级：共形守卫与单次前向 LCS
```
def car_guard_conformal(e, z, cert):
    alpha_k = cert.alpha / len(cert.heads)          # Bonferroni
    m_lo = cert.heads[e].lower_bound(z, alpha=alpha_k)
    return m_lo >= cert.theta[e]

def certify_light_v3(x, guards, budget_us=150):
    b = cert_lookup_L0(x)                            # T-1 查表 (5μs)
    if decided(b, guards): return b, -1
    if budget_us < 120: return downgrade_monotone(b), -1
    z = backbone_int8.encode(x)
    b = multitask_heads(z)                           # T0 单次前向 + K 头
    if decided(b, guards): return b, 0
    return downgrade_monotone(b), 0
```

def curriculum_from_latent(D_unlab, backbone):

## 6. 本轮最大风险

**一句话**：单一主干把 v19 的「多模型各自失效」集中成「单点共享失效」——负迁移、表征坍缩或共形校准在 Sim→Real 漂移下失效，会同时污染所有证书头与检索指纹，而且因为共享表征「看起来处处一致」而更难被察觉；因此 E88（逐头共形覆盖）、E90（域不变覆盖）与 E92（负迁移界）必须作为**红线实验**，任一不达标即冻结主干并回退 v19 的逐任务独立监控。
