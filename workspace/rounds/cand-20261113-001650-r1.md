# 第 3 轮迭代（灵感循环 v3：「惯性测量单元」×「力觉传感」）—— API 抽掉了 IMU 与力传感器，却留下两根「隐性传感器」

> 承接 v2（UIP-01′~15）。v2 把宝押在「人为干扰 = 反向撤回」上，并建立了视觉滚动验证 + Gazebo 造数据/判分的主线。本轮换两个灵感词后，我先做了件反直觉的事：**先去接口目录里找这两个传感器到底存不存在**。结论是——**不存在**。`unibot_submission` 的 observation catalog（2026-11-13 核实）只有 4 路 RGB、左右臂各 7 维关节角、左右末端位姿、夹爪开度、`lower_body[15]` 与语言；**没有 IMU、没有关节力矩、没有 F/T、没有触觉**；动作侧也只能给位置目标（joint 或 ee 二选一）加夹爪与 `pivot[7]`，**没有刚度/力指令**。
>
> 所以本轮不是「加一个 IMU 模块」，而是回答一个更尖锐的问题：**在这样一个被刻意削薄的接口下，如何「无中生有」地重建本体运动感与力觉，并把它们变成可判分、可控制的信号？** 我的答案是两根隐性传感器：① **SVE**（Stereo Visual Egomotion）——用头部的标定双目当「向外的 IMU」；② **VFTE**（Virtual Force/Torque Estimator）——用「指令 vs 实测」的跟踪残差与夹爪堵转当「无传感器力觉」。旗舰也随之从「视觉单通道滚动验证」升级为 **UIP-01″ 双通道滚动验证 RHPV-DH**（视觉 + 隐性触觉，按接触状态仲裁）。

**由接口直接推出的四个硬事实：**

- **F1（无传感器）**：任何依赖原始 IMU/F/T 的方案在评测期**不可实现**；必须从「可观测量的残差」反推力与运动。
- **F2（残差即力）**：策略知道自己上一块下发的目标 `q*`/`x*`，又收到实测 `q`/`x`，因此 `r = q* − q` 或 `r = x* − x` 是**免费**的力觉代理；夹爪「命令闭合而开度停滞」也是免费的抓取接触代理。
- **F3（双目即 IMU）**：末端位姿在 **base 系**，base 被移动时它不报警；但头部双目会随 base 一起动，**场景流能反推出 base/torso 运动**——这正好补上 IMU 缺失。
- **F4（采样极限）**：块内盲区使「瞬时滑移/卡阻」不可见；但**计分相关的人为撤回是持续性状态**（人把东西拿走/拉开后不会瞬间复原），因此边界采样足以检测撤回；高频力觉的真正价值在**接触密集步的一次做对**。

## 2. 两个灵感词：先直觉，再严谨定义

### 2.1 「力觉传感」→ VFTE：被挡住的目标，就是力的读数

**直觉。** 一个位置控制的机械臂去推一个不动的物体，它不会「显示 5N」，它只会**跟不上目标**。目标与实际之间的差，就是力在关节空间留下的脚印。夹爪也一样：命令它闭合，它停在某个宽度不再动——它已经「摸到」物体了。我们不需要 F/T，只需要**记录自己下过什么命令，再对比观测到了什么**。

**严谨定义。** 设第 `t` 次调用时，策略已知上一块最后一个目标 `q*_t`（joint）或 `x*_t`（ee），评测端返回 `q_t` 或 `x_t`。定义跟踪残差

```
r_t = q*_t − q_t            (joint)
r_t = x*_t − x_t            (ee, 米/弧度)
```

在低层 PD 跟踪下，外部关节力矩可近似为 `τ_ext ≈ K_p r_t + K_d ṙ_t + g(q_t)`；`K_p, K_d, g` 未知，所以**不做绝对力回归**，只做**事件检测**。用回合开头的自由空间段估一个基线 `r_free(t)`，标准化

```
ρ_t = (r_t − r_free_t) / σ_r
```

并抽取特征 `(|ρ|, d|ρ|/dt, 符号一致性, 持续时间, 夹爪堵转 s_t = g_cmd − g_obs, Δ开度)`，映射到事件字母表

```
E_t ∈ { free, touch, load, slip, jam, seat, release }
```

其中：`touch`=短促残差出现；`load`=持续同号残差；`slip`=夹爪开度在闭合指令下缓慢增大或物体相对位移；`jam`=残差上升且末端速度趋零；`seat`=残差先升后骤降并伴随小幅回弹；`release`=载荷消失且夹爪开度变化不是自己命令的。`E_t` 带置信度交给 UIP-01″/HVP。

**为什么这在数据上可行。** 公开数据集虽然不含力矩，但**含 (action, observation.state) 对**：`action.left_arm/right_arm` 是关节目标，`observation.state.left_arm/right_arm` 是实测——离线就能算出 `r_t` 的分布；`action.left_gripper` 与 `observation.state.left_gripper` 也能算堵转。等于说，**力觉的监督信号可以零成本从 32 个数据集里挖出来**，再用 Gazebo 的接触真值校准阈值（UIP-11′/UIP-20）。

### 2.2 力觉的采样极限：撤回是持续的，滑移是瞬时的

**直觉。** 开环块像「闭眼走 N 步」。人把毛巾翻开后不会 50ms 内复原，所以下一次睁眼一定看得见；但插头在孔口滑了一下又停住，闭眼期间就错过了。

**严谨定义。** 信息采样周期 `T_s = T_a / f_control`，块内死区 `τ_d = T_s`。对持续时长 `τ_r` 的进度撤回：若 `τ_r ≫ τ_d`，边界采样即可检测；若 `τ_r < τ_d`，需要减小 `T_a` 或在块内插入「探针」。因此 v3 把策略分成两类节拍：

- **慢节拍（大块）**：自由空间搬运、远离接触，追求低延迟与低往返；
- **快节拍（小块 + 探针）**：接触密集步，追求「末端状态可判别」，而不是追求高频闭环。

**关键推论：** 不要试图用块内高频力控去救撤回检测；撤回检测交给边界视觉 + SVE。**力觉的高频价值在「接触执行」**（防卡阻、找孔、控法向力）。

### 2.3 「惯性测量单元」→ SVE：双目是向外的 IMU

**直觉。** 比赛拿走了 IMU，但给了你两只已经标定好的眼睛。你不需要知道「我的角速度是多少」，你只需要知道「这一帧到下一帧，世界相对我转了多少、移了多少」——这正是视觉里程计。短基线、桌面尺度、只在块边界算一次，**不需要全局 SLAM，只需要变化检测**。

**严谨定义。** 对校正后的头部双目，视差 `d = f b / Z`，度量深度

```
Z = f b / d,      ΔZ ≈ (Z² / (f b)) · Δd
```

用数据集的 `camera_params`：`f≈282 px`、`b≈58.25 mm`。于是 `ΔZ/px` 在 `Z=0.3/0.5/1.0 m` 处约为 **5.5 / 15.2 / 60.9 mm**；亚像素匹配（0.2~0.5 px）可压到 **1~3 / 3~8 / 12~30 mm**。这足以做「物体在不在/被移动了多少/堆叠高度变化」的**在线几何判分**，但不足以做「插头插深 2mm」——后者交给腕部相机。

对块边界的两帧，提特征并匹配，解本质矩阵/PnP 得相机运动 `ΔT_t ∈ SE(3)`；再用相机-基座外参换到 base/torso：

```
Δξ_base ≈ Ad(T_base←cam) · Δξ_cam
```

当 `Δξ_base` 与 `pivot` 指令不一致（或 pivot 指令为零却有基座运动）→ **base 被人移动**。当 `ΔT_t≈0` 但场景中某物体的 3D 位置 `X_obj` 发生位移 → **物体被人移动**（拿走锁、挪碗、翻毛巾）。两条判据分别覆盖「动底座」与「动物体」。

**为什么它比关节角更接近 IMU。** `lower_body[15]` 是关节角；整机被平移时，腿部与腰部关节角可以完全不变，末端位姿又在 base 系里也看不出。**只有相机看到的外部世界能告诉你「你被移动了」。** 这是本轮对「IMU」最忠实的落地。

### 2.4 位置接口下的「力控」→ AWC：用一个虚拟弹簧把位置策略变软

**直觉。** API 只让你发位置目标，但你可以让目标本身「退让」：感到阻力就把目标往回收一点。这就是导纳控制——**用软件弹簧模拟柔顺**，不需要力矩指令。

**严谨定义。** 给定名义策略输出 `x_d` 与 VFTE 估计 `ŵ`，解一阶导纳

```
M ẍ + D ẋ + K x = ŵ,     x_cmd = x_d + x
```

离散到块边界，得到 `x_cmd,t = x_d,t + K_a^{-1} ŵ_t`（关节空间则 `q_cmd = q_d + K_q^{-1} Jᵀ ŵ`）。对插入类任务叠加**力门控搜索**（螺旋/锯齿），只有 `E_t ∈ {seat, load}` 才推进下一计分步。因为力估计只在块边界更新，AWC 是**低带宽导纳**；它必须与 HPCD（接触段用小 `T_a`）配合，而不是假装成高频力控。

## 3. 瓶颈假设（v3 更新）

- **H1（自修正）**：人为撤回多数发生在**脱离接触**之后，力觉对它们的覆盖率有限（估计 11 个撤回任务里只有约 3~5 个在撤回瞬间机器人仍在接触/持握）。因此**视觉/SVE 仍是撤回检测主通道**；把力觉当主武器会误判覆盖率。
- **H2（新最高杠杆）**：32 任务的主要失分其实来自**接触密集步一次做不对**（插网线 T26、插头 T10、开锁 T12、拧药瓶 T14、拉链 T19、合盖 T17、针管 T32、耳机 T28）。这些步的共同点是**视觉被手/物体遮挡，且成败由接触状态决定**。VFTE + AWC 正对这块。
- **H3**：`r_t = q*−q` 的**绝对值**被重力、摩擦、PD 增益、关节柔度污染；但**同回合内的相对变化**和**事件形状**鲁棒。只做事件，不做力回归。
- **H4**：头部双目基线仅 58mm，1m 处深度误差可达 3~6cm；适合「物体位移/在场/大致高度」，不适合「毫米级插入」。**SVE 做结构判分，腕部相机做精细判分。**
- **H5**：块内盲区是信息论约束，不是工程 bug；正确做法是**把问题放到块尾**（探针 + 保持），而不是无限缩小块长牺牲延迟。
- **H6**：`control_space` 全局只能选一次。若选 `ee`，AWC 最自然；若选 `joint`，需在策略内做 IK/雅可比转置。这是**提交级架构决策**，不是运行期可切换项。
- **H7**：Gazebo 的接触刚度/摩擦与真机差异大，VFTE 的阈值迁移必须靠少量真机自由空间 + 接触标定（UIP-20），否则「仿真里摸得准、真机里全是误触」。

## 4. 候选与合并（详见产物区）

围绕两个词发散 10 个草案，合并后得到 v3：**升级 6 个（01″/11′/12′/13′/15′/17）、新增 5 个（16/18/19/20 + 17 独立成条）、合并 1 个（09′）、保留 3 个（02′/05/08′/14）**。旗舰是 **UIP-01″ RHPV-DH**，但它的「力觉腿」被重新定位为**接触执行与次级撤回证据**，而不是撤回检测主通道。最值得单独押注的，是 **UIP-16 VFTE × UIP-19 AWC 组成的「无传感器柔顺执行」**——它直接攻 H2 的接触密集失分，且完全落在位置接口与现有数据之内。

## 5. 本轮最大风险

**一句话**：最大的风险不是「力觉不准」，而是**把跟踪残差当成真力传感器去闭环**——残差里混着重力、摩擦、PD 增益与块间延迟，绝对值一偏，导纳就会震荡甚至撞坏物体；必须把 VFTE 限定为**带弃权的离散事件证据**，把 AWC 的增益压到保守区，并用 UIP-15′ 的探针安全阀兜底。

## 1. 旗舰深潜：UIP-01″ · RHPV-DH（Rolling-Horizon Progress-Verified with Disturbance & Haptics）

### 1.1 架构

```
obs_t ──┬─► 视觉验证器 V_vis(obs_t, step) ──────────┐
        ├─► VFTE: r_t = cmd_{t-1} − obs_t ──► HVP ──┤
        ├─► SVE: 双目视差/特征跟踪 ──► ΔT, ΔX_obj ──┤
        └─► 技能图/计分步上下文 ────────────────────┤
                                                    ▼
                                    三源 log-odds 融合 + 弃权
                                                    ▼
                          {done, ongoing, fail, regressed, ambiguous}
                                                    ▼
                        HPCD 选 k / 探针 → 策略出块 → AWC 导纳包装 → action
```

### 1.2 与 v2 的差异

- v2 的 `regressed` 只靠**视觉时序差分**（子目标从 done 回退到 undone）。
- v3 增加两条证据：
  1. **接触内撤回**：`E_t ∈ {release, reverse-load, slip}` 且物体相对位姿反向 → 在视觉尚未稳定前给出早期 `regressed`（典型：T14 拧回、T19 拉开、T10 拔起）。
  2. **脱离接触撤回**：SVE 检测到物体 3D 位置/朝向被改变，或 base 被移动 → 视觉慢通道确认（典型：T12 拿走锁、T16 翻开、T17 再打开、T25 挪底座）。
- 增加 **`ambiguous` 状态**：三源都不够自信时**不动作**（继续当前子目标或做一次低成本探针），避免「误判 regressed → 反复重做」把步骤分和可信度一起烧掉。

### 1.3 仲裁规则（in-contact vs out-of-contact）

定义接触指示 `c_t ∈ {0,1}`：`c_t=1` 当且仅当夹爪闭合且 `E_t ∈ {load, jam, seat}`，或末端残差持续超过自由基线 `3σ`。则

```
if c_t = 1:   先信 HVP 的快通道；视觉用于确认最终几何
if c_t = 0:   先信 V_vis / SVE；VFTE 只提供「载荷突然消失」这一弱证据
if 两源冲突:  状态置 ambiguous，优先「重做当前子目标」而非「跳到下一步」
```

**这条规则是本轮最重要的工程判断**：多数 `human_*` 撤回发生在机器人松手之后，此时机器人感受不到力；把力觉当主通道会漏检。

### 1.4 三源融合的严谨形式

对每个计分步 `g` 维护 done 的对数几率：

```
L_g(t) = L_g(t−1) + w_v·ℓ_vis + w_h·ℓ_hap + w_s·ℓ_sve − λ·1[step changed]
```

其中 `ℓ_*` 是各通道的证据（视觉：子目标谓词成立/不成立；触觉：事件字母表与期望签名的匹配度；SVE：物体 3D 谓词/位移）。`w_*` 由离线标定得到（UIP-20）。当 `max_g L_g` 与次大值差小于 `δ`，或所有单源置信度低于阈值，置 `ambiguous`。`regressed` 用**反向证据**单独累计，避免与 done 证据互相抵消。

## 2. UIP-16 · VFTE：无传感器力/力矩估计

### 2.1 可观测量与残差

| 控制空间 | 策略已知的目标 | 观测到的状态 | 残差 |
|---|---|---|---|
| `joint` | `q*_t ∈ R^7`（每臂） | `q_t`（`observation.state.*_arm`） | `r_t = q*_t − q_t` |
| `ee` | `x*_t ∈ SE(3)` | `x_t`（`*_ee_pose_gripper_base`） | `r_t = x*_t − x_t`（米/弧度） |
| 夹爪 | `g*_t` | `g_t`（`*_gripper`） | `s_t = g*_t − g_t` |

在 PD 跟踪下 `τ_ext ≈ K_p r + K_d ṙ + g(q)`。由于 `K_p, K_d, g` 未知且随姿态变化，**不做绝对力回归**，而是：

1. 用回合开头的自由空间段（或离线数据）估基线 `r_free(q, direction)`；
2. 标准化 `ρ_t = (r_t − r_free_t)/σ_r`；
3. 抽特征 `φ_t = [|ρ|, d|ρ|/dt, sign consistency, duration, s_t, dg_t/dt, |Δx_ee|]`；
4. 事件分类 `E_t = f_θ(φ_t)`，`θ` 由 Gazebo 接触真值预训练、真机少量校准。

### 2.2 事件字母表与物理签名

| 事件 | 残差/夹爪签名 | 典型任务 |
|---|---|---|
| `free` | `|ρ|<1`，`s≈0` | 自由空间搬运 |
| `touch` | 短促 `|ρ|` 上升后回落，无持续载荷 | 接近物体、合盖前 |
| `load` | 持续同号 `ρ`，`|ρ|` 稳定 | 抓取后持握、拉链受力 |
| `slip` | 闭合指令下 `g_obs` 增大，或物体相对位移而夹爪未动 | 光滑物体、耳机 T28 |
| `jam` | `|ρ|` 上升、末端速度趋零、无 `seat` 回弹 | 插网线 T26、插头 T10 |
| `seat` | `|ρ|` 先升后骤降 + 小幅回弹 | 插到底、拉链到位、拧到底 |
| `release` | 载荷突然消失，`g_obs` 变化非自己命令 | 人把物体拿走/拉脱 |

### 2.3 从公开数据零成本挖监督

数据集含 `action.left_arm/right_arm` 与 `observation.state.left_arm/right_arm`，离线即可算 `r_t`；夹爪同理。虽然**没有力矩真值**，但可以：
- 用视觉/几何谓词给「接触/非接触」弱标注；
- 用 Gazebo（UIP-11′）给接触力真值；
- 用「动作与状态的符号关系」自监督 `seat/jam/release` 的形状。

这使 VFTE 不需要任何新传感器，也不违反「单模型」——事件分类器可以是从主骨干蒸馏出的小头，或纯规则。

### 2.4 关键限制（必须写进论文/汇报）

- 残差含重力、摩擦、关节柔度、控制器滞后；**绝对力不可信**。
- 只在**机器人接触/持握**时可观测；人脱离接触动物体时 VFTE 无信号。
- 开环块使 `ṙ` 只能用块边界差分，高频信息丢失。

## 3. UIP-17 · HVP：触觉验证进度（含 09′ 合并）

### 3.1 机制

为每个计分步定义**期望接触事件序列**（来自技能图 UIP-14 的节点注解），运行时用 VFTE 的事件流做正则匹配：

```
done      ⇐ 期望序列完成（如 insert: touch → load → seat）
regressed ⇐ 反向序列（如 release 后物体反向位移；或 load 符号翻转且视觉位置回退）
fail      ⇐ jam/load 持续超时且无 seat
ambiguous ⇐ 事件稀疏或与期望不符但无反向证据
```

与视觉的融合见 §1.4。HVP 的 `regressed` 分支直接吸收 v2 的 UIP-09′。

### 3.2 对 11+ 个撤回型干扰的覆盖率（诚实拆分）

| 任务 | 撤回动作 | 撤回瞬间是否在接触/持握 | 主通道 | 力觉能否提前 |
|---|---|---|---|---|
| T08 | 抓书后挪架子 | 否（书在手上，架子被移） | 视觉/SVE | 否 |
| T10 | 拔起插头 | **是**（若仍握插头） | VFTE + 视觉 | **能** |
| T11 | 抓后动绿盒 | 否 | 视觉/SVE | 否 |
| T12 | 中途把锁拿走 | 通常否 | 视觉/SVE | 否 |
| T14 | 拧开后再拧回去 | **是**（若仍握盖） | VFTE 扭矩反向 + 视觉 | **能** |
| T16 | 叠好后翻开 | 否 | 视觉/SVE | 否 |
| T17 | 合上后再打开 | 否 | 视觉/SVE | 否 |
| T19 | 拉上后再拉开 | **是**（若仍握拉头） | VFTE 载荷反向 + 视觉 | **能** |
| T24 | 把货放回起点 | 否 | 视觉 | 否 |
| T25 | 放第一个后挪底座 | 否（动 base） | SVE/视觉 | 否（但 SVE 能） |

**结论**：力觉对撤回检测的直接覆盖只有约 **3~5/13**；**SVE/视觉才是撤回主通道**。力觉的主价值必须落在 §4 的接触执行上。这是对 v2 押注的明确修剪。

## 4. UIP-18 · SVE：立体视觉自运动与在线 3D

### 4.1 机制

- 头部 `cam_left_high/cam_right_high` 是已校正立体对（`f≈282 px`，`b≈58.25 mm`，`rectified=true`）。
- 视差 → 度量深度 `Z = fb/d`；特征跟踪 + 本质矩阵/PnP → 相机运动 `ΔT_t`；用相机-基座外参转成 `Δξ_base`。
- 同时输出关键物体/桌面标记的 3D 位置 `X_obj(t)`。

### 4.2 三种用途

1. **base/桌面被移动检测**：`pivot` 指令为零但 `Δξ_base≠0`，或 `Δξ_base` 与指令不一致 → 报警。补上「无 IMU」的缺口。
2. **物体被移动检测**：`ΔT≈0` 但 `X_obj` 跳变 → 人为拿走/挪动（T12/T16/T17/T25/T27/T29）。
3. **在线几何判分**：堆叠高度（T27）、盘子位置（T21）、试管排列（T13）、水果分类（T04）、纸杯堆叠（T20）等可直接用 3D 谓词判，不必等 Gazebo 离线。

### 4.3 深度误差与适用边界

`ΔZ ≈ Z²/(fb)·Δd`，取 `f=282 px`、`b=0.05825 m`：

| 距离 Z | 视差 d | 每像素深度误差 | 亚像素 0.3px 误差 |
|---|---|---|---|
| 0.3 m | 54.8 px | 5.5 mm | ~1.6 mm |
| 0.5 m | 32.8 px | 15.2 mm | ~4.6 mm |
| 1.0 m | 16.4 px | 60.9 mm | ~18 mm |

因此：**SVE 做结构/在场/大致高度，腕部相机 + 视觉做毫米级插入**。SVE 不追求全局 SLAM，只在块边界做短时变化检测，漂移可控。

## 5. UIP-19 · AWC：位置接口下的导纳包装

### 5.1 机制

名义策略输出 `x_d`（或 `q_d`），VFTE 给出 `ŵ`，解一阶导纳：

```
M ẍ + D ẋ + K x = ŵ
x_cmd = x_d + x
```

离散到块边界：`x_cmd = x_d + K_a^{-1} ŵ`；关节空间：`q_cmd = q_d + K_q^{-1} Jᵀ ŵ`。对插入类任务叠加**力门控搜索**：

```
spiral(r) 直到 E_t ∈ {seat, load}；否则继续搜索，超时则回退重试
```

### 5.2 为什么这是「位置接口下的力控」

API 不接受刚度/力矩，但接受**位置目标序列**。AWC 通过让目标随估计力退让，等效实现低带宽导纳。它不是高频力控（力只在块边界更新），所以必须与 HPCD 配合：接触段用小 `T_a`，自由段用大 `T_a`。

### 5.3 `control_space` 的全局决策

`control_space` 只能全局选一次：
- 选 `ee`：AWC 最自然，直接笛卡尔导纳；适合接触密集任务。
- 选 `joint`：保留关节策略，AWC 用 `Jᵀ` 实现；需要 IK/雅可比与限位处理。
- 建议：若主策略以 ee 扩散/流匹配为主 → 选 `ee`；若以关节模仿为主 → 选 `joint`。**不要**假设运行期可切换（v2 UIP-10 已确认不可行）。

## 6. UIP-13′ · HPCD：信息增益块调度 + 探针

### 6.1 信息论形式

块内盲区使策略的信息率 = `1/T_s`。对当前接触状态 `E`，定义块长 `k` 的信息增益

```
IG(k) = H(E) − H(E | o_{t+k})
```

选择 `k* = argmax_k IG(k)/(k·Δt)`。工程近似：用事件分类器的**熵/集成 disagreement** 作为 `IG` 的代理。

### 6.2 探针设计（把问题放到块尾）

- **接触前**：末端接近 + 最后 2~3 步「轻推并保持」，让 PD 瞬态衰减，下一次观测的残差更干净。
- **插入**：螺旋/锯齿搜索 + 短保持；`seat` 一出现立即停止搜索。
- **拉链/合盖**：沿任务方向施加小幅往复，用 `load` 的符号与回弹判到位。
- **自由空间**：大块直线运动，不做探针。

### 6.3 伪代码

```python
def choose_k(self, state, skill):
    if state in ("regressed", "ambiguous"):
        return min(self.K_MAX, 2)          # 快节拍确认
    if skill.contact_phase in ("insert", "zip", "screw", "seat"):
        return 2                            # 接触段小块
    return self.K_MAX                       # 自由段大块

def make_probe(self, x_d, skill):
    if skill.contact_phase == "insert":
        return x_d + spiral(self.r, self.phase) + hold(2)
    if skill.contact_phase in ("zip", "seat"):
        return x_d + reciprocate(self.direction, self.amp) + hold(2)
    return x_d
```

## 7. UIP-20 · HSC：隐性传感器标定协议

VFTE/SVE 的成败在标定，不在公式。协议分四步：

1. **自由空间残差基线**：用公开数据 + 真机自由运动，拟合 `r_free(q, direction)`；按关节/方向分桶，取稳健均值与 `σ_r`。
2. **等效 PD 增益辨识**：下发小幅阶跃目标，记录超调/稳态误差，估 `K_p, K_d` 的量级（只需相对值）。
3. **Gazebo 接触真值对齐**：UIP-11′ 输出接触力/残差，拟合 `φ_t → E_t` 的阈值或小分类器；域随机化接触刚度/摩擦。
4. **真机少量锚点**：10~20 次自由空间 + 接触试验（可用已知砝码/弹簧），校准阈值并报告**自由空间误报率**与**检测延迟**。

SVE 另需标定**相机-基座外参**：用 Gazebo 已知变换初始化，真机用桌面标记/棋盘格微调。

## 8. 集成伪代码（UIP-01″ + 16 + 17 + 18 + 19 + 13′ + 15′）

```python
class RHPVDH_Policy:
    def __init__(self, policy, vision, vfte, hvp, sve, awc, hpcd, csg,
                 K_MAX=8, conf_thr=0.6, max_redo=2):
        ...
    def reset(self):
        self.policy.reset()
        self.g = 0
        self.redo = 0
        self.prev_cmd = None
        self.contact = False
        self.vfte.reset(); self.hvp.reset(); self.sve.reset()

    def get_action(self, obs):
        r = None if self.prev_cmd is None else self.prev_cmd - self._state(obs)
        E, conf_e = self.vfte.update(r, obs, self.prev_cmd)
        ego, depth = self.sve.update(obs)
        v, conf_v = self.vision.verify(obs, self.g)
        self.contact = self._is_contact(E, obs)

        st = self.hvp.fuse(v, conf_v, E, conf_e, ego, depth, self.contact)
        if st == "done":
            self.g += 1; self.redo = 0
        elif st == "regressed" and self.redo < max_redo:
            self.redo += 1
        elif st == "fail" and self.redo < max_redo:
            self.redo += 1
        elif st == "ambiguous":
            pass                                   # 不前进，做低成本探针

        k = self.hpcd.choose_k(st, self.skill(self.g))
        x_d = self.policy.get_action(obs, k)
        x_d = self.hpcd.make_probe(x_d, self.skill(self.g))
        x_cmd = self.awc.wrap(x_d, self._last_wrench(E))
        x_cmd = self.csg.clip(x_cmd, E)            # 探针力/位移/时长上限
        self.prev_cmd = x_cmd[-1]
        return x_cmd
```

## 11. 合规与风险

- **单模型合规**：VFTE/HVP 优先用**规则 + 从主骨干蒸馏的小头**；不引入外部 VLM/大模型作为在线裁判。
- **力觉覆盖有限**：不要把 HVP 宣传成「撤回检测主武器」；明确它只覆盖接触内撤回（约 3~5/13）。
- **绝对力不可信**：只做事件，不做力回归；所有力结论标注为「代理」。
- **双目深度边界**：1m 处 3~6cm 误差；精细步用腕部相机。
- **块内盲区**：不追求块内高频力控；用探针 + 小块解决。
- **`control_space` 全局固定**：提交前一次选定，运行期不切换。
- **探针安全**：UIP-15′ 限制最大法向力/位移/时长；宁可失败也不损坏道具。
- **手册未知**：控制频率、时限、base 是否锁定、关节状态是否含速度，仍需真机/手册核实。
- **离线数据使用**：从公开数据挖残差是允许的；但不得把评测期未暴露的键（如 `state_torso`）当作输入。

## 13. 本轮最大风险 & 押注

**一句话**：把跟踪残差当真力传感器去闭环，是这一轮最容易犯、也最致命的错误——残差里的重力/摩擦/PD 增益/延迟一旦被当成「力」，导纳会震荡、探针会撞坏道具；必须坚持「事件 + 弃权 + 安全阀」。

**→ 本轮押注：UIP-16 VFTE × UIP-19 AWC 的「无传感器柔顺执行」**——它不依赖任何被 API 拿掉的传感器，直接攻 A 组接触密集任务（榜单难度与分值的主战场），并由 UIP-11′/UIP-20 提供离线真值与标定；撤回检测则明确交回视觉/SVE，避免重蹈「力觉万能」的过度承诺。
