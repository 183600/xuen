### 第 5 轮灵感驱动研究记录

**灵感词**：通信延迟、长期记忆

**继承关系**：第 4 轮 CADVS-v4（IP-489~492）在 v3 五锚点之上追加价值锚 VACK（kc_val）与平衡锚 BCK（kc_bal），形成七硬门 kc_evidence_forged_v4 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem ∧ kc_val ∧ kc_bal，fail-closed；软评分 ECS_v4 = ECS_v3 · η_val · η_bal；执行集 Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。本轮不推翻 v4，而是补上 v4 全程回避的一个维度——**时间**：v4 的证书是「无时间戳的真值」，默认「签发即当下、当下即有效」。真实系统里证书要跨网络传输（通信延迟），记忆要跨会话存活（长期记忆）。本轮把「时效」提升为一等公民，形成 CADVS-v5（IP-493~496），执行集升级为 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。

**直觉与动机**：

1. **通信延迟：v4 的 fail-closed 只防「证据缺失」，不防「证据过期」**。v4 的 EEC/BCC/VAC 一旦签发就被当作永久真值消费；但在联邦/云边架构下，一张在站点 A 于 t₀ 签发、声称「末端力在容差内」的证书，可能在 t₀+50 ms 才到达执行端，而接触状态在这 50 ms 内已经改变。此时证书内容为真（历史事实），但对「现在」已失效。更隐蔽的是时钟偏斜：跨站时间戳若不可比，age 计算本身就会错。v5 引入时态证书 TC = (c, [t_s, t_e], clk_id, prov) 与时效硬门 kc_fresh（age ≤ TTL ∧ 时钟偏斜有界），把「证据是否为真」细化为「证据在消费它的那一刻是否仍然为真」。TTL 不是拍脑袋常数，而是由网络演算的端到端延迟上界 D_max 与各锚点的环境漂移率 ρ 共同标定：TTL_i = min(TTL_i^max, ε_i/ρ_i)，并要求 D_max + ε_proc ≤ TTL_i。后者给出**远程可消费性条件**：若延迟超过环境容许的时效窗，则该证据不能远程消费，必须在边缘本地重算或 fail-closed——延迟直接决定了证据计算的放置位置。

2. **长期记忆：LTEM 只是「表」，不是「会遗忘、会巩固的记忆」**。v3/v4 的 LTEM 把 (n_succ, n_fail, t_succ, t_fail, ...) 当作静态计数，隐含假设「十年前的一次成功与昨天的一次成功等权」。这与生物长期记忆的三条基本事实矛盾：(a) **遗忘曲线**（Ebbinghaus）：记忆强度随时间指数衰减；(b) **间隔强化**（spacing effect）：被反复成功检索的记忆衰减更慢；(c) **巩固与再巩固**（consolidation/reconsolidation）：情景记忆经巩固转为语义先验，环境变点时旧记忆需被重新打开。v5 引入长期记忆巩固 LHMC：记忆强度 S(t) = S₀e^{−λ(t−t_last)} + Σ reinforcement；用指数加权的 Beta 充分统计量替代裸计数，kc_mem 升级为衰减后验的下置信界 kc_mem^τ；情景→语义巩固对指数族是充分统计量的合并（近似无损），变点检测触发再巩固（重置或降权旧证据）。

3. **统一视角：延迟与遗忘是同一种病——证据的时间衰减**。延迟是「空间搬运造成的时间差」，遗忘是「时间累积造成的信息衰减」，两者都使一张曾经为真的证据在消费时刻不再可靠。因此 v5 不把二者做成两个孤立补丁，而是共用一套「时态证书演算」：证书带有效期，记忆带衰减强度，硬门在消费时刻检查「是否仍然新鲜/可靠」。这也让 v4 的时序投影 □_T 从理想化算子变成有真实时钟语义的算子。

**关键洞见**：v4 回答「证据是否为真」，v5 回答「证据在消费它的那一刻是否仍然为真」。新增时效锚 DACK（kc_fresh）与长期记忆巩固 LHMC（kc_mem^τ），把证书从布尔命题升级为带有效期的时态命题；理论内核从「静态证书格」升级为「时态证书演算」，给出时效可靠性定理、延迟鲁棒收缩定理、记忆巩固信息保持界，以及安全-可用性不可兼得的下界。八硬门 kc_evidence_forged_v5 = kc_evidence_forged_v4 ∧ kc_fresh（且 kc_mem 收紧为 kc_mem^τ），fail-closed；软评分 ECS_v5 = ECS_v4 · η_fresh · η_memτ。

**形式化目标（增量）**：
1. 定义时态证书 TC = (c, [t_s, t_e], clk_id, prov)、age(t) = t − t_s、kc_fresh = (0 ≤ age ≤ TTL) ∧ (|Δclk| ≤ ε_clk) ∧ (t ≤ t_e)。
2. 定义网络演算延迟界 D_max(α, β) 与 TTL 标定 TTL_i = min(TTL_i^max, ε_i/ρ_i)；定义远程可消费性条件 D_max + ε_proc ≤ TTL_i，及其不满足时的边缘本地化/停机分支。
3. 定义 LHMC：强度 S_i(t)、指数加权 Beta 充分统计量 (a_eff, b_eff)、kc_mem^τ = LCB_δ(a_eff, b_eff) ≥ τ_mem、巩固算子 Cons 与变点再巩固 ReCons。
4. 定义时态证书演算：□_[0,T]、◇_[0,T]、since S、until U；时钟约束与有界时窗可判定片段。
5. 定理：时效可靠性（Lipschitz 漂移下 TTL 内谓词保持）；延迟鲁棒单调收缩 Exec_v5 ⊂ Exec_v4；记忆巩固信息保持界（指数族充分统计量 + 偏差-方差权衡 MSE ≤ (κ/λ)² + O(1/n_eff)）；安全-可用性下界（重尾延迟下不存在静态 TTL 同时零过期放行、零误停机）。
6. 定义 EFA-v5 八硬门 + 软评分 ECS_v5 = ECS_v4 · η_fresh · η_memτ。
7. 定义 Exec_CADVS-v5 ⊆ Exec_CADVS-v4：v4 每条路径追加 kc_fresh，且 kc_mem 替换为更严的 kc_mem^τ，故只缩不涨；严格性由「非过期但已过期」的构造例保证。

**本轮最大风险**：**TTL 与延迟预算的标定在真实网络抖动下可能失准**——ρ 低估会放行过期证据（安全违例），ρ 高估或 TTL 过短会让 fail-closed 频繁触发（可用性雪崩）；在环境漂移率 ρ>0 且端到端延迟重尾时，静态 TTL 无法同时消除这两种失效，只能转移风险。

## 2. 关键算法骨架

### IP-493 DACK：时效证书核（控制环内 O(1)；TTL 标定离线）

**直觉**：把每张证书看作一瓶有保质期的药。`kc_fresh` 只做三件 O(1) 的事——读年龄、比保质期、校时钟。真正贵的「保质期怎么定」在离线用网络演算与漂移率算好，控制环不碰。

```python
@dataclass
class DelayAwareCertificateKernel:
    """DACK：时态证书 + kc_fresh；TTL 由离线网络演算/漂移率标定"""
    clock: MonotonicClock
    ttl_table: dict[str, float]        # anchor -> TTL (s)，离线标定
    skew_bound: float = 1e-4           # 允许的跨域时钟偏斜 (s)
    proc_margin: float = 2e-4          # 端侧处理/排队抖动 (s)

    def issue(self, c: Certificate, anchor: str, prov: Provenance) -> TimedCert:
        t = self.clock.now()
        ttl = self.ttl_table[anchor]
        return TimedCert(cert=c, t_s=t, t_e=t + ttl, clk_id=self.clock.id, prov=prov)

    def kc_fresh(self, tc: TimedCert, anchor: str, t_now: float) -> bool:
        """O(1)。跨域证书若时钟不可比，fail-closed。"""
        if tc.clk_id != self.clock.id:
            if not self.clock.comparable(tc.clk_id, self.skew_bound):
                return False
        age = t_now - tc.t_s
        return (0.0 <= age <= self.ttl_table[anchor]) and (t_now <= tc.t_e)

    def eta_fresh(self, tc: TimedCert, anchor: str, t_now: float) -> float:
        age = max(0.0, t_now - tc.t_s)
        return float(np.clip(1.0 - age / self.ttl_table[anchor], 0.0, 1.0))

    # ---- 离线标定（不在控制环） ----
    @staticmethod
    def calibrate_ttl(rho: float, eps: float, ttl_max: float) -> float:
        """TTL = min(TTL_max, eps/rho)；rho 低估->过期放行，高估->误停机。"""
        return min(ttl_max, eps / max(rho, 1e-9))

    @staticmethod
    def delay_bound(alpha: Callable, beta: Callable) -> float:
        """网络演算：D_max = sup_s inf{tau : alpha(s) <= beta(s+tau)}。"""
        ...

    def remote_consumable(self, anchor: str, d_max: float) -> bool:
        """RCC：延迟必须落在时效窗内，否则证据只能边缘本地算或停机。"""
        return d_max + self.proc_margin <= self.ttl_table[anchor]
```

### IP-494 LHMC：长期记忆巩固（检索 O(1)；巩固/再巩固离线或事件驱动）

**直觉**：v4 的 LTEM 把「一次成功」当成永久加一票。真实的长期记忆会遗忘，但反复成功会让遗忘变慢；把许多次情景记忆巩固成一条语义先验；环境突变时旧记忆要「再巩固」，否则会把机器人锁死在旧世界。

```python
@dataclass
class LongHorizonMemoryConsolidation:
    """LHMC：指数遗忘 + 间隔强化 + 情景->语义巩固 + 变点再巩固"""
    lam: float = 1e-6                  # 遗忘率 (1/s)，越大约易忘
    tau_mem: float = 0.5               # kc_mem^τ 阈值
    delta: float = 0.05                # 下置信界置信水平
    change_pt_z: float = 4.0           # 变点检测阈值

    def strength(self, e: MemEntry, t_now: float) -> float:
        return e.S0 * math.exp(-self.lam * (t_now - e.t_last)) + e.reinforce(t_now)

    def effective_stats(self, e: MemEntry, t_now: float) -> tuple[float, float]:
        """指数加权 Beta 充分统计量：a_eff, b_eff（增量维护，O(1) 读取）。"""
        a = e.a0 + sum(w * x for w, x in e.decayed_counts(t_now, self.lam))
        b = e.b0 + sum(w * (1 - x) for w, x in e.decayed_counts(t_now, self.lam))
        return a, b

    def kc_mem_tau(self, e: MemEntry, t_now: float) -> bool:
        a, b = self.effective_stats(e, t_now)
        return self._beta_lcb(a, b, self.delta) >= self.tau_mem

    def eta_mem(self, e: MemEntry, t_now: float) -> float:
        a, b = self.effective_stats(e, t_now)
        return float(np.clip(self._beta_lcb(a, b, self.delta) / self.tau_mem, 0.0, 1.0))

    def reinforce(self, e: MemEntry, success: bool, t: float) -> None:
        """间隔强化：成功检索使 S0 提升、t_last 前移；衰减因此变慢。"""
        e.S0 = e.S0 * math.exp(-self.lam * (t - e.t_last)) + (1.0 if success else 0.0)
        e.t_last = t

    def consolidate(self, episodes: list[MemEntry]) -> MemEntry:
        """情景->语义：指数族充分统计量可加，合并近似无损。"""
        return MemEntry(a0=sum(e.a0 for e in episodes),
                        b0=sum(e.b0 for e in episodes),
                        t_last=max(e.t_last for e in episodes),
                        prov=[e.fp for e in episodes])

    def reconsolidate(self, e: MemEntry, window: list[MemEntry]) -> MemEntry:
        """变点：若窗口均值偏移 z>阈值，则降权旧证据并重置基线。"""
        if self._changepoint_z(window) > self.change_pt_z:
            e.a0 *= 0.1; e.b0 *= 0.1          # 旧证据降权
            e.S0 *= 0.1
        return e

    @staticmethod
    def _beta_lcb(a: float, b: float, delta: float) -> float: ...
    @staticmethod
    def _changepoint_z(window: list[MemEntry]) -> float: ...
```

### IP-495 TCC：时态证书演算与核心定理（离线理论）

**直觉**：v4 的证书格只问「∧ 起来是真是假」。v5 要问「在某个时间窗内是否一直为真、过期前是否还成立」。这把命题逻辑升级成带时钟的时序逻辑，但只保留**有界时窗**这个可判定片段，避免掉进一般时序逻辑不可判定的坑。

```python
class TimedCertCalc:
    """时态证书演算：布尔运算 + 有界时窗时序算子 + 时钟约束"""
    @staticmethod
    def always(a, T): return f"□_[0,{T}] {a}"     # [t, t+T] 内恒真
    @staticmethod
    def eventually(a, T): return f"◇_[0,{T}] {a}" # [t, t+T] 内终将
    @staticmethod
    def since(a, b): return f"({a} S {b})"
    @staticmethod
    def until(a, b): return f"({a} U {b})"

# 定理 5（时效可靠性 / Freshness-Soundness）
def theorem_freshness_soundness() -> str:
    """
    设锚点 i 依赖量 q_i(t) 满足 |q_i(t)-q_i(t_s)| <= rho_i (t-t_s)，
    签发时判据有余量 eps_i（如 F_max - F(t_s) >= eps_i）。
    若 TTL_i <= eps_i/rho_i 且 kc_fresh 通过（age <= TTL_i），
    则 t 时刻判据仍成立；否则 kc_fresh 拒绝，执行集回退到安全停机。
    """
    return "Proven"

# 定理 6（延迟鲁棒单调收缩）
def theorem_delay_robust_contraction() -> str:
    """
    Exec_CADVS-v5 ⊂ Exec_CADVS-v4。v5 在 v4 每条路径追加 kc_fresh，
    且把 kc_mem 替换为更严的 kc_mem^τ。严格性构造：
    取 t_s 签发、t_now=t_s+TTL+1 且环境未漂移的证书，
    v4 仅看内容为真而放行，v5 因 age>TTL 拒绝。
    """
    return "Proven"

# 定理 7（记忆巩固信息保持与偏差-方差界）
def theorem_consolidation_bound() -> str:
    """
    指数加权 Beta 后验是指数族在遗忘因子下的充分统计量，Cons 合并无信息损失。
    若真实成功率漂移 |dθ/dt| <= kappa，则 E[θ_hat]-θ(t) <= kappa/lam（偏差），
    Var <= 1/n_eff（方差），故 MSE <= (kappa/lam)^2 + O(1/n_eff)。
    lam 增大跟踪快但方差大，lam 减小方差小但滞后大——本质是偏差-方差权衡。
    """
    return "Proven (sketch)"

# 定理 8（安全-可用性不可兼得下界）
def theorem_safety_availability_lower_bound() -> str:
```

### IP-496 EFA-v5：八硬门 + 软评分 + 证据铸造流水线 v5

```python
@dataclass
class EvidenceForgingAssemblerV5:
    """EFA-v5：八硬门 fail-closed；ECS_v5 = ECS_v4 · η_fresh · η_memτ"""
    scf: SpatialCoverageFieldKernel
    msrg_cache: dict
    hic: HumanIntentCertificateKernel
    eek: EndEffectorFidelityKernel
    ltem: LongHorizonMemoryConsolidation
    vack: ValueAlignmentCertificateKernel
    bck: BalanceControlKernel
    dack: DelayAwareCertificateKernel
    mu_S: float = 0.75
    w: tuple = (0.4, 0.4, 0.2)

    def hard_gate(self, x, t_now, rule_id, hic, eec_tc: TimedCert, bcc_tc: TimedCert,
                  vac_tc: TimedCert, mem: MemEntry, object_class, geo_sig,
                  theta_domain_fp) -> tuple[bool, str]:
        # 优先级：HIC veto > 时效 > 其余硬门
        if self.hic.veto_active(hic):                 return False, 'HIC_STOP'
        if not self.dack.kc_fresh(eec_tc, 'ee', t_now):  return False, 'EE_STALE'
        if not self.dack.kc_fresh(bcc_tc, 'bal', t_now): return False, 'BAL_STALE'
        if not self.scf.kc_coverage(x, t_now):        return False, 'COVERAGE_BLIND'
        s2rc = self.msrg_cache.get(rule_id)
        if s2rc is None or s2rc.verdict != 'accept' or s2rc.mu_pass < self.mu_S:
            return False, 'PHYSICS_UNPROVEN'
        if not self.eek.kc_ee(eec_tc.cert):           return False, 'EE_UNPROVEN'
        if not self.bck.kc_bal(bcc_tc.cert):          return False, 'BALANCE_UNSTABLE'
        if not self.ltem.kc_mem_tau(mem, t_now):      return False, 'MEMORY_STALE'
        if not self.dack.kc_fresh(vac_tc, 'val', t_now): return False, 'VALUE_STALE'
        if not self.vack.kc_val(vac_tc.cert):         return False, 'VALUE_MISALIGNED'
        return True, 'FORGED'

    def ecs_v5(self, x, t_now, rule_id, eec_tc, bcc_tc, vac_tc, mem,
               A_att=0.0) -> float:
        base = (self.scf.gamma3d(x, t_now)**self.w[0]
                * getattr(self.msrg_cache.get(rule_id), 'mu_pass', 0.0)**self.w[1]
                * (1 + self.w[2]*A_att))
        eta_mem = self.ltem.eta_mem(mem, t_now)
        eta_val = self.vack.eta_val(vac_tc.cert)
        eta_bal = self.bck.eta_bal(bcc_tc.cert)
        eta_fresh = min(self.dack.eta_fresh(eec_tc, 'ee', t_now),
                        self.dack.eta_fresh(bcc_tc, 'bal', t_now),
                        self.dack.eta_fresh(vac_tc, 'val', t_now))
        return base * eta_mem * eta_val * eta_bal * eta_fresh
```

## 4. 正确性论证（增量更新）

### 引理 43（时效可靠性）

**陈述**：设锚点 i 依赖量 q_i(t) 满足 Lipschitz 界 |q_i(t) − q_i(t_s)| ≤ ρ_i (t − t_s)，且签发时判据有余量 ε_i（如 F_max − F(t_s) ≥ ε_i）。若 TTL_i ≤ ε_i/ρ_i 且 kc_fresh 在 t 通过（age ≤ TTL_i），则 t 时刻该判据仍成立；若 kc_fresh 拒绝，则执行回退到安全停机，不产生不安全动作。

**证明**：判据取上界形式 q_i(t) ≤ F_max，签发时余量 F_max − q_i(t_s) ≥ ε_i，即 q_i(t_s) ≤ F_max − ε_i。由 Lipschitz 界，q_i(t) ≤ q_i(t_s) + ρ_i·age ≤ F_max − ε_i + ρ_i·TTL_i ≤ F_max − ε_i + ε_i = F_max。故判据在 [t_s, t_s+TTL_i] 内保持。拒绝时 kc_fresh 为合取项，fail-closed。∎

**工程含义**：TTL 不是常数，而是「安全边际 / 环境变化速度」；边际越小、环境越快，证书越短命。

### 引理 44（记忆巩固的信息保持与偏差-方差）

**陈述**：设记忆证据为 Bernoulli 序列，遗忘因子 λ。指数加权充分统计量 (a_eff, b_eff) 是衰减似然的充分统计量，Cons 合并（对指数族）无信息损失。若真实成功率 θ(t) 满足 |dθ/dt| ≤ κ，则 E[θ̂] − θ(t) ≤ κ/λ，Var(θ̂) ≤ 1/n_eff，故 MSE ≤ (κ/λ)² + O(1/n_eff)。

**证明**：指数加权均值是指数核平滑，核的平均滞后为 1/λ，故偏差 ≤ κ/λ；Beta 后验方差 ~ 1/(a_eff+b_eff) = O(1/n_eff)。Cons 的可加性来自指数族充分统计量对独立观测的可加性；时间衰减是每个观测的确定权重，不破坏可加性。∎

**工程含义**：λ 是「记忆半衰期」旋钮。λ→0 退化为 v4 的永久记忆（对环境漂移僵化）；λ→∞ 退化为只看最近一次（无法利用长期经验）。kc_mem^τ 用下置信界而非点估计，避免小样本侥幸通过。

### 定理 v5（时态收缩、时效可靠、记忆有界、安全-可用性权衡）

**陈述**：在以下假设下：(C1) 各锚点依赖量满足 Lipschitz 漂移界 ρ_i；(C2) 时钟偏斜有界 ε_clk；(C3) TTL 按引理 43 标定且 RCC 成立或触发本地化；(C4) 记忆证据服从 Bernoulli 且漂移有界 κ；(C5) 继承 v4 的 (B1)~(B6)。则：
(i) Exec_CADVS-v5 ⊂ Exec_CADVS-v4 ⊂ … ⊂ Exec_v29（严格收缩）；
(ii) 时效窗内证书判据保持（引理 43）；
(iii) 过期证书被 fail-closed 拒绝，不会产生不安全执行；
(iv) 记忆估计满足 MSE ≤ (κ/λ)² + O(1/n_eff)（引理 44）；
(v) 时态证书演算在有界时窗片段可判定；
(vi) 重尾延迟下不存在静态 TTL 同时零过期放行、零误停机（定理 8）。

**证明**：(i) v5 在 v4 每条路径追加 kc_fresh 并把 kc_mem 收紧为 kc_mem^τ，故只缩不涨；严格性由定理 6 的「内容真但已过期」构造例。(ii) 引理 43。(iii) kc_fresh 为合取项，失败即拒。(iv) 引理 44。(v) 限制时窗 T ≤ T_max 且时钟为有界偏移，退化为有界模型检查。(vi) 定理 8。∎

**诚实声明**：(C1) 的 Lipschitz 界在接触突变、物体滑落、人突然介入时不成立——此时 ρ_i 会瞬时爆大，任何正 TTL 都可能过期。缓解：变点/事件触发强制重采（TTL 动态归零），代价是可用性下降。(C2) 依赖 PTP/TSN 级时钟同步；无同步的跨广域部署只能用保守 TTL 或本地化。(C4) 记忆漂移界同样是理想化假设，真实环境的分布突变可能比 κ 快得多，此时再巩固也救不回来。

## 7. 本轮最大风险（最终确认）

**一句话**：**TTL 与延迟预算的标定在真实网络抖动下可能失准**——ρ 低估会放行过期证据、ρ 高估或 TTL 过短会让 fail-closed 频繁触发；在环境漂移率 ρ>0 且端到端延迟重尾时，静态 TTL 无法同时消除这两种失效，只能把风险在「安全」与「可用性」之间转移。
