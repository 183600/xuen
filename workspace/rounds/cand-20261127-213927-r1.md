**本轮核实带来的三个关键判断**：

1. **部署接口是「绝对位姿轨迹」**（F23），而模型内部是「相对增量」（F21）——两者之间存在一次「相对→绝对」的累积换算，这正是运动规划可以介入的数学缝隙（chunk 边界漂移、可行性、平滑性）。
2. **观测里没有物体位姿/接触状态**（F22/F24），而规划器需要物体位姿——所以规划器**不可能**合法地出现在推理侧，只能当训练时教师。这一条把本轮所有想法天然锁进 PR6。
3. **动作健康度会被计入可信度**（F25）——运动规划带来的平滑/界内/可行性不只是「好看」，而是可能直接影响成绩可信度；这把 I10 的可行性正则从「锦上添花」抬成「风险对冲」。

## 1. 直觉与动机（两个灵感的碰撞）

**灵感 1（运动规划 → VLA 会「反应」，但不会「规划」）**

直觉：当前策略本质是一个反应式局部策略——看到当前帧，吐出一段局部动作 chunk。它没有显式的「全局一致、无碰撞、可执行」路径概念，也没有平滑/可行性保证。人类示教只展示了「一条成功路径」，而不是「可行路径的集合」；策略学到的是「模仿这条路径」，不是「理解哪些动作在几何上做得到、哪些做不到」。运动规划恰好补的是后者：(a) **可行性**（无碰撞、可达、满足工作空间）；(b) **最优性/平滑性**（更短的路径、更小的 jerk）；(c) **反事实生成能力**——从「从未被示教过的偏离状态」生成一条可行的回归路径，这正是第 2 轮 I5 合成恢复示教最缺的东西。但规划器需要物体位姿（F22/F24 观测里没有），又很慢，不可能放进推理侧；所以规划器的正确位置是**教师**，不是模块。核心反直觉点：**VLA 的短板不是「看得不够多」，而是「不知道哪些动作在几何上根本做不到」；规划器补的正是这份「可行性先验」，而它只能通过训练期蒸馏进入单模型。**

严谨定义（自由空间规划）：给定 EE 位姿空间 X（含夹爪开度）、障碍集 O、起点 x0、目标集 G，求轨迹 ξ:[0,T]→X_free 使 ξ(0)=x0、ξ(T)∈G，并最小化代价 J(ξ)=长度 + w_s·jerk + w_c·(1/clearance)。操作任务按阶段分解：自由空间段（接近、搬运、回退）交给规划器；接触段（插入、拉链、倒药、形变）交给人类示教/学习策略。**规划器只监督自由空间段**，接触段不强行规划。

**灵感 2（模型蒸馏 → 单模型约束下，能力只能「训练时借、推理时还」）**

直觉：比赛强制推理侧只有一个模型（单模型 + N 端口 + 延迟/动作健康度记录，F25），但训练侧我们其实很「富」：可以训多个按技能族划分的专家、可以跑规划器、可以跑世界模型前瞻、可以在仿真里拿到特权状态（物体真值位姿、接触）。蒸馏是**唯一合规的通道**，把这些「推理时不允许存在的昂贵教师」压进「一个便宜的学生」。所以蒸馏在这里不是「压缩模型」，而是「把推理期不允许的计算搬到训练期」。核心反直觉点：**在单模型规则下，增加能力只能靠「训练时增加教师」，不能靠「推理时增加模块」——蒸馏是唯一的能力放大器。**

严谨定义（策略蒸馏）：给定教师 π_T(a|o)（或由其诱导的动作分布/速度场 v_T）、学生 π_S(a|o;θ)、状态分布 d^π，最小化 E_{o~d}[D(π_T(·|o), π_S(·|o))]。对 flow-matching 动作头，取 D=‖v_S−v_T‖²（速度场匹配）；对规划器/仿真教师，取 D=动作 L2 或「计划分布匹配」。**on-policy（DAgger）** 用 d^{π_S} 采样，纠正学生自身偏离；**off-policy（BC）** 用 d^{π_T} 采样，存在协变量偏移。

**形式化（两条本轮会用到的界）**

- **去教师化界（DAgger 视角）**：设学生动作误差在自身占用分布上 ≤δ、动力学 L-Lipschitz，则 |J(π_T)−J(π_S)| ≤ C·δ/(1−γ)（Ross–Bagnell 型界）。它说明：*学生必须在自己会到达的状态上被纠正*，纯 BC 的 δ 在 d^{π_S} 上不可控——这就是 I10/I12 必须用 DAgger 而不是纯离线模仿的理由。
- **多模态保持（min-over-K 视角）**：若真实计划分布有 M 个支撑分离的模态、每模态概率 p_m，则用 K 个采样计划做 min-over-K 蒸馏时，每模态被覆盖的概率 ≥ 1−(1−p_m)^K；而「对 K 个计划取均值做 L2 回归」会塌缩到条件均值，直接抹掉多模态。这决定了 I10 的蒸馏目标必须是**计划分布/速度场**，不是「平均计划」。

**两者统一**：运动规划是「教师工厂」（生产人类示教里没有的、几何可行的监督），模型蒸馏是「搬运机制」（把它搬进单一实时学生）。合起来 = 在第 2 轮「数据引擎」之上加一层**「教师引擎」**：数据引擎回答「数据从哪来」，教师引擎回答「高质量监督从哪来、如何在不增加推理成本的前提下进入策略」。本轮结论：**中期胜负手从「数据引擎」上移到「教师引擎」——谁能把规划器/多专家/世界模型/特权仿真变成训练信号，谁就能在单模型、低延迟约束下继续涨点。**

## 2. 对前几轮痛点的增量修订

- P1（弱任务支配平均）：**I11 专家→通才蒸馏**直接针对——按技能族隔离训练、按任务均衡蒸馏，避免弱任务被强任务/110 语料淹没。

- P4（无触觉）：规划器只能覆盖自由空间，**接触段仍需 I3/I5**；但「接近段更准」会减少接触段的初始误差，间接缓解 P4。不夸大。
- P5（时间压力/步骤分）：可行性正则（平滑、界内、可达）减少抖动与重试，直接省时间、提步骤分。
- P6（部署延迟）：**I6 v3** 加「VLM 特征跨 chunk 复用/缓存」与可选 VLM 蒸馏/量化；把 6B VLM 的调用频率降下来。

- P8（示教质量/全成功无失败）：合成示教获得第二个来源（规划器），但质量风险从「扰动是否真实」转移到「教师是否可信」。
- **新增 P9（教师幻觉）**：规划器/世界模型/特权仿真只在自由空间或仿真里可靠；蒸馏可能让学生学到「依赖教师才成立」的行为，在真实接触段/遮挡下退化。→ 必须有「去教师化」门禁。
- **新增 P10（蒸馏塌缩）**：用均值/L2 蒸馏多模态计划会抹掉多模态，降低鲁棒性。→ 必须用分布/速度场蒸馏 + 覆盖率指标。

## 3. 研究问题（本轮立项 Q9–Q11，Q1–Q8 保留）

## 4. 设计原则（新增 PR6/PR7/PR8，其余保留）

- **PR6 教师侧创新律**：单模型约束下，能力增益只能来自「训练时教师」，不能来自「推理时模块」。每个新想法必须写清三件事：教师是谁、蒸馏信号是什么、如何在推理侧完全移除教师。
- **PR7 去教师化门禁**：任何教师监督的模型，在进入 L2 真机前必须先过「学生单独推理」的 L0 测试；教师优势若在去教师化后消失，则该监督不得放量。
- **PR8 多模态守恒**：对存在多解的动作段（用哪只手、从哪侧接近），蒸馏必须保分布不保均值；以「模态覆盖率」作为与「成功率」并列的验收指标。
- PR1–PR5 保留（第 1/2 轮 §4）。

## 0. 创新点清单（每点：动机 / 与现有方案差异 / 技术可行性 / 所需资源 / 落地步骤 / 风险）

### I10 规划器教师蒸馏 + 可行性正则 ★★★★（新）
- **动机**：策略是反应式局部策略，缺少全局可行性/平滑性/反事实生成能力（P2/P4/P5）；人类示教只给「一条成功路径」，不给「可行路径集合」；观测无物体位姿（F22/F24）使规划器只能当训练时教师。
- **与现有方案差异**：纯 SFT 只模仿示教；I5 v2 的扰动重放只能在「成功轨迹附近」造偏离；本点用几何规划器在**自由空间**生成示教里没有的、物理可行的路径与恢复轨迹，并用 DAgger 纠正学生自己的偏离。推理侧**完全没有规划器**，天然满足 PR2/PR6。
- **技术可行性**：中。规划器用 OMPL/RRT*/TrajOpt/cuRobo；场景用 Isaac Lab（F14）+ 32 任务物体模型；教师数据可离线批量生成。难点是 sim-to-real 与阶段切分。
- **所需资源**：仿真数据生成 1×A100（渲染）+ CPU 规划；DAgger 2–3 轮；1 人 3 周。
- **落地步骤**：①按任务 wiki 把 32 任务切成「自由空间主导 / 接触主导」（先做前者，见 §1.7）；②搭「规划→渲染→(obs, plan)」管线；③用计划数据做数据蒸馏（flow matching），并用 min-over-K 保多模态；④DAgger 2–3 轮，在学生自己偏离的状态上让规划器给纠正标签；⑤加可行性正则（平滑/界内/可达）；⑥PR7 去教师化 L0；⑦真机 L2。
- **风险**：教师幻觉（规划器只懂几何、不懂接触/动力学）→ 只监督自由空间段，接触段仍用 I2/I5；sim-to-real 视觉差 → 用真实数据初始状态 + 域随机化，并只迁移「几何量」（接近方向、间隙、平滑度）；平滑正则过度 → 接触精度下降 → 剂量消融，接触段不加或低权重；多模态塌缩 → 速度场/min-over-K 蒸馏 + 覆盖率验收。

### I11 专家→通才蒸馏 ★★★★★（新）
- **动机**：单模型平均分被最弱任务支配（P1）；第 2 轮 I2 的 110 语料加权共训受 F11（weight 不生效）所困，且 110 语料体量可能淹没 32 任务、产生负迁移（第 2 轮最大风险）。
- **与现有方案差异**：不是「一个大杂烩 SFT」，而是「先按技能族训多个共享同一冻结 VLM、仅 head LoRA 不同的专家，再蒸馏成一个通才」。每个专家只吃自己族的数据（32 族内任务 + 110 孪生），天然没有 ConcatDataset 权重问题；蒸馏时按任务均衡采样，消解弱任务淹没与负迁移。推理侧只有一个 head。
- **技术可行性**：高。官方 LoRA 支持 action head（F11/F28），单卡 24GB 可训一个专家；adapter-only checkpoint 很小。先用 TIES/task arithmetic 合并做廉价基线，再上蒸馏处理冲突。
- **所需资源**：K=6–8 个专家 × 单卡 1–3 GPU 日；蒸馏 1–2×A100 × 2–3 天；1 人 2 周。
- **落地步骤**：①定技能族（按技能而非物体：抓放/堆叠、铰接/开合、插入/插拔、倾倒/液体、折叠/形变、工具使用、分拣/颜色、装箱/收纳）；②每族训 LoRA head 专家（32 族内 + 110 孪生）；③TIES 合并基线；④蒸馏通才（速度场匹配 + 任务均衡采样）；⑤逐族 L0 回归检查（任何族退步即回退该族权重）；⑥L2 抽测弱任务。
- **风险**：专家过拟合小族、蒸馏容量/冲突 → 任务均衡 + 逐族门禁；族划分错误（同一任务跨族）→ 允许任务多族软归属；蒸馏塌缩多模态 → PR8；专家训练数据仍可能负迁移 → 族内先做 L0。

### I12 前瞻/特权蒸馏 ★★★（新，救活 I7）
- **动机**：第 2 轮 I7（世界模型测试时前瞻）因延迟预算被判「待裁撤」；但其价值真实（高风险节点择优、遮挡下预判）。本点把「推理时前瞻」改成「训练时前瞻教师」，用蒸馏把价值搬进学生，推理侧零额外开销。
- **与现有方案差异**：I7 原来想在推理时跑 O(1–2) 次世界模型 rollout，延迟不可控；本点让世界模型/仿真特权状态只在训练时当教师（数据蒸馏或速度场蒸馏），学生推理仍是单模型单次前向。
- **技术可行性**：中。WMA-0 已有决策/仿真双模式（F26），可离线批量生成「前瞻择优」标签；仿真可给特权状态（物体真值位姿、接触）。难点是信息不可推断与容量差。
- **所需资源**：WMA-0 推理/仿真 1×A100；DAgger 2 轮；1 人 2–3 周。
- **落地步骤**：①用 WMA-0 仿真模式对高风险节点做 K 路前瞻，产出「择优动作」标签；②仿真特权教师产出动作 + 特权标签；③DAgger 蒸馏进学生；④加「视觉接地」辅助损失（从观测预测物体位姿/关键点），防止学生依赖教师特权；⑤PR7 去教师化 L0；⑥只在 L0 显著的高险节点放量。
- **风险**：特权信息不可从观测推断（信息论上限）→ 只蒸馏「可推断的部分」，用学生单独 rollout 验证；教师误差被继承 → 教师置信门控 + 抽检；世界模型幻觉 → 只用其做「相对排序」而非绝对标签；成本高 → 缓做，先由 I10/I11 验证蒸馏管线。

### I2 v3 数据引擎 2.0（与 I11 合流）

def feasibility_loss(chunk_abs):             # chunk_abs: (H,6) base 系绝对位姿
    acc  = chunk_abs[2:] - 2*chunk_abs[1:-1] + chunk_abs[:-2]
    jerk = acc[1:] - acc[:-1]
    L_smooth = (acc**2).mean() + (jerk**2).mean()
    L_bound  = (relu(chunk_abs[:, :3].abs() - workspace) ** 2).mean()
    L_reach  = (relu(ik_residual(chunk_abs)) ** 2).mean()   # 可微 IK（若可用）
    return w_s*L_smooth + w_b*L_bound + w_r*L_reach
# 只在自由空间段加权；接触段权重≈0，避免牺牲接触精度

def lookahead_teacher(obs, world_model, student, K=4, H=8):
    cands = student.propose_k(obs, K)                 # K 个候选 chunk
    scores = [world_model.rollout_score(obs, c, H) for c in cands]
    return cands[argmax(scores)]                      # 教师择优（仅训练时）

def privileged_teacher(obs, sim_state):
    return policy_with_state(obs, sim_state).act()    # 仿真特权状态

def lpd_loss(student, obs, sim_state, world_model, a_t, t_noise):
    v_T = lookahead_teacher(obs, world_model, student)
    L_distill = ((student.velocity(obs, a_t, t_noise) - v_T) ** 2).mean()
    L_ground  = grounding_loss(obs, sim_state)        # 视觉接地，防依赖特权
    return L_distill + lam * L_ground

def de_teacher_gap(student, teacher, env, n=50):
    s_s = eval_success(student, env, n)               # 学生单独推理
    s_t = eval_success(teacher, env, n)               # 教师（可含规划器/特权）
    return (s_t - s_s) / max(s_t, 1e-6)               # 必须 < GAP_MAX

def mode_coverage(student, states, k=8):
    modes = []
    for o in states:
        chunks = student.propose_k(o, k)
        modes.append(n_clusters(chunks, tau=MODE_TAU))
    return mean(modes)                                 # 蒸馏后不得显著下降

## 2. 实验设计（分级消融协议 v3）

| 级别 | 内容 | 通道/成本 | 通过判据 |
|---|---|---|---|
| L0-a 教师保真 | 规划器计划在仿真里的成功率 vs 学生复现率 | 离线（免费） | 学生复现率 ≥ 规划器成功率 × 0.8 |
| L0-b 去教师化 | 学生单独 rollout vs 教师辅助 rollout（I10/I12） | 离线 | 去教师化间隙 < 20%；否则不放量 |
| L0-c 多模态 | 蒸馏前后模态覆盖率/动作熵（多解任务） | 离线 | 覆盖率下降 < 10% |
| L0-d 蒸馏目标 | 速度场 vs 动作 L2；DAgger vs BC；K=1/4/8 | 离线 | 速度场+DAgger+K≥4 在间隙与覆盖上 Pareto 最优 |
| L0-e 可行性剂量 | w_smooth 三档；接触/自由空间分段加权 | 离线 | 自由空间 jerk↓ 且接触成功率不降 |
| L0-f 专家→通才 | 逐族专家 vs TIES 合并 vs 蒸馏通才 | 离线 | 蒸馏通才逐族不弱于专家−ε；弱于 TIES 则回退 |
| L1 | 2^(3)：{I10, I11, I12} on/off，在 6–8 个代表任务上 | 离线 + 少量真机 | 主效应显著的 ≤3 组合进 L2 |
| L2 | top 2 组合 × 3 任务 × 各 2 次 | 单任务真机通道 | 成功率/步骤分增益 ≥ L0 预测 50%；动作健康度不退化 |
| 门禁 | PR4：run_client 全流程 + p99 + 动作健康度 | 本地 stub | 0 拒绝动作、p99 < 40ms、jerk 不超基线 |

**首批 L2 排队**：①I11 通才 vs I2 混训基线（弱任务 3 个）→ ②I10 自由空间主导 2 任务（HangCup/StoreCups）→ ③I12 高险节点 1–2 个（遮挡/易碰撞）→ ④I6 特征缓存延迟验证。
