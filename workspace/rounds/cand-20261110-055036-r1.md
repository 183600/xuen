# 第 41 轮 · 双灵感落地 v8：证书保持的低秩步态自适应 × 混合步态证书代数（四层架构 v6）

> 承接第 40 轮（v17：可认证流匹配执行 × 度量语义几何锚定 × 证书驱动课程引擎，四层架构 v5）。本轮灵感词「步态规划、LoRA」正好击中 v17 的两个结构性盲区：其一，v17 的证书都是**单连续模式**的命题（h_min、CBF、流证书都假设接触集不切换），而足式/人形机器人的本质是**混合系统**——落脚、离地、相位切换处才是证书最容易漏掉的地方；其二，v17 的证书是**部署前一次性**的，但真实落地必然要在线适配新地形、新负载、新机体，LoRA 是最现实的低秩适配手段，却没有任何理论保证它不会把证书悄悄改坏。本轮把步态规划升格为「混合自动机上的模式族证书」，把 LoRA 升格为「证书预算约束下的低秩切空间编辑」，两者在**证书切空间**中统一：离散的步态脚手架给出模式序列，连续的低秩适配给出模式内的参数修正，证书则同时约束二者并给出可计算的预算。

## 0. 直觉与动机

**灵感 1（步态规划 → 证书必须长在混合自动机上）**：第 40 轮的 CBF h_min 与流证书默认系统停留在同一个连续模式里。但步态不是一条光滑轨迹，而是一个**混合自动机**：接触集 σ 决定动力学 f_σ，触地/离地是 guard G_{σ→σ'} 上的脉冲 reset R，周期轨道是 Poincaré 映射的不动点。把单模式证书直接拼起来是**不 sound** 的：每个模式内部都安全，不代表切换瞬间安全（reset 可能把状态踹出下一个模式的安全集），也不代表整周期收敛（一次触地误差可能被放大成极限环漂移）。正确做法是给每个模式配一份模式证书（安全不变集、轨道收缩度量、接触可行性），再补三个**跨模式条件**：reset 后落入下一模式安全集、guard 穿越有正裕度、驻留时间有下界（非 Zeno）。于是「步态规划」= 在步态图上搜一条**带证书的闭环**，落脚点还必须落在「可达集 ∩ ESDF 安全集 ⊖ 漂移球」的可行域里——这把第 40 轮 IP-49 的几何证书真正接进了运动层。

**灵感 2（LoRA → 适配应当花「证书预算」而不是免费）**：LoRA 用 ΔW_l=(α/r)B_lA_l 改权重，秩 r 很小。它的好处不只是省参数，而是**可计算**：ΔW_l 的谱范数 ≤ (α/r)‖B_l‖₂‖A_l‖₂，逐层 Lipschitz 常数有可加的扰动界，于是速度场证书 L_v、收缩常数 κ、安全裕度 h_min、认证步数 N* 的**变化量都能被上界**。这带来一个反转：证书不是适配的敌人，而是适配的**预算货币**。每个适配器消耗一个预算向量 b(Δ)（Lipschitz 预算、安全预算、步数预算）；适配是否可部署，变成「花掉的预算是否仍在证书松弛量之内」的检查。更妙的是，若适配器基 {Δ_i} 在权重空间相互正交，合并后的谱范数取 max 而非 sum——**正交适配器互不消耗对方的证书预算**，这给了组合式步态适配一个可证明的容量来源。

**灵感 3（耦合 → 在证书切空间里做步态规划）**：步态规划给离散脚手架（模式序列、相位时长、落脚序列），LoRA 给每个模式内的连续低维修正（地形刚度、负载偏移、机体差异）。二者不是两层拼接，而是同一个优化：在步态图的每条边上，选择一组适配器系数 g，使任务代价下降而证书预算不超支；证书同时约束模式内轨迹与模式间切换。由于 g 的维数只有适配器库大小 k（8~16），规划从高维动作空间降到**低维证书切空间**，既快又可解释。课程引擎（IP-50）则专门采样「证书边际最接近违约」的地形/负载，用它来长出新的适配器基，再正交化并入库——证书赤字从训练信号升级为**适配器库的生成器**。

**三灵感的耦合**：混合步态证书回答「离散接触怎么证」，LoRA 预算回答「连续适配怎么证」，切空间规划回答「二者怎么一起搜」。三者拼成的闭环是：**步态图搜索（离散）→ 适配器预算分配（连续）→ 模式/切换证书校验（证明）→ 课程补短板（进化）**。

## 1. 形式化定义

**定义 27（混合步态规划与模式证书）**：步态模型为混合自动机 H_g=(Σ,X,U,E,G,R,φ)，σ∈Σ 为接触模式（接触集 C_σ 与相位区间 I_σ），连续动力学 ẋ=f_σ(x,u)，E 为模式边，G_{σ→σ'}={x:g_{σ→σ'}(x)=0, ġ<0} 为 guard，R_{σ→σ'} 为 reset。模式证书 CG_σ=(V_σ,h_σ,ρ_σ,F_σ)：
- 安全不变性：h_σ(x)≥0 且存在 u 使 ḣ_σ+α h_σ≥0（h_σ 含地形间隙、自碰撞、关节限位、支撑域/ZMP）；
- 轨道收缩：以相位 φ=0 的 Poincaré 映射 P_σ 度量，‖DP_σ‖≤ρ_σ<1（配收缩度量 LMI）；
- 接触可行：接触力满足摩擦锥与单边约束；
- 落脚可行域 F_σ={p: p∈Reach_σ(x) ∩ (ESDF_safe ⊖ (B_t+δ_occ))}，B_t 为 IP-49 漂移球。
**跨模式条件**：R_{σ→σ'}(G_{σ→σ'})⊆{h_{σ'}≥h_cert+B_t}；guard 裕度 ≥ε_g；驻留 τ_σ≥τ_min。满足全部的环 σ₀→…→σ₀ 称为**认证步态环**。

**定义 28（LoRA 适配与证书扰动算子）**：适配器 Δ={(A_l,B_l)}，W'_l=W_l+(α/r)B_lA_l，β_l=(α/r)‖B_l‖₂‖A_l‖₂。定义三类可计算增益：
- 输出增益 G_Δ=Σ_l β_l(Π_{m<l}ℓ_m)(Π_{m>l}ℓ_m)，即 sup_x‖v_Δ(x)−v(x)‖ 的上界；
- Lipschitz 增量 ΔL_v≤Π_l(ℓ_l+β_l)−Π_lℓ_m，即 L'_v 的上界；
- 收缩退化 L_Δ≤L'_v+L_v（保守），精修用差分网络上的 LipSDP/CROWN。
证书扰动算子 D_C(Δ)=(ΔL_v, L_Δ, G_Δ)，并诱导**认证适配信任域**
Θ_cert(C)={Δ: L_v+ΔL_v≤L_max, κ−L_Δ≥κ_min, h_min−L_h(G_Δ+B_t)≥h_cert, N*'≤N_max}。

**定义 29（证书预算与适配器代数）**：证书松弛量 s(C)=(L_max−L_v, κ−κ_min, h_min−h_cert, N_max−N*, …)，预算 b(Δ)=D_C(Δ)/s(C)（分量除，逐项 ≤1 即可接纳）。合并 Δ=Σ_i g_iΔ_i 时谱范数次可加，故 b(Σ_i g_iΔ_i)≤Σ_i|g_i|b(Δ_i)（**预算共享**）；若 {B_i} 列正交且 {A_i} 行正交，则 ‖Σ_i g_iB_iA_i‖₂=max_i|g_i|‖B_iA_i‖₂，b 取 max 而非 sum（**正交免预算**）。称满足后者的基为证书正交基。

**定义 30（证书切空间步态规划）**：给定上下文 τ=(地形,负载,机体)，求解
min_{σ,T,g} J_task(σ,T,g)  s.t. CG(σ) 成立（模式证书 + 跨模式条件）、Σ|g_i|b(Δ_i)≤b_budget（或 max 版本）、落脚 p_k∈F_{σ_k}(g)、相位时长 T 满足非 Zeno。离散部分在步态图 G_g 上做带证书剪枝的分支定界/MCTS；连续部分在 g 上做投影梯度/CMA-ES。解 (σ*,T*,g*) 称为认证步态方案，其证书预算余量 r=1−Σ|g_i|b(Δ_i) 作为在线降级触发器。

## 2. 三大产出设计

### 2.1 IP-51 CERTIFIED-LORA-ADAPTER（证书预算低秩适配）
1. 适配器结构：逐层 rank-r LoRA（r∈{2,4,8}），优先只挂在动作头与速度场关键层，减少 L_Δ 的放大链。
2. 证书扰动计算：SVD 求 β_l、G_Δ、ΔL_v；收缩退化用差分网络 LipSDP 收紧；每适配器输出预算向量 b(Δ)。
3. 正交适配器基：用 SVD/Gram-Schmidt 在 B_l、A_l 上做跨适配器正交化，使合并预算取 max；提供正交化前后预算对照。
4. 合并与遗忘：多适配器按 g 门控合并；合并后用证书预算与验证集双闸；对旧任务做证书赤字加权回放（接 IP-50）。
5. 在线监测：适配器切换/合并触发重算 N*' 与 h_min'；预算余量 r<0 立即回退到已认证基座或保守步态。

### 2.2 IP-52 HYBRID-GAIT-CERTIFICATE（混合步态证书）
1. 步态图建模：模式=接触集×相位区间；边=guard/reset；离线枚举认证步态环，在线做安全剪枝。
2. 模式证书：CBF h_σ（含 ESDF 几何、自碰撞、关节限位）+ Poincaré 收缩 + 摩擦锥；漂移球 B_t 进 h_min。
3. 跨模式证书：reset 后安全集包含、guard 裕度、非 Zeno；对触地冲击做 reset 鲁棒性分析（R 对状态扰动的灵敏度）。
4. 落脚可行域：由 ESDF、可达集、漂移球与适配器对落脚的影响 G_foot 共同定义，随适配预算动态收缩。
5. 证书生命周期：模式切换时只增量校验受影响的 h_σ 与跨模式条件；违约→总线熔断/保守步态/重规划三级降级。

### 2.3 IP-53 GAIT-ADAPTER-PLANNER（证书切空间步态规划）
1. 离散搜索：在步态图上用 A*/MCTS 搜环，节点携带证书余量，边代价含预算消耗，剪掉证书不可行分支。
2. 连续适配：给定 (σ,T)，在 g 上解带预算约束的投影梯度/CMA-ES；目标=任务代价+证书余量正则。
3. 快速在线版：地形/负载变化时只解 k 维最小二乘投影（残差→适配器特征），再做预算投影；失败则升级到完整搜索。
4. 与课程闭环：IP-50 采样证书赤字最大的地形/负载，训练新适配器，正交化后并入库；库容量受证书正交基秩上限约束。
5. 与总线协同：技能契约携带「适配器预算 + 认证步态环」，跨技能切换时校验预算不串扰、模式切换证书成立。

## 5. 本轮最大风险

**一句话**：整套方案悬于「低秩扰动界是否足够紧」——若谱范数界与差分网络界比真实变化松 10~100 倍，认证适配信任域会缩到只剩零适配器、正交预算取 max 的理论优势也会被逐层放大的 G_Δ 吃掉，系统退化为「不敢适配的固定步态」，故 E74 必须作为第一守门实验。

## 2. 关键算法

### IP-51 证书预算低秩适配（伪代码）
```
def certify_adapter(v, delta, C):
    D = {}
    for l, (A,B) in delta.layers:
        beta[l] = (alpha/r) * norm2(B) * norm2(A)
    G_D   = sum_l beta[l] * prod_before(l) * prod_after(l)
    L_new = prod_l (ell[l] + beta[l])
    L_D   = diff_net_lipsdp(v, delta, init=L_new + L_v)   # 差分网络收紧
    D     = (L_new - L_v, L_D, G_D)
    return D, budget_vector(D, slack(C))                # b(Δ)=D/s(C)

def orthogonalize_basis(adapters):
    for l in layers:
        Bs, As = [a.B[l] for a in adapters], [a.A[l] for a in adapters]
        Bs = qr_orthonormalize(Bs)                      # 跨适配器列正交
        As = qr_orthonormalize_rows(As)                 # 跨适配器行正交
        write_back(adapters, Bs, As)
    return adapters                                     # 合并预算由 sum 降为 max

def compose(adapters, g, budget):
    b = componentwise_max([abs(g[i])*adapters[i].budget for i in range(k)])
    if all(b <= budget): return merged_delta(g), 1 - sum(b)  # 正交基
    else:                return None, -1                       # 拒绝/回退
```

def plan_gait(task, graph, adapter_bank, budget):
    frontier = priority_queue(graph, key=certified_lower_bound)
    while frontier:
        sigma = frontier.pop()
        if not certificate_prune(sigma, budget): continue
        g = project_gradient(
                f=lambda g: task_cost(sigma, g) + lam*sum(abs(g)*b),
                proj=lambda g: project_budget(g, budget)) # 可行域为范数交
        if feasible(sigma, g) and residual(g) >= 0:
            return (sigma, g, residual(g))
        frontier.expand(neighbors(sigma))
    return fallback(task)                                 # 退到已认证保守环

def online_adapt(x, terrain_feat, bank, budget):
    g0 = feature_least_squares(terrain_feat, bank)        # k 维，毫秒级
    g  = project_budget(g0, budget)
    if residual(g) >= 0 and hybrid_cert_ok(g):
        return g
    return plan_gait(task, gait_graph, bank, budget)      # 升级为完整搜索

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 正确性保证 |
|---|---|---|
| 适配器证书 | 每层 SVD O(d r²+r k²)；全网 O(Σd_l d_{l−1}r) | 谱范数 ≤ 扰动上界（可证） |
| 差分网络收紧 | LipSDP 仅关键层，分钟级离线 | L_Δ 上界可证，比 L'_v+L_v 更紧 |
| 正交化 | O(k²·r·(d+k)) | 正交基合并预算取 max（可证） |
| 预算合并 | O(k·m)，m 为证书分量数 | 次可加性：b(Σg_iΔ_i)≤Σ|g_i|b_i |
| 步态图搜索 | O(|Σ|·|E|·log|Σ|)（A*）+ 证书缓存 | 环上模式证书 + 跨模式条件 ⟹ 全程安全 |
| 模式增量校验 | O(受影响模式)，切换时毫秒级 | 仅证书条件变化才重算 |
| 切空间规划 | O(K·k·m) 投影梯度；在线最小二乘 O(k²) | 预算可行域为闭凸（范数交），投影收敛 |
| 组合契约 | O(|V|+|E|) | C_ms 蕴含 + 预算可加 + 切换证书 |

**定理 A（适配器证书 soundness）**：若基座证书 C 成立，且适配器 Δ 的 b(Δ) 逐项 ≤1，则适配后 L'_v、κ'、h'_min、N*' 仍满足证书阈值。证明：逐层 Lipschitz 乘积界 + 谱范数三角不等式给出 ΔL_v、L_Δ、G_Δ 上界；κ'≥κ−L_Δ 由 sym(J+J_Δ)⪰sym(J)−‖J_Δ‖I 得；h' 由 L_h-Lipschitz 与状态漂移 B_t 得；N*' 由 ε_ode 对 L_v/κ 的单调性重解。

**定理 B（混合步态闭环安全）**：若认证环的每个模式满足 h_σ≥0 的不变性、reset 后落入下一模式安全集、guard 有正裕度且驻留 ≥τ_min，则任意无限执行恒在 ∪_σ{h_σ≥−B_t} 内，且非 Zeno。证明：模式内用 CBF 不变性归纳；切换点用 reset 包含关系；非 Zeno 由驻留下界排除无限快切换；Poincaré 收缩 ρ<1 保证误差不沿周期累积。

**定理 C（预算代数）**：合并适配器满足次可加界；若基正交，则预算取 max。证明：‖Σg_iB_iA_i‖₂≤Σ|g_i|‖B_iA_i‖₂；正交分块时矩阵在正交基下块对角，谱范数为最大块。

## 5. 风险与缓解

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 谱范数界/差分本征界过松 → 信任域缩为零适配 | 高 | 只适配动作头与少数关键层；差分网络 LipSDP；E74 第一守门 |
| 混合模式证书过保守 → 步态图无可行环 | 高 | 模式证书只在受影响子空间增量校验；保留保守步态兜底；E76 守门 |
| 触地 reset 的冲击鲁棒性未证 → 切换瞬间失稳 | 高 | reset 灵敏度分析 + 冲击裕度膨胀；触地力限幅；近摔率硬门槛 |
| 正交化损害适配表达能力 | 中 | 正交化前后成功率对照；允许少量非正交预算（sum 上限） |
| 适配器库爆炸、组合干扰 | 中 | 证书正交基秩上限 + 预算取 max + 按证书赤字剪枝 |
| 在线最小二乘误选适配器 | 中 | 预算投影 + 混合证书校验 + 失败升级到完整搜索 |
| 步态图搜索实时性 | 中 | 离线预证环 + 在线只做增量校验与局部重规划 |

## 6. 本轮最大风险

**一句话**：方案的命门是「低秩扰动界是否足够紧」——若谱范数界与差分网络界比真实变化松 10~100 倍，认证适配信任域会缩到只剩零适配器，正交预算取 max 的理论优势也会被逐层放大的 G_Δ 吃掉，系统退化为不敢适配的固定步态，故 E74 必须作为本轮第一守门实验。
