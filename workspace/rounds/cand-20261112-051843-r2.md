# 第 58 轮（承接第 57 轮「少样本×多模态×个性化」IP-133~138；灵感循环第 2 轮；本轮灵感：「双臂协作」×「并发推理」）

> 第 57 轮把"证据说可信"推进到少样本可校准、跨模态可对账、个性化有界，但它仍隐含两个"单线程"假设：**(a) 世界在"检查"与"使用"之间不动**——一个检查点的证据被读取后，到真正承诺之前，另一条腿/另一只臂的并发动作可能已经改变了它，这是典型的 TOCTOU 竞态；**(b) 每个检查点的失效率是自足的**——所以可以对检查点直接取 union bound。可一旦多个效应器同时接触，"我安全是因为另一只臂撑着我"就使每个证书变成**有条件的、相互引用的**，串联依赖被误当并联冗余，union bound 不再刻画真实失效率。本轮两个灵感正好补这两刀：**双臂协作**给出角色不对称、接地支撑依赖图与内力预算，把"相互支撑幻觉"变成结构可判定的东西；**并发推理**给出证据事务、乐观并发与推测分支合并，把"检查时成立"升级为"提交时仍成立且未被并发推翻"。二者合流为 **锚-演两阶段物理提交 + 依赖感知可靠性界**，核心命题升级为 **"接地、并发一致的证据说可信"**。

核心矛盾：
- **H29（并行证据耦合 vs 逐检查点独立）**：省事的安全证明把多效应器当独立检查点取 union bound；但耦合支撑是串联不是并联（依赖越多越脆），共享传感器/共同支撑是正相关共模（同错同对），逐点独立界会系统性低估失效。
- **H30（推测提速 vs 承诺一致性）**：并发/推测推理用"先跑后验"换时延；但若提交时不校验读数版本，就会用过期的世界状态下不可逆决定；若校验过严，并发收益归零——需要在"快"与"证据在提交时仍有效"之间划出一条可证的线。
- **H31（双臂冗余 vs 相互支撑幻觉）**：双臂的能力来自一锚一演的冗余；但若两只臂互相把对方写进自己的安全证书，就构成无接地、无终点的循环支撑——没有谁真正站在地上，却每个人都"被支撑"。

## 0. 直觉与动机

**灵感 1（双臂协作 → 角色不对称 + 接地支撑图 + 内力预算）**
直觉：双臂不是"两个单臂相加"。真正的双臂协作是**角色不对称**的：一只当锚（brace）稳住世界，另一只当演（actor）去探、去操作；先有可信的支点，才谈得上冒险的动作。角色带来能力，也带来**借贷**——"我安全，因为另一只臂撑着我"。借贷本身没错，错在借贷可以循环：A 说"有 B 撑我"，B 说"有 A 撑我"，两条腿互相借着对方的信用，谁也没落地。物理上这对应闭合支撑链和过约束（两臂内力互顶，越使劲越不稳）。所以双臂协作的第一性原理不是"加一条臂"，而是：**每个承诺都必须有一条通向已验证地面、且无环的支撑路径；耦合接触的内力必须可被预算约束，超预算就是过约束。**

**灵感 2（并发推理 → 证据事务 + 乐观并发 + 推测执行）**
直觉：真实机器人不是一个线程按检查点排队。感知、推断、控制、另一条腿的动作是**并发**的。并发下最贵的错误不是算得慢，而是**"检查时成立、使用时已失效"（TOCTOU）**：一个线程读到"该表面干燥可承重"，另一个线程同时踩上去扰动/改变了它，等提交时这条证据已经过期。数据库几十年前就解决过同类问题——乐观并发控制：事务在快照上读、记下读写集、提交时校验版本，冲突就中止回滚。把证据地图 𝓜 当版本化共享内存，把每次探针/推断当**证据事务**，把并行假设当**推测执行**：快照内并行推理、提交时校验、冲突则弃分支、保留锚。并发因此不是免费加速，它把"证据足够"重写为**"证据在提交时仍然足够，且没有被并发动作推翻"**。

**灵感 3（合流 → 锚-演两阶段物理提交 + 依赖感知可靠性界）**
直觉：物理动作不能真回滚，所以不能照抄数据库的事务中止。双臂恰好给了一个**物理版两阶段提交**：先提交可卸载的锚，再提交带观察期的演——先让支撑落地，演在 probation 期内持续再验证，失败就卸载回锚。与此同时，安全界的算法必须从"对检查点取 union bound"升级为**在接地支撑的可靠性框图（RBD）上算串并联故障率**：串联（依赖）不是冗余；互相支撑的环是"无接地"而不是"双保险"；共享传感器/共享支撑的共模用 β-factor 显式计入。于是第 57 轮"坏先验普遍"多了一个并发侧的解药（独立多分支、分歧即弃权），也多了一个并发侧的新病（伪独立/回声室）。

**灵感 4（证据门与证书：六类证据 + 两道结构门）**
直觉：本轮不靠堆证据类，而是加两道**结构门**：**接地门 G-gate**（无环 + 接地 + 内力预算）与**并发门 C-gate**（OCC 版本有效 + 可串行化）。证据门 FSE+ 在五类基础上只新增 **EV-cc**（并发独立共识），且它必须同时过 G/C 门、独立性经审计；不可逆接触仍排除 EV-xmodal 与 EV-cc。证书由 J_p 升级为 **J_c = J_p ⊕ (G_s, RBD, β 向量, ver_log, indep_log, commit_log, rollback_log, arb_log)**——从此"证据说"之外还要附上"站在什么上、在哪个版本上"。

**灵感 5（PCE++ → 并发化探-诺-演）**
直觉：把 PCE+ 的串行检查点循环改成"并发分支 + 提交屏障"。对候选步态/接触方案并行做元推断与对账（推测执行）；某分支的证据版本被并发动作推翻就早停；提交前插入 G/C 双门与锚-演排序；内力超预算则降载、换角色或改步态。所有新机制仍只经"更准"（含弃权）或"更保守"（abort/锚优先/降载）两个安全通道，延续交互单调性。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（耦合双臂模型 CAM）** 效应器集 E={e_1,…,e_n}（前肢/后肢/机械臂），配置 x=(x_e)。接触图 G_c=(E,A_c)（边=同时接触/共同承载）。角色 ρ:E→{A(锚),S(演),F(自由)}。支撑依赖图 G_s=(E,A_s)，边 (e→e′) 表示 e 的证书引用了 e′ 的稳定性。**接地性**：存在已验证外部支撑 g0，(i) 每个锚有到 g0 的路径，(ii) G_s 无有向环（禁止相互支撑），(iii) 每个演的路径终止于锚或 g0。**内力预算**：对耦合接触子集 C⊆E，F_int(C)=‖Σ_{e∈C} f_e^int‖_∞ ≤ F_bud(C)，超限即过约束（松弛/换角色/卸载）。**角色语义**：锚承诺不可逆或半不可逆，演承诺 probationary。

**定义 140（证据事务与乐观并发 ETO）** 证据地图 𝓜 带版本 v(𝓜)；证据键 k=(r,modality,claim)。事务 T=(r_T,w_T,v_T)，r_T 记录读键与读版本 v_T(k)。提交校验：**C1** ∀k∈r_T，v(𝓜)(k)=v_T(k)（未被并发动作/事后证伪改动）；**C2** 所有 in-flight 提交的写集冲突图无环（可串行化）；**C3** 若某 in-flight 承诺的证书引用了被 T 改写的键，则 T 不得提交，或该承诺被降级 probationary 并重验。冲突 ⇒ abort(T)，回滚到最近一致快照 v_ckpt，释放演、保留锚。失效窗口 δ_stale=P(提交时读集已失效 ∧ C1 漏检)。

**定义 141（并发推断合并 CIM）** 并行分支 B={b_1,…,b_K}，每分支给候选 (d_i,conf_i,cert_i) 并声明对独立性 ind(b_i,b_j)（不同数据源/模态/元模型/探针史；共享同一 𝒟_meta 或同一传感器的分支视为相关，合并为单票）。合并 ⊕ 产承诺当且仅当：(i) 各 cert_i 可组合（无相互矛盾假设）；(ii) 分歧 Δ_B=max_{i,j} d_TV(b_i,b_j) ≤ θ_merge；(iii) 存在 ≥2 个**独立**同侧分支（独立性经 indep_log 审计，伪独立率 ≤ δ_ind）。否则触发仲裁探针（预算 k_arb）；仲裁仍分歧 ⇒ 弃权。Anytime：分支可在下界证书上提前返回；后到分支与已提交决策矛盾 ⇒ 触发降级/回滚。

**定义 142（锚-演两阶段物理提交 A2C）** 物理动作不可回滚，故按角色排序：
- **P 阶段**：锚以完整证据门（须过 G-gate 与内力预算）准备；演只允许可卸载动作（L0/L1，力矩 ≤ F_act，可退回锚的支撑）。
- **C 阶段**：锚先提交（不可逆/半不可逆）；演仅在锚提交成功 ∧ OCC 校验 C1–C3 ∧ G-gate 通过后，以 probationary 提交，观察期 τ_prob 内每周期重验读版本与支撑；任一失败 ⇒ 卸载到锚、力控回撤、回退，不升级不可逆。
- **换角色**：仅当交换后仍满足接地性与内力预算；接地点不可"交换"。L2 不可逆接触禁止以演的 probationary 证据进入，必要时先转正。

**定义 143（支撑可靠性图 SRD、依赖感知界 DAB 与证书 J_c）** 由 G_s/G_c 构造可靠性框图 RBD：串联依赖为 series，真冗余为 parallel，共享传感器/共享支撑为公共节点并用 β-factor 共模。对含锚的接地连通分量 G_k：
P_fail_k=(1−β_k)·(1−R_ind(G_k))+β_k·p_cm,k，R_k=1−P_fail_k；无接地或含环令 R_k=0（结构拒绝）。**部署界**：P_safe ≥ 1−Σ_k(1−R_k)−δ_stale·N_cp−δ_ind·N_cc−P(𝓜 陈旧未检出)−P(回滚失败)。**证书** J_c=J_p⊕(G_s,RBD,{β_k},ver_log,indep_log,commit_log,rollback_log,arb_log)。

**定义 144（并发双臂探-诺-演算子 PCE++）** 每循环：①并发分支推断（ID→摊销后验/OOD→共形带，多分支 CIM）；②对账：D(r)>θ_D ⇒ 共识探针；③**G/C 双门**：G-gate（接地无环+内力预算）+ C-gate（OCC 版本+可串行化）；④任一门失败 ⇒ abort 当前演分支→保持锚→降档/换角色/改步态→重规划；⑤承诺按 A2C 排序（锚先、演 probationary）；⑥探尽→绕行→L2 协商或安全停。预算 k_probes+k_cons+k_arb，并发分支数 K 受时延预算约束。

## 2. 关键算法伪代码（完整版见产物区）

```python
def grounded(G_s, g0, es):                     # IP-139: 接地 + 无环
    for e in es:
        seen, cur = set(), e
        while cur != g0:
            if cur in seen: return False       # 相互支撑环
            seen.add(cur); cur = G_s.next(cur)
            if cur is None: return False       # 悬空支撑
    return True

def occ_commit(T, M, inflight):                # IP-140: 乐观并发
    if any(M.version(k) != v for k, v in T.read_versions.items()):
        return abort(T, 'stale_read')          # C1: TOCTOU
    if conflict_cycle(T.writes, [c.writes for c in inflight]):
        return abort(T, 'non_serializable')    # C2
    for c in inflight:
        if c.premises & T.writes: c.demote('probationary')   # C3
    M.apply(T.writes); M.bump(); return commit(T)

def a2c_commit(anchor, actor, M, conns):       # IP-142: 锚先演后
    if conns.G_gate(anchor) != 'ok': return reject(anchor)
    commit(anchor, irreversible=True)
    commit(actor, probationary=True)
    if not wait_revalidate(actor, M, tau_prob):
        unload_to(anchor); return rollback(actor)
    promote(actor); return 'ok'
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| CAM/SRD | O(\|E\|+\|A_s\|) 环检测；O(\|C\|) 单约束（子集限于耦合团） | O(\|E\|+\|A_s\|) | 接地点与边须诚实、环即拒 |
| ETO | O(\|r_T\|+\|w_T\|)/提交；冲突图 O(N_c²)（可增量） | O(\|𝓜\|+\|inflight\|) | C1–C3 完备、δ_stale 有界 |
| CIM | O(K²·d_b) 合并；仲裁 O(k_arb) | O(K·\|cert\|) | 独立票计数、伪独立 ≤δ_ind |
| A2C | O(τ_prob/Δt) 观察期 | O(1) | 演可卸载、锚不可逆 |
| DAB | O(\|G_s\|+\|RBD\|) | O(\|RBD\|) | RBD 语义诚实、β 显式 |
| PCE++ | O(K·\|CP\|·(k_p+k_c+k_arb)·(C_VOI+d_φ)) | O(\|V\|+\|σ\|+K·\|cert\|) | 独立票、G/C 门、k 预算终止 |

**正确性定理（DCGS 概要）**：在 A33–A40 上加 (A41) 接地支撑（不可逆承诺位于接地无环 G_s，G-gate 结构完备）；(A42) 证据事务（C1–C3 完备、δ_stale 有界、回滚可实现）；(A43) 独立性声明诚实（伪独立 ≤δ_ind，相关分支合并为单票）；(A44) 内力与角色（F_int 预算可执行、演可卸载、τ_prob 内回滚成功）。则：(i) **接地健全性**——任何已提交不可逆接触属于某接地无环分量；相互支撑环以概率 1 被结构拒绝；(ii) **并发一致性**——已提交承诺的读集在提交时有效（除 ≤δ_stale 漏检），并发提交可串行化，中止演不产生无锚悬空承诺；(iii) **并发不放大置信**——CIM 仅按独立分支计票，伪独立共模假共识 ≤δ_ind+P_cm，故并发只能提速或弃权；(iv) **依赖感知可靠性**——P_fail_k 由 RBD+β 计算，正相关共模显式计入而非独立近似；(v) **终止性**——PCE++ 在 k_probes+k_cons+k_arb 内终止于 {承诺, 绕行, 换角色/降档, L2 协商, 安全停}。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| G_s 的边是自声明 → 假接地/假冗余 | 高 | 未知依赖一律按串联；接地接触需独立实测；G_s 变更走证据门+审计 |
| 伪独立/回声室 → 并发假共识 | 高 | 独立性声明+审计；共享 𝒟_meta/传感器合并单票；分歧即弃权 |

| 内力预算估计误差 → 过约束 | 中 | 力矩/电流实测上限；保守 F_bud；超限降载/换角色 |

## 6. 本轮最大风险

**一句话**：本轮的接地与独立性都是**自声明的元数据**——G_s 的一条边、CIM 的一个 ind 声明，都是"我们说它支撑/独立"，而 OCC 的版本校验只保证"证据没被改过"，不保证"证据是对的、支撑是真的"；一旦把串联依赖误声明为并联冗余、或把悬空支撑误声明为接地，A2C 会先锁定一个并不存在的锚，再让演在 probation 里依赖它，而并发提速会让这个假接地比串行系统更快地变成不可逆承诺。

# 第 58 轮产物 · 创新点清单 v34：DualArm-Concurrent（双臂接地承诺×并发证据事务，CAM×ETO×CIM×A2C×DAB×PCE++）

> 承接第 57 轮 IP-133~138（MFSL/XMC/PTM/MXI/FSE/PCE+）与第 56 轮 IP-127~132（SMM/PCE/BVK/ISE/TAF/MEC）。本轮把部署前提从"少样本可校准、跨模态可对账、个性化有界的证据承诺"推进为 **"接地可证、并发一致、独立性可审的证据承诺"**：多效应器承诺不再对检查点取独立 union bound，而是在接地支撑的可靠性框图（RBD）上算串并联 + 共模；证据地图从只读信念变为版本化共享内存，用乐观并发校验"检查—使用"之间的 TOCTOU 竞态；物理提交改为锚先演后的两阶段，演在 probation 期内可卸载。第 57 轮"一切判定器走隔离"在本轮推广为"**一切承诺走接地与事务校验**"。
> IP 编号：IP-139~IP-144（共 6 个），升级 IP-133/134/137/138 以纳入并发分支、证据事务、结构门与证书 J_c。

## 0. 核心 IP 设计

## 2. 关键算法伪代码

### IP-139 CAM / SRD（接地支撑图与可靠性框图）

```python
def build_support_diagram(E, A_c, support_edges, redundancy_claims, common_cause):
    Gs = DiGraph(E, edges=support_edges)
    if has_cycle(Gs):                          # 相互支撑 -> 结构拒绝
        return None, 'mutual_support_cycle'
    g0 = verified_ground(E)                    # 独立实测的接地点
    if not all(reaches(e, g0, Gs) for e in anchors(E)):
        return None, 'ungrounded_anchor'
    rbd = RBD()
    for e in E:                                # 未知依赖一律按串联
        rbd.add_series(e, Gs.parent(e))
    for a, b in redundancy_claims:
        if not audited_redundancy(a, b):       # 声明需独立实测才升并联
            continue
        rbd.merge_parallel(a, b)
    for c in common_cause:                     # 共享传感器/共享支撑
        rbd.add_beta(c.group, beta=c.beta, p_cm=c.p_cm)
    return rbd, 'ok'

def internal_force_ok(x, G_c, F_bud):
    for C in coupled_cliques(G_c, x):          # 耦合团而非全部 2^|E|
        if norm_inf(sum(internal_force(e, x) for e in C)) > F_bud[C]:
            return False, C                     # 过约束
    return True, None
```

### IP-140 ETO（证据事务与乐观并发）

```python
def evidence_transaction(probe, M, inflight):
    snap = M.snapshot()
    reads = {k: snap.version(k) for k in probe.read_keys}
    writes = probe.compute(reads)              # 在快照上推测执行
    T = Tx(reads=reads, writes=writes, v=snap)
    for k, ver in T.read_versions.items():
        if M.version(k) != ver:
            return abort(T, 'stale_read')      # C1: TOCTOU
    if conflict_cycle(T.writes, [c.writes for c in inflight]):
        return abort(T, 'non_serializable')    # C2
    demoted = [c for c in inflight if c.premises & T.writes]
    for c in demoted:
        c.demote('probationary')               # C3: 前提被改写 -> 降级重验
    M.apply(T.writes); M.bump()
    M.checkpoint()                             # 供 aborted 事务回滚
    return commit(T, demoted=demoted)
```

### IP-141 CIM（并发推断合并，反回声室）

```python
def concurrent_inference_merge(branches, theta_merge, k_arb):
    if not all(composable(b.cert) for b in branches):
        return ('abstain', 'incompatible_certs')
    groups = independent_groups(branches)      # 共享 𝒟_meta/传感器 -> 单票
    D = max(tv(bi.d, bj.d) for g in groups
            for bi in g for bj in g)
    if D > theta_merge:
        return arbitration_probe(k_arb)        # 分歧 -> 仲裁探针
    votes = sum(1 for g in groups if same_side(g))
    if votes < 2:
        return ('abstain', 'no_independent_quorum')
    return ('ok', merge_certs(groups), independence_log(branches))
```

### IP-142 A2C（锚-演两阶段物理提交）

```python
def anchor_actor_commit(anchor, actor, x, M, rbd):
    ok, _ = internal_force_ok(x, G_c, F_bud)
    if not ok or not grounded(rbd, anchor):
        return ('reject', 'grounding_or_force')
    commit(anchor, mode='irreversible')        # P/C: 锚先锁定
    if not grounded(rbd, actor):
        return ('reject', 'actor_grounding')
    commit(actor, mode='probationary')         # 仅可卸载动作进入
    for t in control_cycle(tau_prob):
        if not revalidate_readset(actor, M) or not grounded(rbd, actor):
            unload_to(anchor)                  # 物理回滚到锚
            return ('rollback', actor, t)
    promote(actor)                             # 观察期满才转不可逆
    return ('ok', anchor, actor)
```

### IP-143 DAB（依赖感知部署界与证书 J_c）

```python
def dependency_aware_bound(components, beta, p_cm, deltas, N_cp, N_cc):
    p_fail = []
    for G in components:
        if not grounded(G):
            p_fail.append(1.0); continue        # 无接地/含环 -> 结构拒绝
        R_ind = rbd_reliability(G)              # 串并联公式
        p = (1 - beta[G]) * (1 - R_ind) + beta[G] * p_cm[G]
        p_fail.append(p)
    return (1 - sum(p_fail)
              - deltas.stale * N_cp
              - deltas.ind   * N_cc
              - deltas.map_stale
              - deltas.rollback)

def cert_Jc(Jp, rbd, beta, logs):
    return Jp + (rbd, beta, logs.ver, logs.indep,
                 logs.commit, logs.rollback, logs.arb)
```

### IP-144 PCE++（并发化探-诺-演）

```python
def probe_commit_evolve_plus_plus(x0, M, task, budget, personas):
    branches = spawn_parallel_plans(M, task, K=budget.K)
    for B in speculative_rounds(branches):
        cert = concurrent_inference_merge(B, theta_merge, budget.k_arb)
        if cert[0] != 'ok':
            continue                            # 分歧/仲裁失败 -> 弃权
        route = pick_route(B, cert)
        for cp in route.checkpoints:
            inf = meta_few_shot_infer(M, cp.region, M.obs[cp.region], meta)
            rbd, st = build_support_diagram(cp.E, cp.Gc, cp.Gs,
                                            cp.redundancy, cp.common_cause)
            if st != 'ok':
                break                           # 假接地/环 -> 弃本条
            for c in contacts(cp):
                T = evidence_transaction(probe(c), M, inflight)
                if T.aborted:
                    mark_invalid(B, c); break   # 版本冲突 -> 早停
            if not grounded(rbd, cp.anchor): continue
            if few_shot_plus_gate(cp, M, personas, rbd)[0] != 'ok': continue
            res = anchor_actor_commit(cp.anchor, cp.actor, cp.x, M, rbd)
            if res[0] == 'ok':
                commit_plan(cp)
            elif res[0] == 'rollback':
                degrade_gait(cp); continue      # 演失败 -> 保留锚、降档
        if committed(route):
            return route, cert_Jc(route.Jp, rbd, beta, logs)
    return reroute_or_stop(route, M, personas)
```

### IP-137→FSE+（六类证据 + G/C 双结构门）

```python
def few_shot_plus_gate(c, M, persona, rbd):
    if c.ev == 'EV-cc':
        ok = c.level in ('L0', 'L1') and c.indep_audited \
             and c.cert_serializable
    elif c.ev == 'EV-xmodal':
        ok = c.level == 'L1' and c.indep_declared and D(c.region) <= theta_D
    elif c.ev == 'EV-probe*':
        ok = round57_probe_check(c)             # 继承 ECE_k/共形带
    elif c.ev == 'EV-human':
        ok = round57_human_check(c, persona)    # 继承 auth/佐证
    elif c.ev in ('EV-visit', 'EV-margin'):
        ok = round56_checks(c, M)
    else:
        return ('reject', 'no_evidence_class', c)
    if not ok:
        return ('reject', 'evidence_insufficient', c)
    if not grounded(rbd, c.effector) or not internal_force_ok(c.x, c.Gc, F_bud)[0]:
        return ('reject', 'G_gate', c)          # 接地/内力门
    if c.irreversible and not occ_valid(c):
        return ('reject', 'C_gate_stale', c)    # 并发版本门
    if c.irreversible and c.ev in ('EV-xmodal', 'EV-cc'):
        return ('reject', 'concurrent_ev_on_irreversible', c)
    return ('ok', c)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CAM/SRD | O(\|E\|+\|A_s\|) 环检测；O(\|C\|) 耦合团约束 | O(\|E\|+\|A_s\|) | 接地点与边须诚实、环即拒（A41） |
| ETO | O(\|r_T\|+\|w_T\|)/提交；冲突图 O(N_c²) 可增量 | O(\|𝓜\|+\|inflight\|) | C1–C3 完备、δ_stale 有界（A42） |
| CIM | O(K²·d_b) 合并；O(k_arb) 仲裁 | O(K·\|cert\|) | 独立计票、伪独立 ≤δ_ind（A43） |
| A2C | O(τ_prob/Δt) 观察期 | O(1) | 演可卸载、锚不可逆（A44） |
| DAB | O(\|G_s\|+\|RBD\|) | O(\|RBD\|) | RBD 语义诚实、β 显式 |
| FSE+ | O(\|σ\|+\|A_s\|) | O(\|σ\|+\|A_s\|) | 结构性拒（环/悬空/过期） |
| PCE++ | O(K·\|CP\|·(k_p+k_c+k_arb)·(C_VOI+d_φ)) | O(\|V\|+\|σ\|+K·\|cert\|) | 独立票、G/C 门、k 预算终止 |

**正确性定理（Dual-arm Concurrent Grounded Soundness, DCGS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 接地支撑：所有不可逆承诺位于接地、无环的 G_s 上，G-gate 结构完备（环与悬空以概率 1 拒绝）；**(A42)** 证据事务：C1–C3 检查完备，失效窗口 δ_stale 有界，回滚语义可实现；**(A43)** 独立性声明诚实：CIM/EV-cc 所用分支独立性经审计，伪独立率 ≤δ_ind，共享数据源/传感器的分支合并为单票；**(A44)** 内力与角色：F_int 预算可执行，锚不可逆、演可卸载，τ_prob 内回滚成功。则：

1. **接地健全性**：任何已提交不可逆接触属于某接地无环分量 G_k；相互支撑环与悬空支撑不依赖概率假设，被结构拒绝。
2. **并发一致性**：已提交承诺的读集在提交时有效（除 ≤δ_stale 漏检）；并发提交可串行化；被中止的演保持锚，不产生无锚悬空承诺。
3. **并发不放大置信**：CIM 仅按独立分支计票；伪独立 ∧ 共模的假共识概率 ≤δ_ind+P_cm；故并发最多带来 (a) 更快或 (b) 弃权，不能把置信推到独立证据之外（交互单调性延续）。
4. **依赖感知可靠性**：P_fail(G_k) 由 RBD+β 计算，正相关共模显式计入，而非逐检查点独立 union 近似；β=0 且全串联独立时退化为第 57 轮界。
5. **终止性**：CIM 分支在 τ_b 内返回或中止；PCE++ 在 k_probes+k_cons+k_arb 内终止于 {承诺, 绕行, 换角色/降档, L2 协商, 安全停}。
6. **部署界**（对接地分量取联合界）：

```
P_safe ≥ 1 − Σ_k [ (1−β_k)(1−R_ind(G_k)) + β_k·p_cm,k ]
             − δ_stale·N_cp − δ_ind·N_cc
             − P(𝓜 陈旧未检出) − P(回滚失败) − P(τ_prob 内重验失效漏检)
```

关键：**接地把"借来的稳定"变成结构判定**（无环 + 到地面，否则拒）；**事务把"检查时成立"变成"提交时仍成立"**（版本校验，冲突即弃分支保锚）；**独立性把"多分支同意"变成可信共识**（相关分支只算一票，分歧即弃权）；三个新机制全部经"更准（含弃权）或更保守（abort/锚优先/降载）"两个安全通道起作用。

## 6. 本轮最大风险

**一句话**：本轮的接地与独立性都是**自声明的元数据**——G_s 的一条边、CIM 的一个 ind 声明，都是"我们说它支撑/独立"，而 OCC 的版本校验只保证"证据没被改过"，不保证"证据是对的、支撑是真的"；一旦把串联依赖误声明为并联冗余、或把悬空支撑误声明为接地，A2C 会先锁定一个并不存在的锚，再让演在 probation 里依赖它，而并发提速会让这个假接地比串行系统更快地变成不可逆承诺。
