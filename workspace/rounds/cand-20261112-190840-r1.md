# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 7 轮；本轮灵感：「指令泛化」×「语音合成」）

> 第 60 轮把闭环从「执行→证据」推进到「场景→意图→执行」，但仍留下三个未解的根本矛盾：
> 1. **意图理解的单点脆弱**：CIEC 把意图 I 映射为约束 C，但 I 的获取依赖一次性的语义解析；「轻触」被误听为「加紧」时，错误约束会被 φ_lock 立即锁定 2s，期间物理执行已不可逆。第 60 轮用 SIC 三元校验兜底，却无法**在锁定前发现语义歧义**。
> 2. **指令泛化的分布外空洞**：意图集合 I 是离散闭集（'慢点'/'轻触'/…），真实人类指令是开放集（"别太用力""就一点点劲""稍微托一下"）。离散标签无法覆盖连续语义，遇到未见措辞只能回退默认约束——**泛化不是分类准确率问题，而是安全约束的覆盖问题**。
> 3. **证据链只保「位」，不保「义」**：EPIR 用 seq_id+hash 保证 EV-exec 不丢、不乱序，但哈希只能证明**字节未被篡改**，不能证明**语义未被误解**。一条被正确传输、哈希匹配、但语义解析错误的指令，仍会生成一条"完全合规"的错误执行证据。

> 本轮核心转向：从**「位完整性」**（bit integrity）升级到**「义完整性」**（semantic integrity）。语音合成（TTS）不再只是输出通道，而被重新定义为**可控干预算子**：它能在保持语义不变的前提下干预说话人/语速/口音（检验不变性），也能在保持声学外观近似的前提下干预强调/否定/紧迫度（检验协变性）。由此把「指令泛化」从"多收集语料"变成"在因子空间中做反事实因果检验"。

## 0. 直觉与动机

**灵感 1（语音合成 → 反事实指令生成器 CFG：把 TTS 当 do-算子）**
直觉：TTS 的合成参数是可分解的——文本（语义）、说话人（音色）、语速、音高、强调、情感、噪声。传统做法把 TTS 当数据增强的"黑箱增广"；我们把它当**因果干预算子 do(·)**：固定文本 S，只干预某一因子 f，就得到一对**反事实指令** (x, x')。若解析器 φ 对 x 与 x' 给出显著不同的约束，就说明 φ 把**干扰因子**误当成了**语义因子**。关键洞见：**泛化的本质不是记住更多句子，而是学会在因子空间里"该不变的绝不变、该变的必须变"**。

**灵感 2（指令泛化 → 指令等价类与约束商空间 IQS）**
直觉：两条指令是否"等价"，不该由意图标签决定，而应由它们诱导的**安全约束集**决定。定义 I₁ ~_ε I₂ ⟺ d_C(φ(I₁), φ(I₂)) ≤ ε，其中 d_C 是约束空间的安全度量（力上限、速度上限、阻抗边界、轨迹容差）。于是指令空间被商成若干"约束胞"（constraint cell），泛化 = 把未见措辞映射到正确的约束胞，而不是映射到某个离散意图标签。关键洞见：**标签空间会制造虚假的离散化，商空间才保留安全语义的连续性**。

**灵感 3（语音合成 → 可逆指令编译与回译一致性 RTCC）**
直觉：一个可信的编译器应该"编得过去、也译得回来"。若 I → C 正确，则把 C 用受控语言渲染成 ψ(C)，再经 TTS 合成、ASR 识别、重新解析，应回到同一个约束胞：φ(ASR(TTS(ψ(C)))) ≈ C。把这种**回译一致性** ρ(I) 作为无需人工标注的自监督信号：ρ 大 ⇒ 该指令处于语义歧义区。关键洞见：**语音合成是语义的镜子——它把"隐藏的误解"变成"可观测的不一致"**。

**灵感 4（合流 → 主动指令泛化闭环 AIGL）**
直觉：CFG 找到反事实敏感区，RTCC 找到歧义区，二者交集就是"最该问人"的指令。对这些指令，机器人用 TTS 合成**澄清问句**（"您是要我'轻触'还是'夹紧'？"），一次人类回答同时修正解析器与约束商空间。关键洞见：**澄清不是被动等待，而是把人类注意力当作最稀缺的泛化预算来主动分配**——只在 VOI 最高的歧义点发问。

**灵感 5（语言-物理对偶证书 LPC → 打破共模坍缩）**
直觉：RTCC 有一个致命盲点：若渲染器 ψ 与解析器 φ 共享同一语义偏差，则"错得一致"也能通过回译——这是自编码器式的**共模坍缩**。破解之道是引入**独立的物理锚点**：约束 C 会预测一个安全执行结果（力/位/滑移的可行域），真实执行证据 EV-exec 由物理世界给出，与语言模型独立。若 C 预测"安全"而 EV-exec 显示"越界/滑移/超力"，则无论回译多自洽，φ 必错。**语言自洽 + 物理自洽 = 对偶证书**；单边自洽一律降级为"可疑"。

**灵感 6（PCE+++++ → 语言-泛化-信任三维预算）**
直觉：主动澄清会消耗三样稀缺资源：合成/识别算力 B_verbal、泛化探索样本 B_gen、以及最容易被忽视的**人类耐心 B_trust**（每次打断都在消耗信任）。若 B_trust 耗尽仍强行澄清，会把"安全系统"变成"烦人系统"，人类开始敷衍回答，反而制造新的语义噪声。预算耗尽时必须切换到"保守执行 + 明确告知"的静默模式。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（合成因子空间与反事实指令生成器 CFG）** 因子空间 F = F_sem × F_pros × F_spk × F_env，其中 F_sem 为语义因子（意图、槽位、否定、量级），F_pros 为韵律因子（强调、紧迫度、停顿），F_spk 为说话人因子（音色、口音、性别），F_env 为信道因子（噪声、混响、带宽）。合成算子 Syn: (text, f) → waveform。反事实对：
CFG(text, k) = (Syn(text, f), Syn(text, f^{[k←a]}), k)，即仅干预因子 k。
语义/干扰二分：F_sem ∪ F_pros^sem 为**语义因子**（必须协变），F_spk ∪ F_env ∪ F_pros^nuis 为**干扰因子**（必须不变）。

**定义 162（指令等价类与约束商空间 IQS）** 设 φ: X → C 为指令→约束解析器，d_C 为约束空间安全度量。指令等价关系 I₁ ~_ε I₂ ⟺ d_C(φ(I₁), φ(I₂)) ≤ ε。商空间 Q_ε = X / ~_ε，其每个元素称为**约束胞** c = [I]_ε，代表约束 C_c。泛化算子 G: X_unseen → Q_ε 把未见指令映射到约束胞；**泛化正确** ⟺ G(I) 的约束胞包含人类标注的真实安全约束 C*(I)，即 d_C(C_{G(I)}, C*) ≤ ε。

**定义 163（因子不变性/协变性与泛化界）** 对干扰因子 k ∈ F_nuis，不变性误差
Inv_k(φ) = E_{text,f} d_C(φ(Syn(text,f)), φ(Syn(text,f^{[k←a]})))。
对语义因子 k ∈ F_sem，协变性裕度
Cov_k(φ) = E_{text,f} d_C(φ(Syn(text,f)), φ(Syn(text,f^{[k←a]})))，要求 Cov_k ≥ δ_sem。
局部 Lipschitz 常数 L(I) = sup_{I'∈N_δ(I)} d_C(φ(I),φ(I')) / d_I(I,I')。
**泛化界**：若 φ 对 F_nuis 严格不变（Inv=0）且局部 L-Lipschitz，则对任意未见指令 I，
E[d_C(φ(I), C*(I))] ≤ L·ε_embed(I) + Σ_k Inv_k + δ_parse，
其中 ε_embed 为语义嵌入的覆盖误差，δ_parse 为解析器固有偏差。该界说明：**泛化误差 = 语义分辨率损失 + 干扰泄漏 + 解析偏差**，三者可分别用 CFG 度量。

**定义 164（可逆指令编译与回译一致性 RTCC）** 渲染器 ψ: C → Text 把约束渲染为自然语言；回译算子
RT(I) = φ(ASR(Syn(ψ(φ(I)), f_neutral)))。
回译不一致度 ρ(I) = d_C(φ(I), RT(I))。判定：RT_pass(I) ⟺ ρ(I) ≤ τ_rt。
注意 RTCC 是**必要非充分**检验：ρ 小不能证明 φ 正确（共模坍缩），故必须与物理锚点联用（定义 166）。

**定义 165（主动指令泛化闭环 AIGL）** 歧义集 A = {I | ¬RT_pass(I) ∨ L(I) > L_max ∨ ∃k∈F_nuis: Inv_k(I) > δ_inv}。澄清价值
VOI_clar(I) = P_sem_err(I)·ΔCost_safety(I) − cost_verbal(I) − λ_trust·cost_trust(I)。
每轮选取 I* = argmax_{I∈A} VOI_clar(I)，合成澄清问句 q = Clarify(I*, c_{I*}, RT(I*))，获得人类回答 h 后做约束商空间更新：
φ ← argmin_φ Σ_{I∈D} d_C(φ(I), C*(I)) + λ·Σ_{k∈F_nuis} Inv_k(φ) − μ·Σ_{k∈F_sem} Cov_k(φ)。

**定义 166（语言-物理对偶证书 LPC / J_gen）** 泛化证书
J_gen = (coverage(Q_ε), max_k Inv_k, min_I RT_margin(I), L_max, n_clarify, J_phys)，
其中 J_phys 由 EV-exec 给出：若执行越界（|F|>F_max ∨ 滑移>s_max ∨ |Δx|>x_tol）则 J_phys=0。
**对偶判定**：J_gen.valid ⟺ (coverage ≥ θ_cov) ∧ (Inv ≤ θ_inv) ∧ (RT_margin ≥ θ_rt) ∧ (L ≤ θ_L) ∧ (J_phys = 1)。
**关键定理（反共模）**：若存在物理探针使 φ 与 ψ 的偏差可被 EV-exec 区分，则 J_phys=1 且 RT_pass 可排除共模坍缩导致的假通过（证明见 §3）。

**定义 167（PCE+++++ 语言-泛化-信任预算）** B_verbal = (Syn_ops, ASR_latency, Clarify_bandwidth)，B_gen = (Probe_budget, Quotient_coverage_target, Active_sample_budget)，B_trust = (Human_interrupt_rounds, Patience_decay, Trust_margin)，B_exec 沿用第 60 轮。预算约束下的价值：
voi_gen(π) = VOI_meta_pessimistic(π) − cost_verbal − cost_gen − λ_trust·cost_trust − cost_exec。
若 B_verbal 耗尽 ⇒ 关闭 CFG/RTCC，仅用保守先验；若 B_gen 耗尽 ⇒ 冻结商空间，只做查表；若 B_trust < θ_trust ⇒ **禁止主动澄清**，切换"保守执行 + 事后告知"。

**定义 168（安全-泛化联合决策 SGD）** 给定指令 I，动作集 A = {EXECUTE, CLARIFY, FALLBACK}：
```
if J_gen.valid and RT_pass(I) and SIC_valid:
    return (EXECUTE, φ(I))
elif B_verbal.ok and B_trust.ok and VOI_clar(I) > 0:
    return (CLARIFY, Clarify(I))
else:
    return (FALLBACK, φ_conservative(I))   # 最保守约束 + 明确告知
```
决策原则：**能用物理证据确认的才执行，能问人的才澄清，否则一律保守回退**。

## 2. 关键算法伪代码

### IP-161 CFG（反事实指令生成器）

```python
class CounterfactualInstructionGenerator:
    NUISANCE = ['speaker', 'rate', 'accent', 'noise']
    SEMANTIC = ['emphasis', 'urgency', 'negation', 'magnitude']

    def __init__(self, tts, n_pairs=8):
        self.tts, self.n_pairs = tts, n_pairs

    def pair(self, text, factor, a=None, b=None):
        base = self._sample_factors()
        fa, fb = dict(base), dict(base)
        fa[factor] = a if a is not None else self._sample(factor)
        fb[factor] = b if b is not None else self._sample(factor)
        return self.tts.synth(text, fa), self.tts.synth(text, fb), factor

    def probe(self, texts):
        return [self.pair(t, k)
                for t in texts for k in self.NUISANCE + self.SEMANTIC]
```

### IP-162 IQS（指令商空间）

```python
class InstructionQuotientSpace:
    def __init__(self, phi, dC, eps=0.05):
        self.phi, self.dC, self.eps = phi, dC, eps
        self.cells = []                      # list of (cell_id, C_rep)

    def assign(self, instruction):
        C = self.phi(instruction)
        for cid, rep in self.cells:
            if self.dC(C, rep) <= self.eps:
                return cid, C
        cid = len(self.cells)
        self.cells.append((cid, C))
        return cid, C

    def generalize(self, unseen):
        return self.assign(unseen)           # 泛化 = 映射到正确约束胞
```

### IP-163 FGM（泛化度量）

```python
def factor_metrics(phi, cfg, text, dC):
    inv, cov = {}, {}
    for a, b, k in cfg.probe([text]):
        (inv if k in cfg.NUISANCE else cov)[k] = dC(phi(a), phi(b))
    return inv, cov

def local_lipschitz(phi, dI, text, neighbors, dC):
    C0 = phi(text)
    return max(dC(C0, phi(n)) / max(dI(text, n), 1e-6) for n in neighbors)

def generalization_bound(L, eps_embed, inv_sum, delta_parse):
    return L * eps_embed + inv_sum + delta_parse
```

### IP-164 RTCC（回译一致性）

```python
class RoundTripConsistencyChecker:
    def __init__(self, phi, render, tts, asr, dC, tau_rt=0.10):
        self.phi, self.render, self.tts, self.asr = phi, render, tts, asr
        self.dC, self.tau_rt = dC, tau_rt

    def check(self, instruction):
        C1 = self.phi(instruction)
        text2 = self.render(C1)
        wav2 = self.tts.synth(text2, self._neutral())
        C2 = self.phi(self.asr.transcribe(wav2))
        rho = self.dC(C1, C2)
        return rho <= self.tau_rt, rho, C1, C2
```

### IP-165 AIGL（主动指令泛化闭环）

```python
def active_instruction_generalization(phi, cfg, rtcc, human, budget, dI, dC):
    ambiguous = []
    for I in phi.seen:
        ok, rho, C1, C2 = rtcc.check(I)
        inv, cov = factor_metrics(phi, cfg, I, dC)
        L = local_lipschitz(phi, dI, I, cfg.neighbors(I), dC)
        if (not ok) or L > budget.L_max \
                or max(inv.values(), default=0.0) > budget.delta_inv:
            ambiguous.append((I, rho, L, C1, C2))

    while ambiguous and budget.verbal_ok() and budget.trust_ok():
        I, rho, L, C1, C2 = max(ambiguous, key=lambda x: voi_clar(x, budget))
        q = clarify_text(I, C1, C2)
        wav = tts.synth(q, prosody='clarifying')
        answer = human.respond(wav)
        phi.update(I, answer)
        budget.spend_verbal(q)
        budget.spend_trust()
        ambiguous = [a for a in ambiguous if not rtcc.check(a[0])[0]]
    return phi, ambiguous, budget
```

### IP-166 LPC（语言-物理对偶证书）

```python
@dataclass
class GeneralizationCertificate:
    coverage: float
    inv_max: float
    rt_margin_min: float
    lipschitz_max: float
    n_clarify: int
    j_phys: int                      # 由 EV-exec 物理校验给出

    def valid(self, th):
        return (self.coverage >= th.cov and self.inv_max <= th.inv
                and self.rt_margin_min >= th.rt
                and self.lipschitz_max <= th.L and self.j_phys == 1)
```

### IP-167 PCE+++++（语言-泛化-信任预算）

```python
class VerbalGeneralizationBudget:
    def __init__(self, syn_ops=200, gen_ops=100, trust_rounds=3):
        self.syn_left, self.gen_left, self.trust_left = syn_ops, gen_ops, trust_rounds

    def verbal_ok(self): return self.syn_left > 0
    def trust_ok(self):  return self.trust_left > 0
    def spend_verbal(self, q): self.syn_left -= estimate_syn_cost(q)
    def spend_trust(self): self.trust_left -= 1

    def mode(self):
        if self.trust_left <= 0: return 'silent_conservative'
        if self.gen_left <= 0:   return 'frozen_quotient'
        if self.syn_left <= 0:   return 'no_verbal_probe'
        return 'normal'
```

### IP-168 SGD（安全-泛化联合决策）

```python
def safety_generalization_decision(I, phi, rtcc, j_gen, sic, budget, th):
    ok, rho, C1, C2 = rtcc.check(I)
    if j_gen.valid(th) and ok and sic.valid():
        return ('EXECUTE', C1)
    if budget.verbal_ok() and budget.trust_ok() and voi_clar(I, budget) > 0:
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CFG | O(N_text · N_factor · T_syn) | O(N_pair) | 因子覆盖 ≥ 90%，单因子干预可验证 |
| IQS | O(N_cell) 查表 / O(N_cell·d) 更新 | O(N_cell) | 未见指令映射到正确约束胞 ≥ 85% |
| RTCC | O(T_syn + T_asr + T_parse) | O(1) | 歧义检出 AUROC ≥ 0.90，假通过率 ≤ 2% |
| AIGL | O(|A| · rounds) | O(|A|) | 每轮澄清消歧率 ≥ 70%，B_trust 不超支 |
| LPC | O(1) 校验 | O(1) | 语言-物理对偶一致率 ≥ 99% |

**正确性定理（VIGOR）**：设 A66–A70 成立：
- **(A66)** CFG 的因子干预可分离，且语义/干扰划分与真实因果图一致；
- **(A67)** 解析器 φ 对干扰因子满足 Inv_k ≤ δ_inv，对语义因子满足 Cov_k ≥ δ_sem；
- **(A68)** 回译链路 Syn/ASR 的语义保真度有界（语义失真 ≤ δ_rt），且渲染器 ψ 与 φ 的偏差可被物理探针区分（反共模条件）；
- **(A69)** EV-exec 的物理校验与语言模型独立，且越界事件可观测；
- **(A70)** B_verbal/B_gen/B_trust 单调消耗，耗尽即切换安全模式。

则：
1. **泛化界**：对未见指令，E[d_C(φ(I),C*(I))] ≤ L·ε_embed + ΣInv_k + δ_parse。
2. **歧义可检出**：若 φ(I) 与真实约束偏差 > ε，且 RT 链路失真 ≤ δ_rt，则 ρ(I) > τ_rt 的概率随偏差单调上升（RTCC 是偏差的单调代理）。
3. **反共模**：在 A68 的反共模条件下，J_gen.valid ⇒ 不存在"语言自洽但物理错误"的假通过。
4. **预算安全**：任一预算耗尽 ⇒ 进入 silent_conservative / frozen_quotient / no_verbal_probe，绝不强行澄清或执行。

**反共模证明思路**：设 φ 与 ψ 共享偏差 e，则 RT 输出 C+e 经 ψ/φ 后仍为 C+e，ρ≈0；但物理执行由真实约束 C* 驱动，若 e 导致越界，EV-exec 给出 J_phys=0，于是 J_gen.valid=0。故物理锚点切断了"自洽错误"的通过路径。反之若 e 不导致可观测越界，则 e 落在安全等价类内，误判无害——这正是我们允许的 ε 容差。

## 2. 关键算法伪代码

### IP-161 CFG（反事实指令生成器）

```python
class CounterfactualInstructionGenerator:
    NUISANCE = ['speaker', 'rate', 'accent', 'noise']
    SEMANTIC = ['emphasis', 'urgency', 'negation', 'magnitude']

    def __init__(self, tts, n_pairs=8):
        self.tts, self.n_pairs = tts, n_pairs

    def pair(self, text, factor, a=None, b=None):
        base = self._sample_factors()
        fa, fb = dict(base), dict(base)
        fa[factor] = a if a is not None else self._sample(factor)
        fb[factor] = b if b is not None else self._sample(factor)
        return self.tts.synth(text, fa), self.tts.synth(text, fb), factor

    def probe(self, texts):
        return [self.pair(t, k)
                for t in texts for k in self.NUISANCE + self.SEMANTIC]
```

### IP-162 IQS（指令商空间）

```python
class InstructionQuotientSpace:
    def __init__(self, phi, dC, eps=0.05):
        self.phi, self.dC, self.eps = phi, dC, eps
        self.cells = []                      # (cell_id, C_rep)

    def assign(self, instruction):
        C = self.phi(instruction)
        for cid, rep in self.cells:
            if self.dC(C, rep) <= self.eps:
                return cid, C
        cid = len(self.cells)
        self.cells.append((cid, C))
        return cid, C

    def generalize(self, unseen):
        return self.assign(unseen)           # 泛化 = 映射到正确约束胞
```

### IP-163 FGM（泛化度量）

```python
def factor_metrics(phi, cfg, text, dC):
    inv, cov = {}, {}
    for a, b, k in cfg.probe([text]):
        (inv if k in cfg.NUISANCE else cov)[k] = dC(phi(a), phi(b))
    return inv, cov

def local_lipschitz(phi, dI, text, neighbors, dC):
    C0 = phi(text)
    return max(dC(C0, phi(n)) / max(dI(text, n), 1e-6) for n in neighbors)

def generalization_bound(L, eps_embed, inv_sum, delta_parse):
    return L * eps_embed + inv_sum + delta_parse
```

### IP-164 RTCC（回译一致性）

```python
class RoundTripConsistencyChecker:
    def __init__(self, phi, render, tts, asr, dC, tau_rt=0.10):
        self.phi, self.render, self.tts, self.asr = phi, render, tts, asr
        self.dC, self.tau_rt = dC, tau_rt

    def check(self, instruction):
        C1 = self.phi(instruction)
        text2 = self.render(C1)
        wav2 = self.tts.synth(text2, self._neutral())
        C2 = self.phi(self.asr.transcribe(wav2))
        rho = self.dC(C1, C2)
        return rho <= self.tau_rt, rho, C1, C2
```

### IP-165 AIGL（主动指令泛化闭环）

```python
def active_instruction_generalization(phi, cfg, rtcc, human, budget, dI, dC):
    ambiguous = []
    for I in phi.seen:
        ok, rho, C1, C2 = rtcc.check(I)
        inv, cov = factor_metrics(phi, cfg, I, dC)
        L = local_lipschitz(phi, dI, I, cfg.neighbors(I), dC)
        if (not ok) or L > budget.L_max \
                or max(inv.values(), default=0.0) > budget.delta_inv:
            ambiguous.append((I, rho, L, C1, C2))

    while ambiguous and budget.verbal_ok() and budget.trust_ok():
        I, rho, L, C1, C2 = max(ambiguous, key=lambda x: voi_clar(x, budget))
        q = clarify_text(I, C1, C2)
        wav = tts.synth(q, prosody='clarifying')
        answer = human.respond(wav)
        phi.update(I, answer)
        budget.spend_verbal(q)
        budget.spend_trust()
        ambiguous = [a for a in ambiguous if not rtcc.check(a[0])[0]]
    return phi, ambiguous, budget
```

### IP-167 PCE+++++（语言-泛化-信任预算）

```python
class VerbalGeneralizationBudget:
    def __init__(self, syn_ops=200, gen_ops=100, trust_rounds=3):
        self.syn_left, self.gen_left, self.trust_left = syn_ops, gen_ops, trust_rounds

    def verbal_ok(self): return self.syn_left > 0
    def trust_ok(self):  return self.trust_left > 0
    def spend_verbal(self, q): self.syn_left -= estimate_syn_cost(q)
    def spend_trust(self): self.trust_left -= 1

    def mode(self):
        if self.trust_left <= 0: return 'silent_conservative'
        if self.gen_left <= 0:   return 'frozen_quotient'
        if self.syn_left <= 0:   return 'no_verbal_probe'
        return 'normal'
```

```python
def safety_generalization_decision(I, phi, rtcc, j_gen, sic, budget, th):
    ok, rho, C1, C2 = rtcc.check(I)
    if j_gen.valid(th) and ok and sic.valid():
        return ('EXECUTE', C1)
    if budget.verbal_ok() and budget.trust_ok() and voi_clar(I, budget) > 0:
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| CFG | O(N_text·N_factor·T_syn) | O(N_pair) | 因子覆盖 ≥ 90% |
| IQS | O(N_cell) / 更新 O(N_cell·d) | O(N_cell) | 泛化到正确约束胞 ≥ 85% |

| AIGL | O(|A|·rounds) | O(|A|) | 消歧率 ≥ 70%，B_trust 不超支 |
| LPC | O(1) | O(1) | 语言-物理一致率 ≥ 99% |

**正确性定理（VIGOR）**：若 A66–A70 成立（因子干预可分离；φ 对干扰不变、对语义协变；回译链路语义保真且满足反共模条件；EV-exec 与语言独立可观测；三维预算单调消耗），则：
1. 泛化界 `E[d_C(φ(I),C*(I))] ≤ L·ε_embed + ΣInv_k + δ_parse`；
2. 偏差越大，`ρ(I) > τ_rt` 的概率单调上升（RTCC 是偏差的单调代理）；
3. `J_gen.valid ⇒` 不存在"语言自洽但物理错误"的假通过；
4. 任一预算耗尽 ⇒ 进入 silent_conservative / frozen_quotient / no_verbal_probe。

**反共模证明思路**：若 ψ 与 φ 共享偏差 e，回译输出仍为 C+e，ρ≈0；但真实执行由 C* 驱动，e 导致越界时 EV-exec 置 J_phys=0，故 J_gen 不通过。若 e 不引发可观测越界，则 e 落在安全等价类内，误判无害——这正是 ε 容差所允许的。
