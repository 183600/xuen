# 第 41 轮 · 双灵感落地 v8：共享控制即认证条件化 × VLA 提议—证书处置（四层架构 v6）

> 承接第 40 轮（v17：可认证流匹配执行 × 度量语义几何锚定 × 证书驱动课程引擎，四层架构 v5）。本轮灵感词「共享控制、VLA」把第 40 轮的证书闭环向外推了一步：既不再假设系统全自主，也不再假设意图只由内部任务代数产生。共享控制回答「权威（authority）如何安全地让渡给人」，VLA 回答「开放世界意图如何进入系统」；两者都被压缩成同一个「条件接口」，由流匹配证书 + CBF 盾 + 类型系统统一接管。

## 0. 直觉与动机

**灵感 1（共享控制 → 权威是可以被证书度量的资源）**：直觉上，共享控制就是「人推一点、机器补一点」，工程上常写成 u = α·u_a + (1−α)·u_h 这样一个混合系数。但 α 凭什么取 0.3 而不是 0.7？过去靠调参或人因实验。第 40 轮的流匹配证书给了新视角：只要把人的意图当成速度场的**条件变量** ξ_h，那么「人对动作的影响」就变成一个可证的敏感度问题——速度场对条件的 Lipschitz 常数 L_ξ 与流收缩率 κ 一起，给出 ‖Δ动作‖ ≤ (L_ξ/κ)(1−e^{−κT})‖Δξ‖（与 ODE 误差界同构）。于是 α 不再是拍脑袋的旋钮，而是「在剩余安全裕度内允许多大的条件偏移」的预算分配：α* = 安全预算 /（条件敏感度 × 人机意图差）。共享控制的本质从「混合两路控制」升级为「认证条件化 + 权威预算」。

**灵感 2（VLA → 提议者，而不是执行者）**：直觉上，VLA（视觉-语言-动作）让人一句话就能指挥机器人，但它又大又慢又爱幻觉，直接把它接到底层执行等于把安全交给一个不可证的黑箱。第 40 轮已经把动作生成做成可认证的小流匹配头，这给了一个干净分工：让 VLA 只产出**带类型的意图提议**（语言 + 点云落地的实体 + 技能组合），动作仍由已认证的动作头生成；VLA 提供开放世界的「广度」，证书体系提供执行层的「可信度」。再用保形预测（conformal）给提议配一个带覆盖保证的候选集：只有候选集收缩为单点、且能通过 IP-47 类型检查时才执行，否则回退到共享控制问人。VLA 从「驾驶员」降格为「领航员」。

**灵感 3（两者的公共结构 → 条件接口与证书-规模解耦）**：VLA 的视觉语言嵌入 z_vla 与人的意图 ξ_h，本质上都是作用在同一个动作头上的**条件**。于是可以把巨大的、不可证的 VLM 与小的、可证的动作头用「条件接口」隔开：**证书只覆盖动作头 + 盾，不覆盖 VLA**；VLA 再怎么扩容、换模型，都不会让证书失效，只会让条件分布变化。这化解了第 40 轮潜在的「证书紧致性」与「模型规模」正面冲突——证书与规模解耦。代价是：条件接口成了新的攻击面，必须由 L_ξ 敏感度界、保形覆盖与 CBF 盾三道闸门共同把守。

**三者耦合**：共享控制给出「权威维度的认证」，VLA 给出「意图维度的认证」，流匹配动作头给出「执行维度的认证」；三者共享同一个条件接口，形成「人类/VLA 提议 → 类型检查 → 证书闸门 → 认证流执行 → 盾投影 → 反哺课程」的统一闭环。

## 1. 形式化定义

**定义 27（共享条件化策略）**：给定第 40 轮的认证流 v_θ(x, τ; c, s, g)，把共享控制写成条件扩展 ξ = (ξ_h, z_vla)：
- ξ_h：人类意图目标（由手柄/语言/视线估计得到，落成参考轨迹 r_h 及其不确定球 Δ_h）；
- z_vla：VLA 的视觉语言条件嵌入；
策略变为 v_θ(x, τ; c ⊕ ξ)，其中 c 含任务与几何证书。权威 α ∈ [0,1] 定义在**参考层**而非速度层：r_α = (1−α)·r_h + α·r_a，r_a 为自主认证策略的名义参考。

**定义 28（条件敏感度证书 CertShared）**：设 v_θ 在状态上 κ-收缩（第 40 轮定义 24），在条件上 L_ξ-Lipschitz，条件允许偏移 Δ_ξ。定义
- ε_ξ = (L_ξ/κ)(1 − e^{−κT})·Δ_ξ（Gronwall + 收缩性导出，与 ε_ode 同构）；
- 权威预算 α* = clamp( (h(x) − B_t − margin) / (L_ξ·‖r_h − r_a‖ + ε_ξ + η), 0, 1 )；
- **定理（条件化安全）**：若 α ≤ α* 且 CBF 盾在混合之后投影，则对任意 r_h 都保持 h(x) ≥ B_t；且 ‖φ(ξ) − φ(ξ′)‖ ≤ ε_ξ。
- **推论（混合保收缩）**：两个 κ-收缩速度场的任意凸混合仍收缩，κ_blend ≥ min(κ_a, κ_h)——共享控制不会破坏组合证书。

**定义 29（VLA 提议与处置）**：VLA 提议 ρ = (ℓ, G, Π)：ℓ 为语言指令，G 为落地实体（点云坐标 + 语义标签），Π 为 IP-47 技能组合式。类型规则：
- ρ : C_ms 当且仅当 ground(G) 的保形置信集为单点、且 Π 在 IP-47 下类型检查通过（C_ms 蕴含成立）；
- 处置律（propose–dispose）：执行误差 ≤ 落地误差 ε_g + 组合收缩误差 ε_comp + 流误差 ε_ode（三项各有证书）。VLA 不直接产生底层动作。

**定义 30（保形意图置信与交互消歧）**：以历史 (ℓ, G, Π) 构造非一致性分数 s(ρ, ρ̂)，保形阈值 q_{1−δ} 给出候选集 C_δ(ℓ)，满足 P(ρ_true ∈ C_δ) ≥ 1−δ。若 |C_δ| > 1 或单点未通过类型检查，则触发**共享控制消歧**：把候选集作为可选项，与权威分配一起呈现，本轮 α 降到消歧模式。

## 2. 三大产出设计

### 2.1 IP-51 SHARED-AUTHORITY-CERT（共享权威证书与权威预算）
1. 条件接口：把人类参考 r_h、VLA 嵌入 z_vla 统一为 ξ；条件编码器置于认证边界之外（不可证、可替换）。
2. CertShared 估计：L_ξ 用与 L_v 相同的谱归一化 + 幂迭代（对条件雅可比），κ 复用定义 24；在线输出 ε_ξ 与 α*。
3. 权威分配：最大化 α 且满足「预测裕度 ≥ 0」与「意图一致性 ≥ τ」——最不限制的权威（least restrictive authority），用滑动时域 QP 求解。
4. CBF 盾：混合后统一投影，保证任意人类输入下的前向不变性；盾触发率作为第 40 轮熔断器的第五触发器。
5. 接管与降级：α→0（自主接管）或安全停（IP-38）；接管过程的最小加加速度轨迹由 IP-43 韵律流生成，避免突兀切换。

### 2.2 IP-52 VLA-INTENT-PROPOSER（VLA 提议—证书处置）
1. 双频异步：VLA 低频（1–2 Hz）产出提议 ρ；认证流高频（50 Hz）执行；VLA 不阻塞控制环。
2. 落地与类型：G 经 IP-49 投影到点云得到 C_ms；Π 经 IP-47 做含球包含的类型检查；不通过则整条提议弃用（不部分执行）。
3. 保形校准：按任务族分组构造非一致性分数，在线更新 q_{1−δ}；分布漂移监测（与 IP-50 证书赤字联动）触发重校准。
4. 反事实自检：复用 IP-48 的流头对每个候选做短时域 rollout，用证书估计风险，作为处置前最后一道筛选（几乎不增加延迟，因为复用同一动作头）。
5. 消歧：多候选或低置信 → 进入 IP-51 的人机消歧，VLA 只给选项、不做决定。

### 2.3 IP-53 INTERACTIVE-CERT-CURRICULUM（交互式证书课程）
1. 数据引擎：人类接管/纠正轨迹与 VLA 被盾拒绝的提案自动进入 IP-50 任务池，带「证书赤字 + 权威赤字 + 歧义度」三重难度权重。
2. 安全探索：只在 CBF 盾保护下收集人类纠正数据（human-gated DAgger），保证课程采样不引入不可逆风险。
3. 反事实课程：对「VLA 自信但被拒」的样本加权，专门扩张条件编码器的边界区域（edge-of-competence），而动作头认证不变。
4. 闭环：课程 → 蒸馏 → 重颁流证书/条件证书 → 契约热更新；人类纠正只在条件层沉淀，不破坏已验证的动作头证书。

## 5. 本轮最大风险

**一句话**：把 VLA 与人类降格为「条件接口」后，证书只保证动作头在条件分布内几何安全——一旦 VLA 在分布外自信地给出语义错误提案、或人类持续把条件推出认证信任半径，系统就会「安全地做错事」（证书洗白），或退化为 α→0 的全自主使共享控制名存实亡。

### IP-51 共享权威证书与权威预算（伪代码）

def certify_condition_field(v_theta, xi):
    apply_spectral_norm_to_condition_encoder(v_theta)
    L_xi  = power_iteration_condition_jacobian(v_theta, xi)   # 条件谱上界
    kappa = reuse(CertFlow.kappa)                             # 动作头证书，定义 24
    eps_xi = (L_xi / kappa) * (1 - exp(-kappa*T)) * Delta_xi
    return CertShared(L_xi, kappa, eps_xi)

def allocate_authority(h_x, B_t, r_h, r_a, cert, eta):
    delta = norm(r_h - r_a)
    alpha_cap = clamp((h_x - B_t - margin) /
                      (cert.L_xi*delta + cert.eps_xi + eta), 0, 1)
    alpha = solve_sliding_horizon_qp(
        maximize=alpha,
        s.t. predicted_margin(alpha) >= 0, intent_agreement(alpha) >= tau)
    return min(alpha, alpha_cap)                              # 最不限制的权威

def shared_control_step(x_hat, u_auto, u_h, alpha, h, B_t):
    u_blend = (1-alpha)*u_h + alpha*u_auto
    u_safe, intervened = cbf_shield(u_blend, h, B_t)          # 前向不变性兜底
    if intervened:
        rca.note_shield_event()
        alpha = reduce_authority(alpha)                       # 第五熔断触发器
    return u_safe, alpha

def blend_contraction(v_a, v_h):                               # 推论：混合保收缩
    return max(min(kappa(v_a), kappa(v_h)), 0)
```

def vla_propose(obs, instruction, delta):
    z = vlm.encode(obs, instruction)                          # 大模型，不可证，置于认证边界外

def dispose(rho_list, policy_bank):
    if len(rho_list) != 1:
        return ask_human_via_shared_control(rho_list)         # 消歧，VLA 不做决定
    rho = rho_list[0]

        with cbf_shield_guard():                              # human-gated DAgger
            traj, human = rollout_with_takeover(t, policy_bank)
        buffer.add(filter_certified(traj, CertShared))
    if cert_drift_detected():
        RCA.reissue()
        Registry.hot_reload(contracts)                        # 仅条件层更新，动作头证书不变
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 正确性保证 |
|---|---|---|
| L_ξ 认证 | 条件雅可比幂迭代 O(K·Σn_l·d_l·d_cond)，分钟级 | 上界可证；条件接口不改动作头证书 |
| α* 分配 | 滑动时域 QP，ms 级 | **定理**：α≤α* ⇒ 条件化安全 + 前向不变性 |
| CBF 盾 | 每步 O(d²) QP | 任意人类输入下 h(x)≥B_t（前向不变） |
| 保形提议 | VLA 前向摊销 O(1)，重校准分钟级 | P(ρ_true∈C_δ)≥1−δ（可交换性假设） |
| 处置律 | O(|Π|) 类型检查 + 短时域 rollout | 执行误差 ≤ ε_g+ε_comp+ε_ode（三项证书） |
| 混合保收缩 | O(1) | κ_blend ≥ min(κ_a,κ_h)（凸性） |
| 交互课程 | O(6+3)/任务；带采样 O(1) | Robbins-Monro + 安全探索约束 ⟹ 依概率收敛 |

## 4. 实验设计（E73-E78，硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E73 共享权威安全-效率曲线 | 各级 α、各类人类操作下的碰撞率 vs 纯遥操作/纯自主 | α≤0.7 碰撞率<0.5%；完成率不劣于纯遥操作 10% |
| E74 VLA 提议有效性 | 类型检查通过率、落地实体误差、幻觉率 | 通过率≥90%，落地误差<5cm，危险执行 0 |
| E75 条件敏感度紧致性 | 认证 L_ξ/实测 L_ξ 比值、α* 平均利用率 | 比值≤3；正常操作下 α* 平均≥0.5 |
| E76 异步与接管 | VLA 提议延迟、接管延迟 p99、混合 jerk | 提议<300ms；接管 p99<200ms；jerk<纯自主 2x |
| E77 语义保真（防证书洗白） | 安全通过但语义做错的任务比率 | 错误任务率<2%，盾拒绝误报率可控 |
| E78 交互式课程效率 | 达标样本数 vs v17 无交互课程 | 节省≥30%，人类纠正量下降≥20% |

失败即回退：E73/E77 不达标 → 回退 v17（纯自主、无 VLA 提议）；IP-51 仅保留「CBF 盾 + 权威上限」作安全监视器，IP-52/53 转离线数据工具。

## 5. 风险与缓解

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 条件分布漂移 → L_ξ/保形覆盖失效 | 高 | 在线漂移监测 + 分组重校准 + CBF 盾兜底；E74/E75 守门 |
| 证书洗白（几何安全但语义错误） | 高 | 新增 E77；处置律要求单点候选 + 类型检查 + 短时域反事实自检 |
| 权威退化 α→0，共享控制名存实亡 | 中 | 最不限制权威优化 + E75 利用率下限；放宽人类模型 |
| 人类对抗/误操作 | 中 | CBF 盾前向不变性理论兜底；超预算降级接管 |
| VLA 延迟抖动 | 中 | 双频异步 + 缓存上一提议 + 流式执行 |
| 保形可交换性被非平稳违反 | 中 | 在线加权保形 + 分布漂移触发保守阈值 |

## 6. 本轮最大风险

**一句话**：把 VLA 与人类降格为「条件接口」后，证书只保证动作头在条件分布内几何安全——一旦 VLA 在分布外自信地给出语义错误提案、或人类持续把条件推出认证信任半径，系统就会「安全地做错事」（证书洗白），或退化为 α→0 的全自主使共享控制名存实亡。
