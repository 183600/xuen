# 第 62 轮（承接第 61 轮「具身语义进化闭环」ESEC IP-173~182；灵感循环第 1 轮；本轮灵感：「腕部相机」×「上下文理解」）

> 第 61 轮用 USR/MEL/DMS/SRT-Dual 把「语义—物理—控制」接成闭环，但它的视觉输入仍是**「外部相机的无差别多视角堆叠」**，而「上下文」被简化为**单帧嵌入的拼接**。对「腕部相机」与「上下文理解」这两个词，它至少有五个未言明的漏洞：
> 1. **接触盲区**：外部第三人称相机在机械臂/手爪接近物体的最后 3–5cm 处被自身完全自遮挡，而这一段恰恰决定接触成败（间隙、滑移、形变、碰撞）。第 61 轮没有腕部第一人称视角，等于**在关键时刻闭着眼**。
> 2. **上下文≠历史拼接**：第 61 轮用 scene_emb/intent_emb 的上一帧做条件，这只是「memory」，不是「context」。真正的上下文有**微/中/宏三层时间尺度**（接触状态 ~ms、物体可供性 ~100ms–1s、任务/对话 ~10s），需要分层条件化与分层新鲜度；用宏观上下文去猜微观接触，必然产生语义-现实鸿沟。
> 3. **自运动污染**：腕部相机随腕运动，其画面变化**主要来自机器人自己**。若直接喂给 MEL，会把「我动了」误判为「世界变了」，产生自运动诱导的伪新息与**确认偏误**。
> 4. **视角-预算失配**：B_mel 是单一推理预算，没有回答「**该看哪个视角、看多久、看多细**」。腕部相机高帧率但窄视野，外部相机广视野但低分辨——缺少视角级 VOI 路由。
> 5. **投影头「无上下文」**：Π 只吃 scene_emb+intent_emb，接触瞬态（法向突变、切向滑移、接近速度）无法进入阻抗决策，导致「知道要小心，但不知道此刻怎么小心」。

## 0. 直觉与动机

**灵感 1（腕部相机 → 接触上下文显微镜 CCM）**
直觉：腕部相机不是「多一个视角」，而是一台**接触前的显微镜**。它贴在末端执行器上，能看见外部相机永远看不见的东西：指爪与物体之间的间隙、局部纹理、材料形变、接近速度、以及即将发生的滑移。关键洞见：**它观测的不是「场景」，而是「动作—接触—形变」的因果链**。因此它的输出不应是一个场景标签，而是一个**接触上下文向量** c_contact = (g_gap, n_contact, v_approach, d_deform, s_slip, τ_texture)，直接服务于阻抗与力控。

**灵感 2（上下文理解 → 三层上下文阶梯 CL）**
直觉：上下文不是「更多历史」，而是**不同时间尺度上可预测的那部分世界**。把它做成三层阶梯：微观层 c_micro（~1–20ms：接触/间隙/滑移）、中观层 c_meso（~0.1–1s：物体姿态/可供性/工具使用）、宏观层 c_macro（~1–10s：任务阶段/场景/对话意图）。关键洞见：**信息必须按层条件化**——用宏观层猜微观层是「用地图找门把手」，必然失真；把充分性定义成「在给定控制决策下，上下文对目标阻抗的条件互信息损失 ≤ ε」。

**灵感 3（上下文理解 → 动作条件上下文分解 ACCD）**
直觉：腕部图像的变化 = 自运动（ego-motion）+ 物体运动 + 形变 + 光照。若不做分解，模型会把「自己动了」学成「世界变了」。用本体感受与末端位姿把上一帧 warp 到当前视角：`r_t = I_w(t) − warp(I_w(t−1), T_ego(t))`，**只有 warp 后的残差才是外生上下文新息**。关键洞见：**上下文必须带「内生/外生」标签**，否则语义锚点会自激（这正是第 61 轮 SRT-Dual 未处理的隐性正反馈）。

**灵感 4（上下文理解 → 视角感知 VOI 路由 VVR）**
直觉：看哪里、看多久、看多细，本身就是决策。定义视角级价值：`VOI_view(v) = E[信息增益 | v] / (时延 + 能耗 + 遮挡风险 + 认知负荷)`。腕部相机在接触前 VOI 高、接触后可能被手指遮挡；外部相机在全局场景/人际交互 VOI 高。关键洞见：**视觉不是免费的**，应把视角选择纳入 PCE++++++ 预算，做「按需看图」而非「全图全帧落地大模型」。

**灵感 5（合流 → 上下文锚点双流 WCA-SRT，扩展 ESEC）**
直觉：把腕部上下文做成 USR 的一等公民。语义锚点升级为**上下文锚点 ContextAnchor**，为每层上下文维护独立 TTL（c_micro ~20ms、c_meso ~300ms、c_macro ~2s）与版本号；实时流用 c_micro 调制投影 `Π(K | c_micro)`，语义流用 c_meso/c_macro 驱动 MEL/DMS。关键洞见：**SRT-Dual 从「两流」升级为「两层时间尺度 × 三层上下文」的嵌套系统**，接触级实时性与任务级语义性各得其所。

**灵感 6（上下文理解 → 反事实上下文检验 CCC）**
直觉：腕部相机最大的危险是「看见自己想看见的」。上下文不能自证，必须交叉验证：把 c_micro 替换为「触觉直接测量」或「外部视角反推」的接触状态，若得到的 K* 显著不同，则上下文不可信 ⇒ 降低置信度、切换视角、触发澄清。关键洞见：**上下文的可信度应由「反事实一致性」而非「模型置信度」来度量**。

## 1. 形式化定义（增量：定义 173–184）

**定义 173（腕部相机接触上下文显微镜 CCM）** CCM = (Enc_w, Enc_t, Enc_p, Dec_c, Mode)。其中：
- **腕部图像编码器**：Enc_w: I_w × T_ego → ℝ^{d_w}，输入腕部相机图像流 I_w 与末端位姿 T_ego（来自本体感受/正运动学），输出视角不变特征
- **触觉编码器**：Enc_t: T → ℝ^{d_t}（力/力矩/接触位置序列）
- **本体编码器**：Enc_p: P → ℝ^{d_p}（关节位置/速度/力矩）
- **接触上下文解码头**：Dec_c: ℝ^{d_w+d_t+d_p} → c_contact ∈ ℝ^{d_c}，其中
  - g_gap ∈ ℝ⁺：指爪—物体间隙估计（接触前，单位 mm）
  - n_contact ∈ S²：接触点法向
  - v_approach ∈ ℝ⁺：沿法向的接近速度
  - d_deform ∈ ℝ：局部形变（由纹理/光流估计）
  - s_slip ∈ [0,1]：滑移前兆概率（切向光流散度 + 触觉切向力比）
  - τ_texture ∈ ℝ^{d_tex}：局部材质/纹理嵌入（用于物理属性 zero-shot）
- **模式判别器**：Mode: c_contact → {pre_contact, contact, slip, release}，驱动 Π_ctx 的分段增益

**定义 174（三层上下文阶梯 CL）** 上下文 C_t = (c_micro, c_meso, c_macro)，满足粗粒化关系 φ_{m→m−1}（微观可由中观条件化，而非反之）：
- **微观层** c_micro ∈ ℝ^{d_micro}：接触状态（间隙、法向、滑移、形变），时间常数 τ_μ ≈ 5ms，TTL_micro = 20ms
- **中观层** c_meso ∈ ℝ^{d_meso}：物体姿态、可供性、工具使用阶段，时间常数 τ_m ≈ 200ms，TTL_meso = 300ms
- **宏观层** c_macro ∈ ℝ^{d_macro}：任务阶段、场景类别、对话意图（复用第 61 轮 scene_emb/intent_emb），时间常数 τ_M ≈ 2s，TTL_macro = 2s
- **层间条件化**：p(c_micro | c_meso, c_macro, obs)，即微观层只在中观/宏观先验下解释观测，避免「跨层越级猜测」
- **阶梯更新**：c_l ← (1 − Δt/τ_l)·c_l + (Δt/τ_l)·E_l(obs, c_{l+1})，Δt 为当前层采样周期

**定义 175（上下文充分性 C_suff）** 设 X_{0:t} 为完整观测历史，d_t = K*_t 为真实最优阻抗决策（或其后验样本）。上下文 C_t 的**充分性缺口**定义为
```
Δ_suff(C_t) = I(X_{0:t}; d_t) − I(C_t; d_t)
```
若 Δ_suff(C_t) ≤ ε_suff，则称 C_t 是 ε_suff-充分的。等价地，用条件熵表述：H(d_t | C_t) − H(d_t | X_{0:t}) ≤ ε_suff。
**推论（分层必要性）**：若 C_t 只保留宏观层，则 Δ_suff 主要由接触瞬态贡献，通常 > ε_suff；因此**不同控制决策需要不同层的充分性**——实时阻抗决策需要微观层，任务规划需要宏观层。

**定义 176（动作条件上下文分解 ACCD）** 设 W_ego(·; T_ego(t−1→t)) 为用本体感受/末端位姿把上一帧 warp 到当前视角的算子。腕部残差
```
r_t = I_w(t) − W_ego(I_w(t−1); T_ego(t−1→t))
```
分解为
```
r_t = r_env(t) + r_contact(t) + r_light(t) + ε_t
```
- **内生分量** r_endo = r_contact + (warp 误差项)：可由「我们自己的动作」解释，**禁止**作为新息驱动语义更新
- **外生分量** r_exo = r_env + r_light 中与环境变化相关的部分：允许驱动 MEL 重推理
- **自运动解释率**：η_ego = ‖W_ego(I_w(t−1)) − I_w(t−1)‖ / ‖I_w(t) − I_w(t−1)‖ ∈ [0,1]，在线监控 warp 质量
- **外生性标签**：每一份上下文更新附带 `label ∈ {endo, exo, mixed}` 与置信度；`mixed` 时按 η_ego 加权拆分

**定义 177（上下文锚点 ContextAnchor 与分层 TTL）** 
```
ContextAnchor_t = (c_micro, c_meso, c_macro,
                   ts_micro, ts_meso, ts_macro,
                   ttl_micro, ttl_meso, ttl_macro,
                   src_mask, conf_vec, version, checksum)
```
- **分层新鲜度**：fresh_l(t) ⇔ (now − ts_l) < ttl_l ∧ conf_vec[l] ≥ τ_conf
- **写入原子性**：CAS 写入 + 64 位单调版本号（继承第 61 轮 SACP）
- **部分刷新**：允许只更新 c_micro 而保留 c_meso/c_macro，`src_mask` 记录哪些层在本版本被重算
- **降级**：某层过期时，实时流用该层的「上一有效值 + 不确定度膨胀」；宏观层过期不影响微观实时控制

**定义 178（视角感知 VOI 路由 VVR）** 视角集合 V = {wrist, ext_1, …, ext_N, tactile}，每个视角 v 有动作 a_v = (分辨率 ρ_v, 帧率 f_v, 上下文层 ℓ_v, 裁剪 ROI)。视角级价值：
```
VOI_view(v) = Î(Y_v ; d_t | C_t) / (lat_v(a_v) + λ_e·energy_v(a_v) + λ_o·occlusion_v + λ_c·load_v)
```
路由策略 π_vvr 在预算 B_ctx 下选择子集 S ⊆ V：
```
S* = argmax_S  Σ_{v∈S} VOI_view(v)  s.t.  Σ_{v∈S} cost_v(a_v) ≤ B_ctx
```
由于边际增益递减（次模性），贪心达到 (1−1/e) 近似。**接触前默认 wrist 高权重，接触后按 s_slip/遮挡动态提升 tactile 与外部视角。**

**定义 179（接触上下文条件投影 Π_ctx）** 在 USR 投影头 Π 上增加接触上下文调制：
```
K_prior = Π_ctx([scene_emb, intent_emb, c_micro]) = Π_base(scene_emb + intent_emb) ⊙ G(c_micro) + Δ(c_micro)
```
其中 G(c_micro) 为分段增益门（pre_contact 降刚度、contact 稳态、slip 提阻尼/降刚度、release 复位），Δ(c_micro) 为残差修正（由接近速度、形变、法向决定）。约束：`K_prior ∈ K_safe` 的可行域，且门控增益满足 Lipschitz 上界（供第 61 轮定理复用）。

**定义 180（上下文漂移度量 CDM）** 定义漂移
```
D_ctx(t) = ‖c_t − Ĉ_t‖²_Σ  +  λ_t·‖∂_t c_t‖  +  λ_d·MMD(P_window(c), P_ref)
```
其中 Ĉ_t 为按上一时刻模型的预测（内生预测），∂_t c_t 为上下文变化率，MMD 为最近窗口与参考分布的距离。**漂移触发**：D_ctx > τ_drift ⇒ 触发 MEL 重推理或视角重路由（而不是只对 D⁺_sem 设阈值）。

**定义 181（反事实上下文检验 CCC）** 对每个独立模态 m ∈ M_ind = {tactile, ext_view, proprio}，构造反事实上下文 c_micro^{(m)}（用模态 m 的测量替换腕部推断），并计算
```
C_cf = exp( − max_{m∈M_ind} ‖K*(c_micro) − K*(c_micro^{(m)})‖ / σ_cf ) ∈ [0,1]
```
- C_cf ≥ τ_cf：上下文通过反事实一致性检验，可信
- C_cf < τ_cf：判定为「自证上下文」，降低 conf_micro、提升 U_epistemic、强制视角重路由或请求 DMS 澄清
- **独立性要求**：m 必须与腕部相机条件独立（触觉最可靠，外部视角次之，本体只验证自运动）

**定义 182（七维认知-上下文预算 PCE++++++）** 
```
B_cog7 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_ctx)
B_ctx = (view_quota, max_resolution, context_depth, ttl_budget, recheck_rate)
```
- **成本扩展**：
```
cost_cog7 = cost_cog6
          + λ_view·(Σ_{v∈S} res_v·f_v / Budget_res)
          + λ_depth·(depth(C_t) / 3)
          + λ_recheck·(CCC_calls / recheck_rate)
```
- **降级**：B_ctx 耗尽 ⇒ 冻结高分辨率腕部流，只用降采样 ROI；再耗尽 ⇒ 仅 tactile+proprio（无视觉）；CCC 预算耗尽 ⇒ 强制保守投影（G = 保守增益）
- **VOI 扩展**：voi_cog7 = VOI_meta − cost_mel − cost_usr − cost_ctx − cost_exec

**定义 183（上下文-执行联合证书 J_ctx）** 扩展第 61 轮 J_sem_exec：
```
J_ctx = (J_sem_exec,
         Δ_suff,          # 上下文充分性缺口
         D_ctx,           # 上下文漂移
         C_cf,            # 反事实一致性
         η_ego,           # 自运动解释率
         ctx_version,     # 上下文锚点版本
         view_trace)      # 视角路由与分辨率轨迹（可审计）
```
验证规则：

```
Valid(J_ctx) ⇔ Valid(J_sem_exec)
             ∧ Δ_suff ≤ ε_suff
             ∧ D_ctx ≤ τ_drift
             ∧ C_cf ≥ τ_cf
             ∧ ctx_fresh(micro)
```

```
WISE = SemanticPipeline(ctx_meso, ctx_macro) ∘ RealtimePipeline(ctx_micro) ∘ WCA
```

WISE 在 ESEC 基础上增加三个反馈：① ACCD 把内生新息从语义更新中剔除；② VVR 决定下一次「看哪里」；③ CCC 用独立模态校验上下文。其目标是让**上下文充分、可信、可负担**，使「语义先行」建立在「接触可见」之上。

## 5. 本轮最大风险

**一句话**：腕部相机是「贴着动作的相机」——若自运动未在 ACCD 中被可靠分解（warp 误差、本体标定漂移、接触形变超出刚性假设），上下文就会退化为**自我确认的回声室**：机器人只看得到自己预期的接触、并用它反过来强化自己的语义先验，最终在「上下文高度自信」的同时对真实滑移/碰撞视而不见；因此必须以「外生/内生硬标签 + 触觉独立仲裁 + CCC 反事实否决 + 分层 TTL 降级」构成不可绕过的上下文安全护栏。

### IP-184 CL（三层上下文阶梯）

```python
class ContextLadder:
    def __init__(self, tau=(0.005, 0.2, 2.0), ttl=(0.02, 0.3, 2.0)):
        self.tau = tau
        self.ttl = ttl
        self.c = [None, None, None]   # micro, meso, macro
        self.ts = [0.0, 0.0, 0.0]

    def update(self, layer, obs, prior_upper=None, now=None):
        now = now or time.time()
        dt = now - self.ts[layer]
        # 层间条件化：微观只在上一层先验下解释观测
        enc = self._encode(layer, obs, prior_upper)
        alpha = min(1.0, dt / self.tau[layer])
        if self.c[layer] is None:
            self.c[layer] = enc
        else:
            self.c[layer] = (1 - alpha) * self.c[layer] + alpha * enc
        self.ts[layer] = now
        return self.c[layer]

    def fresh(self, layer, now=None):
        now = now or time.time()
        return (now - self.ts[layer]) < self.ttl[layer]

    def sufficiency_gap(self, layer_mask, decision_posterior, full_history_posterior):
        # 用互信息估计器（如 MINE/InfoNCE）近似 Δ_suff
        C = self._pack(layer_mask)
        return estimate_MI(full_history_posterior, decision_posterior) \
             - estimate_MI(C, decision_posterior)

    def _pack(self, mask):
        return torch.cat([self.c[i] for i in range(3) if mask[i]])
```

### IP-185 ACCD（动作条件上下文分解）

```python
class ActionConditionedContextDecomp:
    def __init__(self, warp_model=None):
        self.warp = warp_model or DifferentiableWarp()
        self.prev = None

    def decompose(self, I_w_t, I_w_prev, T_ego, tau_tex_prev):
        if I_w_prev is None:
            return {'r_exo': I_w_t, 'r_endo': 0.0, 'eta_ego': 0.0, 'label': 'init'}
        warped = self.warp(I_w_prev, T_ego)          # 用末端位姿+深度 warp
        r = I_w_t - warped
        warp_err = torch.norm(warped - I_w_prev)
        raw_diff = torch.norm(I_w_t - I_w_prev) + 1e-8
        eta_ego = float((warp_err / raw_diff).clamp(0, 1))

        # 内生分量：由动作 warp 与接触形变解释；外生：剩余
        r_endo = compute_endo_residual(self.prev_contact, T_ego)
        r_exo = r - r_endo

        if eta_ego > 0.85:
            label = 'mixed'                          # warp 质量差，保守
        elif torch.norm(r_endo) > 0.7 * torch.norm(r):
            label = 'endo'
        else:
            label = 'exo'
        return {'r_exo': r_exo, 'r_endo': r_endo,
                'eta_ego': eta_ego, 'label': label}

    def gate_for_semantic_update(self, decomp):
        # 只有外生新息允许驱动 MEL 重推理；mixed 时按 η_ego 降权
        if decomp['label'] == 'endo':
            return 0.0
        if decomp['label'] == 'mixed':
            return max(0.0, 1.0 - decomp['eta_ego'])
        return 1.0
```

### IP-186 VVR（视角感知 VOI 路由）

```python
class ViewAwareVOIRouter:
    def __init__(self, views, budget):
        self.views = views            # {'wrist': ..., 'ext_1': ..., 'tactile': ...}
        self.B_ctx = budget

    def route(self, context, uncertainty, contact_mode):
        candidates = []
        for name, v in self.views.items():
            for action in v.candidate_actions(contact_mode):
                gain = self._expected_info_gain(name, action, context, uncertainty)
                cost = (v.latency(action) + 0.2 * v.energy(action)
                        + 0.5 * v.occlusion_risk(contact_mode)
                        + 0.1 * v.cognitive_load(action))
                candidates.append((name, action, gain / cost, cost))

        # 次模贪心：每次选边际 VOI 最大且不超预算的视角动作
        chosen, spent, covered = [], 0.0, set()
        while True:
            best = None
            for name, action, voi, cost in candidates:
                if name in covered or spent + cost > self.B_ctx:
                    continue
                marginal = voi * (1.0 - 0.15 * len(covered))  # 递减边际
                if best is None or marginal > best[0]:
                    best = (marginal, name, action, cost)
            if best is None:
                break
            _, name, action, cost = best
            chosen.append((name, action))
            covered.add(name)
            spent += cost
        return chosen, spent

    def _expected_info_gain(self, name, action, context, uncertainty):
        if name == 'wrist':
            return uncertainty.micro * (1.0 + action.resolution / 1080)
        if name == 'tactile':
            return uncertainty.contact * 2.0
        return uncertainty.meso * (1.0 + action.fov / 90.0)
```

```python
class ContextAnchorBuffer:
    def __init__(self):
        self.anchor = None
        self.version = 0
        self.lock = threading.Lock()

    def commit(self, c_micro, c_meso, c_macro, conf, src_mask):

                c_micro=c_micro, c_meso=c_meso, c_macro=c_macro,

                ttl=(0.02, 0.3, 2.0),
                src_mask=src_mask, conf_vec=conf,

            self.version += 1
            return self.anchor

    def read_fresh(self, layer):

        if a is None:

class ContactConditionedProjector(nn.Module):
    def __init__(self, d_us=256, d_c=128):
        super().__init__()
        self.base = ImpedanceProjector(d_us)
        self.gate = nn.Sequential(nn.Linear(d_c, 64), nn.ReLU(), nn.Linear(64, 2))
        self.residual = nn.Sequential(nn.Linear(d_c, 64), nn.ReLU(), nn.Linear(64, 2))
        self.lip_clip = 0.5   # 保证门控增益 Lipschitz 上界

    def forward(self, scene_emb, intent_emb, c_micro, mode):
        base = self.base(scene_emb + intent_emb)          # [K_p, K_d]
        g = 1.0 + self.lip_clip * torch.tanh(self.gate(c_micro))
        if mode == 'pre_contact':
            g = g * torch.tensor([0.7, 1.2])              # 降刚度、增阻尼
        elif mode == 'slip':
            g = g * torch.tensor([0.6, 1.5])
        delta = self.lip_clip * torch.tanh(self.residual(c_micro))
        return base * g + delta
```

### IP-189 CCC（反事实上下文检验）

```python
class CounterfactualContextChecker:
    def __init__(self, projector, sigma_cf=0.1, tau_cf=0.8):
        self.projector = projector
        self.sigma_cf = sigma_cf
        self.tau_cf = tau_cf

    def check(self, c_micro_wrist, K_star, estimators):
        # estimators: {'tactile': fn, 'ext_view': fn, 'proprio': fn}
        deviations = []
        for name, est in estimators.items():
            c_alt = est(c_micro_wrist)       # 用独立模态反推接触上下文
            K_alt = self.projector(c_alt)
            deviations.append(torch.norm(K_star - K_alt))
        dev = max(d.item() if hasattr(d, 'item') else d for d in deviations)
        C_cf = math.exp(-dev / self.sigma_cf)
        return {'C_cf': C_cf, 'pass': C_cf >= self.tau_cf, 'max_dev': dev}

    def on_fail(self, dms, mode):
        # 自证上下文：降权 + 切视角 + 可能触发澄清
        dms.request_view('tactile' if mode != 'pre_contact' else 'ext_view')
        if mode == 'contact':
            dms.maybe_ask_clarify("腕部观测与触觉不一致，是否暂停并复核？")
```

```python
class CognitiveContextBudget:
    def __init__(self, base_budget, view_quota=6, max_res=1080,
                 context_depth=3, ttl_budget=1.0, recheck_rate=0.1):
        self.base = base_budget
        self.B_ctx = dict(view_quota=view_quota, max_resolution=max_res,
                          context_depth=context_depth, ttl_budget=ttl_budget,
                          recheck_rate=recheck_rate)
        self.view_used = 0
        self.ccc_calls = 0.0
        self.ctx_frozen = False

    def can_route(self, n_views, resolution):
        return (not self.ctx_frozen
                and self.view_used + n_views <= self.B_ctx['view_quota']
                and resolution <= self.B_ctx['max_resolution'])

    def spend_views(self, n, resolution):
        self.view_used += n
        self._cost += 0.01 * n * resolution / 1080
        if self.view_used >= self.B_ctx['view_quota']:
            self._degrade()

    def spend_ccc(self):
        self.ccc_calls += 1
        if self.ccc_calls / self._window > self.B_ctx['recheck_rate']:
            self._degrade()

    def _degrade(self):
        # 一级：降分辨率；二级：只用 tactile+proprio；三级：冻结上下文锚点
        if not self.ctx_frozen:
            self.B_ctx['max_resolution'] //= 2
            if self.B_ctx['max_resolution'] < 240:
                self.ctx_frozen = True

    def voi_cog7(self, action):
        base = self.base.voi_cog5(action)
        ctx_cost = 0.0
        if action.type == 'view_query':
            ctx_cost = 0.02 * action.n_views * action.resolution / 1080
        elif action.type == 'ccc_check':
            ctx_cost = 0.1 / max(self.B_ctx['recheck_rate'], 1e-6)
        return base - ctx_cost
```

### IP-192 WISE（腕部上下文驱动的进化闭环）

```python
def WISE_step(M, obs, delta_f_req):
    # ---- 语义流（10–100Hz）----
    c_contact, mode = M.ccm.infer(obs.I_w, obs.T, obs.P, obs.T_ego)
    decomp = M.accd.decompose(obs.I_w, M.prev_I_w, obs.T_ego, M.prev_tex)
    M.prev_I_w, M.prev_tex = obs.I_w, c_contact.tau_tex

    if M.accd.gate_for_semantic_update(decomp) > 0.5:
        scene, intent, phys, U = M.mel.infer(obs.V, obs.T, obs.P, obs.L,
                                             M.anchor.c_meso, M.anchor.c_macro)
    else:
        scene, intent, phys, U = M.cache.reuse()      # 内生新息不驱动更新

    M.ladder.update(0, c_contact)
    M.ladder.update(1, (scene, phys), prior_upper=M.ladder.c[2])
    M.ladder.update(2, intent)
    views, spent = M.vvr.route(M.ladder.c, U, mode)
    M.budget.spend_views(len(views), max(r for _, r in views))

    M.anchor = M.wca.commit(M.ladder.c[0], M.ladder.c[1], M.ladder.c[2],
                            conf=(c_contact.s_slip, U.epistemic, U.aleatoric),
                            src_mask=(True, decomp['label'] != 'endo', True))

    # ---- 实时流（1–10kHz）----
    a = M.wca.anchor
    K_prior = M.pi_ctx(scene, intent, a.c_micro, mode)
    K_safe = M.eeis.compile_with_prior(delta_f_req, obs.fused, obs.xi,
                                       obs.Z_env, K_prior, phys)
    cert = M.ertc.dispatch(K_safe)
    EV = wait_contact_and_build_evidence()

    # ---- 反事实校验与回流 ----
    chk = M.ccc.check(a.c_micro, K_safe, M.independent_estimators(obs))
    if not chk['pass']:
        M.confidence.decay('micro'); M.dms.request_view('tactile')
    M.usr.push_evidence(EV)
    MJ = build_ctx_cert(EV, cert, a, decomp, chk, cost=M.budget.cost)
    return M, K_safe, EV, MJ
```

**正确性定理（WISE-Complete）**：
在 A61–A70 基础上增加：
- **(A71)** CCM 的接触上下文解码头在仿真+真实校准集上满足间隙/法向/接近速度误差 ≤ δ_ccm；滑移前兆概率校准良好（ECE ≤ 0.05）。
- **(A72)** 三层上下文满足层间条件化，且对目标阻抗决策存在 ε_suff-充分表示；充分性估计器（MINE/InfoNCE）的估计误差 ≤ δ_mi。
- **(A73)** ACCD 的 warp 算子在本体标定误差 ≤ δ_cal 且接触形变在刚性假设内时，`‖r_endo − 真实自运动分量‖ ≤ δ_warp`；接触变形超出假设时 Mode 切到 `slip/deform` 并触发保守。
- **(A74)** VVR 的视角信息增益函数次模，贪心近似比 ≥ 1−1/e；各视角成本可加。
- **(A75)** CCC 使用的独立模态与腕部相机条件独立（触觉/外部视角/本体），且各反推估计器偏差 ≤ δ_ind。
- **(A76)** PCE++++++ 预算单调消耗，降级路径（降分辨率→tactile-only→冻结锚点→保守投影）保证安全不退化。

则：
1. **自运动不污染语义**：若 A73 成立，则进入语义更新的新息满足 `E[‖r_exo − 真实环境新息‖] ≤ δ_warp`，内生自激被阻断；否则 Mode 保守分支保证不学习内生新息。
2. **上下文充分性保真**：若 Δ_suff(C_t) ≤ ε_suff 且 A72 成立，则 `‖K*_ctx − K*_full‖ ≤ δ_ctx(ε_suff, δ_mi)`，即用分层上下文做阻抗决策的损失可控。
3. **接触级实时性**：微观上下文 TTL=20ms、Π_ctx≈0.1ms，实时流周期 ≤ 0.3ms，不依赖 MEL/CL 的宏观更新。
4. **上下文可证伪**：若 C_cf < τ_cf，则强制降权并切换独立视角，自证上下文不能进入 J_ctx 的有效路径（A75）。
5. **视角可负担**：VVR 在 B_ctx 内达到 (1−1/e)·OPT 的 VOI；预算耗尽时按 A76 降级，安全约束不放松。
6. **零样本接触泛化**：CCM 的 τ_texture 与 φ_phys 联合，使未见材质的滑移前兆与间隙估计仍满足 δ_ccm（与第 61 轮 ZSSG 相乘）。

**消融设计**：
- A1 去掉腕部相机（仅外部视角）→ 验证接触盲区假设；
- A2 去掉 ACCD（原始帧差）→ 验证自运动污染假设；
- A3 去掉 CL（单层上下文）→ 验证分层必要性；
- A4 去掉 CCC（信任腕部）→ 验证自证风险；
- A5 去掉 VVR（全视角全帧）→ 验证预算与遮挡权衡。

## 5. 本轮最大风险

**一句话**：腕部相机是「贴着动作的相机」——若自运动未在 ACCD 中被可靠分解（warp 误差、本体标定漂移、接触形变超出刚性假设），上下文就会退化为**自我确认的回声室**：机器人只看得到自己预期的接触，并用它反过来强化自己的语义先验，最终在「上下文高度自信」的同时对真实滑移/碰撞视而不见；因此必须以「外生/内生硬标签 + 触觉独立仲裁 + CCC 反事实否决 + 分层 TTL 降级」构成不可绕过的上下文安全护栏。
