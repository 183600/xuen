# 研究循环 · 本轮灵感：「6D位姿估计」×「模块化设计」 → MetricVoiceGauge-NCD-HUTDH-v24

> **基线**：承接 v23（MetricVoiceGauge-NCD-HUTDH-v23：VCDF 认证距离场 + CIC 柔顺阻抗力/位/能三界 + PET 无源能量槽 + UPS 未知空间主动剥离 + HPC-EI 统一门 + CFC+++ 几何一致模态共识；其上承 v22 的 PGEV 三层能量 + HDL/DCL 义务合规 + ACSC 机械臂配空间能量 + DCSC conformal 深度感知 + HPC-E + CFC++、v21 的 SDC/CAC/DCL/GIC 语义-规范层、v20 的 PCA/CTS/CFC/HPC 联邦感知证书、v19 的 DCM/OGCC/CCV/DRS/OGC、v17 的 CLP/S2C/HCG/PSV/APS/AMC）。
> 本轮纪律：**6D 位姿是带 SE(3) 群结构、必须按对称群商化的刚体位姿证据；模块化设计是带假设-保证契约、可验证可替换可重组的组合装配**。不推倒 v23：VCDF/CIC/PET/UPS/HPC-EI 全部原样保留。本轮只做一件事：在 v23 的"匿名连续距离场 + 隐式接口堆叠"之上加一层"**对象-组合（object-composition）**"层——把"离一块模糊几何多远"升级为"离一个带对称结构、带形状模型的认证刚体多远"，把"层层叠加的隐式信任链"升级为"可独立验证、可热替换的假设-保证证书契约"，并顺手封堵 v23 的"平滑假自由"与"接触模型假设悬空"两大风险。

## 0. 直觉与动机

**灵感 1（6D 位姿估计 → 从"匿名距离场"到"对称商化的刚体对象证据"）**
直觉：v23 的 VCDF 给出连续净空，但它是**匿名**的——它知道"此处 20cm 处有表面"，却不知道"那是一个杯子、它的朝向如何、哪一面是把手、哪一面是对称的回转面"。6D 位姿估计 `(R,t)∈SE(3)` 恰好补上三样东西。第一，**朝向**：有了对象坐标系，净空就从"到最近点云"升级为"到对象形状模型 `M` 沿朝向的精确有符号距离"，一个 8cm 的杯子不必再被 15cm 的保守球包住。第二，也是最反直觉的，**对称性把"位姿错误"劈成两类**：绕杯子轴转 30° 的位姿误差，对回转对称体在几何上是**零误差**——把一个对称等价位姿当作危险去膨胀，纯属白白牺牲活性；但若把"看起来对称"当成"真的对称"（杯口有一道缺口、杯子有把手），商掉对称就会**吞掉真实几何**。所以位姿证书必须**按对象对称群 `G_sym` 商化，但只用"在形状容差 `ε_asym` 内可验证的对称子群"**。第三，**位姿不确定性在 SE(3) 上是流形上的测地误差**，不是三个欧拉角的独立标量误差；把 R 的三轴误差当独立量相加会系统性低估最坏朝向位移。核心创新：**对称商化 6D 位姿证书（Symmetry-Quotient Pose Certificate, SQPC）+ 位姿条件形状距离（Pose-Conditioned Shape Distance, PCSD）**。关键洞察：**对象的自由空间只能被"有形状模型背书的认证位姿包络"赎回**——位姿越确定、形状模型越可信，包络越小、活性越高；而任何位姿集扩张、形状失配、对称误判，都只让包络只增不减、净空只减不增。

**灵感 2（模块化设计 → 从"层层隐式堆叠"到"假设-保证证书契约"）**
直觉：v23 已经堆到 VCDF/CIC/PET/UPS 四层，每层都**默默假设**上一层或环境满足某条件（CIC 假设 `K_e` 有上界、PET 假设 `E_res` 分账无误、UPS 假设 CAC 召回下界、VCDF 假设标定不过期）——但这些假设**从未被显式登记、从未被逐条兑现**。这正是上一轮最大风险的根源：当"环境刚度有界""人体主动力有界"不成立时，没有任何一层"负责"。模块化设计的本质不是"分块"，而是**接口契约（interface contract）+ 可组合性（compositionality）+ 可替换性（substitutability）**。核心创新：**假设-保证证书契约（Assume-Guarantee Certificate Contract, AGCC）**：每个模块 `m` 暴露 `(A_m, G_m)`，`A_m` 是它要求上游/环境保证的接口谓词，`G_m` 是它向下的保证；一次组合仅当**上游保证 ⊇ 下游假设**且**假设依赖图无环**时才被认证。这把整栈从"隐式信任链"变成"显式义务账本（contract ledger）"：每条假设要么被某个模块的保证**兑现（记账）**，要么成为**残余义务（residual obligation）**并强制退化为最保守模式。关键洞察：**可替换性 = 精化序（refinement order）`C⊑C'`**：当且仅当 `A'⊆A ∧ G⊇G'` 时，用 `m'` 替换 `m` 不破坏任何下游安全，且**只需重认证受影响子图**（增量重认证），而非整栈重来；这对模块化机械臂的热插拔/重组长尤为关键。

**两者如何统一：位姿定义"对象在哪、多可信"，契约定义"谁为这份可信度负责、能否替换"**
统一为 v23 之上的 **对象-组合层**：
- **SQPC**（对称商化 6D 位姿证书）回答"对象位姿落在 SE(3) 的哪个对称商化后的集合 `P̂` 内、多可信"；
- **PCSD**（位姿条件形状距离）回答"给定形状模型 `M` 与认证位姿集 `P̂`，对象可能占据的包络多大、离机器人多远"，它把**匿名**净空升级为**定向**净空，并把 v23 的机器人保守球升级为机器人形状 SDF；
- **AGCC**（假设-保证证书契约）回答"每个模块拿什么假设、给什么保证、组合是否成立"；
- **MSDR**（模块替换与增量重认证）回答"换一块硬件/算法后，哪些证明仍有效、哪些必须重签"。
统一准入门升级为 **HPC-OC = (HPC-EI, SQPC, PCSD, AGCC-compat)**。共享状态 `ζ_geom` 扩为 `ζ_obj = ζ_geom ∪ (P̂_t, G_sym^ε, M, ε_shape, d_obj, contract_ledger, module_DAG, ε_robot)`。安全继承：SQPC 只在可验证对称商内收缩位姿集、PCSD 只给出保守包络、AGCC 只把隐含假设显式化并把未兑现者降级、MSDR 只在精化序下替换，故 `Exec_v24 ⊆ Exec_v23` 由构造保持。

## 1. 研究问题（轮次升级版）

- **Q16（SE(3) 上的对称商化可靠性界）**：如何用单一非共形度分数 `s = max(ε_t/τ_t, ε_R/τ_R)`（或在 `SE(3)/G_sym` 商空间上的测地分数）给出 `P(P_true ∈ P̂) ≥ 1−α_pose` 的同时置信集？旋转测地误差 `∠(R̂ᵀR)` 与平移误差如何联合标定才能保证"同时覆盖"？**形状容差 `ε_asym`** 如何定义"某个对称在几何上足够成立"（Hausdorff 距离？双向 Chamfer？体素 IoU？），从而只商掉可验证的对称子群 `G_sym^ε = {S : d_H(M, S·M) ≤ ε_asym}`？连续对称（回转体）与离散对称（方盒 C₄、点对称 C₂）分别如何参数化、如何在商空间上取最坏测地代表？

- **Q17（位姿条件包络的保守性与紧致度）**：给定 `M` 与 `P̂`（平移球 `ε_t`、测地旋转球 `ε_R`、商化后），如何导出严格保守包络 `Occ ⊆ P̂_nom·M ⊕ Ball(ε_t + 2ρ_max sin(ε_R/2) + ε_shape)`？其中 `ρ_max`（模型绕旋转中心的半径）、形状模型误差 `ε_shape`（可变形、附件、遮挡缺失）如何标定并计入？PCSD 与 v23 VCDF 的 `d̂` 如何在同一查询点取 `min`（两者都保守）而不产生缝隙或重复膨胀？机器人形状 SDF 与 v23 保守球如何无缝隙衔接，`ε_robot` 由谁背书？

- **Q18（契约组合的可靠性与残余义务）**：`(A_m,G_m)` 的接口变量（单位、坐标系、时间戳、频率、TTL）如何形式化与版本化？循环假设如何用"分层计算 DAG + 无环序"切断（位姿用上一周期的几何、几何不用本周期的位姿）？一条未被任何 `G` 兑现的假设，如何自动降级为残余义务并映射到具体保守模式（而非静默信任为真）？契约账本的 merkle 审计如何与 v22 规则库版本链拼接、如何定位"哪条假设、哪个模块、哪个版本"失责？

- **Q19（模块替换/重组与增量重认证）**：模块化机械臂的"每模块质量/惯量/关节限位/安装位姿（带 6D 标定不确定度 `Σ_mount`）"如何传播为末端位姿不确定度 `ε_robot` 与 `E_arm` 的界面？精化序下替换后，如何用依赖 DAG 的传递闭包只重认证受影响子图（`O(|Affected|)` 而非 `O(整栈)`）？热插拔窗口内"新模块 = 未知"如何强制进入最保守模式且不破坏 `Exec_v24 ⊆ Exec_v23`？组态改变导致的 `ε_robot/E_arm` 上升如何向 CIC/VCDF 传播而不引发 v22 的层级振荡？

## 2. 设计原则（在 v23 的 P43–P46 基础上新增 P47–P50）

**P47 对称商化位姿证书律（Symmetry-Quotient Pose Certificate）**
对对象 `o`，认证位姿集 `P̂_t ⊆ SE(3)` 满足 `P(P_true ∈ P̂_t) ≥ 1−α_pose`。位姿误差用商空间 `SE(3)/G_sym^ε` 上的度量 `d_sym(P,P') = min_{S∈G_sym^ε} d_SE3(P, P'·S)`，其中 `G_sym^ε = {S : d_H(M, S·M) ≤ ε_asym}` 是**形状容差内可验证**的对称子群。**只商可验证对称**：若某对称只在模型上成立、真实对象有破缺（缺口/把手/贴附物），则其 `ε_asym` 超限、不得商掉，位姿集必须保留该方向的不确定性。旋转误差用测地角、平移误差用欧氏范数，联合成非共形度分数并 conformal 标定。**失效向全空间**：位姿失效、对称判定不可信、形状模型缺失时 `P̂_t = SE(3)`（等价"对象可在任意位姿"），包络退化为 v23 的保守 Hull/球。

**P48 位姿条件形状距离律（Pose-Conditioned Shape Distance）**
对象可能占据区域 `Occ_t = ⋃_{P∈P̂_t} P·M`，包络保守界 `Occ_t ⊆ P̂_nom·M ⊕ Ball(ε_obj)`，`ε_obj = ε_t + 2ρ_max·sin(ε_R/2) + ε_shape`。对象距离 `d_obj(x) = sdf_{Occ_t}(x)`，与 v23 的 `d̂(x)` 取 `min`（两者皆保守下界，交仍保守）。**只有**在 `P̂` 由 P47 认证且 `ε_shape` 有标定上界时，`d_obj` 才可作为"赎回自由空间"的证据；`ε_shape` 无上界（可变形/未知物体）时 `d_obj` 不得用于提升任何区域净空，只能用于让障碍更紧（`Occ` 只增不减）。机器人侧用形状 SDF `S_robot(pose_robot; ε_robot)` 替代 v23 保守球 `r_robot`，但 `ε_robot` 必须由 P50 的模块位姿契约背书；无背书则回退球。任何膨胀只增不减，任何失效回退 v23。

**P49 假设-保证证书契约律（Assume-Guarantee Certificate Contract）**
每个模块 `m`（VCDF/CIC/PET/UPS/DCL/SQPC/PCSD/…）暴露契约 `C_m=(A_m,G_m)`，接口变量带**单位、坐标系、时间戳与 TTL**。组合 `⊗` 被认证当且仅当：① 对每条 `a∈A_m`，存在 `g∈G_up` 使 `g ⊨ a`（上游保证兑现下游假设），或 `a` 作为**残余义务**被显式登记并绑定一个保守退化模式；② 假设依赖图 `D` 无环（分层计算 DAG，位姿/几何按周期分层，禁止同周期互用）；③ 时间戳满足 APS 新鲜度阶梯。契约账本 `L` 逐条记录"假设—兑现者—版本哈希"，与 v22 规则库 merkle 链拼接。**未兑现即降级**：任何残余义务（如"`K_e ≤ K_e^max` 无标定""人体主动力无上界"）强制对应模块进入其声明的保守模式，绝不静默假设为真。故组合安全 = 所有边被兑现 ∨ 残余义务已降级。

**P50 模块替换与增量重认证律（Modular Substitution & Delta Re-certification）**
定义精化序 `C ⊑ C'` 当且仅当 `A' ⊆ A ∧ G ⊇ G'`（假设更弱、保证更强）。用模块 `m'`（契约 `C'`）替换 `m`（契约 `C`）**保持系统安全**当且仅当 `C ⊑ C'` 且接口 schema（变量名/单位/坐标系/频率/TTL）完全一致；此时不变量 `Exec` 单调不增。替换或组态变化只使下游传递闭包 `Affected(m) ⊆ D` 失效，**增量重认证**只重签 `Affected(m)`，其余缓存兑现记录仍有效（`O(|Affected|)`）。模块化硬件里，每模块以 `(mass, inertia, joint_limits, mounting_pose ± Σ_mount)` 作为契约参数，末端位姿不确定度 `ε_robot` 与 `E_arm` 由运动学/惯量传播得到；**热插拔窗口**内新模块 `C'=(⊤,⊥)`（假设最强、保证最弱）⇒ 机器人冻结在认证安全态，直到新契约被兑现，故 `Exec` 只减不增。组态变化引起的 `ε_robot/E_arm` 上升只收缩 CIC 可行域 `𝒦`、只增 `r/ε_obj`，与 v22 分层过滤同构，无新振荡源。

## 3. 与基线的接口（如何退化）

- SQPC 失效（位姿不可信/对称不可判/形状模型缺）⇒ `P̂=SE(3)` ⇒ PCSD 退化为 `Occ` 覆盖整工作区 ⇒ 回退 v23 VCDF/Hull（更保守）；
- PCSD 失效（`ε_shape` 无界/可变形物体）⇒ 不用对象包络赎回自由，只用 `Occ` 让障碍更紧 ⇒ 子集；
- AGCC 失效（某假设无兑现者且无降级映射）⇒ 该模块进入"最大限制模式"（如 CIC 关接触、UPS 关剥离）⇒ 子集；
- 残余义务存在（`K_e^max` 未标定）⇒ 关接触任务、退回非接触 ⇒ 子集；
- MSDR 遇接口不匹配（单位/坐标系/频率不一致）⇒ 拒绝替换、保持原模块或安全态 ⇒ 不增 `Exec`；
- 模块热插拔中 ⇒ 新模块按 `(⊤,⊥)` 处理 ⇒ 冻结安全态 ⇒ 子集；
- 全失效 ⇒ 完全回退 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ … ⊆ Exec_v18`。
- **安全继承**：SQPC 只在可验证对称商内收缩 `P̂`、PCSD 只加膨胀并只取 `min`、AGCC 只显式化并降级未兑现假设、MSDR 只在精化序与接口一致下替换；任意失效都向更保守退化。SQPC/AGCC 以 10Hz 事件注入、控制环仅 O(1) 查 `P̂/ε_obj/契约缓存`，与 v23 的 10Hz 事件化、v22 层级降级、v21 APS 新鲜度阶梯同构。

## 4. 预期贡献

1. **对称商化 6D 位姿证书**：首次把"位姿误差"在 `SE(3)/G_sym^ε` 上分解为对称保持/破缺两类，用可验证形状容差只商真对称，既避免"对称等价位姿被当危险"的活性浪费，又避免"把非对称当对称"吞掉真实几何；
2. **位姿条件形状距离**：把无名的连续距离场升级为"带形状模型与朝向的定向净空"，给出 `ε_obj = ε_t + 2ρ_max sin(ε_R/2) + ε_shape` 的严格保守包络，与 v23 VCDF 取 `min` 无缝衔接；
3. **假设-保证证书契约**：把整栈的隐式信任链升级为显式义务账本，每条假设要么被兑现、要么降级为保守模式，直接回应"环境/人体模型假设悬空、无人负责"的 v23 风险；
4. **模块化替换与增量重认证**：给出契约精化序 `C⊑C'` 下的可替换定理与 `O(|Affected|)` 增量重认证，把"模块化机械臂热插拔/重组"变成"契约重签"而非整栈重来；
5. **对象-组合统一门**：`HPC-OC=(HPC-EI,SQPC,PCSD,AGCC-compat)`，`Exec_v24⊆Exec_v23` 闭环；
6. **顺手封堵 v23 风险**：用形状模型 + 位姿包络收紧"平滑假自由"（稀疏结构在模型里显式建模），用契约账本把"接触模型假设"从隐含变显式、未标定即关接触。

## 5. 本轮最大风险

**一句话**：SQPC/PCSD 的全部收益押在"形状模型 `M` 忠实于真实对象、且对称判定可验证"上，AGCC 的全部严谨性押在"每条假设都被某个上游保证真正兑现"上；若真实对象可变形/带未建模附件（衣物、线缆、贴附物）使 `ε_shape` 实际无界，或契约之间出现未被账本覆盖的耦合（A 以为是 B 保证、B 以为是 A 保证，形成"假兑现"），系统就会拿着一份**每层都合规、每条假设都'有主'**的证书，去碰撞一个**没有任何一层真正负责**的真实对象——即"**由契约合法化的责任真空（组合化的建模幻觉）**"。

# IP-442 对称商化 6D 位姿证书
class SymmetryQuotientPoseCertificate:
    def __init__(self, model_M, calib, sym_group, eps_asym, alpha_pose,
                 tau_t=1.0, tau_R=1.0, rho_max=None):
        self.M = model_M            # 形状模型（点云/网格/体素）
        self.calib = calib          # 位姿非共形度分数的 conformal 分位
        self.G = sym_group          # 候选对称群 {S}
        self.eps_asym = eps_asym
        self.alpha_pose = alpha_pose
        self.tau_t, self.tau_R = tau_t, tau_R
        self.rho_max = rho_max or model_M.max_radius()

    def verified_symmetry(self):
        # 只保留在形状容差内可验证的对称：G_sym^eps
        return [S for S in self.G if self.M.hausdorff(S.apply(self.M)) <= self.eps_asym]

    def score(self, P, P_hat):
        # 商空间上的非共形度：对称等价位姿误差记 0
        G = self.verified_symmetry()
        d = min(d_SE3(P, P_hat.compose(S)) for S in G)
        eps_t = d[0]; eps_R = d[1]
        return max(eps_t / self.tau_t, eps_R / self.tau_R)

    def certify(self, P_hat, score_bin):
        # conformal 分位 -> 位姿误差半径；构造平移球 + 测地旋转球
        q = self.calib.quantile(score_bin, self.alpha_pose)  # P(s<=q)>=1-alpha
        eps_t, eps_R = q * self.tau_t, q * self.tau_R
        if not self._pose_trustworthy():
            return PoseSet.full_space()                      # P47 失效向全空间
        return PoseSet(center=P_hat, eps_t=eps_t, eps_R=eps_R,
                       G=self.verified_symmetry())

    def envelope_margin(self, pose_set):
        # P48：旋转弦长项 + 平移项 + 形状误差
        return (pose_set.eps_t
                + 2.0 * self.rho_max * math.sin(pose_set.eps_R / 2.0)
                + self.eps_shape_or_inf())


# IP-443 位姿条件形状距离
class PoseConditionedShapeDistance:
    def __init__(self, vcdf, sqpc, eps_shape):
        self.vcdf, self.sqpc = vcdf, sqpc
        self.eps_shape = eps_shape          # 标定上界；None/∞ => 禁止赎回

    def envelope(self, pose_set):
        if pose_set.is_full_space():
            return Occupancy.full_workspace()         # 退化 v23
        eps_obj = self.sqpc.envelope_margin(pose_set)
        return Occupancy(M=self.sqpc.M, pose=pose_set.nom, inflate=eps_obj)

    def d_obj(self, x, pose_set):
        occ = self.envelope(pose_set)
        return occ.sdf(x)                  # 对膨胀后包络的距离（保守下界）

    def d_combined(self, x, pose_set, U_t):
        # P48：对象包络与 v23 距离场取 min，两者皆保守
        return min(self.d_obj(x, pose_set), self.vcdf.query(x, U_t).d)

    def may_redeem_free(self, pose_set):
        # 仅当位姿已认证且形状误差有界时，对象包络才可赎回自由
        return (not pose_set.is_full_space()) and (self.eps_shape is not None
                and math.isfinite(self.eps_shape))

    def collision_free(self, x, v, pose_set, U_t, r_robot_or_shape):
        d = min(self.d_combined(x, pose_set, U_t),
                r_robot_or_shape.sdf_signed(x, eps_robot=pose_set.eps_robot))
        return d >= self.vcdf.d_brake(v)

    def eps_shape_or_inf(self):
        return self.eps_shape if self.eps_shape is not None else float("inf")


# IP-444 假设-保证证书契约与义务账本
@dataclass(frozen=True)
class Contract:
    name: str
    A: frozenset          # 假设谓词
    G: frozenset          # 保证谓词
    schema: dict          # 变量名->(单位,坐标系,频率,TTL)
    fallback: dict        # 每条残余义务 -> 保守模式

    def refines(self, other):
        # C ⊑ C'  <=>  A'⊆A 且 G⊇G' 且 schema 一致
        return (other.A <= self.A and self.G >= other.G
                and schema_equal(self.schema, other.schema))


class ContractLedger:
    def __init__(self):
        self.entries = []      # (assumption, discharger, version_hash, ts)
        self.dag = nx.DiGraph()

    def compose(self, modules):
        # P49：逐模块检查每条假设是否被上游保证兑现
        for m in modules:
            for a in m.A:
                gs = [u.G for u in self.upstream_of(m)]
                if any(any(g.implies(a) for g in up) for up in gs):
                    self._record(a, discharger=..., version=hash_of(...))
                else:
                    # 残余义务 -> 强制该模块进入保守模式
                    if a not in m.fallback:
                        raise ContractError(a, reason="UNBOUND_ASSUMPTION")
                    self._enforce_fallback(m, a, m.fallback[a])
        if not nx.is_directed_acyclic_graph(self.dag):
            raise ContractError(None, reason="CYCLIC_ASSUMPTION")

    def audit(self):
        # merkle 链：假设—兑现者—版本，可定位"哪条假设、哪个模块失责"
        return merkle_root(self.entries)

    def _record(self, assumption, discharger, version):
        self.entries.append((assumption, discharger, version, now()))


# IP-445 模块替换与增量重认证
class ModularSubstitutionRecertifier:
    def __init__(self, ledger, module_dag):
        self.ledger, self.dag = ledger, module_dag

    def substitute(self, old, new):
        # P50：只用更弱假设、更强保证、同 schema 的模块
        if not old.refines(new):
            return Recert(ok=False, reason="NOT_REFINEMENT")
        if not schema_equal(old.schema, new.schema):
            return Recert(ok=False, reason="SCHEMA_MISMATCH")
        affected = nx.descendants(self.dag, old.name)   # 下游失效子图
        for m in affected:                               # 只重签受影响子图
            self.ledger.invalidate(m)
        for m in affected:
            self.ledger.recheck(m)
        return Recert(ok=True, affected=affected)

    def begin_hotswap(self, slot):
        # 新模块未知：按 (⊤,⊥) 处理，冻结在认证安全态
        self.ledger.install(slot, Contract(name=slot, A=frozenset([TRUE]),
                                            G=frozenset([]),
                                            schema={}, fallback={}))
        return SafetyMode.FROZEN_SAFE

    def propagate_kinematics(self, modules):
        # 模块质量/惯量/安装位姿(±Σ_mount) -> ε_robot 与 E_arm
        eps_robot = 0.0
        for m in modules:
            eps_robot += m.mount_sigma + m.length * m.joint_sigma
        E_arm = sum(m.inertia_energy_bound() for m in modules)
        return eps_robot, E_arm

## 2. 推导（引理 183–189）

**引理 183（可验证对称商化的保守性）** 设 `G_sym^ε = {S : d_H(M,S·M) ≤ ε_asym}`。对任意 `S∈G_sym^ε` 与真实对象 `M*`，若 `d_H(M,M*) ≤ ε_shape`，则 `d_H(S·M, M*) ≤ d_H(S·M,M) + d_H(M,M*) ≤ ε_asym + ε_shape`。因此把 `S` 当作等价位姿商掉，最多引入 `ε_asym + ε_shape` 的形状偏差——它已包含在包络膨胀 `ε_obj` 中。反之，若 `S∉G_sym^ε`，则存在模型点被 `S` 移出 `ε_asym` 带，商掉它会使包络漏掉该方向至少 `ε_asym` 的真实几何，故不得商。∎（这条界把"对称"从定性直觉变成可计算的 `ε_asym` 判据。）

**引理 184（位姿集包络的严格保守界）** 设认证位姿集 `P̂ = {P : ‖t_P−t̂‖≤ε_t, ∠(R_P,R̂)≤ε_R}`（商化后）。任取 `x∈Occ = ⋃_{P∈P̂} P·M`，存在 `P∈P̂, y∈M` 使 `x=P·y`。写 `P·y = t_P + R_P y`。与标称 `P̂_nom·y = t̂ + R̂ y` 比较：`‖x − P̂_nom y‖ ≤ ‖t_P−t̂‖ + ‖(R_P−R̂)y‖ ≤ ε_t + 2‖y−c‖ sin(ε_R/2)`，其中 `c` 为旋转中心、`‖y−c‖≤ρ_max`。故 `Occ ⊆ P̂_nom·M ⊕ Ball(ε_t + 2ρ_max sin(ε_R/2))`；再加入形状误差 `ε_shape` 得 `Occ ⊆ P̂_nom·M ⊕ Ball(ε_obj)`。∎

**引理 185（形状距离的保守下界与取 min 的封闭性）** 设 `Occ ⊆ E`（膨胀包络 `E = P̂_nom·M⊕Ball(ε_obj)`），则对任意 `x`，`dist(x,Occ) ≥ dist(x,E)`，即 `d_obj(x)=sdf_E(x)` 是到真实对象距离的保守下界。又 v23 的 `d̂(x) ≤ d_true^{geo}(x)` 亦为下界，故 `min(d_obj, d̂) ≤ min(d_true^{obj}, d_true^{geo}) ≤ d_true`，交仍为保守下界；且两者均随各自不确定性单调不增，取 `min` 保持单调。∎

**引理 186（假设-保证组合的可靠性）** 对模块集 `ℳ`，若① 每条 `a∈A_m` 存在上游 `g∈G_up` 使 `g⊨a`，或 `a` 已绑定 `Fallback(a)` 并实际进入该保守模式；② 依赖 DAG 无环；③ schema 与新鲜度匹配——则组合 `⊗ℳ` 的保证 `G_⊗ = ` 各 `G_m` 在接口一致的公共变量上成立。证明对 DAG 的拓扑序归纳：最上游模块的假设或由环境/已验证前提兑现、或已降级，故其 `G` 成立；下游模块的全部假设被已证 `G` 兑现或已降级，故其 `G` 成立。无环确保无循环论证。∎

**引理 187（精化替换保持单调）** 若 `C ⊑ C'`（`A'⊆A ∧ G⊇G'`）且 schema 一致，则用 `C'` 替换 `C` 后：`C'` 对每条下游假设的兑现能力不弱于 `C`（`G'⊇G`），而 `C'` 要求的假设更少（`A'⊆A`），故任何在原组合中成立的路径在新组合中仍成立；且新组合不会新增被接纳的计划（残余义务只减不增、保证只强不弱）。因此 `Exec_{C'} ⊆ Exec_{C}`，安全继承保持。∎

**引理 188（增量重认证的完备性）** 替换模块 `m` 只改变 `G_m/A_m`。任何契约成立性只依赖 `m` 及其下游的假设兑现关系；与 `m` 无路径相连的模块，其证明前提与结论均未变，缓存记录仍有效。故只需重签 `Affected(m)=descendants(m)`，`O(|Affected|)` 完备（覆盖所有可能失效的边），且不重签无关模块是安全的。∎

**引理 189（v24 整体安全继承）** 同一几何快照、同一 v23 状态、同一能量/契约账本下：SQPC 只在 `G_sym^ε` 商内收缩 `P̂`，其商化偏差由 `ε_asym+ε_shape` 计入包络（183）；PCSD 只加膨胀、取 `min`，且 `ε_shape` 无界时禁用赎回（184/185）；AGCC 只把未兑现假设降级、无环保证组合可靠（186）；MSDR 只在精化序与 schema 一致下替换、只减 `Exec`（187/188）；HPC-OC 是 v23 HPC-EI 与上述四者的合取。故 `Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`。∎

## 6. 已知风险与失效模式

1. **形状模型失配（最大风险）**：`M` 与真实对象的 `ε_shape` 在可变形/附件/遮挡下无界，使包络漏掉真实几何。缓解：`ε_shape` 无界即禁用赎回、只增障碍、回退 v23（E916/E919/E921）。
2. **对称误判**：把带把手/缺口/贴附物的对象误判为对称而商掉真实几何。缓解：`ε_asym` 双向 Hausdorff 校验、只商可验证子群、破缺方向不商（E910/E911/E937）。
3. **假兑现（契约责任真空）**：A 以为 B 保证、B 以为 A 保证，账本未覆盖的耦合被"合法化"。缓解：依赖 DAG 无环检查 + 残余义务显式降级 + merkle 审计定位（E924/E926）。
4. **SE(3) 度量低估**：用欧拉角独立误差低估最坏朝向位移，导致包络偏小。缓解：测地旋转界 `2ρ sin(ε_R/2)` + 联合 conformal 同时覆盖（E907/E908/E915）。
5. **增量重认证遗漏**：`Affected` 计算漏掉跨层隐式边，导致未重签即放行。缓解：把隐式边显式入 DAG、`descendants` 完备性检验（E932）。
6. **热插拔窗口风险**：新模块 `(⊤,⊥)` 未生效前旧缓存被复用。缓解：安装即失效缓存、冻结安全态、TTL 强制保守（E934）。
7. **机器人形状 SDF 过度乐观**：`ε_robot` 未由模块位姿契约背书却使用形状 SDF。缓解：无背书回退保守球，形状 SDF 只在契约兑现时启用（E918/E933）。

## 7. 本轮最大风险

**一句话**：SQPC/PCSD 的全部收益押在"形状模型 `M` 忠实于真实对象、且对称判定可验证"上，AGCC 的全部严谨性押在"每条假设都被某个上游保证真正兑现"上；若真实对象可变形/带未建模附件（衣物、线缆、贴附物）使 `ε_shape` 实际无界，或契约之间出现未被账本覆盖的耦合（A 以为是 B 保证、B 以为是 A 保证，形成"假兑现"），系统就会拿着一份每层都合规、每条假设都"有主"的证书，去碰撞一个没有任何一层真正负责的真实对象——即"**由契约合法化的责任真空（组合化的建模幻觉）**"。
