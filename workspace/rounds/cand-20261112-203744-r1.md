# 第 62 轮（承接第 61 轮「具身语义进化闭环」ESEC IP-173~182；灵感循环第 8 轮；本轮灵感：「创新点」×「动力学」）

> 第 61 轮用 USR/MEL/DMS/SRT-Dual 把「语义—物理—控制」接成闭环。但它对**动力学**仍有两个未言明的假设，对**创新点**仍停留在口号层面：
> 1. **闭环稳定性只是断言**：ESEC 的语义流（~10–100Hz）与实时流（~1–10kHz）构成一个带 100–500ms 延迟的非线性反馈环——MEL 语义变化 → K_safe 变化 → 接触证据变化 → 语义再更新。第 61 轮只证明了「实时流不阻塞」，**没有证明这个跨时间尺度环路收敛**；延迟反馈在环路增益过大时会产生极限环甚至发散。
> 2. **对齐损失在追自己的影子**：ℒ_align 的目标含 evidence_emb，而 evidence_emb 由刚执行的 K_safe 产生，K_safe 又由 Π(anchor) 产生。于是「语义→阻抗→证据→语义」构成正反馈，**系统可能在学自己刚制造出来的偏差**（self-excitation）。
> 3. **「新息」被当成噪声平均掉**：第 61 轮用 D⁺_sem 阈值触发 MEL 重推理，却没有区分「环境真的变了（外生新息）」与「我们自己刚动了（内生新息）」，也没有区分「可学习（认知）」与「不可约（偶然）」——结果要么对噪声过敏，要么对真正的创新点视而不见。
> 4. **没有「值得学」的判据**：DMS/XMC+++ 会触发重推理，但「这次重推理是否带来信息增益、是否值得冒探索风险」没有形式化。「创新点」在本轮被重新定义为**显著、持续、可约、可承受**的新息事件。
> 5. **接触是混合动力学**：碰撞/粘滞/滑移的模式切换使线性化瞬间失效；在切换瞬间做自适应，等价于在模型不成立时更新模型。

## 0. 直觉与动机

**灵感 1（动力学 → 把 ESEC 当作带延迟的混合动力系统）**
直觉：不要把语义流与实时流看成两个「模块」，而应看成一个状态为 `(语义锚点 a_t, 阻抗 K_t, 接触模式 m_t)` 的**受控动力系统**。a_t 是慢变量、K_t 是快变量、m_t 是离散切换。系统真正的敌人不是「语义不准」，而是**环路增益 × 延迟**导致的振荡：环境越硬（∂F/∂K 越大）、投影越陡（L_Π 越大）、适应越快（η 越大），环路越接近不稳定边界。关键洞见：**稳定性应成为一等公民**——像实时契约一样被预算、被证书、被在线监控。

**灵感 2（创新点 = 新息 → 创新驱动，而非误差驱动）**
直觉：在估计理论里，**innovation（新息）** 是「观测 − 预测」，不是普通误差，而是「模型尚未解释的那部分世界」。把它拆成 `ν = ν_endo + ν_exo`：`ν_endo` 是**我们自己上一步改变 K 所诱发的接触响应**（自效应），`ν_exo` 才是环境/未建模动力学带来的真新息。关键洞见：**只能对外生新息学习**；对内生新息学习就是「追自己的尾巴」，这是自激振荡的根源。

**灵感 3（创新点 → 创新点的四元判据 NPD）**
直觉：不是所有新息都值得学。把「创新点」严格定义为四元组：**显著**（统计上不是噪声）、**持续**（不是瞬时冲击）、**可约**（更新模型能降低未来新息，即认知不确定性）、**可承受**（在安全与预算内）。用 CUSUM/GLR 检测显著与持续，用「学习增益」检验可约，用 CBF 检验可承受。关键洞见：**「创新点」不是一句口号，而是一个可以被拒绝的假设检验**。

**灵感 4（动力学 + 创新 → 收缩性稳定证书与分岔裕度）**
直觉：用**收缩理论（contraction theory）+ 小增益定理**给闭环发证书：只要 `γ_sem·γ_Π·γ_env·γ_ev < 1`，则对**任意语义延迟**增量稳定（延迟无关收缩）。把适应增益 η 当作分岔参数：η 越过 η* 时系统发生 Hopf/倍周期分岔进入振荡。于是增益调度不是调 PID，而是**把系统保持在分岔裕度内**。关键洞见：**延迟不可怕，环路增益才是杀手；稳定性可以被在线估计并写入预算**。

**灵感 5（合流 → 安全创新激励与 DAIEL 闭环）**
直觉：真正的创新点往往在「模型最不确定但风险可控」的地方。用**对偶控制（dual control）**在安全包络内施加小幅激励，最大化「单位风险的信息增益（创新 ROI）」，主动把认知不确定性变成可学习的接触样本。最终形成 **DAIEL（Dynamics-Aware Innovation Evolution Loop）**：观测 → 新息分解 → 创新点检测 → 门控适应/安全激励 → 收缩证书 → 执行 → 证据回流。关键洞见：**创新不是被动等来的，而是在稳定性与安全约束下主动「问」出来的**。

## 1. 形式化定义（增量：定义 173–184）

**定义 173（创新动力学模型 IDM）** IDM = (F_phys, 𝒢_self, Σ_ν, m_t)。在时刻 t：
- **接触观测**：y_t ∈ ℝ^m（力/力矩、滑移指标、振动）。
- **语义预测**：ŷ_t = F_phys(a_{t-τ_s}, K_{t-1}, ξ̂_t)，a 为语义锚点、ξ̂ 为环境状态估计、τ_s 为语义延迟。
- **原始新息**：ν_t = y_t − ŷ_t。
- **自效应**：ν_t^endo = 𝒢_self^{m_t}(ΔK_{t−W:t−1})，ΔK_i = K_i − K_{i−1}。
- **外生新息**：ν_t^exo = ν_t − ν_t^endo。
- **白化**：ν̃_t = Σ_t^{−1/2} ν_t^exo，Σ_t = Σ_al(y_t) + Σ_model(a_t) + Σ_switch(m_t, m_{t−1})。
- **接触模式**：m_t ∈ {free, stick, slip, impact}，由 CMD（IP-189）给出。

**定义 174（自效应算子与可辨识性）** 𝒢_self^m: ℝ^{W·d_K} → ℝ^m 为线性脉冲响应加有界非线性修正：
```
𝒢_self^m(ΔK_{t−W:t−1}) = Σ_{i=1}^{W} H_i^m ΔK_{t−i} + ε_nl,   ‖ε_nl‖ ≤ β‖ΔK‖²
```
H_i^m 用递归最小二乘（RLS）在线辨识。**可辨识条件（PE）**：激励窗口内 ΔK 对阶数 W 持续激励，即 Gram 矩阵 `G_W = Σ_i ΔK_i ΔK_i^T ⪰ c·I`。若 PE 不满足（最小特征值 < c_pe），则 `Σ_model ← Σ_model·(1+κ_pe)`，置 `identifiable = False`，IGA 只检测、不学习。

**定义 175（创新点 NPD）** 新息能量 I_t = ‖ν̃_t‖²。CUSUM 统计量 `S_t = max(0, S_{t−1} + I_t − κ)`，报警当 S_t ≥ h。用 GLR 给出显著性 p_t 与变化时刻。**创新点**是一个四元组 p = (R, [t1,t2], S, r, risk)，满足：
1. **显著**：p_t ≤ α；
2. **持续**：报警在窗口内连续出现，长度 ≥ L_min；
3. **可约**：r = 1 − U_ep^+ / U_ep^− ≥ r_min（模型更新后认知不确定性下降）；
4. **可承受**：risk(p) ≤ risk_max。
其中 R ⊂ 𝒦 × Ξ 是报警在（阻抗, 环境）空间的聚类区域，S 为累积统计量。

**定义 176（认知/偶然新息分解）** 将 ν^exo 分解为可预测（认知）与不可预测（偶然）：
```
U_ep,t = ‖ E[ν_t^exo | ℋ_{t−1}] ‖²_{Σ^{−1}}
U_al,t = E[ ‖ ν_t^exo − E[ν_t^exo | ℋ_{t−1}] ‖²_{Σ^{−1}} | ℋ_{t−1} ]
I_t = U_ep,t + U_al,t
```
E[·|ℋ] 由轻量预测器（接触模式条件 GRU 或线性 AR）估计；U_al 也可由异方差头 σ_al 给出。**只有 U_ep 可驱动学习**；U_al 只用于调整检测阈值（防止把偶然噪声当创新点）。

**定义 177（创新门控语义更新 IGA）**
```
a_{t+1} = a_t + η_t · g_t · ∇_a log p(ν_t^exo | a_t)
g_t = 1[S_t ≥ h] · 1[r_t ≥ r_min] · 1[identifiable_t]
      · 1[ρ_t ≥ ρ_min] · 1[μ_t ≥ μ_min] · 1[stable_mode_t]
η_t = η_0 · tanh(U_ep,t / U_ref) · ρ_t · mode_conf_t
```
连续性约束：两次适应之间至少间隔 τ_adapt，避免与实时环的采样节拍形成共振。**g_t = 0 时不更新，也不向 USR 写入新锚点**——这是与第 61 轮「无条件 align_step」的本质区别。

**定义 178（语义-阻抗耦合动力学）** 令 z_t = (a_t, K_t)，混合系统为：
```
a_{t+1} = (1 − α) a_t + α Φ(a_t, e_t, ν_t^exo)      # 语义流，延迟 τ_s
K_t     = Π(a_{t−τ_s}) + u_t^safe                    # 实时流，反馈由 ERTC/EEIS 给出
e_t     = E_ev(y_t)
y_t     = F(K_t, ξ_t, m_t) + w_t
m_{t+1} = δ(m_t, y_t, K_t)                           # 离散模式转移，满足平均驻留时间 τ_dwell
```
该定义把第 61 轮的两条流水线显式写成一个**带延迟与离散切换的反馈系统**，为稳定性分析提供对象。

**定义 179（收缩度量与小增益条件）** 在切丛上取度量 M(z) ≻ 0。若沿任意两条轨迹的虚位移 δz 满足
```
d/dt (δz^T M δz) ≤ −2λ (δz^T M δz)
```
则系统收缩。对采样 + 延迟环，充分条件为小增益：
```
γ_loop = γ_sem · γ_Π · γ_env · γ_ev < 1
γ_sem = η_t L_Φ,  γ_Π = L_Π,  γ_env = sup_t ‖∂F/∂K‖,  γ_ev = L_ev
```
对收缩/ISS 子系统，该条件**与延迟无关**（任意 τ_s 下稳定）。模式切换时使用逐模式度量 M_m，并要求平均驻留时间 ≥ τ_dwell，避免「切换过快导致逐模式稳定但整体不稳定」。

**定义 180（稳定裕度与最终有界性）** 稳定裕度 ρ_t = 1 − γ_loop,t，调度器强制 ρ_t ≥ ρ_min。取 Lyapunov 函数
```
V_t = ‖a_t − a*‖²_M + λ_K ‖K_t − K*‖²_M
```
在假设 A71–A75 下：
```
E[V_{t+1}] ≤ (1 − γ_t) V_t + c‖ν_t^exo‖² + c_s·1[m_t ≠ m_{t−1}]
limsup_t E[V_t] ≤ (c/γ_min)·sup‖ν^exo‖² + (c_s/γ_min)·Pr(switch)
```
即：**有界外生新息 ⇒ 有界语义漂移**，不会无界发散；模式切换只贡献有界跳变。

**定义 181（分岔裕度与增益调度 BMS）** 以 η 为分岔参数，η* 为线性化特征方程首个穿越单位圆（Hopf/倍周期）的临界增益。分岔裕度 μ_t = (η*_t − η_t)/η*_t，要求 μ_t ≥ μ_min。调度：
```
η_t = min(η_adapt, (1 − μ_min)·η*_t, η_max)
```
η*_t 由递归谱半径估计（每 N 个语义周期）或描述函数法估计。若 μ_t < μ_min 或 ρ_t < ρ_min：置 η_t ← 0，`K_d ← K_d·(1+δ_d)`（增阻尼），并把事件升级给 DMS 澄清，而不是继续自适应。

**定义 182（安全创新激励 SIE 与创新 ROI）** 安全激励集
```
𝒰_safe(a_t) = { δK : K_t+δK ∈ 𝒦_hard(a_t)
                     ∧ max_{φ∈Φ_wc} F_pred(K_t+δK, φ) ≤ F_hard }
```
选择 `δK* = argmax_{δK∈𝒰_safe} ROI(δK)`，其中
```
ROI(δK) = ΔU_ep(δK) / (risk(δK) + λ_c·cost(δK))
ΔU_ep(δK) ≈ I_Fisher(δK; φ_phys) · tr(Σ_φ)        # D-最优 / 信息增益
```
仅当 ROI ≥ ROI_min、B_innov 允许、ρ_t ≥ ρ_min 时执行；激励幅度 ≤ δK_max，持续 ≤ T_probe，并全程受 CBF 约束。

**定义 183（创新-动力学预算 B_dyn 与 PCE++++++）**
```
B_innov = (κ, h, α, r_min, E_probe, ROI_min, T_probe)
B_stab  = (ρ_min, μ_min, η_max, τ_dwell, τ_adapt, freeze_policy)
cost_dyn = λ_ep·(E_probe/E_budget) + λ_fa·FAR
         + λ_mg·max(0, ρ_min − ρ_t) + λ_g·(η_t/η_max)
voi_dyn  = VOI_meta − cost_dyn − cost_exec
```
降级策略：
- **B_stab 耗尽** → 冻结适应（η=0）+ 保守扩展 + 仅使用上一稳定锚点；
- **B_innov 耗尽** → 停止主动激励，只保留被动检测；
- **检测到创新点但 B_stab 不足** → 转 DMS 澄清/协商，而非自适应。

**定义 184（动力学联合证书 J_dyn 与 DAIEL）**
```
J_dyn = (J_sem_exec, H(ν^exo), H(ν^endo), S_t, U_ep/U_al,
         ρ_t, μ_t, η_t, g_t, probe_log, mode_trace, calib_id)
Valid(J_dyn) ⇔ Valid(J_sem_exec) ∧ ρ_t ≥ ρ_min ∧ μ_t ≥ μ_min
               ∧ (adaptation_frozen ∨ I_t ≤ I_max)
DAIEL = NPD ∘ IDM ∘ (IGA ⊕ SIE) ∘ DSC ∘ J_dyn
```
DAIEL 与第 61 轮 ESEC 的语义/实时双流兼容：检测、分解、证书都在语义流完成；实时流只消费冻结后的 K_prior，不承担任何新计算。

### IP-183 IDM（创新动力学模型）

```python
class InnovationDynamicsModel:
    def __init__(self, m, dK, W=16, c_pe=1e-3):
        self.W, self.m, self.dK = W, m, dK
        self.H = {mode: [np.zeros((m, dK)) for _ in range(W)]
                  for mode in ('free', 'stick', 'slip', 'impact')}
        self.P = {mode: np.eye(W * dK) for mode in self.H}
        self.identifiable = True
        self.sigma_model_scale = 1.0
        self.c_pe = c_pe

    def endogenous(self, dK_window, mode):
        # dK_window: [W, dK]，最近 W 步的指令阻抗变化
        return sum(self.H[mode][i] @ dK_window[i] for i in range(self.W))

    def decompose(self, y, y_pred, dK_window, mode, Sigma_al):
        nu = y - y_pred
        nu_endo = self.endogenous(dK_window, mode)
        nu_exo = nu - nu_endo
        Sigma = Sigma_al + self.sigma_model_scale * np.eye(len(y))
        L = np.linalg.cholesky(Sigma)
        nu_exo_w = np.linalg.solve(L, nu_exo)
        return nu, nu_endo, nu_exo, nu_exo_w

    def update_self_effect(self, dK_window, nu, mode):
        X = dK_window.reshape(-1)
        G = np.outer(X, X)
        pe = np.linalg.eigvalsh(G + 1e-9 * np.eye(len(X)))[0]
        self.identifiable = pe >= self.c_pe
        if not self.identifiable:
            # 不可辨识：膨胀模型不确定性，禁止自适应
            self.sigma_model_scale = min(10.0, self.sigma_model_scale * 1.1)
            return
        K_gain = (self.P[mode] @ X) / (1.0 + X @ self.P[mode] @ X)
        theta = np.concatenate([h.reshape(-1) for h in self.H[mode]])
        theta = theta + K_gain * (nu - X @ theta)
        self.P[mode] -= np.outer(K_gain, X @ self.P[mode])
        self.H[mode] = [theta[i*self.m*self.dK:(i+1)*self.m*self.dK]
                        .reshape(self.m, self.dK) for i in range(self.W)]
        self.sigma_model_scale = max(1.0, self.sigma_model_scale * 0.999)
```

### IP-184 NPD（创新点检测）

```python
class NoveltyPointDetector:
    def __init__(self, kappa=1.0, h=8.0, alpha=0.01, r_min=0.2, L_min=3):
        self.kappa, self.h, self.alpha, self.r_min = kappa, h, alpha, r_min
        self.L_min = L_min
        self.S = 0.0
        self.window = deque(maxlen=64)
        self.ep_history = []

    def step(self, nu_w, U_ep, U_al, K, xi):
        I = float(nu_w @ nu_w)
        self.S = max(0.0, self.S + I - self.kappa)
        alarm = self.S >= self.h
        p_val = self.glr_pvalue(nu_w) if alarm else 1.0
        self.window.append((I, U_ep, U_al, K, xi, alarm))

        if len(self.window) < self.L_min:
            return None
        recent = list(self.window)[-self.L_min:]
        persistent = all(w[5] for w in recent)
        if not (alarm and persistent and p_val <= self.alpha):
            return None

        # 可约性：用最近新息做一次一步预测检验
        r = self.reducibility(U_ep)
        if r < self.r_min:
            return None

        return NoveltyPoint(
            region=self.cluster_region(recent),       # 在 (K, xi) 空间聚类
            window=(len(self.window) - self.L_min, len(self.window)),
            S=self.S, p_value=p_val, reducibility=r,
            risk=self.risk_estimate(recent))
```

### IP-185 IGA（创新门控适应）

```python
class InnovationGatedAdaptation:
    def __init__(self, eta0=1e-3, U_ref=1.0, rho_min=0.2, mu_min=0.3,
                 tau_adapt=0.05, ep_ratio_min=0.5):
        self.eta0, self.U_ref = eta0, U_ref
        self.rho_min, self.mu_min = rho_min, mu_min
        self.tau_adapt, self.ep_ratio_min = tau_adapt, ep_ratio_min
        self.last_update = -1e9

    def gate(self, novelty, U_ep, U_al, rho, mu, identifiable, stable_mode, t):
        return (novelty is not None
                and identifiable and stable_mode
                and rho >= self.rho_min and mu >= self.mu_min
                and U_ep / max(U_al, 1e-9) >= self.ep_ratio_min
                and (t - self.last_update) >= self.tau_adapt)

    def step(self, a, grad, novelty, U_ep, U_al, rho, mu,
             identifiable, stable_mode, t):
        if not self.gate(novelty, U_ep, U_al, rho, mu,
                         identifiable, stable_mode, t):
            return a, 0.0
        eta = self.eta0 * np.tanh(U_ep / self.U_ref) * rho
        self.last_update = t
        return a - eta * grad, eta
```

### IP-186 DSC（动力学稳定证书）

```python
class DynamicsStabilityCertificate:
    def __init__(self, rho_min=0.2, mu_min=0.3):
        self.rho_min, self.mu_min = rho_min, mu_min

    def loop_gain(self, eta, L_phi, L_Pi, L_env, L_ev):
        return eta * L_phi * L_Pi * L_env * L_ev

    def margin(self, eta, L_phi, L_Pi, L_env, L_ev):
        gamma = self.loop_gain(eta, L_phi, L_Pi, L_env, L_ev)
        return 1.0 - gamma

    def certify(self, rho, mu, anchor_fresh, J_sem_exec, mode_stable):
        return (rho >= self.rho_min and mu >= self.mu_min
                and anchor_fresh and mode_stable and Valid(J_sem_exec))
```

### IP-187 BMS（分岔裕度调度）

```python
class BifurcationMarginScheduler:
    def __init__(self, mu_min=0.3, eta_max=1e-2, delta_d=0.2):
        self.mu_min, self.eta_max, self.delta_d = mu_min, eta_max, delta_d

    def estimate_eta_star(self, linearized_loop):
        # 对 eta 做二分，找谱半径首次达到 1 的临界值
        lo, hi = 0.0, 1.0
        for _ in range(20):
            mid = 0.5 * (lo + hi)
            if spectral_radius(linearized_loop, mid) < 1.0:
                lo = mid
            else:
                hi = mid
        return hi

    def schedule(self, eta_adapt, eta_star, rho, K):
        mu = (eta_star - eta_adapt) / max(eta_star, 1e-9)
        if mu < self.mu_min or rho < self.rho_min:
            K = dict(K)
            K['K_d'] = K.get('K_d', 1.0) * (1.0 + self.delta_d)
            return 0.0, mu, K, 'freeze_and_damp'
        eta = min(eta_adapt, (1.0 - self.mu_min) * eta_star, self.eta_max)
        return eta, mu, K, 'adapt'
```

### IP-188 SIE（安全创新激励）

```python
class SafeInnovationExcitation:
    def __init__(self, delta_max=0.1, T_probe=0.2, ROI_min=0.05):
        self.delta_max, self.T_probe, self.ROI_min = delta_max, T_probe, ROI_min

    def propose(self, a, usr, eeis, phi_wc, U_ep, t):

        for dK in sample_neighborhood(self.delta_max, n=32):
            if not eeis.in_hard_envelope(a, dK, phi_wc):
                continue

                best, best_roi = dK, roi
        if best is None or best_roi < self.ROI_min:
            return None
        return Probe(delta_K=best, duration=self.T_probe, roi=best_roi)
```

### IP-189 CMD（接触模式切换守卫）

```python
class ContactModeDiscontinuityGuard:
    def __init__(self, L_mode=3, tau_dwell=0.02, jump_thresh=0.3):
        self.L_mode, self.tau_dwell = L_mode, tau_dwell
        self.jump_thresh = jump_thresh
        self.history = deque(maxlen=32)
        self.mode = 'free'
        self.last_switch = -1e9

    def detect(self, y, y_prev, K, K_prev, t):
        jump = np.linalg.norm(y - y_prev)
        mode = infer_mode(y, K, jump)
        if mode != self.mode:
            self.last_switch = t
            self.mode = mode
        self.history.append(mode)
        return mode, jump > self.jump_thresh

    def stable(self, t):
        return (len(self.history) >= self.L_mode
                and all(m == self.mode for m in list(self.history)[-self.L_mode:])
                and (t - self.last_switch) >= self.tau_dwell)
```

## 2. 关键推导

### 2.1 为什么第 61 轮会「追自己的影子」

第 61 轮的语义更新可抽象为 `a_{t+1}=a_t+η∇ℓ(a_t,e_t)`，其中 `e_t=E_ev(y_t)`，`y_t=F(K_t,ξ_t)+w_t`，`K_t=Π(a_{t−τ})`。线性化：

```
δa_{t+1} = δa_t + η L_Φ δe_t
δe_t     = L_ev δy_t
δy_t     = L_env δK_t = L_env L_Π δa_{t−τ}
⇒ δa_{t+1} = δa_t + η L_Φ L_ev L_env L_Π δa_{t−τ}
```

这是一个**带延迟的单位根 + 反馈**系统。若 `η L_Φ L_ev L_env L_Π ≥ 1`，特征根穿出单位圆，出现振荡/发散。注意 δy_t 中包含 `L_env L_Π δa_{t−τ}`——这部分正是「自己上一步改变阻抗造成的响应」，却被第 61 轮当成环境证据学回去。

### 2.2 新息分解切断自激回路

IDM 估计 `ν_endo = 𝒢_self(ΔK)`，令 `ν_exo = ν − ν_endo`。代入线性化：

```
δν_exo = δy − 𝒢_self(δK) = (L_env − Ĝ_self)δK + δξ
```

若 `Ĝ_self ≈ L_env`（自效应辨识准确），则 `δν_exo ≈ δξ` 只含真实环境变化，学习回路增益从 `L_env` 降到 `‖L_env−Ĝ_self‖`。于是小增益条件变为：

```
γ_loop = η L_Φ L_Π L_ev ‖L_env − Ĝ_self‖ < 1
```

**结论**：自效应辨识误差直接决定稳定裕度；辨识越准，允许的适应增益越大，收敛越快。

### 2.3 延迟无关收缩

对收缩/ISS 子系统，小增益条件 `γ_loop<1` 与延迟 τ_s 无关。直观理由：延迟只改变相位，不放大虚位移的范数；只要每一步都按因子 γ_loop 收缩，任意长的延迟都不会破坏收缩性。因此第 61 轮的 200ms MEL 延迟**本身不是不稳定源**，环路增益才是。这纠正了「大模型慢所以必然不稳」的直觉。

### 2.4 分岔裕度

把 η 视为分岔参数，特征方程 `det(I − (1+γ_loop(η)e^{−jωτ})I)=0` 的首个穿越点给出 η*。工程上不必精确解析，可用递归谱半径/描述函数估计。约束 `η ≤ (1−μ_min)η*` 把系统保持在稳定侧，并留出参数漂移（环境刚度变化、接触模式切换）的鲁棒余量。

```python
class InnovationDynamicsModel:
    def __init__(self, m, dK, W=16, c_pe=1e-3):
        self.W, self.m, self.dK = W, m, dK
        self.H = {mode: [np.zeros((m, dK)) for _ in range(W)]
                  for mode in ('free', 'stick', 'slip', 'impact')}
        self.P = {mode: np.eye(W * dK) for mode in self.H}
        self.identifiable = True
        self.sigma_model_scale = 1.0
        self.c_pe = c_pe

    def endogenous(self, dK_window, mode):
        return sum(self.H[mode][i] @ dK_window[i] for i in range(self.W))

    def decompose(self, y, y_pred, dK_window, mode, Sigma_al):
        nu = y - y_pred
        nu_endo = self.endogenous(dK_window, mode)
        nu_exo = nu - nu_endo
        Sigma = Sigma_al + self.sigma_model_scale * np.eye(len(y))
        nu_exo_w = np.linalg.solve(np.linalg.cholesky(Sigma), nu_exo)
        return nu, nu_endo, nu_exo, nu_exo_w

    def update_self_effect(self, dK_window, nu, mode):
        X = dK_window.reshape(-1)
        pe = np.linalg.eigvalsh(np.outer(X, X) + 1e-9*np.eye(len(X)))[0]
        self.identifiable = pe >= self.c_pe
        if not self.identifiable:
            self.sigma_model_scale = min(10.0, self.sigma_model_scale * 1.1)
            return
        K_gain = (self.P[mode] @ X) / (1.0 + X @ self.P[mode] @ X)
        theta = np.concatenate([h.reshape(-1) for h in self.H[mode]])
        theta = theta + K_gain * (nu - X @ theta)
        self.P[mode] -= np.outer(K_gain, X @ self.P[mode])
        self.H[mode] = [theta[i*self.m*self.dK:(i+1)*self.m*self.dK]
                        .reshape(self.m, self.dK) for i in range(self.W)]
        self.sigma_model_scale = max(1.0, self.sigma_model_scale * 0.999)
```

### IP-184 NPD（创新点检测）

```python
class NoveltyPointDetector:
    def __init__(self, kappa=1.0, h=8.0, alpha=0.01, r_min=0.2, L_min=3):
        self.kappa, self.h, self.alpha, self.r_min = kappa, h, alpha, r_min
        self.L_min, self.S = L_min, 0.0
        self.window = deque(maxlen=64)

    def step(self, nu_w, U_ep, U_al, K, xi):
        I = float(nu_w @ nu_w)
        self.S = max(0.0, self.S + I - self.kappa)
        alarm = self.S >= self.h
        p_val = self.glr_pvalue(nu_w) if alarm else 1.0
        self.window.append((I, U_ep, U_al, K, xi, alarm))
        if len(self.window) < self.L_min:
            return None
        recent = list(self.window)[-self.L_min:]
        if not (alarm and all(w[5] for w in recent) and p_val <= self.alpha):
            return None
        r = self.reducibility(U_ep)
        if r < self.r_min:
            return None
        return NoveltyPoint(region=self.cluster_region(recent),
                            S=self.S, p_value=p_val, reducibility=r,
                            risk=self.risk_estimate(recent))
```

### IP-185 IGA（创新门控适应）

```python
class InnovationGatedAdaptation:
    def __init__(self, eta0=1e-3, U_ref=1.0, rho_min=0.2, mu_min=0.3,
                 tau_adapt=0.05, ep_ratio_min=0.5):
        self.eta0, self.U_ref, self.rho_min, self.mu_min = eta0, U_ref, rho_min, mu_min
        self.tau_adapt, self.ep_ratio_min = tau_adapt, ep_ratio_min
        self.last_update = -1e9

    def gate(self, nov, U_ep, U_al, rho, mu, ident, stable_mode, t):
        return (nov is not None and ident and stable_mode
                and rho >= self.rho_min and mu >= self.mu_min
                and U_ep / max(U_al, 1e-9) >= self.ep_ratio_min
                and (t - self.last_update) >= self.tau_adapt)

    def step(self, a, grad, nov, U_ep, U_al, rho, mu, ident, stable_mode, t):
        if not self.gate(nov, U_ep, U_al, rho, mu, ident, stable_mode, t):
            return a, 0.0
        eta = self.eta0 * np.tanh(U_ep / self.U_ref) * rho
        self.last_update = t
        return a - eta * grad, eta
```

### IP-186 DSC（动力学稳定证书）+ IP-187 BMS（分岔裕度调度）

```python
class DynamicsStabilityCertificate:
    def __init__(self, rho_min=0.2, mu_min=0.3):
        self.rho_min, self.mu_min = rho_min, mu_min

    def margin(self, eta, L_phi, L_Pi, L_env, L_ev):
        return 1.0 - eta * L_phi * L_Pi * L_env * L_ev

    def certify(self, rho, mu, anchor_fresh, J_sem_exec, mode_stable):
        return (rho >= self.rho_min and mu >= self.mu_min
                and anchor_fresh and mode_stable and Valid(J_sem_exec))


class BifurcationMarginScheduler:
    def __init__(self, mu_min=0.3, eta_max=1e-2, delta_d=0.2):
        self.mu_min, self.eta_max, self.delta_d = mu_min, eta_max, delta_d

    def estimate_eta_star(self, linearized_loop):
        lo, hi = 0.0, 1.0
        for _ in range(20):
            mid = 0.5 * (lo + hi)
            lo, hi = (mid, hi) if spectral_radius(linearized_loop, mid) < 1.0 else (lo, mid)
        return hi

    def schedule(self, eta_adapt, eta_star, rho, K):
        mu = (eta_star - eta_adapt) / max(eta_star, 1e-9)
        if mu < self.mu_min or rho < self.rho_min:
            K = dict(K); K['K_d'] = K.get('K_d', 1.0) * (1.0 + self.delta_d)
            return 0.0, mu, K, 'freeze_and_damp'
        return min(eta_adapt, (1.0-self.mu_min)*eta_star, self.eta_max), mu, K, 'adapt'
```

```python
class SafeInnovationExcitation:
    def __init__(self, delta_max=0.1, T_probe=0.2, ROI_min=0.05):
        self.delta_max, self.T_probe, self.ROI_min = delta_max, T_probe, ROI_min

        return Probe(delta_K=best, duration=self.T_probe, roi=best_roi)
```

```python
class ContactModeDiscontinuityGuard:
    def __init__(self, L_mode=3, tau_dwell=0.02, jump_thresh=0.3):
        self.L_mode, self.tau_dwell, self.jump_thresh = L_mode, tau_dwell, jump_thresh
        self.history, self.mode, self.last_switch = deque(maxlen=32), 'free', -1e9

    def detect(self, y, y_prev, K, t):
        jump = np.linalg.norm(y - y_prev)
        mode = infer_mode(y, K, jump)
        if mode != self.mode:
            self.last_switch, self.mode = t, mode
        self.history.append(mode)
        return mode, jump > self.jump_thresh

    def stable(self, t):
        return (len(self.history) >= self.L_mode
                and all(m == self.mode for m in list(self.history)[-self.L_mode:])
                and (t - self.last_switch) >= self.tau_dwell)
```

```python
class InnovationDynamicsBudget:
    def __init__(self, rho_min=0.2, mu_min=0.3, eta_max=1e-2, E_probe=1.0):
        self.B_stab = {'rho_min': rho_min, 'mu_min': mu_min, 'eta_max': eta_max}
        self.B_innov = {'E_probe': E_probe, 'E_used': 0.0, 'probes': 0}
        self.adaptation_frozen = False

    def can_adapt(self, rho, mu):
        return (not self.adaptation_frozen and rho >= self.B_stab['rho_min']
                and mu >= self.B_stab['mu_min'])

    def can_probe(self):
        return (not self.adaptation_frozen
                and self.B_innov['E_used'] < self.B_innov['E_probe'])

    def charge_probe(self, dK, T):
        self.B_innov['E_used'] += float(np.linalg.norm(dK)) * T
        self.B_innov['probes'] += 1

    def voi_dyn(self, voi_meta, cost_exec, cost_dyn):
        return voi_meta - cost_dyn - cost_exec
```

```python
def DAIEL_step(M, y, V, T, P, L, delta_f_req, budget, t):
    # 1) 语义流
    phi_phys, z_scene, pi_intact, U_mel = MEL.infer(V, T, P, L, M.scene_emb)
    a_diag, C_pending, b_intent = DMS.step(U_mel)
    a_t = USR.fuse(z_scene, E_intent(b_intent))

    # 2) 新息分解
    dK_window = M.dK_buffer.last(W=IDM.W)
    nu, nu_endo, nu_exo, nu_w = IDM.decompose(
        y, F_phys(M.anchor, M.K_prev, M.xi_hat), dK_window, M.mode, U_mel.Sigma_al)
    IDM.update_self_effect(dK_window, nu, M.mode)

    # 3) 认知/偶然分解 + 创新点检测
    U_ep, U_al = epistemic_aleatoric(nu_exo, M.history)
    novelty = NPD.step(nu_w, U_ep, U_al, M.K_prev, M.xi_hat)

    # 4) 稳定/分岔裕度
    eta_star = BMS.estimate_eta_star(M.linearized_loop)
    rho = DSC.margin(M.eta, M.L_phi, M.L_Pi, M.L_env, M.L_ev)
    eta, mu, K_damped, mode_action = BMS.schedule(M.eta_adapt, eta_star, rho, M.K_prev)

    # 5) 门控适应
    stable_mode = CMD.stable(t)
    if budget.can_adapt(rho, mu):
        a_t, eta_used = IGA.step(a_t, grad_alignment(a_t, nu_exo), novelty,
                                 U_ep, U_al, rho, mu, IDM.identifiable, stable_mode, t)
    else:
        eta_used = 0.0; budget.freeze()

    # 6) 安全创新激励
    probe = None
    if novelty is not None and budget.can_probe() and rho >= DSC.rho_min:
        probe = SIE.propose(a_t, USR, EEIS, M.phi_wc, U_ep)
        if probe is not None:
            budget.charge_probe(probe.delta_K, probe.duration)

    # 7) 实时流：只消费冻结锚点；探测为有界叠加
    USR.commit_anchor(a_t, phi_phys, U_mel)
    K_safe = EEIS.compile(delta_f_req, M.fused, M.xi_exec, M.Z_env,
                          USR.project(a_t), phi_phys)
    if probe is not None:
        K_safe = apply_bounded_probe(K_safe, probe, M.K_prev)
    EV_exec = ERTC.dispatch(K_safe)

    # 8) 证书与证据回流
    M.history.push(nu_exo, EV_exec)
    J_dyn = build_dynamics_certificate(
        M.J_sem_exec, nu_exo, nu_endo, NPD.S, U_ep, U_al,
        rho, mu, eta_used, novelty is not None, probe, M.mode_trace)
    return K_safe, EV_exec, J_dyn
```

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| IDM | O(W·m·d_K) / 步 | O(\|M\|·W·m·d_K) | PE 满足可辨识；否则膨胀 Σ 并禁学 |
| NPD | O(m) CUSUM + O(L) GLR | O(L·m) | FAR ≤ α；检测延迟 ≤ L_min |
| IGA | O(d_us) / 次 | O(d_us) | 门控保证只在稳定/可辨识/可约时更新 |
| DSC | O(d_us²)（对角 O(d_us)） | O(1) | ρ ≥ ρ_min ⇒ 延迟无关收缩 |
| BMS | O(d_us²) / N 周期 | O(1) | η ≤ (1−μ_min)η* ⇒ 远离首次分岔 |
| SIE | O(n_probe·\|Φ\|) + 小 QP | O(1) | δK ∈ 𝒰_safe ⇒ F ≤ F_hard |
| CMD | O(m) | O(L_mode) | 模式稳定 + 驻留时间 ⇒ 逐模式度量有效 |
| PCE++++++ | O(1) | O(1) | 任一预算耗尽触发安全降级 |
| DAIEL | 实时路径 ≤ 1ms | 语义侧 O(1) | 证书异步，不阻塞实时环 |

**正确性定理（DAIEL-Stable）** 在 A71–A75（自效应可辨识、模式内 Lipschitz、平均驻留时间、有界外生新息、证书/检测器校准）下：
1. 若 `γ_loop < 1−γ_margin`，闭环对任意语义延迟 τ_s 增量稳定，语义锚点有界；
2. ν_endo 被显式扣除，适应只由 ν_exo 驱动，自激被自效应误差界住；
3. NPD 误报率 ≤ α，真实变化在 L_min 步内检出，纯偶然新息不触发适应；
4. 任意探测在 𝒰_safe 内，F ≤ F_hard；ρ<ρ_min 或 μ<μ_min 时 η=0 并增阻尼；
5. B_stab/B_innov 耗尽触发冻结/停探/转澄清，不违反 ERTC。

## 6. 本轮最大风险

**一句话**：自效应模型一旦被低估（漏模态、非线性超界、模式切换仍用旧 H_i），「外生新息」就被自身控制回声污染，门控适应退化为自激正反馈——系统会在**证书宣称稳定**的同时进入极限环或发散；因此必须把「PE 在线监测 + 不可辨识即膨胀禁学 + 切换强制冻结 + 独立硬安全层」作为不可绕过的四重护栏。
