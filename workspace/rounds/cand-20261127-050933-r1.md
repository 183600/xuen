### 灵感驱动研究记录：演示数据 × 同步定位与建图（v25）

**灵感词**：演示数据、同步定位与建图

**直觉与动机**：

上一版（v24 / USMC）已经把机器人本体证明成「不会坏的结构-力学实体」：应力、无源性、屈曲都有可机械复核的证书。但它证明的是「本体安全」，没有证明「行为的知识来源可信」。当前具身策略大量依赖演示数据，而一条演示只有被钉在同一张可验证地图上，才谈得上可复现、可部署。本轮补的是**认识论维度**：数据从哪来、覆盖了哪里、与几何世界是否对得上。

两个灵感词并非并列，而是互为对偶：**演示数据是认识论证据（epistemic evidence），SLAM 是几何学证据（geometric evidence）**。没有几何的演示只是录像；没有演示的几何无法产生行动。更深一层，SLAM 的协方差不是附属品，而是证书体系的「汇率」——它把米、弧度、时间统一换算成可比较的置信椭球，使数据误差、标定误差、对齐误差能在同一坐标系里做预算。

**跨学科类比**：

- 统计学：演示覆盖证书类似 conformal prediction，但交换性假设被替换为「部署域 = 地图可达集」这一显式几何条件。
- 控制论：SLAM 协方差 + 对齐协方差 + 数据误差共同构成 tube-MPC 式的「不确定管」，安全裕度必须吞掉整根管子。
- 计量学 / 数据治理：演示数据需要 datasheet + 哈希溯源，证书可撤销；这与 v24「结构证书可机械复核」同构。

**核心洞见**：一条演示轨迹构成有效样本，当且仅当（i）它覆盖了**地图可达集** `R_map`（而非抽象状态空间），（ii）它被**统计一致地**定位且地图自由空间有净空，（iii）它与地图的 SE(3) 对齐不确定管**不侵入障碍**。三者相乘，才是「演示-几何复合安全」；任一缺失，证书必须退化到 v24。

**形式化目标**：

1. 定义演示数据证书（DDC）：`D = {(τ_i, m_i)}` 附带溯源 / 校准 / 有效性 / 覆盖四元证书；覆盖是对 `R_map` 的 `ε_cov`-网覆盖，并给出有效样本量 `N_eff` 与标注一致性下界。
2. 定义 SLAM 一致性证书（SCC）：位姿图协方差经 NEES / χ² 一致性检验，回环残差检验，Hessian 退化检测；给出绝对锚点有效期 `T_cert` 与认证自由空间净空 `d_safe`。
3. 定义演示-几何对齐证书（DGAC）：演示→地图的 SE(3) 对齐 `T_dm` 及其一阶协方差传播，要求重放轨迹的不确定管 `sdf(x) − κ√λ_max(Σ_x) ≥ d_safe`。
4. 构建统一演示-几何准入门（UDGG）：`HPC-E+ ∪ USMC ∪ DDC ∪ SCC ∪ DGAC` 五层一体，`Exec_v25 ⊆ Exec_v24`。
5. 证明复合安全引理与单调退化链在「数据污染 / SLAM 退化 / 对齐漂移」下的保持性，并显式暴露「地图几何正确性」这一不可由证书自证的公理。

# ============================================================
# IP-444 Demonstration Data Certificate (DDC) — 演示数据证书
# ============================================================
GENESIS = "0" * 64

@dataclass
class DemoSegment:
    payload_hash: str          # 原始轨迹/视频/动作的哈希
    parent_hash: str           # 链上前驱哈希
    chain_hash: str            # H(parent_hash + payload_hash + calibration_id)
    calibration_id: str
    calibration_valid: bool
    sync_err: float            # 时间同步误差上界 (s)
    action_recon_err: float    # 动作重构误差上界
    annotator_kappa: float     # 标注一致性
    states: Tensor             # [T, d] 用于覆盖与 N_eff

@dataclass
class DemonstrationDataCertificate:
    """溯源 + 校准 + 有效性 + 地图可达集覆盖 四元证书"""
    dataset_id: str
    provenance_root: str
    segments: list[DemoSegment]
    eps_cov: float = 0.10      # 覆盖半径
    grid_radius: float = 0.02  # 栅格离散化误差 h/2
    eps_u: float = 0.01        # 动作重构误差上界
    tau_sync_max: float = 5e-3 # 时间同步误差上界 (s)
    n_eff_min: int = 200
    kappa_annot_min: float = 0.60
    metric: str = "euclidean"

    def verify_provenance(self) -> bool:
        """哈希链逐段可验，且根哈希一致；任何段被篡改即失败"""
        h = GENESIS
        for seg in self.segments:
            h = sha256(
                (h + seg.payload_hash + seg.calibration_id).encode()
            ).hexdigest()
            if h != seg.chain_hash:
                return False
        return h == self.provenance_root

    def verify_calibration(self) -> bool:
        """标定有效 + 时间同步 + 动作重构均在界内"""
        return all(
            seg.calibration_valid
            and seg.sync_err <= self.tau_sync_max
            and seg.action_recon_err <= self.eps_u
            for seg in self.segments
        )

    def effective_sample_size(self) -> float:
        """核化 ESS = (Σ K_ij)² / Σ K_ij²，抑制近重复演示的虚假样本量"""
        Z = torch.cat([seg.states for seg in self.segments], dim=0)
        if Z.shape[0] < 2:
            return 0.0
        D = torch.cdist(Z, Z)
        K = torch.exp(-D.pow(2) / (2 * self.eps_cov ** 2))
        return float(K.sum().pow(2) / K.pow(2).sum())

    def verify_validity(self) -> bool:
        """溯源 ∧ 校准 ∧ 标注一致性 ∧ 有效样本量"""
        return (
            self.verify_provenance()
            and self.verify_calibration()
            and all(
                seg.annotator_kappa >= self.kappa_annot_min
                for seg in self.segments
            )
            and self.effective_sample_size() >= self.n_eff_min
        )

    def verify_coverage(self, reachable_cells: Tensor) -> bool:
        """对地图可达集 R_map 的 ε_cov-网覆盖（含栅格离散化余量）"""
        Z = torch.cat([seg.states for seg in self.segments], dim=0)
        tree = cKDTree(Z.numpy())
        dist, _ = tree.query(reachable_cells.numpy(), k=1)
        return bool((dist <= self.eps_cov + self.grid_radius).all())

    def verify_all(self, reachable_cells: Tensor) -> bool:
        return self.verify_validity() and self.verify_coverage(reachable_cells)

# IP-445 SLAM Consistency Certificate (SCC) — SLAM 一致性证书
# ============================================================
@dataclass
class SLAMConsistencyCertificate:
    """统计一致性 + 退化检测 + 锚点时域 + 认证自由空间"""
    pose_graph: "PoseGraph"
    Sigmas: list[Tensor]            # [n][6,6] 边缘协方差
    held_out_edges: list["Edge"]    # 独立验证边（不参与优化）
    hessian: Tensor                 # 信息矩阵（稀疏）
    lambda_min_obs: float = 1e-3
    alpha: float = 0.05
    Sigma_max: float = 1e-4         # 定位方差上界 (m² / rad²)
    T_cert_max: float = 30.0        # 绝对锚点有效期 (s)
    d_safe: float = 0.05            # 认证净空 (m)

    def verify_nees(self) -> bool:
        """平均 NEES 落在卡方置信区间内：拒绝「过度自信」的协方差"""
        vals = []
        for e in self.held_out_edges:
            r = e.residual()
            S = e.covariance()
            vals.append(float(r @ torch.linalg.solve(S, r)))
        n, k = len(vals), 6
        if n == 0:
            return False
        lower = float(chi2.ppf(self.alpha / 2, n * k)) / n
        upper = float(chi2.ppf(1 - self.alpha / 2, n * k)) / n
        mean = sum(vals) / n
        # 上界超限 = 过度自信（危险）；下界过低 = 过度保守（可接受但低效）
        return lower <= mean <= upper

    def verify_loop_consistency(self) -> bool:
        """回环残差 χ² 检验：单条回环不得显著超出其声明协方差"""
        for e in self.pose_graph.loop_edges:
            r, S = e.residual(), e.covariance()
            if float(r @ torch.linalg.solve(S, r)) > float(chi2.ppf(1 - self.alpha, 6)):
                return False
        return True

    def verify_observability(self) -> bool:
        """退化检测：最小特征值过低的方向不可观测，证书拒发"""
        evals = torch.linalg.eigvalsh(self.hessian)
        return bool(evals.min() >= self.lambda_min_obs)

    def verify_anchoring(self, last_anchor_time: float, now: float) -> bool:
        """无独立绝对锚点（GNSS/UWB/已知标靶）则证书随时间过期"""
        return (now - last_anchor_time) <= self.T_cert_max

    def certified_free_space(self, sdf, points: Tensor, kappa: float = 3.0) -> Tensor:
        """点 x 通过当且仅当 sdf(x) − κ√λ_max(Σ_x) ≥ d_safe"""
        mask = []
        for i, x in enumerate(points):
            sigma = torch.sqrt(torch.linalg.eigvalsh(self.Sigmas[i]).max())
            mask.append(float(sdf(x)) - kappa * float(sigma) >= self.d_safe)
        return torch.tensor(mask, dtype=torch.bool)

    def verify_all(self, last_anchor_time: float, now: float) -> bool:
        return (
            self.verify_nees()
            and self.verify_loop_consistency()
            and self.verify_observability()
            and self.verify_anchoring(last_anchor_time, now)
        )

# IP-446 Demo-Geometry Alignment Certificate (DGAC) — 对齐证书
# ============================================================
@dataclass
class DemoGeometryAlignmentCertificate:
    """演示→地图 SE(3) 对齐 + 协方差传播 + 重放不确定管"""
    T_dm: Tensor              # [4,4] 演示→地图
    Sigma_T: Tensor           # [6,6] 对齐协方差（右扰动）
    eps_align: float = 0.02   # 对齐残差上界 (m/rad)
    kappa: float = 3.0        # 置信椭球放大因子

    def propagate(self, z: Tensor, Sigma_z: Tensor) -> Tensor:
        """右扰动一阶传播：Σ_x = Σ_T + Ad(T_dm) Σ_z Ad(T_dm)ᵀ"""
        Ad = se3_adjoint(self.T_dm)
        return self.Sigma_T + Ad @ Sigma_z @ Ad.T

    def verify_alignment(self, held_out: list[tuple[Tensor, Tensor]]) -> bool:
        """留出对齐样本的 SE(3) 残差必须 ≤ ε_align"""
        res = []
        for z, x_gt in held_out:
            x_hat = self.T_dm @ z
            res.append(torch.linalg.norm(se3_log(x_hat.inverse() @ x_gt)))
        return bool(torch.stack(res).max() <= self.eps_align)

    def verify_replay_tube(self, replay: list[tuple[Tensor, Tensor]],
                           sdf, d_safe: float) -> bool:
        """重放轨迹的置信管不得侵入障碍：sdf(x) − κ√λ_max(Σ_x) ≥ d_safe"""
        for z, Sigma_z in replay:
            Sigma_x = self.propagate(z, Sigma_z)
            radius = self.kappa * torch.sqrt(torch.linalg.eigvalsh(Sigma_x).max())
            x = self.T_dm @ z
            if float(sdf(x)) - float(radius) < d_safe:
                return False
        return True

    def verify_all(self, held_out, replay, sdf, d_safe) -> bool:
        return (
            self.verify_alignment(held_out)
            and self.verify_replay_tube(replay, sdf, d_safe)
        )

# IP-447 UDGG 统一演示-几何准入门
# ============================================================
@dataclass
class UnifiedDemoGeometryGate:
    hpc_e_plus: "HPCEPlus"
    usmc: "UnifiedStructuralMechanicalCertificate"
    ddc: DemonstrationDataCertificate
    scc: SLAMConsistencyCertificate
    dgac: DemoGeometryAlignmentCertificate

    def admits(self, plan, x, v, z, E_res, margin_req, modules,
               F_hist, v_hist, volume, rho_solid,
               reachable_cells, last_anchor_time, now,
               held_out_align, replay, sdf) -> bool:
        # 1. HPC-E+ 基础验证
        if not self.hpc_e_plus.admits(plan, x, v, z, E_res, margin_req, modules):
            return False
        # 2. v24 结构-力学四证
        if not self.usmc.admits(plan, x, v, z, E_res, margin_req, modules,
                                F_hist, v_hist, volume, rho_solid):
            return False
        # 3. 演示数据证书：溯源/校准/有效性 + 地图可达集覆盖
        if not self.ddc.verify_all(reachable_cells):
            return False
        # 4. SLAM 一致性证书：NEES/回环/可观测/锚点时域
        if not self.scc.verify_all(last_anchor_time, now):
            return False
        # 5. 演示-几何对齐证书：留出残差 + 重放不确定管
        if not self.dgac.verify_all(held_out_align, replay, sdf, self.scc.d_safe):
            return False
        return True

## 2. 复杂度分析（增量）

| UDGG 准入判定 | O(N_seg + N² + N log N + T·6³) | O(N² + T) | 在线关键路径仅 DGAC |
| 端到端单步（增量） | +O(T·6³) | +O(T·6²) | T=500 → +0.4 ms |

**实时性保证**：DDC/SCC 为离线或 1 Hz 周期验证；在线关键路径只增加 DGAC 的 O(T·6³) 协方差传播，满足 20 ms 控制环。覆盖与 NEES 结果带版本号缓存，仅在数据集/位姿图/锚点变更时失效重算。

## 3. 正确性论证（增量）

### 引理 9（演示数据证书的溯源-有效性-覆盖三重保证）
**陈述**：`DDC.verify_all(R_map) = True` ⟺
(1) 哈希链完整且根哈希一致（无篡改/无缺段），
(2) 每段标定有效、时间同步误差 ≤ `τ_sync_max`、动作重构误差 ≤ `ε_u`、标注一致性 ≥ `κ_annot`，
(3) `N_eff ≥ n_eff_min`，且 `R_map` 中每个栅格到最近演示状态的距离 ≤ `ε_cov + h/2`。

**证明**：`verify_provenance` 从 GENESIS 逐段重算链哈希并与声明值比对，碰撞抵抗性保证任何段修改必致链断；`verify_validity` 为四条件连言；`verify_coverage` 用 KD-tree 求每个可达栅格的一近邻距离，`+h/2` 覆盖栅格离散化误差。三者合取即三重保证。∎

**注**：覆盖是对**地图可达集**的确定性几何覆盖；它成为部署分布覆盖的充分条件，依赖额外假设 `supp(P_deploy) ⊆ R_map`（部署不越出认证自由空间）。该假设由 SCC 的净空条件显式承担。

### 引理 10（SLAM 一致性证书是统计证书，而非几何证明）
**陈述**：`SCC.verify_all = True` ⟹ 在显著性水平 α 下，测试约束上的协方差**未被拒绝为过度自信**；它**不**蕴含地图几何正确。

**证明**：平均 NEES 服从 `χ²_{6n}/n`（高斯、线性化、正确协方差下），落在双侧区间外即拒绝；回环残差同理。Hessian 最小特征值界定可观测方向。锚点时域限制漂移累积。以上均为**统计自洽性**检验：存在「协方差自洽但均值有偏」的对抗构造（见风险 R11），故只能是必要条件。∎

### 引理 11（对齐不确定管的保守安全）
**陈述**：若 `DGAC.verify_replay_tube = True`，则在一阶高斯传播假设下，重放轨迹上每步真实位姿以概率 ≥ `1 − δ(κ)` 落在半径 `κ√λ_max(Σ_x)` 的椭球内，且该椭球整体位于 `{sdf ≥ d_safe}` 内。

**证明**：`Σ_x = Σ_T + Ad(T_dm) Σ_z Ad(T_dm)ᵀ` 是复合变换的右扰动一阶协方差（Barfoot–Furgale 2014）。`κ` 取卡方分位数使椭球含真值概率 ≥ 1−δ。管检验逐点要求 `sdf(x) − κ√λ_max(Σ_x) ≥ d_safe`，即整个椭球（保守用最大特征值半径）不侵入障碍。∎

### 引理 12（五证单调退化链延伸）
**陈述**：任意单点/组合失效下，`Exec_v25 ⊆ Exec_v24 ⊆ Exec_v23 ⊆ …` 恒成立。

**证明**：在引理 8 基础上增加三条退化路径：
- 数据污染/覆盖缺失 → `DDC=false` → `UDGG` 拒证 → 退回 `Exec_v24`（改用仿真/遥操作数据，保留结构-力学证书）。
- SLAM 退化/无锚点超时 → `SCC=false` → `UDGG` 拒证 → 退回 `Exec_v24`（降速、仅相对里程计、缩小工作域）。
- 对齐漂移/管侵入障碍 → `DGAC=false` → `UDGG` 拒证 → 退回 `Exec_v24`（暂停演示重放，切安全策略）。
- 组合失效取交集，单调性保持。∎

### 定理（UDGG 五证准入门的安全-合规-可部署-可保护-结构-数据-几何完备性）
**陈述**：对任意计划 π，`UDGG.admits(π) = True` ⟺ π 同时满足：
(1) 物理接地安全（v23 五条件），
(2) 云边版本一致性与统计覆盖承诺，
(3) 少样本适应后 conformal 覆盖 ≥ 1−α，
(4) 核心模块专利保护完备且无侵权风险，
(5) 结构应力/能量/可制造性三重达标，
(6) 力控无源性/带宽/稳定性三重达标，
(7) 轻量化刚度/质量/屈曲三重达标，
(8) 演示数据溯源/校准/有效性/地图覆盖四重达标，
(9) SLAM NEES/回环/可观测/锚点时域四重达标，
(10) 演示-几何对齐残差与重放不确定管双重达标。

**证明**：直接由 `UDGG.admits` 的十个连言条件与引理 1–3、5–12 可得。必要性：任一条件缺失即拒证，对应十类风险之一未被缓解。充分性：十条件全满足时，引理 12 保证执行集单调链，引理 9–11 保证数据-几何证据在同一地图坐标系内闭合。

**复合安全预算（显式公理）**：若额外假设地图几何误差 ≤ `ε_map`，则单步碰撞概率上界为
`δ_D + δ_S + δ_A + β_test`，其中 `β_test` 为 NEES 检验的漏检功效。所需净空为
`m_req = d_safe + r_align + r_slam + ε_cov + L_dyn·ε_u + ε_map`。
**注意**：`ε_map` 无法由本证书链自证——这正是本轮最大风险的来源。∎
