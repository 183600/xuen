# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 1 轮；本轮灵感：「安全性」×「材料选型」）

> 第 60 轮把「执行层→证据层」升级为「认知驱动的场景-执行闭环」：SSM 用场景-阻抗先验 π_scene 提前收敛 K_safe、CIEC 把对话意图锁成实时约束、EPIR 用 seq_id+hash 保障 ROS 证据链、SERC 把场景→意图→约束→阻抗→执行→EV-exec 串成闭环、PCE++++ 拓展四维认知预算。但**三个与「安全」和「材料」相关的根本缺口**尚未触及：
> 1. **安全被压缩成常数边界**：K_safe 只回答「阻抗取多大」，却默认「力是安全/不安全」有一个与对象无关的阈值。现实是**同一个法向力，压在硅胶、木板、薄玻璃上分别意味着无损、安全、永久损伤**——安全本质上是**材料本构的函数**，而非控制器的常数约束。
> 2. **材料只是被估计量，不是决策变量**：SSM/SIC 把材料作为场景的隐变量去推断，却从未让机器人**主动选择接触界面材料**。而「材料选型」恰恰是工程上最直接的安全杠杆：更换末端柔性垫（Shore 20A/50A、橡胶、泡沫、硬质聚合物、金属垫）能在不改变任务的前提下重塑整个安全包络。
> 3. **证据链校验数值，不校验材料身份**：EPIR/J_exec 校验 EV-exec 的时间戳与哈希，但**「这块材料到底是什么」是安全级事实**。把玻璃误判成塑料、把陶瓷误判成木头，会让 K_safe 与 F_max 落在灾难侧，而证据链依然「完整且自洽」——这是比丢包更隐蔽的抽象泄漏。

## 0. 直觉与动机

**灵感 1（安全性 → 安全是材料本构的函数 MASE）**
直觉：安全不是一个数，而是**一条依赖于材料状态的曲面**。给材料状态 m 定义损伤边界：玻璃的 F_damage 极低、木头中等、金属很高；湿滑表面的有效摩擦 μ_eff 低，切向力稍大就滑移；泡沫可承受大位移但怕持续压力蠕变。因此「安全」应形式化为**材料感知安全包络** S_safe(m) = {(F_n, F_t, K, v) | g_j ≥ 0}，控制器只能在这个随 m 变化的集合内取值。关键洞见：**先辨识材料，再谈安全；材料一变，安全包络整体平移**。

**灵感 2（材料选型 → 把界面材料当成与 K 并列的决策变量 MSC²）**
直觉：既然安全包络依赖「对象材料 × 末端材料」的耦合，机器人就可以**换垫子**。面对未知易碎物，选软硅胶垫把接触刚度 k_e 压低、把力峰值削平；面对需要高摩擦的抓取，选橡胶垫提高 μ_eff；面对高温件，选低导热材料隔热。于是材料选型 m_e 与阻抗 K 构成**二维协同决策**：max 任务收益 − 风险，s.t. 整个材料后验支撑集上的安全裕度都 ≥ β_min。关键洞见：**材料选型不是事后适配，而是安全约束下的联合优化**。

**灵感 3（安全证据 → 材料身份必须可证 MIC）**
直觉：材料误判是「静默的灾难」——不会报错，只会让安全证书说谎。因此需要**材料身份证书** Cert_mat = (材料类, 置信 γ_mat, OOD 标志, 证据哈希, 时间戳)，并把「材料身份可信」设为执行前置条件。当 γ_mat 低于阈值或检测到分布外（OOD）材料时，**不猜，直接退到最坏材料假设**（按最脆弱的玻璃/陶瓷处理），用悲观包络保命。关键洞见：**安全不允许「高置信度的错误」，只允许「低置信度的保守」**。

**灵感 4（三灵感合流 → 材料感知安全闭环 MASC）**
直觉：把「探测→辨识材料→选界面材料+选阻抗→带屏障执行→验证安全裕度→更新材料信念」串成闭环：场景先验给材料初值 p₀(m)；安全探测动作采力-位移响应；贝叶斯更新得到 b(m)、γ_mat；MSC² 选 (m_e*, K*)；MCBF 做运行时安全投影；执行后生成 J_safe 安全证书并回灌 EPIR 与材料信念。形成闭环：**场景→材料→选型→阻抗→安全执行→材料证据→材料信念**。

**灵感 5（预算 → 安全-认知预算 SCB / PCE+++++）**
直觉：材料辨识与安全验证本身消耗资源。把 PCE++++ 再扩展一维为 **B_scb = (B_mid, B_msel, B_verify, B_exec)**：B_mid 是材料辨识采样/算力预算；B_msel 是可选界面材料与换装时间预算；B_verify 是安全证书验证预算；B_exec 是原有执行预算。任一耗尽即触发**安全优先的降级**：B_mid 耗尽⇒最坏材料先验；B_msel 耗尽⇒默认最软界面材料 + 保守 K；B_verify 耗尽⇒拒绝高风险动作/转人工；B_exec 耗尽⇒原有降级。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（材料状态空间与材料先验）** 材料状态 m = (E, ν, μ, H, η, φ_dmg, λ_th) ∈ M，其中 E 为杨氏模量、ν 为泊松比、μ 为摩擦系数、H 为硬度、η 为黏弹性阻尼、φ_dmg ∈ [0,1] 为脆性/损伤敏感度、λ_th 为热导率。材料后验为先验混合：
- p_t(m) = Σ_k w_k · N(m; μ_k, Σ_k) + w_OOD · U(M_shell)
- 对象材料类 M_obj = {glass, ceramic, wood, plastic, metal, fabric, unknown}；末端界面材料库 M_e = {silicone_20A, silicone_50A, rubber_70A, foam_soft, polymer_hard, metal_pad}，每个 m_e 带 (k_e, c_e, μ_e, λ_th,e, cost, mass, swap_time)。
- 有效接触参数由对象与界面材料耦合：k_eff = (k_e⁻¹ + k_obj⁻¹)⁻¹，μ_eff = μ(m_e, m_obj)。

**定义 162（材料感知安全包络 MASE）** 给定材料 m 与界面材料 m_e，安全可行集
```
S_safe(m, m_e) = { x = (F_n, F_t, K, v) | g_j(x; m, m_e) ≥ 0, j = 1..5 }
g1: S_f · F_n − F_damage(m) ≤ 0                    （法向损伤）
g2: |F_t| − μ_eff(m, m_e) · F_n ≤ 0                （摩擦锥/防滑）
g3: D_dmg(t) − D_max ≤ 0,  D_dmg = ∫ φ_dmg(m)·(F_n/F_crit(m))^p dτ  （累积损伤）
g4: v · |F_t| − P_max ≤ 0                          （功率/热）
g5: E_contact − E_human ≤ 0                        （人机接触能量上限）
```
安全裕度 β_safe(x; m, m_e) = min_j ( −g_j(x; m, m_e) / n_j ) ∈ [0, 1]，n_j 为各约束归一化尺度；可行当且仅当 β_safe ≥ β_min。**与第 60 轮区别**：K_safe 是 S_safe 在固定 m 下的一个切片，本轮把 m 提升为主自变量。

**定义 163（材料选型-阻抗协同 MSC²）** 决策变量 (m_e, K) ∈ M_e × 𝒦，材料选型策略 π_mat： (b(m), task) → (m_e*, K*)：
```
maximize   J(m_e, K; b) = E_{m∼b}[ U_task(K, m_e; m) ] − λ_r·Risk(m_e, K; b) − λ_c·Cost(m_e) − λ_s·SwapTime(m_e)
subject to (C1) ∀m ∈ supp(b) ∪ OOD_shell:  β_safe(m_e, K; m) ≥ β_min
           (C2) γ_mat ≥ τ_mat  或  已进入最坏材料鲁棒模式
           (C3) k_eff(m_e, m) ∈ [k_min, k_max],  μ_eff ≥ μ_min（防滑）
           (C4) m_e 的换装时间 ≤ B_msel 剩余
```
注意 (C1) 是**全支撑集**约束而非期望约束：材料不确定时按最坏情况保安全。U_task 可取抓取稳定裕度、探测信息增益；Risk 取损伤的 CVaR_α。

**定义 164（材料身份证书 MIC）** Cert_mat = (class_id, γ_mat, OOD_flag, provenance_hash, t, evidence_ids)，其中：
- γ_mat = max_k b(m_k)，为材料类后验置信；
- OOD_flag = 1[ score_OOD(m_obs) > τ_OOD ]，score 用重构误差/能量分数；
- provenance_hash = H(class_id ‖ m_obs ‖ evidence_ids ‖ t)，防篡改、可追溯；
- **安全门** G_mat = 1[ γ_mat ≥ τ_mat ∧ OOD_flag = 0 ]；G_mat = 0 时强制进入**最坏材料鲁棒模式**（定义 167），禁止使用标称 S_safe。

**定义 165（材料感知安全闭环 MASC）** 算子 MASC(M, scene, task, budget)：
```
① SSM→材料初值:  p₀(m) ← scene_material_prior(z_scene)
② 安全探测:      x_probe = safe_explore( S_safe^worst, B_mid )
③ 材料辨识:      b(m), γ_mat, OOD ← BayesianUpdate(p₀, response(x_probe))
④ 安全门:        if not G_mat: b ← worst_case_prior(M_obj)
⑤ 材料选型协同:  (m_e*, K*) ← π_mat(b, task)
⑥ 运行时投影:    K_safe ← MCBF.project(K*, b)   # 材料条件屏障
⑦ 执行:          telemetry ← execute_contact(m_e*, K_safe)
⑧ 安全验证:      J_safe, β_robust ← verify_safety(telemetry, b, m_e*)
⑨ 证据固化:      EPIR.append(J_safe ‖ Cert_mat)
⑩ 信念更新:      b, scene_material_coupling ← update(b, telemetry, J_safe)
⑪ Return: (m_e*, K_safe, J_safe, Cert_mat, β_robust)
```

**定义 166（材料条件控制屏障函数 MCBF）** 定义 h(x; m, m_e) = β_safe(x; m, m_e) − β_min，要求沿执行轨迹
```
ḣ(x; m, m_e) + α · h(x; m, m_e) ≥ 0,  α > 0
```
可行阻抗集 𝒦_safe(m) = { K ∈ 𝒦 | 存在控制使上述约束成立 }。材料不确定时使用鲁棒屏障：
```
h̄(x; b) = inf_{m ∈ supp(b) ∪ OOD_shell} h(x; m, m_e)
```
并把期望阻抗 K* **投影**到 𝒦_safe 上（二次投影）：K_safe = argmin_{K∈𝒦_safe} ‖K − K*‖²。保证安全集前向不变。

**定义 167（材料歧义下的分布鲁棒安全 DRS）** 给定材料后验 b 与歧义球 𝒫 = { p : KL(p‖b) ≤ ρ }：
```
β_robust(m_e, K) = inf_{p ∈ 𝒫} E_p[ β_safe(m_e, K; m) ]       （或支撑集最坏值）
Risk_robust = CVaR_α[ D_dmg | p ∈ 𝒫 ]
```
安全判据：β_robust ≥ β_min ∧ Risk_robust ≤ R_max。**最坏材料模式**取 m_worst = argmin_{m∈M_shell} F_damage(m)，即按「玻璃/陶瓷」级悲观包络执行。DRS 给出：若 β_robust ≥ β_min，则在 KL 球内任意材料分布下安全违反概率 ≤ δ。

**定义 168（安全-认知预算 SCB / PCE+++++）** B_scb = (B_mid, B_msel, B_verify, B_exec)：
- B_mid = (Probe_budget, Identification_ops, Posterior_precision)
- B_msel = (Material_inventory, Swap_time, Selection_ops)
- B_verify = (Certificate_ops, Barrier_eval_budget, Human_escalation_slots)
- B_exec = (WCET_slack, Bus_bw_slack, Thermal_slack, Prio_headroom)（原有）

降级策略（安全优先、单调）：
```
if B_mid ≤ 0     → b ← worst_case_prior(M_obj); 禁止探索性探测
if B_msel ≤ 0    → m_e ← foam_soft; K ← conservative(K)
if B_verify ≤ 0  → 拒绝高风险动作，转人工/停机（绝不「跳过验证继续跑」）
if B_exec ≤ 0    → 第 60 轮原有降级（场景先验→通用先验）
```
VOI 扩展：voi_safe(π) = VOI_meta_pessimistic(π) − cost_cog(π) − cost_mat(π) − cost_exec(π)，其中 cost_mat = λ_mid·Probe_cost + λ_sel·Swap_cost + λ_ver·Verify_cost。

### IP-161 MASE（材料感知安全包络）

```python
class MaterialAwareSafetyEnvelope:
    def __init__(self, beta_min=0.2, S_f=2.0, D_max=1.0, p=2.0):
        self.beta_min = beta_min
        self.S_f = S_f          # 安全系数
        self.D_max = D_max
        self.p = p

    def constraints(self, x, m, m_e):
        Fn, Ft, K, v = x['F_n'], x['F_t'], x['K'], x['v']
        mu_eff = self._mu_eff(m, m_e)
        g = [
            self.S_f * Fn - m['F_damage'],
            abs(Ft) - mu_eff * Fn,
            x['D_dmg'] - self.D_max,
            v * abs(Ft) - x['P_max'],
            x['E_contact'] - x['E_human'],
        ]
        return g

    def safety_margin(self, x, m, m_e):
        g = self.constraints(x, m, m_e)
        norm = [max(1e-6, abs(m['F_damage'])), max(1e-6, m['F_damage']),
                1.0, max(1e-6, x['P_max']), max(1e-6, x['E_human'])]
        return min(gi / ni for gi, ni in zip(g, norm))

    def feasible(self, x, m, m_e):
        return self.safety_margin(x, m, m_e) >= self.beta_min

    def _mu_eff(self, m, m_e):
        return min(m['mu'], m_e['mu'])   # 薄弱侧主导防滑
```

### IP-162 MSC²（材料选型-阻抗协同）

```python
class MaterialSelectionCoDesign:
    def __init__(self, inventory, mase, lam_risk=1.0, lam_cost=0.2, lam_swap=0.1):
        self.inventory = inventory      # M_e
        self.mase = mase
        self.lam_risk, self.lam_cost, self.lam_swap = lam_risk, lam_cost, lam_swap

    def select(self, belief, task, budget):
        best, best_J = None, -float('inf')
        for m_e in self.inventory:
            if m_e['swap_time'] > budget.B_msel_remaining:
                continue
            for K in self._candidate_impedances(task):
                if not self._all_support_safe(belief, m_e, K):
                    continue
                J = (self._expected_utility(task, m_e, K, belief)
                     - self.lam_risk * self._cvar_risk(belief, m_e, K)
                     - self.lam_cost * m_e['cost']
                     - self.lam_swap * m_e['swap_time'])
                if J > best_J:
                    best, best_J = (m_e, K), J
        return best if best is not None else self._safest_fallback(belief, task)

    def _all_support_safe(self, belief, m_e, K):
        support = belief.support() + belief.ood_shell()
        return all(self.mase.feasible(self._nominal_x(K), m, m_e) for m in support)

    def _safest_fallback(self, belief, task):
        m_e = min(self.inventory, key=lambda e: (e['k_e'], e['cost']))
        K = min(self._candidate_impedances(task), key=lambda k: abs(k['K_p']))
        return (m_e, K)
```

### IP-163 MIC（材料身份证书）

```python
class MaterialIdentityCertificate:
    def __init__(self, tau_mat=0.85, tau_ood=0.7):
        self.tau_mat, self.tau_ood = tau_mat, tau_ood

    def issue(self, belief, obs, evidence_ids):
        class_id = belief.argmax_class()
        gamma = belief.max_prob()
        ood = 1.0 if belief.ood_score(obs) > self.tau_ood else 0.0
        body = f"{class_id}|{gamma:.4f}|{ood}|{sorted(evidence_ids)}|{time.time()}"
        cert = {
            'class_id': class_id, 'gamma_mat': gamma, 'ood_flag': ood,
            'provenance_hash': hashlib.sha256(body.encode()).hexdigest()[:16],
            't': time.time(), 'evidence_ids': sorted(evidence_ids),
        }
        cert['safe_gate'] = int(gamma >= self.tau_mat and ood == 0.0)
        return cert

    def gate(self, cert):
        return cert['safe_gate'] == 1
```

```python
def material_aware_safety_closure(M, scene, task, budget):
    p0 = M.scene_model.material_prior(scene)
    x_probe = M.mase.safe_explore(M.pessimistic_material(p0), budget.B_mid)
```

### IP-165 MCBF（材料条件控制屏障）

```python
class MaterialConditionedBarrier:
    def __init__(self, mase, alpha=1.0, beta_min=0.2):
        self.mase, self.alpha, self.beta_min = mase, alpha, beta_min

    def h(self, x, m, m_e):
        return self.mase.safety_margin(x, m, m_e) - self.beta_min

    def robust_h(self, x, belief, m_e):
        return min(self.h(x, m, m_e)
                   for m in belief.support() + belief.ood_shell())

    def project(self, K_star, belief, x_nom):
        if self.robust_h(x_nom, belief, K_star['m_e']) >= 0:
            return K_star
        # 逐级降低 K_p、提高 K_d，直到鲁棒屏障可行
        K = dict(K_star)
        while self.robust_h(self._x_with(K), belief, K['m_e']) < 0:
            K['K_p'] *= 0.7
            K['K_d'] *= 1.3
            if K['K_p'] < 1e-3:
                return self.conservative_stop(K)
        return K

    def conservative_stop(self, K):
        return {**K, 'K_p': 0.0, 'mode': 'force_limited_stop'}
```

### IP-166 DRS（分布鲁棒安全）

```python
class DistributionallyRobustSafety:
    def __init__(self, mase, rho=0.1, alpha=0.95):
        self.mase, self.rho, self.alpha = mase, rho, alpha

    def beta_robust(self, belief, m_e, K):
        support = belief.support() + belief.ood_shell()
        return min(self.mase.safety_margin(self._x(K), m, m_e) for m in support)

    def risk_robust(self, belief, m_e, K):
        samples = [self._damage(K, m) for m in belief.support()]
        samples.sort(reverse=True)
        k = max(1, int((1 - self.alpha) * len(samples)))
        return sum(samples[:k]) / k          # 最坏尾部均值（CVaR 近似）

    def certify(self, belief, m_e, K, beta_min=0.2, R_max=0.05):
        b = self.beta_robust(belief, m_e, K)
        r = self.risk_robust(belief, m_e, K)
        return b >= beta_min and r <= R_max, b, r
```

### IP-167 SCB（安全-认知预算）

```python
class SafetyCognitiveBudget:
    def __init__(self, probe=20, id_ops=100, swap=2, verify=50, exec_budget=None):
        self.B_mid = {'probe': probe, 'id_ops': id_ops}
        self.B_msel = {'swap': swap, 'remaining': swap}
        self.B_verify = {'ops': verify}
        self.B_exec = exec_budget or ExecBudget()

    def degrade_mode(self):
        if self.B_mid['id_ops'] <= 0:
            return 'worst_case_material'
        if self.B_msel['remaining'] <= 0:
            return 'softest_interface'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| MASE | O(1) 每约束求值 | O(1) | 安全裕度与材料参数单调一致；β_safe ∈ [0,1] |
| MSC² | O(|M_e|·|𝒦|·|supp(b)|) | O(|M_e|·|𝒦|) | 全支撑集可行 ⇒ 任意材料下 β ≥ β_min |

| DRS | O(|supp(b)|) | O(|supp(b)|) | KL 球内安全违反概率 ≤ δ |
| SCB | O(1) 降级判定 | O(1) | 预算单调消耗，耗尽必降级 |

**正确性定理（SAFE-MAT）**：假设 A66–A70 成立：
- **(A66)** MASE：各约束 g_j 对 F_n、F_t、K、v 连续且单调，S_safe 为非空紧集；β_safe 可在线求值。
- **(A67)** MSC²：材料后验支撑集与 OOD_shell 覆盖真实材料（无模型外泄漏）；候选 𝒦 有限。
- **(A68)** MIC：哈希抗碰撞；存在 OOD 检测器使 score_OOD > τ_OOD 当且仅当 m_obs ∉ 训练支撑（可容许漏检率 ε_ood）。
- **(A69)** MCBF：存在 α > 0 使约束可行，投影终止；材料在单步内不变。
- **(A70)** DRS：真实材料分布落在 KL 球 𝒫 内；CVaR 估计无偏。

则：
1. **材料条件安全**：若 (m_e, K) 满足 MSC² 的 (C1)，则 ∀m ∈ supp(b)∪OOD_shell，β_safe ≥ β_min ⇒ 执行期无约束违反（在 A69 下前向不变）。
2. **误判安全**：若 G_mat = 1 失败，系统必进入最坏材料模式；该模式下 β_robust 以 F_damage(m_worst) 为界，故即使材料误判也不越过最脆弱材料的损伤边界。
3. **鲁棒安全**：若 DRS.certify 通过，则 KL 球内任意材料分布下 Pr[安全违反] ≤ δ 且 CVaR_α[D_dmg] ≤ R_max。
4. **证据可信**：Cert_mat 的 provenance_hash 使材料身份可追溯、可验伪；J_safe 与 Cert_mat 绑定，材料身份变更会破坏证据一致性。
5. **预算安全**：B_scb 任一维耗尽，降级方向严格朝「更保守/更少动作」，不存在「降级后更激进」的路径。

### IP-161 MASE（材料感知安全包络）

```python
class MaterialAwareSafetyEnvelope:
    def __init__(self, beta_min=0.2, S_f=2.0, D_max=1.0, p=2.0):
        self.beta_min, self.S_f, self.D_max, self.p = beta_min, S_f, D_max, p

    def constraints(self, x, m, m_e):
        Fn, Ft, K, v = x['F_n'], x['F_t'], x['K'], x['v']
        mu_eff = min(m['mu'], m_e['mu'])
        return [
            self.S_f * Fn - m['F_damage'],
            abs(Ft) - mu_eff * Fn,
            x['D_dmg'] - self.D_max,
            v * abs(Ft) - x['P_max'],
            x['E_contact'] - x['E_human'],
        ]

    def safety_margin(self, x, m, m_e):
        g = self.constraints(x, m, m_e)
        norm = [abs(m['F_damage']) + 1e-6, m['F_damage'] + 1e-6,
                1.0, x['P_max'] + 1e-6, x['E_human'] + 1e-6]
        return min(gi / ni for gi, ni in zip(g, norm))

    def feasible(self, x, m, m_e):
        return self.safety_margin(x, m, m_e) >= self.beta_min
```

### IP-162 MSC²（材料选型-阻抗协同）

```python
class MaterialSelectionCoDesign:
    def __init__(self, inventory, mase, lam_risk=1.0, lam_cost=0.2, lam_swap=0.1):
        self.inventory, self.mase = inventory, mase
        self.lam_risk, self.lam_cost, self.lam_swap = lam_risk, lam_cost, lam_swap

    def select(self, belief, task, budget):
        best, best_J = None, -float('inf')
        for m_e in self.inventory:
            if m_e['swap_time'] > budget.B_msel['remaining']:
                continue
            for K in self._candidate_impedances(task):
                if not self._all_support_safe(belief, m_e, K):
                    continue
                J = (self._expected_utility(task, m_e, K, belief)
                     - self.lam_risk * self._cvar_risk(belief, m_e, K)
                     - self.lam_cost * m_e['cost']
                     - self.lam_swap * m_e['swap_time'])
                if J > best_J:
                    best, best_J = (m_e, K), J
        return best if best else self._safest_fallback(belief, task)

    def _all_support_safe(self, belief, m_e, K):
        support = belief.support() + belief.ood_shell()
        return all(self.mase.feasible(self._nominal_x(K), m, m_e) for m in support)

    def _safest_fallback(self, belief, task):
        m_e = min(self.inventory, key=lambda e: (e['k_e'], e['cost']))
        K = min(self._candidate_impedances(task), key=lambda k: abs(k['K_p']))
        return (m_e, K)
```

```python
class MaterialIdentityCertificate:
    def __init__(self, tau_mat=0.85, tau_ood=0.7):
        self.tau_mat, self.tau_ood = tau_mat, tau_ood

    def issue(self, belief, obs, evidence_ids):

            'provenance_hash': hashlib.sha256(body.encode()).hexdigest()[:16],
            't': time.time(), 'evidence_ids': sorted(evidence_ids),
            'safe_gate': int(gamma >= self.tau_mat and ood == 0.0),
        }

    def gate(self, cert):
        return cert['safe_gate'] == 1
```

```python
def material_aware_safety_closure(M, scene, task, budget):
```

### IP-165 MCBF（材料条件控制屏障）

```python
class MaterialConditionedBarrier:
    def __init__(self, mase, alpha=1.0, beta_min=0.2):
        self.mase, self.alpha, self.beta_min = mase, alpha, beta_min

    def h(self, x, m, m_e):
        return self.mase.safety_margin(x, m, m_e) - self.beta_min

    def robust_h(self, x, belief, m_e):
        return min(self.h(x, m, m_e) for m in belief.support() + belief.ood_shell())

    def project(self, K_star, belief, x_nom):
        if self.robust_h(x_nom, belief, K_star['m_e']) >= 0:
            return K_star
        K = dict(K_star)
        while self.robust_h(self._x_with(K), belief, K['m_e']) < 0:
            K['K_p'] *= 0.7
            K['K_d'] *= 1.3
            if K['K_p'] < 1e-3:
                return {**K, 'K_p': 0.0, 'mode': 'force_limited_stop'}
        return K
```

### IP-166 DRS（分布鲁棒安全）

```python
class DistributionallyRobustSafety:
    def __init__(self, mase, rho=0.1, alpha=0.95):
        self.mase, self.rho, self.alpha = mase, rho, alpha

    def beta_robust(self, belief, m_e, K):
        return min(self.mase.safety_margin(self._x(K), m, m_e)
                   for m in belief.support() + belief.ood_shell())

    def risk_robust(self, belief, m_e, K):
        s = sorted((self._damage(K, m) for m in belief.support()), reverse=True)
        k = max(1, int((1 - self.alpha) * len(s)))
        return sum(s[:k]) / k

    def certify(self, belief, m_e, K, beta_min=0.2, R_max=0.05):
        b, r = self.beta_robust(belief, m_e, K), self.risk_robust(belief, m_e, K)
        return b >= beta_min and r <= R_max, b, r
```
