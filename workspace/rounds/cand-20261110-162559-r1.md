# 第 47 轮（承接第 46 轮 v10 / 产物 v23；本轮灵感：行为克隆 × 多机协作） · Behavior-Clone-Coop：行为克隆驱动的多机协作认证执行框架（分布式证书 v11）

> 承接第 46 轮 v10 Energy-Context-Depth 与 v23 记忆-语音-安全。此前所有版本都是**单机视角**：一台 UniBot 拥有姿态证书 P_t、能量租约 ℓ_e、记忆库与语音交互，隐含假设 H5——安全可由单机自证，策略可由规则/实时求解给出。**行为克隆**给出另一条完全不同的策略获取路径：从专家示范监督学习，样本效率高、推理快、能耗低，但**没有任何安全保证且存在协变量偏移/误差复合**；**多机协作**打破 H5 的自证假设：多台 UniBot 的证书互相依赖、能量可互补、动作需联合约束、通信有延迟与丢包。二者耦合出新问题：**如何用行为克隆获得高效多机协调策略，同时用分布式证书盾牌把无保证的 BC 策略“夹”在可证明安全的动作集内，即使 BC 完全错误也不碰撞、不静默失效，并处理盾牌引发的死锁与证书依赖环**。

## 0. 直觉与动机

**灵感 1（行为克隆 → 提议器而非决策者）**
直觉：BC 把“专家怎么做”压成一个前馈网络：推理开销低、可拟人，正好填补 v10 每 100ms 求解 U(m) 与 Q_safe 排队的实时性缺口。但 BC 只在专家状态分布上可靠；一旦执行进入示范未覆盖状态，误差会逐步复合（协变量偏移 / compounding error），且它对姿态证书、能量租约、邻机位置一无所知。因此 BC 只能当**提议器（proposer）**：产生候选动作，执行前必须通过证书盾牌；真正的安全由证书而非网络保证。

**灵感 2（多机协作 → 证书依赖图 + 联合安全包络）**
直觉：两台机器人共享同一物理世界。若 A 的位姿依赖 B 的观测（互定位、共同建图、B 为 A 提供深度补盲），则 A 的证书 soundness 在逻辑上“继承” B 的有效性。多机不是 N 个独立单机的并集，而是一张**证书依赖图 D_t**；任意两机的证书球还须满足分离约束 dist(P_i,P_j) ≥ d_safe，构成联合安全包络。协作的收益（能量互补、视角互补、任务并行）与风险（依赖环、通信陈旧、互相等待）同源。

**灵感 3（二者耦合 → 盾牌内学习 + 干预即示范）**
直觉：把盾牌干预当成“专家纠正”，用 DAgger 把被盾牌改写后的状态回灌训练集，BC 就会主动学会避开盾牌边界。BC 负责“高效/拟人”，盾牌负责“安全”，数据闭环负责“缩小二者差距”。多机下盾牌还可能让两机互相等待而**死锁**，因此必须配一个带确定性优先级、可证明活性的分布式仲裁。

**耦合升级**：在 v10/v23 根信任层新增**通信租约 ℓ_c** 与**跨机证书依赖图 D_t**；新增 L2.5 **分布式协调证书层**与 L3.5 **BC 盾牌层**。v11 层次：根信任（ℓ_p + ℓ_e + ℓ_c）→ 几何（单机 P_t + 多机联合包络）→ 上下文/协调（CTDE 策略 + 依赖图）→ 安全（SAB + 盾牌 + 死锁仲裁）→ 数据（DCL + DAgger 回灌）。

## 1. 形式化定义（增量：定义 59–64）

**定义 59（多机联合状态与证书依赖图）**
N 台机器人；第 i 台状态 x_i、姿态证书 P_i=(x̂_i,r_i)、能量租约 ℓ_e^i、通信租约 ℓ_c^i。依赖图 D_t=(V,E_t)，边 (j→i)∈E_t 表示 P_i 的计算使用了 j 的观测/位姿。要求 D_t **无环**。i 的证书有效依赖集 V_i(t)={j: 存在依赖路径 j→…→i}。级联有效判据：
Valid(P_i)=∧_{j∈V_i(t)} [Valid(P_j) ∧ δ_ij≤τ_comm ∧ ℓ_e^j 有效]。

**定义 60（通信租约与陈旧膨胀）**
通信租约 ℓ_c^i=(δ_ij, τ_comm, v_max^i)。若最近一次来自 j 的消息时延 δ_ij>τ_comm，则 j 的证书球按可达集膨胀：
r_j^δ = r_j + v_max^j·δ_ij。
**通信可行判据**：δ_ij≤τ_comm，或使用膨胀半径 r_j^δ 后仍满足分离约束。否则依赖边 (j→i) 失效并级联 Valid(P_i)=false。通信租约与能量租约并列，任一过期即 fail-closed。

**定义 61（联合协调证书与成对分离）**
联合证书 J_t^N=(⊗_i P_i, ℓ_p, ℓ_e, ℓ_c, a_t)。
**联合 soundness**：
P(∀i: x_i∈P_i | 所有 Valid(P_i), ℓ_e,ℓ_c 有效) ≥ 1-Σ_i α_i，
且**成对分离** ∀i≠j: dist(P_i^δ,P_j^δ) ≥ d_safe + r_i^δ + r_j^δ。
分离裕度 m_sep(i,j)=dist(P_i,P_j)-d_safe-r_i-r_j ≥ 0，违背即触发联合制动。

**定义 62（行为克隆提议器与证书盾牌）**
BC 策略 π_θ(a|o_1..o_N)（CTDE：集中训练、分散执行）；专家示范 D={(o,a*)}。执行时先采样 a_BC~π_θ，再投影到认证安全动作集：
A_safe(t)={a : J_{t+1}^N(a) 满足定义 61 ∧ 鲁棒一步前向}
a_exec = argmin_{a∈A_safe(t)} ||a-a_BC||_2。
若 A_safe(t)=∅ → 联合制动（fail-closed）。**鲁棒一步前向**：证书预测须叠加动力学预测误差裕度 L_dyn·||a||·Δt，保证预测的 J_{t+1}^N 仍 sound。

**定义 63（盾牌干预率与 DAgger 型代价界）**
令 p_θ 为 BC 诱导状态分布、p_E 为专家分布。盾牌干预率
η(π_θ)=E_{s~p_θ}[1(a_BC∉A_safe)]。
在盾牌把干预状态以专家动作重标注后（DAgger 聚合分布），累积代价满足
J(π_shield) ≤ J(π_E) + u·T·(ε_θ + η(π_θ)·β_dead) + O(u·√(T·log(1/δ)))，
其中 ε_θ=sup_s E_{a~π_θ}[ℓ(a,a*)|s] 为监督误差，u 为单步代价上界，β_dead 为死锁/等待惩罚。
**要点**：盾牌把安全性从 π_θ 精度中解耦（安全由定义 61 保证），但 η 通过干预与死锁侵蚀**活性**，故须用 DAgger 回灌压低 ε_θ 与 η。

**定义 64（带优先级的分布式仲裁与活性）**
给每机确定性优先级 p_i（任务关键度/电池余量/离障碍距离）。仲裁规则：若 A_safe^i(t) 仅含“等待”且与 j 冲突，则低优先级方让行，高优先级方须在 τ_live 内取得非等待安全动作。
**活性谓词 Live**：当 D_t 无环、初始分离裕度≥d_safe、每个连通分量至少有一台非阻塞可动机器人、通信时延有界时，系统在 τ_live 内推进，不发生死锁。

## 2. 新增产出与既有 IP 升级

**IP-69 CBC（Certified Behavior Cloning Shielded Policy）**
- π_θ 提议器（CTDE，分散执行）
- 证书盾牌 S_t：动作投影到 A_safe(t)，鲁棒一步前向校验
- DAgger 回灌：干预状态以专家动作重标注
- 盾牌边界特征（分离裕度、租约余量、依赖深度、邻机距离）作为策略输入

**IP-70 MCC（Multi-robot Coordination Certificate）**
- 证书依赖图构建与无环校验
- 成对分离裕度计算与联合制动
- 双向声明一致性校验（A 声称依赖 B ⇔ B 声称被 A 依赖）
- 确定性优先级仲裁与活性监测

**IP-71 DCL-DAgger（Demonstration & Conflict Logger）**
- 记录盾牌干预、跨机冲突、死锁事件
- 专家重标注 → 增量训练 BC
- 冲突样本按稀有度/后果加权入集

**IP-72 CAL（Communication-Aware Lease）**
- 时延/丢包在线估计 δ_ij
- 陈旧膨胀半径 r_j^δ
- 通信失效 → 删边 → 证书级联失效

**既有 IP 升级**
IP-66 MVR：记忆键加入联合观测 o_1..o_N 与依赖图指纹，检索多机协调 episode
IP-67 VAD：语音可指定角色/目标机，需求分布 R(v) 扩展到多机任务分配
IP-68 SAB：绑定从单机 B(v,P_t) 升级为联合绑定 B(v,J_t^N)
IP-63 ECPS：能量可在机间互补（B 为 A 深度补盲），求解加入通信能量成本
IP-61 DCL：采集效用加入“信息互补度”（跨机视角互补带来的证书收缩）
IP-62 CCA：新增依赖环注入、通信中断、盾牌死锁红队
IP-51 CAR：守卫升级为联合安全谓词 + 仲裁活性检查
IP-45 总线：新增 cert-dependency / joint-certificate / shield-intervention / arbitration 话题

## 3. 算法骨架

每控制周期（分散执行，各机并行）：
1. 读本机 o_i、ℓ_p^i、ℓ_e^i、ℓ_c^i
2. 广播/接收邻机位姿证书与依赖声明，更新 D_t 并做无环与双向一致性校验
3. 由 δ_ij 计算膨胀半径 r^δ 与成对分离裕度 m_sep
4. BC 采样 a_BC~π_θ(a|o_1..o_N)
5. 构造 A_safe(t)（候选枚举/采样 + 鲁棒一步前向证书校验）
6. a_exec=投影(a_BC,A_safe)；若 A_safe=∅ → 仲裁；仍无解 → 联合制动
7. 记录干预样本到 DCL-DAgger，离线重训 π_θ
8. 任一租约失效、依赖成环或双向声明不一致 → fail-closed

## 4. 本轮最大风险

**一句话**：证书依赖图一旦成环或出现双向声明不一致（A 信任 B、B 信任 A，而共同根因使两者同时陈旧），各机会各自判定“我有效”，盾牌却基于错误的 soundness 放行 BC 提议的动作，酿成相关性碰撞；因此必须强制 D_t 无环、双向声明一致，并在通信/能量临界时把联合证书收缩为单机保守证书。

## 2. 关键算法 伪代码

### IP-70 MCC：依赖图与联合证书
```
def update_dependency(msgs, local_decl, tau_comm, v_max):
    D = DiGraph()
    for j, (cert_j, deps_j, delta_ij) in msgs.items():
        if delta_ij <= tau_comm:
            r_j_delta = cert_j.r
        else:
            r_j_delta = cert_j.r + v_max[j] * delta_ij
        for i in deps_j:                       # j 声称 i 依赖 j
            D.add_edge(j, i, r_delta=r_j_delta, delta=delta_ij)
    if not is_DAG(D):                          # 依赖环 -> 拒绝
        return None, 'cycle'
    if not bidir_consistent(D, local_decl):    # 双向声明不一致 -> 拒绝
        return None, 'inconsistent'
    return D, 'ok'

def pairwise_separation(D, certs, d_safe):
    min_margin = inf
    for i, j in combinations(nodes(D), 2):
        r_i = inflated_radius(certs[i], D)
        r_j = inflated_radius(certs[j], D)
        m = dist(certs[i].x, certs[j].x) - d_safe - r_i - r_j
        if m < 0:
            return False, m
        min_margin = min(min_margin, m)
    return True, min_margin
```

def comm_lease_update(history, delta_ij, window=20):
    delta_hat = ewma(history.delta, delta_ij)

### IP-69 CBC：鲁棒盾牌投影
```
def robust_forward_ok(a, J_t, L_dyn, dt, eps_pred):
    J_pred = predict_joint_cert(J_t, a, dt)
    margin = J_pred.min_separation - (L_dyn * norm(a) * dt + eps_pred)
    return J_pred.energy_ok and J_pred.comm_ok and margin >= 0

def shield_project(a_bc, J_t, A_cand, L_dyn, dt, eps_pred):
    safe = [a for a in A_cand
            if robust_forward_ok(a, J_t, L_dyn, dt, eps_pred)]
    if not safe:
        return None, 'brake'               # A_safe = empty -> fail-closed
    return min(safe, key=lambda a: norm(a - a_bc)), 'ok'

def cbc_step(obs, J_t, calib):
    a_bc = pi_theta.sample(obs)
    a_exec, status = shield_project(a_bc, J_t, calib.A_cand, calib.L_dyn,
                                    calib.dt, calib.eps_pred)
    if status != 'ok':
        a_exec = arbiter.choose(J_t)       # 优先级仲裁
        if a_exec is None:
            return None, 'fail-closed'
    if a_exec != a_bc:
        logger.push(obs, a_bc, a_exec, 'intervention')
    return a_exec, status
```

### IP-71 DCL-DAgger：回灌与重训
```
def dagger_relabel(log, expert, rare_weight=3.0):
    batch = []
    for (obs, a_bc, a_exec, kind) in log:
        a_star = expert.act(obs) if expert.available(obs) else a_exec
        w = rare_weight if kind in ('conflict', 'deadlock') else 1.0
        batch.append((obs, a_star, w))
    return batch

def retrain(pi_theta, batch, epochs=5):
    for _ in range(epochs):
        for obs, a_star, w in shuffled(batch):
            loss = w * mse(pi_theta(obs), a_star)
            loss.backward(); optimizer.step()
```

### IP-70 分布式仲裁：优先级 + 活性
```
def arbiter_choose(J_t, robots, tau_live):
    joint = {}
    for comp in connected_components(J_t.dep_graph):
        order = sorted(comp, key=lambda i: robots[i].priority, reverse=True)
        winner = next((i for i in order
                       if has_nonwait_safe_action(i, J_t)), None)
        if winner is None:
            return None                    # 全分量不可动 -> 联合制动
        if time_since(comp.wait_start) > tau_live:
            return None                    # 活性违约 -> 保守停机
        joint[winner] = commit_safe_action(winner, J_t)
        for i in comp:
            if i != winner:
                joint[i] = yield_action(i)  # 其余让行
    return joint
```

## 3. 定理与证明

**定理 1（盾牌安全解耦）**
设定 62 的鲁棒一步前向在每个控制步成立，且单步联合证书 soundness 概率 ≥ 1-α（给定 Valid 与租约有效）。则对**任意** BC 策略 π_θ（含对抗性），执行轨迹满足联合安全谓词（无碰撞、证书有效、能量/通信可行）的概率 ≥ 1-αT。
*证明*：盾牌只执行 a∈A_safe，其鲁棒前向保证 J_{t+1} 在动力学误差裕度内仍 sound。对步数归纳：若 J_t sound 则 J_{t+1} sound。单步违例概率 ≤ α，对 T 步取并集界得 ≥1-αT。π_θ 仅决定 A_safe 是否为空（活性），不进入安全性推导。∎
*推论*：把 BC 从安全论证中移除后，安全率不随 ε_θ 变化；BC 变差只表现为干预率 η 与制动次数上升。

**定理 2（DAgger 型性能界）**
若每轮在盾牌诱导分布 p_{π_shield} 上取得监督误差 ε_N，经 N 轮聚合重标注（含干预样本），则
J(π_shield) ≤ J(π_E) + u·T·ε_N + u·√(2T·log(1/δ))。
*证明要点*：盾牌把轨迹限制在安全集内，聚合分布即 p_{π_shield}；每步代价值有界 u，套用标准 DAgger 无遗憾分析（在线遗憾 → 复合误差），干预样本作为专家标注可消除其偏置。∎
*解释*：安全由定理 1 兜底，定理 2 只保证“越训越接近专家效率”；ε_N→0 时接近专家，但 η 引入的 β_dead（死锁等待）不在本界内，由定理 3 单独处理。

**定理 3（优先级仲裁下的无死锁活性）**
若 (i) D_t 无环且双向声明一致；(ii) 初始分离裕度 ≥ d_safe；(iii) 每个连通分量至少有一台非阻塞可动机器人；(iv) 通信时延有界且优先级在窗口内确定不变，则每个分量在 ≤ τ_live 内至少一台机器人执行非等待动作，系统不死锁。
*证明*：分量内优先级最高的机器人无可让行对象，只要存在非等待安全动作即可推进。若其唯一安全动作是等待，则由 (iii) 存在更高可动者矛盾，故必可推进。推进维持 m_sep≥0（定义 61），状态不会回退到死锁构型；时延有界保证优先级视图一致，避免优先级抖动引发活锁。∎
