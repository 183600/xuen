# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感驱动循环第 2 轮；本轮灵感：「面部表情识别」×「UniBot」）

> 第 57 轮把安全性赌注进一步分散到"元先验 + 共形保底 + 跨模态对账 + 单向信任"上，但它仍默认了两个未被言明的强假设：**(a)** 人类状态只经"标注 / 确认"进入系统，而人其实一直在用脸、姿态、语气说话——表情是最早出现、最低带宽、也最容易被误读的意图旁路；**(b)** 系统是"一个本体、一套任务",所以证据与校准只需在该分布上成立。本轮两个灵感恰好各刺穿一个假设：**面部表情识别**把"人的内部状态"变成可读通道，但表情 ≠ 情绪 ≠ 意图，可摆拍、文化依赖、隐私敏感、且会被机器人自己的表达反向塑造——它只能是**弱证据、可否决不能授权**；**UniBot**把系统推向"一套策略、多本体多任务",于是第 57 轮"坏先验普遍"升级为"**坏证书通用**"——校准与安全不是策略的属性，而是 (策略, 本体, 环境) 三元组的属性，可迁移的只能是**重新落地的程序**，不是信任的值。核心命题由"证据说可信"升级为 **"弱情感可否决不可授权、通用策略须逐本体重新取证"**。

核心矛盾：
- **H29（表情 ≠ 意图）**：把可见行为当内部状态的直接读数，会在"摆拍 / 文化显示规则 / 疼痛掩饰 / 神经多样性"上系统性失效；更危险的是把"没有反对的表情"读成"同意"——这是一条既不安全也不道德的授权旁路。
- **H30（通用 ≠ 通用安全）**：通用策略 π 在一个本体上的校准，不能搬到另一个本体：四足的"踩"与机械臂的"压"共享动作标签，却不共享接触力、支撑与失效模式；证书一旦被当作可携带的信任，就会把局部成立的东西普遍化。
- **H31（隐私 vs 效用 / 同意 vs 胁迫）**：越依赖表情，越接近持续情绪监控；端侧最小化保护隐私但损失信号；而"是否允许情感感知"这一层同意本身可以在机器人表达的压力下被诱导给出。
- **H32（表达-感知共谋）**：机器人一旦用表情 / 语气去"让人安心",它就在改变被观察者的表情分布，再把这个被自己塑造过的反应读成"人信任我"的证据——一个自我实现的信任闭环，与第 57 轮"单模态共谋"同构但更隐蔽。

## 0. 直觉与动机

**灵感 1（面部表情识别 → 情感是"否决票"而非"同意票"）**
直觉：读脸像读一个低带宽、高噪声、可被伪造的辅助仪表盘。人皱眉、迟疑、退缩，往往比语言更早预告"别做";但人微笑、点头，绝不足以证明"可以做"。所以正确用法是**非对称**的：情感通道只有否决权，没有授权权。它能把风险估计推高、把佐证要求加严、触发一次显式再确认，但永远不能降低门槛、不能替代 L2 同意、不能进入不可逆接触必要证据集的"充分"侧。校准也必须分组（文化 / 光照 / 是否摆拍 / 年龄），且**校准不过关就弃权**，让系统退回无情感路径——宁可不读，不可误读。

**灵感 2（UniBot → 可迁移的是再取证程序，不是证书）**
直觉：UniBot 的承诺是"一个策略，多个身体、多种任务"。但安全从来不是策略的孤立属性：同一个"向前"在一台轻四足上是滑移，在一条重机械臂上是压溃。因此本轮把第 57 轮的证书 J_p 抽象成**可迁移证书 UUC**，并给它加一条硬规则：外来证书只能作为"先验提议",必须在目标本体上用本地影子数据**再锚定**（迁移间隙 Δ_cal ≤ δ_transfer、OOD 覆盖达标、动作能力包络一致）后才可参与承诺。可携带的是复核程序 R，不是信任值。

**灵感 3（双向表达 → 机器人自己的表情会污染它读到的表情）**
直觉：如果机器人用"安抚性表达"去提升人的配合度，它就读到一个被自己改变过的分布。用因果语言说，我们要的是 p(e_aff | do(m_R = 中性), h)，而不是 p(e_aff | m_R, h)。于是引入**表达污染度 C_aff**：当机器人表达对人所观测表情的影响超过阈值，就折扣情感证据权重，或先切中性表达一个节拍做**中性复测**，再决定是否使用。并且明确禁止把"最大化人的正性表情 / 信任"写进任何目标函数——那是 Goodhart 的入口。

**灵感 4（隐私与同意 → 情感感知是独立且可撤回的许可）**
直觉：读脸不同于读地面。原始画面不落盘、只在端侧产生短寿命派生态 token（AU 摘要 + 粗粒度效价区间 + 不确定度）、k-匿名或加 DP 噪声、禁跨会话身份链接与长期情绪画像。更重要的是，**是否允许情感感知**是一个独立同意级别 L_aff，可随时撤回；撤回后系统走非情感路径——只损失效率，不放宽安全门槛。且 L_aff 的获取必须在**中性表达**下完成，防止机器人用"亲切"诱导同意。

**灵感 5（合流 → 证据门从五类到六类，但第六类是非对称的）**
直觉：第 57 轮证据门 EV-probe*/visit/margin/xmodal/human 在本轮加入 **EV-affect**，但它是六类中唯一**负向单边**的证据：只增风险、只加佐证、只触发再确认。同时承诺前多两道检查：**情感检查**（弱否决 / 中性复测）与**证书检查**（本地再锚定 / 本体绑定）。击穿安全需要：元先验错 ∧ OOD 漏检 ∧ 跨模态无一致 ∧ 情感未否决 ∧ 证书再锚定也错 ∧ 无裕度 ∧ 人也错——纵深从五层到七层，且新增两层都只朝保守方向增加成本。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（非对称情感证据 AAE）** 端侧通道 f_aff 把帧序列映射为情感 token τ_aff=(AU∈[0,1]^n, v̂, â, β_unc, c_aff)，其中 (v̂,â) 为粗粒度效价 / 唤醒，c_aff 为校准置信。契约：(i) 分组校准 ECE_aff(G)≤ε_aff（G 按文化 / 光照 / 摆拍 / 年龄分层），不达标即弃权；(ii) 独立同意 L_aff 有效；(iii) 极性 σ_aff∈{−,0} 只负向。**非对称单调引理**：若决策规则 φ 仅在 (a) 抬高 P_fail、(b) 增加佐证数 corrob、(c) 触发显式再确认三处使用 τ_aff，则对任意固定动作 P_fail(φ 含情感) ≥ P_fail(φ 不含情感)，且不存在由 EV-affect 直接生成承诺的路径。**否决而非同意**：困惑 / 迟疑 / 退缩检出且 c_aff≥θ_aff ⇒ 禁隐含同意，必须走显式替代通道（文本 / 语音 / 触觉）重新征询；EV-affect 只可进入不可逆接触必要证据集的"必要"侧（增加要求），永不进入"充分"侧。

**定义 140（表达闭环与因果去污 CEL）** 机器人表达 m_R（语气 / 灯 / 姿态 / 屏幕），人自身状态 h。污染度 C_aff=sup_h TV(p(e_aff|m_R,h), p(e_aff|do(m_R=m_0),h))，m_0 为中性表达。若 C_aff>θ_c：情感证据权重 w_aff←w_aff·(1−C_aff)，或强制**中性复测**（切 m_0 一个节拍后重采样）；两者都失败则弃权。任何优化目标中禁止出现"最大化正性表情 / 信任度"项；只允许最小化"误解与后悔"。

**定义 141（表情隐私最小化 EPM）** 原始视频留存时长 0；仅派生短寿命 token（寿命 τ_aff）；k-匿名（同 token 至少 k 个主体不可区分）或 (ε_dp,δ_dp)-DP 加噪；禁跨会话身份链接与长期情绪画像；L_aff 独立可撤回，撤回 ⇒ 非情感回退（安全门槛不变、仅效率损失）；L_aff 必须在中性表达下取得，且机器人不得以表达差异作为获取同意的手段。

**定义 142（UniBot 可迁移证书 UUC）** Cert_b=(S_scope, I_cal, OOD_reg, ρ_ℳ, affect_card, B_embodiment, K_margin^min)。迁移算子 T_{a→b} 合法的充要条件：在 b 的本地影子数据上再锚定，迁移间隙 Δ_cal=|ECE_a−ECE_b^{local}|≤δ_transfer，OOD 经验覆盖 ≥1−α_conf^{local}，且 EAB(a)=EAB(b)。**核心命题**：Safety(π,b,e) ≠ Safety(π,b',e')；可迁移的是再取证程序 R，不是证书的值。未再锚定的外来证书只能作为"先验提议"，不得单独作为承诺依据。

**定义 143（本体-动作绑定 EAB）** 本体 b 的动作语义 A_b 与能力包络 E_b（力矩 / 接触 / 支撑多边形 / 自由度 / 失效模式）。承诺规则作用于**物理效果空间**（接触力、摩擦锥、支撑裕度），而非抽象动作标签；跨本体复用 π 时须重新声明 E_b，并把旧证据投影到新效果空间，投影误差进 P_fail。

**定义 144（统一算子 PCE++）** 每检查点顺序：①元推断（第 57 轮 ID / OOD 共形带）；②跨模态对账（第 57 轮）；③**情感检查**（弱否决 / 中性复测 / 弃权）；④**证书检查**（本地再锚定 / 本体绑定）；⑤承诺 ⇔ ∃g:R≤δ_f(g) ∧ 证据门过；否则元悲观 VOI 探询 → 绕行 → 降档 → L2 协商（τ_int(auth)）或安全停。情感缺省 / 撤回 / 校准失败只跳过③并抬高佐证，绝不放宽④或⑤。

## 2. 关键算法伪代码（完整版见产物区）

```python
def affect_evidence(frame, h, consent, calib):         # IP-139: 只负向
    if not consent.L_aff or not calib.group_ok(h): return None   # 弃权
    tau = on_device_extract(frame)                    # AU/v,a,unc,conf
    if tau.conf < theta_aff: return None
    return EV_affect(tau, polarity='-')               # 只能抬高风险/加佐证

def decontaminate(tau, m_R, M):                        # IP-140: 因果去污
    C = expressive_contamination(tau, m_R, M)          # TV vs do(m0)
    if C > theta_c: return neutral_retest(tau) or None # 中性复测或弃权
    return tau

def transfer_certificate(Cert_a, b, shadow):           # IP-142: 强制再锚定
    if not EAB_match(Cert_a.B, Embodiment(b)): return None
    d = abs(Cert_a.ECE - local_ece(shadow, b))
    if d > delta_transfer: return recertify(Cert_a, shadow, b)
    return reanchor(Cert_a, shadow, b)                 # 只作先验，不作承诺
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| AAE | O(1)/帧（端侧） | O(\|τ_aff\|) 不落盘 | 分组校准、弃权、仅负向（A41） |
| CEL | O(T_aff) 复测 | O(1) | 污染估计与中性复测有效（A42） |
| EPM | O(1) | O(k) token 池 | k-匿名 / DP、L_aff 可撤回（A44） |
| UUC | O(N_shadow)/本体 | O(\|Cert\|) | 强制再锚定、Δ_cal 有界（A43） |
| EAB | O(1) | O(\|E_b\|) | 物理效果空间投影诚实（A43） |
| PCE++ | 同 PCE+ + O(N_shadow) 一次性 | O(\|V\|+\|σ\|) | 只增保守、终止性 |

**正确性定理（ACES 概要，Affect-Certified Embodiment-Scoped Safety）**：在 A33–A40 上加 (A41) 情感通道分组校准、弃权与仅负向使用；(A42) 表达污染度估计与中性复测有效，目标函数不含信任最大化；(A43) 证书再锚定有效、迁移间隙 ≤δ_transfer、EAB 绑定诚实；(A44) 隐私 token 满足 k-匿名 / DP 且 L_aff 可撤回、回退不放宽门槛。则：(i) **非对称健全性**：对固定动作，使用 EV-affect 的系统 P_fail 不高于关闭情感通道的系统，且无情感授权路径；(ii) **迁移健全性**：未经再锚定的证书无部署界，经再锚定后 P(fail)≤δ_f+δ_transfer+ε_meta(k)+δ_probe+δ_ood·α_conf；(iii) 交互单调性延续：新机制只经"信念更准（含加宽）"或"动作更保守"起作用；(iv) PCE++ 在 k_probes+k_cons 内终止。

## 4. 实验设计 E177–E181

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 表情被误读为意图 / 同意 | 高 | 仅负向、veto-not-consent、分组校准、弃权与显式替代通道 |
| 隐私侵犯与情绪监控 | 高 | 端侧 token、k-匿名 / DP、短寿命、L_aff 独立可撤回、禁长期画像 |
| 证书被误当可携带信任 | 高 | 强制本地再锚定、Δ_cal 上界、EAB 绑定；外来证书只作先验 |
| 表达-感知闭环自我强化 | 中高 | 污染度估计、中性复测、禁止信任最大化目标 |
| 情感模型群体偏见 | 高 | 分组校准 + 弃权 + 非情感回退；偏见审计随版本发布 |
| 机器人表达本身不被理解 | 中 | MXI 多模态渲染 + 输入误差模型（第 57 轮继承） |

## 6. 本轮最大风险

**一句话**：本轮同时引入"读人的表情"与"把策略推广到多本体",最大的风险是把**在某个分布上成立的信号与证书误当作跨分布真理**——表情被当成意图、通用策略被当成通用安全；必须以"情感只可否决不可授权 + 中性复测去污 + 证书逐本体强制再锚定"三条约束，否则系统会更快、更"体贴地"把错误承诺做实。

# 第 58 轮产物 · 创新点清单 v34：Affect-Asymmetric-UniCert（非对称情感弱证据×表达闭环去污×可迁移再取证，AAE×CEL×EPM×UUC×EAB×PCE++）

> 承接第 57 轮 IP-133~138（MFSL/XMC/PTM/MXI/FSE/PCE+）与第 56 轮 IP-127~132（SMM/PCE/BVK/ISE/TAF/MEC）。本轮把部署前提从"少样本可校准、跨模态可对账、个性化有界"升级为 **"弱情感可否决不可授权、通用策略须逐本体重新取证"**：情感从"可读的授权捷径"降格为"只能让系统更保守的否决票",通用策略从"一套证书走天下"降格为"可迁移的是再取证程序，不是信任值"。第 57 轮"一切判定器（含元模型）走隔离"在本轮推广为"**一切跨分布证据（含情感与外来证书）走再锚定**"。
> IP 编号：IP-139~IP-144（共 6 个），升级 IP-135/136/137/138 以纳入情感弱证据、表达闭环、隐私同意与证书再锚定。

### IP-139 AAE（非对称情感弱证据）

def affect_evidence(frame, h, consent, calib):
    if not consent.L_aff:                              # 无独立同意 → 弃权
        return None
    if not calib.group_ok(h):                          # 分组校准不达标 → 弃权
        return None
    tau = on_device_extract(frame)                     # 原始帧不落盘
    if tau.conf < theta_aff:
        return None
    return EV_affect(tau, polarity='-')                # 只负向，永不授权

def use_affect(decision, ev, corroboration, reconfirm):
    if ev is None: return decision, corroboration      # 弃权 = 回到无情感路径
    risk = max(risk, risk_with_affect(decision, ev))   # 只能抬高 P_fail
    corroboration = max(corroboration, corrob_with(ev))# 只能加佐证
    if ev.hesitation and not reconfirm.explicit:       # 否决隐含同意
        return 'reconfirm_explicit', corroboration
    return decision, corroboration

### IP-140 CEL（表达闭环因果去污）

```python
def expressive_contamination(tau, m_R, M):
    p_obs = M.affect_model(tau, condition=m_R)         # p(e_aff | m_R, h)
    p_do  = M.affect_model(tau, condition=NEUTRAL)     # p(e_aff | do(m_R=m0), h)
    return total_variation(p_obs, p_do)                # C_aff 估计

def decontaminate(tau, m_R, M):
    C = expressive_contamination(tau, m_R, M)
    if C <= theta_c: return tau, C
    tau2 = neutral_retest(tau, m_R=NEUTRAL)            # 中性复测一个节拍
    if tau2 is None: return None, C                    # 复测失败 → 弃权
    return discount(tau2, 1 - C), C                    # 按污染度折扣
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| AAE | O(1)/帧（端侧） | O(\|τ_aff\|)，原始帧 0 留存 | 分组校准、弃权、仅负向（A41） |
| CEL | O(T_aff) 复测 | O(1) | 污染估计与中性复测有效（A42） |
| EPM | O(1) | O(k) token 池 | k-匿名 / DP、L_aff 可撤回（A44） |
| UUC | O(N_shadow)/本体 | O(\|Cert\|) | 强制再锚定、Δ_cal 有界（A43） |
| EAB | O(1) | O(\|E_b\|) | 物理效果空间投影诚实（A43） |
| FSE+ | O(\|σ\|) | O(\|σ\|) | 六类门、EV-affect 非对称、外来证书不得单独承诺 |
| PCE++ | O(\|CP\|·(k_p+k_c)·(C_VOI+d_φ)+\|CP\|·(A\*+N_shadow)) | O(\|V\|+\|σ\|) | 只增保守、k_p+k_c 终止、四态完备 |

**正确性定理（ACES：Affect-Certified Embodiment-Scoped Safety）**
假设 A22–A32（第 53–55 轮）、A33–A36（第 56 轮）、A37–A40（第 57 轮）成立；**(A41)** 情感通道分组校准、不达标弃权，且 EV-affect 只用于抬高风险 / 增加佐证 / 触发显式再确认；**(A42)** 表达污染度 C_aff 估计有效、中性复测可执行，任何优化目标不含"最大化正性表情 / 信任"；**(A43)** 证书再锚定程序有效、迁移间隙 Δ_cal≤δ_transfer、EAB 绑定与效果空间投影诚实；**(A44)** 隐私 token 满足 k-匿名 / DP，L_aff 独立可撤回且回退不放宽门槛。则：

1. **非对称健全性**：对任意固定动作，使用 EV-affect 的系统 P_fail 不高于关闭情感通道的系统；EV-affect 永不进入任何"充分证据"集合，故不存在情感授权路径。
2. **迁移健全性**：未再锚定的外来证书不产生部署界（只能作先验提议）；经本地再锚定后，P(fail) ≤ δ_f + δ_transfer + ε_meta(k) + δ_probe + δ_ood·α_conf + δ_probe^emb，其中 δ_probe^emb 来自 EAB 投影误差。
3. **交互单调性延续**：情感、表达去污、证书再锚定、本体绑定只能经 (a) 校准信念更新（含强制加宽）或 (b) 更保守的动作参数（佐证数↑、τ_int↓、带变宽、步态降档）影响系统，不存在升险路径。
4. **终止性**：每检查点共识探针 ≤k_cons，PCE++ 在 k_probes+k_cons 内终止于 {承诺, 绕行, L2 协商, 安全停}。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + δ_transfer + ε_meta(k) + δ_probe + δ_ood·α_conf
                   + δ_probe^emb + δ_aff(veto_only) + δ_xm·1[L1])
             − P(𝓜 陈旧未检出) − P(护盾回退失败) − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
```

关键：**情感给否决权、不给授权权**（把"读人"的经济学收益限制在安全侧）；**可迁移的是再取证程序，不是信任值**（把 UniBot 的通用性从安全承诺中剥离）；**表达去污打破"我安抚你→你放松→我据此更自信"的自证闭环**；**隐私同意是独立的、可撤回的、非胁迫的**。四个新机制全部经"信念更准或动作更保守"两个安全通道起作用。

## 6. 本轮最大风险

**一句话**：本轮同时引入"读人的表情"与"把策略推广到多本体",最大的风险是把**在某个分布上成立的信号与证书误当作跨分布真理**——表情被当成意图、通用策略被当成通用安全；必须以"情感只可否决不可授权 + 中性复测去污 + 证书逐本体强制再锚定"三条约束，否则系统会更快、更"体贴地"把错误承诺做实。
