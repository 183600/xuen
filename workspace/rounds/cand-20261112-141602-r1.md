# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 4 轮；本轮灵感：「运动控制」×「真机评测」）

> 第 57 轮把先验从手设换成跨区域摊销、把证据从单模态换成分账对账、把人从常量换成单向状态机，安全的赌注再次后移到"元先验的质量"。但第 57 轮的风险自陈暴露了一个更深的裂缝：**这 57 轮认证的全是"名义规划"，而验证这些认证的"真机评测协议"从未被写进任何一条定理**。具体说：**(a)** 证据门批准的是一个名义步态 σ 与名义落足点，真正的机器人却要经过控制器才到达世界——跟踪误差、执行器饱和、热降额、接触滑移把"计划里安全的落足"变成"执行中不安全的落足"，而证据链一眼都没看实际轨迹；**(b)** 所有 δ_f、δ_ood、ε_meta、α_conf 都是关于真实世界的经验断言，却来自昂贵、非平稳、样本极少的真机试验——"100 次 0 失效"根本不能证明 δ_f=0，且评测者选择种子/地形/指标/停止时机的自由度会让"通过"沦为可被博弈的仪式；**(c)** 元语料以仿真为主、真机极少，若用同一批真机试验既微调元模型又给它发安全证书，就是统计上的双重蘸取（double dipping），证书被系统性乐观偏置。本轮两个灵感各补一类"现实见证"：**运动控制**把承诺从名义轨迹搬到**可跟踪管**（跟踪残差共形分位、EV-exec 执行证据、滑移作为负证据、控制器健康作为状态变量）；**真机评测**把评测变成**预注册、anytime-valid、测试集隔离、出处可审计**的推断过程（仿真只许当先验、不许签最终证书）。本轮给第 57 轮"坏先验普遍"一个新约束：坏先验还必须连续骗过**执行见证**与**评测见证**两道现实检验。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"执行可跟踪、评测可复核的证据说可信"**。

核心矛盾：
- **H29（名义 vs 实际）**：计划层裕度与执行层跟踪管之间没有桥；滑移会吃掉裕度却不改变地图，控制器健康（热/磨损/时延抖动）会悄悄加宽管——系统可以在"地图与证据都没变"的情况下从安全滑向不安全。
- **H30（小样本真机 vs 统计效度）**：真机 N 小、非平稳、评测者自由度大；点估计（0/N）不是证书，任意时刻看结果再停会抬高假认证率——需要 anytime-valid 置信序列与预注册冻结。
- **H31（仿真先验 vs 真机证据 / 数据复用）**：语料仿真为主，真机样本是唯一有效证据；用它既拟合又认证＝双重蘸取，仿真-真机差距若不被显式记账，证书就是"用自己的考卷给自己打分"。

## 0. 直觉与动机

**灵感 1（运动控制 → 从名义轨迹到可跟踪管）**
直觉：前 57 轮在图上规划、然后"承诺"一个步态，好像机器人会瞬移到计划落足点。真实机器人要穿过一个控制器：有跟踪误差、力矩饱和、热降额、接触滑移。于是"承诺"的对象必须从一条名义轨迹变成**它能真正跑出的那束轨迹（管）**——这是管式模型预测控制（tube MPC）的直觉：安全裕度至少要覆盖可达集膨胀。本轮的差异是：这个管是**学出来的、随状态变宽的**（泥地/湿草更宽），且一次滑移既是威胁也是证据（实测跟踪残差反过来更新管）。由此引入：可实现落足后验、跟踪误差管 T(r,g,h)、执行裕度 ρ_exec=K_margin−sup‖e‖、执行证据类 EV-exec，以及把控制器健康 h 列为会加宽管的一等状态。

**灵感 2（真机评测 → 评测本身要被审计）**
直觉：第 1~57 轮所有"失效 ≤δ_f""OOD 检出 ≥95%""成功率 +8%"都是经验断言，而真机试验又少又贵。两个陷阱：**(i)** "100 次 0 失效"与真实失效率高达约 3% 相容，有限样本永远证不出 δ_f=0；**(ii)** 评测者自由度——先看结果再挑种子、地形、指标、停止点——就是 p-hacking。所以评测必须是一个**预注册、anytime-valid、分层、测试集隔离**的协议：用测试鞅/e-value 做可随时停止而不膨胀错误率的序贯检验，预先冻结估计量与指标，留出一块**从不用来校准的真机测试地形**，并且只报置信下界而非点值。一句话：评测不是一个分数，而是一个可被审计的推断过程。

**灵感 3（仿真-真机出处账本 → 仿真只能当先验，不能签证书）**
直觉：补贴"仿真-真机"的差距，最危险的做法是把仿真结论当真机结论、或把同一批真机数据既拿去训练又拿去验收。给每个经验常数打上**出处标签**（sim / real-calib / real-verify / expert-prior）与样本量；规则：仿真证据只能设定初值与先验，**最终 δ 必须由 real-verify 产出，且与 real-calib 的样本集合不相交**。这把"不要用测试集调参"从口头纪律变成一条可机器检查的账本约束。

**灵感 4（三灵感合流 → 双层证据门：计划见证 + 执行见证 + 评测见证）**
直觉：第 57 轮的证据门只到"信念→计划"。本轮给承诺加两个现实见证：**执行见证**（计划所在的管仍在安全裕度内、且实测跟踪落在管内）与**评测见证**（所用 δ 由预注册、出处不相交的真机评测产出）。任一见证失败即降档/停。纵深从"元先验错∧OOD 漏检∧跨模态无一致∧无裕度∧人也错"再加"执行滑出管∧评测无效"——坏先验要连骗两道现实检验。

**灵感 5（PCE++ → 双时钟：快环管检查、慢环评测，慢只能收紧）**
直觉：元推断与评测很慢，管检查必须在控制周期内完成。于是把算子拆成两个时钟：**控制时钟**上做 O(1) 的管检查与 EV-exec，一旦实测跟踪越管立即降档/停（纯安全通道）；**评测时钟**上做元推断、校准与序贯检验，其结果**只能收紧快环的参数（θ_exec↑、佐证数↑、档位↓），永不放宽**。这同时把第 57 轮遗留的"元推断时延进入控制回路"风险改造成结构性的安全性质。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（执行保真管 EFT）** 控制器 C 把名义命令映为实测状态，跟踪残差 e=x_real−x_nom。分层残差集 ℛ(r,g,h)，管 T(r,g,h)={x:‖x−x_nom‖_Q≤w(r,g,h)}，w 取 ℛ(r,g,h) 的共形分位（α_exec）并按控制器健康 h（热、磨损、时延抖动）单调加宽。可实现落足后验 b_r^exec=pushforward(b_r,T)。执行裕度 ρ_exec(σ)=K_margin(σ)−sup_{x∈T}‖x−x_nom‖_Q。执行健全要求 ρ_exec≥θ_exec。

**定义 140（执行证据与滑移账本 EVX）** EV-exec ⇔ 实测落足/接触力/滑移在姿态窗口内满足 e_obs∈T ∧ slip≤slip_max ∧ ρ_exec≥θ_exec；可在 L1 顶替一次到访佐证，但不得单独授权不可逆接触（L2）。EV-slip 为**负证据类**：e_obs∉T ⇒ 立即降档（安全通道）+ 把该残差记入 ℛ(r,g,h) 加宽管（证据通道）。控制器健康 h 单调作用于 w 与 θ_exec，退化只能使系统更保守。

**定义 141（真机评测契约 REC）** 预注册元组 Π=(hypothesis, estimator, metric, strata, seed_policy, stopping_rule, verify_set, α)。有效性四要件：(V1) **anytime-valid**：用测试鞅 e-value E_n，H0 下 E[E_τ]≤1（Ville 不等），任意停止不膨胀一类错误；(V2) **测试集隔离**：verify 样本取自未参与校准/微调的分层（出处账本强制）；(V3) **分层**：覆盖 地形×控制器健康×季节；(V4) **只报界**：给出失效率置信序列上界 U_n（P(∀n:p≤U_n)≥1−α），声明 δ_f 仅当 U_n≤δ_f。Π 冻结后不得因观察结果改估计量/指标/停止规则。

**定义 142（仿真-真机出处账本 STE）** 每个经验常数 κ∈{ε_meta,δ_ood,δ_f,θ_D,w,θ_exec} 带来源标签 src(κ)∈{sim,real-calib,real-verify,expert-prior} 与样本数。约束：(S1) 部署证书中最终 δ 的 src 必须是 real-verify；(S2) 拟合/校准所用样本集与 real-verify 集**不相交**（provenance disjointness）；(S3) 仿真证据只许初始化先验或给效率，必须附 sim-real 差距估计及其自身的真机验证。违反任一即证书降级为"实验性"（仅 L1、禁不可逆）。

**定义 143（双层证据门与执行证书 J_e）** 承诺可采纳 ⇔ ①计划证据门 FSE 通过（第 57 轮）；②执行见证 ρ_exec≥θ_exec 且 EV-exec 成立；③所用 δ 经 REC 有效且 STE 出处不相交。J_e=(J_p, T, e_track_log, h_log, Π, provenance_ledger, U_n, EV-exec_log, derate_log)。不可逆接触必要证据集在 J_e 之上再加 EV-exec 与真实评测见证，缺一即拒。

**定义 144（真机-执行协同算子 PCE++ / 双时钟）** 快时钟（控制周期）：每步算 T(r,g,h) 与 ρ_exec；e_obs∉T 或 ρ_exec<θ_exec ⇒ 沿降档梯度 derate（步速↓/接触级↓/绕行）直至安全停。慢时钟（探询/评测周期）：元推断、共形更新、REC 序贯检验、STE 记账；慢环输出只许收紧快环参数 (θ_exec↑,corrob↑,gait↓)，不许放宽。终止于 {承诺, 绕行, L2 协商, 安全停}，探针数 ≤k_probes+k_cons、降档步数 ≤D_max。

## 2. 关键算法伪代码（完整版见产物区）

```python
def execution_tube(M, r, g, health):                 # IP-139
    res = M.track_resid[(r, g)]                      # 分层跟踪残差
    w = conformal_quantile(res, health_shift(health), alpha=M.alpha_exec)
    return Tube(nominal(r, g), radius=w)             # h 退化 ⇒ w 单调变宽

def execution_gate(c, M, health):                    # IP-140/143
    T = execution_tube(M, c.r, c.sigma.gait, health)
    rho = K_margin(c.sigma) - sup_norm(T)
    if c.e_obs not in T:                             # 滑移：安全 + 证据双通道
        M.track_resid[(c.r, c.sigma.gait)].append(c.e_obs)
        return ('derate', 'slip_outside_tube')
    return ('ok',) if rho >= theta_exec and c.slip <= c.slip_max else ('reject', 'exec_margin')

def eval_audit(contract, provenance):                # IP-141/142
    if not contract.preregistered or contract.looks_after:
        return ('invalid', 'frozen_after_look')
    if not provenance.disjoint(contract.calib_ids, contract.verify_ids):
        return ('invalid', 'double_dipping')         # 同一批真机既拟合又认证
    U = upper_conf_sequence(contract.verify_outcomes, alpha=contract.alpha)  # anytime-valid
    return ('valid', U) if U <= contract.delta_target else ('invalid', 'bound_exceeds', U)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| EFT | O(1)/控制步（分位预计算）；O(\|ℛ\|) 回退 | O(\|ℛ\|) 分层残差 | 共形覆盖 ≥1−α_exec、w 对 h 单调 |
| EVX | O(1)/接触 | O(1) | 滑移双通道、健康单调 |
| REC | O(n) 流式，O(1) 内存（网格 e-value） | O(1) | anytime-valid、预注册冻结、分层 |
| STE | O(1)/查询 | O(#κ) | real-verify 签名、出处不相交 |
| EEG | O(\|σ\|) | O(\|σ\|) | 三见证缺一即拒、L2 加执行见证 |
| PCE++ | O(\|CP\|·(k_p+k_c)+T_c·1) | O(\|V\|+\|σ\|) | 快环 O(1)、双时钟、慢只收紧、D_max 终止 |

**正确性定理（Realizable Audited Soundness, RAS 概要）**：在 A37–A40 上加 **(A41)** 管校准：实测跟踪残差在 T 内覆盖 ≥1−α_exec，w 对健康 h 单调不降；**(A42)** 评测有效：Π 预注册冻结、U_n 为任意停止下有效的失效率上界、STE 出处不相交；**(A43)** 双时钟单调：慢环只收紧快环参数、降档只降低风险、健康退化只加宽管。则：(i) 执行健全：实际轨迹失效 ≤ 计划失效 + α_exec（管外逃逸）+ δ_slip；(ii) 评测有效：所报 δ̂ 在整段序贯检验上以 ≥1−α 覆盖真实失效率；(iii) 交互单调性强化：执行/评测机制只能经"信念更准""动作更保守""参数更严"影响系统；(iv) 部署界中的每个 δ 均可追溯到一个有效、出处不相交的真机评测。若 REC/STE 任一无效，证书自动降级为实验性（仅 L1、禁不可逆）。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 管在非平稳滑移下欠覆盖 | 高 | 自适应共形 + 健康变量入管 + 滑移负证据即时加宽 |
| 评测仍可被"指标选择"博弈 | 高 | 预注册冻结 + 测试集隔离 + 出处账本机器检查 + 只报界 |
| 双重蘸取经"仿真微调"变相回流 | 高 | 出处不相交机械校验 + 证书降级为实验性 |
| 快环检查时延进入控制回路 | 中 | 分位预计算 O(1) + 慢环可抢占 + 退化到手设保守管 |
| 降档导致永不承诺/死锁 | 中 | 有界降档梯度 D_max + 升级人工 + 保守默认安全停 |

## 6. 本轮最大风险

**一句话**：本轮用"跟踪管"和"anytime-valid 评测"两把尺子去丈量现实，但这两把尺子本身也由同一批稀缺真机数据估计——一旦出处账本存在泄漏（例如仿真微调悄悄吸走了验证集信息）、或地形非平稳超出管的分层交换性与评测分层假设，系统就会一边输出"认证有效"的置信界、一边让真实失效率漂到界外，最终认证的不是安全，而是**认证流程自身的自洽**；因此必须以出处不相交的机械校验、预注册冻结、滑移负证据即时加宽三者互为交叉验证，宁可把证书降级为"实验性"，也绝不把"流程通过"当成"现实安全"。

### IP-139 EFT（执行保真管）

```python
def execution_tube(M, r, g, health):
    res = M.track_resid[(r, g)]                       # 分层：地形簇×步态×健康档
    w = conformal_quantile(res, alpha=M.alpha_exec)   # 有限样本覆盖 ≥1-alpha
    w = w + health_shift(health)                      # temp/wear/jitter ⇒ 单调加宽
    T = Tube(center=nominal(r, g), radius=w, norm='Q')
    return T

def exec_margin(sigma, T):
    return K_margin(sigma) - sup_norm(T)              # 管上最坏点吃掉的裕度

def realized_foothold_belief(b_nom, T):
    return pushforward(b_nom, T)                      # 承诺落在可达集而非名义点
```

```python
def execution_evidence(c, M, health):
```

### IP-141 REC（真机评测契约，anytime-valid）

```python
def preregister(hyp, est, metric, strata, seed_policy, stop_rule, verify_set, alpha):
    return Contract(hyp, est, metric, strata, seed_policy, stop_rule,
                    verify_set, alpha, frozen=True, looks_after=False)

def upper_conf_sequence(outcomes, alpha, grid=GRID):
    # 对 H0: p>=p0 的测试鞅 E_n(p0)=∫∏(q/p0)^y((1-q)/(1-p0))^(1-y) dπ(q)
    # Ville: P(∃n:E_n>=1/alpha)<=alpha  ⇒ U_n=inf{p0:E_n(p0)>=1/alpha}
    E = {p0: 1.0 for p0 in grid}
    Us = []
    for y in outcomes:
        for p0 in grid:
            E[p0] *= mixture_lr(y, p0)
        Us.append(min([p0 for p0 in grid if E[p0] >= 1.0 / alpha] + [1.0]))
    return Us

def eval_audit(contract, provenance, outcomes):
    if not contract.frozen or contract.looks_after:
        return ('invalid', 'frozen_after_look')       # 看过结果再改规则=无效
    if not provenance.disjoint(contract.calib_ids, contract.verify_ids):
        return ('invalid', 'double_dipping')          # 同批真机既拟合又认证
    if not provenance.covers_strata(contract.verify_ids, contract.strata):
        return ('invalid', 'strata_gap')
    U = upper_conf_sequence(outcomes, contract.alpha)[-1]
    return ('valid', U) if U <= contract.delta_target else ('invalid', 'bound_exceeds', U)
```

```python
SRC_RANK = {'expert-prior': 0, 'sim': 1, 'real-calib': 2, 'real-verify': 3}

def provenance_ok(ledger, cert_deltas, verify_ids, calib_ids):
    if set(verify_ids) & set(calib_ids):
```

### IP-144 PCE++（双时钟：快环管检查 × 慢环评测）

```python
def probe_commit_evolve_plus_plus(x0, M, task, budget, consent, personas, health):
    route = plan_on_map(M, task, risk_model)
    while route.checkpoints:
        cp = route.next()

        inf = meta_few_shot_infer(M, cp.region, M.obs[cp.region], meta)

                    return safe_stop(cp, M, sigma, reason='exec_degrade')
                continue
            break

        g = select_gait(schedule_risk(sigma, M))
        ev = tag_evidence_p(sigma, M, contact_level(cp))
        if g != 'halt' and two_tier_gate(core_contact(cp), M, personas, ood_reg,
                                         health, eval_state, M.ledger)[0] == 'ok':
            commit(sigma, g); continue
        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, M)) != 'halt':
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| EFT | O(1)/控制步（分位预计算）；O(\|ℛ\|) 回退 | O(\|ℛ\|) 分层残差 | 共形覆盖 ≥1−α_exec、w 对 h 单调（A41） |
| EVX | O(1)/接触 | O(1) | 滑移双通道、健康单调（A41/A43） |
| REC | O(n) 流式；O(1) 内存（网格 e-value） | O(1) | anytime-valid、预注册冻结、分层（A42） |
| STE | O(1)/查询 | O(#κ) | real-verify 签名、出处不相交（A42） |
| EEG | O(\|σ\|) | O(\|σ\|) | 三见证缺一即拒、L2 加执行见证 |
| PCE++ | O(\|CP\|·(k_p+k_c)+T_c) | O(\|V\|+\|σ\|) | 快环 O(1)、双时钟单调、D_max 终止 |

**正确性定理（Realizable Audited Soundness, RAS）**
假设 A22–A32（第 53–55 轮）、A33–A36（第 56 轮）、A37–A40（第 57 轮）成立；**(A41)** 管校准：分层跟踪残差在 T 内覆盖 ≥1−α_exec，w 对控制器健康 h 单调不降，滑移残差即时入 ℛ；**(A42)** 评测有效：Π 预注册冻结，U_n 为任意停止下有效的失效率上界（Ville/测试鞅），verify 与 calib 样本出处不相交，且 verify 覆盖声明分层；**(A43)** 双时钟单调：慢环只收紧快环参数（θ_exec↑、corrob↑、gait_cap↓），降档只降低风险，健康退化只加宽管。则：

1. **执行健全性**：实际轨迹失效 ≤ 计划失效 δ_f + α_exec（管外逃逸）+ δ_slip；ρ_exec 校验使名义裕度不可被跟踪误差静默吃掉。
2. **评测有效性**：所报 δ̂ 在整段（可任意停止的）序贯检验上以 ≥1−α 覆盖真实失效率；点估计（0/N）不再被当作证书。
3. **出处不相交**：部署证书中的每个最终 δ 均带 real-verify 签名且与 calib 样本不交；任何仿真唯一来源的常数使证书降级为实验性。
4. **交互单调性强化**：执行见证、滑移负证据、评测收紧只能经 (a) 信念更准（管加宽）或 (b) 动作更保守（降档/停/佐证↑）影响系统，不存在升险路径；快环在任何慢环失败下都只向保守默认收敛。
5. **终止性**：每检查点探针 ≤k_probes+k_cons、降档 ≤D_max，PCE++ 终止于 {承诺, 绕行, L2 协商, 安全停}。
6. **部署界**（对检查点取联合界，且整条界仅在评测有效时成立）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1] + α_exec + δ_slip)
             − P(𝓜 陈旧未检出) − P(护盾回退失败) − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
             − 1[REC/STE 无效]
```

关键：**名义→管**把"计划安全"升级为"执行安全"（管是承诺的最小单位）；**仿真只当先验、真机才能签证书**（出处账本把"别用测试集调参"变成机器可查约束）；**anytime-valid 只报界**把评测从"仪式性通过"变成"可审计推断"；三者全部经"信念更准或动作更保守"两个安全通道起作用。

## 6. 本轮最大风险

**一句话**：本轮用"跟踪管"和"anytime-valid 评测"两把尺子丈量现实，但两把尺子都由同一批稀缺真机数据估计——一旦出处账本有泄漏（如仿真微调悄悄吸走验证集信息）、或地形非平稳超出管的分层交换性与评测分层假设，系统就会一边输出"认证有效"的置信界、一边让真实失效率漂到界外，最终认证的不是安全，而是**认证流程自身的自洽**；必须以出处不相交的机械校验、预注册冻结、滑移负证据即时加宽三者交叉验证，宁可把证书降级为"实验性"，也绝不把"流程通过"当成"现实安全"。
