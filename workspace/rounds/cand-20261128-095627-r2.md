### 第 6 轮灵感驱动研究记录（新循环第 2 轮，承接 CADVS-v5）

**灵感词**：能耗优化、谐波减速器

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）把框架从「规则系统」推广为「认证的生成式执行」（CGE）：条件流匹配提议器 FMPP、嵌入记忆与固化 LMEM-v2、面部情感调制 FAMK，并用定理 6（证书不变性/提议无关性）确立「提议可换、门不可换」，执行集 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。但 v5 的全部证书建立在一个**理想传动假设**上：关节指令力矩 = 实际输出力矩、指令位置 = 实际位置、能耗不是约束。本轮两个灵感词正好击穿这两个隐含假设：(a) 谐波减速器有回差（lost motion）、非线性扭转刚度与迟滞、随载荷/转速/温度变化的效率、力矩脉动、热与柔轮疲劳——「理想传动」在物理上不成立；(b) 能量是真实资源，续航与热/寿命约束会反过来限制可行轨迹，而 v5 完全没有能量维度。二者统一为主题「认证的传动-能量执行」（Certified Transmission-Energy Execution, CTEE），形成 CADVS-v6（IP-497~500）。本轮自律：**硬门仍为七**（延续 R52 负债控制），传动与能量都走「收紧既有门 + 提议塑形 + 软评分」三条非侵入通道；执行集升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ …，且能量无限（β=∞）且传动理想（ε=0）时精确退化 v5。

**直觉与动机**：

1. **谐波减速器 → 物理门第一次面对「传动级」非理想性；证书不是被放松，而是被「吃掉裕度」**。直觉上，v5 的末端门假设「发出 q 就到位 q」，但谐波减速器换向时有回差、受载时有扭转柔度、齿啮合有运动误差和力矩脉动；控制器以为的 0.8 mm 末端误差，真实可能是 1.5–2 mm。严谨做法不是把末端容差放宽（那会破坏 v5 保证），而是把传动误差做成**可证上界**并从既有裕度里扣除。定义每门的规范形 kc_i = 1[s_i(x) ≥ τ_i]（s_i 为越高越安全的裕度分）；HDTK 给出实际分数相对理想分数的偏差上界 |s_i^actual − s_i^ideal| ≤ ε_i^trans（末端门由回差 + 柔度 + 运动误差经雅可比传播，力门由效率下界 + 脉动上界，平衡门由关节力矩误差传播到 ZMP）。**定理 9（传动裕度转移）**：以 τ_i^6 = τ_i^5 + ε_i^trans 评估理想模型，即可保证真实传动下仍满足 v5 安全谓词；故 Exec_v6 ⊆ Exec_v5。关键点：传动模型越不确定，ε 越大，执行集越小——不确定性被转成保守性，而不是转成风险。

2. **能耗优化 → 能量不进信任边界，只做「提议目标 + 软评分 + 预算收紧」**。直觉上，能量最优轨迹倾向于贴着效率峰、贴着力矩/热/寿命边界跑；若把能量做成一个新的硬门，就等于新增一个不可验证的信任根（且违反不增门自律）。严谨做法是把能量拆成三条只缩不放的通道：(a) **提议塑形**：FMPP 条件里加能量-to-go 与效率映射，生成天生省能的候选，但候选仍须过七门；(b) **软评分**：ECS_v6 = ECS_v5·η_energy·η_trans，η ∈ (0,1] 只用于排序，不改变可行集；(c) **预算收紧**：剩余能量 β 低时 γ_E(β) ≥ 1，抬高既有门阈值（安全裕度、末端容差、价值门），β=∞ 时 γ_E=1。**定理 10（能量预算单调）**：β_2 ≤ β_1 ⇒ Exec_v6(β_2) ⊆ Exec_v6(β_1) ⊆ Exec_v5；预算无限时精确退化 v5。能量可行性本身并入既有**价值门**（kc_val^6 = kc_val^5 ∧ E_feas），不新增第八门。

3. **能量估计必须「悲观」：可行性的方向性决定估计误差必须单侧**。直觉上，如果能量-to-go 估低了，机器人会以为够用、跑到半路没电，这是 fail-open；估高了只会提前回充/降级，是 fail-safe。严谨地说，定义可采纳（admissible）估计 Ê_go ≥ E_go^true（用效率**下界**、负载**上界**、保守热模型积分），则预算谓词 E_feas = [Ê_go ≤ β_rem − E_reserve] 是**可靠**的：它通过 ⇒ 真实能量一定够。**定理 11（认证内能量最优选择）**：在已认证候选集 Exec_v6 内按 Ê_go 取最小者，不改变认证性（只是在可行集内重排），且所选点在采样候选集上对 (能量, 认证边际) 帕累托最优；可采纳性保证不会因估计误差放行不可行轨迹。

4. **热与疲劳：能量最优不能拿寿命换电费**。直觉上，短时能量最优可能用高力矩/高转速，导致发热和柔轮疲劳加速；省了一次电，换了一次减速器。严谨做法是 TLFK 维护热状态 T̂ 与累积损伤 D̂（Palmgren–Miner：D = Σ n_i/N_i(τ_i,ω_i,T_i)），并以**保守上界**把它们并入物理/价值门的收紧通道：T̂ ≤ T_max 且 D̂ ≤ D_max。**定理 12（热-疲劳有界累积与反套利）**：若 D̂ 是真实损伤上界，则能量最优选择不会使认证损伤超过 D_max，且加入能量优化只能重排、不能扩张 Exec_v6。诚实边界：S-N 曲线与 Miner 线性累积是经验模型，「有界」只相对于该模型成立。

**关键洞见**：v5 问「提议=任意生成器时证书边界能否不动」；v6 问「当传动本身不理想、能量是有限资源时，证书边界如何仍然成立」。答案是把**传动非理想性做成从既有裕度里扣除的可证误差预算**，把**能量做成只收紧的调制与只重排的软目标**，并让**能量估计单侧悲观**。七门原样保留；新增的只有传动误差预算 ε^trans、能量预算 β 与调制 γ_E、热/疲劳状态 (T̂, D̂)、软因子 η_energy/η_trans。放大的只能是「保真度与效率」，绝不能是「信任假设」。

**形式化目标（增量）**：
1. 传动状态 z=(q,q̇,τ,T̂,D̂,β_rem)；谐波参数 N, η_HD(τ,ω,T), K_t(τ), L_lm, r_rip, (C_th,R_th), S-N。
2. 传动误差上界 ε_i^trans（末端经 J 传播、力经效率下界 + 脉动、平衡经力矩误差），要求可证（区间/解析界），禁止用学习估计冒充。
3. 门规范形 kc_i=1[s_i≥τ_i]；τ_i^6=γ_E(β)·(τ_i^5+ε_i^trans)，γ_E≥1。
4. 能量：P_elec、E_go、可采纳估计 Ê_go≥E_go^true；E_feas 并入 kc_val。
5. 热/疲劳：T̂、D̂（Miner 上界）；并入物理/价值门收紧。
6. 定理 9（传动裕度转移）、定理 10（能量预算单调）、定理 11（认证内能量最优）、定理 12（热-疲劳有界）；引理 45（误差传播）、引理 46（可采纳能量界）。
7. EFA-v6 级联 + Exec_CADVS-v6={x∈supp(π_FM)∩S_energy: ∧_i kc_i(x,c;τ_i^6)=1} ⊆ Exec_CADVS-v5。

**本轮最大风险**：**传动-能量模型成为新的信任根**——谐波减速器的效率、刚度、回差、热与疲劳参数是有限数据辨识出来的，并随磨损、温度、润滑老化漂移；而能量优化恰恰把轨迹推向这些模型的效率/热/寿命边界（模型误差最敏感处），一个静默失真的传动模型会让「已认证」轨迹过热、加速磨损或超出末端容差。保守区间界 + 在线辨识 + 降额只能缓解，无法根除模型失配。

## 2. 关键算法骨架

### IP-497 HDTK：谐波传动保真核（控制环内 O(1) 查表，误差预算离线可证）

```python
@dataclass
class HarmonicDriveTransmissionKernel:
    """HDTK：谐波减速器传动保真 + 可证误差预算。
    定理 9：传动不确定性只从既有裕度里扣除，绝不放松任何门"""
    N: int
    eta_map: Any                 # η_HD(τ,ω,T) -> (eta_lo, eta_hi)，区间图
    K_t: Callable                # 非线性扭转刚度 K_t(τ)
    K_min: float                 # inf_τ K_t(τ)
    L_lm: float                  # 回差半宽（输出侧 rad）
    r_rip: float                 # 力矩脉动上界
    e_kin: float                 # 运动传动误差上界

    def joint_error_bound(self, q, qdot, tau) -> np.ndarray:
        """每关节输出角度误差上界：回差 + 柔度 + 运动误差 + 脉动等效"""
        return (self.L_lm + np.abs(tau) / self.K_min
                + self.e_kin + self.r_rip / self.K_min)

    def eps_ee(self, q, qdot, tau) -> float:
        """末端误差预算：一阶 ‖J‖·‖e_q‖ + 二阶 Hessian 余项上界"""
        e_q = self.joint_error_bound(q, qdot, tau)
        return (np.linalg.norm(self.jacobian(q), 2) * np.linalg.norm(e_q)
                + 0.5 * self.hessian_bound(q) * np.linalg.norm(e_q) ** 2)

    def worst_case_torque(self, tau_cmd) -> tuple[np.ndarray, np.ndarray]:
        """实际输出力矩区间：N·η_lo·τ − r_rip ≤ τ_out ≤ N·η_hi·τ + r_rip。
        力门必须用上界判过载、用下界判保持能力（重力/夹持）"""
        lo = self.N * self.eta_lo(tau_cmd) * tau_cmd - self.r_rip
        hi = self.N * self.eta_hi(tau_cmd) * tau_cmd + self.r_rip
        return lo, hi

        传播到 CoM 加速度，再由 ZMP 支撑多边形边际折算"""
```

### IP-498 EBOK：能量预算与优化核（能量积分在准入时域，不进 1 kHz 环）

```python
@dataclass
class EnergyBudgetOptimizationKernel:
    """EBOK：悲观能量核算 + 预算调制 + 能量条件化提议。
    定理 10/11：预算只收紧；能量估计必须可采纳（只高估，不可低估）"""
    motor: Any
    eta_lo: float = 0.55         # 全链路效率下界（电机×传动，保守）
    reserve_frac: float = 0.12   # 安全储备占满电比例
    beta_lo_frac: float = 0.25   # 低于此比例开始收紧
    kappa_E: float = 0.5         # 调制上限（保证 Δτ ≤ 0.1）

    def p_elec_upper(self, x, t, z) -> float:
        """电功率上界：机械功/效率下界 + 铜损上界 + 铁损上界"""
        tau_m, omega_m = self.motor_state(x, t)
        mech = abs(tau_m * omega_m) / self.eta_lo
        return mech + self.copper_loss_upper(tau_m) + self.iron_loss_upper(omega_m)

    def energy_to_go_upper(self, x, z) -> float:
        """可采纳估计 Ê_go ≥ E_go^true：效率下界 + 负载上界 + 保守热模型"""
        return integrate(lambda t: self.p_elec_upper(x, t, z), 0, x.T)

    def gamma_E(self, z) -> float:
        """预算越低收紧越多；β 充足时精确为 1（退化 v5）"""
        b = self.beta_lo_frac * z.beta_full
        r = (b - z.beta_rem) / b
        return 1.0 + self.kappa_E * clamp(r, 0.0, 1.0)      # ≥ 1 恒成立

    def energy_feasible(self, x, z) -> bool:
        """E_feas：用上界估计判可行 ⇒ 通过则真实一定够（fail-closed）"""
        return self.energy_to_go_upper(x, z) <= z.beta_rem - self.reserve_frac * z.beta_full

    def condition(self, c, z) -> Context:
        """能量条件化：把 β/效率/热/损伤作为流提议的额外条件 token"""
        return c.with_(beta_rem=z.beta_rem, eta_map=z.eta_map,
                       T_hat=z.T_hat, D_hat=z.D_hat)
    # 红线：能量只进提议目标、软评分、预算收紧与价值门合取；不新增硬门。
```

### IP-499 TLFK：热-疲劳寿命核（O(1) 状态更新，慢时域标定）

```python
@dataclass
class ThermalFatigueLifeKernel:
    """TLFK：热网络 + Miner 累积损伤（保守上界）。
    红线：能量最优不得以寿命为代价；T̂/D̂ 只收紧既有门"""
    C_th: float; R_th: float; T_amb: float
    T_max: float; T_derate: float
    sn_curve_lo: Callable        # N_i(τ,ω,T)：寿命下界（保守）
    D_max: float = 0.7
    f_res_band: tuple = (0.85, 1.15)   # 排除共振/脉动集中带（相对固有频率）

    def update_thermal(self, z, P_loss, dt) -> float:
        return z.T_hat + dt / self.C_th * (P_loss - (z.T_hat - self.T_amb) / self.R_th)

    def damage_increment_upper(self, tau, omega, T_hat, n_cycles) -> float:
        if in_band(omega, self.f_res_band):        # 共振带：按最坏寿命计
            return float('inf')
        return n_cycles / self.sn_curve_lo(tau, omega, T_hat)

    def derate(self, tau_max, T_hat) -> float:
        return tau_max * clamp((self.T_max - T_hat) / (self.T_max - self.T_derate), 0.0, 1.0)

    def damage_ok(self, x, z) -> bool:
        return z.D_hat + self.path_damage_upper(x, z) <= self.D_max
```

### IP-500 EFA-v6：七门不变 + 传动误差预算 + 能量/热/疲劳收紧

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：七硬门不变（阈值只紧）+ 传动保真 + 能量/寿命预算 + 级联"""
    hdtk: HarmonicDriveTransmissionKernel
    ebok: EnergyBudgetOptimizationKernel
    tlfk: ThermalFatigueLifeKernel
    v5: EvidenceForgingAssemblerV5          # 复用 scf/msrg/hic/eek/vack/bck 全套

    def select(self, x0_state, z, t_now, rule_id, context) -> tuple[bool, Trajectory | None, str]:
        eps = self.hdtk.eps_budget(z.q, z.qdot, z.tau)          # 传动误差预算
        g_e = self.ebok.gamma_E(z)                              # ≥ 1
        s_emo = self.v5.famk.observe(context.face, t_now)
        g_emo = self.v5.famk.gamma(s_emo)                       # ≥ 1
        tau6 = {i: g_e * g_emo[i] * (TAU5[i] + eps[i]) for i in GATES}   # 只紧
        c = self.ebok.condition(build_ctx(context, s_emo, self.v5.lmem), z)
        cands = self.v5.fmpp.propose(c, self.v5.fmpp.K)         # 能量条件化提议
        # 级联第 1 层：廉价门 + E_feas + 热/疲劳（O(1) 查表/积分）
        surv = [x for x in cands
                if self._cheap_gates(x, tau6)
                and self.ebok.energy_feasible(x, z)
                and self.tlfk.damage_ok(x, z)]
        if not surv:
            return self._fallback_rule_proposal(tau6)           # fail-closed 回退 v5 规则
        # 级联第 2 层：VACK（价值门并入 E_feas/D̂；末端用 ε_ee 收紧）
        surv.sort(key=self._prefilter_score, reverse=True)
        finals = []
        for x in surv[:3]:
            vac = self.v5.vack.evaluate(x, context_with(s_emo), t_now)
            if self.v5.vack.kc_val(vac, tau=tau6['val']):
                finals.append(x)
        # 级联第 3 层：BCK 用最坏实际力矩区间评估（效率下界+脉动上界）
        ok = [x for x in finals if self._bck_preview_worst_case(x, tau6, z)]
        if not ok:
            return False, None, 'ALL_CANDIDATES_REJECTED'
        best = min(ok, key=lambda x: self.ebok.energy_to_go_upper(x, z))  # 认证内能量最优
        return True, best, 'FORGED_CTEE'

    def ecs_v6(self, ..., e_go_hat: float, eps_norm: float, z) -> float:
        eta_energy = exp(-LAM_E * e_go_hat / max(z.beta_rem - E_RESERVE, 1e-6))
        eta_trans = exp(-LAM_T * eps_norm)
        return self.v5.ecs_v5(...) * eta_energy * eta_trans
```

## 4. 正确性论证（增量更新）

### 引理 45（传动误差传播界）

**陈述**：设串联机构第 j 关节输出角度误差满足 |Δq_j| ≤ e_j = L_lm,j + |τ_j|/K_min,j + e_kin,j + r_rip,j/K_min,j。则末端位置误差满足

‖Δp_ee‖ ≤ ‖J(q)‖₂·‖e‖ + ½·L_H·‖e‖² + O(‖e‖³)，

其中 L_H 为末端映射 Hessian 的范数上界。工程上取保守一阶式 ‖Δp_ee‖ ≤ Σ_j ‖J_j(q)‖·e_j。

**证明**：对 p_ee(q+Δq) 在 q 处 Taylor 展开，中值定理给出线性项，余项由 Hessian 有界给出。各关节误差独立取上界后三角不等式合并。∎

### 引理 46（可采纳能量界）

**陈述**：若对轨迹上所有 t 有 η_motor(t) ≥ η_lo、η_HD(t) ≥ η_lo，且负载力矩/转速取上界、热模型取保守参数，则按这些保守量积分的 Ê_go 满足 Ê_go ≥ E_go^true。

**证明**：P_elec = τ_mω_m/η + P_cu + P_fe，对 η 单调递减、对 |τ_mω_m| 单调递增；用下界替换 η、上界替换机械功与损耗，逐点放大后积分保序。∎

**推论**：以 Ê_go 判 E_feas 不会假接受（无「跑到半路没电」），只可能假拒绝（提前降级），即 fail-closed。

### 定理 9（传动裕度转移）

**陈述**：设七门取规范形 kc_i(x)=1[s_i(x) ≥ τ_i^5]，且 HDTK 给出可证界 |s_i^actual(x) − s_i^ideal(x)| ≤ ε_i^trans。若以 τ_i^6 = γ_E·(τ_i^5 + ε_i^trans)（γ_E≥1）在理想模型上评估通过，则真实传动下 s_i^actual ≥ τ_i^5，即 v5 各门仍成立。故 Exec_v6 ⊆ Exec_v5。

**证明**：通过 ⇒ s_i^ideal ≥ γ_E(τ_i^5+ε_i^trans) ≥ τ_i^5 + ε_i^trans；又 s_i^actual ≥ s_i^ideal − ε_i^trans ≥ τ_i^5。对七门取交集即得。∎

**工程含义**：传动越不确定（ε 越大）⇒ 阈值越高 ⇒ 执行集越小。不确定性被换成保守性，而不是风险。

### 定理 10（能量预算单调与精确退化）

**陈述**：γ_E(β) 关于 β_rem 单调不增，E_feas 关于 β_rem 单调（预算越多越容易通过）。因此 β_2 ≤ β_1 ⇒ Exec_v6(β_2) ⊆ Exec_v6(β_1) ⊆ Exec_v5。当 β=∞ 且 ε^trans=0 时 γ_E=1、E_feas≡1，Exec_v6 = Exec_v5。

**证明**：τ_i^6 随 γ_E 单调增 ⇒ 各门通过集单调缩；E_feas 随 β 单调。β=∞ 时 r≤0 ⇒ γ_E=1；ε=0 ⇒ τ^6=τ^5。∎

### 定理 11（认证内能量最优选择）

**陈述**：设选择算子 Sel(E)=argmin_{x∈E} Ê_go(x)。则 (i) Sel(E) ∈ E，认证性不变；(ii) 不存在 x'∈E 使 Ê_go(x')<Ê_go(Sel) 且认证边际 margin(x')>margin(Sel)，即在采样集上对 (能量, 边际) 帕累托；(iii) 若 Ê_go 可采纳，则 E_feas 不会接受真实不可行轨迹。

**证明**：(i)(ii) 由 argmin 定义；(iii) 由引理 46。∎

**注意**：能量最优是「认证集内的重排」，不是「为省能而放宽门」；软评分 η_energy 只影响排序，不影响 kc_i。

### 定理 12（热-疲劳有界累积与反套利）

**陈述**：若 D̂ 是真实 Miner 损伤的上界、T̂ 是真实温度的上界，且门要求 D̂≤D_max、T̂≤T_max，则真实损伤/温度不超过门限；在 Exec_v6 内做能量最优选择不会使认证损伤超过 D_max，也不会扩张 Exec_v6。

**证明**：上界性质 ⇒ 真实量 ≤ 估计量 ≤ 门限。能量选择是 Exec 内映射，且能量通道只收紧阈值/只重排，不放松任何 kc_i，故 Exec 不扩张。∎

**诚实边界**：S-N 曲线、Miner 线性累积、单节点热网络均为经验/简化模型；「有界」只相对于这些模型成立，模型失配不受定理保护。

### 定理 v6（传动-能量总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) 传动参数区间界成立、(B9) 能量估计可采纳下：
(i) Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29；
(ii) 传动不确定性单调：ε↑ ⇒ Exec_v6↓（定理 9）；
(iii) 能量预算单调：β↓ ⇒ Exec_v6↓；β=∞ 且 ε=0 精确退化 v5（定理 10）；
(iv) 认证内能量最优不改变认证性，可采纳估计无预算越界（定理 11）；
(v) 热/疲劳保守上界下累积不越限，能量优化不能以寿命套利（定理 12）；
(vi) 七锚 {3DCF, MSRG, HICK, EEK, LTEM, VACK, BCK} 不变；HDTK/EBOK/TLFK 是保真度/资源/寿命通道，非新锚。

**证明**：(i)(ii) 定理 9；(iii) 定理 10；(iv) 定理 11 + 引理 46；(v) 定理 12；(vi) 锚点集合不变 + 通道只紧（定理 9/10/12）。∎

**诚实声明**：(B8) 传动参数随磨损/温度/润滑老化漂移，区间界需在线辨识维持，失配时只能降额/停；(B9) 能量上界依赖负载/效率界的有效性，分布外负载可能破坏可采纳性；(iii) 疲劳/热模型经验性强；(iv) 低电量时执行集收缩可能导致任务不可完成（liveness 代价），需安全返航/停靠策略兜底。

| R67 | 能量优化与 v5 固化自指回路叠加（策略同时被能量目标与门塑形） | 高 | 能量只进提议/软评分；门与 τ^5 冻结；红队含「省能贴边」对抗集 | 复合 Goodhart 难完全排除 |

## 7. 本轮最大风险（最终确认）

**一句话**：**传动-能量模型成为新的信任根**——谐波减速器的效率、刚度、回差、热与疲劳参数由有限数据辨识并随磨损/温度/润滑老化漂移，而能量优化恰恰把轨迹推向这些模型的效率/热/寿命边界（误差最敏感处），一个静默失真的传动模型会让「已认证」轨迹过热、加速磨损或超出末端容差；保守区间界 + 在线辨识 + 降额只能缓解，无法根除模型失配。
