# 第 43 轮（新循环第 1 轮） · 从「听懂」到「证得」：把自然语言指令编译成可认证的鲁棒避障证书（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR 的 Sim-Cert-RAG 飞轮）。第 42 轮自陈最大风险是「仿真偏差累积 + 检索幻觉」。本轮灵感词「避障控制」「自然语言指令」不是再补一个模块，而是击中前两轮一直默认的隐含前提：**安全目标是被预先写死的几何守卫**。真实用户给的是人话——「从人群左边绕过去」「靠近货架时慢一点」「让叉车先走」——它开放、含歧义、带语用，而现有 CAR/LCS/CMC 只能认证几何距离，无法认证「我是否理解了你的意思」。本轮把自然语言指令拆成**任务意图**与**安全意图**双通道：任务意图仍走 R_φ(w)/规划，安全意图被编译成**指令参数化屏障 (IPA)**，在动态障碍下用**鲁棒时变 CBF** 认证；歧义用「证书分歧」主动询问消解，运行时用**意图符合性残差**守住语义。三者与 v19 飞轮对接：SCV 生成改写/动态体压力测试，CKB 存「指令-证书-修正」对，ECR 执行轻量语义监控。

## 0. 直觉与动机

**灵感 1（避障控制 → 语言与物理的唯一公共变量是「裕度」）**：避障不是往规划器后面串一个避障层，而是让**语言直接落到屏障参数上**。几何避障的天然接口是带符号距离 d(x, O) 与安全半径 r；语言里的「近/远/慢/让/贴左/绕后」恰好可以映射为附加裕度 m、速度上限 v_max、让行谓词 yield、侧向符号约束 s(x)。于是「理解指令」不再是产出一段文本计划，而是产出一组**带参数的屏障原子并证明其可满足**。动态障碍再引入预测占据 Ô_i(t) 与 δ-可达不确定集 U_i(t)，用把 U_i 膨胀进屏障的鲁棒时变 CBF 把「预测会错」变成可计算的安全余量，而不是祈祷预测器准。

**灵感 2（自然语言指令 → 安全意图必须进入证书，否则是语义静默失效）**：VLM/LLM 能把「绕过施工区」变成目标点，但它不承担安全承诺。直觉上要**双通道**：任务通道回答「去哪、做什么」，安全通道回答「以多大裕度、遵守什么让行/侧向/时序约束」。后者被编译为**安全意图图 (SIG)**，每个节点/边对应一个屏障原子；同一句话采样多个 grounding，每个都尝试合成证书。**能证出来**的才是可执行解释；证不出来的解释不是「保守」，而是「没听懂」。不同解释若在可达集上导出的安全动作集不同，就触发**主动消歧**——问题从「分歧最大处」生成，比如「您说的左边，是货架的左侧还是您的左侧？」这比让 LLM 自问自答更可审计。

**灵感 3（修正与经验 → 语言修正即约束更新，接回 v19 飞轮）**：用户最自然的交互是纠正——「太近了」「别从那边走」「刚才那样就很好」。把修正编译成对 margin / 侧向符号 / 让行阈值的**约束**，用投影做增量标定；硬安全原子只允许向更保守方向更新，软偏好可双向收敛。每条 `(指令签名, grounding, 证书参数, 修正)` 写入 CKB，下一次相似指令直接热启动；SCV 对同一语义的多种改写做「改写不变性」压力测试，ECR 则把意图谓词编译成与 L0/L1 同级的轻量监控。

**闭环**：NL 指令 → NBC 编译出 IPA 与意图监控 → RAC 在动态障碍下认证鲁棒避障 → ICR 在边缘同时守几何边际与意图残差 → 修正/分歧回写 CKB、触发 SCV 改写与动态体测试。证书从「几何安全」升级为「几何 × 语义」双重可证。

## 1. 形式化定义（增量：定义 38–43）

**定义 38（自然语言指令的双通道语义）**：编译映射 Γ 把指令 w ∈ W 映射为二元组 (T_w, G_w)。**任务意图** T_w 为时序目标（LTL/STL 片段，供规划器使用）；**安全意图图** G_w = (E, R, M, Σ)：E 为经语义地图 C_ms 实体链接后的对象类/实例集合；R ⊆ E×E×{avoid, keep-left, keep-right, yield, follow, pass-behind, maintain-distance} 为关系；M 为修饰集合 {附加裕度 m_j, 速度上限 v_max, 时序模态 always/until/eventually, 紧迫度}；Σ: R→{hard, soft} 为优先级（「绝不/必须」为 hard，「尽量/稍微」为 soft）。Γ(w) 输出候选 groundings 的分布 {g_1,…,g_K}，每个 grounding 对应一个原子集 A(g)。

**定义 39（指令参数化屏障 IPA 与可行 groundability）**：对 grounding g，定义向量屏障 h_g(x,t) = [h_1,…,h_l]，每个原子
h_j(x,t) = κ_j·(d_j^rob(x,t) − r_j − m_j(g)) + (1−κ_j)·s_j(x; g)，
其中 d_j^rob 为鲁棒距离（定义 41），r_j 为物理半径，m_j 由语言修饰给出，s_j 编码侧向/让行等语义场，κ_j∈[0,1] 平衡几何与语义。**指令条件安全集** C_g = {x : h_g(x,t) ≥ 0 ∀j}；**安全动作集** A_g(x) = {u∈U : h_g(x_{k+1},t+Δt) ≥ (1−α) h_g(x_k,t) ∀j}，α∈(0,1]。称指令在可达集 X_R 上**可行可证 (feasibly groundable)**，当且仅当 A_g(x)≠∅ ∀x∈X_R，或存在保底制动回退使系统进入 C_g 内的不变集。

**定义 40（证书分歧与主动消歧）**：对候选 g_i, g_j，定义动作分歧
D(g_i,g_j;x) = Hausdorff( Proj_U A_{g_i}(x), Proj_U A_{g_j}(x) )，
并在 X_R 上取 D_∞ = sup_x D。若 D_∞ = 0 则称二者**行为等价**；若 D_∞ > τ_div 则称 w 在 (g_i,g_j) 上**歧义**。消歧问题 q 从分歧原子的类型/参数边界生成（如侧向符号、实体指代、让行对象），选择使「期望分歧削减 / 交互成本」最大者。若用户拒绝或超时，则选 g* = argmax_g min_{x∈X_R} h_g(x)（最大最小可证鲁棒性），并把相关原子降级为 soft、在证书中显式标记「未确认语义」。

**定义 41（预测不确定性下的鲁棒时变避障证书）**：动态障碍 i 的预测占据为 Ô_i(t)，预测误差满足 ‖e‖ ≤ ρ_i(t) 的概率 ≥ 1−δ（ρ_i 由 conformal prediction 或 δ-可达集给出）。真实占据 O_i(t) ⊆ Ô_i(t) ⊕ U_i(t)，U_i(t) = {e : ‖e‖ ≤ ρ_i(t)}。定义鲁棒距离与屏障
d_i^rob(x,t) = dist(x, Ô_i(t) ⊕ U_i(t)),  h_i^rob(x,t) = d_i^rob(x,t) − r_i − m_i。
**避障证书** C_avoid = (h^rob, α, {ρ_i}, H_p, τ_replan, fallback)。若在每个重规划时刻鲁棒 CBF 条件成立、且区间内预测误差不超过 ρ_i，则闭环轨迹满足 P(与 i 碰撞) ≤ δ；若 QP 不可行则触发保底制动进入安全集。

**定义 42（意图符合性残差与运行时契约）**：从 G_w 抽取可监控谓词 P_w = {p_1,…,p_l}（如「从右侧通过」「对行人让行」「与货架距离 ≥ d_min」「不在人群密集区停留」）。对轨迹前缀 ξ_{0:t}，意图残差
ε(ξ,t) = max_{p∈P_w} violation_p(ξ_{0:t}) / scale_p ∈ [0,1]。
运行时证书契约为：控制量 u_t 可执行，当且仅当 (几何边际 m_lo ≥ θ) ∧ (ε ≤ ε_max)。任一条件失败即进入 Degraded；ε 持续超限进入 Clarify/SafeStop。**命题**：若所有谓词监控是 sound 的（不把违反判成满足），则 ε ≤ ε_max 蕴含轨迹在所有已形式化语义上符合指令。

**定义 43（语言修正到约束的增量标定）**：语言修正 c（「太近了」「从左边绕」「刚才那样好」）经编译器映射为对参数向量 θ = (m_j, v_max, yield_thr, sign_j) 的线性/半空间约束 C_c。更新为约束投影
θ_{k+1} = Π_{C_c ∩ C_hard}(θ_k + η_k ∇L_task)，
其中 C_hard 为物理安全下界（硬原子裕度不得低于认证安全值，且只允许向更保守方向移动）。软原子可在可行域内双向调节。每条记录 `(sig(w), g, θ, c)` 写入 CKB；在约束为凸、步长满足 ∑η_k < ∞ 时，软参数收敛到可行集，硬安全不退化。

## 2. 新增与升级 IP

### 2.1 IP-57 NL-BARRIER COMPILER（NBC，指令-屏障编译器）
1. **受限语义解析**：LLM 只在给定类型文法（实体/关系/修饰/优先级）内产出 SIG，输出经 schema 校验；实体必须链接到 C_ms 的实例，链接失败即进入 Clarify，不允许「猜一个相似实体」。
2. **原子编译与参数模板**：关系/修饰 → 屏障原子模板（距离、侧向符号、让行时序、速度上限）；参数先由 CKB 检索相似指令热启动，再由 RAC 证书可行性回灌。
3. **多候选落地**：Top-K groundings 并行做采样点 CBF-QP 可行性检查；只保留可证候选，记录各自最小裕度。
4. **证书分歧与主动消歧**：按定义 40 计算候选对分歧，生成最小区分性问题；用户确认后锁定 grounding 并生成版本化证书。
5. **拒绝而非硬编造**：若所有候选都不可证，输出「该指令在当前场景不可安全执行」并给出最接近的可行替代（如「在人群外等待直到出现通道」）。

### 2.2 IP-58 ROBUST-AVOIDANCE-CERTIFIER（RAC，鲁棒避障证书器）
1. **预测 + 不确定集**：短期用常速度/交互式预测，误差用 conformal 分位数给出 ρ_i(t)；对高动态体切换为保守 δ-可达集。
2. **鲁棒时变 CBF-QP**：硬原子无松弛变量，软意图可加松弛并计入代价；非凸障碍用多屏障取 min，或在切平面局部线性化后用多约束表示。
3. **递归可行性与回退**：显式维护制动不变集；当 QP 不可行，立即执行 fallback（制动/让行/原地等待），并把不可行场景作为反例送入 SCV。
4. **证书内容**：h^rob 参数、α、ρ_i、预测视界 H_p、重规划周期 τ_replan、回退策略，全部随证书版本化。

### 2.3 IP-59 INTENT-CONFORMANCE-RUNTIME（ICR，意图符合性运行时）
1. **谓词编译**：P_w 编译成有限状态监控 + 阈值比较；与 L0 查表共用 intent_id，避免重复解析。
2. **双残差监控**：每拍同时输出几何边际 m_lo（IP-56 L0/L1）与意图残差 ε；总 WCET 目标 < 50μs。
3. **澄清对话管理**：问题数硬上限（默认 2 个/歧义指令），超限即选最大最小鲁棒 grounding 并标注「未确认」。
4. **修正摄取**：语言修正 → 约束投影 → 证书增量更新 → 经 IP-45 广播热更新；硬安全参数变更需人工确认。

## 3. 四层架构 v8

```
L1: TRI-FUSE(INT8) + IP-49 LIO(定点) → C_ms + 漂移界 B_t + 语义带符号距离场 SSDF
L2: CTC/VLM → 双通道 (T_w, G_w) + IP-35 仲裁(意图符合性维度) → 候选 groundings {g_i}
L3: IP-57 NBC(实体链接/SIG/原子编译/分歧消歧) → IPA 参数
    → IP-58 RAC(鲁棒时变 CBF-QP + 预测不确定集 + 制动回退) → 避障证书 C_avoid
    → IP-39 规划(margin=鲁棒屏障, 语言裕度入约束) → IP-45 总线(意图/澄清/飞轮心跳)
    → IP-51 CAR(Grounding/Clarify/Degraded) ← IP-56 ECR(L0 查表 + L1 INT8 + IP-59 ICR 双残差)
L4: IP-55 CKB(指令-证书-修正检索) ← IP-54 SCV(改写不变性 + 动态体压力测试 + 反例归因)
    → IP-44 蒸馏 + IP-53 CMC(谓词→监控电路) + IP-50 课程(语言复杂度阶梯)
    → RCA 重颁证书(几何+语义双契约) → 契约热更新
运行期：L0 查表(5μs) + L1 几何边际(100μs) + 意图残差(<50μs) → 任一失败降级 → 修正/偏移回写飞轮
```

## 4. 实验设计（E87–E94 硬门槛，承接 E79–E86）

| E94 冲突指令处理 | 冲突检测率；冲突时安全行为比例；不安全事件 | ≥95%；100% 询问/等待/停车；0 起 |

回退：E87 可证率不足 → 收紧指令文法、把复杂指令拆成可确认子句；E88 改写不一致 → 关闭开放改写、改受限模板并强制确认；E89 预测不确定性失效 → 提高 ρ_i 至 δ-可达集并降速，仍失败则只走保守制动；E90 提问过载 → 降级为默认最大最小 grounding + 明示未确认；E91 超预算 → 只保留几何边际与一个硬意图谓词；E92 修正过拟合 → 冻结软参数、仅保留硬安全；E93/E94 不达标 → 退化为「受限指令集 + 人工确认」模式。

## 5. 本轮最大风险

**一句话**：最大的新失效链是**语义-安全错配**——LLM 把指代/侧向/让行对象理解错，却仍能合成一份数学上自洽的证书，运行时几何边际与意图监控都「通过」，系统就在「证得漂亮、做得错」中静默违背人的意思；因此 E88（改写不变性）与 E90（分歧消歧）必须作为红线，任何未确认 grounding 只能以显式降级/询问执行。

# 第 43 轮产物 · 创新点清单 v20：指令-屏障编译器（NBC）× 鲁棒避障证书（RAC）× 意图符合性运行时（ICR）（四层架构 v8）

> 承接第 42 轮产物 v19（SCV × CKB × ECR）。本轮**增量插入** IP-57/58/59，并升级 IP-31/35/39/47/49/50/51/52/53/54/55/56；不推倒任何既有层级。核心是把 v19 的「几何可证 + 仿真进化」升级为「**语言可证**：自然语言指令 → 安全意图图 → 参数化屏障 → 鲁棒时变避障证书 → 运行时意图符合性」的双通道证书体系。

## 0. 核心 IP 设计

| 编号 | 名称 | 类型 | 关键改进 |

### IP-57 NBC：指令 → 意图图 → 可证屏障
```
def compile_instruction_to_barrier(w, C_ms, KB, budget_qp=64):
    # 1. 受限文法解析：LLM 只填槽位，schema 校验，实体必须链接到实例
    sig_raw = llm_parse_in_grammar(w, schema=SIG_SCHEMA)
    G_w = link_entities(sig_raw, C_ms)          # 链接失败 -> 返回 Clarify
    if G_w.unlinked: return NeedClarify(G_w.unlinked)

    # 2. 任务/安全双通道
    T_w = goal_from_sig(G_w)                    # 供 IP-39 规划
    atoms = [atom_from(r, m, sigma) for r, m in G_w.R, G_w.M]

    # 3. 多候选 grounding：热启动参数来自 CKB 相似指令
    cands = []
    for g in sample_groundings(G_w, K=5):
        theta0 = KB.retrieve_params(sig(w), g)  # 无则用模板默认
        g = calibrate_margins(g, theta0)
        feas, margin = check_qp_feasible(g, atoms, samples(X_R), budget_qp)
        cands.append((g, feas, margin))
    cands = [c for c in cands if c.feas]
    if not cands:
        return RejectWithAlternatives(w, nearest_feasible(w, KB))

    # 4. 证书分歧与主动消歧
    while len(cands) > 1:
        pairs = [(a, b) for a, b in combinations(cands, 2)
                 if D_inf(a.g, b.g) > tau_div]
        if not pairs: break
        q = pick_question(pairs)                # 最大化分歧削减/交互成本
        if questions_asked >= Q_MAX or user_declines(q):
            break
        ans = ask_user(q); cands = filter_by_answer(cands, q, ans)

    g_star = argmax_min_margin(cands)           # 最大最小可证鲁棒性
    intent_spec = compile_predicates(G_w, g_star)  # -> IP-59
    cert = synthesize_certificate(g_star, atoms, C_avoid)
    return GroundedInstruction(T_w, g_star, cert, intent_spec,
                               confirmed=conviction(cands))
```

### IP-58 RAC：预测不确定集 + 鲁棒时变 CBF-QP
```
def robust_avoidance_certificate(x, obstacles, predictor, delta=0.01):
    # 1. 预测 + δ-不确定集（conformal / 可达集）
    preds = []
    for i in obstacles:
        traj = predictor.predict(i, horizon=H_p)
        rho = conformal_quantile(i, delta)      # 或 delta-可达集半径
        preds.append((traj, rho))

    # 2. 鲁棒屏障（膨胀占据）
    h = []
    for i, (traj, rho) in enumerate(preds):
        for k in range(H_p):
            O_hat = traj[k]
            h.append(Barrier(
                d=lambda x, t: dist(x, inflate(O_hat, rho[k])),
                r=obstacles[i].radius, m=lang_margin(obstacles[i]),
                hard=True))

    # 3. 时变 CBF-QP：硬约束无松弛，软意图可松弛并计代价
    def solve(xk):
        u = argmin  ||u - u_task||^2 + lambda * sum(slack_soft)
        s.t.  for hj in hard:
                hj(xk, u, dt) >= (1 - alpha) * hj(xk)     # 无 slack
              for hj in soft:
                hj(xk, u, dt) >= (1 - alpha) * hj(xk) - slack
              u in U,  v <= v_max(lang)
        return u
    try:
        u = solve(x)
        return Certificate(h, alpha, [r for _, r in preds], H_p,
                           tau_replan, fallback=BRAKE)
    except QPInfeasible:
        return FallbackCertificate(BRAKE)       # 保底进制动不变集
```

### IP-59 ICR：意图残差与修正学习
```
def intent_residual_monitor(xi_prefix, intent_spec):
    eps = 0.0
    for p in intent_spec.predicates:
        v = p.violation(xi_prefix) / p.scale    # FSM + 阈值比较
        eps = max(eps, v)
    return eps                                   # <= eps_max 才算符合

def runtime_contract(x, xi_prefix, cert, monitor):
    m_lo = cert_lookup_L0(x).m_lo                # IP-56 几何边际
    eps = intent_residual_monitor(xi_prefix, monitor)
    if m_lo >= cert.theta and eps <= monitor.eps_max:
        return OK
    if m_lo < cert.theta:
        return Degraded(geometric=True)
    return Degraded(intent=True, need_clarify=(eps > 2 * monitor.eps_max))

def ingest_correction(c, sig, cert, C_hard):
    # 语言修正 -> 线性/半空间约束 C_c
    C_c = compile_correction(c)                  # e.g. m_person += 0.3
    theta_new = project(theta, C_c & C_hard)     # 硬安全只向保守方向
    cert.update(theta_new)
    KB.insert(sig, cert.grounding, theta_new, c)
    bus.publish('cert_update', cert.version)     # IP-45 热更新
    return cert
```

## 3. 关键推导

### 3.1 预测误差如何变成可证安全余量
设真实障碍占据 O_i(t)，预测占据 Ô_i(t)，误差 ‖e‖ ≤ ρ_i(t) 的概率至少 1−δ，即 O_i(t) ⊆ Ô_i(t) ⊕ B(ρ_i)。对任意 x：
dist(x, O_i) ≥ dist(x, Ô_i ⊕ B(ρ_i)) = d_i^rob(x,t)。
若控制器在每个重规划时刻满足鲁棒 CBF 条件
h_i^rob(x_{k+1},t+Δt) ≥ (1−α)h_i^rob(x_k,t)，且 h_i^rob(x_0) ≥ 0，
则 h_i^rob(x_k) ≥ 0 ∀k，从而 dist(x_k, O_i) ≥ r_i + m_i − ρ_i。
于是**只有当预测误差超过 ρ_i 时才可能侵入物理半径**，其概率 ≤ δ。故
P(碰撞) ≤ δ，且物理最小间距 ≥ r_i + m_i − ρ_i。这给出一个可直接写进证书的**保守裕度回收**：ρ_i 越紧（预测器越好），越能在语言要求的「离人远一点」下保持可行，而不是一味停车。

### 3.2 改写不变性与语义稳定
若同一语义的两个改写 w, w' 被编译为同一原子集且参数满足 ‖θ_w − θ_{w'}‖ ≤ ε_m、屏障对参数 Lipschitz 连续（常数 L_θ），则
‖h_{g_w} − h_{g_{w'}}‖_∞ ≤ L_θ·ε_m。
取 ε_m ≤ τ_div / L_θ，则二者在 X_R 上的动作分歧 D_∞ < τ_div，判定为行为等价。**命题**：改写不变性可由「原子集一致 + 参数聚簇」充分保证；这为 E88 提供了可检验的判据，而不是只靠端到端成功率。

### 3.3 主动消歧的信息收益
把候选 grounding 的分歧对视为待消除的不确定性。问题 q 把候选集划分为两个子集，其最大组占比 p_q；问一次问题后期望候选熵下降至少 1−max(p_q, 1−p_q)。选择 q* = argmax_q (H_before − H_after)/cost(q) 即在有限提问预算 Q_MAX 下最大化语义确定性。若预算耗尽，退化为最大最小鲁棒 grounding，并把未消除分歧显式写进证书（`confirmed=False`），由 CAR 进入 Clarify。

## 7. 本轮最大风险

**一句话**：最大的新失效链是**语义-安全错配**——指代/侧向/让行对象被理解错，却仍合成出一份数学自洽的证书，几何边际与意图监控同时「通过」，系统在「证得漂亮、做得错」中静默违背人的意思；因此 E88（改写不变性）与 E90（分歧消歧）必须作为红线，任何未确认 grounding 只能显式询问或降级执行。
