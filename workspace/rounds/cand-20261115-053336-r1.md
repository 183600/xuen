# 第 4 轮（灵感循环第 4 轮；本轮灵感：「视觉问答」×「群体智能」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。视觉问答与群体智能都只升级「证据获取」这一条轴，且必须能逐级退回：SwarmGauge → AQ-InstructGauge → InstructGauge → ToolGauge → LeanGauge → MODGAUGE。

## 0. 直觉与动机

**灵感 1（视觉问答 → 把「问什么」变成主动探测，把「答什么」降级为可采纳证据）**
直觉：VQA 真正有用的地方不是「看图说话」，而是**用问题指定当前缺失的证据**。盲区修复时，工程师问的是「左侧支架的高光是否让深度饱和？」，而不是「描述这张图」。所以在计量闭环里，VQA 的正确角色是**主动提问器**：问题必须是类型化、可执行探测计划的一部分，答案必须绑定到它引用的像素区域。VQA 的两个经典病灶——语言先验捷径（不看图也能答）与答案幻觉——恰好对应两条硬门：**反事实遮挡检验**（遮住它声称依据的区域，答案必须改变）与**校准化弃答**（置信不足就 ⊥，绝不允许「猜一个」）。一句话：VQA 只回答「该看哪里、看到什么」，不回答「该做什么」。

**灵感 2（群体智能 → 用独立性与合票换鲁棒，而不是用数量换置信）**
直觉：群体智能的力量来自**大量廉价、局部、可失败**的个体与信息素式共享，而非某个全知中心；它对个体故障鲁棒，是因为个体错误被局部规则与冗余稀释。但群体也有阴暗面：**共识幻觉**。N 个智能体如果共享同一个模型、同一路训练数据、同一个视角，它们的「一致」只是同一个错误的 N 次复制——投票数上去了，有效独立信息没变。因此群体智能进入计量闭环的正确姿势不是「平均所有回答」，而是**先证明独立性、再合票**：同源证据合并为一票（克隆不增益），达到独立类数下限与票差才接受，否则弃答并补问。

**灵感 3（两者耦合 → 集体视觉提问，危险在「相关证据的伪多数」）**
直觉：VQA 定义「问什么」，群体定义「谁来答、信几票」。最危险的耦合是：一句被所有智能体共享的语言先验 + 同一路视觉骨干 + 同一个视角 = 所有回答高度一致却没有一个真正看了目标区域；再叠加第 3 轮的动作分块，一次被「群体背书」的错误接地就会被原子性地执行成 K 步。解法是给证据本身加一层**可采纳性**：答案必须区域接地（遮挡会变）、必须溯源独立（同源只算一票）、必须新鲜（不能跨过块时域），且**物理回执永远压过视觉回答与群体票数**（receipt dominance）。视觉与群体只改证据权重，不改能力、不改安全约束。

## 1. 研究问题（本轮要回答什么）

- **Q1（答案的可采纳性）**：如何让 VQA 答案成为可审计证据，而不是语言先验/幻觉进入数值路径的新入口？
- **Q2（群体的有效性）**：在什么独立性条件下，多个智能体的共识比单智能体更可信？相关误差与拜占庭个体如何把「多数」变成「伪多数」？
- **Q3（与第 3 轮的接口）**：集体证据的获取延迟、新鲜度与置信度，如何与指令接地熵和块长 K 耦合？什么时候它允许更长的块，什么时候必须强制 K=1？

## 2. 三条设计原则（雏形，正式化见产物区定义 448–463）

**P4 证据可采纳性（Admissibility over Authority）**
任何视觉回答或同伴投票，只有同时通过类型闭包、区域接地、反事实遮挡、校准阈值与新鲜度检查，才是「证据」；否则一律 ⊥。**没有来源因为「模型更大」或「智能体更多」而自动获得权威**。

**P5 克隆不增益（Clone No-Gain）**
按溯源签名（模型族、数据血统、视角簇、校准层）合并同源证据，每个独立类只投一票；用有效独立类数 `C_eff`（而非原始个体数 C）计算共识。N 个克隆智能体不得提高置信度，只能提高延迟。

**P6 回执优先（Receipt Dominance）**
物理回执严格支配 VQA 答案与群体票数：冲突时冻结动作、补测或弃答，绝不用视觉共识覆盖回执。证据优先级 `receipts ≻_ev calibrated visual evidence ≻_ev language/anecdote`。

## 3. 与基线的接口（如何退化）

- 无 VQA / 全部答案弃答 / 遮挡检验失败 ⇒ 提问集为空，后验不变 ⇒ 精确退回 InstructGauge；
- 独立类数 `C_eff < K_min`、票差 `< m_cons`、或独立性不可证 ⇒ 只用单智能体 AQ 证据（AQ-InstructGauge），再不可用 ⇒ InstructGauge；
- 证据过期 `Δ_e > H_c` / 与回执冲突 / 跨不可逆屏障 ⇒ 强制 `K=1` 或走原 CVC 截断，等价于 ToolGauge 逐步执行；
- VQA 与群体层整体关闭 ⇒ InstructGauge ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个「答案即证据、问题即探测」的主动视觉提问口径，用反事实遮挡 + 校准弃答把 VQA 的语言先验捷径压到可拒绝；
2. 一个以**溯源独立性与有效独立类数**为核心的群体共识，证明「克隆不增益」，并把相关误差/拜占庭个体纳入可证伪的合票规则；
3. 一个证据-块时域耦合条件：给出集体证据在什么新鲜度/置信度下才允许放大块长，否则退化 K=1；
4. 一条完整可证伪路径：E457–E474 覆盖遮挡接地、提问信息增益、相关误差、拜占庭共识、信息素投毒、分层覆盖、回执冲突与 50Hz 时序。

## 5. 本轮最大风险

**一句话**：最大的残余风险不是单个 VQA 答错，而是**所有智能体共享同一个错误视觉先验/同一路数据血统**，于是 N 个回答只是一个独立类的 N 次重复——克隆投票把置信度抬高却不增加信息，再叠加长块，把一次被「群体背书」的接地错误原子性地执行成 K 步物理动作。

# 第 4 轮产物 · 创新点清单 v4：**SwarmGauge**（Collective Visual-Questioning Metrology）

> 背景：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）；第 2 轮 ToolGauge；第 1 轮 LeanGauge / MODGAUGE 骨架不变。
> 本轮灵感：「视觉问答」×「群体智能」
> **继承纪律**：MODGAUGE 五不变式、4CV 骨架、ToolGauge-6C、InstructGauge-7C 与全部退化链保留。新增组件一律为**可选证据增强**：SwarmGauge → AQ-InstructGauge → InstructGauge → ToolGauge → LeanGauge → MODGAUGE。

**设计直觉（一句话）**：本轮不新增任何控制能力，只新增「证据准入」——VQA 的答案与同伴的投票都只能改变假设后验，且必须先证明「真的看了」与「真的独立」，否则一律弃答退回第 3 轮。

## 2. 形式化定义（要点）

**定义 448（问答能力闭包 CC_A）** `Γ_A: (s,H,E) → (q,A,⊥)`，其中 `q ∈ Q_onto`、`A ∈ A_onto`，二者均为类型化白名单。答案只能通过似然 `L(H;e)` 重加权后验，公理：
`tools(ι⊕A) ⊆ tools(ι)`、`mag(ι⊕A) ⊆ mag(ι)`、`∄ free-text(A) → actuator`。
任意越界问题/答案（新工具、超包线幅值、自由文本直达执行器）⇒ 输出 ⊥。这是第 3 轮 CC 在「感知侧」的对偶：**语言与视觉都不能扩权，只能改证据**。

**定义 449（证据单元与可采纳性 Adm）** `e = (q,A,R,π_e,κ,τ,prov)`，其中 `R` 为答案引用的区域掩码。可采纳性
`Adm(e) ⇔ type(q,A) ∧ R≠∅ ∧ R⊆ROI(s) ∧ π_e ≥ q_{s(e)} ∧ Δ_occ(e) ≥ δ_occ ∧ (t−τ) ≤ H_e ∧ prov 可重放`。
任一失败 ⇒ **丢弃**，而不是降权。理由：未接地证据即使给很小权重，也会在长块内被反复累积；「垃圾进、低权重出」比显式弃答更难审计。

**定义 450（视觉充分性 / 反事实遮挡）** 令 `I⊙(1−R)` 为遮住引用区域后的图像，
`Δ_occ(e) = D( A(q,I), A(q, I⊙(1−R)) )`，
`D` 在分类答案上取 0-1 距离、在数值答案上取归一化绝对差。要求 `Δ_occ(e) ≥ δ_occ > 0`。仅依赖语言先验的答案对任意 `R` 都有 `Δ_occ=0`，故被拒绝。注意：遮挡敏感是**必要非充分**条件——答案可能依赖错误区域；因此仍需 `π_e` 的共形校准与独立性合票（定义 452–455）。

**定义 451（主动提问目标与停止）**
`q* = argmax_{q ∈ Q_adm(s)} [ IG(q) − λ_Q·c(q) ]`，
`IG(q) = H(H|E) − E_{A_q}[ H(H | E, A_q) ]`。
`Q_adm(s)` 只含可执行、可遮挡、预算内的问题；`c(q)` 含视角运动与 VQA 前向代价。停止条件：`H(H|E) ≤ ε_H ∨ |E| ≥ B_Q ∨ max IG < g_min`。冷启动无法估计 IG 时退到固定信息序：先安全攸关槽位，再属性，再关系。

**定义 452（溯源签名与独立证书）**
`κ(e) = Hash(model_family, data_lineage, view_cluster, cal_stratum)`；
`Indep(e,e') ⇔ κ(e)≠κ(e') ∧ ρ̂_{e,e'} ≤ ρ_max`，`ρ̂` 为探针集上残差的相关估计。
**不能证明独立 ⇒ 视为相关**（保守默认）。这条把「独立」从口号变成可检查、可证伪的证书。

**定义 453（合票与有效独立类数）**
同 `κ` 的证据合并为一类，类权重 `w_κ` 取该类最大可采纳证据的校准对数几率。对 `C` 个类、类间平均残差相关 `ρ̄`，有效独立类数
`C_eff = C / (1 + (C−1)·ρ̄)`（Kish 设计效应）。
共识一律用 `C_eff` 而非 `C`：`ρ̄=1` 时 `C_eff=1`，克隆不增益；`ρ̄=0` 时 `C_eff=C`。

**定义 454（共识门 G_cons）** 票数 `V(h) = Σ_{κ: e_κ ⊨ h} w_κ`。接受 `h*` 当且仅当
`V(h*) − V(h₂) ≥ m_cons` 且 `C_eff ≥ K_min` 且 `C_eff ≥ 2f+1`；
否则 ABSTAIN。多数门槛 `Q = ⌊C_eff/2⌋ + 1`。**离散/不可逆槽位要求更保守的 `m_cons`**，且任何共识都不能替代回执（定义 459）。

**定义 455（群体分层共形 SQ-Cal）** 分层 `s = (问题类型, 智能体簇)`。层内阈值 `q_s` 取校准集残差的经验分位，使 `P(A 正确 | s) ≥ 1−α`。低样本层 `n_s < n_min` 时向父层收缩：
`q_s ← (n_s·q_s + n_0·q_0)/(n_s + n_0)`，
并给出层内覆盖与边缘覆盖的 TV 退化界。注意校准样本数也必须按**独立单元**计：相关样本的有效样本量是 `n_s/C_eff`。

**定义 456（信息素黑板与溯源）** 黑板 `ℬ` 存储 `(e, τ, prov, κ)`；读取权重 `γ^{t−τ}`；写入不可变、可重放；当 `γ^{t−τ} < ε_ℬ` 时回收。读端只接受能由 `prov` 重放的单元。**共享只共享证据，不共享结论**——这是防止「一个智能体的判断被复制成群体共识」的结构前提。

**定义 457（ACB 答案-主张绑定）** 主张 `c` 若由视觉证据支持，必须绑定 `(e_id, QuorumCert, receipt_id)`，其中 `receipt_id` 必须是**独立于该视觉采集**的物理回执。无独立回执佐证 ⇒ 剥离为纯解释（沿用第 3 轮定义 441 的纯投影语义，不改变数值行为）。

**定义 458（证据新鲜度-块时域耦合）** 证据年龄 `Δ_e = t_commit − τ_e`，要求 `Δ_e ≤ H_c`（块有效性时域）。若证据在块内过期，CVC 必须在该边界截断，后续块长满足
`K ≤ K_stale(Δ_e) = ⌊K₀ / (1 + K·H(ι|ℓ) + η_stale·Δ_e)⌋`，
其中 `η_stale` 为证据陈旧导致的接地熵增率。**过期证据不得用于放大 K**，只能用于收缩 K 或触发重规划。

**定义 459（证据优先级 ≻_ev）** `receipts ≻_ev calibrated visual evidence ≻_ev language/anecdote`。冲突处理：高优先级证据存在时，低优先级证据只能被记录、不得改变动作；回执与视觉共识冲突 ⇒ 冻结动作、补测、弃答。这是第 3 轮「安全由硬约束负责、语言只负责偏好」的推广：**安全由回执负责、视觉与群体只负责候选证据**。

**定义 460（拜占庭独立类模型）** 设独立类数 `C_ind`，其中至多 `f` 类可被任意篡改。若 `C_ind ≥ 2f+1` 且多数门槛 `Q = ⌊C_ind/2⌋+1`，则未篡改类数 `C_ind − f ≥ Q > f`，正确假设占严格多数。若各类独立正确率 `p > 1/2`，错误接受概率满足
`P_wrong ≤ exp(−2·C_ind·(Q/C_ind − p)²)`。

**定义 461（分歧触发器与安全冻结）** 当 `V(h*) − V(h₂) < m_cons`，或两类在**安全攸关槽位**上冲突 ⇒ 触发 `D_trigger`：冻结动作（不取多数、不取平均），改用回执/补问/回退。冻结期间安全盾与 `K=1` 仍生效；只有回执或新的可采纳证据能解除冻结。

**定义 462（SwarmGauge-8C 闭环）** `I→Q→H→C→E→C→V→G_cons→U`：
`I` 指令接地（定义 432）、`Q` 主动提问（定义 451）、`H` 假设重排、`C` 分块规划（定义 434）、`E` 执行与块证（定义 435）、`C` 校准（438）、`V` 验证、`G_cons` 共识门（454）、`U` 更新契约。`Q` 与 `G_cons` 均为可选增强；任一缺失时逐级退化（定义 463/引理 68）。

**定义 463（集体修复证书 RepairCert″）**
`RepairCert″(s) = (ι, C, ChunkCert, {e_i}, QuorumCert, receipts, claims)`，
沿「问题 → 答案区域 → 独立类 → 共识 → 块 → 回执 → 主张」七级证据链可复现。`QuorumCert = (classes, C_eff, ρ̄, m_cons, f)` 记录每个类的溯源签名与独立性判定，使审计者能重算「为什么这一次多数可信」。

```python
# IP-328/329 AQ-Box + VSR：主动视觉提问（答案只改后验，不产生动作）
class AQBox:
    def ask(self, s, H, scene, budget):
        E = []
        while budget.left > 0 and entropy(H) > EPS_H:
            q = self.select_question(s, H, E)          # argmax IG - λc
            if q is None: break
            v = self.select_view(q, scene)             # 主动选视角
            A, R, pi = self.vqa(q, v)
            e = EvidenceUnit(q, A, R, pi,
                             prov=self.provenance(v), tau=now())
            if admissible(e, scene):                   # 类型/区域/校准/遮挡/新鲜
                E.append(e)
                H = self.reweight(H, e)                # 只重加权，不扩能力
            budget.spend(q)                            # 失败也计费，防止无限补问
        return H, E

def admissible(e, scene):
    return (e.q in Q_onto and e.A in A_onto
            and e.R and e.R <= scene.roi
            and e.pi >= answer_threshold(e, scene.cal)
            and occlusion_sensitivity(e, scene) >= DELTA_OCC
            and now() - e.tau <= H_E
            and replayable(e.prov))

# IP-330/331 PIC + CQ：先证独立，再合票（不是平均、不是取多数）
class CollectiveQuorum:
    def consensus(self, E, H):
        classes = {}
        for e in E:
            k = provenance_signature(e)                # 模型族/数据/视角/校准层
            if k not in classes or e.pi > classes[k].pi:
                classes[k] = e
        classes = {k: e for k, e in classes.items()
                   if independently_certified(e)}      # ρ̂ ≤ ρ_max
        C_eff = effective_classes(classes)             # C/(1+(C-1)ρ̄)
        if C_eff < K_MIN or C_eff < 2 * F + 1:
            return ABSTAIN, None
        V = {h: sum(weight(e) for e in classes.values() if supports(e, h))
             for h in H}
        h1, h2 = top2(V)
        if V[h1] - V[h2] < M_CONS:
            return ABSTAIN, None                       # 分歧 ⇒ 冻结/补问，不取多数
        return ACCEPT(h1), QuorumCert(classes, C_eff, RHO_BAR, F)

# IP-332 SQ-Cal：问题类型 × 智能体簇的分层共形
def answer_threshold(e, cal):
    s = (question_type(e.q), agent_cluster(e.prov))
    if len(cal.get(s, [])) < N_MIN:
        return shrink(cal[s], cal[PARENT])             # 向父层收缩
    return conformal_quantile(cal[s], alpha=ALPHA)

# IP-333 ACB：答案-主张绑定（回执优先）
def bind_claims_vqa(cert, qcert, E, receipts):
    claims = []
    for c in cert.nl_claims:
        ev  = match(c, E)
        rec = independent_receipt(c, receipts)         # 回执须独立采集
        if ev and rec and aq_supported(ev, qcert):
            claims.append(Claim(c, ev, rec, qcert))
        # 无独立回执佐证 ⇒ 剥离为纯解释
    return claims

# IP-334 SwarmGauge-8C（50Hz 路径不变）
def swarmgauge_8c(M, s, ell):
    out  = M.nlib.ground(ell, M.scene, M.ontology)
    iota = out[0] if out else M.default_iota
    H    = M.lbox.hypothesize(s, iota)
    H, E = M.aqbox.ask(s, H, M.scene, M.qbudget(s))    # Q（可选）
    qcert = None
    if M.swarm_online and E:
        hall, qcert = M.cq.consensus(E, H)             # 独立类合票
        if hall is not None:
            H = M.lbox.merge(H, hall)                  # 只重排，不扩能力
    C = M.iac.plan_chunk(iota, H, M.tools,
                         M.budget_left(s), M.drift_bound(s))
    if not fresh_enough(E, C, M.env):                  # 证据过期 ⇒ 收紧 K
        C = M.iac.truncate_to(K_stale(E, C), C)
    cert = M.cvc.commit(C, M.env, iota)                # 与 7C 完全一致
    receipts = cert.receipts
    if not receipt_dominates(E, receipts):              # 回执优先
        return stub_and_red(s, "receipt_conflict")
    if len(receipts) < n_min(s):
        return stub_and_red(s, "insufficient")
    mu, Sig = M.apcal.calibrate(receipts, H, s)
    if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):
        return stub_and_red(s, "cross_failed")
    new_ec = M.apcal.update_contract(M.dpe, mu, Sig, s)
    if not contract_regression(new_ec):
        return stub_and_red(s, "regression")
    M.mreg.hot_replace_at_quiescence(M.dpe, new_ec, cert.boundary)
    bind_claims_vqa(cert, qcert, E, receipts)
    M.pquar.record(M.apcal.last_gain, realized_gain(receipts))
    return True

# 主闭环：Q/共识全异步，50Hz 路径与 MODGAUGE 相同
def SwarmGauge_round(M, obs, audio, tac, depth, det, ell=None):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s)
            submit_async(swarmgauge_8c, M, s, ell)
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 4. 推导

**引理 59（答案能力闭包 / 非扩张）** 在 CC_A 与定义 448 下，对任意可采纳答案 `A`，诱导计划集满足
`Plan(ι⊕A) ⊆ Plan(ι) ⊆ Plan_ToolGauge`；
且答案不改变 `tools(ι)` 与 `mag(ι)`。推论：VQA 与群体共识都不能成为新的越权通道，`free-text(A) → actuator` 的概率为 0。
*证明骨架*：对答案文法归纳。基础：答案取自 `A_onto`；归纳：复合答案只经 `L(H;e)` 改变似然，似然不改可行域，也不注册新工具/新幅值，故计划集不增；越界答案按定义 448 落入 ⊥。

**引理 60（接地答案的捷径拒绝与残余错误界）** 若答案只依赖问题 `q` 而不依赖被引用区域（语言先验捷径），则对任意 `R` 有 `Δ_occ(e)=0`，故 `Adm(e)=false`。因此进入数值路径的答案全部是**区域敏感**的。进一步，若层内共形校准给出覆盖 `1−α`，则
`P(A ≠ truth | Adm, s) ≤ α + β_occ`，
其中 `β_occ` 是遮挡检验「区域敏感但依赖错误区域」的假阳性率。
*证明*：捷径情形落入拒绝域；将失败分解为「未采纳」与「采纳但错」，后者由共形覆盖控制，前者由遮挡检验的必要条件控制。注意这是**必要非充分**，所以 `β_occ` 必须由 E457 实测，不能假设为 0。

**引理 61（主动提问的近优性与停止）** 若 (i) 给定 `H` 时答案条件独立，(ii) `IG(q)` 满足自适应子模性，则贪心提问达到 `(1−1/e)` 最优。若最小正增益为 `g_min`，则把熵从 `H₀` 降到 `ε_H` 至多需要
`⌈(H₀ − ε_H)/g_min⌉`
个问题。若子模性不成立（冷启动/强相关答案），只保留该预算上界，不声称近优；E458 专门检验子模性是否经验成立。
*证明*：标准自适应子模贪心界（Golovin–Krause）；熵的望远镜求和给出问题数上界。

**引理 62（合票的拜占庭可靠性）** 在定义 460 的模型下，若 `C_ind ≥ 2f+1` 且 `Q=⌊C_ind/2⌋+1`，则未篡改类数 `C_ind−f ≥ Q > f`，正确假设获得严格多数，错误共识不可能。若各类独立正确率为 `p>1/2`，则
`P_wrong ≤ exp(−2·C_ind·(Q/C_ind − p)²)`。
*证明*：多数计数 + Hoeffding 不等式；`C_ind−f ≥ Q` 由 `C_ind ≥ 2f+1` 直接代入。

**引理 63（相关性的设计效应 / 克隆不增益）** 设 `C` 个证据类、类间平均误差相关 `ρ̄`，有效独立类数 `C_eff = C/(1+(C−1)ρ̄)`。则：
(i) 加入一个 `ρ̄=1` 的克隆不改变 `C_eff`；
(ii) 若共识用原始 `C` 而真实独立数为 `C_eff`，错误接受界应按 `C_eff` 计，原始置信被高估至多 `C/C_eff` 倍；
(iii) 存在 `ρ_crit` 使 `ρ̄ ≥ ρ_crit ⇒ C_eff < K_min`，此时**任意多克隆都无法达到法定票数**。
*证明*：Kish 设计效应；单调性；解 `C/(1+(C−1)ρ)=K_min` 得 `ρ_crit=(C/K_min−1)/(C−1)`。
**推论（可证伪的负结果）**：增加同源智能体只能增加延迟与伪置信，不能增加信息；只有新增溯源类才可能提升共识。

**引理 64（信息素投毒界）** 在不可变、带 `prov` 的写黑板、按 `κ` 合票、按 `γ` 衰减的机制下，单个拜占庭写者至多改变一个类的权重；因此若 `m_cons > max_κ w_κ`，单类投毒不能翻转共识。其时间累计影响上界为 `w₀/(1−γ)`，但每个类始终只计一票；`prov` 可重放保证可审计与可回滚。
*证明*：合票按类去重 ⇒ 单写者只进入一个类；几何级数给时间累计；票差门槛给翻转条件。

**引理 65（群体分层共形覆盖）** 在每个分层 `s=(问题类型, 智能体簇)` 内、层内可交换下，`P(A 正确 | s) ≥ 1−α`；边缘覆盖
`P ≥ 1−α − Σ_s π_s·TV_s`；
低样本层向父层收缩后覆盖按 `−2η_parent` 优雅降级。**关键补充**：若层内样本相关（同一数据血统），有效样本量是 `n_s/C_eff`，必须按独立单元计，否则名义 `α` 不可达。
*证明*：标准共形 + 分布 TV 传输；设计效应对校准样本量的修正（与引理 63 同源）。

**引理 66（新鲜度-块耦合的安全性）** 若在块边界 `Δ_e ≥ H_c`，则用该证据放大 `K` 会破坏第 3 轮 CVC 的漂移保证；强制 `K ≤ K_stale(Δ_e)` 并在边界截断可保持 `Inv`，检测缺口仍为一个控制拍。反之，在 `H_c` 内取得的集体证据只能**降低**接地熵项、从而放松 `K_MAX(ι)`，绝不能越过回执验证的安全上界。
*证明*：`K_MAX` 对熵单调；CVC 归纳沿用引理 52；过期证据按「缺席」处理（保守）。

**引理 67（共识延迟与 50Hz 保全）** 合票按 `κ` 哈希分组 + 取 top-2，时间 `O(C)`（排序最坏 `O(C log C)`）；VQA 前向与遮挡复核都在异步证据域，只在块静默点把已接受后验发布到规划路径。主循环新增周期 `< 0.2ms`；证据总时延 `L_Q = Σ_q(c_view + c_vqa)` 受 `B_Q` 约束，且当 `L_Q > H_c` 时系统自动退化为 `K=1`，继承 ToolGauge 引理 50 的硬实时结论。

**引理 68（退化等价与端到端风险）** 退化链 `SwarmGauge → AQ-InstructGauge → InstructGauge → ToolGauge → LeanGauge → MODGAUGE` 逐级等价：
`Q=∅ ⇒ H` 不变，与 7C 完全一致；`G_cons` 弃答 ⇒ 保留单智能体 AQ 后验；AQ 空 ⇒ InstructGauge；证据过期/回执冲突 ⇒ `K=1` 即 ToolGauge。故任一增强关闭时，可观察指令流与对应基线逐指令相同。端到端期望损失
`E[L] ≤ P_FA·c_wrong + P_abstain·c_abstain + P_correct·c_right`，
其中 `P_FA` 由引理 62/63 界定；群体优于单智能体的充分条件是
`P_FA·c_wrong + P_abstain·c_abstain < P_wrong^single·c_wrong`。
该不等式由 E462/E470 直接检验，而不是默认成立。

**预期分级**：E457/E460/E462(ρ̄≥ρ_crit)/E463/E464/E468/E469 为「结构级」判据，应严格成立；E458/E461/E465/E466 为「统计级」判据，按置信区间验收；E467/E470/E473 为「系统级」判据，报告效应量与置信区间。

## 8. 本轮最大风险
