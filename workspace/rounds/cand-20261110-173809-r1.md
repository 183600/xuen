# 第 44 轮（新循环第 4 轮） · OSHW-Cert × Anomaly-Gate：把「开源硬件信任根」与「异常检测门」纳入可验证证书闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 把「用户」与「并发」提升为一等公民，但仍压着两块从未被证明的地基：**(H1) 硬件 TCB 被当作固定、封闭、默认可信的黑盒**——所有证书的时钟、时序、故障模型都直接继承平台，却从不检查「这条证书属不属于这块硬件」；**(H2) 证书所依赖假设的失效在运行期不可观测**——分布漂移、传感器退化、硬件分叉、代码/外设替换只能靠离线回归去「相信」。本轮灵感词「开源硬件」「异常检测」精确命中：**开源硬件**把信任根从黑盒变成**可重验证、可被分叉、可异构部署**的基座；**异常检测**把「假设失效」从不可观测变成**可观测但不完备、且可被对抗欺骗**的信号。二者共同触及 soundness 的根基，也共同递来一个危险诱惑：拿「无报警」去换「更少保守」。本轮的硬原则是：**异常检测只赋权收缩、绝不赋权扩张；证书必须绑定平台身份，跨平台只能靠抽象契约精化来移植，否则必须重颁发。**

## 0. 直觉与动机

**灵感 1（开源硬件 → 信任根「可审计」但也「可被分叉」）**：闭源硬件让你只能信厂商；开源 RTL + 开源工具链 + 可复现构建让你能**独立重验证**时序、ISA 语义与故障模型，于是「信任证书」可升级为「**可重推导的证书**」。但开源=可 fork，供应链会漂移：同一份证书可能被部署到一块时序不同、外设被替换、甚至被植入硬件木马的板上。直觉结论：**证书不再是平台无关的真理，而是「在某个平台清单 M 下成立」的带前提结论**；平台变了，证书要么被**抽象契约精化**论证可移植，要么必须**重颁发**。

**灵感 2（异常检测 → 「可观测」但不完备，因此只能做单侧门）**：异常检测能在线发现「证书假设被破坏」（残差越界、传感器掉线、分布漂移、时序抖动、平台指纹变化），收益巨大；但它本质**不完备**（漏报不可避免）、阈值校准**依平台而变**、还可能被**对抗欺骗**。若允许「无异常 ⇒ 放宽阈值/延长租约」，就等于把安全性押在一个不可证完备的检测器上，**引入新的非 sound 单点**。因此把异常检测定义为**单侧门 G_D**：报警只能**收缩**可行集、吊销租约、降级关键级；静默**什么都不增加**。定理：对**任意**检测器 D（含被投毒、被 fork、从未验证的硬件哨兵），G_D 都保持证书不变式——因为动作集只减不增、租约只吊销不续命。**验证 D 只买到可用性与告警时延，买不到安全性**；这反而允许 D 的工程做得又便宜又激进。

**灵感 3（耦合 → 平台异构 × 校准迁移，是本轮真正的新问题）**：开源硬件让平台从 1 块变成 N 个 fork，而共形异常检测的误报保证依赖**可交换性**，某平台校准出的阈值搬到另一 fork 上会**同时误报与漏报**。所以平台清单不只是安全标签，还是**校准表的索引**：证书、异常阈值、硬件哨兵、租约都要按平台分层（Mondrian by platform）。耦合处的矛盾是：**分叉越多 → 需要的校准越多 → 重校准成本爆炸**；缓解是用**抽象契约 Ω 分桶**（时序/ISA/故障模型等价的 fork 共享一套校准），一旦契约不再精化就强制重校准。

**耦合升级**：PAC（平台绑定证书）把每条证书编译成「在 M 下成立」的带前提结论，并负责可移植性判定/重颁发；OAG（单侧异常门）把检测器统一成只能收缩的算子并做按平台共形校准；OSC（开源硬件哨兵编译器）把证书谓词编译进只读 RTL 哨兵，用开源 ISA 的 trigger/PMP/自定义 CSR 在硬件里便宜地跑，并复用第 43 轮 rely-guarantee 强制其**非干扰只读**。四层架构由 v8 升级为 v9：「仿真-检索-边缘飞轮 + 人格契约 + 并发证书」之上，再叠加**平台信任层**与**异常-吊销层**。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（平台清单、证明与证书绑定）**：平台清单 M = (ISA 扩展, RTL 哈希, 工具链哈希, 时序模型 T_M, 故障模型 F_M, 传感器模型 S_M)。平台证明 A_M = Sign(H(M))（实测启动 + RTL/bitstream 哈希 + 可复现构建）。每条证书 c 携带平台前件 π_M(c)；c 仅在「存在有效 A_{M'} 且 M' 精化 c 推导所用抽象契约 Ω_c」时可用于守卫。**绑定不变式**：无有效证明 ⇒ 只能使用**默认保守证书** c_⊥。

**定义 45（抽象契约精化与证书可移植性）**：抽象契约 Ω = (时序上界 T_max, ISA 语义, 故障模型 F_max, 传感器可观测性 S_min)。称平台 p' **精化** Ω（记 p' ⊑ Ω）当且仅当 p' 的实测时序/语义/故障行为均落在 Ω 允许范围内。**可移植定理**：若 c 在 Ω 下 sound 且 p' ⊑ Ω 且 A_{p'} 有效，则 c 在 p' 上 sound。**推论**：开源可复现验证使「p' ⊑ Ω」可被**独立重证**，因此证书可**跨 fork 移植**；一旦精化不成立，必须重颁发 c' = Reissue(c, p')，成本按「受影响的谓词集」计价。

**定义 46（单侧异常门与检测器无关 sound 性）**：检测器 D: 轨迹 → {报警, 静默}。门算子 G_D(C) = C（静默）或 Contract(C, κ_alert)（报警，取按关键级的保守子集），并强制吊销关键级 ≤ κ_alert 的租约。**单调性**：∀D, G_D(C) ⊆ C。**定理**：若底层证书策略在 C 上保持 I，则对任意 D（含对抗/被 fork/从未验证的 D），G_D 仍保持 I。**推论**：D 的正确性不影响安全性，只影响可用性；**禁止**用「静默」做任何扩张（不延长租约、不放松 θ、不扩可行域）——此约束应在接口/类型层强制，而非靠约定。

**定义 47（按平台共形异常检测与误报控制）**：非一致性分数 s(z)（残差、重构误差、时序抖动、指纹距离的融合）。按平台分层（Mondrian by platform，可再按 persona 细分）校准，取秩阈值 q_{1−β}，在**平台内可交换性**下 P(静默 | 正常且平台未漂移) ≥ 1−β，即**误报率 ≤ β**。漂移破坏可交换性，用在线自适应共形（ACI）滚动更新，并以「覆盖率下偏」触发平台重校准。**注**：对**异常**的检出率**不保证**（漏报不可避免）——这正是必须单侧的根本原因。

**定义 48（开源硬件哨兵与其非干扰契约）**：把证书谓词 π（如 m − λ(t−τ) ≥ θ、‖a‖ ≤ a_cap(persona)、平台指纹不变）编译为 RTL 只读哨兵 h_π，部署于开源 ISA 的 trigger/PMP/自定义 CSR。**安全契约**：h_π 只读观测、独立核心/隔离域运行、可见写集为空（复用定义 40 的 rely-guarantee：其 guarantee 不得触及 I 的关键变量）。**双向作用**：报警 → 作为 D 触发单侧收缩（保安全）；静默 → 不提供任何许可（防扩张）。**验证目标**：标称轨迹零误报（保可用性）、告警时延有界、读集最小化、RTL 可被独立形式化重证。

**定义 49（异常触发的吊销、恢复与防抖）**：报警 → 吊销租约 → 进 HI 模式（定义 42）→ 要求**重证明 A_M + 重校准阈值**后才能恢复。恢复**单调**：只能恢复到被重新推导/重新验证过的证书，**禁止信任重置**。用滞回 + 恢复预算 + 按关键级错峰，防「报警-恢复」抖动。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 PLATFORM-ATTESTED-CERTIFICATE（平台绑定证书 PAC）
1. **平台清单与证明**：采集 RTL/bitstream/工具链哈希 + 实测时序/故障模型，产出可复现、可独立核验的 A_M。
2. **证书带平台前件**：每条证书编译为 π_M(c)，归入某个抽象契约桶 Ω；生成精化检查与重颁发计划。
3. **可移植性判定**：自动检查 p' ⊑ Ω（时序/语义/故障），通过则免重证，否则按受影响谓词集重颁。
4. **默认保守证书 c_⊥**：证明缺失/失效时唯一可用，保证可用性不归零且保守性有界。

### 2.2 IP-61 ONE-SIDED-ANOMALY-GATE（单侧异常门 OAG）
1. **融合异常打分**：残差/重构/时序抖动/指纹距离/传感器健康，按平台分层。
2. **共形误报控制**：Mondrian by platform（可选 by persona），ACI 在线更新，漂移即重校准。
3. **单侧门算子**：报警只做 Contract + 租约吊销 + HI 模式；接口层**禁止任何扩张副作用**。
4. **对抗与投毒审计**：检测器被欺骗只影响可用性；记录「漏报-可用性」曲线，绝不作为安全证据。

### 2.3 IP-62 OSHW-SENTINEL-COMPILER（开源硬件哨兵编译器 OSC）
1. **谓词 → RTL**：把守卫谓词/租约判据/指纹不变编译为只读哨兵（trigger/PMP/CSR）。
2. **非干扰形式化**：证明哨兵写集为空、隔离域运行，复用 IP-47 读写集契约做静态检查。
3. **多样性台账**：记录 RTL 血缘（fork 来源），给出**血缘感知的多样性度量**，防止「同源 fork 伪装成冗余」。
4. **独立重证流水**：可复现构建 + 形式化等价检查（RTL ↔ 谓词），产出平台清单输入。

## 5. 本轮最大风险

**一句话**：由于单侧门在构造上保证「任何检测器都不破坏 soundness」，本轮真风险不在安全而在**可用性**——「无报警 ⇒ 偷偷扩张/续租」的实现误用、误报风暴、以及平台分叉导致的校准/重颁发爆炸，可能把系统拖进频繁降级甚至停摆；因此 E96（对抗检测器下 0 违例）与 E97（误报受控）设为红线，并硬性禁止任何「静默 ⇒ 放宽阈值或延长租约」的路径。

# 第 44 轮产物 · 创新点清单 v21：OSHW-Cert × Anomaly-Gate（PAC × OAG × OSC）× 平台可信 + 异常单侧闭环（四层架构 v9）

## 2. 关键算法（伪代码）

### IP-60 PAC：清单、证明、精化与重颁发
```
def build_platform_manifest(board):
    return Manifest(
        ISA      = board.isa,
        RTL      = hash_bitstream(board.bitstream),
        TOOLCHAIN= hash_toolchain(board.toolchain),
        T        = measure_timing(board),       # 最坏延迟/抖动
        F        = fault_inject_profile(board),  # 传感器/执行器故障模型
        S        = observability_profile(board))

def attest(manifest, root_key):
    return Attestation(m=manifest, sig=sign(root_key, hash(manifest)))

def refines(platform, omega):
    return (platform.T <= omega.T_max and platform.F <= omega.F_max
            and platform.ISA.refines(omega.ISA)
            and platform.S.refines(omega.S_min))

def bind_certificate(c, omega, platform, att):
    if not verify(att):            return c_bottom()        # 无证明 => 保守兜底
    if refines(platform, omega):   return c                  # 可移植，免重证
    return Reissue(c, platform)                              # 按受影响谓词重颁
```

### IP-61 OAG：融合打分、按平台共形与单侧门
```
def anomaly_score(z, platform, persona=None):
    r = residual_norm(z)
    t = timing_jitter(z)
    f = fingerprint_distance(z, platform)
    return fuse(r, t, f)        # 可学习，但只影响可用性，绝不进安全判据

def conformal_threshold(platform, persona, beta):
    key    = bucket(platform.isa, platform.T, persona)   # Mondrian 分层
    scores = calibration[key]
    return quantile(scores, 1 - beta)

def one_sided_gate(C, alert, kappa_alert):
    if not alert:
        return C                              # 静默：绝不扩张（禁止续租/放宽）
    revoke_leases(kappa_alert)                # 只吊销
    return contract(C, kappa_alert)           # 只收缩

def aci_update(key, score, beta, gamma):
    # 自适应共形：覆盖率下偏则收紧阈值；仅改变误报，不改变安全
    key.alpha = update_alpha(key.alpha, score, beta, gamma)

def trigger_recovery(platform, att):
    if not verify(att):     return keep_fallback()   # 重证明失败 => 继续 c_⊥
    recalibrate(platform)                            # 重校准阈值
    return monotone_resume(platform)                 # 只能恢复已重证状态
```

def compile_predicate(pi, platform):
    rtl = synth_readonly(pi, platform.isa)   # trigger / PMP / 自定义 CSR

def sentinel_alarm(trace):
    return any(p.violated for p in trace)

def diversity_ledger(fleet):

    return {p.id: lineage(p.rtl_hash) for p in fleet}

### IP-51/56 升级：平台前件 + 单侧门 + 哨兵的守卫
```
def car_transition_guard(e, x, cert_obj, persona, lease, t, platform, att, anomaly):
    if not verify(att) or not refines(platform, cert_obj.omega):
        cert_obj = c_bottom()                 # 平台不匹配 => 保守兜底
    theta   = cert_obj.alpha_e[e] * cert_obj.theta_sim[e]
    m_lookup= cert_lookup_L0(x).m_lo[e]
    m_lease = lease.m - lease.lam * (t - lease.tau)
    m_cap   = persona_cap[e](persona)
    if anomaly.alert or not lease_valid(lease, theta, t):
        return OneSidedContract(e, kappa_alert=anomaly.kappa)  # 只收缩
    return min(m_lookup, m_lease, m_cap) >= theta              # 静默不扩张

def certify_light_v4(x, guards, persona, budget_us, criticality, platform, att):
    if not verify(att): return c_bottom(), None, -1
    b     = cert_lookup_L0(x)
    lease = acquire_lease('lcs', x, theta, criticality, platform_id=hash(att.m))
    sent  = sentinel_check(platform)          # 只读 RTL 哨兵
    if sent.alarm: return one_sided_contract(b, sent.kappa), lease, -1
    U = undecided_guards(b, guards)
    return (b, lease, -1) if not U else (downgrade_monotone(b), lease, -1)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性保证 |
|---|---|---|---|
| IP-60 清单/证明 | O(板级特征) 离线一次性 | 清单 + 证明 O(1) | 实测 + 可复现哈希 ⇒ A_M 可独立核验 |
| IP-60 精化判定 | O(#谓词) | Ω 索引 O(#Ω) | p'⊑Ω 且 c 在 Ω 下 sound ⇒ c 在 p' 上 sound |
| IP-60 重颁发 | O(受影响谓词) | 证书 O(1) | 精化不成立则强制重证，无未证放行 |
| IP-61 异常打分 | O(d) | 分数表 O(N_p) | 分数仅进可用性判据，不进安全判据 |
| IP-61 共形阈值 | O(1) 查表；ACI O(1) | 按平台/人格分数表 | 平台内可交换下误报 ≤ β；漏报不保证（故单侧） |
| IP-61 单侧门 | O(1)+吊销 O(#租约) | 租约表 O(#任务) | G_D(C)⊆C ⟹ 任意 D（含对抗）保持 I |
| IP-62 哨兵编译 | O(|π|) RTL 综合 离线 | 哨兵 O(|π|) | 写集空 + 隔离域 ⟹ 非干扰（定义 40） |

## 6. 本轮最大风险

**一句话**：单侧门在构造上保证「任何检测器都不破坏 soundness」，因此本轮真风险从安全转移到**可用性**——「静默 ⇒ 偷偷扩张/续租」的实现误用、误报风暴、以及平台分叉导致的校准/重颁发爆炸，都可能把系统拖入频繁降级甚至停摆；故 E96（对抗检测器下 0 违例）与 E97（误报受控）设为红线，并硬性禁止任何「静默 ⇒ 放宽阈值或延长租约」的路径。
