# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「角色一致性」×「具身智能大模型」）

> 第 54 轮已把技能组合提升为“动作空间兼容 + 云边联合证书”的可判定体系。本轮转向一个此前被默认掉的前提：**到底是谁在执行？** 具身大模型是通才，但部署需要固定的“行动者身份”。核心矛盾：**H22：具身大模型在长时程、上下文累积、云边切换与跨具身迁移中会发生角色漂移（role drift）——单步鲁棒性不降，行为身份却悄悄改变，导致承诺不一致与安全策略翻转**；**H23：角色一致性只能在意图层度量、在实现层执行——若在动作层强制一致会扼杀跨具身适应性，若只在行为表面度量则会把“稳定的错误”误判为合格**。

## 0. 直觉与动机

**灵感 1（从“外观一致性”到“行为不变量”）**
直觉：生成媒体里的“角色一致性”靠身份嵌入与参考条件，保证同一人物跨帧不变形。具身场景不能照搬：机器人的“角色”不是外观，而是**从情境到行为倾向的稳定映射**。跨帧不变 → 跨时程、跨具身、跨云边不变。因此角色一致性 = 行为身份在某个变换群作用下的**不变性**，而不是像素级相似。数学上，角色是行为轨迹对“实现细节”取商之后剩下的部分；一致性就是这个商映射在变换下不动。

**灵感 2（三性支柱：连续、可实现、不变）**
直觉：v53 的鲁棒性是**连续性**（扰动下成功率不塌），v54 的动作空间是**可实现性**（技能/计划能在真实动作空间落地），本轮补上**不变性**（无论怎样变换，还是同一个行动者）。三者正交：一个策略可以每步都鲁棒、组合都可行，却在长时程里“换了个人”；也可以身份稳定但动作不可实现。证书体系必须同时携带三者，缺一不可。

**灵感 3（角色漂移是一种独立失效模式）**
直觉：长时程闭环里，上下文记忆、奖励反馈、传感器分布漂移会让通才模型逐渐偏离初始角色：安全约束被“合理化”、交互风格走样、任务优先级悄悄变化。它不是某一步失败，而是**轨迹级的身份发散**。因此需要“角色探针集 + 漂移度量 + 重锚定”，像控制里的参考轨迹跟踪，而不是单点验收。

**灵感 4（跨具身：角色不变、动作等变）**
直觉：同一个角色换一副身体（轮式→足式、单臂→双臂），意图与承诺应保持，动作实现必须改变。这正好接住 v54：角色住在“意图空间”，动作剖面 `α_S` 与云边映射 `γ_ce` 只是**实现**。于是要求 role invariance + action equivariance，而不是把动作照抄；照抄动作恰恰是跨具身迁移失败的典型。

**灵感 5（自模型一致性：大模型必须知道自己的身体）**
直觉：具身大模型最大的“角色不一致”是**本体自模型错误**：它以为自己能抓、能到达、能承重，实际不能。角色一致性因此有两面：行为角色（persona/policy identity）与本体角色（body schema / capability self-awareness）。前者答“我想成为谁”，后者答“我到底是谁”。

**灵感 6（角色防火墙与角色越狱）**
直觉：对抗输入、提示注入、异常传感会让机器人**放弃角色**（安全约束被绕过）——这是“角色越狱”。角色应成为解码与执行前的硬边界（role firewall），并用角色条件解码把生成限制在角色允许域内，同时给出可解释的拒绝/升级理由。

**灵感 7（多角色组合）**
直觉：异构机器人团队里每个体有不同角色（侦察/搬运/守护）。组合时不仅技能要兼容（v54），**角色契约也不能冲突**：安全不变量矛盾、动作边界交叉、承诺互相拆台。需要角色组合检查与仲裁。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（角色契约）**
角色 `R = (I, C, ≃_R, B_R)`：`I` 为意图/承诺不变量集合（安全、任务语义、交互契约）；`C` 为行为约束；`≃_R` 为意图层的角色等价关系；`B_R ⊆ A` 为角色允许的动作/意图边界。**关键**：任务回答“要达成什么”，角色回答“以谁的身份、守哪些不可协商的承诺去达成”。

**定义 122（角色投影与角色一致性）**
行为轨迹 `τ` 经角色投影 `π_R: Trace → Sig` 得到意图层签名（刻意遗忘实现细节）。策略 `π` 在变换群 `Φ` 下 **R-一致** 当且仅当
```
∀φ∈Φ: π_R(τ) ≃_R π_R(φ(τ))
```
其中 `Φ = ⟨身份, 具身同态 h, 云边切分, 上下文移位, 时间平移⟩` 由有限生成元生成。一致性即该商映射在 `Φ` 下的不变性。

**定义 123（角色漂移）**
```
drift_R(π_t, π_0) = max_{p∈P_R, φ∈Φ} d_R(π_R(τ_t(p,φ)), π_R(τ_0(p,φ)))
```
`P_R` 为角色探针集，`d_R` 为意图签名距离，`δ_R` 为漂移预算，`Θ_R` 为告警阈值。`drift_R > Θ_R` 称为**角色违例**；若漂移方向仍落在 `I` 之外则称**角色越界**。

**定义 124（角色证书）**
`R_cert = (role_id, I, P_R, δ_R, β_equiv, expiry, evidence)`，其中 `β_equiv` 为等变残差、`expiry` 为短期有效期。`R_cert` 有效当且仅当 `δ_R ≤ Θ_R`、`β_equiv ≤ Θ_equiv`、未过期且 evidence 含探针原始轨迹与复验哈希。**证书只证“稳定”，不证“正确”**——正确性必须由外部安全/任务规约另行绑定。

**定义 125（跨具身角色迁移）**
具身同态 `h: B_1 → B_2`（形态/运动学映射）。迁移有效当且仅当
```
π_R(h_*π_1) ≃_R π_R(π_1)   ∧   δ_a = align(h_*π_1, π_1) ≤ Θ_a
```
即 **角色不变、动作等变**；`δ_a` 与 v54 的联合证书 `J` 共用预算。

**定义 126（本体自模型一致性）**
自模型 `M_self` 预测本体能力（可达、位姿、负载、抓取）。本体一致性
```
ε_body = sup_{p∈P_body} d(M_self(p), obs(p)),   κ_self = corr(M_self.success_prob, observed_success)
```
要求 `ε_body ≤ ε_max` 且 `κ_self ≥ κ_min`。`ε_body` 过大意味着“角色意图正确但身体实现系统性错误”，必须与行为漂移分诊。

**定义 127（角色条件解码与角色防火墙）**
生成 `g(a | s, R)` 的支撑集必须满足 `supp(g) ⊆ B_R` 且 `a ⊨ I`。若越界则 `reject`（硬拒绝）或 `escalate`（带角色解释升级人工/云端），不得静默放行。角色防火墙是执行前的最后一道静态检查。

**定义 128（角色组合契约）**
角色族 `{R_i}` 可组合当且仅当 `⋀_i I_i` 可满足，且存在共享动作边界分解 `B_R = ⋃_i B_{R_i} + B_shared` 使各角色承诺不互相拆台。冲突分三类：不变量矛盾、边界交叉、时序承诺冲突。

## 2. 关键算法 伪代码

### IP-121 RCM（Role Consistency Monitor）

```python
def role_signature(policy, probe, phi):
    tau = rollout(phi(policy), probe.inputs)
    return project_role(tau, probe.intent_levels)   # 多粒度：意图/安全/风格

def role_drift(policy_t, policy_0, P_R, Phi, metric):
    detail = {}
    for probe in P_R:
        for phi in Phi:
            st = role_signature(policy_t, probe, phi)
            s0 = role_signature(policy_0, probe, phi)
            detail[(probe.id, phi.id)] = metric(st, s0)
    return max(detail.values()), detail
```

### IP-122 RCL（Role-Conditioned Lock + Firewall）

```python
def role_conditioned_decode(model, state, R, R_cert):
    if not valid(R_cert) or R_cert.role_id != R.id:
        return ('reject', 'stale_or_foreign_role')
    dist = model.action_dist(state, role_embedding=R)
    support = [a for a in dist.support() if a in R.B_R]
    if not support:
        return ('escalate', 'role_boundary_empty', role_explain(state, R))
    a = sample_restricted(dist, support)
    if not satisfies(a, R.I):                        # role firewall
        return ('escalate', 'invariant_violation', role_explain(state, a, R))
    return ('ok', a)
```

### IP-123 RET（Role-Equivariant Transfer）

```python
def role_equivariant_transfer(pi_src, h, R, P_R, Phi, delta_a_budget):
    pi_dst = pushforward(h, pi_src)                 # 动作实现改变
    sig_src = role_signature(pi_src, P_R, phi=identity)
    sig_dst = role_signature(pi_dst, P_R, phi=h)
    if not equivariant_R(sig_src, sig_dst):         # 角色必须不变
        return ('reject', 'role_broken_by_transfer')
    delta_a = action_alignment(pi_src, pi_dst, h, P_R)
    if delta_a > delta_a_budget:
        return ('reject', 'action_alignment_exceeded', delta_a)
    return ('ok', RoleCert(R.id, R.I, P_R, delta_a=delta_a, evidence=[...]))
```

### IP-124 SMC（Self-Model Consistency）

```python
def self_model_consistency(robot, M_self, P_body):
    errs, pred, obs = [], [], []
    for p in P_body:
        y_hat = M_self.predict(p)
        y = robot.execute_probe(p).observe()
        errs.append(distance(y_hat, y))
        pred.append(M_self.success_prob(p))
        obs.append(y.success)
    eps_body = max(errs) / body_scale(robot)
    kappa = correlation(pred, obs)
    if eps_body > EPS_MAX or kappa < KAPPA_MIN:
        return ('reject', 'body_schema_mismatch', eps_body, kappa)
    return ('ok', eps_body, kappa)
```

### IP-125 RDR（Role Drift Repair）

```python
def repair_role(policy_t, policy_anchor, P_R, Phi, R):
    delta, detail = role_drift(policy_t, policy_anchor, P_R, Phi, d_R)
    if delta <= THETA_R:
        return ('ok', policy_t)
    culprits = top_k(detail, k=3)                   # 哪类不变量/变换漂移最大
    repairs = [anchor_reinject, role_redecode, project_to_role_manifold]
    for repair in repairs:
        cand = repair(policy_t, policy_anchor, R, culprits)
        if role_drift(cand, policy_anchor, P_R, Phi, d_R)[0] <= THETA_R:
            return ('repaired', cand, culprits)
    return ('reject', 'irreparable_drift', culprits)
```

### IP-126 RCC（Role Composition Contract）

```python
def role_composition_check(roles):
    for R1, R2 in combinations(roles, 2):
        if not satisfiable(conjoin(R1.I, R2.I)):
            return ('reject', 'invariant_conflict', (R1.id, R2.id))
        if not decomposable(R1.B_R, R2.B_R):
            return ('reject', 'boundary_conflict', (R1.id, R2.id))
        if temporal_conflict(R1.C, R2.C):
            return ('reject', 'temporal_commitment_conflict', (R1.id, R2.id))
    return ('ok', composite_role(roles))
```

### IP-127 RJC（Role Joint Certificate）

```python
def role_joint_certificate(J, R, P_R, Phi, delta_r_budget, delta_a_budget, eps_max):
    delta_R, detail = role_drift(J.policy, J.anchor, P_R, Phi, d_R)
    if delta_R > delta_r_budget:
        return ('reject', 'role_drift', delta_R, detail)
    smc = self_model_consistency(J.robot, J.self_model, P_body)
    if smc[0] != 'ok' or smc[1] > eps_max:
        return ('reject', 'self_model_mismatch', smc)
    if not role_covers(J.A_cert, R.B_R):
        return ('reject', 'role_action_boundary_mismatch')
    if J.delta_a > delta_a_budget:
        return ('reject', 'action_alignment_exceeded', J.delta_a)
    return ('ok', RJC(J, R_cert=RoleCert(R.id, R.I, P_R, delta_R),
                      eps_body=smc[1], kappa=smc[2]))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| RCM | O(|P_R|·|Φ|·|τ|) | O(|P_R|·|Φ|) | 探针代表性、d_R 度量有效性 |
| RCL | O(|A| log|A| + |I|) / step | O(|A|) | 支撑集完备、不变量可判定 |
| RET | O(|Φ|·(|B|+|A|)) | O(|B|+|A|) | h 为合法具身同态 |
| SMC | O(|P_body|·|B|) | O(|B|) | 本体探针覆盖可达流形 |
| RDR | O(k·|P_R|·|Φ|·|τ|) | O(|P_R|) | 修复收敛、锚点正确 |
| RCC | O(|R|²·|I|) | O(|R|²) | 不变量逻辑可判定 |
| RJC | O(|J| + |P_R|·|Φ|·|τ|) | O(|P_R|+|J|) | 联合证书组合 sound |

**正确性定理（Role-Consistent Embodied Deployment Soundness）**
在 v53 (A22)–(A25)、v54 (A26)–(A28) 之外新增：**(A29)** 角色探针 `P_R` 对部署分布的覆盖缺口 ≤ `β_probe`；**(A30)** 角色防火墙绕过概率 ≤ `β_fw`；**(A31)** 自模型误差 `ε_body ≤ ε_max` 且 `κ_self ≥ κ_min`；**(A32)** 角色投影对 `Φ` 的等变残差 ≤ `β_equiv`。若 `R_cert` 与 v54 联合证书 `J` 同时有效，则
```
P_D(角色违例) ≤ P(δ_R(P_R) > Θ_R) + β_probe + β_equiv + P(ε_body > ε_max) + β_fw
```
且整体部署安全概率
```
P_safe ≥ 1 - [上式] - [v54 的 Σ_d(1-ρ_min) + β_E + P(δ_a>Θ_a)]
```
**关键**：角色一致性是**必要条件而非充分条件**；它把“稳定地错误”的不可能性转化为“先证稳定、再证正确”的分层义务。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 角色探针不具代表性 | 高 | 主动/对抗探针 + 覆盖率证书 |
| 角色过约束损害适应性 | 高 | 角色-性能 Pareto + 可调松弛 |
| 意图投影过粗掩盖有害漂移 | 高 | 多粒度签名字 + 反事实探针 |
| 自模型与真实本体漂移 | 高 | 在线本体标定 + 触觉/本体感知回环 |
| 多智能体角色冲突 | 中 | 组合契约 + 优先级仲裁 |
| 角色证书过期/伪证 | 中 | 短时有效期 + 锚点复验 |
| 一致但错误（stable misalignment） | 高 | 角色证书绑定外部 correctness/safety 语义 |

## 6. 本轮最大风险

**一句话**：角色一致性只保证“还是同一个行动者”，不保证“这个行动者是对的”；一旦角色契约没有与任务正确性、安全语义以及 v53 鲁棒性、v54 联合证书三方绑定，系统就会得到“稳定地偏执、稳定地越界”的高一致性伪安全，因此必须把 `R_cert` 做成**短时、可复验、且以外部规约为锚**的契约证书，宁可拒绝角色，也不把“稳定的漂移”认证成合格。

## 2. 关键算法 伪代码

### IP-121 RCM

```python
def role_signature(policy, probe, phi):
    tau = rollout(phi(policy), probe.inputs)
    return project_role(tau, probe.intent_levels)   # 意图/安全/风格 多粒度

def role_drift(policy_t, policy_0, P_R, Phi, metric):
    detail = {}
    for probe in P_R:
        for phi in Phi:
            st = role_signature(policy_t, probe, phi)
            s0 = role_signature(policy_0, probe, phi)
            detail[(probe.id, phi.id)] = metric(st, s0)
    return max(detail.values()), detail

def monitor(policy_t, policy_0, P_R, Phi, R):
    delta, detail = role_drift(policy_t, policy_0, P_R, Phi, d_R)
    if delta > R.theta:
        return ('violation', delta, top_k(detail, k=3))
    return ('ok', delta)
```

### IP-122 RCL

```python
def role_conditioned_decode(model, state, R, R_cert):
    if not valid(R_cert) or R_cert.role_id != R.id:
        return ('reject', 'stale_or_foreign_role')
    dist = model.action_dist(state, role_embedding=R)
    support = [a for a in dist.support() if a in R.B_R]
    if not support:
        return ('escalate', 'role_boundary_empty', role_explain(state, R))
    a = sample_restricted(dist, support)
    if not satisfies(a, R.I):                        # role firewall
        return ('escalate', 'invariant_violation', role_explain(state, a, R))
    return ('ok', a)
```

### IP-124 SMC

```python
def self_model_consistency(robot, M_self, P_body):
    errs, pred, obs = [], [], []
    for p in P_body:
        y_hat = M_self.predict(p)
        y = robot.execute_probe(p).observe()
        errs.append(distance(y_hat, y))
        pred.append(M_self.success_prob(p))
        obs.append(y.success)
    eps_body = max(errs) / body_scale(robot)
    kappa = correlation(pred, obs)
    if eps_body > EPS_MAX or kappa < KAPPA_MIN:
        return ('reject', 'body_schema_mismatch', eps_body, kappa)
    return ('ok', eps_body, kappa)
```

### IP-125 RDR

```python
def repair_role(policy_t, policy_anchor, P_R, Phi, R):
    delta, detail = role_drift(policy_t, policy_anchor, P_R, Phi, d_R)
    if delta <= R.theta:
        return ('ok', policy_t)
    culprits = top_k(detail, k=3)
    repairs = [anchor_reinject, role_redecode, project_to_role_manifold]
    for repair in repairs:
        cand = repair(policy_t, policy_anchor, R, culprits)
        if role_drift(cand, policy_anchor, P_R, Phi, d_R)[0] <= R.theta:
            return ('repaired', cand, culprits)
    return ('reject', 'irreparable_drift', culprits)
```

### IP-126 RCC

```python
def role_composition_check(roles):
    for R1, R2 in combinations(roles, 2):
        if not satisfiable(conjoin(R1.I, R2.I)):
            return ('reject', 'invariant_conflict', (R1.id, R2.id))
        if not decomposable(R1.B_R, R2.B_R):
            return ('reject', 'boundary_conflict', (R1.id, R2.id))
        if temporal_conflict(R1.C, R2.C):
            return ('reject', 'temporal_commitment_conflict', (R1.id, R2.id))
    return ('ok', composite_role(roles))
```

### IP-127 RJC

```python
def role_joint_certificate(J, R, P_R, Phi, delta_r_budget, delta_a_budget, eps_max):
    delta_R, detail = role_drift(J.policy, J.anchor, P_R, Phi, d_R)
    if delta_R > delta_r_budget:
        return ('reject', 'role_drift', delta_R, detail)
    smc = self_model_consistency(J.robot, J.self_model, P_body)
    if smc[0] != 'ok' or smc[1] > eps_max:
        return ('reject', 'self_model_mismatch', smc)
    if not role_covers(J.A_cert, R.B_R):
        return ('reject', 'role_action_boundary_mismatch')
    if J.delta_a > delta_a_budget:
        return ('reject', 'action_alignment_exceeded', J.delta_a)
    return ('ok', RJC(J, R_cert=RoleCert(R.id, R.I, P_R, delta_R),
                      eps_body=smc[1], kappa=smc[2]))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| RCM | O(|P_R|·|Φ|·|τ|) | O(|P_R|·|Φ|) | 探针代表性，`d_R` 度量有效 |
| RCL | O(|A| log|A| + |I|) / step | O(|A|) | 支撑集完备，不变量可判定 |
| RET | O(|Φ|·(|B|+|A|)) | O(|B|+|A|) | `h` 为合法具身同态 |
| SMC | O(|P_body|·|B|) | O(|B|) | 本体探针覆盖可达流形 |
| RDR | O(k·|P_R|·|Φ|·|τ|) | O(|P_R|) | 修复收敛，锚点正确 |
| RCC | O(|R|²·|I|) | O(|R|²) | 不变量逻辑可判定 |
| RJC | O(|J| + |P_R|·|Φ|·|τ|) | O(|P_R|+|J|) | 联合证书组合 sound |

**正确性定理（Role-Consistent Embodied Deployment Soundness）**
假设第 53 轮 (A22)-(A25) 与第 54 轮 (A26)-(A28) 成立；**(A29)** 角色探针 `P_R` 对部署分布的覆盖缺口 ≤ `β_probe`；**(A30)** 角色防火墙绕过概率 ≤ `β_fw`；**(A31)** `ε_body ≤ ε_max` 且 `κ_self ≥ κ_min`；**(A32)** 角色投影对 `Φ` 的等变残差 ≤ `β_equiv`。若 `R_cert` 与 v54 联合证书 `J` 同时有效，则
```
P_D(角色违例) ≤ P(δ_R(P_R) > Θ_R) + β_probe + β_equiv + P(ε_body > ε_max) + β_fw
P_safe ≥ 1 - [上式] - [v54 的 Σ_d(1-ρ_min) + β_E + P(δ_a>Θ_a)]
```
关键：**角色一致性是必要条件而非充分条件**；一致性证书必须与鲁棒性谱 `ρ`、动作联合证书 `J`、外部安全/任务规约三方绑定，否则只能证明“稳定地是同一个行动者”，无法证明“这个行动者是对的”。

## 5. 本轮最大风险

**一句话**：角色一致性只保证“还是同一个行动者”，不保证“这个行动者是对的”；一旦角色契约没有与任务正确性、安全语义以及 v53 鲁棒性、v54 联合证书三方绑定，系统就会得到“稳定地偏执、稳定地越界”的高一致性伪安全，因此必须把 `R_cert` 做成**短时、可复验、且以外部规约为锚**的契约证书，宁可拒绝角色，也不把“稳定的漂移”认证成合格。
