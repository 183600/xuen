# 第 3 轮（灵感循环续轮；本轮灵感：「路径规划」×「数据质量」）

> **编号说明**：状态文件基线为第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440），
> 其下为第 1 轮 **LeanGauge**（IP-310–314；定义 398–415；引理 42–45；实验 E411–E425）与 **MODGAUGE**。
> 按「在前人基础上改进」的纪律，本轮顺延为第 3 轮。
> **本轮纪律**：不造更大的闭环，不替换任何数值模块；只补 ToolGauge 的两个结构性缺口——
> （1）**路线缺口（空间/调度维）**：T-Box 逐盲区贪心，既不利用相关盲区之间的信息重叠，也不计运动、能量与累积扰动代价；
> （2）**质量缺口（数据/准入维）**：`valid(r)` 是二值判据，有效但低质的回执被等权送入 AP-Cal，
> P-Quarantine 只能全局刹车而不能定点清除。
> MODGAUGE 五不变式、ToolGauge 的 TCV / 双层下注 / AP-Cal / P-Quarantine 全部保留；
> 6C 扩为 **8C**，退化链延长为 `AtlasGauge ⇐ ToolGauge ⇐ LeanGauge ⇐ MODGAUGE`。

## 0. 双轴与耦合（补缺口，而非重写）

| 灵感词 | ToolGauge 的结构性缺口 | 升级为 | 一句话动机 |
|---|---|---|---|
| 路径规划 | T-Box 对每个盲区独立做 `λ/β` 下注，视界=1、无边权、无顺序、无扰动累积 | **R-Box：质量感知的子模路线规划**（盲区图 + 集合信息增益 + 预算/安全/扰动约束 + 滚动重规划） | 探测不是「打地鼠」，而是「巡检路线」：一次探测可同时降低多个相关盲区的不确定性，而过长路线会把后段数据本身做坏 |
| 数据质量 | `valid(r)` 二值；低质但合法的回执与高质回执等权进入校准；谱系不可追溯 | **Q-Box：质量向量 + 方差膨胀似然 + 谱系账本 + 定向撤回 + 质量债务** | 「有效」不等于「可信」：修复的价值必须由有效样本量 `n_eff` 证明，而不是由样本条数证明 |
| 二者耦合（涌现） | 采集与准入各自最优化，互不反馈 | **质量-路线闭环**：路线最大化「可用信息增益」，质量债务与撤回反向驱动重规划 | 采得更多不等于知道更多；系统必须优化「采到且可信」的信息，而非「采到」的信息 |

**核心命题**：`AtlasGauge = ToolGauge + R-Box + Q-Box`。
- **R-Box** 把「逐盲区贪心」升级为「**质量加权的集合信息增益**最大化」：`G_q(A)` 在固定质量权重下是单调子模的（引理 51），故有 `(1−1/e)` 级贪心保证；路线/预算/安全约束以子模 orienteering + 局部搜索处理。
- **Q-Box** 把「二值有效」升级为「**六维质量向量 + 谱系置信**」，并用**方差膨胀**（而非任意 tempering）保持 proper-likelihood 语义：`σ_eff² = σ_decl²/q`，`n_eff = Σq`（定义 437、引理 52）。
- **定向撤回** 把 P-Quarantine 的「全局刹车」升级为「按谱系精确切除 + 定点补采」（定义 439、引理 53）。

**三条可检验主张**：
1. 相同预算下，R-Box 达到目标有效覆盖的成本比 ToolGauge 逐盲区贪心低 ≥30%（E441/E451）；
2. Q-Box 的质量加权使低质数据注入下的后验偏差降低 ≥40%，且不牺牲高质数据下的效率（E446/E448）；
3. 谱系完整时定向撤回的残余污染为 0；谱系缺失时退化按 `γ_l` 线性可控（E447/引理 53）。

**不变式保持声明**：
- MODGAUGE 五不变式全部保留；8C 的第 8 段只是把质量字段写入证书，不在数值通道上；
- 主张绑定扩展：所有「已修复」主张必须携带 `n_eff` 与质量证书 `QCert`，否则剥离（定义 444）；
- **严格退化链延长**：R-Box 失效（不可行/超时）⇒ 视界 1 贪心（即 ToolGauge T-Box）；Q-Box 失效（账本损坏）⇒ `q≡1`（即二值有效）；再失效退回 LeanGauge / MODGAUGE。任何降级必须写 RED 日志与能力声明。

## 0.1 直觉

**灵感 1（路径规划 → 从「逐点下注」到「巡检路线」）**
直觉：ToolGauge 的 T-Box 像消防队——哪里报警去哪里，单次按 `β=Ĝ−c` 判断值不值。但真实计量是巡检：
(a) 相邻盲区常由同一潜在原因致盲（同一块反光表面、同一段热漂移），一次探测可同时降低多个盲区的后验方差，逐点相加会**重复计算**同一份信息；
(b) 探测要移动、要耗能、要时间，路线本身有代价，且顺序可能冲突（先敲击再光学 vs 先光学再敲击，结果不同）；
(c) 探测会扰动环境，扰动沿路线**累积**，后段数据质量会下降。
路径规划的成熟工具箱正好对应：子模信息增益 + 预算/路线约束（orienteering）+ 滚动视界重规划（MPC 式）+ 安全走廊。关键不是「更聪明的贪心」，而是**承认信息增益是集合函数、且采集会改变后续数据的质量**。

**灵感 2（数据质量 → 从「有效/无效」到「有效 ≠ 可信」）**
直觉：ToolGauge 用 `valid(r)` 挡住伪造/过期/越界回执，这是**准入**。但一张回执可以「合法地差」：
接近量程饱和、单点过拟合、与同源数据高度冗余、来自一个即将被发现的错误标定版本。它们全部 `valid`，却会悄悄把后验收紧到错误方向。
数据质量的启示是把「是否有效」细化为**多维度量 + 谱系 + 可撤回**：
- 质量不是玄学，可拆成精度/完整度/时效/一致性/谱系/代表性六维，每维有可观测量（定义 435）；
- 质量应进入**似然**而非只进入日志：用方差膨胀把低质数据等价为高噪声，保持贝叶斯语义（定义 437）；
- 数据是有**血统**的：一旦发现某个标定版本有问题，应能沿谱系**定向撤回**受影响的回执，而不是停掉整个系统（定义 436/439）。
「数据质量」还顺带补上 ToolGauge 预训练层的盲点：MP-Φ 的预训练 episode 也应有质量分 `Q_pretrain`，低质 episode 不应等权塑造先验（§3 备注）。

**灵感 3（耦合 → 「采到且可信」的信息）**
直觉：如果路线只看理论信息增益，它会偏好「信息量大但质量差」的探测（例如远距离、饱和边缘、强扰动路径）；如果质量只看单条回执，它会拒绝「略低质但能与其他回执互补」的数据。
两者必须闭环：路线最大化**期望可用增益** `𝔼[ΔH·q]`，而质量债务 `DQ_s` 与撤回事件反向触发补采路线。
这产生一个必须诚实面对的现象——**质量海市蜃楼**：系统优化的是「它相信的质量」，一旦质量模型本身失准，它会系统性地驶向「看起来高质量」的坏数据（§6 最大风险）。

## 1. 形式化定义（增量：定义 432–445）

**定义 432（盲区图 BSG 与探测路线）** 盲区图 `G_bl = (V_bl, E_bl)`：节点为盲区 s（继承定义 398/399），边 `(s,s')∈E_bl` 表示一次可行转移，边代价
`d(s,s') = α_t·time(s,s') + α_e·energy(s,s') + α_d·disturb(s,s')`。
每个盲区带信息需求 `(u_s, n_req(s), w_s)`，`w_s` 为任务关键度。探测路线 `π=(s_1,…,s_k)` 是 `G_bl` 上的行走序列；执行时每个 `s_i` 展开为 ToolGauge 的探测程序 `Π_{s_i}`（定义 418）。
允许**顺带弱观测**：经过边 `(s,s')` 时，邻近未访问盲区可获得质量较低的证据（`q_weak < 1`），这是路线能「去重」的来源。

**定义 433（质量加权的集合信息增益）** 设当前证据为 `ℱ_{t-1}`，路线覆盖的观测集为 `R(π)`：
`G_q(π) = Σ_{s∈V_bl} w_s · [ H(u_s | ℱ_{t-1}) − H(u_s | ℱ_{t-1} ∪ R(π)) ] · q̄(R(π); s)`，
其中 `q̄` 是用于 s 的证据的期望质量（定义 435/442）。在线性高斯模型下，`[H(·)−H(·|·)] = ½ log det(I + Σ_prior_s · J_R_s)`，其中 `J_R_s` 是证据对 s 的联合信息矩阵。
**关键**：`G_q` 是**集合函数**，不是逐点增益之和；相关盲区共享潜因时，集合增益 < 逐点增益之和（去重），互补时可能接近或超过。

**定义 434（路线可容许性：预算、安全与扰动）** 路线 `π` 可容许（admissible）当且仅当：
① 预算：`Σ_{s∈π} c(Π_s) + Σ_{e∈π} d(e) ≤ B_tools`；
② 安全：每一步满足 `Pre_t` 与力/温/速包络，且任意时刻存在可达的安全回退位姿（安全走廊非空）；
③ 扰动：`Σ_{e∈π} Δ_env(e) ≤ Δ_max`（累积扰动硬顶）；
④ 时序：满足盲区时间窗 `T_s`（时间敏感盲区优先）；
⑤ 长度：`|π| ≤ L_route`。
不可容许 ⇒ 截断为可行前缀（zero-side-effect，继承定义 418）并写 RED。

**定义 435（数据质量向量 DQV 与保守聚合）** 每张合法回执 r 附质量向量
`q(r) = (q_acc, q_cmp, q_tim, q_con, q_prv, q_rep) ∈ [0,1]^6`：
- `q_acc`：`σ_decl` 相对物理噪声底与量程边界（饱和/近界降权）；
- `q_cmp`：回执字段与上下文（温度、位姿、标定版本、单位）完整度；
- `q_tim = exp(−(now−ts)/τ_fresh)`：时效；
- `q_con`：与同源/异源回执的标准化残差一致度（越大越一致）；
- `q_prv`：谱系可信度 = 上游标定版本信任 × 谱系完整度；
- `q_rep`：代表性（距盲区中心/工作包络边界、单点过拟合罚）。
**保守聚合**（默认）：`q(r) = min_i q_i`（木桶原则），可配置为加权几何均值；并强制 `q(r) ≤ q_prv(r)`。
`valid(r)`（定义 417）只是 `q(r)>0` 的必要条件；**低质回执不判无效，而是降权并可能进入隔离池**（定义 438）。

**定义 436（数据谱系 DAG）** 谱系图 `P=(V_P,E_P)`：节点含回执、原始传感器读数、标定版本、工具参数、上游回执；边 `x→y` 表示 y 依赖 x。`lineage(r)` 为 r 的祖先闭包。
**谱系完整不变式**：任何进入 AP-Cal 的数值都必须能沿 `P` 追溯到其工具调用、传感器与标定版本；输入白名单（定义 429）不变。
缺失的依赖边比例记为 `γ_l`（定义 439/引理 53 的退化参数）。

**定义 437（质量膨胀似然与有效样本量）** 把质量解释为**观测方差膨胀**（保持 proper likelihood，避免 power posterior 的非 Bayes 问题）：
`σ_eff(r)² = σ_decl(r)² / q(r)`, `q(r)∈(0,1]`。
线性高斯共轭下：
`Σ_post^{-1} = Σ_0^{-1} + Σ_{r∈R} q(r)·σ_decl(r)^{-2}·J_r`,
等噪声时 `n_eff = Σ_{r∈R} q(r)`。
`q→0` ⇒ 方差→∞ ⇒ 该回执不入样本集（与「无效」一致，但保留了连续过渡）。
**备注（预训练质量）**：同一 DQV 作用于 MP-Φ 的预训练 episode，得到 `Q_pretrain`；元训练目标改为按 `q` 加权的 `−log p(u*|ctx)`，低质 episode 不得等权塑造先验。

**定义 438（质量债务与准入闸门 QG）** 对盲区 s：
`DQ_s = max(0, n_req(s) − Σ_{r∈R_s} q(r))`（有效样本量缺口），
`Q_risk(s) = (1/|R_s|) Σ_{r∈R_s} (1−q(r))`（平均质量风险）。
准入闸门 `QG(s)`：`DQ_s ≤ ε_debt` 且 `Q_risk(s) ≤ ρ_debt` 才允许进入校准与热替换；否则状态置 `QUALITY_INSUFFICIENT`，把「缺口」作为补采需求交回 R-Box（定义 441）。
这把定义 426 的「样本数门槛」升级为「**有效样本量 + 质量风险**」双门槛。

**定义 439（定向撤回 Targeted Retraction）** 给定缺陷谱系源集合 X（例如标定版本 `v_bad`、污染传感器通道）：
`R_X = { r : lineage(r) ∩ X ≠ ∅ }`。
定向撤回：从所有校准样本集与后验中移除 `R_X`，按谱系拓扑序重算受影响盲区的 `q_θ`，把质量债务增量 `Σ_s ΔDQ_s` 反馈给 R-Box 重规划，并冻结所有引用 `R_X` 的热替换子图（回退上一版本或 stub + RED）。
相对 P-Quarantine：从「一有跨盲区相关偏差就全局暂停」变为「**精确切除 + 定点补采 + 其余照常**」。

**定义 440（滚动视界重规划）** 事件 `ε ∈ {新回执, 质量告警, 撤回, 预算变化, 时间窗}` 触发重规划；视界 `H_r`（最多 k 个盲区），提交前缀 `c ≤ k`。
目标：在线最大化 `Σ G_q` 且满足定义 434；重规划延迟 `≤ τ_replan`；两次重规划间沿用已提交前缀，并以滞回阈值 `δ_h` 抑制路线抖动。

**定义 441（质量-路线联合目标与两时间尺度分解）**
`π* = argmax_{π admissible} [ G_q(π) − λ_c·C(π) − λ_s·Risk(π) − λ_d·DQ(π) ]`，
`C = 工具代价 + 行进代价`，`Risk` 为安全风险，`DQ` 为补采质量债务。
**两时间尺度**：慢环（秒级）规划路线，子模贪心 + 局部搜索；快环（毫秒级）做准入、加权校准与质量评分。慢环只产出「路线骨架 + 已提交前缀」，快环可在骨架内即时否决低质调用（双层下注不变，定义 419）。

**定义 442（路线诱导的质量衰减）** 质量依赖路线前缀的累积扰动：
`q(r|π) = q_0(r)·exp(−Σ_{e ∈ prefix(r)} δ_e)`, `δ_e ≥ 0` 为边的扰动/振动/热漂移衰减率。
定义**有效可用增益**为 `G_q` 中代入 `q(r|π)`。
后果：多采集未必多信息；当 `δ_e` 大或路线过长时，后段探测可能接近零增益；`G_q` 可能**失去子模性**（引理 55），故用质量上界代理 + 分段重规划。

**定义 443（数据质量异常指纹与漂移检测）** 维护质量异常指纹库 `F_dq`（模式举例：`q_acc↓ + q_con 同向偏移` ⇒ 饱和/污染；`q_tim 正常但 q_prv↓` ⇒ 标定版本漂移；`q_rep↓ + q_con↑` ⇒ 单点过拟合）。
在质量序列上用 CUSUM / Page-Hinkley 在线检测漂移；命中 ⇒ 生成定向撤回候选集 + 触发 R-Box 重规划。
与 ToolGauge 的 SNC 互补：SNC 查「语义-数值一致」，`F_dq` 查「数据结构-质量一致」。

**定义 444（质量主张与证书 QCert）** 所有「已修复 / 高置信 / 更可靠」类主张必须引用质量证书
`QCert(r) = (q(r), lineage(r), calib_version, n_eff)`。
若主张证据的 `n_eff < n_req` 或 `q < θ_q`，证书必须标注 `QUALITY_CAVEAT`；无法引用有效 QCert 的主张在契约序列化时剥离（继承定义 423）。
**意义**：禁止「用低质数据宣布高置信修复」——把数据质量变成可审计的语言约束。

**定义 445（继承、退化链与编号约定）** 未被本轮重定义的第 2 轮记号（T₀、TCV、λ/β、MP-Φ、AP-Cal、H_s、P-Quarantine、EC、M_ver 等）沿用定义 416–431。
**退化**：令 R-Box = 视界 1 / 无边权的逐盲区贪心，Q-Box = `q ∈ {0,1}`（即 `valid(r)`）⇒ `AtlasGauge ≡ ToolGauge`（定义 416–431、引理 46–50 原样成立）。
**退化链**：`AtlasGauge ⇐ ToolGauge ⇐ LeanGauge ⇐ MODGAUGE`；每次降级写 RED 日志、能力声明与降级原因（R-Box 不可行 / Q-Box 账本损坏 / 质量持续不足 / 预算耗尽）。

## 2. 关键算法骨架

```python
# IP-321 R-Box：质量感知的子模路线规划（CELF 贪心 + 路线局部搜索 + 滚动视界）
class RBox:
    def plan(self, blinds, graph, posterior, budget):
        # 边际增益用联合后验的熵减（定义 433），不是逐点 Ĝ_t 相加
        def gain(A):
            return q_weighted_info_gain(A, posterior, graph)   # G_q(A)
        selected = celf_submodular_max(gain, blinds, budget)   # 引理 51
        route    = budgeted_route(selected, graph, budget)     # 子模 orienteering
        route    = two_opt(route, graph, gain)                 # 局部改进
        return admissible_prefix(route, budget)                # 定义 434：截断到安全前缀

    def replan(self, event, state):
        if event in {NEW_RECEIPT, QUALITY_ALARM, RETRACTION, BUDGET_CHANGE}:
            return self.plan(state.blinds, state.graph, state.posterior,
                             state.budget, horizon=self.H_r)  # 定义 440
        return state.committed_prefix                          # 滞回，不抖动

# IP-322 Q-Box：六维质量评分与保守聚合
class QBox:
    def score(self, r, ctx):
        q_acc = f_accuracy(r.obs.sigma, r.obs.saturation, PHYS_NOISE_FLOOR)
        q_cmp = f_completeness(r.fields, ctx)
        q_tim = exp(-(now() - r.ts) / TAU_FRESH)
        q_con = f_consistency(r, ctx.siblings)
        q_prv = ctx.provenance.trust(r) * ctx.provenance.completeness
        q_rep = f_representativeness(r, ctx.cell)
        q = min(q_acc, q_cmp, q_tim, q_con, q_prv, q_rep)      # 木桶原则
        return min(q, q_prv)

# IP-323 谱系账本与定向撤回
class ProvenanceLedger:
    def append(self, r, parents): self.dag.add_node(r.id, parents)
    def lineage(self, r): return self.dag.closure(r.id)
    def retract(self, X):                                      # 定义 439

        for r in R_X: self.samples.remove(r); self.dag.mark_retracted(r)

# IP-324 QA-Cal：质量膨胀的摊销校准
class QACal:
    def calibrate(self, receipts, H, s):

        Sig = clamp_min(Sig, KAPPA_PHYS)
        n_eff = sum(self.qbox.score(r, self.ctx) for r in receipts)

# IP-325 AtlasGauge-8C 闭环
def atlasgauge_8c(M, s):
    H = M.lbox.hypothesize(s, M.dbox.R[s])                     # H
    if s not in M.committed_prefix:
        M.committed_prefix = M.rbox.replan(PLAN, M.state)
    prog = M.tbox.compile(H, M.committed_prefix.route_to(s))    # R→C
    prog = M.tcv.verify_then_filter(prog, M.budget_left(s))     # C（TCV 不变）
    receipts = M.tcv.execute(prog, M.env)                       # E（PROBING 态）
    scored = [(r, M.qbox.score(r, M.ctx)) for r in receipts]     # Q
    admitted = M.qbox.admit(scored, s)                          # QG（定义 438）
    if M.qbox.debt(s, admitted) > M.eps_debt:
        return defer_and_requeue(s, reason="quality_insufficient")  # 回 R-Box
    mu, Sig = M.qacal.calibrate(admitted, H, s)                  # C
    if not M.qacal.cross_validate(mu, Sig, M.cross_receipt(s)):  # V
        return stub_and_red(s, reason="cross_failed")
    if not M.claims_ok(H, admitted, mu, Sig):                     # 定义 444
        return strip_claims_or_stub(s)
    new_ec = M.qacal.update_contract(M.dpe, mu, Sig, s)           # U
    if not contract_regression(new_ec): return stub_and_red(s, reason="regression")
    M.mreg.hot_replace(M.dpe, new_ec)
    M.dbox.update_from_posterior(s, mu, Sig)
    bind_claims_with_qcert(new_ec, H, admitted)                   # QCert
    M.pquar.record(M.qacal.last_gain, realized_gain(admitted))
    return True

# IP-326 主闭环：规划慢环 + 质量快环 + 严格退化
def AtlasGauge_round(M, obs, audio, tac, depth, det):
```

## 3. 推导

**引理 51（质量加权集合增益的子模性与贪心保证）** 固定质量权重 `q`（与所选集合无关）、观测为条件线性高斯时，`G_q(A)=Σ_s w_s ΔH_s(A)` 是单调子模的；故基数约束下 CELF 贪心达 `(1−1/e)`，背包约束下 cost-benefit greedy 达 `≥½(1−1/e)`，路线（orienteering）约束下由子模 orienteering 的常数因子界保证。
证明思路：`H(u_s|R_A)` 对 A 单调不增（信息不害）；边际递减来自高斯条件协方差 = Schur 补，`ΔH = ½log det(I+ΣJ)` 的凹性；非负权重保持子模。**注意**：一旦 `q` 依赖路线（定义 442），前提失效（引理 55）。

**引理 52（质量膨胀的有效样本量与质量误差敏感度）** 在 `σ_eff²=σ_decl²/q` 下，
`Σ_post^{-1}=Σ_0^{-1}+Σ_r q_r σ_r^{-2}J_r`；等噪声 `n_eff=Σq_r`。要将 `σ_post≤ε` 需
`n_eff ≥ σ_obs²(ε^{-2}−σ_0^{-2})`（推广定义 426）。
若用于加权的 `q_r` 与真实 `q̂_r` 有偏差 `|q_r−q̂_r|≤δ`，则后验均值偏差
`≤ δ·(Σ_r σ_r^{-2}|y_r−μ_0|)/(σ_0^{-2}+Σ_r q_r σ_r^{-2})`，
即偏差随 `n_eff` 衰减；但 `n_eff` 小时质量误差最危险 ⇒ 质量门槛必须与 `n_eff` 联合使用（定义 438）。

**引理 53（定向撤回的充分条件与谱系缺失退化）** 若谱系完整（`γ_l=0`）且缺陷源 X 已知，则撤回 `R_X` 后的后验 = 剔除 X 全部影响后的精确后验，残余污染 = 0。
若谱系缺失比例 `γ_l>0`，则存在未记录的依赖边，残余污染 `≤ γ_l·ρ_X`，其中 `ρ_X` 为 X 在总证据中的影响占比；该界可达（构造：一条未记录的跨通道重用边）。
系：谱系完整性是 AtlasGauge 的**可审计前提**，必须写入 IV-Contract，并由 E447 实测，不得默认成立。

**引理 54（质量门槛下的热替换保守性）** 若 `DQ_s≤ε_debt` 且 V 通过，则替换后 s 上的后验误差
`≤ 基准误差 + c_1·ε_debt + c_2·δ_q`（`δ_q` 为质量估计误差），且界随 `n_eff` 单调收紧；
若 `DQ_s>ε_debt`，拒绝替换并用 stub 保留旧版本 ⇒ 不会比 ToolGauge 更差。
证明：误差分解为「旧版本误差 + 新证据校正误差」；方差膨胀模型的 PSD 序保证低质数据只会放宽后验；热替换等价性继承引理 49。

**引理 55（质量-路线耦合破坏子模性：反例与近似界）** 存在 `δ_e>0` 的实例使 `G_q` 违反边际递减：前半段高质量高增益，后半段因累积振动使所有观测 `q≈0`，于是「加入一个新节点」会降低已选节点的有效增益（后段探测把前段也拖入低质），边际增益反而下降。
若 `q(r|π)` 关于路线前缀扰动总量是 `L_q`-Lipschitz、单点增益有界 M，则用质量上界代理 `G_q^+`（令所有 `q=q_0`）求得 `π̂` 满足
`G_q(π̂) ≥ (1−1/e)·G_q^+(π*) − L_q·M·D_max`，
`D_max` 为最大累积扰动。故扰动小/路线短时代理可靠；扰动大时必须减小视界或分段重规划（工程对策，非定理）。

**引理 56（不变式、时序与退化链保持）** AtlasGauge 只在数值通道外围增加两类输入：「路线选择」影响**采哪些样本**，「质量权重」只影响**观测方差**；所有质量/主张字段都不在 50Hz 数值路径上。
R-Box 失效 ⇒ 视界 1 贪心 = ToolGauge；Q-Box 失效 ⇒ `q≡1` = 二值有效 = ToolGauge；定向撤回只删除证据、不改数值算子。
故 MODGAUGE 五不变式、热替换等价性（引理 49）与硬实时/预算界（引理 45/50）保持；8C 相对 6C 只多出异步的 R/Q 两段。

## 6. 本轮最大风险（一句话）

**一句话**：质量模型与路线目标互相耦合，一旦 `q(r|π)` 被错误设定（尤其是对谱系信任与「看起来干净」的探测过度自信），R-Box 会系统性地驶向**预测质量高但真实质量低**的数据，形成「**质量海市蜃楼**」——系统越是优化自己相信的质量，越是把错误后验收紧得漂亮，而质量证书（QCert）又让这种污染显得格外可信。
这比第 2 轮的「跨盲区相关偏差」更隐蔽：偏差不再来自先验，而来自**采集策略本身的自证循环**；且引理 55 已说明质量-路线耦合会破坏子模性，使「贪心有保证」在真实扰动下失效。
**缓解**：正交质量锚（独立参考测量，不参与路线优化）、保守 `min` 聚合、质量债务闸门、谱系完整性与定向撤回、以及质量盲路线对照组（E449）；P-Quarantine 保留为最后断路器。

**次级风险与缓解**：
1. 子模性失效（定义 442）→ 质量上界代理 + 分段重规划 + 每段子模保证（引理 55）；
2. 谱系不完整（`γ_l>0`）→ 残余污染界（引理 53）+ E447 实测 + 不完整时收紧质量门槛；
3. 路线安全/扰动越界 → 定义 434 硬约束 + PROBING 态（定义 430）+ 可达安全回退位姿；
4. 质量评分抖动导致路线抖动 → 滞回 `δ_h` + 提交前缀（定义 440）；
5. 重规划延迟 → 异步慢环 + 视界上限 + 退化到视界 1；
6. 预训练数据质量偏差 → `Q_pretrain` 加权 + 先验隔离监控（定义 428）扩展；
7. 定向撤回误伤 → 谱系闭包精确匹配 + 撤回后强制 V 交叉验证 + 可回滚账本。

## 2. 形式化定义（要点）

**定义 432/433（盲区图与集合增益）** 盲区为节点、可行为边；路线展开为 ToolGauge 探测程序，允许途经弱观测。`G_q(π)=Σ_s w_s[H(u_s|ℱ)−H(u_s|ℱ∪R(π))]·q̄` 是集合函数：相关盲区共享潜因时集合增益 < 逐点之和（去重），互补时可接近或超过。
**定义 434（路线可容许性）** 预算 `Σc+Σd≤B_tools`、安全包络与可达回退位姿、累积扰动 `≤Δ_max`、时间窗、长度上限；不可容许 ⇒ 截断为可行前缀（零副作用）。
**定义 435（DVQ）** 六维质量，默认 `min` 聚合（木桶原则），强制 `q≤q_prv`；`valid(r)` 仅是 `q>0` 的必要条件。
**定义 436/439（谱系与定向撤回）** 谱系 DAG 记录工具/传感器/标定版本；缺陷源 `X` ⇒ `R_X={r:lineage(r)∩X≠∅}`，精确切除 + 重算后验 + 债务反馈 + 冻结受影响热替换子图。
**定义 437/438（质量膨胀与债务）** `σ_eff²=σ_decl²/q`，`n_eff=Σq`；`DQ_s=max(0,n_req−Σq)`，`Q_risk=mean(1−q)`；双门槛不过 ⇒ `QUALITY_INSUFFICIENT`，退回补采。
**定义 440/441（重规划与联合目标）** 事件驱动、视界 `H_r`、提交前缀 + 滞回；`π*=argmax G_q−λ_c C−λ_s Risk−λ_d DQ`，慢环规划/快环准入两时间尺度。
**定义 442/443（质量衰减与漂移）** `q(r|π)=q_0·exp(−Σδ_e)`；`F_dq` 指纹 + CUSUM 漂移检测，与 SNC 互补（一个查语义-数值，一个查数据结构-质量）。
**定义 444/445（QCert 与退化）** 主张必须携带 `n_eff` 与 QCert，否则 `QUALITY_CAVEAT`/剥离；`R-Box=视界1贪心、Q-Box=q∈{0,1}` ⇒ 精确退化为 ToolGauge。

## 3. 关键算法骨架

```python
# IP-321 R-Box：集合增益 + CELF 子模贪心 + 路线局部搜索 + 滚动视界
class RBox:
    def plan(self, blinds, graph, posterior, budget, horizon):
        gain = lambda A: q_weighted_info_gain(A, posterior, graph)  # G_q，定义 433
        selected = celf_submodular_max(gain, blinds, budget)        # 引理 51
        route = two_opt(budgeted_route(selected, graph, budget), graph, gain)
        return admissible_prefix(route, budget)                     # 定义 434
    def replan(self, event, state):
        if event in {NEW_RECEIPT, QUALITY_ALARM, RETRACTION, BUDGET_CHANGE}:
            return self.plan(state.blinds, state.graph, state.posterior,
                             state.budget, self.H_r)                # 定义 440
        return state.committed_prefix                               # 滞回

# IP-322 Q-Box：六维评分 + 保守聚合
class QBox:
    def score(self, r, ctx):
        q = min(f_accuracy(r.obs.sigma, r.obs.saturation, PHYS_FLOOR),
                f_completeness(r.fields, ctx),
                exp(-(now() - r.ts) / TAU_FRESH),
                f_consistency(r, ctx.siblings),
                ctx.provenance.trust(r) * ctx.provenance.completeness,
                f_representativeness(r, ctx.cell))                  # 定义 435
        return min(q, ctx.provenance.trust(r) * ctx.provenance.completeness)

# IP-323 谱系账本与定向撤回
class ProvenanceLedger:
    def append(self, r, parents): self.dag.add_node(r.id, parents)
    def lineage(self, r): return self.dag.closure(r.id)
    def retract(self, X):
        R_X = [r for r in self.receipts if self.lineage(r) & X]     # 定义 439
        for r in R_X: self.samples.remove(r); self.dag.mark_retracted(r)
        return R_X, affected_posteriors(R_X)

# IP-324 QA-Cal：质量膨胀摊销校准
class QACal:
    def calibrate(self, receipts, H, s):
        mu, Sig = self.mp_phi(featurize_ctx(receipts, H, s))
        Sig = clamp_min(Sig, KAPPA_PHYS)
        n_eff = sum(self.qbox.score(r, self.ctx) for r in receipts)  # 定义 437
        return mu, Sig, n_eff

# IP-325 AtlasGauge-8C
def atlasgauge_8c(M, s):
    H = M.lbox.hypothesize(s, M.dbox.R[s])                          # H
    if s not in M.committed_prefix:
        M.committed_prefix = M.rbox.replan(PLAN, M.state)           # R
    prog = M.tbox.compile(H, M.committed_prefix.route_to(s))
    prog = M.tcv.verify_then_filter(prog, M.budget_left(s))         # C（TCV 不变）
    receipts = M.tcv.execute(prog, M.env)                           # E（PROBING）
    admitted = M.qbox.admit([(r, M.qbox.score(r, M.ctx)) for r in receipts], s)  # Q
    if M.qbox.debt(s, admitted) > M.eps_debt:
        return defer_and_requeue(s, reason="quality_insufficient")  # 回 R-Box
    mu, Sig, n_eff = M.qacal.calibrate(admitted, H, s)              # C
    if not M.qacal.cross_validate(mu, Sig, M.cross_receipt(s)):     # V
        return stub_and_red(s, reason="cross_failed")
    if not M.claims_ok(H, admitted, mu, Sig, n_eff):                # 定义 444
        return strip_claims_or_stub(s)
    new_ec = M.qacal.update_contract(M.dpe, mu, Sig, s)             # U
    if not contract_regression(new_ec): return stub_and_red(s, reason="regression")
    M.mreg.hot_replace(M.dpe, new_ec)
    M.dbox.update_from_posterior(s, mu, Sig)
    bind_claims_with_qcert(new_ec, H, admitted, n_eff)              # QCert
    M.pquar.record(M.qacal.last_gain, realized_gain(admitted))
    return True

# IP-326 主闭环
def AtlasGauge_round(M, obs, audio, tac, depth, det):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s); submit_async(atlasgauge_8c, M, s)
    if M.rbox.stale():      M.rbox.replan(NEW_RECEIPT, M.state)
    if M.ledger.fault():    M.qbox.degrade_to_binary()
    if M.pquar.triggered(): M.qacal.pause(); M.use_bpcal_fallback = True
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 4. 推导

**引理 51（子模性与贪心保证）** 固定质量权重、条件线性高斯下，`G_q(A)=Σ_s w_sΔH_s(A)` 单调子模：信息不害 + Schur 补凹性 + 非负权重。基数约束 CELF 达 `(1−1/e)`；背包约束 cost-benefit greedy 达 `≥½(1−1/e)`；路线约束由子模 orienteering 常数因子保证。质量依赖路线时前提失效（引理 55）。

**引理 52（有效样本量与质量误差）** `Σ_post^{-1}=Σ_0^{-1}+Σq_rσ_r^{-2}J_r`，等噪声 `n_eff=Σq_r`；`σ_post≤ε ⇔ n_eff≥σ_obs²(ε^{-2}−σ_0^{-2})`。若 `|q−q̂|≤δ`，后验均值偏差 `≤δ·Σσ_r^{-2}|y_r−μ_0|/(σ_0^{-2}+Σq_rσ_r^{-2})`，随 `n_eff` 衰减；小 `n_eff` 时质量误差最危险 ⇒ 债务与质量联合门槛。

**引理 53（定向撤回的充分条件）** 谱系完整 + 缺陷源已知 ⇒ 撤回后后验 = 剔除 X 的精确后验，残余污染 0；谱系缺失比例 `γ_l` ⇒ 残余污染 `≤γ_l·ρ_X`，可达。系：谱系完整性写入 IV-Contract，由 E447 实测。

**引理 54（质量门槛下热替换的保守性）** `DQ_s≤ε_debt` 且 V 通过 ⇒ 后验误差 `≤基准+c_1ε_debt+c_2δ_q`，随 `n_eff` 收紧；`DQ_s>ε_debt` ⇒ 拒绝替换、stub 保留旧版本 ⇒ 不劣于 ToolGauge。

**引理 55（耦合破坏子模性：反例与近似界）** 存在 `δ_e>0` 使 `G_q` 违反边际递减（后段累积扰动把前段有效增益也拖低）。若 `q(r|π)` 对前缀扰动是 `L_q`-Lipschitz、单点增益有界 M，则质量上界代理解 `π̂` 满足 `G_q(π̂) ≥ (1−1/e)G_q^+(π*) − L_q M D_max`。扰动大时必须减视界/分段重规划（工程对策）。

**引理 56（不变式与退化链保持）** AtlasGauge 只在数值通道外围加「采哪些样本」与「观测方差」两类输入；R/Q 字段不在 50Hz 路径。R-Box 失效 ⇒ 视界 1 贪心；Q-Box 失效 ⇒ `q≡1`；均精确退化为 ToolGauge，故五不变式、热替换等价性（引理 49）与硬实时/预算界（引理 45/50）保持。

## 8. 本轮最大风险

**一句话**：质量模型与路线目标互相耦合，一旦 `q(r|π)` 被错误设定，R-Box 会系统性地驶向**预测质量高但真实质量低**的数据，形成「**质量海市蜃楼**」——系统越优化自己相信的质量，越把错误后验收紧得漂亮，而 QCert 使污染显得更可信；引理 55 还说明耦合会破坏子模性，使「贪心有保证」在真实扰动下失效。
**缓解**：正交质量锚（独立参考、不参与路线优化）、保守 `min` 聚合、质量债务闸门、谱系完整性与定向撤回、质量盲路线对照（E449）、P-Quarantine 兜底；以 E446/E447/E449/E453 证伪。
