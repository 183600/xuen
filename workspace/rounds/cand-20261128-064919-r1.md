### 第 1 轮灵感驱动研究记录（新一轮循环；承接 CADVS-v5）

**灵感词**：对比实验、实时控制

**继承关系**：上一循环第 5 轮 CADVS-v5（IP-493~496）把提议器升级为条件流匹配、记忆升级为嵌入固化、人因升级为情感调制，并用定理 5~8 证明「换提议不换门、调制只紧不松、固化只改提议器」。v5 留下两个未被理论覆盖的软肋：(a) 所有证书都是**绝对安全谓词**，只回答「这条轨迹安全吗」，不回答「它是否比替代方案更好」；在固化自指回路 R57 中，策略只需通过门即可被当作成功经验回灌，门成了它可优化的环境，缺少**外部对照**。(b) 实时性用 P99 = 0.55 ms 的经验指标背书，P99 不是最坏情况保证；一次 WCET 超标或接触事件突发就可能错过 1 ms 硬截止。本轮用「对比实验」补 (a)、用「实时控制」补 (b)，统一为主题「安全集内的实时对照认证」（Real-time Comparative Certification, RTCC），形成 CADVS-v6（IP-497~500）。本轮自律：**七安全锚不增**；CCK 是晋升/证据层，RTS 是系统时间可行性层，二者都不是新安全门；执行集升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **对比实验 → 从「绝对安全证书」到「相对优越证书」**。v5 的证书是一阶谓词 kc_i(x)=1，天然无法表达「相对于冻结基线 π_0，挑战策略 π_1 在匹配上下文上不更差」。这恰好是 R57 的根因：门只做局部合规判定，策略可以「形式合规、实质退化」而仍被固化。v6 引入**配对对照证书**：在每个准入上下文 X_t 上，让冻结现任 π_0 与挑战者 π_1 同时提议、过同一组门，记录配对效用差 D_t = u(π_1(X_t)) − u(π_0(X_t))；以影子评估为主（挑战者不执行），以安全集内 ε-随机执行做少量在线 A/B 校准；用 anytime-valid e-value 做序贯检验，只有 E_t ≥ 1/α 才晋升。关键设计：**对照对象是冻结的外部基线，不是策略自己的历史证书**——这把「铸证→学习→再铸证」的自指闭环改造成「铸证→外部对照→晋升/回滚」的锚定闭环。

2. **实时控制 → 从「P99 经验指标」到「最坏情况可调度性证书」**。把在线系统显式建模为 sporadic 任务集 τ = {τ_c（1 kHz 控制环，硬截止）, τ_a（10 Hz 准入，软）, τ_f（10–30 Hz FER，软）, τ_e（离线评估，best-effort）}。用响应时间分析检查 R_i ≤ D_i；把缓存证书变成带**租约 ℓ** 与**陈旧度 Δ** 的临时凭证：只有 age ≤ ℓ 且 Δ ≤ Δ_max 才可消费；不可调度或租约失效时走**降级阶梯** full → cached → safe-stop，其中 safe-stop 恒属于已认证安全子集。这样「平均快」升级为「在所有被建模的时序条件下都不错过截止期，且每个执行动作要么持有未过期证书、要么落入安全停机子集」。

3. **统一 → 三层时间尺度的实时对照实验**。两个灵感词不是并列模块，而是同一件事的两面：对照实验需要实时闭环才能拿到外部真值，实时控制需要对照证据才能判断「安全但更差」的退化。设计红线：**1 kHz 硬实时环 / 10 Hz 软实时准入与影子评估 / 分钟级离线统计晋升**三层严格分离；实验只影响「下一个静默切换点装载哪个策略」，永不进入 1 kHz 环；随机化只在已铸证集合内进行——安全由门保证，优劣由对照实验保证，时间由调度保证。

**关键洞见**：v5 回答「提议变成任意生成器时，如何让证书边界保持不变」；v6 回答「当安全不等于更好、快不等于准时，如何用外部对照锚定策略进化、用可调度性锚定时间确定性」。新增维度都不是新的安全锚：CCK 是晋升层（只决定「装载谁」，不决定「能不能执行」），RTS 是时间可行性层（只收缩执行集，失败即降级到安全子集）。七硬门与 Exec_v5 原样保留。

**形式化目标（增量）**：
1. 配对对照：D_t = u(π_1(X_t)) − u(π_0(X_t))；影子双提议 + 安全集内 ε-随机执行；IPS/DR 估计。
2. anytime-valid e-value：E_t = ∏_{s≤t}(1 + λ_s(D_s + δ))；Ville 不等式给出任意停时下假晋升率 ≤ α。
3. 预注册账本：H0/H1、非劣界 δ、α、β、指标、停止规则、Holm 多重比较，在采集前冻结。
4. 实时任务模型与 RTA：τ、C_i、T_i、D_i、R_i；检查 R_i ≤ D_i。
5. 时间证书 kc_time = (RTA 可行, 租约 ℓ, 陈旧度 Δ ≤ Δ_max)；降级阶梯 full → cached → safe-stop。
6. 晋升算子 Promote ∈ {keep, promote, rollback}；双缓冲静默切换 + 证书连续性。
7. 定理 9（anytime-valid 对照晋升）、定理 10（硬实时时间可行性）、定理 11（对照 × 时间复合收缩与嵌套）。

**本轮最大风险**：**对照实验的统计保证只在平稳性/正性假设下成立，硬实时保证只在 WCET 与事件最小间隔假设下成立，而这两组环境假设都无法在线验证**——一旦分布漂移或接触事件突发，系统可能同时做出错误的策略晋升与错过截止期，而每一张局部证书仍显示合规；v6 最大的风险就是用局部可证的「对照正确」与「时间正确」冒充对分布漂移与时间突发的系统级正确。

## 2. 关键算法骨架

### IP-497 CCK：配对对照证书核（分钟级晋升，不进入 1 kHz 环）

```python
@dataclass
class ComparativeCertificateKernel:
    """CCK：外部锚定的配对对照晋升。
    定理 9：冻结现任 + 预注册 + anytime-valid e-value ⇒ 任意停时假晋升率 ≤ α。
    红线：kc_cmp 只决定「装载谁」，不改变「能不能执行」；门集合与 τ^4 冻结"""
    incumbent: Policy             # π_0，晋升周期内只读
    challenger: Policy            # π_1，来自 LMEM-v2 固化候选
    delta: float = 0.02           # 非劣界
    alpha: float = 0.05
    beta: float = 0.20
    lam_max: float = 1.0
    eps_exp: float = 0.02
    min_dwell: int = 50           # 最小驻留周期，防晋升抖动

    def paired_shadow(self, X, gate_fn) -> PairedRecord:
        """同一 context 双策略各提议，过同一组门，记录配对效用差。
        挑战者影子运行、不执行；这是外部对照的数据来源"""
        x0 = self.incumbent.propose(X)
        x1 = self.challenger.propose(X)
        c0, c1 = gate_fn(x0), gate_fn(x1)          # 同一 kc_evidence_forged_v5
        D = self._utility(x1, c1, X) - self._utility(x0, c0, X)
        return PairedRecord(X_hash=hash(X), D=D, c0=c0, c1=c1,
                            both_certified=c0.ok and c1.ok)

    def assign(self, X, rec: PairedRecord) -> Policy:
        """安全集内 ε-随机：只有两候选都认证时才随机，否则执行现任。
        随机化不扩大执行集——安全由门保证，优劣由对照保证"""
        if not rec.both_certified:
            return self.incumbent
        return self.challenger if random() < self.eps_exp else self.incumbent

    def e_value_update(self, E_prev: float, D: float) -> float:
        """下注 e-value；λ_s 预可见且有界，保证 H0 下为非负超鞅（引理 46）"""
        lam = self._predictable_lambda(E_prev)      # ∈ [0, λ_max]
        return E_prev * (1.0 + lam * (D + self.delta))

    def promote(self, E: float, dwell: int) -> str:
        if E >= 1.0 / self.alpha and dwell >= self.min_dwell:
            return 'promote'
        if E <= self.beta:                          # 预注册的无效性停止
            return 'keep'
        return 'keep'

    def dr_estimate(self, logs: list[PairedRecord]) -> tuple[float, float]:
        """双重稳健估计：影子配对 + 少量 ε-随机执行校准倾向得分。
        输出 (效应, 置信区间)；重叠诊断不通过则拒绝晋升"""
```

### IP-498 RTS：实时调度与时间证书核（离线 RTA + 在线 O(1) 检查）

```python
@dataclass
class RealTimeScheduler:
    """RTS：把 P99 经验指标升级为最坏情况可调度性证书。
    定理 10：RTA 可行 + WCET 上界 + 事件最小间隔 ⇒ 无截止期错过且证书有效或安全停机"""
    tasks: list[Task]             # τ_c, τ_a, τ_f, τ_e
    lease: float = 0.010          # ℓ = 10 ms（10 个准入周期）
    delta_max: float = 0.02       # 陈旧度上限（归一化）
    wcet_margin: float = 1.20     # 测量 WCET × 安全系数（或静态上界）

    def response_time(self, i: int) -> float:
        """固定优先级 RTA 不动点：R_i = C_i + Σ_{j∈hp(i)} ceil(R_i/T_j)·C_j"""
        R = self.tasks[i].C
        while True:
            R_new = self.tasks[i].C + sum(
                math.ceil(R / self.tasks[j].T) * self.tasks[j].C
                for j in self.tasks[i].hp)
            if abs(R_new - R) < 1e-9:
                return R_new
            R = R_new

    def schedulable(self) -> bool:
        return all(self.response_time(i) <= self.tasks[i].D
                   for i in range(len(self.tasks)))

    def temporal_cert(self, cert, now, state) -> bool:
        """O(1)：租约未过期且陈旧度在界内"""
        return (now - cert.t_stamp <= self.lease
                and staleness(cert.state, state) <= self.delta_max)

    def degrade(self, cert, now, state):
        """降级阶梯：full → cached（租约内）→ safe-stop（恒在 Exec_v5 子集）"""
        if cert is not None and self.temporal_cert(cert, now, state):
            return cert
        cached = self._last_valid_within_lease(now)
        if cached is not None:
            return cached
        return self._safe_stop()      # S_safe ⊆ Exec_v5
```

### IP-500 EFA-v6：三层时间尺度装配

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：七硬门原样 + 对照晋升 + 时间可行性。
    admit 在 10 Hz 软实时；step 在 1 kHz 硬实时，只消费带租约的缓存证书"""
    v5: EvidenceForgingAssemblerV5
    cck: ComparativeCertificateKernel
    rts: RealTimeScheduler
    prx: PreRegistrationHarness
    buffer: DoubleBuffer          # 双缓冲，静默切换

    # ---------- 10 Hz 软实时：准入 + 影子对照 ----------
    def admit(self, X_t, t_now) -> None:
        rec = self.cck.paired_shadow(X_t, self.v5.gate_fn)   # 双策略过同一组门
        chosen = self.cck.assign(X_t, rec)                   # ε-随机仅在安全集内
        cands = chosen.propose(X_t, self.v5.fmpp.K)
        surv = [x for x in cands if self.v5.cheap_gates(x, rec.gamma)]
        if not surv:
            self.buffer.write(self.rts.degrade(None, t_now, X_t.state))
            return
        finals = [x for x in surv[:3] if self.v5.vack_ok(x, X_t)]
        ok = [x for x in finals if self.v5.bck_preview(x, X_t)]
        if not ok:
            self.buffer.write(self.rts.degrade(None, t_now, X_t.state))
            return
        best = max(ok, key=certified_margin)
        cert = self.v5.issue_cert(best, t_now)               # 带 t_stamp/state
        self.buffer.write(cert)                              # 原子发布

    # ---------- 1 kHz 硬实时：消费 + 时间检查 ----------
    def step(self, state, t_now):
        cert = self.buffer.read()
        if not self.rts.temporal_cert(cert, t_now, state):
            cert = self.rts.degrade(cert, t_now, state)      # full→cached→safe-stop
        return cert.action                                   # 恒在 Exec_v5 或其安全子集

    # ---------- 分钟级离线：统计晋升（不抢占实时环） ----------
    def decide(self, E, dwell) -> str:
        verdict = self.cck.promote(E, dwell)
        if verdict == 'promote':
            self.buffer.schedule_switch(self.cck.challenger) # 静默切换 + 回滚句柄
        return verdict

    def ecs_v6(self, ecs_v5, E, margin) -> float:
        eta_cmp = sigmoid(log(E) - log(1.0 / self.cck.alpha))
        eta_time = 1.0 - max(0.0, (0.10 - margin) / 0.10)    # margin 归一化
        return ecs_v5 * eta_cmp * eta_time
```

### 集成流水线（v5 → v6）

```
【1 kHz 硬实时环 τ_c，截止 1 ms】
  step(state, now)：读双缓冲 ──▶ temporal_cert（O(1)）
       ├─ 有效 ──▶ 执行 cert.action（∈ Exec_v5）
       └─ 失效 ──▶ degrade：cached（租约内）──▶ safe-stop（∈ S_safe ⊆ Exec_v5）

【10 Hz 软实时准入 τ_a，软截止】
  admit(X)：π_0/π_1 配对影子 ──▶ 同一七门 + VACK/BCK ──▶ 选边际最大
       ──▶ issue_cert（含 t_stamp/state）──▶ 双缓冲原子发布
  注：影子评估超时不影响控制环；过期结果直接丢弃，由缓存/安全停机兜底

【10–30 Hz 软实时 FER τ_f】
  FAMK.observe ──▶ γ(ŝ_emo) 预计算；低优先级，绝不抢占 τ_c

【分钟级离线 τ_e，best-effort】
  配对日志 + ε-随机执行日志 ──▶ DR 估计 ──▶ anytime-valid e-value
       ──▶ Promote ∈ {keep, promote, rollback} ──▶ 静默切换/回滚
  预注册账本冻结分析脚本；Holm 校正；负对照与消融回归
```

## 4. 正确性论证（增量更新）

### 引理 45（配对设计的方差缩减）

**陈述**：设同一 context 上两策略效用 U_0, U_1，配对差 D = U_1 − U_0。则 Var(D) = Var(U_1) + Var(U_0) − 2Cov(U_1,U_0) = (σ_1 − σ_0)² + 2σ_1σ_0(1 − ρ)。当 ρ > 0 时，配对相对非配对方差 (σ_1² + σ_0²) 的缩减因子为 1 − 2ρσ_1σ_0/(σ_1²+σ_0²)。

**证明**：直接展开协方差。∎

**工程含义**：同一 context 双提议天然共享大量方差（物体/几何/初始状态），ρ 通常 > 0.6，配对是功效的主要来源。

### 引理 46（anytime-valid e-value 与 Ville 不等式）

**陈述**：若在 H0: E[D] ≤ −δ 下，λ_s 关于历史可预可见且有界（0 ≤ λ_s ≤ λ_max，且 (1+λ_s(D_s+δ)) ≥ 0），则 E_t = ∏_{s≤t}(1+λ_s(D_s+δ)) 是非负超鞅，E_0 = 1。由 Ville 不等式，对任意停时 τ，P_{H0}(∃t: E_t ≥ 1/α) ≤ α。

**证明**：E[(1+λ_s(D_s+δ)) | F_{s−1}] = 1 + λ_s(E[D_s|F_{s−1}] + δ) ≤ 1（H0 下 E[D_s] ≤ −δ）；乘积保持超鞅性；Ville 不等式给出首达概率界。∎

### 引理 47（租约有效性与陈旧度界）

**陈述**：设缓存证书在 t_0 时刻对应状态 s_0，控制跟踪误差 ‖s(t) − s_ref(t)‖ ≤ e_track，接触状态在租约内不发生拓扑变更，则 Δ(t) ≤ e_track + e_contact，且 age = t − t_0 ≤ ℓ。若 e_track + e_contact ≤ Δ_max，则 kc_time = 1。

**证明**：三角不等式 + 事件触发条件。∎

### 定理 9（anytime-valid 对照晋升与外部锚定）

**陈述**：在预注册账本冻结 H0/H1、δ、α、β、停止规则与分析脚本，且晋升仅在 E_t ≥ 1/α 时发生的条件下：
(i) 对真实 E[D] ≤ −δ 的挑战者，任意停时下的假晋升概率 ≤ α；
(ii) 若 DR 估计满足正性/重叠（0 < e(X) < 1）且影子分布与部署分布一致，则 (i) 的推断针对部署分布有效；
(iii) 晋升统计量只依赖冻结现任 π_0 与留出 context，不依赖挑战者自身的历史证书——自指回路被外部基线切断。

**证明**：(i) 由引理 46 + 预注册固定停止规则；(ii) 由 DR 估计的双重稳健性与倾向得分重叠；(iii) 由统计量定义。∎

**诚实边界**：只控制 Type-I；功效依赖 δ、n 与 ρ；影子分布 ≠ 部署分布时估计量有偏；正性违反（某些 context 永不随机到挑战者）使 DR 外推失效，必须用重叠诊断拒绝晋升。

### 定理 10（硬实时时间可行性）

**陈述**：在 sporadic 任务模型、WCET 上界 C_i、最小事件间隔 T_event ≥ T_a、固定优先级调度下，若对所有 i 有 R_i ≤ D_i，且每个控制周期输出要么是 kc_time=1 的缓存证书、要么是 safe-stop ∈ S_safe，则：
(i) 所有任务满足截止期；
(ii) 每个执行动作持有未过期且陈旧度有界的证书，或属于已认证安全子集；
(iii) 降级阶梯的输出恒在 Exec_v5 内。

**证明**：(i) 标准固定优先级 RTA 正确性；(ii) 对控制周期归纳：t=0 由安全停机初始化；若缓存有效则引理 47 给出 kc_time=1，否则降级到 cached/safe-stop；(iii) S_safe ⊆ Exec_v5 且 cached 证书来自已认证候选。∎

**诚实边界**：WCET 必须是真上界（静态分析或带覆盖论证的 pWCET），测量上界不构成硬保证；接触事件突发违反最小间隔假设时，RTA 结论失效，只能依赖看门狗降级；缓存证书的跟踪误差界需在真实执行器上验证。

### 定理 11（对照 × 时间复合收缩与嵌套）

**陈述**：定义 Exec_v6 = {x : x ∈ Exec_v5 ∧ kc_time(x)=1 ∧ (Promote=promote 或 π=π_0)}。则：
(i) Exec_v6 ⊆ Exec_v5 ⊆ … ⊆ Exec_v29（嵌套保持）；
(ii) 对照失败 → 保持 π_0；时间失败 → 降级到 S_safe；两条路径都是 fail-closed 收缩；
(iii) 两层都不改变七硬门谓词与 τ^4，因此 v5 的证书不变性（定理 6）与调制单调性（定理 5）原样保持；
(iv) 若把 kc_time 计入，执行集只会更小；若不计入，七安全锚数量不变。

**证明**：(i) 交集子集 + 降级输出属于 Exec_v5；(ii) 定义 + 定理 10(iii)；(iii) 谓词未变；(iv) 合取只删不增。∎

**诚实声明**：(a) 统计正确 ≠ 系统正确：e-value 只保证「在给定分布与正性假设下」的假晋升率；(b) 时间正确 ≠ 环境正确：RTA 只保证「在给定 WCET 与事件间隔假设下」的截止期；(c) 两者都依赖不可在线验证的环境假设，分布漂移/时间突发时局部证书仍可能全绿而系统级失效；(d) 随机探索虽在安全集内，仍引入性能 regret 与「安全但更差」的暴露；(e) 预注册降低但不能消除研究者自由度（指标选择、场景裁剪仍可操纵）。

## 5. 实验设计与初步结果（本轮把「对比实验」本身作为对象）

### 5.1 预注册与设计（PRX 实例化）

- **估计量**：认证任务成功率的配对风险差 RD = P(success | π_1) − P(success | π_0)；安全违例率差；控制环截止期错过率；时延裕度。
- **设计**：以「匹配 context」为配对单位，按场景族（新物体/长周期/痛苦注入/红队/分布漂移）分块；每块内 π_0 与 π_1 在同一 context 上配对评估；影子为主，ε_exp=0.02 的安全集内随机执行用于校准倾向得分。
- **功效**：先导估计 σ_D ≈ 4.2%（ρ≈0.7）；δ=2%，α=0.05（单侧），β=0.20 → 固定样本约 28 块/臂；序贯 e-value 预期样本量约为固定样本的 0.6–0.7。
- **停止规则**：E_t ≥ 1/α 晋升；E_t ≤ β 无效停止；最大样本量封顶；禁止中途改指标。
- **多重比较**：5 个主要指标用 Holm 校正；次要指标仅作探索性报告。
- **负对照**：(a) π_0 vs 自身（期望不晋升，检验假晋升率 ≈ α）；(b) 随机认证策略 vs π_0（期望不晋升）；(c) 标签置换（e-value 零分布校准）。
- **消融**：A11（v6 − CCK，自指晋升）、A12（v6 − RTS，仅 P99）、A13（固定样本 p 值 + 连续偷看）、A14（非配对设计）、A15（安全集外随机探索——预期违例）。
- **可复现**：预注册哈希、代码提交、随机种子、环境镜像、分析脚本全部冻结并只追加记录。

## 7. 本轮最大风险（最终确认）

**一句话**：**对照实验的统计保证只在平稳性/正性假设下成立，硬实时保证只在 WCET 与事件最小间隔假设下成立，而这两组环境假设都无法在线验证**——一旦分布漂移或接触事件突发，系统可能同时做出错误的策略晋升与错过截止期，而每一张局部证书仍显示合规；v6 最大的风险就是用局部可证的「对照正确」与「时间正确」冒充对分布漂移与时间突发的系统级正确。
