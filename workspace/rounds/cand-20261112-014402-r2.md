# 第 58 轮（承接第 57 轮「少样本可校准×跨模态可对账×个性化有界」证据承诺；新一轮灵感循环第 2 轮；本轮灵感：「多端口部署」×「场景驱动创新」）

> 第 57 轮把安全的赌注从"模型置信"移到"证据质量"，再用元学习把先验从手工挪到摊销、用共形带兜底；但它自陈的最大风险是"坏先验普遍"——语料一旦有系统性盲区，元模型会在 OOD 门学会识别的模式之外给出高度自信的错误后验。本轮两个灵感恰好把这个风险的**发生机制**摆上桌面：**多端口部署**意味着同一套安全架构会被复制到 N 个部署端点（场地×本体×传感×操作者×场景），一个坏先验不再只污染一处，而是经共享工件"广播"成全机队相关失效；**场景驱动创新**意味着参数与机制不该由一个通用默认值统治，而应由显式场景契约编译出来，同时必须警惕"声明一个宽松场景"成为新的博弈通道。本轮把第 57 轮"一切判定器（含元模型）走隔离"再推一步为 **"一切跨端口导入走隔离、一切场景参数受全局地板支配、一切机制必须有场景岗位"**。核心命题由"证据说可信"升级为 **"证据在正确的端口、按正确的场景、以被治理的方式说可信"**。

核心矛盾：
- **H29（共享先验 vs 相关失效）**：跨端口共享元模型/地图先验/模态可靠性，把每个端口各自的小样本经验摊销成机队级效率；但同一份共享工件也把 N 个端口的错误绑在一起——单端口失效率 δ 在机队里不再是 δ^N，而可能仍是 δ。安全界必须从"端口独立乘积"改写为"共享工件簇的并集"，否则效率的收益是真实的、风险的分散是幻觉。
- **H30（场景定制 vs 场景合理化）**：由场景契约编译参数能贴合真实的风险经济学（仓库停车便宜、工地接触不可逆、灾害现场人不可得）；但"声明场景"本身成为可博弈的动作——部署方可以把场景声明得比实际宽松，用"这是我们场景的合理选择"来换取更少探针、更快授权。场景驱动的自由必须先被全局地板和诚实审计夹住。
- **H31（局部最优 vs 组合覆盖 / 机制增殖）**：多端口部署天然诱人按"最容易成功的端口优先"铺开，但 canary 若只覆盖简单场景，staged rollout 会给出**假阳性保护**：它证明的是"简单端口没问题"，而不是"共享工件没问题"。同时，场景驱动的另一半是**纪律**——研究线已叠了太多层，每个新机制都应有场景岗位与退役条件，否则"创新"退化为复杂度增殖。

## 0. 直觉与动机

**灵感 1（多端口部署 → 端口隔离、端口认证、风暴控制、爆炸半径）**
直觉：把"多端口"读作**部署端点**而非物理网口——port=(场地, 本体, 传感套件, 操作者群, 场景)。交换机多端口的三条纪律直接迁移：**端口隔离**（一个端口的证据不能默认被另一个端口采信）、**端口认证**（导入物先证明自己，才允许持有"承诺权"，对应 802.1X 的先认证后放行）、**风暴控制**（坏先验不能被广播成泛洪）。由此得到核心不变式：**跨端口导入默认只有 proposal 权，绝不自动取得 commitment 权**；并派生"爆炸半径"概念——某共享工件被证伪时，哪些未独立验证的端口会被一起拖下水，撤销必须在可界定的时延内传播。多端口还意味着机器人/任务会**跨端口漫游**，于是"证据居住域"和"操作者信任不可移植"成为边界语义。

**灵感 2（场景驱动创新 → 场景契约、场景编译器、场景诚实、机制岗位）**
直觉：安全参数不是普世常数，而是场景的函数——同一台四足，在仓库里"停车等确认"几乎无成本，在灾害搜救里"等一分钟"可能等价于失败，在钢筋工地一次不可逆接触可能不可承受。与其手调一套全局阈值，不如让场景**编译**参数：任务分布决定 δ_f，后果模型决定 corrob\*，人类可得性决定 τ_int 与授权节奏，时间预算决定探针上限。但编译必须服从**全局安全地板**：场景只能把参数调得更保守，永不能更宽松。另一半是"创新纪律"：每个机制都要写清**在哪个场景它胜过现状、什么时候可以退役**——没有场景岗位的机制就是复杂度税。这也给本轮一个自检：不是再加一层，而是让每一层能被场景"雇佣"或"解雇"。

**灵感 3（两灵感合流 → 两级安全：全局地板 + 场景编译；分阶段铺开）**
直觉：安全界变成两层：**ℱ（全局地板，任何场景不可放宽）** 与 **Θ_p=Σ(S_p)（场景参数，满足 Θ_p≽ℱ）**。多端口铺开变成**分阶段发布**：共享工件先上 canary 端口集，canary 通过（局部失效率、校准回归、场景漂移检测、跨模态对账残差）后才全域铺开；canary 的选择由**场景覆盖**而非部署难度决定。这样"坏先验普遍"被拆成三个可治理的量：坏先验的**产生**（SHA/元校准）、坏先验的**传播**（PQG/CBR）、坏先验的**伪装**（DPP 的覆盖优先 canary）。

**灵感 4（与第 57 轮的接口）**
直觉：第 57 轮的四层纵深（元校准、OOD、共形、个性化有界）全部保留，但多端口给每一层加了"来源"维度：EV-probe\* 须声明其元模型的**端口来源与准入状态**；EV-xmodal 的独立性要求新增"非同源传感/非同源标定"；EV-human 的 auth 只在**本端口**有效；J_p 证书新增 provenance 与 port 域。第 57 轮"元模型走隔离"在此正式推广为"**导入物走隔离**"，第 56 轮"地图证据走隔离"则成为其在单端口内的特例。

**灵感 5（DPP → 把"部署组合"本身变成被优化的对象）**
直觉：第 57 轮让探询预算成为学习对象，本轮让**部署顺序与 canary 选择**成为学习对象：不是"先铺最容易的端口"，而是"先用最少端口覆盖最多场景、同时压低共享工件相关性"。这等价于部署层的 VOI：一个 canary 端口的价值 = 它能在多大程度上替代性地检验共享工件（信息增益），减去它自身不可逆接触的风险与成本。完美时它是"用最少的端口，买最大的不确定性削减"。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（部署端口与场景契约 SCP）** 部署端口 p=(site_p, body_p, sensor_p, op_p, S_p)，场景契约 S_p=(𝒯_p 任务分布, 𝒞_p 后果模型, ℰ_p 证据可得性, ℋ_p 人类可得性与可靠性, ℬ_p 时间/预算, 𝒢_p 同意与法规域)。场景编译器 Σ:S→Θ_p，参数向量 Θ_p=(δ_f, θ_D, corrob\*, τ_int, k_probes, θ_ood, α_conf, w_max, θ_voi)。参数按**安全保守序 ≽** 定义：δ_f↓、θ_D↓、corrob\*↑、τ_int↓、k_probes↑、θ_ood↓、α_conf↓、w_max↓ 为更保守。全局安全地板 ℱ 满足 **∀S: Σ(S)≽ℱ**（逐维不更宽松）。端口身份 id(p)=H(site,body,sensor,op,S_p) 写入 provenance。**端口认证**：只有经定义 140 准入的工件才持有该端口的承诺权（commitment authority）。

**定义 140（端口隔离准入 PQG）** 跨端口传输算子 T_{p→q} 把工件 a∈{q_φ, 𝓜, ρ_ℳ, Θ, s_o} 映射为 {proposal, admitted}：
(R1) a.kind=s_o（操作者信任）**不可移植**，恒为 proposal，须在 q 本地重建；
(R2) 若 sim(S_p,S_q)≥θ_match 且 shadow_validate(a,q) 通过（本地校准回归：ECE 不劣化 ∧ OOD 检出率不降 ∧ 分歧下限触发率不降），则 a 可获 q 域内承诺权；
(R3) 否则 a 仅获 proposal 权：可作初始化/先验/候选，但**不得**作为 EV-probe\*/EV-xmodal/EV-human 的授权来源，须由 q 本地独立证据（k_min 次探针或本地事后实测）解除隔离；
(R4) 所有导入物携带 provenance(a)=(id(p), version, evidence, t_import)，版本更新视同**新导入**。
不变式：**导入从不自动晋升**（no auto-promotion）。

**定义 141（相关失效爆炸半径登记 CBR）** 依赖图 G_D=(工件版本, 端口)，边 (a,p) 表示 p 的承诺依赖 a。爆炸半径 BR(a)={q : a∈active(q) ∧ q 未独立验证 a}。按共享工件把机队划分为相关失效簇 {C_c}。撤销算子 Rev(a,T_rev) 把 BR(a) 中所有端口在 T_rev 内降为 proposal-only/本地回退，并回溯其已发出的承诺证据。机队相关失效**按簇取并集**，不按端口独立乘积计：P_corr ≤ Σ_c δ_c^shared。

**定义 142（场景诚实审计 SHA）** 声明契约 S_p 与观测部署分布 D̂_p=(地形/任务/操作者行为/后果) 的漂移 drift(p)=TV(𝒯_obs,𝒯_p)+W₁(𝒞_obs,𝒞_p)+KL(ℋ_obs,ℋ_p)/Z。若 drift>θ_drift，或审计被禁用/证据不足，则端口进入 **floor 模式**：Θ_p←ℱ（最保守可用参数），登记 scenario_drift 事件；恢复需连续 n_clean 次审计通过。审计开关不可由部署方单方关闭（与第 57 轮"判定器走隔离"同源）。

**定义 143（端口边界证据交接 PBH）** 证据 e 的居住域 res(e)⊆ports；e 在 q 处可作承诺证据 **iff** q∈res(e) 或 revalidate(e,q) 通过。机器人/任务跨端口 p→q 时：地图证据降为 proposal，模态可靠性按 q 重新初始化（除非共享同批传感且已过校准回归），操作者状态强制新建。跨界是 PCE++ 的**强制检查点**，禁止"带着 A 端口的信任直接进入 B 端口"。

**定义 144（部署组合规划 DPP）** 给定候选端口集 P、场景空间 𝒮、共享工件爆炸上限 δ_shared^cap、部署预算 B_dep，求有序序列 π=(p_1,…,p_m) 最大化场景覆盖 Cover(π,𝒮) 并满足 P_corr(π)≤δ_shared^cap，且对每个共享工件版本执行 canary 先行：先在小 canary 集 staged rollout，通过（局部失效率 ∧ 校准 ∧ 漂移检测 ∧ 跨模态残差）后才全域铺开。目标不是"最容易成功的端口优先"，而是**"信息增益/场景覆盖最大且相关性最低的端口优先"**。

## 2. 关键算法伪代码（完整版见产物区）

```python
def compile_scenario(S, floor):                    # IP-139: 场景只可更保守
    th = {'delta_f': f_delta(S), 'theta_D': f_D(S),
          'corrob': f_corrob(S), 'tau_int': f_tau(S),
          'k_probes': f_k(S), 'theta_ood': f_ood(S),
          'alpha_conf': f_alpha(S), 'w_max': f_w(S)}
    for k in th: th[k] = more_conservative(th[k], floor[k])
    assert dominates(th, floor); return th          # ∀S: Σ(S) ≽ F

def import_admit(src, dst, a):                      # IP-140: 先认证后放行
    if a.kind == 'operator_trust':
        return Proposal(a, 'persona_not_portable')  # 人不可移植
    if sim(src.S, dst.S) >= theta_match and shadow_validate(a, dst):
        return Admit(a, scope=dst.id, provenance=prov(a))
    if shadow_validate(a, dst) and local_independent_probe(a, dst, k_min):
        return Admit(a, scope=dst.id, provenance=prov(a))
    return Proposal(a, 'needs_local_validation')     # 默认不晋升

def blast_radius(a, fleet):                         # IP-141: 并集而非乘积
    br = {q for q in fleet if a in q.active and not q.independently_validated(a)}
    return CorrelatedCluster(a, br, delta_shared=a.declared_failure)

def scenario_audit(port):                           # IP-142: 漂移即退地板
    if drift(port.contract, observe(port)) > theta_drift or audit_disabled(port):
        port.theta = floor(); audit.flag(port, 'scenario_drift')
    return port

def boundary_handoff(robot, p_from, p_to, ev):      # IP-143: 信任不随行
    for e in ev:
        if not (p_to.id in res(e) or revalidate(e, p_to)):
            e.status = 'proposal'
    robot.persona = fresh_persona(p_to)              # 操作者状态重建
    return revalidate(robot, p_to)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| SCP | O(|S|) 编译 | O(|Θ|) | 逐维保守支配 Θ≽ℱ |
| PQG | O(validate) 每工件 | O(provenance) | 导入无自动晋升 |
| CBR | O(|G_D|) 更新/撤销 | O(|G_D|) | 爆炸半径与撤销完备 |
| SHA | O(|D̂|) 每次审计 | O(|S|) | drift 即退地板，审计不可关 |
| PBH | O(|e|) 每边界 | O(res) | 证据居住域/信任不可继承 |
| DPP | O(|P|²·|𝒮|+rollout) | O(|P|+|𝒮|) | canary 先行、覆盖-风险权衡 |

**正确性定理（DGS：Deployment Governance Soundness）** 在 A22–A40 上新增：(A41) 场景编译器保守支配：∀S，Σ(S)≽ℱ，且 ℱ 在任何部署阶段不被放宽；(A42) 端口准入完备：未通过本地独立验证的导入物只作 proposal，绝不进入承诺证据集，provenance 完整；(A43) 爆炸半径完备：依赖图登记完整，撤销可在 T_rev 内传播到所有未独立验证的导入端口；(A44) 场景诚实：声明与观测分布漂移 ≤θ_drift 或被 SHA 检出并退回 ℱ，审计不可被部署方关闭；(A45) 端口边界：证据居住域与操作者信任不跨端口继承，跨界强制重验证。则：

(i) **单端口界不回退**：每端口承诺失效率 ≤ δ_f^floor + ε_meta(k) + δ_probe + ε_h(w_max)，OOD 路径 ≤ δ_ood·α_conf；
(ii) **机队相关失效界**：P(任一端口不安全承诺) ≤ Σ_c δ_c^shared·𝟙[∃q∈C_c 未独立验证] + Σ_p δ_p^local，且一切导入物停在 proposal 权时相关失效退化为单端口界；canary 对系统性共享错误的检出概率 ≥ 1−(1−p_det)^|canary|；
(iii) **场景不越界**：任何"声明宽松场景"的放宽量都被 ℱ 支配或被 SHA 检出退回，故不能突破全局界；
(iv) **组合终止/覆盖**：DPP 在有限候选集上终止；在 canary 未通过时冻结全域 rollout（fail-closed），不进入"未知端口"。

```
P_fleet_safe ≥ 1 − Σ_c δ_c^shared·𝟙[∃q∈C_c 未独立验证] − Σ_p (δ_f^floor+ε_meta+δ_probe+ε_h)
             − P(T_rev 超时) − P(SHA 漏检 ∧ drift) − P(PBH 漏检)
```

关键：**地板管安全、场景管贴合、canary 管传播**——场景驱动只买"更准的保守"而不是"更松的自由"；多端口只买"摊销效率"，其代价相关失效必须用隔离+爆炸半径登记显式定价。

### IP-139 SCP（场景契约与参数编译器）

```python
CONSERVATIVE = {  # True 表示"更保守"的方向
    'delta_f': 'lower', 'theta_D': 'lower', 'corrob': 'higher',
    'tau_int': 'lower', 'k_probes': 'higher', 'theta_ood': 'lower',
    'alpha_conf': 'lower', 'w_max': 'lower', 'theta_voi': 'lower'}

def more_conservative(v, f, key):
    return min(v, f) if CONSERVATIVE[key] == 'lower' else max(v, f)

def compile_scenario(S, floor):                    # Σ: S -> Θ_p
    th = {'delta_f':   f_delta(S.consequence, S.task),
          'theta_D':   f_D(S.evidence_avail),
          'corrob':    f_corrob(S.consequence, S.human_avail),
          'tau_int':   f_tau(S.time_budget, S.human_avail),
          'k_probes':  f_k(S.evidence_avail, S.task),
          'theta_ood': f_ood(S.evidence_avail),
          'alpha_conf':f_alpha(S.consequence),
          'w_max':     f_w(S.human_avail)}
    for k in th:                                    # 场景只能更保守
        th[k] = more_conservative(th[k], floor[k], k)
    assert dominates(th, floor)                     # A41: Θ_p ≽ ℱ
    return th

def dominates(th, floor):
    return all(more_conservative(th[k], floor[k], k) == th[k] for k in th)
```

### IP-144 DPP（部署组合规划与 staged rollout）

```python
def deployment_portfolio(P, S_space, blast_cap, budget):
    chosen, covered = [], set()
    while budget.left > 0:
        p = argmax(P, key=lambda q:
                   coverage_gain(q, covered, S_space)      # 覆盖新场景
                   - correlated_risk(q, chosen, blast_cap)  # 相关性越低越好
                   - cost(q))
        if coverage_gain(p, covered, S_space) - correlated_risk(p, chosen, blast_cap) <= 0:
            break
        chosen.append(p); covered |= scenarios_covered(p)
        stage_rollout(p, canary=(len(chosen) == 1))       # 首批为 canary
        if canary_mode(p) and not canary_pass(p):         # 局部失效/校准/漂移/残差
            freeze_fleet_rollout(chosen); break           # fail-closed
        budget.spend(p)
    return chosen, covered, canary_log()
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SCP | O(|S|) 编译 | O(|Θ|) | 逐维保守支配 Θ≽ℱ（A41） |
| PQG | O(validate) 每工件 | O(provenance) | 导入无自动晋升（A42） |
| CBR | O(|G_D|) 更新/撤销 | O(|G_D|) | 爆炸半径与撤销完备（A43） |
| SHA | O(|D̂|) 每次审计 | O(|S|) | drift 即退地板（A44） |
| PBH | O(|e|) 每边界 | O(res) | 居住域/信任不继承（A45） |
| DPP | O(|P|²·|𝒮|+rollout) | O(|P|+|𝒮|) | canary 先行、fail-closed |
| MFSL-P/XMC-P/PTM-P/FSE-P | 同前 + O(1) provenance 检查 | 同前 | 同前 + 端口域约束 |

**正确性定理（DGS：Deployment Governance Soundness）**
假设 A22–A40（第 53–57 轮）成立；新增 **(A41)** 场景编译器保守支配：∀S，Σ(S)≽ℱ，且 ℱ 在任何部署阶段不被放宽；**(A42)** 端口准入完备：未通过本地独立验证的导入物只作 proposal，绝不进入承诺证据集，provenance 完整；**(A43)** 爆炸半径完备：依赖图登记完整，撤销可在 T_rev 内传播到所有未独立验证的导入端口；**(A44)** 场景诚实：声明与观测分布漂移 ≤θ_drift 或被 SHA 检出并退回 ℱ，审计不可被部署方关闭；**(A45)** 端口边界：证据居住域与操作者信任不跨端口继承，跨界强制重验证。则：

1. **单端口界不回退**：ID 路径 P(fail) ≤ δ_f^floor + ε_meta(k) + δ_probe + ε_h(w_max)；OOD 漏检路径贡献 ≤ δ_ood·α_conf；EV-xmodal 仅 L1 贡献 ≤ δ_xm。
2. **机队相关失效界**：P(任一端口不安全承诺) ≤ Σ_c δ_c^shared·𝟙[∃q∈C_c 未独立验证] + Σ_p δ_p^local。当所有导入物停在 proposal 权时，第二项退化为单端口界之和；canary 对系统性共享错误的检出概率 ≥ 1−(1−p_det)^|canary|。
3. **场景不越界**：任何"声明宽松场景"的放宽量都被 ℱ 逐维支配，或被 SHA 检出退回 floor 模式；因此场景驱动只能买"更准的保守"，不能买"更松的自由"。
4. **组合终止与覆盖**：DPP 在有限候选集上终止；canary 未通过即冻结全域 rollout（fail-closed）。
5. **部署界**（对端口与工件簇取联合界）：

```
P_fleet_safe ≥ 1 − Σ_c δ_c^shared·𝟙[∃q∈C_c 未独立验证] − Σ_p (δ_f^floor+ε_meta+δ_probe+ε_h)
             − P(T_rev 超时) − P(SHA 漏检 ∧ drift) − P(PBH 漏检) − P(canary 假阴性 ∧ rollout)
```

关键：**地板管安全、场景管贴合、canary 管传播**；多端口只买摊销效率，相关失效必须用"隔离 + 爆炸半径登记"显式定价，而不能默认"端口独立"。

## 7. 本轮最大风险

**一句话**：本轮最大风险是"伪独立"——端口隔离只切断了显式证据共享，却切不断同源元模型、同批传感器与同一份场景编译器带来的隐式相关；若 canary 只覆盖易部署场景，整套多端口治理会把"一个坏先验"伪装成"互相印证的多个好端口"，让相关失效在 staged rollout 的假阳性保护下扩散到全机队。
