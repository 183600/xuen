### 第 8 轮（新循环·第 1 轮）灵感驱动研究记录

**灵感词**：最小可行产品、轻量化设计

**继承关系**：承接第 7 轮 CADVS-v7（IP-501~504）与「七硬门 + 六软因子链」。但本轮发生方向反转：前七轮是「加法式能力堆叠」（每轮新增模块与软因子），而 MVP/轻量化要求做「减法式最小可证内核」。本轮不再问「还能加什么」，而问：**去掉什么，系统仍能保持证书、且仍然有用？**

**直觉与动机**：

1. **最小可行产品 → 证书的最小承载集 ≠ 模块全集**。v7 有 7 个硬门 + 6 个软因子 + DIM/DRC/DAC 三个重模块。但「安全证书」只由少数真正承担判定的门承载；其余门在可达域上可能被别的门「蕴含」——评估它们只是重复验证。MVP 的第一步不是加功能，而是找出**不可再约的证书核心**（minimal certificate core）。

2. **轻量化设计 → 六软因子乘积链其实是一个标量**。v7 的软评分是 ECS_v6·∏η_j、阈值是 τ_v6·∏η_j。数学上 ∏η_j 只是一个随上下文变化的标量 E(c)；对每个候选轨迹而言，真正逐候选变化的只有 η_g(x) 一项。把 6 次乘法折叠成「每上下文算一次 E、每候选只乘 1 次」，是**精确等价**的轻量化，不损失任何证书。

3. **MVP 需要行走骨架（walking skeleton）**。最小可部署闭环 = 七硬门全开 + 单标量预算 E + 冻结日志回放验收；先把「证书正确 + 延迟达标」跑通，再决定是否把 DIM/DRC/DAC 从离线诊断升级为在线依赖。

**关键洞见**：v7 回答「如何加更多保障」；本轮回答「哪些保障真正承担证书、哪些只是仪式」。核心命题：**证书的最小承载集由门之间的蕴含关系决定，而软因子链在观测上坍缩为一个上下文标量**。七硬门记号原样复用，本轮新增：

- IP-505 SKE（安全内核抽取：门蕴含 DAG + 惰性求值），
- IP-506 LBE（log 空间单标量预算评估器），
- IP-507 WSH（MVP 行走骨架与回放验收），
- IP-508 EFA-L（轻量装配器：SKE + LBE）。

**形式化目标（增量）**：

1. **SKE（Safety Kernel Extraction）**：<br>
   - 可达域 D；门 g_i: X×C→{0,1}，证书 C(x,c)=∧_{i=1}^7 g_i。<br>
   - 蕴含见证 W_j ⊆ G\{j}：∧_{i∈W_j} g_i ⇒_D g_j（在 D 上成立）。<br>
   - 惰性求值：按固定序评估；当 W_j 全部已评估且通过，跳过 g_j。<br>
   - 证书不变式：LazyEval_D(x,c) = FullEval(x,c)，∀(x,c)∈D。<br>
   - 域外（OOD）检测触发：关闭跳过、全门评估（fail-closed）。

2. **LBE（Log-space Budget Evaluator）**：<br>
   - 候选无关因子 η_1..η_m（每上下文一次），候选相关因子 η_g(x)。<br>
   - E(c) = ∏_{j=1}^m η_j(c)，β(c)=Σ ln η_j = ln E(c)。<br>
   - 阈值 τ_i^v7 = τ_i^v6·E(c)（逐上下文预计算一次）。<br>
   - 每候选评分 = ECS_v6·η_g(x)·E(c)：6 次乘法 → 1 次乘法。

3. **WSH（Walking Skeleton）**：<br>
   - 最小闭环：FMPP(K=4) + 七硬门全开 + E(c) + 冻结日志回放。<br>
   - 验收：证书一致率=100%、假接受率≤ε_fa、P99≤预算；全过才允许接入 DIM/DRC/DAC。<br>
   - MVP 范围声明：DIM/DRC/DAC 仅离线标定 E，不作为在线必需依赖。

4. **EFA-L（轻量装配器）**：<br>
   - select(x) = 先 OOD 检测 → 计算 E(c) → 惰性门评估（SKE）→ 每候选乘 η_g → 级联 VACK/BCK。<br>
   - 回退：OOD 或 E(c)∉[E_min,E_max] 时退回 v7 全量评估。

**本轮最大风险**：**冗余的分布依赖性**——门蕴含关系只在可达域 D 上成立；一旦分布漂移把某个「被蕴含的门」变成真正承重的门，惰性跳过就会把一次分布偏移静默地转化为证书破缺，除非 OOD 检测的召回率为 100%。

## 2. 关键算法骨架

### IP-505 SKE：门蕴含 DAG + 惰性求值

```python
@dataclass
class SafetyKernelExtractor:
    """SKE：利用门之间的蕴含见证，无损跳过重复评估。"""
    gates: dict[str, Callable]        # g_1..g_7
    witnesses: dict[str, list[str]]   # W_j: g_j 被哪些门合取蕴含
    order: list[str]                  # 固定评估序（拓扑序）
    delta_ood: float = 0.5

    def lazy_certify(self, x, c, ood_score) -> tuple[bool, list[str]]:
        if ood_score > self.delta_ood:            # fail-closed：域外全量
            return self.full_certify(x, c), list(self.gates)
        passed, evaluated = set(), []
        for j in self.order:
            W = self.witnesses.get(j, [])
            if W and all(w in passed for w in W):
                continue                          # 见证全通过 ⇒ 跳过 g_j
            evaluated.append(j)
            if not self.gates[j](x, c):
                return False, evaluated
            passed.add(j)
        return True, evaluated

    def full_certify(self, x, c) -> bool:
        return all(g(x, c) for g in self.gates.values())
```

### IP-506 LBE：log 空间单标量预算

```python
@dataclass
class LogSpaceBudgetEvaluator:
    """LBE：把 ∏η_j 折叠成每上下文一次计算的标量 E(c)。"""
    eps: float = 1e-8
    E_min: float = 1 / 1.3
    E_max: float = 1.3

    def budget(self, eta_ctx: dict[str, float]) -> tuple[float, float]:
        beta = sum(math.log(max(v, self.eps)) for v in eta_ctx.values())
        return beta, math.exp(beta)               # 每上下文一次

    def gate_threshold(self, tau_v6: float, gamma: float, E: float) -> float:
        return tau_v6 * gamma * E                 # 每候选 0 次额外乘法

    def score(self, ecs_v6: float, eta_g_x: float, E: float) -> float:
        return ecs_v6 * eta_g_x * E               # 6 次乘法 → 1 次

    def in_budget(self, E: float) -> bool:
        return self.E_min <= E <= self.E_max
```

### IP-507 WSH：MVP 行走骨架

```python
@dataclass
class WalkingSkeletonHarness:
    """WSH：先证明证书与延迟达标，再谈重模块上线。"""
    fmpp: FlowMatchingProposalPolicyKernel
    ske: SafetyKernelExtractor
    lbe: LogSpaceBudgetEvaluator
    replay: list[tuple]                       # 冻结日志 (x, c, label)
    eps_fa: float = 1e-3

    def accept(self, x, c, eta_ctx, eta_g_x) -> tuple[bool, str]:
        _, E = self.lbe.budget(eta_ctx)
        if not self.lbe.in_budget(E):
            return False, 'BUDGET_OUT_OF_RANGE'
        ok, _ = self.ske.lazy_certify(x, c, ood_score=0.0)
        return ok, 'MVP_ACCEPT' if ok else 'MVP_REJECT'

    def validate(self) -> dict:
        disagree = fa = 0
        for x, c, label in self.replay:
            ok_full = self.ske.full_certify(x, c)
            ok_lazy = self.ske.lazy_certify(x, c, 0.0)[0]
            disagree += (ok_full != ok_lazy)
            fa += (ok_lazy and not label)
        return {'cert_disagree': disagree, 'false_accept': fa / len(self.replay)}
```

### IP-508 EFA-L：轻量装配器

```python
@dataclass
class EvidenceForgingAssemblerLite:
    fmpp: FlowMatchingProposalPolicyKernel
    ske: SafetyKernelExtractor
    lbe: LogSpaceBudgetEvaluator
    ggc: GraspGeometryCutter
    mctm: MobileChassisTopologyMap
    stm: SemanticTrajectoryMapper
    v7: EvidenceForgingAssemblerV7           # 全量回退

    def select(self, L, t_now, context):
        ood = self._ood_score(context)
        eta_ctx = self._context_factors(context, L)   # topo/interp/cmd/demand/affect
        _, E = self.lbe.budget(eta_ctx)
        if ood > self.ske.delta_ood or not self.lbe.in_budget(E):
            return self.v7.select(L, t_now, context)  # fail-closed 全量

        q = self.stm.forward(L)
        cands = self.fmpp.propose(build_ctx(context, q), K=self.fmpp.K)
        surv = []
        for x in cands:
            if not self.ggc.filter(x):
                continue
            eta_g = self.ggc.quality_factor(x)
            ok, _ = self.ske.lazy_certify(x, context, ood)
            if ok:
                surv.append((x, self.lbe.score(1.0, eta_g, E)))
        if not surv:
            return False, None, 'LITE_EMPTY'
        return True, max(surv, key=lambda t: t[1])[0], 'FORGED_CGE_LITE'
```

### 集成流水线（v7 → EFA-L）

```
离线（一次性）：
  蕴含见证挖掘：在冻结日志上检验 ∧_{i∈W_j} g_i ⇒ g_j，产出 witnesses DAG
  预算标定：由 DIM/DRC/DAC 等重模块离线估计 η_ctx，校准 E_min/E_max
  回放验收：WSH.validate() 要求 cert_disagree=0 且 false_accept≤ε_fa

在线（每帧）：
  OOD(c) > δ_ood 或 E(c)∉[E_min,E_max] ──▶ v7 全量（fail-closed）
  否则：
    E(c) = exp(Σ ln η_ctx)             # 每上下文一次
    cands = FMPP.propose(...)
    for x: GGC.filter → SKE.lazy_certify → score = ECS_v6·η_g(x)·E(c)
    取最高分；为空则 LITE_EMPTY
```

## 4. 正确性论证

### 定理 13（惰性证书等价）

**陈述**：若对每个 j，见证 W_j 满足 ∧_{i∈W_j} g_i ⇒_D g_j，且上下文 c 在域内（OOD≤δ_ood），则 ∀(x,c)∈D：LazyEval_D(x,c) = FullEval(x,c)。

**证明**：按 order 归纳。被跳过的 g_j 满足 W_j 全部已评估且通过；由见证 ⇒_D，g_j(x,c)=1，与全量评估结果一致；未跳过者直接评估。故最终合取相同。∎

### 定理 14（预算坍缩的精确等价）

**陈述**：设候选无关因子为 η_1..η_m(c)、候选相关因子为 η_g(x)，E(c)=∏_{j=1}^m η_j(c)。则 ∀x：
- ECS_v7(x,c) = ECS_v6(x,c)·η_g(x)·E(c)，
- 对候选无关门 τ_i^v7 = τ_i^v6·E(c)。

**证明**：ECS_v7 定义为 ECS_v6·∏_{j=1}^6 η_j = ECS_v6·η_g(x)·∏_{j≠g} η_j(c) = ECS_v6·η_g(x)·E(c)；阈值同理。仅用乘法结合律，无近似。∎

**推论**：把 ∏η_j 换成标量 E(c) 不改变任何判定，仅把每候选 6 次乘法降为 1 次。

### 定理 15（MVP 的诚实权衡）

**陈述**：若 MVP 仅用廉价可观测因子构成 E_MVP，而 v7 的 E_v7 还含 DIM/DRC/DAC 信号，则证书一致（定理 13/14），但假拒绝率满足 FR_MVP − FR_v7 = ΔFR ≥ 0；ΔFR 是 MVP 为降低复杂度/延迟所付的「有用性税」。

**证明**：安全证书与因子无关的部分精确保持；被移除因子若携带区分真/假接受的信号，则其在 E 中的缺失只能把部分「本应接受」的候选推向拒绝，故 FR 单调不减。∎

### 诚实声明

- 定理 13 的成立**完全依赖**蕴含见证在 D 上为真；D 漂移即失效。
- 定理 14 是代数恒等式，与分布无关；但它只保证「等价」，不保证 v7 本身正确。
- 定理 15 说明 MVP 不是免费午餐：省下的复杂度以假拒绝率上升为代价，需在回放中量化 ΔFR。

## 5. 实验设计与验证计划（回放优先）

### 5.1 设计

- **数据**：冻结 v7 运行日志 50k 条（x, c, 七门结果, 六因子值, 最终标签）。
- **实验 A（证书等价）**：SKE 惰性求值 vs 全量，要求 cert_disagree=0；统计 Frontier 大小与节省的门评估次数。
- **实验 B（预算坍缩）**：逐条比较 ECS_v7 与 ECS_v6·η_g·E(c)，要求相对误差 < 1e-6；测 P99 延迟。
- **实验 C（因子消融 / MVP 选型）**：对 6 因子做子集消融，画「假接受率 vs 每候选成本」Pareto 前沿，选满足 ε_fa 的最便宜子集。
- **实验 D（域漂移）**：注入光照/布局/用户分布漂移，测 OOD 召回与「静默破缺率」（应为 0；若 >0 则 SKE 不可上线）。
- **实验 E（walking skeleton 端到端）**：仿真 + 实机各跑 1k 次，验收证书一致、ε_fa、P99。
