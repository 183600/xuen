# 第 62 轮（承接第 61 轮「具身语义进化闭环 ESEC」USR×MEL×DMS×SRT-Dual×PCE+++++；灵感循环第 1 轮；本轮灵感：「课程学习」×「视觉问答」）

> 第 61 轮把「场景/意图/阻抗/证据」统一进 USR，用 MEL 做零样本物理推断，用 DMS 做多轮对话，用 SRT-Dual 解耦语义流与实时流。但**信任建立、主动取证、漂移可证伪**三件事仍是空白：
> 1. **一步到位的信任悖论**：MEL 的零样本先验一次性注入 K_safe^mel，没有「逐级建立信任」的过程；一个新场景的第一次接触就可能越过安全边界。
> 2. **语义理解的只读困境**：MEL 被动消费 (V,T,P,L)，不能主动换视角、不能主动提问；遮挡/反光/未知材质下「猜」往往不如「问」。
> 3. **自信地错的不可观测性**：XMC+++ 只能在已知模态之间对账；若场景嵌入与真实物理**一致地错**（confidently wrong），对账发现不了——需要**可证伪探针**。

## 0. 直觉与动机

**灵感 1（课程学习 → 风险课程阶梯 RCL + 课程化执行调度 CES）**
直觉：课程学习（Curriculum Learning）的本质不是「先易后难地训练」，而是「**在能力边界附近持续施压**」（最近发展区）。把这个思想从训练搬到**部署**：机器人不应一上来就执行最高性能/最高风险的动作，而应沿一条**风险课程阶梯**逐级上升——每一级是「更激进、但仍在安全集内」的力/速度/刚度参数；只有当上一级的证书连续通过，才解锁下一级。关键洞见：**难度不是任务的固有属性，而是「场景难度 D」与「当前能力 C_comp」之差**；课程调度就是在 `D - C_comp ∈ [δ_lo, δ_hi]` 的最近发展区内选下一级。

**灵感 2（课程学习 → 问题课程 CQV 与 MEL 训练课程 TCVQ）**
直觉：课程也直接作用于「问题」本身。VQA 问题有难易：「这是什么颜色」易于「它能否承受 8N 而不破裂」。推理期应**只问与当前 VQA 能力匹配的问题**（问了白问、或答案不可信都是浪费）；训练期用「由易到难的问题课程」微调 MEL 的物理属性头，再用「反课程（anti-curriculum）」做消融，检验课程收益不是难度偏差造成的假象。

**灵感 3（视觉问答 → 具身视觉问答 EVQA 与主动提问管理 AQM）**
直觉：VQA 不应是「离线评测集上的问答」，而应是**闭环中的主动感知动作**：机器人可以 (i) 移动视角、改变光照、拨开遮挡以获得更可判读的图像；(ii) 针对高不确定的物理属性（摩擦、刚度、脆性）生成**最小充分问题**。核心是 **VOI 驱动的提问选择**：`q* = argmax_q [关于 φ_phys / 安全边际的期望信息增益 − 提问成本]`，把「问问题」纳入认知预算——**提问是一种可计价的认知动作**。

**灵感 4（视觉问答 → 可证伪探针 VCR + XMC++++ 语义对账）**
直觉：真正能发现「自信地错」的，不是把同一个问题再问一遍，而是问**应当满足特定一致性关系的问题族**：(i) 释义不变性——「表面滑吗」与「摩擦大不大」答案应一致；(ii) 反事实可翻转性——「干燥时滑吗」与「浇水后滑吗」答案应相反；(iii) 跨模态可核验性——VQA 答「光滑玻璃」而触觉证据给出高摩擦，则判为语义漂移。把这些一致性打包成 **VQA 一致性证书 C_vqa**，直接注入第 61 轮 J_sem_exec，形成**可证伪的语义安全护栏**。

**灵感 5（双灵感合流 → 证书门控课程 + 八维预算 + CVES 闭环）**
直觉：课程（往上走）与 VQA（往深看）是同一枚硬币——**课程决定「下一步挑战什么」，VQA 决定「我们对当前场景到底懂不懂」**。二者通过证书耦合：只有 VQA 一致性达标且执行证据支持，课程才允许升级；一旦 VQA 探针报警，课程立即降级（安全优先的非对称迟滞）。预算从第 61 轮 B_cog5（实为六分量）扩展为八维 B_cog8，新增 **B_curr（课程探索预算）** 与 **B_vqa（提问预算：问题数 / VLM 调用 / 人类注意力）**。

## 1. 形式化定义（增量：定义 173–184）

**定义 173（难度-能力估计器 DCE, Difficulty-Competence Estimator）** DCE = (Est_D, Est_C, ZPD, 𝒫_proto)。其中：
- **场景-任务难度**：`Est_D: Z_scene × T × P_req → [0,1]`
  ```
  D(s,t,p) = σ( w_D^T [ novel(z_scene), 1-conf_phys, c_task(t), p/p_max ] )
  novel(z) = min_{i≤N_proto} sqrt( (z-z_i)^T Σ_i^{-1} (z-z_i) ) / sqrt(d_us)
  ```
  其中 `𝒫_proto = {(z_i, Σ_i)}` 是 USR 中的场景原型（可在运行中增删），`conf_phys` 来自 MEL 的物理置信度。
- **能力估计**：用执行证据维护 Beta 后验 `Beta(α,β)`（成功 +1；滑移/超限/振动按 `β_pen` 惩罚），并取**保守下置信界（LCB）**，再做语义一致性修正：
  ```
  C_base = α/(α+β)
  C_lcb  = max(0, C_base - κ·sqrt(C_base(1-C_base)/(α+β+1)))
  C_comp = C_lcb · exp(-λ_e·e_proj - λ_u·U_epistemic)
  ```
  **保守偏置是硬要求**：宁可低估能力、慢一点升级，也不可高估能力、提前越界。
- **最近发展区**：`ZPD = [δ_lo, δ_hi]`，默认 `δ_lo=0.05, δ_hi=0.25`。

**定义 174（风险课程阶梯 RCL, Risk Curriculum Ladder）** 设性能水平 `p ∈ [0,1]`（力设定、速度、刚度缩放等的单调标量），安全可行集为
```
S(p) = { K ∈ 𝒦 : perf(K) ≥ p ∧ margin(K; φ_phys) ≥ m_min }
```
- **单调嵌套**：`p_1 ≤ p_2 ⇒ S(p_1) ⊇ S(p_2)`。越往上，可行集越小、越贴近安全边界。
- **课程阶梯**：`p_1 < p_2 < … < p_L`，第 ℓ 级 `C_ℓ = S(p_ℓ)`，难度 `d_ℓ = D(·, p_ℓ)` 关于 ℓ 单调不减。
- **回退可行性**：`ℓ' < ℓ ⇒ C_ℓ ⊆ C_{ℓ'}`，因此**任何时候回退到低一级都必定可行**（安全方向单调）。
- **升级门槛**：第 ℓ 级携带证书要求 `(τ_vqa^ℓ, k_promo^ℓ, ε_proj^ℓ)`，逐级可不同（越往上越严）。

**定义 175（课程化执行调度器 CES, Curriculum Execution Scheduler）** CES = (S_ces, A_ces, π_ces, Inv)。其中：
- **状态**：`s_ces = (ℓ_t, D_t, C_comp_t, streak_t, C_vqa_t, anchor_version_t)`
- **动作**：`A_ces = {promote, stay, demote(Δ)}`；promote/demote 通过写入**语义锚点的新版本**（复用 SACP 的 CAS 写入）生效，因此课程切换是**慢执行器**，永不进入实时环。
- **策略**（非对称迟滞）：
  ```
  demote  if safety_event ∨ ¬Valid(J_sem_exec) ∨ C_vqa < τ_vqa^- ∨ D_ℓ > C_comp + δ_max
  promote if Valid(J_sem_exec) ∧ C_vqa ≥ τ_vqa^+ ∧ streak ≥ k_promo
            ∧ D_{ℓ+1} ≤ C_comp + δ_hi
  stay    otherwise
  ```
  其中 `τ_vqa^- < τ_vqa^+`，**降级看瞬时、升级看连续**。
- **不变式 Inv**：任意时刻 `K_t ∈ C_{ℓ_t}` 且 `ℓ_{t+1}` 只能由上述规则改变。

**定义 176（具身视觉问答 EVQA, Embodied Visual Question Answering）** EVQA = (𝒱_views, 𝒬, VLM, ActivePerc)。其中：
- **视角集合** `𝒱_views`（相机位姿/光照/拨开遮挡），**主动感知** `ActivePerc: 𝒱_views × Scene → Image`
- **问题库** `𝒬 = 𝒬_phys ∪ 𝒬_sem ∪ 𝒬_safe`，每题带答案空间 `A_q`、释义集 `P(q)`、反事实对 `Cf(q)`
- **问答算子**：`Ask(v,q) → (a, p(a|v,q), c)`，`c = max_a p(a|v,q)` 为置信度
- **证据化**：答案 `(a, c, v, q)` 经 `E_evidence` 编码写入 USR，作为新的多模态证据；**只影响语义流与课程，不直接影响实时 K**。

**定义 177（主动提问管理 AQM, Active Question Manager）** 在物理属性信念 `b(φ)`（离散分箱或高斯）上定义：
```
VOI(q,v) = H(b) − E_{a~p(·|v,q)}[ H(b | a) ] − λ_cost·cost(q,v)
q* = argmax_{(v,q)∈𝒱_views×𝒬} VOI(q,v)
s.t. cost(q*,v*) ≤ B_vqa.remaining
```
- **安全关键覆盖**：`𝒬_safe` 中的问题（如「当前接触区域是否锐利/带电/过热」）**无条件强制提问**，不受 VOI 截断。
- **停止条件**：`max VOI < θ_voi` 或 `B_vqa` 耗尽。

**定义 178（VQA 一致性证书 VCR, VQA Consistency Certificate）**
```
C_vqa = w1·C_para + w2·C_counter + w3·C_cross + w4·C_calib ∈ [0,1]
C_para    = (1/|P(q)|)·Σ_{q'∈P(q)} 1[ a(q') = a(q) ]              # 释义不变性
C_counter = (1/|Cf(q)|)·Σ_{(q⁺,q⁻)} 1[ a(q⁺) ≠ a(q⁻) 符合预期翻转 ]  # 反事实可翻转性
C_cross   = (1/|𝒬_cross|)·Σ 1[ a(q) 与 telemetry/触觉导出的标签一致 ] # 跨模态可核验性
C_calib   = 1 − ECE(confidence)                                    # 置信度校准
Valid_vqa ⇔ C_vqa ≥ τ_vqa
```
关键：VCR 是**可证伪的**——释义不一致、反事实不翻转、跨模态矛盾，任一条都能把「自信地错」暴露出来。

**定义 179（问题课程 CQV 与训练课程 TCVQ）**
- **问题难度** `d_q = 1 − accuracy_hist(q)`（或模型 margin 的补），按历史滚动更新。
- **推理期自步（self-paced）**：仅当 `d_q ≤ f(C_vqa)` 才把 q 纳入候选（`f` 单调递增），避免「问了也白问」；当能力上升后自动开放更难问题。
- **训练期 TCVQ**：样本按 `d` 升序分阶段喂入；第 t 阶段损失
  ```
  ℒ_TCVQ = Σ_i w_t(d_i)·ℓ(MEL(x_i), y_i),  w_t(d)=1 if d≤θ_t else 0（硬课程）
  ```
  并设 **anti-curriculum 对照组**（降序/随机），用于排除「难度分布本身带来的偏差」。

**定义 180（证书门控课程 CVG, Certificate-gated Curriculum）** 升级算子：
```
promote: ℓ → ℓ+1  iff  Valid(J_sem_exec) ∧ Valid_vqa ∧ streak ≥ k_promo ∧ D_{ℓ+1} ≤ C_comp + δ_hi
```
**安全不变式（Safety Invariant）**：`∀t, K_t ∈ C_{ℓ_t}`，且 `ℓ` 的每次增加都伴随一份**已核验**的 `J_sem_exec`。CVG 的意义是把「信任」变成**可累积、可撤销的证书状态**，而不是一次性的模型自信。

**定义 181（八维认知-语义-课程预算 PCE++++++）**
> 注：第 61 轮符号称「五维 B_cog5」但实际列出六个分量，本轮统一修正为八维 `B_cog8`。
```
B_cog8 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_curr, B_vqa)
B_curr = (L_max, exploration_episodes, rollback_budget, k_promo, k_recover)
B_vqa  = (n_q_per_episode, vlm_calls, human_attention_sec, active_view_budget)
cost_cog8 = Σ_{前六维} cost_i + λ_curr·(promotions/L_max + rollback_used/rollback_budget)
                               + λ_vqa·(questions/n_q + vlm_latency/τ_vlm)
```
- **降级**：
  - `B_vqa` 耗尽 ⇒ 仅保留 `𝒬_safe` 强制问题，冻结课程升级（**降级的是探索，不是安全**）。
  - `B_curr` 耗尽 ⇒ 冻结在当前已认证级 `ℓ_t`，不再 promote。
  - 任一预算耗尽都**不降低 ERTC 的安全约束下界**。

**定义 182（课程回滚与迟滞 CRH, Curriculum Rollback with Hysteresis）**
```
ℓ_{t+1} = clamp(ℓ_t − Δ_demote, 1, ℓ_t)        若失稳事件
ℓ_{t+1} = min(ℓ_t + 1, ℓ_max^cert_t)          若连续 k_promo 次 Valid_vqa ∧ Valid(J)
```
- **迟滞带**：`τ_vqa^- < τ_vqa^+`，防止在阈值附近抖动。
- **恢复代价**：降级后重新升到历史最高级需 `k_recover ≥ k_promo` 次连续通过，并消耗 `rollback_budget` 的可审计记录。
- **振荡有界**：单位时间内升级次数受 `B_curr.exploration_episodes` 限制，降级次数受 `rollback_budget` 记录（不阻断安全降级）。

**定义 183（VQA 增强的语义漂移检测 XMC++++）** 在第 61 轮 `D⁺_sem` 上增加可证伪项：
```
D⁺_vqa = D_KL( p_vqa(φ) ‖ p_telemetry(φ) ) + (1 − C_vqa)
C_sem^+ = exp( −(D⁺_sem + λ_v·D⁺_vqa) / σ_sem ) ∈ [0,1]
trigger: D⁺_vqa > τ_drift  ⇒  强制 MEL 换视角重推理 + 触发 DMS 澄清
```
若 VQA 与触觉/力/IMU 导出的物理标签持续矛盾，`C_sem^+` 下降，`J_sem_exec` 失效，课程**自动降级**——这就把「语义漂移」从不可观测变成可观测、可触发动作。

**定义 184（CVES 统一闭环：课程-VQA 门控的具身语义进化）**
```
CVES = RealtimePipeline ∘ CVG ∘ (EVQA/AQM → USR) ∘ CES ∘ ESEC
```
即：`ESEC` 负责「场景→语义→阻抗→执行→证据」的语义进化；`CES` 在能力边界上选课程级；`EVQA/AQM` 在语义流内主动取证；`CVG` 用证书决定「升/降/停」；`SRT-Dual` 保证提问延迟永不进入实时环。

### IP-185 DCE（难度-能力估计器）

```python
class DifficultyCompetenceEstimator:
    def __init__(self, d_us=256, kappa=1.0, delta_lo=0.05, delta_hi=0.25,
                 lambda_e=2.0, lambda_u=1.0, beta_pen=3.0):
        self.d_us, self.kappa = d_us, kappa
        self.delta_lo, self.delta_hi = delta_lo, delta_hi
        self.lambda_e, self.lambda_u = lambda_e, lambda_u
        self.beta_pen = beta_pen
        self.protos = []                      # [(z_i, Sigma_i)]
        self.alpha, self.beta = 1.0, 1.0      # Beta 后验
        self.w_D = np.array([0.35, 0.25, 0.25, 0.15])

    def novelty(self, z_scene):
        if not self.protos:
            return 1.0
        d = [mahalanobis(z_scene, mu, Sig) for mu, Sig in self.protos]
        return float(min(d)) / np.sqrt(self.d_us)

    def estimate_difficulty(self, z_scene, c_task, phi_phys, p_req, p_max=1.0):
        conf_phys = phi_phys[-1]
        feat = np.array([self.novelty(z_scene), 1.0 - conf_phys,
                         c_task, p_req / p_max])
        return float(sigmoid(self.w_D @ feat))

    def update_competence(self, success, e_proj, U_ep):
        if success:
            self.alpha += 1.0
        else:
            self.beta += self.beta_pen
        base = self.alpha / (self.alpha + self.beta)
        var = base * (1 - base) / (self.alpha + self.beta + 1)
        lcb = max(0.0, base - self.kappa * np.sqrt(var))   # 保守下界
        return lcb * np.exp(-self.lambda_e * e_proj - self.lambda_u * U_ep)

    def in_zpd(self, d):
        return (d - self.C_comp) <= self.delta_hi

    def select_rung(self, rungs, C_comp):
        self.C_comp = C_comp
        feasible = [l for l in rungs if self.in_zpd(l.difficulty)]
        if not feasible:
            return rungs[0]                 # 全部过难：回到最低级
        return max(feasible, key=lambda l: l.performance)
```

### IP-187 CES（课程化执行调度器）

```python
class CurriculumExecutionScheduler:
    def __init__(self, usr, tau_vqa_lo=0.55, tau_vqa_hi=0.75,
                 k_promo=3, k_recover=5, delta_demote=1):
        self.usr = usr
        self.tau_lo, self.tau_hi = tau_vqa_lo, tau_vqa_hi
        self.k_promo, self.k_recover = k_promo, k_recover
        self.delta_demote = delta_demote
        self.streak, self.hist_max, self.recover_cnt = 0, 1, 0

    def step(self, ell, D_next, C_comp, J_valid, C_vqa, safety_event):
        # —— 安全优先：任何失稳立即降级，不等连续计数 ——
        if safety_event or (not J_valid) or (C_vqa < self.tau_lo):
            new = max(1, ell - self.delta_demote)
            self.streak, self.recover_cnt = 0, 0
            return self._commit(new)

        # —— 升级：必须连续 k_promo 次且落在 ZPD ——
        can = (C_vqa >= self.tau_hi) and (D_next <= C_comp + self.delta_hi())
        self.streak = self.streak + 1 if can else 0
        need = self.k_promo if ell >= self.hist_max else self.k_recover
        if self.streak >= need and ell < self.L:
            self.streak = 0
            new = ell + 1
            self.hist_max = max(self.hist_max, new)
            return self._commit(new)
        return self._commit(ell)

    def _commit(self, new_ell):
        # 课程级本身是语义锚点的一个字段；CAS 写入，实时流非阻塞读取
        self.usr.set_rung(new_ell)          # version++
        return new_ell

    def delta_hi(self):
        return 0.25
```

```python
class EmbodiedVQA:
    def __init__(self, vlm, question_bank):
        self.vlm = vlm
        self.Q = question_bank
        self.ece = 0.0                       # 由在线校准集滚动估计

    def ask(self, view, q):

class ActiveQuestionManager:
    def __init__(self, evqa, lambda_cost=0.2, theta_voi=0.05):
        self.evqa, self.lam, self.theta = evqa, lambda_cost, theta_voi

    def info_gain(self, belief, view, q):
        h0 = entropy(belief)
        h1 = 0.0
        for a, p in self.evqa.predict(view, q).items():   # 不真正渲染，先解析预测
            h1 += p * entropy(self.evqa.bayes_update(belief, q, a))
        return h0 - h1

    def choose_and_ask(self, views, belief, budget):
        asked = []
        # 1) 安全关键问题：无条件、优先
        for q in self.evqa.Q.safe:
            if budget.can_afford(q, views[0]):
                belief, a, c = self._ask(views[0], q, belief, budget)
                asked.append((q, a, c))
        # 2) VOI 贪心（𝒬 可视为近子模，贪心有 (1-1/e) 近似）
        while budget.remaining > 0:
            best, best_voi = None, -np.inf
            for v in views:
                for q in self.evqa.Q.phys + self.evqa.Q.sem:
                    if not self.evqa.applicable(q, belief):
                        continue
                    voi = self.info_gain(belief, v, q) - self.lam * budget.cost(v, q)
                    if voi > best_voi:
                        best, best_voi = (v, q), voi
            if best is None or best_voi < self.theta:
                break
            belief, a, c = self._ask(best[0], best[1], belief, budget)
            asked.append((best[1], a, c))
        return belief, asked

    def _ask(self, view, q, belief, budget):
        a, pa, c = self.evqa.ask(view, q)
        budget.spend(q, view)
        return self.evqa.bayes_update(belief, q, a, pa), a, c
```

```python
class VQAConsistencyCertificate:
    def __init__(self, evqa, w=(0.25, 0.30, 0.30, 0.15), tau=0.70):
        self.evqa, self.w, self.tau = evqa, w, tau

    def score(self, img, q, telemetry_labels):
        a, _, _ = self.evqa.ask(img, q)
        c_para = np.mean([1.0 if self.evqa.ask(img, qp)[0] == a else 0.0
                          for qp in q.paraphrases])
        flips = [self.evqa.ask(img, qp)[0] for qp in q.counterfactual]
        c_counter = np.mean([1.0 if flips[2*i] != flips[2*i+1] else 0.0
                             for i in range(len(flips) // 2)])
        c_cross = self._cross_modal(a, telemetry_labels)
        c_calib = 1.0 - self.evqa.ece
        c = float(np.dot(self.w, [c_para, c_counter, c_cross, c_calib]))
        return c, dict(para=c_para, counter=c_counter, cross=c_cross, calib=c_calib)

    def valid(self, c):
        return c >= self.tau
```

### IP-185 DCE（难度-能力估计器）

```python
class DifficultyCompetenceEstimator:
    def __init__(self, d_us=256, kappa=1.0, delta_lo=0.05, delta_hi=0.25,
                 lambda_e=2.0, lambda_u=1.0, beta_pen=3.0):
        self.d_us, self.kappa = d_us, kappa
        self.delta_lo, self.delta_hi = delta_lo, delta_hi
        self.lambda_e, self.lambda_u = lambda_e, lambda_u
        self.beta_pen = beta_pen
        self.protos = []                      # [(z_i, Sigma_i)]
        self.alpha, self.beta = 1.0, 1.0
        self.w_D = np.array([0.35, 0.25, 0.25, 0.15])
        self.C_comp = 0.0

    def novelty(self, z_scene):
        if not self.protos:
            return 1.0
        d = [mahalanobis(z_scene, mu, Sig) for mu, Sig in self.protos]
        return float(min(d)) / np.sqrt(self.d_us)

    def estimate_difficulty(self, z_scene, c_task, phi_phys, p_req, p_max=1.0):
        feat = np.array([self.novelty(z_scene), 1.0 - phi_phys[-1],
                         c_task, p_req / p_max])
        return float(sigmoid(self.w_D @ feat))

    def update_competence(self, success, e_proj, U_ep):
        self.alpha += 1.0 if success else 0.0
        self.beta += 0.0 if success else self.beta_pen
        base = self.alpha / (self.alpha + self.beta)
        var = base * (1 - base) / (self.alpha + self.beta + 1)
        lcb = max(0.0, base - self.kappa * np.sqrt(var))       # 保守下界
        self.C_comp = lcb * np.exp(-self.lambda_e * e_proj - self.lambda_u * U_ep)
        return self.C_comp

    def select_rung(self, rungs):
        feasible = [l for l in rungs if (l.difficulty - self.C_comp) <= self.delta_hi]
        return max(feasible, key=lambda l: l.performance) if feasible else rungs[0]
```

```python
class RiskCurriculumLadder:
    """p_1 < ... < p_L；C_l = S(p_l)；S(p_1) ⊇ S(p_2) ⊇ ..."""
    def __init__(self, p_levels):
        self.rungs = [Rung(performance=p, constraints=S(p)) for p in p_levels]

    def contains(self, ell, K):
        return margin(K) >= m_min and perf(K) >= self.rungs[ell].performance

    def clamp(self, ell, K):
        """把任意 K 投影回当前课程级 C_ell（嵌套 ⇒ 回退必可行）"""
        return project_to_S(self.rungs[ell], K)


class CurriculumExecutionScheduler:
    def __init__(self, usr, L, tau_vqa_lo=0.55, tau_vqa_hi=0.75,
                 k_promo=3, k_recover=5, delta_hi=0.25):
        self.usr, self.L = usr, L
        self.tau_lo, self.tau_hi = tau_vqa_lo, tau_vqa_hi
        self.k_promo, self.k_recover, self.delta_hi = k_promo, k_recover, delta_hi
        self.streak, self.hist_max, self.recover_cnt = 0, 1, 0

    def step(self, ell, D_next, C_comp, J_valid, C_vqa, safety_event):
        # 安全优先：任何失稳/证书失效/漂移告警 ⇒ 立即降级
        if safety_event or (not J_valid) or (C_vqa < self.tau_lo):
            self.streak, self.recover_cnt = 0, 0
            return self._commit(max(1, ell - 1))

        can = (C_vqa >= self.tau_hi) and (D_next <= C_comp + self.delta_hi)
        self.streak = self.streak + 1 if can else 0
        need = self.k_promo if ell >= self.hist_max else self.k_recover
        if self.streak >= need and ell < self.L:
            self.streak = 0
            self.hist_max = max(self.hist_max, ell + 1)
            return self._commit(ell + 1)
        return self._commit(ell)

    def _commit(self, new_ell):
        self.usr.set_rung(new_ell)     # 语义锚点 CAS 写入，version++；慢执行器
        return new_ell
```

```python
    def info_gain(self, belief, view, q):
        h0 = entropy(belief)
        return h0 - sum(p * entropy(self.evqa.bayes_update(belief, q, a))
                        for a, p in self.evqa.predict(view, q).items())

    def choose_and_ask(self, views, belief, budget):
        asked = []
        # 1) 安全关键问题：无条件、优先（永不被 VOI 截断）
        for q in self.evqa.Q.safe:
            if budget.can_afford(q, views[0]):
                belief, a, c = self._ask(views[0], q, belief, budget)
                asked.append((q, a, c))
        # 2) VOI 贪心；𝒬 近子模 ⇒ 贪心 ≥ (1−1/e)·OPT
        while budget.remaining > 0:
            best, best_voi = None, -np.inf
            for v in views:
                for q in self.evqa.Q.phys + self.evqa.Q.sem:
                    if not self.evqa.applicable(q, belief):
                        continue
                    voi = self.info_gain(belief, v, q) - self.lam * budget.cost(v, q)
                    if voi > best_voi:
                        best, best_voi = (v, q), voi
            if best is None or best_voi < self.theta:
                break
            belief, a, c = self._ask(best[0], best[1], belief, budget)
            asked.append((best[1], a, c))
        return belief, asked

    def _ask(self, view, q, belief, budget):
        a, pa, c = self.evqa.ask(view, q)
        budget.spend(q, view)
        return self.evqa.bayes_update(belief, q, a, pa), a, c
```

### IP-190 VCR（VQA 一致性证书）

```python
class VQAConsistencyCertificate:
    def __init__(self, evqa, w=(0.25, 0.30, 0.30, 0.15), tau=0.70):
        self.evqa, self.w, self.tau = evqa, w, tau

    def score(self, img, q, telemetry_labels):
        a = self.evqa.ask(img, q)[0]
        c_para = np.mean([self.evqa.ask(img, qp)[0] == a for qp in q.paraphrases])
        flips = [self.evqa.ask(img, qp)[0] for qp in q.counterfactual]
        c_counter = np.mean([flips[2*i] != flips[2*i+1]
                             for i in range(len(flips) // 2)])
        c_cross = self._cross_modal(a, telemetry_labels)
        c_calib = 1.0 - self.evqa.ece
        c = float(np.dot(self.w, [c_para, c_counter, c_cross, c_calib]))
        return c, dict(para=c_para, counter=c_counter, cross=c_cross, calib=c_calib)

    def valid(self, c):
        return c >= self.tau
```

```python
def self_paced_question_filter(Q, C_vqa, f):
    """推理期：只问 d_q <= f(C_vqa) 的问题，能力升则开放难题"""
    return [q for q in Q if q.difficulty <= f(C_vqa)]

def tcvq_train(mel, dataset, stages):
    """训练期：按难度升序分阶段；对照 anti-curriculum（降序）与 random"""
    order = sorted(dataset, key=lambda x: x.difficulty)
    for t, theta in enumerate(stages):
        batch = [x for x in order if x.difficulty <= theta]
        loss = sum(w(d) * ce(mel(x), y) for x, y in batch for d in [x.difficulty])
        mel.update(loss)
    return mel
```

### IP-192 CVG + CRH（证书门控课程 + 迟滞回滚）

```python
class CertificateGatedCurriculum:
    def __init__(self, ladder, ces, tau_vqa=0.70, k_promo=3, k_recover=5):
        self.ladder, self.ces = ladder, ces
        self.tau_vqa, self.k_promo, self.k_recover = tau_vqa, k_promo, k_recover

    def gate(self, ell, J, C_vqa, D_next, C_comp):
        # promote 需要「连续」证据；demote 只需单次失效（安全优先）
        if (J.valid and C_vqa >= self.tau_vqa
                and D_next <= C_comp + self.ces.delta_hi):
            self.ces.streak += 1
        else:
            self.ces.streak = 0
        if not J.valid or C_vqa < self.ces.tau_lo:
            return max(1, ell - 1), 'demote'
        if self.ces.streak >= self.k_promo and ell < len(self.ladder.rungs):
            return ell + 1, 'promote'
        return ell, 'stay'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DCE | O(N_proto·d_us²) | O(N_proto·d_us²) | 难度单调；能力 LCB 保守 |
| RCL | O(L) | O(L·|𝒦|) | `S(p₁)⊇S(p₂)`，回退必可行 |
| CES | O(1)/步 | O(1) | 升级须 Valid(J)∧Valid_vqa；降级瞬时 |
| EVQA | ~50-200ms/问（VLM） | O(|𝒱|·|𝒬|) | 答案校准 ECE≤0.05 |
| AQM | O(|𝒱|·|𝒬|·|A|) | O(|𝒬|) | 贪心 VOI ≥ (1−1/e)·OPT（近子模） |
| VCR | O((|P|+|Cf|+|𝒬_cross|)·VLM) | O(|𝒬|) | C_vqa∈[0,1]，可证伪 |
| CVG/CRH | O(1)/步 | O(1) | `K_t∈C_{ℓ_t}`，振荡有界 |
| PCE++++++ | O(1) | O(1) | 预算单调，安全下界不降 |

**正确性定理（CVES-Safe）**：在 A61–A76 下（A71 DCE 保守 LCB；A72 RCL 单调嵌套 + 可行判定；A73 EVQA 校准且问题覆盖 φ_phys；A74 VCR 对漂移 >δ 有检测功效 ≥1−β、误报 ≤α；A75 VOI 近子模；A76 CVG 迟滞 + 即时降级、预算单调），有：
1. **课程安全不变式**：`∀t, K_t ∈ C_{ℓ_t}`；未通过证书的升级概率 ≤ α。
2. **单调进展 / 有界振荡**：非失稳时 rung 单调不减；失稳立即降级，恢复需 `k_recover` 次连续通过；单位时间振荡受 `B_curr` 约束。
3. **漂移可观测**：语义漂移 >δ ⇒ `D⁺_vqa>τ_drift` 以功效 ≥1−β 触发降级与 MEL 重推理，`C_sem^+` 同步下降。
4. **提问效率**：VOI 贪心累计信息增益 ≥ (1−1/e)·OPT，问题数 ≤ `B_vqa`；耗尽后仅保留安全关键问题并冻结升级。
5. **实时隔离**：VQA/MEL 延迟不进入实时环，实时周期仍 ≤ 1ms（不含 EEIS 优化）。

| 实验 | 指标 | 目标 |

**可复现实验协议建议**：在 3 类材质（刚性/柔性/脆性）× 3 类几何（平面/曲面/复合）× 2 类动态（静态/移动）共 18 个场景族上做 leave-one-family-out（零样本）；难度分级用 `p_ℓ ∈ {0.3,0.5,0.7,0.85,0.95,1.0}`；每组 5 个随机种子，报告均值 ± 95% CI；消融为「去掉 RCL（直接最高级）」「去掉 VCR（仅置信度）」「去掉 AQM（均匀提问）」「TCVQ → anti-curriculum」。

## 5. 本轮最大风险

**一句话**：若 DCE 系统性高估能力、且「问题课程」退化为「只问自己会答的问题」的自我确认回路，则 `C_vqa` 长期虚高、课程在真实漂移下被误升级——即「课程与 VQA 合谋的自信幻觉」；必须以「非对称迟滞升级 + 留出对抗性 VQA 探针 + 安全关键问题强制提问 + 独立 telemetry 交叉核验」构建**反自我确认机制**，否则课程越顺、错得越深。
