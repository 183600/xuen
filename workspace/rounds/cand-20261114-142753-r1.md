# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「动态避障」×「研究空白」）

> R69 的 FLUID-RAS 把不确定性拆成 aleatoric / epistemic，用「流匹配多模态策略 + 主动交互」去消解后者，理论姿态漂亮：R68 是「永不交互」边界。但它悄悄假设了三件事：**（a）歧义在求证期间是静止的；（b）求证是廉价、瞬时、可随时完成的；（c）证书是关于「哪里安全」的正面断言，没说「哪里我根本没资格断言」**。
>
> 动态避障击穿 (a)(b)：障碍物在动，安全走廊以相对速度 v_close 收窄；询问/注视/探针/等待都要花时间，信息可能**在安全动作集分裂之后才到**——迟到的正确答案等于错误答案。研究空白击穿 (c)：真正诚实的系统不该只扩大「已证明」的版图，而要**把「无法证明」的版图显式画出来、移动它、避开它**。前者把「是否值得问」变成「是否还来得及问」；后者把证书从「正例集合」升级为「正例 + 反例（负证书）」。
>
> 核心命题：**把「信息价值」变成时敏的，把「研究空白」变成一等公民的几何对象——维护一张在线演化、可被证明的「空白图谱 G_t」，并把 G_t 当作与动态障碍同构的禁入区，做「物理避障 ∩ 认知避障」的对偶速度障碍闭环。** 命名 **GAP-RAS**（Gap-Aware Predictive risk-adaptive closed loop）。一句话：R69 问「我该向谁求证」，R70 问「**还来不来得及问，以及哪些地方我连问的资格都没有**」。

## 0. 直觉与动机

**灵感 1（动态避障 → 求证是一场与世界的赛跑）**
直觉：人在车流里不会停下来思考人生——不是因为不想，而是因为**思考的代价是位置**。R69 的 `VoI(g) = H(M|o) − E[H(M|o,y)]` 是一个「无限时视界」的量：它假设问完再动也来得及。但动态避障中，安全动作集 `A_safe(t)` 随障碍接近而收缩，存在一个**认知截止期** `τ_epi`：过了它，无论你最终选哪个模态，都已无法保持在安全集里。于是「值不值得问」必须乘上「信息能否在 τ_epi 前到达」——`VoI_τ = p_arr(τ_epi)·ΔH − c`。这不是给 R69 打个补丁，而是把信息论的「价值」从**存量**变成**流量**：信息的价值随截止期临近而蒸发。

**灵感 2（动态避障 → 等待也是信息动作，世界会免费泄题）**
直觉：在动态场景里，即使你什么都不做，障碍物也在**用运动暴露意图**：远处那团模糊是行人还是推车，走近两步就自己清楚了。这叫**自由信息**（free information）。所以 R69 的二选一「问 or 不问」其实是三选一：**问 / 等 / 直接保守行动**。等待没有社交成本，却有安全成本（消耗 τ_epi），而且可能被「假静止」骗（对方其实在蓄力）。把等待纳入动作集后，一个反直觉结论浮现：**当歧义会被世界自然揭开时，最优点往往是「不问，缓行观察」，而不是「追问」**——追问有时反而因社交停顿更危险。

**灵感 3（研究空白 → 证书的背面：负证书与空白图谱）**
直觉：R66–R69 每轮都在扩大「我能证明什么」；但从没有人正式记录「**我在哪里连证明的资格都没有**」。而工程事故恰恰发生在后者：不是证明了错，而是**把没证明的地方默认成了对**。研究空白给我的不是「再补一个模块」，而是一个本体论翻转：把不可判定区域 G 变成显式对象，配一张**负证书** N(s)：不仅说 s 不可证，还说**为什么不可证**（遮挡阴影 / 标定不可辨识 / 流似然 OOD / 截止期过短 / 模型失配）。只要 G 是**保守过近似**（宁可多报空白），系统就永不会发出假证书；代价只是可用性。这把安全性问题变成了可度量的「空白覆盖率」问题。

**灵感 4（动态避障 × 研究空白 → 双速度障碍：物理 VO ∩ 认知 EVO）**
直觉：速度障碍（VO）说「这些速度会在未来撞上那个移动体」；我们完全可以对**空白图谱**定义同构的**认知速度障碍 EVO**：「这些速度会在视界内把系统带进不可证区域」。于是允许速度集 = 物理自由与认知自由之交；规划器同时在**物理空间**和**证书空间**里避障。更强的是，`G_t` 会随障碍运动而移动——遮挡阴影随视角变化、截止期悬崖随 TTC 下移——所以这是「**动态障碍 × 动态空白**」的双动态问题，而不是静态禁区。研究空白第一次不是论文里的「future work」一句话，而是一个每秒都在移动、必须实时避开的物理量。

**灵感 5（研究空白 → 空白是可攻击的：把「不知道」武器化）**
直觉：一旦系统承认并依赖 `G_t`，攻击面就变了。对手不必让你相信假东西，只要**制造/放大空白**（伪造遮挡、注入 OOD、制造假紧迫）就能让你陷入「保守瘫痪」（可用性 DoS）；反过来，**抹掉真实空白**（让 `G_t` 漏报）则直接诱发假证书。所以 GAP-RAS 的安全论证必须区分两类错误：**假空白（只伤可用性）** 与 **假证书（伤安全）**，并用「只允许保守方向出错」的构造把前者变成可接受成本、把后者变成结构性不可能——除非空白本体论本身不完备。这正是「研究空白」的元层面风险：**你无法枚举你没想到的空白**。

**灵感 6（元：本轮真正要填的研究空白）**
直觉：把文献/前序工作摊开看，空白不是「没有动态避障」，也不是「没有主动感知」，而是三者交叉处的三条缝：(1) **没有时敏 VoI**——主动感知/交互决策几乎都假设信息在决策前可得；(2) **没有负证书/有效域边界**——安全论证只报正例，不显式刻画不可证域并在线维护；(3) **没有把动态避障与主动消歧放进同一个可达性问题的基准**。GAP-RAS 的贡献因此不是「又一层」，而是**把「来不及」和「证不了」这两件事变成同一张图上的可计算对象**。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（GAP-RAS 总览）** GAP-RAS = (EDC, GAP, EVO, T-MINT, GRC, FMP†, AUD†, FMA†, IBG†, VQAuditor-G, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **截止期不变式**：任何完成时间 `d(g)+latency` 超过 `τ_epi−ε_margin` 的信息动作不得被认证或执行；
(iii) **空白只向保守方向出错**：空白图谱 `G_t` 必须是真实不可证集的**过近似**（可多报，不可漏报）；
(iv) **双障碍不变式**：每个执行动作的（速度/轨迹）必须落在 物理自由集 `ℱ_t ∩ 证书有效域 V_t` 内，或显式触发「认证机动 / 安全停」这一被认证的离散回退。

**定义 311（动态障碍与可达集）** 障碍 `𝒪_i` 状态 `x_i(t)`，由 VISTA† 给出预测可达集 `R_i(t:t+H|o_t) ⊇ 真实占据`（A99：覆盖概率 ≥ `1−δ_pred`）。物理自由集 `ℱ_t = 𝒮 \ ⋃_i inflate(R_i, ρ_safe)`；相对接近速度 `v_close(t) = max_i −d/dt dist(ego, 𝒪_i)`；`TTC_i`。A100：ego 动力学在 H 上 Lipschitz、控制仿射。

**定义 312（证书有效域与空白图谱）** 给定证据 `e_t` 与假设集 A，**证书有效域** `V_t = {s ∈ 𝒮 : 在 A 下存在对安全谓词 φ 的证明，且证明只依赖 e_t}`。**空白图谱** `G_t = closure(𝒮 \ V_t)`，每个 `s∈G_t` 附**见证** `w(s) ∈ {occl, unident, ood, deadline, mismatch}`（遮挡 / 标定不可辨识 / 流似然 OOD / 截止期不足 / 模型失配）。**负证书** `N(s) = (s∈G_t, w(s), 证据哈希, 证明脚本)`。`G_t` 为过近似：`V_t ⊆ V_t^true`，故 `s∈V_t ⇒ s 可真证`——**只可能多报空白，不可能假证**。

**定义 313（认知截止期 τ_epi）** 对当前 `(s,e)` 与「未消解策略」`π_unres`（尚不知道该选哪个模态），`τ_epi = sup{Δ≥0 : 存在一条未消解但安全的执行，使 ∀δ≤Δ, s(t+δ) ∈ ℱ_{t+δ} ∩ V_{t+δ}，且各候选模态的安全分支尚未被迫收敛}`。直觉：**还能保持「不决定」而不出事的最长时间**；由「承诺前沿」（commitment frontier，安全动作集按模态分裂的首个时刻）与障碍闭合共同决定。

**定义 314（自由信息与等待动作）** 等待 `g_wait`：不施加社交动作，`d(g_wait)=δ_w`。自由信息增益 `I_free(δ_w) = H(M|o_t) − E[H(M|o_{t+δ_w})]`（世界靠运动自己泄题，可为负——新信息也可能制造新歧义）。等待成本 `c_wait = 安全裕度损耗 Δτ_epi + 机会成本`；`g_wait ∈ 𝒜_info`。

**定义 315（时敏 VoI：T-MINT）** `VoI_τ(g) = p_arr(g;τ_epi)·[H(M|o) − E_{y~p(·|g,o)}H(M|o,y)] − c(g) − r_motion(g) − I_free(δ_g)_discounted`，其中 `p_arr(g;τ_epi) = P(d(g)+latency ≤ τ_epi−ε_margin)`。在 `{gaze, probe, ask, wait, none}` 上取 `g* = argmax[VoI_τ − c]`；若 `max ≤ 0` 或所有 g 被截止期排除 → 不交互，进入 GRC 回退。

**定义 316（认知速度障碍 EVO）** 对空白区 `G_{t:t+H}` 与 ego 速度 v：`EVO_G = {v : ∃δ≤H, s+δv ∈ G_{t+δ}}`。**对偶速度障碍** `DVO_t = VO_phys(t) ∪ EVO_G(t)`；可行动速度集 `𝒱_allowed = 𝒱 \ DVO_t`。例外：若 v 的进入被一个**认证机动**伴随（定义 317），该方向可由「软 EVO」放行，但必须在进入前把对应见证消掉。

**定义 317（认证机动）** `c ∈ 𝒜_info` 为移动/观察以**主动缩小 G**（消除遮挡、增加可辨识性、降低 OOD 似然）的机动，自身须过 C-RAS-WM 认证。其价值 `GapRed(c) = |G_before| − |G_after|`；选择 `c* = argmax[GapRed(c) − r_motion(c)]`，且 `d(c) ≤ τ_epi`。这把「主动感知」和「动态避障」缝成一个动作：**先补证书，再走进去**。

**定义 318（双障碍规划 GRC）** 在 `(s, V-margin, τ_epi)` 的积空间上规划；目标为任务进度，约束为 `ℱ_t ∩ V_t` 与截止期。不可行时按**固定优先序**分层回退：
(1) 认证机动（尝试重建证书）→ (2) 若 τ_epi 尚够，问/等（尝试买时间）→ (3) R68 两级保守（`λ=λ_floor(U_ale+U_epi)`）→ (4) 认证安全停。该顺序把「先补证、再买时间、最后刹车」写成可审计状态机。

**定义 319（截止期一致的模态选择）** 模态 k 可执行 ⇔ 承诺时刻 `t_c(k) ≤ t+τ_epi` 且其轨迹使 `s ∈ ℱ∩V`。定义 deadline-aware 打分 `S_k = log ŵ_k − λ_risk·risk(ξ̄_k) − 𝟙[¬deadline-feasible]·∞`；取代 R69 的纯似然选择。系：FMP 的 K 自适应同时受 τ_epi 与 TTC 约束（定义 325）。

**定义 320（空白图谱的维护与时效）** 每个控制周期由见证源更新 `G_t`：遮挡阴影（几何视锥/射线）、不可辨识（标定雅可比秩/条件数）、OOD（FMA 的 a_score）、截止期悬崖（`τ_epi<τ_min`）、失配（r_res 与 Δa 联合）。空白有**时空衰减**：旧见证过期需重探，否则演化为「僵尸空白」（假空白）或「遗忘空白」（漏报）。

**定义 321（空白投毒与干扰集）** `ℰ_gap = {空白膨胀（伪造遮挡/OOD → 可用性 DoS）、空白抹除（抑制真实见证 → 假证书）、截止期欺骗（伪造紧迫感以压制询问）、共谋障碍（多个移动体协同逼出 deadline）}`。`AIC-GAP = AIC-FLUID × ℰ_gap`。

**定义 322（参与式审计 VQAuditor-G）** 新增审计对象：是否在 G 内/无认证进入 G、是否越过 τ_epi 仍执行、每个见证的作者与证据、假空白率、空白投毒迹象。审计结论回灌空白先验与 MINT 成本，形成跨轮学习（仍遵守零实时写）。

**定义 323（证书 J_GAP）** `J_GAP = (J_FLUID, τ_epi, deadline_margin, gap_atlas_hash, gap_coverage, false_gap_rate, evo_feasibility, cert_maneuver_log, gap_poison_flag, gap_ver)`。Valid ⇔ `Valid(J_FLUID) ∧ 执行路径 ⊆ ℱ∩V（或伴随认证机动的受控进入）∧ 截止期满足 ∧ 空白见证可审计`。

**定义 324（空白覆盖率与可用性代价）** `gap_coverage = |G_reported| / |G_true|（≥1，过近似）`；`false_gap_rate = |G_reported \ G_true| / |G_reported|`。**安全 ⇔ false-certificate = 0（构造保证）；可用性 = 1 − false_gap_rate**。GAP-RAS 的设计目标是把错误全部推到可用性轴，并把该代价显式记账，而不是偷偷用「默认安全」支付。

**定义 325（自适应视界与采样）** H 随 TTC 自适应：`v_close` 大 → H 短、K 小、N_step 小；`τ_epi` 小 → 放弃追问、直接回退。FMP 的 anytime 采样在边际 `VoI_τ < 边际时间成本` 时立即停止。P99 预算内同时约束 H、K、N_step。

**定义 326（退化与单调性）** 当 `v_close=0`、`G=∅`、`τ_epi=∞` 时，GAP-RAS 逐指令退化为 FLUID-RAS（进而 R68 的「永不交互」边界）。随 `v_close` 单调增加：`τ_epi` 单调不增、`p_arr` 单调不增、交互概率单调不增、`λ` 单调不减。⇒ 动态性只会让系统**更保守**，不会更冒险。

```python
# IP-264 EDC：认知截止期（承诺前沿 × 障碍闭合）
def epistemic_deadline(s, e, obs_pred, V, F, H):
    lo, hi = 0.0, H
    for _ in range(8):                       # 二分；未消解安全集单调收缩
        mid = 0.5*(lo+hi)
        if unresolved_policy_keeps_safe(s, mid, obs_pred, V, F):
            lo = mid
        else:
            hi = mid
    return lo                                # τ_epi

# IP-265 GAP：只向保守方向出错的空白图谱
def update_gap_atlas(s, o, e, calib, fma, tau_epi):
    G = {}
    G |= occlusion_shadow(s, o)              # 几何视锥/射线
    G |= unidentifiable(calib.jacobian)      # 秩亏 / 条件数
    G |= ood_flow(fma.a_score)               # 流似然 OOD
    G |= deadline_cliff(tau_epi)             # 来不及证
    G |= mismatch_band(M.last_r_res, fma.delta_a)
    return over_approximate(G)               # soundness-only：可多报

# IP-266 EVO：认知速度障碍（与物理 VO 取并）
def dual_velocity_obstacle(s, G, obs_pred, H):
    VO  = velocity_obstacles(obs_pred, H)
    EVO = {v for v in vel_grid if enters_gap(s, v, G, H)
           and not certifiable_entry(v, G)}
    return VO | EVO

# IP-267 T-MINT：时敏 VoI + 自由信息（问 / 等 / 走）
def choose_info_action(modes, w, s, tau_epi, budget):
    cands = info_action_candidates(modes) + [WAIT, NONE]
    best = None
    for g in cands:
        if d(g) + latency > tau_epi - MARGIN:               continue
        if g is not WAIT and not c_ras_wm.certify_info(g, s): continue
        p_arr = P_arrival(g, tau_epi)
        voi   = p_arr * (entropy(w) - expected_entropy(w, g, s))
        score = voi - cost(g) - motion_risk(g) - free_info_value(WAIT, s)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None        # 问不赢 → 回退

# IP-268 GRC：双障碍闭环（继承 R69，只加"来不来得及"与"证不证得了"）
def GAP_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    # 1) 两张图：时间图（τ_epi）与证书图（G_t）
    tau = M.edc.epistemic_deadline(s, o, M.vista.predict(), M.gap.V, M.phys.F, M.H)
    G   = M.gap.update(s, o, M.cof.evidence(), M.cof.calib, M.fma, tau)
    # 2) 双速度障碍：物理 VO ∪ 认知 EVO
    V_allowed = M.evo.dual_velocity_obstacle(s, G, M.vista.predict(), M.H)
    # 3) 时敏交互：问/等/走三选一（不再是"值不值"，而是"来不来得及"）
    g = M.tmint.choose_info_action(modes, U_epi, s, tau, M.budget)
    if g not in (None, WAIT, NONE):
        ans = M.cia.execute(g); U_epi = M.cia.update_belief(modes, ans)
    elif g is WAIT:
        pass                                        # 让世界免费泄题
    # 4) 截止期一致 + 证书一致的模态选择；否则分层回退
    mode = select_mode_deadline_aware(modes, U_epi, V_allowed, tau)
    if mode is None:
        c = choose_cert_maneuver(G, tau)             # 先补证
        mode = (select_mode_deadline_aware(modes, U_epi, V_allowed, tau)
                if c else None)
    if mode is None:
        lam = lam_floor(U_ale + U_epi)
        return M.grc.safe_stop(lam)                  # 最后刹车
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale))
    k   = M.c_ras_wm.certified_prefix(mode.a, ..., V_allowed, G)
    M.vqa_g.submit_async(g, tau, G, U_epi)
    return k, lam, mode, (U_ale, U_epi, tau)
```

## 3. 推导

**引理 19（求证—世界赛跑 / 时敏 VoI 的单调性）** 设障碍闭合速度 `v_close` 增大使安全动作集收缩更快，则 `τ_epi(v_close)` 单调不增、`p_arr(τ_epi)` 单调不增；同时 `r_motion(g)` 随 `v_close` 单调不减。故 `VoI_τ(g)` 关于 `v_close` 单调不增，且存在临界速度 `v*` 使 `max_g VoI_τ ≤ 0`——**超过 v*，再问必亏，唯一理性是立刻保守执行或刹车**。系：动态避障里「聪明的追问」有明确的生命期。

**引理 20（自由信息与等待的最优性）** 令 `ΔH_free(δ)` 为等待 δ 的期望熵减，`c_wait(δ)` 为其安全成本（τ_epi 损耗）。则等待优于询问 g ⇔ `ΔH_free(δ) − c_wait(δ) ≥ p_arr(g)ΔH(g) − c(g) − r_motion(g)`。因 `c_wait` 不含社交成本而常更小，在「世界会自然揭题」的场景（`ΔH_free` 高）中等待占优；当歧义源于**静态不可观察属性**（`ΔH_free≈0`）时询问占优；当两者皆因 `τ_epi→0` 而蒸发时保守行动占优。⇒ R69 的二选一是本引理在 `ΔH_free=0, δ=0` 的特例。

**引理 21（空白只向保守方向出错 ⇒ 无假证书）** 若 `G_t` 是真实不可证集的过近似（`V_t ⊆ V_t^true`），则任何在 `V_t` 内被认证并执行的动作都不会是假证书；错误只可能是 `s∈G_t` 而实际可证（假空白）。于是 `false-certificate = 0` 是**构造性**的，`availability = 1 − false_gap_rate`。系：把安全性从「概率保证」转成「逻辑保证」，代价落在可用性轴。

**引理 22（截止期一致的模态选择不诱发紧急态）** 若只执行满足 `t_c(k) ≤ t+τ_epi` 且轨迹 `∈ ℱ∩V` 的模态，则未消解安全集在承诺前始终非空；因此「由于思考太久而进入紧急态」的概率为 0（相对于给定 `τ_epi` 估计）。⇒ 由 T-MINT 的截止期门控与定义 319 联合保证。

**定理 18（GAP-RAS 严格包含 FLUID-RAS）** 在 A95–A103 下，令 `v_close=0、G=∅、τ_epi=∞`，则 T-MINT 退化为 R69 的 MINT、EVO 为空、GRC 退化为 FLUID 主环 ⇒ 逐指令相同；一般情形下 GAP-RAS 期望风险 ≤ FLUID-RAS（它从不执行迟到信息、从不无证进入 G），效率损失只体现为假空白导致的可用性下降。⇒ R69 是 GAP-RAS 在「静止世界 + 完备证书」边界上的退化。

**定理 19（双障碍安全与无突变）** 在 A99–A103（可达集过近似、gap 边界 Lipschitz、控制仿射、CBF 可行）下：(i) 物理 VO 约束 ⇒ 与预测可达集无碰撞；(ii) EVO 约束 ⇒ 不无证进入 G，除非伴随认证机动在进入前消除见证；(iii) 分层回退的 λ 单调不降、回退状态机沿固定优先序切换 ⇒ 控制连续（R68 定理 15 的换装不变式保持），无因模式切换产生的突变。证略（VO 标准结论 + G 的 Lipschitz + CBF-QP 可行域连续性）。

**定理 20（空白投毒的伤害定向）** 若空白构造满足 soundness-only 且见证需 k 个正交源佐证，则对手注入假见证只能**膨胀 G**（可用性 DoS），无法**抹除真见证**（因为抹除需要破坏过近似构造）；因此假证书率仍为 0。⇒ **空白投毒被结构性地限制为可用性攻击**。推论：真正的安全威胁不是「被骗出假证书」，而是「空白本体论不完备」——见本轮最大风险。

## 6. 本轮最大风险

**一句话**：GAP-RAS 把安全性押在「空白图谱是**完备**的过近似」上——但「枚举所有不可证的原因」本身是一个**不可完备的元问题**：任何见证分类学都会漏掉一个还没被想到的失效模式，而漏掉的那一类会以**过近似构造的自信**被归入「已证」，从而制造出比 R69 更危险的假证书；更糟的是「研究空白」这个词会诱导我们把「已记录的空白」误当成「全部的空白」。**空白图谱越像一份严谨的证明，它漏掉的那一格就越致命。**

**次级风险与缓解**：
1. **僵尸/遗忘空白**（见证过期）→ 定义 320 的时空衰减 + 周期性重探 + E310；
2. **认证机动本身致险**（探针/靠近观察撞上移动体）→ 定义 317 过 C-RAS-WM + 社交 VO + E306；
3. **可达集过近似失效**（预测漏掉急停/变向）→ A99 覆盖概率 + 多模态可达集 + EVO 松弛；
4. **假空白导致保守瘫痪**（可用性 DoS）→ 显式记账 false_gap_rate + E307 + 分层回退的可用性优先序；
5. **互惠/社交反应**使「问」改变障碍轨迹 → 社交 VO 建模 + E313；
6. **截止期估计过乐观** → τ_epi 的保守下界 + ε_margin + E308。

```python
# IP-264 EDC：认知截止期（承诺前沿 × 障碍闭合）
def epistemic_deadline(s, e, obs_pred, V, F, H):
    lo, hi = 0.0, H
    for _ in range(8):
        mid = 0.5*(lo+hi)
        lo, hi = (mid, hi) if unresolved_policy_keeps_safe(
            s, mid, obs_pred, V, F) else (lo, mid)
    return lo

# IP-265 GAP：只向保守方向出错的空白图谱
def update_gap_atlas(s, o, e, calib, fma, tau_epi):

    G |= ood_flow(fma.a_score) | deadline_cliff(tau_epi)
    G |= mismatch_band(M.last_r_res, fma.delta_a)
    return over_approximate(G)               # soundness-only：可多报，不可漏报

        U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    elif g is WAIT:
        pass                                        # 让世界免费泄题
    mode = select_mode_deadline_aware(modes, U_epi, V_ok, tau)
    if mode is None and choose_cert_maneuver(G, tau):
        mode = select_mode_deadline_aware(modes, U_epi, V_ok, tau)  # 先补证
    if mode is None:
        return M.grc.safe_stop(lam_floor(U_ale + U_epi))            # 最后刹车
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale))
    k   = M.c_ras_wm.certified_prefix(mode.a, ..., V_ok, G)
    M.vqa_g.submit_async(g, tau, G, U_epi)
    return k, lam, mode, (U_ale, U_epi, tau)
```

## 4. 推导

**引理 19（求证—世界赛跑）** `v_close↑ ⇒ τ_epi↓, p_arr↓, r_motion↑`，故 `VoI_τ` 关于 `v_close` 单调不增；存在临界 `v*` 使 `max_g VoI_τ≤0`。系：追问有明确生命期，过 `v*` 应立刻保守执行或刹车。

**引理 20（自由信息与等待最优性）** 等待优于询问 ⇔ `ΔH_free(δ)−c_wait(δ) ≥ p_arr·ΔH(g)−c(g)−r_motion(g)`。`ΔH_free` 高（世界自然揭题）→ 等待占优；歧义源于静态不可观察属性（`ΔH_free≈0`）→ 询问占优；`τ_epi→0` → 保守行动占优。R69 二选一是 `ΔH_free=0, δ=0` 的特例。

**引理 21（只保守出错 ⇒ 无假证书）** `V_t⊆V_t^true ⇒` 在 `V_t` 内认证执行不产生假证书，错误仅为假空白；`false-certificate=0` 为构造性，`availability=1−false_gap_rate`。

**引理 22（截止期一致 ⇒ 不诱发紧急态）** 只执行 `t_c(k)≤t+τ_epi ∧ 轨迹∈ℱ∩V` 的模态 ⇒ 未消解安全集在承诺前非空 ⇒ 「思考太久进入紧急态」概率为 0（相对于 `τ_epi` 估计）。

**定理 18（严格包含 FLUID-RAS）** `v_close=0 ∧ G=∅ ∧ τ_epi=∞` 时逐指令等于 R69；一般情形风险 ≤ R69（不执行迟到信息、不无证进入 G），代价仅是可度量的可用性损失。R69 = 静止世界 + 完备证书边界。

**定理 19（双障碍安全与无突变）** A99–A103 下：VO ⇒ 与预测可达集无碰撞；EVO ⇒ 不无证进入 G（除非进入前由认证机动消除见证）；分层回退 λ 单调不降、状态机固定优先序 ⇒ 控制连续（继承 R68 定理 15 换装不变式），无模式切换突变。

**定理 20（空白投毒的伤害定向）** 在 soundness-only + k 源佐证下，注入假见证只能膨胀 G（可用性 DoS），无法抹除真见证（会破坏过近似构造）⇒ 假证书率仍为 0。**空白投毒被结构性限制为可用性攻击**；真正安全威胁转为「空白本体论不完备」。

## 7. 预期结果与可证伪预测

1. 若引理 19 成立：交互率对 `v_close` 呈 S 形塌缩，临界 `v*` 可在 E301 复现；过 `v*` 后强制交互会显著抬升风险。
2. 若引理 20 成立：`ΔH_free` 高的场景中 `wait` 占比单调上升，且相对 oracle 的 regret 小于「只问不等」基线。
3. 若引理 21 成立：E303 中 `false-certificate` 恒为 0，所有误差落在 `false_gap_rate`（可用性）轴上；`gap_coverage` 随见证增多单调趋近 1。
4. 若定理 20 成立：空白膨胀攻击下 `Δsafety≈0、Δavailability<0`；空白抹除攻击成功率≈0。
5. 若定理 18 成立：E309 中静止 + 完备设定下与 R69 逐指令输出一致（行为差 = 0）。

## 8. 研究空白登记（本轮显式回答「空白是什么」）

- **空白 A（时敏信息）**：主动感知 / 交互决策普遍假设信息先于决策可用，缺 deadline-conditioned VoI 与「迟到正确 = 错误」的度量。
- **空白 B（负证书）**：安全论证只报正例，缺在线维护的不可证域 `G_t` 及「为什么不可证」的见证体系。
- **空白 C（双障碍基准）**：动态避障与主动消歧从未被放进同一可达性问题评测；缺「物理 VO ∩ 认知 EVO」的统一基准与相图。
- **空白 D（空白攻击面）**：缺对「制造 / 抹除认知空白」的威胁模型，以及可用性—安全分离的定量分析。
- **元空白（不可消除）**：无法枚举「未想到的不可证原因」。缓解：保留永久保守残差 `U_residual`（永远视为 G 的一部分，绝不认证），并以红队 + 审计持续扩张见证分类学；但只能缩小、不能清零。

## 9. 本轮最大风险

**一句话**：GAP-RAS 把安全性押在「空白图谱是**完备**的过近似」上——但「枚举所有不可证的原因」本身是一个**不可完备的元问题**：任何见证分类学都会漏掉一个还没被想到的失效模式，而漏掉的那一类会以**过近似构造的自信**被归入「已证」，制造出比 R69 更危险的假证书；**空白图谱越像一份严谨的证明，它漏掉的那一格就越致命。**

**次级风险与缓解**：僵尸/遗忘空白（定义 320 时空衰减 + 周期重探 + E310）；认证机动本身致险（过 C-RAS-WM + 社交 VO + E306）；可达集过近似失效（A99 覆盖概率 + 多模态可达集 + EVO 松弛）；假空白导致保守瘫痪（显式 false_gap_rate 记账 + E307 + 可用性优先序）；互惠/社交反应改变障碍轨迹（社交 VO + E313）；截止期估计过乐观（τ_epi 保守下界 + ε_margin + E308）。
