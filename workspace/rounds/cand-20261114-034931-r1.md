# 第 71 轮（承接第 70 轮「BELIEF-RAS 贝叶斯状态估计层」IP-264~274；灵感循环新循环第 1 轮；本轮灵感：「实时性」×「关节驱动」）

> R70 把 epistemic 从「动作模态」提升为显式世界状态后验 b_t，并用 Proto-Val 要求 P99<3.5ms、零交互违规。但整条链（BSE→FMP→MINT→FMA→VQA→LLM 解码）都是**变速率、可抢占、尽力而为**的计算，而机器人真正的安全底线在**关节驱动**的 1 kHz 力矩/电流环。R68–R70 的所有安全定理都默默假设了一件事：**认证过的指令会被及时、准确地执行**。这是一个从未写进假设清单的隐藏假设。
>
> 本轮两个灵感正好戳破它：
> - **实时性**不是平均延迟，而是**截止期语义**——一个决策有有效期，过期即无效，不是「稍微旧一点」，而是「逻辑上已经作废」。
> - **关节驱动**不是理想力矩源：饱和、速率限制、摩擦、齿隙、热降额、驱动延迟，让「指令空间光滑」绝不等于「驱动空间安全」。
>
> 核心命题：**把安全认证从「指令空间 + 软实时」下推到「驱动空间 + 硬实时」；用物理可算的退避/制动视界来定义每个高层决策的有效期，用随年龄单调收紧的 λ 保证任何迟到都不产生不安全动作。** 命名 **TACT-RAS**（Temporal-Actuation Contract for Real-time safe RAS，时序—驱动契约）。
>
> 一句话定位：R66 问谁控制，R67 问未来怎样，R68 问测量还准吗，R69 问该向谁求证，R70 问世界处于什么状态，R71 问：**这个判断在多长时间内还算数，以及关节能不能安全地执行它、或把它撤回**。

## 0. 直觉与动机

**灵感 1（实时性 = 截止期语义，而非延迟统计）**
直觉：R70 用 P99<3.5ms 作为验收。但 P99 只描述分布，不构成保证：只要一次 BSE 发散重采样或一次 LLM 解码卡顿，某个「已认证」的指令就迟到了，而迟到的旧指令往往比没有指令更危险——它把一个已经过时的世界模型强行施加到当前关节上。真正该问的不是「平均多快」，而是「**这个决策的有效期到什么时候**」。把每个决策写成一张契约 (x, t_emit, H_valid, degrade)，执行器只接受未过期的契约；过期即丢弃并进入兜底。于是实时性从一个性能指标变成一个**逻辑谓词**：age ≤ H_valid。

**灵感 2（关节驱动 = 认证必须在驱动空间闭合）**
直觉：R68–R70 认证的是命令 x 及其风险缩放 λ，默认 τ = π(x)·λ 会被关节忠实地执行。但关节有死区、摩擦、齿隙、饱和、速率限制和电流/热约束。一个在指令空间连续、有界的 τ，经过齿隙换向可能产生速度跳变与冲击；一个被 λ 温柔收窄的指令，可能刚好落在摩擦的黏滑边界上而诱发极限环。**「指令空间光滑」不是「驱动空间安全」**。安全的真正定义必须落在关节状态 (q, q̇, τ_actual) 上，并对一族驱动模型成立（鲁棒不变集）。

**灵感 3（交点：有效期由物理退避视界决定，而不是软件 timeout）**
直觉：H_valid 不该是工程师拍的 50ms。它由物理决定：从现在这一刻起，关节还能在多长时间内、用多大的力矩把速度降下来并把系统带进安全集。这就是「**可停性 / 退避视界**」。若一个高层决策会消耗机动余量（加速、伸臂、改变接触），它的有效期就等于「剩余可停时间」减去驱动延迟与余量。软件超时只是这个物理量的一个（很可能过于乐观的）代理。

**灵感 4（热降额 → 有效期本身是时变的）**
直觉：关节驱动不是恒定能力源。电机/驱动器温度上升会降额 τ_max，电池电压下降会降低峰值力矩，谐波减速器的疲劳也会改变可用力矩。τ_max 下降 ⇒ 制动视界缩短 ⇒ 同一个决策的有效期变短。**热状态把「实时性预算」变成随电池与温度漂移的活量**。一个不感知热的有效性契约，会在长时程重载后悄悄失效——这正是 R70 担心的「缓慢漂移」在驱动层的镜像。

**灵感 5（anytime 分离：安全对算力不变，效率对算力单调）**
直觉：既然认知层可能超时，就必须让「安全」完全不依赖它是否算完。做法是把每个认知组件改成 anytime：随时可中断、随时返回一个「合法的、但可能更保守」的结果；关节 tick 永不等待。于是得到一条强性质：**安全保证是算力预算的常数函数（不随预算变化），而决策质量是预算的单调非减函数**。多给算力只会更好，不会更不安全；少给算力只会更保守，不会更危险。这把 R69/R70 的「实时预算焦虑」变成一条可证明的分离定理。

**灵感 6（兜底是双刃剑：抖动与饥饿）**
直觉：若认知时快时慢，系统会在「新契约」和「兜底」之间反复横跳，τ 的高频切换本身就是新的不安全源（抖振、冲击、减速器疲劳）。所以兜底必须带**闩锁与确认窗口**：一旦进入兜底，保持到连续 k 个 tick 收到新鲜且已认证的契约才退出；兜底本身也应是**有认证的柔顺退避**，而不是硬停。另一个极端是认知永远算不完 → 永远兜底 → 安全但瘫痪。因此需要「**有用性下限**」约束，否则 TACT 就退化为一个昂贵的急停按钮。

## 1. 形式化定义（增量：定义 331–347）

**定义 331（TACT-RAS 总览与四不变式）** TACT-RAS = (TCL, AJD, SDF, DRC, JDO, BHG, VQA-III)。四不变式：
(i) **硬实时关节 tick**：每个关节 tick 的 WCET C_j < T_j，认知任务可抢占但绝不抢占关节 tick；
(ii) **有效期语义**：任何被执行的指令满足 age ≤ H_valid(state)，age > H_valid 一律丢弃并进入兜底；
(iii) **驱动空间认证**：被执行指令的驱动实现，对 ∀p ∈ 𝒫_drive 都落在鲁棒不变集 𝒮_cert 内；
(iv) **无静默兜底**：每次兜底、每次丢弃、每次闩锁都进入审计与证书，禁止「悄悄降级」。

**定义 332（驱动模型集 𝒫_drive）** 对关节 i：J_i q̈_i = τ_i − τ_fric,i(q̇_i) − τ_g,i(q) − τ_ext,i，其中 τ_fric ∈ [τ_c^-, τ_c^+]（Coulomb 区间）+ Stribeck 速度项；齿隙死区 |q_m − q_l| ≤ β（电机侧 q_m 与负载侧 q_l 的传动间隙）；饱和 |τ_i| ≤ τ_max,i(T)；速率 |τ̇_i| ≤ r_max,i；有界驱动延迟 d ∈ [0, d_max]；量化与电流环带宽误差。𝒫_drive = Π_i 𝒫_i，每个 p ∈ 𝒫_drive 是一种「可能的真实关节」。

**定义 333（时序契约 Temporal Contract）** 认知层输出 m = (x, t_emit, H_valid, α(·), cert_x)，其中 x 是任务动作/设定点（不是力矩），α: [0, H_valid] → [0,1] 是非减的风险收缩曲线，cert_x 是驱动空间认证。**消费规则**：执行器在 t 时刻接受 m 当且仅当 age = t − t_emit ≤ H_valid，并按 α(age) 收缩；否则丢弃。

**定义 334（可停性 / 退避视界 BHG）** 给定关节状态 (q, q̇)、驱动约束 𝒫_drive、当前力矩上限 τ_max(T)：
H_stop(q,q̇) = min{ T : ∃τ(·), |τ|≤τ_max(T), |τ̇|≤r_max, τ ∈ 认证兜底族，使 q̇(T)=0 且整个轨迹留在安全走廊 𝒞 }。
**契约有效期**取 H_valid(q,q̇) = H_stop(q,q̇) − d_max − ε_margin。若 H_stop 不存在（已不可停），则 H_valid = 0，立即进入兜底。系：H_valid 是状态的函数，每个 tick 重算；它不是常数。

**定义 335（年龄退火的风险缩放 SDF）** λ(age) = min(1, λ_floor(U_ale + α·H[b_t]) + κ·(age/H_valid)^p)，κ≤1, p≥1。性质：λ 对 age 单调非减；age=0 时退化为 R70 的两级退避；age→H_valid 时 λ→1（最保守/兜底）。⇒ R70 是 TACT 在「零延迟、H_valid=∞」边界上的退化。

**定义 336（anytime 认知接口）** 每个认知模块（BSE、FMP 采样、MINT、FMA）暴露 anytime(budget) → (result, quality, cert)，满足：(a) 对任意 budget 返回合法结果（可能更保守）；(b) quality 对 budget 单调非减；(c) **safety 与 budget 无关**（cert 只在合法集内取，不安全结果永不返回，宁可不返回）。中断点只设在可重入的安全检查点。

**定义 337（硬实时调度与无锁契约缓冲）** 三时间尺度：关节 tick T_j（如 1ms）、估计/感知 T_p（5–20ms）、认知/语言 T_c（50–500ms）。关节 tick 独占最高优先级；契约写入用双缓冲/无锁环形队列，读者拿到的一定是完整快照；WCET 约束 C_j + d_max < T_j。

**定义 338（驱动空间鲁棒证书 DRC）** 指令 x 的驱动实现记为 ρ_p(x)（给定 p 的关节轨迹）。x 认证通过 ⇔ 存在鲁棒控制不变集 𝒮_cert 与证书 ψ（控制障碍函数/收缩度量），使 ∀p ∈ 𝒫_drive、∀t∈[0,H_valid]，ρ_p(x)(t) ∈ 𝒮_cert 且 ψ 沿轨迹不增（或收缩率 ≥ γ）；同时兜底族在 𝒮_cert 内可停。认证失败 ⇒ x 降级为更保守的投影 proj_𝒮(x)，仍失败 ⇒ 丢弃。

**定义 339（认证柔顺兜底族 Fallback Family）** 兜底不是「硬停」，而是一族按优先级排列的认证动作：F0 保持当前阻抗并零力矩渐退；F1 阻抗回缩到最近认证平衡点；F2 最大允许减速度制动；F3 安全停止/抱闸。每个 F_k 都带自己的可停视界与冲击上界；选择满足「冲击 ≤ J_max、减速 ≤ a_max、驱动器不越限」的最高优先级者。

**定义 340（关节驱动观测器 JDO）** 用电机电流 τ_m = k_t I 与编码器差分、力矩传感器，估计实际关节力矩 τ̂ 与传动间隙/摩擦状态：
r_drive = (τ_m − τ̂_cmd, q̇_enc − q̇_model, β̂ − β_nom, τ_max,eff/τ_max,nom)。
它给出第三条独立残差通道：r_res（R68 传感器自洽）、Δa（R69 行为自洽）、r_drive（关节自洽）。缓慢的摩擦上升/齿隙增大在传感器与行为通道都可能不明显，却在 r_drive 留下可检测的漂移。

**定义 341（热—力矩时变约束）** τ_max,i(T) = τ_peak,i · η(T_i) · η_V(V_bus)，η 非增。H_stop 随 τ_max 缩短；定义热安全条件：对预测温度轨迹 T(t)，∀t，H_valid(T(t)) > 0。热模型本身是一个慢状态，进入 BSE 的连续参数（R70 定义 311）或独立的热观测器。

**定义 342（契约代数 / 组合规则）** 契约可组合：m1 ⊗ m2 的有效期取 min(H_valid)，收缩取逐点 max（更保守），认证取合取；不可组合的契约（如互相排斥的模式）必须由仲裁器选择，仲裁结果本身写回审计。任何组合都不得延长有效期——**组合只能更保守，不能更自信**。

**定义 343（时序一致性证书 J_TACT）** J_TACT = (J_BELIEF, deadline_miss_count, age_p99/max, fallback_rate, latch_count, drive_margin_min, P_drive_coverage, r_drive_p95, thermal_margin_min, tact_ver)。Valid ⇔ Valid(J_BELIEF) ∧ deadline_miss_count=0 ∧ ∀applied age≤H_valid ∧ drive_margin_min>0 ∧ 热安全条件成立。

**定义 344（VQAuditor-III）** 在 R70 VQAuditor-II 上新增审计：契约是否被超龄执行、兜底是否被静默跳过、闩锁抖动频率、兜底冲击是否越界、热降额是否被及时计入、r_drive 漂移是否被误判为正常。

**定义 345（威胁模型扩展 AIC-TACT）** ℰ_TACT = ℰ_BELIEF × ℰ_time × ℰ_drive，其中 ℰ_time ∈ {延迟注入、抖动放大、时钟漂移、优先级反转、契约重放}，ℰ_drive ∈ {摩擦突变、齿隙增长、驱动延迟伪造、热降额欺骗（如遮挡温度传感）、电流限幅被恶意触发}。攻击目标从「让系统选错」扩展到「让系统用过期的对、或让兜底失效」。

**定义 346（与 R70 的包含关系）** 当 d_max=0、H_valid=∞、𝒫_drive 退化为理想力矩源时，TACT-RAS ≡ BELIEF-RAS；当且仅当认知层永不超时、热降额为零、驱动理想时逐指令相同。⇒ 新层是旧层在「时间—驱动」二维上的严格泛化。

**定义 347（有用性下限）** 为避免「永远兜底」的瘫痪，定义任务层面的有用性指标 U_use = 单位时间内被新鲜契约成功执行的任务片段比例；验收要求 U_use ≥ u_min，否则视为「安全但不可用」，与不安全同等对待。

```python
# IP-275 TCL：时序契约（有效期 = 物理退避视界 − 延迟上界）
@dataclass
class Contract:
    x: Tensor; t_emit: float; H_valid: float; alpha: Callable; cert: Cert

class TemporalContractLayer:
    def issue(self, x, state, drive, thermal):
        H = braking_horizon(state, drive, thermal) - drive.d_max - EPS_MARGIN
        H = max(H, 0.0)
        cert = self.drc.certify(x, H, drive, thermal)
        if not cert.ok:
            return None                          # 认证不过 -> 不发布，走兜底
        return Contract(x, now(), H, lambda a: age_alpha(a, H), cert)

# IP-276 AJD：硬实时关节分发（永不等待认知）
def joint_tick(M, state):
    t = now()
    win = M.tcl.read_snapshot()                  # 无锁双缓冲，完整快照
    while True:
        m = win.latest()
        if m is None or t - m.t_emit > m.H_valid:
            M.tcl.mark_expired(m)
            u = M.fallback.latched(state, M.jdo, M.thermal)   # 认证柔顺兜底
            break
        lam = M.sdf.lambda_floor(m, t)           # λ(U, age)，随年龄单调收紧
        u = M.plant.project(m.x, lam)
        if not M.drc.margin_ok(u, state, M.drive, M.thermal):
            M.tcl.mark_rejected(m); win = win.next(); continue
        break
    return M.jdo.record(u, state)                # JDO 残差 + 审计

# IP-277 SDF：年龄退火缩放
def lambda_floor(m, t):
    age = t - m.t_emit
    base = lam_floor_r70(m.U_ale, m.U_epi_after) # R70 两级退避
    return min(1.0, base + KAPPA * (age / max(m.H_valid, EPS))**P_AGE)

# IP-278 DRC：驱动空间鲁棒认证（对 𝒫_drive 的顶点/最坏情形）
def certify(x, H, drive, thermal):
    for p in drive.sample_vertices(budget=8):    # 摩擦/齿隙/延迟取极值
        traj = simulate_drive(x, p, H)
        if not inside_invariant(traj, S_CERT):  return Cert(False)
        if not contraction_holds(traj, GAMMA):  return Cert(False)
    return Cert(True, margin=min_margin(traj))

# IP-279 JDO：关节驱动观测器（第三条残差通道）
def record(u, state):
    tau_meas  = KT * read_current()
    tau_model = inverse_dynamics(state, u)
    r_drive   = tau_meas - tau_model
    beta_hat  = estimate_backlash(state.encoder_hist)
    return ResidualSet(r_drive=r_drive, beta_hat=beta_hat)

# IP-280 BHG：可停/退避视界（闭式、逐关节取 max）
def braking_horizon(state, drive, thermal):
    tau_max = drive.tau_max(thermal.temp, thermal.vbus)
    return max_j(brake_time_j(state.qd[j], tau_max[j], drive.rate[j]))

# IP-281 热观测器：温度是从不下班的慢状态
def thermal_step(T_prev, currents, dt):
    return T_prev + (R_TH*(currents**2*R_ELEC)
                     - (T_prev - T_AMB)/TAU_TH) * dt

# IP-282 兜底闩锁 + 确认窗口（抗抖振）
class FallbackLatch:
    def __init__(self): self.active, self.confirm = False, 0
    def latched(self, state, jdo, thermal):
        self.active = True
        self.confirm = 0
        return self.select_registered(state, jdo, thermal)   # F0..F3，按冲击上界选
    def try_release(self, fresh_ok):
        self.confirm = self.confirm + 1 if fresh_ok else 0
        if self.confirm >= K_CONFIRM: self.active = False

# IP-283 VQAuditor-III
class VQAuditorIII:
    def submit_async(self, m, b_t, g, U_ale, U_epi, a_hat):
        self.log(age=m.age(), stale=..., latch=self.latch.active,
                 drive_margin=..., r_drive=..., thermal=...)

# IP-285 TACT-RAS 主闭环（认知 anytime，跑在关节 tick 之间的 slack）
def TACT_RAS_round(M, obs):
    job = M.ajs.next_budget()
    b_t, _ = M.bse.anytime(M.b_prev, obs, job.budget_bse)
    samples, _ = M.fmp.anytime(obs, b_t, job.budget_fmp)
    U_ale, U_epi, modes = M.aud.from_belief(b_t)
    a_hat = M.fma.anytime(M.last_action, obs, b_t, job.budget_fma)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    g = (M.mint.anytime(b_t, modes, job.budget_mint)
         if (U_epi > TAU_EPI and not slow) else None)
    if g is not None:
        y = M.cia.execute(g)
        b_t = M.bse.update(b_t, g, y); U_epi = entropy(b_t)
    x = M.policy.propose(modes, b_t, g)          # 只产出设定点/任务片段
    m = M.tcl.issue(x, M.state, M.drive, M.thermal)   # 有效期由物理退避视界决定
    if m is not None:
        M.ajs.publish(m)                          # 无锁，不阻塞关节 tick
        M.latch.try_release(fresh_ok=True)
    M.vqa_iii.submit_async(m, b_t, g, U_ale, U_epi, a_hat)
    M.b_prev = b_t
    return m
```

## 3. 推导

**引理 23（时序契约的延迟无关安全性）** 若 (a) H_valid(s) ≤ H_stop(s) − d_max − ε；(b) λ(age) 非减；(c) 兜底族在 𝒮_cert 内可停；则对任意认知完成时间分布（含无限延迟），关节轨迹始终留在 𝒮_cert。证明要点：按 age 分三段——新鲜段（λ 有界收缩，DRC 保证不变）、超龄段（丢弃并启动兜底，H_stop 保证可停）、闩锁段（兜底保持，不变集自持）。三段都不依赖认知是否算完。系：**安全性对调度策略不敏感**。

**引理 24（驱动空间—指令空间的认证鸿沟）** 存在指令序列 {τ_k}，满足 |τ_k|≤τ_max、|τ_{k+1}−τ_k|/dt ≤ r_max 且指令空间 Lipschitz 很小，但真实关节在齿隙换向时加速度无界（接触瞬间速度差 Δv 与储能 E 满足 a_impact ≳ Δv/dt，Δt→0）。故仅凭指令空间有界性不能推出驱动空间安全；必须显式对 𝒫_drive 做鲁棒证书。

**引理 25（热降额收缩有效期）** 若 τ_max(T) 非增且 H_stop ∝ |q̇|/τ_max 的一阶估计成立，则 dH_valid/dT ≤ 0。若契约不计热，存在长时程重载场景使 age ≤ H_valid^nominal 但 age > H_valid^thermal，此时旧契约仍在被消费却已超出真实可停能力。系：**热观测器是 TACT 安全性的必要组件，不是优化项**。

**引理 26（anytime 安全—质量分离）** 若每个 anytime 模块在任意中断点返回的结果都落在安全子集内（定义 336-a），则安全证书与 budget 无关；且 quality 对 budget 单调（336-b）⇒ 存在 Pareto 前沿。系：调度器可以自由把 slack 分配给认知，而不必担心「给多了反而不安全」；这消除了 R70「实时预算被 K 采样击穿」的焦虑。

**引理 27（契约组合的保守性）** 对任意契约集合，其组合有效期 = min H_valid，收缩 = max α，认证 = ∧。故组合后的可执行动作集 ⊆ 任一成员的；不会因组合而放大自信。系：分层架构中上层永远无法通过「打包」绕过下层的有效期限制。

**定理 20（TACT 严格包含 BELIEF）** 在 A99–A102（驱动模型覆盖、可停性、热单调、anytime 合法返回）下，TACT 的闭环期望风险 ≤ BELIEF（后者隐含 d_max=0、H_valid=∞、理想驱动）；且在零延迟、理想驱动、无热降额时两者逐指令相同。⇒ R68=R69=R70=TACT 在「时间—驱动」理想边界上重合，安全侧层层不让步。

**定理 21（硬实时可调度性）** 若 C_j + d_max < T_j，且认知任务全部可抢占、其非抢占临界区总长 ≤ slack，则关节 tick 零 deadline miss；认知完成时间只影响 U_use（有用性），不影响安全证书。系：实时性验收从「P99」升级为「零 miss + 有用性下限」。

**定理 22（反馈闭合与无抖振）** 在闩锁 + 确认窗口 K_CONFIRM 下，兜底/新鲜模式切换的频率 ≤ 1/(K_CONFIRM·T_j)，且每次切换的力矩差有界（兜底族按冲击上界选择）；故切换本身不会引入超过 J_max 的冲击。系：把「抖动」从不可控的调度伪影变成有界的设计参数。

## 2. 形式规格（定义 331–347 的可执行摘要）

### 2.1 契约五元组
```
Contract := (x, t_emit, H_valid, α, cert)
  x        : 任务设定点/片段（禁止是未经驱动认证的原始力矩）
  t_emit   : 发布时间（单调时钟，非墙钟）
  H_valid  : 有效期 = max(0, H_stop − d_max − ε_margin)
  α(age)   : [0,H_valid] → [0,1]，非减；age→H_valid 时 →1
  cert     : DRC 证书（不变集余量 + 收缩率 + 覆盖的 𝒫_drive 顶点）
```

消费判据（关节 tick 每拍执行）：
```
accept(m, t) ⇔ (t − m.t_emit ≤ m.H_valid) ∧ (m.cert.margin ≥ 0)
             ∧ (drive.margin(π(x)·α(age), state) ≥ 0)
```
不满足任一条 ⇒ 该契约作废，**不得降级使用**（不允许「旧一点但还能用」）。

### 2.2 有效期反解（BHG）
```
H_stop(q,q̇) = min{ T : ∃τ(·), |τ|≤τ_max(T), |τ̇|≤r_max,
                   τ ∈ FallbackFamily, q̇(T)=0, traj ⊂ 𝒞 }
H_valid     = max(0, H_stop − d_max − ε_margin)
```
单关节闭式一阶下界（保守）：`H_stop ≥ |q̇| / a_max + |q̇|²/(2 a_max v_c)`，其中 `a_max = τ_max(T)/J_eff`，`v_c` 为安全走廊速度上限。取所有关节的最大值。**该式必须向下取整**（安全偏置）。

### 2.3 年龄退火（SDF）
```
λ(age) = min(1, λ_floor^R70(U_ale, U_epi) + κ·(age/H_valid)^p)
κ ∈ (0,1], p ≥ 2,  且 λ(0) = λ_floor^R70,  λ(H_valid) = 1
```
⇒ R70 恰为 age=0 且 H_valid=∞ 的边界；年龄只让系统更保守。

### 2.4 契约代数（组合只能更保守）
```
m1 ⊗ m2 := (x1⊗x2, max(t_emit), min(H_valid),
           max(α1,α2), cert1 ∧ cert2)
有效可执行集(⊗) ⊆ 有效可执行集(m1) ∩ 有效可执行集(m2)
```
禁止任何组合规则延长 H_valid 或降低 α。

### 2.5 驱动模型集与鲁棒证书
```
𝒫_drive = Π_i { τ_c ∈ [τ_c^-,τ_c^+], β ∈ [0,β_max],
                τ_max ∈ [τ_max^min, τ_max^nom(T)],
                r ∈ [0,r_max], d ∈ [0,d_max] }
DRC 通过 ⇔ ∀p ∈ Vertex(𝒫_drive), ∀t∈[0,H_valid]:
           ρ_p(x)(t) ∈ 𝒮_cert ∧ V̇ + γV ≤ 0（收缩度量 V）
```

### 2.6 兜底状态机（FFL）
```
        ┌──────────┐   fresh & cert ok (K_CONFIRM 次)   ┌───────────┐
        │  NORMAL  │ ──────────────────────────────────> │  LATCHED  │
        │ 消费契约 │ <────────────────────────────────── │ F0→F1→F2→F3│
        └──────────┘        age > H_valid / cert fail    └───────────┘
F0 零力矩渐退  →  F1 阻抗回缩  →  F2 最大减速度制动  →  F3 抱闸
每次升级必须是连续保持升级条件 N_ESCALATE 拍；降级必须经 K_CONFIRM 次新鲜契约确认。
```

### 2.7 热安全条件
```
τ_max,i(T) = τ_peak,i · η(T_i) · η_V(V_bus),  η 非增
ThermalSafe(t) ⇔ ∀t'∈[t, t+H_max], H_valid(T(t')) > H_stop_required(t')
```
不满足 ⇒ 禁止发放长有效期契约，只允许短契约或直接保持兜底。

```python
class TemporalContractLayer:

            - self.drive.d_max - self.eps

def TACT_RAS_round(M, obs):
    job = M.ajs.next_budget()
    b_t, _   = M.bse.anytime(M.b_prev, obs, job.bse)
    _,  _    = M.fmp.anytime(obs, b_t, job.fmp)
    U_ale, U_epi, modes = M.aud.from_belief(b_t)
    a_hat    = M.fma.anytime(M.last_action, obs, b_t, job.fma)
    slow     = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    g = (M.mint.anytime(b_t, modes, job.mint)
         if (U_epi > TAU_EPI and not slow) else None)
    if g is not None:
        y = M.cia.execute(g)
        b_t = M.bse.update(b_t, g, y); U_epi = entropy(b_t)
    x = M.policy.propose(modes, b_t, g)
    m = M.tcl.issue(x, M.state)
    if m is not None:
        M.ajs.publish(m); M.latch.note_fresh()
    M.vqa_iii.submit_async(m, b_t, g, U_ale, U_epi, a_hat)
    M.b_prev = b_t
    return m
```

## 4. 硬实时可调度性与 WCET 预算

| 任务 | 周期 | WCET 目标 | 可抢占 | 影响安全的路径 |
|---|---|---|---|---|
| 关节 tick（读契约/λ/投影/余量） | 1 ms | ≤ 120 µs（含 DRC 快速查表） | 否（最高优先级） | 是 |
| JDO 残差 + 热观测（并入 tick） | 1 ms | ≤ 15 µs | 否 | 是（慢漂移） |
| 兜底状态机 | 事件 | ≤ 3 µs | 否 | 是 |
| DRC 全量重认证 | 10–50 ms | 30–80 µs | 是 | 否（结果只更新缓存） |
| BSE anytime | 5–20 ms | 0.3–1.0 ms | 是 | 否 |
| FMP anytime | 事件 | 0.8–2.8 ms | 是 | 否 |
| MINT/FMA anytime | 事件 | ≤ 0.6 ms | 是 | 否 |
| LLM 问句解码 | 事件 | 50–300 ms | 是 | 否（永不进安全回路） |

**可调度性判据**：`C_j^tick + d_max < T_j` 且所有认知非抢占临界区总长 ≤ 每拍 slack。满足 ⇒ 关节 tick 零 deadline miss（定理 21）。**安全证书不引用任何认知完成时刻**，因此认知超时只降低 U_use。

**实时性验收**（取代单一 P99）：
1. `deadline_miss_count = 0`（1e6 tick）；
2. `age ≤ H_valid` 对被执行的 100% 契约成立；
3. `U_use ≥ 90%`（常规任务）、`≥ 60%`（强扰动）；
4. 抖动 p99.9 ≤ 50µs，切换冲击 ≤ J_max。

## 5. 驱动空间认证流程（DRC 工程化）

1. **𝒫_drive 辨识**：台架扫频辨识 J_eff、τ_c、Stribeck 参数、β、r_max、d_max、τ_max(T,V)；每项给出区间而非点估计。
2. **顶点枚举**：对每关节取 2^5 个顶点（摩擦 ±、齿隙 0/β_max、延迟 0/d_max、饱和 min/nom、速率 0/r_max），跨关节取最坏组合；超过预算时用最坏角点 + 随机采样补齐。
3. **不变集 𝒮_cert**：以认证兜底族 F0–F3 的可停域构造；用鲁棒 CBF / 收缩度量离线求解，在线只查表 + 余量插值。
4. **余量定义**：`drive_margin = min_{p,t} ψ(ρ_p(x)(t))`；发布契约要求 `drive_margin ≥ 0`，执行每拍复检（快速查表）。
5. **证书外逃逸处理**：任何 p 顶点越界 ⇒ 契约降级投影；仍越界 ⇒ 丢弃；连续丢弃 ⇒ 触发 JDO 漂移告警与 𝒫_drive 重辨识。

## 7. 失败模式归因树

```
安全/实时失败
├─ 建模失配
│  ├─ 𝒫_drive 未覆盖（齿隙/摩擦/延迟超界） → 重辨识 + 扩大区间
│  ├─ 热模型滞后/电压骤降             → THM 刷新率↑ + 短契约
│  └─ H_stop 高估（低估制动距离）      → 安全偏置系数↑，重标定
├─ 算法数值
│  ├─ DRC 收缩证书在边界振荡           → 余量阈值 + 投影
│  └─ BSE anytime 中断点不合法         → 检查点重审（定义 336）
├─ 调度/工程
│  ├─ 优先级反转 / 锁竞争              → 无锁双缓冲 + 优先级继承
│  ├─ 时钟漂移导致 age 低估            → 单调时钟 + 漂移监测
│  └─ 认知饥饿导致 U_use 过低          → 预算重分配 / 降级任务
├─ 驱动硬件
│  ├─ 电流限幅/抱闸失效                → F3 自检 + 硬件看门狗
│  └─ 编码器故障                        → JDO 交叉校验
└─ 对抗
   ├─ 延迟注入/契约重放                → 单调序号 + 签名
   └─ 热传感器遮挡/欺骗                → 多源热估计（电流积分冗余）
```

## 8. 与 R68–R70 的严格包含（小结）

- **R68（CALM）**：无时间维度、无驱动模型；λ_floor(U)。
- **R69（FLUID）**：加流匹配与交互，但仍假设指令即执行。
- **R70（BELIEF）**：加状态后验与 Proto-Val，P99 是统计目标而非保证。
- **R71（TACT）**：λ_floor(U, age)；H_valid 由 H_stop 反解；认证在 𝒫_drive 上鲁棒；安全与调度解耦。理想边界（d_max=0, H=∞, 理想驱动, 无热降额）逐指令退化为 R70。

## 9. 本轮最大风险

**一句话**：TACT-RAS 把「安全」从语义层的概率保证换成了驱动层的物理承诺，而这个承诺的唯一抵押品是驱动模型集 𝒫_drive 与 H_stop 的诚实度——**一旦真实关节在齿隙冲击、摩擦突变、热/电压骤降或延迟超界上逃出了建模区间，物理有效期就会被高估，系统将自信地执行一个早已作废的指令；此时「零 deadline miss」反而成了最危险的假象——它证明系统很准时，却证明不了它准时地在做错事。**
