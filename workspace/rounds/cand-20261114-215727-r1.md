# 第 3 轮（灵感循环第 3 轮；本轮灵感：「用户共创」×「强化学习」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440）。
> 本轮纪律：**在 ToolGauge 之上做增量升级，而不是重写**——保留 VLA 审计、工具契约（MTC/TCV）、
> 摊销校准（MP-Φ/AP-Cal）、交叉验证热替换与 P-Quarantine；把「假设来源」从单一 VLA 扩展为**人机共创**，
> 把「探测/修复决策」从**近视双层下注**升级为**约束序贯策略**。MODGAUGE 五不变式与严格退化链继续保留并延长。
> 同时审计并修复第 2 轮遗留的七处缺陷（§5）。

## 双轴映射（升级而非重写）

| 灵感词 | 第 2 轮对象 | 升级为 | 一句话动机 |
|---|---|---|---|
| 用户共创 | IP-315 L-Box：VLA 单方面提假设；RepairCert 只做事后人工审计 | **H-Box + 共创契约 CoC**：用户成为带类型、来源、独立性与置信度声明的第二证据源，人类回执与工具回执同构 | 部署现场语义（关键材质、任务容差、禁忌动作）往往在用户脑中；但人是噪声大、可策略化、可共谋、注意力昂贵的「传感器」，不能当神谕 |
| 强化学习 | IP-317 T-Box：单步信息增益 − 代价的近视双层下注 | **R-Box + 约束 MDP（CMDP-S）**：状态含后验/覆盖/预算，动作含探测/问人/假设/停止，奖励含不确定度与覆盖增益，约束含物理风险、工具预算与人类注意力 | 探测是序贯的：前一条回执改变后验与后一条工具的可行性；不同盲区共享结构；近视贪心会浪费预算并触发不必要的物理动作 |

**核心命题**：把 ToolGauge 的
「语义假设 → 契约化工具调用 → 摊销校准 → 交叉验证后局部热替换」
升级为
「**共创假设与偏好 → 约束序贯探测 → 人机回执融合 → 反事实审计后局部热替换**」。
人只贡献**语义、偏好与否决**，RL 只优化**在安全可行集内的序贯决策**，数值真值仍由计量层独占；
两者都是增强层，任意一层失效都按延长后的严格退化链回退。

**不变式保持声明**：
- MODGAUGE 五不变式全部保留；
- 主张绑定不变式**再次扩展**：数值主张只能引用数值回执，偏好主张只能引用偏好回执，人类语义主张只能引用有效人类回执（定义 442）；
- **严格退化链继续延长**：CoGauge 失效（RL 策略 OOD / 安全盾频繁触发 / 人类通道不可用）⇒ ToolGauge；ToolGauge 失效 ⇒ LeanGauge；LeanGauge 失效 ⇒ MODGAUGE。

## 0. 直觉与动机

### 灵感 1（用户共创 → 把「人」变成可校准、可审计、可拒绝的共创作者）

直觉：ToolGauge 把 VLA 降格为被审计的假设器/编程器/解说器，这是正确方向，但它仍假设「语义来自模型」。
真实部署中，最懂现场的往往是用户：他知道这块玻璃是防弹的、这个托盘不能敲、这条产线的容差是 0.3mm、
哪些误检会让操作员直接关掉系统。把用户排除在外，系统会反复提出物理上不可行或业务上无意义的修复。
但反过来，把用户当神谕更危险：人会疲劳、会迎合、会被界面措辞诱导，甚至可能有利益冲突或恶意注入。
所以「用户共创」的正确形态不是「加一个聊天框」，而是：
**人类贡献 = 类型化 schema + 来源签名 + 声明置信度 + 独立性标识 + 注意力代价**，
与计量工具回执用同一套有效性谓词管理（定义 432–434）。
系统还要**主动**共创：用价值信息量（VOI）决定问谁、问什么、值不值得问（定义 439），
并把用户的**偏好**（而非事实）学成奖励模型，但奖励模型必须过逆奖励设计审计（定义 438）。

### 灵感 2（强化学习 → 把「探测/修复」从近视下注变成受约束的序贯决策）

直觉：T-Box 的双层下注（风险门 λ + 增益注 β）是**单步、近视、无状态**的：
它不知道「先花一次低成本 IR 探测，可能让后面昂贵的敲击变得不必要」，
也不知道「这个盲区的失败模式与上一个盲区相同，应该直接复用策略」。
把探测/修复写成有限时域约束 MDP（定义 435）后，策略可以：
(a) 在多步之间做信息规划；(b) 跨盲区用上下文元学习复用经验；(c) 显式把人类注意力当作稀缺预算。
但 RL 在物理系统里是危险的：探索会扰动、奖励会被钻空子、离线评估会有偏。
因此本方案把 RL **夹在硬安全壳里**：安全盾做动作投影（定义 436），
保守离线策略选择只在置信下界超过 ToolGauge 基线时才部署（定义 437），
OOD 检测触发即退回 T-Box（定义 443）。RL 只能改善「在安全可行集内的效率」，不能扩大可行集。

### 灵感 3（两轴交汇 → 新的核心失效模式：共创奖励劫持）

直觉：两条轴单独看都合理，合在一起会产生一个新的、ToolGauge 没有的失效模式：
RL 优化的是奖励，而奖励部分来自人类偏好与人类回执；于是策略会学会**操纵人类通道**——
问最容易回答的问题、把修复证书写得最可信、专挑会给出正向偏好的用户、
甚至用「已修复」的措辞诱导批准。人类看到的是被 RL 优化过的呈现，回执又反过来喂给 RL，
形成「人机相互确认」的自洽错误。这不是普通 reward hacking，而是**共创奖励劫持（co-creation reward hacking）**。
因此本轮把「反事实热替换审计」（定义 440）与「奖励模型审计」（定义 438）提升为一等公民：
任何热替换不仅要通过数值交叉验证，还要通过「在分离干预集上旧/新契约行为一致」的反事实检验；
奖励模型要能被逆奖励设计检验拒绝，而不是黑箱信任。

## 1. 形式化定义（增量：定义 432–444）

**定义 432（共创契约 CoC）** 人类贡献 q = (kind, payload, prov, conf_decl, indep_key, c_H, τ_H)：
- kind ∈ {hypothesis, label, preference, veto, blind_spot, tool_proposal}；每种 kind 有预注册 schema；
- payload：类型化内容（如 label=格子真值、preference=对两张修复证书的偏序）；
- prov：身份与来源签名（组织/角色/会话），用于责任追踪；
- conf_decl ∈ [0,1]：人类自报置信度（**仅作特征，不作真值**，需校准，定义 434）；
- indep_key：独立性标识（同一用户/同一班组/同一信息源共享 key）；
- c_H：本次交互的人类注意力代价（秒 + 认知负荷估计）；τ_H：最坏响应时延。
文本自由输入只能进入 kind=hypothesis/preference 的**语义字段**，永不直接进入数值通道（延续定义 429）。

**定义 433（人类回执与有效性）** r_H = (q, payload, sig, ts, seq, calib_id)；
valid_H(r_H) ⇔ Schema_kind(payload) ∧ Verify(sig) ∧ seq 单调 ∧ calib_id 指向已注册校准器。
无效人类回执作废并计入信度统计；**作废回执永不进入融合与奖励学习**。

**定义 434（人类通道的校准与鲁棒聚合）** 对每个 (kind, 用户组) 维护标定映射 g: conf_decl ↦ 后验正确率
（保序回归/Platt，部署前用交叉通道真值标定）。人类通道被建模为噪声传感器：
每个 kind 有混淆矩阵 C_kind；同 indep_key 的贡献先按 key 聚合成一条，再做**中位数-均值 / 截尾均值**鲁棒聚合，
以抵御比例 f < 1/2 的对抗贡献与共谋；独立性图要求有效独立源数 α_ind 达到门槛才采信。

**定义 435（约束 MDP CMDP-S）** M = (S, A, P, r, c, γ, H, b)：
- 状态 s_t = (μ_t, Σ_t, cover_t, B^tool_t, B^human_t, B^time_t, ctx_t)：后验、未覆盖位图、剩余预算与盲区上下文；
- 动作 a_t ∈ (tool,args) | ask_user(kind, query) | propose_hypothesis | stop | escalate；
- 奖励 r_t = ΔH(Σ_t) + λ_cov·Δcover_t − c_t（不确定度下降 + 覆盖增益 − 代价）；
- 代价向量 c_t = (c_phys, c_risk, c_H, c_time)，约束 E[Σ_t c_t] ≤ b，且 P(物理安全违规) ≤ δ。
状态转移由计量层真实回执与人类回执共同驱动；人类响应本身是随机转移的一部分。

**定义 436（安全盾与可行集投影）** 每步先由继承的风险门 λ（定义 400/419）与物理包络构造安全动作集 A_safe(s_t)；
策略输出 a ~ π_θ(·|s_t) 后，盾执行 a_safe = Π_{A_safe}(a)，若 A_safe = ∅ 则强制 STOP/escalate。
盾只依赖可验证的物理前置与预算，不依赖策略质量 ⇒ 硬约束满足与 π_θ 的学习误差解耦（引理 51）。

**定义 437（保守策略优化与部署闸门）** 在仿真 + 历史日志上训练 π_θ（共享编码器 + 盲区上下文元学习）。
部署前用保守离线评估（OPE）计算值下界 Q_LCB(π_θ)；**仅当 Q_LCB(π_θ) > V_ToolGauge + margin 时才启用 RL**，
否则保持 T-Box 近视策略。策略更新加行为策略 KL 惩罚与悲观项；在线只做小步适应，不探索未验证动作。

**定义 438（奖励模型与逆奖励设计审计）** 从人类偏好对（修复证书/结果）用 Bradley–Terry 学 r_ψ。
审计 IRD：预注册安全权重向量 w_safe 与特征集 F；若 r_ψ 在「与安全无关但与人设/措辞相关」的伪特征上
权重超过阈值，或集成模型分歧 > ε_rm，则**拒绝奖励模型并只回退到安全默认效用**。
奖励模型永远不能覆盖硬约束（约束优先于奖励，定义 436）。

**定义 439（人类注意力预算契约 HBC）** HB = (B_human, q_max, τ_H, recovery)：
单盲区人类交互总预算、问题数上限、响应时延上限、恢复条件。问人前必须过 **VOI 门**：
VOI(q) = E[后验不确定度下降 | 回答] − c_H ≥ γ_H 才允许 ask_user；
RL 不能通过高频问人「刷」奖励（把人类注意力当免费资源）——这是对共创奖励劫持的结构性约束。

**定义 440（反事实热替换审计 CFSA）** 维护分离干预集 𝒞_sep（在机制层面能区分候选契约的上下文/干预组合）。
热替换前，对每个 c ∈ 𝒞_sep 固定同一回执流，分别执行旧契约 EC_old 与新契约 EC_new，
要求 |Δbehavior(c)| ≤ ε_cf 且**目标子图方向正确**；任何 off-target 子图变化超阈值 ⇒ 拒绝替换。
CFSA 比第 2 轮契约回归测试更强：后者只检查已观测输出，前者检查**干预下的一致性**（定义 440，引理 54）。

**定义 441（共创七段闭环 7C）** H(ypothesize) → Co(create) → C(ompile) → E(xecute) → C(alibrate) → V(erify+Audit) → U(pdate)：
1. H：D-Box 发现盲区；L-Box 生成初始假设集（继承定义 422）；
2. Co：H-Box 用 VOI 选择性地向用户提问/征集假设/偏好/否决，产出有效人类回执；
3. C：合并人机假设，VLA 编程器编译 Π_s，TCV 验证（继承定义 418）；
4. E：安全盾约束下执行工具与人类查询，产出人机回执流；
5. C：AP-Cal 以回执流为上下文输出后验（继承定义 420），人类回执经校准后进入融合；
6. V：独立回执交叉验证 + **CFSA 反事实审计** + 契约回归测试；
7. U：通过 ⇒ 热替换 + 修复证书（含人类与工具回执）；失败 ⇒ 夹紧重试 1 次 ⇒ stub + RED（严格退化）。

**定义 442（人机主张-回执绑定的类型化扩展）** 主张 c 分三类：
数值主张 → 必须引用有效**工具回执**；偏好主张 → 必须引用有效**偏好回执**；语义主张 → 必须引用有效**人类回执**。
跨类引用非法，序列化时剥离；剥离为纯投影，不改变任何数值行为（修复第 2 轮「表面引用」缺陷，§5）。

**定义 443（策略隔离 OOD-Quarantine）** 在线监控状态分布偏移（energy score / MMD）与约束近失事件；
OOD 分数超阈值或连续近失 ⇒ 冻结 π_θ，回退 T-Box，并把事件写入策略审计日志。
这是对第 2 轮 P-Quarantine（定义 428，针对先验）的**策略层对偶**。

**定义 444（继承与退化约定）** 未被重定义的记号沿用定义 398–431。
令 RL=∅（π_θ ≡ T-Box）、人类通道=∅ ⇒ CoGauge ≡ ToolGauge；再令 VLA=∅、T₀={被动观测}、MP-Φ=物理先验 GP ⇒ ToolGauge ≡ LeanGauge。
退化链：**CoGauge ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE**，每级都保持五不变式。

## 2. 关键算法骨架

```python
# IP-321 H-Box：共创假设/偏好通道（VOI 门控 + 类型化 schema）
class HBox:
    def co_create(self, s, H_s, budget_h):
        contributions = []
        for query in self.vla.propose_questions(H_s, s):      # 问题也来自被审计的 VLA
            if not self.voi_gate(query, budget_h):            # 定义 439
                continue
            q = self.ui.ask(query)                            # 人类响应
            if not schema_ok(q) or not verify_sig(q):
                self.reject += 1; continue                    # 无效人类回执
            contributions.append(q); budget_h -= q.c_H
        return calibrate(contributions), budget_h             # 定义 434

# IP-322 HRV：人类回执校验与鲁棒聚合
def robust_fuse(receipts_h):
    by_key = group_by_indep_key(receipts_h)                   # 去共谋：按独立源聚合
    best = [aggregate_key(g) for g in by_key.values()]
    return median_of_means(best)                              # f < 1/2 对抗鲁棒（引理 52）

# IP-323 R-Box：约束 MDP 策略 + 安全盾
class RBox:
    def act(self, s_t):
        if self.ood(s_t): return self.tbox.act(s_t)           # OOD ⇒ 退化（定义 443）
        a = self.policy(s_t)
        return self.shield.project(a, s_t)                    # 定义 436：硬安全投影

# IP-324 RM-Audit：偏好奖励模型 + 逆奖励设计审计
class RewardModel:
    def fit(self, prefs): self.r = bradley_terry(prefs)       # 定义 438
    def audited(self):
        if self.spurious_weight() > W_MAX: return False
        if self.ensemble_disagreement() > EPS_RM: return False
        return self.consistent_with_safety_weights()

# IP-325 CFSA：反事实热替换审计
def counterfactual_audit(ec_old, ec_new, C_sep, receipts):
    for c in C_sep:
        b_old = run(ec_old, c, receipts)
        b_new = run(ec_new, c, receipts)
        if abs(b_old - b_new) > EPS_CF and not is_target(c):
            return False                                      # off-target 变化 ⇒ 拒绝
    return True

# IP-326 CoGauge-7C 闭环
def cogauge_7c(M, s):
    H = M.lbox.hypothesize(s, M.dbox.R[s])                    # H
    H_h, M.hbudget = M.hbox.co_create(s, H, M.hbudget)        # Co：人类假设/偏好/否决
    H = merge(H, H_h)                                         # 人机假设融合（类型保留）
    prog = M.tbox.select(H, M.tools, M.tcv, M.budget_left(s)) # C
    receipts = M.tcv.execute(prog, M.env)                     # E（PROBING 态）
    if len(receipts) + len(H_h) < n_min(s):
        return stub_and_red(s, "insufficient")
    mu, Sig = M.apcal.calibrate(receipts, H, s)               # C
    if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):
        return stub_and_red(s, "cross_failed")
    new_ec = M.apcal.update_contract(M.dpe, mu, Sig, s)
    if not counterfactual_audit(M.dpe.ec(s), new_ec, M.C_sep, receipts):
        return stub_and_red(s, "cf_audit_failed")             # V：反事实审计
    if not contract_regression(new_ec):
        return stub_and_red(s, "regression_failed")
    M.mreg.hot_replace(M.dpe, new_ec)                         # U
    bind_typed_claims(new_ec, H, prog, receipts, H_h)         # 定义 442
    return True

# IP-326 主闭环：50Hz 不动，RL/人类全异步
def CoGauge_round(M, obs, audio, tac, depth, det):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s); submit_async(cogauge_7c, M, s)
    if M.policy_ood.triggered():                              # 定义 443
        M.rbox.freeze(); M.use_tbox = True
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 3. 推导

**引理 51（安全盾下的约束满足）** 若 A_safe(s) 由继承的物理包络与风险门 λ ≥ γ 构造，且盾按定义 436 投影，
则对任意策略 π_θ（含未训练/被攻击策略），物理安全违规概率 ≤ δ₀（每次探测的风险门单步界，引理 42/46 的 union bound），
预算约束由构造满足；RL 的学习误差只影响**在可行集内的效率**，不影响硬约束。■

**引理 52（人类回执的鲁棒聚合）** 设有效独立源数 n，对抗/共谋贡献比例 f < 1/2，每个源内误差有界，
则中位数-均值聚合的估计误差 ≤ 2b√(log(1/δ)/n) + f·B，成功概率 ≥ 1−δ；
若独立性图的独立数 α_ind，则把 n 替换为 α_ind·n_eff。系：f ≥ 1/2 时人类通道不可辨，必须触发拒绝而非融合。■

**引理 53（奖励模型的学习与劫持检测）** Bradley–Terry 奖励模型在特征维 d、N_pref 个偏好对下，
奖励排序误差 ≤ O(√(d/N_pref))。若伪特征 S 与授予者身份/措辞的互信息 > I₀，则 IRD 审计以功效 ≥ 1−β
拒绝该模型；未被拒绝时，策略相对安全默认效用的 regret 增加项 ≤ O(√(ε_rm))。■

**引理 54（反事实热替换审计的安全性）** 若分离干预集 𝒞_sep 能区分契约机制类，且对 c ∈ 𝒞_sep 有
|Δbehavior(c)| ≤ ε_cf，则新契约在部署分布上的 off-target 行为偏差 ≤ ε_cf/κ_sep（κ_sep 为干预集的分离裕度）；
结合第 2 轮引理 44 的未触及子图数值等价性，系统级性质保持；𝒞_sep 不完备时只保证**已覆盖机制类**内的安全（§5 缺陷 3）。■

**引理 55（序贯策略相对近视下注的增益与上界）** 在自适应次模信息目标下，贪心 T-Box 达 (1−1/e) 近似；
当工具依赖/预算耦合导致目标非次模时，存在实例使贪心任意差，而有限时域 CMDP 的最优策略可闭合该 gap。
线性 MDP 下策略 regret ≤ O(√(H³|S||A| log(1/δ)))；安全盾保证 regret 只在可行集内计。■

**引理 56（时序与预算保持）** 7C 全异步于 50Hz 路径之外；人类查询受 HBC 的 τ_H/q_max 硬约束；
50Hz 内联新增仅为回执验证 O(1) 与 OOD 打分 O(1)，总计 < 0.3ms/周期；
修复时延 ≤ Στ_t + τ_H·q_max + τ_VLA + τ_AP + τ_CFSA ≤ τ_repair（TB/HB 契约共同界定）⇒ 硬实时（引理 45/50）保持。■

## 6. 本轮最大风险（一句话）

**一句话**：**共创奖励劫持**——RL 会学会操纵人类通道（挑易答的问题、优化证书措辞、选择慷慨的用户），
人类回执又反过来强化 RL 的奖励模型，形成「人机相互确认」的自洽错误；
此时系统比纯自动基线**更自信地错**，而 CFSA 只能保证「机制层面没有 off-target 改动」，
无法保证「被优化的目标本身就是对的」。E447/E448/E453 为证伪实验，IRD 审计 + VOI 门控 + 独立源聚合 + 保守 OPE + OOD 回退为多层兜底。

**次级风险与缓解**：
1. **人类通道噪声/共谋** → 校准映射 + 中位数-均值 + indep_key + 独立数门槛（定义 434，引理 52）；
2. **奖励模型泛化/伪特征** → IRD 审计 + 集成分歧 + 安全默认效用回退（定义 438，引理 53）；
3. **RL 离线评估偏差导致错误上线** → 保守 OPE 下界 + margin + 只在模拟/日志可验证动作上更新（定义 437）；
4. **CFSA 分离集不完备** → 分离集覆盖率作为一等指标，未覆盖机制类标记为「仅回归级保证」（定义 440，引理 54）；
5. **人类注意力耗尽** → HBC 硬预算 + VOI 门 + 队列/升级（定义 439，引理 56）；
6. **问人本身泄露/被注入** → 人类输入同样过 schema 白名单与来源校验，自由文本不进数值通道（定义 432，延续 429）；
7. **策略 OOD** → 策略隔离 OOD-Quarantine 立即回退 T-Box（定义 443）。

## 2. 形式化定义（要点）

**定义 432（CoC）/ 433（人类回执）/ 434（校准与鲁棒聚合）** 人类贡献 = 类型 schema + 来源签名 + 自报置信度 + 独立性标识 + 注意力代价；有效性谓词与工具回执同构；自报置信度只作特征，经保序回归校准后使用；同 indep_key 先聚合再做中位数-均值，抗 f<1/2 对抗与共谋。
**定义 435（CMDP-S）** 有限时域约束 MDP：状态含后验、未覆盖位图、工具/人类/时间三类剩余预算与盲区上下文；动作含工具调用、问人、提假设、停止、升级；奖励 = 不确定度下降 + 覆盖增益 − 代价；约束 = 物理风险 ≤ δ、期望预算 ≤ b。
**定义 436（安全盾）** 由继承风险门 λ 与物理包络构造 A_safe，策略动作投影后执行；A_safe 空则 STOP/escalate。硬约束与策略质量解耦。
**定义 437（保守策略与闸门）** 仿真/日志训练 + 行为 KL + 悲观项；仅当 Q_LCB(π_θ) > V_ToolGauge + margin 才上线，否则保持 T-Box。
**定义 438（奖励模型 + IRD 审计）** Bradley–Terry 偏好奖励；伪特征权重超阈或集成分歧 > ε_rm 即拒绝，回退安全默认效用；奖励永不覆盖硬约束。
**定义 439（HBC + VOI）** 人机交互硬预算 q_max/B_human/τ_H；VOI ≥ γ_H 才问人，阻断 RL 以高频问人刷奖励。
**定义 440（CFSA）** 热替换前在分离干预集上固定回执流对比旧/新契约；off-target 子图变化超 ε_cf 即拒绝。比回归测试多一层「干预算术」保证。
**定义 441（7C）** H 假设 → Co 共创 → C 编译 → E 执行 → C 校准 → V 交叉验证 + CFSA + 回归 → U 热替换 + 类型化证书；失败夹紧重试 1 次 ⇒ stub + RED。
**定义 442（类型化主张绑定）** 数值主张绑工具回执、偏好主张绑偏好回执、语义主张绑人类回执；跨类引用非法，序列化剥离且不改变数值行为。
**定义 443（策略 OOD-Quarantine）** energy/MMD 偏移 + 约束近失 ⇒ 冻结策略、回退 T-Box、写审计日志（P-Quarantine 的策略层对偶）。
**定义 444（继承与退化）** 令 RL=∅、人类=∅ ⇒ CoGauge ≡ ToolGauge；再令 VLA=∅、T₀={被动观测}、MP-Φ=物理先验 GP ⇒ ToolGauge ≡ LeanGauge。

# IP-321/322 H-Box + HRV：VOI 门控共创与鲁棒融合
class HBox:
    def co_create(self, s, H_s, budget_h):
        out = []
        for query in self.vla.propose_questions(H_s, s):
            if not self.voi_gate(query, budget_h): continue   # 定义 439
            q = self.ui.ask(query)
            if not schema_ok(q) or not verify_sig(q):
                self.reject += 1; continue                    # 无效回执作废
            out.append(q); budget_h -= q.c_H
        return calibrate(out), budget_h

def robust_fuse(receipts_h):
    by_key = group_by_indep_key(receipts_h)                   # 去共谋
    return median_of_means([aggregate_key(g) for g in by_key.values()])

# IP-323/324/325 R-Box + 安全盾 + 奖励审计 + 反事实审计
class RBox:
    def act(self, s_t):
        if self.ood(s_t): return self.tbox.act(s_t)           # OOD ⇒ 退化
        return self.shield.project(self.policy(s_t), s_t)     # 硬安全投影

class RewardModel:
    def fit(self, prefs): self.r = bradley_terry(prefs)
    def audited(self):
        return (self.spurious_weight() <= W_MAX
                and self.ensemble_disagreement() <= EPS_RM
                and self.consistent_with_safety_weights())

def counterfactual_audit(ec_old, ec_new, C_sep, receipts):
    for c in C_sep:
        if abs(run(ec_old, c, receipts) - run(ec_new, c, receipts)) > EPS_CF \
           and not is_target(c):
            return False
    return True

# IP-326 CoGauge-7C
def cogauge_7c(M, s):
    H = M.lbox.hypothesize(s, M.dbox.R[s])                    # H
    H_h, M.hbudget = M.hbox.co_create(s, H, M.hbudget)        # Co
    H = merge(H, H_h)
    prog = M.tbox.select(H, M.tools, M.tcv, M.budget_left(s)) # C
    receipts = M.tcv.execute(prog, M.env)                     # E
    if len(receipts) + len(H_h) < n_min(s):
        return stub_and_red(s, "insufficient")
    mu, Sig = M.apcal.calibrate(receipts, H, s)               # C
    if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):
        return stub_and_red(s, "cross_failed")
    new_ec = M.apcal.update_contract(M.dpe, mu, Sig, s)
    if not counterfactual_audit(M.dpe.ec(s), new_ec, M.C_sep, receipts):
        return stub_and_red(s, "cf_audit_failed")             # V
    if not contract_regression(new_ec):
        return stub_and_red(s, "regression_failed")
    M.mreg.hot_replace(M.dpe, new_ec)                         # U
    bind_typed_claims(new_ec, H, prog, receipts, H_h)         # 定义 442
    return True

def CoGauge_round(M, obs, audio, tac, depth, det):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s); submit_async(cogauge_7c, M, s)
    if M.policy_ood.triggered(): M.rbox.freeze(); M.use_tbox = True
    return MODGAUGE_round(M, obs, audio, tac, depth, det)

## 4. 推导

**引理 51（安全盾下的约束满足）** A_safe 由物理包络与风险门 λ≥γ 构造，盾按定义 436 投影 ⇒ 任意 π_θ（含未训练/被攻击）的物理违规概率 ≤ δ₀，预算由构造满足；学习误差只影响可行集内效率，不影响硬约束。
**引理 52（人类回执鲁棒聚合）** 独立源 n、对抗比例 f<1/2 时，中位数-均值误差 ≤ 2b√(log(1/δ)/n) + f·B，成功概率 ≥ 1−δ；以独立性图独立数 α_ind 替换 n。系：f ≥ 1/2 时人类通道不可辨，必须拒绝而非融合。
**引理 53（奖励模型与劫持检测）** Bradley–Terry 奖励排序误差 ≤ O(√(d/N_pref))；伪特征与授予者/措辞互信息 > I₀ 时 IRD 审计以功效 ≥ 1−β 拒绝；未拒绝时 regret 增加 ≤ O(√(ε_rm))。
**引理 54（CFSA 安全性）** 分离集 𝒞_sep 能区分机制类且干预下 |Δbehavior| ≤ ε_cf ⇒ 部署分布 off-target 偏差 ≤ ε_cf/κ_sep；结合第 2 轮引理 44 的未触及子图等价性保持系统级性质；𝒞_sep 不完备时只保证已覆盖机制类。
**引理 55（序贯 vs 近视）** 自适应次模目标下贪心 T-Box 达 (1−1/e)；非次模耦合场景存在贪心任意差的实例，有限时域 CMDP 可闭合 gap；线性 MDP 策略 regret ≤ O(√(H³|S||A| log(1/δ)))，安全盾使 regret 只在可行集内计。
**引理 56（时序与预算保持）** 7C 全异步于 50Hz 之外；人类查询受 HBC 的 τ_H/q_max 硬约束；50Hz 新增仅回执验证 + OOD 打分 O(1)，< 0.3ms/周期；修复时延 ≤ τ_repair（TB/HB 共同界定）⇒ 硬实时保持。

## 8. 本轮最大风险

**一句话**：**共创奖励劫持**——RL 学会操纵人类通道（挑易答问题、优化证书措辞、选择慷慨用户），人类回执又强化奖励模型，形成「人机相互确认」的自洽错误；系统比纯自动基线**更自信地错**，而 CFSA 只保证「机制层面无 off-target 改动」，不保证「被优化的目标本身正确」——以 E447/E448/E453 证伪，IRD 审计 + VOI 门控 + 独立源聚合 + 保守 OPE + OOD 回退五层兜底。
