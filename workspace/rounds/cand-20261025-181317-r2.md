# 第 8 轮（本循环第 2 轮）· STANCE：把四足机器人的接触本能装进 VLA

> 检索/复核日期：2026-10-25（UTC）。赛事身份不变：宇树 **UniBot 世界挑战赛**（unibot.unitree.com），G1 + Dex1、32 项桌面任务、通才单模型赛道、选手自部署 + 官方远程真机 API。本轮三个灵感词是「可靠性」「四足机器人」「运动控制」。我先纠正了一个会影响全部判断的事实：公开榜单仍是占位，不能把 29.7% 当成真实榜首；然后我把“头部方案”拆成可核实的模型族，而不是虚构排名；最后把四足机器人能活下来的四件事——盲运动、本体感觉接触估计、全身稳定、跌倒恢复——迁移到桌面操作的最后三厘米。
> **结论先行：最值得押注的不是再训一个更大的 VLA，而是在 WLA 外面加一层“接触期可靠性层”STANCE：用命令–状态残差估计接触/滑移/卡死，用接触感知监督器改写动作，用盲末段技能和任务跌倒恢复兜住失败。**

## 0. 判断链：我如何从三个词走到 STANCE

这不是“看到三个词就拼一个缩写”，而是五次可复核的判断：

1. **先把赛制读对。** 手册写的是 success-first：32 任务总平均成功率优先，成功率相同才看平均步骤分；每任务 10 次 = 5 类泛化 × 2 次；单次 180 秒。也就是说，主指标是 320 次“全有或全无”的整集成功，不是平均动作质量。
2. **再把榜单读对。** `leaderboard.html` 仍是 Coming Soon；`leaderboard_data.json` 的 `generated_from` 是 `gen_leaderboard.py`。占位 JSON 里第一行 `MolmoAct2 / DexHacker` 是 29.7% 成功率、39.0 步骤分，正好接近“榜首不到 30%”，但它是**生成的占位数据**，不是官方真实成绩。因此本轮只能分析公开模型族的做法与瓶颈，不能声称知道真实头部的任务级强弱。
3. **拆头部模型族。** MolmoAct2 走“空间推理 VLA + flow-matching 动作专家”；Wall-OSS-0.5 走“4B 跨具身大规模预训练”；DreamZero 走“14B 视频世界模型联合预测动作”；Spirit / LingBot / π0.5 / GR00T 走“大规模 VLA + 全身/数据工程”。它们的共同强项是语义、空间和泛化；共同弱项是**接触期没有物理反馈、动作块开环、只在成功演示上训练、失败后不会恢复**。
4. **把三个词钉到失败结构上。** 可靠性不是“平均更高”，而是“尾部更少”；四足机器人不是“把机器狗搬上桌”，而是借用它在间歇接触、无力和触觉传感器、未知地形下的生存机制；运动控制不是“再做一个 MPC”，而是在位置接口内做命令–状态残差、接触期减速/回退/探测、相位化技能与全身姿态治理。
5. **合成后做反证。** 如果 PCE 的接触检测 AUROC < 0.65、误报 > 10%，或 CAS 在 T10/T26 上提升 < 3pp，或接触反射延迟 > 400ms，这个押注就不成立，应退回“相位调度 + 落点校验”的轻量版本。

一句话：**头部缺的不是“看懂”，是“摸到之后怎么办”。STANCE 攻的就是这后半句。**

## 1. 先把赛制与榜单读对

### 1.1 success-first 把问题变成可靠性

- 32 任务 × 10 次 = **320 次计分试炼**；10 次 = **5 类泛化 × 每类 2 次**。
- 成功 = 该任务所有评分步骤完成；任何一步失败，整集归零；步骤分只是失败后的安慰值和 tie-break。
- 单次真机上限 **180 秒**；超时失败。
- 5 类泛化是：位置、干扰物、背景、未见物品、人为干扰。
- 32 任务共 2–5 个评分步骤；官方 `info.json` 里终局步骤是 32/32 任务的成功闸门，放置/插入/堆叠/闭合类步骤约占 59.7% 分值（第 7 轮抓全 32 个文件后的统计）。

统计上，p≈0.3 时：

- 320 次总体标准误 ≈ **2.56pp**；
- 单轴 64 次标准误 ≈ **5.73pp**。

所以 +1–2pp 的模块很可能只是噪声；**+5pp 才值得押注**。这也意味着不能用单轴结果做模型选择，必须配对种子、bootstrap、按任务×轴分层报告。

### 1.2 榜单仍是占位：头部分析的正确边界

- `leaderboard.html`：Coming Soon。
- `leaderboard_data.json`：`generated_from: "gen_leaderboard.py"`；8 个模型 × 32 任务 = 256 条 `task_metrics`；第一行 29.7% / 39.0 是占位数据。
- `runs.html`：同样是 256/256 条占位运行记录，详情页写明“测试视频占位”。

因此我在本轮严格区分：

| 能说 | 不能说 |
|---|---|
| 公开模型族的架构、训练方式、公开基准结果 | “真实榜首是某模型”“某模型在 UniBot 上多少分” |
| 占位 JSON 的数值、生成方式、任务名 | 用占位分数推断真实任务难度排序 |
| 官方赛制、任务、数据、API、WLA | 真实头部的失败模式与任务级瓶颈 |

如果用户说的“榜首 <30%”来自内部榜单，那它是一个**待验证先验**；如果只是从占位 JSON 读到的，就更加不能当结论。无论哪种，都不影响本轮的核心判断：**公开模型族普遍没有接触期物理反馈与恢复机制。**

## 2. 头部方案拆解：五种模型族，同一个缺口

> 下面分析的是**公开模型族**，不是占位榜的真实排名。占位名单里的 VLAGO、DM0、RoboReasoner、GigaBrain-0 等我没有足够一手材料，不硬编。

### 2.1 五种路线

| 模型族 | 公开做法 | 强项 | 在 UniBot 的瓶颈 | 我们借什么 |
|---|---|---|---|---|
| **MolmoAct2** | 5.5B；Molmo2-ER 空间/具身推理 VLM + flow-matching 连续动作专家；per-layer KV 条件；开放权重 | 空间 grounding、动作推理、跨具身基础策略 | 仍是成功演示上的动作似然；无接触/力反馈；动作块开环；精细插入与闭合任务缺物理闭环 | 语义/空间先验、候选动作生成、开放权重生态 |
| **Wall-OSS-0.5** | 4B；Qwen2.5-VL-3B + 动作专家；20+ 具身、>1M 轨迹预训练；强调预训练即可上真机 | 跨具身规模、任务进度、零样本先验 | “任务进度”不等于整集成功；接触丰富任务仍靠视觉；无失败恢复 | 跨具身数据配方、预训练/微调范式、部署工程 |
| **DreamZero** | 14B；Wan2.1 视频扩散 backbone；视频与动作联合预测；7Hz 闭环 | 未来预测、新任务/新环境泛化、视频先验 | 14B 算力与 7Hz 延迟；预测像素/潜变量不等于预测接触力；幻觉与误差累积；不适合快速接触反射 | “预测作为辅助验证”的思想；不作为主回路 |
| **Spirit / LingBot / π0.5 / GR00T** | 大规模 VLA；全身/多本体数据；强基准工程 | 平均成功率高、工程完整、可复现训练 | 接触丰富尾部仍难；平台与 UniBot 不匹配；无本体感觉接触层 | 训练/评测纪律、全身控制接口、数据规模 |
| **纯世界模型/视频策略** | 用未来视频或潜状态做规划/验证 | 长程想象、无标签预训练 | 推理贵、动作条件化难、接触力不可见；对 180 秒真机不友好 | 只借“惊奇检测”做可选外环 |

外部校准：Spirit v1.5 在 RoboChallenge 30 个真机任务上是 **50.33% 成功率 / 66.09 分**，是当时唯一超过 50% 的模型（二手来源，且不是 UniBot）。这说明“真机桌面操作 30–50%”并不离谱；UniBot 的接触更密集、泛化轴更明确，头部 <30% 并非不可信。但这是外部证据，不能直接换算。

### 2.2 共同瓶颈：最后三厘米与失败恢复

把五种路线放在 UniBot 的 320 次全有或全无试炼里，缺口高度一致：

1. **成功演示偏置。** 训练数据几乎全是成功轨迹；模型学会“正常情况怎么动”，没学会“卡住/滑了/抓空/被人类移走之后怎么办”。
2. **动作块开环。** 一次 `get_action` 返回 T_a 步，评测端按顺序执行到下次调用；接触事件（插头卡住、碗滑落、拉链咬死）发生在块内，模型看不到。T_a=8 在 30Hz 下就是约 0.27 秒盲区。
3. **没有力/触觉。** 公开观测只有四路 RGB、双臂关节/EE、夹爪、15 维下半身；没有 torque/current/force/tactile。接触丰富任务需要力调制，纯视觉看不到“插头有没有对准孔”“拉链有没有咬住”。
4. **世界模型预测的是像素/潜状态，不是接触状态。** 视频预测可以把“插进去”的画面补出来，但不等于知道真实反作用力；7Hz 的世界模型也追不上接触瞬态。
5. **单模型约束。** 不能为 T10 插插头、T19 拉拉链各放一个模型；per-task LoRA/模型合并的合规性也未明。必须在推理时做任务条件化与运行时 adaptation。
6. **指标错位。** 公开基准多数报平均成功率/进度；UniBot 报的是 320 次整集成功。平均动作更好，不代表尾部失败更少。

**所以头部不是“不会看懂任务”，而是“在最后 3 厘米没有物理感，失败后没有第二次机会”。** 这正是四足机器人最擅长的部分。

## 3. 三个灵感词的真实落点

### 3.1 可靠性：从“平均能力”转向“尾部失败”

- 主指标是整集成功，不是步骤分；一个不可逆失败（碗掉、插头弯、拉链卡死、药撒）就把这一集归零。
- 32 任务里约 20 个是接触丰富/闭合/插入/悬挂类；28/32 的终局步骤是放置、插入、堆叠、闭合。
- 失败不是均匀分布：自由空间抓取通常不是瓶颈，**接触建立、接触维持、释放验证**才是。
- 可靠性层的价值不在“让简单任务更准”，而在“让接触丰富任务从 0 变成 1”，以及“让一次失败不把整集判死”。

### 3.2 四足机器人：四个可迁移的生存机制

不是把四足机器人放进比赛，而是迁移它在间歇接触、无力/触觉传感器、未知地形下的机制：

| 四足机制 | 证据 | 迁移到桌面操作 |
|---|---|---|
| **盲运动** | Lee et al., Science Robotics 2020：仅本体感觉的盲四足控制器，零样本从仿真到自然地形 | 最后 1–3 cm 不依赖视觉，靠本体感觉与接触反馈完成插入/堆叠/挂钩 |
| **本体感觉接触估计** | UniTac（CVPRW 2026）：仅关节传感器做全身触觉定位，FR3 误差 8.0 cm、Spot 7.2 cm；Contact-Anchored Odometry（2026）：用关节力矩估计足端接触；CoPRE（2026）：G1 接触检测 recall 82.2% | 用“命令–状态残差”做接触/滑移/卡死检测，不需要额外传感器 |
| **全身稳定** | Blind Dexterity（2026）：Unitree G1 纯本体感觉全身操作；Workhorse（2026）：五链路目标 + 全身 tracker | 用腰部姿态把手臂留在舒适工作空间；接触期锁腰、用臂；不把底盘当移动工具 |
| **跌倒恢复** | 四足/人形的 fall recovery、push recovery；Blind Dexterity 的 push-resilient walking | 任务跌倒恢复：抓空、滑落、卡死、被人类移走后的退避、重抓、重试 |

其中 **Blind Dexterity 是最直接的证据**：Unitree G1、只用本体感觉、无相机/标记/力/触觉；它明确把 **PD 控制器的跟踪偏差当作接触感知通道**，并通过主动探测让物体状态变得可解码。这几乎就是 STANCE 的物理依据。

### 3.3 运动控制：位置接口内的“接触期治理”

UniBot 不允许 torque 指令，动作是关节位置或 EE 位姿。但这不等于不能做运动控制：

- **命令–状态残差**：位置命令与实测状态之间的偏差，就是最简单的“力代理”。Blind Dexterity 已经证明 PD 跟踪偏差可以当接触通道。
- **位置空间 admittance**：不能直接控力，但可以控“推进速度、步长、回退、侧向搜索、微旋转、保持时间”。接触越强，推进越小；卡死越久，越先退再试。
- **相位化技能**：自由空间用大块快速走；接近/接触/释放用小块、慢速、带验证。BSS 在相位条件下复用技能，而不是每任务一个模型。
- **全身姿态治理**：G1 腰部有 1 或 3 DOF（EDU 可选）；数据里 `waist_state_joint` 是 3 维，HangCup 的 waist pitch 在 0.125–0.204 rad 变化，而 `action.pivot` 的平移分量几乎为 0。说明演示是固定底座 + 轻微腰部参与，不是移动操作。可以先做“腰部预姿态 + 接触期锁腰”，但 `pivot` 权限未核实，默认不依赖。

## 4. 主判断：STANCE

> **STANCE：Stability from Tracking And Contact Estimation。**
> 给 WLA-1.0 加一层单 checkpoint 的接触期可靠性层：VLA 负责“去哪里、做什么”，STANCE 负责“现在摸到了什么、还能不能进、失败后怎么退/重试”。

STANCE 不是第二个 VLA，也不是一个 14B 世界模型。它是 **VLA 外面的物理反射层**，包含六个部件：

```text
语言/任务
   │
   ▼
WLA-1.0（唯一学习主干）──► 候选动作块 a_t
   │                         │
   │                         ▼
   │              ┌─────────────────────┐
   │              │ PCE 本体感觉接触估计 │  r_t = s_t − ŝ_t^free
   │              │ 接触/滑移/卡死/自由  │  + 相位 + 视觉
   │              └─────────┬───────────┘
   │                        ▼
   │              ┌─────────────────────┐
   │              │ CAS 接触感知监督器   │  减速/探测/回退/保持
   │              │ 位置空间 admittance  │  安全包络 + 180s 预算
   │              └─────────┬───────────┘
   │                        ▼
   │              ┌─────────────────────┐
   │              │ BSS 盲末段技能集     │  插入/挂钩/堆叠/拉链/...
   │              │ 相位条件化，单 checkpoint │
   │              └─────────┬───────────┘
   │                        ▼
   │              ┌─────────────────────┐
   │              │ RER 任务跌倒恢复     │  抓空/滑落/卡死/超时
   │              │ 退避/重抓/重试预算   │
   │              └─────────┬───────────┘
   │                        ▼
   └──────────────► 执行动作 / 下一块
```

### 4.1 PCE：命令–状态残差就是“没有力传感器的力”

对每个控制步：

```text
a_{t−δ}：δ 步前发出的位置命令（关节或 EE）
s_t：当前实测状态
ŝ_t^free = f_θ(s_{t−1}, a_{t−δ}, φ_t)：自由空间名义跟踪
r_t = s_t − ŝ_t^free
z_t = sqrt(r_tᵀ Σ_φ^{-1} r_t)
p_t = g_ψ(z_{t−k:t}, ds_t, gripper_t, φ_t)
```

- `φ_t` 是评分步骤/相位（来自 SSG），因为自由空间与接触期的残差分布不同。
- `f_θ` 先在成功演示的**自由空间段**上拟合（每关节 ARX + 小 MLP 残差）；`Σ_φ` 用相位分层协方差。
- `g_ψ` 输出接触、滑移、卡死、自由四类；用仿真特权标签 + 真实演示相位 + 少量调试槽数据训练。
- **关键工程点**：HangCup 实测 action-state 跟踪误差在 lag 2–3 帧最小（30fps 约 67–100ms）；如果不做时间对齐，就会把控制延迟误判成接触。PCE 必须显式估计/补偿 `δ`。
- 置信度用 ensemble/conformal 校准；只有 `p_contact` 超过按任务校准的阈值才触发 CAS，避免误报导致“没碰就退”。

### 4.2 CAS：接触感知监督器，不是 MPC

CAS 是一个确定性有限状态机 + 安全包络，不改 VLA 的语义目标，只改“怎么执行”：

| 状态 | 触发 | 行为 |
|---|---|---|
| FREE | 远离接触 | 放行 VLA；速度/加速度限制 |
| APPROACH | 进入预接触区 | 降速、对准、缩小步长 |
| GUARD | 距离 < 2–3 cm | 慢速小步；准备探测 |
| PROBE | 接触不确定/卡死 | 侧向微扰、螺旋搜索、微旋转 |
| INSERT | 接触稳定且对准 | 小步推进 + 微调姿态；残差过高则回退 |
| SEAT | 到达目标位 | 轻压/轻敲/保持，等待稳定 |
| RELEASE | 放置/插入完成 | 开夹爪、等待、验证物体留在目标 |
| RETREAT | 卡死/滑移/高残差 | 沿接近方向后退，保护物体 |
| RECOVER | 失败已发生 | 重抓/重对准/换手/重置 |
| DONE/ABORT | 成功/预算耗尽 | 结束或保守失败 |

控制律是“位置空间 admittance”：

```text
a_exec = (1−α) · a_VLA + α · a_safe
α = clip((p_contact − τ_low) / (τ_high − τ_low), 0, 1)
若 z_t 高且 progress 低：减小推进、增加侧向搜索或回退
```

- 安全包络：接触区 Cartesian 速度上限、关节单步上限、工作空间盒、最大倾斜、夹爪闭合距离代理、180 秒预算。
- **不是**力控，也不承诺真阻抗；它是“用位置命令模拟柔顺”的工程近似。
- 接触反射只在 chunk 边界发生；所以 T_a 选 4–8，先用 6 做折中，并在消融里比较 4/8/16。

### 4.3 BSS：盲末段技能集

BSS 不是“每任务一个小模型”，而是一个 **phase-conditioned 多任务技能 checkpoint**：

- 技能：insert、hook、stack、zip、cap、pour、syringe、grasp。
- 输入：本体感觉历史 + 腕部图像 + 语言 embedding + 相位；输出：EE delta pose + gripper。
- 训练：Isaac Lab/MuJoCo 里用带接触特权的教师（RL/BC）训练，再蒸馏到只有本体+腕部图像的学生；域随机化覆盖摩擦、质量、高度、位姿、光照、遮挡。
- 复用证据：Blind Precise Assembly 只用本体感觉做 peg insertion，零样本真机 73%，对未见形状泛化优于视觉；Blind Dexterity 在 G1 上做纯本体全身操作；UniTac 证明关节传感器可做全身触觉定位。
- 合规：所有技能打进同一个 checkpoint，用 task/phase embedding 区分；不按任务切模型。
- 兜底：如果 8 周内 sim-to-real 不成立，BSS 降级为“脚本化原语 + 小残差策略”，PCE/CAS 仍独立成立。

### 4.4 WBG：腰部预姿态，不是移动底盘

- G1 腰部 1 或 3 DOF；数据里 waist pitch 在 0.125–0.204 rad 变化，但 `action.pivot` 的平移几乎为 0，说明桌面任务基本固定底座。
- 可用做法：按任务把 waist pitch 预置到演示中位数，让手臂留在舒适工作空间；接触期锁腰，避免接触力把身体推走；只在自由空间缓慢调整。
- **默认不写 `pivot`**：`pivot_3/4/5` 语义未公开，`pivot_4=0.15` 与 waist pitch 并不相等，不能把 `pivot_4` 当 waist 命令。WBG 作为可选开关，先做“只读 waist + 臂补偿”，验证 `pivot` 权限后再开。

### 4.5 RER：任务跌倒恢复

四足机器人摔倒后会站起来；桌面机器人“任务摔倒”后也应该有恢复：

| 失败 | 检测 | 恢复 |
|---|---|---|
| 抓空 | 夹爪闭合到底 + 无残差 + 腕部图像空 | 重开、重对准、重抓 |
| 滑落 | 残差方向突变 + 物体下坠视觉 + 夹爪仍闭 | 立即后退、降低高度、重抓 |
| 卡死 | 残差持续高 + 推进无进展 | 回退 1–2 cm、微旋转、再插 |
| 插错/未对准 | 侧向残差 + 视觉孔位偏移 | 侧向搜索、重对准 |
| 人类移走 | 视觉目标消失/位移 + 残差自由 | 重新观察、更新目标、重试 |
| 超时 | 180s 预算 | 放弃高风险动作，保守结束 |

- 重试预算：每步最多 2 次；不可逆步骤（倒药、拉链、插头）更保守；用 RAMP 的 SORS 动态规划可选。
- 关键是“早退”：在物体掉落/插头弯折之前退，而不是失败后重来。

### 4.6 CAL：接触压力校准套件

不是泛泛的 OOD 集，而是按官方 5 轴 + 接触物理做分层：

| 维度 | 构造 | 用途 |
|---|---|---|
| 位置 | 演示初始位姿聚类，留出整簇 | 校准相对位姿泛化 |
| 干扰物 | 2.5D 插入无关物体 | 校准目标中心裁剪/关系特征 |
| 背景 | 换桌布/光照/纹理 | 防止 PCE 学背景 |
| 未见物品 | 同类别不同外观/尺寸/摩擦 | 校准几何/运动特征 |
| 人为干扰 | 按官方 `human_1/4_note` 回放 | 校准惊奇检测与恢复 |
| 接触压力 | 质量 0.5–2×、摩擦 0.2–1.0、高度 ±1cm、位姿 ±2cm、遮挡、透明/可变形 | 校准 PCE 阈值与 CAS 安全包络 |

这套东西既是训练数据，也是校准集，也是离线评测集；所有阈值按任务/相位分层，不拿全局平均值拍脑袋。

## 5. 与第 7 轮、RAMP 的关系

| 关系 | 内容 |
|---|---|
| **保留** | WLA-1.0-Base；SSG 步骤图；SVL 落点校验；NRB 官方备注；OPT/PGL 放置子技能；L2L 数据协议；DebugLoop；FLEET 工程检查单 |
| **升级** | SVL → 接触感知的 SEAT/RELEASE/VERIFY；NRB → RER 任务跌倒恢复；SSG → PCE/CAS 的相位提供者，不再当主控制器 |
| **新增** | PCE 命令–状态残差接触估计；CAS 接触感知监督器；BSS 盲末段技能；WBG 腰部预姿态；CAL 接触压力校准 |

**与 RAMP 的区别：**

- RAMP 问的是“**哪个候选块更安全**”，需要风险/可恢复性 head 和候选采样，偏决策层。
- STANCE 问的是“**现在物理上发生了什么、该怎么动**”，只需要命令–状态残差和确定性监督器，偏控制层。
- 两者可以叠加：STANCE 做内环接触反射，RAMP 做外环候选选择；但本轮主押注是 STANCE，因为它在无 force/torque 的接口下更便宜、更可验证，也更接近四足机器人的真实经验。

## 6. 为什么可能赢

1. **证据直接落在 G1/四足上**：Blind Dexterity 就是 Unitree G1 纯本体感觉；CoPRE 在 G1 上做接触检测；UniTac 在 Spot 上做关节传感器触觉定位；Blind Precise Assembly 证明纯本体可以完成精密插入。
2. **接口允许**：四路 RGB + 关节/EE + 夹爪 + 15 维下半身，足够算命令–状态残差；不需要额外硬件，不需要力传感器。
3. **成本低**：PCE 是小模型/轻量分类器；CAS 是确定性代码；WLA 官方微调单卡 24GB 可跑；不需要 14B 世界模型。
4. **与 success-first 对齐**：直接减少整集失败，而不是提高平均动作似然；接触丰富任务是失败大头。
5. **单模型友好**：PCE/BSS 可以打进同一个 checkpoint；CAS/CAL 是确定性代码/数据；比“多个任务模型”更合规。
6. **可分层落地**：MVP 只做 PCE + CAS + 相位调度；V2 加 RER；V3 加 BSS/WBG。即使 BSS 失败，前两层仍有价值。
7. **数据现成**：32k 演示提供自由空间名义模型、接触相位、成功轨迹；官方 5 轴备注提供校准脚本；调试槽提供真机 A/B。

## 7. 为什么可能输

1. **没有力/扭矩**：残差是力代理，不是力；受控制延迟、重力、负载、摩擦、关节间隙影响，可能把“正常跟踪误差”误判为接触。
2. **位置接口限制柔顺**：不能真正控力，只能减速/回退/微扰；对插头、拉链、针管等需要持续力控的任务，可能不够。
3. **接触标签稀缺**：成功演示没有失败标签；仿真接触特权有 sim-to-real gap；调试槽次数未知。
4. **动作块开环**：接触反射最早在块边界，T_a=8 时约 0.27s；人为干扰可能更快。
5. **BSS 训练风险**：8 周内 sim-to-real 可能不成立；技能库可能过拟合仿真。
6. **单模型审计**：多 head/技能库是否算“一个模型”需官方确认；保守做法是单 checkpoint + 模型卡披露。
7. **上游错误**：如果 VLA 选错目标/看不懂场景，接触层只能在错误动作上做微调。
8. **腰部权限未知**：`action.pivot` 语义未公开；WBG 可能不可用，默认不依赖。
9. **真实榜单不可见**：不知道头部是否已经在做接触层；占位 29.7% 不能告诉我们真实差距。

# 第 8 轮产物区 · STANCE 技术报告（接触期可靠性 + 四足机制迁移 + 单 checkpoint）

> 目标赛事：宇树 **UniBot 世界挑战赛**（[unibot.unitree.com](https://unibot.unitree.com)），G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署、官方远程真机 API。检索/复核日期：**2026-10-25（UTC）**。
> 本报告承接第 7 轮 PILOT-GPR，但把主押注从“终局放置”推进到“接触期可靠性”：第 7 轮找对了“最后一公里”，本轮进一步指出——**最后一公里不是最后一个动作，而是接触建立、接触维持、释放验证与失败恢复**。第 8 轮并行草案 RAMP 的 success-first 纠正被保留；RAMP 的预测式候选选择降为可选外环，本轮主回路是 STANCE。

## 0. 产物摘要

### 0.1 一句话

**给 WLA-1.0 加一层单 checkpoint 的接触期可靠性层 STANCE：用命令–状态残差估计接触/滑移/卡死，用接触感知监督器做位置空间减速/探测/回退/保持，用相位条件化的盲末段技能与任务跌倒恢复兜住失败；不依赖力/触觉传感器，不引入第二个大模型。**

|---|---|---|---|

### 0.3 预期收益与可证伪目标

- 外部证据：纯本体感觉精密插入可达 73% 零样本；G1 接触检测 recall 82.2%；关节传感器全身触觉定位 7–8 cm；预测式/恢复层在 2026 年论文中带来 4–17pp 量级增益（不同任务，不可直接外推）。
- 本方案目标：**总平均成功率 +5pp**（若基线 30% → 35%），保守 +3pp；接触丰富任务簇 +10pp。
- 可证伪点 1：PCE 在留出任务/轴上的接触检测 AUROC < 0.65，或固定 90% recall 下误报 > 10% → 关闭学习型 PCE，退回“相位调度 + 阈值”。
- 可证伪点 2：CAS 在 T10/T26 调试槽上整集成功率提升 < 3pp → CAS 假设不成立，回退到 WLA + SVL。
- 可证伪点 3：接触反射延迟（chunk 边界 + 推理）> 400ms，或 T_a=6 下有效控制频率 < 12Hz → 缩 T_a/异步推理，仍不达标则放弃接触反射。
- 可证伪点 4：BSS 在仿真 5 技能平均成功率 < 70%，或真机低于脚本基线 → BSS 降级为脚本原语。
- 可证伪点 5：WBG 的 `pivot` 写入导致底盘运动/不稳定，或官方未开放 → 永久关闭 WBG，只读 waist 做补偿。

## 1. 事实核对（2026-10-25）

### 1.1 赛制

来自中文/英文参赛手册与官网：

- 32 项真实桌面任务；G1 系列；单模型完成全部任务；不得混合多个模型做不同任务。
- 每任务 **10 次**独立运行；5 类泛化（位置/干扰物/背景/未见物品/人为干扰）**各 2 次**；共 **320 次**计分试炼。
- 单次真机执行上限 **180 秒**；超时算失败；按执行情况计算步骤分。
- 排名：**总平均成功率优先**；成功率相同看总平均步骤分；仍相同看提交日期。
- 另有**不计分单任务调试**通道：只测 1 个任务、不计入排行榜。
- 选手自部署推理服务；官方远程 API 调用；评测在 N 台机器人上随机顺序进行；提交需暴露 N 个连续端口（8765 起），每端口独立完成一条交互流。
- 评测器记录每步 `get_action` 的延迟与内容；异常/不规则交互可能影响结果可信度。

**口径冲突**：官网首页/榜单页写“按平均成功率与步骤分综合排序”，手册写 success-first。本报告以更具体、可执行的手册为准，并把“综合排序的确切公式”列为开放问题。

### 1.4 数据一手统计

来自 HangCup 数据集 `data0.parquet`（130,565 帧；数据集总计 1,043 episodes / 194,564 帧 / 30fps）：

- 观测：四路 RGB（`cam_left_high`、`cam_right_high`、`cam_left_wrist`、`cam_right_wrist`），480×640；双臂关节/EE 位姿；夹爪；`lower_body[15]`；`waist_state_joint[3]`。
- 动作：双臂关节/EE、夹爪、`action.pivot[7]`、`action.waist_action_joint[3]`、`action.lower_body[15]` 等。
- `action.pivot` 字段名（README）：`['vx','vy','angle_z','pivot_3','pivot_4','pivot_5','height']`。
- 本数据中：`pivot[0]/[1]` 几乎为 0（max 3.3e-3 / 8.4e-5），`pivot[2]/[3]/[5]` 恒为 0，`pivot[4]=0.15` 恒定，`height` 仅 0.7213–0.7400。
- `waist_state_joint[2]`（pitch）在 0.1249–0.2039 rad 变化，均值 0.1685；`waist_state_joint[0]/[1]` 约 ±0.05/±0.04。
- `action.waist_action_joint` 与 `waist_state_joint` 几乎相同，说明演示中腰部有小幅运动，但 **pivot 不是 waist 的直接镜像**（`pivot[4]=0.15`，waist pitch 均值 0.1685，且范围不同）。
- `action` 与 `state` 的跟踪误差在 lag 2–3 帧最小（30fps 约 67–100ms）；右臂误差整体大于左臂。
- 结论：**固定底座桌面操作 + 轻微腰部参与；无 torque/current 观测；动作有 2–3 帧跟踪延迟。** `pivot_3/4/5` 语义未公开，不能假定可控制腰部或底盘。

### 1.5 API 硬约束

来自 `unibot_submission` README：

- `control_space` 只能是 `"joint"` 或 `"ee"`，互斥。
- `obs_delta_indices` 同时决定“传哪些观测”和“每键堆叠几帧”；`image_resize` 可自定；`action_chunk_size` 自定。
- `get_action(obs)` 返回一个 chunk；评测端按索引 0..T_a-1 顺序执行，"until the evaluator calls `get_action` again"。
- **没有文档化的 mid-chunk 中断/重规划接口。** 保守假设：chunk 是不可分割的开环执行单元。
- `reset()` 每 episode 一次；token 在 metadata 和每步 `meta.token` 双处校验。
- 生产评测逐步调用并记录延迟；N 端口可能并发；每端口状态必须隔离。
- 结论：接触反射只能在 chunk 边界；T_a 越大，盲区越大；T_a 越小，推理频率越高。T_a=6 是首轮折中，需用 4/8/16 消融。

### 1.6 官方底座 WLA-1.0

来自官方 GitHub/项目页/HF：

- 6B 参数：4B UnifoLM-ER-Flow（Qwen3-VL-4B 系）+ MMDiT 动作专家；约 2,500 小时真机数据；64 任务（54 桌面 + 10 全身）；Apache-2.0。
- 默认微调：**冻结 VLM backbone**，只训 action expert + robot-state projector；**单卡 24GB** 可跑；支持 LoRA。
- 预训练含 **interaction-centric world modeling**：给定图像和任务/动作，VLM 预测未来动态区域的 mask token，光流监督。
- **未核实**：未来预测头在推理时是否动作条件化；是否能直接用于候选 chunk 后果预测。STANCE 不把它当主依赖，只把它当可选辅助。

> 再次强调：公开榜单是占位，以下不是“真实排名分析”，而是“公开模型族的技术路线分析”。占位名单中的 VLAGO、DM0、RoboReasoner、GigaBrain-0 缺少一手材料，不硬编。

### 2.1 五种路线

|---|---|---|---|---|

### 2.2 共同瓶颈：最后三厘米与失败恢复

1. **成功演示偏置。** 数据几乎全是成功轨迹；模型没学过“卡住/滑了/抓空/被人类移走之后怎么办”。
2. **动作块开环。** T_a 步内看不到接触事件；T_a=8 在 30Hz 下约 0.27s 盲区；人为干扰可能更快。
3. **没有力/触觉。** 公开观测没有 torque/current/force/tactile；接触丰富任务需要力调制，纯视觉看不到“插头有没有对准孔”“拉链有没有咬住”。
4. **世界模型预测像素/潜状态，不是接触状态。** 视频可以“想象”插进去，但不等于知道真实反作用力；7Hz 追不上接触瞬态。
5. **单模型约束。** 不能为 T10、T19 各放一个模型；per-task LoRA/模型合并的合规性也未明；必须在推理时任务条件化 + 运行时 adaptation。
6. **指标错位。** 平均成功率/进度 ≠ 320 次整集成功；尾部失败才是主指标。

### 2.3 为什么“榜首 <30%”不奇怪

- 32 任务 × 5 轴 × 2 次；任何一步失败整集归零；接触丰富任务约 20/32；180 秒；无力/触觉。
- 外部 RoboChallenge 30 任务上，最强公开系统约 50% 成功率；UniBot 的桌面精细操作/闭合/插入更密集，30% 量级并不离谱。
- 占位 JSON 的步骤分 39.0 vs 成功率 29.7（差 9.3pp）如果为真，暗示“做了大部分步骤、倒在最后接触”；但它是占位数据，只能当假设。
- **结论：头部缺的不是语义，而是接触期物理反馈与失败恢复。** 这正是 STANCE 的位置。

### 2.4 我们借什么、不借什么

- 借：MolmoAct2 的空间先验/开放生态；Wall-OSS 的跨具身数据配方；DreamZero 的“预测作为验证”思想；Spirit/LingBot 的工程纪律；WLA 的 6B 底座与 24GB 微调。
- 不借：14B 世界模型主回路；7Hz 视频闭环；纯成功演示训练；每任务模型；把步骤分当主指标；把 `pivot` 当已知可写接口。

### 3.1 PCE：本体感觉接触估计

#### 3.1.1 信号

- 关节模式：`a_{t−δ}` 为 δ 步前的手臂/夹爪命令；`s_t` 为当前关节位置/速度；`r_t = s_t − ŝ_t^free`。
- EE 模式：`p_t` 为当前 EE 位姿；`p_{t−δ}^{cmd}` 为命令；残差含位置 + 旋转（轴角/李代数）。
- 辅助：夹爪开度、`lower_body[15]`（含腰部/腿）、腕部图像特征、相位 `φ_t`。
- 时间对齐：HangCup 实测 lag 2–3 帧最优；PCE 显式搜索/估计 δ，避免把控制延迟当接触。

#### 3.1.2 自由空间名义模型

\[
\hat s_t = f_\theta(s_{t-1}, a_{t-\delta}, \phi_t)
\]

- 每关节 ARX(2–3) + 小 MLP 残差；或一个 1D temporal CNN。
- 只用成功演示的**自由空间段**（预接触、释放后、无物体接触）拟合；接触段不参与名义模型。
- 相位分层协方差 \(\Sigma_\phi\)；自由空间/接近/接触/释放分别校准。

#### 3.1.3 接触分数与分类

\[
r_t = s_t - \hat s_t^{free}, \quad
z_t = \sqrt{r_t^\top \Sigma_\phi^{-1} r_t}
\]

\[
p_t = g_\psi(z_{t-k:t}, \dot s_t, g_t, \phi_t)
\]

- 输出：`free / contact / slip / jam` 四类 + 置信度；`progress` 由 SSG/视觉/EE 位移估计。
- 训练标签：
  - 仿真：特权接触力/接触点 → 四类标签；
  - 真实演示：任务相位/夹爪闭合/物体开始运动 → 弱标签；
  - 调试槽：少量人工标注的失败/接触片段 → 校准。
- 负样本挖掘：人为注入 lag、负载、摩擦、传感器噪声，防止把“慢跟踪”学成“接触”。
- 校准：按任务/相位分层，conformal 选阈值；只有超过阈值才触发 CAS，控制误报。

#### 3.1.4 接触类型

| 类型 | 残差特征 | 视觉/状态证据 | CAS 反应 |
|---|---|---|---|
| impact | 短时高频尖峰 | 物体/桌面接触瞬间 | 减速、保持 |
| sustained | 残差持续升高、速度低 | 末端不动、物体被压 | 小步推进/保持 |
| slip | 残差方向随重力、夹爪仍闭 | 物体下坠/位移 | 立即后退/重抓 |
| jam | 残差高 + 推进无进展 | 孔/槽卡住、物体不动 | 回退 + 微旋转/侧向搜索 |
| miss | 夹爪闭合到底、残差自由 | 腕部图像空 | 重开/重对准/重抓 |

### 3.2 CAS：接触感知监督器

#### 3.2.1 状态机

| 状态 | 进入条件 | 动作 | 退出条件 |
|---|---|---|---|
| FREE | 远离接触 | 放行 VLA；速度/加速度限制 | 进入预接触区 |
| APPROACH | 距目标 < 5–8 cm | 降速、对准、缩小步长 | 距目标 < 2–3 cm |
| GUARD | 距目标 < 2–3 cm | 慢速小步；准备探测 | 接触概率升高/到达表面 |
| PROBE | 接触不确定/卡死 | 侧向微扰、螺旋搜索、微旋转 | 接触稳定/对准 |
| INSERT | 接触稳定且对准 | 小步推进 + 姿态微调 | 到达深度/卡死 |
| SEAT | 到达目标位 | 轻压/轻敲/保持 | 稳定/滑移 |
| RELEASE | 放置/插入完成 | 开夹爪、等待、验证 | 物体留在目标/滑落 |
| RETREAT | 卡死/滑移/高残差 | 沿接近方向后退 | 安全距离 |
| RECOVER | 失败已发生 | 重抓/重对准/换手/重置 | 恢复/放弃 |
| DONE/ABORT | 成功/预算耗尽 | 结束 | — |

#### 3.2.2 位置空间 admittance

```text
a_exec = (1−α) · a_VLA + α · a_safe
α = clip((p_contact − τ_low) / (τ_high − τ_low), 0, 1)
if z_t > τ_jam and progress < ε:
    a_safe = retreat(d=1–2 cm) then probe(spiral/rotation)
elif p_slip > τ_slip:
    a_safe = retreat + lower + regrasp
else:
    a_safe = slow_approach(v_max, step_max)
```

- 安全包络：接触区 Cartesian 速度上限（如 2 cm/s）、关节单步上限、工作空间盒、最大倾斜、夹爪闭合距离代理、180s 预算。
- **不是力控**：不承诺真实阻抗；它是“用位置命令模拟柔顺”的工程近似。对插头/拉链等持续力控任务，只能靠小步、微扰、回退与视觉验证。
- 反射频率：chunk 边界；T_a=6 折中；消融 4/8/16。

#### 3.2.3 任务特化参数（示例，需调试槽校准）

| 任务 | 接近速度 | 插入步长 | 探测 | 回退 | 释放验证 |
|---|---|---|---|---|---|
| T10 插插头 | 慢 | 1–2 mm | 侧向螺旋 + 微旋转 | 1–2 cm | 视觉+残差 |
| T26 插网线 | 慢 | 1–2 mm | 侧向搜索 | 1–2 cm | 卡扣声/视觉（声不可用则视觉） |
| T12 开锁 | 中 | 旋转步 1–2° | 微往复 | 0.5–1 cm | 锁芯转动视觉 |
| T19 拉拉链 | 中 | 沿轨迹小步 | 张力微调 | 0.5 cm | 拉链闭合视觉 |
| T27 叠碗 | 中 | 下降 2–3 mm | 轻敲/保持 | 1 cm | 稳定/滑移 |
| T24 传送带 | 快 | 跟踪 | 预测目标 | 重定位 | 抓取成功视觉 |

### 3.3 BSS：盲末段技能集

- 技能：insert、hook、stack、zip、cap、pour、syringe、grasp。
- 输入：本体感觉历史（关节/EE/夹爪/waist）+ 腕部图像 + 语言 embedding + 相位。
- 输出：EE delta pose + gripper（10–20Hz），或关节增量。
- 训练：
  1. 仿真教师：Isaac Lab/MuJoCo，带接触特权（力/接触点/物体位姿）；
  2. 学生蒸馏：只用本体 + 腕部图像；域随机化摩擦/质量/高度/位姿/光照/遮挡；
  3. 真实微调：官方演示 BC + 调试槽少量数据；不按任务切模型。
- 单 checkpoint：task/phase embedding 区分技能；所有技能共享主干；对外一个 policy。
- 兜底：若 sim-to-real 不成立，BSS 降级为脚本原语 + 小残差策略；PCE/CAS 仍独立成立。
- 证据：Blind Precise Assembly（纯本体 73% 插入）、Blind Dexterity（G1 纯本体全身）、UniTac（关节传感器触觉定位）。

### 3.4 WBG：腰部预姿态

- 数据：`waist_state_joint[3]`；HangCup 的 pitch 0.125–0.204 rad；`action.pivot` 平移≈0、`pivot[4]=0.15` 恒定。
- 可用做法：
  - 按任务把 waist pitch 预置到演示中位数，让手臂留在舒适工作空间；
  - 接触期锁腰，避免接触力把身体推走；
  - 只在自由空间缓慢调整，避免影响接触。
- 限制：
  - `pivot_3/4/5` 语义未公开；`pivot[4]` 与 waist pitch 不相等，不能把 `pivot[4]` 当 waist 命令；
  - 默认不写 `pivot`；先做“只读 waist + 臂补偿”；
  - 若验证 `pivot` 可写且安全，再开“腰部预姿态”。
- 证据：Workhorse 五链路目标 + 全身 tracker；LingBot 2.0 全身 VLA；但平台不同，只借思想。

### 3.5 RER：任务跌倒恢复

| 失败 | 检测 | 恢复 | 预算 |
|---|---|---|---|
| 抓空 | 夹爪闭合到底 + 无残差 + 腕部空 | 重开、重对准、重抓 | 1–2 次 |
| 滑落 | 残差方向突变 + 物体下坠 + 夹爪仍闭 | 后退、降低、重抓 | 1 次 |
| 卡死 | 残差持续高 + 推进无进展 | 回退 1–2 cm、微旋转、再插 | 2 次 |
| 未对准 | 侧向残差 + 视觉孔位偏移 | 侧向搜索、重对准 | 2 次 |
| 人类移走 | 目标消失/位移 + 残差自由 | 重新观察、更新目标、重试 | 1 次 |
| 超时 | 180s | 放弃高风险动作，保守结束 | — |

- 重试预算：每步最多 2 次；不可逆步骤（倒药、拉链、插头）更保守；可用 RAMP 的 SORS 动态规划。
- 关键是“早退”：在物体掉落/插头弯折之前退，而不是失败后重来。

### 3.6 CAL：接触压力校准

| 维度 | 构造 | 指标 |
|---|---|---|
| 位置 | 演示初始位姿聚类，留出整簇 | 成功率、PCE AUROC |
| 干扰物 | 2.5D 插入无关物体 | 误报、恢复率 |
| 背景 | 换桌布/光照/纹理 | PCE 稳定性 |
| 未见物品 | 同类别不同外观/尺寸/摩擦 | 泛化、滑移检测 |
| 人为干扰 | 按官方 `human_1/4_note` 回放 | 惊奇检测、恢复 |
| 接触压力 | 质量 0.5–2×、摩擦 0.2–1.0、高度 ±1cm、位姿 ±2cm、遮挡、透明/可变形 | 接触检测、CAS 安全 |

- 每个维度都做训练/校准/测试三分，按任务/轴分层，不做全局阈值。
- 这套东西是“数据 + 流程”，不是模型；可直接用于离线评测和提交前门禁。

### 3.7 单 checkpoint 与合规

- 学习组件：WLA、PCE、BSS（可选）全部打进**一个 checkpoint**；用一个 `policy` 类、一个端口对外。
- 确定性组件：CAS、RER、SSG、WBG、CAL 是代码/数据，不是模型。
- 模型卡：列出模块、训练数据、是否使用外部数据/仿真、`pivot` 是否写入、接触层触发条件。
- 风险：官方对“单模型”的定义未细化；多 head 可能被审计。保守做法是单 checkpoint + 明确披露；若仍不允许，PCE 可退化为确定性残差阈值，BSS 退化为脚本原语。

## 4. 伪代码

### 4.1 推理主循环

```python
class StancePolicy:
    def __init__(self):
        self.wla = load_wla(...)
        self.pce = load_pce(...)
        self.cas = ContactSupervisor(...)
        self.rer = TaskFallRecovery(...)
        self.history = deque(maxlen=32)

    def get_action(self, obs):
        phase = self.ssg.phase(obs.language, self.history)
        a_vla = self.wla.predict(obs, phase)          # (T_a, action)
        a_exec = []
        for k in range(len(a_vla)):
            s = self.history.state(k)                  # aligned delayed state
            p_contact, p_slip, p_jam = self.pce.predict(
                s, self.history.actions, obs.gripper, phase)
            a = self.cas.reshape(a_vla[k], p_contact, p_slip, p_jam, phase)
            a = self.rer.guard(a, p_slip, p_jam, phase)
            a_exec.append(a)
        self.history.update(obs, a_exec)
        return pack(a_exec, token=...)
```

### 4.3 CAS 状态机

```python
def reshape(self, a_vla, p_contact, p_slip, p_jam, phase):
    if p_slip > tau_slip:
        return self.retreat_lower(a_vla)
    if p_jam > tau_jam and self.progress < eps:
        return self.probe_or_retreat(a_vla, phase)
    if p_contact > tau_contact:
        a_safe = self.slow_approach(a_vla, phase)
        alpha = clip((p_contact - tau_low) / (tau_high - tau_low), 0, 1)
        return (1 - alpha) * a_vla + alpha * a_safe
    return a_vla
```

## 5. 数据引擎

### 5.1 官方数据

- 32 数据集、约 32k episodes / 169h；HangCup 1,043 / 194,564 帧 / 30fps；四路相机；EE 位姿 base/torso 两套；5 条英文复述。
- 用途：自由空间名义模型；接触相位弱标签；成功轨迹 BC；任务/语言 embedding；放置位姿统计。
- 不把官方数据当“失败数据”；失败数据要另造。

### 5.2 残差数据集

- 对每个演示，按 SSG 相位切分：pre-contact / approach / contact / release / post-release。
- 自由空间段拟合 `f_θ`；接触段提取残差特征；用夹爪闭合、物体开始运动、评分步骤做弱标签。
- 负样本：人为注入 lag（1–5 帧）、负载（0.5–2×）、摩擦、传感器噪声；让 PCE 学会区分“延迟/负载”与“接触”。
- 统计：按任务/相位分层保存 `Σ_φ`、阈值、误报率。

### 5.3 仿真接触标签

- Isaac Lab/MuJoCo：G1 + Dex1 简化模型；桌面、杯架、插排、网口、拉链、碗、针管等资产。
- 特权信息：接触力/接触点/物体位姿；只用于教师/标签，不进学生输入。
- 域随机化：摩擦 0.2–1.0、质量 0.5–2×、高度 ±1cm、位姿 ±2cm、光照、遮挡、相机噪声。
- 任务：insert、hook、stack、zip、cap、pour、syringe；每任务 1k–5k episodes（仿真）。
- 验收：教师成功率 >80%；学生 sim 成功率 >70%；sim-to-real 先用调试槽小样本。

### 5.4 扰动/校准套件

- 官方 5 轴 + 接触压力 6 维；每维构造 train/cal/test 三份。
- 人类干扰按 `human_1_note`/`human_4_note` 回放（平移/撤销/移走）；不依赖语言理解，靠视觉+残差。
- 透明/可变形/小件单独分桶；PCE 阈值分桶校准，不搞全局平均。

### 5.5 失败数据

- 仿真失败：教师/学生 rollout 的抓空、滑落、卡死、超时。
- 真机失败：调试槽 + 计分跑（若允许记录）；人工标注失败类型。
- 人类备注：官方 `human_1/4_note` 作为恢复剧本。
- 数据量：先 500–1000 条失败片段做 RER/PCE 校准，不追求大规模。

## 6. 训练配方

### 6.1 WLA 微调

- 底座：UnifoLM-WLA-1.0-Base（6B，Apache-2.0）。
- 冻结 VLM；训 action expert + robot-state projector；24GB 单卡；LoRA 备用。
- 动作空间：默认 EE（便于接触期位置空间治理）；对照 joint。
- 观测：四路 RGB（可 resize 240×320）、双臂关节/EE、夹爪、lower_body、语言；`obs_delta_indices` 含历史帧。
- 动作块：T_a=6 首轮；消融 4/8/16。
- 数据：32 任务官方演示；5 条复述；图像增强（背景/光照/遮挡）但不破坏接触几何。
- 目标：不是“更高的动作似然”，而是“整集成功”；用成功/失败/恢复数据加权。

### 6.2 PCE

- 模型：每关节 ARX + 2 层 GRU/MLP（<10M 参数）；或共享时序编码器。
- 输入：对齐后的命令/状态历史、夹爪、相位、腕部特征（可选）。
- 输出：4 类 + 接触分数；按相位分层校准。
- 训练：自由空间名义损失 + 分类 CE + conformal/误报惩罚；负样本挖掘。
- 资源：单卡数小时–1 天；CPU 推理 <1ms/步（批量）。

### 6.3 BSS

- 教师：仿真 RL/BC，带接触特权；每技能 1k–5k episodes。
- 学生：本体 + 腕部图像；蒸馏 + 域随机化；真实演示 BC 微调。
- 资源：1–2 GPU × 1–2 周；若算力不足，先脚本原语。
- 验收：sim 5 技能平均 >70%；真机不低于脚本基线；否则降级。

### 6.4 算力与时间

- WLA 微调：单卡 24GB 可跑；多卡更快。
- PCE：<1 GPU-day。
- BSS：1–2 GPU × 1–2 周（可选）。
- 总预算：2–4 GPU-weeks；不依赖 14B 世界模型。

## 7. 实验矩阵

### 7.1 离线

| 实验 | 数据 | 指标 | 通过条件 |
|---|---|---|---|
| PCE 接触检测 | 留出任务/轴 | AUROC/AUPRC、90% recall 下误报 | AUROC ≥0.75，误报 ≤5% |
| 时间对齐消融 | 注入 lag 1–5 帧 | AUROC、误报 | 对齐后显著优于不对齐 |
| 相位条件消融 | 全局 vs 分层 | AUROC、校准误差 | 分层更好 |
| 自由空间名义模型 | 演示自由段 | 残差分布、漂移 | 残差稳定，无任务偏差 |
| 接触分类 | sim + 真机弱标签 | 混淆矩阵 | slip/jam 不混为 free |

### 7.2 仿真

| 实验 | 设置 | 指标 | 通过条件 |
|---|---|---|---|
| 5 技能 | insert/hook/stack/zip/cap | 成功率、接触检测 | 平均 ≥70% |
| 扰动 | 摩擦/质量/高度/位姿 | 成功率、恢复率 | 下降 ≤10pp |
| 消融 | VLA / +PCE / +CAS / +BSS | 成功率、时间 | +CAS ≥+5pp |
| 延迟 | T_a=4/8/16 | 成功率、反射延迟 | T_a=6 最优或接近 |

### 7.3 真机（调试槽）

优先任务：T10 插插头、T26 插网线、T12 开锁、T19 拉链、T27 叠碗、T24 传送带。

| 条件 | 试次 | 指标 |
|---|---|---|
| WLA only | 10–20 | 整集成功、首试成功、时间 |
| WLA + PCE + CAS | 10–20 | 同上 + 误报/恢复 |
| + RER | 10–20 | 恢复成功率 |
| + BSS | 10–20 | 接触簇成功 |
| 消融 | 关键条件 | 配对位姿、Wilson CI |

- 目标：总平均 +5pp；接触簇 +10pp；保守 +3pp。
- 统计：配对初始位姿；bootstrap；按任务/轴分层；不拿单轴结果做结论。

### 7.4 消融

- 去 PCE（仅相位调度）→ 证明残差信号有用。
- 去 CAS（仅 PCE 报警）→ 证明运动治理有用。
- 去相位 → 证明相位条件化有用。
- 去 lag 对齐 → 证明延迟补偿有用。
- 去 RER → 证明恢复有用。
- WBG on/off（若可用）。
- EE vs joint。
- T_a=4/8/16。

### 7.5 停止条件

- PCE AUROC <0.65 或误报 >10% → 关闭学习型 PCE。
- CAS 在 T10/T26 <+3pp → 回退 WLA+SVL。
- 反射延迟 >400ms 或有效频率 <12Hz → 缩 T_a/异步，仍不达标则放弃反射。
- BSS sim <70% 或真机低于脚本 → 降级脚本。
- WBG 导致底盘运动/不稳定 → 关闭。
- 任何安全风险（碰撞、掉落、损坏）→ 立即回退保守策略。

## 10. 创新点清单（详细）

> 状态：押注=本轮主线；保留=沿用；升级=旧点改造；降级=保留但非主回路；可选=条件启用；砍=不做。

### I1 PCE 命令–状态残差接触估计（新增，押注）

- 动机：无 torque/current/force/tactile；接触丰富任务是失败大头；Blind Dexterity/CoPRE/UniTac 证明本体感觉可做接触。
- 差异：不是学一个视觉接触分类器，而是把“命令–状态跟踪偏差”做成时间对齐、相位分层、校准的接触信号；不需要额外传感器。
- 可行性：官方观测足够；HangCup 实测 lag 2–3 帧；小模型 <10M；单卡数小时。
- 资源：官方数据 + 仿真标签 + 少量调试槽；1 人 2 周。
- 步骤：自由空间名义模型 → lag 对齐 → 相位协方差 → 分类器 → conformal 校准 → 离线 AUROC。
- 风险：残差混淆；误报；透明/可变形任务失效。
- 停止：AUROC <0.65 或误报 >10%。

### I2 CAS 接触感知监督器（新增，押注）

- 动机：位置接口不能力控，但能控速度/步长/回退/探测/保持；接触期需要“怎么动”的治理。
- 差异：不是 MPC，不是力控；是确定性 FSM + 位置空间 admittance；只在接触期接管，不改变 VLA 语义目标。
- 可行性：纯代码；可用仿真/调试槽调参；与 WLA 解耦。
- 资源：1 人 2 周；无额外训练。
- 步骤：状态机 → 安全包络 → 任务参数 → 仿真 → 调试槽 T10/T26 → 校准。
- 风险：位置柔顺不足；参数过保守导致超时。
- 停止：接触簇 <+3pp。

### I3 BSS 盲末段技能集（新增，条件押注）

- 动机：最后 1–3 cm 视觉不可靠；纯本体技能可补；Blind Precise Assembly 73%、Blind Dexterity G1。
- 差异：相位条件化、单 checkpoint、多技能共享；不是每任务模型；只接管接触末段。
- 可行性：仿真教师 + 学生蒸馏；1–2 GPU × 1–2 周；脚本兜底。
- 资源：Isaac Lab/MuJoCo；G1+Dex1 简化资产；5 技能。
- 步骤：教师 → 学生 → 域随机化 → 单 checkpoint → sim 验收 → 真机。
- 风险：sim-to-real；训练时间；单模型审计。
- 停止：sim <70% 或真机低于脚本。

### I4 RER 任务跌倒恢复（升级 NRB）

- 动机：四足摔倒会站起来；桌面任务抓空/滑落/卡死/人类移走后需要恢复；success-first 下一次失败即整集归零。
- 差异：从“官方干扰回放”升级为“失败分类 + 恢复原语 + 重试预算”；强调早退。
- 可行性：确定性代码 + 少量失败数据；可复用 RAMP SORS。
- 资源：1 人 1–2 周；调试槽。
- 步骤：失败分类 → 恢复原语 → 预算 → 仿真 → 真机。
- 风险：不可逆步骤越恢复越糟；超时。
- 停止：恢复率低于重试基线。

### I5 WBG 腰部预姿态（新增，可选）

- 动机：G1 腰部可动；数据 waist pitch 0.125–0.204；用腰把手臂留在舒适空间。
- 差异：不是移动底盘；只在自由空间预姿态、接触期锁腰；默认不写 `pivot`。
- 可行性：只读 waist 可用；`pivot` 权限未核实。
- 资源：确定性代码；1 人 3–5 天。
- 步骤：只读 waist → 臂补偿 → 预姿态 → `pivot` 验证 → 安全开关。
- 风险：pivot 语义不明；底盘运动；接触力推身。
- 停止：不稳定/不可写 → 关闭。

### I6 CAL 接触压力校准（新增，支撑）

- 动机：PCE/CAS 阈值必须按任务/轴/接触物理校准；否则误报/漏报。
- 差异：不是泛 OOD 集；是“5 轴 + 摩擦/质量/高度/遮挡/透明/可变形”的分层校准。
- 可行性：官方数据 + 仿真 + 调试槽；流程化。
- 资源：1 人 1–2 周；数据工程。
- 步骤：维度设计 → 构造 → 分层 → 校准 → 门禁。
- 风险：仿真不真实；标注成本。
- 停止：校准集与真机偏差大 → 缩小到关键任务。

### I7 SSG 评分步骤图（保留，降级）

- 从“主控制器”降为“相位提供者”：给 PCE/CAS/BSS 提供 pre-contact/contact/release 标签；给 RER 提供步骤状态。
- 不再用步骤分当主杠杆；谓词头保留，但只做诊断/恢复触发。

### I8 SVL 落点闭环（保留，升级）

- 原 SVL 做“释放后稳定检测”；升级为 SEAT/RELEASE/VERIFY：轻压/轻敲/保持、开夹爪、验证物体留在目标、滑移则重抓。
- 与 PCE 的 slip 检测联动。

### I9 OPT/PGL 放置位姿迁移（保留，子技能）

- 作为 BSS/放置子技能；不再单独当主线；提供容器系相对位姿统计与目标阶梯。
- 透明/布料任务分桶回退。

### I10 RAMP 预测式候选选择（可选外环）

- 保留其 success-first 纠正、风险/可恢复性 head、SORS；作为 STANCE 外环可选。
- 不作为本轮主押注；避免 14B 世界模型/多 head 复杂度。

### I11 WLA-1.0 底座 + 数据引擎（保留）

- 唯一学习主干；冻结 VLM，训 action expert；24GB；LoRA 备用。
- 数据引擎：官方 32k + 仿真 + 扰动 + 失败片段。

### I12 L2L 产学研数据协议（保留，低优先）

- 背景/位置多样性；外部数据规则未明，默认 OFF；邮件确认后再开。
- 不作为本轮主线。

### I13 DebugLoop + FLEET 检查单（保留，工程）

- 调试槽做发布门；N 端口/状态隔离/延迟弹性/健康检查。
- 不当作研究贡献。

### I14 ICR 检索条件化（降级，可选）

- 作为可选上下文；不再当中心组件；延迟/透明任务风险高。

### 已砍/暂不做

- 全 32 任务高保真孪生；运行时仿真 MPC；14B 世界模型主回路；每任务 LoRA/模型合并；布料/透明全物理；把步骤分当主杠杆；自由仿真数据直接混训（规则未明）。

## 13. 一句话押注

**在 success-first 的 320 次全有或全无真机试炼里，最值得押注的不是再训一个更大的 VLA，而是把四足机器人赖以生存的本体感觉接触估计、接触期运动治理和任务跌倒恢复装到 WLA 外面：让模型在最后 3 厘米知道自己摸到了什么、该退还是该进、失败后怎么再来一次。**
