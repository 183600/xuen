# 第 70 轮（承接第 69 轮「FLUID-RAS 不确定性二分与主动交互消歧」IP-253~263；本轮灵感：「用户测试」×「最小可行产品」）

> R69 把不确定性一分为二（aleatoric / epistemic），让系统学会「问、看、摸」，并用流匹配多模态策略与流似然第二意见补上了 R68 的两个洞。但 R69 有一个从未被检验的隐含前提：**「问」这个动作本身是有效的**。它默认回答能降低关于模态的不确定性、默认回答者在回答「系统以为自己在问的那个问题」、默认一次成功的消歧在真实用户身上真的转化为任务收益。R69 自陈的最大风险——模态权重不可信、问错比不问更危险——恰恰是这套内部信念无法自证的：**用系统自己的模态分布去评估系统自己的提问，是一个封闭的自我确认循环。**
>
> 本轮两个灵感正好从外部打破这个循环：
> - **用户测试**给出「外部效度」：人不该被当作神谕，而应被建模为一台**有偏、有方差、有能力上限、有激励、有群体差异的测量仪器**；问句是一个**心理测量条目**，必须做构念效度、重测信度、人群效度与预注册对照；
> - **最小可行产品**给出「内部效度的最小载体」：先交付一个**能被独立证伪的最小闭环**（一次探询 → 一个回答 → 一次信念更新 → 一次动作 → 一条反事实日志），只有它通过了预注册的反事实检验，才允许扩展成完整的 FLUID-RAS；否则就 kill 掉交互层，退回 R68。
>
> 核心命题：**把「交互」从「读取神谕」降级为「做一次实验」，把「用户」从 ground truth 降级为「带响应模型的仪器」，把「完整系统」降级为「最小可行探询 + 测试门控的部署」。** 交互层的默认状态是关闭（shadow mode），只有当 held-out 用户上的反事实效应置信下界为正、且打扰可持续时，才允许上线。命名 **PILOT-RAS**（Probe-ladder, Instrumented respondent, Learned validity, Optimal test design, Test-gated deployment）——它既是「试点研究」（MVP），也是「飞行员」（人因回路里的谨慎试飞）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我怎么知道这次求证真的有用、而不是我自己想听**」——不确定性不只需要一句提问，还需要一次诚实的、会被证伪的用户测试。

## 0. 直觉与动机

**灵感 1（MVP → 最小可行的是「闭环」，不是「功能」）**
直觉：R69 的 FLUID-RAS 有六个组件（FMP/AUD/MINT/CIA/FMA/MCG），每个都要独立信任，而全部效率收益押在「模态分布可信」上。如果这个前提错了，整个塔都建在沙上。MVP 的第一性原理不是「砍功能」，而是**先交付一个能产生真实反馈、能被证伪的最小闭环**：状态 → 一次探询 → 一个回答 → 一次信念更新 → 一次动作 → 一条可归因的日志。若连「这一次探询是否让任务更好」都无法识别，那么再多的组件也只会放大一个未经检验的信念。所以本轮的最小单元不是 FLUID-RAS，而是 **Minimum Viable Probe（最小可行探询，MVP 的双关）**：最便宜、最不打扰、却足以判别当前歧义的那一次动作。MVP 在这里是**证伪装置**，不是产品缩水。

**灵感 2（用户测试 → 人不是神谕，是仪器）**
直觉：R69 把人的回答当作证据源，加了抗投毒与「k 个正交源一致」，但仍隐含假设：回答者在回答系统问的那个问题，且回答与真实模态相关。用户测试的教训恰恰相反——人是一台**有系统偏差、有随机方差、有能力上限、有激励、且分布在不同人群里的测量仪器**。同一个问句，可能被误解（构念无效）、可能不稳定（重测信度低）、可能诱导（acquiescence / leading）、可能只对某类用户有效（人群效度差）。因此必须给人建模：响应者群体 u~π(u)，能力 κ_u、偏差 β_u、信度 ρ_u、随和/诱导易感 ℓ_u；把「问一次」从「读取神谕」改写成「对一个人做一次心理测量」。

**灵感 3（用户测试 = 外部效度，MVP = 内部效度的最小载体）**
直觉：R69 的所有定理都是**内部效度**（在 A95–A98 假设下成立）。用户测试提供**外部效度**：真实任务、held-out 用户、预注册成功/失败标准、盲法、反事实对照（问 vs 不问）。MVP 提供内部效度的最小载体：一个可被独立复现、独立证伪的最小实验，而不是一堆耦合模块。二者合起来就是**证据分级**：一个主张必须先过 MVP 的最小证伪，再过用户测试的外部验证，才允许进入闭环默认路径。这不是给论文加一节实验，而是把「证据强度」变成系统运行时的一个显式状态。

**灵感 4（探询阶梯 → 把「问人」放到最后，而不是第一）**
直觉：R69 的 MINT 在候选信息动作里按 VoI 选，但默认看/问/触都可选。MVP 的产品直觉是「最便宜的先试」：先看已有模态是否可分（免费），再等待/多看一帧（几乎免费），再轻微注视/调整视角（低扰动），再触/力探针（有物理风险），最后才问人（高成本、高打扰、有偏）。这形成一条 **escalation ladder**。用户测试还告诉我们一件 R69 没写进模型的事：**过度询问会让人烦躁、敷衍、直答（straight-lining），甚至欺骗**——交互疲劳是真实先验，不是软约束。问得越多，单次回答的信度越低、成本越高，最终有效 VoI 会变负。

**灵感 5（证伪优先 → 对 R69 最大风险的正面回应）**
直觉：R69 的最大风险是「模态分布可信吗」，这是一个**内部信念**问题，无法用内部信念回答。用户测试给出一个不依赖内部信念的检验：**在不问的情况下系统会怎么做？问了之后在 held-out 用户上是否真的更好？** 这是一个反事实/消融检验，能直接证伪「交互有用」的主张。MVP 给出更狠的判据：如果最小探询的边际收益 ≤ 成本 + 打扰 + 疲劳代价，就 kill 掉整个交互层，回到 R68。于是 R69 的「问错比不问更危险」第一次变成一条可执行的 **kill criterion**，而不是一句风险声明。

**灵感 6（Goodhart 的反面 → 测试本身也需要被测试）**
直觉：一旦「用户测试通过」成为部署门，「让测试通过」就变成优化目标——样本选择、指标挑选、停止规则、事后剔除，都会悄悄把测试变成自我实现的预言。所以本轮必须交付**测试的测试**：预注册哈希、held-out 划分、intention-to-treat、多重比较校正、以及「选探询的测试」与「评探询的测试」必须分离。PILOT-RAS 不能自证；它必须把「独立性」写成一条可审计的制度约束，而不是假装它是数学定理。

## 1. 形式化定义（增量：定义 310–323）

**定义 310（PILOT-RAS 总览）** PILOT-RAS = (MPL, RIM, VBD, CATE, TGE, RAS-WM††)。四条不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i、R69 定义 293-i）；
(ii) **MVP 门**：交互层默认关闭（shadow mode），除非最小可行探询通过预注册反事实测试且证据级别 ≥ E4（定义 317–318）；
(iii) **可废止性**：用户可随时 veto / opt-out，且 veto 不得被「提升 VoI」为由绕过；veto 一律视为效度或越界证据（定义 322）；
(iv) **打扰可持续性**：长期询问率 ≤ r\*（定义 319 引理 21），疲劳状态 F 单调反馈进成本与信度。

**定义 311（探询阶梯 MPL）** 层级 ℓ=0,…,L：ℓ0 现有观测（c≈0）、ℓ1 等待/多看一帧（c≈0）、ℓ2 注视/调整视角（低扰动）、ℓ3 触/力探针（有物理风险）、ℓ4 问人（高成本、有偏、有社交后果）。第 ℓ 层动作 g_ℓ、成本 c_ℓ、扰动 D_ℓ、名义边际信息 ΔI_ℓ。选择**最小** ℓ 使
  ΔI_ℓ − c_ℓ − λ_D·D_ℓ > 0，且过 C-RAS-WM 认证（继承 R69 定义 302）。
**最小可行探询** g† = argmin_ℓ c_ℓ，s.t. 期望判别力 ≥ τ_d 且 V(g_ℓ) ≥ v_min（V 见定义 313）。人不是第一手段，而是阶梯顶端。

**定义 312（响应者仪器模型 RIM）** 回答者 u~π(u)，对模态 m、探询 g 的回答 y 服从信号检测型响应：
  p(y | m, g, u) = (1−λ_u)·σ(d'_u(g)·s(m,y) + β_u) + λ_u·q_0(y)，
其中 s(m,y)=+1（y 与 m 一致）或 −1；d'_u(g) 为该用户在该探询上的敏感度，β_u 为偏差（含随和/诱导易感 ℓ_u），λ_u 为失误率，q_0 为先验回答分布。信度 ρ_u(g) = test–retest ICC。传感器/环境类响应者取 κ=1、β=0、ρ=1 的退化情形。RIM 的作用不是「更准地信人」，而是**在计算 VoI 之前先把人折算成一台仪器**。

**定义 313（探询效度 V(g)）** 构念效度 V_con = I(M;Y|g,U)/H(M)（回答是否真的携带模态信息、而非任务无关的干扰）；人群效度 V_ext = 在 held-out 人群 U_test 上的同量。总效度 V(g) = min(V_con, V_ext)——**下限而非平均**，因为部署最怕的是在某一人群上系统性失效。V(g) < v_min 的探询，其名义 VoI 不得进入决策。

**定义 314（折算 VoI）** 
  VoI_eff(g) = ρ̄(g)·V(g)·[H(M|o) − E_{y|g,o} H(M|o,y)] − c(g) − λ_D·D(g) − λ_F·F(t)·1[g 为人]。
使用**有效信息**而非名义信息：信度与效度是乘性的折扣，疲劳是加性的税。若所有层 VoI_eff ≤ 0 ⇒ 不交互，走 R69/R68 兜底。注意 VoI_eff 可以为负——这正是「问错比不问更危险」的数学表达。

**定义 315（反事实探询效应 CATE）** 上下文 x=(o, modes, g)，潜在结果 Y(1)=「问了并按回答执行」、Y(0)=「不问直接执行」。τ(x)=E[Y(1)−Y(0)|x]。用倾向得分 e(x)=P(g=ask|x) 与 doubly-robust 估计从日志中估 τ。部署门只依赖 E_{u~U_test}[τ] 的置信下界，而不依赖任何单一成功案例。

**定义 316（用户测试协议 UTP）** 预注册（protocol_hash）锁定：任务集与成功判据、U_train/U_test 划分、对照臂 {no-ask, ladder, oracle}、主指标 task success、次指标 burden / trust calibration / veto rate、样本量与停止规则、盲法与排除标准、多重比较校正（Benjamini–Hochberg FDR）。**kill criterion**：若 Δsuccess 的 95% CI 下界 ≤ δ_min，或 burden 的 P90 > b_max，或 veto rate > v_max ⇒ 交互层禁用。协议与原始日志哈希写入 AuditBuf。

**定义 317（证据级别 E0–E5）** E0 假设、E1 仿真、E2 离线回放、E3 单用户 pilot（MVP）、E4 held-out 用户测试、E5 纵向部署。**证据使用规则**：任何主张只能在其最高证据级别**减一**的部署层级上使用；低于 E4 的探询只能影子运行（shadow mode），不得驱动真实任务动作。这把「我们做过仿真」与「我们敢上线」明确分开。

**定义 318（测试驱动部署门 TGE 与影子模式）** 交互层三态：{off, shadow, online}。默认 off；进入 shadow 需 E3 + g† 合法；进入 online 需 E4 + J_MVP=keep（定义 323）。运行期若 RIM 信度下滑、疲劳越界、或人群漂移被检测到（V_ext 重估下降），自动回 shadow/off。**降级永远比升级快**：升一次要过门，降一次只需一个越界。

**定义 319（疲劳与打扰动力学 FAT）** 
  F_{t+1} = αF_t + η·1[ask_t] − γ·1[¬ask_t]，
  信度 ρ_u(t) = ρ_0·e^{−μF_t}，问人成本 c_ask(t)=c_0·(1+νF_t)，打扰预算为 token bucket，长期速率上限 r_max。三个量共同刻画「越问越不准、越问越贵、越问越烦」。友好用户不是无限资源。

**定义 320（最小可行切片 MVS）** M0 = {编码器 z, 歧义代理（mode_head 或 K=2 采样）, 阶梯探询 g†, 信念更新, 任务动作, 反事实日志器}。M0 是**能识别 τ(x) 的最小闭环**：有处理（探询）、有对照（不问的日志/随机化）、有结果（任务成功）、有归因（上下文）。完整 FMP、CIA、FMA 都是可后加的增强，不是识别因果效应的必要条件。

**定义 321（预注册与反 HARKing 约束）** 测试前锁定假设、指标、停止规则、排除标准；探索性分析必须单独标记，且不计入 keep/kill 决定；报告所有臂与所有被招募用户（intention-to-treat）；多重比较用 FDR；任何协议改动都要新协议号重跑，不得覆盖旧哈希。**选择探询的测试**与**评估探询的测试**必须在用户/时间上分离。

**定义 322（用户否决、同意与不打扰权）** veto/opt-out 是零成本、先验可用的动作；系统不得以任何信息增益为理由绕过；veto 触发阶梯降级并把该上下文标为「高打扰」，回灌 RIM 与成本先验。问人必须有可撤回同意；语言问句不得伪装成任务动作（禁止「社交工程式提问」）。这条不是伦理附录，而是系统状态的一部分。

**定义 323（PILOT 证书 J_MVP）** 
  J_MVP = (protocol_hash, probe_id, level, V, ρ, n, Δsuccess CI, τ̂ CI, burden P90, fatigue_trace, evid_level, kill/keep, veto_compliance)。
  Valid ⇔ 预注册哈希一致 ∧ 样本量达标 ∧ 多重校正已做 ∧ 无未申报事后改动 ∧ veto 处理合规。只有 Valid ∧ keep 的探询才允许进入 online。J_MVP 是 J_FLUID 的**外部效度侧补丁**：J_FLUID 证明「内部算得对」，J_MVP 证明「在真人身上值得算」。

# IP-264 MPL：探询阶梯（最便宜的可行探询优先）
def choose_min_viable_probe(modes, w, o, budget, rim):
    best = None
    for lvl, g in enumerate(ladder(o)):          # observe -> wait -> gaze -> probe -> ask
        if not budget.allow(g):            continue
        if not c_ras_wm.certify_info(g, o): continue        # 继承 R69 定义 302
        dI   = marginal_info(w, g, o)                       # 名义信息
        rho  = rim.reliability(g, o)                        # 信度
        V    = validity.get(g, v_default)                   # 效度（held-out 估计）
        eff  = rho * V * dI - cost(g) - lam_D*burden(g) - lam_F*fatigue.term(g)
        if eff > 0 and (best is None or cost(g) < best.cost):
            best = Probe(g, lvl, eff)
    return best                                     # None -> 不交互，退 R69/R68

# IP-265 RIM：响应者仪器模型（能力/偏差/信度/群体）
class RespondentModel:
    def __init__(self, population_prior):
        self.pi = population_prior                  # u ~ pi(u)
    def likelihood(self, y, m, g, u):
        d, b, lapse = self.sensitivity(u,g), self.bias(u,g), self.lapse(u)
        return ((1-lapse)*sigmoid(d*sign(m,y) + b)
                + lapse*self.q0(y))
    def reliability(self, g, o):                    # test-retest ICC（离线标定）
        return self.icc.get((g.kind, o.context), self.icc_default)

# IP-266 VBD：效度/信度折算的贝叶斯实验设计
def effective_voi(modes, w, g, o, rim, validity):
    raw = entropy(w) - expected_entropy(w, g, o)
    return rim.reliability(g,o) * validity(g) * raw \
           - cost(g) - lam_D*burden(g) - lam_F*fatigue.term(g)

# IP-267 CATE：从日志估「问 vs 不问」的反事实效应
def estimate_ask_effect(logs):
    x, g, y = logs.X, logs.asked, logs.success
    e = propensity_model(x).predict_proba(x)        # P(ask | x)
    mu1 = outcome_model(x, 1).predict(x)
    mu0 = outcome_model(x, 0).predict(x)
    dr  = (mu1 - mu0
           + g*(y - mu1)/e
           - (1-g)*(y - mu0)/(1-e))
    return bootstrap_ci(dr, alpha=0.05)             # 只信置信下界

# IP-268 UTP：预注册用户测试（kill / keep）
def run_user_test(protocol, system, users_test):
    assert hash(protocol) == protocol.registered_hash   # 预注册完整性
    arms = {'no_ask': abl_system(ask=False),
            'ladder': system,
            'oracle': oracle_probe(system)}
    res = {k: evaluate(s, users_test, metrics=protocol.metrics)
           for k, s in arms.items()}
    delta_ci = paired_bootstrap_ci(res['ladder'], res['no_ask'])
    keep = (delta_ci.low > protocol.delta_min
            and res['ladder'].burden_p90 <= protocol.b_max
            and res['ladder'].veto_rate <= protocol.v_max)
    return J_MVP(protocol=protocol, delta_ci=delta_ci, keep=keep, ...)

# IP-269 TGE：三态门控 + 影子模式
def deployment_gate(cert, drift):
    if not cert.valid: return 'off'
    if cert.evid_level < E4: return 'shadow'        # 只记录，不驱动真实动作
    if drift.reliability_drop or drift.fatigue_over or drift.population_shift:
        return 'shadow'                             # 降级永远比升级快
    return 'online'

# IP-274 PILOT-RAS 主闭环（R69 + 阶梯 + 仪器 + 门控）
def PILOT_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    if M.gate.state == 'off':                       # 默认：R68 纯保守
        return conservative_round(M, z, o, U_ale, U_epi)
    g = M.mpl.choose_min_viable_probe(modes, o, M.budget, M.rim)   # 先便宜后问人
    # 影子模式：探询只算不执行，日志用于反事实估计
    if M.gate.state == 'shadow':
        M.logger.log_counterfactual(o, modes, g)
        return conservative_round(M, z, o, U_ale, U_epi)
    answer      = M.cia.execute(g) if g else None
    U_epi_after = M.cia.update_belief(modes, answer) if answer else U_epi
    U_floor = U_ale + (U_epi_after if answer is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    mode = select_mode(modes, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.fatigue.step(asked=bool(g and g.kind == 'ask'))       # 疲劳反馈
    M.vqa_u.submit_async(M.gate, g, answer, U_epi, U_epi_after, M.fatigue.F)
    return k, lam, mode, (U_ale, U_epi_after)
```

## 3. 推导

**引理 19（折算 VoI 的可识别上界）** 设名义信息增益为 ΔI，响应者信度 ρ、效度 V。任何基于该回答的贝叶斯更新，其可获得的关于 M 的期望信息至多 ρV·ΔI；当 ρV→0 时，更新后的期望任务损失可高于不更新的损失。系：R69 的 VoI 是 ρ=V=1 的**理想化上界**；真实交互的收益被效度/信度乘性折扣，且可能为负——「问了反而更糟」不是哲学警告，是 ρV < c/ΔI 时的直接推论。

**引理 20（探询阶梯的贪心最优性）** 在 A99 下：各层探询嵌套（σ(g_ℓ)⊂σ(g_{ℓ+1})）、信息增益次模、成本严格递增且凸。则最优策略必为某个**前缀** ℓ\*，且「从最便宜层起，选择第一个边际 VoI_eff ≤ 0 的前一层」的贪心策略达到前缀最优。系：MVP 的「先免费、后低扰动、最后问人」不是产品直觉，而是次模信息 + 凸成本下的最优停止；只有当便宜层信息饱和（ΔI 下降）时才值得升到问人。

**引理 21（疲劳下的可持续询问率）** 在定义 319 的疲劳动力学下，长期有效信息率 J(r)=r·ΔI·ρ_0 e^{−μF(r)} − r·c_0(1+νF(r)) 关于询问率 r 先增后减，存在内点 r\* = argmax J(r) < r_max；超过 r\* 后每多问一次，边际有效 VoI 为负。系：R69 的「单位时间 ≤1 次」是硬上限，但**可持续**询问率通常远低于它；把上限当目标会在长时程上自我破坏。

**引理 22（选择–评估循环偏差）** 若探询 g 是**因为**在测试集 T 上表现好而被选中，又在同一 T（或同批用户）上评估 τ̂，则 E[τ̂] 相对真实效应乐观偏置 ≥ 选择偏差项，且随候选数增加而增大（winner's curse）。系：定义 316/321 的预注册、held-out 划分与选择/评估分离，是把「用户测试」从自我确认中救出来的唯一办法；否则 MVP 越成功，偏差越大。

**定理 18（PILOT 严格包含 R69 与 R68）** 在 A99–A101 下：(a) 取 oracle 响应者（ρ=V=1、c=0、F=0、π 退化）、阶梯只留 ℓ4，则 MPL 退化为 R69 的 MINT，VoI_eff 退化为 R69 的 VoI，PILOT 逐指令等价于 FLUID-RAS；(b) 取 evidence_level < E4、kill criterion 触发或 gate=off，则交互层关闭，PILOT 逐指令退化为 R68 纯保守。故 R69 是 PILOT 在「响应者完美」边界上的退化，R68 是「交互不可信」边界上的退化；安全侧永不弱于两者，效率侧只在**被外部证据授权时**才启用。

**定理 19（测试门控的伤害概率界）** 若 kill criterion 基于 held-out 用户上 τ 的 (1−α) 置信下界，且用户划分与预注册独立，则启用有害交互层（真实 τ ≤ 0）的概率 ≤ α + O(√(log(1/δ)/n)) + B_shift，其中 B_shift 为人群漂移造成的效度偏差。系：这不是「保证不问错」，而是把「问错」的概率从 R69 的**未知**压到**可预算**；代价是 n、held-out 与预注册的工程成本。

**定理 20（最小可行切片的可识别性与最小性）** M0（定义 320）是识别 τ(x) 的最小闭环：去掉反事实/随机化 ⇒ 混杂不可识别；去掉信念更新 ⇒ 无法把回答归因到模态；去掉任务动作 ⇒ 无结果；去掉上下文日志 ⇒ 无法条件化 τ。任取更小的子图，τ(x) 不可识别。故 MVP 的「小」是有理论下界的，不是任意裁减。

**定理 21（证据分级的安全性）** 在定义 317 的「最高证据减一」使用规则下，任何 E<4 的探询只能处于 shadow，不改变控制输出；故 PILOT 在证据不足时的行为与 R68 完全一致，用户测试的失败只造成效率损失，不造成安全回退。这把「研究进展」与「部署风险」解耦。

## 6. 本轮最大风险

**一句话**：PILOT-RAS 的安全性不取决于算法，而取决于**测试的独立性**——如果设计 MVP、执行用户测试、判定 kill/keep 的是同一批希望它通过的人，那么预注册只是形式、held-out 会被泄漏、kill criterion 会被悄悄放宽，用户测试就退化为「给 R69 的模态信念盖一枚用户认可的章」，系统会带着**用户背书的自信**去问错，比 R69 的「诚实的不知道」更危险。

**次级风险与缓解**：
1. **小样本 + 自我选择用户** → 预注册样本量、intention-to-treat、按人群分层报告、CI 而非点估计（定理 19）；
2. **选择–评估循环 / winner's curse** → 选择与评估用户/时间分离、held-out、FDR（引理 22）；
3. **RIM 过拟合 pilot 人群** → V_ext 用最小而非平均、跨群重估、漂移即降级（定义 313、318）；
4. **打扰疲劳被低估** → FAT 显式进成本与信度、可持续率 r\* < r_max、veto 零成本（定义 319、322）；
5. **用户测试变成伦理表演** → veto/同意是系统状态、审计哈希、VQAuditor-U 独立于部署决策链（定义 322–323）。

# IP-264 MPL：探询阶梯（最便宜可行优先，问人最后）
def choose_min_viable_probe(modes, w, o, budget, rim):
    best = None
    for lvl, g in enumerate(ladder(o)):           # observe/wait/gaze/probe/ask
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o): continue
        eff = effective_voi(modes, w, g, o, rim, validity)
        if eff > 0 and (best is None or cost(g) < best.cost):
            best = Probe(g, lvl, eff)
    return best                                    # None -> 不交互，退 R69/R68

# IP-265 RIM：响应者仪器模型
class RespondentModel:
    def likelihood(self, y, m, g, u):
        d, b, lapse = self.sensitivity(u,g), self.bias(u,g), self.lapse(u)
        return (1-lapse)*sigmoid(d*sign(m,y) + b) + lapse*self.q0(y)
    def reliability(self, g, o):
        return self.icc.get((g.kind, o.context), self.icc_default)

# IP-266 VBD：效度/信度折算的 VoI
def effective_voi(modes, w, g, o, rim, validity):
    raw = entropy(w) - expected_entropy(w, g, o)
    return rim.reliability(g,o)*validity(g)*raw \
           - cost(g) - lam_D*burden(g) - lam_F*fatigue.term(g)

# IP-267 CATE：问 vs 不问 的因果效应
def estimate_ask_effect(logs):
    x, g, y = logs.X, logs.asked, logs.success
    e  = propensity_model(x).predict_proba(x)
    mu1, mu0 = outcome_model(x,1).predict(x), outcome_model(x,0).predict(x)
    dr = mu1 - mu0 + g*(y-mu1)/e - (1-g)*(y-mu0)/(1-e)
    return bootstrap_ci(dr, alpha=0.05)            # 只信置信下界

# IP-268 UTP：预注册用户测试里的 kill / keep
def run_user_test(protocol, system, users_test):
    assert hash(protocol) == protocol.registered_hash
    arms = {'no_ask': abl_system(ask=False),
            'ladder': system, 'oracle': oracle_probe(system)}
    res  = {k: evaluate(s, users_test, protocol.metrics) for k,s in arms.items()}
    dci  = paired_bootstrap_ci(res['ladder'], res['no_ask'])
    keep = (dci.low > protocol.delta_min
            and res['ladder'].burden_p90 <= protocol.b_max
            and res['ladder'].veto_rate <= protocol.v_max)
    return J_MVP(protocol=protocol, delta_ci=dci, keep=keep, evid_level=E4)

# IP-269 TGE：三态门控（降级永远比升级快）
def deployment_gate(cert, drift):
    if not cert.valid:                     return 'off'
    if cert.evid_level < E4:               return 'shadow'   # 只记录不驱动
    if drift.reliability_drop or drift.fatigue_over \
       or drift.population_shift:          return 'shadow'
    return 'online'

# IP-274 主闭环（默认 R68；shadow 只记录；online 才用回答）
def PILOT_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o,K), z, M.fmp.mode_head)
    if M.gate.state == 'off':
        return conservative_round(M, z, o, U_ale, U_epi)       # = R68
    g = M.mpl.choose_min_viable_probe(modes, o, M.budget, M.rim)
    if M.gate.state == 'shadow':
        M.logger.log_counterfactual(o, modes, g)               # 只记录
        return conservative_round(M, z, o, U_ale, U_epi)
    answer      = M.cia.execute(g) if g else None
    U_epi_after = M.cia.update_belief(modes, answer) if answer else U_epi
    U_floor = U_ale + (U_epi_after if answer is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    mode = select_mode(modes, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.fatigue.step(asked=bool(g and g.kind == 'ask'))
    M.vqa_u.submit_async(M.gate, g, answer, U_epi, U_epi_after, M.fatigue.F)
    return k, lam, mode, (U_ale, U_epi_after)
```

## 4. 推导

**引理 19（折算 VoI 上界）** 名义增益 ΔI 经信度 ρ、效度 V 后真实可获信息 ≤ ρVΔI；ρV→0 时更新后损失可高于不更新。R69 的 VoI 是 ρ=V=1 的理想化上界，真实交互可为负。

**引理 20（阶梯贪心最优）** A99：嵌套、次模信息、凸递增成本下，最优为前缀 ℓ\*；「从最便宜层起、取第一个边际 VoI_eff≤0 的前一层」达到前缀最优。故「先免费后问人」不是产品直觉，而是最优停止。

**引理 21（可持续询问率）** 疲劳动力学下长期信息率 J(r) 先增后减，存在内点 r\*<r_max；超过 r\* 每多问一次边际 VoI 为负。R69 的「≤1 次/单位时间」只是硬上限，不是目标。

**引理 22（选择–评估偏差）** 若探询因在测试集 T 上表现好而被选中又在 T 上评估，E[τ̂] 乐观偏置 ≥ 选择偏差，且随候选数增大（winner's curse）。预注册 + held-out + 选择/评估分离是唯一解。

**定理 18（严格包含）** (a) oracle 响应者（ρ=V=1,c=0,F=0,π 退化）+ 只留 ask ⇒ 退化为 R69 FLUID-RAS；(b) evid<E4 / kill / gate=off ⇒ 退化为 R68。安全侧永不弱于两者，效率侧仅在外部证据授权时启用。

**定理 19（门控伤害界）** kill criterion 基于 held-out 上 τ 的 (1−α) 置信下界时，启用有害交互层概率 ≤ α + O(√(log(1/δ)/n)) + B_shift。把「问错」从未知压到可预算。

**定理 20（MVP 可识别性与最小性）** M0 是识别 τ(x) 的最小闭环：去反事实/随机化⇒混杂不可识别；去信念更新⇒无法归因；去动作⇒无结果；去上下文⇒无法条件化。更小的子图不可识别。

**定理 21（证据分级安全）** 在「最高证据减一」规则下，E<4 只能 shadow，不改变控制输出；故证据不足时行为与 R68 完全一致，用户测试失败只损失效率、不回退安全。

## 7. 本轮最大风险

**一句话**：PILOT-RAS 的安全性不取决于算法，而取决于**测试的独立性**——如果设计 MVP、执行用户测试、判定 kill/keep 的是同一批希望它通过的人，那么预注册只是形式、held-out 会被泄漏、kill criterion 会被悄悄放宽，用户测试就退化为「给 R69 的模态信念盖一枚用户认可的章」；系统会带着**用户背书的自信**去问错，比 R69 的「诚实的不知道」更危险。

**次级风险与缓解**：小样本/自我选择（预注册样本量 + ITT + 分层 CI）；选择–评估循环/winner's curse（选择与评估分离 + held-out + FDR）；RIM 过拟合 pilot 人群（V_ext 取最小 + 跨群重估 + 漂移即降级）；打扰疲劳被低估（FAT 进成本信度 + r\*<r_max + veto 零成本）；测试变伦理表演（veto/同意为系统状态 + 审计哈希 + VQAuditor-U 独立于部署决策链）。
