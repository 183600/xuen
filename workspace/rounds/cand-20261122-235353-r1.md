## 1. 两个灵感的第一性原理

### 灵感 1 ·「交互设计」→ 把策略-环境关系当作一次可设计的交互

**直觉**：交互设计不是「把界面画好看」，而是设计「意图 → 动作 → 反馈 → 修正」的闭环：用户能否看见系统状态、预见动作后果、在出错时低成本恢复、在动手前被约束挡住明显错误。

**严谨**：交互设计可提炼为四条可检验性质——**状态可读（legibility）**、**后果可预判（feedforward）**、**错误可预防（error prevention）**、**失败可修复（recovery）**；再加一条系统观——**交互债务（interaction debt）**：失败往往不是突变，而是小残差长期累积后的崩盘。

转译到 UniBot 策略：

- **可读** → 策略显式输出交互模式/相位/置信度，且这些量可从动作窗口被外部解码（U18）；监视器据此发现「非法转移」。
- **可预判** → 动作块提交前做 feedforward（接 IP-10 的潜空间前瞻），把「后果」纳入决策。
- **防错** → 每个转移带 **guard（前置条件）**：未对齐不许闭合、未夹稳不许抬升（IP-13）。
- **可修复** → 失败触发「修复对话」：重抓 / 重对齐 / 换原语 / **探针**（IP-15），而不是盲目重试。
- **交互债务** → 用残差累积量做早期预警，在终端失败前介入（U17）。

**边界与反例**：交互设计还会提示「演示者的操作风格（operator style）」是数据里的隐变量；但该资产天级可抄、且属数据面（P9），本轮只作数据增强注记，不立项。

### 灵感 2 ·「在线学习」→ 在非平稳世界里的安全序贯适应

**直觉**：在线学习不是「上线后再训一个大模型」，而是「每来一个反馈就小幅修正，并保证不越改越差」。

**严谨**：在线学习的第一性原理 = 在**不假设 i.i.d.**、**反馈稀疏/有延迟**、**分布漂移**的条件下，最小化**动态后悔（dynamic regret）**，同时用**安全投影**约束最坏情形；当「获取信息」本身要花时间时，它就是一个带成本的**动作**（value of information）。

转译到 UniBot：

- 评测是**非平稳序列**（分布偏移轴）⇒ 固定参数必然次优；应在线校准一小组标量（伺服增益 K、断言阈值 τ、chunk 长度 T、混合门控 β），而非更新权重（IP-14）。
- 反馈是**稀疏真值 + 稠密代理**（episode 末成功 + 断言残差/进度）⇒ 用代理损失做在线更新，但必须防「代理 ≠ 真相」。
- 评测**不给重来** ⇒ 探索只放离线/代理；在线只做**受约束的利用**（P12）。
- 不确定性高时，**先探针再重试**：用信息增益换成功概率（IP-15，VoI 判据）。

### 灵感 3 ·「两灵感合流」→ 交互契约 + 在线校准

一句话：**交互设计给结构（契约/债务/可读性），在线学习给动态（安全投影/动态后悔/探针）。**

第 2 轮是「分层执行栈」；本轮升级为「**可读、可修复、可在线校准的交互契约**」：

- 契约不是新模型，而是策略内部的状态机 + 监视器 ⇒ 仍单 checkpoint、单 API；
- 在线校准只改低维参数、不跨 episode ⇒ 合规风险低于 IP-11（IP-11 因此可冻结）；
- 探针是显式的「时间换信息」预算决策 ⇒ 把盲目重试变成可计算的最优探测问题。

**策略含义**：本轮把护城河从「控制栈」进一步推进到「**交互语义层**」——对手可以抄一个伺服器，但很难在一周内抄出「契约 + 债务 + 可读性 + 安全在线校准」这一整套工程密度。

## 2. 研究问题（新增 Q10–Q14，接第 2 轮 Q1–Q9）

- **Q10（交互契约可表达性）**：32 项任务能否被有限模式集 + 转移表 + guard/postcondition 表达？契约覆盖率与「非法转移」检出率能到多高？（E628）
- **Q11（交互可读性）**：交互模式/相位/置信度能否从动作窗口稳定解码？债务统计量能否在终端失败前给出足够提前量的预警？（E629）
- **Q12（安全在线校准域）**：在分布偏移下，θ=(K,τ,T,β) 的安全集、更新率与回滚闸门如何设计，才能把动态后悔压到预算内且不产生参数振荡？（E630/E631）
- **Q13（探针的价值）**：何时「先探测再重试」严格优于「直接重试」？VoI 阈值与硬时间预算如何定？（E632）
- **Q14（在线专家组合 vs 学习路由）**：在线 bandit 组合是否比 IP-01 的学习式 MoE 路由更抗漂移？探索代价是否可接受？（E633，P2 对冲）

## 3. 设计原则（新增 P10–P13，接第 2 轮 P1–P9）

- **P10（契约优先）**：先把任务表达成「模式 + 转移 + guard/postcondition + 修复边」，控制器与适配器只挂在契约的转移上，不直接挂在时间步上。
- **P11（可读性即安全）**：任何在线适应都必须可观测、可归因；不可读的隐式更新一律不上线。
- **P12（安全在线适应三件套）**：任何在线更新必须同时具备 **安全集投影 + 回滚闸门 + 预注册的后悔预算**；评测内不做随机探索。
- **P13（探针优先于盲重试）**：断言失败/不确定性高时，先按 VoI 选择最小安全探针；探针收益不为正就退回保守重试。

## 5. 本轮最大风险

第 2 轮风险「合成负样本假安全」仍在；本轮叠加一条更主动的风险：

**在线校准把代理反馈当真相**：分布偏移下，断言残差/进度是**代理**而非真值；若更新率过高或安全集过宽，策略会追着噪声漂移，甚至比固定参数更差。对冲：P12 三件套（安全投影 + 回滚 + 后悔预算）、代理损失加平滑项、漂移检测（CUSUM/Page-Hinkley）只在置信时放开步长、E630/E631 预注册验收。

## 3. 新增 IP 详述

### IP-13 · InteractionContract 交互契约 + 债务监视（P0，新）

- **动机**：v2 的路标是「序列」，但交互设计指出序列不够——还缺**语法**：哪些转移合法、转移前必须满足什么、失败如何归因、残差如何累积。真实失败常是「未对齐就闭合」「夹稳前抬升」「推动物滑出工作空间」这类**非法转移**，而非单纯漏掉一个路标。
- **与现有方案差异**：IP-09 是「在路标处做伺服」的执行器；IP-13 是「规定路标之间怎么走、何时不许走、走坏了怎么修」的语法与监视器。IP-13 不替代 IP-09，而是包住它：`execute_waypoint` 仍由 IP-09 提供，契约负责模式解码、guard、postcondition 与债务。
- **技术可行性**：高。模式集与转移表可由 32 任务定义 + IP-06 阶段标注手工/半自动生成；guard 用几何/视觉谓词（EE-目标误差、夹爪开合、腕部可见性）；债务是标量累积器；可读性解码器是动作窗口上的小分类器。
- **资源**：数据=阶段标注；算力=小；接口=无新增字段。
- **落地步骤**：①定义模式词汇表 S 与各任务族转移表 T；②从数据标注 guard/postcondition；③实现运行时监视器与债务累积 `D_t`；④训练可读性解码器并验证模式可恢复；⑤把 guard/postcondition 失败接到 IP-02/IP-09 的介入与 IP-15 的修复；⑥E628/E629。

### IP-14 · OnlineCalibration episode 内安全在线校准（P1，新）

- **动机**：评测是分布偏移的非平稳序列；v2 的 K（伺服增益）、τ（断言阈值）、T（chunk 长度）、β（混合门控）全是离线定死，漂移下必然次优。在线学习给出「小幅、可回滚、后悔有界」的修正框架。
- **与现有方案差异**：IP-04 是 episode 前段的**一次性**上下文调制（学习到的 FiLM）；IP-11 是**跨 episode** 非参数记忆（合规未决）。IP-14 是 **episode 内、连续、参数级**校准，不更新权重、不跨 episode、不落盘状态 ⇒ 合规风险最低。
- **形式**：`θ_t=(log K_scale, τ, T, β_max)`；代理损失 `ℓ_t = 断言残差 + 进度惩罚 + 平滑惩罚`；更新 `θ_{t+1}=Proj_{Θ_safe}(θ_t−η_t g_t)`；漂移检测（CUSUM/Page-Hinkley）触发步长调度 `η_t=η_0/√(1+V_t)`；代理后悔超预算即回滚到基线参数。

### IP-15 · ProbeRepair VoI 探针修复（P1，新）

- **落地步骤**：①探针库（lift-test / micro-rotate / retreat-reapproach / gentle-shake）；②不确定性估计；③VoI 规则 `(p′−p)V > c`（U20/L14）；④安全包络（力/速度上限、最大探针时长）；⑤E632；⑥接入 IP-13 的修复边。

### IP-16 · OnlineRouter 在线专家组合（P2，新·对冲）

## 4. 符号与定义（新增 U16–U20；U1–U15 沿用前两轮）

- **定义 U16（交互契约）**：任务 τ 的契约 `C(τ)=(S, s_0, T, G, Q, A)`：`S` 交互模式集；`s_0` 初始模式；`T⊆S×S` 合法转移；`G={γ_e}` 转移 guard（前置条件，`γ_e: O→{0,1}`）；`Q={q_e}` 后置断言（postcondition）；`A` 可供性映射（物体→接触点/接近锥/力包络）。一次执行**合法**当且仅当每次转移满足 guard；**完成**当且仅当沿合法路径到达终态并满足后置断言。
- **定义 U17（交互债务）**：`D_t = Σ_{k≤t} λ^{t−k} ρ_k`，`ρ_k` 为第 k 步归一化后置残差（位姿残差、滑移指标、对齐裕度缺口）；当 `D_t>θ_debt` 或 `dD/dt>θ_slope` 时触发预警。
- **定义 U18（可读性）**：策略是 `(w,ε)`-可读的，若存在解码器 `g: (a_{t−w:t}, o_{t−w:t}) → S`，使模式解码准确率 `≥1−ε`。
- **定义 U19（安全在线校准）**：`θ_t∈Θ_safe`，`θ_{t+1}=Proj_{Θ_safe}(θ_t−η_t g_t)`；动态后悔 `Reg_T=Σ_t[ℓ_t(θ_t)−ℓ_t(θ_t^*)]`，比较序列变差 `V_T=Σ_t‖θ_t^*−θ_{t−1}^*‖`。
- **定义 U20（探针价值）**：探针 `a` 的期望信息增益 `IG(a)=I(ζ; o_{t+1}|a,o_t)`，`ζ` 为潜在失败模式；探针门控为 `E[IG]·V_success > c_probe + c_delay`。

```python
# ===== IP-13: 交互契约运行时（包住 IP-09 执行器）=====
CONTRACT = load_contracts()   # task_token -> (S, T, guards, posts, affordances)

def step_contract(self, s, obs):
    C = CONTRACT[s.task_token]
    m = self.decode_mode(s.action_window)          # U18 可读性
    if m != s.mode:                                 # 模式切换需合法
        e = (s.mode, m)
        if e not in C.T or not C.guards[e](obs):    # guard 防错
            return self.recover(s, obs, reason="illegal_transition")
        s.mode = m
    debt = self.update_debt(s, C, obs)              # U17 交互债务
    if debt > self.theta_debt:                      # 早期预警
        return self.recover(s, obs, reason="debt")
    a = self.execute_waypoint(s, obs)               # IP-09 伺服执行
    if not C.posts[(s.mode, s.wp_idx)](obs):        # postcondition 断言
        s.assert_fail += 1
        if s.assert_fail >= self.patience:
            return self.recover(s, obs, reason="postcondition")
    return a
```

```python
# ===== IP-14: 安全在线校准（episode 内，无权重更新）=====
class SafeOnlineCalibrator:
    def __init__(self, theta0, safe_set, eta0, budget):
        self.theta = theta0; self.safe = safe_set
        self.eta = eta0; self.V = 0.0; self.budget = budget
        self.baseline_theta = theta0

    def update(self, loss_grad, shift_signal):
        if shift_signal:                        # CUSUM / Page-Hinkley
            self.V += shift_signal
            self.eta = self.eta0 / math.sqrt(1 + self.V)   # L12 步长调度
        g = clip(loss_grad, self.grad_clip)     # 平滑 / 限幅
        theta_new = self.theta - self.eta * g
        self.theta = project(theta_new, self.safe)         # L13 安全投影
        if self.regret_proxy() > self.budget:              # 回滚闸门
            self.theta = self.baseline_theta
        return self.theta
```

## 6. 推导（新增引理 L11–L14；L1–L10 沿用前两轮）

**引理 L11（契约归因）** 设失败原因 `ζ` 取值于有限集，契约把失败空间划分为若干「违反条件」单元。若契约在真实原因上满足 p-纯，即 `P(ζ=z | e=e_z) ≥ p`，则基于违反条件的 MAP 归因准确率 `≥ p`，且诊断搜索空间从整条轨迹降为 `|E|` 个转移。证明：由贝叶斯公式，`P(ζ=z|e) ∝ P(e|ζ=z)P(ζ=z)`，p-纯保证真实原因后验不低于任意单点 `p`，MAP 选真；搜索空间由契约划分直接给出。∎ 推论：契约越细越可归因，但过细会降低纯度（偏差-方差权衡），故 guard 宜软、模式集宜小。

**引理 L12（非平稳在线学习的动态后悔）** 对凸损失与比较序列 `θ_t^*`，令变差 `V_T=Σ_t‖θ_t^*−θ_{t−1}^*‖`。在线梯度下降取 `η_t∝1/√(1+V_t)` 时，动态后悔 `Reg_T=O(√(T(1+V_T)))`；该阶在一般凸设定下不可改进（下界 `Ω(√(T(1+V_T)))`，Zinkevich 2003 / Besbes 等 2015 的非平稳结论）。⇒ 漂移越大，固定步长越次优；必须用漂移信号调度步长（IP-14）。∎

**引理 L13（安全投影的最坏情形）** 若 `θ_t=Proj_{Θ_safe}(θ_{t−1}−η_t g_t)`，`Θ_safe` 直径 `D`，损失 `L`-Lipschitz，则对任意参考 `θ^ref∈Θ_safe`，单步瞬时后悔 `ℓ_t(θ_t)−ℓ_t(θ^ref) ≤ L·D`。叠加回滚闸门（代理后悔超预算即回基线）后，最坏情形退化为基线、期望不劣化。证明：Lipschitz 直接给上界；回滚闸门保证不长期停留在劣于基线的参数上。⇒ 安全集直径是可调的「性能-风险」旋钮。∎

**引理 L14（探针的 VoI 阈值）** 设不探测成功率 `p`，探测后最优分支成功率 `p′`，成功价值 `V`，探针成本 `c`（时间+风险）。探测的期望净收益 `=(p′−p)V−c`，故当且仅当 `(p′−p)V>c` 时探测严格占优。若用信息增益表述，`p′−p ≤ √(IG/2)`（Pinsker 型界），故充分条件为 `√(IG/2)·V>c`。⇒ 给出可计算、可预注册的探针门控。∎
