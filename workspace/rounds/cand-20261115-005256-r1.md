# 第 70 轮（承接第 69 轮「FLUID-RAS 不确定性二分交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「时空推理」×「个性化交互」）

> R69 给了闭环一张「嘴」：把不确定性拆成 aleatoric / epistemic，用流匹配多模态策略显式呈现歧义，用注视/探针/问句去主动消解。但 R69 的交互是**一阶、无记忆、无身份**的：它把世界模型当作一个扁平似然，把回答者当作**可交换、同样可靠**的证据源。于是它留下两个洞：
>
> - **洞一（时空的缺失）**：R69 自陈的最大风险是**幻影模态**——流模型幻觉出不存在的峰，系统就去追问一个物理上根本不成立的东西。而幻影模态往往有一个廉价而独立的破绽：它在**时空上说不通**（瞬移、加速度突变、因果倒置、地点动力学不允许）。R69 没有显式使用这条信息，等于浪费了最便宜的审计通道。
> - **洞二（个性的缺失）**：R69 的「k 个正交源一致」默认所有人同样可靠。但可靠性是**人 × 领域 × 地点 × 时刻**的函数：同一个人在本行可信、跨行会瞎猜；疲劳/利益/情绪会漂移；还有「先养信任、再背叛」的 sleeper agent。用人口平均可靠性算 VoI，会**过度纠缠不可靠者、欠利用可靠者**，并让 k-一致纪律既慢又易被高信任单源击穿。
>
> 本轮两个灵感正好补上这两个洞，而且它们不是并列补丁，是**同一件事的两面**：一次交互永远发生在某地、某时、由某个特定的人给出。
> - **时空推理**把「假设是否物理上说得通」变成一个可计算的**软先验** S_ST，用来剪掉幻影模态；
> - **个性化交互**把「回答者是谁、在何时何地、我该信几分」变成**时空可信度场** q(h_p)，用来改写问谁、信几分、何时问。
>
> 核心命题：**用时空一致性做假设剪枝（治 R69 的幻影模态），用个性化时空可信度场做证据加权与提问对象选择（治 R69 的均匀信任），并把「问谁、何时问、在哪问、信多少」统一为带时空约束的 VoI 优化；当个性化退化为均匀、时空先验退化为空时，严格退回 FLUID-RAS。** 命名 **STeP-RAS**（Spatio-Temporal evidence & Personalized interaction, Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**这句话在何时、何地、由谁说出，才值得信**」——不确定性不仅有形状（R69），还有**坐标与署名**。

## 0. 直觉与动机

**灵感 1（时空推理 → 假设必须先「物理上说得通」）**
直觉：R69 的幻影模态不是因为没有证据，而是因为假设**违背了我们已知的时空结构**。目标不会瞬移，因果不会倒置，同一地点不会支持该地点不存在的动力学。把这些结构写成 S_ST = S_space·S_time·S_place，作为落在每条候选轨迹上的**可计算降权分数**，就能在花任何交互预算之前先把「物理上不可能」的峰压下去。关键纪律：**只软剪枝、不硬删**——因为过度刚性的时空先验会把真正的物理异常（恰恰是最该报警的）当成「不可能」剪掉。这与 R69 的 FMA 构成二维证据：FMA 问「行为与观测自洽吗」，ST 问「假设与物理自洽吗」。

**灵感 2（个性化交互 → 回答者不是同质的）**
直觉：向一个刚下夜班的人和向一个领域专家问同一句话，信息量天差地别；向同一个专家问他陌生领域的问题，信息量也骤降。R69 用一个统一可靠度算 VoI，等于假设「人人处处时时一样可信」。个性化 = 给每个伙伴维护一个后验 q(h_p)（领域能力 θ、诚实度 υ、时效/疲劳 φ、欺骗倾向 δ），由此得到 R(p,d,x,τ) ∈ [0,R_max] 的**时空可信度场**，并用它改写三件事：问谁（伙伴选择）、信几分（证据权重）、何时问（时间折扣）。

**灵感 3（时空 × 个性 = 交互本身是时空-社会过程）**
直觉：这两件事在「一次交互」这个事件上合流——交互有地点（走过去要时间/距离）、有时刻（答案要赶在决策窗口内到达才有用）、有署名（谁说的、他当时可信吗）。所以：可靠性要**空间局部**（伙伴对近旁的事更可信）且**时间新鲜**（信息会过期）；「问谁」有行程与延迟成本；过去的交互应被**时空索引的记忆**记住，用于去重（治 R69 的交互疲劳）、自洽检查（前后矛盾→降信任）与先验复用。时空推理与个性化交互因此不是两块，而是**个性化时空可信度场 + 时空索引交互记忆**这一套机制的两面。

**灵感 4（严格包含 → R69 是「均匀信任 + 无时空约束」的边界）**
直觉：沿用上轮铁律——新层必须是旧层的**严格泛化**，否则每加一层就多一个需要独立信任的黑箱。当 β=0（ST 先验关闭）、所有人 R_i=R 且只有一个对话者、无记忆时，STeP 逐指令等于 FLUID-RAS。个性化只**重新分配**同一查询预算，不改变安全包络；安全由两个显式旋钮守住：信任天花板 R_max<1、有效多样性下限 k_eff≥2。

**灵感 5（新的双刃剑 → 个性化会自动化确认偏误）**
直觉：R69 的「问」已经带来投毒面；个性化把它推得更隐蔽：系统可能学会**挑选会同意的人**（而不是寻找真相）——高 R 与高一致性互相强化，形成确认偏误的自动化；信任画像是持续监控；sleeper agent 用长期养成的信任换一次致命误导；时空欺骗（伪造地点、回放旧时间戳）让「本地可信」失效。所以本轮必须同时交付：有效样本量证据纪律、信任变点检测与天花板、时空有效性窗口、以及一条**反谄媚约束**（不得因答案与先验一致而加权）。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（STeP-RAS 总览与四不变式）** STeP-RAS = (STM, PCF, PED, STV, ESM, TCD, TBA, STG, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **ST 先验只软剪枝**：仅允许通过校准门 STG 的乘性降权，硬约束只保留已认证的运动学/因果不变量（如不可瞬移、不可逆时、不可穿透）；
(iii) **个性化只改权重与选择、不改纪律**：任何单一伙伴（即便 R=R_max）不得单独越过决策门限，需 N_eff ≥ k_eff，或 ST-一致 + 至少一个独立非 p* 源（定义 317）；
(iv) **信任有界、可回滚、可遗忘**：R ≤ R_max < 1，变点触发重置，跨回合遗忘（定义 316、326）。

**定义 311（时空一致假设空间 STM 与软剪枝）** 对增广轨迹 ξ（含 (a,g)），定义
S_ST(ξ) = S_space(ξ) · S_time(ξ) · S_place(ξ)，
其中
- S_space = exp(−(1/σ_s²)∫‖ẍ(τ)‖²dτ − (1/σ_j²)Σ‖Δv_jump‖²) · 1[ξ ∩ Occupancy = ∅]（运动学平滑 + 不穿透，后者为已认证硬约束）；
- S_time = Π_{(c,e)} 1[t_cause ≤ t_effect] · exp(−(latency − μ_lat)²/(2σ_lat²))（因果先验 + 动作时长先验）；
- S_place = Π_t p_place(ẋ_t | x_t, region(x_t))（地点条件动力学似然）。
软剪枝：模态后验 ŵ_k^ST ∝ ŵ_k^FLUID · S_ST(ξ̄_k)^β，β ∈ [0, β_max]，由 STG（定义 319）门控。**S_ST 不是概率，只是排序/降权分数**；β=0 时退回 R69。

**定义 312（时空索引交互记忆 ESM）** 记录 r = (τ, x, p, d, y, R_at_time, valid_until)，其中 τ 时间、x 地点、p 伙伴、d 命题域、y 答案、valid_until = τ + τ_valid(x,p,d)。查询 Query(x,τ,d) 返回按时空核加权的历史证据：K((x,τ),(x_i,τ_i))·1[τ ≤ valid_until_i]。用途：(a) ESM 命中则不重复问（去重/降疲劳）；(b) 同一伙伴前后矛盾（相对其领域）→ 触发 TCD 降信任；(c) 提供 VoI 先验。

**定义 313（个性化可信度场 PCF）** 对每个伙伴 p，隐状态 h_p = (θ_p ∈ ℝ^{D_dom} 领域能力, υ_p ∈ [0,1] 诚实度, φ_p(t) 时效/疲劳, δ_p 欺骗倾向)，后验 q(h_p) 用 Beta/Dirichlet（每域）在线更新。答案可靠度
R(p,d,x,τ) = E_q[σ(θ_{p,d})·υ_p] · φ_p(τ) · κ(‖x − x_p‖) ∈ [0, R_max]，
其中 κ 为**空间局部性核**（远处的事降可信），φ_p 为**时间新鲜度**（疲劳/信息过时）。这是一个**时空可信度场**，不是标量。

**定义 314（个性化证据信道）** 伙伴 p 关于模态 M 的答案 y 服从信道 p(y | M=m, p, d, x, τ)，其准确率由 R(p,d,x,τ) 参数化（如 y=m 概率 R + (1−R)ε_unif，或以 R 为温度的 softmax 混淆）。个性化 VoI：
VoI(g,p) = I(M; y | g,p,o) = H(M|o) − E_{y~p(·|g,p,o)}[H(M|o,y)]，
即在**信道模型**下的互信息，而非「信息增益 × R」的粗糙近似。

**定义 315（时空有效性约束 STV-validity）** 一条证据 (p,d,x,τ,y) 只在有效域 V = {(x′,τ′) : ‖x′−x‖ ≤ ρ_d, |τ′−τ| ≤ τ_valid} 内可迁移；超出即权重按核衰减到 0。防止「某人在某地某时对某事的一句话」被错误迁移到别处别时（context aliasing）。

**定义 316（信任更新与变点检测 TCD + 天花板）** 在线 Bayes 更新 q(h_p)；并行 CUSUM/GLR 变点监测：对答案序列的对数似然比累积和，若超过阈值 λ_cp → 判定 p 的可靠性发生**结构变点**（疲劳/背叛/被替换），把 q(h_p) 重置到先验并**降级**（primary→secondary），其历史证据按遗忘因子回溯衰减。信任天花板：R(p,·,·,·) ≤ R_max < 1 恒成立（即便观测再多）。

**定义 317（个性化证据纪律 PED，有效样本量版）** 对一组指向同一模态的加权证据 w_i = R_i，定义有效样本量 N_eff = (Σw_i)²/Σw_i²。决策门限：
Accept(m) ⇔ N_eff ≥ k_eff ∧ (至少两个**不同**伙伴的加权票一致 ∨ ST-一致 + 一个独立非 p* 源)，
其中 k_eff ≥ 2 是硬下限；R_max 与 k_eff 联合封顶单源投毒损害。当所有 w_i 相等时 N_eff = 源数，退化为 R69 的「k 个正交源」——本定义是 R69 定义 293-iii 的**严格推广**。

**定义 318（时空 VoI 规划：何时、何地、问谁）** 候选信息动作扩展为 g = (g_type, p_target, x_approach, τ_sched)。目标：
max_{g,p} [ γ(τ_g)·VoI(g,p) − c_travel(x→x_p) − c_delay(τ_g) − c_social(p) ]
s.t. R69 定义 302 认证、定义 322 预算、τ_g + latency(p) ≤ t_deadline（答案须在因果后果窗内到达）。
时间折扣 γ(τ) = P(answer arrives before deadline) = exp(−latency(p)/τ_window)。若最优值 ≤ 0：不交互，退 R69 兜底。系：**信息也有保质期**——晚到的正确答案可能比早到的保守更差。

**定义 319（ST 先验校准门 STG）** ST 先验自身需被校准：在留有真值的回放集上统计「真模态被 S_ST 判为低分」的假剪枝率 ε_ST 与「幻影模态被保留」的漏剪率。ECE_ST > τ_ST ⇒ β 自动下调（β ← β·decay）直至退回 R69（β=0）。**过度刚性的时空先验会把真异常剪掉**——这是 ST 层自身的 epistemic 风险，必须与 R69 的 MCG 对称地被门控。

**定义 320（个性化证书 J_STeP）** J_STeP = (J_FLUID, ST_prune_ratio, ST_calibration_ece, β, trust_posterior_entropy, N_eff_min, partner_diversity, trust_reset_count, esm_hit_rate, temporal_validity_violations, step_ver)。Valid ⇔ Valid(J_FLUID) ∧ ECE_ST ≤ τ_ST ∧ 定义 317 纪律满足 ∧ 定义 322 预算未越界 ∧ 无时空有效性违例。

**定义 321（威胁模型扩展 ℰ_STeP）** ℰ_STeP = ℰ_FLUID × ℰ_trust × ℰ_st，新增：
- ℰ_trust：信任投毒（sleeper agent：长期可信后单次背叛）、社会工程（利用已知信任关系施压）、共谋轮换（多账号轮流误导以规避单账号变点检测）；
- ℰ_st：地点伪造（GPS/地图欺骗使空间核误判本地可信）、时间戳回放（把旧答案当作新答案）、位置条件先验投毒（污染某区域的动力学统计）；
- ℰ_sycophancy：系统自身偏好与先验一致的答案（确认偏误的自动化）。

**定义 322（交互的时空预算）** 在 R69 预算（≤1 次/单位时间、位移 ≤ ε_g、成本 ≤ c_max）上增加：每地点交互率 ≤ ρ_place、每伙伴交互率 ≤ ρ_partner（防纠缠）、单位时间总行程 ≤ D_travel、每日交互总量 ≤ N_day。任一超限 ⇒ 该 g 作废。

**定义 323（因果后果窗与信息视界）** 当前决策的后果窗 [t, t+Δ_dec]；一个信息动作只有在 τ_answer ≤ t+Δ_dec 内可观测才有正 VoI；定义信息视界 T_info = t + Δ_dec − latency(p)。超过视界的交互其 VoI ≡ 0。这使「等一等再看」也成为一种**可被显式定价**的信息动作。

**定义 324（伙伴提名与惰性排序）** 为避免实时枚举所有伙伴，按上界 U(p) = γ·VoI_upper(p) − c_travel − c_social 排序，惰性求值（lazy greedy），只对可能进入前 k 的伙伴精算 VoI；在子模性下保证 (1−1/e) 近似。

**定义 325（时空-行为对偶审计 TBA）** 两个独立通道给同一假设打分：ST 通道 S_ST（物理自洽）与行为通道 FMA（R69，观测自洽）。四象限判据：双高 ⇒ 可信；ST 高、FMA 低 ⇒ 观测与世界模型可能共同错误（R68 缓变故障线索）；ST 低、FMA 高 ⇒ 很可能是**幻影模态**（R69 最大风险），应降权而非追问；双低 ⇒ 直接保守。这把 R69 的单一「行为自洽」升级为「物理 × 行为」二维证据，是 R69 引理 17 的时空镜像。

**定义 326（信任的继承与遗忘）** 跨回合信任以遗忘因子 α 继承：R_prior(p, next) = α·R_posterior(p, now) + (1−α)·R_0；长期无交互或超期则退回先验。防止陈旧信任被长期利用（sleeper 的时域版），也抑制无限记忆带来的隐私与过拟合。

# IP-264 STM：时空一致软剪枝（治 R69 的幻影模态）
def st_consistency(xi, occupancy, place_model):
    s_space = exp(-accel_penalty(xi)/SIG_S - jump_penalty(xi)/SIG_J)
    s_space *= 1.0 if clear_of(xi, occupancy) else 0.0      # 硬：不可穿透
    s_time  = causal_mask(xi) * duration_likelihood(xi)      # 硬：不可逆时
    s_place = place_model.loglik(xi.trajectory)              # 地点条件动力学
    return s_space * s_time * exp(s_place)

def soft_prune(modes, w, beta):
    s  = [st_consistency(m.prototype, ...) ** beta for m in modes]
    w2 = normalize([w[k] * s[k] for k in range(len(modes))])
    keep = [k for k in range(len(modes)) if w2[k] > W_MIN]    # 只降权，不硬删
    return [modes[k] for k in keep], normalize([w2[k] for k in keep])

# IP-265 PCF：个性化时空可信度场
class PartnerTrust:
    def __init__(self, n_domains, R0=0.6, R_max=0.95):
        self.theta  = [Beta(2, 2) for _ in range(n_domains)]  # 领域能力
        self.honest = Beta(8, 2); self.fresh = 1.0
        self.cusum  = 0.0; self.R_max = R_max

    def reliability(self, d, x, partner_pos, tau):
        comp  = self.theta[d].mean()
        kappa = exp(-norm(x - partner_pos)**2 / (2*RHO**2))   # 空间局部
        fresh = exp(-tau / TAU_FRESH)                          # 时间新鲜
        return min(self.R_max, comp * self.honest.mean() * kappa * fresh)

    def update(self, d, y, mode_true, tau):
        llr = log_likelihood_ratio(y, mode_true, self.reliability(d, ..., tau))
        self.cusum = max(0.0, self.cusum + llr)
        if self.cusum > LAMBDA_CP:              # 结构变点：疲劳/背叛/被替换
            self.reset_to_prior(); self.demote(); self.cusum = 0.0
        else:
            self.theta[d].update(y == mode_true); self.honest.update(...)

# IP-266 PED：有效样本量证据纪律（严格推广 R69 的 k-一致）
def evidence_discipline(weighted_votes, st_agree):
    for mode in candidate_modes:
        ws      = [w for (p, m, w) in weighted_votes if m == mode]
        n_eff   = sum(ws)**2 / sum(w*w for w in ws)
        distinct = len({p for (p, m, w) in weighted_votes if m == mode})
        if n_eff >= K_EFF and (distinct >= 2 or st_agree(mode)):
            return mode
    return None          # 单源（即便 R=R_max）不得单独定案

# IP-267 STV-Planner：何时/何地/问谁（时空 VoI + 时间折扣）
def plan_interaction(modes, o, partners, budget, deadline):
    cands = []
    for p in partners:
        lat = latency(p, o)
        if o.t + lat > deadline: continue                    # 因果后果窗
        gamma = exp(-lat / TAU_WINDOW)                       # 时间折扣
        for g in info_actions_for(p, modes):
            if not budget.allow(g, p) or not c_ras_wm.certify_info(g, o):
                continue
            voi   = mutual_info(modes, channel(p, o), g)     # 个性化信道互信息
            score = gamma*voi - travel(p, o) - delay(p) - social(p)
            cands.append((score, g, p))
    best = lazy_argmax(cands)                                # 惰性子模近似
    return best if best and best[0] > 0 else None            # 无利可图 → R69

    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    # 1) 时空软剪枝：先杀幻影模态（STG 门控 β）
    beta = M.stg.beta(o)
    modes, w = M.stm.soft_prune(modes, ..., beta)
    U_epi = reestimate_epi(modes, w)
    # 2) 行为-时空对偶审计（TBA）
    tba = M.tba.judge(modes, M.fma.flow_anomaly(...), M.stm)
    # 3) 个性化时空 VoI：何时/何地/问谁
    g, p = (M.stv.plan(modes, o, M.pcf.partners(), M.budget, o.t + M.vista.H)
            if (U_epi > TAU_EPI and tba != 'phantom') else (None, None))
    if g is not None:
        y = M.cia.execute(g, p)                   # 认证 + 时空有效性窗
        M.esm.write(o.x, o.t, p, y)               # 时空索引记忆
        M.pcf.update(p, y, mode_true=None)         # 更新信任 + 变点检测
        U_epi = M.ped.merge(modes, y, M.pcf, o)    # 有效样本量纪律
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k   = M.c_ras_wm.certified_prefix(...)
    if tba == 'phantom' or M.stg.untrusted: lam = max(lam, 0.8)   # 退 R69/R68
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_i.submit_async(g, p, U_epi, tba)
    return k, lam, mode, (U_ale, U_epi)
```

## 3. 推导

**引理 19（时空软剪枝对幻影模态的削减）** 设幻影模态 ST-不一致概率 ≥ 1−η_ph，真模态 ST-一致概率 ≥ 1−ε_ST（ST 假剪枝率）。以 ŵ^ST ∝ ŵ·S^β 软剪枝，则期望 U_epi 的**虚高部分**从 H(ŵ) 降到 H(ŵ^ST) + 交叉项，幻影模态期望存活权重 ≤ η_ph^β（归一化后）。当 ε_ST→0、η_ph→0 时幻影全灭且 U_epi 只反映真歧义。**系**：ST 剪枝的净价值 = 真歧义可分性·(1−ε_ST) − 真模态被误剪的风险；因此 β 必须由 STG 校准，否则只是把 R69 的「幻觉歧义」换成「漏掉真异常」。

**引理 20（个性化证据的有效样本量界）** 用权重 R_i 对 K 个伙伴加权多数，错误率满足 Chernoff 型上界 P_err ≤ exp(−N_eff·D(R̄‖1/2))（D 为二元 KL），其中 N_eff = (ΣR_i)²/ΣR_i²。单源时 N_eff = 1，无论 R 多高（受 R_max<1 约束）错误率有正下界；当所有 R_i 相等时 N_eff = K，退化为 R69 引理 18 的 k-一致界。**系**：提高 N_eff 的两条正交途径是「加人（K↑）」与「让权重更平坦」——这解释了为何「过度信任一个高 R 伙伴」在数学上**等同于减少了有效样本量**。

**定理 18（STeP 严格包含 FLUID-RAS）** 当 β=0（STG 关闭）、所有伙伴 R_i=R 且只有单一对话者、ESM 为空、无伙伴选择时，定义 310–318 的每一步都规约到 R69 定义 293–309 的对应步：软剪枝为恒等、PCF 为常数、PED 的 N_eff 退化为 k、STV 退化为单伙伴 VoI。故 STeP 在「均匀信任 + 无时空约束」边界上**逐指令等于** FLUID-RAS；其余情形在相同安全旋钮（R_max、k_eff、STG）下，个性化只把同一查询预算重新分配，安全侧不变、效率侧提升（更少无效追问、更快消歧）。

**引理 21（时空记忆的去重增益与时效上限）** ESM 命中率 h 使重复提问期望减少 h·(重复率)；但记忆答案的可用概率随 age 指数衰减 e^{−age/τ_valid}，故净收益 ΔQ = h·(1 − e^{−age/τ_valid}) − c_lookup，存在最优刷新周期 τ*。**系**：记忆并非越多越好——过时记忆会以「本地可信」的名义把旧结论灌入新情境（对应定义 315 的 context aliasing）。

**定理 19（时空/个性化下的安全与无突变）** (a) ST 软剪枝只降权不硬删，且 `select_mode` 在存在 ST-一致模态时永不选择 ST-不一致模态，配合 R69 的 certified prefix 保证物理包络不变；(b) STV 规划的答案必须落在因果后果窗内，信息动作过 R69 定义 302 认证 ⇒ 交互不改变安全包络；(c) 任一环节失败（STG 不可信 / 变点触发 / 预算越界 / 时空有效性违例）→ λ 单调不降地退化到 R69/R68。故控制连续、无突变。

**定理 20（个性化投毒的信任上限）** 设 sleeper agent 背叛前被赋予 R≤R_max、变点检测期望延迟为 d 次交互、共谋关联 ρ<1。则单次背叛的错误采纳概率 ≤ (1−R_max)·ε_det(d)，且 T 次交互的累积损害 ≤ O((1−R_max)·d + T·δ·ρ^{k_eff−1})——**信任天花板与有效多样性共同把损害从「一次致命」压成「可检测、可回滚」**。若取消 R_max<1 或 k_eff≥2，上界退化为 R69 的单源界（引理 18）甚至更差。

## 6. 本轮最大风险

**一句话**：STeP-RAS 的最大风险不再是「问错」，而是**「问对的人、在对的时空，得到被个性化放大后的偏置」**——个性化可信度场会把系统变成一台**自动化的确认偏误机器**：它学会优先询问那些「会给出它想听的答案」的伙伴（高 R 与高一致性互相强化），把信任画像变成持续监控，并在 sleeper agent 用长期积累的信任换一次背叛时，把 R69 那种「诚实的不知道」升级为**「有据可依的错」**；而时空先验若过刚，又会把真正的物理异常当作「不可能」剪掉——**最危险的错误，是一个既符合物理、又来自最信任的人、还通过了校准门的错误**。

**次级风险与缓解**：
1. **ST 先验过刚剪掉真异常** → STG 校准门 + β 自适应下调 + E303 真异常召回实验；
2. **sleeper / 社会工程 / 共谋轮换** → 信任天花板 R_max + 变点检测 TCD + 有效多样性 k_eff + 定理 20 上界；
3. **确认偏误自动化 / 谄媚** → 反谄媚约束（答案与先验一致性不得进入权重）+ E314；
4. **时空欺骗（伪造地点、回放时间戳）** → 时空有效性窗 STV + 多源地点交叉验证 + ℰ_st 对抗训练 + E316；
5. **隐私与持续画像** → 遗忘因子 α + 信任后验熵上界 + E313 个体不可区分性审计。

def st_consistency(xi, occupancy, place_model):
    s_space = exp(-accel_penalty(xi)/SIG_S - jump_penalty(xi)/SIG_J)
    s_space *= 1.0 if clear_of(xi, occupancy) else 0.0     # 硬：不可穿透
    s_time  = causal_mask(xi) * duration_likelihood(xi)     # 硬：不可逆时
    return s_space * s_time * exp(place_model.loglik(xi.trajectory))

def soft_prune(modes, w, beta):
    s  = [st_consistency(m.prototype, ...) ** beta for m in modes]
    w2 = normalize([w[k]*s[k] for k in range(len(modes))])
    keep = [k for k in range(len(modes)) if w2[k] > W_MIN]   # 只降权，不硬删
    return [modes[k] for k in keep], normalize([w2[k] for k in keep])

def evidence_discipline(weighted_votes, st_agree):

            return mode
    return None            # 单源（即便 R=R_max）不得单独定案

# IP-267 STV-Planner：何时/何地/问谁（时空 VoI + 时间折扣）
def plan_interaction(modes, o, partners, budget, deadline):
    cands = []
    for p in partners:
        lat = latency(p, o)
        if o.t + lat > deadline: continue                     # 因果后果窗
        gamma = exp(-lat / TAU_WINDOW)                        # 时间折扣
        for g in info_actions_for(p, modes):
            if not budget.allow(g, p) or not c_ras_wm.certify_info(g, o):
                continue
            voi   = mutual_info(modes, channel(p, o), g)      # 个性化信道互信息
            cands.append((gamma*voi - travel(p,o) - delay(p) - social(p), g, p))
    best = lazy_argmax(cands)                                 # 惰性子模近似
    return best if best and best[0] > 0 else None             # 无利可图 → R69

# IP-273 STeP 主闭环（继承 R69 FLUID，仅在假设剪枝与交互选择处插 ST/个性）
def STeP_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    beta = M.stg.beta(o)                         # STG 先验校准门
    modes, w = M.stm.soft_prune(modes, ..., beta)   # 1) 先杀幻影模态
    U_epi = reestimate_epi(modes, w)
    tba = M.tba.judge(modes, M.fma.flow_anomaly(...), M.stm)   # 2) 对偶审计
    g, p = (M.stv.plan(modes, o, M.pcf.partners(), M.budget, o.t + M.vista.H)
            if (U_epi > TAU_EPI and tba != 'phantom') else (None, None))  # 3) 个性化 ST VoI
    if g is not None:
        y = M.cia.execute(g, p)
        M.esm.write(o.x, o.t, p, y)              # 4) 时空记忆
        M.pcf.update(p, y, None)                 # 信任更新 + 变点检测
        U_epi = M.ped.merge(modes, y, M.pcf, o)  # 有效样本量纪律
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k   = M.c_ras_wm.certified_prefix(...)
    if tba == 'phantom' or M.stg.untrusted: lam = max(lam, 0.8)  # 退 R69/R68
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_i.submit_async(g, p, U_epi, tba)
    return k, lam, mode, (U_ale, U_epi)
```

## 4. 推导

**引理 19（时空软剪枝对幻影模态的削减）** 幻影模态 ST-不一致概率 ≥ 1−η_ph、真模态 ST-一致概率 ≥ 1−ε_ST，则 `ŵ^ST ∝ ŵ·S^β` 使幻影期望存活权重 ≤ η_ph^β，U_epi 的虚高部分被压掉；ε_ST→0、η_ph→0 时幻影全灭。系：剪枝净价值 = 真歧义可分性·(1−ε_ST) − 真异常被误剪风险，故 β 必须由 STG 校准。

**引理 20（个性化证据的有效样本量界）** 权重 R_i 的加权多数错误率 ≤ `exp(−N_eff·D(R̄‖1/2))`，`N_eff=(ΣR_i)²/ΣR_i²`；单源 N_eff=1 有正错误下界；权重均匀时 N_eff=K，退化为 R69 引理 18。系：过度信任单一高 R 伙伴在数学上等同于减少有效样本量。

**引理 21（ESM 去重增益与时效上限）** 重复提问减少 `h·(重复率)`，但记忆可用概率随 age 指数衰减，净收益 `ΔQ=h(1−e^{−age/τ_valid})−c_lookup`，存在最优刷新周期 τ*；过时记忆以「本地可信」名义污染新情境（context aliasing）。

**定理 18（STeP 严格包含 FLUID-RAS）** β=0 + 均匀信任 + 单对话者 + 空记忆时，STeP 逐指令等于 FLUID-RAS；其余情形在相同安全旋钮（R_max、k_eff、STG）下只重新分配查询预算，安全侧不变、效率侧提升。

**定理 19（时空/个性化下的安全与无突变）** ST 只降权不硬删且 `select_mode` 永不选 ST-不一致模态；STV 答案须落在后果窗内且信息动作过 R69 定义 302 认证 ⇒ 安全包络不变；任一环节失败 ⇒ λ 单调不降退化到 R69/R68，控制连续无突变。

**定理 20（个性化投毒的信任上限）** sleeper agent 单次背叛错误采纳 ≤ `(1−R_max)·ε_det(d)`；T 次累积损害 ≤ `O((1−R_max)·d + T·δ·ρ^{k_eff−1})`。信任天花板 + 有效多样性把损害从「一次致命」压成「可检测、可回滚」；取消 R_max<1 或 k_eff≥2 则退化为单源界甚至更差。

## 7. 本轮最大风险

**一句话**：STeP-RAS 的最大风险不再是「问错」，而是**「问对的人、在对的时空，得到被个性化放大后的偏置」**——个性化可信度场会把系统变成一台**自动化的确认偏误机器**（学会优先询问会给出它想听答案的伙伴，高 R 与高一致性互相强化），把信任画像变成持续监控，并在 sleeper agent 用长期信任换一次背叛时，把 R69 的「诚实的不知道」升级为**「有据可依的错」**；而时空先验若过刚，又会把真正的物理异常当作「不可能」剪掉——**最危险的错误，是一个既符合物理、又来自最信任的人、还通过了校准门的错误**。

**次级风险与缓解**：ST 先验过刚剪真异常（STG + β 自适应 + E303）；sleeper/社会工程/共谋（R_max + TCD + k_eff + 定理 20）；确认偏误自动化（反谄媚约束 + E314）；时空欺骗（STV + 多源地点交叉验证 + ℰ_st + E316）；隐私与持续画像（遗忘因子 α + 后验熵上界 + E313）。
