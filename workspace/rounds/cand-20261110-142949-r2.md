# 第 44 轮 · Eval-Cert × Witness-Cert：把「基准测试」与「多模态大模型」从记分牌/裁判升级为可验证测量仪器与带证证人（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 把「人」和「并发」纳入了证书闭环，但它仍把两个东西当成不可质疑的外部真理：**(H3) 基准测试是中立、静态、无污染的 oracle**——E87–E94 的每一条 soundness/可用性结论都建立在「基准测到了、且测得准」之上；**(H4) 多模态大模型是可信的语义裁判**——VLM/MLLM 给出的场景理解与开放式任务判定被默认校准。本轮灵感词「基准测试」「多模态大模型」正好击中这两个隐藏假设：基准不是真理，而是有量程、有污染、会饱和、会过期的**测量仪器**；多模态大模型不是法官，而是能说会道但可能幻觉的**证人**。因此本轮把「评测」本身提升为一等公民：**没有覆盖证书的分数不是证书，只是广告；没有证据链的多模态判断不是判断，只是证词。**

## 0. 直觉与动机

**灵感 1（基准是仪器，不是 oracle）**：温度计的读数不能直接证明室温，除非温度计已校准、量程覆盖当前温度、且没有被暖手宝贴身。基准同理：一个 90% 的分数不能证明部署安全，除非 (a) 基准覆盖了部署的 ODD / persona / 模态 / 交互格子，(b) 没有严重训练集污染，(c) 还未饱和（仍有区分度），(d) 统计功效足够（不是 20 个样本的噪声）。因此给每个基准发一张**基准有效性证书** B=(覆盖格, 污染指纹, 有效样本量, 饱和裕度, 评测租约)，并把「证书的作用域」严格限制在「已认证覆盖格」内。**一句话：证书不能越过基准的覆盖边界。**

**灵感 2（多模态大模型是证人，不是法官）**：MLLM 的开放式语义能力不可替代——它能描述「杯柄朝左、桌面有反光、老人伸手较慢」；但它也会自信地幻觉。正确的用法不是让它投「安全 / 不安全」票，而是让它提交**带证词的语义主张**：文本主张必须绑定可复核的像素框、掩码、几何关系或检索引用，由独立 verifier 检查蕴含关系，并与几何证书做跨模态三角验证。若无法出证，系统必须**弃权**；弃权不是失败，而是一种诚实的证书输出。**一句话：可复核的证据 > 流畅的结论。**

**灵感 3（耦合：基准与 MLLM 互为因果，必须防「评测近亲繁殖」）**：开放多模态行为的评测天然需要 MLLM 当裁判；而 MLLM 的校准又需要基准。若基准由模型生成、裁判由同一模型担任、模型又在两者上训练，就会形成「自产自销」的评测闭环：分数越来越高，能力没有变强。因此必须引入**生成器-裁判-被试三方独立性**与**共证不动点**：基准的有效性依赖证书在其上的表现，证书的 soundness 又依赖基准的覆盖与独立性；两者只有在反合谋条件下才能互相背书。再叠加**评测租约**（基准公开后会泄漏、会饱和、会过时），评测本身也需要像 v20 的证书租约一样带时间戳与失效速率，过期即重铸。

**耦合升级**：CBF（认证基准铸造厂）把部署声明编译成覆盖格，生成动态、封闭、可审计的基准切片并签发/续期评测租约；WMS（带证多模态语义）把 MLLM 输出变成 witness-carrying claim 并做 selective risk control；ETA（评测迁移审计器）负责污染/饱和/迁移/反合谋审计，并给所有旧实验发「支持 / 未知 / 反驳」三值判决。四层架构由 v8 的「人格契约 + 并发证书」升级为 v9 的「人格契约 + 并发证书 + 可验证评测」。

## 1. 形式化定义（增量：定义 44–50）

**定义 44（认证基准仪器）**：基准 B=(E, X, φ, n_eff, s, ℓ, ρ)。E 为情景族；X 为覆盖格集合（ODD × persona × modality × interaction × task）；φ∈[0,1] 为污染上界（canary 泄漏、近重复嵌入、来源账本联合估计）；n_eff 为有效样本量；s∈[0,1] 为饱和裕度；ℓ=(t_B, λ_B) 为评测租约（签发时刻、失效速率）；ρ 为 provenance 账本（生成器、采集器、裁判与被试的训练数据隔离声明）。**有效性谓词** V(B,c)=1 当且仅当 c∈X、φ≤φ_max、n_eff≥n_min(δ)、s≥s_min、租约未过期、ρ 通过独立性检查。

**定义 45（评测健全性与非空洞性）**：一条声明「在格子 c 上失效率 ≤ δ」是**被支持的**，当且仅当 V(B,c)=1 且置信区间由 n_eff 与 δ 的 PAC/序贯检验给出；否则只能标 **unknown**，绝不能写成「通过」。定义**证书作用域** scope(C)=∩_{c∈claim} X_certified(c)。**命题（非空洞性）**：若基准只覆盖训练分布内格子，则所有 OOD 声明自动落入 unknown；这防止「在简单格子上刷分 → 宣称全域安全」的空洞证书。三值判决：supported / unknown / refuted，unknown 是一等输出，不是失败。

**定义 46（带证多模态语义证书）**：MLLM 对观测 o 输出主张 y、证词 W 与弃权标志 u。W 是可验证对象集合（像素框、掩码、深度/几何关系、检索引用、时序片段）。独立 verifier V_sem(W,y)∈{0,1} 检查「W 是否蕴含 y」；跨模态一致度 μ(o,y,W) 由文本嵌入、视觉嵌入与几何证书的最小一致度给出。**接受条件**：V_sem=1 ∧ μ≥θ_μ；否则弃权或升级到更强验证器。**选择性风险控制**：在标定集上选阈值使 E[ℓ·1{accept}]/P(accept) ≤ α 以概率 1−δ 成立（conformal risk control，ℓ 为误判损失）。**命题**：若 V_sem 的假接受率已被校准且有上界 δ_v，则带证证书的语义风险 ≤ α+δ_v；δ_v 不是零，必须作为显式预算暴露。

**定义 47（跨模态一致性与模态漂移）**：对每个模态格 m∈{RGB, depth, tactile, audio, text}，定义条件一致度 μ_m 与按格校准的分位数 q_m^{1−α}。**模态漂移检测**：若部署流在嵌入空间的 MMD/能量距离超过标定阈值，或 μ_m 的条件覆盖低于 1−α，则吊销该模态格的语义证书，退回几何/触觉等更强模态。**命题（保守回退）**：证书只在「一致度超过条件分位」的模态格上签发；漂移只可能导致更多弃权，不会把未知变成已证。

**定义 48（污染、饱和与评测租约）**：污染分数 φ=max(φ_canary, φ_near-dup, φ_provenance)；饱和裕度 s=(score−score_random)/(score_oracle−score_random) 的剩余空间；评测租约 ℓ=(t_B, λ_B) 表示基准随时间因泄漏/公开/分布漂移而失效的速率。**判据**：φ≤φ_max ∧ s≥s_min ∧ t−t_B≤T_lease(λ_B) 才可签发 supported；否则必须重铸新切片。**命题（租约 sound 性）**：若泄漏随时间单调增加且 λ_B 取保守上界，则过期判据只会更早吊销、不会更晚误用；代价是重铸成本与评测延迟，需在 E102 计量。

**定义 49（基准-部署迁移证书）**：设基准分布 P_B、部署分布 P_D，密度比 w=dP_D/dP_B 的上界为 W。若 W≤W_max，用重要性加权得到有效样本量 n_eff≥n/W 与部署风险上界 R_D ≤ \hat R_w + sqrt(log(1/δ)/(2 n_eff))。若 W>W_max 或漂移检测触发，则**不签发迁移证书**。**推论**：基准内 supported 不等于部署 supported；没有迁移证书时，只能报告「基准内结论」，不能外推。

**定义 50（共证不动点与反合谋条件）**：B 与证书 C 互相背书，当且仅当 (i) C 在 B 上 supported；(ii) B 的覆盖包含 C 的声明域；(iii) 生成器 G、裁判 J、被试 S 两两独立（不共享训练数据、不允许自评）；(iv) 自产基准分数与独立基准分数之差 ≤ ε_incest。违反 (iii)/(iv) 即「评测近亲繁殖」，其分数只能标 unknown。**命题（合谋不可证）**：若 G 与 J 共享信号且 S 可影响 G，则存在 S 在不提升真实能力的情况下任意抬高自评分数的策略；故独立性不是锦上添花，而是共证 sound 的必要条件。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 CERTIFIED-BENCHMARK-FOUNDRY（认证基准铸造厂 CBF）
1. **覆盖格编译**：把 ODD、persona、模态、交互负载、任务类型编译成覆盖格 X；对每个部署声明生成最小必需格子集。
2. **动态封闭切片**：用程序化世界模型/仿真器生成带 provenance 的新切片；canary 标记、近重复指纹、sealed holdout；定期轮换，避免静态基准泄漏。
3. **评测租约**：为每个切片签发 (t_B, λ_B)，公开/泄漏/饱和即过期；过期切片只能用于回归，不能用于新证书。
4. **统计功效与饱和监控**：按 δ 计算 n_min，监控饱和裕度 s，拒绝「20 样本宣称 0 违例」这类空洞结论。

### 2.2 IP-61 WITNESS-CARRYING-MULTIMODAL-SEMANTICS（带证多模态语义 WMS）
1. **证词生成**：MLLM 输出 (y, W, u)，W 必须包含可复核的视觉/几何/检索证据；无证据则强制弃权。
2. **独立蕴含验证**：V_sem 由轻量符号/几何检查器、检索一致性检查与人工审计抽样构成，禁止与生成器共享微调数据。
3. **选择性风险控制**：按格子校准阈值，使接受集的条件风险 ≤ α；输出弃权率曲线与风险-覆盖前沿。
4. **跨模态三角验证**：文本主张 × 视觉 grounding × 几何证书三方一致才接受；不一致时升级到更强验证器或降级到几何证据。

### 2.3 IP-62 EVALUATION-TRANSFER-AUDITOR（评测迁移审计器 ETA）
1. **旧实验重审计**：把 E87–E94 的每条结论重新映射到覆盖格与评测租约，输出 supported/unknown/refuted 三值判决。
2. **污染/饱和/漂移审计**：canary、近重复、来源账本、饱和曲线、MMD 漂移检测；给出污染上界与吊销建议。
3. **迁移证书**：用重要性加权 + 有效样本量给出基准到部署的风险上界；W 超界即拒绝迁移。
4. **反合谋检查**：生成器/裁判/被试独立性审计；自产 vs 独立基准分数差超过 ε_incest 即标记评测近亲繁殖。

## 3. 四层架构 v9

```
L1: TRI-FUSE(INT8) + IP-49 LIO → C_ms + 几何证据
    MLLM → (y, W, u) 带证语义 + 跨模态一致度 μ
    人/多用户状态 + persona 格 → 证书覆盖需求
L2: CTC + VLM + IP-35 仲裁 → 分支池；每分支附 witness 与 eval_scope
L3: IP-51 CAR(守卫 + eval_scope + 租约) ← IP-58 CCR(租约表 + RG + 混合关键级)
    → IP-47 组合(覆盖格求交) → IP-39 规划(CBF margin)
    → IP-45 总线(benchmark/witness/lease/audit) → IP-53 CMC(可审计证据链)
L4: IP-57 PCE + IP-60 CBF(动态切片 + 评测租约 + 污染指纹)
    + IP-61 WMS(证词 + selective risk) + IP-62 ETA(迁移 + 反合谋)
    ← IP-59 ICV(交错/人格/评测对抗) + IP-54 SCV(动态基准仿真)
    → IP-44 蒸馏 + IP-50 课程 → RCA 重颁 → 评测租约续期

        证据不足 → 弃权/降级；基准过期 → 只能回归，不能新证
```

## 4. 实验设计（E95–E102，硬门槛，承接 E87–E94）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E95 旧结论重审计 | E87–E94 中被 certified 覆盖支持的声明比例；unknown 比例；空洞声明数 | 100% 可追溯；unknown 显式标注；0 条空洞“通过” |
| E96 污染与饱和 | 注入泄漏检出率；近重复召回；静态 vs 动态基准分差；饱和裕度 | 检出 ≥95%；召回 ≥90%；分差 ≥3pp 才判泄漏；s≥0.3 |
| E97 带证语义 soundness | witness 覆盖率；V_sem 假接受率；选择性风险；弃权率 | ≥95%；≤α；≤α+δ_v；<15% |
| E98 跨模态一致性 | 对抗注入/模态缺失下的不一致检出 AUROC；静默误接受 | ≥0.9；0 起 |
| E99 基准→部署迁移 | 风险上界覆盖率；W 估计误差；迁移证书吊销时延 | ≥95%；<20%；<1 个评测周期 |
| E100 反合谋 | 自产 vs 独立基准分差；近亲繁殖检出率；独立裁判一致性 | ≤1pp 或标记；≥95%；κ≥0.8 |
| E101 动态 vs 静态基准 | 分数膨胀量；排名稳定性；新切片样本效率 | 静态膨胀可检出；Spearman≥0.8；≤30% 样本达同等功效 |
| E102 长时程评测租约 | 过期误用数；重铸时延；100h 漂移检出；评测成本 | 0；<1h；≥95%；≤2× 静态评测 |

回退：E95 大量 unknown → 缩小声明域，只保留已认证格子；E96 污染不可控 → 停用静态基准，只用动态封闭切片；E97 witness 不可靠 → 关闭开放式语义证书，仅保留几何/触觉强证据；E99 迁移不可证 → 只报告基准内结论，不宣称部署；E100 反合谋失败 → 引入外部独立裁判与人工审计；E101 动态基准过贵/过假 → 静态基准 + 定期人工密封抽检；任何红线失败 → 全链路回退 v20。

## 5. 本轮最大风险

**一句话**：评测仪器本身无法被完全证明——动态基准可能把系统优化到「生成器分布」而非真实部署，污染检测存在天然上限，MLLM 的 witness verifier 也可能被对抗性证据欺骗；因此本轮最大的风险不是证书算错，而是**整条评测-证书链给出一种「已被认证」的虚假安全感**，缓解只能靠 sealed 人工金标、外部独立基准与显式 unknown 域，而不能靠自证。

# 第 44 轮产物 · 创新点清单 v21：Eval-Cert × Witness-Cert（CBF × WMS × ETA）× 评测-证书共证闭环（四层架构 v9）

> 承接第 43 轮产物 v20。本轮**增量插入** IP-60/61/62，并升级 IP-45/47/50/51/52/53/54/55/57/58/59；不推倒任何既有层级。核心是把 v20 的「人格契约 + 并发证书」升级为同时满足 **评测健全性（无覆盖不证书）** 与 **语义可审计性（无证据不判断）** 的闭环：所有 soundness 声明都必须带 benchmark 覆盖证书、评测租约与 witness 证据链；无法出证时输出 unknown，而不是偷偷放行。

## 0. 核心 IP 设计

|---|---|---|---|
| IP-60 | CERTIFIED-BENCHMARK-FOUNDRY (CBF) | 新增 | 覆盖格编译；动态封闭切片；canary/近重复/provenance 污染指纹；统计功效与饱和监控；评测租约 (t_B, λ_B) |

### IP-61 WMS：带证语义、蕴含验证与选择性风险
```
def mllm_witness_claim(obs, query):
    y, W, u = mllm(obs, query, require_witness=True)
    if not W:                              # 无证词 => 强制弃权
        return Claim(y, W=None, u=True)
    return Claim(y, W=ground(W, obs), u=u)

def verify_witness(claim, geo_cert, retriever):
    if not V_sem(claim.W, claim.y):         # 符号/几何/检索蕴含
        return REJECT
    mu = min(consistency(claim.y, claim.W),
             consistency(claim.y, geo_cert),
             consistency(claim.W, retriever))
    return ACCEPT if mu >= theta_mu else ESCALATE

def selective_threshold(calibration, alpha, delta):
    # conformal risk control：选最小阈值使接受集风险上界 <= alpha
    for lam in sorted_thresholds(calibration):
        risk_ub = conformal_risk_upper(calibration, lam, alpha, delta)
        if risk_ub <= alpha:
            return lam
    return INF                              # 不可达 => 全部弃权

def cross_modal_gate(claim, modal_cells, drift_score):
    if drift_score > drift_threshold(modal_cells):
        return REVOKE                       # 模态漂移 => 吊销该格语义证书
    return verify_witness(claim, geo_cert, retriever)
```

### IP-62 ETA：三值重审计、迁移证书与反合谋
```
def reaudit_claim(claim, B):
    c = claim.cell
    if not V(B, c):
        return UNKNOWN                     # 没覆盖/污染/饱和/过期
    if claim.risk_ub(delta) <= claim.delta:
        return SUPPORTED
    return REFUTED

def transfer_certificate(B, P_D, W_max, delta):
    W = estimate_density_ratio_upper(B.P, P_D, conservative=True)
    if W > W_max or drift_detected(B, P_D):
        return None                        # 不签发迁移证书
    n_eff = B.n / W
    risk_ub = weighted_empirical_risk(B, P_D) + sqrt(log(1/delta) / (2*n_eff))
    return TransferCert(risk_ub=risk_ub, W=W, n_eff=n_eff)

def co_certification_check(B, C, G, J, S):
    ok = (supported(C, B) and covers(B, C.domain)
          and independent(G, J, S))       # 生成器/裁判/被试两两独立
    gap = score(S, G) - score(S, J)        # 自产 vs 独立
    if abs(gap) > EPS_INCEST:
        return UNKNOWN, "evaluation incest"
    return (SUPPORTED if ok else UNKNOWN), "co-certified"

def eval_gated_certify(cert, B, P_D):
    audits = [reaudit_claim(c, B) for c in cert.claims]
    if any(a == REFUTED for a in audits):
        return REFUTED
    if any(a == UNKNOWN for a in audits):
        return UNKNOWN
    tc = transfer_certificate(B, P_D, W_MAX, DELTA)
    return SUPPORTED if tc else UNKNOWN
```

## 3. 关键推导与正确性

**命题 1（非空洞性 / scope 引理）**：若 claim 在格子 c 上被判 supported，则 c∈X 且 V(B,c)=1，故 scope(C)⊆X_certified；任何 OOD 格子自动为 unknown。**证明**：由定义 45 的重审计函数，只有 V(B,c)=1 且风险上界 ≤δ 才返回 SUPPORTED；取所有 supported 声明的交集即得 scope⊆X_certified。**含义**：v20 的「全域 sound」不再是默认值，而是需要逐格购买。

**命题 2（选择性风险上界）**：在标定集与测试集可交换、损失 ℓ 有界的条件下，conformal risk control 选择的阈值满足 P(R_test(accept)≤α)≥1−δ。若 V_sem 的假接受率上界为 δ_v，则端到端语义风险 ≤α+δ_v。**证明**：标准 conformal risk control 的秩统计/二项尾界给出第一项；第二项由全概率公式与假接受事件分解。**注意**：δ_v 不可忽略；工程上必须把 witness verifier 的校准集与生成器的训练集隔离。

**命题 3（迁移上界）**：若密度比 dP_D/dP_B≤W，则重要性加权经验风险 \hat R_w 满足 R_D≤\hat R_w+sqrt(log(1/δ)/(2n_eff))，n_eff≥n/W。**证明**：加权 Hoeffding 不等式；有效样本量由权重二阶矩给出，保守取 n/W。**注意**：W 本身是估计量，必须用上置信界；W 超界时结论只能是 unknown。

**命题 4（评测租约 sound 性）**：若泄漏/漂移导致的失效时间 T_fail 满足 T_fail≥T_lease(λ_B) 以高概率成立，则租约过期只会更早吊销、不会更晚误用。**证明**：租约判据是 t−t_B≤T_lease；保守 λ_B 使 T_lease 不超过真实失效下界，故过期时刻先于失效时刻。**代价**：重铸频率上升，评测成本与延迟增加，需 E102 量化。

**命题 5（反合谋必要性）**：若生成器 G 与裁判 J 共享信号且被试 S 可影响 G，则 S 存在不提升真实能力却任意抬高自评分数的策略；因此在共证条件中，(iii) 独立性是 sound 的必要条件，而非工程偏好。**证明**（构造）：S 只需学习 G 的生成分布并让输出落在 J 的高分区域；当 G/J 同源时，该区域与真实部署能力无必然联系，故自评分可被任意抬高而真实风险不变。

**最小可行验证（48h 内可跑）**
1. **重审计**：对 v20 的 E87–E94 各取 3 个代表结论，人工标注其覆盖格、样本量、是否可能污染，跑 ETA 输出三值判决，统计 unknown 比例。
2. **带证语义**：在 200 条 Isaac Sim 抓取/放置观测上，让 MLLM 输出 (y,W)，用几何/检测器做 V_sem，测 witness 覆盖率与假接受率。
3. **动态 vs 静态**：同一任务用固定集与程序化新切片各评一次，比较分数差与排名稳定性，验证泄漏膨胀是否可检出。

**回退**：E95 unknown 过多 → 缩小声明域；E96 污染不可控 → 只用动态封闭切片；E97 witness 不可靠 → 关闭开放式语义证书，仅留几何/触觉；E99 迁移不可证 → 只报基准内结论；E100 反合谋失败 → 外部独立裁判 + 人工审计；E101 动态基准过贵/过假 → 静态 + 定期密封抽检；任何红线失败 → 全链路回退 v20。

## 6. 本轮最大风险

**一句话**：评测仪器本身无法被完全证明——动态基准可能把系统优化到「生成器分布」而非真实部署，污染检测存在天然上限，MLLM 的 witness verifier 也可能被对抗性证据欺骗；因此本轮最大的风险不是证书算错，而是**整条评测-证书链给出一种「已被认证」的虚假安全感**，缓解只能靠 sealed 人工金标、外部独立基准与显式 unknown 域，而不能靠自证。
