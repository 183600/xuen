# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；灵感循环第 6 轮；本轮灵感：「创新点」×「竞赛策略」）

> 第 59 轮把执行层物理彻底纳入安全论证链，系统达到 v16****：151 个 IP、16 个能力层、13 维执行状态、七类证据门、四重预算、双向契约——但这一路有一个从未被审视的公理：**「IP 越多 = 创新越多 = 竞赛越强」**。本轮两个灵感词「创新点」「竞赛策略」正是对这个公理的反证：竞赛评委不会阅读 151 条 IP，只会记住 3~5 个能当场演示、能经受追问、能说清「比谁好、好在哪、凭什么信」的创新点。本轮把研究镜头从「机器人」转向「研究本身」，核心命题：**「把 151 个 IP 蒸馏成一个可演示、可辩护、可复现的创新点组合，并为竞赛设计一套带保底分支的策略树」**——即从「技术堆叠」转向「价值交付」。

核心矛盾：
- **H32（创新点非可加性）**：151 个 IP ≠ 151 个创新点。其中大量是**支撑件**（infrastructure，如 ERTC 的 WCET 认证）、少数是**爆点**（differentiator，如执行接地校准链）、还有一批是**投机件**（speculative，未验证、依赖未成立假设）。把库存当价值，导致「创新通胀」——每轮新增 IP，但**边际差异化价值递减**；评委的感知带宽是常数（约 3~5 个点），超出的部分不是资产而是噪音。
- **H33（证据-主张鸿沟）**：每个创新主张需要**独立、可复现、在演示预算内**的证据。当前 151 条里绝大多数只有「定理 + 假设 A22~A55」，没有对应实验；主张强度与证据强度严重失配。竞赛的真实风险不是「技术不够深」，而是「说得出、证不出、演不了」。
- **H34（评分对齐 vs Goodhart）**：直接对评分表优化会诱发**基准作弊**——演示很炫但能力很浅，评委 Q&A 一轮即穿。需要「rubric 鲁棒」策略：既对齐评分维度，又保持**证据-主张比**诚实，并让每个维度至少有一条可被追问的硬证据。

## 0. 直觉与动机

**灵感 1（创新点 → 四元组而非能力）**
直觉：说「我们有执行接地层」不是创新点，说「在 BLDC 转矩脉动下，我们把接触力估计的 99% 分位误差从 X 降到 Y，相对基线 Z，证据见实验 E182」才是。创新点是**关系性的**：它必须同时钉住「能力、基线、增量、证据」四根桩。缺任一根，它就从「创新」退化为「功能」（无基线）或「主张」（无证据）或「演示」（无增量）。四元组还天然要求**公平基线**：不能拿「第 58 轮的系统」当唯一基线自我循环，必须有外部强基线（商用 VLA/经典阻抗控制/开源栈）。

**灵感 2（创新点 → 蒸馏而非罗列）**
直觉：151 条里有**覆盖**（不同评分维度各取所需）、有**冗余**（多条 IP 讲同一个故事）、有**协同**（共享基础设施，一起演示成本更低）、有**成本**（集成/测试/演示工时）。蒸馏就是在这个结构上选一个不超过 K=3~5 的「冠军组合」，使差异化价值最大、集成债最小。注意它既不是纯子模（覆盖部分可子模化）也不是纯超模（协同部分超模），所以不能直接套贪心 1−1/e，需要「贪心 + 局部交换 + 曲率界」。

**灵感 3（竞赛策略 → 评分对齐与空洞检测）**
直觉：UniBot 评分大致分「创新性、技术深度、完成度、实用性、展示」五维。151 条 IP 在五维上的覆盖是**极不均衡**的：技术深度爆表，完成度与实用性存疑，展示几乎没设计。对齐分析要找出「rubric 空洞」（某维度没有任何强证据覆盖），并把有限精力优先填洞，而不是继续加深已经溢出的维度。

**灵感 4（竞赛策略 → 演示决策树与保底分支）**
直觉：竞赛现场是一次**带时间预算和失败概率的序贯决策**。不是「把所有功能演一遍」，而是「按成功概率/时间/得分设计一棵树，每步失败都能回退到保底演示」。第 59 轮的 DEGRADE_EXEC / 保守阻抗预设恰好可以复用为演示树的安全回退叶——把「安全降级」从运行时机制升级为**叙事机制**：「即使最坏情况，我们也能展示受控降级」。

**灵感 5（竞赛策略 → 保底 + 爆点的组合配置）**
直觉：全部押注高风险爆点 = 可能颗粒无收；全部押注保底 = 平庸。正确做法是组合：用一部分精力确保「保底可完成、可演示、可复现」的地基（safe baseline），把剩余精力按低相关性分散到 2~3 个高上行爆点，用 CVaR 约束下行。这正是金融组合思想迁移到研究下注。

**灵感 6（叙事一致性 → 黄金路径与一句话故事）**
直觉：冠军组合必须能串成一条**黄金路径**：感知 → 证据 → 决策 → 执行 → 安全。若冠军 IP 大量散落在互不相连的分支上，评委看到的是「功能大杂烩」而非「一个系统」。叙事一致性 = 冠军 IP 落在黄金路径上的比例 × 依赖 DAG 的连通度。最终必须收敛成一句话：「我们让机器人 X 在 Y 条件下做到 Z，比基线 B 好 Δ，证据是 E。」

## 1. 形式化定义（增量：定义 153–160）

**定义 153（创新点四元组 IPQ）** 创新点 C=(cap, base, Δ, E)：
- cap：可测能力（行为 + 指标定义）；
- base：公平基线（外部强基线优先，禁用「自我上一轮」作为唯一基线）；
- Δ = (metric(cap) − metric(base)) / scale，需统计显著（置信区间下界 > δ_min）；
- E = (实验协议, 数据集, 复现脚本, 演示时长 t_demo, 已知失败模式)。
有效性：Valid(C) ⇔ (Δ > δ_min) ∧ Fair(base) ∧ Repro(E) ∧ (t_demo ≤ T_slot)。
「无基线的 cap 是功能；无证据的 Δ 是主张；不可复现的 E 是轶事。」

**定义 154（创新点蒸馏 IPD）** 地面集 G={C_1..C_n}（n=151），属性：新颖度 ν_i、证据强度 e_i、演示成本 d_i、依赖深度 ℓ_i、评分覆盖向量 c_i∈{0,1}^5。冠军组合 S，|S|≤K。目标：
```
F(S) = Σ_r w_r·min(1, Σ_{i∈S} c_i[r]·e_i)        # 覆盖（子模）
     + λ_syn·Σ_{i<j∈S} Syn(i,j)                   # 协同（超模）
     − λ_red·Σ_{i<j∈S} Red(i,j)                   # 冗余（次模惩罚）
     − λ_cost·Σ_{i∈S} d_i − λ_dep·max_{i∈S} ℓ_i   # 成本/依赖
```
求解：因 F 非纯子模，采用「贪心初始化 + 成对局部交换 + 曲率界 ρ 的近似保证 (1−e^{−ρ})/ρ」；n 小时退化为 ILP 精确解。输出冠军集 S*、支撑集 S_sup（不进叙事但在系统里）、冻结集 S_frozen（投机件，竞赛周期内不做）。

**定义 155（评分对齐 CRA）** 评分向量 R=(创新性, 技术深度, 完成度, 实用性, 展示)，权重 w。覆盖矩阵 M[i,r]∈[0,1] 表示 IP i 对维度 r 的**证据支撑覆盖**。对齐度 A(S)=Σ_r w_r·min(1, Σ_{i∈S} M[i,r])。空洞 H={r | A_r(S)<a_min}。补洞计划 = 在成本预算内最小代价提升 H 的方案。**Rubric 鲁棒约束**：每个被覆盖维度至少有一条主张满足证据-主张比 ρ=E_strength/claim_strength ≥ ρ_min，防止 Goodhart。

**定义 156（复杂度债与可构建性 CDB）** 集成债 D_int(S)=Σ_{i∈S}(接口复杂度 + 测试成本 + 故障耦合度)。可构建性 B(S)=B_team·T_remaining / D_int(S)。可行 ⇔ B(S) ≥ 1。剪枝规则：若 D_int(S) > B_team·T_remaining，则按边际价值/成本比从低到高剔除，直到可行。**可构建性是一类一等资源，不是事后约束**；第 59 轮的四预算 B_probe/B_ft/B_ux/B_exec 之外，本轮新增 B_build。

**定义 157（演示组合策略 DPS）** 演示决策树 T=(节点=能力, 边=转移, 叶=得分结果)。节点 i 有成功概率 p_i、耗时 t_i、展示得分 s_i。策略 π: state→下一步演示动作。期望得分 E_π=Σ_leaf P(path)·score。失败回退 F(i)（复用第 59 轮 DEGRADE_EXEC/保守预设作为安全回退叶）。优化：
```
max_π  E_π
s.t.   Σ t_i ≤ T_demo
       CVaR_α(score) ≥ baseline_floor
```
关键：回退不是「丢脸的失败」，而是「受控降级」的**叙事资产**。

**定义 158（竞赛策略组合 CSP）** 下注 b_i 有期望增益 g_i、方差 σ_i、相关性矩阵。努力配置 x_i，Σ x_i ≤ 1，其中 x_0 为保底地基。目标：
```
max_x  E[score] − λ_risk·CVaR_α(loss)
s.t.   x_0 ≥ x_safe（保底不可挪用）
       Σ_{i≥1} x_i ≤ 1 − x_safe，且爆点两两相关性 ≤ ρ_max
```
「保底 + 爆点」：保底保证「最坏也能完整演示」，爆点用低相关分散争取上行。

**定义 159（叙事一致性 NCF）** 黄金路径 P*=感知→证据→决策→执行→安全。一致性 κ = |{i∈S* : i∈P*}| / |S*| × connectivity(G_dep[S*])，其中 connectivity 为冠军 IP 依赖子图的连通度（最大连通分量占比）。一句话故事模板：**「我们让机器人 X 在 Y 条件下做到 Z，比基线 B 好 Δ，证据是 E。」** κ 低 ⇒ 组合是「功能袋」而非「一个系统」。

**定义 160（竞赛就绪证书 J_comp）** J_comp=(S*, S_sup, A(S*), H, D_int, B, demo_tree, π*, CSP 配置, κ, 一句话故事, evidence_manifest, risk_register, version)。证书要求：每个冠军点证据清单可追溯、基线可复核、演示树每个节点有回退叶、下行 CVaR 有界。

### IP-152 IPD（创新点蒸馏）

```python
@dataclass
class InnovationClaim:
    cap: str; base: str; delta: float; evidence: EvidencePack
    novelty: float; evidence_strength: float; demo_cost: float
    dependency_depth: int; rubric_coverage: np.ndarray  # (5,)
    role: str  # 'champion' | 'support' | 'speculative'

def distill_innovation_portfolio(G, K=5, budget=None):
    # 1) 有效性过滤：无基线/无证据/不可复现/超时 一律剔除
    valid = [c for c in G if is_valid_claim(c)]
    # 2) 投机件冻结
    frozen = [c for c in valid if c.role == 'speculative']
    valid = [c for c in valid if c.role != 'speculative']
    # 3) 贪心初始化（覆盖优先，协同加成，冗余惩罚）
    S = []
    while len(S) < K:
        best, best_gain = None, -inf
        for c in valid:
            if c in S: continue
            gain = marginal(F, S, c)
            if gain > best_gain:
                best_gain, best = gain, c
        if best_gain <= 0: break
        S.append(best)
    # 4) 成对局部交换（突破贪心局部最优）
    improved = True
    while improved:
        improved = False
        for a in list(S):
            for b in valid:
                if b in S: continue
                if F(S - {a} | {b}) > F(S) + EPS:
                    S = S - {a} | {b}; improved = True
    # 5) 可构建性剪枝（CDB）
    while not buildable(S, budget):
        S.remove(min(S, key=lambda c: marginal(F, S, c) / c.demo_cost))
    support = [c for c in valid if c not in S and c.role == 'support']
    return S, support, frozen

def marginal(F, S, c):
    return F(S | {c}) - F(S)

def is_valid_claim(c):
    return (c.delta > DELTA_MIN and fair_baseline(c.base)
            and reproducible(c.evidence) and c.evidence.demo_time <= T_SLOT)
```

### IP-153 CRA（评分对齐）

```python
def rubric_align(S, M, R_weights, a_min=0.6):
    A = {r: min(1.0, sum(M[i, r] * evidence_strength(i) for i in S))
         for r in range(5)}
    A_score = sum(R_weights[r] * A[r] for r in range(5))
    holes = [r for r in range(5) if A[r] < a_min]
    # Goodhart 护栏：每维至少一条主张的证据-主张比达标
    robust = all(
        any(evidence_strength(i) / claim_strength(i) >= RHO_MIN for i in S)
        for r in range(5) if A[r] > 0
    )
    gap_plan = greedy_fill_holes(holes, S, M, budget) if holes else []
    return A_score, holes, robust, gap_plan
```

def buildable(S, budget):

def prune_by_buildability(S, budget):

### IP-155 DPS（演示决策树）

```python
def optimize_demo_policy(tree, T_demo, alpha, baseline_floor):
    # 动态规划：state=(已演示集合, 剩余时间)
    best = {}
    def dp(node, t_left):
        if t_left <= 0 or node.is_leaf:
            return node.score, []
        key = (node.id, t_left)
        if key in best: return best[key]
        best_score, best_policy = -inf, []
        for child in node.children:              # 含 fallback 分支
            cost = child.time
            if cost > t_left: continue
            s_ok, pol_ok = dp(child.success_branch, t_left - cost)
            s_fb, pol_fb = dp(child.fallback_branch, t_left - cost)
            exp_s = child.p * s_ok + (1 - child.p) * s_fb
            if exp_s > best_score:
                best_score = exp_s
                best_policy = [(child, 'success')] + pol_ok if child.p >= 0.5 \
                              else [(child, 'fallback')] + pol_fb
        best[key] = (best_score, best_policy)
        return best[key]
    return dp(tree.root, T_demo)
```

### IP-156 CSP（竞赛策略组合）

```python
def allocate_strategy(bets, x_safe=0.5, lam_risk=2.0, alpha=0.1):
    # 保底地基锁定
    x = {0: x_safe}
    remaining = 1.0 - x_safe
    # 低相关爆点：按 (g_i - lam_risk*sigma_i) / cost_i 排序
    ranked = sorted(bets[1:], key=lambda b: (b.gain - lam_risk*b.sigma)/b.cost,
                    reverse=True)
    selected = []
    for b in ranked:
        if remaining <= 0: break
        if any(corr(b, s) > RHO_MAX for s in selected): continue
        take = min(remaining, b.max_alloc)
        x[b.id] = take; remaining -= take; selected.append(b)
    # CVaR 下行校验
    assert cvar_alpha(simulate_loss(x), alpha) <= LOSS_CAP
    return x
```

def narrative_coherence(S, G_dep, golden_path):
    on_path = [c for c in S if c.id in golden_path]
    ratio = len(on_path) / max(len(S), 1)
    comp = max_connected_component_ratio(G_dep.subgraph([c.id for c in S]))

    story = f"我们让机器人 X 在 Y 条件下做到 Z，比基线 B 好 Δ，证据是 E。"

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| IPD | 贪心 O(K·n·\|S\|) + 局部交换 O(n²·K)；ILP 为 n 小时精确 | O(n·K) | 有效性过滤完备；曲率界下近似比 (1−e^{−ρ})/ρ |
| CRA | O(\|S\|·5) | O(\|S\|·5) | 对齐度可加、空洞检测完备、Goodhart 护栏 |
| CDB | O(\|S\|) 每轮剪枝 | O(\|S\|) | 剪枝单调、可构建性判定音完备 |
| DPS | O(\|V_tree\|·T_demo/Δτ) DP | O(\|V_tree\|·T_demo) | 期望得分最优（在给定树结构下）、回退叶完备 |
| CSP | O(n log n + 模拟) | O(n) | 保底不可挪用、相关性约束、CVaR 下行有界 |
| NCF | O(\|S\|+\|E_dep\|) | O(\|S\|) | 一致性度量、黄金路径覆盖 |
| J_comp | O(1) 追加 | O(冠军+证据) | 证书审计五项全通过 |

**正确性定理（Competition Value Soundness, CVS）**
假设 **(A56)** IPQ：每个进入冠军集的主张满足四元组有效性（Δ 显著、基线公平、证据可复现、演示不超时）；**(A57)** IPD：覆盖函数子模、协同有界曲率 ρ、冗余与成本非负；**(A58)** CRA：覆盖矩阵 M 诚实反映证据支撑、Goodhart 护栏生效；**(A59)** CDB：集成债诚实上界真实工作量；**(A60)** DPS：节点成功概率诚实、回退叶完备；**(A61)** CSP：保底地基覆盖所有核心维度、爆点相关性可估。则：

1. **主张健全性**：冠军集中不存在「无基线 / 无证据 / 不可复现 / 超演示预算」的伪创新点；每条主张均可被独立复核。
2. **蒸馏近似性**：在 A57 下，贪心+局部交换得到的 S* 满足 F(S*) ≥ ((1−e^{−ρ})/ρ)·F(S_opt) − ε_local。
3. **可构建性**：剪枝后的冠军集满足 B(S*) ≥ 1，即团队剩余时间足以完成集成与演示。
4. **演示下行有界**：存在策略 π* 使 CVaR_α(score) ≥ baseline_floor，且每个节点有回退叶——最坏情况仍可完成受控降级演示。
5. **策略稳健性**：CSP 配置在保底不可挪用的约束下，爆点下行由 CVaR 约束封顶；rubric 鲁棒约束排除「演示作弊」型覆盖。
6. **叙事收敛**：若 κ ≥ κ_min，冠军集可串成单一黄金路径，并收敛为一句话故事。

### IP-152 IPD（创新点蒸馏）

```python
from dataclasses import dataclass, field
import numpy as np

@dataclass
class EvidencePack:
    protocol: str; dataset: str; script: str
    demo_time: float; failure_modes: list

@dataclass
class InnovationClaim:
    id: str; cap: str; base: str; delta: float; evidence: EvidencePack
    novelty: float; evidence_strength: float; demo_cost: float
    dependency_depth: int; rubric_coverage: np.ndarray  # (5,)
    role: str = 'support'  # 'champion' | 'support' | 'speculative'

def is_valid_claim(c: InnovationClaim, delta_min=0.05, t_slot=300.0):
    return (c.delta > delta_min
            and fair_baseline(c.base)
            and reproducible(c.evidence)
            and c.evidence.demo_time <= t_slot)

def distill_innovation_portfolio(G, K=5, budget=None,
                                 lam_syn=0.3, lam_red=0.5,
                                 lam_cost=0.2, lam_dep=0.1):
    valid = [c for c in G if is_valid_claim(c)]
    frozen = [c for c in valid if c.role == 'speculative']
    valid = [c for c in valid if c.role != 'speculative']

    def F(S):
        cover = sum(min(1.0, sum(c.rubric_coverage[r] * c.evidence_strength
                                 for c in S)) for r in range(5))
        syn = sum(synergy(a, b) for i, a in enumerate(S) for b in S[i+1:])
        red = sum(redundancy(a, b) for i, a in enumerate(S) for b in S[i+1:])
        cost = sum(c.demo_cost for c in S)
        dep = max((c.dependency_depth for c in S), default=0)
        return cover + lam_syn*syn - lam_red*red - lam_cost*cost - lam_dep*dep

    # 贪心初始化
    S = []
    while len(S) < K:
        cand = [c for c in valid if c not in S]
        if not cand: break
        best = max(cand, key=lambda c: F(S + [c]) - F(S))
        if F(S + [best]) - F(S) <= 0: break
        S.append(best)

    # 成对局部交换
    improved = True
    while improved:
        improved = False
        for a in list(S):
            for b in valid:
                if b in S: continue
                if F([x for x in S if x is not a] + [b]) > F(S) + 1e-9:
                    S = [x for x in S if x is not a] + [b]
                    improved = True

    # 可构建性剪枝（CDB）
    while not buildable(S, budget):
        victim = min(S, key=lambda c: (F([x for x in S if x is not c]) - F(S))
                     / max(c.demo_cost, 1e-9))
        S.remove(victim)

    support = [c for c in valid if c not in S and c.role == 'support']
    return S, support, frozen
```

def rubric_align(S, M, w, a_min=0.6, rho_min=0.5):

### IP-155 DPS（演示决策树）

```python
def optimize_demo_policy(tree, T_demo, alpha=0.1, baseline_floor=0.0):
    memo = {}

    def dp(node, t_left):
        if t_left <= 0 or node.is_leaf:
            return node.score, []
        key = (node.id, t_left)
        if key in memo: return memo[key]

        best_score, best_policy = -1e9, []
        for child in node.children:            # children 含 fallback 分支
            if child.time > t_left: continue
            s_ok, pol_ok = dp(child.success_branch, t_left - child.time)
            s_fb, pol_fb = dp(child.fallback_branch, t_left - child.time)
            exp_s = child.p * s_ok + (1 - child.p) * s_fb
            if exp_s > best_score:
                best_score = exp_s
                if child.p >= 0.5:
                    best_policy = [(child, 'success')] + pol_ok
                else:
                    best_policy = [(child, 'fallback')] + pol_fb
        memo[key] = (best_score, best_policy)
        return memo[key]

    E_pi, policy = dp(tree.root, T_demo)
    # CVaR 下行校验（蒙特卡洛路径采样）
    assert cvar_alpha(simulate_demo_paths(tree, policy, n=1000), alpha) >= baseline_floor
    return E_pi, policy
```

### IP-156 CSP（竞赛策略组合）

```python
def allocate_strategy(bets, x_safe=0.5, lam_risk=2.0, alpha=0.1,
                      rho_max=0.4, loss_cap=0.2):
    x = {0: x_safe}                       # 保底地基锁定，不可挪用
    remaining = 1.0 - x_safe
    ranked = sorted(bets[1:],
                    key=lambda b: (b.gain - lam_risk*b.sigma) / max(b.cost, 1e-9),
                    reverse=True)
    selected = []
    for b in ranked:
        if remaining <= 0: break
        if any(correlation(b, s) > rho_max for s in selected): continue
        take = min(remaining, b.max_alloc)
        x[b.id] = take
        remaining -= take
        selected.append(b)

    losses = simulate_strategy_loss(x, n=10000)
    assert cvar_alpha(losses, alpha) <= loss_cap
    return x
```

**正确性定理（Competition Value Soundness, CVS）**
假设 **(A56)** IPQ：进入冠军集的主张满足四元组有效性；**(A57)** IPD：覆盖子模、协同有界曲率 ρ、冗余与成本非负；**(A58)** CRA：覆盖矩阵诚实、Goodhart 护栏生效；**(A59)** CDB：集成债诚实上界真实工作量；**(A60)** DPS：节点成功概率诚实、回退叶完备；**(A61)** CSP：保底覆盖核心维度、爆点相关性可估。则：

1. **主张健全性**：冠军集中无「无基线 / 无证据 / 不可复现 / 超演示预算」的伪创新点。
2. **蒸馏近似性**：在 A57 下，F(S*) ≥ ((1−e^{−ρ})/ρ)·F(S_opt) − ε_local。
3. **可构建性**：剪枝后 B(S*) ≥ 1，团队剩余时间足以完成集成与演示。
4. **演示下行有界**：存在 π* 使 CVaR_α(score) ≥ baseline_floor，且每个节点有回退叶。
5. **策略稳健性**：CSP 在保底不可挪用约束下，爆点下行由 CVaR 封顶；rubric 鲁棒约束排除演示作弊。
6. **叙事收敛**：若 κ ≥ κ_min，冠军集可串成单一黄金路径并收敛为一句话故事。

关键：**IPQ 把「创新点」从形容词变成可审计的四元组**；**IPD 把 151 条库存蒸馏为 ≤5 个冠军点**；**CRA 找评分空洞而非继续加深溢出维度**；**CDB 把可构建性提升为一等资源**；**DPS 把竞赛现场变成带保底分支的序贯决策**；**CSP 用组合思想配置「保底 + 爆点」**；**NCF 保证这是一个系统而非功能袋**。七者共同把「技术深度」翻译成「竞赛价值」。

## 6. 本轮最大风险

**一句话**：本轮最大的风险是「蒸馏的诚实」——一旦严格按四元组审计，59 轮深挖可能被证明大多是**无独立证据、无公平基线、无演示路径的纸面创新**，冠军集被迫缩到很小甚至为「保底可完成」而牺牲全部爆点；反之若为对齐评分而放宽证据-主张比，则会造出一个在演示中很炫、在评委追问下一轮即穿的「Goodhart 幻象」——**因此必须以「无证据不进冠军集、无回退不进演示树、无保底不投爆点」三条硬规则守住竞赛价值的真实性。**
