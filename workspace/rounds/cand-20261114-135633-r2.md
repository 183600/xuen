# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「数据规模」×「推理延迟」）

> R69 把不确定性一分为二，并给了系统一张嘴：问。它用流匹配生成多模态动作，用 VoI 决定值不值得问，用「k 个正交证据源一致」防止被单次回答骗。但整套机器对一个量始终沉默：**模态后验到底是在多细的尺度上被估计出来的？** 流匹配吐出的 K 个模态看起来可分，可能只是有限数据上的幻觉；`mode_head` 说「有歧义」，可能只是它没见过足够多的同类样本；`K=4` 的消歧路径看起来算得完，可能只是延迟预算还没被最坏情况击穿。
>
> 本轮两个灵感正好从「训练侧」和「部署侧」同时击中这个沉默变量：
> - **数据规模**告诉我们：模态后验不是真值，而是有限样本估计；真正决定分辨能力的是**有效样本量** `N_eff` 与**偏差地板** `b`，不是数据集里文件的个数。重复、近重复、共模语言变体、机器人农场可以让 `N` 很大而 `N_eff` 很小；平均校准变好，尾组校准却可能停滞甚至变差。
> - **推理延迟**告诉我们：部署时的计算不是免费的；`K` 个样本、`N_step` 步 ODE、检索深度、蒸馏档位共同决定了一个硬截止时刻之前能算出多细的后验。延迟抖动本身是攻击面：攻击者可以用「难例洪水」逼系统在截止前退回保守，或反过来逼它超时。
>
> 核心命题：**把「分辨率」提升为一等公民。数据规模和推理延迟不是两个独立旋钮，而是同一个量的两侧：有效样本量决定分辨率的数据上限，截止时刻决定分辨率的计算上限；系统只能在两者共同允许的尺度上声明「两个模态可分」。** 统一三种货币——交互（VoI）、计算（VoC）、数据（VoD）——它们买的是同一样东西：分辨率。**只有证书支持的分辨率才允许驱动交互与执行；否则退回 R68 的纯保守，而不是用一张过期的证书去执行一个其实分辨不出的动作。** 命名 **LADDER-RAS**（Latency-Aware Data-Determined Epistemic Resolution for Risk-Adaptive Systems：延迟感知、数据决定的分辨率阶梯闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我此刻的资料和算力，究竟支持我分辨到什么尺度？我有没有把『数据很多』误当成『看得清』**」。

## 0. 直觉与动机

**命题 P1（模态后验是估计量，不是真值）**
直觉：R69 的 `U_ale/U_epi` 把流策略采样出的 K 个模态当成世界的真实多峰结构。但流模型是从有限数据里学出来的：数据少时它会把一个真模态拆成两个幻影，或把两个真模态糊成一个；数据重复时它会对同一个幻影异常自信。**「可分」不是一个拓扑事实，而是一个统计结论**——它必须带样本量、带有效样本量、带置信半径。R69 的 A95（`Δ_min ≥ 3σ_in`）是一个理想化条件，R70 要问的是：我凭什么相信我的 `Δ_min` 和 `σ_in` 估计到了这个精度？

**命题 P2（推理延迟是分辨率的快门速度）**
直觉：摄影里，快门越快，进光越少，越难分辨暗处细节。推理也一样：截止时刻越紧，能采的样本越少、能走的 ODE 步越少、能检索的记忆越浅，模态后验的估计噪声越大。R69 把 `K=4` 当成一个固定开关，只在「有歧义」时打开；但「有歧义」本身是由一个可能没校准的 `mode_head` 判断的，而 `K=4` 是否算得完又取决于当时的负载。**延迟不是实现细节，它直接改变后验的分辨率，从而改变安全结论。**

**命题 P3（数据规模可以在推理时购买：检索是「延迟换有效样本」）**
直觉：数据规模不只有「离线训练集变大」一种形态。一个非参数记忆库可以在推理时按状态检索相似经验，等价于临时增加有效样本量 `N_eff`；但检索深度越深、索引越大，延迟越高。于是数据规模与推理延迟在同一个控制面上相遇：**你可以用延迟买分辨率，也可以用分辨率换延迟**。这比「训练一个大模型然后部署」更诚实，因为每次决策都能知道自己实际用了多少有效证据。但检索也会引入新的偏差：检索到的都是高度相关的近重复样本时，`N_ret` 很大而 `N_ret,eff` 很小，后验会围绕一个错误模态异常尖锐。

**命题 P4（三种货币，同一目标）**
直觉：R69 只有一种预算——交互预算。它用 VoI 决定「问不问」。但系统还可以：多算几个样本（VoC，花延迟）、多检索几条经验（VoC，花延迟）、把这次交互的答案留下来训练（VoD，花存储/标注/审计成本，收益在未来）。三者是**替代品也是互补品**：数据多了，未来需要问的和算的都变少；算力多了，当下不必问；问了一次，答案本身又变成数据。把它们放在同一个分辨率目标下做边际配置，才不会出现「一边嫌延迟高，一边把算力花在不会改变决策的样本上」。

**命题 P5（交互数据是投资，也是选择偏误的来源）**
直觉：R69 把交互当纯消费：花一次社交成本，换一次信息增益。但每次交互的答案都是带标签的数据，可以用来提高未来的分辨率——所以交互也是投资。危险在于：**你只会在高歧义处问，于是收集到的数据在高歧义处过采样、在低歧义处欠采样。** 用这批数据训练，模型会在「以前不问」的区域悄悄失准，然后因为「数据变多了」而更自信地不问。这就是主动学习的确认偏误：**越问越准，越准越不问，越不问越不知道自己哪里错。** 必须用选择倾向加权、随机审计切片和探索地板把它按住。

**命题 P6（严格包含 R69 与 R68）**
直觉：当数据规模、计算预算、组别、截止时刻都固定，且不做任何数据获取、证书新鲜时，LADDER 应当逐指令退化为 FLUID-RAS；当 VoI 无利可图或分辨率不足时，再退化为 R68 的纯保守。**新层不能是并列替代，只能是旧层在边界上的严格泛化**：分辨率门只允许「关掉」R69 的消歧，不允许「放宽」R68 的安全下界。

**命题 P7（新的攻击面：把算力和数据规模武器化）**
直觉：一旦系统依赖「更多数据/更多计算 = 更可信」，攻击者就有了两个新杠杆：**难例洪水**（持续输入位于模态边界的样本，逼系统把延迟预算耗在无望的消歧上，最终退回保守或超时）和**规模投毒**（用大量相关样本/机器人农场抬高 `N_eff`，让一个错误模态看起来「证据充分」）。R69 的 `ℰ_poison` 只覆盖「人撒谎」；R70 必须覆盖「数据和算力本身被武器化」。**最危险的攻击不是让系统不知道，而是让它用大量的错误证据证明自己知道。**

## 1. 形式化定义（增量：定义 310–326）

**定义 310（LADDER-RAS 总览）** LADDER-RAS = (MSL, NEA, ADS, VCC, RCG, DVL, DG, SBG, RPD, LAG, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；数据获取与模型更新只走异步影子路径）；
(ii) **分辨率诚实**：任何「两个模态可分」的声明，必须附带在动作执行时刻仍新鲜的分辨率证书；证书不支持 ⇒ 不得声明可分，不得以该声明驱动交互或执行；
(iii) **任意时刻单调**：计算只允许精化后验，证书风险上界取运行最小值；到截止时刻冻结，冻结动作不劣于 R68 的保守动作；
(iv) **有效样本量与来源纪律**：进入训练/标定/检索的样本必须记录来源、重复度、选择倾向；缩放律与证书使用 `N_eff` 而非原始 `N`。

**定义 311（有效样本量 NEA）** 对组 `g`，样本 `i` 带重复/簇权重 `w_i > 0`，定义 `N_eff,g = (Σ_{i∈g} w_i)² / Σ_{i∈g} w_i²`。若数据按簇大小 `m`、组内相关 `ρ̄` 聚集，则近似 `N_eff ≈ N / (1 + (m−1)ρ̄)`。检索记忆同理：`N_ret,eff(s) = (Σ_j v_j)² / Σ_j v_j²`，其中 `v_j` 为第 `j` 条检索结果的去重/相关性权重。**原始 `N` 可被重复、近重复、共模变体和投毒农场无限抬高，`N_eff` 不能。**

**定义 312（分辨率半径）** 状态 `s` 下真实模态最小间距 `Δ_min`、模态内半径 `σ_in`；有效数据 `N_eff`；计算档位 `C = (K, N_step, q, r, d)`（采样数、ODE 步、量化、检索深度、蒸馏档）；组校准误差 `ECE_g`；若使用交互，再计入回答通道的分辨率 `ρ_ans`。定义
`ρ_D(N_eff) = a_D·N_eff^{−α_D} + b_D`（`α_D∈(0,1/2]`，`b_D ≥ 0` 为偏差地板）；
`ρ_C(C) = z_{1−δ}·σ_traj/√K + δ_ODE(N_step) + δ_quant(q)`；
`ρ_cal = rad(ECE_g)`（校准误差到概率半径的单调映射）；
`ρ(s) = sqrt(ρ_D² + ρ_C² + ρ_cal² + 1[用交互]·ρ_ans²)`；
`κ̂(s) = Δ_min / ρ(s)`。
`κ̂` 是**有效分辨率**：它把这轮的两个灵感写进同一个标量。**声明模态可分 ⇔ `κ̂ ≥ κ_req`**。

**定义 313（风险需求的分辨率阈值）** 设选错模态的最坏损失为 `L_gap`，允许的歧义风险为 `ε_amb`。在等方差高斯近似下，错模态概率 `p_err(κ) ≈ Φ(−κ/2)`。定义 `κ_req(ε_amb) = p_err^{−1}(ε_amb / L_gap) = 2·Φ^{−1}(1 − ε_amb/L_gap)`，并与 A95 的几何下界取最大：`κ_req = max(3, κ_req(ε_amb))`。分辨率需求半径 `ρ_req = Δ_min / κ_req`，分辨率缺口 `G = max(0, ρ_req − ρ)`。**只有 `G = 0` 才允许 R69 的消歧路径启动。**

**定义 314（分辨率缩放律 MSL）** 按组 `g` 拟合分层缩放律：
`ECE_g(N) = a_g·N_eff,g^{−α_g} + b_g`；
`h_g(N) = c_g·N_eff,g^{−β_g} + h_∞,g`（幻影模态率）；
`m_g(N) = d_g·N_eff,g^{−γ_g} + m_∞,g`（模态坍缩率）。
低样本组用部分池化估计 `(α_g, b_g)`，并给出置信带。`b_g` 是**不可约偏差地板**：数据规模买不过它。MSL 输出「达到 `κ_req` 所需的最小 `N_eff`」与「该组是否 scale-limited」。若 `b_g` 或预测所需样本超过上限，该组**不得被授予消歧权限**，无论原始 `N` 多大。

**定义 315（数据价值账本 DVL / VoD）** 对候选经验 `e`（状态、候选问句/示范/审计样本），
`VoD(e) = E[Δρ_D(未来)] + β_int·E[Δ未来交互成本] − c_label − c_store − c_audit − c_social`。
仅当 `VoD(e) > 0` 且不在实时环路内时获取；优先级给：`κ̂` 接近 `κ_req` 的边界样本、`N_eff` 低于地板的稀有组、与现有模态矛盾的负证据。DVL 记录每条数据的来源、重复度、选择倾向 `p_sel`、影响上界。

**定义 316（计算价值 VCC 与任意时刻截止调度 ADS）** 计算菜单 `𝒞 = {C_0, C_1, ..., C_m}` 为嵌套档位（`K`、`N_step`、检索深度、蒸馏档），每档有实测延迟分布 `L(C)`（含 P99）与分辨率证书。运行到时刻 `t` 时，第 `t` 档给出经认证的风险上界 `U_t`。定义
`VoC(C_t → C_{t+1}) = U_t − U_{t+1}`。
仅当 `VoC > μ_L·ΔL + μ_E·ΔE` 且 `t + L(C_{t+1}) ≤ D − margin` 时升档；否则冻结。`C_0` 固定为「K=1 + R68 保守动作」，保证任意时刻都有可执行的安全解。`μ_L, μ_E` 为延迟与能耗的影子价格。

**定义 317（任意时刻冻结与证书新鲜度）** 到硬截止 `D`，冻结在最后一个**已认证**的动作；证书字段含 `freeze_ts`、`model_ver`、`data_ver`。证书**新鲜** ⇔ 自签发后模型/数据版本未变且年龄 `≤ τ_fresh`。冻结失败、超时或证书过期 ⇒ `λ = λ_floor(U_ale + U_epi)`，并禁用交互（R68 纯保守）。这条把「延迟抖动」从安全问题降级为性能问题。

**定义 318（分辨率证书门 RCG）** 门条件：
`G = 0 ∧ κ̂_g ≥ κ_req ∧ ECE_g ≤ τ_ece ∧ cert_fresh ∧ N_eff,g ≥ N_min`。
任一不满足 ⇒ 关闭 R69 的 VoI 与模态选择，退回 R68 纯保守，并把失败原因写入审计。R69 的 MCG 是本门在「只检查校准、不检查分辨率与新鲜度」时的特例。**RCG 的核心不是「更保守」，而是「不许虚报分辨率」。**

**定义 319（数据闸门 DG）** 任何「数据 → 模型/记忆」更新在换装前必须通过：
(a) 审计切片上的**最差组 ECE 不劣化**；
(b) `N_eff` 核算（重复、近重复、簇相关）；
(c) 来源影响上限 `γ`（单源/单簇对参数或检索分布的影响不超过 `γ`）；
(d) 重复/投毒/后门/证书重放筛查；
(e) 决策边界覆盖（`κ̂ ≈ κ_req` 区域的样本比例不低于阈值）；
(f) 影子模型回滚点。
全部通过 ⇒ 按 R68 定理 15 的换装不变式原子换装；任一失败 ⇒ 保留旧模型与旧证书。**数据规模越大，闸门应越严，而不是越松。**

**定义 320（选择偏误守卫 SBG 与探索地板）** 交互样本由 VoI 选择，`p_sel(s) ≠ uniform`。用逆倾向加权 `w = 1/p_sel(s)` 估计校准，并维持一个选择概率 `≥ ε_exp` 的**随机审计切片**；证书只在审计切片上定案，不在交互切片上定案。若探索比例 `< ε_exp`，RCG 把 `ρ_cal` 放大到 `ρ_cal^+`（对支持域不确定），**绝不允许用非代表数据把 `ρ_cal` 缩小**。这是对 P5 确认偏误的硬约束。

**定义 321（保分辨率蒸馏 RPD）** 学生策略 `f_S` 延迟 `L_S < L_T`。若在运行域上 `W2(p_S(·|o), p_T(·|o)) ≤ ε_cov`，则学生可认证的模态最小间距至多 `Δ_min,T − 2ε_cov`，可认证分辨率至多
`κ̂_S ≤ (Δ_min,T − 2ε_cov)_+ / (ρ_T + 2ε_cov)`。
要求 `κ̂_S ≥ κ_req`；否则学生只能「提议」模态，由教师或 R68 保守路径定案。**蒸馏只能花掉分辨率换延迟，不能创造分辨率。**

**定义 322（延迟/数据攻击面 ℰ_scale）** 难例洪水（deadline DoS）、边界探测（逼系统升到最贵档）、机器人农场/重复样本（抬高 `N_eff`）、相关投毒簇（制造伪模态）、来源伪造、证书重放/过期、蒸馏后门。并入 AIC：
`ℰ_LADDER = ℰ_FLUID × ℰ_scale`。
LAG（延迟攻击守卫）对每源设置计算配额、难例速率限制、保守动作缓存与降级优先级；攻击的后果是**失去 resolution bonus**，不是突破安全下界。

**定义 323（三货币预算与影子价格）** `B = (B_int, B_comp, B_data)`，影子价格 `(μ_int, μ_comp, μ_data)`。每单位预算配置到「边际认证风险下降 / 总成本」最大的通道，直到边际收益低于影子价格。三者可替代：算力（私有、安全、即时）> 交互（社交成本、即时、可转数据）> 数据（延迟、投资、需闸门）。交互的总价值含期权价值：
`VoI_total(g) = VoI_now(g) + β·VoD(answer(g))`，
但受社交成本、证据纪律与探索地板约束。

**定义 324（证书 J_LADDER）** `J_LADDER = (J_FLUID, κ̂, ρ_D, ρ_C, ρ_cal, ρ_ans, N_eff_worst, ECE_worst, exploration_ratio, deadline_slack, freeze_ts, model_ver, data_ver, provenance_root, voc_ratio, vod_ratio, ladder_ver)`。Valid ⇔ `Valid(J_FLUID)` ∧ 对每个被声明的可分模态 `κ̂ ≥ κ_req` ∧ 最差组 `ECE ≤ τ_ece` ∧ 证书新鲜 ∧ 截止满足 ∧ 来源影响未越界 ∧ 探索比例 ≥ 地板。

**定义 325（严格包含链）** 当 `N=N_0, C=C_0` 固定、无数据获取、单组、校准良好、截止无限、证书新鲜时，LADDER 逐指令退化为 FLUID-RAS；当 `VoI_total ≤ c`、`ECE > τ_ece`、`G > 0` 或证书失效时，FLUID 逐指令退化为 R68 纯保守。于是风险链为
`Risk(LADDER) ≤ Risk(FLUID) ≤ Risk(R68)`，
等号在相应边界上成立。**安全侧不让步，效率侧只在证书允许处获得 resolution bonus。**

**定义 326（数据飞轮与稳定性）** 数据集映射 `T: D → D'`，交互率 `r(D)`。固定点 `D*` 稳定需三个条件：(a) 审计切片校准不劣化；(b) 探索比例 `≥ ε_exp`；(c) 数据漂移有界。若审计 ECE 变差或探索跌破地板，DG 冻结获取并回滚到最后一个已认证数据集。**确认偏误是数据飞轮的主要失效模式：`r(D)` 随分辨率上升而下降，但选择让被问过的区域过表示；没有探索，未问区域会在「数据变多」的表象下悄悄退化。**

## 3. 推导

**引理 19（低分辨率下不可声明可分）** 设两个模态的分布相距 `Δ`、单模态估计半径为 `ρ`。若 `κ̂ = Δ/ρ < κ_req`，则在等方差高斯近似下，任何基于该后验的判决器的错模态概率 `≥ Φ(−κ̂/2)`；特别地，当 `Δ ≤ 2ρ` 时，两分布的总变差 `≤ 1/2`，minimax 错误率 `≥ 1/4`（Le Cam 两点法）。系：**交互可以改变「选哪个模态」的信念，但不能凭空提高当前证据的分辨率；实时环路里能做的只有：用已有分辨率、花计算提分辨率、或诚实退回保守。** 把答案留下训练（VoD）是异步的，不能拿来为当下的错误声明背书。

**引理 20（任意时刻单调性与截止安全）** 设计算档位嵌套 `C_0 ⊂ C_1 ⊂ ...`，且每档只提供经认证的风险上界 `U_t`，调度器维护单调包络 `Ū_t = min_{t'≤t} U_{t'}`。则对任意截止 `D`，冻结动作的认证风险 `Ū_D ≤ U_0`；而 `U_0` 就是 R68 保守动作的风险。故难例洪水/负载抖动只能让系统失去 resolution bonus，**不能抬高安全上界**。系：延迟攻击是可用性攻击，不是安全性攻击；真正的安全风险来自**证书过期仍被使用**，这由定义 317 的新鲜度门挡住。

**引理 21（缩放律的双侧性与最差组）** 平均校准按 `a·N_eff^{−α}` 改善，但组 `g` 的校准有地板 `b_g`，且 `N_eff,g` 可能远慢于 `N` 增长（重复、簇相关、稀有组）。若组份额 `π_g → 0`，则均匀扩数据可使平均 ECE 下降而最差组 ECE 停滞甚至上升。系：**「数据规模」必须按组、按 `N_eff`、按偏差地板读，不能读成「数据集大小」；分辨率缩放不是数据规模缩放。** 这正是 MSL 与 RCG 必须分组的理由。

**引理 22（蒸馏不能创造分辨率）** 若学生与教师的模态分布在运行域上 `W2 ≤ ε_cov`，则学生可认证的最小模态间距至多 `Δ_min,T − 2ε_cov`，在模态内半径不改善的保守假设下可认证分辨率
`κ̂_S ≤ (Δ_min,T − 2ε_cov)_+ / (ρ_T + 2ε_cov) < κ̂_T`。
故低延迟学生只能执行教师已能分辨的任务；需要更细分辨率的决策必须回到教师或交互。系：**延迟-分辨率 Pareto 前沿是硬约束，不是工程调参**；RPD 是「在前沿上选点」，不是「把前沿推出去」。

**引理 23（确认偏误的审计不等式）** 设交互选择分布 `p_sel`，审计分布 `p_aud`（`p_aud ≥ ε_exp` 于支持域）。若只在交互切片上估计校准，则其与审计校准之差满足
`|ECE_sel − ECE_aud| ≤ (1/ε_exp − 1)·sup_s |p_sel(s)/p_aud(s) − 1| + ε_σ`。
故当 `ε_exp → 0` 时偏差上界发散：**没有探索地板的主动学习，其自评校准可以任意乐观。** 系：SBG 的随机审计切片不是可选项，是证书有效性的前提。

**定理 18（LADDER 严格包含 FLUID 与 R68）** 在定义 325 的边界下，LADDER 的任意状态期望风险 `≤` FLUID `≤` R68；且当无数据获取、`N,C` 固定、单组、校准良好、截止无限、证书新鲜时，LADDER 与 FLUID 逐指令相同；当 `VoI_total ≤ c`、`ECE > τ`、`G > 0` 或证书失效时，FLUID 与 R68 逐指令相同。**R70 只增加「拒绝虚报」的能力，不增加任何放宽安全的通道。**

**定理 19（数据飞轮不引入认证安全回归）** 在 DG 通过、原子换装、探索地板 `ε_exp > 0`、来源影响上限 `γ` 与审计切片认证下，以概率 `≥ 1−δ`，换装后审计分布上的最差组 ECE 不劣于换装前 `+ ε`；否则回滚。实时环路无学习写操作，故 R68 的提交/换装不变式与定理 17 的交互无突变性保持。系：**数据飞轮可以提高效率、降低未来交互率，但不能成为绕过安全证书的后门。**

**引理 24（三货币的边际等价）** 在分辨率目标 `κ_req` 与预算约束下，最优配置满足三种货币对认证风险降低的边际收益相等（KKT 条件）。由于算力是私有、即时、无社交成本的，交互含社交成本与数据期权价值，数据含延迟与闸门成本，故典型最优顺序是「先算力、再交互、异步数据」；但当 `VoD` 足够高（边界/稀有组）时，交互可以因期权价值而提前触发。**这把 R69 的单一 VoI 升级为一个可解释的预算分配问题，而不是给每个通道各装一个阈值。**

## 6. 本轮最大风险

**一句话**：LADDER 把「分辨率」当成一个可以由缩放律预测、由证书担保的量，但缩放律是在非平稳、且被系统自身交互选择偏误污染的数据上拟合的；一旦缩放律过期或错估，系统就会拿着「数据规模很大」的自信，去执行一个当前延迟与数据根本分辨不出的动作——**数据越多，越可能自信地错，而且越不去探索**。

**次级风险与缓解**：
1. **缩放律外推失效**（分布漂移、组别新出现）→ 置信带 + RCG 的 `G` 检查 + 证书新鲜度；不确定即退回 R68。
2. **确认偏误/数据飞轮失控** → SBG 随机审计切片 + `ε_exp` 地板 + 逆倾向加权；审计 ECE 变差即冻结获取并回滚。
3. **规模投毒与来源伪造** → DG 的来源影响上限 `γ` + 重复/簇毒筛查 + 证书来源根；绝不用原始 `N` 计分辨率。
4. **延迟抖动/难例洪水** → ADS 的嵌套档位 + 保守动作缓存 + LAG 的每源配额；攻击只损失 resolution bonus。
5. **蒸馏后门/学生过度自信** → RPD 的 `W2` 覆盖约束 + 学生只许提议；关键决策由教师/保守路径定案。
6. **证书本身成为攻击面**（重放、过期、版本错配）→ `freeze_ts/model_ver/data_ver/provenance_root` 全字段签名 + 换装不变式。

# 第 70 轮产物 · 创新点清单 v1：LADDER-RAS（Latency-Aware Data-Determined Epistemic Resolution：数据规模 × 推理延迟共同决定的分辨率阶梯闭环；MSL×NEA×ADS×VCC×RCG×DVL×DG×SBG×RPD×LAG×RAS-WM†）

>

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** LADDER-RAS 由 MSL/NEA/ADS/VCC/RCG/DVL/DG/SBG/RPD/LAG 组成。四不变式：实时零学习写操作；分辨率诚实（可分声明必须附带执行时刻新鲜的证书）；任意时刻单调（计算只精化、截止冻结、冻结不劣于 R68）；有效样本量与来源纪律（`N_eff`、`p_sel`、`provenance`）。

**定义 311–313（分辨率半径与阈值）** `N_eff` 去重；`ρ=sqrt(ρ_D²+ρ_C²+ρ_cal²+ρ_ans²)`；`κ̂=Δ_min/ρ`；`κ_req` 由允许歧义风险 `ε_amb` 反解（等方差高斯近似 `p_err≈Φ(−κ/2)`），并与 A95 的 3 取最大；`G=max(0, Δ_min/κ_req−ρ)`。**`G=0` 是 R69 消歧路径的启动条件。**

**定义 314（MSL 缩放律）** 分组 `ECE_g(N)=a_g N_eff,g^{−α_g}+b_g`，幻影率 `h_g`、坍缩率 `m_g` 同类；低样本组部分池化；`b_g` 为不可约偏差地板。输出「达到 `κ_req` 所需最小 `N_eff`」与 scale-limited 标记。

**定义 315（DVL/VoD）** `VoD(e)=E[Δρ_D]+β·E[Δ未来交互成本]−c_label−c_store−c_audit−c_social`；优先边界样本、稀有组、负证据；异步获取。

**定义 316（ADS/VCC）** 计算菜单嵌套 `C_0⊂...`；`C_0` 恒为 R68 保守动作；`VoC=U_t−U_{t+1}`；仅当 `VoC>μ_LΔL+μ_EΔE` 且能在截止前完成时升档；到 `D` 冻结。

**定义 317（冻结与新鲜度）** 截止冻结最后一个已认证动作；证书含 `freeze_ts/model_ver/data_ver`；过期/超时/冻结失败 ⇒ `λ=λ_floor(U_ale+U_epi)` 且禁用交互。延迟抖动由此降级为性能问题。

**定义 318（RCG）** `G=0 ∧ κ̂_g≥κ_req ∧ ECE_g≤τ_ece ∧ cert_fresh ∧ N_eff,g≥N_min`；否则关闭 R69 VoI/模态选择，退回 R68。R69 的 MCG 是「只查校准」的特例。

**定义 319（DG）** 换装前：审计切片最差组 ECE 不劣化、`N_eff` 核算、来源影响上限 `γ`、投毒/后门/重放筛查、边界覆盖、回滚点；全过才按 R68 换装不变式原子换装。

**定义 320（SBG）** `p_sel≠uniform`；用 `1/p_sel` 逆倾向加权；维持 `p≥ε_exp` 的随机审计切片；证书只在审计切片定案；探索不足时把 `ρ_cal` 放大而非缩小。

**定义 321（RPD）** `W2(p_S,p_T)≤ε_cov ⇒ κ̂_S ≤ (Δ_min,T−2ε_cov)_+/(ρ_T+2ε_cov)`；`κ̂_S<κ_req` 时学生只许提议。蒸馏只花分辨率换延迟。

**定义 322（ℰ_scale + LAG）** 难例洪水、边界探测、机器人农场、相关投毒簇、来源伪造、证书重放、蒸馏后门；LAG 用每源配额/难例限速/保守缓存，把攻击后果限制为失去 resolution bonus。

**定义 323（三货币）** `B=(B_int,B_comp,B_data)`，影子价格 `(μ_int,μ_comp,μ_data)`；边际认证风险下降/总成本最大者优先；`VoI_total=VoI_now+β·VoD(answer)`。典型顺序：算力 → 交互 → 异步数据（边界/稀有组可提前交互）。

**定义 324–326（证书/包含/飞轮）** `J_LADDER` 并入 `κ̂,ρ,N_eff,ECE,exploration,freeze/model/data/provenance`；`Risk(LADDER)≤Risk(FLUID)≤Risk(R68)`，相应边界逐指令相等；数据飞轮稳定需审计不劣化 + 探索地板 + 漂移有界，否则 DG 冻结并回滚。

## 3. 关键算法伪代码

```python
# IP-264/265 MSL + NEA：有效样本量与分组缩放律（离线）
def fit_msl(dataset, groups):
    laws = {}
    for g in groups:
        N_eff = (dataset[g].w.sum()**2) / (dataset[g].w**2).sum()   # 定义 311
        ece   = calibration_curve(dataset[g], weights=ipw(dataset[g]))
        a, alpha, b = hierarchical_fit(N_eff, ece)                   # ECE = a*N_eff^-alpha + b
        laws[g] = (a, alpha, b, fit_hallucination(N_eff, dataset[g]))
    return laws

# IP-266/267 ADS + VCC：任意时刻调度，只接受认证改进
def anytime_plan(s, deadline, menu, cert, mu):
    a_safe, U = conservative_action(s), None
    U = certified_risk(a_safe); best = (a_safe, U, now())
    for C in menu.ascending():
        if now() + menu.latency_p99(C) > deadline - MARGIN: break
        dL = menu.latency_p99(C) - menu.latency_p99(best[3])
        if U - predicted_ucb(C) <= mu.L * dL + mu.E * energy(C): break
        U_next = certify(policy.sample(s, C))
        if U_next < U: U, best = U_next, (policy.argmin(s, C), U_next, now(), C)
    return freeze(best)                                               # 定义 317

# IP-268 RCG：分辨率证书门（不许虚报）
def resolution_gate(s, g, cert):
    kappa, rho = cert.estimate(s)                                    # 定义 312
    G = max(0.0, cert.delta_min(s) / cert.k_req - rho)
    return (G == 0 and kappa >= cert.k_req and cert.ece(g) <= TAU_ECE
            and cert.fresh(now()) and cert.n_eff(g) >= N_MIN)

# IP-269/270/271 DVL + DG + SBG：异步数据经济
def data_economy(experiences, dataset, laws):
    for e in experiences:
        if check_vod(e, laws) > 0: stage(e)                           # 来源/倾向/重复度
    if exploration_ratio(stage) < EPS_EXP: return dataset             # 非代表数据不许换装
    if not audit_slice_noninferior(stage, dataset): return dataset
    if not provenance_caps(stage, gamma=GAMMA): return dataset
    if not poison_screen(stage): return dataset
    return atomic_swap(dataset, stage)                                # R68 换装不变式

# IP-272 RPD：保分辨率蒸馏（只花分辨率，不创造分辨率）
def distill(teacher, student, eps_cov):
    if w2_coverage(student, teacher) > eps_cov: return None
    kappa_s = max(0.0, delta_min(teacher) - 2*eps_cov) / (rho(teacher) + 2*eps_cov)
    return student if kappa_s >= K_REQ else None                      # 否则只许提议

# IP-274 主闭环
def LADDER_round(M, obs, deadline):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    cert = M.rcg.certificate(obs, M.nea, M.msl, M.load)
    if not M.rcg.pass_(cert):
        return M.r68_conservative(obs, reason="resolution")            # 定义 318
    K, N_step, r = M.ads.plan(deadline, cert)                          # 定义 316
    samples = M.fmp.sample(o, K=K, N_step=N_step, retrieve=r)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, obs, o_calibrated)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    g = (M.mint.choose_interaction(modes, o, M.budget, voc=M.vcc)
         if (U_epi > TAU_EPI and not slow and M.rcg.pass_(cert)) else None)
    if g is not None:
        answer = M.cia.execute(g); U_epi = M.cia.update_belief(modes, answer)
        M.dvl.record(o, g, answer, p_sel=M.mint.propensity(g))         # 异步
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + (U_epi if g is None else 0.0)))
    if slow: lam = max(lam, 0.8)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_i.submit_async(g, U_epi, a_hat, cert)
    return k, lam, mode, (U_ale, U_epi), cert
```

## 4. 推导

**引理 19（低分辨率下不可声明可分）** 两模态相距 `Δ`、估计半径 `ρ`，`κ̂=Δ/ρ<κ_req` 时错模态概率 `≥Φ(−κ̂/2)`；`Δ≤2ρ` 时总变差 `≤1/2`，minimax 错误率 `≥1/4`（Le Cam）。系：交互改变「选哪个」的信念，但不能凭空提高当下证据的分辨率；实时环路只能「用已有分辨率、花计算提分辨率、诚实保守」三选一，答案留作训练是异步的。

**引理 20（任意时刻单调与截止安全）** 嵌套档位 + 单调包络 `Ū_t=min_{t'≤t}U_{t'}` ⇒ 冻结风险 `Ū_D≤U_0`（R68 保守动作风险）。难例洪水/负载抖动只能损失 resolution bonus，不能抬高安全上界。系：延迟攻击是可用性攻击；真正安全风险是「证书过期仍被使用」，由新鲜度门挡住。

**引理 21（缩放律双侧性与最差组）** 平均 `ECE≈a·N_eff^{−α}` 改善，但组 `g` 有地板 `b_g`，且 `N_eff,g` 可能远慢于 `N`；组份额 `π_g→0` 时均匀扩数据可使平均 ECE 下降而最差组停滞/上升。系：**数据规模 ≠ 分辨率规模**；必须按组、按 `N_eff`、按地板读。

**引理 22（蒸馏不能创造分辨率）** `W2≤ε_cov ⇒ Δ_min,S≤Δ_min,T−2ε_cov`，保守下 `κ̂_S≤(Δ_min,T−2ε_cov)_+/(ρ_T+2ε_cov)<κ̂_T`。低延迟学生只能执行教师已能分辨的任务；延迟-分辨率 Pareto 是硬约束。

**引理 23（确认偏误的审计不等式）** 交互选择 `p_sel`、审计分布 `p_aud≥ε_exp`，则 `|ECE_sel−ECE_aud| ≤ (1/ε_exp−1)·sup|p_sel/p_aud−1|+ε_σ`。`ε_exp→0` 时上界发散：**没有探索地板的主动学习，自评校准可任意乐观。**

**定理 18（严格包含 FLUID 与 R68）** 定义 325 边界下 `Risk(LADDER)≤Risk(FLUID)≤Risk(R68)`；无数据获取、固定 `N,C`、单组、校准良好、无限截止、证书新鲜时 LADDER=FLUID；`VoI≤c`、`ECE>τ`、`G>0` 或证书失效时 FLUID=R68。R70 只增加「拒绝虚报」，不增加放宽安全的通道。

**定理 19（数据飞轮不引入认证安全回归）** DG 通过 + 原子换装 + `ε_exp>0` + 来源上限 `γ` + 审计切片认证 ⇒ 以概率 `≥1−δ` 换装后最差组 ECE 不劣化 `+ε`，否则回滚；实时零学习写保持 R68 提交/换装不变式与交互无突变性。数据飞轮可提效，但不能成为绕过证书的后门。

**引理 24（三货币边际等价）** 分辨率目标 + 预算约束下，最优配置满足三通道边际认证风险降低相等（KKT）。算力私有即时、交互含社交成本与数据期权、数据含延迟与闸门成本，典型顺序「先算力、再交互、异步数据」；但 `VoD` 高时交互可因期权价值提前触发。

## 7. 本轮最大风险

**一句话**：LADDER 把「分辨率」当成可由缩放律预测、由证书担保的量，但缩放律是在非平稳、且被系统自身交互选择偏误污染的数据上拟合的；一旦缩放律过期或错估，系统就会拿着「数据规模很大」的自信，去执行一个当前延迟与数据根本分辨不出的动作——**数据越多，越可能自信地错，而且越不去探索**。

**次级风险与缓解**：缩放律外推失效（置信带 + `G` 检查 + 新鲜度，不确定即退回 R68）；确认偏误/飞轮失控（SBG 审计切片 + `ε_exp` 地板 + 逆倾向加权，审计变差即冻结回滚）；规模投毒/来源伪造（DG 来源上限 `γ` + 毒簇筛查 + 来源根，禁用原始 `N`）；延迟抖动/难例洪水（ADS 嵌套档 + 保守缓存 + LAG 配额，攻击只损 bonus）；蒸馏后门/学生过度自信（RPD 的 `W2` 覆盖 + 学生只许提议）；证书重放/版本错配（`freeze_ts/model_ver/data_ver/provenance_root` 全字段签名 + 换装不变式）。
