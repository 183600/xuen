# 第 63 轮（承接第 62 轮「ROSE 鲁棒在线场景进化闭环」IP-183~192；灵感循环 II 第 2 轮；本轮灵感：「可重构机构」×「演示数据」）

> 第 62 轮 ROSE 把 ESEC 从「静态闭环」推进到「学习-鲁棒动态闭环」：OLP 给出遗憾界、WCV/RSC 给出偏差球、SBR/SHC 给出场景课程、Shield 给出机制安全。但 ROSE 仍把两件事当成常量：**身体是固定的**、**经验只能自己产生**。本轮的两个灵感恰好击中这两个常量：
> 1. **身体不是常量，而是可切换的区制**：可重构机构（模块化关节、可变连杆、快换末端、锁定/自由关节、变刚度机构）让同一台机器人在寿命内经历 m_0→m_1→… 的形态序列。ROSE 的 USR/MEL/OLP/WCV 全部在固定 m 下训练与证明；一次重构就让 Π_0、φ 先验、安全集 𝒦、乃至用户语义全部错位，而系统对重构**没有事件检测、没有区制记忆、没有交接协议**。
> 2. **经验不只来自自身执行**：ROSE 的 SBR 只做 Mine(EV_exec)，冷启动必须靠真实试错；而重构后的新形态恰是最危险、最不该盲目试错的阶段。人类演示（遥操作/动觉示教/VR）本可提供先验与激励，却因**跨形态不可直接映射**而被整体丢弃。
> 3. **A72 的单点故障可被身体本身修复**：ROSE 最大风险是单构型 J_φ 病态或残差被控制回路吸收。可重构机构提供了一类**免费的物理干预**——同一组物理参数在不同形态下产生不同的灵敏度矩阵 J_φ(m)。主动选择形态，就能把「不可辨识」变成「可辨识」。
> 4. **重构过程本身是安全盲区**：WCV/Shield 只为当前 m 编译；切换瞬间 m 改变，旧 K_safe 失效，J_rose 甚至没有记录 m。安全必须覆盖「过渡」而不只是「稳态」。

## 0. 直觉与动机

**灵感 1（可重构机构 → AIP：重构即干预，身体即探针）**
直觉：第 62 轮把 φ 的辨识压在单一构型的残差反演上，等于用一把尺子量所有方向。可重构机构让我们**换尺子**：伸长连杆改变力臂、换末端改变接触几何、锁住关节改变有效惯量——同一组 φ 在不同 m 下留下不同的「指纹」J_φ(m)。于是把重构从「任务需要时才做」升级为「辨识需要时主动做」：选择使 Fisher 信息 det(I_prev + S_eff(m)ᵀΣ⁻¹S_eff(m)) 最大的配置作为探针，其中 S_eff=(I−C(m))J_φ(m) 是**扣除控制回路吸收后仍可见**的有效灵敏度。关键洞见：**单构型不可辨识 ≠ 多构型不可辨识；多个秩亏的 S_eff 相加可以满秩。** 这直接替代 A72（单 J 良态），把 ROSE 的单点假设变成可设计的持续激励条件（PE-Config）。

**灵感 2（演示数据 → MIS：形态变，技能不变）**
直觉：人类演示与机器人执行在关节空间毫无可比性，但在**任务语义空间**可比：接触点、运动方向、相位、力调制曲线、夹持开合时序。把演示抽象为形态无关的技能嵌入 z（MISE），再用当前形态解码器 g_ψ(z, m) 重定向到本机。于是换工具/换臂长/换自由度时，技能不丢，只换「适配器」。这为 ROSE 补上跨形态先验：演示先告诉系统「大致怎么用力」，在线学习只负责「这具身体差多少」。

**灵感 3（演示数据 → DBR：可复用的演示银行）**
直觉：演示不是一次性模仿样本，而是**覆盖账本**：每条演示标注形态签名、技能标签、接触相位、质量分与覆盖簇。演示银行做三件事：① 为 OLP 提供形态重定向后的暖启动 W_0；② 为 SBR 补足零样本场景，降低冷启动试错；③ 为 MEL-OA 提供防遗忘回放中「人类先验」那一半。演示质量差/形态差大时自动降权，只作软先验，绝不绕过 Shield。

**灵感 4（可重构机构 → RED + MSH：区制分段与安全交接）**
直觉：把机器人寿命切成「形态区制」m_t 的分段平稳过程。重构事件由本体感知（关节/连杆/工具 ID）与动力学残差变点联合检测；进入新区制后，旧学习量不直接复用，而是经形态相似核迁移并进入「保守重启」。安全上，重构必须走**交接协议**：冻结学习写、释放接触/进入自由空间、在中间构型的交集安全集内逐帧校验、生成交接证书后才允许新区制接管。

**灵感 5（演示数据 → DCC + DOLP：演示覆盖课程与演示锚定遗憾）**
直觉：ROSE 的 Hedge 只按「自己亏了多少」调度；冷启动时所有簇一样陌生，调度等于乱撞。演示覆盖给出第二个信号：哪些簇「有人教过」、哪些「完全没教过」。把课程权重改为「集群遗憾 × 演示缺口」双信号，并让 OLP 在演示锚定的信任域内起步——演示越好，有效直径 D_demo 越小，重构后的遗憾常数越小。这里必须诚实：演示只改变常数与冷启动，**不改变 √T 的量级**。

**灵感 6（合流 → PRISM：可重构形态 × 演示数据的闭环）**
直觉：四者咬合成一个闭环：**重构事件 → 区制切分（RED）→ 主动探针（AIP）→ 多区制辨识（MRSC）→ 安全交接（MSH）→ 新形态暖启动（DOLP/DBR）→ 演示覆盖课程（DCC）→ 在线遗憾最小化（OLP）**。一句话概括：**「身体变、技能不变；演示教、探针识；交接稳、证书全。」** 第 62 轮 ROSE 是固定身体的动态闭环；PRISM 是**可换身体、可借他人经验**的动态闭环。

## 1. 形式化定义（增量：定义 185–196）

- **定义 185（PRISM 可重构形态-演示闭环）**：PRISM = (ROSE, RED, MIS, DBR, AIP, MRSC, DOLP, MSH, DCC, RAB, J_prism)。定位：ROSE 的「形态维度 × 演示维度」升级；不推翻 OLP/WCV/SBR/Shield 接口，只给它们增加形态条件与演示先验。
- **定义 186（形态状态与区制）**：m = (κ, ℓ, tool, 𝒦_stiff) ∈ ℳ，κ 为拓扑（连杆/关节连接），ℓ 为连续几何/惯量参数，tool 为末端，𝒦_stiff 为可变刚度范围。区制序列由事件 e_t = 𝟙[Δm_t ≠ 0 ∨ 残差变点]，区制索引 k(t)。
- **定义 187（形态不变技能嵌入 MISE）**：z = S(τ) 为演示/执行轨迹在**物体中心任务系**的语义抽象：{路径点, 接触时序, 力曲线（按物体重量归一）, 夹持开合时序, 相位标签}。解码器 g_ψ(z, m) 将 z 重定向到形态 m 的可执行轨迹。
- **定义 188（演示银行 DBR）**：𝒟 = {(τ_i, m_i, z_i, q_i, cov_i, prov_i)}，q_i 为质量分（成功、平滑、力合规），cov_i 为覆盖簇，prov_i 为来源层级（L0 人类遥操作 / L1 同构机 / L2 异构机 / L3 仿真）。
- **定义 189（形态重定向算子）**：Retarget_{m'←m}(z) = argmin_τ ‖S(τ)−z‖²_{task} + λ_e‖τ‖²_{effort} s.t. τ 满足 m' 的运动学/力矩/限位约束；重定向误差 ε_ret = sup_z ‖S(Retarget(z))−z‖。
- **定义 190（主动干预信息量 AIP）**：对配置 m，Effective 灵敏度 S_eff(m) = (I−C(m))·J_φ(m)（C 为控制回路吸收算子）。单次信息 I(m) = S_eff(m)ᵀΣ⁻¹S_eff(m)；调度 Φ=(m_1..m_n) 的总信息 I_total(Φ)=Σ_k I(m_k)。
- **定义 191（重构持续激励条件 PE-Config）**：存在可行配置序列 Φ 使 λ_min(I_total(Φ)) ≥ σ_PE > 0；等价于 ⋃_k range(S_eff(m_k)ᵀ) = ℝ^{d_φ}。此条件替代 ROSE 的 A72（单 J_φ 良态）。
- **定义 192（多区制残差校准 MRSC）**：跨区制聚合 φ̂ = (Σ_k I_k)⁻¹ Σ_k S_eff,kᵀΣ⁻¹resid_k；球半径 r_t = clip(κ_r·√(d_φ/λ_min(I_total)), r_min, r_max)，与单区制 RSC 的 e_t 反演兼容但不再依赖单个 J_φ。
- **定义 193（演示锚定遗憾）**：设演示重定向给出 W_demo，且 W_*∈B(W_demo,D_demo)∩𝒲；OLP 在信任域 B(W_demo,D_demo) 内做 OGD，定义 R_T^demo = Σ_t ℓ̃_t(W_t) − min_{W∈B(W_demo,D_demo)}Σ_t ℓ̃_t(W)。
- **定义 194（重构交接安全 MSH）**：转移 m→m' 可采纳 ⇔ ① 接触载荷释放或进入自由空间；② 存在中间构型序列 m=m⁽⁰⁾..m⁽ˢ⁾=m' 全在关节/力矩/限位内；③ ∩_i 𝒞_safe(m⁽ⁱ⁾) 非空且 K_handover∈∩_i 𝒦(m⁽ⁱ⁾)。满足时生成交接证书 H_cert。
- **定义 195（演示覆盖课程 DCC）**：簇 c 的演示缺口 gap_c = 1/(1+n_c^demo)；课程权重 w_c ∝ exp(η·Ĝ_c)·(1+γ·gap_c)，同时驱动重推理频率、MEL-OA 采样、仿真生成与演示回放。
- **定义 196（PRISM 证书与闭环算子）**：J_prism = (J_rose, m_t, λ_min(I_total), ε_ret, demo_prov_hash, H_cert)；Valid(J_prism) ⇔ Valid(J_rose) ∧ λ_min(I_total)≥σ_PE ∨ r_t≤r_max（退化可审计）∧ ε_ret≤ε_max ∧ H_cert 有效。闭环算子见定义 202 伪代码。

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 1（多区制可辨识）**：残差线性化 resid_k = S_eff(m_k)Δφ + ε_k。最小二乘误差协方差为 I_total(Φ)⁻¹；若 PE-Config 成立（λ_min(I_total)≥σ_PE），则 ‖φ̂−φ*‖ = O_p(√(d_φ/(n·σ_PE)))。**单个 S_eff 秩亏无妨，聚合满秩即可辨识**——A72 被 A78 取代，ROSE 的单点风险变成可设计的探针条件。
- **引理 2（演示重定向误差 → 先验半径）**：若 Retarget 满足 ε_ret 有界且演示最优性缺口 ≤ D_res，则演示先验满足 D_demo ≤ L_R·ε_ret + D_res；演示覆盖越全、形态差越小，D_demo 越小。
- **引理 3（交接拼接安全）**：若每一步 m⁽ⁱ⁾ 的 ρ_rob(m⁽ⁱ⁾)≥0、接触载荷释放、且 K_handover∈∩_i 𝒦(m⁽ⁱ⁾)，则整个转移过程无安全违规（对中间构型归纳）。
- **定理 1（演示锚定的重构遗憾）**：K 个区制、区制时长 T_k、ΣT_k=T。每区制在 B(W_demo,D_demo) 内跑 OGD，取 η=D_demo/(G̃√T_k)，则 R_T ≤ (3/2)·D_demo·G̃·√(K·T) + K·C_ret + B·c_probe。无演示时 D_demo=D，退化为 ROSE 的 √T 界；演示完美时仅常数变小，**阶仍为 √(KT)**。
- **推论（演示覆盖加速）**：DCC 使最缺演示的簇获得更高调度权重，冷启动阶段该簇的累计遗憾下降速率由「均匀探索」的 1/C 提升到 w_c；E213/E214 验证。
- **安全（PRISM-Complete）**：在 ROSE-Complete 之上增加 (a) PE-Config 或可审计的退化标记、(b) 交接拼接安全、(c) 演示不绕过 Shield；则「可辨识—覆盖—交接」三段安全链闭合。
- **实时性**：AIP 选点、演示重定向、MRSC 聚合均只在语义流/重构窗口执行；实时流仍只读锚点并做 OLP 前向 + WCV 编译，保持 ≤1ms 契约（继承 A75）。

## 2. 形式化定义（完整版）

**定义 185（PRISM 闭环）** PRISM 在 ROSE 的「语义流 ∘ 实时流」骨架上增加两个正交维度：形态维度——把寿命切为区制，区制内复用 ROSE，区制切换走 RED/AIP/MSH/MRSC；演示维度——用 DBR 把跨形态演示变成 OLP 先验、SBR 场景、MEL-OA 回放。不变式：**任何学习/辨识/重定向只在语义流或重构窗口发生；实时流仍零学习写，且任何演示先验都不能绕过 WCV/Shield 的安全编译。**

**定义 186（形态状态与区制）** m = (κ, ℓ, tool, 𝒦_stiff)，κ 为连接拓扑（如 6-DOF 臂 / 双臂 / 变刚度关节锁定模式），ℓ 为连续参数（连杆长、质心、惯量），tool 为快换末端 ID，𝒦_stiff 为可调刚度区间。RED 以本体签名（编码器零点、连杆 ID、工具 ID、锁定状态）为主判据、以动力学残差变点为辅判据：
`e_t = 𝟙[m_t ≠ m_{t−1}] ∨ 𝟙[CPD(resid_{1:t}, δ_cp) = alarm]`，并施加最小驻留时间 T_dwell 防抖。区制 k 的有效数据窗口为 [τ_k, τ_{k+1})。

**定义 187（形态不变技能嵌入 MISE）** 对轨迹 τ（演示或执行），S(τ) 抽取：
`z = ({p_i^obj, ṗ_i^obj}, {t_contact^on/off}, f(·)/W_obj, {aperture(t)}, phase_labels)`。
其中位置/方向在**物体中心系**表达，力按物体重量归一，时间按任务相位归一。形态解码 `g_ψ(z,m)` 通过约束最优控制求解，使重定向轨迹满足 m 的运动学/力矩/限位；`ψ` 为跨形态共享的少量可调参数（MIS 只学这层）。

**定义 188（演示银行 DBR）** 𝒟 中每条演示带形态签名、技能嵌入、质量分 q_i∈[0,1]（任务成功、平滑度、力合规、无碰撞）、覆盖簇 cov_i、来源层级 prov_i∈{L0 人类遥操作, L1 同构机, L2 异构机, L3 仿真}。检索接口：
`𝒟.prior(m, c, k) = fit({Retarget(z_i), w_i})`，权重 `w_i ∝ q_i · sim(m_i,m) · 𝟙[cov_i=c]`，sim 为形态相似核（拓扑匹配 + 连杆尺度比 + 末端类型）。

**定义 189（形态重定向）** `Retarget_{m'←m}(z) = argmin_τ ‖S(τ)−z‖²_task + λ_e‖τ‖²_effort`，约束 τ∈𝒯(m')（关节限位、力矩、速度、自碰、接触可行性）。重定向误差 `ε_ret = sup_z ‖S(Retarget(z))−z‖`。**关键限制**：若 m' 的拓扑不支撑 z 的接触模式（如单指夹持无法实现包络抓取），Retarget 返回不可行，演示降权而非硬用。

**定义 190（主动干预信息量 AIP）** 控制回路会吸收一部分外力矩残差，故观测到的不是 J_φ 而是 `S_eff(m)=(I−C(m))J_φ(m)`。单次信息 `I(m)=S_eff(m)ᵀΣ⁻¹S_eff(m)`；对调度 Φ=(m_1..m_n)，`I_total(Φ)=Σ_k I(m_k)`。探针选择为 D-最优贪心：
`m* = argmax_{m∈ℳ_probe} logdet(I_prev + I(m)) − logdet(I_prev) − λ_p·cost_probe(m)`，且 m 必须满足任务可行与 MSH 可采纳。

**定义 191（PE-Config 持续激励）** 存在可采纳配置序列 Φ 使 `λ_min(I_total(Φ)) ≥ σ_PE > 0`，等价于 `⋃_k range(S_eff(m_k)) = ℝ^{d_φ}`。注意条件建在 **S_eff** 而非 J_φ 上：若控制回路对所有配置等价吸收，则 PE 不成立——这是对 ROSE 风险的正视，而非掩盖。

**定义 192（多区制残差校准 MRSC）** 对每个区制维护信息矩阵与信息向量：
`I_k ← γ_f·I_k + S_eff,kᵀΣ⁻¹S_eff,k`，`b_k ← γ_f·b_k + S_eff,kᵀΣ⁻¹resid_k`（γ_f 为遗忘因子，保留旧区制的可迁移信息）。
`φ̂ = (Σ_k I_k)⁻¹(Σ_k b_k)`，`r_t = clip(κ_r·√(d_φ/λ_min(Σ_k I_k)), r_min, r_max)`。
当 λ_min 过小时，MRSC 输出退化标记 `degraded=True`，交由 MSH 回退保守基线（可审计，不假装有保证）。

**定义 193（演示锚定遗憾）** 演示重定向回归得到 W_demo；设存在 D_demo 使 W_*∈B(W_demo,D_demo)∩𝒲。OLP 的在线更新被限制在信任域 B(W_demo,D_demo) 内：
`W_{t+1} = P_{𝒲∩B(W_demo,D_demo)}(W_t − η_t∇ℓ̃_t)`。
若残差持续把梯度推出信任域（演示偏置报警），按 `D_demo ← min(D, 1.5·D_demo)` 受控扩张，并在证书中记录 `demo_bias_flag`。

**定义 194（重构交接安全 MSH）** 转移 m→m' 可采纳需同时满足：
① 任务状态允许释放接触或已在自由空间（接触载荷 ≤ δ_load）；
② 存在中间构型 m⁽⁰⁾=m..m⁽ˢ⁾=m'，每步满足关节/力矩/速度/限位，且转移路径无自碰；
③ `∩_i 𝒞_safe(m⁽ⁱ⁾) ≠ ∅` 且存在 K_handover∈`∩_i 𝒦(m⁽ⁱ⁾)`，其中 `𝒞_safe(m)=ERTC` 约束在 `B(φ̂,r_t)` 最坏情形下的可行集。
满足则生成 `H_cert={(m⁽ⁱ⁾,ρ_rob(m⁽ⁱ⁾))}`；交接期间 `learning_freeze=True`，OLP/MRSC/MEL-OA 均不写。

**定义 195（演示覆盖课程 DCC）** 每个场景簇 c 统计 `n_c^demo`、`gap_c=1/(1+n_c^demo)`。课程权重
`w_c ∝ exp(η·Ĝ_c)·(1+γ·gap_c)`，
三通道预算（MEL 重推理 / MEL-OA 采样 / 仿真生成）按 w_c 分配；当某簇 n_c^demo=0 时额外触发「演示优先回放」或「请求人类示教」的对话动作（DMS）。演示只提高采样概率，不改变 Hedge 的遗憾界阶。

**定义 196（PRISM 证书与闭环算子）** `J_prism=(J_rose, m_t, λ_min(I_total), ε_ret, demo_prov_hash, H_cert)`。
`Valid(J_prism) ⇔ Valid(J_rose) ∧ [λ_min(I_total)≥σ_PE ∨ (r_t≤r_max ∧ degraded 已标记)] ∧ ε_ret≤ε_max ∧ H_cert_valid ∧ demo_not_bypass_shield`。
闭环算子见 IP-202 伪代码：语义流负责 RED→AIP→MRSC→DOLP→DCC→OLP；实时流负责锚点读→OLP 前向→WCV 编译→派发；重构窗口由 MSH 独占，冻结全部学习写。

### IP-196 AIP（主动干预探针）

```python
class ActiveProbingPlanner:
    def __init__(self, probe_configs, Sigma, lam_p=0.1, budget=8):
        self.configs, self.Sigma, self.lam_p, self.budget = \
            probe_configs, Sigma, lam_p, budget

    def choose(self, I_prev, task_ok, handover_ok):
        base = logdet(I_prev + EPS * np.eye(len(I_prev)))
        best, best_score = None, -np.inf
        for m in self.configs:
            if not (task_ok(m) and handover_ok(m)):
                continue
            S = effective_sensitivity(m)              # (I - C(m)) @ J_phi(m)
            gain = logdet(I_prev + S.T @ inv(self.Sigma) @ S + EPS*I) - base
            score = gain - self.lam_p * probe_cost(m)
            if score > best_score:
                best, best_score = m, score
        return best

def effective_sensitivity(m):
    C = identify_loop_absorption(m)                   # 闭环绕过残差的投影
    return (np.eye(D_PHI) - C) @ jacobian_phi(m)
```

### IP-197 MRSC（多区制残差校准）

```python
class MultiRegimeRSC:
    def __init__(self, d_phi, kappa_r=1.0, gamma_f=0.995,
                 r_min=0.02, r_max=0.5):
        self.I, self.b = {}, {}
        self.d_phi, self.kappa_r, self.gamma_f = d_phi, kappa_r, gamma_f
        self.r_min, self.r_max = r_min, r_max
        self.degraded = False

    def update(self, m, resid, S_eff, Sigma):
        k = regime_id(m)
        Ik = self.I.get(k, np.zeros((self.d_phi, self.d_phi)))
        bk = self.b.get(k, np.zeros(self.d_phi))
        W = inv(Sigma)
        self.I[k] = self.gamma_f * Ik + S_eff.T @ W @ S_eff
        self.b[k] = self.gamma_f * bk + S_eff.T @ W @ resid
        I_tot = sum(self.I.values())
        self.phi_hat = solve(I_tot, sum(self.b.values()))
        lam = eigvalsh(I_tot)[0]
        if lam < SIGMA_PE_MIN:
            self.degraded = True                      # 不假装可辨识
            self.r = self.r_max
        else:
            self.degraded = False
            self.r = np.clip(self.kappa_r * np.sqrt(self.d_phi / lam),
                             self.r_min, self.r_max)
        return self.r, self.degraded
```

```python
class DemoWarmstartProjector(OnlineLearningProjector):
```

```python
def morphing_handover(M, m_new):
    m_old = M.red.current
    if not reconfig_preconditions(M, m_old, m_new):            # 接触/限位/自碰
        return Refuse('precondition')
```

```python
        self.w = sim * self.w + (1 - sim) * np.ones(self.K) / self.K
```

```python
        cert_exec, j_rose=build_j_rose(...), m=M.red.current,
        lam=min_eig(M.mrsc.I_total), eps_ret=M.demo_bank.last_eps_ret,
        demo_hash=M.demo_bank.provenance_hash(), hcert=M.last_hcert,
        degraded=degraded)

def realtime_step(M, delta_f_req):
    anchor, fresh = M.ara.read_latest()
    if anchor is None:
        K_prior = K_BASELINE
    else:
        K_prior = robust_prior(M.olp, anchor, fresh)
    K_safe, rho_rob, _ = wcv_compile(M.olp, anchor.x if anchor else None,
                                     M.eeis, anchor.phi_hat if anchor else PHI_SAFE,
                                     M.mrsc.r, m=M.red.current)
    cert_exec = M.ertc.dispatch(K_safe)        # ≤1ms，零学习写
    EV_exec = wait_contact_and_build_evidence()
    M.usr.push_evidence(EV_exec)
    M.rho = rho_rob
    return K_safe, EV_exec, cert_exec
```

## 4. 推导

**引理 1（多区制可辨识与球覆盖）** 在区制 m_k 上，残差线性化为
`resid_k = S_eff(m_k)·Δφ + ε_k`，`ε_k ~ subGaussian(0, Σ)`。
将 n 次观测堆叠，最小二乘估计 `Δφ̂ = I_total⁻¹ Σ_k S_eff,kᵀΣ⁻¹resid_k`，误差协方差 `Cov(Δφ̂)=I_total⁻¹`。若 PE-Config 成立，则 `λ_min(I_total)≥σ_PE`，对任意 δ∈(0,1)，以概率 ≥1−δ：
`‖φ̂−φ*‖₂ ≤ √(2 log(2d_φ/δ) / σ_PE) · σ_max(Σ)^{1/2}`。
取 `r_t = κ_r√(d_φ/λ_min(I_total))`（κ_r 含噪声与置信因子）即得 `P[φ*∈B(φ̂,r_t)] ≥ 1−δ`。**注意**：单个 S_eff(m_k) 可以秩亏；只要聚合张成 ℝ^{d_φ}，覆盖就成立。A72（单 J_φ 最小奇异值下界）被 A78（聚合 PE）取代。∎

**引理 2（重定向误差 → 演示先验半径）** 设任务嵌入 S 与重定向解算子关于 z 是 L_S-Lipschitz，演示的最优性缺口为 D_res（演示本身不是任务最优解）。则对任意 m：
`D_demo(m) ≤ L_R·ε_ret(m) + D_res`，
其中 L_R 由 S 的 Lipschitz 常数与阻抗回归的条件数决定。演示越贴近目标形态、质量越高，ε_ret 与 D_res 越小，信任域越紧。∎

**引理 3（交接拼接安全）** 对转移路径 m⁽⁰⁾..m⁽ˢ⁾归纳。基例：m⁽⁰⁾=m_old 在上一稳态已安全。归纳步：若在 m⁽ⁱ⁾ 上 K_handover∈𝒦(m⁽ⁱ⁾) 且 ρ_rob(m⁽ⁱ⁾)≥0，则由 WCV 的定义，K_handover 对 B(φ̂,r_t) 内所有 φ 可行；又因接触载荷释放（或 ≤δ_load）使外力不越过 ERTC 边界，故状态在 m⁽ⁱ⁾→m⁽ⁱ⁺¹⁾ 的锁止转移中保持安全。转移结束后，H_cert 记录全部中间 ρ_rob，任何一步为负则 Abort。∎

**定理 1（演示锚定的重构遗憾）** 设寿命含 K 个区制，区制 k 时长 T_k，Σ_k T_k=T。区间内损失 ℓ̃_t 对 W 凸、G̃-Lipschitz（ROSE 引理 1 的鲁棒化上界），且每区制在凸紧信任域 𝒲_k=B(W_demo^{(k)},D_demo)∩𝒲 内优化，W_*^{(k)}∈𝒲_k。由 OGD 标准分析（取 η_k=D_demo/(G̃√T_k)）：
`R_k = Σ_{t∈k}ℓ̃_t(W_t) − min_{W∈𝒲_k}Σ_{t∈k}ℓ̃_t(W) ≤ (3/2)·D_demo·G̃·√T_k`。
对 k 求和并用 Cauchy-Schwarz `Σ_k√T_k ≤ √(K·T)`：
`R_T ≤ (3/2)·D_demo·G̃·√(K·T)`。
加上 K 次重定向成本 K·C_ret 与探针预算 B·c_probe：
`R_T ≤ (3/2)·D_demo·G̃·√(K·T) + K·C_ret + B·c_probe`。
当无演示时 D_demo=D，得到 ROSE 固定形态界的 K 区制版本；当演示完美（D_demo→0）时仅常数下降，**√(KT) 的阶不变**——这是诚实的能力边界。∎

**推论 1（演示覆盖的冷启动加速）** DCC 把簇 c 的采样概率从均匀 1/C 提升到 w_c。若某簇演示缺口 gap_c 大且集群遗憾 Ĝ_c 高，则 w_c 增大；在最陌生簇上，其累计遗憾的相对下降速率为 `w_c·C` 倍。演示覆盖只改善**常数与早期阶段**，长期仍由在线遗憾界主导。∎

**推论 2（退化可审计）** 若 PE-Config 不成立，MRSC 令 r_t=r_max 且 `degraded=True`。此时 J_prism 的验证规则明确要求「degraded 已标记 ∧ r_t≤r_max」，系统以最大保守球兜底并拒绝声称可辨识。**安全不依赖未满足的假设，但性能保证明确降级**。∎

**命题（Shield 与演示解耦）** 演示派生的约束只是 𝒞_safe 的**软先验**（用于排序/加权），不进入硬约束集合；所有 DMS 提案仍必须通过 IP-190 的凸投影。故第 62 轮的「机制安全」在引入演示后仍然成立，演示数据无法绕过 Shield。∎

## 5. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| RED | O(d_proprio) + 变点 O(1) 摊销 | O(窗口) | 最小驻留时间 + 双判据，防抖 |
| MIS/Retarget | O(T_opt)（语义流，可离线缓存） | O(轨迹) | ε_ret 可测量；拓扑不支持则拒绝 |
| DBR 检索/回归 | O(\|𝒟\|·d_sig + k·m·d_out) | O(\|𝒟\|) | 质量分 + 形态相似加权，软先验 |
| AIP 选点 | O(\|ℳ_probe\|·(d_φ³ + d_φ²)) | O(\|ℳ_probe\|·d_φ²) | D-最优贪心，信息增益单调 |
| MRSC | O(K·d_φ² + d_φ³) 语义流 | O(K·d_φ²) | 引理 1：聚合满秩 ⇒ 覆盖 |
| DOLP | 实时前向 O(d_us·m+m·d_out)<0.05ms | O(m·d_out) | 定理 1；信任域可检测扩张 |
| MSH | O(s·C_eeis) 重构窗口 | O(s) | 引理 3：逐中间构型归纳 |
| DCC | O(C)，C=64 | O(C) | 沿用 Hedge 伪遗憾 √(2T log C) |
| RAB | O(K)，K=8 | O(K) | 伪遗憾 √(2KT log K) + 迁移 |
| 实时路径 | ≤1ms（继承） | — | 零学习写（A75）；演示不进入实时写 |

**正确性定理（PRISM-Complete）** 假设 ROSE 的 A61–A76 及：
- **(A77) 区制可检测性**：重构事件在 τ_detect 内被 RED 检出；区制数 K 有限，T_k≥τ_min，驻留时间足够完成一次辨识更新。
- **(A78) 有效灵敏度多样性（PE-Config）**：存在可采纳配置序列 Φ 使 `λ_min(Σ_k S_eff(m_k)ᵀΣ⁻¹S_eff(m_k)) ≥ σ_PE>0`；S_eff 对 m 的依赖可被建模（至少可估计）。
- **(A79) 演示可迁移性**：Retarget 在拓扑支持时 ε_ret≤ε_max，且演示最优性缺口有界；回归条件数有界。
- **(A80) 交接可行性**：转移路径存在、关节/力矩/限位可行、交集安全集非空；接触载荷可释放或 ≤δ_load。
- **(A81) 演示安全隔离**：演示只作软先验，永不写入 𝒞_safe 的硬约束，永不绕过 Shield。
- **(A82) 预算非退化**：探针预算 B 有限且计入遗憾；RAB 的迁移不退化为均匀重置。

则：
1. **可辨识性**：PE-Config 成立时，MRSC 的球覆盖 `P[φ*∈B(φ̂,r_t)]≥1−δ`，且不依赖单构型 J_φ 良态（引理 1）——ROSE 最大风险的单点被「多区制聚合」替代。
2. **交接安全**：MSH 通过的转移满足逐中间构型 ρ_rob≥0，过渡期零学习写，安全违规率为 0（引理 3）；未通过则拒绝/回退，不允许带病接管。
3. **演示加速**：演示锚定 OLP 的信任域 D_demo 使每区制遗憾常数为 (3/2)D_demo G̃√T_k，总遗憾 ≤(3/2)D_demo G̃√(KT)+K·C_ret+B·c_probe（定理 1）——演示降低常数、改善冷启动，不改 √ 阶。
4. **形态迁移**：MIS 使技能嵌入 z 跨形态可比，DOLP/DBR 在新区制给出可用先验；重定向不可行时安全降权而非硬用（定义 189、A79）。
5. **课程自适应**：DCC 的伪遗憾仍 ≤√(2T log C)，且演示缺口使最陌生簇更早被采样（推论 1）。
6. **预算自适应**：RAB 在区制切换时按形态相似度迁移 EXP3 权重，伪遗憾 ≤√(2KT log K)+K·C_migrate。
7. **实时性不变**：所有新增学习/辨识/重定向均在语义流或重构窗口，实时路径仍零学习写，≤1ms 契约不变（A75）。

## 7. 已知风险

**一句话**：PRISM 的核心修复依赖「重构探针能在接触富集区制提供持续激励，且演示能跨形态无偏重定向」；若可重构机构只能在空载/自由空间安全切换，而真正的接触参数恰在接触中被控制回路混淆，则 PE-Config 在关键区制失效、MRSC 退回单 J 反演，ROSE 的 CVaR 球覆盖风险原样回归。

**次级风险与缓解**：
1. **探针物理可行性**：重构可能耗时、耗能、需停机；接触中不可切换 → 把探针限制在安全窗口，允许「延迟辨识」；用 `degraded` 标记 + r_max 兜底，绝不假装可辨识。
2. **控制回路吸收的等价性**：若 C(m) 对所有配置等价吸收，S_eff 的多样性消失 → 在 AIP 中显式估计 C(m)；若秩不足，主动改变控制增益/激励轨迹作为补充探针，并记录不可辨识方向。
3. **演示重定向偏差**：人类与机器人拓扑/尺度差异导致 ε_ret 大，错误演示可能把 W_0 带入坏局部 → 信任域可检测扩张、按 q_i·sim 降权、演示永不硬编码安全约束；E220 专门污染测试。
4. **信任域陷阱**：D_demo 过紧会限制 OLP 逃离演示偏差 → escape 计数触发 1.5× 扩张；若持续越界则退回无演示的 ROSE 模式并标记 `demo_bias_flag`。
5. **区制检测抖动**：误检/漏检导致频繁切换 → 最小驻留时间、双判据、迟滞；每次切换的 C_ret 计入遗憾，避免「为探针而探针」。
6. **交接瞬态未建模接触**：释放/夹持瞬间的冲击可能超出 WCV 假设 → 交接期间强制保守基线 + 力矩限幅 + 机械互锁；MSH 只在自由空间或载荷≤δ_load 时放行。
7. **多区制信息遗忘/数值病态**：旧区制信息与新区制冲突 → 遗忘因子 γ_f 滑动窗；λ_min 数值监控，低于阈值即 degraded；跨形态迁移用相似核而非硬拷贝。
8. **演示数据治理**：隐私、标注质量、来源不可信 → provenance hash 入 J_prism；L0 人类数据脱敏；演示库版本化、可回滚。
9. **三重学习耦合**：OLP、MEL-OA、MRSC 同时更新会互相追逐 → 保留 ROSE 的奇偶步分离，并在重构窗口统一 `learning_freeze`；DOLP 的信任域作为耦合阻尼。
10. **过拟合探针配置**：AIP 反复选同一配置导致局部信息饱和 → D-最优天然鼓励多样性，另加配置冷却时间与探索噪声。
