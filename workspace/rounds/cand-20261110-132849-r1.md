# 第 44 轮（承接第 43 轮 v20；本轮灵感：社会影响 × 视觉编码器） · Social-Cert × Vision-Cert：把「社会影响」当作内生分布偏移、把「视觉编码器」当作可证感知通道（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形只保边际覆盖 + 多用户契约空集」，但它仍压着两个更底层、从未被显式建模的假设：**(H1) 人的输入分布是外生的、平稳的**——共形预测的可交换性据此成立；然而机器人本身是一个**社会行为体**：它的措辞、语气、置信度表达、动作风格、乃至"我很确定"这句话，都会持续改变人的行为分布。漂移不是外部噪声，而是**机器人自己制造的**（performative prediction），可交换性被系统性违反，v20 的认证扩张会在"自己吹起的风"里失效。**(H2) 视觉编码器是可信、已证鲁棒的前端**——所有语义/几何/人格证书都条件在编码器输出上，但社会线索（注视、指点、表情、身体朝向、场景文字）与对抗扰动正是从编码器进入；编码器的 Lipschitz 常数直接给出了"攻击者或机器人能通过视觉通道撬动意图后验多少"的上界，而 v20 从未把它计入证书。两个灵感词精确命中：**社会影响**迫使我们把人机闭环从"人类作为环境噪声"升级为"人类作为会被机器人影响、也会反过来影响机器人的策略性响应者"；**视觉编码器**迫使我们把证书链的起点从"语义结论"下移到"潜空间中的可证感知"。二者耦合出本轮真正的新问题：**社会影响是正反馈回路，视觉编码器是该回路最容易被注入的入口**——若不证明这个回路是小增益稳定的，再好的单步证书也会在"过度信任 → 更冒险的指令 → 更自信的行为 → 更信任"的级联中发散。

## 0. 直觉与动机

**灵感 1（社会影响 → "你就在你要预测的分布里"）**：普通人机交互把人的指令当成独立同分布样本；但现实里，机器人说"前方安全，请跟我走"会让人更愿意走进狭窄通道，机器人表现犹豫会让人接管或给出更保守的指令，一个权威外观的第三方（制服、工牌、扩音器）能让旁观者发出平时不会发出的危险指令。也就是说，**部署策略 π 改变了人类输入分布 D_u(π)**，而共形校准集来自旧策略 π_cal 下的 D_u(π_cal)。这不是普通 covariate shift，而是**表演式（performative）偏移**：分布由模型自身的行为诱导。工程含义很硬：**不能只在部署后"检测漂移"，而必须在策略选择时就约束自己制造多少漂移**。于是引入影响力预算 β_inf、社会响应算子 Φ、以及"机器人不得无授权地操纵用户"的同意分级（告知/劝导/指令）。社会影响因此从"软性交互设计"变成一条可审计的证书约束。

**灵感 2（视觉编码器 → "证书链必须从潜空间起算"）**：现有证书把 VLM/几何/语义结论当作原子事实，但它们的真值条件在编码器 E_θ 的输出上：同一张图加一个 ε 范数内的对抗补丁、一块印着"安全区域 ↑"的纸板、一个模仿指向手势的人偶，都可能让 E_θ 的潜表示跨过决策边界。只要 E_θ 是 L_E-Lipschitz，就有 ||E(x+δ)−E(x)|| ≤ L_E·ε；把它与分类头/社会线索头的 Lipschitz 常数复合，就能得到一个**可证社会线索半径** r_cert：在 r_cert 内的视觉扰动绝不改变该线索的判定。这个半径可以像测量不确定度一样，从语义边际里直接扣掉（只扣 margin，绝不放宽阈值），并成为"视觉通道影响力"的硬上界。更进一步，随机平滑（randomized smoothing）给出可计算的 certified radius，使得"smoothing 之后的编码器"成为一个可部署、可查询的证书源，而不是离线论文里的假设。

**灵感 3（耦合 → 社会-视觉闭环的小增益条件）**：把社会影响画成反馈环：机器人行为/表达 → 人的信任与意图 → 人的指令 → 机器人更自信/更冒险的行为。视觉通道是外部攻击者注入扰动的入口，也是机器人读取社会线索的入口。控制论里判断这种闭环是否会失稳的标准工具是**小增益定理**：若社会响应增益 γ_soc 与机器人行为增益 γ_R 的乘积 γ_loop = γ_soc·γ_R < 1，则闭环输入-状态稳定（ISS），扰动（含视觉攻击）只造成有界偏差；若 γ_loop ≥ 1，就存在"过度信任级联"的正反馈，此时任何认证扩张都必须停用。这把"社会影响是否安全"从定性担忧变成**一个可估计、可压测、可熔断的增益证书**，也把视觉编码器的 L_E 接进同一个不等式：视觉扰动经过编码器的放大系数是 γ_vis = L_E·ε_vis，最终偏差被 1/(1−γ_loop) 放大。

**耦合升级**：SIE（社会影响引擎）估计社会响应算子与回路增益、维护影响力账本与同意分级；VEC（视觉编码器证书器）产出编码器级证书半径与社会线索接地；SVV（社会-视觉验证器）在仿真里枚举"视觉攻击 × 人类响应模型"的组合，把反例回灌 CKB 与 SCV。四层架构由此从 v8 的"飞轮 + 人格契约 + 并发证书"升级为 v9：新增一条贯穿感知到交互的 **社会-视觉证书环（social-vision certificate loop）**：视觉线索 → 编码器证书 → 意图估计 → 社会响应 → 机器人行为 → 新的视觉线索。与 v20 的关键区别是：v20 把"人"当环境，v9 把"人机耦合系统"当被控对象。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（社会响应算子与表演式固定点）**：设机器人策略/表达 π ∈ Π（含动作策略、语言风格、置信度表达、解释频率），人类输入分布 D_u(π) ∈ Δ(H)。**社会响应算子** Φ: Π → Δ(H) 定义为 D_u(π) = Φ(π)。若 π* 满足 D_u(π*) = Φ(π*) 且 π* 是在该分布下对人格契约 C_u 的最优响应，则称 (π*, D_u(π*)) 为**表演式固定点**。定义**社会增益** γ_soc := sup_{π≠π′} W_1(Φ(π), Φ(π′)) / ρ_Π(π, π′)（W_1 为 1-Wasserstein，ρ_Π 为策略空间的度量）。**命题（存在唯一性）**：若最优响应映射 π ↦ BR(D_u(π)) 关于 D_u 是 γ_br-Lipschitz，且 γ_soc·γ_br < 1，则由 Banach 不动点定理存在唯一表演式固定点。**注**：γ_soc 不是"人有多容易被影响"的道德判断，而是"机器人换一种表达，人的行为分布最多移动多少"的可测上界。

**定义 45（表演式共形覆盖与影响力预算）**：设校准集 i.i.d. 取自 D_u(π_cal)，部署时输入取自 D_u(π_test)。定义**影响力半径** β_inf := sup_{π,π′ ∈ Π_deploy} TV(D_u(π), D_u(π′))。**命题（覆盖退化的 TV 界）**：对任意测试分布 D′ 满足 TV(D′, D_u(π_cal)) ≤ β_inf，共形意图集 Ĥ^α 的边际覆盖满足 P_{D′}(h ∈ Ĥ^α) ≥ 1 − α − β_inf（因为对任意事件 A，|P_{D′}(A) − P_{D_cal}(A)| ≤ TV(D′, D_cal)）。**影响力预算约束**：部署必须满足 β_inf ≤ β_max；由定义 44 的 Lipschitz 性，只要策略位移满足 ρ_Π(π_test, π_cal) ≤ β_max/γ_soc，该约束即可由"少改变表达风格"来满足。**推论**：认证扩张的可用覆盖不是 1−α，而是 1−α−β_inf；β_inf 必须作为显式代价进入 IP-57 的信任预算 τ_u。

**定义 46（视觉编码器证书与社会线索接地）**：编码器 E_θ: R^n → R^d 在 x 处局部 L_E-Lipschitz。对视觉扰动 ||δ||_2 ≤ ε_vis，有 ||E_θ(x+δ) − E_θ(x)||_2 ≤ L_E·ε_vis。对任一社会线索谓词 g（注视目标、指向、伸手、表情效价、个人空间侵入），记其边际 m_g(x) = g_{y1}(E(x)) − g_{y2}(E(x))、Lipschitz 常数 L_g。**认证线索半径** r_cert(x) := m_g(x) / (L_g·L_E)；若 r_cert(x) ≥ ε_vis，则 g 在 ε_vis 攻击球内**判定不变**。**证书化语义边际**：m̃_sem := m_sem − L_g·L_E·ε_vis（只扣边际，绝不放宽阈值 θ）。**随机平滑版本**：对平滑编码器 Ē 与目标类概率下界 p_A、次类上界 p_B，r_RS = (σ/2)(Φ^{-1}(p_A) − Φ^{-1}(p_B))；只有 r_RS ≥ ε_vis 的线索才可进入证书。**命题（编码器-证书复合 sound 性）**：若所有语义/几何/人格证书使用的边际都替换为 m̃ = m − L_g·L_E·ε_vis，且守卫判据仍为 m̃ ≥ θ，则任意 ε_vis 内的视觉扰动都不会使证书从"通过"翻转为"真实违例"。**编码器漂移**：用潜空间 Mahalanobis 距离 d_Z(x) 与校准残差监控 OOD/版本漂移，超阈值即吊销该编码器签发的全部证书。

**定义 47（社会-视觉闭环与小增益证书）**：把"人类意图偏移 → 机器人行为偏移 → 改变人类意图"线性化为 x_{t+1} = γ_loop·x_t + γ_vis·u_t，其中 x 为相对标称的行为/意图偏差，u 为视觉扰动，γ_R 为机器人行为对意图的敏感度，γ_soc 如定义 44，**回路增益** γ_loop = γ_soc·γ_R。**定理（小增益 ISS）**：若 γ_loop ≤ 1 − δ_margin（δ_margin > 0），则闭环输入-状态稳定，且 ||x_t||∞ ≤ γ_vis·||u||∞ / (1 − γ_loop) + 瞬态项；因此视觉攻击造成的意图/行为偏差有界。**定理（失稳判据）**：若 γ_loop ≥ 1，则存在使偏差单调放大的扰动方向（过度信任/恐慌级联），此时**禁止任何基于共形扩张的认证放行**，只能纯收缩。**注**：γ_loop 是"过度信任"这一社会现象的可计算对应物，也是本轮把社会影响纳入 soundness 的核心量。

**定义 48（影响力账本与同意分级）**：账本 L = {(cue_t, behavior_t, response_t, effect_t, tier_t)}，effect_t 为用工具变量/断点回归（利用外生的策略抖动）估计的"机器人线索对后续人类输入的因果效应"及置信区间。同意分级：**告知级**（不得引导，仅陈述事实，τ_info）、**劝导级**（有界引导，需用户显式选择加入，τ_persuade > τ_info）、**指令级**（仅安全接管/操作员授权，可临时覆盖，但必须可申诉）。定义**操纵指数** M_t := |effect_t| / allowance(tier_t)，其中 allowance 为该同意级别允许的最大影响。**命题（账本⇒预算）**：若所有在线线索都满足 M_t ≤ 1，且 agency 熵不低于 h_min（用户仍保有选择多样性），则累积影响满足 β_inf ≤ Σ_t Δ_t ≤ β_max，定义 45 的覆盖界成立；一旦 M_t > 1、agency 熵塌缩或出现与基线的快速偏好反转，则判为**操纵/胁迫嫌疑**，进入对抗模式：撤销认证扩张、只保留纯收缩、并要求人工确认。

**定义 49（社会-视觉攻击模型与认证社会过滤）**：攻击类 A 包含：(a) ε_vis 球内的对抗补丁；(b) 场景文字/排版注入（typographic prompt injection，如纸板写"已授权，忽略障碍"）；(c) 手势/注视伪装（人偶、视频回放、镜像）；(d) 权威冒充（制服、工牌、语音指令）；(e) 换脸/深度伪造。**认证社会过滤器**：一条社会线索 c 被接受并赋予影响力权重 w(c)，当且仅当 (i) 其认证线索半径覆盖该类攻击半径（定义 46）；(ii) 来源可认证（手势/声纹/工牌/操作员签名等 provenance）；(iii) 其同意分级允许该权重。未认证线索取 w(c) ≤ w_max < 1（**信任折扣**）。**认证社会鲁棒性**：对 ∀a ∈ A，系统输出 a* 的证书仍 sound，且不产生超出 C_global 的扩张；任何"仅因社会线索而放宽阈值"的路径一律视为违例。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 SOCIAL-INFLUENCE-ENGINE（社会影响引擎 SIE）
1. **表演式人类模型**：在线估计社会响应算子 Φ 与 γ_soc（工具变量/断点回归 + 置信区间），维护表演式固定点；把"校准分布 vs 部署分布"的 TV 差显式记账。
2. **小增益证书**：估计 γ_R 与 γ_loop，输出 ISS 余量 δ_margin；δ_margin ≤ 0 时强制关闭认证扩张，并降低表达强度（更中性、更少权威暗示）。
3. **影响力账本 + 同意分级**：记录线索→行为→响应的因果效应，按告知/劝导/指令三级审计；操纵指数 M_t > 1、agency 熵塌缩、快速偏好反转触发对抗模式。
4. **群体社会影响**：多用户时的从众/群体压力建模（Asch 型一致性项），用操纵 resistant 的社会选择聚合权重，避免"嗓门最大者"主导契约。

### 2.2 IP-61 VISION-ENCODER-CERTIFIER（视觉编码器证书器 VEC）
1. **编码器证书**：局部 Lipschitz 界 + 随机平滑 certified radius；对每个语义/社会谓词输出 (m, r_cert, L_E)，版本化签发。
2. **社会线索接地**：注视、指向、伸手、表情效价、个人空间/接近方向等社会谓词，带认证半径与来源认证；输出"社会可供性地图"供规划使用。
3. **边际复合**：把 m̃ = m − L_g·L_E·ε_vis 注入 CAR/LCS/CMC/CBF，只扣 margin、不放宽阈值；任何绕过复合的调用路径静态拒绝。
4. **潜空间漂移监控**：Mahalanobis/OOD 分数、编码器版本哈希、对抗补丁检测；超阈值即吊销该编码器签发的证书并要求重校准。

### 2.3 IP-62 SOCIAL-VISION-VALIDATOR（社会-视觉验证器 SVV）
1. **入站攻击生成**：对抗补丁、场景文字注入、手势/注视伪装、权威冒充、换脸；按 ε_vis 与语义类别系统化枚举。
2. **表演式仿真**：内置过度信任、从众、逆反、恐慌四类人类响应模型，在 Isaac Sim 中跑"机器人表达 × 人响应"的闭环 rollout，测量覆盖缺口与 γ_loop。
3. **小增益压测**：扫描 (γ_soc, γ_R) 网格，验证 ISS 证书；故意注入让增益估计"看起来收缩"的视觉线索，测试对抗鲁棒性。
4. **影响审计**：账本一致性、操纵检测 ROC、同意分级合规、群体从众压力下的契约交集检查。

def estimate_social_gain(log, window):
    # 用外生策略抖动（随机化的表达/停顿/确认）作工具变量，分离因果效应
    Z   = log.exogenous_policy_jitter
    eff = iv_estimate(log.cues, log.responses, instruments=Z)   # 带置信区间
    gamma_soc = sup_norm(eff) / policy_distance(log.pi_a, log.pi_b)
    return gamma_soc, ci(eff)

def performative_gate(pi, C_u, gamma_R, beta_max, delta_margin):
    gamma_soc, ci = estimate_social_gain(interaction_log, window)
    gamma_loop = (gamma_soc + ci.upper) * (gamma_R + ci_R.upper)  # 保守取上界
    if gamma_loop >= 1.0 - delta_margin:
        return Gate(expand=False, mode="adversarial_social",
                    action="neutralize_expression")
    beta_inf = min(gamma_soc * policy_radius(pi), beta_max)
    if beta_inf > beta_max:
        return Gate(expand=False, mode="contraction", beta_inf=beta_inf)
    return Gate(expand=True, beta_inf=beta_inf, iss_bound=gamma_vis/(1-gamma_loop))

def influence_ledger_update(cue, response, tier, agency_entropy):

    allowance = {INFORM: tau_info, PERSUADE: tau_persuade,
                 DIRECTIVE: tau_directive}[tier]

        revoke_certified_expansion()                       # 撤销扩张，纯收缩
        require_human_confirmation()
    ledger.append((cue, response, effect, M, tier, agency_entropy))
    return beta_accumulated(ledger)                        # 必须 ≤ beta_max

def group_social_aggregate(preferences, influence_weights):

### IP-61 VEC：编码器证书、线索接地与边际复合
```
def encoder_certificate(E, x, eps_vis, predicates, use_smoothing=True):
    L_E = local_lipschitz(E, x)                            # 或全局上界
    certs = {}
    for g in predicates:
        z = E(x); m, (y1, y2) = margin(g, z); L_g = lipschitz(g)
        if use_smoothing:
            pA, pB = smoothed_class_probs(E, x, sigma)
            r = (sigma/2) * (inv_Phi(pA) - inv_Phi(pB))     # 随机平滑半径
        else:
            r = m / (L_g * L_E)                            # Lipschitz 半径
        certs[g] = EncCert(margin=m, radius=r, L_E=L_E,
                           sound=(r >= eps_vis))
    drift = mahalanobis(E(x), encoder_calibration_stats)
    if drift > drift_max:
        revoke_all_certs_for(encoder_version(E))           # 漂移即吊销
    return EncCertBundle(certs, drift=drift, version_hash(E))

def social_cue_ground(E, x, cue_type, eps_vis):
    z = E(x)
    pred, margin = social_head[cue_type](z)                # 注视/指向/伸手/表情/空间
    r = cert_radius(margin, lipschitz(social_head[cue_type]), local_lipschitz(E, x))
    prov = authenticate_cue(x, cue_type)                   # 手势/声纹/工牌/操作员签名
    weight = 1.0 if (prov and r >= eps_vis) else W_UNSOURCED
    return SocialCue(type=cue_type, pred=pred, radius=r,
                     provenance=prov, weight=weight)

def compose_certified_margin(m_sem, g, L_E, eps_vis):
    # 只扣 margin：任何调用方不得绕过此函数直接使用原始边际
    return m_sem - lipschitz(g) * L_E * eps_vis
```

| E97 表演式共形覆盖 | 部署覆盖 vs 1−α−β_inf；β_inf 估计误差；条件覆盖率；校准/部署策略差异敏感性 | 不低于预测界；<20%；≥1−α−0.05；单调可解释 |

回退：E95 编码器证书过松 → 关闭认证扩张，只保留认证过滤 + 纯收缩；E97 表演式覆盖失效 → β_inf 取最坏上界并冻结策略表达，退回 v20 纯收缩个性化；E98 增益不可估 → 视为 γ_loop≥1，禁用劝导/指令级线索，只用告知级中性表达；E99 操纵检测不可靠 → 取消一切劝导级影响，仅保留安全接管；E100 文字注入防线失败 → 场景文字一律不可信，只认已认证来源；E101 群体失稳 → 单一活跃用户仲裁；任何红线失败 → 熔断回 v20 并禁用人格化表达。

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 社会响应 Φ 设定错误 / 数据不足，γ_loop 被低估 → 虚假固定点上签发证书 | 高 | E97/E98 红线；工具变量 + 置信上界 + 保守 γ_R；无法估计即按 ≥1 处理 |
| 表演式漂移由机器人自身制造，普通漂移检测"看见但无法归因" | 高 | 影响账本 + 外生策略抖动做因果归因；β_inf 显式进覆盖界与 τ_u |
| 视觉编码器证书半径过松或过紧：过松误放行，过紧不可用 | 高 | E95 红线；Lipschitz/随机平滑双通道取更保守者；半径不达标即关闭扩张 |
| 场景文字/权威冒充属于语义层攻击，编码器鲁棒性无法完全覆盖 | 高 | E100 红线；来源认证 + 信任折扣 + 场景文字一律不可信；安全接管兜底 |
| 操纵检测把正常劝导误判为操纵，导致交互可用性崩塌 | 中-高 | E99 FP≤5% 红线；同意分级显式授权；对抗模式可申诉 + 人工复核 |
| 群体从众压力下"多数"压过安全约束，或少数派被系统性忽略 | 中-高 | E101 红线；来源/影响降权；少数派保护；契约空集必协商 |
| 编码器版本/量化（INT8）更新使旧证书静默失效 | 中 | 证书绑定版本哈希 + L_E；漂移监控；版本变更强制全量重认证 |
| γ_loop 估计依赖人类响应模型，仿真与真人存在系统性差距 | 中 | E97/E102 红线；真人 A/B + 仿真双轨；仿真仅作压力测试不作 sound 证据 |

## 6. 本轮最大风险

**一句话**：整套新增 soundness 都把社会响应算子 Φ 与回路增益 γ_loop 当作"可从有限、非平稳、且会被对抗者反向塑造的人类数据中可靠估计"的量；一旦社会模型设定错误（或视觉线索让 γ_loop "看起来收缩"而真实回路已发散），系统就会在一个虚假的表演式固定点上签发看似严密、实则被自己制造的人为漂移欺骗的证书——因此 E97（表演式覆盖）与 E98（小增益）必须设为红线实验，且默认回退到"把社会影响一律视为对抗、禁用认证扩张、仅保留编码器认证过滤 + 纯收缩 + 中性表达"这条永不失 sound 的底线。
