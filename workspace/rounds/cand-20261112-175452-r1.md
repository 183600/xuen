# 第 62 轮（承接第 61 轮「ESEC 具身语义进化闭环」IP-173~182；本轮灵感：「流匹配策略」×「应用落地」）

> 第 61 轮用 USR 把场景/意图/阻抗/证据压进共享语义空间，用 MEL 提供零样本物理先验，用 DMS 做执行接地的多轮对话，用 SRT-Dual 解耦语义流与实时流。但**四个落地级硬伤**已经暴露：
> 1. **语义→阻抗是「点投影」而非「轨迹生成」**：投影头 Π: ℝ^d_us → K_safe 把整段交互压成一个瞬时阻抗点，**丢失了阻抗轨迹的时间结构与多模态性**。「轻触」与「稳住」可能对应两条不同的 K(t) 轨迹，Π 只能给出二者的平均值；一旦意图是双峰的，点映射必然落在两峰之间的低概率谷底。
> 2. **语义锚点切换造成阻抗跳变**：语义流 10–100Hz、实时流 1–10kHz，锚点每更新一次，Π 的输出就整体替换一次。第 61 轮的「保守扩展」只是过期后的补偿，**没有从机制上保证锚点变化 → 阻抗变化的连续性**，接触任务中最危险的就是这种阶跃。
> 3. **语义-控制映射不可证**：2 层 MLP 的 Π 既无 Lipschitz 常数、也无采样误差界，USR 的 ℒ_align 是启发式 MSE。**「语义条件满足」与「阻抗合法」之间没有可检验的推理链**，所谓 J_sem_exec 的语义一致性只到嵌入空间，没有落到动力学轨迹。
> 4. **全栈无法落地**：MEL 约 2GB / ~200ms，USR+MEL+DMS 加在一起无法上机器人机载算力；缺少蒸馏、量化、分级降级、影子/金丝雀、现场漂移监控与回滚。**研究结论没有「部署包络」的定义**——不知道在哪个任务/场景/硬件子集上可用，也不知道何时必须拒绝执行。

## 0. 直觉与动机

**灵感 1（流匹配策略 → 语义条件阻抗轨迹生成 FMIP）**
直觉：不要再让 Π 把语义「压」成一个阻抗点，而是学一个**条件速度场** v_θ(K_τ, τ | c)，把「保守安全阻抗」的基分布沿一条概率路径搬运到「语义期望的阻抗轨迹」分布。关键转换：动作不再是 K∈ℝ^d，而是**整条轨迹** K(·) = (K_p(τ), K_d(τ), F_max(τ), …)，τ 是流时间而非物理时间。
三个直接收益：a) **多模态被保留**——基分布采不同的 K_0，就能得到「轻触」与「稳住」两条不同的轨迹；b) **时间结构被保留**——流匹配输出的是连续轨迹，天然满足阻抗调度的平滑性；c) **语义条件只改变速度场**——c 的连续变化经 ODE 积分后成为轨迹的连续扰动，而不是输出点的切换。

**灵感 2（流匹配策略 → 随时流执行 ASFE）**
直觉：流匹配的 ODE 可以**边积分边执行**。实时流每个 tick 只推进一步 ODE，输出当前 K_τ；语义流异步更新条件 c。两个时间尺度不再靠「锚点版本号」硬同步，而是靠**流时间 τ** 自然耦合：语义流改的是速度场，实时流走的是积分路径。
安全性由两道闸门保证：每一步积分后做**安全投影 SPS**（投影到 ERTC/物理/CBF 可行域），并保留保守 fallback。可证性由 **C_flow** 给出：给定速度场 Lipschitz 常数 L_v 与步长 h，积分误差有闭式上界，**采样步数从证书推导，而不是靠调参**。

**灵感 3（应用落地 → 边缘流蒸馏 EFD）**
直觉：落地不能跑 2GB 的 MEL。把「教师流」的多步 ODE 轨迹蒸馏成「学生流」1–4 步：用 reflow / 一致性蒸馏学 K_0 → K_1 的短路径，再 INT8 量化 + 剪枝。关键是把**蒸馏误差与量化误差显式写进部署证书**：δ_edge = δ_distill + δ_quant，若 δ_edge ≤ δ_tol 才允许进入机载 Tier-1。
分层落地：Tier-2 教师（工作站/停靠时异步跑，~200ms）、Tier-1 学生（机载 GPU/NPU，20–50ms）、Tier-0 安全盾（MCU/实时核，<1ms，无大网络）。

**灵感 4（应用落地 → 部署包络与现场证书 DEP）**
直觉：落地不是「移植一次」，而是**在一个明确包络内持续认证**。定义部署包络 E = (任务集 T, 场景集 Z, 硬件 H, 安全等级 S, 时延 L, 内存 M, 功耗 P, 覆盖率 ρ)。部署证书 J_deploy 把 J_sem_exec、流证书 C_flow、蒸馏误差、包络覆盖率、现场漂移绑成一条可审计链。**出包络 ⇒ 降级或拒绝执行**，而不是悄悄失效。这把「研究 demo」和「可交付产品」区分开。

**灵感 5（合流 → 风险感知流采样 RFS + 七维预算 PCE++++++）**
直觉：流采样本身有随机性，直接执行可能踩到低概率危险轨迹。于是采样 M 条候选轨迹，经安全盾过滤，按「任务收益 − 风险 − 成本」选择，用 conformal prediction 给风险上界。PCE++++++ 把 B_flow（积分步数、采样数、投影迭代、速度上限）纳入认知预算：预算耗尽时**先减采样数，再减步数，再切学生，最后冻结到保守解**，安全永不降级。

## 1. 形式化定义（定义 173–184）

**定义 173（语义条件流匹配阻抗策略 FMIP）** 阻抗轨迹策略定义为五元组 F = (𝒦, C, p_0, p_1, v_θ)：
- **阻抗轨迹空间**：𝒦 = 𝒦_p × 𝒦_d × 𝒦_f × …，K = (K_p, K_d, F_max, α_null, …) ∈ 𝒦；轨迹 K(τ) ∈ 𝒦，τ ∈ [0,1] 为流时间
- **语义条件**：c = (scene_emb, intent_emb, φ_phys, U_ep, U_al) ∈ C
- **基分布**：p_0(K_0 | c) = N(K_cons(c), Σ_0(c))，K_cons 为保守安全阻抗（高阻尼、低刚度）
- **目标分布**：p_1(K_1 | c) 为示教 / EEIS 解 / 仿真安全轨迹的经验分布（可多峰）
- **概率路径**：K_τ = (1−τ)K_0 + τK_1，目标速度 u_τ = K_1 − K_0
- **CFM 损失**：
  ```
  ℒ_FM(θ) = E_{c,K_0,K_1,τ} ‖ v_θ(K_τ, τ, c) − (K_1 − K_0) ‖²_W
            + λ_sem ‖ E_impedance(K_1) − (α·scene_emb + β·intent_emb) ‖²
  ```
- **推理**：解 ODE dK/dτ = v_θ(K_τ, τ, c)，K(0)=K_0~p_0，输出 K(1) 或整条 K(τ)
- **多模态性**：若 p_1(·|c) 有多个峰，则不同 K_0 样本收敛到不同峰，FMIP 不做平均
- **与 Π 的关系**：Π 是 FMIP 的**退化特例**（N=1、Σ_0→0、p_1 为 δ 分布）

**定义 174（随时流执行 ASFE）** 实时流第 j 个 tick 的阻抗更新：
```
Δt = 1/f_rt,  h_j = clip(Δt / T_flow, h_min, h_max),  τ_0 = 0
K̃_{j+1} = K_j + h_j · v_θ(K_j, τ_j, c_j)          # 显式 Euler（可在 Tier-0 用 1 步）
K_{j+1} = P_{𝒦_safe(c_j)}(K̃_{j+1})               # 安全投影（定义 176）
τ_{j+1} = τ_j + h_j
if τ_{j+1} ≥ 1:                                   # 轨迹重启：交叉淡入而非硬切
    K_{j+1} ← (1−β)·K(1) + β·K_0^new,  β ∈ [0, 0.5]
c_j ← read_anchor()                                # 零阶保持，异步、非阻塞
```
**连续性引理（直觉版）**：若 v_θ 对 K 为 L_v-Lipschitz、对 c 为 L_c-Lipschitz，则相邻 tick 的锚点变化满足
```
‖K_{j+1}(c) − K_{j+1}(c′)‖ ≤ (1 + h_j L_v)·‖K_j(c) − K_j(c′)‖ + h_j L_c·‖c − c′‖
```
即**锚点阶跃被积分器低通**；当 h L_v < 1 且 v_θ 对 K 收缩时，扰动按 (1+h(L_v−κ)) 衰减。这是「语义更新不产生阻抗跳变」的机制性来源。

**定义 175（流匹配证书 C_flow）** 可检验的采样误差承诺：
```
C_flow = (L_v, L_c, h, N, ε_ode, ε_proj, v_cap, fallback_flag)
显式 Euler 局部截断误差： e_loc ≤ (h²/2)·max_τ ‖K″(τ)‖
全局误差上界：          e_glob ≤ ((e^{L_v} − 1)/L_v)·(h/2)·max_τ ‖K″(τ)‖ + ε_proj
选步数：                N* = min{ N : e_glob(N) ≤ ε_tol }
Valid(C_flow) ⇔ e_glob ≤ ε_tol ∧ ε_proj ≤ ε_proj_tol ∧ max‖v_θ‖ ≤ v_cap
触发 fallback ⇔ max‖v_θ‖ > v_cap ∨ 在线误差估计 e_est > ε_tol ⇒ K ← K_cons(c)
```
**要点**：N 是证书的输出而不是超参；安全盾保证「即使积分有界误差，输出仍在 𝒦_safe 内」。

**定义 176（安全投影盾 SPS）** 阻抗层的最后一道物理闸门：
```
𝒦_safe(c) = { K : K_p ∈ [k_min, k_max], K_d ∈ [d_min, d_max],
                  F_max ≤ μ_fric · N_normal · margin,
                  h_cbf(K) ≥ 0,  ERTC 约束 }
P_𝒦(u) = argmin_{K∈𝒦_safe} ‖K − u‖²_W        # box/线性约束 ⇒ 闭式 clip 或小 QP
离散 CBF 约束：h_cbf(K_{j+1}) ≥ (1 − γ)·h_cbf(K_j)
若 𝒦_safe(c) = ∅ 或投影不可行：K_{j+1} ← K_last_safe，并触发 DMS 澄清/降级
保证：K_{j+1} ∈ 𝒦_safe 且 ‖P_𝒦(u) − u‖ ≤ ε_proj
```
**语义-物理冲突检测**：若某语义条件 c 使 𝒦_safe(c) 为空，说明「意图在物理上不可执行」，必须回到 DMS 重协商，而不是让投影器胡乱裁剪。

**定义 177（边缘流蒸馏 EFD）** 把教师流压成机载学生流：
```
教师轨迹：{(K_0^m, K_1^m)}_{m=1..M} ~ FMIP
Reflow / 一致性蒸馏：student v_φ，N_s ∈ {1, 2, 4}
ℒ_distill = E‖K_1^teacher − K_1^student‖²
          + λ_traj Σ_k ‖K_{k/N_s}^teacher − K_{k/N_s}^student‖²
INT8 量化：Q(v_φ)，δ_quant = E‖Q(v_φ) − v_φ‖
边缘误差：δ_edge = δ_distill + δ_quant
准入：δ_edge ≤ δ_tol ⇒ 允许进入 Tier-1 部署包络
```

**定义 178（部署包络 DEP）** 落地的最小可认证单元：
```
E = (T, Z, H, S, L_max, M_max, P_max, ρ_min)
T：任务分布；Z：场景分布；H：硬件（CPU/GPU/NPU 型号与算力）；
S：安全等级（如 ISO/TS 15066 协作机器人限值）；L/M/P：时延/内存/功耗上限；
ρ_min：最小覆盖率
覆盖率：ρ(E) = P_{t~T, z~Z}[ success ∧ safe ∧ latency≤L_max ∧ mem≤M_max ∧ power≤P_max ]
In-Envelope(x) ⇔ x ∈ T×Z×H ∧ 资源约束满足
```

**定义 179（部署证书 J_deploy）** 现场可审计的落地凭证：
```
J_deploy = (J_sem_exec, C_flow, δ_edge, E, ρ̂_lcb(E), d_field,
            build_hash, jitter_p99, power_p99)
Valid(J_deploy) ⇔ Valid(J_sem_exec) ∧ Valid(C_flow)
  ∧ δ_edge ≤ δ_tol
  ∧ ρ̂_lcb(E) ≥ ρ_min                 # 覆盖率下置信界，非点估计
  ∧ d_field ≤ τ_drift                # 现场分布漂移
  ∧ jitter_p99 ≤ J_max ∧ power_p99 ≤ P_max
```
ρ̂_lcb 用 Clopper–Pearson 或 conformal 下界，**禁止用有限现场测试的均值冒充覆盖率**。

**定义 180（影子-金丝雀-回滚协议 SCR）** 把「上线」变成受控实验：
```
Shadow：学生与教师并行，只记录不执行
        Δ_shadow = E‖K^student − K^teacher‖ + 1[safety_violation]
Canary：按比例 p 上线，监控序列 (success, safety, latency)
Sequential test：H0 无退化 vs H1 退化（SPRT / Bayesian 后验）
Rollback：d_field > τ_drift ∨ safety_event ∨ ρ̂_lcb < ρ_min ⇒ 回滚到上一有效 J_deploy
Data flywheel：失败样本 → 重训/重蒸馏 → 重新认证 → 再金丝雀
```

**定义 181（风险感知流采样 RFS）** 用采样换安全边际：
```
采样：K^{(m)} ~ FMIP(c), m = 1..M
安全过滤：S = { m : K^{(m)} ∈ 𝒦_safe(c) }
若 S = ∅ ⇒ fallback K_cons(c) 并告警
风险估计：R(K) = max(0, −h_cbf(K)) + q_{1−α}(conformal 残差)
效用：U(K) = task_progress_est(K) − λ_r·R(K) − λ_c·cost(K)
选择：K* = argmax_{K∈S} U(K)
Conformal 保证：若校准集可交换，则 P(violation) ≤ α
```

**定义 182（PCE++++++ 七维认知-流预算）** 在第 61 轮六维预算上增加「流采样/积分」维度：
```
B_cog6 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_flow)
B_flow = (N_max, tol, M_max, proj_iters_max, v_cap)
cost_flow = λ_N·N/N_max + λ_M·M/M_max + λ_proj·iters/proj_iters_max + λ_v·max‖v‖/v_cap
voi_cog6 = VOI_meta − Σ_i cost_i
降级阶梯：M 减半 → N 减半 → 切学生 N_s=1 → 冻结到 K_cons
安全不降级：无论预算如何耗尽，SPS 与 fallback 始终生效
```

**定义 183（流匹配部署闭环 FMDL）** 把第 61 轮 ESEC 延伸到部署：
```
FMDL(M, E):
  # 语义流（异步）
  c ← SemanticPipeline(V, T, P, L, M.anchor)
  # 生成-执行流（异步/实时）
  K_traj ← FMIP.sample(c)                 # 教师或学生
  K_traj ← SPS.project(K_traj, c)
  K* ← RFS.select(K_traj, c)
  C_flow ← build_flow_cert(K_traj, c)
  # 实时流
  K_{j+1} ← ASFE.step(K*, c); dispatch(K_{j+1})
  EV_exec ← wait_contact()
  # 落地流
  student ← EFD.distill(FMIP); δ_edge ← EFD.eval(student)
  J_deploy ← build_deploy_cert(M.J_sem_exec, C_flow, δ_edge, E, ρ̂_lcb, d_field)
  if not Valid(J_deploy): SCR.rollback() ∨ shrink_envelope(E) ∨ retrain()
  return K*, J_deploy
```

**定义 184（落地可行性判定 DFC）** 「能不能落地」的形式化回答：
```
给定硬件 H 与基础包络 E，落地算子
  Land(θ, H) = { E′ ⊆ E : Valid(J_deploy(θ, H, E′)) }
落地前沿  E* = argmax_{E′ ⊆ E} [ ρ(E′)·value(E′) ]  s.t. Valid(J_deploy(θ,H,E′))
若 Land(θ,H) = ∅ ⇒ 该 (任务, 场景, 硬件) 组合不可落地：需换硬件、降级或拒绝交付
```
**推论（落地不是布尔值）**：落地是一个**包络族**——同一模型可以在 E₁ 内有效、在 E₂ 外无效；产品交付必须附带 E*，而不是一句「已支持」。

## 2. 关键算法伪代码

### IP-183 FMIP（语义条件流匹配阻抗策略）

```python
class FlowMatchingImpedancePolicy:
    def __init__(self, d_K=8, d_us=256, hidden=256, n_layers=4):
        self.d_K, self.d_us = d_K, d_us
        self.cond_encoder = ConditionEncoder(d_us, hidden)
        self.v_net = VelocityNet(d_K, hidden, n_layers)   # 输入 (K_tau, tau, c_emb)
        self.sem_head = ImpedanceSemanticHead(d_K, d_us)   # E_impedance
        self.W = torch.ones(d_K)                           # 加权范数

    def cfm_loss(self, c, K0, K1, tau):
        K_tau = (1 - tau) * K0 + tau * K1
        target_v = K1 - K0
        c_emb = self.cond_encoder(c)
        pred_v = self.v_net(K_tau, tau, c_emb)
        L_fm = ((pred_v - target_v) ** 2 * self.W).mean()
        # 语义对齐正则：让生成的阻抗可被 USR 解释
        scene_emb, intent_emb = c['scene_emb'], c['intent_emb']
        L_sem = F.mse_loss(self.sem_head(K1),
                           0.5 * scene_emb + 0.5 * intent_emb)
        return L_fm + 0.1 * L_sem

    @torch.no_grad()
    def sample(self, c, N=16, M=1, K_cons=None, sigma0=0.05):
        c_emb = self.cond_encoder(c)
        K0 = K_cons + sigma0 * torch.randn(M, self.d_K)
        K = K0.clone()
        h = 1.0 / N
        traj = [K.clone()]
        for k in range(N):
            tau = torch.full((M, 1), k * h)
            K = K + h * self.v_net(K, tau, c_emb)
            traj.append(K.clone())
        return K, torch.stack(traj, dim=1)   # (M, N+1, d_K)
```

### IP-184 ASFE（随时流执行）

```python
class AnytimeStreamingExecutor:
    def __init__(self, policy, shield, budget, f_rt=1000, T_flow=1.0):
        self.policy, self.shield, self.budget = policy, shield, budget
        self.f_rt, self.T_flow = f_rt, T_flow
        self.K = None
        self.tau = 0.0
        self.c = None

    def reset(self, K0):
        self.K, self.tau = K0.clone(), 0.0

    def tick(self, c, dt=None):
        dt = dt or 1.0 / self.f_rt
        if self.K is None:
            self.K = self.shield.conservative(c)
        # 预算驱动步数：预算紧时降 N，仍受 C_flow 的 ε_tol 约束
        h = min(self.budget.h_max, max(self.budget.h_min, dt / self.T_flow))
        self.c = c
        K_raw = self.K + h * self.policy.v_net(self.K, self.tau, c)
        K_safe = self.shield.project(K_raw, c)          # IP-185
        v_norm = (K_safe - self.K).norm() / h
        if v_norm > self.budget.v_cap:                  # 速度异常 ⇒ 保守回退
            K_safe = self.shield.conservative(c)
        self.K, self.tau = K_safe, self.tau + h
        if self.tau >= 1.0:                             # 交叉淡入重启，避免硬切
            K_new, _ = self.policy.sample(c, N=self.budget.N, M=1,
                                          K_cons=self.shield.conservative(c))
            beta = min(0.5, self.budget.beta)
            self.K = (1 - beta) * self.K + beta * K_new[0]
            self.tau = 0.0
        return self.K
```

### IP-185 SPS（安全投影盾）

```python
class SafetyProjectionShield:
    def __init__(self, phys_cfg, ertc, gamma=0.1, eps_proj=1e-3):
        self.cfg, self.ertc, self.gamma = phys_cfg, ertc, gamma
        self.eps_proj = eps_proj

    def safe_set(self, c):
        phi = c['phi_phys']                      # (mu, k_stiff, eta_damp, sigma)
        mu = phi['mu_fric']
        return SafeSet(
            k_p=(0.2 * phi['k_stiff'], phi['k_stiff']),
            k_d=(phi['eta_damp'], 3.0 * phi['eta_damp']),
            f_max=mu * self.cfg.N_normal * self.cfg.margin,
            ertc=self.ertc.current_constraints())

    def project(self, K, c):
        S = self.safe_set(c)
        if S.is_empty():
            raise InfeasibleSemanticCondition(c)   # 交给 DMS 重协商
        # box 约束闭式 clip；CBF/ERTC 线性约束用极小 QP
        K_clip = K.clamp(S.lo, S.hi)
        K_proj = solve_small_qp(K_clip, S.linear_constraints)
        # 离散 CBF 保底
        if self.cbf(K_proj, c) < (1 - self.gamma) * self.cbf(K, c):
            K_proj = self.minimal_correction(K, c)
        return K_proj

    def conservative(self, c):
        S = self.safe_set(c)
        return (S.lo + 0.1 * (S.hi - S.lo))   # 贴近下界：低刚度、高阻尼
```

def risk_aware_sample(policy, shield, c, M=8, alpha=0.1, lam_r=1.0):
    K_all, traj = policy.sample(c, N=policy.N, M=M)
    safe = [K for K in K_all if shield.in_safe_set(K, c)]

**正确性定理（Flow-Deploy-Safe）**：
假设 A61–A70 继续成立，并新增：
- **(A71) FMIP**：v_θ 对 K 为 L_v-Lipschitz、对 c 为 L_c-Lipschitz；CFM 训练损失收敛到 ε_FM；p_1 的支撑包含于 𝒦 的紧子集。
- **(A72) SPS**：𝒦_safe(c) 非空且凸；投影误差 ≤ ε_proj；CBF h 连续可微。
- **(A73) EFD**：蒸馏+量化误差 δ_edge 可在留出集上校准；N_s 步学生的端点误差 ≤ δ_edge。
- **(A74) DEP**：现场测试样本在包络内可交换；覆盖率下界 ρ̂_lcb 的置信水平为 1−α。
- **(A75) SCR**：漂移监测与回滚为原子操作；影子数据与线上同分布。
- **(A76) RFS**：conformal 校准集与运行时样本可交换。

则：
1. **轨迹连续性**：锚点变化经 ASFE 积分后至多产生 O(h·L_c·δ_c) 的阻抗扰动；不存在锚点切换导致的阶跃（连续性引理）。
2. **可证采样**：C_flow 有效 ⇒ 生成轨迹与理想流场轨迹的误差 ≤ ε_tol；SPS 有效 ⇒ 每条输出轨迹逐点属于 𝒦_safe。
3. **部署安全**：在包络 E 内，若 J_deploy 有效，则现场安全违规概率 ≤ α + O(δ_edge) + O(覆盖率估计误差)。
4. **落地可判定**：Land(θ,H) ≠ ∅ ⇔ 存在非空包络使 J_deploy 有效；E* 给出最大可交付包络。
5. **预算安全**：任一 B_cog6 维度耗尽只降低采样数/步数/学生精度或冻结到保守解，**不会绕过 SPS 与 fallback**。

```python
class FlowMatchingImpedancePolicy:
    def __init__(self, d_K=8, d_us=256, hidden=256, n_layers=4):
        self.cond_encoder = ConditionEncoder(d_us, hidden)
        self.v_net = VelocityNet(d_K, hidden, n_layers)
        self.sem_head = ImpedanceSemanticHead(d_K, d_us)
        self.W = torch.ones(d_K)

    def cfm_loss(self, c, K0, K1, tau):
        K_tau = (1 - tau) * K0 + tau * K1
        pred = self.v_net(K_tau, tau, self.cond_encoder(c))
        L_fm = ((pred - (K1 - K0)) ** 2 * self.W).mean()
        L_sem = F.mse_loss(self.sem_head(K1),
                           0.5 * c['scene_emb'] + 0.5 * c['intent_emb'])
        return L_fm + 0.1 * L_sem

    @torch.no_grad()
    def sample(self, c, N=16, M=1, K_cons=None, sigma0=0.05):
        c_emb = self.cond_encoder(c)
        K = K_cons + sigma0 * torch.randn(M, self.d_K)
        traj, h = [K.clone()], 1.0 / N
        for k in range(N):
            tau = torch.full((M, 1), k * h)
            K = K + h * self.v_net(K, tau, c_emb)
            traj.append(K.clone())
        return K, torch.stack(traj, dim=1)
```

### IP-184 ASFE

```python
class AnytimeStreamingExecutor:
    def __init__(self, policy, shield, budget, f_rt=1000, T_flow=1.0):
        self.policy, self.shield, self.budget = policy, shield, budget
        self.f_rt, self.T_flow, self.K, self.tau = f_rt, T_flow, None, 0.0

    def tick(self, c, dt=None):
        dt = dt or 1.0 / self.f_rt
        if self.K is None:
            self.K = self.shield.conservative(c)
        h = min(self.budget.h_max, max(self.budget.h_min, dt / self.T_flow))
        K_raw = self.K + h * self.policy.v_net(self.K, self.tau, c)
        K_safe = self.shield.project(K_raw, c)
        if (K_safe - self.K).norm() / h > self.budget.v_cap:
            K_safe = self.shield.conservative(c)
        self.K, self.tau = K_safe, self.tau + h
        if self.tau >= 1.0:
            K_new, _ = self.policy.sample(c, N=self.budget.N, M=1,
                                          K_cons=self.shield.conservative(c))
            beta = min(0.5, self.budget.beta)
            self.K = (1 - beta) * self.K + beta * K_new[0]
            self.tau = 0.0
        return self.K
```

## 3. 三层落地路线图

| 层级 | 硬件 | 运行内容 | 时延目标 | 失败时 |
|---|---|---|---|---|
| Tier-2 教师 | 工作站/边缘服务器 | 全量 MEL + FMIP 多步 + DMS | 100–200ms | 异步；不影响实时环 |

**落地准则**：Tier-2 负责「理解」，Tier-1 负责「生成」，Tier-0 负责「不越线」。任何一级的失败都不能穿透到下一级的安全约束。

## 5. 本轮最大风险

**一句话**：本轮把「可证」从嵌入空间推进到动力学轨迹，但**证书的可信度完全依赖假设 L_v、δ_edge、ρ̂_lcb 在真实世界成立**；一旦接触动力学使 Lipschitz 常数暴涨、量化在边缘样本上退化、或现场覆盖率被小样本高估，「可证落地」就会变成「纸面安全」——必须用在线 e_glob 抽查、SPS 硬投影、影子/金丝雀/回滚把证书持续锚定到现场。
