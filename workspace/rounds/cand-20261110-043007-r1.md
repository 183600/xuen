# 第 1 轮 · 具身接触证书 v18：混合接触流匹配 × 具身可达包络 × 落脚契约（四层架构 v6）

> 承接第 40 轮 v17（可认证流匹配执行 × 度量语义几何锚定 × 证书驱动课程引擎）。本轮灵感词「机器人、四足机器人」把焦点从「动作空间里的光滑 ODE 证书」推向「具身接触流形上的混合证书」：v17 的证书在最危险的触地/打滑瞬间恰好缺少定义。本轮新增 IP-51/52/53，并升级 IP-48/49/46/47/45/39/43/50/38；不推倒既有层级。

## 0. 直觉与动机

**灵感 1（机器人 → 证书要落在身体的可达集里）**：v17 的 CertFlow 证明的是「采样器输出 x 与理想 ODE 解 x* 的距离」，但 x 是动作块，不直接等于关节位置、力矩与接触力。一个数值上很紧的流证书，完全可能对应机器人根本执行不了的力矩序列。机器人学的基本事实是：**可行性是几何的**（关节限位、自碰撞、力矩锥），**安全性是动力学的**（CoM/角动量、接触力、支撑多边形）。因此第一直觉：证书的最终裁决权应交给具身可达包络 E，流证书只是 E 的输入；用可微 QP 把流动作投影回 E，并把投影残差 r_E 作为证书的一部分。这样「可认证执行」才真正落到机器人身上，而不是停在动作向量里。

**灵感 2（四足机器人 → 步态是混合自动机，不是一条 ODE）**：四足运动由离散接触模式 σ 组成（哪几条腿着地、处于步态相位的哪一段），模式内是连续流，模式间是冲击型 reset map。v17 的收缩定理在模式内部成立，但触地瞬间速度不连续，Lipschitz/Gronwall 论证恰好在最关键处失效。直觉：把策略拆成「模式条件速度场 v_σ」，证书也拆成「每模式收缩 κ_σ + 守卫裕度 χ + reset 收缩 ρ」。用多 Lyapunov 函数 + 平均驻留时间把局部证书缝成全局证书，让流匹配的连续性与腿式运动的混合性各得其所。步态不再只是控制参数，而是**证书的时间调度表**。

**灵感 3（四足机器人 → 落脚点是一次可签约的接触）**：四足每一步都在「签一份接触契约」：脚落在哪个区域、地形坡度法向如何、摩擦锥能开多大、会不会打滑、支撑多边形还剩多少裕度、落点是否可捕获。v17 的 C_ms 只看语义与漂移球，没有把摩擦、支撑、打滑纳入类型。直觉：落脚区域 F 本身就是一个证书对象，与 ESDF 地形几何、材料摩擦下界、本体滑移检测、捕获点裕度绑定；「步」技能的组合就是落脚契约的链接。这把「几何证书」推进到「接触几何证书」。

**三者耦合**：具身包络回答「能不能执行」，混合证书回答「切换时稳不稳」，落脚契约回答「下一步站不站得住」。三者共同把 v17 的动作空间证书升级为**具身接触证书**，覆盖四足最危险的两类事件：触地冲击与脚底打滑。

## 1. 形式化定义

**定义 27（混合接触自动机）**：四足技能 h 诱导一个混合自动机 H = (M, X, F, E, G, R)。模式 σ = (S_σ, φ_σ) ∈ M，S_σ ⊆ {FL, FR, RL, RR} 为支撑足集合，φ_σ 为步态相位区间；连续状态 x = (q, q̇, λ, l)，q 为广义坐标，λ 为接触力，l 为质心动量。模式内 ẋ = F_σ(x, u)，u 为关节指令；切换边 e = (σ, σ') ∈ E 带守卫 G_e = {x : c_e(x) = 0} 与 reset x⁺ = R_e(x⁻)。模式序列由步态时钟 σ(t) 给出。

**定义 28（混合接触证书 CertH）**：CertH = {(V_σ, κ_σ, c_σ, CertFlow_σ)}_{σ∈M} ∪ {(χ_e, ρ_e, b_e)}_{e∈E} ∪ {T_dwell}。令 e_t = x − x_ref 为跟踪误差，V_σ(e) = eᵀP_σe，认证要求：
- 模式内耗散：V̇_σ ≤ −κ_σV_σ + c_σ；
- 守卫裕度：计划切换时 c_e(x) ≥ χ_e > 0；
- reset 收缩：V_{σ′}(R_e(x⁻)) ≤ ρ_eV_σ(x⁻) + b_e，ρ_e < 1；
- 平均驻留：任意窗口内切换间隔的平均值 ≥ T_dwell。

**定理（混合证书的组合界）**：设 κ_min = min_σ κ_σ，c_max = max_σ c_σ，ρ_max = max_e ρ_e，b_max = max_e b_e，α = ρ_max·e^{−κ_min·T_dwell}。若 α < 1 且上述四条成立，则对任意 t：

V(e(t)) ≤ e^{−κ_min·t}V(e(0)) + c_max/κ_min + (ρ_max·c_max/κ_min + b_max)/(1 − α)。

证明：在单个模式内用比较引理得 V(t) ≤ e^{−κ_minΔ}V(t_k) + c_max/κ_min；跨 reset 用 ρ_e/b_e 放缩，得到 V(t_k⁺) ≤ α^k V(0) + β(1−α^k)/(1−α)，其中 β = ρ_max·c_max/κ_min + b_max；再对末段模式积分即得。该界把「模式内稳定」与「切换稳定」分开认证，避免在冲击瞬间误用光滑 Lipschitz 假设。

**定义 29（具身可达包络与投影证书）**：E = {(q, q̇, τ, λ) : q ∈ Q_lim，τ ∈ T_lim，自碰撞距离 ≥ d_min，λ ∈ K_μ，质心动力学可行，CoM 投影 ∈ 支撑多边形}。全身控制器 g 把动作 a 映到 (q, q̇, τ, λ)。定义投影 Π_E(a) = argmin_{y∈Ê, g(a)≈y} ‖a − a_flow‖²_Σ（Ê 为 E 的局部凸外包），投影证书 CertEmb = (r_E, ε_E, E_version)，r_E = ‖a_flow − Π_E(a_flow)‖_Σ。只有当 r_E ≤ ε_E 时，流证书才被允许签发给总线。

**定义 30（落脚接触契约 C_ft）**：C_ft = (F, μ_lo, p_slip, m_sup, m_cap)。F ⊆ SE(2) 为由 ESDF 认证的落脚区域（坡度、粗糙度、净空约束）；μ_lo 为摩擦系数 (1−δ) 置信下界（材料先验 + 滑移观测的后验）；p_slip 为滑移概率上界；m_sup 为在质心动力学可行集内、接触旋量到摩擦锥/支撑多边形边界的最小裕度；m_cap 为捕获点裕度。契约满足当且仅当：落点 ∈ F ∧ λ ∈ K_{μ_lo} ∧ p_slip ≤ δ_s ∧ m_sup ≥ 0 ∧ m_cap ≥ 0。

**定义 31（接触课程赤字）**：D_ct(τ) = D_v17(τ) + Σ_{j∈{guard,slip,foot}} w_j·max(0, 1 − m_j(τ)/c_j)，其中 m_guard = min_e χ_e 为最小守卫裕度，m_slip = 1 − p̂_slip/δ_s 为滑移余量，m_foot = |F|/|F_ref| 为可落脚区域丰度。课程带在 v17 的随机逼近基础上增加「接触模式轴」，使训练采样优先落在「守卫/摩擦/落脚裕度接近违约」的边界带。

## 2. 三大产出设计

### 2.1 IP-51 HYBRID-CONTACT-CERTIFIED-FLOW（混合接触流匹配）
1. 骨干：v_θ(x, τ; c, s, σ, g) 共享主干 + 模式条件化（FiLM/门控/模式嵌入），每个模式一个速度头；CFM 损失按模式分桶，触地样本单独加权。
2. 证书：逐模式认证 L_vσ、κ_σ、ε_odeσ、N*_σ；守卫与 reset 通过采样 + 集中不等式给 χ_e、ρ_e、b_e 的置信界；组装 CertH。
3. 执行：步态时钟给出 σ(t)，每模式按其 N*_σ 自适应积分；切换前检查守卫裕度，切换后检查 reset 残差；任一超界 → 降级步态（trot→crawl）或触发 IP-38。
4. 步态即证书调度：不同步态对应不同的 CertH 组合；调度器在「速度收益」与「证书裕度」之间做约束优化，禁止进入未认证模式。
5. 与 v17 衔接：CertFlow 作为 CertH 的模式内子证书；IP-43 韵律 s 升级为步态相位/接触时序的条件变量。

### 2.2 IP-52 EMBODIMENT-ENVELOPE-CERTIFICATE（具身可达包络）
1. 可微全身 QP：min ‖a − a_flow‖²_Σ s.t. 关节限位、力矩限位、自碰撞距离、摩擦锥、质心动力学、支撑多边形；非凸项用局部凸外包 + 连续凸化。
2. 投影残差证书：r_E ≤ ε_E 才放行；ε_E 由流证书误差预算反推（投影非扩张性保证误差不被放大）。
3. 形态契约：E 由机器人形态参数（连杆、质量、执行器极限）版本化；换机型只换 E，证书可迁移，MetaAdapter 负责参数对齐。
4. 分级失效：r_E 进入软区 → 降速/加宽支撑/重投影；硬区 → 直接恢复，不把不可执行动作送到电机。

### 2.3 IP-53 FOOTHOLD-CONTACT-CONTRACT（落脚接触契约）
1. 地形认证：ESDF 查询坡度、法向、粗糙度、净空；语义标签给材料摩擦先验；不认识的材质一律用保守 μ_lo。
2. 滑移后验：本体残差 r_slip = ‖v_foot_measured − v_foot_kinematic‖，Beta-Bernoulli 更新滑移率，给 p_slip 上界；检测到滑移立即作废当前契约。
3. 接触裕度：在质心动力学可行集上计算摩擦锥/支撑多边形最小裕度 m_sup；用捕获点/可达集给 m_cap。
4. 契约组合：步技能按落脚契约链接，链断则换步态、换落点或回退；契约类型进入 IP-45 总线，成为路由与熔断的第五类触发器。

## 5. 本轮最大风险

**一句话**：整套混合证书的全局结论依赖「模式切换能被及时检测且守卫裕度为正」这一条；真实四足触地时刻与摩擦状态是模糊且突变的，漏检一次早触地或打滑，就会让多 Lyapunov 的驻留时间与 reset 收缩假设在最危险的瞬间失效——因此模式检测延迟与守卫裕度必须作为本轮第一守门指标（E73/E74）。

## 2. 关键算法

### IP-51 混合接触流匹配（伪代码）
```
def certify_hybrid_flow(v_theta, modes, delta=0.01):
    certs = {}
    for sigma in modes:
        v_sigma = mode_head(v_theta, sigma)
        L_sigma = refine_critical_layers_LipSDP(power_iter_Lip(v_sigma))
        kappa_sigma = lower_bound_one_sided_lip(v_sigma, samples=10k, delta)
        N_sigma = min N s.t. eps_ode(N; L_sigma, kappa_sigma) <= eps_tol
        certs[sigma] = CertFlow(L_sigma, kappa_sigma, N_sigma)
    return CertH(certs, guard_chi, reset_rho, dwell_T)

def hybrid_stream_execute(v_theta, c, s, gait_clock, certH):
    sigma, tau = gait_clock.current()
    x = prior_sample(p0)
    while not horizon_done:
        for k in range(certH.modes[sigma].N_star):
            x = rk4_step(mode_head(v_theta, sigma), x, tau, cond=(c,s,sigma))
            tau += 1 / certH.modes[sigma].N_star
        sigma_next, _ = gait_clock.next()
        if guard_margin(sigma, sigma_next, x) < certH.chi:
            return IP38.fallback(gait='crawl')         # 守卫失败即降级
        x = reset_map(sigma, sigma_next, x)
        if reset_residual(x) > certH.b_reset:
            RCA.recertify(gait_clock)                   # 重置超界即重颁
        sigma, tau = sigma_next, gait_clock.phase(sigma_next)
        if finalized(x, overlap=H//2):
            yield emit(x_tail)                          # 按模式切块流式发射
```

### IP-52 具身包络投影（伪代码）
```
def embodiment_project(a_flow, state, E):
    a_hat = solve_qp(
        min ||a - a_flow||^2_Sigma
        s.t. joint_limits(state, a),
             torque_limits(state, a),
             self_collision_distance(state, a) >= d_min,
             lambda in K_mu,
             centroidal_dynamics(state, a, lambda) == 0,
             com_projection(state, a) in support_polygon(state))
    r_E = ||a_flow - a_hat||_Sigma
    return a_hat, r_E

def certified_execute(a_flow, state):
    a_hat, r_E = embodiment_project(a_flow, state, E)
    if r_E <= eps_E:
        return a_hat                                  # 非扩张投影，流证书保持
    if r_E <= eps_E_soft:
        return slow_down_and_reproject(a_hat)         # 降速/加宽支撑后重投影
    return IP38.recover(state)                        # 硬失效 -> 恢复，不送电机
```

### IP-53 落脚接触契约（伪代码）
```
def foothold_contract(esdf, material_prior, slip_post, state):
    F = []
    for p in sample_footholds(esdf, state, K=32):
        slope, normal, rough = esdf.query(p)
        mu_lo = material_prior.lower_bound(p) * slip_post.scale()
        m_sup = contact_wrench_margin(state, p, mu_lo)
        m_cap = capturability_margin(state, p)
        if slope <= slope_max and rough <= rough_max \
           and m_sup >= 0 and m_cap >= 0:
            F.append((p, mu_lo, m_sup, m_cap))
    return ContactContract(F, slip_post.p_slip_upper(), delta_s)

def update_slip(slip_post, contact, v_meas, v_kin):
    r = ||v_meas - v_kin||
    slipped = r > r_thresh
    slip_post.update(slipped)                         # Beta-Bernoulli 后验
    if slipped:
        invalidate_contract(contact)                  # 立即作废该落脚契约
        IP38.recover()

def step_compose(contracts, state):
    chain = []
    for C in contracts:
        if chain and not reachable(chain[-1].F, C.F):
            continue
        if C.m_sup < 0 or C.p_slip > delta_s or C.m_cap < 0:
            continue
        chain.append(C)
    return chain if chain else gait_change_or_backtrack(state)
```

|---|---|---|

| 混合流采样 | 每个模式 N*_σ ≤ 8 次前向；整段 = Σ_σ N*_σ | **定理**：α<1 时 V(t) ≤ e^{−κ_min t}V(0)+c_max/κ_min+(ρ_max c_max/κ_min+b_max)/(1−α) |

## 5. 风险与缓解

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 接触事件检测延迟/误检 → 守卫裕度失真 | 高 | 高频本体 + 早触地检测 + 守卫不确定区间；E73/E74 第一守门 |
| 混合证书过保守 / 切换过频致驻留违约 | 高 | 仅对关键关节严证；最小驻留 + 限制步态切换率；平均驻留认证 |
| 包络 QP 在高速/崎岖地形不可行 | 高 | 分层松弛 + 降速 + 加宽支撑 + IP-38；E75 守门 |
| 摩擦先验错误 → 落脚契约「假安全」 | 高 | 未知材质一律保守 μ_lo；在线滑移后验；E76 守门 |
| 接触课程组合空间爆炸 | 中 | 因子化采样（步态×地形×落脚丰度各 4 档），不做联合笛卡尔积 |
| 仿真-现实接触时序/摩擦差距 | 高 | 接触参数域随机化 + 硬件在环 + 在线残差监测；E78 守门 |
| C_ms/C_ft 组合类型爆炸 | 中 | 仅对任务相关子空间做蕴含检验，接触类型限制为有限枚举 |

## 6. 本轮最大风险

**一句话**：整套混合证书的全局结论依赖「模式切换能被及时检测且守卫裕度为正」这一条；真实四足触地时刻与摩擦状态是模糊且突变的，漏检一次早触地或打滑，就会让多 Lyapunov 的驻留时间与 reset 收缩假设在最危险的瞬间失效——因此模式检测延迟与守卫裕度必须作为本轮第一守门指标（E73/E74）。
