# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「碰撞检测」×「鲁棒性」）

> R69 把不确定性一分为二，并让闭环学会「问」：aleatoric 收紧，epistemic 去交互消解，信息动作也要过 C-RAS-WM 认证。但它在最要命的一层上仍然天真：它把**安全认证**当成一个不透明、精确、免费的**布尔预言机**——`certified_prefix` 返回一个 k，就仿佛「前 k 步不相撞」是世界的真相。
>
> 真实的碰撞检测从来不是布尔值：它是**离散时间、离散几何、带数值误差的近似**。采样点之间的隧穿、薄障碍与 SDF 分辨率、透明/反光/可变形物体、感知的遮挡与偏置，都会让一个「检查通过」的前缀在真世界里撞上。更根本的是，R69 的所有不确定性都是**关于动作模态**的，而真正致命的歧义是**关于几何**的：这条缝过不过得去？这个杯子在不在我以为的位置？这块地承不承重？
>
> 本轮两个灵感正好补上这块地基：
> - **碰撞检测**告诉我们，安全不是一个点，而是**连续时间 × 连续几何上的间隙下界**；可以证明的只有「保守的下界」，不是「精确的事实」。
> - **鲁棒性**告诉我们，对未来的信念要取 **min over worlds**，而不是 expectation；并且要给「认证器自己失效」留后路——要的是**可审计的失败语义**，而不是「尽量不撞」。
>
> 核心命题：**把 R69 的「点态安全认证」升级为「区间化、保守、对几何歧义集全称量化、并带预言机自检与可恢复核的鲁棒安全层」；几何歧义不靠更强的策略消掉，而靠受认证的交互去收紧其上界，收不紧就退到有界违规的安全港。** 命名 **CLEAR-RAS**（Certified Lower-bound Envelope with Adversarial Robustness）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我脚下这一步，究竟离碰撞有多远——这个『远』，我凭什么证明**」。

## 0. 直觉与动机

**灵感 1（碰撞检测 → 安全的答案必须是区间，不是布尔）**
直觉：离散 CCD 只在采样时刻问「撞没撞」。两次采样之间，机械臂可能已经穿过一张纸、一根细杆、一片玻璃。真正能签发的证书是「在整个时间区间内，在任何与感知一致的几何上，间隙的下界 ≥ 0」，即一个带证明的**间隙下界**与**最早碰撞时间下界**。R69 的 k 只是「采样到第 k 步没撞」；CLEAR 的 k 是「存在一条保守推进证明，使前 k 步连续无碰」。把 `Safe` 从点态判断变成区间对象，是整轮的地基。

**灵感 2（鲁棒性 → 对所有可信世界取最坏，而不是对平均世界取期望）**
直觉：R69 的 VoI 与风险都是期望。但安全失效是尾部事件，世界（或对手）恰恰会把细杆放进你预测的空隙里。鲁棒的姿态是：感知给出场景 ĝ 与一个**标定过的误差上界场 ε(x)**，认证必须对 𝒢(ε) 中**每一个**世界成立。数学上这恰好等价于「把障碍膨胀 ε，再在膨胀世界上做普通 CCD」——鲁棒性被归约成一次几何操作，其代价可度量（鲁棒性价格 PoR）。这让我们不必对世界采样，只需把不确定性搬到几何里。

**灵感 3（碰撞检测也是测量 → 最近距离是被忽视的证据通道）**
直觉：R69 的探针是「信息动作」，但它没把碰撞检测的输出当证据。其实 SDF 的最近距离、时间一致性、接触事件都是极强的几何观测：预测间隙 vs 实测间隙的残差 r_col，能区分「新障碍 / 移动物体 / 世界模型错 / 行为异常」。把这条通道与 R69 的 (r_res, Δa) 拼成三通道，第一次能把**感知错、行为错、几何错**分开。

**灵感 4（交互与碰撞的张力 → 想看就必须靠近，想安全就必须远离）**
直觉：要消解几何歧义，最有效的动作往往正是**靠近看、伸手触**——而这恰恰最危险。R69 的 MINT 只算 VoI−成本，没有算「这次探询消耗了多少安全余量」。CLEAR 把信息动作的价值改写为**每单位风险暴露的安全信息价值 SVoI**，并要求每个探询轨迹本身通过 CCE。有收益但过不了认证的动作，不是「冒险去做」，而是「换一种更安全的看法（换视角 / 绕行 / 等待）」。

**灵感 5（鲁棒性 → 对「鲁棒证书的生成器」也要鲁棒）**
直觉：如果碰撞检测器本身会隧穿、会因 SDF 分辨率把薄片抹掉、会因点云孔洞把墙看成通道，那么再漂亮的 CCE 也是假证书。安全必须**分层冗余**：数值域自检（速度×步长 vs 最小厚度）、第二通道（不同偏置的保守界）、观测一致性（预测距离 vs 实际回波/接触）。三通道不全一致，证书只能降为 `Unknown`——**绝不允许 `Unknown` 被当成 `Safe`**。这是 R69 双通道异常检测思想在安全侧的镜像。

**灵感 6（鲁棒性 → 安全不是一个前缀，而是一个能永远待下去的状态集）**
直觉：R69 只检查「下一段前缀安全吗」。但存在一种更隐蔽的失效：这一步安全，却把你带进一个**下一步再也找不到安全动作**的状态（走进死胡同、停在斜坡、探针缩不回）。真正的鲁棒性要求「**总有一步，既安全，又还能继续安全**」——控制不变集 / 生存核。这把安全从「单步前缀」升级为「归纳不变式」。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（CLEAR-RAS 总览）** CLEAR-RAS = (FLUID-RAS, GAS, CCE, RVI, SVoI, ORACLE-M, MRE)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **认证优先**：任何任务动作与信息动作，执行前必须持有 Valid 的 CCE；未认证动作只能被 MRE 替换，不得靠「降速后执行」绕过；
(iii) **全称鲁棒**：CCE 对几何歧义集 𝒢(ε) 全称量化（min over worlds），不是对点估计 ĝ 判断；
(iv) **生存性**：系统只在鲁棒生存核 𝒦_ε 内选择动作；离开 𝒦_ε 必须有可证明的有界退出契约（定义 319/324）。
R69 恰为 ε≡0、预言机 sound 且 𝒦_ε = 全状态空间 的边界情形。

**定义 311（几何歧义集 GAS）** 设感知场景为 ĝ，标定器给出空间变化的误差上界 ε: ℝ³→[0, ε_max]，使得对真实场景 g* 有 sup_x |sdf_g*(x) − sdf_ĝ(x)| ≤ ε(x)，以概率 ≥ 1−δ（概率鲁棒）或恒成立（最坏鲁棒）。定义 𝒢(ε) = { g : sup_x |sdf_g(x) − sdf_ĝ(x)| ≤ ε(x) }。ε(x) 可按物体类/区域/距离分层，但**安全认证必须用其上界，不能用均值**。

**定义 312（ε-膨胀世界）** ĝ⊕ε = { x : sdf_ĝ(x) ≤ ε(x) }。把「对 𝒢(ε) 的鲁棒碰撞」归约为「对膨胀世界的普通碰撞」：若 sdf 关于几何扰动 1-Lipschitz，则 sdf_g(x) ≥ sdf_ĝ(x) − ε(x)。因此 **CLEAR 的鲁棒认证 = 在 ĝ⊕ε 上做保守连续碰撞检测**。

**定义 313（连续碰撞证书 CCE）** 对轨迹 ξ_{[0,T]}，定义认证间隙下界
ρ_lo(ξ, ε) = inf_{t∈[0,T]} sdf_{ĝ⊕ε}(ξ(t))（用 conservative advancement 求下界），
与最早碰撞时间下界 TTC_lo。证书 CCE(ξ) = (ρ_lo, TTC_lo, ε_hash, checker_ver, margin)。值域三态 {Safe, Unsafe, Unknown}：
Safe ⇔ ρ_lo > 0 ∧ TTC_lo > T_react ∧ checker_ver；
Unknown ⇔ 预言机不在验证域或通道不一致。**Unknown 永不蕴含 Safe**。

**定义 314（隧穿安全条件）** v_max 为轨迹最大速度，w_min 为场景最小障碍厚度，Δt 为检测步长，L_sdf 为 SDF 的 Lipschitz 常数。若 Δt ≤ w_min / (v_max + v_margin) 且保守推进步长 h_j ≤ ρ_lo / L_sdf，则离散检测不漏检；否则隧穿风险 T_risk = v_max Δt / w_min ≥ 1，CCE 必须返回 Unknown。

**定义 315（安全储备）** S = TTC_lo − T_react − T_probe，其中 T_react 为制动/反应时间，T_probe 为（若计划了信息动作）探询到可回退点的时间。动作 Safe ⇔ S ≥ 0 ∧ ρ_lo ≥ ρ_min(kind)，ρ_min 对任务动作与信息动作分别设定（信息动作允许更小间隙，但必须可回退）。

**定义 316（鲁棒生存核 RVI）** 状态 x ∈ 𝒦_ε，当且仅当存在 u ∈ U 使得对所有 g ∈ 𝒢(ε)：(a) CCE(x→x') = Safe；(b) x' ∈ 𝒦_ε 且可递归保持。𝒦_ε 是最大鲁棒控制不变集的安全片段。动作约束：a_t ∈ U(x_t) ∩ {u : x_{t+1} ∈ 𝒦_ε}。

**定义 317（鲁棒安全过滤器 RSF）** 给定 R69 提议的任务动作 a 及其 λ 缩放，RSF 计算 CCE(a)。若 Safe，放行 a；若 Unsafe/Unknown，替换为 a' = argmax_{u∈U_feasible} ρ_lo(u)，其中 U_feasible = {u : x'∈𝒦_ε ∧ 可执行}。RSF 与 λ 正交：λ 调速度，RSF 调「去哪/停哪」；RSF 生效时 λ 取 R69 兜底值。

**定义 318（安全信息价值 SVoI）** 对候选信息动作 g：
SVoI(g) = [VoI(g) − c(g)] / (ρ_margin(g) + κ·exposure(g))，
s.t. CCE(g) = Safe ∧ x'∈𝒦_ε。ρ_margin(g) 为执行 g 后的最小认证间隙，exposure 为处于小间隙的时长。SVoI 是「每单位安全风险换来的消歧收益」。仅当 SVoI > 0 时交互；R69 的 MINT 是 ρ_margin→∞（风险不计）的退化。

**定义 319（最小风险退出 MRE）** 当 𝒦_ε 不可达或 ε 超界，定义
a_MRE = argmin_{a∈U} [ P_collide(a; 𝒢(ε)) + γ‖a − a_brake‖ + ζ·exposure(a) ]，
s.t. 执行约束与 CCE 的 Unknown 处理规则。MRE 必须给出有限退出时间 T_exit 与违规幅度上界 δ_grace；若不存在，进入 Emergency 停稳（定义 324-E）。

**定义 320（预言机鲁棒监视 ORACLE-M）** 三通道：
(a) **数值域**：T_risk < 1、h_j 满足引理 20、SDF 分辨率 ≥ w_min/2；
(b) **冗余界**：inflated mesh 与 α-shape/点云两套偏置不同的保守界，二者都 Safe 才 Safe；
(c) **观测一致性**：预测最近距离 d_pred 与实际回波/接触 d_obs 的残差 r_col 在标定带内。
任一条不满足 ⇒ checker_ver = False ⇒ CCE = Unknown。

**定义 321（几何主动探询 GEO-CIA）** 把 R69 定义 300 的证据集扩展为几何证据 {遮挡边界视差、最近距离回波、接触约束、时间一致性}；主动选对**安全相关几何**（局部 ε 大的区域、窄通道、薄障碍）判别力最大的动作：
g*_geo = argmax_g IG(ε_target; y_g | g) / risk(g)，且 g 的 CCE 必须 Safe。R69 的被动环一致性成为「不探询」特例。

**定义 322（鲁棒证书 J_CLEAR）** J_CLEAR = (J_FLUID, ε_field_hash, ρ_lo_min, S_min, T_risk_max, oracle_channels_agree, kernel_membership, PoR, degrad_state, clear_ver)。
Valid ⇔ Valid(J_FLUID) ∧ 所有执行动作（含信息动作）CCE=Safe ∧ ORACLE-M 一致 ∧ 动作后状态∈𝒦_ε（或 MRE 契约满足且 degrad_state 正确）∧ J_FLUID 的证据纪律未被几何动作绕过。

**定义 323（鲁棒性价格 PoR 与 ε 预算分配）** PoR(ε) = v_safe(ε) / v_safe(0)（同一任务在鲁棒/非鲁棒认证下的最大安全速度比）。总鲁棒预算 B_ε 把 ε 的收紧（更多感知/计算/探询）投到对 PoR 最敏感的区域（窄通道、薄障碍、高速段），最小化 ∫ PoR(x) dμ(x) s.t. 总计算/交互预算。低风险区允许较大 ε 省算力；瓶颈区必须收紧，否则 PoR 发散（定理 19）。

**定义 324（鲁棒退化状态机）** 三档，单调可越级、恢复需重新认证：
N（Normal）：ε 有效、oracle 一致、在 𝒦_ε；
D（Degraded）：ε 或 oracle 不可信 ⇒ 仅允许「认证的最保守动作」+ GEO-CIA 探询，禁新任务承诺；
E（Emergency）：无任何认证动作 ⇒ MRE/停稳，违规上界 δ_grace，暴露时间最小。
切换记录写入 J_CLEAR，并作为下一轮 ε 分配的先验。

**定义 325（碰撞-行为-感知三通道对偶）** 定义碰撞残差 r_col = |d_pred − d_obs|。三通道 (r_res, Δa, r_col) 的分离：
- (r_res↑, Δa≈, r_col≈) → 传感器自洽性下降（R68 通道）；
- (r_res≈, Δa↑, r_col≈) → 行为异常（R69 FMA）；
- (r_res≈, Δa≈, r_col↑) → 几何/世界模型错误（新障碍、移动物体、漂移地图）；
- 多通道同升 → 复合故障，直接 D/E 档。
这把 R69 定义 309 的二通道对偶升级为三通道分离。

```python
# IP-264 GAS：标定空间变化几何误差上界 ε(x)
class GeometryAmbiguitySet:
    def calibrate(self, calib_loader):
        # 按区域/物体类/距离分桶，取高概率上界（不是均值）
        self.eps_field = fit_upper_quantile(calib_loader, q=1 - DELTA)

    def inflate(self, scene_hat):
        return inflate_sdf(scene_hat, self.eps_field)   # ĝ⊕ε

# IP-265 CCE：膨胀世界上的保守连续碰撞检测
def certified_clearance(traj, scene_hat, eps_field):
    world = GeometryAmbiguitySet.inflate(scene_hat, eps_field)
    rho, ttc = conservative_advancement(world, traj, L_sdf)
    if not oracle_monitor.numeric_domain_ok(traj, world):
        return ("Unknown", rho, ttc)
    verdict = "Safe" if (rho > 0 and ttc > T_react) else "Unsafe"
    return (verdict, rho, ttc)

# IP-266 ORACLE-M：三通道预言机自检
def oracle_check(traj, scene_hat, d_pred, d_obs):
    numeric     = tunneling_risk(traj, scene_hat) < 1
    redundant   = (cce_bound_A(traj, scene_hat) >= 0 and
                   cce_bound_B(traj, scene_hat) >= 0)     # 两种偏置界
    consistent  = abs(d_pred - d_obs) <= col_res_band
    return numeric and redundant and consistent

# IP-267 RVI：鲁棒生存核（离线/低频，在线查表）
def in_viability_kernel(x, eps_field):
    return x in self.K_eps                              # lazy certification

# IP-268 SVoI：安全信息价值（替代 R69 裸 VoI）
def choose_safe_interaction(modes, geo, o, budget):
    best = None
    for g in geo_candidates(modes, geo):
        if not budget.allow(g):
            continue
        verdict, rho, ttc = certified_clearance(rollout(g), geo.scene, geo.eps)
        if verdict != "Safe" or not in_viability_kernel(next_state(g), geo.eps):
            continue
        voi  = geo_entropy(geo.eps) - expected_geo_entropy(geo.eps, g)
        risk = 1.0 / max(rho, RHO_EPS) + KAPPA * exposure(g)
        score = (voi - cost(g)) / risk
        if best is None or score > best.score:
            best = (g, score)
    return best if best and best.score > 0 else None

# IP-269 RSF：鲁棒安全过滤器（与 R69 的 λ 正交）
def robust_safety_filter(a, lam, state, geo):
    verdict, rho, ttc = certified_clearance(rollout(a, lam), geo.scene, geo.eps)
    if verdict == "Safe":
        return a, lam, "N"
    feasible = [u for u in feasible_actions(state)
                if certified_clearance(rollout(u), geo.scene, geo.eps)[0] == "Safe"
                and in_viability_kernel(next_state(u), geo.eps)]
    if feasible:
        return max(feasible, key=min_certified_clearance), LAM_CONSERVATIVE, "D"
    return minimum_risk_exit(state, geo), LAM_MAX, "E"

# IP-271 三通道故障分离
def classify_triad(r_res, a_score, r_col):
    flags = (r_res > TAU_RES, a_score > TAU_FMA, r_col > TAU_COL)
    if sum(flags) >= 2:      return "COMPOUND"      # 直接 D/E
    if flags[2]:             return "GEOMETRY"      # 走 GEO-CIA
    if flags[1]:             return "BEHAVIOR"      # R69 FMA
    if flags[0]:             return "SENSOR"        # R68 COF
    return "NOMINAL"

# IP-274 主闭环（继承 R69，仅在安全层插入 CLEAR）
def CLEAR_RAS_round(M, obs):
    z, o = M.mtm.forward(obs)
    c, U_cal, thr = M.cof.step(...)                    # R68 标定
    geo = M.gas.update(obs)                            # ε(x) 上界
    K = 4 if M.fmp.mode_head(z) >= TAU_MODE else 1
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(o, K))
    # 1) 三通道：几何残差优先决定是否先看/退档
    r_col = abs(M.wm.pred_clearance(o) - obs.min_range)
    fault = classify_triad(M.last_r_res, M.fma.score, r_col)
    # 2) 安全信息动作（SVoI），而不是裸 VoI
    g = (choose_safe_interaction(modes, geo, o, M.budget)
         if (U_epi > TAU_EPI and fault != "COMPOUND") else None)
    if g is not None:
        U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    # 3) 选模 + R69 风险缩放
    mode = select_mode(modes, U_epi)
    lam  = max(M.efs.risk_scale(...),
               lam_floor(U_ale + (U_epi if g is None else 0.0)))
    # 4) RSF：认证的是整条轨迹，不只是 λ 缩放
    a, lam, dstate = robust_safety_filter(mode.a, lam, o.x, geo)
    # 5) 证书 + 审计
    rho = min_certified_clearance(a, geo)
    M.vqa_i.submit_async(g, r_col, rho, dstate)
    return a, lam, mode, J_CLEAR(..., rho, dstate)
```

## 3. 推导

**引理 19（膨胀等价与鲁棒碰撞归约）** 设 |sdf_g(x) − sdf_ĝ(x)| ≤ ε(x) 对所有 g∈𝒢(ε) 成立。若 x 在膨胀世界之外，即 sdf_ĝ(x) > ε(x)，则对所有 g∈𝒢(ε)：sdf_g(x) ≥ sdf_ĝ(x) − ε(x) > 0。故在 ĝ⊕ε 上通过连续碰撞检测 ⇒ 对 𝒢(ε) 全称安全。系：**鲁棒认证无需对世界采样，只需一次几何膨胀**；其保守代价恰为 PoR。

**引理 20（离散 CCD 的无隧穿充分条件）** 若 w_min > (v_max + v_margin)·Δt，则相邻采样构型间的扫掠线段必然落入某个采样点的 ε-邻域，离散检测漏检率为 0；反之当 T_risk ≥ 1 时存在一条轨迹在两采样之间穿过薄障碍而任一采样点都不在其中，漏检概率随 T_risk 单调上升。按 h_j ≤ ρ_lo/L_sdf 做保守推进可把漏检压到 0。系：**ORACLE-M 的数值域监视是证书有效性的必要条件，不是工程优化**。

**引理 21（安全信息动作的收益-风险分解）** 在固定最小间隙 ρ_min 下，一次认证过的几何探询使目标区域误差从 ε 降到 ε'（ε'<ε），其期望风险下降 ≥ c·(ε−ε')·(1−e^{−ΔH_geo})；其自身附加碰撞风险 ≤ exposure·v/L_sdf · e^{−(ρ_min−ε)/σ_sdf}（随间隙指数衰减）。因此 SVoI>0 当且仅当「消歧收益 > 风险暴露」，且存在阈值 ρ_min* 使探询从「值」变「不值」。系：**越窄的通道越该先看后过，但只能在经认证的安全接近走廊里看**。

**引理 22（RVI 的归纳不变性）** 若 x_0∈𝒦_ε，且每步策略选择 u_t 使 x_{t+1}∈𝒦_ε 并满足 CCE=Safe，则对任意 g∈𝒢(ε) 与任意步数 T，轨迹无碰撞且始终留在 𝒦_ε。对 T 归纳即得。系：**安全性从「单步前缀」升级为「归纳不变式」**；R69 只检查前缀，可能进入一个下一步无安全动作的「安全陷阱」，RVI 排除之。

**定理 18（CLEAR 对 FLUID/R68 的严格包含）** 当 GAS 取 ε≡0 且关闭生存性约束（𝒦_ε := X）时，CLEAR 的认证与 FLUID 逐指令一致；当 ε>0 时，CLEAR 的可行动作集是 FLUID 可行动作集的子集（更保守），但每个动作带有对 𝒢(ε) 的全称安全保证；当保留 𝒦_ε 时安全集进一步收缩。故安全侧单调加强，效率损失由 PoR 精确计量。R68/R69 是 ε=0、无生存性约束的边界情形。

**定理 19（PoR 下界与窄通道相变）** 设通道净宽 w、感知误差上界 ε、反应时间 T_react。鲁棒通过的最大速度 v_safe(ε) ≤ (w−2ε)/T_react，非鲁棒 v_safe(0) ≤ w/T_react，故 PoR ≥ w/(w−2ε)。当 ε→w/2 时 PoR→∞：**通道窄到与感知误差同阶时，任何正速度都无法鲁棒通过**。此时唯一正确的选择是交互收紧 ε 或换路，而不是「更慢地硬挤」。系：交互的必要性有一个可计算相变阈值 ε* = w/2，而非拍脑袋的调度。

**定理 20（有界违规的优雅退化）** 若 MRE 可行且执行约束满足，则从任意初始状态出发，存在 T_exit ≤ T_max 使系统进入 𝒦_ε，且全程违规幅度（最大穿透深度 / 最小负间隙）≤ δ_grace；若 MRE 不可行，则 Emergency 停稳在 T_stop ≤ v_max/a_b 内完成且停稳终点被 CCE 认证。故 CLEAR 提供「可审计的有界失败」，而非 R69 的「未定义失败」。

## 6. 本轮最大风险

**一句话**：CLEAR-RAS 的全部保证押在「ε(x) 是真实误差的**上界**、且碰撞预言机是 sound 的」这两个前提上——**一旦 ε 被低估或 checker 发生隧穿，系统会签出一张看起来 Valid 的假证书，并因为「有证书」而比 R69 更快、更近、更自信地撞上去；也就是说，错误的间隙上界加上一个被信任的假证书，等于一张有执照的碰撞许可**。

**次级风险与缓解**：
1. **ε 场过度保守 → 系统寸步难行** → PoR-aware ε 分配 + 只在瓶颈区收紧（定义 323、E315）；
2. **RVI 计算昂贵（高维不可解）** → 离线近似 / 局部核 / lazy certification + 保守外逼近（定义 316、E311）；
3. **预言机冗余界同源失效**（两套界共享同一 SDF 误差）→ 强制不同偏置（网格 vs α-shape vs 触觉）并加观测一致性通道（定义 320）；
4. **退化状态被滥用为「合法停机」** → J_CLEAR 记录 degrad_state + 审计回灌，停机也须认证（定义 322/324、E307）；
5. **安全层拖垮实时性** → 增量 SDF 缓存 + 三档频率分离 + `Unknown` 时不重算而是直接保守替代（§4）。

```python
               lam_floor(U_ale + (U_epi if g is None else 0.0)))
    a, lam, dstate = robust_safety_filter(mode.a, lam, o.x, geo)    # 认证轨迹
    rho = min_rho(a, geo)
    M.vqa_i.submit_async(g, r_col, rho, dstate)
    return a, lam, mode, J_CLEAR(..., rho, dstate)
```

## 4. 推导

**引理 19（膨胀等价）** `|sdf_g−sdf_ĝ|≤ε` ⇒ 在 `ĝ⊕ε` 外 `sdf_g>0` 对所有 `g∈𝒢(ε)`。故鲁棒认证 = 一次几何膨胀上的普通 CCD；代价 = PoR。

**引理 20（无隧穿充分条件）** `w_min>(v_max+v_margin)Δt` ⇒ 离散 CCD 漏检为 0；`T_risk≥1` 时薄障碍存在正漏检且随 `T_risk` 上升；保守推进 `h_j≤ρ_lo/L_sdf` 可压到 0。系：ORACLE-M 的数值域监视是证书有效的必要条件。

**引理 21（安全信息动作）** 认证探询把 ε→ε' 的期望风险下降 ≥ `c(ε−ε')(1−e^{−ΔH_geo})`；自身风险 ≤ `exposure·v/L_sdf·e^{−(ρ_min−ε)/σ_sdf}`。故 SVoI>0 ⇔ 消歧收益 > 风险暴露；存在阈值 `ρ_min*`。系：窄通道先看后过，但只看在安全接近走廊内。

**引理 22（RVI 归纳不变性）** `x_0∈𝒦_ε` 且每步留在 `𝒦_ε` 且 CCE Safe ⇒ 任意 `g∈𝒢(ε)`、任意步数无碰撞。系：安全从单步前缀升为归纳不变式，排除安全陷阱。

**定理 18（严格包含）** ε=0 且 `𝒦_ε:=X` 时与 FLUID 逐指令一致；ε>0 时可行动作集 ⊆ FLUID 且带全称保证；保留 `𝒦_ε` 时进一步收缩。R68/R69 是 ε=0、无生存性约束的边界。

**定理 19（PoR 相变）** `PoR ≥ w/(w−2ε)`，`ε→w/2` 时发散：窄通道与误差同阶时任何正速度都不能鲁棒通过，只能交互或换路。给出可计算阈值 `ε*=w/2`。

**定理 20（有界违规）** MRE 可行 ⇒ `T_exit≤T_max` 内进 `𝒦_ε` 且违规 ≤ `δ_grace`；不可行 ⇒ 停稳 `T_stop≤v_max/a_b` 且终点被认证。CLEAR 给「可审计的有界失败」。

**预实验（本机 toy，非正式）** 用随机相位的离散采样轨迹（N=2×10⁵）验证引理 20：薄壁厚度 w∈{0.01,0.02,0.05}，令 `T_risk=vΔt/w`，实测隧穿漏检率与 `max(0, 1−1/T_risk)` 逐点吻合（`T_risk=2` → 0.500±0.001；`T_risk=5` → 0.799±0.001；`T_risk≤1` → 0）。这说明 **`T_risk≥1` 时离散 CCD 的漏检是结构性缺陷而非数值噪声**，ORACLE-M 的数值域门控是证书有效的必要条件，不是工程优化。

## 7. 最值得押注的点与最大风险

**最值得押注**：IP-265（CCE）+ IP-266（ORACLE-M）这一对——把「安全认证」从不可审计的布尔黑箱变成**带下界、带三态、带自检**的对象。它不依赖新数据、不改策略，只加固所有后续层共用的地基，且能直接用于现有 VLA/规划器的安全过滤。

**一句话最大风险**：全部保证押在「ε(x) 是真实误差上界、且碰撞预言机 sound」上——**一旦 ε 被低估或 checker 隧穿，系统会签出一张看起来 Valid 的假证书，并因为有证书而比 R69 更快更近更自信地撞上去；错误的间隙上界 + 被信任的假证书 = 一张有执照的碰撞许可**。

**次级风险与缓解**：ε 过保守使系统寸步难行（PoR-aware 分配，E315）；RVI 高维不可解（离线近似 + lazy certification，E311）；双冗余界同源失效（强制不同偏置 + 观测一致性，定义 320）；退化档被当合法停机（J_CLEAR 记录 + 审计回灌，E307）；安全层拖垮实时（增量 SDF + 三档频率分离，§5）。
