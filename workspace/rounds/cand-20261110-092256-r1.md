# 第 43 轮（新循环第 3 轮） · Cert-Curriculum 闭环：把「机器人基础模型」当课程提议者，把「证书裕度」当可验证的难度标尺（四层架构 v8）

> 承接第 42 轮 v19（Sim-Cert-RAG 飞轮）。第 42 轮把证书做成了「可进化资产」，但关系仍是「证书围着模型转」——机器人基础模型（RFM / VLA）只被当成一个待约束的黑箱策略，课程也只是从知识库里「检索相位序列」。本轮灵感词「课程学习」「机器人基础模型」把关系倒过来：**机器人基础模型是广度来源，课程学习是「广度→可靠性」的转换器，而证书裕度是课程难度的可验证标尺**。核心命题一句话：不要再用稀疏 reward 或人工经验去排课程，用「边际 m_lo(x) 离阈值 θ 有多近」来度量任务难度；不要一上来就让 RFM 直接上线，先用证书把它「最近发展区」里的任务筛出来、只在这些任务上微调、再反过来给模型开一张「能力证书」。

## 0. 直觉与动机

**灵感 1（课程学习 → 用「证书裕度」给难度下定义）**：人类学习不是随机刷题，而是在「跳一跳够得着」的区域练；机器人也一样。但经典 curriculum 用成功率 / reward 定义难度，reward 稀疏、噪声大、还可被策略 hack（reward hacking），难度的「排序」本身不可信。第 42 轮的证书恰好免费给了一个**稠密、单调、可验证**的难度信号：轨迹裕度 μ = min_t (m_lo(x_t) − θ)。裕度远大于 0 = 太简单（不学也安全）；裕度 < 0 = 已经越界（学不会，且危险）；裕度落在 **[0, δ] 的「证书前沿带」= 最近发展区**。于是课程调度从「调参玄学」变成「对证书裕度分位数做分层采样 + 优先回放」。这是把 Vygotsky 的 ZPD 直接写成一个可计算的判据。

**灵感 2（机器人基础模型 → 双重身份：课程提议者 + 被盾包裹的执行体）**：VLA（RT-2 / OpenVLA / π0 一类）给出语言条件下的通用操作先验，但它是黑箱、没有可靠不确定性、长尾会静默失败。它有两个别的东西给不了的身份：(a) **课程提议者**——用语言指令变异 + 场景/物体/动力学扰动，自动生成「证书前沿带」上的任务变体，替代人工设计课程表；(b) **执行体**——被证书盾（shield）投影后执行。关键在于：我们不是要「让 RFM 更安全」这一句空话，而是要**让 RFM 主动去补证书覆盖不到的盲区**，同时用慢证据防止它去钻证书的漏洞。

**灵感 3（反向飞轮 → 用证书产课程喂 RFM）**：第 42 轮是「模型产数据喂证书」；本轮补上反向回路「证书产课程喂模型」：RFM 提议任务 → 证书给难度与安全判据 → 课程筛选并微调 RFM → 证书重新刻画 RFM 的能力边界。这形成一个**对抗-合作闭环**。副产品是第 42 轮没有的东西：一张**能力证书 (competence certificate)**——对哪些 (指令, 状态) 该模型「被认证」、哪些必须「降级」、哪些必须「拒答」，在规划之前就把超域指令挡掉，而不是等它动了再靠 CAR 兜底。

**张力与真正的洞见**：课程学习若只最大化「前沿带任务上的成功率」，它会**主动搜索证书的漏洞**——因为把盾当对手、把 m_lo=θ 的边界当靶心，最省力的「提高成功率」方式往往是把任务挪到快证书误判的位置。这是极其危险的 Goodhart：越训练越自信，越自信越不安全。因此必须引入**双证书**：快证书 C_fast（L0/L1 运行时盾，保守、可能假阴性）负责实时拦截；慢证书 C_audit（仿真/实机回放的真值审计）负责给课程当裁判。**二者不一致的任务才是最高价值的课程样本**——它们要么训练模型，要么暴露快证书的假阴性并喂给 CEGAR 去修补。

## 1. 形式化定义（增量：定义 38–43）

**定义 38（证书裕度与可验证难度）**：给定指令 ℓ、环境 ψ、轨迹 τ=(x_0,…,x_H) 与基础模型 π_FM，定义轨迹裕度 μ(τ;π_FM)=min_{t=0..H}(m_lo(x_t)−θ(x_t))；在 π_FM 动作的 (1−α) conformal 动作集 A_α 上取最坏：μ(ℓ,ψ;π_FM)=min_{a_t∈A_α} μ(τ)。**任务难度** d(ℓ,ψ)=1−Pr_{D_sim}[μ(ℓ,ψ)≥0]。**证书前沿带** F_δ={(ℓ,ψ): 0 ≤ μ ≤ δ}（最近发展区）。**命题**：μ 关于动作扰动是 L_m-Lipschitz，故 d 的估计误差被 conformal 动作集直径界出；前沿带在难度空间是一个厚度可调的环。

**定义 39（证书课程分布与单调调度）**：课程 = 若干难度层 {D_k} 的混合 D_curr=Σ_k w_k D_k，层按 d 的分位数划分。调度规则：w_k ∝ (1/N_k)·1[ŝ_k∈[p_lo,p_hi]]（成功带 p_lo≈0.60、p_hi≈0.85，即「desirable difficulty」），且接受集满足**单调性** d_{k+1} ≥ d_k − ε_mono（只许变难，掉回简单层需冷却）。优先回放优先级 ρ(ℓ,ψ)=|μ−μ*|+λ_nov·novelty(ℓ,ψ)，μ* 为前沿带中心。**命题**：在单调调度下，课程对证书覆盖扩张的期望增益非负（potential-based shaping），且不会退化为「只刷简单题」。

**定义 40（双证书与不一致集）**：C_fast（L0/L1 运行时盾，保守、可能假阴性/假阳性）、C_audit（Sim/实机回放全量验证，慢而准）。**不一致集** D_disc = {τ: C_fast 接受 ∧ C_audit 拒绝}（安全悬案，喂 CEGAR 收紧 C_fast）∪ {τ: C_fast 拒绝 ∧ C_audit 接受 ∧ μ≥0}（可用性悬案，可放宽）。**pair-soundness**：若 P(D_disc) ≤ δ_pair 且 C_audit 在 A_α 上 sound，则盾后策略的违例概率 ≤ α+δ_pair。

**定义 41（Conformal 动作集与盾投影）**：A_α(o,ℓ)={a : s(o,ℓ,a) ≥ q_{1−α}}（s 为非一致性分数，校准集给分位数，覆盖 ≥1−α）。投影 Π_C(a)=argmin_{a'∈S_C}||a−a'||，安全集 S_C={a' : 存在证书见证使 rollout 满足 m_lo≥θ}。若 ||a−Π_C(a)||>ε_proj 则**弃权**（abstain → SafeStop/委派）。**定理**：在 exchangeability 与 C_audit sound 下，shielded π 的安全违例 ≤ α+δ_pair，且弃权率是 ε_proj 与分布偏移的单调函数。

**定义 42（能力证书 meta-certificate）**：CC:(ℓ,x)↦{certified, degraded, refused}，由课程测试集上 C_audit 的经验覆盖 + split-conformal 下界校准：certified 当且仅当 UCB_{1−δ}(coverage) ≥ 1−α；带有效期（版本 + TTL）与漂移监控。任务级语义卫在规划前先查 CC，超域指令直接拒绝，而不是交给 CAR 事后兜底。**命题**：若 CC 与课程同分布校准，则拒答精确率 ≥ 1−δ。

**定义 43（课程-证书联合目标）**：max_{D_curr} E_{τ∼D_curr}[Δcov(C)] s.t. 每条 rollout 安全、课程单调、实机风险预算 ≤ B_risk。拉格朗日形式 J = Δcov − λ_risk·Risk − λ_mono·viol(mono)。**PAC 直觉**：在前沿带采 N 个独立任务且全部通过审计，认证区域至少扩张 Ω(√(log(1/δ)/N)) 的覆盖半径——样本越多，安全边界越宽，这正是「课程把算力换成可靠性」的数学形态。

## 2. 产出设计（新增 IP-57/58/59 + 升级）

### 2.1 IP-57 VLA-SHIELD（基础模型盾：conformal 动作集 + 证书投影 + 定长前缀）
1. **语言契约解析**：指令 ℓ → 任务契约（目标、约束拓扑、禁止区、可接受工具集），与 CKB 中的契约模板做兼容性检查。
2. **任务级语义卫**：查能力证书 CC，refused 则直接弃权（不进入动作生成），degraded 则只允许最短前缀 + 高频复核。
3. **Conformal 动作集**：π_FM 采样 K 个候选动作块，用校准好的非一致性分数过滤出 A_α，给出「动作级」统计保证。
4. **证书投影与可认证前缀**：把每个候选块投影到 S_C；投影距离 > ε_proj 的块丢弃；返回最长可认证前缀（horizon 课程，见 IP-52）。

### 2.2 IP-58 CERT-CURRICULUM（证书课程引擎 CCC）
1. **提议者（RFM）**：语言变异（同义改写、约束增删、目标复合）、场景扰动（物体位姿/布局/摩擦）、动力学扰动，生成候选任务。
2. **难度预言机（证书）**：对每个候选算最坏 conformal 裕度 μ，只保留前沿带 0≤μ≤δ。
3. **双证书裁判**：C_fast 与 C_audit 分别判定；不一致者入悬案集喂 CEGAR，一致且审计通过者才进训练池。
4. **单调分层 + 优先回放**：按 μ 分位分层，维持成功率带；优先级 = 距前沿中心距离 + 新颖度。
5. **安全微调**：LoRA 低秩微调 / diffusion-guidance 正则，损失含 CBF 引导项与证书一致性项，避免把盾当对手。

### 2.3 IP-59 COMPETENCE-CERT（能力证书）
1. **分层校准**：任务类型 × 环境 × 难度分箱，每箱独立 split-conformal，输出覆盖下界。
2. **三态判定**：certified / degraded / refused，附 TTL 与版本哈希。
3. **漂移联动**：实机分布偏移统计量 S_t 超阈值时，自动降低相关箱的置信、触发重校准（接第 42 轮飞轮）。
4. **用途**：规划前的指令准入、课程采样的可训练区约束、对外的人机契约（哪些承诺有证书背书）。

回退：E87 难度信号失相关 → 退回第 42 轮 CKB 相位检索课程；E88 提议质量低 → RFM 只做执行体，课程用人工模板；E90 悬案不可控 → 关闭 RFM 提议，改用 SCV 纯仿真课程；E91 盾保证不达标 → 收紧 α、增大 ε_proj（多弃权）；E92 能力证书不可校准 → 退回 CAR 事后兜底，不承诺任务级准入。

## 5. 本轮最大风险

**一句话**：课程学习会把机器人基础模型变成证书的「对抗攻击者」——只要 C_audit 本身覆盖不全，前沿带上的任务就会系统性地搜索并放大快证书的假阴性，形成「越训练越自信、越自信越不安全」的 Goodhart 失效；因此 E90（双证书不一致召回）与 E92（能力证书校准）必须作为红线监控，任何一项漂移即冻结课程并收回 CC 的 certified 承诺。

| CC:(ℓ,x)↦{cert,degr,refuse} | 能力证书（meta-certificate） | 分层 split-conformal 覆盖下界 + TTL |
| J=Δcov−λ_risk·Risk−λ_mono·viol(mono) | 课程-证书联合目标 | 覆盖扩张 / 风险 / 单调性三权衡 |

## 2. 关键算法（伪代码）

### IP-57 VLA-SHIELD：conformal 动作集 + 证书投影
```
def vla_shield_step(pi_FM, obs, instr, C_fast, CC, calib, alpha, eps_proj):
    # 1) 语言契约解析
    contract = parse_instruction_contract(instr)
    # 2) 任务级语义卫：能力证书先拦截超域指令
    verdict = CC.verdict(instr, obs)
    if verdict == 'refused':  return ABSTAIN
    # 3) 基础模型采样 K 个动作块，conformal 过滤
    cand = pi_FM.sample(obs, instr, K)
    A_alpha = [a for a in cand if nonconformity(a, obs, instr) >= calib.q(1-alpha)]
    # 4) 证书投影 + 弃权判定
    safe = []
    for a in A_alpha:
        a_proj, d_proj = project_to_cert_set(a, C_fast, contract)  # 区间/CBF 投影
        if d_proj <= eps_proj: safe.append(a_proj)
    if not safe: return ABSTAIN
    # 5) 只取最长可认证前缀（horizon 课程，见 IP-52）
    H_ok = longest_certified_prefix(safe, C_fast)
    return choose(safe, horizon=H_ok)
```

### IP-58 CCC：证书裕度驱动的单调课程
```
def cert_curriculum_round(pi_FM, KB, C_fast, C_audit, CC, budget):
    # 1) RFM 提议：语言变异 + 场景/动力学扰动
    props = propose_tasks(pi_FM, KB, n=budget.n_prop,
                          mutate=['instruction','objects','layout','friction','payload'])
    # 2) 证书难度预言机：只保留前沿带 0 <= mu <= delta
    scored = [(t, cert_margin(pi_FM, t, C_fast)) for t in props]
    frontier = [t for t, mu in scored if 0.0 <= mu <= delta]
    # 3) 双证书裁判：不一致者是悬案，喂 CEGAR；只用审计通过者训练
    train_pool = []
    for t in frontier:
        v_fast  = C_fast.verify(t)
        v_audit = C_audit.verify(t)
        if v_fast != v_audit:
            KB.add_discrepancy(t, v_fast, v_audit)   # 安全/可用性悬案
        if v_audit.accept(t):
            train_pool.append(t)
    # 4) 单调分层 + 成功率带 + 优先回放
    train_pool = monotone_schedule(train_pool, p_lo=0.60, p_hi=0.85, eps_mono=0.05)
    batch = prioritized_replay(train_pool,
                priority=lambda t: abs(cert_margin(pi_FM,t,C_fast)-mu_star)
                                   + lambda_nov*novelty(t, KB))
    # 5) 安全微调（LoRA + CBF/diffusion-guidance 正则，防「把盾当对手」）
    pi_FM = safe_finetune(pi_FM, batch, reg='cbf_guidance', cert_consistency=True)
    # 6) 重校准能力证书
    CC = competence_cert_update(pi_FM, audit_log=C_audit.log, alpha=alpha)
    return pi_FM, CC
```

### IP-59 COMPETENCE-CERT：分层 conformal 能力证书
```
def competence_cert_update(pi_FM, audit_log, alpha=0.05, delta=0.05):
    bins = stratify(audit_log, by=['task', 'env', 'difficulty'])
    CC = {}
    for b in bins:
        cov_b = empirical_audit_coverage(pi_FM, b)          # C_audit 通过率
        lo = conformal_lower_bound(cov_b, n=len(b), delta=delta)
        if   lo >= 1 - alpha:      CC[b] = 'certified'
        elif lo >= 1 - alpha/2:    CC[b] = 'degraded'
        else:                      CC[b] = 'refused'
    return CC

def cc_verdict(CC, instr, obs):
    b = fingerprint(instr, obs)      # 任务/环境/难度箱
    rec = CC.lookup(b)
    return rec.state if rec.valid() else 'refused'   # 过期/TTL 到期即拒绝
```

## 6. 本轮最大风险

**一句话**：课程学习会把机器人基础模型变成证书的「对抗攻击者」——只要 C_audit 本身覆盖不全，前沿带上的任务就会系统性地搜索并放大快证书的假阴性，形成「越训练越自信、越自信越不安全」的 Goodhart 失效；因此 E90（双证书不一致召回）与 E92（能力证书校准）必须作为红线监控，任何一项漂移即冻结课程并收回 CC 的 certified 承诺。
