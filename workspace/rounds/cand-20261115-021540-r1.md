# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「指令泛化」×「任务分解」）

> R69 给闭环装上了「会问的嘴」，但它的所有计量都偷偷默认了一件事：**指令已经被正确理解，而且是一个原子目标**。残差通道测传感器自洽，流似然通道测行为自洽，主动交互消解的是「同一个目标下选哪个动作模态」——它们都测不到「我执行得完美，但做的不是你要的事」。真实的长指令恰恰在更上游引入两层不确定性：**指令泛化**（没见过的说法如何映射到已知能力）与**任务分解**（把一句话拆成一串可执行子任务）。这两层一旦出错，下游每一层都只会忠实地放大错误：一个被误读的目标可以被完美地、可认证地执行。
>
> 本轮两个灵感给出两条互补的纪律：
> - **指令泛化**不是「相似度插值」，而是「在封闭技能本体上的组合」。最危险的失败不是听不懂，而是**目标误泛化**（goal misgeneralization）：把新指令最近邻地解释成一个熟悉的旧目标，然后自信地做错。原则：**靠组合泛化，不靠基元外推**；基元/谓词级的新奇必须求证或拒绝。
> - **任务分解**不是免费的：每拆一步就多一组前置假设，每条接缝都可能断。**局部安全不会自动组合成全局安全**，全局目标正确也不保证接缝处安全。原则：**每条假设都要记账，每条接缝都要有契约**；LLM 只提议，验证器才签发。
>
> 核心命题：**把 R69 的不确定性二分再抬升一层——从「动作模态」抬到「目标解释」；把任务分解变成一份带契约、带预算、可审计的假设账本；执行只允许发生在「所有可信解释都接受的动作交集」上，其余一律求证或拒绝。** 命名 **LEDGER-RAS**（Language-grounded Epistemic Decomposition with Guaranteed Entailment and Refusal：语言接地的认知分解、可保证的蕴含与拒绝）。
>
> 一句话定位：R67 问「未来怎样」，R68 问「测量还准吗」，R69 问「该向谁求证」，R70 问「**我到底被要求做什么、这个拆法我付得起吗、做完还是不是原来那件事**」——安全不只是每一步都不越界，更是整条计划没有偷偷换掉目标。

## 0. 直觉与动机

**灵感 1（指令泛化 → 目标误泛化才是真正的 OOD）**
直觉：R68 的 OOD 检测看的是**观测**是否离开训练分布；但机器人最常见的灾难性泛化失败，观测完全在分布内，变的是**目标语义**。例如训练里「把药放进柜子」，新指令是「把药放到孩子够不到的地方」；最近邻解释会退化成「放进柜子」，动作熟练、局部安全，但药仍在孩子可及的高度。系统不是不会开柜门，而是**把「安全」偷换成了「柜子」**。这类错误无法靠残差或流似然发现，因为执行在世界模型里是自洽的。结论：指令泛化必须以**语义蕴含**而非嵌入相似度为判据；必须区分「组合新颖」（旧基元的新组合，可由契约组合承担）与「基元新颖」（出现本体中没有的谓词/技能，必须求证或拒绝）。

**灵感 2（任务分解 → 分解是一串假设，不是一串步骤）**
直觉：把「做一顿早饭」拆成「取蛋→打蛋→煎蛋→装盘」，每一步都隐含假设：冰箱里有蛋、蛋壳可破、锅已热、盘子可及、台面承重。单步策略再安全，也无法保证这些假设同时成立；而分解越深，假设面越大、接缝越多。更隐蔽的是，LLM 规划器会**幻觉前置条件**（「抓住把手」——可那里根本没有把手）。因此分解不是规划器的自由创作，而是一份**证明义务**：每个子任务携带前置/后置/不变式契约，每条边要求「前一个后置蕴含后一个前置」，否则插入带契约的桥接动作或重规划；每条假设要么被观测验证、要么被 R69 的交互消解、要么被显式记账并支付失败质量。没有担保的步骤，不允许到达执行器。

**灵感 3（语义不确定性也要二分 → R69 的二分是它的投影）**
直觉：目标层同样有两种东西。**指称歧义**（哪个杯子、哪扇门、先左还是先右）是 epistemic：问一句、指一下、看一眼就能降；**模糊谓词**（「一点」「尽快」「整齐」「小心」）是 aleatoric：再问也问不出一个精确阈值，只能用一个稳健的满足带（satisficing band）去兜。R69 的 U_ale/U_epi 是在「目标已定」的动作空间里做这件事；R70 把它抬到目标空间，并且明确：**指称歧义交给交互，模糊语义交给稳健裕度**，两者不做简单加和。于是 R69 恰好是「目标解释集为单点」的边界情形。

**灵感 4（安全不能相加，接缝要单独证）**
直觉：R66–R69 的证书都是**单步/单技能**的。可"局部安全 + 局部安全"并不等于"全局安全"：子任务 A 的后置状态可能让子任务 B 的前置不再成立（把杯子放到桌沿，下一步抓取就会碰落）；反过来，全局目标正确也不代表接缝处安全。因此需要两个独立证书：**宏任务证书**（目标蕴含与整体不变式）与**接缝证书**（相邻子任务的契约蕴含 + 运行时监测）。接缝不是胶水，是新的证明义务。

**灵感 5（新攻击面：指令层投毒与分解注入）**
直觉：一旦系统会"理解指令、拆解任务"，攻击面就从传感器上移到了**语言与规划层**。对抗指令可以让每个子任务都合法、整体却有害（"把钥匙放到门外垫子下"）；分解注入可以让规划器把违禁动作藏进一个看似无害的子任务；幻觉前置条件可以让系统对不存在的对象执行抓取。对策必须是**指令无关的宪法包络**：无论用户说什么、无论怎么拆，某些硬约束不可被任何计划越过；冲突时不是"再问一句"，而是**拒绝**。同时，LLM 只有提议权，没有执行权。

**灵感 6（LLM 出实时环 → 不破坏 R68/R69 的时延保证）**
直觉：语义解析、分解、等价性检验都很重，不能塞进 2.6ms 的控制环。正确的架构是：LLM/规划器在**异步慢环**里提议计划，验证器签发带证书的有限状态控制器；实时环只执行已编译的子任务，并在接缝处复用 R69 的残差/似然监测。这样 R70 增加的是**换计划时的宏观决策延迟**，而不是每一步的控制延迟；同时把"语言模型幻觉"隔离在控制环之外。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（LEDGER-RAS 总览与四不变式）** LEDGER-RAS = (SIG, GAD, ACL, DCP, SET, CEI) + RAS-WM†。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **无未担保执行**：任何未被验证的前置条件必须进入假设账本（定义 321）并支付失败质量；未验证且未记账的前置条件使计划非法；
(iii) **语义闭包纪律**：泛化只允许发生在已认证技能本体 𝒪 的组合闭包内；出现基元/谓词级新奇时必须求证或拒绝，禁止最近邻外推（定义 312、325）；
(iv) **指令无关的宪法包络**：存在与指令无关的硬约束 H（定义 319），任何指令、任何分解都不得使其失效；冲突时拒绝，而不是继续求证。
另设**提议—签发分离**：LLM 规划器无执行权，只有经 DCP/SET 验证并签发证书的编译计划可进入执行（定义 324）。

**定义 311（指令的语义形式）** 指令 i 经类型化解析得到目标公式 G(i)，其语言为 ℒ_𝒪：对象项、谓词、技能符号、量词、时序/因果算子、以及可分级谓词（gradable predicates）。一个**解释** g 是 G(i) 在观测 o 上的接地实例（绑定对象、量词域、时序顺序、模糊谓词阈值带）。记 Eff(g) 为达成 g 的效果集，Perm(i) 为指令允许的效果集，Acc(g) 为在 g 与 H 下可接受的动作集。

**定义 312（泛化阶梯 G0–G3）** 对指令 i 与技能本体 𝒪：
- **G0**：分布内、原子、已有直接对应；
- **G1**：同义改写（meaning-preserving paraphrase），语义等价类已知；
- **G2**：已知基元/谓词的新组合（组合新颖）；
- **G3**：出现 𝒪 中不存在的基元/谓词，或参数越出该技能的标定工作包络（基元新颖）。
执行许可：G0/G1 在其余检查通过时可直接执行；G2 必须通过契约组合、接缝与双向泛化检验；G3 **一律**降级为求证（若 R69 的 VoI > 成本）或拒绝。宪法包络冲突不属于任何 G 级，直接拒绝。

**定义 313（目标级不确定性二分）** 设 𝒢 为解释空间：
- **U^G_epi = H(G | i, o)**：指称/量词辖域/顺序/偏好等可约歧义，存在信息动作使其下降；
- **U^G_ale = E_g[width(Vague(g))]**：可分级谓词与偏好阈值的不可约模糊带宽，任何有限询问都不能把它压到零。
二者语义不同，不做简单加和：U^G_epi 进入 R69 的 MINT 交互通道；U^G_ale 进入稳健满足带与风险裕度通道（定义 320、326）。操作判据：若某信息动作的 VoI 低于分辨率下限，则剩余部分归入 U^G_ale。

**定义 314（校准解释集）** 对指令 i，按意图类别 c（如「放置/取回/清洁/避让」）做 **Mondrian conformal**：𝒢_α(i) = { g : s(i,g) ≤ q_{α,c} }，其中 s 为非一致性分数，q_{α,c} 为第 c 层的校准分位数。在层内可交换假设下，P(G* ∈ 𝒢_α(i)) ≥ 1−α。三个安全细节：(a) 若 𝒢_α 为空，视为**没有可信解释**，禁止执行；(b) 若检测到层内分布漂移，𝒢_α 失效，转入定义 325；(c) 禁止用「取分数最高的单个 g」替代集合，除非该 g 在集合内以高置信占优且其余解释与它动作兼容。

**定义 315（技能契约与假设携带子任务 ACT）** 子任务 τ = (σ, φ, Pre, Post, Inv, Ev, p, c)，其中 σ 为技能，φ 为参数，Pre/Post/Inv 为 ℒ_𝒪 上可判定的谓词（前置/后置/不变式），Ev ∈ {perception, interaction, simulation, assumption} 为证据来源，p 为该契约在标定分布下的成立概率，c 为执行成本。契约必须显式携带**工作包络**（力、速度、位姿、时间窗）；越出包络即视为 G3。

**定义 316（分解 DAG 与契约有效性）** 计划 P = (V, E)，V 为 ACT（含桥接动作），E 为数据/时序依赖边。P **契约有效**当且仅当：对每条边 i→j，在 Inv_i ∧ Inv_j 下 Post_i ⇒ Pre_j（或中间插入桥接 b，见定义 317）；所有 Inv 的合取在宏不变式下可满足；深度 d、宽度 w 在预算内。P 的**宏不变式** I_P = ∧_i Inv_i ∧ H。

**定义 317（接缝义务与桥接动作）** 边 i→j 的接缝义务 seam(i,j) 为「Post_i ⇒ Pre_j 在监测误差内成立」，其风险记 ε_seam。若义务不成立：插入桥接动作 b（本身是 ACT，必须持契约）使 Post_i ⇒ Pre_b 且 Post_b ⇒ Pre_j；无可行 b 则重规划；重规划失败则该分解非法。执行 τ_i 后必须由接缝监测器验证 Post_i；失败则进入修复/重规划，**不得带病推进**。

**定义 318（语义蕴含检验：不多不少）** 两个独立检查：
- **达成性 / no-less**：Post(P) ⊨ Goal(g)（含时序与因果结构）；
- **不过界 / no-more**：Eff(P) 中**任何不可逆效果**都必须被 Perm(i) 显式蕴含；可逆探索允许在 H 内自由进行。
「不可逆须显式蕴含、可逆可探索」这条非对称规则，避免了对长指令过度约束，又堵住了"顺手多做一个危险动作"的主要通道。

**定义 319（宪法包络 CEI）** H 为指令无关的硬约束集合（人身安全、不可逆破坏、禁入区、隐私与社交边界等），在计划态与执行态双重生效：计划态用 DCP 静态检查，执行态用 C-RAS-WM 前缀认证兜底。若某指令/分解要求违反 H，则**拒绝**并给出理由，不进入"问一句再试"的通道。若计划态无法判定某效果是否越界，按**可能越界**处理（保守拒绝或先求证）。

**定义 320（解释集上的共识核执行 CKE）** 对解释集 𝒢_α 定义**共识核** K(𝒢_α) = ∩_{g∈𝒢_α} Acc(g)。执行器每一步只允许执行 a ∈ K；若 K = ∅，则调用 R69 的 MINT 选择信息动作（若 VoI > 成本），否则拒绝。**核心纪律：不得因为某个解释更安全/更容易就单独采纳它**——除非它在所有可信解释下都被接受。这样在指称歧义下，系统可以"先走到中性位再问"，但不会"猜一个然后做到底"。

**定义 321（假设账本 ACL）** 每个活跃假设 A_i 携带状态 ∈ {verified, assumed, expired}、标定成立概率 p_i、失败质量 1−p_i、有效期 ttl_i。账本余额
L(P) = Σ_{i: Assumed} (1 − p_i) + Σ_{seams} ε_seam。
执行条件：L(P) ≤ δ。证据可"偿还"（降低 1−p_i）；假设过期必须重新验证或重新记账；**跨轮单调**：不得通过重命名/重标定把已支付的假设债务清零。状态为 unresolved 的假设**不得**进入账本（它不是"可接受的赌注"，而是未回答的问题），必须求证或拒绝。

**定义 322（前置条件接地与幻觉拦截）** 每个 Pre 必须满足三者之一：(a) 由感知以校准置信度验证；(b) 由 R69 的信息动作消解；(c) 显式声明为假设并记账。LLM 声称的"前置条件成立"**没有证据权重**；若感知与规划器冲突，以感知为准并拒绝该计划。抓取类技能额外要求可抓性/可达性/力包络三项接地检查。

**定义 323（双向泛化检验 PCD）** 对 G2 及以上指令，在签发前做两组运行时检验：
- **同义不变性**：对保义改写 i′，要求 d(P(i), P(i′)) ≤ ε_par；
- **对比敏感性**：对最小语义改动 i⁻（换对象/否定/量词/顺序），要求 d(P(i), P(i⁻)) ≥ Δ_con，或计划显式转入求证/拒绝。
阈值 ε_par、Δ_con 由校准集上的 conformal 分位数给出（层内覆盖率 ≥ 1−α′）。同义不变性失败 = 欠泛化（被表面措辞绑架）；对比敏感性失败 = 过泛化（目标误泛化）。任一失败即降级为求证/拒绝。这是把"泛化单元测试"搬进运行时。

**定义 324（提议—验证分离与计划证书）** LLM 规划器输出候选计划分布；验证器 DCP/SET 检查契约、接缝、语义蕴含、宪法包络与账本，任一失败则拒绝或要求重规划。只有通过验证的计划被编译为有限状态控制器，附 `plan_hash, ontology_ver, verifier_ver`。LLM 不接触执行器；执行环只运行已签发计划。语言模型的幻觉因此被限制在"提议被拒"这一无害后果内。

**定义 325（语义 OOD 与诚实策略）** 以下任一成立即判为语义 OOD：𝒢_α = ∅；层内覆盖率检验失败；PCD 双向检验失败；检测到基元/谓词级新奇；账本在允许的求证预算内无法平衡。策略按序：若存在正 VoI 且安全的信息动作 → 求证（R69）；否则 → 拒绝并给出可执行的最小澄清请求。**禁止静默最近邻**：不得在语义 OOD 下沿用最相似旧指令继续执行。

**定义 326（证书 J_LEDGER 与严格包含）** J_LEDGER = (J_FLUID, g_level, conformal_coverage, interpretation_set_hash, contract_valid, seam_risk, ledger_balance, entailment_ok, pcd_scores, envelope_ok, plan_hash, ledger_ver)。Valid ⇔ Valid(J_FLUID) ∧ coverage ≥ 1−α ∧ contract_valid ∧ entailment_ok ∧ pcd_ok ∧ envelope_ok ∧ L(P) ≤ δ。
**严格包含**：当指令为 G0/G1、𝒢_α 为单点、分解深度为 1、无未验证假设且 H 满足时，SIG/DCP/SET/CKE 全部退化为恒等检查，LEDGER 逐步执行与 FLUID 完全相同的动作；当任一检查失败时，LEDGER 选择求证或拒绝，而 R69 会直接执行。故安全侧永不弱于 R69，任务收益仅在 G0/G1 不退步——这是有意的取舍。

## 2. 关键算法骨架

```python
# IP-264 SIG：类型化解析 + 泛化阶梯 + 校准解释集
def interpret(instruction, onto, calib):
    parses = parse_typed(instruction, onto)              # LLM/文法 -> 目标公式
    level  = generalization_level(instruction, onto, calib)  # G0..G3
    if level == G3:
        return None, level                               # 基元新奇 -> 求证/拒绝
    scores = [conformal_score(instruction, g) for g in parses]
    Gset   = mondrian_conformal_set(parses, scores, calib)    # 覆盖率 >= 1-alpha
    if (not Gset) or shift_detected(scores, calib):
        return None, level                               # 语义 OOD
    return Gset, level

# IP-265 GAD：目标级 aleatoric / epistemic 二分
def split_goal_uncertainty(Gset, o, mint):
    U_epi = entropy(Gset)
    U_ale = mean(vagueness_width(g) for g in Gset)
    if U_epi > TAU_EPI and mint.max_voi(Gset, o) <= mint.cost_floor:
        U_ale += U_epi; U_epi = 0.0                      # 问不出来 -> 并入模糊带
    return U_ale, U_epi

# IP-267/268/321：DCP + SET + ACL 计划验证
def verify_plan(P, Gset, onto, ledger, env):
    if not env.envelope_ok(P):            return False, "envelope"
    if not contracts_valid(P, onto):      return False, "contract"
    if not seams_ok(P):                   return False, "seam"        # 或插入 bridge 后重验
    if not entail(P, Gset):               return False, "entail"
    if ledger.balance(P) > DELTA:         return False, "ledger"
    return True, "ok"

# IP-271 CKE：共识核执行；空核 -> 信息动作 / 拒绝
def consensus_step(Gset, o, mint):
    acc = [acceptable_actions(g, o) for g in Gset]
    K = set.intersection(*acc)
    if K:
        return choose_safe(K)                            # 所有可信解释都接受
    g = mint.choose_interaction(Gset, o)                 # 复用 R69 的 VoI
    return g if g is not None else REFUSE                # 不许挑软柿子

# IP-274 LEDGER 主闭环（LLM 在异步慢环，执行环复用 R69）
def LEDGER_round(instruction, o):
    Gset, lvl = interpret(instruction, ONTO, CALIB)
    if Gset is None:
        return ask_or_refuse(instruction, lvl)           # 语义 OOD / G3
    if ENV.conflicts(instruction, Gset):
        return REFUSE                                    # 宪法包络不可让渡
    P = PLANNER.propose(instruction, Gset)               # 异步，无执行权
    ok, why = verify_plan(P, Gset, ONTO, LEDGER, ENV)
    if not ok:
        P = PLANNER.repair(P, why, Gset)
        ok, why = verify_plan(P, Gset, ONTO, LEDGER, ENV)
    if not ok:
        return ask_or_refuse(instruction, lvl)
    while not P.done(o):
        a = consensus_step(Gset, o, MINT)
        if a is REFUSE:
            return REFUSE
        if is_information_action(a):
            o = execute_info(a)                          # R69 认证 + 证据纪律
            Gset = bayes_update(Gset, o)
        else:
            o = execute_subtask(a, o)                    # 内部就是 FLUID_RAS_round
        if not SEAM.monitor(P, o):                       # 接缝失败 -> 修复/重规划
            P = PLANNER.repair(P, "seam", Gset)
            if not verify_plan(P, Gset, ONTO, LEDGER, ENV)[0]:
                return ask_or_refuse(instruction, lvl)
        if LEDGER.balance(P) > DELTA:
            return ask_or_refuse(instruction, lvl)       # 预算耗尽 -> 求证/拒绝
        Gset = update_from_observation(Gset, o)
    return P.done(o)
```

## 3. 推导

**引理 19（契约组合的加性风险界）** 在 A99（Pre/Post/Inv 监测器对违反是可靠的，或误差已计入 ε）与 A100（每个子任务的证书把其违反 Inv∨H 的概率上界为 ε_i）下，若每条子任务间依赖都被唯一的接缝或桥接覆盖，则对深度 d、接缝数 m 的计划 P：
`P(执行期任一 Inv/H 违反) ≤ Σ_i ε_i + Σ_j ε_seam,j + L(P)`。
证明：对"子任务违反""接缝失败""假设失败"三类事件取并集上界；假设 i 的失败质量就是 1−p_i，故第三项即账本余额。注意该界**不要求各类失败独立**，因此对相关假设也成立，代价是保守。系：**账本不是记账美学，而是这条上界里的真实一项**。

**引理 20（共识核的语义安全性）** 设真实解释 G* ∈ 𝒢_α 的概率 ≥ 1−α（层内 conformal）。若每一步只执行 a ∈ K(𝒢_α) = ∩_g Acc(g)，则在覆盖事件下 a ∈ Acc(G*)，即该动作对真实指令可接受。若 K = ∅，则不执行，转入信息动作或拒绝。故**逐步语义违反概率 ≤ α + ε_Acc**，其中 ε_Acc 是 Acc 判定器的误差。
系（反目标误泛化）：若两个可信解释的可接受动作集不相交，则 K=∅，系统**必须**求证/拒绝，而不能"选那个更安全的解释"继续做。这把"猜一个旧目标"从策略空间里删掉了。

**引理 21（双向检验的 conformal 检出界）** 设校准集 𝒫 为保义改写对、𝒞 为最小语义对比对；取 ε_par 为 𝒫 上 d(P(i),P(i′)) 的 (1−α′) 分位，Δ_con 为 𝒞 上 d(P(i),P(i⁻)) 的 α′ 分位。则在层内可交换下：正确泛化的计划以 ≥1−α′ 通过同义不变性；对语义间隔超过 Δ_con 的对比，计划若仍不变则被检出为过泛化。误报率 ≤ 2α′。证明用 conformal 的边际覆盖；检测功效随对比的语义间隔单调上升。系：**泛化检验不需要一个完美的语义裁判，只需要一组校准过的"反例对"**——这把信任从"模型懂语义"转移到了"样本对覆盖了语义"。

**定理 18（LEDGER 严格包含 FLUID/R69）** 在 A95–A101 下：
(i) 对任意状态，LEDGER 的安全违反风险 ≤ R69（它要么执行经 R69 认证且被共识核接受的动作，要么求证/拒绝；拒绝与受认证的信息动作不增加包络违反）；
(ii) 当指令为 G0/G1、𝒢_α 为单点、分解深度 1、无未验证假设且 H 满足时，LEDGER 与 FLUID **逐指令相同**；
(iii) 当语义检查/账本/包络任一失败时，LEDGER 可能拒绝而 R69 会执行，因此**任务成功率可能下降**；
(iv) 故 FLUID = LEDGER 在「原子、分布内、目标无歧义、零假设债务」边界上的退化。
注：这里刻意区分**安全风险**与**任务收益**；不宣称任务收益也单调不降，否则就是自欺。

**定理 19（无未担保执行与拒绝安全）** 任何到达执行器的命令都来自一个满足 L(P) ≤ δ、且每个前置条件处于 verified/assumed/expired 已重验状态的计划；由引理 19，未担保假设导致违反的概率 ≤ δ + Σ ε。若验证器不能建立该条件，系统拒绝；拒绝是"不运动/安全停"动作，位于 H 内，故不会造成包络违反。又由 CEI，任何指令都不能豁免 H，因此对抗指令/分解注入最多导致拒绝，不能导致越界执行。

**定理 20（深度—风险权衡与最大分解深度）** 对深度 d、每子任务风险 ε_t、每接缝风险 ε_s、账本 L 的计划，引理 19 给出总风险 ≤ d·ε_t + (d−1)·ε_s + L。给定安全预算 δ，最大可执行深度
`d_max = floor((δ − L + ε_s) / (ε_t + ε_s))`。
系：**长时程能力的瓶颈不是规划器的想象力，而是验证资源与假设预算**；要做得更长，必须降低单步风险（更强验证）或降低 L（更多交互/观测），而不是只换更大的 LLM。这为"任务分解深度"给出了一个可审计的上界。

## 6. 本轮最大风险

**次级风险与缓解**：
1. **语义裁判本身不可信**（形式化本体不完整、蕴含检验漏判）→ 用 PCD 反例对做运行时单元测试 + 本体版本化 + 高风险不可逆效果强制人工/远程确认；
2. **conformal 覆盖率在组合移位下失效**（可交换性被 G2/G3 破坏）→ Mondrian 分层 + 漂移报警 + 集空即拒绝，绝不用边际覆盖率冒充条件覆盖率；
3. **账本概率未校准**（p_i 乐观）→ 在线校准 + 过期重验 + 跨轮单调，不允许"重标定洗债"；
4. **共识核过度保守**（空核频繁、任务几乎不可完成）→ 用 R69 的 VoI 选择最省成本的信息动作 + 允许"先到中性位再问"的渐进式共识；
5. **规划器与验证器共谋/同源错误**（同一 LLM 既提议又解释语义）→ 提议与验证使用不同模型/不同本体视图，验证器输出可被第三方复算。

**一句话**：LEDGER-RAS 的全部保证都嫁接在一个「语义裁判」上——若形式化本体或蕴含检验本身错了，系统会以完备的账本、可审计的证书，自信地执行一个被证明错误的指令理解；**「可认证的错误」比「诚实的不知道」更难被发现，也更危险**。

**定义 313（目标级二分）** `U^G_epi=H(G|i,o)` 可由信息动作降低；`U^G_ale=E_g[width(Vague(g))]` 不可约，只能进稳健满足带；二者不做简单加和；VoI 低于分辨率下限的残差并入 U^G_ale。

**定义 314（校准解释集）** Mondrian conformal 按意图类别分层；空集 / 漂移 / 未校准 → 语义 OOD，禁止执行；不得用「分数最高的单点」冒充集合。

**定义 315–317（ACT、DAG、接缝）** 子任务带 Pre/Post/Inv/证据/概率/成本；分解 DAG 每条边要求 `Post_i ⇒ Pre_j`，否则插桥接 b 或重规划；执行后必验 Post_i，接缝监测失败则修复，不得带病推进。

**定义 318（语义蕴含：不多不少）** 达成性：`Post(P) ⊨ Goal(g)`；不过界：所有**不可逆效果**须被 `Perm(i)` 显式蕴含，可逆探索可在 H 内自由进行。

**定义 319（宪法包络 CEI）** H 与指令无关，计划态 + 执行态双重生效；冲突不是"再问一句"而是拒绝；不可判定按可能越界处理。

**定义 320（共识核 CKE）** 只执行 `a∈∩_g Acc(g)`；空核 → R69 信息动作（若 VoI>成本）或拒绝；**不得**因为某解释更安全就单独采纳。

**定义 321–322（账本与接地）** `L=Σ(1−p_i)+Σε_seam ≤ δ`；证据可偿还、过期重验、跨轮单调；unresolved 不得入账；LLM 声称的前置无证据权重，感知冲突以感知为准。

**定义 323（双向泛化检验 PCD）** 保义改写要求计划不变（≤ε_par）；最小语义对比要求计划改变（≥Δ_con）或转求证；失败=欠/过泛化，降级求证/拒绝；阈值由 conformal 分位给出。

**定义 324–326（提议—验证、语义 OOD、证书与严格包含）** LLM 无执行权，签发计划附 plan_hash/ontology_ver；语义 OOD 时求证或拒绝，禁止静默最近邻；`J_LEDGER` 合并 J_FLUID 与全部语义/账本字段；G0/G1 + 单点集 + 深度 1 + 零债务 ⇒ 逐指令等价于 FLUID。

## 3. 关键算法伪代码

```python
# IP-264 SIG：泛化阶梯 + 校准解释集
def interpret(instruction, onto, calib):
    parses = parse_typed(instruction, onto)
    level  = generalization_level(instruction, onto, calib)   # G0..G3
    if level == G3: return None, level                        # 基元新奇
    scores = [conformal_score(instruction, g) for g in parses]
    Gset   = mondrian_conformal_set(parses, scores, calib)    # 覆盖率 >= 1-alpha
    if (not Gset) or shift_detected(scores, calib): return None, level
    return Gset, level

# IP-265 GAD：目标级不确定性二分
def split_goal_uncertainty(Gset, o, mint):
    U_epi = entropy(Gset); U_ale = mean(vagueness_width(g) for g in Gset)
    if U_epi > TAU_EPI and mint.max_voi(Gset, o) <= mint.cost_floor:
        U_ale += U_epi; U_epi = 0.0                           # 问不出来 -> 并入模糊带
    return U_ale, U_epi

# IP-267/268/321：契约 + 蕴含 + 账本验证
def verify_plan(P, Gset, onto, ledger, env):
    if not env.envelope_ok(P):       return False, "envelope"
    if not contracts_valid(P, onto): return False, "contract"
    if not seams_ok(P):              return False, "seam"
    if not entail(P, Gset):          return False, "entail"
    if ledger.balance(P) > DELTA:    return False, "ledger"
    return True, "ok"

# IP-271 CKE：共识核，空核 -> 求证/拒绝
def consensus_step(Gset, o, mint):
    K = set.intersection(*[acceptable_actions(g, o) for g in Gset])
    if K: return choose_safe(K)
    g = mint.choose_interaction(Gset, o)
    return g if g is not None else REFUSE

# IP-274 LEDGER 主闭环（LLM 异步慢环；执行环复用 R69）
def LEDGER_round(instruction, o):
    Gset, lvl = interpret(instruction, ONTO, CALIB)
    if Gset is None or ENV.conflicts(instruction, Gset):
        return ask_or_refuse(instruction, lvl)
    P = PLANNER.propose(instruction, Gset)                    # 无执行权
    ok, why = verify_plan(P, Gset, ONTO, LEDGER, ENV)
    if not ok:
        P = PLANNER.repair(P, why, Gset)
        ok, why = verify_plan(P, Gset, ONTO, LEDGER, ENV)
    if not ok: return ask_or_refuse(instruction, lvl)
    while not P.done(o):
        a = consensus_step(Gset, o, MINT)
        if a is REFUSE: return REFUSE
        if is_information_action(a):
            o = execute_info(a); Gset = bayes_update(Gset, o)   # R69 认证 + 证据纪律
        else:
            o = execute_subtask(a, o)                          # 内部为 FLUID_RAS_round
        if not SEAM.monitor(P, o):
            P = PLANNER.repair(P, "seam", Gset)
            if not verify_plan(P, Gset, ONTO, LEDGER, ENV)[0]:
                return ask_or_refuse(instruction, lvl)
        if LEDGER.balance(P) > DELTA: return ask_or_refuse(instruction, lvl)
        Gset = update_from_observation(Gset, o)
    return P.done(o)
```

## 4. 推导

**引理 19（契约组合的加性风险界）** 在监测器可靠（或误差计入 ε）、每子任务违反上界 ε_i、每条依赖被唯一接缝/桥接覆盖时：
`P(执行期任一 Inv/H 违反) ≤ Σ_i ε_i + Σ_j ε_seam,j + L(P)`。
证：对子任务违反、接缝失败、假设失败取并集上界；假设 i 的失败质量即 1−p_i。无需独立性，故对相关假设也成立。系：账本是该上界中的真实项，不是记账美学。

**引理 20（共识核的语义安全性）** 若 G*∈𝒢_α 的概率 ≥1−α，且每步只执行 `a∈∩_g Acc(g)`，则覆盖事件下 `a∈Acc(G*)`。若交集为空则不执行、转信息动作或拒绝。故逐步语义违反 ≤ α + ε_Acc。
系（反目标误泛化）：两个可信解释的可接受动作集不相交时，系统必须求证/拒绝，不能「选那个更安全的解释」继续做——这把「猜一个旧目标」从策略空间删除。

**引理 21（双向检验的 conformal 检出界）** 以保义改写对集 𝒫 的 (1−α′) 分位为 ε_par、以最小语义对比对集 𝒞 的 α′ 分位为 Δ_con，则正确泛化以 ≥1−α′ 通过同义不变性；语义间隔超过 Δ_con 的对比若计划不变即被检出为过泛化；误报 ≤2α′。证明用 conformal 边际覆盖；检测功效随语义间隔单调。系：泛化检验不需要完美的语义裁判，只需要一组校准过的反例对。

**定理 18（LEDGER 严格包含 FLUID/R69）** A95–A101 下：(i) 任意状态的安全违反风险 ≤ R69（执行已认证动作，或求证/拒绝）；(ii) G0/G1、单点 𝒢_α、深度 1、零债务、H 满足时与 FLUID 逐指令相同；(iii) 任一语义/账本/包络检查失败时可能拒绝而 R69 会执行，故**任务成功率可能下降**；(iv) FLUID = LEDGER 在「原子、分布内、目标无歧义、零假设债务」边界的退化。刻意区分安全风险与任务收益，不宣称后者单调。

**定理 19（无未担保执行与拒绝安全）** 到达执行器的命令均来自 L(P)≤δ 且前置处于 verified/assumed/expired 重验状态的计划；由引理 19，未担保假设致违反 ≤δ+Σε。验证器不能建立该条件时拒绝；拒绝是安全停，位于 H 内。CEI 使任何指令都不能豁免 H，故对抗指令/分解注入最多导致拒绝，不能导致越界执行。

**定理 20（深度—风险权衡）** 深度 d、单步 ε_t、接缝 ε_s、账本 L 时总风险 ≤ d·ε_t+(d−1)·ε_s+L；给定预算 δ，
`d_max = floor((δ−L+ε_s)/(ε_t+ε_s))`。
系：长时程瓶颈不是规划器想象力，而是验证资源与假设预算；要做得更长，必须降低单步风险或降低 L（更多交互/观测），而不是只换更大的 LLM。

## 7. 本轮最大风险

**次级风险与缓解**：语义裁判不可信（PCD 反例对 + 本体版本化 + 不可逆效果强确认）；conformal 在组合移位下失效（Mondrian + 漂移报警 + 集空即拒绝，不用边际覆盖冒充条件覆盖）；账本概率未校准（在线校准 + 过期重验 + 跨轮单调，禁止重标定洗债）；共识核过度保守（VoI 选最省成本信息动作 + 渐进式共识）；提议/验证同源共谋（不同模型/不同本体视图，验证可复算）。

**一句话**：LEDGER-RAS 的全部保证都嫁接在一个「语义裁判」上——若形式化本体或蕴含检验本身错了，系统会以完备的账本、可审计的证书，自信地执行一个被证明错误的指令理解；**「可认证的错误」比「诚实的不知道」更难被发现，也更危险**。
