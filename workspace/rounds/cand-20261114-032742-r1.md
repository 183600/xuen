# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动交互消歧」IP-253~263；本轮灵感：「多模态交互」×「通信延迟」）

> R69 教会闭环「去问」，却偷偷假设了**问是瞬时的**：发出注视/探针/问句，答案立刻回来，并且答案针对的就是当下的歧义。真实链路是 感知→编码→上行→人/VLM 思考→下行→融合，每一段都有延迟；等答案回来，世界已经移动、模态可能已经切换、截止时间可能已经过去。于是 R69 最锋利的那条判据 `VoI(g) > c(g)` 其实是「零延迟 VoI」，它对**慢通道**系统性乐观。
>
> 本轮两个灵感正好补上这一层时间维度：
> - **通信延迟**把「交互」从一次查询变成**一张对未来的期权**——现在付成本，未来收货，而货会过期；
> - **多模态交互**则给出**一组延迟与信息量各异的通道**（注视/触觉是本地反射，语言问答经人/云，远程专家更慢），问题从「问不问」升级为「**用哪条通道、等到什么时候、什么时候必须不再等**」。
>
> 核心命题：**给 R69 的每个信息动作补上时延模型、证据时效与模态半衰期；把交互搬到不阻塞控制回路的异步层；用「延迟感知 VoI（D-VoI）+ 截止时间承诺」替代零延迟 VoI。当延迟超过模态半衰期、通道不可信、或临近截止时，逐指令退化为 R69/R68 的保守路径。** 命名 **TIDE-RAS**（Temporal Interaction-aware Disambiguation Engine for Risk-adaptive Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**等不等得起、答案到时还算数吗**」——不确定性不仅是刹车和提问，也是一场与时间的赛跑。

## 0. 直觉与动机

**灵感 1（通信延迟 → 交互是一张关于未来的期权）**
直觉：R69 的 `VoI(g)` 在「发问时刻」估算信息增益，默认答案瞬时到达且永远有效。但问句要经过感知、编码、网络、人的反应、回传、融合；答案到达时，`M_t` 已经变成 `M_{t+τ}`。如果模态在 τ 内已经改变，答案就是旧闻——不仅无用，还可能因为被赋予高权重而有害。交互因此是**期权**：支付成本换取「未来的信息」，其价值必须乘以「未来仍有效」的概率，并扣除等待期间保守动作的机会成本。

**灵感 2（多模态交互 → 通道有异构延迟，选择是前沿问题）**
直觉：R69 把 `g_gaze / g_probe / g_ask` 放进同一个动作空间，却没区分它们的时延。注视与触觉探针是本地闭环（约 10–50ms），本地语言问答约 0.5–2s，经人/云/VLM 的问答常在 100ms–3s，远程专家更久。于是「多模态交互」真正的结构不是「融合更多模态」，而是**在延迟-信息前沿上做调度**：快通道低信息但及时，慢通道高信息但易过期。可以流水线：先用 gaze 快速收窄候选项，同时发出语言问句，慢答案回来时用来修正**下一拍**的先验——这就是 anytime 证据。

**灵感 3（模态半衰期 → epistemic 还要再分成持久与瞬态）**
直觉：R69 的 `U_epi` 只回答「是否可约」，没回答「现在约是否值得」。有的歧义是持久的（地图结构性歧义，晚问也有效），有的是瞬态的（对方犹豫一下后自己就走过来，晚问纯属旧闻）。定义模态自相关时间 `τ_M`，则延迟 τ 后的信息增益按 `e^{−τ/τ_M}` 衰减。R69 恰好是 `τ=0`、`ρ_M≡1`（模态永不变化）的边界。这给出一条可算的判据：只有 `τ < τ_M·ln(I₀/c)` 时交互才值钱——**「歧义大」不够，「持久且分得开的歧义」才值得问**。

**灵感 4（实时解耦 → 慢交互不能拖垮快环）**
直觉：R68/R69 的命根子是 P99 2.6–3.4ms 的硬实时。同步等一次云问答（几十到几百 ms）会直接击穿控制周期。所以交互必须搬到**异步层**：快环每拍只读取带时间戳的证据快照（非阻塞），异步层负责发送、超时、重试、时序校验、TTL 过滤、写回队列。最坏情况（无任何新鲜证据）下，快环行为逐指令退化为 R69/R68。通信延迟被**架构性隔离**，而不是被「优化掉」——承认它存在，然后不让它进入安全关键路径。

**灵感 5（延迟可攻击，也会伪装成欺骗 → 时效性是新的信任根）**
直觉：R69 的威胁模型是「回答撒谎」。延迟打开新的攻击面：
- **延迟注入**：把关键答案拖过决策截止时间，逼迫系统在无证据下保守或冒险；
- **重放/乱序**：拿旧答案冒充新答案，系统以为「已验证」；
- **丢包诱发重复提问**：同一问题反复问，耗尽交互预算、暴露社交意图；
- **良性 lag 伪装成欺骗**：R68 的 `r_sync` 把音视频不同步当成情绪欺骗，但真实传输延迟也产生同样的残差——系统会把「网络慢」误判成「对方在撒谎」，并停止信任一个诚实的伙伴。
所以必须给证据加 `(t_stamp, seq, ttl)`，给同步残差做传输延迟校准，并把通信故障并入新的干扰集 `ℰ_comm`。

**灵感 6（理论姿态 → R69 是零延迟边界）**
直觉：本轮最重要的理论纪律仍然是「新层是旧层的严格泛化」。当 τ→0、无丢包、`ρ_M≡1`、时域无限时，D-VoI 退化为 R69 的 VoI、通道调度退化为 MINT、承诺规则恒等、行为逐指令相同。延迟只会**移除**交互选项（不会新增安全风险），所以任意延迟配置下期望风险 ≤ R69。安全侧不让步，效率侧获得「时间折扣后的 resolution bonus」。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（TIDE-RAS 总览）** TIDE-RAS = (AIL, DVOI, CMS, ASE, TCS, RAS-WM†)，构建在 FLUID-RAS 之上。三不变式：
(i) **快环零阻塞**：控制回路永不等待通信；跨层只通过无锁证据快照交换；
(ii) **证据时效**：任何证据携带 `(t_stamp, seq, ttl)`，过期、乱序、重放一律拒绝；
(iii) **截止时间纪律**：仅当 `P(τ_c ≤ d − δ) ≥ p_min` 时发起交互，否则不发起或放弃，退 R69/R68。

**定义 311（交互时延模型）** 通道集合 `C = {gaze, probe, ask_local, ask_remote}`。每通道 `c` 有端到端时延 `τ_c ~ D_c`（重尾、对数正态），丢包率 `p_loss,c`、乱序率 `p_reorder,c`。端到端分解 `τ = τ_sense + τ_up + τ_think + τ_down + τ_fuse`。只用 `p50/p95` 不足以描述重尾，风险决策用上分位数 `τ_c^{p95}` 与超时概率。

**定义 312（带时效的证据）** 证据 `e = (y, c, t_stamp, seq, ttl)`，年龄 `a(t) = t − t_stamp`。可接受 iff `a ≤ ttl` 且 `seq > last_seq[c]`（单调）。时效衰减似然 `p_a(y|M) ∝ p(y|M)^{κ(a)}`，`κ(a)=e^{−a/τ_evid}`；`a > ttl` 视为零信息。**乱序的旧 `seq` 直接丢弃，绝不覆盖新证据。**

**定义 313（模态持续性）** 模态过程 `M_t`，自相关 `ρ_M(Δ) = Corr(M_t, M_{t+Δ})`，半衰期 `τ_M = −Δ / ln ρ_M(Δ)`。**持久歧义** `τ_M ≫ d`（晚问仍有效）；**瞬态歧义** `τ_M ≲ τ`（问到时已过期）。R69 隐含 `ρ_M ≡ 1`。

**定义 314（延迟感知 VoI，D-VoI）** 对通道 `c`：
`D-VoI(c) = E_{τ_c}[ ρ_M(τ_c) · ( H(M_t|o_t) − E_y[H(M_{t+τ_c}|o_t,y)] ) ] − c_wait(τ_c) − c_energy(c)`，
其中 `ρ_M(τ_c)` 是信息在 τ 后仍关于当前模态有效的概率，`c_wait` 是等待期间保守动作的机会成本。**R69 的 VoI 是 `ρ_M≡1, τ=0, c_wait=0` 的特例。**

**定义 315（延迟-信息前沿与通道调度 CMS）** 每通道给出 `(τ_c^{p50}, τ_c^{p95}, I_c)`。选择
`c* = argmax_c D-VoI(c)`，s.t. `P(τ_c ≤ d−δ) ≥ p_min`、预算未超、安全认证通过。
允许多通道并行：按到达顺序做异步贝叶斯更新；也可**流水线**——先执行低信息快动作，慢通道答案只修正下一拍先验（定义 317）。

**定义 316（任意时刻承诺与等待期权 ASE）** 剩余时隙 `r`、安全截止 `d`。继续等待的边际期权价值 `OV(r) = E[下一时刻证据带来的风险降低] − P(过期)·风险(过期等待)`。承诺规则：当 `OV(r) ≤ 0` 或 `r ≤ δ`（缓冲覆盖控制周期 + 执行抖动）时，**停止等待**，以当前信念执行。保证永不 deadline miss。

**定义 317（异步交互层 AIL）** 独立线程/进程：快环提交 `g`，AIL 负责发送、超时、受限重试、回收、验签与时序校验、TTL 过滤，写入证据队列 `Q`。快环每拍只读 `Q` 的**最新快照**（seqlock/RCU，非阻塞）。`Q` 是唯一跨层状态，快环读操作 O(1)、无锁、永不等待。

**定义 318（传输延迟校准的同步残差 TCS）** 把 R68 的 `r_sync` 拆为 `r_sync = r_transport + r_content`，`r_transport` 由已知/估计的通道延迟分布解释；校准后的 `r_content = r_sync − ĝ_transport(τ̂)`。**只有 `r_content` 进入欺骗证据集**，避免「网络慢 = 在撒谎」的假阳性。

**定义 319（通信干扰集 ℰ_comm）** 丢包、超时、乱序、重放、延迟注入（deadline attack）、重复问句诱发预算耗尽、时间戳伪造、良性 lag 伪装欺骗。AIC：`ℰ_TIDE = ℰ_FLUID × ℰ_comm`。

**定义 320（证书 J_TIDE）** `J_TIDE = (J_FLUID, evidence_age_p95, ttl_violations, deadline_miss, staleness_bound, async_block_count, channel_mix, comm_attack_block_rate, tide_ver)`。Valid ⇔ `Valid(J_FLUID)` ∧ 证据全在 TTL 内 ∧ 快环零阻塞 ∧ `deadline_miss=0`。

**定义 321（延迟扩展的两级退避）** 若 `D-VoI ≤ 0`、`P(及时到达) < p_min`、通信不可信、或已近截止：不发起/放弃交互，`U_epi` 视同未消解，走 R69 定义 307 的保守（`λ = λ_floor(U_ale + U_epi)`）。⇒ **R69 是 τ→0、无丢包、`ρ_M≡1`、`d→∞` 的严格退化边界。**

**定义 322（时效状态与新鲜度指数）** 定义系统的「证据新鲜度」`F = min_e (ttl_e − a_e)/ttl_e ∈ [0,1]`，以及「有效交互预算」`B_eff = B − 因丢包/超时浪费的预算`。`F < F_min` 时禁止任何新的 VoI 触发，只能走 R68 兜底。

**定义 323（重尾下的鲁棒 VoI）** 当 `D_c` 为重尾时，用 CVaR 替代期望：`D-VoI_CVaR(c) = CVaR_α[ ρ_M(τ)·信息增益 ] − c_wait`。避免均值被少量超长延迟掩盖、在尾部场景误发起交互。

**定义 324（跨轮证据的过期语义）** 跨轮保留的证据、模态先验与审计结论都带时间戳；超过 `ttl_round` 的先验在下一轮降权而非直接删除，防止「上一轮的自信」污染本轮，也防止瞬态现象被长期记忆固化。

**定义 325（延迟-欺骗联合判据）** 对同步残差与到达时刻的联合分布，定义 `(r_content↑, a↑)` 为内容欺骗模式、`(r_transport↑, a↑)` 为传输延迟模式、`(r_content↑, a modest)` 为即时的跨模态共谋。该三元划分把 R69 的 `ℰ_poison` 与 `ℰ_comm` 在观测层分开，是识别「良性 lag 伪装欺骗」的形式化依据。

## 2. 关键算法骨架

```python
# IP-264 AIL：异步交互层（快环永不等待通信）
class AsyncInteractionLayer:
    def __init__(self, send_fn, clock):
        self.send, self.clock = send_fn, clock
        self.Q = EvidenceQueue()                      # seqlock / RCU
        self.last_seq = defaultdict(int)
    def submit(self, g, deadline):
        self.send(g)                                  # 非阻塞
    def on_message(self, msg):                        # 异步回调
        e = Evidence(y=msg.y, c=msg.c, t=msg.t_stamp,
                     seq=msg.seq, ttl=msg.ttl)
        if self.clock() - e.t > e.ttl: return          # 过期 → 丢弃
        if e.seq <= self.last_seq[e.c]: return         # 乱序/重放 → 丢弃
        self.last_seq[e.c] = e.seq
        self.Q.publish(e)                              # 快照原子替换
    def snapshot(self):                                # 快环只读、O(1)、无锁
        return self.Q.read()

# IP-265 DVOI：延迟感知 VoI（含模态半衰期与重尾 CVaR）
def dvoi(channel, belief, deadline, rho_M, alpha=0.95):
    gain = entropy(belief.w) - expected_entropy(belief, channel)
    samples = [rho_M(tau) * gain - wait_cost(tau) - energy(channel)
               for tau in channel.latency_samples]
    val = cvar(samples, alpha)                         # 重尾鲁棒
    arrive = P(channel.tau <= deadline - DELTA)
    return val if arrive >= P_MIN else -inf

# IP-266 CMS：通道调度（延迟-信息前沿 + 流水线）
def schedule(belief, channels, deadline):
    feasible = [c for c in channels
                if pik(c) and budget.allow(c) and c_ras_wm.certify_info(c)]
    c = max(feasible, key=lambda c: dvoi(c, belief, deadline, rho_M))
    if dvoi(c, ...) <= 0: return None                 # 无利可图 → R69/R68
    return Pipeline([c] + fast_prefix(channels))       # 快通道先执行

# IP-267 ASE：任意时刻承诺（等待期权）
def anytime_commit(belief, remaining, deadline):
    if remaining <= DELTA or option_value(belief, remaining) <= 0:
        return COMMIT                                  # 停止等待，以当前信念执行
    return WAIT

# IP-268 TCS：传输延迟校准的同步残差
def calibrated_sync(r_sync, tau_hat):
    return r_sync - transport_lag_model(tau_hat)       # 只把 r_content 送入欺骗证据

# IP-274 主闭环（继承 R69，把同步交互替换为异步证据消费）
def TIDE_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    snap = M.ail.snapshot()                            # 非阻塞读，可能为空
    belief = M.aud.decompose(M.fmp.sample(o, K=K_of(z)), z, M.fmp.mode_head)
    belief = M.belief.update(belief, snap, decay=KAPPA)  # 时效衰减后验
    U_ale, U_epi = belief.U_ale, belief.U_epi
    # 仅在「持久歧义 + 来不及则不问」时发起交互
    if U_epi > TAU_EPI and not slow_fault_suspect(M):
        g = M.cms.schedule(belief, M.channels, deadline=M.control_deadline)
        if g is not None: M.ail.submit(g, deadline=M.control_deadline)
    # 承诺：不阻塞等待，当前拍用现有信念执行
    r = M.control_deadline - now()
    if anytime_commit(belief, r, M.control_deadline) == COMMIT:
        U_floor = U_ale + U_epi                        # 未消解 → R69/R68 保守
    else:
        U_floor = U_ale                                # 已有够新证据 → resolution bonus
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_mode(belief.modes, U_epi, lam)
    tau_cmd = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_i.submit_async(g if 'g' in locals() else None, snap, a_hat)
    return k, lam, mode, belief
```

## 3. 推导

**引理 19（信息半衰期）** 若 `ρ_M(Δ)=e^{−Δ/τ_M}`，则延迟 τ 后的期望信息增益 `≤ I₀·e^{−τ/τ_M}`。系：交互值得当且仅当 `I₀·e^{−τ/τ_M} > c_wait + c`，即 `τ < τ_M·ln(I₀/c)`。因此 R69 的零延迟 VoI 系统性地把收益高估了 `e^{τ/τ_M}` 倍。要点：**「可约」不等于「此刻值得约」；持久且分得开的歧义才值得问。**

**引理 20（异步解耦保持实时）** 快环只读 `Q` 的快照，读操作 O(1)、无锁；任何通信时延不进入控制关键路径。无新鲜证据时，决策与 R69 fallback 同分布。⇒ 通信延迟不改变最坏控制周期上界。

**引理 21（时效纪律的投毒/重放上界）** 接受规则 `a ≤ ttl ∧ seq 单调` 使重放旧答案的成功率 `≤ P(ttl 内 ∧ seq 伪造) ≤ δ_time`。延迟注入把答案推到 TTL 外 ⇒ 拒绝，退 R69。攻击者最多造成「无信息」（可用性攻击），无法造成「错误信息被采纳」（完整性攻击）——**前提是时间戳不可伪造**。系：同步时钟或验签是 TIDE 的信任根。

**定理 18（TIDE 严格包含 R69）** 当 `τ_c→0, p_loss→0, ρ_M≡1, d→∞` 时，`D-VoI→VoI`、`CMS→MINT`、承诺规则恒等，行为与 R69 逐指令相同；且任意延迟配置下期望风险 ≤ R69（延迟只移除交互选项，不新增风险；在途证据总被 TTL/承诺规则在截止前截断）。安全侧不让步，效率侧获得「时间折扣后的 resolution bonus」。

**定理 19（截止安全与无突变）** 承诺规则保证每拍决策在 `d` 前产生；快环零阻塞；AIL 只改未来先验、不改当前已认证动作；失败/超时/丢包时 `λ` 单调不降地退化为 R69/R68；换装不变式（R68 定理 15）保持 ⇒ 控制连续、无突变、`deadline_miss=0`。

**引理 22（延迟-欺骗可分性）** 若传输延迟 `τ_transport` 与内容一致性在给定通道下条件独立，则联合观测 `(r_sync, a)` 的三类模式 `(r_content↑,a↑)`、`(r_transport↑,a↑)`、`(r_content↑,a modest)` 在 `τ_c` 已知时可由贝叶斯因子分开，避免把良性 lag 判为欺骗。系：定义 318 的校准把 R68 同步残差的假阳性率从「凡不同步即欺骗」降到「仅内容不一致才欺骗」。

## 6. 本轮最大风险

**一句话**：TIDE-RAS 把「何时该等」押在**延迟分布与模态半衰期的估计**上——若 `τ_M` 被低估（误以为歧义会自己消失）或重尾延迟被均值掩盖，系统就会在**信息已过期**时仍去问，或在该等时过早承诺；更糟，若时间戳可伪造，重放的旧答案会被盖上「新鲜且已验证」的章，R69 的「问错比不问更危险」升级为「**晚到的正确答案与准时的错误答案无法区分**」。

**次级风险与缓解**：
1. **异步层状态竞争/脏读** → seqlock/RCU + 单调 seq + 快照不可变（定义 317、引理 20）；
2. **延迟重尾导致预算耗尽** → CVaR 鲁棒 VoI + 有效预算 `B_eff` + 重复问句抑制（定义 322/323）；
3. **良性 lag 被误判为欺骗** → `r_transport/r_content` 分解 + 贝叶斯可分（定义 318、引理 22、E308）；
4. **时间戳伪造/重放** → 验签/同步时钟 + TTL + 单调序列（定义 312、引理 21）；
5. **跨轮先验污染** → 证据过期语义与降权（定义 324、E313）。

## 2. 形式化定义（要点版）

**定义 310（总览与三不变式）** `TIDE-RAS=(AIL,DVOI,CMS,ASE,TCS,RAS-WM†)`；快环零阻塞；证据须 `(t_stamp,seq,ttl)` 且在期内、序内；交互仅在 `P(τ≤d−δ)≥p_min` 时发起，否则退 R69/R68。

**定义 311–312（时延模型与带时效证据）** 通道 `c`：`τ_c~D_c`、`p_loss,c`、`p_reorder,c`；证据可接受 iff `a≤ttl ∧ seq>last_seq`；似然按 `κ(a)=e^{−a/τ_evid}` 衰减；乱序旧证据丢弃不覆盖。

**定义 313–314（模态持续性与 D-VoI）** `τ_M=−Δ/ln ρ_M(Δ)`；`D-VoI(c)=E_τ[ρ_M(τ)·infoGain]−c_wait−c_energy`。R69 的 VoI = `ρ_M≡1, τ=0, c_wait=0` 特例。

**定义 317（异步交互层）** AIL 独立线程负责发送/超时/重试/TTL/seq 校验并写证据队列；快环只读不可变快照（seqlock/RCU），O(1) 无锁。

```python
# IP-264 AIL：异步交互层（快环永不等待通信）
class AsyncInteractionLayer:
    def submit(self, g, deadline): self.send(g)         # 非阻塞
    def on_message(self, msg):                          # 异步回调
        e = Evidence(msg.y, msg.c, msg.t_stamp, msg.seq, msg.ttl)
        if clock() - e.t > e.ttl: return                # 过期 → 丢
        if e.seq <= self.last_seq[e.c]: return           # 乱序/重放 → 丢
        self.last_seq[e.c] = e.seq
        self.Q.publish(e)                               # 快照原子替换
    def snapshot(self): return self.Q.read()            # 快环 O(1) 无锁

# IP-265 DVOI：延迟感知 VoI（半衰期折扣 + 重尾 CVaR）
def dvoi(channel, belief, deadline, rho_M, alpha=0.95):
    gain = entropy(belief.w) - expected_entropy(belief, channel)
    vals = [rho_M(tau)*gain - wait_cost(tau) - energy(channel)
            for tau in channel.latency_samples]
    return cvar(vals, alpha) if P(channel.tau <= deadline-DELTA) >= P_MIN else -inf

# IP-266 CMS：通道调度（延迟-信息前沿 + 流水线）
def schedule(belief, channels, deadline):
    feas = [c for c in channels
            if pik(c) and budget.allow(c) and c_ras_wm.certify_info(c)]
    c = max(feas, key=lambda c: dvoi(c, belief, deadline, rho_M), default=None)
    return None if c is None or dvoi(c, ...) <= 0 else Pipeline([c]+fast_prefix(channels))

# IP-267 ASE：任意时刻承诺（等待期权）
def anytime_commit(belief, remaining):
    return COMMIT if (remaining <= DELTA or option_value(belief, remaining) <= 0) else WAIT

# IP-268 TCS：传输延迟校准的同步残差
def calibrated_sync(r_sync, tau_hat):
    return r_sync - transport_lag_model(tau_hat)        # 只有 r_content 进欺骗集

# IP-274 主闭环（继承 R69，把同步交互替换为异步证据消费）
def TIDE_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    snap = M.ail.snapshot()                             # 非阻塞，可能为空
    belief = M.aud.decompose(M.fmp.sample(o, K_of(z)), z, M.fmp.mode_head)
    belief = M.belief.update(belief, snap, decay=KAPPA) # 时效衰减后验
    U_ale, U_epi = belief.U_ale, belief.U_epi

        g = M.cms.schedule(belief, M.channels, M.control_deadline)
        if g is not None: M.ail.submit(g, M.control_deadline)
    r = M.control_deadline - now()
    if anytime_commit(belief, r) == COMMIT:
        U_floor = U_ale + U_epi                         # 未消解 → R69/R68 保守
    else:
        U_floor = U_ale                                 # 有够新证据 → resolution bonus
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_mode(belief.modes, U_epi, lam)

    M.vqa_i.submit_async(g if 'g' in locals() else None, snap, a_hat)
    return k, lam, mode, belief
```

## 4. 推导

**引理 19（信息半衰期）** `ρ_M(Δ)=e^{−Δ/τ_M}` 时，延迟 τ 后信息增益 `≤ I₀·e^{−τ/τ_M}`；交互值得当且仅当 `τ < τ_M·ln(I₀/c)`。系：R69 的零延迟 VoI 高估收益 `e^{τ/τ_M}` 倍——**持久且分得开的歧义才值得问**。

**引理 20（异步解耦保持实时）** 快环只读无锁快照，通信延迟不进关键路径；无新鲜证据时与 R69 fallback 同分布。⇒ 最坏控制周期上界不变。

**引理 21（时效纪律的投毒/重放上界）** `a≤ttl ∧ seq 单调` 使重放成功率 `≤δ_time`；延迟注入被 TTL 拒绝。延迟攻击降级为可用性攻击，而非完整性攻击（前提：时间戳不可伪造）。

**引理 22（延迟-欺骗可分性）** `τ_transport` 与内容一致性条件独立时，`(r_content,a)`、`(r_transport,a)`、`(r_content, modest a)` 三类可由贝叶斯因子分开，避免把良性 lag 判为欺骗。

**定理 18（TIDE 严格包含 R69）** `τ→0, p_loss→0, ρ_M≡1, d→∞` 时 `D-VoI→VoI`、`CMS→MINT`、承诺恒等，逐指令相同；任意延迟下期望风险 ≤ R69（延迟只移除交互选项，不新增风险）。

**定理 19（截止安全与无突变）** 承诺规则保证每拍在 `d` 前决策；快环零阻塞；超时/丢包时 λ 单调不降退 R69/R68；换装不变式保持 ⇒ 控制连续、无突变、`deadline_miss=0`。

| E312 延迟+OOD | 双重压力 | OOD 检出 ≥ 90%，无交互风暴 |
| E313 24h 长时程 | 延迟漂移×疲劳 | 交互稳定，跨轮瞬态先验不固化 |
| E314 消融 | AIL/DVOI/CMS/ASE/TCS | 去 DVOI 收益高估回潮；去 ASE 出现 miss |
| E315 延迟-成功率 Pareto | 预算/等待档位 | 给出 D-VoI/延迟曲线拐点 |

## 7. 本轮最大风险

**一句话**：TIDE-RAS 把「何时该等」押在**延迟分布与模态半衰期的估计**上——若 `τ_M` 被低估或重尾延迟被均值掩盖，系统会在**信息已过期**时仍去问，或在该等时过早承诺；更糟，若时间戳可伪造，重放的旧答案会被盖上「新鲜且已验证」的章，R69 的「问错比不问更危险」升级为「**晚到的正确答案与准时的错误答案无法区分**」。

**次级风险与缓解**：异步层脏读/竞争（seqlock/RCU + 单调 seq + 不可变快照）；重尾耗尽预算（CVaR + `B_eff` + 重复问句抑制）；良性 lag 误判欺骗（`r_transport/r_content` 分解 + 贝叶斯可分）；时间戳伪造/重放（验签/同步时钟 + TTL + 单调序列）；跨轮先验污染（证据过期语义 + 降权）。
