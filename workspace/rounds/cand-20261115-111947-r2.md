# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；本轮灵感：「迁移学习」×「传感器融合」）

> R69 让系统学会了「问」，却把「谁有资格回答、谁来验证答案」这一前提留在了暗处：**它全部的自信——模态权重、标定、证书、证据纪律——都绑定在它出生时的那套传感器与那具身体上**。一旦换平台、换传感器套件、换环境，R69 不会报错，它会**继续自信**：旧的流策略仍在采样，旧的融合权重仍在加权，旧的证书仍然写着 Valid。这不是噪声，也不是歧义，而是**地图和城市对不上**。
>
> 本轮两个灵感正好给出两把尺子：
> - **迁移学习**告诉我们哪些东西可以「带走」——跨平台不变的动力学/接触/任务流形；也告诉我们哪些必须「重学」——传感器特异的融合接口；并且提供了**负迁移**这个概念：搬错了还不如不搬。
> - **传感器融合**告诉我们接口到底在哪里失效——异构传感器的覆盖与冗余、误差相关结构，以及「多装几个传感器」不等于「多几份独立证据」。

## 0. 直觉与动机

**灵感 1（迁移学习 → 证书有有效域，出错还有一种叫「越界」）**
直觉：R69 的三张底牌——流策略 p_θ、标定 COF、模态权重——都是在源域的数据流形上拟合的。换域之后它们未必「错」，而是「不在射程内」。像拿旧地图找新城市：地图没画错，是地方变了。把这种失败叫噪声（U_ale）会去无谓地收紧，叫歧义（U_epi）会去无谓地追问——两种都不对。它是第三种：**U_dom（域不确定性）：我的模型和这个世界还对得上吗？** 它既不能靠「慢一点」消，也不能靠「问一句」消，只能靠**重新证明对应关系**（迁移 + 标定）或者**放弃外推、退回源域已知安全的行为**。注意它的不可交互性：你问环境「你是不是换了一具身体」，环境不会回答；U_dom 的可约化算子是「重认证」，不是「交互」。

**灵感 2（传感器融合 → 「多传感器」会制造虚假置信）**
直觉：R69 的证据纪律假设 k 个正交证据源，投毒上界 δ_p·ρ^{k−1}。但真实的多传感器不是 k 份独立证据：共享支架、共享电源、共享标定、共享环境 → 误差高度相关。N 个等方差传感器的最优融合方差是 σ²(1+(N−1)ρ)/N；若误设独立，报告 σ²/N，**被虚窄了 κ=√(1+(N−1)ρ) 倍**。等价地，**有效独立传感器数 N_eff = N/(1+(N−1)ρ)**，ρ→1 时 N_eff→1：再多的传感器也只有一份证据。于是「加了传感器」会让系统报告更窄的置信区间、做更少的交互、收更少的紧——**恰在它证据最不独立的时候最自信**。迁移到新平台时相关性结构未知且通常更高（便宜的转接件、共享总线），这把「融合」从安全网变成了**共模放大器**。

**灵感 3（迁移的两半 → 带走规律，重学接口）**
直觉：R69 的 z_t = Φ(o_t) 把感知和动力学揉在一起。可以拆成 z = (z_inv, z_spec)：z_inv 是接触/受力/任务进度这类**跨平台不变**的量；z_spec 是具体传感器的几何、量纲、安装、噪声。迁移应该**冻结 z_inv 编码器（带走规律），只用少量目标示教适配 z_spec 融合层与低秩 adapter（重学接口）**，并用源策略在目标状态上的蒸馏做「锚」，防灾难性遗忘。这样迁移是「局部手术」，不是「整机重训」——也才有可能保留证书。

**灵感 4（负迁移 → 迁移本身必须被证明，而不是被相信）**
直觉：迁移不是免费午餐。经典域适配界 R_t ≤ R_s + d(源,目标) + λ* 说明：源域再好，域散度大或理想联合误差大时目标域仍可能更差——这就是**负迁移**。关键是 R69 已经有一条现成的、可测的散度代理：**流似然**。定义迁移增益 G = E_t[log p_θt(ξ|o)] − E_t[log p_θs(ξ|o)]（在同一批独立目标数据上比较目标策略与源策略）。G < 0 ⇒ 负迁移，拒绝。**「能搬」不等于「该搬」；只有被证书证明为增益的迁移才允许生效。**

**灵感 5（迁移期安全 → 运行中只读不学）**
直觉：R68/R69 的铁律是实时流零学习写操作，正是为了防止一次坏更新当场失控。迁移适配天然是一次「写」——所以它必须发生在 **commissioning（调试/预热期）或受卫离线缓冲**里，适配完重新跑全部证书，再按 R68 定理 15 热换装；运行中只允许「读」和「拒绝」，不允许「学」。**适配失败就回滚，回滚不改安全包络。** 这把「迁移」从一次赌博变成一次可审计的换装。

**灵感 6（缺模态 → 退化是一等公民）**
直觉：新平台常常少一个传感器（没有触觉阵列、没有力矩、没有某路相机）。与其把它当故障，不如在源域训练时就随机 dropout 模态，让融合层学会**缺失时重归一化**，并输出 (融合量, active_mask, N_eff)。缺模态于是不是「失效」，而是「切换到一个已知的、更保守的配置」——R68/R69 一直把退化当补救，本轮把它变成**被认证的正常形态**。

# IP-264 STR：源-目标表征分解与轻量适配（源域只搬不变子空间）
class SplitTransferTrunk:
    def __init__(self, phi_inv, phi_spec, fusion, source_policy):
        self.phi_inv  = freeze(phi_inv)        # 跨平台不变：接触/动力学/任务进度
        self.phi_spec = phi_spec               # 传感器特异：几何/量纲/安装
        self.fusion   = fusion                 # 含 dropout 重归一化 + 相关感知
        self.pi_src   = source_policy          # 源策略，仅作蒸馏锚
        self.lora     = LowRankAdapter()       # 只对 phi_spec/融合微调

    def encode(self, o, active_mask):
        z_inv  = self.phi_inv(o)                          # 冻结
        z_spec = self.phi_spec(o, active_mask)            # 适配对象
        z, neff = self.fusion(z_inv, z_spec, active_mask) # 相关性感知 + 重归一化
        return z, neff

# IP-266 CCF：相关性感知融合 + N_eff + 虚假置信因子（Σ̂ 在 commissioning 估，在线只乘）
def corr_aware_fuse(ys, W, Sigma_hat):
    rho   = mean_offdiag_corr(Sigma_hat)
    N     = len(ys)
    N_eff = N / (1 + (N - 1) * rho)                       # 等相关近似
    kappa = sqrt(1 + (N - 1) * rho)                       # 误设独立时的虚窄倍数
    sigma_f2 = 1.0 / (ones @ inv(Sigma_hat) @ ones)
    return (W @ ys, sigma_f2, N_eff, kappa)

# IP-268 TCG：迁移证书门（评估集必须与适配集分离，防自评偏差）
def transfer_gate(pi_tgt, pi_src, D_eval, cert_src, mar):
    G     = mean(logp(pi_tgt, xi, o) - logp(pi_src, xi, o)
                 for (o, xi) in D_eval)                   # 独立目标评估集
    d_hat = domain_divergence_proxy(pi_tgt, pi_src, D_eval)   # XFA 提供
    B_t   = cert_src.risk_bound + d_hat + lambda_star_hat(D_eval)
    ok = (B_t <= cert_src.risk_bound - DELTA
          and G >= 0
          and mar.kappa <= KAPPA_MAX
          and mar.N_eff >= N_MIN
          and mcg_pass(pi_tgt, D_eval))                   # R69 校准门
    return ok, dict(G=G, d_hat=d_hat, B_t=B_t)

# IP-271 SDA：commissioning 适配 → 证书 → 热换装（运行中只读）
def commission_adaptation(M, D_target, holdout):
    M.split.lora.fit(D_target, anchor=M.pi_src, kl=KL_ANCHOR)  # 冻结 phi_inv
    Sig   = shrink_cov(estimate_cov(D_target), prior=Sig_src, alpha=ALPHA)
    W     = inv(Sig) @ ones / (ones @ inv(Sig) @ ones)
    mar   = corr_aware_fuse_stats(Sig)
    ok, info = transfer_gate(M.pi_tgt, M.pi_src, holdout, M.cert_src, mar)
    if not ok:
        return reject_and_fallback_R69(M)              # 负迁移/共模/校准失败
    cert = issue_J_SHIFT(M, info, mar)                 # 定义 322
    hot_swap(M.pi_tgt, cert)                           # R68 定理 15 不变式
    return cert

## 3. 推导

**引理 19（可测域散度代理）** 设目标风险 R_t、源风险 R_s。在 A99（存在理想联合假设，λ* 有界）下，R_t ≤ R_s + ½ d_{HΔH}(D_s, D_t) + λ*。流似然的跨域差 Δa_dom 在 A98（策略密度对条件 Lipschitz）下是 d_{HΔH} 的单调代理：d_{HΔH} ≥ c·E_t[Δa_dom] − ε_flow。故 TCG 用 (R̂_s, d̂, λ̂*) 构造的目标上界是可证的可测界（取上界而非点估计），保守性来自「包住」而非「算准」。

**引理 20（融合虚假置信 / N_eff）** N 个等方差 σ²、等相关 ρ 的传感器，最优（=对称）融合方差 σ_f² = σ²(1+(N−1)ρ)/N。独立误设报告 σ²/N。故：(i) 有效独立数 N_eff = N/(1+(N−1)ρ)，ρ→1 时 N_eff→1——再加传感器也只是同一份证据的复制；(ii) 置信区间被虚窄 κ = √(1+(N−1)ρ) 倍；(iii) 若 ρ 被低估 Δρ，方差低估因子约 1+(N−1)Δρ，随 N 线性放大。系：**「多传感器」不是「多证据」；跨域共享失效模式会把 N 折成 N_eff，R69 的投毒上界 δ_p·ρ^{k−1} 必须换成 δ_p·ρ^{k_eff−1}。**

**引理 21（负迁移门的保守性）** 若仅在 B_t ≤ B_s − δ 时接受适配，则被证书担保的目标风险 ≤ B_s − δ < B_s（源域证书界）；拒绝时退回源域策略，风险 ≤ B_s。故 SHIFT 在目标域的风险上界 ≤ 源域证书界：**迁移只会「更好或不变」，不会「更差」**——前提是 B_t 的界有效（A99 + 引理 19）。

**引理 22（k_eff 修正的证据纪律）** R69 引理 18 的 δ_p·ρ^{k−1} 中 k 实为有效独立源数。相关共模下 k → k_eff = N_eff。若新平台使 ρ↑（共享转接件/总线），即使传感器个数 k 不变，错误采纳上界也单调上升；k_eff → 1 时退回单源，证据纪律失效。系：**「加传感器」必须先证明它真的抬高了 N_eff，否则是在给共模攻击加权重。**

**定理 18（SHIFT 严格包含 R69）** 在 A98–A99 下，目标=源（无域移）时 d̂=0、G=0、κ=0、N_eff=N，TCG 平凡通过，SHIFT 逐指令退化为 R69；一般情形下 SHIFT 的期望风险 ≤ R69 在源域的证书界（引理 21），且当 TCG 拒绝/κ 越界/N_eff 不足/U_dom 超阈时两者逐指令相同（都走源域保守）。故 R69 是 SHIFT 在「零域移」边界上的退化；安全侧不让步。

**定理 19（迁移安全与热换装无突变）** 适配只在 commissioning/受卫离线发生，运行中只读（定义 319）；热换装复用 R68 定理 15 的提交/换装不变式；回滚不改安全包络。⇒ 适配期与换装期控制连续、无突变；任何适配失败都单调退化为源域策略（定义 323），安全界不降。

## 4. 推导

**引理 19（可测域散度代理）** A99（λ* 有界）下 `R_t ≤ R_s + ½d_{HΔH} + λ*`；A98 下流似然跨域差 `Δa_dom` 是 `d_{HΔH}` 的单调代理：`d_{HΔH} ≥ c·E_t[Δa_dom] − ε_flow`。故 TCG 的上界是可证可测界（取上界而非点估计），保守性来自「包住」。

**引理 20（融合虚假置信 / N_eff）** 等方差等相关 N 传感器：`σ_f² = σ²(1+(N−1)ρ)/N`。独立误设报 `σ²/N` ⇒ 有效独立数 `N_eff=N/(1+(N−1)ρ)`（ρ→1 时 →1），置信区间虚窄 `κ=√(1+(N−1)ρ)` 倍；ρ 低估 Δρ 时方差低估约 `1+(N−1)Δρ`，随 N 线性放大。系：多传感器 ≠ 多证据。

**引理 21（负迁移门的保守性）** 仅当 `B_t≤B_s−δ` 才接受 ⇒ 目标风险 ≤ `B_s−δ`；拒绝退回源域 ⇒ ≤ `B_s`。故迁移只会「更好或不变」，不会更差（前提界有效：A99+引理 19）。

**引理 22（k_eff 修正证据纪律）** R69 的投毒上界 `δ_p·ρ^{k−1}` 中 k 实为有效独立源数；共模下 `k→k_eff=N_eff`，新平台 ρ↑ 时错误采纳上界单调上升，`k_eff→1` 退化为单源。系：加传感器必须先证明抬高 N_eff，否则是给共模攻击加权重。

**定理 18（SHIFT 严格包含 R69）** 零域移时 `d̂=0,G=0,κ=0,N_eff=N`，TCG 平凡通过 ⇒ 逐指令退化为 R69；一般情形目标风险 ≤ R69 源域证书界（引理 21）；TCG 拒绝/κ 越界/N_eff 不足/U_dom 超阈时两者逐指令相同（都走源域保守）。安全侧不让步。

**定理 19（迁移安全与热换装无突变）** 适配离线、运行只读；热换装复用 R68 定理 15 提交/换装不变式；回滚不改安全包络 ⇒ 适配/换装期控制连续、无突变，任何失败单调退化为源域策略。

## 6. 实验设计 E301–E315

| 实验 | 核心问题 | 关键目标 |
|---|---|---|
| E301 表征分解可迁移性 | z_inv 是否跨平台不变 | 漂移 ≤ ε_inv，性能保持 ≥ 90% |
| E302 负迁移检测 | TCG 拦「越搬越差」 | 负迁移接受 ≤ 5%，G<0 召回 ≥ 95% |
| E303 相关共模融合 | κ/N_eff 准不准 | κ 误差 ≤ 15%，虚窄 CI 被修正 |
| E304 N_eff 修正证据纪律 | 上界是否可信 | 覆盖经验错误率，过紧率 ≤ 2% |
| E305 缺模态迁移 | 少传感器优雅退化 | 缺 1–2 模态降幅 ≤ 8%，active_mask 全记 |
| E306 标定迁移可辨识性 | 不可辨识方向被拒 | 禁外推 100%，可辨识分量 ≤ 源域 1.2× |
| E307 跨本体/sim-to-real | 真迁移有效 | 成功率 ≥ 源域 −5%，换装零违规 |
| E308 迁移后门 | 源域植入随适配激活 | 激活 ≤ 1%，TCG+FEA 拦截 |
| E309 热换装无突变 | 换装期连续 | jerk/超调与稳态无显著差异 |
| E310 目标域 24h | 漂移 × 负迁移 | 交互/收紧稳定，零适配诱发违规 |
| E311 对 R69 严格包含 | 零域移逐指令一致 | 目标=源时行为差 = 0 |
| E312 融合证据审计 | 归因准确 | 驱动传感器归因 ≥ 90% |
| E313 在线预算 | 域门控守时 | 常规 P99 < 2.7ms |
| E314 相关性误设鲁棒 | 高/低估 ρ 代价 | 低估不降安全（κ 门），高估仅效率损失 |
| E315 迁移 Pareto | 示教增益/成本曲线 | 给「示教数—增益—证书风险」拐点 |

## 7. 本轮最大风险

**一句话**：SHIFT 的迁移证书与适配**共用那点稀缺的目标域数据**，而目标域的共模相关 ρ 又总被低估（新支架/新总线天然共享失效模式、样本又少）——于是「自评」给出乐观的迁移增益、融合又报出虚窄的置信，系统**恰在最缺证据的地方最自信**，可能把一次有害的负迁移盖章为「已验证的进步」。

**次级风险与缓解**：自评偏差（定义 316 强制 holdout 与 D_target 不相交 + E302）；ρ 低估（shrink 向保守先验 + κ 门限 + E303/E314）；N_eff 不足（n_min 门控，低于阈值退回 R69）；迁移后门（ℰ_xfer 对抗 + FEA 归因 + E308）；标定外推（定义 317 可辨识性 + 保守上界 + E306）。
