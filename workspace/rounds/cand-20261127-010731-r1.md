# 灵感驱动研究循环 · 第 1 轮（v24）

本轮灵感：「跌倒恢复」×「个性化交互」

> **基线**：MetricVoiceGauge-NCD-HUTDH-v23（HPC-E+ 四证准入门：HPC-E ∪ CESC ∪ FSVC ∪ IPAttest；其上承 v22 分层 PGEV/ACSC/DCSC、v21 语义-规范层 SDC/CAC/DCL/GIC、v20 联邦感知证书 PCA/CTS/CFC/HPC、v19 DCM/OGCC/CCV/DRS/OGC、v17 感知链 CLP/S2C/HCG/PSV/APS/AMC）。
> **本轮纪律**：**安全是"别进入坏状态"，可恢复是"进入后能回来"——两者是对偶不变量，不是包含关系；个性化不是放宽标准，而是向已认证包络的投影。** 不推倒 v23：PCA/CTS/CFC/HPC、SDC/CAC/DCL/GIC、HDL/ACSC/DCSC、CESC/FSVC/IPAM 全部保留。本轮只做一件事：**给 v18–v23 这条只会单向下调的单调链补上第二条轴——可恢复性/活性 (liveness)**，并把人从"一个通用障碍物"升级为"带跌倒风险与知情同意的异构个体"。

## 0. 直觉与动机

**灵感 1（跌倒恢复 → 可恢复性是对安全的对偶，而不是安全的子集）**
直觉：v18–v23 的所有证书都在回答"会不会进入坏状态"（碰撞、违规、能量不足、侵权……），并且刻意设计成**单向棘轮**：一有故障就只会更保守（`Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`）。这套体系有一个被忽略的盲区：**它从不回答"已经掉进坏状态之后怎么办"**。一个四足机器人侧翻在地，是物理上最安全的状态（静止、低能量、不撞人），却是运行上最灾难的状态（完全失去服务能力，且可能永远起不来）。也就是说，"安全"与"可恢复/可用"是**两个正交坐标**：跌倒态恰好是 `m ≥ 0`（安全裕度非负）而 `r < 0`（恢复裕度告负）的典范。核心创新：**可恢复性证书 (Recovery Viability Certificate, RVC)** 与 **跌倒态证书 (Fallen-State Certificate, FSC)**——把"存在一条在时间 `T_rec`、能量 `E_rec` 预算内、且沿途不破坏任何 v23 证书的返回路径"形式化为新的准入不变量。关键反直觉点：**恢复不是退化的逆运算**；退化可以瞬间发生（单向、无需证明），恢复必须逐张重新取证并跨过滞回门槛——这恰好给 v22 遗留的"层级退化振荡"风险提供了原理性解药。

**灵感 2（个性化交互 → 个性化是向已认证包络的投影，只能收紧或重分配）**
直觉：v18–v23 里的"人"是一个**通用障碍物**：统一的个人空间、统一的速度上限、统一的召回下界 `κ_c`、统一的意图门槛。但真实的人是异构的——儿童、拄拐老人、轮椅使用者、熟悉流程的同事，他们的**移动能力、跌倒风险、个人空间、沟通偏好、对机器人的信任与知情同意**都不同。个性化的诱惑是"按喜好放宽"，但那会击穿安全链。核心创新：**人条件包络 (Person-Conditioned Envelope, PCE)**：把每个用户 `u` 的画像 `θ_u` 映射为参数调整 `Δ_u`，并**强制投影到 v23 已认证的可行域** `Δ_u := Proj_{E_cert}(Π(θ_u))`。于是 `Exec(θ_u) ⊆ Exec(∅)` 恒成立：个性化只能让约束更紧（体弱者更大个人空间、更低速度、更小加加速度），或在不改变安全包络的前提下**重分配交互方式**（语音/手势/屏幕），绝不放宽。**跌倒风险直接参数化安全裕度**：`d_req(u) = d_base + γ·f_u + δ_cap(c_u)`，`v_max(u) = v_base·(1 - β·f_u)`——风险越高，机器人离得越远、越慢越柔，从源头降低"机器人把人碰倒"的概率。关键反直觉点：**"个性化"与"安全单调性"不矛盾，因为投影算子是压缩映射**。

**两者如何统一：人是异构的"恢复主体"，机器人是自恢复主体**
统一在 **v23 之上的"可恢复-个性化"层 (Viability-Recovery-Personalization, VRP)**：
- **RVC/FSC** 回答"这个状态还能不能回来、回不来时进入哪种受控恢复模式"；
- **PCE/TCL** 回答"对这个人，安全包络与恢复协助的边界在哪里"；
- **FERC** 回答"当人跌倒时，机器人该以多高的门槛介入（接触/非接触）"。
最妙的耦合：**机器人自身跌倒后的自恢复可能需要旁人协助，而是否允许/请求协助本身就是一个个性化交互问题（同意、信任、能力）**；反过来，**人跌倒的协助是一次"恢复动作"，必须走最高的证书门槛**。于是"跌倒恢复"与"个性化交互"在同一个对象——**可恢复性**——上合流。
共享状态扩展：`ζ_vrp = ζ_ce ∪ (V_rec, r(x), mode, θ_u, f_u, consent_u, trust_u, fall_events)`。
统一准入门：**HPC-R = (HPC-E+, RVC, PCE, FERC) 四证一体**；正常模式下 `Exec_v24 = Exec_v23 ∩ Fil_rec ∩ Fil_pers ⊆ Exec_v23`；恢复模式下正常任务集为空，只准入受认证的恢复机动 `RecSet ⊆ SafeExec_v23`。

## 1. 研究问题（Q12–Q15）

- **Q12（可恢复性的可靠性界）**：如何用**证书化方法**（而非精确可达集）给 `r(x)` 一个保守下界，使 `r(x) ≥ 0 ⇒ 存在真实恢复路径`的概率 `≥ 1-δ`？在模型不确定（摩擦、坡度、执行器退化、恢复扫掠区被人占据）下如何 fail-safe（模型不确定时把 `r` 往负里估）？可恢复性核 `V_rec` 的离线近似（抽象/学习值函数）如何与在线 O(1) 复核衔接？

- **Q13（退化-恢复的稳定性）**：单向快速退化 + 滞回慢恢复的 dwell-time `τ_dwell` 与阈值对 `(r_low, r_high)` 如何选取，才能同时保证**无 Zeno/无振荡**与**活性不坍缩**？恢复失败（`T_rec` 超时、能量不足、扫掠区被占）如何升级到"请求人类协助/停驻待援"，且升级本身可审计？

- **Q14（个性化的非扩张性）**：`Π` 的哪些自由度可安全投影（个人空间、速度、加加速度、交互模态）、哪些会击穿 `E_cert`（例如"关掉人体检测""允许更近接触"）？跌倒风险后验 `f_u` 的 conformal 上界 `f_hi` 如何在分布漂移（新鞋、疲劳、康复进展、季节衣着）下维持保守？多用户同时在场时包络如何取交？

- **Q15（跌倒事件的不对称响应）**：人体跌倒检测的**低门槛（高召回）**与协助动作的**高门槛**（同意 ∧ 能力匹配 ∧ 无搬动禁忌 ∧ ≥2 模态 ∧ 人类确认）如何统一为两级响应？漏检跌倒如何被手势/在场证据翻转（复用 GIC 的"手势蕴含在场"条款）？机器人自身跌倒与人体跌倒两条恢复链如何共享同一套 RVC 形式化？

## 2. 设计原则（在 P37–P42 基础上新增 P43–P46）

**P43 可恢复性不变量律（Recoverability Invariant）**
定义恢复裕度 `r(x) = min(时间余量, 能量余量, 净空余量)`，取遍所有"受认证恢复机动"的最坏情形：
`r(x) = max_{π ∈ RecManeuvers(x)} min( (T_rec - dur(π))/T_rec, (E_res - E_rec - E(π))/E_res, (d_clear - sweep(π))/d_clear )`。
正常模式仅准入 `m(x) ≥ 0 ∧ r(x) ≥ 0` 的状态与计划；`r(x) < 0` 或检测到跌倒 → 进入恢复模式，正常任务集为空，仅准入 `RecSet ⊆ SafeExec_v23`。**可恢复性只增补"能回来"的约束，绝不新增自由空间。**

**P44 退化-恢复非对称律（Degrade-Fast-Recover-Slow / Hysteresis）**
退化是**瞬时且单向**的：任一证书失效、`m < 0` 或 `r < r_low` 立即下调到更低层级，无需证明。恢复是**慢且需证据**的：仅当全证书重签 ∧ `r ≥ r_high` ∧ `dwell ≥ τ_dwell` ∧（跌倒后）恢复态稳定 `≥ τ_stable` 才回升。因 `r_high > r_low` 且 `τ_dwell > 0`，模式机不存在无限快速切换（无 Zeno），从而**原理性消除 v22 的层级振荡风险**。

**P45 个性化非扩张律（Personalization Non-Expansion）**
个性化算子 `Π` 的输出必须投影到已认证包络 `E_cert`：`Δ_u := Proj_{E_cert}(Π(θ_u))`。故 `∀u: Exec(θ_u) ⊆ Exec(∅)`；个性化只能收紧（更大 `d`、更小 `v`、更小 `jerk`）或重分配交互模态。跌倒风险只能用其**上置信界 `f_hi`** 进入裕度，禁止用点估计放宽。多用户在场取各包络之交。

**P46 跌倒事件非对称律（Fall-Event Asymmetry）**
跌倒检测走**低门槛高召回**（`p ≥ q_fall_low` 即进入"疑似跌倒"，代价只是活性）；接触式协助走**最高门槛**（`p ≥ q_fall_high` ∧ `consent.assist ∧ consent.contact` ∧ 无搬动禁忌 ∧ `≥2` 模态 ∧ 人类确认 ∧ `trust ≥ trust_thr`）。不满足则退化为**非接触支持**（照明、封路、呼救、提供支撑物、保持在场）。机器人自身跌倒 → 立即恢复模式。任何被识别的手势或跌倒证据都**构造性地蕴含"有人在场"**，必须先作废该区域 AbsCert（复用 GIC 在场翻转），否则不得签发缺席证书。

## 3. 与基线的接口（如何退化）

- **RVC 失效**（可恢复性模型不可信）⇒ 回退 v23 纯安全模式：不主动进入未认证可恢复态，遇跌倒只做最保守自恢复或停驻 ⇒ 更保守；
- **FSC 失效**（跌倒检测失灵）⇒ 视为"可能已跌倒"，进入停驻待援 ⇒ 更保守；
- **PCE 失效**（画像缺失/投影异常）⇒ 用通用画像 `∅` ⇒ 等价 v23；
- **FERC 失效** ⇒ 跌倒只报警、绝不接触协助 ⇒ 最保守；
- **TCL 失效**（同意/信任账本不可用）⇒ 默认不协助，需现场口头二次确认 ⇒ 最保守；
- **全失效** ⇒ 完全回退 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ … ⊆ Exec_v18`；且恢复机动 `RecSet ⊆ SafeExec_v23`（恢复只在安全集内进行，不放宽安全链）。
- **安全继承**：RVC 只增加"可回来"约束；PCE 只做压缩投影；FERC 只在更高门槛下动作；TCL 只提供否决（信任/同意只能关闸、不能开闸）；任意失效都向更保守方向退化。

## 4. 预期贡献

1. **可恢复性证书（安全的对偶轴）**：首次把"进入后能否回来"形式化为与碰撞证书并列的准入不变量，给出 `r(x)` 的证书化保守下界与恢复机动准入；
2. **退化-恢复滞回**：单向瞬时退化 + 滞回慢恢复的 dwell-time 设计，证明无 Zeno/无振荡，原理性封堵 v22 的层级振荡风险；
3. **个性化非扩张投影**：证明 `Exec(θ_u) ⊆ Exec(∅)`，把"按人定制"从安全威胁变成压缩映射；
4. **跌倒风险参数化安全裕度**：用 `f_u` 的上置信界直接放大个人空间、降低速度/加加速度，从源头降低机器人诱发的跌倒；
5. **跌倒事件两级不对称响应**：低门槛检测 / 高门槛协助，接触协助假阳性概率有显式上界，漏检可被手势/在场证据翻转；
6. **HPC-R 统一门与单调链闭环**：`Exec_v24 ⊆ Exec_v23 ⊆ … ⊆ Exec_v18`，恢复机动 `RecSet ⊆ SafeExec_v23`。

## 5. 本轮最大风险

**一句话**：可恢复性证书把"能不能起来"押在机器人自恢复能力与环境模型（摩擦、坡度、空间）的准确性上；一旦真实恢复能力低于模型（打滑、执行器损伤、恢复扫掠区被人占据），机器人会自信地进入"模型认为可恢复、实际却逃不出"的状态；再叠加对特定用户跌倒风险的**系统性低估**，最坏情形是机器人"合规地、可审计地"把一个人置于它无法救助的跌倒中——即**"可恢复幻觉"与"个性化缺席幻觉"的叠加**。

## 1. 关键算法骨架（在 IP-440–446 骨架上扩展）

```python
# ============================================================
# IP-440 Recovery Viability Certificate (RVC) — 可恢复性证书
# ============================================================
@dataclass
class RecoveryBudget:
    T_rec: float = 8.0       # 秒
    E_rec: float = 0.15      # 归一化能量预算
    d_clear: float = 0.30    # 恢复扫掠区净空（米）

class RecoveryViabilityCertificate:
    """r(x) 的证书化保守下界：只接受"有受认证恢复路径"的状态。"""
    def __init__(self, budget: RecoveryBudget, delta: float = 1e-3):
        self.b = budget
        self.delta = delta
        self.V_rec = None     # 离线近似的可恢复性核（抽象表/学习值函数）

    def recovery_margin(self, x, env, robot) -> float:
        best = -math.inf
        for man in robot.recovery_maneuvers(x):          # 有限候选集
            if not self._safe_along(man, env):            # 沿途证书必须成立
                continue
            t_slack = (self.b.T_rec - man.duration) / self.b.T_rec
            e_slack = (robot.E_res - self.b.E_rec - man.energy) / max(robot.E_res, 1e-9)
            c_slack = (self.b.d_clear - man.swept_clearance(env)) / self.b.d_clear
            best = max(best, min(t_slack, e_slack, c_slack))
        return best   # r(x) ≥ 0 ⇔ 存在受认证恢复路径

    def _safe_along(self, man, env) -> bool:
        # 每个离散构型必须落在 S_safe，且恢复扫掠区无"未认证人"
        for cfg in man.trajectory:
            if not env.safe(cfg):
                return False
            if env.person_in(cfg.swept) and not env.abs_cert_valid(cfg.swept):
                return False
        return True

    def admits(self, x, env, robot) -> bool:
        return self.recovery_margin(x, env, robot) >= 0.0

    def conservative_r(self, x, env, robot) -> float:
        # 模型不确定时把 r 往负里估：用参数下界 env.lower_bound() 重算
        return min(self.recovery_margin(x, env.lower_bound(), robot),
                   self.recovery_margin(x, env, robot))


# ============================================================
# IP-441 Fallen-State Certificate (FSC) — 跌倒态与恢复模式机
# ============================================================
class RecoveryModeMachine:
    def __init__(self, r_low=0.0, r_high=0.20, tau_dwell=2.0, tau_stable=1.0):
        self.mode = "NOMINAL"
        self.r_low, self.r_high = r_low, r_high
        self.tau_dwell, self.tau_stable = tau_dwell, tau_stable
        self.since_switch = 0.0
        self.stable_since = None

    def update(self, dt, m, r, fallen, certs_ok):
        self.since_switch += dt
        # --- 单向、瞬时退化：任一失败立即下调 ---
        if fallen or (not certs_ok) or r < self.r_low or m < 0:
            if fallen or r < self.r_low:
                self.mode = "RECOVERY"
            elif self.mode == "NOMINAL":
                self.mode = "DEGRADED"
            self.since_switch = 0.0
            self.stable_since = None
            return self.mode
        # --- 慢恢复：全证书重签 + 滞回 + dwell + 稳定 ---
        if self.mode in ("DEGRADED", "RECOVERY") and certs_ok and r >= self.r_high:
            self.stable_since = (self.stable_since or 0.0) + dt
            if self.since_switch >= self.tau_dwell and self.stable_since >= self.tau_stable:
                self.mode = "NOMINAL"
                self.since_switch = 0.0
                self.stable_since = None
        return self.mode


class FallenStateController:
    def __init__(self, rvc: RecoveryViabilityCertificate, mode: RecoveryModeMachine):
        self.rvc, self.mode = rvc, mode

    def plan(self, x, env, robot, detect_fallen):
        fallen = detect_fallen(robot.imu, robot.leg_contact, robot.orientation)
        r = self.rvc.conservative_r(x, env, robot)
        m = env.safety_margin(x)
        mode = self.mode.update(0.02, m, r, fallen, env.all_certs_ok())
        if mode == "NOMINAL":
            return ("TASK", None)
        if mode == "DEGRADED":
            return ("SHRUNK_TASK", None)
        if mode == "RECOVERY":
            # 只在安全集内选择受认证恢复机动；否则请求协助/停驻
            man = self._best_recovery(x, env, robot)
            if man is None:
                return ("ASSIST_WAIT", None)   # 升级：请求人类协助（走 FERC/TCL）
            return ("RECOVERY", man)
        return ("ASSIST_WAIT", None)

    def _best_recovery(self, x, env, robot):
        cands = [m for m in robot.recovery_maneuvers(x)
                 if self.rvc._safe_along(m, env) and m.energy <= robot.E_res - self.rvc.b.E_rec]
        return min(cands, key=lambda m: m.duration) if cands else None


# ============================================================
# IP-442 Person-Conditioned Envelope (PCE) — 个性化非扩张投影
# ============================================================
@dataclass
class PersonProfile:
    c_u: str = "adult"
    f_u: float = 0.0
    f_hi: float = 0.0
    d_u: float = 0.6
    vpref_u: float = 1.0
    apref_u: float = 1.0
    consent: dict = field(default_factory=lambda: {"assist": False, "contact": False, "record": False})
    trust: float = 0.0

class PersonConditionedEnvelope:
    def __init__(self, E_cert: dict, gamma=0.5, beta=0.3, beta_j=0.4):
        self.E = E_cert
        self.gamma, self.beta, self.beta_j = gamma, beta, beta_j

    def _delta_cap(self, c_u: str) -> float:
        return {"child": 0.3, "elderly": 0.4, "wheelchair": 0.5,
                "worker": 0.0, "adult": 0.1}.get(c_u, 0.2)

    def params(self, th: PersonProfile) -> dict:
        # 跌倒风险用上置信界 f_hi → 只收紧
        d_req = self.E["d_min"] + self.gamma * th.f_hi + self._delta_cap(th.c_u)
        v_max = self.E["v_max_cert"] * (1 - self.beta * th.f_hi)
        j_max = self.E["j_max_cert"] * (1 - self.beta_j * th.f_hi)
        raw = {"d": max(d_req, th.d_u),
               "v": min(v_max, th.vpref_u),
               "a": min(j_max, th.apref_u)}
        return self._project(raw)

    def _project(self, raw: dict) -> dict:
        # 投影到已认证包络：只能更紧，绝不放宽
        return {"d": max(raw["d"], self.E["d_min"]),
                "v": min(raw["v"], self.E["v_max_cert"]),
                "a": min(raw["a"], self.E["j_max_cert"])}

    def combine(self, profiles: list) -> dict:
        # 多用户在场取交（最严者胜）
        ps = [self.params(p) for p in profiles]
        if not ps:
            return self.params(PersonProfile())
        return {"d": max(p["d"] for p in ps),
                "v": min(p["v"] for p in ps),
                "a": min(p["a"] for p in ps)}


# ============================================================
# IP-443 Fall-Event Response Certificate (FERC)
# ============================================================
class FallEventResponseCertificate:
    def __init__(self, q_low=0.20, q_high=0.90, trust_thr=0.7):
        self.q_low, self.q_high, self.trust_thr = q_low, q_high, trust_thr

    def detect(self, obs) -> Optional[FallEvent]:
        p = self._calibrated_fall_prob(obs)   # conformal 校准后的跌倒概率
        if p >= self.q_low:                    # 低门槛高召回：宁可误报
            return FallEvent(p=p, t=obs.t, region=obs.region,
                             do_not_move=self._do_not_move(obs))
        return None

    def response_tier(self, ev: Optional[FallEvent], th: PersonProfile,
                      modalities: set, human_confirmed: bool) -> str:
        if ev is None:
            return "NONE"
        tier = "NONCONTACT_SUPPORT"            # 非接触支持始终可做
        if (ev.p >= self.q_high
                and th.consent.get("assist") and th.consent.get("contact")
                and not ev.do_not_move
                and len(modalities) >= 2
                and human_confirmed
                and th.trust >= self.trust_thr):
            tier = "CONTACT_ASSIST"
        return tier

    def invalidate_absence(self, ev: Optional[FallEvent], cac) -> None:
        # 任何跌倒证据 ⇒ 构造性"有人在场" ⇒ 作废该区 AbsCert
        if ev is not None:
            cac.revoke_absence(ev.region)


# ============================================================
# IP-444 Trust & Consent Ledger (TCL)
# ============================================================
class TrustConsentLedger:
    def __init__(self):
        self._consent = {}   # uid -> dict
        self._trust = {}     # uid -> float
        self._root = None    # merkle 根（审计）

    def grant(self, uid, scope, value=True):
        # 授予需显式动作；记录审计
        self._consent.setdefault(uid, {})[scope] = value
        self._rehash()

    def revoke(self, uid, scope=None):
        # 撤销单向、立即生效：scope=None 表示全部撤销
        if uid not in self._consent:
            return
        if scope is None:
            for k in self._consent[uid]:
                self._consent[uid][k] = False
        else:
            self._consent[uid][scope] = False
        self._rehash()

    def update_trust(self, uid, value):
        # 信任只用于"是否允许协助"，且不得放宽任何安全约束
        self._trust[uid] = max(0.0, min(1.0, value))
        self._rehash()

    def effective(self, uid) -> tuple:
        return dict(self._consent.get(uid, {})), self._trust.get(uid, 0.0)

    def _rehash(self):
        self._root = merkle_root(self._consent, self._trust)


# ============================================================
# IP-445 HPC-R 统一四证准入门 + 端到端流水线
# ============================================================
@dataclass
class HPCR:
    hpc_e_plus: 'HPCEPlus'
    rvc: RecoveryViabilityCertificate
    pce: PersonConditionedEnvelope
    ferc: FallEventResponseCertificate
    tcl: TrustConsentLedger
    mode: RecoveryModeMachine

    def admits(self, plan, x, env, robot, users, fall_event) -> bool:
        # 0) 模式机：恢复模式只准入恢复机动
        if self.mode.mode in ("RECOVERY", "ASSIST_WAIT"):
            return plan is not None and plan in RecSet
        # 1) v23 四证
        if not self.hpc_e_plus.admits(plan, x, env.v, env.z, robot.E_res, env.margin_req, env.modules):
            return False
        # 2) 可恢复性：正常态必须 r ≥ 0（模型不确定取保守下界）
        if self.rvc.conservative_r(x, env, robot) < 0:
            return False
        # 3) 个性化包络：计划参数必须落在投影包络内
        envl = self.pce.combine(users)
        if not plan.within(envl):
            return False
        # 4) 跌倒事件：接触协助需 FERC 高门槛；否则不得执行接触动作
        if plan.contacts_human and self.ferc.response_tier(
                fall_event, users[0], plan.modalities, plan.human_confirmed) != "CONTACT_ASSIST":
            return False
        return True


class ViabilityRecoveryPipeline:
    def __init__(self, cfg):
        self.rvc = RecoveryViabilityCertificate(cfg["budget"])
        self.mode = RecoveryModeMachine(cfg.get("r_low", 0.0), cfg.get("r_high", 0.2))
        self.fsc = FallenStateController(self.rvc, self.mode)
        self.pce = PersonConditionedEnvelope(cfg["E_cert"])
        self.ferc = FallEventResponseCertificate()
        self.tcl = TrustConsentLedger()
        self.gate = HPCR(cfg["hpc_e_plus"], self.rvc, self.pce, self.ferc, self.tcl, self.mode)

    def step(self, sensor, users):
        x, env, robot = sensor["x"], sensor["env"], sensor["robot"]
        # 1) 跌倒检测（低门槛）并作废对应 AbsCert
        ev = self.ferc.detect(sensor["fall_obs"])
        self.ferc.invalidate_absence(ev, sensor["cac"])
        # 2) 模式决策（跌倒/不可恢复 → 恢复模式）
        kind, man = self.fsc.plan(x, env, robot, sensor["detect_fallen"])
        if kind in ("RECOVERY", "ASSIST_WAIT"):
            return self._execute_recovery(kind, man, users, ev)
        # 3) 正常/降级：v23 计划 + HPC-R 准入
        plan = sensor["planner"](self.pce.combine(users), self.mode.mode)
        ok = self.gate.admits(plan, x, env, robot, users, ev)
        return ok, {"mode": self.mode.mode, "plan": plan if ok else None, "fall": ev}

    def _execute_recovery(self, kind, man, users, ev):
        # 自恢复若需协助，走 FERC 高门槛 + TCL 同意；否则停驻待援
        if kind == "ASSIST_WAIT":
            tier = self.ferc.response_tier(ev, users[0], {"vision", "audio"},
                                           human_confirmed=False)
            return (tier == "CONTACT_ASSIST"), {"mode": "ASSIST_WAIT", "tier": tier}
        return True, {"mode": "RECOVERY", "maneuver": man}
```

## 2. 复杂度分析

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| RVC 恢复裕度 | O(\|RecManeuvers\|·L)（L=轨迹离散点数） | O(\|V_rec\|) 离线表 | 候选机动 ≤ 8，L ≤ 100 |

| FSC 模式机 | O(1) / 控制步 | O(1) | τ_dwell=2s, τ_stable=1s |
| PCE 参数投影 | O(1) / 用户；多用户 O(U) | O(U) | γ=0.5, β=0.3, U≤8 |

## 3. 正确性论证

### 引理 5（恢复保持安全单调链）
**陈述**：若 `RecSet ⊆ SafeExec_v23` 且正常模式 `Exec_v24 = Exec_v23 ∩ Fil_rec ∩ Fil_pers`，则 `Exec_v24 ⊆ Exec_v23 ⊆ … ⊆ Exec_v18`，且恢复模式执行的所有机动都落在 `S_safe` 内，不新增任何不安全状态。

**证明**：
1. 正常模式是 v23 执行集与两个过滤器的交，故 `Exec_v24 ⊆ Exec_v23`，链式传递到 v18。
2. 恢复机动由 `RecoveryViabilityCertificate._safe_along` 逐构型校验 `env.safe(cfg)`，即每个离散构型 `∈ S_safe`；扫掠区有人且无 AbsCert 时拒绝，故恢复不进入不安全态。
3. 恢复只恢复"可做任务"的能力，不扩张安全集本身；因此安全链（关于"允许做什么"）不变，新增的是"何时可再做"的活性维度。
∎

### 引理 6（退化-恢复无 Zeno / 无振荡）
**陈述**：在 P44 下（`r_high > r_low`、`τ_dwell > 0`、`τ_stable > 0`），模式机在有限时间内切换次数有界，不存在无限快速切换。

**证明**：
1. 每次上调（DEGRADED/RECOVERY → NOMINAL）要求 `since_switch ≥ τ_dwell` 且 `stable_since ≥ τ_stable`，故任意两次上调之间至少间隔 `τ_dwell > 0`。
2. 每次下调由离散事件（跌倒/证书失效/`r < r_low`）触发；在事件率有界的前提下，下调次数与时间成正比。
3. 上调需跨过 `r_high`，下调需跌破 `r_low < r_high`，形成滞回带；状态在带内不来回翻转。
4. 故在任意有限区间内切换次数 ≤ `T/τ_dwell + N_events`，无 Zeno 行为。
∎

### 引理 7（个性化非扩张）
**陈述**：`∀θ_u: Exec(θ_u) ⊆ Exec(∅)`。

**证明**：
1. PCE 的 `_project` 对每个参数取 `d ≥ d_min`、`v ≤ v_max_cert`、`a ≤ j_max_cert`，即结果始终不松于 `E_cert` 的边界；而 `E_cert` 正是 v23 的认证边界。
2. `Exec` 关于约束紧度是反单调的：约束集越紧，可行计划集越小。
3. 由于对任意 `θ_u` 投影结果都不松于 `E_cert`，故 `Exec(θ_u) ⊆ Exec(E_cert) = Exec(∅)`（`∅` 为通用画像，取边界）。
4. 多用户取交进一步收缩，仍保持包含关系。
∎

### 引理 8（跌倒事件失效安全的不对称性）
**陈述**：FERC 的检测低门槛与协助高门槛使"漏检跌倒"的代价有界，而"误判协助"的概率被显式压低；且任何跌倒证据都作废对应区域 AbsCert。

**证明**：
1. 检测用 `q_low`，故 `P(p < q_low | 真跌倒)` 小，漏检率受 `q_low` 与校准覆盖控制；漏检最坏后果是退化为非接触支持或未响应，不主动造成接触伤害。
2. 接触协助要求 `p ≥ q_high ∧ consent ∧ ¬do_not_move ∧ ≥2 模态 ∧ 人类确认 ∧ trust ≥ trust_thr` 的合取，误触发概率 ≤ 各条件漏检概率之积量级，且受 conformal 覆盖约束。
3. `invalidate_absence` 在检测到任何跌倒证据时立即撤销该区 AbsCert，故不会出现"覆盖区内无人"与"有人跌倒"同时成立的矛盾，杜绝该区的缺席幻觉。
∎

### 定理（HPC-R 四证一体的安全-可恢复-个性化完备性）
**陈述**：对任意计划 `π`，`HPCR.admits(π) = True` ⟺ `π` 同时满足：(1) v23 物理/规范/能量/云边/IP 安全（HPC-E+）；(2) 正常态可恢复（`r ≥ 0`，恢复模式则 `π ∈ RecSet`）；(3) 个性化包络内（`π` 参数落于 `Proj_{E_cert}`）；(4) 接触动作满足 FERC 高门槛。并且 `Exec_v24 ⊆ Exec_v23 ⊆ … ⊆ Exec_v18`。

**证明**：直接由 `HPCR.admits` 的四个连言条件，结合引理 5–8：必要性——任一条件缺失即拒证，对应安全/可恢复/个性化/跌倒响应四类风险之一未缓解；充分性——四条件成立时，引理 5 保证安全链与恢复安全，引理 6 保证模式稳定，引理 7 保证个性化不放宽，引理 8 保证跌倒响应失效安全，构成闭环。∎

## 6. 本轮最大风险（最终确认）

**一句话**：可恢复性证书把"能不能起来"押在机器人自恢复能力与环境模型（摩擦、坡度、空间）的准确性上；一旦真实恢复能力低于模型（打滑、执行器损伤、恢复扫掠区被人占据），机器人会自信地进入"模型认为可恢复、实际却逃不出"的状态；再叠加对特定用户跌倒风险的**系统性低估**，最坏情形是机器人"合规地、可审计地"把一个人置于它无法救助的跌倒中——即**"可恢复幻觉"与"个性化缺席幻觉"的叠加**。
