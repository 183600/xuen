# 第 44 轮（新循环第 1 轮） · Reg-Cert × Competition-Strategy：把「点云配准」升级为带退化证书的 SE(3) 置信域，并让「竞赛策略」用证书半径兑换风险预算（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形只保边际覆盖、多用户契约求交可空」——但这两个风险都还压着两个更靠前的单点假设：**(H1) 几何证书的前端是可信的**——LIO / IP-49 被当作输出精确变换的「干净传感器」，可真实点云配准在走廊、平面、对称重复结构、外点与部分重叠下会给出**自信地错**的 T̂；**(H2) 策略是被动执行器**——系统的任务被默认为「尽量安全地完成任务」，而竞赛场景的真实目标是「在安全硬约束下最大化比分」，需要在落后/时间压力下**主动承担受控风险**。本轮灵感词「点云配准」「竞赛策略」精确命中：**点云配准**迫使我们把配准从单点估计升级为带退化证书的 **SE(3) 置信域**，让几何证书诚实地携带不确定性；**竞赛策略**迫使我们把「冒险」从禁忌变成**可审计的资源分配**，并用一个漂亮的汇率把它们缝起来——**认证配准半径 ρ 就是风险货币**。核心命题：**感知不确定度必须能被定价，风险必须能被证书购买；收缩永远安全，冒险必须持证。**

## 0. 直觉与动机

**灵感 1（点云配准 → 从「一个变换」到「一个带退化证书的置信域」）**：直觉上，配准只要残差小就「对齐了」。但在长走廊里，点云沿走廊方向平移几乎不改变残差——这是一个**零空间方向**：配准算法可以非常自信地报一个 T̂，而真值 T* 可以沿该方向滑走几米。v20 的几何证书把这个 T̂ 当作真值，等于把「不可辨识」误当成「高精度」。正确做法是把配准输出写成 𝒞_reg=(T̂, 𝒯_ρ, c)：𝒯_ρ 是覆盖真值的 SE(3) 置信集，c 显式标注**退化零空间 D_null**、可辨识子空间 D_id、重叠率与鲁棒外点率。校准用**按场景结构分层的共形预测**（复用 v20 定义 39 的 Mondrian 思想，但搬到 SE(3) 上，以鲁棒统计残差为非一致性分数）。一句话：**能辨识的方向给有限半径，不能辨识的方向老老实实说 ∞。**

**灵感 2（竞赛策略 → ρ 是风险货币，Oracle 比例在感知与行动两侧同时结算）**：竞赛不能只求稳：永远走最保守路线会在比分上输，永远激进会违例出局。于是把策略层写成一个**受约束的在线风险分配**：给定比分差 Δs、剩余时间 T_rem、对手观测 ô 与认证状态估计 𝒞_reg，风险预算 r_t 定义为「在 𝒯_ρ 内最坏情况下仍满足安全裕度 θ_safe 的最大激进等级」。关键结构性结论：**ρ 越大，𝒯_ρ 越大，最坏 margin 越小，r_t 越小**——感知不确定度自动、单调地折算成可用冒险额度。反过来，当竞赛需要更高风险但 ρ 太大时，portfolio 可以**花算力并行竞赛**去把 ρ 压小（多初值、多算法、多假设），等于「用算力买入冒险许可」。这把上一轮定义 43 的「并发投机」从「降延迟」升级为「降不确定度以购买策略空间」。

**灵感 3（耦合 → 「假自信」的套利路径必须被堵死）**：最危险的耦合不是「配准错」，而是「配准错得很有自信」。portfolio 的选择分数若读残差，则一个落在 D_null 里、残差极小但真值漂移的专家会被选中；策略层看到声称的 ρ 很小，就兑换出很高的 r_t 去做激进动作。这条链叫**证书套利（certificate arbitrage）**：用不可辨识方向上的「低残差」去购买真实世界里的「高激进」。三层防御：(a) 选择分数**禁止读 D_null 分量**；(b) **对抗 holdout 审计**：nominal 分数与 adversarial 分数 gap 过大即判为「博取选择」，降为 shadow-only；(c) **校准投毒检测**：对手污染标定集让 q 偏小，用 CUSUM 监测条件覆盖率漂移并收紧 ρ。策略侧再加一道硬屏蔽：任何动作必须通过证书 shield，竞赛目标只能在屏蔽内优化。

**耦合升级**：CRC（证书配准内核）把点云变成 𝒯_ρ 并提供退化/对抗证书；CSE（竞赛策略引擎）把 𝒯_ρ 兑换成风险预算并在 portfolio 内部按证书单调规则做竞赛；RGA（配准博弈审计器）在仿真里用对抗点云与投毒标定攻击这两者，把反例回灌 CKB 与 SCV。四层架构从 v8 的「仿真-检索-边缘 + 人格 + 并发」升级为 v9 的「仿真-检索-边缘 + 人格 + 并发 + **感知证书域 + 竞赛策略层**」。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（证书化点云配准与 SE(3) 置信域）**：给定源点云 P、目标点云 Q，配准输出三元组 𝒞_reg=(T̂, 𝒯_ρ, c)。𝒯_ρ⊆SE(3) 为置信集，满足 P(T*∈𝒯_ρ) ≥ 1−α（T* 为真值变换，概率对场景采样）；c=(q, o, β̂, η, D_id, D_null) 为证书，分别记录残差阈值、重叠率、鲁棒外点率、退化指标与可辨识/零空间。校准：非一致性分数 s(T;P,Q)=trimmed-Chamfer(T;P,Q)，按场景类别（几何结构 × 传感器）分层的标定集取 q=Quantile_{1−α}(s)；在 T̂ 附近做二阶展开，用信息矩阵 H 反解可辨识方向半径 ρ_id=√(2(q+ε_opt)/λ_min^{D_id})。**使用纪律**：下游（LIO、规划、CAR）只允许读取 𝒯_ρ 与 D_null，**禁止只读 T̂**；零空间方向不声明任何有限安全界。

**定义 45（退化证书与可辨识子空间）**：在 T̂ 处对配准代价在 se(3) 基下做二阶展开，H=J^T J 为 6×6 信息矩阵，特征分解 λ_1..λ_6、V。取阈值 λ_min，定义可辨识子空间 D_id=span{V_i: λ_i≥λ_min} 与零空间 D_null=span{V_i: λ_i<λ_min}（走廊方向、平面法向旋转、重复纹理滑移等）。**退化证书规则**：𝒯_ρ 在 D_null 方向的半径记为 ∞；任何安全断言只允许建立在 D_id 上。**命题 44.1（不可辨识下错声明必不 sound）**：若真实代价在 D_null 上近似常数（λ_i≈0），则存在两个变换 T_1,T_2 使残差差 <ε 但物理位姿相差任意大；因此在 D_null 上声称有限误差界必然存在场景使其失效——**不声明优于错声明**。

**定义 46（对抗配准博弈与 minimax 证书）**：对手（在竞赛语境里就是竞争者/环境）可在预算 (ε_pt, β, γ) 内扰动：逐点有界扰动 ‖δp‖≤ε_pt、外点比例 ≤β、部分重叠率 ≤γ。定义最坏置信域直径 W(𝒞_reg)=sup_{P'∈B_{ε_pt}(P), |O|≤β|Q|} diam(𝒯_ρ(P',Q))。若 W≤ρ_target 且所有扰动下仍有 T*∈𝒯_ρ，则称 𝒞_reg 为 (ε_pt,β,γ,ρ_target)-**鲁棒证书**。这是估计器与外点对手之间零和博弈的 sup-inf 值；竞赛中对手可主动制造外点、遮挡与退化几何。

**定义 47（竞赛风险预算与证书屏蔽策略）**：策略层在 𝒞_reg、比分差 Δs、剩余时间 T_rem、对手观测 ô 下选动作 a∈A。动作按激进等级分层 A=∪_r A_r。**风险预算** r_t := max{ r : ∃a∈A_r, min_{T∈𝒯_ρ, w∈W} margin(a,T,w) ≥ θ_safe }。策略求解受约束问题 a_t*=argmax_{a∈A_{r_t}} E[score(a) | T̂, ô]，硬约束 P(安全违例)=0 由**证书 shield**兜底。**命题 47.1（感知-策略汇率）**：𝒯_ρ 随 ρ 单调扩张 ⇒ 最坏 margin 单调不增 ⇒ r_t 单调不增；故 ∂r_t/∂ρ ≤ 0。**推论**：认证配准半径是可定价的「风险货币」，降低 ρ 等价于买入激进动作的许可。**推论**：单一固定策略（永远保守/永远激进）是该框架的两个退化边界，竞赛收益来自按 Δs、T_rem 动态定价。

**定义 48（配准 portfolio 与证书单调选择）**：专家集 E={e_1..e_k}（ICP 变体、FPFH+RANSAC、NDT、TEASER、深度配准等），每个专家输出 𝒞_reg^j=(T̂_j,𝒯_{ρ_j},c_j)。选择规则 σ 只在「证书 valid 且对当前关键级安全」的专家中选择；用 successive-halving/UCB 把预算 B_p 分配给仍有希望的专家。**证书单调性**：选择分数 s(⋅) 必须满足 c_1⊑c_2（c_1 置信域更小且在相同 D_id 上更保守）⇒ s(c_1)≥s(c_2)，且 s **只读 D_id 分量**。**定理 48.1（竞争不破坏 soundness）**：因只在 valid 证书间选择且 σ 不修改证书，选中者的证书仍 sound；竞争只决定「在多个 sound 证书里选哪个、花多少算力」。**定理 48.2（遗憾界）**：在平稳可交换场景下，UCB/EXP3 的累计遗憾 R_T=Σ_t(min_j ℓ_t(e_j)−ℓ_t(σ_t))=O(√(kT log k))，即竞赛策略不劣于「事后最优专家」至多一个次线性项。

**定义 49（证书博弈与校准投毒检测）**：定义专家 e 的**博弈风险** G_e = score_nominal(e) − score_adversarial-holdout(e)。若 G_e>τ_game，则 e 在用标称分数「博取选择」（典型：在退化零空间或过拟合标定残差上刷分）。**校准投毒**：对手污染标定集使共形分位 q 偏小（覆盖率虚高）。检测三件套：(a) 选择分数对证书单调且不读 D_null；(b) 影子标定集与对抗 holdout 定期交叉验证条件覆盖率；(c) 覆盖率 CUSUM 漂移检测。**规则**：触发 G_e>τ_game 或覆盖率漂移 → 专家降为 shadow-only、q 取保守上界、ρ 收紧；连续触发 → 回退到 v20 的纯点估计 + 附加保守 margin。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 CERTIFIED-REGISTRATION-CORE（证书配准内核 CRC）
1. **全局-局部证书配准**：分支定界 ε-最优 + TEASER 式鲁棒截断最小二乘 → (T̂, q, β̂, o, ε_opt)；只在 overlap≥O_MIN 时签发 valid。
2. **退化分解**：se(3) 信息矩阵特征分解 → D_id/D_null；置信域只在 D_id 给有限半径，D_null 返回 ∞。
3. **分层共形 SE(3)**：非一致性分数 = 鲁棒残差，按「场景结构类 × 传感器」分层校准 → 𝒯_ρ；覆盖率在线监测。
4. **对抗鲁棒扩展**：在 (ε_pt,β,γ) 预算下采样/区间最坏搜索，签发 minimax 鲁棒证书；不达标则标注 unverified。

### 2.2 IP-61 COMPETITION-STRATEGY-ENGINE（竞赛策略引擎 CSE）
1. **竞赛状态机**：比分差 Δs、剩余时间 T_rem、对手模型 ô → 目标激进需求 needed_risk。
2. **风险预算定价**：由定义 47 把 ρ 单调映射为 r_t；预算不足时先尝试「花算力降 ρ」，再退保守。
3. **证书屏蔽策略优化**：constrained MDP / shielded bandit（EXP3 或 UCB）在安全动作集内最大化期望比分；硬约束由 shield 执行，绝不放宽 θ_safe。
4. **感知 portfolio 竞赛**：successive-halving/UCB 在有效证书专家间分配预算，目标在保证 soundness 下最小化 ρ（买风险货币）；空集则协商/保守回退。

### 2.3 IP-62 REGISTRATION-GAME-AUDITOR（配准博弈审计器 RGA）
1. **对抗点云生成**：有界逐点扰动、外点注入、部分重叠、以及**定向退化场景**（走廊/平面/对称重复）。
2. **校准投毒模拟**：污染标定集，测条件覆盖率崩塌与 q 偏移。
3. **证书博弈审计**：nominal vs adversarial holdout 分数 gap；生成黑名单并回灌 CKB。
4. **竞赛回放闭环**：在 Isaac Sim 跑「感知→风险定价→策略→安全监控」，统计 unsafe 事件与比分，做反事实回放找套利路径。

### IP-60 CRC：证书化配准、退化分解与对抗鲁棒
```
def certify_registration(P, Q, alpha, budget, scene_class):
    # 1) 全局初值 + 局部精化，附 ε-最优间隙
    T_hat, eps_opt = branch_and_bound(P, Q, eps=budget.eps)     # SE(3) 上 BnB
    # 2) 鲁棒残差与外点/重叠估计（截断最小二乘 / TEASER）
    cost, beta_hat, overlap = robust_trimmed_cost(P, Q, T_hat)
    # 3) 退化分解：6x6 信息矩阵；零空间方向不声明有限界
    H = information_matrix(P, Q, T_hat)          # J^T J in se(3) basis
    lam, V = eigh(H)
    D_id   = span([V[:,i] for i in range(6) if lam[i] >= LAMBDA_MIN])
    D_null = span([V[:,i] for i in range(6) if lam[i] <  LAMBDA_MIN])
    # 4) 分层共形阈值 -> 置信半径（只在可辨识方向）
    q = conformal_quantile[scene_class](alpha)    # 标定集非一致性分数分位
    lam_min_id = min_eig(H, D_id)
    rho_id = sqrt(2.0 * (q + eps_opt) / max(lam_min_id, 1e-9))
    valid = (overlap >= O_MIN)
    return RegCert(T_hat, radius_id=rho_id, null=D_null, overlap=overlap,
                   beta=beta_hat, eps_opt=eps_opt, valid=valid)

def certified_radius(cert, direction):
    # 下游查询：允许 direction 落在零空间时必须返回 inf
    if project(cert.null, direction) > 1e-6:
        return INF                          # 不可辨识：绝不声明有限界
    return cert.radius_id

def adversarial_register_cert(P, Q, eps_pt, beta, gamma, alpha, rho_target):
    worst = 0.0
    for P_adv in attack_oracle(P, eps_pt, beta, gamma):   # 定向退化 + 外点
        c = certify_registration(P_adv, Q, alpha, budget=default, scene_class=c)
        worst = max(worst, diameter(c.radius_id))
    return RobustCert(ok=(worst <= rho_target), rho=worst)
```

### IP-61 CSE：风险定价、证书屏蔽与感知 portfolio 竞赛
```
def competition_step(score_diff, T_rem, obs_opp, cert, experts, budget):
    # 1) 认证半径 -> 风险预算（感知-策略汇率，定义 47）
    rho = cert.radius_id
    r_max = risk_budget(rho, score_diff, T_rem)      # 单调递减于 rho
    # 2) 需要更激进但 rho 太大 => 花算力竞赛式降 rho（买风险货币）
    if needed_risk(score_diff, T_rem) > r_max and budget > 0:
        cert, spent = portfolio_minimize_rho(experts, cert, budget)
        r_max = risk_budget(cert.radius_id, score_diff, T_rem)
    # 3) 证书 shield：只在最坏 margin 达标的动作集内选择
    A_safe = [a for a in A if worst_margin(a, cert) >= THETA_SAFE]
    if not A_safe:
        return safestop(), cert, 0.0
    # 4) 屏蔽 bandit（EXP3/UCB）在安全动作集内最大化期望比分
    a = shielded_bandit_select(A_safe, score_diff, T_rem, obs_opp)
    return a, cert, r_max

def risk_budget(rho, score_diff, T_rem):
    # 结构性：rho 越大 -> 预算越小；落后越多/时间越少 -> 名义需求越大
    base = k_score * score_diff + k_time * (1.0 / max(T_rem, EPS))
    return clip(base - k_unc * rho, 0.0, R_MAX)

def portfolio_minimize_rho(experts, cert, budget):
    active = [e for e in experts]
    while budget > 0 and len(active) > 1:
        for e in active:
            e.run(share=budget / len(active))
        certified = [e for e in active
                     if e.cert.valid and safe_for_criticality(e.cert)]
        if not certified:                        # 全部无效 => 不得静默放行
            return conservative_fallback(cert), budget
        # 证书单调选择：sound_score 只读 D_id，防止用零空间刷分
        active = top_half(certified, key=lambda e: sound_score(e.cert))
        budget /= 2
    return min(active, key=lambda e: e.cert.radius_id).cert, budget

def sound_score(cert):
    # 只比较可辨识方向；不可辨识方向不计分（防证书博弈）
    return -cert.radius_id - LAMBDA_COST * cert.beta
```

### IP-62 RGA：证书博弈审计与校准投毒检测
```
def audit_certificate_gaming(experts, nominal_set, adversarial_holdout, tau_game):
    flags = []
    for e in experts:
        gap = score(e, nominal_set) - score(e, adversarial_holdout)
        if gap > tau_game:
            flags.append((e, gap))       # 用标称分数博取选择
    return flags

def detect_calibration_poisoning(coverage_stream, alpha, delta, h):
    # CUSUM 监测条件覆盖率显著低于 1-alpha
    s = 0.0; alarms = []
    for t, cov in enumerate(coverage_stream):
        s = max(0.0, s + ((1.0 - alpha) - cov) - delta)
        if s > h:
            alarms.append(t); s = 0.0
    return alarms

def degrade_on_alarm(experts, flags, alarms):
    for e, _ in flags:                   # 博弈专家降为 shadow-only
        e.mode = 'shadow_only'
    if alarms:                           # 投毒 => 收紧 q 与 rho
        conformal_quantile.bump_conservative()
        shrink_radius()
    if persistent(flags, alarms):        # 连续告警 => 回退 v20
        return fallback_v20_point_estimate_with_margin()
    return experts
```

```
def car_guard_over_regcert(e, x, cert, persona, lease, t):
```
