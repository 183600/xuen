# 第 10 轮（新灵感循环第 1 轮；本轮灵感：「模型预测控制」×「零样本泛化」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**用 MPC 把"预测"从一次性块证书变成闭环反馈；用零样本泛化把"域外安全"从学习型检测器的经验赌注变成无分布假设的覆盖保证。** 三个新模块（CEO/TCP/ZRA/CSD）均为可选增强，失效时注入中立元、严格退回 v9（引理 92），绝不行为漂移。

## 0. 直觉与动机

**灵感 1（模型预测控制 → 滚动时域 + 管束鲁棒）**
直觉：v9 的 AC 是一个"开环块"——一次性生成 K 步、用固定余量 β 担保；一旦前向模型在新域失准，整块证书一起失效，而反馈只藏在 50Hz 便宜守卫里。MPC 的本质不是"多步规划"，而是三点：**每步用最新观测重解一个带约束的最优控制问题**、**把约束显式写进优化**、**用终端集把有限时域安全性递归到无限时域**。核心创新：**管束分块规划器（TubeChunkPlanner, TCP）**——以"标称轨迹 ⊕ 管束"替代点预测，约束按管束半径收紧（tightening），终端集取鲁棒控制不变集，于是 v9 的"误差≤β 假设"升级为"递归可行性 + 逐时约束满足"。工程收益：模型误差被"看到一次、修正一次"，不再攒到块尾才爆发。

**灵感 2（零样本泛化 → 无分布、免训练的覆盖保证）**
直觉：v9 最大的债是 β 靠离线标定，而域偏移恰恰是标定失效时。这里的零样本泛化不该理解为"再训一个更泛化的网络"，而应理解为**分布无关、免标签、免梯度**的在线机制。共形预测（conformal prediction）只用残差的排序就给出有限样本覆盖保证，完全不假设误差分布；自适应共形推断（ACI）在任意分布漂移下仍保长期平均覆盖；更妙的是共形 p 值序列本身就是**免训练的漂移报警器**——不需要 DA-ML 那样的域分类器。核心创新：**共形误差预言机（ConformalErrorOracle, CEO）** 与 **共形漂移检测器（ConformalShiftDetector, CSD）**：β 从常数变成随残差在线更新的分位数 β_t(k)，CSD 用 p 值 CUSUM 在新域上"零样本"报警，误报率有分布无关上界。

**灵感 3（两者相乘 → 覆盖度驱动块长 + 语义化风险预算）**
直觉：MPC 回答"能走多远"，共形回答"敢信多远"。块长不应由学习到的 Δ_dom 单独门控，而应由**当前覆盖度/管束可承受性**门控：K_eff^conf = 满足"管束收紧后仍可行且覆盖事件成立"的最大前缀。同时情感层（ER）可充当 α 的"风险预算"调节器（落在 [α_min, α_max]），把"社会语境下的谨慎"翻译成有统计含义的参数，而不是凭空的奖励项。

## 1. 研究问题（轮次升级版）

- **Q1（共形覆盖的时序性）**：块级（horizon-wise）共形分数如何在强自相关、非平稳的机器人残差上同时保证边际与近似条件覆盖？滑动窗 + ACI 能否把 v9 的"20 帧滞后"变成"单步响应"？
- **Q2（管束安全的闭环性）**：在对偶误差集合 W_t={‖w‖≤β_t} 下，收紧约束的 tube-MPC 能否保证递归可行与真实约束满足（以覆盖事件为条件）？鲁棒终端不变集如何与 v9 的中止点集统一？
- **Q3（零样本退化的严格性）**：CEO/CSD/TCP/ZRA 任一失效时能否逐位退回 v9 ACMD？当共形可交换性被违反时，失效模式是否被"模型无关的 50Hz 活守卫"兜住，而不是被统计证书的"平均正确"掩盖？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 覆盖驱动决策律（Coverage-Conditioned Decision）**
一切"敢走多远/敢信多深"的决策以共形覆盖事件为条件：一旦覆盖审计（连续未覆盖计数 / ACI 的 α_t 越界）失败，立即 K_eff←1 并交回模型无关活守卫，禁止继续消费已过期的证书。

**P14 管束收紧律（Tube-Tightening）**
MPC 的每条软/硬约束按对应层的管束半径 β_t^{(i)}(k) 收紧；终端的滚动约束必须落入鲁棒控制不变集；禁止"未收紧的约束 + 点预测"这一组合出现在任何可行解中。

**P15 零样本不重训律（Zero-Shot-No-Retrain）**
新域适配只允许在线、无标签、免梯度更新的操作：滑窗重标定、ACI 的 α 更新、带遗忘因子的残差辨识、固定投影的域无关残差基。任何需要目标域标注或再训练的能力必须走可选路径，并可在失效时回退。

## 3. 与基线（v9）的接口（如何退化）

- TCP 不可行（管束膨胀越界 / QP 超时）⇒ 退回 v9 AC 的采样 MPC + 固定 β；再不可行 ⇒ K=1 单步；
- CEO 失效（校准集不足 / 覆盖审计失败）⇒ β_t(k)←β（v9 常数余量）、α_t←α_base；
- CSD 失效 ⇒ 漂移信号回退 DA-ML 的 Δ_dom；ZRA 失效 ⇒ 冻结 f̂（v9 前向模型）；
- 治理层 CG 失效 ⇒ K_eff 回退 v9 定义 539 的 Δ_dom 门控；
- 全部新模块失效 ⇒ 精确 v9 ACMD；再沿 v9 链退到 v8/v7/v6。

## 4. 预期贡献

1. **共形管束 MPC**：把"块证书"升级为具有有限样本 / 长期平均覆盖保证的滚动管束证书，安全论证从"假设误差≤β"变为"覆盖事件 + 鲁棒不变集"；
2. **免训练零样本漂移检测**：共形 p 值 CUSUM，误报率有分布无关上界，替代/增强学习型 Δ_dom，正面治理 v9 的最大风险（检测滞后）；
3. **覆盖度驱动的块长与风险预算**：K_eff^conf 由可行性 + 覆盖度决定；情感层以 α∈[α_min,α_max] 表达风险偏好；
4. **v10 退化格**：所有新模块可注入中立元、逐位等价退回 v9，安全性由 v9 引理 82–86 传递。

## 5. 本轮最大风险

**一句话**：共形保证是**边际 / 长期平均**意义而非逐状态条件意义，ACI 在突变后若干步内仍可能连续"未覆盖"；若把统计保证误读为逐时刻硬保证，就会在最需要安全的瞬间交出一张"平均而言正确"的证书。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-CTZ**（Conformal Tube-MPC with Zero-shot shift detection & transfer）

> 背景：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮灵感：「模型预测控制」×「零样本泛化」
> **继承纪律**：MetricVoiceGauge 九不变式（CVC-闭环、SpatialCert、RT-CVC、FaultCert、PrimitiveGraph、严格退化链、OTL、GCT、ER）全部保留；v9 的 AC/MW/ID 三模块原样继承。新组件一律为**可选增强**：任一环节不可用 ⇒ 注入中立元，严格等价退回 v9 ACMD（引理 92），而非行为漂移。

## 0. 核心 IP 设计

| 编号 | 名称 | 类型 | 关键改进（相对 v9 ACMD） |
|---|---|---|---|
| IP-354–356 | AC / MW / ID | 继承 | 语义不变；AC 被 TCP 包裹调用，MW 契约表新增 CEO/TCP/ZRA/CSD 四行 |
| IP-357 | ConformalErrorOracle（CEO）共形误差预言机 | 新增核心模块 | 残差滑窗 + horizon-wise 共形分位数 β_t^{(i)}(k)；ACI 在线更新 α_t；顺带输出共形 p 值 p_t |
| IP-358 | TubeChunkPlanner（TCP）管束分块规划器 | 新增核心模块（升级 AC） | 标称 MPC ⊕ 管束收紧 ⊕ 鲁棒终端集；生成 ζ^tube=(a^{1:K}, Ĉ^tube, P^tube)；固定 β 时退化为 v9 AC |

**退化链声明（v10 契约化六级，全部可由中立元触发）：**
- **Level-0**：CSD 报警或覆盖审计失败 ⇒ α_t 提升、K_eff←1、切模型无关活守卫 + 单步保守动作（新增，最先触发）。
- **Level-1**：TCP 不可行 / 管束半径越 β_max / QP 超时 ⇒ 退回 v9 AC（固定 β 的采样 MPC）；再不可行 ⇒ K=1 单步。
- **Level-2**：CEO 失校（校准窗太小 / 覆盖审计失败）⇒ β_t^{(i)}(k)←β^{(i)}（v9 常数余量）。
- **Level-3**：ZRA 失效（辨识发散 / 病态）⇒ 冻结 f̂（v9 前向模型）。
- **Level-4**：CSD 失效 ⇒ 漂移信号回退 DA-ML 的 Δ_dom 门控。
- **Level-5**：全部新模块失效 ⇒ 精确 v9 ACMD；再沿 v9 链退到 v8 → v7 → v6。

**与 v9 的差异（一表看清）：**

| 维度 | v9 ACMD | v10 CTZ |
|---|---|---|
| 前向不确定性 | 固定余量 β，离线标定 | 在线共形分位数 β_t^{(i)}(k)，分布无关覆盖 |
| 多步规划 | 采样 MPC，点预测 + β | tube-MPC，集合传播 + 约束收紧 + 鲁棒终端集 |
| 域偏移信号 | 学习型 Δ_dom（20 帧滑窗） | 共形 p 值 CUSUM（逐残差响应，误报可控），Δ_dom 作回退 |
| 块长门控 | K_eff(Δ_dom, risk_SLAM) | K_eff = min(v9 门控, K_eff^conf) |
| 域外适配 | 无（假设标定有效） | ZRA 在线残差辨识 + ACI 重标定（免训练、免标签） |
| 安全责任划分 | 块证书承担多步安全 | 统计证书管"性能与中止率"，逐时安全交给模型无关活守卫（引理 90） |

## 1. 符号体系增量（定义 540–551）

| 符号 | 含义 |
|---|---|
| r_t = x_{t+1} − f̂(x_t,a_t) | 前向模型单步残差（x 为状态/关键观测量） |
| s_t^{(i)} = ‖Π_i r_t‖_{Q_i} | 第 i 层的共形非一致性分数（i ∈ 六层指标 + 状态亚层） |
| β_t^{(i)}(k) | 第 i 层、前缀 k 的共形管束半径（定义 541） |
| α_t ∈ [α_min, α_max] | ACI 在线误覆盖目标（定义 542）；越小越保守 |
| W_t = {w : ‖w‖ ≤ β_t(K)} | 对偶残差不确定集（管束的外生扰动集） |
| Ω_rob | 鲁棒控制不变终端集（定义 544） |
| Π | 域无关残差基投影（定义 546），d ≪ n_x，离线固定 |
| λ ∈ (0,1] | ZRA 的遗忘因子（定义 547） |
| p_t ∈ (0,1] | 共形 p 值（定义 548）；无漂移时超均匀 |
| Λ_t | 共形 CUSUM 统计量（定义 549） |
| K_eff^conf(t) | 覆盖度可承受的最大块长（定义 550） |
| α_base, κ_R, κ_C | 风险预算基准与情感/置信度调节系数（定义 551） |

**新增定义 540（残差与共形分数）** 前向模型单步残差 r_t = x_{t+1} − f̂(x_t,a_t)。对第 i 个受证书保护的层，定义非一致性分数 s_t^{(i)} = ‖Π_i r_t‖_{Q_i}，Q_i 为按层量纲的加权范数。校准窗口 C_t = {s_τ^{(i)} : τ ∈ [t−W, t)}，W=200（4s@50Hz）。**关键**：分数作用在"残差"而非原始状态/图像上，因此天然跨域可比，这是零样本迁移的统计基础。

**新增定义 541（块级共形管束半径）** 对前缀 k，定义轨迹级分数
```
s_{t:k}^{(i)} = max_{j≤k} s_{t+j}^{(i)} ,     β_t^{(i)}(k) = Quantile_{1−α_t}( { s_{τ:k}^{(i)} : τ ∈ C_t } )
```
并取**单调包络** β_t^{(i)}(k) ← max_{j≤k} β_t^{(i)}(j)，反映误差随视界的累积。工程上另提供"整个视界的单一分数 s_{t:K}"作为低样本量下的保守版本（W 小时优先用它）。β^{(i)} 的上界 β_max^{(i)} 由物理可行性给出（如刹车距离上界），越界即触发 Level-1。

**新增定义 542（ACI 覆盖控制器）**
```
err_t = 1[ s_t^{(i)} > β_t^{(i)}(1) ]            # 单步是否未覆盖
α_{t+1} = clip( α_t + γ (α_base − err_t), α_min, α_max )
```
γ∈(0,1)、α_min=0.001、α_max=0.2、α_base=0.05。α 下降 ⇒ β 变大 ⇒ 更保守；域突变时 err_t 连发会推高 α_t，从而自动放宽目标，避免"永远追不上"的不可行。注意：α 被 [α_min,α_max] 夹住是保证长期覆盖界可陈述的前提。

**新增定义 543（管束 MPC 问题）**
```
min_{a_{0:K−1}}  Σ_{k=0}^{K−1} ℓ_i(x̂_k, a_k, τ_i(t)) + V_f(x̂_K)
s.t.  x̂_{k+1} = f̂(x̂_k, a_k),   x̂_0 = x_t
      g_i(x̂_k, a_k) ≥ d_safe,i + β_t^{(i)}(k)          # 约束收紧（P14）
      a_k ∈ A,  Δa_k ≤ Δa_max
      x̂_K ∈ Ω_rob ,   a_k ∈ K_rob(x̂_k)                 # 鲁棒终端
```
ℓ_i 复用六层指标权重（定义 493/495），τ_i(t) 为 v8/v9 在线阈值。约束收紧只作用于"受模型误差影响的软/硬层"；M₀ 的几何硬检查仍走独立、模型无关的实时通道（不参与此 QP）。

**新增定义 544（鲁棒终端不变集 Ω_rob）** Ω_rob 是对扰动集 W_t 的**最大鲁棒控制不变集**：∀x∈Ω_rob，∃u∈A 使对一切 w∈W_t 有 f̂(x,u)+w ∈ Ω_rob 且约束收紧后仍满足。实现：对 f̂ 在某工作点族的局部线性化，用多面体/椭球近似离线预计算若干模板，运行期按当前 β_t 选择覆盖 W_t 的最小模板；模板不匹配即判 TCP 不可行（Level-1）。

**新增定义 545（中止点集升级）** p ∈ P_t^tube 当且仅当管束收紧后的停车不变式成立：
```
d_brake(v_p) + d_safe + β_t^{(clear)}(p) ≤ dist(s_p, O) − |traj_{p:K}|
```
与 v9 定义 534 在 β_t^{clear}→0 时逐项一致；故 P_t^tube ⊆ P_t（更严），"无点可退"只会在 K=1 fallback 发生（与 v9 语义相同）。

**新增定义 546（域无关残差基 DARB）** 用多个离线源域的残差协方差做联合分析，取固定线性投影 Π: R^{n_x}→R^d（d≈8），使投影后各源域残差协方差最接近单位阵（跨域白化 / 主成分交集），并对投影方向做符号与尺度归一。Π 一旦部署即冻结、不在目标域更新，因此不违反 P15。作用：把"外观/材质/光照"等域特异方向挤压掉，只保留动力学误差主方向，从而减小共形分位数被域特异噪声撑大、提升覆盖效率（非覆盖保证本身）。

**新增定义 547（零样本残差适配 ZRA）** 残差模型 r_t ≈ Φ(s_t,a_t)^⊤ θ，Φ 为固定特征（含低阶多项式与 DARB 投影）。带遗忘因子的递推最小二乘：
```
K_t = P_{t−1}Φ_t / (λ + Φ_t^⊤ P_{t−1} Φ_t)
θ_t = θ_{t−1} + K_t (r_t − Φ_t^⊤ θ_{t−1})
P_t = (P_{t−1} − K_t Φ_t^⊤ P_{t−1}) / λ
```
λ=0.995。增广前向模型 f̂_θ(x,a)=f̂(x,a)+Π^⊤(Φ^⊤θ)。O(d²)/step，无梯度、无标签。辨识发散（trace(P) 越界或 θ 范数爆炸）⇒ 冻结并回退 v9 的 f̂（Level-3）。

**新增定义 548（共形 p 值）**
```
p_t = ( 1 + #{ τ ∈ C_t : s_τ ≥ s_t } ) / ( W + 1 )
```
在窗口内可交换假设下 p_t 超均匀：∀u, P(p_t ≤ u) ≤ u。它同时是"覆盖是否成立"的在线证据：p_t 很小 ⇒ 当前残差比历史绝大多数都大 ⇒ 可能漂移。

**新增定义 549（共形漂移检测 CSD）** 在 p 值上做 e-value CUSUM：
```
e_t = 1 / max(p_t, ε) ,   Λ_t = max( 0, Λ_{t−1} + log e_t − c )
报警 ⇔ Λ_t ≥ log(1/δ)       (ε=1e−3, c=0.5, δ=0.01)
```
零假设（窗口内可交换 / 无漂移）下 {e_t} 的乘积为测试鞅，Ville 不等式给出 P(∃t: Λ_t ≥ log(1/δ)) ≤ δ，**误报率与数据分布无关**——这正是零样本检测相对学习型 Δ_dom 的核心优势。检测延迟（Hoeffding 型界）≈ log(1/δ)/KL(p_alt‖uniform)，漂移越强越快。报警后不是直接停车，而是先让 α_t 抬高、K_eff←1、启用活守卫（Level-0），给重标定留时间窗。

**新增定义 550（覆盖度驱动块长）**
```
K_eff^conf(t) = max { k ≤ K_max : TubeMPC_k feasible ∧ β_t^{(i)}(k) ≤ β_max^{(i)} ∀i ∧ coverage_audit_ok }
K_eff(t) = min( v9 定义 539 的 K_eff(Δ_dom, risk_SLAM),  K_eff^conf(t) )
```
“覆盖度”同时包含"分位数未越物理上界"和"连续未覆盖计数 < c_unc（默认 3）"两条审计。二者任一失败 ⇒ K_eff=1，交回活守卫。

**新增定义 551（风险预算 α）**
```
α_t = clip( α_base + κ_R · R_social(t) − κ_C · (1 − conf_t),  α_min, α_max )
```
R_social(t) 为 ER 层输出的社会风险（拥挤、操作员焦虑等），conf_t 为当前覆盖置信（如 1−近期未覆盖率）。直觉：社会语境越紧张，α 越小（越保守、β 越大）；但被 α_min 兜底，**情感永不把系统调到比硬安全更冒险**。该式让"情感"从奖励项变成一个可审计的统计参数。

# IP-357 ConformalErrorOracle：共形误差预言机
class ConformalErrorOracle:
    def __init__(self, W=200, alpha_base=0.05, alpha_min=0.001,
                 alpha_max=0.2, gamma=0.05):
        self.buf = deque(maxlen=W)          # 残差分数（按层）
        self.alpha = alpha_base
        self.alpha_base, self.alpha_min, self.alpha_max = alpha_base, alpha_min, alpha_max
        self.gamma = gamma

    def score(self, resid, layer):
        return weighted_norm(project(layer, resid))       # 定义 540

    def update(self, s_t, layer):
        self.buf.append((layer, s_t))
        err = 1.0 if s_t > self.radius(1, layer) else 0.0
        self.alpha = clip(self.alpha + self.gamma * (self.alpha_base - err),
                          self.alpha_min, self.alpha_max)  # 定义 542
        return self.p_value(s_t, layer)

    def radius(self, k, layer):
        scores = [max(s for (l, s) in self.window(layer, k)) for _ in (0,)]  # 轨迹级分数
        if len(scores) < MIN_CAL:                         # 校准不足 ⇒ 请求 Level-2
            return None
        return quantile(scores, 1 - self.alpha)           # 定义 541

    def p_value(self, s_t, layer):
        hist = [s for (l, s) in self.buf if l == layer]
        return (1 + sum(1 for s in hist if s >= s_t)) / (len(hist) + 1)  # 定义 548


# IP-358 TubeChunkPlanner：管束分块规划器
class TubeChunkPlanner:
    def __init__(self, f, oracle, omega_rob_bank, K_max=10, beta_max=None):
        self.f, self.oracle = f, oracle
        self.omega = omega_rob_bank
        self.K_max, self.beta_max = K_max, beta_max

    def plan(self, x0, layer_thresholds, social_risk):
        K = 1
        for k in range(1, self.K_max + 1):
            betas = {i: self.oracle.radius(k, i) for i in CERT_LAYERS}
            if any(b is None or b > self.beta_max[i] for i, b in betas.items()):
                break                                   # 覆盖不足/越界 ⇒ 定义 550
            if not self.omega.feasible(x0, betas):
                break                                   # 鲁棒终端不可行 ⇒ Level-1
            K = k
        if K == 1:
            return self.ac_fallback(x0)                 # 等价 v9 AC 单步
        prob = MPProblem(self.f, horizon=K, tighten=betas,
                         terminal=self.omega.select(betas))
        sol = prob.solve(deadline_ms=8.0)
        if sol is None:
            return self.ac_fallback(x0)                 # Level-1：退回 v9 AC
        pts = self._abort_points(x0, sol, betas)        # 定义 545
        if not pts:
            return self.ac_fallback(x0)
        return Chunk(sol.actions, CertTube(betas, sol.bounds), pts, sol.score)


# IP-360 ConformalShiftDetector：共形漂移检测器
class ConformalShiftDetector:
    def __init__(self, delta=0.01, c=0.5, eps=1e-3):
        self.Lambda, self.delta, self.c, self.eps = 0.0, delta, c, eps

    def step(self, p_t):
        e = 1.0 / max(p_t, self.eps)
        self.Lambda = max(0.0, self.Lambda + math.log(e) - self.c)
        return self.Lambda >= math.log(1.0 / self.delta)   # 定义 549


# IP-359 ZeroShotResidualAdapter：零样本残差适配器
class ZeroShotResidualAdapter:
    def __init__(self, d=8, lam=0.995, Pi=None):
        self.theta, self.P, self.lam, self.Pi = np.zeros(d), np.eye(d) * 1e3, lam, Pi

    def observe(self, s, a, resid):
        phi = features(s, a) @ self.Pi.T
        k = self.P @ phi / (self.lam + phi @ self.P @ phi + 1e-9)
        self.theta += k * (resid - phi @ self.theta)
        self.P = (self.P - np.outer(k, phi) @ self.P) / self.lam
        return self.healthy()                          # trace(P)/‖θ‖ 越界 ⇒ False

## 4. 推导（引理 87–93）

**引理 87（块级共形覆盖）** 设窗口内分数 {s_τ:k} ∪ {s_test:k} 可交换。取 β = 第 ⌈(W+1)(1−α)⌉ 个次序统计量，则
```
1 − α ≤ P( s_test:k ≤ β_t(k) ) ≤ 1 − α + 1/(W+1)
```
证明：标准 split-conformal 秩论证。由于 s_{t:k} 是 max 型单调分数，"真实前缀误差 ≤ β"与"分数 ≤ β"是同一事件；对 k 取 max 包络不破坏单调性，故每个前缀都得到保守覆盖。∎

**引理 88（ACI 的任意漂移长期覆盖）** 对任意残差序列（不要求可交换），定义 542 的 α 更新与 err_t，有
```
| (1/T) Σ_{t=1}^T err_t − α_base | ≤ (α_max − α_min) / (γ T)
```
证明：α_{t+1} = α_t + γ(α_base − err_t) 求和望远镜，并用 clip 保证 α_T 有界。故平均误覆盖收敛到 α_base，**与分布无关**；这正是"零样本"的统计内核。∎

**引理 89（管束 MPC 的递归可行与约束满足）** 若 (i) 初始状态在鲁棒可行集内，(ii) 终端集 Ω_rob 对 W_t 鲁棒控制不变，(iii) 约束按 β_t(k) 收紧，则 (a) 每个 k 的 MPC 均可行；(b) 在覆盖事件 E_t = {真实轨迹始终落在标称 ⊕ β_t 管内}（由引理 87 给 P(E_t) ≥ 1−α_t）条件下，真实约束 g_i(x_k) ≥ d_safe,i 对全部 k≤K 成立；(c) P_t^tube 非空时，任意中块时刻可安全停驻。证明：(a) 标准 tube-MPC 归纳；(b) 管束包含真实偏差 + 收紧裕度；(c) 代入定义 545。注意：这是**以覆盖事件为条件**的确定性安全，不是逐状态无条件保证（见引理 90 与 §8）。∎

**引理 90（模型无关活守卫的逐时兜底）** 50Hz 活守卫只用**实测**间隙与速度、以及保守减速度上界 a_min，检查 d_meas − d_brake(v_meas) − d_safe ≥ 0。若检查通过，则存在一条从当前实测状态出发、逐时刻保持 ≥ d_safe 的停驻轨迹，该结论不依赖 f̂ 与任何模型误差。因而：块内逐时安全由活守卫承担；统计证书只决定"能否再往前规划/走多远"。组合引理 89：安全 = 活守卫（硬）+ 管束（性能/中止率），二者职责分离。∎

**引理 91（CSD 误报控制与延迟）** 零假设下 e_t=1/p_t 的乘积为测试鞅，Ville 不等式 ⇒ P(∃t: Λ_t ≥ log(1/δ)) ≤ δ，与数据分布无关；故新域中误报率仍被 δ 控制。备择下检测延迟满足 E[τ] ≲ log(1/δ)/KL(p_alt ‖ U)，漂移越强延迟越短。相对学习型 Δ_dom 的优势：不依赖训练分布，且对单步残差异常即时响应，天然免疫 v9 的"20 帧滑窗滞后"。∎

**引理 92（对 v9 的逐位退化等价）** 令 β_t^{(i)}(k)≡β^{(i)}、α_t≡α_base、CSD 关闭且漂流信号接 Δ_dom、ZRA 关闭（f̂=f̂_v9）、K_eff^conf≡K_max。则定义 543 退化为 v9 的采样 MPC + 固定余量，定义 545 退化为定义 534，定义 550 退化为定义 539，主闭环与 v9 ACMD 逐位一致：TLP 只改变"取哪个 β"与"是否收紧约束"，在常数 β 下二者取值集合相同。故 v10 的故障格点 ⊇ v9，任一增强失效均可按 Level-0…Level-5 逐级注入中立元、可观测日志逐位等价。∎

**引理 93（无标签零样本迁移）** v10 的证书流水线只消费 (a) 残差分数的窗口次序统计量、(b) 免训练的残差递推辨识、(c) 离线冻结的 Π、(d) ACI 标量更新。四者都不需要目标域标签、不执行梯度更新、不使用域身份。故在新域部署时**没有任何参数针对目标域被拟合**；引理 87/88 的覆盖保证对任何满足"窗口内可交换"或"任意流（长期平均）"的残差流成立。零样本安全性则进一步由引理 90 的模型无关活守卫承担，与任务分布无关。∎

**一句话**：共形保证是**边际 / 长期平均**意义而非逐状态条件意义，ACI 在突变后若干步内仍可能连续"未覆盖"；若把统计保证误读为逐时刻硬保证，就会在最需要安全的瞬间交出一张"平均而言正确"的证书。
