# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「竞品分析」×「视觉编码器」）

> R69 的 FLUID-RAS 把不确定性拆成 aleatoric 与 epistemic，用「流匹配多模态策略 + 主动多模态交互」去消解歧义，并新增一条「动作似然」第二意见去补 R68 最脆弱的洞。但它和 R68 一样，把全部判断**寄生在同一个视觉编码器 Φ 上**：R68 的残差在 Φ 的特征上算，R69 的流似然以 z=Φ(o) 为条件，连交互后的证据也经 Φ 解释。Φ 是共同原因（common cause）——它一旦悄悄丢掉一个因素（低光下的深度、遮挡下的目标身份、纹理缺失时的尺度），两条通道会**一起坏、并且一起自信**。共因冗余不是冗余。
>
> 本轮两个灵感正好给出解药与新的病理：
> - **竞品分析**：安全的置信不该是绝对自评，而该是**相对表现**——不问「我有多确定」，问「我在跟谁比、在什么条件下赢多少、这个赢是真本事还是大家都读错了同一份材料」。无标签的相对排序，比自我校准更可验证。
> - **视觉编码器**：把冗余放回它该在的位置——不是在同一根柱子上再挂一个传感器，而是引入**异构的眼睛**（语义 / 几何 / 时序）和一个**不吃学习数据的物理参照**；比较它们的分歧结构，而不是把分歧平均掉。
>
> 核心命题：**在 R68（测量）与 R69（行为）之上再加第三通道 U_rep（表征），并用「视觉编码器联盟 × 无套利竞品分析 × 红队竞品」来度量它；三通道有严格优先级——先证明表征可信，才允许花交互预算去消解动作歧义。** 命名 **RIVAL-RAS**（Representation-Integrity Verification via Adversarial League）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我用来看世界的这双眼睛本身还可信吗；如果不可信，我能借谁的眼睛**」。

## 0. 直觉与动机

**灵感 1（竞品分析 → 校准需要外部参照系）**
直觉：一个人说「我很确定」是无法验证的；但说「在同场竞标里我连续 20 次赢过对手 A、却持续输给对手 B，而且只在雨夜输」是可验证的。绝对置信度缺乏标签时几乎无法校准，而**相对次序**只需要可比较的评分，不需要真值。把多个视觉编码器放进一个「竞技场」：让它们对同一观测各自给出信念，用适当的评分规则（proper scoring）两两对照，就得到一个无标签的信任权重、一个胜率矩阵、一个价差。竞品分析在这里不是商业修辞，而是**把校准问题从「绝对量纲」转成「相对序」**，从而可被数据检验。

**灵感 2（视觉编码器 → 所有通道共享的共同原因）**
直觉：R68 校准残余、R69 行为似然，看起来是两条独立通道；但它们都在 Φ 的输出上做文章。若 Φ 在某个方向上系统性失明，残差会被标定吸收（R68 已自陈），流似然也会在「错的条件」上给出高概率——因为策略正是以这双错眼睛训练出来的。**两条通道的相关失效，等于一条通道**。真正独立的第二意见，必须来自**不共享 Φ 的归纳偏置与训练数据**：几何（双目/深度/对极约束）、时序（事件/光流）、以及一个可解析验证的物理参照。冗余必须放在共同原因的上游，而不是下游。

**灵感 3（平均会掩盖，竞争会揭示）**
直觉：对多个编码器做加权平均，会把分歧压成 0，恰好抹掉最有用的信号。市场类比更准确：**共识价是均值，买卖价差是不确定性，成交量的突变是 regime 警报**。保留竞争者之间的分离，把「价差」和「胜率变化」当一等信息；只在报告层做融合，不在安全层做平均。这也解释了为什么 R69 的单一策略采样再多也测不出表征问题：对同一个 Φ 多采样，只能得到「内部一致」，得不到「外部一致」。

**灵感 4（竞争的双刃 → 串谋与相关失效是新的头号威胁）**
直觉：竞品可以串通。更常见、更隐蔽的是**非恶意串谋**：几个编码器都基于同源互联网数据、相似架构、相似捷径，于是它们「默契地」在同一类样本上一起错。此时联盟高度一致、价差很小、无套利门通过，系统在最该警惕时反而最自信——这是**市场泡沫**。所以本轮必须交付：有效独立性 M_eff（不是名义成员数 M）、串谋检测、反单文化准入、以及一个不吃学习数据的参照锚。否则「多加几个编码器」只是把同一个偏见复制了几份。

**灵感 5（最强竞品是红队 → 证书必须可伪证）**
直觉：最值得警惕的对手不是同行的平均表现，而是一个专门寻找「证书宣称安全、现实却越界」的输入。红队竞品的任务就是最大化这个**认证—现实缺口**：它的成功一次就能推翻证书。这把 R68/R69 那种「我算出来安全」的静态声明，升级为一个**可被独立对手攻击、尚未被证伪**的科学假设；同时诚实地承认：有限红队不能证明「不存在漏洞」，只能给出「暂未被证伪」。

**灵感 6（优先级 → 先验表征，再问世界）**
直觉：R69 会为了消解动作歧义去「看/问/触」。但如果眼睛本身坏了，你去问的其实是一个幻影世界，得到的回答只会被错误编码器解释成「已验证」。因此三通道不能平权：**U_rep 是门，U_epi 是门后的预算，U_ale 是永远的地板**。表征门不过，就只允许「换一双独立眼睛」的探询，不允许基于可疑特征去花社交/物理交互预算。这是 R70 最重要的顺序性主张，也是 R69「问错比不问更危险」的真正根治。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（RIVAL-RAS 总览）** RIVAL-RAS = (VEL, ARB, RIV, RED, RAG, RAS-WM††)。四不变式：
(i) **实时零学习写操作**（继承 R68 定义 276-i / R69 定义 293-i）；
(ii) **表征多样性下限**：联盟中至少含一个解析/物理参照编码器 Φ_ref，其运行不依赖任何学习权重，且与学习编码器不共享训练数据；
(iii) **独立性与优先级纪律**：联盟共识只有在有效独立性 M_eff ≥ 2 且未检出串谋时方可托付；且表征门（定义 319）严格先于 R69 的交互门；
(iv) **竞争不改安全包络**：竞品分析只改变「用哪双眼睛、信到什么程度」，不改变任务安全包络（继承 R69 定理 17）。

**定义 311（视觉编码器联盟 VEL）** E = {Φ_e}_{e=1..M}，Φ_e: 𝒪 → ℝ^{d_e}，并各自给出信念 b_e ∈ Δ(ℳ)（模态/风险档/动作族上的分布）。异构类别至少覆盖：语义（自监督表征）、几何（双目/深度/对极）、时序（事件/光流）、参照（解析几何或已知标定物）。两两分歧 D(e,e') = D_KL(b_e‖b_e') 或信念空间上的 Wasserstein。运行时按定义 323 条件激活，不在每帧跑满联盟。

**定义 312（竞品分析市场协议 ARB）** 在滑动窗口 W 上，对每个 e 计算适当评分 S_e：
S_e = α·S_e^ref + (1−α)·S_e^peer，
其中 S_e^ref 只在参照 Φ_ref 有效的样本子集 V 上、以 ref 为伪标签的 proper score；S_e^peer 用相关一致性/贝叶斯真值血清（peer prediction）在学习编码器两两之间给分，弥补 ref 失效时段。信任权重 w_e ∝ exp(η S_e)（仅供诊断与选眼，不直接并入安全带）。另定义：
- **共识价** b̄ = Σ_e w_e b_e（仅报告层）；
- **价差** s = Σ_e w_e D(b_e, b̄)（分歧，一等信息）；
- **胜率** π_{e,e'} = P_W(S_e > S_{e'})，按 regime 分层统计。

**定义 313（三通道不确定性分解）** U := (U_ale, U_epi, U_rep)。
- U_ale：模态内不可约噪声（R69 定义 297）；
- U_epi：动作/语义模态间的可约歧义（R69 定义 297）；
- U_rep：**共享表征层的可约但不可在同源编码器内消解**的不确定性，定义为
  U_rep = s·(1/M_eff) + κ·(1 − M_eff/M) + λ_c·CollapseRisk + λ_d·Drift。
  第二项是「单文化惩罚」：即便价差 s≈0，只要 M_eff≈1（大家同源同错），共识也不构成证据。三通道不作简单加和，分别进入定义 319 的不同分支。

**定义 314（表征完整性验证 RIV）** 三项可观测诊断：
(i) **坍塌风险** CollapseRisk：z_e 的有效秩/有效维数低于阈值，或特征协方差的最小特征值趋零；
(ii) **漂移** Drift：当前 z_e 分布与参考缓冲的 MMD / 能量距离；
(iii) **跨编码器不一致** C = max_{e,e'} D(b_e, b_e')。
U_rep 由 (s, M_eff, CollapseRisk, Drift) 组成；RIV 输出 U_rep、以及「哪一类编码器在何种 regime 上失配」的归因（供 RED 与 LPL 使用）。

**定义 315（有效独立性与串谋检测 MCE）** 令 ε_e 为编码器 e 在无标签留出集上的残差向量，R 为其相关矩阵，特征值 λ_i。有效独立数 M_eff = (Σ_i λ_i)² / Σ_i λ_i²（参与率），完全相关时 M_eff=1，完全独立时 M_eff=M。串谋检测 CD：若「联盟联合错误率」显著低于独立假设下的乘积边际（过度一致且不能由参照锚解释），或任意子集的残差在参照失效区间内同向偏移，则 CD=+1。**M_eff 用参照锚校准，串谋者无法与物理串谋。**

**定义 316（无套利门 NAC）** 联盟「无套利」当且仅当
NAC ⇔ (M_eff ≥ 2) ∧ (s ≤ τ_spread) ∧ (∀ 学习编码器 e, π_{e,ref} ≥ τ_win) ∧ (CD = 0)。
直觉：若存在一个编码器能系统性「套利」——持续战胜共识或持续战胜物理参照——说明市场定价错了，共识不可托付。NAC 通过是「共识可信」的**充分不必要条件**：它宁可保守地拒绝好共识，也不放行坏共识。

**定义 317（红队竞品 RED）** 在物理可实现扰动集 Δ 上搜索
δ* = argmax_{δ∈Δ} [ R_cert(Φ(o+δ)) − R_real(δ) ]，
即最大化「证书宣称的风险」与「现实风险」之间的缺口；同时报告首个使 J_RIVAL 失效的证伪样本。RED 只用于**证伪**，不参与认证打分，且离线运行。

**定义 318（参照引导探询 RGP）** 当 U_rep > τ_rep 时，信息动作必须使用**独立于可疑编码器的通道**：切换几何/双目、请求一个能触发参照锚的视角、或提出其答案可被物理参照验证的问题。禁止用可疑编码器去解释回答。表征级 VoI：
VoI_rep(g) = H(ℳ_rep|o) − E_{y~p(·|g,o)}[H(ℳ_rep|o,y)]，其中 ℳ_rep 是「哪双眼睛的世界为真」的隐变量。选择 g* = argmax[VoI_rep − c(g)]，过 C-RAS-WM 认证。

**定义 319（表征风险仲裁门 RAG）** 三出口，严格有序：
(1) 若 NAC ∧ U_rep ≤ τ_rep：表征可信，进入 R69 原流程（获得 resolution bonus）；
(2) 若 ¬NAC ∨ U_rep > τ_rep，但参照/几何编码器单独足以支撑一个更慢的安全策略：切到 **reference-only 安全模式**，并允许 RGP；
(3) 若参照也失效（纹理缺失、黑暗、标定丢失）：退化为 R68 纯保守（λ = λ_floor(U_ale+U_epi+U_rep)），停止一切基于学习特征的交互。
仲裁单调：竞争只可能让策略更保守，绝不越过 R68 的地板。

**定义 320（竞品相对证书 J_RIVAL）** J_RIVAL = (J_FLUID, competitor_set C, M, M_eff, s, na_ok, u_rep, red_falsification_rate, collusion_flag, league_hash, rival_ver)。Valid ⇔ Valid(J_FLUID) ∧ na_ok ∧ M_eff ≥ 2 ∧ collusion_flag=0 ∧ u_rep ≤ τ_rep ∧ RED 在证伪集上未发现超过 τ_red 的缺口。**证书必须显式报告对手集 C 与 M_eff**（定义 324）。

**定义 321（市场泡沫界）** 设学习编码器共享一个共同失效事件 B（P(B)=p_c），在 B 上全部以 ≥1−ε 概率给出同一错误模态。则对任意融合/投票规则，P(联盟错) ≥ p_c(1−ε)；增加 M 不改变该下界，只有引入与 B 不相关的参照才能降低它。系：名义冗余 M 是虚荣指标，M_eff 才是可靠性的通货。

**定义 322（升降级与反单文化 LPL）** 编码器按持续胜率升降级；新成员准入需通过 (a) 与现役成员的残差去相关检验、(b) RED 抽检、(c) 参照锚下的校准检验。任何单一架构占比超过阈值即触发「单文化告警」，强制保留一个异构参照成员。所有调整在离线/换班期完成，实时期零学习写。

**定义 323（条件联盟与预算）** 默认每帧只跑主编码器 + 一个廉价「分歧草图」（特征 sketch / 低维投影）与缓存参照统计比对；仅当草图异常、或周期性（每 T ms）、或 R69 报歧义时激活完整联盟（M≤3）。红队完全离线。以此把联盟成本摊到 alarm 路径而非常规路径。

**定义 324（认证的相对性）** 风险证书总是相对于一个对手集/威胁集 C 才有意义：记 R_cert(RIVAL | C)。同一系统可能对 C1 可认证、对 C2 不可认证。**不报告 C 与 M_eff 的绝对安全声明，视为无效声明。**

## 2. 关键算法骨架

```python
# IP-264 VEL：异构视觉编码器联盟（含解析参照，实时只条件激活）
class VisualEncoderLeague:
    def __init__(self, semantic, geometric, temporal, reference, sketch, M_max=3):
        self.enc = [semantic, geometric, temporal]   # 学习编码器
        self.ref, self.sketch, self.M_max = reference, sketch, M_max

    def quick(self, o):                               # 常规路径：主编码器 + 分歧草图
        z = self.enc[0](o)
        chi = self.sketch(z)                         # 低维草图，与缓存参照统计比对
        return z, chi

    def full(self, o):                                # alarm/周期路径：完整联盟
        zs = [e(o) for e in self.enc[:self.M_max]]
        zr, ref_valid = self.ref(o)                  # 解析参照，可能失效
        return zs, zr, ref_valid

# IP-265 ARB：无标签竞品分析（proper scoring + peer prediction + 胜率）
def arena_market(beliefs, ref_belief, ref_valid, window):
    S = {}
    for e in beliefs:
        s_ref  = proper_score(beliefs[e], ref_belief) if ref_valid else None
        s_peer = correlated_agreement(beliefs, e)                    # 无 ref 时段兜底
        S[e] = blend(s_ref, s_peer)
    w = softmax(eta * S)
    b_bar = weighted_mean(beliefs, w)
    spread = sum(w[e] * divergence(beliefs[e], b_bar) for e in beliefs)
    win = win_rate_matrix(window, S)                 # 分 regime 的 π_{e,e'}
    return w, b_bar, spread, win

# IP-266/267/268：表征完整性 + 有效独立 + 无套利
def representation_gate(league_out, beliefs, window):
    zs, zr, ref_valid = league_out
    collapse = collapse_risk(zs)                     # 有效秩 / 最小特征值
    drift    = mdd_drift(zs, ref_buffer)
    m_eff    = participation_ratio(residual_corr(window))
    collude  = collusion_test(window, ref_valid)
    w, b_bar, spread, win = arena_market(beliefs, zr, ref_valid, window)
    u_rep = spread / max(m_eff, 1e-6) + kappa * (1 - m_eff / M) \
            + lambda_c * collapse + lambda_d * drift
    na_ok = (m_eff >= 2) and (spread <= TAU_SPREAD) \
            and all(win[(e, 'ref')] >= TAU_WIN for e in learned) and not collude
    return u_rep, na_ok, m_eff, spread, collapse, drift, collude

# IP-269 RED：红队竞品（离线，最大化认证—现实缺口）
def red_team_falsify(cert, policy, Delta):
    best = None
    for delta in Delta:                              # 物理可实现扰动
        gap = cert.claimed_risk(policy, delta) - realized_risk(policy, delta)
        if best is None or gap > best.gap: best = (delta, gap)
    return best                                     # 一次成功即证伪 J_RIVAL

# IP-270/271/274：主闭环（表征门严格先于交互门）
def RIVAL_RAS_round(M, obs):
    z, chi = M.vel.quick(obs)
    alarm = M.vel.sketch_alarm(chi) or M.periodic_due()
    if alarm:
        zs, zr, ref_valid = M.vel.full(obs)
        u_rep, na_ok, m_eff, spread, collapse, drift, collude = \
            M.riv.representation_gate((zs, zr, ref_valid), M.beliefs, M.window)
    else:
        u_rep, na_ok = M.riv.cached_estimate(), True
    # ── 表征门：先验眼睛，再问世界 ──
    if not na_ok or u_rep > TAU_REP:
        if M.ref.sufficient(obs):
            g = M.rgp.choose_reference_probe(obs)    # 只允许换独立眼睛
            return M.reference_only_safe_policy(obs, g)
        lam = M.efs.lam_floor(M.u_ale + M.u_epi + u_rep)   # 回 R68 最保守
        return M.pure_conservative(obs, lam)
    # ── 表征可信：进入 R69 交互消歧 ──
    return M.fluid_ras_round(obs, z, resolved_bonus=True)
```

## 3. 推导

**引理 19（共同原因下冗余无效）** 设学习编码器共享失效事件 B（P(B)=p_c），在 B 上均以概率 ≥1−ε 给出同一错误信念。对任意确定性/随机融合规则 f，P(f(b_1..b_M) 错) ≥ p_c(1−ε)。故增加 M 无法把错误率降到 p_c 以下；只有与 B 不相关的参照编码器能改变该下界。系：定义 315 的 M_eff 是冗余增益的正确度量，定义 321 是其概率表述。

**引理 20（相对校准的可辨识性与相关偏置）** 在给定真实隐变量 ℳ 条件独立、且参照锚在子集 V 上有效的假设下，ARB 的排序 argmax_e S_e 依概率收敛到真实技能排序 argmin_e R_e，有限样本误差 O(1/√|V|)（proper scoring 的严格一致性）。若条件独立被破坏（残差相关 ρ>0），排序偏置 ≤ c·ρ/(1−ρ)；故必须用 M_eff 折算、并用 CD 检测「过度一致」。这给出「竞品分析可做无标签校准」的严格依据，也给出它失效的边界。

**引理 21（无套利门的可靠性）** 若窗口内存在一个编码器 e 在统计上主导性错误（相对参照持续败北或胜率异常领先），则在定义 316 的阈值下 NAC 以 ≥1−δ 概率失败。取逆否：NAC 通过 ⇒ 不存在可被窗口检出的主导性错误。故 NAC 是**健全的**（不轻易放行坏共识），但可能**保守**（拒绝好共识）——对安全系统，这个方向的不对称是正确的。

**引理 22（可伪证性）** J_RIVAL 的有效性要求 RED 在物理扰动集 Δ 上未找到缺口 > τ_red。因此任一满足条件的 δ 都是证书的证伪见证；证书语义严格为「截至当前对手集 C 与红队预算下，尚未被证伪」，而非「已证明安全」。系：认证是相对的（定义 324），报告必须带 C。

**定理 18（RIVAL 严格包含 FLUID 与 R68）** 在 A99（参照锚有效、M_eff≥2、无串谋、RED 通过）下，RIVAL 在任意状态的期望风险 ≤ FLUID-RAS；当 NAC 失败、U_rep 越界或参照失效时，RIVAL 逐指令退化为 R68 纯保守（或 reference-only 安全策略）。R69 是「联盟退化为单编码器」的边界，R68 是「联盟关闭」的边界。安全侧不让步；效率侧只在**表征被独立验证**后获得 resolution bonus。

**定理 19（表征门先于交互门的安全性）** 定义 319 的严格优先级保证：任何基于可疑特征的动作/问句都不会被执行（定义 318 只放行独立通道探询）。故 R69「在错误信念上自信追问」的失败模式被结构性阻断；结合 R69 定理 17 的认证与换装不变式，控制连续、无突变，且交互预算不会消耗在幻影世界上。

```python
# IP-264 VEL：异构联盟（常规只跑主编码器 + 分歧草图）
class VisualEncoderLeague:
    def quick(self, o):
        z = self.semantic(o); chi = self.sketch(z)     # 低维草图
        return z, chi

    def full(self, o):
        zs = [e(o) for e in self.enc[:self.M_max]]     # M≤3
        zr, ref_valid = self.reference(o)              # 解析参照可失效
        return zs, zr, ref_valid

# IP-265 ARB：无标签竞品分析
def arena_market(beliefs, ref_belief, ref_valid, window):
    S = {}
    for e in beliefs:
        s_ref  = proper_score(beliefs[e], ref_belief) if ref_valid else None
        s_peer = correlated_agreement(beliefs, e)      # ref 失效时段兜底
        S[e] = blend(s_ref, s_peer)
    w = softmax(eta * S)
    b_bar = weighted_mean(beliefs, w)
    s = sum(w[e] * divergence(beliefs[e], b_bar) for e in beliefs)
    return w, b_bar, s, win_rate_matrix(window, S)

# IP-266/267/268：表征完整性 + 有效独立 + 无套利
def representation_gate(league_out, beliefs, window):
    zs, zr, ref_valid = league_out
    collapse = collapse_risk(zs); drift = mdd_drift(zs, ref_buffer)
    m_eff = participation_ratio(residual_corr(window))
    collude = collusion_test(window, ref_valid)
    w, b_bar, s, win = arena_market(beliefs, zr, ref_valid, window)
    u_rep = s / max(m_eff, 1e-6) + kappa * (1 - m_eff / M) \
            + lambda_c * collapse + lambda_d * drift
    na_ok = (m_eff >= 2) and (s <= TAU_SPREAD) \
            and all(win[(e, 'ref')] >= TAU_WIN for e in learned) \
            and not collude
    return u_rep, na_ok, m_eff, s, collapse, drift, collude

# IP-269 RED：红队竞品（离线，最大化认证—现实缺口）
def red_team_falsify(cert, policy, Delta):
    best = None
    for delta in Delta:
        gap = cert.claimed_risk(policy, delta) - realized_risk(policy, delta)
        if best is None or gap > best.gap: best = (delta, gap)
    return best                                        # 一次成功即证伪

# IP-270/271/274：主闭环（表征门严格先于交互门）
def RIVAL_RAS_round(M, obs):

    if M.vel.sketch_alarm(chi) or M.periodic_due():

            (zs, zr, ref_valid), M.beliefs, M.window)

    # 表征门：先验眼睛，再问世界

        lam = M.efs.lam_floor(M.u_ale + M.u_epi + u_rep)
        return M.pure_conservative(obs, lam)           # R68 最保守
    return M.fluid_ras_round(obs, z, resolved_bonus=True)   # 进入 R69
```

## 4. 推导

**引理 19（共同原因下冗余无效）** 学习编码器共享失效事件 `B`（`P(B)=p_c`），在 `B` 上以 ≥1−ε 概率给出同一错误信念；则任意融合规则 `P(联盟错) ≥ p_c(1−ε)`，增加 M 不改变下界。系：`M_eff` 才是冗余增益的正确通货，名义 M 是虚荣指标。

**引理 20（相对校准可辨识性与相关偏置）** 给定隐变量条件独立且参照锚在子集 V 上有效，ARB 排序依概率收敛到真实技能排序，误差 `O(1/√|V|)`；若残差相关 ρ>0，偏置 `≤ c·ρ/(1−ρ)`，须以 M_eff 折算并用 CD 检测过度一致。

**引理 21（无套利门可靠性）** 若窗口内存在主导性错误的编码器，则 NAC 以 ≥1−δ 概率失败；逆否得 NAC 通过 ⇒ 无可检出的主导性错误。故 NAC 健全、可能保守，方向对安全有利。

**引理 22（可伪证性）** J_RIVAL 要求在物理扰动集 Δ 上红队未找到 >τ_red 的缺口；任一这样的 δ 都是证伪见证。证书语义严格为「截至对手集 C 与红队预算下尚未被证伪」，不是「已证明安全」。

**定理 18（严格包含 FLUID 与 R68）** 在 A99（参照有效、M_eff≥2、无串谋、RED 通过）下，RIVAL 任意状态期望风险 ≤ FLUID-RAS；NAC 失败 / U_rep 越界 / 参照失效时逐指令退化为 R68 纯保守（或 reference-only 安全策略）。R69 = 单编码器边界，R68 = 联盟关闭边界；安全不让步，效率仅在表征被独立验证后获得 resolution bonus。

**定理 19（表征门先于交互门）** 严格优先级保证任何基于可疑特征的动作/问句都不执行；RGP 只放行独立通道探询。故 R69「在错误信念上自信追问」被结构性阻断；结合 R69 定理 17 的认证与换装不变式，控制连续、无突变，交互预算不消耗在幻影世界上。

## 7. 本轮最大风险

**一句话**：RIVAL-RAS 的全部收益押在「联盟成员真的相互独立」这一前提上——**若竞品们共享训练数据、架构捷径或同一个物理盲区，它们会在同一类输入上一起错、并因彼此一致而显得高度可信，价差小、NAC 通过、系统在最该保守时反而最自信；而唯一的救命锚（物理参照）也可能在黑暗/无纹理/标定丢失时同时失效，所谓冗余本身就是那个共同原因**——**共识不等于真值，unanimous 也可能只是 everybody read the same bad memo**。

**次级风险与缓解**：参照锚失效（RAG 第三出口回 R68 + E310）；串谋/同源污染（M_eff + CD + LPL + E304）；多编码器计算预算（条件联盟 + 草图门控 + 周期全量 + E311）；相对证书被误读为绝对安全（定义 324 强制报告 C 与 M_eff + E315）；红队有限性（引理 22 明确「尚未证伪」语义，证书带红队预算）。
