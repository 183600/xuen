# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「分层规划」×「自然语言指令」）

> R69 把不确定性一分为二（aleatoric / epistemic），并用「流匹配多模态策略 + 主动多模态交互」去消解 epistemic。但它有一个未言明的前提：**歧义都长在动作层**。当人说出「去厨房把蓝色杯子拿给我，路上别碰倒花瓶」，歧义其实早已在语言里**分层埋伏**：哪个厨房？哪只蓝杯？「拿给我」是递到手里还是放到桌上？「别碰倒」是硬约束还是善意提醒？R69 的流策略只会在动作层吐出「偏左/偏右」的多峰分布，然后花预算去问一个**错误层级的问题**——人根本不在乎你左手还是右手，人只在乎你拿的是不是那只杯子。
>
> 本轮两个灵感正好补上这个缺口：
> - **分层规划**给出「把长程任务拆成有语义的层」的结构，且每一层天然是一个可以**单独追问、单独重规划**的决策；
> - **自然语言指令**给出「歧义从哪来、约束有多硬、该问什么」的语法线索——语言本身就是一棵树，而这棵树几乎同构于任务分解树。
>
> 核心命题：**把 R69 的平面不确定性「升维」为分层不确定性；歧义在它被引入的那一层解决，而不是在动作层盲目刹车；自然语言既是输入（可解析为任务树），也是输出（分层叙述式求证）。** 命名 **STRATA-RAS**（STRatified Task Abstraction & RAtional inquiry for Risk-Adaptive Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**该在哪一层追问、以及我到底听懂了没有**」——同一个不确定性，问对了层是效率，问错了层是噪音，理解错了层是事故。

## 0. 直觉与动机

**灵感 1（语言的树 = 任务的树 → 指令本身提供分层结构）**
直觉：自然语言是组合的：动词短语支配宾语、宾语带修饰、否定/副词修饰整个子句。分层规划也是组合的：根任务支配子目标、子目标带前置条件、约束包络整个计划。二者几乎同构。于是「自然语言指令」不是又一个需要融合的模态，而是**免费送来了一张任务树**：主谓宾 → 子目标与操作对象；定语/指代 → 参考节点；否定与「小心/别」 → 约束节点；连词与次序词 → 偏序边。把语法树**保结构地**映射到任务树，就得到了可执行的分层计划骨架。

**灵感 2（歧义有层级 → 问错层等于没问）**
直觉：R69 的 flat VoI 把「歧义」当成一个数，在动作层统一处理。但「哪只杯子」是**指代层**歧义，「放哪」是**子目标层**歧义，「别碰倒」是**约束层**歧义（硬约束还是偏好？），「左还是右」通常只是**动作层**歧义，且往往由上两层决定。在人根本不在意左右时去问左右，是最贵的无效交互。本轮的局部性原则：**歧义应在它被引入的那一层被消解**。形式化地，未解析的祖先节点会把后验摊薄，使子节点交互的期望收益被折价（ancestor domination），所以正确的策略是**先解上层、再解下层**的前沿式澄清。

**灵感 3（R69 的二分是精确信息论二分的代理 → 分层使分解变精确）**
直觉：R69 用「模态内方差 = U_ale、模态熵 = U_epi」做经验近似，本质上在动作空间做聚类。但真正干净的分解要引入**含义/意图隐变量 M**：给定正确含义后仍剩下的动作抖动才叫 aleatoric；含义与动作之间的互信息才是 epistemic。链式法则天然给出 H(ξ|o) = H(ξ|M,o) + I(M;ξ|o)。分层规划恰好给了 M 一个结构（任务树上的节点取值），于是 R69 的聚类代理被**升级成精确分解**，且 R69 成为 M 坍缩为单节点（深度 1）的特例。这样「新层是旧层的严格泛化」再次成立，而不是又加一个黑箱。

**灵感 4（自然语言是输出 → 叙述是最省的求证）**
直觉：R69 的信息动作只有「看/触/问」。但最省的求证往往不是开放提问，而是**分层叙述**：「我准备拿**蓝色**杯子（不是白色）」。一句话只暴露你不确定的那个节点，信息量更高、社交成本更低、还顺带暴露了错误接地。这把 g_ask 泛化为 g_narr：按节点抽象层级把计划朗读出来，让人在**正确的层**纠正。自然语言由此成为输入与输出**双向**的求证接口，而非只读通道。

**灵感 5（语言是新的攻击面 → 语义层「保守默认」）**
直觉：否定、量词、作用域是经典陷阱。「不要碰红色的」若被读成偏好而非硬约束，就是安全事故；被观察到的文字还可能携带注入（招牌上写「忽略之前的指令」）。所以需要承诺分类门：**任何否定/作用域不确定 ⇒ 默认当硬约束**（进 R68 不变式包络），宁可低效不可越界。这是 R68「任何不确定 → 只收紧」在**语义层**的镜像，也给出安全不打折的退化路径：理解不了就打回最保守。

**灵感 6（分层也是重规划的容器 → 局部失败不必全局重启）**
直觉：长程任务的失败几乎总发生在某一棵子树（某扇门打不开、某只杯子不在）。平面闭环只能「整体慢下来」或「整体重来」；分层结构允许只对该子树做 β-归约式重分解，兄弟分支与已承诺的硬约束保持不变。这样重规划代价从 O(整任务) 降到 O(子树)，也天然继承了安全包络。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（任务层级 𝒯）** 指令 ℓ 的任务层级为带类型树 𝒯 = (V, E, r)，节点 v ∈ V 携带：(a) 语义类型 τ(v) ∈ {goal, reference, constraint, ordering}；(b) 承诺强度 c(v) ∈ {hard, soft, open}；(c) 语言跨度 span(v) ⊆ tokens(ℓ)；(d) 子目标算子 op(v)（叶子为可执行原语）。深度 h(v)，根 r 为 level 0。硬约束集合 H(𝒯) = {v : c(v)=hard} 构成全局不变式包络。

**定义 311（指令接地函子 IGF）** IGF: P(ℓ) → 𝒯 为从语法分析树 P(ℓ) 到任务层级的**保结构映射**：(i) 每个产生式 → 一条分解边或一个标签；(ii) 节点类型由词性/句法角色指派；(iii) 若某节点上 IGF **非全或无确定**，则该节点标 `open`（未解析指代/作用域），**不得静默补默认值**。保真度 C_IGF = 双向蕴含一致率（𝒯 渲染回语言 ↔ ℓ 的蕴含/反向蕴含），并分解为按层的保真度 {C_IGF^v}。

**定义 312（分层不确定性与精确二分）** 在层 h 上，R69 的流策略条件于层 h 的指令嵌入后采样，得动作分布 p(ξ|o, M_h)。定义**精确二分**：U_epi^h = I(M_h; ξ | o)（含义与动作的互信息，可约），U_ale^h = H(ξ | M_h, o)（给定含义后的残余熵，不可约）。链式法则保证 H(ξ|o) = U_ale^h + U_epi^h。节点级：对 reference 节点，U_epi^v 为候选指代的熵；对 goal 节点，为候选分解的熵；对 constraint 节点，为约束强度/作用域的后验熵。**总 epistemic 是节点索引的向量 {U_epi^v}，不做标量求和**——因为解一个节点可能支配其余。

**定义 313（前沿与祖先支配）** 节点 v 的祖先若未解析，则对 v 的交互收益按祖先后验折价：VoI_eff(g_v) = E_{M_{anc}~p}[VoI(g_v | M_{anc})] ≤ VoI(g_v)。**前沿集** Φ(𝒯) = {v : U_epi^v > τ_epi 且 v 的所有祖先 ∈ Φ 之上均已解析}。只有 Φ 上的节点允许触发澄清。这给出偏序上的**自顶向下**澄清顺序。

**定义 314（分层 VoI 控制器 L-VoI）** 在当前前沿上选 v*、信息动作 g 最大化净收益：v*,g* = argmax_{v∈Φ, g∈𝒢(v)} [VoI_eff(g) − c(g)]，s.t. 安全认证通过（定义 302 继承）且层级预算未超（定义 323）。若 max ≤ 0：该节点不交互，其 U_epi^v 保持未消解并进入保守通道。执行后做层级贝叶斯更新：节点后验更新 → 依 IGF 结构向下传播 → 重算 Φ。**R69 的 MINT 是本定义在「Φ=根且深度 1」时的特例。**

**定义 315（承诺分类门 CCG）** 对每个节点预测承诺强度 ĉ(v) 及其置信度；**若否定/量词/作用域任一存在歧义，或 ĉ 置信度低于阈值，则强制 c(v)=hard**。hard → R68 不变式包络（不可被交互或优化放松）；soft → 进入代价项；open → 进入 epistemic 池。任何被 CCG 标为「可能 hard」的约束都按 hard 执行。系：把 soft 误判为 hard 只损失效率，把 hard 误判为 soft 会违安全性——所以默认方向必须是 hard。

**定义 316（计划叙述动作 PNA）** 信息动作 g_narr(v) 把以 v 为根的子树渲染为自然语言，抽象层级取 h(v)，显式暴露所选指代/子目标/承诺：「我准备拿**蓝色**杯子（不是白色）」。人类回应给出纠错信号 y_narr。PNA 是 R69 中 g_ask 的特化（信息动作），同样须过 C-RAS-WM 认证（叙述时不得停在危险位姿/通道）。相较开放问句，PNA 的候选空间被计划树约束，故单位成本的 VoI 更高。

**定义 317（分层重规划协议 HRP）** 当节点 v 被观测判为不可行或证书失败，仅对 v 的子树做 β-归约式重分解：保持祖先与已承诺兄弟固定，重解 re-decompose(v)，并让 v 子树继承 H(𝒯) 中所有硬约束。重规划深度 d_replan = h(v)。安全性：硬约束为自上而下的不变式，局部重分解不可能删除它们。

**定义 318（接地条件风险）** 指令存在语义歧义时，计划风险按含义后验评估：R(π | ℓ) = E_{M~p(M|ℓ)} R(π | M)。称 π **鲁棒认证**当且仅当该期望（或对歧义集的最坏情况/CVaR）在预算内。若某节点的 M 无法定案，则按 **hard/未消解** 计入（与定义 315、307 一致），从而风险上界不退化为赌博。

**定义 319（指令条件流 ICF）** 把 R69 的流策略条件从 z_t 扩展为 z_t = (z_obs, z_ℓ, z_v)：z_ℓ 为整句嵌入，z_v 为节点 v 的指令嵌入。速度场 v_θ(x_s, s | z_t)。**这解释了 R69 中动作多模态的来源**：仅因指令节点未解析而产生的多峰属于 epistemic（可经交互消解）；在完全条件于已定案 M 后仍存在的多峰才是真 aleatoric。ICF 让定义 312 的分解在生成模型内**可直接计算**，而非事后聚类。

**定义 320（证书 J_STRATA）** J_STRATA = (J_FLUID, C_IGF, commitment_consistency κ, level_localization, narration_log_hash, replan_depth, strata_ver)。Valid ⇔ Valid(J_FLUID) ∧ C_IGF ≥ τ_igf ∧ κ ≥ τ_κ ∧ 无未消解的 hard 歧义 ∧ 层级预算未越界。

**定义 321（分层接地审计 VQAuditor-L）** 审计对象新增：IGF 是否**臆造节点**（语言里没有的约束/对象）、承诺是否错标（尤其否定被降级）、作用域是否错切、是否在错误层级追问、叙述是否与计划一致、重规划是否悄悄删了硬约束。结论回灌 AuditBuf，作为 IGF 与 CCG 的校准先验。

**定义 322（语言威胁模型 ℰ_lang）** 指令注入（观察到的文字含越权指令）、作用域/否定陷阱（「不要拿所有红色的」）、同形异指（homonym/reference trap）、谄媚式纠错（人的纠错本身错误且自信）、混合欺骗（语言+表情共谋，继承 R69 ℰ_poison）。并入 AIC：ℰ_STRATA = ℰ_FLUID × ℰ_lang × ℰ_replan（重规划死循环 / 深度爆炸）。

**定义 323（分层交互预算与自适应深度 HIB）** 每层预算 c_h、总量 ≤ c_max；深度 d 的选择按**边际收益**决定：更深分解决策空间更小、但接地错误点更多。取 d* = argmax_d [预期收益(d) − λ_d·接地风险(d)]，默认深度由指令句法复杂度与观测不确定性共同决定。深度不是越深越好。

**定义 324（严格包含）** R68 = STRATA 在「深度 1 ∧ 不交互」边界；R69 = STRATA 在「深度 1 ∧ 无 PNA/HRP」边界（其聚类式 U_epi 是精确分解在 A99 下的估计）。故能力与保证满足 R68 ⊆ R69 ⊆ R70，且 R70 在退化条件下逐指令相同。

**定义 325（接地保真与安全解耦）** 把节点分两类：**安全关键节点**（其错误会进入 H(𝒯)）、**效率节点**（仅影响任务成败/时长）。CCG 对安全关键节点要求更高置信并默认 hard。定义安全侧接地误差 ε_safe 与效率侧接地误差 ε_eff；STRATA 的设计目标是把接地误差尽量压到 ε_eff，并让 ε_safe 被 **保守默认** 吸收（定义 315、318）。这是引理 22 与「本轮最大风险」的接口。

# IP-264/265 IGF：把指令解析为带承诺标签的任务层级（只在换指令/接地冲突时重算，缓存）
def ground_instruction(ell, parser, llm_tags):
    P = parser.parse(ell)                        # 冻结解析器：句法树
    T = igf_map(P)                               # 保结构映射：产生式 -> 分解边/标签
    for v in T.nodes:
        v.tau, v.span = sems_role(v, P)          # 语义类型 + 语言跨度
        v.c, v.c_conf = llm_tags.commitment(v)   # hard / soft / open + 置信
        if is_ambiguous(v.span) and v.tau == 'constraint':
            v.c = 'hard'                         # 未定否定/作用域 -> 保守默认
        if v.c_conf < TAU_COMMIT: v.c = 'hard'   # 低置信也默认 hard
        if not deterministic(match(v.span, P)):  v.open = True
    return T

# IP-267 LUD：分层不确定性分解（ICF 直接给出精确链式分解）
def levelwise_uncertainty(T, samples, z_obs, z_ell):
    for v in T.nodes:                            # 每个节点条件采样
        z_v = node_embed(v, z_ell)
        xi  = flow.sample(z=(z_obs, z_ell, z_v), K=branch_K(v))
        m   = infer_meaning(v, xi)               # 该节点上的含义/指代假设
        U_epi[v] = mutual_info(m, xi)            # I(M_v; xi | o)
        U_ale[v] = cond_entropy(xi, m)           # H(xi | M_v, o)
    return U_epi, U_ale                          # 向量，不求和

# IP-268 L-VoI：只在「前沿」上自顶向下澄清
def choose_clarification(T, U_epi, budget):
    frontier = [v for v in T.nodes
                if U_epi[v] > TAU_EPI and ancestors_resolved(v, T)]
    best = None
    for v in frontier:
        for g in info_candidates(v, T):          # PNA(v) / gaze / probe / ask
            if not budget.allow(v, g):  continue
            if not c_ras_wm.certify_info(g): continue
            score = effective_voi(v, g, T) - cost(g)   # 祖先未定则折价
            if best is None or score > best.score: best = (v, g, score)
    return best if best and best.score > 0 else None

# IP-269 PNA：按节点抽象层叙述，暴露不确定点
def narrate(v, T, mode):
    sentence = render(v, T, level=h(v), commit=T.node(v).c,
                      chosen=mode)               # "我准备拿蓝色杯子(不是白色)"
    return SpeechAct(sentence, guard=c_ras_wm.certify_info)

# IP-270 HRP：只重解失败子树，硬约束自上而下继承
def hierarchical_replan(T, v_failed, obs):
    keep = T.ancestors(v_failed) | T.siblings(v_failed)
    sub  = redecompose(T.subtree(v_failed), obs)
    sub.inherit_constraints(T.hard_set)          # 不可删除硬约束
    return graft(T, v_failed, sub)              # beta-归约式替换

# IP-276 主闭环（继承 R69，只在「不确定性处置」处替换为分层版）
def STRATA_round(M, ell, obs):
    if M.need_reground(ell, obs):
        M.T = ground_instruction(ell, M.parser, M.tagger)   # 缓存，不在实时环内
    z, o = M.mtm.forward(obs)                     # R69/R68 一次前向
    c, U_cal, thr = M.cof.step(...)
    # 1) 分层不确定性（ICF 条件采样；深度由 HIB 自适应）
    U_epi, U_ale = M.lud.levelwise_uncertainty(M.T, o, z)
    # 2) 只在正确层做交互：前沿 + 自顶向下 + 叙述优先
    pick = M.lvoi.choose_clarification(M.T, U_epi, M.budget)
    if pick is not None:
        v, g, _ = pick
        y = M.pna.execute(g)                      # 看/触/问/叙述，带认证
        M.bayes.update_node(M.T, v, y)            # 层级贝叶斯更新 + 向下传播
        U_epi = M.lud.recompute(M.T)
    # 3) 未消解的任何 hard 歧义 -> 全保守（R68 边界），安全不打折
    hard_open = any(U_epi[v] > TAU_EPI and M.T.node(v).c == 'hard'
                    for v in M.T.nodes)
    U_floor = U_ale_total(U_ale) + (U_epi_total(U_epi)
                                    if (pick is None or hard_open) else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    # 4) 分层执行 + 局部重规划，硬约束始终在包络内
    A = M.hrp.compile_leaf_plan(M.T, lam)         # 叶子交给 R69/R68 控制器
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if M.hrp.subtree_failed(M.T):
        M.T = M.hrp.hierarchical_replan(M.T, M.hrp.failed_node(M.T), o)
        A = M.hrp.compile_leaf_plan(M.T, lam)     # 局部替代，不改兄弟/祖先
    if M.fma.flow_anomaly(...) > TAU_FMA and M.last_r_res < TAU_RES:
        lam = max(lam, 0.8)                       # R69 缓变故障第二意见保留
    tau = M.pi_sigma.prefix_dispatch(A[:k]) * lam
    M.vqa_l.submit_async(ell, M.T, pick, U_epi, lam)   # 接地审计
    return k, lam, A, U_epi
```

## 3. 推导

**引理 19（精确信息分解，含 R69 为特例）** 对任意条件 o 与指令含义 M，H(ξ|o) = H(ξ|M,o) + I(M;ξ|o)。取 U_ale = H(ξ|M,o)、U_epi = I(M;ξ|o) 即得定义 312 的无损二分。若 M 退化为单节点且 p(M|o) 在采样簇上近似为均匀混合，则 H(ξ|M,o) ≈ Σ_k ŵ_k tr Σ_k、I(M;ξ|o) ≈ H_mode（在 A99：簇内高斯、簇可分下成立）。**故 R69 的「模态内方差 / 模态熵」是精确分解在簇级近似下的估计量，而非另一个独立假设。** 系：当指令接地使 M 可定案时，R69 中表现为「动作多模态」的那部分 U_epi 会**迁移**成 U_ale 之外的、可被消除的项——这正是「问对层」能降低有效不确定性的理论来源。

**引理 20（祖先支配与自顶向下最优）** 设 u 为 v 的祖先、M_u 未解析。对任意 g_v，VoI_eff(g_v) = E_{M_u}[VoI(g_v|M_u)] ≤ VoI(g_v)，且等号仅在 M_u 退化为点质量时成立。若在前沿 Φ 之外（祖先未解析）先问 v，其净收益被 P(M_u 未解析) 折价；由交换论证，在预算 c_max 下按「先祖先、后后代」的次序取前沿节点，取得的期望信息增益不低于任意逆序方案。系：**先问「哪只杯子」，再问「用左手还是右手」；反过来是浪费。**

**引理 21（承诺保守性 → 安全不因误读而下降）** 设真实承诺为 c*，CCG 输出 ĉ；在否定/作用域/低置信时强制 ĉ=hard。则系统实际执行的可行域 F(ĉ) 满足：当 c*=hard 时 F(ĉ)=F(c*)（不会放松）；当 c*=soft 而 ĉ=hard 时 F(ĉ) ⊆ F(c*)（过保守，仅损失效率）。因此**把软约束误判为硬约束不产生安全性违规，只会多绕路**。系：定义 315 的默认方向把语言误读的代价从「安全事故」转移到「效率损失」。

**引理 22（接地误差的安全/效率解耦）** 记安全关键节点的接地误差概率上界为 ε_safe、效率节点为 ε_eff。在定义 315 的保守默认与定义 318 的未定案按 hard 计入下，计划安全性违规概率 ≤ ε_safe，而任务失败/时长损失 ≤ ε_eff + O(过保守代价)。即：接地错误**集中在效率侧**，安全侧由「未定 → hard」吸收。证明骨架：任何进入 H(𝒯) 的错误必须使某安全关键节点的 ĉ 由 hard 变 soft；CCG 在不确定时强制 hard，故仅当 CCG 以高置信**错误地**判 soft 才可能越界，概率 ≤ ε_safe。

**定理 18（STRATA 严格包含 R68/R69 且安全单调）** 在 A95–A99 下，STRATA 的任意状态期望风险 ≤ R69 ≤ R68；且当「深度 1 ∧ 前沿为空（VoI≤成本）」时 STRATA ≡ R69，当进一步「不交互 ∧ 缓变故障判据触发」时 STRATA ≡ R68，均逐指令相同（定义 324）。安全侧：硬约束包络 H(𝒯) 在交互、叙述、重规划中均为不变式，故 F 不扩大；效率侧获得「层内 clarify + resolution bonus」。**新层是旧层的严格泛化而非并列替代。**

**定理 19（局部重规划可靠性与无突变）** HRP 只替换失败子树且继承 H(𝒯)，故重规划后的计划仍满足全部硬约束；控制量在 graft 边界按 R68 提交/换装不变式（定理 15）连续性保持 ⇒ 无突变。重规划复杂度由 O(全任务) 降为 O(子树)，且不会删除不可回溯的承诺。系：与 R69 的缓变故障第二意见叠加时，仍走「λ 单调不降 → R68 保守」的退化路径。

def ground_instruction(ell, parser, tagger):
    P = parser.parse(ell)
    T = igf_map(P)                                   # 保结构：产生式 -> 分解边/标签
    for v in T.nodes:
        v.tau, v.span     = sem_role(v, P)
        v.c, v.c_conf     = tagger.commitment(v)     # hard / soft / open + 置信
        if is_ambiguous(v.span) and v.tau == 'constraint': v.c = 'hard'

    return T

# IP-267 LUD：精确信息分解（ICF 条件采样，R69 聚类式为深度 1 特例）
def levelwise_uncertainty(T, z_obs, z_ell):
    for v in T.nodes:
        xi = flow.sample(z=(z_obs, z_ell, node_embed(v, z_ell)), K=branch_K(v))

# IP-270 HRP：只重解失败子树，硬约束继承
def hierarchical_replan(T, v_failed, obs):
    sub = redecompose(T.subtree(v_failed), obs)
    sub.inherit_constraints(T.hard_set)              # 硬约束不可删
    return graft(T, v_failed, sub)                   # beta-归约式替换

# IP-276 主闭环（继承 R69，仅替换不确定性处置为分层版）
def STRATA_round(M, ell, obs):
    if M.need_reground(ell, obs):
        M.T = ground_instruction(ell, M.parser, M.tagger)      # 缓存
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)
    U_epi, U_ale = M.lud.levelwise_uncertainty(M.T, z, z_ell)  # 1) 精确二分
    pick = M.lvoi.choose_clarification(M.T, U_epi, M.budget)   # 2) 前沿澄清
    if pick is not None:
        v, g, _ = pick
        M.bayes.update_node(M.T, v, M.pna.execute(g))          # 层级贝叶斯
        U_epi = M.lud.recompute(M.T)
    hard_open = any(U_epi[v] > TAU_EPI and M.T.node(v).c == 'hard'
                    for v in M.T.nodes)
    U_floor = U_ale_total(U_ale) + (U_epi_total(U_epi)
                                    if (pick is None or hard_open) else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))        # 3) 两级退避
    A = M.hrp.compile_leaf_plan(M.T, lam)                       # 4) 分层执行
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if M.hrp.subtree_failed(M.T):                               # 局部重规划
        M.T = M.hrp.hierarchical_replan(M.T, M.hrp.failed_node(M.T), o)
        A = M.hrp.compile_leaf_plan(M.T, lam)
    if M.fma.flow_anomaly(...) > TAU_FMA and M.last_r_res < TAU_RES:
        lam = max(lam, 0.8)                                     # 继承 R69 第二意见
    tau = M.pi_sigma.prefix_dispatch(A[:k]) * lam
    M.vqa_l.submit_async(ell, M.T, pick, U_epi, lam)            # 5) 接地审计
    return k, lam, A, U_epi
```

## 4. 推导

**引理 19（精确信息分解）** `H(ξ|o) = H(ξ|M,o) + I(M;ξ|o)`。取 `U_ale=H(ξ|M,o)`、`U_epi=I(M;ξ|o)` 得无损二分。若 `M` 退化为单节点、簇内高斯且可分（A99），则 `H(ξ|M,o)≈Σŵ_k trΣ_k`、`I(M;ξ|o)≈H_mode`——**R69 的聚类式二分是精确分解在深度 1 的估计量，不是独立假设**。

**引理 20（祖先支配）** 祖先 `u` 未解析时 `VoI_eff(g_v)=E_{M_u}[VoI(g_v|M_u)]≤VoI(g_v)`，等号仅在 `M_u` 为点质量时成立；由交换论证，预算受限下按「先祖先后后代」取前沿节点不劣于任意逆序。系：先问「哪只杯子」，再问「左手还是右手」；反之是浪费。

**引理 21（承诺保守性）** CCG 在否定/作用域/低置信时强制 `hard`，则执行可行域 `F(ĉ)` 满足：`c*=hard ⇒ F(ĉ)=F(c*)`；`c*=soft, ĉ=hard ⇒ F(ĉ)⊆F(c*)`。故软误判硬只损失效率，硬误判软才危险——默认方向必须是 hard。

**引理 22（接地误差安全/效率解耦）** 安全关键节点接地误差 `≤ ε_safe`、效率节点 `≤ ε_eff`；在保守默认与「未定按 hard」下，安全违规概率 `≤ ε_safe`，任务损失 `≤ ε_eff + O(过保守代价)`。证明骨架：越界必须使某安全关键节点由 hard 变 soft，而 CCG 不确定时强制 hard，故仅高置信误判可越界。

**定理 18（严格包含且安全单调）** A95–A99 下 STRATA 期望风险 ≤ R69 ≤ R68；`深度1 ∧ 前沿空` 时 ≡ R69，再叠加 `不交互 ∧ 缓变故障判据` 时 ≡ R68（逐指令相同，定义 324）。硬约束包络在交互/叙述/重规划中为不变式 ⇒ 可行域不扩大。

**定理 19（局部重规划可靠性）** HRP 只替换失败子树且继承 `H(𝒯)`，故全局硬约束保持；graft 边界按 R68 提交/换装不变式连续 ⇒ 无突变；重规划复杂度 O(子树)。

## 7. 本轮最大风险

**一句话**：STRATA 的全部收益押在「自然语言指令能被**正确分层接地**」这一前提上——**若上层把指代、约束强度或否定作用域理解错，错误会沿层级向下放大，而每一层都还能出具「局部安全」的证书，最终把一次误解洗成一份「已验证」的计划；理解错，比不执行更危险。**

**次级风险与缓解**：
1. **IGF 臆造/静默补齐** → 未定即标 `open` + C_IGF 门 + VQAuditor-L（E301/E314）；
2. **否定/作用域陷阱** → 保守默认 hard + 引理 21/22 + E304/E309；
3. **错层追问浪费** → 前沿 + 自顶向下 + 引理 20 + E302/E303；
4. **深度爆炸/重规划死循环** → 自适应深度 + HRP 深度上限 + ℰ_replan（E306/E311）；
5. **接地幻觉被证书合法化（最危险）** → 安全关键节点双源核实 + hard 未定案一律回 R68 保守 + PNA 人工可见（E304/E314/E315）。
