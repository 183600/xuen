# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「智能体」×「场景落地」）

> R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」。四轮下来，闭环越来越会**处理不确定性**，却始终默认一件事：**它有资格在这里行动**。R69 的 FLUID-RAS 是一个「会提问的策略」，不是「有授权的智能体」；它的证书 J_FLUID 是**逐窗口**的，而现场要的是**逐任务、逐车队、可撤销**的部署保证。
>
> 本轮两个灵感正好戳中这个盲区：
> - **智能体**：策略只是「手」；智能体 = 记忆 + 技能组合 + **授权（mandate）** + 跨任务持续性。智能体的失效主因往往不是「我不确定」，而是「我做了不该我做的事」——越权、目标蠕变、责任扩散。
> - **场景落地**：落地不是「跑起来」，而是一份**可撤销的合同**：ODD、授权、证据义务、回退目标、到期与续签。实验室里环境是围栏，现场里环境是**运营设计域**。
>
> 核心命题：**把「不确定性治理」升级为「授权治理」。R66–R69 都在优化内环（毫秒级「怎么做」），R70 补上外环（小时级「准做、做多久、谁签字」）。引入「智能体部署合同 ADC」+「分权编队 ROSTER」+「快降慢升的部署阶梯」；内环严格复用 R69，外环只能收缩授权、绝不能在线扩张。** 命名 **MANDATE-RAS**（Mandate-bounded Agentic Deployment with Non-self-certification And Two-timescale Evidence）。
>
> 一句话定位：R69 让系统学会「问」，R70 让系统学会「**被授权才做、越界就退、退出要能签收**」——不确定性是刹车，授权是驾照。

## 0. 直觉与动机

**灵感 1（智能体 ≠ 策略：多了一层「授权」）**
直觉：把 R69 的 FLUID-RAS 放进真实场景，最先出事的通常不是它「算不准」，而是它「做超了」：把副驾模式当自主开、把试验场的 ODD 带到公开道路、把一次人类口头许可当成永久授权。策略关注「在给定状态下哪个动作最优」；智能体还要回答「**在这个场景、这个等级、这段时间里，我到底被允许做什么**」。后者不是不确定性的子问题——一个百分之百自信的动作也可能百分之百越权。R69 的不确定性二分 (U_ale, U_epi) 再精细，也覆盖不了「合法性」这一维。

**灵感 2（场景落地 = 可撤销合同）**
直觉：实验室用围栏定义安全，现场用**运营设计域（ODD）+ 授权 + 证据义务 + 回退目标 + 有效期**定义安全。R69 的 J_FLUID 是「这一窗我很好」，现场要的是「这一趟、这一队、这一版模型，能不能上路，出了事谁负责，什么时候必须停」。逐窗口证书不会自动合成逐任务保证——**证书不组合，部署就是赌博**。这就是「落地」与「演示」的分水岭。

**灵感 3（自我认证是原罪 → 分权）**
直觉：R69 已经埋了雷：MCG 用同一个模型判断自己的模态可信不可信，再用这个判断去驱动交互。到了智能体，这个雷会长大——actor 自己评估自己的目标是否漂移、自己签发自己的越权豁免、自己决定晋升。**任何「我检查过我自己」的证书都不值钱**。严谨做法是分权：产生动作的、评估动作的、签发许可的、事后审计的，必须是架构上独立的实体；在依赖图上，签发者不能是被签发者的祖先。

**灵感 4（落地失效的主因是授权漂移，不是不确定性）**
直觉：现场失效有四类——U（不确定，R69 管）、M（越权 / 授权漂移）、O（跑出 ODD）、S（组织 / 社会：责任扩散、过度依赖、监督疲劳）。R66–R69 把火力全压在 U 上，但真正让「落地」失败的往往是 M/O/S。于是需要一个监测**授权**而不是监测**测量**的层：越权度、ODD 边界裕度、目标偏离、监督负担。这也是对「不确定性 vs 合法性不是同一件事」的形式化承认。

**灵感 5（长寿命智能体的记忆是新的攻击面）**
直觉：R69 的交互投毒是单发的；长寿智能体会把交互写进记忆，再用记忆校准自己、再据校准后的自己签发证书。**自我生成的污染数据一旦进入自我认证回路，就完成了「自我洗白」**。所以记忆必须带来源与污点，且 agent 不得在自己生成的未验证数据上训练 / 校准 / 自我认证。这与 R69 的「单次交互不得定案」同构，但作用在更慢的时间尺度上。

**灵感 6（部署是一个快降慢升的控制问题）**
直觉：晋升自主等级是承诺，降级是保命。控制上应当非对称：**降级即时、晋升缓慢且需持续证据**（像断路器）。把部署当成外环控制问题，安全势函数 Ψ（未消解 epistemic、越权次数、证书失败率、目标漂移）单调不增才允许晋升；任何异常立即降级。这样「落地」从一次发布变成一条**状态机轨迹**，而可撤销性本身成为设计对象。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（MANDATE-RAS 总览）** MANDATE-RAS = (ADC, ROSTER, SPG, DGL, MLM, TEG, RAS-WM‡)。四不变量：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **权限单调不增**：运行时可执行能力集只能收缩；任何扩张必须离线、双签、带版本；
(iii) **无自我授权**：Actor 与其 Certifier 在依赖图上无祖先关系，证书绑定 (weights_hash, data_manifest, runtime_cfg)；
(iv) **证书可组合**：mission 级有效 ⇔ 全部 window 有效 ∧ 未消解预算不超 q ∧ 无越权 ∧ 回退可达。

**定义 311（智能体部署合同 ADC）** ADC = (ODD, A_hold, D_duty, E_evid, R_rollback, T_expiry, σ)。ODD 为可判定谓词族；A_hold ⊆ 𝒜_cap 为被授权能力集；D_duty 为义务（让行、报告、最小干预…）；E_evid 为证据义务（证书种类、频率、留存期）；R_rollback 为安全回退目标；T_expiry 为授权有效期；σ 为签署链。ADC 是**运行时可检查**的，不是一份 PDF。

**定义 312（授权格与越权度）** 能力偏序格 (𝒜_cap, ⊑, ∧, ∨)。任务所需授权 A_req(τ) 由 Planner 从任务规格导出；持有授权 A_hold(τ) 由 ADC 与当前 DGL 等级交叠得到。越权度 V_auth(τ) = 1[A_req(τ) \ A_hold(τ) ≠ ∅]；部分越权按格的秩差定义严重度。在线算子 Contract(c) 单调收缩；Expand 仅离线且需双签。

**定义 313（ODD 与边界裕度）** ODD = {x : odd_i(x) ≥ 0, ∀i}；边界裕度 m_odd(x) = min_i odd_i(x)。m_odd < δ_odd ⇒ 边界态：行为退化为 R69 最保守分支，且禁止进入 L≥2 自主等级。

**定义 314（分权编队 ROSTER）** 角色：Planner P（低频，可含 LLM）、Actor A（毫秒级策略，复用 R69）、Critic C（独立权重 / 数据）、Governor G（授权与安全门）、Auditor U（只读、离线）。通信只走结构化契约消息；**P 不得向 A 下发实时动作，只能下发目标与约束**（防实时注入与越权夹带）。

**定义 315（分权治理与无自我授权 SPG）** 证书签发者集合 S，被签发对象集合 O，依赖图 G_dep。No-self-grant：∀s ∈ S, o ∈ O，s 不是 o 的祖先。独立性证明 π_indep = (weights≠, data_manifest≠, runtime_pid≠)。违例 ⇒ 证书作废，部署等级强制降一级。

**定义 316（部署阶梯 DGL）** 等级 𝓛 = {L0 影子, L1 副驾, L2 监督自主, L3 有界自主, L4 编队}。每级 L 定义 (max_authority, min_supervision_ratio, required_evidence, exit_criteria)。晋升：连续 N 个 mission 证书全绿 ∧ 未消解 epistemic 预算 = 0 ∧ 对抗审计通过 ∧ Ψ 单调不增。降级：任一触发即生效（≤ 1 外环周期）。

**定义 317（任务级证书组合 MLM）** 给定 mission 的窗口证书序列 {J_FLUID^(i)}、未消解预算序列 {u_i}、事件向量 e、ODD 覆盖率 cov、监督审计 a：
J_mission = (⊕_i J_FLUID^(i), Σ_i 1[u_i>0], e, cov, a, dep_hash)。
J_mission Valid ⇔ ∀i J_FLUID^(i) Valid ∧ Σ_i 1[u_i>0] ≤ q ∧ V_auth = 0 ∧ ∀i e_i ∉ 𝓔_crit。这是把「窗口可信」提升为「任务可信」的**唯一合法合成器**。

**定义 318（两时间尺度证据治理 TEG）** 内环周期 τ_ms 执行 R69；外环 τ_h 执行晋升 / 降级 / 撤销。非对称律：降级延迟 ≤ τ_h，晋升需 N·τ_h 持续证据。安全势函数 Ψ_t = (Σ 未消解 U_epi, V_auth 计数, 证书失败率, 目标漂移 d_goal)。仅当 Ψ 单调不增且低于阈值才允许晋升。

**定义 319（记忆来源与隔离 MQ）** 记忆条目 m = (content, provenance, taint, verifier, t)。taint=1 当且仅当内容由 agent 自身生成且未经独立验证。禁止：taint=1 数据参与训练 / 校准 / 自我认证；推理时只能作为「待验证假设」。隔离区 Q 中的条目需 k 个正交源验证才转正。

**定义 320（目标漂移监测 GDM）** 宪章目标 g_charter 由 ADC 固定；运行时目标 g_t 由 P 产生。漂移 d_goal = d(g_t, g_charter)（语义 + 约束投影）。d_goal > δ_goal ⇒ 收缩授权、升监督等级、冻结 P 的在线改写。由独立 Critic 计算，Actor 无权自评。

**定义 321（场景落地失效分类学 FIT）** 现场失效四类：U（不确定性，R69 覆盖）、M（Mandate：越权 / 授权漂移 / 自我授权）、O（ODD 外 / 边界）、S（社会 / 组织：责任扩散、过度依赖、监督疲劳）。R70 的新增治理对象是 M/O/S，U 仍交 R69。每条现场事件必须归入且仅归入一类，归不进去即视为标本缺口。

**定义 322（部署证据链 DEP）** 每 mission 追加不可篡改记录：观测摘要、授权快照 A_hold/A_req、证书链、交互与人类介入、回退事件、监督日志、版本三元组。链按 hash 串接，DEP_hash 进入 J_mission；缺链 ⇒ 不可晋升、不可用于事后定责。

**定义 323（安全回退）** 回退目标 r ∈ ODD ∧ authority(r) ⊆ A_safe；回退轨迹过 C-RAS-WM 认证；回退决策**不得依赖 taint=1 记忆**（防污染记忆劫持回退）。回退成功是下一轮晋升的前置条件。

**定义 324（人因与监督负担 HCL）** 监督比率 ρ_sup = 人类介入时间 / 任务时间；告警熵 / 精确率刻画认知负荷。落地可行 ⇐ ρ_sup ≤ ρ_max ∧ 告警精确率 ≥ p_min ∧ 监督者响应时间 ≤ R_max。**这是运营约束，不是模型指标**。

**定义 325（授权提升与组织攻击集 AAEs）** ℰ_mandate：提示注入诱导越权、伪造证书、Critic 共谋、记忆投毒、监督者社会工程、ODD 谓词投毒。并入 AIC：ℰ_AGORA = ℰ_FLUID × ℰ_mandate × ℰ_memory × ℰ_org。

**定义 326（证书 J_MANDATE）** J_MANDATE = (J_mission, signature_chain, ADC_hash, DGL_level, Ψ_trace, DEP_hash, π_indep, version_triple)。Valid ⇔ J_mission Valid ∧ 无自我授权 ∧ 未过期 ∧ 回退可达 ∧ π_indep 通过。**J_MANDATE 不是「模型很好」的证明，是「这次部署被允许且可追责」的证明**。

**定义 327（R69 退化边界）** 当 ADC 授予全部能力、ODD = 全空间、taint 全为 0、d_goal ≡ 0、DGL 固定于 L0/L1、且 mission 仅含单窗口时，MANDATE-RAS 与 FLUID-RAS **逐指令相同**。新增层只允许收缩授权与收紧门槛，任何放松都必须走离线签署。

## 2. 关键算法骨架

```python
# IP-264 ADC 编译器：把场景/法规文本编译成可执行合同
def compile_adc(spec_text, capability_lattice, law_refs):
    odd      = compile_predicates(spec_text.odd, law_refs)     # 可判定谓词
    a_hold   = capability_lattice.meet(spec_text.allowed)      # 授权下界
    duty     = extract_obligations(spec_text + law_refs)
    evid     = evidence_schedule(duty)                          # 证书种类/频率
    rollback = safe_target_selector(spec_text.fail_safe)
    return ADC(odd, a_hold, duty, evid, rollback, expiry=spec_text.ttl)

# IP-265/272 外环监测：ODD 边界 + 目标漂移（独立于 Actor）
def outer_monitor(obs, adc, p_goal, critic):
    m_odd  = min(p(obs) for p in adc.odd)                      # 边界裕度
    d_goal = critic.goal_distance(p_goal, adc.charter_goal)    # 独立 Critic
    return m_odd, d_goal

# IP-267 无自我授权：依赖图上检查签发者独立性
def certify(obj, signer, dep_graph):
    if dep_graph.is_ancestor(signer, obj):                     # 自我授权
        return VOID
    pi = (signer.weights_hash != obj.weights_hash,
          signer.data_manifest != obj.data_manifest,
          signer.runtime_pid != obj.runtime_pid)
    return CERT(signature=signer.sign(obj), indep=pi) if all(pi) else VOID

# IP-269 任务级证书组合（窗口 -> 任务）
def compose_mission(window_certs, unresolved, events, coverage, audit):
    ok  = all(c.valid for c in window_certs)
    ok &= sum(1 for u in unresolved if u > 0) <= Q_MAX
    ok &= not any(e in E_CRIT for e in events)
    return JMission(valid=ok, dep_hash=ledger.head(), coverage=coverage,
                    supervision=audit)

# IP-268/270 部署阶梯：快降慢升（外环，异步）
def deployment_step(state, j_mission, psi, m_odd):
    if (not j_mission.valid) or psi.increased() or m_odd < DELTA_ODD:
        return demote(state, reason=first_violation())          # 立即
    if state.level >= L3: return state
    if (state.consecutive_green >= N_PROMOTE and psi.flat_below(TAU_PSI)
            and adversarial_audit_pass(state) and rollback_reachable(state)):
        return promote(state)                                   # 缓慢且需持续证据
    return state

# IP-277 主环路：内环严格复用 R69，外环只收缩
def MANDATE_round(M, obs, adc, mission):
    # 0) 输入合法性：越权任务直接拒绝（不进入内环）
    a_req = mission.required_authority()
    if not a_req <= adc.a_hold: return REFUSE(reason="out_of_mandate")
    # 1) 内环 = R69 FLUID-RAS（毫秒级，原样）
    k, lam, mode, (u_ale, u_epi) = M.fluid.fluid_ras_round(obs)
    # 2) 外环监测（异步/低频，绝不下发实时动作）
    m_odd, d_goal = M.outer_monitor(obs, adc, mission.goal, M.critic)
    v_auth = 1 if mission.drifted_authority() else 0
    if m_odd < DELTA_ODD or d_goal > DELTA_GOAL or v_auth:
        k, lam, mode = M.rollback.contract(k, lam, mode, adc)   # 只收缩
    # 3) 记忆准入：taint 数据不得进入认证回路
    M.mq.ingest(obs, mode, taint=mission.self_generated)
    # 4) 窗口证书 -> 任务证书 -> 部署阶梯
    jw = M.cert.window_cert(k, lam, mode, u_epi, M.last_r_res)
    jm = M.mlm.compose(mission.windows + [jw], mission.unresolved,
                       mission.events, mission.odd_cov, mission.supervision)
    M.dgl.step(jm, M.psi, m_odd)
    # 5) 证据链 + 独立审计
    M.dep.append(obs, adc.snapshot(), jw, M.interaction_log, M.rollback_log)
    M.auditor.submit_async(jm, dep_hash=M.dep.head())
    return k, lam, mode, jm
```

## 3. 推导

**引理 19（越权风险的不可约性）** 设动作 a 在状态 s 下任务最优且策略自信；若 a 超出 A_hold，则无论 U_ale/U_epi 多小，其部署风险下界 ≥ c_out > 0，且不随内环任何不确定性缩放而下降。系：**不确定性治理无法覆盖授权治理**——R69 再完美也救不了一次越权；M/O 类风险必须在授权层拦截。

**引理 20（窗口证书的可组合性）** 若 J_FLUID 各窗口的定义域互不重叠且首尾以相同版本三元组衔接，则窗口证书可合成 mission 证书，其错误率 ≤ Σ_i ε_i + q·ε_u；反之，若版本三元组在 mission 中变更（热更新 / 换装），合成失效，必须重新起一次 mission。系：**版本漂移是证书组合的断点**——这解释了现场「昨天还好好的」。

**引理 21（快降慢升的越权窗口上界）** 若降级在一个外环周期内生效，则任何授权漂移导致的越权执行时间 ≤ τ_h + τ_ms；晋升的滞后不增加越权风险（晋升只会扩大授权，且只在 Ψ 单调不增时发生）。故非对称律使「越权暴露时间」与「晋升激励」解耦。

**引理 22（非自我认证的欺骗上界）** 设 self-cert 的错误率 δ_self、独立 Critic 的错误率 δ_c，且二者错误相关 ρ<1；采用无自我授权 + 独立证书后，同源偏差同时污染 Actor/Critic/Governor/Auditor 的联合概率按独立性下降；更关键的是**共谋检测面**从「1 个模型」扩大到「依赖图」，单一提示注入无法同时攻破四个角色。

**定理 18（MANDATE 严格包含 R69）** 在定义 327 的退化条件下，MANDATE 与 FLUID-RAS 逐指令相同；在非退化条件下，MANDATE 的执行动作集 ⊆ FLUID-RAS 动作集（授权只收缩）。因此部署安全侧不弱于 R69，且新增的是「越权 / ODD / 责任」三维保证。

**定理 19（部署合同的单调安全与可撤销性）** 若 Ψ 单调不增是晋升的必要条件、降级即时、且回退目标恒在 ODD 内，则 DGL 等级在 ODD 内对应的期望风险随等级非增；撤销一个合同（T_expiry 到期或 SPG 违例）至多损失一个外环周期的自主性，不损失安全不变式（R69 内环仍在）。

**定理 20（污染记忆的不可自我洗白）** 若认证路径禁止 taint=1 数据，且 taint 只能经 k 个正交源验证清零，则 agent 自身生成的污染在进入认证回路前至少需要 k 个独立源共同被骗；单源投毒对自主等级无影响。

## 6. 本轮最大风险

**一句话**：MANDATE-RAS 把安全押在「治理层独立且诚实」上——**若 ODD 由运营方自己写宽、Critic 与被认证者共享数据或目标、晋升指标又恰好可被优化，那么这套分权与证书只会产出「证书剧场」（certification theater）：它把「未经证实的自主」包装成「已合规的自主」，而且治理层越完备，越擅长测量自己想测量的东西、越难被外部质疑**。真正的落地风险不是 agent 不会问，而是**签名的人和被签名的系统，其实是同一伙人**。

**次级风险与缓解**：
1. **分权导致责任扩散**（「都说不是自己签的」）→ DEP 证据链 + 法定签署人 + 不可抵赖签名；
2. **外环滞后 / 误升** → 快降慢升 + Ψ 单调不增硬门 + 误降级成本可承受；
3. **ODD 谓词投毒 / 写宽** → ODD 版本化 + 外部法规映射 + E301 人工复核；
4. **治理开销拖垮运营** → 外环异步、窗口聚合、E315 预算；
5. **R69 内环被过度收缩**（每次都降级、系统变废）→ resolution bonus 与升级证据联动，防止「安全但无用」。

## 4. 推导

**引理 19（越权风险的不可约性）** 若任务最优动作 a 超出 A_hold，则无论 U_ale/U_epi 多小，部署风险下界 ≥ c_out>0，且不随内环不确定性缩放下降。系：**不确定性治理无法覆盖授权治理**，M/O 类风险必须在授权层拦截。

**引理 20（窗口证书可组合性）** 定义域不重叠且版本三元组首尾一致的窗口证书可合成 mission 证书，错误率 ≤ `Σ_i ε_i + q·ε_u`；版本三元组中途变更则合成失效，必须重起 mission。系：**版本漂移是证书组合的断点**。

**引理 21（快降慢升上界）** 降级在一个外环周期内生效 ⇒ 越权执行时间 ≤ `τ_h + τ_ms`；晋升滞后不增加越权风险。非对称律使越权暴露时间与晋升激励解耦。

**引理 22（非自我认证的欺骗上界）** self-cert 与独立 Critic 错误相关 ρ<1 时，同源偏差同时污染 Actor/Critic/Governor/Auditor 的联合概率按独立性下降；共谋检测面从「1 个模型」扩大到「依赖图」。

**定理 18（MANDATE 严格包含 R69）** 定义 327 退化条件下逐指令相同；非退化时执行动作集 ⊆ FLUID-RAS 动作集（授权只收缩）。部署安全侧不弱于 R69，新增「越权/ODD/责任」三维保证。

**定理 19（部署合同单调安全与可撤销）** Ψ 单调不增是晋升必要条件、降级即时、回退目标恒在 ODD 内 ⇒ DGL 等级的期望风险随等级非增；撤销至多损失一个外环周期的自主性，不损失 R69 安全不变式。

## 7. 本轮最大风险

**一句话**：MANDATE-RAS 把安全押在「治理层独立且诚实」上——**若 ODD 由运营方自己写宽、Critic 与被认证者共享数据或目标、晋升指标又恰好可被优化，那么这套分权与证书只会产出「证书剧场」（certification theater）：它把「未经证实的自主」包装成「已合规的自主」，而且治理层越完备，越擅长测量自己想测量的东西、越难被外部质疑**。真正的落地风险不是 agent 不会问，而是**签名的人和被签名的系统，其实是同一伙人**。

**次级风险与缓解**：责任扩散（DEP 证据链 + 法定签署人 + 不可抵赖签名）；外环滞后/误升（快降慢升 + Ψ 硬门 + 可承受的误降级成本）；ODD 谓词投毒/写宽（ODD 版本化 + 外部法规映射 + E301 人工复核）；治理开销拖垮运营（外环异步、窗口聚合、E315）；内环被过度收缩成「安全但无用」（resolution bonus 与升级证据联动）。
