# 第 2 轮（灵感循环第 2 轮；本轮灵感：「差异化定位」×「原型验证」）

> **基线继承**：上一循环的 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440），
> 其本身又继承 **LeanGauge** → **MODGAUGE**。本轮纪律：**在 ToolGauge 之上改进，而不是推倒重来**。
> ToolGauge 解决了「探测动作无接口」「先验不可审计」「逐盲区从零校准」三个结构性问题，
> 却把最大风险留在了结构里：**单一全局摊销先验 + 一次性热替换**
> ⇒ 在「预训练分布 → 部署分布」偏移下产生**跨盲区强相关**的系统性偏差，
> 一次坏先验同时污染所有被热替换的子图，且 VLA 语言修复证书会放大其可信度外观。
> 本轮沿两条新灵感各切一刀：
> **差异化定位**把「一个全局先验」拆成「有位置、可区分、会弃权」的专家组合，并引入**差分锚定**；
> **原型验证**把「直接热替换」改为「先代理、再灰度、后全量」的**分级提升**。

## 双灵感映射（互补，而非并列）

| 灵感词 | ToolGauge 中的对象 | 升级为 | 一句话动机 |
|---|---|---|---|
| 差异化定位（differentiated） | 单一 MP-Φ 声称「处处可用」 | **P-Box 差异化专家组合 + 定位登记表**：K 个专家各有显式能力区域、定位半径与弃权规则 | 没有位置的先验无法被审计；专家**差异本身**就是共模偏差的免费诊断信号 |
| 差异化定位（differential） | V 阶段只查一条独立回执 | **Diff-Box 差分锚定**：用参考盲区估计共模误差子空间并做差分校正 | 基线最大风险是「被所有盲区共享的偏差」；差分定位正是用参考站抵消共模的教科书解 |
| 原型验证 | U 阶段「V 通过即全量替换」 | **Proto-Box 原型门控 + 分级提升**（shadow → canary → full） | 替换前必须在廉价代理上预演，且代理差距要有界、门控要有统计功效、放量要可回滚 |

> **一个刻意的双关**：中文「差异化定位」在产业语境里指「与别人不一样的位置」，在测量学语境里指「差分定位」。
> 本轮两种读法都要用，而且它们**互补**：
> 差异化让各专家的错误朝不同方向（无需参考站即可诊断共模）；差分即使专家完全同质也能抵消共模（无需多样性）。
> 任一机制可独立工作；同时成立时互为交叉验证。这同时构成本轮的**研究定位**：
> 我们不主张「更强的先验」，而主张「**误差可分解、可定位、可预演的修复**」。

## 0. 直觉与动机

### 灵感 1：差异化定位——从「全能专家」到「有位置、会弃权的团队」

直觉：ToolGauge 的 MP-Φ 像一个声称「哪里都懂」的专家。它当然可以被训练得很好，
但一旦部署分布偏离预训练分布，它的错误不会随机散落，而会**沿同一个方向**出现在所有盲区上——
因为所有盲区共享同一个先验、同一条传感链、同一次域偏移。
这正是基线的「跨盲区强相关污染」。

差异化定位给出两层解药：

**(a) differentiated（差异化）**：把单一先验换成 K 个**有明确能力区域**的专家。
每个专家只在它的定位半径 r_k 内发言；所有专家都觉得「不熟」时，系统输出 UNKNOWN 并退回纯数值探测，
而不是硬答。**会弃权**是比「更准」更可审计的性质。
更进一步：若专家组合是**真差异**的（错误响应子空间不同），那么它们的**分歧**就是共模偏差的探测器——
共模会让所有专家沿相关方向一起偏，而局部特异误差只会让个别专家偏。

**(b) differential（差分）**：差分 GPS/RTK 的关键从来不是流动站更准，而是**参考站**。
参考站与流动站共享同一片电离层与钟差（共模误差 c），把两者相减，c 抵消，只剩各自的特异残差。
把这一思想搬到计量修复上：
- 维护少量**参考盲区** ℛ，其真值 u*_ℛ 由可移除基准件 / 高成本离线真值 / 签名标定获得；
- 参考盲区与目标盲区共享同一先验与传感链，故共享同一个共模系数 c；
- 用参考残差估计 ĉ，再对目标预测减去 B_s ĉ ⇒ **共享偏差被减去，局部偏差被保留**。

这不是「再加一个校准器」，而是把误差**分解**成「共享（危险）」与「特异（局部）」两部分，
并对共享部分做**可观测、可检验、可拒绝**的抵消。

### 灵感 2：原型验证——先预演，再上台

直觉：ToolGauge 的 U 阶段「V 通过就全量热替换」相当于演员不彩排直接上台。
「原型验证」的工程智慧有四条：

1. **代理可预演**：先在数字孪生 / 缩比原型 / 影子回放（shadow）上跑候选契约，代价远低于真实部署；
2. **代理必须被证明是代理**：预演结论迁移到真实部署存在**代理差距** Δ_s；没有 Δ_s 的界，彩排通过毫无意义，
   甚至比不彩排更危险（虚假安心）；
3. **分级放量**：shadow（只观察、零生效）→ canary（小比例、可一键回滚）→ full；每级都有**预注册**的通过/回滚判据；
4. **统计功效**：门控不是「看起来没问题」，而是「在效应量 δ、显著性 β、功效 1−β_p 下需要 m 个样本」——
   m 由功效分析给出，并在事后可复核。

一句话：原型验证把「替换」从一个**不可逆事件**变成一个**可预演、可度量、可回滚的过程**；
它恰好补上差分校正的最后一个缺口——**即使差分校正错了，也只会在 canary 的小爆炸半径内出错**。

### 核心命题

把 ToolGauge 的「单一全局先验 + 一次性替换」升级为
「**差异化专家定位 → 差分锚定校正 → 原型门控分级提升**」：

- 误差的**共享部分**（跨盲区相关、真正危险的部分）由参考站差分抵消；
- 误差的**局部部分**留给差异化专家组合与原型门控；
- 于是「局部修复、误差局部化」重新成立，且这次是**有界、可测、可回滚**的；
- 方法论上：**定位即假设，原型即检验**——每条差异化定位声明都必须绑定一个能证伪它的原型实验（定义 444）。

**不变式保持声明**：
- MODGAUGE 五不变式全部保留；
- 主张绑定不变式的语言扩展（定义 423）继续有效：VLA 仍只做「提假设 / 选工具 / 写主张」，数值真值由计量层独占；
- **严格退化链继续延长**：DiffGauge 失效（参考不可观 / 专家全弃权 / 原型差距失效 / 预算耗尽）⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE。
  差分与原型都是**增强项**，不是依赖项。

## 1. 形式化定义（增量：定义 432–446）

**定义 432（定位上下文与差异化专家组合）**
定位上下文 φ(s) ∈ ℝ^{d_φ} 是盲区 s 的**可审计数值特征**（材质类枚举、光照区间、传感模态、几何尺度；不含自由文本）。
差异化专家组合 ℰ = {E_k}_{k=1..K}，每个专家
E_k = (μ^pos_k, r_k, B_k, q_k)，其中 μ^pos_k 是定位原型、r_k 是经校准的定位半径、
B_k 是该专家误差对共模系数的响应矩阵、q_k(u_s)=𝒩(μ_k,Σ_k) 是契约参数后验。
定位权重 w_k(s)=softmax(−d_k(φ(s))/T)，d_k 为到 μ^pos_k 的马氏距离。

**定义 433（定位空白与弃权）**
若 min_k d_k(φ(s)) > r_k（r_k 取校准集上 1−α_pos 分位），则系统处于**定位空白**，
输出 H_s := {UNKNOWN} 并退回 LeanGauge 纯数值探测。禁止外推；定位空白比例作为运行期覆盖率告警量。

**定义 434（定位分离与差异化多样性）**
*分离*：任意两专家在预注册校准集上的错误分布经双样本检验可区分（拒绝「同分布」）；
不满足则合并专家，禁止用「数量」冒充「差异」。
*多样性*：D_div = min_{k≠l} ‖B_k − B_l‖_F / (√2·max(‖B_k‖_F,‖B_l‖_F))。
若 D_div < δ_div（默认 0.1），专家组合**不得宣称**具备共模诊断力，只保留差分校正路径（见引理 52）。

**定义 435（共模误差模型 C1）**
e(s) = f_θ(s) − u*(s) = B(φ(s))·c + ε(s)，
其中 c ∈ ℝ^r 是**部署期内共享**的共模系数，B 是响应矩阵（由历史残差 PCA 与物理先验联合估计），
ε(s) 是特异误差，满足：跨盲区 Cov(ε_i, ε_j) ≈ 0，‖ε‖ ≤ ε_max，E[ε]=0。

**定义 436（参考盲区与参考完整性）**
参考盲区集 ℛ = {ρ_1,…,ρ_nr}，真值 u*_ρ 由可移除基准件 / 高成本离线测量 / 签名标定获得。
每条参考回执带 (u*, σ_ref, sig, ts, 有效期)。参考需**轮换**并对自身漂移建模；
过期、签名失效或漂移超限的参考被降权或剔除（鲁棒加权，Huber 影响函数）。

**定义 437（差分可观测定量）**
B_ℛ 为参考处响应矩阵的堆叠。若 rank(B_ℛ) < r，则存在**不可观子空间**，差分只能抵消其可观测部分。
可观测定量 obs = σ_min(B_ℛ) / σ_max(B_s)。差分门要求
obs ≥ obs_min（默认 0.3）且参考数 nr ≥ r + 2；否则 corrected=False，绝不做「半盲」校正。

**定义 438（差分校正与差分门）**
共模估计 ĉ = B_ℛ⁺ y_ℛ（y_ℛ 为参考预测残差，B_ℛ⁺ 为伪逆）；
校正预测 f̃(s) = f_θ(s) − B_s ĉ。
**差分门（方差感知）**：仅当预估偏差能量 ‖B_s ĉ‖² 超过校正引入的方差
tr(B_s B_ℛ⁺ Σ_ℛ B_ℛ⁺ᵀ B_sᵀ) 加安全边际 κ_m 时施加校正；
否则 corrected=False（宁可不修，不可过度修）。这条门把「参考噪声大、共模小时越修越差」挡在外面。

**定义 439（差分残差检验 V_d）**
在**未参与 ĉ 估计**的留出参考或独立 cross.modal 回执上计算
z_diff = (y_hold − B_hold ĉ) / sqrt(σ²_hold + [B_hold B_ℛ⁺ Σ_ℛ B_ℛ⁺ᵀ B_holdᵀ])。
要求 |z_diff| ≤ ε_diff **且**残差方向与 ĉ 预测方向一致；否则判为共模模型失配，禁止进入 P 阶段。

**定义 440（原型代理与代理差距）**
原型 P_s（数字孪生 / 缩比件 / 影子回放）给出风险估计 R_proto。
**代理差距** Δ_s 是预注册量，满足 P(|R_dep − R_proto| ≤ Δ_s) ≥ 1 − γ（按原型类别由 E445 校准）。
若 Δ_s ≥ ε_tol（门控容差），则原型门**不可用于 full 提升**（门控空洞化），只能停留在 canary 或 stub。

**定义 441（原型验证门）**
给定容差 ε_tol、效应 δ = ε_tol − Δ_s、显著性水平 β、目标功效 1−β_p、风险标准差 σ：
最小样本 m ≥ 2σ²(z_{1−β} + z_{1−β_p})² / δ²。
接受条件（两者同时）：
(i) R̂_proto + Δ_s ≤ ε_tol；
(ii) 单侧检验在水平 β 下拒绝「R_proto > ε_tol − Δ_s」，样本量 n ≥ m。
推论：若 n < m，即使点估计好看也必须拒绝（功效不足 = 不可提升）。

**定义 442（分级提升协议）**
shadow（N_sh 次只读回放，零生效）→ canary（比例 p_c，子图可一键回滚）→ full。
每级有预注册通过判据与最大停留时间；canary 用 e-value / CUSUM 序贯检测，超阈立即回滚并计入失败账本。
爆炸半径定义为其间可能被影响的子图比例（≤ p_c）。

**定义 443（提升风险预算）**
单盲区提升的污染风险 ≤ γ + β + α_canary（代理差距事件 + 检验水平 + 序贯误报）。
全系统按盲区数做 Bonferroni / FDR 控制；预算不可满足 ⇒ 停留 canary 或 stub + RED。
提升风险预算独立于 TB-Contract（定义 424），记为 PR-Contract = (ε_tol, γ, β, α_canary, p_c, N_sh)。

**定义 444（定位-原型登记表）**
每条差异化定位声明 d 必须登记四元组
(claim, metric, falsifier, power)：
claim 是一句可检验的定位主张；metric 是主指标；falsifier 是一个**可执行原型实验**；
power 是该实验在预注册效应量下的功效。
未登记、未通过 falsifier、或功效不足的声明，不得进入 EC.claims 与论文主张。
这是「差异化定位」从修辞变成**可证伪假设**的机制。

**定义 445（差异诊断不一致性）**
D(s) = max_{k≠l} ‖μ_k − μ_l‖_{Σ_k+Σ_l}。
在特异误差校准模型下给出零分布尾界 τ_D(α)；
D > τ_D 触发共模告警（P-Quarantine 的新触发源）。
其检测功效由 ‖(B_k − B_l)c‖ 决定；若 D_div < δ_div 则关闭该诊断，并显式记录「诊断不可用」。

**定义 446（继承与严格退化映射）**
未重定义的记号沿用定义 416–431。
令 K=1、ℛ=∅、P_s=∅ ⇒ DiffGauge ≡ ToolGauge（严格退化，逐指令等价）；
再失效 ⇒ LeanGauge ⇒ MODGAUGE。差分与原型阶段均异步，不改变 50Hz 主路径（引理 55）。

# IP-321 P-Box：差异化定位、弃权与差异诊断
class PBox:
    def select(self, s):
        phi = featurize_pos(s)                       # 仅审计数值特征（继承定义 429）
        d = [mahalanobis(phi, E.k.anchor, E.k.cov) for k in range(E.K)]
        if min(d) > E.r_min:                          # 定位空白（定义 433）
            return None, "UNKNOWN"
        ws = softmax([-dk / E.T for dk in d])
        return mixture(E.experts, ws), "positioned"

    def disagreement(self, qs):                       # 定义 445
        if E.D_div < E.delta_div:                     # 假多样性：关闭诊断
            return 0.0, "diagnosis_disabled"
        D = max(norm(q_i.mu - q_j.mu, q_i.Sig + q_j.Sig)
                for i < j)
        return D, "ok"

# IP-322 Diff-Box：共模估计、差分门、留出检验
class DiffBox:
    def fit_common_mode(self, refs):
        B_R = stack([B(phi(r.context)) for r in refs])
        y_R = stack([r.mu - f_theta(r.context) for r in refs])
        if matrix_rank(B_R) < self.r: return None, "unobservable"
        if sigma_min(B_R) / sigma_max(self.B_s) < self.obs_min:
            return None, "ill_conditioned"            # 定义 437
        c_hat = pinv(B_R) @ y_R                       # 定义 438
        return c_hat, "observable"

    def correct(self, q, s, c_hat):
        B_s = B(phi(s)); bias = B_s @ c_hat
        var_added = trace(B_s @ pinv(B_R) @ Sigma_R
                          @ pinv(B_R).T @ B_s.T)
        if norm(bias)**2 <= var_added + self.kappa_m: # 差分门：方差感知
            return q, False
        return q.shift(-bias), True

    def holdout_check(self, c_hat, r_hold):           # 定义 439
        B_h = B(phi(r_hold.context))
        pred = B_h @ c_hat
        var  = r_hold.var + quadratic(B_h @ pinv(B_R), Sigma_R)
        z = (r_hold.mu - f_theta(r_hold.context) - pred) / sqrt(var)
        return abs(z) <= self.eps_diff and sign_consistent(z, pred)

# IP-323 Proto-Box：原型门控与分级提升
class ProtoBox:
    def min_samples(self, delta, sigma, beta, beta_power):  # 定义 441
        return ceil(2 * sigma**2 * (z(1-beta) + z(1-beta_power))**2 / delta**2)

    def gate(self, cand, s):
        m = self.min_samples(eps_tol - Delta[s], sigma[s], beta, beta_power)
        R_hat, n = self.run_prototype(cand, s, m)
        if n < m: return False, "underpowered"
        if R_hat + Delta[s] > eps_tol: return False, "proxy_bound"
        return self.reject_upper(R_hat, eps_tol - Delta[s], beta, n), "ok"

    def promote(self, cand, s):                        # 定义 442
        if not self.shadow(cand, s, N_sh): return "stay_shadow"
        for ev in self.canary_sequential(cand, s, p_c):
            if ev.alarm: return self.rollback(s, blast_radius=p_c)
        return self.full(cand, s)

# IP-324 7C 闭环：H → C → E → C → V → P → U
def diffgauge_7c(M, s):
    H = M.lbox.hypothesize(s, M.dbox.R[s])                       # H
    prog = M.tbox.select(H, M.tools, M.tcv, M.budget_left(s))    # C
    receipts = M.tcv.execute(prog, M.env)                        # E
    if len(receipts) < n_min(s): return stub_and_red(s, "insufficient")

    q, pos = M.pbox.select(s)                                    # C：定位
    if q is None: return lean_numeric_fallback(M, s)             # 弃权 ⇒ 退化链
    q = M.apcal.calibrate(receipts, H, s)                        # C：摊销后验

    c_hat, ok = M.diffbox.fit_common_mode(M.refs)                # 差分锚定
    if ok == "observable" and M.diffbox.holdout_check(c_hat, M.holdout(s)):
        q, corrected = M.diffbox.correct(q, s, c_hat)
    elif ok != "no_refs":                                        # 定义 439 失败
        return stub_and_red(s, "diff_model_mismatch")
    else:
        corrected = False                                        # 无参考：退回 ToolGauge 路径

    D, dst = M.pbox.disagreement(M.pbox.experts_at(s))           # 共模诊断
    if dst == "ok" and D > tau_D(alpha): M.pquar.flag_common_mode()

    if not contract_regression(q): return stub_and_red(s, "regression")  # V
    okP, why = M.protobox.gate(q, s)                             # P：原型门
    if not okP: return stay_canary_or_stub(s, why)               # 不 full 提升
    promoted = M.protobox.promote(q, s)                          # P：shadow→canary→full
    if promoted != "full": return promoted

    new_ec = M.apcal.update_contract(M.dpe, q, s)                # U
    M.mreg.hot_replace(M.dpe, new_ec)
    M.dbox.update_from_posterior(s, q)
    bind_claims(new_ec, H, prog, receipts, corrected=corrected)  # 定义 423/427
    M.pquar.record(M.apcal.last_gain, realized_gain(receipts),
                   differential=corrected)                       # 定义 428 扩展
    return True

# IP-325 主闭环：50Hz 不动；差分/原型全异步；三重断路器
def DiffGauge_round(M, obs, audio, tac, depth, det):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s); submit_async(diffgauge_7c, M, s)
    if M.pquar.triggered():                       # 基线断路器

    if M.diffbox.reference_integrity_broken():     # 参考被污染/漂移
        M.diffbox.disable_correction(); M.monitor.emit("reference_quarantine")
    return MODGAUGE_round(M, obs, audio, tac, depth, det)

## 3. 推导

**引理 51（差分抵消界）**
在 C1（定义 435）、rank(B_ℛ)=r、‖ε‖≤ε_max、参考噪声 ‖ζ_ℛ‖≤ζ_max 下，记 κ_B = σ_max(B_s)/σ_min(B_ℛ)，
差分校正后的目标误差满足
‖ẽ_s‖ = ‖ε_s − B_s B_ℛ⁺(ε_ℛ + ζ_ℛ)‖ ≤ ε_max + κ_B(ε_max + ζ_max)。
共模项 B_s c 被**精确抵消**（与 c 无关）。
证明：ẽ_s = B_s c + ε_s − B_s B_ℛ⁺(B_ℛ c + ε_ℛ + ζ_ℛ) = ε_s − B_s B_ℛ⁺(ε_ℛ+ζ_ℛ)，三角不等式即得。
**系 51.1（秩亏泄漏）** 若 rank(B_ℛ)=r′<r，令 P 为到 range(B_ℛ) 的正交投影，则额外泄漏项为
‖B_s(I−P)c‖；此时必须满足可观测定量门槛（定义 437），否则 corrected=False。
**系 51.2（误差从全局变局部）** 共模方差项 ‖B_s c‖² 被消去，只剩 ε 的本地方差；
若 κ_B = O(1)，跨盲区误差协方差的非对角项由共享 c 主导变为由特异 ε 主导（引理 54）。

**引理 52（差异诊断的功效与其盲区）**
设专家 k 的误差响应为 B_k c + ε_k，零假设 c=0 下 D(s)（定义 445）有尾界 τ_D(α)，故
P(D > τ_D(α) | c=0) ≤ α。
备择下若存在 k≠l 使 ‖(B_k−B_l)c‖ ≥ τ_D(α)+ε_max，则检测概率随 ‖c‖ 单调上升并趋于 1。
特别地，若所有 B_k 相同（D_div=0），则 D 对 c **完全不敏感**（零功效）——
这就是「假多样性」为何必须由定义 434 显式禁止。
系：差异化诊断不需要参考站，但需要**真差异**；差分校正不需要差异，但需要**可观测参考**。
两条机制互补，不能互相替代。

**引理 53（原型门控的污染风险界）**
设代理差距事件 G = {|R_dep − R_proto| ≤ Δ_s} 满足 P(G) ≥ 1−γ；
门控在水平 β 下检验 H0: R_proto ≤ ε_tol − Δ_s。
则 P(接受 ∧ R_dep > ε_tol) ≤ γ + β。
证明：接受 ∧ R_dep>ε_tol ⇒ G^c，或 G 下 R_proto > ε_tol−Δ_s 而检验未拒绝（概率 ≤ β）。
**系 53.1（门控空洞化）** 若 Δ_s ≥ ε_tol，则接受条件不可能同时满足（除非 R̂_proto 为负），
必须禁止 full 提升；这防止「代理太差却仍然放行」。
**系 53.2（功效不足）** n<m 时检验功效 < 1−β_p，实际污染风险可远超 γ+β；故定义 441 强制 n≥m。

**引理 54（局部性恢复与爆炸半径）**
在引理 51 与 53 下，提升后盲区 i,j（i≠j）的误差互协方差满足
|Cov(ẽ_i, ẽ_j)| ≤ κ_i κ_j (ε_max² + 2ζ_max²) + 泄漏项，
在 C1（Cov(ε_i,ε_j)=0）与可观测定量门槛下，非对角项不再由共享 c 主导；
若 κ_i κ_j 有界，则「一次坏先验污染所有子图」的结构性通道被切断。
canary 阶段即使误接受，爆炸半径 ≤ p_c（定义 442），且回滚时延由序贯检测控制。
系：基线的「局部修复、误差局部化」论证在 DiffGauge 中重新成立，但此时代价是
**参考集与原型代理的可观测性假设**（见本轮最大风险）。

**引理 55（时序、预算与严格退化）**
差分拟合 O(r·nr·d_u + nr·d_u²)、单盲区校正 O(r·d_u)、原型门控 O(m) 与 canary 回放全部位于 50Hz 路径之外（异步、事件驱动）。
50Hz 周期新增仅为回执验证与 O(1) 定位查表，< 0.2ms。
预算拆分为 B_tools + B_proto + B_canary，均受 PR-Contract（定义 443）与 TB-Contract（定义 424）硬顶约束；
令 K=1、ℛ=∅、P_s=∅ 时 7C 退化为 6C，逐指令等价（定义 446），硬实时（引理 45）保持。

## 3. 关键算法骨架

# IP-321 P-Box：定位、弃权、差异诊断
class PBox:
    def select(self, s):
        phi = featurize_pos(s)                         # 仅审计数值特征（继承 429）
        d = [mahalanobis(phi, E.k.anchor, E.k.cov) for k in range(E.K)]
        if min(d) > E.r_min: return None, "UNKNOWN"    # 定义 433
        ws = softmax([-dk / E.T for dk in d])
        return mixture(E.experts, ws), "positioned"

    def disagreement(self, qs):                         # 定义 445
        if E.D_div < E.delta_div: return 0.0, "diagnosis_disabled"
        D = max(norm(q_i.mu - q_j.mu, q_i.Sig + q_j.Sig) for i < j)
        return D, "ok"

# IP-322 Diff-Box：共模估计 / 方差感知差分门 / 留出 V_d
class DiffBox:
    def fit_common_mode(self, refs):
        B_R = stack([B(phi(r.context)) for r in refs])
        y_R = stack([r.mu - f_theta(r.context) for r in refs])
        if matrix_rank(B_R) < self.r: return None, "unobservable"
        if sigma_min(B_R) / sigma_max(self.B_s) < self.obs_min:
            return None, "ill_conditioned"
        return pinv(B_R) @ y_R, "observable"            # 定义 437/438

    def correct(self, q, s, c_hat):
        B_s = B(phi(s)); bias = B_s @ c_hat
        var_added = trace(B_s @ pinv(B_R) @ Sigma_R
                          @ pinv(B_R).T @ B_s.T)
        if norm(bias)**2 <= var_added + self.kappa_m:   # 差分门
            return q, False
        return q.shift(-bias), True

    def holdout_check(self, c_hat, r_hold):             # 定义 439
        B_h = B(phi(r_hold.context)); pred = B_h @ c_hat
        var = r_hold.var + quadratic(B_h @ pinv(B_R), Sigma_R)
        z = (r_hold.mu - f_theta(r_hold.context) - pred) / sqrt(var)
        return abs(z) <= self.eps_diff and sign_consistent(z, pred)

# IP-323 Proto-Box：功效门控 + 分级提升
class ProtoBox:
    def min_samples(self, delta, sigma, beta, beta_power):   # 定义 441
        return ceil(2 * sigma**2 * (z(1-beta) + z(1-beta_power))**2 / delta**2)

    def gate(self, cand, s):
        m = self.min_samples(eps_tol - Delta[s], sigma[s], beta, beta_power)
        R_hat, n = self.run_prototype(cand, s, m)
        if n < m: return False, "underpowered"
        if R_hat + Delta[s] > eps_tol: return False, "proxy_bound"
        return self.reject_upper(R_hat, eps_tol - Delta[s], beta, n), "ok"

    def promote(self, cand, s):                            # 定义 442
        if not self.shadow(cand, s, N_sh): return "stay_shadow"
        for ev in self.canary_sequential(cand, s, p_c):
            if ev.alarm: return self.rollback(s, blast_radius=p_c)
        return self.full(cand, s)

# IP-324 DiffGauge-7C：H → C → E → C → V → P → U
def diffgauge_7c(M, s):
    H = M.lbox.hypothesize(s, M.dbox.R[s])                        # H
    prog = M.tbox.select(H, M.tools, M.tcv, M.budget_left(s))     # C
    receipts = M.tcv.execute(prog, M.env)                         # E
    if len(receipts) < n_min(s): return stub_and_red(s, "insufficient")

    q, pos = M.pbox.select(s)                                     # C：定位
    if q is None: return lean_numeric_fallback(M, s)              # 弃权 ⇒ 退化链
    q = M.apcal.calibrate(receipts, H, s)                         # C：摊销后验

    c_hat, ok = M.diffbox.fit_common_mode(M.refs)                 # 差分锚定
    if ok == "observable" and M.diffbox.holdout_check(c_hat, M.holdout(s)):
        q, corrected = M.diffbox.correct(q, s, c_hat)
    elif ok != "no_refs":
        return stub_and_red(s, "diff_model_mismatch")             # V_d 失败
    else:
        corrected = False                                         # 无参考 ⇒ ToolGauge 路径

    D, dst = M.pbox.disagreement(M.pbox.experts_at(s))            # 共模诊断
    if dst == "ok" and D > tau_D(alpha): M.pquar.flag_common_mode()

    if not contract_regression(q): return stub_and_red(s, "regression")
    okP, why = M.protobox.gate(q, s)                              # P：原型门
    if not okP: return stay_canary_or_stub(s, why)
    promoted = M.protobox.promote(q, s)                           # P：灰度提升
    if promoted != "full": return promoted

    new_ec = M.apcal.update_contract(M.dpe, q, s)                 # U
    M.mreg.hot_replace(M.dpe, new_ec)
    M.dbox.update_from_posterior(s, q)
    bind_claims(new_ec, H, prog, receipts, corrected=corrected)   # 定义 423/427
    M.pquar.record(M.apcal.last_gain, realized_gain(receipts),
                   differential=corrected)
    return True

# IP-325 主闭环：50Hz 不动；差分/原型异步；三重断路器
def DiffGauge_round(M, obs, audio, tac, depth, det):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s); submit_async(diffgauge_7c, M, s)
    if M.pquar.triggered(): M.apcal.pause(); M.use_bpcal_fallback = True
    if M.pbox.diversity_broken():
        M.pbox.disable_diagnosis(); M.monitor.emit("diversity_low")
    if M.diffbox.reference_integrity_broken():
        M.diffbox.disable_correction(); M.monitor.emit("reference_quarantine")
    return MODGAUGE_round(M, obs, audio, tac, depth, det)

## 4. 推导

**引理 51（差分抵消界）** 在 C1、`rank(B_ℛ)=r`、`‖ε‖≤ε_max`、`‖ζ_ℛ‖≤ζ_max` 下，`κ_B=σ_max(B_s)/σ_min(B_ℛ)`：
`‖ẽ_s‖ ≤ ε_max + κ_B(ε_max+ζ_max)`，共模项 `B_s c` 精确抵消；
秩亏时附加泄漏 `‖B_s(I−P)c‖`（P 为到 `range(B_ℛ)` 的投影）。
系 51.1：共模方差 `‖B_s c‖²` 被消去，误差由「全局共享」退化为「局部特异」。
系 51.2：可观测定量 `obs` 与 `κ_B` 互为倒数关系，是差分校正可用性的**可计算网关**。

**引理 52（差异诊断功效）** 零假设 `c=0` 下 `P(D>τ_D(α)) ≤ α`；
备择下若 `‖(B_k−B_l)c‖ ≥ τ_D(α)+ε_max`，检测概率随 `‖c‖` 上升趋于 1；
若所有 `B_k` 相同（`D_div=0`），`D` 对 `c` 完全不敏感（零功效）。
系：差异化诊断无需参考站但需真差异；差分校正无需差异但需可观测参考；二者互补。

**引理 53（原型门控污染风险）** 代理差距事件 `G` 满足 `P(G)≥1−γ`，门控在水平 β 检验 `H0: R_proto≤ε_tol−Δ_s`，则
`P(接受 ∧ R_dep>ε_tol) ≤ γ+β`。
系 53.1：`Δ_s≥ε_tol` ⇒ 门控空洞化，禁止 full（定义 440）。
系 53.2：`n<m` ⇒ 实际功效低于目标，污染风险可远超 `γ+β`，必须拒绝（定义 441）。

**引理 54（局部性恢复与爆炸半径）** 结合引理 51/53，提升后盲区 i,j 的误差互协方差
`|Cov(ẽ_i,ẽ_j)| ≤ κ_iκ_j(ε_max²+2ζ_max²)+泄漏项`；
C1 与可观测定量门槛下非对角项不再由共享 c 主导，「一次坏先验污染所有子图」的结构性通道被切断；
canary 阶段误接受的爆炸半径 ≤ `p_c`，回滚由序贯检测控制。

**引理 55（时序预算与严格退化）** 差分拟合 `O(nr·r·d_u+nr·d_u²)`、校正 `O(r·d_u)`、原型门控 `O(m)` 与 canary 全异步于 50Hz 外；
周期新增仅回执验证 + `O(1)` 定位查表，`<0.2ms`；
预算拆分 `B_tools+B_proto+B_canary`，受 PR-Contract 与 TB-Contract 硬顶；
`K=1,ℛ=∅,P_s=∅` ⇒ 7C 退化为 6C（逐指令等价），硬实时（引理 45）保持。

## 9. 本轮最大风险

**一句话**：共模子空间模型（维数 r、响应矩阵 B、参考集 ℛ）一旦错设或漂移，
差分校正会把真实的空间变化当成共模减掉（过度校正），而原型代理差距 Δ_s 若本身未被验证，
门控就会在「看起来更局部、更安全」的假象下放行——以 E441/E442/E445/E451 证伪，
差分门（定义 438）+ 留出 V_d（定义 439）+ 参考隔离（IP-325）三重兜底；
若兜底也失效，严格退化链保证系统仍可回落到 ToolGauge/LeanGauge 的保守行为。
