## 1. 两个灵感的第一性原理

### 灵感 1 ·「因果推理」→ 机器人不是 SLAM 的被动观测者，而是天生的干预者

**【直觉】** SLAM 的隐含前提是「被动观测者」：从一串观测里估计状态，观测与你无关。但操作机器人恰恰相反——它每一步都在**动手**，动作是它对外部世界施加的干预（intervention）。而因果推理最核心的工具（`do(a)` 算子、反事实）要的正是干预。**机器人自带的动作，就是因果推断梦寐以求的随机实验**。这带来一个视角翻转：回放数据里的「观测 + 动作」是观测性数据（association / seeing）；一旦区分「我看到 X 在 Y 之后发生」（看）与「我让 Y 发生，X 随之而来」（做），就爬上了因果阶梯。

**【严谨】** 因果阶梯三级：关联 `P(y|x)` < 干预 `P(y|do(x))` < 反事实 `P(y_{x'}|e)`。今天 VLA 的行为克隆与世界模型（含 IP-10）基本停在第 1 级；机器人的自发动作给了我们登上第 2/3 级的合法通道。结构因果模型（SCM）把场景变量 V 与机制 F 写成有向图，`do(a)` 是「外科手术式地替换动作节点机制」。两个对「最后一厘米」的直接兑现：

- **绑定的可识别性**：第 3 轮最大风险「地图毒化」本质是**可识别性问题**。被动多帧一致性（第 3 轮对冲①）在「同一物体被移动」与「外观相同的新物体出现在新位置」这两假设下**观测等价**——似然相同、后验不动，任何被动估计器都只能返回先验，歧义集上错误率下界锁死（L14）。唯一破局是**干预**（轻推/接触），因为接触把「动力学响应」这一新观测通道打开，两假设在该通道下分布不同。这与 SLAM 的经典解法完全同构：**感知混叠（perceptual aliasing）**下被动地点识别会串，**主动 SLAM / 主动回环**的答案就是「动一下换个视角再认」。
- **归因的因果化**：第 3 轮的「六因子 × 五泛化轴」矩阵（IP-06）是**相关矩阵**——某因子与失败共现不等于致败（物体质量 Z 同时影响抓点选择 F 与滑移 Y，是混杂）。按相关排序选修复，可能系统性地选错。升级为干预效应 ACE（L15、U20）：用带 `do` 日志的数据估 `P(fail|do(F=f₁)) − P(fail|do(F=f₀))`，矩阵从「描述共现」变成「诊断致因」。

**策略含义**：因果信息来自**干预**，不来自新语料——这与 F4′ 的「挑战语料静止、数据护城河≈零」严丝合缝：它是又一条「不靠数据、靠机制」的护城河。

### 灵感 2 ·「SLAM」→ 从「状态层」升级为「可因果查询的状态层」

**【直觉】** 第 3 轮的三件套（估计/地图/重定位）回答了「现在在哪、目标是谁、卡没卡住」，但没回答「**为什么失败、换个动作会不会好**」。地图是一张静态快照；因果推理把它变成一个**带机制的、可被 `do/反事实` 查询的对象**。好比从「一张标了路标的静态地图」升级为「一张能回答『如果我从另一侧接近，还会被挡吗』的地图」。

**【严谨】** 把 U16 场景图从「状态快照」提升为 SCM 的**状态节点**（U19）：

- 机制边：`action → displacement`、`occlusion → detection_dropout`、`slip → wrist_micro_motion`、`contact → held_flag`、`distractor_present → binding_confusion`；
- **回环闭合 → 因果环检测**：VLA 的「复读」失败是确定性环 `action→state→action`，因果图上的有向环检测是 IP-13 行为回环检测的原理化版本；
- **重定位 → 干预知情重锚**：扰动后先判「是哪一类扰动」（遮挡/位移/替换），再选恢复动作（保持/重定位/重绑定），而不是把所有扰动当同一种；
- **反事实地图查询**：「若改为从另一侧接近，目标是否仍被遮挡」——把「探测 vs rollout」（IP-10）的抉择交给一个因果目标（L16）。

**策略含义**：第 3 轮的状态层解决「该信什么」；本轮再加「为什么、换招会不会好」，把它变成**可调试、可迁移的机制层**。因果结论不消耗新语料，而是消耗**动作预算**（探测步数），因此必须过 P12/L13/L16 的步数账——这也天然把因果层与评测器的「步骤分」绑在一起。

## 2. 研究问题（新增 Q13–Q15，接第 1–3 轮 Q1–Q12）

- **Q13（因果绑定的可识别性）**：在「移动 vs 替换」构造的观测等价混淆集上，被动多帧绑定与主动干预（轻推/接触）绑定各自的错误率是多少？干预能否把绑定错误压到 ≤1%（突破第 3 轮纯被动门槛）？主动绑定所需步数是否被 L16 的账允许？（E634）
- **Q14（因果归因 vs 相关归因）**：用干预日志估计的 ACE 矩阵与相关矩阵在六因子排序上差多少？按因果矩阵选修复是否比按相关矩阵选修复在同一测试集上多得分数？（E635）
- **Q15（反事实前瞻的可用性）**：反事实 rollout（do 语义，IP-17）相对观测式 rollout（IP-10）在虚假相关压力测试下的鲁棒性与「剂量-反应」校准如何？在什么模型误差/步数预算下它严格优于真实探测？（E637）

## 3. 设计原则（新增 P13–P14，接第 1–3 轮 P1–P12）

- **P13（干预可识别性）**：凡会影响后续动作的**因果结论**（绑定、归因、反事实），被动证据是必要非充分；必须附干预证据或显式标注为「观测性假设」并对其置信度封顶。带 `do` 的干预日志升为一等公民（哪些路标允许轻推/接触、何时执行）。
- **P14（反事实剂量-反应校准）**：反事实世界模型仅当在 `do(a)` 扫描上呈单调剂量-反应且预测校准误差 ≤ 阈值时，才可进入决策；未校准的反事实只允许做「假设生成/排序」，**不得覆盖真实探测结果**（真实证据优先级恒高于模型反事实）。

## 4. 清单处置（深化 / 修剪 / 新增）

- **深化**：**IP-13**（场景图升为 U19 SCM：加机制边、干预日志、因果绑定触发器；重定位改为「先分类扰动后恢复」）；**IP-06**（失败矩阵单元格由「相关占比」升为「干预效应 ACE」，并标注哪些格有干预证据、哪些仅为观测假设）；**IP-10**（查询接口从观测式升为反事实式，见 IP-17）；**IP-14**（滑移归因因果化：用主动预升力/轻推区分「抓点几何失配 / 质量摩擦意外 / 腕部遮挡」，不再只报警）；**IP-04**（特征加「因果不变」约束：跨 32 任务域保持稳定的动作-结果映射方向）。
- **新增**：**IP-16 CausalScene（P0 扩展，挂 IP-13）**；**IP-17 CounterfactualRollout（P1，升级 IP-10）**。
- **修剪**：不新增归档。IP-16 **不是新模型**，是 IP-13 的图结构扩展（现成检测/跟踪 + 干预日志 + 效应估计）；IP-17 **只替换查询接口**，底层世界模型可沿用 IP-10/WMA-0。
- **MVP 不变**：IP-06 + IP-02 + IP-09 + IP-03 + 通用基线；**IP-13 仍是 MVP 后第一扩展，IP-16 为其后的第二扩展**（纯软件，无新模型、无新语料）。
- **退化链更新**：新增 **Level-1.7：因果层不可识别/未校准 → 回落 IP-13 状态层 + 固定阈值断言（Level-1.6）**；绝不允许带着未校准的因果结论行动。

## 5. 本轮最大风险

**虚假因果 / 反事实幻觉**：反事实世界模型若在相关式回放上拟合，会对「换抓点能不能治滑移」这类查询给出**高置信的错误答案**（真实致因是质量/摩擦，不是抓点），从而让系统**系统性地**押错干预——这比没有因果层更糟，因为它把错误信念固化为「可执行的信心」。对冲：P14 剂量-反应校准；只信通过干预检验的边（P13）；反事实永不覆盖真实探测（P14 后半）；Level-1.7 回落。次要风险：干预步数成本吃掉收益（L16/E636）；主动轻推改变真实评测分布、与合成干扰域差问题叠加（沿用 Q12 悬置）。

**一句话最大风险：方案成败押在「反事实是否可被剂量-反应校准证伪」上——若世界模型在分布外系统性地自信地错，因果层会把「拍脑袋」升级成「有理论包装的拍脑袋」，比第 3 轮的纯被动状态层更难被工程直觉发现和回滚。**

## 6. 下一轮迭代计划（深化与修剪，不推倒重来）

- **深化**：E634 的「观测等价混淆集」构造（同外观、移动 vs 替换的成对样本 + 干预信道标注）；E635 的干预日志采集协议（哪些路标允许轻推、探测动作的白名单与步数记账）；E636 的因果信息增益规划器（与 P12 记账合并）；E637 的虚假相关压力测试集（相关性成立但因果方向被翻转的对抗场景）。

## 3. 新增 IP 详述

### IP-16 · CausalScene 因果场景图（P0，新，扩展 IP-13）

- **动机**：第 3 轮状态层解决「是什么」，不解决「为什么/若…会怎样」。而「地图毒化」是**可识别性死结**（L14）：被动多帧在「移动 vs 同外观替换」上观测等价，任何被动器只能返回先验；SLAM 的主动回环早已给出同构答案——主动移动制造新观测信道。机器人每步动作天然是 `do(a)`，是免费的干预来源。
- **与现有方案差异**：teaser 榜（待复核假设）8 模型均「观测→动作」单通路、无显式状态，更无因果结构；v3 的状态层是静态快照；本方案在状态层上加 SCM（机制边 + 干预日志 + 效应估计 + 反事实查询），全部现成件（开词汇检测/跟踪 + 逻辑回归或双稳健 ACE 估计），**无新模型**。
- **技术可行性**：高。机制边由领域知识给定（`occlusion→dropout` 等），只需估计边上的效应量；ACE 用 IPW/双稳健估计；因果绑定用「轻推响应签名」匹配档案动力学。开发量单卡小时级。
- **资源**：数据=IP-06 已有标注 + **干预日志**（新采集项：记录哪些动作是主动探测及其 `do` 语义）；算力=小（低频/事件触发）；接口=无新增字段（全在策略内部）。
- **落地步骤**：①把 U16 场景图改写为 U19 SCM（节点/机制边声明 + 观测/干预数据分离）；②干预日志协议（轻推/预升力动作打 `do` 标签，接入 P12 步数账）；③因果绑定触发器（歧义时执行轻推，按响应签名消歧，E634）；④归因估计（ACE，接入 IP-06 矩阵，E635）；⑤反事实查询接口（供 IP-17/U22）；⑥与 IP-15 共用扰动分类器。
- **风险**：虚假因果边（P13/P14 约束、只信过干预检验的边）；干预步数成本（L16/E636）；主动轻推改变评测分布（合成-真实域差沿用 Q12）。

### IP-17 · CounterfactualRollout 反事实前瞻（P1，新，升级 IP-10）

- **动机**：IP-10 的 rollout 是观测式的（`P(future|history, a)`），在虚假相关下会「预测得像」但「干预后错」。真正的动作选择问的是反事实：`P(outcome | history, do(a'))`——「若我从另一侧抓，还会滑吗」。把查询接口升为 `do` 语义，是让世界模型**可被干预检验**的关键一步。
- **差异**：不换底层模型（可沿用 WMA-0/IP-10），只改「喂给模型的动作」为干预语义（去混杂：屏蔽与动作相关的伪通道，如背景共变），并加 P14 剂量-反应校准门。
- **可行性**：中。`do` 语义在生成式世界模型上可用「动作替换 + 反事实一致性损失」近似；难点在校准与分布外自信错误（Q15）。
- **资源**：沿用 IP-10；新增 = 虚假相关压力测试集（E637），近零算力增量。
- **步骤**：①定义反事实查询 API；②去伪通道的动作编码（仅保留干预语义）；③剂量-反应校准（`do(a)` 扫描单调性 + 校准误差）；④探测 vs 反事实的账（L16）接入 P12；⑤反事实难例喂 IP-12。
- **风险**：反事实幻觉（最大风险，P14 门禁）；探测真实成本（L16）；压力测试过拟合（保留 held-out 伪相关模式）。

## 5. 符号与定义（新增 U19–U22；U1–U18 沿用第 1–3 轮）

- **定义 U19（因果场景图 SCM）**：episode 内结构 `G = (V, E, F)`。`V` = 场景变量 {目标位姿 x_T、held 标志、slip 量、occlusion 标志、干扰物集合、动作 a}；`E` = 机制边；`F` = 结构方程（如 `slip = f(F_grasp, Z_mass, noise)`）。观测分布 `P(V)` 与干预分布 `P(V|do(a))` 共同定义模型；U16 的地图 M 是 G 中的状态子图。跨 episode 版须过 Q9。
- **定义 U20（因果失败归因 ACE）**：因子 F 对失败 Y 的平均因果效应 `ACE(F) = E[Y|do(F=f₁)] − E[Y|do(F=f₀)]`；用双稳健/IPW 从干预日志估计。IP-06 矩阵单元格 = `ACE(F=factor)`（带证据等级），取代相关占比。
- **定义 U21（因果探测目标）**：在路标 w 选择探测动作 `a* = argmax_a  IG(结构边 | do(a)) / cost(a)`，`IG` 为期望信息增益，`cost` 过 P12/L16 步数账；与 L13 的「状态信息」并列，L21 关注「结构信息」（是哪条边导致的）。
- **定义 U22（反事实查询）**：给定观测证据 `e` 与假设动作 `a'`，查询 `Q = P(Y | e, do(a'))`；仅当 IP-17 通过 P14 剂量-反应校准（`a'` 扫描单调、校准误差 ≤ ε）才允许进入决策；否则 `Q` 仅作排序假设。

```python
# ===== IP-16: 因果场景图（在 U16 地图之上加机制边与干预日志）=====
class CausalScene:
    def __init__(self, task_token):
        self.map = SceneState(task_token)          # U16 状态子图（沿用 IP-13）
        self.edges = DEFAULT_MECHANISMS            # 领域给定：occlusion->dropout, slip->micro_motion, ...
        self.log = []                              # 干预日志：(do_action, pre_state, post_state)
        self.ace = defaultdict(lambda: "unknown")  # 因子 -> ACE(证据等级)

    def observe(self, obs, action, is_probe=False):
        self.map.update(obs)
        if is_probe:                               # 只有主动探测才进入干预日志
            self.log.append((action, self.map.snapshot(), None))
        elif self.log and self.log[-1][2] is None: # 回填探测后的状态
            self.log[-1] = (self.log[-1][0], self.log[-1][1], self.map.snapshot())
```

```python
# ===== 因果绑定：观测等价时用轻推制造新观测信道（解 L14 死结）=====
def causal_bind(dets, scene, bind_conf):
    cands = scene.map.associate(dets)              # 被动多帧一致（v3 对冲①）
    if bind_conf >= TAU_BIND or len(cands) < 2:
        return cands[0]                            # 无歧义：被动绑定即可
    # 歧义集：执行最小轻推 do(nudge)，按动力学/接触响应签名消歧
    resp = scene.probe(nudge(delta=EPS))           # 消耗步数，过 P12 记账
    return match_signature(resp, scene.map.dossiers)  # 新信道下似然不同 → 可识别
```

```python
# ===== U20: 干预效应归因（IP-06 矩阵单元格）=====
def estimate_ace(log, factor):
    treat = [r for r in log if r.do.get(factor) == "high"]
    ctrl  = [r for r in log if r.do.get(factor) == "low"]
    if not treat or not ctrl:
        return ("observational-assumed", assoc_effect(log, factor))   # 无干预证据 → 降级
    return ("interventional", doubly_robust(treat, ctrl, outcome="fail"))
```

```python
# ===== IP-17: 反事实查询（须过 P14 剂量-反应校准）=====
def counterfactual(world_model, evidence, a_hyp):
    if not world_model.dose_response_ok(a_hyp, tol=EPS_CAL):
        return None                                # 未校准：拒绝进入决策
    return world_model.predict(evidence, do=a_hyp) # do 语义：去伪通道后的干预预测
```

```python
# ===== L16: 反事实 vs 真实探测的账（并入 P12）=====
def choose_measurement(a, scene):
    probe_cost = scene.expected_steps(a)                       # 真实探测步数 s_p
    cf_err     = scene.world_model.expected_error(a)           # 模型误差 ε
    cf_value   = scene.world_model.info_gain(a)
    probe_val  = scene.expected_info_gain(a)
    return "probe" if probe_val - probe_cost > cf_value - cf_err * LOSS else "counterfactual"
```

## 7. 推导（新增引理 L14–L16；L1–L13 沿用第 1–3 轮）

**引理 L14（观测等价下的被动绑定不可识别；干预恢复可识别）** 设两假设 `H_move`（同一目标被移动 Δ）与 `H_swap`（同外观新物体置于新位）。若传感器模型在其歧义集上满足 `P(obs|H_move)=P(obs|H_swap)`，则对任何仅依赖 obs 的被动估计器，后验比恒等于先验比，决策错误率在等先验下 ≥ ½·P(ambiguous)——**多帧一致性无法突破**。引入干预 `do(nudge)` 后，接触/动力学响应 `r` 在 `H_move`（目标自身档案动力学）与 `H_swap`（替换物不同于档案）下分布不同，`P(r|H_move) ≠ P(r|H_swap)`，似然比偏离 1，可识别性恢复。⇒ 第 3 轮「地图毒化」不是工程疏忽而是**信息论下界**；主动绑定（IP-16）是其原理性解药，与 SLAM「主动回环破感知混叠」同构。∎

**引理 L15（混杂下相关归因可反序；干预可识别 ACE）** 设因子 F、混杂 Z（如物体质量）、结果 Y（如滑移），且 `Z→F`、`Z→Y`、`F→Y`。则观测关联 `P(Y|F)` 一般 ≠ 因果 `P(Y|do(F))`：存在参数使按观测关联排序把「伪因子」排到真因之前（Simpson 型反转）。干预 `do(F)` 切断 `Z→F`，故 ACE 可识别；仅用相关矩阵（第 3 轮 IP-06）会系统性误序，带干预日志的 ACE 校正之。⇒ 归因升级不是精度改良而是**方向正确性**问题。∎

**引理 L16（反事实 vs 真实探测的盈亏平衡）** 真实探测耗 `s_p` 步、信息增益 `G_p`；反事实查询耗算力 `c_cf`、信息增益 `G_cf` 但含模型误差：错误决策损失期望 `ε·L`（ε 为校准误差，L 为错误干预损失）。反事实严格优于探测 ⇔ `G_cf − ε·L − c_cf > G_p − s_p`，即 `ε* = (G_cf − G_p − c_cf + s_p)/L` 之下才用反事实。⇒ 步数预算紧（`s_p` 大）或信息相近时反事实占优；模型误差大（`ε>ε*`，正是分布外的常态）时**必须真实探测**——这为 P14 门禁与「真实证据优先」提供了定量依据。∎
