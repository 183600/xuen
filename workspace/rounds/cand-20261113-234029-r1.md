# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「姿态估计」×「目标检测」）

> R69 让系统学会了「问」，但它把观测 `o_t` 当成一个**已经被整理好的向量**：不确定性只发生在动作侧（动作模态、交互、似然），感知侧则是干净输入。这是整套「求证」论证里最大的盲区——**证人本身是怎么被造出来的，R69 没有管**。真实机器人的观测从来不是一个数，而是一份**结构化场景报告**：目标检测给出「有几个、是什么、大致在哪」（离散身份 + 粗定位），姿态估计给出「它到底朝向哪」（连续 SE(3) 几何）。这两半恰好是「谁」与「怎么摆」，任何一半单独出错都足以让下游策略执行一个物理上错误、却统计上自信的动作。
>
> 更关键的是，这两种不确定性有**完全不同的代数结构**，R69 的标量 U 一个都装不下：
> - 检测的歧义是**指派（assignment）歧义**——「我知道有两个物体，但不知道哪个是哪个」，它住在置换群 / Birkhoff 多面体上，是组合性的；
> - 姿态的歧义常常是**对称（symmetry）歧义**——杯子转 180° 还是同一个杯子，扳手翻个面仍然装得上，它住在商空间 `SE(3)/G` 上，是群轨道（orbit），不是高斯噪声，也不是「多采几次样」能消掉的。
>
> 于是本轮的核心命题是：**把不确定性对象从 R69 的动作空间上移到结构化场景信念：联合假设 h=(指派 σ, 几何 Ξ, 类别 C)，检测层给指派信念、姿态层给对称商上的轨道信念；两者的危险不是各自低置信，而是「各自高置信、联合却不自洽」的共谋（collusion）；消歧也不是多算几次，而是执行真正打破对称的信息动作（换视角、抓取旋转、接触探询）；且只在任务真正在乎该对称时才花预算。** 命名 **ORBIT-RAS**（Object-identity & pose-oRbit Belief with Interactive Testing）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我的证人是怎么看错的——它是分不清『谁』，还是分不清『怎么摆』，而这个分不清到底要不要紧**」——不确定性不只在动作里，也在「把世界切成物体」的那一刀里。

## 0. 直觉与动机

**灵感 1（检测与姿态：同一次感知的两半，误差互补又共轭）**
直觉：检测回答「是什么、大概在哪」，姿态回答「精确怎么摆」。只有检测，机器人知道该抓杯子却不知道杯柄朝哪；只有姿态，它能算出抓取位姿却不知道这个位姿属于桌上哪个杯子。二者的错误是**共轭**的：检测错是「把 A 认成 B」，姿态错是「把 B 摆成 A 的样子」。R69 把它们压进一个 `o_t`，等于把「身份」和「几何」两种正交的错误结构提前平均掉了。ORBIT 要做的第一件事，就是**拒绝把观测当向量，而把它当假设**。

**灵感 2（对称：姿态歧义是群轨道，不是噪声）**
直觉：对称物体（圆柱、方盒、瓶子、扳手，甚至某些构型下的人体）存在多个**物理上不可区分**的姿态。你无法通过「算得更久」或「采更多样本」区分它们，因为似然在轨道上完全相同；你只能**换一个不在稳定子里的观测**。因此正确的表示不是 SE(3) 上的单峰高斯，而是商空间 `𝒬_c = SE(3)/G_c` 上的分布：若干个由群元 `g∈G_c` 相连的轨道模态 `g·ξ̄`、轨道权重 `w_g`、以及轨道内协方差。这也解释了一个常见 bug：对两个对称姿态做欧氏平均，会得到一个**根本不是刚体变换**的「矩阵」（旋转部分不再正交）——所以 R69 那套「聚类后取原型均值」在姿态上会静默地产生非物理结果（引理 19）。

**灵感 3（指派：检测歧义住在置换群上）**
直觉：多目标场景里，检测器给你一堆框和分数，真正的问题是「这一帧的哪个框接上一条轨迹的哪个实例」。这是一个**匹配**问题，歧义是置换上的概率（Birkhoff 多面体、Sinkhorn），不是某个框的分数高低。遮挡、杂波、标签抖动都会制造「身份熵」`H_id`。它的危险性在于：一个高分的错误指派会让下游把一个**完全合理的姿态**装到**错误的物体**上——每一步都自洽，整体却错了。

**灵感 4（共谋：高置信的不一致才是真正的敌人）**
直觉：R69 最怕「证人串供」。在感知层，串供有了精确的几何形态：检测锁定了 A（高分），姿态拟合出一个本属于 B 的几何（高似然），两个模块各自校准良好，但联合场景假设**几何上不可能**——多视图极线对不上、时序刚体运动不连续、接触/运动学不可行、检测-姿态的重投影环不闭合。**边际置信对共模误差不敏感，几何环一致性却必然被共模误差破坏**。所以「第二意见」不该是再加一个同源证人，而应是一条**结构性约束**：联合一致性检验（引理 22）。这也是对 R69「正交证据」最实质的补强——正交性不靠假设，靠几何约束的可证伪性。

**灵感 5（不是所有对称都值得打破：任务相关对称）**
直觉：杯子绕自身轴转 180°，如果任务是「把它放进槽里」，可能完全无所谓；如果任务是「把杯柄对准人手」，就致命。**姿态的轨道歧义只有在任务代价打破该对称时才影响决策。** 定义 `G_eff = G / Stab_G(ℓ)`（被任务代价稳定的那部分对称不产生任务相关歧义）。这给了一个 R69 没有的、非常锋利的预算判据：`G_eff` 平凡时，花任何预算去消解轨道都是纯浪费且增加风险（引理 21）。消歧不是「越确定越好」，而是「只消除决策真正在乎的那部分不确定」。

**灵感 6（对称破缺需要动作，而不是采样）**
直觉：要区分圆柱的 0° 与 180°，沿对称轴再看一百眼都没用——观测在稳定子里。你必须做一件**不在稳定子里**的事：横向换视角、抓起来转一下、推一下看它怎么动。于是「信息动作」多了一条硬约束：`T_g ∉ Stab_G(ξ̄)`，否则期望信息增益恒为零（引理 20）。这把 R69 的 MINT 从「看/问/触」升级为「**对称破缺动作**」，也让「主动姿态探询」第一次有了可证明的必要条件。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（ORBIT-RAS 总览与三不变式）** ORBIT-RAS = (SGB, OGM, ABD, JCT, TSR, SBI, JCG, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；等变训练、对称目录学习全部离线）；
(ii) **联合证书纪律**：任何单模块置信（检测分、姿态似然、轨道权重）都不得单独授权动作，必须通过场景级联合一致性（身份 × 几何）；
(iii) **严格退化**：当对称群平凡 `G={e}`、指派确定 `H_id=0`、姿态单峰且 `κ<τ_κ` 时，逐指令等于 R69（定理 18）。

**定义 311（场景假设空间）** 设检测集 `D_t={d_j}`、实例集 `𝒪_t={1..N}`。场景假设 `h=(σ, Ξ, C)`，其中 `σ: D_t ⇀ 𝒪_t` 为部分单射指派，`Ξ=(ξ_1,…,ξ_N)`，`ξ_i∈SE(3)`，`C=(c_1,…,c_N)` 为类别。联合信念 `b_t(h)=p(σ,Ξ,C | o_{1:t})`。后续所有操作都在 `b_t` 上，而不是在某个点估计上。

**定义 312（检测层：指派信念 ABD）** 给匹配代价矩阵 `S∈ℝ^{M×N}`，指派后验用熵正则 Sinkhorn 得双随机矩阵 `P=Sinkhorn(S/τ,ε)∈𝔅_{M,N}`（Birkhoff 多面体）；身份熵 `H_id=−Σ_σ P(σ)log P(σ)`（实现上用边际熵之和逼近）。检测分数经温度/Platt 校准，`ECE_det` 入联合校准门。遮挡标记由框几何与可见性估计给出。

**定义 313（姿态层：对称商与轨道信念 OGM）** 对类别 `c`，对称群 `G_c ≤ SE(3)`（离散：`C_2`、`D_2`、`C_4`；连续：绕轴 `SO(2)`；含反射时取 `O(3)` 的子群），作用在物体坐标系上。姿态信念定义在**商空间** `𝒬_c=SE(3)/G_c` 上。轨道分解：模态 `m_g=g·ξ̄`、轨道权重 `w_g`、轨道内协方差 `Σ_g`（在商切空间上）。`U_ale^pose=Σ_g w_g tr(Σ_g)`（不可约部分）；`U_epi^pose=H(G)·sep(G·ξ̄)`（可约部分）。姿态均值取 **Karcher / 商均值**，**绝不做欧氏平均**（引理 19）；连续对称按 Haar 测度积分。

**定义 314（身份-几何纠缠与联合一致性 JCT）** 对假设 `h` 定义环残差集合 `r_con(h)=(r_mv, r_tmp, r_kin, r_rep)`：多视图极线残差、时序刚体运动残差、接触/运动学可行性残差、检测-姿态重投影环残差。联合得分
`J(h)=log p(D_t|h)+log p(Ξ|C)−λ_c Σ r_con(h)`。
**共谋指数** `κ = max_module confidence(h) − σ(J(h_best_consistent)/T)`：当各模块都很自信、但最优联合一致假设的后验很低时，`κ` 大。`κ` 大不表示「不确定」，而表示「自信地不自洽」，必须拦截（定义 319、引理 22）。

**定义 315（任务相关对称削减 TSR）** 设任务代价 `ℓ(a,ξ)`（含安全代价）。稳定子 `Stab_G(ℓ)={g∈G : ℓ(a,gξ)=ℓ(a,ξ), ∀a}`，**有效对称** `G_eff=G/Stab_G(ℓ)`。只保留 `G_eff` 生成的轨道歧义：`U_epi^eff=H(G_eff)·sep(G_eff·ξ̄)`。若 `G_eff={e}`，该姿态歧义**可证明与决策无关**，不花预算、也不必消解（引理 21）。注意：这不是「忽略歧义」，而是「证明它不影响任何动作的代价」。

**定义 316（对称破缺信息动作 SBI）** 信息动作扩充为 `g∈{g_view, g_rot, g_push, g_ask}`：换视角、抓取旋转、接触探询、提问。每个动作诱导观测变换 `T_g`。称 `g` **对称破缺**当且仅当 `T_g ∉ Stab_G(ξ̄)` 且观测模型在轨道方向的 Fisher 信息 `J_G(g)>0`。轨道信息增益 `VoI_G(g)=H(G|o)−E_{y~p(·|g,o)}[H(G|o,y)]`。稳定子内的动作（例如绕圆柱对称轴再看一眼）`VoI_G(g)≡0`（引理 20）。

**定义 317（主动姿态探询控制器）** `g* = argmax_g [VoI_G(g)+ω·VoI_σ(g)−c(g)]`，约束：预算未超、`g` 过 C-RAS-WM 认证（含接触力/旋转角限幅）、满足对称破缺条件（定义 316）、接触安全。轨道与指派的增益合并，因为同一个动作（如抓取旋转）可能同时降低 `H(G)` 与 `H_id`。

**定义 318（联合校准门 JCG）** 门集合：`ECE_det≤τ_d`、`ECE_pose≤τ_p`、`ECE_orb≤τ_o`、**等变性检验** `‖f(g·o)−g·f(o)‖≤τ_eq (∀g∈G_c)`、以及**联合/条件校准** `ECE_joint≤τ_j`（校准的是 `p(σ,ξ)` 而非各边际）。任一越界 ⇒ 禁用 SBI/TSR，退化为 R69 纯保守。理由：用校准良好的边际冒充校准良好的联合，正是共谋的温床。

**定义 319（结构化不确定性度量）** `U=(U_ale^pose, U_epi^eff, U_epi^id, U_con)`，**不做简单加和**：`U_ale^pose` 进 λ floor；`U_epi^eff` 与 `U_epi^id` 进 SBI；`U_con` 不是不确定性而是**证书违规**（`r_con` 超阈 / `κ` 超阈），直接阻断并审计。四者语义不同，混加会重犯 R69 批评过的「aleatoric/epistemic 混为一谈」。

**定义 320（两级退避与 R69 包含接口）** 若轨道与指派在预算内消解且 JCG 通过：`λ=λ_floor(U_ale^pose)`（resolution bonus，比 R69 更不保守但不更低安全）；若未消解/超时/门控越界/预算耗尽/`κ` 超阈：`λ=λ_floor(U_ale^pose+U_epi^eff+U_epi^id)`，并逐指令退化为 R69。`G={e}, H_id=0, κ<τ` 时与 R69 完全相同（定理 18）。

**定义 321（身份切换安全 ISS）** 目标实例的切换需同时满足：联合后验优于当前身份一个硬边际 `Δ_id`、连续 `T_switch` 帧一致、`κ` 与 `r_con` 通过、新目标前缀过 C-RAS-WM 认证。状态机带迟滞，单帧身份翻转**永远不允许驱动动作**（防止把标签抖动变成物理目标突变）。

**定义 322（多假设追踪与剪枝）** 在 `h` 上维护多假设树（MHT）：Bayes 更新、按 `J(h)` 剪枝、对称等价假设在商空间合并以省内存、按可见性做出生/死亡。实时只保留 `N_max` 个假设；被剪掉的概率质量计入 `U_epi^eff`，不静默丢弃。

**定义 323（证书 J_ORBIT）** `J_ORBIT=(J_FLUID, ECE_det, ECE_pose, ECE_orb, ECE_joint, equivariance_res, κ_p95, H_id, U_epi^eff_before/after, r_con_p95, symmetry_catalog_ver, orbit_log_hash)`。`Valid ⇔ Valid(J_FLUID) ∧ 全部门控通过 ∧ 交互/旋转预算未越界 ∧ ISS 纪律满足`。

**定义 324（对称威胁模型 ℰ_sym）** 对称欺骗（对抗纹理/几何让非对称物体「看起来」对称，或让对称物体显得可区分）、检测欺骗（对抗 patch 造成高置信错误检测）、身份掉包、姿态轨道投毒、以及最危险的**共谋欺骗**（检测与姿态被同一扰动方向一起骗过，各自都高置信且联合仍近似自洽）。并入 AIC：`ℰ_ORBIT=ℰ_FLUID×ℰ_sym`。

**定义 325（离线等变训练约束）** 姿态头满足群等变 `f(g·o)=g·f(o)`；损失定义在商空间（轨道不变损失）；指派用 Sinkhorn/匈牙利软标签；轨道负采样；对称目录 `G_c` 离线学习并冻结版本号。全部离线，实时零学习写操作（定义 310-i）。

**定义 326（ORBIT 主闭环）** 顺序：`SGB 场景信念 → JCT 联合一致性 → TSR 任务对称削减 → SBI 对称破缺交互（仅当 G_eff 非平凡且 JCG 通过）→ 消解/退避 → ISS 认证切换 → R69 执行与审计`。任一环节失败都沿定义 320 单调退化，安全侧永不弱于 R69。

```python
    r_con, kappa = M.jct.residuals(h), M.jct.collusion(hyps, post)

    if kappa > TAU_KAPPA or max(r_con) > TAU_CON:
        return M.r69.fallback(h, reason="collusion")        # 回 R69 最保守
    # 2) 任务相关对称削减：平凡则不花预算
    G_eff = M.tsr.reduce(h.G, M.task_cost)
    # 3) 联合校门 + 可解则对称破缺交互
    if M.jcg.pass_gates(h) and not M.tsr.is_trivial(G_eff):
        g = M.sbi.choose_symmetry_breaking(h, G_eff, M.budget)
        if g is not None:
            y = M.sbi.execute(g)                            # 认证的换视角/旋转/探询
            h = M.sgb.update_with(h, y); h = M.jct.recheck(h)
    # 4) 消解失败/门控越界：单调退化为 R69
    U_floor = h.U_ale + (0.0 if h.resolved else h.U_epi_eff + h.U_epi_id)
    lam = max(M.r69.risk_scale(h), lam_floor(U_floor))
    # 5) 身份切换必须迟滞 + 认证（禁止单帧翻转驱动动作）
    target = M.iss.select(h, M.tracks)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(target, M.vista.H), ..., M.wm_preds)
    mode = M.r69.select_mode(target, lam)
    M.vqa_s.submit_async(h, g if 'g' in locals() else None, r_con, kappa)
    return k, lam, mode, (h.U_ale, h.U_epi_eff, h.U_epi_id)
```

## 3. 推导

**引理 19（商空间姿态的非欧性）** 设 `G` 有限或紧，轨道 `O=G·ξ`。欧氏均值 `μ=(1/|G|)Σ_g (g·ξ)` 的旋转部分一般不再正交，故 `μ∉SE(3)`；它与商空间的最近点距离下界为轨道半径 `ρ_orb`。因此对对称模态做逐分量平均会**静默产生非物理位姿**。当 `Δ_orb ≥ 3σ_in`（A99，轨道可分）时，商/Karcher 均值 `argmin_ξ Σ_g w_g d^2(ξ, g·ξ̄)` 唯一且落在 `𝒬_c` 上。系：R69 的「聚类取原型均值」必须替换为商均值；否则 `U_epi` 本身不可信。

**引理 20（对称破缺的零 VoI 判据）** 若 `T_g∈Stab_G(ξ̄)`，则对所有 `g'∈G` 有 `p(y|g,g'·ξ̄)=p(y|g,ξ̄)`，故后验 `p(G|o,y)=p(G|o)`，`VoI_G(g)=0`。反之，若 `T_g∉Stab_G(ξ̄)` 且观测模型在轨道方向 Fisher 信息 `J_G(g)>0`，则小噪声下 `VoI_G(g) ≥ ½log(1+J_G σ_prior²) − o(1) > 0`。系：绕圆柱对称轴多看无用；横向平移、绕横轴旋转、接触扰动才可能破缺——这给「主动姿态探询」一条可执行的准入条件。

**引理 21（任务相关对称的预算节约与安全中性）** 若 `G_eff={e}`，则对任意 `g∈G`、任意 `a` 有 `ℓ(a,gξ)=ℓ(a,ξ)`，动作的期望代价对轨道不变，故任何交互只能增加成本 `c(g)>0` 而不能降低任务风险；不交互弱占优。因此 TSR 在**不削弱安全**的前提下节约预算：它拒绝的是「可证明与决策无关」的歧义，而不是「懒得处理」的歧义。

**引理 22（联合一致性对共谋的检测功效）** 设单模块误差分解为 `e=e_ind+e_common`。在 A100（边际校准对 `e_common` 不敏感、几何约束对 `e_common` 的 Jacobian `J_c` 秩 ≥1）下，边际置信近似不随 `e_common` 变化，而环残差满足 `‖r_con‖ ≥ σ_min(J_c)‖e_common‖ − ε`。于是 `κ=置信−一致性` 能把「独立噪声」（`κ` 小）与「自信共谋」（`κ` 大）分开，效应量 `δ_c` 下 ROC-AUC ≥ 0.85。要点：**结构性约束不是又一个同源证人，而是一条共模误差必须违反的几何法律**——这是对 R69「证人可能串供」的正面回答。

**定理 18（ORBIT 严格包含 R69）** 在 `G={e}`、`H_id=0`、姿态单峰、`κ<τ_κ` 时：OGM 退化为点姿态、ABD 退化为硬指派、TSR 遇平凡群直接跳过、JCT 恒通过、SBI 退化为 MINT。故 ORBIT 与 R69 在任意状态上**逐指令相同**（λ、交互决策、前缀、执行序列）。一般情形下，ORBIT 只在 `G_eff` 非平凡且联合一致性通过时扩大动作/交互空间，故期望风险 ≤ R69；效率收益全部来自「可证明任务相关的对称」被正确利用、以及「可证明任务无关的对称」被正确跳过。R69 是 ORBIT 在「感知结构平凡」边界上的严格退化。

**定理 19（对称破缺交互的安全、无突变与单调退化）** SBI 的换视角/旋转/接触动作均经 C-RAS-WM 认证（含力/位/角限幅），物理风险 ≤ `ε_int`；ISS 迟滞使身份切换有界且经认证，故目标变化不会造成执行突变；若消解失败、门控越界、预算耗尽或 `κ` 超阈，λ 单调不降地退化为定义 320 的 R69 兜底；提交/换装不变式（R68 定理 15）保持。因此控制连续、安全侧永不弱于 R69。

## 6. 本轮最大风险

**一句话**：ORBIT-RAS 的全部收益押在**对称目录 `G_c` 正确、且「任务相关对称」判定正确**这一前提上——一旦把**真实的姿态差异误判成对称**（可形变、铰接、近似对称、被对抗纹理伪装），商空间会把危险差异当成「物理上相同的轨道」而抹掉，系统会自信地认为「这个歧义任务不在乎」，于是不探询、或朝错误的一侧抓取；反过来，把**无关对称误判为相关**则会白白耗尽预算并引入接触风险。**「把分不清误判为不必分清」，比单纯分不清更危险。**

**次级风险与缓解**：
1. **对称目录错误/近似对称**（形状公差、可形变、铰接）→ 目录带置信与版本号，`ECE_orb` + 等变检验门控，越界即退回 R69 保守；
2. **共谋盲区**（检测与姿态同向被欺骗）→ JCT 几何环残差 + `κ` 拦截 + 定义 324 的共谋对抗训练，绝不把边际置信当联合置信；
3. **身份切换突变** → ISS 迟滞 + 认证切换 + 单帧禁止，`H_id` 计入退避；
4. **对称破缺动作本身不安全**（旋转碰障碍、接触超力）→ C-RAS-WM 认证 + 预算 `ρ_max`/`f_max` + 定理 19 单调退化；
5. **实时预算被 MHT/多假设击穿** → `N_max` 剪枝 + 商空间假设合并 + JCG 廉价门控，被剪概率质量显式计入 `U_epi^eff`，不静默丢失。

## 3. 关键算法伪代码

```python
# IP-264 SGB：观测 → 联合场景假设
class SceneGraphBelief:
    def update(self, dets, poses, tracks):
        P    = self.abd.match(dets, tracks)                # 指派信念
        H_id = entropy(P)
        hyps = [(sigma, self.ogm.refine(dets, sigma), C)
                for sigma in top_matchings(P, K=4)]
        return hyps, normalize([self.jct.score(h) for h in hyps]), H_id

# IP-265 OGM：对称商姿态（不做欧氏平均）
class OrbitGeometryModel:
    def refine(self, dets, sigma):
        xi = self.pose_head(...); G = self.symmetry_catalog[category]
        modes = [g @ xi for g in G]; w = self.orbit_weights(modes)
        U_ale = sum(w[g] * trace(self.tangent_cov(modes[g])) for g in G)
        U_epi = entropy(w) * self.orbit_sep(modes)
        return OrbitBelief(karcher_mean(modes, w), w, U_ale, U_epi, G)

# IP-266 ABD：指派后验
def match(self, dets, tracks):
    return sinkhorn(-cost_matrix(dets, tracks) / self.tau, eps=0.05, iters=5)

# IP-267 JCT：结构性第二意见 + 共谋指数
def joint_consistency(h):
    return [epipolar_cycle_residual(h), rigid_motion_residual(h),
            contact_kinematic_violation(h), reprojection_cycle_residual(h)]

def collusion_index(conf_per_module, J_best_consistent):
    return max(conf_per_module) - sigmoid(J_best_consistent)

# IP-268 TSR：任务相关对称
def task_symmetry(G, task_cost):
    return quotient_group(G, {g for g in G if is_invariant(task_cost, g)})

# IP-269 SBI：对称破缺交互（稳定子动作必跳过）
def choose_symmetry_breaking(h, G_eff, budget):
    best = None
    for g in (g_view, g_rot, g_push, g_ask):
        if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
        if g.transform in stabilizer(h.xi, G_eff): continue          # VoI ≡ 0
        score = (orbit_entropy(h) - expected_orbit_entropy(h, g)
                 + OMEGA * (identity_entropy(h) - expected_identity_entropy(h, g))
                 - cost(g))
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None                 # 退化 R69

# IP-275 主闭环（继承 R69）
def ORBIT_RAS_round(M, obs):
    hyps, post, H_id = M.sgb.update(obs.detections, obs.poses, M.tracks)
    h = argmax(post, key=lambda h: (M.jct.score(h), post[h]))
    r_con, kappa = M.jct.residuals(h), M.jct.collusion(hyps, post)
    if kappa > TAU_KAPPA or max(r_con) > TAU_CON:
        return M.r69.fallback(h, reason="collusion")                # 联合不自治 → 最保守
    G_eff = M.tsr.reduce(h.G, M.task_cost)
    g = None
    if M.jcg.pass_gates(h) and not M.tsr.is_trivial(G_eff):
        g = M.sbi.choose_symmetry_breaking(h, G_eff, M.budget)
        if g is not None:
            h = M.jct.recheck(M.sgb.update_with(h, M.sbi.execute(g)))
    U_floor = h.U_ale + (0.0 if h.resolved else h.U_epi_eff + h.U_epi_id)
    lam = max(M.r69.risk_scale(h), lam_floor(U_floor))
    target = M.iss.select(h, M.tracks)                              # 迟滞 + 认证
    k = M.c_ras_wm.certified_prefix(M.ach.propose(target, M.vista.H), ..., M.wm_preds)
    mode = M.r69.select_mode(target, lam)
    M.vqa_s.submit_async(h, g, r_con, kappa)
    return k, lam, mode, (h.U_ale, h.U_epi_eff, h.U_epi_id)
```

## 4. 推导

**引理 19（商空间姿态的非欧性）** 轨道 `O=G·ξ` 的欧氏均值旋转部分一般不正交，故不在 `SE(3)` 内；对对称模态逐分量平均会静默产生非物理位姿。`Δ_orb≥3σ_in`（A99）时 Karcher/商均值唯一且在 `𝒬_c` 上。系：R69 的原型均值必须换成商均值，否则 `U_epi` 不可信。

**引理 20（对称破缺零 VoI 判据）** `T_g∈Stab_G(ξ̄)` ⇒ `p(y|g,g'ξ̄)=p(y|g,ξ̄)` ⇒ `VoI_G(g)=0`；反之 `T_g∉Stab` 且 `J_G(g)>0` ⇒ 小噪声下 `VoI_G(g)≥½log(1+J_Gσ²)−o(1)>0`。系：沿对称轴多看无效，横向移动/旋转/接触才可能破缺。

**引理 21（任务相关对称的预算节约）** `G_eff={e}` ⇒ `ℓ(a,gξ)=ℓ(a,ξ)`，交互只增成本不降任务风险，不交互弱占优。故 TSR 不削弱安全，只拒绝可证明无关的歧义。

**引理 22（联合一致性的共谋检测功效）** 误差分解 `e=e_ind+e_common`；A100 下边际置信对 `e_common` 不敏感，环残差 `‖r_con‖≥σ_min(J_c)‖e_common‖−ε`。故 `κ=置信−一致性` 可分离独立噪声与自信共谋，AUC ≥ 0.85。结构性约束是共模误差必须违反的几何法律，而非又一个同源证人。

**定理 18（ORBIT 严格包含 R69）** `G={e}, H_id=0`、姿态单峰、`κ<τ` 时，OGM→点姿态、ABD→硬指派、TSR→跳过、JCT→恒通过、SBI→MINT，故与 R69 **逐指令相同**；一般情形只在 `G_eff` 非平凡且联合一致时扩大动作/交互空间，期望风险 ≤ R69。R69 是 ORBIT 的「感知结构平凡」边界退化。

**定理 19（对称破缺交互安全、无突变、单调退化）** SBI 动作过 C-RAS-WM 认证 ⇒ 物理风险 ≤ `ε_int`；ISS 迟滞使身份切换有界且认证，目标变化无执行突变；消解失败/门控越界/超预算/`κ` 超阈时 λ 单调不降退化为 R69；R68 提交/换装不变式保持 ⇒ 控制连续、安全侧永不弱于 R69。

## 7. 本轮最大风险

**一句话**：ORBIT-RAS 的全部收益押在**对称目录 `G_c` 正确、且任务相关对称 `G_eff` 判定正确**这一前提上——一旦把**真实姿态差异误判成对称**（可形变/铰接/近似对称/对抗伪装），商空间会把危险差异当成「同一轨道」抹掉，系统会自信地认为「这个歧义任务不在乎」，于是不探询、或朝错误的一侧抓取；否则把无关对称误判为相关又白白耗尽预算并引入接触风险——**「把分不清误判为不必分清」，比单纯分不清更危险。**

**次级风险与缓解**：对称目录错误/近似对称（目录置信 + `ECE_orb` + 等变门控，越界退 R69）；共谋盲区（JCT 几何环残差 + `κ` 拦截 + ℰ_sym 对抗训练，拒绝用边际置信冒充联合置信）；身份切换突变（ISS 迟滞 + 认证 + 单帧禁止，`H_id` 计入退避）；对称破缺动作越界（C-RAS-WM 认证 + `ρ_max/f_max` + 定理 19 单调退化）；实时预算被 MHT 击穿（`N_max` 剪枝 + 商空间合并 + 被剪质量显式计入 `U_epi^eff`）。
