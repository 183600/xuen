# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「SLAM」×「决策规划」）

> R69 把不确定性一分为二，但它默认了一个前提：**世界模型（地图/观测表征）是给定的、正确的**。它问的是「我该向谁求证」（动作层），却没有问「**我在哪、这块地方我到底见过没有**」（地图层）。SLAM 指出：地图不是背景，而是一个被动作持续改写、跨时间共享、自身携带不确定性的**持久状态**；决策规划也不只是消费地图，它还是**唯一能减小地图不确定性的手段**（走到能看清的地方）。R70 把 R69 的二分从「动作不确定性」抬升到「**地图不确定性**」，并揭示二者共有的病灶：**被证实的错误**——R69 是被一句谎话证实，R70 是被一个长得像的地方证实。
>
> 核心命题：**地图不确定性同样分 aleatoric（几何/噪声，探访也消不掉，只能膨胀保守）与 epistemic（未探索、数据关联歧义、拓扑歧义，可规划去消解）；决策规划是地图层的「信息动作」；只有在预算内消解不了、或证据不独立、或地图过期时，才退化为 R69 的纯保守。** 命名 **ATLAS-RAS**（Active Topological-Localization-Aware Safe planning）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我在哪、这地方我真见过吗、该不该绕去看一眼**」——地图不是背景板，而是一个会撒谎、会过期、会被自己的猜测喂大的第二证人。

## 0. 直觉与动机

**灵感 1（SLAM → 地图是共享的、动作耦合的、持久的不确定性载体）**
直觉：动作不确定性是「此刻」的；地图不确定性是「历史积累」的。一次错误的回环闭合会把整张图折起来——你以为在 A，其实在 B，而地图会「自洽地」解释你看到的一切。SLAM 的独特之处在于：不确定性不在单个观测里，而在**关联（association）与拓扑**里。把地图后验写成「假设混合」{M_k, w_k}（不同数据关联/拓扑），恰好复用了 R69 流策略「多模态」的同一套数学：R69 是动作多峰，R70 是**地图多峰**。

**灵感 2（决策规划 → 规划是地图层唯一的信息动作，也是唯一的自证陷阱）**
直觉：不走到岔口，就永远分不清两条走廊。所以探索不是可选项，是控制的一部分：ASAP（active SLAM planner）把「去哪个视点/回环验证」当作 MINT 的信息动作在空间尺度上的推广——R69 是看/问/触，R70 是**走过去看一眼**。但同一枚硬币的背面：规划也会**选择那些能印证当前地图的视角**。如果地图错了，规划就会主动去收集「证明它对」的证据——这不是探索，是**确认偏误的自动驾驶**。

**灵感 3（地图不确定性也必须二分 → R69 是「地图固定」的退化）**
直觉：U_map 里，观测噪声/几何分辨率是 aleatoric（再去看也一样粗），未探索区域与关联歧义是 epistemic（去一次就能消）。R69 只在「地图已冻结且正确」时成立；R70 把地图固定当作边界情形：U_map^epi→0 时 ASAP 不动、λ_map→0，逐指令退化为 FLUID-RAS。**新层必须严格包含旧层**这条铁律从 R69 继承，链条变成 R70 ⊆ R69 ⊆ R68。

**灵感 4（感知别名 = 空间的谎言 → R69 投毒的空间版）**
直觉：R69 怕人撒谎；R70 怕**地方撒谎**——两条一模一样的走廊、镜像房间、动态的「长得像」目标。而且它比人更阴险：地图一旦接受错误关联，就会用后续观测把这个错误**越喂越可信**（残差变小、地图更「自洽」）。这与 R68 的「缓变故障被标定吸收」、R69 的「误导回答被盖上已验证的章」是同一病灶的第三种形态：**证据通道被错误假设俘获**。对策也必须是同一味药：正交证据 + **以证伪为目标**的验证（不是以确认为目标），且提交前只是假设、不写进已认证地图。

**灵感 5（安全 = 在最坏地图假设下的悲观包络）**
直觉：如果一张图可能错，那么基于它的「最优」轨迹就是一场赌博。安全做法不是选最可能的图去规划，而是要求轨迹在**所有足够可能的图假设下都可行**（共同的、悲观的安全包络），否则先去消歧或退回停/慢。这条「悲观包络」正是 R69「未消解 epistemic 视同 aleatoric」在地图层的镜像。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（ATLAS-RAS 总览）** ATLAS-RAS = (MUD, ASAP, FATE, RAMP, MLF, TMC, MFG, FMS, VQAuditor-M, AIC-ATLAS, RAS†)。三不变式：
(i) **控制环只读冻结认证地图**：实时控制只能读已认证快照 M†；一切地图写入先进影子地图 M̂，审计通过后**原子换装**（继承 R68 提交/换装不变式），实时环零全局优化；
(ii) **地图级信息预算硬约束**：单位时间/单位里程的回环验证与探索绕行有上限，且验证动作必须与任务动作一样过 C-RAS-WM 前缀认证；
(iii) **拓扑变更证据纪律**：单通道回环不得提交；需 ≥k 个正交证据一致，或通过「证伪测试」；未通过者的假设保留、不写入 M†。

**定义 311（地图后验 = 假设混合）** p(M|h_t) ≈ {(M_k, w_k)}_{k=1..K}，每个 M_k = (位姿图 G_k, 占据栅格 O_k, 路标 L_k, 关联 A_k)。假设间差异可来自数据关联（哪些观测是同一地点）、拓扑（连通性）与未观测占据。R69 的「动作多峰」在此变为「**地图多峰**」，同一套聚类/权重/间距工具复用。

**定义 312（冻结快照与影子换装 FMS）** M† = (G^*, Σ^*, cert^*) 为实时可见的认证快照；新观测只更新 M̂；当 VQAuditor-M 通过且 J_ATLAS 有效时，执行 M†←M̂ 的**原子替换**，旧证书作废、新证书重签。M† 在换装间隙不可被部分读取 ⇒ 控制连续、无半更新地图。这把 R68「提交/换装」从执行器推广到**认知状态**。

**定义 313（地图不确定性二分 MUD）**
- U_map^ale = Σ_k w_k tr(Σ_k^{local})：模态内几何/噪声不确定性（重访也不减，标定为真也仍在）。
- U_map^epi = H(w) + H_frontier + H_assoc：模态间可约不确定性。H(w)=−Σ_k w_k log w_k（拓扑/关联假设熵）；H_frontier = 可达边界内未观测栅格的占据熵；H_assoc = 别名集合上的关联熵（定义 314）。
- 二者分通道处置：U_map^ale → 几何膨胀（RAMP 的鲁棒半径）；U_map^epi → ASAP 去消解，残余进 λ_map（定义 318）。

**定义 314（感知别名与可判别性）** 地点描述子 d(p)；别名集 𝒜(p) = {q : d(q) ≈ d(p)}，别名熵 H_alias(p) = log|𝒜(p)|（最坏情形）。仅用外观做关联时，后验关联熵下界为 H_alias（看多少次都分不清）。正交通道集 𝒞 = {外观, 几何, 里程/时序, 语义/拓扑}；其联合信息可把关联熵压到 H_alias − I(𝒞)。可判别性 κ(p) = H_alias(p) − H_assoc(p) 度量「这地方值不值得专门去看」。

**定义 315（ASAP 主动 SLAM 规划器）** 轨迹 ξ 的信念空间目标：
J(ξ) = E_{M~p}[任务代价] + λ_risk·CVaR_δ(碰撞/违规风险 over {M_k}) − β·VoI_map(ξ)，
其中 VoI_map(ξ) = H(M|h) − E_{y~p(·|ξ,h)}[H(M|h,y)]，为「走这条轨迹后地图不确定性的期望下降」。
可选集要求：ξ 的前缀在**所有 w_k≥w_min 的 M_k 下**均通过 C-RAS-WM 认证。ξ* = argmin J；若 max(VoI_map/cost) ≤ 0 ⇒ 不绕行，直接按 R69 执行。

**定义 316（证伪优先的关联检验 FATE）** 对竞争关联假设 M_i、M_j，验证动作 ξ_v 的**判别增益**（而非确认增益）：
D(ξ_v) = ½ E[ KL(p(y|ξ_v,M_i)‖p(y|ξ_v,M_j)) + KL(p(y|ξ_v,M_j)‖p(y|ξ_v,M_i)) ]。
选 ξ_v* = argmax D/cost，**不选** argmax E[确认当前 MAP]。提交规则：后验赔率 > τ_odds **且** 观测似然未落在当前假设的「非证伪区」之外 **且** ≥k 正交通道一致。核心纪律：**以证伪为目的去看，而不是以确认为目的去看**（引理 20–21）。

**定义 317（歧义鲁棒规划 RAMP）** 对每个 w_k≥w_min 的场景 M_k 要求 P(collision|ξ,M_k) ≤ δ（或对混合取 CVaR_δ ≤ δ）。若不存在跨场景可行 ξ：要么先 ASAP 消歧，要么执行**共同安全包络**（所有假设下都安全的减速/停/回撤策略），绝不按最可能假设赌一把。这是「悲观包络」原则。

**定义 318（地图风险下限 MLF）** λ_map = λ_map(U_map^epi 未消解量) ∈ [0,1] 单调；最终风险 λ = max(λ_FLUID, λ_map)。地图歧义未消解处，几何代价膨胀、速度上限下调，**与任务紧迫性无关**。这是 R68 λ_floor 在地图层的镜像。

**定义 319（拓扑—度量风险级联 TMC）** 全局路由用拓扑信念（H_assoc、连通熵）；当 H_topo 高时，局部规划被约束到「再观测流形」上：减速、抬传感器、走走停停，禁止任何**预设了特定拓扑**的高速承诺。级联律：H_topo↑ ⇒ v_max↓、λ_map↑、验证优先级↑。

**定义 320（地图新鲜度与认知老化 MFG）** 区域 p 的陈旧度 τ(p) = 距上次观测的时间；世界变化率 κ 下，地图误差期望 ≥ f(κ·τ(p))。任务相关区域需 τ(p) ≤ τ_max，否则该区域**按未观测处理**（epistemic→保守），并触发再观测预算。防止系统无限期地吃一张已过期的认证地图。

**定义 321（地图投毒威胁模型 AIC-ATLAS）** ℰ_alias（感知别名、镜像地形、动态相似物）、ℰ_map_poison（伪造路标、注入假回环、篡改地图交换）、ℰ_drift（缓慢世界变化）。合并 ℰ_ATLAS = ℰ_FLUID × ℰ_alias × ℰ_map_poison × ℰ_drift。

**定义 322（参与式地图审计 VQAuditor-M）** 审计：关联是否单通道提交、验证是否在「寻求确认」、是否吃陈旧地图、影子→认证的换装是否合规、U_map^epi 是否被低报。结论回灌 AuditBuf，成为 ASAP 的成本/风险先验（与 R69 VQAuditor-I 同构）。

**定义 323（证书 J_ATLAS）** J_ATLAS = (J_FLUID, map_version_hash, Σ_consistency(NEES), U_map^epi_before/after, assoc_evidence_hash, D_verify, freshness_p95, λ_map, atlas_ver)。
Valid ⇔ Valid(J_FLUID) ∧ NEES ∈ χ² 置信带（协方差自洽） ∧ 拓扑证据纪律满足 ∧ 信息预算未越界 ∧ freshness_p95 ≤ τ_max。

**定义 324（严格包含 R69）** 当地图固定且可信（U_map^epi=0、所有 VoI_map ≤ 代价）时：λ_map=0、ASAP 返回原轨迹、RAMP 退化为单场景机会约束 ⇒ 逐指令等同 FLUID-RAS。故 R70 ⊆ R69 ⊆ R68：安全侧不让步，效率侧获得「地图分辨率 bonus」。

**定义 325（时间尺度与视界截断）** VoI 规划的视界 H 不得超过地图有效期：远区按未观测处理（对地图乐观、对执行悲观）；近区用认证快照。保证「规划视野」与「认知有效期」对齐，不拿远期幻觉地图驱动近期快动作。

## 2. 关键算法骨架

```python
# IP-264 MUD：地图不确定性二分（R69 的 AUD 上抬到地图层）
def decompose_map(belief, reachable):
    ale = sum(w * trace(cov(Mk.local)) for Mk, w in belief)
    epi = entropy([w for _, w in belief]) \
        + occupancy_entropy(unobserved(reachable)) \
        + association_entropy(belief)          # 定义 313/314
    return ale, epi

# IP-266 FATE：证伪优先的关联检验（不是确认优先）
def falsification_test(pairs, h):
    best = None
    for (Mi, Mj) in pairs:
        for xv in verification_candidates(Mi, Mj):
            if not c_ras_wm.certify(xv, under_all=[Mi, Mj]): continue
            D = sym_kl(pred_obs(Mi, xv), pred_obs(Mj, xv))   # 判别增益
            s = D / cost(xv)
            if best is None or s > best.s: best = (xv, s)
    return best          # 返回「去看什么最能证伪」，而非「最能印证」

# IP-265 ASAP：地图层信息动作（走到能看清的地方）
def choose_verification(belief, task, budget):
    if max_voi_map(belief, task) <= travel_cost(task): return None
    return argmin_traj(lambda xi: task.cost(xi)
                       + lam_risk * cvar_belief(xi, belief)
                       - beta * voi_map(xi, belief))

# IP-267 RAMP：悲观包络下规划（跨所有足够可能的图假设）
def robust_plan(belief, reachable):
    scenarios = [(Mk, w) for Mk, w in belief if w >= W_MIN]
    for xi in plan_candidates(belief):
        if all(chance_constraint(xi, Mk) <= DELTA for Mk, _ in scenarios):
            return xi
    return common_safe_envelope(belief)     # 跨场景共同可安全执行部分（减速/停/撤）

# IP-275 ATLAS 主闭环（继承 R69/R68，仅在地图/规划层插入 ATLAS 层）
def ATLAS_round(M, obs):
    Mt     = M.fms.snapshot()                 # 只读认证快照 M†
    ale, epi = M.mud.decompose_map(M.belief, M.reachable)
    voi      = M.asap.voi_map(M.belief, M.task)
    # 1) 有歧义且值得看 → 规划一次「证伪优先」的验证/回环
    xv = (M.fate.pick(M.belief) if (epi > TAU_EPI and voi > COST) else None)
    if xv is not None:
        M.fms.shadow_commit(xv.observations)  # 先入影子，不写认证图
    # 2) 悲观包络下规划；跨场景不可行则先消歧或退回共同安全包络
    xi = M.ramp.plan(M.belief, M.reachable)
    if xi is ROBUST_INFEASIBLE:
        xi = M.ramp.common_safe_envelope(M.belief)
    # 3) 地图级风险下限 + 拓扑→度量级联
    lam = max(M.fluid.lambda_floor(...), M.mlf.lambda_map(epi))
    if M.tmc.topology_entropy(M.belief) > TAU_TOPO:
        xi = M.tmc.constrain_to_reobserve(xi)     # 减速/抬传感器/走走停停
    # 4) 审计 + 原子换装（若影子审计通过）
    if M.vqa_m.audit(M.fms.shadow):
        M.fms.atomic_swap()                       # M† ← M̂，重签 J_ATLAS
    M.runtime.execute(M.fluid.certified_prefix(xi))
    return xi, lam, (ale, epi), M.fms.version
```

## 3. 推导

**引理 19（别名熵下界与正交证据增益）** 若地点仅以外观关联，且别名集大小 |𝒜|=A，则任意多外观观测后的关联熵 ≥ log A − ε（同分布描述子无法区分）；引入 k 个条件独立正交通道，关联熵可降至 ≤ log A − Σ I(𝒞_i; A)（下限至 0）。系：**外观再怎么看也分不清的地方，必须几何/时序去破**；这正是 FATE 选「判别通道」而非「更多同通道数据」的依据。

**引理 20（错误回环是自证的不动点）** 一旦提交错误关联 A_wrong，后续观测在条件于该地图时被解释为「自我一致」：新息 r_k 与 NEES 反而下降（地图越错越「平滑」）。因此 **(r_res↓, NEES↓) 不是正确性的证据**，与 R68 缓变故障被标定吸收、R69 谎言被盖章同构。唯一可靠证据是**提交前**的判别增益 D 与正交一致性，而非提交后的残差。⇒ 定义 316 的提交纪律。

**引理 21（证伪增益 ≠ 信息增益，且证伪更抗自欺）** 在别名区，两假设对外观的预测分布几乎重合，故最大化 VoI 的动作可能只增加「共同信息」而不降低关联不确定性；而最大化对称 KL（D）直接指向**预测分歧最大**的视角。故以 D/cost 选择验证，其单次把错误假设后验压低的速率 ≥ 以 VoI/cost 选择；当两假设可判别时 D>0 而 VoI 可≈0。系：**探索的目标函数应是「让两个可能的我分开」，不是「让我更确定我是我」**。

**引理 22（新鲜度下界）** 若探索/再观测频率 f < f_min(κ, τ_max)，则随 t→∞ 任务相关区域的老化误差 f(κ·τ) 无界；存在频率 f_min 使误差有界（与 κ、τ_max 成比例）。系：**再观测不是浪费，是维持地图可信度的必要成本**；MFG 的强制预算把这条下界变成硬约束。

**定理 18（ATLAS 严格包含 FLUID-RAS/R69，从而包含 CALM-RAS/R68）** 在 U_map^epi=0 或所有 VoI_map≤cost 或证据不独立/地图过期时，ATLAS 逐指令等同 FLUID-RAS（定义 324），故期望风险 ≤ R69 ≤ R68；安全侧不让步，效率侧获地图分辨率 bonus。链条 R70 ⊆ R69 ⊆ R68 闭合。

**定理 19（悲观包络安全）** 若规划 ξ 在所有 w_k≥w_min 的 M_k 下满足机会约束、且未消解地图 epistemic 经 λ_map 膨胀、且被丢弃假设的权重上界 Pr(M∉{M_k}) ≤ ε_h，则错误关联导致的碰撞概率 ≤ δ + ε_h；即「关联错」不能单独造成违规，除非出现权重被严重低报的未建模假设（此时由 VQAuditor-M 的 NEES 一致性兜底）。

## 6. 本轮最大风险

**一句话**：ATLAS-RAS 的全部收益押在「地图假设混合真实覆盖了世界」这一前提上——**最致命的失败不是地图有噪声，而是「幽灵地图」：一次感知别名下的错误回环被提交后，地图会自洽地解释后续观测（残差与 NEES 假性下降），而 ASAP 又会主动选择印证该错误地图的视角，形成自证循环；系统于是带着「已认证」的自信高速规划进一片实际未建图的空间——被一个长得像的地方证实，比被一个人撒谎更危险。**

**次级风险与缓解**：
1. **确认偏误被写进目标函数**（VoI 奖励共同信息）→ FATE 用判别增益 D 取代 VoI，只以证伪为目的、提交前不定案（定义 316、引理 21）；
2. **权重低报/未建模假设**（把真假设的 w_k 压到 w_min 以下）→ VQAuditor-M 的 NEES 一致性 + 被弃假设质量上界 ε_h 进定理 19，超界即拒绝认证快照；
3. **认证快照过期**（世界变了但图还「认证」着）→ MFG 新鲜度硬预算，τ(p)>τ_max 一律按未观测处理（定义 320、引理 22）；
4. **实时环被地图重算拖垮**→ FMS 只读快照 + 影子离线优化 + 原子换装，实时零全局优化（定义 312、定理 20）；
5. **跨场景规划不可行导致僵死**→ 明确降级为共同安全包络（减速/停/撤）并立即触发消歧，绝不按最可能假设强行通过（定义 317、定理 19）。

# IP-264 MUD：地图不确定性二分
def decompose_map(belief, reachable):
    ale = sum(w * trace(cov(Mk.local)) for Mk, w in belief)
    epi = entropy([w for _, w in belief]) \
        + occupancy_entropy(unobserved(reachable)) \
        + association_entropy(belief)
    return ale, epi

# IP-266 FATE：证伪优先（不是确认优先）
def falsification_test(pairs):
    best = None
    for (Mi, Mj) in pairs:
        for xv in verification_candidates(Mi, Mj):
            if not c_ras_wm.certify(xv, under_all=[Mi, Mj]): continue
            D = sym_kl(pred_obs(Mi, xv), pred_obs(Mj, xv))
            if best is None or D / cost(xv) > best.s: best = (xv, D / cost(xv))
    return best

# IP-265 ASAP：把「去看一眼」纳入规划
def choose_verification(belief, task):
    if max_voi_map(belief, task) <= travel_cost(task): return None
    return argmin_traj(lambda xi: task.cost(xi)
                       + lam_risk * cvar_belief(xi, belief)
                       - beta * voi_map(xi, belief))

# IP-267 RAMP：悲观包络（跨所有足够可能的图假设）
def robust_plan(belief):
    scenarios = [(Mk, w) for Mk, w in belief if w >= W_MIN]
    for xi in plan_candidates(belief):
        if all(chance_constraint(xi, Mk) <= DELTA for Mk, _ in scenarios):
            return xi
    return common_safe_envelope(belief)      # 减速/停/撤

# IP-275 主闭环（继承 R69/R68）
def ATLAS_round(M, obs):

          if (epi > TAU_EPI and M.asap.voi_map(M.belief, M.task) > COST) else None)

    xi = M.ramp.plan(M.belief)
    if xi is ROBUST_INFEASIBLE: xi = M.ramp.common_safe_envelope(M.belief)

## 4. 推导

**引理 19（别名熵下界与正交增益）** 纯外观关联时，`|𝒜|=A` 的别名区关联熵 ≥ `log A − ε`，看多少次都不降；k 个条件独立正交通道可降到 `≤ log A − Σ I(𝒞_i;A)`。系：外观分不清处必须用几何/时序去破。

**引理 20（错误回环是自证不动点）** 提交错误关联后，后续观测条件于该图被「自洽解释」，新息与 NEES 反而下降；故 `(r_res↓, NEES↓)` 不是正确性证据，与 R68 标定吸收、R69 谎言盖章同构。唯一可靠证据是提交前的判别增益 D 与正交一致性。

**引理 21（证伪 ≠ 信息，且更抗自欺）** 别名区两假设外观预测近乎重合，最大化 VoI 只增共同信息、不降关联不确定性；最大化对称 KL（D）直指预测分歧最大视角。故以 D/cost 选验证，单次压低错误假设后验的速率 ≥ 以 VoI/cost 选。

**引理 22（新鲜度下界）** 探索频率 `f < f_min(κ,τ_max)` 时长期老化误差无界；存在 f_min 使有界。再观测是维持地图可信的必要成本。

**定理 18（严格包含 R69/R68）** U_map^epi=0 或所有 VoI_map≤cost 或证据不独立/地图过期时，ATLAS 逐指令等同 FLUID-RAS；故风险 ≤ R69 ≤ R68。链条 R70⊆R69⊆R68 闭合。

**定理 19（悲观包络安全）** 若 ξ 在所有 `w_k≥w_min` 的 M_k 下满足机会约束、未消解 epi 经 λ_map 膨胀、被弃假设质量 `Pr(M∉{M_k})≤ε_h`，则错误关联致碰撞概率 ≤ `δ+ε_h`；关联错不能单独致违规。

**定理 20（换装无突变）** FMS 原子换装 + M† 只读 + 换装前重签证书 ⇒ 控制只看到一致地图快照；验证动作过 C-RAS-WM 后风险 ≤ ε_int；失败/超时/投毒时 λ_map 单调不降地退化为 R69；继承 R68 定理 15 ⇒ 控制连续、无突变。

## 7. 本轮最大风险

**一句话**：ATLAS-RAS 的全部收益押在「地图假设混合真实覆盖了世界」这一前提上——**最致命的失败不是地图有噪声，而是「幽灵地图」：一次感知别名下的错误回环被提交后，地图会自洽地解释后续观测（残差与 NEES 假性下降），而 ASAP 又会主动选择印证该错误地图的视角，形成自证循环；系统于是带着「已认证」的自信高速规划进一片实际未建图的空间——被一个长得像的地方证实，比被一个人撒谎更危险。**

**次级风险与缓解**：确认偏误写进目标函数（FATE 用判别增益 D 取代 VoI，提交前不定案，定义 316/引理 21）；权重低报/未建模假设（VQAuditor-M 的 NEES 一致性 + ε_h 进定理 19，超界拒绝认证快照）；认证快照过期（MFG 新鲜度硬预算，τ>τ_max 一律按未观测处理，定义 320/引理 22）；实时环被地图重算拖垮（FMS 只读快照 + 影子离线优化 + 原子换装，定义 312/定理 20）；跨场景不可行导致僵死（降级共同安全包络并立即消歧，定义 317/定理 19）。
