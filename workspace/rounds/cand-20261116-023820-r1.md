# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「多端口部署」×「动力学」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**可移植证书 + 动力学条件化 + 端口退化**。v9 已把退化链变成契约数据、把执行变成动作块，但它的安全余量 β、刹车距离 d_brake、冻结前向模型 F̂ 全部在**单一开发本体**上标定；换端口就是换动力学，证书的数值语义随之漂移。本轮要求：新端口的安全论证不重跑全部实验，而由**适配器组合 + 动力学敏感度 + 保形余量**从 v9 证书严格推出；任一端口能力缺失或辨识失败，必须注入中立元并严格退回 v9 单端口行为。

## 0. 直觉与动机

**灵感 1（多端口部署 → 端口是函子，不是环境变量）**
直觉：v9 的 E568 已出现"双机共享契约表"，但那只是**数据共享**，不是**证书共享**。真正部署到异构端口（差速轮 / 全向轮 / 轻量臂；不同质量、轮胎、驱动延迟、传感器套件）时，若每个端口都重跑 E551–E570，部署成本随端口数线性爆炸，且不同端口的"安全"不再可比。更优雅的做法：把端口差异压缩成四件可组合的事——能力 α_cap、信号 α_sig、动力学 R_θ、预算 Δβ——每件事一个适配器；证书像代码一样被"编译"到新端口。核心创新：**端口适配范畴 PortCat（IP-357）**：恒等适配器逐位复现 v9，适配器复合满足结合律，多跳迁移的余量按三角不等式可加。

**灵感 2（动力学 → 把参数不确定度直接烧进证书）**
直觉：安全证书里几乎所有"长度"都是动力学的函数。最简刹车距离 d_brake(v)=v²/(2a_max) 已隐含最大减速度 a_max；真实端口还要加驱动延迟 τ_a（刹车晚 τ_a 才生效）与摩擦限幅（a_max ≤ μg），负载又改变质量 m。与其"相信辨识、忽略误差"，不如**把动力学参数当作安全余量的一等自变量**：若证书判据 g_c 对 θ 的敏感度有界 L_c，参数可行集直径 ε_p 就能换算成余量 L_c·ε_p；未建模动力学再由保形分位数 q_{1−α} 以分布无关的有限样本覆盖吸收。核心创新：**动力学条件化余量 β_p = β_0 + L_c·ε_p + q_{1−α}（IP-359）** 与**集合成员 + 保形辨识（IP-358）**。

**灵感 3（多端口一致性 → 残差是保险丝）**
直觉：多端口同时部署时，两个端口可能对同一场景给出不同预测。差异本身不一定是错误（观测角度不同），但**未被察觉的差异**是危险的。把跨端口残差 ρ_pq 当作在线保险丝：超过阈值即双端保守化（K_eff←1、余量膨胀），而不是让某一端"自信地"继续。核心创新：**跨端口残差监控（IP-360）**——它是检测器而非证书，检测延迟有界，但不能替代安全论证。

## 1. 研究问题（轮次升级版）

- **Q1（可移植性）**：在什么适配器代数与动力学敏感度界下，一个在开发端口 p0 上成立的 v9 证书可以迁移到端口 p，且安全失效概率不超过 α？多跳适配的余量是否可加、可交换、可静态检验？
- **Q2（辨识可靠性）**：集合成员辨识在存在未建模动力学时如何避免"非空但排除真值"的静默失败？保形校准能否给出分布无关的覆盖保证，并把未建模项显式计入余量？
- **Q3（多端口并发）**：共享契约表、共享计划与共享算力下，端口间残差和资源竞争如何被隔离？一个端口的退化是否会通过共享状态污染另一个端口的证书？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 端口可移植律（Portable-Certificate Law, DCP）**
每个端口声明剖面 Π_p=(S_p,A_p,θ_p,λ_p,B_p) 与适配器 A_p。证书迁移规则：
```
β_p = β_0 + L_c·ε_p + q_{1−α},     ε_p = diam(Θ̂_p)
```
其中 β_0 为 v9 在 p0 的模型误差余量，L_c 为证书判据对 θ 的 Lipschitz 常数，q_{1−α} 为动力学残差的保形分位数。恒等端口（Π_p=Π_{p0} 且 A_p=id）必须逐位复现 v9。

**P14 动力学条件化律（Dynamics-Conditioned Margin, DCM）**
刹车距离、前向模型、WCET 均显式条件化于 θ：
```
d_brake(v;θ) = v·τ_a + v²/(2·a_max(θ)),   a_max(θ)=min(μ·g, k_b)
```
θ 的可行集 Θ̂_p 必须 sound（不排除真值）；未建模项不得被当噪声吞掉，而必须以保形分位数或残差包络进入 β_p。辨识失败 ⇒ 退回保守包络 Θ_max，等价 v9 最保守单端口配置。

**P15 端口退化律（Port-Neutral Degradation, PND）**
端口缺能力 ⇒ 对应模块注入中立元 v^⊥（复用 v9 表 536）；适配器复合失败 ⇒ 只用恒等适配器，退单端口 v9；跨端口残差超阈 ⇒ 双端 K_eff←1 且余量膨胀；任何端口级退化都必须落在 v9 五级退化格点内，安全性由 v9 引理 82–86 传递。

## 3. 与基线的接口（如何退化）

- 动力学辨识失效（Θ̂ 为空或覆盖检验失败）⇒ 用保守包络 Θ_max，β←β_max，K_eff←1，等价 v9 最保守单端口配置；
- 端口缺能力（无某传感器/执行器）⇒ 该模块注入 v^⊥，等价 v9 该模块超时；
- 适配器复合失败（α 不可组合 / 预算不可行）⇒ 仅保留恒等适配器，退单端口 v9；
- 跨端口残差超阈 ⇒ 双端 K_eff←1、β 膨胀 ρ_max，停止跨端口计划交换；
- v9 的 AC/MW/ID 任一失效 ⇒ 按 v9 五级链继续退 v8 / v7 / v6。

## 4. 预期贡献

1. **可移植证书**：把跨本体/跨端口的证书迁移从"重跑实验"变为"适配器组合 + 敏感度界 + 保形余量"，给出余量子可加性的代数结构；
2. **动力学条件化安全**：把辨识不确定度与未建模动力学显式写进证书余量，避免"辨识看起来很好、证书却静默失效"；
3. **多端口部署格**：PortCat 的恒等/结合/子可加性使部署路径可静态比较，CI 可在全端口格上验证最小余量；
4. **端口级反脆弱**：缺能力、辨识失败、跨端口分歧统一映射到 v9 退化格点，任何新端口都不会把系统带出已证明的安全包络；E571–E592 覆盖辨识、迁移、并发、退化与长跑。

## 5. 本轮最大风险

**一句话**：可移植证书的全部保证都压在"Θ̂_p 必须包含真值 θ_p"上，而最危险的失败不是辨识不准，而是**非空却排除了真值**——一旦未建模的接触/摩擦/延迟被当成有界噪声吸收，L_c·ε_p 会给出一个过小的余量，证书在新端口上"合法地"失效。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-DCP**（Metric Voice Gauge with Dynamics-Conditioned Portability，动力学条件化多端口可移植）

> 背景：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮灵感：「多端口部署」×「动力学」
> **继承纪律**：MetricVoiceGauge 九不变式（CVC-闭环、SpatialCert、RT-CVC、FaultCert、PrimitiveGraph、严格退化链、OTL、GCT、ER）与 v9 的 AC/MW/ID 全部原样保留。端口层一律为**可选增强**：恒等端口逐位复现 v9；端口能力缺失注入中立元；辨识失败退回保守包络。v10 只回答一个问题——**v9 的证书能否、以多大余量、在什么条件下被搬到另一个动力学不同的端口上**。

**退化链声明（v10 端口化六级）：**
- Level-0（正常）：可移植证书 C_{p,t} 有效，跨端口残差 ρ_pq ≤ ρ_max，各端口 EDF 可行；
- Level-1（残差/余量告警）：ρ_pq > ρ_max 或可移植余量 < 0 ⇒ 双端 K_eff←1、β←β_p，停止跨端口计划交换；
- Level-2（辨识失败）：Θ̂ 为空或保形覆盖检验失败 ⇒ 保守包络 Θ_max，β_max，K_eff=1，等价 v9 最保守单端口配置；
- Level-3（适配失败）：适配器不可复合 / 预算不可行 ⇒ 仅恒等适配器，退单端口 v9；
- Level-4（缺能力）：端口缺模块 ⇒ 中立元注入，等价 v9 该模块超时；
- Level-5（v9 链）：v9 AC/MW/ID 失效 ⇒ v8；DA/SPR/Cal 失效 ⇒ v7；全失效 ⇒ v6。

**新增定义 540（端口剖面 PortProfile）** 端口 p 的部署剖面 Π_p=(S_p,A_p,θ_p,λ_p,B_p)。S_p/A_p 为可用传感器/执行器能力集；θ_p∈Θ⊂ℝ^d 为动力学指纹；λ_p 为计算/通信剖面（CPU、传感时延、周期抖动上界）；B_p 为感知+决策的每周期预算。端口 p0 为开发端口，其 Π_{p0} 即 v9 的标定条件。

**新增定义 541（端口适配器与端口范畴 PortCat）** 适配器 A_{p→q}=(α_cap,α_sig,R_θ,Δβ)：α_cap 把 q 不可用的能力映射到中立元；α_sig 完成单位、坐标系、时间戳对齐；R_θ 把动力学参数从 p 的可行集搬到 q 的可行集；Δβ 为迁移新增余量。要求：
```
A_{p→p} = id_p = (id, id, id, 0)                     （恒等）
A_{q→r} ∘ A_{p→q} = (α_cap^r∘α_cap^q, α_sig^r∘α_sig^q,
                      R_θ^r∘R_θ^q, Δβ_{p→q}+Δβ_{q→r})
```
即端口构成范畴 PortCat：对象是端口，态射是适配器，恒等与结合律成立。

**新增定义 542（动力学指纹与可行集 DynamicsFingerprint）** 连续时间模型 ṡ=f(s,a;θ)+w，‖w‖≤w_max。辨识器维护椭球/多面体可行集 Θ̂_p(t)，并按集合成员规则更新：
```
Θ̂_{t+1} = Θ̂_t ∩ { θ ∈ Θ : ‖ y_t − h(s_t,a_t;θ) ‖ ≤ w_max }
```
soundness 要求：若 θ_p∈Θ̂_0 且噪声有界，则 θ_p∈Θ̂_t 对所有 t 成立。直径 ε_p 以证书相关方向加权：ε_p = max_{θ,θ'∈Θ̂_p} ‖θ−θ'‖_W。

**新增定义 543（证书敏感度与动力学条件化余量）** 对任一证书判据 g_c（如 ĝ_min、d_brake、预测间隙），定义
```
L_c = sup_{s,a,θ∈Θ_max} ‖ ∇_θ g_c(s,a;θ) ‖_*
```
并对端口 p 定义可移植余量
```
β_p = β_0 + L_c·ε_p + q_{1−α}
```
其中 q_{1−α} 由跨端口校准集上的残差 { |g_c^{real} − g_c^{pred}| } 的保形分位数给出。三项分别对应：开发端口模型误差、参数迁移误差、未建模动力学/分布偏移。

**新增定义 544（可移植证书 PortableCertificate）** C_{p,t}=(Ĉ_t, θ̂_p, Θ̂_p, β_p, 1−α)。在端口 p 上有效当且仅当
```
ĝ_min^{p} − β_p ≥ d_safe  ∧  ê_max^{p} + β_p ≤ τ_eff  ∧  γ̂_grasp = valid
∧ Δ_dom < τ_dom  ∧  risk_SLAM < τ_SLAM  ∧  ρ_pq ≤ ρ_max
```
即 v9 的五条件块证书，把 β 替换为 β_p，并追加跨端口残差条件。

**新增定义 545（跨端口残差 CrossPortResidual）** 当端口 p、q 执行/观测同一任务片段时，
```
ρ_pq(t) = ‖ ŷ_p(t) − ŷ_q(t) ‖ / max(1, scale(t))
```
ŷ 为证书相关预测（间隙、速度、停止距离）。ρ_pq 是**检测统计量**，不是安全证书：它只能发现已显现的分歧，不能证明未显现的一致。

**新增定义 546（端口慢化因子与预算缩放 PortSlowdown）** s_p=(Ŵ_p+λ_p^{comm})/(Ŵ_{p0}+λ_{p0}^{comm}) 为该端口相对开发端口的慢化因子。端口 p 的契约表按
```
Ŵ_m^p = s_p·Ŵ_m,   D_m^p = s_p·D_m,   准入需 Σ_m Ŵ_m^p ≤ B_p
```
缩放；缩放后 EDF 可行性由引理 92 保证。慢化只影响调度，不改变证书语义。

**新增定义 547（部署格与端口准入 DeploymentLattice / PortAdmission）** 节点为端口，边为适配器，路径 p0→p* 的组合余量为
```
Δβ(p0→p*) = Σ_{e∈path} Δβ_e
```
准入端口 p 需同时通过：(i) 能力检查（缺失项→中立元）；(ii) Θ̂_p 保形覆盖检验（在留出端口上覆盖率 ≥1−α）；(iii) 预算/EDF 检查 Σ_m Ŵ_m^p ≤ B_p；(iv) 可移植余量 β_p 使证书有效；(v) ρ 监控已上线。任一失败 ⇒ 降级准入（Level-1..4）。

**新增定义 548（保守包络与失败回退 ConservativeEnvelope）** 令 Θ_max = Conv(∪_{p∈P_known} Θ̂_p)。辨识失败时令 β←β_max = β_0 + L_c·diam(Θ_max) + q_{1−α}^{max}，并令 K_eff←1；此时 v10 退化为 v9 的逐步保守执行，不再依赖任何新端口参数。

**新增定义 549（保形动力学分位数 ConformalDynamicsQuantile）** 给定 n 个可交换校准残差 R_1..R_n，取
```
q_{1−α} = R_{(⌈(n+1)(1−α)⌉)}   （排序后第 ⌈(n+1)(1−α)⌉ 小；越界取 max）
```
则在可交换性下 P(R_{n+1} ≤ q_{1−α}) ≥ 1−α，无需高斯/有界噪声假设；用于吸收未建模动力学。校准集必须来自**非部署端口**的留出数据，防止乐观偏差。

## 2. 形式化定义（要点与升级）

**定义 493（六层指标层级）** 继承 v9：(M₀,M₁,M₂,M₃,M_dom,M_SLAM) 不变。
**定义 495/524（MetaWeight/情感，5 维）** 继承 v9 不变。
**定义 521（DA-OTL）** 继承 v9 不变；τᵢ(t) 的逐步复核在 K_eff>1 时仍由块证书代理。
**升级定义 533（块证书，v10）** 前向模型由 F̂ 变为 F̂_{θ̂_p}，余量由 β 变为 β_p；证书的三元组 Ĉ_t=(ĝ_min,ê_max,γ̂_grasp) 语义不变。

@dataclass
class PortProfile:
    name: str
    caps: frozenset                 # {'lidar','depth','gripper',...}
    theta_nominal: dict             # {'m','mu','tau_a','k_b','J'}
    latency_ms: float
    budget_ms: float


class DynamicsIdentifier:
    """集合成员辨识 + 保形校准；输出 θ̂、Θ̂、ε、q。"""
    def __init__(self, theta0, w_max=0.02, alpha=0.05):
        self.Theta = Ellipsoid(center=theta0, shape=np.eye(len(theta0)))
        self.w_max, self.alpha = w_max, alpha
        self.residuals = []

    def update(self, s, a, s_next, dt):
        pred = self.f(s, a, self.Theta.center, dt)
        r = s_next - pred
        if np.linalg.norm(r) > self.w_max:
            self.Theta.project_inward(r, self.w_max)   # 集合成员交集
        self.residuals.append(np.linalg.norm(r))
        if self.Theta.is_empty():
            return None                                # 触发保守包络（定义 548）
        return self.Theta.center

    def epsilon(self, weight):
        return self.Theta.diameter(weight)

    def conformal_q(self):
        n = len(self.residuals)
        k = min(n - 1, math.ceil((n + 1) * (1 - self.alpha)) - 1)
        return sorted(self.residuals)[max(0, k)]


class CertificateReparameterizer:
    """定义 543：把动力学不确定度烧进证书余量。"""
    def __init__(self, beta0, L_c, g=9.81):
        self.beta0, self.L_c, self.g = beta0, L_c, g

    def a_max(self, theta):
        return min(theta['mu'] * self.g, theta['k_b'])

    def brake_distance(self, v, theta):
        return v * theta['tau_a'] + v * v / (2.0 * self.a_max(theta))

    def beta_port(self, eps, q_conf):
        return self.beta0 + self.L_c * eps + q_conf


class PortabilityOrchestrator:
    """定义 541/547：端口范畴、部署格与准入。"""
    def __init__(self, base_port, adapters, identifier, reparam, cert):
        self.base, self.adapters = base_port, adapters
        self.idt, self.rp, self.cert = identifier, reparam, cert

    def path_margin(self, path):
        return sum(self.adapters[(u, v)].delta_beta
                   for u, v in zip(path, path[1:]))

    def admit(self, port):
        if not self.base.caps <= port.caps:
            return AdmitResult('degraded-neutral',      # 缺能力→中立元
                               missing=self.base.caps - port.caps)
        theta_hat = self.idt.update_from_port(port)
        if theta_hat is None:
            return AdmitResult('conservative', beta_max=self.beta_max())
        eps = self.idt.epsilon(weight=self.rp.cert_weight)
        q = self.idt.conformal_q()
        beta_p = self.rp.beta_port(eps, q)
        if not self.edf_feasible(port):
            return AdmitResult('single-port-v9')        # 适配失败→v9
        if not self.cert.valid_with(beta_p):
            return AdmitResult('reject', beta_p=beta_p)
        return AdmitResult('admitted', theta_hat=theta_hat, beta_p=beta_p)


class PortResidualMonitor:
    """定义 545：检测器，不是证书。"""
    def __init__(self, rho_max=0.05):
        self.rho_max = rho_max

    def observe(self, y_p, y_q, scale):
        rho = np.linalg.norm(y_p - y_q) / max(1.0, scale)
        if rho > self.rho_max:                          # Level-1
            self.enter_conservative(p='p', q='q', rho=rho)
        return rho

## 4. 推导

**引理 87（端口范畴：恒等、结合、余量子可加）** PortCat 中 id_p 是双边恒等；适配器复合满足结合律；对任意路径 p0→p1→p2，
```
A_{p0→p2} = A_{p1→p2} ∘ A_{p0→p1},   Δβ_{p0→p2} ≤ Δβ_{p0→p1} + Δβ_{p1→p2}
```
证明：α_cap、α_sig、R_θ 均为映射，复合天然结合；id 逐分量恒等且 Δβ=0，故恒等端口逐位复现 v9。余量项由 L_c 的链式法则与三角不等式给出上界，复合时取各边上界之和即得子可加性。∎

**引理 88（动力学条件化证书迁移）** 设 (A1) θ_p∈Θ̂_p；(A2) 对证书判据 g_c，|g_c(θ)−g_c(θ̂)| ≤ L_c‖θ−θ̂‖_W 对 θ∈Θ̂_p 成立；(A3) 保形残差满足 P(R≤q_{1−α})≥1−α；(A4) v9 在 p0 上以 β_0 有效。则取 β_p=β_0+L_c·ε_p+q_{1−α}，v9 引理 82 的安全结论可迁移到端口 p，单块失效概率 ≤α（对 K 步用 Bonferroni 取 α/K）。证明：由 (A2) 与 ε_p 定义，参数迁移误差 ≤L_c·ε_p；由 (A3) 未建模项以 ≥1−α 被 q 覆盖；与 (A4) 的 β_0 相加得 β_p。将引理 82 中的 β 替换为 β_p，其 (i)(ii) 的推导只用到"真实值落在预测±β 内"，故逐条成立；对块内 K 个判据做联合界即得 α。∎

**引理 89（集合成员辨识的 soundness 与空集告警）** 若噪声有界 ‖w‖≤w_max、初始 θ_p∈Θ̂_0、更新为与一致集的交，则 θ_p∈Θ̂_t 对所有 t 成立（不会静默排除真值）。若模型类错误设定出现未建模动力学，则只可能发生两种可观测结局：(i) Θ̂ 变空 ⇒ 显式回退保守包络 Θ_max（定义 548）；(ii) Θ̂ 非空但有偏 ⇒ 留出端口的保形覆盖检验以 ≥1−α 的概率失败 ⇒ 拒绝准入。故静默失败仅剩"覆盖检验假通过"，其概率由保形保证约束在 α 量级。证明：归纳法验证交集保持 θ_p；空集由 is_empty 检测；覆盖检验失败概率由定义 549 直接给出。∎

**引理 90（跨端口残差检测的延迟界；非证书）** 若 ρ_pq 每控制周期基于同步观测计算一次，则任何超过 ρ_max 的已显现分歧在 ≤1 个控制周期内被检测，检测后双端进入 Level-1 保守模式。该引理**不**保证未显现分歧的安全，因为不同视角/遮挡可使 ρ_pq 在危险存在时仍然很小；它只提供检测时延与降级动作的确定性。证明：监控器在主循环每周期执行一次，阈值比较即时。∎

**引理 91（端口退化等价）** 端口级四类失败均落在 v9 退化格点内：缺能力→v^⊥（v9 引理 83）；适配失败→恒等适配器单端口 v9；辨识失败→β_max + K_eff=1（v9 最保守配置）；残差超阈→双端 K_eff=1。故任意端口失败下系统行为 ∈ v9 退化格点，安全性由 v9 引理 82–86 传递成立。∎

**引理 92（多端口 EDF 隔离与 50Hz 守恒）** 各端口独立运行 EDF，WCET/截止期按 s_p 缩放；若对每个 p 有 Σ_m Ŵ_m^p ≤ B_p，且端口间只共享**只读**契约表、可写状态采用 copy-on-write，则每个端口保持自己的 50Hz，超时模块注入 v^⊥；端口间不存在共享硬截止期，故无跨端口优先级反转。证明：单端口 EDF 可行性由 v9 引理 86；只读共享不引入阻塞；copy-on-write 把跨端口写冲突转为版本合并，不延长本端口周期。∎

## 9. 本轮最大风险
