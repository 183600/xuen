# 第 3 轮（研究线累计；灵感循环新循环第 1 轮；本轮灵感：「实时性」×「嵌入式系统」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440），
> 其继承第 1 轮 **LeanGauge**（IP-310–314；定义 398–415；引理 42–45；实验 E411–E425）。
> 本轮纪律：**继续在前人基础上改进，而不是推倒重来**——MODGAUGE 五不变式、MTC/TCV 工具契约、
> 双层下注、AP-Cal 摊销校准、6C 闭环、语言-数值隔离与严格退化链全部保留。
> 本轮只攻击 ToolGauge 的两个**部署假设**：
> (i) 「修复可以无限期异步化，且异步不产生资源竞争」——但端侧 CPU/NPU/总线/功耗是共享的；
> (ii) 「数值层是精确的、内存是无限的、故障是良性的」——但定点量化、有限 RAM、掉电与热降额会改变后验本身。
> 一句话：ToolGauge 证明了「修复在**逻辑上**安全」；本轮要证明「修复在**真实端侧机器**上、在**截止期之内**、
> 用**可表示的数值**依然安全」。

## 0. 直觉：为什么「异步」不是「免费」，「正确」不是「可部署」

### 0.1 ToolGauge 的两个未言明假设

ToolGauge 引理 50 说：6C 闭环全部位于 50Hz 计量路径之外，异步执行，因此硬实时保持。这个论证有一个隐藏前提：
**异步任务对主路径没有共享资源干扰，且自身时延可以被 τ_repair 任意界定**。在数据中心里这近似成立；
在一颗端侧 SoC 上不成立：

1. **计算资源竞争**：VLA 前向 0.2–0.8 s、AP-Cal 单前向 <10 ms、回执签名/哈希、语言证书序列化，
   全部与 C0 控制回路共享 CPU 核、NPU、L2/DRAM 带宽与功耗预算。一个「后台」VLA 推理可以把 C0 的
   cache 全部冲掉，使其 WCET 翻倍。
2. **调度不确定性**：「异步」在 RTOS 里意味着某个优先级、某个预算服务器、某次中断屏蔽。没有响应时间分析
   （RTA），τ_repair 只是一个愿望，不是上界。
3. **过载不是概率问题**：当多个盲区同时触发修复，ToolGauge 的「每盲区至多一次在飞」只限制了并发数，
   没有限制总带宽；排队时延可以无限增长，而安全论证假设它有限。

第二个假设更隐蔽：AP-Cal 的 `mu, Sig` 与契约回归测试都按实数、float64、无限精度历史书写。端侧部署时：

- **定点/量化**：MP-Φ 必须量化到 INT8/INT16 或 NPU 的定点格式；量化误差会系统性地改变 `Σ`，
  可能把「保守」变成「过度自信」。
- **有限内存**：回执与假设集不能无限增长；一旦淘汰历史，后验就不再是原来那个后验。
- **良性故障假设**：掉电可能发生在热替换的中间态，把 EC 写坏；热降额会改变 WCET；看门狗复位可能留下
  半提交的契约。

所以本轮的核心不是再发明一个校准器，而是给 ToolGauge 的每一次修复加上**四重包络证书**：
时间、数值、内存、失效。

### 0.2 三个直觉

**直觉 1（实时性 → 修复必须是一个「可调度对象」，而不是一个「后台线程」）**
实时系统的第一性原理不是「快」，而是「可预测」：给定任务集、优先级、预算服务器与 WCET，能在部署前
回答「最坏情况下 C0 是否仍然满足 20 ms 截止期」。因此修复程序 Π_s 必须像控制任务一样被准入：
它要在 TCV 阶段就通过 RTA，而不是执行到一半才发现超时。更进一步，修复的**降级**也必须是确定性的：
同一个故障，在任何时刻、任何负载下，都产生同一个安全动作。

**直觉 2（嵌入式系统 → 数值正确性必须包含「表示误差」，而不是假设实数）**
安全论证的逻辑链是「后验 σ 不小于物理噪声底 ⇒ 契约保守 ⇒ 热替换安全」。定点量化破坏的正是这条链的第一环。
解决办法不是「用更高精度」，而是**把表示误差显式提升为协方差的一部分**：任何进入契约的浮点数都携带一个
区间 `[x−δ, x+δ]`，量化后的后验必须在 Loewner 序上支配真实后验；否则拒绝替换。
也就是把「数值表示」纳入契约，而不是当作实现细节。

**直觉 3（实时性 × 嵌入式 → 时间、数值、内存、失效四个包络必须联合签发）**
单独看每个包络都不够：一个满足 WCET 的修复可能用了会溢出的定点数；一个数值保守的修复可能因为掉电把 EC
写坏；一个内存有界的修复可能因为热降额而超时。因此热替换只接受一张**联合证书 TNM-Cert**：
同一份 `(Π_s, receipts, EC)` 必须同时通过时序准入、数值包络、内存上界与原子提交四条检查。
任何一条不通过，就按确定性退化矩阵降级，而不是「尽力而为」。

### 0.3 一句话押注

> **把 ToolGauge 的「逻辑上安全的局部修复」升级为 TEMPOGAUGE 的「在端侧实时包络内可认证的局部修复」：
> 时序上可调度、数值上可支配、内存上有界、失效上原子。**

## 三位一体映射（本轮两个灵感词 + 一条交叉轴）

| 灵感词 | ToolGauge 的隐含假设 | 升级为 | 一句话动机 |
|---|---|---|---|
| 实时性 | 50Hz 路径不动 + 修复异步（引理 50） | **MC-3 三级临界性 + TI-Sched 时间隔离 + RTA 准入** | 「异步」不是「无干扰」；修复必须被证明不会推迟 C0 的截止期 |
| 嵌入式系统 | 抽象资源模型（O(·)、float、无限内存） | **QA-Cal 量化感知校准 + BMR 有界内存 + AHR 原子回滚 + TEE 热/能降额** | 端侧不是数据中心的缩小版；数值证明必须穿过定点与有限内存 |
| 交叉（实时 × 嵌入式） | 时间与数值彼此独立 | **TNM-Cert 四重包络联合证书** | 只有 WCET、量化误差、内存足迹、掉电一致性同时被认证，契约才允许热替换 |

**核心命题**：
把 ToolGauge 的「语义假设 → 契约化工具调用 → 摊销校准 → 交叉验证后局部热替换」升级为
「**在端侧实时包络内**：准入 → 有界执行 → 量化保守校准 → 原子热替换 → 确定性降级」。
TEMPOGAUGE 不改变 6C 的逻辑结构，而是在每个阶段插入一个**可检查的包络**：
H/C 阶段做可调度性与内存准入；E 阶段做预算服务器与看门狗；C 阶段做量化误差传播；
V 阶段做实时交叉验证；U 阶段做 A/B 原子提交；失败时走确定性退化矩阵。

**不变式保持与扩展**：
- MODGAUGE 五不变式全部保留；
- **新增时序确定性不变式 TDI**：C0 回路的 WCET 与 C1/C2 的到达模式无关；任何修复都不得使 C0 错过截止期；
- **新增数值包络不变式 NEE**：进入契约的每个数都带区间；量化后验必须在 Loewner 序上支配真后验，
  否则拒绝热替换；
- **新增内存有界不变式 MBE**：临界路径无动态分配，所有缓冲与统计量有编译期常数上界；近似误差计入 NEE；
- **新增失效原子不变式 FRI**：任何掉电/复位/超时后，EC 只能处于 old 或 new，不能是中间态；
  同一故障类映射到同一退化动作；
- **严格退化链延长**：TEMPOGAUGE（C0+C1+C2）⇒ LeanGauge-tiny（C0+C1-light，定点、静态、纯数值）
  ⇒ MODGAUGE（仅 C0）。VLA 与 AP-Cal 只在 C2/C1 的包络通过时存在；它们永远是增强项，不是依赖项。

## 1. 形式化定义（增量：定义 432–447）

**定义 432（实时计量工具契约 WC-MTC）** 在定义 416 基础上，工具
t = (Schema_t, Pre_t, Post_t, C_t, M_t, E_t, κ_t, τ_t, Ĝ_t)：
- C_t：最坏执行时间上界（含缓存/总线干扰的最坏情形），单位 µs；
- M_t：静态内存足迹上界（栈 + 静态缓冲），单位 B；
- E_t：单次调用能量上界，单位 mJ；
- κ_t ∈ {C0, C1, C2}：工具所属临界性等级；τ_t：该调用的相对截止期；
- Schema/Pre/Post/Ĝ 沿用定义 416。原标量代价 `c_t` 被展开为向量 (C_t, M_t, E_t)，不再是一个归一化数。

**定义 433（三级临界性 MC-3）**
- C0（计量/控制，hard）：50 Hz，D0 = 20 ms，零截止期错过；只做读、轻量校验与指针切换；
- C1（探测/修复，firm）：非周期，D1 = τ_repair（默认 2 s）；超时允许放弃，但放弃必须原子回滚；
- C2（学习/推理，soft）：VLA 前向、AP-Cal 重训、预训练更新；无截止期，只在 C1/C0 的 slack 中运行，
  可被随时抢占或丢弃。
6C 阶段映射：H、C、E、V 主要落在 C1（必要时用 C2 缓存）；校准 C 若超过 C1 预算则降级到 C2；
U 的提交必须在 C1 的临界区完成，但读侧（C0）只做原子指针读。

**定义 434（时间隔离调度 TI-Sched）** C0 采用最高优先级的固定优先级抢占调度；C1/C2 由一个周期资源
服务器（PRM/CBS）供给，服务器带宽 U_s，周期 T_s，预算 Q_s（U_s = Q_s/T_s）。C0 可抢占服务器，
服务器不可抢占 C0。调度配置满足
U0 + U_s ≤ 1 − μ_res，μ_res 为中断、DMA、总线与临界区阻塞预留的余量。
C0 的最坏响应时间按 RTA 计算：R0 = C0^WC + B0 + Σ_{hp}⌈R0/T⌉C_hp；由于 C0 最高优先级，hp = ∅，
只剩阻塞项 B0。

**定义 435（实时准入 SAT）** 对探测程序 Π_s，SAT(Π_s) 逐条检查：
① 继承 TCV 的 schema/前置/循环检查（定义 418）；
② **可调度性**：按 κ_t 分组，用 RTA 验证每组响应时间 ≤ 其截止期；
③ **利用率**：U0 + U_s + Σ_{C1} C_t/D1 + Σ_{C2} C_t/T_s ≤ 1 − μ_res；
④ **内存高水位**：max_t (M_t + M_ctx) ≤ M_budget；
⑤ **能量预算**：hyperperiod 内 Σ E_t ≤ E_budget；
⑥ **数值可表示性**：所有参数与输出落在预注册定点范围内（定义 437）。
任一失败 ⇒ 拒绝该程序，**在产生任何物理副作用之前**退化；禁止「先执行再发现」。

**定义 436（量化感知保守校准 QA-Cal）** 部署的 MP-Φ 是一个定点/量化网络 q_θ，附逐层误差界：
对任意输入，|q_θ(x) − MP-Φ_θ(x)| ≤ δ_μ（均值），且协方差的每个元素满足 |Σ_q − Σ_θ| ≤ Δ_Σ。
**保守化**：用区间/仿射算术计算方差下界，令
Σ_c = max(Σ_q, Σ_lower) + (ε_q² + 2Δ_Σ)·I，
并要求 Σ_c ≽ (κ_phys² + q_floor²)·I。
只要 Σ_c 在 Loewner 序上支配浮点后验 Σ_θ，量化后的契约就是保守的；若无法给出该支配关系，拒绝校准。
舍入模式固定为 round-to-nearest-even，随机种子在构建期固定，保证回执可复现。

**定义 437（定点契约序列化 FCS）** 契约参数以定点数存储，附 (scale_u, δ_u, crc)：
u_s 的每个分量 u_i 满足 |u_i − û_i| ≤ δ_u；契约回归测试在定点域重跑；
若 δ_u 导致安全裕度下降超过 Δ_margin，则拒绝该契约。
**数值表示是契约的一部分**：改变 scale 等同于改变契约，必须重新走 V/U。

**定义 438（有界内存回执 BMR）** 不为每个盲区保存无界回执历史，而维护一个固定大小的充分统计量 Z_s：
- 高斯情形：Z_s = (精度矩阵 Λ_s ∈ R^{d×d}, 均值向量 η_s)，大小 O(d²)，与回执条数无关；
- 非高斯情形：容量为 B_r 的加权 coreset，附认证近似误差 ε_sk。
任何合并/淘汰必须满足**保守膨胀**：Σ_sketch ≽ Σ_full − ε_sk·I，且均值漂移 ≤ δ_μ。
B_r、d 与 ε_sk 均在构建期固定；运行期不允许改变。

**定义 439（原子热替换 AHR）** EC 采用双缓冲 A/B + 版本号 + CRC + 日志：
写非活动缓冲 → 刷写非易失存储 → 校验 → 在关中断 ≤ 1 µs 的临界区内原子切换指针。
掉电/看门狗复位后，bootloader 只选择 CRC 有效的最后一个缓冲；若两者皆无效，进入安全默认 EC。
保证 old-or-new，禁止 torn contract。

**定义 440（确定性退化矩阵 DDM）** 退化是一个全函数
DDM: (Fault, Mode) → Action，Fault ∈ {deadline_miss, wcet_overrun, power_loss, thermal_throttle,
ood, cross_timeout, bit_flip, mem_high}，Mode ∈ {C0, C1, C2}。
动作集合 = {continue, drop_C2, rollback, stub+RED, safe_stop}。同一故障在任意时刻、任意负载下
必须映射到同一动作；禁止随机/自适应退化。

**定义 441（热-能-时耦合包络 TEE）** 定义降额因子 ρ(Θ, f, V) ∈ (0,1]，WCET 随降额放大：
C_t(ρ) = C_t^0 / ρ。要求在最坏热工况 ρ_min 下 C0 仍可调度；C1/C2 仅在热余量与能量预算允许时启动。
能量是一等预算：每次修复消耗 E_repair ≤ E_budget；连续修复不允许耗尽电池安全裕度。

**定义 442（实时预算契约 RTB-Contract）** RTB = (D0, D1, U_s, T_s, Q_s, M_budget, E_budget, ρ_min, recovery)：
四维预算（时间/内存/能量/热）与恢复条件；是 TB-Contract（定义 424）的实时化细化，
时序结论继承并强化引理 45/50。

**定义 443（实时交叉验证 RCV）** V 阶段的独立 cross.modal 回执必须在 D_V 内到达（D_V ≤ D1）；
**超时不等于通过**：超时即 V 失败。交叉回执还必须来自不同的资源域（不同传感器/不同总线/不同核），
以排除共因时序故障。

**定义 444（时序质量证书 QoT）** 在 RepairCert（定义 427）上增加
(R_i^WC, δ_num, M_peak, E_used, ρ_min, commit_ver)，
每个字段由运行时监控测量并签名。任何主张若引用了超过声明上界的数值，整条证书作废
（扩展定义 423 的主张绑定）。

**定义 445（端侧退化阶梯 EDL）**
- 若 SAT 失败且 D1 内无法修复 ⇒ 退到 **LeanGauge-tiny**：定点 GP、静态内存、仅被动/轻量工具、
  无 VLA/AP-Cal；
- 若 LeanGauge-tiny 仍不满足 U0 + U_s ≤ 1 − μ_res ⇒ 退到 **MODGAUGE**：关闭所有主动探测，只保留 C0；
- 任何一级退化都必须写 RED 事件并排队人工；退化动作由 DDM 唯一确定。

**定义 446（静态配置闭合 SAC）** 任务参数、工具表、量化 scale、缓冲大小、随机种子、调度表全部在
构建期固定；运行期只允许在维护模式下、验签通过后更新镜像；临界路径禁止动态内存分配（malloc/free）、
禁止运行期改优先级。目的：消除配置漂移与不可复现的抖动。

**定义 447（继承与退化）** 未被重定义的 ToolGauge/LeanGauge 记号沿用定义 398–431。
TEMPOGAUGE 在极限下退化为 ToolGauge：令 C_t → 0、U_s → 1、浮点精确、内存无限、ρ ≡ 1、无故障，
则四重包络全部自动满足，SAT ≡ TCV，QA-Cal ≡ AP-Cal，AHR ≡ 直接写，TEMPOGAUGE ≡ ToolGauge。
因此本轮是严格细化而非替换。

## 2. 关键算法骨架

```python
# IP-321 WC-MTC + SAT：实时契约与准入（先准入，后动作）
@dataclass
class RTMetrologyTool:
    schema: Callable[[dict], bool]
    pre:    Callable[[Snapshot], bool]
    post:   Callable[[Raw], "Receipt | None"]
    wcet:   float          # C_t，含缓存/总线干扰
    mem:    int            # M_t，静态字节
    energy: float          # E_t，mJ
    crit:   int            # 0 / 1 / 2
    deadline: float        # τ_t

class SAT:
    def admit(self, prog, cfg):
        if not schema_pre_loop_ok(prog):               return False, "contract"  # 继承 TCV
        for lvl in (0, 1, 2):
            if not rta_feasible(prog.by_level(lvl), cfg):
                return False, f"rta_{lvl}"
        if utilization(prog, cfg) > cfg.U_max:          return False, "util"
        if high_water(prog) > cfg.M_budget:             return False, "mem"
        if energy(prog, cfg.hyperperiod) > cfg.E_budget:return False, "energy"
        if not fixed_point_representable(prog):         return False, "numeric"
        return True, "ok"

# IP-322 TI-Sched：周期资源服务器；C0 永远最高优先级
class PRM:
    def __init__(self, T_s, Q_s):
        self.T_s, self.Q_s = T_s, Q_s
    def supply(self, t):
        return min(self.Q_s, max(0.0, self.Q_s - self.used_in(t // self.T_s)))
    def has_budget(self):
        return self.supply(now()) > 0.0

# IP-323 QA-Cal：量化后验 + 保守膨胀 + 定点契约
class QACal:
    def calibrate(self, z_s, H, s):
        mu_q, Sig_q, dmu, dSig = self.q_mp_phi(z_s, H, s)      # 定点网络
        Sig_c = loewner_max(Sig_q, lower_bound(Sig_q, dSig))
        Sig_c = Sig_c + (self.eps_q**2 + 2*dSig) * I
        Sig_c = clamp_min(Sig_c, self.kappa_phys**2 + self.q_floor**2)
        if not dominates(Sig_c, self.float_reference(z_s)):
            raise NumericEnvelopeError(s)                       # 拒绝，不替换
        return FixedPoint(mu_q, dmu), FixedPoint(Sig_c, self.delta_Sig)
    def cross_validate(self, mu, Sig, r_indep, D):
        if now() > D: return False                              # 超时≠通过
        return abs((r_indep.mu - mu) / sqrt(Sig + r_indep.var)) <= self.eps_cross

# IP-324 BMR：有界充分统计量（高斯精确 / 非高斯 coreset）
class BMR:
    def __init__(self, d, B_r, eps_sk):
        self.Lambda, self.eta = zeros((d, d)), zeros(d)         # 固定大小
        self.sketch, self.B_r = Coreset(B_r), B_r
        self.eps_sk = eps_sk
    def update(self, r):
        self.Lambda += r.precision; self.eta += r.precision @ r.mu
        self.sketch.add(r)                                      # 超容量则合并
        self.eps_sk = certified_error(self.sketch)
    def posterior(self):
        Sig = inv(self.Lambda) + self.eps_sk**2 * I             # 保守膨胀
        return self.Lambda @ self.eta, Sig

# IP-325 AHR：掉电原子的热替换
class AHR:
    def commit(self, slot, new_ec):
        buf = 1 - slot
        write(buf, new_ec); flush()
        assert crc(buf) == crc_of(new_ec)
        with interrupts_disabled(max_us=1):
            self.slot = buf                                     # 原子指针切换
        journal("commit", self.slot)
    def recover(self):
        for s in (self.slot, 1 - self.slot):
            if crc_ok(s): self.slot = s; return load(s)
        return SAFE_DEFAULT_EC                                  # 两坏则安全默认

# IP-326 TEMPOGAUGE 6C：每个阶段插入包络检查
def tempogauge_6c(M, s):
    H    = M.lbox.hypothesize(s, M.dbox.R[s])                   # 允许在 C2 slack
    prog = M.tbox.plan(H)                                       # VLA 编程器
    ok, why = M.sat.admit(prog, M.cfg)                          # SAT：动作前准入
    if not ok: return M.ddm.degrade(s, why)                     # DDM 唯一动作
    receipts = M.tcv.execute_bounded(prog, M.env, D=M.cfg.D1)   # PRM 供给 + 看门狗
    if M.tcv.overrun or len(receipts) < n_min(s):
        return M.ddm.degrade(s, "deadline_or_evidence")
    z_s = M.bmr.update_all(receipts)                            # 有界统计量
    try:
        mu, Sig = M.qacal.calibrate(z_s, H, s)                  # 量化保守后验
    except NumericEnvelopeError:
        return M.ddm.degrade(s, "numeric_envelope")
    if not M.qacal.cross_validate(mu, Sig, M.cross_receipt(s), D=M.cfg.D_V):
        return M.ddm.degrade(s, "cross_timeout_or_fail")        # 超时≠通过
    new_ec = M.qacal.update_contract(M.dpe, mu, Sig, s)
    if not contract_regression_fixed_point(new_ec):
        return M.ddm.degrade(s, "regression")
    M.ahr.commit(M.slot, new_ec)                                # 原子提交
    M.mreg.publish(M.slot)                                      # C0 只做原子读
    M.pquar.record(M.qacal.last_gain, realized_gain(receipts))
    M.audit.write(TNMCert(s, prog, receipts, mu, Sig, M.mon.measure()))
    return True
```

## 3. 推导

**引理 51（时间隔离：C0 的 WCET 与修复到达无关）** 在 TI-Sched 下，若 U0 + U_s ≤ 1 − μ_res，
且 C0 为最高优先级、其阻塞上界为 B0，则对任意 C1/C2 到达序列，C0 的最坏响应时间满足
R0^WC ≤ C0^WC + B0，与 C1/C2 的数量、到达时刻、执行时长无关。
证明思路：固定优先级抢占调度中，只有更高优先级任务能延迟 C0；C0 之上无任务，故干扰为 0；
C1/C2 被服务器带宽封顶，服务器自身在 C0 就绪时立即被抢占；B0 来自非抢占临界区（AHR 关中断 ≤ 1 µs）
与 DMA/总线预留 μ_res。用 PRM 的供给界代入标准 RTA 即得。
系：ToolGauge 引理 50 的「新增 ≤ 0.2 ms」被替换为可计算的 R0^WC。

**引理 52（修复时延的确定性上界与超时原子性）** 对通过 SAT 的 Π_s，若 WCET 模型正确，则 R1 ≤ D1；
若 WCET 被违反或服务器预算耗尽，看门狗在 D1 + ε 内中止该作业并由 AHR 回滚，C0 不受影响。
即：**条件于 C_t，完成时间有硬上界；无条件，系统在 D1 + ε 内回到一致状态，绝不无限阻塞。**
证明思路：服务器预算 + 看门狗的硬件定时器给出强制截断；中止发生在 AHR 提交点之前时，
旧 EC 未被修改（双缓冲），故回滚是 O(1) 指针保持。
系：P99 不再是 SLA，而是可证明的上界；E441/E446 检验 C_t 模型。

**引理 53（量化后验的保守支配）** 设浮点后验为 N(μ_θ, Σ_θ)，量化网络误差满足
|μ_q−μ_θ| ≤ δ_μ、|Σ_q−Σ_θ| ≤ Δ_Σ（逐元素）。若按定义 436 构造
Σ_c = max(Σ_q, Σ_lower) + (ε_q² + 2Δ_Σ)I，且 Σ_c ≽ (κ_phys²+q_floor²)I，则
Σ_c ≽ Σ_θ + q_floor² I，
从而任何依赖「后验方差 ≥ 物理噪声底」的安全论证在量化后仍然成立，代价是置信区间整体膨胀
ε_q + √(2Δ_Σ)；均值误差 δ_μ 以加性项进入契约回归的裕度。
证明思路：Loewner 序对逐元素误差界的支配；max 取逐元素上界保证半正定方向的保守性；夹紧给下界。
系：**不允许「用更高精度蒙混」**——必须显式给出 δ_μ、Δ_Σ、ε_q 才能进入 U。

**引理 54（有界内存的保守代价）** 若 BMR 维护的充分统计量满足 Σ_sketch ≽ Σ_full − ε_sk I、
均值漂移 ≤ δ_μ，则把历史从无界截断到 B_r 只使后验膨胀至多 ε_sk、均值偏移至多 δ_μ；
因此「遗忘」是保守的，内存上界 B_r 可以在构建期固定，且不破坏引理 53 的支配关系（把 ε_sk 并入 ε_q）。
证明思路：精确贝叶斯中丢弃数据只会增大熵/协方差（信息不增）；coreset 的 ε_sk 是对该理想膨胀的
可证上界；均值漂移由加权合并的稳定性给出。
系：ToolGauge 的「回执流越长越好」被替换为「固定大小统计量 + 可证遗忘代价」。

**引理 55（掉电原子与退化确定性）** AHR 的 A/B + CRC + 日志 + 临界区指针切换保证：任意时刻掉电，
复位后 EC ∈ {old, new}；若两者 CRC 均失效，则进入安全默认。DDM 是全函数且不依赖随机数，
因此同一 (Fault, Mode) 在任意历史下产生同一动作。结合引理 54 的保守遗忘，系统级不变式
（契约完整性、组合单调性、反作用通道完备、主张绑定、严格退化链）在掉电/超时/热降额下保持。
证明思路：标准 crash-consistency 论证；提交点在临界区内是原子的；退化函数的确定性由构建期表驱动。

**引理 56（端到端包络合成）** 若 U0 + U_s ≤ 1 − μ_res（引理 51）、WCET 模型正确（引理 52）、
数值包络通过（引理 53）、内存有界（引理 54）、提交原子（引理 55），则 TEMPOGAUGE 的每次修复满足：
(a) C0 零截止期错过；
(b) 修复在 D1 内完成或于 D1 + ε 内原子回滚；
(c) 进入 C0 的契约在量化意义下保守；
(d) 内存峰值 ≤ M_budget、能量 ≤ E_budget、热降额不低于 ρ_min。
这是可组合的安全案例骨架；任一条不成立时，SAT/DDM 在动作前拒绝或降级，不产生「部分正确」的中间态。

## 6. 本轮最大风险（一句话）

**一句话**：TEMPOGAUGE 的全部硬实时保证都**条件于 WCET 模型与时间隔离假设**——在真实端侧 SoC 上，
缓存、总线、DMA、DVFS 与热降额等共享资源效应会让 WCET 静态分析系统性低估，而修复任务本身恰好是
最坏情况抖动的来源，于是系统可能在形式证明上满足截止期，却在现场以不可复现的方式偶发超时，
且这种失效会被「已认证」标签掩盖。

**次级风险与缓解**：
1. **WCET 低估** → 静态分析 + 测量混合、安全裕度、运行时预算强制、硬件看门狗；E442/E446 交叉验证；
2. **量化误差累积** → 区间/仿射算术、饱和运算、NEE 门禁；E443 检查覆盖率而非仅 ECE；
3. **热/能超支** → TEE 降额、先丢 C2 再丢 C1、能量预算硬顶；E449；
4. **内存碎片/栈溢出** → SAC 静态分配、栈水位分析、MPU 保护；E444；
5. **掉电撕裂** → A/B + 日志 + CRC + 安全默认；E445；
6. **交叉验证超时被当通过** → RCV 明确超时即失败；E447；
7. **OTA/配置漂移** → SAC + 签名镜像 + 维护模式；E450；
8. **硬件隔离不成立**（DMA 绕过、cache 未分区）→ 资源分区 + 隔离测试；E441/E451；
9. **VLA/NPU 非确定性** → 仅在 C2 slack 运行、缓存结果、永不进入 C0；E454。

任一失败即在零物理副作用前退化；禁止「先执行再发现」。

**定义 436（QA-Cal）** 量化网络误差界 `(δ_μ, Δ_Σ, ε_q)`；构造
`Σ_c = max(Σ_q, Σ_lower) + (ε_q² + 2Δ_Σ)I`，并夹紧 `Σ_c ≽ (κ_phys² + q_floor²)I`；
若 `Σ_c` 不支配浮点后验则拒绝校准。舍入固定 RNE，种子构建期固定。

**定义 437（FCS）** 契约参数以定点存储并附 `(scale, δ, crc)`；定点域重跑回归；δ 使安全裕度下降超阈值则拒绝。
数值表示视为契约的一部分。

**定义 438（BMR）** 用固定大小充分统计量替代无界回执历史：高斯情形存 `(Λ, η)`；非高斯情形存容量 `B_r` 的
coreset 并附认证误差 `ε_sk`；合并/淘汰满足 `Σ_sketch ≽ Σ_full − ε_sk I` 与均值漂移 `≤ δ_μ`。

**定义 439（AHR）** A/B 双缓冲 + CRC + 日志 + 关中断 ≤ 1 µs 的原子指针切换；掉电复位后 old-or-new，
两缓冲皆坏则安全默认 EC。

**定义 440（DDM）** 退化是全函数，故障类 × 模式映射到唯一动作（continue / drop_C2 / rollback / stub+RED / safe_stop）；
禁止随机或自适应退化。

**定义 441（TEE）** 热降额 `ρ(Θ,f,V)` 放大 WCET：`C_t(ρ)=C_t^0/ρ`；最坏热工况 `ρ_min` 下 C0 仍可调度；
C1/C2 仅在热余量与能量预算内启动。

**定义 442（RTB-Contract）** 四维预算（时间/内存/能量/热）+ 恢复条件，是 TB-Contract（定义 424）的实时化细化。

**定义 443（RCV）** 独立 cross.modal 回执必须在 `D_V` 内到达；超时即 V 失败；回执须来自不同资源域以排除共因故障。

**定义 444（QoT）** RepairCert 增加 `(R_i^WC, δ_num, M_peak, E_used, ρ_min, commit_ver)`，由监控测量并签名；
引用超界数值的主张整条作废（扩展定义 423）。

**定义 445（EDL）** SAT 失败且 D1 内无法修复 ⇒ LeanGauge-tiny；仍不可调度 ⇒ MODGAUGE；每级写 RED 并排队人工。

**定义 446（SAC）** 任务参数、工具表、量化 scale、缓冲大小、随机种子、调度表构建期固定；运行期只允许验签 OTA；
临界路径禁止动态分配与运行期改优先级。

**定义 447（继承与退化）** 未重定义的 ToolGauge/LeanGauge 记号沿用定义 398–431；令 `C_t→0, U_s→1`、浮点精确、
内存无限、`ρ≡1`、无故障，则 TEMPOGAUGE ≡ ToolGauge（严格细化）。

## 3. 关键算法骨架

```python
# IP-321 SAT：动作前准入（可调度性是执行的前提）
class SAT:
    def admit(self, prog, cfg):
        if not schema_pre_loop_ok(prog):                return False, "contract"
        for lvl in (0, 1, 2):
            if not rta_feasible(prog.by_level(lvl), cfg): return False, f"rta_{lvl}"
        if utilization(prog, cfg) > cfg.U_max:          return False, "util"
        if high_water(prog) > cfg.M_budget:             return False, "mem"
        if energy(prog, cfg.hyperperiod) > cfg.E_budget:return False, "energy"
        if not fixed_point_representable(prog):         return False, "numeric"
        return True, "ok"

# IP-322 PRM：周期资源服务器；C0 可随时抢占
class PRM:
    def __init__(self, T_s, Q_s): self.T_s, self.Q_s = T_s, Q_s
    def supply(self, t): return min(self.Q_s, max(0.0, self.Q_s - self.used_in(t // self.T_s)))
    def has_budget(self): return self.supply(now()) > 0.0

# IP-323 QA-Cal：量化保守后验 + 实时交叉验证
class QACal:
    def calibrate(self, z_s, H, s):
        mu_q, Sig_q, dmu, dSig = self.q_mp_phi(z_s, H, s)
        Sig_c = loewner_max(Sig_q, lower_bound(Sig_q, dSig))
        Sig_c = Sig_c + (self.eps_q**2 + 2*dSig) * I
        Sig_c = clamp_min(Sig_c, self.kappa_phys**2 + self.q_floor**2)
        if not dominates(Sig_c, self.float_reference(z_s)):
            raise NumericEnvelopeError(s)                # 拒绝，不替换
        return FixedPoint(mu_q, dmu), FixedPoint(Sig_c, self.delta_Sig)
    def cross_validate(self, mu, Sig, r, D):
        if now() > D: return False                        # 超时≠通过
        return abs((r.mu - mu) / sqrt(Sig + r.var)) <= self.eps_cross

# IP-324 BMR：固定大小统计量 + 可证遗忘
class BMR:
    def __init__(self, d, B_r, eps_sk):
        self.Lambda, self.eta = zeros((d, d)), zeros(d)
        self.sketch, self.eps_sk = Coreset(B_r), eps_sk
    def update(self, r):
        self.Lambda += r.precision; self.eta += r.precision @ r.mu
        self.sketch.add(r); self.eps_sk = certified_error(self.sketch)
    def posterior(self):
        return self.Lambda @ self.eta, inv(self.Lambda) + self.eps_sk**2 * I

# IP-325 AHR：原子提交与掉电恢复
class AHR:
    def commit(self, slot, new_ec):
        buf = 1 - slot
        write(buf, new_ec); flush(); assert crc(buf) == crc_of(new_ec)
        with interrupts_disabled(max_us=1): self.slot = buf
        journal("commit", self.slot)
    def recover(self):
        for s in (self.slot, 1 - self.slot):
            if crc_ok(s): self.slot = s; return load(s)
        return SAFE_DEFAULT_EC

# IP-326 6C：包络检查嵌入每个阶段
def tempogauge_6c(M, s):
    H = M.lbox.hypothesize(s, M.dbox.R[s])                        # 可放 C2 slack
    prog = M.tbox.plan(H)
    ok, why = M.sat.admit(prog, M.cfg)                            # 动作前准入
    if not ok: return M.ddm.degrade(s, why)
    receipts = M.tcv.execute_bounded(prog, M.env, D=M.cfg.D1)     # PRM + 看门狗
    if M.tcv.overrun or len(receipts) < n_min(s):
        return M.ddm.degrade(s, "deadline_or_evidence")
    z_s = M.bmr.update_all(receipts)
    try:
        mu, Sig = M.qacal.calibrate(z_s, H, s)                    # 量化保守后验
    except NumericEnvelopeError:
        return M.ddm.degrade(s, "numeric_envelope")
    if not M.qacal.cross_validate(mu, Sig, M.cross_receipt(s), D=M.cfg.D_V):
        return M.ddm.degrade(s, "cross_timeout_or_fail")
    new_ec = M.qacal.update_contract(M.dpe, mu, Sig, s)
    if not contract_regression_fixed_point(new_ec):
        return M.ddm.degrade(s, "regression")
    M.ahr.commit(M.slot, new_ec); M.mreg.publish(M.slot)          # 原子提交，C0 只读
    M.pquar.record(M.qacal.last_gain, realized_gain(receipts))
    M.audit.write(TNMCert(s, prog, receipts, mu, Sig, M.mon.measure()))
    return True

# IP-326 主闭环：C0 路径不新增阻塞；C1/C2 仅在预算内
def TEMPOGAUGE_round(M, obs, audio, tac, depth, det):
    out = MODGAUGE_round(M, obs, audio, tac, depth, det)
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight and M.prm.has_budget():
            M.inflight.add(s)
            submit_to_server(tempogauge_6c, M, s, deadline=M.cfg.D1)
    if M.ddm.triggered():
        M.degrade_to(M.ddm.next_mode(), M.ddm.action())
    return out
```

## 4. 推导

**引理 51（时间隔离）** 若 `U0 + U_s ≤ 1 − μ_res`，C0 最高优先级且阻塞上界 `B0`，则对任意 C1/C2 到达序列，
`R0^WC ≤ C0^WC + B0`，与修复任务的到达模式无关。证明：FP 抢占调度下只有更高优先级任务能延迟 C0，C0 之上无任务；
C1/C2 被服务器带宽封顶，服务器在 C0 就绪时立即被抢占；B0 来自关中断临界区与 DMA/总线预留。系：引理 50 的经验
「新增 ≤ 0.2 ms」被替换为可计算的 R0^WC。

**引理 52（修复时延硬上界与超时原子性）** 对通过 SAT 的 Π_s，若 WCET 模型正确则 `R1 ≤ D1`；若 WCET 被违反或
预算耗尽，看门狗在 `D1+ε` 内中止并由 AHR 回滚，C0 不受影响。于是「条件于 C_t 完成时间有硬上界；无条件在 D1+ε
内回到一致状态」。证明：服务器预算 + 硬件定时器强制截断；中止发生在提交点前，双缓冲保证旧 EC 未被修改。

**引理 53（量化后验保守支配）** 若 `|μ_q−μ_θ| ≤ δ_μ`、`|Σ_q−Σ_θ| ≤ Δ_Σ`，且按定义 436 构造
`Σ_c = max(Σ_q, Σ_lower) + (ε_q²+2Δ_Σ)I ≽ (κ_phys²+q_floor²)I`，则 `Σ_c ≽ Σ_θ + q_floor² I`。
因此依赖「后验方差 ≥ 物理噪声底」的安全论证在量化后仍成立；代价是区间膨胀 `ε_q + √(2Δ_Σ)`，
均值误差 `δ_μ` 作为加性项进入回归裕度。系：必须显式给出 `(δ_μ, Δ_Σ, ε_q)` 才能进入 U。

**引理 54（有界内存的保守代价）** 若 BMR 的统计量满足 `Σ_sketch ≽ Σ_full − ε_sk I` 且均值漂移 `≤ δ_μ`，
则把历史截断到 `B_r` 只使后验膨胀至多 `ε_sk`、均值偏移至多 `δ_μ`；遗忘是保守的，且可把 `ε_sk` 并入引理 53 的 `ε_q`。
证明：精确贝叶斯中丢弃数据只会增大熵/协方差；coreset 误差给出该理想膨胀的可证上界。

**引理 55（掉电原子与退化确定性）** AHR 的 A/B + CRC + 日志 + 临界区指针切换保证任意掉电后 EC ∈ {old, new}，
两者皆坏则安全默认；DDM 是全函数且无随机性，故同一 (Fault, Mode) 在任意历史下产生同一动作。结合保守遗忘，
五不变式在掉电/超时/热降额下保持。证明：标准 crash-consistency + 构建期表驱动退化。

**引理 56（端到端包络合成）** 若引理 51–55 同时成立，则每次修复满足：C0 零错过；修复在 D1 内完成或 D1+ε 内
原子回滚；进入 C0 的契约在量化意义下保守；内存 ≤ M_budget、能量 ≤ E_budget、热降额 ≥ ρ_min。
任一条不成立时 SAT/DDM 在动作前拒绝或降级，不产生「部分正确」的中间态。这是可组合的安全案例骨架。

## 7. 与 ToolGauge 的差异与继承

- **继承**：MODGAUGE 五不变式、MTC/TCV 契约与回执（定义 416–418）、双层下注（419）、AP-Cal 摊销先验（420）、

- **升级**：ToolGauge 的「异步即安全」→ MC-3 + TI-Sched + SAT + RTA；「浮点后验」→ QA-Cal + 定点契约；
  「无界历史」→ BMR；「直接写 EC」→ AHR；「策略式退化」→ DDM 全函数；「预算」→ 四维 RTB（时间/内存/能量/热）。
- **新增不变式**：TDI（时序确定性）、NEE（数值包络）、MBE（内存有界）、FRI（失效原子）。
- **退化链**：TEMPOGAUGE ⇒ LeanGauge-tiny ⇒ MODGAUGE；VLA/AP-Cal 仅在包络通过时存在。

## 8. 本轮最大风险

**一句话**：TEMPOGAUGE 的全部硬实时保证都条件于 WCET 模型与时间隔离假设——真实 SoC 上的缓存、总线、DMA、
DVFS 与热降额会让静态 WCET 系统性低估，而修复任务本身就是最坏抖动源，导致「证明上满足截止期、现场却偶发超时」，
且这种失效会被「已认证」标签掩盖；以 E441/E442/E446/E451 证伪，以硬件分区、混合 WCET、运行时预算强制与看门狗兜底。
