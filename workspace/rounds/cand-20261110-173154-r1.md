# 第 44 轮（新循环第 4 轮） · Scene-Grounded Persona-Cert：把「个性化交互」从抽象动作空间落到「场景 × 人格」可执照的部署单元（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形边际覆盖被欺骗 + 多用户契约空集」，但它仍压着一个更根本的隐含假设：**(H3) 场景是已知且平稳的**——证书在某个标称场景分布上校准，就默认部署时还在同一个场景里。真实「场景落地」恰恰相反：场景是隐变量、在运行时才被推断、且在部署中漂移；「个性化交互」也不是一次编译好的静态契约，而是在现场遇到具体的人、具体的场景、并可能被误识别的人所触发。本轮两个灵感词因此不是复述 v20，而是把 v20 的「人格证书」推进到 **场景条件化的人格证书 C_{u,s}**，并把「落地」从一次性的二进制部署，变成 **(人格 × 场景) 单元上的分级执照 + 现场漂移归因 + 证书债务账本**。

## 0. 直觉与动机

**灵感 1（场景不是标签，是隐变量：把分类错误从安全漏洞降级为可用性损失）**：直觉上，机器人说「我现在在走廊/电梯/人群」，这个判断几乎一定会错，尤其在人机混杂的边缘分布。若个性化直接依赖「场景分类器的 argmax」，一次误分类就可能让「在空旷走廊被允许的快步速」落到「电梯口人群」里，且没有任何证书会被违反——因为证书根本没被查询。**关键转向**：不做 argmax，而输出**集合值场景辨识** Ŝ_t^β（共形保证 P(s_t∈Ŝ_t^β)≥1−β），并且只在**所有可能场景都对该人格持有执照且契约兼容**时才个性化：`Ŝ_t^β ⊆ Licensed(u,·)`。这样，**只要覆盖成立，分类错误只损失可用性（回退保守），不损失 soundness**；覆盖不成立才是唯一的安全漏洞，而它是可校准、可预算的。

**灵感 2（落地不是「上线」，是分级暴露：执照格 deny→shadow→supervised→autonomous）**：直觉上，没人会把一个刚训好的个性化策略直接全量放开。落地应是 **(u,s) 单元上的分级执照**：先影子运行（不执行只比对）、再监督运行（操作员确认）、最后自治；每一级必须通过上一级的现场证据，且证据**不跨单元免费迁移**。场景相似才允许带衰减率 η 的迁移，否则禁止——因为「走廊的证据不能给电梯担保」。这把 v20 的「认证扩张三重闸门」从离线仿真扩展到现场，并给出一条可审计规则：**先在低暴露级证明，再单调升级；任何现场违例只降不升**。

**灵感 3（现场不是平稳的：证书债务 + 风险预算 + 漂移归因）**：直觉上，部署最贵的不是算力，而是**还没测过的 (u,s) 单元**。我们不可能把人格 × 场景的笛卡尔积都测完，于是把未验证性显式记为**证书债务 d_{u,s}**，用总量风险预算 ρ 约束暴露：`Σ exposure_{u,s}·d_{u,s} ≤ ρ`。现场监控用序贯检验做漂移检测，再用仿真回放做**归因**（是哪个人格、哪个场景参数、哪个交互模式变了），高置信违例立即吊销执照并回灌 Sim/CKB。主动采样则选择「信息增益/风险」比最高的单元去测。落地由此从「祈祷没遇到长尾」变成「用有限风险预算买最多覆盖」。

**灵感 4（个性化交互的现场化：双集合支配）**：现场不仅场景是隐变量，**人也是**。多用户/快速切换时先辨识用户集合 Û_t，再与场景集合做保守合成：取 Û_t 上人格契约之交（最保守）与 Ŝ_t^β 上场景契约之交，仅当该交集非空且 **Û_t × Ŝ_t^β 中每个单元都持照** 时才执行个性化；否则退回**公共保守契约 Π_∅**（v20 的纯收缩轨道）或发起最小让步协商。注意这与 v20 的「多用户契约求交可空」直接对接：**空集不再靠猜一个活跃用户，而是靠集合值用户辨识 + 公共回退**。

**耦合升级**：v20 的 PCE→CCR→ICV 链路之上加一层「落地治理」：SIC（场景辨识）产出 Ŝ；DLM（部署执照）维护 (u,s) 单元执照与债务；FSA（现场漂移归因）做检测、归因、吊销与回灌。四层架构 v9 = v8 的「仿真-检索-边缘飞轮 + 人格契约 + 并发证书」再叠加**场景契约层 + 落地治理层**。

## 1. 形式化定义（增量：定义 44–50）

**定义 44（场景契约 Σ_s）**：场景 s∈S 的契约 Σ_s=(X_s, W_s, H_s, T_s)：X_s⊆X 为可容许状态域（几何/速度/区域），W_s 为扰动与 actor 包络，H_s 为人类交互模式集，T_s 为任务语法。场景**不是**状态 x 的函子，而是决定「哪些证书在该分布下被校准过」的索引。ODD = ∪_{s∈S_lic} Σ_s。

**定义 45（集合值场景辨识证书）**：辨识器 g: O→2^S 由按场景分层的共形校准给出，满足 P(s_t∈Ŝ_t^β)≥1−β。**辨识弃权**：若 Ŝ_t^β=∅ 或存在 s∈Ŝ_t^β 未持照，则弃权。**支配判据**：个性化可执行仅当 Ŝ_t^β ⊆ Lic(u)（该人格在当前暴露级下持照的场景集合）。**命题（错误降级）**：在覆盖成立时，任何分类错误都不改变已执行动作的证书 soundness，只可能减少可用动作集；因此辨识器的 accuracy 不再进入安全论证，只有 coverage 进入。

**定义 46（场景条件化人格证书与双集合支配）**：C_{u,s}=C_global ∩ Π_u ∩ Σ_s。**单调性**：u 更保守或 s 更受限 ⟹ C_{u,s} 更小。**双集合支配**：给定 Û_t 与 Ŝ_t^β，取 Π_{Û}=∩_{u∈Û_t}Π_u、Σ_{Ŝ}=∩_{s∈Ŝ_t^β}Σ_s，则执行契约为 C_{Û,Ŝ}=C_global ∩ Π_{Û} ∩ Σ_{Ŝ}；若 Π_{Û}=∅ 或 C_{Û,Ŝ} 对目标不可行，则回退 Π_∅（纯收缩）或协商。**命题**：对集合取交只增加保守性，故模糊的辨识不会破坏 soundness，只会牺牲可用性。**禁止免费迁移**：C_{u,s} 的有效性不得推断为 C_{u,s'} 的有效性，除非声明相邻性 d_S(s,s')≤δ 并给出迁移界（定义 49）。

**定义 47（部署执照格与单调暴露）**：执照 L⊆U×S→E，E={deny,shadow,supervised,autonomous}，偏序 deny≺shadow≺supervised≺autonomous。发照条件：低一级的现场证据 + 校准有效 + 该单元仿真覆盖达标 + 操作员接受。**单调升级**：只允许逐级升；**单调降级**：任何现场违例吊销至不高于违规前的级别。**定理（执照安全）**：若每一时刻实际执行单元 (u,s) 的执照级满足义务（autonomous 需全部闸门、supervised 需操作员在环、shadow 不执行），且 C_{u,s} sound、Ŝ/Û 覆盖成立，则现场个性化违例概率 ≤ β_u+β_s+Σ_cell 覆盖失效预算。**注**：这是并集界，故 β 必须计入总风险预算，不能各自免费。

**定义 48（证书债务与风险预算）**：每单元债务 d_{u,s}≥0 表示「未验证程度」（由仿真覆盖缺口、校准误差、现场小时数反比等构成）。暴露风险近似 R=Σ_{(u,s)} exposure_{u,s}·d_{u,s}。**落地约束**：R≤ρ。**主动采样**：下一测试单元 (u,s)*=argmax_{(u,s)} InfoGain(u,s)/d_{u,s}，在预算内最大化债务下降。**命题**：在 d 有界且采样无偏时，贪心采样对债务下降给出 (1−1/e) 近似。

**定义 49（跨单元迁移界）**：若场景距离 d_S(s,s')≤δ 且人格序 u⪯u'（u' 更保守），则允许以衰减因子 η(δ) 迁移证据：d_{u',s'} ≤ η(δ)·d_{u,s}，且 η 需由仿真中成对场景的证书差经验标定；η 未标定的场景对**禁止迁移**。

**定义 50（现场漂移归因与再认证）**：现场残差 r_t 上跑 SPRT/CUSUM 得漂移告警；用仿真回放做**参数归因**：在 Σ_s 的参数上求使回放违例成立的**最小变更集** Δ_s，并以归因置信度决定吊销范围。**再认证**：更新 Σ_s → 重校准 Ŝ 与 C_{u,s} → 重算债务 → 逐步复照。**命题（归因充分性）**：若回放函数对场景参数 Lipschitz 且 Δ_s 覆盖真实变更，则归因可把「未知漂移」转化为「已知单元 + 已知参数」的可再认证问题。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 SCENE-IDENTITY-CERTIFIER（场景辨识证书器 SIC）
1. 场景特征与签名（几何/actor/光照/网络/人密度/任务），按场景分层共形校准。
2. 集合值辨识 + 弃权 + 支配判据接口（供 DLM 与 PCE 查询）。
3. 场景歧义显式化：集合基数、边界样本、混合场景（走廊-电梯过渡）单独建模。
4. 与 IP-49 几何证书、IP-55 CKB 指纹联动，避免「场景标签与几何不一致」。

### 2.2 IP-61 DEPLOYMENT-LICENSE-MANAGER（部署执照管理器 DLM）
1. (u,s) 单元执照格，分级暴露、逐级升级、违例单调降级。
2. 证书债务账本 + 风险预算约束 + 主动场景采样（信息增益/风险）。
3. 迁移界管理：η 标定、相邻性声明、未标定即禁迁。
4. 审计与回滚：执照事件、债务变动、采样决策全量日志；一键回退到 Π_∅ + 保守 ODD。

### 2.3 IP-62 FIELD-SHIFT-ATTRIBUTOR（现场漂移归因器 FSA）
1. 序贯漂移检测（SPRT/CUSUM），按单元分流。
2. 仿真回放归因：最小参数变更集 Δ_s，区分场景漂移 / 人格漂移 / 交互漂移。
3. 吊销建议与回灌：把归因后的反例写成 CKB 指纹与 SCV 回归用例。
4. 现场-仿真差距度量：回放可复现率、归因命中率、再认证时延。

## 4. 实验设计（E95–E102 硬门槛，承接 E87–E94）

| E101 漂移归因 | 检测时延；归因命中率；再认证耗时 | <10s；≥90%；<5min |

回退：E95 覆盖不达标 → 只允许单例场景 + 保守 ODD；E97 迁移不可靠 → 全面禁止跨单元迁移；E98 越级 → 强制影子期且人工双签；E99 长尾未持照 → 收缩 ODD、关闭个性化扩张；E101 归因慢 → 缩短执照 TTL + 定期全量再认证；任何红线失败 → 全链路熔断回退 v20 的纯收缩人格 + 串行安全监控。

## 5. 本轮最大风险

**一句话**：场景是隐变量且部署中非平稳，集合值辨识的覆盖只是边际保证，可能在现场真正访问的长尾单元上失效——于是执照格可能「地图全绿、领土失守」，即纸面全部持照而实际执行落在未覆盖单元；因此 E95（场景覆盖）与 E99（长尾持照率）必须是红线，并默认回退到「保守 ODD + 纯收缩人格 Π_∅」。

## 2. 关键算法（伪代码）

### IP-60 SIC：集合值场景辨识
```
def identify_scene(obs, beta, calib_by_scene):
    # 按场景分层共形：每个场景维护各自的非一致性分数分布
    scores = {s: nonconformity(obs, calib_by_scene[s]) for s in calib_by_scene}
    q = quantile(flatten(scores), 1 - beta)          # 秩统计阈值
    S_hat = {s for s, sc in scores.items() if sc <= q}
    return S_hat if S_hat else Abstain()

def dominated_scene_contract(S_hat, scene_contracts):
    # 集合取交 = 只增加保守性，模糊辨识不破坏 soundness
    return intersect([scene_contracts[s] for s in S_hat])
```

### IP-61 DLM：执照格、支配检查、债务与主动采样
```
def can_personalize(U_hat, S_hat, level, C, licenses, personas):
    if not U_hat or not S_hat: return False
    # 执照支配：每个可能单元都必须达到当前暴露级
    if any(licenses[(u, s)] < level for u in U_hat for s in S_hat):
        return False
    # 人格契约求交：空集则只能回退 Pi_empty / 协商
    P = intersect([personas[u] for u in U_hat])
    if P.is_empty(): return False
    return all(C[u, s].valid for u in U_hat for s in S_hat)

def next_level(level):
    order = [DENY, SHADOW, SUPERVISED, AUTONOMOUS]
    i = order.index(level)
    return order[i + 1] if i + 1 < len(order) else None

def issue_or_upgrade(cell, licenses, evidence, debts, migrations):
    cur = licenses[cell]; nxt = next_level(cur)
    if nxt is None: return cur
    # 只逐级升：低一级现场证据 + 校准有效 + 仿真覆盖 + 操作员接受
    if not gates_pass(cell, nxt, evidence, debts, migrations):
        return cur
    return nxt

def revoke(cell, violation, licenses, debts, adjacency):
    licenses[cell] = min(licenses[cell], level_before(violation))  # 只降不升
    for c in adjacency[cell]:                                     # 只影响声明相邻单元
        debts[c] += transfer_debt(cell, c)

def allocate_tests(debts, budget, risk_of):
    # 贪心"信息增益/风险"，受总风险预算 rho 约束
    plan = []
    while budget > 0:
        cell = argmax(debts, key=lambda c: info_gain(c) / max(risk_of(c), EPS))
        if risk_of(cell) > budget: break
        plan.append(cell); budget -= risk_of(cell)
        debts[cell] *= discount(cell)
    return plan
```

### IP-62 FSA：漂移检测、回放归因与吊销
```
def field_monitor(residuals):
    return sprt_or_cusum(residuals)                  # 序贯检验，按单元分流

def attribute_shift(field_log, scene_contract, CKB):
    # 在场景参数上搜索"使回放违例成立"的最小变更集
    cands = minimal_param_changes(scene_contract)
    for delta in sorted(cands, key=param_size):
        if replay_violates(field_log, delta):
            return delta, replay_confidence(delta)
    return UnknownShift(), 0.0

def on_violation(cell, delta, conf, licenses, debts, CKB, SCV, adjacency):
    if conf >= TAU_ATTR:
        revoke(cell, violation=True, licenses=licenses,
               debts=debts, adjacency=adjacency)
    CKB.add_counterexample(cell, delta)              # 归因后回灌
    SCV.add_regression(cell, delta)
```

### IP-51/57/58 升级：场景条件化守卫与租约
```
def scene_conditioned_guard(e, x, U_hat, S_hat, C, personas, licenses, level, lease, t):
    if not can_personalize(U_hat, S_hat, level, C, licenses, personas):
        return guard_with_public_contract(e, x, lease, t)   # Pi_empty 纯收缩
    P = intersect([personas[u] for u in U_hat])             # 最保守人格
    Sig = intersect([scene_contracts[s] for s in S_hat])    # 最保守场景
    C_eff = intersect_all([C_global, P, Sig])
    theta = C_eff.alpha_e[e] * C_eff.theta_sim[e]
    return (C_eff.margin[e](x) >= theta
            and lease.scene_id in S_hat                     # 租约场景一致
            and lease.license_epoch >= current_epoch(licenses)
            and lease_valid(lease, theta, t))               # 复用 v20 定义 41

def acquire_lease_v2(task, x, theta, kappa, scene_id, license_epoch):
    b = cert_lookup_L0(x)
    lam = L_m * v_max_bound(x)
    return Lease(m=b.m_lo, tau=monotonic_now(), lam=lam,
                 kappa=kappa, scene_id=scene_id,
                 license_epoch=license_epoch)

def on_license_downgrade(cell, cert_runtime):
    # 执照降级 -> 该单元所有租约立即作废，禁止使用旧边际
    cert_runtime.invalidate_leases(lambda l: (l.scene_id, l.persona) == cell)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性保证 |
|---|---|---|---|
| IP-60 集合辨识 | O(\|S\|·d) 每步 | 分层校准表 O(N_p) | 若覆盖成立，误辨识只减可用动作，不改 soundness |
| IP-60 场景交 | O(\|Ŝ\|) | 契约 O(\|Ŝ\|) | 集合取交只增保守性 ⟹ 模糊不破 sound |
| IP-61 支配检查 | O(\|Û\|·\|Ŝ\|) | 执照表 O(\|U\|·\|S\|) | 每单元持照 + 契约非空 ⟹ 可执行 |
| IP-61 发照/升级 | O(1) + gates | O(1) | 只逐级升 ⟹ 无越级自治 |
| IP-61 吊销 | O(deg(cell)) | O(deg) | 只降不升 ⟹ 违例后暴露单调收缩 |

## 4. 实验设计（E95–E102，硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E95 场景辨识覆盖 | 集合覆盖率；弃权率；混合场景边界覆盖率 | ≥1−β(β=0.1)；<15%；≥95% |
| E96 分类错误安全性 | 覆盖成立下的误辨识执行违例；回退正确率 | 0；≥99% |
| E97 跨单元迁移 | 未标定迁移次数；迁移证据违例；η 标定误差 | 0；0；<20% |

| E99 长尾单元暴露 | 现场访问单元持照率；未持照执行次数 | 100%；0 |

回退：E95 覆盖不达标 → 只允许单例场景 + 保守 ODD；E96 出现误辨识违例 → 立即禁止集合个性化，退回单例+双签；E97 迁移不可靠 → 全面禁止跨单元迁移；E98 越级 → 强制影子期 + 人工双签；E99 长尾未持照 → 收缩 ODD、关闭个性化扩张；E100 预算超支 → 冻结升级、只做采样；E101 归因慢 → 缩短执照 TTL + 定期全量再认证；任何红线失败 → 全链路熔断回退 v20 的纯收缩人格 + 串行安全监控。

| 风险 | 等级 | 缓解措施 |

## 6. 本轮最大风险

**一句话**：场景是隐变量且部署中非平稳，集合值辨识的覆盖只是边际保证，可能在现场真正访问的长尾单元上失效——于是执照格可能「地图全绿、领土失守」，即纸面全部持照而实际执行落在未覆盖单元；因此 E95（场景覆盖）与 E99（长尾持照率）必须是红线，并默认回退到「保守 ODD + 纯收缩人格 Π_∅」。
