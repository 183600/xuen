### 第 1 轮灵感驱动研究记录（新循环 · 继承 CADVS-v7）

**灵感词**：碰撞避免、LoRA

**继承关系**：上一循环第 7 轮 CADVS-v7（IP-501~IP-504）以 DIM/DRC/DAC 把系统从「指令响应」推向「需求推导」，七硬门 kc_evidence_forged_v5 原样保留，但最大风险是「需求意图的可解释性假设」——推断的需求可能与当下真实需求相悖，且在 fail-closed 边界内仍可能「正确但不该做」。本轮开启新循环，灵感「碰撞避免」与「LoRA」把焦点从「意图对不对」转回两个更硬的命题：「物理上撞不撞」与「适配可不可证」。据此提出「**低秩安全适配（Low-Rank Safety Adaptation, LRSA）**」，核心是把参数空间的低秩更新与状态空间的碰撞证书**对偶耦合**——LoRA 负责「做什么」（个性化/任务适配），CBF 安全滤波器负责「怎么不撞」（前向不变证书），并用低秩范数给出适配对安全裕度扰动的可计算上界。

**直觉与动机**：

1. **碰撞避免 → 从「点态硬门」到「连续前向不变证书」**。v7 的 VACK/BCK 只在采样候选轨迹的离散点上验证碰撞，存在「隧道效应」：相邻两个采样点都无碰撞，点与点之间却已穿过障碍。本轮把碰撞门升级为**控制屏障函数（CBF）**的离散时间前向不变条件 h(x_{k+1}) ≥ (1-α)·h(x_k)，并用 Lipschitz 界把采样间隔内的屏障衰减折算成「膨胀屏障」h̃ = h − L_h·Δt，从结构上消灭隧道效应。关键洞见：**碰撞避免是连续时间性质，必须用不变量而非逐点检查来证明**。

2. **LoRA → 从「全参数适配」到「低秩安全子空间」**。全参数微调会不可控地改变策略，使安全证书失效；LoRA 的 ΔW = B·A（rank r ≪ d）把适配限制在低秩子空间，于是适配对动作的扰动可被 Jacobian 范数界定：‖δu‖ ≤ ‖J‖·‖BA‖_F，进而对下一时刻屏障值的扰动有 |δh| ≤ Λ_max·‖BA‖_F。关键洞见：**低秩结构本身就是一个安全预算**——它让「适配有多激进」第一次成为可量化、可约束的量。

3. **二者耦合 → 「参数-状态安全对偶」**。把 LoRA 适配器与 CBF 安全滤波器串联：适配器输出名义动作 u_π，CBF-QP 把 u_π 投影到满足屏障约束的最大可容许集。于是**无论适配器多激进，动作层都被硬投影回安全集**；低秩范数界决定 QP 是否始终可行（捕获区是否非空）。这把 v7 的「软因子链调阈值」升级为「参数预算调可行域」。

**关键洞见**：v7 回答「如何主动推导需求」；本轮回答「如何让任意（甚至被误推断驱动的）适配都保持碰撞安全，且适配强度可证」。七硬门数量不增——碰撞门在**原地升级**为 CBF 连续证书（kc_cbf 取代点态 kc_collision），LoRA 只受**软**的秩预算约束，绝不放松任何硬门。本轮新增：

- IP-505 CSF（CBF 安全滤波器，连续前向不变证书）
- IP-506 LRSA（低秩安全适配器 + 扰动上界）
- IP-507 ASSP（安全子空间投影，训练期约束）
- IP-508 EFA-v8（七硬门 + CBF 证书 + 秩预算软约束）

**形式化目标（增量）**：

1. **CSF（CBF Safety Filter）**：
   - 屏障 h: 𝒳 → ℝ，安全集 C = {x : h(x) ≥ 0}；离散 CBF：h(f(x,u)) ≥ (1−α)·h(x)，α ∈ (0,1]
   - 采样鲁棒膨胀屏障 h̃ = h − L_h·Δt（L_h 为 h 沿轨迹的 Lipschitz 常数）
   - 安全滤波 QP：u* = argmin_{u∈U} ‖u − u_π‖² s.t. h̃(f(x,u)) ≥ (1−α)·h̃(x)

2. **LRSA（Low-Rank Safety Adapter）**：
   - LoRA：θ = θ_0 + B·A，B ∈ ℝ^{d×r}, A ∈ ℝ^{r×k}，rank r
   - 扰动界：|h(x_{k+1}^{ΔW}) − h(x_{k+1}^{0})| ≤ Λ_max·‖BA‖_F + O(‖BA‖_F²)，Λ_max = sup_x ‖L_g h‖·‖J_π(x)‖
   - 安全秩预算：‖BA‖_F ≤ ρ_safe := α·h_min / Λ_max

3. **ASSP（Adapter Safety Subspace Projection）**：
   - 训练损失：L = L_task(BA) + λ·max(0, Λ_max·‖BA‖_F − ρ_safe)²
   - 每步投影：SVD 截断到 rank ≤ r，再按 Frobenius 球缩放至 ‖BA‖_F ≤ ρ_safe

4. **EFA-v8（七硬门 + CBF 证书）**：
   - 碰撞门原地升级：kc_collision（点态）→ kc_cbf（连续膨胀屏障前向不变）
   - ECS_v8 = ECS_v7 · η_rank，η_rank = 1 − clip(‖BA‖_F/ρ_safe − 1, 0, 1) ∈ (0,1]
   - 硬门数量不变（七），软因子链新增秩预算项

5. **形式化定义**：给定状态 x、名义适配策略 π_{θ0+BA}、备份安全控制 u_b：
   - u_π = π_{θ0+BA}(x)；u* = CBF-QP(x, u_π, h̃)
   - 若 QP 可行：执行 u*；否则执行 u_b（制动/退避）
   - 证书：h̃(x_0) ≥ 0 ∧ 每步满足离散 CBF ⇒ ∀t ≥ 0, h(x(t)) ≥ 0

**本轮最大风险**：**「安全 ≠ 正确」的假信心**——CBF 只保证不碰撞，无法保证适配后的行为符合用户真实需求，一个被误推断需求驱动的 LoRA 可能做出「物理安全但任务/社交上错误」的动作，而连续碰撞证书反而让系统显得比实际更可靠。

## 2. 关键算法骨架

### IP-505 CSF：CBF 安全滤波器

```python
@dataclass
class CBFSafetyFilter:
    """CSF：把任意名义动作 u_pi 投影到满足离散 CBF 的最大可容许集。
    膨胀屏障 h̃ = h - L_h·Δt 把采样间隔内的屏障衰减折算为固定裕度。"""
    h: Callable[[torch.Tensor], torch.Tensor]     # 屏障函数
    f0: Callable[[torch.Tensor], torch.Tensor]    # 漂移项 f0(x)
    g: Callable[[torch.Tensor], torch.Tensor]     # 控制矩阵 g(x)
    L_h: float                                    # h 的 Lipschitz 常数
    alpha: float = 0.3                            # 离散 CBF 衰减率
    dt: float = 1e-3                              # 控制周期
    u_min: torch.Tensor | None = None
    u_max: torch.Tensor | None = None

    def inflated_barrier(self, x: torch.Tensor) -> torch.Tensor:
        """h̃ = h - L_h·Δt：保证区间 [kΔt,(k+1)Δt] 内 h 仍 ≥ 0（消灭隧道效应）"""
        return self.h(x) - self.L_h * self.dt

    def qp(self, x: torch.Tensor, u_pi: torch.Tensor):
        """min ‖u - u_pi‖²  s.t.  L_g h̃·u ≥ -α·h̃(x) - L_{f0} h̃"""
        ht = self.inflated_barrier(x)
        Lf0 = self._lie_f0(x)              # L_{f0} h̃(x)
        Lg = self._lie_g(x)               # 行向量 L_g h̃(x)
        rhs = -self.alpha * ht - Lf0
        try:
            u = solve_qp_box(u_pi, Lg, rhs, self.u_min, self.u_max)
            feasible = bool(Lg @ u >= rhs - 1e-6)
        except InfeasibleQP:
            return None, False
        return u, feasible

    def step(self, x, u_pi, u_backup):
        """QP 不可行 → 备份安全控制（fail-closed）"""
        u, feasible = self.qp(x, u_pi)
        if not feasible:
            return u_backup, 'CBF_INFEASIBLE_BACKUP'
        return u, 'CBF_SAFE'

    def _lie_g(self, x):
        """L_g h̃ = ∂h/∂x · g(x)，解析或自动微分"""
        return jacobian(self.h, x) @ self.g(x)
```

### IP-506 LRSA：低秩安全适配器

```python
@dataclass
class LowRankSafetyAdapter:
    """LRSA：对 FMPP 速度场 v_θ 施加 LoRA，并给出屏障扰动一阶上界。
    θ = θ_0 + B·A，rank r ≪ d。"""
    base_policy: nn.Module            # v_{θ_0}
    rank: int = 8
    B: nn.Parameter = None            # ℝ^{d×r}
    A: nn.Parameter = None            # ℝ^{r×k}

    def delta_norm(self) -> float:
        """‖BA‖_F：安全预算的度量"""
        return torch.linalg.matrix_norm(self.B @ self.A, ord='fro').item()

    def action(self, x, t):
        """名义动作 = 基策略 + 低秩增量"""
        return self.base_policy(x, t) + self._lora_forward(x, t)

    def perturbation_bound(self, lambda_max: float) -> float:
        """|δh| ≤ Λ_max·‖BA‖_F（一阶），用于在线可行性预判"""
        return lambda_max * self.delta_norm()

    def safe_rank_budget(self, h_min, lambda_max, alpha) -> float:
        """ρ_safe = α·h_min / Λ_max"""
        return alpha * h_min / max(lambda_max, 1e-9)

    def _lora_forward(self, x, t):
        """B·A·φ(x,t)：φ 为基策略的中间特征"""
        phi = self.base_policy.features(x, t)
        return phi @ (self.B @ self.A).T
```

### IP-507 ASSP：安全子空间投影

```python
@dataclass
class AdapterSafetySubspaceProjection:
    """ASSP：训练期把 LoRA 更新约束在 rank ≤ r 且 ‖BA‖_F ≤ ρ_safe 的安全子空间。"""
    rank: int
    rho_safe: float
    lam: float = 1.0

    def loss(self, task_loss: torch.Tensor, adapter: LowRankSafetyAdapter) -> torch.Tensor:
        """L = L_task + λ·max(0, Λ_max‖BA‖_F - ρ_safe)²（软约束，训练期）"""
        excess = max(0.0, adapter.delta_norm() - self.rho_safe)
        return task_loss + self.lam * excess ** 2

    @torch.no_grad()
    def project_(self, adapter: LowRankSafetyAdapter):
        """SVD 截断到 rank ≤ r，再按 Frobenius 球缩放至 ρ_safe"""
        W = adapter.B @ adapter.A
        U, S, Vh = torch.linalg.svd(W, full_matrices=False)
        r = self.rank
        W_r = (U[:, :r] * S[:r]) @ Vh[:r]
        n = torch.linalg.matrix_norm(W_r, ord='fro').item()
        if n > self.rho_safe:
            W_r = W_r * (self.rho_safe / n)
        adapter.B, adapter.A = self._factorize(W_r, r)

    @staticmethod
    def _factorize(W, r):
        U, S, Vh = torch.linalg.svd(W, full_matrices=False)
        S_sqrt = S[:r].sqrt()
        return (U[:, :r] * S_sqrt), (S_sqrt[:, None] * Vh[:r])
```

### IP-508 EFA-v8：七硬门 + CBF 证书 + 秩预算

```python
@dataclass
class EvidenceForgingAssemblerV8:
    """EFA-v8：七硬门不变（碰撞门原地升级为 kc_cbf）+ 低秩安全适配。
    任何 LoRA 适配器都被逐 tick 的 CBF-QP 硬投影回安全集。"""
    v7: EvidenceForgingAssemblerV7
    csf: CBFSafetyFilter
    adapter: LowRankSafetyAdapter
    assp: AdapterSafetySubspaceProjection
    u_backup: Callable
    rho_safe: float
    alpha: float = 0.3

    def select(self, L, t_now, context):
        # 1. v7 七硬门先给出名义轨迹（含 DIM/DRC/DAC 需求路由）
        ok, x_nom, tag = self.v7.select(L, t_now, context)
        if not ok:
            return False, None, tag

        # 2. 秩预算软门（不放松任何硬门，只收紧 ECS）
        eta_rank = self._rank_factor()
        if eta_rank <= 0.0:
            return False, None, 'RANK_BUDGET_EXCEEDED'

        # 3. 沿名义轨迹逐 tick 做 CBF 投影（连续碰撞证书）
        x = context.x0
        safe_controls = []
        for u_pi in x_nom.controls:
            u, status = self.csf.step(x, u_pi, self.u_backup(x))
            if status == 'CBF_INFEASIBLE_BACKUP':
                return False, None, 'CBF_INFEASIBLE'      # fail-closed
            safe_controls.append(u)
            x = self.csf.f0(x) + self.csf.g(x) @ u
            if self.csf.h(x) < 0:                          # 数值兜底
                return False, None, 'CBF_VIOLATION'
        return True, x_nom.with_controls(safe_controls), 'FORGED_CBF_LORA_V8'

    def _rank_factor(self) -> float:
        ratio = self.adapter.delta_norm() / max(self.rho_safe, 1e-9)
        return max(0.0, 1.0 - max(0.0, ratio - 1.0))

    def ecs_v8(self, x, n_flow, s_emo, eta_factors) -> float:
        """ECS_v8 = ECS_v7 · η_rank（碰撞安全由 kc_cbf 硬门保证，不进软分）"""
        return self.v7.ecs_v7(x, n_flow, s_emo, eta_factors) * self._rank_factor()
```

### 集成流水线（v7 → v8）

```
离线/慢时域：
  屏障拟合（小时级）：从几何场景拟合 h（多障碍取 min 或 max 组合）+ 估计 L_h、Λ_max
  LoRA 适配训练（小时级）：按需求簇训练 r∈{2,4,8,16} 的适配器
  ASSP 约束（训练期）：SVD 截断 + Frobenius 球投影，落盘前校验 ‖BA‖_F ≤ ρ_safe
  联邦下发：适配器权重、ρ_safe、h 参数、L_h、α → 站内签名分发

在线准入（亚秒级）：
  DIM 需求路由 ──▶ 选 LoRA 适配器（rank r, ‖BA‖_F）
  EFA-v7 七硬门 ──▶ 名义轨迹 x_nom
  for each tick:  u_pi ──▶ CBF-QP(u*) ──▶ 若不可行 → u_backup (fail-closed)
  输出 kc_cbf 通过的安全轨迹

在线控制环（目标 < 1.0 ms）：
  CBF-QP 为 9 维小 QP（OSQP 热启动）≈ 0.1~0.3 ms/tick
  LoRA 增量 B·A·φ 为 O(d·r)，< 0.02 ms
  η_rank 计算 O(d·r)，< 0.01 ms
```

## 4. 正确性论证（增量更新）

### 定理 13（采样鲁棒 CBF 前向不变）

**陈述**：设膨胀屏障 h̃(x) = h(x) − L_h·Δt。若 h̃(x_0) ≥ 0，且对每个控制步 k 有 h̃(x_{k+1}) ≥ (1−α)·h̃(x_k)，则对任意 t ≥ 0 有 h(x(t)) ≥ 0。

**证明**：由递推 h̃(x_k) ≥ (1−α)^k·h̃(x_0) ≥ 0。对 t ∈ [kΔt,(k+1)Δt]，由 h 的 Lipschitz 性 |h(x(t)) − h(x_k)| ≤ L_h·|t−kΔt| ≤ L_h·Δt，故 h(x(t)) ≥ h(x_k) − L_h·Δt = h̃(x_k) ≥ 0。∎

**意义**：把「点与点之间的碰撞」纳入证书，隧道效应被结构性排除。

### 定理 14（低秩扰动界）

**陈述**：设 ΔW = B·A，则适配引起的单步屏障变化满足
|h(x_{k+1}^{ΔW}) − h(x_{k+1}^{0})| ≤ Λ_max·‖BA‖_F + O(‖BA‖_F²)，
其中 Λ_max = sup_x ‖L_g h‖·‖J_π(x)‖。

**证明**：h(x_{k+1}) = h(f(x_k,u_k))，u = π_θ(x)。对 θ 在 θ_0 处一阶展开：δh = (L_g h)ᵀ·J_π·vec(ΔW) + R，余项 |R| ≤ ½M‖ΔW‖²。由 ‖vec(ΔW)‖₂ = ‖BA‖_F 与 Cauchy–Schwarz，|δh| ≤ ‖L_g h‖·‖J_π‖_op·‖BA‖_F + O(‖BA‖²)。∎

### 定理 15（安全秩预算充分性 ⇒ fail-closed）

**陈述**：若 ‖BA‖_F ≤ ρ_safe = α·h_min/Λ_max，且备份控制 u_b 满足 h̃(f(x,u_b)) ≥ (1−α)h̃(x)，则 CBF-QP 对任意名义动作 u_π 均可行，且 Exec_EFA-v8 ⊆ Exec_CADVS-v7 ∩ Safe。

**证明**：由定理 14，适配使单步屏障下降最多 α·h_min；从 h̃ ≥ h_min 出发，CBF 约束右端仍容许 u_b，故可行域非空，QP 至少可取 u_b。硬门判定与 v7 一致（kc_cbf 仅收紧），软因子 η_rank ≤ 1 仅收紧 ECS，故执行集为 v7 子集且落在安全集内。∎

### 诚实声明

- **线性化误差**：定理 14 是一阶界，余项 O(‖BA‖²)；大秩/大范数时需二阶校正或直接收缩 ρ_safe。
- **Lipschitz 保守性**：L_h、Λ_max 的估计若偏大 → 过度限制适配；若偏小 → 证书失效（不安全）。估计误差方向必须保守。
- **模型失配**：CBF 依赖已知 f、g；真实动力学偏差会侵蚀前向不变性，需鲁棒/自适应 CBF 或在线辨识。
- **多障碍/非凸**：单一 h 难以表达复杂障碍，需多个 CBF 的组合（min 形式易致 QP 不可行），需 nonsmooth CBF 或高阶 CBF。
- **执行器权限**：若物理上已无法避免碰撞（如距离小于最小制动距离），任何 QP 都不可行，只能进入 u_b 并报告失败。

## 5. 实验设计与验证计划（仿真 → 实机）

### 5.1 实验设计（MuJoCo 3.x + MJX）

- **平台**：UR10e（6DOF）+ 移动底盘（2DOF）+ 动态障碍物发生器；策略 50 Hz，底层控制 1 kHz，碰撞检测 10 kHz（用于捕捉子 tick 碰撞）。
- **数据集 / 适配器**：
  - 按需求簇训练 4 个 LoRA 适配器，rank r ∈ {2,4,8,16}
  - 障碍场景：静态/动态/窄走廊/突发闯入四类，各 200 条
  - 屏障参数：h 由几何 sdf 拟合，L_h 由轨迹采样上界估计，Λ_max 由 Jacobian 采样估计
- **对照**：v7-full、v8-full、消融 A21（关闭 CBF，仅点态门）、A22（无 ASSP，无约束 LoRA）、A23（rank 扫描 r=2/4/8/16）、A24（Λ_max 低估 20% 对抗性设置）、A25（关闭需求路由，单一适配器）
- **场景**：
  - (a) 动态障碍横穿：障碍以 1.5 m/s 穿过工作空间 → 检验连续证书
  - (b) 窄走廊：安全裕度逼近 h_min → 检验 QP 可行性与备份切换
  - (c) 采样隧道：高速运动 + 100 Hz 策略 → 对比点态门与膨胀屏障
  - (d) 需求误推断 + 激进适配器：DIM 路由到错误适配器 → 检验「安全但错误」的边界
  - (e) 执行器饱和：贴近障碍时权限不足 → 检验 fail-closed 与失败上报
- **指标**：子 tick 碰撞率、CBF 违反率、QP 不可行率、干预率、任务成功率、适配质量-秩曲线、P99 延迟、最小屏障裕度 h_min 分布、误推断下的安全保持率。

## 7. 本轮最大风险（最终确认）

**一句话**：**「安全 ≠ 正确」的假信心**——CBF 只保证不碰撞，无法保证适配后的行为符合用户真实需求，一个被误推断需求驱动的 LoRA 可能做出「物理安全但任务/社交上错误」的动作，而连续碰撞证书反而让系统显得比实际更可靠。
