# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「比赛策略」×「语言指令」）

> R69 让系统学会「看、问、触」，并用 VoI 给每一次提问定价。但它有两条从未被检验的隐含假设：
> **(i) 对话者是一个非策略、平稳的信息源**——回答的分布不随「你问了什么、你显得多不确定」而改变，于是 VoI 是良定义的、非负的信息收益；
> **(ii) 语言只用来「查询」**——所有话语都被当作「关于世界隐状态 M 的带噪观测」，系统自己的语言没有博弈后果。
>
> 真实竞赛把这两条同时击穿。第一，**比赛里的提问会长出对手**：你一问「红杯子在哪」，对方就知道你没看见，就可以选择告诉你左边还是右边；提问本身是一次可被利用的**信息披露**，VoI 完全可以为负。第二，**比赛里绝大多数语言是命令而非断言**：裁判的判罚、队友的调度、规则的禁止、对手的挑衅——它们改变的不是「世界是什么」，而是「你被允许/被要求做什么、做了会被怎样惩罚」。把命令当观测会得出荒谬结论：当「把红杯子拿来」与视觉冲突时，R69 会去下调视觉置信度；正确做法是承认**指令约束可行集与收益，事实约束信念，两者不能混进同一张似然表**。
>
> 两个灵感各补一刀：
> - **比赛策略**给出正确的评价尺度：不再是「熵降了多少」，而是「均衡收益变了多少」，并显式计入**泄漏成本**与**时钟机会成本**；同时要求策略**不可被利用**（exploitability 有界），这又和「语言承诺需要可预测」形成张力。
> - **语言指令**给出正确的作用对象：指令是带**权威、道义算子、时限、预设**的言语行为；它首先改变可行集与收益，其次才（若它是断言）改变信念。合规不等于服从：可以**质疑、要求澄清、带理由违抗**。
>
> 再加两条承重结构：
> - **安全必须对手无关，性能才对手自适应**。若允许对手模型扩大安全包络，对手只要「演得像队友」就能把你骗出安全区——这正是 R69「被投毒模态驱动交互」的博弈版。故做双层：外层是取全类型交集的 minimax 安全盾，内层是对手自适应的 Bayes / Stackelberg 策略层。
> - **第二意见升级为「策略惊讶度」**：一句话语义再合理，若时机、指向、与说话者自身利益不一致，就可疑。它补上 R69「被证实的错误」的漏洞——**说得对不等于动机对**。
>
> 核心命题：**把 R69 的「向被动传感器采样」升级为「在部分可观测随机博弈中做信号交互」；把「语言」从查询载体升级为带道义效力与承诺效力的博弈动作；用「对手无关安全盾 × 对手自适应策略层」双层分解，使安全永不被对手模型污染。** 命名 **GAMBIT-RAS**（Game-theoretic Adversarial Multi-agent Bayesian Instruction-Trust Risk-Adaptive System）——弃子开局：一次有意的信息披露、一次可验证的承诺，都是为长期优势付出的当期代价。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**对方为什么要告诉我/命令我这件事，我该信几分、听几分、什么时候反过来利用它**」。

## 0. 直觉与动机

**灵感 1（比赛策略 → 提问有对手，VoI 会变负）**
直觉：合作场景里问问题像拿温度计测室温；竞赛里问问题像在牌桌上问对手「你手里是什么牌」。你不但可能得到一句为操纵你而设计的话，还把「我很不确定」这条信息免费送给了对方。更狠的是，时钟是对手：你停下来问的每一秒，对方都在推进自己的计划。于是「值不值得问」要同时算三笔账：**信息收益**、**泄漏成本**（你的查询暴露了你的信念）、**机会成本**（时间与先手）。R69 的 VoI 只算了第一笔。严格地说，正确的量是「在均衡中，多这一个信息动作让我的期望收益变化多少」——**策略性信息价值 SVoI**，它完全可能为负。负 SVoI 的提问不是保守，是**送人头**。

**灵感 2（语言指令 → 命令是契约，不是观测）**
直觉：「把红杯子拿给我」不描述世界，它**规定世界应当怎样**。它有说话者（谁有权要求）、道义算子（必须/可以/禁止）、命题内容（拿什么、给谁）、时限（在裁判吹哨前）。把它当观测，等价于相信「有人命令我拿红杯子」就等于「红杯子存在且可拿」——在竞赛里这很危险：对手完全可以用一句假指令把你引到错误区域。正确分层是：**事实层**（传感器与断言）更新信念；**道义层**（指令）更新可行集与收益；**语用层**（谁说的、为什么现在说）更新对说话者意图的信念。三层各有证据纪律，不能互相冒充。

**灵感 3（承诺 → 语言可信度由「能否绑定未来」决定）**
直觉：竞赛里「我保证」「我一定会」是最廉价的话。语言只有在**能绑定未来行为**时才可信：公开一个可验证的计划、把动作做成不可逆的落子、或用重复博弈的声誉作抵押。于是机器人自己的语言也要分级：**廉价话语（cheap talk）** 只影响对手信念，**绝不能回流成自己的证据**（否则模型会被自己的幻觉自我催眠）；**可信承诺（commitment）** 必须附带可审计的绑定。R69 的 MINT 只生成「问」，本轮动作空间还要长出 **announce / commit / challenge / refuse**——它们都是 ξ 的一部分，也都必须过安全认证。

**灵感 4（对偶结构 → 安全对手无关，性能对手自适应）**
直觉：R69 把不确定性拆成 aleatoric / epistemic。这里有一个同构：**安全必须对手无关**（对最坏类型成立），**性能应该对手相关**（对当前后验最优）。若允许对手模型扩大安全包络，对手只要「演得像队友」就能把你骗出安全区——这正是 R69「被投毒的模态驱动交互」的博弈版。所以采用双层：外层是**对手无关的安全盾** \(W_{\min}=\bigcap_{\theta\in\Theta}\mathrm{Safe}(\theta)\)，内层是**对手自适应的策略**。当类型后验收敛到「合作、非策略、无指令」时，内层退化为 R69，外层退化为 R68 的 λ 保守。安全侧永不让步。还有一层反身性：对手也在更新对你的信念，所以要维护共同信念与层级推理，深度 d 本身用元推理选。

**灵感 5（第二意见 → 语用/策略一致性：说得对 ≠ 动机对）**
直觉：R69 的 FMA 用「动作在策略密度下的似然」做标定不可吸收的第二意见。这里可以做一个**语用一致性**通道：一句话即使语义上完全合理，若它**时机、指向、与说话者自身利益的一致性**不对，就可疑。对手在你即将得分时突然「好心」提醒你规则——这句话的**策略似然**极低。定义**策略惊讶度**：观测信号相对于「该类型说话者在均衡下的信号分布」的负对数似然。它不依赖语义解析，也不能靠「话说得漂亮」掩盖，正好补上 R69 对「被证实的错误」的漏洞。此外，指称的**预设失败**（「那个红杯子」但其实有两个）本身就是关于说话者世界模型的证据：要么他错了，要么他在试探你。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（GAMBIT-RAS 总览）** GAMBIT-RAS = (SPG, LAP, ITS, SVoI, CBA, PAA, DSS, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **对手无关安全盾**：任何策略选择不得逃出 \(W_{\min}=\bigcap_{\theta\in\Theta}\mathrm{Safe}(\theta)\)；语言指令只可缩小可行集、添加偏好项，**永不可扩大** \(W_{\min}\)；
(iii) **可信性分级**：语言分为 cheap-talk / verifiable-commitment / directive，证据权重与审计要求不同；任何单一不可信信号不得改变安全包络，cheap-talk 不得回流为自身证据。

**定义 311（策略交互博弈 SPG）** 部分可观测随机博弈 \(G=(N=\{R,H_1,\dots,H_m\},S,\{A_i\},O,T,\{Z_i\},\{u_i\},\Theta)\)。转移 \(T\) 依赖联合动作，观测 \(Z_{H}\) 依赖机器人动作（**策略性观测**：你怎么看/问，决定对方怎么显形）。机器人维护对手**类型后验** \(b(\theta_{-R})\) 与共同信念 \(\mu\)。与 R69 的单智能体 POMDP 的差别在于：\(T\) 与 \(Z\) 都含对手的最优反应，故「动作—观测」不是外生的。

**定义 312（语言动作五元组 LAP）** 每条语言输入 \(\ell\) 解析为 \(\ell=(\kappa,\alpha,\mu,\varphi,\tau,\mathrm{PF})\)：
- \(\kappa\in\{\text{assert},\text{directive},\text{question},\text{promise},\text{threat},\text{expressive}\}\)：言语行为类型；
- \(\alpha\in\mathfrak{A}\)：权威/身份（裁判/队友/对手/操作员）；
- \(\mu\in\{\text{oblige},\text{permit},\text{forbid},\text{none}\}\)：道义算子；
- \(\varphi\)：命题内容（含指称与预设）；
- \(\tau\)：时限/有效期；
- \(\mathrm{PF}\)：预设失败集合（指称唯一性、存在性、可及性）。
解析器输出的是上述五元组的**分布** \(p(\ell)\)，而非单点判决。

**定义 313（道义可行性约束）** 指令 \(\ell\) 诱导可行集 \(A_\ell(s)\subseteq A\)：`forbid φ` 删除使 φ 成立的原子动作；`oblige φ` 加入软约束 \(u_\ell(a,s)=-\rho_\ell\,\mathbf{1}[\neg\varphi(a,s)]\)；`permit φ` 不约束。执行层强制 \(A_{\mathrm{exec}}=A_\pi\cap A_\ell\cap W_{\min}\)。**推论**：指令只能缩小可行集或改偏好，不能扩张安全包络。

**定义 314（权威合法性）** \(a(\alpha)\in[0,1]\) 由规则手册先验、身份验证、时空有效性合成。仅当 \(a(\alpha)\ge a_{\min}\) 时，\(\ell\) 才被允许施加道义约束；否则降级为 `assert`（只进事实层，不改可行集）。

**定义 315（指令信任分 ITS）** \(\mathrm{ITS}(\ell)=f\big(a(\alpha),\,\mathrm{IC}(\ell),\,V(\ell),\,\mathrm{PF}(\ell),\,\mathrm{cons}(\ell)\big)\)：
- \(\mathrm{IC}(\ell)\)：激励相容度——给定 α 的目标，说真话是否弱占优（Bayes 一致 / 机制设计意义下）；
- \(V(\ell)\)：可验证性——\(\varphi\) 能否被独立传感器或第二条正交证据核验；
- \(\mathrm{PF}(\ell)\)：预设失败严重度；
- \(\mathrm{cons}(\ell)\)：与既有证据、其他指令、规则文本的一致性。
\(\mathrm{ITS}\in[0,1]\)；低于 \(\tau_{\mathrm{trust}}\) 时指令进入 contest 通道，**不得直接执行**。

**定义 316（合规决策：合规 ≠ 服从）** 机器人选择 \(c\in\{\text{comply},\text{clarify},\text{contest},\text{defect}\}\)：comply 执行 \(A_\ell\cap W_{\min}\)；clarify 调用 R69 的 MINT 信息动作（问），但受时钟与泄漏成本约束；contest 执行任务目标并广播可审计理由；defect 拒绝并留痕，触发审计。选择 \(\arg\max\) 期望收益 − 违规罚 − 社会/时钟成本。**defect 是合法动作**，其合法性由审计与理由质量保证。

**定义 317（策略性信息价值 SVoI 与操纵溢价）** 对信息动作 \(g\)（R69 的看/问/触，加 announce/challenge）：
\[
\mathrm{SVoI}(g)=\mathbb{E}_{\theta,\,y\sim\sigma^*_\theta(\cdot\mid g,b)}\big[u_R(a_R^*(b(\cdot\mid y)),\theta)\big]-u_R(a_R^*(b),\theta)-c(g)-\lambda_{\mathrm{leak}}L(g;b),
\]
其中 \(\sigma^*_\theta\) 是对手在均衡下的**信号策略**（会响应你的查询），\(L(g;b)\) 是查询对对手泄漏的关于你信念 \(b\) 的信息量。**SVoI 可以 < 0，即使 R69 的 VoI > 0**。定义**操纵溢价** \(\mathrm{MP}(g)=\mathrm{VoI}_{R69}(g)-[\mathrm{SVoI}(g)+c+\lambda_{\mathrm{leak}}L]\ge 0\)。

**定义 318（时钟与机会成本）** 竞赛时钟使单位时间的机会成本为 \(\lambda_{\mathrm{clock}}\cdot(\text{剩余任务价值}/\text{剩余时间})\)。SVoI 中的 \(c(g)\) 显式包含 \(\lambda_{\mathrm{clock}}\Delta t(g)\)。\(\lambda_{\mathrm{clock}}\) 大时，即使信息增益高也可能不问——因为「问」本身让对手多走一步。

**定义 319（层级推理深度与元推理）** 对手类型后验按 level-k 认知层级建模，机器人深度 \(d_R\)。深度选择本身是一个 SVoI 问题：\(d^*=\arg\max_d\big(\mathbb{E}[\text{payoff}\mid d]-c_{\mathrm{compute}}(d)\big)\)。给出 level-k 策略与 Bayes-Nash 策略的收益差距上界（A103）。

**定义 320（廉价话语与可信承诺）** 机器人语言输出分两类：
- **cheap-talk \(\chi\)**：不影响自身未来动作的声明；只能进入对手信念，**不得进入机器人自己的证据集**（防自我催眠/幻觉固化）；
- **commitment \(\gamma\)**：附带可验证绑定 \(B(\gamma)\)（公开计划哈希、物理锁存动作、规则登记）。
\(\mathrm{credible}(\gamma)\iff \exists B:\ \text{auditable}(B)\ \wedge\ \mathrm{deviation\_gain}(\gamma)<\mathrm{breach\_cost}(\gamma)\)。

**定义 321（策略惊讶度 PAA）** 说话者类型的均衡信号分布 \(p_\theta(\ell\mid \mathrm{ctx})\)；策略惊讶度
\[
s(\ell)=-\log\sum_{\theta}b(\theta)\,p_\theta(\ell\mid \mathrm{ctx}),
\]
其判别特征只用**时机、指向、与说话者自身利益的一致性**，不依赖语义真值。**（ITS 高，s 高）** 是「说得漂亮但在操纵」的联合判别模式。

**定义 322（指令—事实分离更新）** 把观测拆成 \(o_{\mathrm{fact}}\)（传感器）与 \(\ell_{\mathrm{dir}}\)（指令）。信念更新只用 \(o_{\mathrm{fact}}\) 与 \(\kappa=\text{assert}\) 的语言；道义指令只改 \(u\) 与 \(A_\ell\)。**禁止把 directive 当作关于世界的事实证据**。反之，事实冲突不降低指令的权威 \(a(\alpha)\)，只降低 ITS 的可验证项 \(V(\ell)\)，触发 clarify。

**定义 323（指称歧义与澄清 VoI）** 指称歧义产生指称熵 \(H(\mathrm{ref})\)；澄清问题 \(q\) 的收益为 \(H(\mathrm{ref})-\mathbb{E}[H(\mathrm{ref}\mid y)]\)，减去时钟/泄漏成本。消歧优先级：**先自验（多模态证据）→ 再问队友 → 再问裁判 → 绝问对手**（除非作为对抗性探针）。与 R69 的模态歧义不同：这里的歧义在**语言指称空间**，且「问错人」会被误导。

**定义 324（混合策略与不可利用性）** 竞赛中策略需混合以不可被利用：\(\mathrm{exploitability}(\pi^*)\le\varepsilon_{\mathrm{expl}}\)。混合要求不可预测，承诺要求可预测——冲突的解法是**分层混合**：在承诺层固定策略族，在族内混合（commit to a mixed strategy），得到 commitment-mixed equilibrium。

**定义 325（道义冲突的词典序消解 LEX）** 多条指令冲突时按词典序消解：`安全不变式 > 高权威 > 更具体 > 更新近 > 默认`。若在同一优先级上仍冲突 ⇒ 强制 clarify，禁止静默择一。

**定义 326（证书 J_GAMBIT）**
\[
J_{\mathrm{GAMBIT}}=(J_{\mathrm{FLUID}},\ \mathrm{exploitability}_\varepsilon,\ \mathrm{ITS}_{p05},\ \mathrm{SVoI\_regret},\ \mathrm{leak\_budget\_used},\ \mathrm{commitment\_log\_hash},\ \mathrm{PAA}_{p95},\ \mathrm{policy\_hash}).
\]
Valid \(\iff\) Valid(\(J_{\mathrm{FLUID}}\)) \(\wedge\) exploitability \(\le\varepsilon_{\mathrm{expl}}\) \(\wedge\) 安全盾未越界 \(\wedge\) 承诺可审计。

**定义 327（两级退化与严格包含）** 当 (a) \(b(\theta_{\mathrm{coop}})\to1\)（合作、非策略、无指令），(b) \(\lambda_{\mathrm{clock}}\to0\)，(c) 输入无 directive 时，\(\mathrm{SVoI}\equiv\mathrm{VoI}\)、ITS 退化为 R69 的证据纪律、\(W_{\min}\) 退化为单个 Safe，GAMBIT-RAS 逐指令退化为 FLUID-RAS（R69）；进一步当 \(\mathrm{VoI}\le c\) 时退化为 R68。安全侧永不弱。

```python
# IP-264 SPG：策略交互博弈与类型信念（显式条件于「对方看得见我的历史」）
class StrategicGame:
    def __init__(self, type_space, signal_model, payoff, level_k=2):
        self.Theta = type_space                    # {coop, referee, adversary, confused}
        self.sigma = signal_model                  # p(signal | query, belief, theta)
        self.u, self.d = payoff, level_k

    def update_type(self, ell, action_hist):
        return bayes(self.b, likelihood=self.sigma.obs(ell, action_hist))

# IP-265 LAP：语言动作解析（言语行为 + 道义 + 预设）
def parse_language(utterance, ctx):
    kappa = classify_speech_act(utterance)          # assert/directive/question/promise/threat
    alpha = identify_authority(utterance, ctx)      # referee/teammate/opponent/operator
    mu, phi, tau = parse_deontic(utterance)         # oblige/permit/forbid
    pf = check_presupposition(phi, ctx)             # 指称/唯一性/存在性
    return Act(kappa, alpha, mu, phi, tau, pf)

# IP-266 ITS：指令信任分
def instruction_trust(act, ctx):
    a  = authority_score(act.alpha, ctx.rules)
    ic = incentive_compatibility(act, ctx.alpha_goal)   # 说真话是否弱占优
    v  = verifiability(act.phi, ctx.sensors)            # 能否被正交证据验证
    return fuse(a, ic, v, act.pf.severity, consistency(act, ctx.belief))

# IP-270 DSS：道义安全盾（先取交，再谈偏好）
def deontic_shield(act, s, trusted):
    A_ell = feasible_under(act.mu, act.phi, s) if trusted else ALL_ACTIONS
    return A_ell & W_min(s)                             # 安全包络永不扩大

# IP-267 SVoI：含泄漏与时钟的策略性信息价值
def choose_signal(acts, b, theta, budget_clock):
    best = None
    for g in candidate_signals(acts):                   # gaze/probe/ask/announce/challenge
        if not budget_clock.allow(g):      continue
        if not dss.certify(g):             continue      # 信息动作也要过安全认证
        gain  = E[u_R(a_star(update(b, y)), theta) for y in theta.sigma(g, b)]
        gain -= u_R(a_star(b), theta)
        score = gain - leak_cost(mutual_info(g, b)) - clock_cost(g) - c(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None     # 负 SVoI → 不问

# IP-268 CBA：可信承诺与绑定审计
def is_credible(commitment, binding):
    if commitment in cheap_talk: return False            # 不得回流为自身证据
    return binding.auditable and deviation_gain(commitment) < breach_cost(commitment)

# IP-269 PAA：策略惊讶度（不看语义真值，只看时机/指向/利益）
def pragmatic_anomaly(ell, b_theta, ctx):
    return -logsumexp([b_theta[t] * sigma_t.logprob(ell, ctx) for t in b_theta])

# IP-274 主闭环（继承 R69，在「交互决策」处插入博弈层）
def GAMBIT_RAS_round(M, obs):
    # 0) R69 感知 / 标定 / 流策略照旧
    z, o    = M.mtm.forward(obs)
    c, U_cal = M.cof.step(...)
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, M.k()), z, M.fmp.mode_head)
    # 1) 语言分层：先说话语行为与道义，再谈信念
    act = M.lap.parse(obs.language, M.ctx)
    its = M.its.score(act, M.ctx)
    paa = M.paa.score(obs.language, M.spg.b_theta, M.ctx)
    # 2) 事实层 vs 道义层分离更新
    if act.kappa == 'assert':
        M.spg.update_type(act, obs.history)              # 只有断言更新信念
    else:
        M.spg.deontic_log.append((act, its, paa))        # 指令只进道义层
    # 3) 可信度决定合规方式：合规 / 质疑 / 带理由违抗
    trusted  = (its >= TAU_TRUST) and (paa <= TAU_PAA)
    decision = M.dss.arbitrate(act, s, trusted)          # comply/clarify/contest/defect
    # 4) 策略层：SVoI 决定看不看 / 问不问 / 宣不宣布 / 挑不挑衅
    g = M.svoi.choose_signal(modes, M.spg.b_theta, M.budget)
    # 5) 流策略在「道义可行集 ∩ 安全盾」内采动作
    A = M.ach.propose(o, H=M.vista.H) & decision.feasible
    k = M.c_ras_wm.certified_prefix(A, ..., M.vista.pred)
    # 6) 负 SVoI / 高 PAA / 低 ITS：单调退回 R69 保守层
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale) if g else lam_floor(U_ale + U_epi))
    if g is None or paa > TAU_PAA:
        lam = max(lam, lam_floor(U_ale + U_epi))         # R69 / R68 边界
    # 7) 选模态、参与式审计、证书
    mode = select_mode(modes, U_epi, lam)
    M.vqa_g.submit_async(act, its, paa, g, decision)
    return k, lam, mode, decision
```

## 3. 推导

**引理 19（操纵溢价与 R69 退化）** 设 R69 的 VoI 为 \(\mathrm{VoI}_0(g)=H(M\mid o)-\mathbb{E}_{y\sim p_0}[H(M\mid o,y)]\)，\(p_0\) 为平稳传感器似然；SVoI 如定义 317。则
(i) \(\mathrm{SVoI}(g)\le L_V\,\mathrm{VoI}_0(g)-c(g)-\lambda_{\mathrm{leak}}L(g;b)\)，其中 \(L_V\) 是决策价值对信念全变差的 Lipschitz 常数（A100）；
(ii) 若 \(\sigma^*_\theta(\cdot\mid g,b)=p_0(\cdot\mid o)\)（非策略、与 b 无关），则 \(L=0\) 且 \(\mathrm{SVoI}(g)=\mathrm{VoI}_0(g)-c(g)\)——即 R69 定义 298；
(iii) 操纵溢价 \(\mathrm{MP}(g)=\mathrm{VoI}_0(g)-[\mathrm{SVoI}(g)+c+\lambda_{\mathrm{leak}}L]\ge0\)，当且仅当信号策略不随你的查询/信念改变时为 0。
**系**：竞争里 R69 会系统性高估提问价值，高估量恰是 MP。**负 SVoI 的提问，是把不确定性当礼物送给对手。**

**引理 20（道义安全的对手无关性）** 若执行层强制 \(A_{\mathrm{exec}}=A_\pi\cap A_\ell\cap W_{\min}\)，且 \(W_{\min}=\bigcap_{\theta\in\Theta}\mathrm{Safe}(\theta)\neq\varnothing\)，则对任意对手类型 θ 与任意（可能被投毒/伪造的）指令 ℓ，执行动作的物理风险 \(\le\varepsilon_{\mathrm{safe}}(\theta)\)，且指令只能**缩小**可行集。证明：可行集对交运算单调，安全盾对全类型取交，故 \(A_{\mathrm{exec}}\subseteq\mathrm{Safe}(\theta)\) 对每个 θ 成立。\(\square\)
**系**：语言永远不能把机器人骗出安全区，只能把它骗进一个**更保守的子集**——最坏后果是任务失败，不是安全事故。

**引理 21（廉价话语中性、承诺扩展）**
(i) 若语言 \(o_R\) 不影响自身未来动作（cheap-talk），把它加入自己的证据集不改变最优动作，只会引入自我确认偏差（定义 320 明令禁止）；
(ii) 重复博弈中，若承诺 γ 附带可审计绑定 \(B(\gamma)\) 使偏离收益 < 违约成本，则 γ 可信；可信承诺使均衡收益集单调扩展，无可验证绑定的语言不扩展均衡收益集。
**系**：机器人说「我会 X」不构成「我会 X」的证据；只有**绑定**构成。

**引理 22（层级深度的收益—计算权衡）** 在 A103（level-k 层级稳定、共同先验）下，收益随深度 d 单调不减但增量以几何速率衰减，而计算成本至少线性增长；故存在有限最优深度 \(d^*\)，且 \(d^*\le \lceil\log_\kappa(\Delta u/\Delta c)\rceil\)。**系**：不必解完整 Bayes-Nash，只需解到「增量收益 < 增量成本」的深度。

**定理 18（GAMBIT 对 FLUID 的严格包含与可利用性有界）** 在 A99–A103 下：
(i) **安全**：GAMBIT 的执行风险对所有 \(\theta\in\Theta\) 不高于 FLUID（引理 20，\(A_{\mathrm{exec}}\subseteq A_{\mathrm{FLUID}}\)）；
(ii) **退化**：当 \(b(\theta_{\mathrm{coop}})\to1\)、\(\lambda_{\mathrm{clock}}\to0\)、输入无 directive 时，SVoI ≡ VoI、ITS 退化为 R69 的证据纪律、\(W_{\min}\) 退化为单个 Safe，两者逐指令相同（定义 327）；
(iii) **策略**：GAMBIT 的动作集 \(\supseteq\) FLUID 的动作集 \(\cup\{\text{不行动},\text{承诺},\text{质疑}\}\)，且 SVoI 是均衡收益的一阶无偏估计（A100），故其选择在期望收益上弱支配「照 FLUID 的 VoI 行动」；对策略性对手，混合层的 exploitability \(\le\varepsilon_{\mathrm{expl}}\)。
> 注意 (iii) 的「弱支配」限定在**模型正确**的前提下；模型错误的风险见第 6 节。

**定理 19（指令不改变安全包络、只改变偏好，控制无突变）** 道义算子只通过 \(A_\ell\)（缩小可行集）与 \(u_\ell\)（加惩罚）进入决策；安全盾在偏好之前取交；承诺/质疑/违抗都发生在执行层之上。故任何指令、任何可信度、任何对手反应下，λ 单调不降地退化为 R69；提交/换装不变式（R68 定理 15）保持，控制连续、无突变。

**定义 319–320（层级推理与承诺）** level-k 深度 d 由元推理选（收益—计算折中）；语言分 cheap-talk（不得回流为自身证据）与 commitment（须有可审计绑定 `B(γ)`）。

```python
    return A_ell & W_min(s)                       # 安全包络永不扩大

# IP-267 SVoI：含泄漏与时钟的策略性信息价值（负值即不问）
def choose_signal(acts, b, theta, budget_clock):
    best = None
    for g in candidate_signals(acts):
        if not budget_clock.allow(g) or not dss.certify(g): continue
        gain = E[u_R(a_star(update(b, y)), theta) for y in theta.sigma(g, b)] - u_R(a_star(b), theta)
        score = gain - leak_cost(mutual_info(g, b)) - clock_cost(g) - c(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-268 CBA / IP-269 PAA：承诺可信性、策略惊讶度
def is_credible(gamma, binding):
    return gamma not in cheap_talk and binding.auditable \
           and deviation_gain(gamma) < breach_cost(gamma)

def pragmatic_anomaly(ell, b_theta, ctx):
    return -logsumexp([b_theta[t] * sigma_t.logprob(ell, ctx) for t in b_theta])

# IP-274 主闭环（继承 R69）
def GAMBIT_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal = M.cof.step(...)
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, M.k()), z, M.fmp.mode_head)
    act = M.lap.parse(obs.language, M.ctx)
    its = M.its.score(act, M.ctx); paa = M.paa.score(obs.language, M.spg.b_theta, M.ctx)
    if act.kappa == 'assert': M.spg.update_type(act, obs.history)   # 只有断言更新信念
    else:                     M.spg.deontic_log.append((act, its, paa))
    trusted  = (its >= TAU_TRUST) and (paa <= TAU_PAA)
    decision = M.dss.arbitrate(act, s, trusted)                     # comply/clarify/contest/defect
    g = M.svoi.choose_signal(modes, M.spg.b_theta, M.budget)
    A = M.ach.propose(o, H=M.vista.H) & decision.feasible
    k = M.c_ras_wm.certified_prefix(A, ..., M.vista.pred)
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale) if g else lam_floor(U_ale + U_epi))
    if g is None or paa > TAU_PAA: lam = max(lam, lam_floor(U_ale + U_epi))
    mode = select_mode(modes, U_epi, lam)
    M.vqa_g.submit_async(act, its, paa, g, decision)
    return k, lam, mode, decision
```

## 4. 推导

**引理 19（操纵溢价与 R69 退化）** \(\mathrm{SVoI}(g)\le L_V\mathrm{VoI}_0(g)-c-\lambda_{\mathrm{leak}}L\)；当 \(\sigma^*=p_0\)（非策略传感器）时 \(L=0\) 且 \(\mathrm{SVoI}=\mathrm{VoI}_0-c\)，即 R69 定义 298；操纵溢价 \(\mathrm{MP}=\mathrm{VoI}_0-[\mathrm{SVoI}+c+\lambda_{\mathrm{leak}}L]\ge0\)，当且仅当信号策略不随查询/信念改变时为 0。**系**：负 SVoI 的提问是把不确定性当礼物送给对手。

**引理 20（道义安全的对手无关性）** 强制 \(A_{\mathrm{exec}}=A_\pi\cap A_\ell\cap W_{\min}\)，\(W_{\min}=\bigcap_\theta\mathrm{Safe}(\theta)\neq\varnothing\)，则对任意 θ 与任意（可能被投毒/伪造的）指令，执行风险 \(\le\varepsilon_{\mathrm{safe}}(\theta)\)，且指令只能缩小可行集。证明：交运算单调 + 对全类型取交。**系**：语言只能把机器人骗进更保守的子集，最坏是任务失败，不是安全事故。

**引理 21（廉价话语中性、承诺扩展）** cheap-talk 不改变自身最优动作，加入自身证据集只会引入自我确认偏差（定义 320 禁止）；带可审计绑定、偏离收益 < 违约成本的承诺可信，且使均衡收益集单调扩展；无可验证绑定的语言不扩展。**系**：说「我会 X」不构成「我会 X」的证据，绑定才构成。

**引理 22（层级深度折中）** A103 下收益随 d 单调不减但增量几何衰减，成本至少线性增长，故存在有限 \(d^*\le\lceil\log_\kappa(\Delta u/\Delta c)\rceil\)；不必解完整 Bayes-Nash。

**定理 18（对 FLUID 的严格包含）** A99–A103 下：(i) 安全对所有 θ 不弱于 FLUID（引理 20）；(ii) 当 \(b(\theta_{coop})\to1\)、\(\lambda_{clock}\to0\)、无 directive 时逐指令相同（定义 327）；(iii) 动作集包含 FLUID ∪{不行动,承诺,质疑}，SVoI 为均衡收益一阶无偏估计，故期望收益弱支配「照 FLUID 的 VoI 行动」，对策略性对手 exploitability ≤ ε。**注**：(iii) 的弱支配以模型正确为前提，模型风险见第 7 节。

**定理 19（指令只改偏好、不改安全包络，控制无突变）** 道义算子只经 \(A_\ell\)（缩小）与 \(u_\ell\)（惩罚）进入决策，安全盾在偏好之前取交；故任何指令/可信度/对手反应下，λ 单调不降地退化为 R69，提交/换装不变式（R68 定理 15）保持。

## 7. 本轮最大风险

**一句话**：GAMBIT-RAS 的全部策略收益押在「对手类型模型 + 均衡信号模型」正确这一前提上——**若类型/层级识别错误（把合作队友误判为对手、把廉价话语当成可信承诺、或把类型集合 Θ 做窄），系统就会在错误的博弈里做出精致的、可审计的、却系统性地错误的决策；且安全盾的对手无关性依赖 Θ 覆盖真实对手，真实对手一旦落在 Θ 外，最坏情况保证直接失效——「在错的棋盘上算出最优解」比不会下棋更危险。**

**次级风险与缓解**：语言解析误判道义算子（分布输出 + 低置信强制 clarify + E309）；承诺绑定脆弱/可伪造（可审计绑定 + 重复博弈声誉 + E306）；λ_clock 估计偏差（在线标定 + 收益拐点实验 E311）；对手用「演队友」污染类型后验（PAA 第二通道 + 类型集合覆盖审计）；均衡求解超预算（level-k 截断 + 引理 22 + 自适应深度）；对 exploitability 的 Goodhart（同时报告对手最优反应收益）。
