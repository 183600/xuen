# 第 10 轮（本轮灵感：「强化学习」×「人机交互」；接续 v9）

> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**屏蔽式学习 + 人在环契约 + 可信解释**。RL 只提案、证书可否决；人只表达偏好与否决、安全做终审。三个新模块全部可选：失效即注入中立元，严格等价退回 v9。

## 0. 直觉与动机

**灵感 1（强化学习 → 屏蔽残差策略改进）**
直觉：v9 的策略仍是手工采样 + 评分，样本效率低、跨域自适应弱；但让端到端 RL 直接接管 50Hz 安全关键回路，等于拿机器人做随机探索。正确姿势不是"RL 替换控制器"，而是"RL 只在已认证集合内提出残差，证书是屏蔽"。核心创新 **ShieldedResidualImprover（SRPI）**：在 v9 认证动作 a_base 上叠加有界残差 Δa，盾算子 S_C 把越界提案拒绝回 a_base；再用证书余量构造势函数做奖励塑形，使"安全最优策略集"在策略改进下保持不变（引理 87）。于是**在线不安全探索步恒为 0**，RL 成为一个安全的策略改进算子。

**灵感 2（人机交互 → 混合主动式契约）**
直觉：v9 的 5Hz 块边界天然是人机协同节拍，但人的指令有延迟、会犹豫、会自相矛盾，不能直接塞进控制回路。把"人"也建模成一个契约模块 κ_H：输出提案/否决/偏好，**中立元 = 弃权**，超时或冲突即退回 v9 全自主。核心创新 **MixedInitiativeArbiter（MIA）**：块边界提案进入候选先验，块内否决映射到中止点，M₀ 硬检查对人类拥有最终否决权——**人低于安全，但高于残差与默认策略**（引理 88）。

**灵感 3（交汇 → 偏好/安全解耦与可信解释）**
直觉：RL 与人机交互都想改变"机器人想要什么"，但都不能改变"机器人绝不能做什么"。因此奖励偏好只在有界信任域内更新，安全约束冻结；解释由证书字段直接投影生成，**解释不能说出证书没蕴含的安全断言**（引理 89）。核心创新 **TrustCalibratedExplainer（TCE）** 与 **PreferenceRewardAdapter（PRA）**：解释只读、不进控制路径；其失效只影响措辞，决策流与 v9 逐位一致。

## 1. 研究问题（轮次升级版）

- **Q1（安全可学习性）**：在线 RL 的每次更新在什么条件下既是策略改进、又不缩小 v9 的安全不变式集？证书余量势函数能否保证"安全最优集不变"？
- **Q2（人的安全边界）**：任意人类提案/否决序列（含对抗、冲突、超时）在什么契约与仲裁格下都不可能违反 M₀，且弃权时与 v9 逐位等价？
- **Q3（可信解释）**：如何让解释"由构造忠实"（每个断言都有证书/日志见证），并用信任校准与迟滞同时抑制过度信任、信任不足与界面抖振？

## 2. 设计原则（P13–P15）

**P13 屏蔽残差改进律（Shielded Residual Improvement, SRPI）**
执行动作 a_exec = S_{C_t}(a_base ⊕ Δa)，‖Δa‖_∞ ≤ ρ；S 把越界提案拒绝回 a_base（若 a_base 也已失效，则让位给 v9 的 K_eff=1 fallback）。奖励 R^Φ = R + γΦ(s') − Φ(s)，Φ = λ·margin(s) 为证书余量势函数。策略更新只在块边界发生，且仅当保守下界估计 ΔĴ_LCB ≥ 0 时接受，否则回滚。

**P14 混合主动契约律（Mixed-Initiative Arbitration, MIA）**
人类输入 h = (type, payload, confidence, ttl) 进入契约 κ_H；中立元 v_H^⊥ = 弃权。权限格（更保守者优先）：M₀ ≻ 证书/中止点 ≻ 人类 ≻ 残差 ≻ 默认。块内否决映射到最近可行中止点；过期/冲突输入一律弃权；人不能把动作推到认证集 C_t 之外。

**P15 忠实解释与信任校准律（Trust-Calibrated Explanation, TCE）**
解释原子 e 必须是证书/日志字段的确定性投影；LLM 只负责措辞、不负责选择断言，渲染后经见证校验器逐句核对，失败即回退模板。解释只读：TCE 失效时输出静态证书摘要，决策流与 v9 逐位一致。解释粒度 g 由信任估计 τ 经 Schmitt 迟滞调节。

## 3. 与基线的接口（如何退化）

- SRPI 失效 ⇒ Δa ≡ 0，执行 v9 认证块；学习状态冻结；
- MIA 失效/超时 ⇒ 弃权（v_H^⊥），完全自主，等价 v9；
- TCE 失效 ⇒ 静态证书摘要，控制流不变；
- PRA 失效 ⇒ ER 五维权重冻结为 v9 值；
- 以上任意组合失效 ⇒ 精确退回 v9，再按 v9 五级链退回 v8/v7/v6。

## 4. 预期贡献

1. **屏蔽残差 RL**：零在线不安全探索 + 安全最优集不变的策略改进算子（引理 87/91）；
2. **人机混合主动契约**：把人类延迟/冲突/弃权纳入契约格，安全性对人的任意输入封闭（引理 88）；
3. **由构造忠实的解释**：证书→解释的可验证投影，附信任校准与迟滞（引理 89/90）；
4. **安全—偏好—解释三解耦**：E571–E590 覆盖屏蔽功效、样本效率、人类在环功效、对抗输入、解释忠实审计、信任校准、负载与端到端任务。

## 5. 本轮最大风险

**一句话**：屏蔽把学习限制在当前证书信任域内，而 RL 最想学的恰恰是"证书保守边缘"的改进行为——盾太紧，RL 退化为对 v9 的微扰（无学习收益）；盾太松（放松 β/信任域换收益），则"零在线不安全步"与证书可靠性同时失效，即**安全的可学习性与证书的保守性之间存在根本张力**。

**新增定义 541（盾算子与屏蔽更新）** 盾 S_{C_t}: A → C_t ∪ {a_base}：
```
S_{C_t}(a) = a        若 a ∈ C_t
           = a_base   否则
```
屏蔽执行器保证每周期 a_exec = S_{C_t}(a_base ⊕ Δa) ∈ C_t。若 a_base ∉ C_t（信任域破坏），SRPI 直接让位给 v9 的 K_eff=1 fallback。学习只更新残差生成器 π_θ，不更新 S。

**新增定义 542（证书余量势函数与塑形）** 归一化余量
```
m(s) = min( (g_min(s) − d_safe)/d_safe,
            (τ_eff − e_max(s))/τ_eff,
            slack_stop(s)/d_safe )      ，三项各自 clip 到 [0,1]
Φ(s) = λ·m(s)，   R^Φ = R + γΦ(s') − Φ(s)
```
势函数仅定义在 C_t 上；C_t 外沿用 v9 退化值 m≡0。

**新增定义 543（人类输入契约）** κ_H = (In_H, Out_H, D_H, Ŵ_H, v_H^⊥, auth_H, φ_H^elig)，其中
```
h = (type ∈ {propose, veto, prefer, query}, payload, confidence ∈ [0,1], ttl, t_arrive)
v_H^⊥ = abstain；D_H = 200ms（一个块）；Ŵ_H ≤ 0.2ms；φ_H^elig = ✓
```
过期（now − t_arrive > min(ttl, T_H)）或 confidence < c_min（默认 0.3）的输入按 v_H^⊥ 处理。ID 可将 MIA 置为 dormant，此时等价于持续弃权。

**新增定义 544（混合主动仲裁格）** 约束按保守度构成 meet-半格 (D, ⊑)：a ⊑ b 表示 a 不晚于且不大于 b（更保守）。执行决策
```
a* = S_{C_t}(a_base ⊕ Δa) ⊓ h_propose ⊓ h_veto，
```
其中 h_veto 只把停车时刻提前，h_propose 只允许在 C_t 内改变偏好。权限全序
```
M₀ ≻ cert/abort ≻ human ≻ residual ≻ default
```
人不能把动作推到 C_t 外；冲突时取 meet（更保守者），绝不取"更激进者"。假设 A1：C_t 对保守序是下集（减速/提前停不减小证书余量），故 meet 封闭。

**新增定义 545（解释原子与忠实投影）** E_t = {e_1,…,e_n}，e=(claim, witness)，witness ∈ Cert_t ∪ Abort_t ∪ TriggerLog_t。允许的 claim 文法：
```
(i)  margin_x ≥ v；(ii) abort at p；(iii) trigger = c；
(iv) counterfactual：若 margin_x 放宽 δ 则可执行 a'
```
π_faith 为确定性映射：每个 claim 必须由 witness 的相应不等式/等值式蕴含。渲染器 R（可含 LLM）只做措辞；输出句 s 经 V(s,E_t)=1 才显示，否则回退模板。故 E_t 对控制器**可靠（sound）**；完备性受原子文法限制并在界面显式披露"未解释项"。

**新增定义 546（信任状态与校准算子）** 操作员信任 τ_t ∈ [0,1]（由交互探针、自评与接受率融合）。观测量 o_t ∈ [0,1] 为近期接受率与解释兑现率的加权。更新
```
τ_{t+1} = Π_[0,1]( τ_t + η_t (o_t − τ_t) )，  η_t = η_0/(1 + t/T_τ)
e_t = |τ_t − o_t|（信任误差）
```
解释粒度 g_t ∈ {summary, margin, counterfactual} 仅在 e_t 跨越 θ_hi/θ_lo 且满足最小驻留 L_g 时切换（Schmitt）。

**新增定义 547（偏好奖励适配器）** 人类偏好更新 ER 五维权重 w_t ∈ Δ⁴，但限制在信任域
```
‖w_t − w_v9‖₁ ≤ ε_p（默认 ε_p=0.15），且 w_t 不进入任何安全约束
w_{t+1} = Π_{Δ⁴ ∩ B(w_v9, ε_p)}( w_t − α ∇_w L_pref )
```
故偏好学习可改变"想要什么"，不可改变 M₀/证书/中止点。

```python
# IP-357 ShieldedResidualImprover：屏蔽残差策略改进器
class ShieldedResidualImprover:
    def __init__(self, actor, critic_lcb, shield, rho=0.15, lam=0.5,
                 lr=3e-4, rollback_buffer=None):
        self.actor, self.critic_lcb, self.shield = actor, critic_lcb, shield
        self.rho, self.lam, self.lr = rho, lam, lr
        self.rollback = rollback_buffer or []

    def propose(self, state, a_base, n=8):
        best = None
        base_score = self.critic_lcb(state, a_base) + self.lam * margin(state)
        for delta in self.actor.sample(state, n=n):        # 有界残差提案
            delta = clip_inf(delta, self.rho)
            a = self.shield.compose(a_base, delta)
            if not self.shield.certified(a, state):        # S_C 成员判定
                a = a_base                                 # 拒绝回退（不越界）
            score = self.critic_lcb(state, a) + self.lam * margin(state)
            if best is None or score > best.score:
                best = (a, score)
        return best if best and best.score >= base_score else (a_base, base_score)

    def update(self, batch):
        dJ = conservative_improvement_lcb(batch, delta=0.05)  # 保守改进下界
        if dJ < 0.0:                                          # 不接受非改进更新
            self.rollback.append(snapshot(self.actor)); self.restore()
            return False
        grad = self.actor.grad(batch, potential_lam=self.lam)  # R^Φ 塑形
        self.actor.step(grad, lr=self.lr)
        return True


# IP-358 MixedInitiativeArbiter：混合主动仲裁器
@dataclass
class HumanInput:
    type: str          # propose | veto | prefer | query
    payload: object
    confidence: float
    ttl: float
    t_arrive: float

class MixedInitiativeArbiter:
    def __init__(self, tau_ttl=0.2, c_min=0.3):
        self.tau_ttl, self.c_min = tau_ttl, c_min
        self.deferred_veto = None

    def ingest(self, h, now):
        if h is None:
            return None                                    # v_H^⊥ = abstain
        if now - h.t_arrive > min(h.ttl, self.tau_ttl):
            return None                                    # 过期 ⇒ 弃权
        if h.confidence < self.c_min:
            return None                                    # 低置信 ⇒ 弃权
        return h

    def arbitrate(self, state, a_base, delta, shield, h, k_exec, chunk):
        a = shield.compose(a_base, clip_inf(delta, shield.rho))
        if not shield.certified(a, state):
            a = a_base                                     # 残差永不越界
        h = self.ingest(h, now())
        if h is None:
            return a, ("continue", k_exec + 1)             # 精确等价 v9
        if h.type == "veto":
            p = chunk.nearest_abort_ge(k_exec)             # 最近可行中止点
            if p is not None:
                return a, ("abort", p)                     # 人可提前停，不可推迟
            self.deferred_veto = h                          # 过晚 ⇒ 下个块边界生效
            return a, ("continue", k_exec + 1)
        if h.type == "propose":
            a_h = shield(h.payload, state)                 # 人的提案也被盾筛选
            a = meet_conservative(a, a_h)                  # 定义 544 的 meet
        return a, ("continue", k_exec + 1)


# IP-359 TrustCalibratedExplainer：信任校准解释器
class TrustCalibratedExplainer:
    GRAMMAR = {"margin_ge", "abort_at", "trigger", "counterfactual"}

    def explain(self, cert, chunk, triggers, trust):
        atoms = [("margin_ge", cert.margin(), cert)]
        if chunk.aborted:
            atoms.append(("abort_at", chunk.abort_point, chunk.abort_ledger))
        atoms += [("trigger", c, trigger_log(c)) for c in triggers]
        if trust < 0.4:                                    # 低信任 ⇒ 反事实解释
            atoms.append(("counterfactual", min_relax(cert), cert))
        text = self.renderer.render(atoms)                 # LLM 仅措辞
        if not all(self.verifier.entails(s, e) for s, e in text):
            text = self.template.render(atoms)             # 校验失败 ⇒ 模板
        return text


# IP-360 PreferenceRewardAdapter：偏好奖励适配器
class PreferenceRewardAdapter:
    def __init__(self, w0, eps_p=0.15, alpha=1e-3):
        self.w = w0.copy(); self.w0 = w0.copy(); self.eps_p = eps_p
        self.alpha = alpha

    def step(self, grad_pref):
        w = self.w - self.alpha * grad_pref
        self.w = project_simplex_box(w, self.w0, self.eps_p)   # 限界投影
        return self.w                                          # 不触碰安全约束
```

## 4. 推导

**引理 87（屏蔽改进的安全性、不变性与单调性）**
设 C_t 按定义 540，S 按定义 541，Φ 按定义 542。则：
(i) **零不安全探索**：∀t，a_exec(t) = S_{C_t}(a_base ⊕ Δa) ∈ C_t ∪ {a_base}；C_t 已逐项保证 v9 的块证书、中止点非空与 M₀ 通过，故任意策略 π_θ 下的在线轨迹都满足 v9 引理 82/80/81 的安全不变量，与学习是否收敛无关。
(ii) **安全最优集不变**：将 MDP 限制在 C_t 上。Ng–Harada–Russell 势函数定理给出：对任意势函数 Φ，R^Φ = R + γΦ(s') − Φ(s) 不改变最优策略集合；Φ 在 C_t 外取 0 不影响 C_t 内比较。故策略改进不会把安全最优策略挤出最优集。
(iii) **单调改进**：仅当保守下界 ΔĴ_LCB ≥ 0 才接受更新，否则回滚；故以概率 ≥1−δ 有 J(π_{k+1}) ≥ J(π_k)。
证明：(i) 由 S 的像集直接得到；(ii) 势函数塑形的 telescoping 求和使任意轨迹的回报差为 Φ(s_0)−γ^TΦ(s_T)，与策略无关；(iii) 保守策略迭代的标准下界论证。∎

**引理 88（人类输入的安全支配与弃权等价）**
在假设 A1（C_t 对保守序下闭）下，任意人类输入序列（提案/否决/偏好/查询，含对抗、冲突、超时）满足：
(i) 执行动作恒在 C_t 内；
(ii) 有效否决只能提前、不能推迟停车；
(iii) 弃权/过期/低置信时，MIA 为恒等映射，系统与 v9 逐位等价。
证明：(i) 人类提案经盾筛选后进入 meet，meet 的两个操作数均在 C_t（A1 保证 h_veto 的提前停仍在 C_t），故结果在 C_t；(ii) h_veto 的像为 p≥k_exec 的最早中止点，停车时刻单调不晚；(iii) ingest 返回 None 时 arbitrate 直接返回 (a, continue)，与 v9 的单步执行路径相同；deferred_veto 不改变当前块。∎

**引理 89（解释的可靠性与不可伪造性）**
对任意证书/日志与任意渲染器 R（含 LLM），若 V(s,E_t)=1 对所有显示句成立，则每个显示的安全断言都由 E_t 的某个 witness 蕴含；渲染器不能引入无见证的新断言。故解释对控制器可靠（sound）；完备性受文法限制，未解释项必须显式列出。
证明：π_faith 逐原子构造 witness；V 逐句检查 claim 是否属于 GRAMMAR 且被 witness 蕴含；失败即回退模板。LLM 仅在已有原子集合上做同义改写，不参与断言选择。∎

**引理 90（信任校准的稳定性与界面无抖振）**
在平稳观测下，投影 Robbins–Monro 更新 τ_{t+1}=Π(τ_t+η_t(o_t−τ_t)) 以概率 1 收敛到 E[o]；在慢变 E[o](t) 下，跟踪误差有界 O(L/η_0)（L 为变化率上界）。粒度切换受最小驻留 L_g 与双阈 θ_lo<θ_hi 约束，故切换率 ≤ 1/L_g，有限时间内切换次数有限（无 Zeno）。
证明：标准随机逼近收敛定理 + 投影的非扩张性；慢变情形由 ODE 方法得跟踪界。粒度过程是带驻留的有限状态机，双阈保证不会在阈值附近无限翻转。∎

**引理 91（安全样本复杂度）**
在 C_t 限制的 MDP 上，残差维数为 d_r、奖励∈[0,R_max] 的保守 Q 学习达到 ε-次优所需安全样本数
```
N(ε,δ) = O( d_r · R_max² · ln(1/δ) / ε² )，
```
且在线不安全样本数恒为 0（引理 87(i)）。当域偏移使 C_t 收缩、其平稳分布的最小质量 μ_min(C_t)→0 时，有效样本率下降，界按 O(1/μ_min) 放大——即域偏移拖慢学习，但不破坏安全。
证明：将屏蔽执行器视为 C_t 上的受限 MDP，应用保守 Q 学习的有限样本界；不安全样本被 S 拒绝，不进入在线数据。μ_min 因子来自重要性采样/覆盖系数的标准转换。∎
