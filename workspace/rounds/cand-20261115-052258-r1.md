# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 1 轮；本轮灵感：「人机交互」×「主动交互」）

> R69 把「交互」从被动融合升级成了可优化的信息动作：VoI 选动作、看/问/触、k 个正交证据源一致才定案。但它仍把一个关键对象当成了**静止的单向传感器**——人类。R69 的提问只降低**机器自己**的熵；它会默认人的回答分布 \(p(y\mid g,o)\) 不随交互历史变化，也不会因为「机器刚才问了一个很蠢的问题」而改变对这个机器的看法。
>
> 人机交互（HCI）恰好否定这个默认：人不是传感器，而是**会反过来给机器建模的合作者**。机器每一次主动开口，既是「问世界」，也是「向人发信号」——暴露自己的不确定、能力边界与优先级。问得太频繁会疲劳，问得太基础会掉信任，解释得过头会造成过度依赖。**主动交互因此有两条信息通道，而 R69 只计了其中一条。**
>
> 本轮的灵感组合给出的正是缺失的另一半：
> - **人机交互**：交互是一段有历史、有共地、有信任、有契约的**关系**，不是一次性的 VoI 探针；
> - **主动交互**：主动不等于打断，而是**分级、可推迟、可撤回、可协商**的混合主动（mixed-initiative）行为，且必须"说到做到"。
>
> 核心命题：**把 R69 的单向 VoI 升级为「问世界（VoI）＋向人发信号（Sig）」的双向信息交易，并用共地、信任校准、打扰债、社会契约、混合主动仲裁五重约束把它包住；R69 是 \(\lambda_S=0\) 且人类静止时的严格退化边界。** 命名 **RAPPORT-RAS**（Relationship-Aware Proactive Policy with Observable Reciprocity and Trust-calibration）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**什么时候该开口、开口之后对方会怎么看我、这段关系还能承受几次打扰**」——主动交互不只是获取信息，也是在经营一段可被对方理解和信任的关系。

## 0. 直觉与动机

**灵感 1（HCI：交互不是查询，而是关系）**
直觉：R69 把每次主动交互当作打在静止 oracle 上的一个 VoI 探针；回答被污染只是"噪声"。但真实的人会累积印象：被反复打断会烦，被问显而易见的事会怀疑机器能力，被过度解释会偷懒。于是人的回答策略本身是**内生的**：\(\pi_H(y\mid g,o,h,C)\) 依赖交互历史 \(h\) 和当前契约 \(C\)。R69 的 \(p(y\mid g,o)\) 是它在"人不会变"假设下的特例。忽略内生性，VoI 就是在一条会随自己动作漂移的通道上做开环优化。

**灵感 2（主动交互：每个主动行为都是双向信号）**
直觉：一个主动提问同时做两件事——机器从人那里获得信息（inquiry），人也从机器"问什么、怎么问、何时问"推断机器的意图、能力与不确定（signaling）。信息论上这是**两条方向相反的信道**：\(VoI_R\) 是"人→机"，\(Sig_H\) 是"机→人"。R69 只最大化前者，于是会选出"信息上最优、社交上灾难"的动作：比如为消除一个对人毫无意义的 0.01 nat 歧义而打断人。把两条通道写进同一个目标，才谈得上"主动"而不"冒犯"。

**灵感 3（共地：目标不是降低我的熵，而是维持共同的行动基础）**
直觉：HCI 的 common ground 说，合作靠的是双方对"当前该做什么、彼此知道什么"的**共享**理解。机器内部的熵再低，若它掌握的世界模型与人不在同一页，行动仍会错。因此主动交互的价值应以**共地增益** \(\Gamma(g)\) 计量，而不是裸信息增益：只做能提升共同行动基础的 grounding act，禁止"纯好奇式审问"（对机器有信息量、对共同行动无贡献的提问）。这一条把 R69 的"想问就问"改成"问了要能一起用"。

**灵感 4（主动不等于打断：分级、可推迟、可撤回、可协商）**
直觉：人类专家不会一有不确定就拍你肩膀；他先用环境提示（一个眼神、一盏灯），不行再给建议，再不行才问，最后才接管。主动交互应当有**等级**（tier 0 环境提示 → tier 1 建议 → tier 2 询问 → tier 3 解释 → tier 4 接管），每一级都有不同打扰成本，并且必须**可推迟**（deferrable）、**可撤回**（revocable）、受一份**社会契约**约束（打扰预算、同意模式、沉默权）。"主动"的正确反面不是"被动"，而是"越权"。

**灵感 5（信任是会被主动行为改造的状态量，且改造有方向性）**
直觉：机器主动解释会改变人的信任。解释不足→不信任/弃用；解释过度且能力不匹配→过度信任/自动化偏见，出事时人来不及接管。所以信任必须像 R68 的传感器一样被**校准**：目标不是"信任越高越好"，而是 \(|{\tau}_H-r_{\text{true}}|\le\varepsilon_\tau\) 的**恰当依赖**。更危险的是：一旦把"信任"写进优化目标，系统就有了**制造信任**（讨好、报喜不报忧）的动机。因此必须加一条硬约束——**信号必须真实**：解释只能是自身后验的忠实函数，不能被优化来"让人更信我"。

**灵感 6（关系是慢变量，且会被攻击）**
直觉：共地、信任、契约都是慢变量，会漂移、会被社会工程攻击（反复虚警先磨掉信任再利用；伪装成"懂了"的假共地；诱导机器把契约解释得更宽松）。R70 因此不是加一个漂亮目标函数，而是加一层**新的攻击面与审计对象**：机器人自己的主动行为是否在操纵人。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（RAPPORT-RAS 总览）** RAPPORT-RAS = (CoG, SIG, MIX, SCM, TC, RAS-WM†)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i / R68 定义 276-i）；
(ii) **社会契约硬约束**：任何主动行为只有在当前契约 \(C\) 下 admissible 才可执行；契约只能由人类**显式批准**更新，机器人只能"提议"，不得自行放宽；
(iii) **真实信号约束**：主动行为的解释内容必须是机器人真实后验的固定可审计函数 \(e=\phi(b_R)\)，不得为了提升信任而策略性扭曲；有物理效果的信息动作仍须过 C-RAS-WM 认证。

**定义 311（人作为共适应响应者）** 人类回答模型
\[
\pi_H\big(y \mid g, o, b_H, h, C\big),
\]
其中 \(b_H\) 是人关于机器人潜在意图/能力的信念，\(h\) 是交互历史，\(C\) 是当前契约。定义**内生性** \(\partial \pi_H/\partial h\ne 0\)：人会被机器先前的主动行为改变。R69 的静止模型 \(p(y\mid g,o)\) 是本定义在 \(\partial\pi_H/\partial h=0\) 时的特例。

**定义 312（交互式 POMDP 与递归心智模型）** 联合状态 \(s=(s_{\text{world}},\theta_R,\theta_H)\)：\(\theta_R\) 为机器人意图/模式，\(\theta_H\) 为人类类型（工作负载、偏好、信任倾向）。机器人维护 \(b_R(s_{\text{world}},\theta_R)\)、对人的估计 \(\hat b_H(\theta_H)\)，以及二阶模型 \(\hat b_H^{(2)}=\hat b_H(\theta_R\text{ 的后验})\)（"我以为你以为我是什么"）。在**行动相关投影** \(\tau\)（只保留影响联合动作的变量）上定义共地：
\[
CG_t \;=\; 1-\frac{D_{JS}\!\left(b_R^{\tau}\,\big\|\,\hat b_H^{\tau}\right)}{\log 2}\in[0,1].
\]
\(CG_t\) 低意味着"各想各的"，即使双方各自都很确定。

**定义 313（双向信息价值：主动行为的统一目标）** 对一个主动行为 \(g\)（环境提示/建议/询问/解释/信息性物理动作）：
\[
Q(g)=VoI_R(g)+\lambda_S\,Sig_H(g)-c_{\text{act}}(g)-c_{\text{fatigue}}(g)-c_{\text{trust}}(g)-c_{\text{contract}}(g),
\]
其中
\[
VoI_R(g)=H(M\mid b_R)-\mathbb E_{y\sim\pi_H(\cdot\mid g)}[H(M\mid b_R,y)]
\]
是 R69 的 inquiry 通道（人→机）；
\[
Sig_H(g)=\mathbb E_{\hat b_H}\!\left[H(\theta_R\mid h)-H(\theta_R\mid h,g)\right]
\]
是 signaling 通道（机→人）——**人通过这次主动行为对机器意图/不确定性的认知增益**。\(c_{\text{fatigue}}\) 见定义 317，\(c_{\text{trust}}\) 见定义 318，\(c_{\text{contract}}\) 为契约违反罚（admissible 时为 0，否则 \(+\infty\)）。选择
\[
g^\*=\arg\max_g Q(g)\quad\text{s.t. } \mathrm{admissible}(g,C,h)=1,\ \mathrm{risk}(g)\le\varepsilon_{\text{int}}.
\]
**要点**：\(VoI_R\) 与 \(Sig_H\) 是同一交易的两个方向；R69 目标 \(=Q\) 在 \(\lambda_S=0\)、成本项归零时的退化。

**定义 314（可读性与真实披露）** 主动行为 \(g\) 的可读性
\[
Leg(g)=\frac{Sig_H(g)}{c_{\text{act}}(g)+\epsilon},
\]
即"单位打扰换来的可理解度"。**真实披露约束**：解释 \(e\) 必须满足 \(e=\phi(b_R)\)，\(\phi\) 为事先注册、可审计的固定映射（可以是校准后的粗化，但不能依赖"人会不会更信"来调参）。因此系统只能**选择哪条真实信号发**，不能**改造信号去取悦**。

**定义 315（共地接地行为与反审问约束）** 行为 \(g\) 是 **grounding act** 当且仅当它同时（a）降低机器人对行动相关变量的熵，（b）提升期望共地。接地增益
\[
\Gamma(g)=\mathbb E[CG_{t+1}-CG_t\mid g]-c_{\text{act}}(g).
\]
**只允许 grounding act 作为主动询问**；若 \(VoI_R(g)>0\) 但 \(\Gamma(g)\le 0\)（对机器有信息量、对共同行动无贡献），则禁用——这条把"审问"从目标函数层面排除。

**定义 316（社会契约 SCM）** 契约
\[
C=(N_{\max},\ \tau_{\min},\ \text{tier\_policy},\ \text{consent\_mode},\ \text{revoke\_policy},\ \text{disclosure\_level}),
\]
其中 \(N_{\max}\) 为窗口内主动中断上限、\(\tau_{\min}\) 为最小触发风险、tier_policy 规定各等级升级条件、consent_mode ∈ {opt-in, opt-out, contextual}、revoke_policy 规定人类如何随时降级/静音、disclosure_level 规定解释粒度。\(\mathrm{admissible}(g,C,h)\in\{0,1\}\)。契约带版本号；机器人可**提议** \(C'\)，但只有人类显式批准才生效。

**定义 317（打扰债与疲劳动力学）** 疲劳/打扰债状态
\[
f_{t+1}=\mathrm{clip}\!\left(\gamma f_t+w(g_t)-\rho\,\mathbf 1[\text{人类发起或恢复期}],\ 0,\ f_{\max}\right),
\]
打扰成本 \(c_{\text{fatigue}}(g)=c_0(g)\,(1+\kappa f_t)\)，等级权重 \(w\)：tier0 0.2、tier1 0.5、tier2 1.0、tier3 1.5、tier4 3.0。\(f\) 把 R69 只在 E297 里观察的"交互疲劳"提升为**显式状态量**。

**定义 318（信任校准与恰当依赖）** 设 \(r_{\text{true}}\) 为机器人真实可靠度（由 R69 的 MCG/ECE 标定得到），\(\hat\tau_H\) 为从行为（采纳率、接管率、响应时延、注视）估计的人对机器的信任。信任偏差
\[
\Delta\tau=\hat\tau_H-r_{\text{true}}.
\]
**恰当依赖**当且仅当 \(|\Delta\tau|\le\varepsilon_\tau\)。\(\Delta\tau>\varepsilon_\tau\) 为过度信任（自动化偏见/自满），\(\Delta\tau<-\varepsilon_\tau\) 为信任不足（弃用）。任何主动行为若使 \(|\Delta\tau|\) 增大，则 \(c_{\text{trust}}>\varepsilon\) 且不可采——**即使 \(VoI_R>0\)**。

**定义 319（混合主动仲裁 MIX）** 双方均可发起。仲裁规则：
1. 人类发起 **抢占** 机器人发起（yield）：机器人先响应/接地，不得抢话；
2. 机器人发起受工作负载 \(\hat w_H\) 与紧迫度门控；
3. 若紧迫度低于 \(\tau_{\min}\) 且风险不高于 \(r_0\)，则**推迟**到 tier0/tier1，不进入 tier2 询问。
仲裁策略记作 \(\mathcal A(g_{\text{robot}},g_{\text{human}}, \hat w_H, C)\)。

**定义 320（分级主动与可推迟信号）** 主动等级
\[
\text{tier0 环境提示}<\text{tier1 建议}<\text{tier2 询问}<\text{tier3 按需解释}<\text{tier4 接管}.
\]
升级条件：仅在"下一等级的期望风险降低"超过"该等级的打扰成本"时升级；接地成功或风险解除则降级。**沉默权**：人类可将任意等级设为静音；静音不撤销安全兜底（兜底仍可 tier4）。

**定义 321（关系感知退化边界）** 若 \(CG_t<\tau_{cg}\)，或 \(|\Delta\tau|>\varepsilon_\tau\)，或契约被违反，或 \(f_t>f_{\max}\)，则**关闭主动信号**：\(\lambda_S\leftarrow 0\)，退回 R69 FLUID（纯 VoI 交互）；若此时 VoI 也无利可图，再退回 R68 纯保守。保证关系层失效时安全侧单调不降。

**定义 322（新威胁模型 \(\mathcal E_{\text{RAPPORT}}\)）** 在 \(\mathcal E_{\text{FLUID}}\) 上新增：
- **讨好/操纵**：系统优化"让人更信"而非"让人更懂"（由定义 310-iii + 定义 326 审计反制）；
- **信任投毒**：反复虚警侵蚀信任后利用，或反向刷信任；
- **假共地（phantom grounding）**：人口头确认"懂了"但信念未变；
- **契约博弈**：诱导人类放宽契约，或利用契约歧义越权；
- **二阶模型欺骗**：人策略性模仿某类型以操纵机器人的 \(\hat b_H^{(2)}\)。
\[
\mathcal E_{\text{RAPPORT}}=\mathcal E_{\text{FLUID}}\times\mathcal E_{\text{social}}.
\]

**定义 323（双侧证据与相互接地纪律）** 一次主动交互"成功"需两侧证据同时成立：
(i) 机器人后验确实改变（inquiry 侧）；
(ii) 存在**独立于人类口头回答**的可观测信号表明人的模型也一致改变（ack 后的行为改变、复述正确、后续动作与共地一致）。
单侧证据不足；仅口头确认不算接地。这把 R69 的 k 源一致纪律升级为**相互确认**，专门反制假共地。

**定义 324（证书 J_RAPPORT）**
\[
J_{\text{RAPPORT}}=(J_{\text{FLUID}},CG_{\text{before/after}},\Delta\tau,Sig_H,\Gamma_{\text{grounding}},f_{\text{interrupt}},\text{contract\_ver},\text{disclosure\_hash},\text{rapport\_ver}).
\]
Valid \(\Leftrightarrow\) Valid\((J_{\text{FLUID}})\wedge CG_{\text{after}}\ge\tau_{cg}\wedge|\Delta\tau|\le\varepsilon_\tau\wedge f\le f_{\max}\wedge\)（契约遵守）\(\wedge\)（真实披露审计通过）。

**定义 325（关系非平稳与再接地）** \(\theta_H\)、\(C\) 与共地会漂移；对 \(\pi_H\) 的响应统计做变点检测。检测到漂移 ⇒ 冻结主动 tier（降到 tier0/1）、重估 \(CG\) 与 \(\Delta\tau\)、要求重新接地后才恢复主动等级。继承 R68 的漂移监测，但监测对象从传感器扩到"人机关系"。

**定义 326（说做一致性与解释-行动审计）** 对任何解释 \(e\) 之后执行的动作 \(a\)，要求
\[
\mathrm{Cons}(e,a)=\Pr(a\mid e;\ \hat b_H)\ge\tau_{\text{cons}}.
\]
解释不得超出系统将要做的事（"说到做到"）；违反时即使 \(Sig_H\) 很高也判为信任崩塌风险，触发回滚与审计。这是反"解释性欺骗"的结构性约束。

## 2. 关键算法骨架

```python
# IP-264 CoG：共地估计（行动相关投影上的 JS 散度）
def common_ground(b_R, b_H_hat, project=action_relevant):
    p, q = project(b_R), project(b_H_hat)
    return 1.0 - js_divergence(p, q) / math.log(2.0)     # ∈ [0,1]

# IP-265 SIG：双向价值（inquiry + signaling - 三类成本）
def proactive_value(g, b_R, b_H_hat, M, contract, fatigue):
    if not contract.admissible(g, history): return -inf
    voi   = entropy(b_R[M]) - expected_entropy(b_R, M, g, pi_H_hat)     # 人->机
    sig   = entropy(b_H_hat[THETA_R]) - expected_entropy(b_H_hat, THETA_R, g)  # 机->人
    c_f   = cost(g) * (1 + KAPPA * fatigue.f)
    c_t   = trust_penalty(g, b_H_hat, r_true, eps_tau)                  # 偏离恰当依赖则 +inf
    return voi + LAM_S * sig - cost(g) - c_f - c_t

# IP-266 MIX：混合主动仲裁（人发起抢占，机器人受负载/紧迫度门控）
def arbitrate(g_robot, g_human, w_hat_H, urgency, contract):
    if g_human is not None:            return Respond(g_human)      # 人类抢占
    if urgency < contract.tau_min:     return DeferToAmbient()       # 不打断
    if w_hat_H > W_MAX:                return Defer()                # 高负载推迟
    return EscalateTier(g_robot)                                     # 逐级升级

# IP-267 SCM：社会契约（只可提议，不可自行放宽）
def update_contract(C, proposal, human_ratified):
    return proposal if human_ratified else C      # 机器人永远不能单方面改契约

# IP-268 TC：信任校准（只认"恰当依赖"，不追"越高越好"）
def trust_gap(tau_hat_H, r_true):
    return tau_hat_H - r_true                     # |gap|<=eps_tau 才算恰当依赖
def trust_penalty(g, b_H_hat, r_true, eps_tau):
    gap_after = predict_trust(b_H_hat, g) - r_true
    return 0.0 if abs(gap_after) <= eps_tau else INF

# IP-269 RAPPORT 主闭环（R69 FLUID 外包一层关系约束）
def RAPPORT_RAS_round(M, obs, human, contract):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)            # R68
    b_R = M.belief(o)
    b_H_hat = M.cog.update(human.signals)                               # IP-264
    cg  = common_ground(b_R, b_H_hat)
    gap = trust_gap(M.tc.estimate(human), M.mcg.r_true)                 # IP-268
    # 1) 关系层失效 -> 严格退化 R69 / R68
    if cg < TAU_CG or abs(gap) > EPS_TAU or not contract.respected(human):
        return FLUID_RAS_round(M, obs)                                  # 定义 321
    # 2) R69 的歧义处理（FMP/AUD/FMA 不变）
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    if U_epi <= TAU_EPI:
        return execute_task_only(M, modes, U_ale)
    # 3) 候选主动行为按"双向价值 + 接地"筛选
    best = None
    for g in tiered_candidates(modes, contract):
        if grounding_gain(g, b_R, b_H_hat) <= 0: continue                # 反审问
        q = proactive_value(g, b_R, b_H_hat, M.mode, contract, M.fatigue)
        if best is None or q > best.q: best = (g, q)
    if best is None or best.q <= 0:
        return FLUID_RAS_round(M, obs)                                  # 无利可图 -> R69
    # 4) 混合主动仲裁：人优先；否则按等级升级
    g = arbitrate(best[0], human.pending, human.workload, U_epi, contract)
    if isinstance(g, Defer): return FLUID_RAS_round(M, obs)
    # 5) 执行 + 双侧证据（口头确认不算数）
    y = g.execute()
    grounded = M.grounding.two_sided_ack(y, human)                      # 定义 323
    if not grounded:
        M.vqa_r.flag_phantom_grounding(g, y); return FLUID_RAS_round(M, obs)
    # 6) 真实披露 + 说做一致审计
    e = faithful_explain(b_R, g, contract.disclosure_level)             # IP-270
    M.vqa_r.audit_consistency(e, planned_action=M.ach.peek())
    # 7) 更新关系状态与证书
    M.fatigue.step(g.tier); M.tc.update(human, grounded)
    return M.cert.emit_J_RAPPORT(cg, gap, best[1], g, e)
```

## 3. 推导

**引理 19（双向信息分解）** 对联合目标 \((\theta_R,M)\)，一次主动行为 \(g\) 带来的总互信息可分解为
\[
I\big((\theta_R,M);\,(g,y)\big)=\underbrace{VoI_R(g)}_{\text{人}\to\text{机}}+\underbrace{Sig_H(g)}_{\text{机}\to\text{人}}+\underbrace{\Delta_{\text{syn}}(g)}_{\text{协同项}},
\]
其中 \(\Delta_{\text{syn}}\ge 0\) 来自"人因理解机器而给出更有用的回答"的正反馈。R69 恰为 \(Sig_H\equiv\Delta_{\text{syn}}\equiv0\)。系：**存在 \(VoI_R>0\) 但 \(Q(g)<0\) 的行为**——信息上划算、社交上亏损；R69 会执行它们，R70 不会。

**引理 20（打扰债有界，不唠叨）** 在定义 317 的疲劳动力学与定义 316 的预算 \(N_{\max}\) 下，任意长度 \(W\) 的窗口内主动中断次数 \(\le N_{\max}\)，且 \(f_t\le f_{\max}\) 一致有界。证明：对 \(f\) 的递推做归纳，结合 clip 与预算计数；每次 tier4 的 \(w=3.0\) 使 \(f\) 快速触顶，从而自动抑制后续主动行为。系：主动率有上界，系统不会因优化 \(Q\) 而退化为持续打扰。

**引理 21（真实披露下的信任上界）** 若披露满足 \(e=\phi(b_R)\)（定义 314）且说做一致 \(\mathrm{Cons}(e,a)\ge\tau_{\text{cons}}\)（定义 326），则
\[
|\Delta\tau|\le \mathrm{ECE}_R+\varepsilon_{\text{expl}}+\varepsilon_{\text{est}},
\]
其中 \(\mathrm{ECE}_R\) 为机器可靠度的标定误差、\(\varepsilon_{\text{expl}}\) 为解释粒度误差、\(\varepsilon_{\text{est}}\) 为信任估计误差。故**过度信任不能被"造"出真实能力之外**；要操纵信任必须违反真实披露或说做一致，而二者都可被审计捕获。

**定理 18（RAPPORT 严格包含 FLUID 与 R68）** 在 A99–A101 下：令 \(\lambda_S=0,\ c_{\text{fatigue}}=c_{\text{trust}}=0\)、契约平凡、且 \(\partial\pi_H/\partial h=0\)（人静止），则 RAPPORT 的目标、可行集与执行轨迹与 R69 FLUID **逐指令相同**；再令无任何交互（\(VoI\le c\)），则与 R68 逐指令相同。因此 R70 在安全侧不做让步，在关系侧获得共地与恰当依赖收益；R69/R68 是其边界退化。

**定理 19（混合主动安全与无突变）** 在定义 319–320 下：(i) 人类发起严格抢占，机器人不抢话；(ii) 任何 tier 的主动行为都不直接下发未认证的执行器指令，tier4 仍走 C-RAS-WM 前缀认证；(iii) 关系层失效时按定义 321 单调退化为 R69/R68；(iv) 契约只能由人批准更新，机器人单方面不能放宽风险预算。故主动交互不会突破安全包络，控制连续、无突变（继承 R69 定理 17）。

**推论 18.1（默认契约风险非增）** 在默认契约（保守 \(N_{\max}\)、\(\tau_{\min}>r_0\)、\(consent=\text{opt-out}\)）下，RAPPORT 的团队风险不超过 R69；只有人类显式提高风险预算时，才允许用风险换共地/效率——**风险预算的处置权始终在人手里**。

```python
# IP-264 CoG：共地估计
def common_ground(b_R, b_H_hat, project=action_relevant):
    p, q = project(b_R), project(b_H_hat)
    return 1.0 - js_divergence(p, q) / math.log(2.0)          # ∈[0,1]

# IP-265 SIG：双向价值（inquiry + signaling - 三类成本）
def proactive_value(g, b_R, b_H_hat, M, contract, fatigue):
    if not contract.admissible(g, history): return -inf
    voi = entropy(b_R[M]) - expected_entropy(b_R, M, g, pi_H_hat)
    sig = entropy(b_H_hat[THETA_R]) - expected_entropy(b_H_hat, THETA_R, g)
    c_f = cost(g) * (1 + KAPPA * fatigue.f)
    c_t = trust_penalty(g, b_H_hat, r_true, eps_tau)
    return voi + LAM_S * sig - cost(g) - c_f - c_t

# IP-266 MIX：混合主动仲裁
def arbitrate(g_robot, g_human, w_hat_H, urgency, contract):
    if g_human is not None:        return Respond(g_human)   # 人类抢占
    if urgency < contract.tau_min: return DeferToAmbient()    # 不打断
    if w_hat_H > W_MAX:            return Defer()
    return EscalateTier(g_robot)                              # 逐级升级

# IP-267 SCM：契约只可提议，不可自行放宽
def update_contract(C, proposal, human_ratified):
    return proposal if human_ratified else C

# IP-268 TC：信任校准（只认恰当依赖）
def trust_gap(tau_hat_H, r_true): return tau_hat_H - r_true
def trust_penalty(g, b_H_hat, r_true, eps_tau):
    gap_after = predict_trust(b_H_hat, g) - r_true
    return 0.0 if abs(gap_after) <= eps_tau else INF

# IP-275 主闭环（R69 FLUID 外包一层关系约束）
def RAPPORT_RAS_round(M, obs, human, contract):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    b_R = M.belief(o); b_H_hat = M.cog.update(human.signals)
    cg  = common_ground(b_R, b_H_hat)
    gap = trust_gap(M.tc.estimate(human), M.mcg.r_true)
    # 1) 关系层失效 -> 严格退化 R69 / R68
    if cg < TAU_CG or abs(gap) > EPS_TAU or not contract.respected(human):
        return FLUID_RAS_round(M, obs)
    # 2) R69 歧义处理（FMP/AUD/FMA 不变）
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    if U_epi <= TAU_EPI: return execute_task_only(M, modes, U_ale)
    # 3) 双向价值 + 反审问筛选
    best = None
    for g in tiered_candidates(modes, contract):
        if grounding_gain(g, b_R, b_H_hat) <= 0: continue      # Γ<=0 禁问
        q = proactive_value(g, b_R, b_H_hat, M.mode, contract, M.fatigue)
        if best is None or q > best.q: best = (g, q)
    if best is None or best.q <= 0: return FLUID_RAS_round(M, obs)
    # 4) 混合主动仲裁
    g = arbitrate(best[0], human.pending, human.workload, U_epi, contract)
    if isinstance(g, Defer): return FLUID_RAS_round(M, obs)
    # 5) 执行 + 双侧证据（口头确认不算接地）
    y = g.execute()
    if not M.grounding.two_sided_ack(y, human):
        M.vqa_r.flag_phantom_grounding(g, y); return FLUID_RAS_round(M, obs)
    # 6) 真实披露 + 说做一致
    e = faithful_explain(b_R, g, contract.disclosure_level)
    M.vqa_r.audit_consistency(e, planned_action=M.ach.peek())
    # 7) 关系状态更新与证书
    M.fatigue.step(g.tier); M.tc.update(human, grounded=True)
    return M.cert.emit_J_RAPPORT(cg, gap, best[1], g, e)
```

## 4. 推导

**引理 19（双向信息分解）** `I((θ_R,M);(g,y)) = VoI_R + Sig_H + Δ_syn`，`Δ_syn≥0` 为"人因理解机器而给出更有用回答"的正反馈。R69 为 `Sig_H≡Δ_syn≡0`。系：存在 `VoI_R>0` 但 `Q(g)<0` 的行为——信息划算、社交亏损，R69 会做、R70 不做。

**引理 20（打扰债有界）** 定义 316–317 下，任意窗口内主动中断 ≤ `N_max`，且 `f_t≤f_max` 一致有界；主动率有上界，系统不会因优化 `Q` 退化为持续打扰。

**引理 21（真实披露下的信任上界）** 若 `e=φ(b_R)` 且 `Cons(e,a)≥τ_cons`，则 `|Δτ| ≤ ECE_R + ε_expl + ε_est`；过度信任不能被造到真实能力之外，操纵必须违反真实披露/说做一致，可被审计捕获。

**定理 18（严格包含 FLUID 与 R68）** 令 `λ_S=0`、`c_fatigue=c_trust=0`、契约平凡、`∂π_H/∂h=0`，则 RAPPORT 与 R69 逐指令相同；再令无交互，则与 R68 逐指令相同。R70 安全侧不让步，关系侧获得共地与恰当依赖收益。

**定理 19（混合主动安全与无突变）** 人类发起抢占；任何 tier 不直接下发未认证执行器指令（tier4 仍过 C-RAS-WM）；关系层失效按定义 321 单调退化；契约仅人可批准。故主动交互不突破安全包络，控制连续、无突变（继承 R69 定理 17）。

**推论 18.1（默认契约风险非增）** 默认契约（保守 `N_max`、`τ_min>r_0`、opt-out）下团队风险不超过 R69；只有人类显式提高风险预算才允许以风险换共地/效率——**风险处置权始终在人手里**。

## 7. 本轮最大风险

**一句话**：RAPPORT 的全部收益押在「我能估准对方脑子里的我」这一前提上——**共地、信任、二阶心智模型都是不可直接观测的隐变量，只能在自我实现的闭环里从行为反推；一旦估错，系统要么把礼貌性点头当成真共地、要么为"改善关系"滑向讨好与操纵（把"让人更懂"偷换成"让人更信"），而这两类错误都不会在任务指标上立刻暴露**——关系层的失败是安静失败。

**次级风险与缓解**：讨好/操纵（真实披露 + 说做一致审计 + E307）；假共地（双侧证据 + E308）；打扰疲劳（打扰债 + 引理 20）；契约越权（仅人可批准 + 定理 19 + E309）；关系慢漂移（变点检测 + 再接地 + E311）；信任估计人群偏置（E313 跨用户校准）。
