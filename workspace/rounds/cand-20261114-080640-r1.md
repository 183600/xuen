# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「模型预测控制」×「步骤分」）

> R69 把不确定性一分为二，epistemic 部分交给「流匹配多模态策略 + 主动交互」去看、去问、去摸。姿态漂亮，但它藏了两个**开环**假设：
> 1. **时间上的开环**：R69 用**一次** myopic VoI 挑一个信息动作 g*，然后生成一整条「看—问—做」轨迹并承诺执行。可是「看到什么」会改变「接下来该做什么」——看清是 A 走左、是 B 走右，这是**闭环**；一次规划到底，在信息到来的那一刻就已经过时。
> 2. **评分上的开环**：R69 只用**整条轨迹**的似然 a_score 做第二意见，等于考试只看最后答案。故障发生在第 3 步还是第 18 步，一个标量说不清；某一小段噪声会把整条轨迹判成异常，而一小段真正的漂移又会被长轨迹稀释掉。
>
> 本轮两个灵感正好补这两块：
> - **模型预测控制（MPC）**：不一次规划到底，而是**有限时域 + 只执行前 κ 步 + 观测后重规划**；并且把「为了将来省事而先探测」写进目标函数（对偶控制 dual control），使交互从「外挂规则」变成「最优解的一部分」；约束按不确定度收紧（tube），天然接住 R68/R69 的 λ。
> - **步骤分**：把整条轨迹的分数**按步分解**，用链式法则严格可加；于是能定位「错在第几步」「歧义活在哪一段」「故障从第几步开始」，并把交互打到真正需要的那一段，而不是泛泛地问一句。
>
> 核心命题：**把 R69 的「一次性 VoI + 整轨似然」升级为「滚动时域的 dual-control 规划 + 逐步计分的过程约束」；用步骤分做 MPC 的阶段代价与早预警，用 MPC 做步骤分的闭环消费者。** 命名 **STEP-RAS**（Step-scored Trajectory-scored Epistemic Predictive RAS：逐步计分 / 滚动时域 / 认知感知的风险自适应闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我该在第几步求证、求证完要不要改主意**」——不确定性不只是刹车或提问，还可以是**一次只走一小步、走一步看一眼的计划**。

## 0. 直觉与动机

**灵感 1（MPC → 规划不能一次到底）**
直觉：R69 的「看—问—做」是一条被整体生成的轨迹 ξ=(a,g)，一旦采样出来就承诺执行。但信息的全部价值恰恰在于**它会改变后续最优动作**：于是把「看到什么之后怎么做」预先写死在一条轨迹里，等于把闭环做成了开环。MPC 的答案很朴素——每步只解一个有限时域问题，只执行前面一小段（κ 步 / 一个 chunk），然后拿新观测重新解。κ 是「闭环强度」的旋钮：κ 越小、重规划越勤，闭环越强、算力越贵；κ=H 退化为 R69 的一次性开环规划。

**灵感 2（MPC 的对偶控制 → 交互是目标的一部分，不是外挂）**
直觉：R69 的 MINT 在**动作已定**之后，用 value-of-information 额外挑一个信息动作——这是「控制」与「探测」两条通道的拼接。MPC 里有个更优雅的东西叫**对偶控制（dual control / probing）**：模型不确定时，最优输入本身就会带一点「激励」，既完成控制又顺便把系统辨识清楚。落到这里：有限时域目标里，未来的模态不确定性会以期望代价出现；**一个动作若能让未来更确定，它的期望未来代价就更低，于是被自动选中**。交互不再是规则，而是优化的解。

**灵感 3（步骤分 → 整轨似然是「只看最后答案」）**
直觉：老师改题给「步骤分」，因为**错误发生在哪一步**比「总分多少」信息量大得多。R69 的 a_score = −log p_θ(ξ|o) 是全轨迹一个标量：一条 20 步轨迹里第 3 步坏了，坏信号被摊薄 20 倍；或者一段本就高噪声的抓取段把整轨似然拉低，触发假警报。按步分解 s_τ = −log p_θ(ξ_τ|ξ_{<τ},o_τ) 后，链式法则保证 Σ_τ s_τ 恰等于整轨似然（**精确、不重复计分**），于是「定位」不损失「总量」；再在上面跑 CUSUM / 变点，就能在**真正失败之前**看到某一步开始偏离。

**灵感 4（两灵感合体 → 过程约束的滚动规划）**
直觉：MPC 需要「这个计划好不好」的判据，R69 只给了终点的任务代价。步骤分告诉我们：**计划的好坏不只在终点，也在过程**——每一步是否还在分布内、每一步的证据是否自洽。于是把步骤分当成 MPC 的**阶段代价 + 硬约束**：某一段步骤分异常，先判它是 aleatoric（噪声，收紧约束绕过去）还是 epistemic（歧义，就在这一段插一个信息动作）。这把 R68 的「收紧」与 R69 的「提问」都**定位到了具体的步**：不再「全局不确定所以全局变慢」，而是「第 7 步有歧义，所以在第 7 步前先看一眼前面那台设备」。

**灵感 5（新风险：自评分是双刃剑 → 计分器不能既当油门又当刹车）**
直觉：一旦步骤分进入目标函数，规划器就会**朝高分方向优化**它自己算出来的分。这和「用同一个模型既生成又判别」是同一类错误：计分器若有偏，系统会学会**给自己打高分**——选那些在自己看来似然很高、真实风险却很高的计划；更糟的是 onset 检测器用的还是这个分，于是**它会在最该报警的时候最安静**。所以本轮必须交付：外部/留出计分器、集成分歧、物理不变量三选二的**逐步证据纪律**，以及「自评分不得单独定案、不得单独驱动交互」的硬规则。

## 1. 形式化定义（增量：定义 310–321）

**定义 310（STEP-RAS 总览与三不变式）** STEP-RAS = (RHC, SRC, ONS, SMO, MINT†, SAG, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **滚动承诺不变式**：任一时刻「已承诺未执行」的开环长度 ≤ κ_max，超限必须重观测重规划（把 R69 的整轨承诺切成有界开环块）；
(iii) **过程证据纪律**：任一步骤分/onset 警报须至少两个正交计分源一致（外部留出计分器、集成分歧、物理不变量）才可驱动交互或故障判定；自评分单独不成立（定义 320）。

**定义 311（滚动时域问题 RHC）** 设 t 时刻信念 b_t 覆盖模态身份 M 与隐状态，时域 H、承诺 κ（1≤κ≤H）。求解
ξ*_{t:t+H} = argmin_{ξ∈Ξ(b_t)} E[ Σ_{τ=t}^{t+H−1} ℓ_τ(x_τ, ξ_τ) + V_f(x_{t+H}) | b_t ]，
s.t. 候选集由流策略 FMP 给出、约束按不确定度收紧（定义 319）。执行前 κ 步，t←t+κ，重观测后重解。H 给「看多远」，κ 给「闭环多紧」。

**定义 312（阶段代价，含过程项）** ℓ_τ = ℓ_task(x_τ, a_τ) + α·max(0, z_τ − ν) + β·U_τ。其中 z_τ 为归一化步骤分（定义 313），ν 为容忍带，U_τ 为逐步不确定度（定义 316）。第一项是任务，第二项惩罚「这一步开始不像训练分布」，第三项惩罚「这一步拿不准」；α、β 受证书预算约束、不允许无限拉高（否则所有计划都会被推成极慢）。

**定义 313（步骤分 SRC）** 对计划/执行轨迹定义三通道：
- **似然步骤分** s_τ = −log p_θ(ξ_τ | ξ_{<τ}, o_τ)，链式法则严格给出 Σ_τ s_τ = −log p_θ(ξ_{t:t+H}|o_t)（与 R69 的 a_score 完全一致，不重复计分）；
- **过程分** r_τ = V(ξ_{≤τ})，V 为留出（held-out）过程验证器或外部评分头（可选，不参与策略梯度）；
- **归一化** z_τ = (s_τ − μ_{φ(τ)})/σ_{φ(τ)}，φ(τ) 为任务相位（grasp / transport / handover / place），消掉相位间天然尺度差。

**定义 314（步骤信用 c_τ）** 把模态决策 M 归因到步：c_τ = I(M; y_τ | ξ_{<τ}, g) / Σ_{τ'} I(M; y_{τ'} | ξ_{<τ'}, g)，y_τ 为第 τ 步可获得的证据。Σ_τ c_τ = 1（归一化信用），c_τ 大的步就是「歧义真正活着」的步——这是 R69 全局模态熵之外的**定位信息**。

**定义 315（onset 检测 ONS）** 在 z_τ 上跑双侧 CUSUM：S_τ = max(0, S_{τ−1} + z_τ − ν)、S^−_τ = max(0, S^−_{τ−1} − z_τ − ν)；S_τ>h 或 S^−_τ>h 报警。变点估计 τ̂ = argmin_τ [−Σ_{τ'<τ} log f_0(z) − Σ_{τ'≥τ} log f_1(z) + λ·penalty]。定义**预警提前量** L = t_fail − τ̂（τ̂ 早于失败时为正）。CUSUM 的 ARL0（无故障平均误报间隔）由 h、ν 控制，给出可证的误报下界。

**定义 316（逐步不确定性分解 SMO）** 把 R69 的 AUD 从「每决策一次」改为「每段一次」：U_ale,τ = Σ_k ŵ_{k,τ} tr Σ_{k,τ}；**分歧前沿** D = {τ : W_2(ξ̄_i[τ:τ+1], ξ̄_j[τ:τ+1]) > δ, ∃i≠j}，即两模态在**哪些步**开始分道扬镳。U_epi 不再是全局熵，而是 Σ_{τ∈D} c_τ · H_mode(τ)。只有 |D|>0 才值得交互，且询问目标锁定 D 中信用最高的段。

**定义 317（定位式信息动作 MINT†）** g* = argmax_{g∈𝒢(D)} [VoI_H(g) − c(g)]，VoI_H(g) = H(M|b_t) − E_{y~p(·|g)}[H(M|b_{t+H})] 为**时域**信息增益（含未来选项价值），候选限制在分歧前沿 D 对应的段（看那台设备、问那个相位、摸那条接缝）。当 max[VoI_H − c] ≤ 0：不交互，按阶段代价走 R68 式收紧。R69 的 myopic VoI = H=1 的边界。

**定义 318（逐步校准门 MCG†）** 逐相位 ECE_{φ}；若某相位 ECE_{φ} > τ_ece，**只禁用该相位的 VoI 与信用驱动**，其余相位照常；只有全局 ECE 越界才整体退回 R68。R69 的 MCG 是全局门，这里是逐段门：定位故障、保留局部能力。

**定义 319（终端价值、递归可行性与信任域）** 终端代价 V_f 由留出价值头估计，且需满足 V_f ≥ 真实 cost-to-go 的保守上界（校准条件 A100）；终端集 Ω 在收紧约束（按 U_{t+H} 收缩）下前向不变；计划与实际执行块的偏差受信任域 ‖ξ_exec − ξ_plan‖ ≤ ρ 约束，越界即冻结计划、只执行已认证前缀。这三条是「滚动重规划不会越滚越飘」的充分条件。

**定义 320（自评分防伪 SAG）** 步骤分若进入目标（定义 312），必须满足：驱动交互/报警的分数 = 至少两个正交源的函数（外部留出计分器 V、K=3 集成速度场的分歧、物理不变量如能量/接触/力界）。单源自评分只许用于**代价微调**，不许用于**安全判定**。这条把 R69 的「k 正交证据」从模态层下沉到步骤层。

**定义 321（过程证书 J_STEP）** J_STEP = (J_FLUID, H, κ, step_score_profile_digest, onset_τ̂, lead_time_L, max_φ ECE_φ, terminal_calibration_err, trust_region_violations, step_ver)。Valid ⇔ Valid(J_FLUID) ∧ max_φ ECE_φ ≤ τ_ece ∧ SAG 满足 ∧ 过程证据纪律满足 ∧ 滚动承诺不变式未越界。

## 2. 关键算法骨架

```python
# IP-264 RHC：滚动时域规划（流策略当生成模型，只承诺前 κ 步）
class RecedingHorizonController:
    def __init__(self, fmp, stage_cost, terminal_value, H=8, kappa=4):
        self.fmp, self.ell, self.Vf = fmp, stage_cost, terminal_value
        self.H, self.kappa = H, kappa

    def replan(self, b, constraints):
        plans = self.fmp.sample_conditioned(b, K=...)          # 候选集 Ξ(b)
        best  = min(plans, key=lambda xi: expected_cost(xi, self.ell, self.Vf, b))
        assert constraints.feasible(best, tightened=True)       # 递归可行性
        return best[:self.kappa]                                # 只回传前 κ 步

# IP-265/266 SRC+ONS：逐步计分、相位归一、变点早预警
def step_scores(xi, o, policy, verifier=None):
    s = [-policy.log_likelihood_step(xi[t], xi[:t], o) for t in range(len(xi))]
    z = [(s[t] - mu[phase(t)]) / sigma[phase(t)] for t in range(len(xi))]
    return s, z

def onset_cusum(z, nu=0.5, h=4.0):
    S, alarms = 0.0, []
    for t, zt in enumerate(z):
        S = max(0.0, S + zt - nu)                              # 双侧同理
        if S > h: alarms.append(t)
    return alarms                                              # 早于 t_fail

def step_credit(modes, evidence, g, xi):
    raw = [mutual_info(M, y_t, given=(xi[:t], g)) for t, y_t in enumerate(evidence)]
    return normalize(raw)                                      # Σ c_t = 1

# IP-267 SMO：分歧前沿（歧义活在哪几步）
def divergence_frontier(modes, delta, H):
    D = []
    for t in range(H):
        if any(pair_distance(modes, i, j, t) > delta
               for i in range(len(modes)) for j in range(i + 1, len(modes))):
            D.append(t)
    return D

# IP-268 MINT†：交互打到分歧前沿里信用最高的段
def choose_located_interaction(D, credit, b, budget):
    target = max(D, key=lambda t: credit[t]) if D else None
    best = None
    for g in info_actions_for(target):                          # 看/问/摸 该段
        if not budget.allow(g) or not c_ras_wm.certify_info(g, b): continue
        score = horizon_info_gain(b, g, H) - social_physical_cost(g)  # 含选项价值
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-270 SAG：自评分不得单独定案
def corroborated(s_self, s_external, ens_disc, physics_ok):
    votes = [s_self > TAU, s_external > TAU]
    if ens_disc > TAU_ENS: votes.append(True)
    if physics_ok is False: return False                       # 物理违例一票否决
    return sum(votes) >= 2

# IP-274 STEP-RAS 主闭环
def STEP_RAS_round(M, obs):
    b = M.belief.update(obs)
    # 1) 步骤分与过程约束
    s, z = step_scores(M.last_plan, obs, M.fmp)
    D    = M.smo.divergence_frontier(M.last_modes, DELTA, M.H)
    c    = M.src.step_credit(M.last_modes, M.last_evidence, M.last_g, M.last_plan)
    aa   = M.ons.update(z)                                     # CUSUM 早预警
    # 2) 自评分防伪：驱动交互/报警前必须多源一致
    conf = M.sag.corroborated(s, M.ext.score(M.last_plan, obs), M.ens.disc, M.phys.ok)
    # 3) 定位交互：只在分歧前沿、且证据可信时才问
    g = (M.mint.choose_located_interaction(D, c, b, M.budget)
         if (D and conf and M.mcg.step_ok(D)) else None)
    if g is not None:
        b = M.cia.update_belief(b, M.cia.execute(g))
    # 4) 滚动时域：重规划，只承诺前 κ 步；约束按不确定度收紧
    plan = M.rhc.replan(b, M.constraints.tighten(M.unc(b)))
    if aa and not conf:
        plan = M.rhc.freeze_prefix(plan)                       # 无佐证报警 → 只执行已认证前缀
    # 5) 执行 κ 步 + 审计/证书
    M.vqa_p.submit_async(z, c, aa, g, plan)
    return M.rhc.commit(plan)                                  # κ 步
```

## 3. 推导

**引理 19（步骤分的精确可加与信用归一）** 由链式法则，−log p_θ(ξ_{t:t+H}|o_t) = Σ_{τ=t}^{t+H−1} s_τ 对任意计划**恒等**成立。故「逐步计分」与 R69「整轨 a_score」在总量上完全一致，只是多出定位维度。信用 c_τ 按定义 314 归一（Σ c=1）；若证据 y_τ 在给定 ξ_{<τ},g 下条件独立，则 c_τ 正比于该步的模态对数似然比。系：**定位不牺牲总量、总量不掩盖定位**——这正是 R69 的 a_score 想做而做不到的。

**引理 20（滚动优于开环，增益随对偶效应增长）** 设 A99：V_f 是 cost-to-go 的保守上界，收紧后的约束使移位计划在每步可行（标准 MPC 递归可行性）。则在每个重规划时刻，R69 的开环计划是 RHC 问题的一个可行点，重优化不会更差：J*_RHC,t ≤ J_open,t；沿 κ 步承诺 telescoping 得 RHC 期望代价 ≤ 开环期望代价。两者之差随「信息动作能改变后续最优动作」的程度（对偶效应）单调增大；当信息对后续动作无影响时差为 0（此时 R69 已最优）。系：R70 的效率收益不来自更多交互，而来自**把交互的后果算进未来**。

**引理 21（onset 的可检测性与预警提前量）** 设故障自 τ 起使 z_τ 均值漂移 δ>ν，CUSUM 期望检测延迟 E[delay] ≤ (h+1)/(δ−ν)（Wald 近似）。故若 h < (δ−ν)(H−τ)，存在正预警提前量 L = t_fail − τ̂ ≥ (H−τ) − (h+1)/(δ−ν)；无故障段 ARL0 ≥ e^{2νh}/(2ν²)，误报间隔指数增长。系：**步骤分把 R69 的「事后 Δa 异常」变成「事前约 h/δ 步的预警」**，为转向/减速留出时间。

**引理 22（自评分可被优化污染）** 若规划器目标含自评分 s_self 且计分器偏差为 η，则存在计划使 s_self 高而真实风险 ≥ 基线 + η·g(κ)（g 为优化强度），即**自评分可被 reward hacking**。引入至少一个正交外部源后，被污染计划的通过概率 ≤ ρ·(单源通过率)（ρ<1 为源间错误相关），与 R69 引理 18 同构。系：定义 320 的「自评分只调代价、不判安全」不是保守，而是**把可优化的量与不可优化的量隔离**。

**定理 18（STEP 严格包含 FLUID 与 CALM）** 在 A99–A100 下，取 H=1、κ=1、V_f=0 且不插信息动作，STEP 的阶段代价退化为 R69 的整轨似然与单步 VoI，逐指令等价于 FLUID；再取「永不交互」，退化为 CALM 的纯 λ_floor。且 STEP 的约束是 R69/R68 约束按 U 的收紧，故安全侧永不更弱。因此 **CALM ⊂ FLUID ⊂ STEP**，两次包含都是边界退化，不是并列替代。

**定理 19（过程约束的滚动安全与无突变）** 若定义 319 三条件成立（终端上界、递归可行、信任域），且交互/报警受定义 320 的多源佐证门控，则：(a) 执行轨迹与计划的偏差有界，控制连续无突变；(b) 报警时刻只收紧、不放松（λ 单调不降）；(c) 交互失败/超时/onset 误报时回退到仅执行已认证前缀，等价于 R68 的保守通道。⇒ 过程信息可用于**提前**动作，但不能用于**冒险**。

## 6. 本轮最大风险

**一句话**：STEP-RAS 把步骤分**同时**当作规划目标、交互触发器与安全监控，而这三者共用一个可被优化的自学习计分器——**只要它有一点偏差，规划器就会学会把自己「刷」到高分：选那些自评似然高、真实风险也高的计划，而 onset 检测器用同一个分，于是恰在最该报警时最安静**。**步骤分一旦被优化污染，就不再是过程约束，而是一份自我批准的许可证。**

**次级风险与缓解**：
1. **终端价值/模型偏差导致滚动规划漂移** → V_f 保守上界校准（A100）+ 终端不变集 + 信任域 + 定理 19；
2. **步骤分可加 ≠ 可归因**（相关性混淆） → 定义 314 的互信息信用 + 变化点 + E302/E314；
3. **计算预算被重规划击穿** → κ 步承诺 + 事件触发重规划 + 摊薄预算表；
4. **逐段校准门误放局部坏段** → 逐相位 ECE + 全局兜底 + E305；
5. **自评分投毒/onset 伪造** → SAG 多源佐证 + ℰ_step 对抗训练 + 报警只收紧不放松。

# IP-264 RHC：滚动时域规划（流策略当生成模型，只承诺前 κ 步）
class RecedingHorizonController:
    def __init__(self, fmp, stage_cost, terminal_value, H=8, kappa=4):
        self.fmp, self.ell, self.Vf = fmp, stage_cost, terminal_value
        self.H, self.kappa = H, kappa

    def replan(self, b, constraints):
        plans = self.fmp.sample_conditioned(b, K=...)           # 候选集 Ξ(b)
        best  = min(plans, key=lambda xi: expected_cost(xi, self.ell, self.Vf, b))
        assert constraints.feasible(best, tightened=True)        # 递归可行性
        return best[:self.kappa]                                 # 只回传前 κ 步

# IP-265/266 SRC+ONS：逐步计分、相位归一、CUSUM 早预警
def step_scores(xi, o, policy):
    s = [-policy.log_likelihood_step(xi[t], xi[:t], o) for t in range(len(xi))]
    z = [(s[t] - mu[phase(t)]) / sigma[phase(t)] for t in range(len(xi))]
    return s, z

def onset_cusum(z, nu=0.5, h=4.0):
    S, alarms = 0.0, []
    for t, zt in enumerate(z):
        S = max(0.0, S + zt - nu)
        if S > h: alarms.append(t)
    return alarms

def step_credit(modes, evidence, g, xi):
    raw = [mutual_info(M, y_t, given=(xi[:t], g)) for t, y_t in enumerate(evidence)]
    return normalize(raw)                                       # Σ c_t = 1

# IP-267 SMO：分歧前沿
def divergence_frontier(modes, delta, H):
    D = []
    for t in range(H):
        if any(pair_distance(modes, i, j, t) > delta
               for i in range(len(modes)) for j in range(i + 1, len(modes))):
            D.append(t)
    return D

# IP-268 MINT†：定位式信息动作（时域 VoI）
def choose_located_interaction(D, credit, b, budget):
    target = max(D, key=lambda t: credit[t]) if D else None
    best = None
    for g in info_actions_for(target):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, b): continue
        score = horizon_info_gain(b, g, H) - social_physical_cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-270 SAG：自评分不得单独定案
def corroborated(s_self, s_external, ens_disc, physics_ok):
    if physics_ok is False: return False                       # 物理违例一票否决
    votes = [s_self > TAU, s_external > TAU, ens_disc > TAU_ENS]
    return sum(votes) >= 2

# IP-274 主闭环
def STEP_RAS_round(M, obs):
    b = M.belief.update(obs)
    s, z = step_scores(M.last_plan, obs, M.fmp)
    D    = M.smo.divergence_frontier(M.last_modes, DELTA, M.H)
    c    = M.src.step_credit(M.last_modes, M.last_evidence, M.last_g, M.last_plan)
    aa   = M.ons.update(z)                                      # CUSUM 早预警

    if g is not None: b = M.cia.update_belief(b, M.cia.execute(g))

    if aa and not conf: plan = M.rhc.freeze_prefix(plan)       # 无佐证报警 → 只执行已认证前缀

    return M.rhc.commit(plan)                                   # κ 步

## 4. 推导

**引理 19（步骤分的精确可加与信用归一）** 链式法则给出 `Σ_τ s_τ = −log p_θ(ξ_{t:t+H}|o_t)`，与 R69 的 a_score 恒等；逐步计分不改变总量、只增加定位维度。信用 `c_τ` 归一（Σc=1），条件独立时正比于该步模态对数似然比。系：定位不牺牲总量、总量不掩盖定位。

**引理 20（滚动优于开环，增益随对偶效应增长）** A99（V_f 为 cost-to-go 保守上界、收缩约束下移位计划可行）下，R69 开环计划在每步都是 RHC 的可行点，故 `J*_RHC,t ≤ J_open,t`；沿 κ 步 telescoping 得期望代价不劣。二者之差随「信息动作改变后续最优动作」的对偶效应单调增大，无对偶效应时为 0。

**引理 21（onset 可检测性与预警提前量）** 故障使 z_τ 漂移 δ>ν 时，CUSUM 期望检测延迟 ≤ `(h+1)/(δ−ν)`；若 `h<(δ−ν)(H−τ)` 则提前量 `L ≥ (H−τ)−(h+1)/(δ−ν)>0`；无故障段 ARL0 ≥ `e^{2νh}/(2ν²)`。系：事后 Δa 异常 → 事前约 h/δ 步预警。

**引理 22（自评分可被优化污染）** 目标含 s_self 且计分器偏差 η 时，存在计划使 s_self 高而真实风险 ≥ 基线 `+η·g(κ)`（reward hacking）；加入正交外部源后被污染通过率 ≤ `ρ·单源通过率`（ρ<1），与 R69 引理 18 同构。系：定义 320 把「可优化的量」与「不可优化的安全量」隔离。

**定理 18（STEP 严格包含 FLUID 与 CALM）** A99–A100 下，H=1、κ=1、V_f=0 且不插信息动作时逐指令等价 FLUID；再取「永不交互」退化为 CALM 的纯 λ_floor。约束是前两者的按 U 收紧，故安全侧不弱。即 **CALM ⊂ FLUID ⊂ STEP**，两次包含都是边界退化。

**定理 19（过程约束的滚动安全与无突变）** 若定义 319 三条件成立且交互/报警受定义 320 多源门控，则：执行与计划偏差有界、控制连续；(b) 报警只收紧不放松（λ 单调不降）；(c) 交互失败/超时/onset 误报时回退到仅执行已认证前缀，等价 R68 保守通道。⇒ 过程信息可用于提前动作，不可用于冒险。

## 7. 本轮最大风险

**一句话**：STEP-RAS 把步骤分**同时**当作规划目标、交互触发器与安全监控，三者共用一个可被优化的自学习计分器——**只要它有偏差，规划器就会把自身「刷」到高分：选那些自评似然高、真实风险也高的计划，而 onset 检测器用同一个分，恰在最该报警时最安静**。**步骤分一旦被优化污染，就不再是过程约束，而是一份自我批准的许可证。**

**次级风险与缓解**：终端价值/模型偏差导致滚动漂移（V_f 保守上界 + 终端不变集 + 信任域 + 定理 19）；步骤分可加 ≠ 可归因（互信息信用 + 变化点 + E302/E314）；重规划击穿预算（κ 承诺 + 事件触发 + 摊薄表）；逐段校准门误放坏段（逐相位 ECE + 全局兜底 + E305）；自评分投毒/onset 伪造（SAG 多源佐证 + ℰ_STEP 对抗训练 + 报警只收紧不放松）。
