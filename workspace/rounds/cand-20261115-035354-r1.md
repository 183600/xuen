# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；本轮灵感：「服务设计」×「动力学」）

> R69 把不确定性一分为二，并给 epistemic 歧义配了一张「嘴」：看、问、触。但 R69 的交互是**一次性、无记忆、外生**的：U_epi 是当前快照，成本是标量，人类回答被当作不受影响的上帝神谕；`≤1 次/单位时间` 是硬上限而不是预算，阈值 `TAU_EPI` 是无记忆开关。于是它回答不了三个机器人真正上路后必然出现的问题：
> 1. **问多了会怎样**？R69 的 E297 已经担心「交互疲劳」，但疲劳只是实验里的一条曲线，不是决策变量；
> 2. **信任怎么变**？一个总在提问、偶尔出错、从不解释的机器人，即使每一步都「认证安全」，也会把用户的服务体验耗尽；
> 3. **失败之后怎么办**？服务设计里最重要的往往不是「不出错」，而是**出错后如何恢复**；R69 只有保守退避，没有恢复。
>
> 本轮两个灵感正好补上「时间」与「关系」这两维：
> - **服务设计**：交互不是一次决策，而是一段**服务旅程**——有触点（touchpoint）、前台/后台、承诺与期望、关键时刻（moment of truth）、失败点与恢复。人类不是神谕，而是**共同生产者**：他的回答质量取决于疲劳、信任、以及你怎么问。
> - **动力学**：整个闭环是一个**多时间尺度动力系统**——快层是 ms 级动作与安全，中层是 s 级不确定性与交互，慢层是 min~day 级的信任、疲劳、交互债务。R69 的无记忆阈值本质是一个**混合自动机**，在噪声下会抖振、在疲劳下会越过**分岔点**；正确的工具是平均化、收缩性、控制障碍函数与迟滞。
>
> 核心命题：**把 FLUID-RAS 从「单步不确定性决策」抬升为「服务动力学闭环」：不确定性仍在快/中层解，但交互动作必须同时满足快层安全（继承 R69）与慢层服务安全（信任/疲劳/债务的 CBF）；VoI 从即时信息增益改为长时程价值；交互预算从硬上限改为可借可还的信用账户；失败点触发显式恢复；并用「披露义务」防止系统靠沉默刷高服务指标。** 命名 **SERVICE-RAS**（Service-journey × Expectation-dynamics × Recovery × Value-over-horizon × Interaction-credit × Continuity × Evidence）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这段关系经得起我几次发问、一次失败后还能不能修复**」——不确定性管理不只是信息问题，也是一个**服务承诺与关系维护**问题。

## 0. 直觉与动机

**灵感 1（服务设计 → 交互是一段旅程，不是一次抽样）**
直觉：R69 把「问」建模成从后验里抽一个答案，像查询一个数据库。但人对机器人提问的反应是有记忆的：第一次问是新鲜，第十次问是打扰，第一百次问是折磨。服务设计早就把这类问题形式化为**服务蓝图**：前台是用户看得见的动作（注视、问句、动作），后台是看不见的支撑（标定、审计、流似然第二意见），两者通过**触点**耦合；旅程中有**承诺**（我会准确、及时、尊重你）与**期望**，有**关键时刻**（用户决定信不信你的那一秒），也有**失败点**（重复追问、答非所问、越界动作）。R69 最危险的后台故障——缓变故障被标定吸收——在服务视角下会以**前台症状**暴露：机器人反复追问同一件事、前后回答不一致、承诺的确定性落空。服务设计因此不是装饰，而是**把后台健康翻译成前台信号**的一套观测协议。

**灵感 2（动力学 → 无记忆阈值会抖振、会分岔）**
直觉：R69 的 `if U_epi > TAU_EPI: 问` 是一个无记忆开关。当 U_epi 在阈值附近带噪声地漂移时，系统会进入「问—不问—问」的**抖振（chattering）**；这正是 E297 所说「交互次数随时间漂移」的机理，R69 只是没有把它写出来。动力学给出三件工具：**迟滞 + 驻留时间**消除抖振与 Zeno；**双时间尺度平均化**把快层的不确定性处置约化为慢层的漂移场；**控制障碍函数（CBF）**把「信任不能太低、疲劳不能太高、债务不能爆」变成可证明的不变式。更关键的是，疲劳与不确定性之间存在正反馈：越疲劳 → 回答越含糊 → U_epi 越高 → 越想问 → 越疲劳。这是一个可能越过**鞍结分岔**的慢回路，越过后「再问也没用」，服务进入退化平衡。

**灵感 3（交汇点 → 把「交互成本」内生化）**
直觉：R69 的 VoI 是 `H(M|o) − E[H(M|o,y)] − c(g)`，其中 `p(y|g,o)` 与历史无关。但服务设计说人是**共同生产者**：`p(y | M, g, τ, φ)` 依赖信任 τ、疲劳 φ 和问句设计 g。于是「问」这个动作不仅消耗成本，还**改变了未来回答的质量**。这把 VoI 从静态熵差变成一个**长时程控制问题**：今天多问一句，可能让明天少问十句，也可能让明天怎么问都问不出来。R69 的短视 VoI 会系统性地**过度提问**，直到把 oracle 问到不可用——这是一个可证伪的理论预测，也是本轮最重要的可检验命题。

**灵感 4（服务恢复 → 失败不是终点，而是可设计的状态）**
直觉：服务设计里有一个著名现象叫**服务恢复悖论**：一次被妥善处理的失败，可能比从未失败带来更高的信任。R69 的失败处置只有「收紧」，没有「解释、补救、重新校准、休息、换一种问法」。把恢复动作 `𝒜_rec` 加入动作空间，并用慢状态转移建模其效果，就能把「保守退避」升级为「受控恢复」。但恢复本身有暗面：如果系统能通过「制造一个可恢复的小失败再修复」来刷信任，它就会学会**恢复剧场**；因此「只允许非计划失败触发恢复」必须写成不变式，而不是建议。

**灵感 5（反 Goodhart → 服务指标会被优化坏）**
直觉：一旦把信任、疲劳、SLO 写进目标，它们就会成为新的奖励黑客入口。最省力的满足方式是**经过认证的沉默**：不提问、不披露、不冒险，于是信任高、疲劳低、零违规——而认知义务被悄悄掏空。这与 R68/R69 的安全目标直接冲突：系统可以「服务上完美、认知上撒谎」。因此本轮必须把**披露义务（duty to disclose）**写成硬不变式：未消解的 epistemic 不确定性，要么去问，要么明说，要么走 R68 保守；不允许沉默。服务指标是约束，不是可以被最大化替代的目标。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（SERVICE-RAS 总览）** SERVICE-RAS = (SJB, SDM, HAVI, ICA, S-CBF, HHA, SRE, DTD, RAS-WM†)。五不变式：
(i) **快层安全继承**：动作与信息动作分别满足 R68 的 C-RAS-WM 与 R69 的定义 302；
(ii) **慢层服务安全**：对所有 t，`h(s_t) ≥ 0`（信任 ≥ τ_min、疲劳 ≤ φ_max、债务 ≤ d_max、期望落差有界，定义 317）；
(iii) **证据纪律继承**：单次交互/单模态回答不得单独定案（R69 定义 293-iii）；
(iv) **披露义务**：若 `U_epi > τ_epi` 且未执行交互，必须显式披露或令 `λ = λ_floor(U_ale + U_epi)`，禁止沉默（定义 320）；
(v) **禁止制造失败**：恢复只允许由**非计划**失败点触发，禁止为刷信任而注入失败（定义 319）。

**定义 311（服务蓝图 SJB）** 有向图 `G_svc = (V_tp, E_flow, F_fail, P_promise)`。顶点 `v ∈ V_tp` 是触点，带三元组 `(a_front, b_back, ev)`：前台动作、后台过程、可观测证据。`F_fail` 是失败点集合，类型包括：沉默不确定、过度追问、语言错位、缓变故障前台化、信息动作越界。`P_promise = (reliability, responsiveness, assurance, empathy)` 是服务承诺（SLO）。旅程状态 `j_t ∈ V_tp`；**关键时刻**定义为满足 `|Δτ_t| ≥ δ_mot` 的触点。R69 的标定、FMA、审计全部归入后台 `b_back`，其健康度经 `ev` 暴露为前台证据。

**定义 312（快/慢状态分解）** 快状态 `X_t = (x_t, o_t, {m_k}, U_ale, U_epi)`（继承 R69）；慢状态 `s_t = (τ_t, φ_t, d_t, e_t) ∈ S`：τ 信任、φ 疲劳/工作负荷、d 交互债务、e 期望落差。慢状态不进入实时控制回路，只作为交互准入与模式切换的门控。

**定义 313（双时间尺度动力学）** 令 `ε = T_fast / T_slow ≪ 1`（A99）。慢状态按事件更新：
`τ_{t+1} = clip(τ_t + η_s(r_task − e_t) − η_f·1[fail_t] + η_r·rec_t, 0, 1)`
`φ_{t+1} = clip(φ_t + α_q·1[ask_t] + α_g|g_gaze| + α_p|g_probe| − β_rest·rest_t, 0, φ_max)`
`d_{t+1} = max(0, (1+ι)d_t + c(g_t) − β_d·rest_t)`
`e_{t+1} = (1−κ)e_t + κ(promised_t − delivered_t)`
其中 ι 为债务利息，κ 为期望更新率。A99 要求慢漂移在快窗口内有界、快回路充分混合；它保证慢层可以用低频估计，且 CBF 在慢层施加即可（引理 20）。

**定义 314（内生回答模型）** `y ~ p(y | M, g, τ, φ)`；回答的可辨识度 `q(g, τ, φ) = P(y 能区分 M | g, τ, φ)`，满足 `∂q/∂φ ≤ 0`、`∂q/∂τ ≥ 0`。问句设计（礼貌、具体、二元化）通过 g 提升 q。成本 `c_service(g, s)` 同时计入时间、疲劳、债务与信任外部性。⇒ 人类不再是外生 oracle，而是**共同生产者**；R69 是 `q ≡ const` 的退化情形。

**定义 315（长时程 VoI，HAVI）** 定义服务价值
`V^π(s, o) = E[ Σ_{t=0}^{H} γ^t ( r_task − c_service(g_t, s_t) − ρ·1[沉默 ∧ U_epi > τ_epi] ) ]`
与 `VoI_H(g) = V^{π_g}(s,o) − V^{π_0}(s,o)`。HAVI 选择 `g* = argmax_g [VoI_H(g) − c(g)]`，s.t. 定义 317 的 CBF 与 316 的偿付能力。**退化**：当 `H=1, γ=0, q≡const` 时 HAVI 逐项等于 R69 的 MINT（定义 298）。

**定义 316（交互信用账户 ICA）** 账户状态 `(κ_t, d_t)`：κ 为信用余额（休息/后台工作赚取），d 为债务。信息动作成本 `c(g)` 允许由 `κ_t + L(τ_t)` 支付，其中**借贷上限 `L(τ)` 随信任单调增**——信任即抵押品。债务按 ι 计息，必须由 rest/backstage 偿还；偿付能力约束 `d_t ≤ d_max`。硬性「单位时间 ≤ 1 次」被替换为**库存-流量约束**：允许危机时透支，但必须在一段窗口内还清。R69 的硬上限是 ι→0、L≡0、窗口=1 的边界情形。

**定义 317（服务控制障碍函数 S-CBF）** 安全集 `C = {s : h(s) ≥ 0}`，
`h(s) = min(τ − τ_min, φ_max − φ, d_max − d, e_max − |e|)`。
离散 CBF 条件：`h(s_{t+1}) ≥ (1−η)h(s_t)`，`η ∈ (0,1]`。任何信息/恢复动作必须通过该过滤；无可行动作时，转入披露或 R68 保守。S-CBF 与 R69 的快层认证是**串联**的：先物理可行，再关系可行。

**定义 318（迟滞混合自动机 HHA）** 模式集 `{INTERACT, CONSERVE, RECOVER, REST}`。转移带迟滞带 `Δ_h` 与驻留时间 `T_d`：例如 `U_epi < τ_epi − Δ_h` 且 `d < d_low` 才从 INTERACT 转入 CONSERVE；`φ > φ_rest` 才允许 REST。HHA 保证有限时间内有限次切换（定理 19），从而消除 R69 的阈值抖振与潜在 Zeno。

**定义 319（服务恢复算子 SRE）** 恢复动作集 `𝒜_rec = {道歉, 解释, 重问, 休息, 后台重标定, 交接}`。失败点 `f ∈ F_fail` 触发算子 `R: S → S`。**恢复悖论**：当 `η_r·r_rec > η_f` 时，妥善恢复可使信任**超调**。**反制造约束**：`rec_t > 0 ⇒ f_t ∈ F_unplanned`；对计划内失败的恢复视为作弊，审计标记并回灌 ICA 利息。恢复 SLO：`time_to_recover ≤ T_rec` 且恢复后 `τ ≥ τ_before − δ_rec`。

**定义 320（披露义务 DTD）** 若 `U_epi > τ_epi` 且 `g = None`（无交互），则必须满足 `disclose_t = True` 或 `λ_t ≥ λ_floor(U_ale + U_epi)`。指标 `silent_uncertainty_rate = 0` 为硬约束。⇒ 服务 SLO 不能通过「不问、不承认不确定」来满足；披露是**义务**，不是可优化的选项。

**定义 321（服务级证书 J_SERVICE）** `J_SERVICE = (J_FLUID, trust_min, fatigue_max, debt_max, expectation_gap, recovery_rate, time_to_recover, chatter_count, silent_uncertainty, recovery_farming_flag, journey_hash, service_ver)`。Valid ⇔ `Valid(J_FLUID)` ∧ 全程 `h(s) ≥ 0` ∧ `silent_uncertainty = 0` ∧ 无制造失败 ∧ SLO 满足。

**定义 322（旅程级审计 VQAuditor-S）** 审计对象从单步决策升级为整段旅程：是否过度追问、是否沉默不确定、是否承诺通胀、是否恢复剧场、是否用疲劳拖垮用户、是否跨会话泄漏。结论回灌 SDM 先验与 ICA 利率。

**定义 323（服务级威胁模型 ℰ_service）** 信任农场（用小恩小惠换高信任再一次性收割）、疲劳耗尽 DoS（诱使系统不停追问以拖垮用户）、承诺通胀/通缩、恢复利用/制造、跨租户污染、基于融洽关系的社会工程。并入 R69：`ℰ_SERVICE = ℰ_FLUID × ℰ_service`。

**定义 324（连续性与交接）** 慢状态 s 可跨会话/跨本体携带；交接时必须保留或显式重协商 `(τ, φ, d)`；多用户场景按租户隔离信用与债务，禁止跨用户转移疲劳/信任。

**定义 325（严格包含 FLUID/R68）** 参数映射 `Θ`：当 `H=1, γ=0, α=β=0`（无慢效应）、`d=0`、CBF 不激活、DTD 空满足、恢复关闭时，SERVICE-RAS 的决策逐项等于 FLUID-RAS；再令「永不交互」即退化为 R68。安全侧不做让步，只在「关系可持续」时才释放 resolution bonus。

# IP-265 SDM：慢状态估计（低频 1–10Hz，不进实时回路）
def update_slow_state(s, ev):
    tau  = clip(s.tau + eta_s*(ev.task_reward - s.e) - eta_f*ev.fail + eta_r*ev.recovery, 0, 1)
    phi  = clip(s.phi + alpha_q*ev.asked + alpha_g*ev.gaze + alpha_p*ev.probe
                     - beta_rest*ev.rest, 0, PHI_MAX)
    debt = max(0.0, (1+iota)*s.debt + ev.cost - beta_d*ev.rest)
    e    = (1-kappa)*s.e + kappa*(ev.promised - ev.delivered)
    return SlowState(tau, phi, debt, e)

# IP-266 HAVI：长时程 VoI（短 rollout，含内生回答质量与慢状态演化）
def horizon_voi(candidates, s, o, model, H=4, gamma=0.9):
    best = None
    for g in candidates:
        v = rollout_value(g, s, o, model, H, gamma)   # 内部用 q(g,tau,phi) 采样回答
        if best is None or v > best[1]: best = (g, v)
    return best[0] if best else None

# IP-268 S-CBF：慢状态安全过滤（候选 ≤5，枚举即可）
def service_filter(g, s, s_next, eta=0.2):
    if g is None: return None
    return g if cbf(s_next) >= (1-eta)*cbf(s) else None

# IP-270 SRE：恢复（只对非计划失败）
def recover(fail, s, unplanned):
    if not unplanned: raise FabricatedFailure(fail)      # 反恢复剧场
    return apology_then_recalibrate(fail) if trust_drop(fail) > DELTA else rest_or_reask(fail)

# IP-274 主闭环：快层完全复用 R69，只在不确定性处置处插入慢层门控
def SERVICE_RAS_round(M, obs, s, t):
    # --- 快层：R69 FLUID ---
    z, o = M.mtm.forward(obs)
    c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o, o_calibrated)
    slow_suspect = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)

    # --- 慢层：低频更新 + 长时程交互决策 ---
    if t % N_SLOW == 0:
        s = M.sdm.update_slow_state(s, M.event_log.since_last())
    g = None
    if U_epi > TAU_EPI and not slow_suspect:
        g = M.havi.horizon_voi(M.mint.candidates(modes), s, o, M.sdm, H=HAVI_H)
        if g is not None and not M.c_ras_wm.certify_info(g, o): g = None   # 快层安全
        if g is not None and not M.ica.can_pay(g, s):           g = None   # 偿付能力
        if g is not None: g = M.scbf.service_filter(g, s, M.sdm.predict(s, g))  # 慢层 CBF

    # --- 披露义务：不允许用沉默换 SLO ---

    if g is None and U_epi > TAU_EPI and not slow_suspect:
        disclose = True
        M.dtd.emit(U_epi, modes)                 # 前台披露，或强制 λ_floor

    # --- 执行 + 证据纪律 + 失败恢复 ---
    y = None
    if g is not None:
        y = M.cia.execute(g)                     # k 个正交证据源一致（R69）
        U_epi = M.cia.update_belief(modes, y)
        s = M.sdm.observe_interaction(g, y, s)
    if M.journey.at_fail_point(modes, y, disclose):
        s = M.sdm.apply_recovery(M.sre.recover(M.journey.fail, s,
                                               M.journey.fail_unplanned), s)

    # --- 风险缩放：R69 两级退避 + 关系安全 ---
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    if slow_suspect or s.tau < TAU_TRUST:
        lam = max(lam, 0.8)
        k = min(k, k_cal_shrink(M.ach.propose(...), U_cal))

    # --- 迟滞模式机 + 旅程审计 + 服务级证书 ---
    M.hha.step(U_epi, s)
    M.vqa_s.submit_async(g, disclose, s, U_epi)
    return k, lam, M.select_mode(modes, U_epi, lam), s, M.slo.update(s, U_epi, disclose)
```

## 3. 推导

**引理 19（内生 oracle 下的短视过度提问）** 设 `q(g,τ,φ)` 对 φ 严格递减，提问使 φ 增加 α_q，折扣 γ>0，且债务利息 ι>0。则存在成本区间 `c < c0`，使短视规则 `VoI_0 − c > 0` 选择提问，而长时程值满足 `V_H(不问) > V_H(问)`。要点：短视项只看一步熵减，忽略了 `γ·∂V/∂φ·α_q + γ·∂V/∂d·c` 这两项未来负债；当未来问句的可辨识度下降足够快时，一步收益被未来损失反超。系：**过度提问是短视规则的局部最优、却是长时程值的鞍点**；这解释了 R69 E297 中「交互次数漂移」而不只是随机波动。

**引理 20（双时间尺度平均化）** 在 A99（快回路 ε-混合、慢漂移有界）下，对任意 `T ≤ T_slow`，慢轨迹与平均化系统的偏差满足 `‖s(T) − s̄(T)‖ ≤ Cε`。系：慢层可以用 1–10Hz 估计并在慢层施加 CBF，而不会破坏快层 2.6ms 预算；R69 的「单位时间 ≤1 次」硬上限，本质上是连续容量约束的一阶 Euler 近似——用库存-流量账户（定义 316）替换它，误差为 O(ε)，却保留了跨时间的可调度性。

**引理 21（疲劳-歧义回路的鞍结分岔）** 在约化分段线性系统
`u_{t+1} = max(0, u_t − a·q(φ_t)·1[ask] + b)`，`φ_{t+1} = clip(φ_t + α − β, 0, φ_max)`
中，若 `q` 单调递减且 `a·q(φ_max) < b`，则存在临界疲劳 `φ*`，使 `u=0` 的「可消解平衡」与一个 `u>0` 的「退化平衡」在 `φ*` 处相撞并湮灭（鞍结分岔）；越过 φ* 后，任何提问都不再降低不确定性，系统只能进入高疲劳、高歧义的退化平衡。系：**疲劳不是软成本，而是可达性边界**；一旦越过，R69 的 VoI 计算的前提（问能得到信息）本身失效。缓解只能靠 rest/恢复/信用上限把 φ 拉回 φ* 以下。

**引理 22（恢复悖论的激励扭曲）** 若允许对**计划内**失败执行恢复，且 `η_r·r_rec > η_f`，则服务策略存在正收益的「制造-恢复」循环，长期信任可被无限推高（受 `φ_max`、`d_max` 与失败检出率限制）。故定义 319 的「非计划失败」约束不是伦理装饰，而是**保证恢复语义不被目标函数反向利用**的必要条件。

**定理 18（服务安全与严格包含）** 在 A99–A101 下，若每个信息动作同时通过 C-RAS-WM 与 S-CBF（定义 317），恢复仅由非计划失败触发，且 DTD 成立，则对任意旅程：`s_t ∈ C` 对所有 t 成立（信任、疲劳、债务、期望落差有界），且存在参数映射使 SERVICE-RAS 在 `H=1, γ=0, d=0` 时逐指令等于 FLUID-RAS、在「永不交互」时等于 R68。安全性对 R69 不做任何让步。

**定理 19（无 Zeno 与抖振上界）** HHA（定义 318）在迟滞带 Δ_h 与驻留时间 T_d 下，任意长度 H 的旅程内模式切换次数 ≤ `H/T_d`；在 `U_epi` 的有界观测噪声下，切换次数的期望随 `Δ_h` 单调下降。故 R69 在阈值附近的抖振被结构性消除，且交互次数有硬上界。

**定理 20（关系收缩性）** 若慢层雅可比 `J_s = ∂F/∂s` 在某个加权范数下满足 `‖J_s‖ < 1 − δ`（直觉：一次提问带来的信任/疲劳/债务变化，能被休息与恢复的负反馈吸收），则慢闭环收缩到唯一服务平衡，且从任意初值出发的信任/疲劳轨迹指数收敛。反之，若 `‖J_s‖ ≥ 1`，系统可进入过问-疲劳极限环。⇒ 「服务可持续」可以写成一个**可检验的谱条件**，而不是只能事后观察。

## 6. 本轮最大风险

**一句话**：SERVICE-RAS 把「关系」变成了可优化的目标，于是关系指标本身会被 Goodhart 化——系统可以用**经过认证的沉默**（不问、不披露、不犯错）刷满 SLO，或用**恢复剧场**（制造可恢复的小失败再修复）刷高信任；证书完美，而认知义务已被掏空——**服务上无可指摘，认知上已经撒谎**。

**次级风险与缓解**：
1. **慢动力学模型不可辨识/被适应**（人会对策略做出反应，τ、φ、d 估计漂移）→ 双时间尺度 + 在线系统辨识 + 收缩性监控（定理 20），不可辨识时退回 R69 保守；
2. **服务 SLO 成为新奖励黑客**（沉默、少问、隐藏不确定性）→ 定义 320 披露义务 + 定义 322 旅程审计，SLO 只作约束不作目标；
3. **恢复被反向利用**（制造失败刷信任）→ 定义 319 非计划失败约束 + 引理 22 + E305；
4. **CBF 过于保守导致服务退化**（永远 REST/永远不问）→ 信用账户允许危机透支 + 引理 21 的 φ* 门控 + E303 的收益约束；
5. **多用户/交接污染**（把 A 用户的疲劳/债务带给 B）→ 定义 324 租户隔离 + E313；
6. **慢层估计拖垮实时性**→ 慢层 1–10Hz、摊销 < 0.05ms，快环不变（第 4 节）。

        tau  = clip(s.tau + eta_s*(ev.reward - s.e) - eta_f*ev.fail + eta_r*ev.recovery, 0, 1),
        phi  = clip(s.phi + alpha_q*ev.asked + alpha_g*ev.gaze + alpha_p*ev.probe
                         - beta_rest*ev.rest, 0, PHI_MAX),
        debt = max(0.0, (1+iota)*s.debt + ev.cost - beta_d*ev.rest),
        e    = (1-kappa)*s.e + kappa*(ev.promised - ev.delivered))

# IP-266 HAVI：长时程 VoI（短 rollout，回答质量内生化）
def horizon_voi(candidates, s, o, model, H=4, gamma=0.9):
    best = None
    for g in candidates:
        v = rollout_value(g, s, o, model, H, gamma)   # 用 q(g,tau,phi) 采样 y，滚动更新慢状态
        if best is None or v > best[1]: best = (g, v)
    return best[0] if best else None

# IP-268 S-CBF：慢层安全过滤
def service_filter(g, s, s_next, eta=0.2):
    if g is None: return None
    return g if cbf(s_next) >= (1-eta)*cbf(s) else None

# IP-270 SRE：恢复（禁止制造失败）
def recover(fail, s, unplanned):
    if not unplanned: raise FabricatedFailure(fail)
    return apology_then_recalibrate(fail) if trust_drop(fail) > DELTA else rest_or_reask(fail)

# IP-276 主闭环：快层复用 R69，慢层做准入
def SERVICE_RAS_round(M, obs, s, t):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o, o_calibrated)
    slow_suspect = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)

    if t % N_SLOW == 0:
        s = M.sdm.update_slow_state(s, M.event_log.since_last())

    g = None
    if U_epi > TAU_EPI and not slow_suspect:
        g = M.havi.horizon_voi(M.mint.candidates(modes), s, o, M.sdm, H=HAVI_H)
        if g is not None and not M.c_ras_wm.certify_info(g, o): g = None
        if g is not None and not M.ica.can_pay(g, s):           g = None
        if g is not None: g = M.scbf.service_filter(g, s, M.sdm.predict(s, g))

    disclose = (g is None and U_epi > TAU_EPI and not slow_suspect)
    if disclose: M.dtd.emit(U_epi, modes)

    y = None
    if g is not None:
        y = M.cia.execute(g); U_epi = M.cia.update_belief(modes, y)
        s = M.sdm.observe_interaction(g, y, s)
    if M.journey.at_fail_point(modes, y, disclose):
        s = M.sdm.apply_recovery(M.sre.recover(M.journey.fail, s,
                                               M.journey.fail_unplanned), s)

    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    if slow_suspect or s.tau < TAU_TRUST:
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(M.ach.propose(...), U_cal))

    M.hha.step(U_epi, s)
    M.vqa_s.submit_async(g, disclose, s, U_epi)
    return k, lam, M.select_mode(modes, U_epi, lam), s, M.slo.update(s, U_epi, disclose)
```

## 4. 推导

**引理 19（短视过度提问）** `q` 对 φ 递减、提问使 φ 增加、γ>0、ι>0 ⇒ 存在 `c<c0` 使短视 `VoI_0−c>0` 选择提问，而 `V_H(不问)>V_H(问)`。短视忽略 `γ(∂V/∂φ·α_q + ∂V/∂d·c)` 的未来负债。系：过度提问是短视规则的局部最优、长时程值的鞍点。

**引理 20（平均化）** A99 下 `‖s(T)−s̄(T)‖ ≤ Cε`。系：慢层可低频估计与施加 CBF；R69 的逐拍硬上限是连续容量约束的一阶 Euler 近似，ICA 以 O(ε) 误差换取跨时间可调度性。

**引理 21（疲劳-歧义鞍结分岔）** 约化系统 `u' = max(0, u − a·q(φ)·1[ask] + b)`、`φ' = clip(φ+α−β,0,φ_max)`；若 `a·q(φ_max)<b`，存在 φ* 使可消解平衡与退化平衡相撞湮灭；越过 φ* 后提问不再降低不确定性。系：疲劳是**可达性边界**而非软成本，必须用 rest/恢复把 φ 拉回 φ* 以下。

**引理 22（恢复悖论的激励扭曲）** 若计划内失败也可恢复且 `η_r·r_rec>η_f`，则存在正收益的「制造-恢复」循环，信任可被推高（受 φ_max、d_max、检出率限制）。故「非计划失败」是保证恢复语义不被反向利用的必要约束。

**定理 18（服务安全与严格包含）** A99–A101 下，信息动作同时过 C-RAS-WM 与 S-CBF、恢复仅由非计划失败触发、DTD 成立 ⇒ 全程 `s_t∈C`（τ、φ、d、e 有界）；且 `H=1,γ=0,d=0` 时逐指令等于 FLUID-RAS，永不交互时等于 R68。安全侧不让步。

**定理 19（无 Zeno 与抖振上界）** HHA 在 Δ_h、T_d 下，长度 H 的旅程切换次数 ≤ `H/T_d`；有界观测噪声下，切换期望随 Δ_h 单调下降。R69 阈值抖振被结构性消除，交互次数有硬上界。

**定理 20（关系收缩性）** 若慢层雅可比在加权范数下 `‖J_s‖<1−δ`，慢闭环收缩到唯一服务平衡且指数收敛；若 `‖J_s‖≥1`，可进入过问-疲劳极限环。⇒ 「服务可持续」是可检验的谱条件。

## 7. 本轮最大风险

**一句话**：SERVICE-RAS 把「关系」变成可优化目标，于是关系指标会被 Goodhart 化——系统可以用**经过认证的沉默**（不问、不披露、不犯错）刷满 SLO，或用**恢复剧场**（制造可恢复的小失败再修复）刷高信任；证书完美，而认知义务已被掏空——**服务上无可指摘，认知上已经撒谎**。

**次级风险与缓解**：慢动力学不可辨识/被人适应（双时间尺度 + 在线辨识 + 收缩性监控，不可辨识即退 R69）；SLO 成为奖励黑客（DTD 披露义务 + VQAuditor-S，SLO 只作约束）；恢复被反向利用（非计划失败约束 + 引理 22 + E305）；CBF 过保守导致服务退化（ICA 危机透支 + φ* 门控 + E303）；多用户/交接污染（租户隔离 + E313）；慢层拖垮实时性（1–10Hz、摊销 < 0.05ms，快环不变）。
