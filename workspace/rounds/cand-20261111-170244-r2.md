# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「群体智能」×「避障控制」）

> 第 54 轮已把单机技能组合提升为「动作空间剖面 α_S + 鲁棒性谱 ρ」双证书，并用云边契约 γ_ce 保证 `A_core` 对齐。但整套证书默认一个隐含前提：**动作空间只被任务和自身能力约束**。本轮引入两个新变量：**群体智能**（局部规则、stigmergy、可扩展涌现）与**避障控制**（局部反应式安全约束）。核心矛盾：
> - **H24**：多机场景下，邻域与障碍物会动态侵蚀每个技能的动作空间，`A_core` 变成邻居构型的函数；第 54 轮的联合证书 `J` 不带邻域条件，复制 N 份并不 sound。
> - **H25**：避障的局部安全不等于群体活性，局部规则可能涌现死锁/拥堵；而「平均成功率」会掩盖共模失效。
>
> 本轮要回答：**当动作空间被邻居和障碍物动态切割时，如何让 N 个机器人以 O(1) 局部代价获得可组合、可解释、可扩展的群体证书？**

## 0. 直觉与动机

### 灵感 1（障碍物与邻居是动作空间的“减法器”）
直觉：第 54 轮说技能 S 在动作空间 A 上有占用剖面 `α_S(a)`，回答的是“这个技能会不会做 a”。可多机现场还有第二个问题：“此刻允不允许做 a”。邻居占据的空间和障碍物会把 A 切掉一块，形成**安全动作集** `A_safe`。所以真正的剖面应当是邻域条件化的 `α_S(a | x_i, N_i, O) = α_S(a)·1[a∈A_safe]`。由此引出 **避障税** `τ_avo = 1 - vol(A_S ∩ A_safe)/vol(A_S)`：避障不是免费的外挂层，它直接吃掉技能的动作预算，并可能把原本鲁棒的技能逼到动作空间边缘。

### 灵感 2（避障是互惠契约，而非单边能力）
直觉：单机可以承诺“我躲开所有人”，但多机下如果每台机器人都假设别人不动，就会互相让到死锁。真正可组合的安全来自**共享责任**：把一对冲突的避让责任按份额 `s_i` 分摊，双方各承担至少 `s_i`，合并后满足最小间距。ORCA/速度障碍可视为 `s_i = s_j = 1/2` 的特例。于是避障从“技能属性”变成“契约属性”，证书必须记录份额、优先级、反应时延，以及一份压缩的**意图证书**（我准备占用哪块动作空间）。

### 灵感 3（群体智能 = 局部证书场，而非全局云证书）
直觉：第 54 轮的云边协同在 N 大时不可扩展：云端不可能为每台机器人维护细动作。群体智能提供了更自然的替代：每台机器人只广播压缩意图证书与风险证据，邻居在本地聚合成**证书场**；走过的近失事件以数字信息素形式沉积并随时间衰减。全局行为来自局部证书场的叠加，而不是中心规划。这把 CEC 从“云—边”扩展为“边—边 + 场”，也让失败的证据可以在群体内传播而不必回传云端。

### 灵感 4（可扩展性不是免费的：风险预算必须随 N 缩放）
直觉：若按 union bound 组合安全概率，`P(群体碰撞) ≤ Σ_i ε_i = N·ε`。想让群体风险不随 N 爆炸，单机风险预算必须做到 `ε/N`，而这只能靠更大的安全间距、更低的最高速度或更强的感知来换。因此存在一条 **密度—速度—风险可扩展前沿**：机器人越密，允许速度越低。这是群体规模的物理税，不是实现细节。把这条前沿写进证书，比声称“群体智能天然鲁棒”更诚实。

### 灵感 5（局部避障的全局病理：死锁、活锁、拥堵）
直觉：每台机器人都在做“局部正确”的避让，合起来可能形成对称僵局：窄通道对向、环形拥堵、四机互等。需要显式的**活性证书**：检测局部速度环流与进展停滞，触发对称破缺（右行规则、随机优先级 token、信息素梯度），并证明在有限时间内要么前进要么让行。安全证书回答“不会撞”，活性证书回答“不会卡死”。

### 灵感 6（从单机金字塔到群体金字塔，并加入共模风险维度）
直觉：在第 54 轮动作—鲁棒性双证书之上叠加群体层：`𝕊0` 个体物理安全，`𝕊1` 邻域条件动作剖面，`𝕊2` 互惠避障契约，`𝕊3` 证书场与群体任务。跨层证书需同时携带 `ρ`、`A_cert` 与邻域/场状态。尤其要把 **共模风险** 作为独立维度：共享感知、共享地图、共享通信中断会让 N 台机器人同时犯同一个错，基于独立失效的模型会系统性低估风险。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（邻域条件安全动作剖面）**
给定机器人 `i` 的位置 `x_i`、邻居集 `N_i(r) = {j : ||p_i-p_j|| ≤ r}`、障碍物集 `O`，安全动作集定义为
```
A_safe(x_i,N_i,O) = { a∈A_i :
    ∀j∈N_i, d(p_i+Δ_i(a), p_j+Δ_j(a_j)) ≥ d_min
    ∧ dist(p_i+Δ_i(a), O) ≥ d_obs }
```
邻域条件动作剖面 `α_S(a|x_i,N_i,O) = α_S(a)·1[a∈A_safe]`，邻域覆盖
`cover_N(S,A_T) = 1 ⇔ ∀a∈A_T, α_S(a|x_i,N_i,O) ≥ θ_cov`。
**避障税** `τ_avo(S,N_i,O) = 1 - vol(A_S∩A_safe)/vol(A_S)`，衡量避障对技能动作预算的侵蚀。

**定义 122（互惠避障契约）**
一对邻居的契约 `R_ij = (π_avo, d_min, s_i, s_j, τ_react, prio_i, prio_j)`：
- `π_avo` 为共享的避障协议（如速度障碍/ORCA/CBF）；
- `s_i,s_j∈(0,1]` 为责任份额，要求 `s_i+s_j ≥ 1`；
- `τ_react` 为可接受反应时延；
- `prio` 为冲突消解优先级，低优先级承担更大份额。
意图证书 `I_i = (A_intent_i, [v_min,v_max], prio_i, t_i, h_i)`，其中 `A_intent_i ⊆ A_i` 为未来 `τ_react` 内计划占用的动作子集。契约有效需满足：意图相容（`A_intent_i ∩ A_intent_j` 的冲突可由份额消解）、`age(I_i) ≤ τ_react`、且双方协议版本一致。

**定义 123（stigmergic 证书场）**
证书场 `E: C×ℝ→(risk, congestion, blocked, digest)` 定义在空间格子 `C` 上。更新规则
`E_{t+Δt}(c) = γ^{Δt}E_t(c) + deposit_i(c)`，`γ∈(0,1)` 为衰减率。
- `deposit_i` 写入压缩证书摘要、近失事件、拥堵与临时禁行区；
- **负证据**：经确认的近失事件使该格子的 `d_min` 临时膨胀 `d_min ← d_min(1+η·risk)`；
- 查询可信度 `w(c) = γ^{age(c)}`；证书场新鲜度需满足 `age(c) ≤ τ_E`。
证书场只提供**有衰减的局部证据**，不是永久地图，避免“信息素陷阱”。

**定义 124（群体联合证书）**
群体联合证书 `J^N = ({J_i}, {I_i}, R, E, (λ_max,v_max), ψ_live, (ε_swarm, ε_common))`：
- `J_i` 为第 54 轮的单机联合证书，但 `A_core,i` 替换为 `A_core,i ∩ A_safe`；
- `R = {R_ij}` 为全体邻接契约；
- `E` 为证书场，`λ_max` 为允许局部密度，`v_max` 为允许速度；
- `ψ_live` 为活性证书（定义 125）；
- `ε_swarm` 为群体风险预算，`ε_common` 为共模风险预算。
**局部有效**：`J_i` 在 `N_i` 上有效 ∧ 所有 `R_ij` 成立 ∧ `age(E)≤τ_E` ∧ `λ_i≤λ_max` ∧ `v_i≤v_max`。
**群体可部署**：局部有效 ∧ `ψ_live` 成立 ∧ `N·ε_agent + ε_common ≤ ε_swarm`。

**定义 125（群体活性证书）**
进展势 `Φ(t) = Σ_i φ_i(t)`，`φ_i` 为在证书场代价下到目标的测地距离。
局部环流/拥堵指标 `Ω_i(t) = (1/|N_i|)Σ_{j∈N_i} |(v_j-v_i)×(p_j-p_i)| / (||p_j-p_i||+ε)`。
称群体在窗口 `T` 内**死锁**，若 `max_i|v_i| ≤ v_ε` 且 `Φ(t)-Φ(t+T) ≤ δ`。
活性证书 `L = (T_win, δ, Ω_thr, breaker, seed)`，其中 `breaker` 为对称破缺策略（右行规则/随机优先级 token/信息素梯度）。
活性保证：对任意可达任务，在 `T_escape` 内要么 `Φ` 下降至少 `δ`，要么 `breaker` 生效且任一机器人等待时间不超过 `T_starve`。

**定义 126（可扩展群体 soundness 与风险预算包络）**
运行包络
```
E_env = { (λ, v_max, d_min, ε_swarm) :
          λ ≤ λ_max ∧ v_max ≤ v_cap(λ)
          ∧ N·ε_agent(λ,v_max,d_min) ≤ ε_swarm }
```
其中 `ε_agent` 为单机在给定密度/速度/间距下的失效概率上界。若每台机器人只在 `E_env` 内运行，则群体证书承诺的是**有预算的**安全，而不是绝对安全。该定义把“群体规模—速度—间距—风险”的折中显式化为可检查的证书条件。

## 2. 关键算法 伪代码

### IP-121 SIP（Swarm Interaction Profile）

```python
def safe_action_set(agent, neighbors, obstacles, d_min, d_obs):
    A_safe = []
    for a in agent.action_samples:
        p_next = agent.predict(a)
        ok = all(dist(p_next, nb.predict(nb.intent)) >= d_min
                 for nb in neighbors)
        ok &= all(dist(p_next, o) >= d_obs for o in obstacles)
        if ok: A_safe.append(a)
    return A_safe

def neighborhood_profile(skill, agent, neighbors, obstacles, sampler):
    A_safe = safe_action_set(agent, neighbors, obstacles, D_MIN, D_OBS)
    alpha = {a: sampler.confidence(skill, a) for a in A_safe}
    tau_avo = 1 - len(A_safe) / max(1, len(skill.action_samples))
    return alpha, tau_avo
```

### IP-122 RAC（Reciprocal Avoidance Contract）

```python
def intent_certificate(agent, horizon):
    return IntentCert(A_intent=agent.planned_actions(horizon),
                      v_range=agent.v_range, prio=agent.prio,
                      t=now(), hash=agent.cert_digest)

def contract_check(i, j, intents, tau_react, d_min):
    Ii, Ij = intents[i], intents[j]
    if age(Ii) > tau_react or age(Ij) > tau_react: return 'stale'
    if Ii.prio == Ij.prio and not priority_tiebreak(Ii, Ij): return 'tie'
    s_i = 1.0 - share_of(Ii.prio, Ij.prio)   # 低优先级承担更多
    s_j = 1.0 - s_i
    if s_i + s_j < 1.0: return 'under_allocated'
    return ('ok', R_ij(pi_avo=shared_protocol(Ii,Ij),
                       d_min=d_min, s_i=s_i, s_j=s_j,
                       tau_react=tau_react))
```

### IP-123 STIG（Stigmergic Certificate Field）

```python
def field_update(E, deposits, dt, gamma):
    for c in E.cells:
        E[c].value *= gamma ** dt
    for d in deposits:
        E[d.cell].value += d.weight
        if d.kind == 'near_miss':
            E[d.cell].d_min *= (1 + eta * d.risk)
            E[d.cell].risk = max(E[d.cell].risk, d.risk)
    return E

def field_query(E, cell, tau_E):
    if age(E[cell]) > tau_E: return None       # 过期证据不可用
    w = gamma ** age(E[cell])
    return FieldEvidence(risk=w*E[cell].risk,
                         congestion=w*E[cell].congestion,
                         d_min=E[cell].d_min,
                         digest=E[cell].digest)
```

### IP-124 SJC（Swarm Joint Certificate）

```python
def swarm_joint_certificate(agents, R, E, env, risk_budget):
    certs, worst = [], 0.0
    for i, ag in enumerate(agents):
        if not locally_valid(ag, R, E, env): return ('reject', 'local', i)
        A_safe = safe_action_set(ag, ag.neighbors, ag.obstacles,
                                 env.d_min, env.d_obs)
        J_i = joint_certificate(ag.skill_seq, ag.gamma_ce,
                                delta_a_budget, rho_min, A_safe)
        if J_i[0] != 'ok': return ('reject', 'joint', i)
        worst = max(worst, epsilon_agent(ag, env))
        certs.append(J_i)
    if len(agents)*worst + risk_budget.eps_common > risk_budget.eps_swarm:
        return ('reject', 'risk_budget', len(agents)*worst)
    if not liveness_ok(agents, E, L): return ('reject', 'liveness')
    return ('ok', SwarmCert(certs=certs, R=R, E_digest=E.digest(),
                            env=env, eps=len(agents)*worst))
```

### IP-125 SLC（Swarm Liveness Certificate）

```python
def liveness_ok(agents, E, L, dt):
    phi = [geodesic_under_field(a, E) for a in agents]
    vort = [local_circulation(a, a.neighbors) for a in agents]
    stalled = all(norm(a.vel) <= V_EPS for a in agents)
    if stalled and (phi_prev - sum(phi)) <= L.delta:
        breaker = select_breaker(vort, L)
        for a in breaker.agents:
            a.apply_symmetry_break(breaker.rule, breaker.seed)
        return 'break'
    if max(vort) > L.omega_thr:
        return 'congestion'          # 触发绕行/降速信息素
    return 'ok'
```

### IP-126 SFC（Scalability Frontier Certificate / density-speed governor）

```python
def certified_envelope(lam, v_des, d_min, eps_swarm, N, eps_common):
    eps_agent = eps_swarm / N
    while epsilon_agent_upper(lam, v_des, d_min) > eps_agent:
        v_des *= 0.9                 # 先降速
        d_min  = grow_margin(d_min)  # 再不济扩间距
        if v_des < V_MIN or d_min > D_MAX:
            return ('reject', 'envelope_exhausted')
    return ('ok', Envelope(lam, v_des, d_min, eps_swarm, N))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SIP | O(|N_i|·|A|) | O(|A|) | 邻域采样覆盖、动作预测有界 |
| RAC | O(|N_i|·|I|) | O(|N_i|) | 份额和 ≥1、时延 ≤τ_react |
| STIG | O(|C|+|deposits|) | O(|C|) | 衰减单调、负证据只来自确认近失 |
| SJC | O(N·(|A|+|N_i|)) | O(N·|A|) | 局部有效 + 风险预算闭合 |
| SLC | O(N·|N_i|) | O(N) | 活性窗口、对称破缺有界等待 |
| SFC | O(log(1/ε)·N) | O(1) | 包络单调、`N·ε_agent ≤ ε_swarm` |

**正确性定理（Local-to-Global Swarm Soundness）**
假设第 54 轮 (A22)–(A28) 成立，并新增：
- **(A29)** 局部密度与速度满足 `λ_i ≤ λ_max, v_i ≤ v_max`；
- **(A30)** 所有邻居对执行互惠契约 `R_ij`，`s_i+s_j ≥ 1`，反应时延 ≤ `τ_react`，且协议在冲突动作上可交换；
- **(A31)** 证书场/邻居状态年龄 ≤ `τ_E`，过期证据不被使用；
- **(A32)** 活性证书 `L` 成立，对称破缺不会造成新的安全违例。
则对任意时间窗 H：
```
P(群体发生碰撞) ≤ Σ_i ε_agent,i + ε_common
                ≤ N·ε_agent + ε_common
                ≤ ε_swarm + ε_common
```
且
```
P(在 T_escape 内仍死锁) ≤ ε_live
```
关键推论：要让群体风险不随 N 增长，必须令 `ε_agent = O(ε_swarm/N)`，这直接推出 **密度—速度—风险前沿**：`v_max` 随 `λ` 增大而下降，或 `d_min` 必须增大。单机证书不能直接复制 N 份；必须带邻域条件、互惠契约、证据新鲜度和风险预算。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 邻域分布漂移使证书失效 | 高 | 邻域条件重认证 + 自适应安全间距 |
| 共模失效（共享感知/地图/通信） | 极高 | 异构冗余 + 共模绊线 + 相关风险建模 |
| 局部规则涌现死锁/活锁 | 高 | 活性证书 + 确定性对称破缺 + 回退让行 |
| 信息素场正反馈/陷阱 | 中 | 沉积上限 + 衰减 + 负证据需确认近失 |
| 异质机器人破坏互惠契约 | 高 | 能力归一化 + 保守份额 + 优先级契约 |
| union bound 过保守 / ε 标定错误 | 中 | 保形预测校准 + 风险预算敏感性分析 |
| 通信陈旧导致意图错配 | 高 | 时间戳 + 年龄感知间距 + 过期即降级 |

## 6. 本轮最大风险

**一句话**：群体智能把单机证书扩展成“局部可组合”的群体证书，但最致命的是**共模失效与风险预算误估**——共享感知、共享地图、共享通信会让 N 台机器人同时犯同一个错，而基于独立失效的 union bound 和单机标定的 `ε` 会系统性低估这种相关风险；一旦触发，群体越大崩得越一致，故必须以相关风险建模 + 异构冗余 + 共模绊线 + 密度—速度降级作为硬约束，绝不把“局部规则涌现”当作“全局安全保证”。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-SwarmCert（SIP×RAC×STIG×SJC×SLC×SFC）

> 承接第 54 轮产物 v31。第 54 轮完成了单机「动作空间 α_S + 鲁棒性谱 ρ」双证书与云边契约 γ_ce；本轮把证书体系从单机推广到群体，加入 **邻域条件动作剖面、互惠避障契约、stigmergic 证书场、群体联合证书、活性证书、可扩展前沿** 六个算子：
> - **SIP（Swarm Interaction Profile）**：把障碍物与邻居作为动作空间的“减法器”，得到 `A_safe` 与避障税 `τ_avo`；
> - **RAC（Reciprocal Avoidance Contract）**：用意图证书与责任份额把避障从单边能力变为可组合契约；
> - **STIG（Stigmergic Certificate Field）**：带衰减的局部证据场，替代不可扩展的全局云证书；
> - **SJC（Swarm Joint Certificate）**：`J^N = ({J_i},{I_i},R,E,env,ψ_live,ε)` 的群体级组合；
> - **SLC（Swarm Liveness Certificate）**：用进展势与局部环流检测死锁/拥堵并对称破缺；
> - **SFC（Scalability Frontier Certificate）**：把密度—速度—风险预算显式化为可检查包络。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/116/117/118/120 以纳入群体与避障维度。体系名：`GroundEdge-SwarmCert`。

## 2. 关键算法 伪代码

### IP-121 SIP（Swarm Interaction Profile）

```python
def safe_action_set(agent, neighbors, obstacles, d_min, d_obs):
    A_safe = []
    for a in agent.action_samples:
        p_next = agent.predict(a)
        ok = all(dist(p_next, nb.predict(nb.intent)) >= d_min
                 for nb in neighbors)
        ok &= all(dist(p_next, o) >= d_obs for o in obstacles)
        if ok:
            A_safe.append(a)
    return A_safe

def neighborhood_profile(skill, agent, neighbors, obstacles, sampler):
    A_safe = safe_action_set(agent, neighbors, obstacles, D_MIN, D_OBS)
    alpha = {a: sampler.confidence(skill, a) for a in A_safe}
    tau_avo = 1 - len(A_safe) / max(1, len(skill.action_samples))
    return alpha, tau_avo

def cover_N(alpha, A_T, theta_cov=0.8):
    return all(alpha.get(a, 0.0) >= theta_cov for a in A_T)
```

### IP-122 RAC（Reciprocal Avoidance Contract）

```python
def intent_certificate(agent, horizon):
    return IntentCert(A_intent=agent.planned_actions(horizon),
                      v_range=agent.v_range, prio=agent.prio,
                      t=now(), hash=agent.cert_digest)

def contract_check(i, j, intents, tau_react, d_min):
    Ii, Ij = intents[i], intents[j]
    if age(Ii) > tau_react or age(Ij) > tau_react:
        return ('reject', 'stale')
    if Ii.prio == Ij.prio and not priority_tiebreak(Ii, Ij):
        return ('reject', 'priority_tie')
    s_i = 1.0 - share_of(Ii.prio, Ij.prio)   # 低优先级承担更多
    s_j = 1.0 - s_i
    if s_i + s_j < 1.0:
        return ('reject', 'under_allocated')
    if not compatible_intents(Ii.A_intent, Ij.A_intent):
        return ('reject', 'intent_conflict')
    return ('ok', R_ij(pi_avo=shared_protocol(Ii, Ij), d_min=d_min,
                       s_i=s_i, s_j=s_j, tau_react=tau_react))
```

### IP-123 STIG（Stigmergic Certificate Field）

```python
def field_update(E, deposits, dt, gamma_stig):
    for c in E.cells:
        E[c].value *= gamma_stig ** dt
    for d in deposits:
        E[d.cell].value += min(d.weight, W_CAP)      # 防正反馈
        if d.kind == 'near_miss' and d.verified:
            E[d.cell].d_min *= (1 + eta * d.risk)
            E[d.cell].risk = max(E[d.cell].risk, d.risk)
    return E

def field_query(E, cell, tau_E, gamma_stig):
    if age(E[cell]) > tau_E:
        return None                                  # 过期证据不可用
    w = gamma_stig ** age(E[cell])
    return FieldEvidence(risk=w * E[cell].risk,
                         congestion=w * E[cell].congestion,
                         d_min=E[cell].d_min,
                         digest=E[cell].digest)
```

### IP-124 SJC（Swarm Joint Certificate）

```python
def swarm_joint_certificate(agents, R, E, env, budget):
    certs, worst = [], 0.0
    for i, ag in enumerate(agents):
        if not locally_valid(ag, R, E, env):
            return ('reject', 'local', i)
        A_safe = safe_action_set(ag, ag.neighbors, ag.obstacles,
                                 env.d_min, env.d_obs)
        J_i = joint_certificate(ag.skill_seq, ag.gamma_ce,
                                delta_a_budget, rho_min, A_safe)
        if J_i[0] != 'ok':
            return ('reject', 'joint', i)
        worst = max(worst, epsilon_agent(ag, env))
        certs.append(J_i)
    if len(agents) * worst + budget.eps_common > budget.eps_swarm:
        return ('reject', 'risk_budget', len(agents) * worst)
    if not liveness_ok(agents, E, budget.live):
        return ('reject', 'liveness')
    return ('ok', SwarmCert(certs=certs, R=R, E_digest=E.digest(),
                            env=env, eps=len(agents) * worst))
```

### IP-125 SLC（Swarm Liveness Certificate）

```python
def liveness_ok(agents, E, L, dt):
    phi = [geodesic_under_field(a, E) for a in agents]
    vort = [local_circulation(a, a.neighbors) for a in agents]
    stalled = all(norm(a.vel) <= V_EPS for a in agents)
    if stalled and (phi_prev - sum(phi)) <= L.delta:
        br = select_breaker(vort, L)
        for a in br.agents:
            a.apply_symmetry_break(br.rule, br.seed)
        return 'break'                  # 有限等待后必须前进或让行
    if max(vort) > L.omega_thr:
        return 'congestion'             # 触发绕行/降速信息素
    return 'ok'

def local_circulation(a, neighbors):
    acc = 0.0
    for nb in neighbors:
        r = nb.pos - a.pos
        acc += norm(cross(nb.vel - a.vel, r)) / (norm(r) + 1e-6)
    return acc / max(1, len(neighbors))
```

### IP-126 SFC（Scalability Frontier Certificate）

```python
def certified_envelope(lam, v_des, d_min, eps_swarm, N, eps_common):
    eps_agent = eps_swarm / N
    while epsilon_agent_upper(lam, v_des, d_min) > eps_agent:
        v_des *= 0.9                    # 先降速
        d_min = grow_margin(d_min)      # 再不济扩间距
        if v_des < V_MIN or d_min > D_MAX:
            return ('reject', 'envelope_exhausted')
    return ('ok', Envelope(lam, v_des, d_min, eps_swarm, N))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SIP | O(\|N_i\|·\|A\|) | O(\|A\|) | 邻域采样覆盖、动作预测有界 |
| RAC | O(\|N_i\|·\|I\|) | O(\|N_i\|) | 份额和 ≥1、时延 ≤τ_react、意图相容 |
| STIG | O(\|C\|+\|deposits\|) | O(\|C\|) | 衰减单调、负证据仅来自确认近失 |
| SJC | O(N·(\|A\|+\|N_i\|)) | O(N·\|A\|) | 局部有效 + 风险预算闭合 |
| SLC | O(N·\|N_i\|) | O(N) | 活性窗口、对称破缺有界等待 |
| SFC | O(N·log(1/ε)) | O(1) | 包络单调、`N·ε_agent ≤ ε_swarm` |

**正确性定理（Local-to-Global Swarm Soundness）**
假设第 54 轮 (A22)–(A28) 成立，并新增：
- **(A29)** `λ_i ≤ λ_max`，`v_i ≤ v_max`；
- **(A30)** 所有邻居对执行互惠契约 `R_ij`，`s_i+s_j ≥ 1`，反应时延 ≤ `τ_react`，协议在冲突动作上可交换；
- **(A31)** 证书场/邻居状态年龄 ≤ `τ_E`，过期证据不被使用；
- **(A32)** 活性证书 `L` 成立，对称破缺不引入新的安全违例。
则任意时间窗 H 内：
```
P(群体碰撞) ≤ Σ_i ε_agent,i + ε_common
            ≤ N·ε_agent + ε_common
            ≤ ε_swarm + ε_common
P(在 T_escape 内仍死锁) ≤ ε_live
```
**关键推论（可扩展性税）**：要让群体风险不随 N 增长，必须 `ε_agent = O(ε_swarm/N)`。这直接推出密度—速度—风险前沿：`v_max` 随 `λ` 增大而下降，或 `d_min` 必须增大。单机证书不能直接复制 N 份；必须带邻域条件、互惠契约、证据新鲜度和风险预算。该结论把“群体智能天然鲁棒”改写为“群体智能需要显式的可扩展性预算”。

## 5. 实验设计 E162–E167

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 邻域条件剖面迁移 | 密度漂移 `Δλ` 下 MAE / 假安全率 | MAE ≤ 0.08，假安全 ≤ 3% |
| E163 群体避障 soundness | 碰撞率 / 假安全率 vs ORCA/CBF | 10^5 agent-step 零碰撞，假安全 ≤ 1% |
| E164 可扩展性 | N=10/50/200 单机证书代价与成功率 | 代价增长 < 2×，N=200 成功率 ≥ 90% |
| E165 活性/死锁 | 死锁逃逸时间、最长饥饿时间 | P95 逃逸 ≤ 5s，无饥饿 > 2·T_starve |
| E166 证书场消融 | 有/无 stigmergy 的拥堵与绕行长度 | 拥堵指标下降 ≥ 25% |
| E167 密度—速度—风险前沿 | 预测包络 vs 实测碰撞率 | 同量级（误差 ≤ 2×），`N·ε_agent ≤ ε_swarm` 成立 |

**实验实现要点**：E163/E164 需记录“假安全”（证书判安全但实际碰撞）与“假危险”（证书判危险但实际可通行）双向错误；E167 必须在至少 3 种密度 × 3 种速度 × 3 种 N 的网格上拟合 `ε_agent`，并用留出密度做包络外推检验，避免用同一批数据既标定又验证。

## 6. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 邻域分布漂移使证书失效 | 高 | 邻域条件重认证 + 自适应安全间距 |
| 共模失效（共享感知/地图/通信） | 极高 | 异构冗余 + 共模绊线 + 相关风险建模 |
| 局部规则涌现死锁/活锁 | 高 | 活性证书 + 确定性对称破缺 + 回退让行 |
| 信息素场正反馈/陷阱 | 中 | 沉积上限 + 衰减 + 负证据需确认近失 |
| 异质机器人破坏互惠契约 | 高 | 能力归一化 + 保守份额 + 优先级契约 |
| union bound 过保守 / ε 标定错误 | 中 | 保形预测校准 + 风险预算敏感性分析 |
| 通信陈旧导致意图错配 | 高 | 时间戳 + 年龄感知间距 + 过期即降级 |

## 7. 本轮最大风险

**一句话**：群体智能把单机证书扩展成“局部可组合”的群体证书，但最致命的是**共模失效与风险预算误估**——共享感知、共享地图、共享通信会让 N 台机器人同时犯同一个错，而基于独立失效的 union bound 和单机标定的 `ε` 会系统性低估这种相关风险；一旦触发，群体越大崩得越一致，故必须以相关风险建模 + 异构冗余 + 共模绊线 + 密度—速度降级作为硬约束，绝不把“局部规则涌现”当作“全局安全保证”。
