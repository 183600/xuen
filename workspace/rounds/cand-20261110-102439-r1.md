# 第 43 轮（新循环第 3 轮） · 具身时序证书 ELC：把「延迟」从预算资源升级为安全变量，用身体动力学充作算力缓冲（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR）。第 42 轮自陈最大风险是「仿真偏差累积 + 检索幻觉导致静默失效」，并用 E79/E82 做红线。本轮灵感词「具身智能」「低延迟推理」没有继续追问「仿真像不像」，而是戳中 v19 一个更基础的盲点：**v19 的证书全是状态空间里的对象，时间维度没有被认证**。ECR 把延迟当作「预算/WCET」去压缩（L0 5μs、L1 100μs），LCS 把延迟当作「算力档位」去分配；但具身系统的动作永远由**过期状态**算出、再**延迟施加**，一个在空间上完全 sound 的证书，仍可能因为「算的时候还安全、执行的时候已经撞上边界」而失效。具身智能给出新资源：**身体不是被动 plant，而是可被证书利用的「时间缓冲」**——关节柔顺、阻尼、低重心、接触稳定域能在控制器掉线时物理地维持安全 T_body；低延迟推理给出新对象：**延迟不是要最小化的成本，而是必须进入证书、并被调度对齐到 time-to-unsafe 的安全变量**。于是 v20 给证书加上第三根轴：时间。证书从「这个状态安全吗」升级为「这个状态还能安全多久、我有多久可以算、算不完时身体能替我撑多久」。

## 0. 直觉与动机

**灵感 1（具身智能 → 身体是免费的算力缓冲，而非待控对象）**：v19 的 ECR 默认「算得越久越危险」，因此把 L1 压到 100μs、把 L0 压到 5μs。但具身智能的核心直觉恰恰相反：**形态与被动动力学本身在计算**（morphological computation）。一条带阻尼的串联弹性关节、一个低重心移动底盘、一只处于稳定接触中的手，在控制器「卡住」的几百毫秒里并不会立刻失控——它有自己的安全保持时间 T_body。于是「安全约束」不该写成 `L_infer ≤ 100μs`，而该写成 `L_infer ≤ τ(x) − T_hold`，并且当算力不够时，**可以合法地把差额记在身体的账上**：先切被动/阻抗模式让身体滑行，用 T_body 换一段额外计算时间。这把「低延迟」从「拼命压缩推理」变成「以 time-to-unsafe 为截止期、按需购买推理」，是具身系统独有的优化自由度。

**灵感 2（低延迟推理 → 证书驱动的 just-in-time 推理，而非固定档位）**：v19 的 LCS 档位是「按状态选最小充分档 j*(x)」，但选的依据只有空间边际 m_lo，没有时间。若某状态 m_lo 很高但仍以高速逼近边界，τ 很短，反而需要**更快**的档；若某状态 m_lo 一般但身体有很长的被动保持，τ 很长，反而可以**多算**、调用更大模型换更高质量动作。正确的选择规则应是：在小模型到大模型的阶梯 π_0…π_K 上，找**满足「余量能覆盖自身延迟」的最小档**：`j* = min{ j : m_j(x) − β(x)·l_j ≥ θ }`，其中 β 是边际衰减率上界。算不完就沿阶梯降级，降到不能再降就切被动缓冲，再不行才 SafeStop。这不是「更快的推理」，而是「**推理速度与物理紧迫度对齐**」的 anytime 控制。

**灵感 3（耦合 → 时序证书 + 延迟调度 + 被动缓冲三件套）**：三者缺一不可。只有 τ 没有 T_body，系统会在算力不足时过早 SafeStop；只有 T_body 没有 τ，会把身体缓冲浪费在无意义的大模型上；只有 JIT 没有时间证书，则「省下的延迟」无法证明安全。三者合成 **ELC（时序认证）→ AIS（延迟调度）→ EBE（身体缓冲利用）** 的运行时闭环，并把「延迟尖峰 + 低余量」作为一类新的**时序反例**写回 CKB：飞轮不只追分布漂移，还追**时间漂移**（p99 延迟漂移、驱动抖动、总线拥塞）。

**与前轮的耦合升级**：v19 的 Sim→RAG→Edge→Sim 解决「证书内容对不对」；本轮解决「证书在时间上还成不成立」。SCV 增加延迟/抖动/丢帧的域随机化，CKB 增加「时序剖面 + 时序反例」，ECR 增加 T-2 被动层与 EDF 调度器，CAR 的守卫增加「延迟鲁棒」修正，LCS 的预算从「固定 μs」改为「动态截止期 τ−T_hold」。

## 1. 形式化定义（增量：定义 38–43）

**定义 38（端到端具身延迟向量）**：L(x) = L_sense + L_infer(x) + L_comm + L_act，四项均为随机变量；记其 WCET 上界为 L_wc，p99 为 L_p99，抖动 J = L_wc − L_p99。L_infer(x) 依赖所选模型档 j 与是否 early-exit，因此 L 与策略选择耦合。**关键约定**：进入证书的必须是 L_wc（最坏情形），p99 只用于性能评估，不能用于安全放行。

**定义 39（安全剩余时间 time-to-unsafe，τ）**：τ(x, u_fb) = inf{ t ≥ 0 : x(t) ∉ S_safe }，其中 x(t) 在扰动与回退策略 u_fb（制动/阻尼/零力矩）下演化；若在 S_safe 内永不越界则 τ = ∞。工程下界由边际衰减给出：令 β(x) = L_m·v_max(x) + b（b 为输入/扰动对边际的贡献率），则 **τ(x) ≥ m_lo(x) / β(x) =: τ_lo(x)**；也可用制动距离下界 τ_brake = v/a_brake 取更紧者。

**定义 40（时序证书 temporal certificate）**：C_τ(x) 成立当且仅当
`τ_lo(x) ≥ L_wc + T_hold + ε_j`，
其中 T_hold 是 CAR 保持时间、ε_j 是档位 j 的数值/插值余量。定义**时序边际** `m_τ(x) = τ_lo(x) − L_wc − T_hold`。v19 的空间证书是 m_τ = ∞ 的特例；v20 要求每个安全决策同时满足 `m_lo ≥ θ` 与 `m_τ ≥ 0`。

**定义 41（具身被动缓冲 T_body）**：T_body(x) = sup{ t : 在保持最后安全指令或切零力矩/纯阻尼后，x(t) ∈ S_safe }。用能量法给下界：若被动系统能量 E(x) ≤ E_safe 且耗散率 ≥ λ_min，则 `T_body(x) ≥ (1/λ_min)·ln(E_safe/E(x))`；移动底盘可用 `T_body ≥ v_stop/a_damp`。T_body 是**只在当前状态已验证安全、且能证明被动流不越界时**才能兑现的「信用额度」，不是无条件豁免。

**定义 42（anytime 推理阶梯与 JIT 选择）**：阶梯 Π = {π_0,…,π_K}，每档给出认证延迟 l_j（WCET）与空间边际保证 m_j(x)（来自 IP-52 LCS / IP-53 CMC）。**JIT 选择**：
`j*(x) = min{ j : m_j(x) − β(x)·l_j ≥ θ }`；
若无解，则 j* = ⊥，转入被动缓冲或 SafeStop。**命题（按构造成立）**：j* 是满足「延迟后仍安全」的最小延迟档；任何 j < j* 都不满足时序充分条件。

**定义 43（证书门控的推测执行 speculation gating）**：快路径 π_f 给出安全动作与廉价验证器 V_0（延迟 l_v）；慢模型 π_s 给出候选动作 u_s（延迟 l_s）。仅当以下三条同时成立才提交 u_s：
(a) `l_s + l_v ≤ τ_lo(x) − T_hold`；
(b) `m_{u_s}(x) ≥ θ + β(x)·(l_s + l_v)`（用提交时刻的状态预测播延迟衰减）；
(c) V_0(u_s) = PASS。
否则丢弃 u_s，执行快路径安全动作。**定理 5（时序充分性）**：若 m(x) ≥ θ + β·L_wc 且 T_body(x) ≥ L_wc，则任意 L ≤ L_wc 的延迟执行都不会在 [t, t+L+T_hold] 内离开 S_safe；若延迟超过 L_wc 但 ≤ T_body，切被动模式仍安全。证明由 β 的边际衰减界与 T_body 定义直接得到。

## 2. 三大产出设计（增量 IP-57/58/59 + 升级 IP-45/49/50/51/52/53/54/55/56）

### 2.1 IP-57 EMBODIED-LATENCY-CERTIFIER（ELC，具身时序认证器）
1. **延迟测量学**：硬件时间戳打点（曝光→驱动→推理→总线→执行器），按档位维护 WCET/p99/抖动直方图；区分「可认证的 WCET」与「仅供优化的 p99」。
2. **τ 下界估计**：由 IP-49 的 m_lo、L_m、v_max 与制动能力算 τ_lo；对接触/非光滑段用保守分段常数 β；输出 τ_lo 的置信下界。
3. **T_body 估计**：仿真扫被动轨迹标定 λ_min/E_safe；实机用小幅激励在线校正；输出 `{T_body, 适用条件(接触态/速度域)}`，条件不满足即视为 0。
4. **时序风险归因**：延迟尖峰导致 m_τ 跌破 0 时，记录 `(x, 档位, 延迟分解, 触发原因)` 作为时序反例入 CKB。

### 2.2 IP-58 ANYTIME-INFERENCE-SCHEDULER（AIS，延迟调度器）
1. **JIT 阶梯选择**：按定义 42 选 j*；每拍重算，避免用过期 τ。
2. **EDF 实时调度**：把每个待执行推理任务视作截止期为 `D = m_eff/β` 的任务，最早截止期优先；单批次大小固定为 1，禁止为吞吐牺牲确定性。
3. **证书门控推测**：快路径先出安全动作并立即锁存；慢路径只在定义 43 三条件下被允许提交，提交前必须过 V_0。
4. **降级阶梯**：`JIT 降档 → 被动/阻抗滑行 → 定点保守动作 → SafeStop`；每次降级写总线事件，供第 42 轮飞轮做时序漂移统计。

### 2.3 IP-59 EMBODIED-BUFFER-EXPLOITER（EBE，身体缓冲利用器）
1. **被动安全模式**：零力矩/纯阻尼/阻抗保持三选一，按接触态切换；切换本身有 WCET 预算并计入 L_act。
2. **compute-while-coasting**：当 `L_wc > τ_lo − T_hold` 但 `L_wc ≤ T_body` 时，允许先切被动模式再算，用 T_body 换取额外算力；期间以能量/速度监控作为硬看门狗。
3. **额度记账**：T_body 不是白给的，每次兑现都扣减安全裕度；连续兑现超过冷却期必须回到主动模式重新认证，防止「身体信用」被耗尽。

## 3. 四层架构 v8

```
L1: TRI-FUSE(定点) + IP-49 LIO → C_ms + 漂移界 B_t + L_m/v_max/β
L2: CTC + VLM + IP-35 仲裁 → R_φ(w) + 几何残差证书 → CKB 指纹 (φ, ψ, ψ_time)
L3: IP-57 ELC(τ_lo, L_wc, T_body, m_τ) → IP-58 AIS(JIT 选档 + EDF 截止期 + 推测门控)
    → IP-51 CAR(延迟鲁棒守卫) → IP-39 规划(CBF margin=时序有效 m_lo) → IP-45 总线(时序心跳)
    → IP-59 EBE(被动滑行/阻抗保持，compute-while-coasting) → IP-53 CMC(WCET 标注 + 多档导出)
    → 降级阶梯：JIT 降档 → 被动滑行 → 保守动作 → SafeStop
L4: IP-54 SCV(Δ_time 随机化 + 时序压力测试) → IP-55 CKB(时序剖面 + 时序反例)
    → IP-50 课程(延迟尖峰相位) → RCA 重颁「含时域有效区间」的证书 → 契约/调度参数热更新
运行期：ELC 发时序证书 → AIS 以 τ−T_hold 为截止期按需推理 → EBE 兑现身体缓冲 → 违约即降级
```

## 4. 实验设计（E87–E94 硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E87 τ 下界有效性 | 实测越界时间 vs τ_lo；n=10k 轨迹违例数 | 违例 0；保守比 ≤ 3x |
| E88 延迟剖面 | L0/L1/各档 WCET、p99、抖动 | WCET 可复现；抖动 < 20% |
| E89 JIT vs 固定档 | 平均推理时间、算力、Nominal 占比 | 推理时间降 ≥ 40%；Nominal 不降 |
| E90 推测门控 | 提交动作的真实违例数、延迟下降 | 违例 0；端到端延迟降 ≥ 25% |
| E91 被动缓冲 | T_body 预测 vs 实测保持时间；滑行期越界 | 误差 < 25%；0 越界 |
| E92 时序飞轮 | 注入延迟尖峰后，3 轮内 Nominal 恢复 | 每轮 +5pp，最终 ≥ 80% |
| E93 长时程 | 100h、含延迟注入：不安全事件、p99、降级次数 | 0 起；p99 达标；降级 < 10 次/天 |
| E94 跨平台 | Orin Nano / STM32H7 上 WCET 与内存 | 均满足 L_wc 预算；INT8 路径 < 8KB |

**回退**：E87 失效 → τ 估计退回纯制动界并放大 ε_j，或禁用 JIT 只用最保守档；E90 失效 → 关闭推测，只保留快路径；E91 失效 → T_body 置 0，退化为 v19 的纯空间证书；E92 不收敛 → 人工锁定延迟预算，仅保留固定档 + SafeStop。

## 5. 本轮最大风险

**一句话**：本轮把「安全裕度」当作「算力预算」来花——一旦 τ_lo 的估计偏乐观、或尾延迟/未建模接触让实际 τ 小于估计，系统就会**主动把本该保命的时间用于推理**，把一次延迟尖峰直接放大成不安全事件；因此 E87（τ 下界实测）与 E91（被动缓冲实测）必须作为红线，任一失败即禁用 JIT 与 compute-while-coasting，退回 v19 的固定档 + 空间证书。

## 1. 符号体系（增量：定义 38–43 符号）

| 符号 | 含义 | 定义 |

| C_τ(x) | 时序证书 | 当且仅当 m_τ(x) ≥ 0 且 m_lo(x) ≥ θ |
| T_body(x) | 具身被动缓冲 | 切被动/零力矩后保持在 S_safe 的最长时间；能量法下界 |
| Π={π_j}, (l_j,m_j) | anytime 推理阶梯 | 每档的认证延迟与边际保证 |
| j*(x) | JIT 最优档 | min{j : m_j(x) − β l_j ≥ θ}，无解则 ⊥ |
| (l_s,l_v) | 慢模型/验证器延迟 | 推测提交门控用 |
| ψ_time | 时序指纹 | 延迟分布/抖动/丢包率的嵌入，入 CKB 检索 |

## 2. 关键算法（伪代码）

### IP-57 ELC：时序证书签发
```
def issue_temporal_certificate(x, cert_spatial, latency_profile):
    # 1) 空间量：m_lo 与 Lipschitz/速度界
    m_lo = cert_spatial.m_lo
    beta = cert_spatial.L_m * v_max(x) + cert_spatial.b_input
    # 2) time-to-unsafe 下界（取较紧者）
    tau_cbf   = m_lo / max(beta, EPS)
    tau_brake = v_max(x) / max(a_brake(x), EPS)
    tau_lo    = min(tau_cbf, tau_brake)
    # 3) 认证延迟：只用 WCET，不用 p99
    L_wc = latency_profile.wcet  # 已含感知/通信/执行
    # 4) 被动缓冲（条件不满足直接置 0）
    T_body = passive_hold_bound(x) if passive_conditions_met(x) else 0.0
    # 5) 时序边际
    m_tau = tau_lo - L_wc - cert_spatial.T_hold - cert_spatial.eps_j
    cert_t = TemporalCert(tau_lo=tau_lo, L_wc=L_wc, T_body=T_body,
                          m_tau=m_tau, valid_until=now + max(0, m_tau))
    if m_tau < 0:
        log_timing_counterexample(x, latency_profile, reason='m_tau_negative')
    return cert_t

def passive_hold_bound(x):
    # 能量法：E(x) <= E_safe，耗散率 >= lambda_min
    # T_body >= (1/lambda_min) * ln(E_safe / max(E(x), EPS))
    return (1.0 / lambda_min(x)) * log(E_safe(x) / max(E(x), EPS))
```

### IP-58 AIS：JIT 选档 + EDF 截止期 + 证书门控推测
```
def jit_select(x, ladder, theta, beta):
    # 按延迟从低到高扫描；m_j 为档 j 的空间边际保证
    for j, stage in enumerate(ladder):        # l_j 单调增，m_j 单调增
        if stage.m_j(x) - beta * stage.l_j >= theta:
            return j
    return None  # 无档可满足 -> 被动缓冲/降级

def latency_aware_step(x, ladder, cert_t):
    # 动态截止期 = 剩余安全时间（扣掉保持时间）
    deadline = cert_t.tau_lo - cert_t.T_hold
    j = jit_select(x, ladder, theta, cert_t.beta)
    if j is None:
        return degrade(x, level=1)           # 转被动滑行
    action, m = ladder[j].infer(x)           # 锁存快路径安全动作
    if not provably_safe(m, x, ladder[j].l_j, cert_t):
        return degrade(x, level=1)
    # 推测：仅在门控三条件下允许慢模型覆盖快动作
    if speculative_enabled and cert_t.m_tau > 0:
        l_rem = deadline - ladder[j].l_j
        if l_rem >= ladder[-1].l_slow + VERIFIER_LAT:
            u_slow = ladder[-1].infer_async(x)
            if verifier_pass(u_slow) and \
               margin_after_delay(u_slow, x, ladder[-1].l_slow + VERIFIER_LAT) >= theta:
                action = commit(u_slow)
    return action

def degrade(x, level):
    # 1: 被动/阻抗滑行 (EBE)；2: 定点保守动作；3: SafeStop
    if level == 1 and passive_conditions_met(x) and energy_margin(x) > 0:
        return enter_passive_mode(x)
    if level == 2:
        return conservative_action(x)
    return safe_stop(x)
```

### IP-59 EBE：compute-while-coasting 与额度记账
```
def compute_while_coasting(x, cert_t, plan):
    # 只有当推迟的代价可由身体吸收时才允许
    if not passive_conditions_met(x):
        return None
    budget = cert_t.T_body - cert_t.T_hold
    if budget <= 0:
        return None
    enter_passive_mode(x)                    # 先让身体接管
    action = plan.compute(budget_us=budget)  # 用身体时间换推理时间
    # 硬看门狗：能量/速度/接触任何一项越界立即 abort
    if watchdog_tripped(x):
        return conservative_action(x)
    if not reclaim_active_mode(x):           # 主动模式恢复有 WCET 预算
        return safe_stop(x)
    return action

def passive_hold_bound_online(x):
    # 实机小幅激励校正 lambda_min；与仿真标定值做保守取小
    return min(sim_T_body(x), measured_T_body(x) * (1 - SAFETY_MARGIN))
```

### IP-51/52 升级：延迟鲁棒守卫与时序充分 LCS
```
# CAR：守卫必须覆盖整整一个最坏延迟的边际衰减
def car_guard_delay_robust(e, x, cert_t):
    theta_real = cert_t.alpha_e * cert_t.theta_sim[e]
    required = theta_real + cert_t.beta * cert_t.L_wc
    return cert_t.m_lo[e] >= required and cert_t.m_tau >= 0

# LCS：时序充分才允许停在这一档
def certify_light_v3(x, guards, cert_t, ladder):
    j = jit_select(x, ladder, theta, cert_t.tau_lo)
    if j is None:
        return degrade(x, 1), -1
    b = ladder[j].infer(x)
    U = undecided_guards(b, guards)
    if not U and cert_t.m_tau >= 0:
        return b, j                      # 时序+空间同时充分
    return downgrade_monotone(b), j      # 保守降级仍保持 sound
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性保证 |
|---|---|---|---|
| IP-57 τ_lo 估计 | O(1)（查 m_lo/β/制动表） | O(1) | τ ≥ m_lo/β 且 τ ≥ v/a_brake，取下界保 sound |
| IP-57 T_body 估计 | O(1) 能量式 / 离线 O(N_sim) | O(1) | 条件不满足即置 0，保守兜底 |
| IP-58 JIT 选档 | O(K)（K 档，通常 ≤4） | O(K) | j* 按构造为满足 `m_j−βl_j≥θ` 的最小延迟档 |
| IP-58 EDF 调度 | O(log Q) 队列操作 | O(Q) | 截止期 D=τ_lo−T_hold；EDF 在单处理器可调度性最优 |
| IP-58 推测门控 | 快路径 O(1) + 慢路径异步 | 双缓冲动作 | 三条件 + 定理 5 ⟹ 提交动作延迟后仍 ≥ θ |
| IP-59 被动滑行 | O(1) 模式切换 + 看门狗 | O(1) | T_body 条件成立 + 看门狗 ⟹ 滑行期不越界 |
| IP-51 延迟鲁棒守卫 | O(|E|) 查表+比较 | 同 L0 | θ+βL_wc 修正后守卫 ⊇ 真实安全集 ⟹ 无漏报警 |
| IP-52 时序充分 LCS | O(K) 选档 + 既有查表/推理 | 同 L0+L1 | 同时满足 m_lo 与 m_τ 才停机，否则保守降级 |
| IP-53 多档导出 | 离线 O(K·QAT) | O(K·模型) | 每档独立验证；部署清单含 WCET 与 cert_hash |
| IP-54 Δ_time 压力测试 | 离线 O(|E|·N_traj·T_sim) 可并行 | 仿真日志 | 经验覆盖延迟分位 ⟹ α_e 与 L_wc 的置信界 |
| IP-55 CKB 时序检索 | HNSW O(log N) + 重排 | O(N·d) | 时序指纹纳入相似度，避免「空间像、时间不像」的误检索 |

**定理 5（时序充分性，复述）**：若 `m_lo(x) ≥ θ + β·L_wc` 且 `T_body(x) ≥ L_wc`，则任意 `L ≤ L_wc` 的延迟执行在 `[t, t+L+T_hold]` 内不会离开 S_safe；若 `L_wc < L ≤ T_body`，切被动模式的滑行仍安全。**证明**：由 β 定义，边际在延迟 L 内最多衰减 βL，故执行时刻边际 `m_lo − βL ≥ θ`；保持时间 T_hold 覆盖执行后窗口；被动段由 T_body 定义保证。证毕。

**命题 6（JIT 不劣于固定档）**：对同一状态，固定档 j_fix 若安全则 JIT 选出的 j* 满足 `l_{j*} ≤ l_{j_fix}`，即 JIT 至少不增加延迟；若 j_fix 不安全，JIT 会降档或进入被动层，避免静默失效。

## 4. 实验设计（E87–E94，硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E87 τ 下界有效性 | 实测越界时间 vs τ_lo；10k 轨迹违例数 | 违例 0；保守比 ≤ 3x |
| E88 延迟剖面 | L0/L1/各档 WCET、p99、抖动（Orin Nano / STM32H7） | WCET 可复现；抖动 < 20% |
| E89 JIT vs 固定档 | 平均推理时间、算力、Nominal 占比 | 推理时间降 ≥ 40%；Nominal 不降 |
| E90 推测门控 | 提交动作真实违例数、端到端延迟降幅 | 违例 0；延迟降 ≥ 25% |
| E91 被动缓冲 | T_body 预测 vs 实测保持时间；滑行期越界数 | 误差 < 25%；0 越界 |
| E92 时序飞轮 | 注入延迟尖峰后 3 轮内 Nominal 恢复 | 每轮 +5pp，最终 ≥ 80% |
| E93 长时程 | 100h + 延迟注入：不安全事件、p99、降级次数 | 0 起；p99 达标；降级 < 10 次/天 |
| E94 跨平台 | WCET 与内存占用 | 均满足 L_wc；INT8 路径 < 8KB |

**回退**：E87 失效 → τ 退回纯制动界并放大 ε_j，或禁用 JIT；E90 失效 → 关闭推测，只保留快路径；E91 失效 → T_body 置 0，退化为 v19 纯空间证书；E92 不收敛 → 人工锁定延迟预算，仅留固定档 + SafeStop。

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| τ_lo 乐观 / 尾延迟漏检，把延迟尖峰放大为不安全 | 高 | 只用 L_wc 入证书；E87 红线；τ 估计分段保守；在线越界监测触发熔断 |
| 被动缓冲 T_body 在真实接触/坡道上失效 | 高 | 条件化 T_body（接触态/速度域）；实机激励校正 + 安全裕度；E91 红线；看门狗 |
| compute-while-coasting 把身体信用透支 | 高 | 额度记账 + 冷却期；连续兑现上限；能量/速度硬看门狗；异常即回主动模式 |
| JIT 选档抖动/频繁切换 | 中 | 档位滞回（hysteresis）；EWMA 平滑 τ 与 β；切换有最小驻留时间 |
| 推测执行提交了「验证通过但延迟后不安全」的动作 | 高 | 门控条件 (b) 显式扣除 l_s+l_v 的 β 衰减；V_0 与证书双保险；E90 审计 |
| EDF 在共享总线/多核上不可调度 | 中 | 单批次=1、固定优先级兜底；总线预留带宽；WCET 隔离开关 |
| 时序飞轮频繁重跑耗尽预算 | 中 | 延迟漂移阈值 + 冷却期；只在 p99/WCET 同时超限时触发 |

## 6. 本轮最大风险

**一句话**：本轮把「安全裕度」当作「算力预算」来花——一旦 τ_lo 的估计偏乐观、或尾延迟/未建模接触让实际 τ 小于估计，系统就会**主动把本该保命的时间用于推理**，把一次延迟尖峰直接放大成不安全事件；因此 E87（τ 下界实测）与 E91（被动缓冲实测）必须作为红线，任一失败即禁用 JIT 与 compute-while-coasting，退回 v19 的固定档 + 空间证书。
