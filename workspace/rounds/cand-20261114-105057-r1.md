# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~301；灵感循环第 1 轮；本轮灵感：「专利布局」×「数据配比」）

> R73 把证据计量变成**可组合的契约**（MMS / EC / CCA / ΣREFLEX / CPB），把 R72 的单体审计拆成「模块证书 ⊗ 组合校验」，并声称系统级安全在热替换、增删、迁移下由组合规则自动保持。但整座大厦压在两个**从未被审计的前提**上：
> - **前提 A（支撑盲区 / support gap）**：conformal 覆盖率 1−α 被声称在有效域 D 上成立，但校准数据是用某个——通常隐式、从未记录、也从未进入证书——**配比**在 D 的各分层上采的。若部署分布、或组合后系统实际走到的**联合分层**不在该配比的支撑内，证书就会在「它声称覆盖的那块区域」上恰好失效。R73 的 PAR 一致性审计 `conformal_covers(r)` 完全可以在**边际**都覆盖的情况下，于**联合**分层样本数为 0——审计通过，而融合域上的 conformal 集根本不存在。这不是表达力不够的模糊风险，是一个可构造的反例。
> - **前提 B（主张过宽 / claim overbreadth）**：CPB 的三条主张只在基准上逐点验证，从未被约束**宽度**。一条主张可以「在一个基准上被支持」同时「相对其证据过宽」——这正是专利法里 claim 超出说明书 enablement 的**无效主张**。R73 的蒸馏纪律只问「组件是否服务某主张」，没问「该主张是否被其证据所 enable、是否会被同行用另一个基准轻易绕开」。
>
> 两者不是两件事，而是同一枚硬币的两面：**声明范围（declared scope）与支撑范围（supported scope）脱钩**。专利法为此发明了 enablement / novelty / 审查中的 narrowing；统计学习为此发明了 covariate shift / conformal under shift；R73 则把两者都当成「证书里没写的假设」。本轮把这两个前提**升格为一等、可审计、可组合的对象**。
>
> 本轮两个灵感正好各补一面：
> - **专利布局** → **CBG（Claim Breadth Geometry）+ 审查算子**：主张 =（声称区域 P_C ⊆ Θ，证据集 E_C）。可采纳 ⇔ **enablement**（P_C ⊆ Hull(E_C)）∧ **novelty**（相对基线邻域显著超过复现带）∧ **非平凡**（宽度 ≥ b_min）。过宽 = 无效主张；过窄 = 易被绕开。引入**收缩算子 Shrink(C)**（等同于专利审查中的 narrowing）与**绕行抵抗度**，把 CPB 从「三句口号」升级为**可被无效宣告检验的 claim 组合**。
> - **数据配比** → **CMA（Calibration Mixing Allocation）+ DRC（Data-Ratio Certificate）**：把校准配比 π 当作一等设计变量；覆盖率不再是「1−α」，而是**偏移球上的下界** 1−α−g(ρ)；证书必须记录 (π, n_s, ρ) 并在部署漂移越界时**过期**。核心新定理：D_cert(π) ⊆ D_decl——**支撑诱导的域收缩**，即「契约的 enablement 原则」。
> - 二者对偶：**主张要宽到能挡住绕行，证书要窄到每层都有支撑**；唯一安全的方向是「声明 ⊆ 支撑」。
>
> 核心命题：**审计对象不再是「证书是否齐全」，而是「每个声明是否被其支撑所 enable」——主张宽度（专利）与数据配比（支撑）是同一枚硬币的两面，声明超出支撑的那部分，就是系统的残余风险。**

## 0. 直觉与动机

**灵感 1（专利布局 → 主张不是真/假二元，而是「有宽度、有支撑、可被绕开」的几何对象）**
直觉：一个专利组合的价值不是「专利数」，而是它**在设计空间中圈住并封死的区域**。三件事同时决定价值：(i) **enablement**——权利要求不能比说明书公开的更宽，否则无效；(ii) **novelty / non-obviousness**——不能被现有技术或其显而易见的组合涵盖；(iii) **绕行（design-around）成本**——太窄的主张，竞争者微调即可绕过。专利审查本身是一个**收缩过程**：审查员用 prior art 逼你把 claim 从宽改到窄，直到它恰好落在说明书 enable、又仍覆盖核心创新。R73 的 CPB 只做了「这个组件证明哪条主张」，完全没做「这条主张有多宽、是否超出证据、能不能被一个没做过的基准绕开」。把主张看成 Θ（设计空间）里的区域，三个概念立刻可度量：宽度 b(C)=μ_Θ(P_C)、支撑 Hull(E_C)、绕行抵抗 = 1 − 未被覆盖的设计质量。**论文的 claim 和专利的 claim 受同一套审查逻辑约束**——这是本轮的第一根支柱。

**灵感 2（数据配比 → 校准覆盖率是配比的函数，配比错则证书空转）**
直觉：conformal 的 1−α 从来不是「免费的」，它由**校准样本落在哪个分层**决定。数据配比（edge/rare-stratum 比例、模态间预算分配、ID 与 OOD 的混合比）不是训练技巧，而是**证书的定义域**。两个必须直面的层次：(i) **边际 vs 联合**——两路模态各自在边际上都校准良好，不等于它们的**联合分层**上有样本；可 R73 的 PAR 恰恰只在联合域上融合。(ii) **偏移**——部署分布 q 不会等于校准配比 π；在没有 q 的似然比时，**对任意 q 的分布无关覆盖是不可能的**（这是负结果，必须诚实写出来）。所以数据配比能买到的东西不是「普适覆盖」，而是一个**偏移球内的覆盖下界** 1−α−g(ρ)，其中 ρ 是 q 相对 π 的 f-散度半径。配比 π 因此变成一个**极小极大实验设计**变量：在固定校准预算下，选 π 使最坏部署 q（在 ρ 球内）的覆盖最好。且配比是稀缺资源的分配——分给透明物体的样本多了，镜面物体的支撑就薄了。

**灵感 3（两者对偶 → 声明 ⊆ 支撑，是唯一的 sound 方向）**
直觉：专利的 enablement 说的是「claim ⊆ 说明书」；统计的支撑说的是「D_decl ⊆ D_cert(π)」。把两者抽象成同一个算子：每个 **warrant（证书/主张）** 携带一个**声明范围** Scope_decl 和一个**支撑范围** Supp；**支撑包含不变式 SCI**：Scope_decl ⊆ Supp，否则 warrant 无效。「专利过宽 = 无效」与「覆盖率声称超出校准支撑 = 空转」是同一条不变式的两个实例。这把 R73 的证书从「一个数（coverage）」变成「一个带定义的集合（在哪些分层上、以多大偏移半径、覆盖多少）」。副产品：**组合在 R73 里对不确定度是单调的，对支撑却是反单调的**——PAR 需要两边都支撑，所以融合把支撑收窄到交集；若交集上无联合校准，组合会**把两张有效证书合成一张无效证书**。这是 R73「组合不产生免费午餐」在支撑轴上的对偶：**组合也不产生免费宽度**。

**灵感 4（三资源前沿 → 交互预算、校准预算、残余风险三者不可互相免费替代）**
直觉：R73 已有反作用预算 Σc_reflex ≤ B_total（交互成本）。本轮引入校准预算 Σ_s c_s n_s ≤ B_cal（支撑成本）。一个自然的幻想是「多交互 → 多数据 → 更好校准」，于是两者可互换。真相更微妙：**主动感知只能扩展它真正访问到的分层**；如果探索策略不在未支撑分层上留下覆盖保证，它会花掉反作用预算却仍然留下支撑空洞。于是存在一条**三资源前沿**（交互预算 ↔ 校准预算 ↔ 残余风险），且**支撑覆盖是一个次模最大化问题**——贪心分层采样可达 (1−1/e) 最优，这正是把 R73 的 ERVOI 从「选哪个动作降不确定度」升级为「选哪个动作补哪个支撑洞」。**没有免费的预算套利**是本轮的第二根支柱。

**灵感 5（自我应用 → 论文自己的主张也必须通过 enablement 审查）**
直觉：本轮提出 C4（支撑包含 / 配比证书）与 C5（主张宽度审查）。但更重要的是**元一致性**：既然主张必须被证据 enable，那么本文自己的 C1–C5 也必须通过 CBG 审查——每条主张的宽度不得超过其预注册实验的支撑（leave-one-benchmark-out 后仍成立），否则就是**自我过宽**。这把 R73 的蒸馏纪律（只保留服务主张的组件）升级为**双向纪律**：组件必须服务主张，主张也必须被证据支撑。审稿人问「贡献是不是堆叠」，答案从「三条可隔离主张」升级为「一个可被无效宣告检验、且通过了自我审查的 claim 组合」。

## 1. 形式化定义（增量：定义 383–398）

**定义 383（CLAIM-GAUGE-RAS 总览与八不变式）** CLAIM-GAUGE-RAS = (MODGAUGE-RAS†, MIX, DRC, CBG, J_SUP, SSA, PPL, SDM)。在 R73 五不变式之外新增：
(vi) **支撑包含（SCI）**：每个 warrant 的声明范围 ⊆ 其支撑范围（定义 384、392）；
(vii) **主张可采纳**：每条进正文的主张经 CBG 审查（enablement ∧ novelty ∧ 非平凡，定义 389/390）；
(viii) **偏移预算化覆盖**：任何 coverage 声明都附带偏移半径 ρ，部署漂移越界即证书过期（定义 387、395）。
R73 的五不变式作为特例保留（当 π 在全部可达分层上均匀且 n_s→∞、主张取最大可采纳时，CLAIM 退化为 MODGAUGE，定理 31）。

**定义 384（计量分层与声明/支撑测度）** 给定有效域 D（R73 定义 367），取一个**计量分层** 𝕊 = {s_1,…,s_K}，使每层内噪声机制近似同质，D = ⊔_{s∈𝕊} D_s（深度实例：距离箱 × 材质类 × 边缘态 × 互扰态）。**声明测度** μ_decl 由契约给出（它声称覆盖哪些分层的多大风险质量）；**支撑测度** μ_supp 由校准数据给出。分层是为了让「覆盖」可以被逐层计数，而不是被一个全局标量掩盖。

**定义 385（数据配比策略 CMP）** 配比策略 π ∈ Δ(𝕊)（分层上的概率向量），每层样本数 n_s，单位成本 c_s。**配比证书候选** = (π, {n_s}, {c_s}, 采样协议哈希, SEAL 引用)。关键：π 是**显式、持久、进证书**的——不再是一个隐式默认。有效样本量 n_s^eff = n_s / (1 + 层内自相关时间/去相关长度)，用于处理非 i.i.d. 采集。

**定义 386（分层 conformal 与有效域收缩 / enablement 原则）** 令 n_min(α,δ,|𝕊|) 为同时（simultaneous）覆盖 1−α（置信 1−δ）所需的最小分层样本数（Bonferroni 型 n_min = ⌈(|𝕊|/α)⌉，或按层风险质量的加权版）。定义**已认证域**
D_cert(π) = ⊔_{s : n_s^eff ≥ n_min(α,δ,|𝕊|)} D_s。
**enablement 原则（契约版）**：D_decl \ D_cert(π) 上的覆盖率**无保证**；诚实证书只应声明 D_cert(π)。故恒有 D_cert(π) ⊆ D_decl，且二者之差 = 声明超出支撑的那部分 = **支撑空洞**。

**定义 387（偏移球与数据配比证书 DRC）** 设部署/运行诱导的分层分布为 π_req。用 f-散度 D_f(π_req‖π) 度量偏移。偏移球 Q_ρ = {q : D_f(q‖π) ≤ ρ}。**DRC** = (π, {n_s}, ρ, 1−α−g_f(ρ,α), 生成时刻, 到期条件)，其中 g_f 是覆盖率惩罚（见引理 40）。**负结果（诚实声明）**：不存在不约束 ρ 而能对任意 q 保证 1−α 的配比——配比买到的只是**球内**保证。DRC 的到期条件：部署漂移检验拒绝「D_f(π̂_req‖π) ≤ ρ」。这相当于专利的**年费/复审**：新出现的 prior art（支撑漂移）可使旧证书失效。

**定义 388（联合分层与边际审计陷阱）** 组合后的实际域是**联合分层** S_joint ⊆ 𝕊_A × 𝕊_B × …（各模态分层的笛卡尔积）。MReg 的实际运行诱导**可达联合分层** S_reach(MReg) ⊆ S_joint。**边际审计**只核验每个模态的边缘配比 π_A、π_B；**联合支撑**核验 S_reach 上每一联合层 s 的 n_s^eff ≥ n_min。二者可以严重脱钩（引理 39 给出构造）。**CCA† 修订**：PAR 的 `conformal_covers(r)` 必须升级为**联合层条件**——在 s ∈ S_reach 上审计，而非在边际上审计。

**定义 389（主张宽度几何 CBG）** 设计空间 Θ（所有可能的系统设计/工况/对手策略/替代方法）。一条主张 C = (P_C, E_C)：声称区域 P_C ⊆ Θ，证据集 E_C ⊆ Θ（预注册实验实际覆盖的点/区域）。**宽度** b(C) = μ_Θ(P_C)。**可采纳** ⇔
(i) **enablement**：P_C ⊆ Hull(E_C)（或其 ε-膨胀，ε 为预注册外推许可）；
(ii) **novelty**：∀ 基线 β ∈ N(P_C)（P_C 的邻域），∃ p ∈ P_C 使 C 在 p 上超过 β 且超出复现带 Δ_rep；
(iii) **非平凡**：b(C) ≥ b_min。
三种无效：**过宽（overclaim，违反 enablement）**、**被预见（anticipation，某基线在 P_C 上不可区分）**、**显而易见（obviousness，由两条已知结果组合可推）**。

**定义 390（主张审查算子 / prosecution）** 收缩算子 Shrink(C) = 最大的可采纳子主张 C′ ⊆ C（存在性与唯一性见引理 41）。审查流程：对每条主张执行 (i) leave-one-benchmark-out——去掉任一基准后 P_C 是否仍在剩余证据的 Hull 内；(ii) prior-art 邻域搜索——用已有方法/基线在 N(P_C) 上做显著性检验；(iii) 若违反则迭代 Shrink 直到可采纳或宽度 < b_min（此时主张降级为工程附件）。**结论句**：专利审查不是修辞，是一个可执行算法。

**定义 391（主张组合与绕行抵抗）** 主张组合 Π = {C_1,…,C_m}。**设计空间覆盖率** Cov(Π) = μ_Θ(∪_i P_{C_i})。**绕行抵抗度** DR(Π) = 1 − μ_Θ(Θ \ ∪_i P_{C_i}) / μ_Θ(Θ)（在相关子空间上）。**不可免费变宽（主张版）**：P_{C_i ⊗ C_j} ⊆ Conv(E_{C_i} ∩ E_{C_j})——组合不能凭空扩大被支撑的区域（定理 32）。故「加一条主张」只在它填补未被覆盖的 Θ 区域、且有自己的证据支撑时才有价值。

**定义 392（支持闭合证书 J_SUP）** J_SUP = J_MOD ⊗ J_DRC ⊗ J_CLAIM，其中 J_DRC 校验 ∀s ∈ S_reach：n_s^eff ≥ n_min 且 ρ 已声明；J_CLAIM 校验每条进正文主张可采纳。**Valid(J_SUP) ⇒ Valid(J_MOD)**（R73 证书为忽略支撑轴的特例）。Certificate 记录从「一堆数值」变成「一张带定义域、偏移半径、分层计数的结构」。

**定义 393（配比预算分配 CMA / 极小极大实验设计）** 给定总校准预算 B_cal，选 (π,{n_s}) 使最坏部署覆盖最大：
min_{q∈Q_ρ} cov(q; π) 最大化，s.t. Σ_s c_s n_s ≤ B_cal，且 s ∈ S_reach ∩ D_cert 的约束优先（保障组合有效）。等价于在分层上做**带对抗权重的注水（water-filling）**：给最坏 q 下权重最高、且单位成本覆盖增益最大的层多分配样本。**不可行情形**：若某层在预算内无法达到 n_min，则它必须被**显式移出 D_decl**（域收缩），而不是被假装覆盖。

**定义 394（支撑靶向主动采样 SSA）** 主动感知的动作不仅降不确定度，还应**填补支撑洞**。把「未达标分层集合」的覆盖视为次模函数 f(A) = μ(∪_{s∈A} D_s)，动作 a 带来新样本覆盖 Δ_s(a)。SSA 在 R73 的 ERVOI 目标上加入支撑项：
a* = argmax_a [ −λ·E[u_next] − Σ_i c_reflex^i(a) + γ·Δ_support(a) ]，s.t. V_safe、REG 契约、单步样本成本 ≤ 剩余 B_cal。
贪心可达 (1−1/e) 的支撑覆盖（引理 42）。

**定义 395（支撑漂移监测 SDM）** 运行时对部署分层经验分布 π̂_req 做两样本检验（或在线 f-散度估计），维护 ρ̂。若 ρ̂ > ρ（DRC 声明半径）⇒ 触发：优先 SSA 补样；补不上则**域收缩**（把越界层移出 D_decl，BSE 相应 stub 化该层）；再不行则拒绝该交互（继承 R71 非补偿否决）。SDM 是 DRC 的**运行时执行器**。

**定义 396（主张组合规划 PPL / portfolio planner）** 在认证预算 CertCost（R73 定义 380）下选择模块/主张以最大化 Cov(Π) − η·CertCost：
Π* = argmax_Π [ Cov(Π) − η·CertCost(Π) ]，s.t. 每条 C_i 可采纳。
这把专利布局的「组合成本 vs 覆盖收益」写成优化问题；也把 R73 的「组件必须服务主张」扩展为「主张必须填补设计空间」。

**定义 397（数据配比威胁面 AIC-RATIO）** ℰ_ratio = {校准投毒（在关键分层注入偏移样本）、隐分层（采集协议系统性漏掉某材质/光照/距离组合）、配比操纵（对手影响训练/校准数据来源）、偏移诱导（部署时把系统逼到未支撑层）}。防线：配比哈希与采集协议入证书；隐分层用**残差分层检验**主动发现；偏移诱导由 SDM + 域收缩兜底；配比投毒由「分层留出 + 双层交叉拟合」检出。**单源不定案**（继承 E356/E357）。

**定义 398（CLAIM-GAUGE 结构上限与退化）** 新增上限：|𝕊| ≤ 64、|S_joint| ≤ 512、被认证主张数 m ≤ 8、ρ ≤ ρ_max（超过即视为域外，不许使用证书）。全部为可审计的有限对象。退化：π 在 S_reach 均匀且 n_s → ∞、主张取最大可采纳、ρ → 0 ⇒ CLAIM 逐指令等于 MODGAUGE（定理 31）。

# IP-302 CMA：分层配比预算分配（极小极大注水）
def calibrate_mix(strata, req_dist, budget, alpha, delta, f_div):
    n_min = min_samples_per_stratum(alpha, delta, len(strata))
    # 对抗权重：最坏部署 q 在 ρ 球内对每层的权重
    w = worst_case_weights(req_dist, f_div, rho=req_dist.rho)
    pi, n = {}, {}
    remaining = budget
    # 注水：单位成本覆盖增益最大的层先补到 n_min（组合有效性硬约束）
    for s in sorted(strata, key=lambda s: w[s] / strata[s].cost, reverse=True):
        need = max(0, n_min - strata[s].n_eff)
        alloc = min(remaining // strata[s].cost, need)
        n[s] = strata[s].n_eff + alloc; remaining -= alloc * strata[s].cost
        if strata[s].n_eff + alloc < n_min:
            strata[s].certified = False          # 显式域收缩（定义 393）
    pi = normalize(n)
    return MixPolicy(pi=pi, n=n, rho=req_dist.rho, budget_spent=budget - remaining)

# IP-303 DRC：数据配比证书（带偏移半径与到期）
@dataclass(frozen=True)
class DataRatioCert:
    pi: dict; n: dict; rho: float; alpha: float
    coverage_floor: float                        # 1 - alpha - g_f(rho, alpha)
    protocol_hash: str; issued_at: int; seal_ref: str
    def expired(self, prov_req):                 # SDM 调用
        return f_divergence(prov_req, self.pi) > self.rho

# IP-304 CBG：主张宽度几何与审查算子
def certify_claim(claim, evidence, baselines, theta_measure, eps=0.05, b_min=0.02):
    P, E = claim.region, evidence.support
    if not subset(P, expand(convex_hull(E), eps)):      # enablement
        return Claim(cid=claim.cid, status='OVERCLAIM')
    for b in baselines_in(neighborhood(P)):             # novelty
        if not beats(b, claim, margin=DELTA_REP, region=P):
            return Claim(cid=claim.cid, status='ANTICIPATED', prior=b)
    if theta_measure(P) < b_min:                        # 非平凡
        return Claim(cid=claim.cid, status='TRIVIAL')
    return Claim(cid=claim.cid, status='ADMISSIBLE', breadth=theta_measure(P))

def shrink(claim, evidence, baselines, theta_measure):
    C = claim
    while certify_claim(C, evidence, baselines, theta_measure).status == 'OVERCLAIM':
        C = Claim(C.cid, region=C.region & expand(convex_hull(evidence.support), 0.0),
                  text=C.text)                      # 审查式 narrowing
    return C                                        # 极大可采纳子主张（引理 41）

def leave_one_benchmark_out(claim, benches):
    over = []
    for i in range(len(benches)):
        rest = benches[:i] + benches[i+1:]
        if certify_claim(claim, evidence_of(rest), baselines_of(rest),
                         claim.theta_measure).status == 'OVERCLAIM':
            over.append(i)
    return over                                     # 空 = 主张不依赖单一基准

# IP-305 J_SUP：支持闭合证书（扩展 J_MOD）
def J_SUP(mreg, drc, claims, S_reach):
    j_mod = J_MOD(mreg)                             # R73
    j_drc = all(drc.n.get(s, 0) >= drc.n_min for s in S_reach) and drc.rho_declared
    j_claim = all(c.status == 'ADMISSIBLE' for c in claims)
    return Certificate(j_mod=j_mod, j_drc=j_drc, j_claim=j_claim,
                       valid=j_mod.valid and j_drc and j_claim,
                       support_holes={s for s in S_reach if drc.n.get(s,0) < drc.n_min})

# IP-306 SSA：支撑靶向主动采样（次模覆盖贪心）
def support_aware_select(state, actions, mods, budget, gamma=0.3):
    holes = drc.support_holes
    def gain(a):
        cover = expected_new_strata(a, state)            # 该动作会新覆盖的层
        f = measure(cover & holes)                       # 次模覆盖增益
        reflex = sum(m.reflex_cost_estimate(state[m], m.ec.chi_R(a)) for m in mods)
        return -risk_params.lam*expected_u(a) - reflex + gamma*f
    a = max(actions, key=gain)
    return a if budget.can_afford(a) and gain(a) > 0 else None

# IP-307 SDM：支撑漂移监测与域收缩
def support_drift_monitor(prov_req, drc, bse, t):
    rho_hat = online_f_divergence(prov_req, drc.pi)
    if rho_hat <= drc.rho:
        return 'OK'
    if ssa_can_fill(prov_req, drc):                  # 先补样
        return 'RESAMPLE'
    bse.shrink_domain(prov_req.over_support_strata())# 再收缩域（stub 化）
    return 'SHRINK' if not prov_req.outside_all() else 'VETO'   # 继承非补偿否决

# IP-308 PPL：主张组合规划（覆盖 vs 认证成本）
def plan_portfolio(modules, claims, theta, cert_cost, eta):
    best = None
    for subset in feasible_subsets(modules, claims, cap=24):   # R73 结构上限
        admissible = [c for c in claims if certify_claim(c, ...).status=='ADMISSIBLE']
        cov = measure(union_regions(admissible), theta)
        score = cov - eta * cert_cost(subset)
        if best is None or score > best.score:
            best = Portfolio(subset, admissible, cov, score)
    return best

# IP-309 CLAIM-GAUGE 主闭环（在 R73 MODGAUGE 上挂三个新钩子）
def CLAIM_GAUGE_round(M, obs, audio, tac_frame, depth_img):

            if st == 'SHRINK': b_t = M.bse.restrict_to(M.drc.certified_strata)

        if M.mreg.has_par_edge():

        g = M.ervoi.choose(...)                      # R73

                                      M.budget_cal, gamma=M.gamma)  # IP-306

## 3. 推导

**引理 38（支撑包含在串联下保持、在并联下需联合支撑）** SER：D_out = D_A ∩ D_B，故 D_cert,out ⊆ D_cert,A ∩ D_cert,B，支撑包含传递。PAR：融合域是联合分层 S_joint；即使 D_cert,A、D_cert,B 各自非空，若 S_reach ∩ (D_cert,A × D_cert,B) 在联合校准中样本为 0，则融合域**不在支撑内**，SCI 被破坏。系：**组合对不确定度单调，对支撑反单调——这是「组合不产生免费午餐」在支撑轴的对偶。**

**引理 39（边际审计陷阱 / 反例）** 取两模态，A 的分层 {不透明, 透明}、B 的分层 {近, 远}。设校准配比满足 n_A(不透明)=n_A(透明)=500，n_B(近)=n_B(远)=500（两条边际均充分），但所有透明样本恰在近距采集，故联合层（透明，远）样本数 n_{AB}=0。则：两个边际 conformal 审计**全部通过**，而 PAR 在（透明，远）上的融合 conformal 集**不存在**——R73 的 `conformal_covers(r)` 在此处给出**空洞的通过**。这是对 R73 PAR 审计的一个精确、可复现的反例。系：**联合分层配比不是「更细的记账」，而是组合证书 soundness 的必要条件。**

**引理 40（偏移球覆盖下界 / 配比的极限）** 在 f-散度球 Q_ρ 内，最坏覆盖满足 cov_worst(π) ≥ 1 − α − g_f(ρ, α)，其中 g_f 单调增、g_f(0,α)=0；且该界在无更多结构假设下是紧的（对任意 ρ>0 存在使覆盖降到 1−α−g_f 的 q）。**负结果**：ρ→∞ 时 g_f→∞，故不存在配比能对任意部署保证 1−α。系：**证书必须携带 ρ，覆盖率必须写成「球内下界」而非「普适常数」——把 R73 的无条件 1−α 修正为一个有条件、可失效的声明。**

**引理 41（主张收缩的单调性与唯一极大可采纳子主张）** 可采纳性关于区域包含是单调的：若 C′ ⊆ C 且 C 可采纳，则 C′ 可采纳（enablement/novelty/非平凡均在子区域上保持，novelty 需邻域定义在 C′ 上重算，取保守即可）。故对任一主张 C，其可采纳子主张族在包含关系下有唯一极大元 C* = Shrink(C)。系：**任何主张都能被规范化为「恰好被其证据 enable 的最大主张」——这给出一道可执行的无过宽保证。**

**引理 42（支撑覆盖的次模性与 (1−1/e) 贪心界）** 支撑覆盖 f(A) = μ(∪_{s∈A} D_s) 是次模、单调的。SSA 的贪心选择在基数/预算约束下达到最优的 (1−1/e)（预算约束下为 1−1/e 的变体界）。故**补支撑洞的主动采样是可控的**；但贪心只保证覆盖层，不保证每层达到 n_min，故仍需 CMA 的硬约束兜底。系：**主动感知不是万能补丁——它只能按次模界补覆盖，样本量仍由 CMA 保障。**

**定理 30（支撑健全性 / support soundness）** 若 Valid(J_SUP)，则：(i) 对 D_cert(π) 内每一分层、在偏移球 Q_ρ 内任意部署 q，覆盖率 ≥ 1−α−g_f(ρ,α)；(ii) D_decl \ D_cert(π) 上的任何覆盖声明都**未被认证**，不得进入 λ 或安全论证；(iii) 每条正文主张被其证据 enable。**证明要点**：分层 conformal + 偏移加权界（引理 40）+ 联合分层计数（定义 388）+ CBG 可采纳性（引理 41）。系：**这把 R73 的「证书齐全」替换为「证书在其定义域内成立且定义域 ⊆ 支撑域」——从存在性保证升级为带定义域的保证。**

**定理 31（CLAIM-GAUGE 严格包含 MODGAUGE）** 当 π 在 S_reach 上均匀且 n_s→∞（D_cert = D_decl）、ρ→0（无偏移）、主张取最大可采纳 C*（等价于 R73 的逐点基准绑定）时，J_DRC 恒真、J_CLAIM 恒真，故 J_SUP = J_MOD。由定义 383 与引理 38，CLAIM-GAUGE 逐指令退化为 R73 MODGAUGE；再退化至 R72/R71/R68。且存在（引理 39 的）联合空洞实例，使 MODGAUGE 通过而 CLAIM-GAUGE 拒绝——故包含**严格**。系：**安全侧只增不减，扩展只在支撑轴上加约束。**

**定理 32（主张/支撑的不可免费变宽与预算不可套利）** (i) 对组合 Π，P_{Π} ⊆ Conv(∩ evidence)，故 Cov(Π) 不可能超过支撑交集所 enable 的区域（主张不能靠叠加变宽）。(ii) 设支撑空洞由 SSA 以反作用预算填补，则填补速率受次模界（引理 42）与 V_safe 约束；不存在一个常数汇率使「省下的校准预算」被「多花的交互预算」等价补偿，除非探索策略在未支撑层留下覆盖保证。**证明**：构造两个任务，一个支撑洞可由零风险探索补，另一个必须进入 V_safe 之外才能采样——后者即使反作用预算无限也无法在安全约束内补上。系：**三资源前沿真实存在，R73 的「组合不产生免费午餐」在资源轴上有第三个对偶。**

## 6. 本轮最大风险

**一句话**：CLAIM-GAUGE 把「证书有效性」从「覆盖率数字」推进到「声明 ⊆ 支撑」，但支撑本身是**用有限分层去近似连续、且会漂移的真实世界**——如果真实失效模式落在我们**从未想到要分的那一层**（未知未知：如多模态共享的、未被 𝕊 表达的共因，或随时间缓慢变化的环境语义），那么 D_cert 在它自己的坐标系里完全 sound，审计会证明「每一层都有足够样本、偏移在球内、每条主张都被 enable」，而系统恰恰在**分层之外**失效——我们用一个更精细、更可辩护的坐标系，换来了一个更精致、也更难被质疑的盲区。

次级风险与缓解：
1. **分层本身不完备（未知未知层）** → 分层版本化 + 残差池（未归类样本单独作 OOD 层，强制 n_min）+ 定期用聚类/密度检验提议新层，触发契约版本升级。
2. **联合分层爆炸** → 结构上限 |S_joint| ≤ 512 + 只对 S_reach 建联合层 + 稀疏回退到更粗层并相应收缩 D_decl。

# IP-302 CMA：分层配比预算分配（极小极大注水）
def calibrate_mix(strata, req_dist, budget, alpha, delta, f_div):
    n_min = min_samples_per_stratum(alpha, delta, len(strata))
    w = worst_case_weights(req_dist, f_div, rho=req_dist.rho)   # 最坏部署权重
    n, remaining = {}, budget
    for s in sorted(strata, key=lambda s: w[s]/strata[s].cost, reverse=True):
        need = max(0, n_min - strata[s].n_eff)
        alloc = min(remaining // strata[s].cost, need)
        n[s] = strata[s].n_eff + alloc; remaining -= alloc * strata[s].cost
        if n[s] < n_min: strata[s].certified = False            # 显式域收缩
    return MixPolicy(pi=normalize(n), n=n, rho=req_dist.rho,
                     budget_spent=budget - remaining)

# IP-304 CBG：主张审查与收缩
def certify_claim(claim, evidence, baselines, theta, eps=0.05, b_min=0.02):
    P, E = claim.region, evidence.support
    if not subset(P, expand(convex_hull(E), eps)):        # enablement
        return Claim(claim.cid, status='OVERCLAIM')
    if any(not beats(b, claim, margin=DELTA_REP, region=P)
           for b in baselines_in(neighborhood(P))):       # novelty
        return Claim(claim.cid, status='ANTICIPATED')
    if theta.measure(P) < b_min:                          # 非平凡
        return Claim(claim.cid, status='TRIVIAL')
    return Claim(claim.cid, status='ADMISSIBLE', breadth=theta.measure(P))

def shrink(claim, evidence, baselines, theta):
    C = claim
    while certify_claim(C, evidence, baselines, theta).status == 'OVERCLAIM':
        C = Claim(C.cid, region=C.region & convex_hull(evidence.support), text=C.text)
    return C                                              # 最大可采纳子主张（引理 41）

# IP-306 SSA：支撑靶向主动采样（次模覆盖贪心）
def support_aware_select(state, actions, mods, budget, gamma=0.3):
    holes = drc.support_holes
    def gain(a):
        cover = expected_new_strata(a, state) & holes
        reflex = sum(m.reflex_cost_estimate(state[m], m.ec.chi_R(a)) for m in mods)
        return -risk_params.lam*expected_u(a) - reflex + gamma*measure(cover)
    a = max(actions, key=gain)
    return a if budget.can_afford(a) and gain(a) > 0 else None

# IP-308 PPL：主张组合规划（覆盖 vs 认证成本）
def plan_portfolio(modules, claims, theta, cert_cost, eta):
    best = None
    for subset in feasible_subsets(modules, cap=24):
        admiss = [c for c in claims if certify_claim(c, *evidence(c)).status=='ADMISSIBLE']
        cov = theta.measure(union_regions(admiss))
        score = cov - eta * cert_cost(subset)
        if best is None or score > best.score:
            best = Portfolio(subset, admiss, cov, score)
    return best

## 4. 推导

**引理 38（支撑在串联下保持、在并联下需联合支撑）** SER 支撑传递；PAR 融合域是联合分层，边际各自有效不代表联合有效；组合对不确定度单调、对支撑反单调。**系**：组合不产生免费宽度。

**引理 39（边际审计陷阱 / 精确反例）** A 分层 {不透明,透明}、B 分层 {近,远}，边际各 500 样本均达标，但透明样本全在近距，故联合层（透明,远）n=0；两边际 conformal 审计全通过，PAR 在（透明,远）的 conformal 集不存在。**系**：联合配比是组合 soundness 的必要条件，不是更细的记账。

**引理 40（偏移球覆盖下界与极限）** 球内最坏覆盖 ≥ 1−α−g_f(ρ,α)，g_f 单调增、g_f(0)=0 且紧；ρ→∞ 则无保证（负结果）。**系**：覆盖率必须写成「球内下界」，证书必须携带 ρ。

**引理 41（主张收缩的唯一极大可采纳子主张）** 可采纳性关于区域包含单调 ⇒ 存在唯一极大可采纳子主张 C* = Shrink(C)。**系**：任何主张可规范化为「恰好被证据 enable 的最大主张」，给出可执行的无过宽保证。

**引理 42（支撑覆盖次模性与 (1−1/e)）** f(A)=μ(∪_{s∈A}D_s) 次模单调，贪心可达 (1−1/e)；但贪心只保覆盖层、不保每层 n_min，故仍需 CMA 硬约束。**系**：主动感知只能按次模界补覆盖。

**定理 30（支撑健全性）** Valid(J_SUP) ⇒ 对 D_cert(π) 内各层、Q_ρ 内任意 q，覆盖 ≥ 1−α−g_f(ρ,α)；D_decl\D_cert 上任何覆盖声明未被认证；每条正文主张被证据 enable。**系**：从「证书齐全」升级为「证书在其定义域内成立且定义域 ⊆ 支撑域」。

**定理 31（CLAIM-GAUGE 严格包含 MODGAUGE）** π 均匀、n_s→∞、ρ→0、主张取 C* ⇒ J_SUP = J_MOD，逐指令退化为 MODGAUGE→R72→R71→R68；且引理 39 实例使 MODGAUGE 通过而 CLAIM-GAUGE 拒绝 ⇒ 严格包含。**系**：安全侧只增不减，扩展只在支撑轴加约束。

**定理 32（不可免费变宽与预算不可套利）** (i) P_Π ⊆ Conv(∩ evidence) ⇒ 组合不能扩大被支撑区域；(ii) 支撑洞的补齐受次模界与 V_safe 约束，不存在常数汇率使交互预算等价补偿校准预算（构造必须越出 V_safe 才能采样的任务反证）。**系**：三资源前沿真实存在，是「组合不产生免费午餐」在资源轴的第三个对偶。

## 7. 本轮最大风险

**一句话**：CLAIM-GAUGE 把「证书有效性」从「覆盖率数字」推进到「声明 ⊆ 支撑」，但支撑本身是**用有限分层去近似连续、且会漂移的真实世界**——如果真实失效模式落在我们**从未想到要分的那一层**（未知未知：未被 𝕊 表达的共因，或缓慢变化的环境语义），那么 D_cert 在它自己的坐标系里完全 sound，审计会证明「每层样本充足、偏移在球内、每条主张都被 enable」，而系统恰恰在**分层之外**失效——我们用一个更精细、更可辩护的坐标系，换来了一个更精致、也更难被质疑的盲区。

次级风险与缓解：
1. **分层不完备（未知未知层）** → 分层版本化 + 残差池强制作 OOD 层 + 密度检验提议新层并升级契约。
2. **联合分层爆炸** → |S_joint|≤512 + 只建 S_reach + 稀疏时退更粗层并收缩 D_decl。
3. **偏移球误设** → 多散度并行取最保守 + E394 紧性校验 + 经验似然比交叉验证。
4. **收缩过度削没贡献** → 只收缩到最大可采纳，被削部分入附录；E398 同报宽度与复现率。
5. **CMA 与 ERVOI/PVOP 冲突** → 三目标加权 + V_safe 硬约束 + 任务/支撑预算分账。
6. **自我审查形式化** → E407 预注册 + 第三方复现 + 审查脚本公开可无效宣告。
7. **配比证书被当普适保证** → 接口强制 coverage 必附 ρ 与 D_cert，禁止无条件「1−α 覆盖」措辞。
