# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「少样本学习」×「低延迟推理」）

> R69 给闭环装上了一张嘴：把不确定性拆成 aleatoric / epistemic，前者收紧，后者用流匹配策略的多模态 + 主动交互（看/问/触）去消解。但 R69 有一个未被言明的前提——**模态表（repertoire）和它的校准在部署时就已经固定**。"我的模态表对不对"这个问题，R69 只能用一个全局 ECE 门（MCG）来回答；一旦门判定不可信，它唯一的选择是退回 R68 的纯保守。于是系统陷入两难：**在已知模态里问，问不到表外的东西；在表外，它要么把幻影当答案，要么永远不敢动。**
>
> 本轮两个灵感正好补上这两块：
> - **少样本学习**把"学习"从离线训练搬进部署期：用少量**已认证**的示范，长出模态表里没有的新模态/新校准，而不是在错误的假设空间里继续追问；
> - **低延迟推理**给出在同一个 L_max 内完成这一切的办法：把计算本身当作一种"询问"，用 anytime + 置信序列尽早停、用置信证书替代固定 K、把昂贵适配放到冷路径再用热插拔换装。
>
> 核心命题：**在 R69 的 (U_ale, U_epi) 之外补第三类不确定性 U_nov（开集/表外）；U_nov 高时"问世界"无效，必须"向少量已认证示范学习"；学习与推理共享一个硬延迟预算，用 VoC（计算的价值）与 VoI（交互的价值）联合调度；学不会/不可信/被投毒时，退化为 R69 的纯保守。** 命名 **FLORA-RAS**（Few-shot LOw-latency Repertoire Adaptation for Risk-Adaptive Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我怎样才能听懂答案——我的模态表里，是否根本没有正确答案**」——少样本不是背答案，是长出新的模态；低延迟不是砍功能，是把算力花在会改变决定的地方。

## 0. 直觉与动机

**灵感 1（少样本学习 → 不确定性的第三种：不是选错，而是没有）**
直觉：R69 的 U_epi 是"多选题里选哪一个"，它假设正确答案一定在选项表中。但真实部署里更危险的是**开集**情形：面前的东西不是"绕左还是绕右"的已知岔路，而是一类从没见过的地形；对方的表情不是"开心还是紧张"，而是一种训练集里没有的情绪。此时继续追问，只会把新东西硬塞进旧模态——就像用只会十以内加减法的人去问微积分，他会给你一个"最像"的错误答案，而且很自信。
这提示一个 R69 无法表达的区分：U_epi 是"表内的歧义"（可问），U_nov 是"表外的缺失"（问不出来，只能学）。少样本学习的意义不是"用更少数据训练一个更大的模型"，而是**在部署时用少量样本把假设空间本身扩一格**——从"在 {m_1..m_K} 里选"变成"发现并加入 m_{K+1}"。

**灵感 2（原型与闭式适配 → 少样本恰好是低延迟的盟友）**
直觉：若把"学习"理解成反向传播，它和 2ms 控制环天然冲突。但少样本最有效的两种形态都很便宜：
- **非参数原型记忆**：新模态 = 特征空间里一个原型点，插入 O(d)、查询 O(1)，无需梯度；
- **元学习初始化 + 一步闭式修正**：在特征层上解一个岭回归/最小二乘，得到低秩修正 Δ，`θ' = θ + Δ` 有闭式解，廉价且可解释。
因此"学得快"和"算得省"不是矛盾，而是同一种结构选择：**把容量放在低秩适配器与可增长的原型表里，而不是重训主干**。这也天然保住 R69 的"实时流零学习写操作"不变式——热环只读，适配在冷路径完成，再热插拔换装。

**灵感 3（低延迟推理 → 计算也是一种"询问"，而且常常比问人便宜）**
直觉：R69 的决策空间是"问世界（VoI）"或"不问（保守）"。但在延迟预算内，还有第三条路：**问自己**——多采几个模态样本、跑一次流似然校验、把 ECE 重新估一遍。它们同样降低不确定性，且不产生社交成本、不引人注意、不会撒谎，只是消耗毫秒。
于是可以定义 **VoC（Value of Computation）** 与 VoI 并列：当"多看两条轨迹"比"问人一句"每毫秒降熵更多时，就该先算再说。更妙的是，anytime 推理让我们在**决策已确定**时立刻停：R69 固定 K=4 的歧义路径，在多数情形下前 1–2 个样本就已把两个模态分开；早停使 P99 反而**低于** R69——低延迟不是功能削减，而是"只在会改变决定的地方花算力"。

**灵感 4（开集不是许可证 → 学习必须先被认证）**
直觉：发现 U_nov 高，不等于可以马上学。一次偶然的传感器故障、一个恶作剧的示范、一个分布外的光照，都会让新颖性检测器报警。若"报警即学习"，系统会不断把噪声固化成模态——这比 R69 的"永远保守"更糟，因为它会**主动把错误写进自己的能力**。
所以 FLORA 的第一原则是：**学习是特权，不是反射**。新颖性只产生"适配候选"，候选必须依次通过：共形新颖性（是不是真分布外）→ 支持集来源与影响证书（示范可信吗）→ 信任域（改了多少）→ 影子 rollout 与延迟基准（换上去安全吗、来得及吗）→ 原子热插拔与可回滚。任一环节失败，就退回 R69 的保守——**安全侧永不让步**。

**灵感 5（少样本也是攻击面 → 自我确认闭环）**
直觉：R69 已经担心"被证实的错误"；R70 让这个风险拥有了**放大器**。攻击者只需投毒一两个示范，就能在模态表里装一个"幻影原型"；更糟的是，FLORA 自己的适配-认证管线会拿这个原型去解释后续观测，形成**自我确认**：越用越像真的，证书越漂亮。而且低延迟把"投毒 → 生效 → 扩散"的时间压缩到一个 tick 量级，人类审计根本追不上。
因此必须把"适配"与"认证"的证据源**物理隔离**：认证只用独立的、带来源签名的留出流，绝不用被适配的支持集本身；影响力用留一法上界约束；安全关键模态加**钉住保护**，任何适配不得驱逐。否则 R70 只是给 R69 的嘴装上了一副"过目不忘"的脑子——它会把谎言记成真理。

**灵感 6（持续适配 → 校准债与灾难性遗忘）**
直觉：每次少样本适配都会让分布轻微漂移，模态权重的校准随之过期。R69 用 MCG 一次性检查 ECE，但 R70 的适配是**持续**的，校准会像信用卡一样累积"债务"。正确做法不是假装没有，而是显式记账：**校准债 D_cal** 进入 λ 的附加项，债务未偿还（在独立留出流上重校准）前，适配备份只能部分信任。同理，持续写入会把罕见但安全关键的模态挤掉；解决办法是**钉住集 + 回放缓冲**，让"忘记"在安全维度上不发生。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（FLORA-RAS 总览）** FLORA-RAS = (FLUID-RAS, OSN, SPC, FSA, CDL, LAS, CSS, HSC, MRG, RAS-WM††)。继承 R69 的 FLUID 层，新增四个不变式：
(i) **热环零写**（继承 R68 定义 276-i / R69 定义 293-i）：控制环只读，适配只在冷路径；
(ii) **硬延迟契约**：任意控制 tick 必须在 L_max 内返回一个**已认证**动作，超时只能单调变保守，不得返回未认证动作；
(iii) **学习认证优先**：任何参数/记忆写入必须先通过 SPC ∧ HSC，否则视为未发生；
(iv) **开集安全退化**：U_nov 未消解且无合法支持集时，逐指令退化为 R69 保守路径。

**定义 311（开集新颖性 OSN）** 设表征 z = Φ(o)，校准集为训练分布内的留出观测。新颖分 s(o) = d_kNN(z, 𝒟_train) + β·(−log p_θ(ξ_obs|o))（复用 R69 的 FMA 似然项）。共形 p 值 p(o) = (1 + #{i : s_i ≥ s(o)}) / (n+1)，定义 **U_nov := 1 − p(o)**。它是"该观测不属于训练流形"的分布无关证据强度；U_nov ≥ 1−α 即判为表外候选（引理 19 给出误报率 ≤ α）。

**定义 312（三分解）** U = (U_ale, U_epi, U_nov)，三者语义不同、分通道处置、不做简单加和：
- U_ale（模态内噪声，不可约）→ R68 的 λ floor；
- U_epi（表内歧义，可问）→ R69 的 MINT/VoI 交互；
- U_nov（表外缺失，问不出）→ FLORA 的 FSA 学习或保守退化。
关键命题：**U_epi 的交互对 U_nov 无效**——在错误假设空间里做最优实验设计，期望信息增益上界为 0（引理 20 系）。

**定义 313（支持集与来源证书 SPC）** 支持集 S = {(o_i, ξ_i, w_i, prov_i)}。prov_i 含来源模态、时间戳、R69 证据纪律结果、签名哈希。S 合法 ⇔
(a) 正交来源数 ≥ k_src；
(b) 留一稳定性 stab(S) = 1[移除任一示范不改变适配后模态集] ≥ 1−δ；
(c) 最大影响力 I_max(S) = max_i ‖Δ(o; S) − Δ(o; S∖i)‖ ≤ ε_inf；
(d) 新鲜度 age(S) ≤ ttl 且未被 AIC 标记。
不合法 ⇒ 不学习，U_nov 保持未消解。

**定义 314（少样本获取算子 FSA，双轨）** 对合法 S：
(a) **原型轨**：ℳ ← ℳ ∪ {φ(ξ_S)}，φ 为冻结特征，插入 O(d)、查询 O(log|ℳ|)；
(b) **低秩轨**：θ' = θ + Δ，Δ = argmin_Δ Σ_i ‖f_{θ+Δ}(o_i) − ξ_i‖² + λ‖Δ‖²，在特征层有闭式解，且投影到信任域 ‖Δ‖_F ≤ ε_tr。
热环只做 (a) 的最近原型查询与 (b) 的前向；梯度/闭式求解都在冷路径。

**定义 315（校准债 CDL）** 适配后模态权重与真实后验的偏移记为校准债 D_cal(t+1) = γ·D_cal(t) + ECE_{heldout}(ŵ)（γ<1 为自然衰减）。λ 附加保守税：λ ← λ + g(D_cal)，g 单调、g(0)=0。只有用独立留出流完成重校准且 D_cal ≤ τ_debt 时，适配才被视为"全额可信"；否则按债务比例降权。

**定义 316（计算动作与 VoC）** 计算动作 c ∈ 𝒞（多采 1 个样本、再跑一次流似然、重估 ECE、跑一次影子 rollout），时间成本 t(c) 可测。VoC(c) = E[U_before] − E[U_after(c)]，以"每毫秒降熵"计。联合调度：在预算 B 下选 (g, c) 最大化 VoI(g) + VoC(c) − λ_t·(cost(g) + t(c))，s.t. 总时间 ≤ B 剩余。**VoI 问世界，VoC 问自己；两者共用同一条延迟预算。**

**定义 317（认证序贯采样 CSS）** 第 n 个样本后，用 anytime 有效的经验 Bernstein 置信序列给出每个模态权重的 [lo_k(n), hi_k(n)]（覆盖概率 ≥ 1−δ 对所有 n 同时成立）。停止规则三选一：
(i) 某模态 lo_k > max_{j≠k} hi_j（决策已定，certified gap > 0）；
(ii) 边际 VoC(再采一个) ≤ 0；
(iii) 到达 deadline。
返回样本集与证书；未定则 U_epi 取置信上界而非点估计。R69 的固定 K∈{1,4} 是"关闭 CSS、只允许两个 n"的退化。

**定义 318（延迟契约与单调降级 LAS）** 设剩余预算 L。调度器只接受 t(c) ≤ L 的动作，并预留回退动作的认证时间。若预算不足，降级序列为：完整 R69 → 仅 K=1 → 仅当前模态 → R68 纯保守，且 λ 沿序列**单调不降**。因此"没算完"只会更保守，不会更冒险。

**定义 319（热插拔认证 HSC）** 新版本 (ℳ', θ') 上线需同时满足：
(a) 信任域 ‖Δ‖ ≤ ε_tr 或 KL(π'‖π) ≤ ε_kl；
(b) 在独立影子流上 N_shadow 步无安全包络越界；
(c) P99 延迟基准 ≤ L_max；
(d) 原子换装于 tick 边界，保留旧版本与证书，可在 1 个 tick 内回滚。
继承 R68 定理 15 的提交/换装不变式。

**定义 320（开集退化 / R69 边界）** 若 U_nov ≤ τ_nov（表内）、支持集为空或非法、且预算充足（关闭 CSS 自适应），则 FLORA 的决策与 λ **逐指令等于 R69**。故 R69 是 FLORA 在"封闭世界 + 不学习 + 固定算力"边界上的严格退化。

**定义 321（模态保留守卫 MRG）** 将安全关键模态（碰撞/越界/急停/人因相关）标记为 pinned。MRG 约束：任何适配、淘汰、原型合并都不得使 pinned 集合的覆盖下降；记忆容量满时只淘汰非 pinned 中影响力最小者。持续学习允许忘记，但不允许忘记"保命"。

**定义 322（对抗少样本 ℰ_fewshot）** 投毒示范、后门原型、幻影模态注入、自我确认攻击（用被污染支持集反过来认证自己）、校准债耗尽攻击（持续小幅漂移使保守税失真）、延迟 DoS（诱导昂贵路径造成 deadline miss）。并入 AIC：ℰ_FLORA = ℰ_FLUID × ℰ_fewshot。

**定义 323（证书 J_FLORA）** J_FLORA = (J_FLUID, U_nov, p_conformal, support_provenance_hash, I_max, adapter_ver, trust_region, latency_p99, deadline_miss_rate, D_cal, pinned_coverage)。Valid ⇔ Valid(J_FLUID) ∧ 支持集合法 ∧ HSC 通过 ∧ 延迟契约满足 ∧ pinned_coverage = 1。

**定义 324（参与式审计 VQAuditor-F）** 新增审计项：适配依据（支持集来源、影响力、是否自我确认）、延迟事件（deadline miss、降级次数）、校准债轨迹、回滚事件、pinned 覆盖。结论回灌 AuditBuf，作为下一轮 OSN 阈值、FSA 信任域与 LAS 预算的先验。

# IP-264 OSN：共形开集新颖性（复用 R69 z 与 FMA 似然）
class ConformalNovelty:
    def score(self, o, z, policy):
        return knn_dist(z, self.train_index) + BETA * flow_residual(policy, o)
    def unov(self, o, z, policy):
        s = self.score(o, z, policy)
        p = (1 + count_ge(self.calib_scores, s)) / (len(self.calib_scores) + 1)
        return 1.0 - p

# IP-265 FSA：少样本获取（原型轨 + 闭式低秩轨）
def acquire(support, theta, eps_tr, memory, adapter):
    if not certify_support(support):                    # IP-266 SPC
        return None
    proto = mean(feature(xi) for xi in support)          # O(d) 插入
    memory.insert(proto)
    if adapter.enabled:
        Delta = ridge_closed_form(adapter.feats(support),
                                  adapter.targets(support), lam=adapter.lam)
        Delta = project_ball(Delta, eps_tr)              # 信任域
        adapter.set(theta + Delta)                       # 冷路径
    return memory, adapter

# IP-266 SPC：支持集来源与影响证书
def certify_support(S):
    return (n_orthogonal_sources(S) >= K_SRC
            and leave_one_out_stability(S) >= 1 - DELTA_LOO
            and max_influence(S) <= EPS_INF
            and freshness(S) <= TTL
            and not aic.flagged(S))

# IP-267 LAS：VoC / VoI 联合调度（anytime、硬 deadline）
def schedule(U, g_candidates, o, budget):
    while budget.remaining() > MIN_T:
        g = best_info_action(g_candidates, o)            # R69 MINT
        c = best_compute_action(U, budget.remaining())   # 采样/似然/ECA/影子
        voi = 0 if g is None else voi_of(g, o) - cost(g)
        voc = 0 if c is None else voc_of(c, U) / t(c)
        if max(voi, voc) <= 0: break
        if voi >= voc and g is not None: execute(g); budget.spend(cost(g))
        else: execute(c); budget.spend(t(c))
    return budget

# IP-268 CSS：认证序贯采样，决策一定就停
def sample_until_certified(policy, o, delta, L):
    xs, n = [], 0
    while True:
        xs.append(policy.sample(o, 1)); n += 1
        lo, hi = confidence_sequence(xs, delta)          # anytime-valid
        if decided(lo, hi): return xs, "certified"
        if voc_one_more(xs) <= 0: return xs, "no_value"
        if remaining_time() <= MIN_T: return xs, "deadline"   # 降级

# IP-269 HSC：影子认证 + 原子换装 + 回滚
def hot_swap(M_old, M_new, budget):
    if not in_trust_region(M_new, M_old) or not pinned_ok(M_new): return M_old
    if not shadow_rollout_safe(M_new, N_SHADOW):                  return M_old
    if benchmark_p99(M_new) > L_MAX:                              return M_old
    return atomic_swap(M_new, rollback=M_old)                     # tick 边界

# IP-275 FLORA 主闭环（继承 R69，仅在"模态表是否可信"处插入 FLORA 层）
def FLORA_round(M, obs):

    c, U_cal, thr = M.cof.step(...)                       # R68 标定
    # 1) 先问：我的模态表对吗？（开集门，O(1) 级）
    u_nov = M.osn.unov(o, z, M.fmp)
    if u_nov > TAU_NOV:
        S = M.buffer.certified_support(o)
        if S is None or not M.spc.certify_support(S):
            return R69_conservative(M, o, U_cal + u_nov)  # 无合法示范：不学，退化
        M2 = M.fsa.acquire(S, M.fsa.theta, EPS_TR, M.memory, M.adapter)
        M = M.hsc.hot_swap(M, M2, M.budget)               # 认证失败则保持 M
        U_epi = u_nov if M is old else 0.0                # 只有换装成功才消解
    # 2) R69 表内路径：认证序贯采样（anytime，替代固定 K）
    xs, cert = M.css.sample_until_certified(M.fmp, o, DELTA, M.budget.remaining())
    U_ale, U_epi, modes = M.aud.decompose(xs)
    # 3) 剩余预算在"问世界"与"问自己"之间分配
    M.las.schedule((U_ale, U_epi, u_nov), M.mint.candidates(modes), o, M.budget)
    # 4) 风险缩放：aleatoric + 未消解 epistemic + 校准债
    lam = max(M.efs.risk_scale(...),
              lam_floor(U_ale + U_epi_unresolved) + g_debt(M.cdl.debt))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if cert == "deadline": lam = max(lam, LAMBDA_DEGRADE)  # 单调降级
    # 5) 执行 + 审计 + 证书
    mode = select_mode(modes, lam); tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_f.submit_async(u_nov, S, M.cdl.debt, cert, M.budget.events)
    return k, lam, mode, (U_ale, U_epi, u_nov)
```

## 3. 推导

**引理 19（共形开集覆盖）** 对与校准集可交换的分布内观测，P(U_nov(o) ≥ 1−α) ≤ α。即"把正常样本误判为表外"的概率不超过 α，有限样本、无分布假设。系：U_nov 不是启发式分数，而是可出具误报率证书的门；τ_nov = 1−α 直接对应安全预算，可与 R69 的 ECE 门并列进入 J_FLORA。

**引理 20（表内交互对表外无效）** 设真实模态 m* ∉ ℳ。任何仅在 ℳ 上定义的信息动作 g 的条件分布 p(y|g,o) 与 m* 独立，故 I(m*; y | g) = 0，且 argmax_g VoI(g) 的增益对 U_nov 的上界为 0。系：这是 R69 的结构性盲点——**问得越努力，越可能把 m* 投影成某个 m_k 并高置信地确认它**。FLORA 必须先做开集判定，再决定"问"还是"学"。

**引理 21（少样本适配的风险界）** 设适配类为信任域内低秩修正族，有效维度 d_eff，支持集 |S| = m。则相对基座策略的期望超额风险满足
R(θ') − R(θ) ≤ ε_tr·L + O(√(d_eff·log m / m)) + g(D_cal)，
其中 L 为损失对参数的 Lipschitz 常数。系：**少样本可行的前提是 d_eff 小，而不是 m 大**——这正好与低延迟同向：低秩适配器既降低样本需求，又降低推理/换装成本；反之，全参数微调既费样本又费毫秒。

**引理 22（投毒影响界与自我确认破除）** 在 SPC 的留一影响约束 I_max ≤ ε_inf 与 k 正交来源多数一致（各源欺骗相关 ρ<1）下，单个投毒示范对最终模态决策的改变量 ≤ ε_inf，且错误采纳率 ≤ δ_p·ρ^{k−1} + ε_σ（沿用 R69 引理 18）。进一步，若 HSC 的影子认证流与被适配支持集**独立**，则"被投毒支持集自我认证成功"的概率 ≤ δ_shadow，与投毒者能否构造支持集无关。系：**认证证据源必须与学习证据源物理隔离**，否则再强的上界也会被自我确认绕开。

**引理 23（序贯采样的期望延迟）** 在模态可分（间距 Δ、内方差 σ²）时，经验 Bernstein 置信序列使停止时间满足 E[n] ≤ C·log(1/δ)/Δ²（C 为常数）；当 Δ 大（决策清晰）时 E[n] → 1，显著小于 R69 固定 K=4。且因覆盖对所有 n 同时成立，早停不牺牲校准性。系：**低延迟与可信模态权重不是取舍，而是同一置信证书的两面**——这也正面回应 R69"模态权重不可信"的最大风险。

**定理 18（FLORA 严格包含 R69）** 在 A99–A102 下，FLORA 的期望风险 ≤ R69；且当 U_nov ≤ τ_nov、支持集为空或非法、关闭 CSS 自适应、预算充足时，两者**逐指令相同**（定义 320）。因此 R69 是 FLORA 在"封闭世界 + 不学习 + 固定算力"边界上的退化：安全侧不作任何让步，效率侧获得开集能力与更低的常规延迟。

**定理 19（硬实时与单调降级）** LAS 在任意 tick 返回前必执行一次 O(1) 的可行性检查与回退认证，故对任意计算动作序列，返回动作的时间 ≤ L_max（w.p. 1）；预算越少，可用样本越少、U_epi 置信上界越大、λ 越大，故降级序列上 λ 单调不降。结合 R68 定理 15 的换装不变式 ⇒ 控制连续、无安全突变。

**定理 20（适配安全与无灾难更新）** HSC 通过信任域 + 独立影子认证 + 延迟基准 + 原子换装回滚，保证换装前后安全包络不变；未通过则保持旧版本，等价于"本次不学"。MRG 钉住安全关键模态使其覆盖不随适配下降，故在安全维度上灾难性遗忘概率为 0；非安全维度的遗忘由回放缓冲与校准债上界约束。

## 6. 本轮最大风险

**一句话**：FLORA-RAS 把"学习"压到几次示范、把"生效"压到一个 tick，也就把"一条被投毒示范被自我认证、并快速扩散成新模态"的延迟压到了最低——**学得快，同样意味着错得快；低延迟把审计窗口也一起压没了。**

**次级风险与缓解**：
1. **自我确认污染**（被污染支持集反过来认证自己）→ 认证流与支持集物理隔离 + 留一影响界 + 独立来源签名；
2. **校准债累积**（持续适配使权重校准过期）→ 显式 D_cal 记账 + 保守税 + 定期独立重校准；
3. **灾难性遗忘安全模态** → MRG 钉住集 + 回放缓冲 + pinned 覆盖硬约束；
4. **延迟压力下的危险早停**（在最该多想的地方省算力）→ CSS 只允许在"决策已定或边际价值为零"时停，deadline 只触发单调降级而非降低认证；
5. **开集误报导致频繁无效适配** → 共形误报率证书 + 支持集门槛 + HSC 失败即保持旧版本（不学的代价有界）。

    u_nov = M.osn.unov(o, z, M.fmp)                         # 1) 表对不对？
    if u_nov > TAU_NOV:
        S = M.buffer.certified_support(o)
        if S is None or not M.spc.certify_support(S):
            return R69_conservative(M, o, U_cal + u_nov)    # 不学，退化
        M2 = M.fsa.acquire(S, M.fsa.theta, EPS_TR, M.memory, M.adapter)
        M = M.hsc.hot_swap(M, M2, M.budget)
        U_epi = 0.0 if M is not M2_old else u_nov
    xs, cert = M.css.sample_until_certified(M.fmp, o, DELTA, M.budget.remaining())
    U_ale, U_epi, modes = M.aud.decompose(xs)
    M.las.schedule((U_ale, U_epi, u_nov), M.mint.candidates(modes), o, M.budget)
    lam = max(M.efs.risk_scale(...),
              lam_floor(U_ale + U_epi_unresolved) + g_debt(M.cdl.debt))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if cert == "deadline": lam = max(lam, LAMBDA_DEGRADE)
    mode = select_mode(modes, lam); tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_f.submit_async(u_nov, S, M.cdl.debt, cert, M.budget.events)
    return k, lam, mode, (U_ale, U_epi, u_nov)
```

## 4. 推导

**引理 19（共形开集覆盖）** 对可交换分布内观测，`P(U_nov ≥ 1−α) ≤ α`。故 `τ_nov = 1−α` 是可出具误报率证书的门，可与 ECE 门并列进入 J_FLORA。

**引理 20（表内交互对表外无效）** 若 `m* ∉ ℳ`，任何仅在 ℳ 上定义的信息动作满足 `p(y|g,o)` 与 `m*` 独立，`I(m*; y|g)=0`，故 `argmax_g VoI(g)` 对 U_nov 的增益上界为 0。系：R69 会高置信地把 `m*` 投影成某个 `m_k`；必须先开集判定，再问/学。

**引理 21（少样本适配风险界）** `R(θ') − R(θ) ≤ ε_tr·L + O(√(d_eff·log m / m)) + g(D_cal)`。系：**d_eff 小才是少样本可行的关键**，与低延迟同向——低秩适配器同时省样本、省毫秒；全参数微调两头都亏。

**引理 22（投毒影响界与自我确认破除）** 在 `I_max ≤ ε_inf` 与 k 正交来源（ρ<1）下，单毒示范对决策改变 ≤ `ε_inf`，错误采纳率 ≤ `δ_p·ρ^{k−1}+ε_σ`；若影子认证流与支持集独立，则自我认证成功率 ≤ `δ_shadow`。系：**认证证据源必须与学习证据源物理隔离**。

**引理 23（序贯采样期望延迟）** 可分模态下 `E[n] ≤ C·log(1/δ)/Δ²`；Δ 大时 `E[n]→1`，远小于固定 K=4，且覆盖对所有 n 同时成立，早停不损校准。系：低延迟与可信模态权重是同一置信证书的两面。

**定理 18（FLORA 严格包含 R69）** A99–A102 下期望风险 ≤ R69；当 `U_nov ≤ τ_nov`、支持集空/非法、关闭 CSS 自适应、预算充足时两者**逐指令相同**。R69 = 「封闭世界 + 不学习 + 固定算力」边界；安全不让步，效率获开集能力与更低常规延迟。

**定理 19（硬实时与单调降级）** 每次 tick 必做 O(1) 可行性与回退认证，故返回时间 ≤ L_max（w.p. 1）；预算越少 ⇒ 样本越少 ⇒ U_epi 置信上界越大 ⇒ λ 越大，降级序列 λ 单调不降；结合 R68 换装不变式 ⇒ 控制连续、无安全突变。

**定理 20（适配安全与无灾难更新）** HSC 的信任域 + 独立影子认证 + 延迟基准 + 原子换装回滚保证安全包络不变；失败即保持旧版（等价"本次不学"）。MRG 使 pinned 覆盖不随适配下降 ⇒ 安全维度灾难性遗忘概率为 0。

## 7. 本轮最大风险

**一句话**：FLORA-RAS 把"学习"压到几次示范、把"生效"压到一个 tick，也就把"一条被投毒示范被自我认证、并快速扩散成新模态"的延迟压到了最低——**学得快，同样意味着错得快；低延迟把审计窗口也一起压没了。**

**次级风险与缓解**：自我确认污染（认证流与支持集物理隔离 + 留一影响界 + 来源签名）；校准债累积（显式记账 + 保守税 + 定期独立重校准）；灾难性遗忘安全模态（MRG 钉住 + 回放 + pinned 覆盖硬约束）；延迟压力下的危险早停（CSS 只在决策已定/边际价值为零时停，deadline 只单调降级）；开集误报致频繁无效适配（共形误报率证书 + 支持集门槛 + HSC 失败即保持旧版）。
