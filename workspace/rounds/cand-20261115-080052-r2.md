# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环本轮第 2 轮；本轮灵感：「避障控制」×「差异化定位」）

> R69 教会系统「问」，但它问世界时，**自己站在哪儿仍然是一个点**。整个 FLUID 层默认位姿由前端给出一个均值（外加一个协方差），于是「动作多峰」被认真对待，「位置多峰」却被悄悄压平：走廊对称时它在两个完全相反的位置上都可能是自己；玻璃反光时它把三米外的自己当成一米内的自己；对手用一次 UWB/GNSS 欺骗就能把它整体平移两米；被绑架之后它仍会自信地输出一个低协方差。**R69 说「问错比不问更危险」；R70 要说「定位错了却以为自己知道，比不知道更危险」。**
>
> 本轮两个灵感正好从上下两端把它夹住：
> - **避障控制**给出安全侧的硬纪律：安全集必须对**所有尚未被反驳的位姿假设**取交集，语义/权重/置信度都不能单独把约束放松；CBF-QP 的每一条约束属于一个「可能的自己」。
> - **差异化定位**给出效率侧的钥匙：位姿不确定性不是均匀的标量。两个相差 2cm 的位姿，在空旷走廊里对避障完全等价，在门框阈值处却是「过」与「撞」的分界。因此定位必须被**差异化**：不是一个均值加一个方差，而是一组带出处、带年龄、带安全后果的假设；只有**会改变避障动作的歧义**才值得花预算，只有**尚未被两个正交见证退休**的假设才保留约束。
>
> 核心命题：**用「差异化位姿假设账本」取代「单点位姿 + 协方差膨胀」；用「安全同伦商」把位姿空间按避障谓词分成决策等价类；用「全假设鲁棒 CBF-QP」保证不过期的安全下界；用「主动视差」只消解会改变动作的歧义，且任何消歧机动本身必须对全部假设安全；当假设覆盖或商的有效性不可信时，合并为单一最坏单元，逐指令退回 R69 的保守闭环。** 命名 **PRISM-RAS**（Pose-Relevance Interval Safety Margins：位姿相关性区间安全边际）。棱镜的隐喻正是「差异化」：一束白光（一个位姿信念）被安全谓词分成不同颜色（不同后果的等价类），不是所有颜色都值得看，但所有颜色都必须先被算进安全。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我到底在哪儿——以及，‘在哪儿’这件事，对这个具体的障碍和这个具体的动作，究竟重不重要**」。

## 0. 直觉与动机

**灵感 1（单点位姿 + 协方差是「均匀化的谎言」）**
直觉：一个全局定位系统在对称走廊里可能同时相信自己在 A 点和 B 点，二者相距两米；把它压成一个均值，会得到「在 A 与 B 中点」这个**从未存在过的自己**。为了覆盖两个模态，协方差必须膨胀到米级；于是系统在空旷处也以为处处危险，寸步难行。反过来，若只保留均值加一个小协方差，则 B 点那个真模态被彻底抹掉，系统会按 A 点的安全证明通过一个实际会撞的通道。**协方差膨胀要么过保守（效率死），要么欠保守（安全死），因为它强行把「多峰」说成「单峰但很胖」。** 正确对象不是更胖的椭圆，而是一组**分立假设及其安全后果**。

**灵感 2（避障控制 → 安全是对假设取交，不是对标签取信）**
直觉：控制屏障函数（CBF）给的是「存在一个使 h(x)≥0 的前向不变集」。当 x 本身不确定时，正确的鲁棒化不是把 x 换成均值，而是要求**对每一个仍可能的 x 都满足约束**：`∀ i: L_f h_i + L_g h_i u + α h_i ≥ 0`。这与 R69 的「不确定性不只是刹车踏板」形成对照：R69 用 λ 缩放**动作**，R70 用约束交集守卫**状态**。避障的特殊性在于它只关心**符号与同伦类**——撞不撞、从哪一侧绕——而不关心位姿的毫米级精度。这个观察是整轮的支点。

**灵感 3（差异化定位 → 按「安全后果」商掉位姿空间）**
直觉：给定当前障碍集 O 与候选机动 u，每个位姿假设 h 产生一对标签：安全边际的符号/桶（会不会撞）与同伦类（从哪边过）。若两个假设给出相同标签，它们在**这次避障决策**上就是等价的，无论它们在欧氏空间里相距多远。于是我们不再对 10⁴ 个粒子求交，而对商空间 `H / ~_u` 求交；典型场景只剩 1–3 个真正相关的等价类。**「差异化定位」的第一层含义：不同位姿假设按其对动作的后果被区别对待；第二层含义：不同证据源按失败模式被区别对待（绝对定位/相对里程/地图匹配/学习前端各自带健康度）；第三层含义：定位预算按「是否会改变动作」差异化分配，而不是按全图熵。** 顺带一句双关：本轮的研究定位也要差异化——不去继续卷「更强的交互」，而是补 R69 一直踩在脚下的那块地。

**灵感 4（主动视差 → 移动本身就是一种定位动作）**
直觉：人看不清自己在哪时，不会原地提高采样率，而会**走两步换个视角**：侧移产生视差、回转打破对称、后退暴露新地标。视差（parallax）本质就是「差异化定位」的物理实现——同一个世界在不同观察位置上呈现不同投影，差异越大，位置越可辨。但机器人不能像人一样随便走：**消歧机动本身必须对全部未退休假设安全**。于是「好奇」被关进「安全」的笼子：可以为了看清而移动，但不能为了看清而撞上任何一个可能的自己。这也给出一个漂亮的否定判据：若两个假设对所有小机动都产生几乎相同的观测（感知混叠），则视差信息增益≈0，此时**不该动，应该退回最坏情况保守**——这与 R69 引理 16「模糊而不可分时交互无益」是同一条纪律。

**灵感 5（证据纪律 → 低权重假设可以少花预算，但绝不能被少算安全）**
直觉：R69 的模态权重可以驱动 VoI，因为选错动作只是选错一次。位姿不同：一个权重 0.1% 的假设若正好落在门框另一侧，它决定的不是「这次绕左还是绕右」，而是「撞不撞」。因此必须立一条反直觉的铁律：**权重只影响预算与计算顺序，绝不影响安全交集**；只有「被两个正交见证正式退休」的假设才能移出交集。这防止两类灾难：把低概率真模态当噪声删掉；被单源欺骗（伪造 GNSS/UWB）用一个「高置信」假位姿把真位姿退休掉。

**灵感 6（与 R69 的关系 → 单胞退化，安全不让步）**
直觉：若账本里只有一个假设，或所有假设落在同一个安全等价类，PRISM 的商空间退化为一个单元，鲁棒 CBF 退化为普通 CBF，主动视差因决策相关质量≈0 而不触发——**逐指令等价于 R69 的几何避障路径**。若假设集覆盖可信，PRISM 只是在同一安全下界上换来了更紧的边际（少停、能过）；若覆盖不可信、商过期、预算超限或被洪水攻击，则合并为单一最坏单元并调用 R69 的 λ_floor 保守闭环。理论姿态延续 R68→R69：**新层必须是旧层的严格泛化，安全侧永不弱于旧层。**

## 1. 形式化定义（增量：定义 310–326）

**定义 310（PRISM-RAS 总览）** PRISM-RAS = (DPL, SHQ, RSM, DRB, APA, TWE, RAS-WM‡)。继承 R69 定义 293 的实时零学习写操作、交互预算与证据纪律，新增五条不变式：
(i) **安全对假设取交**：认证只依赖几何/动力学与所有**未退休**位姿假设，权重、置信度、语义标签均不得单独放松约束；
(ii) **权重不豁免安全**：ŵ_i 只决定计算顺序与预算分配，不决定是否进入交集；
(iii) **商的局部性**：安全等价类只在「当前障碍集 × 当前承诺视界 × 当前机动族」内有效，带版本与有效期 τ_q，过期即重算或退化；
(iv) **退休需双见证**：任一假设的退休至少需要两个失败模式正交的证据源一致，单源（含单次外部定位）不得退休；
(v) **消歧机动受全假设安全约束**：任何为获取信息而执行的机动，必须先对全部未退休假设通过鲁棒安全认证。

**定义 311（差异化位姿账本 DPL）** 维护假设集 `H_t = {h_i}`，`h_i = (T_i, w_i, s_i, a_i, ϑ_i, e_i)`：位姿 `T_i ∈ SE(3)`、权重 `w_i≥0`、来源向量 `s_i`（绝对外感受 / 相对本体 / 地图匹配 / 学习前端）、年龄 `a_i`、健康度 `ϑ_i`、证据哈希 `e_i`。前端只允许**增加假设、重加权、标记退休**，禁止把多个假设融合成单点后删除原假设。`Σ_i w_i = 1` 仅在预算分配时使用。

**定义 312（避障谓词与安全签名）** 给定障碍表示 O、机身足迹 B、候选机动 `u ∈ U` 与承诺视界 H，假设 h 下的安全边际
`μ_h(u) = min_{t∈[0,H]} dist( T_h ⊕ x_body(t;u), O )`，
同伦类 `κ_h(u)` 表示轨迹从障碍的哪一侧/哪个通道通过。安全签名
`σ_h(u) = ( ⌊μ_h(u)/ε_m⌋, κ_h(u) )`，
其中 ε_m 为边际分辨率。签名只保留「会不会撞」与「从哪边过」，主动丢弃与避障无关的毫米级位姿差异。

**定义 313（安全同伦商 SHQ）** 在固定 (O, u, H, ε_m) 下定义等价关系
`h_i ~_u h_j ⇔ σ_{h_i}(u) = σ_{h_j}(u)`，
商空间 `Q_u = H_unretired / ~_u`。类内任取代表元即可确定该类对本次避障的符号与同伦决策；类间签名不同者才进入鲁棒交集。商不是永久对象：障碍移动超过 δ_O、机动离开当前同伦类、或超过 τ_q，即 `stale`，必须刷新。

**定义 314（差异化鲁棒安全边际 RSM）** 鲁棒 CBF-QP：
```
u* = argmin_u  ||u − u_ref||² + λ_amb · U_loc^dec(u)
     s.t.  ∀ h_i ∈ H_unretired :
           L_f h_i + L_g h_i u + α( h_i − ε_safe − δ_i ) ≥ 0
```
其中 `δ_i = δ(ϑ_i, a_i, s_i) ≥ 0` 是**差异化膨胀**：来源越不可信、年龄越大，膨胀越大——但只能**增加**边际，永不减少。为免枚举全部假设，对每个等价类用代表元加 Lipschitz 半径给出**区间下界**：
`LB(Q) = μ_rep − L_μ · diam(Q)`；
只有 `LB` 可能成为全局最小值的类才精算，其余被**认证剪枝**。剪枝是精确的，不是近似：被剪掉的类不可能改变最小边际的符号。

**定义 315（决策相关定位不确定性）** 令 `σ*` 为当前主导动作的签名，定义
`U_loc^dec(u) = Σ_i w_i · 1[σ_{h_i}(u) ≠ σ*(u)]`。
它度量的是「会改变避障决策的位姿质量」，而不是 `tr(Σ)` 或位姿熵。系：位姿在自由空间里飘 10cm 可以 `U_loc^dec=0`；在门框处飘 1cm 也可能 `U_loc^dec≈1`。**真正该花预算的定位不确定性，是决策相关的那一部分。**

**定义 316（歧义税与差异化预算 DRB）** 规划代价 `J(u) = E_{h}[cost(u;h)] + λ_amb·U_loc^dec(u) + compute(u)`。交互/传感预算按边际安全收益分配：优先给 `U_loc^dec` 最大的等价类，而不是给位姿熵最大的区域。预算与 R69 的 MINT 共享；若位姿歧义的安全影响大于动作歧义，则先执行 APA，本轮不再向世界提问。

**定义 317（主动视差 APA）** 候选消歧机动 `g ∈ G`（小幅侧移、慢速回转、后退、外置视角请求、短暂停车多帧），信息增益以**签名空间**而非位姿空间定义：
`IG(g) = H(σ | o) − E_{y~p(·|g,o)}[ H(σ | o,y) ]`。
选择 `g* = argmax_g [ IG(g) − c(g) ]`，约束：预算允许、`∀ h_i: μ_{h_i}(u⊕g) ≥ ε_safe + δ_i`。若检测到感知混叠（两假设对所有 `g∈G` 的观测分布 KL ≤ ε_ali），则 `IG≈0`，不机动，直接走最坏情况保守。

**定义 318（双见证退休 TWE）** 假设 h 的退休证书 `R(h) = (w_a, w_b, e_a, e_b)` 需满足：`w_a, w_b` 属于正交证据类（如外感受绝对定位 vs 本体里程残差，或两种失败模式不重叠的外感受模态），二者独立地否定 h 且一致；欺骗相关性 ρ<1。单源、单次外部定位、R69 的单次交互回答均不足以退休。未退休假设即使权重极低也保留在安全交集中。

**定义 319（位姿第二意见 PLC）** 复用 R69 的对偶思想：地图匹配残差 `r_map` 只能说明「与地图自洽」，不能排除地图/定位被整体欺骗；因此增加独立通道 `Δp = ‖T_map − T_dead‖_Σ + |a_score(o) − a_score(o_cal)|`（含 R69 的流似然项）。`(r_map↓, Δp↑)` 是「定位被平滑/被欺骗/被绑架」的判别性联合模式，类比 R68→R69 的 `(r_res↓, Δa↑)`。

**定义 320（快照、年龄与商的生命周期 LSR）** 控制读不可变快照 `snap_t`；语义/定位更新异步写入下一版本。断言年龄 `a_i > τ_age` 时其膨胀 δ_i 单调增大；商带 `(version, O_hash, u_family, τ_q)`，任何一项变化即失效。过期商只能用于解释，不能用于放宽第一步的硬安全约束。

**定义 321（覆盖门 CCG）** 用 split conformal 给出假设集覆盖保证：`P( T_true ∈ ∪_i cell(h_i) ) ≥ 1−α`。覆盖未过门（前端漏模态、绑架、分布外、在线校准漂移）时，禁止使用商与 APA，全部假设合并为单一最坏单元（取并集包围盒 + 最大膨胀），逐指令退回 R69 保守闭环。**商能省的是计算，不能省的是覆盖。**

**定义 322（AIC-PRISM 威胁模型）** `ℰ_PRISM = ℰ_FLUID × ℰ_alias × ℰ_spoof × ℰ_flood`：感知混叠（对称走廊、重复纹理、玻璃反射）、单源欺骗（GNSS/UWB/视觉标签伪造）、重放与地图投毒、以及**假设洪水**（攻击者注入大量看似合理的假设，撑爆商的计算或迫使系统永远保守停车）。威胁模型的目标不是「不被骗」，而是**被骗的方向有界**：注入假设只会让系统更保守；想扩大安全集必须攻破双见证与覆盖门。

**定义 323（证书 J_PRISM）** `J_PRISM = (J_FLUID, hypothesis_coverage, quotient_version_hash, min_margin_lb, decision_relevant_mass, retired_set_hash, apa_log_hash, spoof_score, prism_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ coverage ≥ 1−α ∧ quotient_not_stale ∧ 双见证退休完整 ∧ 计算预算未越界`。

**定义 324（参与式审计 VQAuditor-L）** 审计对象新增定位决策：低权重假设是否被错误删除、单源是否退休过假设、商是否在承诺视界外被复用、消歧机动是否只对相关类做了安全认证、假设洪水是否触发降级。结论回灌 AuditBuf，成为下一轮 DRB 的成本先验。

**定义 325（严格包含与共享预算）** 若 `|H|=1` 或 `|Q_u|=1`，PRISM 逐指令退化为 R69：无 APA、无歧义税、`λ` 与 R69 相同。若覆盖门失败、商过期、或假设洪水导致 `|Q_u|` 超预算，则 `H ← hull(H)` 单胞化并执行 R69 的 `λ_floor` 保守路径。R69 是 PRISM 在「单位姿/单胞」边界上的严格退化。

**定义 326（实时时序与自适应分辨率）** 默认 `ε_m` 粗、商类数 ≤3、APA 候选 ≤6、单步前瞻；仅当 `U_loc^dec > TAU_LOC` 且安全边际接近阈值时升 `ε_m` 并做两步前瞻。分辨率本身是「安全分辨率 vs 实时预算」的折中，保证 P99 不击穿 R69 的 2.6ms 环路。

# IP-264 DPL：差异化位姿账本（只增删假设，不压成点）
class DifferentiatedPoseLedger:
    def __init__(self, sources):
        self.H = []                                  # h=(T,w,srcs,age,health,hash)
        self.sources = sources

    def update(self, obs):
        fresh = []
        for s in self.sources:                       # 绝对/相对/地图/学习前端
            fresh += s.hypotheses(obs)
        self.H = merge_same_provenance(self.H, fresh) # 同源合并，异源并存
        for h in self.H:
            h.age += 1
            h.inflate = delta(h.health, h.age)       # 只增不减
        return self.H

    def retire(self, h, wa, wb):                     # IP-269 双见证退休
        if orthogonal(wa, wb) and agree(wa, wb, h):
            h.retired = True
            self.audit.log_retirement(h, wa, wb)

# IP-265 SHQ + IP-266 RSM：安全同伦商 + 区间下界鲁棒边际
def safety_signature(h, u, O, eps_m):
    mu = min_signed_distance(h.T, body, u, O)
    return (floor(mu / eps_m), homotopy_class(h.T, body, u, O))

def robust_margin(H, u, O, eps_m, L_mu):
    cls = group_by(H, lambda h: safety_signature(h, u, O, eps_m))
    best = +inf
    for Q in sorted(cls, key=class_lower_bound):      # 按区间下界升序
        lb = class_margin_rep(Q) - L_mu * radius(Q)
        if lb > best:
            continue                                  # 认证剪枝：不可能改变 min
        for h in Q:
            best = min(best, margin(h, u, O))         # 只在相关类内精算
    return best

# IP-267/268 DRB + APA：决策相关质量与主动视差
def decision_relevant_mass(H, u, O, eps_m):
    sig = {h: safety_signature(h, u, O, eps_m) for h in H}
    dom = majority_signature(sig)
    return sum(h.w for h in H if sig[h] != dom)

def choose_parallax(H, u, O, budget, eps_m):
    best = None
    for g in parallax_candidates(H):                  # 侧移/回转/后退/停车多帧
        if not budget.allow(g):
            continue
        ug = compose(u, g)
        if robust_margin(H, ug, O, eps_m) < EPS_SAFE:
            continue                                  # 消歧机动须对全假设安全
        ig = signature_entropy(H, ug) - expected_signature_entropy(H, ug)
        if perceptual_aliasing(H, g):
            ig = 0.0                                  # 混叠不可分：不动
        score = ig - cost(g)
        if best is None or score > best.score:
            best = (g, score)
    return best if best and best.score > 0 else None

## 3. 推导

**引理 19（安全同伦商的压缩正确性）** 在 A99（边际对位姿 `L_μ`-Lipschitz）与 A101（类直径 ≤ `d_max`）下，对任意等价类 `Q_u`，`LB(Q_u)=μ_rep−L_μ·diam(Q_u)` 是类内真实最小边际的**严格下界**；若 `LB(Q_u)` 大于当前已算出的全局最小边际，则 `Q_u` 不可能改变鲁棒约束的符号与同伦决策。故按 `LB` 升序的认证剪枝**不改变**安全判定，只减少精算次数。系：计算量从 `O(|H|)` 降到 `O(|Q_u|)`，而 `|Q_u|` 由障碍几何与同伦结构决定，通常 ≤3，与粒子数无关。

**引理 20（区间商对高斯膨胀的支配）** 设位姿信念含两个相距 Δ 的模态、模态内标准差 σ_in。任何覆盖两模态的单峰高斯在置信 1−α 下需 σ_G ≥ c·Δ；它在自由空间给出的边际下界比真实最坏边际小 `Ω(Δ)`，造成不必要的减速。区间商保留真实最坏边际，同时不覆盖不存在的「中间自己」。在 A99–A101 下，存在势函数使 `μ_true ≥ μ_interval ≥ μ_Gaussian`：**PRISM 在自由空间更不保守、在安全边界同样保守**。这就是 resolution bonus 的来源，而不是放松安全。

**引理 21（视差可辨识性）** 若两假设 `h_i,h_j` 对机动族 G 中所有 g 的观测分布满足 `KL(p(y|g,h_i) ‖ p(y|g,h_j)) ≤ ε_ali`，则任意 `g∈G` 的签名空间信息增益 `IG(g) ≤ ε_ali`，主动视差无益，必须退回最坏情况保守；反之若存在 g 使该 KL ≥ κ，则有限次查询即可把二者分入不同签名类。系：**可辨识性由视差几何决定，不由位姿熵决定**——混叠场景下「多走两步」可能完全无用，此时正确动作是停，而不是探。

**引理 22（双见证退休的欺骗上界）** 设单源欺骗率 δ_p、两见证失败相关性 ρ<1，则单源退休的错误率 ≥ δ_p；双正交见证一致退休的错误率 ≤ `δ_p·ρ + ε_σ`。系：R69 的「单次交互不得定案」在位姿层升级为「单个定位源不得退休假设」；这堵住了「伪造一个高置信位姿、把真位姿从交集里删掉」的扩集攻击。

**定理 18（PRISM 严格包含 R69）** 在 A99–A102 下：
(i) 若 `|H|=1` 或 `|Q_u|=1`，PRISM 的鲁棒边际、风险缩放与动作选择逐指令等于 R69；
(ii) 若覆盖门通过，PRISM 的鲁棒安全下界不弱于 R69 的单点+膨胀方案；
(iii) 若覆盖失败/商过期/洪水超预算，PRISM 合并为单胞并执行 R69 的 `λ_floor` 保守路径。
故 R69 是 PRISM 在「单位姿/单胞」边界上的严格退化，安全侧不做让步。

**定理 19（消歧机动安全与无突变）** 若 APA 的候选机动 `g` 通过 `∀h_i∈H_unretired: μ_{h_i}(u⊕g) ≥ ε_safe+δ_i`，则执行 g 不降低任何未退休假设下的安全下界；退休只经双见证，故 h 不会因一次信息动作被误删；消歧失败/超时/混叠时 `λ` 单调不降地退回 R69。结合 R69 定理 17 的提交/换装不变式，控制连续、无突变。

**定理 20（假设洪水与投毒的方向有界性）** 注入额外假设只能使 `Q_u` 变大、鲁棒边际不增，故攻击者可造成的是**可用性损失（保守停车/计算超时）**，不可能单靠注入扩大安全集；要扩大安全集必须退休真假设，须同时攻破两个正交见证与覆盖门，其概率由引理 22 与 CCG 上界控制。故 PRISM 的威胁面是**有方向**的：被骗只会更慢，不会被骗着撞。

## 6. 本轮最大风险

**一句话**：PRISM 的安全性完全押在「真位姿始终落在未退休假设集内，且安全等价类在承诺视界内不过期」这两条上——**一旦定位前端漏掉真模态（绑架、感知混叠、单源欺骗）或障碍演化使旧商失效，系统就会对错误的假设集合求交，并以「已认证」的姿态撞上那个它从未考虑过的自己**；覆盖门和双见证只能把这种失败压成可声明的小量，不能把它变成零。

**次级风险与缓解**：
1. **假设洪水撑爆实时预算** → 认证剪枝 + 类数上限 + 洪水即触发单胞降级（定理 20，方向有界：只会更慢）；
2. **商在动作后过期** → 商带版本/有效期，第一步硬安全始终用全假设 hull 认证（定义 320、定理 19）；
3. **低权重真模态被误删** → 权重不豁免安全 + 双见证退休 + 审计（定义 310-ii、318）；
4. **主动视差本身诱发危险** → 全假设 CBF 认证后才允许执行（定义 317、定理 19）；
5. **覆盖门漂移（conformal 校准过期）** → 在线覆盖监控 + 年龄膨胀 + 越界即退回 R69 纯保守（定义 321）。

## 2. 形式化定义（要点版）

**定义 310（总览与五不变式）** 安全对假设取交；权重不豁免安全（只影响预算/顺序）；商只在「障碍 × 视界 × 机动族」内局部有效；退休需两个正交见证；消歧机动须先通过全假设安全认证。

**定义 311（DPL）** 维护 `H_t={h_i}`，前端只增假设、重加权、标退休，禁止融合成点后删除原假设；`w_i` 只在预算分配时使用。

**定义 312–313（签名与 SHQ）** `σ_h(u)=(⌊μ_h/ε_m⌋, κ_h(u))`；按签名相等求商 `Q_u`；障碍移动 >δ_O、离开同伦类或超过 τ_q 即 stale。

**定义 314（RSM）** `u*=argmin ‖u−u_ref‖²+λ_amb U_loc^dec`，s.t. 对每个未退休 h：`L_f h_i+L_g h_i u+α(h_i−ε_safe−δ_i)≥0`；用 `LB(Q)` 升序做认证剪枝，剪掉的类不可能改变最小边际符号。

**定义 315–316（决策相关质量与预算）** `U_loc^dec(u)=Σ_i w_i·1[σ_i(u)≠σ*(u)]`；预算按边际安全收益分配；与 R69 的 MINT 共享，位姿歧义的安全影响更大时先执行 APA。

**定义 317（APA）** 候选 `g∈G`（侧移/回转/后退/停车多帧/外置视角），`g*=argmax[IG(g)−c(g)]`，s.t. 预算与全假设安全；感知混叠时 `IG≈0`，不机动、走最坏情况保守。

**定义 318–319（TWE 与 PLC）** 退休需两个失败模式正交的见证一致；`(r_map↓, Δp↑)` 是绑架/欺骗/被平滑的判别模式。

**定义 320–321（快照生命周期与覆盖门）** 控制读不可变快照；年龄越大膨胀越大；conformal 覆盖不过门即单胞化回退 R69，商只能用于解释、不能用于放宽第一步硬约束。

**定义 322–324（威胁/证书/审计）** `ℰ_PRISM=ℰ_FLUID×ℰ_alias×ℰ_spoof×ℰ_flood`；J_PRISM 并入覆盖、商哈希、边际下界、决策相关质量；VQAuditor-L 审定位决策。

**定义 325–326（严格包含与时序）** 单位姿/单胞 → 逐指令等于 R69；覆盖失败/商过期/洪水超预算 → 单胞化 + R69 `λ_floor`；默认粗分辨率、类数 ≤3、候选 ≤6，仅歧义路径升分辨率/两步前瞻。

def robust_margin(H, u, O, eps_m, L_mu):
    cls = group_by(H, lambda h: (floor(min_dist(h.T,body,u,O)/eps_m),
                                 homotopy_class(h.T,body,u,O)))
    best = +inf
    for Q in sorted(cls, key=class_lower_bound):
        if class_lower_bound(Q) > best:                 # 不可能改变 min
            continue
        for h in Q:
            best = min(best, min_dist(h.T, body, u, O))
    return best

def decision_relevant_mass(H, u, O, eps_m):
    sig = {h: signature(h, u, O, eps_m) for h in H}
    dom = majority_signature(sig)
    return sum(h.w for h in H if sig[h] != dom)

def choose_parallax(H, u, O, budget, eps_m):

        ug = compose(u, g)

## 4. 推导

**引理 19（安全同伦商的压缩正确性）** A99（边际对位姿 L_μ-Lipschitz）+ A101（类直径 ≤ d_max）下，`LB(Q)=μ_rep−L_μ·diam(Q)` 是类内真实最小边际的严格下界；若 `LB(Q)` 大于当前全局最小边际，则 Q 不可能改变鲁棒约束的符号与同伦决策。按 `LB` 升序剪枝不改变安全判定，只把计算量从 `O(|H|)` 降到 `O(|Q_u|)`，典型 `|Q_u|≤3` 且与粒子数无关。

**引理 20（区间商对高斯膨胀的支配）** 两模态相距 Δ、模态内标准差 σ_in 时，覆盖两模态的单峰高斯在置信 1−α 下需 σ_G ≥ c·Δ，它在自由空间的边际下界比真实最坏边际小 `Ω(Δ)`，导致不必要减速；区间商保留真实最坏边际且不覆盖「从未存在的中间自己」。A99–A101 下 `μ_true ≥ μ_interval ≥ μ_Gaussian`：自由空间更不保守、安全边界同样保守，resolution bonus 来自更紧的认证下界而非放松约束。

**引理 21（视差可辨识性）** 若两假设对 ∀g∈G 的观测分布 `KL ≤ ε_ali`，则签名空间 `IG(g) ≤ ε_ali`，主动视差无益，必须退回最坏情况保守；反之若 ∃g 使 `KL ≥ κ`，有限次查询即可分离。可辨识性由视差几何决定，不由位姿熵决定。

**引理 22（双见证退休上界）** 单源欺骗率 δ_p、两见证失败相关性 ρ<1 时，单源退休错误率 ≥ δ_p，双正交见证一致退休错误率 ≤ `δ_p·ρ+ε_σ`。R69 的「单次交互不得定案」在位姿层升级为「单个定位源不得退休假设」，堵住「伪造高置信位姿、把真位姿从交集删掉」的扩集攻击。

**定理 18（严格包含 R69）** A99–A102 下：(i) `|H|=1` 或 `|Q_u|=1` 时逐指令等于 R69；(ii) 覆盖门通过时鲁棒安全下界不弱于 R69 单点+膨胀；(iii) 覆盖失败/商过期/洪水超预算时单胞化并执行 R69 `λ_floor`。R69 是 PRISM 的「单位姿/单胞」严格退化。

**定理 19（消歧机动安全与无突变）** APA 机动通过全假设认证后不降低任何未退休假设下的安全下界；退休只经双见证，不会因一次信息动作误删；失败/超时/混叠时 λ 单调不降退回 R69；继承 R69 定理 17 的提交/换装不变式，控制连续无突变。

**定理 20（洪水与投毒方向有界）** 注入假设只使 `|Q_u|` 增大、鲁棒边际不增，攻击者能造成的是可用性损失（保守停车/超时），不能单靠注入扩大安全集；扩大安全集须退休真假设，须同时攻破两个正交见证与覆盖门，概率由引理 22 与 CCG 控制。故威胁面有方向：**被骗只会更慢，不会被骗着撞**。

## 7. 本轮最大风险

**一句话**：PRISM 的安全性完全押在「真位姿始终落在未退休假设集内，且安全等价类在承诺视界内不过期」这两条上——**一旦定位前端漏掉真模态（绑架、感知混叠、单源欺骗）或障碍演化使旧商失效，系统就会对错误的假设集合求交，并以「已认证」的姿态撞上那个它从未考虑过的自己**；覆盖门与双见证只能把这种失败压成可声明的小量，不能把它变成零。

**次级风险与缓解**：假设洪水撑爆实时预算（认证剪枝 + 类数上限 + 洪水即单胞降级，方向有界：只会更慢）；商在动作后过期（版本/有效期 + 第一步始终用全假设 hull 认证）；低权重真模态被误删（权重不豁免安全 + 双见证退休 + 审计）；主动视差诱发危险（全假设 CBF 认证后才执行）；conformal 覆盖漂移（在线覆盖监控 + 年龄膨胀 + 越界即退回 R69 纯保守）。
