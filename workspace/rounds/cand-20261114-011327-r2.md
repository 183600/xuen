# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「多传感器融合」×「面部表情识别」）

> R69 问出「我该向谁求证、还能问什么」，并用一条证据纪律兜底：**单次交互/单模态不得定案，需 k 个正交证据源一致**。但这条纪律悄悄假设了三件在真实系统里几乎从不成立的事：
> 1. **见证者独立**——可传感器共享标定、时钟、供电、物理通道、模型权重。三个共用坏标定的摄像头会「完美一致」。**相关的一致不是证据，是共因伪装成的共识**；R69 的 k-一致纪律会在共因最强时给出最高置信，这是一个灾难性的反向。
> 2. **见证者同时**——传感器速率/延迟差几个数量级。把陈旧读数当作当前读数融合，会制造**幽灵一致**：两个源一致，只因为它们都在描述同一个过去。
> 3. **见证者回答同一个问题**——几何传感器回答「在哪/是什么」，面部表情回答「这个人感觉如何/想做什么」。**笑不是安全证书**；把情绪证据直接接到安全命题上是范畴错误。
>
> 本轮两个灵感刚好逐条补洞：
> - **多传感器融合**：真正的问题不是「再加一个传感器」，而是「**认证独立性、溯源、时序与语义**」。它同时送来一个新的信息动作——**主动感知**（换视角/曝光/采样率/传感器子集）：以前只能问人，现在可以问世界。
> - **面部表情识别**：它是软社会传感器的原型——低可靠、高语义、可掩饰、可伪装、跨文化漂移。它只能充当**经桥接校准的意图先验**，可以抢占一次昂贵的提问，但永远不能单独签发安全证书。
>
> 核心命题：**把 R69 的「名义正交」升级为「认证的有效独立」（`k_eff`）；把「证据源」从标量通道升级为带溯源、时效与语义类型的图节点；把表情作为显式桥接、欺骗折价、永不定案的意图先验；把主动感知纳入同一 VoI 预算。** 命名 **MOSAIC-RAS**（Multi-source prOvenance-aware Semantic-Aware Independence-Certified RAS）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**这些见证者真的在独立见证——还是在重复同一个错误？**」

## 0. 直觉与动机

**灵感 1（多传感器融合 → 融合的敌人是相关性，不是噪声）**
直觉：人们默认「多一个传感器多一份保险」。但只要两个源的误差来自同一个源头（同一块标定板、同一个时钟、同一条供电、同一款模型、同一个物理扰动），它们的「一致」在信息上约等于**一个**源说了两遍。用等相关模型量化：k 个等方差、两两误差相关 ρ 的源，融合后的有效样本量是 `k_eff = k / (1 + (k−1)ρ)`；ρ→0 时退化为 k，ρ→1 时坍缩为 1。这直接改写 R69 的证据纪律：**要求的是 `k_eff ≥ 2`，不是 `k ≥ 2`**。三个亲戚互相作证不算三方独立作证。

**灵感 2（多传感器融合 → 不同时的证据不是同一个命题）**
直觉：融合发生在「决策时刻」，但每个读数属于它自己的**测量时刻**。快传感器的当前值、慢语义传感器的旧值，不能当作同一瞬间的联合观测。若忽略时效，两个陈旧源会因为指向同一个过去而「一致」——这是**幽灵一致**。正确做法是给每个证据一个有效期区间与陈旧衰减，只在有效期与决策时刻重叠时融合。

**灵感 3（面部表情识别 → 语义鸿沟，必须先架桥）**
直觉：表情测的是**内部状态**，不是外部世界。从「嘴角上扬」到「此人愿意配合」再到「此刻安全」，中间是两层推断，每一层都有基率与文化先验。R69 把 `r_emo` 当作与 `r_geo` 并列的残差通道，这在形式上抹掉了这个鸿沟。本轮要求：所有证据节点带**语义类型**（PHYSICAL / AFFECT / CONTEXT），跨类型必须先经一座**校准过的语义桥**；桥不存在或未校准时，系统**拒绝融合**（abstain），而不是硬接。

**灵感 4（面部表情识别 → 表情是软的、可操纵的，信任必须分区）**
直觉：人会礼貌地笑、会掩饰恐惧、会按社交剧本表演；还会因口罩、光照、文化差异让解码器系统性偏移。因此表情的可信度不能是一个固定权重，而要区分**自主通道**（摆出的表情、口头回答）与**非自主通道**（微表情泄漏、眨眼率、韵律、注视回避、生理信号）。欺骗分 = 两通道的发散；信任折价 `γ_d = 1/(1+κ·d)`。单靠自主通道，永远不能把证据权重推高到「可定案」。

**灵感 5（融合 → 新的信息动作：主动感知；也是两个灵感的交汇点）**
直觉：R69 的信息动作是看/问/触。融合补上第四类：**换传感器**——换视角、换曝光、提高采样率、选一个子集去「验一验」。这让 VoI 有了第二个执行器：问人贵，问世界便宜。表情先验恰好可以**抢占**一次昂贵提问（意图已足够确定且被非自主通道佐证），或在表情「自相矛盾」时**抬高**提问的 VoI。问世界与问人共享同一套安全认证与交互预算。

**灵感 6（严格泛化姿态 → R69 是 ρ=0、无陈旧、单语义、表情关闭的边界）**
直觉：若证据图只有一个节点，或所有源真独立（ρ=0）、严格同时、语义全对齐、表情关闭，则 MOSAIC 逐指令退化为 FLUID-RAS；再令 VoI≤成本即退化为 R68。任何一项认证失败都只能**降级**（MOSAIC→FLUID→R68），不能升级。这条单调退避是整轮的安全底线。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（MOSAIC-RAS 总览）** MOSAIC-RAS = (SEG, EID, TAF, SAB, AER, DDT, CCF, MINT-F, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **认证独立性 + 时效 + 语义**：只有 `k_eff ≥ 2`、有效期与决策时刻重叠、且语义桥已校准的证据才可参与定案；
(iii) **表情永不定案**：AFFECT 类证据只能更新意图先验与交互需求，不能单独提升任何安全命题的置信，不能签发证书；
(iv) **问世界与问人同预算**：主动感知 `g_sense` 与 `g_ask` 共享 R69 的交互预算与 C-RAS-WM 认证。

**定义 311（传感器证据图 SEG）** 决策时刻 t 的证据图 G_t = (V, E)。节点 v = (id, sensor_type, semantic_type, p_v, t_meas, τ_valid, calib_lineage, model_hash, value, uncertainty)，其中 semantic_type ∈ {PHYSICAL, AFFECT, CONTEXT}，p_v 是该节点所主张的命题。边类型：SHARED_CALIB、SHARED_CLOCK、SHARED_PHYSICAL_PATH、SHARED_MODEL、CAUSAL。`calib_lineage` 记录标定来源与版本，是共因推断的结构依据。

**定义 312（有效独立性 EID 与 k_eff）** 源误差 e_i 的相关阵 R（在给定共因路径条件下估计，而非名义独立）。有效样本量 `k_eff(S) = 1ᵀ R_S^{-1} 1`（单位方差归一化）；等相关特例 `k_eff = k/(1+(k−1)ρ)`。证据纪律升级为 **`k_eff(S) ≥ 2`**：名义 k 再多，只要共因把 k_eff 压到 1，就只算一个见证者。R69 的 `k ≥ 2` 是 ρ=0 的边界。

**定义 313（时序有效性与陈旧衰减 TAF）** 节点有效期 [t_meas, t_meas+τ_valid)。陈旧权重 `w_stale(τ) = exp(−λ_s·τ)`，τ = t − t_meas。仅当有效区间的重叠覆盖决策时刻且重叠比例 ≥ 1−τ_c 时才允许融合；相关性按重叠比例折减。**陈旧的证据只能削弱、不能增强**关于当前的断言（防重放/幽灵一致）。

**定义 314（语义对齐桥 SAB）** 决策命题 P 与节点命题 p_v 的语义对齐 `α(v,P) ∈ [0,1]`；跨 semantic_type 时需显式桥 `p(P | v)` 且其校准误差 ECE_bridge ≤ τ_α。`α < α_min` 或桥未校准 ⇒ 该节点对 P 的贡献置零。**类别错误守卫**：AFFECT 不能不经桥直接佐证 PHYSICAL 安全命题（「笑 ≠ 路清」）。

**定义 315（表情证据读取 AER）** 面部输入 → 动作单元强度 a_t（FACS）、valence/arousal，以及解码分布 q(a | image)（异方差、遮挡感知、口罩/光照显式入模）。输出：`p_affect(intent | a, context, display_rule)`。不确定性二分：aleatoric（模糊/遮挡）、epistemic（跨文化/OOD 身份/罕见表情）。频率受限（≤30Hz）、异步、**永不进入快速安全回路的门控路径**。

**定义 316（显示规则与欺骗模型 DDT）** 自主通道 v（摆出的表情、口头回答）与非自主通道 u（微表情泄漏、眨眼率、韵律、注视回避、瞳孔/生理）。欺骗分 `d = JS(v ‖ u)`；信任折价 `γ_d = 1/(1+κ·d)`，并叠加文化/显示规则先验 g_c。**单靠自主通道不得把任何证据权重推过定案阈值**。

**定义 317（共因失效监测 CCF）** 残差共动统计：共模指数 `CMI(S) = 第一公共因子解释的残差方差比例`。CMI 高 ⇒ **下调**一致性权重（相关一致被当作一个见证者），而非上调。这是对 R69「数源」直觉的正面反转。

**定义 318（信任加权融合 TWF）** 每个命题的对数几率按权重累加：`w(v) = independence(v) · freshness(v) · α(v,P) · γ_d(v) · (1−ECE_v)`；融合后置信设硬上限，除非有独立佐证不得越过定案阈值。融合是可审计的线性/证据推理过程，不引入新的不可解释黑箱。

**定义 319（主动感知动作 g_sense）** 增广动作扩展为 `ξ = (a, g_gaze, g_probe, g_ask, g_sense)`，其中 `g_sense = (传感器子集, 视角, 曝光, 采样率, 停留)`。`g_sense` 必须过 C-RAS-WM（换视角可能移动本体），并计入同一交互预算。

**定义 320（VoI 融合控制 MINT-F）** `g* = argmax_{g ∈ g_sense ∪ g_ask} [VoI_k(g) − c(g)]`。VoI 在**融合后信念 + k_eff 折减**下计算：`VoI_k(g) = H(M|o) − E[H(M|o,y)] / max(k_eff,1)`。问世界与问人是同一预算下的可互换候选；无利可图即退化为 FLUID 的纯保守。

**定义 321（表达-意图先验门 AIG）** 当 `p_affect` 高置信、`d` 低、且至少一条非自主通道佐证时，可用表情先验**抢占**一次 g_ask（省预算）；当自主/非自主通道冲突时，**抬高** g_ask 的 VoI。边界：AIG 只能移除一次「交互」，**永不能移除一次安全检查**。

**定义 322（语义级联拒绝 ACG）** 当语义类型不匹配且无已校准桥时，系统**拒绝融合**（abstain），U_epi 标记为未消解并走 R69/R68 兜底。「拒绝融合」是一等动作，等价于承认「这些证据说的不是同一件事」。防的是自信的范畴错误。

**定义 323（参与式审计 VQAuditor-F）** 审计对象新增：证据图溯源是否正确、k_eff 估计是否偏移、陈旧/重放是否被误当新鲜、语义桥是否被投毒、欺骗折价是否被绕过、被抢占的提问是否本应发生。结论回灌 AuditBuf，成为下一轮先验。

**定义 324（MOSAIC 干扰集 ℰ_MOSAIC）** `ℰ_MOSAIC = ℰ_FLUID × ℰ_common × ℰ_stale × ℰ_semantic × ℰ_affect`：共因/相关故障；陈旧与重放；语义桥投毒与范畴错误；掩饰、伪装、跨文化错配与遮挡。并入 AIC 做对抗训练。

**定义 325（证书 J_MOSAIC 与严格退避）** `J_MOSAIC = (J_FLUID, graph_hash, k_eff, max_staleness, α_min, deception_score, affect_bridge_ece, preempt_count)`。Valid ⇔ Valid(J_FLUID) ∧ `k_eff ≥ 2`（或已 abstain）∧ 时效达标 ∧ 语义对齐 ∧ 表情非唯一源。退化链：任一认证失败 ⇒ 降级为 FLUID；VoI≤成本/ECE 越界 ⇒ 降级为 R68。安全侧永不弱于上一轮。

# IP-264 SEG：建证据图（溯源/时效/语义三分）
def build_evidence_graph(obs, calib):
    V = [Node(id=v.id, semantic_type=type_of(v), p_v=claim(v),
              t_meas=v.t, tau_valid=v.tau, value=v.x,
              calib_lineage=calib.lineage(v), model_hash=v.model_hash)
         for v in obs]
    E = infer_common_causes(V, calib)      # 共享标定/时钟/通道/模型
    return Graph(V, E)

# IP-265/313 EID：有效独立 + 陈旧折减（替代 R69 的「数源」）
def effective_independence(G, t):
    R   = error_correlation(G, condition_on=common_causes(G))
    R   = R * freshness_overlap(G, t, tau_c=TAU_C)   # 不同时 → 相关折减
    k_e = 1.0.T @ inv(R + EPS * eye(len(R))) @ 1.0   # = k/(1+(k-1)rho)
    return k_e, R

# IP-266 CCF：共模指数；高则「一致」降权
def common_mode_index(residuals):
    return explained_variance_first_factor(residuals)  # 0..1

# IP-268 AER：表情 → 意图先验（异方差 + 遮挡/文化/OOD）
def read_affect(face_crop, context, display_rule):
    qa   = face_model(face_crop)          # AU + valence/arousal + 置信
    ua   = qa.aleatoric                   # 模糊/遮挡
    ue   = qa.epistemic                   # 跨文化/OOD/罕见表情
    p    = bridge(qa, context, display_rule)   # p(intent|a)，须已校准
    return p, ua, ue

# IP-269 DDT：自主 vs 非自主通道；欺骗折价
def deception_score(voluntary, involuntary):
    d  = js_divergence(voluntary, involuntary)      # 微表情/韵律/注视/生理
    return d, 1.0 / (1.0 + KAPPA * d)               # gamma_d ∈ (0,1]

# IP-271 MINT-F：主动感知 + 提问共享预算，VoI 按 k_eff 折减
def choose_action(belief, G, budget, t):
    k_e = effective_independence(G, t)[0]
    best = None
    for g in info_sensors(G) + ask_candidates(belief):  # 问世界 + 问人
        if not budget.allow(g) or not c_ras_wm.certify(g, t): continue
        voi   = entropy(belief) - expected_entropy(belief, g, t) / max(k_e, 1.0)
        score = voi - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-272 AIG：表情只可抢占「是否提问」，不可抢占「是否检查安全」
def affect_gate(p_affect, d, support, ask_voi):
    if p_affect.confident and d < TAU_D and support >= 1:
        return ('preempt_ask', ask_voi * 0.0)      # 省预算，但不省安全检查
    if support == 0 and p_affect.high_entropy:
        return ('raise_ask', ask_voi * 1.5)        # 自相矛盾 → 更该问
    return ('neutral', ask_voi)

# IP-275 主闭环：R69 流程外挂融合层，认证失败即降级
def MOSAIC_round(M, obs):
    G = build_evidence_graph(obs, M.calib)
    # 1) 表情先验（异步、出快环）
    prior, ua, ue = (M.aer.read(obs.face, obs.context)
                     if M.aer.enabled else (None, 0.0, 0.0))
    if prior is not None:
        d, gamma   = M.ddt.score(prior.voluntary, prior.involuntary)
        support    = M.ddt.nonvoluntary_support(obs)
        prior      = temper(prior.p, gamma, display_rule=obs.culture)
    # 2) R69：流策略 + 不确定性二分（不变）
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(obs, K), z, M.fmp.mode_head)
    # 3) 融合认证：独立 + 时效 + 语义；不达标就拒绝融合
    k_e, R = effective_independence(G, obs.t)
    status = certify(G, k_e, obs.t, alpha_min=ALPHA_MIN)
    if status is ABSTAIN:
        return M.fluid_fallback(obs, U_ale, U_epi)   # 降级，不硬接
    belief = M.twf.fuse(G, modes, prior, weights_of(R, obs.t))
    # 4) 问世界 or 问人（同一预算）；表情只调节提问需求
    g = choose_action(belief, G, M.budget, obs.t)
    g = apply_affect_gate(g, prior, d, support) if prior is not None else g
    if g is not None:
        answer = M.cia.execute(g)                     # 看/问/触/换传感器
        belief = M.cia.update(belief, answer, discipline='k_eff>=2')
    # 5) 风险缩放 + 安全前缀（继承 R69/R68）
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_mode(modes, belief, lam)
    # 6) 审计 + 证书
    M.vqa_f.submit_async(G, k_e, d, g, prior)
    return k, lam, mode, (U_ale, U_epi, k_e)

## 3. 推导

**引理 19（有效独立性 / 设计效应）** k 个单位方差源、等误差相关 ρ，最优线性融合的信息量为 `1ᵀR^{-1}1 = k/(1+(k−1)ρ)`。故名义「k 源一致」相对真实独立的置信被高估因子 `1+(k−1)ρ ≥ 1`；ρ→1 时 k_eff→1，一致不提供任何新信息。**系**：R69 的证据纪律必须改写成 `k_eff ≥ 2`；在共因最强的场景，R69 反而最自信——这是它最危险的失效方向。（一般相关阵用 `1ᵀR_S^{-1}1`。）

**引理 20（陈旧幽灵一致）** 设源 i 的年龄为 τ_i，可靠性按 `exp(−λ_s τ_i)` 衰减。两个源可以仅因共享同一个过去而一致，其对当前命题的虚假置信增益为 `O(λ_s·τ_c)`。**系**：只在有效期重叠覆盖决策时刻时融合；陈旧证据对当前断言只能降权，不能增权——这与「多源必然更好」的直觉相反。

**引理 21（语义桥 / 范畴错误）** 设安全命题 P、表情证据 A。若缺少已校准桥，直接用 `p(intent|A)` 佐证 P，在基率偏移下后验可能朝错误方向移动（桥的敏感性/特异性被基率压过）。**系**：表情只能作为「是否需要提问」的先验，不能作为「是否安全」的证据；跨类型必须先过桥并校 ECE，否则 abstain。

**引理 22（欺骗折价上界）** 自主通道可被对手以有限预算操纵；非自主通道泄漏与操纵的相关为 ρ_u<1。采用信任折价 `γ_d` 后，单靠自主通道的操纵成功率 ≤ `δ·(1−ρ_u)^{m}`，且权重被硬上限截断。**系**：R69 的「k 个正交源」若全为自主通道，则正交性被对手一并伪造（共谋），必须由非自主通道或物理源提供真正独立的一票。

**定理 18（MOSAIC 严格包含 FLUID/R68）** 在 ρ=0、无陈旧、α=1、表情关闭的退化极限下，MOSAIC 与 FLUID 逐指令相同；一般情形下，MOSAIC 只在认证通过时获得不低于 FLUID 的证据增益，认证失败时 abstain（更保守）。故任意状态的期望风险 ≤ FLUID ≤ R68，且 R69/R68 是 MOSAIC 的边界。安全侧不做任何让步。

**定理 19（主动感知的贪心保证）** 在给定假设 M 下传感器观测条件独立时，`I(M; Y_S)` 对子集 S 单调子模，贪心传感器调度达到 `(1−1/e)` 最优 VoI；加入 k_eff 折减只对所有增益乘一个与 S 无关的常数，子模性保持。**系**：问世界与问人共享预算后，表情先验抢占一次提问所省下的预算，可以再投资给一次主动感知，二者在期望上不冲突。

## 6. 本轮最大风险

**一句话**：MOSAIC 的安全性压在「我们能正确估计有效独立性 ρ_eff 与语义桥」之上——**若共因结构估错（把真独立当相关→过度保守、把同源故障当独立→假确定性），或表情桥被文化/欺骗系统性偏移，系统会在最需要证据时把信任给错**；校准「相关性」比校准传感器更难，因为错误的相关性只在故障发生那一刻才暴露。

**次级风险与缓解**：
1. **k_eff 低估/高估** → E302 在线校准 + 保守先验（宁可少算独立）+ 审计回灌；
2. **语义桥投毒** → SAB ECE 门控 + ℰ_semantic 对抗训练 + 桥版本哈希入证据图；
3. **表情隐私与伦理** → 表情仅用于意图先验、永不定案、可关闭、审计留痕；
4. **异步表情拖慢快环** → AER/DDT 全异步旁路，快环只读缓存先验；
5. **过度保守导致不可用** → 以 abstain/降级为安全侧，效率收益只在认证通过时兑现，并由 E310/E311 量化拐点。

# IP-264 SEG + IP-265/313 EID：建图 + 有效独立 + 陈旧折减
def build_evidence_graph(obs, calib):
    V = [Node(v.id, type_of(v), v.t, v.tau, calib.lineage(v), v.model_hash, v.x)
         for v in obs]
    return Graph(V, infer_common_causes(V, calib))

def effective_independence(G, t):
    R   = error_correlation(G, condition_on=common_causes(G))
    R   = R * freshness_overlap(G, t, TAU_C)        # 不同时 → 相关折减
    k_e = 1.0.T @ inv(R + EPS * eye(len(R))) @ 1.0  # = k/(1+(k-1)rho)
    return k_e, R

# IP-266 CCF：共模高 → 一致降权
def common_mode_index(residuals):
    return explained_variance_first_factor(residuals)

# IP-268 AER + IP-269 DDT：表情先验 + 欺骗折价
def read_affect(face, context, display_rule):
    qa = face_model(face)                           # AU + valence/arousal
    return bridge(qa, context, display_rule), qa.aleatoric, qa.epistemic

def deception_score(voluntary, involuntary):
    d = js_divergence(voluntary, involuntary)
    return d, 1.0 / (1.0 + KAPPA * d)

# IP-271 MINT-F：问世界 + 问人共享预算，VoI 按 k_eff 折减
def choose_action(belief, G, budget, t):
    k_e = effective_independence(G, t)[0]
    best = None
    for g in info_sensors(G) + ask_candidates(belief):
        if not budget.allow(g) or not c_ras_wm.certify(g, t): continue
        score = (entropy(belief)
                 - expected_entropy(belief, g, t) / max(k_e, 1.0)
                 - cost(g))
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None       # 无利可图 → FLUID

# IP-272 AIG：表情只抢占提问，不抢占安全检查
def affect_gate(p_affect, d, support, ask_voi):
    if p_affect.confident and d < TAU_D and support >= 1:
        return ask_voi * 0.0          # 省预算
    if support == 0 and p_affect.high_entropy:
        return ask_voi * 1.5          # 自相矛盾 → 更该问
    return ask_voi

# IP-275 主闭环：认证失败即降级，不硬接
def MOSAIC_round(M, obs):
    G = build_evidence_graph(obs, M.calib)
    prior, ua, ue = (M.aer.read(obs.face, obs.context)
                     if M.aer.enabled else (None, 0.0, 0.0))
    if prior is not None:
        d, gamma = M.ddt.score(prior.voluntary, prior.involuntary)
        support  = M.ddt.nonvoluntary_support(obs)
        prior    = temper(prior.p, gamma, obs.culture)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4

    k_e, R = effective_independence(G, obs.t)
    if certify(G, k_e, obs.t, ALPHA_MIN) is ABSTAIN:
        return M.fluid_fallback(obs, U_ale, U_epi)          # 降级，不硬接
    belief = M.twf.fuse(G, modes, prior, weights_of(R, obs.t))
    g = choose_action(belief, G, M.budget, obs.t)
    g = apply_affect_gate(g, prior, d, support) if prior is not None else g
    if g is not None:
        belief = M.cia.update(belief, M.cia.execute(g), discipline='k_eff>=2')
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_mode(modes, belief, lam)
    M.vqa_f.submit_async(G, k_e, d, g, prior)
    return k, lam, mode, (U_ale, U_epi, k_e)

## 4. 推导

**引理 19（有效独立性 / 设计效应）** 单位方差、等误差相关 ρ 的 k 源，最优线性融合信息量 `1ᵀR^{-1}1 = k/(1+(k−1)ρ)`；名义独立高估因子 `1+(k−1)ρ`。ρ→1 ⇒ k_eff→1。**系**：R69 的 `k≥2` 改为 `k_eff≥2`；共因最强时 R69 最自信，是危险的反向。

**引理 20（陈旧幽灵一致）** 源年龄 τ_i、可靠性 `exp(−λ_s τ_i)`；两源仅因共享同一过去而一致的虚假置信增益为 `O(λ_s τ_c)`。**系**：仅有效期覆盖决策时刻才融合；陈旧证据只能削弱当前断言。

**引理 21（语义桥 / 范畴错误）** 无校准桥时用 `p(intent|A)` 佐证安全 P，在基率偏移下后验可朝错误方向移动。**系**：表情只作「是否需要提问」的先验；跨类型须过桥并校 ECE，否则 abstain。

**引理 22（欺骗折价上界）** 自主通道被操纵率 δ、非自主泄漏相关 ρ_u<1 时，信任折价后单自愿源操纵成功率 `≤ δ(1−ρ_u)^m`，且权重被硬上限截断。**系**：若「k 个正交源」全为自主通道，正交性可被共谋一并伪造。

**定理 18（MOSAIC 严格包含 FLUID/R68）** ρ=0、无陈旧、α=1、表情关闭时逐指令相同；一般情形只在认证通过时获得不低于 FLUID 的证据增益，失败时 abstain 更保守。任意状态期望风险 ≤ FLUID ≤ R68。

**定理 19（主动感知贪心保证）** 条件独立下 `I(M;Y_S)` 对 S 单调子模，贪心调度达 `(1−1/e)` 最优；k_eff 折减只是全局常数，子模性保持。**系**：表情抢占省下的提问预算可再投给主动感知，期望上不冲突。

## 7. 本轮最大风险

**一句话**：MOSAIC 的安全性压在「我们能正确估计有效独立性 ρ_eff 与语义桥」之上——**若共因结构估错（真独立当相关→过度保守、同源故障当独立→假确定性），或表情桥被文化/欺骗系统性偏移，系统会在最需要证据时把信任给错**；校准「相关性」比校准传感器更难，因为错误的相关性只在故障发生那一刻才暴露。

**次级风险与缓解**：k_eff 估偏（E302 在线校准 + 保守先验 + 审计回灌）；语义桥投毒（ECE 门控 + ℰ_semantic 对抗训练 + 桥版本哈希）；表情隐私伦理（仅作意图先验、永不定案、可关闭、留痕）；异步表情拖慢快环（AER/DDT 全异步旁路）；过度保守（abstain/降级为安全侧，效率收益仅在认证通过时兑现，E310/E311 量化拐点）。
