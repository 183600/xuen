### 第 4 轮灵感驱动研究记录

**灵感词**：主动交互、阻抗控制

**承接**：第 3 轮 KT-MPC（IEKC ∪ CTKTP ∪ AKWA ∪ KTCG）把常识从「静态包容」推进到「可解释-可迁移-可自适应」。但它仍把常识写成标量代价 W_kc(x)=Σ_i λ_i(1-c_i)σ_i，把交互写成「传感器先给、控制器后算」的单向流程。

**直觉与动机**：

1. **常识不是墙，而是阻抗**。硬约束把安全边界当不可穿越的墙；软惩罚把它当可用其他代价交换的分数。真实的安全边界更像弹簧-阻尼：越靠近越硬，但允许被「压」出一点位移；而**位移/反力的大小恰好暴露了这条规则到底有多硬**。把每条常识 c_i 写成虚拟阻抗场 Z_kc,i=(K_kc,i, D_kc,i)，则 W_kc 的梯度就是反力，控制器从「躲避代价」变成「与边界接触」。这既让安全行为连续、可解释（力/能量是物理量），也让「常识是否真的适用」变成一个可以被测量的量。

2. **主动交互 = 用安全的小动作换取信息**。KEMPC 从不主动试探：摩擦系数、人的阻抗、地面承重都靠传感器「喂」。但很多量只有在**接触中**才可辨识，而辨识需要激励。于是机器人应被允许在**安全可辨识集**内主动做一次轻踩/轻推/轻问，以降低隐藏参数的不确定性。关键约束是：**探测本身也是接触，也花安全预算**；信息收益不能补偿安全违规。这把安全交互变成对偶控制：同一个输入既在调节、又在辨识。

3. **阻抗控制给出「主动」与「安全」的统一语言**。位置/速度 MPC 把交互当成扰动；阻抗控制把交互当成可设计的端口。用变阻抗 u = -K_r(x-x_d) - D_r ẋ + u_ff，把知识边界、探测激励、让位柔顺都写成同一组阻抗参数，才有可能在一个优化里同时回答「多硬、多快、问什么」。但必须补上经典阻抗控制回避的坑：**机器人单侧无源 ≠ 人-机耦合稳定**，因为人带延迟反射会倒灌能量。

**关键洞见**：前几轮问「机器人是否遵守了常识」；本轮改问「**机器人以多大的阻抗、花多少能量、换取了多少关于边界的信息，并且这个交换是否仍在安全契约内**」。这把 KEMPC 从「知识约束下的规划器」推进为「**知识阻抗 + 主动辨识**的交互控制器」。

**形式化目标（增量）**：
1. IKC：把 IEKC 的 σ_i 扩展为阻抗元组 (K_kc, D_kc, Z_safe, E_max, P_peak_max)，并定义反力 F_kc = -K_kc(x-x_safe) - D_kc ẋ 与边界证据 (deflection, reaction energy)。
2. AIS：定义主动交互动作 g ∈ {probe, ask, yield, hold}，以 VoI(g)=E[ΔH(θ)] - c_safe - c_energy - c_time 选择，约束为 belief-robust safety。
3. PIC：给出含人体延迟反射 τ_h 的耦合无源性充分条件与能量罐 E_tank 更新。
4. EIL：把每次接触的 E_{r→h}, E_{h→r}, P_peak 记账，未记账的力不得施加。
5. PI-MPC/AICG：Exec_v29 = Exec_v28 ∩ Fil_impedance ∩ Fil_probe ∩ Fil_passivity ∩ Fil_energy，十证合取、不可补偿。
6. 可检验命题：在相同能量预算下，主动探测把摩擦/人体刚度估计误差降低 ≥40%；PIC 把耦合失稳率降低 ≥50%；AICG 的误准入率 ≤1%，且所有准入轨迹的峰值功率不超契约。

**本轮最大风险**：**软边界侵蚀（compliant boundary erosion）**——把硬安全边界写成可推的阻抗场、又允许主动探测，等于允许机器人「压着边界」甚至「压过边界」；而阻抗越柔顺，越界时的反力反而越小，系统会在力信号上「感觉安全」，却已经在位置/能量上越界。主动交互会把这种风险从「偶发扰动」放大为「策略性行为」。

### IP-467 Impedance-Knowledge Certificate (IKC)

```python
@dataclass
class ImpedanceKnowledgeCertificate:
    """IKC：把常识规则写成虚拟阻抗场，并输出边界证据"""
    name: str
    precond: Callable                 # P(x)：规则是否适用
    postcond: Callable                # Q(x)：边界约束
    phi: str = ""
    H: int = 10
    sigma: float = 1.0                # 激活显著性，承 IEKC
    K_kc: float = 50.0                # 虚拟刚度，建议 K_kc = λ_i·σ_i·K0
    D_kc: float = 5.0                 # 虚拟阻尼
    x_safe: Tensor | None = None      # 边界参考（由 postcond 等值面投影得到）
    F_max: float = 40.0               # 该规则允许的最大知识反力
    P_peak_max: float = 80.0          # 峰值功率上限
    E_max: float = 2.0                # 单次接触能量预算
    is_active: bool = True
    boundary_evidence: list = field(default_factory=list)

    def impedance_force(self, x: Tensor, x_dot: Tensor) -> Tensor:
        """F_kc = -K(x-x_safe) - D·ẋ；前置不满足则不产生反力"""
        if not self.precond(x):
            return torch.zeros_like(x)
        x_ref = self.x_safe if self.x_safe is not None else x
        return -self.K_kc * (x - x_ref) - self.D_kc * x_dot

    def safe_interaction_set(self, x: Tensor, x_dot: Tensor) -> bool:
        """准静态安全检查：力、功率不越界"""
        F = self.impedance_force(x, x_dot)
        return bool((F.abs() <= self.F_max).all()
                    and float((F * x_dot).abs()) <= self.P_peak_max)

    def boundary_energy(self, traj: Tensor, dt: float) -> float:
        """一次接触内知识反力做的功，作为规则强度的物理证据"""
        E = 0.0
        for k in range(1, min(len(traj), self.H)):
            v = (traj[k] - traj[k - 1]) / dt
            F = self.impedance_force(traj[k], v)
            E += float((F * v).abs()) * dt
        return E

    def evidence(self, traj: Tensor, dt: float) -> dict:
        """边界证据：反力、位移、耗散能量、是否逼近越界"""
        x0, xH = traj[0], traj[min(len(traj) - 1, self.H - 1)]
        F = self.impedance_force(xH, (xH - x0) / (dt * max(1, self.H - 1)))
        ev = {
            "rule": self.name,
            "deflection": float(torch.norm(xH - x0)),
            "reaction_force": float(torch.norm(F)),
            "reaction_energy": self.boundary_energy(traj, dt),
            "near_boundary": not self.safe_interaction_set(xH, (xH - x0) / dt),
            "sigma": self.sigma,
        }
        self.boundary_evidence.append(ev)
        return ev
```

### IP-468 Active Interaction Scheduler (AIS)

```python
@dataclass
class ActiveInteractionScheduler:
    """AIS：在安全可辨识集内主动探测/询问，最大化信息价值"""
    belief: dict                    # θ 的后验均值
    belief_cov: np.ndarray          # 参数协方差
    safe_eps: float = 0.05          # 最坏风险阈值 ε_robust
    info_floor: float = 0.05        # 低于此信息增益则诚实放弃探测
    probe_energy_budget: float = 0.2
    w_safe: float = 1.0
    w_energy: float = 1.0
    w_time: float = 0.1
    time_cost: float = 1.0
    probes: list = field(default_factory=list)   # 候选探测动作（幅值/方向/时长）

    def robust_safe(self, g: dict, x: Tensor) -> bool:
        """对信念 ε-支撑集做最坏情况安全校验（保守探索）"""
        for theta in self._support_samples(self.belief, self.belief_cov, n=32):
            if self._worst_case_risk(g, x, theta) > self.safe_eps:
                return False
        return True

    def value_of_information(self, g: dict, x: Tensor) -> float:
        dH = self._expected_entropy_reduction(g, x)
        c_safe = self._worst_case_risk(g, x, self.belief)
        c_energy = self._expected_energy(g)
        c_time = self._duration(g) * self.time_cost
        return dH - self.w_safe * c_safe - self.w_energy * c_energy - self.w_time * c_time

    def select(self, x: Tensor) -> dict | None:
        """返回最优探测；无可行或信息不足时返回 None（进入 blind 模式）"""
        feasible = [g for g in self.probes if self.robust_safe(g, x)]
        if not feasible:
            return None
        g_star = max(feasible, key=lambda g: self.value_of_information(g, x))
        if self.value_of_information(g_star, x) < self.info_floor:
            return None
        if self._expected_energy(g_star) > self.probe_energy_budget:
            return None
        return g_star

    def update_belief(self, g: dict, observation: dict) -> None:
        """贝叶斯更新：用接触响应更新 θ 的后验"""
        # 线性化观测 y = φ(g)ᵀθ + ε，做卡尔曼/贝叶斯线性回归更新
        H = self._observation_jacobian(g, observation)
        R = self._noise_cov(observation)
        K = self.belief_cov @ H.T @ np.linalg.inv(H @ self.belief_cov @ H.T + R)
        self.belief = self.belief + K @ (observation["y"] - H @ self.belief)
        self.belief_cov = (np.eye(len(self.belief)) - K @ H) @ self.belief_cov

    def identifiability(self, g: dict) -> bool:
        """安全 Fisher 信息是否足以辨识 θ（id_h 标志）"""
        I = self._fisher_information(g)
        return bool(np.linalg.cond(I) <= 1e4 and np.trace(np.linalg.inv(I)) <= 1.0)
```

### IP-469 Passivity-Impedance Certificate (PIC)

```python
@dataclass
class PassivityImpedanceCertificate:
    """PIC：含延迟反射的人-机耦合无源性认证"""
    D_r: float                    # 机器人阻尼
    D_h_hat: float                # 人体阻尼估计
    g_h_hat: float                # 反射增益估计
    tau_h_hat: float              # 反射延迟估计
    omega_c: float                # 耦合回路穿越频率
    E_tank: float = 0.0
    E_cap: float = 5.0

    def reflex_gain_bound(self) -> float:
        """一阶保守界：G(τ,ω) ≈ |g| / (1 + (ωτ)²)"""
        return abs(self.g_h_hat) / (1.0 + (self.omega_c * self.tau_h_hat) ** 2)

    def margin(self) -> float:
        return self.D_r + self.D_h_hat - self.reflex_gain_bound()

    def certify(self) -> tuple[bool, float]:
        m = self.margin()
        return (m > 0.0 and self.E_tank >= 0.0), m

    def update_tank(self, P_in: float, P_out: float, dt: float) -> None:
        """能量罐：注入受 E_cap 限制，输出不得使罐为负"""
        self.E_tank = min(self.E_cap, self.E_tank + P_in * dt)
        if P_out * dt > self.E_tank:
            raise RuntimeError("energy tank depleted: passivity violated")
        self.E_tank -= P_out * dt
```

### IP-470 Energy-Interaction Ledger (EIL)

```python
@dataclass
class EnergyInteractionLedger:
    """EIL：接触能量账本与疲劳账户"""
    E_max: float
    fatigue_half_life: float = 3600.0
    entries: list = field(default_factory=list)
    E_used: float = 0.0
    P_peak: float = 0.0

    def record(self, region: str, F: Tensor, v: Tensor, dt: float) -> dict:
        p = float((F * v).sum())
        e_r2h = max(p, 0.0) * dt
        e_h2r = max(-p, 0.0) * dt
        self.E_used += e_r2h
        self.P_peak = max(self.P_peak, abs(p))
        entry = {
            "region": region, "E_r2h": e_r2h, "E_h2r": e_h2r,
            "P_peak": abs(p), "E_used": self.E_used,
            "fatigue_left": self.fatigue_budget(),
        }
        self.entries.append(entry)
        return entry

    def fatigue_budget(self) -> float:
        """疲劳使可用能量单调衰减，休息才恢复"""
        return max(0.0, self.E_max - self.E_used) / (
            1.0 + self.E_used / self.E_max)

    def audit(self) -> bool:
        return (self.E_used <= self.E_max
                and self.P_peak <= getattr(self, "P_peak_max", float("inf"))
                and len(self.entries) > 0)
```

### IP-471 Proactive-Impedance KEMPC (PI-MPC)

```python
@dataclass
class ProactiveImpedanceMPC:
    """PI-MPC：变阻抗 + 知识阻抗 + 安全探测 + 无源性"""
    dynamics: Callable
    horizon: int = 20
    dt: float = 0.01
    weights: dict = field(default_factory=dict)
    ikc_list: list = field(default_factory=list)
    ais: ActiveInteractionScheduler | None = None
    pic: PassivityImpedanceCertificate | None = None
    eil: EnergyInteractionLedger | None = None
    x_bounds: Tensor | None = None
    u_bounds: Tensor | None = None
    terrain_map: Callable | None = None
    alpha: float = 1.0                 # 权威份额
    impedance_enabled: bool = True
    probe_enabled: bool = True

    def solve(self, x0: Tensor) -> tuple:
        import cvxpy as cp
        N, n_x = self.horizon, len(x0)
        n_u = self._control_dim()
        X = cp.Variable((N + 1, n_x))
        U = cp.Variable((N, n_u))
        g = self.ais.select(x0) if (self.ais and self.probe_enabled) else None

        cost, constraints = 0.0, [X[0] == x0]
        for k in range(N):
            constraints.append(X[k + 1] == self.dynamics(X[k], U[k]))
            if self.x_bounds is not None:
                constraints += [X[k + 1] >= self.x_bounds[0],
                                X[k + 1] <= self.x_bounds[1]]
            if self.u_bounds is not None:
                constraints += [U[k] >= self.u_bounds[0],
                                U[k] <= self.u_bounds[1]]

            # 知识阻抗：用反力代替标量惩罚
            if self.impedance_enabled:
                F_kc = self._aggregate_knowledge_force(X[k + 1], (X[k + 1] - X[k]) / self.dt)
                cost += self.weights.get("impedance", 1.0) * cp.sum_squares(F_kc)
                constraints.append(cp.norm(F_kc, 2) <= self.weights.get("F_max", 40.0))

            # 任务阻抗（变刚度）与探测分量
            cost += cp.quad_form(U[k] - self._impedance_ref(X[k]), 
                                 self.weights.get("control", 0.01) * np.eye(n_u))
            if g is not None:
                cost += self.weights.get("probe", 0.1) * cp.sum_squares(U[k] - g["u"])

        prob = cp.Problem(cp.Minimize(cost), constraints)
        try:
            prob.solve(solver="OSQP", warm_start=True)
            if prob.status != "optimal":
                return self._fallback(x0)
        except Exception:
            return self._fallback(x0)

        traj = X.value
        cert = self._certify(x0, traj, g)
        return U.value[0], cert

    def _aggregate_knowledge_force(self, x: Tensor, v: Tensor) -> Tensor:
        F = torch.zeros_like(x)
        for kc in self.ikc_list:
            F = F + kc.impedance_force(x, v)
        return F

    def _impedance_ref(self, x: Tensor) -> Tensor:
        # 变阻抗律：u = -K_r(x-x_d) - D_r·v；此处给出期望控制参考
        return -self.weights.get("K_r", 10.0) * x

    def _certify(self, x0: Tensor, traj: Tensor, g: dict | None) -> dict:
        evidence = [kc.evidence(traj, self.dt) for kc in self.ikc_list]
        stable, margin = self.pic.certify() if self.pic else (True, float("inf"))
        audited = self.eil.audit() if self.eil else True
        return {
            "evidence": evidence, "probe": g,
            "passivity_margin": margin, "stable": stable,
            "energy_audited": audited,
            "identifiable": self.ais.identifiability(g) if g else False,
        }

    def _fallback(self, x0: Tensor) -> tuple:
        u = np.zeros((self.horizon, self._control_dim()))
        cert = {"evidence": [], "probe": None, "passivity_margin": -1.0,
                "stable": False, "energy_audited": False, "identifiable": False}
        return u[0], cert

    def _control_dim(self) -> int:
        return 6
```

### IP-472 Active-Interaction Cert Gate (AICG)

```python
@dataclass
class ActiveInteractionCertificationGate:
    """AICG：KTCG ∪ IKC ∪ AIS ∪ PIC ∪ EIL 十证一体"""
    ktcg: "KnowledgeTransilientCertificationGate"   # 前轮九证
    ikc_list: list
    ais: ActiveInteractionScheduler
    pic: PassivityImpedanceCertificate
    eil: EnergyInteractionLedger

    def admits(self, robot_plan, sensor_data: dict) -> bool:
        # 1-9. 前轮九证（结构/语义/KT-MPC/IEKC/CTKTP/AKWA/KC/DCC/一致性）
        if not self.ktcg.admits(robot_plan, sensor_data):
            return False

        # 10a. IKC：每条激活规则都必须有可解释的边界证据
        for kc in self.ikc_list:
            if kc.is_active and not kc.boundary_evidence:
                return False
            if kc.is_active and not kc.safe_interaction_set(
                    robot_plan.init_state, torch.zeros_like(robot_plan.init_state)):
                return False

        # 10b. AIS：探测必须可行且信息价值达标；不可行则必须 blind
        g = self.ais.select(robot_plan.init_state)
        if g is not None and not self.ais.robust_safe(g, robot_plan.init_state):
            return False
        if g is None and self.ais.identifiability(g) is False:
            # blind 模式合法，但必须显式降级：禁止精细力控声明
            if robot_plan.claims_fine_force_control:
                return False

        # 10c. PIC：耦合无源性裕度必须为正
        stable, margin = self.pic.certify()
        if not stable or margin <= 0.0:
            return False

        # 10d. EIL：能量账本必须完整且未超支
        if not self.eil.audit():
            return False

        return True
```

## 3. 复杂度分析（增量更新）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| IKC 反力/证据 | O(N_rule · n_x) | O(N_rule · H) | N_rule≤50, n_x=12 |
| AIS 候选筛选 | O(N_probe · S · C_risk) | O(N_probe · n_θ) | N_probe≤16, S=32 支撑样本 |
| AIS 信念更新 | O(n_θ³) | O(n_θ²) | n_θ≤6 |
| PIC 认证 | O(1) | O(1) | 仅代数条件 |
| EIL 记账/审计 | O(N_contact) | O(N_contact) | 每步一条 |
| PI-MPC 求解 | O(N·n_x³ + N·n_u²·m + N_rule·n_x) | O(N·n_x + N_rule) | N=20, 阻抗项增加 <10% 开销 |
| AICG 总体 | O(N·n_x³ + N_probe·S) | O(N·n_x + N_rule + N_contact) | 主瓶颈仍是 MPC |

**实时性**：PI-MPC 典型 6–18ms；IKC 证据 <2ms；AIS 在 N_probe=8、S=32 时 <4ms（可低频触发，如 10Hz）；PIC/EIL <1ms。总体单步仍可压在 20ms 内满足 50Hz；主动探测只在关键事件（进入新地形、接触新人、置信度骤降）触发，避免每步都探测。

## 4. 正确性论证（增量更新）

### 引理 26（KAI 对 KEMPC 的包含性）

**陈述**：若取 K_kc,i = ∇²W_kc,i(x_safe) 且 x_safe 为 W_kc,i 的极小点，则在准静态小位移极限下 F_kc,i = -∇W_kc,i(x)，即虚拟阻抗场是标量常识惩罚的梯度；因此 KEMPC 的最优解是 PI-MPC 在 K_kc→0 极限下的一阶近似，KAI 不弱于原框架。

**证明**：对 W_kc,i 在 x_safe 处二阶展开 W ≈ ½(x-x_safe)ᵀK_kc,i(x-x_safe)，梯度为 K_kc,i(x-x_safe)。取阻抗力 F_kc,i=-K_kc,i(x-x_safe)-D_kc,i ẋ，在 ẋ→0 的准静态极限即得 F_kc,i=-∇W_kc,i。故原惩罚项等价于该势场的梯度力，KAI 在极限下退化回 KEMPC，且额外提供阻尼项与能量证据。∎

### 引理 27（安全探测的最坏情况保持）

**陈述**：若 AIS 仅选择 g 使得对所有 θ ∈ supp_ε(b_t) 有 Risk(g,θ) ≤ ε_robust，则执行该探测后的真实风险上界仍 ≤ ε_robust + δ_model，其中 δ_model 为模型失配界；当 id_h=0 时不执行任何改变接触力的探测。

**证明**：由 robust_safe 的定义，g 在信念支撑集上的最坏风险已被逐点约束。真实 θ* 属于支撑集或与支撑集的距离不超过 ε（由信念校准保证），故 Risk(g,θ*) ≤ ε_robust + L_risk·ε，其中 L_risk 为风险对 θ 的 Lipschitz 常数；模型失配并入 δ_model。id_h=0 时 select 返回 None，控制器进入 blind 保守模式，不施加额外探测力。∎

### 引理 28（含延迟反射的耦合无源性充分条件）

**陈述**：若 D_r + D_h > |g_h|·G(τ_h,ω_c) 且能量罐 E_tank 非负，则人-机单轴耦合回路在穿越频率 ω_c 附近耗散，闭环稳定。

**证明**：将反射项 g_h φ(t-τ_h) 视为有界扰动，其频率响应增益上界为 |g_h|G(τ_h,ω)。耦合回路总阻尼为 D_r+D_h；由小增益定理，若扰动回路增益严格小于耗散，则闭环回路增益 <1，扰动能量沿时间衰减。能量罐保证机器人端口在任意时刻满足 ∫(u·v)dt ≤ E_tank(0)，不会向耦合注入净能量。故系统耗散且稳定。∎

### 引理 29（信息-安全前沿）

**陈述**：在安全力限 F_max 下准静态辨识刚度 K_h，其估计方差下界为 Var(K̂_h) ≳ σ²K_h²/(F_max²·T_eff)。因此 K_h 越大（人越僵），在同等安全预算内越难辨识；当 K_h > F_max/σ_K 时 id_h=0。

**证明**：准静态位移 x≈F/K_h，安全约束 |F|≤F_max 给出可观测位移上界 x_max=F_max/K_h。Fisher 信息 I(K_h) ∝ (∂x/∂K_h)²/σ² = (F/K_h²)²/σ²；在 T_eff 个独立样本上积分得 I ∝ F_max²T_eff/(σ²K_h²)，故 Var(K̂_h) ≥ 1/I ∝ σ²K_h²/(F_max²T_eff)。当所需精度 σ_K 满足 Var^{1/2}>σ_K 时，安全集内不存在满足条件的激励，id_h=0。∎

### 定理（AICG 十证准入的不可补偿安全性）

**陈述**：对任意计划 Π，`AICG.admits(Π)=True` ⟺ Π 同时满足前轮九证，且：(10a) 所有激活 IKC 有边界证据且力/功率不越界；(10b) 探测在信念鲁棒安全集内或已显式 blind 降级；(10c) 耦合无源性裕度为正；(10d) 能量账本完整未超支。任一条件为假即拒绝，且信息增益不能补偿任一为假。

**证明**：AICG.admits 是十项谓词的合取，逐项调用对应验证器；10a 由 IKC.safe_interaction_set 与 boundary_evidence 保证，10b 由 AIS.robust_safe 与 identifiability 保证，10c 由 PIC.certify 保证，10d 由 EIL.audit 保证。合取式无补偿项，故任一项失败即整体失败；由引理 27–29，各子条件分别给出风险、稳定性与可辨识性的充分保证。∎

## 5. 实验设计

**平台**：双足机器人仿真（MuJoCo），变摩擦地面 μ∈[0.2,0.8]，外加人手交接场景（人体阻抗 K_h∈[100,2000] N/m，反射延迟 τ_h∈[20,80] ms）。

**基线**：
1. KEMPC（第 3 轮，被动标量惩罚）；
2. KEMPC + 固定阻抗（无知识阻抗、无探测）；
3. PI-MPC 去掉 AIS（只做知识阻抗）；
4. PI-MPC 去掉 PIC（检验耦合稳定性必要性）；
5. PI-MPC 完整版。

**指标**：
- 安全：越界率、峰值接触力/功率、能量超支率、AICG 误准入率；
- 估计：摩擦系数相对误差、K_h 相对误差、id_h 误判率；
- 交互：VoI 实现值、探测能量占比、探测次数、撤销/停止响应延迟；
- 稳定：耦合失稳率、PIC 裕度分布、能量罐耗尽次数；
- 任务：成功率、完成时间、恢复时间。

**预期（可检验）**：
- 相同能量预算下，主动探测把 μ/K_h 估计误差降低 ≥40%；
- PIC 把耦合失稳率降低 ≥50%；
- AICG 误准入率 ≤1%，且准入轨迹峰值功率全部 ≤ 契约；
- 关闭 robust_safe 后越界率显著上升，验证「软边界侵蚀」风险真实存在。

**消融**：分别移除 IKC 阻抗项、AIS、PIC、EIL，观察各指标退化，定位贡献。

## 6. 已知风险与缓解（增量更新）

| 风险编号 | 描述 | 严重度 | 缓解措施 | 剩余风险 |
|---|---|---|---|---|
| R25 | **软边界侵蚀**：可推阻抗场 + 主动探测导致压过硬边界，且柔顺性掩盖越界 | 高 | 1) 对每条 IKC 保留硬兜底约束（位置/能量双保险）；2) 越界检测用位置/能量而非力；3) 阻抗刚度下界 K_min 防止过软 | 高速冲击下硬兜底仍可能触发过晚 |
| R26 | 探测本身造成伤害/失稳（主动交互的短时风险） | 高 | 1) belief-robust safety；2) 探测能量独立预算；3) id_h=0 强制 blind；4) 可撤销探测（Δ_revoke 超时即停） | 极端个体差异下最坏情况界过保守，导致探测不可用 |
| R27 | **主动交互剧场**：探测收益被最坏情况约束吃掉，系统只是重复确认先验 | 中 | 1) 记录 VoI 实现值，低于 info_floor 就诚实放弃；2) 报告 id_h 与信息增益，禁止「假装在学习」；3) 定期用离线数据校准先验 | 非平稳环境中先验快速过期，探测又不可行 |
| R28 | 人体阻抗/疲劳参数漂移导致 PIC 认证失效 | 中 | 1) 在线辨识 + 保守上界；2) 疲劳账户折减能量预算；3) 裕度不足即降 α、增阻尼 | 长时间作业后参数漂移快于辨识速度 |
| R29 | 主动探测与阻抗项增加计算/实时开销 | 低 | 1) 探测低频触发；2) 证据异步生成；3) 简化模式关闭探测 | 关键事件密集时仍可能超时 |

## 7. 本轮最大风险（最终确认）

**一句话**：**软边界侵蚀**——把硬安全边界改写成可推的虚拟阻抗场、又允许机器人主动探测，等于允许它「压着边界」甚至「压过边界」；阻抗越柔顺，越界时反力反而越小，系统会在力信号上「感觉安全」，却在位置/能量上已经越界，而主动交互把这种越界从偶发扰动升级为策略性行为，是当前方案最隐蔽也最危险的安全隐患。
