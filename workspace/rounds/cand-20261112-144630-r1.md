# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；新灵感循环第 1 轮；本轮灵感：「通用操作」×「视觉语言模型」）

> 第 60 轮把「场景」变成阻抗先验、「意图」变成约束锁定、「ROS」变成因果隔离，实现了场景感知闭环 SGEC。但面向**通用操作（general manipulation）**，三个根本矛盾暴露无遗：
> 1. **场景集合的闭集性**：SSM 的 10 个预定义场景无法覆盖开放世界——新物体、新工具、新任务（倒水、系绳、开抽屉）根本不在 Z_scene 中；场景识别器无法"识别"它没见过的场景，只能落到 `unknown`→保守回退。**通用性要求开放词汇，而 SSM 是闭集分类器**。
> 2. **语义与物理的接地鸿沟**：视觉语言模型（VLM）能以开放词汇理解图像与指令，输出「抓住杯柄」「把书竖起来」的语义提案；但 VLM 的输出是**二维像素 + 语言，无米制精度、无接触力、无稳定性**。直接把 VLM 当策略执行，等于让一个"从不接触世界"的模型决定接触世界的方式。
> 3. **成功判定的语义-证据错位**：第 60 轮的 EV-exec 只回答"执行是否合规"，不回答"任务是否真的完成"。VLM 会**幻觉式宣称成功**（"已放置"其实悬空、遮挡误判），而力/触觉证据可能与之冲突。通用操作需要**语义声明与物理证据的对账**，否则"成功证书"是空中楼阁。

## 0. 直觉与动机

**灵感 1（VLM → 操作提案图 VMP，而非直接策略）**
直觉：不要问 VLM"下一步关节角是多少"，而要问它"这张图里，为了完成这句话，**哪些物体、哪个可供性（affordance）、什么先后关系**"。把 VLM 的输出约束为**类型化的操作提案图**：节点 = 可供性锚定的子目标（物体 o、部位 a、目标区域 r），边 = 带前置/后置条件的时序关系，节点附软约束标签（易碎/可滑/需插入）。关键洞见：**VLM 负责"做什么"的语义泛化，不负责"怎么做"的数值精度**——把它从"控制器"降级为"提案者"，是从根上控制幻觉的方式。

**灵感 2（提案 → 接地操作契约 GMC）**
直觉：语义提案必须被"翻译"成执行层能编译、能核验的契约：米制位姿、力包络、速度、阻抗种子、硬约束，以及**接地协方差**。二维像素→三维米制的不确定性必须显式携带（Σ_grd），而不是被隐含丢掉。关键洞见：**接地的本质是把"置信"与"精度"一并传递**——执行层不该相信一个没有方差的位姿。

**灵感 3（通用操作技能库 GMSL → 可组合契约）**
直觉：通用不是"一个万能策略"，而是"一套带契约的原子技能 + 语义层的组合"。抓、放、推、拉、插、擦、递……每个技能都有前置/后置条件、参数、执行映射与**证据签名**。VLM 只做技能选择与参数建议，技能契约保证可组合性：`post(σ_i) ⇒ pre(σ_{i+1})`。关键洞见：**通用性来自组合闭包，而非单点泛化**。

**灵感 4（物理合理性防火墙 PPF + 提案-执行一致性 PEC）**
直觉：VLM 提议，物理否决。PPF 用运动学可达、无碰撞、力可行、稳定裕度、夹爪能力筛掉物理不可行提案，把反例回喂 VLM 做有界修复。执行后，PEC 把 VLM 的"视觉+语言成功声明"与力/触觉/位姿证据对账：声明说"已放稳"，证据说"接触力为零、物体仍在动"→判为幻觉 H_vlm。关键洞见：**语义声明必须被物理证据背书，成功证书只能由证据签发**。

**灵感 5（推测式通用操作 SGM + 主动感知接地 APG + 五维预算）**
直觉：VLM 推理是秒级的，等它算完再动太慢。按**可逆度 ρ** 把任务拆成"可逆前缀（接近、对齐）"与"不可逆后缀（夹紧、释放、切割）"：可逆前缀**投机执行**，VLM 结果按时到达则提交，否则回滚到安全位姿。若接地熵高（VLM 看不清/拿不准），用 APG 主动换视角或轻触探询，按 VOI 选动作。整套预算升为五维 B_gm=(B_vlm, B_grd, B_probe, B_exec, B_cog)。关键洞见：**用可逆性换时延，用主动感知换确定性**。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（VLM 操作提案图 VMP）** 给定图像 I、语言指令 L、机器人状态 s，VLM 提案器 V 输出类型化图：
```
G = (V, E, Φ)
V = { v_i = (o_i, a_i, r_i, g_i) }        # 物体、可供性、目标区域、抓取候选
E ⊆ V × V，边带时序/因果标号
Φ: V → 2^{软约束}，软约束 ∈ {易碎, 光滑, 需插入, 可形变, 需双手}
```
- VMP 表达"要完成的语义谓词与先后关系"，**不含动作序列、不含米制位姿**。
- VLM 输出经类型化模式（JSON schema + 词表）解析；解析失败或类型不合法即拒收并回退。
- VMP 不可直接执行，必须经接地算子 `Grd` 成为契约。

**定义 162（接地操作契约 GMC）** GMC = ⟨T, P, C, Σ_grd, ρ⟩：
- **T** = (σ₁, …, σₙ)：技能序列（来自 GMSL）
- **P**：米制参数（位姿、力包络、速度、阻抗种子）
- **C**：硬约束（工作空间、力上限、碰撞、稳定裕度 m_stab）
- **Σ_grd**：接地协方差（像素→米制的位姿不确定性）
- **ρ** ∈ [0,1]：可逆度，ρ=1 完全可逆（接近/退回），ρ=0 不可逆（夹紧/释放/切割）
- **可容许**：`admissible(GMC) ⇔ C ∩ K_safe ≠ ∅ ∧ tr(Σ_grd) ≤ θ_Σ ∧ reachable(P)`。

**定义 163（通用操作技能库 GMSL）** 技能 σ = ⟨pre, post, params, exec_map, evid_map⟩：
- **pre/post**：状态谓词契约
- **exec_map**：params → (EEIS.compile, ERTC.lock) 调用
- **evid_map**：期望证据签名（力剖面类别、接触序列、滑动检测）
- **组合闭包**：若 `post(σ_i) ⇒ pre(σ_{i+1})` 则 σ_i∘σ_{i+1} 合法
- GMSL = {reach, grasp, place, push, pull, insert, wipe, handover, …}

**定义 164（提案-执行一致性 PEC 与接地成功证书）** 给定 VLM 结果声明 y_claim（视觉判定 + 语言断言）与执行证据 EV-exec：
- **一致性**：`c = 1 − d(y_claim, y_evid)`，d 为任务相关散度（力剖面/位姿/接触序）
- **接地成功证书**：`J_vlm = (success, c, refs, rejected_claims)`，仅当 `c ≥ τ_pec` 且 `success_evid = true` 时签发
- **幻觉判定**：`H_vlm ⇔ (y_claim = 成功) ∧ (c < τ_pec ∨ success_evid = false)`

**定义 165（物理合理性防火墙 PPF）** 验证器 `V_phys: GMC → {accept, reject(counterexample), repair}`：
- 检查：运动学可达、无碰撞、力可行（F ≤ F_max）、稳定（CoM 投影在支撑多边形内且 m_stab ≥ m_min）、夹爪能力
- **保形接受**：在标定条件下，`P(V_phys = reject | infeasible) ≥ 1 − α`
- **有界修复**：反例回喂 VLM，重试 k ≤ 3
- **原则**：VLM proposes, physics disposes（模型提议、物理否决）。

**定义 166（推测式通用操作 SGM）** 给定 VLM 延迟 L_vlm 与提交截止 d：按 ρ 切分可逆前缀 π_pre（ρ=1）与不可逆后缀 π_post（ρ<1）：
- t=0 起**投机执行** π_pre，同时异步等待 VLM
- 若 VLM 在 τ_commit ≤ d 到达：用其参数提交 π_post；否则**回滚**到安全位姿 s_safe，代价 C_rb
- 期望增益：`E[G] = P(on-time)·(L_vlm − τ_pre) − P(late)·C_rb`

**定义 167（主动感知接地 APG）** 接地熵 `H(Grd) = E[−log p(pose | I)]`。当 `H(Grd) > θ_H`，在动作集 A（换视角/变焦/轻触）上按 VOI 选择：
```
a* = argmax_{a ∈ A, cost(a) ≤ B_probe}  E[ H(Grd) − H(Grd | a) ] / cost(a)
```

**定义 168（五维预算 PCE+++++ 与 GMEC）** `B_gm = (B_vlm, B_grd, B_probe, B_exec, B_cog)`。
- 降级次序：B_vlm 耗尽 → 禁用 VLM 提案、退回 GMSL 默认技能；B_grd 耗尽 → 仅执行已缓存契约；B_probe 耗尽 → 用先验姿态谨慎接近；B_exec 耗尽 → 保守阻抗；B_cog 耗尽 → 原有降级。
- **GMEC（通用操作执行证书）** = `(J_vlm, J_exec, PPF_trace, ρ_trace)`：语义、执行、物理、可逆性四证合一。

class VLMProposer:
    def __init__(self, vlm_client, schema, max_retry=2):
        self.vlm = vlm_client
        self.schema = schema          # 类型化 VMP JSON schema

    def propose(self, image, instruction, state):

    def _well_typed(self, g):

### IP-162 GMC（接地操作契约）

```python
def ground_vmp(graph, calibration, depth, state):
    gmc = GMC(skills=[], params=[], constraints=[])
    Sigma = np.zeros((6, 6))
    for node in topo_sort(graph):
        skill = GMSL.select(node.affordance)
        pose2d = node.anchor
        pose3d, cov = triangulate(pose2d, depth, calibration)
        Sigma += cov                                  # 显式传播接地不确定性
        params = skill_parameterize(skill, pose3d, node.soft_constraints)
        constraints = derive_constraints(skill, node, state)
        gmc.skills.append(skill)
        gmc.params.append(params)
        gmc.constraints.extend(constraints)
    gmc.Sigma_grd = Sigma
    gmc.rho = min(s.rho for s in gmc.skills)
    return gmc

def admissible(gmc, K_safe):
    return (intersects(gmc.constraints, K_safe) and
            np.trace(gmc.Sigma_grd) <= THETA_SIGMA and
            reachable(gmc.params))
```

### IP-165 PPF（物理合理性防火墙）

```python
class PhysicalPlausibilityFirewall:
    def __init__(self, alpha=0.05, k_max=3):
        self.alpha, self.k_max = alpha, k_max

    def verify(self, gmc, state):
        for name, check in [('reach', reachable), ('collision', collision_free),
                            ('force', force_feasible), ('stability', stability_margin),
                            ('gripper', gripper_capable)]:
            ok, cex = check(gmc, state)
            if not ok:
                return Verdict('reject', name, cex)   # 反例回喂 VLM
        return Verdict('accept', None, None)

    def repair_loop(self, proposer, gmc, state):
        for _ in range(self.k_max):
            v = self.verify(gmc, state)
            if v.status == 'accept':
                return gmc
            gmc = ground_vmp(proposer.revise(gmc, v.counterexample),
                             *state.ground_ctx)
        return None                                   # 有界修复失败→安全回退
```

### IP-164 PEC（提案-执行一致性）

```python
def proposal_execution_consistency(claim, ev_exec, tau_pec=0.8):
    d = task_divergence(claim, ev_exec)     # 力剖面/位姿/接触序散度
    c = 1.0 - d
    success_evid = ev_exec.task_success
    hallucination = claim.success and (c < tau_pec or not success_evid)
    if hallucination:
        return Certificate(success=False, reason='H_vlm', refs=ev_exec.id)
    if c >= tau_pec and success_evid:
        return Certificate(success=True, c=c, refs=ev_exec.id)
    return Certificate(success=False, reason='uncertain', refs=ev_exec.id)
```

### IP-166 SGM（推测式通用操作）

```python
def speculative_general_manipulation(gmc, vlm_future, deadline):
    prefix, postfix = split_by_reversibility(gmc)   # prefix.rho == 1
    s_safe = current_state()
    execute_async(prefix)                            # 投机：仅执行可逆动作
    try:
        vlm_out = vlm_future.result(timeout=deadline)
        gmc = merge(gmc, ground_vmp(vlm_out, *state.ground_ctx))
        if firewall.verify(gmc, state).status == 'accept':
            execute(postfix)                         # 提交不可逆后缀
            return 'committed'
    except TimeoutError:
        pass
    rollback_to(s_safe)                              # 回滚到安全位姿
    return 'rolled_back'
```

### IP-167 APG（主动感知接地）

```python
def active_perception_grounding(graph, budget):
    H = grounding_entropy(graph)
    while H > THETA_H and budget.B_probe > 0:
        scored = []
        for a in PERCEPTION_ACTIONS:
            gain = H - expected_entropy_after(graph, a)
            scored.append((gain / action_cost(a), a))
        _, a = max(scored)
        observe(a)
        budget.B_probe -= 1
        graph = re_ground(graph)
        H = grounding_entropy(graph)
    return graph, H
```

### IP-168 PCE+++++（五维预算）

```python
class GeneralManipulationBudget:
    def __init__(self, vlm_ms=1500, grd_ops=200, probe_ops=10,
                 exec_budget=None, cog_budget=None):
        self.B_vlm, self.B_grd, self.B_probe = vlm_ms, grd_ops, probe_ops
        self.B_exec, self.B_cog = exec_budget, cog_budget

    def degradation(self):
        if self.B_vlm <= 0:   return 'default_skills_only'
        if self.B_grd <= 0:   return 'cached_contracts_only'
        if self.B_probe <= 0: return 'prior_pose_cautious'
        if self.B_exec <= 0:  return 'conservative_impedance'
        return 'normal'

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| VMP | O(|V|+|E|) 解析（VLM 推理 O(L_vlm)） | O(|V|+|E|) | 类型合法性 100%，不合规即拒收 |
| GMC | O(n) 接地 | O(n) | admissible 判定；Σ_grd 显式传播 |
| GMSL | O(1) 查询 | O(S) 技能库 | 组合闭包 post(σ_i)⇒pre(σ_{i+1}) |
| PPF | O(k·C_check) | O(1) | 保形：P(reject|infeasible) ≥ 1−α |
| PEC | O(1) | O(1) | 幻觉检出 ≥ 1−β |
| SGM | max(τ_pre, L_vlm)+τ_post | O(1) | 不可逆动作仅在证书通过后执行 |
| APG | O(|A|·probe) | O(1) | 接地熵单调下降 |
| PCE+++++ | O(1) | O(1) | 任一维耗尽即降级 |

**正确性定理（SPS，语义-物理分离定理）**：
假设 A66–A70 成立：**(A66)** 接地协方差已标定，Σ_grd 以概率 ≥ 1−α 覆盖真实米制误差；**(A67)** PPF 可靠，物理不可行 GMC 必被拒或修复（修复有界 k≤3）；**(A68)** PEC 对真实幻觉的检出率 ≥ 1−β；**(A69)** SGM 可逆性闸门，ρ<1 的后缀仅在 PPF=accept 且 PEC 预检通过后执行，且 s_safe 可达；**(A70)** 五维预算单调消耗，任一耗尽触发降级。
则可证：
1. **安全性（幻觉遏制）**：未经接地或未过 PPF 的不可逆动作被执行的概率 ≤ α + β + ε_budget；即 **VLM 幻觉不能升级为不可逆物理伤害**。
2. **可信性**：VLM 无证据的成功声明以概率 ≥ 1−β 被判 H_vlm，不签发 J_vlm；签发的成功证书必须由 EV-exec 背书。
3. **通用性**：开放词汇任务成功率 ≥ VLM 提案召回 × 技能组合成功率；未覆盖任务回退为"安全探索"而非"危险执行"。
4. **时延**：SGM 把单任务时延从 L_vlm + τ_exec 降到 max(τ_pre, τ_commit) + τ_post。

### IP-161 VMP（VLM 操作提案图）

class VLMProposer:
    def __init__(self, vlm_client, schema, max_retry=2):
        self.vlm, self.schema, self.max_retry = vlm_client, schema, max_retry

    def propose(self, image, instruction, state):
        prompt = build_grounded_prompt(image, instruction, state)
        for _ in range(self.max_retry + 1):
            graph = self._parse_typed(self.vlm.query(prompt))
            if graph is not None and self._well_typed(graph):
                return graph
        return REJECT_AND_FALLBACK_SKILL(state)

    def _well_typed(self, g):
        return all(n.affordance in AFFORDANCES and
                   n.relation in RELATIONS for n in g.nodes)
```

### IP-162 GMC（接地操作契约）

```python
def ground_vmp(graph, calibration, depth, state):
    gmc = GMC(skills=[], params=[], constraints=[])
    Sigma = np.zeros((6, 6))
    for node in topo_sort(graph):
        skill = GMSL.select(node.affordance)
        pose3d, cov = triangulate(node.anchor, depth, calibration)
        Sigma += cov                                  # 显式传播不确定性
        gmc.skills.append(skill)
        gmc.params.append(skill_parameterize(skill, pose3d, node.soft_constraints))
        gmc.constraints.extend(derive_constraints(skill, node, state))
    gmc.Sigma_grd = Sigma
    gmc.rho = min(s.rho for s in gmc.skills)
    return gmc

def admissible(gmc, K_safe):
    return (intersects(gmc.constraints, K_safe) and
            np.trace(gmc.Sigma_grd) <= THETA_SIGMA and reachable(gmc.params))
```

### IP-165 PPF（物理合理性防火墙）

```python
class PhysicalPlausibilityFirewall:
    def __init__(self, alpha=0.05, k_max=3):
        self.alpha, self.k_max = alpha, k_max

    def verify(self, gmc, state):
        for name, check in [('reach', reachable), ('collision', collision_free),
                            ('force', force_feasible), ('stability', stability_margin),
                            ('gripper', gripper_capable)]:
            ok, cex = check(gmc, state)
            if not ok:
                return Verdict('reject', name, cex)
        return Verdict('accept', None, None)

    def repair_loop(self, proposer, gmc, state):
        for _ in range(self.k_max):
            v = self.verify(gmc, state)
            if v.status == 'accept':
                return gmc
            gmc = ground_vmp(proposer.revise(gmc, v.counterexample), *state.ground_ctx)
        return None
```

### IP-164 PEC（提案-执行一致性）

```python
def proposal_execution_consistency(claim, ev_exec, tau_pec=0.8):
    c = 1.0 - task_divergence(claim, ev_exec)      # 力剖面/位姿/接触序
    hallucination = claim.success and (c < tau_pec or not ev_exec.task_success)
    if hallucination:
        return Certificate(success=False, reason='H_vlm', refs=ev_exec.id)
    if c >= tau_pec and ev_exec.task_success:
        return Certificate(success=True, c=c, refs=ev_exec.id)
    return Certificate(success=False, reason='uncertain', refs=ev_exec.id)
```

def speculative_general_manipulation(gmc, vlm_future, deadline):
    prefix, postfix = split_by_reversibility(gmc)   # prefix.rho == 1
    s_safe = current_state()
    execute_async(prefix)

        vlm_out = vlm_future.result(timeout=deadline)

        if firewall.verify(gmc, state).status == 'accept':

### IP-167 APG（主动感知接地）

```python
def active_perception_grounding(graph, budget):
    H = grounding_entropy(graph)
    while H > THETA_H and budget.B_probe > 0:
        _, a = max((H - expected_entropy_after(graph, a)) / action_cost(a), a)
        # 等价于按 VOI/cost 选择动作
        observe(a); budget.B_probe -= 1
        graph, H = re_ground(graph), grounding_entropy(re_ground(graph))
    return graph, H
```

class GeneralManipulationBudget:
    def __init__(self, vlm_ms=1500, grd_ops=200, probe_ops=10,
                 exec_budget=None, cog_budget=None):
        self.B_vlm, self.B_grd, self.B_probe = vlm_ms, grd_ops, probe_ops
        self.B_exec, self.B_cog = exec_budget, cog_budget

        if self.B_grd <= 0:   return 'cached_contracts_only'

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| VMP | O(|V|+|E|) 解析 | O(|V|+|E|) | 类型合法性 100%，不合规即拒收 |
| GMC | O(n) 接地 | O(n) | Σ_grd 显式传播，admissible 判定 |
| GMSL | O(1) 查询 | O(S) | 组合闭包 post(σ_i)⇒pre(σ_{i+1}) |
| PPF | O(k·C_check) | O(1) | 保形拒绝 ≥ 1−α，修复有界 k≤3 |
| PEC | O(1) | O(1) | 幻觉检出 ≥ 1−β |
| SGM | max(τ_pre, L_vlm)+τ_post | O(1) | 不可逆动作仅在证书通过后执行 |
| APG | O(|A|·probe) | O(1) | 接地熵单调下降 |
| PCE+++++ | O(1) | O(1) | 任一维耗尽即降级 |

**正确性定理（SPS，语义-物理分离定理）**：
若 A66–A70 成立——(A66) 接地协方差标定覆盖 ≥1−α；(A67) PPF 对不可行必拒或修复；(A68) PEC 幻觉检出 ≥1−β；(A69) SGM 可逆性闸门 + s_safe 可达；(A70) 预算单调消耗——则：
1. **幻觉遏制**：未接地/未过 PPF 的不可逆动作执行概率 ≤ α+β+ε_budget，**VLM 幻觉不能升级为不可逆物理伤害**。
2. **可信性**：无证据的成功声明以概率 ≥1−β 判为 H_vlm，不签发 J_vlm；J_vlm 必须由 EV-exec 背书。
3. **通用性**：开放词汇成功率 ≥ VLM 提案召回 × 技能组合成功率；未覆盖任务回退为安全探索。
4. **时延**：SGM 将时延从 L_vlm+τ_exec 降至 max(τ_pre, τ_commit)+τ_post。
