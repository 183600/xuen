# 第 47 轮（承接第 46 轮 v10/v23；本轮灵感：数据集 × 仿真训练） · Data-Sim Coverage Calculus：数据覆盖租约与仿真-现实间隙校正的姿态证书（五层架构 v11）

> 承接第 46 轮 v23 MVR×VAD×SAB。v23 已把记忆、语音、安全绑定接入姿态证书，但所有层共享一个从未被检验的隐含假设 **H6：校准数据集对部署上下文是覆盖的、且近似独立同分布**。真实 UniBot 的透明杯、镜面门、弱纹理白墙、快速甩手等退化层在真实校准集中样本极少；仿真训练能廉价生成海量这类场景，却引入 sim-to-real 间隙。结果是：证书在标定集上 sound，在部署中于未覆盖层**静默失效**。两个灵感词精确命中 H6：**数据集**把「上下文覆盖度」升为根信任对象，需要数据租约 ℓ_d；**仿真训练**给出低成本扩覆盖的手段，但其证据必须按间隙折扣后才能计入真实覆盖。核心新问题：**如何用带间隙折扣的加权共形校准，把真实 + 仿真数据合成可验证的上下文覆盖证书，并在覆盖不足时主动采集或 fail-closed，而不是让姿态证书在未覆盖层静默失效**。

## 0. 直觉与动机

**灵感 1（数据集 → 覆盖租约，而非样本数量）**
直觉：数据不是「越多越好」，而是「在安全关键上下文格上有没有足够多的**有效**样本」。把上下文空间 Ω 离散为覆盖网格 G={g}，每个格子的有效样本数按来源可信度加权；只有当某格的加权样本数 n_eff(g) ≥ n_min 时，该格才被认证覆盖。数据租约 ℓ_d=(D_r, D_s, ŵ, W, δ_gap, ρ_cov, t_d, τ_d) 像姿态/能量租约一样会**过期**：分布漂移、物体/光照/任务变化都会让旧覆盖失效，过期即触发半径膨胀或拒绝签发。

**灵感 2（仿真训练 → 有偏见证人，证据必须打折）**
直觉：仿真样本是「有偏的见证人」：它能证明「这类场景模型可能见过」，但不能直接证明「真实世界该类场景的误差分位数」。设仿真与真实在特征空间的密度比 w(x)=p_real(x)/p_sim(x)，并用 W 作上界；再把仿真-现实总变差估计 δ_gap 与保真度残差 ε_f 合并成间隙上界。仿真证据按权重 w 计入覆盖，且**每用一分仿真证据，就从共形显著性里扣一分间隙税**。仿真保真度分层 F0 渲染 → F1 域随机化 → F2 物理/材质准确 → F3 数字孪生，越高的层残差越小、成本越高。

**灵感 3（耦合 → 证书驱动的主动数据实验设计）**
直觉：不要等部署失败再补数据。覆盖函数对「新增一个数据单元」是次模的：每补一个格子的边际价值随已覆盖格数递减。于是「在有限仿真算力 + 真实采集工时下，先仿真什么、再补哪些真实审计样本」是一个**加权最大覆盖**问题，贪心可拿到 1-1/e 近似。这把数据采集从被动记录升级为**由证书缺口驱动的主动实验设计**：哪个上下文格的半径最宽、下游安全敏感度最高，就先补哪里。

**耦合升级**：v10/v23 的四层（根信任 / L1 几何 / L2 上下文-记忆 / L3 安全 CAR / L4 采集 DCL）之上新增 **L5 数据-仿真层 DSL（Data-Sim Layer）**。根信任新增数据租约 ℓ_d；L1 几何层半径按覆盖条件化；L2 记忆条目携带数据租约戳，租约过期即不可复用；L3 CAR 守卫加入覆盖有效性；L4 DCL 升级为主动采集；L5 负责仿真课程、间隙审计与租约签发。核心问题从「感知开不开」升级为「**在数据预算与间隙约束下，如何让证书只在被真实证据覆盖的上下文里签发**」。

## 1. 形式化定义（增量：定义 59–64）

**定义 59（数据护照与上下文覆盖测度）**
数据护照 p=(source, f, g, x, t, license, gap_tag)，其中 source∈{real, sim}，f 为保真度层，g∈G 为上下文格。设样本权重 w_i∈[0,W]，有效样本数
n_eff(g)=Σ_{i∈g} w_i，
覆盖指示 Cov_D(g)=1[n_eff(g)≥n_min ∧ f_i≥f_min(g)]。
认证覆盖集 C_cert(D)={g: Cov_D(g)=1}。
**数据租约** ℓ_d=(D_r, D_s, ŵ, W, δ_gap, ρ_cov, t_d, τ_d, α_min)。
**租约可行判据**：now-t_d≤τ_d、ρ_cov≥ρ_min、W·δ_gap≤α-α_min。失效时 C_cert←∅，所有依赖覆盖的姿态证书级联失效。

**定义 60（仿真保真度与间隙上界）**
保真度层 f 的物理/渲染残差上界 ε_f。给定真实审计集 A_real 与加权仿真分布 P̃_sim^w，
δ_gap(f)=min{1, TV(P_real^A, P̃_sim^w) + ε_f + ε_est},
ε_est=√(log(1/β)/(2|A_real|)) 为有限样本估计误差，以概率 ≥1-β 成立。
**密度比上界** W=min{W_max, sup_x p_real(x)/p_sim(x)}，实现中用判别器/MMD 上置信界估计并保守取大。

**定义 61（间隙校正加权共形证书）**
非一致性分数 s(x,y)=‖y-ŷ(x)‖/σ(x)。加权分位数
q̂_{1-α_eff}=inf{q: Σ_{i:s_i≤q} w_i / Σ_i w_i ≥ 1-α_eff}，
其中**间隙税** α_eff=α-W·δ_gap。
**覆盖迁移不等式**：在密度比 ≤W、δ_gap 为上界、格子内可交换的假设下，
P_{(x,y)~P_real}(s≤q̂_{1-α_eff}) ≥ 1-α_eff-W·δ_gap = 1-α。
故间隙税不是启发式，而是把间隙「花掉」以换回名义 α；当 α_eff<α_min 时证书不可签发。

**定义 62（覆盖门控姿态证书与 OOD 半径税）**
对上下文 ω_t、模态 m、数据租约 ℓ_d，姿态盒
P_t(ω_t)=Ball(X̂_t, rad)，其中
rad=q̂_{1-α_eff}(ω_t)+L_φ·dist_Ω(ω_t,C_cert)+L_g·(W·δ_gap-(α-α_min))_+。
若 ω_t∈C_cert 且 ℓ_d 有效，退化为标准共形半径；否则按到认证覆盖集的上下文距离与间隙盈余线性加税。**签发契约**：仅当 rad≤rad_max 且 ℓ_e、ℓ_τ 有效时签发，否则 fail-closed。

**定义 63（仿真数据边际效用与主动采集）**
对候选数据单元 z（仿真场景或真实审计样本），边际覆盖增益
ΔCov(z|D)=|C_cert(D∪{z})|-|C_cert(D)|，
上下文临界度 κ(z)=Σ_{g∈new(z)} κ(g)，其中 κ(g)=S_col(g)·prox(g,∂E)·rel(g,task)。
效用
U(z)=κ(z)·ΔCov(z|D) / (c_fid(f_z)+c_gap(z)+c_real·1[real])。
预算 B 下主动采集为加权最大覆盖：
max_{S⊆Z, cost(S)≤B} Σ_g κ(g)·1[g 被 S 覆盖]。
覆盖函数对格子是次模的，贪心达到 (1-1/e)·OPT；仿真候选仅在 f_z≥f_min(g) 且按 w 计入时有效。

**定义 64（数据-姿态-能量-延迟联合证书）**
J_t=(P_t, ℓ_p, ℓ_e, ℓ_τ, ℓ_d, m_t)。联合 soundness：
P(X_t∈P_t | J_t 有效) ≥ 1-α_p 且 ω_t∈C_cert(ℓ_d) 且 E(t)≥E_min 且 τ_eff>0。
**边际转移**：m_true ≥ m̂ - L_φ·rad(P_t) - L_e·(B_min-E(t))_+ - L_g·W·δ_gap。
**级联**：ℓ_d 失效 → C_cert=∅ → OOD 半径税升高 → 超过 rad_max 即 CAR fail-closed。

## 2. 三大新增产出与既有 IP 升级

**IP-69 SCD（Sim-Coverage Dataset Foundry）**
- 保真度阶梯 F0–F3 与场景课程：按未覆盖格/宽半径格生成透明、镜面、弱纹理、深度空洞、快速运动场景
- 数据护照注入：source/fidelity/gap_tag/时间戳/许可，供审计追溯
- 间隙感知重加权训练：以判别器权重 w 训练/校准，输出每个格的分数分布与置信样本数

**IP-70 DCA（Data Coverage Auditor，DCL 新内核）**
- 覆盖网格维护：滑窗 n_eff(g)、覆盖率 ρ_cov、认证覆盖集 C_cert
- 间隙估计与数据租约签发/吊销：审计集估计 δ_gap、W，检查 W·δ_gap≤α-α_min
- 主动采集调度：对候选仿真场景与真实审计样本做次模贪心，输出采集任务给 DCL
- 漂移检测：特征/残差分位数漂移触发租约过期，而不是等部署违例

**IP-71 DPC（Data-Pose Certificate）**
- 覆盖门控半径：按 (m, ω, ℓ_d) 查间隙校正分位数
- OOD 半径税与拒签契约：未覆盖/租约过期时先加税，超阈值直接 fail-closed
- 证书溯源：每个 P_t 记录其依赖的数据租约、格子与样本护照，可回放复算

**既有 IP 升级**
IP-60 PSE：半径查表从 r_ω(m) 升级为 r_ω(m, ℓ_d)，覆盖不足层直接标红。
IP-61 DCL：采集效用加入能耗 c_e 与间隙成本 c_gap；由 DCA 缺口驱动，而非均匀采集。
IP-62 CCA：新增数据投毒、校准/测试泄漏、间隙低估、分布漂移四类红队。
IP-51 CAR：守卫加入 C_cert(ω_t)=1 与 W·δ_gap<α。
IP-45 总线：新增 data-lease / coverage-cell / sim-scenario / gap-audit 话题。
IP-66 MVR：记忆条目携带数据租约戳，ℓ_d 过期或格子未覆盖时禁止复用该记忆。

## 3. 算法骨架

DSL 每轮（会话级或每 N 个控制周期）：
1. 由护照更新覆盖网格 n_eff(g)，计算 ρ_cov 与 C_cert
2. 在真实审计集上估计 δ_gap、W；若 W·δ_gap≥α-α_min → 吊销 ℓ_d 并缩小 C_cert
3. 签发/续期数据租约 ℓ_d（含过期时间 τ_d）
4. 控制周期内：PSE 用 (m,ℓ_d) 取半径；DPC 按 ω_t 是否覆盖签发证书或加 OOD 税；CAR 统一守卫四条租约
5. 若存在未覆盖关键格、宽半径格或租约临近过期 → DCA 触发主动采集：先跑高保真仿真，再请求真实审计样本
6. 任何租约失效或间隙超限 → fail-closed，并记入 CCA 审计日志

## 4. 本轮最大风险

**一句话**：仿真-现实间隙 δ_gap 一旦被低估（仿真在退化层「看起来很好」而真实误差分布更重尾），间隙税就会收得过少，证书会在真实未覆盖层被错误签发并静默失效；因此必须用独立真实审计集给出 δ_gap 的保守上界、对 W 取上置信界，并在 W·δ_gap 逼近 α 时主动吊销数据租约或 fail-closed，而不是继续用仿真覆盖冒充真实覆盖。

## 1. 符号体系（增量：定义 59–64）

| 符号 | 含义 |

| ε_f | 保真度层 f 的残差上界 |
| δ_gap | 仿真-现实总变差上界（含估计误差） |

| q̂_{1−α_eff}(g) | 格子 g 的加权共形分位数 |
| κ(g) | 上下文格临界度 S_col·prox·rel |
| U(z) | 数据单元 z 的采集效用 |
| rad(P_t) | 覆盖门控姿态盒半径（含 OOD 半径税） |

**关键恒等式（覆盖迁移）**
在 A1 密度比≤W、A2 δ_gap 为上界、A3 ω_t∈C_cert 且 n_eff≥n_min、A4 格内可交换下：
```
1 − α_eff − W·δ_gap = 1 − (α − W·δ_gap) − W·δ_gap = 1 − α
```
即用 `α_eff` 做加权共形，正好把间隙税全部花掉，换回部署分布上的名义覆盖率。

## 2. 关键算法 伪代码

### IP-70 间隙估计与数据租约
```
def estimate_gap(D_real_audit, D_sim, f_tier, beta=0.05):
    w = fit_density_ratio(D_real_audit, D_sim)   # p_real/p_sim
    W = min(W_max, upper_conf_bound(w, beta))    # 保守取上界
    tv = total_variation_mmd(D_real_audit, D_sim, weights=clip(w, 0, W))
    eps_f = FIDELITY_RESIDUAL[f_tier]            # F0..F3 标定残差
    eps_est = sqrt(log(1/beta) / (2*len(D_real_audit)))
    delta_gap = min(1.0, tv + eps_f + eps_est)
    return delta_gap, W

def issue_data_lease(D, alpha, alpha_min, tau_d, now, beta=0.05):
    delta_gap, W = estimate_gap(D.audit, D.sim, D.sim.fidelity, beta)
    C_cert = {g for g in G if n_eff(g, D, W) >= n_min(g)
                            and fidelity_ok(g, D)}
    rho_cov = weighted_measure(C_cert) / weighted_measure(G)
    valid = (W * delta_gap <= alpha - alpha_min) and (rho_cov >= rho_min)
    if not valid:
        C_cert = set()                           # 间隙超限：清空覆盖
    return DataLease(D, W, delta_gap, rho_cov, t_d=now,
                     tau_d=tau_d, C_cert=C_cert, valid=valid)
```

### IP-70 加权分位数与主动采集
```
def weighted_quantile(scores, weights, level):
    order = argsort(scores)
    w = weights[order]
    cw = cumsum(w) / sum(w)
    idx = searchsorted(cw, level)
    return scores[order][min(idx, len(scores)-1)]

def active_acquire(cells, sim_budget, real_budget, D, f_min, alpha):
    S, spend_sim, spend_real = [], 0.0, 0.0
    while True:
        best, best_u = None, 0.0
        for z in candidate_units(cells, D):
            if z.source == 'sim' and (z.cost > sim_budget - spend_sim
                                      or z.fidelity < f_min(z.cell)):
                continue
            if z.source == 'real' and z.cost > real_budget - spend_real:
                continue
            u = criticality(z) * marginal_coverage(z, D) / (z.cost + gap_cost(z, D))
            if u > best_u:
                best, best_u = z, u
        if best is None or best_u <= 0:
            break
        S.append(best); D = D + passport(best)
        if best.source == 'sim':
            spend_sim += best.cost
        else:
            spend_real += best.cost
    return S                                  # 次模贪心：≥ (1-1/e)·OPT
```

### IP-71 覆盖门控姿态证书
```
def issue_pose_certificate(omega, m, D, lease, P_hat, alpha,
                           L_phi, L_g, rad_max):
    if not lease.valid or omega.cell not in lease.C_cert:
        tax = (L_phi * dist_omega(omega, lease.C_cert)
               + L_g * max(0.0, lease.W * lease.delta_gap - (alpha - alpha_min)))
        rad = P_hat.radius + tax
        if rad > rad_max:
            return None                       # CAR fail-closed
        return Certificate(P_hat.center, rad, mode='ood-tax', lease=lease)
    alpha_eff = alpha - lease.W * lease.delta_gap
    q = weighted_quantile(scores_for(omega.cell, D),
                          weights_for(omega.cell, D, lease.W),
                          1 - alpha_eff)
    if q > rad_max:
        return None
    return Certificate(P_hat.center, q, mode='certified', lease=lease)
```

def dsl_cycle(c_t, omega_t, m_t, D, alpha, budgets):
    lease = issue_data_lease(D, alpha, alpha_min, tau_d, now)
    P_t = issue_pose_certificate(omega_t, m_t, D, lease,
                                 P_hat=pose_estimate(), alpha,
                                 L_phi, L_g, rad_max)
    if P_t is None:

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| 间隙估计 | O(\|A\|·d) 每次审计 | O(\|A\|) | δ_gap 为真实总变差的高概率上界（含 ε_f、ε_est） |
| 覆盖更新 | O(1)/护照，O(\|G\|)/周期 | O(\|G\|) | n_eff≥n_min 且保真度达标才认证 |
| 加权分位数 | O(n log n) 预处理，O(log n) 查询 | O(n) | 加权共形覆盖 ≥1−α_eff（密度比有界） |
| 主动采集 | 每步 O(\|Z\|·\|G\|) | O(\|S\|) | 覆盖函数次模 ⇒ 贪心 ≥(1−1/e)·OPT |
| 证书签发 | O(log n) 查询 | O(1) | 覆盖+间隙+能量+延迟全有效才签发，否则加税/拒签 |

**正确性定理（Data-Sim Soundness）**
设 A1 密度比 p_real/p_sim ≤ W；A2 δ_gap 以概率 ≥1−β 上界真实 TV；A3 目标上下文格 ω_t∈C_cert 且 n_eff≥n_min；A4 格内真实样本可交换。则 DPC 签发的认证证书满足
```
P_{P_real}(X_t ∈ P_t | mode='certified') ≥ 1 − α，
```
若任一假设不成立，则进入 OOD 半径税模式；当 `rad>rad_max` 或 `W·δ_gap≥α−α_min` 时拒绝签发并 fail-closed。

**证明要点**：加权 split conformal 在密度比 ≤W 时给出 ≥1−α_eff 的加权覆盖；用 TV 上界把加权仿真分布替换为真实分布，覆盖率最多损失 W·δ_gap；两者相加即得 1−α。OOD 税的线性增长由姿态误差对上下文距离的 Lipschitz 常数 L_φ 与间隙敏感度 L_g 保证；主动采集由加权最大覆盖的次模性 + 贪心近似比给出。

## 4. 实验设计 E115–E120

| 实验 | 指标 | 门槛 |
|---|---|---|
| E115 数据覆盖审计 | 各退化层认证覆盖率、半径误差 | 覆盖判定与留出真实集一致率 ≥ 95% |
| E116 间隙上界有效性 | 名义 vs 经验覆盖率、上界违约率 | 经验覆盖 ≥ 1−α；δ_gap 违约率 ≤ β |
| E117 主动采集效率 | 每真实样本覆盖增益、仿真/真实成本比 | 贪心增益 ≥ 随机 1.5×；覆盖 ≥ 90% 关键格 |
| E118 覆盖门控安全 | OOD 税率、拒签次数、静默违例 | 100h 静默违例 0 起；拒签可解释率 ≥ 99% |
| E119 数据红队 | 投毒检测率、泄漏检出率、漂移召回 | 投毒检出 ≥ 95%；泄漏检出 100% |
| E120 闭环 sim-pretrain | 仿真占比、任务成功率、续航 | 仿真证据占比 ≥ 60% 且任务成功率 ≥ 95% |

**回退策略**：E115 覆盖误差 >5% → 收缩 C_cert 并加大真实审计；E116 上界违约 >β → 提高 δ_gap/W 保守度或直接吊销租约；E117 贪心不如随机 → 回退均匀采集并补真实样本；E119 投毒 >1% → 隔离该数据源并做护照溯源；任何租约过期 → 强制 fail-closed。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| δ_gap 低估导致间隙税不足 | 高 | 独立真实审计集 + 上置信界 + α 临近时吊销租约 |
| 密度比 W 估计偏低 | 高 | 判别器保守校准、下限截断、按最坏源域取上界 |
| 主动采集只补已测格、漏掉稀有灾难层 | 中 | 对 κ(g) 加稀有层权重；保留固定比例探索采样 |
| 仿真保真度成本过高 | 中 | F0/F1 先粗覆盖，F2/F3 只用于高风险格 |
| 校准/测试泄漏使覆盖虚高 | 高 | 护照级来源隔离、CCA 泄漏审计、按采集批次留出 |
| 分布漂移使旧租约过期 | 中 | 漂移检测 + τ_d 短周期续期 + fail-closed |

## 6. 本轮最大风险

**一句话**：仿真-现实间隙 δ_gap 与密度比 W 只要被低估一次，覆盖迁移恒等式就会把「虚高的仿真覆盖」错当成「真实覆盖」，让姿态证书在透明/镜面/弱纹理等真实灾难层被错误签发并静默失效；因此数据租约必须以独立真实审计集给出保守上界，并在 W·δ_gap 逼近 α 时主动吊销或 fail-closed，绝不能拿仿真覆盖率冒充真实覆盖率。
