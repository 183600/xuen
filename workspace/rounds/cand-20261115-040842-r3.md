# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环第 3 轮；本轮灵感：「分层规划」×「深度相机」）

> R69 把不确定性拆成 aleatoric（噪声）与 epistemic（歧义），并用流似然做「标定不可吸收」的第二意见。但它仍站在一个隐含前提上：**观测至少在语义上是可读的**——只要策略的行为自洽，就说明信念没跑偏。深度相机恰好打破这个前提。玻璃、镜面、无纹理、细结构会让 RGB-D 返回一份**自洽但错误**的几何：局部平面拟合极好、同视图残差≈0、策略在这份「假世界」里生成的动作也完全合理。于是 R68 的传感器残差与 R69 的行为似然**同时失效**——它们都是「内部自洽」检验，测的是「我的传感器/行为是否自洽」，而不是「我的世界是否真实」。
>
> 更麻烦的是，R69 的交互与不确定性都活在一个**单一时间尺度**上：它默认「歧义发生在哪一层，就在哪一层用证据消解」。但真实歧义是分层的（我在做哪个任务？/这个子目标可达吗？/这条轨迹稳吗？），而**消解它的动作往往不在同一层**——一个 5cm 的相机侧移（运动层）就能回答「这堵墙是不是玻璃」（任务层）。R69 的扁平 VoI 要么在无法改变上层计划的细层上白花预算，要么把上层语义歧义硬压成下层平滑噪声。
>
> 核心命题：把不确定性从「类型」扩展到「**类型 × 层级**」的二维对象，并显式区分**歧义所在层（locus）**与**消解动作所在层（channel）**；所有深度几何证据必须通过「同视图不可辨识性」检验，只有主动视差/跨模态/触觉这类**外部证据**才能为高层符号命题盖章；只有当外部证据不可得或不可信时，才退化为 R69/R68 的保守。命名 **STRATA-RAS**（Stratified Trust & Resolution with Active depth-grounded evidence）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我看到的这个世界本身是真的吗**」——以及，为了回答它，我该在哪一层花掉我唯一的那次侧移。

## 0. 直觉与动机

**灵感 1（深度相机 → 自洽的假世界）**
直觉：玻璃不是「噪声大」，而是「噪声小得可疑」——它把后面的东西原样透射/反射回来，局部拟合、法向、平面度全都漂亮。镜面把远处场景折叠到近处，flying pixel 在边缘拉出薄纱。这些失效**在单一视图内与真实几何不可区分**，因为它们不是随机误差，而是「另一个同样合法的几何解释」。所以任何只吃同视图残差的检测器，原理上就测不出来——这不是检测器不够强，而是信息不够。

**灵感 2（分层规划 → 歧义有层，证据有层，两者常常不同层）**
直觉：人类不会为了确认「这堵墙是不是玻璃」去重写整个任务计划，也不会为了一个 0.2 秒的轨迹抖动去叫停任务；他会侧一下身（运动层），然后继续（任务层）。**歧义住在哪一层，和哪个动作能消解它，是两个独立坐标。** 扁平 VoI 把这两个坐标合并成一个，于是产生两类浪费：在细层消解（改变不了粗层计划，VoI 为零）与在粗层消解（留下细层未消解，只能保守）。R70 把 locus 与 channel 拆开，并把「层级失配」变成一个可计算的成本项。

**灵感 3（两个内部检验的盲区 → 必须做外部检验）**
直觉：R68 的残差 = 传感器自洽；R69 的流似然 = 行为自洽。假世界可以同时满足两者：玻璃被读成空处，局部几何自洽；策略据此规划「穿过去」，行为在其信念下完全合理。**要测世界自洽，证据必须来自世界本身**——换视角（视差）、换模态（结构光/ToF/双目/RGB 语义）、换物理接触（轻触）。这解释了为什么「主动」不是可选项：目的不是提高精度，而是**打破退化对称**。

**灵感 4（分层会放大错误，而不是自动纠错）**
直觉很美：高层慢、低层快，高层错了低层兜底。实际相反——高层一旦把「玻璃墙」读成「通路」，低层会在一个自洽的错误世界里**高效且安全地**执行：避开不存在的障碍，撞上没被表示的玻璃。分层不是纠错机制，而是**误差放大器 + 责任稀释器**：子目标错了，低层说「我完成了」，高层说「我下发了」。所以必须交付：可行性双证书、跨层接地证书、禁止跨层混合、逐层保守退避。

**灵感 5（可辨识性有物理下限）**
直觉：视差不是万能的。玻璃贴着背景时，表面与背景的深度差趋近于零，任何基线都分不开——这时只能换模态或承认不可验证。**承认「测不出来」比假装测出来更安全**，而这一点必须写进几何层，而不是留给下游的自信。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（STRATA-RAS 总览）** STRATA-RAS = (HPA, CUL, DVF, PAV, HVOI, SAB, CGC, DFM, FDC, RAS-WM‡)。继承 R69 定义 293 的三不变式，新增三条：
(iv) **层级不变式**：每个高层决策携带 (locus ℓ_amb, channel ℓ_act, 证据有效性 V_ev)，禁止跨层插值混合；
(v) **外部证据不变式**：任何用于认证「世界几何」的证据不得仅来自同视图内部量（残差、策略似然、单视图深度先验），必须含至少一个跨视图/跨模态/接触证据，或显式标记 unverifiable；
(vi) **分层预算单调**：预算按层分配，任一层的未消解 epistemic 不得被下推为另一层的「噪声」来静默吸收。

**定义 311（层级抽象 HPA）** 层 ℓ∈{0,1,…,L}（默认 L=2：ℓ=0 轨迹/控制，ℓ=1 子目标/选项，ℓ=2 任务/符号计划）。每层有抽象状态 s^ℓ、抽象动作 z^ℓ∈Z^ℓ、选项 o^ℓ=(I^ℓ, π^ℓ, β^ℓ)（启动集、低层策略、终止条件）、时间抽象 Δt^ℓ。高层发出子目标序列，低层用选项执行。**抽象屏障**：动作只能在某一层的选项内生成，不允许在两层的动作/子目标间做线性插值。

**定义 312（分层不确定性账本 CUL）** 不确定性对象 U = {U_ale^ℓ, U_epi^ℓ, locus(·), channel(·), evidence(·), V_ev(·)}_{ℓ=0..L}。两个新失效模式：
- **向下泄漏（downward leakage）**：U_epi^ℓ 未消解却被当作 U_ale^{ℓ−1} 吸收（表现为低层「噪声大」或轨迹被平滑，看起来合法）；
- **向上膨胀（upward inflation）**：U_ale^{ℓ−1} 被误判为 U_epi^ℓ（深度噪声被读成「任务不确定」），触发不必要的重规划/提问。
CUL 不变式：任何 U 的下降必须登记「由哪个 channel、哪条 evidence、其有效性 V_ev 是多少」；无登记不得下降。

**定义 313（深度有效性场 DVF）** 对每个决策相关像素/面片 x，有效性后验 V_d(x)=P(valid|x)，失效类 F={valid, transparent, specular, textureless, thin, out_of_range, occluded, multipath, adversarial}。每类携带**结构化误差模型** ε_f（如 transparent: D_meas(x)≈D_bg(x)，且局部平面拟合残差反而更小）。DVF 输出 (V_d, argmax f, 不可验证标记 u(x))；u=1 表示现有证据在该面片上无法区分 valid 与某失效类。

**定义 314（同视图不可辨识性）** 令 𝒟_view 为单视图深度/法向/残差统计，𝒢 为真实几何。存在非平凡核 K：对 x∈K，存在另一几何 𝒢'≠𝒢（如「玻璃后是空的」vs「玻璃」），使 𝒟_view(𝒢)≈𝒟_view(𝒢') 在传感器噪声内。任何仅依赖 𝒟_view 的判据（含在同视图残差上训练的判别器）在 K 上不可辨识。⇒ **外部证据是必要条件，不是性能增强。**

**定义 315（视差主动验证 PAV）** 信息动作 g_par = 沿基线 b 的平移/主动光照。视差一致性：用当前几何假设 H 把 t 时刻深度重投影到 t+1，r_par(H)=‖D_{t+1}−W(D_t,T;H)‖ 限制在 supp(H)。对「真实表面」与「透明→背景」两个假设，r_par 的期望差随 b 与深度差增长（引理 21）。PAV 把 R69 的注视/移动信息动作落到「几何可辨识性」上。

**定义 316（跨层接地证书 CGC）** 高层命题 φ（「通路无遮挡」「杯子可抓」）有几何支撑集 S(φ) 与谓词裕度 m(φ)。接地证书 Ground(φ)=1 ⇔
(i) S(φ) 中决策相关面片 V_d ≥ τ_v；
(ii) m(φ) ≥ 3σ_geo（裕度显著）；
(iii) 若存在 u=1 或 V_d<1，则至少一条外部证据（视差/跨模态/接触）确认。
否则 φ 为 ungrounded：高层不得据此行动，只能下降取证或上升重规划，**不得混合**。

**定义 317（分层 VoI 分配器 H-VOI）** 候选三元组 (ℓ_amb, ℓ_act, g)。**适度分辨率原则**：ℓ_amb 是歧义所在层，ℓ_act 是证据动作所在层，二者可以不同（本轮核心）。边际 VoI_{ℓ_amb}(g) = 因消解 ℓ_amb 层歧义而降低的**计划级期望风险**（不是局部轨迹误差）。选择 (ℓ*,g*) = argmax [VoI_{ℓ_amb}(g) − c_{ℓ_act}(g)]，约束：evidence(g) 对 ℓ_amb 有效（V_ev ≥ τ_ev）；ℓ_amb 必须是该歧义**最粗的可行动层**（在此之上消解不改变计划）。若无正收益或外部证据不可得 → 不交互，走定义 325 退避。

**定义 318（分层预算 SAB）** 预算 B 按层分配：B_ℓ 由水位填充使各层边际 VoI/成本相等，并对高层的「风险在险」（错误子目标的期望损失）设下限配额；硬约束 Σ_ℓ B_ℓ ≤ B，低层不得占用高层预留。同一证据不重复购买（缓存），并对「预算耗尽攻击」设每层单调计数器。

**定义 319（深度故障监视 DFM 与自洽幻觉判据）** DFM 综合：同视图残差（弱）、视差残差 r_par（强）、跨模态差（立体/ToF/结构光）、时间持续性、RGB 语义-材料先验，输出 V_d 与 unverifiable。**自洽幻觉判据**：r_geo≈0 ∧ (r_par↑ ∨ u=1) ⇒ 疑似「自洽的假几何」。这是 R68 (r_res↓) 与 R69 (Δa↑) 在几何侧的第三次镜像；关键补充：**Δa 对自洽幻觉不敏感**（假世界里的行为依然高似然），因此必须新增 r_par 这条外部通道。

**定义 320（分层证据纪律）** 高层符号命题的证据必须「层级适配且几何有效」：单视图深度永远不算独立证据；深度 + 一条外部证据（或两条正交外部证据）才可定案。继承 R69 的 k-正交一致，但把「单视图」从合格源中剔除。

**定义 321（意图-可行性双证书 FDC）** 每个子目标 z^ℓ 需 (a) 语义证书：与任务及已认证证据一致；(b) 可行性证书：低层在当前**已接地**几何下给出可达/无碰/时间窗证书。任一失败 ⇒ 高层必须**修订子目标**，不得把不可行下推为「执行噪声」。这是对分层幻觉的直接检查。

**定义 322（分层干扰集 ℰ_STRATA）** = ℰ_FLUID × ℰ_depth × ℰ_plan。ℰ_depth：镜面/玻璃注入、投影仪伪造视差、红外致盲、对抗纹理、flying pixel；ℰ_plan：看似合理但不可行的子目标投毒、抽象屏障利用（诱导跨层混合）、预算耗尽（诱使系统在低层反复取证）、层级提升攻击（把低层噪声包装成高层歧义以触发重规划）。

**定义 323（参与式审计 VQAuditor-H）** 审计：歧义是否在正确层消解、是否用了外部证据、是否发生向下泄漏/向上膨胀、高层命题是否被单视图深度盖章、预算在层间的分布与是否被耗尽攻击。结论回灌 H-VOI 成本先验与 DVF 校准集。

**定义 324（STRATA 证书 J_STRATA）** = (J_FLUID, locus/channel, dvf_ece, unverifiable_rate, r_par_p95, cross_level_consistency, budget_by_level, plan_cert_hash, strata_ver)。Valid ⇔ Valid(J_FLUID) ∧ DVF 校准 ∧ 无 ungrounded 高层动作 ∧ 无跨层混合 ∧ 预算未越界。

**定义 325（逐层保守退避）** 每层 λ^ℓ = λ_floor(U_ale^ℓ + 未消解 U_epi^ℓ)。高层出现 ungrounded 命题或外部证据不可得 ⇒ **高层冻结（hold-and-gather）**：不执行新子目标，低层在已验证区域维持安全驻留。这比 R69 的「整体放慢」更精确——不是所有关节一起变慢，而是**在错误的那一层停住**。退化：L=1 且 V_d≡1 ⇒ 逐指令等于 R69。

**定义 326（深度校准门 DCG）** DVF 的可靠性用 ECE 与「不可验证召回率」衡量；ECE>τ 或 unverifiable 被系统性漏报 ⇒ 关闭自主几何接地，退化为 R69（把深度当普通带噪观测，不做高层几何断言）。这是 R69 MCG 的几何版：**不让不可信的「有效性判断」去给世界盖章。**

## 2. 关键算法骨架

```python
# IP-264 HPA：分层规划（任务/子目标/轨迹；发子目标，不混合层）
class HierarchicalPlanner:
    def __init__(self, planners, option_lib, L=2):
        self.planners, self.options, self.L = planners, option_lib, L
    def propose(self, s_abs, level):
        return self.planners[level].propose(s_abs)      # z^level
    def switch(self, z, level):                         # 只允许层内选项
        return self.options[level].instantiate(z)

# IP-266 DVF：深度有效性场（只算 ROI，输出不可验证标记）
def depth_validity(depth, rgb, roi, dvf_net):
    V, fcls, unver = dvf_net(depth, rgb, roi)
    return V, fcls, unver

# IP-267 PAV：视差主动验证（几何假设重投影一致性）
def parallax_residual(H, D_t, D_next, T, mask):
    return norms(D_next - warp(D_t, T, H), mask & supp(H))

# IP-268 CGC：跨层接地证书（单视图深度永不单独盖章）
def ground(phi, S_phi, V, unver, cross_modal):
    relevant = S_phi[decision_relevant(S_phi)]
    if (V[relevant] < TAU_V).any():
        if not (unver[relevant].any() or cross_modal.available(relevant)):
            return False
        if not cross_modal.confirm(phi):                 # 视差/ToF/接触
            return False
    return margin(phi) >= 3.0 * sigma_geo

# IP-269 H-VOI：在「歧义层 × 可用证据通道」上选动作（可跨层取证）
def choose_action(U, channels, budget):
    best = None
    for amb in U.unresolved_epistemic():                 # 歧义住在哪一层
        for act in channels.for_level(amb):              # 哪个动作能产生有效证据
            if not budget.allow(act) or not evidence_valid(act, amb):
                continue                                 # 无外部证据 → 不算候选
            score = plan_risk_reduction(amb, act) - cost(act)
            if best is None or score > best.score:
                best = (amb, act, score)
    return best if best and best.score > 0 else None     # 无利可图 → 逐层退避

# IP-276 主闭环：高频控制只加 ROI 深度校验；任务层在低频、非关键路径
def STRATA_round(M, obs):
    # ---- 高频：R69 基线 + 几何外部校验 ----
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    V, fcls, unver = M.dvf(obs.depth, obs.rgb, roi=M.attention_roi)
    r_par = M.pav(parallax_residual, M.last_H, M.last_D, obs.depth, obs.delta_T)
    halluc = (M.last_r_geo < TAU_RGEO) and ((r_par > TAU_PAR) or unver.any())
    if halluc:                                           # 自洽的假几何：外部证据说不
        M.cul.mark_invalid(M.attention_roi, fcls)
        unver = unver | M.attention_roi                  # 保守：不可验证视同无效
    # ---- 语义层：只在已接地几何上提出/认证命题 ----
    phi = M.hpa.predicates(level=1)
    grounded = {p: M.cgc.ground(p, M.support(p), V, unver, M.cross_modal) for p in phi}
    z_sub = M.hpa.propose(M.state_abs, level=1)
    feas  = M.fdc.check(z_sub, V, unver)                 # 可行性双证书
    if (not all(grounded.values())) or (not feas):
        # 高层不凭单视图深度行动：要么上升重规划，要么下降取证，禁止混合
        up = M.hpa.propose(M.state_abs, level=2)
        M.cul.escalate(level=1, reason="ungrounded_or_infeasible")
        return M.freeze_high_level(up)                   # 定义 325：停错的那一层
    # ---- 不确定性的层级化处置（locus × channel）----
    U = M.cul.snapshot()                                 # 每个未消解项带 locus
    act = M.hvoi.choose_action(U, M.channels, M.budget)
    if act is not None:
        l_amb, g, _ = act
        ans = M.execute_info(g)                          # 视差/问/触，均过认证
        M.cul.resolve(l_amb, evidence=ans, V_ev=M.evidence_validity(g))
    else:
        M.cul.keep_unresolved()
    # ---- 逐层 λ + 执行 ----
    lam = {l: max(M.efs.risk_scale(l), lam_floor(M.cul.U_ale[l] + M.cul.U_epi_open[l]))
           for l in range(M.hpa.L + 1)}
    k = M.c_ras_wm.certified_prefix(M.hpa.switch(z_sub, 1), ...)
    M.vqa_h.submit_async(U, grounded, r_par, M.budget.by_level())
    return k, lam, z_sub, U

## 3. 推导

**引理 19（层级失配代价）** 设歧义 locus 在 ℓ_a，改变 ℓ_a 计划的最小风险降幅为 R*。若在 ℓ'<ℓ_a 用细层证据消解：细层证据不能改变粗层抽象动作，对 ℓ_a 计划 VoI=0，却消耗成本 c；若在 ℓ'>ℓ_a：遗漏 ℓ_a 的未消解项，被迫 λ_floor(U_epi^{ℓ_a})，代价 ≥ Δλ·D_task。故最优层 ℓ*=ℓ_a；跨层仍可有正收益，当且仅当「channel 在 ℓ_act≠ℓ_a，但其证据对 ℓ_a 有效」（如低层侧移回答高层的玻璃问题）。系：**locus 与 channel 可分离，但必须逐项记账，否则会退化成向下泄漏或向上膨胀。**

**引理 20（同视图深度不可辨识性）** 存在开集 K（透明/镜面/细结构），使 𝒟_view(𝒢) 与 𝒟_view(𝒢') 的分布 TV 距离 ≤ ε_sensor。任何只依赖 𝒟_view 的判别器（含学习型）在 K 上 AUROC ≤ 0.5+ε。推论：R68 残差与 R69 Δa 在 K 上均无判别力——Δa 用的是策略似然，而假世界中行为自洽 ⇒ Δa≈0。故「外部」是获得可辨识性的必要条件。

**引理 21（视差分离条件与物理下限）** 基线 b、表面距离 d_s、背景距离 d_b 下，真实表面假设与「透明→背景」假设的视差残差期望差 ≥ c·b·|1/d_s − 1/d_b| − σ_d。故存在最小基线 b_min = (τ_par+σ_d)/(c·|1/d_s−1/d_b|)；当 |d_s−d_b|→0（玻璃贴背景）时 b_min→∞，视差失效，必须换模态或标记 unverifiable。系：**可辨识性有物理下限，算法不能凭空补出信息。**

**引理 22（分层 VoI 的次模性与贪心界）** 若层间不确定性在给定已消解父层后条件独立，则集函数 f(S)=E[计划风险降幅] 单调次模；按边际 VoI/成本贪心分配预算达 (1−1/e) 近似，层级配额保证高层不被低层饿死。系：SAB 的水位填充有近似保证，且「预算耗尽攻击」只能降低效率、不能危及安全（因为退避单调）。

**定理 18（STRATA 严格包含 R69/R68）** L=1 ∧ V_d≡1 ⇒ 逐指令等于 R69；再令 VoI≤成本 ⇒ 等于 R68。安全侧严格不弱：任一外部证据失败/不可得/unverifiable ⇒ λ 单调不降，且高层冻结。故 R70 不引入新的不安全动作，只在可外部验证处购买效率。

**定理 19（无幻觉接地与无跨层混合）** 在 DVF 校准（ECE≤τ）且证据纪律成立时，任何被执行的高层命题 φ 满足 Ground(φ)=1 且 FDC=1；若存在自洽幻觉，则必然 u=1 或 r_par↑，被 DFM 捕获 ⇒ 不执行。禁止跨层混合 ⇒ 不存在「两条子目标的平均」这类无意义动作。故高层错误不会被低层「平滑地执行成事故」，而是被冻结在错误的那一层。

**定理 20（外部证据必要性与安全单调）** 由引理 20，任何无外部证据的自主几何接地在 K 上可被任意欺骗；由引理 21，b≥b_min 时视差可分离。故「外部证据不变式」是 K 上获得可辨识性的必要条件；而把 unverifiable 当 invalid 只增加保守性 ⇒ 安全性对观测欺骗单调不降。这是「负结果 + 构造」的组合：既证明为什么必须主动，也给出何时主动有效。

## 6. 本轮最大风险

**一句话**：STRATA-RAS 把「深度是否可信」交给一个同样由数据学出来的 DVF——**如果这个有效性估计器本就在同视图特征上训练，它就继承了引理 20 的不可辨识性，会把「自洽但错误」的几何认证为有效；一旦它把不可验证误判为可验证（或被镜面/投影伪造的外部证据骗过），分层规划会把假世界盖章成真、再高效地传播到任务层，而自洽幻觉判据本身也可能被同一盲区蒙住**——深度让错误看起来更真，分层让错误传得更快。

**次级风险与缓解**：
1. **DVF 是新的信任单点** → 强制外部证据不变式（定义 310-v）；DCG 以 ECE 与不可验证召回率门控，越界即退回 R69；
2. **视差在玻璃贴背景时物理失效** → 引理 21 给出 b_min，做不到就换模态/接触或标记 unverifiable，绝不硬猜；
3. **分层幻觉（不可行子目标）** → FDC 可行性双证书 + 高层修订而非下推；
4. **向下泄漏/向上膨胀** → CUL 逐项记账 + 禁止跨层混合 + E307 消融；
5. **预算耗尽与层级提升攻击** → SAB 高层预留 + 每层单调计数器 + ℰ_plan 对抗训练。

**定义 319（DFM 与自洽幻觉）** 自洽幻觉判据 `r_geo≈0 ∧ (r_par↑ ∨ u=1)`；强调 Δa 对自洽幻觉不敏感，故必须新增 r_par 外部通道。

**定义 320–321（分层证据纪律与 FDC）** 单视图深度不算独立证据；子目标需语义证书 + 低层可行性证书，不可行则高层修订而非下推。

**定义 325–326（逐层退避与 DCG）** 每层独立 λ^ℓ；高层 ungrounded/外部证据不可得 ⇒ hold-and-gather，在错误层停住；DVF 的 ECE 与不可验证召回越界 ⇒ 关闭几何接地、退回 R69。

        l_amb, g, _ = act
        ans = M.execute_info(g)                            # 视差/问/触，均过认证
        M.cul.resolve(l_amb, evidence=ans, V_ev=M.evidence_validity(g))
    lam = {l: max(M.efs.risk_scale(l),
                  lam_floor(M.cul.U_ale[l] + M.cul.U_epi_open[l]))
           for l in range(M.hpa.L + 1)}
    k = M.c_ras_wm.certified_prefix(M.hpa.switch(z_sub, 1), ...)
    M.vqa_h.submit_async(M.cul.snapshot(), grounded, r_par, M.budget.by_level())
    return k, lam, z_sub, M.cul.snapshot()
```

## 4. 推导

**引理 19（层级失配代价）** 歧义 locus 在 ℓ_a 时，在 ℓ'<ℓ_a 消解对 ℓ_a 计划 VoI=0 却耗成本；在 ℓ'>ℓ_a 消解遗漏 ℓ_a 未消解项，被迫 λ_floor，代价 ≥ Δλ·D_task。故最优层 ℓ*=ℓ_a；跨层正收益当且仅当证据动作在 ℓ_act≠ℓ_a 但对 ℓ_a 有效。系：locus 与 channel 可分离，但须逐项记账。

**引理 20（同视图深度不可辨识性）** 存在退化集 K，使 𝒟_view(𝒢) 与自洽假几何 𝒟_view(𝒢') 的 TV 距离 ≤ ε_sensor；任何同视图判据 AUROC ≤ 0.5+ε。推论：R68 残差与 R69 Δa 在 K 上均失效（假世界里行为自洽 ⇒ Δa≈0），外部证据是必要条件。

**引理 21（视差分离与物理下限）** 真实表面与「透明→背景」假设的视差残差期望差 ≥ c·b·\|1/d_s−1/d_b\|−σ_d；b_min=(τ_par+σ_d)/(c\|1/d_s−1/d_b\|)。玻璃贴背景时 b_min→∞，视差失效，须换模态或标 unverifiable。

**引理 22（分层 VoI 次模性）** 层间条件独立时，计划风险降幅集函数单调次模，贪心预算分配达 (1−1/e) 近似；层级配额保证高层不被饿死。

**定理 18（严格包含 R69/R68）** L=1 ∧ V_d≡1 ⇒ 逐指令等于 R69；再 VoI≤成本 ⇒ 等于 R68。安全侧严格不弱：外部证据失败/不可得/unverifiable ⇒ λ 单调不降且高层冻结。

**定理 19（无幻觉接地/无跨层混合）** DVF 校准且证据纪律成立时，被执行的高层命题均 Ground=1 ∧ FDC=1；自洽幻觉必触发 u=1 或 r_par↑ 而被 DFM 捕获；禁止混合 ⇒ 无「子目标平均」类无意义动作。

**定理 20（外部证据必要性与安全单调）** 由引理 20，无外部证据的自主几何接地在 K 上可被任意欺骗；由引理 21，b≥b_min 时视差可分离。故外部证据不变式是可辨识性的必要条件；把 unverifiable 当 invalid 只增保守性 ⇒ 安全性对观测欺骗单调不降。

## 7. 本轮最大风险

**一句话**：STRATA-RAS 把「深度是否可信」交给一个同样由数据学出来的 DVF——**若它在同视图特征上训练，就继承引理 20 的不可辨识性，会把「自洽但错误」的几何认证为有效；一旦它把不可验证误判为可验证（或被镜面/投影伪造的外部证据骗过），分层规划会把假世界盖章成真并高效传播到任务层，而自洽幻觉判据本身也可能被同一盲区蒙住**——深度让错误看起来更真，分层让错误传得更快。

**次级风险与缓解**：DVF 成为新信任单点（强制外部证据 + DCG 门控 + 越界退回 R69）；玻璃贴背景时视差物理失效（引理 21 的 b_min，做不到则换模态/接触或标 unverifiable）；分层幻觉（FDC 双证书 + 高层修订）；向下泄漏/向上膨胀（CUL 记账 + 禁止跨层混合 + E307）；预算耗尽与层级提升攻击（SAB 高层预留 + 每层计数器 + ℰ_plan 对抗训练）。
