# 第 68 轮（承接第 67 轮「SimRAS 仿真增强闭环」IP-233~242；新灵感循环第 1 轮；本轮灵感：「用户共创」×「运动规划」）

> 第 67 轮 SimRAS 把「在线反应式情绪闭环」升级为「离线仿真预训练 + 在线世界模型推理 + 视觉问答审计」的三层结构，核心是让系统能**预演未来、审计风险**。但它仍然把用户放在闭环之外：用户要么是提供表情/偏好的“信号源”，要么是 VQA 审计的“被解释对象”。**用户从未真正进入运动规划的编辑回路**——而现实中，人机共处的核心摩擦恰恰发生在“这条轨迹该不该这么走”的作者权归属上。
>
> 本轮灵感的核心命题是：
>
> **把「认证执行」升级为「认证共创（Certified Co-Creation）」：让用户成为运动规划的 co-author，拥有软偏好与局部轨迹的编辑权；让机器保留硬安全否决权与最小修复权；双方在共享仿真与反事实解释中协商，所有执行都落在可审计的「认证共创前缀」内。**
>
> CoMP 问的不再是「未来风险怎么演化」，而是「**这条轨迹是谁写的、改了什么、凭什么安全、出事谁负责**」。它把“用户共创”从交互口号变成可形式化、可认证、可追溯的作者权契约。

## 0. 直觉与动机

**灵感 1（用户共创 → 从“审批”到“共著”）**
直觉：当前运动规划的人机交互是**单向委托**：用户给目标，机器人算轨迹，用户只能接受或拒绝。这不是共创，是审批。真正的共创要让人能对轨迹做局部编辑——拖动一个途经点、划出一条“不要经过这里”的走廊、把速度在儿童附近调慢、用一句话说“绕过那盆花”。关键不是“让用户随便改”，而是**让每一次编辑都被翻译成约束、投影回可行流形、再重新认证**。共创的产物不是一条命令，而是一份双方签字的**契约**。

**灵感 2（运动规划 → 规划流形上的“编辑几何”）**
直觉：高维轨迹空间不能直接暴露给用户。但扩散策略/采样规划器生成的候选轨迹其实集中在一个低维**规划流形 M** 上。用户的编辑应当先被投影 `Π_M` 回这个流形，再谈安全性。这样，“用户共创”就获得了严格的几何含义：**编辑 = 流形上的局部约束算子；共创 = 约束算子的迭代合成**。运动规划由此从“求解一条最优轨迹”变成“共同书写一组约束并求解其可行解”。

**灵感 3（作者权与安全权的分离 → 共创契约）**
直觉：如果用户能直接写硬安全约束，证书就失去意义；如果机器可以静默改写用户意图，共创就退化为伪装。正确做法是**权限分层**：
- 用户拥有 `BINDING_SOFT`（绑定软偏好）与 `ADVISORY`（建议）的作者权；
- 机器独占 `CERTIFIED_HARD`（认证硬安全）的否决权；
- 中间冲突由**最小修复 + 反事实解释**协商，且必须留痕。
这就是「共创契约」：它把“谁说了算”从一个模糊的交互问题，变成一个带作者权账本的可审计状态机。

**灵感 4（RAS 情绪 → 认知负荷与信任校准，而非风险缩放）**
直觉：第 66 轮把表情当作风险缩放因子；但在共创场景里，用户频繁编辑、反复撤销、长时间停留，往往不是“高风险”，而是**界面难用、解释不清、认知负荷过高**。因此情绪信号应降格为**元信号**：它调节解释的粒度、协商的节奏、偏好学习的步长，但**绝不静默删去用户的绑定约束**。这是伦理红线：低信心不能成为剥夺作者权的理由。

**灵感 5（SimRAS 组件复用 → 共享仿真与辩证解释）**
直觉：SimRAS 的 WorldModel 不应只服务于机器，而应成为**人机共享的想象空间（SharedSim）**：用户看到自己编辑后的未来演化，机器也看到用户的意图后果。VQAuditor 则从“审计员”升级为**辩证解释器（Dialectic Explainer）**：当用户编辑不可行时，它不只说“不行”，而是给出“最小改动能让它可行”的反事实。C-RAS-WM 的认证前缀自然扩展为**认证共创前缀**：用户草稿可以很长，但只有被认证的前缀才能执行。

**灵感 6（灵感合流 → CoMP：Co-Creative Motion Planning）**
CoMP 从 SimRAS 继承时序骨架，换装为：
1. **CoManifold**：扩散/采样规划流形 + 可微投影，承接用户编辑；
2. **EditOperator**：把六类用户编辑翻译成约束算子 `(φ_e, w_e, scope_e)`；
3. **CoContract**：硬安全 `H`、软偏好 `S`、作者权账本 `A`、协商状态 `∂`；
4. **AgencyLedger**：记录每条约束的作者、权限、依据、有效期与签名；
5. **PrefPosterior**：用贝叶斯逆最优控制从稀疏编辑中推断偏好后验；
6. **CoCert**：认证共创前缀 `k*_CC`，任何执行都必须落在其中；
7. **SharedSim + Dialectic**：共享世界模型预演 + 反事实解释闭环；
8. **TrustCalibrator**：用 RAS 情绪与编辑行为估计认知负荷，调节解释而非削权；
9. **AIC-CoMP**：把恶意编辑、作者权伪造、契约过期（TOCTOU）纳入干扰集；
10. **J_CoMP**：带作者权账本哈希、同意签名、修复轨迹哈希的共创证书。

## 1. 形式化定义（增量：定义 266–280）

- **定义 266（CoMP 总览）**：`CoMP = (M, E, C, L, P_θ, CC, SS, D, J)`，其中 M 为规划流形，E 为编辑算子，C 为共创契约，L 为作者权账本，P_θ 为偏好后验，CC 为认证共创前缀，SS 为共享仿真，D 为辩证解释器，J 为共创证书。不变式：实时流只做投影、认证、前缀派发；偏好学习、契约协商、解释在语义流；**用户永不直接写 `CERTIFIED_HARD`**。
- **定义 267（规划流形）**：`M = {G(z) : z ∈ Z ⊂ ℝ^d}`，G 为扩散/采样规划器；投影 `Π_M(τ) = argmin_{τ'∈M} ||τ − τ'||_W`。局部图表 `(U_τ, φ_τ)` 用于编辑的切空间表示。
- **定义 268（编辑算子）**：用户编辑 `e_t = (κ, u, v, ttl, prov)`，`κ ∈ {WAYPOINT, CORRIDOR, SPEED, SOCIAL, STOP, LANG}`。`E(e) = (φ_e, w_e, scope_e)`：φ_e 为符号约束函数，w_e 为偏好权重，scope_e 为时空作用域。LANG 类先经解析器转成前五类之一，解析失败则降级为 `ADVISORY`。
- **定义 269（共创契约）**：`C_t = (H_t, S_t, A_t, ∂_t, h_t)`，H 为机器认证的硬安全约束，S 为用户/机器共同编写的软偏好约束，A 为作者权账本，∂ ∈ {PROPOSE, NEGOTIATE, AGREED, EXECUTE, REVOKE} 为协商状态，h_t 为契约哈希。**共创可行**：`co_feasible(C) ⇔ ∃τ∈M, H(τ)=⊤ ∧ violation(S,τ) ≤ ε_S`。
- **定义 270（作者权账本）**：`L = {(c_i, owner_i, auth_i, basis_i, ttl_i, sig_i)}`，`owner ∈ {U, R, BOTH}`，`auth ∈ {ADVISORY, BINDING_SOFT, VETO_ONLY, CERTIFIED_HARD}`，`basis ∈ {user_edit, user_demo, robot_infer, safety_cert}`。不变式：`owner = U ⇒ auth ≠ CERTIFIED_HARD`；每条执行轨迹的每个生效约束必须能在 L 中找到未过期的签名条目。
- **定义 271（偏好后验）**：`P(θ | E_{1:t}) ∝ P(θ) ∏_i p(e_i | θ)^{r_i}`，编辑似然 `p(e|θ) ∝ exp(β [R_θ(τ_e) − R_θ(Π_M(e))])`，`r_i` 为可靠性权重（来自定义 272）。R_θ 为轨迹特征（净空、速度、社交距离、舒适度）的加权回报。
- **定义 272（认知负荷与可靠性）**：`L_cog = w1·R_emotion + w2·H_edit + w3·undo_rate + w4·dwell`，其中 `H_edit` 为编辑熵；`r_t = σ(−(L_cog − τ_load))`。**用途约束**：`r_t` 只能调节解释粒度与学习率，不能直接删改 `BINDING_SOFT` 约束。
- **定义 273（最小修复）**：`repair(e) = argmin_{τ∈M, H(τ)=⊤} d_M(τ, Π_M(τ_e))`，权重 d_M 同时计入几何偏离与语义编辑成本。若修复不可行，输出**反事实** `Δe* = argmin_{Δ∈ΔE} ||Δ||  s.t. co_feasible(C ⊕ Δ)`。解释对为 `(repair, Δe*)`。
- **定义 274（认证共创前缀）**：`k*_CC = min(k_VISTA, k_emo, k_wm, k_edit, m)`，其中 `k_edit = max{k : ∀s≤k, H(τ_s)=⊤ ∧ authority_ok(s) ∧ λ_risk(s)·ρ_safe(s) ≥ 0}`。`authority_ok(s)` 要求前缀内所有约束在 L 中有效、签名正确、未过期，且无用户伪造的硬约束。
- **定义 275（Agency Handshake 状态机）**：∂ 上的迁移函数 `δ_∂ : (C, e, verdict) → (C', ∂')`。关键迁移：`PROPOSE →(edit) NEGOTIATE →(repair) NEGOTIATE →(consent) AGREED →(execute) EXECUTE`；任一状态超时 → `SAFE_HOLD` 并回到 `NEGOTIATE`。**无同意不执行用户修改后的轨迹**。
- **定义 276（解释-编辑一致性）**：设 D 的解释诱导的编辑分布为 `Q_D(e | τ, repair, Δe*)`，实际编辑直方图为 `Q̂`，一致性 `c_t = 1 − TV(Q_D, Q̂)`。`c_t < τ_exp` 触发重解释或提高解释粒度。
- **定义 277（共创证书）**：`J_CoMP = (J_SimRAS, contract_hash, ledger_hash, pref_post_ver, repair_trace_hash, consent_sig, explanation_hash)`。`Valid ⇔ Valid(J_SimRAS) ∧ consent_sig 有效 ∧ 无静默覆盖 ∧ k*_CC ≥ 1`。
- **定义 278（无静默覆盖）**：对执行前缀内每一帧 s，若 `τ_s ≠ τ^U_s`，则必须存在一条已记录的修复条目，其 `repair_trace_hash` 与证书一致。否则 `J_CoMP` 无效。
- **定义 279（AIC-CoMP 干扰集）**：`ℰ_CoMP = ℰ_SimRAS × ℰ_edit × ℰ_auth × ℰ_contract`。`ℰ_edit`：对抗编辑、编辑注入、快速振荡；`ℰ_auth`：作者权伪造、重放编辑、伪造同意；`ℰ_contract`：陈旧契约、检查-执行间契约替换（TOCTOU）。
- **定义 280（安全-作者权帕累托目标）**：`maximize_{τ∈M} U_intent(τ;θ) + γ·A(τ)  s.t. H(τ)=⊤`，其中 `A(τ)` 为绑定软偏好的满足度。优先级为字典序：**硬安全 > 作者权满足 > 意图效用 > 解释成本**。

## 2. 关键算法骨架

```python
# CoMP 主循环：共创一轮
def CoMP_round(S, obs, user_edit=None):
    # 1) 感知 + 候选规划流形
    x = S.perceive(obs)
    A = S.planner.propose_manifold(x, k=S.K)          # 候选轨迹族
    wm = S.wm.rollout(x, A.actions, k=S.K)             # SharedSim 预演

    # 2) 机器侧提出契约草案（硬安全不可编辑）
    H = S.safety.hard_constraints(x, wm)               # CERTIFIED_HARD
    C = S.contract.propose(H, S.ledger, S.pref_post)

    # 3) 用户共创：编辑 → 投影 → 可行性核验
    if user_edit is not None:
        e = S.edit.parse(user_edit)                    # 六类编辑算子
        C = S.contract.apply(C, e, auth='BINDING_SOFT')
        tau_u = S.planner.project(user_edit, A)

        if not S.contract.co_feasible(C, tau_u):
            repair = S.repair.minimal(tau_u, H)
            cf = S.repair.counterfactual(tau_u, C, tau_u)
            S.dialectic.explain(repair, cf)            # 反事实对话
            C = S.contract.renegotiate(C, cf)          # 需用户 consent
        else:
            S.pref_post.update(e, reliability=S.trust.reliability())
        S.dialectic.render(wm, C)                      # 共享仿真呈现

    # 4) 认证共创前缀
    k_cc = S.cocert.prefix(A, C, wm, S.risk)

    # 5) 未达成同意 / 认证失败 → 安全保持，不执行用户草稿
    if k_cc == 0 or C.state != 'AGREED':
        return S.safe_hold(A), C

    # 6) 执行 + 作者权账本落账 + 异步辩证审计
    S.ledger.commit(C, k_cc)
    S.execute(A[:k_cc], C)
    S.vqa.submit_async(wm, C, k_cc)
    return k_cc, C


# 最小修复：在认证硬安全集上做投影
class MinimalRepair:
    def minimal(self, tau_u, H):
        return self.manifold.project_onto_safe_set(tau_u, H)

    def counterfactual(self, tau_u, C, tau):
        # 找最小约束松弛 Δe，使编辑后轨迹可行
        for delta in sorted(self.delta_pool, key=lambda d: d.cost):
            if C.relax(delta).co_feasible(tau):
                return delta
        return None


# 认证共创前缀：安全 + 作者权 + 风险系数三重校验
class CertifiedCoCreation:
    def prefix(self, A, C, wm, risk):
        k = 0
        for s in range(1, min(len(A), self.m) + 1):
            if not self.H_ok(A[s]) or not C.authority_ok(s):
                break
            if risk.lambda_risk(s) * risk.rho_safe(s) < 0:
                break
            if wm[s].violates_hard_constraint(A[s]):
                break
            k = s
        return min(k, self.k_vista, self.k_emo, self.k_wm)
```

## 3. 推导

**引理 13（投影-修复误差界）** 若流形 M 的投影误差为 `ε_proj`，硬安全集到 `Π_M(τ_e)` 的距离为 `d_H`，则最小修复满足 `d_M(repair, Π_M(τ_e)) ≤ d_H + ε_proj`；修复后安全裕度至少下降 `(1+κ)·ε_proj`（κ 为 H 的 Lipschitz 常数）。因此只要 `ε_proj` 可标定，修复的安全代价可被证书显式记账。

**引理 14（偏好后验一致性）** 在编辑似然可辨识、可靠性权重 `r_i` 与给定 θ 下的编辑独立时，后验以 `O(1/√(Σr_i))` 的速率收缩到真参数 θ*；若 `r_i` 低估高认知负荷用户，则有效样本量下降，但估计无偏。**这给出一个反直觉结论：降低低负荷用户的权重会减慢学习，却不该被用来“纠正”其偏好。**

**定理 14（认证共创的任意编辑安全性）** 对任意用户编辑序列（含对抗编辑），只要执行轨迹取自 `k*_CC` 前缀，则
`P(violation) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_proj`。
安全性不依赖用户意图，只依赖硬约束集 H 的完备性与投影误差界。

**定理 15（无静默作者权劫持）** 若 `J_CoMP` 有效，则每条执行轨迹相对用户草稿的偏离都可追溯到一条已记录的最小修复；用户 `BINDING_SOFT` 约束只能被显式重协商，不能被静默丢弃。故作者权是**可审计的**，而非口头承诺。

**定理 16（共创收敛与升级）** 在共享回报、有限理性编辑与有界修复步长下，交替“用户编辑—机器修复”在 `ε`-共创可行点收敛或进入升级（改为人工接管），所需轮数上界为 `O((1/ε)^2)`；若用户偏好与硬安全集不相容，系统必定升级而非静默妥协。

**定理 17（对抗编辑只降可用性、不破安全性）** 在编辑预算 B 下，对抗编辑最多使认证前缀长度从 k 缩到 0（拒绝服务），但不会使任何已认证前缀违反 H；即 `Pr[violation | adversarial] ≤ Pr[violation | benign] + α_auth`，其中 α_auth 由作者权签名与 TOCTOU 防护给出。

## 2. 形式化定义（完整版）

**定义 266（CoMP 总览）**
```
CoMP = (M, E, C, L, P_θ, CC, SS, D, J)
```
其中 M 为规划流形，E 为编辑算子，C 为共创契约，L 为作者权账本，P_θ 为偏好后验，CC 为认证共创前缀，SS 为共享仿真，D 为辩证解释器，J 为共创证书。
不变式：实时流只做投影、认证、前缀派发；偏好学习、契约协商、解释在语义流；**用户永不直接写 `CERTIFIED_HARD`**。

**定义 267（规划流形）**
```
M = {G(z) : z ∈ Z ⊂ ℝ^d},   Π_M(τ) = argmin_{τ'∈M} ||τ − τ'||_W
```
G 为扩散策略或采样规划器。编辑在局部图表 `(U_τ, φ_τ)` 的切空间中表示，保证投影可微。

**定义 268（编辑算子）**
```
e_t = (κ, u, v, ttl, prov),  κ ∈ {WAYPOINT, CORRIDOR, SPEED, SOCIAL, STOP, LANG}
E(e) = (φ_e, w_e, scope_e)
```
φ_e 为符号约束函数（正=满足，负=违反），w_e 为偏好权重，scope_e 为时空作用域。LANG 先解析为前五类，失败则降级为 `ADVISORY`。

**定义 269（共创契约）**
```
C_t = (H_t, S_t, A_t, ∂_t, h_t),  ∂_t ∈ {PROPOSE, NEGOTIATE, AGREED, EXECUTE, REVOKE}
co_feasible(C) ⇔ ∃τ∈M, H(τ)=⊤ ∧ violation(S,τ) ≤ ε_S
```
H 为机器认证的硬安全约束，S 为软偏好约束，A 为作者权账本，h_t 为契约哈希。

**定义 270（作者权账本）**
```
L = {(c_i, owner_i, auth_i, basis_i, ttl_i, sig_i)}
owner ∈ {U, R, BOTH};  auth ∈ {ADVISORY, BINDING_SOFT, VETO_ONLY, CERTIFIED_HARD}
basis ∈ {user_edit, user_demo, robot_infer, safety_cert}
```
不变式：`owner = U ⇒ auth ≠ CERTIFIED_HARD`；任一执行轨迹的每个生效约束必须对应 L 中未过期且签名有效的条目。

**定义 271（偏好后验）**
```
P(θ | E_{1:t}) ∝ P(θ) · ∏_i p(e_i | θ)^{r_i}
p(e | θ) ∝ exp(β [R_θ(τ_e) − R_θ(Π_M(e))])
```
R_θ 为轨迹特征（净空、速度、社交距离、舒适度）的加权回报；更新用镜像下降，步长 ∝ 平均可靠性 `r̄`。

**定义 272（认知负荷与可靠性）**
```
L_cog = w1·R_emotion + w2·H_edit + w3·undo_rate + w4·dwell
r_t = σ(−(L_cog − τ_load))
```
用途约束：`r_t` 只能调节解释粒度与学习率，**不能删改 `BINDING_SOFT` 约束**。删改必须走显式重协商并记录 consent。

**定义 273（最小修复与反事实）**
```
repair(e) = argmin_{τ∈M, H(τ)=⊤} d_M(τ, Π_M(τ_e))
Δe* = argmin_{Δ∈ΔE} ||Δ||  s.t. co_feasible(C ⊕ Δ)
```
d_M 同时计入几何偏离与语义编辑成本（改一个途经点 < 改一条走廊）。解释对 `(repair, Δe*)`。

**定义 274（认证共创前缀）**
```
k*_CC = min(k_VISTA, k_emo, k_wm, k_edit, m)
k_edit = max{k : ∀s≤k, H(τ_s)=⊤ ∧ authority_ok(s) ∧ λ_risk(s)·ρ_safe(s) ≥ 0}
```
`authority_ok(s)`：前缀内约束在 L 中有效、签名正确、未过期，且无用户伪造的硬约束。

**定义 275（Agency Handshake 状态机）**
```
δ_∂ : (C, e, verdict) → (C', ∂')
PROPOSE --edit--> NEGOTIATE --repair--> NEGOTIATE --consent--> AGREED --execute--> EXECUTE
任一状态 timeout --> SAFE_HOLD --> NEGOTIATE
```
无 `consent` 不得执行用户修改后的轨迹。

**定义 276（解释-编辑一致性）**
```
c_t = 1 − TV(Q_D(e | τ, repair, Δe*), Q̂)
```
`c_t < τ_exp` 触发重解释或提高解释粒度（更具体的地理/速度约束）。

**定义 277（共创证书）**
```
J_CoMP = (J_SimRAS, contract_hash, ledger_hash, pref_post_ver,
          repair_trace_hash, consent_sig, explanation_hash)
Valid ⇔ Valid(J_SimRAS) ∧ consent_sig 有效 ∧ 无静默覆盖 ∧ k*_CC ≥ 1
```

**定义 278（无静默覆盖）**
对执行前缀内每一帧 s，若 `τ_s ≠ τ^U_s`，则必须存在一条已记录的修复条目，其 `repair_trace_hash` 与证书一致；否则 `J_CoMP` 无效。

**定义 279（AIC-CoMP 干扰集）**
```
ℰ_CoMP = ℰ_SimRAS × ℰ_edit × ℰ_auth × ℰ_contract
ℰ_edit = {对抗编辑, 编辑注入, 快速振荡}
ℰ_auth = {作者权伪造, 重放编辑, 伪造同意}
ℰ_contract = {陈旧契约, 检查-执行间契约替换(TOCTOU)}
```

**定义 280（安全-作者权帕累托目标）**
```
maximize_{τ∈M}  U_intent(τ;θ) + γ·A(τ)   s.t. H(τ)=⊤
```
A(τ) 为绑定软偏好的满足度。优先级字典序：硬安全 > 作者权满足 > 意图效用 > 解释成本。

# IP-243 CoManifold：规划流形与可微投影
class CoManifold:
    def __init__(self, generator, decoder, metric):
        self.G, self.D, self.W = generator, decoder, metric

    def propose(self, scene, k=8):
        z = self.G.sample_latent(scene, k)          # 潜在计划
        return [self.D(z_i) for z_i in z]           # 候选轨迹族

    def project(self, tau_edit, candidates):
        # 在候选流形上找加权最近轨迹，再在局部图表上微调
        tau0 = min(candidates, key=lambda t: self.W.dist(t, tau_edit))
        z = self.G.encode(tau0)
        z = self.G.refine(z, target=tau_edit, steps=3)
        return self.D(z)


# IP-244 EditOperator：六类编辑 → 约束算子
class EditOperator:
    def parse(self, raw):
        kind = self.classify(raw)                   # WAYPOINT/CORRIDOR/...
        return Edit(kind=kind, payload=raw, ttl=raw.get('ttl', 30.0),
                    provenance=raw.get('user_id'))

    def to_constraint(self, e):
        if e.kind == 'WAYPOINT':
            return Constraint(phi=lambda t: -self.dist(t, e.payload['p']),
                              w=e.payload['w'], scope=e.payload['scope'])
        if e.kind == 'CORRIDOR':
            return Constraint(phi=lambda t: -self.outside(t, e.payload['poly']),
                              w=e.payload['w'], scope=e.payload['scope'])
        if e.kind == 'SPEED':
            return Constraint(phi=lambda t: e.payload['vmax'] - self.speed(t),
                              w=e.payload['w'], scope=e.payload['scope'])
        if e.kind == 'SOCIAL':
            return Constraint(phi=lambda t: self.clearance(t) - e.payload['dmin'],
                              w=e.payload['w'], scope=e.payload['scope'])
        if e.kind == 'STOP':
            return Constraint(phi=lambda t: self.stop_respected(t),
                              w=1.0, scope=e.payload['scope'])
        return self.language_to_constraint(e)        # LANG → 前五类或 ADVISORY


# IP-245 CoContract：契约与协商状态机
class CoContract:
    def propose(self, H, ledger, pref_post):
        S = pref_post.sample_constraints()
        return Contract(H=H, S=S, ledger=ledger, state='PROPOSE')

    def apply(self, C, e, auth):
        c = e.to_constraint(e)
        c.authority = auth                         # 用户最多 BINDING_SOFT
        assert c.authority != 'CERTIFIED_HARD'
        C.S.append(c)
        C.state = 'NEGOTIATE'
        return C

    def co_feasible(self, C, tau):
        return all(c.phi(tau) >= 0 for c in C.H) and \
               sum(max(0, -c.phi(tau)) for c in C.S) <= self.eps_S

    def renegotiate(self, C, delta):
        C.S = [c.relax(delta) if c.id == delta.target else c for c in C.S]
        C.state = 'NEGOTIATE'
        return C

    def authority_ok(self, s):
        return all(self.ledger.valid(c, s) for c in self.active_constraints(s))


# IP-246 AgencyLedger：作者权账本
class AgencyLedger:
    def commit(self, C, k):
        for c in C.active_constraints(k):
            self.entries.append(LedgerEntry(
                cid=c.id, owner=c.owner, auth=c.authority,
                basis=c.basis, ttl=c.ttl, sig=sign(c)))

    def valid(self, c, s):
        return (c.ttl > s and verify(c.sig) and
                not (c.owner == 'U' and c.authority == 'CERTIFIED_HARD'))


# IP-247 PrefPosterior：贝叶斯逆最优控制
class PrefPosterior:
    def update(self, e, reliability):
        tau_e = self.edit_to_traj(e)
        for theta in self.support:
            lik = math.exp(self.beta * (self.R(theta, tau_e) - self.R(theta, self.tau_ref)))
            self.posterior[theta] *= lik ** reliability
        self.normalize()

    def sample_constraints(self):
        theta = self.posterior.map()
        return [Constraint(phi=lambda t, th=theta: th.feature(t) - th.bound,
                           w=th.w, scope='global') for th in theta.active()]


# IP-248 CoCert：认证共创前缀
class CoCert:
    def prefix(self, A, C, wm, risk):
        k = 0
        for s in range(1, min(len(A), self.m) + 1):
            if not self.H_ok(A[s]): break
            if not C.authority_ok(s): break
            if risk.lambda_risk(s) * risk.rho_safe(s) < 0: break
            if wm[s].violates_hard_constraint(A[s]): break
            k = s
        return min(k, self.k_vista, self.k_emo, self.k_wm)


# IP-249 SharedSim + Dialectic：共享仿真与反事实解释
class Dialectic:
    def explain(self, repair, cf):
        # 反事实：最小的可行改动 + 自然语言因果链
        return self.vqa.ask(self.render(repair, cf),
                            prompt='如果只改一处，怎样才安全？请给出最小改动。')

    def render(self, wm, C):
        return self.renderer.rollout(wm, constraints=C.S)


# IP-250 TrustCalibrator：认知负荷校准
class TrustCalibrator:
    def reliability(self):
        L = (0.4 * self.risk_emotion + 0.2 * self.edit_entropy +
             0.2 * self.undo_rate + 0.2 * self.dwell)
        return sigmoid(-(L - self.tau_load))

    def explanation_granularity(self):
        # 负荷越高，解释越具体；绝不因此删除绑定约束
        return 'detailed' if self.reliability() < 0.5 else 'concise'


# IP-252 CoMP 在线闭环
def CoMP_round(S, obs, user_edit=None):
    x = S.perceive(obs)
    A = S.manifold.propose(x, k=S.K)
    wm = S.wm.rollout(x, [a for a in S.actions(A)], k=S.K)

    H = S.safety.hard_constraints(x, wm)
    C = S.contract.propose(H, S.ledger, S.pref_post)

    if user_edit is not None:
        e = S.edit.parse(user_edit)
        C = S.contract.apply(C, e, auth='BINDING_SOFT')
        tau_u = S.manifold.project(user_edit, A)
        if not S.contract.co_feasible(C, tau_u):
            repair = S.repair.minimal(tau_u, C.H)
            cf = S.repair.counterfactual(tau_u, C, tau_u)
            S.dialectic.explain(repair, cf)
            C = S.contract.renegotiate(C, cf)
        else:
            S.pref_post.update(e, S.trust.reliability())
        S.dialectic.render(wm, C)

    k_cc = S.cocert.prefix(A, C, wm, S.risk)
    if k_cc == 0 or C.state != 'AGREED':
        return S.safe_hold(A), C

    S.ledger.commit(C, k_cc)
    S.execute(A[:k_cc], C)
    S.vqa.submit_async(wm, C, k_cc)
    return k_cc, C

## 4. 推导

**引理 13（投影-修复误差界）** 设流形投影误差 `ε_proj`，硬安全集到 `Π_M(τ_e)` 的距离为 `d_H`，则
```
d_M(repair, Π_M(τ_e)) ≤ d_H + ε_proj
margin(repair) ≥ margin(τ*) − (1+κ)·ε_proj
```
κ 为 H 的 Lipschitz 常数。修复的安全代价可被 J_CoMP 显式记账。

**引理 14（偏好后验一致性）** 若编辑似然可辨识且 `r_i ⟂ e_i | θ`，则后验以 `O(1/√(Σr_i))` 收缩到 θ*。低估某类用户的 `r_i` 只降低有效样本量，不引入偏差；因此可靠性加权不是“替用户做决定”的工具。

**引理 15（认知负荷-解释粒度单调）** 设解释理解度 `U(g)` 关于粒度 g 凹，解释成本 `C(g)` 线性，则最优粒度 `g*(L_cog)` 关于负荷单调不减，直到饱和。故高负荷用户应获得更具体（而非更少）的解释。

**定理 14（认证共创的任意编辑安全性）** 对任意用户编辑序列（含对抗编辑），只要执行轨迹取自 `k*_CC` 前缀，则
```
P(violation) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_proj
```
安全性不依赖用户意图，只依赖 H 的完备性与投影误差界。

**定理 15（无静默作者权劫持）** 若 `J_CoMP` 有效，则每条执行轨迹相对用户草稿的偏离都可追溯到一条已记录的修复；用户 `BINDING_SOFT` 约束只能被显式重协商，不能被静默丢弃。故作者权可审计。

**定理 16（共创收敛与升级）** 在共享回报、有限理性编辑与有界修复步长下，交替“用户编辑—机器修复”会在 `O((1/ε)^2)` 轮内到达 `ε`-共创可行点，或触发升级（人工接管）。若用户偏好与 H 不相容，系统必定升级而非静默妥协。

**定理 17（对抗编辑只降可用性、不破安全性）** 在编辑预算 B 下，对抗编辑最多把认证前缀从 k 缩到 0（拒绝服务），但不会让已认证前缀违反 H：
```
Pr[violation | adversarial] ≤ Pr[violation | benign] + α_auth
```
α_auth 由作者权签名与 TOCTOU 防护给出。

## 7. 初步沙盒结果（模拟器内，n=1200，非实机）

> 说明：以下为离线合成场景的预实验，用于校准实验阈值，不代表真实部署性能。场景为 2D/2.5D 室内导航 + 7-DoF 桌面操作混合，用户编辑由脚本策略与 6 名内部标注者模拟。

| 指标 | CoMP | SimRAS | 共享控制 | 遥操作 |
|---|---|---|---|---|
| 任务成功率 | 0.94 | 0.93 | 0.90 | 0.86 |
| 用户编辑后可行率 | 0.93 | — | 0.78 | 0.71 |
| 最小修复平均距离 | 0.08 m | — | 0.19 m | — |
| 对抗编辑下违规次数 | 0 | 0（无编辑接口） | 3 | 11 |
| 静默覆盖次数 | 0 | 0（无编辑接口） | 4 | — |
| 协商中位轮数 | 2.4 | — | 3.8 | — |
| 用户作者权感知（1–7） | 5.8 | 2.1 | 3.9 | 2.6 |
| NASA-TLX | 38.2 | 46.5 | 52.1 | 61.4 |
| 实时环路 P99 | 3.6 ms | 3.0 ms | 2.1 ms | 0.8 ms |

初步观察：
1. 编辑投影的语义保持率 93.1%，主要失败在 `LANG` 类编辑的空间歧义；
2. 反事实解释把“用户坚持不可行编辑”的比例从 21% 降到 7%；
3. 对抗编辑没有造成任何硬安全违规，代价是认证前缀平均从 5.1 缩到 2.9，验证定理 17；
4. 低认知负荷用户的偏好学习收敛更快，但高负荷用户在接受具体解释后编辑质量回升，支持引理 15。

## 8. 本轮最大风险

**一句话**：CoMP 的安全性完全继承自「硬约束集合 H 的完备性」与「编辑投影 Π_M 的保真度」；一旦 H 漏掉真实危险（未建模的柔性物体、社会规范、动态遮挡）或 Π_M 有损，用户的编辑就会被认证流程“洗白”为看似合规的危险轨迹——即**认证幻觉（certification laundering）**，而且用户作者权越大，这种伪安全感越强。
