# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「轻量化结构」×「技能组合」）

> R69 把不确定性一分为二：aleatoric 交给 λ_floor，epistemic 交给「流匹配多模态策略 + 主动交互」。这套框架很优雅，但它偷偷押了三个前提：**（a）所需能力都在同一个单体策略的支持集里；（b）只要存在歧义，就一定能靠采样或提问消解；（c）动作块是一个不可再分的整体。** 在真实系统里，这三个前提都不成立。真实机器人不是一只巨兽，而是一个**技能库**：抓、放、推、拧、看、问，每个技能各自训练、各自认证、各自轻量；任务是把它们按接口拼起来。于是，一旦把「单体策略」换成「轻量技能组合」，R69 的 epistemic 里就漏出两种它没有命名的东西：
>
> - **结构不确定性 U_cov（absence，覆盖缺口）**：不是「哪个假设对」，而是「**我手里根本没有对的零件**」。再多采样、再多次提问也无法消解——向一个没有相应能力的系统提问，只会得到一个编造的答案。这是 R69 的盲区，也是轻量化的必然后果：库越小，越容易拿锤子看什么都像钉子。
> - **接缝不确定性 U_seam（seam，组合边界）**：两个各自正确的技能，在交接处可能因为坐标系、单位、时序、状态估计误差而失配；单技能证书对它一无所知。组合的失败往往不在零件内部，而在**零件之间**。
>
> 本轮两个灵感正好给出两条互补的线索：
> - **轻量化结构**告诉我们：能力可以做成共享 trunk 上的微型 adapter，每个技能只带自己的契约头与不确定性签名；运行时只激活计划需要的那一小块，成本随活跃度而非库规模增长。但轻量化不是免费午餐——量化/剪枝会侵蚀 R69 赖以工作的模态可分性与校准，必须用「轻量化感知」的门去兜底。
> - **技能组合**告诉我们：任务是一个类型化 DAG，不是一个大动作块；组合需要**契约**（pre/post/invariant + assume-guarantee）而不是简单拼接；组合的风险不服从加法，而服从接缝处的传播与放大。
>
> 核心命题：**把 R69 的单体策略拆成「契约化轻量技能原子库 + 最小稀疏组合器」；把不确定性从二分扩展为四分（aleatoric / epistemic / structure / seam），分通道处理；用 assume-guarantee 证书代数在运行时增量认证组合，而不重跑整链；任何一环无法放电，就逐指令回退到 R69。** 命名 **MOSAIC-RAS**（Modular Skill Atoms with Interface Contracts：契约化技能原子 × 轻量组合的闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我手里有没有对的零件，按这个顺序拼起来还成立吗**」——不确定性不只在测量里、在假设里，也在**零件的有无与零件之间**。

## 0. 直觉与动机

**灵感 1（轻量化结构 → 能力不必装在一只巨兽里，不确定性也不必每次都全量计算）**
直觉：R69 的流匹配策略把所有技能压进一个速度场。这在理论上很美，在工程上却同时犯了三个错：算力上，每一个动作都要跑同一个大网络；认证上，要信任一个巨大黑箱的全局行为；可维护上，换一个抓取风格就得重训整只模型。轻量化结构的直觉是把「能力」拆成共享表示 + 大量微型技能头：共享 trunk 负责感知与条件编码（直接复用 R69/R68 的 z_t），每个技能只是一个很小的 adapter 或 velocity head，附带自己的契约元数据、资源足迹和不确定性签名。运行时按任务只激活活跃的少数几个头（top-1/top-k 稀疏），成本随活跃技能数增长，而不是随库规模增长。更重要的是，**认证面也变小了**：我们只需要信任一个个小模块的契约，而不是一只巨兽的全局圣谕。但轻量化是双刃剑：量化、剪枝、低秩化会压缩表示，恰好可能把 R69 用来分辨模态的那点可分性（Δ_min/σ_in）磨平，于是「更轻」可能等价于「更瞎」。所以本轮必须把轻量化本身当作一个会引入不确定性的操作，而不是免费的工程优化。

**灵感 2（技能组合 → 任务是类型化 DAG，失败在接缝处）**
直觉：一个「把杯子放进水槽」的任务，不是一个大动作块，而是 `定位 → 抓取 → 抬起 → 移动 → 对准 → 放置 → 松爪` 的技能序列，可能还带分支与并行。组合不是字符串拼接：每个技能有类型化接口（坐标系、单位、频率）、前置条件（物体已抓稳）、后置条件（物体在夹爪中、姿态在容差内）、不变式（不碰人、不超力）、资源足迹（工作空间、力预算、注意力）。组合的第一性风险不是「某个技能不准」，而是**前置条件在后继技能看来不成立**：上游说「已抓稳」，下游需要的是「已抓稳且杯口朝上」，中间差了一个没被任何单一技能覆盖的谓词。这就是接缝。组合的第二性风险是误差传播：每个技能端口上的一点偏差，会沿 DAG 被下一段放大或缩小；如果增益乘积大于 1，两个 95% 的模块拼起来可能只有 80%。第三性风险是资源冲突：两个并行技能都声称自己占用了同一个工作空间或同一份交互预算。R69 的单技能视角对这些一无所知，因为它根本没有「边界」这个概念。

**灵感 3（第三种不确定性：absence 不是 ambiguity）**
直觉：这是本轮最重要的概念增量。R69 的 U_epi 默认「正确答案在支持集里，只是暂时分不清」——所以采样和提问有用。但一个有限、轻量的技能库会经常遇到另一种处境：**所需的技能根本不存在**。这不是「把 A 看成 B」的歧义，而是「A 和 B 都不存在」的缺席。把它塞进 U_epi 会造成灾难性的行为：系统会自信地在最近的技能上做最近邻顶替（有锤子看什么都像钉子），或者把「问一句」当成万能解药，去问一个它根本没有能力执行的问题。更糟的是，覆盖缺口不会自己暴露——如果系统总用已有的技能勉强成功，它永远不会知道自己缺了什么。因此 U_cov 必须有独立通道：它不驱动「多采样」，而驱动「请求新技能 / 推迟 / 移交 / 回退到通用单体」。这也是对 R69「不确定性都可被交互消解」这一乐观假设的正面反驳：**有些不知道，问也问不出来，因为问题不在信息，而在能力边界。**

**灵感 4（接缝是组合时代的「标定」）**
直觉：R68 的洞见是「测量本身需要被测量」，于是有了标定层；R70 的对应洞见是「组合本身需要被组合验证」，于是接缝必须成为一等测量对象。接缝误差至少有四种来源：坐标系/单位转换误差、时序抖动与延迟、上游状态估计的偏差、以及分布偏移（下游技能在训练时没见过这种上游终态）。R69 的证书是对单个动作轨迹开的；组合证书必须对每一条边记录「上游后置条件与下游前置条件的残差」。如果残差小，接缝可信；如果残差大，就必须显式抬高 U_seam 并收紧 λ，或者重新规划。关键点：**接缝处的失配可以被运行时监控看到，但不能被单技能的离线证书预测到**。这就像 R68 的缓变故障：单看传感器自洽没用，必须有一条独立的边界通道。

**灵感 5（契约代数：让「不重验整链」成为可能）**
直觉：如果每拼一个技能都要把整条链重新形式化验证一遍，轻量化就毫无意义。组合时代的正确工具是 assume-guarantee 推理：每个技能 σ 离线认证为 `⟨A_σ, G_σ⟩`——只要入口满足假设 A_σ，出口就保证 G_σ，失败概率 δ_σ、风险上界 r̄_σ、端口误差增益 κ_σ 都有声明。运行时组合只需检查每条边 `G_u ⇒ A_v`，以及共享资源不变式；证书可以增量合成，成本 O(|E|)。这就是「轻量」的严格含义：**不是把模型压小，而是把认证做成可组合的局部代数**。但这也埋下了本轮最大的隐患：整套安全性从此押在「契约集合完备且诚实」上；一个写错、写漏、或只在训练分布内成立的契约，会让组合器把局部正确的零件拼成全局错误，而每个模块的自检都完美通过。

**灵感 6（严格包含 R69：单体只是「一个技能、零契约」的边界）**
直觉：本轮的姿态必须与 R68→R69 一致——新层是旧层的严格泛化，而不是并列替代。当技能库只有一个通用技能、契约集合为空、没有量化压缩、任务不需要组合时，MOSAIC 必须逐指令退化为 FLUID：同样的 z_t、同样的 FMP 采样、同样的 AUD 分解、同样的 MINT、同样的 λ floor。更强的是回退：当组合无法认证（契约无法放电、SCC 硬违规、U_cov 越界、LCQ 禁用、资源冲突不可解）时，直接折叠回 R69 的单技能通用策略，并令 λ 单调不降。于是安全侧永不弱于 R69；效率侧的收益（稀疏激活 + 摊销认证 + 技能重用）只在能够认证时兑现。这是本轮的理论底线。

**灵感 7（组合的新攻击面与「责任扩散」）**
直觉：一旦系统会从库里选零件，攻击面就从「动作」扩展到「库」与「装配」：可以污染一个后门 adapter；可以让一个技能的声明与实现不符（契约欺骗）；可以让两个各自合规的技能在组合后越界（跨技能共谋）；可以利用接缝的坐标系/时序误差做夹带；还可以塞一个诱饵技能，让组合器选择昂贵或错误的路径（覆盖耗尽）。更隐蔽的是审计上的**责任扩散**：每个技能都通过了自己的自检，接缝监控也没有单独报错，于是出事之后没有任何一个模块「有罪」——系统在局部诚实的累积中完成了全局错误。因此本轮必须交付：组合级对抗集、责任账本、反事实重放归因、金丝雀组合，以及「拒绝/移交」作为一等公民。

## 1. 形式化定义（增量：定义 310–329）

**定义 310（MOSAIC-RAS 总览）** MOSAIC-RAS = (MSL, LC, SCC, SUE, CUQ, RLD, AGC, LCQ, VQAuditor-X)。五条不变式：
(i) **零运行时结构写操作**：技能库的增删改、契约替换、量化位宽变更只能发生在离线认证边界（继承 R68 定义 276-i 的「零学习写操作」并扩展到结构层）；
(ii) **契约先于执行**：任何技能原子在通过契约检查（定义 313、315）前不得进入组合；
(iii) **接缝一等公民**：跨技能边界的状态失配必须显式估计为 U_seam，不得默认「接口正确」；
(iv) **最小激活**：运行时只实例化计划中活跃的技能子图，成本随活跃度而非库规模增长；
(v) **严格回退**：组合无法认证时，逐指令退化为 R69 的单技能 FLUID，或安全中止。

**定义 311（技能原子）** σ = (π_σ, I_σ, C_σ, ρ_σ, u_σ, h_σ)。π_σ 是共享 trunk 上的轻量策略头（adapter 或 velocity head），参数量不超过 ε_p；I_σ 是类型化接口；C_σ 是契约；ρ_σ 是资源足迹；u_σ 是不确定性签名 (U_ale^σ, U_epi^σ, ECE_σ, Δ_min^σ, σ_in^σ)；h_σ 是版本哈希。技能库 MSL = {σ_1, …, σ_N} 是一个只读（运行时）集合。

**定义 312（类型化接口）** 端口 p = (τ, frame, unit, rate)；技能有输入端口集 In_σ 与输出端口集 Out_σ。匹配谓词 Match(p_out, p_in) ∈ {exact, coercible(ε_co), incompatible}。只允许 exact 或显式、带误差界 ε_co 的 coercion；incompatible 直接判组合非法。接口是技能的「物理类型系统」：它先于任何数值检查，排除掉单位/坐标系层面的错误拼接。

**定义 313（技能契约与假设-保证对）** C_σ = (Pre_σ, Post_σ, Inv_σ)，其中 Pre/Post 是入口/出口状态谓词，Inv 是执行期间不变式；并附带假设-保证对 ⟨A_σ, G_σ⟩，A_σ ⇒ Pre_σ 是环境假设，G_σ ⇒ Post_σ 是保证。技能证书声明三元组 (δ_σ, r̄_σ, κ_σ)：失败概率上界、风险上界、端口误差增益（Lipschitz 常数）。四者可离线测得，也可由形式化验证与统计测试联合给出。

**定义 314（组合计划）** 𝒫 = (V, E, μ)，V ⊆ MSL 是活跃技能集，E 是满足 Match 的类型化边，μ 给出串行/并行/条件调度。可采纳计划集 Π(t, o) = {𝒫 : 依赖闭合 ∧ 资源可行 ∧ 契约可放电 ∧ 接口匹配}。计划是任务 t 在观测 o 下的候选装配。

**定义 315（运行时契约一致性监控 SCC）** 对每个活跃技能的入口与出口，监控 m_σ: 观测 → {pass, soft_violation, hard_violation}；soft 违规转入 U_seam 预算，hard 违规立即中止并回退。契约一致性 = 所有活跃技能与所有边均 pass。软硬之分对应「可容忍的数值漂移」与「契约被证伪」。

**定义 316（接缝不确定性）** 边 e = (u, v) 的接缝：
U_seam(e) = E[d(state_out^u, Pre_v)] + λ_t·jitter_e + λ_f·frame_unit_e + λ_d·drift_e，
其中 d 是状态空间距离，jitter 是时序抖动，frame_unit 是坐标系/单位残差，drift 是上游终态相对下游训练分布的偏移。总 U_seam = Σ_e w_e·U_seam(e)，权重 w_e 按下游风险敏感度归一。

**定义 317（组合不确定性四分）** U_comp = (U_ale, U_epi, U_seam, U_cov)。前两者继承 R69（技能内噪声、技能间歧义）；U_seam 是边界失配；U_cov 是结构/覆盖。四者走不同通道：
- U_ale → R68 的 λ floor（不可约，收紧）；
- U_epi → R69 的 MINT 交互（可约，看/问/触）；
- U_seam → 契约放电失败则收紧 λ 并触发重规划；
- U_cov → 禁止最近邻顶替，触发「请求缺失技能 / 推迟 / 移交 / 回退通用单体」。
四者不做简单加和，因为它们对应的动作完全不同。

**定义 318（结构不确定性 CUQ 与覆盖头）** 任务需求嵌入 t，技能效应签名 e_σ（由接口 + 契约的后置条件嵌入得到）。覆盖缺口 d_cov(t) = min_σ d(t, e_σ)；U_cov = 1 − exp(−d_cov/τ_c)，或用校准后的覆盖头直接输出概率。当 U_cov > τ_cov 时，组合器不得用最近邻技能顶替缺失技能，必须走缺技能协议。注意：U_cov 度量的是「库里有没有合适的效应」，不是「模型有没有见过相似输入」——这是 absence 与 novelty 的区别。

**定义 319（轻量组合器 LC）** 在 Π(t, o) 上求解
𝒫* = argmin_{𝒫} [ C_comp(𝒫) + C_ver(𝒫) + λ_risk·R(𝒫) ]
s.t. R(𝒫) ≤ R_budget(o) ∧ 资源账本可行 ∧ U_cov ≤ τ_cov ∧ 契约可放电，
其中 C_comp 只计活跃技能的计算，C_ver 用 AGC 增量证书的成本，R(𝒫) 用引理 19 的路径加权风险界。采用 beam search 或 A*，候选数 N_c ≤ 32；深度受任务步数上界约束。

**定义 320（资源账本与冲突检测 RLD）** 每个技能声明 ρ_σ = (时间窗, 工作空间, 力/力矩, 注意力/交互预算, 功耗)。并行组合要求资源不相交或显式共享协议；冲突检测朴素 O(|V|²)，用区间树/空间哈希可降到 O(|V| log |V|)。资源冲突与物理安全不同：它不一定立刻危险，但会让两个正确技能互相拆台。

**定义 321（假设-保证证书代数 AGC）** 组合规则：若对每条边 u→v 有 G_u ⇒ A_v（在容差 δ_seam 内），且共享资源不变式成立，则由 {⟨A_σ, G_σ⟩}_{σ∈V} 可推出 𝒫 的 ⟨A_in, G_out⟩，失败概率 ≤ Σ_σ δ_σ + Σ_e δ_seam(e)。证书增量合成，无需重跑整链；每一步都可写入 AGC_trace 供审计。AGC 的可靠性依赖运行时监控来检出「假设被违反」——离线证书只能保证「假设成立时」的结论。

**定义 322（轻量化校准门 LCQ）** 对压缩/量化后的技能，检验两条：(a) 模式权重扰动 ‖ŵ − ŵ_q‖_1 ≤ ε_w；(b) Δ_min^q ≥ 3σ_in^q（R69 的 A95 模态可分条件在压缩后的版本）。任一不满足 ⇒ 该技能禁用 VoI 交互，U_epi 视为未消解，走 R69 保守通道；极端情形直接禁用该技能。LCQ 是「轻量化」与「R69 交互」之间的兼容性条件，不是可选的工程细节。

**定义 323（组合证书 J_MOSAIC）** J_MOSAIC = (library_hash, plan_hash, {J_FLUID^σ}_{σ∈V}, AGC_trace, seam_ledger, resource_ledger, U_cov, LCQ_status, attribution_hash, mosaic_ver)。Valid ⇔ 每个活跃技能 J_FLUID 有效 ∧ AGC 放电成功 ∧ SCC 全 pass ∧ 资源账本未越界 ∧ U_cov ≤ τ_cov ∧ LCQ 通过。

**定义 324（组合对抗集 ℰ_comp）** 污染技能（后门 adapter）、契约欺骗（声明与实现不符）、跨技能共谋（每个单独合规、组合越界）、接缝利用（利用 frame/时序误差夹带）、诱饵技能与覆盖耗尽（迫使组合器选错/选贵）。ℰ_MOSAIC = ℰ_FLUID × ℰ_comp。对抗训练与测试必须在「组合级」进行，单技能对抗集无法覆盖。

**定义 325（责任账本与归因审计 VQAuditor-X）** 记录每个技能入口/出口的观测哈希、契约判定、资源占用、接缝残差；失败时用反事实重放定位**最小违规契约集**（minimal contract violation set），区分四类责任：技能错（π_σ 不满足自己的 Post）、契约错（C_σ 本身写错或过强）、组合错（单看都对、拼起来违反 Inv）、覆盖错（所需效应不在库中）。结论回灌 MSL 的契约与成本先验，但只在离线更新。

**定义 326（回退与单调性）** 当 AGC 失败 / SCC hard violation / U_cov 越界 / LCQ 禁用 / 资源冲突不可解时，执行 Collapse(𝒫)：若存在通用单技能 σ_gen（即 R69 的 FLUID 策略），退化为它并令 λ = λ_floor(U_ale + U_epi + U_seam + U_cov)；否则安全中止。λ 单调不降，物理安全包络不扩大。这条定义保证 MOSAIC 的安全侧是 R69 的严格下界。

**定义 327（技能获取与版本化，离线）** 新技能只能离线归纳（示教 / RL / 蒸馏 / 组合搜索），生成契约候选，经形式化或统计验证、以及 ℰ_comp 测试后入库；入库产生新 library_hash，旧证书全部失效并重签。运行时只读。这样「换零件」永远不会绕过认证，也不会在闭环中引入学习写操作。

**定义 328（风险预算切分）** 全局单步风险预算 R_budget 沿计划按引理 19 的敏感度 w_σ 切分，每个活跃技能分配 R_σ = w_σ·R_budget；组合器不得让 Σ_σ R_σ + R_seam > R_budget。切分不是平均主义：下游误差增益大的技能拿更小预算，接缝多的路径拿更多预算。

**定义 329（实时激活与摊销认证）** 运行时只惰性加载活跃技能，认证成本离线摊销；P99 预算按活跃技能数线性。目标：常规路径（活跃 1 个轻量技能）< 2.0ms，双技能组合路径 < 3.0ms；库规模 N 只影响查表 O(log N)，不影响单步前向。注意这个预算是「轻量化 + 稀疏激活」带来的真实收益，而不是把 R69 的 K 采样偷偷藏起来。

## 2. 关键算法骨架

```python
# IP-264 MSL：契约化轻量技能原子（共享 trunk + 微型 adapter）
@dataclass
class SkillAtom:
    name: str
    policy: FlowHead                  # 共享 trunk 上的 adapter / velocity head
    iface: SkillInterface             # (tau, frame, unit, rate) 类型化端口
    contract: Contract                # Pre/Post/Inv + <A,G> + (delta, r_bar, kappa)
    footprint: ResourceFootprint      # 时间窗/空间/力/注意力/功耗
    unc: UncertaintySig               # U_ale, U_epi, ECE, Delta_min, sigma_in
    version: str                      # library_hash 的一部分

# IP-265 LC：最小稀疏组合器（覆盖门控 + beam 搜索 + 契约放电）
def compose(task, o, lib, budget):
    t = task_embedding(task)
    if coverage_head(t, lib) > TAU_COV:
        return MISSING_SKILL                       # 禁止最近邻顶替（定义 318）
    beam = [Plan.empty(o)]
    for _ in range(MAX_DEPTH):
        beam = [p for p in expand(beam, lib, o)     # 只扩展接口匹配的边
                if resource_ok(p) and risk_bound(p) <= budget.R]
        beam = topk(beam, K_BEAM, key=lambda p: total_cost(p, budget))
    return best_certified(beam)                    # 无证书则 None

# IP-266 SCC：运行时契约一致性监控
def monitor(plan, o):
    for sigma in plan.active:
        state = sigma.contract.Pre(o)
        if state == HARD_FAIL: return FALLBACK
        if state == SOFT_FAIL: seam_budget += seam_penalty(sigma)
    for e in plan.edges:
        if not implies(e.up.Post, e.down.Pre, tol=TAU_SEAM):
            return FALLBACK
    return OK

# IP-267/268 SUE + CUQ：接缝与覆盖不确定性
def seam_uncertainty(plan, o):
    return sum(w[e] * (state_gap(e, o) + LAM_T * jitter[e]
                       + LAM_F * frame_unit[e] + LAM_D * drift[e])
               for e in plan.edges)

def coverage_head(t, lib):
    d = min(distance(t, effect_signature(s)) for s in lib)
    return 1.0 - exp(-d / TAU_C)                   # 越界即缺技能

# IP-271 LCQ：轻量化后的模态可分性门（与 R69 A95 对齐）
def lcq(sigma):
    if l1_norm(sigma.w - sigma.w_q) > EPS_W: return False
    if sigma.delta_min_q < 3.0 * sigma.sigma_in_q: return False
    return True

# IP-272 AGC：假设-保证增量证书
def certify(plan, seam_u, budget):
    delta = sum(s.contract.delta for s in plan.active)
    for e in plan.edges:
        if not implies(e.up.contract.G, e.down.contract.A, tol=TAU_SEAM):
            return Cert.invalid("assumption_undischarged", e)
        delta += TAU_SEAM_BASE + seam_u.edge[e]
    risk = path_weighted_risk(plan, seam_u)          # 引理 19
    return Cert(valid=(delta <= DELTA_MAX and risk <= budget.R),
                delta=delta, risk=risk, trace=plan.edges)

# IP-275 主闭环：先组合，再逐技能复用 R69；任一环失败即回退
def MOSAIC_RAS_round(M, task, obs):
    plan = M.lc.compose(task, obs, M.lib, M.budget)
    if plan is None or plan is MISSING_SKILL:
        return M.fluid_round(obs)                   # 严格回退 R69
    U = ComposeUncertainty()
    for sigma in plan.topo():
        if not M.lcq(sigma):                        # 压缩磨平了模态可分性
            U.epi_unresolved += sigma.unc.U_epi
            continue_aleatoric_only = True
        U.entry += M.sue.entry(sigma, obs)
        k, lam, mode, u = M.fluid_step(sigma, obs)  # 复用 R69 FMP/AUD/MINT
        U += u
        if M.scc.check(sigma, obs) == HARD_FAIL:
            return M.collapse(plan, U)               # 定义 326
    U.seam = M.sue.exit(plan)
    J = M.agc.certify(plan, U.seam, M.budget)
    if not J.valid:
        return M.collapse(plan, U)
    M.auditor_x.log(plan, J, U)                     # 责任账本（离线回灌）
    return J
```

## 3. 推导

**引理 19（接缝误差传播与收缩条件）** 设串行路径 σ_1→…→σ_n，技能 i 的端口误差为 e_i，增益为 κ_i，接缝间隙为 g_i。则末端误差
e_out ≤ (Π_i κ_i)·e_in + Σ_i (Π_{j>i} κ_j)·(e_i + g_i)。
若所有 κ_i ≤ κ < 1，则 e_out ≤ (Σ_i (e_i + g_i))/(1 − κ)，误差不随链长指数爆炸；若存在 κ_i > 1，则必须显式把放大因子计入风险预算（定义 328），否则组合会悄悄把局部小误差攒成全局大误差。要点：**组合安全的核心不是每个模块多准，而是每段是否收缩**；这解释了为什么有些「每个技能都 95%」的系统拼起来只有 70%。

**引理 20（假设-保证放电的可靠性）** 若每条边的蕴含 G_u ⇒ A_v 在容差 δ_seam 内成立，且运行时监控对假设违反的召回率为 ρ，则组合保证的失败概率 ≤ Σ_σ δ_σ + Σ_e δ_seam(e) + (1−ρ)·Σ_e P(A_v 被违反)。要点：离线契约再漂亮，也只为「假设成立」的世界背书；未被监控覆盖的接缝是组合证书的真正漏洞。系：SCC 的覆盖率必须被计入 J_MOSAIC，而不是当成实现细节。

**引理 21（轻量化压缩对模态可分的侵蚀）** 设每个权重的量化误差为 δ_q，技能头对模式权重与原型位置的 Lipschitz 常数分别为 L_w、L_x，则 ‖ŵ − ŵ_q‖_1 ≤ L_w·δ_q，Δ_min^q ≥ Δ_min − 2L_x·δ_q。因此存在临界 δ* = (Δ_min − 3σ_in)/(2L_x + L_w)，当 δ_q > δ* 时 A95（Δ_min ≥ 3σ_in）被破坏，R69 的 VoI 不再可靠。LCQ 的阈值正是由这个不等式反解出来的。要点：**轻量化与 R69 的交互能力之间存在可计算的兼容区间**，不是「压得越小越好」，也不是「一律不许压」。

**引理 22（覆盖盲区的最近邻替代风险）** 设覆盖缺口为 d，覆盖头 Lipschitz 常数为 L_c、校准误差为 ε_c，则「用最近邻技能顶替缺失技能且未被检出门控」的概率 ≤ exp(−(d − d_0)/τ_c) + ε_c。要点：U_cov 必须作为**硬门控**参与组合（定义 318），而不是软惩罚；软惩罚在优化压力下会稳定地选择「更便宜但错误」的近邻技能，这正是对齐剧场在技能层的版本。

**定理 18（严格包含与安全不回退）** 当 |𝒫| = 1、该技能为 R69 通用 FLUID 策略、契约集合为空、且无压缩（δ_q = 0）时，MOSAIC 的所有定义逐条退化为 FLUID，行为逐指令相同。对任意状态，MOSAIC 要么返回一个通过 AGC/SCC/LCQ/覆盖门控的证书组合，要么执行 Collapse 回退到 FLUID；因此其物理安全侧不弱于 R69。R69 恰为「单技能、零契约、无压缩」边界。

**定理 19（组合的效率-风险分离）** 在契约声音（contract soundness）、覆盖充分（U_cov ≤ τ_cov）与收缩（κ < 1）三个假设下，组合计划的期望风险 ≤ Σ_σ w_σ·r̄_σ + U_seam，且运行时计算成本只与活跃技能数成正比、与库规模 N 无关；因此 MOSAIC 可以在不抬高安全上界的前提下，用更小的计算获得与 R69 相当或更好的任务表现（技能重用 + 稀疏激活）。反之，若任一假设失败，定理 18 的回退机制保证安全侧不退化。要点：**效率收益是条件性的，安全保证是无条件的（通过回退）。**

**定理 20（归因可判定性与责任扩散的消除）** 若最小违规契约集在观测下可分离（不同责任类的反事实重放产生不同观测签名），则 VQAuditor-X 以至少 1 − δ_attr 的概率定位到该集合；若不可分离，它必须输出一个责任歧义类而不是单一替罪羊。要点：组合系统的审计目标不是「找到谁的错」，而是**诚实地报告「错在技能/契约/组合/覆盖」中的哪一类**；把不可判定伪装成已判定，正是责任扩散的审计版本。

## 6. 本轮最大风险

**一句话**：MOSAIC-RAS 的全部安全性押在「技能契约集合完备且诚实」这一前提上——**若某个契约只在训练分布内成立、或库中根本没有所需技能而组合器用最近邻顶替，轻量化会让失效局部化得不可见：每个模块的自检都完美通过，拼起来却在接缝处失败**；组合越多、零件越轻，越没有一个模块为「装配后的整体」负责——**拼得越省，越可能把一个没写进契约的错误拼进去。**

## 2. 形式化定义（要点版）

**定义 310（总览与五不变式）** 零运行时结构写操作；契约先于执行；接缝一等公民；最小激活；组合不可认证则逐指令回退 R69 或安全中止。

**定义 311–312（技能原子与类型化接口）** `σ=(π_σ,I_σ,C_σ,ρ_σ,u_σ,h_σ)`；端口 `p=(τ,frame,unit,rate)`，`Match ∈ {exact,coercible,incompatible}`，incompatible 直接判非法。这是技能的物理类型系统。

**定义 313（契约与假设-保证）** `C_σ=(Pre,Post,Inv)`、`⟨A_σ,G_σ⟩` 与证书三元组 `(δ_σ,r̄_σ,κ_σ)`。

**定义 314–315（计划与运行时一致性）** `𝒫=(V,E,μ)`；SCC 输出 `pass/soft_violation/hard_violation`，soft 进 U_seam，hard 立即回退。

**定义 316–317（接缝与四分）** `U_seam` 覆盖状态/时序/坐标系/漂移；`U_comp=(U_ale,U_epi,U_seam,U_cov)` 分通道：λ floor / MINT 交互 / 收紧重规划 / 缺技能协议。

**定义 318（覆盖头 CUQ）** `d_cov=min_σ d(t,e_σ)`，`U_cov=1−exp(−d_cov/τ_c)`；越界禁止最近邻顶替。U_cov 是 absence，不是 novelty。

**定义 319–320（组合器与资源账本）** 覆盖门控下最小化 `C_comp+C_ver+λ_risk R`；资源账本 `ρ_σ` 检测并行冲突。

**定义 321（AGC 证书代数）** 每条边 `G_u ⇒ A_v`（容差内）+ 资源不变式 ⇒ 组合保证；失败概率 `≤ Σδ_σ + Σδ_seam`。证书增量合成，接缝必须被运行时监控覆盖。

**定义 322（LCQ）** 压缩后 `‖ŵ−ŵ_q‖_1 ≤ ε_w` 且 `Δ_min^q ≥ 3σ_in^q`；否则禁用该技能的 VoI，退回 R69 保守。

**定义 323–326（证书/对抗/审计/回退）** `J_MOSAIC` 汇总组合证据；`ℰ_comp` 覆盖后门/契约欺骗/共谋/接缝/诱饵；VQAuditor-X 用最小违规契约集区分四类责任；Collapse 回退 R69 且 λ 单调不降。

**定义 327–329（版本化/预算/实时）** 技能只离线入库并重签证书；风险预算按敏感度切分；运行时惰性激活，常规 <2.0ms、双技能 <3.0ms。

## 3. 关键算法伪代码

```python
# IP-264 MSL：契约化轻量技能原子
@dataclass
class SkillAtom:
    policy: FlowHead            # 共享 trunk 上的 adapter / velocity head
    iface: SkillInterface       # (tau, frame, unit, rate)
    contract: Contract          # Pre/Post/Inv + <A,G> + (delta, r_bar, kappa)
    footprint: ResourceFootprint
    unc: UncertaintySig         # U_ale, U_epi, ECE, Delta_min, sigma_in
    version: str

# IP-265 LC：覆盖门控 + 最小稀疏组合
def compose(task, o, lib, budget):
    if coverage_head(task_embedding(task), lib) > TAU_COV:
        return MISSING_SKILL                       # 禁止最近邻顶替
    beam = [Plan.empty(o)]
    for _ in range(MAX_DEPTH):
        beam = [p for p in expand(beam, lib, o)
                if resource_ok(p) and risk_bound(p) <= budget.R]
        beam = topk(beam, K_BEAM, key=lambda p: total_cost(p, budget))
    return best_certified(beam) or None

# IP-266 SCC：运行时契约一致性
def monitor(plan, o):
    for sigma in plan.active:
        s = sigma.contract.Pre(o)
        if s == HARD_FAIL: return FALLBACK
        if s == SOFT_FAIL: seam_budget += seam_penalty(sigma)
    for e in plan.edges:
        if not implies(e.up.Post, e.down.Pre, tol=TAU_SEAM): return FALLBACK
    return OK

# IP-267/268 SUE + CUQ
def seam_uncertainty(plan, o):
    return sum(w[e] * (state_gap(e, o) + LAM_T * jitter[e]
                       + LAM_F * frame_unit[e] + LAM_D * drift[e])
               for e in plan.edges)

def coverage_head(t, lib):
    d = min(distance(t, effect_signature(s)) for s in lib)
    return 1.0 - exp(-d / TAU_C)

# IP-271 LCQ：轻量化后的模态可分门（对应 R69 A95）
def lcq(sigma):
    if l1_norm(sigma.w - sigma.w_q) > EPS_W: return False
    return sigma.delta_min_q >= 3.0 * sigma.sigma_in_q

# IP-270 AGC：增量 assume-guarantee 证书
def certify(plan, seam_u, budget):
    delta = sum(s.contract.delta for s in plan.active)
    for e in plan.edges:
        if not implies(e.up.contract.G, e.down.contract.A, tol=TAU_SEAM):
            return Cert.invalid("assumption_undischarged", e)
        delta += TAU_SEAM_BASE + seam_u.edge[e]
    risk = path_weighted_risk(plan, seam_u)        # 引理 19
    return Cert(valid=(delta <= DELTA_MAX and risk <= budget.R),
                delta=delta, risk=risk, trace=plan.edges)

# IP-275 主闭环
def MOSAIC_RAS_round(M, task, obs):
    plan = M.lc.compose(task, obs, M.lib, M.budget)
    if plan is None or plan is MISSING_SKILL:
        return M.fluid_round(obs)                  # 严格回退 R69
    U = ComposeUncertainty()
    for sigma in plan.topo():
        if not M.lcq(sigma):
            U.epi_unresolved += sigma.unc.U_epi
            continue
        U.entry += M.sue.entry(sigma, obs)
        k, lam, mode, u = M.fluid_step(sigma, obs) # 复用 R69 FMP/AUD/MINT
        U += u
        if M.scc.check(sigma, obs) == HARD_FAIL:
            return M.collapse(plan, U)             # 定义 326
    U.seam = M.sue.exit(plan)
    J = M.agc.certify(plan, U.seam, M.budget)
    if not J.valid: return M.collapse(plan, U)
    M.auditor_x.log(plan, J, U)
    return J
```

## 4. 推导

**引理 19（接缝误差传播与收缩条件）** 串行路径上 `e_out ≤ (Πκ_i)e_in + Σ_i(Π_{j>i}κ_j)(e_i+g_i)`；若 `κ<1`，误差不随链长指数爆炸，否则必须把放大因子计入风险预算。系：组合安全的核心是每段是否收缩，而不是每个模块多准。

**引理 20（假设-保证放电的可靠性）** 组合失败概率 `≤ Σδ_σ + Σδ_seam + (1−ρ)ΣP(A_v 被违反)`。系：离线契约只为「假设成立」的世界背书；未监控的接缝是证书的真正漏洞，SCC 覆盖率必须写入 J_MOSAIC。

**引理 21（压缩对模态可分的侵蚀）** `‖ŵ−ŵ_q‖_1 ≤ L_w δ_q`，`Δ_min^q ≥ Δ_min − 2L_x δ_q`；临界 `δ*=(Δ_min−3σ_in)/(2L_x+L_w)`，超过则 A95 失效、VoI 不可靠。LCQ 阈值由此反解。系：轻量化与 R69 交互能力存在可计算的兼容区间。

**引理 22（覆盖盲区的最近邻替代风险）** 顶替未被检出的概率 `≤ exp(−(d−d_0)/τ_c)+ε_c`。系：U_cov 必须是硬门控而非软惩罚，否则优化压力会稳定选择更便宜的错误近邻（技能层的对齐剧场）。

**定理 18（严格包含与安全不回退）** `|𝒫|=1`、技能为 R69 通用 FLUID、契约为空、无压缩时，MOSAIC 逐指令等于 FLUID。任意状态要么返回通过 AGC/SCC/LCQ/覆盖门控的组合，要么 Collapse 回退；安全侧不弱于 R69。R69 = 单技能、零契约、无压缩边界。

**定理 19（效率-风险分离）** 契约声音、覆盖充分、收缩（κ<1）三假设下，`risk(𝒫) ≤ Σw_σ r̄_σ + U_seam`，运行时成本只与活跃技能数成正比、与 N 无关；任一假设失败则由定理 18 回退。系：效率收益是条件性的，安全保证是无条件的。

**定理 20（归因可判定性）** 若最小违规契约集在观测下可分离，VQAuditor-X 以 `≥1−δ_attr` 概率定位；否则必须输出责任歧义类而非单一替罪羊。系：组合审计的目标是诚实报告责任类别，而不是掩盖责任扩散。

## 7. 本轮最大风险

**一句话**：MOSAIC-RAS 的全部安全性押在「技能契约集合完备且诚实」这一前提上——**若某个契约只在训练分布内成立、或库中根本没有所需技能而组合器用最近邻顶替，轻量化会让失效局部化得不可见：每个模块的自检都完美通过，拼起来却在接缝处失败**；组合越多、零件越轻，越没有一个模块为「装配后的整体」负责——**拼得越省，越可能把一个没写进契约的错误拼进去。**

**次级风险与缓解**：契约欺骗/后门 adapter（ℰ_comp 组合级对抗训练 + 契约变异测试 + 离线重签）；跨技能共谋（组合级金丝雀 + 资源不变式 + 反事实重放）；接缝误差被低估（SCC 覆盖率写入证书 + U_seam 抬高 λ + 引理 20 的漏检项）；压缩磨平模态可分性（LCQ 硬门控，越界即退回 R69 保守）；组合搜索爆炸（beam ≤32 + 活跃稀疏 + 覆盖门控提前返回）；责任扩散（VQAuditor-X 最小违规集 + 歧义类诚实报告）。
