# 第 62 轮（承接第 61 轮「具身语义进化闭环」IP-173~182；新灵感循环第 1 轮；本轮灵感：「群体智能」×「预测性维护」）

> 第 61 轮构建了单机「语义-实时」闭环 ESEC：USR 把场景/意图/阻抗/证据统一到 ℝ^d_us，MEL 提供零样本物理属性推断，DMS 实现执行接地的多轮对话，SRT-Dual 解耦语义流与实时流，PCE+++++ 做六维预算兜底。但面向真实部署，仍有**五个结构性局限**：
> 1. **单体经验孤岛**：每个机器人的 MEL 物理先验只能从自身数据学习，**经验不可迁移**；新机器人面对新场景仍从零开始，第 61 轮的零样本能力在长尾场景下退化为「单机随机猜测」。
> 2. **健康假设静态**：EEIS/ERTC 默认本体、关节、力传感器是「时不变健康系统」，**阻抗证书按额定模型编译**；但齿轮磨损、谐波减速器背隙、力传感器漂移、电池老化会持续改变被控对象，证书在几小时后已悄悄失效。
> 3. **反应式而非预测式**：EFGP 依据「滑移、振动、力超限」等**事后证据**触发调整，属于「坏了再修」；缺乏对退化轨迹与剩余寿命（RUL）的前瞻预测，无法在失效前主动重规划。
> 4. **证书只证当下不证未来**：J_sem_exec 证明「当前这一拍安全」，但不证明「在未来任务时域 H 内仍安全」；一旦硬件退化，语义一致性与控制安全同时漂移。
> 5. **任务分配无视健康**：多机系统中任务分配只看能力与距离，**不看剩余寿命**；一台即将失效的机器人可能被派去执行长程任务，造成群体级停摆。

## 0. 直觉与动机

**灵感 1（群体智能 → 共识语义场 CSF）**
直觉：第 61 轮的 USR 是「单机大脑里的向量空间」，而群体智能的核心是**没有中心、靠局部交互涌现全局智能**。把 USR 从「单机私有的 ℝ^d_us」升级为**群体共享的语义场 F**：每个机器人把自己观测到的 scene_emb、φ_phys、evidence_emb、health_emb 像「信息素」一样写入场，其他机器人按信任度与时间衰减读取；场通过 gossip 做 CRDT 式合并，无需中心服务器。关键洞见：**物理经验成为可沉积、可挥发、可共识的公共资源**——一台机器人踩过的坑，成为整个群体的先验。

**灵感 2（预测性维护 → 退化轨迹证书 ProgCert）**
直觉：预测性维护的本质不是「检测故障」，而是**估计隐退化状态 h_t 并预测 RUL 分布**。为每个子系统 s（关节、减速器、力传感器、电池）建立退化动力学：h_{t+Δ} = h_t + μ_θ(h_t)Δ + σ_θ(h_t)√Δ·ξ + 负载耦合项；用粒子滤波/卡尔曼从遥测观测 y_t 反推 h_t，用 Wiener/Gamma 过程外推 RUL。关键洞见：**把 RUL 做成一张「证书」** ProgCert = (RUL 分位、退化轨迹、未来阻抗漂移 ΔK(H)、覆盖保证、有效期 H、维护触发器)，让「预测」进入可验证、可审计的证书体系。

**灵感 3（融合 → 退化感知阻抗先验 DAP）**
直觉：第 61 轮的 K_safe 假设「额定健康」。若齿轮磨损使等效摩擦 μ_fric 上升、传动刚度 k_stiff 下降，则同一个 K_p 在 t+H 时刻会表现出不同的闭环特性。**退化感知先验**把 ProgCert 中的 ΔK_s(H) 前馈进 EEIS：控制命令做「预补偿」K_cmd = K* ⊖ ΔK_s(H)，并把健康包络 K_health 与语义包络 K_safe 求交。关键洞见：**不是等退化发生后再调参，而是提前把未来的退化编译进当下的阻抗。**

**灵感 4（群体 × 预测 → 群体预后共识 SPC 与经验迁移 GEX）**
直觉：单机 RUL 估计样本极少、方差极大；但**同型号机器人的退化是同分布的**（同一批次、同一工况），可做分层贝叶斯：群体先验 p(θ) + 个体似然 p(D_i|θ)。新机器人无需经历失效，就能继承群体的退化参数后验。关键洞见：**群体既是「物理域随机化器」，也是「失效样本放大器」**；但必须用稳健聚合（trimmed/product-of-experts）抵御拜占庭与共模偏差，并显式承认「共模偏差不可由共识消除」。

**灵感 5（群体 + 维护 → 健康感知任务分配 HAT 与维护-任务协同 MTS）**
直觉：群体智能的另一半是**任务分配**。把任务 j 的时域 H_j 与机器人 i 的 ProgCert 对齐：只有 P(RUL_i ≥ H_j) ≥ 1-α 的机器人才能投标；投标值 = 成功概率 − 能耗 − 风险。当 RUL 余量不足时触发**交接证书**：状态、语义锚点、未完成约束一起迁移给健康同伴。维护不再是「停机事件」，而是与任务竞争时间资源的**可调度动作**，用信息素在群体中涌现出「谁先维护、谁先干活」。

**灵感 6（预算 → 八维认知-预后预算 PCE++++++）**
直觉：预后推理（粒子滤波、RUL 外推、保形校准）和群体共识（gossip、信任更新、拜占庭剔除）都要花算力与通信。第 61 轮六维预算缺这两项。拓展 **B_cog8 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_prog, B_swarm)**：B_prog 耗尽 ⇒ 粒子滤波降级为线性外推 ⇒ 再降级为「固定保守 RUL」；B_swarm 耗尽 ⇒ 降低 gossip 扇出、冻结信任更新、退回本地先验。**安全方向永不降级**。

## 1. 形式化定义（增量：定义 173–184）

**定义 173（共识语义场 CSF, Collective Semantic Field）**
F = (N, {U_i}, M, D_τ, ⊕, T)。其中：
- **智能体集** N = {1,…,N}，每个 i 持有本地 USR U_i（第 61 轮定义 161）
- **场存储** M：键值映射，key = (scene_hash, subsystem_id)，value = FieldEntry
  - FieldEntry = (src_id, scene_emb, φ_phys, evidence_emb, health_emb, RUL_est, trust, vclock, timestamp)
- **时间衰减** D_τ：w(Δt) = exp(−Δt/τ_field)，旧信息自动「挥发」，避免过期先验污染
- **合并算子** ⊕：对高斯量用加权 product-of-Gaussians；对嵌入用信任加权 Fréchet 均值；满足交换/结合/幂等（CRDT join）
- **拓扑** T：时变 gossip 图，每轮随机选 fanout k 个邻居交换摘要
- **读算子**：read_population_prior(x) = ⊕_{e∈M(x)} w_τ(e)·trust_e·e.φ_phys

**定义 174（退化状态与预后证书 ProgCert）**
对子系统 s ∈ S = {joint, reducer, force_sensor, battery}：
- **隐健康状态** h_t^s ∈ ℝ^{d_h}，退化动力学
  ```
  h_{t+Δ}^s = h_t^s + μ_θ(h_t^s, u_t)·Δ + σ_θ(h_t^s)·√Δ·ξ_t,  ξ_t ~ N(0,I)
  ```
  其中 u_t 为负载/温度/速度工况；μ_θ 单调非负（磨损不可逆），σ_θ 为扩散项
- **观测模型** y_t^s = g_θ(h_t^s) + ε_t（力噪声、电流、温度、振动频谱）
- **剩余寿命** R_s(t) = inf{Δ ≥ 0 : h_{t+Δ}^s ≥ h_fail^s}
- **预后证书** PC_s = (F̂_{R_s}, {h_{t+Δ}} 分位轨迹, ΔK_s(H), coverage, H_valid, trigger_s, σ_sig)
  - F̂_{R_s}：RUL 的经验/参数分布（保形校准后的分位）
  - ΔK_s(H)：未来 H 时域内该子系统退化导致的阻抗漂移预测
  - coverage：预测区间对真实 RUL 的覆盖保证（目标 1−α）
  - trigger_s：维护触发阈值（RUL < τ_RUL 或退化斜率 > τ_slope）
- **有效性**：Valid(PC_s, H) ⇔ P(R_s(t) ≥ H) ≥ 1−α ∧ ‖ΔK_s(H)‖ ≤ ε_drift

**定义 175（退化感知阻抗先验 DAP, Degradation-Aware Prior）**

**定义 176（群体预后共识 SPC, Swarm Prognostic Consensus）**

**定义 177（健康感知任务分配 HAT, Health-Aware Task Allocation）**

**定义 183（群体经验迁移 GEX, Group Experience Transfer）**
```
φ_phys^prior(i) = E[φ | F, U_i] ∝ p(φ) · Π_{j∈N(i)} p(D_j | φ)^{w_j}
N_eff = (Σ_j w_j)² / Σ_j w_j²
E[err_i] ≤ δ_sim2real / √N_eff + bias_common
```
- **收益**：同分布下物理先验误差随 N_eff 降；新机器人零样本能力随群体规模提升
- **边界**：共模偏差 bias_common **不可**被共识消除；只有独立批次/独立传感器/主动激励实验能降低它
- **迁移门控**：仅当 relevance_i（工况相似度）> τ_rel 且 trust_j > τ_trust 时允许注入

**定义 184（维护-任务协同调度 MTS, Maintenance-Task Scheduling）**
建模为带约束的 restless bandit / 长期平均 MDP：
- **状态**：({h_t^s}, task_queue, maintenance_resources, field_pheromone)
- **动作**：assign(task, robot)、maintain(robot, subsystem)、idle、handoff
- **奖励**：R = throughput − λ_D·downtime − λ_F·failure_risk − λ_C·maintenance_cost
- **约束**：长期非计划失效频率 ≤ ε_fail；证书有效性覆盖率 ≥ 1−α
- **信息素调度**：在退化证据密集的 (robot, subsystem) 上沉积维护信息素，按 D_τ 挥发；调度器优先处理信息素高且 RUL 低的单元，实现去中心化的「涌现式维护排序」

### IP-183 CSF（共识语义场）

```python
class CollectiveSemanticField:
    def __init__(self, N, d_us=256, tau_field=300.0, fanout=3):
        self.N = N
        self.d_us = d_us
        self.tau_field = tau_field
        self.fanout = fanout
        self.store = CRDTMap()          # key -> list[FieldEntry]
        self.trust = {i: 1.0 for i in range(N)}
        self.vclock = {i: 0 for i in range(N)}

    def deposit(self, src, scene_emb, phi_phys, evidence_emb, health_emb, pc):
        key = (hash_embedding(scene_emb), pc.subsystem_id)
        entry = FieldEntry(
            src_id=src, scene_emb=scene_emb, phi_phys=phi_phys,
            evidence_emb=evidence_emb, health_emb=health_emb,
            RUL_est=pc.rul_quantiles, trust=self.trust[src],
            vclock=dict(self.vclock), timestamp=time.time())
        self.store.join(key, entry)     # CRDT：幂等、可交换合并
        self.vclock[src] += 1

    def read_population_prior(self, key, now=None):
        now = now or time.time()
        cands = self.store.get(key, [])
        scored = []
        for e in cands:
            w = math.exp(-(now - e.timestamp) / self.tau_field) * e.trust
            if w >= W_MIN:
                scored.append((w, e))
        if not scored:
            return None, 0.0            # 无新鲜信息：回退本地先验
        # 拜占庭剔除：按与加权中位数的残差剔除两端 f 个
        med = weighted_median([e.phi_phys for _, e in scored],
                              [w for w, _ in scored])
        scored.sort(key=lambda we: dist(we[1].phi_phys, med))
        f = min(len(scored) // 3, MAX_TRIM)
        kept = scored[f:len(scored) - f] if len(scored) > 2 * f else scored
        phi = weighted_frechet_mean([e.phi_phys for _, e in kept],
                                    [w for w, _ in kept])
        conf = sum(w for w, _ in kept) / (sum(w for w, _ in scored) + 1e-9)
        return phi, conf

    def update_trust(self, src, predicted_phi, observed_phi, sigma_obs):
        err = dist(predicted_phi, observed_phi) / sigma_obs
        self.trust[src] = float(np.clip(
            self.trust[src] + ETA * (1.0 - err), 0.0, 1.0))

    def gossip_merge(self, rng):
        for i in range(self.N):
            peers = rng.choice(self.N, self.fanout, replace=False)
            for j in peers:
                self.store.merge_from(j)   # 交换摘要 + 向量时钟合并
```

### IP-184 ProgCert（预后证书）

```python
class PrognosticCertificate:
    def __init__(self, subsystem_id, n_particles=512, alpha=0.05):
        self.sid = subsystem_id
        self.alpha = alpha
        self.pf = ParticleFilter(n_particles, DegradationDynamics())
        self.conformal = ConformalCalibrator(coverage=1 - alpha)

    def update(self, y_t, u_t):
        self.pf.predict(u_t)
        self.pf.update(y_t)
        h_mean, h_cov = self.pf.moments()
        return h_mean, h_cov

    def predict_rul(self, h_t, u_profile, H_max):
        # 蒙特卡洛外推：每个粒子推演到 h_fail
        ruls = []
        for p in self.pf.particles:
            h = p.h.copy()
            for step in range(int(H_max / DT)):
                h = self.pf.dyn.step(h, u_profile(step), DT, rng)
                if h >= self.pf.dyn.h_fail:
                    ruls.append(step * DT)
                    break
            else:
                ruls.append(np.inf)
        return np.array(ruls)

    def predict_impedance_drift(self, h_t, H):
        # 退化→阻抗映射：磨损↑摩擦、背隙↑阻尼不确定性、刚度↓
        d_mu = self.pf.dyn.dmu_dh(h_t) * H
        d_k = self.pf.dyn.dk_dh(h_t) * H
        return ImpedanceDrift(mu_fric=d_mu, k_stiff=d_k)

    def build(self, h_t, u_profile, H_valid):
        ruls = self.predict_rul(h_t, u_profile, H_valid)
        q_lo, q_hi = np.quantile(ruls, [self.alpha / 2, 1 - self.alpha / 2])
        q_lo = self.conformal.calibrate(q_lo)   # 保形校准，保证覆盖
        drift = self.predict_impedance_drift(h_t, H_valid)
        return ProgCert(
            sid=self.sid, rul_quantiles=(q_lo, q_hi),
            rul_dist=ruls, impedance_drift=drift,
            coverage=1 - self.alpha, H_valid=H_valid,
            trigger=self._maintenance_trigger(ruls, drift),
            timestamp=time.time())

    def _maintenance_trigger(self, ruls, drift):
        return {'rul_threshold': np.quantile(ruls, 0.1),
                'drift_threshold': DRIFT_EPS}
```

```python
class MaintenanceTaskScheduler:
    def __init__(self, lam_D=1.0, lam_F=2.0, lam_C=0.5, eps_fail=0.01):
        self.lam_D, self.lam_F, self.lam_C = lam_D, lam_F, lam_C
        self.eps_fail = eps_fail
        self.pheromone = defaultdict(float)

    def deposit(self, robot_id, pc):
        self.pheromone[(robot_id, pc.sid)] += max(0.0, 1.0 - pc.rul_quantiles[0] / RUL_REF)

    def evaporate(self, dt):
        for k in list(self.pheromone):
            self.pheromone[k] *= math.exp(-dt / TAU_PHEROMONE)

    def schedule(self, assignment, pcs_by_robot):
        # restless bandit：优先处理 (pheromone 高 ∧ RUL 低) 的单元
        priority = []
        for rid, pcs in pcs_by_robot.items():
            for sid, pc in pcs.items():
                idx = self.pheromone[(rid, sid)] * (1.0 / (pc.rul_quantiles[0] + EPS))
                priority.append((idx, rid, sid))
        priority.sort(reverse=True)
        plan = []
        for idx, rid, sid in priority:
            if idx < MAINT_MIN_PRIORITY:
                break
            if self._worth_interrupting(rid, assignment):
                plan.append(MaintenanceJob(rid, sid, at=self._earliest_slot(rid)))
        return plan

    def _worth_interrupting(self, rid, assignment):
        # 长期约束：非计划失效频率 ≤ eps_fail；宁可计划停机
        return expected_failure_prob(rid) > self.eps_fail
```

```python
class CollectiveSemanticField:
    def __init__(self, N, d_us=256, tau_field=300.0, fanout=3):
        self.N, self.d_us = N, d_us
        self.tau_field, self.fanout = tau_field, fanout
        self.store = CRDTMap()
        self.trust = {i: 1.0 for i in range(N)}
        self.vclock = {i: 0 for i in range(N)}

    def deposit(self, src, scene_emb, phi_phys, evidence_emb, health_emb, pc):
        key = (hash_embedding(scene_emb), pc.subsystem_id)
        self.store.join(key, FieldEntry(
            src, scene_emb, phi_phys, evidence_emb, health_emb,
            pc.rul_quantiles, self.trust[src],
            dict(self.vclock), time.time()))
        self.vclock[src] += 1

    def read_population_prior(self, key):
        now = time.time()
        scored = [(math.exp(-(now - e.timestamp) / self.tau_field) * e.trust, e)
                  for e in self.store.get(key, [])]
        scored = [(w, e) for w, e in scored if w >= W_MIN]
        if not scored:
            return None, 0.0
        med = weighted_median([e.phi_phys for _, e in scored],
                              [w for w, _ in scored])
        scored.sort(key=lambda we: dist(we[1].phi_phys, med))
        f = min(len(scored) // 3, MAX_TRIM)
        kept = scored[f:len(scored) - f] if len(scored) > 2 * f else scored
        phi = weighted_frechet_mean([e.phi_phys for _, e in kept],
                                    [w for w, _ in kept])
        return phi, sum(w for w, _ in kept) / (sum(w for w, _ in scored) + 1e-9)

    def update_trust(self, src, predicted_phi, observed_phi, sigma_obs):
        err = dist(predicted_phi, observed_phi) / sigma_obs
        self.trust[src] = float(np.clip(
            self.trust[src] + ETA * (1.0 - err), 0.0, 1.0))

    def gossip_merge(self, rng):
        for i in range(self.N):
            for j in rng.choice(self.N, self.fanout, replace=False):
                self.store.merge_from(j)
```

### IP-184 ProgCert（预后证书）

```python
class PrognosticCertificate:
    def __init__(self, subsystem_id, n_particles=512, alpha=0.05):
        self.sid, self.alpha = subsystem_id, alpha
        self.pf = ParticleFilter(n_particles, DegradationDynamics())
        self.conformal = ConformalCalibrator(coverage=1 - alpha)

    def update(self, y_t, u_t):
        self.pf.predict(u_t)
        self.pf.update(y_t)
        return self.pf.moments()

    def predict_rul(self, h_t, u_profile, H_max):
        ruls = []
        for p in self.pf.particles:
            h = p.h.copy()
            for step in range(int(H_max / DT)):
                h = self.pf.dyn.step(h, u_profile(step), DT, rng)
                if h >= self.pf.dyn.h_fail:
                    ruls.append(step * DT); break
            else:
                ruls.append(np.inf)
        return np.array(ruls)

    def build(self, h_t, u_profile, H_valid):
        ruls = self.predict_rul(h_t, u_profile, H_valid)
        q_lo, q_hi = np.quantile(ruls, [self.alpha / 2, 1 - self.alpha / 2])
        q_lo = self.conformal.calibrate(q_lo)
        drift = self.predict_impedance_drift(h_t, H_valid)
        return ProgCert(self.sid, (q_lo, q_hi), ruls, drift,
                        1 - self.alpha, H_valid,
                        self._trigger(ruls, drift), time.time())
```

### IP-185 DAP（退化感知阻抗先验）

```python
class DegradationAwarePrior:
    def compile(self, anchor, delta_f_req, fused, xi_exec, Z_env, pcs, H_task):
        K_star = self.usr.project_to_impedance(anchor)
        if not all(pc.valid_for(H_task) for pc in pcs):
            return None, 'prognostic_invalid'
        drift = sum_impedance_drift([pc.impedance_drift for pc in pcs], H_task)
        K_cmd = self.compensate(K_star, drift)
        K_health = self.health_envelope(pcs, H_task)
        K_safe = intersect_envelope(
            self.eeis.compile(delta_f_req, fused, xi_exec, Z_env, K_cmd),
            K_health)
        return (K_safe, 'ok') if not K_safe.is_empty() else (None, 'envelope_empty')

    def compensate(self, K, drift):
        K = K.copy()
        K['K_p'] /= max(1.0 - drift.alpha_wear, EPS)
        K['K_d'] *= (1.0 + drift.beta_backlash)
        K['F_max'] *= (1.0 - drift.mu_margin)
        return K
```

```python
class SwarmPrognosticConsensus:
    def aggregate_theta(self, key):
        priors = self.field.store.get(key, [])
        if not priors:
            return None
        return robust_mle(
            data=[p.degradation_data for p in priors],
            weights=[p.trust * p.relevance for p in priors],
            loss='tukey', trim=1/3)

    def consensus_rul(self, pcs):
        lo = weighted_quantile([pc.rul_quantiles[0] for pc in pcs],
                               [pc.trust for pc in pcs], 0.05)
        hi = weighted_quantile([pc.rul_quantiles[1] for pc in pcs],
                               [pc.trust for pc in pcs], 0.95)
        return RULConsensus(lo, hi,
            disagreement=(hi - lo) / max(np.median([np.mean(pc.rul_dist) for pc in pcs]), EPS))

    def detect_byzantine(self, pcs, observations):
        res = [abs(pc.last_pred - observations[pc.sid]) for pc in pcs]
        med = np.median(res)
        mad = np.median(np.abs(np.array(res) - med)) + EPS
        return [pc.sid for pc, r in zip(pcs, res) if r > 3.5 * mad]
```

### IP-187 HAT（健康感知任务分配）

```python
class HealthAwareAllocator:
    def eligible(self, robot, task):
        return all(pc.valid_for(task.horizon) for pc in robot.pcs) \
               and robot.K_envelope.intersect(task.requirements) is not None

    def bid(self, robot, task):
        if not self.eligible(robot, task):
            return -np.inf
        margin = min_rul(robot.pcs) - task.horizon
        return (robot.success_model.predict(task, robot.pcs)
                - self.lam_E * robot.energy_model.estimate(task)
                - self.lam_R * robot.risk_model.predict(task, robot.pcs)
                - self.lam_M * max(0.0, self.margin_min - margin))

    def auction(self, robots, tasks):
        bids = {(r.id, t.id): self.bid(r, t) for r in robots for t in tasks}
        x = solve_assignment(bids, redundancy=REDUNDANCY)
        handoffs = [self.build_handoff(r, x) for r in robots
                    if min_rul(r.pcs) < min(t.horizon for t in tasks)]
        return x, handoffs
```

```python
class CognitivePrognosticBudget:
    def __init__(self, base, n_particles=512, prog_freq=1.0, rul_horizon=100.0,
                 gossip_fanout=3, consensus_rounds=2, msg_budget=1000):
        self.base = base
        self.B_prog = dict(n_particles=n_particles, freq=prog_freq,
                           horizon=rul_horizon, calib=100)
        self.B_swarm = dict(fanout=gossip_fanout, rounds=consensus_rounds,
                            msgs=msg_budget)
        self.prog_used = self.swarm_used = 0
        self.prog_mode, self.swarm_mode = 'particle', 'full'

    def prog_step(self, latency):
        self.prog_used += 1
        if self.prog_used > self.B_prog['freq'] * self.B_prog['horizon']:
            self.prog_mode = 'linear'
        if latency > TAU_PROG:
            self.prog_mode = 'fixed'
        if self.prog_mode == 'fixed' and self.prog_used > 2 * self.B_prog['freq']:
            self.prog_mode = 'forbid'

    def voi_cog8(self, action):
        base = self.base.voi_cog5(action)
        if action.type == 'prognostic_update':
            return base - 0.3 * (action.particles / self.B_prog['n_particles'])
        if action.type == 'gossip':
            return base - 0.2 * (action.fanout / self.B_swarm['fanout'])
        return base

    def tighten_safety(self):
        return {'drift_margin_scale': 0.7 if self.prog_mode != 'particle' else 1.0,
                'health_envelope_scale': 0.8 if self.swarm_mode != 'full' else 1.0}
```

```python
def cscp_merge(local, incoming):
    for key, entries in incoming.items():
        for e in entries:
            if dominates(e.vclock, local.vclock[key]):
                local[key] = [e]
            elif concurrent(e.vclock, local.vclock[key]):
```

```python
class DegradationDialogue:
    def actions(self, pcs, H_task):
        acts = []
        rul = min(pc.rul_quantiles[0] for pc in pcs.values())
        slope = max(pc.degradation_slope for pc in pcs.values())
        if rul < H_task:
            acts.append(DialogueAction('handoff_request',
                reason=f'RUL {rul:.1f}s < task horizon {H_task:.1f}s'))
        elif slope > TAU_SLOPE:
            worst = max(pcs.values(), key=lambda pc: pc.degradation_slope)
            acts.append(DialogueAction('recommend_maintenance',
                subsystem=worst.sid, urgency=slope / TAU_SLOPE,
                evidence=worst.rul_quantiles))
        if self.field_disagreement > TAU_DIS:
            acts.append(DialogueAction('report_health',
                consensus_interval=self.consensus.interval))
        return acts
```

```python
class MaintenanceTaskScheduler:
    def deposit(self, rid, pc):
        self.pheromone[(rid, pc.sid)] += max(
            0.0, 1.0 - pc.rul_quantiles[0] / RUL_REF)

    def evaporate(self, dt):
        for k in list(self.pheromone):
            self.pheromone[k] *= math.exp(-dt / TAU_PHEROMONE)

    def schedule(self, assignment, pcs_by_robot):
        priority = []
        for rid, pcs in pcs_by_robot.items():
            for sid, pc in pcs.items():
                priority.append((self.pheromone[(rid, sid)]
                                 / (pc.rul_quantiles[0] + EPS), rid, sid))
        priority.sort(reverse=True)
        return [MaintenanceJob(rid, sid, at=self._earliest_slot(rid))
                for idx, rid, sid in priority
                if idx >= MAINT_MIN_PRIORITY
                and expected_failure_prob(rid) > self.eps_fail]
```

**正确性定理（SPEL-Sound）**：
在 A61–A70 与 A71–A76 下：
1. **预后安全性**：∀s Valid(PC_s,H_task) ∧ K_safe∈K_health ⇒ H_task 内保持安全包络的概率 ≥ 1−α−δ_pf。
2. **群体增益**：E[err] ≤ δ_sim2real/√N_eff + bias_common；群体规模收益亚线性，共模偏差为硬下界。
3. **共识稳健性**：f<N/3 拜占庭下，RUL 共识偏差 ≤ 3.5·MAD_trim。
4. **分配安全性**：HAT 只把任务分配给证书覆盖任务时域的机器人；无人满足则维护/交接而非冒险。
5. **实时性不退化**：预后与共识异步于语义流/群体层，实时流周期 ≤ 1ms 契约不变。
6. **预算安全**：B_prog/B_swarm 降级只收紧 drift_margin 与 K_health，绝不放宽。

## 5. 本轮最大风险

**一句话**：若群体共享同一批次缺陷或同一传感器偏差（共模偏差），CSF/SPC 会把「一致的错误」放大为「集体的自信」，再叠加退化模型对突发非单调失效（如轴承瞬间抱死）的系统性低估，将出现「全体证书都说健康、任务却集体停摆」的**共识性虚假安全**；必须以「共模偏差显式建模 + 独立物理冗余 + 保形 RUL 下界 + 硬维护联锁 + 主动激励实验」构建群体级安全护栏，绝不让「共识」替代「独立验证」。
