# 第 71 轮（承接第 70 轮「BELIEF-RAS 贝叶斯状态估计交互消歧闭环」IP-264~274；灵感循环新循环第 1 轮；本轮灵感：「姿态估计」×「UniBot」）

> R70 把不确定性从「动作模态」推进到「世界状态后验 b_t(s)」，交付了贝叶斯滤波、状态校准门与原型验收。但 R70 的后验活在一个**没有单位、没有共同物理坐标、也只有一个本体**的空间里：
> 1. **无度量**：H[b_t] 是表征相关的。换一套潜变量参数化、换一个粒子数、换一个编码器，熵就变；而「慢 1 厘米会不会撞」是物理问题，熵回答不了。
> 2. **无共同坐标**：视觉、力、语言、仿真被融合进一个学出来的抽象状态，彼此是否自洽只能靠概率，不能靠几何。标定一旦把残差抹平，后验仍可「自信地错」。
> 3. **无第二本体**：单本体系统的全部证据都经过同一套传感器、同一套标定、同一个模型，系统性偏差因此不可见——它没有独立的第二个「我」来质疑第一个「我」。
>
> 本轮两个灵感正好各补一块：
> - **姿态估计**把「世界在哪」落成**可度量的 SE(3) 对象**：位姿连同其李代数协方差，是少数同时具备物理单位、可微、跨模态可比较的不确定性载体。任务只关心它的一小部分投影（任务雅可比），于是「不确定」第一次可以被翻译成「沿插入轴差几毫米、绕抓取轴差几度」。
> - **UniBot**（通用机器人智能体／跨本体统一模型）把「多个本体、多个内部仿真、多个候选解」当作一等资源：同一潜变量经不同本体适配器产生多个可执行方案，同一动作在多个仿真器中预演并仲裁。它让我们可以组织一个**锚定在同一几何坐标上的委员会**，用「本体间／仿真间的几何分歧」而不是「单一模型的熵」来度量 epistemic。
>
> 核心命题：**把 R70 的抽象后验熵替换／补充为「姿态锚定的度量式 epistemic」——以 SE(3) 轨迹的委员会分歧为不确定性的物理单位；以规范不变相对几何（GIC）作为标定无法吸收的第三意见；以最坏情况委员会仲裁（CWG）保证任何单一模型的自信都不能越过几何安全；以任务投影（TAP）只对真正影响任务的自由度收紧或探询。** 命名 **ANCHOR-RAS**（**A**nchored **N**eural **C**ommittee for **H**olistic **O**bservation and **R**igid-body geometry for **R**isk-**A**ware **S**afety）。
>
> 一句话定位：R68 问「尺子准吗」，R69 问「该问谁」，R70 问「我在什么状态」，R71 问「**我的状态信念在世界坐标里到底偏了几毫米，我的多个身体／多个仿真是否同意，而我的任务是否真的在乎这几毫米**」。

## 0. 直觉与动机

**灵感 1（姿态估计 → 不确定性第一次有了单位）**
直觉：R70 用 H[b_t] 说「我有多不确定」。但熵的单位是 nat，无法直接进入安全包络：0.8 nat 到底是「可以抓」还是「该停」？姿态估计给出的是另一类东西——一个 SE(3) 分布，其李代数协方差可以直接投影成末端执行器的毫米与弧度。更关键的是，**姿态是关系性的**：物体相对夹爪、相机相对机体、多视角之间的相对位姿。关系量对全局刚体变换不变，而标定恰恰只能吸收全局刚体变换（规范自由度）。这给出一条与「传感器残差」和「流似然」都正交的证据通道。
直觉结论：把「状态」从抽象潜变量换成**姿态锚点 x ∈ SE(3)^N**，不确定性的主语言就从「熵」变成「度量式协方差」，而度量式协方差可以被任务雅可比筛成「真正要紧的那几毫米」。

**灵感 2（任务投影 → 不是所有不确定都值得慢下来）**
直觉：绕一根圆柱的轴旋转 ±30°，对「把圆柱插进孔」几乎无影响，对「把带标记的面朝上」却是灾难。R70 对两者一视同仁地收紧，既保守又浪费。姿态的几何结构让这件事可以被精确切开：任务输出 τ = T(x) 的雅可比 J = ∂T/∂x 给出「任务敏感子空间」；落在 ker J 里的不确定性对任务风险贡献为零。于是**同一套位姿不确定性，在不同任务下有不同的有效大小**——这才是「任务相关」的严格含义，也是 resolution bonus 的几何版本。

**灵感 3（UniBot → 用「多个身体/多个仿真」制造独立冗余）**
直觉：单模型的最大问题是共享偏差：训练数据错了，所有头一起错，委员会一致通过。UniBot 式通用智能体天然提供两种多样性：(a) **本体多样性**——同一任务可由不同运动学/执行器的适配器实现，它们对「世界怎么变」的预测必须落在同一个物理结果上；(b) **仿真多样性**——同一动作在多个内部仿真里预演，落地结果应在同一 SE(3) 坐标里收敛。于是 epistemic 可以被定义为**这些独立实现所预测的度量轨迹之间的分歧**，而不是单一网络的输出方差。它还有一个 R70 没有的好处：**分歧是用米/弧度度量的，与各本体的潜变量参数化无关**——换表征不改变结论。
直觉结论：把 UniBot 从「一个更大的模型」重新理解为「一个**锚定在同一几何上的委员会**」；它的价值不在于更强，而在于**可被证伪的多样性**。

**灵感 4（规范不变几何 → 标定吸收不了的那一部分）**
直觉：R68 的 COF 用传感器残差判断「尺子弯没弯」，R69 用流似然做第二意见。但两者都能被一个足够灵活的校准层「解释掉」。姿态几何给出第三条：**相对几何闭合误差**。一个缓慢的关节零点漂移、连杆热膨胀、尺度漂移、柔性变形，都不是刚体变换；它们无法被「每个传感器/每个刚体一个刚体校正」同时抹平，因此会在相对位姿闭合、运动学闭合、接触非穿透里留下规范不变的残差。用群的 LanGUAGE 说清楚：**标定能吸收的恰是规范群；商空间上的残差才是真故障**。
直觉结论：GIC 不是又一个残差通道，而是**第一个有群论边界的残差通道**——它知道自己的盲区，也知道盲区之外一定看得见。

**灵感 5（最坏情况 + 主动探询 → 安全由委员会的下界决定，效率由探询购买）**
直觉：如果委员会的成员彼此不同意，取平均是最坏的赌注——平均动作可能对每个成员都危险。正确姿态是**最坏情况仲裁**：只在所有成员都认为安全的动作集合里选；若交集为空，不执行、先探询。探询也不该瞎问：在度量空间里，分离前两名委员会成员的最优测量方向有闭式解（T-最优实验设计，沿 (Σ_1+Σ_2)^{-1}(μ_1−μ_2) 方向）。这让「问」从启发式变成一次廉价的二次型计算。
直觉结论：ANCHOR 的安全性是**可证的下界**（最坏成员），效率是**可买的**（主动探询），而不是靠平均或熵阈值许愿。

class PoseAnchor:
    def __init__(self, pose_net, calib, fk, task_jac_fn):

## 3. 推导

**引理 23（度量式 epistemic 的表征不变性）** 设潜变量表征 φ 与 φ′ 由微分同胚 h 连接，R70 的后验熵满足 H[b′] = H[b] + E[log|det Dh|]，一般不为零；而 U_epi^metric 只依赖规范坐标中的 SE(3) 轨迹差与固定的任务雅可比 J_T，故在 h 下不变。系：**ANCHOR 的 epistemic 是「可写进证书的物理量」，R70 的熵不是**；表征升级（换编码器/粒子数）不再改变风险结论，只改变实现。

**引理 24（任务投影的风险上界）** 若任务损失 ℓ 对 τ 为 L-Lipschitz，则对任意动作
E[ℓ(T(x))] ≤ ℓ(T(x̄)) + L·√(tr(Π_𝒯 Σ Π_𝒯^T))。
证明：Jensen + Lipschitz + 把 Σ 分解为 𝒯 与 ker J_T；后者被 T 湮灭。系：**ker J_T 内的不确定性可以被安全地忽略而不抬高认证风险上界**——这是 geometric resolution bonus 的合法性来源；反之，若把真风险投影进 ker J_T，上界失效（VQAuditor-III 审计对象）。

**引理 25（标定规范群的可吸收性）** 在无噪声线性化下，故障 δ 使所有 r_GIC 恒为零 ⇔ δ ∈ Lie(𝒢_cal)。证明：𝒢_cal 正是使所有刚体相对位姿约束保持为零的变换群；其李代数即约束的零空间；商残差即零空间的正交补上的投影。系：**关节零点、柔性、热膨胀、尺度漂移等非刚体慢故障必然被 GIC 看见**，即使 COF 把传感器残差抹平；这是对 R69 引理 17 与 R68 反吸收引理的几何补强。

**引理 26（最坏情况委员会安全与覆盖失败）** 设真实世界模型 m* 属于委员会预测包络（覆盖假设 A106：∃k, ‖Log(x̂_k)−Log(x*)‖ ≤ τ_cov）。则对任意 a ∈ 𝒜_safe（定义 339），真实风险 r*(a) ≤ max_k r̂_k(a) + L_cov·τ_cov ≤ ε + L_cov·τ_cov。若 A106 失败（真模型在包络外），委员会可以**一致且自信地错**，此时 CWG 下界失效。系：**ANCHOR 的安全是条件安全**；覆盖是唯一必须被独立监测的假设，必须由 GIC 与 open-set 密度兜底。

**引理 27（T-最优探询的闭式增益）** 对两个高斯假设 𝒩(μ_1,Σ_1)、𝒩(μ_2,Σ_2) 与测量噪声 Σ_g，选择线性测量方向 v 的期望对数似然比增益为
IG(v) = ½ (v^T(μ_1−μ_2))² / (v^T(Σ_1+Σ_2+Σ_g)v)，
在 v* ∝ (Σ_1+Σ_2+Σ_g)^{-1}(μ_1−μ_2) 处取最大，最大值为 ½·(μ_1−μ_2)^T(Σ_1+Σ_2+Σ_g)^{-1}(μ_1−μ_2)。系：**探询的排序是一次广义特征值/二次型计算，O(d²)**；且只在任务敏感子空间内做，探询不会去分离一个对任务无影响的自由度。

**定理 20（四层严格嵌套）** A99–A106 下，ANCHOR 的期望风险 ≤ BELIEF ≤ FLUID ≤ R68；且当 K=1、无姿态测量、r_GIC=0、Cov(𝒞)=1、U_epi^metric=0 时逐指令相同。任何新通道只能让系统**更早保守或更早探询**，不能更晚保守。

**定理 21（几何否决封住「自信地错」）** 若存在成员 k 使某动作违反刚体/运动学/接触约束（r_GIC>τ 或几何包络越界），则该动作不可认证，无论语义后验多自信；此时 λ 单调不降地退回 R68 最保守。故「自信地错」的后果被限制为**效率损失**，而非**未认证的不安全动作**。这是对 R70 最大风险的直接封堵：**语义可以错，几何是否决权**。

**定理 22（实时性与无突变）** PGA（<0.5ms）+ 委员会 K≤3（<0.6ms，复用 trunk 缓存）+ MED/TAP（<0.03ms）+ GIC（<0.05ms）+ T-最优探询（<0.02ms）+ CWG（<0.05ms）总增量 <1.3ms；流形认证保证位姿轨迹连续，探询失败/超时/覆盖不足时 λ 单调不降，R68 换装不变式（定理 15）保持。**P99 名义 <5.6ms，歧义路径 <6.4ms**；Proto-Val 的口径必须以证书中的 anchor_ver 与 K 为准。

## 6. 本轮最大风险

**一句话**：ANCHOR-RAS 把安全押在「委员会覆盖真实世界」这一假设上——**若所有成员共享同一个训练偏差或同一套错误物理（同源仿真、同源数据、同源适配器），它们会一致同意一个错误结论，MED 趋向零而 U_model 却不自知；此时「分歧小」被误读成「确定」，越一致越危险**；而最坏情况仲裁只能防「成员之间不一致」，防不了「全体一起错」，因此覆盖监测（GIC/open-set）一旦失灵，R71 会用比 R70 更精致、更有物理单位的方式，把系统更快地推向同一个错误。

**次级风险与缓解**：
1. **任务投影被滥用**（把真风险投进 ker J_T）→ VQAuditor-III 审计 + E323 安全约束内比较 + 投影算子可追溯；
2. **GIC 规范群建模错误**（漏掉某个真实柔性自由度）→ 保守取超集 𝒢_cal + E325/E326 + 残差阈值随工况自适应；
3. **委员会成员假多样性**（同源）→ 成员来源审计 + E324/E332 + 强制至少一个物理独立成员（不同传感器/仿真器）；
4. **探询动作本身不安全** → C-RAS-WM 认证 + 任务敏感方向约束 + E330 零违规；
5. **T-最优探询的线性高斯假设失配** → 只在 top-2 近高斯时启用，否则回退 R70 MINT 的通用 VoI；
6. **实时预算被 K 与姿态推理击穿** → 自适应 K + 缓存 + DERATE 风格的显式降级配置（证书记录实际档位）。

## 2. 形式化定义（要点版）

**定义 331（总览与四不变式）** ANCHOR-RAS 继承 BELIEF 全部组件（† 升级），新增 PGA/UBC/MED/TAP/GIC/CAP/UBA/CWG/COV。四不变式：(i) 实时流零学习写操作；(ii) 度量纪律——进入安全路径的不确定性必须能表示为任务投影后的 SE(3) 散度；(iii) 委员会/探询预算（K≤K_max、单位时间探询≤1、探询需认证）；(iv) 最坏情况下界纪律——证书不得用均值替代最坏成员，覆盖不足必须 open-set 并退回 R68。

**定义 332（度量姿态状态）** s = (x, ψ)，x ∈ SE(3)^{N_o+1}，ψ ∈ {1..M}；任务 τ = T(x,ψ)。位姿用左不变集中高斯在 se(3)≅ℝ⁶ 上表达；禁止对旋转矩阵逐元素求平均。

**定义 333（PGA 姿态锚定）** 输出 q_t(x)=Σ_j π_j N_{SE(3)}(μ_j,Σ_j) 与标定后协方差 Σ^cal、几何校准误差 ECE_geo。标定只允许在 Lie(𝒢_cal) 上作用。

**定义 334（UBC 委员会）** 成员 k 给出规范坐标中的 (ξ̂_k, v̂_k, r̂_k)。成员来源必须至少有一个物理独立维度（不同传感器/仿真器/本体），否则视为假多样性（定义 347）。

**定义 335（MED）** 见符号表。相对 R70 的 H[b_t]：有单位、表征不变、只计任务敏感方向。

**定义 336（TAP）** 任务敏感子空间 𝒯=row(J_T)；ker J_T 内的不确定性不收紧、不探询、不降速；但最坏成员安全包络仍需满足。

**定义 337（GIC）** 四残差在规范重锚定后取商；r_GIC^gauge 对 𝒢_cal 不变。

**定义 338（标定规范群）** 故障可被标定吸收 ⇔ δ∈Lie(𝒢_cal)。非刚体故障（关节零点、柔性、热膨胀、尺度漂移、滑移）必然留下非零商残差。GIC 与 R68 传感器残差、R69 流似然正交。

**定义 339（CWG）** a*=argmin_{a∈𝒜_safe} max_k r̂_k(a)；𝒜_safe=∅ ⇒ 不执行，转 CAP 或退回 R68。证书记录最坏成员身份。

**定义 340（CAP）** 对 top-2 成员用 T-最优方向 v*；IG 闭式计算；只在 𝒯 内探询；g*=argmax[IG−c]，需预算与认证。

**定义 341（路由代数）** U_ale→λ_floor；U_epi^metric→CAP/仲裁；r_GIC^gauge→重标定/降级/open-set；U_model→open-set+最保守。未消解者才并入 λ_floor。

**定义 342（UBA）** 规范机体 ℬ、重定向 R_{e→c}、共享编码 Φ_U；跨本体比较必须在规范坐标；位姿先验跨本体迁移。

**定义 343（COV 与模型形式 epistemic）** U_model=1−Cov(𝒞)。委员会一致但覆盖低 = 集体育信地错；共享偏差不产生分歧，故「分歧小 ≠ 正确」。

**定义 344（两级风险缩放）** U_floor=U_ale+α_epi U_epi^metric+α_fault U_geo^fault+α_model U_model；λ=max(λ_efs, λ_floor(U_floor))。任务投影为零的方向获得 geometric resolution bonus。

**定义 345（流形认证前缀与几何否决）** 对每个成员与每个中间位姿检查可达流形、r_rigid/r_kin/r_contact、摩擦锥；任一越界即不可认证；语义置信不得覆盖几何否决。

**定义 346（J_ANCHOR）** 见符号表。Valid ⇔ Valid(J_BELIEF) ∧ ECE_geo≤τ ∧ r_GIC^gauge≤τ ∧ Cov(𝒞)≥c_min ∧ 度量纪律 ∧ 预算。

**定义 347（VQAuditor-III）** 审：任务投影是否藏风险、探询是否越界、最坏成员是否被均值替换、GIC 告警是否被语义覆盖、成员是否同源假多样性。

**定义 348（AIC-ANCHOR）** ℰ_ANCHOR=ℰ_BELIEF×ℰ_pose×ℰ_committee；重点防「相关性攻击」——让委员会一起错，比让一个成员错更容易。

**定义 349（Pipeline 与严格包含）** 主闭环见下；边界 K=1/无姿态/无 GIC/U_model=0 ⇒ BELIEF；再禁交互 ⇒ FLUID；再永不保守 ⇒ R68。

## 4. 推导

**引理 23（MED 的表征不变性）** 潜变量表征 φ→φ′ 由微分同胚 h 连接时，R70 的 H[b′]=H[b]+E[log|det Dh|] 一般改变；U_epi^metric 只依赖规范坐标 SE(3) 轨迹差与固定 J_T，故不变。⇒ 换编码器/粒子数不改变风险结论，只改变实现。

**引理 24（任务投影风险上界）** ℓ 对 τ 为 L-Lipschitz ⇒ E[ℓ(T(x))] ≤ ℓ(T(x̄))+L√(tr(Π_𝒯 Σ Π_𝒯^T))。⇒ ker J_T 内不确定性可安全忽略而不抬高认证上界；把真风险藏进 ker J_T 则上界失效（审计对象）。

**引理 25（规范群可吸收性）** 无噪声线性化下，r_GIC≡0 ⇔ δ∈Lie(𝒢_cal)。⇒ 关节零点、柔性、热膨胀、尺度漂移、滑移等非刚体慢故障必被 GIC 看见，即使 COF 抹平了传感器残差；这是对 R69 引理 17、R68 反吸收引理的几何补强。

**引理 26（最坏情况安全与覆盖失败）** 若 A106（∃k, ‖Log x̂_k−Log x*‖≤τ_cov），则 ∀a∈𝒜_safe，r*(a)≤ε+L_cov τ_cov。若 A106 失败，委员会可一致且自信地错，CWG 下界失效。⇒ 安全是条件安全，覆盖必须被独立监测（GIC+open-set）。

**引理 27（T-最优探询闭式解）** 两高斯假设 + 测量噪声 Σ_g 下，方向 v 的增益 IG(v)=½(v^TΔμ)²/(v^TΣ_Σ v)，在 v*∝Σ_Σ^{-1}Δμ 处最大，最大值 ½ Δμ^TΣ_Σ^{-1}Δμ。⇒ 探询排序 O(d²)，且只在 𝒯 内做，不会去分离任务无关自由度。

**定理 20（四层严格嵌套）** A99–A106 下风险 ≤ BELIEF ≤ FLUID ≤ R68；K=1、无姿态、r_GIC=0、Cov=1、MED=0 时逐指令相同。新通道只让系统更早保守或更早探询。

**定理 21（几何否决封住「自信地错」）** 任一成员预测违反刚体/运动学/接触约束 ⇒ 动作不可认证，语义后验再自信也无效；λ 单调不降回 R68 最保守。⇒ 语义可以错，几何拥有否决权；R70 的「H 变小风险变大」被限制为效率损失，而非未认证的不安全动作。

**定理 22（实时性与无突变）** 增量 <1.3ms；流形认证保证轨迹连续；探询失败/超时/覆盖不足时 λ 单调不降，R68 换装不变式保持。名义 P99 <5.6ms、歧义路径 <6.4ms；Proto-Val 口径按 anchor_ver 与 K 记录。

## 7. 本轮最大风险

**一句话**：ANCHOR-RAS 的安全建立在「委员会覆盖真实世界」之上——**当所有成员共享同一训练偏差或同一套错误物理（同源数据、同源仿真、同源适配器）时，它们会一致同意一个错误结论：MED→0 而 U_model 不自知，「越一致越确定」被误读成「越一致越正确」；最坏情况仲裁只防成员间不一致，防不了全体一起错，于是系统可能以比 R70 更精致、更有物理单位的方式，更快地走向同一个错误。**

**次级风险与缓解**：
1. **任务投影被滥用**（真风险藏进 ker J_T）→ VQAuditor-III + E323 安全约束内比较 + 投影算子可追溯；
2. **规范群建模错误**（漏掉真实柔性自由度）→ 取超集 𝒢_cal + E325/E326 + 阈值随工况自适应；
3. **假多样性**（同源成员）→ 成员来源审计 + E324/E332 + 强制至少一个物理独立成员；
4. **探询动作越界** → C-RAS-WM 认证 + 仅任务敏感方向 + E330 零违规；
5. **线性高斯假设失配** → 仅 top-2 近高斯时启用 T-最优，否则回退 R70 MINT 通用 VoI；
6. **实时预算被 K 与姿态推理击穿** → 自适应 K + 缓存 + 显式降级配置（证书记录实际档位）。
