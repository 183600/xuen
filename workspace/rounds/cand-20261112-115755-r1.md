# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 4 轮；本轮灵感：「多轮对话」×「主动交互」）

> 第 57 轮把安全的赌注从"模型置信"搬到"少样本可校准、跨模态可对账、个性化有界的证据承诺"，但它的风险自陈暴露了一个被三种机制共同放大的隐患：**所有"证据"与"同意"仍被当作一次性事件**。EV-probe 问一次、EV-human 确认一次、解释发一次、授权判一次——人类交互被压成"单轮问答 + 即时签字"，而真实的监督是**有时间结构的对话**：先澄清指代、再对齐语义、再确认风险、再给同意，中间还会反悔。一次性的"确认"既无法暴露"机器人指的和我理解的不是同一块冰"（假共同基础），也无法在疲劳或被引导时被逐步纠正。更关键的是，第 57 轮的"个性化授权"与"跨模态一致加成"一旦遇到"主动发问"，就获得了一个新的博弈面：**谁来发起对话、何时发起、问几轮**，本身就是可被利用的自由度——问得越勤不代表问得越对，只代表更会制造同意。本轮两个灵感各补一条结构：**多轮对话**把证据与同意从"点事件"变成"带共同基础状态的轨迹"，用相关证据折扣与对话修复防止"多轮 = 多样本"的错觉；**主动交互**把"何时开口"变成显式的、受 VoI/打扰成本/反操纵约束的决策，并给"沉默"保留一等公民地位。核心命题升级为 **"共同基础可追溯、多轮证据不膨胀、主动交互不操纵的证据承诺"**。

核心矛盾：
- **H29（多轮 vs 独立性）**：多轮对话增加了信息，却破坏了统计独立性——同一操作者、同一会话、同一提问框架下的多次确认高度相关；把轮次当独立样本会系统性高估置信（"问了五遍" ≠ "五个证据"），引导式提问还会污染证据本身。
- **H30（主动 vs 操纵/打扰）**：主动发问能在恰当时刻降低不确定性，但"何时问、问什么、问几轮"也可被用来择时制造同意（疲劳时问、问到同意为止）；打扰有成本，"有权不被骚扰"与"必须确认"直接冲突。
- **H31（共同基础 vs 承诺可撤销）**：有效同意要求双方对关键命题有共同基础，但对话修复总是滞后——已做出的承诺可能建立在未接地的理解上；而承诺可撤销与实时控制/规划稳定性相冲突。

## 0. 直觉与动机

**灵感 1（多轮对话 → 共同基础状态机，而非聊天记录）**
直觉：人和人确认危险，不会只说一句"行"；会说"你说的是左边那块？""不是，是桥面中间那块暗的。""哦那块我上周踩过，是湿的不是冰。"——**同意不是一次输入，而是一段被共同基础撑起来的轨迹**。机器人需要的不是更长的聊天记录，而是一个显式的**共同基础状态 κ**：哪些关键命题双方已"接地"（grounded）、哪些只是"推定"（presumed，会过期）、哪些还有悬而未决的指代/问题（pending）。只有 κ 覆盖了这次承诺的**关键命题集**，人类证据才算数；"嗯/好/收到"这类 backchannel 不足以接地，必须是对具体命题的可核验确认。这把第 57 轮的橡皮章检测从"时延 + 频率"升级为"**这条证据到底接没接地**"。

**灵感 2（多轮对话 → 相关证据折扣，多轮 ≠ 多样本）**
直觉：同一个疲惫操作者在同一会话里连点三次"确认"，信息量远小于三个独立观察者在三个场景下的各一次确认。第 57 轮把每条人工证据当独立项累加，等于把"同一个问题问五遍"当成五个证据。本轮给证据账本加**来源-会话-链条**三元组与**有效样本量 n_eff**：同链证据按 ρ_chain^k 衰减，n_eff=(Σw)²/Σw²，引导式提问的证据打折。于是多轮对话有两种截然不同的用途：**增加独立来源**（有价值）与**重复同一来源**（饱和无价值）——系统必须能区分二者，否则多轮只会加速虚假信心。

**灵感 3（主动交互 → VoI/打扰/自主三元权衡，沉默是一等公民）**
直觉：第 57 轮的探询是"机器人内部想不想探"，人类侧基本被动应答。但真实交互里，"该不该开口"是独立决策：一次主动提醒可能省掉一次不可逆接触，也可能只是打扰。本轮把主动交互形式化为 `a∈{silent,notify,ask,confirm,warn,volunteer,refuse}` 的选择，目标 = VoI（风险加权的不确定性下降）− λ_i·打扰成本 − λ_a·自主性成本；再加两条硬约束：**打扰率上限**（有权不被骚扰）与**反操纵屏障**（真实安全不变时，主动行为不得抬高同意概率——不能"择时催同意"）。**沉默永远可行**，因此主动交互不会成为新的安全漏洞，只会是"用打扰换安全"的可选交易。

**灵感 4（对话修复 → 承诺撤销阶梯，而非覆水难收）**
直觉：多轮对话最有价值的产物不是"更多确认"，而是**更早发现误解**。当后续轮次推翻一个此前"推定"甚至"已接地"的命题（"不，我说的是另一条路"），所有依赖该命题的承诺必须能被找到并处置。本轮引入**证据链依赖图**与撤销阶梯：未执行的实时撤销、已执行可逆的补偿、已不可逆的则**污染证书并触发审计**。这把第 57 轮"事后证伪回溯降权历史证据"从"降权"推进到"**撤销/补偿具体承诺**"。

**灵感 5（四机制合流 → 证据门从五类到六类，交互从单轮到有界轨迹）**
直觉：EV-dialog（多轮接地的人类 attestation）作为第六类证据，但**只能替代人类佐证层，永不替代不可逆接触所需的物理证据**；且必须挂 J_d 证书（共同基础快照 + 接地状态 + 修复账本 + 主动交互日志 + n_eff）。击穿安全需要：元先验错 ∧ OOD 漏检 ∧ 跨模态不一致 ∧ 无裕度 ∧ 对话未接地 ∧ 主动交互也没问到点上 ∧ 人也错——纵深从五层到七层。但对话轮次、主动打扰次数、修复重试次数全部有界，PCE++ 仍在有限预算内终止。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（对话共同基础状态 DCG）** 对话状态 d_t=(κ_t,π_t,σ_t,β_t)：κ_t 为共同基础（已接地命题集），π_t 为待决集（未答问题、未消解指代、未接地声明），σ_t 为参与者模型（机器人对操作者已知/所需/所指的估计），β_t=(B_turn,B_int) 为轮次与打扰预算。接地算子：给定机器人行为 a_t 与人类应答 u_t，
κ_{t+1}=κ_t ∪ {p∈Crit(a_t) : g(p,a_t,u_t)≥θ_g}，
其中 g 要求"针对命题 p 的可核验确认或修复无异议"，backchannel 记 g<θ_g。三值接地状态 gr(p)∈{grounded,presumed,ungrounded}，presumed 有寿命 τ_pres，过期退回 ungrounded。**关键命题集** Crit(c) 为承诺 c 的安全性所依赖的命题；仅当 Crit(c)⊆κ_t 时人类证据可进入证据门（与第 57 轮 EV-human 正交）。

**定义 140（多轮证据账本 MTE 与有效样本量）** 证据项 e_i 带溯源 (src_i,sess_i,chain_i) 与引导标记 ℓ_i。权重
w_i = w_0(src_i)·ρ_chain^{depth(chain_i)}·(1−λ_lead·ℓ_i)·decay(age_i)，
同会话同链第 k 次确认额外乘 ρ_same^{k−1}。有效样本量 n_eff=(Σ_i w_i)²/Σ_i w_i²（Kish）。独立佐证要求 src 与 chain 均不同；总证据强度用凹函数 f(n_eff) 而非 Σw_i 结算。结论：重复确认饱和、引导提问折价、跨来源才近似线性增益。

**定义 141（主动交互策略 PIP）** 每决策点选 a∈𝒜={silent,notify,ask,confirm,warn,volunteer,refuse}：
a\* = argmax_a [ VoI(a) − λ_i·Cost_int(a) − λ_a·R_auto(a) ]
s.t. **(C1)** 打扰率 ≤ rate_max（有权不被骚扰）；**(C2)** 反操纵屏障：若真实安全估计不变，则 a 对 P(consent) 的期望因果效应必须 ≤0（不得择时/择框架抬高同意）；**(C3)** 内容诚实：消息是当前证据的可靠摘要（无选择性呈现，KL(P_h^after‖P_cal) 不因 a 增大）；**(C4)** silent 永远可行，拒绝发问不构成不安全。VoI(a) 用第 57 轮元后验的悲观估计；Cost_int 与 R_auto 由 PTM 的 vig/auth 调制（疲劳者打扰成本更高、授权越低越保守）。

**定义 142（对话修复与承诺撤销 DRR）** 修复事件：后续轮次使命题 p 从 grounded/presumed 变为被否定。依赖集 D(p)={c : p∈chain_evidence(c)}（由 MTE 溯源图给出）。撤销阶梯：未执行 ⇒ 立即撤销并重入对话；已执行可逆 ⇒ 补偿动作 + 更新 𝓜；已执行不可逆 ⇒ 证书 J_d/J_p 标记 tainted、写入审计、触发同类区域回溯复检。**无静默承诺**：每条承诺的证据链必须可重建，否则不得承诺（可靠溯源性作为承诺前提）。

**定义 143（对话证据门与证书 DSE/J_d）** 证据类新增 EV-dialog（多轮接地人类 attestation）。准入：gr(Crit(c))=grounded 全覆盖；非引导（ℓ=0 或已修复）；n_eff≥n_min；无未决修复（π_t∩Crit(c)=∅）；仅可替代 EV-human 佐证层，**永不替代不可逆接触的 EV-probe\*/EV-margin**。证书 J_d=(dialogue_log, κ 快照, gr 向量, repair_ledger, initiative_log(VoI/Cost/act), n_eff, consent_turn, manipulation_audit)，与 J_p 合并校验。

**定义 144（PCE++ 有界对话控制器）** 在 PCE+ 每个检查点，承诺前运行有界对话控制：①计算关键命题缺口 Crit(c)\κ_t 与跨模态分歧 D(r)；②若缺口非空或 D(r)>θ_D，用 PIP 选主动行为（受 β_t 约束）；③更新 DCG 与 MTE，重估证据门；④承诺 ⇔ g≠halt ∧ FSE 过 ∧ DSE 过 ∧ Crit(c)⊆κ_t；⑤修复触发 ⇒ DRR；⑥轮次/打扰/修复预算耗尽 ⇒ 绕行/降档/L2 协商/安全停。沉默与安全停始终可达，故不引入无界对话。

## 2. 关键算法伪代码（完整版见产物区）

```python
def dialogue_update(d, a, u, evidence):            # IP-139/140
    for p in crit_props(a):
        g = grounding_evidence(p, a, u)            # backchannel -> 0
        d.kappa[p] = 'grounded' if g >= theta_g else ('presumed' if g > 0 else 'ungrounded')
    for e in evidence:
        e.w = provenance_weight(e)                  # src/session/chain/leading/age
        d.ledger.append(e)
    d.n_eff = kish(sum(e.w for e in d.ledger), sum(e.w**2 for e in d.ledger))
    return d

def choose_initiative(d, c, M, persona):            # IP-141
    best, best_u = 'silent', 0.0
    for a in ['silent','notify','ask','confirm','warn','volunteer','refuse']:
        if not anti_manipulation_ok(a, c, M):       # C2/C3
            continue
        u = voi_pessimistic(a, M) - lam_i*interrupt_cost(a, persona) - lam_a*autonomy_cost(a)
        if rate_ok(persona) and u > best_u:
            best, best_u = a, u
    return best                                      # silent 永远可行

def repair_and_revoke(p, d, commits):               # IP-142
    d.kappa[p] = 'ungrounded'
    for c in dependents(p, d.ledger):
        if not c.executed:      c.revoked = True
        elif c.reversible:      compensate(c)
        else:                   taint(c.cert); audit.flag(c, p)
    return d, commits

def dse_gate(c, d, M):                              # IP-143
    if not crit_covered(c, d.kappa):   return 'ungrounded_critical'
    if d.pending_repair(c):            return 'repair_open'
    if guided(d.ledger, c) and d.n_eff < n_min: return 'correlated_or_leading'
    if c.irreversible and uses_only_dialog(c): return 'dialog_on_irreversible'
    return 'ok'                                     # 仅补充 EV-human 佐证层
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| DCG | O(\|Crit\|) / 轮 | O(\|κ\|+\|π\|) | 接地漏检 ≤δ_g、presumed 过期有效 |
| MTE | O(\|E\|) / 更新 | O(\|E\|·d_e) | 溯源完备、ρ 折扣诚实、n_eff 不高估 |
| PIP | O(\|𝒜\|·C_VOI) / 决策 | O(\|𝒜\|) | 反操纵屏障、打扰率上限、silent 可达 |
| DRR | O(\|D(p)\|·log\|C\|) | O(\|C\|+\|E\|) | 依赖图完备、无静默承诺 |
| DSE | O(\|Crit\|+\|E\|) | O(\|E\|) | 仅补充人类佐证、不可逆硬禁令 |
| PCE++ | O(\|CP\|·(k_p+k_c)(C_VOI+d_φ) + \|CP\|·B_turn·\|𝒜\|·C_VOI) | O(\|V\|+\|σ\|+\|E\|) | 轮次/打扰/修复有界终止 |

**正确性定理（CIGS, Conversational Initiative Grounded Soundness）** 在 A22–A40 上新增：**(A41)** 接地算子对关键命题漏接地率 ≤δ_g，presumed 过期机制有效；**(A42)** MTE 溯源与相关折扣诚实（ρ_chain/ρ_same 有下界，n_eff 高估 ≤δ_eff）；**(A43)** 反操纵屏障成立（安全不变时主动行为对同意的因果效应 ≤0）；**(A44)** DRR 依赖图完备（每条承诺证据链可重建）。则：
(i) **多轮不膨胀**：n 轮同源确认的等效证据 ≤ f(n_eff)，n_eff 有界，承诺失效率不随轮次单调上升；
(ii) **主动交互单调**：主动行为只能经"更准的信念（含加宽）"或"更保守的动作"影响系统，沉默不升险；
(iii) **修复一致性**：修复后所有依赖承诺被撤销/补偿/污染，无"覆水难收的静默错误"；
(iv) **终止性**：对话轮次、打扰次数、修复次数均有界，PCE++ 有限步终止于 {承诺, 绕行, L2 协商, 安全停}。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 假共同基础（都"确认"了却理解不同） | 高 | 三值接地 + 关键命题显式化 + 反例复述探针 |
| 多轮证据仍被高估 | 高 | n_eff 保守下界 + 来源多样性硬要求 + 引导折价 |
| 反操纵约束不可操作或过严 | 中高 | 可审计的操纵定义 + silent 默认 + 仅在 L2 前主动 |
| 对话拖慢节拍 / 打扰疲劳 | 中 | 打扰预算 + 会话自适应 + 超时保守停 |
| DRR 依赖图维护成本 | 中低 | 有限链长 + 证书化溯源 + 后台审计 |

## 6. 本轮最大风险

**一句话**：本轮把"理解是否对齐"的判定权交给了接地检测器，而它的假接地（把"推定"误判为"已接地"）会在多轮重复中被放大成"双方都反复确认过"的合法性幻觉——主动交互越高效，越可能在对齐尚未真正发生时，更快地把一个误解推向不可逆承诺。

# 第 58 轮产物 · 创新点清单 v34：DialogInitiative-CC（多轮共同基础×主动交互×相关证据折扣，DCG×MTE×PIP×DRR×DSE×PCE++）

> 承接第 57 轮 IP-133~138（MFSL/XMC/PTM/MXI/FSE/PCE+）与第 56 轮 IP-127~132（SMM/PCE/BVK/ISE/TAF/MEC）。本轮把证据承诺的时间结构补上：**证据与同意不再是一次性事件，而是带共同基础状态的对话轨迹**；把"何时开口"从隐式等待变成显式、受 VoI/打扰/反操纵约束的主动决策；并用相关证据折扣使"多轮"不再等价于"多样本"。
> IP 编号：IP-139~IP-144（共 6 个），升级 IP-137/138 以纳入对话证据门与有界对话控制。

## 0. 核心 IP 设计

| 编号 | 名称 | 类型 | 关键改进 |
|---|---|---|---|
| IP-139 | DCG Dialogue Common Ground | 新增 | κ/π/σ/β 对话状态、接地算子、三值接地、关键命题集 Crit(c) |

## 2. 关键算法伪代码

### IP-139 DCG（对话共同基础状态机）

```python
def dcg_track(d, a, u, turn_budget):
    # a: 机器人行为；u: 人类应答；只对"关键命题"要求接地
    for p in crit_props(a):
        g = grounding_evidence(p, a, u)          # backchannel("嗯/好") -> 0
        if g >= theta_g:
            d.kappa[p] = ('grounded', t_now)
        elif g > 0:
            d.kappa[p] = ('presumed', t_now)
        else:
            d.kappa[p] = ('ungrounded', t_now)
            d.pending.add(p)
    for p, (st, ts) in d.kappa.items():          # presumed 过期退回
        if st == 'presumed' and t_now - ts > tau_pres:
            d.kappa[p] = ('ungrounded', ts); d.pending.add(p)
    d.beta.turn -= 1
    return d

def crit_covered(c, kappa):
    return all(kappa.get(p, ('ungrounded',))[0] == 'grounded' for p in Crit(c))
```

### IP-140 MTE（多轮证据账本与有效样本量）

```python
def evidence_weight(e, ledger, rho_chain, rho_same, lam_lead):
    depth = chain_depth(e, ledger)
    k_same = sum(1 for x in ledger if x.src == e.src and x.sess == e.sess and x.chain == e.chain)
    w = e.w0 * (rho_chain ** depth) * (rho_same ** max(0, k_same - 1))
    w *= (1.0 - lam_lead * e.leading)
    w *= decay(age(e))
    return w

def ledger_update(d, e):
    e.w = evidence_weight(e, d.ledger, RHO_CHAIN, RHO_SAME, LAM_LEAD)
    d.ledger.append(e)
    sw  = sum(x.w for x in d.ledger)
    sw2 = sum(x.w ** 2 for x in d.ledger)
    d.n_eff = (sw ** 2) / sw2 if sw2 > 0 else 0.0
    return d

def corroboration_strength(d):                   # 凹结算：重复确认会饱和
    return f_concave(d.n_eff)                    # f' > 0, f'' < 0

def independent_pair(e1, e2):                     # 独立佐证须来源与链均不同
    return e1.src != e2.src and e1.chain != e2.chain
```

### IP-141 PIP（主动交互策略：VoI / 打扰 / 反操纵）

```python
ACTS = ['silent', 'notify', 'ask', 'confirm', 'warn', 'volunteer', 'refuse']

def choose_initiative(d, c, M, persona, t_now):
    best, best_u = 'silent', 0.0                  # 沉默是默认且永远可行
    for a in ACTS:
        if a == 'silent':
            continue
        if not rate_ok(persona, t_now, rate_max=persona.rate_max):  # C1
            break
        if not anti_manipulation_ok(a, c, M):     # C2: 安全不变时不得抬高同意
            continue
        if not content_honest(a, M, persona):     # C3: 消息为证据的可靠摘要
            continue
        u = voi_pessimistic(a, M) \
            - lam_i * interrupt_cost(a, persona, d.beta) \
            - lam_a * autonomy_cost(a, persona)
        if u > best_u:
            best, best_u = a, u
    return best, best_u

def anti_manipulation_ok(a, c, M):
    # 因果效应：固定证据下，行为对 P(consent) 的提升必须伴随真实安全提升
    d_consent = causal_delta_consent(a, c, M)
    d_safety  = causal_delta_safety(a, c, M)
    if abs(d_safety) < EPS_SAFE:
        return d_consent <= 0.0                   # 不得择时催同意
    return (d_consent <= 0.0) or (d_safety > 0.0 and abs(d_consent) <= abs(d_safety))
```

### IP-142 DRR（对话修复与承诺撤销阶梯）

def repair_and_revoke(p, d, commits):
    d.kappa[p] = ('ungrounded', t_now)
    d.repair_log.append((p, t_now))
    for c in dependents(p, d.ledger):             # 由 MTE 溯源图反查

def no_silent_commitment(c, d):

def dialogue_evidence_gate(c, d, M):
    if not crit_covered(c, d.kappa):                 return ('reject', 'ungrounded_critical')
    if d.pending_repair(c):                          return ('reject', 'repair_open')
    if not no_silent_commitment(c, d):               return ('reject', 'unreconstructible_chain')

### IP-144 PCE++（探-诺-演++：有界对话控制器）

```python
def probe_commit_evolve_plus_plus(x0, M, task, budget, consent, personas):
    route, sched, log = plan_on_map(M, task, risk_model), [], []
    d = init_dialogue_state(personas.active)          # IP-139
    for cp in route.checkpoints:
        inf = meta_few_shot_infer(M, cp.region, M.obs[cp.region], meta)   # IP-133
        M.b[cp.region] = inf.post if inf.cls == 'ID' else worst_in(inf.belt)
        sigma = foothold_schedule(x0, cp, M); R = schedule_risk(sigma, M)
        while select_gait(R) == 'halt' and budget.probes_left > 0:        # IP-138 继承
            cands = admissible_probes(cp, M, F_abs)
            if not cands: break
            p = argmax(cands, key=lambda q: voi_meta_pessimistic(q, M, inf) - cost(q))
            if voi_meta_pessimistic(p, M, inf) < theta_voi: break
            M, _, D = xmodal_fuse(M, cp.region, execute_probe(p, cap=F_abs))  # IP-134
            sigma = reselect_footholds(x0, cp, M); R = schedule_risk(sigma, M)
            budget.spend(p)
        g = select_gait(R); lv = contact_level(cp)
        c = core_contact(cp)
        while d.beta.turn > 0 and d.beta.interrupt > 0:                  # 有界对话
            gap = Crit(c) - set(p for p, (st, _) in d.kappa.items() if st == 'grounded')
            if not gap and D <= theta_D and dialogue_evidence_gate(c, d, M)[0] == 'ok':
                break
            a, u_a = choose_initiative(d, c, M, personas.active, t_now)
            if a == 'silent':
                break
            resp = execute_initiative(a, c, M, personas.active)
            d = dcg_track(d, a, resp, budget.dialogue_turn)
            d = ledger_update(d, parse_evidence(resp, a))
            d.beta.interrupt -= 1 if a not in ('silent',) else 0
            if resp.repair:                                         # IP-142
                d, sched = repair_and_revoke(resp.repaired_prop, d, sched)
            if d.beta.repair <= 0: break
        ev = tag_evidence_p(sigma, M, lv)
        if g != 'halt' and few_shot_evidence_gate(c, M, personas, ood_reg)[0] == 'ok' \
           and dialogue_evidence_gate(c, d, M)[0] == 'ok':
            sched.append(commit(sigma, g)); log.append((ev, Jd_of(d))); continue
        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, M)) != 'halt': route = alt; continue
        return negotiate_or_stop(cp, M, sigma, R, consent,
                                 tau_int=tau_int(personas.active.auth))  # 超时保守停
    return sched, log, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DCG | O(\|Crit\|)/轮 | O(\|κ\|+\|π\|) | 漏接地 ≤δ_g、presumed 过期有效（A41） |
| MTE | O(\|E\|)/更新 | O(\|E\|·d_e) | 溯源完备、ρ 折扣诚实、n_eff 不高估（A42） |
| PIP | O(\|𝒜\|·C_VOI)/决策 | O(\|𝒜\|) | 反操纵屏障、打扰率上限、silent 可达（A43） |
| DRR | O(\|D(p)\|·log\|C\|) | O(\|C\|+\|E\|) | 依赖图完备、无静默承诺（A44） |
| DSE | O(\|Crit\|+\|E\|) | O(\|E\|) | 仅补人类佐证、不可逆硬禁令 |
| PCE++ | O(\|CP\|·(k_p+k_c)(C_VOI+d_φ)+\|CP\|·B_turn·\|𝒜\|·C_VOI) | O(\|V\|+\|σ\|+\|E\|) | 三重预算有界终止、四态完备 |

**正确性定理（CIGS：Conversational Initiative Grounded Soundness）**
在 A22–A40 成立的基础上新增：**(A41)** 接地算子对关键命题漏接地率 ≤δ_g，presumed 过期机制有效；**(A42)** MTE 溯源与相关折扣诚实（ρ_chain/ρ_same 有下界，n_eff 高估 ≤δ_eff）；**(A43)** 反操纵屏障成立（真实安全不变时主动行为对 P(consent) 的因果效应 ≤0）；**(A44)** DRR 依赖图完备（每条承诺证据链可重建）。则：

1. **多轮不膨胀**：n 次同源同链确认的等效证据 ≤ f(n_eff)，n_eff 有界且随重复饱和；承诺失效率不随对话轮次单调上升。多轮唯一的安全增益来自独立来源（distinct src ∧ distinct chain）。
2. **主动交互单调**：主动行为只经 (a) 更准/更宽的信念或 (b) 更保守的动作参数（打扰率上限、τ_int↓、佐证数↑）影响系统；silent 为默认且永远可达，故不存在"必须开口才安全"的升险路径。
3. **修复一致性**：修复后所有依赖该命题的承诺被撤销（未执行）/补偿（可逆）/污染证书并审计（不可逆），不存在"覆水难收的静默错误"。
4. **终止性**：每检查点对话轮次 ≤B_turn、打扰 ≤B_int、修复 ≤B_repair，PCE++ 在有限步内终止于 {承诺, 绕行, L2 协商, 安全停}。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                   + δ_g·1[EV-dialog] + δ_eff·1[n_eff>N_MIN])
             − P(𝓜 陈旧未检出) − P(护盾回退失败) − P(对话/打扰预算耗尽 ∧ 安全停失效)
```

关键：**对话给对齐、折扣给诚实、主动给时机、修复给可撤销**——四者都只能经"信念更准"或"动作更保守"两个安全通道起作用，且 EV-dialog 永不越过物理证据进入不可逆层。

## 6. 本轮最大风险

**一句话**：本轮把"理解是否对齐"的判定权交给了接地检测器，而它的假接地（把"推定"误判为"已接地"）会在多轮重复中被放大成"双方都反复确认过"的合法性幻觉——主动交互越高效，越可能在对齐尚未真正发生时，更快地把一个误解推向不可逆承诺。
