# 第 1 轮（UniBot 线 · 新灵感循环第 1 轮；本轮灵感：「谐波减速器」×「多视角视觉」）

> **基线继承**：UniBot-SAGE v1（定义 U1–U12、引理 L1–L7、实验 E601–E618）。本轮不推倒 v1，而是把 v1 的“抓握隐变量”升级为“跨模态交互证书”；新增定义 U13–U24、引理 L8–L14、实验 E619–E636、创新点 IP-09–IP-13。合规纪律不变：单 checkpoint、单 API、不读评测侧私有信息、不做任务硬编码。
>
> **数据纪律**：官方事实与接口口径继承 v1（32 任务、4 路 480×640 相机、单 `get_action` API、N 端口）；榜单数字来自 `unibot_leaderboard_20261102.json`（teaser/占位表，检索日期 2026-11-17），只作结构参考，不作调参依据。

## 0. 一句话
把“抓住了吗”从“腕部相机 + 1 维夹爪标量”的单一证据，升级为**谐波减速器的柔顺残差（隐式接触/负载传感器）× 四路相机的多视角几何（隐式 6D 位姿/滑移传感器）**的**跨模态交互证书**；两条证据链一致时才高置信判定，不一致时用一个低风险“探针动作”去测量而不是猜。

## 1. 直觉：两个灵感各自击中了 v1 的哪根软肋

### 灵感 1 ·「谐波减速器」→ 执行器不是刚性执行器，而是一条被忽略的力/接触证据链
**直觉**：v1 把关节当作“命令下去就到位”的刚性执行器，把抓握判断几乎全压在视觉上。但 G1 的关节里有谐波减速器（若个别关节为行星/摆线传动，则按对应传动模型替换参数）：柔轮（flexspline）是一个薄壁弹性体，波发生器让它产生可控弹性变形。它带来三件事：
1. **有限柔顺度**：关节不是刚性的，命令位置与实际位置之间存在与负载相关的偏差；
2. **滞回与传动误差**：偏差不是简单的弹簧，历史路径、温度、磨损都会改变它；
3. **零回程但非零柔顺**：没有传统齿轮的反向间隙，但柔轮本身存储弹性能。

这三件事在 v1 里被当成“干扰”，但在本轮的视角里，它们是**免费的传感器**：当夹爪接触物体、抬起物体、物体滑移、或插入时发生卡阻，外部力矩会通过柔轮偏转和关节跟踪误差留下痕迹。接口没有触觉、没有六维力传感器，但**执行器本身就是一根弹簧秤**。更准确地说：谐波残差不是替代触觉，而是提供一条**与视觉独立的接触变化证据链**——它的强项是“变化检测”（接触/滑移/卡阻/负载突变），而不是“绝对力标定”。

**第一性原理**：关节动力学 `M(q)q̈ + C(q,q̇)q̇ + g(q) = τ_act + J^T w_c`。若我们能估计 `τ_act`（由命令 + 执行器模型），就能用广义动量观测器从 `q, q̇` 反解外部力矩 `J^T w_c`。谐波柔顺度把 `τ_act` 与 `q` 的关系变成一个有记忆的非线性弹簧；这既增加了模型误差，也**放大了接触力矩在位置残差中的可观测性**。关键不是“消除柔顺”，而是“把柔顺建模成观测通道”。

**三个可执行推论**：
- **(a) 夹爪闭合残差是最可靠的物体存在信号**：命令闭合 vs 实际开合；如果夹爪一路闭合到 0，说明没夹到；如果在宽度 `w>0` 处停住，说明夹到了。这个信号在接口里直接可得，且对未见物体比外观分类器更稳。
- **(b) 抬升/搬运时的关节外部力矩是负载与滑移的独立证据**：物体越重、夹得越松，抬升瞬间的关节力矩残差越大；若物体滑移，残差会出现特征性下降/振荡。
- **(c) 插入/旋转时的力矩残差是“卡住”的早期警报**：在 v1 最难的 Plug In Ethernet / Unlock / Open Pill Bottle 上，视觉可能被手指遮挡，但力矩残差不会。

### 灵感 2 ·「多视角视觉」→ 四路相机不是四张图，而是一台分布式 3D 量具
**直觉**：v1 把四路相机（头部双目 + 左右腕）主要当作策略输入，抓握确认只用了腕部单视图的几何贴合。但四路相机是一个**已标定（或可自标定）的多视角系统**：头部双目提供全局上下文与遮挡冗余，腕部相机提供接触近景；同一个物体、同一个夹爪在多视角下必须满足极线约束、光度一致性和刚体运动一致性。**一致性本身就是标签**：物体被夹住时，它在所有视角下都应随夹爪刚体运动；物体滑移时，物体-夹爪相对位姿会漂移；某个视角被手指挡住时，可见性掩码会告诉我们“这条证据不可用”。

**第一性原理**：多视角三角化的深度误差 `σ_z ≈ z² σ_d/(f b)`。在腕部近景（z≈0.1–0.2 m），毫米级甚至亚毫米级精度是可达的；在头部全局（z≈0.5–0.8 m），精度降到厘米级但覆盖范围大。于是可以做一个**分层量具**：头部双目负责“物体在哪、有没有被挡住、场景里还有什么”，腕部相机负责“夹爪与物体的相对位姿、接触面、滑移”。对未见物体，几何一致性（轮廓、边缘、深度、运动）比外观语义更不容易分布外失效。

**三个可执行推论**：
- **(a) 滑移检测 = 物体-夹爪相对位姿的时间导数**：刚体抓握时 `T_og` 应近似恒定；滑移时 `T_og` 漂移。这比“看物体有没有动”更直接，因为它扣除了夹爪自身的运动。
- **(b) 遮挡感知的置信度**：每个视角输出可见性掩码与几何残差；融合权重由残差和可见性决定，而不是简单平均。手指挡住腕部相机时，头部双目接管；两路都不可靠时，证书输出“不确定”而不是硬判。
- **(c) 插入对齐 = 多视角相对位姿 + 力矩残差的联合闭环**：视觉给出毫米级对齐，力矩给出接触/卡阻；两者一个管“对不对得准”，一个管“插不插得进”。

### 合成：从“抓握隐变量”到“跨模态交互证书”
v1 的核心风险是**抓握误判的不对称性**：漏判（没抓住却以为抓住）会把可救的失败变成硬失败。本轮的解不是“把视觉分类器做得更准”，而是**结构上制造两条独立证据链，并把“分歧”变成一等信号**：
- 两条链都说“抓住了” → 高置信，继续执行；
- 两条链都说“没抓住” → 高置信，触发重抓/改抓；
- 两条链**不一致** → 不猜，执行一个低风险**探针**（轻抬 2–5 mm、轻捏、轻晃、换视角重观测），用测量把不确定性打下去，再决策。

这把 v1 的“高精度低召回、尽量不干预”升级为“**该测就测、只在证据一致时下结论**”。探针有次数上限与风险预算，最坏退回 v1 的不干预开环。

**统一变量**：接触状态 `s_t = (grasp, slip, load, relative pose, contact stiffness)`；谐波通道给 `(load, contact stiffness, slip 的变化)`，多视角通道给 `(relative pose, slip 的几何)`；证书 `κ_t` 是两者的联合后验 + 一致性分歧。两者共享同一个“物体-夹爪”物理对象，因此不是两个补丁，而是一个**接触状态的双通道观测器**。

## 2. 为什么是现在：与 v1 断点和 teaser 榜的对齐

本轮在本地 `unibot_leaderboard_20261102.json`（teaser 占位表，8 模型 × 32 任务 = 256 个点）上重新做了三组分析，全部可复现：

| 分析 | 数值 | 含义 |
|---|---|---|
| 最难 6 任务 vs 最易 6 任务的平均成功率 | 21.30 vs 28.52（差 7.22） | 难度分层明显，且最难组集中在插入/旋转/细粒度摆放 |
| 手工“接触/精度相关度”评分（0–2；口径见产物 §7.5(A)）与任务均值成功率 | Spearman −0.37 | 越接触/越要精度，越难 |
| 同一评分与跨模型 headroom（best−mean） | Spearman +0.24 | 越接触/越要精度，模型间差距越大 |
| 跨模型 CV 最高的 10 个任务 | 全部属于接触或精度相关（手工标签） | 这些任务的失败模式高度模型相关，单靠堆参数收益递减 |
| 跨模型 Kendall τ | 均值 0.064（28 对） | 复现 v1：任务间准正交，专长差真实存在 |
| 每任务 oracle / top-2 混合 | 33.96 / 32.22（相对最好单模型 29.70：+4.26 / +2.52） | 复现 v1：路由与专长红利仍在 |

**解读（克制版）**：这些数字不能证明“谐波 + 多视角”一定涨点，但它们说明两件事：**(i)** 最难、跨模型分歧最大的任务，恰好是接触丰富、遮挡/精度要求高的任务；**(ii)** 这些任务的 headroom 也更大，说明“换一种观测方式”比“把同一个模型再放大”更有希望。下一轮的 E619/E621 会直接检验两条通道的物理可辨识性，而不是靠这张相关性表。

## 3. 研究问题（本轮新增 Q6–Q10）

- **Q6（谐波残差的可辨识性）**：在只暴露关节位置 + 1 维夹爪开合、可能不暴露电机侧编码器/电流的接口下，能否用指令-执行残差 + 广义动量观测器，把外部力矩估到“足以做接触/滑移变化检测”的精度？其可辨识性边界与模型误差上界是什么？
- **Q7（多视角几何的精度与鲁棒性）**：在四路相机不同步、手眼标定有漂移、腕部视角被夹爪遮挡的条件下，物体-夹爪相对位姿能否稳定到毫米级？未见物体上几何一致性的假阳性率是多少？
- **Q8（跨模态一致性的校准）**：两条证据链的误差相关吗？在正相关下，“两者都漏判”的概率上界是什么？如何把一致性分歧校准成可用的置信度，而不是过度自信？
- **Q9（探针的最优性）**：轻抬/轻捏/轻晃/换视角四类探针，在“信息增益 vs 扰动风险”下如何选？探针次数上限与成功率的关系是什么？最坏情况能否严格退回 v1？
- **Q10（谐波感知的工程语义）**：chunk 边界应该在位置空间缝合还是在 `(位置, 速度, 力矩)` 空间缝合？谐波共振/滞回对 chunk 长度与频率内容有什么约束？如何对齐官方“动作统计规律性”的可信度口径？

## 4. 设计原则（新增 P7–P10）

- **P7 执行器即传感器**：任何可观测的指令-执行残差都必须被建模成证据通道，而不是当作噪声抹掉；但只把它用于“变化检测”，不假装它是经过标定的六维力传感器。
- **P8 多视角一致性即标签**：优先使用极线/光度/刚体运动一致性这类**无标签、外观不变**的信号；外观分类器只作辅助，不作抓握证书的唯一依据。
- **P9 分歧不猜，探针测量**：两通道不一致时禁止硬判；用有风险预算、有次数上限的探针把不确定性打下去；探针失败严格退回 v1 的不干预开环。
- **P10 证书可校准、可审计**：证书必须输出校准后的置信度与分量证据（谐波残差、跨视角残差、可见性、延迟），并能导出可靠性图与审计日志；未校准的分数不得用于干预决策。

## 5. MVP 与退化链

**MVP = IP-09（谐波抓握探针）+ IP-10（多视角抓握融合）+ IP-11（跨模态证书 + 探针）+ v1 的 IP-02/IP-03 + 通用 VLA 基线**。

**退化链（任一环节不可用 ⇒ 行为回退，不漂移）**：
- D0 完整 HARMONIC；
- D1 探针不可用 ⇒ 只做“一致才判、不一致不干预”的被动证书；
- D2 多视角不可用 ⇒ 退到谐波通道 + v1 腕部单视图；
- D3 谐波残差不可辨识 ⇒ 退到多视角通道 + v1 视觉抓握确认；
- D4 两通道都不可用 ⇒ 退到 v1 的高精度低召回抓握确认；
- D5 证书整体不可用 ⇒ 退到 v1 的不干预开环；
- D6 整条新链路失效 ⇒ 纯 v1 基线（永远保留一份能跑通的最小提交）。

## 6. 预期贡献（可验收）

1. **把执行器柔顺度从“干扰”变成“证据”**：给出谐波残差的可观测性分析、动量观测器实现与校准曲线，证明它在接触/滑移变化检测上优于纯视觉。
2. **给出多视角抓握/滑移的几何证书**：物体-夹爪相对位姿 + 可见性掩码 + 跨视角残差，毫米级对齐、遮挡感知、未见物体上外观不变。
3. **跨模态一致性校准**：给出两条证据链误差相关下的误判上界（Fréchet 界），把 v1 的不对称误判风险转成可量化的证书风险。
4. **探针式主动感知**：把“猜”变成“测”，给出探针的信息增益/风险预算与最坏退化保证。
5. **谐波感知的工程层**：力矩空间 chunk 缝合、共振避让、视角预算调度、可审计证书，直接对齐官方可信度口径。

## 7. 本轮最大风险（一句话）

**最大风险**：谐波残差与多视角几何可能共享同一个“物体随夹爪运动”混淆源（两者都在看同一个物体动），一旦手眼标定漂移或执行器模型误差偏大，两条“独立”证据链会**同向出错**，让跨模态证书在最需要它的未见物体/接触瞬间变得过度自信；而探针又可能扰动一个本来已经夹稳的物体，把“不确定”变成“真失败”。

## 8. 下一轮迭代计划（深化与修剪）

- **深化**：把证书从“每步二值/三值”升级为“带时序的接触状态机”（approach → contact → load → slip → insert → release），把谐波残差与多视角残差按阶段动态加权；把探针策略从贪心 VoI 升级为有限时域 POMDP。
- **修剪预案**：若 E619（谐波残差标定）与 E621（多视角精度）中任一未达标，则砍掉对应通道，只保留单通道 + v1 证书；若 E623（融合校准）显示两通道误差相关 >0.5，则禁止用“一致性”做高置信判定，退回保守的 v1 策略。
- **保留项**：IP-09 的夹爪闭合残差、IP-10 的滑移几何、IP-11 的分歧-探针逻辑在任何情况下保留（它们不依赖绝对力标定，机制正确性最强）。

## 2. 创新点详述

### IP-09 · HarmonicGraspProbe（HGP）谐波抓握探针（P0）

- **动机**：接口只给 1 维夹爪开合，无触觉、无六维力；但 G1 关节（谐波减速器方案）有有限柔顺度、滞回、零回程。外部接触/负载会通过关节跟踪误差和柔轮偏转留下痕迹。v1 把这当噪声；我们把它当**与视觉独立的证据链**。
- **建模假设**：若个别关节使用行星/摆线减速器，HGP 的“柔顺残差”仍成立，只是 `K_h/D_h/滞回` 参数不同；若关节完全刚性且无电流/力矩遥测，HGP 退化为“夹爪闭合残差 + 指令-执行残差变化检测”。
- **与 v1 的差异**：v1 的抓握确认主要靠腕部几何 + 夹爪标量 + EE 速度；HGP 增加两路物理证据：**(a) 夹爪闭合残差**（命令闭合 vs 实际开合，最可靠的物体存在信号）；**(b) 关节外部力矩残差**（广义动量观测器，检测负载/滑移/卡阻）。它不是“再训练一个分类器”，而是**基于动力学模型的观测器 + 小校准头**。
- **技术可行性**：中–高。①夹爪闭合残差直接可算，不需要额外遥测；②关节外部力矩需要 `τ_act` 模型，可用官方 32 数据集离线辨识等效 PD/摩擦参数（`τ_act ≈ K_p(a−q) − K_d q̇ + τ_ff`）；若接口不暴露关节速度，用相邻观测差分 + 低通估计；③若辨识残差过大，退化为“只用变化检测”，不报绝对力；④谐波滞回用 Bouc–Wen/Preisach-lite 建模，温度/磨损作为慢变量在线更新。
- **所需资源**：数据 = 官方 32 数据集（动作/状态对）；算力 = 单卡数小时辨识 + 小校准头；接口 = 纯策略内部逻辑，不新增字段。
- **落地步骤**：①离线辨识 `τ_act` 等效模型与摩擦；②实现广义动量观测器，估计 `τ̂_ext`；③实现夹爪闭合残差与物体刚度估计；④用实验室六维力/力矩传感器做一次真机标定（E619）；⑤在官方数据上做离线 AUROC（E620）；⑥定义输出 `(P_obj, f̂_load, τ̂_ext, P_slip)` 并交给 IP-11。
- **风险**：①`τ_act` 模型误差大 ⇒ 绝对力矩不可信；缓解：只做变化检测、用相对残差、退化到夹爪残差；②谐波滞回导致重复性差 ⇒ 用滞回状态与温度补偿；③不同关节/负载下参数漂移 ⇒ 在线慢更新 + 置信度门控。

### IP-10 · MultiViewGraspFusion（MVGF）多视角抓握融合（P0）

- **动机**：四路相机（头 stereo×2 + 左右腕）是一个多视角系统。v1 只用腕部单视图做几何贴合；我们利用**跨视角一致性**：极线约束、光度一致性、刚体运动一致性。物体被夹住时，它在所有视角下都应随夹爪刚体运动；滑移时，物体-夹爪相对位姿漂移；遮挡时，可见性掩码标记证据不可用。
- **与 v1 的差异**：v1 的抓握确认是“单视图 + 分类器”；MVGF 是“多视图几何 + 运动一致性”，输出带协方差的 6D 相对位姿、滑移速度、可见性掩码与跨视角残差。它对外观不敏感，因此对未见物体更稳。
- **技术可行性**：中–高。①头部双目在硬件上构成立体对，外参可由官方数据自标定/核验；②腕部相机是 eye-in-hand，需要手眼外参（可从官方数据自标定）；③用轻量特征/深度 + 多视图重投影优化；④对未知物体用模板无关的轮廓/边缘/深度一致性，而不是外观模板；⑤用可见性掩码处理夹爪自遮挡。
- **所需资源**：数据 = 官方 32 数据集（4 路图像 + 关节/EE）；算力 = 轻量编码器 + 优化，在线 6–15 ms；接口 = `obs_delta_indices` 请求所需视角，`image_resize` 降分辨率。
- **落地步骤**：①从官方数据估计头/腕相机外参与手眼外参，验证重投影误差；②实现跨视角光度/几何残差与可见性掩码；③实现物体-夹爪相对位姿与滑移估计；④在官方数据上做遮挡/滑移离线评估（E621/E622）；⑤输出 `(T_og, v_slip, Σ, c_uv, m_vis)` 给 IP-11。
- **风险**：①外参漂移 ⇒ 在线自标定 + 不确定度膨胀；②腕部视角被夹爪挡住 ⇒ 头部双目接管，双路都差则输出“不确定”；③不同步 ⇒ 用时间戳 + 本体运动补偿；④未知物体几何退化 ⇒ 轮廓/边缘 + 多视角约束，不用外观模板。

### IP-11 · CrossModalGraspCertificate（CMGC）跨模态证书 + 探针（P0）

- **动机**：v1 的最大风险是抓握误判的不对称性：漏判（没抓住却以为抓住）会把可救的失败变成硬失败。单通道再准也无法消除这个风险；两条独立证据链 + 一致性分歧 + 主动探针，才能把风险变成可测量量。
- **与 v1 的差异**：v1 是“高精度低召回、尽量不干预”的二值门控；CMGC 是**三值证书** `{GRASPED, NOT_GRASPED, UNCERTAIN}`：一致才判，分歧则用探针测量；探针有次数上限（≤2/episode）和风险预算，最坏退回 v1。
- **技术可行性**：高。证书融合是校准 + 决策论，不需要大模型；探针是四类低幅动作，可由同一个策略执行；所有分量都可审计。
- **所需资源**：算力 = 极小（融合/校准 <1 ms）；数据 = 官方数据 + 少量真机探针试验；接口 = 无新增字段。
- **落地步骤**：①在官方数据上拟合两通道的联合校准（温度缩放/等渗回归）；②实现三值决策与代价敏感阈值；③实现四类探针与 VoI 选择；④真机 A/B（E623/E624）；⑤导出可靠性图与审计日志。
- **风险**：①两通道误差正相关 ⇒ “一致”不等于独立，证书过度自信；缓解：估计相关 ρ，ρ>0.5 时禁用高置信判定；②探针扰动已夹稳物体 ⇒ 小幅、限力矩、限次数、失败即回退；③校准漂移 ⇒ 每 episode 自校准 + 定期重标定。

### IP-12 · HarmonicAwareChunkStitch（HACS）谐波感知 chunk 缝合（P1）

- **动机**：v1 的 IP-03 在位置空间做 chunk 缝合；但谐波柔顺度让“位置连续”不等于“力矩连续”。chunk 边界的位置跳变会在柔轮上产生力矩尖峰，尤其抓握/插入瞬间最易失败；谐波共振还会被高频 chunk 切换激励。
- **与 v1 的差异**：HACS 在 `(q, q̇, τ̂_ext)` 空间缝合：首动作满足位置 C0、速度 C1 近似、力矩速率限幅、频谱避让 `ω_res`；chunk 长度仍按相位自适应（抓握/对齐短、搬运长），但切换受最小驻留时间与力矩预算约束。
- **技术可行性**：中–高。需要 `τ̂_ext`（IP-09）与执行器模型；若不可用，退回 v1 的位置缝合（默认关）。
- **所需资源**：算力 = 极小；数据 = 官方数据回放做连续性自检；接口 = 无。
- **落地步骤**：①用官方 client 复刻评测器 chunk 语义（v1 步骤①）；②实现力矩速率限幅与共振陷波；③实现相位自适应 chunk + 最小驻留；④真机 A/B（E626/E627）；⑤审计看板导出边界力矩/jerk。
- **风险**：①评测端自带平滑 ⇒ 叠加抖动；缓解：默认关，真机 A/B 决定；②短 chunk 增加调用次数 ⇒ 延迟压力；用 VBS/降分辨率对冲；③过度平滑降低成功率 ⇒ 只作用在力矩残差，不改均值。

### IP-13 · ViewBudgetScheduler（VBS）视角预算调度（P1）

- **动机**：4 路 480×640 全量跑小 CNN 约 12–20 ms，策略主干 35–70 ms，融合 3–5 ms；p99 105 ms 预算下不能“全都要”。需要按相位选视角与分辨率，精度不够就降级，而不是超时。
- **与 v1 的差异**：v1 的 `image_resize` 是静态的；VBS 是**相位相关的动态调度**：抓握/对齐用双腕 + 头部低分辨率；搬运用头部双目；插入用双腕高分辨率。调度目标是在延迟预算内最大化证书置信度（互信息），而不是固定分辨率。
- **技术可行性**：高（工程 + 小优化）。延迟模型可离线标定；视角选择是子模最大化：基数约束下贪心有 (1−1/e) 保证，预算约束下需用修正贪心/部分枚举。
- **所需资源**：算力 = 极小；接口 = `metadata` 的 `image_resize`/`obs_delta_indices` 可动态声明（需按官方语义验证）；数据 = 延迟标定。
- **落地步骤**：①标定每路/每分辨率的延迟分布；②定义相位→候选视角集；③实现在线选择与降级；④N 端口并发压测（E628/E635）。
- **风险**：①动态 `image_resize` 是否被评测端允许需验证；②视角切换引入时序不一致 ⇒ 固定最小驻留；③降级后证书置信度下降 ⇒ 不确定时禁止干预。

## 3. 符号与定义（U13–U24）

| 符号 | 含义 |
|---|---|
| `h_t` | 谐波执行器状态 `(θ_flex, τ_h, θ̇_flex, T, w)` |
| `τ̂_ext,t` | 广义动量观测器估计的外部关节力矩 |
| `f̂_load,t` | 沿负载方向的等效力估计 |
| `r_g,t` | 夹爪闭合残差（命令开合 vs 实际开合） |
| `O_t` | 多视角观测集 `{(I_t^v, K_v, T_v^b, m_t^v)}` |
| `c_t^{uv}` | 视角 u,v 的跨视角一致性分数 |
| `x_t` | 多视角几何状态 `(T_og, v_slip, Σ)` |
| `κ_t` | 跨模态交互证书 `(P^g, P^s, f̂, δ, σ)` |
| `δ_t` | 两通道后验的分歧度 |
| `d_t` | 三值决策 `{G, N, U}` |
| `Π_p` | 探针原语集 `{LIFT, SQUEEZE, SHAKE, REOBSERVE}` |
| `Ψ_h` | 谐波感知 chunk 缝合算子 |
| `B_t` | 视角预算调度 `(V_t, r_t)` |

**定义 U13（谐波执行器状态）** `h_t = (θ_flex,t, τ_h,t, θ̇_flex,t, T_t, w_t)`。若电机侧角度 `θ_m` 可观测，则 `θ_flex = θ_m/N − q`，`τ_h = K_h(T,w) θ_flex + D_h θ̇_flex + H_h[θ_flex]`，其中 `H_h` 为滞回算子（Bouc–Wen/Preisach-lite）；若 `θ_m` 不可观测，则 `h_t` 为潜变量，由 U14 估计。

**定义 U14（外部力矩观测器与夹爪残差）** 广义动量 `p_t = M(q_t) q̇_t`；观测器
`r_t = K_o [ p_t − ∫_0^t (τ_act + C(q,q̇)^T q̇ − g(q) + r) dσ ]`，`τ̂_ext,t = r_t`。
接触力旋量 `ŵ_t = J(q_t)^{−T} τ̂_ext,t`；负载投影 `f̂_load,t = b_g^T ŵ_t`。
执行器模型 `τ_act,t = f_θ(a_{t−1}, q_t, q̇_t) + η_t`，`‖η_t‖ ≤ η_max`。
夹爪残差 `r_g,t = a_{g,t−1} − q_{g,t}`，物体存在概率 `P_obj,t = σ(f_ψ(r_g,t, q_{g,t}, q̇_{g,t}))`。

**定义 U15（多视角观测集）** `O_t = {(I_t^v, K_v, T_v^b, m_t^v)}_{v∈V}`，`V = {HL, HR, WL, WR}`；`T_v^b` 为相机到机器人基座的外参（头部）或手眼外参（腕部）；`m_t^v` 为可见性掩码。

**定义 U16（跨视角一致性）** 对视角对 `(u,v)` 与像素 `x`（深度 `d`）：
`x' = π_v(T_v^b (T_b^u π_u^{−1}(x,d)))`，
`ρ_t^{uv}(x) = ‖I_t^u(x) − I_t^v(x')‖`，
`c_t^{uv} = exp(−(1/|Ω|)∫_Ω m_t^u(x) m_t^v(x') ρ_t^{uv}(x) / σ_ρ)`。
几何残差 `g_t^{uv} = ‖x' − x̂'‖` 用于关键点。

**定义 U17（多视角几何状态）** `x_t = (T_og,t, v_slip,t, Σ_t)`，
`x̂_t = argmin_x Σ_v ‖π_v(T_v^g x) − u_t^v‖²_{Σ_v} + λ Σ_{u,v} c_t^{uv} + μ‖x − x_{t−1}‖²_{Σ_motion}`，
`Σ_t = (∇² cost)^{−1}`。未知物体用模板无关的 3D 关键点/符号距离场参数化，位姿由多视角轮廓/边缘/深度对齐估计。

**定义 U18（跨模态交互证书）** `κ_t = (P_t^g, P_t^s, f̂_t, δ_t, σ_t)`：
`P_t^g = P(grasped | o_{1:t})`，`P_t^s = P(slip | o_{1:t})`，`f̂_t = f̂_load,t`，
`δ_t = D(p_HGP(·|o), p_MVGF(·|o))`（Jensen–Shannon 或全变差），
`σ_t` 为校准不确定度（后验熵或保形区间宽度）。
证书有效当且仅当 `σ_t ≤ σ_max` 且 `δ_t ≤ δ_max`；否则强制 `U`。

**定义 U19（三值决策）** `d_t ∈ {G, N, U}`，代价 `c_{N|G}=c_fp`、`c_{G|N}=c_fn`、`c_U=c_p`，且 `c_fn ≫ c_fp`。决策：
- `G`：`P_t^g ≥ 1−α` 且 `δ_t ≤ δ_max` 且 `σ_t ≤ σ_max`；
- `N`：`P_t^g ≤ β` 且 `δ_t ≤ δ_max` 且 `σ_t ≤ σ_max`；
- `U`：其余。
阈值在校准集上取使 `P(G|N) ≤ ε_A`、`P(N|G) ≤ ε_B` 的最小风险解。

**定义 U20（探针与 VoI）** `Π_p = {LIFT, SQUEEZE, SHAKE, REOBSERVE}`，每个 `π` 有风险 `c_risk(π)` 与信息增益 `VoI(π) = H(P_t^g) − E_{o'|π}[H(P_{t+1}^g)]`。
选择 `π* = argmax_{π, n_p<N_max} VoI(π) − λ c_risk(π)`；若无正收益，则 `U` 不干预。
LIFT：垂直 2–5 mm、保持 0.2 s；SQUEEZE：夹持命令 +10–20%、保持 0.1 s；SHAKE：横向 ±2 mm、0.2 s；REOBSERVE：移动到新视角、不接触物体。

**定义 U21（谐波感知 chunk 缝合）** `Ψ_h(a^{new}, s^{prev})` 选择首动作使
`q_1 = q_T + Δt q̇_T + r_q`，`q̇_1 = q̇_T + r_v`，
`|τ̂_{ext,1} − τ̂_{ext,T}| ≤ Δτ_max`，`|τ̇_1| ≤ Δτ̇_max`，
且 chunk 频谱 `|A(f)| ≤ ε` 对 `f ≥ ω_res/(2π)`。若不可行，缩短 chunk 或施加无源混合。

**定义 U22（视角预算调度）** `B_t = (V_t, r_t)`，`V_t ⊆ V`，`r_t` 为分辨率；预测延迟 `L(B_t)`；
`B_t^* = argmax_{B: L(B) ≤ τ_budget} I(s_t; O_t(B))`；若 `I` 单调子模且 `L` 模块化，基数约束下贪心给出 `(1−1/e)` 近似；预算约束下用修正贪心/部分枚举得到常数近似。

**定义 U23（可信度审计）** `A_t = (ℓ_t, j_t, τ̂_{ext,t}, δ_t, c_t^{uv}, n_p, degraded)`；导出延迟/jerk/力矩/跨视角残差直方图与每 episode 摘要；定义规则性分数 `R = 1 − norm(ℓ_p99, j_p99, δ_p99, n_p)`。

**定义 U24（退化链）** `D0` 完整 HARMONIC；`D1` 无探针；`D2` 无 MVGF；`D3` 无 HGP；`D4` 无融合（v1 保守证书）；`D5` 无证书（v1 不干预开环）；`D6` v1 基线。每个 `D_{i+1}` 由对应模块注入中立元得到，且 `π_{D6} = π_{SAGE-v1}`。

```python
# ===== IP-09: HarmonicGraspProbe =====
class HarmonicGraspProbe:
    def __init__(self, dyn, K_o, dt, gripper_model, tau_max):
        self.dyn, self.K_o, self.dt = dyn, K_o, dt
        self.gm, self.tau_max = gripper_model, tau_max
        self.r = 0.0          # momentum observer state
        self.integral = 0.0

    def update(self, obs, prev_action):
        q, qd = obs.joint_pos, obs.joint_vel
        p = self.dyn.M(q) @ qd
        tau_act = self.dyn.actuator_model(prev_action, q, qd)   # f_theta
        cg = self.dyn.C(q, qd).T @ qd - self.dyn.g(q)
        self.integral += (tau_act + cg + self.r) * self.dt
        self.r = self.K_o * (p - self.integral)
        tau_ext = self.r
        w_c = np.linalg.pinv(self.dyn.J(q).T) @ tau_ext
        f_load = self.load_direction(q) @ w_c
        r_g = prev_action.gripper - obs.gripper
        p_obj = self.gm(r_g, obs.gripper, obs.gripper_vel)
        return HGPEstimate(p_obj, f_load, tau_ext, self.confidence())
```

```python
# ===== IP-10: MultiViewGraspFusion =====
class MultiViewGraspFusion:
    def estimate(self, obs, prev):
        views = self.vbs.select(obs.phase)          # IP-13
        feats = {v: self.encoder(obs.images[v]) for v in views}
        x = prev.x if prev else self.init_pose(feats)
        for _ in range(self.n_iter):
            cost, J = self.multiview_cost(x, feats, views, obs.extrinsics)
            x = x - self.solve(J.T @ J + self.lam * np.eye(J.shape[1]), J.T @ cost)
        Sigma = self.solve(J.T @ J + self.lam * np.eye(J.shape[1]), np.eye(J.shape[1]))
        slip = self.se3_log(prev.x.T_og.inv() @ x.T_og) / self.dt if prev else 0.0
        cons = {uv: self.consistency(feats, uv) for uv in pairs(views)}
        return MVGFEstimate(x.T_og, slip, Sigma, cons, visibility(feats))
```

```python
# ===== IP-11: CrossModalGraspCertificate + probe =====
class CrossModalGraspCertificate:
    def decide(self, hgp, mvfg):
        p_g = self.calibrated_fusion(hgp, mvfg)      # temperature/isotonic
        delta = self.divergence(hgp.posterior, mvfg.posterior)
        sigma = self.uncertainty(p_g, hgp, mvfg)
        if sigma <= self.sigma_max and delta <= self.delta_max:
            if p_g >= 1 - self.alpha: return GRASPED
            if p_g <= self.beta:      return NOT_GRASPED
        return UNCERTAIN

    def act(self, d, obs, state):
        if d == NOT_GRASPED and state.n_retry < 3:
            return self.re_grasp_or_primitive(obs)
        if d == UNCERTAIN and state.n_probe < self.N_max:
            pi = max(PROBES, key=lambda p: self.voi(p, state) - self.lam * self.risk(p))
            if self.voi(pi, state) > self.lam * self.risk(pi):
                state.n_probe += 1
                return pi
        return CONTINUE   # 不干预
```

```python
# ===== IP-12: HarmonicAwareChunkStitch =====
class HarmonicAwareStitcher:
    def stitch(self, a_new, prev, obs):
        q1 = prev.q + self.dt * prev.qd + self.r_q
        qd1 = prev.qd + self.r_v
        a1 = self.project(a_new[0], q1, qd1, prev.tau_ext)
        a = np.concatenate([[a1], a_new[1:]])
        a = self.torque_rate_limit(a, prev.tau_ext)
        a = self.notch(a, self.omega_res)
        return a
```

```python
# ===== IP-13: ViewBudgetScheduler =====
class ViewBudgetScheduler:
    def select(self, phase):
        best, best_info = None, -1.0
        for B in self.candidates[phase]:
            if self.latency(B) > self.tau_budget: continue
            info = self.mutual_information(B, phase)
            if info > best_info: best, best_info = B, info
        return best if best else self.fallback[phase]
```

## 5. 推导（引理 L8–L14）

**引理 L8（谐波残差的可观测性与分辨率）**
设关节动力学 `M(q)q̈ + C(q,q̇)q̇ + g(q) = τ_act + J^T w_c`，执行器模型误差 `‖τ_act − f_θ(a,q,q̇)‖ ≤ η_max`。采用 U14 的动量观测器，误差动态为 `ṙ = −K_o r + K_o(τ_ext + η)`，故 `‖τ̂_ext − τ_ext‖ ≤ η_max + ‖r(0)‖e^{−K_o t}`；对常值外力，稳态误差上界为 `η_max`。力分辨率 `Δf ≥ ‖J^{−T} b_g‖ Δτ`。若电机侧角度可观测，柔顺度直接给出偏转信号；若不可观测，柔顺度通过跟踪误差间接提高低频灵敏度（`∂q/∂τ ≈ 1/K_h`），但同时增加模型误差。观测器带宽受 `ω_o < min(ω_res, K_h/D_h)` 限制；因此 HGP 适合**低频接触/负载变化检测**，不适合高频力控或绝对力标定。∎

**引理 L9（多视角三角化精度）**
对焦距 `f`、基线 `b`、视差误差 `σ_d`、深度 `z` 的立体对，`σ_z ≈ z² σ_d/(f b)`。取 `f=500 px`、`b=0.10 m`、`σ_d=0.5 px`：

| z (m) | 0.1 | 0.2 | 0.3 | 0.5 | 0.8 | 1.0 |
|---|---|---|---|---|---|---|
| σ_z (mm) | 0.10 | 0.40 | 0.90 | 2.50 | 6.40 | 10.00 |
| σ_θ (mrad) | 1.00 | 2.00 | 3.00 | 5.00 | 8.00 | 10.00 |

因此腕部近景（z≤0.2 m）可达亚毫米–毫米级，足以判定插入对齐；头部全局（z≥0.5 m）是厘米级，只用于上下文/遮挡/粗定位。多视角融合的协方差为 `Σ_x = (Σ_v J_v^T Σ_v^{−1} J_v)^{−1}`，增加一个非退化视角只会降低 `tr(Σ_x)`。∎

**引理 L10（跨模态融合的误判上界）**
设 `A_H` 为 HGP 在“未抓住”时误判为“抓住”的事件，`A_V` 为 MVGF 的同一事件，`P(A_H) ≤ ε_H`、`P(A_V) ≤ ε_V`。若融合规则是“两通道都判抓住才判 G”，则 Type A 误判为 `A_H ∩ A_V`。由 Fréchet 界，**任意相关结构下** `P(A_H ∩ A_V) ≤ min(ε_H, ε_V)`；若条件独立，则 `= ε_H ε_V`。因此融合在最坏情况下不劣于较好的单通道，在独立时显著更优；正相关会侵蚀收益，但不会突破 `min` 上界。∎

**引理 L11（探针的净收益条件）**
设探针 `π` 的信息增益为 `VoI(π)`，风险为 `c_risk(π)`，探针成本 `c_p`。当前决策的期望代价与探针后决策的期望代价之差约为 `VoI(π)·(c_fn − c_fp)`。探针值得执行当且仅当
`VoI(π)·(c_fn − c_fp) > c_p + λ c_risk(π)`。
在 `N_max` 次上限下，若值函数对观测是自适应子模的，贪心 VoI 策略的期望信息增益至少为最优的 `1−1/e`。∎

**引理 L12（谐波感知缝合的稳定性）**
若执行器无源（`K_h, D_h > 0`，滞回无源），且 U21 的缝合满足力矩速率限幅与共振避让，则边界能量 `E_b = ½Δq^T K_h Δq + ½Δq̇^T M Δq̇` 不超过朴素位置缝合的边界能量；边界力矩尖峰被 `Δτ_max` 限制，且不会向 `ω_res` 注入能量。∎

**引理 L13（视角调度的近似最优性）**
若互信息 `I(B)` 对视角集单调子模、延迟 `L(B)` 模块化，则在基数约束 `|B| ≤ k` 下贪心达到 `(1−1/e)` 近似；在预算约束 `L(B) ≤ τ` 下，简单贪心没有 `1−1/e` 保证，需用修正贪心/部分枚举，仍可在多项式时间内得到常数近似。∎

**引理 L14（OOD 几何不变性的条件界）**
若证书只使用外观不变的残差（轮廓、边缘、深度、刚体运动），且标定误差 `‖ΔT‖ ≤ ε_cal`，则对未见物体的假阳性率满足 `FPR ≤ ε_cal + P(geometric residual > τ | shape class)`。该界**不是对所有形状一致**的：形状复杂度会改变几何残差尾部；因此必须用 E629 在留出物体上实测，而不能把“外观不变”误当成“形状不变”。∎

| **谐波残差不可辨识/模型误差大** | 中高 | 高（HGP 失效） | 夹爪残差优先；只做变化检测；实验室力传感器标定；退化到视觉 |

## 10. 与 v1 的接口与退化链

- **动作策略**：仍是 v1 的单一 checkpoint；HGP/MVGF/CMGC 只产生证书与门控，不产生动作；探针由同一策略执行，因此对外仍是“一个模型、一个 API”。
- **观测接口**：复用 v1 的 `metadata`/`obs_delta_indices`/`image_resize`；HGP 不需要新字段；MVGF 需要 2–3 路图像与相机外参（外参从官方数据自标定，若评测端不提供）。
- **退化链**：`D0 → D1 → D2 → D3 → D4 → D5 → D6`，每级注入中立元；`D6 = v1 SAGE`。任何新模块失效都**行为回退**而非漂移。
- **安全继承**：证书只能“删动作/加探针/降置信”，不能绕过 v1 的安全限幅与审计；探针受力矩/幅度/次数三重限制。

## 12. 本轮最值得押注的创新点（一句话）

**押注 IP-11（跨模态证书 + 探针）**：它不要求“谐波一定准”或“多视角一定准”，而是要求两条证据链在“不一致时诚实地说不确定并主动测量”——这正好把 v1 最大的不对称误判风险转成可校准、可审计、可退化的工程问题；即使两条通道各自只有中等精度，合成实验也显示“融合 + 探针”能把期望代价降到单通道的约 0.59×（ρ=0）到 0.87×（ρ=0.9）。

## 13. 本轮最大风险（一句话）

**最大风险**：谐波残差与多视角几何可能共享同一个“物体随夹爪运动”混淆源，一旦手眼标定漂移或执行器模型误差偏大，两条“独立”证据链会同向出错，让跨模态证书在最需要它的未见物体/接触瞬间变得过度自信；而探针又可能扰动一个本来已经夹稳的物体，把“不确定”变成“真失败”。
