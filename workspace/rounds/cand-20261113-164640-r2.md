# 第 68 轮（承接第 67 轮「SimRAS 仿真增强风险闭环」IP-233~242；灵感循环第 2 轮；本轮灵感：「视觉问答」×「多模态交互」）

> 第 67 轮 SimRAS 首次把「视觉问答」接进安全闭环，但它的 VQAuditor 是一个**被动、单轮、无落地**的“事后评论员”：它对世界模型渲染出的视频按模板提问，得到一段自由文本，再从中解析出 `λ_adjust`。这留下三个结构性缺陷：
> 1. **问答不是测量，而是神谕**：它没有信息增益的概念，不知道一个问题值不值得问，也不知道问完是否更确定；
> 2. **语言没有落地**：答案里的「左边那个杯子」无法映射到机器人度量场景图中的具体实体，因此这段审计只能当软先验，进不了认证前缀；
> 3. **交互是单向的**：真正的多模态交互允许机器人移动视角、指点、触碰、追问，也允许人用指向和注视回答；SimRAS 完全放弃了这条主动取证通道。
>
> 本轮的核心命题是：
>
> **把「VQA 审计」从一次性的被动神谕，升级为一场有成本、可证伪、可落地的「具身多模态审问」（SOCRATES）：机器人主动选择要看什么、指什么、问什么，用跨模态证据把语言指代钉到度量场景图上，再用标定后的信息增益去修正风险证书。**
>
> SOCRATES 问的不再是「这安全吗」，而是「**我刚才那个判断，究竟建立在哪个可以被指认、被复核、被证伪的证据上？为了得到这个证据，我愿意付出多少安全预算？**」

## 0. 直觉与动机

**灵感 1（视觉问答 → 问答是一种有成本的测量，而非免费的真值）**
直觉：把 VQA 当成 oracle，是 SimRAS 最大的隐含假设。可现实中，一个问题的价值取决于三件事：它能减少多少关于风险状态的不确定性、它要花多少交互成本、以及它的答案有多可信。问「你还好吗？」几乎零信息；问「你指的是不是左前方那个有裂纹的玻璃杯？」信息量很大，但需要机器人先把视角转过去。于是审计变成一个**贝叶斯实验设计**问题：`q* = argmax VoI(q)/cost(q)`。更尖锐的是：**不问，可能比问错更安全**——诱导性问题会把人的回答推向机器人已有的假设，制造“被问出来的安全感”。

**灵感 2（多模态交互 → 指代落地是对齐语言与度量世界的必要条件）**
直觉：VQA 的答案天然是符号/语言的，而安全证书定义在度量状态上（位姿、力、几何球）。二者之间缺一个映射。多模态交互恰好提供了锚点：人用手指、用注视、用「不是那个、是这个」的否定；机器人用深度、触觉、本体感受去核对。**没有落地的审计，只是一句无法签名的证词。** 因此本轮把“指代落地”提升为一等公民：审计报告的每个风险因子都必须携带 `(scene_entity_id, grounding_score)`，否则不计入证书。

**灵感 3（交互的观察者效应 → 取证会改变被取证的对象）**
直觉：主动取证不是免费的午餐。机器人为了看清而移动，移动本身进入安全预算；提出的问题会锚定用户；探针可能激发人的紧张，反过来改变情绪观测。这与第 66 轮 RAS 的“情绪观测污染”同构，但发生在**证据层**：`P(evidence | question) ≠ P(evidence)`。所以 SOCRATES 必须把「探针」当作受认证约束的动作，而不是审计器内部的免费函数调用。

**灵感 4（多轮对话 → 信息增益是次模的，但信任不是）**
直觉：多轮追问的边际信息通常递减，可用次模性给出贪心 `(1−1/e)` 保证。但还有一个更隐蔽的问题：**多轮一致不等于多轮正确**。如果每轮都由同一个 VQA 模型、同一段渲染、同一套提示词生成，轮与轮之间的证据高度相关；问十轮可能只是把同一个错误重复十次。故 SOCRATES 要求每轮至少更换一个“证据维度”（模态/视角/指代来源），并显式维护**证据相关性** `ρ_e`，用有效证据量 `N_eff = N/(1+(N−1)ρ̄)` 折减信息增益。

**灵感 5（对前三轮的升级映射）**
- **SimRAS 的 VQAuditor → MIAuditor**：单轮模板问答升级为多轮、带落地与停止规则的审计对话；
- **WM 滚动 → 对话前瞻**：不只看“未来会怎样”，还看“下一问会问出什么”；
- **`λ_risk` → `λ_audit`**：审计证据只有落地且一致时，才允许把风险系数往上限回调；否则只允许收紧，并触发 `H_hallucination`；
- **`k_wm` → `k_ground`**：认证前缀额外受“可落地证据覆盖”约束，没有足够落地证据支撑的步数不予认证；
- **`J_SimRAS` → `J_SOCRATES`**：证书新增 `grounding_score`、`consistency_score`、`dialogue_hash`、`probe_budget_used`。

## 1. 形式化定义（增量：定义 266–285）

- **定义 266（SOCRATES 总览）** SOCRATES = (MIAuditor, RGL, QPolicy, CMCC, ACB, SGS, DSR)。定位：把 SimRAS 的“审计”升级为“可落地的交互取证”。不变式：审计异步于实时控制；任何探针执行前必须通过 SGS 认证；实时环路零学习写、零自由文本写。
- **定义 267（度量场景图）** `G_t = (O_t, A_t, R_t)`；O 为实体（id、位姿、包围盒、材质、置信度），A 为属性（可抓/易碎/有裂纹），R 为关系（左/右/接近/支撑）。`x_t` 为机器人度量状态。
- **定义 268（潜在风险状态）** `θ_t = (H_t, E_t, Ref_t)`，H 为 VISTA 故障假设，E 为 RAS 情绪假设，`Ref_t` 为人当前指称的实体。审计目标是降低 `H(θ_t | D_t)`。
- **定义 269（指代落地算子）** `γ: ℒ × G_t → Δ(O_t)`，把语言提及 `ℓ`（“左边那个杯子”“刚才那个”）映射到实体分布；`g = max_o P(o | ℓ)` 为 grounding score。若 `g < τ_ground`，指代标记 `ungrounded`，其证据权重置 0。
- **定义 270（探针空间）** `P = M × O_t × Q`，探针 `q = (m, o, ψ)`：模态 `m ∈ {move_view, point, zoom, depth, tactile, speech, gaze_cue}`、指代实体 `o`、问题模板 `ψ`。探针会改变 `x_t` 与 `G_t`，故它同时是一个受认证约束的动作。
- **定义 271（多模态答覆）** `a = (a_text, a_mask, a_depth, a_force, a_gaze)`；答覆通道 `p(a | q, θ, G)`，文本只是其中一个分量。
- **定义 272（对话状态）** `D_t = (q_{1:t}, a_{1:t}, b_t, G_t, ρ_e)`，其中 `b_t = P(θ | D_t)`。
- **定义 273（风险信念更新）** `b_{t+1}(θ) ∝ b_t(θ)·p(a | q, θ, G_t)·P(q | θ)`；`P(q | θ)` 显式建模**提问的选择偏差**。
- **定义 274（期望信息增益）** `VoI(q) = E_{a|q}[H(b_t) − H(b_{t+1})]`；证据相关时折减 `VoI_eff(q) = VoI(q)·N_eff(q)/N(q)`。
- **定义 275（交互成本）** `c(q) = c_time + c_move + c_attention + c_safety(q)`，`c_safety(q)` 为探针轨迹占用的认证前缀步数；交互安全预算 `B_probe`。
- **定义 276（安全探针约束 SGS）** 探针可执行 ⇔ `CertifiedPrefix(probe) ≥ 1` 且 `∑_{i≤t} c_safety(q_i) ≤ B_probe`。
- **定义 277（跨模态一致性）** `C(a) = 1 − D_KL(p(o | a_text) ‖ p(o | a_mask, a_depth))`，并对力/注视做同类对齐；`C(a) < τ_consist ⇒ inconsistent`。
- **定义 278（审计标定与风险回调）** 用 split-conformal 给出答覆正确性的覆盖率保证：`λ_audit = λ_risk·exp(κ·g·C·1[VoI_eff > τ_voi])`，截断于 `[0.5, 1.2]`；`g` 或 `C` 低时只允许收紧。
- **定义 279（审计-证书桥）** `k_ground = max{k : ∀i≤k, 步 i 的风险因子均有 g ≥ τ_ground 的落地证据}`；最终 `k*SOCRATES = min(k_VISTA, k_emo, k_wm, k_ground, m_ras)`。
- **定义 280（停止规则）** `max_q VoI_eff(q)/c(q) < τ_stop` 或 `H(b_t) < τ_entropy` 或 `∑c_safety ≥ B_probe` 时停止。
- **定义 281（MIAuditor）** MIAuditor = (VideoRenderer, VQA_Model, QPolicy, RGL, CMCC, ACB)；输出 `AuditReport = {risk_factors[(f, o, g, C)], counterfactuals, λ_audit, dialogue_hash}`。
- **定义 282（QPolicy）** 贪心选择 `q* = argmax_{q∈P} VoI_eff(q)/c(q)`，约束 `SGS(q)`；每轮强制更换至少一个证据维度，防止共因重复。
- **定义 283（CMCC）** 对每个 risk factor 检查文本指代与掩码/深度/力/注视的一致性；不一致时上调 `H_hallucination` 并下调 `λ_audit`。
- **定义 284（AIC-SOCRATES 干扰集）** `ℰ_SOCRATES = ℰ_SimRAS × ℰ_ground × ℰ_turn × ℰ_probe`；`ℰ_ground` = 指代错配/同义歧义/遮挡，`ℰ_turn` = 多轮漂移/诱导性提问/证据相关，`ℰ_probe` = 探针副作用/视角暴露/触碰改变场景。
- **定义 285（J_SOCRATES 证书）** `J_SOCRATES = (J_SimRAS, grounding_score, consistency_score, dialogue_hash, probe_budget_used, socrates_ver)`。Valid ⇔ `Valid(J_SimRAS)` ∧ `grounding_score ≥ 0.8` ∧ `probe_budget_used ≤ B_probe` ∧ 无 `g < τ_ground` 的风险因子。

## 2. 关键算法骨架

```python
# IP-243 MIAuditor + IP-245 QPolicy：有成本的交互式取证
class SOCRATESAuditor:
    def __init__(self, vqa, renderer, rgl, cmcc, acb, sgs,
                 tau_ground=0.6, tau_consist=0.7, tau_stop=0.05):
        self.vqa, self.render, self.rgl = vqa, renderer, rgl
        self.cmcc, self.acb, self.sgs = cmcc, acb, sgs
        self.tau_g, self.tau_c, self.tau_stop = tau_ground, tau_consist, tau_stop

    def audit(self, wm_preds, G0, x0, b0, B_probe=3):
        D = DialogueState(b=b0, G=G0, budget=B_probe, rho_e=init_rho_e())
        while not self._stop(D):
            best = None
            for q in enumerate_probes(D.b, G0):
                if not self.sgs.certifiable(q, x0):
                    continue                       # 探针自身必须可认证
                score = expected_voi(D.b, q, D.rho_e) / self._cost(q)
                if best is None or score > best[0]:
                    best = (score, q)
            if best is None or best[0] < self.tau_stop:
                break
            q = best[1]
            x0 = self.sgs.execute(q, x0)           # 取证本身消耗安全预算
            vid = self.render.render(wm_preds, q)
            a = self.vqa.ask(vid, q.prompt)
            ground = self.rgl.ground(a.text, G0, a)  # γ：语言 -> 实体分布
            C = self.cmcc.check(a, ground)           # 跨模态一致性
            D = D.update(q, a, ground, C)            # 贝叶斯更新 + 换维度
        return self.acb.calibrate(D, self.tau_g, self.tau_c)

    def _stop(self, D):
        return (D.budget <= 0 or entropy(D.b) < 0.1
                or max_voi(D) / 1.0 < self.tau_stop)


# IP-244 RGL：把语言指代钉到度量场景图
class ReferentGroundingLayer:
    def ground(self, mention, G, anchors):
        cand = language_to_entities(mention, G)
        scores = {}
        for o in cand:
            feats = [semantic_score(mention, o),
                     visual_anchor_score(o, anchors.mask, anchors.depth),
                     gaze_score(o, anchors.gaze),
                     pointing_score(o, anchors.pointing)]
            scores[o] = softmax(self.w @ feats)
        dist = Categorical(scores)
        return dist, max(scores.values())


# IP-246 CMCC + IP-247 ACB：一致性检查与标定回调
def cross_modal_check(a, ground, tau_consist):
    p_text = ground                               # 文本指代分布
    p_geo = fuse(a.mask, a.depth, a.gaze)         # 几何/注视指代分布
    C = 1 - kl_div(p_text, p_geo)
    return C, (C >= tau_consist)


def calibrate_audit(D, tau_g, tau_c):
    g = min(r['g'] for r in D.risk_factors)
    C = min(r['C'] for r in D.risk_factors)
    if g < tau_g or C < tau_c:
        return {'lambda_audit': min(1.0, D.lambda_risk),   # 只紧不松
                'grounding_score': g, 'consistency_score': C,
                'reason': 'ungrounded_or_inconsistent'}
    delta = math.exp(kappa * g * C) - 1.0
    return {'lambda_audit': clip(D.lambda_risk * (1 + delta), 0.5, 1.2),
            'grounding_score': g, 'consistency_score': C}
```

## 3. 推导

**引理 13（VoI 的次模性与贪心界）** 若单轮答覆通道满足条件独立（固定 q 后 `a ⟂` 历史给定 θ），则集函数 `F(S) = I(θ; a_S | q_S)` 关于证据集 S 次模。带预算 B 的贪心 `q* = argmax VoI_eff/c` 满足 `F(S_greedy) ≥ (1−1/e)·F(S*)`。当证据相关系数为 `ρ̄` 时，界退化为 `(1−1/e)·(N_eff/N)·F(S*)`——**相关性直接吃掉信息收益**。

**引理 14（落地误差到安全裕度）** 设落地错误概率为 `ε_g`，安全裕度对实体参数 Lipschitz 常数为 `L_m`，则 `E|m(ô) − m(o*)| ≤ L_m·ε_g`；由此损失的可认证步数 `≤ L_m·ε_g/ρ_min`，其中 `ρ_min` 为单步最小安全余量。

**定理 14（SOCRATES 端到端风险一致性）** 在 A87–A91、WM 误差界、VQA 标定覆盖下：
1. `P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_ground + α_cal`；
2. `λ_audit ≥ 0.6 ⇔ 实际执行风险 ≤ 设定上限 × 1.2`；
3. `grounding_score < 0.8 ∨ C < τ_consist ⇒ λ_audit ≤ λ_risk`（审计永不因“没看懂”而放行）；
4. `face_unobservable ∨ wm_drift ⇒ k_ground = k_wm`（回退到 SimRAS，不额外加码）。

**定理 15（交互安全预算守恒）** 若每个探针在 SGS 下可认证且累计 `∑c_safety ≤ B_probe`，则交互导致的认证前缀收缩不超过 `⌊B_probe/ρ_min⌋` 步；预算耗尽后系统严格回退到 SimRAS 行为，因此**审计永远不能把系统置于比不审计更危险的执行状态**。

**定理 16（多模态幻觉检测）** 对一条幻觉性断言，若其与 `m` 个相互独立的锚点（掩码、深度、力、注视）不一致，且单锚点检出率 `p_d`，则 `P(detect) ≥ 1 − (1−p_d)^m`；在 conformal 阈值 `α` 下误报率 `≤ α`。故“多模态”不是装饰，而是把检测概率从 `p_d` 抬到指数级。

## 6. 本轮最大风险

**一句话**：SOCRATES 用“落地＋跨模态一致”来认证审计，但这两者度量的是**内部自洽**而非**外部为真**；当问策由它所要检验的同一个信念来选择、当提问又会锚定回答者时，对话可能演化成一个自我确认回路——**机器人一直问，直到问出它原本就想听的答案**，从而拿到一份技术上可落地、逻辑上却循环论证的证书。这是本轮所有理论依赖的核心假设：**主动取证选择的证据与待检验的风险状态之间不存在由问策本身引入的选择偏差**。

## 2. 形式化定义（完整版）

**定义 266（SOCRATES 总览）** SOCRATES 把 SimRAS 的“审计”升级为“可落地的交互取证”：
```
SOCRATES = (MIAuditor, RGL, QPolicy, CMCC, ACB, SGS, DSR)
```
不变式：审计异步于实时控制；任何探针执行前必须通过 SGS 认证；实时环路零学习写、零自由文本写。

**定义 267（度量场景图）** `G_t = (O_t, A_t, R_t)`。O 为实体（id、位姿、包围盒、材质、置信度），A 为属性（可抓/易碎/有裂纹），R 为关系（左/右/接近/支撑）。`x_t` 为机器人度量状态。

**定义 268（潜在风险状态）** `θ_t = (H_t, E_t, Ref_t)`。H 复用 VISTA 故障假设，E 复用 RAS 情绪假设，`Ref_t` 为人当前指称的实体。审计目标是降低 `H(θ_t | D_t)`。

**定义 269（指代落地算子）** 
```
γ: ℒ × G_t → Δ(O_t),  g = max_o P(o | ℓ)
```
把语言提及 `ℓ` 映射到实体分布。若 `g < τ_ground`，指代标记 `ungrounded`，其证据权重置 0。

**定义 270（探针空间）** `P = M × O_t × Q`，`q = (m, o, ψ)`，`m ∈ {move_view, point, zoom, depth, tactile, speech, gaze_cue}`。探针会改变 `x_t` 与 `G_t`，故它同时是一个受认证约束的动作。

**定义 271（多模态答覆）** `a = (a_text, a_mask, a_depth, a_force, a_gaze)`，答覆通道 `p(a | q, θ, G)`；文本只是其中一个分量。

**定义 272（对话状态）** `D_t = (q_{1:t}, a_{1:t}, b_t, G_t, ρ_e)`，`b_t = P(θ | D_t)`，`ρ_e` 为证据相关矩阵。

**定义 273（风险信念更新）**
```
b_{t+1}(θ) ∝ b_t(θ) · p(a | q, θ, G_t) · P(q | θ)
```
`P(q | θ)` 显式建模**提问的选择偏差**：同一问题在不同假设下被问到的概率不同。

**定义 274（期望信息增益）**
```
VoI(q) = E_{a|q}[H(b_t) − H(b_{t+1})]
VoI_eff(q) = VoI(q) · N_eff(q) / N(q)
```

**定义 275（交互成本）** `c(q) = c_time + c_move + c_attention + c_safety(q)`；`c_safety(q)` 为探针轨迹占用的认证前缀步数，预算 `B_probe`。

**定义 276（安全探针约束 SGS）** 探针可执行 ⇔ `CertifiedPrefix(probe) ≥ 1` 且 `∑_{i≤t} c_safety(q_i) ≤ B_probe`。

**定义 277（跨模态一致性）**
```
C(a) = 1 − D_KL(p(o | a_text) ‖ p(o | a_mask, a_depth))
```
并对力/注视做同类对齐；`C(a) < τ_consist ⇒ inconsistent`。

**定义 278（审计标定与风险回调）** split-conformal 给出答覆正确性的覆盖率保证：
```
λ_audit = clip( λ_risk · exp(κ·g·C·1[VoI_eff > τ_voi]), 0.5, 1.2 )
```
`g` 或 `C` 低时只允许收紧，`λ_audit ≤ λ_risk`。

**定义 279（审计-证书桥）**
```
k_ground = max{k : ∀i≤k, 步 i 的风险因子均有 g ≥ τ_ground 的落地证据}
k*SOCRATES = min(k_VISTA, k_emo, k_wm, k_ground, m_ras)
```

**定义 280（停止规则）** `max_q VoI_eff(q)/c(q) < τ_stop` 或 `H(b_t) < τ_entropy` 或 `∑c_safety ≥ B_probe` 时停止。

**定义 281（MIAuditor）** `MIAuditor = (VideoRenderer, VQA_Model, QPolicy, RGL, CMCC, ACB)`；输出
```
AuditReport = {risk_factors[(f, o, g, C)], counterfactuals, λ_audit, dialogue_hash}
```

**定义 282（QPolicy）** 贪心选择 `q* = argmax_{q∈P} VoI_eff(q)/c(q)`，约束 `SGS(q)`；每轮强制更换至少一个证据维度，防止共因重复。

**定义 283（CMCC）** 对每个 risk factor 检查文本指代与掩码/深度/力/注视的一致性；不一致时上调 `H_hallucination` 并下调 `λ_audit`。

**定义 284（AIC-SOCRATES 干扰集）**
```
ℰ_SOCRATES = ℰ_SimRAS × ℰ_ground × ℰ_turn × ℰ_probe
```
`ℰ_ground` = 指代错配/同义歧义/遮挡；`ℰ_turn` = 多轮漂移/诱导性提问/证据相关；`ℰ_probe` = 探针副作用/视角暴露/触碰改变场景。

**定义 285（J_SOCRATES 证书）**
```
J_SOCRATES = (J_SimRAS, grounding_score, consistency_score,
              dialogue_hash, probe_budget_used, socrates_ver)
```
Valid ⇔ `Valid(J_SimRAS)` ∧ `grounding_score ≥ 0.8` ∧ `probe_budget_used ≤ B_probe` ∧ 无 `g < τ_ground` 的风险因子。

```python
# IP-243/245 MIAuditor + QPolicy
class SOCRATESAuditor:
    def __init__(self, vqa, renderer, rgl, cmcc, acb, sgs,
                 tau_ground=0.6, tau_consist=0.7, tau_stop=0.05):
        self.vqa, self.render, self.rgl = vqa, renderer, rgl
        self.cmcc, self.acb, self.sgs = cmcc, acb, sgs
        self.tau_g, self.tau_c, self.tau_stop = tau_ground, tau_consist, tau_stop

    def audit(self, wm_preds, G0, x0, b0, B_probe=3):
        D = DialogueState(b=b0, G=G0, budget=B_probe, rho_e=init_rho_e())
        while not self._stop(D):
            best = None
            for q in enumerate_probes(D.b, G0):
                if not self.sgs.certifiable(q, x0):
                    continue                       # 探针自身必须可认证
                score = expected_voi(D.b, q, D.rho_e) / self._cost(q)
                if best is None or score > best[0]:
                    best = (score, q)
            if best is None or best[0] < self.tau_stop:
                break
            q = best[1]
            x0 = self.sgs.execute(q, x0)           # 取证消耗安全预算
            vid = self.render.render(wm_preds, q)
            a = self.vqa.ask(vid, q.prompt)
            ground = self.rgl.ground(a.text, G0, a)
            C = self.cmcc.check(a, ground)
            D = D.update(q, a, ground, C)          # 贝叶斯更新 + 维度轮换
        return self.acb.calibrate(D, self.tau_g, self.tau_c)


class DialogueState:
    def __init__(self, b, G, budget, rho_e):
        self.b, self.G, self.budget, self.rho_e = b, G, budget, rho_e
        self.history, self.risk_factors = [], []

    def update(self, q, a, ground, C):
        self.b = bayes_update(self.b, q, a, self.G)
        self.budget -= q.c_safety
        self.rho_e = update_correlation(self.rho_e, q)
        self.history.append((q, a))
        if ground[1] >= TAU_GROUND:
            self.risk_factors.append({'g': ground[1], 'C': C})
        return self


# IP-244 RGL
class ReferentGroundingLayer:
    def __init__(self, w):
        self.w = w

    def ground(self, mention, G, anchors):
        cand = language_to_entities(mention, G)
        scores = {}
        for o in cand:
            feats = [semantic_score(mention, o),
                     visual_anchor_score(o, anchors.mask, anchors.depth),
                     gaze_score(o, anchors.gaze),
                     pointing_score(o, anchors.pointing)]
            scores[o] = softmax(self.w @ feats)
        dist = Categorical(scores)
        return dist, max(scores.values())


# IP-246 CMCC
def cross_modal_check(a, ground, tau_consist):
    p_text = ground
    p_geo = fuse(a.mask, a.depth, a.gaze)
    C = 1 - kl_div(p_text, p_geo)
    return C, (C >= tau_consist)


# IP-247 ACB
def calibrate_audit(D, tau_g, tau_c):
    g = min([r['g'] for r in D.risk_factors], default=0.0)
    C = min([r['C'] for r in D.risk_factors], default=0.0)
    if g < tau_g or C < tau_c:
        return {'lambda_audit': min(1.0, D.lambda_risk),   # 只紧不松
                'grounding_score': g, 'consistency_score': C,
                'reason': 'ungrounded_or_inconsistent'}
    delta = math.exp(KAPPA * g * C) - 1.0
    return {'lambda_audit': clip(D.lambda_risk * (1 + delta), 0.5, 1.2),
            'grounding_score': g, 'consistency_score': C}


# IP-248 SGS
class SafeGroundingSet:
    def __init__(self, csc_ras, B_probe=3):
        self.csc, self.B, self.used = csc_ras, B_probe, 0

    def certifiable(self, q, x):
        return (self.used + q.c_safety <= self.B
                and self.csc.certified_prefix(q.trajectory(x)) >= 1)

    def execute(self, q, x):
        self.used += q.c_safety
        return q.apply(x)


# IP-252 SOCRATES 在线部署（审计异步，不阻塞 3ms 控制环）
def SOCRATES_round(M, obs, B_probe=3):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    M.lsf.update_geometry(P_cloud)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))

    # --- SimRAS 实时环路（同步，照旧） ---
    act_seq = M.vista.ach.propose_actions(x_prime, H=M.vista.H, steps=5)
    face_gate = M.erg_wm.recognize(img, x_prime, act_seq)
    A = M.vista.ach.propose(x_prime, H=M.vista.H)
    wm_preds = M.wm.rollout(x_prime, act_seq, k=min(5, len(A)))
    rho = M.vista.fir.signature(M.vista.stage.split(M.vista.residual_log))
    joint_post, _ = M.efs_wm.synthesize(rho, face_gate, x_prime, act_seq)
    m_ras = min(M.vista.m, M.er.max_m_emotion)
    k_ras = M.csc_ras_wm.certified_prefix_ras_wm(
        A, joint_post, m_ras, M.alpha_chunk, wm_preds)
    λ_risk = M.efs_wm.risk_scale(joint_post)

    # --- 异步审计：提交不阻塞；命中缓存则读回 ---
    report = M.socrates.try_read(M.scene_hash(x_prime, face_gate, joint_post))
    if report is None:
        M.socrates.submit_async(wm_preds, M.scene_graph, x_prime,
                                b0=joint_post, B_probe=B_probe)
        λ_audit, k_ground = λ_risk, k_ras          # 无审计 → 不回拨
    else:
        λ_audit = report['lambda_audit']
        k_ground = compute_k_ground(report, wm_preds) if report['grounding_score'] >= 0.8 else 0
        k_ground = min(k_ground, k_ras)

    # --- 控制：审计只能收紧，不能越过 SimRAS 的兜底 ---
    k_final = min(k_ras, k_ground) if report else k_ras
    tau_cmd = M.vista.pi_sigma.prefix_dispatch(A[:k_final])
    tau_cmd = tau_cmd * λ_audit
    tau_cmd = emotion_response_shaping_wm(tau_cmd, joint_post, wm_preds)
    return k_final, λ_audit, report, face_gate
```

## 4. 推导

**引理 13（VoI 的次模性与贪心界）** 固定问策后，若单轮答覆通道满足条件独立 `a ⟂ 历史 | θ`，则集函数 `F(S) = I(θ; a_S | q_S)` 关于证据集 S 次模。带预算 B 的贪心满足 `F(S_greedy) ≥ (1−1/e)·F(S*)`。当证据平均相关系数为 `ρ̄` 时，界退化为 `(1−1/e)·(N_eff/N)·F(S*)`——相关性直接折减信息收益，这解释了为什么“问十次同一模型”约等于“问一次”。

**引理 14（落地误差到安全裕度）** 设落地错误概率 `ε_g`，安全裕度 `m(·)` 对实体参数 Lipschitz 常数 `L_m`，则 `E|m(ô) − m(o*)| ≤ L_m·ε_g`；损失的可认证步数 `≤ L_m·ε_g/ρ_min`，`ρ_min` 为单步最小安全余量。

**定理 14（SOCRATES 端到端风险一致性）** 在 A87–A91、WM 误差界、VQA conformal 覆盖下：
1. `P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_ground + α_cal`；
2. `λ_audit ≥ 0.6 ⇔ 实际执行风险 ≤ 设定上限 × 1.2`；
3. `grounding_score < 0.8 ∨ C < τ_consist ⇒ λ_audit ≤ λ_risk`（审计永不因“没看懂”而放行）；
4. `face_unobservable ∨ wm_drift ⇒ k_ground = k_wm`（回退 SimRAS，不额外加码）。

**定理 15（交互安全预算守恒）** 若每探针在 SGS 下可认证且累计 `∑c_safety ≤ B_probe`，交互导致的认证前缀收缩不超过 `⌊B_probe/ρ_min⌋`；预算耗尽后严格回退 SimRAS。故审计永远不能把系统置于比“不审计”更危险的执行状态。

**定理 16（多模态幻觉检测）** 对一条幻觉断言，若其与 `m` 个相互独立锚点（掩码/深度/力/注视）不一致、单锚点检出率 `p_d`，则 `P(detect) ≥ 1 − (1−p_d)^m`；conformal 阈值 `α` 下误报率 `≤ α`。多模态把检测概率从 `p_d` 抬到指数级。

## 8. 本轮最大风险

**一句话**：SOCRATES 用“落地＋跨模态一致”来认证审计，但这两者度量的是**内部自洽**而非**外部为真**；当问策由它所要检验的同一个信念来选择、当提问又会锚定回答者时，对话可能演化成一个自我确认回路——**机器人一直问，直到问出它原本就想听的答案**，从而拿到一份技术上可落地、逻辑上却循环论证的证书。这是本轮所有理论依赖的核心假设：**主动取证所选择的证据与待检验的风险状态之间不存在由问策本身引入的选择偏差**。
