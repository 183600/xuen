# 第 57 轮（承接第 56 轮「证据地图-探询-协商」IP-127~132；灵感循环第 1 轮；本轮灵感：「物体泛化」×「多模态融合」）

> 第 56 轮把安全赌注从"模型置信"换到"证据"，用 SMM/PCE/BVK/ISE/TAF/MEC 让证据可积累、可探询、可协商。但它有一个从未被挑战的隐含前提：**证据是区域级的**。而部署现场的威胁常常是**物体级**的——同一个"已验证区域"今天被放进一块透明玻璃、一坨泡沫石头、一个高仿真的仿真道具，区域信念完全正确，对象却完全陌生。本轮两条灵感各补一刀：**物体泛化**指出"泛化不是一个布尔量，而是一组有坐标、有支撑、有迁移可靠度的属性轴"；**多模态融合**指出"融合的价值不在把方差压小，而在把'模态不同意'这件事显式暴露出来"。核心命题由"证据说可信"升级为 **"证据在说哪个属性的可信、由谁独立佐证"**。

核心矛盾：
- **H26**：证据门是区域级的，威胁常是物体级的。一个今天新放进正确区域的陌生物体，可以让完全正确的区域证据为完全错误的对象放行。"见过这个区域"不等于"认识这个物体"；而"认识这个物体"也不等于"知道它这一根属性"。
- **H27**：多模态融合常被当成降方差机器，默认模态条件独立；可视觉、触觉、声学往往由**同一真实材料**驱动，误差是共因的，相乘会把相关误差当独立证据，制造比单模态更危险的虚假置信。真正稀缺的信息不是融合均值，而是**跨模态预测残差**——它是可在部署时直接测量的泛化检验。

## 0. 直觉与动机

**灵感 1（物体泛化 → 泛化有坐标，不是一个布尔量）**
直觉：机器人见过很多箱子，能泛化箱子的"几何"，却未必泛化它的"质量分布"；能泛化椅子的"可坐性"，却未必泛化它的"易碎性"。所以"泛化到新物体"应被拆成**属性轴**（几何 / 材料柔顺 / 质量分布 / 可动性 / 表面摩擦）上的**有界迁移**，而不是一个整体置信度。物体是属性束的联合；新颖 = 至少一根**负载轴**跑出了支撑集。系统不必"认识整个物体"才敢行动，只需"本次承诺所依赖的那几根轴有支撑或有独立证据"。

**灵感 2（多模态融合 → 融合的价值在冲突残差，不在平均）**
直觉：若视觉说"刚性方块"而第一次轻触说"很软"，最有价值的输出不是方差更小的融合后验，而是一声**认知警报**：至少有一个模态跑出了它的适用域。因此融合应是**带共因隐变量的因子图**——显式建模"同一材料同时支配多个模态"的相关误差，输出 `(后验, 冲突残差 ξ, 各模态适用域指示)`。冲突残差本身就是新颖度统计量。

**灵感 3（跨模态预测 → 泛化的可检验性）**
直觉：检验"泛化是否成立"最便宜的办法，是让一个模态去**预测**另一个模态：视觉先验预测"摸上去该多硬/多重/多滑"，再去测。预测残差小 → 支撑成立；残差大 → 泛化假设被证伪。这让"泛化"从训练时的口号变成**部署时每个检查点都可测的量**，并天然接入第 56 轮的探-诺-演回路。

**灵感 4（属性级承诺 → 只承诺"有支撑或有独立证据"的属性）**
直觉：第 56 轮的证据门挂的是"区域证据类"，本轮把它细化为**属性级泛化门**：承诺 c 有一个负载属性集 `P(c)`（踏石承载依赖材料与质量；抓取依赖几何与表面摩擦）。只要某根负载轴既无支撑、又无正交佐证，就**不允许**做出依赖它的承诺——转探询、绕行、降档或协商。

**灵感 5（泛化证书 → 从全局泛化幻觉退到条件保证）**
直觉：没人能证明"对任意新物体安全"。但可以证明："本次承诺所依赖的每根属性轴，要么在支撑内且迁移可靠，要么有正交模态的独立佐证，且无未解冲突。"这是**逐承诺的泛化证书**，把不可能的整体保证换成可审计的条件保证，也更诚实。

## 1. 形式化定义（增量：定义 133–137）

**定义 133（属性分解的对象模型与泛化坐标）**
物体 `o` 分解为属性束 `φ(o) = (φ_geo, φ_mat, φ_mass, φ_art, φ_surf)`（几何 / 材料与柔顺 / 质量分布 / 关节与可动性 / 表面摩擦与纹理）。每个属性轴 `a` 有表示空间 `Z_a`、历史/训练证据的支撑集 `S_a ⊆ Z_a`、距离 `d_a` 与支撑半径 `r_a`。定义
- **泛化坐标** `g_a(o) = d_a(φ_a(o), S_a) / r_a`，`g_a ≤ 1` 称在支撑内；
- **迁移可靠度** `T_a: [0,∞) → [0,1]` 单调不增、`T_a(0)=1`，为沿轴 `a` 外推时下游接触参数预测的可靠度**上界**；**泛化间隙** `γ_a(o) = 1 − T_a(g_a(o))`；
- **负载属性集** `P(c) ⊆ {geo,mat,mass,art,surf}`：承诺 `c` 的可行性与安全判定实际依赖的属性子集（如踏石承载依赖 `{mass,mat}`，抓取依赖 `{geo,surf}`）。
关键：物体级新颖度 `nov(o)=max_a g_a(o)` 只是诊断量；**决定风险的是 `P(c)` 上的逐轴状态**。

**定义 134（冲突感知多模态证据与冲突残差）**
模态 `m ∈ M = {RGB, depth, tactile, audio, proprio, thermal}`；因子 `F_{m,a}` 把观测映射到属性轴 `a`，并带**适用域指示** `reg_{m,a} ∈ {0,1}`。引入**共因隐变量** `c`（如"真实材料"）显式建模模态相关误差：
`p(φ, c | E) ∝ Π_m p(e_m | φ, c) · p(c)`，**不假设模态条件独立**。
跨模态预测残差 `ξ_{m→m'}(a) = ‖ observed_{m'}(a) − pred_{m'}( posterior_m(φ_a) ) ‖`；**冲突残差** `ξ_a = max_{m→m'} ξ_{m→m'}(a)`。融合输出 `Fuse(E) = (posterior(φ), {ξ_a}, {reg_a})`——不仅给后验，还给"哪里不同意、哪个模态此刻不算数"。

**定义 135（泛化门与属性级承诺）**
记**正交佐证** `OE_a(c)` ≜ 存在与主导模态 `m0(a)` 在给定 `φ_a` 下条件独立的模态 `m ⟂ m0 | φ_a`，其在 `a` 上 in-regime 且 `ξ_a ≤ ξ_max`、残差口径泛化间隙 `γ_a^res ≤ γ_max`。泛化门：
`G-ok(c) ⇔ ∀a ∈ P(c): [ g_a ≤ 1 ∧ γ_a ≤ γ_max ] ∨ OE_a(c)`，且 `∀a ∈ P(c): ξ_a ≤ ξ_max`。
直觉：**只承诺"有支撑或有独立证据"的负载属性**；无支撑又无正交佐证的负载属性必须转探询/绕行/降档/协商。

**定义 136（泛化导向的跨模态主动探询 XAP）**
探针 `π = (m, action)` 绑定模态 `m`。设最紧轴 `a* = argmax_{a∈P(c)} max(γ_a, ξ_a)`。VOI 相对 `a*` 计算，并施加：**(i) 正交优先**——`m ⟂ m0(a*) | φ_{a*}` 得全权，否则权重乘 `w_orth < 1`；**(ii) 悲观新颖先验**——`S_a` 之外不外推，似然取最坏情形包络，避免 VOI 被乐观外推高估。决策 `π* = argmax_π [ VOI_pess(π; a*) − cost(π) − λ·risk_probe(π) ]`；`VOI_pess < θ_voi` 则拒绝承诺。

**定义 137（泛化证书 J_g）**
`J_g(c) = (o, P(c), { (g_a, γ_a, ξ_a, reg_a, evidence_modalities) }_{a∈P(c)}, novelty_verdict, xmodal_probe_log)`。校验：每根负载轴满足支撑或正交佐证、`ξ_a ≤ ξ_max`、探针继承 A34 非破坏、`novelty_verdict ≠ reject`。证书是**条件证书**：以"轴迁移可靠度界 A37 成立"为条件。

**正确性定理（Generalization-Conditional Commitment Soundness, GCCS）**
在 A29–A36 基础上加：**(A37)** 轴迁移可靠度诚实且校准——沿轴预测下游接触参数误差 `≤ ε_a` 的概率 `≥ 1−δ_a`，且 `T_a` 为可靠度上界；**(A38)** 共因模型诚实且冲突残差是有效新颖度统计量——`ξ_a > ξ_max` 蕴含 `g_a > 1 ∨ reg_a = 0` 的概率 `≥ 1−δ_ξ`，融合**不假设**条件独立；**(A39)** 正交探针在给定属性下条件独立、且非破坏。则：
1. **属性级健全性**：若 `G-ok(c)`，则 `P(fail(c)) ≤ Σ_{a∈P(c)}(δ_a + γ_a) + δ_probe + ε_fuse`，`ε_fuse` 为共因模型误设惩罚；
2. **新颖性单调性**：`g_a` 或 `ξ_a` 增大时 `G-ok` 的可接受集单调收缩——系统不会因"更陌生"而"更敢承诺"；
3. **不可全局泛化（下界）**：不存在分布无关、对任意新物体的统一保证；`J_g` 只能是条件保证，且**轴间纠缠会使上界退化**（见第 6 节）。

## 2. 关键算法伪代码（完整版见产物区）

### IP-133 GOF（Generalization-Ordinated Factorization）

```python
def factorize(o, encoders):
    phi = {a: encoders[a](o) for a in ['geo', 'mat', 'mass', 'art', 'surf']}
    g = {a: dist(phi[a], S[a]) / r[a] for a in phi}          # 泛化坐标
    gamma = {a: 1.0 - T[a](g[a]) for a in phi}               # 迁移间隙
    return PropertyBundle(phi=phi, g=g, gamma=gamma)
```

### IP-134 CMF（Conflict-aware Multimodal Fusion）

```python
def fuse_multimodal(obs, axes, common_cause_prior):
    post, xi = {}, {}
    for a in axes:
        factors = [f for m in obs if obs[m].in_regime.get(a, False)]
        post[a], c = factor_graph_infer(factors, common_cause_prior[a])  # 共因，不独立
        xi[a] = max(cross_predict_residual(obs, post[a], a) for m in obs)
    return post, xi, regime_map(obs)
```

### IP-135 G-Gate（泛化门）

```python
def generalization_gate(c, bundle, fused, cfg):
    for a in load_bearing(c):
        supported  = bundle.g[a] <= 1.0 and bundle.gamma[a] <= cfg.gamma_max
        orthogonal = (fused.reg[a] and fused.xi[a] <= cfg.xi_max
                      and has_orthogonal_evidence(c, a, fused))
        if not (supported or orthogonal):
            return GateReject(a, reason='unsupported_and_unprobed')
        if fused.xi[a] > cfg.xi_max:
            return GateReject(a, reason='unresolved_conflict')
    return GateOk()
```

### IP-136 XAP（跨模态主动探询）

```python
def cross_modal_probe(c, bundle, fused, budget, cfg):
    a_star = max(load_bearing(c), key=lambda a: max(bundle.gamma[a], fused.xi[a]))
    best = None
    for m in modalities:
        if not in_valid_regime(m, a_star): continue
        w = 1.0 if orthogonal_to(m, dominant_modality(a_star), a_star) else cfg.w_orth
        score = w * voi_pessimistic(m, a_star, bundle) - cost(m) - cfg.lam * risk_probe(m)
        if best is None or score > best[1]: best = (m, score)
    return best[0] if best and best[1] >= cfg.theta_voi else None
```

### IP-137 GEC（泛化证书）

```python
def generalization_certificate(c, bundle, fused, probe_log, cfg):
    for a in load_bearing(c):
        ok = (bundle.g[a] <= 1.0 and bundle.gamma[a] <= cfg.gamma_max) \
             or orthogonal_corroborated(a, fused, probe_log, cfg)
        if not ok:                  return ('reject', 'axis_unsupported', a)
        if fused.xi[a] > cfg.xi_max: return ('reject', 'unresolved_conflict', a)
    if novelty_verdict(c, bundle, fused) == 'reject':
        return ('reject', 'novel', None)
    return ('ok', GenCert(c, load_bearing(c), bundle.g, bundle.gamma,
                          fused.xi, fused.reg, probe_log, conditional_on='A37'))
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| GOF | O(|A|·d_enc) | O(|A|·d_z + |S_a|) | 每轴支撑/距离与迁移界诚实（A37） |
| CMF | O(|M|·d_φ + |E_fg|) | O(|φ|+|c|) | 共因模型不假设独立、冲突残差有效（A38） |
| G-Gate | O(|P(c)|) | O(1) | 只放行"有支撑或有正交佐证"的负载轴 |
| XAP | O(|M|·(C_VOI+|E|)) | O(|φ|) | 悲观 VOI、正交约束、预算终止 |
| GEC | O(|P(c)|+|probe_log|) | O(|P(c)|) | 条件证书、拒绝纯新颖、日志完备 |

**核心定理（GCCS）**见定义 137 后：属性级健全性、新颖性单调性、不可全局泛化。要点是**保证被局部化到"本次承诺实际依赖的属性轴"**，并由**正交模态**打破共因，而不是靠一个全局泛化分数。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 属性分解不成立、轴间高度纠缠（同一材料支配视觉透明/触觉柔顺/声学），"正交模态"名不副实 | 高 | 显式共因隐变量 + 冲突残差兜底 + 纠缠轴禁止仅凭"多模态一致"放行 |
| 支撑集 `S_a` 覆盖不到部署长尾，`d_a` 度量本身在错的空间 | 高 | 多表示/多度量集成 + 在线扩展支撑 + 拒绝域校准 |
| 冲突阈值 `ξ_max` 漂移，导致漏报或过度拒承诺 | 中 | 在线校准 + 以实际失效率反馈调节 + 高险强制重测 |
| 跨模态探针本身改变物体（触摸污染、划伤、声学扰动） | 中 | 继承 A34 力帽与非破坏审计 + 探针风险项 `λ·risk_probe` |
| 属性级门导致过度保守、任务成功率下降 | 中 | 只在负载轴设门；可绕行/降档；用 E176 校准松紧 |

## 6. 本轮最大风险

**一句话**：本轮全部保证都压在"接触相关风险可沿少数属性轴分解、且轴间可由正交模态独立取证"这一建模假设上——一旦真实世界的属性高度纠缠（同一材料同时支配视觉透明、触觉柔顺与声学，使所谓"正交模态"其实共享共因），泛化门就会把"同一原因造成的多模态一致"误读为"跨轴独立佐证"，从而在陌生物体上系统性地过度自信；这比第 56 轮"坏证据长寿"更隐蔽，因为证据本身是真的、只是不独立。

| `T_a(g_a), γ_a = 1 − T_a(g_a)` | 轴迁移可靠度上界与泛化间隙 |
| `P(c) ⊆ {geo,mat,mass,art,surf}` | 承诺 c 的负载属性集 |
| `M = {RGB,depth,tactile,audio,proprio,thermal}` | 模态集合 |
| `c` | 共因隐变量（如"真实材料"），建模模态相关误差 |
| `reg_{m,a} ∈ {0,1}` | 模态 m 在属性 a 上的适用域指示 |
| `ξ_a = max_{m→m'} ξ_{m→m'}(a)` | 属性 a 的跨模态预测/冲突残差 |
| `OE_a(c)` | 正交模态对轴 a 的独立佐证 |
| `VOI_pess(π; a*)` | 指向最紧轴 a* 的悲观信息价值 |
| `w_orth, ξ_max, γ_max` | 正交折扣、冲突阈值、泛化间隙阈值 |
| `J_g(c)` | 逐承诺泛化证书（条件于 A37） |

## 2. 关键算法伪代码

### IP-133 GOF（Generalization-Ordinated Factorization）

```python
AXES = ['geo', 'mat', 'mass', 'art', 'surf']

def factorize(o, encoders, support):
    phi = {a: encoders[a](o) for a in AXES}
    g   = {a: support[a].dist(phi[a]) / support[a].radius for a in AXES}
    gamma = {a: 1.0 - support[a].T(g[a]) for a in AXES}   # 迁移间隙
    return PropertyBundle(phi=phi, g=g, gamma=gamma)

def extend_support(support, a, phi_a, evidence):
    # 只有通过事后探针/实测校准的证据才扩张支撑边界；否则只记录不扩张
    if evidence.calibrated:
        support[a].expand(phi_a, radius=evidence.conf_radius, source=evidence.src)
    return support
```

### IP-134 CMF（Conflict-aware Multimodal Fusion）

```python
def fuse_multimodal(obs, axes, common_cause_prior):
    """obs: {m: (evidence, {a: in_regime})}；不假设模态条件独立。"""
    post, xi, reg = {}, {}, {}
    for a in axes:
        active = [m for m in obs if obs[m].in_regime.get(a, False)]
        reg[a] = {m: (m in active) for m in obs}
        # 共因 c 吸收"同一物理原因同时驱动多模态"的相关误差
        post[a], c = factor_graph_infer(active, obs, common_cause_prior[a])
        xi[a] = max(cross_predict_residual(obs[m], post[a], a) for m in active) if active else INF
    return post, xi, reg

def cross_predict_residual(obs_m, post_a, a):
    # 用模态 m 的后验去预测别的模态在轴 a 上应有观测，再与实测比
    pred = forward_model(obs_m.modality, post_a, a)
    return norm(pred - obs_m.observed[a])
```

### IP-135 G-Gate（属性级泛化门）

```python
def load_bearing(c):
    if c.kind == 'foothold': return {'mass', 'mat'}
    if c.kind == 'grasp':    return {'geo', 'surf'}
    if c.kind == 'push':     return {'mass', 'art'}
    return {'geo', 'mat', 'mass'}

def generalization_gate(c, bundle, fused, cfg):
    P = load_bearing(c)
    for a in P:
        supported  = bundle.g[a] <= 1.0 and bundle.gamma[a] <= cfg.gamma_max
        orthogonal = (all(fused.reg[a].values()) is False and
                      fused.xi[a] <= cfg.xi_max and
                      has_orthogonal_evidence(c, a, fused, cfg))
        if not (supported or orthogonal):
            return GateReject(a, 'unsupported_and_unprobed')
    for a in P:
        if fused.xi[a] > cfg.xi_max:
            return GateReject(a, 'unresolved_conflict')
    return GateOk()
```

### IP-136 XAP（泛化导向跨模态主动探询）

```python
def cross_modal_probe(c, bundle, fused, budget, cfg):
    P = load_bearing(c)
    a_star = max(P, key=lambda a: max(bundle.gamma[a], fused.xi[a]))  # 最紧轴
    m0 = dominant_modality(a_star, fused)
    best = None
    for m in MODALITIES:
        if not in_valid_regime(m, a_star): continue
        w = 1.0 if orthogonal_to(m, m0, a_star) else cfg.w_orth
        score = (w * voi_pessimistic(m, a_star, bundle)
                 - cost(m) - cfg.lam * risk_probe(m))
        if best is None or score > best[1]: best = (m, score)
    if best is None or best[1] < cfg.theta_voi: return None
    budget.spend(best[0])
    return best[0]
```

### IP-137 GEC（泛化证书）

```python
def generalization_certificate(c, bundle, fused, probe_log, cfg):
    P = load_bearing(c)
    axes = {}
    for a in P:
        supported = bundle.g[a] <= 1.0 and bundle.gamma[a] <= cfg.gamma_max
        orthogonal = orthogonal_corroborated(a, fused, probe_log, cfg)
        if not (supported or orthogonal):
            return ('reject', 'axis_unsupported', a)
        if fused.xi[a] > cfg.xi_max:
            return ('reject', 'unresolved_conflict', a)
        axes[a] = AxisCert(g=bundle.g[a], gamma=bundle.gamma[a],
                           xi=fused.xi[a], reg=fused.reg[a],
                           orthogonal=orthogonal)
    if novelty_verdict(c, bundle, fused) == 'reject':
        return ('reject', 'novel', None)
    return ('ok', GenCert(obj=c.obj, load_bearing=P, axes=axes,
                          probe_log=probe_log, conditional_on='A37'))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| GOF | O(\|A\|·d_enc + \|A\|·\|S_a\|) | O(\|A\|·d_z + Σ\|S_a\|) | 每轴支撑/距离与迁移界诚实（A37） |
| CMF | O(\|M\|·d_φ + \|E_fg\|) | O(\|φ\|+\|c\|+\|M\|) | 共因模型不假设独立、冲突残差有效（A38） |
| G-Gate | O(\|P(c)\|) | O(1) | 只放行"有支撑或正交佐证"的负载轴 |
| XAP | O(\|M\|·(C_VOI+\|E\|)) | O(\|φ\|) | 悲观 VOI、正交约束、预算终止 |
| GEC | O(\|P(c)\|+\|probe_log\|) | O(\|P(c)\|) | 条件证书、新颖否决、日志完备 |

**正确性定理（Generalization-Conditional Commitment Soundness, GCCS）**

假设 A22–A28（第 53/54 轮）、A29–A36（第 55/56 轮）成立，并新增：
- **(A37)** 轴迁移可靠度诚实且校准：沿轴 `a` 预测下游接触参数误差 `≤ ε_a` 的概率 `≥ 1−δ_a`，`T_a` 为可靠度上界；
- **(A38)** 共因模型诚实且冲突残差是有效新颖度统计量：`ξ_a > ξ_max ⇒ g_a > 1 ∨ reg_a = 0` 的概率 `≥ 1−δ_ξ`，融合**不假设**条件独立；
- **(A39)** 正交探针在给定属性下条件独立，且继承 A34 非破坏。

则：

1. **属性级健全性**：若 `G-ok(c)`，则 `P(fail(c)) ≤ Σ_{a∈P(c)}(δ_a + γ_a) + δ_probe + ε_fuse`，其中 `ε_fuse` 为共因模型误设惩罚；
2. **新颖性单调性**：`g_a` 或 `ξ_a` 增大时 `G-ok` 的可接受集单调收缩（不存在"越陌生越敢承诺"的路径）；
3. **冲突不可掩盖**：任何 `ξ_a > ξ_max` 的负载轴使证书直接拒绝，无论后验均值多自信；
4. **不可全局泛化（下界）**：不存在分布无关、对任意新物体的统一 `P_safe ≥ 1−ε` 保证；`J_g` 只能是条件保证，且轴间纠缠使 `ε_fuse` 增大、上界退化。

关键：**保证被局部化到本次承诺实际依赖的属性轴**；**正交模态是打破共因的唯一手段**；**冲突残差优先于后验均值**——后验再自信，只要跨模态预测对不上，就不放行。

## 6. 本轮最大风险

**一句话**：本轮全部保证都压在"接触相关风险可沿少数属性轴分解、且轴间可由正交模态独立取证"这一建模假设上——一旦真实世界的属性高度纠缠（同一材料同时支配视觉透明、触觉柔顺与声学，使所谓"正交模态"其实共享共因），泛化门就会把"同一原因造成的多模态一致"误读为"跨轴独立佐证"，从而在陌生物体上系统性地过度自信；这比第 56 轮"坏证据长寿"更隐蔽，因为证据本身是真的、只是不独立。
