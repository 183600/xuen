# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「行为树」×「移动操作」）

> 第 57 轮把"证据是否可信"做成了分层判定：元少样本推断给效率、共形带给保底、跨模态对账给不一致下限、个性化信任状态给人类维度。但它默认了两个从未被写进形式化的前提：**(i) 执行器是一个顺序过程**——PCE+ 隐含假设"检查点→推理→对账→承诺"按代码顺序发生，遇到突发障碍、抓取滑移、电量骤降时由谁抢占、抢占后证据门是否仍然生效，没有任何结构保证；一个写在主循环里的 `if evidence_gate(...)` 只要被一次异常回退或恢复子树绕过，整套证书就作废。**(ii) 动作空间只有移动**——探针是"脚踩一下"，证据是"这块地形能不能承重"；一旦机器人伸手去抓、去撑、去放，基座与机械臂共享同一套质量、支撑多边形与接触力，**未加载时测到的地形证据不能迁移到加载后的操作**，而"把手臂当探针"又会反过来改变被测量的力学状态。本轮两个灵感正好各补一个缺口：**行为树**把证据门从"外墙检查"变成"执行结构本身"——每个节点携带证据契约，不可逆动作只能是被门支配的密封叶，恢复子树同样过门；**移动操作**把风险从"地形承重"扩展为"负载条件化的全身耦合风险"——证据按负载/伸展/支撑模式分账，借力支撑既是安全手段又是消耗恢复容量的承诺。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为**"证据契约可组合、负载条件可追溯、恢复预算可守恒的全身证据执行"**。

核心矛盾：
- **H29（局部契约 vs 全局安全）**：行为树的模块化让每个子树都能声明自己的前/后置条件与风险等级，但安全是全局性质；Sequence/Fallback/Parallel 的组合、优先级抢占、以及"恢复子树"都可能在局部契约都成立时拼出一条全局危险路径——尤其当恢复动作本身比它要挽救的失败更危险时，Fallback 就成了"用更大的赌注掩盖小失败"。
- **H30（全身耦合 vs 证据迁移）**：移动操作把基座、机械臂、被持物绑成一个动力学整体；风险不再可加，支撑裕度与可操作度相互挤压。更致命的是证据的**负载条件性**：空载轻踩得到的"可承重"不蕴含"伸臂+持物时仍可承重"，而手臂触探本身会改变接触力与质心——观测者与被观测系统耦合，同一动作不能既当探针又当支撑。
- **H31（反应式抢占 vs 不可逆承诺）**：行为树以高频 tick 做反应式仲裁，而元推断、跨模态对账、L2 同意都是慢过程；若让快 tick 随意抢占慢推理，会在证据尚未闭合时进入不可逆接触；若让慢推理阻塞快 tick，又会在突发失稳时错过反射窗口。必须区分"可抢占的可逆动作"与"不可抢占的密封承诺"，并在二者之间设同步屏障。

## 0. 直觉与动机

**灵感 1（行为树 → 证据门成为执行结构，而非执行外层的 if）**
直觉：把安全门写成主循环里的一个检查，就像把刹车装在驾驶座旁边而不是车轮上——正常路径有效，一旦司机换人（异常回退、恢复子树、云端更新）就可能被绕过。行为树的正确用法不是"在上面加一层决策树"，而是**把契约下沉到每个节点**：Action 节点声明 `(前置条件, 后置条件, 必需证据类, 风险等级, 是否可抢占, 风险预算)`；证据门是 Decorator/Condition 节点，不可逆动作是**密封叶（sealed leaf）**——一旦开始不可被抢占，只有后置条件满足才返回 Success。于是安全性变成一个**图上的支配关系**：每一条从根到 L2 危险叶的路径都必须经过一个覆盖其必需证据的门节点。这个性质可以在部署前静态检查、在每次子树更新后重验，而不是靠代码审阅者的记忆。

**灵感 2（移动操作 → 负载条件化的证据与全身风险包络）**
直觉：移动操作不是"移动 + 操作"两件事相加，而是"用一个会走路的身体去施力"。一个区域"能站稳"与"能边站稳边把 3 kg 物体举到 1.2 m 外"是两个不同的命题；前者的证据不能自动给后者背书。因此证据必须带**负载标签** λ=(被持物质量/惯量, 伸展半径, 支撑模式, 接触力上限)：`EV-probe*(λ)` 只在同一 λ 类内有效；跨类使用不是"证据弱一点"，而是**没有保证**。同时定义**可操作-稳定包络** ℰ：支撑裕度 ≥ m0、可操作度 ≥ μ0、可达裕度 ≥ r0 的全身状态集合；任何承诺动作在其预测轨迹上都必须留在 ℰ 内。风险会计采用**不对称原则：收益不入账，代价必入账**——借力支撑对稳定性的好处必须另行证明才可减扣风险，而它占用手臂、增加接触、降低恢复能力的代价必须立刻计入。

**灵感 3（借力支撑 → 双刃与恢复容量）**
直觉：在斜坡上伸手撑住岩壁能显著降低摔倒概率，但这一刻起机器人多了一个"不能马上离开"的接触点：撑住时手臂不能去抓物体，撑点打滑时会被动失去平衡，快速撤离又可能造成新的失稳。借力是**用恢复容量换稳定裕度**。因此引入**恢复容量 RC**（当前状态下仍可行的、证据可支撑的逃生动作的数量与质量），并把"RC ≥ RC_min"作为硬不变量；支撑接触必须证明**可释放性**（力低于阈值、释放时间有界、释放后仍在包络内），承载型支撑若不可快速释放，则升级为 L2 密封承诺。还有一个容易被忽视的陷阱：**同一接触不能既当探针又当支撑**——支撑改变接触力与质心，用它测出的"承重证据"是被自己行为污染的自证证据，除非在时间上解耦并显式声明。

**灵感 4（恢复不是免费的 → 恢复预算与良基回退）**
直觉：Fallback 的自然语义是"这个不行就试那个"，但"那个"若是未探明的捷径，Fallback 就变成了绕过证据门的后门。恢复动作必须**自己过证据门、自己花风险预算、自己占用恢复容量**；全局预算中必须预先划出**恢复储备**，且不能被正常承诺挪用。更进一步，恢复链必须有**良基排名函数**：每次恢复要么严格减少某个进度度量、要么严格增加证据量，否则系统会陷入"恢复→失败→再恢复"的循环。安全不是"有 Fallback"，而是"Fallback 也是一个被证明的动作"。

**灵感 5（两灵感合流 → 双速率执行器与可验证行为树证书）**
直觉：行为树负责高频反应与结构可验证，证据栈负责低频推理与承诺资格；二者用**同步屏障**连接——快 tick 只做包络检查、密封节点推进与可逆反射；任何 L2 承诺必须等慢推理与同意闭合，在同一屏障处由两条速率共同签字。行为树本身成为一个证书 `J_bt`：图结构、节点契约、门支配关系、预算账本、可抢占映射、恢复储备计划、包络版本，任一子树更新都使旧证书失效。云端下发的新子树沿用第 57 轮"一切判定器走隔离"：影子模式跑契约重验与回归测试，通过后才接管。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（证据契约行为树 ECBT）** 行为树 `BT=(N,E,type,root)`，节点类型 `{Seq,Fall,Par,Dec,Action,Cond,Gate}`。每节点 `n` 携带契约 `K_n=(pre_n,post_n,E_n,ρ_n,ab_n,b_n,seal_n)`：`E_n` 必需证据类集合，`ρ_n∈{L0,L1,L2}` 风险等级，`ab_n` 是否可抢占，`b_n` 风险预算，`seal_n` 是否密封。tick 语义 `τ_n(x,B)∈{Success,Failure,Running}`，`Running` 携带节点记忆。**结构安全不变量 SI**：(a) 每条根→L2 叶路径存在门节点 `g` 支配该叶且 `E_g` 覆盖该叶必需证据；(b) 密封叶在 `Running` 期间不可被抢占，只有 `post` 成立才推进；(c) 恢复子树同样满足 (a)(b)，且其预算从 `res_rec` 支出。**无旁路引理**：若 SI 成立且运行期尊重前置条件，则任一实际执行的 L2 叶都在当前 tick 或其未过期的持久证书内通过过对应门；`P(旁路) ≤ P(契约漂移)+P(结构重验遗漏)`。

**定义 140（全身耦合风险 WBR 与可操作-稳定包络）** 全身状态 `x=(q_b,q_a,o)`，动作 `a=(a_loco,a_man)`。风险采用保守分解
`R_total(x,a) ≤ R_loco(q_b,a_loco)+R_man(q_a,o,a_man)+R_cpl(q_b,q_a,o,a)`，
其中 `R_cpl≥0` 由质心相对支撑多边形裕度、接触反力可行域、伸展引起的转动惯量变化三项取最大。**收益不入账**：借力等耦合收益只有在单独证书下才允许从 `R_total` 扣除，否则一律按 0 收益计。**包络** `ℰ_{μ0,m0,r0}={x: μ(x)≥μ0 ∧ margin_support(x)≥m0 ∧ margin_reach(x)≥r0}`；承诺动作 `a` 可采纳当且仅当其预测执行轨迹 `{x_t}` 全程在 `ℰ` 内（末端用保守驻留时间上界外推）。证据的**负载类** `λ(a)=(payload,reach,support_mode,force_cap)`；证据 `e` 对 `a` 有效当且仅当 `λ(e)=λ(a)` 且 `age(e)≤τ_stale(λ)`；跨负载类迁移不提供保证（不是弱保证）。

**定义 141（借力支撑 BC 与恢复容量）** 支撑接触 `c=(point,force_share,release_time,load_bearing)`，分 `B0` 被动轻触（不承载、可快速释放）、`B1` 主动承载且可快速释放、`B2` 承载且不可快速释放（升为 L2）。**可释放性证明** `Rel(c)`：`release_time≤τ_rel ∧ force_share≤F_rel ∧ release 后 x∈ℰ`。**恢复容量** `RC(x)=|{r∈Recovery: admissible(r,x)}|` 的加权版（按代价与证据质量加权）；硬不变量 `RC(x)≥RC_min`。规则：(R4) `B1/B2` 必须 `Rel(c)∨seal`，且 `RC(x)−cost_RC(c)≥RC_min`；(R5) 同一接触若同时声明"探针"与"支撑"，其证据值置零，除非时间解耦且 `|t_probe−t_brace|≥τ_decouple`；(R6) 支撑收益不许自动抵扣 `R_total`，须由 `C_cpl` 单独证明。

**定义 142（恢复预算与无免费恢复 NFR）** 全局预算 `B` 分为 `b_commit` 与 `res_rec`，`res_rec` 不被正常承诺挪用。恢复动作 `r` **可采纳**当且仅当：(i) `r` 过自身证据门；(ii) `R(r)≤ρ_rec·R(failure)`（恢复不得比它挽救的失败更危险）；(iii) `r` 后 `RC≥RC_min`；(iv) 存在良基排名 `φ`，`r` 使 `φ` 严格下降或证据量严格上升。恢复子树不得引用"未来会补的证据"来为当前 L2 动作背书。**无免费恢复定理**：在 (i)–(iv) 下，任何 Fallback 的成功都不蕴含"绕过了一次未满足的证据门"。

**定义 143（行为树-全身证书 J_bt）** `J_bt=(BT 图, {K_n}, 支配关系证明, 预算账本 b_commit/res_rec, 门覆盖映射, 可抢占映射, 包络版本 ℰ, 负载类表, RC_min, 良基排名 φ, 回归测试记录)`。任一节点契约、边、优先级、包络或负载类表变更即令 `J_bt` 失效并触发重验；云端更新在影子模式重验通过前不得接管承诺。`J_bt` 与第 57 轮 `J_p` 合并为 `J_mm`（移动操作证书），后者是部署放行条件。

**定义 144（全身探-诺-演行为树算子 WMPCE-BT）** 双速率执行器：**快速率**（控制周期）只做 `observ→包络检查→密封节点推进→可逆反射`；**慢速率**（按需）做元少样本推断、跨模态对账、L2 同意与负载类证据补采。**同步屏障**：任一 L2 承诺必须在屏障处同时满足快侧包络与慢侧证据门，二者签字后才把密封叶置为 `Running`；屏障未闭合时快侧只允许进入"保持安全姿态/可逆撤离"的恢复子树。检查点循环仍为探询→承诺→演化，但**承诺不再是一个函数调用，而是一次结构性屏障**。终止性由 `b_commit+res_rec` 有限与良基 `φ` 共同保证，终态为 `{承诺成功, 替代路径, L2 协商, 安全停}`。

```python
def tick_node(n, x, B):                       # IP-139: 契约化 tick
    if n.sealed and n.mem.state == 'RUNNING': # 密封叶不可抢占
        return advance_atomic(n, x) if n.post(x) else ('RUNNING', n.mem)
    if n.type == 'gate':
        return tick_node(n.child, x, B) if evidence_gate(n.E, x, B) else ('FAILURE', None)
    if n.type == 'fallback':
        for c in n.children:
            if not pre(c, x): continue
            st, _ = tick_node(c, x, B)
            if st != 'FAILURE': return st, None
        return ('FAILURE', None)
    if n.type == 'action':
        if not (pre(n, x) and in_envelope(x, IP140) and B.has(n.b)): return ('FAILURE', None)
        return run_action(n, x, B)
    ...

def whole_body_admit(x, a, B, M):            # IP-140/141: 全身承诺准入
    if not in_envelope(x, M.env): return reject('outside_ms_envelope')
    R = r_loco(x,a) + r_man(x,a) + r_cpl(x,a)          # 收益不入账
    if R > B.commit_left: return reject('budget')
    if not evidence_gate(need_evidence(a), x, M, lam=load_class(a)):
        return reject('load_conditioned_evidence')
    if a.kind == 'brace':
        if not (Rel(a) or a.seal): return reject('brace_not_releasable')
        if RC(x) - cost_RC(a) < M.RC_min: return reject('recovery_reserve')
    return commit(a, R)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| ECBT | O(\|π\|) 每 tick（π 为活动路径） | O(\|N\|) | 门支配静态可查、密封叶不可抢占（A41） |
| WBR | O(d_x+\|contact\|)/动作 | O(\|ℰ\| 预计算) | 耦合界保守、包络成员判定诚实（A43） |
| BC | O(\|brace\|) | O(\|contact\|) | 可释放性证明、RC 不变量（A41/A43） |
| NFR | O(\|Recovery\|) | O(\|Recovery\|) | 恢复过门、预算预留、φ 良基（A42） |
| J_bt | O(\|N\|·\|CP\|) 重验 | O(\|N\|+\|CP\|) | 任一变更即失效、影子模式 |
| WMPCE-BT | O(\|CP\|·(\|π\|+k_p·d_φ+\|ℳ\|²)) | O(\|V\|+\|σ\|+\|N\|) | 双速率屏障、密封原子性（A41–A44） |

**正确性定理（Whole-body Composable Soundness, WCS 概要）**：在 A33–A40 之上加 (A41) ECBT 结构不变量与密封叶原子性、可抢占映射诚实；(A42) 预算单调、恢复储备不可挪用、恢复动作过门且 φ 良基；(A43) 全身耦合界保守、包络判定与负载类声明诚实、RC 计算保守；(A44) 负载条件证据仅在同类使用，跨类使用显式禁用，支撑/探针时刻解耦诚实。则：
(i) **无旁路**：任一实际执行的 L2 动作都在屏障处通过了对应证据门，旁路概率 ≤ P(契约漂移)+P(结构重验遗漏)；
(ii) **负载条件健全**：操作失败率只被同负载类证据约束，`P(fail_man) ≤ δ_f+ε_meta+δ_probe+δ_grasp+ε_h+δ_ood·α_conf`；跨类迁移项被移除而非被低估；
(iii) **恢复健全与活性**：无免费恢复；在有限预算与良基 φ 下，执行在 `|CP|` 个检查点与有限 Recovery 步内终止于 `{承诺, 替代, 协商, 安全停}`，不存在无进展恢复环；
(iv) **部署界**：对检查点与恢复步取联合界，
`P_safe ≥ 1 − Σ(δ_f+ε_meta+δ_probe+δ_grasp+ε_h+δ_ood·α_conf+δ_xm·1[L1]) − P(契约漂移) − P(包络/RC 估计错误) − P(屏障超时∧安全停失效)`。

## 6. 本轮最大风险

**一句话**：行为树的组合能力会把"局部都过了门"的节点拼成一条从未被整体证明过的危险路径，而移动操作又让"这条路径上的证据"带上负载条件——如果门支配检查、负载类分账或恢复储备三者有一个被实现偷懒，行为树就会从"安全执行骨架"退化成"把未证明承诺洗白的结构化机器"；必须用可静态检查的 J_bt、负载条件证据的跨类禁用、以及不可挪用的恢复预算三道硬约束守住，宁可退回可逆反射与安全停，也不让 Fallback 用更大的赌注掩盖小失败。

### IP-139 ECBT（证据契约行为树，门支配与密封叶）

```python
def tick_node(n, x, B, M):
    if n.sealed and n.mem.state == 'RUNNING':        # 密封叶：不可抢占
        if n.post(x): return ('SUCCESS', None)
        return advance_atomic(n, x)                  # 只前进，不接受 recover 抢占
    if n.type == 'gate':                             # 证据门装饰器
        if not evidence_gate(n.E, x, M, lam=n.lam):  # 负载条件化
            return ('FAILURE', None)
        return tick_node(n.child, x, B, M)
    if n.type == 'sequence':
        for c in n.children:
            if not pre(c, x): return ('FAILURE', None)
            st, mem = tick_node(c, x, B, M)
            if st != 'SUCCESS': return (st, mem)
        return ('SUCCESS', None)
    if n.type == 'fallback':                         # 每个候选也须 pre + 证据门
        for c in n.children:
            if not (pre(c, x) and B.has(c.b)): continue
            st, mem = tick_node(c, x, B, M)
            if st != 'FAILURE': return (st, mem)
        return ('FAILURE', None)
    if n.type == 'action':
        if not (pre(n, x) and in_envelope(x, M.env)): return ('FAILURE', None)
        if n.risk == 'L2' and not n.gated: return ('FAILURE', None)   # 结构违约
        return run_action(n, x, B, M)
    return ('FAILURE', 'unknown_node_type')

def check_structure(bt):                             # 部署前/更新后静态重验
    for leaf in l2_leaves(bt):
        assert any(g.type == 'gate' and dominates(g, leaf)
                   and covers(g.E, need(leaf)) for g in nodes(bt))
        assert leaf.seal and not leaf.abortable              # L2 必须密封
    for sub in recovery_subtrees(bt):
        assert gates_dominate_l2(sub) and budget_of(sub) <= bt.res_rec
    assert well_founded(bt.recovery_edges, bt.phi)
    return True
```

```python
def whole_body_risk(x, a):
    r_loco = risk_locomotion(x.q_b, a.loco)
    r_man  = risk_manipulation(x.q_a, x.o, a.man)

def in_envelope(x, env):

            support_margin(x) >= env.m0 and

def trajectory_stays_inside(x0, a, env, horizon):

        if not in_envelope(x_t, env): return False
    return True
```

```python
def wmpce_bt(x0, bt, M, task, consent, persona, budget):
    route = plan_on_map(M, task, risk_model)
    for cp in route.checkpoints:
        inf = meta_few_shot_infer(M, cp.region, M.obs[cp.region], meta)
        M.b[cp.region] = inf.post if inf.cls == 'ID' else worst_in(inf.belt)
        while True:
            x = observe_whole_body()
            # 快速率：包络与反射；任何 L2 承诺必须走同步屏障
            if not in_envelope(x, M.env):
                if not run_fast_reflex(bt.recovery, x, budget, M):
                    return safe_stop(x, 'envelope_violation')
                continue
            st, _ = tick_node(bt.safety, x, budget, M)     # 只含可逆与监测
            if st == 'FAILURE':
                return safe_stop(x, 'safety_tick_failure')
            a = bt.select(task, x, M)
            if a.risk != 'L2':
                tick_node(bt.execute(a), x, budget, M)
                if progress(cp, x): break
                continue
            # 慢速率：负载条件证据 + 同意 + 预算，在屏障处合流
            if not evidence_gate(need(a), x, M, lam=load_class(a)):
                p = argmax(admissible_probes(cp, M),
                           key=lambda q: voi_meta_pessimistic(q, M, inf) - cost(q))
                if voi_meta_pessimistic(p, M, inf) < theta_voi:
                    route = reroute_or_stop(M, cp, consent)
                    break
                M, _, D = xmodal_fuse(M, cp.region, execute_probe(p, cap=F_abs))
                if D > theta_D and 'consensus' not in cp.done:
                    p2 = most_disagreeing_modality_probe(M, cp.region)
                    M, _, D = xmodal_fuse(M, cp.region, execute_probe(p2, cap=F_abs))
                    cp.done.add('consensus')
                continue
            if not consent.resolved(a) and not negotiate(a, tau_int(persona.auth)):
                return safe_stop(x, 'L2_denied_or_timeout')
            if not whole_body_admit(x, a, budget, M)[0]:
                return safe_stop(x, 'whole_body_reject')
            barrier_commit(a)                              # 快慢共同签字后密封
            if progress(cp, observe_whole_body()): break
        if budget.exhausted(): return safe_stop(x, 'budget')
    return 'done', M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| ECBT | O(\|π\|)/tick；结构检查 O(\|N\|+\|E\|) | O(\|N\|) | 门支配、密封原子性（A41） |
| WBR | O(d_x+\|contact\|)/动作 | O(\|ℰ\|) 预计算 | 耦合界保守、包络诚实（A43） |
| BC | O(\|brace\|) | O(\|contact\|) | 可释放性、RC 不变量（A41/A43） |
| NFR | O(\|Recovery\|) | O(\|Recovery\|) | 恢复过门、储备独立、φ 良基（A42） |
| J_bt | O(\|N\|·\|CP\|) 重验 | O(\|N\|+\|CP\|) | 变更即失效、影子回归 |
| WMPCE-BT | O(\|CP\|·(\|π\|+k_p·d_φ+\|ℳ\|²)) | O(\|V\|+\|σ\|+\|N\|) | 双速率屏障、密封原子性（A41–A44） |

**正确性定理（Whole-body Composable Soundness, WCS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** ECBT 结构不变量 SI 成立，密封叶不可抢占且可抢占映射诚实；**(A42)** 预算单调、`res_rec` 不被承诺挪用、恢复动作过门且 `φ` 良基；**(A43)** 全身耦合界保守（`R_total≤R_loco+R_man+R_cpl`）、包络与 RC 判定诚实、收益不入账；**(A44)** 负载条件证据仅在同类使用、支撑/探针解耦诚实、跨类迁移被禁用。则：

1. **无旁路（结构健全）**：任一实际执行的 L2 叶都在同步屏障处通过其门；"恢复/异常路径绕过门"只能以结构违约发生，而结构违约被静态检查与影子重验拦截：
   `P(bypass) ≤ P(契约漂移) + P(结构重验遗漏)`。
2. **负载条件健全**：操作失败率只被同负载类证据约束，
   `P(fail_man) ≤ δ_f + ε_meta(k) + δ_probe + δ_grasp + ε_h(w_max) + δ_ood·α_conf`；
   跨 λ 证据不进入该界（它不是"更宽的界"，而是"不成立的界"）。
3. **恢复健全与活性**：无免费恢复；每次恢复使 `φ` 严格下降或证据严格增加，且花独立储备，故不存在无进展恢复环；执行在 `|CP|` 个检查点与有限恢复步内终止于 `{承诺成功, 替代路径, L2 协商, 安全停}`。
4. **交互单调性继承与加强**：ECBT 只能通过 (a) 更严格的门/契约、(b) 更保守的包络/RC/预算、(c) 更慢的升级来影响系统；不存在"因为行为树方便所以更敢赌"的通道。
5. **部署界**（对检查点与恢复步取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta + δ_probe + δ_grasp + ε_h
                  + δ_ood·α_conf + δ_xm·1[L1])
             − P(契约漂移) − P(包络或 RC 估计错误)
             − P(屏障超时 ∧ 安全停失效)
```

关键：**门支配把"是否有检查"变成"结构上不可能没有检查"**；**负载类把"证据迁移"从经验问题变成声明问题**（同类才可用，跨类直接禁用）；**恢复储备把"Fallback 的乐观"变成"预先付费的悲观"**。三者合起来，行为树不再只是模块化装饰，而是可静态验证、可审计、可隔离更新的安全执行骨架。

## 6. 本轮最大风险

**一句话**：行为树的组合能力会把"每个局部节点都过了门"拼成一条从未被整体证明过的危险路径，而移动操作又给这条路径上的证据加上负载条件——一旦门支配检查、负载类分账或恢复储备三者有一个被实现偷懒，行为树就会从安全执行骨架退化成"把未证明承诺洗白的结构化机器"；必须以可静态检查的 `J_bt`、负载条件证据的跨类禁用、不可挪用的恢复预算三道硬约束守住，宁可退回可逆反射与安全停，也不让 Fallback 用更大的赌注掩盖小失败。
