# 第 2 轮（UniBot 线 · 第 2 轮；本轮灵感：「通用机器人」×「数据质量」）

> **承接与编号**：第 1 轮建立 UniBot-SAGE（接地层 / 技能层 / 适应层 / 工程层）。本轮**不推倒重来**，编号续用：定义 U13–U21、引理 L8–L13、实验 E619–E633；第 1 轮 U1–U12 / L1–L7 / E601–E618 仍可引用。
> **数据纪律（本轮加强）**：本轮**不新增外部情报**，沿用第 1 轮来源清单。文中凡标 **[sim]** 的数字均为本机可复现的蒙特卡洛/解析结果（numpy，固定随机种子），**不是官方数据**；凡标 “[teaser]” 的仍指第 1 轮那张由 `gen_leaderboard.py` 随机生成的占位表。

## 0. 本轮一句话：先纠错，再换重心

**第 1 轮把最大的赌注（IP-01 技能路由，oracle +4.26）建在了一张官方自己标注为“随机生成”的 teaser 表上；本轮的首要工作不是加新模块，而是承认这个证据链不成立，把研究重心从“在榜单结构上套利”迁移到“用真实数据做可复现的质量度量与通用性度量”。**

一句话路线：**通用性 = 不变性谱 × 组合性**（不是 32 个任务的平均分）；**数据质量 = 与失败因子对齐的“决策相关性”向量**（不是泛泛的“干净”）。于是本轮主线变为：
**质量账本（LADA / DQL / RecoverMine）→ 不变性谱评测（GenProfile）→ 条件化的技能路由（SLot，需先过零假设与样本外检验）**。

## 1. 对第 1 轮的统计复核：为什么必须自我纠错

### 1.1 三处被误读的证据

| 第 1 轮用法 | 问题所在 | 严格结论 |
|---|---|---|
| `step ≈ 1.337·succ + 0.09`，R²=0.9955 ⇒ “两指标共线，只优化终态成功” | 0.9955 更像**生成器构造**（步骤分被写成成功率的函数）而非独立测量；且它完全来自 teaser | 该等式**不能**作为“单一计分货币”的经验证据；该原则只能由**官方评分规则**支撑，不能由 teaser 支撑 |
| 跨任务 Kendall τ 均值 0.064 ⇒ “模型强弱在任务间准正交 ⇒ 通用=技能向量” | **τ 对“加性模型能力”完全不敏感**：若 `s_{tm}=μ+α_t+β_m+γ_{tm}+ε`，则固定模型对 (i,j) 跨任务比较时 `β_i−β_j` 是常数，在 Kendall 比较中整体抵消 ⇒ τ 只反映**交互项 γ 与噪声 ε**，**根本检验不了 β** | “τ≈0 ⇒ 没有单一通用能力”是**错误推断**；τ≈0 与“存在很强的全局能力 β”完全相容。第 1 轮把“交互项小”误读成了“能力不正交” |
| per-task oracle 33.96 vs 最优单模型 29.70 = **+4.26** | 这是**样本内 oracle**（在同一批 256 个点上“事后挑每任务最好的模型”），存在选择偏差；且整表是随机占位表 | +4.26 **不是**可兑现上界；可兑现量是**样本外** `Δ_route^{OOS}`，必须在独立 episode/任务划分上估计 |

### 1.2 可复现的零假设校准 [sim]

以第 1 轮报告的聚合量为参数（32 任务 × 8 模型、任务内跨模型标准差 σ=5.6、每任务均值近似落在 [17.7, 30.3]），在 `s_{tm}=μ_t+σ·ε_{tm}` 的纯噪声零假设下做 5000 次复现：

| 统计量 | 零假设 95% 区间（2.5 / 50 / 97.5 分位） | teaser 观测值 | 读法 |
|---|---|---|---|
| 样本内 oracle − 最优单模型 | −2.76 / +0.28 / +2.69 | +4.26 | 略越界，但**强烈依赖未知的生成参数**（σ、任务均值散布）；参数略变即落入区间内 |
| top-2 混合 − 最优单模型 | −4.30 / −1.34 / +0.98 | +2.52 | 零假设下**中位为负**（“最优单模型”本身就是选择偏差的产物），观测为正说明生成器结构未知 |
| 28 对 Kendall τ 的均值 | 0.113 / 0.201 / 0.288 | 0.064 | 观测甚至**低于**含共同任务难度的零假设 ⇒ 只能说明“交互项弱”，不能说明“无全局能力” |
| τ 的标准差 | 0.076 / 0.105 / 0.140 | ≈0.09–0.10（由范围 [−0.107,0.202] 估） | 与噪声一致 |

**结论**：这些统计量对**未知生成器参数高度敏感**，而该表又被官方注明为随机生成。因此它既不能证伪、也不能证实任何关于“技能专长”的实质假设——它只能当作**字段与任务面的规格说明书**，不能当作**效应量的证据**。

### 1.3 决策相关的量：样本外路由增益 [sim]

真正要问的是：**在独立样本上，按任务选专家还能不能打赢“全局最优单模型”**。做分半检验（用一半 episode 估每个 (任务, 模型) 的均值，在另一半上评估；`Δ_route^{OOS}` = 选中专家 − 全局最优单模型）：

| 交互项标准差 `s_γ`（点） | Δ_route^{OOS} 95% 区间 | 均值 |
|---|---|---|
| 0（纯加性，无专长） | [−0.07, −0.002, 0.00] | −0.016 |
| 2 | [0.41, 0.85, 1.31] | 0.85 |
| 4 | [1.54, 2.53, 3.39] | 2.51 |
| 6 | [3.09, 4.66, 6.08] | 4.66 |
| 8 | [4.90, 7.04, 8.97] | 7.03 |

**读法**：要让 Δ_route^{OOS} ≥ 1.0 分，需要交互项标准差 ≳2.5 点；要 ≥2.5 分，需要 ≳4 点。也就是说，**第 1 轮的 +4.26 是样本内数字，它只有在真实交互项很大时才兑现**；而交互项大小**只能靠分半可靠性检验去测**，τ 测不出来。⇒ **IP-01 从 P0 降级为“条件实验”（见 IP-13），在样本外增益未过门槛前不投入 8×A100×3 天。**

### 1.4 第 1 轮哪些结论仍然成立

- **仍然成立（与 teaser 数值无关）**：①RoboDojo 真机观察“崩在最后对齐 / 插入 / 恢复”，这是独立的跨基准定性证据；②由**任务语义**（Plug In Ethernet / Unlock / Open Pill Bottle 等名字本身）可先验判断“最后一环 = 插入 / 旋转 / 细粒度对齐”，不需要 teaser 分数；③由**接口第一性原理**（Dex1 单自由度、1 维开合、无触觉）推出抓握是隐变量、部分抓法物理不可行。⇒ **IP-02 的最后环节战场判断保留。**
- **降级**：IP-01 的 +4.26 上界、任务难度排序的具体数值、“步骤分与成功率共线”的经验证据。
- **升级为方法论原则**：任何以 teaser 为据的结论，必须配 **置换/分半零假设** 才能写入主线（新原则 P7）。

## 2. 「通用机器人」的第一性原理：通用性 = 不变性谱 × 组合性

**直觉**：一个“通用”机器人不是“在 32 个任务上都会一点”，而是“**把同一套技能，在没见过的扰动下、以没见过的组合方式**仍然管用”。任务数量度量的是**广度（breadth）**，而泛化场景度量的是**不变性（invariance）**，跨任务复用度量的是**组合性（compositionality）**。把三者混成一个平均成功率，会把“宽而脆”的模型误判为“通用”。

**严谨定义**：
- 令 `T_{a,ε}` 为第 a 类扰动的强度 ε 干预算子（a ∈ {位置, 干扰物, 背景, 未见物品, 人扰}），`s(π,x)` 为成功指示。
- **不变性谱（U14）**：`G_a(π) = E_{x∼D}[s(π(T_{a,ε}(x)))] / E_{x∼D}[s(π(x))]`，`I_a(π)=1−G_a(π)` 为不变性缺口。
- **组合性（U15）**：把任务分解为技能图 `G=(V_skills, E_comp)`；`C(π)` = 在数据中**未同时出现过**的技能边上仍能成功的比例（held-out composition）。
- **通用性不是标量**：`Gen(π) = (G_pos, G_dist, G_bg, G_obj, G_human, C)`。它**不是**平均成功率的单调函数（见引理 L13）。

**推论（对策略设计的直接约束）**：
1. 评测必须**主动干预**并报告谱，而不是只报一个平均数；这同时是**数据增广的靶子**（哪个轴最弱，就在哪个轴造数据）。
2. 技能条件化应条件在**估计出的技能/扰动后验**上，而不是“任务 id”。按任务 id 路由 = 32 路记忆，既可能不合规，也**不产生任何不变性**；按潜在技能状态路由 = 组合性。于是我们把 IP-01 改造为 **SLot（IP-13）**：`z_skill` 由语言 grounding + 相位后验 + 扰动估计共同给出，而非 32 类 one-hot。

## 3. 「数据质量」的第一性原理：质量是“决策相关性”向量

**直觉**：数据质量不是“干净 / 脏”，而是“**这段数据能否降低模型在真正会失败的那个决策上的不确定性**”。一段平滑漂亮的搬运轨迹，对“插入失败”可能毫无信息量；一段抖动难看但包含“掉了重抓”的片段，反而价值连城。因此质量必须**按失败因子分解**，并与策略的当前不确定性对齐。

**严谨定义（U17）**：对片段 `s=(episode, 时间窗)`，定义质量向量
`q(s) = (q_time, q_phys, q_view, q_lang, q_cov, q_rec)`，
六维分别对应：时序对齐、物理可行性、多视角一致性、语言 grounding、稀有相位覆盖、恢复内容。
训练权重 `w(s) = f(q(s), u(s))`，其中 `u(s)` 为**数据估值**（对 OOD 验证损失的 TracIn/影响函数估计）。加权风险 `L_w = Σ_s w(s)·ℓ(s)`，并受**有效样本量** `ESS=(Σw)²/Σw²` 约束（见引理 L11）。

**四条具体的、可在真实 32 个数据集上直接验证的质量缺陷假设**：
1. **时序错位（H1）**：遥操采集的 `action_t` 与 `observation_t` 可能相差 δ 帧；多相机之间也可能不同步。策略会把“用旧观测反应”学进权重，**恰好在需要高频反馈的对齐/插入相位致命**。
2. **成功偏差 / 恢复覆盖缺失（H2）**：官方数据几乎全是**成功**演示 ⇒ 失败状态分布极窄，真正的失败（滑移、戳偏、卡住）在训练分布中**没有支持**。这是**覆盖率缺陷**，不是标签噪声；单纯“清洗”无法修，必须**挖掘 + 合成恢复数据**。
3. **语言退化（H3）**：若每任务的语言指令高度模板化/重复，则“语言条件化”实际上不可辨识，VLM 语言分支会退化为任务常数 ⇒ 泛化到改写指令时崩。
4. **视角错配（H4）**：左右腕 / 头 stereo 可能标错或帧不同步；多视角一致性可当作无标签的体检指标。

**关键论断**：H1–H4 中，**H2 是可解释“最后一环瓶颈”的数据侧根因**，而 H1 是“为什么闭环在真机上比离线更差”的隐藏变量。两者都比“再多采 10% 数据”更值得做。

## 4. 研究问题（第 2 轮）

- **Q6（零假设与可复现性）**：teaser 派生的路由红利能否被样本外分半检验与置换零假设复现？若不能，IP-01 应如何降级？
- **Q7（时序对齐）**：obs–action 偏斜 δ 是否可从数据中**可辨识地**估计（逐数据集/逐相机）？校正后，精度相位（grasp/align/insert）的成功率是否提升？
- **Q8（质量账本）**：片段级质量/估值能否比“数据量”更好地预测 OOD 增益？质量加权训练能否在**不牺牲**恢复片段的前提下降低 OOD 风险？
- **Q9（恢复覆盖）**：官方数据里“微恢复”（掉了重抓、戳偏重对齐）占多少？挖掘 + 反事实合成能否补上真实失败分布的支持？
- **Q10（通用性度量）**：不变性谱是否比平均成功率更能预测真机 OOD？它是否稳定（test–retest）且不可被训练增广“刷分”？
- **Q11（条件化路由）**：在**真实**数据/榜单上，按潜在技能状态的条件化能否复现出 OOS 路由增益，且仍在“单 checkpoint、单 API”合规形态内？

## 5. 设计原则（增补与修订）

- **P7（零假设先行，新增）**：任何“红利/上界/相关”结论，必须同时报告**置换零假设**与**样本外（分半/嵌套）**估计；只报样本内数字的结论不得进入主线。
- **P8（质量为向量且任务相关，新增）**：质量不是标量；每条质量轴必须绑定一个失败因子或一个可检验的机制假设（H1–H4）。
- **P9（恢复覆盖优先于数据量，新增）**：在固定采集/训练预算下，优先补“失败→恢复”覆盖，而不是均匀增加成功演示。
- **P10（通用性以不变性谱度量，新增）**：对外报告 `Gen(π)` 谱，不以单一平均成功率作为“通用”的证据。
- **修订 P1**：“单一计分货币”仍作为**优化目标**，但其依据改为**官方评分规则**，不再是 teaser 的共线回归。
- **修订 P3**：技能专家按“**潜在技能/相位**”划分，不按 32 个任务 id 划分；并要求每个专家至少在 2 个任务、且至少 1 个 OOD 轴上被验证复用。
- **P2/P4/P5/P6 保留**：隐状态显式化、推理期吸收偏移、合规优先、单 checkpoint 单 API。

## 6. MVP v2 与退化链

**MVP v2 = LADA（IP-09，时序对齐审计）+ DQL（IP-10，质量账本）+ RecoverMine-lite（IP-11，微恢复挖掘）+ GenProfile（IP-12，不变性谱）+ 第 1 轮 IP-02 抓握状态机 + IP-03 工程层 + 通用 VLA 基线。**
**IP-01/SLot（IP-13）不进 MVP**：先由 E619 的分半检验决定是否投入。

**严格退化链（任一环节不可用 ⇒ 行为回退而非漂移）**：
- L0 质量账本不可用 ⇒ 退回均匀权重 + 全量数据（并显著标注“未审计”）；
- L1 时序对齐估计不可信（δ 不稳定/多峰）⇒ 退回原始对齐（不做平移），只在精度相位改用更短的 chunk（IP-03）；
- L2 恢复挖掘为空 ⇒ 退回纯成功演示策略 + IP-02 的规则式重抓，不做合成；
- L3 GenProfile 评测不可靠 ⇒ 退回真机 A/B 的小样本 + 预注册判据；
- L4 SLot 未过分半门槛 ⇒ 退回单专家 + 潜在技能 token（合规下界）；
- L5 整条新链路失效 ⇒ 退回**纯基线最小提交**（永远保留的安全网）。

## 7. 本轮最大风险（一句话）

**最大的风险是：我们用来定义“质量”和“通用性”的数据本身有偏——质量账本可能合法地把唯一稀缺的恢复/失败片段判成低质而剪掉，不变性谱又可能被与训练同源的增广“刷高分”，于是测量与优化共享同一个盲区，我们越优化越自信地偏离真机 OOD。**

## 8. 下一轮迭代计划（深化与修剪）

- **深化**：把 IP-11 的“微恢复挖掘”升级为“失败状态 → 恢复动作”的条件策略，并与 IP-02 的抓握状态机共用同一套相位/失败标签；把 GenProfile 的 5 轴谱接入 DQL 的数据增广靶向。
- **修剪预案**：若 E620（时序对齐）显示 δ 不稳定或校正后精度相位无增益，则**关闭 LADA 的平移**，只保留“审计报告”；若 E625/E626 显示微恢复样本 <1% 且合成不可迁移，则**放弃 RecoverMine 合成**，只保留真实微恢复的加权。
- **保留项**：IP-02（断点直击）、IP-03（工程确定性）、DQL/GenProfile（测量基础设施）在任何情况下不砍。

## 2. 创新点详述

### IP-09 · LADA：观测–动作时序对齐审计（P0）

- **动机（H1）**：遥操数据的 `action_t` 与 `observation_t` 可能相差 δ 帧（采集延迟、重定向、时间戳抖动），多相机之间也可能不同步。策略若在这批数据上训练，会学成“对旧观测做反应”；而抓握/对齐/插入需要**最短反馈回路**，δ 的偏差恰好在这个相位被放大。这是一条**此前完全没被列入**的数据质量缺陷。
- **与现有做法的差异**：常规做法只做“时间戳对齐/丢帧过滤”；我们把 δ 当作**可辨识参数**去估计，并把“δ 不稳”当作**数据质量信号**（不稳 ⇒ 该数据集/相机不可信）。
- **估计方法**：对每个数据集、每类信号（夹爪开合、EE 位置/速度、腕部图像光流），在候选滞后 `δ ∈ [−K, K]`（如 ±5 帧）上最大化**动作与下一状态变化**的耦合（或最小化一步预测损失）。见 §4 算法与定义 U16。
- **可辨识性**：见引理 L10——响应有唯一峰时 δ 可辨识；周期性动作会混叠，需要跨任务池化 + 多信号交叉验证。
- **所需资源**：数据 = 官方 32 份；算力 = 单卡数小时（只做相关/小回归）；接口 = 无。
- **落地步骤**：①逐数据集解码时间戳与帧号，检查 fps 抖动/丢帧；②三信号分别估 δ，取稳健中位数与 bootstrap CI；③若 CI 宽 >1 帧 ⇒ 标记“不可靠”，不校正；④校正后重算一步预测损失与相位标签一致性；⑤把校正版本作为训练输入，**保留原始版本**做 A/B。
- **风险**：①周期性运动造成 δ 多峰 ⇒ 只能给出集合而非点估计；②过度校正（把真实因果延迟当错位去掉）⇒ 只在多信号一致且 CI 窄时启用；③评测端本身有延迟 δ_eval，训练端校正后仍需用 IP-03 的延迟整形对齐。

### IP-10 · DQL：片段级质量账本 + 数据估值（P0）

- **动机（质量是向量）**：32k 成功演示在“数量”上够，但在**决策相关性**上高度不均：容易的 reach/transport 片段大量冗余，关键的抓握/对齐/恢复片段稀缺；同时存在错位、视角错配、语言模板化等缺陷。均匀训练 = 让冗余淹没关键。
- **与现有做法的差异**：不做“清洗一遍就完”，而是给每个片段打**质量向量 q** 与**数据估值 u**，用它们定义训练权重，并强制**保护恢复片段**（q_rec 高的片段权重有下界，避免被估值误杀）。
- **质量六轴（U17）**：`q_time`（LADA 的 δ 稳定性）、`q_phys`（关节限位/速度/加速度可行性）、`q_view`（多视角重投影一致性）、`q_lang`（指令与视觉/动作的 grounding 一致）、`q_cov`（相位/状态稀有度）、`q_rec`（是否含失败→纠正）。
- **数据估值 u(s)**：用 TracIn/影响函数近似“加入该片段对 OOD 验证损失的边际影响”；与 q 做**收缩加权**（u 噪声大，向 0 收缩），并监控 ESS。
- **加权风险（U18）**：`L_w = Σ_s w(q,u)·ℓ(s)`，`w = clip(exp(λ·û)·g(q), w_min, w_max)`，其中 `g(q)` 对 `q_rec` 设下界。
- **所需资源**：数据 = 官方 32 份；算力 = 中（影响函数需若干次 checkpoint 梯度缓存，可用小模型/小样本近似）；接口 = 无。
- **落地步骤**：①实现六轴度量（纯规则 + 小模型）；②人工抽检 200 片段，估各轴与“是否关键”的一致率；③用一次性小规模 TracIn 估 u；④加权训练 vs 均匀训练 vs 随机剪枝（等预算）三方对照；⑤输出**质量账本报告**（每数据集的质量分布 + 被剪片段的可视化理由）。
- **风险**：①**估值噪声** ⇒ 收缩 + 只用高置信片段加权；②**自噬偏差**（用同一批有偏数据估质量）⇒ 人工抽检锚定 + 保留随机对照；③**误杀恢复片段** ⇒ 对 `q_rec` 设权重下界（这是本 IP 的第一红线）。

### IP-11 · RecoverMine：微恢复挖掘 + 反事实合成（P0）

- **动机（H2，成功偏差）**：官方数据几乎全是成功演示，失败状态（滑移、戳偏、卡住）在训练分布中**没有支持**。而“最后一环”恰恰是策略最需要“失败后怎么办”的地方。第 1 轮 IP-02 只能做规则式重抓；本轮补上**数据侧支持**。
- **与现有做法的差异**：不是简单数据增广（随机裁剪/颜色抖动），而是**任务相关的恢复覆盖**：从成功轨迹内部挖“微失败→纠正”，再合成“更严重失败→纠正”的配对。
- **两阶段**：
  1. **挖掘（可靠）**：用相位状态机 + 夹爪/EE/腕部信号检测“夹爪闭合但物体未随动→重新张开→再接近”这类**微恢复**；这些是真实数据，标签可信。
  2. **合成（需验证）**：对已挖出的恢复点，在状态空间施加**受控扰动**（目标位姿偏移、夹爪提前闭合、插入角度偏斜），用检索到的成功纠正段做配对，构造“失败初态 → 恢复动作”。合成器可离线（轨迹重定向/物理近似）或半离线（少量真机回放）。
- **覆盖度量（U19）**：`R_cov(t) = #(含失败→纠正的 episode)/#(episode)`；按任务/相位统计，定位“恢复覆盖空窗”。
- **所需资源**：数据 = 官方 32 份 + 少量真机回放；算力 = 小；接口 = 无。
- **落地步骤**：①定义微恢复检测器并与 IP-02′ 共用失败标签；②统计 `R_cov` 分布（预期：多数任务接近 0）；③挖掘真实微恢复并做一份人工验证集；④合成恢复段，先离线做“恢复策略在合成初态上的成功率”筛选；⑤只在**难任务**（插入/旋转类）上做真机 A/B，预注册停止条件。
- **风险**：①**合成分布与真实失败不匹配**（最大风险）⇒ 合成只做“难任务的小剂量”并必须真机 A/B 通过；②微恢复样本 <1% ⇒ 放弃合成，只做真实微恢复加权（见剪枝预案）；③扰动可能制造物理不可行状态 ⇒ 加物理可行性过滤器。

### IP-12 · GenProfile：不变性谱 + 组合性度量（P0）

- **动机**：第 1 轮用“32 任务平均成功率”谈通用性；但“宽而脆”的模型平均分可能不低。评测端明确有 5 类泛化场景，正好是**受控干预轴**。通用性应当是**谱**，不是标量。
- **与现有做法的差异**：把评测从“报一个数”改成“报一条谱 + 组合性”，并把谱反过来当作**数据增广的靶子**（哪个轴弱就造哪个轴的数据）和**路由的条件**（IP-13）。
- **定义**：见 U14/U15；`G_a(π)=E[s(π(T_{a,ε}(x)))]/E[s(π(x))]`；组合性 `C(π)` 在“训练中未同时出现的技能边”上评估（用任务/相位先验构造 held-out 组合）。
- **所需资源**：数据 = 官方数据 + 可控合成（位置/背景/干扰物/遮挡）；算力 = 中；接口 = 无。
- **落地步骤**：①实现 5 轴可控干预器（先合成、后真机小样本）；②在基线/各 IP 上测谱；③做 test–retest 与敏感性分析；④检验“谱是否比平均分更能预测真机 OOD”；⑤把最弱轴反馈给 DQL 做定向增广。
- **风险**：①合成干预与真机干预不一致（谱失真）⇒ 用小样本真机锚定；②训练增广与评测增广同源 ⇒ 会“刷分”，必须用**留出增广族**（评测用训练没见过的扰动实现）；③谱维度多、样本少 ⇒ 预注册主分析（最弱轴）避免多重比较。

### IP-13 · SLot：潜在技能状态条件化路由（P1，条件）

- **动机与降级理由**：第 1 轮 IP-01 的 +4.26 是**样本内、随机 teaser** 的产物；且 τ 检验不了加性能力（引理 L8）。但“组合性”本身作为**先验结构**仍值得保留——只是必须换成**可检验、按潜在技能条件化、且合规**的形态。
- **与 IP-01 的差异**：①条件变量从“32 类任务 id”改为**潜在技能后验** `z_skill = (相位后验, 语言 grounding, 扰动估计)`；②先做 E619 的**分半 OOS 检验**，未过门槛不投入；③默认提交**单专家 + 潜在技能 token** 的合规下界形态。
- **可验收**：E619 的 `Δ_route^{OOS} ≥1.0` 且置换 `p<0.05`；严格单专家形态损失 ≤1.5 分；每专家至少在 2 任务 + 1 OOD 轴上被复用。
- **风险**：OOS 增益不成立 ⇒ 直接砍掉，不做 MoE（这是本轮相对第 1 轮最重要的“省下 8×A100×3 天”的决策）。

## 3. 符号与定义（U13–U21）

| 符号 | 含义 |
|---|---|
| `T_{a,ε}` | 第 a 类扰动（位置/干扰物/背景/未见物品/人扰）强度 ε 的干预算子 |
| `G_a(π)` | 不变性比值：扰动后成功率 / 原始成功率 |
| `I_a(π)` | 不变性缺口 `1−G_a` |
| `C(π)` | 组合性：held-out 技能组合上的成功率 |
| `β_m` | 模型 m 的加性通用能力（variance decomposition） |
| `γ_{tm}` | 任务 t × 模型 m 的交互项（特长） |
| `δ` | 观测–动作时序偏斜（帧） |
| `q(s)` | 片段质量六维向量 |
| `u(s)` | 片段数据估值（对 OOD 损失的边际影响） |
| `w(s)` | 训练权重 |
| `R_cov(t)` | 恢复覆盖率 |
| `Δ_route^{OOS}` | 样本外路由增益 |

**定义 U13（方差分解）** 把 model×task 分数写成 `s_{tm} = μ + α_t + β_m + γ_{tm} + ε_{tm}`；`β` 为加性通用能力，`γ` 为任务特异交互（特长）。
**定义 U14（通用性谱）** `Gen(π) = (G_pos, G_dist, G_bg, G_obj, G_human, C)`，其中 `G_a` 在固定干预强度 ε 下估计；主分析预注册为 `min_a G_a`（最弱轴）。
**定义 U15（样本外路由增益）** 用一半 episode 估 `θ̂_{tm}`，在另一半上 `Δ_route^{OOS} = E_t[s_{t,m*(t)}] − E_t[s_{t,m_g}]`，`m*(t)=argmax_m θ̂_{tm}`，`m_g=argmax_m mean_t θ̂_{tm}`。
**定义 U16（时序偏斜）** `δ* = argmin_{|δ|≤K} L_pred(δ)`，`L_pred(δ)=E‖f(o_t, a_{t−δ}) − o_{t+1}‖²`（或等价的动作–状态互相关最大）。
**定义 U17（质量向量）** `q(s) = (q_time, q_phys, q_view, q_lang, q_cov, q_rec) ∈ [0,1]^6`。
**定义 U18（加权风险与有效样本量）** `L_w = Σ_s w_s ℓ(s)`，`w_s = clip(exp(λ·û_s)·g(q_s), w_min, w_max)`，`ESS = (Σw)²/Σw²`。
**定义 U19（恢复覆盖）** `R_cov(t) = |{e : 存在失败→纠正转移}| / |{e}|`，失败与纠正由 IP-02′ 状态机定义。
**定义 U20（组合性）** 在技能图 `(V,E)` 上，`C(π) = P(success | 边 e ∉ E_train 的 held-out 组合)`。
**定义 U21（质量账本闸门）** 训练/评测仅在 `q_time` 与 `q_phys` 过阈值、且 `ESS ≥ ESS_min` 时启用加权；否则回退均匀权重并标记“未审计”。

```python
# ===== IP-09：LADA 时序偏斜估计（多信号交叉验证）=====
def estimate_lag(episode, signals, K=5):
    """
    signals: 每项为 (action_seq, state_change_seq) 的配对
    返回每个信号的 delta* 与 bootstrap 置信区间
    """
    est = {}
    for name, (a, ds) in signals.items():
        scores = []
        for d in range(-K, K + 1):
            aa, dd = shift(a, d), ds
            m = align_len(aa, dd)
            # 归一化互相关 / 负一步预测损失
            scores.append(normalized_xcorr(aa[:m], dd[:m]))
        d_star = int(np.argmax(scores) - K)
        est[name] = (d_star, bootstrap_ci(scores, K))
    # 只在多信号一致且 CI 窄时接受
    ds = [v[0] for v in est.values() if v[1] <= 1]
    delta = int(np.median(ds)) if ds else 0
    reliable = len(ds) == len(est) and max(ds) - min(ds) <= 1
    return delta, reliable, est
```

```python
# ===== IP-10：DQL 质量账本 + 估值加权 =====
def quality_vector(seg):
    return {
        "q_time": 1.0 - min(1.0, abs(seg.delta) / 5.0) * (0.0 if seg.delta_reliable else 1.0),
        "q_phys": physical_feasibility(seg.action),      # 限位/速度/加速度
        "q_view": multi_view_reproj_consistency(seg.frames),
        "q_lang": language_grounding(seg.instruction, seg.frames),
        "q_cov":  phase_rarity(seg.phase, seg.task),
        "q_rec":  recovery_content(seg),                 # 与 IP-11 共用
    }

def train_weight(seg, u_hat, lam=1.0):
    q = quality_vector(seg)
    base = np.exp(lam * shrink(u_hat, k=3.0))                # 估值向 0 收缩
    w = base * (q["q_time"] * q["q_phys"]) ** 0.5
    if q["q_rec"] >= REC_THRESH:                             # 恢复片段保护下界
        w = max(w, W_FLOOR)
    return float(np.clip(w, W_MIN, W_MAX))

def weighted_training_ok(weights):
    ess = weights.sum() ** 2 / (weights ** 2).sum()
    return ess >= ESS_MIN and weights.size > 0
```

# ===== IP-11：RecoverMine 微恢复挖掘 =====
def find_micro_recoveries(episode):
    """检测：夹爪闭合但物体未随动 -> 张开 -> 再接近（真实数据，高可信）"""
    events = []

        closed = episode.gripper[t] < CLOSE_TH
        not_following = object_not_following(episode, t)   # 腕部几何 + EE 随动
        if closed and not_following:
            j = next_open(episode, t + 1)
            if j is not None:
                events.append((t, j, "micro_recovery"))
    return events

def synthesize_recovery(seg, perturb):
    """对已挖出的恢复点施加受控扰动，配对检索到的成功纠正段"""
    state0 = apply_perturb(seg.state_at_recovery, perturb)   # 位姿/夹爪/角度
    if not physically_feasible(state0):
        return None
    correction = retrieve_correction(seg.task, state0)       # 检索最近成功纠正
    return RecoverySample(state0, correction, src=seg.id, kind="synthetic")
```

# ===== IP-12：GenProfile 不变性谱 =====
def gen_profile(policy, envs, axes, eps):
    base = mean_success(policy, envs.samples)
    G = {}
    for a in axes:                                  # pos/dist/bg/obj/human
        intervened = [T(a, eps)(x) for x in envs.samples]
        G[a] = mean_success(policy, intervened) / max(base, 1e-6)
    C = compositional_success(policy, envs.heldout_compositions)
    return {"G": G, "C": C, "worst_axis": min(G, key=G.get)}
```

# ===== IP-13：分半 + 置换零假设的路由检验 =====
def split_half_routing(scores):  # scores: [n_tasks, n_models] of mean scores per half
    A, B = scores["A"], scores["B"]
    m_star = A.argmax(axis=1)                    # 每任务专家（在 A 上选）
    m_g = A.mean(axis=0).argmax()                # 全局最优单模型（在 A 上选）
    gain = (B[np.arange(len(B)), m_star] - B[:, m_g]).mean()
    null = permutation_null(B, n=5000)           # 打乱任务-模型对应
    return gain, float((null >= gain).mean())

## 5. 推导（引理 L8–L13）

**引理 L8（Kendall τ 对加性模型能力不可见）** 设 `s_{tm}=μ+α_t+β_m+γ_{tm}+ε_{tm}`。对任意模型对 `(i,j)`，`s_{ti}−s_{tj} = (β_i−β_j) + (γ_{ti}−γ_{tj}) + (ε_{ti}−ε_{tj})`。跨任务做 Kendall 比较时，常数 `β_i−β_j` 在每一对任务比较中同号抵消，故 τ 只依赖 `γ,ε`，与 `β` 无关。∎
**推论**：第 1 轮“τ≈0 ⇒ 没有单一通用能力/技能准正交”**不成立**；τ≈0 与“`β` 很大、`γ` 很小”完全相容。检验通用能力应看 `β` 的跨模型散布；检验可路由红利应看 `γ` 的可靠性与 OOS 增益。

**引理 L9（样本内 oracle 的选择偏差）** 对任意 `γ`（含 `γ≡0`），`E[样本内 oracle] ≥ E[最优单模型]` 一般不取等：前者是同一批点的逐任务极大值，后者是均值极大值，二者共用同一批噪声。故 `+4.26` 不能解释为可兑现红利；决策量是 `Δ_route^{OOS}`（定义 U15）。在 `γ≡0` 时 `E[Δ_route^{OOS}]=0`（[sim] 实测均值 −0.016，95% CI 覆盖 0）。∎

**引理 L10（时序偏斜的可辨识性）** 若 `L_pred(δ)` 在 δ* 处有唯一极小、且动作谱在采样率下不产生与 δ* 同周期的混叠，则 δ* 随 episode 数增大而一致估计。若动作近似周期且周期与候选滞后重合（如擦拭/往复），则 `L_pred` 多峰 ⇒ 只能给集合；此时须跨任务池化并用多信号（夹爪/EE/光流）交叉验证。∎

**引理 L11（质量加权的有效样本量约束）** 对权重 `w_s`，加权估计的方差近似正比于 `1/ESS`，`ESS=(Σw)²/Σw²`。若少数恢复片段被赋予极高权重，ESS 急剧下降、方差爆炸。故质量加权必须同时报告 ESS 并设 `ESS ≥ ESS_min`；恢复片段用**下界保护 + 温度缩放**，而非无上限放大。∎

**引理 L12（恢复覆盖的边际价值集中在最弱相位）** 设各相位独立成功概率为 `p_1…p_K`，无恢复时 `P_succ=∏p_j`。对最弱相位 `j*=argmin p_j`，`∂P_succ/∂p_{j*}` 的绝对值最大；引入恢复后 `P_succ' ≈ P_succ·(1 + Σ_j (1−p_j)/p_j·ρ_j·r_j)`（`r_j` 为恢复覆盖率、`ρ_j` 为恢复成功率的一阶近似），其增量对 `p_j` 最小的相位最大。⇒ **恢复数据应优先投在最弱相位（插入/旋转/对齐），而不是均匀铺开。** ∎

**引理 L13（平均成功率不是通用性的充分统计量）** 若两策略 `π1,π2` 在原始分布上平均成功相同，但在某轴 `a` 上 `G_a(π1) > G_a(π2)`，则对任何把该轴权重调高的测试分布 `D'`，存在权重区间使 `π1` 严格优于 `π2`。故仅凭平均成功率无法排序“通用性”；必须报告谱。∎
