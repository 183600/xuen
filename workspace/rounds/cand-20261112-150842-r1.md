# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 7 轮；本轮灵感：「技术路线图」×「竞赛策略」）

> 第 60 轮把「执行层→证据层」的闭环升级为「认知驱动的场景-执行闭环」（SSM×CIEC×EPIR×SERC×PCE++++）。但**三个更上位的问题**在第 60 轮之后反而被放大：
> 1. **能力碎片化与优先级失序**：60 轮累计 160 个 IP，系统已能声称「会做很多事」，却没有一个**可审计的机制回答「现在最该做哪一件事、做到什么程度才敢在 UniBot 上声称」**。能力之间只有依赖关系，没有**成本-收益-证据**的统一度量，导致研究被「最近实现的模块」牵着走，而非被「赢得竞赛的关键路径」牵着走。
> 2. **评估函数的黑箱与对抗性**：竞赛不是「分数最大化」，而是**排名/晋级**。评委权重 w、对手策略、评分细则漂移都是不确定甚至对抗的；第 60 轮的 PCE++++ 仍是「期望效用最大化」的内核，而「期望分数最高」与「夺冠概率最高」在方差维度上可以给出**相反**的决策。
> 3. **证据与主张的脱节**：第 60 轮的 EPIR 保证了 EV-exec 不丢，但**「有证据」不等于「有资格声称」**。若成熟度可以由自己训练、自己评测、自己签字，系统会系统性地高估自己（Goodhart / 自评偏差），在单次竞赛中把「证据层高度确定」变成「执行层灾难」的放大器。

## 0. 直觉与动机

**灵感 1（技术路线图 → 能力路线图 CRG）**
直觉：技术路线图不是待办清单，而是**一张带证据刻度的有向无环图（DAG）**。节点是「可被证据支撑的能力主张」，边是「前置依赖」，每个节点有成本 c、分数敏感度 ρ、成熟度 μ、证据强度 ε。路线图真正的产出不是「画图」，而是三个可计算量：**可行前沿、关键路径、下一个最便宜的去风险实验**。
关键洞见：**成熟度不能超过证据强度**，即 `μ_v ≤ ε_v`。这条不等式把「技术路线图」从自我叙事变成**可证伪的承诺表**：没有 EPIR 证据链与 J_exec 证书支撑的能力，只能待在「影子模式」，不能进入对外声称集。

**灵感 2（竞赛策略 → 排名感知组合 CPP）**
直觉：竞赛的目标函数是**排名**，不是分数。两件事立刻改变：
（a）**对手不是「平均对手」，而是「要跨过的门槛」**——在 m 个对手的 top-1 竞争中，真正的参照是对方分数的**次序统计量（极大值）** `b_m = E[max_k S_k]`，而非均值。我们常看到「均值 80、对手均值 75」却仍是下风，因为 19 个 N(75,5) 对手的期望最大值约 84.3。
（b）**方差是有方向的**：落后于门槛时应主动拥抱方差（赌上限），领先于门槛时应压缩方差（守下限）；但 top-1 对大赛场有「极大值的凸性」，方差在边界附近并非单调——**方差价态 ν = ∂P(win)/∂σ 必须在线上估计，不能用一个固定口号**。
关键洞见：竞赛策略 = 在「依赖闭包 + 预算 + 不破产（CVaR/晋级线）」约束下，最大化 `P(rank=1)` 的**组合选择**；均值只是其中一个变量，方差与尾部风险必须进入目标函数。

**灵感 3（证据-gated 成熟度 RMU）**
直觉：给每个能力维护一个 Beta 后验 `μ_v = a_v/(a_v+b_v)`，每次由 EPIR 证据链驱动的验证试验成功则 a+1、失败则 b+1。但后验均值还会被三条「证据折扣」封顶：链完整性 `ι_chain`（seq/hash/因果顺序完整比例）、可复现性 `ι_rep = 1−e^{−n/κ}`、**独立性 `ι_ind`（自己产证据自己验则打 0.5 折）**。声称成熟度取 `μ_v^claim = min(μ_v^post, ε_v)`。
关键洞见：**独立性折扣是反 Goodhart 的核心**。没有第三方/异构验证者的能力，无论自测多高，都不能进入高置信声称集。

**灵感 4（技术路线图 × 竞赛策略 → 双时间尺度治理 RGCR）**
直觉：第 60 轮的 SERC 是**毫秒—秒级**的快回路；路线图/策略是**小时—赛段级**的慢回路。两者不该同频：快回路负责「把已批准的能力执行好并产出证据」，慢回路负责「根据证据与评分回读，决定下一赛段批准哪些能力、压多少方差」。
关键洞见：这是一个**奇异摄动/双时间尺度**结构——慢变量把快回路的均衡当作自己的「环境」，快回路把慢变量当作准静态参数。只要慢步长 η 足够小、快回路指数稳定，联合迭代收敛到均衡邻域。

**灵感 5（PCE+++++ → 战略预算）**
直觉：在第 60 轮 `B_cog=(B_scene,B_intent,B_ros,B_exec)` 之上再加两维：`B_road`（证据摄取、成熟度更新、路线图维护）与 `B_strat`（组合求解、评分后验推断、重规划）。战略计算本身要花预算，且其价值是**信息价值**：`VOI_strat = E[ΔP(win)] − cost_strat − opportunity_cost`。若 B_strat 耗尽 ⇒ 退化为上一次的关键路径固定优先级；若 B_road 耗尽 ⇒ 冻结 μ、只敢声称 ε。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（能力路线图图 CRG）** 路线图 `G = (V, E, μ, ε, c, ρ)`：
- 能力集 `V = {v₁,…,v_n}`，边 `E ⊆ V×V`，`(u,v)∈E` 表示 v 需要 u 达到阈值 `θ_{uv}`；
- **成熟度** `μ: V→[0,1]`，**证据强度** `ε: V→[0,1]`，**推进成本** `c: V→R₊`（升一级的工时/算力），**分数敏感度** `ρ: V→R₊`（当前评分细则下每单位成熟度的边际得分）；
- **依赖闭包** `cl(S)`：包含 S 且对所有 `(u,v)` 满足 `u∈cl(S)` 的最小超集；
- **关键路径** `CP(G)`：DAG 上以 `c_v/ρ_v`（单位得分成本）为节点权的最长路，给出「最该先打通的能力链」；
- **声称集** `Claim(G) = {v | μ_v^{claim} ≥ τ_deploy ∧ ε_v ≥ τ_evid}`，且满足**证据闸门不变量** `μ_v^{claim} ≤ ε_v`。
路线图的价值量：可行前沿 `F(G) = {cl(S) | cost(cl(S)) ≤ B}`、关键路径、下一个最优去风险实验。

**定义 162（评分模型与排名目标 SRT）** 评分维度 `D={accuracy, robustness, novelty, efficiency, presentation}`，细则权重 `w∈Δ^{|D|−1}` 未知，后验 `P(w|obs)`；能力向量诱导分数 `s_d = f_d(μ)`，总分 `S = w·s(μ) + η`。
- **排名目标**：`P_win(π) = P(S(π) ≥ max_{k=1..m} S_k^opp)`；
- **门槛次序统计量**：对手 i.i.d. 时 `b_m = E[max_k S_k^opp]`；高斯近似 `b_m ≈ μ_o + σ_o·Φ^{-1}(1 − 1/(m+1))`；
- **方差价态**：`ν(π) = ∂P_win/∂σ_S(π)`，表示「多承担一单位标准差」对夺冠概率的边际贡献；
- **晋级/不破产约束**：`q(π)=P(S(π) ≥ τ_qual)`，并要求 `CVaR_α(S(π)) ≥ s_min`。
- **命题（2 人对局精确解）**：若 `S~N(μ_s,σ_s²)`、`O~N(μ_o,σ_o²)`，则
  `P_win = Φ((μ_s−μ_o)/√(σ_s²+σ_o²))`，
  `∂P_win/∂σ_s = φ(z)·δ·σ_s/σ³`，其中 `δ=μ_o−μ_s`、`σ=√(σ_s²+σ_o²)`。
  故 **落后（δ>0）时增大方差提高胜率，领先（δ<0）时减小方差提高胜率**；打平（δ=0）时方差中性。
- **命题（m 人竞技的次序统计修正）**：真正的「领先/落后」应相对 `b_m` 而非 `μ_o` 判定；当 `μ_s` 低于 `b_m` 时，小方差区间的 `ν>0`；当 `μ_s` 明显高于 `b_m` 时 `ν<0`；在 `b_m` 邻域 `ν` 可能非单调，**必须用 MC/数值微分在线估计**，不能套用固定口诀。

**定义 163（排名感知竞赛组合 CPP）** 给定路线图 G、预算 B、赛段视界 H、对手模型与晋级线，求解
```
max_{π}  P_win(π)
s.t.     cost(π) ≤ B,   π 对 E 封闭,
         CVaR_α(S(π)) ≥ s_min,   q(π) ≥ q_min
```
其中 π 是各能力「推进级数」的分配。**领先/落后策略**：令 `δ_m = b_m − μ_s(π₀)`，用边际替代率 `λ = (∂P/∂σ)/(∂P/∂μ)` 把方差折算成「均值当量」，在依赖闭包下按 `(E[ΔS_v] + λ·sign(δ_m)·SD[ΔS_v])/c_v` 做闭包感知贪心，再做局部搜索与 CVaR 修正。当 `δ_m>0`（落后于门槛）时 `λ>0`，偏向高方差分支；当 `δ_m<0` 时 `λ<0`，偏向低方差分支；CVaR 约束负责防止「赌到出局」。

**定义 164（证据-gated 成熟度更新 RMU）** 每个能力维护 `μ_v ~ Beta(a_v,b_v)`。一次来自证据链的验证试验成功判据：
```
success_v(t) = chain_intact(EV-exec) ∧ cert_valid(J_exec) ∧ (ΔD⁺ ≤ ε_sic)
a_v ← a_v + 1  (成功)   /   b_v ← b_v + 1  (失败)
μ_v^post = a_v/(a_v+b_v)
ε_v = ι_chain · ι_rep · ι_ind
ι_rep = 1 − exp(−(a_v+b_v)/κ)
ι_ind = 1.0 (异构/独立验证) 或 0.5 (自产自验)
μ_v^claim = min(μ_v^post, ε_v)
```
**反 Goodhart 不变量**：任何对外 demo / 论文声称 / 竞赛提交只允许使用 `Claim(G)` 中的能力；影子能力可运行、可记录，但不得计入得分主张。

**定义 165（路线图-执行耦合 CEC）** 激活映射 `α: G × 策略π → 执行配置`：
- `μ_v^claim ≥ τ_deploy ∧ ε_v ≥ τ_evid` ⇒ 激活并**可声称**；
- `μ_v^post ≥ τ_shadow` 但未过证据闸门 ⇒ **影子模式**（内部运行、只写证据、不对外）；
- 否则关闭。
运行时预算按边际得分贡献分配 `b_v ∝ ρ_v·μ_v^claim`，并**永久预留**基线安全预算 `b_0`（保证 CVaR 下界与降级路径）。CEC 输出直接进入第 60 轮 SERC 的能力开关与第 59 轮 PCE+++ 的 `B_exec` 配额。

**定义 166（对抗性路线图重规划 ARR）** 当出现以下任一触发：评分细则后验漂移 `KL(P(w|obs)‖P₀(w)) > θ_w`、对手暴露新能力、某节点证据被证伪——则重解 CPP。维护策略臂集合 `𝒜`（不同组合/方差档位），用 Thompson 采样或 EXP3 选择；定义累积遗憾
```
R_T = max_{π∈𝒜} Σ_{t=1..T} P_win(π) − Σ_{t=1..T} P_win(π_t)
```
平稳评分下 `E[R_T] = O(√(T·|𝒜|·log|𝒜|))`；分段漂移下以漂移检测重置后验，遗憾上界按漂移次数线性放大。**证伪触发**：若节点 v 的验证连续失败，`μ_v ← μ_v·(1−ρ_fail)` 并把依赖它的下游节点降级，防止「一个坏假设污染整条路线图」。

**定义 167（双时间尺度路线图治理 RGCR）** 快回路（第 60 轮 SERC，周期 `ε_f`）与慢回路（路线图/策略，周期 `ε_s`，`ε_s ≫ ε_f`）：
```
慢：θ_{n+1} = θ_n + η·h(θ_n, φ(θ_n))      // θ=(μ, P(w), π), φ=快回路均衡
快：x_{k+1} = f(x_k; θ_n)                  // SERC 执行并产出 EV-exec
```
**引理（双时间尺度收敛）**：若快回路对固定 θ 有唯一指数稳定均衡 `φ(θ)`，h 关于 θ 为 L-Lipschitz，慢步长 `η < 1/L`，且快回路跟踪误差为 `O(ε_f)`，则 `θ_n` 收敛到联合均衡的 `O(η+ε_f)` 邻域。工程含义：**赛段级决策不要按毫秒级证据抖动反复改路线图**。

**定义 168（战略预算 PCE+++++）** 在 `B_cog=(B_scene,B_intent,B_ros,B_exec)` 上增加
```
B_road  = (Evidence_ingest_rate, Maturity_update_rate, Roadmap_memory)
B_strat = (Portfolio_solve_budget, Rubric_inference_budget, Replan_budget)
```
```
VOI_strat(π) = E[ΔP_win(π)] − cost_strat(π) − opp_cost(π)
cost_strat = λ_r·cost_road + λ_s·(solve_cost + infer_cost + replan_cost)
```
降级链：`B_strat` 耗尽 ⇒ 冻结为上一赛段关键路径的固定优先级；`B_road` 耗尽 ⇒ 冻结 μ、只声称 ε；`B_exec` 耗尽 ⇒ 回退第 59 轮降级；任一时刻基线 `b_0` 不可被战略层挪用。

## 2. 关键算法伪代码

### IP-161 CRG（能力路线图）
```python
class CapabilityRoadmap:
    def __init__(self, nodes, edges, cost, sensitivity):
        self.V, self.E = nodes, edges
        self.mu  = {v: 0.0 for v in nodes}
        self.eps = {v: 0.0 for v in nodes}
        self.c, self.rho = cost, sensitivity

    def closure(self, S):
        S = set(S); changed = True
        while changed:
            changed = False
            for v in list(S):
                for u in self.pred(v):
                    if u not in S:
                        S.add(u); changed = True
        return frozenset(S)

    def critical_path(self):
        order = self.topo_sort()
        dist = {v: self.c[v] / max(self.rho[v], 1e-6) for v in self.V}
        nxt  = {v: None for v in self.V}
        for v in reversed(order):
            for w in self.succ(v):
                if dist[w] + self.c[v] / max(self.rho[v], 1e-6) > dist[v]:
                    dist[v] = dist[w] + self.c[v] / max(self.rho[v], 1e-6)
                    nxt[v] = w
        start = max(self.V, key=lambda v: dist[v])
        path = []
        while start is not None:
            path.append(start); start = nxt[start]
        return path, dist

    def claim_set(self, tau_deploy, tau_evid):
        return {v for v in self.V
                if self.mu[v] <= self.eps[v] + 1e-9
                and self.mu[v] >= tau_deploy and self.eps[v] >= tau_evid}
```

### IP-162 SRT（排名目标与方差价态）
```python
def win_prob(mu_s, sd_s, field_samples):
    S = np.random.normal(mu_s, sd_s, len(field_samples))
    return float(np.mean(S > field_samples.max(axis=1)))

def variance_valence(mu_s, sd_s, field, h=1e-2):
    return (win_prob(mu_s, sd_s + h, field)
          - win_prob(mu_s, sd_s - h, field)) / (2 * h)

def threshold_bar(field):
    return float(np.mean(np.max(field, axis=1)))   # b_m 的经验估计
```

### IP-163 CPP（排名感知组合）
```python
def rank_aware_portfolio(roadmap, field, budget, cvar_min):
    b_m  = threshold_bar(field)
    mu0, sd0 = current_score_moments(roadmap, field)
    delta = b_m - mu0
    lam  = marginal_rate_substitution(mu0, sd0, field)  # (dP/dσ)/(dP/dμ)
    items = frontier_items(roadmap)
    value = {v: (mean_gain[v] + lam * np.sign(delta) * sd_gain[v])
                / roadmap.c[v] for v in items}
    S = roadmap.closure(greedy(items, value, budget))
    while cost(S) > budget or cvar(S) < cvar_min:
        S = roadmap.closure(drop_min_density(S, value))
    return local_search(S, budget, cvar_min, field)
```

### IP-164 RMU（证据-gated 成熟度）
```python
def update_maturity(v, trial, independent, kappa=5.0):
    ok = trial.chain_ok and trial.cert_ok and trial.dplus <= trial.eps_sic
    M.a[v] += int(ok); M.b[v] += int(not ok)
    mu_post = M.a[v] / (M.a[v] + M.b[v])
    i_chain = trial.chain_integrity
    i_rep   = 1.0 - np.exp(-(M.a[v] + M.b[v]) / kappa)
    i_ind   = 1.0 if independent else 0.5
    M.eps[v] = i_chain * i_rep * i_ind
    M.mu[v]  = min(mu_post, M.eps[v])      # 证据闸门
```

### IP-167 RGCR（双时间尺度治理闭环）
```python
def rgcr_loop(M, stage):
    while not stage.done:
        # ---- 慢回路（每赛段/每 K 次快回路）----
        M.roadmap.ingest(M.epir.export_evidence())      # B_road
        for v in M.roadmap.V:
            update_maturity(v, M.epir.latest_trial(v), M.verifier.is_independent(v))
        M.rubric.update(stage.scores, stage.judge_feedback)
        if M.rubric.kl_drift() > M.theta_w or M.evidence_falsified():
            M.plan = replan(M.roadmap, M.rubric, M.field_model, stage.budget)
        M.plan = rank_aware_portfolio(M.roadmap, M.field_model,
                                      stage.budget, stage.cvar_min)
        alpha = cec_activation(M.roadmap, M.plan)        # 声称集/影子/关闭
        # ---- 快回路（第 60 轮 SERC）----
        for _ in range(M.fast_steps_per_stage):
            M = serc_execute(M, alpha)
        stage.budget -= cost_of(M.plan)
    return claim_report(M.roadmap)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CRG | O(V+E) 拓扑+关键路径 | O(V+E) | 声称集 ⊆ 证据支撑集（不变量） |
| SRT | O(K·N_mc) / 次；高斯近似 O(1) | O(N_mc) | 2 人对局方差价态精确；m 人用 MC 一致估计 |
| CPP | NP-hard（带前置的随机背包）；贪心 O(V log V)+闭包，局部搜索 O(V²) | O(V) | 子模无前置时 (1−1/e)；有前置用闭包贪心+局部搜索 |
| RMU | O(1)/试验 | O(V) | μ_claim ≤ ε，独立性折扣可证伪 |
| ARR | O(|𝒜|) / 重规划（Thompson） | O(|𝒜|) | 平稳评分遗憾次线性；漂移下重置 |
| RGCR | 慢回路 O(V+E+V²)/赛段；快回路复用第 60 轮 | 复用 | 双时间尺度收敛到 O(η+ε_f) |

### IP-161 CRG（能力路线图与关键路径）
```python
class CapabilityRoadmap:
    def __init__(self, nodes, edges, cost, sensitivity):
        self.V, self.E = nodes, edges
        self.mu  = {v: 0.0 for v in nodes}
        self.eps = {v: 0.0 for v in nodes}
        self.c, self.rho = cost, sensitivity

    def closure(self, S):
        S = set(S); changed = True
        while changed:
            changed = False
            for v in list(S):
                for u in self.pred(v):
                    if u not in S:
                        S.add(u); changed = True
        return frozenset(S)

    def critical_path(self):
        order = self.topo_sort()
        w = {v: self.c[v] / max(self.rho[v], 1e-6) for v in self.V}
        dist = dict(w); nxt = {v: None for v in self.V}
        for v in reversed(order):
            for s in self.succ(v):
                if dist[s] + w[v] > dist[v]:
                    dist[v], nxt[v] = dist[s] + w[v], s
        start = max(self.V, key=lambda v: dist[v])
        path = []
        while start is not None:
            path.append(start); start = nxt[start]
        return path, dist

    def claim_set(self, tau_deploy, tau_evid):
        return {v for v in self.V
                if self.mu[v] <= self.eps[v] + 1e-9
                and self.mu[v] >= tau_deploy and self.eps[v] >= tau_evid}
```

### IP-162 SRT（排名目标、门槛与方差价态）
```python
def win_prob(mu_s, sd_s, field):
    S = np.random.normal(mu_s, sd_s, len(field))
    return float(np.mean(S > field.max(axis=1)))

def threshold_bar(field):
    return float(np.mean(field.max(axis=1)))          # b_m 经验估计

def variance_valence(mu_s, sd_s, field, h=1e-2):
    return (win_prob(mu_s, sd_s + h, field)
          - win_prob(mu_s, sd_s - h, field)) / (2 * h)

def mrs(mu_s, sd_s, field, h=1e-2):
    dP_dmu = (win_prob(mu_s + h, sd_s, field)
            - win_prob(mu_s - h, sd_s, field)) / (2 * h)
    dP_dsd = variance_valence(mu_s, sd_s, field, h)
    return dP_dsd / max(abs(dP_dmu), 1e-9)
```

### IP-163 CPP（排名感知组合）
```python
def rank_aware_portfolio(roadmap, field, budget, cvar_min, q_min):
    b_m = threshold_bar(field)
    mu0, sd0 = current_score_moments(roadmap, field)
    delta = b_m - mu0
    lam = mrs(mu0, sd0, field)
    items = frontier_items(roadmap)
    value = {v: (mean_gain[v] + lam * np.sign(delta) * sd_gain[v])
                / roadmap.c[v] for v in items}
    S = roadmap.closure(greedy(items, value, budget))
    while cost(S) > budget or cvar(S) < cvar_min or qualify(S) < q_min:
        S = roadmap.closure(drop_min_density(S, value))
    return local_search(S, budget, cvar_min, q_min, field)
```

```python
def update_maturity(v, trial, independent, kappa=5.0):
    ok = trial.chain_ok and trial.cert_ok and trial.dplus <= trial.eps_sic
    M.a[v] += int(ok); M.b[v] += int(not ok)
    mu_post = M.a[v] / (M.a[v] + M.b[v])
    i_chain = trial.chain_integrity
    i_rep   = 1.0 - np.exp(-(M.a[v] + M.b[v]) / kappa)
    i_ind   = 1.0 if independent else 0.5
    M.eps[v] = i_chain * i_rep * i_ind
    M.mu[v]  = min(mu_post, M.eps[v])          # 反 Goodhart 闸门
```

```python
class StrategicBudget:
    def __init__(self, road, strat, cog):
        self.B_road, self.B_strat, self.B_cog = road, strat, cog
```

## 4. 解析结论与代理实验（本轮实跑，固定随机种子）

### 4.1 命题：2 人对局的方差方向是精确可判的
设 `S~N(μ_s,σ_s²)`、`O~N(μ_o,σ_o²)`，独立。则
```
P_win = Φ((μ_s−μ_o)/√(σ_s²+σ_o²)) = Φ(−δ/σ),  δ=μ_o−μ_s, σ=√(σ_s²+σ_o²)
∂P_win/∂σ_s = φ(−δ/σ) · δ·σ_s/σ³
```
故 `sign(∂P_win/∂σ_s) = sign(δ) = sign(μ_o−μ_s)`：**落后时加方差、领先时减方差、打平时方差中性**。这与「期望分数最大化」无关——期望分数只取决于 μ，完全看不见 σ。

**实跑（2 人，对手 N(75,5)，解析值与 20 万次 MC 一致）**

| 我方 | σ_s=1 | 3 | 5 | 8 | 12 |
|---|---|---|---|---|---|
| 领先 μ=80 | .8366 | .8044 | .7602 | .7019 | .6497 |
| 打平 μ=75 | .5000 | .5000 | .5000 | .5000 | .5000 |
| 落后 μ=70 | .1634 | .1956 | .2398 | .2981 | .3503 |

### 4.2 修正：m 人竞技的「对手」是极大值，不是均值
19 个 `N(75,5)` 对手的期望最大值 `b_19 ≈ 75+5·Φ⁻¹(1−1/20) ≈ 84.3`。因此「均值 80」其实**仍低于门槛**，应加方差。

| 我方均值 | σ=1 | 3 | 5 | 8 | 12 |
|---|---|---|---|---|---|
| 80（相对均值领先、相对门槛落后） | .0554 | .1444 | .2295 | .3095 | .3656 |
| 75 | .0000 | .0080 | .0504 | .1369 | .2260 |
| 70 | .0000 | .0001 | .0053 | .0464 | .1242 |
