# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~301；灵感循环第 4 轮；本轮灵感：「夹爪控制」×「抗干扰」）

> R73 把「证据」变成可组合契约（EC / MMS / CCA / ΣREFLEX / CPB），系统级安全第一次在证据侧有了类型与代数。但 R73 只计量了「知道什么」，没有计量「能做什么」，也把「干扰」当成一个未分化的标量。三个结构问题：
> - **单侧计量**：夹爪控制器仍是主闭环里的黑箱，只消费 `u_tac` 标量。证据说「接触不确定度 0.3 N」，却没有任何类型回答「夹爪还能出多大力、多快、多大行程、热降额后还剩多少」。知道得够多 ≠ 有权限安全纠正；权限充足 ≠ 证据足够。安全是二者的**积**，R73 只度量了其中一个因子。
> - **干扰范畴错误**：R73 把 IR 互扰、材质失效、外参漂移都压进 u 分量并用 stub 处理，但对「夹爪被推、负载突变、传感器被伪造偏置」没有区分。控制论的抗干扰手段（积分作用、扰动观测器、自适应）会把持续偏置**吸收**进状态；若偏置是攻击者伪造的，控制器会忠实把测量误差归零而真实状态持续发散——**积分器是 stealth 攻击的免费权限**。抗干扰（容纳）与抗攻击（拒绝）的正确响应相反，误分两个方向都不安全。
> - **反馈破坏单货币单调性**：CCA 的「串联只增、并联审计后才可缩窄」在开环证据链成立；夹爪是闭环，高增益反馈可在低频压低扰动灵敏度（u 下降），代价是高频率灵敏度上升与执行权限消耗（Bode 水床）。R73 的组合下界定理在闭环下**失效**：u 可下降，但 `(u,e)` 对不会同时下降。证书必须从单货币升为**双货币（信息 × 权限）**，组合代数必须容纳耗散/小增益反馈复合。
>
> 本轮两个灵感正好补两块，第三块由二者交叉逼出：
> - **夹爪控制** → **AC（Actuation Contract）**：执行契约与证据契约对偶——权限包络 A、阻抗工作流形 Γ、耗散存储函数 S 与供给率 s、权限反作用通道 χ_A、执行有效域 D_A、执行否决 I⊥；**CAGE 抓取包络**把「抓得稳」写成受扰能量下的不变集；**证据买权限**：可维持扰动上界 `F_dist_max(u_tac, u_depth, e)` 显式依赖证据质量。
> - **抗干扰** → **DIST（Disturbance Source Taxonomy & Attribution）** + **AW-SEC**：干扰五源分解（模型/环境/传感/对抗/自致），先归因再决定「容纳 or 拒绝」；反积分隐身界 β_max；归因-精度权衡。
> - **交叉** → **LCA（Loop Composition Algebra）+ UET（Uncertainty–Effort Trade-off）**：反馈复合的耗散/小增益证书 + 灵敏度频带分配；组合单调性升级为双货币 Pareto 单调，给出「反馈无免费午餐」定理。
>
> 核心命题：**不再问「证据是否可信」，而问「证据与权限能否成对签约——使抓取安全在扰动、攻击与环路组合下由双货币代数自动保持？」** 把 R73 重构为 **DUALGAUGE-RAS**（DUal-currency, Authority-aware, Loop-certified GAUGE for RAS）——**双货币计量契约代数**。

## 0. 直觉与动机

**灵感 1（夹爪控制 → 权限是证据的对偶货币）**
直觉：抓取不是一个静态的「抓取质量分数」，而是一个**在扰动下被持续维持的不变集**。夹爪能维持多大的外部扰动，取决于两件事的乘积：(a) 对接触状态的证据质量（摩擦锥在哪、法向力置信区间多宽、是否已进入微滑）；(b) 执行权限（还能加多大力、多快调整、行程还剩多少、电机温度允许多久）。R73 的 DMEM 只给了 (a) 的一个标量，控制器却暗自假设 (b) 无限。真实夹爪的 (b) 是有限的、会随温度/饱和/背驱动衰减的。更深一层：**力控与位控不可兼得**——阻抗控制里刚度 K 与可施加力范围互相挤压，这是执行器层面的「不确定性原理」。所以执行侧必须有一份与 EC 对偶的契约，显式声明「我在什么阻抗工作点上、用多少权限、换到多大的扰动抑制」。这把 R73 的「证据计量」扩展为**证据-权限对偶计量**：知道得越多，同样权限下能维持的扰动越大（证据买权限）。

**灵感 2（抗干扰 → 先归因，再决定容纳还是拒绝）**
直觉：中文「抗干扰」同时指两件相反的事。控制论的**抗扰（disturbance rejection）**把未知输入当作可容纳的物理量：用积分作用、扰动观测器、自适应把它「吃掉」，让输出回到设定值。通信/安全的**抗干扰（anti-jamming / anti-interference）**把未知输入当作必须拒绝的欺骗：绝不能把它吸收进状态。最危险的情形是**用前者处理后者**：一个持续伪造的力传感器偏置（或磁性夹爪偏置、被替换的负载）会被积分器忠实地「吃掉」——测量误差归零，真实抓取力却持续偏离，直到滑落。反过来，把真实的环境扰动误判为攻击会频繁触发否决，损失可用性。这是**类型 I/II 错误且代价不对称**的检测问题。因此 DIST 的第一性任务不是估计 d 的大小，而是**给 d 归因**：模型失配 / 环境外力 / 传感器故障与互扰 / 对抗伪造 / 自致耦合（线缆、惯性、热）。只有 {模型, 环境, 自致} 属于「可容纳集」，{传感, 对抗} 属于「必须拒绝集」。归因本身必须带证书（可分离性与混淆界），否则「归因正确」只是又一句无根据的断言。

**灵感 3（反馈 → 水床：组合代数的第二货币）**
直觉：R73 的「组合不产生认知免费午餐」是对的，但只在开环成立。闭环反馈是一个**用权限换灵敏度**的装置：高增益把低频扰动灵敏度压下去，Bode 灵敏度积分却逼着高频灵敏度升上来（水床效应），同时执行器要付出更大的力/带宽/发热。所以闭环里 u 可以下降，但不可能「白降」——代价记在 e（权限/努力）上，并且只能在一个**声明的频带内**下降。R73 用单货币 u 记账，在闭环下会得出错误的安全界：它看见低频 u 变小就以为更安全，却没看见高频 u 变大、权限预算被吃穿。正确的组合对象是 `(u, e)` 二元组，组合单调性是**乘积偏序上的 Pareto 单调**：没有路径能在两个坐标上同时支配输入，除非附上耗散性/小增益证书和权限预算。Bode 积分是这条定律的物理见证。

**灵感 4（交叉 → 证据不能脱离权限被认证）**
直觉：R73 的 J_MOD 只证明了「证据链合规」。但如果一个高置信度的接触证据被送进一个没有权限执行的夹爪，系统会「正确地知道」却「安全地失败」——证书齐全而抓取失败。反过来，权限充足但证据差的夹爪会「自信地抓错」。因此**任何下游安全断言都必须同时消费 EC 与 AC**，证书从 `J(module)` 升为 `J_pair(EC, AC)`。这不是把两个证书拼在一起，而是要求它们在同一扰动能量假设下闭合：证据给出的扰动上界 ≤ 权限能维持的扰动上界。这也给 CPB 增加两条可证伪主张（C4 双货币反馈无免费午餐、C5 归因分离抗扰与抗攻击）。

**灵感 5（与 R73 的关系：严格包含而非推翻）**
直觉：如果把执行契约平凡化（A=∞ 但 e≡0、无反馈、D_A 全域），把 DIST 退化为「只有模型/环境源」、把频带声明退化为全频带，DUALGAUGE 就逐指令回到 MODGAUGE。也就是说 R73 是 DUALGAUGE 在「e≡0 切片 + 无 FDB/ADP」上的特例。新增的两条货币和反馈算子不是替换，而是在原有安全证明上**只增不减**：任何 R73 能证的，DUALGAUGE 在其退化实例上照样能证；任何 DUALGAUGE 新证的，都必须显式给出多出来的假设（A114–A118）。

## 1. 形式化定义（增量：定义 383–398）

**定义 383（DUALGAUGE-RAS 总览）** DUALGAUGE-RAS = (DMS, AC, DIST, LCA, UET, CAGE, AW-SEC, MODGAUGE†)。六不变式：
(i) **双契约完整性**：每个节点至少实例化 EC 或 AC（既感知又执行的节点两者都要）；每条边的两侧货币类型必须匹配，缺一不得入图；
(ii) **Pareto 单调性**：所有组合路径经 LCA 校验，输出 `(u,e)` 不得在乘积偏序下同时优于全部输入，除非附耗散/小增益与权限预算证书（引理 38、40）；
(iii) **归因完备性**：每个被「容纳」的持续偏置必须携带归因证书；归因置信度低于阈值时积分作用必须锁定（AW-SEC，定义 394）；
(iv) **耗散闭合**：每个反馈互联必须给出存储函数与供给率，且小增益 `γ_A·γ_B < 1`（或其 LPV 等价条件）；
(v) **抓取不变式**：在声明的扰动能量预算内 `x_g ∈ CAGE`（定义 391）；
(vi) **严格退化**：AC 平凡 + 无 FDB/ADP + DIST 塌缩 + D_ω 全域 ⇒ 逐指令等于 MODGAUGE（定理 30）。

**定义 384（执行契约 AC）** AC = (T_cmd, T_obs, A, Γ, S, s, χ_A, D_A, I⊥, W, seal_ref)：
- T_cmd/T_obs：指令/执行观测类型（与证据类型隔离）；
- A：权限包络 `A = (F_max, τ_max, v_max, stroke, BW, 热降额曲线)`，`e ∈ [0,1]` 为归一化权限消耗；
- Γ：阻抗工作流形——允许的 (刚度 K, 阻尼 D, 力偏置 f_0) 三元组集合，含饱和与背驱动边界；
- S: X→R≥0 存储函数候选；s: 供给率（耗散性 `dS/dt ≤ s(u,y)`）；
- χ_A: 权限反作用通道：动作/工况如何调制 A 与 Γ（热、饱和、背驱动、电压跌落）；
- D_A：执行有效域（温度、电压、负载、方位、背驱动状态）；
- I⊥：执行否决指示（可拒绝执行而不影响证据模块）；
- W：WCET/执行域预算；seal_ref：SEAL-Grasp / SEAL-Actuator 审计集。

**定义 385（双货币状态与预算）** 每个模块运行时状态为 `(u_i, e_i)`：`u_i` 为 R73 意义下的证据不确定度，`e_i ∈ [0,1]` 为权限消耗。全局预算 `(U_total, E_total, Φ)`，其中 `Φ ⊂ R²` 为**联合可行域**（不是两个独立之和）：`Φ` 由热、能量、带宽与安全裕度共同定义。偏序：`(u,e) ⪯ (u′,e′) ⇔ u≤u′ ∧ e≤e′`。**组合目标不是最小化 u，而是在 Φ 内寻找 Pareto 点**。

**定义 386（LCA 反馈组合代数）** 在 R73 的 SER/PAR/VETO 之外新增三算子：
- **FDB（反馈互联）**：A 前向、B 反馈。若 A 为 `(S_A,s_A)`-耗散、B 为 `(S_B,s_B)`-耗散且互联下 `s_A+s_B ≤ 0`，则闭环稳定，且 `L2` 增益 `γ ≤ γ_Aγ_B/(1−γ_Aγ_B)`（小增益形式）；`e_out = e_A + e_B + e_loop(γ)`（权限不免费）。
- **ADP（自适应/学习）**：引入持久记忆。必须带**归因门**（仅对 {模型, 自致} 更新）与**泄漏**（遗忘率 λ），否则持续未验证偏置可获得无界权限（定理 32）。
- **MIX（阻抗混合）**：位置通道与力通道并联，输出必须在 Γ 上；`u_out` 取证据保守值，`e_out = max(e_pos, e_force) + e_switch`（切换成本）。
- 三种旧算子按 `e_out = e_A + e_B`（SER/PAR）或 `max`（VETO）提升到双货币；VETO 的 `e` 记为 0 但 `u=∞`。

**定义 387（DIST：干扰五源归因）** 观测到的偏离写作
`d = d_model + d_env + d_sensor + d_adv + d_self`。
- d_model：参数/结构失配——响应：鲁棒/有界自适应（容纳）；
- d_env：外部物理输入（人推、负载、风）——响应：扰动观测 + 反馈（容纳）；
- d_sensor：故障/互扰/漂移——响应：检测 + stub/否决（拒绝）；
- d_adv：对抗伪造（偏置注入、重放、磁偏置）——响应：检测 + 否决 + 锁定（拒绝，绝不吸收）；
- d_self：自致耦合（线缆、惯性、热变形、饱和）——响应：前馈/模型修正（容纳）。
归因输出 `a_t ∈ Δ^5` 与混淆界 `C ∈ R^{5×5}`，代价矩阵**不对称**：`C(adv→env) ≫ C(env→adv)`。**归因契约**必须声明它在该工况下能分离哪些源、最小可分离幅度、检测延迟与混淆上界。「可容纳集」`𝒜={model,env,self}`；「拒绝集」`ℛ={sensor,adv}`。

**定义 388（抗扰-抗攻击对偶与反积分隐身界）** 设线性化回路直流增益 P、比例增益 k_p、泄漏积分 `ẋ_i = −λx_i + e`。对持续传感器偏置 b，稳态真误差满足
`|e_true| = |b| / (1 + P k_p + P/λ)`。
定义**吸收权限**（在容差 ε 内能被完整「吃掉」而不被察觉的持续偏置上界）
`β_max(λ, ε) = ε·(1 + P k_p + P/λ)`。
`λ→0`（纯积分）时 `β_max→∞`：抗扰越好，stealth 权限越大。这是**归因-精度权衡的定量形式**。AW-SEC 的任务不是消灭这个权衡，而是把它变成**显式预算**：`β_max ≤ β_cert` 或必须由独立通道复核。

**定义 389（抗干扰证书 γ）** 对闭环、扰动 d、性能输出 z（滑移速度、抓取力误差、位姿误差），证书给出 `∫|z|² ≤ γ²∫|d|² + S(x_0)`。γ 即抗干扰证书；SER 下 `γ ≤ γ_1γ_2`，FDB 下用定义 386 的小增益式。γ 必须在 D_A ∩ D_ω 内有效。

**定义 390（水床预算与灵敏度频带分配 UET）** 对稳定最小相位回路，Bode 灵敏度积分 `∫_0^∞ log|S(jω)| dω = 0`（含 RHP 零点时用 Poisson 积分推广）。因此任何「抑制」必须声明其代价频带。契约中显式写入**频带分配** `{(B_k, φ_k)}`：在 B_k 内声明的灵敏度上界 `φ_k`，以及频带外的**不承诺区**。约束：
`Σ_k |B_k|·log φ_k ≥ 0`（近似形式），且 `e` 随带宽与增益单调增。
**频域有效域** `D_ω`：下游只能在其声明频带内使用该证据/控制证书；跨频带推断视为契约违约。

**定义 391（CAGE 抓取包络）** 抓取状态 `x_g = (v_slip, m_cone, m_force, ε_pose, T_motor)`：
`CAGE = { x_g : m_cone ≥ m_0 ∧ E_slip ≤ E_slip^max ∧ F ≤ F_max(e) ∧ T ≤ T_max ∧ x_g 兼容 D_tac ∩ D_depth ∩ D_A }`。
抓取认证 = 在扰动能量预算 `E_d` 内 `x_g` 保持于 CAGE。CAGE 是 R73「证据有效域」在执行侧的像。

**定义 392（证据买权限）** 摩擦锥保守界：`F_dist_max = μ·(F_max(e) − z_{1−α}·u_tac) − m·a_dist`。其中 `u_tac` 含检测延迟项 `u_eff = u_tac + ṡ·τ_d`（定义 393）。单调性：`∂F_dist_max/∂u ≤ 0`、`∂F_dist_max/∂e ≥ 0`。**证据质量以「可维持扰动」为汇率兑换成权限裕度**——这是本轮把两个世界接起来的最小物理公式。

**定义 393（滑移前兆与检测延迟）** 微滑振动/接触阻抗突变的检测延迟 `τ_d` 进入有效不确定度：`u_eff = u_tac + ṡ·τ_d`（`ṡ` 为滑移速度上界）。证书必须同时声明 `τ_d` 与其分布；延迟越大，等效证据越差、CAGE 越小。

**定义 394（AW-SEC：反积分攻击）** 积分/自适应通道受归因门控：`ġate = 1[a_t(𝒜) ≥ τ_a ∧ ¬anomaly]`。门关时积分器切换为泄漏/冻结（`λ←λ_lock`），并只允许**独立物理通道**（本体/触觉/已知几何）重新开启。任何持续偏置在门关时不得改变稳态工作点，只能改变声明的误差界。

**定义 395（频域有效域 D_ω 与跨频带推断禁令）** 见定义 390；形式化为证据/控制契约上的附加字段，组合时取交，空交即非法。

**定义 396（双货币组合证书 J_DUAL）** `J_DUAL = ⊗_i J_pair(EC_i, AC_i) ⊗ J_comp(MReg) ⊗ J_attr(DIST) ⊗ J_diss(LCA)`。Valid 条件：双契约完备、每条边预算闭合（`u` 与 `e` 分别）、`D ∩ D_A ∩ D_ω ≠ ∅`、归因证书在混淆界内、耗散/小增益条件成立、`ΣREFLEX ∪ ΣAUTHORITY` 预算未超。`Valid(J_DUAL) ⇒ Valid(J_MOD)（R73）`（退化时）。

**定义 397（结构上限：环路与权限）** 环路深度 ≤ 3、单回路小增益裕度 `γ_Aγ_B ≤ 1−ρ_min`（`ρ_min=0.1`）、权限利用率 `e ≤ e_max`、归因源数 ≤ 5、频带数 ≤ 6、`|V_M| ≤ 32`——全部为 MReg/LReg 的**可审计图性质**。

**定义 398（MBench2 最小基准）** MB4（夹爪扰动：人推/负载突变/背驱动 × 证据质量矩阵）、MB5（归因与攻击：五源注入 + 反积分 stealth 偏置）、MB6（双货币复合：串联/并联/反馈/自适应 × 权限预算）。各 ≤ 3 小时单卡可复现，预注册脚本 + 固定种子 + 密封保持集 SEAL-MB2。

```python
# IP-302 DMS：双契约注册表（EC / AC 异构节点）
@dataclass(frozen=True)
class ActuationContract:
    t_cmd: type; t_obs: type
    authority: AuthorityEnvelope        # F_max, tau_max, v_max, stroke, BW, derating
    impedance: ImpedanceManifold        # Gamma: (K, D, f0) 可行集
    storage: Callable                   # S(x) >= 0
    supply: Callable                    # s(u, y): dS/dt <= s
    chi_A: Callable[[Action], AuthorityMod]   # 权限反作用通道（热/饱和/背驱动）
    domain: Predicate                   # D_A
    veto_set: FrozenSet[str]
    wcet_us: float; seal_ref: str

@dataclass
class PairModule:                       # 证据-权限对偶模块
    ec: Optional[EvidenceContract]; ac: Optional[ActuationContract]
    impl: object; cert: Cert

class DualRegistry:                     # DMS：扩展 R73 MReg
    def compose(self, a, b, op):        # op in {SER,PAR,VETO,FDB,ADP,MIX}
        assert self.types_match(a, b, op)          # 双货币类型匹配
        assert self.budget_closed(a, b, op)        # u 与 e 分别闭合
        if op == 'FDB':
            assert small_gain(a.cert.gamma, b.cert.gamma, rho_min=0.1)
            assert dissipative_pair(a.ac, b.ac)
        return PairComposite(a, b, op)

# IP-303 DIST：五源归因（先归因，后动作）
class DisturbanceAttributor:
    def update(self, residual, cmd, obs, peers, temp):
        feats = extract(residual, cmd, obs, peers, temp)
        a = self.classifier(feats)                 # a_t in Delta^5
        conf = self.certified_confusion(a, feats)  # 归因契约的混淆界
        source = argmax(a)
        if source in {'sensor', 'adv'}:
            return Attribution(source, conf, admit=False,
                               veto={'DIST_REJECT'})          # 拒绝，绝不吸收
        if conf < self.tau_attr:                              # 归因不可信
            return Attribution(source, conf, admit=False, veto={'ATTR_LOW'})
        return Attribution(source, conf, admit=True)          # {model,env,self}

# IP-304 AW-SEC：反积分攻击门控
def aw_sec_step(integ, attr, lambda_lock, tau_a):
    if attr.admit and attr.conf >= tau_a:
        integ.lambda_ = integ.lambda_nom            # 正常抗扰：可吸收有界偏置
        integ.gate = True
    else:
        integ.lambda_ = lambda_lock                 # 冻结/泄漏：限制吸收权限
        integ.gate = False
    integ.x = (1 - integ.lambda_ * DT) * integ.x + DT * integ.e
    return integ.x, beta_max(integ.lambda_, EPS)    # 返回当前吸收权限上界

# IP-305 LCA：双货币反馈/自适应/混合组合
def lca_compose(a, b, op):
    if op == 'SER':
        return Pair(u=a.u + lipschitz(b, a.u), e=a.e + b.e,
                    D=a.D & b.D, gamma=a.gamma * b.gamma)
    if op == 'PAR':
        if conformal_covers(a, b) and abs(estimate_corr(a, b)) < RHO_MAX:
            return Pair(u=fuse(a.u, b.u), e=max(a.e, b.e), D=a.D & b.D)
        return Pair(u=max(a.u, b.u), e=max(a.e, b.e), D=a.D & b.D,
                    veto={'PAR_AUDIT_FAIL'})
    if op == 'VETO':
        return Pair(u=INF if a.veto or b.veto else max(a.u, b.u), e=0.0,
                    D=a.D & b.D, veto=a.veto | b.veto)
    if op == 'FDB':
        assert small_gain(a.gamma, b.gamma) and dissipative_pair(a, b)
        return Pair(u=a.u + b.u, e=a.e + b.e + e_loop(a.gamma, b.gamma),
                    gamma=a.gamma * b.gamma / (1 - a.gamma * b.gamma),
                    D=a.D & b.D)
    if op == 'ADP':
        assert attribution_gate(a.attr)                 # 只对可容纳源更新
        return Pair(u=a.u, e=a.e + e_adapt, D=a.D,
                    beta=beta_max(lambda_, EPS))        # 显式吸收权限
    if op == 'MIX':
        return Pair(u=max(a.u, b.u), e=max(a.e, b.e) + E_SWITCH,
                    D=a.D & b.D, Gamma=a.Gamma & b.Gamma)

# IP-306 CAGE：抓取包络与证据买权限
def cage_certificate(tac_ev, depth_ev, ac, v_slip, tau_d, dist_energy):
    u_eff = sqrt(tac_ev.u**2 + (v_slip * tau_d)**2)     # 检测延迟进有效证据
    F_max = ac.authority.F_max * derate(ac.chi_A, ac.state)
    F_dist = MU * (F_max - Z_ALPHA * u_eff) - MASS * ACC_DIST
    cage = (cone_margin(tac_ev) >= M0) and (slip_energy(v_slip) <= E_SLIP) \
           and (F_dist >= sqrt(2 * dist_energy * STIFF_EFF))
    return CageCert(ok=cage, F_dist_max=F_dist, u_eff=u_eff,
                    band=declare_bands(ac), D_omega=ac.D_omega)

# IP-307 夹爪控制器：双货币 + 归因门控（1kHz 硬实时，只读快照）
def grip_step(snap, attr, integ):
    u_eff = snap.cage.u_eff
    K, D, f0 = impedance_point(snap.ac.Gamma, snap.cage.F_dist_max, u_eff)
    f_cmd = f0 + K * (snap.x_d - snap.x) + D * (snap.v_d - snap.v)
    f_cmd = clamp(f_cmd, -snap.ac.authority.F_max, snap.ac.authority.F_max)
    if not attr.admit:
        f_cmd = f0 + snap.hold_force                 # 拒绝集：不进积分，保持hold
    i_cmd, _ = aw_sec_step(integ, attr, LAMBDA_LOCK, TAU_A)
    return f_cmd, i_cmd, snap.cage.band              # 只在声明频带内承诺

# IP-308 DUALGAUGE 主闭环（在 R73 三域上增加执行域与环路审计）
def DUALGAUGE_round(M, obs, audio, tac_frame, depth_img, cmd):
    d_ev = M.dpe.update(depth_img, rgb, M.cam_state, M.motion, M.peers)
    t_ev = M.dmem.update(tac_frame, M.last_action)
    if not (d_ev.valid and t_ev.valid):                  # 模块级 stub（R73）
        d_ev, t_ev = stub_pair(d_ev, t_ev)
    if M.clock.due_metric():
        b_t = M.bse.step_full(..., d_ev=d_ev, t_ev=t_ev)
        g = M.ervoi.choose(b_t, ..., M.budget, M.fmp, M.bse)
        attr = M.dist.update(residual=M.sensor_resid(), cmd=cmd,
                             obs=obs, peers=M.peers, temp=M.temp)
        if g:
            s2, cost = sigmareflex_step(M.mods, g, M.state, M.budget)
            if s2 is not None: M.last_g, M.state = g, s2
        cage = cage_certificate(t_ev, d_ev, M.ac, M.v_slip, M.tau_d, M.E_d)
        M.dual_audit(attr, cage)                          # J_DUAL 增量校验
        M.snapshot.write(b_t, d_ev, t_ev, attr, cage, M.state)
    snap = M.snapshot.read_latest()
    f_cmd, i_cmd, band = grip_step(snap, snap.attr, M.integ)   # 控制域 1kHz
    M.ctrl_out.publish(f_cmd, i_cmd, band)
    return f_cmd, J_DUAL(M.registry)
```

## 3. 推导

**引理 38（双货币 Pareto 单调性）** 把 SER/PAR/VETO 提升到 `(u,e)` 后，任何组合的输出满足：若 `(u_out,e_out) ⪯ (u_i,e_i)` 对路径上所有 i 成立，则该路径必含一个非空证书项（conformal 审计、耗散证书或归因证书）。开环证据模块 `e≡0` 时退化为 R73 引理 34。系：**组合不产生「信息与权限同时免费」的午餐。**

**引理 39（耗散反馈复合与小增益）** 若前向 A、反馈 B 分别 `(S_A,s_A)`、`(S_B,s_B)`-耗散，且互联下 `s_A+s_B ≤ 0`，则闭环耗散、`L2` 增益有界；`e_out = e_A + e_B + e_loop(γ)`。系：**反馈是权限换灵敏度的合法交易，但交易的汇率由 γ 决定，不可零成本。**

**引理 40（水床/频带声明义务）** 对稳定最小相位回路，∃ RHP 零点时用 Poisson 积分：低频灵敏度下降必伴随某频段上升。因此任何「已抑制」的断言只能在其声明频带 `B_k` 内成立；跨频带使用即违约。系：**R73 的单货币组合下界在闭环下不成立（反例：高增益把低频 u 压到输入以下），取代它的是 `(u,e)` Pareto 下界 + `D_ω` 义务。**

**引理 41（归因-吸收权权衡）** 在 A114 线性化下，泄漏积分对持续偏置的吸收权限 `β_max(λ,ε)=ε(1+Pk_p+P/λ)`：`λ↓ ⇒ β_max↑` 且抗扰精度↑；但检测延迟与混淆界也随 `λ↓` 变差（积分越强，attacker 越容易隐藏在低频）。存在**不可同时最优**的前沿。系：**抗扰精度与抗 stealth 权限是同一枚硬币——AW-SEC 只能把权衡显式化，不能消除它。**

**引理 42（CAGE 保持）** 若 `E_d ≤ (F_dist_max(u_eff,e))²/(2K_eff)`、`u_eff = sqrt(u_tac² + (ṡτ_d)²)`、且滑移前兆在 τ_d 内可检（A117），则 `x_g` 在扰动期间保持于 CAGE。边距对 u_eff 单调减、对 e 单调增。系：**「抓得稳」是可计算的能量不等式，不是经验调参。**

**引理 43（证据买权限的单调性）** `F_dist_max = μ(F_max(e) − z_{1−α}u_eff) − m a_dist`，故 `∂F_dist_max/∂u_eff = −μz_{1−α} < 0`、`∂F_dist_max/∂e ≥ 0`。存在**证据-权限等值线**：用更好证据可在更小权限下维持同一扰动。系：**R73 的 u 与 R74 的 e 通过摩擦锥汇率可换算，这使 CPB 能做跨轮归因。**

**定理 30（DUALGAUGE 严格包含 MODGAUGE）** 在 A114–A118 下，取 AC 平凡（`e≡0`、无执行否决）、无 FDB/ADP/MIX、DIST 仅 {model,env}、`D_ω` 全域，则 DUALGAUGE 逐指令等于 MODGAUGE（R73），再退化等于 R71/R68。安全单调不减；新货币与新算子在退化实例上自动消失。系：**R74 不是替代 R73，而是把 R73 嵌为 `e≡0` 切片。**

**定理 31（双货币证书 ⇒ 抓取安全）** 若 `Valid(J_DUAL)` 且 `E_d ≤ E_cage`，则抓取在扰动期间保持 CAGE，物理滑落概率 ≤ ε_pair（相对证据模型、权限模型与归因证书）。证明重量落在：耗散性在 D_A 内成立、归因混淆界被遵守、`τ_d` 被真实上界覆盖。系：**证据与权限必须成对认证——单侧证书不足以支撑安全断言。**

**定理 32（反积分隐身界）** 在 AW-SEC 门控下，任何持续未验证偏置 b 要么被归因检出（概率 ≥ 1−η），要么其可吸收权限满足 `|b| ≤ β_max(λ_lock, ε)`；若攻击者试图超过 β_max，则必在 `O(log(β_max/|b|)/λ_lock)` 内触发饱和或残差异常而被检出。不存在「既完全隐身又获得无界积分权限」的策略。系：**积分器不再是免费攻击面，但代价是稳态抗扰精度下降（引理 41）。**

**定理 33（反馈无免费午餐 / Pareto 前沿不可支配）** 在 A114–A118 下，对任意容许的闭环组合，不存在一条路径在 `(u,e)` 上同时严格优于所有输入且不违反水床积分与小增益条件。等价地，可实现的 `(u,e)` 位于一条由 `{γ, B_k, A}` 参数化的 Pareto 前沿上；R73 的开环下界是该前沿在 `e=0` 的截距。系：**「更安全的抓取」只能通过在证据、权限、频带三者之间重新分配来获得，不能靠组合规则凭空生成。**

## 6. 本轮最大风险

**一句话**：DUALGAUGE 把抓取安全的最后一道保证押在「干扰归因」上，而归因在有限时间与有限传感下存在**根本不可辨识性**——同一个观测残差可以由环境外力、传感器老化漂移或攻击者伪造偏置产生，三者在任何有限检测窗口内可能观测等价；于是攻击者只要把伪造偏置塑造成落在归因契约声明的混淆界内，系统就会按「环境扰动」合法地把它**吸收**进积分器，在每一张证书都有效、每一步归因都「在混淆界内」的情况下安静地失去权限。

次级风险与缓解：
1. **归因不可辨识** → 强制独立物理通道复核（本体/触觉/已知几何）+ 混淆界显式入证书 + 对 `adv→env` 设极小上界；超出即拒绝而非容纳。
2. **水床/频带被下游误用** → `D_ω` 作为组合取交字段；跨频带推断直接判非法；E392 回归。
3. **耗散证书跨工况失效（LPV 间隙）** → 分片存储函数 + 切换证书；切换瞬间按 VETO 处理；ρ_min 裕度。
4. **β_max 线性化失真** → 非线性/饱和下用区间算术给保守上界；A114 仅在声明工况内有效。
5. **CAGE 过保守导致可用性下降** → 证据-权限等值线在线重规划（引理 43）；允许「先补证据再授权限」而非一味降力。

**定义 383（DUALGAUGE-RAS 总览与六不变式）** 双契约完整性 / Pareto 单调性 / 归因完备性 / 耗散闭合 / CAGE 不变式 / 严格退化。缺任一项不得入图。

**定义 385（双货币状态与预算）** 模块状态 `(u_i,e_i)`；预算 `(U_total,E_total,Φ)`；组合目标是在 Φ 内求 `(u,e)` 的 Pareto 点，而非单目标最小化 u。

**定义 386（LCA）** SER/PAR/VETO 提升为双货币；FDB 需耗散互联 + 小增益 `γ_Aγ_B<1`，`e_out=e_A+e_B+e_loop(γ)`；ADP 需归因门 + 泄漏 λ；MIX 输出在 Γ 上且付切换成本。

**定义 388（抗扰-抗攻击对偶与 β_max）** 泄漏积分对持续偏置的吸收权限 `β_max=ε(1+Pk_p+P/λ)`；`λ→0` 时抗扰最好但 stealth 权限无界。AW-SEC 将其显式预算化。

**定义 389（抗干扰证书 γ）** 在 `D_A ∩ D_ω` 内给出 L2 增益界；SER 乘性、FDB 小增益、VETO 记 `γ=∞`。

# IP-302 DMS：双契约注册表（EC / AC 异构节点）
@dataclass(frozen=True)
class ActuationContract:
    t_cmd: type; t_obs: type
    authority: AuthorityEnvelope        # F_max, tau_max, v_max, stroke, BW, derating
    impedance: ImpedanceManifold        # Gamma: (K, D, f0) 可行集
    storage: Callable                   # S(x) >= 0
    supply: Callable                    # s(u, y): dS/dt <= s
    chi_A: Callable[[Action], AuthorityMod]   # 权限反作用通道（热/饱和/背驱动）
    domain: Predicate                   # D_A
    veto_set: FrozenSet[str]
    wcet_us: float; seal_ref: str

@dataclass
class PairModule:
    ec: Optional[EvidenceContract]; ac: Optional[ActuationContract]
    impl: object; cert: Cert

class DualRegistry:
    def compose(self, a, b, op):        # op in {SER,PAR,VETO,FDB,ADP,MIX}
        assert self.types_match(a, b, op)          # 双货币类型匹配
        assert self.budget_closed(a, b, op)        # u 与 e 分别闭合
        if op == 'FDB':
            assert small_gain(a.cert.gamma, b.cert.gamma, rho_min=0.1)
            assert dissipative_pair(a.ac, b.ac)
        return PairComposite(a, b, op)

# IP-303 DIST：五源归因（先归因，后动作）
class DisturbanceAttributor:
    def update(self, residual, cmd, obs, peers, temp):
        feats = extract(residual, cmd, obs, peers, temp)
        a = self.classifier(feats)                 # a_t in Delta^5
        conf = self.certified_confusion(a, feats)  # 归因契约的混淆界
        source = argmax(a)
        if source in {'sensor', 'adv'}:
            return Attribution(source, conf, admit=False,
                               veto={'DIST_REJECT'})          # 拒绝，绝不吸收
        if conf < self.tau_attr:                              # 归因不可信
            return Attribution(source, conf, admit=False, veto={'ATTR_LOW'})
        return Attribution(source, conf, admit=True)          # {model,env,self}

# IP-305 AW-SEC：反积分攻击门控
def aw_sec_step(integ, attr, lambda_lock, tau_a):
    if attr.admit and attr.conf >= tau_a:
        integ.lambda_ = integ.lambda_nom            # 正常抗扰：可吸收有界偏置
        integ.gate = True
    else:
        integ.lambda_ = lambda_lock                 # 冻结/泄漏：限制吸收权限
        integ.gate = False
    integ.x = (1 - integ.lambda_ * DT) * integ.x + DT * integ.e
    return integ.x, beta_max(integ.lambda_, EPS)    # 返回当前吸收权限上界

# IP-306 LCA：双货币反馈/自适应/混合组合
def lca_compose(a, b, op):
    if op == 'SER':
        return Pair(u=a.u + lipschitz(b, a.u), e=a.e + b.e,
                    D=a.D & b.D, gamma=a.gamma * b.gamma)
    if op == 'PAR':
        if conformal_covers(a, b) and abs(estimate_corr(a, b)) < RHO_MAX:
            return Pair(u=fuse(a.u, b.u), e=max(a.e, b.e), D=a.D & b.D)
        return Pair(u=max(a.u, b.u), e=max(a.e, b.e), D=a.D & b.D,
                    veto={'PAR_AUDIT_FAIL'})
    if op == 'VETO':
        return Pair(u=INF if a.veto or b.veto else max(a.u, b.u), e=0.0,
                    D=a.D & b.D, veto=a.veto | b.veto)
    if op == 'FDB':
        assert small_gain(a.gamma, b.gamma) and dissipative_pair(a, b)
        return Pair(u=a.u + b.u, e=a.e + b.e + e_loop(a.gamma, b.gamma),
                    gamma=a.gamma * b.gamma / (1 - a.gamma * b.gamma),
                    D=a.D & b.D)
    if op == 'ADP':
        assert attribution_gate(a.attr)                 # 只对可容纳源更新
        return Pair(u=a.u, e=a.e + e_adapt, D=a.D,
                    beta=beta_max(lambda_, EPS))        # 显式吸收权限
    if op == 'MIX':
        return Pair(u=max(a.u, b.u), e=max(a.e, b.e) + E_SWITCH,
                    D=a.D & b.D, Gamma=a.Gamma & b.Gamma)

# IP-307 CAGE：抓取包络与证据买权限
def cage_certificate(tac_ev, depth_ev, ac, v_slip, tau_d, dist_energy):
    u_eff = sqrt(tac_ev.u**2 + (v_slip * tau_d)**2)     # 检测延迟进有效证据
    F_max = ac.authority.F_max * derate(ac.chi_A, ac.state)
    F_dist = MU * (F_max - Z_ALPHA * u_eff) - MASS * ACC_DIST
    cage = (cone_margin(tac_ev) >= M0) and (slip_energy(v_slip) <= E_SLIP) \
           and (F_dist >= sqrt(2 * dist_energy * STIFF_EFF))
    return CageCert(ok=cage, F_dist_max=F_dist, u_eff=u_eff,
                    band=declare_bands(ac), D_omega=ac.D_omega)

# IP-307 夹爪控制器：双货币 + 归因门控（1kHz 硬实时，只读快照）
def grip_step(snap, attr, integ):
    u_eff = snap.cage.u_eff
    K, D, f0 = impedance_point(snap.ac.Gamma, snap.cage.F_dist_max, u_eff)
    f_cmd = f0 + K * (snap.x_d - snap.x) + D * (snap.v_d - snap.v)
    f_cmd = clamp(f_cmd, -snap.ac.authority.F_max, snap.ac.authority.F_max)
    if not attr.admit:
        f_cmd = f0 + snap.hold_force                 # 拒绝集：不进积分，保持hold
    i_cmd, _ = aw_sec_step(integ, attr, LAMBDA_LOCK, TAU_A)
    return f_cmd, i_cmd, snap.cage.band              # 只在声明频带内承诺

# IP-308 DUALGAUGE 主闭环（在 R73 三域上增加执行域与环路审计）
def DUALGAUGE_round(M, obs, audio, tac_frame, depth_img, cmd):

    t_ev = M.dmem.update(tac_frame, M.last_action)
    if not (d_ev.valid and t_ev.valid):                  # 模块级 stub（R73）
        d_ev, t_ev = stub_pair(d_ev, t_ev)
    if M.clock.due_metric():
        b_t = M.bse.step_full(..., d_ev=d_ev, t_ev=t_ev)
        g = M.ervoi.choose(b_t, ..., M.budget, M.fmp, M.bse)
        attr = M.dist.update(residual=M.sensor_resid(), cmd=cmd,
                             obs=obs, peers=M.peers, temp=M.temp)
        if g:

            if s2 is not None: M.last_g, M.state = g, s2
        cage = cage_certificate(t_ev, d_ev, M.ac, M.v_slip, M.tau_d, M.E_d)

    snap = M.snapshot.read_latest()
    f_cmd, i_cmd, band = grip_step(snap, snap.attr, M.integ)   # 控制域 1kHz
    M.ctrl_out.publish(f_cmd, i_cmd, band)

## 4. 推导

**引理 38（双货币 Pareto 单调性）** SER/PAR/VETO 提升到 `(u,e)` 后，任何输出若在乘积偏序下同时不劣于所有输入，则路径必含非空证书项（conformal/耗散/归因）；开环 `e≡0` 退化为 R73 引理 34。系：**不存在信息与权限同时免费的组合。**

**引理 39（耗散反馈复合与小增益）** A、B 分别耗散且互联 `s_A+s_B≤0` ⇒ 闭环稳定、`L2` 有界；`e_out=e_A+e_B+e_loop(γ)`。系：**反馈是权限换灵敏度的合法交易，汇率由 γ 决定。**

**引理 40（水床/频带声明义务）** 稳定最小相位回路 `∫log|S|dω=0`（RHP 零点用 Poisson）；低频下降必伴某频段上升 ⇒ 抑制断言只能在其 `B_k` 内成立。系：**R73 单货币下界在闭环下不成立；取代它的是 `(u,e)` Pareto 下界 + `D_ω` 义务。**

**引理 41（归因-吸收权权衡）** A114 线性化下 `β_max=ε(1+Pk_p+P/λ)`；`λ↓ ⇒ β_max↑` 且抗扰精度↑，但低频谱可辨识性↓。存在不可同时最优的前沿。系：**抗扰精度与抗 stealth 权限是同一枚硬币。**

**引理 42（CAGE 保持）** 若 `E_d ≤ F_dist_max²/(2K_eff)`、`u_eff=sqrt(u_tac²+(ṡτ_d)²)`、前兆在 τ_d 内可检（A117），则 `x_g` 保持 CAGE；边距对 u_eff 单调减、对 e 单调增。

**引理 43（证据买权限单调性）** `F_dist_max=μ(F_max(e)−z_{1−α}u_eff)−m a_dist` ⇒ `∂F_dist_max/∂u_eff<0`、`∂/∂e≥0`；存在证据-权限等值线。系：**u 与 e 可经摩擦锥汇率换算，CPB 因而能做跨轮归因。**

**定理 30（DUALGAUGE 严格包含 MODGAUGE）** 取 AC 平凡（`e≡0`）、无 FDB/ADP/MIX、DIST 仅 {model,env}、`D_ω` 全域 ⇒ 逐指令等于 MODGAUGE，再退化等于 R71/R68。安全单调不减。系：**R73 是 R74 的 `e≡0` 切片。**

**定理 31（双货币证书 ⇒ 抓取安全）** `Valid(J_DUAL)` 且 `E_d ≤ E_cage` ⇒ 扰动期间保持 CAGE，滑落概率 ≤ ε_pair（相对证据/权限/归因模型）。证明重量落在耗散性在 D_A 成立、归因混淆界被遵守、τ_d 被真实覆盖。系：**单侧证书不足以支撑安全断言。**

**定理 32（反积分隐身界）** AW-SEC 门控下，任何持续未验证偏置 b 要么被检出（概率 ≥1−η），要么 `|b| ≤ β_max(λ_lock,ε)`；超过则在 `O(log(β_max/|b|)/λ_lock)` 内触发饱和/残差异常。不存在「既完全隐身又无界积分权限」的策略。系：**积分器不再是免费攻击面，代价是稳态抗扰精度（引理 41）。**

**定理 33（反馈无免费午餐 / Pareto 前沿不可支配）** A114–A118 下，不存在路径在 `(u,e)` 上同时严格优于所有输入而不违反水床与小增益；可实现的 `(u,e)` 位于 `{γ,B_k,A}` 参数化的 Pareto 前沿，R73 开环下界是 `e=0` 截距。系：**更安全的抓取只能靠证据、权限、频带三者重新分配获得。**

**假设 A114–A118**：A114 线性化回路（β_max 推导）；A115 耗散证书在 D_A 内、跨工作点 LPV 成立；A116 归因在声明检测窗口内可分离（或混淆界被遵守）；A117 微滑前兆在 τ_d 内可检；A118 Bode/Poisson 积分条件（稳定、无 RHP 极点穿越）。

## 7. 本轮最大风险

**一句话**：DUALGAUGE 把抓取安全的最后一道保证押在「干扰归因」上，而归因在有限时间与有限传感下存在**根本不可辨识性**——同一观测残差可由环境外力、传感器老化漂移或攻击者伪造偏置产生，三者在任何有限检测窗口内可能观测等价；于是一个知道归因契约的攻击者只要把伪造偏置塑造成落在声明的混淆界内，系统就会按「环境扰动」合法地把它吸收进积分器，在每张证书都有效、每步归因都「在混淆界内」的情况下安静地失去权限。

次级风险与缓解：
1. **归因不可辨识** → 强制独立物理通道复核（本体/触觉/已知几何）+ 混淆界显式入证书 + `adv→env` 上界极小；超界即拒绝而非容纳。
2. **水床/频带被下游误用** → `D_ω` 作为组合取交字段；跨频带推断直接判非法；E392 回归。
3. **耗散证书跨工况失效（LPV 间隙）** → 分片存储函数 + 切换证书；切换瞬间按 VETO；ρ_min 裕度。
4. **β_max 线性化失真** → 饱和/非线性下用区间算术给保守上界；A114 仅在声明工况内有效。
5. **CAGE 过保守导致可用性下降** → 证据-权限等值线在线重规划（引理 43）；允许「先补证据再授权限」。
6. **双货币预算被单侧优化钻空子** → 联合可行域 Φ 不可分解为 `U×E`；审计同时检查两坐标与前沿距离。
7. **归因延迟造成瞬态失稳** → τ_d 进 u_eff（定义 393）+ 前兆触发的保守 hold；E397 覆盖。
