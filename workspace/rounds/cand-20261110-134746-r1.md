# 第 44 轮（新循环第 4 轮） · Drive-Cert × Embodiment-Cert：把「关节驱动」与「通用机器人」纳入驱动接地与本体可移植的证书闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形边际覆盖 + 多用户契约空集」，但它仍压着两个未言明的单点假设：**(H3) 执行器是标称的**——语义/几何/人格证书都默认低层关节能精确执行所认证的动作；**(H4) 本体是单一的**——证书表、阈值表与失效模式默认绑定同一台机器人。本轮灵感词「关节驱动」「通用机器人」精确命中这两个假设：**关节驱动**迫使我们承认证书真正的“签名人”是执行器，力矩-转速-热-磨损-间隙-跟踪残差会让“已认证动作”在物理上不可实现；**通用机器人**迫使我们把“一套策略跨多本体”的规模红利，改写为“证书跨本体移植必须持证”的证明债务。二者耦合处才是真正的新问题：**跨本体移植 × 时变驱动健康**——源本体上的证书被搬到目标本体，而目标关节正在热降额或磨损，包络被高估时几何证书会静默失效。

## 0. 直觉与动机

**灵感 1（关节驱动 → 「地基本身会漂移」）**：几何证书说“这条轨迹不会碰”，但它只是一句承诺，真正签字的是关节驱动器。若指令要求的力矩/转速超出当前包络，跟踪误差会把实际轨迹推到证书边界之外；若电机过热、齿轮磨损、编码器退化，同一个证书今天有效、明天失效。所以驱动不是“执行细节”，而是**证书的签名人**。最保守的做法是把认证动作收缩到可实现集 \(A_e^{real}\)，收缩对 soundness 免费，但热降额时会复发可用性崩塌；要扩张，就必须为**跟踪残差管**、**能量/功率界**与**健康下界**同时持证。一句话：**可实现集是证书的地基，但地基随温度与磨损漂移，扩张必须证明残差管覆盖它。**

**灵感 2（通用机器人 → 「通用是红利，移植是债务」）**：通用策略共享感知、语义与任务先验，这是规模红利；但证书不能跨本体白嫖。源本体的“安全速度上限”搬到腿式、轮式、机械臂、人形上会因关节构型、传动比、摩擦、延迟不同而失效。正确姿势不是“一套证书打天下”，而是**本体契约 + 证书模式 + 可移植映射**：共享一个跨本体不变的安全核（能量、功率、接触力/冲量、动量），每个本体再做局部细化。一句话：**语义可以通用，证书必须本地化；免费移植的地方，一定有一个本体在静默越界。**

**灵感 3（耦合 → 健康 epoch 与负迁移）**：通用机器人往往由“源本体标定 → 目标本体部署”的流水线发布，而目标本体的驱动健康是时变的。移植映射若只在名义包络上验证，就会在热降额/磨损时变成**负迁移**：证书仍被租约保护，但租约的边距建立在过时包络上。必须把驱动健康 epoch、本体 id、证书模式 id 写进租约，让包络一缩、健康一降、本体一换，旧证书立即失效并单调降级；同时维护“已验证移植对”集合，未验证的 \((e_1,e_2,\Sigma)\) 只能走本地认证。一句话：**移植要带证明，健康要带 epoch，失效只能向保守方向走。**

**耦合升级**：AGC（驱动接地证书层）把任务证书落到可实现集与残差管；ECA（本体契约代数）把跨本体移植写成带证明义务的映射；DHV（驱动健康验证器）用在线遥测与故障注入守住包络下界，并把负迁移对纳入红线。四层架构由此从 v8 的「仿真-检索-边缘 + 人格 + 并发」升级为 v9 的「仿真-检索-边缘 + 人格 + 并发 + 驱动接地 + 本体可移植」。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（驱动包络与可实现动作集）**：设本体 \(e\) 的关节状态 \(z_q=(q,\dot q)\)，驱动状态 \(s_e=(\tau,i,T,\text{wear},\text{backlash})\)。**驱动包络**
\[
D_e(t)=\{(\dot q,\tau)\mid q\in Q_{safe},\ |\dot q|\le \dot q_{max},\ \tau\in T_e(\dot q,T,\text{wear}),\ |\tau\dot q|\le P_{max},\ T_{joint}\le T_{max}\}.
\]
**任务级可实现动作集** \(A_e^{real}(t)=\{a\in A\mid \exists u\in D_e(t):\ \mathrm{track}(a,u)\le \rho_e(t)\}\)。**驱动接地证书**
\[
C_e^{\rho}(t)=\bigl(C_{global}\cap A_e^{real}(t)\bigr)\ominus B_{\rho_e(t)},
\]
其中 \(\ominus B_\rho\) 为按跟踪残差球做腐蚀。**单调性命题**：若 \(D_{e_1}(t)\subseteq D_{e_2}(t)\)，则 \(C_{e_1}^{\rho}\subseteq C_{e_2}^{\rho}\subseteq C_{global}\)。**推论**：用保守标称包络得到的接地证书天然 sound；任何“扩张”都必须由残差证书与健康下界共同背书，否则只是把不安全藏进跟踪误差。

**定义 45（跟踪残差管与驱动接地引理）**：把跟踪残差分解为
\[
\rho_e(t)=\rho_{model}+\rho_{sat}+\rho_{thermal}+\rho_{latency}+\rho_{est},
\]
分别对应模型误差、饱和、热降额、通信/控制延迟与估计误差。**接地引理**：若规划不变量 \(S\) 满足 \(S\oplus B_{\rho_e(t)}\subseteq C_{global}\)，且底层控制器保证 \(\|x(t)-x_{plan}(t)\|\le \rho_e(t)\)，则真实状态始终留在 \(C_{global}\)；若 \(S\) 在扰动管下鲁棒不变，则结论对多步成立。**组合命题**：几何证书 + 残差管 + 能量/功率核 = 驱动接地证书；三者任一失效，接地证书失效。**注**：残差上界用“物理 Lipschitz 界 + 饱和上界 + 在线影子证书”给出，共形分位数只能作为经验佐证，不能单独作为 worst-case 保证。

**定义 46（驱动健康下界与单调退化）**：健康状态 \(h_e(t)=(\kappa_{thermal},\kappa_{wear},\beta_{backlash},f_{friction},\sigma_{enc})\)，有效包络
\[
D_e(t)=\mathrm{diag}(\kappa_h^{LB}(t))\,D_e^{nominal},\qquad \kappa_h^{LB}(t)\le \kappa_h^{true}(t).
\]
**健康下界 sound 性命题**：只要估计器输出的是真实降额因子的**单侧下界**，所有由 \(D_e(t)\) 导出的证书都 sound；唯一危险方向是**高估包络**。**故障单调性**：发生故障 \(F\)（过热、编码器异常、间隙突增、持续饱和）后，\(\kappa_h^{LB}\) 在重新标定前单调不增，健康 epoch \(h_{epoch}\) 递增。**推论**：单调退化 + 租约绑定 \(h_{epoch}\)，可保证不会用“旧包络”签“新证书”。

**定义 47（本体契约与证书可移植性）**：本体契约
\[
E=(\mathrm{Morph},\mathrm{Act},D_E\ \text{族},\mathrm{Sensors},\mathrm{Dyn},\mathrm{Latency},\mathrm{API}).
\]
证书模式 \(\Sigma=(\mathrm{pre},\mathrm{post},\mathrm{inv},\mathrm{params})\) 是参数化规范。**移植映射** \(\varphi_{e_1\to e_2}:\Sigma_{e_1}\to\Sigma_{e_2}\) **sound** 当且仅当三条证明义务同时成立：
1. **仿真/细化关系**：\(e_2\) 在 \(\varphi(a)\) 下的安全可观测量细化 \(e_1\) 在 \(a\) 下的行为；
2. **包络包含**：\(\varphi(a)\in A_{e_2}^{real}\)，且留有残差管余量；
3. **不变式保持**：\(\varphi\) 保持安全核 \(K\)、人格契约 \(\Pi_u\) 与接触力/冲量约束。
**移植定理**：若三条义务成立且目标包络用下界近似，则源证书在目标本体上 sound；任一义务失败即为**负迁移**，必须回退到目标本体的本地认证。**注**：通用策略共享的是语义/任务层，证书模式必须在每个本体上重新实例化；“可移植”是带证明的产物，不是超参数。

**定义 48（本体不变安全核与两层证书）**：定义跨本体安全核
\[
K=\{\,E_{tot}\le E_{budget},\ |P|\le P_{budget},\ \|F_{contact}\|\le F_{budget},\ \|p\|\le p_{budget}\,\},
\]
其中能量、功率、接触力/冲量、动量在不同本体上均有物理意义。能力映射 \(\gamma_e:K\to 2^{D_e}\) 把核约束细化为关节级约束。**两层证书** \(C_e=(K\cap C_{global}\cap \gamma_e(D_e))\)。**命题**：若 \(\gamma_e\) sound 且 \(K\) 鲁棒不变，则核层安全可跨本体保持；几何/任务层的性能仍由本地证书决定。**推论**：这是“通用机器人”唯一可被证明的通用性——共享不变量，不共享具体包络。

**定义 49（驱动在环的证书刷新与跨本体验证）**：证书租约扩展为
\[
\ell=(m,\tau,\lambda,\kappa,h_{epoch},e_{id},\Sigma_{id}).
\]
可用条件：\(m-\lambda(t-\tau)\ge\theta\) 且 \(h_{epoch}=h_{epoch}^{current}\) 且 \(e_{id}\) 与当前本体一致且 \(\Sigma_{id}\) 已在 \((e_{id},\Sigma_{id})\) 上验证。**重认证算子** \(\mathrm{Recert}\)：包络收缩时单调限制证书；故障时立即过期并转安全停机/阻抗保持；移植对 \((e_1,e_2,\Sigma)\) 不在已验证集合 \(\mathcal{V}\) 中时禁止迁移。**定理（无陈旧/越界证书）**：若所有守卫都检查 \(e_{id},h_{epoch},\Sigma_{id}\) 且包络始终用下界近似，则任何交错下都不存在“用旧包络/旧本体”签发的有效证书。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 ACTUATION-GROUNDED-CERT（驱动接地证书层 AGC）
1. **驱动包络编译**：电机/减速器规格 + 热模型 + 磨损模型 + 关节耦合 → \(D_e(t)\)；再经可达性/逆动力学得到 \(A_e^{real}(t)\)。
2. **残差管证书**：模型误差、饱和、热降额、延迟、估计误差 → 上界 \(\rho_e(t)\)；与几何证书做腐蚀/膨胀组合，输出 \(C_e^{\rho}\)。
3. **能量/功率安全核**：把 passivity、能量坦克、功率/接触力/冲量约束作为跨本体可移植的底层核。
4. **接地闸门**：候选动作必须先通过 \(a\in C_e^{\rho}\)；否则重规划、降级或协商，绝不让“几何上可行但驱动上不可实现”的动作进入守卫。

### 2.2 IP-61 EMBODIMENT-CONTRACT-ALGEBRA（本体契约代数 ECA）
1. **本体契约注册**：形态、关节类型/传动比、包络族、传感器、动力学参数、控制延迟、接口能力签名。
2. **证书模式与移植映射**：\(\Sigma\) 参数化；\(\varphi_{e_1\to e_2}\) 生成三条证明义务并做静态/仿真检查。
3. **通用策略适配**：共享语义/任务层；动作解码时注入目标本体能力约束，形成“能力感知的动作实例化”。
4. **负迁移检测与本地回退**：仿真 + 少量真机回归维护已验证移植集 \(\mathcal{V}\)；未验证对一律本地认证。

### 2.3 IP-62 DRIVE-HEALTH-VALIDATOR（驱动健康验证器 DHV）
1. **在线健康估计**：热降额、磨损、间隙、摩擦、编码器置信度的单侧下界估计；只允许保守方向。
2. **故障注入与退化仿真**：过热、持续饱和、编码器故障、齿轮磨损、关节抱死，覆盖“慢退化 + 突故障”。
3. **健康 epoch 租约审计**：包络/健康一变化即审计旧租约是否过期；禁止静默续租。
4. **跨本体验证**：本体 × 故障模式 × 任务矩阵；输出负迁移集合与安全案例，回灌 CKB/SCV。

## 3. 四层架构 v9

```
L0(新): 关节驱动遥测(τ,i,T,编码器,磨损) → D_e(t), h_e(t), ρ_e(t)
        → 硬件级力矩/功率/温度限幅(最后一道物理防线)
L1: TRI-FUSE(INT8) + IP-49 LIO → C_ms + B_t + L_m
    + AGC 接地: C_e^ρ = (C_global ∩ A_e^real) ⊖ B_ρ
    + 人/多用户状态 → x_human, H_u(共形意图集), τ_u
L2: CTC + VLM + IP-35 仲裁 → R_φ(w) 分支池
    + ECA 能力感知解码: 通用语义 → 目标本体动作实例化(φ 证明义务)
L3: IP-51 CAR(包络 + 残差 + 健康 epoch + persona)
    ← IP-58 CCR(租约 + RG + 混合关键级 + h_epoch)
    → IP-47 组合(本体细化 + 包络包含) → IP-39 规划(CBF margin = min(查表, 租约, 包络, persona))
    → IP-45 总线(drive/health/embodiment/portability) → IP-53 CMC(关节级监控)
L4: IP-57 PCE + IP-60 AGC + IP-61 ECA + IP-55 CKB(本体契约指纹)
    ← IP-62 DHV(健康下界 + 故障注入 + 负迁移) + IP-59 ICV(并发/人格/驱动)
    + IP-54 SCV(热/磨损/跨形态) → IP-44 蒸馏 + IP-50 课程 → RCA 重颁(本体/健康条件化)
运行期：包络估计 → 证书接地 → 租约(含 h_epoch) → 并发认证 → 残差/健康监控
        健康下降/故障 → 包络收缩 → 租约过期 → 单调降级/安全停机
        跨本体发布 → 移植证明检查 → 未验证对走本地认证 → 负迁移回灌
```

## 4. 实验设计（E95–E102 硬门槛，承接 E87–E94）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E95 驱动接地 soundness | 接地前越界率；接地后真机违例；残差超管次数 | 记录问题；0 起；0 |
| E96 跟踪残差管 | 经验残差覆盖率；管宽/性能损失；跨载荷/地形违例 | ≥99%；<20%；0 |
| E97 健康下界 | 热降额下界覆盖率；包络高估次数；磨损估计误差 | 100%；0；<15% |
| E98 热-磨损长时程 | 100h 过热事件；包络相关违例；证书刷新时延；可用性 | 0 起；0 起；<100ms；≥90% |
| E99 跨本体移植 | 本体数；移植证书违例；负迁移检出率；性能保持 | ≥4 形态；0 起；≥95%；≥80% |
| E100 通用策略×本体契约 | 多本体任务成功率；安全违例；本地回退率 | ≥基线 95%；0 起；<10% |
| E101 驱动故障注入 | 故障检出率/时延；不安全动作；安全降级成功率 | ≥95% / <200ms；0 起；≥99% |
| E102 能量/功率不变核 | 功率/能量/接触力越界；跨本体核违例；核层性能保持 | 0 起；0 起；≥90% |

回退：E95 不达标 → 锁定标称保守包络 + 硬件力矩/功率限幅；E96 不达标 → 加宽残差管并降速；E97 健康下界不可靠 → 弃用在线扩张，只保留最保守额定降额；E99 移植不达标 → 关闭跨本体移植，逐本体本地认证；E100 不达标 → 限制到已验证本体集合；E101 故障检出不足 → 硬件看门狗 + 机械限位兜底；E102 核不安全 → 撤销“通用核”声明，退回逐本体证书。

## 5. 本轮最大风险

**一句话**：驱动健康下界（尤其热/磨损导致的时变降额）与跨本体移植证明只要有一次高估或漏证，就会把“通用机器人”的规模红利变成跨本体静默失效——因此 E95/E97/E99 必须设为红线实验，默认回退到“每本体最保守标称包络 + 硬件级力矩/能量限幅”这条不依赖估计的物理底线。

## 2. 关键算法（伪代码）

### IP-60 AGC：包络编译、残差管、接地证书与安全核
```
def compile_drive_envelope(e, q, qdot, telemetry):
    # 电机/减速器规格 + 热模型 + 磨损/间隙模型 + 关节耦合
    kappa = health_lcb(telemetry)                  # 定义 46，单侧下界
    tau_max = e.tau_rated * kappa.thermal * kappa.wear
    D = { (qd, tau) for qd in joint_velocity_grid(q)
                    for tau in torque_range(q, qd, telemetry.temp)
                    if abs(qd) <= e.qdot_max
                    and tau <= tau_max
                    and abs(tau * qd) <= e.power_max
                    and joint_temp_ok(telemetry, tau, qd) }
    return D                                        # 当前有效包络

def realizable_actions(e, D, task_actions, rho):
    # 逆动力学/可达性：动作 a 是否可由包络内关节指令实现且残差可控
    return { a for a in task_actions
             if exists_joint_command(u, a, D)
             and tracking_residual_bound(a, u) <= rho }

def residual_tube(e, x, telemetry):
    rho = (model_error_bound(e, x)
           + saturation_bound(telemetry)
           + thermal_derating_bound(telemetry)
           + latency_bound(e, telemetry)
           + estimation_error_bound(telemetry))
    return rho

def grounded_cert(C_global, e, D, task_actions, rho):
    A_real = realizable_actions(e, D, task_actions, rho)
    return erode(intersect(C_global, A_real), rho)   # C_e^rho，定义 44

def energy_kernel_guard(K, e, state):
    gamma = capability_map(e)                        # K -> D_e 的细化
    return (state.E_tot <= K.E_budget
            and abs(state.P) <= K.P_budget
            and norm(state.F_contact) <= K.F_budget
            and norm(state.p) <= K.p_budget
            and gamma_admissible(gamma, state))
```

### IP-61 ECA：本体契约、移植证明与能力感知解码
```
def register_embodiment(e):
    return EmbodimentContract(
        morph=e.morphology, act=e.actuator_types, envelope_family=e.D_family,
        sensors=e.sensors, dyn=e.dynamics_params,
        latency=e.control_latency, api=e.interface_signature)

def portability_check(sigma_src, e_src, e_dst, phi):
    obligations = {
        # (1) 仿真/细化：目标在 phi(a) 下的安全可观测量细化源 a 的行为
        "simulation": simulation_refines(e_dst, phi, e_src, sigma_src),
        # (2) 包络包含：phi(a) 必须落在目标可实现集内并留残差余量
        "envelope": all(phi(a) in realizable_actions(e_dst, D_dst, {a}, rho_dst)
                        for a in sigma_src.admissible),
        # (3) 不变式保持：K / persona / contact 约束不得被放松
        "invariants": preserves_kernel(phi, K)
                      and preserves_persona(phi, sigma_src.persona)
                      and preserves_contact(phi, sigma_src.contact_limits),
    }
    return all(obligations.values()), obligations

def capability_aware_decode(task_semantics, e, sigma_src=None):
    if sigma_src is None or (e.id, sigma_src.id) not in VALIDATED_TRANSFERS:
        return local_certify(task_semantics, e)       # 未验证对：本地认证
    ok, obl = portability_check(sigma_src, e_src, e, phi_for(e_src, e, sigma_src))
    if not ok:
        record_negative_transfer(e_src, e, sigma_src, obl)
        return local_certify(task_semantics, e)       # 负迁移：绝不静默移植
    return apply_phi(phi_for(e_src, e, sigma_src), task_semantics)

def negative_transfer_campaign(embodiments, sigma_family, fault_modes):
    N = set()
    for e1, e2 in pairs(embodiments):
        for sigma in sigma_family:
            for f in fault_modes:
                e2f = inject_fault(e2, f)
                ok, obl = portability_check(sigma, e1, e2f, phi_for(e1, e2, sigma))
                if not ok: N.add((e1.id, e2.id, sigma.id, f))
    return N
```

### IP-62 DHV：健康下界、单调退化、租约审计
```
def health_lcb(telemetry):
    # 只输出单侧下界：宁可保守，不允许高估包络
    k_thermal = lower_quantile(thermal_model(telemetry.temp, telemetry.current), 0.01)
    k_wear    = lower_quantile(wear_model(telemetry.usage), 0.01)
    return Health(k_thermal=k_thermal, k_wear=k_wear,
                  backlash=estimate_backlash_lb(telemetry),
                  friction=estimate_friction_lb(telemetry),
                  enc_conf=encoder_confidence_lb(telemetry))

def monotone_fault_update(h_prev, fault):
    # 故障后只允许下降；重新完整标定前不得回升
    if fault in {OVERHEAT, ENCODER_FAULT, BACKLASH_JUMP, LOCKED_JOINT}:
        return Health(min(h_prev.k_thermal, fault.k_thermal),
                      min(h_prev.k_wear, fault.k_wear),
                      max(h_prev.backlash, fault.backlash),
                      h_prev.friction, min(h_prev.enc_conf, fault.enc_conf),
                      epoch=h_prev.epoch + 1)
    return h_prev

def audit_drive_lease(lease, e, h, sigma_id):
    return (lease_valid(lease.m, lease.tau, lease.lam, lease.kappa, now())
            and lease.h_epoch == h.epoch
            and lease.e_id == e.id
            and lease.sigma_id == sigma_id
            and sigma_id in VALIDATED_TRANSFERS.get(e.id, set()))

def cross_embodiment_validate(embodiments, tasks, fault_modes):
    report = {}
    for e in embodiments:
        for f in fault_modes:
            h = monotone_fault_update(nominal_health(e), f)
            D = compile_drive_envelope(e, e.q0, e.qd0, h)
            for t in tasks:
                cert = grounded_cert(t.C_global, e, D, t.actions, residual_tube(e, t.x0, h))
                report[(e.id, f, t.id)] = (cert.nonempty, cert.volume, D.volume)
    return report
```

### IP-49/51/53/58 升级：驱动-健康-本体感知的证书栈
```
def car_transition_guard(e, x, cert_obj, persona, lease, h, t):
    theta   = cert_obj.alpha_e[x.edge] * cert_obj.theta_sim[x.edge]
    m_lookup = cert_lookup_L0(x).m_lo[x.edge]
    m_lease  = lease.m - lease.lam * (t - lease.tau)
    m_env    = envelope_margin(e, x, h)              # D_e 内剩余余量
    m_cap    = persona_cap[x.edge](persona)
    grounded = grounded_cert(cert_obj.C_global, e, compile_drive_envelope(e, x.q, x.qd, h),
                             {x.action}, residual_tube(e, x, h))
    return (min(m_lookup, m_lease, m_env, m_cap) >= theta
            and x.action in grounded
            and audit_drive_lease(lease, e, h, cert_obj.sigma_id))

def cec_monitor_step(x, h):
    # 关节级监控：电流/温度/力矩/残差；超阈值即单调降级
    checks = [current_within(x.i, h), temperature_within(x.T, h),
              torque_within(x.tau, h), residual_within(x.e_track, h)]
    return all(checks), min_margin(checks)

def acquire_drive_lease(task, x, theta, kappa, e, h, sigma_id):
    b   = cert_lookup_L0(x)
    lam = L_m * v_max_bound(x)                       # 定义 41 的衰减率
    return Lease(m=b.m_lo, tau=monotonic_now(), lam=lam,
                 kappa=kappa, h_epoch=h.epoch, e_id=e.id, sigma_id=sigma_id)

def grounded_speculative_select(branches, e, h, persona, C_global):
    certs = parallel_map(lambda b: (b, certify_branch(b)), branches)
    valid = []
    for b, c in certs:
        D = compile_drive_envelope(e, b.x.q, b.x.qd, h)
        G = grounded_cert(intersect(C_global, persona), e, D, {b.action}, residual_tube(e, b.x, h))
        if c.valid and c.admissible <= G and energy_kernel_guard(K, e, b.state):
            valid.append((b, c))
    if not valid:
        return negotiate_or_safestop()               # 空集绝不静默放行
    return max(valid, key=lambda bc: score(bc[0]))
```

| 移植证明与真机行为不一致（仿真关系过强） | 中 | 仿真 + 少量真机回归双签；证明义务可审计；不一致即加入负迁移集 |

## 6. 本轮最大风险

**一句话**：驱动健康下界（尤其热/磨损导致的时变降额）与跨本体移植证明只要有一次高估或漏证，就会把“通用机器人”的规模红利变成跨本体静默失效——因此 E95/E97/E99 必须设为红线实验，默认回退到“每本体最保守标称包络 + 硬件级力矩/能量限幅”这条不依赖估计的物理底线。
