# 第 69 轮（承接第 68 轮「CALM-RAS 标定感知闭环」IP-243~252；灵感循环新循环第 2 轮；本轮灵感：「决策规划」×「零样本泛化」）

> 第 68 轮用在线标定回答了「我的测量还准吗」，并把「不确定就收缩」立为总纪律。但它自陈的最大风险（缓变故障被标定吸收）与真实部署一起，暴露了下一条断层：**R68 的全部保证都成立于「见过的分布、已建模的故障、可枚举的任务」之上；一旦机器人进入未见场景、遭遇未建模失效、或自行组合出从未见过的任务序列，闭环里没有任何部件有资格对「未见」作承诺。** 更棘手的是，规划器会主动把系统推向这些区域——它优化的是学到的世界模型，而模型误差最大的地方，恰恰是它最想去的方向。这是「决策规划 × 零样本泛化」这对灵感词的真正交点：**零样本泛化不是模型精度问题，而是一个闭环契约问题——模型无法对未见分布作承诺，但规划器可以承诺「只在可兑现的乐观程度上行动，并永远保留一条无模型的安全退路」。**
>
> 核心命题：
>
> **把「零样本泛化」从模型精度问题重构为「规划契约」问题：在信念空间对「名义 / 已知故障 / 未知新颖」三类情形做鲁棒与对偶规划；用共形支持集给出带「移位税」的安全边界；把 OOD 检测从观测层上移到规划后果层以抓住乐观偏差；用无模型安全盾作为不可兑现时的可微降级落点——ZEN-RAS（Zero-shot ENvelope RAS）。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**在一个我没见过的世界里，我的计划还配被信任吗**」——不可兑现的乐观必须降级为可验证的保守，而不是被静默外推。

## 0. 直觉与动机

**灵感 1（决策规划 → 分离原理在模型不确定下失效，规划器是自身模型的对手）**
直觉：在模型已知的 LQR 里，「先估计、再规划」的确定性等价原理成立。但一旦模型本身有不确定、观测只是部分可观测，分离原理就失效：**动作同时有「控制」与「信息」两种作用**，而规划器优化的是学到的模型——它天然会找到模型误差最大、预测回报最高的状态。也就是说，**规划器是自身世界模型的对抗性搜索器**，乐观偏差不是 bug 而是优化的必然产物。传统做法（在观测上做 OOD、在单步上设阈值）挡不住它：单步误差 ε 在 H 步开环里按 L^H 放大（引理 20），而「多步后果才危险」恰恰是 OOD 在观测层面看不出来的。结论：模型误差必须**计入规划代价**（风险敏感规划），并且要**在信念空间对模型集合做鲁棒规划**，而不是对一个点模型做最优化。

**灵感 2（零样本泛化 → 闭环要承诺的不是「精度不降」，而是「保留退路」）**
直觉：零样本分类的通用叙事是「准确率掉了多少」。但在闭环里，零样本失败的后果不是错一个标签，而是进入一个**不可恢复的状态**。因此正确的承诺对象不是「模型在未见分布上仍然准」（这无法被有限样本证明），而是「**安全在性能优雅退化时仍被保持**」：系统可以承认自己不会、可以变笨、可以退化成保守策略，但不能在自以为会的时候把安全裕度用光。零样本泛化的可验证形式因此是**一条退路的存在性**：从当前状态出发，无模型安全盾（CBF/能量/被动动力学）能在 T_shield 内接管并保持在不变集内；规划器只需保证「下一步的最坏可达集仍在盾的吸引域里」。这把「零样本」从「我要泛化得多好」改写为「**我允许自己泛化失败到什么程度而不出事**」——一个可以被证书约束的量。

**灵感 3（二者合流 → 新颖性预算 + 规划后果层 OOD + 共形移位税）**
直觉：R68 已有「探测预算」，本轮引入它的对偶——**新颖性预算 B_nov**：闭环在一个决策窗口内允许自己向「模型不可信区域」暴露多少步。规划目标从 max U_task 变为 max U_task − γ·EPR，s.t. 累计新颖性暴露 ≤ B_nov；信息增益动作则作为「花预算换可辨识度」的对偶手段保留。检测层面必须双通道：**观测层共形检测**（便宜但只看输入）与**规划后果层检测**（贵但看模型外推的自洽性：集成分歧、跨模态环一致性、残差非共形）。最后，共形保证在分布移位下不是免费的：覆盖率的下降由密度比上界 w_max 给出一个明确的「**移位税**」（引理 19）——零样本（w_max = ∞）时，任何有限保证都自动失效。这迫使证书**显式报告泛化债 G**，而不是含糊地宣称「泛化良好」。

**灵感 4（对 R68 风险对症）**
- R68「缓变故障被标定吸收」：把「未建模缓变失效」显式放进情形集作为 ⊥ 情形，其动力学是**集合值**的（只有可达集、没有点预测）；即使标定吸收掉了均值漂移，在 ⊥ 下规划后果的可达集仍会分叉，EPR 升高 → 触发盾或信息动作；
- R68「CAC 金标集未覆盖该故障」：泛化债 G 把「覆盖率不足」变成可度量、可撤销证书的量；G > G_max 即撤销 zero-shot 标签并降级；
- R68「表征坍缩 / 负迁移 / 伪标签偏差 / CAC 竞态」：全部继承 CALM-RAS†，不做重复论证；
- **新增盲区（本轮自陈）**：R68 为提升 wm_drift 灵敏度刻意让五头共享 trunk 以获取共模抵消（引理 15）；而规划后果层的 OOD 依赖集成分歧——**共享越强，分歧越小，成员越可能共享同一个盲区**。共模抵消与新颖性可见性在结构上互相拆台（命题 2），这是本轮最大风险的种子。

**灵感 5（一句话把三种"未知"分开）**
直觉：未知至少有三类，不能混为一谈——**已知的未知**（情形集里的 r_1..r_K，可针对建模）、**未知的未知**（⊥，只能用集合值动力学 + 盾兜底）、**关于"我是否能识别未知"的未知**（元新颖性：检测器自身可能被分布移位骗过，见定义 305）。R68 把三者都塞进 U(ĉ) 的一个标量里赌后验；ZEN-RAS 要求三者分别进入信念、预算与证书，任一不可兑现即降级。

## 1. 形式化定义（增量：定义 293–307）

**定义 293（ZEN-RAS 总览与三不变式）** ZEN-RAS = (ZSC, RBH, PRP, NBP, ZSF, CSC | CALM-RAS†)。不变式三升级：
(i) **盾优先（fallback-first）**：任何计划在提交前必须先通过「盾可达」检查；不通过则只允许执行盾动作；证书不得声称超出共形支持集的保证；
(ii) **乐观度可计价**：一切模型外推必须换算为认知规划风险 EPR 并计入新颖性预算，禁止用点预测做长时程外推；
(iii) **降级而非停机**：零样本不可兑现时进入 shield-constrained 模式，保留可验证的最小可用性——把 liveness 与 safety 同时显式化，而不是硬停（硬停是 safety=1、liveness=0 的退化角点）。

**定义 294（零样本支持集与新颖性分数）** 以名义分布 𝒟_0 的标定集 {(o_i)} 定义非共形分数 n(o)（能量分数 / Mahalanobis / 1 − p̂(o)），取共形分位数 q_α，支持集 𝒮_α = {o : n(o) ≤ q_α}。在可交换性下 P_{𝒟_0}(n ≤ q_α) ≥ 1 − α；在移位 w(o) = p_test(o)/p_0(o) 下只保留 `1 − α·w_max` 的覆盖（引理 19）。**𝒮_α 不是「安全区」，只是「模型有资格说话的区域」**。

**定义 295（情形集与信念）** ℛ = {r_0} ∪ {r_1,…,r_K} ∪ {⊥}。信念 b_t ∈ Δ(ℛ) 由贝叶斯更新（各情形对观测/残差的似然）。r_0 为名义模型；r_k 为已建模故障；**⊥ 为新颖情形，其动力学是集合值的**：s_{t+1} ∈ F_⊥(s_t, a_t) ⊆ 𝒮，只由物理约束/能量界/Lipschitz 界给出，不给点预测。b_t(⊥) 在任一新新颖性检测器触发或滚动残差非共形时上升。

**定义 296（规划后果与认知规划风险 EPR）** 对计划 π = a_{0:H−1}，
EPR(π | b) = max_{r : b(r) ≥ ε_b} [ Disagree_r(π) + λ_c·max_{t≤H} n(s_t^r) + λ_l·LoopInconsistency_r(π) ]，
其中 Disagree_r 为集成成员在 r 下滚动的方差，n(s_t^r) 为预测状态的新颖性分数，LoopInconsistency 为跨模态环（视觉-触觉-力）在滚动轨迹上的违反度。**关键：EPR 在「可信情形」上取最坏，而非取期望**——期望会奖励「赌一把」，最坏才会为未知留出裕度。

**定义 297（新颖性预算与双控制）** 计划选择
a_{0:H−1} = argmax E_b[U_task] + β·IG(a_{0:H−1}; r, c) − γ·EPR，s.t. Σ_t E_b[n(s_t)] ≤ B_nov 且盾可达（定义 299）。
β = 0 退化为纯鲁棒规划；γ = 0 退化为 R68 的乐观闭环。IG 使系统可以「花新颖性预算买可辨识度」，与本轮的对偶主题闭合。

**定义 298（零样本安全盾与吸引域）** Π_shield 为与一切学习参数解耦的模型无关控制器（CBF-QP / 能量法 / 被动动力学），不变集 S_inv，吸引域 D_ρ = {s : 在 Π_shield 下 T_shield 内可达 S_inv 且过程中满足安全约束}。规划约束：对 b 下（含 ⊥ 的集合值动力学）的**最坏下一步可达集**，要求 `Post_⊥(s_t, a_t) ⊆ D_ρ`。

**定义 299（零样本安全契约 K_zs）** K_zs = (𝒮_α, Π_shield, S_inv, T_shield, B_nov, δ_shield, ŵ_max)。计划 π 称 **zero-shot admissible** 当且仅当
(a) EPR(π) ≤ τ_epr，且 (b) 首动作的 worst-case 后继 ⊆ D_ρ，且 (c) 新颖性预算未超；
其中 ŵ_max 是移位上界的估计；**ŵ_max 未知时契约自动偏向盾**（保守侧默认），绝不默认零移位。

**定义 300（泛化债 G）** G_t = ŵ_max·α + E_b[1 − coverage(𝒮_α)] + EPR_max / τ_epr。G 单调、可观测、进证书。**G > G_max ⇒ 撤销 zero-shot 声明，降级为 supervised-only + shield**——「我不知道我能否泛化」本身必须作为一等状态被报告，而不是被平均掉。

**定义 301（组合技能契约）** 技能库 {σ}，每个技能带前置条件 σ_pre、后置条件 σ_post、验证误差 δ_σ；在线前置检查的共形误判率 α_σ。复合计划 π = σ_1∘…∘σ_n **可执行**当且仅当每个 σ_i 的前置在进入时通过检查，且 n ≤ n_max(G)。在长度 k_zs 处强制重规划——把「组合泛化」的风险截断在可验证前缀内（引理 22）。

**定义 302（移位条件共形 / 移位税）** 对任意可测集 C，P_{test}(C) = ∫_C w dP_0 ≤ w_max·P_0(C)。故 P_test(n > q_α) ≤ α·w_max，覆盖率 ≥ 1 − α·w_max。**零样本即 ŵ_max = ∞ ⇒ 有限保证为空**；这正是必须报告 G、必须保留盾的形式原因。

**定义 303（J_ZEN 证书）** J_ZEN = (J_CALM, support_hash, q_α, ŵ_max, b(⊥), EPR_max, B_nov_used, shield_reach_hash, G, n_max, zen_ver)。Valid ⇔ Valid(J_CALM) ∧ EPR ≤ τ_epr ∧ 盾可达 ∧ G ≤ G_max ∧ 新颖性预算未超 ∧ 元新颖性未告警。

**定义 304（管线）** 离线：拟合名义模型 + 已知故障模型；构建**去相关**的辅助集成（不同架构/增广/负对照训练，见命题 2）；标定共形分数；学 CBF/盾与吸引域。在线：新颖性打分 → 信念更新（含 ⊥）→ 候选计划 → 逐计划 EPR → 新颖性预算下的鲁棒/对偶选择 → 盾可达检查 → 继承 CALM-RAS†（标定/归因/前缀/风险缩放）→ 出证书。执行中 EPR 突升即重规划或切盾。

**定义 305（元新颖性 / 双检测器一致性）** 两个检测器：D_obs（观测层共形）与 D_plan（规划后果层的残差非共形/集成分歧）。新颖性判定取「与」保守合成：仅当 `D_obs ∧ D_plan` 才认为「已知的新颖」；两者不一致时标为**元不确定**，按 ⊥ 处理（最坏侧）。该定义针对「只骗过一个检测器的对抗性 OOD」。

**定义 306（零样本可用性 / 弹性指标）** 弹性剖面：L(s) = P(任务仍在推进 | 新颖度 = s)、退化斜率 dL/ds、恢复时间 T_rec、盾占用率 u_shield。**零样本泛化的人类可读定义 = 在 s 增大时 L(s) 平滑下降而非断崖，且 u_shield 有界**。

**定义 307（反事实规划回放）** 对每条实际执行的计划 π，在注入新颖情形的反事实仿真器中回放，比较 EPR(π) 与实际后果（是否违规/是否显著偏离预测）。该回放是**对检测器本身的元评测**：EPR 若不能预测真实后果，则 τ_epr 无效，证书中的 EPR 项不得计入保证。

## 2. 关键算法骨架

# IP-253 ZSC：共形零样本支持集（含移位税估计）
class ZeroShotSupportCertificate:
    def score(self, obs):
        n = self.nonconformity(obs)
        return n, n <= self.q_alpha
    def shift_tax(self):
        # w_hat_max 由影子流的密度比估计/上置信界给出；无证据时取保守大值
        return self.w_hat_max * self.alpha

# IP-254 RBH：情形信念（含集合值 ⊥）
class RegimeBeliefHypothesis:
    def update(self, obs, n_obs, residual):
        lik = {r: self.likelihood[r](obs, residual) for r in self.regimes}
        lik['⊥'] = self.novel_likelihood(n_obs)          # 新颖度 -> ⊥ 质量
        self.b = self.bayes_update(lik)
        return self.b
    def worst_next_set(self, s, a):
        return set_union([self.F[r](s, a) for r in self.regimes if self.b[r] > EPS_B])

# IP-255 PRP：规划后果层认知风险
class PlanRiskPredictor:
    def epr(self, plan, b, mtm):
        worst = 0.0
        for r in [x for x in b if b[x] >= EPS_B]:
            preds = self.rollout_ensemble(plan, r)
            disagree = self.variance(preds)
            novelty   = max(self.zsc.score(y) for y in preds)
            loop      = self.loop_inconsistency(preds)
            worst = max(worst, disagree + LC*novelty + LL*loop)
        return worst

# IP-256 NBP：新颖性预算下的鲁棒/对偶规划
def novelty_budgeted_plan(plans, b, eprs, budget):
    return argmax(plans, lambda p: task_value(p, b) + BETA*info_gain(p)
                  - GAMMA*eprs[p]
                  if expected_novelty(p, b) <= budget else -inf)

# IP-257 ZSF：盾可达检查（最坏后继进吸引域）
def shield_feasible(s, a, b, shield):
    return shield.worst_next_set(s, a, b) <= shield.domain_of_attraction

# IP-262 主闭环：ZEN-RAS round
def ZEN_RAS_round(M, obs):
    # 1) 观测层新颖性 + 情形信念（含 ⊥）
    n_obs, in_support = M.zsc.score(obs)
    b = M.rbh.update(obs, n_obs, M.last_residual)

    # 2) 候选计划 + 规划后果层认知风险（定义 296）
    plans = M.planner.propose(obs, H=M.H)
    eprs  = {p: M.prp.epr(p, b, M.mtm) for p in plans}

    # 3) 新颖性预算下的鲁棒/对偶选择（定义 297）
    plan = novelty_budgeted_plan(plans, b, eprs, M.B_nov)

    # 4) 盾优先契约：不可达 -> 只执行盾动作（定义 298/299）
    if not shield_feasible(obs.s, plan[0], b, M.zsf):
        return M.zsf.fallback(obs), 'SHIELD', M.zsc.shift_tax()

    # 5) 继承 CALM-RAS†：标定/归因/前缀/风险缩放；新颖性只许抬升不确定度
    z, o = M.mtm.forward(obs, M.a_prev, M.scene_ctx)
    c, Uc, thr = M.cof.step(o['cal'], residuals(obs, o), sigma_stat(M))
    U_zs = max(Uc, M.zsc.inflate_U(n_obs, eprs[plan]))      # 只升不降
    joint = M.cfa(o['pi'], M.fir_signature(z), c, U_zs)
    k = min(M.c_ras_wm.certified_prefix(plan, joint, M.m_ras, M.alpha_chunk),
            M.csc.n_max(M.zsc.generalization_debt()))
    lam = max(M.efs.risk_scale(joint), thr['lam_floor'],
              0.8 if (o['qual']['face'] < 0.8 or wm_drift(o)) else 0.6)

    # 6) 元新颖性 + 证书 + 泛化债（定义 300/303/305）
    if M.zsc.meta_disagree(n_obs, eprs[plan]):
        b['⊥'] = max(b['⊥'], M.beta_meta)                   # 不一致 -> 保守侧
    G = M.zsc.generalization_debt(b, eprs[plan], M.zsc.shift_tax())
    M.cert.issue(J_ZEN(M, b, eprs[plan], G))
    if G > G_MAX: return M.zsf.fallback(obs), 'DEGRADED', G

    tau = M.pi_sigma.prefix_dispatch(plan[:k]) * lam
    M.gda.replay_async(plan, M.zsc)                        # 反事实回放审计
    return tau, k, lam, (b, G)
```

## 3. 推导

**引理 19（移位税 / 零样本不是免费午餐）** 设 w_max = sup_o p_test(o)/p_0(o)。对共形支持集 𝒮_α，P_test(n > q_α) = ∫ 1[n > q_α]·w dP_0 ≤ w_max·P_0(n > q_α) ≤ α·w_max。故覆盖率 ≥ 1 − α·w_max；w_max = ∞（无重叠的零样本）时有限保证为空。**系**：任何「零样本安全」证书都必须携带 ŵ_max 与由此导出的泛化债 G；不报 ŵ_max 的零样本保证是伪保证。

**引理 20（规划乐观偏差的多步放大）** 设单步模型误差 ≤ ε、状态转移对初值 L-Lipschitz。H 步开环预测误差 ≤ ε·(L^H − 1)/(L − 1)。故以「单步 OOD」作安全判据在 H ≥ 2 时失效：最坏计划会把误差放大到跨量级。给定容差 ε_tol，认证视界 H_cert ≈ log(1 + ε_tol(L−1)/ε)/log L。**系**：R67 的认证前缀 k* 与 R69 的 n_max 必须随 EPR 单调收缩——长时程外推是零样本下最昂贵的动作。

**引理 21（盾可达 ⇒ 安全，且降级是优雅的）** 若每个执行步都满足 worst-case 后继 ⊆ D_ρ，则对任意 b（含 ⊥）系统在 T_shield 内必进入 S_inv 并保持，安全违规 = 0；可用性上界为 1 − P(s ∈ S_inv)，且随新颖度升高连续下降（因为 D_ρ 收缩、可采纳动作集缩小）。**系**：零样本下的「停机」不是唯一保守解；shield-constrained 模式给出 (safety=1, liveness>0) 的内部点，这正是定义 293(iii) 的工程价值。

**引理 22（组合泛化的线性衰减）** 复合计划 π = σ_1∘…∘σ_n，若每步前置检查误判率 α_σ、后置验证误差 δ_σ，则任务成功概率 ≥ 1 − Σ_i(α_{σ_i} + δ_{σ_i})（联合界），且存在对抗构造使该界紧到常数因子。故要保持失败率 ≤ ε，须 n ≤ ε/(α+δ) —— 与引理 20 的 H_cert 取小者，得到本轮的**可认证前缀长度** k_zs = min(H_cert, n_max, k*)。**系**：零样本组合泛化的正确旋钮不是「更强模型」，而是「更短的可信前缀 + 更强的盾」。

**定理 17（ZEN-RAS 端到端零样本风险）** 在 A87–A94 与 A98–A101（盾可达、移位上界可估、情形集包含 ⊥、去相关辅助集成）下：
1. P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + **α_zs**，其中 α_zs ≤ α·ŵ_max + exp(−T_det·D_plan) + δ_shield；
2. 若 EPR > τ_epr 或盾不可达 ⇒ 切盾，违规 = 0、可用性 ≥ L(S_inv)（引理 21）；
3. 若 G > G_max ⇒ 撤销 zero-shot 声明并降级，证书不再携带「泛化」语义；
4. 新颖性预算用尽 ⇒ 只保留信息动作与盾动作，任务回报上界 ≤ B_nov·(γ·τ_epr)。

**定理 18（泛化–可用性的不可能三角）** 对任意策略类与任意 δ < 1/2，若要求在无重叠移位（w_max = ∞）下违规率 ≤ δ，则唯一可行策略在 S_inv 外与盾一致，任务成功率 ≤ 1 − P(S_inv)（即退化为盾）；反之，若要求任务成功率 ≥ 1 − η > 1 − P(S_inv)，则必存在某个无重叠移位使其违规 > δ。**故「高零样本成功率 ∧ 零违规 ∧ 无移位假设」三者不可兼得**；ZEN-RAS 的选择是显式放弃第一条的绝对性、把第三条（ŵ_max）报出来，用 G 与盾把不可兑现的部分转成可管理的降级。

**命题 2（共模抵消 vs 新颖性可见性——本轮的结构性发现）** 设集成的第 i 个成员误差 e_i = e_c + e_i^⊥，e_c 为共享分量（同 trunk 导致），e_i^⊥ 独立。集成分歧只能观测到 e_i^⊥ 的方差，对 e_c **完全不可见**：Disagree → 0 当 ρ → 1，即使真实误差 ‖e_c‖ 很大。而 R68 引理 15 恰恰要求高 ρ 以做共模噪声抵消、提升 wm_drift 灵敏度。**同一个「共享」既让漂移检出更灵敏，又让零样本盲区更隐形**：R68 优化的量与 R69 需要的量方向相反。缓解不是折中 ρ，而是**分工**：共享 trunk 的 MTM 负责「已知故障的灵敏检出」，另建一套与 MTM 去相关的辅助集成/负对照（不同架构、不同增广、不同数据切片）专门负责「未知盲区的新颖性可见性」；EPR 用后者，wm_drift 用前者。这解释了为什么本轮必须新增 IP-255 而不能复用 MTM 五头。

## 6. 本轮最大风险

**一句话**：ZEN-RAS 的新颖性可见性建立在「辅助集成成员错误去相关」之上，而 R68 为提升 wm_drift 灵敏度刻意让五头共享 trunk 做共模抵消——**共享越强，集成分歧越小，成员越可能共享同一个盲区（命题 2）；当零样本下最危险的失效恰好落在所有成员的共同盲区里时，EPR ≈ 0，系统会以「零分歧 = 零新颖 = 零样本安全」的假象完成自我认证**，把「看不见」误当成「不存在」。

**次级风险与缓解**：
1. **移位税不可估**：ŵ_max 由影子流密度比估计，真实无重叠移位下 ŵ_max 被低估 → 保守上置信界 + 无证据时默认偏向盾 + G 显式报告，绝不默认零移位；
2. **盾的模型无关性也是假设**：CBF 依赖执行器/被动动力学模型，新颖执行器故障下盾本身可能失效 → 多盾冗余 + 出厂物理验证 + 盾失效检测纳入 ℰ_zs；
3. **元新颖性退化**：两个检测器共享同一特征提取器会一起被骗 → 检测器特征与主 trunk 解耦 + 随机化增广 + 外部审计；
4. **保守导致可用性塌陷**：EPR/预算过紧使系统长期只走盾 → 把「可用性」作为一等指标上报（定义 306），区分「安全地不可用」与「不安全地可用」，由运维而非系统自裁；
5. **反事实回放的仿真偏差**：用仿真回放审计 EPR 等于用自己的世界模型检验自己的世界模型 → 定期注入真实 canary 移位、并接受「回放通过 ≠ 真实安全」的残余不确定性。

# IP-253 ZSC：共形支持集 + 移位税
class ZeroShotSupportCertificate:
    def score(self, obs):
        n = self.nonconformity(obs)
        return n, n <= self.q_alpha
    def shift_tax(self):
        return self.w_hat_max * self.alpha        # 无证据时 w_hat_max 取保守大值

# IP-254 RBH：情形信念（含集合值 ⊥）
class RegimeBeliefHypothesis:
    def update(self, obs, n_obs, residual):
        lik = {r: self.likelihood[r](obs, residual) for r in self.regimes}
        lik['⊥'] = self.novel_likelihood(n_obs)
        self.b = self.bayes_update(lik); return self.b
    def worst_next_set(self, s, a):
        return set_union([self.F[r](s, a) for r in self.regimes if self.b[r] > EPS_B])

# IP-255 PRP：规划后果层认知风险（取最坏，不取期望）
class PlanRiskPredictor:
    def epr(self, plan, b):
        worst = 0.0
        for r in [x for x in b if b[x] >= EPS_B]:
            preds = self.rollout_ensemble(plan, r)
            worst = max(worst, self.variance(preds)
                        + LC*max(self.zsc.score(y) for y in preds)
                        + LL*self.loop_inconsistency(preds))
        return worst

# IP-256 NBP：新颖性预算下的鲁棒/对偶规划
def novelty_budgeted_plan(plans, b, eprs, budget):
    return argmax(plans, lambda p: task_value(p, b) + BETA*info_gain(p) - GAMMA*eprs[p]
                  if expected_novelty(p, b) <= budget else -inf)

# IP-257 ZSF：盾可达（最坏后继进吸引域）
def shield_feasible(s, a, b, shield):
    return shield.worst_next_set(s, a, b) <= shield.domain_of_attraction

# IP-262 主闭环
def ZEN_RAS_round(M, obs):
    n_obs, in_support = M.zsc.score(obs)                       # 1) 观测层新颖性
    b = M.rbh.update(obs, n_obs, M.last_residual)              #    情形信念（含 ⊥）
    plans = M.planner.propose(obs, H=M.H)
    eprs  = {p: M.prp.epr(p, b) for p in plans}                # 2) 规划后果风险
    plan  = novelty_budgeted_plan(plans, b, eprs, M.B_nov)     # 3) 预算内鲁棒选择
    if not shield_feasible(obs.s, plan[0], b, M.zsf):          # 4) 盾优先契约
        return M.zsf.fallback(obs), 'SHIELD', M.zsc.shift_tax()

    z, o = M.mtm.forward(obs, M.a_prev, M.scene_ctx)           # 5) 继承 CALM-RAS†
    c, Uc, thr = M.cof.step(o['cal'], residuals(obs, o), sigma_stat(M))
    U_zs = max(Uc, M.zsc.inflate_U(n_obs, eprs[plan]))         #    新颖性只升不降
    joint = M.cfa(o['pi'], M.fir_signature(z), c, U_zs)
    k = min(M.c_ras_wm.certified_prefix(plan, joint, M.m_ras, M.alpha_chunk),
            M.csc.n_max(M.zsc.generalization_debt()))
    lam = max(M.efs.risk_scale(joint), thr['lam_floor'],
              0.8 if (o['qual']['face'] < 0.8 or wm_drift(o)) else 0.6)

    if M.zsc.meta_disagree(n_obs, eprs[plan]):                 # 6) 元新颖性
        b['⊥'] = max(b['⊥'], M.beta_meta)
    G = M.zsc.generalization_debt(b, eprs[plan], M.zsc.shift_tax())
    M.cert.issue(J_ZEN(M, b, eprs[plan], G))
    if G > G_MAX: return M.zsf.fallback(obs), 'DEGRADED', G

    M.gda.replay_async(plan, M.zsc)                            # 反事实回放审计
    return M.pi_sigma.prefix_dispatch(plan[:k]) * lam, k, lam, (b, G)
```

## 4. 推导

**引理 19（移位税 / 零样本不是免费午餐）** `P_test(n>q_α) = ∫1[n>q_α]·w dP_0 ≤ w_max·α`，故覆盖率 ≥ `1−α·w_max`；w_max=∞ 时有限保证为空。**系**：不报 ŵ_max 的零样本安全保证是伪保证，必须携带泛化债 G。

**引理 20（乐观偏差多步放大）** 单步误差 ε、L-Lipschitz 下 H 步开环误差 ≤ `ε(L^H−1)/(L−1)`；认证视界 `H_cert≈log(1+ε_tol(L−1)/ε)/log L`。单步 OOD 在 H≥2 时失效——长时程外推是零样本下最昂贵的动作。

**引理 21（盾可达 ⇒ 安全且优雅降级）** 每步 worst-case 后继 ⊆ D_ρ ⇒ 必在 T_shield 内进 S_inv，违规=0；可用性上界 `1−P(S_inv)`，随新颖度连续下降。零样本保守解不只有停机，(safety=1, liveness>0) 的内部点由盾给出。

**引理 22（组合泛化线性衰减）** 复合 n 技能成功 ≥ `1−Σ(α_σ+δ_σ)`（联合界，且紧到常数）；保持失败 ≤ ε 需 `n≤ε/(α+δ)`。与引理 20 取小得可认证前缀 `k_zs=min(H_cert,n_max,k*)`——零样本组合的正确旋钮是更短可信前缀 + 更强盾，而非更强模型。

**定理 17（端到端零样本风险）** A87–A94、A98–A101 下：
1. `P(|τ_cmd−τ*|>ε) ≤ Σα_prev + α_zs`，`α_zs ≤ α·ŵ_max + exp(−T_det·D_plan) + δ_shield`；
2. `EPR>τ_epr` 或盾不可达 ⇒ 切盾，违规=0、可用性 ≥ L(S_inv)；
3. `G>G_max` ⇒ 撤销 zero-shot 声明并降级；
4. 预算用尽 ⇒ 只剩信息动作与盾动作。

**定理 18（泛化–可用性不可能三角）** 无重叠移位（w_max=∞）下要求违规 ≤ δ<1/2，则 S_inv 外必须与盾一致，成功率 ≤ 1−P(S_inv)；反之要求成功率更高，则存在某无重叠移位使违规 > δ。**高零样本成功率 ∧ 零违规 ∧ 无移位假设三者不可兼得**；ZEN-RAS 显式放弃第一条的绝对性、把第三条报成 ŵ_max，用 G 与盾把不可兑现部分转为可管理降级。

**命题 2（共模抵消 vs 新颖性可见性）** 成员误差 `e_i=e_c+e_i^⊥`，集成分歧只见 e_i^⊥ 方差，对共享 e_c 不可见：ρ→1 时 Disagree→0，即使 ‖e_c‖ 很大。R68 引理 15 恰要求高 ρ 做共模抵消以提升 wm_drift 灵敏度——**同一「共享」既让已知漂移更灵敏，又让零样本盲区更隐形**。缓解不是折中 ρ 而是分工：MTM 共享 trunk 负责已知故障检出，另建与 MTM 去相关的辅助集成/负对照负责未知盲区；EPR 用后者。这解释了为何必须新增 IP-255 而不能复用 MTM 五头。

## 7. 本轮最大风险

**一句话**：ZEN-RAS 的新颖性可见性依赖「辅助集成成员错误去相关」，而 R68 为提升 wm_drift 灵敏度刻意让五头共享 trunk 做共模抵消——共享越强，集成分歧越小，成员越可能共享同一盲区（命题 2）；当零样本下最危险的失效落在所有成员的共同盲区时，EPR ≈ 0，系统会以「零分歧 = 零新颖 = 零样本安全」的假象自我认证，把「看不见」误当成「不存在」。

**次级风险与缓解**：移位税不可估（ŵ_max 保守上置信界 + 无证据默认偏盾 + G 显式上报，绝不默认零移位）；盾的模型无关性也是假设（多盾冗余 + 出厂物理验证 + 盾失效纳入 ℰ_zs）；元新颖性退化（检测器特征与主 trunk 解耦 + 随机化增广 + 外部审计）；保守致可用性塌陷（可用性作为一等指标上报，运维裁定而非系统自裁）；反事实回放的仿真偏差（注入真实 canary 移位 + 承认「回放通过 ≠ 真实安全」的残余不确定性）。
