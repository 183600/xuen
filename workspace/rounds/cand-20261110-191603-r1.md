# 第 47 轮（承接第 46 轮 v10/v23；本轮灵感：通信延迟 × 语义分割） · Latency-Semantic：延迟租约与 stale-mask 驱动的语义安全证书与关键区域延迟分配（五层架构 v11）

> 承接第 46 轮 v23 MVR×VAD×SAB。v23 补齐了记忆-语音-安全链路，但隐含假设 H5：语义理解与通信链路是**无延迟、可随时获取**的。UniBot 实机中语义分割（开放词汇分割/实例掩码）常需上边缘 GPU 或云端，端到端延迟 80–300ms 且抖动显著；通信延迟使"看到的场景"与"执行动作的时刻"错位，语义掩码在被使用时已经 stale。两个灵感词精确命中 H5：**通信延迟**把观测新鲜度升为一等公民，需要延迟租约 ℓ_τ 与 worst-case age；**语义分割**给出物体级/区域级安全语义，但其边界与类别置信会随延迟漂移。耦合出新问题：**如何用延迟租约约束 stale 语义掩码的可用性，把碰撞包络/操作目标等语义关键区域的延迟预算做最优分配，并在语义漂移超出安全裕度时 fail-closed，而非静默执行**。

## 0. 直觉与动机

**灵感 1（通信延迟 → 延迟租约与 last-mile 新鲜度）**
直觉：延迟不是"慢一点"，而是"证书在被使用前就已过期"。任何基于 t-τ 时刻观测签发的姿态/语义证书，必须扣掉 age = now - t_stamp（含时钟偏移 δ）和推理耗时；否则证书的 soundness 会被时间悄悄侵蚀。把延迟建模为租约 ℓ_τ=(τ_max, σ_jitter, δ_clock, t_stamp, k)，有效新鲜度 τ_eff = τ_max - age - k·σ_jitter。若 τ_eff ≤ 0，所有依赖该观测的证书级联失效——延迟租约与能量租约 ℓ_e 并列，成为根信任的第三条腿。

**灵感 2（语义分割 → 区域语义与安全边界）**
直觉：语义分割的价值不在"全图好看"，而在碰撞包络附近物体边界是否可靠。定义逐像素标签分布与边界带，把下游安全敏感度写成区域临界度 κ。分割边界不确定性会直接膨胀姿态证书半径；而类别翻转（如把"可穿越的帘布"误判为"刚性障碍"或反之）比像素误差更危险，属于语义层面的 soundness 漏洞。

**灵感 3（耦合 → 语义漂移界与关键区域延迟分配）**
直觉：不要用"均匀降分辨率"来省延迟。给碰撞包络/操作目标所在 ROI 分配高分辨率与更短队列延迟，给背景分配粗分割甚至复用上一帧；这才是把延迟花在刀刃上。语义漂移 D_s(τ) 与物体速度、动力学 Lipschitz、边界不确定度相关；当 D_s(τ_eff) ≥ 到碰撞包络的安全裕度 margin 时，stale 掩码已不可信，必须 inflate 证书或 fail-closed。

**耦合升级**：四层 v10 → 五层 v11。根信任层新增延迟租约 ℓ_τ；L1 几何层引入语义分区并与姿态分区对齐；L2 上下文-记忆层给记忆条目加延迟戳；L3 安全层加入语义漂移守卫；L4 采集层计入延迟/带宽成本；新增 **L5 语义-延迟调度层 SLS**。核心问题从"感知开关"升级为"**在双租约（能量×延迟）与语义漂移约束下，把有限延迟预算分配到安全关键区域，并给出可证伪的 stale-mask 安全证书**"。

## 1. 形式化定义（增量：定义 59–64）

**定义 59（延迟租约与有效新鲜度）**
设观测时间戳 t_stamp、当前时刻 now、最坏端到端延迟 τ_max、抖动标准差 σ_jitter、时钟偏移 δ_clock、安全系数 k。定义
age(o) = now - t_stamp + δ_clock， τ_eff = τ_max - age(o) - k·σ_jitter。
**延迟可行判据**：ℓ_τ 有效 iff τ_eff > 0 且 |δ_clock| ≤ δ_max。失效时所有依赖该观测的语义/姿态证书级联失效。

**定义 60（语义分割掩码与边界置信）**
逐像素标签分布 p(l|x) ∈ Δ^{|L|}，分割掩码 S_t = { x : argmax_l p(l|x) ∈ L_obj }，边界带 B_ε = { x : dist(x, ∂S_t) ≤ ε }，边界不确定度 u_b = mean_{x∈B_ε} H(p(·|x))。类别翻转风险 R_flip = Σ_x 1[argmax 发生跨安全类跳变]·p。

**定义 61（语义漂移界）**
设物体速度上界 v_max、场景动力学 Lipschitz 常数 L_v、边界带换算系数 ρ_b。在延迟 τ 内
D_s(τ) = v_max·τ + L_v·τ·rad(P_t) + u_b·ρ_b。
D_s(τ) 是对"真实掩码与 stale 掩码对称差"的保守上界；它把时间不确定度转成空间不确定度。

**定义 62（区域临界度与延迟预算分配）**
对 ROI r，临界度 κ(r) = S_col(r)·prox(r, ∂E)·rel(r, task)，其中 ∂E 为碰撞/禁入包络边界。延迟/算力预算 C_budget 的分配为
max_{cfg} Σ_r κ(r)·Δmargin(r; cfg_r)
s.t. Σ_r cost(r, cfg_r) ≤ C_budget， max_r τ(r, cfg_r) ≤ τ_max。
即"把高分辨率与低队列延迟优先给高临界度 ROI"，背景走粗分割或帧间复用。

**定义 63（延迟-语义联合证书与 stale 校正）**
联合证书 J_t = (P_t, ℓ_p, ℓ_e, ℓ_τ, S_t)。**联合 soundness**：
P( X_t ∈ P_t ∧ 对 S_t 无碰撞 | ℓ_τ 有效, ℓ_e 有效 ) ≥ 1 - α_p。
**stale 校正规则**：若 D_s(τ_eff) ≥ margin(S_t, ∂E)，则 P_t ← inflate(P_t, D_s(τ_eff) - margin)；若膨胀后 rad(P_t) > r_max 或 R_flip > θ_flip，则整张证书失效、fail-closed。

**定义 64（语义-延迟调度策略）**
策略 π_s(cfg, ROI, ℓ_τ, ℓ_e) = cfg^* 最大化
U_s = Σ_r κ(r)·[ E_{ω}[安全裕度增益(r; cfg_r)] ] / [ cost(r, cfg_r) + λ_τ·τ(r, cfg_r) + λ_e·P(cfg_r) ]
约束：τ_eff > 0，E(t+Δ) ≥ E_min，且高临界度 ROI 的 cfg 不得低于安全下限（保守下界，防止为省延迟牺牲关键区）。

## 2. 新增产出与既有 IP 升级

**IP-69 SLS（Semantic-Latency Scheduler）**
- 区域临界度评估：碰撞包络距离、任务相关性、类别翻转代价
- 延迟/分辨率预算分配：机载粗分割保底 + 边缘/云端细分割加速
- 关键区域下界约束：高 κ ROI 强制最小分辨率与最大队列延迟
- 双租约联动：ℓ_τ 与 ℓ_e 同时可行才放行高成本配置

**IP-70 SDP（Semantic Drift Predictor）**
- 光流/相对运动估计物体速度与边界偏移
- 保守漂移界 D_s(τ_eff)：速度上界 + Lipschitz + 边界熵
- 欠估监测：用下一帧真值回查预测界，欠估样本回灌 DCL

**IP-71 LSC（Latency-Semantic Certificate Adapter）**
- 从 ℓ_τ 扣除 age 与抖动，计算 τ_eff
- 距离变换求 margin(S_t, ∂E)，执行 stale 校正/膨胀
- 漂移越界、类别翻转超阈、租约过期 → fail-closed

**既有 IP 升级**
IP-63 ECPS：能量租约 × 延迟租约的联合可行域，任一过期即级联失效
IP-66 MVR：记忆条目增加 t_stamp 与 τ_eff，stale 记忆禁止复用
IP-68 SAB：B(v, P, S) 中加入语义漂移裕度，stale 语义下降低绑定概率
IP-51 CAR：守卫新增 ℓ_τ 有效 与 D_s(τ_eff) < margin 两项
IP-45 总线：新增 latency-lease / seg-mask / drift-pred / roi-budget 话题

## 3. 算法骨架

SLS 每个分割周期：
1. 读 ℓ_τ、ℓ_e、ROI 临界度 κ、上一帧 S_{t-1}
2. 机载低分辨率全图粗分割保底（确保 τ_eff 始终有值）
3. 按 κ/cost 贪心分配细分割预算给高临界 ROI
4. SDP 用运动/边界熵估计 D_s(τ_eff)
5. LSC 用 τ_eff、D_s 校正 P_t，检查 margin 与 R_flip
6. 若 ℓ_τ 失效 / 漂移越界 / 类别翻转超阈 → 降级机载粗分割或 fail-closed
7. CAR 用联合证书守卫动作；必要时进入 Q_safe 等待新鲜观测

## 4. 本轮最大风险

**一句话**：语义漂移界 D_s(τ_eff) 一旦对快速/形变物体与时钟偏移估计不足，stale 掩码会在证书仍显示"有效"时越过碰撞包络，造成静默的安全违例；因此必须用 v_max/L_v 的保守上界、最坏时钟偏移和边界熵三重膨胀，并在 margin 不足以覆盖 D_s 时无条件 fail-closed，而不是继续用上一帧掩码执行。

## 2. 关键算法 伪代码

### IP-69 SLS：延迟预算分配
```
def criticality(roi, P_t, task, envelope):
    return (collision_sensitivity(roi)
            * proximity(roi, boundary(envelope))
            * task_relevance(roi, task))

def allocate_roi(rois, kappa, C_budget, tau_max):
    # 机载低分辨率全图粗分割保底，保证 τ_eff 始终有值
    cfg = {r: 'coarse_onboard' for r in rois}
    spent = cost_full_coarse
    # 高临界度 ROI 先拿细分割预算
    order = sorted(rois, key=lambda r: kappa[r] / max(cost(r,'fine'), eps),
                   reverse=True)
    for r in order:
        if spent + cost(r, 'fine') <= C_budget and tau(r,'fine') <= tau_max:
            cfg[r] = 'fine_edge'
            spent += cost(r, 'fine')
        elif kappa[r] >= kappa_safe_lower:
            # 保守下界：关键区不得低于最小安全配置
            cfg[r] = 'fine_onboard'
    return cfg
```

### IP-70 SDP：语义漂移界
```
def semantic_drift(flow, v_max, L_v, tau_eff, u_b, P_t, rho_b):
    d_flow = velocity_bound(flow) * tau_eff
    d_dyn  = L_v * tau_eff * P_t.radius
    d_bnd  = u_b * rho_b
    return d_flow + d_dyn + d_bnd   # 保守上界

def check_underestimate(D_pred, D_true, stats):
    if D_true > D_pred:            # 界被突破，说明模型欠估
        stats['under'] += 1
        return 'underestimate'
    return 'ok'
```

### IP-71 LSC：联合证书
```
def latency_lease(t_stamp, now, tau_max, sigma_j, delta_clock, k=3.0):
    age = now - t_stamp + delta_clock
    tau_eff = tau_max - age - k * sigma_j
    valid = (tau_eff > 0) and (abs(delta_clock) <= delta_max)
    return age, tau_eff, valid

def lsc_certify(P_t, S_t, tau_eff, D_s, margin, R_flip,
                r_max, theta_flip):
    if tau_eff <= 0:
        return None, 'latency_lease_expired'
    if R_flip > theta_flip:
        return None, 'semantic_flip_risk'
    if D_s >= margin:
        # stale 掩码可能越过碰撞包络：保守膨胀姿态证书
        P_t = inflate(P_t, D_s - margin)
        if P_t.radius > r_max:
            return None, 'semantic_drift_exceeds_margin'
    return (P_t, S_t), 'certified'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SLS 预算分配 | O(|ROI| log|ROI|) | O(|ROI|) | 高 κ ROI 不低于安全下限，预算不超 C_budget |
| SDP 漂移估计 | O(|mask|) 光流+距离变换 | O(|mask|) | D_s 为保守上界（速度/Lipschitz/熵三重膨胀） |
| LSC 证书校正 | O(|mask|) 距离变换 | O(|mask|) | τ_eff>0 且 D_s<margin 才签发；否则 fail-closed |
| 全局决策 v24 | O(|M|+|mask|) | O(|mask|) | 双租约 + 语义守卫 + 记忆/队列 ⇒ 无静默失效 |

**正确性定理**：设 D_s(τ_eff) 为对称差漂移的合法上界，margin 由掩码到碰撞包络的距离变换给出，且时钟偏移有界 |δ_clock|≤δ_max。若 ℓ_τ 有效且 D_s(τ_eff) < margin，则执行时刻 t+τ_eff 的真实语义几何与 stale 掩码的偏差被 margin 覆盖，任何对膨胀后 P_t 无碰撞的动作对真实场景仍无碰撞，概率 ≥ 1-α_p；若校验不满足，则 LSC 返回失效并 fail-closed，不产生安全性未知的执行。

| 类别翻转（帘布/玻璃/反光） | 高 | 用深度/多帧一致性交叉校验；R_flip 超阈拒绝执行 |

## 6. 本轮最大风险

**一句话**：语义漂移界对快速/形变物体与时钟偏移的欠估会让 stale 掩码在证书"仍有效"时越过碰撞包络，造成静默安全违例；因此必须采用最坏速度、最坏时钟偏移与边界熵三重保守膨胀，并在 margin 无法覆盖 D_s 或类别翻转风险超阈时无条件 fail-closed。
