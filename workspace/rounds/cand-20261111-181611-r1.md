# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；本轮灵感：「安全性」×「交互设计」）

> 第 54 轮把技能组合抬升为动作空间剖面 α_S、组合图 G_S 与云边映射 γ_ce 的可判定问题。本轮引入两条新矛盾：H22：**证书可读性缺口**——内部 sound 的联合证书 J 若不能转化为人类可感知、可执行的动作选项，则在真实交互环路中不产生安全增益，形成「证书完备而交互失效」的安全幻觉；H23：**授权逆权窗口**——共享控制中若授权切换不以人类响应时延 τ_h 与双方不变式同时成立为前提，则会出现「当前控制方已无法阻止违规、而另一方可阻止却未获授权」的窗口。

## 0. 直觉与动机

**灵感 1（安全性是交互环路的联合不变式，而非自主策略的孤立属性）**
直觉：前 54 轮的安全/鲁棒性证书 ρ、A_cert、J 都默认「系统自己执行」。但具身系统中大量安全边界由人机共享控制决定：人看见什么、理解什么、多久能反应，直接决定安全集是否真正可达。一个必须在 200ms 内接管、却只在 800ms 后才显示的警告，不是安全机制。于是安全应从「策略不变式」升级为「交互可操作安全集」`S_I(τ_h^max)`：在人类最长响应时间内，机器仅靠自身回退动作仍能守住安全函数 `h(x)≥0` 的状态集合。

**灵感 2（交互设计 = 把内部证书编译为可操作 affordance）**
直觉：证书不是给人看的日志，而是交互设计的输入。交互层应把 `(ρ, A_cert, J)` 编译为「此刻唯一安全的动作 + 其代价 + 不做的后果」三件套。定义 **可读性** `Leg(y)=I(U*;y)`（信号 y 与最优安全动作的互信息）与 **可操作性** `Act(y)=P(u_h=u*|y)`，并用 **理解缺口** `Δ_c` 度量人类推断证书与内部证书的偏差。`Δ_c` 超阈值时，即使 J sound，部署安全概率也应打折——这正是「安全幻觉」的形式化入口。

**灵感 3（共享控制：授权状态机与 handover-safe set）**
直觉：安全交互的核心不是「谁更聪明」，而是「何时允许换手」。把授权建模为 `A_auth: X→{M,H,S}`，规定只有在双方都能在 `τ_ho` 内独立维持不变式的 **可交接集** `S_ho` 内才允许切换；并把「控制方已无可行动作、而另一方可救」的时间段记为 **逆权窗口** `W_inv`，作为一等安全指标而非事后复盘。

**灵感 4（可争辩的安全案例：挑战-反事实-回应）**
直觉：交互设计不仅是「系统告诉人」，也包括「人质疑系统」。接第 53 轮 Explain，定义 **安全挑战协议 SCR**：人类可就任一证书提出反事实挑战（“若我此时左转会怎样”），系统必须在 `τ_cr` 内给出可验证反例或修正证书。安全案例因此从单向声明变为可争辩的对话，且挑战日志进入证书证据链。

**灵感 5（风险账本与可逆承诺：优雅降级）**
直觉：把总安全预算显式分解为 `ε_tot=ε_m+ε_h+ε_c+ε_unk`（机器、人类、通信、未知），运行时单调记账；当 `R(t)+risk(u)>ε_tot` 时触发降级/回退。与之配套，只有在 `δ_r` 预算内存在回收动作的 **可逆动作** 才允许在 `S_I` 之外执行。安全和交互由此共享同一个预算语义，避免「各层证书都 sound、合起来预算超支」。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（交互可操作安全集）**
设联合状态 `x∈X`，机器动作 `u_m∈U_m`，人类动作 `u_h∈U_h`，交互信号 `y=σ(x,J)`，人类响应时延随机变量 `τ_h`，安全函数 `h:X→ℝ`。定义
```
S_I(τ_h^max) = { x∈X | h(x)≥0 ∧ ∃ u_m^fb∈U_m^safe :
                 ∀ t∈[0,τ_h^max], h(x(t;u_m^fb)) ≥ 0 }
```
即机器单独回退即可覆盖人类最长响应期的状态集。`S_I ⊆ S_safe`，缺口 `S_safe \ S_I` 是「必须依赖人类及时接管」的危险带。

**定义 122（交互契约）**
交互契约 `C_I=(O_m,O_h,S_I,A_auth,fb)`：
- `O_m`：进入 `∂S_I` 前 `δ_w` 内展示证书、给出安全动作与后果，并请求接管；
- `O_h`：在 `τ_h^max` 内响应，超时则授权自动回退；
- `A_auth`：授权状态机（定义 124）；
- `fb`：回退策略，满足 `fb` 在 `S_I` 内保持不变式。

**定义 123（可读性、可操作性与理解缺口）**
```
Leg(y) = I(U*; y)
Act(y) = P(u_h = u* | y)
Δ_c    = D_KL( cert_human(·|y) || cert_internal )
```
其中 `U*` 为 `S_I` 内的安全动作集，`u*=argmax_{u∈U*} safe_value(u)`。可部署要求 `Act(y)≥θ_act ∧ Δ_c≤Θ_c`。注意 `Leg` 高不蕴含 `Act` 高（信息可读但不可执行），二者需同时约束。

**定义 124（授权分配与逆权窗口）**
授权状态机 `A_auth: X→{M,H,S}`（M 机器、H 人类、S 共享）。可交接集
```
S_ho = { x | Inv_M(x,τ_ho) ∧ Inv_H(x,τ_ho) }
```
其中 `Inv_*(x,τ)` 表示该控制方在 τ 内存在保持 `h≥0` 的动作序列。逆权窗口
```
W_inv = { t | A_auth(x(t))=M ∧ ¬Inv_M(x(t),τ_h) ∧ Inv_H(x(t),τ_h) }
```
其测度 `|W_inv|` 必须 `≤ Θ_inv`；H→M 对称定义。逆权窗口是「名义控制方已失去可行动作、实际可救方未获授权」的时间。

**定义 125（安全交互证书）**
```
J_I = (S_I, C_I, Leg, Act, Δ_c, auth_trace, challenge_log, ε_tot, R(t))
```
部署条件：
```
dom(J_I)=in ∧ Act≥θ_act ∧ Δ_c≤Θ_c ∧ |W_inv|≤Θ_inv ∧ R(t)≤ε_tot
```

**定义 126（可逆安全承诺）**
动作 `u` 在 `x` 处 `δ_r`-可逆，若存在回收动作 `r` 与 `τ_rec`，使 `cost(r)≤δ_r` 且 `x(t+τ_rec;u,r)∈S_safe`。记
```
Rev(x,u) = max{ δ_r | ∃r, x(t+τ_rec;u,r)∈S_safe }
```
在 `S_I` 外仅允许 `Rev(x,u)≥Rev_min` 的动作；这把「安全」转化为对动作可撤销性的约束。

**定义 127（风险账本）**
`ε_tot=ε_m+ε_h+ε_c+ε_unk`；风险增量 `risk(u,x)` 满足次可加性。账本
```
R(t+1) = R(t) + risk(u_t,x_t),   R(0)=0
```
若 `R(t)+risk(u,x) > ε_tot` 则降级到 `fb` 或拒绝。账本单调、不可回填；重校准只能在部署外进行。

## 2. 关键算法 伪代码

### IP-121 SIL（Safety-Interaction Loop）

```python
def interaction_safe_set(safe_fn, U_m_safe, tau_h_max, dt, state_grid):
    S_I = {}
    for x in state_grid:
        if safe_fn(x) < 0:
            S_I[x] = False
            continue
        ok = False
        for u_fb in U_m_safe:
            if all(safe_fn(rollout(x, u_fb, t)) >= 0
                   for t in np.arange(0, tau_h_max + dt, dt)):
                ok = True
                break
        S_I[x] = ok
    return S_I
```

### IP-122 LSV（Legibility-Safety Verification）

```python
def verify_legibility(signal_map, human_model, certs, theta_act, theta_c):
    report = []
    for x, J in certs:
        y = signal_map(x, J)
        u_star = safe_argmin(J.S_I, x)
        act = human_model.p_action(y, u_star)
        delta_c = kl_divergence(human_model.cert(y), J.to_cert())
        if act < theta_act:
            report.append(('unactionable', x, act))
        if delta_c > theta_c:
            report.append(('misunderstood', x, delta_c))
    return report
```

### IP-123 AAM（Authority Arbitration Monitor）

```python
def authority_monitor(x, tau_h, inv_M, inv_H, auth, S_ho):
    if auth == 'M' and not inv_M(x, tau_h) and inv_H(x, tau_h):
        return ('authority_inversion', transfer('M', 'H', x))
    if auth == 'H' and not inv_H(x, tau_h) and inv_M(x, tau_h):
        return ('authority_inversion', transfer('H', 'M', x))
    if inside(x, S_ho):
        return ('handover_safe', None)
    return ('hold', None)
```

### IP-124 SCR（Safety Challenge-Response）

```python
def challenge_response(J, challenge, sim_model, tau_cr):
    trace = sim_model.run(challenge.x, challenge.u_alt, horizon=tau_cr)
    if violates(trace, J.S_I):
        witness = extract_witness(trace)
        return ('counterexample', witness, revise(J, trace))
    return ('no_counterexample', certificate_for(trace), J)
```

### IP-125 RBL（Risk-Budget Ledger）

```python
def ledger_step(R, eps_total, risk_u, fallback):
    if R + risk_u > eps_total:
        return ('degrade', fallback, R)
    return ('continue', None, R + risk_u)
```

### IP-126 RSC（Reversible Safety Commitment）

```python
def admissible(x, u, Rev_min, S_I, tau_rec):
    if inside(x, S_I):
        return True
    return Rev(x, u, tau_rec) >= Rev_min
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SIL | O(|X|·|U_m^safe|·(τ_h^max/dt)) | O(|X|) | 回退覆盖完整、时域离散上界 |
| LSV | O(|cert|·(|Y|+|U|)) | O(|Y|) | 人类模型校准、KL 估计无偏 |
| AAM | O(1) 每步（查表 + 不变式查询） | O(|X|) | τ_h 保守、S_ho 判定 sound |
| SCR | O(τ_cr/dt·|X|) | O(τ_cr/dt) | 反例可复现、修正单调 |
| RBL | O(1) | O(1) | 风险次可加、ε_tot 有效上界 |
| RSC | O(|R|·τ_rec/dt) | O(|R|) | 回收动作完备、Rev 下界保守 |

**正确性定理（Interaction-Aware Safety Soundness）**
承接 (A22)–(A28)；新增 **(A29)** 人类模型 `π_h` 在部署分布上校准，`τ_h` 取保守上界；**(A30)** 交互信号满足 `Act≥θ_act, Δ_c≤Θ_c`；**(A31)** 回退 `fb` 在 `S_I` 内保持不变式；**(A32)** 风险账本次可加且未知项上界 `ε_unk` 有效。则
```
P(violation) ≤ ε_m + P(τ_h > τ_h^max) + P(Δ_c > Θ_c)
             + P(|W_inv| > Θ_inv) + ε_unk
```
关键：安全增益不来自证书更 sound，而来自 **证书被转化为可执行动作**；`Δ_c` 与 `|W_inv|` 是把「可解释/可交互」纳入安全概率的两个显式扣减项。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 人类响应模型失配（慢反应/分心） | 高 | 分人群校准 + τ_h 保守上界 + 在线漂移检测 |
| 过度可读化导致告警疲劳与自满 | 高 | 自适应显著性 + 动作化而非文字堆叠 + 定期演练 |
| 授权抖动/频繁换手 | 中 | 滞回 + 授权锁 + `S_ho` 停留时间约束 |
| 安全案例被「表演式可争辩」糊弄 | 高 | 独立红队挑战 + 反例可复现性审计 |
| 风险账本重复计数或隐藏耦合 | 中 | 保守联合上界 + 层间相关性显式建模 |

## 6. 本轮最大风险

**一句话**：把安全性从「证书 sound」升级为「交互可操作」方向正确，但其成立**同时依赖人类响应模型校准、`Act/Δ_c` 在真实界面上的可测性、以及 `S_ho`/回退不变的保守判定**；一旦人类模型在长尾用户上失配、或交互信号把「可读」误当成「可执行」，`S_I` 会系统性高估安全边界，逆权窗口反而在真正危险时扩大——故必须以 **保守 τ_h + 动作化 affordance + 独立红队挑战** 三重护栏，宁可多报不可少报。

```python
def safety_interaction_certificate(skill_seq, gamma_ce, human_model,
                                   S_I, S_ho, eps_total, R):
    J = joint_certificate(skill_seq, gamma_ce, delta_a_budget, rho_min)  # IP-118
    if J.status != 'ok':
        return J
    leg = min(Leg(signal_map(x, J)) for x in critical_states(J))
    act = min(Act(signal_map(x, J)) for x in critical_states(J))

    if measure(W_inv, J) > theta_inv or R > eps_total:

    return ('ok', SafetyCert(J, S_I, S_ho, leg, act, delta_c, auth_trace, challenge_log))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SIL | O(\|X\|·\|U_m^safe\|·τ_h^max/dt) | O(\|X\|) | 回退覆盖完整，时域离散上界 |
| LSV | O(\|cert\|·(\|Y\|+\|U\|)) | O(\|Y\|) | 人类模型校准，KL 估计无偏 |
| AAM | O(1)/步 + 不变式查询 | O(\|X\|) | τ_h 保守，S_ho 判定 sound |
| SCR | O(τ_cr/dt·\|X\|) | O(τ_cr/dt) | 反例可复现，修正单调 |
| RBL | O(1) | O(1) | 风险次可加，ε_tot 为上界 |
| RSC | O(\|R\|·τ_rec/dt) | O(\|R\|) | 回收动作完备，Rev 下界保守 |

**正确性定理（Interaction-Aware Safety Soundness）**
承接第 54 轮 (A22)–(A28)；新增 **(A29)** 人类模型 `π_h` 在部署分布上校准且 `τ_h` 取保守上界；**(A30)** 交互信号满足 `Act≥θ_act, Δ_c≤Θ_c`；**(A31)** 回退 `fb` 在 `S_I` 内保持不变式；**(A32)** 风险账本次可加且未知项上界有效。则
```
P(violation) ≤ ε_m + P(τ_h > τ_h^max) + P(Δ_c > Θ_c)
             + P(|W_inv| > Θ_inv) + ε_unk
```
关键：**安全增益来自证书被转化为可执行动作**；`Δ_c` 与 `|W_inv|` 是可解释/可交互性进入安全概率的两个显式扣减项。

## 5. 本轮最大风险

**一句话**：把安全性从「证书 sound」升级为「交互可操作」方向正确，但其成立**同时依赖人类响应模型校准、`Act/Δ_c` 在真实界面上的可测性、以及 `S_ho`/回退不变的保守判定**；一旦人类模型在长尾用户上失配、或交互信号把「可读」误当成「可执行」，`S_I` 会系统性高估安全边界，逆权窗口反而在真正危险时扩大——故必须以 **保守 τ_h + 动作化 affordance + 独立红队挑战** 三重护栏，宁可多报不可少报。
