# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「用户共创」×「深度学习」）

> R69 给闭环装上了一张「嘴」：看不清就看、拿不准就问、质感不明就触，并用 k 个正交证据源约束「问到的答案」。但它对「人」与「学习」仍有两个未经审视的假设：人只是一个**随叫随到、情绪中性、成本固定的标注源**，而系统**永不在线学习**。于是每次交互的收获都随 episode 结束而蒸发——闭环会问，却不会**记住**；会消歧，却不会**变好**。
>
> 更危险的是，一旦真的让它学（深度学习），就会同时打破 R66–R69 辛苦建立的三条安全前提：(i) 实时回路是「**冻结策略 + 有效证书**」；(ii) 证书使用的世界模型与策略共享同一条主干，学习会同时改变「被认证者」和「认证者」；(iii) 认证假设的状态分布是固定的，而更好的策略会**访问新状态**、改变不变集。
>
> 本轮两个灵感正好把这条缺口补成闭环：
> - **用户共创**把用户从「答案来源」升级为「共同作者」——数据带契约、出处、归因、撤回权；改进的功劳与责任都可追溯；
> - **深度学习**提供把共创数据压进策略的能力，也带来压缩丢尾、表演性反馈、谄媚、投毒、灾难性遗忘的全部风险。
>
> 核心命题：**学习不是一个更新，而是一个必须重新挣得证书的动作。** 实时回路保持冻结与认证；共创数据经契约与账本进入慢回路；深度学习只在两时间尺度下产出候选；候选必须通过「行为差分证书 + 认证防火墙 + 表演性/代表性/长尾/谄媚约束」才能晋升；任何一次晋升都可被认证回滚或遗忘。命名 **CIVIC-RAS**（Co-created Incrementally-Verified Interactive Continual Risk-Adaptive System）；「CIVIC」是双关：共创是一种公民参与，而安全是一份可被审计的公共契约。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**谁在教我、我学到的是谁的偏好、这些教训能否被安全地撤回**」——共创不是把用户数据倒进模型，而是让每一次改进都留下可追责、可回滚的公共记录。

## 0. 直觉与动机

**灵感 1（用户共创 → 用户不是神谕，而是共同作者）**
直觉：R69 的 MINT 把人当成一个「问一句就少一点熵」的信息源，成本是静态标量。但真实共创里，人带着**权利**与**立场**进来：他可能只同意自己的数据用于「这个房间」、可能要求撤回、可能只代表一小群用户、也可能想借「共创」把自己的偏好写成所有人的规范。共创的第一性问题不是「怎么采数据」，而是「**这份数据凭什么能被用来改变系统，改变后又该记在谁头上**」。所以本轮把每条数据升级为一份带来源、同意范围、用途约束与归因的**契约**；没有契约的数据不是数据，而是污染。

**灵感 2（深度学习 → 学习即压缩，压缩必然吃掉长尾）**
直觉：深度网络把海量用户偏好压进权重，这是它的力量，也是它的病灶。均值意义上的「大家都喜欢」能被平滑地学会，而**安全恰恰住在长尾**：那 0.3% 的极端场景、少数用户的强烈异议、一次差点出事的近失。压缩会用「看起来合理」的插值把长尾抹平，而且抹得越干净、置信度越高。破解办法不是不用深度学习，而是**不让长尾只活在权重里**：把一个冻结的、带出处的**异议与稀有账本**放在模型外，作为晋升的硬约束；模型负责压缩大多数，账本负责否决被压掉的少数。

**灵感 3（深度学习 → 更新会改变证书的前提，所以证书必须重新挣得）**
直觉：R68–R69 的证书有一个隐含前提——策略不变，因而它访问的状态分布不变，安全不变集不变。一次微调把策略挪动一点点，参数空间里也许只差 0.01，但**状态空间里可能整片迁移**：新策略更敢走、更敢试、更接近边界。此时旧证书不是「还差不多」，而是「完全失效」——它保证的是另一个闭环。正确姿态是两时间尺度：实时回路冻结、证书有效；慢回路只在离线产出**候选**；候选必须证明「行为差分集被重新认证的状态集覆盖」，否则不得晋升。证书不是继承的，是**重新挣得的**。

**灵感 4（自指风险 → 谁认证认证者）**
直觉：为了省算力，R68/R69 让策略、世界模型、标定器共享 MTM 主干。这带来一个致命的自指：深度学习更新主干后，**认证者与被认证者一起变了**；模型可以学到一套自洽但错误的世界，然后用这套世界给自己发证书。R68 已经吃过「标定把缓变故障吸收掉」的亏，R70 的风险更高一层——现在是「**学习把误差学成共识**」。因此必须设**认证防火墙**：认证所依赖的安全核（世界模型 + 安全监视器 + 标定基线）不允许被共创循环更新；它只能由**不被共创立的数据**与独立的对抗验证来升级。认证者必须站在被认证者之外。

**灵感 5（用户共创 → 共创是一个策略塑造数据的闭环，人也会被系统塑造）**
直觉：共创不是被动采样：系统展示什么、怎么问、怎么解释，会改变用户给什么反馈；系统越强，人越容易过度信任、越少核对（自动化偏差与去技能化）。于是数据分布是**策略的函数** D(θ)，而监督者的可靠性 ρ_t 也会随系统能力下降。天真地在 D(θ) 上做经验风险最小化，会收敛到一个「表演性稳定」却更差的点；而把越来越不认真的反馈当真理去学，会把错误固化成共识。**共创要可持续，必须同时监测两件事：数据是不是被策略塑造的，人是不是还在一线认真监督。**

**灵感 6（双刃剑 → 投毒、女巫、谄媚与遗忘）**
直觉：一旦「共创」能改模型，它就成了新的攻击面：女巫账号刷票、少数人合谋把后门写进微调、用户只给「让系统顺着我」的反馈把模型训成谄媚者、以及「请忘掉我的数据」与「请记住这次近失」之间的权利冲突。R69 的「k 个正交证据源」只解决**回答**层面的欺骗，解决不了**数据**层面的共谋与代表性偏差。本轮必须交付：出处多样化的鲁棒聚合、偏好/真值双通道、可认证遗忘与回滚，以及把「监督者可靠性」当成一等状态量来守护。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（CIVIC-RAS 总览）** CIVIC-RAS = (CLD, TTC, ΔCERT, PRM, CRD, DRL, RPA, SCF, CUR, HAC, RAS-WM‡)。六条不变式：
(i) **实时零学习写**：继承 R69 定义 293-i，在线回路内 θ 不变；
(ii) **学习即提案**：任何参数更新只作为候选进入慢回路，未过晋升门不得进入实时回路；
(iii) **包络单调**：一次更新可以**收窄**已认证安全包络，但不得**扩张**它，除非通过独立的再认证（定义 316）；
(iv) **契约可追**：每条训练数据都可追溯到一份有效共创契约与一段账本（定义 311–312）；
(v) **长尾不减**：晋升不得使异议账本上的损失超过容差（定义 318）；
(vi) **可逆**：每个被晋升的版本都有一个**已认证的回滚目标**（定义 324）。

**定义 311（共创数据契约）** 一条训练数据 d = (o, a, y, u, τ, c, π_scope, sig)，其中 o 观测、a 动作、y 反馈（偏好/纠正/真值标注）、u 用户或群体标识、τ 时间戳、c ∈ 𝒞 同意范围（场景/用途/期限）、π_scope 允许的策略用途集合、sig 签名。契约谓词 Valid(d) ⇔ τ 未过期 ∧ 用途被 π_scope 许可 ∧ 同意未被撤回。**不满足 Valid 的数据不得进入任何梯度。**

**定义 312（共创账本 CLD）** 只追加的 Merkle 账本 ℒ，记录每条 d 的承诺、契约哈希与归因。归因用影响函数近似 α_d = −∇_θ L(d; θ_ref)·H^{-1}∇_θ L(D_val; θ_ref)（或 TracIn 类一阶近似），用户级归因 A_u = Σ_{d∈u} α_d。账本根 root(ℒ) 进入证书；用于学分分配、撤回定位与投毒取证。归因只用于**审计与撤销**，不用于在线奖励（防止为刷归因而刷数据）。

**定义 313（两时间尺度 TTC）** 快回路 = R69 的 FLUID 闭环，使用冻结的 θ_k 与有效证书 J_k；慢回路 = 巩固（consolidation）：在数据窗口 W_k 上训练候选 θ'，依次通过 SCF → ΔCERT → PRM/CRD/DRL 门，全部通过才晋升 θ_{k+1}。约束：晋升只在 episode 边界发生，且晋升延迟 ≥ 一个采集窗口；**禁止 episode 内热更新**（保住 R69 的实时预算与可复现性）。

**定义 314（行为差分集）** D_δ(θ, θ') = { s ∈ S : TV(π_θ(·|s), π_θ'(·|s)) > δ ∨ ‖a_θ(s) − a_θ'(s)‖ > δ_a }。其支撑用双策略状态访问分布估计：D̂_δ = { s : ŝ(s) > s_min }，ŝ 由对 θ 与 θ' 的短滚出（rollout）采样得到。关键：**差分集是状态空间的，不是参数空间的**。

**定义 315（Δ-证书 J_Δ，含认证防火墙 ICF）** J_Δ(θ_k → θ') = (J_k, D̂_δ, S_cert(θ_k), R̂(θ'), R_play, ECE', tail_gap, perf_gap, syc_bias)。Valid(J_Δ) ⇔
(a) **可达包含**：新闭环在扰动界内的可达集 R̂(θ') ⊆ S_cert(θ_k) ∪ S_reverify；
(b) **安全关键回放**：在 S_crit（R68/R69 的标定关键态 + 近失 + 交互失败态）上，P_unsafe(θ', s) ≤ P_unsafe(θ_k, s)；
(c) **长尾**：tail_gap ≤ ε_d（定义 318）；
(d) **认证者独立**：计算 J_Δ 的安全核 WM_safe / 监视器 / 标定基线 ∈ ICF，且 θ' 的训练数据与梯度**未曾**修改 ICF；(e) 校准 ECE' ≤ τ_ece。
**ICF（认证防火墙）** 是一个冻结的、版本化的安全核，只接受「不被共创循环生成」的数据与独立对抗测试的升级；它与策略主干**不共享可训练参数**（共享只允许只读副本）。

**定义 316（安全包络单调与再认证）** Env(θ) 为 θ 下可证明安全的（状态×动作）集合。晋升要求 Env(θ') ⊆ Env(θ_k) ∪ Env_verified(θ')，默认**收缩优先**（shrink-only）。Env_verified(θ') 只能由三类独立证据生成：①对新增状态的对抗/形式化验证；②独立安全核的 WM 验证；③人类授权签署（HAC 定义 323）。无再认证时，任何扩张都视为无效晋升。

**定义 317（共创覆盖与群体 DRO）** 将共创者分为群体 𝒢，群体参与质量 p_g（有效样本数/目标数）与覆盖 κ_g = min(1, n_g/n_min)。晋升目标不是样本均值风险，而是群体鲁棒风险：θ' = argmin_θ max_g [ R_g(θ) + ρ(κ_g)·D_g ]，其中 D_g 为对未覆盖层的分歧惩罚，ρ(κ) 随覆盖下降而增大。**未覆盖层不允许外推**：其行为回退到 θ_k 并标记 unsupported；证书只对覆盖层作声称。

**定义 318（异议与稀有账本 DRL）** 冻结集合 𝒟_r 保存少数派意见、罕见上下文、近失与「用户明确反对但被平均值淹没」的样本，带出处与权重。硬约束：L_{𝒟_r}(θ') ≤ L_{𝒟_r}(θ_k) + ε_d；若违反，候选必须对相关上下文保留**门控专家**（gating）或整体回滚。DRL 与生成式回放的区别：DRL 是**真实数据锚**，不得由模型自生成（防止模型坍缩把尾巴越生越短）。

**定义 319（表演性风险与策略独立锚集）** 数据分布 D(θ) 随策略变化（系统展示/提问/解释改变反馈）。设重训算子 G，候选 θ'。**表演性稳定**：‖θ' − G(θ')‖ ≤ ε_perf。另维护策略独立锚集 𝒜：由随机化采集/独立队列/不依赖系统建议的样本构成，仅用于估计 D(θ) 的漂移方向与风险差，不直接用于拟合（防泄漏）。

**定义 320（鲁棒出处聚合 RPA）** 设共创者中恶意比例为 ε_adv，出处聚类数 ≥ k。聚合不用样本均值，而用出处分层的中位数/截尾均值/影响裁剪（median-of-means、trimmed mean、influence clipping），要求每个聚合桶内出处多样（provenance diversity）。R69 的「k 个正交证据源」在此升级为「**k 个独立出处簇**」：同一用户的脸/声音/回答不算三个源。

**定义 321（安全约束微调 SCF）** 候选求解
θ' = argmin_θ L_task(θ) + λ_r L_{𝒟_r}(θ) + λ_c L_cal(θ)
s.t. KL_safety(θ‖θ_k) ≤ ε_tr（按风险敏感度加权的行为 KL，而非裸参数范数）；
P_unsafe(θ, s) ≤ P_unsafe(θ_k, s)，∀s ∈ S_crit（回放约束）；
L_{𝒟_r}(θ) ≤ L_{𝒟_r}(θ_k) + ε_d（长尾约束）；
|b̂_syc| ≤ ε_syc（谄媚约束，定义 322）。
回放分两类：**真实安全关键回放**（冻结，必须）与**生成式多样性回放**（可选，只用于非关键层）；后者需监测模型坍缩（生成分布对真实分布的尾部覆盖不得下降）。

**定义 322（谄媚解耦）** 用户反馈分解为 y = y_v ⊕ y_p：y_v 是可验证结果（做了是否成功、是否碰撞、是否超时），y_p 是表达性偏好（我喜欢/我不喜欢）。SCF 只用 y_v 更新「真值通道」，y_p 只在信任域内更新「风格/交互通道」；在验证审计集 𝒜_v 上估计谄媚偏差 b̂_syc = E[y_p − y_v]，约束其不随训练增大。无 y_v 覆盖的层，**偏好不得冒充真值**。

**定义 323（监督者漂移与有意义人类控制 HAC）** 监督者可靠性 ρ_t（回答正确率×认真度代理：响应时延、核对率、与独立证据一致率）随系统自主度/准确率与解释质量演化。约束 ρ_t ≥ ρ_floor；干预包括校准解释、抽查式提问、强制关键决策人工确认。**包络扩张必须由人类授权**（定义 316-③），且该系统不得通过改变提问/展示来降低用户核对的边际收益（反劝服约束）。

**定义 324（可认证遗忘与回滚 CUR）** 撤回请求 u：寻找 θ' 使 u 的残留影响 Inf_u(θ') ≤ ε_u，且 J_Δ 仍 Valid；若不可行，则在推理期用门控屏蔽 u 相关上下文，并把数据移入隔离区（quarantine），同时记录「未能遗忘」的审计事实。回滚：若 θ_k 仍持有效证书且当前状态 ∈ S_cert(θ_k)，则允许原子回滚；否则先进入保守态（R69 纯保守 + 收缩包络）再回滚。**安全记忆（近失）与隐私撤回的冲突由治理规则显式裁决**，不得静默丢弃近失。

**定义 325（证书 J_CIVIC）** J_CIVIC = (J_FLUID(θ_k), J_Δ, root(ℒ), κ_coverage, tail_gap, perf_gap, syc_bias, ρ_floor_ok, rollback_hash, icf_version, civic_ver)。Valid ⇔ 快回路证书有效 ∧ J_Δ 有效 ∧ 所有治理门通过。证书公开可审计，但不含原始用户数据（只含承诺与统计量）。

**定义 326（退化到 R69）** 若无有效共创契约、或同意全部撤回、或晋升门全拒、或覆盖 κ 不足，则 CIVIC-RAS 逐指令执行 R69：冻结策略、只交互不学习、U 的分辨与保守退避完全一致。**R69 是 CIVIC 在「零学习、零共创」边界上的严格退化**；安全侧不做任何让步。

# IP-264 CLD：共创契约 + 账本 + 归因（只审计，不参与在线奖励）
def ingest(datum, consent, ledger):
    d = sign(datum, consent)                       # (o,a,y,u,τ,c,π_scope)
    if not Valid(d): return None                   # 过期/越权/已撤回 → 拒绝
    ledger.append(commit(d)); return d

# IP-265/266 TTC + ΔCERT：两时间尺度候选生成与「重新挣得证书」
def consolidate_and_gate(theta_k, J_k, window, cfg):
    data = [d for d in window if Valid(d)]
    if coverage(data) < KAPPA_MIN:                 # 定义 317：覆盖不足不学
        return theta_k, J_k, 'unsupported'
    theta_c = SCF.train(theta_k, data,            # 定义 321：安全约束微调
                        replay=S_crit_real,       # 真实安全关键回放（冻结）
                        dissent=DRL,              # 定义 318：长尾硬约束
                        robust=RPA(data),         # 定义 320：出处鲁棒聚合
                        dro=group_dro(data))      # 定义 317：群体鲁棒
    D_hat  = behavioral_delta(theta_k, theta_c)   # 定义 314：状态空间差分集
    R_hat  = reachable_set(theta_c, disturbance_bound)
    if not (R_hat <= S_cert(theta_k) | S_reverify(theta_c)):   # 定义 315-a
        return theta_k, J_k, 'reachability_fail'
    if not safety_replay_ok(theta_c, S_crit):     # 定义 315-b
        return theta_k, J_k, 'replay_fail'
    if not tail_ok(theta_c, DRL, eps_d):          # 定义 315-c
        return theta_k, J_k, 'tail_fail'
    if not certification_firewall_ok(theta_c):    # 定义 315-d：认证者独立
        return theta_k, J_k, 'icf_violation'
    if not performative_ok(theta_c, anchor_set):  # 定义 319：表演性稳定
        return theta_k, J_k, 'performative_fail'
    if not sycophancy_ok(theta_c, audit_veridical):  # 定义 322
        return theta_k, J_k, 'sycophancy_fail'
    return theta_c, build_delta_certificate(theta_k, theta_c, D_hat), 'ok'

# IP-272 CUR：可认证遗忘 / 原子回滚
def withdraw(user, theta_k, ledger):
    theta_c = unlearn(theta_k, influence_of(user, ledger))
    if delta_cert_valid(theta_k, theta_c):
        return promote(theta_c)                    # 安全地忘掉
    return quarantine(user), audit('unlearn_infeasible')  # 忘不掉也要诚实记账

# IP-274 CIVIC 主闭环：快回路完全继承 R69，仅在 episode 边界换版本
def CIVIC_round(M, obs, episode_done):
    if episode_done and M.slow_ready:              # 只在边界、只在离线
        theta_new, J_new, why = consolidate_and_gate(
            M.theta, M.J, M.window, M.cfg)
        if why == 'ok': M.promote(theta_new, J_new)  # 晋升；否则保持旧版
        else:          M.audit('promotion_rejected', why)
    # 以下与 R69 的 FLUID_RAS_round 逐指令相同（冻结策略 + 有效证书）
    return R69_fluid_round(M, obs, enforce_hac=True)   # 定义 323：人类控制门

## 3. 推导

**引理 19（参数近似 ≠ 证书可迁移）** 设旧闭环在 S_cert(θ_k) 上鲁棒不变。若候选 θ' 的可达集 R̂(θ') ⊄ S_cert(θ_k) ∪ S_reverify，则 J_k 对 θ' 不提供任何安全保证，且该结论与 ‖θ'−θ_k‖ 多小无关。系：**参数空间信任域不能替代状态空间可达分析**；这是 R68–R69「证书继承」假设的反例来源。

**引理 20（表演性稳定下的风险上界）** 设分布映射 D(θ) 在 W_1 下 L_p-Lipschitz，候选满足 ε_perf-稳定，经验误差 ≤ ε_est，则部署风险满足 R_{D(θ')}(θ') ≤ R_{D(θ_k)}(θ_k) + L_p·(‖θ'−θ_k‖ + ε_perf) + ε_est。系：共创带来的改进必须**先付清表演性税** L_p·ε_perf；若账面提升小于该税，正确动作是不晋升——这解释了为何「均值变好」不等于「部署变好」。

**引理 21（异议账本的尾部保持）** 设群体质量 p_g，若无 DRL 约束，平均风险下降 Δ 时最坏群体风险可上升至 Δ/p_min（把负担转嫁给小群体）；若施加 L_{𝒟_r}(θ') ≤ L_{𝒟_r}(θ_k) + ε_d 且 𝒟_r 覆盖最坏群体，则最坏群体风险增量 ≤ ε_d + p_min^{-1}·ε_est。系：**长尾账本把「不可控的转嫁」变成「可定价的容差」**。

**引理 22（出处鲁棒聚合的投毒界）** 设恶意共创者比例 ε_adv < 1/2，采用分桶中位数-of-means 且每桶出处多样，则聚合估计误差 ≤ O(σ/√m + ε_adv·B)（B 为有界影响），与模型维度无关；若攻击者跨出处相关 ρ<1，等效恶意比例 ≤ ε_adv·ρ^{k−1} + (1−ρ)ε_adv²。系：R69 的「k 个正交源」在数据层必须升级为「k 个独立出处簇」，否则同一人的多份数据会伪造出「一致」。

**引理 23（谄媚偏差的可辨识性）** 反馈 y = y_v + b(θ,u) + η。若验证审计集 𝒜_v 在相关特征层上满秩覆盖，则 b 可辨识至噪声水平，偏好更新导致的真值漂移被 ‖P_{𝒜_v} b̂‖ + η 界定；若某层无 y_v 覆盖，则偏好与真值在该层**不可辨识**，任何「已学会正确」的声称都不成立，必须回退或标记 unsupported。系：**谄媚不是训练技巧问题，而是可辨识性问题**；没有真值覆盖，越优化偏好越自信地错。

**定理 18（CIVIC 严格包含 R69）** 在无有效契约、或覆盖不足、或晋升门全拒时，CIVIC 与 R69 逐指令相同；且由定义 315–316，任何未再认证的更新都不能扩张安全包络。故 CIVIC 的安全侧不弱于 R69，效率与能力收益仅在「过了门」时获得。**R69 = CIVIC 在「零学习、零共创」边界上的严格退化。**

**定理 19（跨版本安全非退化与回滚可靠性）** 若每次晋升都持有效 J_CIVIC、认证者受 ICF 保护、快回路安全过滤器完整，且保留有效回滚目标，则任意晋升/回滚序列中，部署策略在任意时刻要么持有效证书，要么处于「收缩包络 + R69 纯保守」的安全态；因此闭环安全概率不低于初始已认证版本。系：**「越学越危险」不是深度学习的宿命，而是缺少证书与回滚纪律的后果。**

**定理 20（有意义人类控制的保持）** 在定义 323 下，包络扩张必须经人类授权，且 HAC 维持 ρ_t ≥ ρ_floor；则共创循环不能在不经人类批准的情况下扩张安全边界，自动化偏差只能降低监督的**效率**、不能静默降低监督的**权威**。系：共创的合法性来自可撤回的同意与可拒绝的授权，而不是模型的可信度。

## 6. 本轮最大风险

**一句话**：CIVIC 的证书由安全核计算，而安全核与策略共享世界模型、共创数据又可能被策略自身塑造——**一旦「被认证者」与「认证者」在同一个自指回路里共同漂移，模型会用一套自洽但错误的世界给自己发一张正确的证书**；此时深度学习把误差压得越平滑、越自信，认证就越像自证，共创也越像一场所有人都在点头的幻觉。

**次级风险与缓解**：认证防火墙被工程上绕过（ICF 独立版本化 + 只读副本 + 独立数据）；代表性偏差把少数当噪声（群体 DRO + 异议账本 + unsupported 回退）；恶意共创/女巫（出处鲁棒聚合 + 引理 22 + 契约举证）；谄媚把偏好当真值（双通道 + 验证审计 + 引理 23）；自动化偏差侵蚀监督（HAC + 授权门 + 定理 20）；遗忘与安全记忆冲突（治理显式裁决 + 可认证回滚）。

**定义 317–318（覆盖/DRO 与长尾账本）** 群体覆盖 `κ_g`，目标 `argmin max_g [R_g+ρ(κ_g)D_g]`，未覆盖层回退旧版标 unsupported；冻结长尾账本 `𝒟_r` 硬约束 `L_{𝒟_r}(θ')≤L_{𝒟_r}(θ_k)+ε_d`，违规则门控专家或回滚；`𝒟_r` 用真实数据，禁自生成替代。

**定义 319–320（表演性与鲁棒聚合）** `D(θ)` 随策略变；表演性稳定 `‖θ'−G(θ')‖≤ε_perf`；策略独立锚集 `𝒜` 只估漂移不拟合。聚合用出处分层中位数/截尾/影响裁剪，`k` 个**独立出处簇**而非同一人的多模态。

**定义 321–322（安全约束微调与谄媚解耦）** `θ'=argmin L_task+λ_r L_{𝒟_r}+λ_c L_cal`，s.t. 风险加权行为 KL≤ε_tr、`P_unsafe(θ',s)≤P_unsafe(θ_k,s)` on `S_crit`、长尾≤ε_d、`|b̂_syc|≤ε_syc`；真实安全关键回放必须、生成式回放可选且监测尾部覆盖。反馈 `y=y_v⊕y_p`：真值通道用 `y_v`，偏好通道只进信任域；无 `y_v` 覆盖的层偏好不得冒充真值。

**定义 323–324（HAC 与可认证遗忘）** 监督者可靠性 `ρ_t≥ρ_floor`，包络扩张须人类授权，反劝服约束；遗忘找 `Inf_u(θ')≤ε_u ∧ J_Δ` 有效，否则隔离 + 诚实记账；回滚需目标证书有效且当前状态在 `S_cert`。

**定义 325–326（J_CIVIC 与退化）** `J_CIVIC=(J_FLUID,J_Δ,root(ℒ),κ,tail_gap,perf_gap,syc_bias,ρ_floor_ok,rollback_hash,icf_version,civic_ver)` 公共可审计；无契约/撤回/门全拒/覆盖不足 ⇒ 逐指令执行 R69，**R69 为严格退化边界**。

## 3. 关键算法伪代码

```python
# IP-264 CLD：契约 + 账本（不参与在线奖励）
def ingest(datum, consent, ledger):
    d = sign(datum, consent)
    if not Valid(d): return None                 # 过期/越权/已撤回
    ledger.append(commit(d)); return d

# IP-265/266 TTC + ΔCERT：候选生成 + 「重新挣得证书」
def consolidate_and_gate(theta_k, J_k, window, cfg):
    data = [d for d in window if Valid(d)]
    if coverage(data) < KAPPA_MIN:               # 定义 317
        return theta_k, J_k, 'unsupported'
    theta_c = SCF.train(theta_k, data,
                        replay=S_crit_real,      # 真实回放（冻结，必须）
                        dissent=DRL,             # 长尾硬约束
                        robust=RPA(data),        # 出处鲁棒聚合
                        dro=group_dro(data))     # 群体 DRO
    D_hat = behavioral_delta(theta_k, theta_c)   # 状态空间差分集
    R_hat = reachable_set(theta_c, disturbance_bound)
    if not (R_hat <= S_cert(theta_k) | S_reverify(theta_c)): return theta_k, J_k, 'reachability_fail'
    if not safety_replay_ok(theta_c, S_crit):    return theta_k, J_k, 'replay_fail'
    if not tail_ok(theta_c, DRL, EPS_D):         return theta_k, J_k, 'tail_fail'
    if not certification_firewall_ok(theta_c):   return theta_k, J_k, 'icf_violation'
    if not performative_ok(theta_c, ANCHOR):     return theta_k, J_k, 'performative_fail'
    if not sycophancy_ok(theta_c, AUDIT_VERIDICAL): return theta_k, J_k, 'sycophancy_fail'
    return theta_c, build_delta_certificate(theta_k, theta_c, D_hat), 'ok'

# IP-272 CUR：可认证遗忘 / 原子回滚
def withdraw(user, theta_k, ledger):
    theta_c = unlearn(theta_k, influence_of(user, ledger))
    if delta_cert_valid(theta_k, theta_c): return promote(theta_c)
    return quarantine(user), audit('unlearn_infeasible')   # 忘不掉也诚实记账

# IP-274 CIVIC 主闭环：快回路完全继承 R69，只在边界换版本
def CIVIC_round(M, obs, episode_done):
    if episode_done and M.slow_ready:
        theta_new, J_new, why = consolidate_and_gate(M.theta, M.J, M.window, M.cfg)
        if why == 'ok': M.promote(theta_new, J_new)
        else:           M.audit('promotion_rejected', why)
    return R69_fluid_round(M, obs, enforce_hac=True)   # 定义 323
```

## 4. 推导

**引理 19（参数近似 ≠ 证书可迁移）** 旧闭环在 `S_cert(θ_k)` 鲁棒不变；若 `R̂(θ')⊄S_cert(θ_k)∪S_reverify`，则 `J_k` 对 `θ'` 无任何安全保证，且与 `‖θ'−θ_k‖` 多小无关。系：参数信任域不能替代状态空间可达分析。

**引理 20（表演性稳定下的风险上界）** `D(θ)` 为 `L_p`-Lipschitz、候选 `ε_perf`-稳定、经验误差 `ε_est`，则 `R_{D(θ')}(θ') ≤ R_{D(θ_k)}(θ_k) + L_p(‖θ'−θ_k‖+ε_perf) + ε_est`。系：共创改进必须先付表演性税；账面提升小于税则不晋升。

**引理 21（异议账本的尾部保持）** 无 DRL 时平均风险降 `Δ` 可使最坏群体升 `Δ/p_min`；施加 `L_{𝒟_r}(θ')≤L_{𝒟_r}(θ_k)+ε_d` 且账本覆盖最坏群体时，最坏群体增量 `≤ ε_d + p_min^{-1}ε_est`。系：把「不可控的转嫁」变成「可定价的容差」。

**引理 22（出处鲁棒聚合的投毒界）** `ε_adv<1/2`、分桶中位数-of-means、桶内出处多样时，误差 `≤ O(σ/√m + ε_adv·B)`，与维度无关；跨出处相关 `ρ<1` 时等效恶意比例 `≤ ε_adv·ρ^{k−1}+(1−ρ)ε_adv²`。系：数据层必须用「独立出处簇」，同一人多模态不算多源。

**引理 23（谄媚偏差可辨识性）** `y=y_v+b(θ,u)+η`；`𝒜_v` 满秩覆盖时 `b` 可辨识至噪声，真值漂移 `≤ ‖P_{𝒜_v}b̂‖+η`；某层无 `y_v` 覆盖则偏好与真值不可辨识，任何「已学会正确」的声称不成立，须回退或标 unsupported。系：谄媚是可辨识性问题，不是调参问题。

**定理 18（CIVIC 严格包含 R69）** 无有效契约/覆盖不足/门全拒时逐指令同 R69；未再认证更新不得扩张包络。故安全不弱于 R69，收益仅在过门时获得——**R69 = 「零学习、零共创」边界上的严格退化**。

**定理 19（跨版本安全非退化与回滚可靠性）** 每次晋升持有效 `J_CIVIC`、认证者受 ICF 保护、安全过滤器完整且保留有效回滚目标时，任意晋升/回滚序列中部署策略要么持有效证书，要么处于「收缩包络 + R69 纯保守」安全态；闭环安全概率不低于初始已认证版本。系：「越学越危险」是缺证书与回滚纪律的后果，不是宿命。

**定理 20（有意义人类控制）** 包络扩张须人类授权、HAC 维持 `ρ_t≥ρ_floor` 时，共创不能未经批准扩张安全边界；自动化偏差只能降低监督效率，不能静默降低监督权威。系：共创合法性来自可撤回的同意与可拒绝的授权，而非模型可信度。

## 7. 本轮最大风险

**一句话**：CIVIC 的证书由安全核计算，而安全核与策略共享世界模型、共创数据又可能被策略自身塑造——**一旦「被认证者」与「认证者」在同一个自指回路里共同漂移，模型会用一套自洽但错误的世界给自己发一张正确的证书**；此时深度学习把误差压得越平滑、越自信，认证就越像自证，共创也越像一场所有人都在点头的幻觉。

**次级风险与缓解**：ICF 被工程绕过（独立版本化 + 只读副本 + 独立数据）；代表性偏差（群体 DRO + 异议账本 + unsupported 回退）；恶意共创/女巫（出处鲁棒聚合 + 引理 22 + 契约举证）；谄媚（双通道 + 验证审计 + 引理 23）；自动化偏差（HAC + 授权门 + 定理 20）；遗忘与安全记忆冲突（治理显式裁决 + 可认证回滚）。
