# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「在线学习」×「平衡控制」）

> 第 54 轮把技能组合提升为动作空间-鲁棒性双证书，但所有证书仍是**离线**的：隐含假设部署时分布不变、边端能按预演动作执行。本轮直视两个更物理的事实：**(i)** 真实机器人必须**在线学习**（接触参数、负载、地面摩擦、自身磨损持续漂移）；**(ii)** 平衡是**不可逆风险**任务（探索性动作可能直接摔倒，代价不可回滚）。核心矛盾：H22：在线学习需要探索，而平衡控制禁止灾难性探索，二者在最需要适应的边界处冲突；H23：离线证书在分布漂移下会**静默过期**，而朴素的在线更新会以“探索”为名扩大未验证动作域，使证书从 sound 退化为 optimistic。

## 0. 直觉与动机

**灵感 1（平衡不是“safe set”，而是“可恢复域”）**
直觉：CBF/不变集要求每一步都待在安全集内，过于保守，会掐死在线学习所需的探索。平衡的真实结构是：只要**还来得及救回来**，短暂进入危险边缘是可接受的。因此把探索约束从“不变安全集 B”放宽为**可恢复域 R_ε**：存在恢复策略 π_rec，在 T_rec 步内把状态拉回 B 且不违反接触力锥。探索只在 R_ε 内进行——**能救回来才允许试**。

**灵感 2（在线证书的单调性 → 让学习只会“变安全”，不会“变乐观”）**
直觉：在线学习的危险在于“数据越多越自信”，而自信可能是错的。我们反过来：用**一致参数集 Θ_t**（与已有数据相容的动力学参数集合）的**最坏情形**来定义证书。数据增加 ⇒ Θ_t 收缩 ⇒ 证书域单调扩张；分布漂移 ⇒ 一致性检验失败 ⇒ Θ_t 重置并**收缩**证书。这样在线更新天然是“保守单调”的，除非新证据明确支持扩张。

**灵感 3（证书遗憾而非奖励遗憾）**
直觉：平衡任务里“多赚一点奖励”远不如“少一次越界”重要。因此在线学习的优化目标不应是回报 regret，而应是**证书遗憾**：`KR_T = Σ_t (m*(x_t) - m_cert_t(x_t))`（相对 oracle 可达裕度的保守损失）与**安全遗憾** `SR_T = Σ_t max(0, m_min - m_t)`。前者要求次线性、后者要求恒为零（高概率）。

**灵感 4（Explain 引导的降维在线学习）**
直觉：分布漂移往往只发生在少数鲁棒性维度上（如摩擦↓、负载↑），第 53 轮的 Explain 能定位根因维度 d*。于是在线更新不必在全部参数上重学，只需沿 d* 更新 Θ_t 的一个切片，样本复杂度从 O(d) 降到 O(d_eff)。这把“反向解释”从诊断工具升级为**在线学习的主动查询策略**。

**灵感 5（双时间尺度：云端学策略，边端学平衡）**
直觉：云端可以慢（学任务级平衡偏好、恢复策略族），边端必须快（学当前接触的瞬时控制、力矩分配）。二者时间尺度分离 `T_c ≫ T_e`，用奇异摄动/平均化保证稳定性；云端下发的证书在边端被快速层“局部兑现”，边端把 margin 违例反传触发云端重学。这与第 54 轮的云边协同 `γ_ce` 自然衔接。

**灵感 6（在线技能组合：证书在编队中失效与重生效）**
直觉：技能组合图 G_S 的边权（compat、ρ_comp）在在线执行中会漂移。不能每步重建整图，而应给每条边一个**证书有效期 epoch**：边被使用时才增量校准，一旦某条边的 margin 低于阈值即**惰性失效**并触发局部重搜索。组合证书因此从静态文件变成带 TTL 的活对象。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（平衡状态与稳定裕度）**
质心状态 `x=(c, ċ)`，自然频率 `ω=√(g/z_c)`，发散分量 `ξ = c + ċ/ω`。支撑多边形 `S⊂ℝ²`（凸）。稳定裕度 `m(x)=dist(ξ, ∂S)`（进入支撑域为负）。平衡安全包络 `B_{m0}={x: m(x) ≥ m0}`；物理摔倒阈值 `m_fall < m0`。

**定义 122（平衡鲁棒性谱）**
`ρ^{bal} = (m, T_rec, c_w, σ_w)`：稳定裕度、恢复时域、接触力锥余量 `c_w = dist(τ_c, ∂𝒦_wrench)`、扰动界 `σ_w`。与第 53 轮 ρ 的其他维度做笛卡尔积：`ρ ⊕ ρ^{bal}`。

**定义 123（可恢复域与恢复算子）**
给定恢复策略族 Π 与扰动集 W，可恢复域
```
R_ε = { x : ∃π∈Π, ∃τ≤T_rec, x_τ ∈ B_{m0}, ∀w∈W,
        接触力 ∈ 𝒦_wrench, 且 P(成功) ≥ 1-ε }
```
恢复算子 `Rec(x)=argmin_{π∈Π} τ s.t. x_τ∈B_{m0}`。**可恢复探索准则**：在 x 处允许探索扰动 `δu` 当且仅当 `x ⊕ δu ∈ R_ε` 且 `m(x⊕δu) ≥ m0 - ζ`。

**定义 124（在线平衡证书 OBC）**
`O_t = (ρ^{bal}_t, R_{ε,t}, Θ_t, κ_t, ν_t, evidence_t)`：
- `Θ_t` 为与数据 `D_t` 相容的动力学参数集（含摩擦、负载、惯量）；
- `κ_t = diam(Θ_t)` 为不确定性半径；
- `ν_t` 为有效性 epoch（TTL）；
- **证书语义（sound，最坏情形下界）**：只要 `θ*∈Θ_t`，则 `∀x: m_true(x) ≥ m_cert(x)`，其中 `m_cert(x)=min_{θ∈Θ_t} m_θ(x)`。

**定义 125（一致参数集与在线单调更新）**
`Θ_{t+1} = Θ_t ∩ {θ : |r_t(θ)| ≤ β(δ,t)}`，`r_t` 为一步预测残差，`β` 为置信半径（自归一化界/共形界）。**单调性要求**：若一致性检验通过，则 `Θ_{t+1}⊆Θ_t`，从而 `m_cert(Θ_{t+1}) ≥ m_cert(Θ_t)`；若检验失败，则触发**收缩协议** `Θ_{t+1} ← Θ_prior`、`ν_t ← ν_t+1`，证书域收缩而非扩张。

**定义 126（证书遗憾与安全遗憾）**
```
SR_T = Σ_{t=1}^T max(0, m_min - m_true(x_t))
KR_T = Σ_{t=1}^T (m*(x_t) - m_cert_t(x_t))
```
目标：`P(SR_T = 0) ≥ 1-δ` 且 `KR_T = O(√(d_eff·T))`。

def update_balance_certificate(O, D_new, prior, delta):

### IP-122 ROE（Recoverable Online Exploration）

```python
def recoverable_step(x, u_nom, explorer, O, zeta):
    if not in_recoverable(x, O.R, zeta):
        return recovery_controller(x, O)             # 先救再学
    u_expl = explorer.sample(x)
    u = solve_qp(cost=||u - u_nom - u_expl||,
                 s.t. viable_next(x, u, O.R), wrench_cone(x, u),
                      margin(x, u) >= m_min - zeta)
    if u is None:
        return u_nom                                  # 探索预算耗尽，退回名义
    return u
```

def certificate_regret_learn(xs, O, T, delta):

### IP-124 DBL（Dual-timescale Balance Learning）

```python
def dual_timescale(cloud, edge, T_c, T_e):
    O = edge.OBC
    for k in range(T // T_e):
        O = edge.fast_update(O, T_e)                  # 快层：接触级

def online_compose(G, task, O, now, ttl=64):

### IP-115 ACS

def action_profile(skill, A_c, A_e, sampler):
    alpha = {}
    for a_c in A_c:
        for a_e in A_e:
            feas, conf = sampler.query(skill, a_c, a_e)
            alpha[(a_c,a_e)] = conf if feas else 0.0
    return alpha

def cover_check(alpha, A_T, theta_cov=0.8):
    return all(alpha.get(a,0.0) >= theta_cov for a in A_T)
```

### IP-116 SCOM

```python
def build_composition_graph(skills, theta_a, tau_e, K):
    G = nx.DiGraph()
    for i,s1 in skills:
        for j,s2 in skills:
            if i==j: continue
            alpha1, alpha2 = s1.alpha, s2.alpha
            inter = jaccard(alpha1, alpha2)
            c_trans = transition_cost(s1, s2)
            if inter >= theta_a and c_trans <= tau_e:

                G.add_edge(i,j, compat=inter, cost=c_trans, rho_comp=rho_comp, A_overlap=intersection(alpha1,alpha2))
    return G
```

## 5. 本轮最大风险

**一句话**：动作空间剖面化与云边协同将技能组合从能力匹配升级为动作-鲁棒性双证书，但其 soundness **三重依赖动作剖面的完备采样、γ_ce 映射的单调可逆、以及 Explain 回传的实时收敛**；一旦动作剖面欠采样导致虚假兼容、或云边映射在极限动作处非单调，组合路径在真实边端会系统性动作错位并触发负迁移，故必须以 **主动剖面采样 + Lipschitz 约束的 γ_ce + 负迁移绊线** 三重护栏，宁可保守组合，绝不把动作空间的“可对齐假象”当作部署前提。
