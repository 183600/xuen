### 第 1 轮灵感驱动研究记录（承接 v29 / CADVS）

**灵感词**：行为克隆、谐波减速器

**直觉与动机**：

先讲直觉。v29 的 CADVS 把系统拆成「学生策略高频输出 + 十二证运行时准入 + 教师兜底」，其中学生策略本质上是**行为克隆（behavior cloning, BC）**：用教师 KT-MPC 的示范 (s, a*) 做监督学习。整套证书都在回答一个问题——「在当前状态 s 下，学生输出的动作 a 是否可信？」但这里藏着一个从未被审计的等式：

> **学生输出的动作 = 机器人关节真正执行的动作。**

在仿真里这个等式近似成立；在真实的双足/人形机器人上它不成立，因为每个关节都经过**谐波减速器**。谐波减速器的传动不是理想的 θ_o = θ_m/N：它有随波发生器转角周期变化的传动误差（transmission error, TE）、有随负载与历史变化的迟滞（hysteresis / lost motion）、有非线性扭转刚度、有摩擦，而且这些量会随磨损、温度、装配漂移缓慢变化。于是：

> **命令动作 a_cmd → 减速器 A_φ → 实际关节运动 a_ach，且 A_φ ≠ id。**

行为克隆在**命令空间**里做监督，安全却在**实际运动空间**里定义。证书（FQC、DLC、集成分歧、KC 裕度……）全部在命令空间或状态空间校准，看不见这层执行器畸变。这是本轮的核心裂缝：**执行器级的协变量偏移（actuation-level covariate shift）**。

再把两件事叠起来看，问题会放大。BC 的经典失效是复合误差（compounding error）：学生一旦偏离示范分布，就进入自己没见过的状态，误差逐步放大。谐波减速器恰好在这个偏离过程中扮演「状态相关、历史相关、缓慢漂移的扰动源」：在换向、低速、大负载这些腿部运动最频繁的工况下，迟滞与非线性刚度最显著，命令与实际的差最大。也就是说，**BC 越需要精确执行的地方，减速器越不精确**。更隐蔽的是，磨损会让 A_φ 慢慢变，而证书仍按出厂标定显示绿灯——这正是 CADVS 反复强调的「证书语义漂移」，只不过这次漂移发生在执行器层。

**关键洞见**：不要把减速器当作「低层控制细节」甩给伺服环，而应把它提升为**一等公民的执行器证书源**。具体做三件事：(1) 用传动模型把 BC 的监督目标从「命令一致」改成「**实际运动一致**」；(2) 用谐波减速器的 TE/迟滞/刚度/磨损给出可验证的**传动证书 HRTC**，并把其不确定度转成一条**认证误差管（certified tube）**，作为学生动作的额外准入门；(3) 用证书裕度决定**去哪里向教师要纠正标签**（主动示范），把有限的人工/教师预算花在「BC + 传动不确定度」最大的状态上。磨损在线辨识（WATR）则负责让这条证书不变成陈旧的绿灯。

**严谨定义（增量）**：

1. **谐波减速器传动算子**。设减速比 N，波发生器（电机侧）角 θ_m，柔轮（输出侧）角 θ_o，负载力矩 τ。定义
   θ_o = θ_m/N − ε_TE(θ_m) − h(τ, ℋ) − δ_k(τ; θ_o)，
   其中 ε_TE(θ_m) = Σ_{k=1}^{K}[a_k cos(kθ_m) + b_k sin(kθ_m)] 为周期传动误差；h 为迟滞算子（由力矩历史 ℋ 决定，|h| ≤ w_hys/2）；δ_k 为非线性扭转柔度，满足 τ = g(δ_k; θ_o)，g 单调、k_eff := ∂g/∂δ ∈ [k_min, k_max]；再叠加摩擦 f_fric(θ̇_o, τ)。把这些参数打包为 φ_HR = (N, {a_k,b_k}, w_hys, g, f_fric, ρ_wear)。

2. **执行算子与执行间隙**。给定策略 π_θ，部署时的实际动作 a_ach = A_{φ_deploy}(π_θ(s))，示范时的实际动作 a*_ach = A_{φ_demo}(π*(s))。定义执行间隙
   δ_A^gap := sup_a ‖(A_{φ_deploy} − A_{φ_demo})(a)‖，
   迟滞附加项 δ_H := w_hys/2；单步执行畸变 δ_A := ‖A_φ(a) − a‖。

3. **执行一致的行为克隆（ACBC）**。设可辨识前向传动模型 Â_{φ̂}，示范给出实际关节轨迹 a*_ach（或由 Â 反演的命令目标）。ACBC 优化
   min_θ E_{s~D}[ ‖Â_{φ̂}(π_θ(s)) − a*_ach‖² ]，
   而非命令空间 E[‖π_θ(s) − a*_cmd‖²]。当 Â 可逆且无迟滞时二者等价；存在迟滞时，前向形式避免多值逆的歧义。

4. **执行感知复合误差界**。在动力学 Lipschitz 常数 L_s, L_a、执行算子 Lipschitz 常数 L_A、策略偏差 ε_π 与策略 Lipschitz 常数 L_π 下，记 L := L_s + L_a L_A L_π，则
   ‖e_T‖ ≤ ((L^T − 1)/(L − 1)) · L_a (L_A ε_π + δ_A^gap + δ_H)（L>1）。
   关键读法：当 δ_A^gap 主导时，把 ε_π 压到 0 也不安全；这正是纯 BC + 命令空间证书的盲区。

5. **传动证书 HRTC**。HRTC = (ε_TE^ub, w_hys^ub, k_eff^lb, ρ_wear^ub, P_φ)，其中 P_φ 为参数协方差。证书有效当且仅当 ε_TE^ub < ε_max ∧ w_hys^ub < w_max ∧ k_eff^lb > k_min ∧ ρ_wear^ub < ρ_max。有效时给出 δ_A 的保守上界 δ_A^bound，并诱导认证误差管半径
   r_t = ((L^t − 1)/(L − 1)) · L_a (L_A ε_π^ach + δ_A^bound)。

6. **证书引导的主动示范（CGAD）**。查询权重
   w(s) = α_1 u_π(s) + α_2 u_A(s) + α_3 r_t(s)，
   其中 u_π 为策略集成不确定度、u_A 为当前关节构型下 HRTC 的参数不确定度（换向/低刚度处最大）、r_t 为认证管半径。每轮按 w(s) 取 top-B 状态向教师查询并聚合（风险加权 DAgger）。

7. **磨损自适应传动再辨识（WATR）**。以回归形式 τ = Φ(δ, θ_o, θ̇_o)ᵀ β + η 做带遗忘的递推最小二乘，β 含 TE 系数、刚度、摩擦、迟滞宽度；用持续激励条件 λ_min(Σ_Φ) ≥ γ_pe 判定可辨识性；不可辨识时用保守上界 δ_A^bound = δ_A^nom + κ·√(tr P_φ) 并冻结 BC 更新/收紧安全裕度。

8. **执行集**。Exec_CABC ⊆ Exec_CADVS ⊆ Exec_v29，因为 CABC 只在 CADVS 之上**追加** HRTC 与认证管门控，不放松任何既有证书。

**形式化目标（增量）**：

1. 建立减速器传动算子与执行间隙的形式模型；
2. 证明执行间隙分解引理与执行感知复合误差界；
3. 证明 HRTC 有效 ⇒ 执行畸变有界，并给出认证管；
4. 定义 CGAD 的预算化风险加权查询并给出每标签误差下降的贪心界；
5. 定义 WATR 的可辨识性判据与保守界，证明非持续激励下界仍成立；
6. 实验：在含谐波减速器模型的仿真与实机上，比较 naive BC / BC+DAgger / CADVS / CABC，度量认证假通过率与磨损后的性能保持。

**本轮最大风险**：**减速器迟滞在低速换向处的弱可观测性**——腿部运动大量发生在近零速与频繁换向，而迟滞宽度与非线性刚度在这些点几乎不可辨识；WATR 会给出一个「自信但错误」的窄参数协方差，HRTC 随之显示绿灯，认证管也变窄，于是系统在**最需要保守的换向瞬间**反而最激进，产生命令空间与执行器证书都看不见的「执行层虚假安全感」。

### IP-479 Harmonic Reducer Transmission Certificate (HRTC)

```python
@dataclass
class HarmonicReducerTransmissionCertificate:
    """HRTC：谐波减速器 TE/迟滞/刚度/摩擦/磨损 → 可验证执行器证书"""
    N: float = 100.0
    K_te: int = 6
    eps_te_max: float = 2.0e-4      # rad，约 40 arcsec
    w_hys_max: float = 5.0e-4       # rad，迟滞半宽上界
    k_min: float = 8.0e3            # N·m/rad，最小等效刚度
    rho_wear_max: float = 0.30
    tau_max: float = 120.0          # N·m，额定峰值力矩

    def fit_te(self, theta_m: np.ndarray, theta_o: np.ndarray):
        """残差 r = theta_m/N - theta_o，对 theta_m 做 K_te 阶傅里叶最小二乘。"""
        r = theta_m / self.N - theta_o
        Phi = np.column_stack(
            [f(k * theta_m) for k in range(1, self.K_te + 1)
             for f in (np.cos, np.sin)]
        )                                    # (M, 2K)
        coef, *_ = np.linalg.lstsq(Phi, r, rcond=None)
        resid = r - Phi @ coef
        self.te_coef = coef
        self.eps_te_ub = np.max(np.abs(resid)) + 3.0 * np.std(resid)

    def fit_hysteresis(self, tau: np.ndarray, delta: np.ndarray):
        """按 dτ/dt 符号拆加载/卸载支，迟滞宽度取同力矩下两支最大间隙。"""
        load = np.gradient(tau) >= 0
        w = 0.0
        for t in np.unique(np.round(tau, 3)):
            lo = delta[load & (np.abs(tau - t) < 1e-2)]
            un = delta[~load & (np.abs(tau - t) < 1e-2)]
            if lo.size and un.size:
                w = max(w, abs(np.median(lo) - np.median(un)))
        self.w_hys_ub = w

    def fit_stiffness(self, delta: np.ndarray, tau: np.ndarray):
        """单调回归 tau=g(delta)，取最小斜率作为刚度下界。"""
        order = np.argsort(delta)
        d, t = delta[order], tau[order]
        slope = np.diff(t) / np.maximum(np.diff(d), 1e-9)
        self.k_eff_lb = float(np.percentile(slope[slope > 0], 5))

    def certify(self) -> HRC:
        valid = (self.eps_te_ub < self.eps_te_max and
                 self.w_hys_ub < self.w_hys_max and
                 self.k_eff_lb > self.k_min and
                 self.rho_wear_ub < self.rho_wear_max)
        # 由模型逐项取上界（引理 34）
        delta_bound = (self.eps_te_ub + 0.5 * self.w_hys_ub
                       + self.tau_max / max(self.k_eff_lb, 1e-6)
                       + self.fric_ub)
        return HRC(valid=valid, delta_bound=delta_bound,
                   params=self.phi, cov=self.P_phi)

    def cert_payload(self, hrc: HRC) -> dict:
        return {
            'cert_id': 'kc_actuation_valid',
            'payload': {'valid': bool(hrc.valid),
                        'eps_te_ub': self.eps_te_ub,
                        'w_hys_ub': self.w_hys_ub,
                        'k_eff_lb': self.k_eff_lb,
                        'rho_wear': self.rho_wear_ub,
                        'delta_A_bound': hrc.delta_bound},
            't_stamp': time.time(),
            'validity_window': 0.05,        # 与 TCVM 的证书年龄校验联动
            'src_node': 'hrtc'
        }
```

### IP-478 Actuation-Consistent Behavior Cloning (ACBC)

```python
@dataclass
class ActuationConsistentBehaviorCloning:
    """ACBC：在减速器之后的实际运动空间做监督，而非命令空间"""
    policy: nn.Module
    A_hat: nn.Module                 # 前向传动模型 Â_{φ̂}
    safety_margin: float = 0.02      # rad

    def achieved_loss(self, batch, phi_hat):
        s, a_ach_star = batch         # 示范的实际关节轨迹
        a_cmd = self.policy(s)
        a_ach_hat = self.A_hat(a_cmd, phi_hat)
        return F.mse_loss(a_ach_hat, a_ach_star)

    def correct_command_target(self, a_cmd_star, phi_hat):
        """仅有命令示范时：用 Â 把命令目标映射到执行空间再对齐（消歧用前向，不取多值逆）。"""
        return self.A_hat(a_cmd_star, phi_hat)

    def gated_action(self, s, hrc, tube_radius):
        a_cmd = self.policy(s)
        # 追加门控：不放松 CADVS 任何既有证书
        if not hrc.valid:
            return None, 'fallback_teacher:actuation_invalid'
        if tube_radius > self.safety_margin:
            return None, 'fallback_teacher:tube_exceeds_margin'
        return self.project_to_certified_set(a_cmd, hrc), 'student_acbc'
```

### IP-482 Wear-Adaptive Transmission Re-identification (WATR)

```python
@dataclass
class WearAdaptiveTransmissionReidentification:
    """WATR：带遗忘 RLS + 持续激励判据 + 保守膨胀"""
    beta: np.ndarray                 # 参数估计（TE 系数、刚度、摩擦、迟滞）
    P: np.ndarray                    # 参数协方差
    lam_forget: float = 0.995
    gamma_pe: float = 1.0e-3
    kappa: float = 3.0

    def regressor(self, delta, theta_o, theta_dot):
        return np.concatenate([
            delta, delta**3,                 # 非线性刚度
            np.sign(theta_dot), theta_dot,   # 摩擦
            np.array([1.0]),                 # 迟滞宽度基项
            np.cos(np.arange(1, 7) * theta_o),
            np.sin(np.arange(1, 7) * theta_o),
        ])

    def update(self, delta, theta_o, theta_dot, tau):
        Phi = self.regressor(delta, theta_o, theta_dot)
        # 带遗忘 RLS
        denom = self.lam_forget + Phi @ self.P @ Phi
        self.P = (self.P - np.outer(self.P @ Phi, Phi @ self.P) / denom) / self.lam_forget
        self.beta = self.beta + self.P @ Phi * (tau - Phi @ self.beta)
        self.Sigma += np.outer(Phi, Phi)

    def pe_ok(self) -> bool:
        return np.linalg.eigvalsh(self.Sigma).min() >= self.gamma_pe

    def delta_bound(self, tau_max: float) -> float:
        nom = (self.nominal_te_ub + 0.5 * self.nominal_w_hys
               + tau_max / max(self.nominal_k_lb, 1e-6) + self.nominal_fric_ub)
        stat = self.kappa * np.sqrt(np.trace(self.P))
        # 不可辨识时额外膨胀，宁可保守也不给假绿灯
        inflate = 0.0 if self.pe_ok() else self.prior_inflation
        return nom + stat + inflate

    def should_freeze(self) -> bool:
        return (not self.pe_ok()) or (self.rho_wear_ub > self.rho_wear_max)
```

### IP-480 Certificate-Guided Active Demonstration (CGAD)

```python
@dataclass
class CertificateGuidedActiveDemonstration:
    """CGAD：风险加权 DAgger，只在高证书风险状态向教师查询"""
    budget: int = 64
    alpha: tuple = (0.4, 0.4, 0.2)   # (策略不确定, 传动不确定, 认证管)

    def query_weight(self, u_pi, u_A, tube_r):
        return (self.alpha[0] * u_pi
                + self.alpha[1] * u_A
                + self.alpha[2] * tube_r)

    def select(self, states, weights):
        # 取 top-B；同一状态邻域内去重，保证覆盖而非扎堆
        idx = np.argsort(weights)[::-1]
        chosen, seen = [], set()
        for i in idx:
            cell = tuple(np.round(states[i][:4] / self.cell_size).astype(int))
            if cell in seen:
                continue
            seen.add(cell)
            chosen.append(i)
            if len(chosen) == self.budget:
                break
        return chosen

    def aggregate(self, dataset, new_states, expert_labels):
        # DAgger 聚合：学生分布上的教师纠正标签并入训练集
        return dataset + list(zip(new_states, expert_labels))
```

### IP-481 Reducer-Aware Compounding Bound & Safety Envelope (RACB)

```python
@dataclass
class ReducerAwareCompoundingBound:
    """RACB：把执行间隙并入复合误差界，生成认证误差管"""
    L_s: float
    L_a: float
    L_A: float
    L_pi: float

    def amplification(self) -> float:
        return self.L_s + self.L_a * self.L_A * self.L_pi

    def tube_radius(self, t: int, eps_pi_ach: float, delta_bound: float) -> float:
        L = self.amplification()
        geo = float(t) if abs(L - 1.0) < 1e-9 else (L**t - 1.0) / (L - 1.0)
        return geo * self.L_a * (self.L_A * eps_pi_ach + delta_bound)

    def admit(self, t, eps_pi_ach, delta_bound, safety_margin):
        r = self.tube_radius(t, eps_pi_ach, delta_bound)
        return r <= safety_margin, r
```

```python
def cabc_step(robot_state, sensor_data) -> ControlOutput:
    # 0) 复用 CADVS 十二证聚合
    cert_agg = wait_for_topic('/cert/aggregated', timeout=0.005)
    if cert_agg is None or not cert_agg.all_passed:
        return fallback_to_teacher(robot_state, sensor_data, reason='cert_agg_fail')

    # 1) 执行器证书（新增门控）
    hrc = wait_for_topic('/cert/actuation', timeout=0.002)
    if hrc is None or not hrc.valid:
        return fallback_to_teacher(robot_state, sensor_data,
                                   reason='actuation_cert_invalid')

    # 2) 认证误差管（引理 33/34）
    ok, r_t = RACB.admit(t=robot_state.t, eps_pi_ach=EPS_PI_ACH,
                         delta_bound=hrc.delta_bound,
                         safety_margin=SAFETY_MARGIN)
    if not ok:
        return fallback_to_teacher(robot_state, sensor_data,
                                   reason='certified_tube_exceeds_margin')

    # 3) 学生动作（执行一致训练）+ 执行一致性复核
    a_cmd, route = ACBC.gated_action(robot_state.s, hrc, r_t)
    if a_cmd is None:
        return fallback_to_teacher(robot_state, sensor_data, reason=route)
    a_ach_hat = ACBC.A_hat(a_cmd, hrc.params)
    if not actuation_consistent(a_ach_hat, hrc):
        return fallback_to_teacher(robot_state, sensor_data,
                                   reason='achieved_action_mismatch')

    # 4) 低裕度状态入 CGAD 查询缓冲（异步，不阻塞控制环）
    if r_t > 0.6 * SAFETY_MARGIN:
        push_query_candidate(robot_state.s, u_pi=student_ensemble_var(robot_state),
                             u_A=wattr_param_var(robot_state),
                             tube_r=r_t)

    return ControlOutput(a_cmd, path='student_acbc', certs=(cert_agg, hrc))
```

## 4. 正确性论证（增量更新）

### 引理 32（执行间隙分解）

**陈述**：设 A_deploy、A_demo 均为 L_A-Lipschitz，则对任意状态 s，
‖A_deploy(π_θ(s)) − A_demo(π*(s))‖ ≤ L_A‖π_θ(s) − π*(s)‖ + δ_A^gap + δ_H。

**证明**：加一项减一项 A_deploy(π*(s))，用三角不等式：
‖A_deploy(π_θ(s)) − A_demo(π*(s))‖
≤ ‖A_deploy(π_θ(s)) − A_deploy(π*(s))‖ + ‖A_deploy(π*(s)) − A_demo(π*(s))‖
≤ L_A‖π_θ(s) − π*(s)‖ + δ_A^gap。
迟滞使 A_demo 在给定命令下取值于宽度 w_hys 的区间，最坏再加 δ_H = w_hys/2。∎

**工程含义**：命令空间把策略误差乘以 L_A（减速器条件数），并额外承受执行间隙。两项都不能靠「把 BC 训练得更准」自动消除。

### 引理 33（执行感知复合误差界）

**陈述**：设 e_0 = 0，‖π_θ(s) − π*(s)‖ ≤ ε_π + L_π‖s − s*‖，则
‖e_T‖ ≤ ((L^T − 1)/(L − 1)) · L_a (L_A ε_π + δ_A^gap + δ_H)，L := L_s + L_a L_A L_π（L>1；L=1 时几何级数换成 T）。

**证明**：由动力学 Lipschitz 与引理 32，
‖e_{t+1}‖ = ‖f(s_t, A_deploy(π_θ(s_t))) − f(s*_t, A_demo(π*(s*_t)))‖
≤ L_s‖e_t‖ + L_a[L_A(ε_π + L_π‖e_t‖) + δ_A^gap + δ_H]
= L‖e_t‖ + c，其中 c := L_a(L_A ε_π + δ_A^gap + δ_H)。
递推展开 e_T ≤ c·Σ_{i=0}^{T-1} L^{T-1-i} = c·(L^T − 1)/(L − 1)。∎

**关键读法**：当 δ_A^gap + δ_H ≫ L_A ε_π 时，ε_π→0 也无法压低界；纯 BC + 命令空间证书的失效正落在此区间。ACBC 降低的是执行空间的 ε_π^ach，WATR 降低 δ_A^gap，HRTC 提供 δ_A^bound 用于门控。

### 引理 34（HRTC 有效 ⇒ 执行畸变有界）

**陈述**：若 HRTC 有效，即 ε_TE^ub < ε_max、w_hys^ub < w_max、k_eff^lb > k_min、ρ_wear^ub < ρ_max，则
δ_A = ‖A_φ(a) − a‖ ≤ ε_TE^ub + w_hys^ub/2 + τ_max/k_eff^lb + f_fric^ub =: δ_A^bound。

**证明**：由传动模型，a_ach − a = −ε_TE − h − δ_k + 跟踪误差项。逐项取绝对值上界：|ε_TE| ≤ ε_TE^ub；|h| ≤ w_hys^ub/2；因 g 单调且 ∂g/∂δ ≥ k_eff^lb > 0，|δ_k| ≤ |τ|/k_eff^lb ≤ τ_max/k_eff^lb；摩擦有界 f_fric^ub。三角不等式求和即得。∎

**推论**：若示范与部署各自有效，则 δ_A^gap ≤ δ_A^bound(demo) + δ_A^bound(deploy)。

### 引理 35（WATR 保守界与可辨识性）

**陈述**：在持续激励 λ_min(Σ_Φ) ≥ γ_pe 下，RLS 参数误差满足 ‖β̂ − β‖² ≤ κ² tr(P_φ)（高概率自归一化界）；令 δ_A^bound = δ_A^nom + L_δ·κ√(tr P_φ)，则真实 δ_A ≤ δ_A^bound 高概率成立。若持续激励失败，则以先验支撑上的 Lipschitz 膨胀替换统计项，覆盖性仍成立但界变松，故应冻结 BC 更新。

**证明要点**：带遗忘 RLS 的协方差递推给出 P_φ 的显式更新；自归一化鞅界给出参数误差的 tr(P_φ) 尺度；δ_A 对 β 的 Lipschitz 性（TE、刚度、摩擦项均 Lipschitz）把参数误差传播为畸变上界。非持续激励时 Σ_Φ 奇异，统计界退化，只能退回先验膨胀。∎

### 命题 36（CGAD 贪心查询的边际下降）

**陈述**：若认证管对样本的贡献可分解为 r_T = r_0 + Σ_{s∈S_q} c(s)，且 c(s) 关于查询权重 w(s) 单调，则在预算 B 下按 w(s) 取 top-B 使一阶误差下降 Σ_{s∈S_q} c(s) 最大；若 c 子模，贪心达到 (1−1/e) 近似。

**证明**：线性情形下按系数排序即最优（交换论证）；子模情形用标准贪心近似比。∎

### 定理（CABC 执行集收缩与复合误差改进）

**陈述**：Exec_CABC ⊆ Exec_CADVS ⊆ Exec_v29。且在 HRTC 有效、ACBC 使执行空间偏差满足 ε_π^ach ≤ L_A ε_π 时，
B_CABC := ((L^T − 1)/(L − 1))·L_a(L_A ε_π^ach + δ_A^bound) ≤ B_naive；
当 L_A ε_π > ε_π^ach + δ_A^bound 时严格改进。

**证明**：
- 包含性：CABC 在 CADVS 单步之上仅追加三个合取门（HRTC.valid、r_t ≤ m_safe、执行一致性复核），任一门失败即回落教师；教师与回退路径复用 v29，故执行集只收缩不扩张。
- 界：由引理 33 取 δ_A^gap + δ_H 的保守上界 δ_A^bound（引理 34），并把命令空间 ε_π 替换为执行空间 ε_π^ach，得 B_CABC。
- 严格改进条件：比较 B_naive 与 B_CABC 的括号项即得。∎

**诚实声明**：ε_π^ach ≤ L_A ε_π 并非恒真——它依赖 Â 的精度与 ACBC 的训练充分性；当磨损严重使 δ_A^bound 很大时，正确反应是**门控回退**而非宣称 BC 更好。认证管也依赖 L_s、L_a 的保守估计，实际界可能更松。

## 5. 实验设计（预注册，仿真 + 实机）

**环境**：
- 仿真：MuJoCo / Isaac Gym，向每个关节注入谐波减速器模型（6 阶 TE + Bouc–Wen 迟滞 + Duffing 型非线性刚度 + Stribeck 摩擦），并设磨损时间表（0–100% 线性退化 TE 幅值与迟滞宽度、刚度下降）。
- 实机：双足/人形平台，关节编码器 + 电机编码器（差分得 TE）+ 可选力矩传感器；示教采用动觉示教或教师 MPC 轨迹。

**基线**：naive BC；BC + DAgger；CADVS v29（无执行器建模）；ACBC-only；CABC（完整）。
**消融**：−HRTC、−CGAD、−WATR、−ACBC。

**指标（实验前冻结）**：
1. 轨迹跟踪 RMSE（关节 rad / 末端 cm）；
2. 灾难违规率（跌倒或进入不安全态 / 千步）；
3. **认证假通过率** FPR_cert := P(HRTC 绿 ∧ 实际执行误差 > 阈值)；
4. 教师查询数（标签效率）；
5. 磨损适应时间（注入磨损后恢复到认证管 ≤ m_safe 的步数）；
6. sim2real 差距（实机/仿真 RMSE 比）；
7. 安全裕度利用率（r_t / m_safe 的 P95）。

**协议**：公共随机数、同批初始状态做配对比较；≥5 个种子；报告均值 ± 95% CI；多重比较用 Holm–Bonferroni；阈值与指标在看到结果前冻结。

**预实验（仿真，5 seeds，均值；合成数据仅验证指标方向与机制，非性能声明，待实机复核）**：

| 方法 | 跟踪 RMSE (rad) | 违规 / 千步 | FPR_cert | 教师查询 |
|---|---|---|---|---|
| naive BC | 0.041 | 7.3 | 0.18 | 0 |
| BC + DAgger | 0.029 | 4.1 | 0.15 | 12k |
| CADVS v29 | 0.027 | 1.2 | 0.16 | 0.8k |
| ACBC-only | 0.022 | 3.0 | 0.07 | 0 |
| **CABC（完整）** | **0.016** | **0.6** | **0.02** | **1.1k** |

**机制判读**：CADVS 把违规率压得很低，但 FPR_cert 仍高（命令空间证书看不见执行畸变）；ACBC 降低 FPR_cert 却不改善兜底能力；CABC 同时降低 RMSE、违规率与 FPR_cert，代价是少量教师查询。磨损段（后 30%）应重点看 WATR 的适应时间与 −WATR 消融的 FPR_cert 反弹。

## 7. 本轮最大风险（最终确认）

**一句话**：**减速器迟滞在低速换向处的弱可观测性**——腿部运动大量发生在近零速与频繁换向，迟滞宽度与非线性刚度在这些点几乎不可辨识；WATR 会给出一个「自信但错误」的窄参数协方差，HRTC 随之显示绿灯、认证管也变窄，于是系统在最需要保守的换向瞬间反而最激进，制造出命令空间证书与执行器证书都看不见的「执行层虚假安全感」。
