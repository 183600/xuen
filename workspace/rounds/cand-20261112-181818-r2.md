# 第 62 轮（承接第 61 轮「具身语义进化闭环」IP-173~182；灵感循环第 2 轮；本轮灵感：「用户共创」×「深度学习」）

> 第 61 轮用 USR×MEL×DMS×SRT-Dual×PCE+++++ 构建了「语义统一、零样本泛化、对话接地、双流解耦」的具身语义进化闭环。但它把**用户**当作「指令源」而非「共创者」，把**学习**当作「一次性训练」而非「持续共适应」。四个更深层的局限浮现：
> 1. **语义空间是设计者先验，不是用户共写的**：USR 的 E_scene/E_intent/E_impedance 一旦训练完成即冻结，用户的纠正（「不是这样，要更贴近表面」）只能改变当次 K，**无法回流去重塑表征本身**——共创被截断在控制层，未进入语义层。
> 2. **个性化与泛化的悖论**：MEL 是单一全局模型，但「轻一点」对不同用户意味着不同力阈值、不同接近速度、不同容错半径。全局模型对所有人「平均正确」，对每个具体的人「系统性偏差」——缺乏**少样本个性化**机制。
> 3. **持续学习即灾难性遗忘**：用户每天贡献纠正/示范，若在线更新 MEL/USR，会在学到新用户偏好的同时**覆盖旧技能与他人偏好**（catastrophic forgetting）；若冻结不学，则个性化永远无法收敛。
> 4. **共创数据稀缺、昂贵且涉隐私**：示范与偏好标注是用户最稀缺的注意力资源，不能漫无目的地索取；也不能把所有用户数据集中到中心服务器（隐私与合规）。当前 DMS 的 `ask_clarify` 是启发式触发，**未按信息价值（VOI）择优提问**，也无联邦式的跨用户共享。
>
> 本轮的核心跃迁：**从「语义进化」到「共创进化」——让用户在回路里共同编写表征、共同训练策略、共同守护安全，同时用深度学习（偏好学习、元学习、持续学习、主动学习、联邦学习）把这些「共同」变成可计算、可证明、可审计的机制。**

## 0. 直觉与动机

**灵感 1（用户共创 → 共创语义空间 Co-USR）**
直觉：第 61 轮的 USR 像一本「官方词典」，用户只能按词典说话。真正的共创，应允许每个用户拥有自己的「方言子空间」：共享语义（摩擦/刚度/轻触）仍然通用，但用户 A 的「轻」和用户 B 的「轻」可以在各自的低秩子空间里被精确表达。关键洞见：**把 USR 分解为「共享流形 ⊕ 个人流形」**——共享流形由所有用户通过联邦方式共同维护，个人流形是每个用户的低秩适配器（rank ≤ 8），由该用户的纠正/示范增量更新。这样「共性可迁移、个性不互扰」，且个人适配器永不回写污染共享语义。

**灵感 2（深度学习 → 偏好对齐阻抗 PAL）**
直觉：「轻一点」不是一条可精确编码的规格，而是一个**偏好**。人无法直接给出 K_p=37.2，但能轻松判断「这组参数比那组更舒服/更稳」。关键洞见：把阻抗策略学习从「回归/规则」升级为**成对偏好学习（Bradley-Terry + DPO）**——用户只做「A 比 B 好」的比较，模型拟合隐式奖励 r_ψ(K, context)，再用带安全 KL 约束的 DPO 对齐生成式阻抗策略（扩散/GMM 策略）。偏好数据天然低负荷、可累积、可审计。

**灵感 3（用户共创 × 深度学习 → 少样本个性化 PMEL）**
直觉：一个新用户不该被要求演示 100 次。用元学习（MAML/Reptile）在「多用户任务分布」上预训练，使模型「学会如何快速学会一个用户」；再用 HyperNetwork 从该用户 3~5 次示范直接生成 LoRA 适配器。关键洞见：**基座冻结、适配器生成、元学习预热**——个性化成本从「重训练」降到「K-shot 适配 ≤ 10 步」，且不破坏共享安全先验。

**灵感 4（深度学习 → 持续共适应 CCL，抗灾难遗忘）**
直觉：机器人与用户是「共同适应」的——用户改变习惯，机器人也要跟进；机器人改变行为，用户也会调整。关键洞见：在**共享参数上做 EWC（弹性权重固化）+ 知识蒸馏 + 经验回放**，在**个人适配器上放开学习**；每次提交适配器前必须通过「安全回归测试」。遗忘被度量、被约束、被证书化，而不是被祈祷。

**灵感 5（用户共创 × 深度学习 → 主动共创查询 ACQ）**
直觉：用户注意力是预算。不要每隔 10 秒问一句「这样对吗」，而应在**模型最不确定、且该不确定性最影响安全/任务**的地方提问。关键洞见：用 BALD/互信息估计个人适配器的认知不确定性，乘以风险权重得到 VOI，再扣掉人类认知负荷成本；`ask_clarify` 从「规则触发」升级为「VOI 最优查询」，并显式受 B_hitl 人类注意力预算约束。

**灵感 6（三灵感合流 → 联邦共创 + 安全证书）**
直觉：跨用户共享能加速学习，但不能搬运隐私；个人偏好还会互相冲突，甚至用户可能给出不安全偏好。关键洞见：**FCL 联邦共享编码器（DP-SGD + 安全聚合），PAL 在安全 KL 球内对齐，CCL 提交前过安全回归，J_coadapt 证书记录偏好一致性/遗忘度/隐私预算/安全回归**。共创不是「用户说了算」，而是「用户在安全护栏内共同定义多样性」。

**灵感 7（PCE++++++ → 八维认知-语义-学习预算）**
直觉：第 61 轮 B_cog5 只有「推理/对齐」预算，缺少「学习预算」与「人的预算」。拓展为 **B_cog8 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_learn, B_hitl)**：B_learn 管梯度步/回放容量/适配器秩/蒸馏频率/隐私 ε；B_hitl 管提问次数/示范次数/认知负荷上限。任何一维耗尽都触发安全降级，且**安全维度永不降级**。

## 1. 形式化定义（增量：定义 173–184）

**定义 173（共创语义空间 Co-USR）** 对用户集合 𝒰，Co-USR = (E_sh, {A_u}_{u∈𝒰}, D_u, ℒ_co, X_anchor)：
- **共享子空间**：E_sh: X → ℝ^{d_s}，d_s = 192；场景/意图/阻抗/证据的通用语义，仅经联邦聚合更新
- **个人子空间**：A_u: ℝ^{d_s} → ℝ^{d_p}，d_p = 64，A_u(x) = B_u A_u^T x，秩 r_u ≤ 8，谱范数 ‖A_u‖_2 ≤ B_A
- **用户嵌入**：z_u(x) = [E_sh(x); A_u(E_sh(x))] ∈ ℝ^{d_us}，d_us = d_s + d_p = 256
- **个人方言映射**：D_u: (utterance, context) → personal_intent ∈ ℝ^{d_p}，把「轻一点」在该用户语境下解析
- **共创损失**：ℒ_co = ℒ_contrast(shared) + λ_p·ℒ_pref(personal) + λ_r‖A_u‖_* + λ_s‖A_u‖_2²
  - ℒ_contrast 在共享空间保持跨用户语义关系（距离/邻域结构）不变
  - ℒ_pref 用 PAL 的偏好损失更新个人子空间
- **跨用户锚点**：X_anchor 为一组规范探针，要求共享编码在更新前后 ‖E_sh^{new}(x) - E_sh^{old}(x)‖² ≤ ε_stab，防止共享语义漂移
- **隔离性**：∀u≠v，∂z_u/∂A_v ≡ 0（个人适配器互不干扰）

**定义 174（偏好对齐阻抗学习 PAL）** PAL = (r_ψ, π_θ, D_u^{pref}, δ_safe)：
- **偏好数据**：D_u^{pref} = {(c_i, τ_i^+, τ_i^-)}，c 为上下文（场景/意图/物理先验），τ 为阻抗轨迹（K(t) 序列）
- **隐式奖励**：r_ψ(c, τ) ∈ ℝ，Bradley-Terry 似然 P(τ^+≻τ^-|c) = σ(r_ψ(c,τ^+) - r_ψ(c,τ^-))
- **生成式阻抗策略**：π_θ(τ|c)（扩散或 GMM），可表达多模态「舒适区」
- **安全约束 DPO**：
  ```
  ℒ_DPO(θ) = -E_{(c,τ⁺,τ⁻)} log σ( β · [ log(π_θ(τ⁺|c)/π_ref(τ⁺|c))
                                        - log(π_θ(τ⁻|c)/π_ref(τ⁻|c)) ] )
  s.t.  D_KL( π_θ(·|c) ‖ π_safe(·|c) ) ≤ δ_safe      # 安全先验 KL 球
        supp(π_θ(·|c)) ⊆ 𝒦_safe(φ_phys, C_exec)      # 支撑集在安全阻抗集内
  ```
- **偏好一致性**：C_pref = (1/|D_val|)Σ 𝕀[π_θ 满足留出偏好对] ∈ [0,1]
- **冲突消解**：当个人偏好与安全先验冲突（D_KL > δ_safe），自动投影回安全球并在 CDMS 中发起协商，不静默服从用户

**定义 175（个性化具身大模型 PMEL）** PMEL_u = (Θ_base, φ_u, H)：
- **基座**：Θ_base 为第 61 轮 MEL，冻结
- **个人适配器**：φ_u = (ΔW_u^{LoRA}, b_u)，LoRA ΔW_u = B_u A_u，秩 r_u ≤ 8
- **超网络**：H(ξ_u) → φ_u，ξ_u = (K-shot 示范, 用户画像, 个人方言 D_u) 的聚合嵌入
- **元训练（MAML/Reptile）**：
  ```
  min_{Θ_base,H} Σ_{u∈𝒰_train} L_u( Θ_base, H(ξ_u) - α∇H(ξ_u) L_u^{support}(Θ_base, H(ξ_u)) )
  ```
  目标：让 H 输出「只需 ≤ T_adapt 步适配」的初始适配器
- **K-shot 适配**：给定 K∈{3,5,10} 个示范，最多 T_adapt=10 步梯度，达到个人化误差 ≤ ε_personal
- **解耦保证**：共享参数不变，仅 φ_u 更新；换用户时切换适配器即可，无需重载基座

**定义 176（持续共适应学习 CCL）** CCL = (M_mem, ℒ_CCL, Gate_safety)：
- **持续损失**：
  ```
  ℒ_CCL(θ) = ℒ_task(θ)
           + λ_e · Σ_i F_i (θ_i - θ_i^*)²         # EWC：保护重要参数
           + λ_kd · KL( π_old(·|c) ‖ π_new(·|c) ) # 蒸馏：旧策略不遗忘
           + λ_r · ℒ_replay(M_mem)                 # 回放：重放旧经验
  ```
- **情节记忆**：M_mem，容量 B_mem.B_replay，reservoir 采样 + 按「对安全/偏好信息量」重要性淘汰
- **共享语义稳定**：共享编码仅在 ‖E_sh^{new}(x)-E_sh^{old}(x)‖² ≤ ε_stab（X_anchor 上）时提交
- **安全门控**：个人适配器只在通过安全回归套件 R_safe（无 ERTC 违规、力/速限不越界）后上位；否则保留旧适配器并记录失败
- **遗忘度量**：F_forget = max_t (perf_t - perf_final)；后向迁移 BWT = (1/(T-1))Σ_{t<T}(perf_{T,t} - perf_{t,t})

**定义 177（主动共创查询 ACQ）** ACQ = (Q, VOI, B_hitl, π_q)：
- **查询空间**：Q = {preference_pair, demonstration, correction, physical_property, vocabulary}
- **信息价值**：
  ```
  VOI(q) = E_{y~p(y|q,D)}[ H(Θ_personal|D) - H(Θ_personal|D∪{(q,y)}) ] · w_risk(q)
  近似为 BALD：VOI(q) ≈ I(y ; Θ_personal | q, D) · w_risk(q)
  ```
- **选择规则**：
  ```
  q* = argmax_{q∈Q}  VOI(q) - λ_hitl · cost_hitl(q)
       s.t.  cost_hitl(q) ≤ B_hitl.remaining  ∧  q 不重复（语义去重）
  ```
- **类型选择策略**：认知不确定性高 → demonstration；偏好不确定 → preference_pair；物理属性不确定 → physical_property；方言歧义 → vocabulary
- **集成 CDMS**：ACQ 产出候选并按 VOI 排序，CDMS 决定「现在问 / 稍后问 / 不问（超预算）」

**定义 178（共创对话管理 CDMS）** 升级第 61 轮 DMS，CDMS = (S', A', P', R', π')：
- **状态扩展**：S' = (H_diag, b_intent, C_exec, C_pending, U_mel, turn_id, u, learn_buf, adapter_status, U_personal)
  - u: 用户标识；learn_buf: 待入库的 (示范/纠正/偏好) 元组；adapter_status: 个人适配器版本与安全回归状态；U_personal: 个人化不确定性
- **动作扩展**：A' = A ∪ {teach_by_demo, correct_trajectory, prefer(A,B), co_design_representation(edit_vocab/subspace), teach_physical_prior}
- **奖励扩展**：R' = 𝕀[task_complete] - λ_cog·load - λ_safe·risk - λ_lat·latency + λ_learn·VOI_realized
- **接地规则**：用户纠正 → (s,a,r,s') 写入 learn_buf → 触发 PAL/PMEL/CCL；执行证据 EV-exec 与用户话语共同接地，形成「执行→语言→学习」闭环
- **共创约束**：co_design_representation 只能修改**个人子空间**；修改共享子空间必须走联邦聚合 + 证书，单个用户无权改写公共语义

**定义 179（联邦共创学习 FCL）** FCL = (E_sh, {φ_u}, DP, SecAgg)：
- **本地私有**：用户原始数据与个人适配器 φ_u 永不出本地
- **共享聚合**：
  ```
  E_sh^{t+1} = Σ_{u∈𝒰_t} (n_u / N) · E_sh^{t,u},   E_sh^{t,u} ← E_sh^t - η·clip(∇L_u; C) + N(0, σ²C²I)
  ```
  DP-SGD 提供 (ε_u, δ_u)-DP；安全聚合保证服务器只见聚合结果
- **隐私账本**：每个用户维护 ε_used，超 ε_max 即退出本轮聚合
- **跨用户对齐**：X_anchor 上的共享表示一致性作为聚合验收条件；个人子空间允许差异

**定义 180（八维认知-语义-学习预算 B_cog8 与 PCE++++++）** B_cog8 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_learn, B_hitl)：
- **B_learn** = (Grad_steps, Replay_capacity, Adapter_rank, Distill_freq, DP_epsilon)
- **B_hitl** = (Query_budget, Max_turns, Cognitive_load_cap, Demo_budget)
- **成本函数**：
  ```
  cost_cog8 = λ_scene·Rec + λ_intent·Lat + λ_ros·Msg
            + λ_mel·(Mel_lat/τ_mel + Tokens/Token_budget)
            + λ_usr·(Align_iters/Max_iters + Proj_error/Proj_tol)
            + λ_learn·(Grad_steps/Steps_max + ε_used/ε_max + Replay_used/Replay_capacity)
            + λ_hitl·(Queries/Query_budget + Load/Load_cap)
  ```
- **降级（安全不降级）**：
  - B_hitl 耗尽 ⇒ ACQ 停止提问，退回「保守先验 + 自主探索」，CDMS 只发紧急澄清
  - B_learn 耗尽 ⇒ 冻结个人适配器（用缓存的 φ_u），停止回放/蒸馏
  - B_usr 耗尽 ⇒ 冻结共享编码，仅用个人子空间投影
  - B_mel 耗尽 ⇒ 第 61 轮三级降级（蒸馏→缓存→冻结锚点）
  - **任何降级都不得放宽 ERTC 实时契约与 J_coadapt 安全校验**

```
J_coadapt = ( J_sem_exec,
```

**定义 182（共创具身语义进化闭环 CoESEC）** 统一算子：
```
CoESEC(M, u, V, T, P, L, delta_f_req):
  # ① 主动共创：决定是否/如何向用户学习
  q* ← ACQ.select(U_personal, B_hitl, risk)
  if q* ≠ ∅: a_q ← CDMS.elicit(q*); learn_buf.push(a_q)

  # ② 语义流（~10-100Hz）
  φ_phys, z_scene, π_intact, U_mel ← PMEL_u.infer(V,T,P,L, M.scene_emb, M.evidence_emb)
  a_diag ← CDMS.step(M.H_diag, M.b_intent, M.C_exec, U_mel, U_personal)
  M.scene_emb  ← z_scene
  M.intent_emb ← CoUSR.encode_intent(D_u(b_intent))
  M.anchor     ← CoUSR.commit(scene_emb, intent_emb, φ_phys, U_mel)

  # ③ 实时流（~1-10kHz，只消费锚点，不阻塞）
  anchor, fresh ← CoUSR.read_latest()
  K_prior ← Π(anchor.scene_emb + anchor.intent_emb)
  K_safe  ← EEIS.compile(delta_f_req, fused, ξ_exec, Z_env, K_prior, φ_phys)
  dispatch(K_safe)
  EV_exec ← wait_contact()

  # ④ 执行→语言→学习接地
  CDMS.ground(EV_exec, L)
  if learn_buf 达到触发条件:  CCL.update_local(learn_buf)        # EWC+蒸馏+回放
  if 个人适配器候选:          Gate_safety(φ_u^{new}) → 通过则换装
  if 满足联邦周期:            FCL.aggregate(E_sh; DP, SecAgg)     # 仅共享编码

  # ⑤ 认证
  M.J_coadapt ← build_coadapt_cert(EV_exec, CoUSR, C_pref, F_forget, ε_dp, safety_regression)
  return M, K_safe, EV_exec, M.J_coadapt
```

**定义 183（共适应收敛与个性化泛化界）** 设元训练用户数 M、每用户 K-shot、假设类复杂度由适配器秩 r 与谱范数 B_A 约束。则对未见用户 u_new，K-shot 适配后的期望个人化误差满足：
```
E[err_u] ≤ ε_base + O( √( r·B_A²·log(M/δ) / K ) ) + O( √( (d_s·log M)/M ) )
```
即：**用户越多（M↑）共享先验越好；示范越多（K↑）个性化越准；适配器越简（r↓, B_A↓）泛化越稳**。这解释了为什么「低秩个人子空间 + 元学习预热」优于「全参数微调」。

**定义 184（共创安全性定理 Co-Safety）** 若每次提交的个人策略满足 `D_KL(π_θ ‖ π_safe) ≤ δ_safe`、`supp(π_θ) ⊆ 𝒦_safe`、且 `‖A_u‖_2 ≤ B_A`、`safety_regression = True`，则对任意用户 u 与任意执行时刻 t：
```
P( K_safe(t) ∈ 𝒦_safe ) ≥ 1 - α
```
其中 α 由 δ_safe、B_A 与实时流投影误差 e_proj 联合界定。**用户共创可以改变「偏好分布」，但不能改变「安全集合的边界」**——这是本轮的核心安全不变量。

```python
    def __init__(self, d_s=192, d_p=64, rank=8, B_A=1.0, anchor_ttl=0.2):

        self.dialect[u] = PersonalDialectMap(self.d_p)

    def encode(self, u, x):

        z_p = self.personal[u](z_sh)                   # 个人方言
        return torch.cat([z_sh, z_p], dim=-1)          # ∈ R^{d_us}

    def encode_intent(self, u, b_intent):

        z_p = self.dialect[u].project(b_intent)
        return torch.cat([z_sh, z_p], dim=-1)

    def co_loss(self, u, batch, pref_pairs):
        z = self.encode(u, batch.x)
        L_contrast = contrastive_keep_relations(z[:, :self.d_s])   # 共享关系不漂移
        L_pref = self.personal[u].preference_loss(pref_pairs)      # 个人偏好
        L_reg = self.rank(self.personal[u]) + self.B_A * self.personal[u].spectral_norm()
        return L_contrast + 0.5 * L_pref + 1e-3 * L_reg

    def shared_drift(self, new_shared):
        with torch.no_grad():
            d = sum(((new_shared(x) - self.shared(x)) ** 2).sum()
                    for x in self.X_anchor)
        return float(d / len(self.X_anchor))

    def commit_shared(self, new_shared, eps_stab=1e-3):
        if self.shared_drift(new_shared) <= eps_stab:
            self.shared = new_shared
            return True
        return False                                    # 共享语义拒绝漂移
```

### IP-184 PAL（偏好对齐阻抗）

```python
class PreferenceAlignedImpedance:
    def __init__(self, policy, ref_policy, safe_policy, beta=0.1, delta_safe=0.05):
        self.pi = policy                # 生成式阻抗策略 pi_theta(tau|c)
        self.pi_ref = ref_policy        # 参考策略（冻结）
        self.pi_safe = safe_policy      # 安全先验（来自第 61 轮 EEIS）
        self.beta = beta
        self.delta_safe = delta_safe

    def dpo_loss(self, c, tau_plus, tau_minus):
        lp = self._logp(self.pi, tau_plus, c) - self._logp(self.pi_ref, tau_plus, c)
        lm = self._logp(self.pi, tau_minus, c) - self._logp(self.pi_ref, tau_minus, c)
        return -F.logsigmoid(self.beta * (lp - lm)).mean()

    def safe_step(self, c, tau_plus, tau_minus):
        loss = self.dpo_loss(c, tau_plus, tau_minus)
        self.opt.zero_grad(); loss.backward(); self.opt.step()
        # 安全投影：KL 球 + 支撑集
        with torch.no_grad():
            kl = self._kl(self.pi, self.pi_safe, c)
            if kl.item() > self.delta_safe:
                self._project_to_safe_ball(c, self.delta_safe)
        return loss.item()

    def _project_to_safe_ball(self, c, delta):
        # 沿 (pi_safe - pi) 方向插值，二分找到 KL=delta 的投影点
        for _ in range(20):
            lam = self._bisect_lambda(c, delta)
            self._interpolate_towards(self.pi_safe, lam)

    def preference_consistency(self, val_pairs):
        return np.mean([self._satisfies(c, tp, tm) for c, tp, tm in val_pairs])
```

```python
class ContinualCoAdaptiveLearner:
    def __init__(self, model, ewc_lambda=0.4, kd_lambda=0.3, replay_lambda=0.3,
                 mem_size=1000, eps_stab=1e-3):
        self.model = model
        self.ewc = EWC(ewc_lambda)
        self.pi_old = copy.deepcopy(model)
        self.mem = EpisodicMemory(mem_size)
        self.eps_stab = eps_stab

    def update_local(self, learn_buf):
        batch = self.mem.sample() + learn_buf
        loss = self._task_loss(batch)
        loss += self.ewc.penalty(self.model)
        loss += 0.3 * self._distill_kl(self.pi_old, self.model, batch)
        loss += 0.3 * self._task_loss(self.mem.sample())
        self.model.step(loss)
        self.mem.add_important(learn_buf)           # 按安全/偏好信息量入memory

    def try_promote(self, phi_candidate, safety_suite):
        if not safety_suite.pass_(phi_candidate):    # 安全回归门控
            log_reject(phi_candidate); return False
        if self.model.shared_drift(phi_candidate) > self.eps_stab:
            return False                             # 共享语义不漂移
        self.model.swap_adapter(phi_candidate)
        self.ewc.update_fisher(self.mem.sample())
        return True

    def forgetting(self, per_task_perf):
        T = len(per_task_perf)
        final = [per_task_perf[T-1][t] for t in range(T)]
        best = [max(per_task_perf[t][t], final[t]) for t in range(T)]
        return float(np.mean([best[t] - final[t] for t in range(T)]))
```

```python
class ActiveCoCreationQuery:
    def __init__(self, ensembler, B_hitl, risk_weights):
        self.ens = ensembler             # 个人适配器集成/多head，用于 BALD
        self.B_hitl = B_hitl
        self.w_risk = risk_weights

    def voi(self, q, context):
        probs = self.ens.predictive_distribution(context, q)   # [N_models, n_y]
        mean_p = probs.mean(0)
        H_total = entropy(mean_p)
        H_aleatoric = probs.apply_along_axis(entropy, 1).mean()
        mutual_info = H_total - H_aleatoric                    # BALD
        return mutual_info * self.w_risk[q.type]

    def select(self, candidates, context):
        best, best_score = None, -1e9
        for q in dedup_semantic(candidates):
            c = self.cost(q)
            if c > self.B_hitl.remaining: continue
            score = self.voi(q, context) - self.lam * c
            if score > best_score:
                best, best_score = q, score
        return best                                            # 可为 None（不问）

    def cost(self, q):
        return {'preference_pair': 0.5, 'demonstration': 3.0,
                'correction': 1.0, 'physical_property': 0.8,
                'vocabulary': 0.6}[q.type]
```

```python
class FederatedCoCreation:
    def __init__(self, shared_encoder, dp_epsilon=1.0, delta=1e-5, clip=1.0):
        self.E = shared_encoder
        self.eps, self.delta, self.clip = dp_epsilon, delta, clip
        self.ledger = {}                         # u -> eps_used

    def local_update(self, u, local_data):
        if self.ledger.get(u, 0.0) >= self.eps:
            return None                          # 隐私预算耗尽，退出
        grad = clip_grad(self._grad(local_data), self.clip)
        noisy = grad + torch.randn_like(grad) * self.clip * self._sigma()
        self.ledger[u] = self.ledger.get(u, 0.0) + self._eps_spent()
        return noisy

    def aggregate(self, updates, weights):
        # 安全聚合：服务器只见加权和，不见单个用户更新
        agg = sum(w * g for g, w in zip(updates, weights))
        candidate = apply_grad(self.E, agg)
        if self.E.drift_to(candidate, X_anchor) <= 1e-3:
            self.E = candidate
        else:
            log_reject('shared drift on aggregation')
```

### IP-183 Co-USR（共创语义空间）

```python
class CoCreativeUSR:
    def __init__(self, d_s=192, d_p=64, rank=8, B_A=1.0, anchor_ttl=0.2):
        self.d_s, self.d_p, self.rank, self.B_A = d_s, d_p, rank, B_A
        self.shared = SharedSemanticEncoder(d_s)      # 仅联邦聚合更新
        self.personal = {}                             # u -> LowRankAdapter
        self.dialect = {}                              # u -> PersonalDialectMap
        self.anchor_ttl = anchor_ttl
        self.anchor_buf = SharedMemoryAnchor(d_s + d_p)
        self.X_anchor = load_canonical_probes()

    def register_user(self, u):
        self.personal[u] = LowRankAdapter(self.d_s, self.d_p, self.rank, B_A=self.B_A)
        self.dialect[u] = PersonalDialectMap(self.d_p)

    def encode(self, u, x):
        z_sh = self.shared(x)
        return torch.cat([z_sh, self.personal[u](z_sh)], dim=-1)  # R^{256}

    def encode_intent(self, u, b_intent):
        z_sh = self.shared.intent(b_intent)
        return torch.cat([z_sh, self.dialect[u].project(b_intent)], dim=-1)

    def co_loss(self, u, batch, pref_pairs):
        z = self.encode(u, batch.x)
        L_contrast = contrastive_keep_relations(z[:, :self.d_s])
        L_pref = self.personal[u].preference_loss(pref_pairs)
        L_reg = self.rank(self.personal[u]) + self.B_A * self.personal[u].spectral_norm()
        return L_contrast + 0.5 * L_pref + 1e-3 * L_reg

    def shared_drift(self, new_shared):
        with torch.no_grad():
            return float(sum(((new_shared(x) - self.shared(x)) ** 2).sum()
                             for x in self.X_anchor) / len(self.X_anchor))

    def commit_shared(self, new_shared, eps_stab=1e-3):
        if self.shared_drift(new_shared) <= eps_stab:
            self.shared = new_shared; return True
        return False
```

### IP-184 PAL（偏好对齐阻抗）

```python
class PreferenceAlignedImpedance:
    def __init__(self, policy, ref_policy, safe_policy, beta=0.1, delta_safe=0.05):
        self.pi, self.pi_ref, self.pi_safe = policy, ref_policy, safe_policy
        self.beta, self.delta_safe = beta, delta_safe

    def dpo_loss(self, c, tau_plus, tau_minus):
        lp = self._logp(self.pi, tau_plus, c) - self._logp(self.pi_ref, tau_plus, c)
        lm = self._logp(self.pi, tau_minus, c) - self._logp(self.pi_ref, tau_minus, c)
        return -F.logsigmoid(self.beta * (lp - lm)).mean()

    def safe_step(self, c, tau_plus, tau_minus):
        loss = self.dpo_loss(c, tau_plus, tau_minus)
        self.opt.zero_grad(); loss.backward(); self.opt.step()
        with torch.no_grad():
            if self._kl(self.pi, self.pi_safe, c) > self.delta_safe:
                self._project_to_safe_ball(c, self.delta_safe)   # 硬投影
        return loss.item()

    def preference_consistency(self, val_pairs):
        return np.mean([self._satisfies(c, tp, tm) for c, tp, tm in val_pairs])
```

### IP-185 PMEL（少样本个性化）

```python
class PersonalizedMEL:
    def __init__(self, base_mel, d_context=128, rank=8, T_adapt=10):
        self.base = base_mel
        self.hyper = HyperNetwork(d_context, rank)
        self.rank, self.T_adapt = rank, T_adapt

    def adapt(self, xi_u, support_demos, steps=None):
        phi = LoRAAdapter(*self.hyper(xi_u))
        opt = torch.optim.SGD(phi.parameters(), lr=0.05)
        for _ in range(steps or self.T_adapt):
            loss = self._personal_loss(phi, support_demos)
            opt.zero_grad(); loss.backward(); opt.step()
        return phi

    def infer(self, phi_u, V, T, P, L, scene_emb, evidence_emb):
        return self.base.infer(V, T, P, L, scene_emb, evidence_emb, adapter=phi_u)

    def meta_train(self, users, inner_steps=5, outer_steps=2000):
        for _ in range(outer_steps):
            meta_grad = 0
            for u in sample(users):
                phi = self.hyper(u.context)
                for _ in range(inner_steps):
                    phi = phi - 0.05 * grad(self._personal_loss(phi, u.support))
                meta_grad += grad(self._personal_loss(phi, u.query), self.hyper)
            self.hyper.step(meta_grad / len(users))
```

### IP-186 CCL（持续共适应，抗遗忘）

```python
class ContinualCoAdaptiveLearner:
    def __init__(self, model, mem_size=1000, eps_stab=1e-3):
        self.model, self.eps_stab = model, eps_stab
        self.ewc = EWC(0.4)
        self.pi_old = copy.deepcopy(model)
        self.mem = EpisodicMemory(mem_size)

    def update_local(self, learn_buf):
        batch = self.mem.sample() + learn_buf
        loss = self._task_loss(batch)
        loss += self.ewc.penalty(self.model)
        loss += 0.3 * self._distill_kl(self.pi_old, self.model, batch)
        loss += 0.3 * self._task_loss(self.mem.sample())
        self.model.step(loss)
        self.mem.add_important(learn_buf)

    def try_promote(self, phi_candidate, safety_suite):
        if not safety_suite.pass_(phi_candidate):    # 安全门控
            log_reject(phi_candidate); return False
        if self.model.shared_drift(phi_candidate) > self.eps_stab:
            return False                             # 共享语义不漂移
        self.model.swap_adapter(phi_candidate)
        self.ewc.update_fisher(self.mem.sample())
        return True
```

### IP-187 ACQ（VOI 最优提问）

```python
class ActiveCoCreationQuery:
    def __init__(self, ensembler, B_hitl, risk_weights, lam=0.2):
        self.ens, self.B_hitl = ensembler, B_hitl
        self.w_risk, self.lam = risk_weights, lam

    def voi(self, q, context):
        probs = self.ens.predictive_distribution(context, q)
        mean_p = probs.mean(0)
        H_total = entropy(mean_p)
        H_aleatoric = probs.apply_along_axis(entropy, 1).mean()
        return (H_total - H_aleatoric) * self.w_risk[q.type]  # BALD

    def select(self, candidates, context):
        best, best_score = None, -1e9
        for q in dedup_semantic(candidates):
            c = self.cost(q)
            if c > self.B_hitl.remaining: continue
            score = self.voi(q, context) - self.lam * c
            if score > best_score:
                best, best_score = q, score
        return best                                   # None = 现在不问

    def cost(self, q):
        return {'preference_pair': 0.5, 'demonstration': 3.0,
                'correction': 1.0, 'physical_property': 0.8,
                'vocabulary': 0.6}[q.type]
```

```python
class FederatedCoCreation:
    def __init__(self, shared_encoder, dp_epsilon=1.0, delta=1e-5, clip=1.0):
        self.E, self.eps, self.delta, self.clip = shared_encoder, dp_epsilon, delta, clip
        self.ledger = {}

    def local_update(self, u, local_data):
        if self.ledger.get(u, 0.0) >= self.eps:
            return None                                # 隐私预算耗尽
        grad = clip_grad(self._grad(local_data), self.clip)
        noisy = grad + torch.randn_like(grad) * self.clip * self._sigma()
        self.ledger[u] = self.ledger.get(u, 0.0) + self._eps_spent()
        return noisy

    def aggregate(self, updates, weights):
        agg = sum(w * g for g, w in zip(updates, weights))  # 安全聚合
        candidate = apply_grad(self.E, agg)
        if self.E.drift_to(candidate, X_anchor) <= 1e-3:
            self.E = candidate
        else:
            log_reject('shared drift on aggregation')
```
