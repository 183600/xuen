# 第 58 轮（承接第 57 轮「FewShot-XModal-Persona」IP-133~138；新灵感循环第 1 轮；本轮灵感：「任务分解」×「基线复现」）

> 第 57 轮把证据承诺推到"少样本可校准、跨模态可对账、个性化有界"，其风险自陈却暴露了一个更靠后的方法论问题：**这 57 轮本身就是一座越垒越高的理论塔**——每一轮都宣称"相对上一轮 +8%/−30%"，却 **(a) 没有一个被复现过的稳定基线**，所谓"上一轮"的指标从未在固定环境指纹下重跑，改进可能只是环境/种子/仿真器版本差异的伪影；**(b) 整体架构已大到无法端到端复跑**，失败只能靠"再加一个机制"局部打补丁，机制之间是否相互抵消无人验证；**(c) 任务分解一直是隐式而随意的**（路线→检查点），从没证明过"每个检查点局部安全 ⇒ 整条路线全局安全"。本轮两个灵感恰好互为对偶：**任务分解**回答"如何把安全命题切小、切到可核验"——显式构造带接口与误差预算的契约树，并把"分解本身"当作待证明对象；**基线复现**回答"如何让改进命题可信"——钉住基线与环境指纹、先复现再比较，把"改进"变成证书。二者合流：**分解使复现可行（复现契约而非复现巨石），复现使分解诚实（每个契约的界都必须重跑，接缝误差无处藏身）**。核心命题由"证据说可信"升级为 **"可复现、可组合的契约说可信"**。

核心矛盾：
- **H29（分解间隙）**：局部安全不等于全局安全。子目标用代理指标"成功"、前置条件在接缝处泄漏、误差预算重复计数、子证据跨上下文不迁移——越是分解，接缝越多，而被低估的恰恰是接缝；"我的子任务做完了"永远不等于"整体是安全的"。
- **H30（基线漂移）**：仿真器版本、硬件批次、种子集合、地形分布任一改变，都能让"改进 8%"变成环境失配的伪影；而"上一轮"自身从未被复现，比较对象本身就是一个移动靶。没有指纹的基线不是基线，只是传说。
- **H31（复现税 vs 研究速度）**：全量复现昂贵到拖死迭代；不复现则未验证的声明层层累积，整座塔建在流沙上。必须给复现定价：按风险加权决定"哪些契约必须现跑、哪些可按指纹复用"，把复现当成可预算的投资而非道德义务。

## 0. 直觉与动机

**灵感 1（任务分解 → 契约树 + 接缝账本）**
直觉：一段长距离穿越不是"一个巨大的承诺"，而是一串小承诺；真正危险的从来不是任何单个承诺，而是**接缝**。把任务显式分解成 AND/OR 契约树：每个结点携带契约 C=(Pre, Post, ε 预算, 证据义务 E, 步态 G, 接触级 L)，每条边携带**接缝条件 S_e**（父结点在交班时到底保证了什么）。安全必须被**结构化地清偿**：父 Prior 蕴含首子 Prior；子 Post 蕴含下一子 Pre（链式无缝）；子预算按并集界求和再加接缝误差；OR 分支另计选择误差。于是"分解"本身成为一个证明对象 J_dec——这是第 57 轮"证据按模态分账"在任务层的对偶：**证据按模态分账，安全按任务结点分账**。

**灵感 2（基线复现 → 环境指纹 + 复现证书）**
直觉："相对第 57 轮提升 8%"在"第 57 轮根本没在同一地形分布/同一机器人/同一噪声/同一种子上跑过"时毫无意义。给每个基线钉上**环境指纹** F_env（地形分布参数、形态学参数、传感器噪声模型、种子集、仿真/硬件版本），并给出**复现证书** RepCert：任何比较之前，必须先在方法 M 的 F_env 下重跑基线，做统计等价检验（TOST），并报告漂移 d_rep。**未被复现的"改进"只能算猜想，不得进入证据门**——复现是门，不是杂务。

**灵感 3（二者的对偶 → 分解使复现可行，复现使分解诚实）**
直觉：整座巨石无法端到端复跑，但一个契约可以。分解把"复现一个系统"切成"复现若干个契约"，让复现第一次变得可行；反过来，复现专门抓分解的谎——一个"孤立时成立、组合时失效"的子契约，正是**组合复现**会在接缝处暴露出来的东西。因此复现必须**分层**：既复现叶子，也复现接缝。两个机制共用同一个危险对象——**接口**（接缝条件 / 环境指纹），也共用同一个新的信任锚。

**灵感 4（复现税与复现缓存）**
直觉：复现很贵，不能什么都复现。给每个契约一个**风险加权的复现义务**：高 ε / 高接触级 L2 / 高新颖度（d_env 大）的契约必须现跑；低风险、指纹匹配的契约可复用缓存 RepCert，只做小样本再验证。显式预算**复现税** Rtax 与缓存失效，把复现当成 VOI 问题——把复现花在"最能把全局失效概率压下去"的接缝上。

**灵感 5（合流 → 证据门升级为契约门，PCE++）**
直觉：证据门变成**契约门**：一次承诺可采纳，当且仅当叶子契约的证据义务满足 ∧ 每个祖先结点的分解义务（O1–O4）已清偿 ∧ 每份被复用的基线/契约都持有有效 RepCert。PCE++ 在每个检查点于 {探针, 分解, 复现, 绕行, 协商, 停} 间选择，VOI 里新增 **VOI_repro**：当当前契约的界太松而无法承诺时先分解；当声明依赖于未复现的参照时先复现，否则把它降级为猜想。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（分层契约树 HCT）** 树 𝒯=(𝒩,ℰ,type)，结点 n 携带契约 C_n=(Pre_n,Post_n,ε_n,E_n,G_n,L_n)（前后置世界谓词、失效预算、证据义务、步态、接触级）；type(n)∈{AND,OR,LEAF}；接缝 e=(n→m) 携带接缝条件 S_e（父对子保证什么）与接缝误差 δ_e。

**定义 140（健全分解 SCD 与分解间隙 δ_dec）** 分解健全当且仅当：(O1 覆盖) Pre_n ⇒ ∨_{m∈child}Pre_m（AND 顺序）或 OR 的选择可行性；(O2 链式) Post_m ⇒ Pre_{next}（沿执行序）；(O3 预算) AND 时 ε_n ≥ Σ_m ε_m + Σ_e δ_e + δ_dec(n)，OR 时 ε_n ≥ min_m ε_m + δ_sel + δ_dec(n)；(O4 接缝) 每条 S_e 由接缝证据见证。**分解间隙** δ_dec(n)=sup 部署 |P(¬safe_global | 全部子契约成立) −(Σε+Σδ_e)|，即子契约与接缝账本都未覆盖的失效质量；必须**实测**而非假设，且 δ_dec.upper≤δ_dec*。证书 J_dec=(树, 义务清偿日志, 接缝账本, δ_dec 估计+置信区间)。

**定义 141（可复现基线与复现证书 RBR）** 基线 b=(name,ver,F_env,μ_b,CI,seeds,code/hw hash)，F_env=(地形分布, 形态学, 传感器噪声, 种子集, 仿真/硬件版本)。复现：在评估指纹 F_env′ 下重跑 b，在等价边界 Δ_equiv、显著性 α_rep 下做 TOST，报告漂移 d_rep=|μ_b^rep−μ_b|。RepCert=(b,F_env′ 指纹, 复现 CI, TOST 结论, d_rep, 评测者哈希)。声明"M 相对 b 改进 Δ"被**认证**当且仅当 RepCert 有效 ∧ d_env(F_env,F_env′)≤τ_env。

**定义 142（复现出处门 RPG）** 证据/声明进入门须带出处：(P1) 参照基线已复现（RepCert 有效）否则标记为猜想并排除出安全/改进；(P2) 任何被转移的契约 F_env 匹配；(P3) 漂移监控未触发；(P4) 审计链（谁跑、代码哈希、种子）完整。未复现的改进一律降级为猜想，不得抬高 ε 预算或激活任何证据类。

**定义 143（组合复现缓存与复现税 CPR）** 缓存 K: 契约-id → RepCert，以 F_env 指纹哈希为键。仅当 d_env≤τ_env 且再验证样本通过时复用；指纹漂移/代码变更/漂移监控触发即失效。复现税 Rtax(𝒯)=Σ_n c_rep(n)·oblig(n)，oblig(n)∈{现跑,再验证,复用} 由风险权重 w_rep(n)（ε_n、L_n、新颖度 d_env）决定；约束 Rtax≤B_rep，按 VOI_repro 分配。

**定义 144（PCE++ 算子：分解-复现-承诺-演化）** 每检查点：①当前结点契约核对；②若界过松（ε>δ_f）则分解（AND/OR）直至叶子契约可清偿，并行清偿 J_dec；③凡复用基线/契约，校验 RepCert 与指纹，否则复现或降级猜想；④在 {探针, 分解, 复现, 绕行, 协商, 停} 上取 argmax[VOI−cost]（VOI 含 VOI_repro）；⑤契约门过（叶子证据 ∧ 祖先义务 ∧ RepCert）才承诺，否则演化。在探针+分解+复现有界预算内终止。

## 2. 关键算法伪代码（完整版见产物区）

```python
def decompose(task, M, budget):                        # IP-139/140
    if leaf_contract_feasible(task, M): return TaskLeaf(contract(task))
    kids = choose_split(task, M)                       # AND / OR
    tree = TaskNode(type=split_type(task),
                    children=[decompose(c, M, budget) for c in kids])
    tree.seams = build_seam_ledger(kids)               # S_e
    return tree

def certify_decomposition(tree, M):                    # O1–O4 + δ_dec
    for n in postorder(tree):
        if not (coverage_ok(n) and chain_ok(n)
                and budget_ok(n) and seam_witnessed(n)):
            return ('reject', n, first_violation(n))
    d_dec = estimate_gap(tree, M)                      # 实测，不假设
    if d_dec.upper > delta_dec_star:
        return ('reject', 'decomposition_gap', d_dec)
    return ('ok', J_dec(tree, obligation_log, seam_ledger, d_dec))

def reproduce_or_reject(claim, baseline, cache, env):  # IP-141/142/143
    b = baseline[claim.ref]
    if d_env(env.fp, b.F_env) <= tau_env and cache.valid(b, env):
        return ('reproduced', cache.get(b, env))
    rep = rerun(b, env)                                # 计入 Rtax
    if not tost_equivalent(rep, b, margin=Delta_eq, alpha=alpha_rep):
        return ('drift', b, rep)                       # 重新钉住或降级猜想
    cert = RepCert(b, env.fp, rep, evaluator_hash())
    cache.put(b, env, cert); return ('reproduced', cert)

def contract_gate(c, tree, M, personas, baseline, cache):  # IP-144
    leaf = few_shot_evidence_gate(c, M, personas, ood_reg)  # 继承第 57 轮
    if leaf[0] != 'ok': return leaf
    dec = certify_decomposition(tree, M)               # 祖先义务
    if dec[0] != 'ok': return dec
    rep = (reproduce_or_reject(c.claim, baseline, cache, env)
           if c.claim.ref else ('reproduced', None))
    if rep[0] == 'drift': return ('reject', 'unreproduced_baseline', rep)
    return ('ok', J_rhc(dec[1], rep[1], leaf[1]))
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| HCT | O(\|𝒩\|) 构建 | O(\|𝒩\|+\|ℰ\|) | 契约字段完整、接缝显式 |
| SCD | O(\|𝒩\|+\|ℰ\|) 校验；间隙估计 O(N_dec) | O(\|𝒩\|) | O1–O4 全清偿、δ_dec 实测 |
| RBR | O(现跑成本)；缓存查询 O(1) | O(\|基线\|+\|缓存\|) | TOST 有效、指纹诚实 |
| RPG | O(1)/声明 | O(\|审计链\|) | 未复现即降级、审计完备 |
| CPR | O(1) 命中 + 再验证 | O(\|缓存\|) | 指纹失效、税在预算内 |
| PCE++ | O(\|CP\|·(k_p+k_d+k_r)·(C_VOI+d_φ)) | O(\|𝒩\|+\|σ\|) | 三类预算有界终止 |

**正确性定理（Reproducible Hierarchical Contract Soundness, RHCS）**：在 A33–A40（第 56–57 轮）上加 **(A41)** 分解义务 O1–O4 诚实清偿且 δ_dec≤δ_dec*；**(A42)** 环境指纹诚实稳定、TOST 复现有效、漂移检出率 ≥1−δ_drift；**(A43)** 缓存失效健全、Rtax 在预算内；**(A44)** 契约仅可于 d_env≤τ_env 内转移。则：(i) 全局失效 ≤ Σ_叶子(δ_f+ε_meta(k)+δ_probe+ε_h)+Σ_接缝 δ_e+δ_dec+δ_unrepro；(ii) 分解单调性：义务清偿后分解不抬高界，任何降低接口不确定性的切分降低风险，未降低的由 δ_dec 兜住；(iii) 复现健全性：未复现改进不得抬高已承诺 ε，证书链可审计；(iv) PCE++ 在 k_probes+k_dec+k_rep 内终止。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 分解间隙被低估、"局部复现"洗白整体 | 高 | δ_dec 独立测量 + 接缝复现（不只叶子）+ 预算单调性检查 |
| 环境指纹失真/漂移漏检 | 高 | 指纹审计 + TOST + 漂移监控 + 失配即拒 |
| 复现税拖慢研究/部署 | 中 | 风险加权复现义务 + 缓存 + VOI_repro 预算 |
| 复现缓存陈旧复用 | 中 | 指纹哈希失效 + 再验证样本 + 漂移触发清空 |
| 契约门与既有证据门冲突 | 中低 | 契约门向下兼容 FSE，证据类唯一入口不变 |

## 6. 本轮最大风险

**一句话**：本轮把安全与改进的判定权交给两份新的诚实性承诺——契约树的接缝账本 J_dec 与环境指纹 F_env；风险从"坏先验普遍"变成"**分解洗白**"：每个子契约都能被单独复现、单独声称局部健全，而真正决定全局的接缝误差 δ_dec 与指纹失配恰恰是最难测量、最容易被低估的两项，于是复现证书会为未被检验的整体提供虚假信心；必须以接缝复现（而非仅叶子复现）、δ_dec 的独立测量、F_env 失配即拒三重护栏，宁可把"已复现"降级为"仅局部复现"，也不让证书替接缝背书。

# 第 58 轮产物 · 创新点清单 v34：ReproDecomp（可复现任务分解：分层契约×接缝账本×基线复现，HCT×SCD×RBR×RPG×CPR×PCE++）

### IP-140 SCD（健全分解 + 分解间隙证书）

```python
def decompose(task, M, budget):
    if leaf_contract_feasible(task, M):     # 界足够紧、证据可负担
        return make_leaf(task, M)
    kind, kids = choose_split(task, M)      # kind ∈ {AND, OR}
    node = TaskNode(kind=kind,
                    children=[decompose(c, M, budget) for c in kids])
    node.seam_ledger = [seam_condition(a, b) for a, b in sequence(kids)]
    return node

def certify_decomposition(tree, M):
    for n in postorder(tree):               # O1 覆盖
        if not implies(n.pre, disj(c.pre for c in n.children)):
            return ('reject', n, 'O1_coverage')
    for n in postorder(tree):               # O2 链式（AND）
        if n.kind == 'AND':
            for a, b in sequence(n.children):
                if not implies(a.post, b.pre):
                    return ('reject', a, 'O2_chain_gap')
    for n in postorder(tree):               # O3 预算（并集界）
        need = (sum(c.eps for c in n.children)
                + sum(e.delta for e in n.seam_ledger)
                + estimate_gap(n, M))
        if n.contract.eps < need:
            return ('reject', n, 'O3_budget', need)
    for n in postorder(tree):               # O4 接缝见证
        for e in n.seam_ledger:
            if not seam_witnessed(e, M):
                return ('reject', e, 'O4_unwitnessed_seam')
    d = estimate_gap(tree.root, M)          # 实测分解间隙（含 CI）
    if d.upper > delta_dec_star:
        return ('reject', 'decomposition_gap', d)
    return ('ok', J_dec(tree, obligation_log, seam_ledger, d))

def estimate_gap(n, M):
    # 不假设局部健全蕴含全局健全：在接缝上做定向扰动
    local = simulate_child_contracts(n, M)
    glob = simulate_composed(n, M, perturb_seams=True)
    resid = max(0.0, glob.fail - local.fail - n.eps_accounted)
    return bootstrap_ci(resid, n_rep=200)
```

### IP-141 RBR（可复现基线注册表 + 复现证书）

```python
def fingerprint(env):
    return Hash(terrain_dist=env.T, morphology=env.robot,
                noise=env.sensor_noise, seeds=env.seeds,
                sim_version=env.sim_ver, hw=env.hw_rev)

def reproduce(b, env):                      # 钉住基线在评估指纹下重跑
    assert fingerprint(env) == env.fp
    runs = [run(b.code, b.seeds, env) for _ in b.seeds]
    mu = mean(m.kpi for m in runs); ci = bootstrap(runs)
    drift = abs(mu - b.mu)
    tost = tost_equivalent(mu, b.mu, margin=Delta_equiv, alpha=alpha_rep)
    return RepCert(b=b, fp=env.fp, mu=mu, ci=ci,
                   tost=tost, drift=drift, evaluator=hash_of(env.runner))

def drift_monitor(registry, env_stream):
    for b in registry:
        if recent_drift(b, env_stream) > tau_drift:
            registry.flag(b, 'DRIFT'); invalidate_cache_for(b)
```

### IP-142 RPG（复现出处门）

```python
def provenance_check(claim, baseline, cache, env):
    if claim.ref is None:                   # 无参照：内部对比，走内部复现
        return ('ok', None)
    b = baseline[claim.ref]
    if d_env(env.fp, b.F_env) > tau_env:
        return ('reject', 'fingerprint_mismatch', b)   # 失配即拒
    cert = cache.get(b, env) or reproduce(b, env)
    if not cert.tost or cert.drift > tau_drift:
        return ('downgrade', 'conjecture', cert)        # 改进降级为猜想
    if not audit_chain_complete(cert):
        return ('reject', 'audit_incomplete', cert)
    return ('ok', cert)
```

### IP-143 CPR（组合复现缓存 + 复现税）

```python
def oblig(n, env):                          # 风险加权复现义务
    risk = w_eps(n.eps) + w_level(n.level) + w_novelty(d_env(env.fp, n.fp))
    return 'fresh' if risk >= r_hi else ('revalidate' if risk >= r_lo else 'reuse')

def revalidate(cert, env, sample=8):
    runs = [run_reduced(env, seed) for seed in first(env.seeds, sample)]
    return tost_equivalent(mean(runs), cert.mu, margin=Delta_eq, alpha=alpha_rep)

def allocate_reproduction(tree, B_rep, env):
    items = [(n, voI_repro(n, tree, env)) for n in nodes(tree)]
    items.sort(key=lambda x: -x[1])
    plan, spent = [], 0.0
    for n, v in items:
        c = cost_rep(n, oblig(n, env))
        if v <= 0 or spent + c > B_rep: continue
        plan.append((n, oblig(n, env))); spent += c
    return plan, spent                      # Rtax = spent ≤ B_rep
```

### IP-144 PCE++（分解-复现-承诺-演化）

```python
def pce_plus_plus(x0, task, M, budget, consent, personas, baseline, cache, env):
    tree = build_contract_tree(task, M, budget)
    for cp in plan_on_contracts(tree):
        cp.done = set()
        for _ in range(budget.per_cp):
            acts = ['probe', 'decompose', 'reproduce', 'reroute', 'negotiate', 'stop']
            a = argmax(acts, key=lambda z: voi(z, tree, cp, M, baseline) - cost(z))
            if voi(a, tree, cp, M, baseline) < theta_voi:
                break
            if a == 'probe':
                M, _, D = xmodal_fuse(M, cp.region, execute_probe(best_probe(cp, M), F_abs))
            elif a == 'decompose':
                tree = refine(tree, cp, M)                  # 产生更紧的子契约
                tree_cert = certify_decomposition(tree, M)
            elif a == 'reproduce':
                reproduce_or_reject(cp.claim, baseline, cache, env)
                budget.spend_rep(cost_rep(cp, env))
            elif a == 'reroute':
                tree = reroute_on_contracts(tree, cp, M)
            elif a in ('negotiate', 'stop'):
                return negotiate_or_stop(cp, tree, M, consent,
                                         tau_int=tau_int(personas.active.auth))
        leaf = contract_gate(core_contact(cp), tree, M, personas, baseline, cache)
        if leaf[0] == 'ok':
            commit(core_contact(cp)); continue
        if leaf[1] == 'unreproduced_baseline':
            continue                                        # 复现后才可能承诺
        return negotiate_or_stop(cp, tree, M, consent,
                                 tau_int=tau_int(personas.active.auth))
    return tree
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| HCT | O(\|𝒩\|) 构建 | O(\|𝒩\|+\|ℰ\|) | 结点契约完整、接缝显式（A41） |
| SCD | O(\|𝒩\|+\|ℰ\|)；间隙 O(N_dec·n_rep) | O(\|𝒩\|) | O1–O4 全清偿、δ_dec 实测（A41） |
| RBR | O(复现成本)；查询 O(1) | O(\|基线\|) | TOST 有效、指纹诚实（A42） |
| RPG | O(1)/声明 | O(\|审计链\|) | 未复现降级、失配即拒（A42） |
| CPR | O(1) 命中 + O(样本) 再验证 | O(\|缓存\|) | 指纹失效、Rtax≤B_rep（A43） |
| PCE++ | O(\|CP\|·(k_p+k_d+k_r)·(C_VOI+d_φ)) | O(\|𝒩\|+\|σ\|) | 三类预算有界终止 |

**正确性定理（Reproducible Hierarchical Contract Soundness, RHCS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 分解义务 O1–O4 诚实清偿且 δ_dec≤δ_dec*，接缝账本完整；**(A42)** 环境指纹诚实稳定、TOST 复现有效、漂移检出率 ≥1−δ_drift、指纹失配即拒；**(A43)** 缓存失效健全（漂移/代码变更即失效）、Rtax≤B_rep；**(A44)** 契约仅可于 d_env≤τ_env 内转移，超出即重跑。则：

1. **全局失效界**（分解后对叶子与接缝取联合界）：
```
P(fail_global) ≤ Σ_leaf (δ_f + ε_meta(k) + δ_probe + ε_h + δ_xm·1[L1])
                + Σ_seam δ_e + δ_dec + δ_unrepro
```
其中 δ_unrepro 为"已过复现门但基线实为失配"的残余，受 δ_drift 与 τ_env 约束。
2. **分解单调性**：义务清偿后，任一切分不抬高上界；若子契约降低接口不确定性则严格降低风险，未降低的部分由 δ_dec 显式兜底——**分解不能无代价地把风险藏进接缝**。
3. **复现健全性**：未持有有效 RepCert 的改进只能以猜想存在，不得抬高任何已承诺 ε、不得激活证据类；证书链（基线指纹/种子/代码哈希/评测者）可审计、可重放。
4. **终止性**：每检查点探针 ≤k_p、分解 ≤k_dec、复现 ≤k_r，PCE++ 在 k_p+k_dec+k_r 内终止于 {承诺, 绕行, L2 协商, 安全停}。

**关键**：**分解给可核验性、复现给可信性**（切小与重跑是同一枚硬币两面）；**δ_dec 是分解的"诚实税"，δ_drift 是复现的"诚实税"**（两税都显式入账，不许隐去）；**契约门 = 叶子证据 ∧ 祖先义务 ∧ 复现证书**，任一缺失即降级——证书永远替接缝背书，而不是替整体背书。

## 6. 本轮最大风险

**一句话**：本轮把安全与改进的判定权交给两份新的诚实性承诺——契约树的接缝账本 J_dec 与环境指纹 F_env，风险从"坏先验普遍"变为"**分解洗白**"：每个子契约都能被单独复现、单独声称局部健全，而真正决定全局的接缝误差 δ_dec 与指纹失配恰恰是最难测量、最容易被低估的两项，于是复现证书会为未被检验的整体提供虚假信心；必须以接缝复现（而非仅叶子复现）、δ_dec 的独立测量、F_env 失配即拒三重护栏，宁可把"已复现"降级为"仅局部复现"，也不让证书替接缝背书。
