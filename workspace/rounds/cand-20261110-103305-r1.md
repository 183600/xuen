# 第 43 轮（新循环第 1 轮） · RC³：角色一致闭环认证 —— 给 Sim-Cert-RAG 飞轮装上「稳定性」与「角色契约」双保险（四层 + 角色控制平面 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR）。第 42 轮自陈最大风险是「仿真偏差累积 + 检索幻觉」：飞轮可能在各模块都"自信满满"时静默失效。本轮灵感词「闭环控制」「角色一致性」恰是这对风险的对偶解药。**闭环控制**把飞轮从"经验上转得动"升级为"可证明稳定地转"——把每轮更新看成控制作用，把仿真偏差、量化误差、检索噪声看成扰动，用环增益、收缩性、小增益定理、延迟裕度与抗积分饱和回答三个此前没问的问题：飞轮会振荡吗？会发散吗？长时滞（人审+仿真重跑）会失稳吗？**角色一致性**把闭环中的每个模块（感知 VLM、规划器、边缘监控、云端证书器、RAG 合成器、人类复核）视为承担明确**角色契约**的 agent，用会话类型与假设-保证契约约束"谁在什么阶段只能说什么、保证什么"，从根上把"检索幻觉"从概率问题变成契约违规问题。二者耦合得到本轮主命题：**一个闭环认证系统是安全的，当且仅当它在角色一致的模式切换下仍保持证书误差收缩**——角色一致性提供"模式良定义与切换合法性"，闭环控制提供"模式内与切换间的收敛性"。这不是两个新 IP 的叠加，而是把前 42 轮的"证书栈"重构为"证书控制系统"。

## 0. 直觉与动机

**灵感 1（闭环控制 → 飞轮是被控对象，必须证明稳定性而不能只靠实测）**：第 42 轮的 Sim→RAG→Edge→Sim 本质是一个离散时间反馈系统：被控量是证书误差 e_t = m_true − m_cert（正=过于保守、负=过估即不安全），控制量是每轮的阈值/模板/量化更新 u_t，扰动 d_t 来自仿真偏差、INT8 舍入与检索噪声。没有整定的反馈环有三种典型病症，第 42 轮全都可能犯：**振荡**（阈值在 Sim 与实机之间来回追，Nominal 占比锯齿）；**发散**（一次 RAG 幻觉被下轮仿真"确认"并放大，误差越滚越大）；**时滞失稳**（人审 10 分钟 + 仿真重跑 30 分钟，长时滞把负反馈拖成过冲）。闭环控制的直觉是把它当伺服系统整定：用比例增益 a_t + 每轮阈值变更限幅 Δθ_max 做"过阻尼"；用李雅普诺夫/收缩性证明 V(e) 每轮按 ρ<1 衰减到有界球；用延迟裕度 τ_max 约束"人多快确认、仿真多快重跑"；用抗积分饱和防止阈值单方向 windup。稳定不是实验结论，而是**可审计的证书 (ρ, δ, τ_max)**。

**灵感 2（角色一致性 → 闭环里每个 agent 都要"守住人设"，否则被控对象中途换了个"人"）**：闭环里六类角色各说各话：VLM 说"我看到障碍在左"、规划器说"我生成绕行轨迹"、边缘监控说"边际 m=0.7"、云端证书器说"我认证 m≥0.9"、RAG 说"我检索到相似任务模板"、人类说"我确认"。角色不一致有两类灾难：**横向**——RAG 检索到"角色不符"的模板（导航模板被套到抓取任务，两者守卫语义根本不同）却因嵌入相似而高置信合并；**纵向**——VLM 在长时程对话中发生角色漂移（从"只做感知描述"漂移成"越权下指令"），输出不再满足其角色契约。直觉解法：把角色写成四元契约 Role=(A 输入假设, G 输出保证, I 不变式, Π 交互协议)，用多参与方会话类型（MPST）做协议符合性、用假设-保证（assume-guarantee）蕴含做契约组合、用 SMT 检查 G_i ⊆ A_j。角色一致性把"这个模板能不能用"降维成"这两条契约是否蕴含"，可判定、可审计。

**灵感 3（二者耦合 → 角色切换就是模式切换，用驻留时间同时锁住两件事）**：第 42 轮没意识到"换角色"本身是控制事件：从导航模式切到抓取模式，旧角色的保证必须蕴含新角色的假设（否则交接瞬间证书作废），而且要停留足够久（否则频繁切换积分器尚未收敛）。这正是**切换系统**理论：为每个角色配一个李雅普诺夫函数 V_r，要求模式内 ë 收缩（ρ_r<1）、切换点 V_{r'} ≤ η·V_r（η≥1 的切换冲击有界）、平均驻留时间 ≥ τ_d。于是「角色一致性」和「闭环稳定性」在同一套数学里合流：**契约蕴含保证切换不产生证书跳变，驻留时间保证切换后误差来得及收缩**。这把第 42 轮的"SimValidated 标记"细化为"角色契约 + 模式驻留"的可运行证明。

**与第 42 轮的差异**：v19 回答"飞轮能不能转（功能）"，v20 回答"飞轮敢不敢一直转（稳定 + 合规）"。新增 IP-57/58/59/60，不推翻 SCV/CKB/ECR，而是在其上叠加一个纵贯的**角色控制平面（RCP）**。

## 1. 形式化定义（增量：定义 38–45）

**定义 38（角色与角色契约）**：角色 r = (id_r, A_r, G_r, I_r, Π_r)。A_r 为输入假设集（前置条件/可接受的输入保证），G_r 为输出保证集（后置条件），I_r 为跨步不变式，Π_r 为与其他角色交互的协议——用多参与方会话类型（MPST）表示，如 μX.(!m·τ; ?n·σ; X)。**角色细化** r ⊑ r' 表示在不违反 r' 契约的前提下 r 可替代 r'（A_r ⇒ A_{r'} 且 G_r ⇒ G_{r'}）。角色是"带协议的行为类型"，不是自由文本 prompt。

**定义 39（角色一致闭环系统 RC-loop）**：S = ⟨R, E, Φ, Σ⟩。R 为角色集合；E 为契约依赖边（异步组合）；Φ 为假设-保证满足关系：∀(i→j)∈E, G_i ⊆ A_j；Σ 为模式切换信号（由 Π 决定哪些切换合法）。一次运行**角色一致**，当且仅当：(a) 每条总线消息满足当前活跃角色对的会话类型；(b) 每次切换 r→r' 满足 G_r ⊆ A_{r'} 且驻留时间 ≥ τ_d；(c) 所有不变式在切换前后成立。即"角色一致性 = 协议符合性 + 假设保证蕴含 + 驻留合法性"三者同时成立。

**定义 40（角色增益、一致性裕度与切换冲击）**：角色 r 的**增益** γ_r = sup_{δx∈A_r} ‖G_r(x+δx) − G_r(x)‖/‖δx‖（其保证映射的 Lipschitz 常数）。**一致性裕度** μ_r = dist(A_r, ¬G_r)，即假设集到"保证被违背"集合的距离（裕度越大越鲁棒）。**切换冲击** b_{rr'} = sup_x ‖G_{r'}(x) − G_r(x)‖，刻画交接时保证的不连续度。角色一致性强 ⟺ b_{rr'} 小且 τ_d 足够大。

**定义 41（证书误差动态、收缩性与有界误差稳定）**：令 e_t = m_true − m_cert ∈ R^d。闭环更新写成 e_{t+1} = F(e_t, u_t) + d_t，u_t 为更新控制量，d_t 为有界扰动（仿真偏差+量化+检索噪声），‖d_t‖ ≤ δ。若存在 P≻0、ρ∈(0,1) 使 F^T P F ⪯ ρ² P，则 V(e)=eᵀPe 满足 ‖e_t‖ ≤ ρ^t‖e_0‖ + δ/(1−ρ)。**定理（闭环证书稳定）**：ρ<1 ⟹ 误差指数收敛到半径 δ/(1−ρ) 的球（BIBO 有界稳定），且存在有限 T(ε)，使 t≥T 后 ‖e_t‖ ≤ δ/(1−ρ)+ε。ρ 称为**收缩率**，1/(1−ρ) 称为**误差放大因子**。

**定义 42（级联环增益、延迟裕度与小增益判据）**：级联角色 r_1→…→r_k 的**环路增益** L = ∏_i γ_i。计入环内总时滞 τ = τ_sim + τ_human + τ_comm，连续时间小增益要求 L·e^{λτ} < 1（λ 为扰动增长率的界），离散时间要求 L < 1 且相位裕度 φ_m ≥ φ_min。**延迟裕度** τ_max = max{τ : L·e^{λτ} < 1}。角色的驻留时间 τ_d 与每轮限幅 Δθ_max 是压低 L 的两个物理旋钮：驻留让积分器收敛，限幅让单轮冲击有界。

**定义 43（角色一致检索与跨角色迁移）**：检索器 R_role(φ, ψ, r) 只在角色签名兼容子集 KB_r = {i : role(C_i) ⊑ r} 上检索，打分 s = λ₁·sim(φ,φ_i) + λ₂·sim(ψ,ψ_i) + λ₃·role_match(r,r_i)，其中 role_match 作为**硬门槛**（低于 ρ_min 直接不可选）而非软加分。跨角色迁移 i→r 仅当存在显式角色适配算子 T_{i→r}，且 T_{i→r}(C_i).G ⊆ A_r 经 SMT 再验证成立；否则拒绝并记入"角色幻觉"反例集。**角色幻觉** = 把不相容角色模板以高相似度合并。

**定义 44（角色漂移与角色共识）**：对 LLM/VLM 角色 r，行为嵌入 z_t 相对参考分布 P_r^ref 的漂移 D_t = MMD(z_t, P_r^ref)，用 CUSUM 累积 s_t = max(0, s_{t−1} + D_t − k) 检测，s_t > h 报警。多验证者 V={edge, cloud, human} 的**角色共识**：同一时刻活跃角色估计须多数一致；分歧即触发 SAFE_HOLD。单点角色漂移不得改变全局活跃角色。

**定义 45（闭环控制成本与安全-可用前沿）**：COT_loop = COT + C_stab·1/(1−ρ) + C_switch·N_switch + C_delay·τ。其中 C_stab 是稳定性维护成本（辨识、限幅、证书求解），N_switch 为角色切换次数，C_delay 为时滞占用成本。可用性 Nominal 占比是 (ρ, Δθ_max, τ_d) 的单调函数：ρ 越小越安全但越保守，Δθ_max 越大越敏捷但越易振荡。**安全-可用 Pareto 前沿**在 (COT_loop, 安全违例率, Nominal 占比) 三维空间显式给出，而不是隐含在实验里。

## 2. 四大产出设计（新增 IP-57/58/59/60 + 升级既有）

### 2.1 IP-57 ROLE-CONTRACT ENGINE（角色契约引擎 RCE）
1. **角色注册表**：六类角色签名（Perceiver-VLM、Planner、Guard/Verifier、Explainer、Synthesizer、Human），显式声明 A/G/I/Π；Π 用 MPST 语法写死"允许的消息序列"。
2. **契约编译器**：把假设-保证边与会话类型编译成运行时 monitor，挂在 IP-45 总线每个 topic；消息携带 (role_tag, protocol_step, guarantee_witness)，monitor 逐消息做协议步进与契约断言。
3. **组合检查**：新技能组合前自动做 G_i ⊆ A_j 的蕴含检查（SMT/区间算术），任一依赖边失败即拒绝组合；组合结果生成"角色依赖图"存档。
4. **角色切换事务**：handoff 视为原子事务——旧角色后置 G_old 必须满足新角色前置 A_new，且驻留计时器 ≥ τ_d 才提交；不满足则保持旧角色（安全但保守），避免"半切换"态。

### 2.2 IP-58 LOOP-STABILITY CERTIFIER（闭环稳定证书器 LSC）
1. **在线系统辨识**：从飞轮日志用最小二乘/Kalman 辨识误差转移映射 Â 与环增益 γ̂，滚动估计谱半径；分布偏移时用带遗忘因子的递推辨识跟踪增益漂移。
2. **收缩性证书**：线性部分解 LMI A^T P A − ρ²P ≺ 0 求 (P, ρ)；非线性用数据驱动 Lipschitz + SoS 松弛；输出可审计证书 (ρ̂, δ̂, τ_max, 数据窗口哈希)。
3. **整定与限幅**：自动调 Δθ_max、更新增益 a_t（衰减/漏积分），做抗 windup（阈值上下限 + 泄漏）；这是"过阻尼整定"的工程实现。
4. **冻结断路器**：若 γ̂ ≥ 1、或 ρ̂ 连续 k 轮不降、或检测到时滞超过 τ_max，则 LOOP_FREEZE——锁定最近一次已认证版本、回退、转人工。**这是把第 42 轮"静默失效"显式化的安全控制器**：宁可误冻结，不可假收敛。

### 2.3 IP-59 ROLE-CONSISTENT CKB（角色一致知识库 RC-CKB）
1. **角色索引**：KB 记录增加 role 签名与协议字段，HNSW 按角色建子图，检索时先定位角色子图再近邻搜索。
2. **角色条件检索 + 重排**：role_match 作为硬门槛 + λ₃ 软打分；重排器额外校验模板前提是否落在当前角色假设内。
3. **跨角色适配**：显式 T_{i→r} 算子 + 再验证门；失败即隔离为角色幻觉反例，供后续对比学习当负样本。
4. **一致性审计**：合并前检查不变式不冲突、假设被上游保证覆盖；输出人类可读的"角色兼容性报告 + 差异集 Δ"。

### 2.4 IP-60 ROLE-DRIFT MONITOR（角色漂移监控 RDM）
1. **参考行为建模**：为每个 LLM/VLM 角色建参考行为嵌入分布（离线采集合规样本）。
2. **漂移检测**：CUSUM/SPRT 检测 MMD 漂移，报警延迟与误报率可调，绑定角色契约版本。
3. **角色再锚定**：漂移报警 → 重提示/角色重锚/降级到只读安全角色（例如 VLM 只剩"描述"权、失去"下指令"权）。
4. **角色共识**：edge/cloud/human 三票，2-of-3 才改变活跃角色；分歧 → SAFE_HOLD + 降速，而非静默选一个。

## 3. 四层架构 v8（四层 + 纵贯角色控制平面 RCP）

    → 输出：活跃角色、契约违规告警、稳定性证明 (ρ,δ,τ_max)、冻结/回退指令

L3: IP-51 CAR(role-guard + Δθ_max 限幅) ← IP-56 ECR(L0查表 + L1 INT8 + 偏移监控)
    → IP-47 乘积模板检索组合(契约蕴含证明) → IP-39 规划(CBF margin=查表 m_lo)

    → IP-58 LSC(闭环收缩证书) → IP-44 蒸馏(QAT→INT8) + IP-50 课程(角色相位序列)
    → RCA 重颁证书(含有效区间 + 角色 + 稳定性元数据) → 契约热更新(受 Δθ_max 与驻留约束)
运行期：L0查表(5μs) + T-Role 契约检查(10μs) + L1 INT8监控(100μs) + 角色/漂移/增益监控
    → 任一红线触发(契约违规/环增益≥1/漂移/时滞超裕度) → LOOP_FREEZE + 回退已认证版本
```

## 5. 本轮最大风险

**一句话**：本方案把安全押在「环增益可在线辨识」上——一旦分布偏移使真实增益越过 1 而 LSC 的辨识模型滞后，系统会误判"仍在收敛"并继续更新，形成比第 42 轮更隐蔽的「假稳定」失效；因此 E88（收缩性实测）、E89（延迟裕度）、E92（发散断路器）必须作为红线，任何一项不达标即冻结飞轮、回退到已验证的静态证书。

### IP-57 RCE：角色契约编译与一致性检查

Role = (id, A, G, I, Pi)   # A: 假设, G: 保证, I: 不变式, Pi: MPST 协议

def check_role_consistency(R, edges, switches, dwell, tau_d):
    # (a) 假设-保证蕴含：上游保证必须覆盖下游假设
    for (i, j) in edges:
        if not implies(G[i], A[j]):        # SMT / 区间算术
            return False, f"contract_gap {i}->{j}"
    # (b) 切换合法性 + 冲击有界
    for (r, r2) in switches:
        if not implies(G[r], A[r2]):
            return False, f"illegal_handoff {r}->{r2}"
        if dwell[r2] < tau_d:
            return False, f"dwell_violation {r2}"
        if b_switch(r, r2) > B_MAX:
            return False, f"switch_impact {r}->{r2}"
    return True, "role_consistent"

def compile_mpst_monitor(Pi):
    # 把会话类型编译为运行时状态机（协议步进）
    sm = automaton_from_session_type(Pi)
    def monitor(msg):                     # msg=(role_tag, label, step, witness)
        return sm.step(msg.role_tag, msg.label) is not None
    return monitor

def handoff_transaction(r_old, r_new, state, dwell):
    if not implies(G[r_old], A[r_new]): return state, r_old   # 保持旧角色
    if dwell[r_new] < tau_d:           return state, r_old
    return execute_handoff(state, r_old, r_new), r_new
```

### IP-58 LSC：闭环辨识、收缩证书与冻结断路器
```
def identify_loop(logs, forget=0.98):
    # 递推最小二乘辨识 e_{t+1} = A e_t + B u_t + d
    A_hat, B_hat, resid = rls_identify(logs, forget)
    rho_hat   = spectral_radius(A_hat)
    gamma_hat = norm(A_hat, 2)                  # 环增益上界
    delta_hat = quantile(resid, 0.99)           # 扰动界
    return A_hat, rho_hat, gamma_hat, delta_hat

def certify_contraction(A_hat, rho_target=0.8):
    # LMI: 求 P>0 使 A^T P A - rho^2 P < 0
    P = solve_lmi(A_hat, rho_target)
    if P is None: return None                   # 无法证明 -> 不得放行
    rho = sqrt(max_eigval(inv(diag(P)) @ (A_hat.T @ P @ A_hat)))
    return Certificate(rho=rho, P=P, window_hash=hash_window())

def tune_and_limit(dtheta, dtheta_max, leak=0.1):
    dtheta = clip(dtheta, -dtheta_max, dtheta_max)   # 限幅
    dtheta = dtheta - leak * dtheta                  # 漏积分抗 windup
    return dtheta

def delay_margin(gamma_hat, lam=1.0):
    return float('inf') if gamma_hat <= 0 else 1.0/gamma_hat  # 再解 L*e^{lam*tau}<1

def supervise(e_hist, cert, gamma_hat, tau, tau_max):
    if cert is None:                       return 'FREEZE_AND_ROLLBACK'
    if gamma_hat >= 1.0:                   return 'FREEZE_AND_ROLLBACK'
    if not decreasing(e_hist, k=3):        return 'FREEZE_AND_ROLLBACK'
    if tau > tau_max:                      return 'FREEZE_AND_ROLLBACK'
    return 'CONTINUE'
```

| 角色漂移检测语义盲区：行为看似合规但意图漂移 | 中-高 | 多探针（日志/动作/语言）+ 三票共识；CUSUM + 定期人工抽查 |

| 切换冲击大：驻留过短导致积分器未收敛 | 中 | 平均驻留时间约束 + 切换冲击 b_{rr'} 上界；E89 振荡门槛 |
| 契约组合状态爆炸：组合技能角色数指数增长 | 中 | 假设-保证分解 + 分层组合 + 模板缓存；只对活跃接口做动态 monitor |
| 断路器抖动：误冻结损伤可用性 | 低-中 | 触发冷却期；分级冻结（先降级再冻结）；人工快速恢复通道 |

## 6. 本轮最大风险

**一句话**：本方案把安全押在「环增益可在线辨识」上——一旦分布偏移使真实增益越过 1 而 LSC 的辨识模型滞后，系统会误判"仍在收敛"并继续更新，形成比第 42 轮更隐蔽的「假稳定」失效；因此 E88（收缩性实测）、E89（延迟裕度）、E92（发散断路器）必须作为红线，任何一项不达标即冻结飞轮、回退到已验证的静态证书。
