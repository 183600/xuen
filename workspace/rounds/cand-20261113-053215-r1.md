# 第 1 轮（灵感循环 v3：「本体感知」×「抓取」）—— 把计分步里的「抓住」变成可测量的物理事件

> **本轮不是推倒 v2，而是给 v2 补上「触觉之外的那只眼」。** v2 的旗舰 UIP-01′ 用视觉/几何验证器判断子目标是否 `done/regressed`，但它有两个硬伤：① 手挡住物体时视觉看不见；② 视觉看不出「手到底有没有真的夹住」。本轮两个灵感词恰好指向一个**免费、稠密、低延迟、单模型合规**的通道——**本体感知（关节位置、夹爪开度、末端位姿）**；而「抓取」正是 32 个任务里出现频率最高的原子技能，甚至**直接写在计分步里**（T10「抓住插排/抓住插头」、T12「抓起锁」、T16「抓住左边/右边」）。一句话：**抓取不是达成手段，它本身就是分数。**

## 1. 直觉解释（先讲人话）

闭眼去握一个杯子，你怎么知道握住了？不是靠看，而是靠三件事：

1. **合不拢**：手指被杯壁挡住，闭合量停在杯子的宽度上；
2. **拎得动**：抬手时手臂没有「空落落」的感觉，关节跟踪误差变小/负载感出现；
3. **滑不滑**：杯子往下出溜时，手指会被动地继续合拢，或需要更大的力。

机器人也有这套「本体感觉」，只是它是**极简版**：每个手臂 7 个关节角、每个夹爪 1 个开度、一个末端位姿。没有力传感器，但它仍然保留了最关键的一条信息——**命令它闭合，它到底合到了多少**。

- 命令闭合到 0，实测停在 2.0 cm：**中间有东西**（或卡住）。
- 命令闭合到 0，实测也到 0：**空夹**。
- 刚才停在 2.0 cm，抬臂后开度掉到 0.5 cm：**东西在滑 / 已经掉了**。
- 开度一直是 6.0 cm，怎么都合不下去，抬臂还特别费劲：**卡死/撞到环境**，不是「握住了」。

所以本轮的核心直觉只有一句：**「抓取」在位置通道里留下的不是一张图，而是一段「命令—实测」的差分成败签名；把它做成带记忆的状态机，就能免费地判断抓没抓住、掉没掉、卡没卡。**

## 2. 严谨定义（再把话说死）

### 2.1 准本体感知向量

在每个控制步 `t`，接口可观测的本体量为

```
p_t = [ q_t (14) , g_t (2) , x_t (12) , b_t (15) ]  ∈ R^43
q_t : 左右臂关节角 (各7)
g_t : 左右夹爪开度 (各1，5.5=张开，0=闭合)
x_t : 左右末端位姿 xyz+rpy (各6)
b_t : lower_body (15)
```

可用 `obs_delta_indices` 堆叠历史帧，免费得到差分：

```
Δq_t = q_t − q_{t−1},  Δg_t = g_t − g_{t−1},  Δx_t = x_t − x_{t−1}
```

### 2.2 两个核心残差

设上一步下发的夹爪命令为 `g^cmd_t`、手臂目标为 `q^cmd_t`。

**闭合亏欠（closure deficit）**：

```
δ_t = max(0, g_t − g^cmd_t)
```

含义：命令闭合时，实测开度比命令「多出来」的部分，就是物体挡住夹爪的宽度。满载时稳态 `g_t → w`（物体宽度），故 `δ_t → w − g^cmd_t`；若 `g^cmd_t≈0`，则 `δ_t ≈ w`。**δ 是一个零成本的「指间有物」传感器。**

**跟踪残差（tracking residual）**：

```
r^q_t = q_t − q^cmd_t          （关节空间）
r^x_t = x_t ⊖ x^cmd_t          （末端平移/姿态误差）
```

含义：负载、接触、卡阻会让实际关节追不上目标。没有力矩时，`r` 是「费力程度」的代理量，但会被控制器刚度、重力、摩擦混淆——这正是「准」而非「真」本体感知的原因。

### 2.3 抓取相位状态机

定义抓取相位

```
G_t ∈ { OPEN, APPROACH, CLOSING, CONTACT, HOLD, SLIP, JAM, LOST, RELEASE }
```

转移（阈值按任务校准）：

```
OPEN/APPROACH --(g^cmd 开始下降)--> CLOSING
CLOSING --(δ_t > θ_c 且 Δg_t < 0)--> CONTACT
CONTACT/CLOSING --(δ_t > θ_h 且 |Δg_t| < θ_s 连续 n 步)--> HOLD
HOLD --(Δg_t < −θ_slip 连续 m 步 且 δ_t > θ_c)--> SLIP
HOLD/CONTACT --(δ_t 从 >θ_h 跌到 <θ_l)--> LOST      # 曾经握住，现在没了
HOLD --(主动探测残差 > θ_j)--> JAM
任意 --(g^cmd 上升)--> RELEASE
```

关键点：`SLIP` 与 `LOST` **不可能**由单帧阈值稳定判出，因为它们本质是「曾经 δ 高、后来 δ 低」的**时序事件**；必须有记忆。本文第 8 节的合成实验会把这一点量化。

### 2.4 本体动力学残差（PDR）

在公开数据上自监督训练一个前向模型

```
f_θ : (p_t, a_t) ↦ p_{t+1}
e_{t+1} = || p_{t+1} − f_θ(p_t, a_t) ||_2
```

对 `e_t` 做 CUSUM/变点检测。**外部人类干扰**（把物体从手里拿走、挪底座、推手臂）会造成机器人状态的非预期跳变，`e_t` 出现尖峰。注意边界：**当人的动作没有接触机器人/被持物体时，本体感知看不到**（例如机器人手离开后，人偷偷把拉链拉开）——此时必须靠视觉，不能神话本体感知。

### 2.5 抓取事件与抓取位姿记忆

从公开数据自动抽取抓取事件三元组：

```
t_g = 夹爪命令由开到闭的 onset
t_c = t_g 之后首个 δ_t > θ_c 的时刻（接触）
t_l = t_c 之后首个 Δz_ee > θ_lift 的时刻（抬起）
事件 E = ( language, x_{t_c}, ŵ = g_{t_c}, 接近方向 u = normalize(x_{t_c} − x_{t_c−k}), 腕部图像嵌入 )
```

建立**抓取位姿记忆** `M = {E_i}`；对未见物体，用「语言嵌入 + 估计宽度 ŵ' + 接近方向」检索最近邻，输出抓取位姿先验。这直接对应泛化轴 `unseen_object_*`。

## 3. 本轮的关键洞察

1. **I1（免费接触传感器）**：`δ = g − g^cmd` 把「指间有物」变成一个无需额外传感器、无需额外带宽的标量。夹爪单通道反而使它干净：没有多指关节的歧义。
2. **I2（记忆 > 阈值）**：SLIP/LOST 是时序事件。合成实验中，逐帧阈值法的 SLIP 召回只有 **1.3%**；带记忆状态机升到 **92.4%**，总准确率 61.5%→84.8%。
3. **I3（主动探测解卡阻）**：纯被动位置通道**分不清「握住」与「卡死」**（JAM 召回仅 47.0%，大量被判成 HOLD）；在安全方向上加一次 ±5 mm 微抖动、比较跟踪残差，JAM 召回升到 **97.7%**，总准确率 **97.2%**。主动探测是「本体感知的触觉化」。
4. **I4（堆叠本体几乎免费）**：接口一帧图像 480×640×3；一帧本体 43 个 float。堆 4 帧本体 ≈ 688 B，只有一张 JPEG 的约 1–2%。因此「多堆本体帧换差分信息」在实时性上几乎无代价，真正贵的仍是图像与 `get_action` 往返次数。

---

## 4. 与 v2 的关系（升级，不是重来）

- **UIP-01′（滚动验证-重做）**：验证器改为**双通道**——视觉答「是什么/到哪了」，本体答「手到底有没有拿住」。`regressed` 的触发新增 `SLIP/LOST` 两个物理分支。
- **UIP-09′（扰动撤回检测）**：PDR 能抓「接触式撤回」（拿走手里物体、挪底座、推手臂），但抓不到「非接触式撤回」（手离开后偷偷拉开拉链）。边界写清，避免过度承诺。
- **UIP-12（扰动-恢复数据工厂）**：不再需要新传感器，只需在仿真里扫物体**宽度/质量/摩擦/质心**，就能批量生成 `EMPTY/HOLD/SLIP/JAM/LOST` 的正负样本与本体签名。
- **UIP-14（模块化技能图）**：把「抓取」从隐含动作升级为**一等技能节点**，自带状态机与成功谓词；「插入/拧动/拉拉链」都以「稳定抓持」为前置条件。
- **UIP-15（可信度安全阀）**：本体判定是 CPU 级、O(1)、微秒级，可在两次 `get_action` 之间完成，重做决策比视觉-only 更快；但必须设最大重做次数，避免「误判 SLIP→无限重抓」。

---

## 5. 瓶颈假设（更新）

- **H1（最高杠杆）**：若「抓住 X」本身是计分步，则**本体抓取验证**把「不可见的步骤分」变成可控信号；谁先稳定判出抓取事件，谁就能在步骤分上系统性领先。
- **H2**：位置-only 的本体感知可判「有/无/掉」，**不能可靠判「力/卡」**；必须用主动探测或学习残差补足。
- **H3**：接触式人为撤回可由 PDR 捕获；非接触式撤回必须视觉兜底，单靠本体必然漏检。
- **H4**：实时性瓶颈不在本体通道，而在图像与调用次数；因此「加本体」几乎不增加延迟，还能通过相位提前缩短块长（与 UIP-13 ACS 协同）。

---

## 6. 本轮最大风险（一句话）

**把准本体感知当成真值——没有力矩/触觉时，「握住/卡住/重物/慢滑」在位置通道上高度混淆，若不在每个任务上校准并与视觉融合，误判会直接变成反复重做带来的延迟灾难。**

## 1. 旗舰深潜：UIP-16 · PGV（Proprioceptive Grasp Verifier）

### 1.1 机制

在每个 `get_action` 调用中（或两次调用之间），用最近历史做一次 O(1) 状态机更新：

- **输入**：`q_t, g_t, x_t, b_t`（接口 state）、上一步下发的 `g^cmd, q^cmd`（策略自己知道）、可选堆叠帧差分。
- **输出**：`G_t ∈ {EMPTY, HOLD, SLIP, JAM, LOST, OPEN, RELEASE}` + 置信度。
- **用途**：
  1. 作为 UIP-01′ 的 `regressed` 物理分支：`HOLD→SLIP/LOST` 直接触发重做；
  2. 作为计分步「抓住 X」的在线自检：`HOLD` 稳定 n 步才允许推进到下一步；
  3. 作为 UIP-13 的相位信号：`APPROACH/CLOSING` 用短块，`HOLD` 搬运用长块。

### 1.2 为什么是它（相对 v2 验证器）

| 维度 | 视觉/几何验证器（v2） | PGV（v3） |
|---|---|---|
| 被手遮挡 | 看不见 | 不受影响（本体在关节里） |
| 延迟 | 依赖 JPEG 与骨干 | 微秒级阈值/小模型 |
| 带宽 | 每帧多张 JPEG | 已有 state，**零新增** |
| 判断「抓住没有」 | 间接、易错 | 直接（δ 签名） |
| 判断「抓的是什么/在哪」 | 强 | 弱，需要视觉 |

结论：**视觉答「是什么」，本体答「拿没拿到」**，二者互补而非替代。

### 1.3 逐任务校准流程（基于公开数据）

1. 解析每集 `action.left/right_gripper`，找到由 5.5→0 的闭合 onset；
2. 用 `observation.state.*_gripper` 计算 `δ_t`，取闭合后稳态中位数作为 `ŵ`；
3. 用 `ee_pose` 的 z 方向差分找抬升/搬运段，统计负载下 `r` 的分布；
4. 由正样本（成功抓取）估 `θ_c, θ_h, θ_s, θ_slip, θ_l`；
5. 用「空夹/提前闭合」负样本与「滑落」片段估误报率；
6. 每任务存一组阈值，运行时按 `language` 路由。

> 这一步是**完全离线**的，且不需要人工标注：闭合命令与夹爪开度天然给出弱标签。

## 2. 信号与推导

### 2.1 夹爪模型与物体宽度估计

一阶近似（`α` 为执行器/滤波响应系数）：

```
g_{t+1} = g_t + α ( clip(g^cmd_t, w_t, 5.5) − g_t ) + ε_t
```

- 空夹：`w_t = 0` ⇒ 稳态 `g→g^cmd`，`δ→0`；
- 握住宽度 `w` 的物体：`g→max(g^cmd, w)` ⇒ 稳态 `δ→w − g^cmd`；
- 因此 **物体宽度估计**：`ŵ = median_{t∈hold}( g_t )`（当 `g^cmd≈0`）。

### 2.2 滑移的可检测性

若物体开始滑出，`w_t` 以速率 `v_s = −dw/dt > 0` 减小，则

```
dg/dt ≈ (w_t − g_t)/τ + dw/dt = (w_t − g_t)/τ − v_s
```

在保持闭合命令时 `g_t≈w_t`，第一项趋零，**符号由 −v_s 主导** ⇒ `Δg<0` 是滑移的直接证据。检测延迟约 `τ·log(Δw/噪声)`；慢滑（`v_s` 小于噪声/τ）会漏检——这正是合成实验中 SLIP 仍有约 8.7% 被判成 HOLD 的来源，也是需要 PDR/视觉融合的原因。

### 2.3 跟踪残差与「费力」

```
r_t ≈ K^{-1} F_load + b_gravity + b_friction
```

无力矩观测时，`r_t` 只能作为负载/卡阻的**单调代理**；控制器刚度 `K` 越大，`r` 越小、越难分辨。主动探测通过**主动注入已知激励**提高信噪比：

```
probe: q^cmd_t += A·sin(2πft)·e_probe ,  A≈5 mm, f≈1–2 Hz, 0.3 s
score = median( ||r_t|| / ||q^cmd_t − q^ref_t|| )
JAM if score > θ_j
```

探测方向只取**侧向/竖直安全方向**，禁止沿插入方向探测，避免把物体顶坏或顶得更深。

### 2.4 带宽与延迟核算

单帧本体维度：`7+7+6+6+1+1+15 = 43` floats = 172 B（float32）。

- 堆叠 4 帧 ≈ **688 B**；单张 480×640 RGB JPEG（q95）通常 **数十 KB**。本体堆叠约占一张图的 **1–2%**。
- 因此：**加本体历史几乎不增加传输延迟**；实时性瓶颈仍是图像数量、`action_chunk_size` 与 `get_action` 往返次数。
- PGV 本身可在 CPU 上以固定阈值运行，避免 GPU 排队，适合放在两次网络调用之间。

## 3. UIP-17 · APP（Active Proprioceptive Probing）

- **触发条件**：`G_t == HOLD` 但置信度低，或该计分步分值高（如 T10 的 30 分「抓住插头」），或即将进入插入/拧动前。
- **动作**：在安全方向注入小抖动，比较「有负载响应」与「刚性卡死响应」的跟踪残差。
- **成本模型**：

```
gain = P(step_score) · ΔP(success | probe) · score
cost = t_probe · λ_latency + risk_penalty
probe iff gain > cost
```

- **与 UIP-15 的关系**：探测耗时计入延迟预算；若预算不足则退化为被动 PGV + 视觉确认。
- **预期收益**：把 JAM 与 HOLD 的混淆（合成中召回 47.0%）拉开到 97.7%。

## 4. UIP-18 · GEM/GPM（Grasp Event Mining + Grasp Pose Memory）

### 4.1 自动事件抽取

```python
def mine_grasp_events(episode):
    events = []
    for side in ("left", "right"):
        gcmd = episode[f"action.{side}_gripper"]      # 5.5 open -> 0 close
        g    = episode[f"observation.state.{side}_gripper"]
        ee   = episode[f"observation.state.{side}_ee_pose_gripper_base"]
        for t in closing_onsets(gcmd):
            t_c = first t2 > t with (g[t2] - gcmd[t2]) > TH_CONTACT
            t_l = first t2 > t_c with (ee[t2,2] - ee[t2-1,2]) > TH_LIFT
            if t_c and t_l:
                events.append(dict(
                    lang=episode["task"],
                    t_c=t_c,
                    ee_pose=ee[t_c],
                    width_hat=g[t_c],
                    approach=normalize(ee[t_c] - ee[t_c - K]),
                    img_embed=wrist_embed(episode, side, t_c),
                ))
    return events
```

### 4.2 未见物体上的检索

```
score(E) = sim(lang_embed, E.lang) + sim(img_embed, E.img_embed)
           − λ_w |ŵ' − E.width_hat| − λ_u (1 − cos(u', E.approach))
```

取 top-k 抓取位姿，做 SE(3) 对齐后作为策略的抓取先验；若 `ŵ'` 超出记忆范围，则退化为「先合到接触、依据 δ 自适应停止」的闭环抓取。

### 4.3 与泛化轴的关系

- `unseen_object_*`：靠「语言 + 宽度 + 接近方向」检索，避免对具体物体过拟合；
- `human_*`：抓取后若被拿走，PGV 的 `LOST` 直接惩罚（见 UIP-19/20）。

## 5. UIP-19 · PDR（Proprioceptive Dynamics Residual）

```python
# 离线：在公开数据上训练前向模型（小 MLP/GRU 即可，单骨干共享编码）
for (p_t, a_t, p_{t+1}) in replay:
    loss = || f_theta(p_t, a_t) - p_{t+1} ||^2

# 在线：CUSUM 变点检测
e = || f_theta(p_t, a_t) - p_{t+1} ||
z = max(0, z + (e - mu) / sigma - k)
if z > h:
    flag("external_event")
```

- **能抓**：人从手里拿走物体（夹爪开度突变 + 末端被拖拽）、挪底座（`lower_body`/`ee` 基座坐标跳变）、推手臂（关节跟踪残差尖峰）。
- **不能抓**：机器人手离开后，人偷偷把已完成的拉链拉开、把叠好的毛巾翻开（无接触、无状态跳变）。
- **结论**：PDR 是 UIP-09′ 的**物理补充**，不是替代；非接触语义撤回仍由视觉/几何验证器负责。

## 6. UIP-20 · GRR（Grasp Recovery Reflex）与 UIP-21 · PAF

### 6.1 GRR 反射表

| 相位 | 触发 | 反射动作 | 预算 |
|---|---|---|---|
| SLIP | Δg<−θ 连续 m 步 | 加大闭合 → 停顿 → 小幅回拉确认 → 继续 | ≤1 次/子目标 |
| LOST | δ 从高跌到低 | 回到抓取位姿记忆 top-k，重新对准抓取 | ≤2 次/子目标 |
| JAM | 主动探测残差高 | 反向退让 1–2 cm，侧移重对准，降速重试 | ≤1 次/子目标 |
| EMPTY | δ≈0 且已闭合 | 重新张开、对准、再抓 | ≤2 次 |

所有反射必须经过 UIP-15 的延迟/抖动预算与最大次数门控。

### 6.2 PAF：确保策略「真的用」本体

- 许多模仿学习策略过度依赖视觉，state 只是摆设；本轮做**消融 + 强制融合**：
  - 视觉 token 与本体 token 分别编码，交叉注意力融合；
  - 随机 dropout 视觉 token（训练期），迫使策略在本体通道上建立可用的抓取表征；
  - 用 PGV 的伪标签做辅助头（预测 `G_t`），共享骨干，单模型合规。

## 7. 伪代码：PGV + UIP-01′ 的联合调度

```python
class PGV:
    def __init__(self, th):
        self.th = th
        self.reset()

    def reset(self):
        self.g_prev = None
        self.g_cmd_prev = None
        self.hold_count = 0
        self.slip_count = 0
        self.was_holding = False
        self.phase = "OPEN"

    def update(self, obs, last_action):
        g   = obs["observation.state.left_gripper"][0]     # 单侧示例
        q   = obs["observation.state.left_arm"]
        gcmd = last_action["action.left_gripper"][0]
        dg   = 0.0 if self.g_prev is None else g - self.g_prev
        delta = max(0.0, g - gcmd)
        r     = norm(q - last_action["action.left_arm"])

        if gcmd > self.g_cmd_prev:                 # 命令张开
            self.phase = "RELEASE"
        elif self.phase in ("OPEN", "APPROACH") and gcmd < g - 0.1:
            self.phase = "CLOSING"
        elif self.phase in ("CLOSING", "CONTACT"):
            if delta > self.th.c and dg < 0:
                self.phase = "CONTACT"
            if delta > self.th.h and abs(dg) < self.th.s:
                self.hold_count += 1
            else:
                self.hold_count = 0
            if self.hold_count >= self.th.n:
                self.phase = "HOLD"; self.was_holding = True
        elif self.phase == "HOLD":
            if delta < self.th.l and self.was_holding:
                self.phase = "LOST"
            elif dg < -self.th.slip:
                self.slip_count += 1
                if self.slip_count >= self.th.m:
                    self.phase = "SLIP"
            else:
                self.slip_count = 0
                if r > self.th.j:
                    self.phase = "JAM"

        self.g_prev, self.g_cmd_prev = g, gcmd
        return self.phase, delta, r


class GraspAwarePolicy:                 # UIP-01′ + UIP-16/17/20
    def __init__(self, policy, pgv, gpm, governor):
        self.policy, self.pgv, self.gpm, self.gov = policy, pgv, gpm, governor

    def reset(self):
        self.policy.reset(); self.pgv.reset(); self.gov.reset()

    def get_action(self, obs):
        phase, delta, r = self.pgv.update(obs, self.last_action)
        if phase in ("SLIP", "LOST", "JAM", "EMPTY"):
            self.gov.on_failure(phase)
            obs = self.gpm.recover(obs, phase)          # 调整目标位姿/抓取先验
            self.policy.clear_buffer()
        k = 2 if phase in ("APPROACH", "CLOSING", "CONTACT") else 8
        return self.policy.get_action(obs, k)
```

```python
# UIP-13 相位自适应块长（与 PGV 联动）
def pick_k(phase, remaining_budget):
    if phase in ("APPROACH", "CLOSING", "CONTACT"): return 1   # 高频重观测
    if phase in ("HOLD", "RELEASE"):                 return 8   # 搬运，少往返
    return 4
```

## 8. 合成机制验证（本轮已跑；**非数据集/真机结果**）

### 8.1 设定

- 8000 个 episode，4 类均衡：EMPTY / HOLD / SLIP / JAM（各 2000）。
- 夹爪一阶响应 `α=0.5`，开度噪声 `σ=0.0025`；
- HOLD 物体宽度 `w~N(0.040,0.009)`；JAM `w~N(0.050,0.009)`（**刻意重叠**，模拟纯位置不可分）；
- SLIP 在 `t∈[31,42]` 开始，滑出速率 `u~U(0.002,0.012)`；
- 抬升段跟踪残差：负载 `0.020`，JAM 额外 `0.015`，噪声 `σ=0.008`。
- 三种检测器：
  1. **逐帧阈值 + 多数投票**（无记忆）；
  2. **带记忆状态机**（`established = max δ_{22..34} > 0.012`，`final δ_{45..55}`，`dropped = 连续两步 Δg<−0.0035`）；
  3. **状态机 + 主动探测**（`median r_{38..52} > 0.030 → JAM`）。

### 8.2 结果

| 检测器 | 总准确率 | EMPTY | HOLD | SLIP | JAM |
|---|---|---|---|---|---|
| 逐帧阈值（无记忆） | **0.615** | 1.000 | 1.000 | **0.013** | 0.447 |
| 带记忆状态机 | **0.848** | 0.997 | 1.000 | **0.924** | 0.470 |
| 状态机 + 主动探测 | **0.972** | 0.998 | 1.000 | 0.913 | **0.977** |

带记忆状态机的混淆矩阵（行=真值）：

| 真值\预测 | EMPTY | HOLD | SLIP | JAM |
|---|---|---|---|---|
| EMPTY | 1993 | 7 | 0 | 0 |
| HOLD | 0 | 2000 | 0 | 0 |
| SLIP | 0 | 151 | 1849 | 0 |
| JAM | 0 | 1059 | 0 | 941 |

### 8.3 读出的三条结论

1. **记忆是刚需**：逐帧法几乎测不到 SLIP（1.3%），因为「曾经握住、后来掉了」本质是时序事件；状态机把它抬到 92.4%。
2. **纯位置分不清 JAM/HOLD**：即使宽度刻意重叠，JAM 仍有 1059/2000 被判成 HOLD；这不是调阈值能解决的，必须主动探测（→97.7%）。
3. **剩余误差集中在慢滑**：151 个 SLIP 被判成 HOLD（滑速低于噪声/阈值），需要 PDR 或视觉位移做二次确认。

> 方法学声明：该实验只验证「状态机 + 主动探测」的**机制必要性**，不代表真实数据精度。下一步必须用 32 个公开数据集做回放校准（见 §10）。

## 10. 公开数据校准协议（离线、无人工标注）

1. 下载/映射 32 个 HF 数据集；统一键名（数据 `head_stereo_*`→接口 `cam_*_high`，`wrist_*`→`cam_*_wrist`）。
2. 逐集抽 `action.*_gripper` 的闭合 onset，计算 `δ_t`、`Δg_t`、`r_t`、`Δz_ee`。
3. 成功抓取段：`δ` 稳态高 + 抬升后仍高 → 正样本；
   空夹：`δ≈0`；提前闭合/未接触：`δ` 低但 `Δg≈0` → 负样本。
4. 用正样本分位数设 `θ_h/θ_c/θ_l`；用负样本误触发率设 `θ_slip/θ_jam`。
5. 留出任务做跨任务泛化测试；用 UIP-11 GSO 在仿真里做扰动回放（宽度/质量/摩擦）。
6. 真机只做**小样本锚点**（每类 10–20 次），校准仿真阈值，不承担大规模统计。

## 11. 合规、接口与风险

- **单模型合规**：PGV/PDR 若是阈值/小 MLP，与主骨干共享或独立小头均可；辅助抓取头必须挂在同一骨干，避免被判「多模型」。
- **接口红线**：只使用 README 列出的 state 键；`gripper` 是单通道，别假设多指；返回动作形状严格 `(T_a, …)`。
- **无外力观测**：必须把结论表述为「准本体感知」，不能宣称测到了力；合成实验的 97.2% 是理想上界，真实数据会显著下降。
- **误判代价**：错误的 `SLIP/LOST` 会触发重抓，增加延迟与动作异常，反而伤可信度；必须用 UIP-15 限制次数并做动作平滑。
- **非接触撤回**：PDR 抓不到，必须保留 v2 的视觉/几何验证器。
