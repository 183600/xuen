# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「微调」×「创新点挖掘」）

> R69 让系统学会了「问」：把不确定性拆成 aleatoric 与 epistemic，用流匹配多模态策略显式表示歧义，再用注视/探针/问句这些信息动作去消解。但 R69 有一个它自己没意识到的浪费：**它从不改变自己**。同一个歧义，今天问、明天问、每个新部署都问；如果世界结构是稳定的，第二次提问就应该比第一次便宜。更尖锐地说，R69 的「问」是**动作空间里的信息购买**，却缺少它的慢时标对偶——**参数空间里的能力购买**。
>
> 同时，走到第 69 轮，架构已叠了六层闭环、几十个 IP。继续「加一层」的边际收益越来越难验证；真正稀缺的不是想法，而是**判断哪个想法值得留下、哪个区域值得学、什么时候该停止创新**。这正是两个灵感词的切口：
> - **微调**：一种低频、离线、可回滚的参数动作；不是「再训练一个大模型」，而是**在外科手术式的塑性隔离下，只改动被证明值得改的那一小块参数**。
> - **创新点挖掘**：不是「生成更多创新点」，而是**用可操作判据去挖掘真正的能力缺口、给已有创新点做信用归因，并识别「创新破产」——即继续加模块已无正收益的时刻**。
>
> 核心命题：**一个能力缺口应被三路仲裁——现在就能廉价问清的去「问」（R69），反复出现且可学的去「微调」（R70），既不可约又不可学或不可信的去「弃权」（R68/R69 保守兜底）。微调只发生在离线、冻结安全层、信任域内、可回滚、且通过「幻影创新门」之后；R69 是本轮在「零适应」边界上的严格退化。** 命名 **MINE-RAS**（Mining Innovation & Novelty-guided Epistemic micro-fine-tuning for Risk-Adaptive Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我该改变自己的哪一部分，以及何时停止改变**」——学习不是往网络里灌数据，而是一次有预算、有证据、有回滚的受控手术。

## 0. 直觉与动机

**灵感 1（微调 = 慢时标的信息动作）**
直觉：R69 的 VoI 回答「这一步值不值得多看一眼」；但若同一类歧义在每个 episode 都以概率 q 重现，逐次交互就是在为同一份信息反复付费。人类不会每次都问路，而是把答案内化成习惯。于是「问」与「学」不是替代关系，而是**同一笔信息投资的两种期限**：交互是活期，微调是定期。给定复发率 q、单次交互成本 c_ask、微调摊销成本 c_ft，存在一个盈亏平衡时程 N* = c_ft / [q(c_ask − c_res)]；低于 N* 就问，高于 N* 就学。这把 R69 的瞬时 VoI 扩展为跨 episode 的 **LVoI**。

**时标表（本轮的核心世界观）**

| 时标 | 决策 | 作用对象 | 失效方式 | 对应层 |
|---|---|---|---|---|
| 微秒–毫秒 | 控制/认证 | 动作前缀 k、缩放 λ | 越界、突变 | R66–R68 |
| 毫秒–秒 | 信息动作 | 注视/探针/问句 g | 问错、被投毒 | R69 |
| 小时–天 | 微调 | 低秩参数 Δθ | 遗忘、安全回退、幻影创新 | **R70** |
| 周–月 | 架构/创新点 | 模块与 IP | 复杂度膨胀、创新破产 | **R70（元层）** |

**灵感 2（创新点挖掘 = 从「提出」转向「归因与停止」）**
直觉：研究循环最容易犯的错是「因为能加，所以加」。一个架构创新若不能被消融实验证明其边际贡献，它就是**新颖性债务**（novelty debt）——复杂度上升、可信边界变窄、验证成本变高。真正的「挖掘」要做两件事：(a) **向外挖**：从部署流里挖出当前策略反复失败/反复歧义的状态区域，判断那里是否存在可学的结构；(b) **向内挖**：对已有 IP 做干预式消融，估计每个模块的边际信用，并检测「继续挖也挖不出正收益」的**创新破产**。两者共用同一个价值函数，因此不是两个系统，而是同一个算子的两个方向。

**灵感 3（三路仲裁：问 / 学 / 弃权）**
直觉：面对一个能力缺口 R，系统其实有三个动作，而 R69 只实现了第一个：
- **Ask**：R69 的交互，成本 c_ask，收益 VoI；适合「一次性、可当场消解」的歧义；
- **Adapt**：R70 的微调，成本 c_ft，收益 LVoI；适合「复发、可学、跨 episode 存在」的结构；
- **Abstain**：不交互也不学习，走 R68 的 λ_floor；适合「aleatoric、不可学、或证据不可信」。
仲裁规则是三者取最大净收益：`max(VoI − c_ask, LVoI − c_ft, 0)`。这条规则让 R69 成为 LVoI ≤ c_ft 时的边界情形，而不是被丢掉。

**灵感 4（塑性隔离：只让该变的变）**
直觉：微调最危险的地方不是「学不会」，而是「学会了不该学的」。安全评论家、校准器、证书生成器、WM 认证器一旦被微调，整个系统的安全论证就失效了。因此 R70 必须做**参数分区**：只允许策略主干上的低秩适配器（plastic set 𝒫）更新；所有承担安全论证的模块（frozen set ℱ）冻结并做哈希封存。再加上信任域（KL ≤ δ）、保护集非回归、以及一键回滚，微调才从「不可控训练」变成「有证书的受控干预」。

**灵感 5（创新也是攻击面：幻影创新与指标古德哈特）**
直觉：R69 的最大风险是「追问一个幻影模态」。R70 把同一风险放大到参数层：如果新颖性挖掘器把一个采样噪声簇当成「新能力缺口」，微调就会**把幻觉固化进权重**——从「问错」升级为「学错」，而学错比问错更难撤销。更隐蔽的是指标古德哈特：一旦用「挖掘出的创新点数量」考核研究循环，系统就会生产看起来新颖、实际无用的模块。故本轮必须交付：幻影创新门（PIC）、创新归因账本（IAL）、以及显式的创新破产判据。

## 1. 形式化定义（增量：定义 310–322）

**定义 310（MINE-RAS 总览）** MINE-RAS = (NIM, LVA, AFG, μFT, SGS, RDC, IAL) 构建在 FLUID-RAS 之上。四不变式：
(i) **实时零学习写**（继承 R68 定义 276-i）：控制环路内不发生任何参数更新，微调只在 episode 之间/离线进行；
(ii) **塑性隔离**：仅允许 𝒫 上的低秩参数更新，ℱ = {安全评论家, 校准器, 证书生成器, WM 认证器, 审计器} 冻结并哈希封存；
(iii) **单调接受**：更新在保护集上不得回归，且必须在挖掘集上带来可证增益，否则拒绝；
(iv) **可回滚**：每次接受都产生版本化检查点与回滚触发器，任何一次更新都可被原子撤销。

**定义 311（创新点 / 能力缺口区域）** 部署流产生事件 (s, m, y)。一次聚类得到候选区域 R = (S_R, M_R)，其统计量为：支撑 n(R)、复发率 q(R)（单位 episode 命中次数）、当前损失 ℓ̄(R)、认知占比 η(R) = U_epi/(U_ale+U_epi)、可学性 λ(R)（留出集上参数更新的可达增益）。称 R 为一个**创新点**当且仅当 q(R) ≥ q_min、η(R) ≥ η_min、λ(R) ≥ λ_min 且 n(R) ≥ n_min；否则它是噪声、aleatoric、或不可学区域。

**定义 312（学习价值 LVoI）** 对创新点 R，定义
LVoI(R) = N·q(R)·[c_ask(R) − c_res(R)] − c_ft(R) − λ_f·Forget(R) − ρ_risk·Risk(R)，
其中 N 为部署时程，c_ask 为若不学则每次需交互的期望成本，c_res 为学习后残余交互成本，c_ft 为微调摊销成本，Forget 为对保护集的遗忘损失，Risk 为安全风险溢价。LVoI > 0 才允许「学」。这是 R69 的 VoI 在参数时标上的对偶：**VoI 买的是此刻的信息，LVoI 买的是未来的能力**。

**定义 313（微调算子 μFT）** 设冻结参数 θ_ℱ，塑性参数 θ_𝒫。更新 Δθ = B A，A ∈ ℝ^{r×d}, B ∈ ℝ^{d×r}, r ≪ d；θ' = θ + α BA。约束：‖Δθ‖_F ≤ ε_θ、KL(π_{θ'}‖π_θ | S_R) ≤ δ_FT、α ≤ α_max。仅 𝒫 被写；ℱ 的哈希在更新前后必须一致。

**定义 314（三路仲裁 AFG）** 对每个能力缺口 R，计算
a* = argmax_{a ∈ {Ask, Adapt, Abstain}} {VoI(R) − c_ask, LVoI(R) − c_ft, 0}。
Ask 分支调用 R69 的 MINT；Adapt 分支仅在 PIC 与 SGS 都通过时进入 μFT；Abstain 分支逐指令退化为 R68/R69 的保守路径。R69 恰是「Adapt 恒不可用」时的 AFG。

**定义 315（安全盾 SGS）** 冻结安全评论家 V_safe 与屏蔽器。更新 θ' 被接受的必要条件：在保护集 P_prot ∪ S_R 上，违规率的置信上界 UCB_α(V_safe, θ') ≤ ε_safe，且认证前缀长度 k(θ') ≥ k(θ) − κ。置信界用 conformal 或 Hoeffding 给出，样本量不足时自动拒绝。

**定义 316（保护集与防遗忘）** P_prot 包含安全关键状态、历史交互失败、以及既往已接受的创新区域。微调使用 replay 混合，保护集在每批中的占比 ≥ r_p。接受条件：max_{x∈P_prot}(ℓ_{θ'}(x) − ℓ_θ(x)) ≤ β。若 β 越界，则拒绝并记一次「遗忘事件」入账本。

**定义 317（创新归因账本 IAL）** 对每个组件/IP i，在固定评测套件上用留一消融估计边际信用 C_i = E[ℓ_{−i}] − E[ℓ]，必要时用 Shapley 值 φ_i 校正交互项。定义**新颖性债务** D_i = Complexity_i − κ·C_i。当 D_i > τ_debt 时，标记为「待验证/待剪枝」。IAL 是「向内挖掘」的产物，也是研究循环的审计对象。

**定义 318（幻影创新门 PIC）** 在微调前，区域 R 必须通过三项检验：(a) 复发可复现（不同随机种子/时段下仍存在）；(b) 模态校准可信（继承 R69 的 ECE ≤ τ_ece，且不计入未消解的 U_epi）；(c) 反事实可归因（在留出集上，增益确实来自参数更新，而非采样噪声或评测泄漏）。任一不过，R 进入「未证实创新」桶，不进入 μFT。

**定义 319（回滚证书 RDC）** 每次接受生成 checkpoint (θ', hash, eval_snapshot)。在线监控两个量：保护集损失与安全评论家输出的违规 UCB。若任一越过阈值 τ_roll，则在下一个安全窗口原子回滚到 θ，并把该次更新标记为「失败创新」，其区域加入 P_prot 的负样本。回滚本身不改变控制环路，只换权重版本，继承 R68 定理 15 的无突变性。

**定义 320（证书 J_MINE）** J_MINE = (J_FLUID, LVoI_est, Δℓ_mined, Δℓ_protected, KL_FT, PIC_evidence, rollback_hash, IAL_snapshot, mine_ver)。Valid ⇔ Valid(J_FLUID) ∧ LVoI > 0 ∧ PIC 通过 ∧ SGS 通过 ∧ P_prot 非回归 ∧ 冻结集哈希不变。

**定义 321（创新预算与创新破产）** 每个部署有适应预算 B_adapt（算力/时间/风险）。当 max_R LVoI(R) ≤ 0、或所有候选 R 均被 PIC 拒绝、或 IAL 中所有新 IP 的边际信用 C_i ≤ τ_credit 时，系统进入**创新破产**状态：停止微调与加模块，只保留监控与回滚。这是研究循环自身的停止准则——**没有可证增益时，停止创新也是一种正确决策**。

**定义 322（部署协议 shadow→canary→promote）** 新权重先在影子模式下与旧权重并行推理（不执行），比较 mined/protected 指标；通过后进入 canary（限时、限域、限力），最后 promote。任一阶段失败即回滚。该协议把「微调」从单点事件变成有阶段门的安全发布流程。

## 2. 关键算法骨架

```python
# IP-264 NIM + IP-265 LVA：从部署流中挖掘创新点并估计学习价值
def mine_innovation(stream, fluid, budget):
    events = cluster_events(stream)                    # 状态×模态轨迹聚类
    regions = []
    for R in events:
        if not (R.n >= N_MIN and R.q >= Q_MIN
                and R.eta >= ETA_MIN and R.lam >= LAMBDA_MIN):
            continue                                   # 噪声/aleatoric/不可学
        R.voi   = fluid.mint.value_of_info(R)          # R69 的瞬时 VoI
        R.lvoi  = (budget.N * R.q * (R.c_ask - R.c_res)
                   - R.c_ft - LAMBDA_F * R.forget
                   - RHO_RISK * R.risk)                # 定义 312
        if R.lvoi > 0: regions.append(R)
    return sorted(regions, key=lambda r: -r.lvoi)

# IP-266 AFG：三路仲裁（问 / 学 / 弃权）
def arbitrate(R, fluid, budget):
    options = [("Abstain", 0.0)]
    if R.voi > R.c_ask:  options.append(("Ask",   R.voi - R.c_ask))
    if R.lvoi > R.c_ft:  options.append(("Adapt", R.lvoi - R.c_ft))
    action, score = max(options, key=lambda t: t[1])
    return action if score > 0 else "Abstain"          # LVoI<=成本 → 退化 R69

# IP-271 PIC：幻影创新门（先证伪，再学习）
def phantom_gate(R, fluid, replay):
    if not reproducible(R, seeds=3, windows=2): return False
    if fluid.mcg.ece(R) > TAU_ECE:              return False
    if not counterfactual_gain(R, replay):      return False
    return True

# IP-267/268/269 μFT + SGS + RDC：受控手术
def micro_finetune(policy, R, prot, frozen_hash, cfg):
    assert hash_params(policy.frozen_set) == frozen_hash     # 塑性隔离
    theta0 = snapshot(policy)
    for step in range(cfg.steps):
        batch = mix(R.samples, replay(prot), ratio=cfg.r_p)
        loss  = task_loss(policy, batch) + cfg.beta * kl_anchor(policy, theta0, R)
        grad  = only_plastic_grad(loss, policy)               # 冻结集梯度为 0
        policy.plastic -= cfg.lr * low_rank_project(grad, rank=cfg.r)
        if kl(policy, theta0, R) > cfg.delta: break            # 信任域
    # SGS：冻结评论家 + 保护集非回归 + 违规 UCB
    if not safety_accept(policy, theta0, prot, R, cfg): return None
    return checkpoint(policy)

# IP-263 主闭环之后的离线适应段（控制环路内不调用）
def MINE_RAS_offline(M, stream, budget):
    regions = mine_innovation(stream, M.fluid, budget)        # 向外挖
    for R in regions:
        act = arbitrate(R, M.fluid, budget)                   # 问/学/弃权
        if act != "Adapt": continue
        if not phantom_gate(R, M.fluid, M.replay): continue   # 幻影创新门
        ck = micro_finetune(M.policy, R, M.prot, M.frozen_hash, M.cfg)
        if ck is None: continue                               # 安全盾拒绝
        if not shadow_canary_eval(M, ck, R, M.prot):          # 定义 322
            rollback(M, ck); continue
        promote(M, ck)                                        # 原子换装
        M.ial.charge(R, ck)                                   # 创新归因
    if max((r.lvoi for r in regions), default=0) <= 0:
        M.ial.mark_bankrupt()                                 # 创新破产
    return M.ial.summary()                                    # 向内挖 + 停止判据
```

## 3. 推导

**引理 19（交互-微调替代率）** 设某创新点每 episode 以期望 q 次出现，单次交互净成本 c_ask，学习后残余成本 c_res < c_ask，微调摊销成本 c_ft。则部署时程 N 上的 LVoI(N) = N q (c_ask − c_res) − c_ft，盈亏平衡时程 N* = c_ft / [q(c_ask − c_res)]。系：**复发率越高、单次交互越贵、残余越接近零，越应「学」而不是「问」**；当 N < N* 时 AFG 正确选择 Ask，当 N > N* 时选择 Adapt。

**引理 20（保护集上的安全微调上界）** 在冻结安全评论家、KL ≤ δ_FT、且保护集样本量 n 足够时，更新后违规率相对基线的期望增量 ≤ L_v·δ_FT + √(log(1/α)/(2n))（L_v 为评论家对策略分布的 Lipschitz 常数）。故取 ε_safe = 该上界即可保证 SGS 的接受条件是可证安全的；样本不足时上界变松，系统自动拒绝。

**引理 21（replay 下的防遗忘界）** 若每批中保护集占比 ≥ r_p，且损失对参数的 Lipschitz 常数为 L，则 T 步内保护集上的累积漂移 ≤ η T (1−r_p) G_max L。取 β = 该界，即得定义 316 的非回归条件；r_p → 1 时漂移 → 0（退化为只学保护集，无增益）。

**引理 22（幻影创新的放大效应）** 若区域 R 实为采样噪声簇（真实模态权重近零），而微调在其上最小化训练损失，则策略会把该噪声方向的权重从 ŵ 抬高到 ŵ+Δ，导致模态校准误差 ECE 至少上升 c·Δ；参数化后的错误比 R69 的「追问一次」更持久。故 PIC 的三项检验不是可选项，而是防止「把幻觉写进权重」的必要条件。

**定理 18（MINE 严格包含 R69）** 在 A99–A101 下，对任意状态，MINE 的策略空间包含 R69；当 LVoI ≤ c_ft、PIC 失败、SGS 失败或预算耗尽时，AFG 返回 Abstain，系统**逐指令与 R69 相同**。因此 R69 是 MINE 在「零适应」边界上的严格退化；安全侧不做任何让步，效率侧只在通过证据门的 Adapt 分支上获得增益。

**定理 19（无振荡与有限终止）** 在单调接受（保护集非回归）、信任域有界、适应预算有限三条下，已接受更新的数量有限；每次接受要么提升 mined 指标，要么在保护集约束下被拒绝，故不存在接受-回滚-再接受的无限循环。系统最终到达不动点或创新破产状态。

**定理 20（创新归因的可识别性）** 若模块间不存在三阶及以上交互，则留一消融的边际信用 C_i 等于 Shapley 值 φ_i；存在高阶交互时，|C_i − φ_i| ≤ Σ_{|S|≥3} |φ_S|/(|S|)，可用二阶 Shapley 截断控制误差。系：IAL 的「新颖性债务」判据在有界交互假设下是可审计的，而不是主观叙事。

## 6. 本轮最大风险

1. **指标古德哈特**（用「创新点数量」考核研究循环）→ IAL 用留一消融/Shapley 计信用，不以数量计；定义 321 显式允许「创新破产」；

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** MINE-RAS = (NIM, LVA, AFG, μFT, SGS, RDC, IAL)。(i) 实时零学习写；(ii) 塑性隔离（仅 𝒫 更新，ℱ 冻结并哈希封存）；(iii) 单调接受（保护集非回归 + 挖掘集可证增益）；(iv) 可回滚（版本化检查点 + 原子撤销）。

**定义 311（创新点）** R = (S_R, M_R)，满足 n ≥ n_min、q ≥ q_min、η ≥ η_min、λ ≥ λ_min；否则是噪声 / aleatoric / 不可学区域。

**定义 312（LVoI）** `LVoI(R)=N·q(R)·[c_ask−c_res]−c_ft−λ_f·Forget−ρ_risk·Risk`。LVoI>0 才允许学；这是 R69 的 VoI 在参数时标的对偶。

**定义 313（μFT）** `Δθ=BA`，`θ'=θ+αBA`；`‖Δθ‖_F≤ε_θ`、`KL(π_{θ'}‖π_θ|S_R)≤δ_FT`；仅 𝒫 被写，ℱ 哈希前后一致。

**定义 314（三路仲裁 AFG）** `a*=argmax{VoI−c_ask, LVoI−c_ft, 0}`；Ask→MINT，Adapt→μFT（须过 PIC/SGS），Abstain→R68/R69 保守。R69 = 「Adapt 恒不可用」的 AFG。

**定义 315（SGS）** 接受条件：保护集∪S_R 上 `UCB_α(V_safe,θ')≤ε_safe`，且认证前缀 `k(θ')≥k(θ)−κ`；样本不足自动拒绝。

**定义 316（保护集与防遗忘）** P_prot 含安全关键状态、历史交互失败、既往创新区域；replay 占比 ≥ r_p；接受需 `max_{P_prot}(ℓ_{θ'}−ℓ_θ)≤β`，越界记「遗忘事件」。

**定义 317（IAL）** `C_i=E[ℓ_{−i}]−E[ℓ]`，必要时用 Shapley φ_i；新颖性债务 `D_i=Complexity_i−κ·C_i`，`D_i>τ_debt` 标记待验证/待剪枝。

**定义 318（PIC）** 微调前三检：(a) 跨种子/时段复发可复现；(b) 模态校准 ECE≤τ_ece；(c) 留出集反事实可归因。任一不过→「未证实创新」桶，不进入 μFT。

**定义 319（RDC）** 每次接受生成 (θ', hash, eval_snapshot)；在线监控保护集损失与违规 UCB，越 τ_roll 则在下一安全窗口原子回滚，区域入 P_prot 负样本；换装继承 R68 定理 15 无突变。

**定义 321（创新预算与创新破产）** 适应预算 B_adapt；当 `max_R LVoI≤0`、候选全被 PIC 拒、或新 IP 边际信用 `C_i≤τ_credit` 时进入创新破产：停止微调与加模块，只保留监控与回滚。

## 3. 关键算法伪代码

```python
# IP-264 NIM + IP-265 LVA：能力缺口挖掘与学习价值
def mine_innovation(stream, fluid, budget):
    regions = []
    for R in cluster_events(stream):                    # 状态×模态轨迹聚类
        if not (R.n >= N_MIN and R.q >= Q_MIN
                and R.eta >= ETA_MIN and R.lam >= LAMBDA_MIN):
            continue                                    # 噪声/aleatoric/不可学
        R.voi  = fluid.mint.value_of_info(R)            # R69 瞬时 VoI
        R.lvoi = (budget.N * R.q * (R.c_ask - R.c_res)
                  - R.c_ft - LAMBDA_F * R.forget
                  - RHO_RISK * R.risk)                  # 定义 312
        if R.lvoi > 0: regions.append(R)
    return sorted(regions, key=lambda r: -r.lvoi)

# IP-266 AFG：三路仲裁
def arbitrate(R, budget):
    opts = [("Abstain", 0.0)]
    if R.voi  > R.c_ask: opts.append(("Ask",   R.voi  - R.c_ask))
    if R.lvoi > R.c_ft:  opts.append(("Adapt", R.lvoi - R.c_ft))
    action, score = max(opts, key=lambda t: t[1])
    return action if score > 0 else "Abstain"           # 退化 R69

# IP-271 PIC：先证伪，再学习
def phantom_gate(R, fluid, replay):
    return (reproducible(R, seeds=3, windows=2)
            and fluid.mcg.ece(R) <= TAU_ECE
            and counterfactual_gain(R, replay))

# IP-267/268/272 μFT + SGS + ARB：塑性隔离下的受控手术
def micro_finetune(policy, R, prot, frozen_hash, cfg):
    assert hash_params(policy.frozen_set) == frozen_hash  # 定义 310-ii
    theta0 = snapshot(policy)
    for _ in range(cfg.steps):
        batch = mix(R.samples, replay(prot), ratio=cfg.r_p)
        loss  = task_loss(policy, batch) + cfg.beta * kl_anchor(policy, theta0, R)
        grad  = only_plastic_grad(loss, policy)           # ℱ 梯度恒为 0
        policy.plastic -= cfg.lr * low_rank_project(grad, rank=cfg.r)
        if kl(policy, theta0, R) > cfg.delta_FT: break    # 信任域
    if not safety_accept(policy, theta0, prot, R, cfg):   # SGS
        return None
    return checkpoint(policy)                             # RDC 用

# IP-275 离线适应闭环（控制环路内禁止调用）
def MINE_RAS_offline(M, stream, budget):
    regions = mine_innovation(stream, M.fluid, budget)    # 向外挖
    for R in regions:
        if arbitrate(R, budget) != "Adapt": continue
        if not phantom_gate(R, M.fluid, M.replay): continue
        ck = micro_finetune(M.policy, R, M.prot, M.frozen_hash, M.cfg)
        if ck is None: continue                           # 安全盾拒绝
        if not shadow_canary_eval(M, ck, R, M.prot):      # 定义 322
            rollback(M, ck); M.replay.add_negative(R); continue
        promote(M, ck)                                    # 原子换装
        M.ial.charge(R, ck)                               # 创新归因
    if max((r.lvoi for r in regions), default=0.0) <= 0:
        M.ial.mark_bankrupt()                             # 定义 321
    return M.ial.summary()                                # 向内挖 + 停止判据
```

## 4. 推导

**引理 19（交互-微调替代率）** 每 episode 期望 q 次复发，单次交互净成本 c_ask，学习后残余 c_res，摊销微调成本 c_ft，则 `LVoI(N)=N·q·(c_ask−c_res)−c_ft`，盈亏平衡 `N*=c_ft/[q(c_ask−c_res)]`。系：复发越高、交互越贵、残余越近零，越该「学」；`N<N*` 时 AFG 选 Ask，`N>N*` 时选 Adapt。

**引理 20（安全微调上界）** 冻结评论家、`KL≤δ_FT`、保护集样本 n 足够时，违规率期望增量 `≤ L_v·δ_FT + √(log(1/α)/(2n))`；取 ε_safe 为该上界，SGS 的接受条件即可证安全；样本不足时上界变松，系统自动拒绝。

**引理 21（replay 防遗忘界）** 保护集每批占比 ≥ r_p、损失 Lipschitz 常数 L，则 T 步内保护集累积漂移 `≤ η·T·(1−r_p)·G_max·L`；取 β 为该界即定义 316 的非回归条件；`r_p→1` 时漂移→0 但无增益。

**引理 22（幻影创新放大）** 若 R 实为采样噪声簇而微调在其上最小化训练损失，则模态权重被抬高 Δ，ECE 至少上升 c·Δ；参数化错误比 R69 的「追问一次」更持久。故 PIC 是必要非可选。

**定理 18（MINE 严格包含 R69）** A99–A101 下，MINE 策略空间包含 R69；当 `LVoI≤c_ft`、PIC 失败、SGS 失败或预算耗尽时 AFG 返回 Abstain，系统逐指令与 R69 相同。R69 = 「零适应」边界；安全不让步，效率仅在过证据门的 Adapt 分支获益。

**定理 19（无振荡与有限终止）** 单调接受 + 信任域有界 + 预算有限 ⇒ 已接受更新数有限；每次接受要么提升 mined 指标，要么被保护集约束拒绝，故不存在接受-回滚-再接受的无限循环；系统终达不动点或创新破产。

**定理 20（创新归因可识别性）** 若无三阶及以上交互，留一消融边际信用 `C_i=φ_i`；否则 `|C_i−φ_i| ≤ Σ_{|S|≥3}|φ_S|/(|S|)`，可用二阶 Shapley 截断控制误差。系：IAL 的「新颖性债务」在有界交互假设下可审计，而非主观叙事。

| RDC 在线监控 | O(1)（EMA） | O(1) | 定义 319；不入控制环 |

| **控制环路延迟** | **与 R69 持平 < 2.6ms** | — | 定义 310-i：实时零学习写 |

## 7. 本轮最大风险

**一句话**：微调是**单向门**——若新颖性挖掘器把「幻影区域」误判为可学缺口、PIC 又没拦住，系统就会把幻觉固化进权重，把 R69 的「问错」升级成「学错」；而学错比问错更难撤销，因为回滚依赖的监控本身可能已被同一偏见污染——**学错，比不问、不学都更危险**。

**次级风险与缓解**：指标古德哈特（IAL 用留一/Shapley 计信用，不以数量计；定义 321 允许创新破产）；安全层被污染（冻结集哈希封存 + 定义 310-ii + SGS 独立评论家）；保护集被挤压导致遗忘（replay 硬比例 + 引理 21 漂移界 + RDC 回滚）；LVoI 估计偏差（影子/canary 分阶段 + E302/E309 校准）；回滚滞后（保护集损失 + 违规 UCB 双指标 + 安全窗口原子换装）；归因主观化（定理 20 可识别性 + 固定评测套件 + 预注册消融）。
