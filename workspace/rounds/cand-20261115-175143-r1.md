# 第 8 轮（灵感循环第 8 轮；本轮灵感：「主动交互」×「用户测试」）

> **基线**：第 7 轮 MetricVoiceGauge-OTL-GC-ER（定义 493–525；引理 73–76；实验 E513–E525）。
> 本轮纪律：**主动不等于多说话，用户测试不等于让用户打分**。把「主动交互」约束成可计算信息收益的契约，把「用户测试」约束成可预注册、可反博弈的证伪程序；两者都必须能无损退回 v7 的被动闭环。

## 0. 直觉与动机

**灵感 1（主动交互 → 把证书的不确定性外包给人，但必须先付预算）**
直觉：v7 的系统其实很「内向」——它算证书、做退化、发告警，但只在被观测或被指令触发后反应。真正的主动交互是：当证书置信区间过宽、或某层指标即将越界时，系统主动问一句「你指的是这个吗？」「要保守还是快？」「我已降到安全模式，可以吗？」。这把一个内部隐变量（不确定性）换成一次可解决的外部查询。但人的注意力是稀缺且不可再生的：每次询问都在消耗信任、增加工作负荷。因此「主动」必须建模为**信息收益 vs 打扰成本**的决策，而不是「尽量多交互」。

**灵感 2（用户测试 → 交互策略的唯一裁判，也是最容易被作弊的裁判）**
直觉：主动交互策略的好坏无法只靠离线指标判断，它取决于人是否理解、是否信任、是否被打扰烦。用户测试给出 completion、信任校准、工作负荷、接受度等经验证据。但用户测试有三个结构性缺陷：①样本是「被观察的人」，受 Hawthorne 与新奇效应影响；②测试指标一旦成为优化目标，策略会「投其所好」——例如少问问题以降低打扰，却把失败变成沉默失败；③留出用户与部署人群存在分布差。因此用户测试必须带**护栏指标**与**反事实审计集**，否则它会把系统调成一个「看起来受欢迎、实际更不安全」的版本。

**合起来的核心命题**：主动交互是「用人的注意力换证书的确定性」，用户测试是「用有限的人的经验换策略的参数」。二者都在消耗一种不可再生资源（注意力 / 测试样本）。本轮把这两种资源都写成**有预算、有收益、可证伪**的约束，并证明「更主动」与「更讨喜」都不是单调更好。

## 1. 研究问题（轮次升级版）

- **Q1（主动性的可计算门控）**：在什么条件下系统应当主动询问/预警/确认，而不是静默退化？能否用信息价值（VoI）与注意力预算给出 O(1) 在线判据，且判据可解释？
- **Q2（非阻塞与安全）**：主动交互如何**永不阻塞** 50Hz 控制环与硬约束 M₀？人的回复延迟不能假设有界，超时后系统必须能独立地走默认回退。
- **Q3（用户测试的可证伪性）**：如何设计用户测试协议，使「策略在测试中更好」能推出「部署中不更差」，且不能被「减少打扰、增加沉默失败」所博弈？

## 2. 设计原则（在 P7–P9 基础上升级为 P10–P12）

**P10 主动交互契约（Proactive Interaction Contract, PIC）**
主动行为不是自由发挥的对话，而是一组**带证书载荷的类型化契约** κ = (trigger, ask, resolves, VoI, cost, deadline, fallback)。只允许四类：`clarify`（澄清意图）、`warn`（预警越界）、`confirm`（请求确认高风险动作）、`disclose`（告知已退化）。每个 κ 必须声明它解决哪个不确定性、预期把证书收紧多少、以及无人应答时的默认动作。
```
VoI(κ|s) = E_{r~P(r|s)}[ U(C(s,r)) ] − U(C(s)) − c_int(κ) − c_trust(κ)
主动触发 κ ⇔ VoI(κ|s) > 0 ∧ tokens(s) ≥ cost(κ) ∧ d_κ ≤ slack(s)
```

**P11 注意力预算（Attention Budget, AB）**
用令牌桶把主动频率变成硬约束：容量 B、补充率 r。为安全告警预留 B_safe 令牌，普通询问不得动用。这样「主动」不会退化成打扰轰炸，且安全告警永远不会被普通闲聊饿死。
```
tokens(t+Δt) = min(B, tokens(t) + r·Δt)
admit(κ) ⇔ tokens ≥ cost(κ) + [B_safe if κ 非安全关键 else 0]
```

**P12 用户测试账本（User-Test Ledger, UTL）**
用户测试先预注册：主指标 = 任务完成率与信任校准误差 TCE；护栏 = 沉默失败率、主动率、工作负荷（NASA-TLX）。用**按用户分层**的 K 折：训练折选策略，留出折只评估一次；并设**反事实审计集**（低 ASR、故意歧义、紧急场景）专门测量「本应主动却沉默」的失败。重复曝光分块估计新奇效应衰减。
```
TCE = E_t[ | trust_h(t) − reliability(t) | ]
可行策略集 Π_feas = { π : SF(π) ≤ ε_sf ∧ IntRate(π) ≤ ε_int ∧ TLX(π) ≤ τ_tlx }
π* = argmax_{π∈Π_feas} Completion(π, held-out)
```

## 3. 与基线的接口（如何退化）

- 主动路由器失效 / 超时 ⇒ 纯被动 v7：只算证书、静默退化，等价于 MetricVoiceGauge-OTL-GC-ER；
- 注意力预算失效 ⇒ 退化为保守静态预算（或直接关闭非安全主动），安全告警仍走 v7 的告警通道；
- 用户测试标定不可用 / 未预注册 ⇒ 用先验阈值与最保守预算，不做在线调参；
- 三者同时失效 ⇒ 完整退回 v7，不产生 v7 之外的行为。

## 4. 预期贡献

1. **主动性的信息论门控**：把「该不该问」从产品直觉变成 VoI 阈值规则，并给出预算下的最优选择结构（引理 77）；
2. **注意力预算的安全性证明**：令牌桶 + 安全预留保证告警时延与主动率有界，且非阻塞契约保证 50Hz 控制环不受人的回复延迟影响（引理 78）；
3. **信任校准的内点最优**：证明主动率—TCE 曲线是 U 形，「更多主动」不是单调更好（引理 79）；
4. **可证伪的用户测试协议**：给出留出泛化界与「无护栏即可被博弈」的构造性反例（引理 80），实验 E526–E540 覆盖门控、预算、泛化、反博弈、退化与端到端。

## 5. 本轮最大风险

**一句话**：主动交互会把系统的「不确定性」转译成对人的打扰，而用户测试又会把「人的偏好」转译成策略的优化目标——当测试缺少沉默失败护栏时，系统可能学会「少问问题、多沉默失败」来讨好测试，形成一种在测试中更受欢迎、在部署中更不可靠的**表演性主动**。

## 1. 符号体系增量（定义 526–533）

| 符号 | 含义 |
|---|---|
| `C(s)` | 当前状态 s 下系统内部的证书 |
| `U(C)` | 证书效用（= −期望违约风险 + 任务进度） |
| `K_p` | 候选主动契约集合 |
| `κ = (trigger, ask, resolves, cost, deadline, fallback)` | 主动交互契约 |
| `r` | 用户对 κ 的回复（随机变量） |
| `VoI(κ; s)` | 主动契约的信息价值 |
| `c_int(κ), c_trust(κ)` | 打扰成本 / 信任成本 |
| `B, r_refill, B_safe` | 令牌桶容量、补充率、安全预留 |
| `d_κ, slack(s)` | 回复截止期 / 当前控制周期的剩余时间裕度 |
| `trust_h(t)` | 用户在 t 时刻对系统的信任度（测试测得） |
| `reliability(t)` | 系统在窗口内的真实可靠度 = 1 − 违约率 |
| `TCE` | 信任校准误差 `E[abs(trust_h − reliability)]` |
| `SF(π)` | 策略 π 的沉默失败率 |
| `Π_feas` | 满足护栏约束的可行策略集 |

**定义 526（主动交互契约 PIC）** 一次主动行为是一个带证书载荷的类型化契约：
```
κ = (trigger, ask, resolves, cost, deadline, fallback)
domain(trigger) = {cert_gap > g0, layer_near_threshold, asr_conf < τ_voice, hard_degrade}
type(ask) ∈ {clarify, warn, confirm, disclose}
```
`resolves` 必须指向一个具体的不确定量（意图、物体、阈值、动作），`fallback` 必须是一个无需用户回复即可执行的默认动作。

**定义 527（信息价值门控 VoI Gate）** 以期望证书效用差减去打扰与信任成本：
```
VoI(κ|s) = E_{r~P(r|s)}[ U(C(s,r)) ] − U(C(s)) − c_int(κ) − c_trust(κ)
proactive(κ|s) ⇔ VoI(κ|s) > 0 ∧ tokens(s) ≥ cost(κ) ∧ d_κ ≤ slack(s)
```
其中 `C(s,r)` 为把用户回复 r 并入状态后重算的证书；`c_trust` 用当前 TCE 估计加权，信任越差，打扰的边际成本越高。

**定义 528（注意力预算 AB）** 容量 B、补充率 r_refill、安全预留 B_safe 的令牌桶：
```
tokens(t+Δt) = min(B, tokens(t) + r_refill·Δt)
admit(κ) ⇔ tokens ≥ cost(κ) + (B_safe if κ 非安全关键 else 0)
safety_admit(κ_s) ⇔ tokens_safe ≥ cost(κ_s)      # 独立的 B_safe 子桶
```
安全子桶与普通子桶分离，保证安全告警在任何普通主动洪峰下仍可发出。

**定义 529（非阻塞交互语义）** 主动契约在异步任务中执行，控制环只读取「当前最佳估计」：
```
reply_arrival(κ) > d_κ ⇒ execute(fallback(κ))
∀ t: latency(control_cycle(t)) ≤ WCET_v7 + O(1)   # 与人的回复无关
```
人的回复只影响**后续**周期的证书，绝不进入当前周期硬约束 M₀ 的关键路径。

**定义 530（信任校准误差 TCE）** 同时惩罚过度信任与信任不足：
```
TCE = E_t[ | trust_h(t) − reliability(t) | ]
over-trust  : trust_h > reliability  （危险：该谨慎时不谨慎）
under-trust : trust_h < reliability  （低效：该信任时不信任）
```

**定义 531（用户测试账本 UTL）** 预注册、分层留出、重复曝光的测试协议：
```
UTL = (Π, metrics, folds, audit_set, blocks)
metrics  = {Completion, TCE, SF, IntRate, TLX}
folds    = StratifiedKFold(by_user, K)
audit_set= {low_ASR, ambiguous_intent, safety_critical}
blocks   = 首次曝光 / 二次曝光（估计新奇效应衰减）
```

**定义 532（反博弈护栏）** 只有同时满足主指标与护栏的策略才可发布：
```
Π_feas = { π ∈ Π : SF(π) ≤ ε_sf ∧ IntRate(π) ≤ ε_int ∧ TLX(π) ≤ τ_tlx }
π* = argmax_{π ∈ Π_feas} Completion(π, held_out)
```
`SF`（沉默失败率）是**不可交易**的护栏：不允许用「减少打扰」去换「更多沉默失败」。

**定义 533（统一退化标识）** v8 与 v7 的可判定区分：
```
Φ_v8 = { proactive = VoI-gated, budget = token-bucket, C admitted after UTL guardrails }
Φ_v7 = { proactive = ∅,        budget = ∅,            C admitted by static check }
退化映射 ρ: Φ_v8 → Φ_v7 为逐坐标投影；UTL 过拟合不投影，而是置位告警位 alarm_UTL。
```

## 2. 形式化定义（要点）

**定义 493（MetricLadder）** 保留自 v6/v7；主动契约只允许**读取**层级状态与 τᵢ，不允许直接改写硬约束 τ₀。

**定义 494（VoiceCommandTyping）** 保留自 v7；当 `asr_conf < τ_voice` 时，v8 可发出 `clarify` 契约，但该契约带默认回退 ι₀，不阻塞当前动作。

**定义 495（RewardDecomposer）** 保留自 v7；主动交互的收益以「证书效用差」计量，不直接注入奖励，避免策略为了奖励而刷询问次数。

**定义 496（SoftCert）** v8 把 SoftCert 的置信区间显式暴露为可查询量：`cert_gap = τ_safe − σ`，`cert_gap > g0` 是 `clarify/confirm` 的主要触发条件之一。

**定义 521/528（OTL / GCT）** 保留自 v7；OTL 的调节速率可被 UTL 标定，但标定值必须落在 v7 的 clip 范围内，且未通过护栏时回退先验。

**定义 534（主动收益的可加性假设）** 对一组互不解决同一不确定量的契约，证书收紧近似可加：
```
Δ_κ(S) ≈ U(C | 并入 κ 的回复) − U(C | S)，  Δ_{κ1∪κ2} ≈ Δ_{κ1} + Δ_{κ2}
```
该假设是引理 77 精确最优性的前提；不成立时退化为子模近似（仍有 1−1/e 保证）。

## 3. 关键算法骨架

```python
import math
from dataclasses import dataclass, field


@dataclass
class Contract:
    name: str
    kind: str                 # clarify | warn | confirm | disclose
    resolves: str             # 被解决的不确定量
    cost: int                 # 消耗令牌数
    deadline_ms: float
    fallback: str
    safety_critical: bool = False


class TokenBucketBudget:
    """IP-357：注意力令牌桶，安全子桶独立，防闲聊饿死告警。"""
    def __init__(self, capacity, refill_per_s, safe_capacity):
        self.capacity = capacity
        self.refill = refill_per_s
        self.safe_capacity = safe_capacity
        self.tokens = capacity
        self.safe_tokens = safe_capacity
        self._last = 0.0

    def _refill(self, now):
        dt = max(0.0, now - self._last)
        self.tokens = min(self.capacity, self.tokens + self.refill * dt)
        self.safe_tokens = min(self.safe_capacity,
                               self.safe_tokens + self.refill * dt)
        self._last = now

    def admit(self, k: Contract, now: float) -> bool:
        self._refill(now)
        if k.safety_critical:
            if self.safe_tokens >= k.cost:
                self.safe_tokens -= k.cost
                return True
            return False
        if self.tokens >= k.cost + 1e-9 + self.safe_capacity * 0:
            # 普通契约不得动用安全预留：安全子桶已独立，这里只检查普通桶
            self.tokens -= k.cost
            return True
        return False


class ProactiveInteractionRouter:
    """IP-355/356：VoI 门控 + 预算选择的主动路由器。"""
    def __init__(self, budget: TokenBucketBudget, trust_cost_scale=0.3,
                 slack_fn=None, u_fn=None):
        self.budget = budget
        self.beta = trust_cost_scale
        self.slack_fn = slack_fn or (lambda state: 1e9)
        self.u_fn = u_fn or (lambda cert: -cert.get("risk", 0.0))

    def _expected_utility(self, cert, contract, state):
        # 用证书置信区间近似回复后的效用：假设回复能把 cert_gap 按
        # resolves 的可靠度 rho 收紧。
        rho = state.get("reply_reliability", {}).get(contract.resolves, 0.5)
        gap = max(0.0, cert.get("gap", 0.0))
        improved = dict(cert)
        improved["gap"] = gap * (1.0 - rho)
        improved["risk"] = cert.get("risk", 0.0) * (1.0 - rho)
        return self.u_fn(improved)

    def value_of_information(self, cert, contract, state, tce):
        base = self.u_fn(cert)
        after = self._expected_utility(cert, contract, state)
        c_int = float(contract.cost)
        c_trust = self.beta * float(tce) * float(contract.cost)
        return after - base - c_int - c_trust

    def select(self, cert, candidates, state, tce, now):
        feasible = []
        for k in candidates:
            if k.deadline_ms > self.slack_fn(state):
                continue
            voi = self.value_of_information(cert, k, state, tce)
            if voi <= 0.0:
                continue
            feasible.append((voi / max(1.0, k.cost), voi, k))
        # 引理 77：可加收益下按 VoI/成本 降序取前缀即最优
        feasible.sort(key=lambda x: x[0], reverse=True)
        chosen = []
        for _, _, k in feasible:
            if self.budget.admit(k, now):
                chosen.append(k)
        return chosen


class TrustCalibration:
    """IP-359：信任校准误差，同时惩罚 over-trust 与 under-trust。"""
    def __init__(self, window=50):
        self.window = window
        self.samples = []

    def update(self, trust_h, violation_flags):
        rel = 1.0 - (sum(violation_flags) / max(1, len(violation_flags)))
        self.samples.append((trust_h, rel))
        if len(self.samples) > self.window:
            self.samples.pop(0)

    def tce(self):
        if not self.samples:
            return 0.0
        return sum(abs(t - r) for t, r in self.samples) / len(self.samples)

    def over_trust_rate(self):
        if not self.samples:
            return 0.0
        return sum(1 for t, r in self.samples if t > r) / len(self.samples)


class UserTestLedger:
    """IP-358：预注册 + 分层留出 + 反事实审计 + 护栏。"""
    def __init__(self, eps_sf, eps_int, tau_tlx, delta=0.05, n_folds=5):
        self.eps_sf = eps_sf
        self.eps_int = eps_int
        self.tau_tlx = tau_tlx
        self.delta = delta
        self.k = n_folds

    @staticmethod
    def feasible(metrics, eps_sf, eps_int, tau_tlx):
        return (metrics["SF"] <= eps_sf
                and metrics["IntRate"] <= eps_int
                and metrics["TLX"] <= tau_tlx)

    def select(self, policies, held_out_metrics):
        feasible = [p for p in policies
                    if self.feasible(held_out_metrics[p], self.eps_sf,
                                     self.eps_int, self.tau_tlx)]
        if not feasible:
            return None  # 无策略过护栏 ⇒ 退回 v7 与保守预算
        return max(feasible, key=lambda p: held_out_metrics[p]["Completion"])

    def generalization_bound(self, n_users, n_policies):
        # Hoeffding + 并集界（引理 80(a)）
        return math.sqrt(math.log(2.0 * n_policies / self.delta)
                         / (2.0 * max(1, n_users)))


def metricvoicegauge_round_8(M, s, obs, audio_stream=None, ell=None,
                             router=None, tce_estimator=None):
    """v8 主路径：v7 控制环不变；主动交互仅在异步旁路中发生。"""
    # --- 1. 先跑 v7 的被动闭环，保证 50Hz WCET 不受主动模块影响 ---
    C, spatial_cert, claims, metrics, rewards = \
        M.metricvoicegauge_round_7(s, obs, audio_stream, ell)

    # --- 2. 异步旁路：估计证书缺口与信任校准误差 ---
    if router is None:
        return C, spatial_cert, claims, metrics, rewards  # 无主动 ⇒ 等价 v7

    cert = {"risk": metrics.get("risk", 0.0),
            "gap": max(0.0, metrics.get("tau_safe", 0.0)
                       - metrics.get("sigma", 0.0))}
    tce = tce_estimator.tce() if tce_estimator is not None else 0.0
    candidates = M.proactive_contracts(cert, metrics)

    # --- 3. VoI + 预算选择；不阻塞当前周期 ---
    chosen = router.select(cert, candidates, {"reply_reliability": {}},
                           tce, now=metrics.get("t", 0.0))
    for k in chosen:
        M.async_issue(k)  # 带 deadline 与 fallback，回复只影响后续周期

    return C, spatial_cert, claims, metrics, rewards
```

## 4. 推导

**引理 77（预算化 VoI 选择的结构）** 设有候选契约集合 K_p，每个 κ 的证书效用增益 `Δ_κ ≥ 0`、成本 `c_κ > 0`，预算为令牌数 B。
- (a) 若各契约解决的 uncertainty 互不重叠，即收益可加（定义 534），则按 `Δ_κ / c_κ` 降序取前缀直到预算耗尽，得到 0/1 预算下的最优解（整数前缀与分数松弛最多差一项）。
- (b) 若收益为单调子模，则同一贪心给出 `(1 − 1/e)` 近似（Nemhauser–Wolsey–Fisher）。
- (c) 因此在线选择只需 `O(|K_p| log|K_p|)` 排序 + 一次前缀扫描；且证书缺口 `gap` 增大时，`Δ_κ` 单调不减，故主动概率对缺口单调——「越不确定越该问」被形式化为阈值行为。
**证明要点**：(a) 交换论证：若最优解含比率较低者而排除比率较高者，交换后总增益不降、成本不增。(b) 标准子模贪心界。(c) 由 U 对风险的单调性与 gap 的定义直接得到。

**引理 78（注意力预算的稳定性与告警时延界）** 令普通桶容量 B、补充率 r，安全子桶 B_safe 独立。
- (a) 任意长度 W 的窗口内，普通主动次数 ≤ rW + B，故主动率有界。
- (b) 安全告警永不因普通契约而阻塞：`safety_admit` 只检查 `safe_tokens`。
- (c) 若安全告警到达率 λ_s < r，则其队列稳定，且最坏排队等待 ≤ B_safe / r。
- (d) 控制周期延迟 ≤ WCET_v7 + O(1)，与人的回复时间无关（定义 529）。
**证明要点**：(a) 令牌守恒：每次准入消耗 ≥1 令牌，窗口内补充 ≤ rW，初始 ≤ B。(b) 子桶隔离。(c) Lindley 递推给出队列上界，服务率 r 大于到达率 λ_s。(d) 主动契约在异步任务中执行，控制环只做一次入队操作。

**引理 79（信任校准的内点最优）** 设主动次数 n 对 TCE 有两股相反作用：信息增加使可靠度估计误差按 `a·e^{−c1 n}` 下降；打扰与新奇衰减使过度依赖/烦躁按 `b·(1 − e^{−c2 n})` 上升，`a,b,c1,c2 > 0`。则
```
TCE(n) = a·e^{−c1 n} + b·(1 − e^{−c2 n}) + d
```
在 `n* = (1/(c1+c2))·ln(a·c1/(b·c2))` 处取唯一极小（当 `a·c1 > b·c2`）；当 `a·c1 ≤ b·c2` 时 TCE 在 n=0 处最小。因此「更主动」不是单调更好，存在内点最优或「不该主动」的明确边界。
**证明要点**：二阶导数 `TCE'' = a c1² e^{−c1 n} − b c2² e^{−c2 n}`，令其为 0 得驻点，代入一阶条件即得 n*；边界条件给出 n*=0 的情形。

**引理 80（用户测试的泛化界与反博弈必要性）**
- (a) 若 `Π` 有限、留出用户 n 个、预注册主指标与护栏，则以概率 ≥ 1−δ，
```
TCE_deploy ≤ TCE_heldout + sqrt( ln(2|Π|/δ) / (2n) )
```
（Hoeffding + 并集界）。因此留出评估给出的是可发布的置信上界，而非点估计。
- (b) 若测试分数**不含**沉默失败率 SF（例如只用 `Completion − λ·IntRate`），则对任意有限样本存在策略 π_silent：`IntRate = 0`，观测到的完成率可任意接近 1，但 `SF = 1`。故仅由该分数选出的策略可以「零打扰、全沉默失败」。
- (c) 结论：`SF ≤ ε_sf` 不是可选美化项，而是使测试统计量成为部署安全**充分统计量**的必要成分；反事实审计集（低 ASR、歧义、紧急场景）是测量 SF 的唯一入口。
**证明要点**：(a) 标准浓度不等式；(b) 构造 π_silent 在歧义输入上执行默认回退并把该样本标为「未尝试/未计入完成」，于是打扰为零、完成率的分母被策略选择性剔除；(c) 由 (b) 的存在性直接得必要性。

**引理 81（联合退化正确性）** PIC 路由失效 ⇒ 被动 v7；AB 失效 ⇒ 保守静态预算或关闭非安全主动；UTL 不可用 ⇒ 先验阈值与最保守预算。任意组合均不产生 v7 之外的行为。**唯一例外**：UTL 过拟合不会触发上述任一失效，因此必须由定义 532 的护栏与审计集**置位告警**，而不是假装已退化。
**证明要点**：逐项检查退化映射 ρ 的坐标投影；PIC/AB 失效时 `proactive = ∅`，控制环等于 v7；UTL 是离线标定件，缺失时只改参数不改结构，参数落在 v7 clip 范围内即等价 v7。

## 8. 本轮最大风险

**一句话**：主动交互会把「不确定性」转译成对人的打扰，而用户测试又会把「人的偏好」转译成策略的优化目标——当测试缺少沉默失败护栏时，系统可能学会「少问问题、多沉默失败」来讨好测试，形成一种在测试中更受欢迎、在部署中更不可靠的**表演性主动**。
