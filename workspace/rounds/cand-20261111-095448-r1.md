# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim++；灵感循环第 1 轮；本轮灵感：「抓取位姿估计」×「论文发表」）

> 第 54 轮把技能组合推进到动作空间剖面 `α_S` 与云边协同 `γ_ce`。本轮换一个看似无关的视角：**抓取位姿估计**与**论文发表**。二者共享同一个深层结构——**在一个多峰、带等价类、且证据彼此相关（而非独立）的选择问题上，做一个可辩护的接受决定**。抓取器要在 SE(3) 上从多假设中选出可执行位姿；论文要在多假设中选出可发表主张，而审稿人恰好像仿真/边端/真机三类证据一样**相关而非独立**。核心矛盾：H22：抓取位姿分布在物体对称与夹爪对称下退化，top-1 选取消灭了合法的等价类，产生系统性假阴性；H23：多源证据像审稿人一样共享潜在站点偏差，朴素多数投票在 sim-to-real 相关误差下过度自信，把「可复现」误判为「已复现」。

## 0. 直觉与动机

**灵感 1（对称商 → 位姿不是点，而是双陪集）**
直觉：圆柱体的抓取位姿绕轴连续无穷多解，平行夹爪自身还允许绕接近轴翻转 π。把它们当成互不相同的点去匹配，会把正确解判成错误（假阴性）。正确对象不是单个位姿，而是**等价类**：`p ~ g_o · p · g_g^{-1}`。于是估计器的输出应是 `SE(3)` 的**双陪集商空间** `Q = G_o \ SE(3) / G_g` 上的分布。这一步把「估得准不准」重写为「在商空间上覆盖没覆盖」。

**灵感 2（抓取证书 → 从 top-1 到可证覆盖区）**
直觉：部署真正需要的不是分数最高那个位姿，而是一个**经碰撞与力闭合校验的覆盖区域** `Q_cover`，以及该区域成功率下界 `η`。只要选中位姿落在 `Q_cover` 的 `δ_Q` 邻域且力闭合裕度达标即可执行。这把抓取从「排序取第一」变成「发证书」，与第 54 轮的组合证书同构。

**灵感 3（评审式证据聚合 → 相关审稿人与有效样本量）**
直觉：论文由多位审稿人评，机器人抓取由多个仿真种子、边端探针、真机试验评。审稿人不是独立的：同一仿真器的物理近似会让多个种子一起错。等相关下平均票方差是 `(σ²/m)(1+(m-1)ρ̄)`，故**有效样本量** `m_eff = m/(1+(m-1)ρ̄)`，远小于 m。朴素多数投票把 ρ 当 0，会系统性低估方差、放大置信、放宽接受阈值。证据聚合必须显式估计相关矩阵并做「合谋检测」。

**灵感 4（预注册与多场复现 → 抗过拟合的证据纪律）**
直觉：论文发表的核心纪律是**先注册假设与阈值，再看结果**，并要求**多场复现**。抓取基准同样会过拟合：反复在测试场景上调阈值、挑种子。把 `(Π, Θ)` 在评估前哈希承诺，并要求至少 `r` 个独立站点的成功率下界达标，可把「发不发表」与「可不可部署」统一到同一证据标准。

**灵感 5（证据-几何层 → 金字塔升级为三证书体系）**
直觉：在 L1 几何感知之上加入 **证据-几何层 EGL**，把第 54 轮的「动作-鲁棒性双证书」升级为 **动作-鲁棒性-证据三证书**：`ρ`（鲁棒谱）、`A_cert`（动作占用）、`E`（发表级证据）。跨层迁移时，三者必须同时满足，否则拒绝。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（位姿双陪集等价类）**
物体对称群 `G_o ⊂ SE(3)`（回转体为连续 `S^1`，长方体为离散 `D_2` 等），夹爪对称群 `G_g ⊂ SE(3)`（平行夹爪绕接近轴 π，吸盘绕轴连续 `S^1`）。抓取位姿 `p ∈ SE(3)` 上定义等价关系
```
p ~ p'  ⟺  ∃ g_o ∈ G_o, g_g ∈ G_g :  p' = g_o · p · g_g^{-1}
```
等价类构成双陪集空间 `Q = G_o \ SE(3) / G_g`。代表映射 `κ: SE(3) → Q` 取最小范数/字典序代表。商度量
```
d_Q([p],[p']) = min_{g_o∈G_o, g_g∈G_g} d_SE3(g_o · p · g_g^{-1}, p')
```

**定义 122（抓取证书）**
给定估计器假设集 `H = {(p_i, s_i)}` 与商聚类 `{C_j}`。抓取证书
```
GC = (Q_cover, δ_Q, η, μ_min)
```
- `Q_cover ⊆ Q`：通过碰撞检测与力闭合校验的已证抓取区域；
- `δ_Q`：商度量容差，`κ(p*)` 落在 `Q_cover` 的 `δ_Q`-邻域即算覆盖；
- `η`：标定得到的成功率下界；
- `μ_min`：力闭合裕度下限。
部署条件：`κ(p_sel) ∈ Q_cover ∧ force_margin(p_sel) ≥ μ_min`。

**定义 123（相关审稿式证据聚合）**
证据源 `R_1,…,R_m`（仿真种子、边端探针、真机试验）。审稿人 `R_j` 对抓取主张投 `y_j ∈ {0,1}`，可靠度 `α_j = P(y_j = label)`，两两相关 `ρ_{jk}`。潜在站点偏差 `z` 使误差条件相关：`y_j = label ⊕ (z ∧ b_j)`。等相关近似下平均票方差与有效样本量为
```
Var(ȳ) = (σ²/m)(1 + (m-1)ρ̄),    m_eff = m / (1 + (m-1)ρ̄)
```
证据证书 `RC = (P_acc, m_eff, ρ̂, e_cal)`，其中 `ρ̂` 为相关矩阵估计，`e_cal` 为校准误差。

**定义 124（预注册承诺）**
主张在观测评估数据前固定协议与阈值 `(Π, Θ)`，`Θ = (ε, μ_min, η_min, δ_max, p_min)`，并发布哈希承诺 `h = H(Π, Θ)`。评估时若修改 `(Π, Θ)`、复用测试集调参或选择性报告站点，则证据证书失效。这把「发表纪律」形式化为**不可事后调阈值**的约束。

**定义 125（多场复现证书）**
`K` 个在给定潜变量下可交换的站点（种子、物体实例、光照、边端节点），站点 `k` 观测 `(n_k, s_k)`。主张在置信度 `1-γ` 下**可复现**当且仅当至少 `r` 个站点的 Clopper–Pearson 下界满足 `LCB_k ≥ η_min`：
```
Repl = (reproducible, r̂, min_k LCB_k, {LCB_k})
```

**定义 126（发表级证据证书 PEC）**
`E = (GC, RC, Prereg, Repl, Explain)`。当且仅当
```
Prereg 有效 ∧ RC.P_acc ≥ p_min ∧ λ_max(ρ̂) ≤ λ_thr
∧ Repl.reproducible ∧ GC.η ≥ η_min
```
时 `decide(E) = accept`。这给出「可发表」与「可部署」共享的**同一证据标准**：接受一个抓取主张 = 接受一个可被复核、可被多场复现、且对称等价类被正确计价的位姿主张。

## 2. 关键算法 伪代码

### IP-121 GSQ（Grasp Symmetry Quotient）

```python
def effective_symmetry(obj, gripper):
    G_o = object_symmetry_group(obj)        # 连续 S^1 / 离散 D_2 ...
    G_g = gripper_symmetry_group(gripper)   # 平行夹爪 π / 吸盘 S^1
    return DoubleCosetGroup(G_o, G_g)

def canonicalize(p, G):
    best = None
    for g_o in G.reps_o(p):
        for g_g in G.reps_g(p):
            q = g_o @ p @ inv(g_g)
            best = q if best is None or lex_less(q, best) else best
    return best                              # κ(p)

def quotient_metric(p, p2, G, d_SE3):
    return min(d_SE3(g_o @ p @ inv(g_g), p2)
               for g_o, g_g in G.pairs(p, p2))

def quotient_cluster(H, G, eps):
    reps = [canonicalize(p, G) for p, s in H]
    return cluster(reps, eps, metric=lambda a, b: quotient_metric(a, b, G, d_SE3))
```

### IP-122 GCC（Grasp Certificate Construction）

```python
def grasp_certificate(clusters, obj, gripper, eps, mu_min, tau_score):
    Q_cover = []
    for c in clusters:
        if c.score < tau_score:
            continue
        p = c.rep
        if collision_free(p, obj) and force_closure_margin(p, obj, gripper) >= mu_min:
            Q_cover.append(p)
    if not Q_cover:
        return ('reject', 'no_certified_grasp')
    eta = lower_bound_success(Q_cover, calibration)
    return ('ok', GraspCert(Q_cover, delta_Q=eps, eta=eta,
                            force_margin=min_margin(Q_cover)))
```

### IP-123 RAG（Reviewer Aggregation）

```python
def review_aggregate(votes, reliability, corr_matrix, prior_logit):
    m = len(votes)
    w = [logit(a) for a in reliability]           # 可靠度 → log-odds 权重
    rho_bar = (corr_matrix.sum() - m) / (m * (m - 1)) if m > 1 else 0.0
    m_eff = m / (1 + (m - 1) * rho_bar)
    score = prior_logit + sum(w[j] * (2 * votes[j] - 1) for j in range(m))
    sigma = sqrt(1.0 / m_eff)                      # 相关膨胀后的不确定度
    p_acc = sigmoid(score / max(sigma, 1e-6))
    return ReviewCert(p_acc, m_eff, rho_bar, calibration_error(votes))

def detect_collusion(corr_matrix, lam_thr):
    return max_eigenvalue(corr_matrix) > lam_thr   # 共享偏差/合谋告警
```

### IP-124 PRE（Preregistration）

```python
def preregister(protocol, thresholds):
    commit = sha256(canonical_json(protocol, thresholds))
    return Prereg(commit, protocol, thresholds)

def verify_prereg(prereg, protocol, thresholds):
    return sha256(canonical_json(protocol, thresholds)) == prereg.commit

def evaluate(prereg, data, claim):
    if not verify_prereg(prereg, claim.protocol, claim.thresholds):
        return ('invalid', 'post_hoc_tuning')
    return claim.evaluate(data, prereg.thresholds)
```

### IP-125 MRS（Multi-site Replication Score）

```python
def replication_score(site_results, r_required, eta_min, conf):
    lcbs = {k: clopper_pearson_lcb(s, n, conf)
            for k, (s, n) in site_results.items()}
    pass_sites = sum(1 for v in lcbs.values() if v >= eta_min)
    return ReplCert(reproducible=(pass_sites >= r_required),
                    r_hat=pass_sites, min_lcb=min(lcbs.values()), lcbs=lcbs)
```

### IP-126 PEC（Publication-grade Evidence Certificate）

```python
def publication_evidence_certificate(gc, rc, prereg, repl, explain, cfg):
    if prereg is None or not prereg.valid:
        return ('reject', 'no_prereg')
    if gc is None or gc.eta < cfg.eta_min:
        return ('reject', 'grasp_not_certified', gc)
    if rc.p_acc < cfg.p_min:
        return ('reject', 'review_not_accepted', rc)
    if detect_collusion(rc.corr_matrix, cfg.lam_thr):
        return ('reject', 'reviewer_collusion', rc)
    if not repl.reproducible:
        return ('reject', 'not_reproducible', repl)
    return ('ok', PEC(gc, rc, prereg, repl, explain))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| GSQ | `O(|H|·|G_o|·|G_g| + |H| log|H|)` | `O(|H|)` | κ 商映射良定义、商度量满足三角不等式 |
| GCC | `O(|Q_cover|·(c_col + c_fc))` | `O(|Q_cover|)` | 碰撞/力闭合校验 sound |
| RAG | `O(m² + m log m)` | `O(m²)` | `ρ̂` 估计无偏、`m_eff` 正确收缩 |
| PRE | `O(1)` 哈希 | `O(1)` | 哈希碰撞可忽略、协议冻结 |
| MRS | `O(K·n)` | `O(K)` | Clopper–Pearson 区间保守有效 |
| PEC | `O(组件之和)` | 同上 | 子证书 sound + 合取保持 sound |

**命题 1（相关审稿的过度自信）**
若审稿误差等相关 `ρ̄ > 0`，朴素独立聚合把方差估为 `σ²/m`，而真实方差为 `σ²(1+(m-1)ρ̄)/m`，故置信区间被低估因子 `1+(m-1)ρ̄`，接受阈值被系统性放宽；站点越多、相关性越强，过度自信越严重。

**定理（对称-证据联合 soundness）**
假设 (A29) `G_eff` 既不遗漏也不过度归并物体/夹爪对称性；(A30) 站点潜在偏差模型成立且 `|ρ̂ - ρ| ≤ ε_ρ`；(A31) 预注册哈希在评估前提交且协议被遵守；(A32) 各站点在给定潜变量下可交换。则
```
P_deploy ≥ (1 - β_sym) · (1 - β_agg) · min_k LCB_k - β_E
```
其中 `β_sym = P(κ 归并非等价位姿)`，`β_agg = f(ε_ρ, e_cal)` 为相关性与校准误差导致的接受偏差，`β_E` 为边端执行噪声。关键：**商化保证召回，相关校正保证置信，预注册+复现保证主张不可被事后挑选**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 对称群过识别（把非对称件当对称） | 高 | 多视角一致性校验 + 商外反例探针 |
| 评审相关性估计偏差（站点太少） | 高 | 分层贝叶斯 + 增加站点多样性 + 合谋告警 |
| 预注册抑制必要迭代 | 中 | 探索/确认两阶段预注册 |
| 商度量病态、代表选择不稳 | 中 | 局部李代数度量 + 代表稳定性检查 |
| 复现站点非可交换（域偏移） | 高 | 按域标签分层抽样 + 域外站点显式建模 |

## 6. 本轮最大风险

**一句话**：对称商 + 相关证据证书把抓取从「排序取第一」升级为「可复核的覆盖与置信」，但其 soundness 同时依赖**对称群没有被过识别、审稿相关性被正确估计、预注册规则没有被事后绕过**；一旦把非对称/被遮挡的可形变物体误并入等价类，`Q_cover` 会以「对称等价」为名覆盖真实不可行的位姿，且所有下游证书都会一致地通过，故必须以 **多视角对称性验证 + 商外反例探针 + 相关性合谋检测** 三重护栏，宁可少覆盖，也绝不把「对称假象」当成可部署证据。

```python
def review_aggregate(votes, reliability, corr_matrix, prior_logit):
    m = len(votes)
    w = [logit(a) for a in reliability]
    rho_bar = (corr_matrix.sum() - m) / (m * (m - 1)) if m > 1 else 0.0
    m_eff = m / (1 + (m - 1) * rho_bar)
    score = prior_logit + sum(w[j] * (2 * votes[j] - 1) for j in range(m))
    p_acc = sigmoid(score / max(sqrt(1.0 / m_eff), 1e-6))
    return ReviewCert(p_acc, m_eff, rho_bar, calibration_error(votes))

def detect_collusion(corr_matrix, lam_thr):
    return max_eigenvalue(corr_matrix) > lam_thr
```

### IP-126 PEC

```python
def publication_evidence_certificate(gc, rc, prereg, repl, explain, cfg):
    if prereg is None or not prereg.valid:
        return ('reject', 'no_prereg')
    if gc is None or gc.eta < cfg.eta_min:
        return ('reject', 'grasp_not_certified', gc)
    if rc.p_acc < cfg.p_min:
        return ('reject', 'review_not_accepted', rc)
    if detect_collusion(rc.corr_matrix, cfg.lam_thr):
        return ('reject', 'reviewer_collusion', rc)
    if not repl.reproducible:
        return ('reject', 'not_reproducible', repl)
    return ('ok', PEC(gc, rc, prereg, repl, explain))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| GSQ | `O(|H|·|G_o|·|G_g| + |H|log|H|)` | `O(|H|)` | κ 良定义、`d_Q` 为伪度量 |
| GCC | `O(|Q_cover|·(c_col+c_fc))` | `O(|Q_cover|)` | 力闭合/碰撞校验 sound |
| RAG | `O(m² + m log m)` | `O(m²)` | `ρ̂` 近似无偏、`m_eff` 收缩 |
| PRE | `O(1)` | `O(1)` | 哈希承诺、协议冻结 |
| MRS | `O(K·n)` | `O(K)` | CP 区间保守 |
| PEC | `O(子组件之和)` | 同上 | 合取保持 sound |

**命题 1（相关审稿过度自信）**
等相关 `ρ̄>0` 时，真实方差 `σ²(1+(m-1)ρ̄)/m` 相对朴素估计 `σ²/m` 被低估因子 `1+(m-1)ρ̄`，故独立多数投票会系统性放宽接受阈值。

**定理（对称-证据联合 soundness）**
假设 (A29) `G_eff` 不过识别/不遗漏对称性；(A30) `|ρ̂-ρ|≤ε_ρ`；(A31) 预注册先于评估且被遵守；(A32) 站点在给定潜变量下可交换。则
```
P_deploy ≥ (1 - β_sym)·(1 - β_agg)·min_k LCB_k - β_E
```
其中 `β_sym=P(κ 归并非等价位姿)`，`β_agg=f(ε_ρ,e_cal)`，`β_E` 为执行噪声。关键：**商化保召回、相关校正保置信、预注册+复现保主张不被事后挑选**。

## 5. 本轮最大风险

**一句话**：对称商 + 相关证据证书把抓取从「排序取第一」升级为「可复核的覆盖与置信」，但其 soundness 同时依赖**对称群没有被过识别、审稿相关性被正确估计、预注册规则没有被事后绕过**；一旦把非对称/被遮挡的可形变物体误并入等价类，`Q_cover` 会以「对称等价」为名覆盖真实不可行的位姿，且所有下游证书都会一致地通过，故必须以 **多视角对称性验证 + 商外反例探针 + 相关性合谋检测** 三重护栏，宁可少覆盖，也绝不把「对称假象」当成可部署证据。
