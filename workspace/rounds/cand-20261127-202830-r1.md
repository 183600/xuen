### 第 3 轮灵感驱动研究记录

**灵感词**：三维感知、决策规划

**继承关系**：第 2 轮 CADVS-v2（IP-481~484）用三个证据锚点（空间 Γ_3D、物理 S2RC、人因 HIC）修补了 v1 的 R36 证据链断裂，但也留下一个未被命名的结构性盲点：**所有锚点都只在「决策时刻」做一次性点检查**。v2 的 Γ_3D(x,t) 只在查询瞬间求值，默认「此刻通过 ⟹ 执行期间一直通过」。然而覆盖分的新近项 r_k = e^{−(t−t_k)/τ_rec} 随时间单调衰减，证书是会**过期**的易腐品；v2 从未显式检查「执行到那一步时，这张证书是否还活着」。本轮不推翻 v2，而是把证据从**门控谓词**升级为**可规划、会过期、可续期的时空资源**，形成 CADVS-v3（IP-485~488）。执行集关系升级为「固定覆盖场下逐点嵌套」：对任意同一 Γ，Exec_v3(Γ) ⊆ Exec_v2(Γ) ⊆ Exec_v1(Γ) ⊆ Exec_v29；主动取证只通过安全动作改变 Γ，绝不放松门。

**直觉与动机**：

1. **三维感知：给每张证书打上「保质期」**。3DCF 的每个体素早已存了 (n_k, t_k, q̄_k)，v2 只用了它们的当前值，浪费了 t_k 携带的时间信息。把覆盖分沿未来时间外推，可以精确算出「这个体素还能在多久内支撑 γ_Γ」——**证据地平线** T_ev。关键结论（引理 38）：在把 n̂、q̄ 显式截断到 [0,1] 之后，**任何能通过覆盖门的证书，寿命都不超过 17.4 s**（缺省 τ_rec = 30 s、γ_Γ = 0.95）；而一个「刚好过门」的体素（如 n=37, q̄=1）寿命只有 **0.19 s**。也就是说，v2 会把一条耗时 10 s 的计划放心地压在 0.2 s 后就失效的证据上。三维感知第一次让我们能对「证据还剩多久」给出闭式答案，而不是笼统的「最近观测过」。这也顺带修掉 v2 代码里 n̂ = n/n_sat 未截断、理论上无限观测可使覆盖永不衰减的归一化缺陷。

2. **决策规划：把规划问题变成「易腐证书的时空调度」**。既然证书会过期，那么一条耗时超过 T_ev 的计划在执行后半段时，前半段建立的证据已经作废——v2 只能在执行中才发现覆盖门关闭，被迫急停或教师接管。v3 把「续证」提前进规划：沿轨迹预测每个依赖证书的时空点，在到达那一刻是否仍然有效；若否，就在失效前插入一个「观察点」（next-best-view），让机器人先去看一眼再继续。类比：**证书是带有效期的签证，规划要在时空证据地图上找一条签证始终有效的路径，观察点就是续签点**。这把 v2 的「被动回退」变成 v3 的「主动续证」，也让「决策规划」第一次直接作用于感知资源，而不只是作用于几何路径。

3. **决策规划之二：取证本身是行动，也必须被证书约束**。主动取证会移动机器人、伸出机械臂，把「信息不足」转化为「运动风险」——越缺证据越要冒险去看，可能形成正反馈。因此 v3 规定：取证动作必须属于一个**已验证安全探索原语集 E_safe**，其安全性只依赖当前帧直接测得的局部几何（**局部几何证书 LGC**），不依赖待获取的 Γ_3D。这为「所有行动都要证书」提供了**基例**，避免无限回退（要证书→要取证→取证也要证书→…）。同时引入**证据预算 B_ev** 与势函数终止条件，防止「取证活锁」（分析瘫痪）。

**关键洞见**：v1 问「证书是否通过」，v2 问「证书是否有证据支撑」，v3 问「**证书在需要它的那一刻是否仍然有证据支撑，以及为了让它有，机器人该先做什么**」。这把安全从「瞬时谓词」推进到「时空契约」：决策规划的输出不再只是一条轨迹，而是一条**带续证点的轨迹 + 一张按证书结果分支的策略树**。安全单调性不被主动感知破坏：对固定 Γ，v3 的每条路径仍要过 v2 的三锚点硬门；主动感知只是通过 E_safe 动作改变 Γ，让原本不可行的计划在**证据真的到手之后**才变得可行。这样，「扩展执行集」与「安全只缩不涨」不再矛盾：变的是世界（证据），不是门。

**形式化目标（增量）**：
1. 定义预测覆盖场 Γ_3D(x,t+Δ)（无新观测时的衰减外推）与证据地平线 T_ev(x,t) = sup{Δ ≥ 0 : Γ_3D(x,t+Δ) ≥ γ_Γ}，给出闭式解 t_exp = t_k + τ_rec·ln(0.3/B_k) 与硬上界 T_ev ≤ 17.4 s，其中 B_k = s* − 0.5n̂_k − 0.2q̄_k。
2. 定义局部几何证书 LGC = (d_min, v, δ_stop(v), verdict) 与安全探索原语集 E_safe，作为取证链的基例；定义 E_safe 动作只读当前深度帧、不读 Γ_3D。
3. 定义证书条件规划问题 CCP(Γ, G, R, H, B_ev)：在证书时空有效约束下最小化「任务代价 + 风险 + 取证代价」；定义证书缺口泛函 D(π) 与续证点集 W_renew。
4. 定义主动取证规划 AEAP：在缺口时空点做 next-best-view，最大化「单位代价的期望缺口缩减」；定义证书条件策略树 CCDP，按续证结果 {pass, fail, inconclusive} 分支。
5. 定义证据预算 EBM 与终止条件；证明 (i) 固定 Γ 下 Exec_v3(Γ) ⊆ Exec_v2(Γ)，(ii) 所有提交步骤在执行时刻仍满足三锚点，(iii) LGC 基例切断无限回退，(iv) 预算下规划必终止、无取证活锁。

**本轮最大风险**：**主动取证把「信息不足」转化为「运动风险」**——为了续证而移动或伸臂观察，本身可能把机器人推入覆盖更差、动态障碍更多的区域，形成「越缺证据越冒险取证」的正反馈；若 E_safe 的局部几何基例或 T_ev 的静态世界假设失准，v3 会以「主动获取证据」之名制造比 v2 被动回退更隐蔽、更危险的新失效模式。

## 2. 关键算法骨架

### IP-485 PCC：预测覆盖场与证据地平线

```python
@dataclass
class PredictiveCoverageCertificate:
    """PCC：把 v2 的瞬时覆盖门升级为带过期时刻的时空契约（引理 38）"""
    scf: SpatialCoverageFieldKernel
    gamma_Gamma: float = 0.95
    kappa_s: float = 8.0
    tau_rec: float = 30.0
    tau_dyn: float = 1.0            # 动态体素有效期上限（R42 缓解）

    def s_star(self) -> float:
        return 0.5 + math.log(self.gamma_Gamma / (1 - self.gamma_Gamma)) / self.kappa_s

    def expiry(self, x: np.ndarray) -> float:
        """绝对过期时刻；-inf 表示即使刚观测也无法过门。O(1)。"""
        k = self.scf._hash(x[None, :])[0]
        if k not in self.scf.voxels:
            return -math.inf                       # 盲区
        n, t_last, q_sum = self.scf.voxels[k]
        n_hat = min(n / self.scf.n_sat, 1.0)       # v3 修正：显式截断
        q_bar = min(q_sum / n, 1.0)
        B = self.s_star() - 0.5 * n_hat - 0.2 * q_bar
        if B > 0.3:
            return -math.inf                       # r<=1 也救不回来
        if B <= 0.0:
            return math.inf                        # 截断后不会发生，防御性保留
        t_exp = t_last + self.tau_rec * math.log(0.3 / B)
        if self.scf.is_dynamic.get(k, False):
            t_exp = min(t_exp, t_last + self.tau_dyn)
        return t_exp

    def horizon(self, x, t_now) -> float:
        return max(0.0, self.expiry(x) - t_now)

    def valid_at(self, x, t_exec) -> bool:
        """执行时刻是否仍在保质期内；供 EFA.hard_gate_at 调用"""
        return t_exec <= self.expiry(x)

    def max_lifetime(self) -> float:
        """引理 38：任何可通过证书的寿命上界（缺省 17.4 s）"""
        return self.tau_rec * math.log(0.3 / (self.s_star() - 0.7))
```

### IP-486 AEAP：主动取证 + LGC 基例

```python
@dataclass
class LocalGeometryKernel:
    """LGC：无限回退的基例——安全性只依赖当前帧直接测得的深度几何"""
    depth: np.ndarray
    K: np.ndarray
    delta_stop: Callable[[float], float]     # v2 MSRG.stop_envelope 的保守下包络
    margin: float = 0.05

    def safe(self, viewpoint, v: float) -> bool:
        d_min = self._min_depth_along_path(viewpoint)   # 实测，不经过 Γ_3D
        return d_min > self.delta_stop(v) + self.margin

@dataclass
class ActiveEvidenceAcquisitionPlanner:
    """AEAP：在证书缺口处做 next-best-view；取证动作受 E_safe/LGC 约束"""
    scf: SpatialCoverageFieldKernel
    pcc: PredictiveCoverageCertificate
    lgk: LocalGeometryKernel
    v_exp: float = 0.3
    n_candidates: int = 64
    min_gain: float = 1e-3

    def deficit_points(self, rollout, t0):
        """rollout: [(tau, x)]；返回执行时已过期的时空点"""
        return [(tau, x) for tau, x in rollout
                if not self.pcc.valid_at(x, t0 + tau)]

    def next_best_view(self, deficit, t0, budget_remaining):
        cands = self._sample_reachable_viewpoints(deficit, t0, budget_remaining)
        best, best_score = None, 0.0
        for v in cands:
            if not self.lgk.safe(v, self.v_exp):    # 基例：只读当前帧实测几何
                continue                            # 不允许「为了取证而冒险」
            travel = self._travel_time(v)
            if travel > budget_remaining:
                continue
            gain = self._expected_deficit_reduction(v, deficit) / max(travel, 1e-6)
            if gain > best_score:
                best, best_score = v, gain
        if best_score < self.min_gain:
            return None, 0.0                        # 无增益 → 交 EBM 回退
        return best, best_score
```

### IP-487 CCDP：证书条件策略树（风险敏感）

```python
@dataclass
class CertificateContingentDecisionPlanner:
    """CCDP：在证书结果上分支的 receding-horizon 策略树"""
    pcc: PredictiveCoverageCertificate
    aeap: ActiveEvidenceAcquisitionPlanner
    efa: EvidenceForgingAssembler
    ebm: 'EvidenceBudgetManager'
    horizon: float = 2.0
    dt: float = 0.1
    cvar_alpha: float = 0.9
    lam_risk: float = 5.0

    def plan(self, x0, goal, t0):
        root = {'act': None, 'children': {}, 'p': 1.0}
        stack = [(x0, t0, root)]
        while stack and not self.ebm.exhausted():
            x, t, node = stack.pop()
            rollout = self._task_rollout(x, goal, t, self.horizon)
            deficit = self.aeap.deficit_points(rollout, t)
            if not deficit:
                # 截断到最早过期时刻之前，保证提交前缀全程有效
                node['act'] = ('commit', self._truncate_to_min_expiry(rollout, t))
                continue
            v, score = self.aeap.next_best_view(deficit, t, self.ebm.remaining())
            if v is None:
                node['act'] = ('fallback', self.efa.safe_set(x, t))
                continue
            node['act'] = ('acquire', v)
            self.ebm.charge(self.aeap.travel_time(v), self.aeap.energy(v))
            for outcome, p in self._outcomes(v):     # pass / fail / inconclusive
                child = {'act': None, 'children': {}, 'p': p}
                node['children'][outcome] = child
                stack.append((v, t + self.aeap.travel_time(v), child))
        return root

    def risk(self, tree) -> float:
        """CVaR_α：对缺口最坏 1−α 尾部分支做风险约束"""
        deficits, probs = self._leaf_deficits(tree)
        return cvar(deficits, probs, self.cvar_alpha)
```

### IP-488 EBM：证据预算与终止

```python
@dataclass
class EvidenceBudgetManager:
    """EBM：有限预算保证终止，杜绝取证活锁（引理 40）"""
    B_time: float = 3.0
    B_energy: float = 50.0
    spent_time: float = 0.0
    spent_energy: float = 0.0

    def charge(self, dt: float, de: float):
        self.spent_time += dt
        self.spent_energy += de

    def exhausted(self) -> bool:
        return self.spent_time >= self.B_time or self.spent_energy >= self.B_energy

    def remaining(self) -> float:
        return max(0.0, self.B_time - self.spent_time)
```

### 集成流水线（v2 → v3）

```
在线重规划环（5–10 Hz，与 200 Hz 控制环解耦）：
  CCDP.plan(x0, goal, t0)
    ├─ 任务 rollout ──▶ AEAP.deficit_points
    │        ├─ 无缺口 → commit（截断到 min_k t_exp(k) 之前）
    │        └─ 有缺口 → AEAP.next_best_view
    │                 ├─ LGC 安全 ∧ 预算足够 → 插入续证点
    │                 │     └─ 按 pass / fail / inconclusive 分支成策略树
    │                 └─ 无安全视角 / 增益 < ε → EFA.safe_set（v2 兜底）
 每一步执行前（200 Hz 控制环，O(1)）：
    EFA.hard_gate_at(x, t_exec, rule, hic)
      = ¬veto(HIC) ∧ PCC.valid_at(x, t_exec) ∧ S2RC(rule).valid_at(t_exec)
    HIC STOP 优先：直接剪枝到 S_stop，取消所有续证分支
 记账：EBM.charge；预算耗尽 → 强制回退并上报 TCVM
```

| PCC expiry / valid_at | **O(1)** | O(1) | — | < 0.01 ms |
| PCC 沿 rollout 扫描 | O(H/Δt) | O(1) | H=2 s, Δt=0.1 s | < 0.1 ms |
| AEAP 缺口扫描 | O(H/Δt) | O(H/Δt) | 同上 | < 0.1 ms |
| AEAP next-best-view | O(N_cand·V_vis + N_cand log N_cand) | O(V_vis) | N_cand=64, V_vis≈10³ | < 1.5 ms |
| CCDP 策略树 | O(b^d·H/Δt)（概率剪枝） | O(b^d) | d ≤ B_time/τ_step ≈ 10 | 2–7 ms @5 Hz |
| EBM 记账 | **O(1)** | O(1) | — | < 0.001 ms |
| 在线执行门 hard_gate_at | **O(1)** | O(1) | — | 不劣化 v2 的 P99 < 8 ms |
| 教师兜底 | ≤ 20 ms | 同 v29 | — | 不劣化 v2 |

**通信开销**：新增证书字段为 `t_exp`（8 B）与续证点（约 0.1 KB/次，低频），S2RC 增加 `horizon`（8 B）与 `theta_fingerprint`（约 1 KB，低频重发）；总计增量 < 0.5 MB/s，与 v2 同量级。

## 4. 正确性论证（增量更新）

### 引理 38（证据地平线的闭式解与硬寿命上界）

**陈述**：设 n̂_k = min(n_k/n_sat,1), q̄_k = min(q̄_sum/n_k,1)，s* = 0.5 + (1/κ_s)ln(γ_Γ/(1−γ_Γ))，B_k = s* − 0.5n̂_k − 0.2q̄_k。则对体素 k：

1. 若 B_k > 0.3，则无论多新，该体素都无法过覆盖门（返回 t_exp = −∞）；
2. 若 0 < B_k ≤ 0.3，则绝对过期时刻为 **t_exp = t_k + τ_rec·ln(0.3/B_k)**，剩余寿命 T_ev = t_exp − t ∈ (0, T_ev^max]；
3. **硬上界** T_ev^max = τ_rec·ln(0.3/(s*−0.7)) = 17.4 s（缺省参数），与观测次数、质量无关。

**证明**：固定 n̂、q̄，Γ_3D(x,t+Δ) = σ(κ_s(s(Δ)−0.5))，其中 s(Δ) = 0.5n̂ + 0.3e^{−(t+Δ−t_k)/τ_rec} + 0.2q̄ 关于 Δ 严格递减。过门 ⟺ s(Δ) ≥ s* ⟺ e^{−(t+Δ−t_k)/τ_rec} ≥ B_k/0.3。若 B_k > 0.3，右端 > 1，无解；否则 Δ ≤ τ_rec ln(0.3/B_k) − (t−t_k)，即 t+Δ ≤ t_exp。又因 n̂,q̄ ≤ 1，B_k ≥ s* − 0.7 = 0.1681，故 0.3/B_k ≤ 1.7846，t_exp − t_k ≤ 30·ln(1.7846) = 17.4 s。∎

**推论 38.1（「刚好过门」极短命）**：取 n=37, q̄=1（引理 35 的边界），B = 0.8681 − 0.37 − 0.2 = 0.2981，T_ev = 30·ln(0.3/0.2981) ≈ **0.19 s**。即 v2 的「通过」可能只意味着「0.19 秒后失效」，而 v2 会据此规划一条 10 s 的路径。

**推论 38.2（续证不可避免）**：任何依赖证书的步骤若发生在该体素最近观测后 17.4 s 以上，则**无论过去观测多少次都无法补救**，必须在规划中插入新观测。这把「主动续证」从优化项变成正确性要求。

### 引理 39（主动取证不扩大固定覆盖场下的执行集，且无安全欠账）

**陈述**：设 Γ 为某一时刻的完整覆盖场。(a) Exec_v3(Γ) ⊆ Exec_v2(Γ)。(b) 跨时间看，Exec_v3(Γ(t)) 只有在 Γ 经 E_safe 动作增长后才可能扩张，且每条新准入计划都会在执行时刻被重新门控，因此不存在「先扩张、后补证」的安全欠账。(c) 证书依赖链有良基：E_safe 动作由 LGC 门控，LGC 只读当前深度帧，不读 Γ_3D 或 S2RC，故不存在无限回退。

**证明**：(a) v3 每步谓词为 v2 三锚点 ∧ PCC.valid_at ∧ 预算约束，合取只减不增。(b) 3DCF 只经 `ingest_pointcloud` 改变，而该调用只来自感知动作；AEAP 只准入 E_safe 动作；摄取后 CCDP 重跑、EFA 重新门控，故任何一步都不会在未验证的 Γ 上执行。(c) LGC 的输入为 (depth, K, δ_stop)，与 Γ_3D、S2RC 无依赖，依赖链「任务证书 → 取证 → LGC」终止于直接测量几何。∎

**工程含义**：主动感知带来的「执行集扩张」来自世界状态改变（证据到手），而非门变松；这既保留了 v2 的安全单调性，又让机器人能主动把不可行变可行。

### 引理 40（证据预算下的终止性，无取证活锁）

**陈述**：设每次被接受的取证至少消耗 τ_min > 0 时间。CCDP 在证据预算 B_time 下最多进行 ⌊B_time/τ_min⌋ 轮取证；若 `next_best_view` 返回 None（增益 < ε_gain），该分支立即回退。故规划必终止，不存在无限取证循环。

**证明**：令势函数 Φ = B_time − spent_time。每轮被接受的取证使 spent_time 增加 ≥ τ_min，故 Φ 严格下降 ≥ τ_min；当 Φ < τ_min 时不再有可行取证。被拒绝的取证（增益不足或超出预算）直接转入 fallback 分支，不再展开。动态世界可能因衰减产生新缺口，但预算按**时间**计量，与缺口如何翻新无关，因此上界仍成立。∎

**工程含义**：活锁不是靠「调参希望它停」，而是由有限预算给出的硬终止；ε_gain 只是避免把预算浪费在无效观察上。

### 定理 v3（时空契约下的执行集与主动取证）

**陈述**：在假设 (A1″) 世界在 T_ev 内静态或动态体素已被标记；(A2″) LGC 的深度几何在当前帧可靠（遮挡/噪声受控）；(A3″) S2RC 的 horizon 与 Θ_domain 指纹一致；(A4″) HIC 按 v2 引理 37 部署。则：

(i) 对固定 Γ：Exec_v3(Γ) ⊆ Exec_v2(Γ) ⊆ Exec_v1(Γ) ⊆ Exec_v29；
(ii) 每个提交的证书依赖步骤在其**执行时刻**仍满足三锚点（PCC + 到达重检），从而同时封住 v2 的「空间盲区」与「时间过期」两类证据链断裂；
(iii) 取证动作受 LGC/E_safe 门控，证书依赖链良基，无无限回退；
(iv) 在预算 B_ev 下规划必终止，无取证活锁；
(v) 在长时、覆盖退化任务上成功率高于 v2（实验 §5，仿真测得）。

**证明**：(i) 由引理 39(a)；(ii) 由 `hard_gate_at` 在执行时刻同时检查 `PCC.valid_at` 与 S2RC 有效期，结合 v2 引理 35；(iii) 由引理 39(c)；(iv) 由引理 40；(v) 为仿真实测，见 §5。∎

**诚实声明**：假设并非恒真。(A1″) 是本轮最脆弱假设——T_ev 的闭式解假设世界静态，快速移动的遮挡物会让「17.4 s 内有效」变成高估（见 R42）；(A2″) 受深度噪声与透明/反光表面影响；(A3″) 继承 v2 的 R38 模拟门伪神谕。v3 的应对是把这些假设转为可测量：T_ev 与实测失效时刻的偏差、LGC 误判率、S2RC horizon 与实机迁移误差均入 TCVM 监控。

## 7. 本轮最大风险（最终确认）

**一句话**：**主动取证把「信息不足」转化为「运动风险」**——为了续证而移动或伸臂观察，本身可能把机器人推入覆盖更差、动态障碍更多的区域，形成「越缺证据越冒险取证」的正反馈；若 E_safe 的局部几何基例或 T_ev 的静态世界假设失准，v3 会以「主动获取证据」之名制造比 v2 被动回退更隐蔽、更危险的新失效模式，这是 CADVS-v3 从仿真走向实机部署的生死线。
