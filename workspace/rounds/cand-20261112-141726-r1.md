# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 4 轮；本轮灵感：「轻量化设计」×「开源硬件」）

> 第 57 轮用元先验、跨模态对账、个性化信任把"证据说可信"推到五层纵深；但它自陈的最大风险（坏先验普遍）背后站着一个更朴素的问题：**这套安全架构本身越来越重**——元推断、共形带、四模态分账、信任状态机、J_p 证书，任何一层在真实四足的嵌入式控制器上都可能塞不进控制回路，于是"安全"只能跑在更贵的算力、更少人拥有的平台上。同时，第 57 轮默认硬件是一个可信、均质、封闭的黑盒；可一旦换板、换传感器、换固件版本，所有校准与证书都默默失效。本轮两个灵感正面回应这两点：**轻量化设计**不是删安全，而是把"质量"从在线关键路径搬到离线生成端——重推理保持纵深、允许慢、允许错、允许被审；在线只留一个**最小可信内核（LSK）**，检查**证明携带承诺（PCC-L）**。**开源硬件**不是无条件信任，而是把信任对象从"厂商/外观"换成"**可度量的物料 + 可复现的构建 + 可公开验证的透明日志**"：证书绑定开源物料清单（OBOM）与硬件根度量，异构板靠**硬件分层共形**（PCH）保持校准覆盖，供应链靠**N-版本交叉核验 + 防降级**（OSH-G）兜底。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"轻、可验、可携带的证书说可信"**：纵深留在生成端，轻量留在检查端，信任根从模型转到规范与度量。

核心矛盾：
- **H29（轻量 vs 纵深）**：安全靠多层独立防线，但每层都要算力、时延、传感器与人力维护；真实边缘平台放不下五层在线检查，粗暴裁剪又会把"独立"裁成"单点"。轻量化的难点不是减少代码，而是证明"删到哪一层仍然充分"。
- **H30（开放 vs 对抗）**：开源硬件让蓝图、固件、检查器全部公开——这既是可审计、可复现、可社区验证的前提，也把精确的攻击面交到对手手里；开放供应链还会带来克隆件、替换件、固件回滚与恶意分叉，"看起来一样"恰恰是最危险的证据。
- **H31（异构 vs 校准）**：第 57 轮的共形带与元校准是对某一块板、某个传感器噪声谱拟合的；开源硬件意味着同一算法跑在几十种板上。证书若不能声明并验证"它在哪种硬件层上成立"，跨板迁移时覆盖率会静默崩塌。

## 0. 直觉与动机

**灵感 1（轻量化设计 → 生成/检查分离与证明携带承诺）**
直觉：过去三轮在给机器人穿一件越来越厚的"安全外骨骼"——理论上更抗打，但重到走不动。轻量化设计的工程直觉不是"少穿点、裸奔"，而是**把质量挪出关键路径**：结构上受力的地方用最少的材料，非关键处能空就空。对应到信任系统：把"会犯错但可以慢"的重推理（元推断、跨模态融合、规划）挪到离线/云/旁路，让它们**生产证书**而不是**生产决定**；在线只留一个极小的检查器，它不懂材质、不跑神经网络，只逐条核对"这份承诺是否附带了可验证的证据与度量"。这像建筑验收：设计师的复杂计算在事务所完成，现场验收员只核对一小组结构不变量。算力质量骤降，保证却不降——因为系统不再"相信"复杂模型，而是"检查它的产物"。这正是证明携带代码（PCC）/可认证算法的思路。

**灵感 2（开源硬件 → 物料绑定、可复现构建与透明日志）**
直觉：开源硬件把图纸公开，等于把"信任谁"这个问题从"信厂商品牌"改成"信可核对的事实"。开放是双刃：人人能审计，也人人能克隆。因此证书不能只说"我在某型号机器人上成立"，而要携带**开源物料清单摘要 + 固件摘要 + 度量启动链 + 透明日志索引**，并由硬件根签名。任何人（包括第三方审计者、对手）都能验证这份绑定；而"换了一块同型号的板""刷了旧版固件""用了未验证的分叉"都会变成**不同的硬件层**，自动落入需要重新校准或直接降级的分支。开源在这里不是放宽信任，而是把信任变成**可验证性**。

**灵感 3（开源 × 轻量 → 多样性作为廉价的冗余）**
直觉：传统纵深靠"同一系统多跑几遍"（贵的冗余）。开源硬件提供另一种冗余：**独立实现**。两个不同团队、不同编译器、不同算法写出的检查器/驱动，对同一证书给出相同判定，比一个巨无霸模型自证可信便宜得多，也更难被单点后门同时攻破。轻量化的极致不是"更少的检查"，而是"更少但彼此独立的检查"。

**灵感 4（轻量 × 第 57 轮 → 最小充分证据集与硬禁令）**
直觉：第 57 轮证据门有五类证据、多重佐证、元校准证书；但并非所有证据都对"防假承诺"有独立贡献。轻量化要做的，是在**假承诺预算 δ_f 的约束下**求解一个最小证据子集 ℰ\*：删掉一条证据必须能论证它不增加假承诺，否则不许删。硬禁令（EV-xmodal 仅限 L1、无 attestation 不承诺、不可逆接触不含跨模态、OOD 未建带禁 EV-probe）永远不可被"优化掉"。这叫"轻在可省处，重在不可省处"。

**灵感 5（轻量探-诺-演 → 证书是硬门槛，降级是默认）**
直觉：第 57 轮 PCE+ 用 VOI 决定探不探。本轮把"证书可验证"放在 VOI 之前，作为不可协商的硬门槛：证书验不过、attestation 失败、落在可移植域外、N-版本不一致——任一发生就**单调降级**（绕行→安全停），而不是"再赌一次探针"。降级模式（无云、无证明）只允许第 56 轮最保守的本地子集；云回来后再离线补证书。这样"轻"不牺牲"稳"：宁可慢、宁可绕，绝不在未验证下承诺。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（轻量证明携带承诺 PCC-L 与最小可信内核 LSK）** 重生成器 𝔾（不可信：可离线、可冗余、可错）对每个承诺 σ 产出证书 C=⟨σ, 约束摘要, 证据摘要与传感器签名, 校准摘要, attestation 引用, OBOM 摘要 h, 透明日志索引, 资源声明⟩。在线可信内核 V（LSK）实现谓词族 V={v_1..v_m}，承诺允许 ⇔ V(C,s)=1。健全性：V 接受 ⇒ 第 57 轮约束以 ≥1−δ_f 成立，且 V **不依赖 q_φ 的校准声明**，只依赖可独立核验的证据摘要与硬件度量。最小充分性：∀i，删除 v_i 存在反例使 P(fail)>δ_f。资源契约：TCB 代码 ≤L_max、单次检查 ≤τ_chk、能耗 ≤e_max，作为 C 的显式声明并受审计。**生成-检查解耦**：重模型的 ε_meta 只影响接受率与效率，不影响承诺健全性（除非它能伪造传感器签名，这被 attestation 与物理证据类覆盖）。

**定义 140（开源物料证明 HAB）** 硬件指纹 h=H(OBOM_digest ‖ fw_digest ‖ measured_boot ‖ component_IDs)，由设备身份密钥签名。证书 C 携带 h 与假设集 H_assume（哪些组件/版本被纳入信任、哪些只当数据）。度量链 ROM→bootloader→OS→runtime 逐级扩展；透明日志 TL 为 append-only，固件/物料变更追加并给出一致性证明，C 引用 TL 索引。h 无效或链断 ⇒ 证书不可接受。攻击者被假定知晓 V 与协议（Kerckhoffs），安全只来自密钥、度量与透明性。

**定义 141（硬件分层可移植校准 PCH）** 观测 y=f(θ,h)+ε(h)，硬件自表征 φ(h)=(噪声谱, 量化, 时延, 温漂, 安装偏差)。对可移植域 𝒫_h 内的层，用 Mondrian/加权共形构造 C_α(z,φ(h))，要求同层覆盖 ≥1−α_conf；跨板留一移植测试：若目标板覆盖下降 >Δ_port，则拒绝该证书的移植并降级。校准摘要（非原始数据）随 C 携带，保持轻量。

**定义 142（开源供应链护栏 OSH-G）** 四规则：(G1) N-版本交叉核验：≥2 个独立实现（不同开发方/编译器/算法）对 C 的关键字段一致，否则隔离；(G2) 可复现构建：源码+工具链 ⇒ 二进制哈希一致，否则视为不可信变体；(G3) 防降级：单调版本计数器，更新后旧固件/旧证书不再被接受；(G4) 分叉隔离：未验证 fork 先影子运行，未过回归（ECE 不劣化 ∧ OOD 检出率不降 ∧ 假接受不增）不得接管。任一规则失败 ⇒ 单调趋向降级。

**定义 143（最小充分证据集 MSES，升级 FSE）** 给定第 57 轮证据类 ℰ，在假承诺预算 δ_f 与成本 cost(e)（时延/能耗/传感器占用）下求 ℰ\*⊆ℰ：min Σ_{e∈ℰ\*}cost(e) s.t. false-accept(ℰ\*→V) ≤ δ_f+δ_comp，且每删除一条须给出"不增假接受"的论证。硬禁令集合 ℋ（EV-xmodal 限 L1、attestation 缺失禁承诺、不可逆接触排除 xmodal、OOD 未建带禁 EV-probe）不可删。原始探针流压缩为可验证摘要（Merkle/签名），V 只看摘要。

**定义 144（轻量探-诺-演 LPC）** 每检查点顺序：①attestation 与证书可验证性（硬门槛，失败即降级）；②可移植域检查（域外即降级/重校准）；③N-版本与防降级检查；④通过后按 VOI_元悲观 选探针，探针结果上送重生成器补证书；⑤承诺 ⇔ V 接受；否则绕行→降级→L2 协商或安全停。降级模式 DGR：无云/无证明时仅允许第 56 轮最保守子集（绕行/安全停），并记录待补证据。

## 2. 关键算法伪代码（完整版见产物区）

```python
def lightweight_commit(cert, s):                    # 定义139：硬门槛先于一切优化
    if not verify_attestation(cert.h, s.root): return 'degrade', 'attest_fail'
    if not in_portability_domain(cert.h, s.phi): return 'degrade', 'port_out'
    if not osh_guard_ok(cert): return 'degrade', 'supply_chain'
    return ('commit', cert.sigma) if lsk_verify(cert, s) else ('degrade', 'lsk_reject')

def lsk_verify(C, s):                               # 极小谓词族，不调用重模型
    return (C.sig_ok and C.evidence_digest_ok and C.calib_digest_ok
            and C.resource_ok and hard_ban_ok(C) and consents_ok(C, s))
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| LSK | O(m)，m 为常数 | O(\|C\|) | TCB 完整、规范正确、硬禁令不可删 |
| HAB | O(depth) 度量；在线 O(1) 验签 | O(1) | 度量无漏检、绑定不可伪造 |
| PCH | 离线 O(N_stratum)；在线 O(1) | O(分层校准摘要) | 域内覆盖、域外强制降级 |
| OSH-G | O(N_impl) | O(1) | N-版本独立、可复现、防降级 |
| MSES | 离线 O(2^{\|ℰ\|}) 或贪心；在线 O(\|ℰ\|) | O(\|ℰ\|) | 假接受预算、硬禁令不可删 |
| LPC | O(\|CP\|·(m+N_impl+k_p)) | O(\|V\|+\|σ\|) | 硬门槛先于 VOI、单调降级 |

**正确性定理（LPCS 概要）**：在 A41（检查器健全、TCB 完整、资源界满足）A42（度量启动无漏检、BOM/固件绑定不可伪造、失败率 ≤δ_att）A43（可移植域内分层共形覆盖 ≥1−α_conf，域外降级）A44（N-版本独立、可复现构建、防降级有效，接管失败率 ≤δ_guard）下：(i) 轻量承诺失效率 ≤ δ_f+δ_att+δ_port+δ_guard+δ_comp，且与 ε_meta 无关；(ii) 最小充分性：ℰ\* 满足假接受预算且成本最小，硬禁令不可删；(iii) 跨板在 𝒫_h 内覆盖 ≥1−α_conf，域外动作单调保守；(iv) 交互单调性保持：attestation/移植/N-版本/检查器任一失败只能使系统更保守；(v) 在线检查 O(m)、空间 O(\|C\|)，与 \|𝒟_meta\| 无关。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 检查器/规范缺陷成为单点 | 高 | 形式化规范 + 关键谓词形式验证 + N-版本检查器 + 差分测试 + 影子部署 |
| attestation 根妥协或侧信道 | 高 | 硬件根 + 多根/透明日志 + 防拆检测 + 定期密钥轮换 |
| 轻量化过度删证据 | 中高 | MSES 以假接受预算约束删除；硬禁令不可删；删除须附论证与回归 |
| 异构板校准漂移 | 中 | 硬件分层共形 + 域外降级 + 在线再校准 + 移植测试 |
| 开源被对手精确优化 | 中 | Kerckhoffs 假设、密钥与度量、N-版本、红队与模糊测试 |
| 供应链碎片化/版本碎片 | 中 | OBOM 绑定 + 可复现构建 + 单调版本 + 分叉影子隔离 |

## 6. 本轮最大风险

**一句话**：轻量化把五层纵深压缩成一个"小而全"的检查器、开源又把它的规范与实现完整暴露给对手，于是全部保证最终压在"这一小段规范没有错、这一个度量根没有被攻破"上——一旦出现规格盲区或根妥协，系统会源源不断地签发**可移植、可复用、跨板通用**的假证书，其扩散速度和范围都超过第 57 轮"坏先验"的局部失准；必须以形式化规范 + N-版本独立检查器 + 硬件度量根 + 透明日志 + 影子部署五重护栏，把"轻"限制在可验证的范围内，绝不把"小"误当作"可信"。

# 第 58 轮产物 · 创新点清单 v34：LightPort-Trust（轻量证明携带承诺×开源物料绑定×硬件分层可移植校准，LSK×HAB×PCH×OSH-G×MSES×LPC）

> 承接第 57 轮 IP-133~138（MFSL/XMC/PTM/MXI/FSE/PCE+）、第 56 轮 IP-127~132（SMM/PCE/BVK/ISE/TAF/MEC）与第 55 轮 IP-121~126。本轮把部署前提从"少样本可校准、跨模态可对账、个性化有界的证据承诺"升级为 **"轻、可验、可携带的证书承诺"**：在线只保留一个最小可信内核（LSK），重推理退居离线生产**证明携带承诺（PCC-L）**；证书绑定**开源物料清单（OBOM）与硬件根度量（HAB）**，异构硬件靠**分层共形（PCH）**保持覆盖率，开放供应链靠**N-版本交叉核验 + 可复现构建 + 防降级（OSH-G）**兜底；证据门升级为**最小充分证据集（MSES）**，探-诺-演升级为**证书硬门槛优先的 LPC**。第 57 轮"一切判定器走隔离"在本轮推广为"**一切承诺携带可在最小内核上验证的证书，且证书绑定可度量的硬件**"。
> IP 编号：IP-139~IP-144（共 6 个），升级 IP-137（FSE→MSES）与 IP-138（PCE+→LPC），并改造 IP-133/134/135 的输出形态为"证书内摘要"。

### IP-139 LSK/PCC-L（轻量证明携带承诺，生成-检查分离）

```python
def heavy_generate_cert(task, M, meta, cloud):
    # 不可信端：可慢、可冗余、可错；只产证书，不直接产生在线决定
    sigma = cloud.plan(task, M)                       # 复用第57轮重推理（MFSL/XMC/PTM）
    ev    = evidence_digest(M)                        # Merkle 根 + 传感器签名
    cal   = calibration_digest(meta, M)               # 校准摘要（非原始数据）
    h     = measure_hardware()                        # 定义140
    C = Cert(sigma=sigma, constr=constraints_summary(sigma), evidence=ev,
             calib=cal, h=h, tl=transparency_log.append(hash_of(sigma)),
             res=ResourceDecl(L_MAX, TAU_CHK, E_MAX))
    return sign_by_device(C, cloud.k_att)

def lsk_verify(C, s):
    # 极小谓词族：不加载 q_φ、不做融合、不读原始观测
    if C.res.exceeds(L_MAX, TAU_CHK, E_MAX):   return False   # 资源契约
    if not C.sig_ok:                            return False   # 设备签名
    if not C.evidence_digest_ok:                return False   # 证据摘要可核
    if not C.calib_digest_ok:                   return False   # 校准摘要可核
    if not hard_ban_ok(C):                      return False   # ℋ 不可删硬禁令
    if not consents_ok(C, s):                   return False   # 同意/授权摘要
    return avalanche_and_margin_ok(C)                         # 轻量几何谓词

def hard_ban_ok(C):                                           # 与第57轮一致，永不可被"优化"掉
    return (not (C.irreversible and C.ev == 'EV-xmodal')
            and not (C.ood and not C.ood.certified)
            and C.attestation_present)
```

### IP-140 HAB（开源物料证明与度量链）

def measure_hardware():
    obom = hash_obom(read_bom())                      # 开源物料清单（板卡/传感器/执行器/版本）
    fw   = hash_firmware(read_fw_version())           # 可复现构建产物
    boot = measured_boot_log()                        # ROM->bootloader->OS->runtime
    ids  = component_ids()                            # 防克隆的元件标识
    return H(obom, fw, boot, ids)

def verify_attestation(h, root):
    if not root.valid:                    return False
    if not root.verify_measurement(h):    return False   # 度量链 + 身份密钥
    idx = root.tl_index(h)
    return root.tl.consistency_proof(idx)                # append-only 一致性证明

def certify_hardware_stratum(h):
    # 同一 h 的板归入同一"硬件层"；不同 OBOM/固件/度量 → 不同层
    return stratum_id(h)

### IP-141 PCH（硬件分层可移植校准）

def self_characterize():

def hardware_stratum(phi, P_h):
    s = nearest_stratum(phi, P_h)
    return s if dist(phi, s.center) <= DELTA_PORT else None   # 域外 -> 降级

def portable_conformal(stratum, z, alpha):
    if stratum is None:                       return None   # 不可移植，禁止承诺
    cal = load_stratum_calibration(stratum)                 # 分层校准摘要（轻量）

def transplant_test(src, dst, trials):                      # 离线证书移植审计
    cov = empirical_coverage(src.cert, dst.board, trials)
    return cov >= 1 - ALPHA_CONF and (src.cov - cov) <= DELTA_PORT

### IP-142 OSH-G（开源供应链护栏）

```python
def osh_guard_ok(C, shadow_passed):
    if not reproducible_build_match(C.fw_digest):   return False   # G2 可复现构建
    if not antirollback_ok(C.version, monotonic_ctr):return False   # G3 防降级
    votes = [impl.verify(C) for impl in independent_impls]          # G1 N-版本
    if len(votes) < 2 or not all_equal(votes):       return False
    if C.fork not in shadow_passed:                  return False   # G4 分叉影子
    return True

def antirollback_ok(ver, ctr):
    return ver >= ctr.floor                                  # 单调：旧固件/旧证书失效

def shadow_accept(impl, stream, regression):
    # 新实现/新元模型先在影子模式跑，回归不劣化才接管
    m = impl.run_shadow(stream)
    return (m.ece <= regression.ece + EPS
            and m.ood_recall >= regression.ood_recall - EPS
            and m.false_accept <= regression.false_accept + EPS)
```

### IP-143 MSES（最小充分证据集，升级 FSE）

```python
def compute_mses(E, delta_f, cost, hard_bans):
    best = None
    for S in powerset(E):
        if not hard_bans <= S:                       continue   # ℋ 必须在
        if false_accept_bound(S) > delta_f + DELTA_COMP: continue
        c = sum(cost(e) for e in S)
        if best is None or c < best.cost:
            best = Subset(S, c)
    return best                                              # 离线求，证书内引用

def evidence_digest(M):
    # 原始探针流 -> 可验证摘要；LSK 只核对摘要与签名，不读原始大数据
    leaves = [sign(sensor_key(o), canonical(o)) for o in probe_stream(M)]
    return merkle_root(leaves)

def mses_gate(C, S_star):
    return all(e in S_star for e in C.claimed_evidence) and hard_ban_ok(C)
```

### IP-144 LPC（轻量探-诺-演：证书硬门槛优先）

```python
def probe_commit_evolve_lite(x0, M, task, budget, cloud, consent, s):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        C = cloud.get_certificate(M, cp, task)            # 离线重推理（可慢可错）
        # ①-③ 硬门槛：任一失败即单调降级
        if not verify_attestation(C.h, s.root):   return degrade(cp, 'attest_fail')
        if hardware_stratum(s.phi, P_h) is None:  return degrade(cp, 'port_out')
        if not osh_guard_ok(C, s.shadow):         return degrade(cp, 'supply_chain')
        # ④ 轻量证据检查 + 仅在未过时用 VOI 补探
        while budget.probes_left and not lsk_verify(C, s):
            cands = admissible_probes(cp, M, F_abs)
            if not cands: break
            p = argmax(cands, key=lambda q: voi_meta_pessimistic(q, M, C) - cost(q))
            if voi_meta_pessimistic(p, M, C) < theta_voi: break
            M = ingest(M, cp, execute_probe(p, cap=F_abs))
            C = cloud.get_certificate(M, cp, task)        # 探针后补证书（重端）
        # ⑤ 承诺 ⇔ LSK 接受；MSES 限定可声明证据集
        if lsk_verify(C, s) and mses_gate(C, s.E_star):
            sched.append(commit(C.sigma, C)); log.append(C); continue
        alt = reroute(M, cp, risk_model)
        if alt and lsk_verify(cloud.get_certificate(M, cp, alt), s):
            route = alt; continue
        return degrade(cp, 'no_certificate')              # 降级默认：绕行/协商/安全停

def degrade(cp, reason):
    # DGR：无云/无证明时只允许第56轮最保守子集
    return negotiate_or_stop(cp, mode='DGR', allowed={'reroute', 'safe_stop'}), reason
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| LSK | O(m)，m=常数 | O(\|C\|) | TCB 完整、规范正确、硬禁令不可删（A41） |
| HAB | O(depth) 度量；在线 O(1) 验签 | O(1) | 度量无漏检、绑定不可伪造（A42） |
| PCH | 离线 O(N_stratum)；在线 O(1) | O(分层校准摘要) | 域内覆盖、域外强制降级（A43） |
| OSH-G | O(N_impl) | O(1) | N-版本独立、可复现、防降级（A44） |
| MSES | 离线 O(2^{\|ℰ\|}) 或贪心；在线 O(\|ℰ\|) | O(\|ℰ\|) | 假接受预算、硬禁令不可删 |
| LPC | O(\|CP\|·(m+N_impl+k_p)) | O(\|V\|+\|σ\|) | 硬门槛先于 VOI、单调降级、终止 |

**正确性定理（Lightweight Portable Certified Soundness, LPCS）**
假设 A22–A32（第 53–55 轮）、A33–A36（第 56 轮）、A37–A40（第 57 轮）成立；**(A41)** 检查器健全：LSK 正确实现规范，TCB 未被篡改且满足资源契约；**(A42)** 硬件证明：度量启动无漏检，OBOM/固件绑定不可伪造，attestation 失败可检出且失败率 ≤δ_att；**(A43)** 可移植校准：在 𝒫_h 内分层共形覆盖 ≥1−α_conf，域外强制降级，移植拒绝判定完备；**(A44)** 供应链护栏：N-版本实现相互独立，可复现构建成立，防降级有效，恶意变体接管概率 ≤δ_guard。则：

1. **轻量承诺健全性**：`P(fail) ≤ δ_f + δ_att + δ_port + δ_guard + δ_comp`，且**与 ε_meta 无关**——重模型的误差只改变接受率/探针效率，不改变承诺健全性；因为 V 只核对可独立验证的摘要、签名与度量，不采信 q_φ 的校准声明。
2. **最小充分性**：ℰ\* 在 δ_f+δ_comp 预算内成本最小；硬禁令集合 ℋ 不可删；`false_accept(ℰ*) − false_accept(ℰ) ≤ δ_comp`。
3. **可携带性**：在 𝒫_h 内跨板覆盖 ≥1−α_conf；域外证书被拒绝并单调降级，安全性不降（性能可降）。
4. **交互单调性强化**：attestation、移植、N-版本、LSK 任一失败只能经"更保守动作"影响系统（绕行/安全停/协商），不存在升险路径。
5. **终止与资源**：在线检查 O(m) 与 O(\|C\|)，与 \|𝒟_meta\| 无关；LPC 在 k_p+k_cons 内终止于 {承诺, 绕行, L2 协商, 安全停}。

**部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + δ_att + δ_port + δ_guard + δ_comp)
             − P(TCB 规范缺陷) − P(降级执行失败)
             − P(TL 不一致未检出) − P(N_版本独立性失效)
```

关键：**纵深在生成端、轻量在检查端**（重推理可慢可错，在线只验证证书）；**信任根从模型转到规范与度量**（q_φ 不再是被赌注的对象）；**开源以可验证性换信任**（OBOM + 可复现构建 + 透明日志 + N-版本）；**轻在可省处、重在不可省处**（MSES 只在 δ_f 预算内删证据，ℋ 永不可删）。

## 6. 本轮最大风险

**一句话**：轻量化把五层纵深压缩成一个"小而全"的检查器、开源又把它的规范与实现完整暴露给对手，于是全部保证最终压在"这一小段规范没有错、这一个度量根没有被攻破"上——一旦出现规格盲区或根妥协，系统会源源不断地签发**可移植、可复用、跨板通用**的假证书，其扩散速度和范围都超过第 57 轮"坏先验"的局部失准；必须以形式化规范 + N-版本独立检查器 + 硬件度量根 + 透明日志 + 影子部署五重护栏，把"轻"限制在可验证的范围内，绝不把"小"误当作"可信"。
