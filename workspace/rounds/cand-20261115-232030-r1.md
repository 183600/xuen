# 第 11 轮（本轮灵感：「平衡控制」×「通用机器人」）

> **基线**：第 10 轮 MetricVoiceGauge-STF-NRB-LS（定义 540–548；引理 87–91；实验 E571–E590）。
> 本轮纪律：**平衡即证书 + 通用有界 + 能力留痕**。两个灵感分别治理 v10 的两种债：**平衡债**——Ĉ⁺ 认证了间隙、力与语义信任，却没有认证“这一块执行完、被推一下、接触丢失时，机器人还站得住吗”；在轮足/人形/全身操作上，无碰撞但动态不可行的块会以“证书合格地摔倒”收场。**通用债**——F̂_q、β_STF 与技能集都标定在单一形态/任务分布上，换形态、换任务、换接触模式时，v10 的“覆盖”没有被定义，通用性只能靠乐观外推。铁律不变：新模块失效 ⇒ 注入声明中立元，行为对 v10 **等价**（USG 失效退回 C₀）或**支配/更保守**（BE/GC 失效退回 Π_b/U），绝不行为漂移。

## 0. 直觉与动机

**灵感 1（平衡控制 → 从“停车点”到“可捕获证书”）**
直觉：v10 的中止机制本质上是**空间刹车**——沿块路径找一个最近安全停驻点，再证明停车距离内不撞。这个机制默认“停得下来”等价于“站得住”。但平衡控制的真正对象不是位置，而是**质心-动量-接触**三者构成的可恢复性：一个块可以全程无碰撞、力也在阈值内，却在末尾把发散分量（DCM）推到支撑域外，或被一次横向推力推入不可恢复区。此时“最近中止点”仍存在，物理上却已经回不来。更合理的做法是把 v10 的“完成 + 中止”证书升级为“**完成 + 恢复 + 守卫**”三件事：块结束时不仅要有停车点，还要有**可执行的恢复接触/恢复步**；50Hz 守卫不只看间隙与力，还要看 DCM 裕度与接触新鲜度。核心创新：**平衡包络（BalanceEnvelope, BE）**——用 DCM/N 步可捕获域处理移动与踏步，用质心动量-接触力锥可行性处理全身操作，把“站得住”变成 Ĉ⁺ 上的一个可测余量；任何接触不确定（打滑、丢失、地形未知）都只能让动作集收缩到 Π_b，绝不乐观外推。这样 v10 的“最近中止点”被替换为“**最近可恢复接触点**”，安全语义从“停下来”升级为“回得来”。

**灵感 2（通用机器人 → 从“一个策略泛化”到“可证能力边界”）**
直觉：通用机器人最危险的叙事是“一个模型什么都能做”。v10 已经证明：真正可部署的通用性不是无限外推，而是**在可标定边界内组合已验证能力**。换形态（轮式↔足式、臂长/质量变化）、换任务（新物体、新接触模式）、换环境（非平坦、低摩擦）都会同时击穿 F̂_q 与 β_STF；如果仍用同一套余量，系统会把“分布外”误当成“分布内”。因此要把通用性写成**技能图 + 通用性证书**：每个技能 s 携带前/后置条件、任务空间参数化、能力证书 C_s 与有效域 V_s；形态/任务用归一化描述子 (m,τ) 表示；对有效域内的新点，用 Lipschitz 迁移界 + conformal 残差分位数给出可测上界；对域外点，只允许**短探针**校准，探针失败就拒绝，而不是“先做做看”。核心创新：**通用技能图（UniversalSkillGraph, USG）+ 通用性证书（GeneralityCertificate, GC）+ 通用安全内核（UniversalSafeKernel, U）**。语言指令只用于生成任务描述子 τ，绝不直接生成动作；τ 歧义或越界时，系统用语音澄清/拒绝。通用性因此从“模型自信”变成“**可审计的能力边界**”。

**咬合**：BE 保证被选中的技能组合在动力学上做得到、停得下、回得来；USG/GC 保证被组合的技能本身在标定域内；能力台账 CL 把准入、探针、拒绝与迁移界留痕。三者共同把 v10 的 Ĉ⁺ 升级为**平衡-通用证书 Ĉ_t^× = (ĝ_min, ê_max, γ̂_grasp, β_STF, n_t, B̂_t, Ĝ_t, κ_t)**，其中 κ_t 是从技能图选出并验证过的路径证书。关键不是把“通用”塞进控制目标，而是把它放在**字典序**里：物理安全/平衡 ≻ 硬规范 ≻ 通用能力 ≻ 任务效用。通用性只能扩大“可做集合”，不能降低“安全余量”。

## 1. 研究问题（轮次升级版）

- **Q1（平衡证书）**：如何把 v10 的“停车点”升级为“完成 + 恢复 + 守卫”的平衡证书，使轮足/人形/全身操作在推力、低摩擦、接触丢失与非平坦地形下**不可恢复摔倒为 0**、50Hz 守卫 WCET 不破，且平衡约束只在必要时收缩而不显著牺牲任务吞吐（≤5%）？
- **Q2（通用有界）**：如何用归一化形态/任务描述子、技能图与迁移界，把“换形态/换任务”变成可测的证书扩展，使有效域内组合成功率 ≥ 预注册门槛、域外**越界执行 0**、未知任务以语音澄清或拒绝收场，而不是静默外推？
- **Q3（能力留痕与隔离）**：如何把技能准入、探针、迁移界、拒绝理由与平衡降级写入 append-only 能力台账，使篡改检出 100%、64 块内缺口自检、责任归因 100%，并证明审计面不回灌当期控制？

## 2. 设计原则（在 P13–P15 基础上新增 P19–P21）

**P19 平衡即证书律（Balance-as-Certificate, BE）**
每个块必须同时认证“完成、恢复、守卫”三件事：块末存在可执行恢复接触/恢复步；DCM 或质心-接触力锥裕度为正；50Hz 守卫能在裕度跌破前触发。静态 ZMP/质心投影合格不构成平衡证明；接触状态过期、地形未知或力矩模型失配 ⇒ 直接进入 Π_b，绝不带病执行。

**P20 通用有界律（Bounded Generality, USG/GC）**
“通用”只允许两种形式：在已验证技能图上做前后置条件可证的组合；在标定形态/任务有效域内做有迁移界的技能复用。域外只允许短探针校准；探针失败、无迁移界或组合证书不闭合 ⇒ 拒绝或退到通用安全内核 U。禁止把开放世界任务直接喂给未验证策略做乐观外推。

**P21 能力留痕与可撤销律（Capability Ledger, CL）**
技能准入、探针、迁移界、拒绝理由、平衡降级与恢复接触全部写入 append-only 哈希链。台账缺口或校验失败 ⇒ 下一块强制 Π_b ∩ Π_r 并只允许 U；台账后置写入，不回灌当期控制。能力是可撤销的：一次越界或一次未解释的降级都必须留下可复盘证据。

## 3. 与基线的接口（如何退化）

- **BE 失效**（IMU/接触估计过期、地形/摩擦未知、质心模型失配）⇒ Π_b（双支撑或立即恢复接触、降质心、限速、K_eff≤2、禁腾空、禁新高风险抓取、语音披露）：动作集 ⊆ v10 安全集，**支配** v10 的乐观执行；
- **USG 失效**（技能图不可读/版本偏斜/搜索超时）⇒ 默认技能集 C₀（v10 原始标定形态/任务技能），任务集**等价** v10；
- **GC 失效**（形态/任务越界、无迁移界、探针超时）⇒ 仅通用安全内核 U（停、蹲、退、交接、拒绝、回坞），高风险技能一律拒绝；动作集 ⊆ v10；
- **CL 失效** ⇒ 审计面冻结，控制与证书不变，**等价** v10 控制；若 CL 报缺口/篡改 ⇒ 下块 Π_b ∩ Π_r 且 GC 置 unknown；
- **v10 原链**：STF 失效 ⇒ K=1/β=β_base；NRB 失效 ⇒ Π_r；LS/AC/ID/MW 失效沿 v10 六级退化 ⇒ v9 ⇒ v8 ⇒ v7 ⇒ v6。

## 4. 预期贡献

1. **平衡包络证书**：把“停车点”升级为 DCM/N 步可捕获域与质心-接触力锥双重认证，给出“完成-恢复-守卫”的平衡余量与 Π_b 单调收缩（引理 92–93）；
2. **可证通用性**：用归一化形态/任务描述子、技能图组合证书、Lipschitz 迁移界与 conformal 探针，把“通用”限制在可审计能力边界内，域外拒绝而非外推（引理 94–95）；
3. **通用安全内核与能力台账**：给出不依赖 USG/GC 的最小安全动作集，并把准入/探针/拒绝/降级写入哈希链（引理 96–97）；
4. **E591–E610** 覆盖平衡标定、推力恢复、低摩擦/接触丢失、跨形态迁移、域外拒绝、探针开销、台账完整性与综合竞赛。

## 5. 本轮最大风险

**一句话**：最大风险是**形态/任务描述子把“看起来相似”当成“物理相似”**——迁移界与探针都建立在描述子度量上的 Lipschitz 假设，若接触动力学在描述子邻域内不连续（轮式↔足式、刚性↔柔性接触、平地↔可变形地面），GC 会给出形式合格但物理错误的通用性证书，而平衡守卫只在已选技能内部检查 DCM/力锥，无法发现“技能本身选错”，最终表现为“证书齐全的摔倒”。

**新增定义 549（形态描述子与距离）** m 各分量按参考量纲归一化：ℓ̃=ℓ/ℓ_ref，m̃=m/m_ref，τ̃=τ/(m_ref g ℓ_ref)，接触几何用足底多边形顶点/轮半径/末端包络的尺度不变矩表示。d_m 为加权 L∞：d_m(m,m′)=max_j w_j·|m̃_j−m̃′_j|，w_j 经 E591 标定使“单位距离≈单位迁移误差”。m 只描述物理形态，不含任务身份。

**新增定义 550（任务描述子与指令接地）** τ 由目标谓词、物体类、所需接触、视界、环境类与语言嵌入组成。语音指令 ℓ 只生成候选集 T(ℓ)={τ: sim(z_ℓ,z_τ)≥τ_amb}；仅当候选 top-2 距离裕度 ≥δ_amb 时选定 τ*，否则语音澄清或拒绝。**语言永不直接产生动作**；τ* 是 USG 的唯一任务输入。

**新增定义 551（通用技能图）** G_S=(S,E)。技能 s 的策略 π_s 在任务空间/相对坐标系中参数化，只通过 m 注入形态相关量（尺度、限位、力矩），不允许形态专用常量散落在策略中。边 (s_i,s_j)∈E 当且仅当 post_{s_i} ⇒ pre_{s_j} 且接口坐标系/接触模式兼容；组合路径 P=(s_1,…,s_n) 必须逐边满足该蕴含。

**新增定义 552（技能能力证书）** C_s=(p_s, ε_s, κ_s)，在有效域 V_s 上由 E597 标定：p_s 为成功率下界，ε_s 为归一化约束违背上界（含安全距离、力/力矩、平衡裕度），κ_s 为时间/能量代价上界。C_s 对 (m,τ) 有效 ⇔ (m,τ)∈V_s 且标定置信 ≥1−α。

**新增定义 553（形态迁移界与 conformal 残差）** 设技能 s 的归一化结果残差 r_s(m,τ)=最大约束违背。假设 r_s 在 V_s 上对 d_m+d_τ 为 L_s-Lipschitz。给定标定集 n 个样本，q_s(α) 取第 ⌈(n+1)(1−α)⌉ 小的残差（split conformal）。则对 (m′,τ′)，以概率 ≥1−α：r_s(m′,τ′) ≤ q_s(α)+L_s·(d_m(m′,m_s)+d_τ(τ′,τ_s))。若 d_m+d_τ>ρ_s，则无迁移界，只允许探针或拒绝。

**新增定义 554（通用性证书）** 对路径 P=(s_1,…,s_n)：η_g = clip(min( (ρ_min−d_m−d_τ)/ρ_min, (ε_min−q_t−L_min·(d_m+d_τ))/ε_min ), 0, 1)，其中 q_t=Σq_{s_i}(α/n)（Bonferroni），L_min=min_i L_{s_i}，ρ_min=min_i ρ_{s_i}，ε_min=min_i ε_{s_i}。Ĝ_t valid ⇔ 所有技能有效、逐边前后置蕴含成立、组合证书闭合、η_g≥0、探针残差 ≤ 迁移界。unknown=1 表示无证书路径；通用赤字 g_t=1−η_g。

**新增定义 555（平衡状态、DCM 与 N 步可捕获域）** 移动模式用 LIPM：ω=√(g/z_c)，ξ=x+ẋ/ω，ξ̇=ω(ξ−p)。支撑域 S(c(t)) 由当前接触调度 c(t) 给出；N 步可捕获域 C_N(c) 为存在 ≤N 个落脚点 p_i∈F_reach（腿长/摩擦/地形约束）使 ξ 最终进入 S 的状态集合。全身操作模式用质心动量 h=(m,l,k) 与接触力锥：w_i∈W_i（单边、摩擦锥、力矩限），可行 ⇔ ∃w_i 使 ḣ=Σw_i+m g 且运动学可达。wrench 裕度 η_w=max{s: s·w∈W_i 且动力学可行}。

**新增定义 556（平衡证书）** B̂_t=(η_sup, η_cap, η_w, c_t, fresh)。η_sup=min_t dist(ξ(t),∂S(c(t)))/ℓ_ref；η_cap=min_t dist(ξ(t),∂C_N(c(t)))/ℓ_ref；η_w 为归一化力锥裕度；η_b=min(η_sup,η_cap,η_w)−β_B。B̂_t valid ⇔ η_b≥0 ∧ 接触调度 c_t 可行（摩擦/运动学/执行器）∧ fresh（IMU/接触年龄 ≤T_c=50ms）∧ 存在 T_rec≤0.2s 内可达的恢复接触。β_B 为 LIPM/质心模型误差界，经 E592 标定（覆盖 ≥99%）。**B̂ 同时覆盖“完成、恢复、守卫”三件事，缺一不可。**

**新增定义 557（平衡收缩剖面）** Π_b：双支撑或立即执行最近恢复接触；质心高度 ≤z_safe；速度 ≤v_safe；K_eff≤2；禁止腾空/单脚动态步；禁止把手臂伸到会显著移动质心的构型；禁止新高风险抓取；强制语音披露“平衡受限”。Π_b 只收缩动作空间/加严裕量，物理动作集 ⊆ v10 安全集（引理 96）。

**新增定义 558（通用安全内核）** U={u_stop 平衡停驻, u_crouch 双支撑降质心, u_retreat 沿已验证走廊后退, u_handover 向人呈递/请求接管, u_refuse 语音拒绝且不动作, u_dock 回坞}。每个 u 携带前/后置条件并在 Π_b 下认证；U 不依赖 USG/GC，是 BE/GC/USG/CL 失效时的最小可用集。U 只保证“停得住、说清楚、可接管”，不保证任务完成。

**新增定义 559（平衡/通用赤字与扩展有效块长）** b_t=clip(1−η_b/(β_B+δ_b),0,1)；g_t=clip(1−η_g,0,1)。则
```
K_eff^×(t) = 1   若 ¬U_t^sem ∨ ¬B̂_t valid ∨ ¬Ĝ_t valid ∨ Ĉ_t^× 不可得
           = 2   若 NRB 失效（Π_r）或 BE 失效（Π_b）
           = max(1, ⌊K_max·(1 − max(Δ_dom/τ_dom, sup_走廊 T/τ_sem, b_t, g_t))⌋)  否则
```
四路取 max：语义领先、标量域偏移、平衡赤字、通用赤字任一越阈即收缩；域越陌生/越站不稳/越超出能力边界，块越短，极端 K=1 退回逐步模式。

**新增定义 560（能力台账）** CL 记录 = H(prev‖t‖chunk_id‖m_hash‖τ_hash‖P_t‖Ĝ_t‖B̂_t‖outcome‖refusal_reason)，append-only 哈希链（κ_h=256），块边界批量写，每 C_w=64 块链头校验点。缺口（漏写/校验失败/双重记账）⇒ 下一块 Π_b∩Π_r、GC 置 unknown、只允许 U 直至重验。写入在块执行后，审计面不回灌当期控制。

# IP-361 BalanceEnvelope：平衡包络（DCM + 质心-接触力锥）
class BalanceEnvelope:
    def __init__(self, beta_B=0.03, delta_b=0.01, T_c=0.05,
                 T_rec=0.2, N_cap=2, z_safe=0.85):
        self.beta_B, self.delta_b = beta_B, delta_b
        self.T_c, self.T_rec, self.N_cap = T_c, T_rec, N_cap
        self.z_safe = z_safe

    def certify(self, state, chunk, contact_schedule):
        # 1) 移动：DCM 支撑裕度 + N 步可捕获裕度
        xi = state.com + state.com_vel / state.omega
        eta_sup = min(distance_to_boundary(xi, S(c))
                      for c in contact_schedule) / state.l_ref
        eta_cap = min(distance_to_boundary(xi, C_N(c, self.N_cap))
                      for c in contact_schedule) / state.l_ref
        # 2) 全身：质心动量-接触力锥可行性（含手臂）
        eta_w = centroidal_wrench_margin(state, chunk, contact_schedule)
        # 3) 块末必须存在恢复接触（不是“最近停车点”）
        recovery = self._nearest_recovery_contact(state, chunk, contact_schedule)
        fresh = state.imu_age <= self.T_c and state.contact_age <= self.T_c
        eta_b = min(eta_sup, eta_cap, eta_w) - self.beta_B
        valid = (eta_b >= 0 and fresh and recovery is not None
                 and recovery.time_to_reach <= self.T_rec
                 and contact_schedule.feasible(state))
        return Bcert(eta_sup, eta_cap, eta_w, eta_b, contact_schedule,
                     recovery, fresh, valid)

    def guard(self, live_state, chunk):
        if live_state.imu_age > self.T_c or live_state.contact_age > self.T_c:
            return 'Pi_b'                       # 接触/姿态不确定 ⇒ 收缩
        eta_b = self._live_margin(live_state, chunk)
        if eta_b < self.beta_B + self.delta_b:
            return 'abort_recovery'             # 切最近恢复接触
        return 'continue'

# IP-362 UniversalSkillGraph：通用技能图（确定性有界组合）
class UniversalSkillGraph:
    def __init__(self, skills, max_nodes=64, max_edges=256, T_search=0.2):
        self.S, self.E = build_graph(skills, max_nodes, max_edges)
        self.T_search = T_search

    def admit_and_compose(self, m, tau, gc, be, state):
        # 只保留“前置条件成立 + 通用性证书有效”的技能
        start = [s for s in self.S if s.pre(m, tau) and gc.valid(s, m, tau)]
        # A*：字典序代价 = (约束违背上界, 时间/能量代价, 路径长度)
        # 逐边检查 post_i ⇒ pre_j；证书传播 p=Πp_i, eps=Σε_i
        for path in deterministic_astar(start, self.E, tau,
                                        key=lambda p: (p.eps, p.cost, len(p)),
                                        deadline=self.T_search):
            if not path.post_chain_closed() or not path.cert_valid():
                continue
            # 组合后的接触调度必须被 BE 认证；否则该路径不可执行
            if be.certify(state, path.as_chunk(), path.contact_schedule).valid:
                return path.with_certificate()
        return None                              # 无证书路径 ⇒ U/拒绝

# IP-363 GeneralityCertificate：迁移界 + conformal 探针
class GeneralityCertificate:
    def __init__(self, alpha=0.05, rho_min=0.15, T_probe=1.0, E_probe=0.02):
        self.alpha, self.rho_min = alpha, rho_min
        self.T_probe, self.E_probe = T_probe, E_probe

    def evaluate(self, skill, m, tau):
        d = d_m(m, skill.m0) + d_tau(tau, skill.tau0)
        if d > skill.rho:
            return Unknown(d)                    # 域外：只许探针/拒绝
        bound = skill.q(self.alpha) + skill.L * d
        if bound > skill.epsilon:
            return Invalid(bound)                # 形式上界已破 ⇒ 不执行
        eta_g = min((skill.rho - d) / skill.rho,
                    (skill.epsilon - bound) / skill.epsilon)
        return Cert(eta_g, bound)

    def probe(self, skill, m, tau, U, be, state):
        # 仅在站立/双支撑/无人在场；探针本身必须被 BE 认证
        if not (state.standing and be.certify(state, U.u_crouch,
                                              state.contact_schedule).valid):
            return Unknown('unsafe-to-probe')
        if self.T_probe <= 0 or self.E_probe <= 0:
            return Unknown('budget')
        residual = run_certified_probe(skill, m, tau,
                                       budget=(self.T_probe, self.E_probe))
        return update_conformal(skill, residual, self.alpha)

# IP-354（升级）：平衡-通用结构化证书执行器
class BalanceUniversalChunkCertifier(StructuredChunkCertifier):
    def generate_chunk(self, state, ctx, stf, nrb, be, usg, gc, cl):
        # 0) 形态/任务变化或 GC 过期 ⇒ 先评估/探针；失败则仅 U
        if ctx.embodiment_changed or ctx.task_changed or gc.stale:
            gc = gc.evaluate_all(usg, ctx.m, ctx.tau)
            if gc.unknown:
                gc = gc.probe_safe(ctx.m, ctx.tau, U, be, state)
            if not gc.valid:
                cl.append(ctx, 'gc_refuse', gc); return U.u_refuse(ctx)
        # 1) 技能组合（确定性、有界）
        path = usg.admit_and_compose(ctx.m, ctx.tau, gc, be, state)
        if path is None:
            cl.append(ctx, 'no_certified_path'); return U.u_refuse(ctx)
        # 2) v10 生成候选块；B̂ 认证“完成+恢复+守卫”
        K = self.effective_K_x(ctx.delta_dom, ctx.tau_dom, stf, be, gc)
        if K == 1:
            return self._single_step_fallback(state)
        best = None
        for cand in self.policy.sample_sequences(state, K, path, n=64):
            pred = self.Fq.rollout(state, cand)
            beta_stf = self.beta_base + self.lam * stf.field_on_footprint(pred.corridor)
            bcert = be.certify(state, pred, cand.contact_schedule)
            if not bcert.valid:
                continue                         # 动态不可行 ⇒ 拒绝本候选
            g_min = pred.min_clearance - beta_stf
            e_max = pred.max_effort + beta_stf
            if g_min < self.d_safe or e_max > state.tau_eff:
                continue
            pts = self._abort_points(state, cand, pred, bcert.recovery)
            if not pts:
                continue
            chunk = Chunk(cand, CertX(g_min, e_max, beta_stf, bcert,
                                      gc, path), pts)
            chunk, verdict = nrb.review_chunk(chunk, stf, ctx)
            if chunk is None:
                continue
            best = self._argmax(best, chunk)
        return best or self._single_step_fallback(state)

    def midchunk_guard(self, chunk, k_exec, live_obs, stf, nrb, be):
        """50Hz 六检 ≤0.7ms"""
        if not chunk.cert_still_valid(live_obs):             # 1
            return self._nearest_abort(chunk, k_exec)
        if (live_obs.nearest_clearance - self.d_brake(live_obs.speed)
                - self.d_safe) < chunk.remaining_len(k_exec): # 2
            return self._nearest_abort(chunk, k_exec)
        if stf.surprise_near(live_obs.pose) > stf.tau_sem:    # 3
            return self._nearest_abort(chunk, k_exec)
        if nrb.fast_norms(live_obs).violated:                 # 4
            return self._nearest_abort(chunk, k_exec)
        bal = be.guard(live_obs, chunk)                       # 5
        if bal != 'continue':
            return ('abort', chunk.nearest_recovery_contact(live_obs)
                    if bal == 'abort_recovery' else chunk.pi_b_contact())
        if (live_obs.contact_age > be.T_c
                or not chunk.contact_schedule.matches(live_obs)): # 6
            return ('abort', chunk.nearest_recovery_contact(live_obs))
        return ('continue', k_exec + 1)

## 4. 推导

**引理 92（平衡证书的守卫及时性与单调收缩）** 设 (A1) LIPM/质心模型误差 ≤β_B；(A2) 50Hz 守卫用最新 IMU/关节/接触重算 DCM，帧间 DCM 漂移 ≤δ_s；(A3) 恢复接触在 T_rec 内可达且其接触力锥可行。若 B̂_t valid 且每帧守卫通过，则执行块保持 N 步可捕获；若扰动使 η_b<β_B+δ_b，守卫在 1 帧（20ms）内触发并切最近恢复接触或 Π_b，不会落入不可恢复区。证明：由 ξ̇=ω(ξ−p) 与 A2，帧间裕度下降 ≤δ_s；守卫阈值取 β_B+δ_b>β_B+δ_s，故在 η_b<0 前必触发；A3 保证触发后存在可行恢复。全身模式同理：wrench 可行域对缩放 s 单调，η_w 下降越阈即触发。对比 v10：v10 的停车不变式只约束“刹车距离不撞”，不含 DCM/力锥，因此“停下来但已经回不来”不被检测；v11 把该空洞显式化为可测裕度。∎

**引理 93（技能组合证书传递）** 设路径 P=(s_1,…,s_n) 逐边满足 post_{s_i}⇒pre_{s_{i+1}}，每个 C_{s_i} 在 (m,τ) 上有效，且 BE 认证组合后的接触调度。则组合路径的约束违背 ≤Σ_i ε_{s_i}+n·β_B（并集界），成功率 ≥Π_i p_{s_i}，代价 ≤Σ_i κ_{s_i}。若任一边不闭合、任一技能证书无效或 BE 不通过，则 USG 不返回该路径；无路径时只允许 U/拒绝。证明：对 i 归纳，post_i 的成立由前驱保证；约束违背与成功率由并集界/乘法下界给出；BE 把“符号上前置成立但动态不可行”的组合排除。∎

**引理 94（迁移界与域外拒绝的保守性）** 在 L_s-Lipschitz 与 split-conformal 标定下，对有效域内新点 (m′,τ′)，以概率 ≥1−α 有 r_s(m′,τ′) ≤ q_s(α)+L_s(d_m+d_τ)。若该上界 >ε_s，则 GC 判 invalid，USG 排除 s；若 d_m+d_τ>ρ_s，则无上界，只允许探针或拒绝。因此任何被执行的技能要么残差被测量/上界覆盖，要么不被执行；**不存在“无证书外推”**。证明：三角不等式 r(m′,τ′)≤r(m_s,τ_s)+L_s(d_m+d_τ)，conformal 给出 r(m_s,τ_s)≤q_s(α) 的边际覆盖；域外无 Lipschitz 保证，故拒绝。∎

**引理 95（通用安全内核的支配性与活性边界）** U 的每个动作要么是 v10 已验证的安全停驻/后退/交接，要么是 Π_b 下更严格的变体；u_refuse 为“不动作 + 语音披露”。故 U 下物理动作集 ⊆ v10 安全集，不引入新物理行为；U 失效只可能是硬件故障，沿 v10 中立元链退化。活性上，U 只保证“停得住、说清楚、可接管”，不保证任务完成；任务完成性是假设（E603 验证 ≥85%）。∎

**引理 96（能力台账完整性与审计隔离）** CL 采用 256 位哈希链，任何历史删除/改写以 ≥1−2^{−256} 被离线检出；每 64 块链头校验点使在线缺口至多存续 64 块即触发 Π_b∩Π_r + GC unknown + U-only。写入在块执行后、批量摊销 O(1)，且不进入当期控制回路，故审计面不回灌。∎

**引理 97（字典序安全与“只收缩”组合）** v11 的执行链是过滤器复合：v10 安全不变式 → BE（平衡）→ USG/GC（能力）→ NRB（规范）→ 效用选择。后级只能在前级留下的可行集中删除动作或挑选，不得放宽前级约束；BE/GC/USG/NRB 失效分别注入 Π_b/U/C₀/Π_r，均为“更保守或等价”。因此所有被执行动作同时满足安全、平衡与已证能力；经济/任务效用不能反向侵蚀安全余量。∎

## 8. 本轮最大风险

**一句话**：最大风险是**形态/任务描述子把“看起来相似”当成“物理相似”**——迁移界与探针都建立在描述子度量上的 Lipschitz 假设，若接触动力学在描述子邻域内不连续（轮式↔足式、刚性↔柔性接触、平地↔可变形地面），GC 会给出形式合格但物理错误的通用性证书，而平衡守卫只在已选技能内部检查 DCM/力锥，无法发现“技能本身选错”，最终表现为“证书齐全的摔倒”。
