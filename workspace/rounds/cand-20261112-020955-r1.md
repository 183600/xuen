# 第 59 轮（承接第 58 轮「知识图谱×安全微调×心智模型」IP-139~144；灵感循环第 1 轮；本轮灵感：「数字孪生」×「云边协同」）

> 第 58 轮把安全论证的中心从"证据承诺"推到"结构化记忆"——KG 统一驱动检索、OOD、微调、证据合成与心智预测；它的风险自陈也点中了要害：**一旦 KG 有系统性结构错误，元推断、OOD、微调、类比证据、UX 预测会同时失效，这是共模故障**。本轮两个灵感像是天赐的解药：数字孪生提供"先在虚拟世界里试一遍"的独立验证，云边协同提供"全局知识 + 本地实时"的分工。但直觉必须先泼一盆冷水：**孪生若由同一个 KG/同一批语料训练，它只是 KG 的另一种渲染；云端若只是把同一批历史证据重新加权，它只是更大号的 KG。** 因此本轮不把孪生与云端升格为新的"信任源"，而是给它们一个严格受限的角色：**孪生只当可否证器（twin-as-falsifier），云边只做单调合并（monotone merge），不可逆接触永远需要本地物理证据。** 核心命题由"结构化记忆守护下的安全自适应"升级为 **"孪生可否证、云边可单调、版本可追溯的证据承诺"**。

核心矛盾：
- **H29（孪生同源 vs 独立证据）**：孪生的价值来自"它和真实世界不同"，但它的构建又必须依赖 KG/历史语料；同源共训使"孪生说安全"与"KG 说安全"高度相关，独立验证的假设被悄悄违反。若再把孪生预测成功当作正证据，等于用同一个错误回答两遍。
- **H30（云边时新 vs 版本一致）**：云端有全局数据但可能过期，边端有实时局部证据但样本少；版本偏斜下，两边对"同一次接触"可能给出不同结论。若云端有权直接改写下行安全判定，就会出现"陈旧权威覆盖新鲜现实"的分裂脑。
- **H31（协同收益 vs 通道攻击面）**：云边通道本身是攻击面——投毒的 KG 增量、重放的旧证据、回滚的模型版本都能借"协同"之名进入安全链；协同越深，单点被俘获后的影响面越大。

## 0. 直觉与动机

**灵感 1（数字孪生 → 不是"预演成功"，而是"预演失败"）**
直觉：人类工程师用仿真，最有价值的时刻往往不是"仿真说能过"，而是"仿真里炸了"——因为失败可以在不付出物理代价前被看见。把孪生做成**单向证伪器**：孪生预测某动作会违反约束 ⇒ 该动作从可行集中移除或强制加宽后验；孪生预测安全 ⇒ **零证据信用**，最多在同等风险等级内调整探针顺序，且不得删除不可逆接触的必要物理证据。这样孪生的错误被压成两类：误报（保守，损失效率）与漏报（不被采信，不损失安全）。孪生不再是"第二个乐观模型"，而是"一个只会说'别去'的悲观顾问"。

**灵感 2（云边协同 → 不是"云说了算"，而是"单调合并"）**
直觉：云端有舰队史，边端有此刻的触觉。正确的合并不是"云端覆盖边端"，而是**在保守序上取并**：两边的区间取凸包/加宽、裕度取最小、授权取最低、佐证要求取最高、证据集取并集并带版本；任何合并都只能让系统更保守，不能让系统"更敢赌"。云端可以提出"更窄的后验"，但边端只在本地复验通过后才接受；边端对不可逆接触保留一票否决。版本向量 + 陈旧衰减把"云端旧知识"降权为零，断网时边端独立降级运行。

**灵感 3（版本化证据账本 → 信任来自溯源，不来自权威）**
直觉：协同系统最怕"谁说的"取代"凭什么"。给每条证据一个签名哈希链与版本向量，追加不可改写，撤回必须新开 epoch；合并前先找共同祖先，拒绝回滚/重放/跨 epoch 冲突。于是"云端说安全"不再是权威陈述，而是一串可核验的物理证据 + 可比较的版本区间。

**灵感 4（预算三分 → 仿真便宜但不作证，云端广但会过期，物理贵但权威）**
直觉：把探询预算分成 B_tw（孪生 rollout）、B_cloud（云边往返/舰队查询）、B_phys（物理探针）。孪生用于**排除**（便宜、单向），云端用于**佐证/发现**（广、需版本门），物理用于**作证**（贵、不可替代）。不可逆接触必须保留至少一个物理证据配额，孪生与云端都不能把这一配额"省掉"。

**灵感 5（合流 → 证据门不扩类，只加两条硬禁令）**
直觉：第 58 轮已有六类证据门（EV-probe*/visit/margin/xmodal/human/ft/ux）。本轮**拒绝**新增"EV-twin"作为证据类；新增的只有 **EV-fleet**（他机物理证据，仅可作 L1 佐证，不得进入不可逆必要集）与两条硬禁令：**孪生不得作证、云端不得收窄**。安全纵深不靠"多一个模型"，而靠"多一层单调性"。

## 1. 形式化定义（增量：定义 145–150）

**定义 145（带间隙记账的数字孪生 DTG）** 区域 r 的孪生 𝒯_r=(ŝ_r,f̂_r,U_r,δ_tw(r))，ŝ 状态估计、f̂ 转移动力学、U 不确定性、δ_tw 间隙证书。在留出物理转移集 𝒟_phys(r) 上要求 E[TV(P_phys,P_twin)]≤δ_tw(r)，并分别声明漏报率 δ_FS（孪生说安全而实际失败）与误报率 δ_FA（孪生说失败而实际安全）。仅当 |𝒟_phys(r)|≥N_tw 且残差覆盖≥1−α_tw 时孪生"持证"；未持证 ⇒ 输出一律 UNKNOWN，不参与任何筛选。

**定义 146（孪生证伪协议 TFP）** 对检查点 cp 与候选动作集 A，采样 K_tw 条 rollout，得 τ_viol=违反安全约束的比例，判定
TwinVerdict = FAIL 若 LB(τ_viol)>θ_tw；PASS 若 UB(τ_viol)<θ_tw^safe；否则 UNKNOWN。
动作规则：(T1) FAIL ⇒ 该动作移出可行集（或后验强制加宽），可触发重规划/绕行；(T2) PASS ⇒ **零正证据**，仅允许在同风险等级内重排探针顺序，且必须保留"不可逆必要物理证据预留配额"；(T3) UNKNOWN ⇒ 退回第 58 轮基线；(T4) 孪生永不进入任何证据门，EV-twin 不存在。

**定义 147（云边单调合并 CEMM）** 节点状态 X=(b,K_margin,𝒦,ρ,corrob_req,auth,VV,ledger_head)，VV 为版本向量。保守序 ⊑：X₁⊑X₂ 当且仅当 b₁ 更宽、K_margin¹≤K_margin²、auth¹≤auth²、corrob_req¹≥corrob_req²、𝒦₁⊇𝒦₂。合并 X₁⊔X₂ 取 b 的凸包/最大熵加宽、K_margin 取 min、ρ 取 min、corrob_req 取 max、auth 取 min、证据集取带溯源并集、VV 取逐分量 max；**合并结果必须在保守序上 ≥ 两个输入**（单调性公理 M1）。云端下发的"收窄"提案不直接生效：边端须本地复验且更新后的状态仍 ⊒ 合并前（M2：本地单调过滤）。陈旧：若 age>τ_stale 或云端 VV 不支配边端 VV，权重 w_stale=exp(−age/τ_stale)，age>τ_max ⇒ 权重 0 并标记"无证据"。

**定义 148（版本化证据账本 VEL）** 每节点维护追加式哈希链 ℒ：entry=(evidence,provenance,VV,epoch,parent_hash,sig)。合并前置检查：共同祖先存在、无跨 epoch 冲突、无回放（epoch/哈希重复）、无篡改（签名链）。撤回只能追加新 epoch 的 retraction 条目，不得删除或改写；被撤回证据的支撑权重归零并触发后验加宽。账本完整性缺口以 δ_ledger 计入部署界。

**定义 149（孪生-云-物理三分预算 TCB）** 预算 B=(B_tw,B_cloud,B_phys,B_ft,B_ux)，其中 B_phys=Σ 必须预留的物理探针配额。每检查点分配
π*=argmax_{π: cost(π)≤B} [VOI_元悲观(π) − λ_tw·K_tw − λ_cloud·K_cloud − λ_phys·K_phys]
s.t. (C1) 不可逆接触 ⇒ 至少一个 EV-probe*/EV-margin 物理证据且配额不被孪生/云端抵扣；(C2) 孪生只能减少候选动作，不能减少必要证据；(C3) 云端 VV 陈旧 ⇒ 其证据权重按定义 147 衰减。

**定义 150（探-诺-演+++ 算子 PCX+++）** 每检查点：①孪生证伪预筛（FAIL⇒改动作/绕行，PASS⇒仅重排）；②KG 检索与元推断（第 58 轮）；③跨模态对账（第 57 轮）；④云边单调合并与账本校验；⑤UX 前置检查（第 58 轮）；⑥六类证据门 + EV-fleet 佐证门；⑦承诺 ⇔ R≤δ_f ∧ 证据门过；否则按 VOI 元悲观（扣除孪生/云端成本）探询；探尽/预算尽 ⇒ 绕行→降档→L2 协商→安全停。孪生 FAIL 与云端陈旧只经"动作更保守/后验更宽"两个安全通道起作用。

## 2. 关键算法伪代码

```python
def twin_falsify(T, cp, actions, K_tw, theta):        # IP-146: 单向证伪
    if not T.certified(cp.region):                    # 未持证 ⇒ 不参与
        return {a: 'UNKNOWN' for a in actions}
    out = {}
    for a in actions:
        viol = run_rollouts(T, cp, a, K=K_tw)
        lb, ub = wilson(viol, K_tw)
        out[a] = 'FAIL' if lb > theta.tw else \
                 ('PASS' if ub < theta.safe else 'UNKNOWN')
    return out                                           # PASS 不产生任何证据

def cloud_edge_merge(local, remote, now):             # IP-147: 单调合并
    remote = stale_decay(remote, now, tau_stale, tau_max)
    if not vv_dominates(remote.VV, local.VV) and remote.age > tau_max:
        remote = no_evidence(remote)                  # 旧知识降为零
    merged = State(
        b=convex_hull(local.b, remote.b),             # 只能加宽
        K_margin=min(local.K_margin, remote.K_margin),
        rho=min(local.rho, remote.rho),
        corrob_req=max(local.corrob_req, remote.corrob_req),
        auth=min(local.auth, remote.auth),
        K=local.K | remote.K,                         # 带溯源并集
        VV=vv_max(local.VV, remote.VV))
    assert merged <= local and merged <= remote       # M1 保守序单调
    return local_guard(merged, local)                 # M2 本地复验/否决

def ledger_merge_check(local_L, remote_L):           # IP-148
    if not common_ancestor(local_L, remote_L): return reject('no_ancestor')
    if has_conflict(local_L, remote_L):        return reject('epoch_conflict')
    if replay_or_rollback(remote_L):           return reject('replay')
    if not verify_sig_chain(remote_L):         return reject('bad_sig')
    return accept(append_only_union(local_L, remote_L))
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| DTG | O(K_tw·d_T)/检查点 | O(\|𝒟_phys\|) | 间隙证书诚实、未持证即 UNKNOWN |
| TFP | O(\|A\|·K_tw) | O(\|A\|) | PASS 零信用、不可逆物理配额不被抵扣 |
| CEMM | O(\|VV\|+d_b+log\|𝒦\|) | O(\|𝒦\|) | 合并为保守序上的并（M1）、本地否决（M2） |
| VEL | O(1) 追加；O(\|ℒ\|) 校验 | O(\|ℒ\|) | 签名链、epoch 单增、撤回只追加 |
| TCB | O(\|A\|·(K_tw+C_VOI)) | O(\|A\|) | 物理配额硬保留、三预算单调耗尽 |
| PCX+++ | O(\|CP\|·(K_tw+k_p+k_c+k_ft+k_ux+K_cloud)) | O(\|V\|+\|σ\|+\|𝒢\|+\|ℒ\|) | 五预算终止、孪生/云端不进证据门 |

**正确性定理（Twin-Falsifying, Cloud-Edge Monotone Soundness, TCMAS 概要）**：在第 58 轮 A22–A45 上加 (A46) 孪生持证与间隙诚实（留出物理集、δ_FS/δ_FA 声明、未持证即 UNKNOWN）；(A47) 合并单调（M1 并性质、M2 本地否决、云端不得收窄）；(A48) 陈旧界（VV 支配关系、w_stale 衰减、τ_max 归零）；(A49) 账本完整（签名链、epoch 单增、回放/回滚可检）；(A50) 物理证据保留（不可逆接触的必要物理配额不被孪生/云端抵扣）。则：
(i) **孪生单向性**：任意孪生输出只会缩小可行动作集或加宽后验；PASS 不进入任何证据门，故 δ_FS 不进入安全界（只进入效率/误报代价），孪生错误不可能"制造"承诺；
(ii) **云边单调性**：任意合并序列在保守序上不减；分裂脑与版本偏斜只能使系统更保守，云端无法收窄边端、无法撤销边端否决；
(iii) **陈旧有界**：超过 τ_max 的云端证据权重为 0，陈旧贡献以 δ_stale 计入且随版本收敛而消失；
(iv) **终止性**：TCB 五预算有限且每轮至少消耗一个单位，PCX+++ 在 K_tw+k_p+k_c+k_ft+k_ux+K_cloud 内终止于 {承诺,绕行,L2,安全停}。

部署界（对检查点取联合界）：
```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                   + δ_ft·1[回滚窗口] + δ_kg·1[检索失败] + δ_ux·1[μ_mis>θ_mis]
                   + δ_fleet·1[EV-fleet] + δ_stale·1[合并] + δ_ledger·1[账本缺口])
         − P(不可逆物理配额被预算耗尽) − P(本地否决失效) − P(τ_int 超时∧安全停失效)
```
注意：**δ_tw 不出现在安全项中**——孪生只可能造成误报（效率），不可能造成虚假安全；这是本轮最重要的不对称性。

## 0. 核心 IP 设计与三条戒律

**三条设计戒律（本轮的安全骨架）**

- **R1（孪生只证伪）**：孪生输出 FAIL ⇒ 移除动作/加宽后验；PASS ⇒ 零正证据，只可同风险等级内重排探针；UNKNOWN ⇒ 回基线。**不存在 EV-twin 证据类。**
- **R2（云端只加宽）**：云边合并是保守序上的并；区间加宽、裕度取 min、授权取 min、佐证要求取 max；云端"收窄"提案须边端本地复验；边端对不可逆接触保留一票否决。
- **R3（不可逆只认物理）**：任何 L2/不可逆接触的必要证据集必须含至少一个本地物理证据（EV-probe* 或 EV-margin），孪生与云端都不得抵扣该配额；EV-fleet 仅可作 L1 佐证。

### IP-145 DTG（带间隙记账的数字孪生）

```python
class DigitalTwin:
    def __init__(self, state_model, dyn_model):
        self.state = state_model
        self.dyn = dyn_model
        self.phys_residuals = defaultdict(list)   # 区域 -> 留出物理残差
        self.gap = {}                             # 区域 -> (delta_tw, dFS, dFA)

    def certified(self, region):
        res = self.phys_residuals[region]
        if len(res) < N_TW: return False
        cov = empirical_coverage(res, alpha=ALPHA_TW)
        return cov >= 1 - ALPHA_TW

    def rollout(self, region, cp, action, K):
        """在孪生里执行 K 条蒙特卡洛 rollout，返回违反约束的比例"""
        viol = 0
        for _ in range(K):
            s = self.state.sample(region, cp)
            for t in range(cp.horizon):
                s = self.dyn.step(s, action, noise=True)
                if violates_constraint(s, cp): viol += 1; break
        return viol / K

    def certify_gap(self, region, heldout_phys):
        """只用留出物理集更新间隙证书；训练集不得复用"""
        tv = [total_variation(p, self.dyn.predict(p.prev, p.action))
              for p in heldout_phys]
        self.gap[region] = GapCert(delta_tw=mean(tv) + 2*std(tv),
                                   dFS=empirical_false_safe(heldout_phys),
                                   dFA=empirical_false_alarm(heldout_phys),
                                   n=len(heldout_phys))
        self.phys_residuals[region] = [p.residual for p in heldout_phys]

    def monitor_and_revoke(self, region, new_phys):
        """在线监测：间隙漂移超阈即吊销证书，孪生退回 UNKNOWN"""
        self.certify_gap(region, self.phys_residuals[region] + new_phys)
        if self.gap[region].delta_tw > DELTA_TW_MAX:
            self.revoke(region)                   # 退回第 58 轮基线
```

### IP-146 TFP（孪生证伪协议）

```python
def twin_falsify(T, cp, actions, budget):
    """返回动作 -> TwinVerdict；PASS 不产生任何证据信用"""
    if not T.certified(cp.region):
        return {a: 'UNKNOWN' for a in actions}, GapCert.none()

    verdicts = {}
    for a in actions:
        if budget.tw_left <= 0: break
        k = min(BUDGET_PER_ACTION, budget.tw_left)
        viol = T.rollout(cp.region, cp, a, K=k)
        budget.tw_spend(k)
        lb, ub = wilson_lower(viol * k, k), wilson_upper(viol * k, k)
        if lb > THETA_TW:
            verdicts[a] = 'FAIL'                 # 保守：剪枝/加宽
        elif ub < THETA_TW_SAFE:
            verdicts[a] = 'PASS'                 # 零信用，只可重排
        else:
            verdicts[a] = 'UNKNOWN'
    return verdicts, T.gap[cp.region]

def apply_twin_verdicts(cp, actions, verdicts, reserved_phys):
    """R1/R3：FAIL 可剪枝，PASS 只重排，物理配额永不被抵扣"""
    feasible = [a for a in actions if verdicts.get(a) != 'FAIL']
    if not feasible:
        return [], 'all_failed'                 # 触发绕行/安全停
    # PASS 仅用于同风险等级内排序，不删除任何必要证据
    order = sorted(feasible,
                   key=lambda a: (risk_rank(a), verdicts.get(a) != 'PASS'))
    assert reserved_phys >= MIN_PHYS_EVIDENCE      # R3 硬断言
    return order, 'ok'

def twin_never_contributes_evidence(cp):
    """硬禁令：任何证据门内禁止查询孪生判定"""
    return True   # EV-twin 不存在；孪生只能出现在 apply_twin_verdicts
```

### IP-147 CEMM（云边单调合并）

```python
def conservative_join(X1, X2):
    """保守序 ⊑ 上的并：结果必须 ⊒ 两个输入（M1）"""
    return NodeState(
        b=convex_hull(X1.b, X2.b),                        # 只能加宽
        K_margin=min(X1.K_margin, X2.K_margin),
        K=X1.K | X2.K,                                    # 带溯源并集
        rho={m: min(X1.rho[m], X2.rho.get(m, X1.rho[m]))
             for m in X1.rho},
        corrob_req=max(X1.corrob_req, X2.corrob_req),
        auth=min_rank(X1.auth, X2.auth),
        VV=vv_componentwise_max(X1.VV, X2.VV),
        ledger_head=merge_heads(X1.ledger_head, X2.ledger_head))

def stale_decay(remote, now):
    age = now - remote.timestamp
    if age > TAU_MAX: return remote._replace(weight=0.0, evidence=[])
    w = exp(-age / TAU_STALE)
    return remote._replace(weight=w, K=fresh_only(remote.K, w))

def cloud_edge_merge(local, remote, now):
    if not vv_compatible(local.VV, remote.VV):
        remote = quarantine(remote)                       # 版本不可比 ⇒ 隔离
    remote = stale_decay(remote, now)
    merged = conservative_join(local, remote)
    assert merged <= local and merged <= remote           # M1 单调断言
    return local_guard(merged, local)                     # M2 本地否决

def local_guard(merged, local):
    """边端否决：不可逆相关状态不得比本地更放松；云端不得撤销本地撤回"""
    if merged.auth > local.auth: merged.auth = local.auth
    if merged.K_margin < local.K_margin:
        merged = merged._replace(K_margin=local.K_margin)
    if merged.allows_irreversible() and not local.allows_irreversible():
        return local                                      # 一票否决
    return merged

def accept_cloud_narrowing_proposal(local, proposal):
    """云端提案只有经本地物理复验且合并后仍 ⊒ 原状态才生效（M2）"""
    if not local_reverify(proposal.evidence, local): return local
    merged = conservative_join(local, proposal)
    return merged if merged <= local else local
```

### IP-148 VEL（版本化证据账本）

```python
class VersionedEvidenceLedger:
    def __init__(self):
        self.chain = []
        self.epoch = 0
        self.vv = {}

    def append(self, evidence, prov, sig):
        parent = self.chain[-1].hash if self.chain else GENESIS
        e = Entry(evidence=evidence, prov=prov, vv=dict(self.vv),
                  epoch=self.epoch, parent=parent, sig=sig)
        e.hash = hash_entry(e)
        self.chain.append(e)
        return e

    def verify(self, other):
        if not common_ancestor(self, other): return False, 'no_ancestor'
        if self.has_epoch_conflict(other):   return False, 'epoch_conflict'
        if replay_or_rollback(other):        return False, 'replay_or_rollback'
        if not verify_sig_chain(other.chain): return False, 'bad_sig'
        return True, 'ok'

    def retract(self, target_hash, reason, sig):
        """撤回只追加新 epoch；历史不可删改"""
        self.epoch += 1
        self.append(Retraction(target=target_hash, reason=reason), 'retract', sig)

    def merge(self, other):
        ok, why = self.verify(other)
        if not ok: return quarantine(other), why
        for e in append_only_difference(self.chain, other.chain):
            self.chain.append(e)
        self.vv = vv_componentwise_max(self.vv, other.vv)
        return self, 'merged'
```

```python
def allocate_budget(cp, actions, budgets, T, M):
    """五预算分配：孪生便宜但不作证、云端广但会过期、物理贵但权威"""
    best, best_val = None, -inf
    for plan in candidate_plans(cp, actions):
        if plan.phys < reserved_phys(cp):        # C1：不可逆物理配额

               - LAMBDA_TW * plan.tw
               - LAMBDA_CLOUD * plan.cloud
               - LAMBDA_PHYS * plan.phys)
        if val > best_val: best, best_val = plan, val
    return best
```

**正确性定理（Twin-Falsifying, Cloud-Edge Monotone Soundness, TCMAS）**

假设 A22–A45（第 53–58 轮）成立；并新增：
**(A46) 孪生持证与间隙诚实**：孪生只在与训练集不相交的留出物理集 𝒟_phys(r) 上校准 δ_tw/δ_FS/δ_FA；|𝒟_phys|<N_tw 或覆盖<1−α_tw ⇒ 输出 UNKNOWN；间隙漂移超阈即吊销。
**(A47) 合并单调**：convex_hull 加宽、逐项 min/max 保守、VV 逐分量 max；合并结果在保守序 ⊑ 上 ≥ 两输入（M1）；云端收窄提案须本地复验且仍 ⊒ 合并前（M2）；边端对不可逆接触保留否决。
**(A48) 陈旧有界**：版本向量不可比或 age>τ_max ⇒ 证据权重归零；w_stale=exp(−age/τ_stale) 单调不增。
**(A49) 账本完整**：条目签名、parent 哈希链、epoch 单增；回放/回滚/跨 epoch 冲突可检出；撤回只追加。
**(A50) 物理保留**：不可逆接触必要证据集含至少一个本地物理证据；孪生与云端（含 EV-fleet）不得抵扣该配额。

则：
1. **孪生单向性（核心）**：对任意动作 a，TwinVerdict(a)=PASS 不产生任何证据信用，故孪生漏报 δ_FS 不进入承诺失效界；TwinVerdict(a)=FAIL 只移除动作或加宽后验。因此孪生的全部安全影响是单向的（只能更保守），其错误只表现为误报成本（δ_FA）而非虚假安全。**δ_tw 不出现在 P_safe 的失败项中。**
2. **云边单调性**：任意合并序列在保守序上不减；分裂脑、版本偏斜、陈旧云端证据只能使系统更保守。云端无法收窄边端、无法撤销边端撤回、无法绕过边端否决；因此"云端被俘获"不能直接制造不安全承诺，只能制造拒绝服务/低效。
3. **陈旧与账本健全性**：超过 τ_max 的云端证据权重为 0；账本缺口/回滚/重放被检出后进入隔离，未通过校验的证据不进入合并。因此陈旧与通道攻击的贡献分别以 δ_stale、δ_ledger 计入部署界，且随版本收敛而消失。
4. **终止性**：TCB 五预算有限、每轮至少消耗一单位（孪生 rollout、云边往返、物理探针、微调、UX 升级各自单调），PCX+++ 在 K_tw+k_p+k_c+k_ft+k_ux+k_cloud 内终止于 {承诺, 绕行, L2 协商, 安全停}；孪生异步 rollout 不阻塞主回路。

部署界（对检查点取联合界）：
```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                   + δ_ft·1[回滚窗口] + δ_kg·1[检索失败] + δ_ux·1[μ_mis>θ_mis]
                   + δ_fleet·1[EV-fleet] + δ_stale·1[合并] + δ_ledger·1[账本缺口])
         − P(不可逆物理配额被预算耗尽) − P(本地否决失效) − P(τ_int 超时∧安全停失效)
```
关键不等式：**δ_FA 只进入效率项，δ_FS 不进入安全项**；这是"孪生只证伪"带来的结构性收益——孪生可以经常错，但只能错在"多拒绝"。

## 6. 本轮最大风险

**一句话**：孪生、云端与第 58 轮 KG 很容易由同一批历史语料共同训练，于是"孪生验证云端、云端再训练孪生"形成自我确认的闭环——系统在被系统性误建模的世界里反而更快、更自信；必须以"孪生只证伪（PASS 零信用）、云端只加宽（本地否决）、不可逆永远物理（配额硬保留）、账本独立可核验（留出集不回流）"四条硬约束，确保闭环里始终存在一个不来自该语料的外部物理锚点。
