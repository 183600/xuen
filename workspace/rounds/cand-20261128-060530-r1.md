### 第 6 轮灵感驱动研究记录（新循环第 1 轮，承接 CADVS-v5）

**灵感词**：预训练、多模态大模型

**继承关系**：继承第 5 轮 CADVS-v5（IP-493~496）「认证的生成式执行（CGE）」：七硬门 kc_evidence_forged_v4 与 τ^4 冻结只读、定理 5~8、执行集 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。v5 已把「单轨迹提议器」从离散规则推广到任意生成分布，并用定理 6 证明证书与提议无关。但 v5 仍留两个结构性缺口：(a) 提议器是**按部署从零训练**的小模型，不读自然语言、不理解开放世界语义，只能在见过的物体/任务上泛化；(b) 七门全是**安全/可行性门**，从不检查「这条轨迹是否真的完成了人类想要的任务」——v5 能证明「动得安全」，不能证明「做得对」。本轮用两个灵感词补这两个缺口，主题定为「**认证的基础模型执行**（Certified Foundation Execution, CFE）」，形成 CADVS-v6（IP-497~500）。自律延续前几轮：**安全硬门数量不增**（仍七门）；基础模型的能力只准进入**提议分布**与**软评分**，任何需要「信任」的语义判断都必须先被**编译成可符号检查的形式规格**，再由**共形校准**做分布无关的弃权（abstention）。执行集升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **预训练 → 基础模型带来开放世界先验，但「预训练不能洗白门」**。直觉：预训练模型像一位见多识广、却会一本正经胡说八道的老师傅——能提出你从没见过的方案，也会自信地给出错误方案。v5 的定理 6 已给出安全底座：**换提议器不换门**。因此无论基础模型多强、是否在铸证数据上继续预训练/微调，它只能改变 supp(π_F)，不能扩大执行集；这条「提议-门分离」是本轮定理 9。预训练真正可兑现的资源有两个：(a) 开放世界**语义先验**（语言指令、物体功能、任务常识），把提议从「见过的轨迹」推广到「没见过但合理」；(b) 预训练世界模型的**能量/密度**，作为比 v5 部署内流似然更宽的 OOD 先验（缓解 R53 的密度盲区，但不消除）。二者都只作用于提议与软因子。

2. **多模态大模型 → 语义意图必须被「编译」成形式规格，而不是交给一个不可验证的裁判**。直觉：v5 的七门回答「这样动安不安全」，从不回答「这样动对不对」。直接加一个「MLLM 语义门」会破坏硬门的形式谓词性质（不可审计、可被提示注入、可被对抗样本欺骗），等于把信任边界建在流沙上。本轮的解法是 **LLM 提议、符号裁决**：多模态大模型把（自然语言意图 + 多模态场景）**编译**成一个人类可读、机器可判定的形式规格 φ（场景图谓词 + 有界时序逻辑），再由**确定性符号检查器** C(φ,x) 对实际 rollout 判定。φ 是显式、可 diff、可人工审阅的工件；学习只发生在「意图→φ」的翻译处，翻译正确性由**人工抽检**与**共形弃权**共同兜底。这把不可验证的语义裁判，替换成「可验证的规格 + 可度量的翻译错误率」。

3. **共形校准 → 给「何时该信基础模型」一个分布无关、有限样本的保证**。直觉：基础模型的置信度（logit/自评）系统性过度自信，不能直接当阈值。共形预测只要求校准集与部署**可交换**，就能给出覆盖率的有限样本下界。我们用它做三件事：(a) 语义接受集的**误接受率 ≤ α**；(b) 开放世界 OOD 的**弃权阈值** τ_abst（校准而非拍脑袋）；(c) 跨域时用加权/在线共形跟踪覆盖率退化。弃权永远只**删候选**（fail-closed），所以共形层只会让执行集更小，不会更大（定理 12）。一个额外收获：共形校准要求**人工标注的语义成功/失败**，等于以抽样方式把**外部真值**重新注入系统，从而部分偿还 v5 最大风险 R57（固化自指回路缺外部真值）——但只偿还「语义层」，不偿还「安全层」，且只给边缘覆盖，不给条件覆盖。

**关键洞见**：v5 回答「任意单轨迹提议器下证书边界不变」；v6 回答「**当提议器是一个会读语言、会看世界、会胡说八道的基础模型时，如何让『安全』仍由形式门负责、让『正确』由可审计规格负责、让『该不该信』由共形弃权负责**」。七硬门原样冻结；新增的是：基础模型提议器 π_F（预训练 VLA/VLM）、形式规格编译器 FSC（意图→φ）、共形能力校准器 CCC、装配器 EFA-v6。执行集 Exec_v6 = {x ∈ X : ∧_i kc_i(x;τ_i^5)=1 ∧ C(φ,x)=1 ∧ Abs(x)=0}。规格检查与弃权都是**前置过滤**（收缩支撑），不是第八门；无规格、无弃权时精确退化为 v5。

**形式化目标（增量）**：
1. 基础模型提议 π_F(·|ℓ,o,m,ŝ_emo)：ℓ 为语言意图、o 为多模态观测、m 为检索记忆，输出候选轨迹/子目标；只在准入时域（秒级）运行，与控制环解耦。
2. 形式规格编译器 FSC：(ℓ,o) → φ ∈ Φ（受限文法下的场景图谓词 + 有界时序逻辑）；符号检查器 C(φ,x)∈{0,1}，可靠性由人工抽检错误率 ε_spec 刻画。
3. 共形校准 CCC：非一致性分数 r(x)=1−p̂_success(x,φ)（含多模态一致性、世界模型能量作为分量），校准得阈值 q_{1−α}，保证 P(接受 ∧ 语义失败) ≤ α（可交换性下，边缘）。
4. 弃权算子 Abs(x)=1[r(x)>q_{1−α}]，fail-closed 回退 v5 的 FMPP 部署策略；能力包络 K_ε 之外的输入强制弃权。
5. 定理 9（提议-门分离/预训练不可洗白）、定理 10（共形语义覆盖）、定理 11（规格健全性边界）、定理 12（弃权单调收缩）、定理 13（跨域共形退化界）；引理 49（预训练世界模型能量的 OOD 谬拒界）。
6. Exec_CADVS-v6 = {x ∈ X : ∧_i kc_i(x;τ_i^5)=1 ∧ C(φ,x)=1 ∧ Abs(x)=0} ⊆ Exec_CADVS-v5。

**本轮最大风险**：**规格编译幻觉（specification hallucination / Goodhart）**——系统会「健全地」满足一个由多模态大模型写错的 φ；一旦 φ 错或可被博弈，证书就从「证明安全」退化为「严格证明了一件错事」，而共形覆盖只是对校准分布的边缘保证，无法证明语义意图本身正确。

### IP-497 FMPK：基础模型提议核（准入/秒级，不在 1 kHz 环）

```python
@dataclass
class FoundationMultimodalProposalKernel:
    """FMPK：预训练 VLA/VLM 作开放世界提议器。
    定理 9（提议-门分离）：无论怎样预训练/继续预训练/微调，
    只改变 supp(π_F)，永不改变门 G_5。"""
    vla: Any                      # 预训练 VLA/VLM（冻结或 LoRA），语言/视觉/本体条件
    world_model: Any              # 预训练世界模型（能量/密度）
    S: int = 10                   # 蒸馏/解码步数
    K: int = 8

    def propose(self, intent, obs, mem, s_emo, k: int = None) -> list[Trajectory]:
        c = fuse(intent, obs, mem, s_emo)          # 多模态条件融合
        plans = self.vla.decode(c, k=k or self.K)  # 语言条件候选（可含子目标）
        return [self._to_trajectory(p) for p in plans]

    def energy(self, x, c) -> float:
        """预训练世界模型能量 E_pre(x)，作 OOD 先验（引理 49）；不进门"""
        return self.world_model.neg_log_lik(x, c)

    def in_envelope(self, x, c, q_eps: float) -> bool:
        return self.energy(x, c) <= q_eps          # 能力包络 K_ε
```

### IP-498 FSC：形式规格编译器与符号检查器（LLM 提议、符号裁决）

```python
@dataclass
class FormalSpecCompiler:
    """FSC：把（意图, 观测）编译成形式规格 φ，再由确定性检查器判定。
    设计红线：LLM 只产出 φ（受限文法 AST），绝不直接给「通过/拒绝」。"""
    mllm: Any
    grammar: Any                  # Φ 的受限文法（场景图谓词 + BTL）
    ontology: Any                 # 物体/关系/区域类型系统
    spec_cache: dict              # (hash(intent, scene_sig)) → φ，秒级编译一次

    def compile(self, intent, obs) -> SpecResult:
        key = (hash(intent), scene_signature(obs))
        if key in self.spec_cache:
            return self.spec_cache[key]
        ast = constrained_decode(self.mllm, intent, obs, self.grammar)  # 语法受约束
        if ast is None or not typecheck(ast, self.ontology):
            return SpecResult(ok=False, reason='ILLTYPED_OR_UNPARSEABLE')  # 弃权
        res = SpecResult(ok=True, phi=ast, hash=sha256(canonical(ast)))
        self.spec_cache[key] = res
        return res

    def check(self, phi, x) -> bool:
        """确定性符号检查器 C(φ,x)：在 rollout 场景图上求值，无学习、可复现"""
        return symbolic_eval(phi, rollout_scene_graph(x))   # O(|φ|·T)
```

### IP-500 EFA-v6：七硬门冻结 + 规格前置过滤 + 共形弃权 + 两级路由

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：安全由七门负责，正确由 φ 负责，该不该信由共形弃权负责。
    规格检查与弃权都是前置过滤（收缩支撑），不是第八门。"""
    fmpk: FoundationMultimodalProposalKernel
    fsc: FormalSpecCompiler
    ccc: ConformalCompetenceCalibrator
    v5: EvidenceForgingAssemblerV5          # 七门 + FMPP 回退

    def select(self, intent, obs, t_now, context) -> tuple[bool, Trajectory | None, str]:
        # 1) 编译规格（秒级；按任务/场景缓存，失败即回退 v5）
        spec = self.fsc.compile(intent, obs)
        if not spec.ok:
            return self.v5.select(intent, obs, t_now, context)   # ILLTYPED_SPEC
        # 2) 提议（能力包络内用基础模型，否则回退部署内 FMPP）
        if self._in_envelope(obs, context):
            cands = self.fmpk.propose(intent, obs, context.mem, context.s_emo)
        else:
            return self.v5.select(intent, obs, t_now, context)   # OUT_OF_ENVELOPE
        # 3) 前置过滤：v5 七门（冻结）→ 符号规格 → 共形弃权
        surv = []
        for x in cands:
            if not self.v5._cheap_gates(x, gamma=context.gamma):     # G_5（定理 9）
                continue
            if not self.fsc.check(spec.phi, x):                      # 符号裁决
                continue
            if self.ccc.abstain(x, spec.phi):                        # 共形弃权
                continue
            surv.append(x)
        if not surv:
            return self.v5.select(intent, obs, t_now, context)       # fail-closed 回退
        # 4) 昂贵门与 v5 相同（VACK 调制 + BCK 预览），取 ECS_v6 最大者
        finals = [x for x in surv[:3] if self.v5._vack_ok(x, context)]
        ok = [x for x in finals if self.v5._bck_preview(x, context.gamma)]
        if not ok:
            return False, None, 'ALL_CANDIDATES_REJECTED'
        best = max(ok, key=lambda x: self.ecs_v6(x, context, spec))
        return True, best, 'FORGED_CFE'

    def _in_envelope(self, obs, context) -> bool:
        return self.fmpk.in_envelope(obs, context, self.ccc.q_eps)

    def ecs_v6(self, x, context, spec) -> float:
        eta_found = sigmoid(self.fmpk.energy(x, context) - self.b_found)
        eta_sem = self.ccc.critic(x, spec.phi) if self.fsc.check(spec.phi, x) else 0.0
        return self.v5.ecs_v5(x, context) * eta_found * eta_sem
```

```python
# 引理 49：预训练世界模型能量的 OOD 谬拒界（分布内）
def lemma49_energy_false_rejection() -> str:
    """

    return "Proven"

# 定理 10：共形语义覆盖（分布无关、有限样本）
def theorem_conformal_semantic_coverage() -> str:
    """
    定理 10：设 (Z_i,Y_i) 校准与测试可交换，Z=(o,ℓ,φ,x)，Y∈{success,fail}，
    r(z)=1−p̂_success(z)，q 为 ⌈(n+1)(1−α)⌉/n 经验分位。接受集 A={z:r(z)≤q}。

    """

# 定理 11：规格健全性边界（诚实边界，不可形式化根除）
```

## 4. 正确性论证（增量更新）

### 引理 49（预训练世界模型能量的 OOD 谬拒界）

**陈述**：设 E_pre 为预训练世界模型能量，ID 校准集上取共形阈值 q_ε（1−α 分位）。若部署 ID 样本与校准可交换，则 P(E_pre(x) > q_ε) ≤ α。

**证明**：共形分位的交换性论证。∎

**诚实边界**：该界只约束 ID 的**误弃权**；OOD 的**假接受**无分布无关界——任何能量/密度模型都有盲区。因此 E_pre 只作先验与弃权信号，OOD 最终由「能力包络外回退 v5 FMPP」兜底，而非由能量模型兜底。

### 引理 50（受限文法消除语法错误，不消除语义错误）

**陈述**：若 φ 由受限文法 Φ 约束解码产生并通过类型检查，则 φ 必然可解析、可执行；剩余错误仅为语义错误（φ 不等于意图），其率由 ε_spec 刻画。

**证明**：约束解码保证 AST ∈ L(Φ)；类型检查保证算子/关系类型一致。语义等价性不在文法内可判定。∎

**推论**：FSC 的失败模式被压缩为「语义错误」一类，便于用单一指标 ε_spec 监控与审计。

### 定理 9（提议-门分离 / 预训练不可洗白）

**陈述**：令 G_5 = {x : ∧_{i=1}^7 kc_i(x;τ_i^5)=1}。对任意提议分布 π（包括任意预训练、继续预训练、微调、甚至对抗性的基础模型），
Exec(π) = {x ∈ supp(π) : x ∈ G_5 ∧ C(φ,x)=1 ∧ ¬Abs(x)} ⊆ G_5。
因此换 π 不换边界；任何 π→π' 更新只改变被尝试的候选，不能扩大 Exec。特别地，在自铸证数据上继续预训练（v5-R57 自指回路）也不洗白安全边界（推论 9.1）。

**证明**：G_5、C(φ,·)、Abs 的定义均不含 π，π 只出现在 supp(π) 的交集中；交集随被交集合固定而单调。∎

**意义**：这是本轮的安全底座——基础模型的全部能力被限制在「提议」侧，安全边界仍由形式门定义。它把 v5 的定理 6 从「换提议器」强化为「换任意预训练/对抗提议器」。

### 定理 10（共形语义覆盖）

**陈述**：设 (Z_i,Y_i)_{i=1}^n 与 (Z_test,Y_test) 可交换，Z=(o,ℓ,φ,x)，Y∈{success,fail}，r(z)=1−p̂_success(z)，q 为 ⌈(n+1)(1−α)⌉/n 经验分位，接受集 A={z:r(z)≤q}。则边际覆盖 P(Y_test∈{success}) ≥ 1−α，等价地 P(Accept ∧ Y=fail) ≤ α。

**证明**：split conformal 的标准交换性论证（含 n+1 个分数的秩均匀性）。∎

**诚实边界**：(i) 只给**边缘**覆盖，不给条件覆盖（不同场景/物体分组可能远超 α）；(ii) 可交换性被对抗性漂移破坏时保证失效（见定理 13）；(iii) Y 依赖人工标注，标注噪声/审计缺口直接污染保证。

### 定理 11（规格健全性边界）

**陈述**：若符号检查器 C 对 φ 健全（C(φ,x)=1 ⇒ x⊨φ），则任何被接受的 x 满足**编译后的** φ。但「φ 是否等于人类真实意图」不可形式证明，只能由抽样人工审计的错误率 ε_spec 经验刻画。

**证明**：健全性由 C 的定义直接给出；语义等价性无形式判据（意图是自然语言对象，非形式对象）。∎

**诚实声明**：证书保证「x 满足 φ」，**不保证**「x 满足意图」。这是本轮无法根除的边界，也是最大风险（规格幻觉）的根源。

### 定理 12（弃权与规格过滤的单调收缩）

**陈述**：在门与阈值冻结（G_5 不变）下，追加 Sem_φ 与 ¬Abs 两个指示过滤，
Exec_v6 = G_5 ∩ Sem_φ ∩ ¬Abs ⊆ G_5 = v5 安全边界。
结合定理 9，π 的预训练/固化更新不能使 Exec 增大。故「预训练 + 固化 + 弃权」只会更小或不变。

**证明**：指示过滤取交集；定理 9 保证 π 不影响 G_5。∎

### 定理 13（跨域共形退化界）

**陈述**：若部署相对校准为协变量漂移，密度比 w=dP_dep/dP_cal 已知，则加权共形恢复覆盖 ≥ 1−α；若用估计 ŵ 且 ‖ŵ−w‖_1 ≤ ε_w，则覆盖 ≥ 1−α−ε_w/2（草图）。

**证明**：加权共形（Tibshirani et al. 2019）的加权交换性 + 权重误差的 L1 扰动。∎

**诚实边界**：对抗性/支撑外漂移下 w 不可估，保证失效；在线共形只能跟踪退化，不能预防。

### 定理 v6（执行集收缩与语义接入，总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8)「校准与部署可交换（或漂移有界）」下：
(i) Exec_CADVS-v6 ⊆ G_5 = v5 安全边界（同门 + 规格过滤 + 弃权，定理 12）；
(ii) 提议-门分离：任意预训练/对抗提议器不扩大 Exec（定理 9）；
(iii) 语义误接受率边际 ≤ α（定理 10）；
(iv) 被接受轨迹满足编译规格 φ（定理 11），但 φ 与意图的等价性仅由 ε_spec 经验刻画；
(v) 跨域覆盖按定理 13 退化；
(vi) 七锚完备性与定理 5~8 原样保持（本轮不增删安全门）。

**证明**：(i)(ii) 定理 12/9；(iii) 定理 10；(iv) 定理 11；(v) 定理 13；(vi) 门集合不变。∎

**诚实声明**：(B8) 可交换性在真实部署中常被违反（新房间/新光照/新任务），只能用加权/在线共形跟踪；(iv) 的意图等价性不可形式化；(ii) 只保护安全边界，不保护「语义正确性」——语义层可被规格博弈（Goodhart）。

## 7. 本轮最大风险（最终确认）

**一句话**：**规格编译幻觉（specification hallucination / Goodhart）**——系统会「健全地」满足一个由多模态大模型写错的 φ；一旦 φ 错或可被博弈，证书就从「证明安全」退化为「严格证明了一件错事」，而共形覆盖只是对校准分布的边缘保证，无法证明语义意图本身正确。
