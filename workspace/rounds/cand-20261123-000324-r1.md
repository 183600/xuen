## 1. 两个灵感的第一性原理

### 灵感 1 ·「机械臂抓取」→ 抓取是一个可计算的谓词，不是一个学出来的隐变量

**直觉**：v2 的 IP-02 把「抓住没有」当作一个带置信度的隐变量，从成功演示里学一个判别器。这在数据上先天残缺（演示全是成功，见 v2 负样本困境）。但抓取和「插入最后一厘米」不同：它有一整套四十年的经典力学——接触、摩擦锥、力封闭。给定接触几何与摩擦，一个抓取「好不好」是**可以算出来的**，不需要先看过一万次失败。把可计算的先算掉，只把真正算不出的残差交给学习，这才是数据效率最高的接地层。

**严谨骨架**：

- 设接触点 `p_i`、单位法向 `n_i`、摩擦系数 `μ`。接触 `i` 的单位法向力旋量 `w_i = [n_i; p_i × n_i] ∈ R^6`（相对质心）。
- 线性化摩擦锥的每条棱给一个单位方向 `d_{ij}`，原语旋量 `w_{ij} = [d_{ij}; p_i × d_{ij}]`；抓取矩阵 `G = [w_{ij}] ∈ R^{6×mk}`。
- 可达旋量锥 `W = {G f : f ≥ 0}`；**ε-质量**（Ferrari–Canny）：`ε(g) = max{ ε : ε·B_6 ⊆ conv(G) }`，`B_6` 为六维单位球。`ε(g) > 0` ⇔ 力封闭。
- 对给定外旋量 `w_ext`（重力+惯性），**握力可行性**是线性规划：`∃ f ≥ 0, G f = −w_ext`；同时检查握力不超过执行器上限。
- **抓取证书** `cert(g) = (ε(g), f*(g))`：`ε` 是抗扰裕度，`f*` 是所需握力。执行「合爪—抬起」前，只有 `ε(g) > ε_min` 且 `f*(g) ≤ f_max` 才放行。

**策略含义**：把 IP-02 从「学一个分类器」升级为「算一个证书 + 学一个残差」。证书负责高精度、可解释、可审计的否决；学习只补证书算不出的部分（视觉接触估计误差、软接触、非刚体）。

### 灵感 2 ·「虚拟仿真」→ 仿真在抓取层是可信的 oracle 与反事实工厂，而不是长程评测的替代品

**直觉**：v2 把仿真/世界模型当成「评测替代」与「负样本合成」，但长程视频生成的保真度是死穴（IP-10 的「假安全」）。换一个视角：**仿真的价值不在「像真机」，而在「能算真值、能做反事实」**。对刚体抓取，物理引擎直接算「会不会滑、会不会弹飞、会不会碰倒」——这是**物理真值**，不是生成的幻觉；而且可以做**干预**（把摩擦改成 0.3 再看结果），这在真机数据里永远做不到。

**严谨骨架**：

- **SimGraspOracle**：输入对象网格 + 惯性参数 + 候选抓取 + 物理引擎；输出 `y ∈ {success, slip, eject, collision, miss}`。失败标签由物理计算，不经生成模型。
- **sim-to-real 差距** `ε_s = TV(P_real(y|x), P_sim(y|x))`；用少量真机抓取日志标定。由于刚体接触误差不随长程复合，`ε_s(grasp) ≪ ε_s(long-horizon video)`。
- **分布无关覆盖**：用 conformal prediction，以仿真分数为 score、真机小样本为校准集，给出覆盖 `1−α` 的预测集；`α` 是「证书认错」的预算。
- **反事实课程**：在仿真里对 `(抓取位姿 × μ × 质量 × 质心 × 接近速度)` 做干预采样，生成**平衡**的成功/失败集，专门覆盖真机罕见失败模式（低摩擦滑脱、高速弹飞、偏质心旋转）。

**策略含义**：v2 的负样本困境在**抓取层**被解开——不是靠更逼真的生成，而是靠**更窄、更可算、更可干预**的物理域。IP-10 因此被修剪：抓取层用物理仿真，操作层才留给 WMA-0/扰动回放。

### 交汇 · SimCertifiedGrasp（仿真认证抓取）：算证书、验残差、按不确定性退让

两条灵感合成一个**级联**接地器：

| 层 | 组件 | 职责 | 何时退让 |
|---|---|---|---|
| L1 解析 | 力封闭证书 `cert(g)`（含参数区间） | 高精度否决/放行 | 参数区间太宽 → 交给 L2 |
| L2 学习 | IP-02 残差判别器（仿真+真机混合训练） | 补软接触/视觉误差 | 置信低 → 交给 L3 |
| L3 监控 | 仅断言监控 + 纯 VLA（Level-1.8） | 兜底 | — |

一句话：**证书负责「确定的坏」，学习负责「不确定的灰」，状态机负责「什么时候认输」。**

## 2. 研究问题（新增 Q10–Q13，接上轮 Q1–Q9）

- **Q10（证书的可观测性）**：在「腕部相机 + 1 维夹爪 + EE 位姿」的接口下，接触点/摩擦/质量能被估到什么精度？证书对这些隐参数的敏感性（Lipschitz 常数）多大？交互探针（轻夹—轻抬）能把区间收窄多少？（E628/E632）
- **Q11（仿真 oracle 的保真与校准）**：Dex1 与平行夹爪的 sim-to-real 抓取结果差距各多大？conformal 校准能否给出有覆盖保证的「证书认错」上界？（E629/E633）
- **Q12（证书级联的净收益）**：在等数据/等算力下，「证书+残差级联」相对纯学习判别器（IP-02 v2）能多拿多少抓取成功率、少多少误介入？（E630）
- **Q13（反事实课程的可迁移性）**：仿真反事实课程训练出的残差判别器，在未见物体（OOD）上的抓取失败识别能否保持？（E631）

## 3. 设计原则（新增 P10–P12，接上轮 P1–P9）

- **P10（先算后学）**：凡是经典力学能算的（力封闭、握力可行性、静摩擦滑移边界），必须先用解析式计算并给出证书；学习只处理解析式覆盖不到的残差。禁止用大模型去拟合一个可解析谓词。
- **P11（仿真信任域显式化）**：仿真不是全局可信，而是**按技能层分域可信**。任何「用仿真当真值」的组件必须声明域（抓取/操作）、末端执行器、以及该域的 sim-to-real 差距测量（E629）；未测量的域一律不信。
- **P12（认错优于装懂）**：证书与判别器都必须能输出「不确定」并退让（abstain）。**一个自信的错证书比一个诚实的「不知道」更危险**；所有证书必须带参数区间与退让规则。

## 5. 本轮最大风险（更新）

上轮「合成负样本假安全」「伺服/VLA 打架」「会话记忆合规」继续成立；本轮叠加一条**结构性风险**：

**证书的输入是弱可观测的隐参数，而证书的输出却极其自信。** 力封闭证书依赖接触点、法向、摩擦、质量/质心，而官方接口只给腕部相机 + 1 维夹爪 + EE 位姿——这些量要么被遮挡、要么根本不在观测里。若我们把「估出来的接触」当成「真接触」，证书会以数学的确定性给出错误结论：**一个被「认证」的抓取在真机上滑脱，比一个被「怀疑」的抓取更伤**。更糟的是 Dex1 多指柔顺接触，仿真保真与接触估计都更难，证书可能只在平行夹爪上成立。对冲：P12 强制区间/退让、E632 专测可观测性敏感性、E633 分末端执行器标定、Level-1.8 兜底、以及「证书只否决、不单独放行高风险抓取」的双闸门。

## 0. 本轮结论摘要

**一句话路线**：v2 的三层栈（接地→技能→适应）+ 工程层保持不变；本轮把接地层的抓取子问题**从「学习隐变量」改为「物理证书 + 仿真 oracle + 学习残差」**：用经典抓取力学算力封闭证书（IP-13），用物理仿真做抓取失败的真值 oracle 与反事实工厂（IP-14），用反事实课程训练残差与 OOD 泛化（IP-15）。核心收益：在抓取层**绕开 v2 世界模型负样本的保真度死穴**，把「数据效率」与「可解释否决」同时拿下。

三条结构性依据：

| 依据 | 事实 | 推出的设计 |
|---|---|---|
| H3 抓取是力封闭谓词（经典理论） | 接触几何 + 摩擦 + 惯性 ⇒ ε-质量可算 | IP-13 解析证书，先算后学（P10） |
| H4 刚体接触 sim-to-real 可测且小 | 误差不随长程复合 | IP-14 仿真作抓取 oracle，域内可信（P11） |
| v2 负样本困境（演示全成功） | 抓取失败标签稀缺 | 仿真直接生成物理真值失败 + 反事实干预（IP-14/15） |

## 3. 新增/深化 IP 详述

### IP-13 · GraspCert 力封闭证书 + 参数区间 + 双闸门（P0，新）

- **动机**：v2 的 IP-02 是纯学习判别器，受制于「演示全成功、无失败监督」。抓取有可解析的力封闭判据（H3），应先把「可计算的」算掉，减少对失败数据的依赖。
- **与现有方案差异**：不是「又一个抓取质量网络」，而是**带参数区间的解析证书 + 学习残差 + 监控**的三级级联。证书输出 `(ε, f*, δ)`：`ε` 抗扰裕度、`f*` 所需握力、`δ` 参数不确定半径。闸门是「鲁棒 ε」`ε_est − L·δ ≥ ε_min` 且 `f* ≤ f_max`。
- **技术可行性**：高（平行夹爪）/ 中（Dex1）。接触点与法向由腕部深度/点云 + 夹爪开合量估计；摩擦与质量/质心用区间先验 + 轻夹—轻抬探针收窄。ε 与握力 LP 在毫秒级可解。
- **资源**：数据=对象网格 + 少量真机抓取日志；算力=小；接口=无新增字段（证书随 checkpoint 交付）。
- **落地步骤**：①按任务建对象几何/惯性先验库（可复用 IP-06 标注）；②实现线性化摩擦锥 + ε-质量 + 握力 LP；③参数区间估计与 Lipschitz 常数 `L` 标定（E628）；④双闸门：证书「确定坏」→ 重抓/换抓取；「确定好」→ 放行；「不确定」→ 交 IP-02 残差；⑤真机 A/B（E630）。
- **风险**：①弱可观测导致自信的错证书 ⇒ 区间 + abstain + 只否决高风险抓取；②Dex1 柔顺接触不满足刚体假设 ⇒ 仅粗否决（E633）。

### IP-14 · SimGraspOracle 抓取域物理 oracle + conformal 校准（P0，新）

- **动机**：v2 的 IP-10 用 WMA-0 生成失败视频，存在「假安全」；抓取失败可由物理引擎直接计算（H4），是更可靠的负样本来源。
- **差异**：把仿真从「生成式数据引擎」换成**判别式真值 oracle**：输入抓取与对象参数，输出物理结果类别（success/slip/eject/collision/miss），并用真机小样本做 conformal 校准，给出有覆盖保证的预测集。
- **可行性**：高。刚体接触在主流物理引擎（Isaac Lab / MuJoCo）上稳定；标定只需几十次真机抓取。
- **步骤**：①对象集与摩擦参数标定协议；②仿真抓取结果与真机结果对齐（E629）；③conformal 校准（分数=仿真置信，校准集=真机）；④输出「域内可信」标签给 IP-02/IP-13；⑤按末端执行器分别报告差距（E633）。
- **风险**：摩擦/质心标定偏差导致系统性偏移 ⇒ 用区间 + 校准集重加权；Dex1 柔顺接触保真不足 ⇒ 抓取层仅用于平行夹爪，Dex1 退回学习。

### IP-15 · CounterfactualGraspCurriculum 反事实抓取课程（P1，新）

- **动机**：真机数据里失败罕见（v2 负样本困境）；仿真可做**干预**，直接生成平衡的失败集，且专攻罕见模式。
- **差异**：不是「域随机化堆数据」，而是**定向反事实**：对 `do(μ=μ')`、`do(m=m')`、`do(grasp=g')`、`do(v_approach=v')` 采样，针对残差判别器当前的失败盲区补样（主动学习闭环）。
- **步骤**：①定义干预谱与失败类别；②仿真批量生成 + 去重；③按残差判别器的不确定性主动采样；④训练残差 + OOD 切分（E631）；⑤与 IP-12 课程调度器对接。
- **风险**：仿真干预分布不迁移真机 ⇒ 只用其做预训练、真机小样本微调（P8 强制流程）；OOD 无增益则并入普通域随机化。

### IP-02（重写）· GraspVerify = 证书级联

- **L1 证书**：IP-13 的鲁棒 ε 与握力可行性 → 高精度否决/放行。
- **L2 残差**：学习判别器（输入证书特征 + 视觉 + 夹爪/EE 时序），用 IP-14 仿真标签预训练、真机小样本微调（IP-15 课程）。
- **L3 监控**：仅路标断言监控 + 纯 VLA（Level-1.8）。
- **闸门**：`z=bad ⇒ 放弃/重抓`；`z=good ⇒ 执行`；`z=abstain ⇒ L2`。阈值按 v2 成本敏感 `p*_s`，但验收指标改为**否决组失败率（precision）**（见 L13）。

## 4. 符号与定义（新增 U16–U20；U1–U15 沿用前两轮）

- **定义 U16（接触模型与抓取旋量空间）**：接触集 `C = {(p_i, n_i, μ_i)}`；线性化摩擦锥棱方向 `d_{ij}`；原语旋量 `w_{ij} = [d_{ij}; p_i × d_{ij}]`；抓取矩阵 `G = [w_{ij}] ∈ R^{6×mk}`；可达旋量锥 `W = {G f : f ≥ 0}`。
- **定义 U17（鲁棒 ε-证书）**：`ε(g) = max{ε : ε·B_6 ⊆ conv(G)}`；`cert(g) = (ε_est, f*, δ)`，其中 `δ` 为接触/摩擦/惯性参数的不确定半径、`L` 为 `ε` 对这些参数的 Lipschitz 常数。**鲁棒闸门**：`ε_est − L·δ ≥ ε_min` 且 `f* ≤ f_max`。
- **定义 U18（仿真 oracle 与校准）**：`O(x) → y`，`y ∈ {success, slip, eject, collision, miss}`；`ε_s = TV(P_real(y|x), P_sim(y|x))`；conformal 预测集 `C_α(x)` 满足 `P(Y ∈ C_α(x)) ≥ 1−α`。
- **定义 U19（证书级联）**：决策 `D(x) ∈ {accept, reject, abstain}`：`reject` 当证书确定坏；`accept` 当证书确定好；`abstain` 当 `δ` 过宽或 `ε` 临界 → 交 L2 残差；L2 低置信 → L3。
- **定义 U20（反事实抓取分布）**：`P(y | do(μ=μ'), do(m=m'), do(g=g'), do(v=v'))`，由物理引擎生成；用于主动补样与 OOD 训练。

## 5. 关键算法骨架（新增片段；主体沿前两轮 `UniBotSAGEPolicy`）

```python
# ===== IP-13/IP-14: 证书 + 仿真 oracle（挂在 contact/close/lift 路标）=====
def robust_certificate(g, contact_est, L, eps_min, f_max):
    eps, fstar = epsilon_quality_and_grip_force(g, contact_est)  # ε-质量 + 握力 LP
    delta = contact_est.uncertainty_radius                      # 参数区间
    if eps - L * delta < eps_min:          # 鲁棒裕度不足 → 不确定
        return "abstain", eps, fstar, delta
    if fstar > f_max:
        return "reject", eps, fstar, delta
    return "accept", eps, fstar, delta

def sim_oracle(x, sim, calib):
    y = sim.rollout(x)                     # 物理结果：success/slip/eject/...
    return calib.conformal_set(y, alpha=calib.alpha)   # U18 覆盖保证

def execute_grasp(self, s, obs):
    g = self.propose_grasp(obs)                        # 候选抓取
    z, eps, fstar, delta = robust_certificate(
        g, self.estimate_contacts(obs), self.L, self.eps_min, self.f_max)
    if z == "reject":
        return self.intervene(s, obs, mode="regrasp")
    if z == "abstain":
        if self.residual_verifier(obs, g, eps, fstar, delta) < self.p_thr:
            return self.intervene(s, obs, mode="regrasp")
    # accept 或残差通过 → 合爪、轻抬、到点断言
    return self.execute_waypoint(s, obs, g)
```

# ===== IP-15: 反事实课程（离线，主动补样）=====
def counterfactual_curriculum(sim, verifier, params, budget):
    samples = []
    while len(samples) < budget:
        # 优先在 verifier 不确定性高 / 失败模式覆盖不足处干预采样
        x = active_pick(params, verifier)
        for pert in params.interventions(x):           # do(μ,m,g,v)
            y = sim.rollout(pert)                       # 物理真值
            samples.append((pert, y))
    return balance_by_failure_mode(samples)

## 6. 推导（新增引理 L11–L14；L1–L10 沿用前两轮）

**引理 L11（证书的参数误差传播 / 鲁棒性）** 设 `ε(g)` 对接触点、法向、摩擦、惯性参数在度量 `d` 下是 `L`-Lipschitz 的，且估计参数满足 `d(params_est, params_true) ≤ δ`。则 `ε_true ≥ ε_est − L·δ`。故以 `ε_est − L·δ ≥ ε_min` 为闸门时，任何被放行的抓取在真值参数下仍有 `ε_true ≥ ε_min`（保守性成立）。∎
*推论*：证书的可靠性可分解为「解析精度（`ε_est`）」×「可观测精度（`δ`）」。弱可观测时 `δ` 大，闸门自动退让——这正是 P12 的数学依据。

**引理 L12（仿真标签的迁移损失，抓取版）** 设真实与仿真抓取结果在判别特征 `φ` 上的总变差 `TV(φ(P_real), φ(P_sim)) = ε_s`，则用仿真标签训练、在真机评估的判别器满足 `AUROC_real ≥ AUROC_sim − 2ε_s`（标准 TV–AUROC 不等式）。由于刚体接触误差不随长程复合，`ε_s(grasp) ≪ ε_s(long-horizon video)`，故抓取层仿真标签的迁移损失显著小于 v2 的 WMA-0 视频路线。∎

**引理 L13（证书闸门的期望效用：验收指标应为 precision）** 设真实结果 `Y∈{0,1}`（1=成功），证书输出 `z∈{bad, other}`；策略为「`z=bad` 则放弃，否则执行」。相对「总是执行」，闸门的期望效用变化近似为 `Δ ≈ P(z=bad)·[P(Y=1|z=bad)·u_skip − P(Y=0|z=bad)·u_fail]`。故证书价值由**被否决组的真实失败率**（即否决 precision）与放弃的机会成本决定；证书的总体 AUC 不是正确验收指标。∎
*推论*：E630 应报告「否决组失败率 / 覆盖率」，而非单一 AUROC；当 `u_skip` 高（任务只有一次机会）时应收紧否决、宁可交给 L2。

**引理 L14（反事实采样的失败数据效率）** 设观测数据中失败率为 `q ≪ 1`，要获得 `N` 个失败样本，观测式采样需约 `N/q` 个真机 episode；反事实（干预）采样可在仿真中直接定位失败区，用约 `N` 次 rollout 得到 `N` 个失败样本。故失败数据成本比约为 `q`（数量级收益）；代价是引入 `ε_s` 分布差（由 L12 界定）。∎

## 11. 本轮最值得押注的创新点（一句话）

**押注 IP-13 + IP-14 的「仿真认证抓取」组合：抓取是整条接地层里唯一「成功可解析计算、失败可由物理仿真生成真值」的子问题——用经典力封闭证书负责高精度否决，用物理仿真当负样本真值 oracle 与反事实工厂，既绕开 v2 世界模型的保真度死穴，又把 IP-02 的负样本困境在抓取层解开；它对算力要求低、对真机标定的工程密度高，天然是「数据同质、底座趋同」赛场上难被一周抄走的护城河。**

**最大风险（一句话）**：证书依赖的接触点/摩擦/质量在官方观测接口下弱可观测，我们很可能用「估出来的接触」算出「数学上确定、物理上错误」的自信证书——被认证的抓取在真机滑脱，比被怀疑的抓取更致命，尤其对 Dex1 的柔顺多指接触。
