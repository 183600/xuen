### 第 4 轮灵感驱动研究记录（机器人 × 物体泛化）

**灵感词**：机器人、物体泛化

**直觉与动机**：

前几轮把双足机器人控制从「常识包容」(KEMPC) 推进到「知识可迁移」(KT-MPC / v28)：知识证书 KC 可以解释、可以跨任务迁移、权重可自适应。但这些工作都隐含一个假设——**知识与「任务」绑定，而物体只是背景**。真实机器人却始终在与物体打交道：搬运不同质量的箱子、踩踏碎石与台阶、推开门、在湿滑物体表面落脚。同一条平衡规则「CoM 投影落在支撑多边形内」，在空载、5kg 箱、20kg 箱下对应的安全裕度完全不同；同一条摩擦规则「所需摩擦系数 ≤ 可用摩擦系数」，在木箱与冰面箱上结论可能相反。

「物体泛化」的直觉是：机器人不该为每一个新物体重新学一套规则，而应把已有规则迁移到没见过的物体上。但这里有一个危险的陷阱——**泛化必须是「物理属性泛化」，而不是「外观泛化」**。两个外观几乎一样的箱子，一个装满泡沫、一个装满金属，质量与转动惯量可能相差一个量级。若系统按外观相似度判定「可迁移」，就会把针对轻箱的平衡规则套用到重箱上，从而产生「看起来安全、实际上濒临失稳」的虚假包容。

因此本轮的核心主张是：**物体泛化必须建立在「物理属性空间」而非「感知外观空间」之上，并且迁移决策必须由「属性不确定性球 + 规则鲁棒裕度」共同背书。** 换言之，只有当「目标物体的真实物理属性以高概率落在规则有效域内部、且离边界足够远」时，迁移才被允许。

**关键洞见**：
1. 知识规则的适用范围不是一个「任务标签」，而是物理属性空间中的一个**有效域 V(c) = {p : 规则 c 在属性 p 下成立}**。跨物体迁移 = 判断目标属性估计的不确定性球 B(p̂, ε_p) 是否被 V(c) **鲁棒包含**。
2. 感知给出的属性估计天然带不确定性（质量、摩擦、柔度难以从单帧视觉精确反演）。这种不确定性必须**显式进入证书**，而不是被点估计吞掉——点估计会系统性地高估泛化能力。
3. 物体的「类别」应当由**可供性等价类**（哪些规则在其上成立、裕度多大）诱导，而不是由视觉语义标签给定。这样才能让「类别」直接服务于控制有效性，而不是服务于人类命名习惯。

**形式化目标（增量 v29）**：
1. 定义物体中心知识证书 OKC = (P, Q, φ, σ, H, o, ψ, p̂, ε_p)，把物体绑定 o、可供性谓词 ψ、属性估计 p̂ 与不确定半径 ε_p 纳入证书。
2. 定义物理属性不确定估计器 PPUE：输出 p̂ 与经 conformal 校准的 ε_p，并附带 OOD 分数 s_ood。
3. 定义物体迁移因子 μ_o = exp(−D_prop(p̂_s, p̂_t)/τ) · ρ(ψ_s, ψ_t)，以**属性距离**而非外观距离度量。
4. 定义鲁棒裕度迁移门 RMTG：仅当 m_c(p̂_t) > L·ε_p·(1 + β·s_ood) 时允许迁移（OOD 时放大不确定性）。
5. 定义可供性等价抽象 AEA：以规则裕度签名 Sig(o) = (m_{c1}(p̂), …, m_{cn}(p̂)) 聚类物体，使同类内规则适用性一致。
6. 证明 v29 的准入执行集 Exec_v29 ⊆ Exec_v28（单调精化），并给出「迁移泛化风险」的可分解上界。

**本轮最大风险（一句话）**：**分布外物体的不确定性低估（OOD 过度自信）**——conformal 覆盖率保证依赖可交换性，新物体恰恰破坏这一假设；若估计器对陌生物体仍报告很小的 ε_p，RMTG 会放行实际无效的规则，导致比「不迁移」更危险的接触与失稳。

### IP-467 Object-Centric Knowledge Certificate (OKC)

```python
@dataclass
class ObjectCentricKnowledgeCertificate:
    """OKC：把知识规则绑定到物体属性，而非任务标签"""
    name: str
    precond: Callable                     # P(x; p) 依赖物体属性
    postcond: Callable                    # Q(x; p)
    phi: str = ""
    H: int = 10
    sigma: float = 1.0                    # 与 IEKC 一致的激活显著性
    o: object = None                      # 绑定的物体表征
    psi: Callable = None                  # 可供性谓词
    p_hat: np.ndarray = None              # 目标物体属性点估计
    eps_p: np.ndarray = None              # 逐维不确定半径
    ood_score: float = 0.0

    def margin(self, p: np.ndarray) -> float:
        """有符号裕度 m_c(p)：正=成立，负=违反，绝对值=到有效域边界距离。

        由物理模型给出，例如：
          balance:  margin = dist(CoM_proj(p), support_polygon) - delta_safe
          friction: margin = mu_f(p) - mu_required(p)
          step:     margin = h_foot_clearance - h_object(p)
        """
        return self._margin_impl(p)

    def check_violation(self, trajectory: Tensor, dt: float,
                        dynamics: Callable) -> bool:
        """在给定属性点估计下检查违反（退化到 IEKC 语义）"""
        x_k, x_H = trajectory[0], trajectory[min(len(trajectory) - 1, self.H - 1)]
        if not self.precond(x_k, self.p_hat):
            return False
        return not self.postcond(x_H, self.p_hat)

    def to_iekc(self) -> 'InterpretabilityEnhancedKnowledgeCertificate':
        """固定 p = p_hat 后退化为 v28 的 IEKC，保证向后兼容"""
        return InterpretabilityEnhancedKnowledgeCertificate(
            name=self.name,
            precond=lambda x: self.precond(x, self.p_hat),
            postcond=lambda x: self.postcond(x, self.p_hat),
            phi=self.phi, H=self.H, sigma=self.sigma,
        )
```

### IP-468 Physical Property Uncertainty Estimator (PPUE)

```python
@dataclass
class PhysicalPropertyEstimate:
    p_hat: np.ndarray          # [m, c_x, c_y, mu_f, k, h, I]
    eps: np.ndarray            # 逐维 conformal 半径
    s_ood: float               # OOD 分数
    calibrated: bool


class PhysicalPropertyUncertaintyEstimator:
    """PPUE：属性点估计 + split conformal 校准 + OOD 检测"""

    def __init__(self, ensemble: list, calib_objects: list,
                 alpha: float = 0.1, ood_detector=None,
                 scale: np.ndarray = None):
        self.ensemble = ensemble          # E 个属性回归器（不同种子/模态）
        self.alpha = alpha
        self.ood = ood_detector
        self.scale = scale if scale is not None else np.ones(7)
        self._calib_radius = self._fit_conformal(calib_objects)

    def _fit_conformal(self, calib_objects) -> np.ndarray:
        """split conformal：以非符合度 |p_true - p_hat| 的经验分位数定半径"""
        scores = []
        for obj in calib_objects:
            preds = np.stack([m.predict(obj.obs) for m in self.ensemble])
            p_hat = preds.mean(0)
            scores.append(np.abs(obj.p_true - p_hat) / self.scale)
        scores = np.stack(scores)                        # (n_calib, 7)
        n = len(scores)
        q = min(np.ceil((n + 1) * (1 - self.alpha)) / n, 1.0)
        return np.quantile(scores, q, axis=0)            # 逐维半径

    def estimate(self, obj_obs) -> PhysicalPropertyEstimate:
        preds = np.stack([m.predict(obj_obs) for m in self.ensemble])
        p_hat = preds.mean(0)
        # 集成方差作为同分布内的额外缓冲
        eps = self._calib_radius + preds.std(0)
        s_ood = float(self.ood.score(obj_obs)) if self.ood else 0.0
        return PhysicalPropertyEstimate(
            p_hat=p_hat, eps=eps, s_ood=s_ood,
            calibrated=(s_ood <= getattr(self.ood, 'tau_ood', np.inf)),
        )
```

### IP-469 Object Generalization Operator (OGO)

```python
class ObjectGeneralizationOperator:
    """OGO：把源物体上的 KC 迁移到目标物体，输出带 μ_o 的迁移证书"""

    def __init__(self, tau: float = 0.5, mu_min: float = 0.3):
        self.tau = tau
        self.mu_min = mu_min

    def compute_object_factor(self, kc: 'ObjectCentricKnowledgeCertificate',
                              p_src: np.ndarray, p_tgt: np.ndarray,
                              psi_s: Callable, psi_t: Callable,
                              scale: np.ndarray) -> float:
        # 1. 属性距离（Mahalanobis，按物理敏感度加权）
        d = np.sqrt(np.sum(((p_src - p_tgt) / scale) ** 2))
        # 2. 属性相似度：距离越大，迁移因子指数衰减
        sim_prop = math.exp(-d / self.tau)
        # 3. 可供性相关性：动作集合重叠度（而非外观）
        rho_aff = self._affordance_corr(psi_s, psi_t)
        mu_o = max(0.0, min(1.0, sim_prop * rho_aff))
        return mu_o

    def _affordance_corr(self, psi_s: Callable, psi_t: Callable) -> float:
        """可供性集合的 Jaccard 相似度；缺省返回 1（保守交由 RMTG 裁决）"""
        try:
            a, b = set(psi_s()), set(psi_t())
            return len(a & b) / len(a | b) if (a | b) else 1.0
        except Exception:
            return 1.0

    def transfer(self, kc: 'ObjectCentricKnowledgeCertificate',
                 est: PhysicalPropertyEstimate,
                 psi_t: Callable) -> 'TransferredObjectKnowledgeCertificate':
        mu_o = self.compute_object_factor(
            kc, kc.p_hat, est.p_hat, kc.psi, psi_t, self.scale)
        return TransferredObjectKnowledgeCertificate(
            base=kc, mu_o=mu_o, p_hat=est.p_hat, eps_p=est.eps,
            s_ood=est.s_ood, validated=False,
        )
```

### IP-470 Affordance-Equivalence Abstraction (AEA)

```python
class AffordanceEquivalenceAbstraction:
    """AEA：按规则裕度签名聚类物体，形成控制有效域等价类"""

    def __init__(self, kc_list: list, tol: float = 0.2):
        self.kc_list = kc_list
        self.tol = tol
        self.classes = []          # 每类含代表物与成员

    def signature(self, p: np.ndarray) -> np.ndarray:
        return np.array([kc.margin(p) for kc in self.kc_list])

    def fit(self, objects: list):
        sigs = [self.signature(o.p_hat) for o in objects]
        # 以符号一致性 + 归一化距离做贪心聚类
        self.classes = []
        for obj, sig in zip(objects, sigs):
            placed = False
            for cl in self.classes:
                if self._same_class(sig, cl['rep_sig']):
                    cl['members'].append(obj)
                    placed = True
                    break
            if not placed:
                self.classes.append({'rep': obj, 'rep_sig': sig,
                                     'members': [obj]})
        return self.classes

    def _same_class(self, a: np.ndarray, b: np.ndarray) -> bool:
        # 符号逐维一致（适用规则集合相同）且归一化 L∞ 距离 < tol
        if not np.all(np.sign(a) == np.sign(b)):
            return False
        denom = np.maximum(np.abs(a) + np.abs(b), 1e-6)
        return float(np.max(np.abs(a - b) / denom)) < self.tol

    def representative_for(self, p: np.ndarray):
        """找到目标属性所属等价类的代表物，用于回测校准 μ_o"""
        sig = self.signature(p)
        for cl in self.classes:
            if self._same_class(sig, cl['rep_sig']):
                return cl['rep']
        return None
```

### IP-471 Robustness-Margin Transfer Gate (RMTG)

```python
class RobustnessMarginTransferGate:
    """RMTG：鲁棒裕度检验——泛化 = 有效域对不确定性球的鲁棒包含"""

    def __init__(self, L: float = 1.0, beta: float = 0.5):
        self.L = L            # 裕度函数 Lipschitz 常数（可由物理模型估计）
        self.beta = beta      # OOD 不确定性膨胀系数

    def effective_radius(self, est: PhysicalPropertyEstimate) -> np.ndarray:
        """OOD 时放大不确定半径，抵消可交换性失效"""
        return self.L * est.eps * (1.0 + self.beta * est.s_ood)

    def admit(self, kc: 'ObjectCentricKnowledgeCertificate',
              est: PhysicalPropertyEstimate) -> tuple[bool, float]:
        m = kc.margin(est.p_hat)                 # 标量裕度（取最紧维度）
        eps_eff = float(np.max(self.effective_radius(est)))
        slack = m - eps_eff                      # > 0 才算鲁棒成立
        return (slack > 0.0), slack

    def filter_kcs(self, kc_list, est):
        """返回 (允许迁移的 KC, 被拒的 KC 及原因)"""
        admitted, rejected = [], []
        for kc in kc_list:
            ok, slack = self.admit(kc, est)
            if ok:
                admitted.append((kc, slack))
            else:
                rejected.append((kc, slack))
        return admitted, rejected
```

### IP-472 Object-Generalizing MPC (OG-MPC)

```python
@dataclass
class ObjectGeneralizingMPC:
    """OG-MPC：KT-MPC ∪ OKC ∪ PPUE ∪ OGO ∪ AEA ∪ RMTG（v29）"""
    dynamics: Callable
    horizon: int = 20
    dt: float = 0.01
    weights: dict = field(default_factory=dict)
    okc_list: list['ObjectCentricKnowledgeCertificate'] = field(default_factory=list)
    ppue: 'PhysicalPropertyUncertaintyEstimator' = None
    ogo: 'ObjectGeneralizationOperator' = None
    aea: 'AffordanceEquivalenceAbstraction' = None
    rmtg: 'RobustnessMarginTransferGate' = None
    kt_mpc: 'KnowledgeTransilientMPC' = None      # 复用的 v28 求解器

    def compute_object_conditioned_penalty(self, x: Tensor,
                                           est: PhysicalPropertyEstimate) -> float:
        """W_kc(x; o) = Σ_i λ_i·(1 − c_i(x; p̂))·σ_i，仅计入通过 RMTG 的规则"""
        admitted, _ = self.rmtg.filter_kcs(self.okc_list, est)
        lambdas = self.kt_mpc.akwa.get_current_weights() if self.kt_mpc.akwa else {}
        penalty = 0.0
        for kc, _slack in admitted:
            c_i = 1.0 if kc.precond(x, est.p_hat) and kc.postcond(x, est.p_hat) else 0.0
            lam = lambdas.get(kc.name, self.weights.get('knowledge', 10.0))
            penalty += lam * (1.0 - c_i) * kc.sigma
        return penalty * self.weights.get('knowledge', 10.0)

    def solve(self, x0: Tensor, obj_obs) -> dict:
        # 1. 属性估计（低频缓存，见 §3）
        est = self.ppue.estimate(obj_obs)
        # 2. 鲁棒迁移筛选
        admitted, rejected = self.rmtg.filter_kcs(self.okc_list, est)
        # 3. 以通过筛选的规则构造物体条件化代价，交给 v28 求解器
        self.kt_mpc.kc_list = [kc.to_iekc() for kc, _ in admitted]
        self.kt_mpc.compute_knowledge_penalty = (
            lambda x, idx=None: self.compute_object_conditioned_penalty(x, est))
        u_cmd, kc, dcc, explanation = self.kt_mpc.solve(x0)
        # 4. 回测校准：若目标属性落在某等价类内，用代表物修正 μ_o
        rep = self.aea.representative_for(est.p_hat) if self.aea else None
        return {
            "u": u_cmd, "kc": kc, "dcc": dcc, "explanation": explanation,
            "property_estimate": est, "admitted": admitted,
            "rejected": rejected, "representative": rep,
        }
```

### IP-473 Object-Centric Cert Gate (OCCG)

```python
@dataclass
class ObjectCentricCertificationGate:
    """OCCG：十证一体准入 = KTCG ∪ OKC ∪ PPUE ∪ OGO ∪ AEA ∪ RMTG"""
    ktcg: 'KnowledgeTransilientCertificationGate'
    ogmpc: 'ObjectGeneralizingMPC'

    def admits(self, robot_plan: 'RobotPlan', sensor_data: dict) -> bool:
        # 1) 先过 v28 的九证
        if not self.ktcg.admits(robot_plan, sensor_data):
            return False
        # 2) 属性估计必须已校准（OOD 未超阈，或已按 β 膨胀）
        est = self.ogmpc.ppue.estimate(sensor_data['object_obs'])
        if est.s_ood > getattr(self.ogmpc.ppue.ood, 'tau_reject', np.inf):
            return False
        # 3) 鲁棒裕度：所有被激活的迁移规则都必须 slack > 0
        admitted, rejected = self.ogmpc.rmtg.filter_kcs(
            self.ogmpc.okc_list, est)
        if any(slack <= 0.0 for _, slack in admitted):
            return False
        # 4) 若拒绝集非空，必须存在保守回退规则，否则拒绝
        if rejected and not self._has_conservative_fallback(robot_plan):
            return False
        # 5) 可供性一致性：物体的可供性必须覆盖计划动作
        if not self._affordance_covers(est, robot_plan):
            return False
        return True

    def _has_conservative_fallback(self, plan) -> bool:
        return bool(self.ogmpc.weights.get('fallback_enabled', False))

    def _affordance_covers(self, est, plan) -> bool:
        # 计划中的接触/承载动作必须属于物体可供性集合
        required = set(plan.required_affordances)
        available = set(est.psi()) if hasattr(est, 'psi') else required
        return required.issubset(available)
```

## 3. 复杂度分析（增量更新）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| PPUE 属性估计 | O(E·C_enc + d·log n_calib) | O(E·d) | E≤8 集成、C_enc 编码器、d=7 属性维 |
| OGO 迁移因子 | O(N_kc·d) | O(N_kc) | N_kc≤50 |
| AEA 聚类 | O(N_obj²·N_rule)（可近似为 O(N_obj·N_rule)） | O(N_obj·N_rule) | N_obj≤200 |
| RMTG 鲁棒裕度 | O(N_kc) | O(1) | 每规则一次 margin 求值 |
| OG-MPC 求解 | O(N·n_x³ + N·N_rule) | O(N·n_x + N_rule) | 主瓶颈仍是 QP，N=20 |

**实时性**：属性估计（PPUE）是新增主导开销，单次 5–20ms（取决于编码器），但物体属性在**物体获取时刻**变化缓慢，故按 5–10Hz 低频运行并缓存 `est`；控制主循环仍以 50Hz 调 v28 的 QP（5–15ms）。RMTG + AEA 查询 <2ms。因此「感知慢、控制快」的双速率架构满足实时性，且属性估计不进入控制核心的 50Hz 路径。

## 4. 正确性论证（增量更新）

### 引理 26（OKC 对 IEKC 的保守退化）
**陈述**：对任意 OKC，固定 p = p̂ 后 `to_iekc()` 得到的 IEKC 与原 v28 语义一致；因此 OKC 是 IEKC 的严格扩展，不改变既有已验证行为。
**证明**：`to_iekc()` 仅把 `precond(x, p̂)`、`postcond(x, p̂)` 柯里化为单参数谓词，φ、σ、H 原样保留，故与 IEKC 的 `check_violation`/`verify` 逐行等价。∎

### 引理 27（属性空间 Lipschitz 迁移的充分条件）
**陈述**：设规则裕度 m_c 关于属性 p 是 L-Lipschitz。若真实属性 p_t 满足 ‖p_t − p̂_t‖_∞ ≤ ε_p，且 m_c(p̂_t) > L·ε_p，则 m_c(p_t) > 0，即规则在真实属性下成立。
**证明**：由 Lipschitz 性，|m_c(p_t) − m_c(p̂_t)| ≤ L·‖p_t − p̂_t‖_∞ ≤ L·ε_p。故 m_c(p_t) ≥ m_c(p̂_t) − L·ε_p > 0。∎

### 引理 28（split conformal 覆盖率，及 OOD 失效）
**陈述**：若校准物体与测试物体可交换，则 P(‖p_t − p̂_t‖_∞ ≤ ε_p) ≥ 1 − α。若可交换性被破坏（新类别物体），该下界不再成立，需以 (1 + β·s_ood) 膨胀半径以恢复保守性。
**证明**：split conformal 的标准秩论证给出边际覆盖 1 − α；可交换性是前提。OOD 时非符合度分布右移，原始分位数低估真实误差，故引入膨胀系数 β·s_ood 使 ε_eff ≥ 实际误差，代价是 α′ 由 β 与 s_ood 决定而非名义 α。∎

### 引理 29（可供性等价类内规则适用性一致）
**陈述**：若两物体 o_i、o_j 属于同一 AEA 等价类，则对所有规则 c 有 sign(m_c(p_i)) = sign(m_c(p_j))，即「适用的规则集合」完全相同。
**证明**：AEA 的 `_same_class` 显式要求逐维符号一致；因此类内任意两点的裕度符号相同，规则成立与否一致。∎

### 定理（OG-MPC 迁移泛化风险分解）
**陈述**：设接受事件 A = {m_c(p̂_t) > L·ε_eff}。则被接受迁移的规则在真实属性下失效的概率满足
P(fail | A) ≤ P(‖p_t − p̂_t‖_∞ > ε_eff | A) ≤ α′，
其中 α′ 在可交换时为 α，在 OOD 时由膨胀系数 β、s_ood 与真实分布偏移共同决定。第二项（确定性部分）在 A 下恒为 0。
**证明**：由引理 27，若 ‖p_t − p̂_t‖_∞ ≤ ε_eff 且 A 成立，则规则成立。故失效只能来自「真实属性落在膨胀球之外」这一随机事件，其概率由引理 28 的覆盖率控制。OOD 下覆盖率退化为 α′。∎

### 定理（v29 单调精化）
**陈述**：Exec_v29 = Exec_v28 ∩ Fil_object ∩ Fil_property ∩ Fil_margin ⊆ Exec_v28。
**证明**：OCCG 第 1 步显式要求 `ktcg.admits` 为真，其余步骤为合取附加约束；交集只会缩小执行集。∎

## 5. 实验设计（v29 验证方案）

**物体划分**：base（已见实例）/ novel-instance（同类新实例）/ novel-category（新类别）/ adversarial-OOD（外观相似、物理不同，如泡沫箱 vs 金属箱）。

**对照**：v28 无迁移；外观相似度迁移；属性迁移但无 conformal；完整 v29。

**指标**：
1. 迁移成功率（被接受且在真值仿真中规则成立的比例）；
2. **不安全迁移率**（被接受但真值违反的比例）——本方案最关心的指标；
3. conformal 经验覆盖率 vs 名义 1−α（校准性）；
4. OOD 检测 AUROC；
5. 端到端控制成功率与跌倒率。

**预期**：外观迁移在 adversarial-OOD 上不安全迁移率显著偏高；v29 通过 RMTG + OOD 膨胀把不安全迁移率压到接近名义 α，同时保留 novel-instance 上 >85% 的迁移成功率；代价是 OOD 上更频繁地回退到保守规则。

## 7. 本轮最大风险（最终确认）

**一句话**：**分布外物体的不确定性低估（OOD 过度自信）**——conformal 覆盖率保证依赖校准集与测试物体的可交换性，而「没见过的物体」正是对这一假设的系统性违背；一旦属性估计器对陌生物体仍输出很小的 ε_p，RMTG 的鲁棒裕度检验就会被「虚假的小半径」骗过，放行在真实物理属性下并不成立的规则，使机器人以「通过证书」的姿态做出比完全不迁移更危险的接触与失稳。这一风险最隐蔽之处在于：所有证书都是绿的，唯独物理世界不认账。
