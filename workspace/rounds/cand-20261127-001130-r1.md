## 1. 直觉与动机

### 1.1 灵感 1（奖励设计）：排行榜就是一个奖励函数，而大多数人只优化了它的第一项

**直觉**：3.2 万条演示全是「成功」轨迹，没有一条奖励标签——所以绝大多数队伍把训练当成二分类模仿：动作像不像演示。但排行榜不是二分类，它是「平均成功率 + 平均步骤分」。步骤分在超时后仍按进度给分（F3/F3′），这意味着**评测规则里本来就藏着一个稠密奖励**：任务完成到哪一步。我们不是没有奖励，而是奖励被隐式编码在演示的「先后顺序」里——演示之所以先接近再抓取再放置，是因为那正是进度增加的方向。把这个顺序学成一个标量势函数，等于从成功数据里免费反演出 dense reward。

**严谨定义**：把单任务写成 MDP \(M=(S,A,T,r,\gamma)\)，但 \(r\) 未知、只给成功演示 \(D=\{\tau_i\}_{i=1}^{N}\)。定义**进度势** \(\Phi:S\to\mathbb{R}\)，\(\Phi(s)=-\mathbb{E}[\text{剩余步数}\mid s]\)，终止态 \(\Phi(s_g)=0\)；沿一条成功演示 \(\Phi(s_t)=-(T_i-t)\)。则势差
\[
F(s,s')=\gamma\Phi(s')-\Phi(s)
\]
就是 Ng–Harada–Russell (1999) 的 potential-based shaping：把它加到任意 \(r\) 上，**最优策略集合不变**，且任何闭环绕行收益为 0（天然免疫「原地刷进度」这类奖励黑客）。在只有成功数据时，\(\Phi\) 在演示流形上是可辨识的（剩余步数有监督），但**离开演示流形不可辨识**——这一点决定了 I9 能做什么、不能做什么（见 §1.4 与产物区 §2.4）。

**反直觉点**：稀疏成功信号不是「没有奖励」，而是「奖励的排序信息被浪费了」。把「离成功还有多远」学出来，比再多训一个任务更划算，因为同一个 \(\Phi\) 同时服务四个环节：**训练加权、增广筛选、卡滞恢复、测试时选动作**。

### 1.2 灵感 2（群体智能）：单模型赛道的「群体」不是多模型投票，而是同一模型的多样本 + 一个共享选择器

**直觉**：6B 通才模型在测试时像一只「单蚁」——一次前向只给一个 chunk，错了就一路错下去。群体智能的朴素联想是「多模型投票」，但 F1/F11 明确禁止多模型混用，所以那条路直接出局。合法的读法是把「群体」放进**同一个 policy 内部**：让同一组权重做 K 次随机前向，得到 K 个候选 chunk（粒子），再用一个共享选择器挑/融合。这正是 self-consistency（多路径采样后投票）在连续动作上的版本，也是粒子滤波 / cross-entropy method 的动作级退化形式。

**严谨定义**：
- **推理层（粒子采样）**：从同一策略 \(\pi_\theta(\cdot\mid s)\) 采样 \(a^{(k)}\sim\pi_\theta(\cdot\mid s), k=1..K\)，共享视觉-语言编码器、只对 action expert 采样（把 K 倍成本压到最小）。粒子权重 \(w_k\propto\exp(\beta\,\mathrm{score}(s,a^{(k)}))\)，输出 \(\hat a=\sum_k w_k a^{(k)}\) 或最大簇代表。选择器 \(\mathrm{score}\) 由三部分组成：**簇共识度**（连续动作先聚类）、**认知不确定性**（ensemble/多次采样的方差，越低越好）、以及（可选）**\(\Phi\) 预测进度**。这是「群体」的合法形态：一个模型、一组权重、K 个假设、一个共享评分。
- **训练/评测层（信息素 + bandit）**：实验臂 \(j\)（增广方案、采样权重、K 值、触发阈值）共享一张失败地图；信息素更新 \(p_j\leftarrow(1-\lambda)p_j+\lambda\cdot \mathrm{fail}_j\)，预算按 \(p_j\) 的 softmax 分配并保留探索下限 \(\varepsilon\)。这是蚁群式 stigmergy：每个实验把「哪里痛」写回共享地图，后续实验沿梯度走；bandit（UCB / successive halving）负责在稀缺的真机单任务时段上做序贯分配。

**反直觉点**：群体智能的收益来自「多样性 × 选择器」，而不是多样性本身。**没有可靠选择器时，群体只是把噪声放大 K 倍**——所以「群体智能」必须先有「奖励设计」，否则是负资产。两个灵感词在这里不是并列，而是有严格先后：\(\Phi\) 是罗盘，群体是搜索。

### 1.3 两者合流：一个统一框架

**奖励设计造罗盘，群体智能造搜索**。统一为：**价值/共识引导的群体采样（推理）+ 信息素式实验分配（训练/评测）**。前者把单步决策从「一次前向」变成「K 个假设 + 选择」，后者把稀缺真机预算从「均匀铺开」变成「沿失败梯度分配」。两者的公共货币都是 \(\Phi\)：训练时用 \(\Phi\) 做 AWR 加权与增广筛选，推理时用 \(\Phi\)/共识做粒子选择，评测时用失败率做信息素。

### 1.4 与 v1.0 的关系（为什么不是重复）

v1.0 的 I5 已经有一个「进度估计头」，但它只是**卡滞检测器**（副产品），且默认能直接用。本轮把它升格为 **I9 公共奖励底座**，并补上 v1.0 缺失的三件事：(a) 从成功演示反演 \(\Phi\) 的**可辨识性边界**；(b) \(\Phi\) 在离流形处的**不可靠性**，因此测试时选择器改用「共识 + 不确定性」而非裸 \(\Phi\)；(c) 用 \(\Phi\) 统一 I1/I2/I5 的加权与筛选。v1.0 的 I7（在线 world-model 前瞻）在本轮被修剪：它既贵、又可能触碰「第二个模型」边界，而 I10 的共识采样能用同一模型拿到它的大部分收益。

## 3. 新增研究问题（Q6–Q10）

- **Q6（势函数的可辨识性与保序性）**：如何只用成功演示学一个 \(\Phi\)，使其在「留出任务/留出泛化轴」上仍与剩余步数单调相关？跨任务长度差异如何归一而不引入任务身份泄漏？
- **Q7（奖励塑形与奖励黑客）**：用 \(\Phi\) 做 AWR 与恢复奖励时，如何保证不奖励「原地抖动/绕圈/反复抓空」？PBRS 的终止态 \(\Phi(s_g)=0\) 与有界性如何落实到实现？
- **Q8（离流形选择）**：成功数据只约束演示流形，测试时要给 K 个**未见** chunk 排序，\(\Phi\) 本身不够——共识度、认知不确定性、demo-一致性三者如何组合？权重如何在不碰真机的情况下标定？
- **Q9（单模型群体合规 + 延迟）**：K 次采样是否被认定为「单模型」？共享编码器只采 action expert 能否把 K 倍成本压到可接受？触发门控（只在近接触/高熵节点开）的期望延迟模型是什么？
- **Q10（稀缺预算的群体分配）**：单任务真机时段如何用 bandit/successive halving 在 I1–I6 的实验臂间分配？信息素正反馈如何用探索下限防止「早期噪声锁死预算」？

## 4. 设计原则（PR1–PR4 沿用，本轮新增 PR5–PR8）

- **PR5 奖励保序律**：任何奖励/势函数只能依赖可观测且与任务因果相关的量；上线前必须在留出演示上通过「\(\Phi\) 与剩余步数 Spearman \(\rho\) 达标 + 跨泛化轴不显著退化」双门禁。禁止使用评测现场信号。
- **PR6 单模型群体律**：推理时「群体」必须是同一组策略权重的多样本 + 服务内选择器；禁止外部模型投票、禁止按任务切换权重。选择器必须是同一 checkpoint 的附属头或纯统计量（共识/方差）。
- **PR7 预算分配律**：真机单任务时段按 bandit 分配，任何实验臂保留 \(\varepsilon\ge 10\%\) 探索下限，防止信息素正反馈锁死。
- **PR8 反奖励黑客律**：代理奖励必须通过「静止测试、绕圈测试、随机势平移测试」三项红队；凡能被无进展动作刷高的代理量一律不得作为训练/选择信号。

## 1. 形式化基础

### 1.1 评测目标与「未知聚合」的稳健化

**直觉**：我们只知道排行榜按「成功率 + 步骤分」排，但不知道是严格字典序还是加权和。与其猜，不如设计一个在两种聚合下都不亏的策略。

**定义**：对任务 \(\tau\) 的一次评测，记 \(S\in\{0,1\}\) 为成功、\(G\in[0,1]\) 为归一化步骤分、\(T_{\text{sub}}\) 为提交时间。评测目标是某个未知聚合
\[
J=\mathcal{A}\big(\mathbb{E}[S],\ \mathbb{E}[G]\big),\qquad
\mathcal{A}\in\{\text{lexicographic},\ \text{weighted sum}\}.
\]
**稳健目标**：寻找策略使 \(\mathbb{E}[S]\) 不降的前提下最大化 \(\mathbb{E}[G]\)（Pareto 改进），即
\[
\max_\pi\ \mathbb{E}[G]\quad \text{s.t.}\quad \mathbb{E}[S]\ge \mathbb{E}[S]_{\text{base}}.
\]
这样无论 \(\mathcal{A}\) 是字典序（先比 \(S\)）还是加权和（\(S,G\) 可交换），都不会因「只刷步骤分」而丢主序。步骤分假设为里程碑的单调函数 \(G=\sum_j w_j\mathbf{1}[\text{milestone}_j]/\sum_j w_j\)（**只用到序关系，不假设精确权重**）。

### 1.2 奖励设计：从成功演示反演进度势

**直觉**：演示的顺序 = 进度的方向。沿演示，每过一步就离终点近一步，所以「剩余步数」是天然监督。

**定义**：给定成功演示集 \(D=\{\tau_i\}_{i=1}^{N}\)，\(\tau_i=(s_0,a_0,\dots,s_{T_i})\)，\(s_{T_i}=s_g\)。定义
\[
\Phi(s)=-\mathbb{E}\big[\text{steps to goal}\mid s\big],\qquad \Phi(s_g)=0.
\]
沿演示有监督目标 \(\Phi(s_t)\approx -(T_i-t)\)。用参数化 \(\Phi_\psi\) 拟合：
\[
\mathcal{L}_\Phi=
\underbrace{\mathbb{E}_{(s_t,t,T_i)\sim D}\big[(\Phi_\psi(s_t)+(T_i-t))^2\big]}_{\text{时间距离回归}}
+\lambda_1\underbrace{\mathbb{E}_{t<t'}\big[\max(0,\Phi_\psi(s_{t'})-\Phi_\psi(s_t))\big]}_{\text{演示内单调}}
+\lambda_2\underbrace{\mathbb{E}\big[\Phi_\psi(s_g)^2\big]}_{\text{终止态归零}}
+\lambda_3\,\mathcal{L}_{\text{rank}},
\]
其中 \(\mathcal{L}_{\text{rank}}\) 用跨轨迹对（同一任务内更接近目标的样本应更大）做 pairwise ranking，缓解不同任务长度尺度不一致。

**势塑形**：用
\[
F(s,s')=\gamma\,\Phi_\psi(s')-\Phi_\psi(s)
\]
作为稠密奖励。由 Ng et al. (1999)，在终止态 \(\Phi=0\) 且有界的前提下，势塑形不改变最优策略，且任何闭环的净势差为 0——这是反奖励黑客的理论基础。

**可辨识性边界（关键）**：成功数据只覆盖演示流形。\(\Phi\) 在流形上可辨识，但**离流形不可辨识**：给定两个都「看起来合理」的候选 chunk，\(\Phi\) 没有足够证据说哪个更好。因此 \(\Phi\) 可用于（a）训练期样本加权、（b）在策略自身轨迹上检测卡滞（on-policy，仍在流形附近），但**不能单独用于给 K 个未见 chunk 排序**。测试时选择必须引入「共识 + 不确定性」作为离流形打分（见 §3.1）。

### 1.3 群体智能：单模型合规的两种「群体」

**推理层（粒子采样）**：共享编码器，只对 action expert 采样：
\[
a^{(k)}\sim\pi_\theta(\cdot\mid s),\quad k=1..K;\qquad
w_k=\frac{\exp(\beta\,r_k)}{\sum_j\exp(\beta\,r_j)},\quad
\hat a=\sum_k w_k a^{(k)}.
\]
打分 \(r_k\) 由三项组成（见 §3.1），其中 \(\Phi\) 只是可选弱项，主导项是**簇共识度**与**负认知不确定性**。这是 cross-entropy method / 粒子滤波在动作 chunk 上的退化形式，也是连续动作版 self-consistency。

**训练/评测层（信息素 + bandit）**：实验臂 \(j\) 的失败率 \(f_j\) 写成信息素
\[
p_j\leftarrow(1-\lambda)p_j+\lambda f_j,\qquad
\pi_j=\frac{\exp(p_j/T)}{\sum_l\exp(p_l/T)},\qquad
\pi_j\leftarrow(1-\varepsilon)\pi_j+\varepsilon/|\mathcal{J}|.
\]
预算按 \(\pi_j\) 分配；对单任务真机时段用 UCB / successive halving 选择实验臂。\(\varepsilon\) 是探索下限（PR7）。

### 1.4 单模型合规性论证（PR2 / PR6）

- 参赛实体：**一个 policy 类、一组权重 \(\theta\)**。K 次采样是同一权重的随机前向，不是 K 个模型；选择器是同一 checkpoint 的附属头（价值/不确定性头）或纯统计量（簇大小、方差）。
- **不做**：按任务切换权重、加载第二个基座做投票、在线调用世界模型做 rollout。
- **边界风险**：若把「独立训练的价值模型」或「独立世界模型」接入控制回路，可能被认定为多模型。规避：价值头与策略共享 backbone、同一 checkpoint 保存；世界模型只离线造数据，不进入 `get_action`。
- **待办**：就「同权重 K 采样 + 附属价值头」向组委会书面确认（PR2 边界模糊处先求证）。

## 2. I9 奖励设计：成功演示反演进度势函数（核心新增）

### 2.1 动机

- 步骤分是官方承认的稠密信号（F3′），超时仍按进度给分（F3）；只优化成功率等于放弃平手裁决轴与超时保底分。
- 成功演示无奖励标签，但顺序蕴含进度；反演 \(\Phi\) 是零额外标注的稠密奖励来源。
- 一个 \(\Phi\) 同时服务：I2 的 AWR、I1 的增广筛选、I5 的卡滞恢复、I10 的粒子选择（弱项）。

### 2.2 与现有方案差异

| 现有做法 | I9 |
|---|---|
| 纯行为克隆（BC），所有样本等权 | AWR：按 \(\Phi\) 优势给样本加权，高进度段权重更大 |
| 进度头只做「卡滞检测」 | \(\Phi\) 升为公共底座，统一训练/筛选/恢复/选择 |
| 手工里程碑标签 | 自监督时间距离 + 跨轨迹 ranking，无需逐步标注 |
| 奖励塑形易被刷 | 强制 PBRS 形式（势差），闭环净收益为 0 |

### 2.3 技术可行性

- 数据：LeRobot 演示含状态与 4 相机（F4）；时间距离标签由帧序号直接得到，**零人工标注**。
- 结构：官方 WLA 底座（F6）加一个标量头（共享 backbone），LoRA 微调即可。
- 跨任务：任务语言 `observation.language`（接口有该字段）做条件输入；损失按任务内归一化，避免长任务支配。
- 若 F10 属实（单任务数据偏少），跨任务共享 backbone 反而是优势。

### 2.4 四个下游用途（这是 I9 的价值所在）

1. **AWR 加权（I2）**：对样本 \((s_t,a_t)\) 计算优势 \(\hat A_t=\gamma\Phi(s_{t+1})-\Phi(s_t)\)，权重 \(w_t=\mathrm{clip}(\exp(\hat A_t/\beta),w_{\min},w_{\max})\)，做加权回归。高进度段（接近成功的关键动作）被放大，低信息段被降权。
2. **增广筛选（I1）**：增广后要求 \(\Phi\) 沿轨迹仍单调、终点仍趋 0；若某增广样本的 \(\Phi\) 曲线崩塌（伪影让感知失效），直接丢弃。这是视觉 QA 之外的**语义 QA**。
3. **卡滞恢复（I5）**：在线监测 \(\dot\Phi_t=\Phi(s_t)-\Phi(s_{t-k})\)；若 \(\dot\Phi<\epsilon\) 持续 \(k\) 步，判卡滞，触发「后撤-重接近-重抓」。比基于动作重复的检测更本质。
4. **粒子选择的弱先验（I10）**：仅当候选 chunk 的预测末态 \(\Phi\) 差异显著且选择器置信时作为 tie-break；不作为主打分（离流形不可靠）。

### 2.5 反奖励黑客红队（PR8）

- **静止测试**：构造原地不动/微抖轨迹，要求累计 \(F\) 增量 \(\le 0\)。
- **绕圈测试**：任意闭环 \(\sum F=0\)（PBRS 自动满足），显式单测。
- **随机势平移**：\(\Phi+c\) 不应改变任何排序/权重（检查实现里没有绝对势的偏置）。
- **终点归零**：训练时强制 \(\Phi(s_g)=0\)，否则超时截断会制造假高势。
- **有界性**：\(\Phi\in[-\Phi_{\max},0]\)，防止个别长任务数值爆炸。

### 2.6 风险

- 跨泛化轴保序失败（最大风险）：\(\Phi\) 可能学到背景/外观伪相关。缓解：留出泛化轴验证 + 跨任务 ranking + 失败即降级为单任务卡滞检测。
- 任务长度归一化引入任务身份泄漏：缓解：只用 `language` 条件，不喂 task id；做「去任务 id」消融。
- \(\Phi\) 与真实步骤分权重不一致：缓解：只用序关系（Pareto/ranking），不拟合绝对分值。

## 3. I10 群体智能：价值/共识引导的粒子采样 + 信息素实验分配

### 3.1 推理时粒子采样（单模型群体）

**触发门控**（只在值得花 K 倍算力的节点开）：
- 策略熵高（多峰）；
- 近接触/高险节点（抓取前、插入前、放置前）；
- \(\Phi\) 平台期（可能卡滞）；
- 人为干扰恢复后（世界被改写，需重估）。

**选择器打分**（离流形可用）：
\[
r_k=\alpha\,\underbrace{\text{mass}(C(a^{(k)}))}_{\text{簇共识}}
+\beta\,\underbrace{\big(-\mathrm{Var}_{k}(a^{(k)})\big)}_{\text{负认知不确定性}}
+\eta\,\underbrace{\Phi(\hat s_{T_a}^{(k)})}_{\text{可选弱先验}}
-\rho\,\underbrace{\|\Delta a^{(k)}\|}_{\text{平滑/动作健康}}.
\]
其中 \(C(\cdot)\) 是把 K 个 chunk 按末端位姿/动作轨迹聚类的簇；\(\text{mass}\) 是所在簇的样本占比。**共识优先**是因为成功数据无法给未见 chunk 排序，但「同一模型多数采样落在同一模式」是可观测的、且与 demo 一致性正相关。若所有簇质量接近（无共识）→ 不融合，退化为最短 chunk（提反应性）或 `safe_hold()`。

**延迟模型**：
\[
\mathbb{E}[t]=t_{\text{enc}}+t_{\text{head}}+p_{\text{trig}}\,(K-1)\,t_{\text{head}},
\]
共享编码器后 \(t_{\text{head}}\ll t_{\text{enc}}\)，故 K 倍成本主要落在 head。约束：\(\mathbb{E}[t]\) 与 p99 必须过 PR4 门禁；否则降 K 或收紧触发。

**为什么不是世界模型 rollout**：世界模型在线前瞻 = K× 世界模型前向 + 第二个模型边界 + 5 轴预测偏差。共识采样用同一模型，成本低一个量级，覆盖「多峰决策」这一主要收益。I7 因此只保留离线合成数据用途。

### 3.2 信息素式实验分配（训练/评测层）

**信息素地图**：每个任务/任务族 \(j\) 维护失败率 \(f_j\)（来自单任务真机诊断 + 离线留出验证）。更新 \(p_j\leftarrow(1-\lambda)p_j+\lambda f_j\)，预算比例 \(\pi_j=\mathrm{softmax}(p_j/T)\)，再与探索下限混合。

**bandit 分配**：把单任务真机时段看成稀缺拉杆。用 UCB：
\[
j^\*=\arg\max_j\ \big(\hat\mu_j+c\sqrt{\ln n/n_j}\big),
\]
其中 \(\hat\mu_j\) 是该实验臂的预期增益（成功率或步骤分），\(n_j\) 已用次数。批次间用 successive halving：先小样本筛掉明显差的臂，把预算集中到有希望的臂。

**防正反馈锁死**：\(\varepsilon\ge 10\%\) 探索下限；对新臂/新族给冷启动先验；对信息素做时间衰减，避免早期噪声永久占优。

### 3.3 与 I6 的联合预算

- K 采样是「用延迟换决策质量」。必须把 \(K\)、触发率 \(p_{\text{trig}}\)、`action_chunk_size`、`image_resize` 放进同一个联合网格：目标是在 p99 延迟预算内最大化「有效决策数」。
- 稳定态长 chunk（吞吐高、延迟暴露低）；高险节点短 chunk + K 采样（反应性高）。二者切换要有滞回，避免抖动（延续 I4）。

### 3.4 风险

- 共识选择在「全模型一起错」时无效（相关误差）：缓解：只把它当方差缩减，不当纠错；与 \(\Phi\) 平台检测联动。
- K 采样推高 p99，触发官方可信度标记：缓解：触发门控 + K≤4 起步 + 延迟预算硬门禁。
- 信息素把预算锁死在早期噪声：缓解：探索下限 + 衰减 + 冷启动先验。

## 4. 升级后的 I1 / I2 / I5 / I8（只写增量）

### I1 五轴泛化增广 + \(\Phi\) 保序筛选（升级）
- 在 v1.0 的视觉 QA 门禁后加**语义 QA**：增广样本必须满足 \(\Phi\) 沿轨迹单调、终点 \(\to 0\)、且与原轨迹的 \(\Phi\) 曲线 Spearman \(\rho\ge 0.8\)；否则丢弃。
- 好处：把「看起来真但破坏动作语义」的伪影挡在训练外；这正是 v1.0 最大风险的直接缓解。

### I2 弱任务诊断 + AWR 优势加权共训（升级）
- 采样权重从「族级 \(1/\text{成功率}\)」改为「样本级优势 + 族级下限」：
\[
w_{t}=\mathrm{clip}\big(\exp(\hat A_t/\beta),w_{\min},w_{\max}\big)\cdot \big(1/\hat s_{j}\big)^{\kappa},
\]
其中 \(\hat s_j\) 是族成功率，\(\kappa\) 控制族级补偿强度；保留 PCGrad 防梯度冲突。
- 强任务下限保护：\(w_t\) 上界 + 每族最少采样比例。

### I5 \(\Phi\) 导数驱动的卡滞恢复（升级）
- 判据：\(\dot\Phi_t=\Phi(s_t)-\Phi(s_{t-k})<\epsilon\) 持续 \(k\) 步，或 \(\Phi\) 连续 \(m\) 步下降（倒退）。
- 恢复原语：后撤→重接近→重抓；每 episode 次数上限；恢复后强制短 chunk。
- 与步骤分对齐：恢复本身算「进度」，因为避免了卡死到超时（超时仍按进度给分，但卡死会停在低进度）。

### I8 信息素式群体实验分配（升级）
- 周节奏不变，但每个时段用 bandit 选实验臂（增广轴、AWR 强度、K 值、触发阈值）；失败地图信息素驱动下一轮预算。
- 先手窗口（F7/F9）：高频小实验 + successive halving，比一次性大实验更快找到有效方向。

### 5.1 \(\Phi\) 训练（I9）

```python
def train_phi(demos, base, steps):
    phi = PhiHead(base)                      # 共享 backbone + 标量头，同一 checkpoint
    for batch in demos:                      # 每样本: (s_t, t, T_i, task_lang, is_terminal)
        s, t, T, lang, term = batch
        pred = phi(s, lang)                  # 形状 [B]
        target = -(T - t).float()            # 剩余步数的负数
        loss_td = F.mse_loss(pred, target)
        loss_mono = monotonic_violation(phi, batch)      # 演示内 t<t' 时 phi(t')>=phi(t)
        loss_term = (pred[term] ** 2).mean()             # 终止态归零
        loss_rank = pairwise_rank_loss(phi, batch)       # 同任务跨轨迹
        loss = loss_td + 1.0*loss_mono + 0.5*loss_term + 0.2*loss_rank
        update(phi, loss)
    return phi
```

### 5.2 AWR 加权（I2）

```python
def awr_weight(phi, s_t, s_t1, gamma=0.99, beta=0.1):
    adv = gamma * phi(s_t1) - phi(s_t)       # 势差 = 优势代理
    return torch.clamp(torch.exp(adv / beta), 0.1, 10.0)
```

### 5.3 推理时粒子采样（I10）

```python
def get_action_particle(policy, phi, obs, K=4, trig=False):
    if not trig:
        return clip_smooth(policy.sample_chunk(obs, k=1))     # 常规路径
    # 共享编码器，仅 action expert 采样 K 次
    z = policy.encode(obs)
    chunks = [policy.decode_action(z, sample=True) for _ in range(K)]
    clusters = cluster_by_endpose(chunks, tol=0.01)
    scores = []
    for c in chunks:
        mass = cluster_mass(c, clusters)
        unc  = -cluster_var(c, clusters)
        pg   = phi(predict_end_state(obs, c)) if phi is not None else 0.0
        smooth = -action_jerk(c)
        scores.append(alpha*mass + beta*unc + eta*pg + rho*smooth)
    if consensus_low(clusters):              # 无共识 → 不融合
        return clip_smooth(chunks[argmin_len(chunks)])   # 最短 chunk 提反应性
    w = softmax(torch.tensor(scores) * beta_sel)
    return clip_smooth(sum(wi * ci for wi, ci in zip(w, chunks)))
```

### 5.4 信息素 + UCB 实验分配（I8）

```python
def allocate(arms, pheromone, counts, eps=0.10, c=1.0):
    n = sum(counts.values()) + 1
    ucb = {j: pheromone[j] + c * math.sqrt(math.log(n) / (counts[j] + 1))
           for j in arms}
    j_star = max(ucb, key=ucb.get)
    # 与探索下限混合
    if random.random() < eps:
        j_star = random.choice(arms)
    return j_star

def update_pheromone(pheromone, j, fail_rate, lam=0.3):
    pheromone[j] = (1 - lam) * pheromone[j] + lam * fail_rate
```

### 5.5 GuardedPolicy v1.1（I3+I4+I5+I9+I10 组合，单服务内）

```python
class GuardedPolicy:                       # 唯一参赛实体：一个 PolicyService / 一组权重
    def __init__(self):
        self.vla  = load_wla_finetuned()   # I2 产物（含共享 backbone）
        self.phi  = PhiHead(self.vla.backbone)  # I9，同一 checkpoint 的附属头
        self.hand = HandDetector()         # I4
        self.servo = KeypointServo("contact_rich")  # I3（边界确认后）
        self.state = FSM(default="EXECUTE")

    def get_action(self, obs):
        imgs = stack(obs)
        if self.hand.detect(imgs[-1]) or self.interrupted(imgs):
            self.state.enter("YIELD")      # PR3
        if self.state == "YIELD":
            if self.hand.clear(imgs[-1]) and self.rescan(imgs):
                self.state.enter("EXECUTE"); self.chunk_len = 4
            else:
                return safe_hold()

        phi_now = self.phi(obs)
        if self.stuck(phi_now):            # I5：Phi 导数 < eps 持续 k 步
            plan = recovery_primitive(self.vla, obs)
        elif self.risky_node(obs, phi_now):# I10：高熵/近接触/Phi 平台
            plan = get_action_particle(self.vla, self.phi, obs, K=4, trig=True)
        else:
            plan = self.vla.sample_chunk(obs, k=self.chunk_len)

        if self.near_contact(plan) and self.servo.confident(imgs):
            plan = self.servo.correct_tail(plan, imgs)   # I3
        return clip_smooth(plan)
```

## 10. 本轮最值得押注（一句话）

**押 I9「成功演示反演进度势函数」——它是唯一同时改善成功率（卡滞恢复）、步骤分（AWR/恢复）、增广质量（保序筛选）与推理决策（粒子选择）的公共底座，且零额外标注、不碰单模型红线；I10 则是把它的价值放大到测试时的杠杆。**

**本轮最大风险（一句话）**：整个方案押在「成功演示里反演出的进度势 \(\Phi\) 能跨 5 类泛化轴保持保序」这一假设上——若 \(\Phi\) 学到的是标称场景的伪相关，AWR 加权、增广筛选与粒子选择会系统性地偏爱「自信地错」的 chunk，而稀缺的真机单任务时段可能直到计分评测才暴露。
