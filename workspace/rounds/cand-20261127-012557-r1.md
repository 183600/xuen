## 0. 直觉与动机

**灵感 1（ROS → 证书的运行时载体：QoS 即安全契约、生命周期即证书有效性、rosbag 即审计账本）**
直觉：v23 的证书全是"纸面谓词"——它证明"若这些条件成立则安全"，却从未回答"这些证书在真实机器人上如何被传输、如何过期、如何被取证"。ROS 2 恰好提供三样把谓词变成契约的东西：其一，**QoS 即安全契约**：证书不是普通消息，它必须 `RELIABLE + TRANSIENT_LOCAL`，并携带 `deadline` 与 `lifespan`；`deadline` 违约即"证书流中断"，`lifespan` 到期即"证书作废"，二者任一发生都必然 fail-safe。这把 v17 APS 新鲜度阶梯从"应用层自觉"升级为"中间件层强制"。其二，**生命周期节点即证书有效性**：ROS 2 managed node 的 `configure/inactive/active/error` 状态机与 CESC 原子切换、SafeStop 降级一一对应——只有处于 `ACTIVE` 态的节点签发的证书才进入准入门，节点滑入 `INACTIVE/ERROR` 即等同于证书被吊销。其三，**TF2 即几何一致性骨架、rosbag 即可审计账本**：所有 CertBox 必须表达在带时间戳的统一坐标系里，经 TF 链传播并按外参/时戳误差膨胀；每张证书写入 rosbag（MCAP）并做哈希链，回放即可机械复核——"可审计"从形容词变成可执行动作。核心创新：**ROS 证书运行时契约 (ROS Certificate Runtime Contract, RCRC)**：QoS 契约 + 生命周期状态机 + TF 接地 + rosbag 哈希链四位一体。

**灵感 2（差异化定位 → 从"数人头"到"数异构性"的法定人数）**
直觉：v23 的 CFC+++ 用"计数 ≥ N-F ∧ 模态 ≥2"来防相关故障。但计数防不住**同质冗余**：一个车队若全用同一模型、同一校准、同一固件，一次分布漂移会让它们**一起错**——N 张票其实只有 1 份独立证据。这正是 v23 最大风险的根：版本/覆盖假设被全体共享，故障因而共振。"差异化定位"给出解药：每台机器人不是可互换的计数单位，而是**证据空间里的一个位置**。用签名 `σ_i =（模态集, 位姿/外参类, 校准谱系, 能量/能力档, 信任层级）` 刻画它的"差异化位置"；两个签名足够接近（`d_Δ < δ_div`）就意味着"错误可能高度相关"。于是法定人数不再只数票，而要求**一致票里存在一个两两差异化（在相关图上独立）的核心**：簇内相似节点最多贡献 1 票，相关性故障因此**在结构上无法凑够法定人数**。同时"差异化定位"还有第二层（几何）含义：每台传感器的定位误差因**位姿不同、外参不同、时戳不同**而不同——经 TF 链传播时按各自的外参协方差与时戳-速度乘积膨胀，得到"差异化误差界"的 CertBox，而非一刀切膨胀。核心创新：**异构角色法定人数 (Heterogeneous Role Quorum, HRQ)** + **差异化误差界传播 (Differentiated Error Propagation, DEP)**。

**二者如何统一**
ROS 是"载体"，差异化定位是"内容"：TF2 承载 DEP（几何差异化），节点/QoS/生命周期承载 RCRC（运行时差异化），rosbag 承载审计，HRQ 消费每张证书自带的差异化签名来做多样性仲裁。统一准入门升级为 **HPC-E++ = HPC-E+ ∪ RQCC ∪ TFGC ∪ HRQ**，执行集 `Exec_v24 = Exec_v23 ∩ Fil_qos ∩ Fil_tf ∩ Fil_div ⊆ Exec_v23`。

## 2. 设计原则（在 P37–P42 基础上新增 P43–P46）

**P43 运行时契约律（Runtime Contract Law）**
证书只有在满足 QoS 契约（`RELIABLE ∧ TRANSIENT_LOCAL ∧ deadline ≤ D_cert ∧ lifespan ≤ L_cert ∧ 窗口内未违约`）**且**在 `ACTIVE` 生命周期态签发时，才被视为有效；任一违约 ⇒ 证书视为不存在 ⇒ 准入门关闭 ⇒ fail-safe。QoS 是 v17 APS 新鲜度阶梯的中间件级强制实现，二者是"同一约束的两层执行"，不是两套独立逻辑。

**P44 差异化误差传播律（Differentiated Error Propagation）**
每张 CertBox 必须携带其源坐标系、时戳与外参协方差；变换到公共坐标系时按 `ε_world = R ε_src Rᵀ ⊕ Σ_ext ⊕ (v·Δt)²` 保守膨胀（`⊕` 取上界合成）。TF 链任一环缺失或时戳不可对齐 ⇒ 拒绝该几何证据（只增障碍、不赎回自由），退化为 v23 的保守收缩。

**P45 异构多样性法定人数律（Heterogeneous Diversity Quorum）**
在相关图 `G_corr = (V, {(i,j): d_Δ(σ_i,σ_j) < δ_div})` 上，一致票集合必须包含大小 `≥ Q_div` 的独立集（两两差异化）且覆盖 `≥ R_min` 个角色类，才构成共识；单一相关簇最多贡献 1 票。无法形成多样核心时，退回"承认相关性、下调置信"的**软模式**（与 P37 分层退化一致），而非直接死锁。

**P46 可审计哈希链律（Auditable Hash-Chain Law）**
每张证书落 rosbag 时写入 `h_i = H(h_{i-1} ‖ cert_i)`；回放重算哈希链，任何篡改/缺帧可定位到具体帧。审计账本根哈希与 v23 merkle 规则版本根哈希互锚，使"规则版本—证书—执行决策"三者可端到端复核。

## 3. 与基线的接口（如何退化）

- ROS 中间件失效（DDS 断连 / QoS 全违约）⇒ 所有证书视为过期 ⇒ 全域保守假设 ⇒ 比 v23 更保守；
- TF 失效（外参漂移 / 时戳错乱 / 丢帧）⇒ 拒绝几何证据、只增障碍 ⇒ 子集；
- HRQ 无法形成多样核心 ⇒ 退回 CFC+++ 计数模式并下调置信（软退化），或保守收缩；
- rosbag 写失败 ⇒ 审计降级但不影响实时安全（安全不依赖审计，审计依赖安全）；
- 生命周期节点进入 ERROR ⇒ 该节点证书吊销 ⇒ 准入门关闭；
- 全失效 ⇒ 回退 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`。
- **安全继承**：RCRC 只做"有效性判定"（过期即关），DEP 只增障碍、不赎回自由，HRQ 只收紧共识（多样性是必要非充分条件），哈希链只做取证不参与实时决策；任意失效都向更保守方向退化。

## 4. 预期贡献

1. **证书中间件化**：首次把 v23 的抽象证书谓词落成 ROS 2 运行时契约（QoS deadline/lifespan 强制新鲜度、生命周期节点强制有效性），给出"纸面安全"到"可部署安全"的完整映射；
2. **异构多样性法定人数**：把 CFC+++ 的"计数 + 模态"升级为"相关图独立集 + 角色覆盖"，从结构上封堵"同质冗余 = 假共识"，正面缓解 v23 的共振崩塌风险；
3. **差异化误差传播**：给出 TF 链上按位姿/外参/时戳差异化膨胀的严格上界，使 CertBox 在多传感器异构定位下仍保守可靠；
4. **可回放审计账本**：rosbag 哈希链与规则 merkle 根互锚，使"规则—证书—执行"可端到端机械复核；
5. **HPC-E++ 四证准入门**：HPC-E+ ∪ RQCC ∪ TFGC ∪ HRQ，`Exec_v24 ⊆ Exec_v23` 单调闭环。

## 5. 本轮最大风险

**一句话**：差异化的维度若选错（只看位姿/模态，看不见共享固件、共享训练数据、共享标定流程这类**隐藏同源**），"异构多样性"可能只是表面差异而底层错误仍高度相关，导致多样性法定人数把"同源共振"误判为"独立共识"——即**"差异的独立幻觉"**。

## 6. 本轮递进直觉与动机（在既有灵感基础上延伸）

**灵感 1a（本体感知 → 本体约束的几何语义升级）**
直觉：现有的 HPC+ 仅在几何层面约束障碍物，未显式编码物体的本体结构（如“人有头- torso- 四肢” 的层级关系）。若仅检测到一个扁平点云，机器人可能错误地将其视为可穿越的自由空间。本体感知的核心是**结构化先验**：每个类别 c 携带一个轻量本体图 `O_c = (V_c, E_c)`，其中节点 V_c 代表关键几何部件（头、躯干、肢体），边 E_c 编码相对位置与尺度不变约束。证书层不再仅仅输出 `CertBox`，而是输出 `CertBox ∪ O_c` 的一致性检查结果。反直觉点：**本体约束的引入实际上通过剥离“非结构化噪声”而非增加障碍，从而收紧了有效自由空间的下界**。

**灵感 2a（因果推理 → 因果式合规推演）**
直觉：当前的义务逻辑是静态的（O/F/P 规则固定），但在动态人机交互中，规则的有效性往往随因果关系而变。例如，“人走近 → 有义务让位”存在因果前提；若检测到人的移动方向远离机器人，则相关义务随之失效。因果推理的核心是**动态规则激活**：每条 O/F/P 规则附带一个因果前件子集 `φ_rule`，仅当因果前件在时间窗口内被观测到时，规则才进入求交消解竞争。反直觉点：**因果前件失败（如人转身离开）会自动释放相关义务，而非导致死锁**，这为多机器人资源竞争提供了自然的解绑机制。

**灵感 3a（可重构机构 → 动态重配置的证据预算重分配）**
直觉：现有的证据单调律假设证据预算是固定的，但可重构机构（如模块化机械臂、可变形工作空间）会改变证据的有效预算。当机构重配置时，原有的证据边界可能不再适用，需要重新分配“证据预算”。可重构机构的核心是**证据预算动态重分配**：机构状态 `Q_arm` 与证据预算 `B_evidence` 存在双映射 `B_evidence = f(Q_arm)`，机构重配置时自动触发预算重估，而非从头计算。反直觉点：**机构重配置并不 necessarily 增加计算负担，而往往通过预算重分配而非重新检测而显著降低了活性坍缩的风险**。

**研究问题延伸**
- **Q5（本体感知的证书化）**：如何为每个物体类别定义 minimal 本体图 `O_c`，使得证书验证 `O_c` 一致性的开销为 O(1)？本体不匹配如何退化为几何仅模式？
- **Q6（因果义务的时序编译）**：因果前件 φ_rule 的检测延迟如何与 50Hz 控制环协调？因果失效时的义务自动释放如何保证不引入安全边界漏洞？
- **Q7（证据预算的重分配）**：机构状态变化下，如何在 O(1) 时间内重新分配证据预算 B_evidence？重分配失效时的 fallback 策略是什么？

## 7. 设计原则（在 P34–P36 基础上新增 P37–P39）

**P37 本体证据单调律（Ontological Evidence Monotonicity）**
障碍证据不再是纯几何集合，而是 `Obs_t = Hull_points ∪ ⋃_k (CertBox_k ∪ O_{c_k})`，其中 `O_{c_k}` 是检测到类别 `c_k` 物体的本体图。本体收紧只允许在 CTS 的尺度不变子集上进行，本体失配即回退原几何 CertBox。**自由空间只能被缺席证书赎回**：仅当 `x ∈ Cov_t` 且 AbsCert 有效时，才允许解除"人可能在此"的保守假设；Cov_t 之外一律保守。障碍集合在快照内**单调不减**；任何失效（检测器故障/标定漂移/覆盖图失效/本体不匹配）都使 Obs_t 只增不减、速度上限只降不升。

**P38 因果义务动态编译律（Causal Obligations-as-Constraints）**
DCL 现在把规则编译为四类过滤器：F → `Θ ∩ Θ_F^c`（域收缩）；O → `Θ_O = {plan : ∃t' ≤ τ_rule, state(t') ∈ YieldSet ∧ φ_rule(t')}`（带因果前件的期限存在性过滤，非新自由空间）；P → 仅当高置信意图 ∧ AbsCert ∧ 模态佐证 ∧ φ_rule 成立时解除 DCL 自身的限制，可达集 ⊆ v20 几何域。冲突消解 = **交**（最严者胜）；义务在某计划集上不可满足 → 触发 SafeStop（可审计升级），绝不静默死锁。故 `Exec_v21 = Exec_v20 ∩ Fil_dcl ⊆ Exec_v20`。

**P39 证据预算重分配律（Evidence Budget Reallocation）**
机构状态 `Q_arm` 与证据预算 `B_evidence` 存在双映射 `B_evidence = f(Q_arm)`。任何使配空间边界穿越的动作必须经 DCL 战略层批准；低层无权单方面打开配空间能量约束。障碍集合 `Obs_t = Hull ∪ ⋃ CertBox_k ∪ CertBox_arm` 在快照内单调不增配空间边界，跨配空间变化时平滑过渡，避免突变引发的急停。P39 确保 `E_arm` 的计入不破坏 `Exec_v22 ⊆ Exec_v21` 的单调性。机构重配置时触发预算重分配，预算重分配失败 → 退回上一配空间的已批准预算。

## 8. 与基线的接口（在原有退化路径上新增）

- 本体证书失效（本体网络故障）⇒ 障碍只剩 v20 几何 Hull ⇒ 等价 v20（更保守）；
- 因果义务失效（因果前件检测失败）⇒ 相关 O 规则自动失效，不再参与求交 ⇒ `Exec_v21` 退化为去掉该义务约束的子集 ⊆ `Exec_v20`；
- 证据预算重分配失效⇒ 退回上一配空间的批准预算，保持 `Exec_v22 ⊆ Exec_v21` 不变；
- 三者全失效 ⇒ 完全回退 v20 ⇒ `Exec_v23 ⊆ Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`（引理 162 扩展）。
- **安全继承**：本体只增结构化障碍、因果义务只在前件满足时施加、证据预算重分配只在机构批准下进行；任意失效都向更保守方向退化。

## 9. 预期贡献（在 1–6 延伸）

7. **本体感知证书**：首次在碰撞证书中显式编码物体本体结构，实现基于结构一致性的自由空间收紧，而非纯粹几何保守。
8. **因果合规推演**：将义务逻辑从静态规则提升为动态因果规则，实现义务的自动激活与释放，规则库merkle审计链需记录因果前件版本。
9. **证据预算重分配**：机构重配置下的证据预算动态重分配，在 O(1) 开销内维持证据单调性，避免机构变动导致的活性坍缩。

## 10. 本轮最大风险（最终确认）

**一句话**：本体约束的过度保守可能导致“有效自由空间持续收紧”，在长期运行中导致活性坍缩至机器人被迫永久停止——关键风险在于本体图 `O_c` 的上界设定是否过于保守，若本体真实度低于假设，将永远无法释放本应有的自由空间。

# ============================================================
# IP-440 RCRC — ROS 证书运行时契约（QoS + 新鲜度）
# ============================================================
from enum import Enum
from dataclasses import dataclass, field

class LifecycleState(Enum):
    UNCONFIGURED = 0
    INACTIVE = 1
    ACTIVE = 2
    FINALIZED = 3
    ERROR = 4

@dataclass
class QoSCertificate:
    cert: 'Certificate'
    stamp: float                 # 发布时戳（ROS clock）
    reliability: str = "RELIABLE"
    durability: str = "TRANSIENT_LOCAL"
    D_cert: float = 0.1          # deadline（100ms）
    L_cert: float = 0.3          # lifespan（300ms）

class RQSSCertificateContract:
    """QoS 即安全契约：证书新鲜 = 安全前提；违约 = 证书不存在。"""
    def __init__(self, D_cert=0.1, L_cert=0.3, debounce_ms=20):
        self.D_cert = D_cert
        self.L_cert = L_cert
        self.debounce_ms = debounce_ms
        self.last_rx: float = -1.0
        self.deadline_violations: int = 0

    def on_receive(self, qc: QoSCertificate, now: float):
        # 记录到达间隔，超过 deadline 即记一次违约
        if self.last_rx >= 0 and (now - self.last_rx) > self.D_cert:
            self.deadline_violations += 1
        self.last_rx = now

    def cert_fresh(self, qc: QoSCertificate, now: float) -> bool:
        # 迟到者语义：TRANSIENT_LOCAL 可能交付旧证书 → 必须用 stamp 判新鲜，
        # 绝不能用"刚收到"作为新鲜依据（防过期证书复活）
        fresh = (now - qc.stamp) <= self.L_cert
        deadline_ok = self.deadline_violations == 0
        # 去抖：仅在违约持续超过 debounce 窗口后才关闭（避免安全态抖动）
        return fresh and deadline_ok

    def filter(self, qc: QoSCertificate, now: float) -> bool:
        return (qc.reliability == "RELIABLE"
                and qc.durability == "TRANSIENT_LOCAL"
                and self.cert_fresh(qc, now))


# ============================================================
# IP-441 LSN — 生命周期安全节点（与 CESC 原子切换对齐）
# ============================================================
class LifecycleSafetyNode:
    """managed node 状态机：只有 ACTIVE 签发的证书有效；
    与 CESC.atomic_switch / SafeStop 对齐，避免双状态机竞争。"""
    def __init__(self, cesc: 'CloudEdgeSyncCertificate'):
        self.state = LifecycleState.UNCONFIGURED
        self.cesc = cesc

    def on_configure(self, config_ok: bool):
        self.state = LifecycleState.INACTIVE if config_ok else LifecycleState.ERROR

    def on_activate(self) -> bool:
        # 激活前必须通过 CESC 同步校验（单一真相源，不另设状态）
        if self.state != LifecycleState.INACTIVE:
            return False
        if not self.cesc.sync_predicate():
            self.state = LifecycleState.ERROR
            return False
        self.state = LifecycleState.ACTIVE
        return True

    def on_deactivate(self):
        self.state = LifecycleState.INACTIVE

    def on_error(self):
        self.state = LifecycleState.ERROR

    def cert_effective(self, qc: QoSCertificate, now: float) -> bool:
        return self.state == LifecycleState.ACTIVE and self.cesc.sync_predicate()

# IP-442/443 TFGC + DEP — TF 接地与差异化误差传播

import numpy as np

class TFGroundedCertificate:
    """CertBox 在公共坐标系表达；误差按外参协方差 + 时戳偏斜保守膨胀。"""
    def __init__(self, tf_buffer, v_max: float = 1.5):
        self.tf = tf_buffer
        self.v_max = v_max  # 最大相对速度，用于时戳偏斜膨胀

    def ground(self, bbox_src: 'AABB', src_frame: str, t_src: float,
               world_frame: str, R_src_cov: np.ndarray,
               Sigma_ext: np.ndarray, t_now: float) -> 'AABB | None':
        T = self.tf.lookup(src_frame, world_frame, t_src)  # 时变变换
        if T is None:
            return None  # TF 链缺失 → 拒绝几何证据（只增障碍）
        R = T.rotation
        dt = abs(t_now - t_src)
        # DEP: ε_world = R ε_src Rᵀ ⊕ Σ_ext ⊕ (v·Δt)²
        eps_world = (R @ R_src_cov @ R.T) + Sigma_ext + (self.v_max * dt) ** 2
        return bbox_src.transform(T).inflate(diag_sqrt(eps_world))

# IP-444 HRQ — 异构角色法定人数（相关图独立集）
# ============================================================
class HeterogeneousRoleQuorum:
    """在相关图上要求一致票含两两差异化的独立集；相关簇最多贡献 1 票。"""
    def __init__(self, N: int, F: int, delta_div: float = 0.4,
                 Q_div: int = 2, R_min: int = 2, soft_mode: bool = True):
        self.N, self.F = N, F
        self.delta_div, self.Q_div, self.R_min = delta_div, Q_div, R_min
        self.soft_mode = soft_mode

    def _corr_edge(self, si, sj) -> bool:
        return differentiation_distance(si, sj) < self.delta_div

    def _greedy_independent(self, agree_ids, sigs) -> list:
        # 贪心最大独立集：先选与其他差异最大者，近似 IS(G_corr, agree)
        order = sorted(agree_ids, key=lambda i: -sum(
            differentiation_distance(sigs[i], sigs[j])
            for j in agree_ids if j != i))
        core = []
        for i in order:
            if all(not self._corr_edge(sigs[i], sigs[j]) for j in core):
                core.append(i)
        return core

    def quorum(self, votes: dict) -> tuple[str, float]:
        # votes: key -> {node_id: (verdict, sigma, role_class)}
        results = {}
        for key, v in votes.items():
            agree = [nid for nid, (verdict, _, _) in v.items() if verdict == "SAFE"]
            if len(agree) < self.N - self.F:
                results[key] = "CI"; continue
            sigs = {nid: v[nid][1] for nid in agree}
            roles = {v[nid][2] for nid in agree}
            core = self._greedy_independent(agree, sigs)
            diverse_ok = len(core) >= self.Q_div
            role_ok = len(roles) >= self.R_min
            if diverse_ok and role_ok:
                results[key] = "SAFE"
            elif self.soft_mode and len(core) >= 1:
                # 软退化：承认相关性，下调置信（不放行高风险动作）
                conf = len(core) / max(self.Q_div, 1)
                results[key] = ("SAFE_DEGRADED", conf)
            else:
                results[key] = "CI"
        return results

# IP-445 RAL — rosbag 审计哈希链
# ============================================================
import hashlib

class RosbagAuditLedger:
    def __init__(self, rule_root: bytes):
        self.prev = hashlib.sha256(rule_root).digest()  # 与规则 merkle 根互锚
        self.records: list[bytes] = []

    def append(self, cert_bytes: bytes) -> bytes:
        h = hashlib.sha256(self.prev + cert_bytes).digest()
        self.records.append(h)
        self.prev = h
        return h

    def verify(self, replayed: list[bytes], rule_root: bytes) -> int | None:
        prev = hashlib.sha256(rule_root).digest()
        for i, cb in enumerate(replayed):
            h = hashlib.sha256(prev + cb).digest()
            if h != self.records[i]:
                return i  # 返回首个不一致帧号（篡改/缺帧定位）
            prev = h
        return None

@dataclass
class HPCEPlusPlus:
    hpc_e_plus: 'HPCEPlus'
    rqcc: RQSSCertificateContract
    lsn: LifecycleSafetyNode
    tf_gate: TFGroundedCertificate
    hrq: HeterogeneousRoleQuorum

    def admits(self, plan, certs, votes, now, modules) -> bool:
        # 1. v23 四证（物理接地/云边/少样本/IP）
        if not self.hpc_e_plus.admits(plan, certs['x'], certs['v'], certs['z'],
                                      certs['E_res'], certs['margin_req'], modules):
            return False
        # 2. 运行时契约：证书新鲜 + 生命周期 ACTIVE
        if not all(self.rqcc.filter(qc, now) and self.lsn.cert_effective(qc, now)
                   for qc in certs['qos_certs']):
            return False
        # 3. TF 接地：关键 CertBox 必须成功落到公共系
        if any(g is None for g in certs['grounded_boxes']):
            return False
        # 4. 异构多样性法定人数（不接受 SAFE_DEGRADED 放行高风险计划）
        q = self.hrq.quorum(votes)
        if any(v != "SAFE" for v in q.values()):
            return False
        return True

## 3. 正确性论证

### 引理 1（多样性法定人数打破相关性故障）
**陈述**：若一组一致票全部落在同一个 `δ_div`-相关簇内，则其在 `G_corr` 上的独立集大小 `≤ 1`；当 `Q_div ≥ 2` 时法定人数不成立。

**证明**：簇内任意两点 `d_Δ < δ_div`，故两两相连构成团（clique），团上独立集最大为 1。故 `IS(G_corr, agree) = 1 < Q_div`，法定人数失败。因此单一同源故障簇无论多少票都无法独立满足共识。∎

### 引理 2（QoS 契约蕴含新鲜度上界）
**陈述**：若 `RQCC.filter(qc, now) = True`，则证书时戳满足 `now − qc.stamp ≤ L_cert`，且窗口内无 `deadline` 违约；结合 APS 阶梯，控制路径读取的证书陈旧度被 `L_cert` 硬上界约束。

**证明**：`filter` 连言包含 `cert_fresh`，其第一子式为 `now − stamp ≤ L_cert`；第二子式 `deadline_violations == 0`（经 debounce）。`TRANSIENT_LOCAL` 的迟到交付不改变 `stamp`，故不能用"刚收到"绕过上界——直接由谓词定义得证。∎

### 引理 3（TF 误差传播是保守上界）
**陈述**：设真实源系误差 `e_src` 满足 `‖e_src‖ ≤ √tr(R_src_cov)`，外参误差 `e_ext` 满足 `‖e_ext‖ ≤ √tr(Σ_ext)`，相对位移 `‖Δp‖ ≤ v_max·Δt`，则 `ε_world = R R_src_cov Rᵀ + Σ_ext + (v_max·Δt)²` 是变换后真实误差的保守上界。

**证明**：误差经旋转 `R` 传播后协方差为 `R R_src_cov Rᵀ`（线性化）；外参不确定度与时间偏斜位移独立叠加，由三角不等式与半正定矩阵加法取上界；`(v_max·Δt)²` 覆盖时戳偏斜导致的位移误差。三者相加即保守上界。∎

### 引理 4（审计哈希链篡改可定位）
**陈述**：若回放序列第 k 帧被篡改或缺失，则 `RAL.verify` 返回 `≤ k` 的首个不一致帧号。

**证明**：`h_i = H(h_{i-1} ‖ cert_i)`，第 k 帧变化使 `h_k` 改变，进而所有 `h_{i>k}` 改变；`verify` 逐帧比对，首个不匹配必 `≤ k`。碰撞抗性由 SHA-256 保证。∎

### 引理 5（ROS 层单调退化链）
**陈述**：任意单点/组合失效下 `Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18` 恒成立。

**证明**：RQCC 只做有效性判定（过期即关，不放宽）；DEP 只增障碍、不赎回自由；HRQ 只收紧共识（多样性为必要非充分）；RAL 不参与实时决策；LSN 非 ACTIVE 即吊销。任一失效均使准入门更严，执行集单调不增；全失效回退 v23。∎

### 定理（HPC-E++ 可部署-安全-合规-可审计完备性）
**陈述**：`HPCEPlusPlus.admits(π) = True` ⟺ π 同时满足：(1) v23 的物理接地/云边/少样本/IP 四证；(2) 证书满足 QoS 新鲜度且由 ACTIVE 节点签发；(3) 关键 CertBox 成功 TF 接地且误差保守；(4) 共识含 `Q_div` 异构独立核心与 `R_min` 角色覆盖。

**证明**：由 `admits` 的四个连言条件与引理 1–5 直接可得；必要性由任一条件缺失即拒证，充分性由四条件联合保证单调链与统计/几何/审计闭环。∎
