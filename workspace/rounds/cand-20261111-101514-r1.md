# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 3 轮；本轮灵感：「UniBot-V1」×「人机交互」）

> 第 54 轮用动作空间剖面、技能组合图与云边协同把“系统能做什么”证到了动作粒度。但只要现场有人，证书就有一个未建模变量：**人不是 i.i.d. 噪声，而是有意图、会改变任务前提的半可观测协作者/干扰源**。本轮把 HRI 显式接入证书链：人因后验 → 联合动作安全域 → 可读性执行 → 权限分配 → 交互证书。核心矛盾：H22：把人当噪声会把“协作”误判为“扰动”，导致过度保守或误伤；H23：UniBot-V1 没有音频/显示通道，交互只能靠视觉观测与运动本身表达，若把可读性当作安全前提，则安全证书不成立。

## 0. 直觉与动机

**灵感 1（人因状态是隐变量，不是噪声）**
直觉：同样的“手伸过来”，可能是递物、夺物、只是路过、或遮挡。把人的动作当成加性噪声，会得到一个对所有人都保守、却对任何一种意图都不准确的策略。正确做法是维护一个**有限意图集上的后验** `b_t(z)`，并显式记录“不知道”（abstain）。交互的第一性不是“读出人心”，而是“在不知道时仍然安全”。

**灵感 2（安全域必须在联合动作空间里定义）**
直觉：第 54 轮的 `α_S` 是机器人单边动作剖面。人在场时，安全不是 `a_R` 的属性，而是 `(a_R, a_H)` 的属性。定义联合动作空间 `A_J = A_R × A_H` 与联合兼容性，要求机器人动作对**所有可信人动作**都安全。这把“人机交互”从 reward shaping 变成**安全域约束**，并与第 54 轮的动作剖面/技能组合图直接对接。

**灵感 3（可读性只买效率，不买安全）**
直觉：机器人放慢、停顿、绕行、改变接近方向，能让人预测它下一步。这是 UniBot-V1 在没有屏幕和语音时唯一的“表达通道”。但人可能误读，所以**安全不能依赖人读懂机器人**；可读性只用于减少不必要的让行、提升协作效率。这条“安全/可读性解耦”是本轮最关键的反直觉设计。

**灵感 4（权限分配是显式状态机，不是连续插值）**
直觉：共享自治不是把控制权按比例混合，而是离散权限模式：`robot_lead / shared / human_lead / yield / wait / reobserve`。每种模式有进入/退出条件和安全义务。UniBot-V1 里人不在 API 内，因此契约是**单边承诺**：机器人承诺在人类进入安全包络时让行；人类没有对等义务，所以机器人不能假设“人会让”。

**灵感 5（交互证书把人的不确定性记账）**
直觉：在第 54 轮联合证书 `J` 上增加 `b_t, A_J^safe, α_auth, Leg, δ_H`，形成 `J_HRI`。只有当人因后验误差 `δ_H` 有界、联合安全域非空、可读性达标时，才允许按“协作模式”部署；否则退回“保守让行模式”。这把 HRI 从演示效果变成**可审计的部署条件**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（交互上下文与人因状态）**
交互上下文 `c_H = (h, o, τ)`：`h` 为人的可观测状态（位置、手部包围盒、运动速度、朝向、是否遮挡物体），`o` 为物体状态，`τ` 为任务阶段。人因隐状态 `z ∈ Z = {idle, assist, interfere, observe, handover, occlude, relocate, undo}`。观测代理 `y_t = Φ(c_H)`，人策略 `π_H(z_t | h_{1:t})` 非平稳。**UniBot-V1 边界**：无音频，`language` 是 episode 级固定文本，因此 `y_t` 只来自四路 RGB 与本体感觉，交互必须是**隐式、视觉/运动驱动**的。

**定义 122（人因后验与三值交互判定）**
`b_t(z) = P(z | y_{1:t})`，认知不确定性 `u_t = 1 - max_z b_t(z)`。三值交互判定：
```
mode_t = assist     若 b_t(assist) ≥ θ_H 且 u_t ≤ u_max
       = interfere  若 b_t(interfere) ≥ θ_H 且 u_t ≤ u_max
       = unknown    否则
```
`unknown` 不是失败，而是**必须触发保守策略**的一等状态。后验误差界 `δ_H` 满足 `P(z ∉ argmax b_t 且 mode_t ≠ unknown) ≤ δ_H`。

**定义 123（联合动作空间与交互安全）**
`A_J = A_R × A_H`。联合兼容性
```
compat_J(a_R,a_H) = 1 - risk_collision(a_R,a_H) - risk_semantic(a_R,a_H)
```
其中 `risk_semantic` 惩罚“机器人抓取人正在递/正在用的物体”。可信人动作集 `A_H^plaus(b_t) = {a_H : P(a_H | b_t) ≥ ε_p}`。机器人动作**交互安全**当且仅当
```
∀ a_H ∈ A_H^plaus(b_t): compat_J(a_R,a_H) ≥ θ_J
```
这直接扩展第 54 轮定义 115/116：技能组合之前先过联合安全筛，`A_J^safe` 再与 `A_core` 取交。

**定义 124（可读性与可预期性成本）**
可读性 `Leg(a_R | b_t) = E_{z~b_t}[ log P(a_R | z) / P(a_R) ]`（机器人动作对该意图的区分度），可预期性 `Pred(a_R) = -H(a_R | history)`，人类惊讶 `Surp(a_R) = -log P_H(a_R)`。执行成本
```
cost_exec = w_t·(1 - progress) + w_s·Surp + w_l·max(0, θ_leg - Leg)
```
**硬约束**：`a_R` 必须先属于 `A_R^safe`；可读性项只在安全域内做选择，绝不用于放宽安全。

**定义 125（权限分配与交互契约）**
权限模式 `α ∈ {robot_lead, shared, human_lead, yield, wait, reobserve}`。交互契约
```
C_HRI = (b_t, A_H^plaus, α, O_R, E_stop)
```
`O_R` 为机器人单边义务（如“人进入安全包络 ⇒ 降速/让行/保持距离”），`E_stop` 为升级条件（如“连续 k 帧 unknown ⇒ 进入 wait”）。因为人不在 API 内，**不存在人类义务项**；任何需要人配合才能成立的安全主张都视为无效。

**定义 126（人机交互联合证书）**
`J_HRI = (J, b_t, A_J^safe, α, Leg, δ_H, evidence)`：
- `J` 为第 54 轮动作-鲁棒性联合证书；
- `A_J^safe` 为交互安全动作集；
- `δ_H` 为人因后验误差上界；
- `Leg` 为可读性下界；
- `evidence` 至少含人类干扰试次、反事实遮挡/移动/递物回放、以及 `unknown` 状态的让行日志。
部署判定：`dom_J(T)=in ∧ A_J^safe≠∅ ∧ δ_H≤Δ_H ∧ Leg≥θ_leg ∧ P(collision)≤ε_H`。任一不满足则降级到 `yield/wait`，而不是拒绝整个任务。

## 2. 关键算法 伪代码

### IP-121 HIP（Human Intent Posterior）
```python
def update_intent_belief(b_prev, y_t, T, u_max, theta_H):
    pred = T @ b_prev
    b = normalize(pred * likelihood(y_t))
    u = 1.0 - max(b.values())
    if u > u_max:
        return b, 'unknown'
    z = argmax(b)
    if b[z] >= theta_H and z in ('assist','interfere'):
        return b, z
    return b, 'unknown'
```
轻量检测/跟踪人-物关系；HMM/贝叶斯后验；滞回 + abstain；不引入第二个在线大模型。

### IP-122 JAS（Joint Action Safety）
```python
def joint_safe_set(candidates, b, eps_p, theta_J):
    A_H = plausible_human_actions(b, eps_p)
    safe = []
    for a_R in candidates:
        if all(compat_J(a_R, a_H) >= theta_J for a_H in A_H):
            safe.append(a_R)
    return safe
```
候选动作来自第 54 轮技能图 `G_S`，返回安全集与最小安全包络。

### IP-123 LEC（Legible Execution Controller）
```python
def select_execution(safe_set, b, theta_leg):
    best, best_cost = None, inf
    for a_R in safe_set:           # 安全域内选择
        c = w_t*(1-progress(a_R)) + w_s*surprise(a_R) \
            + w_l*max(0, theta_leg-legibility(a_R, b))
        if c < best_cost:
            best, best_cost = a_R, c
    return best
```
运动原语：接近方向、速度剖面、停顿、绕行；只改变“怎么说”，不改变“安不安全”。

### IP-124 SAA（Shared Authority Allocation）
```python
def allocate_authority(mode_t, u_t, dist, phase, hist):
    if mode_t == 'unknown' or intrusion(dist):
        return escalate(hist, ['yield','wait','reobserve'])
    if mode_t == 'interfere':
        return 'yield'
    if mode_t == 'assist' and u_t < u_low:
        return 'shared' if phase.requires_human else 'robot_lead'
    return 'robot_lead'
```
权限模式带滞回，防止在边界抖动；升级链 `robot_lead → shared → yield → wait → reobserve`。

### IP-125 HIC（Human-Interaction Certificate）
```python
def interaction_certificate(J, b, safe_set, alpha, leg, delta_H, evidence):
    if not safe_set:
        return ('degrade','no_joint_safe_action')
    if delta_H > Delta_H or leg < theta_leg:
        return ('degrade','uncertain_or_illegible')
    if intrusion_rate(evidence) > eps_H:
        return ('reject','human_harm_risk')
    return ('ok', JointCert_HRI(J, b, safe_set, alpha, leg, delta_H))
```
检查 `δ_H`、`Leg`、安全包络、`unknown` 比例；输出 `deploy / degrade / reject`。

### IP-126 HRL（Human-Robot Loop）
```python
def human_robot_loop(obs, J54, theta):
    b = init_belief()
    while not done:
        y = observe_human(obs)
        b, mode = update_intent_belief(b, y, T, theta.u_max, theta.H)
        safe = joint_safe_set(skill_candidates(J54), b, theta.eps_p, theta.J)
        alpha = allocate_authority(mode, uncertainty(b), dist(obs), phase(obs), hist)
        a_R = select_execution(safe, b, theta.leg) if alpha != 'wait' else hold()
        execute(a_R)
        if surprise(a_R) > theta.surprise or intrusion(obs):
            exp = explain_failure(simulate(a_R, obs), sim_model)
            b = update_intent_belief(b, exp.counterfactual, T, theta.u_max, theta.H)
        obs, done = step()
    return b, alpha
```
在线闭环：perceive → infer → allocate → execute → monitor → update；触发第 54 轮 `reprofile` 与 `Explain` 反向解释。

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| HIP | O(|Z|² + |Y|·|Z|) | O(|Z|) | 后验校准、abstain 覆盖 |
| JAS | O(|A_R|·|A_H^plaus|) | O(|A_R|) | 人动作集覆盖 sound、兼容性下界 |
| LEC | O(|A_R^safe|) | O(1) | 只在安全域内选择 |
| SAA | O(1) | O(1) | 滞回、升级链单调 |
| HIC | O(|A_R|·|A_H|) | O(|A_R|) | 联合证书 sound、`δ_H` 记账 |
| HRL | 每步同 JAS+HIC | O(|Z|+|A_R|) | 闭环收敛、Explain 一致 |

**正确性定理（Human-Interaction-Aware Deployment Soundness）**
假设第 54 轮 (A26)–(A28) 成立；新增：
**(A29)** 后验校准：`P(z ∉ argmax b_t 且 mode_t≠unknown) ≤ δ_H`；
**(A30)** JAS sound：通过 `A_J^safe` 的动作对 `A_H^plaus(b_t)` 内任意人动作的碰撞概率 ≤ ε_H；
**(A31)** 可读性不参与安全约束（`Leg` 只影响效率项）。
则
```
P(task success ∧ no human harm | J_HRI)
  ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a) - δ_H - ε_H
```
关键：`Leg` **不出现在安全项**；安全由保守联合动作覆盖保证，可读性只降低不必要的让行。

## 4. 实验设计 E162–E166

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 人因后验校准 | ECE / Brier / abstain 率 / unknown 覆盖 | ECE ≤ 0.05，高风险 unknown 召回 ≥ 95% |
| E163 联合动作安全 | near-miss 率 / 安全包络入侵率 | near-miss = 0，入侵 ≤ 0.5% |
| E164 可读性 | 人类预测下一动作准确率 / 代理 surprise | 准确率 +20% 或 surprise 显著下降 |
| E165 交互证书有效性 | 人在场成功率 vs 第 54 轮 | +12%，零安全事故 |
| E166 权限分配 | 干扰后恢复时间 / 误让行率 | 恢复 ≤ 3s，误让行 ≤ 10% |

**对照与消融**：① 第 54 轮无 HRI 证书；② 人当噪声的保守基线；③ 有可读性无联合安全；④ 联合安全无 abstain。分离“安全收益”和“效率收益”，防止用流畅演示掩盖安全包络缺口。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| RGB 单帧意图不可辨识 | 高 | 时序证据 + abstain + 保守让行 |
| 过度让行导致任务超时 | 高 | 最小可行交互 + 预测性避让 + 影子模式 |
| 可读性误导人 | 中 | 只在可保证时表达 + 反事实测试 |
| 安全包络过保守 | 中 | 任务阶段自适应包络 + 距离分层 |
| 单模型约束被破坏 | 高 | 轻量头/规则；禁第二个在线大模型 |
| 人故意对抗 | 高 | V1 明确不承诺对抗安全，只承诺非恶意不确定性下安全 |

## 6. 本轮最大风险

**一句话**：把“人”从噪声升级为带后验的隐变量，确实让 HRI 进入证书链，但整条链的 soundness 最终取决于 **RGB 单模态下人因后验的可辨识性与安全包络的覆盖度**；一旦 `assist` 与 `interfere` 在观测上不可分却被强行分类，或安全包络漏掉“人会把物体移走/占住”的联合动作，证书会精确地为一个错误的人因状态背书，故必须以 **abstain 优先 + 单边保守义务 + 联合动作反事实回放 + 对抗/非对抗分层声明** 四重护栏，宁可让行，绝不把“人看起来会配合”当作安全前提。

# 第 55 轮产物 · 创新点清单 v32：CoCal-HRC（CCO×CAX×CDD×HCC×CDC×JCC）

> 承接第 54 轮产物 v31（GroundEdge-GenSim+++）。本轮在动作-鲁棒性双证书之上，增加**共标定（Co-Calibration）**维度，把“感知/坐标系已标定且不变”这一隐含前提显式化为可验证、可过期、可作废的证书：
> - **CCO（Co-Calibration Observer）**：联合估计人-机关系标定 `C=(T_HR,δ_t,b_s,π_h)` 与其协方差；
> - **CAX（Calibration eXcitation Planner）**：在激励-流畅前沿上做约束贪心，保证可观测而不牺牲流畅；
> - **CDD（Calibration Drift Detector）**：CUSUM 漂移检测，触发证书作废与域收缩；
> - **HCC（Human Cue Credibility）**：把人作为含噪标定源，在线估计并封顶其可信度；
> - **CDC（Calibration Domain Certificate）**：标定域 `D_cal` 与有效期 `τ_valid` 的 sound 证书；
> - **JCC（Joint Calibration Certificate）**：标定-动作-鲁棒性三联证书 `J⁺`，统一部署判据。
>
> IP 编号：IP-121~IP-126（共 6 个新增），并升级 IP-115/117/118/120 以接入标定维度。

## 2. 关键算法 伪代码

### IP-121 CCO

```python
def cco_slide(window, anchors, human_cues):
    graph = FactorGraph()
    for t, (z_prop, z_ext) in enumerate(window):
        graph.add(OdometryFactor(C[T_HR], z_prop, W_prop))
        graph.add(ExtrinsicFactor(C[T_HR], z_ext, W_ext))
        if t in human_cues:
            w_h = human_cues[t].weight * r_h
            graph.add(HumanCueFactor(C, human_cues[t], w_h))
    C_hat, Sigma_C = graph.optimize(robust_kernel='huber')
    O = normalized_min_eigenvalue(graph.information_matrix(C_hat))
    return C_hat, Sigma_C, O

def calibration_gate(O, Sigma_C, O_min, Sigma_budget):
    return O >= O_min and trace(Sigma_C) <= Sigma_budget
```

### IP-122 CAX

```python
def plan_excitation(xi, E_primitives, O_min, f_max, r_min, budget):
    chosen, O_cur, cost = [], O(xi), 0.0
    while O_cur < O_min and budget > 0:
        best, best_gain = None, 0.0
        for e in E_primitives:
            gain = (O(xi + chosen + [e]) - O_cur) / max(c_fl(e), 1e-6)
            if c_fl(e) <= f_max and r_h(e) >= r_min and gain > best_gain:
                best, best_gain = e, gain
        if best is None: break
        chosen.append(best); cost += c_fl(best)
        O_cur = O(xi + chosen); budget -= cost_of(best)
    return chosen, O_cur, cost, observer_shift(chosen)
```

### IP-123 CDD

```python
def drift_detect(stream, C_hat, Sigma_C, tau_d):
    S = innovation_covariance(C_hat, Sigma_C)
    cusum_pos = cusum_neg = 0.0
    for z_t in stream:
        r = mahalanobis(z_t - h(C_hat), S)
        cusum_pos = max(0, cusum_pos + r - k_drift)
        cusum_neg = max(0, cusum_neg + k_drift - r)
        if cusum_pos > h_drift or cusum_neg > h_drift:
            K.invalidate(); D_cal = shrink(D_cal, rho_shrink)
            return ('drift', t, request_recalibration())
    return ('ok', None, None)
```

def certify_domain(C_hat, Sigma_C, workspace_grid, residual_model,
                   delta_cal_budget):

def joint_certificate_v2(skill_seq, gamma_ce, delta_a_budget,
                         K, rho_min, h_cert):
    if not valid(K, query=skill_seq.workspace, t=now):
        return ('reject', 'calibration_void', K.explain())
    A_core = reduce(intersection, [s.alpha for s in skill_seq])
    delta_a = max_alignment_error(gamma_ce, A_core)
    if delta_a > delta_a_budget:
        return ('reject', 'action_mismatch', delta_a)
    h_min = kappa * sqrt(trace(P_pos @ K.Sigma_C @ P_pos.T)) + eps_reach
    if h_cert < h_min:
        return ('reject', 'safety_margin_fail', h_min - h_cert)
    rho_comp = compose_robustness_chain([s.rho for s in skill_seq], K_coupling)
    if min(rho_comp.values()) < rho_min:
        return ('reject', 'robustness_fail', rho_comp)
    return ('ok', JointCertV2(rho_comp, A_core, K, h_min, K.evidence))

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CCO | O(N·d³) | O(N·d²) | Fisher 可逆、鲁棒核有界 |
| CAX | O(|ℰ|²·T·d³) | O(|ℰ|·T) | `O` 次模 → 贪心 (1-1/e) |
| CDD | O(T·d²) | O(d²) | 检测延迟 ≤ `τ_d` |
| HCC | O(1)/次 | O(1) | 独立锚点、非循环 |
| CDC | O(|grid|·L·d) | O(|grid|) | Lipschitz 残差界 sound |
| JCC | O(d³+|S|·|A|) | O(d²+|A|) | 五条件合取、拒绝可解释 |

**定理（Calibration-Aware HRC Soundness）**
第 54 轮 (A22)–(A28) 成立；新增 **(A29)** `O(ξ)≥O_min`；**(A30)** 漂移检测延迟 `≤τ_d`；**(A31)** `r_h≤r_max<1` 且锚点独立。则
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - P(δ_a>Θ_a) - P(¬valid(K))
            - P(drift undetected within τ_d) - β_E
```
**证明（并集界）**：定义 126 的部署条件是五个失败事件 `E_ρ,E_a,E_K,E_drift,E_ev` 补集之交，故 `P_fail ≤ ΣP(E_i)`；各项分别由鲁棒性谱、动作对齐预算、标定证书、CDD 延迟界与证据误差 `β_E` 控制。取补即得。**要点**：`E_K`、`E_drift` 无法被第 54 轮的动作-鲁棒性证书吸收，故标定维度是必要新增，而非冗余项。

## 6. 本轮最大风险

**一句话**：共标定把人从“环境”提升为“可验证的标定源”，但它把系统最危险的失效从“标定不准”变成了“人机互适应后共同收敛到一个彼此一致、证书自洽、却与物理真值系统性错位”的**共谋式标定幻觉**；此时所有内部一致性检验都会通过，故必须以**独立物理锚点 + 保留式强制微激励 + 负迁移绊线**三重护栏，宁可在流畅性上付代价，也绝不把“人机互相同意”当作标定正确。
