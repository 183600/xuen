# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「动作空间」×「传感器融合」）

> 第 57 轮把证据门做成五类（EV-probe\*/visit/margin/xmodal/human），并用跨模态对账把"一致"升格为证据；但它有一个从未被写进假设的前提：**产生这些证据的动作集合是固定的，且足以看清目标属性**；**融合是有效的，即模态误差近似独立**。这两个前提各自裂开一道缝：**(a) 证据是动作条件的**——若探针动作从未激励判别维度（只做法向轻触、不做切向刮擦，就分不清"干地"与"薄冰"），跨模态一致只是"对不可观测量的一致"，是空洞证据；k 次同动作探针只在一个方向上累积信息，与判别维度正交的方向信息为零，而样本计数 k 却让人误以为覆盖了 k 个方向——"少样本"有时其实是"单方向重复"。**(b) 融合的独立性假设正是物理共谋的藏身处**——视觉与触觉被同一块透明冰面同时骗过时，加权融合会"既一致又错误"：分歧 D 很小，融合后新息/NEES 却爆表；第 57 轮的 D(r) 能抓"不一致"，抓不住"一致地错"。本轮两个灵感各补一条腿：**动作空间**让"探针"从执行动作变成"提问设计"，把可观测性从默认变为必须用激励挣得的**可观测性证书**；**传感器融合**让融合本身可审计，用**协方差交叉 + NEES 一致性监控**替代"独立即可信"。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据承诺"升级为 **"动作可激励、融合可一致、样本可有效计数的证据承诺"**——**你只能承诺你的动作空间已使之可观测、且你的融合已保持一致的量**。

核心矛盾：
- **H29（可观测性 vs 证据）**：证据门的所有证据类都假设"观测已包含判别信息"；但可观测性依赖激励。未激励的判别方向方差无穷，此时任何"跨模态一致"或"高置信后验"都是对不可观测量的自信。样本数 k 与信息量不是一回事：k_eff 可能远小于 k，而正交方向可能从未被覆盖。
- **H30（融合一致性 vs 相关误差）**：加权贝叶斯融合在误差相关时会系统性过度自信；"独立"被当作 EV-xmodal 的前提，却无人检验融合结果本身是否自洽。物理共谋 = 未知相关 = 融合一致但错误；需要的是一个**在未知相关下仍保守**的融合算子（CI）和一个**能看见"一致地错"**的体检指标（NEES）。
- **H31（动作空间设计 vs 安全/可逆）**：为获得可观测性需要"激励性动作"（剪切、刮擦、下压、局部升温），它们往往不可逆或破坏环境；动作空间不是给定菜单，而是要在"信息增益 / 可逆性 / 破坏量 / 节拍 / 能耗"间权衡的设计对象。扩大动作空间能提效，也能把系统推向"为看清而先弄坏"。

## 0. 直觉与动机

**灵感 1（动作空间 → 探针是提问，可观测性要用激励挣得）**
直觉：传感器不会"看见"它没被激励的自由度。要估计摩擦的各向异性，必须施加切向载荷；只做垂直轻触，无论融合多少模态，切向参数都停在先验上。把动作 a=(模式,方向,力,时长) 看作对属性 θ 的"提问"，每个动作携带一份 Fisher 信息 F_a(θ)；动作序列 σ 的可观测性 Gramian O_θ(σ)=Σ_i J_iᵀΣ_ε⁻¹J_i 决定了哪些判别方向被照亮。于是承诺前先问一句：**我的动作序列是否张满了临界属性空间？** 张不满，就不是"再融合一下"，而是"换一种问法"。

**灵感 2（传感器融合 → 融合要一致，不只独立）**
直觉：第 57 轮把"独立"当证据的入场券，但独立是**无法验证的强假设**；一旦两模态共享同一个物理偏差，它们会一起错、一起自信。融合的正确底线不是独立，而是**一致性**：协方差交叉（CI）在相关未知时仍给出保守覆盖；NEES/新息检验则像体检——若融合结果与各模态的自身不确定度矛盾，说明它们并非独立，融合在撒谎。于是把 XMC 的"分歧 D"升级为"分歧 D + 融合不一致 V"：**分歧是模态吵架，不一致是它们合谋**。

**灵感 3（动作空间 × 传感器融合 → 动作-观测联合设计）**
直觉：既然可观测性靠激励、融合一致性靠观测，那"选动作"与"做融合"就不该分开：应选**每单位风险带来最大可观测性增益**的动作，并在动作不可逆时把它升级为协商对象。动作的多样性本身就是信息：在可观测方向内，动作越多样，k_eff 越接近真实信息量；在正交方向，只有"新动作"才能开新维度。样本效率证书因此从"探了几次"变成"**有效信息量 k_eff + 覆盖了哪些方向**"。

**灵感 4（合流 → 证据门从五类到六类，证书从二元到三元）**
直觉：EV-probe\* 必须同时挂**元校准证书**（第 57 轮）与**可观测性证书**（本轮），缺一不可；新增 **EV-excite**——"存在一个动作序列使临界属性可观测且条件数良好"本身就是最强的一类证据，因为它是"证据的证据"；EV-xmodal 额外要求融合一致性 V≤θ_V，而不只是分歧 D≤θ_D。击穿安全需要：元先验错 ∧ OOD 漏检 ∧ 动作未激励 ∧ 融合不一致 ∧ 无裕度 ∧ 人也错——纵深从五层到六层。

**灵感 5（PCE++ → 动作承诺成为探-诺-演的第一公民）**
直觉：在第 57 轮 PCE+ 的每个检查点前插入**可观测性审计**：若临界方向 rank 不足，先做可逆激励动作；可逆动作耗尽仍不可观测，则绕行/降档/L2，而不是"再融合一次"。动作承诺 ac=(σ, 覆盖子空间, 可逆性, 破坏量) 与证据一起入证书。安全通道仍是那两条：**信念更准（补可观测性/一致性融合）**或**动作更保守（不可逆激励升级 L2、破坏预算、绕行）**——不新增升险路径。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（动作空间与可观测性证书 AOC）** 动作库 𝒜={a=(mode,dir,F,τ,dur)}；对区域临界属性 θ_crit（判别性参数：μ,k,F_bear、隐藏薄层厚度等），动作序列 σ=(a_1..a_n) 诱导观测 z_i=h(θ;a_i)+ε_i。局部可观测性 Gramian O_θ(σ)=Σ_i J_iᵀΣ_ε⁻¹J_i（J_i=∂h/∂θ|a_i），Fisher 信息 F_θ(σ)=Σ_a n_a F_a(θ)。**可观测性证书** J_obs(σ,θ\*)=(rank(O_θ), λ_min(O_θ), cond(O_θ), span_obs)：要求 rank(O_θ)≥dim(θ_crit) ∧ λ_min(O_θ)≥λ_0 ∧ cond(O_θ)≤κ_0。非线性下用经验 Gramian 与 profile-likelihood 曲率；**鲁棒版**要求 θ 落在不确定集 Θ_unc 内时证书仍成立（模型误差裕度）。

**定义 140（动作多样性与有效样本 ESS）** 标量化信息 i_a(θ)=1ᵀF_a(θ)1；有效样本 k_eff(σ)=(Σ_a n_a i_a)²/Σ_a n_a i_a²（Kish；同动作重复增益递减），并以信息矩阵有效秩 rank_eff(F_θ) 描述方向覆盖。**二元样本证书**：可观测方向内以 k_eff 计校准与样本效率（ECE_{k_eff}≤ε_meta(k_eff)，k\*(w\*)=min{k_eff:E|C|≤w\*}）；未被 span_obs 覆盖的 θ 方向显式标 `unobservable`（方差视为无穷，**禁止进入承诺**），不得用 k 冒充覆盖。

**定义 141（一致性融合 CFM 与 NEES 监控）** 相关未知时融合用协方差交叉：P_f⁻¹=Σ_m ω_m P_m⁻¹，Σω_m=1，ω 由最小化 tr(P_f)（或迹最优/自适应）求解，保证一致覆盖。一致性检验：两两新息 ε_{mm'}=(θ̂_m−θ̂_{m'})ᵀ(P_m+P_{m'})⁻¹(θ̂_m−θ̂_{m'})，及融合残差 NEES_k=(θ̂_f−θ̂_m)ᵀP_f⁻¹(θ̂_f−θ̂_m)；在一致假设下 ε~χ²(d)。**融合不一致度 V(r)=max(0, ε−χ²_{1−α_f}(d))**；V>θ_V ⇒ 判"融合不一致"（疑似相关/共谋）⇒ 加宽 P_f、降权相关模态、强制激励对账，并禁止该区域使用 EV-xmodal。XMC 的 D(r) 保留，报警条件升级为 (D>θ_D)∨(V>θ_V)。

**定义 142（动作-观测联合设计 AOJD）** 给定 θ_crit 与当前 AOC 缺口，选 a\*=argmax_a [ΔI_θ(a)/risk(a)] s.t. a∈𝒜_rev（可逆）∨ a 走 L2 协商；受力/力矩硬界 F_abs、破坏预算 B_destr、节拍预算约束。动作承诺 ac=(σ, span_obs, rev(a), Δ_destr(a)) 入证书；不可逆激励的破坏量估计须诚实（A44）。

**定义 143（激励证据门 AEG，证据门六类）** EV-probe\* 须同时满足 (i) ECE_{k_eff}≤ε_meta(k_eff) 且 (ii) J_obs 过（rank/λ_min/cond）；**新增 EV-excite** ⇔ ∃σ∈𝒜_rev：rank(O_θ(σ))≥dim(θ_crit) ∧ λ_min≥λ_0（激励是"证据的证据"）；EV-xmodal 额外要求 V(r)≤θ_V（不只 D≤θ_D）且仅限 L1；EV-visit/margin/human 承第 56–57 轮。**不可逆接触必要证据集必须含 EV-excite**；未覆盖 `unobservable` 方向的属性一律不得作为承诺依据。

**定义 144（动作承诺-探-诺-演 ACPCE / PCE++）** 每检查点：①元推断（承 57：ID→摊销后验 / OOD→共形带）；②**可观测性审计**：若 J_obs 缺 rank/λ_min ⇒ 用 AOJD 插入可逆激励 a\*（预算 k_exc）；可逆动作耗尽仍不可观测 ⇒ 绕行→降档→L2，**不得以融合代替激励**；③对账：D>θ_D 或 V>θ_V ⇒ 共识/激励探针；④承诺 ⇔ ∃g:R≤δ_f(g) ∧ 六类证据门过 ∧ 动作承诺覆盖 θ_crit；⑤否则 argmax_π[VOI_元悲观(π)−cost(π)]≥θ_voi；探尽→绕行→降档→L2（τ_int(auth)）或安全停。

## 2. 关键算法伪代码（完整版见产物区）

```python
def action_observability_gate(M, r, theta_crit, sigma, unc):   # IP-139: 鲁棒 AOC
    O = sum(fisher(a, theta_crit) for a in sigma)              # 动作诱导 Gramian
    ok = (rank(O) >= dim(theta_crit) and lmin(O) >= lambda_0
          and cond(O) <= kappa_0 and holds_for_all(O, unc))    # 不确定集内仍成立
    return J_obs(O, span(O), ok)

def effective_sample(sigma):                                   # IP-140: 有效样本
    i = [n * scalar_info(a) for a, n in counts(sigma)]
    return sum(i)**2 / sum(x*x for x in i) if i else 0.0

def consistent_fuse(beliefs, alpha_f):                         # IP-141: CI + NEES
    P_inv = sum(omega[m] * inv(beliefs[m].P) for m in beliefs)  # 未知相关下保守
    fused = Gaussian(solve(P_inv, sum(omega[m]*inv(P_m)*mu_m for m)),
                     inv(P_inv))
    V = max(0.0, nees(beliefs, fused) - chi2(1 - alpha_f, dim))
    return (widen(fused, V) if V > theta_V else fused), V

def joint_action_design(M, r, theta_crit, gap, budget):        # IP-142: AOJD
    cand = [a for a in M.A if reversibility(a) or budget.l2_open]
    return max(cand, key=lambda a: dI(a, theta_crit, gap) / risk(a),
               default=None)                                   # 无可逆激励 -> 绕行/L2
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| AOC | O(d_θ²·n)/序列；鲁棒版 O(\|Θ_unc\|·d_θ²) | O(d_θ²) | 证书在不确定集内成立（A41）、`unobservable` 显式 |
| ESS | O(n) | O(n) | k_eff 计数诚实、方向覆盖不混同 |
| CFM | O(\|ℳ\|·d³)/区域（CI 求 ω） | O(\|ℳ\|·d²) | 未知相关下保守、NEES 漏检 ≤δ_nees（A43） |
| AOJD | O(\|𝒜\|·d_θ) | O(\|𝒜\|) | 可逆优先、破坏预算硬界（A44） |
| AEG | O(\|σ\|) | O(\|σ\|) | 六类证据、EV-excite 必备、unobservable 禁承诺 |
| ACPCE | O(\|CP\|·(k_p+k_c+k_exc)·(C_VOI+d_θ)) | O(\|V\|+\|σ\|) | 可观测性审计先行、三预算终止 |

**正确性定理（Action-Observable Consistent Fusion Soundness, AOCFS 概要）**：在 A33–A40 上加 **(A41)** 可观测性证书诚实且鲁棒（模型误差裕度、漏检不可观测方向 ≤δ_obs）；**(A42)** 有效样本按 k_eff 计、未覆盖方向显式 `unobservable` 且不入承诺；**(A43)** CI 在未知相关下覆盖 ≥1−α_f、NEES 漏检 ≤δ_nees、EV-xmodal 仅在 V≤θ_V 且 L1 使用；**(A44)** 动作可逆性判定与破坏量估计诚实、不可逆激励走 L2、B_destr 硬界。则：(i) 承诺失效率 ≤ δ_f + ε_meta(k_eff) + δ_probe + ε_h + δ_obs + δ_nees·1[融合相关] + δ_xm·1[L1]；(ii) 交互单调性：动作空间机制只能经"信念更准（补可观测性/一致性融合）"或"动作更保守（不可逆激励升级 L2、破坏预算、绕行）"影响系统，不存在升险路径；(iii) ACPCE 在 k_probes+k_cons+k_exc 内终止于 {承诺, 绕行, L2 协商, 安全停}。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 可观测性证书在模型误差/非线性下乐观 | 高 | 鲁棒 AOC（不确定集内成立）+ profile-likelihood 曲率 + 证书裕度审计 |
| 激励动作不可逆/破坏环境 | 高 | 可逆动作优先；不可逆激励强制 L2；B_destr 硬界；动作承诺审计 |
| CI 过度保守 → 效率下降 | 中 | 自适应 ω/迹最优；用可观测性补信息而非一味加宽；退回独立融合需通过一致性回归 |

## 6. 本轮最大风险

**一句话**：本轮为了"看清"而赋予系统设计激励动作的权力，风险从第 57 轮的"坏先验普遍"变成"**为可观测性而先弄坏**"——可观测性证书若在模型误差/非线性下偏乐观，系统会自信地执行剪切、刮擦、下压等不可逆激励，把安全预算花在更激进的探测上；必须以可逆激励优先、不可逆激励强制 L2、破坏预算硬界、鲁棒可观测性证书与动作承诺审计五重护栏，宁可承认"这个方向我暂时看不见"而绕行，也不为取证而破坏环境。

# 第 58 轮产物 · 创新点清单 v34：ActionObs-Fusion（动作可观测性×一致性传感器融合，AOC×ESS×CFM×AOJD×AEG×ACPCE）

> 承接第 57 轮 IP-133~138（MFSL/XMC/PTM/MXI/FSE/PCE+）与第 56 轮 IP-127~132（SMM/PCE/BVK/ISE/TAF/MEC）。本轮把部署前提从"少样本可校准、跨模态可对账、个性化有界的证据承诺"升级为 **"动作可激励、融合可一致、样本可有效计数的证据承诺"**：可观测性不再默认成立，而要用激励动作挣得并证书化；跨模态融合不再以"独立"为信任底线，而以"未知相关下仍保守 + NEES 一致"为底线；样本效率不再数探针次数，而数有效信息量 k_eff 与方向覆盖。第 57 轮"一切判定器走隔离"在本轮推广为"**一切激励动作走动作承诺与破坏预算**"。

## 0. 核心 IP 设计

## 2. 关键算法伪代码

### IP-139 AOC（动作可观测性证书，鲁棒版）

```python
def aoc_certificate(theta_crit, sigma, unc, cfg):
    O = zeros(dim(theta_crit), dim(theta_crit))
    for a, n in counts(sigma):
        J = jacobian(h, theta_crit, a)                 # ∂h/∂θ|a
        O += n * J.T @ inv(noise_cov(a)) @ J
    span = observable_subspace(O, tol=cfg.tol)
    ok = (rank(O) >= dim(theta_crit)
          and lmin(O) >= cfg.lambda_0
          and cond(O) <= cfg.kappa_0
          and all(robust_holds(O, theta, unc) for theta in grid(unc)))
    return J_obs(O=O, span=span, rank=rank(O),
                 lmin=lmin(O), cond=cond(O), ok=ok)
```

### IP-140 ESS（动作多样性与有效样本）

```python
def sample_certificate(sigma, theta, meta):
    i = [(n, scalar_info(a, theta)) for a, n in counts(sigma)]  # i_a=1ᵀF_a1
    num = sum(n * ia for n, ia in i) ** 2
    den = sum(n * ia * ia for n, ia in i) or 1.0
    k_eff = num / den                                  # Kish 有效样本
    cover = rank_eff(sum(n * fisher(a, theta) for a, n in counts(sigma)))
    unobs = theta_dirs(theta) - cover                  # 未覆盖方向 -> unobservable
    return ESS(k_eff=k_eff, rank_eff=cover, unobservable=unobs,
               ece=meta.ece_decl_at(k_eff))
```

### IP-141 CFM（一致性融合 + NEES 监控）

```python
def consistent_fusion(beliefs, alpha_f, theta_V):
    omega = trace_optimal_ci(beliefs)                  # Σω=1, min tr(P_f)
    P_inv = sum(omega[m] * inv(beliefs[m].P) for m in beliefs)
    mu = solve(P_inv, sum(omega[m] * inv(beliefs[m].P) @ beliefs[m].mu
                          for m in beliefs))
    fused = Gaussian(mu, inv(P_inv))
    V = 0.0
    for m in beliefs:                                  # 融合残差 NEES
        e = (fused.mu - beliefs[m].mu).T @ inv(fused.P) @ (fused.mu - beliefs[m].mu)
        V = max(V, e - chi2(1 - alpha_f, dim(mu)))
    if V > theta_V:                                    # 一致地错 -> 疑似共谋
        fused = widen(fused, V)
        flag_inconsistent(beliefs)                     # 降权相关模态 + 禁 EV-xmodal
    return fused, V
```

### IP-142 AOJD（动作-观测联合设计 + 动作承诺）

```python
def joint_design(M, r, theta_crit, gap, budget):
    cand = [a for a in M.A
            if budget.destr_left >= est_destr(a) and
               (reversibility(a) or budget.l2_open)]
    if not cand:
        return None                                    # 无可逆激励 -> 绕行/L2
    a = max(cand, key=lambda a: dI(a, theta_crit, gap) / risk(a))
    ac = ActionCommit(sigma=[a], span=observable_subspace(fisher(a, theta_crit)),
                      rev=reversibility(a), destr=est_destr(a))
    budget.spend(a)
    return a, ac
```

### IP-143 AEG（激励证据门，证据门六类）

```python
def excitation_evidence_gate(c, M, persona, ood_reg, cfg):
    if c.ev == 'EV-probe*':
        ok = (c.inf.cls == 'ID' and c.inf.ece_k <= eps_meta(c.k_eff)) and \
             c.j_obs.ok and not c.j_ess.unobservable_hit
    elif c.ev == 'EV-excite':
        ok = c.j_obs.ok and c.action_commit.rev           # 可逆激励张满 θ_crit
    elif c.ev == 'EV-xmodal':
        ok = (c.level == 'L1' and c.indep_declared
              and D(c.region) <= theta_D and V(c.region) <= theta_V)
    elif c.ev == 'EV-human':
        ok = persona[c.op].auth >= 'A1' and \
             c.corrob >= quarantine_exit(persona[c.op].auth)
    elif c.ev in ('EV-visit', 'EV-margin'):
        ok = round57_checks(c, M)
    else:
        return ('reject', 'no_evidence_class', c)
    if not ok: return ('reject', 'evidence_insufficient', c)
    if c.irreversible and c.ev != 'EV-excite' and 'EV-excite' not in c.evidence_set:
        return ('reject', 'missing_excitation', c)        # 不可逆必备激励证据
    if c.irreversible and c.ev == 'EV-xmodal':
        return ('reject', 'xmodal_on_irreversible', c)
    return ('ok', c)

def map_evidence_certificate_a(sched, log, M, consent_log, auth_log, ood_reg):
    for c in contacts(sched):
        st = excitation_evidence_gate(c, M, persona_of(c), ood_reg, cfg)
        if st[0] != 'ok': return st
    if any(dir_ in J_ess.unobservable for J_ess in sched_ess(sched)):
        return ('reject', 'unobservable_critical_direction')
    if min(x.K_margin for x in sched) < budgets.theta_K: return ('reject', 'K_margin')
    if rho_sem(sched, M) < budgets.rho_min:           return ('reject', 'rho_sem')
    if not all(l2.resolved for l2 in consent_log):    return ('reject', 'consent_open')
    return ('ok', Ja(M.core, sched_actions(sched), J_obs_all, ESS_all,
                     V_all, action_commits, probe_log, consent_log,
                     meta_cal_log, xmodal_log, auth_log, ood_reg))
```

### IP-144 ACPCE（动作承诺-探-诺-演 / PCE++）

```python
def action_commit_probe_commit_evolve(x0, M, task, budget, consent, personas):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        inf = meta_few_shot_infer(M, cp.region, M.obs[cp.region], meta)
        M.b[cp.region] = inf.post if inf.cls == 'ID' else worst_in(inf.belt)
        theta_crit = critical_properties(cp)
        sigma = []                                     # ① 可观测性审计先行
        while not aoc_certificate(theta_crit, sigma, unc, cfg).ok \
              and budget.exc_left > 0:
            out = joint_design(M, cp.region, theta_crit, aoc_gap(sigma), budget)
            if out is None: break                      # 无可用激励 -> 降级
            a, ac = out
            M, _, D = xmodal_fuse(M, cp.region, execute_probe(a, cap=F_abs))
            sigma.append(a); cp.action_commits.append(ac)
            fused, V = consistent_fusion(M.b[cp.region], alpha_f, theta_V)
            M.b[cp.region] = fused
            if V > theta_V:                            # ② 一致地错 -> 激励对账
                p2 = most_disagreeing_modality_probe(M, cp.region)
                M, _, D = xmodal_fuse(M, cp.region, execute_probe(p2, cap=F_abs))
                sigma.append(p2)
            budget.spend(a)
        j_obs = aoc_certificate(theta_crit, sigma, unc, cfg)
        j_ess = sample_certificate(sigma, theta_crit, meta)
        if not j_obs.ok:                               # 不可观测 -> 不承诺
            alt = reroute(M, cp, risk_model)
            if alt and select_gait(schedule_risk(alt, M)) != 'halt':
                route = alt; continue
            return negotiate_or_stop(cp, M, sigma, None, consent,
                                     tau_int=tau_int(personas.active.auth))
        # ③ 常规探-诺-演（承第 57 轮），证据门换成 AEG
        while select_gait(schedule_risk(foothold_schedule(x0, cp, M), M)) == 'halt' \
              and budget.probes_left > 0:
            p = argmax(admissible_probes(cp, M, F_abs),
                       key=lambda q: voi_meta_pessimistic(q, M, inf) - cost(q))
            if voi_meta_pessimistic(p, M, inf) < theta_voi: break
            M, _, D = xmodal_fuse(M, cp.region, execute_probe(p, cap=F_abs))
            sigma.append(p); budget.spend(p)
        sigma_sched = foothold_schedule(x0, cp, M)
        g = select_gait(schedule_risk(sigma_sched, M))
        if excitation_evidence_gate(core_contact(cp), M, personas, ood_reg, cfg)[0] == 'ok':
            sched.append(commit(sigma_sched, g))
            log.append(tag_evidence_a(sigma, M, contact_level(cp))); continue
        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, M)) != 'halt': route = alt; continue
        return negotiate_or_stop(cp, M, sigma, None, consent,
                                 tau_int=tau_int(personas.active.auth))
    return sched, log, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| AOC | O(d_θ²·n)/序列；鲁棒 O(\|Θ_unc\|·d_θ²) | O(d_θ²) | 不确定集内成立、`unobservable` 显式（A41） |
| ESS | O(n) | O(n) | k_eff 诚实、方向覆盖不混同（A42） |
| CFM | O(\|ℳ\|·d³)/区域 | O(\|ℳ\|·d²) | 未知相关保守、NEES 漏检 ≤δ_nees（A43） |
| AOJD | O(\|𝒜\|·d_θ) | O(\|𝒜\|) | 可逆优先、破坏预算硬界（A44） |
| AEG | O(\|σ\|) | O(\|σ\|) | 六类证据、EV-excite 必备、unobservable 禁承诺 |
| ACPCE | O(\|CP\|·(k_p+k_c+k_exc)·(C_VOI+d_θ)) | O(\|V\|+\|σ\|) | 审计先行、三预算终止、四态完备 |

**正确性定理（Action-Observable Consistent Fusion Soundness, AOCFS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 可观测性证书诚实且鲁棒：J_obs 在模型不确定集 Θ_unc 内成立，漏检不可观测临界方向概率 ≤δ_obs；**(A42)** 有效样本按 k_eff 计，未覆盖方向显式 `unobservable` 且不得进入承诺；**(A43)** CI 在未知相关下覆盖 ≥1−α_f，NEES 漏检 ≤δ_nees，EV-xmodal 仅在 V≤θ_V 且 L1 使用；**(A44)** 可逆性判定与破坏量估计诚实，不可逆激励强制 L2，B_destr 为硬界。则：

1. **动作-融合承诺健全性**：P(fail) ≤ δ_f + ε_meta(k_eff) + δ_probe + ε_h(w_max) + δ_obs + δ_nees·1[融合相关] + δ_xm·1[L1]。
2. **交互单调性强化**：动作空间与一致性融合只能经 (a) 补可观测性/校准信念，或 (b) 更保守的动作参数（不可逆激励→L2、B_destr↓、绕行、带变宽）影响系统，不存在升险路径。
3. **终止性**：每检查点激励探针 ≤k_exc、共识探针 ≤k_cons，ACPCE 在 k_probes+k_cons+k_exc 内终止于 {承诺, 绕行, L2 协商, 安全停}。
4. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k_eff) + δ_probe + ε_h + δ_obs
                   + δ_nees·1[融合相关] + δ_xm·1[L1])
             − P(𝓜 陈旧未检出) − P(护盾回退失败)
             − P(动作可逆性误判 ∧ 破坏预算漏计) − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
```

关键：**可观测性给效率、动作承诺给安全**（不激励就不承诺）；**CI 给保守、NEES 给体检**（未知相关下仍不自信）；**k_eff 给样本效率、方向覆盖给诚实**（不把重复当覆盖）；三个新机制仍全部经"信念更准或动作更保守"两个安全通道起作用。

## 6. 本轮最大风险

**一句话**：本轮为了"看清"而赋予系统设计激励动作的权力，风险从第 57 轮的"坏先验普遍"变为"**为可观测性而先弄坏**"——可观测性证书若在模型误差/非线性下偏乐观，系统会自信地执行剪切、刮擦、下压等不可逆激励，把安全预算花在更激进的探测上；必须以可逆激励优先、不可逆激励强制 L2、破坏预算硬界、鲁棒可观测性证书与动作承诺审计五重护栏，宁可承认"这个方向我暂时看不见"而绕行，也不为取证而破坏环境。
