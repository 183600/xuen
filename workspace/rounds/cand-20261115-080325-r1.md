# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环第 3 轮；本轮灵感：「路径规划」×「状态机」）

> R69 教会系统「问」：把不确定性拆成 (U_ale, U_epi)，用流匹配策略显式表示多模态，用 MINT 按 VoI 选择「看 / 问 / 触」，并自陈最大风险——若模态权重不可信，系统会自信地追问一个幻影。
>
> 但 R69 的「问」有一个从未被审视的默认：**一次只问一步，且每一步只看「此刻哪个动作信息量最大」。** 这是**无记忆、单步贪心、按熵**的决策器，它带来四类结构性疾病：
> - **P1 幻影追逐（目标函数错了）**：熵版 VoI 会**奖励**幻影模态——幻觉模态抬高 H_mode，于是"看起来信息量很大、很值得问"。R69 的最大风险不是校准不够，而是**目标函数在奖励幻影**。
> - **P2 无记忆重复**：MINT 没有状态，不知道「这个我刚问过、答案是否定的」，可被反复追问 → 交互疲劳、社交 DoS。
> - **P3 短视**：单步贪心忽略**信息互补**——「先看一眼，才知道该问谁」。最优第一步常常不是即期 VoI 最高的那步。
> - **P4 无承诺**：模态在噪声下抖动，mode 与 λ 跟着抖（flip-flop / chattering）。
> - **P5 无终止**：预算只约束**单步**，不约束**整个 episode**；理论上可以无限追问。
>
> 本轮两个灵感正好对上：
> - **路径规划**：消歧不是「选一个动作」，而是**在信念空间里从『歧义』走到『可决 / 放弃』的一条路径**——起点、目标集 G={COMMIT, DEFER}、边成本、终点。这是随机最短路（SSP），不是贪心；若把信息动作的空间可达成本算进去，「看 / 触 / 问」还是一条**物理 vantage 巡游路线**（informative path planning）。
> - **状态机**：把探询写成**有限状态协议**（IDLE→OBSERVE→PROBE/ASK→CROSS_CHECK→COMMIT/DEFER/ESCALATE），带**转移守卫**、**不变量**、**活性**；从一段 if 变成可**离线模型检验、在线运行时监控**的对象；任何守卫不过即吸收到 DEFER（=R68 兜底）。
>
> 核心命题：**把交互决策从「单步熵贪心」换成「决策论非短视信念空间规划」，把交互执行从「无状态追问」换成「有限、可验证、保证终止的协议状态机」；只有能改变最优动作的歧义才值得交互（决策论 VoI），失败的消歧以负证据回流校准模态权重，整个探询路径必须在预算内到达 COMMIT 或 DEFER。** 命名 **COMPASS-RAS**（Cost-optimal Multimodal Probe planning And Supervisory State machine）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**这一问值不值得问、先问哪一句、问到什么时候必须停**」——追问不是一次冲动，而是一条有终点、可审计、保证会结束的路。

## 0. 直觉与动机

**灵感 1（路径规划 → 消歧是一条路，不是一个动作）**
直觉：R69 的 MINT 是「在岔口原地挑一个动作」。但真正解决歧义更像**规划一条路线**：先退一步看全局（vantage），再凑近看清，再问一句，再看对方是否自洽——每一步都改变「我接下来该做什么」，而不是各自独立地最大化熵减。这就是**信念空间里的随机最短路**：状态是后验 b，边是信息动作 g，边权是物理/社交/时间成本，目标集是「已可决」或「该放弃」。贪心是深度 1，规划是深度 H。更具体地，信息动作有**空间可达成本**（要看得清得走过去、要触到得靠近、要问人得面向对方），所以这条路径同时是**物理空间的 vantage 巡游**——这正是 informative path planning 的标准形态。R69 的 MINT 是它在 H=1、零位移、无记忆时的退化。

**灵感 2（状态机 → 探询必须是有限、可验证、会结束的协议）**
直觉：人类问路有一套隐式协议：先自己看，看不清再问，问完还要交叉验证，实在不行就说「我也不确定，先按最保守的走」。R69 把这一切压成一行 `choose_interaction(...)`，于是系统**不知道自己在哪个阶段、问过什么、该不该停**。状态机把它显式化：有限状态、带守卫的转移、每步不变量、以及**活性**（每个非终态必在 H_int 步内到达 COMMIT/DEFER）。好处是双重的：**可离线模型检验**（安全性与终止性成为定理而非祈祷），**可在线监控**（任何守卫违例立即强制 DEFER）。协议不是形式主义——它是把「问错比不问更危险」变成可执行的纪律。

**灵感 3（目标函数：熵是错的，决策损失才对）**
直觉：熵测「我对世界多不确定」，决策损失测「这份不确定会不会让我做错事」。**不确定性的价值不在其大小，而在其是否落在决策边界上**：若两个模态导向同一个最优动作（决策等价），追问它们对任务毫无价值，但在熵版里它们制造巨大的 H_mode。R70 的 VoI 改用 EVPI：只计**能改变最优动作**的那部分后验变化。于是幻影（若无决策影响）在目标函数层 VoI≡0——不是靠事后 MCG 门控去拦，而是它根本**不值得被规划进路径**。这是本轮最锋利的一刀。

**灵感 4（负证据回流 → 失败的消歧是一次测量）**
直觉：R69 的 MCG 需要「模态权重是否可信」的监督信号，却只能靠离线校准。但探询本身就在产标签：一个模态被**反复追问、用尽预算的判别性观测**仍不被独立证据支持，它就该被降权——这是**负证据**。把每次 DEFER 记入 DSR，在线修正 mode_head 的伪标签与校准曲线，等于让 R69 最脆弱的「模态分布可信度」获得一个**自监督闭环**。失败不是浪费，是把幻影钉进负样本。

**灵感 5（协议是新的攻击面 → 攻击者会利用你的纪律）**
直觉：一旦探询有固定协议，敌人就有**可预测的把手**：诱导你反复追问（社交 DoS，用你的礼貌耗尽预算）、伪造一致证据触发错误状态转移（state desync）、污染成本模型让规划器偏爱"看起来很值"的路径。对抗必须写进协议：同一问题无新证据不得重复（repeat guard）、成本模型禁止在线学习写、monitor 与状态机同构且违例即 DEFER。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（COMPASS-RAS 总览）** COMPASS-RAS = (ISP, ISM, VMon, DVI, DVP, FBL, HYS, DSR, FMA†, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；成本模型/损失模型同样禁止在线写）；
(ii) **有限终止**：任何交互 episode 在 H_int 步或预算耗尽内到达 COMMIT 或 DEFER；
(iii) **协议门控**：ISM 转移仅在守卫（定义 316）全部满足时发生，且证据须满足 R69 的 k-正交纪律；
(iv) **DEFER 吸收**：DEFER 等价于 R68 纯保守（λ=λ_floor(U_ale+U_epi)），并在本周期内吸收。

**定义 311（交互信念态）** b_t = (w_t ∈ Δ^{K̂−1}, κ_t, ℓ_t, q_t, E_t, τ_t)：模态后验权重、标定信任（来自 MCG 的 1−ECE）、预算账本（次数/位移/社交）、ISM 状态、已收证据集、episode 已用时长。b_t 是 ISP 的状态，也是 ISM 的输入。

**定义 312（决策论 VoI / EVPI）** 任务损失 ℓ(a,m)，决策损失 L(a|b)=Σ_m w_m ℓ(a,m)，a*(b)=argmin_a L(a|b)。定义
VoI_D(g) = L(a*(b)|b) − E_{y~p(·|g,b)}[ L(a*(b')|b') ],  b'=Bayes(b,y)。
只计**能改变最优动作**的信息。与 R69 熵版关系：熵版是忽略损失结构的代理；当模态决策等价时 VoI_D=0 而熵版>0，这正是幻影追问的机制。**系：决策无关的歧义永不进入规划，除非它先变得决策相关。**

**定义 313（信息路径规划 ISP / 随机最短路）** 目标集 G={COMMIT, DEFER}。规划
π* = argmin_π E[Σ_k c(g_k) | b_0, π]，s.t. 以概率 1 到达 G，且每步 risk(g_k) ≤ ε_int。
Bellman：V(b)=0 (b∈G)，V(b)=min_g [ c(g)+E_{b'~T(·|b,g)} V(b') ]。
深度上限 H_int，点基/栅格近似；启发式 h(b)=0（Dijkstra，精确）或 h(b)=d_G(b)·c_min（到终态最少转移数 × 最小边成本，**可采纳下界**）。**深度 1 即 R69 MINT**。

**定义 314（信息-空间耦合与 vantage 巡游）** 信息动作 g 有空间可达成本 d(s,s_g)：要看清需到 vantage、要触需接触、要问需面向人。c(g)=w_t·d(s,s_g)+w_s·social(g)+w_e·energy(g)。一条规划路径 (g_1..g_n) 对应一条物理 vantage 巡游；ISP 因而是 belief-space 与 physical-space 的联合最短路。R69 的零位移假设是 d≡0 的退化。

**定义 315（交互状态机 ISM）** Q={IDLE, OBSERVE, PROBE, ASK, CROSS_CHECK, COMMIT, DEFER, ESCALATE}。转移 δ⊆Q×Ev×B→Q，终态集 T={COMMIT, DEFER}（ESCALATE 为转交人类后的中间态，仍需回到 T）。每次 episode 从 IDLE 进入，首次动作必为 OBSERVE（不得一上来就问）。

**定义 316（转移守卫与证据纪律）** 守卫 γ(q→q') 合取：预算未越界 ∧ κ≥τ_κ（MCG 未越界）∧ 证据满足 k-正交一致（若目标是 COMMIT）∧ 反幻影前置（若目标是 ASK，须先有 OBSERVE 的证伪尝试，定义 319）∧ 未触发 poison 警报 ∧ 冷却满足（定义 317）。任一不满足 ⇒ 该转移不可用；无可用转移 ⇒ 强制 DEFER。

**定义 317（重复/冷却与疲劳账本 FBL）** repeat guard：同一 (semantic_hash(g_ask), m) 在 T_cool 内且**无新证据**时不得重复；账本 ℓ 单调不减；ℓ.spent+c(g)>c_max ⇒ 强制 DEFER。直接缓解 R69 的 E297 交互疲劳与协议 DoS。

**定义 318（滞回与承诺锁存 HYS）** 模态仅在 w_{m'} > w_{m_cur}+h（h>0 滞回带）时切换；未越带时保持 m_cur 与 λ 不变。与 R69「交互不改安全包络、控制连续」对齐，消除 flip-flop 与 λ 抖动。

**定义 319（证伪优先规划 DVP）** 每个候选模态 m 有可证伪观测集 F(m)（能使其后验下降的观测/回答）。规划优先选择「对**错误代价最高**的模态最具证伪力」的动作。若某模态在预算内**不可证伪**（无可用判别性观测）⇒ 标记 unfalsifiable 并从决策集中降权。**系：幻影在最坏 b 步内被移除或降权，而非被无限追问。**

**定义 320（负证据回流 DSR）** DEFER 且模态未定时，把「反复追问仍不被独立证据支持」的模态写入负证据集，更新 mode_head 伪标签与校准曲线。即 R69 的 MCG 获得在线可监督信号，把「模态权重不可信」转化为可学习的负样本。

**定义 321（运行时监控与模型检验 VMon）** 离线：对 ISM 用 LTL/CTL 检验 **safety**（¬single_source_commit ∧ budget≤c_max ∧ 未消解时 λ 单调不降）与 **liveness**（F^{≤H_int}(COMMIT∨DEFER)）。在线：monitor 与 ISM 同构，观测事件流；任何守卫违例 ⇒ 强制 DEFER 并写入 J_COMPASS。trace hash 可审计。

**定义 322（交互协议攻击模型 ℰ_protocol）** 诱导重复追问（社交 DoS）、伪造证据触发错误转移（state desync）、污染规划成本模型。并入 AIC：ℰ_COMPASS = ℰ_FLUID × ℰ_protocol。防御：repeat guard、证据纪律、成本/损失模型零在线写、monitor 违例即 DEFER。

**定义 323（两级退避的路径版）** 路径在预算内到达 COMMIT ⇒ λ=λ_floor(U_ale)（resolution bonus）。终止于 DEFER / monitor 违例 / 预算耗尽 ⇒ λ=λ_floor(U_ale+U_epi)。ESCALATE ⇒ λ=λ_floor(U_ale+U_epi) 且请求人类，人类回答作为外部证据仍受 k-正交纪律约束。**⇒ R69 是 H_int=1 的边界。**

```python
# IP-264 DVI：决策论 VoI（EVPI），只计能改变最优动作的歧义
def decision_voi(b, g, loss, T):
    a_star = argmin_a(expected_loss(a, b, loss))
    L0 = expected_loss(a_star, b, loss)
    L1 = 0.0
    for y, py in outcomes(b, g, T):              # 枚举/采样可能观测
        b2   = bayes_update(b, y)
        L1  += py * expected_loss(argmin_a(expected_loss(a, b2, loss)), b2, loss)
    return L0 - L1                                # 决策等价模态 → 恰为 0
```

```python
# IP-265 ISP：信念空间随机最短路（anytime；depth-1 严格等于 R69 MINT）
def plan_episode(b0, ism, budget, H=3):
    if b0.q in TERMINAL: return []
    best, best_v = [], myopic_value(b0)           # depth-1 解作为初始上界
    for depth in range(1, H + 1):
        for path in lattice_paths(b0, depth, ism, budget):
            v = path_cost(path, b0) + rollout_value(path[-1], ism)  # c(g)+E V
            if v < best_v: best, best_v = path, v
        if time_left() < EPS: break                # anytime：超时即返回当前最优
    return best

# IP-266 ISM：有限状态交互协议（守卫 + 不变量 + 活性）
TRANSITIONS = {
    'IDLE':        ['OBSERVE', 'DEFER'],
    'OBSERVE':     ['PROBE', 'ASK', 'CROSS_CHECK', 'COMMIT', 'DEFER'],
    'PROBE':       ['CROSS_CHECK', 'COMMIT', 'DEFER'],
    'ASK':         ['CROSS_CHECK', 'COMMIT', 'DEFER'],
    'CROSS_CHECK': ['COMMIT', 'DEFER', 'ESCALATE'],
    'ESCALATE':    ['COMMIT', 'DEFER'],
}
def ism_step(q, ev, b, budget, ledger):
    for q2 in TRANSITIONS[q]:
        if guard(q2, ev, b, budget, ledger): return q2
    return 'DEFER'                                 # 无守卫可用 → 吸收到 R68
```

```python
# IP-268 DVP：证伪优先——先规划能推翻「错误代价最高假设」的观测
def disconfirmation_first(b, loss, budget):
    m_bad = argmax_m(b.w[m] * loss_if_wrong(m))    # 错误代价 × 仍可能为真
    for g in info_candidates(m_bad):
        if budget.allow(g) and has_disconfirming_power(g, m_bad):
            return g
    mark_unfalsifiable(m_bad)                      # 预算内不可证伪 → 降权
    return None

# IP-269 FBL：重复/冷却与疲劳账本（终止性 + 反社交 DoS）
def ledger_allow(g, ledger):
    key = semantic_hash(g)
    if key in ledger.recent and not ledger.new_evidence_since(key):
        return False                               # 无新证据不重复问
    return ledger.spent + cost(g) <= ledger.c_max

# IP-270 HYS：带滞回的模态承诺，防 chattering
def commit_mode(m_cur, w, h=0.15):
    m_best = argmax(w)
    return m_best if w[m_best] > w[m_cur] + h else m_cur
```

## 3. 推导

**引理 19（决策论 VoI 结构性消除幻影）** 若模态 m 与其余模态**决策等价**（对任意其余模态后验，argmin_a L 不变），则 ∀g: VoI_D(g|m)=0；而熵版 VoI(g)=H(w)−E[H(w')]>0（除非 w 退化）。故 DVI 把幻影/决策无关歧义从**规划目标**中剔除，而非依赖事后 MCG 门控。系：R69 的最大风险在目标函数层被消除；MCG 只需处理「决策相关但权重不可信」的残余。

**引理 20（非短视规划的严格增益与代价）** 存在信念 b 使 depth-1 选 g_a 而 depth-2 选 g_b，且 g_b 的期望总成本更低（**信息互补**：g_b 即时 VoI 低，但解锁后续高判别力观测）。界：短视相对最优的期望成本遗憾 ≤ (H_int−1)·max_g c(g)·Pr[互补性>0]；当信息互补为零时两者相同。系：**R69 的贪心是 ISP 在 H=1 且无互补时的特例**。

**引理 21（ISM 终止性与疲劳上界）** 设每条边 c(g) ≥ c_min>0，预算 c_max，repeat guard 使同一 (g,m) 在无新证据时不可重复。则任何执行在 ≤ min(H_int, ⌊c_max/c_min⌋) 步内到达 T={COMMIT,DEFER} a.s.，且同一语义问题的重复次数 ≤ ⌈c_max/c_min⌉/(1+T_cool 窗口)。⇒ 无限追问与社交 DoS 被**结构性**禁止。

**定理 18（COMPASS 严格包含 FLUID 与 R68）** 在 A95–A99 下：(a) H_int=1、ISM 退化为 {IDLE→g→T}、c(g)≡social 时，COMPASS 的决策与 FLUID-RAS **逐指令相同**；(b) 一般情形期望风险 ≤ FLUID（DEFER 吸收到 R68；信息只减不增 U_epi；每步 risk≤ε_int 与 λ 单调只收紧）；(c) 当 VoI_D≡0（决策等价）、κ<τ_κ 或 monitor 违例时，两者逐指令相同。⇒ 新层是旧层的严格泛化，安全侧不让步，效率侧获非短视增益。

**定理 19（协议安全与活性）** 若 ISM 的 LTL 规格 G(¬single_source_commit ∧ budget≤c_max ∧ (U_epi>0 ⇒ λ 单调不降)) 与 F^{≤H_int}(COMMIT∨DEFER) 经模型检验成立，且在线 monitor 与 ISM 共享同一转移关系（事件不丢、语义一致），则离线结论对在线执行成立；任何守卫违例强制 DEFER，λ 单调退化为 R68。⇒ 交互安全从「设计者相信」变为「可验证」。

**定理 20（负证据校准收敛）** 在 A100（幻影模态不能被持续的多源一致证据支持；欺骗率有界 δ_p<1/2）下，DSR 对反复追问仍无独立证据的模态做贝叶斯负证据更新，其权重在 ≤ b 次后降到 τ_below 以下，ECE 单调不增到不动点；等价于给 R69 的 mode_head 增加一个无标签自监督项。系：R69 最大风险随交互次数**递减**，而非累积。

## 6. 本轮最大风险

**一句话**：COMPASS 的全部正确性押在「**ISM 的事件模型与世界一致、决策损失 ℓ 估得准**」这两条前提上——若观测事件丢失/延迟/语义漂移，离线模型检验证明的就是一个**不存在的协议**（"验证通过，但验证错了对象"），此时 monitor 的强制 DEFER 虽保守，却可能把系统冻结在永远 DEFER、永久退回 R68 并失去全部 resolution bonus；更隐蔽的是，若任务损失 ℓ(a,m) 或成本模型估错，规划会系统性地偏爱「看起来信息很多、实则决策无关」的路径——**规划得越精致，越可能问了个寂寞**。

**次级风险与缓解**：
1. **模型-现实失配（事件语义漂移）** → 在线 monitor 与离线同构性检查 + 定期一致性回归 + 失配即 DEFER；
2. **损失/成本模型错误** → 零在线学习写 + 保守损失上界 + E312/E315 审计；
3. **协议 DoS / state desync** → repeat guard + k-正交纪律 + 成本模型不可在线写 + 定义 322；
4. **非短视规划的超时** → anytime + depth-1 精确兜底 + 可采纳启发式；
5. **DEFER 陷阱（永远放弃）** → 记录 DEFER 原因分布，DSR 负证据只在「有判别性观测却仍不支持」时触发，避免把正常困难误判为幻影。

```python
# IP-264 DVI：决策论 VoI（EVPI）——决策等价模态恰为 0
def decision_voi(b, g, loss, T):
    a  = argmin_a(expected_loss(a, b, loss))
    L0 = expected_loss(a, b, loss); L1 = 0.0
    for y, py in outcomes(b, g, T):
        b2  = bayes_update(b, y)
        L1 += py * expected_loss(argmin_a(expected_loss(a, b2, loss)), b2, loss)
    return L0 - L1

# IP-265 ISP：信念空间随机最短路（anytime；depth-1 == R69 MINT）
def plan_episode(b0, ism, budget, H=3):
    if b0.q in TERMINAL: return []
    best, best_v = [], myopic_value(b0)
    for depth in range(1, H + 1):
        for path in lattice_paths(b0, depth, ism, budget):
            v = path_cost(path, b0) + rollout_value(path[-1], ism)   # c(g)+E V
            if v < best_v: best, best_v = path, v
        if time_left() < EPS: break                      # 超时 → 返回当前最优
    return best

# IP-266 ISM：有限状态协议（守卫 + 活性）
TRANSITIONS = {
  'IDLE':['OBSERVE','DEFER'], 'OBSERVE':['PROBE','ASK','CROSS_CHECK','COMMIT','DEFER'],
  'PROBE':['CROSS_CHECK','COMMIT','DEFER'], 'ASK':['CROSS_CHECK','COMMIT','DEFER'],
  'CROSS_CHECK':['COMMIT','DEFER','ESCALATE'], 'ESCALATE':['COMMIT','DEFER'],
}
def ism_step(q, ev, b, budget, ledger):
    for q2 in TRANSITIONS[q]:
        if guard(q2, ev, b, budget, ledger): return q2
    return 'DEFER'                                       # 守卫不过 → 吸收 R68

# IP-268 DVP：证伪优先（先推翻最贵的错误假设）
def disconfirmation_first(b, loss, budget):
    m_bad = argmax_m(b.w[m] * loss_if_wrong(m))
    for g in info_candidates(m_bad):
        if budget.allow(g) and has_disconfirming_power(g, m_bad): return g
    mark_unfalsifiable(m_bad); return None

# IP-269 FBL：repeat guard + 预算（禁止无限追问 / 社交 DoS）
def ledger_allow(g, ledger):
    key = semantic_hash(g)
    if key in ledger.recent and not ledger.new_evidence_since(key): return False
    return ledger.spent + cost(g) <= ledger.c_max

# IP-270 HYS：滞回承诺（防 chattering）
def commit_mode(m_cur, w, h=0.15):
    m_best = argmax(w)
    return m_best if w[m_best] > w[m_cur] + h else m_cur

# IP-275 主闭环（继承 FLUID，仅在「怎么问」处替换为「规划 + 协议」）

        if not M.fbl.allow(g): continue

    else:
```

## 4. 推导

**引理 19（决策论 VoI 结构性消除幻影）** 若模态 m 与其余模态决策等价（argmin_a L 不随其变化），则 ∀g: VoI_D(g|m)=0；而熵版 VoI>0（除非 w 退化）。故 DVI 把幻影从规划目标剔除，而非靠事后 MCG 门控。系：R69 最大风险在目标函数层被消除；MCG 只处理「决策相关但权重不可信」的残余。

**引理 20（非短视的严格增益）** 存在 b 使 depth-1 选 g_a 而 depth-2 选 g_b，且 g_b 期望总成本更低（信息互补：g_b 即时 VoI 低但解锁高判别力后续观测）。遗憾 ≤ (H_int−1)·max_g c(g)·Pr[互补性>0]；互补为零时两者相同。系：R69 贪心 = ISP 在 H=1 且无互补时的特例。

**引理 21（ISM 终止性与疲劳上界）** c(g)≥c_min>0、预算 c_max、repeat guard 生效时，任何执行 ≤ min(H_int, ⌊c_max/c_min⌋) 步到达 {COMMIT,DEFER} a.s.；同一语义问题重复次数被 T_cool 与 c_max 双重限制 ⇒ 无限追问与社交 DoS 被结构性禁止。

**定理 18（COMPASS 严格包含 FLUID 与 R68）** A95–A99 下：(a) H_int=1、ISM 退化、c(g)≡social 时决策与 FLUID 逐指令相同；(b) 一般情形期望风险 ≤ FLUID（DEFER 吸收 R68；信息只减不增 U_epi；每步 risk≤ε_int，λ 单调只收紧）；(c) VoI_D≡0 / κ<τ_κ / monitor 违例时逐指令相同。⇒ 严格泛化，安全不让步，效率获非短视增益。

**定理 19（协议安全与活性）** 若 ISM 满足 LTL `G(¬single_source_commit ∧ budget≤c_max ∧ (U_epi>0 ⇒ λ 单调不降))` 与 `F^{≤H_int}(COMMIT∨DEFER)`，且在线 monitor 与 ISM 共享同一转移关系，则离线结论对在线执行成立；任何守卫违例强制 DEFER、λ 单调退化到 R68。⇒ 交互安全从「相信」变为「可验证」。

**定理 20（负证据校准收敛）** A100（幻影不被持续多源一致证据支持，δ_p<1/2）下，DSR 对反复追问仍无独立证据的模态做贝叶斯负证据更新，权重 ≤ b 次后降到 τ_below 以下，ECE 单调不增到不动点。系：R69 最大风险随交互次数**递减**而非累积。

## 7. 本轮最大风险

**一句话**：COMPASS 的全部正确性押在「**ISM 事件模型与世界一致、决策损失 ℓ 估得准**」上——若观测事件丢失/延迟/语义漂移，离线模型检验证明的是一个**不存在的协议**（验证通过，但验证错了对象），monitor 的强制 DEFER 虽保守，却可能把系统冻结在永远 DEFER、永久退回 R68 并丧失全部 resolution bonus；更隐蔽的是，若 ℓ(a,m) 或成本模型估错，规划会系统性偏爱「看起来信息多、实则决策无关」的路径——**规划得越精致，越可能问了个寂寞**。

**次级风险与缓解**：模型-现实失配（同构性检查 + 一致性回归 + 失配即 DEFER）；损失/成本模型错误（零在线学习写 + 保守损失上界 + E312/E315）；协议 DoS/desync（repeat guard + k-正交 + 成本模型不可在线写 + 定义 322）；非短视规划超时（anytime + depth-1 精确兜底 + 可采纳启发式）；DEFER 陷阱（记录退避原因分布，DSR 仅在「有判别性观测却仍不支持」时触发，避免把正常困难误判为幻影）。
