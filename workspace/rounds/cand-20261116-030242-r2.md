# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「群体智能」×「闭环控制」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**闭环化 + 群体化 + 可退化**。两个灵感分别治理 v9 的两种债：**开环信任债**（β 与 Δ_dom 全靠离线标定/滑窗，恰在最危险时最不可靠）与**单机信息债**（20 帧滑窗天然滞后，且无同伴先验）。安全底线：任何群体/闭环模块失效 ⇒ 注入中立元，严格退回 v9 本地契约链，绝不行为漂移。

## 0. 直觉与动机

**灵感 1（群体智能 → 分布式见证，而非分布式决策）**
直觉：v9 的域偏移检测是"单机独白"——一台机器人用 20 帧窗口判断世界变了没有。群体智能的启发不是让机器人投票决定动作（那会把安全责任稀释到无人负责），而是让它们**互为见证**：每台机器人广播一个极小的"见证向量"（域偏移、SLAM 风险、前向模型残差、见证新鲜度），邻居用抗拜占庭的稳健聚合得到比本地窗口更早的分布跳变告警。核心创新：**群体见证总线（SwarmWitnessBus, SWB）**：只共享证据，不共享控制权；证据带时间戳与新鲜度衰减，网络分区时自动退化为本地证据。安全关键动作仍由本地证书与本地硬检查一票否决。

**灵感 2（闭环控制 → 把证书余量变成被调变量）**
直觉：v9 里 β 是 E554 标定出的常数、K_eff 是 Δ_dom 的开环函数；这是"标定—执行"开环链，误差一旦超界只能事后中止。闭环控制的启发：把"预测残差"当作被控量的测量，把 β_t、K_eff(t) 当作控制量，构造**残差反馈的证书调节器**。核心创新：**闭环证书调节器（ClosedLoopCertificateGovernor, CLCG）**：以 e_t=‖观测−预测‖ 为反馈，PI+抗积分饱和地调 β_t，并用"余量—块长"单调映射调 K_eff；只在块边界改 K_eff 并加驻留时间，保证不引入抖振。其稳定性用 ISS/Lyapunov 势函数刻画。

**灵感 3（两者相乘 → 把"最危险时刻"提前）**
v9 最大风险是：Δ_dom 的 20 帧滑窗滞后于真实跳变，导致证书已失效的块仍取大 K。SWB 用 m 个独立见证把检测延迟从"单机窗口"降到"最早见证"；CLCG 再把这份提前量转成 β 抬升与 K_eff 收缩。二者不是并列模块，而是一条**感知—反馈—执行**的闭环：群体提前看见，闭环安全减速。核心创新：**群体见证闭环证书（Swarm-Witnessed Closed-loop Certificates）**；并保留"见证不可信时只信自己"的降级路径。

## 1. 研究问题（轮次升级版）

- **Q1（群体见证可靠性）**：在通信延迟 τ_comm、丢包与 f<n/3 拜占庭见证下，稳健聚合能否保证"群体告警不晚于本地告警"？当相关失效（同一种新地面材质、同一束强光同时影响所有机器人）时，群体是否反而放大虚假安全感？
- **Q2（闭环证书稳定性）**：残差反馈调 β_t/K_eff 的闭环是否 ISS 稳定？抗积分饱和、块边界驻留与中立元注入能否共同排除"证书—块长"极限环？
- **Q3（群体契约安全边界）**：把 MW 契约表扩展为联邦契约表后，quorum 否决、分区降级与本地一票否决如何共同保证"群体失效不降低单机安全等级"？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 群体见证律（Swarm-Witnessed Evidence, SWB）**
每机广播见证 w_i=(Δ_dom^i, risk_SLAM^i, β̂^i, novelty^i, τ_i, conf_i, sig_i)，**不广播动作、轨迹或原始感知**；邻居按新鲜度加权、截尾中位数/上分位聚合得到 Δ_dom^sw、risk^sw、β^sw。群体只提供**提前告警与先验**，安全否决权始终在本地。网络分区/见证不足（<2f+1）⇒ 只用本地证据，等价 v9。

**P14 闭环证书律（Closed-loop Certificate Governor, CLCG）**
以预测残差 e_t 为反馈，调证书余量 β_t 与有效块长 K_eff：
```
I_t = clip(I_{t-1} + max(0, e_{t-1} − β*), 0, I_max)              # 只累积越界
β_t = clip(β_{t-1} + η(e_{t-1} − β_{t-1}) + γI_t
           + ζ(β^sw − β_{t-1}), β_min, β_max)
K_eff(t) = max(1, ⌊K_max·(1−Δ_dom^sw/τ_dom)·(1−β_t/β_max)⌋)      # 仅块边界可变
```
抗积分饱和：β_t 触界、K_eff=1 或 Δ_dom^sw≥τ_dom 时冻结 I_t；K_eff 允许快速收缩、缓慢恢复（需连续 T_up 个块证书健康），并设驻留时间 T_dwell 防抖。

**P15 群体契约否决律（Federated Veto, FCT）**
契约表跨机复制；安全关键契约行（M₀ 硬检查、SpatialCert、FaultCert、AC 守卫）采用"**本地一票否决 + 群体 quorum 仅能提前激活、不能延后停用**"的非对称权限；分区时本地表优先。任何远程契约不可达 ⇒ 该行注入中立元。

## 3. 与基线的接口（如何退化）

- SWB 失效 / 分区 / 见证不足 ⇒ Δ_dom^sw←Δ_dom^local、risk^sw←risk_local，等价 v9；
- CLCG 失效 ⇒ β_t←β_E554 常数、K_eff←定义 539 开环式，等价 v9；
- FCT 失效 ⇒ 本地 v9 契约表，等价 v9 MW；
- 群体蒸馏失效 ⇒ 通道归因冻结、全部通道常开，等价 v9 ID；
- 上述全失效 ⇒ 完整退回 MetricVoiceGauge-ACMD v9，再退回 v8/v7/v6。

## 4. 预期贡献

1. **群体见证总线**：把群体智能从"分布式决策"改写为"分布式证据"，用稳健聚合 + 新鲜度衰减 + 拜占庭界，在不稀释安全责任的前提下缩短域偏移检测延迟；
2. **闭环证书调节器**：把 v9 的常数余量升级为残差反馈的被调量，给出 ISS 稳定性与无极限环条件，直接对冲 v9 的"最危险时刻证书最不可靠"；
3. **联邦契约与群体蒸馏**：退化链从单机配置升级为可分区、可否决、可归因的群体配置，且任一远程组件失效都严格退回本地 v9；
4. **闭环—分块—群体三耦合实验**：E571–E590 覆盖见证时延、拜占庭、分区、闭环阶跃、驻留防抖、群体归因与端到端多机任务。

## 5. 本轮最大风险

**一句话**：群体见证的收益建立在"同伴的失效与我的失效不同步"这一独立性假设上，而真实分布跳变（同一种新地面材质、同一束强光）会同时污染所有机器人——此时群体聚合既不能提前，还可能用"多数一致"放大虚假的安全感，即「群体在最需要独立见证时最同质」。

## 1. 符号体系增量（定义 540–549）

| 符号 | 含义 |
|---|---|
| w_i(t) | 见证向量：Δ_dom、risk_SLAM、β̂、novelty、时间戳、可信度、签名 |
| N_i(t) | 机器人 i 在时刻 t 的可达且新鲜邻居集合 |
| a_j(t)=t−τ_j | 见证年龄；新鲜度权重 ω_j=conf_j·exp(−λa_j) |
| A_trim(·) | 截尾稳健聚合算子（中位数/上分位，trim=f/n） |
| Δ_dom^sw, risk^sw, β^sw | 群体聚合的域偏移、SLAM 风险、证书余量 |
| e_t | 预测残差：观测指标与块证书预测的最大归一化偏差 |
| z_t=(β_t, I_t) | CLCG 状态：证书余量、越界积分 |
| V_t | 闭环势函数（跟踪误差² + 安全余量亏欠² + 群偏差异²） |
| T_dwell, T_up | K_eff 驻留块数、恢复前需连续健康块数 |
| r_m=(κ_m,owner,replicas,q_m,safety) | 联邦契约行；safety 行本地一票否决 |
| c_{i←j} | 机器人 i 对同伴通道 j 的边际贡献 EMA |
| m_eff | 群体有效独立见证数（相关失效下 m_eff<m） |

**新增定义 540（见证向量 WitnessVector）** 机器人 i 在 5Hz 节拍广播
```
w_i(t) = (Δ_dom^i, risk_SLAM^i, β̂^i, novelty^i, τ_i, conf_i, sig_i)
```
其中 novelty∈[0,1] 为对局部场景记忆的粗粒度新颖度（只发标量，不发地图）；τ_i 为单调时钟；conf_i∈[0,1] 为该机历史"先报后验"一致度；sig_i 为轻量签名。禁止广播动作、轨迹、图像与原始点云——群体只共享证据。

**新增定义 541（稳健群体聚合 RobustWitnessAggregate）** 邻居集 N_i(t)={j: 可达 ∧ a_j(t)≤T_stale}。若 |N_i|<n_min=2f+1，返回 ⊥（触发 Level-1）。否则按权重 ω_j=conf_j·exp(−λa_j) 做截尾聚合：
```
Δ_dom^sw = A_trim^{med}({Δ_dom^j}_{j∈N_i}, trim=⌊f/n⌋)
risk^sw   = A_trim^{q90}({risk^j}_{j∈N_i}, trim=⌊f/n⌋)     # 安全侧取高侧
β^sw      = A_trim^{q90}({β̂^j}_{j∈N_i}, trim=⌊f/n⌋)
```
Δ_dom 用中位数压虚假告警；risk 与 β 用上分位，保证恶意低报不能掩盖风险（高报只会保守减速，可接受）。

**新增定义 542（证书残差 CertificateResidual）** 仅在"观测指标与预测指标同时可算"的块边界/每 10 周期采样：
```
e_t = max_{m∈{clearance,effort,grasp}} |m_obs − m̂_pred| / Δm_scale^m
```
e_t 是闭环的测量输入；无观测时保持 e_{t-1} 并置 stale 标志，CLCG 进入保守冻结。

**新增定义 543（闭环证书调节器 CLCG）** 状态 z_t=(β_t,I_t)，参数 η,γ,ζ∈(0,1)，η+ζ<1。在块边界执行：
```
I_t = clip(I_{t-1} + max(0, e_{t-1} − β*), 0, I_max)
β_t = clip(β_{t-1} + η(e_{t-1} − β_{t-1}) + γI_t
           + ζ(β^sw − β_{t-1}), β_min, β_max)
K_eff(t) = 1                                          若 ¬U_t^sw
         = max(1, ⌊K_max·(1−min(1,Δ_dom^sw/τ_dom))
                       ·(1−min(1,β_t/β_max))⌋)        否则
```
**抗积分饱和**：β_t∈{β_min,β_max}、K_eff=1、Δ_dom^sw≥τ_dom 或 e_t stale 时，本周期不累加 I_t。**方向不对称**：K_eff 允许立即收缩；增大需连续 T_up 个块满足证书健康 h=1 且 β_t 未触界。**驻留**：K_eff 两次改变间隔 ≥T_dwell 个块。

**新增定义 544（闭环势函数 ClosedLoopPotential）**
```
V_t = (β_t − β*)² + λ₁·(max(0, d_safe − margin_t^min))² + λ₂·(max(0, Δ_dom^sw − τ_dom))²
```
其中 margin_t^min 为块内最小间隙余量。若 V_{t+1} ≤ (1−α)V_t + σ(‖e_t−β_t‖, τ_comm) 对某 α∈(0,1) 与 class-K 函数 σ 成立，则称闭环 **ISS-证书稳定**。

**新增定义 545（联邦契约行 FederatedContractRow）**
```
r_m = (κ_m, owner, replicas, q_m, safety_m)
```
κ_m 继承 v9 契约；replicas 为副本集合；q_m 为激活 quorum；safety_m=true 的行（M₀、SpatialCert、FaultCert、AC 守卫、MW 自身）采用**非对称权限**：任一持有者可立即停用（本地一票否决），但激活/放宽必须 quorum 同意。安全行的写权限只读复制，版本号单调。

**新增定义 546（quorum 退化 QuorumDegradation）** 可选模块 m 的激活需 ≥q_m 个新鲜副本一致；停用/安全停驻**不需要** quorum，本地立即执行。分区检测（心跳超时 T_part）⇒ 整表切回本地 v9 契约表；恢复后先做版本对账，冲突时以更保守（更短 D_m、更小 K、更大 β）者为准。

**新增定义 547（群体通道归因 SwarmChannelAttribution）** 对同伴 j 的非安全见证通道，定义边际贡献
```
c_{i←j} ← clip(0.9·c_{i←j} + 0.1·norm(J_with(j) − J_base), 0, 1)
```
J 继承 ID 的块级任务进展−安全罚。c_{i←j}<τ_off 持续 H_off 回合 ⇒ **静音**该通道的非安全字段（≠删除），c≥τ_on 恢复。安全字段（risk_SLAM、Δ_dom 的告警位）永不静音。

**新增定义 548（见证可信度与拜占庭界 WitnessTrust）** 对见证 j 维护
```
conf_j ← clip(1 − EMA[1(w_j 的预测与 i 的后续观测矛盾)], 0, 1)
```
聚合仅使用 conf_j≥c_min 的见证；拜占庭假设 f<n/3（即 |N_i|≥3f+1 时稳健）。签名验证失败、时间戳回退或 conf 跌破 c_min 的见证直接丢弃并记审计事件。

**新增定义 549（群体闭环证书等级 SwarmCertificateLevel）** 由 (SWB 可用, CLCG 可用, FCT 可用, SS 可用) ∈ {0,1}⁴ 映射到 Level-0..5：
```
L = 0                    若四者全 1
  = 1                    若 SWB=0（其余任意）
  = 2                    若 SWB=1 ∧ CLCG=0
  = 3                    若 SWB=CLCG=1 ∧ FCT=0
  = 4                    若前三者=1 ∧ SS=0
  = 5                    其余（全失效回 v9 → v8…）
```
等级只降不升需连续 T_recover 健康周期；升级必须显式日志，防"幽灵恢复"。

## 2. 形式化定义（要点与升级）

**定义 493（六层指标层级）** 继承 v9：M=(M₀,M₁,M₂,M₃,M_dom,M_SLAM) 不变。
**定义 495/524（MetaWeight/情感，5 维）** 继承 v9 不变。
**定义 521（DA-OTL）** 继承 v9 不变；τᵢ(t) 复核入口增加群体证据。
**升级定义 496（软证书，v10）**
```
δ_trigger = {σ < τ_safe ∧ γ_grasp valid ∧ Δ_dom^sw < τ_dom
             ∧ risk^sw < τ_SLAM ∧ Ĉ_t valid(e_t ≤ β_t)}
```
块证书失效、单步条件失效、群体告警任一触发 M₀ 硬检查；不存在"块内软通过、硬失"的空洞（引理 87 + v9 引理 82）。
**升级定义 531（软硬约束衔接）** 中块守卫输入增加 (e_t, β_t, Δ_dom^sw)；违规立即切最近中止点 p* 或安全停驻，不等块边界。
**升级定义 533/539（块证书/有效块长）** β 由 CLCG 给出 β_t（保留 v9 常数作为 Level-2 默认）；K_eff 采用定义 543 的闭环式，并在块生成时锁定，块内不可变。

# IP-357 SwarmWitnessBus：群体见证总线（只共享证据，不共享控制权）
@dataclass
class Witness:
    robot_id: str
    delta_dom: float; risk_slam: float; beta_hat: float
    novelty: float; stamp: float; conf: float; sig: bytes

class SwarmWitnessBus:
    def __init__(self, n_min=3, f_max=None, T_stale=0.5, lam=2.0,
                 c_min=0.3, T_part=1.0):
        self.inbox, self.n_min, self.f_max = {}, n_min, f_max
        self.T_stale, self.lam, self.c_min = T_stale, lam, c_min
        self.T_part = T_part

    def publish(self, w):
        if verify(w.sig):                      # 签名失败直接丢弃
            self.inbox[w.robot_id] = w

    def aggregate(self, now):
        fresh = [w for w in self.inbox.values()
                 if now - w.stamp <= self.T_stale and w.conf >= self.c_min]
        if len(fresh) < self.n_min:            # 分区/见证不足 → Level-1
            return None
        fresh.sort(key=lambda w: w.delta_dom)
        f = self.f_max if self.f_max is not None else (len(fresh) - 1) // 3
        f = min(f, (len(fresh) - 1) // 2)
        core = fresh[f:len(fresh) - f]         # 截尾：去极值
        wts = [w.conf * math.exp(-self.lam * (now - w.stamp)) for w in core]
        return SwarmEvidence(
            delta_dom=w_median([w.delta_dom for w in core], wts),
            risk_slam=w_quantile([w.risk_slam for w in core], wts, 0.90),
            beta_hat=w_quantile([w.beta_hat for w in core], wts, 0.90),
            n=len(core), fresh=min(wts))


# IP-358 ClosedLoopCertificateGovernor：闭环证书调节器
class ClosedLoopCertificateGovernor:
    def __init__(self, beta0, tau_dom, eta=0.2, gamma=0.02, zeta=0.1,
                 beta_star=0.02, beta_min=0.005, beta_max=0.08, I_max=0.05,
                 K_max=10, T_dwell=3, T_up=5):
        self.beta, self.I, self.e_prev = beta0, 0.0, beta0
        self.eta, self.gamma, self.zeta = eta, gamma, zeta
        self.beta_star, self.beta_min, self.beta_max = beta_star, beta_min, beta_max
        self.I_max, self.K_max, self.tau_dom = I_max, K_max, tau_dom
        self.K, self.T_dwell, self.T_up = 1, T_dwell, T_up
        self.blocks_since_change, self.healthy_run = 0, 0

    def observe(self, e, stale=False):
        self.e_prev, self.stale = e, stale

    def _freeze_integral(self, beta_next, K_next, ev):
        return (self.stale or K_next == 1
                or beta_next <= self.beta_min or beta_next >= self.beta_max
                or (ev is not None and ev.delta_dom >= self.tau_dom))

    def step_at_block_boundary(self, ev, trust_ok):
        e = self.e_prev
        I_next = self.I if self._freeze_integral(self.beta, self.K, ev) else \
                 min(self.I_max, self.I + max(0.0, e - self.beta_star))
        beta_next = clip(self.beta
                         + self.eta * (e - self.beta)
                         + self.gamma * I_next
                         + self.zeta * ((ev.beta_hat if ev else self.beta) - self.beta),
                         self.beta_min, self.beta_max)
        if trust_ok:
            d = ev.delta_dom if ev else 0.0
            K_next = max(1, int(self.K_max
                                * (1 - min(1.0, d / self.tau_dom))
                                * (1 - min(1.0, beta_next / self.beta_max))))
        else:
            K_next = 1
        if self.blocks_since_change < self.T_dwell:      # 驻留
            K_next = self.K
        if K_next > self.K and self.healthy_run < self.T_up:   # 慢恢复
            K_next = self.K
        self.blocks_since_change = 0 if K_next != self.K else self.blocks_since_change + 1
        self.healthy_run = self.healthy_run + 1 if self.cert_healthy() else 0
        self.beta, self.I, self.K = beta_next, I_next, K_next
        return self.beta, self.K

    def cert_healthy(self):
        return (not self.stale) and self.e_prev <= self.beta


# IP-359 FederatedContractTable：联邦契约表（扩展 v9 MW）
@dataclass
class FederatedContract:
    base: Contract
    owner: str; replicas: set; quorum: int; safety: bool

class FederatedContractTable:
    def __init__(self, rows, local_id, T_part=1.0):
        self.rows, self.local_id, self.T_part = rows, local_id, T_part
        self.partitioned = False

    def activate(self, name, votes):
        row = self.rows[name]
        if row.safety:                                  # 安全行：全体副本一致
            return all(votes.get(r, False) for r in row.replicas)
        return sum(votes.get(r, False) for r in row.replicas) >= row.quorum

    def deactivate(self, name, local_stop=False):
        if local_stop or self.rows[name].safety:
            return True                                 # 本地立即停用，无需 quorum
        return False

    def on_partition(self):
        self.partitioned = True
        self.rows = {k: FederatedContract(v.base, v.owner,
                                          {self.local_id}, 1, v.safety)
                     for k, v in self.rows.items()}     # 退回本地 v9 契约表编码


# IP-360 SwarmDistiller：群体蒸馏器（扩展 v9 ID）
class SwarmDistiller(InnovationDistiller):
    def __init__(self, bus, tau_on=0.03, tau_off=0.01, H_off=3, **kw):
        super().__init__(mw=None, tau_on=tau_on, tau_off=tau_off, H_off=H_off, **kw)
        self.bus, self.ema_peer = bus, {}

    def attribute_channel(self, peer, J_with, J_base):
        d = max(0.0, normalize(J_with - J_base))
        self.ema_peer[peer] = 0.9 * self.ema_peer.get(peer, d) + 0.1 * d

    def step(self, cycle_idx, ctx):
        for peer, c in self.ema_peer.items():
            if peer in ctx.safety_peers:
                continue                                # 安全见证永不静音
            if c < self.tau_off:
                self.bus.mute_nonsafety(peer)           # 仅静音非安全字段
            elif c >= self.tau_on:
                self.bus.unmute(peer)


# 主闭环集成：MetricVoiceGauge-SWCC
def metricvoicegauge_round_10(M, s, obs, peers, ...):

    local = local_perception_cycle(M, obs)

    if current_chunk is None or current_chunk.exhausted:

        current_chunk = chunker.generate_chunk(

            trust_ok=(delta_sw < M.tau_dom and risk_sw < M.tau_slam),
            beta_override=beta, K_override=K)
    # ---- 4) 50Hz 中块守卫（继承 v9，附加群体提前告警）----
    verdict, k_next = chunker.midchunk_guard(current_chunk, k_exec, obs, swarm=ev)

    # ---- 5) 观测到的指标反哺闭环（定义 542）----
    if obs.metrics_available:

    # ---- 6) v8/v9 继承路径 + 联邦契约 ----

    swarm_distiller.step(cycle_idx, ctx)

## 4. 推导

**引理 87（残差反馈的证书覆盖）** 设真实残差序列满足 |e_t−e_{t−1}|≤L_e，β*≥0，η+ζ<1，且 I_t 有界。则闭环跟踪误差满足
```
|β_t − e_t| ≤ (ζ‖β^sw−e‖∞ + γI_max + L_e) / (η+ζ)  +  (1−η−ζ)^t·|β_0−e_0|
```
特别地，若 β_0≥e_0 且 (ζ‖β^sw−e‖∞+γI_max+L_e)/(η+ζ) ≤ β*，则 β_t≥e_t 对所有 t 成立，块证书始终保守有效。证明：把 β_t 更新式减去 e_t，整理 β_t−e_t=(1−η−ζ)(β_{t−1}−e_{t−1})+ζ(β^sw−e_t)+γI_t−(e_t−e_{t−1})，取绝对值并用三角不等式与有界性即得；β_t≥e_t 代入定义 533 即得 g_min−β_t≤g_min−e_t≤真实最坏间隙。∎

**引理 88（群体最早见证时延）** 设各机对同一跳变的检测时刻 T_j 条件独立、同分布、CDF 为 F，则 T_sw=min_j T_j 满足
```
P(T_sw > t) = (1−F(t))^m ≤ (1−F(t))^m_eff
```
独立时 m_eff=m，故 P(T_sw≤t) ≥ 1−(1−F(t))^m ≥ P(T_local≤t)：群体检测以概率意义不晚于任何单机。若存在共同冲击使相关系数为 ρ，则有效样本量 m_eff=m/(1+(m−1)ρ)（对等相关的均值方差展开），ρ→1 ⇒ m_eff→1，群体收益消失。证明：独立情形由最小值 CDF 直接得到；相关情形对标准化见证做等相关分解，方差 σ²(1+(m−1)ρ)/m，反解有效样本量即得。∎

**引理 89（拜占庭稳健聚合）** 设 |N_i|=n≥3f+1，至多 f 个恶意见证。截尾中位数去除两端各 f 个值后，剩余集合中诚实见证不少于 n−2f≥f+1，严格多于任意一侧恶意值，故 Δ_dom^sw 落在诚实值区间内；risk^sw 取 q90 且 trim=f/n，恶意低报至多压低一个分位，不能把真实高风险藏到阈值以下。恶意高报只会使系统更保守（β 增大、K 减小），不破坏安全性。∎

**引理 90（群体/闭环退化与 v9 逐位等价）** 对 Level-1..4 逐一注入中立元：SWB 不可用 ⇒ Δ_dom^sw=Δ_dom^local、risk^sw=risk_local，与 v9 定义 539 输入逐位一致；CLCG 不可用 ⇒ β_t=β_E554、K_eff 取 v9 开环式；FCT 不可用 ⇒ 契约表替换为本地 v9 表；SwarmDistiller 不可用 ⇒ 全通道常开。中立元不改变下游端口取值集合，故可观测行为与 v9 对应退化级等价。∎

**引理 91（群体蒸馏安全不变式）** 群体蒸馏仅能静音**非安全**见证字段；risk_SLAM 与 Δ_dom 告警位在定义 547 中被硬编码为不可静音，φ^elig=false 的安全通道集合与 v9 引理 84 相同。故任意蒸馏状态下，安全关键输入 ∈ v9 退化格点，安全性由 v9 引理 80–84 传递成立。∎

**引理 92（无 Zeno / 驻留与预算守恒）** K_eff 只在块边界改变且相邻改变间隔 ≥T_dwell 个块；β_t 连续有界。故单位时间内 K_eff 切换次数 ≤1/(T_dwell·K·Δt)，有限时间切换有限，无 Zeno 抖振。SWB 聚合 5Hz、FCT 对账 5Hz、CLCG 块边界 O(1)，加上 v9 路径后典型 ≤9ms、p99 ≤20ms，50Hz 保持不变。∎

**引理 93（群体—闭环联合中止增益）** 在引理 87/88 成立且见证时延优于本地的条件下，证书失效被 CLCG 转化为 β 抬升与 K_eff 收缩的时刻不晚于本地检测时刻；因此最坏中止延迟不超过 v9，且在独立见证下按引理 88 的检测增益严格下降。若相关失效使 m_eff→1，则退化为 v9 界，不产生负增益。证明：由引理 87 得 β_t≥e_t；由引理 88 得检测时刻不等式；K_eff 的单调收缩映射与块锁定保证收缩在下一个块边界生效；三式复合即得。∎

| 契约表 | 单机配置 | 联邦复制、quorum 激活、本地一票否决 |
| 归因 | 单机模块贡献 | 单机模块 + 同伴非安全通道贡献 |
| 失效语义 | 五级退化 | 六级退化，新增 Level-1..4 均可逐位回 v9 |
| 最大风险 | 滑窗滞后 | 群体相关性使"独立见证"假设失效 |

## 10. 本轮最大风险

**一句话**：群体见证的收益建立在"同伴的失效与我的失效不同步"这一独立性假设上，而真实分布跳变（同一种新地面材质、同一束强光）会同时污染所有机器人——此时群体聚合既不能提前，还可能用"多数一致"放大虚假的安全感，即「群体在最需要独立见证时最同质」。
