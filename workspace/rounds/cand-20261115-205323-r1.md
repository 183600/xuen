# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环第 3 轮；本轮灵感：「演示方案」×「语音合成」）

> R69 把不确定性拆成 aleatoric / epistemic，并让系统学会**问**：用流匹配生成多模态动作，用 VoI 选一个信息动作（看 / 问 / 触）。但它对「问」的建模停在**符号层**——`g_ask` 经冻结 LLM 解码成一段文字，仿佛信息以纯文本形式无损抵达人类。真实交互不是这样：问题是被**说**出来的，语气、语速、停顿、迟疑先于语义到达；而人类的回答也常是被**合成**或被**转述**的语音。与此同时，R69 用证书约束系统行为，却没有回答一个元问题：这些证书与主张，**怎么向人类证明**？
>
> 本轮两个灵感正好补上这两块：
> - **语音合成**：让「怎么说」成为可控制、可校准、可认证的信息动作——韵律即认识论姿态；
> - **演示方案**：让「怎么证明」成为可编译、可复现、可审计的沟通动作——演示即证据，而非叙事。
>
> 核心命题：**把「沟通」提升为一等的信息动作。** R69 只校准了「问不问」，R70 校准「怎么说」与「怎么证明」：对外说的每一句话，其韵律必须与系统真实的不确定性一致（stance calibration）；向外展示的每一个演示，其覆盖必须与主张的真实证据一致（demo calibration）。二者共享同一条纪律——**表达的不确定度不得低于实际的不确定度**。命名 **VOICE-RAS**（Voice-grounded Output-calibrated Interactive Certificate-compiled Evidence for Risk-Adaptive Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我该怎么说、又该拿什么来证明**」——不确定性不仅能变成一句提问，也必须决定这句话的**语气**和支撑它的**证据**。

## 0. 直觉与动机

**灵感 1（语音合成 → 韵律是「第二语义」）**
直觉：同一句「你确定吗？」，用平静、上扬、急促三种语调说出，会得到三种不同的回答。文字只规定**问什么**，韵律规定**怎么问**：它携带置信（confidence）、紧迫（urgency）、礼貌（politeness）、迟疑（hesitation）四个近似正交的姿态维度。R69 把「问」当作单通道符号消息，等于假设人类只读文字。更现实的是：很多交互系统（陪伴、客服、车载、护理）本来就通过 TTS 发声，人类也常用语音回复。语音不是可选的皮肤，而是闭环里真实存在的执行器与传感器。把韵律纳入动作空间，`g = (g_text, g_pros)` 才是一个完整的信息动作。

**灵感 2（韵律必须被校准，而不是被优化得更好听）**
直觉：一个错误假设若用笃定语气说出，人类更可能顺着答「对」；系统于是得到高置信的错误标签。**自信的错比犹豫的对更危险**，因为它同时污染了决策与后续学习。R69 已经有「模态校准门」：模态权重不可信就不许驱动交互。R70 需要它的对偶：**姿态校准门**——系统表达的置信必须匹配其历史正确率；一旦过度自信，强制退回中性语气。这不是风格问题，而是可信性问题。

**灵感 3（操纵校正 VoI → 不能把「被说服」当成「被澄清」）**
直觉：若 VoI 只计算「回答后模态熵下降多少」，系统会学到一个阴暗捷径：把语气调得更急、更权威，人就更容易给出一致答案，熵当然下降。但这不是信息，是顺从。必须定义**操纵校正的 VoI**：从信息增益中扣除人类顺从偏置（compliance bias），并给韵律强度设安全包络。否则 R69 的「主动求证」会退化成 R70 的「主动施压」。

**灵感 4（语音是双向攻击面）**
直觉：出站方向，韵律可被用来操纵；入站方向，回答可能是深伪语音、重放录音、同音词陷阱，或 TTS/ASR 自身造成的语义漂移。R69 的 ℰ_poison 只覆盖文字层面的误导，覆盖不了声学层。因此需要**声学验证门**：活体检测、说话人真实性、ASR 置信、跨模态一致性；并通过「复述确认」把同音歧义转成可验证证据。单条语音回答永远只是一个证据源，不能单独定案。

**灵感 5（演示方案 → 演示是研究者的信息动作）**
直觉：研究者向评审者、用户、监管者演示系统，本质是发出一个信息动作：用可复现的证据降低对方对「这套系统真的能做到」的后验不确定性。它同样有成本（场景搭建、演员、安全员）、有安全边界（演示中不能让机器人真伤人）、有投毒面（选择性展示、演员化、临时改指标）。既然 R69 要求系统的每次交互都可审计，R70 也应要求研究的每次「证明」都可审计。

**灵感 6（演示也会说谎 → 证书编译与防挑选）**
直觉：最危险的演示不是造假，而是**只演示成功路径**——它在每一帧都真实，却在统计上撒谎。这与「用自信韵律说一句内容正确但代表性不足的话」是同构的。解法也同构：预注册种子集、强制负例与故障注入、全量发布（含失败）、可重放哈希、覆盖度对威胁模型。演示方案因此从「一份 PPT 脚本」升级为**从证书编译出的、可执行的证据程序**。

**灵感 7（统一 → R69 是「中性语气 + 纯文本 + 不演示」的退化）**
直觉：如果关掉语音（只发文字）、把姿态固定为中性、关掉演示协议，VOICE-RAS 必须逐指令退化为 FLUID-RAS。这样新层不是并列的第二个黑箱，而是旧层在「沟通维度」上的严格扩展：安全侧只加约束，效率侧多出「把话说清楚」和「把证据摆出来」两种收益。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（VOICE-RAS 总览）** VOICE-RAS = (FLUID-RAS†, PAA, SCL, MSL, AVG, CDP)。三不变式：
(i) **控制环零学习写操作且永不被音频阻塞**：TTS/ASR/活体检测全部异步，实时安全环仍继承 R68 定义 276-i；
(ii) **出站语音受操纵包络约束**：韵律强度有硬上界，且表达置信不得超过姿态校准后的真实置信；
(iii) **证明纪律**：任何对外主张必须由证书编译出可重放演示，预注册、含负例、全量发布，且覆盖度对威胁模型达标。

**定义 311（韵律增广动作）** 任务动作 a ∈ 𝒜_task；文本提问 g_text ∈ ℝ^{d_q}；韵律 g_pros = (F0 轮廓 c(·), 时长 d, 能量 e(·), 停顿型 p, 音色风格 v) ∈ 𝒫，𝒫 为紧致有界集。增广动作 ξ = (a, g_text, g_pros) ∈ 𝒜_+。信息动作仍记 g = (g_text, g_pros)。

**定义 312（可控语音合成契约）** 冻结 TTS：TTS(text, g_pros, seed) → 波形 w，须满足：(i) 可懂度 WER ≤ ε_w；(ii) 有界性 ‖∂w/∂g_pros‖ ≤ L_p；(iii) 给定 seed 确定性可复现；(iv) **姿态可渲染性** d_stance(S(w), s_target) ≤ ε_s，其中 S 为冻结姿态识别器。TTS 参数不参与在线学习，问句语义仍由冻结 LLM 解码（继承 R69 定义 295）。

**定义 313（姿态向量与姿态抽象）** 姿态 s = (κ, υ, ρ, η) ∈ [0,1]^4：置信、紧迫、礼貌、迟疑；中性姿态 s_0 = (0.5, 0.2, 0.5, 0.2)。文本到姿态的映射由 SCL 给出 s = Stance(g_text, U_ale, U_epi)，其中置信 κ 的上界由当前校准后的正确率决定（定义 315）。

**定义 314（姿态条件回答模型）** 人类回答 Y ~ Q(· | g_text, s, context)。固定文本时姿态仍改变回答分布；定义**顺从偏置** B(s) = E[Y | g_text, s] − E[Y | g_text, s_0]，以及**回答率提升** r(s) = P(answer | s) − P(answer | s_0)。B 与 r 都由人类研究在线下标定，在线只查表。

**定义 315（姿态校准 SCL）** 将历史交互按表达置信 κ 分桶，桶 b 内实际正确率 acc(b)、平均表达置信 κ̄(b)，定义 ECE_stance = Σ_b (n_b/N)|acc(b) − κ̄(b)|。在线约束 κ ≤ Calib(κ_raw)，即**表达置信被历史正确率封顶**。ECE_stance > τ_ece ⇒ 强制中性姿态 s_0（姿态校准门）。

**定义 316（声学不确定性二分）** U_ale^ac = TTS 随机性 / ASR 声学噪声 / 信道噪声（不可约，沿用 R69 的 λ_floor 处理）；U_epi^ac = 同音歧义、姿态误读、说话人意图歧义（可约，允许触发复述确认或换措辞）。二者与 R69 的 U_ale / U_epi 正交叠加，不做简单标量求和。

**定义 317（操纵校正 VoI）** 内容-姿态联合信息价值
VoI†(g) = I(M; Y | g_text, s) − λ_m · B(s) − c(g_text, s)，
其中 M 为模态身份，λ_m 为操纵厌恶系数，B(s) 为定义 314 的顺从偏置。选择 g* = argmax_g VoI†(g)，s.t. M(s) ≤ M_max、risk(g) ≤ ε_int、预算未超。**注意：VoI† 明确拒绝把「靠施压换来的一致性」计入信息增益。** 若 max VoI† ≤ 0：不交互，退化 R69。

**定义 318（操纵安全包络 MSL）** 操纵势 M(s) = ‖s − s_0‖_Σ；要求 M(s) ≤ M_max、预测偏置 B̂(s) ≤ B_max，且 κ 不得超过定义 315 的封顶值。紧迫维度另设硬阈值：任何涉及安全的关键问句不得使用高紧迫姿态（防止诱导恐慌或仓促确认）。

**定义 319（入站声学证据 AVG）** 语音回答 ŷ 提取四元组 (L, A, C, X)：活体 L、说话人真实性 A、ASR 语义置信 C、跨模态一致性 X（与视觉/传感器/上下文是否自洽）。仅当 L ≥ τ_L ∧ A ≥ τ_A ∧ C ≥ τ_C 时，ŷ 才被计为一个证据源；同音歧义必须通过「复述确认」或「书面/结构化确认」消解后才能入账。

**定义 320（声学证据纪律）** 单条语音回答、单个 TTS 生成的问题、单次复述一致，均不得单独定案。沿用 R69 的 k 源一致纪律：至少两个正交证据源（如语音 + 视觉 + 传感器，或语音 + 结构化确认）一致，或其操纵校正 VoI 增益超过高置信阈值；否则 U_epi^ac 保持未消解并走保守退避。

**定义 321（演示协议 D）** D = (claim c, 证书 J, 场景采样器 P_scene, 预注册种子集 S, 故障注入集 F, 不变式集 Φ, 期望结果, 重放哈希 h, 操作员脚本 O, 成本预算)。D 有效 ⇔ 对每个 seed ∈ S 重放都复现哈希 h，且所有 Φ 在该 seed 下成立；**只展示部分 seed 的演示视为无效**。

**定义 322（证书编译 CDP）** CDP: J_VOICE → D。证书中每个数值字段必须至少被一个可重放场景见证；每条安全主张必须至少配一个负例或故障注入场景。编译是确定性、带版本的：相同 J + 相同代码版本 → 相同 D 与相同哈希。

**定义 323（演示覆盖度）** 命题覆盖 Cov_c = 被见证的证书字段数 / 总字段数；威胁覆盖 Cov_e = 被演示注入的威胁集合大小 / |ℰ_VOICE|。要求 Cov_c = 1，Cov_e ≥ 1 − δ_demo。覆盖度不足时，主张只能降级为「未验证假设」，不得写入产物结论。

**定义 324（演示投毒 ℰ_demo 与防挑选审计 DAG）** ℰ_demo = {种子挑选, 事后改主张, 隐藏失败, 演员化人类, 环境临时篡改, 指标切换, 只演示成功路径}。纪律：预注册种子与主张、全量发布（含失败）、指标版本锁定、环境快照哈希。DAG 审计可选停止偏差：事后从 n 个种子里挑 k 个最好结果，报告成功率的上偏可达 O(√(log n / n))；预注册并全量发布把该上偏降为 0（仅余抽样误差）。

**定义 325（证书 J_VOICE）** J_VOICE = (J_FLUID, stance_ECE, prosody_envelope_ok, liveness_score, acoustic_voi_ratio, demo_replay_hash, demo_coverage, demo_tamper_ok, voice_ver)。Valid ⇔ Valid(J_FLUID) ∧ stance_ECE ≤ τ_ece ∧ 包络未越界 ∧ 活体过门 ∧ 演示覆盖达标 ∧ 哈希可复现。

**定义 326（三级退避阶梯）** 若姿态未校准 / 活体可疑 / 演示覆盖不足：先降为**中性语气 + 纯文本问答**（关闭韵律，保留 R69 的语义层）；若文本层证据仍不可信或被投毒：关闭交互，退化为 R69 的保守路径；若连标定都不可信：退化为 R68 的 λ_floor。安全侧单调不降，效率侧逐级让渡。

```python
# IP-264 PAA：文本 -> 姿态 -> 可控语音（全冻结，只做选择与裁剪）
class ProsodyAction:
    def __init__(self, stance_map, tts, stance_recognizer):
        self.stance_map, self.tts, self.S = stance_map, tts, stance_recognizer

    def render(self, g_text, U_ale, U_epi, seed):
        s = self.stance_map(g_text, U_ale, U_epi)          # (kappa, upsilon, rho, eta)
        s = clip_to_envelope(s)                            # MSL 包络裁剪
        w = self.tts(g_text, s, seed)                      # 冻结 TTS，确定性
        return w, s, self.S(w)                             # 回读实际渲染姿态

# IP-265/266 SCL + MSL：姿态校准门与操纵包络
def calibrated_stance(s_raw, calib_table, ece):
    if ece > TAU_ECE: return neutral_stance()              # 姿态校准门
    s = dict(s_raw)
    s['kappa'] = min(s['kappa'], calib_table.cap(s['kappa']))  # 置信封顶
    if manipulation_potential(s) > M_MAX: s = shrink_toward_neutral(s)
    if s['upsilon'] > URGENCY_SAFE_MAX: s['upsilon'] = URGENCY_SAFE_MAX
    return s

# IP-268 AVoI：操纵校正的信息价值（拒绝"被说服"冒充"被澄清"）
def acoustic_voi(g_text, s, modes, w, budget):
    if not budget.allow(g_text, s): return -inf
    info = entropy(w) - expected_entropy(w, g_text, s)     # I(M;Y|g)
    bias = compliance_bias(s)                              # 标定表查得
    score = info - LAMBDA_M * bias - cost(g_text, s)
    return score

def choose_spoken_action(modes, w, budget):
    best = None
    for g_text in candidate_questions(modes):
        for s in stance_candidates(modes):
            s = calibrated_stance(s, CALIB, ece)
            if not c_ras_wm.certify_info(g_text, s): continue
            score = acoustic_voi(g_text, s, modes, w, budget)
            if best is None or score > best.score: best = (g_text, s, score)
    return best if best and best.score > 0 else None       # 无利可图 -> R69

# IP-267 AVG：入站语音证据验证（活体/真实性/同音/跨模态）
def verify_answer(audio, context):
    L, A, C, X = liveness(audio), speaker_auth(audio), asr_conf(audio), cross_modal(audio, context)
    if L < TAU_L or A < TAU_A or C < TAU_C: return None    # 不计证据
    if homophone_risk(audio) > TAU_H:
        if not confirm_by_paraphrase(audio): return None   # 同音 -> 复述确认
    return evidence(audio, quality=min(L, A, C, X))

# IP-269/270 CDP + DAG：从证书编译可重放演示，并做防挑选审计
def compile_demo(J, seed_set, fault_set):
    scenes = [instantiate(J.claim, s, f) for s in seed_set for f in fault_set]
    assert all(certificate_witnessed(J, sc) for sc in scenes)   # 每个字段有见证
    assert has_negative_cases(scenes)                            # 至少一个负例
    return Demo(claim=J.claim, scenes=scenes, hash=replay_hash(scenes),
                preregistered=True, publish='all_seeds_including_failures')

def audit_demo(D, J):
    ok_hash = (replay_hash(run(D)) == D.hash)
    ok_cov  = (demo_coverage(D, J) >= 1 - DELTA_DEMO)
    ok_prereg = D.preregistered and not post_hoc_claim_edit(D, J)
    return ok_hash and ok_cov and ok_prereg

# IP-274 主闭环：在 R69 的不确定性处置处插入"沟通层"
def VOICE_RAS_round(M, obs, seed):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)     # R68
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)  # R69
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o, o_calibrated)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)

    act = (M.avoi.choose_spoken_action(modes, w, M.budget)
           if (U_epi > TAU_EPI and not slow and M.scl.ece <= TAU_ECE) else None)

    if act is not None:

        w_audio, s_rendered, s_perceived = M.paa.render(g_text, U_ale, U_epi, seed)
        if stance_error(s, s_perceived) > TAU_STANCE:             # 渲染失真
            act = None                                            # 退中性/文本
        else:
            ans = M.avoi.execute_async(w_audio, M.cia)             # 语音问 + 多模态等答

            if ev is not None:

            else:
                U_epi_after = U_epi                                # 未消解 -> 保守
    # 2) 风险缩放：只对 aleatoric + 未消解 epistemic 收紧（继承 R69）

    if slow: lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, U_cal))
    mode = select_mode(modes, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # 3) 交互审计 + 演示证书（离线）
    M.vqa_d.submit_async(act, ev, U_epi, U_epi_after, a_hat)
    return k, lam, mode, (U_ale, U_epi_after)
```

## 3. 推导

**引理 19（姿态增益的条件分解）** 设姿态被正确感知的概率为 1−ε_stance，误读时回答对模态 M 的信息增益为 0（最坏情形）。则 VoI†(g) ≤ (1−ε_stance)·I(M;Y|g_text,s) − λ_m B(s) − c(g)。因此当 ε_stance > 1 − (λ_m B + c)/I 时，任何非中性姿态的操纵校正 VoI 都 ≤ 0。**系**：姿态校准不是锦上添花，而是「说」这件事有正收益的**前提**；姿态误读率高的系统应当闭嘴或只用中性文本。

**引理 20（操纵—顺从权衡的内点条件）** 设回答率 r(s) 随操纵势 M(s) 递增且凹，顺从偏置 B(s) ≤ β·M(s) 线性。则未校正目标在 M 上有内点最优；但操纵校正目标 VoI† 的最优点满足 ∂I/∂M = λ_m β，只依赖真实信息增益，不依赖「人多容易被吓住」。**系**：若用未校正 VoI，系统会系统性高估强姿态的价值；校正后，最优姿态只由信息结构与成本决定。这也解释为什么必须把 λ_m 写进目标而不是只写进约束——约束会被「刚好卡边界」的策略利用。

**引理 21（演示覆盖—主张风险）** 设主张依赖性质集 Φ，未覆盖的隐藏失效模式总概率质量为 δ_hidden，演示覆盖度为 Cov_e，抽样误差为 ε_s。则「主张成立」被错误接受的概率 ≤ (1−Cov_e)·δ_hidden + ε_s。若进一步允许事后从 n 个种子挑选 k 个最好结果报告，选择性上偏可达 O(√(log n / n))；预注册全部种子并全量发布后，该上偏消失，只剩 ε_s。**系**：演示的可信度 = 覆盖度 × 复现率 × 预注册，而不是「现场效果好不好」。

**定理 18（VOICE 严格包含 FLUID）** 在 A99–A101 下，VOICE-RAS 的期望风险 ≤ FLUID-RAS；且当姿态固定为 s_0、关闭语音改用文本、关闭演示协议时，两者**逐指令相同**。因此 FLUID 是 VOICE 在「不做声学沟通、不做对外证明」边界上的退化；安全侧只增约束（定义 310-ii、定义 318、定义 320），效率侧获得「说清楚」与「可复现」两种收益。

**定理 19（发声闭环安全、异步与无突变）** 出站韵律经 MSL 包络裁剪后，社交/物理风险 ≤ ε_int；入站经 AVG 验证失败时只**减少**可用证据，因而 U_epi 只能保持或增大，λ 单调不降地退化到 R69/R68；TTS/ASR/活体检测全部异步，控制环不等音频，换装不变式（R68 定理 15）保持 ⇒ 控制连续、无突变。

## 6. 本轮最大风险

**一句话**：VOICE-RAS 可能把「说得更自信」误当成「变得更确定」——韵律能让一个错误假设听起来像结论，而证书编译的演示又天然倾向于展示成功路径，于是 R69 的「被证实的错误」会被包装成「被演示背书的真理」；发声与演示都必须被**校准**，而不是被优化得更好听、更好看。

```python
# IP-264/265/266：文本 -> 校准姿态 -> 包络裁剪 -> 冻结 TTS
def render_question(g_text, U_ale, U_epi, seed):
    s = stance_map(g_text, U_ale, U_epi)                 # (kappa, upsilon, rho, eta)
    if stance_ece > TAU_ECE: s = neutral_stance()        # 姿态校准门
    s['kappa'] = min(s['kappa'], calib.cap(s['kappa']))  # 置信封顶
    if manip_potential(s) > M_MAX: s = shrink_to_neutral(s)
    if s['upsilon'] > URGENCY_SAFE_MAX: s['upsilon'] = URGENCY_SAFE_MAX
    w = tts(g_text, s, seed)                             # 冻结、确定性
    return w, s, stance_recognizer(w)                    # 回读实际渲染姿态

# IP-268：操纵校正 VoI，拒绝把"被说服"当"被澄清"
def acoustic_voi(g_text, s, modes, w, budget):
    if not budget.allow(g_text, s): return -inf
    info = entropy(w) - expected_entropy(w, g_text, s)
    return info - LAMBDA_M * compliance_bias(s) - cost(g_text, s)

def choose_spoken_action(modes, w, budget):
    best = None
    for g_text in candidate_questions(modes):
        for s in stance_candidates(modes):
            if not c_ras_wm.certify_info(g_text, s): continue
            score = acoustic_voi(g_text, s, modes, w, budget)
            if best is None or score > best.score: best = (g_text, s, score)
    return best if best and best.score > 0 else None     # 无利可图 -> R69

# IP-267：入站语音证据验证（活体/真实性/同音/跨模态）
def verify_answer(audio, ctx):
    L, A, C, X = liveness(audio), speaker_auth(audio), asr_conf(audio), cross_modal(audio, ctx)
    if min(L, A, C) < TAU_AVG: return None               # 不过门不计证据
    if homophone_risk(audio) > TAU_H and not confirm_by_paraphrase(audio):
        return None
    return evidence(audio, quality=min(L, A, C, X))
```

## 4. 推导

**引理 19（姿态增益的条件分解）** 姿态正确感知率 1−ε_stance，误读时信息增益为 0（最坏），则 `VoI† ≤ (1−ε_stance)·I(M;Y|g,s) − λ_m B(s) − c`。当 `ε_stance > 1 − (λ_m B + c)/I` 时任何非中性姿态都无正收益。系：姿态校准是「说」有正收益的**前提**；误读率高就应闭嘴或只用中性文本。

**引理 20（操纵—顺从权衡的内点条件）** 回答率随操纵势递增且凹、偏置线性时，未校正目标有内点最优；操纵校正目标的最优点满足 `∂I/∂M = λ_m β`，只由真实信息结构与成本决定。系：不校正 VoI 会系统性高估强姿态；λ_m 必须进目标而非只进约束，否则策略会「卡边界」施压。

**引理 21（演示覆盖—主张风险）** 隐藏失效模式质量 δ_hidden、威胁覆盖 Cov_e、抽样误差 ε_s 时，错误接受「主张成立」的概率 `≤ (1−Cov_e)·δ_hidden + ε_s`；事后从 n 个种子挑 k 个报告的选择性上偏可达 `O(√(log n / n))`，预注册并全量发布后消失。系：演示可信度 = 覆盖度 × 复现率 × 预注册，而非现场效果。

**定理 18（VOICE 严格包含 FLUID）** A99–A101 下期望风险 ≤ FLUID；姿态固定 `s_0`、关闭语音、关闭演示时两者**逐指令相同**。FLUID = 「不做声学沟通、不做对外证明」的边界；安全侧只增约束，效率侧获「说清楚」与「可复现」两收益。

**定理 19（发声闭环安全、异步与无突变）** 出站经 MSL 包络裁剪后社交/物理风险 ≤ ε_int；入站 AVG 失败只减少证据 ⇒ U_epi 不降、λ 单调退化到 R69/R68；音频全异步，控制环不等 TTS，换装不变式（R68 定理 15）保持 ⇒ 控制连续、无突变。

## 7. 本轮最大风险

**一句话**：VOICE-RAS 可能把「说得更自信」误当成「变得更确定」——韵律能让错误假设听起来像结论，证书编译的演示又天然倾向展示成功路径，于是 R69 的「被证实的错误」被包装成「被演示背书的真理」；发声与演示都必须被**校准**，而不是被优化得更好听、更好看。
