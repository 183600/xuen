# 第 43 轮（新循环第 3 轮） · Grasp-SSL-Cert：接触模式感知的自监督证书——把「机械臂抓取」的接触图与「自监督学习」的免费监督焊入 Sim-Cert-RAG 飞轮（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR）。v19 自陈最大风险是「仿真偏差累积 + 检索幻觉」导致证书静默失效。本轮两个灵感词恰好击中 v19 的两处结构性软肋：**「机械臂抓取」暴露了 L_m 连续假设的致命边界**——抓取是接触模式的离散切换（接近→接触→力闭合→滑动→脱落），切换瞬间安全边际跳变，任何基于全局 Lipschitz 的 margin 界都会失效；**「自监督学习」提供了把最昂贵的「抓取失败标签」变成免费信号的路径**——时序一致性、跨模态一致性、物理守恒，以及最关键的时间反演不对称性，都能在无标注下构造失败监督。二者耦合出「接触图证书飞轮」：无标签实机抓取 → SSL 表征/失败分数 → 接触模式分类 → 模式条件证书 → SCV 压力测试 → CKB 接触模板 → ECR 部署，证书第一次能覆盖「接触」这一 sim-to-real 最深的鸿沟。

## 0. 直觉与动机

**灵感 1（机械臂抓取 → 证书必须从「状态空间」搬到「接触图」）**：v19 的所有界都建立在 `|m(x)−m(x')| ≤ L_m‖x−x'‖` 上，但抓取的物理本质是**接触模式的离散切换**。接近阶段没有接触力，接触瞬间法向力从 0 跳到正值，滑动/脱落又是另一套动力学；每次模式切换，有效惯量、雅可比、摩擦锥约束都改变，margin 在切换点不连续。直觉上，正确的对象不是「一个全局安全集」，而是**接触图 G_c 上的 hybrid 证书**：每个接触模式 c 一个局部证书 (θ_c, L_{m,c}, Inv_c)，每条模式转移边 e=(c,c') 一个「切换安全条件」，切换时必须同时满足前一模式的出口不变式、后一模式的入口不变式，以及与守卫面保持 ε_h 的留白。抓取特有的两类证书可以显式写出来：**力闭合证书**（抓取矩阵 G 在摩擦锥内的鲁棒 wrench 余量）与**滑动证书**（切向/法向力比到摩擦极限的距离）。这样 v19 的 L_m 只需在模式内成立，接触不连续性被显式建模而不是被 Lipschitz 假设吞掉。

**灵感 2（自监督学习 → 把最贵的失败标签变成免费信号）**：抓取的真机失败标签极其昂贵——每次「试到掉」都可能损坏物体或机械臂。SSL 的直觉是：物理世界自带三类**免费监督**。其一是**时序一致性**：在已知动作下，相邻时刻的表征应缓慢变化（slow feature），剧变往往对应接触事件或滑动。其二是**跨模态一致性**：视觉应能预测触觉/力/本体感受，反之亦然；模态间「对不上」正是接触状态误判的征兆。其三是**物理守恒残差**：接触互补 0 ≤ λ_n ⊥ φ(q) ≥ 0、摩擦锥 ‖λ_t‖ ≤ μλ_n、刚体动量方程，这些是无需标签的硬约束，残差大即物理不一致。最关键的是**时间反演不对称性**：滑移、碰撞、脱落是耗散且不可逆的过程，把轨迹时间反演后，前向分布与反演分布在这些事件处显著分离，而在准静态可逆运动中几乎重合——于是「前向/反演判别器」等于一个**免费的、逐时刻定位的失败探测器**。对比学习再把「失败」变成表征空间中的离群点，无需失败标签即可训练。

**灵感 3（耦合 → 接触图证书飞轮，并用 conformal 给 SSL 重新上「保险」）**：SSL 分数本身没有覆盖保证，直接当证书用是危险的。直觉是把它分成两层：SSL 负责**产生候选信号**（模式分类、失败分数、采样先验），conformal 负责**把信号校准成有有限样本覆盖保证的 margin 下界**（split conformal + 漂移下的自适应 conformal）。飞轮因此变成：无标签实机抓取日志 → SSL 表征 z 与失败分数 s_fail → 模式分类器 ĉ → 接触图模式条件证书 → 失败分数作为 SCV 的对抗采样先验（优先压测高失败分数区域）→ CKB 存接触模板与反例 → ECR 部署 INT8 模式分类器与 conformal 查表。v19 的 `Sim→RAG→Edge→Sim` 由此升级为 `Unlabeled-Real→SSL→Contact-Cert→Sim→KB→Edge→Real`，接触数据第一次能低成本回流。

**与 v19 的差异（不推倒，只加层）**：v19 把 margin 当连续标量，v8 把它当「模式索引 + 模式内标量」；v19 的失败样本靠仿真注入，v8 增加「无标签实机 + 时间反演」这一免费来源；v19 的 CKB 只有任务/环境指纹，v8 增加「接触图指纹」；v19 的 ECR 只有连续 margin 查表，v8 增加「模式分类 + conformal 下界」两条最小路径。

## 1. 形式化定义（增量：定义 38–44）

**定义 38（接触模式与接触图）**：接触模式 c = (C_contact, grasp_type, object_pose_bucket)，其中 C_contact 是当前处于接触的几何基元集合。接触图 G_c = (M, E) 的节点是物理可行的接触模式，边 e=(c,c') 标注接触事件类型（make / break / slip / re-grasp / impact）。运行时模式估计器 Ĉ(x) 给出后验，模式不确定度 δ_mode(x) = 1 − max_c P(c|x)。**要求**：当 δ_mode(x) > δ_max 时，禁止使用模式条件证书，退化为模式无关保守包络或 SafeStop。

**定义 39（模式条件 hybrid 证书）**：对每个模式 c，证书三元组 (S_c, Inv_c, m_c)，S_c = {x : m_c(x) ≥ θ_c}，且仅在模式内要求 Lipschitz：|m_c(x) − m_c(x')| ≤ L_{m,c}‖x − x'‖。对转移边 e=(c,c')，切换证书定义为
`Trans_e(x) ⇔ x ∈ Inv_c ∩ Inv_{c'} ∧ h_e(x) ≥ ε_h ∧ m_{c'}(x^+) ≥ θ_{c'} − L_{m,c'}·‖x^+ − x‖`，
其中 h_e(x) 是到守卫面 g_e(x)=0 的有符号留白，ε_h 是切换留白下界。**命题 39**：若每条边的边内证书与切换证书同时成立，则轨迹在接触图上的连续拼接保持 sound，即使 m 在模式边界不连续。

**定义 40（力闭合证书与滑动证书）**：抓取映射 G(q) ∈ ℝ^{6×m} 把接触力 λ 映为物体 wrench，摩擦锥 FC(μ) = {λ : λ_{n,i} ≥ 0, ‖λ_{t,i}‖ ≤ μ_i λ_{n,i}}。**鲁棒力闭合余量**
`ε_fc(q) = max{ε ≥ 0 : B_6(w_load, ε) ⊆ G(q)·FC(μ)}`，
可由二阶锥规划求解；归一化 m_fc(q) = ε_fc(q)/‖w_load‖。**滑动余量** m_slip,i = 1 − ‖λ_{t,i}‖/(μ_i λ_{n,i})，聚合 m_slip = min_i m_slip,i。两者都只在当前接触模式内定义，正好嵌入定义 39 的 m_c。

**定义 41（自监督一致性目标）**：设编码器 f 把观测 o 映到表征 z。多路 SSL 损失
`L_ssl = L_temp + λ₁L_cross + λ₂L_phys + λ₃L_nce`，
其中 L_temp = E‖f(o_t) − f(o_{t+1})‖²（已知动作下的慢特征）；L_cross = E‖g_v(o^vis_t) − g_t(o^tac_t)‖²（跨模态互预测）；L_phys = ‖M(q)q̈ + C(q,q̇)q̇ + g(q) − Jᵀλ‖² + ReLU(−λ_n) + ReLU(‖λ_t‖ − μλ_n)（动量残差 + 接触互补/摩擦锥违反量）；L_nce 为对比项（见定义 42）。**命题 41**：若 L_phys → 0，则表征所编码的物理量与接触约束一致；L_phys 可作为无标签的「接触模型可信度」指标。

**定义 42（时间反演失败统计量与对比失败发现）**：设轨迹 τ = (o₁,…,o_T, a₁,…,a_{T−1})，时间反演 τᴿ = (o_T,…,o₁, a_{T−1},…,a₁)。训练判别器 D 区分 τ 与 τᴿ，逐时刻失败分数
`s_fail(o_t) = σ(D(f(o_t), f(o_{t+1}), a_t))`（σ 为 sigmoid）。
直觉依据：准静态可逆运动满足时间反演近对称，而滑移/碰撞/脱落是耗散过程，反演后动力学不可行，故 D 的 logit 在这些事件处升高。对比目标把正样本（相邻时刻、跨模态）与负样本（时间反演、模态错配、动作置换）分开；失败分数即表征到正样本流形的距离。**定义（对比失败召回的类条件重叠界）**：若正/负类条件分布在表征空间的重叠系数为 ρ，则失败召回率下界 ≥ 1 − ρ/2。

**定义 43（conformal 化自监督边际下界）**：在少量带失败标注的校准集 D_cal = {(x_i, y_i)} 上定义非一致性分数 A(x) = 1 − s_fail(x)。split conformal 取 q = Quantile_{1−α}({A(x_i) : y_i 为安全})，输出
`m_lo(x) = q − A(x)`。
则在新样本可交换假设下 P(m(x) ≥ m_lo(x)) ≥ 1 − α。漂移场景用自适应 conformal（ACI）：α_{t+1} = α_t + γ(α − err_t)，保证长期覆盖。**命题 43**：conformal 下界不依赖 SSL 模型正确性，只依赖校准集可交换性；因此它是给「免费信号」重新上保险的关键一层。

**定义 44（接触感知的 Sim-to-Real 迁移）**：按模式定义 Wasserstein 距离 W₁^c(D_real^c, D_sim^c)，并设表征域偏移 ε_rep = W₁(f(D_real), f(D_sim))。则模式内迁移界为
`m_real,c(x) ≥ m_sim,c(x) − L_{m,c}·W₁^c − L_f·ε_rep`，
其中 L_f 是编码器 Lipschitz 常数（谱归一化控制）。SSL 的目标之一是压低 ε_rep（域不变表征），从而把 v19 的 α_e 收紧。**注意**：接触模式的 W₁ 必须按模式分别估计，混在一起估计会因模式比例差异系统性低估接触边界处的偏移（v19 的一个隐藏偏差来源）。

## 2. 四大产出设计（增量 IP-57/58/59 + 升级 IP-51/52/53/54/55/56/49/50/47）

### 2.1 IP-57 CONTACT-GRAPH-CERT（接触图证书 CGC）
1. **接触模式自动发现**：从无标签抓取日志中聚类接触状态（接触基元集合 + 物体位姿桶），再用少量标签校准边界；模式数受最小描述长度约束，防止模式爆炸。
2. **模式条件证书合成**：每个模式内跑 v19 的 CEGAR/采样，但只在模式可行域内；力闭合余量 m_fc 与滑动余量 m_slip 作为几何/动力学证书注入 m_c。
3. **切换证书生成**：对每条接触事件边，反向可达采样逼近守卫面，要求留白 h_e ≥ ε_h，并验证 x^+ 落入后一模式的入口不变式。
4. **模式无关保守包络**：为 δ_mode > δ_max 的场景预计算一个「所有模式取交」的保守安全集，作为模式误判时的兜底（宁可停机，不可错模式）。

### 2.2 IP-58 SELF-SUPERVISED-CERT-LEARNER（自监督证书学习器 SSCL）
1. **多视图编码器**：视觉/触觉/本体三路编码器 + 跨模态预测头；视觉编码器用高分辨率 patch，触觉用高频时序卷积。
2. **物理残差头**：从表征回归接触力 λ、物体 6D 位姿与速度，计算定义 41 的 L_phys；接触互补违反量直接作为负样本权重。
3. **时间反演判别器**：轻量时序 Transformer，输出逐时刻 s_fail；训练时用动作置换与模态错配做额外负样本。
4. **conformal 校准器**：在少量失败标注上做 split conformal，输出 m_lo(x) 与覆盖率监控；漂移时切 ACI。
5. **表征证书约束**：谱归一化限制 L_f，并记录表征域偏移 ε_rep；L_f·ε_rep 显式进入定义 44 的迁移界。

### 2.3 IP-59 CONTACT-GRAPH-FLYWHEEL（接触图飞轮 CGF）
1. **无标签数据引擎**：实机抓取日志（含失败/中止）自动切片、打模式伪标签、抽时间反演负样本，入库。
2. **失败分数驱动 SCV**：把 s_fail 高的状态作为 IP-54 的对抗采样先验（重要性采样权重 ∝ s_fail），把仿真预算集中在 SSL 认为危险的区域。
3. **接触模板入库**：CKB 新增接触图指纹字段（接触基元拓扑、抓取类型、物体质量分布桶），支持「相似抓取」的模板检索与合并。
4. **闭环下发**：模式分类器蒸馏到 INT8 下发 ECR；conformal 表随 CKB 版本热更新；持续监控模式混淆率与覆盖率。

## 5. 本轮最大风险

**一句话**：接触模式的离散切换让证书第一次可以「按模式」变保守，但也引入了 **mode confusion（模式误判后套用错误模式的证书）** 与 **时间反演负样本的准静态失效** 两条新失效链——若模式分类器在接触建立/断裂瞬间把「接近」误判成「力闭合」，或抓取动作本身近似可逆导致 s_fail 静默漏检，证书会在「模式正确」的错觉下被错误模式套用，比 v19 的连续 margin 偏差更隐蔽；因此 E87（模式混淆率，且必须含未触发门控的漏网率）与 E90（时间反演在准静态动作上的误报）必须作为红线实验，任一不达标即禁用模式条件证书、全链路回退到模式无关保守包络。

def discover_contact_modes(unlabeled_logs, eps_merge=0.05):
    # 以 (接触基元集合, 抓取类型, 位姿桶) 为键聚类；MDL 控制模式数
    modes = []
    for traj in unlabeled_logs:
        for seg in segment_by_contact_events(traj):
            c = contact_signature(seg)
            c = merge_if_close(c, modes, eps_merge)
            if c is None: modes.append(c)
    return Modes(modes)

def force_closure_margin(q, contacts, mu, load_wrench):
    G = grasp_matrix(q, contacts)          # 6 x m
    # SOCP: max eps  s.t.  w_load + eps*u ∈ G·FC(mu),  ∀‖u‖<=1
    eps = socp_robust_force_closure(G, friction_cone(mu), load_wrench)
    return eps / max(1e-6, norm(load_wrench))

def slip_margin(contact_forces, mu):
    return min(1.0 - norm(lam_t_i) / max(1e-6, mu[i]*lam_n_i)
               for i, (lam_n_i, lam_t_i) in enumerate(contact_forces))

def synthesize_mode_certificate(mode, x_samples, rng):
    # 仅在模式可行域内跑 v19 的 CEGAR/采样
    x_in = [x for x in x_samples if mode_consistent(x, mode)]
    cert = cegar_refine(x_in, budget=300s)
    cert.m_fc   = [force_closure_margin(x.q, x.contacts, x.mu, x.w) for x in x_in]
    cert.m_slip = [slip_margin(x.forces, x.mu) for x in x_in]
    cert.theta  = conformal_quantile(cert.margins, alpha=0.05)
    cert.L_m    = empirical_lipschitz(cert.margins, x_in)   # 仅模式内！
    cert.Inv    = invariant_from(x_in)
    return cert

def transition_certificate(e, x, dt, cert):
    c, cp = e.src, e.dst
    if not (in_invariant(x, cert[c].Inv) and in_invariant(x, cert[cp].Inv)):
        return False
    if signed_guard_whitespace(e.guard, x) < EPS_H:
        return False
    x_next = integrate_mode(cp, x, dt)
    bound  = cert[cp].theta - cert[cp].L_m * norm(x_next - x)
    return cert[cp].m(x_next) >= bound

def conservative_envelope(all_mode_certs):
    # 模式不确定时的兜底：所有模式安全集取交（更保守）
    return intersect([cert.S for cert in all_mode_certs])

### IP-58 SSCL：自监督证书学习与 conformal 校准
```
def ssl_pretrain(trajs, encoder_f, heads):
    for batch in trajs:
        o_t, o_t1, a_t = batch.obs, batch.next_obs, batch.act
        z_t, z_t1 = encoder_f(o_t), encoder_f(o_t1)

        L_temp = mse(z_t, z_t1)                         # 已知动作下慢特征
        L_cross = mse(heads.vis(o_t.vis), heads.tac(o_t.tac))
        # 物理残差：动量 + 接触互补 + 摩擦锥违反
        lam = heads.force(z_t)
        L_phys = (norm(heads.dyn_residual(o_t, a_t, lam))**2
                  + relu(-lam.n).mean()
                  + relu(norm(lam.t, dim=-1) - mu*lam.n).mean())

        # 时间反演负样本 + 动作置换 + 模态错配
        neg_rev   = encoder_f(time_reverse(batch))
        neg_perm  = encoder_f(shuffle_actions(batch))
        neg_mis   = encoder_f(mismatch_modality(batch))
        L_nce = info_nce(z_t1,
                         pos=z_t,
                         negs=[neg_rev, neg_perm, neg_mis],
                         tau=0.1)
        update(encoder_f, L_temp + L_cross + L_phys + L_nce)
    return encoder_f

def train_time_reversal_discriminator(trajs, f):
    D = TemporalTransformer()
    for batch in trajs:
        fwd = f(batch)
        rev = f(time_reverse(batch))
        # 判别前向 vs 反演；滑移/碰撞/脱落处 logit 升高
        update(D, bce(D(fwd), 1) + bce(D(rev), 0))
    return D

def failure_score(traj, f, D):
    z = f(traj)
    return sigmoid(D(z))          # 逐时刻，高=不可逆/危险

def conformalize(scores, labels, alpha=0.05):
    # labels: 1=安全, 0=失败；仅安全样本入校准分位
    A = [1.0 - s for s, y in zip(scores, labels) if y == 1]
    q = quantile(A, 1 - alpha)
    def m_lo(x):
        return q - (1.0 - failure_score(x, f, D))
    return m_lo, q

class AdaptiveConformal:
    def __init__(self, alpha, gamma=0.01): self.a, self.g = alpha, gamma
    def update(self, covered):
        err = 0.0 if covered else 1.0
        self.a += self.g * (self.alpha_target() - err)   # ACI
    def quantile(self, scores):
        return quantile(scores, 1 - self.a)
```

## 6. 本轮最大风险

**一句话**：接触模式的离散切换让证书第一次可以「按模式」变保守，但也引入了 **mode confusion（模式误判后套用错误模式的证书）** 与 **时间反演负样本的准静态失效** 两条新失效链——若模式分类器在接触建立/断裂瞬间把「接近」误判成「力闭合」，或抓取动作本身近似可逆导致 s_fail 静默漏检，证书会在「模式正确」的错觉下被错误模式套用，比 v19 的连续 margin 偏差更隐蔽；因此 E87（模式混淆率，且必须含未触发门控的漏网率）与 E90（时间反演在准静态动作上的误报）必须作为红线实验，任一不达标即禁用模式条件证书、全链路回退到模式无关保守包络。
