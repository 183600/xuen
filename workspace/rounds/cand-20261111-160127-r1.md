# 第 56 轮（承接第 55 轮语义-接触生存核；灵感循环第 2 轮；本轮灵感：「可扩展性」×「移动底盘」）

> 第 55 轮把“感知标签”升级为“接触约束”，把单机动作升级为“生存核”。本轮把问题从 **一台机器人是否安全** 提升到 **一族异构移动底盘能否以可证明、可摊销的成本共享同一套语义-接触安全层**。核心矛盾：**H24**：生存核 `K(Σ)` 是底盘相关的——换底盘就等于换动力学、支撑多边形与非完整约束，逐台重建使成本随底盘数 `N` 线性甚至超线性增长，吃掉语义层复用的全部收益；**H25**：移动底盘的“可行动”不只由接触决定，还由**滚动/非完整运动学与倾覆边界**决定，语义边界裕度与倾覆裕度会在高速转向、斜坡、软地面处相互叠加，单机静态核无法安全外推。

## 0. 直觉与动机

**灵感 1（可扩展性 → 生存核参数化族，而非逐台重建）**
直觉：可扩展性不是“同一套代码跑得快”，而是“**安全证明能沿底盘族摊销**”。把生存核拆成两层：底盘无关的语义接触层 `K_sem(Σ)` 与底盘相关的动力学投影层 `K_dyn(φ)`，其中 `φ` 是轴距、轮距、质心高度、质量、摩擦、悬挂柔度、运动学类型。新底盘落在已标定参数的凸包内时只验证差异子空间；落在凸包外则显式拒绝并触发重标定。可扩展性的本质是 **迁移证书可组合 + 标定成本亚线性**。

**灵感 2（移动底盘 → 底盘锚定接触契约）**
直觉：语义接触点不该以世界坐标存储，而应锚定在底盘坐标系，随基座位姿变换。同一段扶手，对高底盘是“可抓”，对低底盘是“不可达”；同一个语义边界，在底盘坐标系里才是底盘无关的。于是把接触从“世界系像素点”升级为 **接触契约** `(p_b, c, κ, m_s, conf)`，让语义层与底盘解耦。代价是：锚定假设刚体，忽略了悬挂与轮胎变形。

**灵感 3（可扩展性 → 车队级证据复用与负迁移绊线）**
直觉：证书与反例不应每台底盘重跑，而应作为“接触契约证据”在车队内广播；新底盘只补差异证据。但错误的复用比不复用更危险：同款底盘共享同一系统性缺陷会导致**相关故障**。因此必须同时具备 **分布外底盘拒绝**、**证据版本/新鲜度** 与 **负迁移绊线**，让复用只在“可证明相似”的区域内发生。

**灵感 4（移动底盘 → 语义-倾覆联合裕度）**
直觉：移动底盘最危险的失效不是静止踩空，而是“语义误判 + 高速转向/侧倾”的耦合：脚掌压上被误判的边界，同时质心投影逼近支撑多边形边缘。语义裕度 `m_s`、倾覆裕度 `m_tip`、摩擦裕度 `m_fric` 必须在**同一时域上取联合最小值**，而不是逐帧分别检查。把三者压成一条约束，护盾才知道“此刻该减速还是该停”。

**灵感 5（可扩展性 → 扩展谱，回答“何时停止迁移”）**
直觉：可扩展性需要可度量，否则只是口号。定义 `Cost(N,H)` 与 `Success(N,H)` 随底盘数 `N`、任务数 `H` 的曲线，拟合扩展指数 `α` 与复用收益 `G_N`。当迁移的边际收益低于重标定成本时，正确动作是 **重标定而非硬迁移**。这把“可扩展”从架构承诺变成可证伪的工程判据。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（底盘配置与支撑多边形）**
底盘配置 `φ = (l, w, h_c, m, μ, s, k) ∈ Φ`：`l/w` 轴距轮距、`h_c` 质心高度、`m` 质量、`μ` 摩擦、`s` 悬挂/轮胎柔度、`k` 运动学类型（轮式/履带/腿式）。位姿 `q=(x,y,θ)`。支撑多边形 `P(φ,q) ⊆ ℝ²` 为当前接触点凸包；非完整约束 `A(q)q̇=0`。归一化倾覆裕度
`m_tip(q,φ) = dist(proj(CoM), ∂P(φ,q)) / r_φ`。

**定义 128（底盘锚定语义-接触契约）**
世界系接触点 `p` 经 `A_b: p ↦ p_b = R(θ)^T(p - t)` 映射到底盘系。接触契约
`CC(Σ;φ) = {(p_b, c, κ̄, m_s^b, conf) | p_b ∈ P^+(φ), κ(Σ̄(p),c) ≥ θ_κ, m_s^b ≥ θ_m(κ̄,c), conf ≥ θ_conf}`，
其中 `P^+(φ)` 为支撑多边形的保守内缩，`m_s^b` 为底盘系下的语义边界裕度。**锚定不变性**：同一 `p_b` 在不同基座位姿下对应同一接触语义条件。

**定义 129（参数化生存核族）**
`K(Σ;φ) = {x | ∃u∈A_WB(φ), λ : f_φ(x,u,λ)=ẋ ∧ supp(λ) ⊆ CC(Σ;φ) ∧ A(q)q̇=0 ∧ λ∈FC(μ) ∧ x'∈𝒳_safe}`。
分解假设 `K(Σ;φ) ≈ K_sem(Σ) ∩ K_dyn(φ)`：`K_sem` 底盘无关，`K_dyn(φ)` 由 `(m,h_c,P,μ,A)` 决定。参数插值
`K̂(Σ;φ) = K_sem(Σ) ∩ Interp_{φ_i∈Φ_cal}(K_dyn(φ_i); φ)`，且只在 `φ ∈ conv(Φ_cal) ⊕ B(ε_φ)` 内可信。

**定义 130（底盘迁移证书）**
`T_{φ→φ'} = (ΔCC, ΔK_margin, ΔM_joint, Δρ_sem, domain_ok, evidence)`：
- `ΔCC = d_H(CC(Σ;φ), CC(Σ;φ'))` 接触契约 Hausdorff 距离；
- `ΔK_margin = |K_margin(φ) - K_margin(φ')|`，`ΔM_joint` 同理；
- `domain_ok = 1[φ' ∈ conv(Φ_cal) ⊕ B(ε_φ)]`。
若 `domain_ok ∧ ΔCC ≤ Θ_c ∧ ΔK_margin ≤ Θ_K ∧ ΔM_joint ≤ Θ_M ∧ Δρ_sem ≤ Θ_ρ`，则迁移可部署；否则触发 **差异重标定**，而非强制外推。

**定义 131（语义-倾覆联合裕度）**
`m_joint(x,Σ;φ) = min(m_s(p), m_tip(x,φ), m_fric(x,λ,μ))`，沿预测时域 `H_p` 取
`M_joint = min_{t∈[0,H_p]} m_joint(x_t,Σ;φ)`。联合护盾要求 `M_joint ≥ θ_j`；这使“边界置信下降”与“转弯过快”在同一个约束里竞争。

**定义 132（车队扩展谱与可扩展判据）**
给定底盘族 `Φ_N={φ_1..φ_N}` 与任务集 `H`：
`σ_ext(N,H) = (Cost(N,H), Success(N,H))`，
`Cost(N,H)=C_0 + Σ_i c_mig(φ_i) + N·H·c_eval`，
`c_mig(φ_i)=c_cal·1[¬domain_ok] + c_verify·1[domain_ok]`，`c_cal ≫ c_verify`。
复用收益 `G_N = (N-1)·c_rebuild - Σ_{i>1} c_mig(φ_i)`；扩展指数 `α` 由 `Cost ∝ N^α` 拟合。
**可扩展** 定义为 `α < 1 且 G_N > 0`；否则应重标定或收缩底盘族。

### IP-127 BCA（Base-Contact Anchoring）

```python
def build_contact_contracts(Sigma, phi, q, kappa, theta):
    CC = set()
    P_plus = erode(support_polygon(phi, q), margin=phi.s)
    M = boundary_margin(Sigma)
    for p in grid(Sigma):
        p_b = to_base_frame(p, q)
        if p_b not in P_plus:                 # 只在支撑多边形保守内缩内
            continue
        l = argmax(Sigma[p])
        if confidence(Sigma[p]) < theta.conf:
            continue
        for c in CONTACT_TYPES:
            if kappa[l][c] >= theta.kappa:
                CC.add((round(p_b, d), c, kappa[l][c],
                        M[p], confidence(Sigma[p])))
    return CC
```

### IP-128 PKF（Parametric Kernel Family）

```python
def parametric_kernel(Sigma, phi, calib_set, K_sem, eps_phi):
    if not in_convex_hull(phi, [c.phi for c in calib_set], eps_phi):
        return None, 'out_of_domain'          # 拒绝外推，触发重标定
    weights = barycentric(phi, calib_set)
    K_dyn = set()
    for x in sample_states(phi):
        if all(feasible_dyn(x, c.phi) for w, c in weights if w > 0):
            K_dyn.add(x)                      # 保守交集：所有邻近底盘都可行
    K_hat = intersect(K_sem, conservative_hull(K_dyn))
    return K_hat, 'ok'
```

### IP-129 CMT（Chassis Migration Test）

```python
def chassis_migration_certificate(CC_src, CC_tgt, K_margin_src, K_margin_tgt,
                                  M_joint_src, M_joint_tgt, rho_src, rho_tgt,
                                  phi_tgt, calib_set, budgets):
    domain_ok = in_convex_hull(phi_tgt, [c.phi for c in calib_set], budgets.eps_phi)
    if not domain_ok:
        return ('recalibrate', 'out_of_domain')
    delta_cc  = hausdorff(CC_src, CC_tgt)
    delta_k   = abs(K_margin_src - K_margin_tgt)
    delta_M   = abs(M_joint_src - M_joint_tgt)
    delta_rho = max(0.0, rho_src - rho_tgt)
    if (delta_cc > budgets.Theta_c or delta_k > budgets.Theta_K
            or delta_M > budgets.Theta_M or delta_rho > budgets.Theta_rho):
        return ('recalibrate', 'contract_drift', delta_cc, delta_k, delta_M, delta_rho)
    return ('ok', ChassisCert(phi_tgt, delta_cc, delta_k, delta_M, delta_rho))
```

### IP-130 JMS（Joint Margin Shield）

```python
def joint_margin_shield(u_nom, x, Sigma, phi, K_in, Hp, theta_j, W):
    u = qp_solve(
        H=W, g=-W @ u_nom,
        constraints=[
            viability_constraint(x, u, K_in),
            nonholonomic_constraint(x, u, phi),        # A(q) qdot = 0
            contact_contract_constraint(u, CC(Sigma, phi)),
            friction_cone_constraint(u, mu=phi.mu),
            tipover_constraint(x, u, phi, margin=theta_j),
            semantic_margin_constraint(x, u, Sigma, margin=theta_j),
        ])
    if u is None or rollout_joint_margin(x, u, Sigma, phi, Hp) < theta_j:
        return safe_brake(x, phi), 'joint_margin_fallback'
    return u, 'ok'
```

### IP-131 FSL（Fleet Scaling Law）

```python
def fleet_scaling_law(Phi, H, history):
    points, acc = [], history.C0
    for N in [1, 10, 100]:
        c = history.C0 + sum(migration_cost(p, history) for p in Phi[:N]) \
            + N * len(H) * history.c_eval
        points.append((N, c))
    alpha = fit_power_law(points)             # Cost ~ N^alpha
    G = reuse_gain(Phi, history)              # 相对逐台重建的节省
    return ScalingLaw(alpha=alpha, G=G, scalable=(alpha < 1.0 and G > 0))
```

### IP-132 EBR（Evidence Broadcast & Reuse）

```python
def evidence_broadcast(phi_new, fleet_evidence, phi_cal, eps_phi):
    if not in_convex_hull(phi_new, phi_cal, eps_phi):
        return ('reject', 'ood_chassis')      # 分布外，禁止复用
    refs = [e for e in fleet_evidence
            if e.phi_distance(phi_new) <= eps_phi and e.fresh()]
    merged = merge_contracts(refs)
    if negative_transfer_tripwire(merged, phi_new):
        return ('reject', 'negative_transfer_risk')
    return ('ok', merged, merge_uncertainty(refs))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| BCA | O(|Ω| + |P|) | O(|CC|) | 锚定变换刚性、支撑多边形保守内缩 |
| PKF | O(|X|·|Φ_cal|·QP) | O(|X|) | 凸包内插值、保守交集 sound |
| CMT | O(|CC|·|P| + |X|) | O(|CC|) | Hausdorff 上界、域判定 sound |
| JMS | O(QP·H_p) 每次 | O(|A_WB|) | 联合裕度保守、回退有界 |
| FSL | O(N·|H|) | O(N) | 成本模型闭合、α 可复现 |
| EBR | O(|E|·|CC|) | O(|E|) | 证据新鲜度、负迁移绊线 sound |

**正确性定理（Semantic-Contact-Chassis Transfer Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** `φ' ∈ conv(Φ_cal) ⊕ B(ε_φ)`，参数插值误差 ≤ `ε_φ`；**(A34)** 接触契约 Hausdorff 迁移误差 ≤ `Θ_c`，且联合裕度保守可算；**(A35)** 联合护盾在不可行时回退 `safe_brake ∈ 𝒳_safe`；**(A36)** 车队证据带版本与新鲜度，负迁移绊线 sound。
则目标底盘部署单步安全概率：
```
P_safe ≥ 1 - P(φ'∉domain) - P(ΔCC>Θ_c) - P(M_joint<θ_j) - P(negative transfer)
```
关键：**只在内插域内迁移、把语义与倾覆压成同一裕度、证据复用带绊线**，三层任一失守都不允许把“同族底盘看起来一样”当作“安全可复用”。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 底盘参数凸包外推失效 | 高 | OOD 拒绝 + 差异重标定，绝不外推 |
| 刚体锚定忽略悬挂/轮胎变形 | 高 | 柔度项 `s` 进参数 + 在线估计接触点漂移 |
| 迁移证书只覆盖静态，动态滚动失稳 | 高 | 时域联合裕度 + 高速/斜坡工况测试 |
| 车队证据过时、语义漂移 | 中 | 证据版本化 + 新鲜度预算 + 定期重验 |
| 同款底盘相关故障 | 高 | 多样性采样 + 独立绊线 + 故障注入 |
| 过度保守导致车队“冻结” | 中 | 裕度预算 + 主动探索 + 分层核 |

## 6. 本轮最大风险

**一句话**：把生存核参数化、把接触契约锚定到底盘系、把证据在车队内复用，能把安全层从“一台车”扩展到“一族车”，但其 soundness **三重依赖参数凸包内插的可信、刚体锚定对悬挂/轮胎变形的近似、以及车队证据与当前底盘分布的一致性**；一旦新底盘只是“参数上看起来在凸包内”却在动态滚动特性上根本不同，迁移证书会放行一个伪相似底盘，使同一套保守护盾在高速转向时集体失效——因此必须以 **OOD 拒绝 + 时域联合裕度 + 负迁移绊线** 三重护栏，宁可重标定，绝不把参数空间的“邻近”当作动力学上的“等价”。

def semantic_contact_certificate(traj, Sigma, kappa, rho_sem, budgets):

def build_contact_contracts(Sigma, phi, q, kappa, theta):

def parametric_kernel(Sigma, phi, calib_set, K_sem, eps_phi):

### IP-129 CMT

```python
def chassis_migration_certificate(CC_src, CC_tgt, K_margin_src, K_margin_tgt,
                                  M_joint_src, M_joint_tgt, rho_src, rho_tgt,
                                  phi_tgt, calib_set, budgets):
    if not in_convex_hull(phi_tgt, [c.phi for c in calib_set], budgets.eps_phi):
        return ('recalibrate', 'out_of_domain')
    delta_cc, delta_k = hausdorff(CC_src, CC_tgt), abs(K_margin_src - K_margin_tgt)
    delta_M, delta_rho = abs(M_joint_src - M_joint_tgt), max(0.0, rho_src - rho_tgt)
    if (delta_cc > budgets.Theta_c or delta_k > budgets.Theta_K
            or delta_M > budgets.Theta_M or delta_rho > budgets.Theta_rho):
        return ('recalibrate', 'contract_drift', delta_cc, delta_k, delta_M, delta_rho)
    return ('ok', ChassisCert(phi_tgt, delta_cc, delta_k, delta_M, delta_rho))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SCG | O(|Ω|·(|L|+|C|)) | O(|Ω|·|L|) | 置信校准、可供性标定 |
| WBV | O(|X|·T·QP) | O(|X|) | 外近似 sound、接触集完备 |
| SSF | O(QP) 每次 | O(|A_WB|) | QP 可行或安全回退 |
| SCC | O(|轨迹|·|Ω|) | O(|Ω|) | δ_s 预算闭合、核心接触非空 |
| BCA | O(|Ω|+|P|) | O(|CC|) | 锚定刚性、支撑多边形保守内缩 |
| PKF | O(|X|·|Φ_cal|·QP) | O(|X|) | 凸包内插值、保守交集 sound |
| CMT | O(|CC|·|P|+|X|) | O(|CC|) | Hausdorff 上界、域判定 sound |
| JMS | O(QP·H_p) | O(|A_WB|) | 联合裕度保守、回退有界 |
| FSL | O(N·|H|) | O(N) | 成本模型闭合、α 可复现 |
| EBR | O(|E|·|CC|) | O(|E|) | 证据新鲜度、绊线 sound |

**正确性定理（Semantic-Contact-Chassis Transfer Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** `φ' ∈ conv(Φ_cal) ⊕ B(ε_φ)` 且参数插值误差 ≤ `ε_φ`；**(A34)** 接触契约 Hausdorff 迁移误差 ≤ `Θ_c`，联合裕度保守可算；**(A35)** 联合护盾不可行时回退 `safe_brake ∈ 𝒳_safe`；**(A36)** 车队证据带版本与新鲜度，负迁移绊线 sound。
则目标底盘部署单步安全概率：
```
P_safe ≥ 1 - P(φ'∉domain) - P(ΔCC>Θ_c) - P(M_joint<θ_j) - P(negative transfer)
```
关键：**只在内插域内迁移**、**语义与倾覆压成同一裕度**、**证据复用带绊线**；任一层失守都不允许把“同族底盘看起来一样”当作“安全可复用”。

## 6. 本轮最大风险

**一句话**：v32 用“底盘锚定接触契约 + 参数化生存核族 + 迁移证书 + 联合裕度护盾 + 车队证据复用”把单机语义安全扩展为车队级安全，但其 soundness **三重依赖参数凸包内插的可信、刚体锚定对悬挂/轮胎变形的近似、以及车队证据与当前底盘分布的一致性**；一旦新底盘在参数上落入凸包却在动态滚动特性上根本不同，迁移证书会放行“伪相似底盘”，让同一套保守护盾在高速转向时集体失效——因此必须以 **OOD 拒绝 + 时域联合裕度 + 负迁移绊线** 三重护栏，宁可重标定，绝不把参数空间的“邻近”当作动力学上的“等价”。
