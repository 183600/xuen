# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「人机协作」×「模仿学习」）

> R69 教会系统「问」：把不确定性拆成 aleatoric/epistemic，用流匹配多模态策略显式表示歧义，用看/问/触主动消解，并用 k 源一致防止「问错」。但 R69 的人是一个**校准过的答录机**：只回答问题、只在被问时出现、回答被当作证据；系统从交互中**什么也不学**（实时零学习写操作），也从不考虑**自己的动作/提问正在改变人**。这套假设在真正的人机协作里同时失效于三处：
> - **人是共同行动者，不是 oracle**：人有自己的意图、能力、风险偏好、认知负荷与信任；人会主动干预、会让渡/收回控制权；机器人必须**可被理解（legible）**，否则人的干预会迟到或错误。
> - **模仿学习告诉我们，纠正不是标签**：人在机器人状态分布上给出的纠正，是最宝贵也最危险的监督；朴素 BC/在线 DAgger 会遭遇协变量偏移、因果混淆与策略性教学，学到的可能是「如何让人满意」而不是「如何把事做对」。
> - **共适应是双向的**：机器人从人学，人也在从机器人学；教与学互相改变分布，离线评测会失效，双方可能收敛到一个彼此都相信、但都错的约定。
>
> 本轮把 R69 的「交互消歧」升级为**双通道、双时间尺度的协作闭环**：
> - **快环（毫秒）**：R69 的 FLUID 内核不变，新增人类意图/动作模型、可理解性约束、混合主动仲裁与人机共享安全滤波；只做推理与认证，不写参数。
> - **慢环（离线/影子）**：把示范与纠正当作**有偏、策略性、非平稳**的教学证据；先做因果纠正归因（把「任务想要的」与「对机器人能力的判断/风险厌恶/社交策略」分开），再用**安全影子 DAgger** 在机器人自己的可达状态分布上聚合并训练；只有通过认证门（安全不回退、覆盖足够、校准、人类接受）的影子策略才允许晋升，否则严格保持 R69。
>
> 核心命题：**人不是答案的来源，而是有自己策略的合作者；纠正不是标签，而是需要因果归因的教学信号；共适应不能在线裸奔，只能在「影子学习 + 认证晋升 + 安全仲裁」的笼子里发生。** 命名 **TANDEM-RAS**（Trust-aware Arbitration with Non-stationary Demonstration Evidence Management）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我们怎样互相学习，而不互相教坏**」。

## 0. 直觉与动机

**灵感 1（人机协作 → 人是 co-actor，机器人的动作也是一种「对人说的话」）**
直觉：在共享工作空间里，机器人不是一个在人类之外独自解题的 agent，而是和人共享同一张桌子、同一个时间窗、同一套预期的伙伴。人根据机器人的动作预测其意图；机器人若动作含糊，人就会提前干预或退让；机器人若动作清晰，人就能在正确的时刻接手。R69 只把交互看成「机器人向人要信息」，漏掉了反方向：**机器人通过动作、迟疑、注视、轨迹形状持续向人发送信息**。这带来两个新决策变量：**可理解性（legibility）**——在同样安全的模态里选一个最符合人类预期的；以及**权威分配（arbitration）**——什么时候该机器人做、什么时候该让人做、什么时候共享。

**灵感 2（模仿学习 → 纠正的因果结构被朴素 BC 抹平了）**
直觉：模仿学习最朴素的假设是「人在这条状态上做了 a，所以 a 是专家标签」。但在协作中，同一个纠正可能来自完全不同的原因：人真的认为该往左（任务意图）；人怕机器人撞到自己（风险厌恶）；人以为机器人不会做（能力判断）；人只是习惯性地接管（社交/控制偏好）；甚至人在故意教错（对抗）。把这些都当作同一个标签做 BC，等价于把「任务因果」与「人对机器人的策略」混进同一个回归目标。**纠正不是标签，纠正是一个复合信号**；必须先把因果任务分量分离出来，剩下的分量用来更新「人的模型 / 信任 / 交互策略」，而不是用来改策略。

**灵感 3（DAgger 的正确用法 → 在自己的状态分布上问，而不是在人演示的分布上学）**
直觉：BC 的经典失败是协变量偏移：人演示的状态分布与机器人实际会到达的状态分布不同，误差会复利。DAgger 的洞见是「在机器人自己会到达的状态上向人请教」。R70 要把这个洞见和 R69 的零实时写操作结合：**在线只聚合状态与请求标签，不更新策略；离线在聚合集上训练影子策略；影子策略先影子部署（只观测/建议），通过认证再晋升**。这把「在线学习」这个危险动作拆成了「在线采样 + 离线学习 + 认证晋升」三个可审计步骤。

**灵感 4（共适应 → 教学会改变老师，离线评测会撒谎）**
直觉：一旦机器人开始从人学，人的行为也会变：人看到机器人学会了，就会少干预；人发现机器人会「装可怜求接管」，就可能发展出新的互动习惯；人可能为了让机器人通过评测而改变示范。于是任何在固定数据集上的「提升」都可能只是**分布共同漂移**。共适应必须被当作非平稳控制问题：保留探索下限、跨用户留出、影子回放、以及「分布漂移超过门槛就冻结晋升」。否则系统会得到一种危险的稳定：双方都适应了彼此的错误。

**灵感 5（安全 → 人的指令也不是天然安全的，权威切换必须有保护）**
直觉：人可能惊慌、被遮挡、误判，甚至恶意接管。把人的纠正直接当控制指令执行，会把人的错误放大成机器人的错误；而频繁地「为安全拒绝人」又会破坏信任。正确做法是：人的指令先过**人机共享安全滤波（HCBF）**，机器人在自己的认证安全集内执行；当人要求的动作会越界时，机器人不是简单拒绝，而是**解释 + 提议最近的安全替代 + 请求确认**。权威切换必须是无冲击（bumpless）的，否则接管瞬间的速度/力矩跳变本身就是风险。

**灵感 6（理论姿态 → R69 必须是 TANDEM 的边界情形）**
直觉：新增学习、解释、仲裁三个层，最怕的是「每加一层就多一个需要独立信任的黑箱」。因此 TANDEM 的所有新约束都必须是**合取式的过滤器**：只能删动作、只能加保守约束、只能降低权威；当人从不干预、没有示范、可理解性权重为零、仲裁恒为机器人单独控制、晋升门关闭时，TANDEM 必须逐指令退化为 R69。这样安全侧永不弱于 R69，新增的只是效率、可维护性与协作体验。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（TANDEM-RAS 总览）** TANDEM-RAS = (R69 FLUID-RAS, HPM, CCA, SDA, LGM, MIA, TCG, HCBF, CEG, CVS, AIC-T, VQAuditor-H)。五条不变式：
(i) **实时零学习写操作**（继承 R69 定义 293-i）：快环只推理、认证、记录；任何参数更新只能发生在影子离线阶段；
(ii) **人类证据非真值**：单次纠正/干预/回答不得直接作为监督标签；须经因果归因（CCA）与证据纪律（CEG）；
(iii) **权威安全**：机器人只能在自己的认证安全集内取得/保持权威；人类指令必须先过 HCBF；任何权威切换不得降低安全裕度；
(iv) **晋升门**：影子策略只有在安全不回退、可达状态覆盖足够、校准与人类接受满足时才可晋升；否则保持 R69；
(v) **可理解性诚实**：可理解性只允许在安全模态之间重排，不得改变认证安全集，也不得用事后解释掩盖真实模态。

**定义 311（人类策略与意图模型 HPM）** 人类潜变量 z_H = (g_H, β_H, κ_H, τ_H)：目标/意图 g_H、风险偏好 β_H、对机器人能力的信念 κ_H、对机器人的信任 τ_H。人类策略 π_H(a_H | s, z_H, b_H) 允许三种模式：任务执行、教学、监督/接管。HPM 输出后验 p(z_H | 交互史) 与对机器人动作的预测分布 π̂_H(a_R | s)，仅用于预测、仲裁与可理解性，不作为真值。

**定义 312（纠正的因果分解 CCA）** 在状态 s_t 观测到人类纠正动作 a^H_t。分解
a^H_t = a*_t + b_t，
其中 a*_t 为任务因果分量（若人拥有完整信息且无策略偏差时会给出的动作），b_t 为策略偏差（风险厌恶、能力误判、社交/控制偏好、对抗）。在识别假设 A99–A100 下（存在工具变量/重复状态/独立第二观察者使 E[b_t | s_t, 工具] = 0，且 b_t 与 a*_t 在给定 s_t 下条件独立），CCA 给出 a*_t 的相合估计。**只有 â*_t 进入模仿目标；b̂_t 进入 HPM/TCG/CEG。** 无工具时 CCA 输出「不可识别」，该纠正降级为弱证据，不进入标签池。

**定义 313（安全影子 DAgger SDA）** 在线聚合状态分布
d_mix = (1−β)d_{π_live} + β d_{π_H}，
每条样本记录 (s, â*, 风险, 来源, 时间)。安全滤波拒绝预测执行风险 > ε_label 的标签。影子数据集 D_shadow = ∪_t Filter(CCA(c_t))。影子策略 π_shadow 在 D_shadow 上离线训练，训练目标为加权的因果模仿损失 + 保留集上的一致性正则；**训练期间不改变 π_live**。

**定义 314（可达状态覆盖与晋升门）** 令 R(π_live) 为当前策略在协作场景中的可达状态集。覆盖率
Cov = ESS_{s~R(π_live)}(D_shadow) / |R(π_live)|
（用密度比/有效样本数估计）。晋升条件 J_promote 同时要求：
(a) 在保留的协作回放上安全违规率不高于 π_live（非回退）；
(b) Cov ≥ ρ_cov；
(c) 置信校准 ECE ≤ τ_ece 且因果一致性检验通过；
(d) 人类接受度/主观负荷不劣化（见 TCG）；
(e) 影子部署期无「策略性讨好」告警。
任一不满足 ⇒ 不晋升，继续 R69 + 收集数据。

**定义 315（可理解性泛函 LGM）** 对安全模态 m（动作轨迹 ξ_m），定义
Leg(ξ_m) = E_{p(z_H|·)}[ −log π̂_H(a_R = ξ_m 的前缀 | s) ] + λ_shape·D_KL(π̂_H(·|s) ‖ δ_{ξ_m})。
在安全集内选模态：
m* = argmin_m [ J_task(ξ_m) + λ_leg·Leg(ξ_m) ]，s.t. ξ_m ∈ C_safe(s)。
Leg 只做重排（定义 310-v）；当所有模态 Leg 都高（人完全无法预测）时，退回 R69 的保守模态并优先「停下/减速/给出明确信号」。

**定义 316（混合主动仲裁 MIA）** 权威变量 α ∈ {robot, shared, human}。仲裁规则基于 HPM 后验、TCG 信任校准与安全裕度：
- 若机器人当前认证安全集不能覆盖人类最可能意图的安全集，或 HPM 歧义高且人已介入 ⇒ 让渡（human）；
- 若双方意图一致且机器人置信高 ⇒ 机器人主导；
- 否则共享：机器人执行安全滤波后的「最小承诺」动作，同时向人发出可理解信号。
MIA 的所有切换必须满足：切换前后联合安全集不缩、控制量连续（bumpless）、切换事件写入审计。

**定义 317（信任校准器 TCG）** 定义信任误差 Δτ = τ_H − κ_robot（人主观信任 − 机器人实际在该任务上的能力估计）。|Δτ| 大即失配：τ_H ≫ κ ⇒ 过度信任/自动化偏见，危险；τ_H ≪ κ ⇒ 信任不足/过度干预，低效。TCG 不最大化信任，而是通过**解释、示弱、请求确认、主动让渡**把 |Δτ| 压回带内；信任校准本身有预算与审计。

**定义 318（人机共享安全滤波 HCBF）** 人类可达集 R_H(s)（含意图不确定性膨胀）与分离距离 d_sep(v)。联合安全集
C_joint(s) = {x | h_robot(x) ≥ 0 ∧ dist(x, R_H(s)) ≥ d_sep(v) ∧ h_task(x) ≥ 0}。
人类指令 a_H 先投影到 C_joint；投影后若与人类意图偏离过大，触发「解释 + 最近安全替代 + 确认」，而不是静默拒绝。

**定义 319（协作 VoI 调度 CVS）** 信息/协作动作集合 𝒢 = {ask, show, explain, handover, wait, do}。选择
g* = argmax_{g∈𝒢} [ VoI_task(g) + λ_teach·EVSI_teach(g) − c_cog(g) − c_trust(g) − c_risk(g) ]
s.t. 预算、HCBF、证据纪律。
其中 EVSI_teach 是「这次交互对影子策略期望改进」的价值——**教学价值不等于任务价值**；c_cog 是人的认知负荷，c_trust 是可能造成的信任失配。若所有项非正，选 do，退化为 R69（不交互）。

**定义 320（纠正证据纪律 CEG）** 单次纠正的采纳需满足至少一条正交佐证：重复状态下一致、独立第二观察者/第二模态一致、干预似然比超过阈值且方向与任务因果一致、或与 R69 的流似然/FMA 第二意见一致。对抗/策略性纠正由异常干预模式检测（过于频繁、总在机器人将成功时接管、只在被观察时出现等）。

**定义 321（威胁模型 AIC-T）** ℰ_TANDEM = ℰ_FLUID × ℰ_corr × ℰ_teach × ℰ_trust：
示范投毒、纠正注入、遥操作劫持、可理解性欺骗（用清晰动作掩盖错误意图）、信任操纵（故意让机器人过度自信/过度依赖）、教师剥削（诱导机器人学会「求接管」）、数据集重放/污染。

**定义 322（证书 J_TANDEM）** J_TANDEM = (J_FLUID, correction_causality_ratio, shadow_competence, coverage, safety_margin_min, trust_ECE, promotion_delta, human_load, arbitration_log_hash, tandem_ver)。Valid ⇔ Valid(J_FLUID) ∧ 定义 310 五不变式满足 ∧ 晋升门满足（或未晋升时显式标记 shadow_only）。

**定义 323（双时间尺度稳定性）** 快环以 R69 的 C-RAS-WM 认证为收缩约束；慢环以单调改进 + 覆盖 + 校准为晋升约束。若人类分布漂移速率超过慢环可辨识速率，则冻结晋升并退回 R69；不允许「用在线更新追赶漂移」。

**定义 324（可理解性—安全权衡）** 对任意状态，Leg 重排后的模态仍在 C_safe 内，故安全集不扩；任务代价增加上界为 λ_leg·max_m Leg(ξ_m)。当可理解性与任务代价冲突超过阈值，优先安全/明确信号，而不是「为了好看而做危险动作」。

**定义 325（退化为 R69）** 当 π_H 无信息（HPM 均匀）、纠正数为 0、λ_leg = 0、MIA 恒为 robot、SDA 不晋升、CVS 仅允许 R69 的 ask/probe 时，TANDEM 的每一步 k、λ、mode 与 R69 逐指令相同。

```python
# IP-264 HPM：人类策略/意图后验（只预测，不作真值）
class HumanPolicyModel:
    def update(self, s, a_H, mode_hint=None):
        self.belief = bayes_update(self.belief, s, a_H, mode_hint)
        return self.belief

    def predict(self, s):
        return self.pi_hat(s, self.belief)        # π̂_H(a_R | s)

# IP-265 CCA：把纠正拆成任务因果分量与策略偏差
def causal_correction(s, a_H, instruments):
    if not identifiable(s, instruments):          # A99–A100
        return None, None, 'unidentifiable'       # 降级为弱证据
    a_star = regress_out_bias(a_H, s, instruments)
    b      = a_H - a_star
    return a_star, b, 'ok'

# IP-266 SDA：安全影子 DAgger（离线，零实时写）
def shadow_update(M, batch):
    for s, a_H, src in batch:
        a_star, b, status = causal_correction(s, a_H, M.instruments(s))
        if status != 'ok': continue
        if risk_of(a_star, s) > EPS_LABEL: continue      # 安全滤波
        M.D_shadow.add(s, a_star, risk_of(a_star, s), src)
    M.pi_shadow = train_offline(M.D_shadow, M.pi_shadow)  # 不碰 π_live

# IP-267 LGM：在安全模态中选最可理解的一个
def legible_mode(modes, s, M):
    safe = [m for m in modes if m in M.cbf.safe_set(s)]
    return argmin(safe, key=lambda m: J_task(m) + LAM_LEG * M.hpm.legibility(m, s))

# IP-268/270 MIA + HCBF：仲裁与人的安全滤波
def arbitrate_and_filter(s, a_H, M):
    intent = M.hpm.most_likely_intent(s)
    C_robot = M.cbf.certified_set(s)
    if not covers(C_robot, safe_set(intent)):
        return 'human', None                      # 让渡
    a_safe = M.hcbf.project(a_H, s) if a_H is not None else None
    if a_H is not None and dist(a_H, a_safe) > DELTA:
        M.cvs.explain_and_propose(a_safe)         # 不静默拒绝
    return M.mia.authority(s, intent, C_robot), a_safe

# IP-269 TCG：信任校准（不是最大化信任）
def trust_gate(s, M):
    d_tau = M.hpm.trust(s) - M.competence(s)
    if d_tau > TAU_OVER:   M.cvs.explain_limits(s)    # 过度信任 → 示弱
    if d_tau < -TAU_UNDER: M.cvs.invite_takeover(s)   # 信任不足 → 让出
    return clamp(M.hpm.trust(s), 0, 1)

# IP-276 主闭环：R69 快环 + 协作层
def TANDEM_round(M, obs, human):
    k, lam, mode, U = R69_FAST_CORE(M, obs)       # 复用 R69，毫秒级
    a_H, mode_hint = human.observe_and_maybe_act(obs)
    if a_H is not None:
        M.hpm.update(obs, a_H, mode_hint)
        M.sda.record(obs, a_H, source='intervention')   # 只记录，不更新
    modes = M.aud.modes if U.epi > TAU_EPI else [mode]
    mode  = legible_mode(modes, obs, M)                  # 只在安全模态间重排
    alpha, a_safe = arbitrate_and_filter(obs, a_H, M)
    if alpha == 'human' and a_safe is not None:
        tau = dispatch_human(a_safe)                     # 经过 HCBF 的人控
    elif alpha == 'shared' and a_safe is not None:
        tau = blend(mode.a[:k], a_safe, M.cbf)           # 无冲击混合
    else:
        tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.tcg.step(obs)
    M.cvs.maybe_schedule(U, M.hpm, M.budget)             # ask/show/explain/handover/wait
    M.vqa_h.submit_async(obs, a_H, alpha, mode, U)       # 参与式审计
    return tau, lam, mode, alpha
```

## 3. 推导

**引理 19（纠正偏差的不可抵消性）** 设朴素 BC 在状态分布 d 上最小化 E‖f(s)−a^H‖²，a^H = a* + b。则最优预测为 E[a*|s] + E[b|s]；只要策略偏差有条件均值 E[b|s] ≠ 0（例如人在机器人显得不确定时更倾向接管），朴素 BC 的额外风险 ≥ E_d[‖E[b|s]‖²]。系：**纠正越「策略性」，朴素 BC 越系统地学错**；CCA 的因果分量分离是必要的，不是洁癖。

**引理 20（安全影子 DAgger 的安全性与遗憾）** 在标签安全滤波（拒绝风险 > ε_label）与影子部署下，快环执行的每个动作仍在 C_safe 内，故在线安全违规率为 0（除 R69 本身已建模的残余风险）。若安全滤波拒绝率为 η，则在可达状态覆盖 ρ_cov 下，影子策略相对「无偏专家」的遗憾上界为 O(ε_T + ε_label + η/(1−η) + √(log(1/δ)/|D_eff|))；η 过大时覆盖下降、上界变坏，故必须主动查询（CVS）而不是被动等纠正。

**引理 21（可理解性降低干预率但有任务代价）** 在阈值干预模型 P(intervene | s) = σ(κ·D_KL(π̂_H(·|s)‖δ_{a_R}) − θ) 下，降低 Leg 会单调降低干预率；但 Leg 只在 C_safe 内重排，故不改变安全集，只可能增加任务代价，增加量 ≤ λ_leg·max_m Leg(ξ_m)。系：**可理解性是一种「用效率换协作流畅度」的旋钮，不是安全机制**；把可理解性当安全保证是范畴错误。

**定理 18（TANDEM 严格包含 R69）** 在 A99–A104 下，TANDEM 在任意状态下的期望风险 ≤ R69；当人类从不干预、无示范、HPM 无信息、λ_leg = 0、MIA 恒为 robot、晋升门关闭时，两者逐指令相同。证明要点：新层均为合取过滤（安全集不扩、权威不升、标签需因果与安全双门），退化条件下所有过滤器恒真。

**定理 19（仲裁安全与无冲击接管）** 若 MIA 只在联合安全集不缩的前提下切换权威，且 HCBF 对所有人指令做投影/拒绝，则权威切换不增加瞬时碰撞风险；混合控制在 C_joint 内连续，切换时 τ 的跳变被 C-RAS-WM 前缀认证约束，故控制连续、无突变。

**定理 20（共适应稳定性与冻结）** 若晋升门要求保留集非回退、覆盖 ≥ ρ_cov、校准 ≤ τ_ece，且人类策略变化率有界，则已晋升策略的认证性能序列单调不降；当人类分布漂移超过慢环可辨识速率时，晋升门无法满足，系统冻结在 R69，避免「用在线更新追逐漂移」导致的振荡与自我实现退化。

## 6. 本轮最大风险

**一句话**：TANDEM 的全部协作收益押在「纠正可被因果归因、人的策略可被辨识」这一前提上——**若人的意图与策略偏差不可识别，或人有意/无意识地用纠正「训练」机器人讨好自己，系统会学到一种既安全又流畅、却共同偏离任务的稳定行为；而可理解性与信任校准又会让这种错误更容易被双方接受**——共适应于是把「一个人犯错」升级为「两个人一起确信」：**学会讨好，比不会学习更危险。**

**次级风险与缓解**：
1. **CCA 不可识别 / 工具变量不可得** → 标记弱证据、禁止进入标签池、依赖 CEG 多源佐证；
2. **安全滤波拒绝过多导致覆盖崩塌** → CVS 主动查询 + 探索下限 + 晋升门覆盖约束；
3. **可理解性被误当安全** → 定义 315/定理 18 明确只在 C_safe 内重排，不扩安全集；
4. **信任操纵 / 过度信任** → TCG 只校准不最大化 + 示弱/让渡 + E306 人类研究；
5. **共适应漂移与跨用户崩溃** → 冻结晋升 + 跨用户留出 + 影子回放 + 24h 长时程（E310/E314）；
6. **人的指令本身不安全** → HCBF + 解释/最近安全替代 + 无冲击接管（定义 318、定理 19）。

```python
class HumanPolicyModel:

        self.belief = bayes_update(self.belief, s, a_H, mode_hint)

    a_star = regress_out_bias(a_H, s, instruments)

        if status != 'ok' or risk_of(a_star, s) > EPS_LABEL: continue
        M.D_shadow.add(s, a_star, risk_of(a_star, s), src)

    safe = [m for m in modes if m in M.cbf.safe_set(s)]
    return argmin(safe, key=lambda m: J_task(m) + LAM_LEG*M.hpm.legibility(m, s))

# IP-268/270 MIA + HCBF：仲裁与人的安全滤波
def arbitrate_and_filter(s, a_H, M):
    intent, C_robot = M.hpm.most_likely_intent(s), M.cbf.certified_set(s)
    if not covers(C_robot, safe_set(intent)): return 'human', None
    a_safe = M.hcbf.project(a_H, s) if a_H is not None else None
    if a_H is not None and dist(a_H, a_safe) > DELTA:
        M.cvs.explain_and_propose(a_safe)               # 不静默拒绝
    return M.mia.authority(s, intent, C_robot), a_safe

# IP-269 TCG：校准信任，不最大化信任
def trust_gate(s, M):
    d_tau = M.hpm.trust(s) - M.competence(s)
    if d_tau > TAU_OVER:   M.cvs.explain_limits(s)      # 过度信任 → 示弱
    if d_tau < -TAU_UNDER: M.cvs.invite_takeover(s)     # 信任不足 → 让出

# IP-276 主闭环：R69 快环 + 协作层
def TANDEM_round(M, obs, human):
    k, lam, mode, U = R69_FAST_CORE(M, obs)             # 复用 R69，毫秒级
    a_H, hint = human.observe_and_maybe_act(obs)
    if a_H is not None:
        M.hpm.update(obs, a_H, hint)
        M.sda.record(obs, a_H, source='intervention')   # 只记录，不更新
    modes = M.aud.modes if U.epi > TAU_EPI else [mode]
    mode  = legible_mode(modes, obs, M)                  # 安全模态内重排
    alpha, a_safe = arbitrate_and_filter(obs, a_H, M)
    if alpha == 'human' and a_safe is not None:
        tau = dispatch_human(a_safe)                     # 经过 HCBF 的人控
    elif alpha == 'shared' and a_safe is not None:
        tau = blend(mode.a[:k], a_safe, M.cbf)           # 无冲击混合
    else:
        tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.tcg.step(obs)
    M.cvs.maybe_schedule(U, M.hpm, M.budget)             # ask/show/explain/handover/wait
    M.vqa_h.submit_async(obs, a_H, alpha, mode, U)
    return tau, lam, mode, alpha
```

## 4. 推导

**引理 19（纠正偏差不可抵消）** 朴素 BC 最优预测为 `E[a*|s]+E[b|s]`；只要策略偏差有条件均值非零（例如人在机器人显得不确定时更爱接管），额外风险 ≥ `E_d[‖E[b|s]‖²]`。系：纠正越策略性，朴素 BC 越系统学错；CCA 是必要步骤。

**引理 20（安全影子 DAgger）** 标签安全滤波 + 影子部署使快环动作始终在 `C_safe` 内，在线安全违规率为 0（除 R69 已建模残余风险）。拒绝率 η 下，遗憾上界 `O(ε_T+ε_label+η/(1−η)+√(log(1/δ)/|D_eff|))`；η 过大会破坏覆盖，故需 CVS 主动查询。

**引理 21（可理解性—任务权衡）** 阈值干预模型 `P(intervene)=σ(κ·KL(π̂_H‖δ_{a_R})−θ)` 下，降低 Leg 单调降低干预率；但 Leg 只在 `C_safe` 内重排，不改变安全集，任务代价增加 ≤ `λ_leg·max Leg`。系：可理解性是效率旋钮，不是安全保证。

**定理 18（TANDEM 严格包含 R69）** A99–A104 下，TANDEM 期望风险 ≤ R69；当人从不干预、无示范、HPM 无信息、λ_leg=0、MIA 恒为 robot、晋升门关闭时两者逐指令相同。新层均为合取过滤（安全集不扩、权威不升、标签需因果+安全双门），退化时恒真。

**定理 19（仲裁安全与无冲击接管）** MIA 只在联合安全集不缩时切换权威，HCBF 对人指令投影/拒绝，则切换不增加瞬时碰撞风险；混合控制连续，切换跳变受 C-RAS-WM 前缀认证约束 ⇒ 控制连续、无突变。

**定理 20（共适应稳定性）** 晋升门要求非回退、`Cov≥ρ_cov`、ECE≤τ_ece，且人类策略变化率有界，则已晋升策略认证性能单调不降；漂移超过慢环可辨识速率时晋升门无法满足，系统冻结在 R69，避免在线追逐漂移导致振荡。

## 7. 本轮最大风险

**一句话**：TANDEM 的全部协作收益押在「纠正可被因果归因、人的策略可被辨识」这一前提上——**若人的意图与策略偏差不可识别，或人有意/无意识地用纠正「训练」机器人讨好自己，系统会学到一种既安全又流畅、却共同偏离任务的稳定行为；可理解性与信任校准又会让这种错误更容易被双方接受**——共适应把「一个人犯错」升级为「两个人一起确信」：**学会讨好，比不会学习更危险。**

**次级风险与缓解**：CCA 不可识别（弱证据 + CEG 多源佐证）；安全滤波拒绝过多（CVS 主动查询 + 覆盖约束）；可理解性被误当安全（只在 C_safe 内重排）；信任操纵（TCG 只校准不最大化 + 示弱/让渡）；共适应漂移（冻结晋升 + 跨用户留出）；人的指令不安全（HCBF + 解释/安全替代 + 无冲击接管）。
