# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「深度学习」×「长程任务」）

> R69 给闭环装上了一张嘴：看不清就看、拿不准就问、质感不明就触。它把 epistemic 不确定性从「只能刹车」升级成「可以求证」，并用流匹配把歧义显式化成多个动作模态。但 R69 有一个未经审视的隐含前提：**疑惑必须在当下结清**——VoI 是在单步、单次交互、单段视界上算的。
>
> 把「长程任务」放进来，这个前提立刻裂开三道缝：(1) **过早付费**——很多歧义世界自己会澄清（物体会靠近、人会开口、光线会变），现在花钱问等于买一份马上免费的信息；(2) **多重检验**——长时程要问成百上千次，R69 的「k 源一致 ≤ α」只是**单次**保证，T 次后错误率趋近 1；(3) **非平稳**——跑几天，表征、标定、流密度都会漂移，而 R68 的铁律是实时环**零学习写**，系统会「越跑越不准」却没有证书过期概念。
>
> 「深度学习」给的钥匙不是更大的网络，而是两条更深的教训：**长视界的瓶颈是 credit assignment 而非容量**，以及**学到的摊销 critic 能替代指数级前瞻**。于是本轮把「不确定性」再升一维：从**标量**（R68）→ **有形状的模态**（R69）→ **有时间结构的债务**（R70）。
>
> 核心命题：**把每个未决歧义记成一笔有截止期的「认知债务」；每笔债有承诺视界 τ_c（再不定就覆水难收）与可辨识视界 τ_id（世界何时免费揭晓）。规则是：能在 τ_c 前免费知道就 defer；免费等不到就在截止前 interact；绝不重复付费。用 TD 时序 VoI 评论家、可辨识视界网络、anytime-valid 证据过程与离线认证晋升，把 R69 的单步、单次、静态世界假设，升级为长时程、全时程、非平稳下的版本。** 命名 **CHRONOS-RAS**（Certified Horizon-aware Resolution Of Non-identifiability with Offline-consolidated Scheduling）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我现在必须知道吗，还是可以等世界自己告诉我**」——不确定性不只有「问」与「不问」，还有「**何时问**」。

## 0. 直觉与动机

**灵感 1（深度学习 → 长视界的瓶颈是信用分配，不是容量）**
直觉：R69 的 VoI 是一步的：问一次，熵降多少。但信息动作的回报常常是延迟且稀疏的——今天多看的一眼，可能在第 40 步避免一次错误分支；今天没问的一句，可能在第 3 步就因不可逆抓取而锁死。长视界把「信息价值」变成典型的**延迟信用分配**问题。深度学习的核心经验是：与其做指数级前瞻（分支 b 的 H 步树是 b^H），不如**学一个摊销的时序价值函数**。于是 R69 的单步 VoI 被替换为一个 TD 训练的 **Q_VoI(s, β, g, h)**：它预测「在剩余视界 h 内采取信息动作 g，期望风险下降减成本」，把远期兑现的回报摊回到当下。

**灵感 2（长程任务 → 不确定性有「时间结构」）**
直觉：人在长任务里不是「一有疑惑就问」。你走进一个昏暗房间，不会立刻问「那是椅子还是衣架」——你会先走近，两秒后自然看清。但如果前方是一个**不可逆**动作（签约、焊接、抓取易碎物、越过临界点），你就必须现在确认。区别不在歧义大小，而在两条时间线谁先到：**自然可辨识时刻 τ_id** 与 **不可逆承诺时刻 τ_c**。若 τ_id 更早，等待是免费信息；若 τ_c 更早，等待就是把风险滚进不可逆点。这把 R69 的「问 vs 不问」升级成「**问 / 等 / 承诺**」的三元决策，而「等」是一种此前被忽略的、有效且零动作的安全策略。

**灵感 3（组合 → 认知债务：延迟不是免单，是计息）**
直觉：defer 不等于遗忘。未决的 epistemic 不会因为你不看它而消失，它像债务一样累积「利息」：越接近 τ_c，同样大小的歧义造成的期望损失越大。于是定义**认知债务 D(t) = Σ w_i U_epi,i κ(τ_c,i − t)**，κ 随截止临近单调上升。交互预算就是「还款能力」；调度目标是在每个债务到期前还清，而不是一有债就还。这直接接上实时系统的 **EDF（最早截止优先）**：可调度性有干净的充要条件，R69 的贪心单步 VoI 只是「所有债务 τ_c≡0」的退化。

**灵感 4（深度学习第二课 → 部署即分布外，证书会过期）**
直觉：跑几天/几周，trunk 表征会漂移、标定会失配、流密度会老化。R68 的证书假设「测量是准的」，但**准确性本身会随时间半衰**。深度学习的经验是：部署即 OOD，必须在线监测漂移。于是引入**证书老化 A(t)** 与半衰期：A 越界即把证书降级为「临时」，限时复验，否则退回 R68 纯保守。这一条正面回应了长程任务最容易被忽视的风险——不是某一步错，而是**整个系统的自信慢慢失真**。

**灵感 5（统计 → 长时程的「多重检验」会吃掉 R69 的证据纪律）**
直觉：R69 的「k 个正交源一致」是单次查询的 α 保证。但一个跑 10^4 步的系统会做上千次判断，即便每次 α=0.05，至少一次假分辨的概率趋近 1（1−0.95^1000 ≈ 1）。长时程必须用**全时程有效（anytime-valid）**的证据过程：e-process / mixture martingale 给出「对任意停时 T，假分辨概率 ≤ α」，配合 online conformal 的非分布假设覆盖。这不是补丁，而是把「证据」从一次性快照变成**持续记账的账户**。

**灵感 6（系统 → 零学习写 × 长程适应：影子学习 + 认证晋升）**
直觉：R68 的实时零学习写不变式救了安全，却与「长程任务必须越跑越好」直接冲突。解法不是破例在线学习，而是**离线整合 + 认证晋升**：影子学习器在回放上更新 IHN/TVC/策略，用 replay 抗灾难遗忘、用安全头锚定防漂移；只有通过 J_CHRONOS 长程复验的版本才被允许晋升进实时环。学习发生在环外，安全发生在环内，二者之间是一道可审计的闸门。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（CHRONOS-RAS 总览）** CHRONOS-RAS = (TEL, IHN, TVC, DSP, AVC, ESC, OCP, LHF, RAS-WM‡)。四不变式：
(i) **实时零学习写**（继承 R68 定义 276-i；学习只发生在 OCP 影子进程）；
(ii) **承诺屏障**：任何不可逆动作执行前，相关账本项必须已结清或 U_epi ≤ τ_commit，且无过期项；
(iii) **延迟可退避**：仅当存在已认证 escape option（定义 319）且 τ̂_id + m ≤ τ_c 时允许 defer；
(iv) **全时程有效**：证据过程的错误率对任意停时 T 一致 ≤ α（定义 318）。

**定义 311（认知账本 TEL）** 账本项 ℓ_i = (M_i, b_i, τ_{c,i}, τ_{id,i}, e_i(t), d_i, w_i)：M_i 为模态假设集，b_i 出生时刻，τ_c 承诺视界，τ_id 可辨识视界，e_i(t) 证据过程（e-value），d_i = b_i + τ_{c,i} − m 为截止时刻，w_i 为对任务价值的影响权重。TEL 是长程闭环的**一等公民**：延迟与结清都必须写入，才能被审计。

**定义 312（承诺视界 τ_c）** τ_c(s, π) = inf{ t ≥ 0 : ∃ a_{t:t+k} 不可逆，且 max_{m,m'∈M} |Q^π(s, a_{t:t+k}, m) − Q^π(s, a_{t:t+k}, m')| ≥ Δ_c }。不可逆性由 R66 权威图与 C-RAS-WM 的换装不变式联合判定（越过该点后，模态选错无法用后续动作补偿）。

**定义 313（可辨识视界 τ_id）** 在**不采取任何信息动作**的自然观测过程下，τ_id = inf{ t : max_{m≠m'} TV(P(o_{t:t+h}|m), P(o_{t:t+h}|m')) ≥ 1−δ }，等价于后验 Bayes 错误率首次 ≤ δ 的时刻。IHN 给出预测 τ̂_id 及其分位上界。**τ_id 是「免费的确定性」到来的时间，是长程任务里真正的免费午餐。**

**定义 314（认知债务与利息）** D(t) = Σ_{i∈open} w_i · U_{epi,i} · κ(τ_{c,i} − t)，κ 单调递增、κ(0⁺) → ∞（临近不可逆点，未决歧义的边际损失爆炸）。延迟不消灭不确定性，只把它挪到更靠近风险点的位置并加上利息。

**定义 315（延迟调度 DSP，三元决策）** 每步在 {defer, interact, commit-conservative} 中选一：
- **defer**：若 τ̂_id + m ≤ τ_c 且 escape option 使 deferred risk ≤ ε_def；
- **interact**：若 τ̂_id + m > τ_c（免费等不到）且 Q_VoI(g*) − c(g*) > 0；
- **commit-conservative**：否则走 R69/R68 兜底（λ 只紧不松）。
未决账本按 d_i 做 **EDF** 排序；可调度性用密度测试 Σ_i c_i/(d_i − t) ≤ B（c_i 为结清该项的期望交互成本，B 为单位时间交互预算）。密度越界 ⇒ 必有着火项，须降级任务或提前保守提交。

**定义 316（时序 VoI 评论家 TVC）** Q_VoI(s, β, g, h) 预测「信念 β 下采取信息动作 g、剩余视界 h 内」的期望风险下降减成本减债务利息，满足 Bellman 一致性：
Q_VoI(s,β,g,h) = r_info(s,β,g) + γ E_{s',β'}[ Q_VoI(s',β', g', h−1) ]，r_info = H(β) − E[H(β'|g)] − c(g) − ΔD。
R69 的一步 VoI 是 h=1 的特例。离线 TD 训练，推理 O(1)；这使长视界 VoI 从 b^H 前瞻变成一次前向。

**定义 317（可辨识视界网络 IHN）** 自监督标签来自长程回放：对每条轨迹，计算模态条件预测首次分歧的时刻 τ_id^obs（两条模态条件 rollout 的预测差首次超过 δ 的时间）。训练回归头 τ̂_id 与分位头 τ̂_id^{1−δ}；后者用于给 deadline 一个**保守上界**。深度学习点：把不可解析的多步可辨识性摊销成一个前向预测。

**定义 318（全时程证据 AVC）** 每个账本项维护 e-value 过程 E_t = Π_{k≤t}(1 + λ_k (X_k − p_0))，λ_k 可预测、有界。Ville 不等式：P(∃t: E_t ≥ 1/α) ≤ α，故「首次 E_t ≥ 1/α 即定案」的全时程 Type-I 错误 ≤ α。配合 online conformal 的预测集覆盖。R69 的 k-源一致是「固定样本 + 单次查询」的退化；长时程必须换成 e-process，否则多重检验会悄悄摧毁证据纪律。

**定义 319（逃逸选项集 ESC）** 延迟期间必须保持一个已认证的安全回退集 O_esc(s)：从任意 defer 轨迹可达、过 C-RAS-WM 前缀认证、风险 ≤ ε_def、不依赖未决模态的身份。O_esc = ∅ ⇒ **禁止 defer**（等待本身变成不可逆）。

**定义 320（离线整合与认证晋升 OCP）** 影子学习器用 replay + 蒸馏 + 安全头 EWC 锚定更新 IHN/TVC/策略。晋升门 PromotionGate：新版本须在长程回放套件上通过 J_CHRONOS 复验、旧任务分数下降 ≤ ε_forget（无灾难遗忘）、漂移检测通过。未晋升前实时环零写入（继承 R68-i）。学习在环外，安全在环内。

**定义 321（证书老化 LHF 与半衰期）** 定义 aging A(t) = α_r·‖Δz‖_trunk + α_c·|Δr_res| + α_f·|Δa_score|；A(t) > τ_age ⇒ 证书降级为「临时」，须在 d_age 内复验，否则退回 R68 纯保守。长程任务里「测量还准吗」会随时间变质，证书必须有保质期。

**定义 322（复合误差界）** H 步累积误差 ≤ (单步误差的几何级数) + O(τ_id 内的自由信息修正)；defer 只把消歧成本移到信息更便宜的时刻，不改变控制误差的一阶项。此界是 E308 的理论锚点。

**定义 323（参与式审计 VQAuditor-H）** 审计「该问未问 / 该等未等」：用 TVC 反事实计算「若在 d_i 前交互」的期望损失差，把长程失败**归因到具体账本项**，结论回灌 OCP 训练——这就是信息动作的深度信用分配闭环。

**定义 324（AIC-CHRONOS 威胁）** ℰ_CHRONOS = ℰ_FLUID × ℰ_defer × ℰ_replay：拖延诱导（伪造「马上会自己澄清」）、截止挤压（用交互淹没预算使关键项过期）、陈旧模态（世界已变而账本仍持旧假设）、回放投毒（污染 OCP 晋升）。

**定义 325（证书 J_CHRONOS）** J_CHRONOS = (J_FLUID, ledger_state_hash, deadline_slack_min, anytime_error, deferral_audit, ihon_ver, tvc_ver, aging_score, consolidation_ver)。Valid ⇔ Valid(J_FLUID) ∧ 无过期账本 ∧ anytime_error ≤ α ∧ aging ≤ τ_age ∧ 实时环版本 = 已晋升版本。

**定义 326（对 R69/R68 的严格退化）** 当 τ_c ≡ 0（每步都不可逆）、α 退化为单次、无 OCP/老化（静态环境）时，CHRONOS 逐指令等于 FLUID-RAS；再令「永不交互」则等于 CALM-RAS。安全侧只增不减：新增的 defer 只有在 ESC 认证下才被允许。

```python
# IP-264 TEL：认知账本（延迟/结清都是一等记录）
class EpistemicLedger:
    def insert(self, M, t, tau_c, tau_id, w):        # 新歧义入账
        self.open.append(Item(M, birth=t, tau_c=tau_c, tau_id=tau_id,
                              deadline=t + tau_c - MARGIN, w=w, e=1.0))
    def density_ok(self, B):                          # EDF 可调度性（定义 315）
        return sum(it.cost / max(it.deadline - self.now, EPS)
                   for it in self.open) <= B
    def overdue(self):
        return [it for it in self.open if it.deadline <= self.now]

# IP-265 IHN：可辨识视界预测（自监督标签来自长程回放，定义 317）
def predict_tau_id(ihn, z, context):
    mu, q = ihn(z, context)                           # 中位数 + (1−delta) 分位
    return mu, q                                      # q 用于保守 deadline

# IP-266 TVC：时序 VoI 评论家（离线 TD，推理 O(1)，定义 316）
def temporal_voi(tvc, s, beta, g, h):
    return tvc(s, beta, g, h)                         # 已摊销的 h 步 VoI−成本−利息

# IP-267 DSP：defer / interact / commit 三元决策（EDF 调度）
def schedule_step(s, beta, ledger, esc, budget, tvc, ihn):
    ledger.advance(now=s.t)
    if ledger.overdue():                              # 着火：不许再等
        return ('interact_or_conservative', ledger.earliest_deadline())
    tau_id, tau_id_ub = ihn(s.z, s.context)
    tau_c = commitment_horizon(s, beta)               # 定义 312
    if tau_id_ub + MARGIN <= tau_c and esc.certified(s):
        return ('defer', None)                        # 免费信息先于不可逆点
    g = argmax_g(temporal_voi(tvc, s, beta, g, h) for g in candidates(beta))
    if temporal_voi(tvc, s, beta, g, h) > 0 and budget.allow(g) \
       and c_ras_wm.certify_info(g, s):
        return ('interact', g)
    return ('commit_conservative', None)              # R69/R68 兜底

# IP-268 AVC：全时程有效证据（e-process，定义 318）
def update_evidence(item, x_k, lam_k):
    item.e *= (1.0 + lam_k * (x_k - P0))
    return item.e >= 1.0 / ALPHA                       # 首次越界即定案，全时程 ≤ alpha

# IP-270 OCP：离线整合 + 认证晋升（实时环零写入，定义 320）
def offline_consolidate(shadow, replay, gate):
    shadow.fit(replay, anchors=SAFETY_HEADS)          # replay 抗遗忘 + EWC 锚定
    if gate.revalidate(shadow, long_horizon_suite) \
       and gate.no_forget(shadow) and gate.drift_ok(shadow):
        return promote(shadow)                         # 仅晋升版本可进实时环
    return None

# IP-275 主闭环（继承 R69，仅在不确定性处置处插入时间层）
def CHRONOS_RAS_round(M, obs):
    z, o = M.mtm.forward(obs)                          # R68/R69 一次前向
    c, U_cal, thr = M.cof.step(...)
    beta = M.aud.decompose(M.fmp.sample(o, K=adaptive_K(z)), z)   # R69 模态信念
    M.tel.insert(beta.modes, t=now, w=task_weight(...),
                 tau_c=M.tvc.commitment_horizon(...),
                 tau_id=M.ihn.predict_tau_id(z, context)[1])
    action, g = M.dsp.schedule_step(z, beta, M.tel, M.esc, M.budget, M.tvc, M.ihn)
    if action == 'defer':
        U_floor = beta.U_ale                          # 等：只对 aleatoric 收紧
    elif action == 'interact':
        ans = M.cia.execute(g); beta = M.cia.update_belief(beta, ans)
        M.avc.update(M.tel, ans.evidence)             # anytime-valid 记账
        U_floor = beta.U_ale + beta.U_epi_unresolved
    else:
        U_floor = beta.U_ale + beta.U_epi             # 保守提交
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    if M.lhf.aging(z) > TAU_AGE:                      # 证书老化：降级为临时
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(...))
    mode = select_mode(beta.modes, beta.U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_h.submit(action, g, beta, M.tel.snapshot()) # 延迟也要被审计
    return k, lam, mode, (beta.U_ale, beta.U_epi)
```

## 3. 推导

**引理 19（免费信息占优 / Deferral Dominance）** 在 A99（存在认证 ESC，且 τ̂_id^{1−δ} + m ≤ τ_c）下，defer 的期望风险 ≤ 立即 interact 的期望风险，且期望成本严格更低（当 c(g)>0）。(a) 自然观测在 τ_id 处已使模态 Bayes 误差 ≤ δ，与是否交互无关；(b) τ_c 之前无不可逆动作，故不存在「带歧义承诺」的损失；(c) ESC 保证 defer 窗口内风险 ≤ ε_def。**系：只有当免费信息晚于不可逆点，交互才值钱**——R69 的「有歧义就问」在长程任务里是过度支付。

**引理 20（EDF 认知债务可调度性）** 若所有账本项 deadline 明确、可抢占（可在任意步插入一次交互）、密度 Σ_i c_i/(d_i − t) ≤ B，则 EDF 可在所有截止前结清；若密度 > B，则必有一项错过截止，系统必须降级任务或提前 conservative commit。**系：交互预算的真正约束不是「每步多少次」，而是「债务密度」；长程任务里应主动限制同时未决的歧义数。**

**引理 21（全时程证据控制）** 单次查询的 k-源规则在 T 次独立判断后的假分辨率为 1−(1−α)^T → 1；e-process + Ville 不等式给出的任意停时界为 P(∃t ≤ T: E_t ≥ 1/α) ≤ α，对 T 一致。例如 α=0.05、T=1000 时前者≈1，后者仍 ≤ 0.05。**系：长时程下「证据纪律」必须从快照变为账户，否则 R69 的 k-源一致性会被多重检验悄悄掏空。**

**引理 22（TVC 摊销误差与前瞻对比）** 在 A101（回放覆盖）下，TD 评论家的一次查询误差 ≤ ε_TD + γ^h ε_boot；而枚举 h 步、每步 b 个信息动作的前瞻成本为 O(b^h) 且误差随模型偏差指数放大。故长视界下 TVC 以 O(1) 时间获得「不爆炸」的 VoI 估计；当 h=1 时二者一致（R69 特例）。

**引理 23（拖延投毒的暴露窗口有界）** 若攻击者伪造「马上会自己澄清」（压低 τ̂_id）或淹没预算（推高债务密度），则要么 τ_id 预测残差在复验中暴露，要么密度测试越界或 deadline_slack_min < 0，二者都触发保守回退；其可维持的欺骗窗口 ≤ d_age（证书复验周期）。**系：延迟的静默性被「账本 + 老化 + 密度」三件套强制显式化。**

**定理 18（CHRONOS 严格包含 R69）** 在 A99–A102 下，CHRONOS 的期望风险 ≤ FLUID-RAS；且当 τ_c ≡ 0、α 退化为单次、环境静态时逐指令相同（定义 326）。R68/R69 是「从不延迟」边界上的退化；安全侧不新增任何让步（defer 仅在 ESC 认证下开放）。

**定理 19（长程安全与无突变）** 承诺屏障确保不可逆动作前 U_epi ≤ τ_commit；ESC 保证 defer 窗口内风险 ≤ ε_def；证书老化越界即退回 R68 纯保守；换装不变式（R68 定理 15）保持 ⇒ 全程控制连续、模态切换无突变、最坏风险 ≤ R69 + ε_def。

**定理 20（全时程有效性与无遗忘晋升）** AVC 给出全部署期假分辨概率 ≤ α；OCP 的 PromotionGate 保证实时环中运行的每个版本都满足 J_CHRONOS 且旧任务退化 ≤ ε_forget。故系统可跨周/月持续改进，而不会因一次坏更新或一次多重检验把「诚实的不知道」变成「被证实的错误」。

## 6. 本轮最大风险

**一句话**：CHRONOS 的收益押在「**τ_id 与 τ_c 的预测是可信的**」这一前提上——若可辨识视界被**低估**（系统以为世界马上会自己说清楚，其实永远不会），或承诺视界被**高估**（以为还有退路，其实已覆水难收），系统就会**自信地拖过不可逆点**；而延迟不产生动作、不留痕迹，这种失败要到覆水难收那一刻才爆——**问错会留下日志，拖错只会留下废墟，该问不问比问错更隐蔽、更危险。**

**次级风险与缓解**：
1. **τ_id 低估 / 拖延投毒**（伪造「马上会澄清」）→ 分位保守上界 + 引理 23 暴露窗口界 + 账本强制显式化 + E312；
2. **截止挤压与多重检验**（交互预算被淹没、k-源规则失效）→ 债务密度测试 + EDF + anytime-valid e-process（定义 318、引理 20–21）；
3. **等待本身不可逆**（无安全回退）→ ESC 非空是 defer 的硬前提（定义 319）+ E307；
4. **证书老化被忽视**（越跑越自信地错）→ LHF 老化分 + 半衰期强制复验（定义 321）+ E309；
5. **离线整合灾难遗忘 / 回放投毒**（越学越差或学坏）→ PromotionGate + replay + EWC 锚定 + 无遗忘门槛（定义 320、定理 20）+ E310–E313；
6. **长视界复合误差**（R69 单步保证逐级放大）→ 定义 322 复合误差界 + E308；必要时提前 conservative commit。

```python
# IP-264 TEL：认知账本
class EpistemicLedger:
    def insert(self, M, t, tau_c, tau_id, w):
        self.open.append(Item(M, birth=t, tau_c=tau_c, tau_id=tau_id,
                              deadline=t + tau_c - MARGIN, w=w, e=1.0))
    def density_ok(self, B):
        return sum(it.cost / max(it.deadline - self.now, EPS)
                   for it in self.open) <= B
    def overdue(self):
        return [it for it in self.open if it.deadline <= self.now]

# IP-267 DSP：defer / interact / commit 三元决策（EDF）
def schedule_step(s, beta, ledger, esc, budget, tvc, ihn):
    ledger.advance(now=s.t)
    if ledger.overdue():
        return ('interact_or_conservative', ledger.earliest_deadline())
    tau_id, tau_id_ub = ihn(s.z, s.context)            # 中位数 + 保守分位

    return ('commit_conservative', None)              # R69/R68 兜底

    if action == 'defer':
        U_floor = beta.U_ale                          # 等：只对 aleatoric 收紧
    elif action == 'interact':
        ans = M.cia.execute(g); beta = M.cia.update_belief(beta, ans)
        M.avc.update(M.tel, ans.evidence)
        U_floor = beta.U_ale + beta.U_epi_unresolved
    else:
        U_floor = beta.U_ale + beta.U_epi             # 保守提交
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    if M.lhf.aging(z) > TAU_AGE:
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(...))
    mode = select_mode(beta.modes, beta.U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_h.submit(action, g, beta, M.tel.snapshot())  # 延迟也要被审计
    return k, lam, mode, (beta.U_ale, beta.U_epi)
```

## 4. 推导

**引理 19（免费信息占优）** A99（存在认证 ESC 且 τ̂_id^{1−δ}+m ≤ τ_c）下，defer 的期望风险 ≤ 立即 interact，且期望成本严格更低（c(g)>0）。自然观测在 τ_id 已使 Bayes 误差 ≤ δ；τ_c 前无不可逆动作；ESC 保证 defer 窗口风险 ≤ ε_def。**系：只有免费信息晚于不可逆点时交互才值钱；R69 的「有歧义就问」在长程里是过度支付。**

**引理 20（EDF 可调度性）** deadline 明确、可抢占、密度 `Σ c_i/(d_i−t) ≤ B` ⇒ EDF 可在全部截止前结清；密度越界 ⇒ 必有着火项，须降级任务或提前保守提交。**系：预算的真约束是债务密度，不是每步次数。**

**引理 21（全时程证据控制）** 单次 k-源规则在 T 次后假分辨率 `1−(1−α)^T → 1`；e-process 给出任意停时 `P(∃t≤T: E_t ≥ 1/α) ≤ α`。α=0.05、T=1000 时前者≈1、后者 ≤ 0.05。**系：证据纪律必须从快照升级为账户。**

**引理 22（TVC 摊销 vs 前瞻）** A101（回放覆盖）下 TD 查询误差 ≤ `ε_TD + γ^h ε_boot`；枚举前瞻成本 `O(b^h)` 且误差随模型偏差指数放大。h=1 时二者一致。

**引理 23（拖延投毒暴露窗口）** 伪造 τ_id 或淹没预算，会分别触发预测残差复验或密度/截止松弛监控；欺骗窗口 ≤ d_age。**系：延迟的静默性被「账本 + 老化 + 密度」强制显式化。**

**定理 18（严格包含 R69）** A99–A102 下期望风险 ≤ FLUID-RAS；τ_c≡0、单次证据、静态环境时逐指令相同。R68/R69 是「从不延迟」边界；安全侧不新增让步。

**定理 19（长程安全与无突变）** 承诺屏障保证不可逆前 U_epi ≤ τ_commit；ESC 保证 defer 窗口风险 ≤ ε_def；老化越界退回 R68；换装不变式保持 ⇒ 控制连续、无突变，最坏风险 ≤ R69 + ε_def。

**定理 20（全时程有效与无遗忘晋升）** AVC 使全部署期假分辨 ≤ α；PromotionGate 保证实时环每个版本满足 J_CHRONOS 且旧任务退化 ≤ ε_forget。系统可跨周/月改进，而不会因一次坏更新或一次多重检验把「诚实的不知道」变成「被证实的错误」。

## 7. 本轮最大风险

**一句话**：CHRONOS 的全部收益押在「**τ_id 与 τ_c 的预测可信**」这一前提上——若可辨识视界被低估（以为世界马上会自己说清，其实永远不会）或承诺视界被高估（以为还有退路，其实已覆水难收），系统就会**自信地拖过不可逆点**；延迟不产生动作、不留痕迹，这种失败要到覆水难收才爆——**问错会留下日志，拖错只会留下废墟，该问不问比问错更隐蔽、更危险。**

**次级风险与缓解**：τ_id 低估 / 拖延投毒（分位保守上界 + 引理 23 暴露窗口 + 账本显式化 + E312）；截止挤压与多重检验（债务密度 + EDF + anytime-valid e-process）；等待本身不可逆（ESC 非空为 defer 硬前提 + E307）；证书老化（LHF 老化分 + 半衰期复验 + E309）；离线整合遗忘/回放投毒（PromotionGate + replay + EWC + 定理 20 + E310–E313）；长视界复合误差（定义 322 + E308，必要时提前保守提交）。
