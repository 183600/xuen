## 1. 两个灵感的第一性原理

### 灵感 1 ·「成本控制」→ 计算是一种要花预算的行动

**直觉**：机器人不是「想得越多越好」。每多跑一次断言、一次视觉伺服、一次世界模型 rollout、一次失败介入，都要付出延迟、算力、风险或标注成本；而赛制是实时评测，预算有限。成本控制的正确姿势不是「全部砍掉」，而是**在预算约束下把计算分配到边际收益最高的地方**。

**严谨骨架**：

- 每个组件声明**成本向量** `c = (ℓ 延迟, r 风险, m 算力, d 标注/数据)`，全局预算 `B`；
- 目标从 `max E[success]` 变为**约束 MDP**：`max E[success] s.t. E[Σc] ≤ B`；拉格朗日形式 `max E[success − λ·c]`，`λ ≥ 0` 是预算的**影子价格**；
- **计算价值（VOC）**：`VOC_c(s) = V_c(s) − V_0(s) − λ·τ_c`，只有 `VOC_c(s) > 0` 才「买」这次计算（metareasoning / optimal stopping）；
- **成本敏感阈值**：介入与否由后验失败概率与两类错误成本决定，`p*_s = c_FP(s) / (c_FP(s) + c_FN(s))`——上轮「高精度低召回」只是 `c_FP ≫ c_FN` 的特例，**在终结态 `c_FN` 极高时阈值应下调**；
- **评估也有成本**：用序贯检验（SPRT）替代固定 N 次 A/B，在同等 α/β 下减少样本量。

**策略含义**：把上轮散落的「延迟预算、β 门控、介入保守、E622 门槛、代理评测」全部收编到同一个 `λ` 与 VOC 框架下；λ 可调即得「成功率—成本」帕累托前沿，而不是拍脑袋的固定超参。

### 灵感 2 ·「状态机」→ 把路标/断言/介入从散落规则变成可验证控制器

**直觉**：上轮 IP-09 实际上已经是一个**隐式状态机**——路标是状态，断言是迁移守卫，介入是失败迁移。显式化不是为了好看，而是为了四件事：**守卫可验证、切换可滞回、超时可兜底、恢复可审计**。更重要的是，状态外置在控制器里、不写进权重，天然满足「单 checkpoint」合规，并让 `reset()` 的语义变得干净。

**严谨骨架**：

- **分层状态机** `H = (S, s_0, A, →, G, C)`：任务层（waypoint 序列）→ 技能层（grasp / align / insert 子 FSM）→ 恢复层（retry / regrasp / re-align / **escape**）；
- **option / SMDP 视角**：每个路标是一个 option，带期望时长与 **cost-to-go** `C(s)`；状态机的期望成本可递推，因而预算可事前规划；
- **守卫**：`g: Obs × B_remaining → {0,1}`，带滞回（防抖振）与超时（防死锁）；
- **安全阀 `escape`**：当相位序列超出路标词汇表、或连续守卫失败时，回退纯 VLA（Level-1.5）——这是防止「状态机把学习策略天花板钉死」的必要结构。

**策略含义**：FSM 不是替代 VLA，而是**给 VLA 套一个可审计的执行外壳**；它的价值在于把「最后一厘米」和「失败恢复」变成显式、可测、可复现的控制问题。

### 交汇 · 成本感知分层状态机（CA-HSM）

状态决定「该不该买计算」，成本决定「买到什么程度」：

| 上轮机制 | 本轮统一解释 |
|---|---|
| IP-09 的 β 混合门控 | VOC 的**连续版**：`β = argmax_β [V(β) − λ·τ_servo(β)]` |
| IP-02 的介入准则 | VOC 的**离散版**：`intervene iff p_fail > p*_s` |
| IP-10 的 rollout 预验证 | **高成本 VOC**：只有离线或 `VOC > 0` 且预算允许才跑 |
| IP-06 的代理评测 | **元层成本**：用 SPRT 决定「还要不要再评一轮」 |
| IP-12 的课程/replay | **训练成本**：以「每单位分数的训练成本」而非绝对分数排序 |

一句话：**成本敏感阈值 + 状态 = 每个状态不同的 p\***。终结态失败代价高 → 阈值低；正常推进态误介入代价高 → 阈值高。

## 2. 研究问题（新增 Q10–Q13，接上轮 Q1–Q9）

- **Q10（成本模型可辨识性）**：在只有延迟/成功率观测的条件下，各状态的 `c_FP / c_FN / τ` 能被估计到什么精度？λ 的合理区间有多宽？成本估计误差如何传导到成功率（E628/E634）？
- **Q11（状态机的表达力上限）**：显式 FSM + 有限路标词汇表 `L(W)` 是否会成为策略天花板？真实任务的相位序列落在 `L(W)` 之外的比例有多高？`escape` 状态能否把上限损失压到可忽略（E629/E632）？
- **Q12（VOC 门控的净收益）**：在**同等成本预算**下，VOC 自适应计算相对固定调度能多拿多少成功率？VOC 的估计偏差多大时会反噬（E630/E634）？
- **Q13（评估成本的压缩）**：序贯检验在保持决策一致性的前提下能省多少代理评测样本？不当的「边跑边看」会不会膨胀一类错误（E633）？

## 3. 设计原则（新增 P10–P12，接上轮 P1–P9）

- **P10（成本显式化）**：任何新组件上线前必须声明成本向量与预算上界；**不存在无界组件**。成本默认按「每 episode 延迟 + 每千次调用算力 + 误动作风险」记账。
- **P11（状态外置）**：策略状态放在控制器（可枚举、可清零、可审计），不放进权重；`reset()` 必须能证明把全部控制器状态清零。跨 episode 记忆（IP-11）仍为条件项，不因状态机而放宽。
- **P12（价值优先于成本）**：只有当 `VOC ≤ 0` 时才砍成本；**严禁为账面节约牺牲护城河组件**（伺服、断言、评测栈）。每笔「省钱」必须附带「成功率不变差」的证据，否则视为假节约。

## 5. 本轮最大风险（更新）

上轮「合成负样本假安全」与「抓握漏判不对称」继续成立；本轮叠加一条**结构性风险**：

**成本模型与状态机的双重先验错配**：λ 估错会把预算从真正产生分数的伺服/断言上抽走（假节约）；守卫阈值写死会把学习策略的天花板钉在人工路标语言之内（硬先验）。两者叠加时，系统会以「更省钱、更可控」的假象，稳定地输给一个什么都不管的端到端基线。对冲：P12 禁止砍护城河、E632 专测天花板、escape 状态 + 守卫软化为概率型、λ 只在 E628 校准区间内使用。

## 2. 新增 / 升级 IP 详述

### IP-13 · CA-HSM 成本感知分层状态机（P0，升级自 IP-09）

- **动机**：上轮 IP-09 的路标 + 断言 + 介入已是隐式状态机，但规则散落、阈值全局、失败恢复无结构；显式化后可验证、可滞回、可超时、可审计，并让 `reset()` 语义干净。
- **结构**：三层嵌套——
  1. **任务层**：`W(τ) = (w_1..w_K)` 路标序列（option 序列）；
  2. **技能层**：每个路标内部子 FSM（如 grasp: approach → close → verify → lift）；
  3. **恢复层**：retry / regrasp / re-align / **escape**（回退纯 VLA）。
- **差异**：v2 是「VLA + 伺服」的单一循环；v3 是「VLA 作为状态机里的一个动作源」，状态与守卫显式、成本可记账。仍是单 checkpoint、单 API、无新增字段。
- **可行性**：高。守卫多为几何/视觉判据；阶段标注复用 IP-06，并用自监督分割降标注成本（E636）。
- **步骤**：①建「任务 → HSM 模板」库与覆盖率验收（E629）；②守卫参数化 + 滞回 + 超时；③escape 判定（序列越界或连续守卫失败）；④与 IP-14 对接（β 由 VOC 定）；⑤难任务 A/B 与天花板测试（E632）。
- **风险**：①硬先验压天花板 ⇒ escape + 概率守卫（L13）；②守卫过拟合代理评测 ⇒ 只认真机/半真值复核；③状态泄漏跨 episode ⇒ 每 episode 显式清零并做泄漏测试（P11）。

### IP-14 · VOC-Gate 计算价值门控（P0，新）

- **动机**：伺服、rollout、介入各有成本，却没有共同货币；上轮只能靠固定超参分别拍板。
- **机制**：估计每次候选计算的期望价值增益 `ΔV` 与成本 `τ`，当 `ΔV > λ·τ` 才执行；λ 为预算影子价格，由 E628/E634 校准。β 混合、介入、rollout 预验证、评估早停全部是同一判据的不同实例。
- **差异**：把「成本控制」从工程护栏变成**运行时决策**；与 IP-13 共用状态，因此 `ΔV` 可按状态条件化（终结态更愿买计算）。
- **可行性**：中。`ΔV` 估计器是轻量回归/不确定性头，先离线标定，再在线用保守下界（避免过度自信地买计算）。
- **步骤**：①定义成本向量与预算（U16）；②离线拟合 `ΔV` 代理（以专家修正与成功标签为监督）；③在线用保守估计 + 滞回；④等预算 A/B（E630）；⑤λ 扫描得帕累托前沿（E634）。
- **风险**：`ΔV` 高估 → 超预算且抖振；低估 → 假节约（P12 红线）。对冲：保守下界 + Level-1.6 回退。

### IP-15 · SequentialEval 序贯评测（P1，新）

- **动机**：代理评测（IP-06）与真机 A/B 都贵；固定 N 次在效应明显时浪费，在效应微弱时又不够。
- **机制**：对「A 优于 B」的假设做 SPRT/置信序列检验，累计对数似然比越过边界即停；边界由预注册 α/β 固定，避免「边跑边看」膨胀一类错误。
- **差异**：把「评多少轮」也纳入成本控制（元层 VOC）；与 IP-06 的六因子诊断共享样本。
- **可行性**：高（统计工具成熟）。
- **步骤**：①定义 per-episode 对数似然与边界；②与固定 N 在历史代理评测数据上回放对比（E633）；③预注册 α/β 与停止规则，禁止事后改边界。
- **风险**：非独立样本（episode 相关）破坏 i.i.d. 假设 ⇒ 用块序贯/混合效应模型，或只用于粗筛。

## 3. 符号与定义（新增 U16–U20；U1–U15 沿用）

- **定义 U16（成本向量与预算）**：组件 `c` 的成本 `κ(c) = (ℓ, r, m, d)` 分别对应延迟、风险、算力、标注/数据；预算 `B` 为各维上界向量；成本-to-go `C(s) = E[Σ κ | s]`。
- **定义 U17（分层状态机）**：`H = (S, s_0, A, →, G, C)`，`S = S_task × S_skill × S_rec`；迁移 `(s,a,s') ∈ →` 由守卫 `g ∈ G` 使能，`g: Obs × B_remaining → {0,1}`，带滞回与超时；`escape ∈ S_rec` 为回退纯 VLA 的安全阀。
- **定义 U18（影子价格与计算价值）**：`λ ≥ 0` 为预算对偶变量；对候选计算 `c`，`VOC_c(s) = V_c(s) − V_0(s) − λ·τ_c`，其中 `V_0` 为不买该计算的默认策略价值，`τ_c` 为其成本标量；**买当且仅当 `VOC_c(s) > 0`**。
- **定义 U19（成本敏感阈值）**：状态 `s` 下介入当且仅当 `p_fail(s) > p*_s`，`p*_s = c_FP(s) / (c_FP(s) + c_FN(s))`；`c_FP` 为误介入成本（打断正常执行），`c_FN` 为漏判成本（整段失败）。
- **定义 U20（相位语言与覆盖）**：`L(W)` 为路标词汇表 `W` 生成的所有合法相位序列集合；覆盖率 `ρ = P(τ 的真实相位序列 ∈ L(W))`；`escape` 在序列越界或守卫连续失败时激活。

## 4. 关键算法骨架（新增片段；主体沿 `UniBotSAGEPolicy`）

```python
# ===== IP-13 + IP-14: CA-HSM 主循环 =====
class CAHSM:
    def __init__(self, hsm, lam, budget):
        self.hsm, self.lam, self.budget = hsm, lam, budget
        self.state = hsm.initial()          # 每 episode 必须 reset()

    def reset(self):
        self.state = self.hsm.initial()     # P11: 状态外置、逐 episode 清零

    def step(self, obs, task_token, spent):
        s = self.state
        # 1) 便宜守卫优先：O(1) 断言，始终执行
        for tr in self.hsm.transitions[s]:
            if tr.guard(obs) and tr.cost_within(self.budget - spent):
                self.state = tr.next
                return self.hsm.emit(tr)     # 迁移动作（如进入 align）
        # 2) 失败/超时 → 恢复层
        if self.hsm.timed_out(s, obs) or self.hsm.guard_failed(s, obs):
            self.state = self.hsm.recover(s, obs)   # retry/regrasp/escape
        # 3) 昂贵计算：按 VOC 决定是否购买
        a_vla = self.model.act(obs, task_token, self.hsm.phase(s))
        beta, u_servo = 0.0, None
        if should_compute("servo", s, obs, self.lam):
            u_servo = self.servo(self.hsm.anchor(s), obs)
            beta = self.hsm.gate(s, obs)            # 连续版 VOC
        a = a_vla if u_servo is None else (1 - beta) * a_vla + beta * u_servo
        return a

def should_compute(comp, s, obs, lam):
    dv = value_gain_lower_bound(comp, s, obs)       # 保守下界，防高估
    tau = cost_scalar(comp, s)                      # ℓ + λ_r·r + ...
    return dv > lam * tau                           # U18: VOC > 0
```

```python
# ===== IP-02: 状态相关成本敏感阈值 =====
def intervene(p_fail, s, cost_table):
    c_fp, c_fn = cost_table[s.phase]                # 误介入 / 漏判
    return p_fail > c_fp / (c_fp + c_fn)            # U19: p*_s

# ===== IP-15: SPRT 序贯评测 =====
def sequential_ab(xs, alpha, beta, llr_fn):
    lo = math.log(beta / (1 - alpha))
    hi = math.log((1 - beta) / alpha)
    llr = 0.0
    for x in xs:                                    # 预注册 α/β，边界固定
        llr += llr_fn(x)
        if llr >= hi: return "H1"
        if llr <= lo: return "H0"
    return "continue"
```

## 5. 推导（新增 L11–L14；L1–L10 沿用）

**引理 L11（状态相关成本敏感阈值）** 设状态 `s` 下失败后验为 `p`；介入的期望成本为 `(1−p)·c_FP`（误介入），不介入为 `p·c_FN`（漏判）。则最优介入当且仅当
`(1−p)c_FP < p c_FN ⇔ p > c_FP/(c_FP+c_FN) = p*_s`。
且 `∂p*_s/∂c_FN < 0`、`∂p*_s/∂c_FP > 0`：**终结态漏判代价越高，阈值越低**。上轮「高精度低召回」只在 `c_FP ≫ c_FN` 时成立，不能全局套用。∎

**引理 L12（VOC 与预算对偶）** 对约束问题 `max E[Σr] s.t. E[Σκ] ≤ B`，若成本可标量化且约束紧，存在 `λ* ≥ 0` 使无约束 `max E[Σ(r − λ*κ)]` 的解满足约束（KKT）。若各候选计算的 `ΔV_i` 相互可分，则按 `ΔV_i/τ_i` 降序购买至预算耗尽为最优（分数背包）；若存在次模交互，贪心达 `1−1/e` 近似。**推论**：VOC 门控不是启发式，而是预算约束下的对偶最优；λ 估错等价于用错预算价格。∎

**引理 L13（状态机的语言覆盖上界）** 设严格 FSM 只能执行 `L(W)` 内的相位序列，覆盖率 `ρ = P(seq ∈ L(W))`，escape 分支成功率为 `p_esc`，则
`P_succ(HSM) ≤ ρ·P_succ(HSM | in-language) + (1−ρ)·p_esc ≤ ρ + (1−ρ)p_esc`。
无 escape 时 `P_succ ≤ ρ`。因此**硬 FSM 的天花板由词汇表覆盖率决定**；escape 是把上限从 `ρ` 抬回 `ρ+(1−ρ)p_esc` 的必要结构（P11/IP-13 的安全阀）。∎

**引理 L14（序贯检验的样本优势）** 对简单假设 `H0` vs `H1`，固定 α/β 的 SPRT 在 i.i.d. 观测下以概率 1 终止，且期望样本量 `E[N] ≤ N_fixed`（Wald）；在效应明显时严格更小。对数似然比在真值下为鞅，故按固定边界停止不会膨胀一类错误。**推论**：E633 的样本节省是免费的，代价是对非 i.i.d.（episode 相关）需块序贯修正。∎

## 10. 本轮最值得押注的创新点（一句话）

**押注 IP-13 + IP-14 的组合（CA-HSM + VOC-Gate）：它把上轮「路标 + 伺服 + 断言」从一个聪明的启发式升级为**有结构（分层状态机、守卫、恢复、escape）、有预算（影子价格 λ、计算价值门控）、可校准（E628）可回退（Level-1.6）**的执行栈；状态外置不碰权重因而合规，成本核算不碰数据因而零新数据依赖，而「状态 + 成本」的联合设计恰恰是竞品在「换底座、堆数据」的红海里不会去做的那一层。**

**最大风险一句话**：成本模型与状态机的双重先验一旦错配——λ 砍掉真正的护城河、守卫钉死学习策略的天花板——系统会以「更省钱、更可控」的假象稳定地输给一个什么都不管的端到端基线。
