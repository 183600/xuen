# 第 12 轮（灵感循环第 1 轮；本轮灵感：「奖励设计」×「推理延迟」）
> **基线**：第 11 轮 MetricVoiceGauge-GSCF-SRA-JSSE（定义 549–561；引理 92–96；实验 E591–E610）。
> 本轮纪律：**奖励可认证 + 延迟可入证 + 计算可定价**。两个灵感分别治理 v11 的两种债：**目标债**（安全已证书化，但"选哪块"的 score/reward 仍是隐式代码行——无定义、无审计、无失效语义，可被 Goodhart 攻破）、**时间债**（所有证书都隐含"观测时刻＝执行时刻"，而 SRA 5ms、块生成 10ms、p99 抖动使观测-执行间存在真实间隙 Δ，世界在此期间演化而证书余量未为它预留）。必须保持 v11 铁律：任一新模块失效 ⇒ 注入声明中立元，行为严格**等价**（RCD/VoC）或**支配**（ALC 回退到静态 WCET 上界，只会更保守）于 v11，而非行为漂移。

## 0. 直觉与动机

**灵感 1（奖励设计 → 把 reward 从隐式代码行升级为带证书的数据行）**
直觉：前十一轮把安全做成了证书，却把"选哪块"的 score 当成不言自明的代码。score 就是 reward；它没有定义、没有留痕、没有失效语义，也没有被证明不压过安全。奖励设计领域的三件武器正对症：(i) **势函数塑形**（Ng et al. 1999）保证塑形不改变最优策略；(ii) **约束 MDP / 安全支配**把 reward 限制在可行集内排序；(iii) **逆奖励设计/反事实审计**把"为什么给高奖励"变成可质询对象。核心创新：**奖励证书对偶（Reward-Certificate Duality, RCD）**——把块奖励显式分解为 R = R_task + 势函数塑形项 + 证书余量项 λ_c·m(Ĉ) + 可读性项，并定义**奖励-证书一致性（RCC）**：任务收益相等、终止状态相等时，证书余量大者奖励必不低。于是 reward 只许在"证书有效"的可行集内排序，**永不越权压过安全**；塑形项用势函数证明策略不变；新增**反事实奖励审计器（CRA）**：对落选块重放"若给它更高 reward 会否更不安全"，量化"奖励相对证书的杠杆率"ρ_hack 并检测 Goodhart。关键一跃：reward 从"训练/调参用的隐形标量"变成"与 NRB 规范表同构、可审计、可失效的声明式数据行"。

**灵感 2（推理延迟 → 把延迟从调度预算升级为证书状态变量）**
直觉：v11 的证书全部隐含"观测时刻＝执行时刻"。但 SRA 5ms、块生成 10ms、GSCF/感知 2.5ms，加上 p99.9 抖动，观测与执行之间存在 Δ；世界在 Δ 内演化，间隙可能缩小、目标可能移动、人可能走入。现有 E598 只测 p99，把延迟当**性能指标**，没当**安全变量**。严谨做法有两条：(i) **延迟入证**：证书余量加一项 β_lat(Δ) = 世界在 Δ 内可能的间隙缩减上界（速度/加速度包络 L_v·Δ + ½L_a·Δ²），并把证书打上**过期时刻 T_exp**；(ii) **随时算法（anytime）**：每个模块有"算力-保证"曲线 (c_{m,ℓ}, q_{m,ℓ})，延迟紧时选较低档位，证书仍有效但保证变弱（显式写在证书里，而不是偷偷超时）。核心创新：**随时延迟证书（Anytime Latency Certificate, ALC）**——每个模块输出带档位的证书片段，块证书 Ĉ⁺⁺⁺ 携带 (β_lat, T_exp, 各模块档位 ℓ⃗)；任何"执行晚于 T_exp"即证书失效 ⇒ 守卫中止。这把不可控的 p99 从"可能迟到"变成"到期即失效"的可证命题，且实测上界 Δ̂（p99.9/WCET）而非均值进入证书——安全必须用较坏值。

**灵感 3（二者咬合 → 计算价值调度：延迟是奖励的成本，也是安全的约束）**
直觉：奖励设计与推理延迟天然耦合——花 5ms 跑 SRA 值不值，本质是**计算价值（VoI）是否超过其延迟成本**。但安全是硬约束，不能因省时降低证书。核心创新：**计算价值调度器（Value-of-Compute, VoC）**：以 ALC 的"档位-保证"曲线与 RCD 的"奖励-余量"梯度为输入，解一个带硬安全约束的**延迟预算分配**问题：max E[R] − λ_lat·Σc s.t. 证书在 T_exp 前有效、各模块不低于证书最低档。典型二选一极具体：SRA 全档（+5ms）可换回 K_max 的分块吞吐，SRA 档 0（0ms）则 n_reason 全 0 ⇒ K_eff≤2（Π_r 级）；VoC 就是判定"这笔延迟买不买"。边际价值递减 ⇒ 贪心 (1−1/e) 近似，且永不把**硬安全模块**（GSCF 检、JSSE 投影）降到证书不可证的档。三方咬合：RCD 定义"值多少"、ALC 定义"要多久 / 值多久"、VoC 在硬约束下分配"算在哪里"。

## 1. 研究问题（轮次升级版）

- **Q1（奖励可认证）**：如何把块选择 score 分解为 R_task + 势函数塑形 + 证书余量项，使 (i) 塑形不改变任务最优策略（可证），(ii) reward 只作用于证书可行集内部排序、任何权重都不能扩张可行集（安全支配），(iii) 奖励误设可被反事实审计量化并留痕（ρ_hack 检出）？
- **Q2（延迟可入证）**：如何把观测-执行延迟 Δ 作为状态变量写入证书（β_lat、T_exp），使"执行晚于 T_exp 即失效"成为可证中止条件，且 β_lat 对真实间隙缩减的覆盖概率 ≥99.9%、不再出现"带着过期证书执行"？
- **Q3（计算可定价）**：如何用随时保证曲线 (c_{m,ℓ}, q_{m,ℓ}) 与证书最低档约束，在延迟预算下分配算力，使同等安全下吞吐 ↑≥20%（或同等吞吐延迟 ↓≥30%），且硬安全模块永不低于证书最低档？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 奖励只排序不越权律（Reward Ranks, Never Overrides, RCD）**
可行集 F_t 由证书唯一决定，与奖励无关；奖励只允许在 F_t 内部排序。任何奖励权重（λ_c、λ_L）都不得使 F_t 扩张。塑形项必须是势函数形式以保策略不变性；reward 的误设由反事实审计显式量化并写台账。

**P17 延迟入证律（Latency Enters Certificate, ALC）**
凡"观测→执行"存在间隙处，证书必须携带延迟余量 β_lat 与过期时刻 T_exp；进入证书的是实测上界 Δ̂（p99.9/WCET）而非均值。执行晚于 T_exp ⇒ 证书失效 ⇒ 守卫中止，不依赖"是否实际危险"。模块降档只许降到 q ≥ q_min 的可证档位，降档事实显式写入证书。

**P18 计算有价律（Compute Has a Price, VoC）**
算力分配是带硬安全约束的预算优化：延迟计入奖励成本（−λ_lat·delay），但硬安全模块的档位下界由证书决定、不可被价值优化突破。降档导致 K_eff 收缩属声明退化，不得伪装成满保证。

## 3. 与基线的接口（如何退化）

- **RCD 失效**（奖励表损坏/势函数越界/λ 未声明）⇒ λ_c=λ_L=0、R←R_task（≡ v11 原始 score 排序），选择行为**等价 v11**；失去 RCC 排序与余量塑形；
- **CRA 失效**（审计超时/OOM）⇒ 审计跳过、λ_c 冻结当前值、Λ 标记；审计面不参与当期控制，物理行为不变；
- **ALC 失效**（时钟源失效/timestamp 缺失/标定丢失）⇒ β_lat←L_v·Δ_WCET（部署期静态上界，比在线估计更保守）、T_exp←t_obs+Δ_WCET_max；保守性不降，行为**支配** v11；
- **VoC 失效**（调度求解超时/价值模型损坏）⇒ 全部模块取 v11 参考档 ℓ*，**等价 v11** 固定预算调度；硬安全模块本就固定最高档，不受影响；
- 其余沿 v11 九级退化链：GSCF→STF→NRB→AC→ID→MW→v8→v7→v6。

## 4. 预期贡献

1. **奖励证书对偶**：把 reward 从隐式代码行升级为可认证、可审计、可失效的数据行；证明势函数塑形策略不变（引理 97）与安全支配（reward 不扩张可行集），把 Goodhart 风险从"不可见"变成"可量化 ρ_hack + 台账留痕"；
2. **随时延迟证书**：把观测-执行延迟作为证书状态变量，β_lat + T_exp + 档位向量使"过期即失效"可证（引理 98–99），消除 v11 "观测=执行"的隐性前提；
3. **计算价值调度**：在硬安全下界内按边际价值分配算力（引理 100），把"省时"从隐患变成显式声明退化，联合支配 v11（引理 101）；
4. **E611–E630** 覆盖奖励分解、Goodhart 对抗、延迟标定与过期、随时曲线、VoC 调度、联合压测、长跑与竞赛。

## 5. 本轮最大风险

**一句话**：RCD 的证书余量项 m(Ĉ) 与 ALC 的延迟余量 β_lat 都从**同一套前向/动力学模型**导出——模型偏保守时两者同时乐观、模型误差使"奖励排序"与"安全余量"**同向失真**；v11 引以为傲的"三重守护失效正交"在这里被打破：奖励误设（夸大任务进度）与延迟界偏松（低估间隙缩减）会合谋，让系统在**证书自洽但物理已危**的窗口里既给高奖励又不中止。

# 第 12 轮产物 · 创新点清单 v12：**MetricVoiceGauge-RCD-ALC-VoC**（Reward-Certificate Duality, Anytime Latency Certificate & Value-of-Compute Scheduler）

> 背景：第 11 轮 MetricVoiceGauge-GSCF-SRA-JSSE（定义 549–561；引理 92–96；实验 E591–E610）。
> 本轮灵感：「奖励设计」×「推理延迟」
> **继承纪律**：MetricVoiceGauge 九不变式 + v11 全部模块（STF/NRB/LS/GSCF/SRA/JSSE）保留；新组件为可选增强：RCD 失效 ⇒ 退回 v11 标量 score（等价）；CRA 失效 ⇒ 审计面跳过、不影响当期控制；ALC 失效 ⇒ 静态 WCET 上界（更保守，支配 v11）；VoC 失效 ⇒ v11 固定档调度（等价）。v11 最大风险（几何/推理/关节三重守护各自失效可能同时触发且无优雅路径）由 ALC 的"到期即失效"与 RCD 的"reward 不扩张可行集"部分拆除（引理 98、97）；但两者模型同源带来的**相关性失效**被列为 v12 最大风险（第 8 节）。

## 1. 符号体系增量（定义 562–576）

| 符号 | 含义 |
|---|---|

| Φ(s) | 有界势函数 S→ℝ，部署期固定的声明式数据 |
| F_ζ | 势函数塑形项：γΦ(s'_ζ) − Φ(S_t) |
| λ_c, λ_L | 证书余量项、可读性项的权重，**声明式数据行**（非代码常量） |
| m(Ĉ) | 证书余量归一化标量 ∈(−∞,1]，三通道余量取 min（定义 565） |
| RCC | 奖励-证书一致性（定义 563） |
| ρ_hack | 反事实杠杆率：提高落选块任务奖励会否改选更不安全块的事件率 |
| Δ, Δ̂ | 观测-执行延迟及其安全上界（p99.9/WCET） |
| L_v, L_a | 走廊间隙缩减的速度/加速度上界（E614 标定） |
| β_lat(Δ) | 延迟余量 = L_v·Δ + ½L_a·Δ² |
| T_exp | 证书过期时刻 = t_obs + Δ_max，Δ_max 由 β_lat(Δ)≤B_margin 反解 |
| c_{m,ℓ}, q_{m,ℓ} | 模块 m 第 ℓ 档的计算时延与保证质量（单调非减） |
| ℓ⃗, q_min(m) | 各模块实际档位向量、证书要求的保证门槛 |
| Ĉ⁺⁺⁺ | 随时延迟块证书 (ĝ_min, ê_max, γ̂_grasp, β_GSCF, β_lat, n_t, n_t^reason, Q_abort, T_exp, ℓ⃗) |
| VoC_m(ℓ) | 模块 m 从档 ℓ 升到 ℓ+1 的边际价值/时延比 |
| Λ_lat | 延迟台账（定义 575），与 Λ 同哈希链 |

**新增定义 562（块奖励分解，RCD）** 对候选块 ζ（由 S_t 生成、预测终止状态 s'_ζ），显式奖励为
`R(ζ) = R_task(ζ) + γΦ(s'_ζ) − Φ(S_t) + λ_c·m(Ĉ_ζ) + λ_L·L(ζ)`。
其中 R_task ≡ v11 `policy.score`；λ_c, λ_L ≥ 0 为声明式数据行。RCD 失效 ⇒ λ←0、R←R_task，选择行为等价 v11。

**新增定义 563（奖励-证书一致性 RCC）** 奖励设计满足 RCC，当且仅当对任意 ζ_a, ζ_b：若 R_task 相等、s' 相等、L 相等，则 `m(Ĉ_a) ≥ m(Ĉ_b) ⇒ R(a) ≥ R(b)`。由 λ_c ≥ 0 构造性成立。含义：任务收益打平时，安全余量不被奖励偏好压过。

**新增定义 564（安全支配，Safety Dominance）** 选择算子
`π(S_t) = argmax_{ζ ∈ F_t} R(ζ)`，其中可行集
`F_t = { ζ : Ĉ⁺⁺⁺_ζ 在 t_exec 前有效 ∧ n_t^reason 全 1 或降级档 ≥ q_min(SRA) ∧ t_exec ≤ T_exp }`。
**关键**：F_t 完全由证书决定，与 R 无关；奖励只作用于 F_t **内部**的排序。故任意 λ 取值下 π 输出 ⊆ v11 可行行为，reward 无法以任何权重"买通"不安全块。

**新增定义 565（证书余量标量 m）**
`m(Ĉ) = min( (ĝ_min−d_safe)/c_scale, (τ_eff−ê_max)/τ_scale, (β_budget_max−β_lat)/β_scale )`。
m<0 时证书已失效（不在 F_t 内）；m 对三通道余量单调递增，作为奖励塑形的"余量梯度"。

**新增定义 566（反事实奖励审计 CRA）** 后台 1Hz 抽样历史决策 (S_t, F_t, π)。对每对 (ζ_sel, ζ_alt) 反事实重放：若把 R_task(ζ_alt) 提高 δ，π 是否改选 ζ_alt 且 m(Ĉ_alt) < m(Ĉ_sel)？记事件率 ρ_hack（奖励相对证书的杠杆率）。ρ_hack > τ_hack ⇒ λ_c 自适应上调并写 Λ；审计还核验 R_task 与离线标注真实完成度的相关（E613），定位误设项。

**新增定义 567（观测-执行延迟与延迟台账 Λ_lat）** 每块记录 t_obs（生成观测时刻）、t_ready（块可用）、t_exec（首动作执行），`Δ_gen=t_ready−t_obs`、`Δ_sched=t_exec−t_ready`、`Δ=Δ_gen+Δ_sched`。进入证书的是安全上界 `Δ̂=max(Δ, WCET 或 p99.9)`——**安全必须用较坏值**。Λ_lat 每块一行 (ζ_id, t_obs, t_ready, t_exec, Δ_gen, Δ_sched, Δ, ℓ⃗)。

**新增定义 568（延迟余量 β_lat）** 设沿块走廊间隙缩减速率上界 L_v、加速度上界 L_a（E614 标定），则 `β_lat(Δ) = L_v·Δ + ½L_a·Δ²`。证书余量更新 `β_GSCF ← β_GSCF + β_lat(Δ̂)`。若真实缩减 ≤ 上式，则证书在 Δ̂ 延迟下仍保守。

**新增定义 569（证书过期 T_exp）** 证书生成时按可用安全余量预算 B_margin（三通道最小可用余量）反解 `Δ_max = max{Δ : β_lat(Δ) ≤ B_margin}`，令 `T_exp = t_obs + Δ_max`。执行时 `t_exec > T_exp` ⇒ 证书失效 ⇒ 守卫中止，绝不"带过期证书继续"。

**新增定义 570（随时档位与保证曲线）** 每模块 m 档位 ℓ∈{0,…,L_m}，每档 (c_{m,ℓ}, q_{m,ℓ})，q 关于 c 单调非减（E616 实测）。v11 固定预算对应参考档 ℓ*。证书要求 `q_{m,ℓ_m} ≥ q_min(m)`。例：SRA 档 0=跳过（n_reason 全 0 ⇒ K_eff≤2）、档 1=8 模板、档 2=16 模板全推理；GSCF 检与 JSSE 投影为硬安全模块，只允许最高档。

**新增定义 571（随时延迟块证书 Ĉ⁺⁺⁺）**
`Ĉ⁺⁺⁺ = (ĝ_min, ê_max, γ̂_grasp, β_GSCF, β_lat, n_t, n_t^reason, Q_abort, T_exp, ℓ⃗)`。
有效 ⇔ v11 定义 552 条件 ∧ `t_exec ≤ T_exp` ∧ `q_{m,ℓ_m} ≥ q_min(m)`（∀m）。

**新增定义 572（VoC 调度问题）** 每块生成时，在延迟预算 B（由 T_exp 与调度余量反推）下：
`max_{ℓ⃗} E[R(ζ;ℓ⃗)] − λ_lat·Σ_m c_{m,ℓ_m}  s.t.  Σ_m c_{m,ℓ_m} ≤ B,  ℓ_m ≥ ℓ_m^cert,  q_{m,ℓ_m} ≥ q_min(m)`。
硬安全模块 ℓ 固定最高档；只对审计/推理模块（SRA、CRA）做价值分配。典型二选一：SRA 全档（+5ms）换 K_max 吞吐，或 SRA 档 0（0ms）降 K_eff=2。

**新增定义 573（边际价值与贪心分配）**
`VoC_m(ℓ) = [E[R|ℓ+1] − E[R|ℓ)] / [c_{m,ℓ+1} − c_{m,ℓ}]`。
若 E[R|ℓ] 边际递减（凹），按 VoC 降序贪心分配得子模背包 (1−1/e) 近似；剩余预算无正价值项即不再花（延迟是成本）。

**新增定义 574（延迟感知守卫，六检）** 50Hz 守卫在 v11 五检基础上加**检 6**：`t_now ≤ T_exp`（证书未过期）∧ `Δ̂` 未超 β_lat 预算。任一失败 ⇒ 切中止。总预算 ≤0.65ms。过期检查先于动作执行、使用同一时钟源。

**新增定义 575（延迟台账扩展 Λ_lat）** 见定义 567；哈希链 κ_h=256 同 Λ。缺口（某块缺 t_exec 或 Δ）本身触发 K_eff≤2 并标记。

**新增定义 576（退化与中立元）**
- RCD 失效 ⇒ λ_c=λ_L=0、R←R_task（≡v11 score），**等价 v11**；
- CRA 失效 ⇒ 审计跳过、λ_c 冻结、Λ 标记，控制面不变；
- ALC 失效 ⇒ β_lat←L_v·Δ_WCET、T_exp←t_obs+Δ_WCET_max，**支配 v11**（更保守）；
- VoC 失效 ⇒ 全部取 v11 参考档 ℓ*，**等价 v11**；
- 其余沿 v11 九级退化链。

# IP-365 RewardCertificateDuality：奖励证书对偶（把 score 变成可认证数据行）
class RewardCertificateDuality:
    def __init__(self, task_score_fn, potential, lam_c, lam_L, gamma=0.99):
        # task_score_fn ≡ v11 policy.score；potential 为有界势函数（声明式数据）
        self.task_score, self.Phi = task_score_fn, potential
        self.lam_c, self.lam_L, self.gamma = lam_c, lam_L, gamma

    def margin(self, cert):                    # 定义 565：三通道余量取 min
        return min((cert.g_min - self.d_safe) / self.c_scale,
                   (cert.tau_eff - cert.e_max) / self.tau_scale,
                   (self.beta_budget_max - cert.beta_total) / self.beta_scale)

    def score(self, chunk, s_t, s_next):       # 定义 562：只在可行集内排序
        R = self.task_score(chunk)                       # R_task
        R += self.gamma * self.Phi(s_next) - self.Phi(s_t)  # 势函数塑形（策略不变）
        R += self.lam_c * self.margin(chunk.cert)        # 证书余量项
        R += self.lam_L * chunk.legibility              # 可读性项
        return R

    def select(self, candidates, s_t):         # 定义 564：可行集由证书决定
        feasible = [c for c in candidates if cert_valid_at_exec(c.cert)]
        if not feasible:
            return None                        # 不可行 ⇒ 单步/Π_r，reward 无权放行
        return max(feasible, key=lambda c: self.score(c, s_t, c.pred.s_next))


# IP-366 CounterfactualRewardAuditor：反事实奖励审计器（1Hz 后台）
class CounterfactualRewardAuditor:
    def __init__(self, rcd, ledger, tau_hack=0.05, delta=0.1):
        self.rcd, self.ledger = rcd, ledger
        self.tau_hack, self.delta = tau_hack, delta
        self.rho_hack = 0.0

    def audit(self, samples):                  # samples: [(S_t, F_t, pi, margins)]
        hits, total = 0, 0
        for S_t, F_t, pi, margins in samples:
            for alt in F_t:
                if alt is pi:
                    continue
                total += 1
                # 反事实：把 alt 的任务奖励抬高 delta，是否改选且更不安全？
                boosted = self.rcd.task_score(alt) + self.delta
                if boosted > self.rcd.task_score(pi) and margins[alt] < margins[pi]:
                    hits += 1
        self.rho_hack = hits / max(total, 1)
        if self.rho_hack > self.tau_hack:
            self.rcd.lam_c *= 1.5              # 自适应上调余量项权重
            self.ledger.append_reward_audit(self.rho_hack, self.rcd.lam_c)
        return self.rho_hack


# IP-367 AnytimeLatencyCertificate：随时延迟证书（延迟入证 + 过期）
class AnytimeLatencyCertificate:
    def __init__(self, L_v, L_a, levels, q_min, wcet, clock):
        # levels[m] = [(c_{m,0}, q_{m,0}), ...]；硬安全模块只含最高档
        self.L_v, self.L_a = L_v, L_a
        self.levels, self.q_min = levels, q_min
        self.wcet, self.clock = wcet, clock

    def beta_lat(self, delta_hat):             # 定义 568
        return self.L_v * delta_hat + 0.5 * self.L_a * delta_hat ** 2

    def expiry(self, t_obs, margin_budget):    # 定义 569：单调反解 Δ_max
        lo, hi = 0.0, self.wcet["max_delta"]
        for _ in range(32):
            mid = 0.5 * (lo + hi)
            if self.beta_lat(mid) <= margin_budget:
                lo = mid
            else:
                hi = mid
        return t_obs + lo

    def certify(self, base_cert, t_obs, margin_budget, levels_chosen):
        delta_hat = max(self.clock.now() - t_obs, self.wcet["delta_p999"])
        beta_l = self.beta_lat(delta_hat)
        t_exp = self.expiry(t_obs, margin_budget - beta_l)
        for m, ell in levels_chosen.items():
            if self.levels[m][ell][1] < self.q_min[m]:
                return None                    # 档位低于证书门槛 ⇒ 证书不可得
        return Cert3(base_cert, beta_l, t_exp, levels_chosen)


# IP-368 ValueOfComputeScheduler：计算价值调度器（硬约束下的延迟预算分配）
class ValueOfComputeScheduler:
    def __init__(self, alc, rcd, lam_lat=1.0):
        self.alc, self.rcd, self.lam_lat = alc, rcd, lam_lat

    def schedule(self, B_budget, expected_R):
        # 硬安全模块固定最高档；只优化可降级模块（SRA/CRA）
        allocation = {m: len(self.alc.levels[m]) - 1 for m in self.alc.hard_modules}
        spend = sum(self.alc.levels[m][-1][0] for m in self.alc.hard_modules)
        upgradable = [m for m in self.alc.levels if m not in self.alc.hard_modules]
        # 贪心：按边际价值/时延比降序
        while True:
            best, best_voc = None, 0.0
            for m in upgradable:
                ell = allocation.get(m, 0)
                if ell + 1 >= len(self.alc.levels[m]):
                    continue
                dc = self.alc.levels[m][ell + 1][0] - self.alc.levels[m][ell][0]
                dv = expected_R(m, ell + 1) - expected_R(m, ell)
                if spend + dc <= B_budget and dv > 0 and dv / max(dc, 1e-9) > best_voc:
                    best, best_voc = (m, ell + 1, dc), dv / max(dc, 1e-9)
            if best is None:
                break
            m, ell_next, dc = best
            allocation[m] = ell_next
            spend += dc
        # 安全下界：可降级模块若连证书最低档都放不下 ⇒ 退 K_eff≤2
        for m in self.alc.levels:
            if allocation.get(m, 0) < self.alc.cert_min_level[m]:
                return None, spend            # 返回 None ⇒ 触发 Π_r 级收缩
        return allocation, spend


# IP-370（升级）：六检守卫（v11 五检 + 证书未过期）
def midchunk_guard_v12(chunk, k_exec, live_obs, stf, gscf, nrb, jsse, alc, clock):
    """50Hz 六检 ≤0.65ms"""
    if not chunk.cert_still_valid(live_obs):
        return abort_to_jsse(chunk, k_exec, jsse)
    if (live_obs.nearest_clearance - d_brake(live_obs.speed) - d_safe
            < chunk.remaining_len(k_exec)):
        return abort_to_jsse(chunk, k_exec, jsse)
    if stf.surprise_near(live_obs.pose) > stf.tau_sem:
        return abort_to_jsse(chunk, k_exec, jsse)
    if nrb.fast_norms(live_obs).violated:
        return abort_to_jsse(chunk, k_exec, jsse)
    if not gscf.geo_ok_near(live_obs.pose):
        return abort_to_jsse(chunk, k_exec, jsse)
    if clock.now() > chunk.cert.t_exp:          # 检 6：证书过期 ⇒ 立即中止
        return abort_to_jsse(chunk, k_exec, jsse)
    return ('continue', k_exec + 1)

## 4. 推导

**引理 97（RCD 的塑形不变性与安全支配）**
(i) 势函数塑形 `F=γΦ(s')−Φ(s)` 不改变任意任务 MDP 的最优策略（Ng, Harada & Russell 1999 势函数定理），故加入塑形项只引导/加速，不改变任务最优动作集。
(ii) 由定义 564，可行集 F_t 完全由证书决定、与 R 无关；`argmax_{F_t} R` 的输出 ⊆ F_t 的物理行为集合 ⊆ v11 可行集。λ_c、λ_L 取任意大/小都不能使 F_t 扩张，**安全支配成立**。
(iii) 由定义 563，RCC 保证同等任务收益、同等终止状态与可读性下，高余量块不被奖励偏好压过。
证明：(i) Ng 定理；(ii) 集合约束与排序分离；(iii) λ_c≥0 单调。∎

**引理 98（延迟余量与过期的保守性）**
设真实间隙缩减 `c(t_obs)−c(t_exec) ≤ L_v·Δ + ½L_a·Δ²`（Lipschitz/动力学界，E614），且用安全上界 `Δ̂ ≥ Δ` 计算 β_lat。则证书预测的间隙下界 ≥ 真实下界（证书保守）；且 `t_exec ≤ T_exp = t_obs+Δ_max` 时预留 `β_lat(Δ̂) ≤ B_margin`，不越安全预算。
证明：β_lat 单调增，Δ̂≥Δ ⇒ β_lat(Δ̂)≥β_lat(Δ)≥真实缩减；Δ_max 由 β_lat 单调反解。∎

**引理 99（随时证书的单调降级与到期失效）**
(i) q_{m,ℓ} 关于 c_{m,ℓ} 单调非减 ⇒ 升档只增强或保持保证；降档只削弱保证，若仍满足 q_min(m) 则证书**有效但更弱**（显式写 ℓ⃗），不会"偷偷超时却声称满保证"。
(ii) 若调度后无档位组合满足 `Σc ≤ B ∧ ℓ_m ≥ ℓ_m^cert`，则证书不可得 ⇒ 退回单步/Π_r，绝不超时执行。
(iii) `t_exec > T_exp` ⇒ 检 6 使证书失效 ⇒ 中止，不依赖"是否实际危险"。
证明：构造性，单调性与定义 569/574。∎

**引理 100（VoC 贪心的近似最优与安全下界）**
(i) 若 E[R|ℓ] 边际递减，则可降级模块的预算分配是子模背包，VoC 降序贪心达 (1−1/e) 近似（Nemhauser et al.）。
(ii) 硬安全模块档位固定最高档，故任何 VoC 分配都满足 q ≥ q_min，证书不因省时失效；VoC 只影响"安全前提下多花多少算力"，**只会少花、不会降安全**。
(iii) SRA 降到档 0 ⇒ n_reason 全 0 ⇒ K_eff≤2（Π_r 级），属声明退化。
证明：(i) 边际递减 ⇒ 子模；(ii) ℓ^cert 下界约束；(iii) 定义 570 档 0 语义。∎

**引理 101（RCD+ALC+VoC 的联合保守性与支配性）**
在引理 97–100 与 v11 引理 92–96 假设下，v12 物理行为集合 ⊆ v11，且危险事件捕获概率不低于 v11：β_lat 只增余量、检 6 只增中止、RCD 只重排、VoC 只降算力不降证书门槛。联合失效（RCD 误设 + ALC 界偏松 + VoC 误判价值）时退化到 v11 固定预算 + v11 score + 静态 WCET，行为支配 v11。
证明：逐模块支配 + 并集界。∎

**引理 102（奖励-延迟相关性失效的显式化——本轮风险的形式化）**
记奖励塑形与延迟界的模型误差分别为 ε_R、ε_L，二者同源（同一前向/动力学模型）⇒ 一般 `Cov(ε_R, ε_L) > 0`。则联合安全概率 `Pr[safe] ≥ 1 − ε_R − ε_L` 的并集界在正相关时**不可加分解**，v11"三重守护失效正交"的假设失效；CRA 仅能观测 ε_R 的可表现部分，ALC 仅能观测 ε_L 的可表现部分，二者不可见的共模分量是该相关性的来源。
证明：正相关下 `Pr(¬safe) = Pr(ε_R>0 ∨ ε_L>0) ≥ max(Pr(ε_R>0), Pr(ε_L>0))`，并集界较独立时更松；同源误差使二者同时偏向乐观。∎

## 8. 本轮最大风险

**一句话**：RCD 的证书余量项 m(Ĉ) 与 ALC 的延迟余量 β_lat 都从**同一套前向/动力学模型**导出——模型偏保守时两者同时乐观、模型误差使"奖励排序"与"安全余量"同向失真；v11 引以为傲的"三重守护失效正交"在这里被打破：奖励误设（夸大任务进度）与延迟界偏松（低估间隙缩减）会合谋，让系统在**证书自洽但物理已危**的窗口里既给高奖励又不中止，而 CRA 与 ALC 各自只能观测到本通道可表现的部分（引理 102 的共模误差不可见）。
