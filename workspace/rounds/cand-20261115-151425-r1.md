# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「产学研合作」×「手势识别」）

> R69 给闭环装上了一张会提问的嘴：把 U 拆成 aleatoric/epistemic，用流匹配多模态策略生成「看—问—触」，用 VoI 决定值不值得问，用「k 个正交证据一致」防撒谎，用 `(r_res↓, Δa↑)` 抓被标定吸收的缓变故障；它也自陈了最尖锐的风险——**问错，比不问更危险**。
>
> 但 R69 的整套交互理论**默认了一本共享词典**：它假设「我该问 A 还是 B」这个问题本身有意义，假设回答者与系统对 A、B 的所指一致，假设标签是被观测出来的真值。手势识别把这三个假设同时击穿：
> - **手势的意义是约定的，不是物理的**：同一轨迹在甲地是「停止」，在乙地可能是侮辱；竖大拇指在一种文化是赞许，在另一种是冒犯。识别的对象不是像素轨迹，而是**一个共同体签过字的语义**。
> - **词汇表本身是产学研的产物**：高校定义类目与采集数据、产业选定部署场景、标注者来自特定人群、标准/监管给出适用范围。所谓「真值」是多机构**裁决出的同意**，不是自然事实；机构间错误还会因同一笔经费、同一批数据而高度相关。
> - **开口问也会失败**：当用户根本不在你的词典里（做了一个你没定义的手势），强制二选一会把人逼进一个错误答案，系统再盖上「已确认」的章——这正是 R69 风险的最尖锐形态。
>
> 本轮的核心命题：**手势指令不是待识别的标签，而是被共同签署的意义（a co-signed meaning）；一张安全证书必须同时是语义许可证、证据来源链与责任担保书。** R69 问「我该向谁求证、还能问什么」，R70 问「**我们说的是同一本词典吗？这本词典是谁签的、对谁有效、读错了谁担责**」。
>
> 命名 **PALM-RAS**（Provenance-Aware Lexicon Mediation for Risk-Adaptive Systems；palm 亦指手掌）。一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我们凭什么共享同一个意思**」。

## 0. 直觉与动机

**灵感 1（手势识别 → 识别的对象是「言语行为」，不是轨迹）**
直觉：挥手可以是打招呼、可以是驱赶、也可以只是散热。物理轨迹相同，**言外之力（illocution）不同**。R69 的信息动作把「看/问/触」当消歧工具，却默认观测到的就是「意义」；手势场景里，系统必须先判断这是不是一次**通信**（communicative intent），再判断它**是哪一次通信**。把手势当连续动作块做流匹配，天然同时给出轨迹模态与开放集质量；但只有加上「发送者是否有意发出」这一层，才谈得上安全执行。否则一次挠头就能触发一条指令——**假接受（把非通信当命令）在尊严与安全上都远贵于假拒绝（漏掉一条命令）**。

**灵感 2（产学研合作 → 词典是多方合写的，标签是裁决出来的）**
直觉：手势数据几乎从不来自单一机构：实验室定义类目、众包/外包标注、产业提供现场日志、标准组织给适用范围。每家都有激励：实验室想把类目做通用、产业想快速覆盖场景、标注方想少返工。于是「真值」不是被观测到的，而是被**谈判**出来的。R69 的「k 个正交证据」假设源独立；产学研现场更常见的是**同源错误**（同一批数据、同一个示范点、同一份有利评测）。因此必须把「谁签的字、用的谁的数据、适用于谁」写进每个手势类目，并用**制度相关**而非独立同分布来估计标签方差。

**灵感 3（二分 → 四分：把「问不出」与「不该问」分开）**
直觉：R69 只有两类不确定性、两种动作（收紧或问）。手势把它撕成四类，且**每类的正确动作不同**：
- `U_ale`（抖动、遮挡、协同发音）：问也问不出 → R69 收紧；
- `U_ref`（多个已许可类目都像）：问得出 → R69 交互；
- `U_lex`（意思根本不在词典里／问句对这个用户无意义）：**问了会更糟** → 不能强制选择，只能示证、给「都不是」、换通道；
- `U_inst`（这个类目的许可证在此地是否有效／来源是否可信）：**再采样也没用** → 查许可、重签、隔离。
把 `U_lex` 当 `U_ref` 去问，是 R69 风险的技术根源；把 `U_inst` 当 `U_ale` 去收紧，则是用保守掩盖治理失败。

**灵感 4（对偶通道 → 语义漂移是第三条「被吸收」的故障）**
直觉：R68 用 `(r_res↓, Δa↑)` 抓被标定吸收的传感器漂移。手势还有第三种隐形故障：**约定在变**（新员工、新方言、新一代用户改变了手势含义），而传感器与行为似然都正常。此时唯一可见的信号是**交互结局的纠正率/撤回率上升**——用户不断改口、系统不断被「不是这个意思」打回。于是 `(r_res 正常, Δa 正常, correction_rate↑)` 成为**语义漂移**的判别模式，必须触发重许可，而不是继续相信旧词典。

**灵感 5（双刃剑 → 有了词典就有了新的攻击面）**
直觉：一旦「意义」被写成可签署的许可证，攻击面就从像素转移到**制度与语用**：伪造来源、贿赂标注、把方言写成普适、用强制二选一诱导用户确认错误含义、用「同意」洗白常开摄像头、以及系统自己的回应手势冒犯用户（竖大拇指！）。最危险的不是识别错了，而是**用一张多方签字的许可证，把一个社区真正在用的手势判为「不存在」**。所以本轮必须同时交付：许可掩码、开放集弃权、问题有效性、通信意图双钥、来源感知裁决、语义担保与隔离、同意可撤销、反向通道安全。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（PALM-RAS 总览）** PALM-RAS = (FLUID-RAS†, GLP, LIC, QAD, DGK, MINT-L, SPA, DRM, SWQ, BCG, CPL, SDS, J_PALM)。在 R69 三不变式上增加四条：
(iv) **许可先行**：任何手势只有在「站点 × 用户 × 目的 × 同意」下被许可，才进入候选集；未许可手势一律弃权，绝不映射到最近邻类目；
(v) **意义共签（双钥）**：执行指令需同时满足「通信意图成立」与「指称唯一且已许可」，缺一即不执行；
(vi) **语义可追溯与担保**：每个类目携带作者、数据来源、适用辖区、语义方差与担保份额；现场证据越界即隔离并回溯作者；
(vii) **不可强制提问**：仅在问题有效性 `q(g)` 足够高时才允许强制二选一；否则只能用示证式/开放式/换通道交互，且换通道需另行同意。

**定义 311（带来源的手势词汇表 GLP/GLE）** 词汇表 L = {e}。条目 `e = (c_e 原型轨迹分布, def_e 自然语言定义, A_e 作者机构与其数据来源哈希, Pop_e 标注/签字人群, J_e 适用辖区（文化 × 站点 × 任务）, Conf_e 混淆/否定集, V_e 语义方差, κ_e 同意策略, w_e 担保份额, ver_e, state_e ∈ {active, quarantined, retired})`。时刻 t 的**有效许可集** `L_t = {e : J_e ∋ S_t, κ_e 允许当前目的, state_e = active}`。

**定义 312（语义转移缺口）** 站点方言 P_S 与条目许可人群 P_e 的差距不是特征距离，而是**读法分歧**：`Δ_sem(e,S) = E_{x~P_S}[1{argmax p(·|x;e) ≠ 站点标注}]`（用少量配对样本估计）。在 A102（误读率对语义距离 Lipschitz）下，站点误读率 ≤ `V_e + L_s·Δ_sem(e,S)`。证书必须声明该上界；跨站点部署是**重许可**问题，不只是协变量偏移。

**定义 313（四分不确定性 QAD）** 在有效许可集上：
- `U_ale = Σ_e p_e·tr(Σ_e)`（类内噪声，不可约）；
- `U_ref = H(p)`（已许可类目间的指称歧义，可问）；
- `U_lex = H(1{meaning ∈ L_t})`（开放集/词典外质量，问不出来，只能弃权或重签）；
- `U_inst = H(1{license valid}) + H(θ_source)`（许可与来源可信度，采样无益，只能查证/隔离）。
四者分别进入不同通道（定义 325），**不做加权求和**。R69 的 `U_ale/U_epi` 是本定义在 `U_lex = U_inst = 0` 时的前两维。

**定义 314（许可掩码 LIC）** 识别后验被硬掩码：`p(e|o) ∝ p(o|e)·1{e ∈ L_t}`，未许可质量全部进入 `abstain`。硬掩码不是软先验：软先验仍会把词典外手势分给最近的合法类目（引理 19），而那正是「合法地误读」。

**定义 315（通信意图与双钥认证 DGK）** 设 `ι ∈ {communicative, incidental}`。指令被**认证**当且仅当 `P(ι = communicative | o) ≥ τ_int`、存在 `e ∈ L_t` 使后验 `p(e|o) ≥ τ_ref` 且与次优的间距 `≥ δ_margin`、且 `U_inst ≤ τ_inst`。损失满足 `L_FA ≫ L_FR`（假接受 ≫ 假拒绝）；未认证手势不产生动作，只产生（可能免费的）观察。

**定义 316（问题有效性 QV）** 对信息动作 g，其回答在用户词典下「有意义」的概率 `q(g) ∈ [0,1]`（由开放集头、方言估计与问句约束性预测）。有效信息价值
`VoI_eff(g) = q(g)·VoI(g) − c(g) − λ_c·coerce(g)`，
其中 `coerce(g)` 度量强制程度（二选一 > 是/否 > 示证 > 开放）。当 q 低时，强制问题不仅无益，还会**制造高置信错误**（引理 20）。

**定义 317（MINT-L 交互选择）** 候选信息动作含 R69 的看/问/触，另加示证式动作集 `O = {示范一次, 镜像用户手势, 提供「都不是/其他」, 经同意换通道（语音/按键）}`。`g* = argmax_g VoI_eff(g)`，s.t. 预算、C-RAS-WM 安全认证、同意、`q(g) ≥ q_min`。若最优值 ≤ 0 或 `U_lex` 高而无有效示证动作：**不交互、不执行**，走定义 325 兜底。

**定义 318（本地方言与重许可 DRM）** 当 `Δ_sem(e,S) > δ_sem` 或开放集质量超阈值时，进入**方言登记**：经同意采集每类目 n 个少样本示范，估计站点方言并生成新条目 `e_S`（作者 = 站点 + 原作者共同签字，`J = 当前站点`），旧条目在新站点置为 `out-of-scope`。登记完成前只能用非手势通道。这把「死亡之谷」从一句口号变成**语义上的重签流程**。

**定义 319（来源感知标签裁决 SPA）** 标注者 i 对样本 n 给 `y_{i,n} ∈ L ∪ {abstain}`。分层潜真值模型：`P(y|e,i)` 含逐机构混淆矩阵与机构间错误相关 `ρ_{ij}`（由资金同源、数据重叠、人员重叠估计）。后验给出指称分布与**语义方差** `V_e = 裁决后仍存的机构分歧`。裁决协议（谁有票、如何弃权、如何上诉）写入条目元数据；`V_e > τ_V` 的条目不得 active，只能拆分或补采。**多数票会因 ρ 系统性低估 V_e（引理 21）。**

**定义 320（语义担保与隔离 SWQ）** 条目 e 的作者在 `J_e` 内为 `V_e` 提供担保份额 `w_e`。现场证据（交互纠正、撤回、事故）若显著超出声明方差，触发**担保索赔**：e 立即 quarantine、回溯作者与数据来源、要求重验；系统在隔离期退回非手势安全通道。超额声明适用范围会使期望赔付上升——这使「诚实声明辖区」成为均衡（定理 19）。

**定义 321（反向通道手势 BCG）** 系统自己的确认/应答手势（点头、高亮、「?」、镜像）也是一次通信，必须来自**反向通道词典**并在当前辖区许可、非冒犯；否则退化为中性通道（灯光/声音，且需同意）。**系统必须遵守它要求人类遵守的同一份合同**：不得在未许可的辖区「竖大拇指」。

**定义 322（同意与传感预算 CPL）** 同意 `κ = (目的, 时长, 可撤销, 数据保留, 派生模型用途, 敏感属性最小化)`。常开手势传感会泄露健康、残障、情绪等信息；定义传感预算与最小化原则。撤销必须传播为：许可失效 → 相关条目/方言停用 → 派生数据按承诺清除。**同意不是一次性勾选，而是附在条目与站点上的可撤销许可。**

**定义 323（治理/语用干扰集 ℰ_PALM）** `ℰ_PALM = ℰ_FLUID × ℰ_lex × ℰ_coerce × ℰ_consent`：词条投毒（恶意作者把危险动作写成安全标签）、来源伪造、文化错配、强制选择诱导、偶发动作利用、反向通道冒犯、同意洗白、担保规避（用合同把责任推给最弱方）。

**定义 324（证书 J_PALM）** `J_PALM = (J_FLUID, lexicon_hash, license_scope, adjudication_protocol, V_e, Δ_sem, q(g), intent_proof, consent_chain, warranty_state, palm_ver)`。Valid ⇔ Valid(J_FLUID) ∧ 所有执行类目在许可集内 ∧ 双钥认证成立 ∧ `U_inst ≤ τ_inst` ∧ 同意链完整 ∧ 无 quarantine 冲突。

**定义 325（四通道退避与 resolution bonus）** 若 `U_ref` 被消解且 `U_lex, U_inst` 均在门内：`λ = λ_floor(U_ale)`（resolution bonus）；若 `U_ref` 未消解但许可有效：`λ = λ_floor(U_ale + U_ref)`（R69 兜底）；若 `U_lex` 高：**弃权**并（经同意）换通道，不把词典外质量当噪声收紧；若 `U_inst` 高：隔离条目、退回 R69/非手势安全通道。R69 是「单词典、全域许可、`U_lex = U_inst = 0`、只用强制问」的边界。

**定义 326（许可过滤下的自适应采样）** 流匹配只对 `L_t` 内类目采样；开放集头与方言头决定是否升 K 或进入登记；未许可类目的模态即便高密度也不得被选中（掩码在解码侧再次校验）。

**定义 327（语义漂移对偶通道 SDS）** 维护 `(r_res, Δa, correction_rate)` 三通道。判据：`r_res` 与 `Δa` 正常、但被接受手势的**纠正/撤回率**显著上升 ⇒ 疑似语义漂移（约定变了），触发重许可与方言登记，而非继续相信旧 `V_e`。这是 R68/R69 反吸收引理在**语用层**的镜像。

**定义 328（严格包含与安全单调）** 在 A102–A104 下，PALM 的可执行动作集 ⊆ R69 的可执行动作集（双钥 + 许可掩码只做收缩）；当词典唯一、许可全域、同意常开、`U_lex = U_inst = 0`、且只用强制问时，两者逐指令相同。故 PALM ⊃ FLUID ⊃ CALM，安全侧单调不让步。

```python
# IP-264 GLP/LIC：带来源的词典 + 许可硬掩码（未许可 → 弃权）
def licensed_posterior(p, L_t):
    mask = {e: p[e] for e in L_t}
    z = sum(mask.values())
    return ({e: v / z for e, v in mask.items()}, max(0.0, 1.0 - z))  # abstain mass

# IP-265 QAD：四分不确定性（四类各走各的通道）
def quad_decompose(p, modes, L_t, trust, license_conf, open_mass):
    U_ale  = sum(p[e] * trace(cov(modes[e])) for e in L_t)
    U_ref  = entropy([p[e] for e in L_t])
    U_lex  = bernoulli_entropy(open_mass)
    U_inst = bernoulli_entropy(license_conf) + entropy(trust)
    return U_ale, U_ref, U_lex, U_inst

# IP-266 DGK：双钥认证（意图 × 指称 × 许可），缺一不执行
def certify(o, p, L_t, P_intent, trust):
    e, p1 = argmax_licensed(p, L_t)
    p2 = second_best(p, L_t)
    return (P_intent >= TAU_INT and p1 >= TAU_REF and
            (p1 - p2) >= DELTA_MARGIN and trust[e] <= TAU_INST)

# IP-267 MINT-L：问题有效性加权的交互选择（绝不强制问词典外的事）
def choose_interaction(modes, L_t, o, budget, consent):
    best = None
    for g in candidates(modes) + ostensive_acts(modes):
        if not budget.allow(g) or not consent.allow(g):     continue
        if not c_ras_wm.certify_info(g, o):                 continue
        q = question_validity(g, L_t, o)                    # 0..1
        if q < Q_MIN:                                       continue  # 问了会更糟
        val = q * voi(g) - cost(g) - LAM_C * coerce(g)
        if best is None or val > best.val: best = (g, val)
    return best if best and best.val > 0 else None

# IP-268 SPA：来源感知标签裁决（离线；产出 V_e 与裁决协议）
def adjudicate(labels, institutions, rho):
    conf = hierarchical_confusion(labels, institutions, rho)  # 机构相关
    post = latent_truth(conf, labels)
    V_e  = residual_disagreement(post, labels)                # 不把「同意」当零方差
    return post, V_e

# IP-269 SWQ：语义担保与隔离（越界即回溯作者）
def warranty_step(e, field_evidence, claims):
    if exceeds(e.V_e, field_evidence) and not e.quarantined:
        e.state = 'quarantined'
        claims.open(author=e.A_e, share=e.w_e, data=e.data_hash)
    return e.state

# IP-270 BCG：反向通道手势生成 + 辖区许可校验
def backchannel(intent, L_back, site):
    g = flow_match_backchannel(intent)
    return g if licensed(g, L_back, site) and not offensive(g, site) else neutral_channel(site)

# IP-275 DRM：方言登记 → 站点共签的新许可
def enroll_dialect(site, consent, n_shot):
    if not consent.allow('dialect_enrollment'): return None
    S = collect_demonstrations(site, n_shot)          # 每类目 n 个
    return relicense(author=site + original_authors, scope=site, dialect=S)

# IP-276 SDS：语义漂移哨兵（第三条对偶通道）
def semantic_drift(r_res_hist, da_hist, correction_hist):

            and trend(correction_hist) > 0)           # 传感正常但纠正率升

# IP-273 PALM 主闭环（继承 R69，仅在「意义/许可/意图」处插入新闸门）
def PALM_round(M, obs, S_t):

    p, abstain = licensed_posterior(M.head(samples), M.glp.active(S_t))
    U_ale, U_ref, U_lex, U_inst = M.qad.quad(
        p, samples, M.glp.active(S_t), M.trust, M.license_conf, abstain)
    # 双钥：通信意图 × 指称唯一 × 许可可信
    ok = M.dgk.certify(o, p, M.glp.active(S_t), M.intent(o), M.trust)
    if not ok and U_lex <= TAU_LEX and U_inst <= TAU_INST:

        if g is not None: p = M.cia.update_belief(p, M.cia.execute(g))
    if U_lex > TAU_LEX:                       # 词典外：弃权/登记，不硬凑
        M.drm.maybe_enroll(S_t, M.consent); return M.abstain_or_switch(S_t)
    if U_inst > TAU_INST:                     # 来源/许可不可信：隔离
        M.swq.quarantine(M.glp.active(S_t)); return M.fallback_nongesture(S_t)
    if not ok: return M.hold()                # 未认证：不执行
    U_floor = U_ale + (U_ref if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(...)
    mode = select_mode(samples, p, lam)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    ack = M.bcg.backchannel(mode, M.glp.back, S_t)   # 回应也要许可
    M.vqa_i.submit_async(g, p, U_lex, U_inst, ack)
    return k, lam, mode, (U_ale, U_ref, U_lex, U_inst)
```

## 3. 推导

**引理 19（硬掩码的开放集安全界）** 设词典外手势在特征空间与某合法类目重叠度为 β。软最近邻分配的错误接受率 ≥ `β·(1 − ε_ood)`（OOD 检测必有漏检）；硬掩码把词典外质量全部导入弃权，错误接受率 ≤ `ε_ood`。系：**「不认识的就不认」比「认成最像的」安全**；掩码必须在解码侧二次校验，否则高密度模态仍会越狱。

**引理 20（问题有效性与强制选择的下界）** 设问题有效性 q，强制二选一。用户词典不匹配时回答近似随机，系统后验熵被人为压低但**期望错误率 ≥ (1 − q)/2**，校准误差至少上升 `(1 − q)/2 − ε_cal`。故 `VoI_eff` 可为负：**q 低时，提问把「诚实的不知道」变成「被确认的错误」**——R69 风险的形式化。系：`q_min` 门与示证式/开放式动作不是礼貌，而是安全约束。

**引理 21（机构相关下的语义方差）** 若 k 个来源错误相关 ρ > 0，多数票估计的条目准确率被高估、语义方差 `V_e` 被低估，偏差随 ρ 与来源同源性上升；加入 abstain 与机构分层混淆矩阵后可识别 `V_e` 至 `O(1/√n) + ρ` 项。系：**「三家机构都同意」在 ρ 高时约等于「一家机构说了三遍」**——这就是产学研同源数据/同源资金的危险。

**定理 19（语义担保的激励相容）** 设作者可声明辖区 J 与方差 V，超范围部署被现场证据检出的概率 `p_d > 0`，赔付与真实伤害成正比、且担保份额 w 与声明范围正相关。则当 `p_d·赔付 > 超范围带来的收益` 时，**如实声明最小足够辖区是贝叶斯纳什均衡**；否则作者有动机把方言写成普适。系：担保/隔离把「语义泛化」从免费宣传变成**有价格的承诺**。

**定理 18（PALM 严格包含 FLUID）** 许可掩码、双钥认证与四通道退避都只**收缩**可执行动作集，故任意状态下执行风险 ≤ R69；当词典唯一、许可全域、同意常开、`U_lex = U_inst = 0`、只用强制问时，所有新闸门恒真，逐指令等于 FLUID。R69 是 PALM 的「共享词典、无制度摩擦」边界。

**定理 20（双钥与语义漂移下的无突变）** 未认证手势只观测不执行；`U_inst` 越界时隔离条目并切换到预置安全通道，λ 单调不降；反向通道经许可校验后才发出。故模式切换连续、无突变，且语义漂移只能通过重许可改变行为，不能偷偷改写安全包络。

## 6. 本轮最大风险

PALM-RAS 最大的风险不是「读错手势」，而是「**用一张多方签字的许可证，把一个社区真正在用的手势合法地判为不存在**」——许可掩码与担保机制一旦被作者/部署方的合同权力俘获（把方言写成越界、把方差压低、把责任推给最弱方），系统会比 R69 更自信地弃权或误读，且披着「合规」外衣。

**次级风险与缓解**：许可掩码导致可用性塌陷（示证式动作 + 方言登记 + E316/E322）；机构裁决被俘获（分层相关模型 + abstain + 独立审计位 + E320）；强制问/社交工程（`q_min` + 证据纪律 + E318/E329）；反向通道冒犯（反向词典 + 中性通道 + E323）；同意洗白与常开传感泄露（可撤销许可 + 最小化 + 派生清除 + E324）；语义漂移被旧 `V_e` 吸收（`correction_rate` 第三通道 + 重许可 + E325）。

**一句话最大风险**：意义被合同化了，但合同可能被更有权力的一方书写——PALM 可能用「合规」把方言判成非法，而不是把它学会。

## 3. 关键算法伪代码

```python
# IP-264 许可硬掩码：未许可 → abstain，绝不映射最近邻
def licensed_posterior(p, L_t):
    mask = {e: p[e] for e in L_t}
    z = sum(mask.values())
    return ({e: v / z for e, v in mask.items()}, max(0.0, 1.0 - z))

# IP-265 四分不确定性
def quad_decompose(p, modes, L_t, trust, license_conf, open_mass):
    U_ale  = sum(p[e] * trace(cov(modes[e])) for e in L_t)
    U_ref  = entropy([p[e] for e in L_t])
    U_lex  = bernoulli_entropy(open_mass)
    U_inst = bernoulli_entropy(license_conf) + entropy(trust)
    return U_ale, U_ref, U_lex, U_inst

# IP-266 双钥认证
def certify(o, p, L_t, P_intent, trust):
    e, p1 = argmax_licensed(p, L_t); p2 = second_best(p, L_t)
    return (P_intent >= TAU_INT and p1 >= TAU_REF and
            (p1 - p2) >= DELTA_MARGIN and trust[e] <= TAU_INST)

# IP-267 问题有效性加权的交互选择
def choose_interaction(modes, L_t, o, budget, consent):
    best = None
    for g in candidates(modes) + ostensive_acts(modes):
        if not budget.allow(g) or not consent.allow(g): continue
        if not c_ras_wm.certify_info(g, o):             continue
        if question_validity(g, L_t, o) < Q_MIN:        continue   # 问了会更糟
        val = q * voi(g) - cost(g) - LAM_C * coerce(g)
        if best is None or val > best.val: best = (g, val)
    return best if best and best.val > 0 else None

# IP-268 来源感知裁决 / IP-269 担保隔离 / IP-270 反向通道
def adjudicate(labels, institutions, rho):
    conf = hierarchical_confusion(labels, institutions, rho)
    post = latent_truth(conf, labels)
    return post, residual_disagreement(post, labels)      # V_e

def warranty_step(e, field_evidence, claims):
    if exceeds(e.V_e, field_evidence) and not e.quarantined:
        e.state = 'quarantined'
        claims.open(author=e.A_e, share=e.w_e, data=e.data_hash)
    return e.state

def backchannel(intent, L_back, site):
    g = flow_match_backchannel(intent)
    return g if licensed(g, L_back, site) and not offensive(g, site) else neutral_channel(site)

# IP-273 PALM 主闭环（继承 R69）
def PALM_round(M, obs, S_t):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    p, abstain = licensed_posterior(M.head(samples), M.glp.active(S_t))
    U_ale, U_ref, U_lex, U_inst = M.qad.quad(
        p, samples, M.glp.active(S_t), M.trust, M.license_conf, abstain)
    ok = M.dgk.certify(o, p, M.glp.active(S_t), M.intent(o), M.trust)
    if not ok and U_lex <= TAU_LEX and U_inst <= TAU_INST:
        g = M.mintl.choose_interaction(samples, M.glp.active(S_t), o, M.budget, M.consent)
        if g is not None: p = M.cia.update_belief(p, M.cia.execute(g))
    if U_lex > TAU_LEX:
        M.drm.maybe_enroll(S_t, M.consent); return M.abstain_or_switch(S_t)
    if U_inst > TAU_INST:
        M.swq.quarantine(M.glp.active(S_t)); return M.fallback_nongesture(S_t)
    if not ok: return M.hold()
    U_floor = U_ale + (U_ref if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(...); mode = select_mode(samples, p, lam)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    ack = M.bcg.backchannel(mode, M.glp.back, S_t)
    M.vqa_i.submit_async(g, p, U_lex, U_inst, ack)
    return k, lam, mode, (U_ale, U_ref, U_lex, U_inst)
```

## 4. 推导

**引理 19（硬掩码的开放集安全界）** 软最近邻把词典外手势分给合法类目的错误接受率 ≥ `β·(1−ε_ood)`；硬掩码把词典外质量全导入弃权，错误接受率 ≤ `ε_ood`。系：「不认识的就不认」比「认成最像的」安全；掩码需在解码侧二次校验。

**引理 20（问题有效性与强制选择下界）** 强制二选一在词典不匹配时期望错误率 ≥ `(1−q)/2`，校准误差上升 ≥ `(1−q)/2 − ε_cal`；故 `VoI_eff` 可为负——**q 低时提问把「诚实的不知道」变成「被确认的错误」**。系：`q_min` 与示证/开放动作是安全约束，不是礼貌。

**引理 21（机构相关下的语义方差）** 来源错误相关 ρ > 0 时多数票高估准确率、低估 `V_e`，偏差随 ρ 与同源性上升；分层混淆 + abstain 可识别至 `O(1/√n)+ρ`。系：「三家都同意」在 ρ 高时约等于「一家说三遍」。

**定理 19（语义担保的激励相容）** 检出概率 `p_d > 0`、赔付与真实伤害成正比且担保随声明范围上升时，当 `p_d·赔付 > 超范围收益`，如实声明最小足够辖区是贝叶斯纳什均衡；否则作者会把方言写成普适。

**定理 18（PALM 严格包含 FLUID）** 许可掩码、双钥、四通道退避只收缩动作集 ⇒ 任意状态执行风险 ≤ R69；单词典、全域许可、同意常开、`U_lex=U_inst=0`、只用强制问时逐指令等于 FLUID。R69 是 PALM 的「共享词典、无制度摩擦」边界。

**定理 20（双钥与语义漂移下的无突变）** 未认证手势只观测不执行；`U_inst` 越界隔离条目并切预置安全通道，λ 单调不降；反向通道经许可校验；语义漂移只能通过重许可改变行为，不能改写安全包络。

## 7. 本轮最大风险

**一句话**：PALM-RAS 最大的风险不是「读错手势」，而是「**用一张多方签字的许可证，把一个社区真正在用的手势合法地判为不存在**」——许可掩码与担保机制一旦被作者/部署方的合同权力俘获（把方言写成越界、把方差压低、把责任推给最弱方），系统会比 R69 更自信地弃权或误读，且披着「合规」外衣。

**次级风险与缓解**：可用性塌陷（示证式动作 + 方言登记 + E316/E322）；机构裁决被俘获（分层相关 + abstain + 独立审计位 + E320）；强制问/社交工程（`q_min` + 证据纪律 + E318/E329）；反向通道冒犯（反向词典 + 中性通道 + E323）；同意洗白/常开传感泄露（可撤销许可 + 最小化 + 派生清除 + E324）；语义漂移被旧 `V_e` 吸收（`correction_rate` 第三通道 + 重许可 + E325）。

**一句话最大风险**：意义被合同化了，但合同可能被更有权力的一方书写——PALM 可能用「合规」把方言判成非法，而不是把它学会。
