# 第 62 轮（承接第 61 轮「具身语义进化闭环」IP-173~182；灵感循环第 8 轮；本轮灵感：「常识推理」×「机器人竞赛」）

> 第 61 轮构建了 ESEC：USR 统一语义表征、MEL 具身大模型、DMS 多轮对话、SRT-Dual 双流、PCE+++++ 六维预算。它把「场景→意图→阻抗→证据」拉进同一向量空间，解决了**表征割裂**与**时序鸿沟**。但把系统放进真实机器人竞赛（UniBot 类）后，**四个新暴露的局限**更致命：
> 1. **参数化推理 ≠ 概念化常识**：MEL 输出 φ_phys=(μ,k,η,σ)，能「估参数」却不能「讲道理」——它不知道满杯从杯沿抓会倾覆、薄瓷盘受压会先裂、抽屉要先向外再向上拉。USR 的嵌入再平滑，也可能落在「物理上荒谬但向量上邻近」的位置，缺少**符号化、可检验的常识层**。
> 2. **语义一致 ≠ 常识自洽**：ℒ_align 只约束「编码接近」，不约束「命题为真」。C_sem 高只说明四路嵌入互相靠近，不说明「支撑关系成立 / 容器不溢出 / 因果链闭合」。系统需要一个**常识一致性验证器**，而不只是一个对齐损失。
> 3. **任务完成 ≠ 竞赛得分**：ESEC 的优化目标是「完成任务」，而竞赛是**限时、按细则给部分分、隐藏任务、现场扰动、重置与违规惩罚**的。把每条任务都做完既不现实也不最优；缺少以「每秒得分率」为目标的**竞赛感知元控制**。
> 4. **常识幻觉 × 竞赛压力 = 高危组合**：LLM 的常识是「听起来对」，不是「已验证真」。在限时压力下，系统会**高置信度地执行错误常识**（如「抓住把手就能提起装满水的壶」）。必须把每条常识当作**可证伪先验**，用执行证据在线校准。
> 5. **预算维度缺失**：B_cog5 没有「常识推理」和「竞赛试错」两类资源，导致要么常识无限调用拖垮时延，要么盲目试错耗尽比赛时间。

## 0. 直觉与动机

**灵感 1（常识推理 → 具身常识因果图 ECG）**
直觉：第 61 轮的 USR 是「连续语义」，缺的是「离散关系」。人类操作物体靠的不是回归一个摩擦系数，而是一张关系网：`杯子 --支撑于--> 桌面`、`水 --容纳于--> 杯子`、`杯沿 --可抓但会倾覆-->`、`瓷 --脆性--> 受压先裂`。构建**具身常识因果图 ECG**：节点=物体/属性/动作/效果/任务/规则，边=支撑/容纳/可达/因果/先行/评分。ECG 是「连续感知」与「离散推理」之间的桥：视觉把观测实体链接到图节点，图上的消息传递给出**预期效果分布**；LLM 只负责补全缺失关系（软先验），物理约束投影负责拒绝荒谬补全。关键洞见：**常识不是知识库查表，而是"上下文→关系假设→可观测预测"的可微/可证伪推理**。

**灵感 2（机器人竞赛 → 竞赛感知元控制 CAM）**
直觉：竞赛不是「做完所有任务」，而是「在 T 秒内最大化得分」。构建**竞赛感知元控制 CAM**：状态=(任务信念, 剩余时间, 当前得分, 重置次数, 规则状态)，动作={attempt, explore, verify, safe_partial, reset, abort}，目标=期望得分率 E[score]/E[time] 而非完成率。关键洞见：**常识用于估计每个候选动作的"可行性×得分效率"**——常识说「这个任务 30 秒内做不完」，CAM 就应选择拿部分分的稳妥策略；常识说「再试一次大概率翻车」，CAM 就应放弃探索。竞赛把「常识」从离线知识变成了**在线资源分配的输入**。

**灵感 3（常识 × 竞赛 → 常识竞赛策略树 CST）**
直觉：常识负责「展开可能性」，竞赛负责「剪枝」。构建 AND/OR 策略树：根=竞赛任务，OR 节点=由 ECG 生成的替代分解/策略，AND 节点=子任务（带偏序约束）；每个节点带 (期望得分, 期望耗时, 常识可行性, 物理风险)。用**时间受限的 MCTS + 常识先验**搜索，剪掉「常识不可行」和「得分率低于阈值」的分支。这把「临场决策」从「单步反应」升级为「常识先验 + 竞赛价值」的树搜索。关键：树的展开不靠穷举，而靠 ECG 的 `requires/precedes/part_of` 关系做**组合式任务生成**。

**灵感 4（合流 → 常识-竞赛双环 CCL）**
直觉：第 61 轮是「语义-实时双流」，本轮在其上再加一个**任务级外层环**。内层仍是 ESEC（~10–1000Hz，保证执行安全）；外层是**常识-竞赛环**（~0.1–1Hz，CST+CAM）。两层耦合：外层输出「子任务 + 策略 + 常识先验」→ 写入 USR 任务意图；内层输出「执行证据 EV-exec」→ 经 CEG 证伪常识 → 外层更新图与得分估计。形成 `常识假设 → 执行检验 → 常识修正 → 竞赛决策` 的闭环。关键：**常识既能提高样本效率，又能被执行证据推翻**——这把它与「LLM 一次性规划」区分开。

**灵感 5（预算修正 → 认知-竞赛预算 B_cog⁺）**
直觉：新增两类资源：B_cs=(图查询次数、LLM token、验证试验次数)、B_comp=(剩余时间、尝试次数、风险额度、重置额度)。预算不足时：B_cs 耗尽 ⇒ 退化为「仅图查询 + 规则常识」（无 LLM）；B_comp 的剩余时间不足 ⇒ CAM 强制切换到「保守部分分」策略。预算与安全联动：**任何耗尽都不得放宽安全约束，只允许降低探索/得分野心**。降级优先级固定为「安全 > 得分 > 探索」。

## 1. 形式化定义（增量：定义 173–184）

**定义 173（具身常识因果图 ECG）** G_cs = (V, E, R, W, Gnd)。其中：
- **节点类型**：V = V_obj ∪ V_attr ∪ V_act ∪ V_eff ∪ V_task ∪ V_rule（物体、属性、动作、效果、任务、竞赛规则）
- **关系类型**：R = {has_attr, supports, contains, on_top_of, reachable_by, graspable_by, causes, prevents, requires, precedes, part_of, scores, violates}
- **置信权重**：W: E → [0,1]；带极性 polarity ∈ {+1, −1}，−1 为已证伪的反例边
- **观测接地**：Gnd: V_obj → USR 观测实体（视觉框 + 触觉材质 + 位姿），保证图节点最终指向当前感知
- **常识查询**：CSQuery(G_cs, c, a) → P(ŷ | do(a), c)，即「在上下文 c 执行动作 a，会产生什么可观测效果」
- **子图检索**：Ret(G_cs, c, k) = 以 c 中实体与动作任务为种子、取 k-hop 诱导子图（k=2~3，控制成本）

**定义 174（可证伪常识命题 FCP）** p = (φ, ŷ, h, c0, T, ttl)。其中：
- φ：命题本体（图上的一个关系假设，如 `cup is full ⇒ grasping_by(rim) causes spill`）
- ŷ ∈ ℝ^m：可观测预测（滑移概率、接触力峰值、倾角、溢出量、成功概率）
- h：适用上下文谓词（材质、姿态、任务阶段），h=false 时命题不生效
- c0 ∈ [0,1]：先验置信（来自 W 与 LLM 软先验的融合）
- T：检验协议（在 ≤ k 步内测哪些量、用哪个阈值 τ_falsify）
- ttl：有效期（材质/工具/场景变化后失效，避免过期常识污染）
- **关键**：每条常识都被编译为一个可执行检查，而不是一句自然语言。**不可检验的常识不得进入控制回路。**

**定义 175（常识推理算子 CS-Infer）** 输入 (Obs, task, G_cs, budget)，输出 (cs_emb, P_cs, risk_cs)：
1. **实体链接**：Gnd: Obs → V_obj（视觉检测 + 触觉材质分类 + 位姿配准）
2. **子图检索**：G_sub ← Ret(G_cs, Obs.entities ∪ task, k=2)
3. **消息传递**：h_v^{(l+1)} = σ( Σ_{r} Σ_{u∈N_r(v)} W_r h_u^{(l)} )，层数 L=3，得到节点状态
4. **LLM 补全**：对缺失边给出软先验 Ŵ_r（受 B_cs.LLM_Tokens 约束），且强制 Ŵ_r ≤ w_llm_max
5. **物理一致性投影**：Proj_phys 拒绝违反「支撑链非空、容器不悬浮、不可穿透、因果不逆序」的补全
6. **命题生成**：P_cs = {p_i}，含预测 ŷ_i、置信 c_i、检验协议 T_i
7. **语义嵌入**：cs_emb = E_cs(G_sub 池化) ∈ ℝ^{d_us}
- **常识一致性能力**：E_cs(G_sub) = Σ_{(u,r,v)} w_{uvr} · 𝟙[Consistent(u,r,v)]。不一致边触发**降权而非直接删除**（保留反例，供 CEG 使用）

**定义 176（常识-语义对齐 CSA）** 在 USR 中新增常识子空间与一致性惩罚：
- ℒ_csa = ℒ_align + λ_cs·(1 − E_cs/|E|) + λ_prop·Σ_i BCE(ĉ_i, y_i)
- 其中 ĉ_i 为命题预测置信，y_i 为执行验证结果（0/1 或连续）
- 与第 61 轮 ℒ_align 的区别：**不仅让嵌入靠近，还要求命题经得起检验**；对齐目标从「表征相似」升级为「表征相似 ∧ 预测正确」
- **常识锚点扩展**：Anchor_t 增加 cs_emb、P_cs 摘要（活跃命题 id + 预测哈希）、commonsense_version

**定义 177（竞赛感知元控制 CAM）** CAM = (S_meta, A_meta, P_meta, R_meta, π_meta)：
- S_meta = (b_task, τ_left, score_so_far, n_reset, rule_state, risk_used)
- A_meta = {attempt(j, π), explore, verify(p), safe_partial(j), reset, abort}
- R_meta(s,a) = Δscore − λ_t·Δt − λ_reset·𝟙[reset] − λ_viol·𝟙[violation] − λ_risk·risk(a)
- **目标**：π_meta = argmax_π E[Σ_t R_meta] / E[Σ_t Δt]（得分率，而非累计奖励）
- **硬约束**：任何动作若导致 ERTC 违规风险 > ρ_safe，一律屏蔽——**安全优先于得分**

**定义 178（竞赛得分模型 SM）** 对任务 j：
```
s_j = s_j^full · g_j(completion)
      − p_j^time · max(0, t_j − t_j^budget)
      − p_j^reset · n_reset_j
      − p_j^viol · n_viol_j
g_j ∈ [0,1] 为部分分函数（分阶段/分质量给分）
总分 S = Σ_j s_j
```
CAM 用 SM 的**在线估计** ŝ_j：隐藏细则未知，故用「历史同类任务 + 常识先验（ECG 的 scores 边）+ 少量探测」做贝叶斯更新，维护后验 N(μ_j, σ_j²)。

**定义 179（常识竞赛策略树 CST）** 树 T = (N_or, N_and, val, cost)：
- **OR 节点**：同一任务的替代分解/策略（来自 ECG 的 `part_of/requires` + LLM 补全）
- **AND 节点**：子任务序列（带 `precedes` 偏序约束）
- **节点值**：val(n) = (E[score|n], E[time|n], feas_cs(n), risk_phys(n))
- **选择（UCT_cs）**：
```
UCT_cs(n) = Q(n)/N(n)
          + c·√( ln N(parent)/N(n) )
          + κ·feas_cs(n)
          − μ·risk_phys(n)
```
**常识先验作为额外奖励项**，时间预算作为硬截断
- **剪枝**：feas_cs < θ_feas 或 E[score]/E[time] < θ_rate 的分支剪除；但**永远保留 1 条「安全兜底分支」**（最低风险、最低得分）

**定义 180（常识-执行证伪接地 CEG）** 每当执行子任务返回 EV_exec，对每个活跃命题 p_i：
- **残差**：e_i = ‖ŷ_i − y_i^obs‖（如预测滑移 0.1 vs 观测 0.8）
- **贝叶斯更新**：c_i ← c_i·L(y_i^obs | ŷ_i) / [ c_i·L + (1−c_i)·L̄ ]
- **证伪**：若 e_i > τ_falsify，向 ECG 写入反例边 (u, r, v, polarity=−1)，降低 W，并触发 CAM 重规划
- **退役**：被证伪命题进入「退役集」；只有当上下文 h 发生改变（换材质/换姿态）才允许重新激活
- **校准指标**：ECE_cs = Σ_b (|B_b|/N)·|acc(B_b) − conf(B_b)|
- **关键**：常识不是被「相信」，而是被「检验后暂时保留」；**证伪比确认更重要**（确认只加一分信心，证伪能避免一次灾难）

**定义 181（常识-执行联合证书 J_cs_exec）** 扩展第 61 轮 J_sem_exec：
```
J_cs_exec = ( J_sem_exec,
              cs_consistency,          # E_cs/|E|
              prop_coverage,           # 活跃命题覆盖的边 / 总关键边
              ece_cs,                  # 常识命题校准误差
              n_falsified,             # 本轮被证伪命题数
              competition_compliance,  # 无规则违规
              score_snapshot )         # 决策时得分快照
Valid(J_cs_exec) ⇔ Valid(J_sem_exec)
                   ∧ cs_consistency ≥ τ_c
                   ∧ ece_cs ≤ τ_ece
                   ∧ competition_compliance
```

**定义 182（常识-竞赛双环 CCL）**
- **外层（0.1–1Hz）**：CST.search → 选 (子任务 j, 策略 π, 常识先验 P_cs) → 写入 USR 任务意图；CAM.step 更新得分/时间
- **内层（ESEC，10–1000Hz）**：USR → Π → EEIS → ERTC → EV-exec
- **耦合**：(a) 外层常识先验降低内层探索；(b) 内层 EV-exec 经 CEG 证伪外层常识；(c) 外层得分反馈更新 SM
- **稳定性条件**：外层决策周期 T_out 与内层任务时长 T_in 满足 T_out ≤ α·T_in（α≈0.3），否则外层「决策过时」，动作前必须重新读取 anchor_version；版本不一致则丢弃该外层决策

**定义 183（认知-竞赛预算 B_cog⁺）** B_cog⁺ = (B_perc, B_sem, B_cs, B_comp, B_exec, B_meta)：
- B_perc = (B_scene, B_intent)，B_sem = (B_mel, B_usr)（继承第 61 轮）
- B_cs = (GraphQueries, LLM_Tokens, VerifyTrials)
- B_comp = (TimeLeft, Attempts, RiskQuota, Resets)
- B_exec = 执行预算，B_meta = (CST_Nodes, MCTS_Rollouts)
```
cost_cs   = λ_g·Q/Q_max + λ_tok·Tok/Tok_max + λ_v·V/V_max
cost_comp = λ_τ·(1 − τ_left/T) + λ_a·Attempts/A_max + λ_r·risk_used/risk_quota
```
- **降级序（固定）**：B_cs 耗尽 ⇒ 只用图查询（无 LLM）；B_meta 耗尽 ⇒ 贪心选最高得分率子任务；B_comp 时间不足 ⇒ safe_partial；B_comp 风险额度耗尽 ⇒ 只保留安全兜底分支
- **安全单调性**：任何降级都不得放宽 ERTC / EEIS 安全约束，只允许降低探索与得分野心

**定义 184（常识驱动的组合泛化 CSG）** 设未见任务 τ* 可分解为已见原语集合 {(a_i, o_i)} 与常识关系 r ∈ R_cs 的组合。若：
(i) ECG 覆盖 τ* 所需全部原语与关系；
(ii) 每个原语的命题校准误差 ≤ ε（即预测可信）；
(iii) CST 能在 B_meta 内枚举该组合；
则 τ* 的期望得分率与已见任务的差距 ≤ δ_comp。
- **经验目标**：未见组合任务成功率 ≥ 70%，得分 ≥ 满分的 60%（对比第 61 轮零样本新任务约 40–50%）
- **注意**：这是**条件性保证**，不是无条件定理——它的价值在于把「泛化」拆成三个可测条件（覆盖、校准、搜索），从而可诊断失败原因

## 1.5 一个具体样例（把定义串起来）

场景：桌上一个**装满水的薄瓷杯**，任务「把它移到 20cm 外」，限时 25s，评分「不洒 + 不碎 = 满分；洒一半 = 0.4；碎 = 0」。

1. **ECG 接地**：检测到 `cup(瓷, 薄壁)`、`water(满)`、`table`；链接出边 `water --contains--> cup`、`cup --supports--> table`、`grasp(rim) --causes--> spill`、`press(>5N) --causes--> crack`。
2. **CS-Infer**：生成命题 p1「抓杯沿⇒溢出概率 0.7」、p2「夹持力>5N⇒开裂概率 0.6」、p3「抓杯身中部⇒稳定 0.8」；cs_emb 与 `φ_phys=(μ≈0.35, σ_brittle 高)` 共同写入锚点。
3. **CST + CAM**：OR 节点 {grasp_rim, grasp_body, scoop_from_below, push_slide}；CST 用常识可行性剪掉 grasp_rim（溢出风险）与 scoop（薄瓷怕侧压）；CAM 比较 `grasp_body`（得分率 0.9/12s）与 `push_slide`（0.7/18s），选前者。
4. **内层执行 + CEG**：实际夹持时触觉观测到滑移 0.5（p1 方向对但机制不同），CEG 更新「瓷面湿滑⇒grasp_body 也滑」；CAM 立即切到 `safe_partial`（低刚度、慢速推滑，保 0.4 分）而不是硬提。
5. **证书**：J_cs_exec 记录 cs_consistency、被证伪命题数=1、无违规、score_snapshot=0.4，可赛后审计「为什么放弃满分」。

这个样例说明：**常识提供候选与风险，竞赛提供取舍，证据负责推翻，证书负责复盘**。

## 2. 关键算法伪代码（IP-183 ~ IP-192）

### IP-183 ECG（具身常识因果图）

```python
class EmbodiedCommonsenseGraph:
    def __init__(self, d=256):
        self.V = {}                       # id -> Node(type, attrs, emb)
        self.E = defaultdict(list)        # (src, rel) -> [(dst, w, pol)]
        self.constraints = [SupportChain(), NoPenetration(),
                            Containment(), CausalOrder()]
        self.llm = None

    def ground(self, obs, usr):
        # 视觉检测框 + 触觉材质 + 位姿 -> 图节点（实体链接）
        ents = []
        for det in obs.detections:
            nid = self.link_or_create(det)
            self.V[nid].emb = usr.scene_encoder(det.crop)
            ents.append(nid)
        return ents

    def k_hop(self, seeds, k=2):
        frontier, seen = set(seeds), set(seeds)
        for _ in range(k):
            nxt = set()
            for u in frontier:
                for rel, outs in self.E.items():
                    if rel[0] == u:
                        nxt |= {v for v, _, pol in outs if pol > 0}
            frontier = nxt - seen
            seen |= nxt
        return self.induced(seen)

    def message_passing(self, sub, L=3):
        h = {v: self.V[v].emb for v in sub.nodes}
        for _ in range(L):
            nh = {}
            for v in sub.nodes:
                agg = sum(self.W[rel] @ h[u]
                          for (u, rel) in sub.in_edges(v)
                          if sub.pol[(u, rel, v)] > 0)
                nh[v] = relu(agg + h[v])
            h = nh
        return h

    def llm_complete(self, sub, budget):
        # 仅补缺失边，且软先验权重受硬上限约束
        missing = self.find_missing_relations(sub)
        for (u, rel, v) in missing:
            if budget.tokens <= 0:
                break
            w = min(self.llm.score(u, rel, v), self.w_llm_max)
            self.E[(u, rel)].append((v, w, +1))
            budget.tokens -= self.llm.tokens_used
        return sub

    def project_physics(self, sub):
        for c in self.constraints:
            sub = c.enforce(sub)      # 违反则降权 / 标记反例，不静默删除
        return sub
```

```python
class CommonsenseStrategyTree:
    def search(self, task, G, budget):
        root = AndOrNode(task, kind='OR')
        while budget.mcts_rollouts_left > 0 and budget.time_left > 0:
            path = self.select(root)            # UCT_cs
            leaf = self.expand(path, G)        # OR: 常识分解; AND: 子任务序列
            val = self.simulate(leaf, budget)  # score/time/feas/risk
            self.backprop(path, val)
            budget.mcts_rollouts_left -= 1
        best = self.best_child(root)
        if best.feas < budget.theta_feas:
            best = self.safe_fallback(root)   # 永远保留安全兜底
        return best

    def select(self, node):
        while node.is_expanded():
            node = max(node.children, key=self.uct)
        return node

    def uct(self, n):
        return (n.Q / n.N
                + self.c * math.sqrt(math.log(n.parent.N) / n.N)
                + self.kappa * n.feas
                - self.mu * n.risk)
```

```python
class EmbodiedCommonsenseGraph:
    def __init__(self, d=256):
        self.V = {}                        # id -> Node(type, attrs, emb)
        self.E = defaultdict(list)         # (src, rel) -> [(dst, w, pol)]
        self.W = {}                        # rel -> [d, d]
        self.constraints = [SupportChain(), NoPenetration(),
                            Containment(), CausalOrder()]
        self.w_llm_max = 0.5               # LLM 软先验权重硬上限

    def ground(self, obs, usr):
        ents = []
        for det in obs.detections:
            nid = self.link_or_create(det)          # 视觉框 + 触觉材质 + 位姿
            self.V[nid].emb = usr.scene_encoder(det.crop)
            ents.append(nid)
        return ents

    def k_hop(self, seeds, k=2):
        frontier, seen = set(seeds), set(seeds)
        for _ in range(k):
            nxt = {v for u in frontier for (v, _, pol) in self.E.get(('rel', u), [])
                   if pol > 0}
            frontier = nxt - seen
            seen |= nxt
        return self.induced(seen)

    def message_passing(self, sub, L=3):
        h = {v: self.V[v].emb for v in sub.nodes}
        for _ in range(L):
            h = {v: relu(sum(self.W[r] @ h[u]
                              for (u, r) in sub.in_edges(v)
                              if sub.pol[(u, r, v)] > 0) + h[v])
                 for v in sub.nodes}
        return h

    def llm_complete(self, sub, budget):
        for (u, rel, v) in self.find_missing_relations(sub):
            if budget.tokens <= 0:
                break
            w = min(self.llm.score(u, rel, v), self.w_llm_max)
            self.add_edge(u, rel, v, w, +1)
            budget.tokens -= self.llm.last_tokens
        return sub

    def project_physics(self, sub):
        for c in self.constraints:
            sub = c.enforce(sub)           # 违反则降权/标记反例，不静默删除
        return sub

    def add_counterexample(self, phi):
        u, rel, v = phi
        self.add_edge(u, rel, v, w=1.0, pol=-1)
        self.retired.add(phi)
```

```python
    ents = G.ground(obs, usr)
    sub = G.k_hop(ents + task.entities, k=2)
    h = G.message_passing(sub)
    if budget.llm_tokens_left > 0:
        sub = G.llm_complete(sub, budget.consume_llm())
    sub = G.project_physics(sub)

    props = [
        FalsifiableProposition(
            phi=(u, rel, v),
            y_hat=G.predict_observable((u, rel, v), obs),
            h=context_predicate(u, rel, v),
            c0=w,
            T=verification_protocol((u, rel, v)),
            ttl=task.horizon)
        for (u, rel, v, w, pol) in sub.positive_edges()
    ]
    cs_emb = G.pool(sub, h)
    risk_cs = G.risk_prior(sub, props)
    E_cs = G.consistency_energy(sub)
    return cs_emb, props, risk_cs, E_cs
```

### IP-185 CAM（竞赛感知元控制）

```python
class CompetitionAwareMetaControl:
    def __init__(self, score_model, cost_model, ertc, budget, rho_safe=0.01):
        self.sm, self.cm = score_model, cost_model
        self.ertc, self.budget = ertc, budget
        self.rho_safe = rho_safe
        self.posterior = {}                 # task -> N(mu_s, sigma_s^2)

    def step(self, state):
        best, best_rate = None, -inf
        for a in self.enumerate_actions(state):
            if self.risk(a, state) > self.rho_safe:
                continue                    # 安全硬约束
            if not self.budget.comp.can_afford(a, state):
                continue                    # 竞赛预算
            gain = self.sm.expected_gain(a, self.posterior)
            dt = self.cm.expected_time(a, state)
            rate = gain / max(dt, 1e-3)
            if rate > best_rate:
                best, best_rate = a, rate
        return best, best_rate

    def update_from_score(self, task, observed):
        self.posterior.setdefault(task, Gaussian(0.5, 0.3)).update(observed)
```

### IP-186 CST（常识竞赛策略树）

```python
class CommonsenseStrategyTree:
    def search(self, task, G, budget):
        root = AndOrNode(task, kind='OR')
        while budget.rollouts_left > 0 and budget.time_left > 0:
            path = self.select(root)
            leaf = self.expand(path, G)     # OR: 常识分解; AND: 子任务偏序
            val = self.simulate(leaf, budget)
            self.backprop(path, val)
            budget.rollouts_left -= 1
        best = max(root.children, key=lambda n: n.Q / max(n.N, 1))
        return self.safe_fallback(root) if best.feas < budget.theta_feas else best

    def uct(self, n):
        return (n.Q / n.N
                + self.c * math.sqrt(math.log(n.parent.N) / n.N)
                + self.kappa * n.feas
                - self.mu * n.risk)

    def expand(self, node, G):
        if node.kind == 'OR':
            for decomp in G.commonsense_decompositions(node.task):   # requires/part_of
                node.add_child(AndOrNode(decomp, kind='AND'))
        else:
            for seq in G.temporal_orderings(node.task):              # precedes
                node.add_child(AndOrNode(seq, kind='OR'))
        return node
```

```python
def ceg_update(G, props, EV_exec, task):
    falsified = []
    for p in props:
        if p.retired or not p.h(EV_exec.context):
            continue
        y = extract_observable(EV_exec, p.T)
        e = norm(p.y_hat - y)

            falsified.append(p)
            task.request_replan = True
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| ECG | O(|V|+|E|) 检索 / O(L·|E|·d) 传递 | O(|V|·d+|E|) | 实体链接 F1 ≥ 0.85；物理约束违反率 ≤ 1% |
| CS-Infer | 5–20ms 图 / +50–300ms LLM | O(k-hop) | 命题 ECE_cs ≤ 0.08 |
| CAM | O(|A|) | O(1) | 不安全动作过滤率 100% |
| CST | O(rollouts·branching·depth) | O(nodes) | 与穷举得分差距 ≤ 15% |
| CEG | O(|P|)/次 | O(|P|) | 证伪后 ≤ 5 次观测完成校准 |
| CCL | 外 0.1–1Hz / 内 10–1000Hz | 共享内存+图缓存 | 内层阻塞 ≤ 1ms；过时决策丢弃 |

**正确性命题（CS-Comp-Complete，条件性）**：假设 A61–A70 及
**(A71)** ECG 实体链接 F1 ≥ 0.85，物理约束投影 sound；
**(A72)** 每条活跃 FCP 有可执行检验协议，观测噪声有界；
**(A73)** CEG 似然校准，τ_falsify 与噪声上界匹配；
**(A74)** CAM 安全过滤先于得分优化，ERTC 风险估计保守；
**(A75)** CST 的 feas_cs 是真实可行性乐观上界，risk_phys 是保守下界；
**(A76)** CCL 动作执行前 anchor_version 未变或被重读确认；
**(A77)** B_cog⁺ 降级序单调，安全约束不在降级集合内。
则：
1. **常识可靠性**：若 ECE_cs ≤ ε，则活跃命题预测误差期望 ≤ ε + δ_noise；被证伪命题不再进入控制回路。
2. **竞赛近似最优**：CST 在预算内找到的分支与全树最优得分率之差 ≤ O(√(log N/N)) + δ_feas + δ_risk。
3. **安全优先**：任意状态下 π_meta 的动作要么风险 ≤ ρ_safe，要么是安全兜底分支；得分永不覆盖安全。
4. **组合泛化**：定义 184 三条件成立时，未见组合任务得分退化 ≤ δ_comp。
5. **实时隔离**：外层常识/竞赛推理不进入实时临界路径，内层抖动 ≤ 0.2ms。

**与第 61 轮的区别**：第 61 轮正确性 =「表征一致 + 时序隔离」；本轮新增「**命题可证伪 + 得分可优化 + 决策可审计**」，把系统从语义闭环推进到**认识论闭环**——它不仅对齐世界，还承认自己可能错并用证据修正。

## 5. 本轮最大风险

**一句话**：若 LLM 补全的常识在竞赛限时压力下被系统性当成「已验证事实」（校准崩塌），或 ECG 常识先验使 CST 的可行性估计过度乐观而反复选择注定失败的任务，或 CEG 证伪信号被噪声淹没以致剩余时间内无法重规划，则系统会陷入「**常识越丰富、错得越自信、时间越不够**」的自我强化失败；必须以「每条常识可证伪 + CEG 在线校准 + CAM 安全硬约束优先 + 永远保留安全兜底分支 + B_comp 时间预算强制切换部分分」构建**常识护栏**，并牢记：**竞赛里最危险的不是不会，而是自信地做错。**
