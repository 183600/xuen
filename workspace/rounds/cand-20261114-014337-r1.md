# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；本轮灵感：「同步定位与建图」×「四足机器人」）

> R69 把不确定性一分为二，并让系统学会「问」。但它的「问」是**当下、局部、健忘**的：在单一观测 o_t 上采样模态、算一次 VoI、消解一次、然后丢弃。这对桌面操作够用，对**野外四足**不够——那里最贵的不确定性不是「这一帧该怎么动作」，而是「**我站的这块地、我走过的这条路，到底是地图里的哪一个地方**」：它**空间上驻留、时间上可复发、并且由身体自己的移动产生**。R69 的每步后验无法表达「上次我对这块地的判断错了」，更无法在重访时把那个错误重新唤醒。
>
> 本轮两个灵感恰好把 R69 的「点式消歧」提升为「**图式消歧**」：
> - **SLAM** 天生用**混合信念**（离散数据关联假设 × 连续因子协方差）承载不确定性——这正是 (U_epi, U_ale) 的**空间载体**；R69 的「模态」是动作假设，R70 的「模态」是**地图假设**（哪次回环为真、哪块地形属于哪一类）。
> - **四足机器人**揭示一个被轮式/手持 SLAM 掩盖的事实：**走就是测，踩就是实验**。腿式里程计在打滑时退化，而打滑恰恰发生在最模糊的地形上——**身体的漂移与地图的漂移是同一个隐变量**，只能由外感受或接触探询来解开。于是 R69 的 g_probe（探针）在四足上有了最自然的肉身形态：**一次落脚前的轻踏**。主动 SLAM 与主动感知在落脚点这一层合流。
>
> 核心命题：**把 R69 的 (U_ale, U_epi) 从逐步动作分布，提升为空间驻留的混合地图信念；把主动交互从「问一句」扩展为「走一步 / 踩一下 / 回环一次」；并用「反坍缩一致性证书 + 嵌入式运动学先验 + 开放式覆盖守卫」堵住 SLAM 特有的两种致命错误——自信地错（overconfident collapse）与真相不在假设集里（open-world failure）。** 命名 **STANCE-RAS**（Spatio-Temporal ANchored Contact-groundEd epistemics for Risk-Adaptive Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我站的地方真的是我以为的那个地方吗——而我还能走多远**」。地图是身体的记忆，身体是地图的传感器。

## 0. 直觉与动机

**灵感 1（SLAM 的混合信念 = R69 二分法的空间化）**
直觉：R69 的 U_ale 是「同一模态内的抖动」，U_epi 是「几个模态之间选哪个」。SLAM 的因子图里有一模一样的结构，只是对象换成了地图：同一个关联假设内，位姿/路标的协方差是 aleatoric（测量噪声、线性化残差，收不回来）；而在几个**数据关联假设**之间——「这帧激光是不是三个月前那个走廊」「这块起伏是石头还是坑」——是 epistemic（可约，靠回环、重访、探询消解）。更妙的是，SLAM 从不把两者压成一个标量：它用**离散假设上的权重 + 每个假设内的连续高斯**来表达。所以 R70 不需要发明新表示，只需**承认地图就是 (U_ale, U_epi) 的天然容器**。R69 的模态分解（对动作聚类）升级为 R70 的假设维护（对关联/地形聚类）。
关键差别：R69 的模态**用完即弃**；SLAM 的假设**写进地图、可被再次读到、也会在重访时被证伪**。这就是「驻留」二字的分量。

**灵感 2（走就是测：腿式里程计的滑移不可辨识）**
直觉：轮式打滑还能靠轮速差大致察觉；四足的腿式里程计只有一个「脚没动→身体动了」的纯运动学积分。一旦脚在碎石/冰面/软土上滑移，本体感觉**根本分不清**是「我滑了」还是「世界在动」——两者对关节编码器产生完全相同的观测。这不是噪声大，而是**秩亏**：滑移方向与位移方向线性相关，信息矩阵在该方向上是零。于是「我走了多远」这个最重要的 SLAM 输入，恰恰在最需要它的时候失效。解法只有一个：引入**本体之外的观测**——外感受（视觉/激光）或**接触**（踩实了没有）。而四足恰好有四个可以「主动去踩」的接触探针。这直接改写了 R69 的 VoI：信息动作不再只是「看/问」，而是「**这一步踩哪里、要不要先轻踏试探**」。

**灵感 3（踩就是实验：落脚点 = 任务动作 × 不可逆信息动作）**
直觉：R69 把 ξ=(a,g) 拼在一起，但默认 g 是**可逆的**——看错可以再看，问错可以再问。四足的探询不是：脚一旦落下、重心一旦压过去，**滑倒或踩塌就发生了**，没有「撤销」。所以这里的信息动作是**单向门**（one-way door）：它同时是测量和承诺。两个后果：(1) 安全认证必须从 R69 的「前缀认证」升级为**执行前认证**（pre-execution certificate），因为执行后已无前缀可退；(2) 必须允许**弃权**（abstain）——当探询的期望信息收益抵不过不可逆风险时，宁可不探，退回更保守的步态。主动 SLAM 的经典病是「为了地图熵而降速乱走」；四足把它的代价变得**物理可见**：乱探会摔。

**灵感 4（任务加权 VoI：不是所有熵都值得降）**
直觉：主动 SLAM 有一个老陷阱——直接最大化「地图熵的下降」会派生出大量**与任务无关**的探索：远处一片从不在任何可行路径上的区域，熵再高，降它对「下一步会不会踩空」毫无帮助；反过来，一个只涉及**单个落脚点**、熵值很小的歧义（这块石头会不会滚），却可能决定这一步是走还是绕。所以 R70 的 VoI 必须打在**任务泛函** φ(b) 上（下一步落脚可行性的分布、H 步 cost-to-go 的分布），而不是原始地图熵。这也解释了为什么「不确定性」不能脱离任务单度量——R69 已暗示过（VoI 是可分歧义而非模糊本身的函数），R70 把它彻底任务化。

**灵感 5（反坍缩：协方差变小不等于更准）**
直觉：R68 的最大恐惧是「缓变故障被标定解释掉」；SLAM 有一个同构却更阴险的版本：**一次错误的回环把两张本不相连的地图强行焊在一起，协方差会显著缩小（因为多了约束），而地图其实彻底错了**。因子图的线性化误差也会让 Σ 系统性偏小（overconfidence）。于是「我变得更确定了」本身是一个**不可信的信号**：R69 的 MCG 只看权重准不准，看不到「置信度增长与观测创新是否自洽」。所以 R70 必须引入**反坍缩证书**：任何让 Σ 变小、却让归一化创新（NIS）越过 χ² 上界的编辑，判为**过度自信坍缩**，触发保守步态而不是加速。一句话：**缩小协方差是一种主张，必须用一致性来担保，而不是当作证据。**

**灵感 6（嵌入式先验：身体给地图修正上了一道物理锁）**
直觉：轮式/手持 SLAM 可以「瞬移」——回环一来，估计位姿一步可以跳两米，因为载体没有强运动学约束。四足不行也不能：**腿决定了你不可能比 v_max·Δt 走得更远**，接触相位还约束了「此刻哪只脚必须着地」。所以任何一次地图/位姿修正，若蕴含的位移超过运动学可达、或与接触相位矛盾，就应被**物理合理性先验**直接拒绝——这不是学习出来的，是身体自带的、免费的、对抗错误回环的强先验。这是本轮最「四足特异」的贡献：**embodiment 本身是一种 SLAM 正则**。

**灵感 7（开放式：真相可能不在假设集里）**
直觉：以上一切仍默认「正确的解释在我的假设集合里」。但野外会遇到**集合外**的情况：从未见过的地形物理（会蠕动的沙）、系统性的传感器模型错误、或对抗性的「看起来完全像已知类」的伪装地形。此时多假设地图不是「不确定」，而是**自信地错**，而且**主动探询会让它错得更自洽**——因为每次探询都在同一套错误假设下被解释，形成「认知近亲繁殖」。这不是靠 VoI 能救的。唯一诚实的做法：用一个**新颖性/覆盖守卫**，当观测落在已知假设的低密度区时，**扩大假设集或转保守步态，而不是继续探询**。这是本轮最大风险的形式化入口，也是它与 R69 的根本分界：R69 的风险是「权重没校准」，R70 的风险是「假设集没覆盖」。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（STANCE-RAS 总览）** STANCE-RAS = (HMS, CBA, LAS, LCE, ACC, TMP, FIS, BFP, MLR, OWG, RAS-WM‡)。三不变式：
(i) **分层实时不变式**：控制层 ≥500 Hz 与 R68 逐指令同构，地图层 ≤50 Hz、任务层 ≤10 Hz，地图更新对控制层只呈现为**有界扰动**；
(ii) **单向门纪律**：不可逆信息动作（落脚探询）必须过**执行前**证书，且允许弃权；弃权绝不比不动作更不安全；
(iii) **地图编辑证据纪律**：任何改变地图拓扑的编辑（回环提交、路标合并）需 ≥k 个正交证据一致 **且**通过反坍缩一致性检验，否则只能作为软约束，单模态不得提交。

**定义 311（混合地图信念 HMS）** 地图信念 b = {(w_h, μ_h, Σ_h)}_{h∈ℋ}，ℋ 为离散假设空间（数据关联 / 地形类 / 回环真假），w_h 为假设权重（Σ_h w_h = 1），(μ_h, Σ_h) 为该假设下的连续因子图后验（位姿+路标+地形参数）。地图上的二分：
U_ale(b) = Σ_h w_h tr(Σ_h)（假设内、不可约：噪声/线性化）；
U_epi(b) = H(w) · s(ℋ)（假设间、可约：s 为假设可分性，同 R69 定义 296 的 sep_factor）。
与 R69 定义 297 的关系：把「动作模态」换成「地图假设」即可，代数结构完全同构——这正是「R70 是 R69 的空间化」的严格含义。

**定义 312（接触-本体耦合里程计 CBA 与滑移不可辨识）** 本体观测 y_odo = Δx_body + s + ε，滑移 s ∈ ℝ³ 不可由 y_odo 单独辨识：对任意 s，存在 Δx 使 y_odo 相同。定义滑移可辨识当且仅当存在接触约束或外感受使观测矩阵 O(Δx,s) 满秩。**滑移退化态**：rank O = 2（平面位移可辨、滑移不可辨）时，纯本体定位漂移速率下界 ≥ E‖s‖。

**定义 313（任务加权主动 SLAM VoI，LAS）** 设任务泛函 φ(b) = 下一步落脚可行性的后验分布（或 H 步 cost-to-go 分布）。信息动作 g 的任务 VoI：
VoI_φ(g) = H(φ(b)) − E_{y~p(·|g,b)}[H(φ(b′) | b, y)]，
选择 g* = argmax_g [VoI_φ(g) − c_exec(g) − c_irrev(g)]，s.t. 执行前风险 ≤ ε_int；若 max ≤ 0 ⇒ 弃权。**关键**：用 φ 而非恒等映射，杜绝「熵驱动乱探索」（引理 20）。

**定义 314（不可逆信息动作与执行前证书）** 探询 g 具执行风险 r_exec(g) 与不可逆度 ι(g)（无法回退的物理后果）。执行前证书 Cert_pre(g) ⇔ r_exec(g) + ι(g)·L_fall ≤ ε_int **且**存在可行的弃权/恢复动作。R69 的前缀认证（前缀可停）在此不足，因为执行后已无前缀可退。

**定义 315（分层信念抽象与有界扰动）** 控制层不直接消费 b，而消费其**可行性抽象** Feas(b) = ⋃_h {x : (x−μ_h)ᵀΣ_h⁻¹(x−μ_h) ≤ χ²_α}。地图层更新对控制层等效为扰动 d_t，满足 ‖d_t‖ ≤ diam(ℋ)·λ_max(Σ)^{1/2}，且必须经**限速投射**（定义 320）后才进入 Feas。

**定义 316（回环闭合证据纪律 LCE）** 回环编辑 e 需四类正交证据投票：外观描述子、几何校验（RANSAC 内点数/重投影）、本体轨迹一致性（脚/IMU 预积分与候选回环之差）、时间顺序合理性。票数 < k_LC ⇒ 仅提交**软约束**（不改拓扑）；≥ k_LC 且过定义 317 ⇒ 才允许硬编辑。单模态回环**永不**单独提交（R69 定义 293-iii 在地图侧的推广）。

**定义 317（反坍缩一致性证书 ACC）** 对一次地图更新 b→b′：置信度增量 Δc = tr Σ(b) − tr Σ(b′)；一致性用滑动窗归一化创新平方 NIS = Σ_i ν_iᵀ S_i⁻¹ ν_i（应 ~ χ²）。**过度自信坍缩** ⇔ Δc > 0 且 NIS > χ²_{1−α}（更自信却不自洽）。触发即拒绝本次编辑的协方差收缩、回滚权重、进入保守步态。注意：ACC 只抓「不一致的错」，抓不到「自洽的错」（引理 21）。

**定义 318（地形后验 TMP）** 每个地形片元 x 带类后验 p(τ_x | 𝒟)，τ ∈ {solid, deformable, sloped, void}，并给出可通行代价分布 p(cost | τ_x)。脚接触（力/位移/滑移响应）是**直接观测**，更新该片元的类后验；外感受是**间接观测**。地形后验是 U_epi 的主要来源之一（类身份歧义）。

**定义 319（落脚点联合动作 FIS）** 落脚动作 ξ_f = (a_step(f), g_probe(f))，f 为候选落脚片元，g_probe ∈ {轻踏, 重心预压, 全承重}。评分 S(f) = progress(f) − P_fall(f | b) + VoI_φ(g_probe) − c_irrev(g_probe)。选择 f* = argmax S；若 S* < −m_abs（弃权裕度）⇒ ABSTAIN，退回保守步态。

**定义 320（嵌入式运动学先验，Bumpless 地图更新）** 任何位姿修正 Δμ 必须满足物理可达：‖Δμ_trans‖ ≤ v_max·Δt，‖Δμ_rot‖ ≤ ω_max·Δt，且与接触相位一致。违反者判为**不可信回环**（引理 22），把修正**限速投射**到可达集后再进入控制层，避免估计「瞬移」造成的控制突变。这是四足相对轮式/手持 SLAM 的 embodiment 正则。

**定义 321（地图生命周期与休眠歧义 MLR）** 假设权重随时间与空间衰减/合并：w_h ← w_h·exp(−λ_t Δt)，空间重访时注入**再验证势**；休眠假设在重访该区域时以成本 c_react 被唤醒。防止「一次提交、永远遗忘」，也避免假设数无界增长。

**定义 322（信念条件流策略 BFP）** 复用 R69 FMP 的速度场与 trunk，但条件改为 c = Pool_attn({(w_h, h_enc(μ_h, Σ_h))})（对假设集合**置换不变**的注意力池化）。采样得 ξ = (step, probe)。解决 R69 无法处理「变长、带权、可交换假设集合」的问题。

**定义 323（开放式覆盖守卫 OWG）** 假设覆盖 κ = P(truth ∈ ℋ)（不可直接观测）。用新颖性分数 ν(o) = −log p_prior(o)（或到已知地形流形的距离）。ν > τ_nov ⇒ **不探询**，改为「扩集或保守」（扩假设 / 降速、降重心、加宽支撑多边形）。理由：当真相可能在集外时，继续探询只会产生自洽的错误证据（认知近亲繁殖）。

**定义 324（证书 J_STANCE）** J_STANCE = (J_FLUID, map_nis_pvalue, loop_evidence_hash, hypothesis_coverage_est, probe_risk, u_ale_before/after, u_epi_before/after, acc_flags, stance_ver)。Valid ⇔ Valid(J_FLUID) ∧ NIS 一致 ∧ 回环证据达标 ∧ 探询执行前证书通过。

**定义 325（STANCE 对 R69/R68 的退化边界）** 当 |sites|=1（单帧、无重访）、探询可逆、H=1 时，STANCE ≡ FLUID-RAS；再令 VoI≤成本、无交互，则 ≡ CALM-RAS。逐指令相同，安全侧单调不弱。

# IP-264 HMS：混合地图信念（离散关联假设 × 连续因子协方差）
class HybridMapBelief:
    def __init__(self, H_max=4):
        self.hyps = []                    # [{'w','graph','assoc','mu','Sigma'}]
    def update(self, z, u_odo):
        for h in self.hyps:               # 每个假设内增量因子图
            h['graph'].add(z, assoc=h['assoc'])
            h['mu'], h['Sigma'] = h['graph'].marginalize()
            h['w'] *= h['graph'].evidence()          # 关联似然
        self.hyps += spawn_assoc_hypotheses(z, self.hyps, K_split=2)
        self.hyps = merge_and_prune(self.hyps, H_max); normalize(self.hyps)
    def u_ale(self): return sum(h['w']*trace(h['Sigma']) for h in self.hyps)
    def u_epi(self): return entropy([h['w'] for h in self.hyps]) * sep(self.hyps)

# IP-265 CBA：滑移可观测性（纯本体里程在滑移方向秩亏）
def slip_observable(leg_odo, contact, extero):
    return rank(observability_matrix(leg_odo, contact, extero)) == FULL_RANK

# IP-266 LAS：任务加权主动 SLAM 的 VoI（不是地图熵，是任务泛函 φ）
def task_voi(belief, plan, g):
    phi0 = task_functional(belief)            # 下一步落脚可行性 / cost-to-go 分布
    b1   = predict_belief_after(belief, plan, g)
    return entropy(phi0) - expected_entropy(task_functional(b1)) - risk(g) - irrev_cost(g)

# IP-267 LCE：回环证据纪律 + 嵌入式运动学先验
def commit_loop_closure(e, belief):
    votes = [appearance(e), geometric_verify(e), proprio_consistency(e), temporal_order(e)]
    if sum(votes) < K_LC:            return soft_constraint(e)   # 只作软约束，不改拓扑
    if not kinematic_plausible(e):   return soft_constraint(e)   # 腿不可能瞬移（定义 320）
    if not nis_test(e):              return soft_constraint(e)   # 反坍缩一致性
    return hard_edit(e)                                          # 才允许改图

# IP-268 ACC：反坍缩证书（协方差变小 ≠ 更准）
def anti_collapse(before, after, innovations):
    d_tr = trace(before.Sigma) - trace(after.Sigma)              # 置信度上升
    nis  = normalized_innovation_sq(innovations)                 # 可观测一致性
    return (d_tr > 0) and (nis > CHI2_UPPER)                     # 更自信却不自洽 → 保守步态

# IP-270 FIS：落脚点 = 任务动作 + 不可逆信息动作（可弃权）
def select_foothold(belief, gait, budget):
    best = None
    for f in candidate_footholds(belief):
        a = step_traj(gait, f); g = probe_policy(f, belief)      # 轻踏/预压/承重
        if not cert_pre_execution(a, g, belief): continue        # 单向门：执行前证书
        score = progress(f) - fall_risk(f, belief) \
                + task_voi(belief, a, g) - irrev_cost(g)
        if best is None or score > best.score: best = (f, g, score)
    return best if best and best.score > -M_ABS else ABSTAIN     # 弃权 → 保守步态

# IP-271 BFP：信念条件流策略（对变长假设集合置换不变）
class BeliefConditionedFlow:
    def encode(self, belief):
        return permutation_invariant_pool(
            [(h['w'], self.h_enc(h['mu'], h['Sigma'])) for h in belief.hyps])
    def sample(self, belief, K, N_step=2):
        c, xs = self.encode(belief), randn(K, D)
        for i in range(N_step):
            xs = xs + (1.0/N_step) * self.v(xs, i/N_step, c)
        return [self.decode(x) for x in xs]                      # ξ = (step, probe)

## 3. 推导

**引理 19（滑移不可辨识与探询的必要性）** 在纯腿式里程计下，观测 y = Δx + s + ε。对任意滑移 s，取 Δx′ = Δx + s − s′ 使 y 不变，故似然 L(Δx, s) = L(Δx′, s′)，关于 (Δx, s) 的 Fisher 信息阵在方向 (1,−1) 上为零 ⇒ 秩亏；关于地形类 τ 的信息在滑移方向上恒为 0。**结论**：纯本体里程无法区分「身体漂移」与「地形运动」，必须由接触/外感受打破退化；这正是 FIS 探询存在的信息论理由，也是 CBA 的秩判据。

**引理 20（任务加权 VoI 阻断熵驱动乱探索）** 存在两类构造：(a) 远处不属于任何可行计划的区域，其地图熵可任意大、但 H(φ) 不变 ⇒ 原始熵 VoI → 大而任务 VoI = 0；(b) 单个落脚片元熵很小（近二值），但直接决定「走/绕」，其任务 VoI 可占主导。故对任意 ε>0 存在场景使 argmax 原始熵动作与 argmax 任务 VoI 动作不同，且前者诱发的期望代价高出 ε。**系**：主动 SLAM 的「熵最大化」不是本方案的特例，而是必须被 φ 显式排除的病态目标。

**引理 21（反坍缩的可检测域与盲区）** 模型正确时 NIS ~ χ²_{m}。设真实误差增大而 Σ 被错误缩小，则 S 偏小 ⇒ NIS 期望偏大，P(NIS > χ²_{1−α}) ≥ 1−α ⇒ ACC 可检出**不一致的过度自信**。但若错误回环同时把创新也变小（观测与错误地图自洽），则 NIS 仍在界内 ⇒ **盲区**：ACC 无法区分「真收敛」与「自洽地错」。**系**：ACC 必须与 LCE 证据纪律、OWG 覆盖守卫联合使用；单靠一致性检验不足以担保地图正确。

**引理 22（嵌入式运动学先验过滤错误回环）** 记一次回环蕴含的位姿跳变 Δμ。真实载体满足 ‖Δμ_trans‖ ≤ v_max·Δt、‖Δμ_rot‖ ≤ ω_max·Δt。若候选回环违反之，则其为错误的概率 ≥ 1 − P(合法的急停/跌倒事件)，后者可由接触相位与 IMU 冲击独立核验。故把修正限速投射（定义 320）可在几乎不损失真回环召回的前提下拒掉大部分「瞬移型」错误回环——这是轮式/手持 SLAM 不具备的免费先验。

**定理 18（混合地图信念的决策占优）** 设损失 ℓ(θ, decision) 对位姿误差有界，且信念 b 校准（权重可靠、truth ∈ ℋ w.p. κ）。则基于完整混合信念做出的决策，其期望损失 ≤ 任何「先坍缩到单一假设（含 MAP）再决策」的规则；当且仅当 b 为点质量（H=1 或 U_epi=0）时取等。**直觉**：MAP 坍缩丢弃了 epistemic 质量，而 Bayes 决策对任意凸/有界损失都不劣于任何点提交。**系**：这正是「保留未消解的地图歧义比自信地提交更安全」的形式化，也是 STANCE 对 R69「保守侧不退让」的继承（κ=1 时严格占优；κ<1 时优势随错误坍缩率单调增大，直至被 OWG 接管）。

**定理 19（STANCE 严格包含 FLUID 与 CALM）** 当 |sites|=1、无重访、探询可逆、H=1 时，HMS 退化为 R69 的单帧模态集，LAS 退化为 R69 MINT 的 VoI，FIS 退化为 R69 的 (a,g) 选择 ⇒ 逐指令相同，STANCE ≡ FLUID-RAS。再令 VoI≤成本、无信息动作 ⇒ ≡ CALM-RAS。且退化路径上安全约束单调不弱（定义 325）。**意义**：R70 不是又一个并列黑箱，而是 R69 在地图维度上的**严格泛化**；每加一层都可独立回退到已验证的旧层。

**定理 20（两速率分层的有界扰动稳定性）** 设地图层以周期 T_map 更新，其位置修正经限速投射后对控制层等效为扰动 d_t，且 ‖d_t‖ ≤ v_max·T_map。若控制层在 Feas(b) 上的鲁棒 MPC 对直径 ≤ D 的信念集可行，则闭环对 d_t **输入-状态稳定（ISS）**，切换无突变；进一步，若地图跳变超出运动学可达，则按定义 320 被截断，控制指令的连续性由 R68 定理 15 的换装不变式保持。**系**：**地图修正必须与身体速度同量级**——「估计瞬移」在物理上不可信，也在控制上不安全。

## 6. 本轮最大风险

**一句话**：STANCE-RAS 的全部安全性押在「真相 ∈ 维护中的假设集（κ≈1）」这一**内部不可验证**的前提上——**若真相落在集外（未见地形物理、系统性传感器模型错误、对抗性伪装地形），多假设地图会自信地错，而每一次主动落脚探询都在同一套错误假设下被解释，形成「自洽的错误证据」；此时探询不只无用，反而把 R69 那种「诚实的不知道」升级成「越来越自洽的错误」，最终由一次不可逆的落脚把地图错误变成物理坠落**——认知近亲繁殖，比无知更危险。

**次级风险与缓解**：
1. **过度自信坍缩**（错误回环缩小协方差）→ ACC 反坍缩证书 + 引理 21 可检测域 + LCE 证据纪律；

3. **主动 SLAM 乱探索** → 任务加权 VoI（定义 313、引理 20），只看任务泛函不看地图熵；
4. **集外真相** → OWG 覆盖守卫（定义 323）：新颖性越界时不探询、改扩集或保守步态；
5. **分层延迟击穿实时** → 控制/地图/任务三速率解耦 + 地图层仅作有界扰动（定义 315、定理 20）。

**定义 316–317（LCE 与 ACC）** 回环需外观/几何/本体轨迹/时序四证据投票，<k_LC 只作软约束；更新后 `Δc>0 ∧ NIS>χ²_{1−α}` ⇒ 过度自信坍缩，回滚并保守。ACC 抓「不一致的错」，抓不到「自洽的错」。

**定义 318–319（TMP 与 FIS）** 地形类后验 `p(τ_x|𝒟)`（含可通行代价分布），脚接触为直接观测；落脚评分 `S(f)=progress−P_fall+VoI_φ−c_irrev`，`S*<−m_abs` 则 ABSTAIN。

**定义 320（嵌入式运动学先验）** 位姿修正须满足 `‖Δμ_trans‖≤v_max·Δt`、`‖Δμ_rot‖≤ω_max·Δt` 且契合接触相位；违者判不可信回环并限速投射。四足相对轮式/手持 SLAM 的 embodiment 正则。

**定义 321–323（MLR/BFP/OWG）** 假设衰减/合并/重访唤醒；BFP 对变长假设集合置换不变；新颖性 `ν>τ_nov` ⇒ 不探询、扩集或保守步态（防认知近亲繁殖）。

**定义 324–325（证书与退化边界）** J_STANCE 并入 NIS p 值、回环哈希、覆盖估计、探询风险；`|sites|=1 ∧ 探询可逆 ∧ H=1 ⇒ ≡FLUID`，再 `VoI≤成本 ⇒ ≡CALM`，逐指令相同。

# IP-264 HMS：混合地图信念（离散关联假设 × 连续因子协方差）
class HybridMapBelief:
    def update(self, z, u_odo):
        for h in self.hyps:                       # 每假设内增量因子图
            h['graph'].add(z, assoc=h['assoc'])
            h['mu'], h['Sigma'] = h['graph'].marginalize()
            h['w'] *= h['graph'].evidence()        # 关联似然
        self.hyps += spawn_assoc_hypotheses(z, self.hyps, K_split=2)
        self.hyps = merge_and_prune(self.hyps, H_max); normalize(self.hyps)
    def u_ale(self): return sum(h['w']*trace(h['Sigma']) for h in self.hyps)
    def u_epi(self): return entropy([h['w'] for h in self.hyps]) * sep(self.hyps)

# IP-265 CBA
def slip_observable(leg_odo, contact, extero):
    return rank(observability_matrix(leg_odo, contact, extero)) == FULL_RANK

# IP-266 LAS：任务加权 VoI（不是地图熵）
def task_voi(belief, plan, g):
    phi0 = task_functional(belief)
    b1   = predict_belief_after(belief, plan, g)
    return entropy(phi0) - expected_entropy(task_functional(b1)) - risk(g) - irrev_cost(g)

# IP-267 LCE：回环证据纪律 + 运动学先验
def commit_loop_closure(e, belief):
    votes = [appearance(e), geometric_verify(e), proprio_consistency(e), temporal_order(e)]
    if sum(votes) < K_LC:           return soft_constraint(e)
    if not kinematic_plausible(e):  return soft_constraint(e)     # 腿不可能瞬移
    if not nis_test(e):             return soft_constraint(e)     # 反坍缩
    return hard_edit(e)

# IP-268 ACC：反坍缩证书
def anti_collapse(before, after, innovations):
    d_tr = trace(before.Sigma) - trace(after.Sigma)
    nis  = normalized_innovation_sq(innovations)
    return (d_tr > 0) and (nis > CHI2_UPPER)                      # 更自信却不自洽

# IP-270 FIS：落脚 = 任务动作 × 不可逆信息动作（可弃权）
def select_foothold(belief, gait, budget):
    best = None
    for f in candidate_footholds(belief):
        a = step_traj(gait, f); g = probe_policy(f, belief)
        if not cert_pre_execution(a, g, belief): continue
        score = progress(f) - fall_risk(f, belief) + task_voi(belief, a, g) - irrev_cost(g)
        if best is None or score > best.score: best = (f, g, score)
    return best if best and best.score > -M_ABS else ABSTAIN

# IP-271 BFP：信念条件流策略（置换不变）
class BeliefConditionedFlow:
    def encode(self, belief):
        return permutation_invariant_pool(
            [(h['w'], self.h_enc(h['mu'], h['Sigma'])) for h in belief.hyps])
    def sample(self, belief, K, N_step=2):
        c, xs = self.encode(belief), randn(K, D)
        for i in range(N_step):
            xs = xs + (1.0/N_step) * self.v(xs, i/N_step, c)
        return [self.decode(x) for x in xs]                       # ξ=(step, probe)

# IP-276 STANCE 主闭环（控制 500Hz / 地图 50Hz / 任务 10Hz）
def STANCE_round(M, obs, odo, contact):
    if M.map_clock.due():

        if anti_collapse(M.belief_prev, M.belief, obs.innov):
            M.gait.enter_conservative()

        K = 1 if M.fmp.mode_head(M.belief) < TAU_MODE else 4

    M.tmp.update_from_contact(contact, A, M.belief)               # 脚落地即地形观测

## 4. 推导

**引理 19（滑移不可辨识）** 纯腿式里程 `y=Δx+s+ε`：对任意滑移 `s` 可取 `Δx′` 使 `y` 不变，Fisher 信息在 `(1,−1)` 方向为零，地形信息在滑移方向恒为 0 ⇒ 秩亏，必须接触/外感打破退化。系：FIS 探询的存在性由信息论强制，而非工程偏好。

**引理 20（任务加权 VoI 阻断乱探索）** 存在场景使原始熵最大的动作任务 VoI 为 0（远处非计划区域），也存在小熵但决定「走/绕」的单落脚歧义任务 VoI 占主导 ⇒ 熵最大化必须被 `φ` 显式排除。

**引理 21（反坍缩的可检测域与盲区）** 模型正确时 `NIS~χ²`；真实误差增大而 `Σ` 被缩小 ⇒ `P(NIS>χ²_{1−α})≥1−α`，ACC 可检出不一致过度自信；但错误回环令创新同时变小时 NIS 仍在界内 ⇒ 盲区，须联合 LCE/OWG。

**引理 22（运动学先验过滤错误回环）** 真实载体 `‖Δμ‖≤v_max·Δt`；违反者大概率为错误回环，可由接触相位/IMU 冲击独立核验 ⇒ 限速投射几乎不损真回环召回即可拒掉「瞬移型」错误回环（轮式/手持 SLAM 不具备）。

**定理 18（混合信念决策占优）** 损失有界、信念校准（`truth∈ℋ` w.p. `κ`）时，基于完整混合信念的决策期望损失 ≤ 任何先坍缩到单假设（含 MAP）再决策的规则；点质量时取等。系：保留未消解地图歧义比自信提交更安全，`κ` 越低优势越大，直至 OWG 接管。

**定理 19（严格包含 FLUID 与 CALM）** `|sites|=1 ∧ 无重访 ∧ 探询可逆 ∧ H=1 ⇒ STANCE≡FLUID`；再 `VoI≤成本` ⇒ `≡CALM`；退化路径安全单调不弱。R70 是 R69 的地图维度严格泛化，每层可独立回退。

**定理 20（两速率分层有界扰动稳定性）** 地图更新经限速投射后为扰动 `‖d_t‖≤v_max·T_map`；若控制层对直径 ≤D 的信念集可行，则闭环 ISS、切换无突变；超运动学可达的地图跳变被定义 320 截断，连续性由 R68 定理 15 换装不变式保持。系：**地图修正必须与身体速度同量级**。

## 7. 本轮最大风险

**一句话**：STANCE-RAS 的安全性押在「真相 ∈ 维护中的假设集（κ≈1）」这一**内部不可验证**的前提上——**若真相落在集外（未见地形物理、系统性传感器模型错误、对抗性伪装地形），多假设地图会自信地错，且每次主动落脚探询都在同一套错误假设下被解释，形成自洽的错误证据；此时探询把 R69 的「诚实的不知道」升级成「越来越自洽的错误」，最终由一次不可逆落脚把地图错误变成物理坠落**——认知近亲繁殖，比无知更危险。

**次级风险与缓解**：过度自信坍缩（ACC 反坍缩 + 引理 21 + LCE）；不可逆探询跌倒（执行前证书 + 弃权 + 定理 20）；主动 SLAM 乱探索（任务加权 VoI + 引理 20）；集外真相（OWG 覆盖守卫：不探询、扩集或保守步态）；分层延迟击穿实时（三速率解耦 + 地图仅作有界扰动）。
