# 第 58 轮（承接第 57 轮「少样本元推断×跨模态对账×个性化有界信任」IP-133~138；灵感循环第 1 轮；本轮灵感：「地形适应」×「视觉语言动作模型」）

> 第 57 轮把安全的赌注从"模型置信"换成"少样本可校准、跨模态可对账、个性化有界的证据承诺"：MFSL 用元先验换效率、用共形带保底，XMC 用分歧下限与 EV-xmodal 拆穿单模态共谋，PTM 把人从常量变成单向有界的信任状态机。但它的风险自陈留下三个更深的裂缝：**(a)** 它把"区域"当成安全的原子，信念只覆盖地形参数 θ=(μ,k,F_bear)，却默认执行政策不变——可机器人真正能做的是**适应**：换步态、换刚度、换落脚与速度。同一块碎石，刚性高速是陷阱，柔性低速是通途；于是安全不是地形 r 的属性，而是 **(r,π) 的属性**，第 57 轮的全部证据都隐含绑定在某个从未被声明的 π 上。**(b)** 它的证据全部来自物理探针与人类，没有机制把"语义"接进来：面对从未探过的新地形，只能退回又宽又慢的共形区间；人类说"那边是苔藓，别踩"，系统既听不懂，也不会把这句话变成可检验的义务。**(c)** 它"一切判定器（含元模型）走隔离"的原则尚未轮到**基础模型**：VLA（Vision-Language-Action）能看图说话、零样本泛化、听自然语言指令，但它会幻觉、会被语言先验带偏、其置信与物理风险没有校准关系。若把 VLA 当权威，等于把第 57 轮刚拆掉的"单点过度自信"以更大规模请回来。本轮两个灵感各补一条腿：**地形适应**把安全从"区域"升级为"区域×政策"，并引入**政策相对证据**、**证据转移界**与**适应债**；**VLA**被降格为**语义提议器与义务编译器**——它只能加约束、加探针、加警报，永不单独作证。核心命题升级为 **"政策可切换、证据可转移、语义可编译、自信不可转移的承诺"**。

核心矛盾：
- **H29（适应即证据失效）**：适应能扩大安全包络，但每换一次政策，旧证据的语义就变一次；越适应，旧证据越不算数。若无"转移界"与"适应债"，适应会变成用未来安全透支当下效率的隐形杠杆。
- **H30（语义先验 vs 物理证据）**：VLA 给的是零样本泛化与语言接地，但它给出的"看起来安全"与物理可承载/可附着不是同一件事；语言先验很容易压制一次微弱但真实的触觉反对票。
- **H31（语义-适应共谋 / 自诱导分布漂移）**：若 VLA 提议适应政策，而该政策又生成让 VLA 看起来正确的证据，闭环就自我确认；且适应本身会改变输入分布，使第 57 轮的 OOD 门面对"自己制造出来的漂移"而失灵。

## 0. 直觉与动机

**灵感 1（地形适应 → 政策条件安全包络：安全是 (区域, 政策) 的属性）**
直觉："这地形能不能走"是个错问题，对的问题应是"**在这套步态/刚度/落脚/速度下**能不能走"。砾石对刚性高速是陷阱、对柔性低速是通途；泥面的安全取决于足端面积与接地时长。于是把第 57 轮的区域信念扩成**响应面** b_r(θ|π)，把证据标上"采于哪个政策"，并定义**政策条件安全包络** S_cert(r)：只有同时落在"已证政策集"与"可逆可执行政策集"里的 π 才允许承诺。适应不是免费的午餐，而是**向未来借安全**——借的额度就是适应债。

**灵感 2（地形适应 → 适应即实验 + 适应债/前沿）**
直觉：换刚度去"轻踩一下"本身就是一次探针——柔顺触地和刚性触地返回的地形响应结构不同，恰好多问了一个正交问题。于是新增证据类 **EV-adapt**：一次可逆、非破坏、受控的构型改变，用来最大化对地形响应面的信息增益。但适应也有反作用：频繁换步态会抖动、会消耗节拍、会让证据账本碎成一地。用**适应债** d(r,π) 约束"未用新鲜证据结算的适应量"，用**适应前沿** F(r) 表示当前可承诺的政策边界，用滞回阈值 h_switch 压住抖动。适应只能把系统推进"已证且可逆"的包络，不能把未证政策洗白。

**灵感 3（VLA → 语义提议器 + 义务编译器，而不是判官）**
直觉：VLA 是个"博学的实习生"：能命名地形（苔藓/浮土/湿混凝土）、能建议一条路线与步态、能听懂人话并解释，但**不能签安全证书**。它的输出一律是**提议**：地形标签、可供性、建议政策、语言约束、置信度。系统用一个**义务编译器**把提议翻译成可检验的义务：STL 时序约束 + 需要的证据类与数量 + 同意等级 + 证伪测试集。"这边滑，慢点走"→ v≤0.3 m/s、F_foot≤F_max、需一次滑移探针、L1 通知。VLA 的自信永不直接转移到动作；只有被物理检验接地的部分才算数，且它只能**加**义务，不能删义务。

**灵感 4（VLA × 地形适应 → 语义-物理对账 + 反事实适应检验）**
直觉：VLA 常与相机共享传感器，所以它**不是**独立模态，不能拿来凑第 57 轮的 EV-xmodal。正确用法有两层：**(i) 语义-物理对账**——VLA 说"干燥"，触探说低摩擦，这个分歧本身就是第 57 轮意义上的"不确定性下限"，应强制加宽并触发判别性探针；**(ii) 反事实适应检验**——VLA 预测"把刚度降低 30%，滑移会减少"，那就真的做一次可逆降刚度并测量，预测残差就是 VLA 的校准信号。这样不需要地面真值，也能把"会说话的自信"逐步校准成"可检验的物理直觉"。为避免语义-适应共谋，确认证据必须带**独立见证**：要么由 VLA 未提议的政策采集，要么由反事实适应产生。

**灵感 5（合流 → 政策条件证据门 + PCE++ 联合探询-适应 VOI）**
直觉：证据门从五类扩到七类，新增 **EV-adapt**（限 L0/L1 且可逆）与 **EV-sem**（只生成义务/警报，永不单独作证）。承诺对象从"区域"变成"区域×政策锁"；一旦执行中政策被迫改变（扰动、坡度超限），旧证书立即失效，必须回到探-诺-演闭环重证。探询动作空间扩为 A_probe ∪ A_adapt，VOI 变成**联合 VOI**：一次适应既能提高安全又能产生信息，但要扣掉适应债与切换代价。所有新机制仍只经两个安全通道起作用：**信念更准（含强制加宽）**或**动作更保守（降档、减速、加佐证、缩短超时）**。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（政策条件安全包络 PSE）** 政策空间 Π∋π=(gait,K_stiff,v,foothold_pattern,h_body)，区域 r 的响应面信念 b_r(θ|π)，θ 含 μ,k,F_bear,slip。安全包络 S^δ_f(r)={π:P_fail(r,π)≤δ_f}；可证包络 S_cert(r)={π:∃e 在 (r,π) 上过证据门}；可逆可执行包络 S_adm(r)⊆Π（L0/L1、可撤销、非破坏）。承诺硬条件：π_lock∈S_cert(r)∩S_adm(r)。

**定义 140（政策相对证据与适应债 PTE/AD）** 证据 e 携带采集政策 π_e、支撑域 supp(e) 与敏感界 L_e，对任意 π'：若 ‖π'−π_e‖_Π≤supp(e)/L_e 则可转移，转移后置信折减 L_e‖π'−π_e‖_Π；否则 e 过期。适应债 d(r,π)=∫(适应代价+未结算政策变更量)dt∈[0,d_max]，仅新鲜证据可清偿。适应前沿 F(r)={π:d(r,π)≤d_max ∧ π∈S_cert(r)∩S_adm(r)}。切换需滞回：E[Δ安全/效用]>h_switch 且债务预算允许。

**定义 141（VLA 语义提议与义务编译 VSP）** VLA 映射 (I,ℓ,ctx)→提议 p=(terrain_label,affordance,π_suggest,ℓ_constraints,conf)。编译器 C:p→O(p)=(φ_STL,{证据义务},同意等级,证伪测试集 T(p))。接地谓词 G(p)：每条语义断言都配一个可执行证伪测试。安全不变量：(V1) VLA 只增义务/约束/警报，不删；(V2) VLA 永不单独满足证据门；(V3) VLA conf 不可转移到动作；(V4) VLA 与视觉共享传感器，不得充当 EV-xmodal 的第二模态。

**定义 142（语义-物理对账 SPR）** 语义-物理分歧 D_sem(r)=dist(lbl_vla,affordance_vla; b_r^phys)，阈值 θ_sem。D_sem>θ_sem ⇒ 强制加宽信念并触发"最大分歧"判别探针/适应；D_sem≤θ_sem **不**产生证据（共享传感器，非独立）。VLA 可靠性 ρ_vla 由 CAT 残差与人工纠正按 proper scoring 更新、按事后证伪回溯降权。

**定义 143（反事实适应检验 CAT）** 对 VLA 的政策预测 π→π' 与预测响应 ŷ，执行可逆适应 π'（L0/L1，代价≤c_cat）并测量 y，残差 ε_cat=y−ŷ。|ε_cat|>θ_cat ⇒ 该语义断言失效、ρ_vla 降级、并把相关证据标为"政策相对待重证"；否则 ρ_vla 有界恢复。CAT 同时是一次响应面探针。

**定义 144（政策条件证据门 PGE 与证书 J_q）** 证据类 EV-probe\*/EV-visit/EV-margin/EV-xmodal（限 L1）/EV-human/EV-adapt（限 L0/L1、可逆、政策相对）/EV-sem（仅生成义务，永不单独）。承诺证书 J_q=(J_p 全量, policy_lock, adaptation_ledger, transfer_log, vla_ground_log, spr_log, cat_log, debt_state, sem_independence_witness)。政策锁一旦断裂，证书作废并回到 PCX/PCE++ 重证。

## 2. 关键算法伪代码

```python
def policy_conditioned_commit(r, pi, M, ledger):        # IP-139/140
    if pi not in M.S_cert[r] or pi not in M.S_adm[r]:
        return ('reject', 'policy_not_certified', pi)
    if M.debt(r, pi) > M.d_max:
        return ('reject', 'adaptation_debt', M.debt(r, pi))
    for e in M.evidence[r]:                             # 政策相对证据转移
        d = pdist(pi, e.pi)
        if d <= e.support / e.L_e:
            e.conf_used = e.conf - e.L_e * d            # 折减，不新增强度
        else:
            return ('reject', 'evidence_expired', e)    # 超界即过期
    return ('ok', Jq(pi, ledger))

def adapt_or_probe(r, M, budget):                       # 联合 VOI
    cands = [a for a in M.A_probe(r) + M.A_adapt(r) if feasible(a)]
    a = argmax(cands, key=lambda x: voi_joint(x, M, pessimistic=True)
                                - cost(x) - debt_penalty(x, M))
    if voi_joint(a, M, pessimistic=True) < theta_voi:
        return ('halt', None)
    if a.kind == 'adapt':                               # 可逆、非破坏
        M = apply_reversible(M, a); M.debt_bump(r, a.delta)
    return ('go', a)

def vla_compile(I, ell, ctx, vla):                      # IP-141/142
    p = vla.propose(I, ell, ctx)
    O = compile_obligations(p)                          # STL + 证据义务 + 同意级
    D_sem = semantic_physical_disagree(p, ctx.M.b[ctx.r])
    if D_sem > theta_sem:
        ctx.M = widen(ctx.M.b[ctx.r], D_sem)
        O = O + [Probe('max_disagree'), MaybeAdapt('discriminating')]
    return p, O, D_sem                                 # VLA 永不返回 "safe"

def counterfactual_adapt_test(p, ctx):                  # IP-143
    y_hat = p.predict_delta(ctx.pi, p.pi_suggest)
    y = execute_reversible(ctx.pi, p.pi_suggest)        # L0/L1, cost<=c_cat
    eps = y - y_hat
    ctx.M.rho_vla = score_update(ctx.M.rho_vla, eps)
    if abs(eps) > theta_cat:
        ctx.M = invalidate_claim(ctx.M, p); ctx.M.debt_bump(ctx.r, ctx.pi)
    return ctx.M, eps
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| PSE | O(\|Π_r\|·d_b)/区域 | O(\|V\|·\|Π_r\|·d_b) | 包络覆盖≥1−α、政策锁完整 |
| PTE/AD | O(1)/证据转移检查；O(\|Π\|) 前沿维护 | O(\|evidence\|) | L_e 诚实、超界即过期、债务≤d_max |
| VSP | O(d_VLA)+O(\|O(p)\|) | O(\|O\|) | 只增义务、永不单独作证 |
| SPR | O(\|ℳ_sem\|·d_b)/区域 | O(\|V\|·d_b) | 分歧下限保守、共享传感器禁入 EV-xmodal |
| CAT | O(c_cat)+O(1) 更新 | O(\|cat_log\|) | 可逆、有界、残差诚实 |
| PGE | O(\|σ\|) | O(\|σ\|) | 政策锁断即拒、EV-adapt 限 L0/L1 |

**正确性定理（Policy-Conditioned Grounded Soundness, PCGS 概要）**：在 A33–A40 上加 **(A41)** 政策相对证据转移诚实：|P_fail(r,π')−P_fail(r,π_e)|≤L_e‖π'−π_e‖_Π，超界即过期；**(A42)** 适应可逆有界：EV-adapt 仅 L0/L1 且可撤销，d(r,π)≤d_max，执行风险≤δ_adapt；**(A43)** VLA 接地单向：只增义务、永不单独作证、conf 不转移，且 VLA 与视觉共享传感器，不用于 EV-xmodal；**(A44)** 语义-物理对账保守、CAT 可逆且残差阈值诚实。则：

(i) **政策条件承诺健全性**：政策锁未断时 P(fail) ≤ δ_f+ε_meta(k)+δ_probe+ε_h(w_max)+δ_ood·α_conf+δ_xm·1[L1]+L_e‖π'−π_e‖_Π；任一项越界或政策锁断裂则拒绝承诺。
(ii) **适应单调性**：适应只能经"进入已证且可逆的包络"或"增加探针/义务/加宽/降档"影响系统，不存在"适应后自动更敢赌"的路径；债务越界只导致绕行/重证/安全停。
(iii) **语义单调性**：VLA 只增约束与警报，其错误最多导致更保守（漏提议→更慢更宽/更多探针）；语义唯一的安全相关通道是影响人类同意，故仍受 MXI 输入误差模型与 L2 超时保守停约束。
(iv) **终止性**：PCE++ 在 k_probes+k_cons+k_adapt 内终止于 {承诺, 绕行, L2 协商, 安全停}。

**部署界（对检查点取联合界）**：
```
P_safe ≥ 1 − Σ_cp [δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                  + L_e·||π'−π_e||_Π + δ_adapt]
             − P(政策锁断裂未检出) − P(适应债越界未结算) − P(VLA 语义越权 ∧ SPR 漏检)
             − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
```

关键：**包络给适应以边界、转移界给旧证据以寿命、债务给适应以预算**；**VLA 只做提议与解释，义务编译让它只能把世界变得更受约束；反事实适应检验用可逆动作给语义先验做物理校准**。效率与安全再次解耦：成本押在"可逆适应 + 便宜探针"，赌注不押在"VLA 的自信"上。

## 6. 本轮最大风险

**一句话**：本轮把安全从"区域"搬到"区域×政策"，又请来 VLA 做语义向导，最大风险是"适应债 + 语义先验"共同制造一个自证循环——VLA 提议的适应政策恰好生成让 VLA 看起来正确的证据，而政策切换又把旧证据悄悄作废，使系统在"会适应的自信"与"会说话的自信"互相背书中越过包络；必须以政策锁、适应债硬预算、VLA 永不单独作证、反事实适应检验四道护栏，宁可停在旧包络里重新探针，也不让一次漂亮的适应或一句自信的描述替代一次物理结算。

    S = {}
    for pi in parameterized_policies(r):                # 参数化政策族，粗到细
        if pi not in M.S_adm[r]:        continue        # 只允许可逆非破坏

def transfer_evidence(e, pi_new, L_e=None):
    L = L_e or e.L_e
    d = pdist(pi_new, e.pi)                             # 政策向量距离
    if d > e.support / L:
        return None                                     # 超出支撑域：过期
    return Evidence(like=e.like, pi=pi_new,
                    conf=e.conf - L * d,                # 只折减，不增强
                    support=e.support, L_e=L)

def adapt_with_debt(M, r, pi_new, a):
    if M.debt(r, pi_new) + a.cost > M.d_max:
        return ('reject', 'debt_budget', M.debt(r, pi_new))
    if expected_gain(M, r, pi_new) - switch_cost(a) <= M.h_switch:
        return ('reject', 'hysteresis', a)              # 抑制步态抖动
    M = apply_reversible(M, a)                          # L0/L1 且可撤销
    M.debt_bump(r, a.cost); M.ledger.log(r, pi_new, a)
    return ('ok', M)

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PSE | O(\|Π_r\|·d_b)/区域 | O(\|V\|·\|Π_r\|·d_b) | 包络覆盖≥1−α、政策锁完整（A41） |
| PTE/AD | O(1)/转移；O(\|Π\|) 前沿 | O(\|evidence\|) | 超界即过期、债务≤d_max（A41/A42） |
| VSP | O(d_VLA)+O(\|O\|) | O(\|O\|) | 只增不减、永不单独作证（A43） |
| SPR | O(\|ℳ_sem\|·d_b)/区域 | O(\|V\|·d_b) | 分歧下限保守、共享传感器禁入（A43/A44） |
| CAT | O(c_cat)+O(1) | O(\|cat_log\|) | 可逆有界、残差诚实（A44） |
| PGE | O(\|σ\|) | O(\|σ\|) | 政策锁断即拒、软证据限 L0/L1 |
| PCE++ | O(\|CP\|·(k_p+k_c+k_a)·(C_VOI+d_φ+d_VLA)+\|CP\|·A\*) | O(\|V\|+\|σ\|) | 联合 VOI 悲观、三项预算终止 |

**正确性定理（Policy-Conditioned Grounded Soundness, PCGS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 政策相对证据转移诚实：|P_fail(r,π')−P_fail(r,π_e)|≤L_e‖π'−π_e‖_Π，超界即过期；**(A42)** 适应可逆有界：EV-adapt 仅 L0/L1 且可撤销，d(r,π)≤d_max，执行风险≤δ_adapt；**(A43)** VLA 接地单向：只增义务、永不单独作证、conf 不转移，且 VLA 与视觉共享传感器、不用于 EV-xmodal；**(A44)** 语义-物理对账保守、CAT 可逆且残差阈值与 c_cat 声明诚实。则：

1. **政策条件承诺健全性**：政策锁未断时，P(fail) ≤ δ_f + ε_meta(k) + δ_probe + ε_h(w_max) + δ_ood·α_conf + δ_xm·1[L1] + L_e‖π'−π_e‖_Π + δ_adapt；任一项越界或政策锁断裂则拒绝承诺，回到探-诺-演。
2. **适应单调性**：适应只能经 (a) 进入 S_cert∩S_adm 的已证政策，或 (b) 增加探针/义务/加宽/降档，影响系统；不存在"适应后自动更敢赌"的路径；适应债越界只导致绕行/重证/安全停。
3. **语义单调性**：VLA 只增约束与警报，其错误最多导致更保守（漏提议→更慢、更宽、更多探针）；语义唯一的安全相关通道是影响人类同意，故受 MXI 输入误差模型、接地披露与 L2 超时保守停约束。
4. **终止性**：每检查点共识探针 ≤k_cons、适应 ≤k_adapt，PCE++ 在 k_probes+k_cons+k_adapt 内终止于 {承诺, 绕行, L2 协商, 安全停}。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp [δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                  + L_e·||π'−π_e||_Π + δ_adapt]
             − P(政策锁断裂未检出) − P(适应债越界未结算)
             − P(VLA 语义越权 ∧ SPR 漏检 ∧ CAT 未触发)
             − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
```

关键：**包络给适应以边界，转移界给旧证据以寿命，债务给适应以预算**；**VLA 只做提议与解释，义务编译让它只能把世界变得更受约束**；**反事实适应检验用可逆动作给语义先验做物理校准**。效率与安全再次解耦：成本押在"可逆适应 + 便宜探针"，赌注不押在"VLA 的自信"上；"会适应的自信"与"会说话的自信"都不许互相背书。

## 6. 本轮最大风险

**一句话**：本轮把安全从"区域"搬到"区域×政策"，又请来 VLA 做语义向导，最大风险是"适应债 + 语义先验"共同制造一个自证循环——VLA 提议的适应政策恰好生成让 VLA 看起来正确的证据，而政策切换又把旧证据悄悄作废，使系统在"会适应的自信"与"会说话的自信"互相背书中越过包络；必须以政策锁、适应债硬预算、VLA 永不单独作证、反事实适应检验四道护栏，宁可停在旧包络里重新探针，也不让一次漂亮的适应或一句自信的描述替代一次物理结算。
