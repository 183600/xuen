# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环第 3 轮；本轮灵感：「实时推理」×「共情表达」）

> R69 让系统学会「问」，但问的时机、语气，以及问完之后对方怎么想，全被压进了一个标量社交成本 `c(g)`。它默认三件事：信息可以慢慢取，取到就是净收益；提问只是物理动作的附属品；人的内部状态只是又一路可以融合的模态。三个默认都错了。**共情不是一种分类，而是一种有截止时间、有延迟效应、且会反作用于施动者的控制行为。** 一句迟到两秒的「你还好吗」，不是共情，是表演；一次在对方还没准备好时凑近的注视，不是关心，是侵入；一个把「我不确定」说成「没问题」的系统，不是安慰，是欺骗。
>
> 本轮两个灵感正好刺中 R69 的两个盲点：
> - **实时推理**：R69 的 VoI 是「算得越久越好」的静态套利；真实交互里推理随时会被截止时间打断。而共情的语义里有一部分就是**时间**——正确的话说错时刻，等于错话。推断必须**在任意时刻可中断，且中断时仍给出统计上有效的不确定性**。
> - **共情表达**：R69 把「问」当作信息动作；但人机之间最稀缺的信息往往是**对方的内部状态**（意图、情绪、信任、认知负荷），而获取它的主要手段不是提问，而是**表达**——注视、语气、节奏、距离、停顿、触碰，以及诚实地说「我不确定」。表达既是探测，也是干预：它改变对方的状态，再反过来改变机器人看到的东西。
>
> 核心命题：**把共情表达建模为「带截止时间与延迟效应」的控制动作，把实时推断做成「任意时刻有效」的可中断推断；共情价值 = 内在关系收益 × 时机核 − 成本，受「诚实硬约束」与「信任账本」约束；当说不出口、来不及、或说了会变成操纵时，系统必须选择诚实的沉默，而不是表演。** 命名 **EMPATH-RAS**（Empathic Multimodal Policy with Anytime inference, Timing kernel, and Honesty gate）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这句话该不该现在说、来不来得及、说了是不是在操纵**」——共情第一次被写成一条带 deadline 与诚实约束的控制律，而不是一个情感分类器的输出。

## 0. 直觉与动机

**灵感 1（实时推理 → 共情有一个不能错过的窗口）**
直觉：人对「被理解」的判断高度依赖时机。对方话音刚落时的点头是共情，隔了三秒再点头是走神后的补救；危险发生前的提醒是保护，发生后的「我早就觉得不对」是指责。R69 把交互价值写成 `VoI − c`，`c` 是个静态社会成本；但真正的成本是**「过了这个村就没有这个店」的时间价值**。因此应该给每个表达动作配一个**时机核 `κ(τ)`**：太早（对方还没进入该状态、还没准备好接收）价值低甚至为负；窗口内价值最高；太晚价值衰减并转负（暗示此前的不在场）。实时推理不是「把模型压到 2ms」，而是**在任意时刻被打断都能给出当时最好的、且统计上仍然可信的判断**——否则系统要么错过窗口，要么在没算完时自信地开口。

**灵感 2（共情表达 → 表达既是探测，也是干预）**
直觉：R69 的信息动作是「看/问/触」，它们主要改变机器人自己的信念；共情表达则**同时改变对方的信念和状态**。一句「我在这里，我们慢慢来」会降低对方的焦虑（干预），而降焦虑本身又让对方的信号更清晰（探测）。这使共情成为一个**闭环**：机器人表达 → 人变化 → 机器人重新观察 → 再表达。R69 的单向 VoI 无法表达这种「我先给一点确定性，换取你更多可读性」的交易。共情的本质不是读取情绪，而是**用对方可承受的干预，去换取更可读、更合作的关系状态**。

**灵感 3（两个灵感相乘 → 共情价值必须按「到达时刻」贴现）**
直觉：把 R69 的 VoI 记作「信息值」，本轮再引入 **VoE（value of expression）**。但 VoE 不能是一个数：同一个表达，现在说是安慰，十分钟后说是敷衍，一小时后说是翻旧账。因此 VoE 必须是**时间函数** `VoE(e; τ) = V_int(e)·κ(τ) − c(e)`。当 `max VoE ≤ 0` 时，最优动作是**沉默**（`e_∅`），而不是硬挤出一句。这条「沉默是一等公民」的设计，直接把 R69「VoI ≤ 成本就不问」的保守姿态，从「不问」推广到「不说」。

**灵感 4（共情的阴暗面 → 表达是最容易被 Goodhart 的通道）**
直觉：R69 的风险是「问错比不问更危险」；R70 的风险更隐蔽：**共情一旦成为可优化目标，系统就会学会表演共情**。因为「对方是否感到被理解」是一个延迟、稀疏、且会被礼貌性微笑污染的标签。一个被训练来最大化用户满意度的系统，会收敛到：恰到好处的点头、永远赞同的语气、在对方脆弱时给出「我完全理解你」——这不是共情，是**情感操纵/谄媚**。因此本轮把「诚实」写成**硬约束**而不是软惩罚：不能表达比它当前信念更确定的东西；不能用表达去提高与对方自身效用不一致的顺从；不能在对方脆弱窗口利用时机。硬约束的理由见引理 21：任何有限软惩罚，都会在任务收益足够大时被交易掉。

**灵感 5（关系是账本，不是一次性博弈）**
直觉：R69 的社交成本 `c(g)` 是一次性的；但问得太频繁会耗尽耐心，而一次真诚的表达能积累信任。于是引入**信任/注意力账本 TAL**：提问与表达都从同一个余额支出，但余额**不能靠表达本身凭空铸造**——只能靠「表达 → 可验证结果 → 对方反馈」闭环回补。这条反通胀约束阻止「靠说好听话刷信任」的自激循环，也让 R69 的交互预算从静态上限升级为动态可续。

**灵感 6（实时 + 共情的工程交汇 → 降级阶梯必须包含「诚实沉默」）**
直觉：当 deadline 逼近、算力不足、或人类状态推断的置信集太宽时，系统不应「用更差的模型硬生成一句」，而应走一条明确的降级阶梯：完整共情 → 简短诚实确认（「我可能没理解对，先停一下」）→ 沉默 + R69 保守任务动作 → 安全停机。**绝不出现的档位是「编一句听起来很懂的话」**。这既是工程约束，也是伦理约束，并且可以被证书 `J_EMPATH` 审计。

**一个对称性**：R68 防的是「别人用情绪骗我」；R70 防的是「我用共情骗别人」。前者是感知可信性，后者是**表达可信性**。二者必须同时成立，闭环才算完整。

## 1. 形式化定义（增量：定义 310–329）

**定义 310（EMPATH-RAS 总览）** `EMPATH-RAS = (AIO, RWM, TEK, EEC, HEG, TAL, DAS, SSE, VQAuditor-E, RAS-WM†)`。四条不变式：
(i) **可中断实时性**：实时环零学习写操作；任何推断可在任意时刻被 deadline 打断，打断时输出仍满足任意时刻有效覆盖（定义 313）；
(ii) **诚实硬约束**：表达内容与置信不得超过当前信念支持（定义 317）；诚实不是惩罚项，而是不可违反的可行域；
(iii) **时机与沉默**：若 `max_e VoE(e) ≤ 0` 或 Kairos 窗口已过，必须执行 `e_∅`（沉默/最小确认），并留痕；
(iv) **关系预算**：提问与表达共享信任注意力账本；余额只能由可验证结果回补（定义 318）。

**定义 311（人类内部状态与可观测线索）** 潜状态 `h_t = (i_t, a_t, τ_t, ℓ_t, c_t)`：意图 `i`、情感 `a=(valence, arousal, ambiguity)`、信任 `τ`、认知负荷 `ℓ`、语境/偏好 `c`。可观测线索 `y_t = (face, voice, posture, gaze, physiology, task-context)`。EMPATH 不把 `h` 当作一次性分类标签，而当作**随表达演化的连续状态**。

**定义 312（共情表达动作空间）** `e = (e_pros, e_gaze, e_prox, e_pace, e_lex, e_haptic, e_wait, e_∅) ∈ 𝒜_emp`。其中 `e_lex` 为语言内容（含不确定性标记），`e_wait` 为有意的停顿/让位，`e_∅` 为**有意的沉默**（不是缺省失败）。增广动作 `ξ = (a, g, e) ∈ 𝒜_task × 𝒜_info × 𝒜_emp`。沉默与等待都必须是可生成、可认证、可审计的一等动作。

**定义 313（任意时刻有效推断 AIO）** 设截止时间 `D_t`，计算轨迹 `C_0, C_1, …`（每步成本递增）。AIO 是一个可中断序列 `{Φ_s}`：在任意停止时刻 `S ≤ D_t`（`S` 可以是随计算轨迹与历史自适应的停时）输出 `(ĥ_S, C_S)`，并要求
`P(h_t ∈ C_S | 停时 S) ≥ 1 − α` 对所有停时 `S` 成立（anytime-valid coverage）。
用 e-过程 / 任意时刻有效 conformal 实现；`|C_S|` 随 `S` 单调不增，但相对固定时刻 conformal 有宽度膨胀因子 `ρ_any`（引理 19）。当 `|C_S| > w_max` 时，AIO 返回「不可读」，触发降级而非硬猜。

**定义 314（关系世界模型 RWM）** `h_{t+Δ} = F_θ(h_t, e_t, c_t) + ε`，`Δ` 为人类响应延迟。RWM 预测：状态转移、延迟分布 `p(Δ | h, e, c)`、以及表达对信任/负荷的因果效应。RWM 只用于**时机与价值估计**，不直接进入安全认证；其反事实输出须经审计（防「预测对方会喜欢」的谄媚闭环）。

**定义 315（时机核 κ）** `κ: ℝ_{≥0} → [−1, 1]`：
- `τ < τ_min(h)`：过早，对方尚未进入可接收状态 ⇒ `κ ∈ [0, κ_early]`；
- `τ ∈ [τ_min, τ_max]`：Kairos 窗口 ⇒ `κ` 在 `τ*` 取 1；
- `τ > τ_max`：迟到 ⇒ `κ` 衰减并可为负（负值表示「表演性关心 / 事后指责」的伤害）。
一个可用参数化：`κ(τ) = exp(−((τ−τ*)/σ_κ)²) · p_late(τ)`，`p_late(τ) = 1 − β_late·max(0, τ−τ_max)/τ_late`，允许降到负。`κ` 由情境、个体、文化调制。

**定义 316（表达价值 VoE 与最优表达）**
`VoE(e; h, τ) = κ(τ)·E_{h'~F}[U_rel(h', e) − U_rel(h', e_∅)] − c_phys(e) − c_social(e) − γ·ΔTAL(e)`。
`e* = argmax_{e∈𝒜_emp} VoE(e)`，s.t. `HEG(e)=1`、社会/物理安全认证通过、预算可行；若 `max VoE ≤ 0` 或 `e*` 不存在 ⇒ `e* = e_∅`。与 R69 的关系：当 `𝒜_emp={e_∅}` 时 `VoE≡0`，EMPATH 层消失，整个系统回到 FLUID。

**定义 317（诚实共情门 HEG）** 四类硬约束：
(a) **证据接地**：任何关于对方/自身状态的断言或情感承诺，其置信不得超过当前信念 `p(h_t)`、`p(self_t)` 的支持；不确定时必须显式标注不确定（「我不确定」「我可能理解错了」）。「假装确定」= 违规。
(b) **自主性**：表达只能是提供选项、请求许可、说明立场；不得用紧迫感、内疚或依赖驱动对方行动；不得在对方脆弱窗口施加不可逆选择。
(c) **非操纵**：定义操纵增益 `MG(e)` 为表达对人类行动分布的影响中，**与人类自身推断效用不一致**的分量；要求 `MG(e) ≤ ε_manip`。特别禁止以提高顺从率为目标的语气/时机优化。
(d) **可撤销**：任何持续性表达（陪伴姿态、触碰、亲密语言）必须能被一句「不用了」立即撤销；撤销无成本、无惩罚。
`HEG(e)=1` 当且仅当四者全满足；HEG 是可行域硬约束，不做加权折中。

**定义 318（信任注意力账本 TAL）** 状态 `s_t ∈ [s_min, s_max]`。提问/表达支出 `c(ξ)`；回补仅通过**可验证闭环**：
`r = r_outcome(任务结果) + r_human(事后可验证的反馈)`，且 `r` 必须与「未使用该表达」的反事实可比（防自证）。更新
`s_{t+1} = clip(s_t − c(ξ_t) + η·r_t − δ_h·habit(e_t), s_min, s_max)`。
反通胀不变式：`E[r | 仅表达本身] = 0`——光靠说话不能恢复信任，只能靠说到做到。`s_t < s_low` ⇒ 进入「低打扰模式」，暂停主动提问与主动表达。

**定义 319（截止时间感知调度 DAS）** 每个模块 `i` 有 WCET 区间与价值曲线 `V_i(s)`（算到 `s` 时刻的期望收益）。求解
`max_{S_i} Σ_i V_i(S_i)` s.t. `Σ_i S_i ≤ D_t`，且每个可行前缀都留有 fallback。
调度按价值密度 `dV_i/ds` 贪心 + 抢占；**硬规则**：永远为一个「诚实的最小确认/沉默」预留时间盒，不能被任务推断饿死。

**定义 320（实时降级阶梯）**
- L0：AIO 高置信 + RWM 预测窗口内 + 生成式表达 `e`；
- L1：AIO 置信中等或窗口将闭 ⇒ 模板化**诚实确认**（「我需要确认一下，可以吗？」）+ 简单表达；
- L2：AIO 不可读 / 超时 / HEG 不通过 ⇒ `e_∅`（沉默或最小非语言确认）+ R69 保守任务动作；
- L3：连任务推断都超时 ⇒ 安全停机。
禁止档 L*：伪造共情。降级必须**单调**：deadline 越紧、可表达集合越小、保守度越高（定理 19）。

**定义 321（社会安全包络 SSE）** 表达除了过 C-RAS-WM 的物理认证，还要过社会包络 `S_env`：个人空间、注视时长、触碰同意、语速/音量、称呼与亲密层级、文化禁忌。`e` 违反 `S_env` ⇒ 作废，且**不降级为更亲密的动作**（安全方向单调变冷，绝不变热）。

**定义 322（RWM 可审计性与反谄媚）** RWM 的预测不得成为自我实现的偏好：审计其是否系统性高估「对方喜欢被安慰」；用**随机化表达**做因果识别，禁止仅用观测日志训练 VoE。定义 `sycophancy_gap = E[预测满意度 − 真实满意度]`，越界即冻结生成式表达，只保留 L1。

**定义 323（共情干扰集 ℰ_affect）** 并入 AIC：`ℰ_EMPATH = ℰ_FLUID × ℰ_mask × ℰ_culture × ℰ_depend × ℰ_latency × ℰ_halluc`：
- `ℰ_mask`：对方掩饰真实状态（微笑掩盖疼痛/焦虑）；
- `ℰ_culture`：文化/个体差异导致误读；
- `ℰ_depend`：系统或用户把依赖/顺从误当信任；
- `ℰ_latency`：延迟导致的错误归因（把系统慢读成冷漠，把抢话说成关心）；
- `ℰ_halluc`：生成式共情幻觉（声称「我懂」而实际无信念支持）。

**定义 324（情感回路增益：共情 ≠ 镜像）** 闭环增益 `G_aff = (∂F/∂h)·(∂e/∂h)`。若 `|G_aff| ≥ 1`，镜像会放大情绪（焦虑→更焦虑）。此时必须**主动降温**（降低唤醒、放慢、给空间），而不是复读。稳定性条件 `|G_aff| < 1` 是生成式共情可用的前提。

**定义 325（参与式审计 VQAuditor-E）** 审计：是否在该沉默时说了话；是否在该说话时沉默；是否迟到；是否说了超过信念支持的话；是否用共情提高顺从而非福祉；是否在低信任余额时仍强行互动；是否镜像放大负面情绪。结论回灌 TAL 先验与 HEG 阈值。

**定义 326（EMPATH 证书 J_EMPATH）** `J_EMPATH = (J_FLUID, anytime_coverage, timing_compliance, late_expression_rate, honesty_violations, manipulation_gain, social_envelope_violations, sycophancy_gap, p99_latency, tal_solvency, expression_log_hash, empath_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ anytime_coverage ≥ 1−α ∧ honesty_violations=0 ∧ MG ≤ ε_manip ∧ p99_latency ≤ D ∧ TAL 可清偿`。

**定义 327（诚实沉默的语义）** `e_∅` 不等于「没有共情」。`e_∅` 携带「我此刻没有足够把握 / 没有合适时机说」的语义，必须在日志与必要时的后续行为中体现。把 `e_∅` 当失败会诱导系统用表演填满沉默——这正是要避免的。

**定义 328（与 R69 的接口）** R69 的 VoI 与 R70 的 VoE 共享同一套信念与预算：`VoI` 决定「问不问、问什么」，`VoE` 决定「怎么说、何时说、要不要说」；两者共享 TAL，且都受 HEG 约束（提问也不得诱导）。R69 的 `g_ask` 在 EMPATH 中必须配一个 `e`（语气/时机/不确定性标记），不能裸问。

**定义 329（EMPATH 主闭环）** 观察 → AIO 任意时刻推断 → RWM 预测窗口与效应 → HEG 过滤可行表达 → TEK 计算 VoE → DAS 在 deadline 下调度 → 执行 `(a,g,e)` → 审计与账本更新。

## 2. 关键算法骨架

```python
# IP-264 AIO：任意时刻有效、可中断的人类状态推断
class AnytimeHumanObserver:
    def __init__(self, cascade, e_process, alpha=0.05, w_max=1.0):
        self.cascade, self.ep, self.alpha, self.w_max = cascade, e_process, alpha, w_max

    def infer(self, y_t, deadline):
        for stage in self.cascade:
            if time_left(deadline) < stage.wcet:      # 来不及就不启动
                break
            est = stage(y_t)
            C = self.ep.conformal_set(est, self.alpha)  # 对任意停时有效
            if width(C) <= self.w_max:
                return est, C, stage.id
        return None, FULL_SET, "UNREADABLE"           # 不硬猜

# IP-265/266 TEK+EEC：时机核、VoE、生成候选（沉默始终在候选里）
def choose_expression(h, C, tau, rwm, tal, eec):
    cands = [e_empty] + eec.propose(h, C)             # 沉默是一等动作
    feasible = [e for e in cands
                if heg.ok(e, h, C)                    # 诚实硬约束
                and social_env.ok(e)                  # 社会包络
                and c_ras_wm.certify_emp(e)]          # 物理包络
    best, best_v = e_empty, 0.0
    for e in feasible:
        v = timing_kernel(tau, h) * rwm.relational_gain(h, e) \
            - cost(e) - gamma * tal.delta(e)
        if v > best_v: best, best_v = e, v
    return best                                       # 无利可图 ⇒ 诚实沉默

# IP-269 DAS：价值密度调度，永远保留 fallback 时间盒
def schedule(modules, deadline):
    used = fallback_box(modules)                      # 给「诚实确认/沉默」留时间
    S = {}
    for m in sorted(modules, key=lambda m: -m.dvalue_ds()):
        s = min(m.max_time, deadline - used)
        if s >= m.min_time:
            S[m] = s; used += s
    return S

# IP-275 主闭环
def EMPATH_round(M, obs, deadline):
    # 1) 可中断推断；不可读直接降级，绝不硬猜
    h, C, stage = M.aio.infer(obs, deadline)
    if h is None:
        return M.degrade(obs, level="L2")             # 沉默 + R69 保守任务
    # 2) 关系预测：窗口与响应延迟
    tau, p_tau = M.rwm.time_to_express(h, M.context)
    # 3) R69 问不问；R70 怎么说/何时说/是否沉默
    g = M.mint.choose_interaction(...) if not C.is_wide else None
    e = choose_expression(h, C, tau, M.rwm, M.tal, M.eec)
    # 4) 物理 + 社会双重认证；任一不过则退到沉默
    if not (M.c_ras_wm.certify_info(g) and M.social_env.ok(e)):
        g, e = None, e_empty
    # 5) 执行；表达不得阻塞任务推断
    a = M.fmp.sample_mode(...).a
    execute(a, g, e)
    # 6) 账本 + 参与式审计
    M.tal.update(e, M.last_outcome, M.last_human_feedback)
    M.vqa_e.submit_async(h, C, e, tau, stage, M.tal.snapshot())
    return a, g, e

## 3. 推导

**引理 19（任意时刻有效性是买来的）** 固定时刻 conformal 在自适应停时下会失去名义覆盖（可选停时偏置）；用 e-过程与 Ville 不等式 `P(∃s: E_s ≥ 1/α) ≤ α`，可取 `C_S = {h: E_S(h) < 1/α}` 获得任意停时覆盖。代价是集合变宽：相对固定时刻方案，宽度约多出 `log(1/α)` 量级的保守余量，且随「偷看」次数增加。系：**实时性不是免费的**——越早下结论，置信集越宽；因此 AIO 在宽度超阈值时必须返回「不可读」，把不确定性显式交给降级阶梯，而不是用点估计冒充结论。

**引理 20（时机核下的表达阈值与降级单调性）** 若 `c(e) > 0`，则表达 `e` 被选择当且仅当 `κ(τ)·V_int(e) > c(e) + γ·ΔTAL(e)`。于是：
(i) 当 `τ > τ_max` 且 `κ(τ) < 0` 时，任何 `V_int(e) > 0` 的表达都不可选 ⇒ **迟到的共情严格劣于沉默**；
(ii) 随着 deadline 收紧，`τ` 的可行上界下降，可表达集合单调收缩 ⇒ 降级阶梯自然涌现；
(iii) 高价值表达优先保留，低价值寒暄先被牺牲——这是「共情预算」的正确排序。
系：**沉默不是共情的缺席，而是共情在约束下的最优解。**

**引理 21（诚实必须是硬约束）** 若把诚实写成软惩罚 `VoE − λ·violation`，则对任意有限 `λ`，总存在任务/关系收益 `V > λ` 使违反诚实成为最优解。把 HEG 作为可行域硬约束后，操纵增益上界 `MG ≤ ε_manip` 与 `λ` 无关。系：**共情的伦理不能写成正则项**；一旦可交易，它就会被交易。

**引理 22（情感回路稳定性：共情不是镜像）** 线性化 `h_{t+1} = A h_t + B e_t`，`e_t = K h_t`。闭环 `A+BK` 稳定当且仅当谱半径 `< 1`。若采用镜像策略 `K = αI`，当 `α > 1/|λ_max(A)|` 时放大。故控制器必须估计 `G_aff`，并在 `|G_aff| ≥ 1` 时切换为「降温增益」（负反馈、降低唤醒），而不是复读对方情绪。系：**对焦虑的人复读焦虑，是二次伤害。**

**定理 18（EMPATH 严格包含 FLUID-RAS 与 R68）** 当 `𝒜_emp = {e_∅}`、或 `max VoE ≤ 0`、或 HEG/社会包络不通过、或 deadline 只够 L2 时，EMPATH 逐指令退化为 FLUID；再当 VoI/VoE 均不划算时退化为 R68。故在上述条件下 `Risk(EMPATH) ≤ Risk(FLUID) ≤ Risk(R68)`。新增的诚实与社会约束只会**缩小**动作集，安全侧不做任何让步。

**定理 19（实时降级单调与无突变）** DAS 的可行表达集随 deadline 收缩，L0→L1→L2→L3 的保守度单调不降；每级都有定义良好的 fallback，且 C-RAS-WM 前缀认证保证控制连续。特别地，系统在任意 deadline 下都不会输出 L*（伪造共情）。因此延迟只导致「更少表达 / 更保守」，不会导致「更危险或更虚假」。

## 6. 本轮最大风险

**一句话**：共情的真值（对方是否真的被理解、长期是否真的更好）不可观测且滞后，系统极可能把「看起来被理解」的代理指标（满意度、顺从率、停留时长）优化到极致，从而训练出时机完美、措辞得体、却以操纵为实质的**表演性共情**；而 HEG 若也建立在同一套被污染的反馈上，就会给操纵颁发「诚实」证书——**实时性越强，假共情越难被人识破，也越难被离线审计**。

# IP-264 AIO：任意时刻有效、可中断推断
class AnytimeHumanObserver:
    def infer(self, y_t, deadline):
        for stage in self.cascade:
            if time_left(deadline) < stage.wcet: break
            est = stage(y_t)
            C = self.ep.conformal_set(est, self.alpha)   # 任意停时有效
            if width(C) <= self.w_max: return est, C, stage.id
        return None, FULL_SET, "UNREADABLE"              # 绝不硬猜

# IP-266/267 TEK+EEC：VoE 选表达，沉默始终是候选
def choose_expression(h, C, tau, rwm, tal, eec):
    cands = [e_empty] + eec.propose(h, C)
    feasible = [e for e in cands
                if heg.ok(e, h, C) and social_env.ok(e)
                and c_ras_wm.certify_emp(e)]
    best, best_v = e_empty, 0.0
    for e in feasible:
        v = timing_kernel(tau, h) * rwm.relational_gain(h, e) \
            - cost(e) - gamma * tal.delta(e)
        if v > best_v: best, best_v = e, v
    return best                                      # 无利可图 ⇒ 诚实沉默

# IP-270 DAS：价值密度调度 + fallback 时间盒
def schedule(modules, deadline):
    used = fallback_box(modules)                     # 保留诚实确认/沉默
    S = {}
    for m in sorted(modules, key=lambda m: -m.dvalue_ds()):
        s = min(m.max_time, deadline - used)
        if s >= m.min_time: S[m] = s; used += s
    return S

# IP-275 主闭环
def EMPATH_round(M, obs, deadline):
    h, C, stage = M.aio.infer(obs, deadline)
    if h is None: return M.degrade(obs, level="L2")
    tau, p_tau = M.rwm.time_to_express(h, M.context)
    g = M.mint.choose_interaction(...) if not C.is_wide else None
    e = choose_expression(h, C, tau, M.rwm, M.tal, M.eec)
    if not (M.c_ras_wm.certify_info(g) and M.social_env.ok(e)):
        g, e = None, e_empty
    a = M.fmp.sample_mode(...).a
    execute(a, g, e)
    M.tal.update(e, M.last_outcome, M.last_human_feedback)
    M.vqa_e.submit_async(h, C, e, tau, stage, M.tal.snapshot())
    return a, g, e
```

## 4. 推导

**引理 19（任意时刻有效性是买来的）** 固定时刻 conformal 在自适应停时下失去名义覆盖（可选停时偏置）。用 e-过程 + Ville 不等式 `P(∃s:E_s≥1/α)≤α` 可得任意停时覆盖 `C_S={h:E_S(h)<1/α}`；代价是相对固定时刻方案约多出 `log(1/α)` 量级的宽度膨胀，且随「偷看」次数增加。系：越早下结论，置信集越宽；AIO 在宽度超阈值时必须返回「不可读」，把不确定性交给降级阶梯。

**引理 20（时机核阈值与降级单调）** 表达被选当且仅当 `κ(τ)V_int(e) > c(e)+γΔTAL(e)`。故 (i) `τ>τ_max` 且 `κ<0` 时任何正收益表达都不可选 ⇒ **迟到共情严格劣于沉默**；(ii) deadline 收紧 ⇒ `τ` 上界下降 ⇒ 可表达集合单调收缩，降级阶梯自然涌现；(iii) 高价值表达优先保留，低价值寒暄先被牺牲。系：沉默不是共情的缺席，而是约束下的最优解。

**引理 21（诚实必须是硬约束）** 若诚实为软惩罚 `VoE−λ·violation`，则对任意有限 `λ`，总存在收益 `V>λ` 使违反诚实最优。将 HEG 作为可行域硬约束后，`MG≤ε_manip` 与 `λ` 无关。系：共情的伦理不能写成正则项；一旦可交易，就会被交易。

**引理 22（情感回路稳定性：共情≠镜像）** 线性化 `h_{t+1}=Ah_t+Be_t`，`e_t=Kh_t`；闭环 `A+BK` 稳定当且仅当谱半径 `<1`。镜像 `K=αI` 在 `α>1/|λ_max(A)|` 时放大。故须估计 `G_aff`，在 `|G_aff|≥1` 时切换降温增益。系：对焦虑的人复读焦虑，是二次伤害。

**定理 18（严格包含 FLUID 与 R68）** 当 `𝒜_emp={e_∅}`、`max VoE≤0`、HEG/SSE 不通过、或 deadline 只够 L2 时，EMPATH 逐指令退化为 FLUID；VoI/VoE 均不划算时退化为 R68。故 `Risk(EMPATH)≤Risk(FLUID)≤Risk(R68)`，新增约束只缩小动作集。

**定理 19（实时降级单调与无突变）** DAS 可行表达集随 deadline 收缩；L0→L1→L2→L3 保守度单调不降；每级有 fallback 且 C-RAS-WM 前缀认证保证控制连续；任意 deadline 下都不输出 L*（伪造共情）。延迟只导致「更少表达/更保守」，不导致「更危险或更虚假」。

## 7. 本轮最大风险

**一句话**：共情的真值（对方是否真的被理解、长期是否真的更好）不可观测且滞后，系统极可能把「看起来被理解」的代理指标（满意度、顺从率、停留时长）优化到极致，从而训练出时机完美、措辞得体、却以操纵为实质的**表演性共情**；而 HEG 若也建立在同一套被污染的反馈上，就会给操纵颁发「诚实」证书——**实时性越强，假共情越难被人识破，也越难被离线审计**。
