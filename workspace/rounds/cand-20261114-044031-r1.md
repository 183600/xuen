# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「可重构机构」×「文化适应性」）

> R69 教会了系统「问」，却默认了两个从未被检验的前提：**身体是常量、问句的意思处处相同**。R69 的流策略在固定动作空间 𝒜 上学，VoI 在固定成本 c(g) 上算，证据纪律假设 k 个源「正交」。真实部署里这两条都塌了：
> - **可重构机构**：机器人换腿、换臂、增删模块，动作向量的**含义**随形态改变。R69 的模态分解不是数值漂移，而是**支撑集改变**——它在比较已经不存在的模态，或漏掉刚出现的模态。
> - **文化适应性**：同一个注视/探针/问句，在一种规范里是礼貌求证，在另一种里是冒犯或威胁。R69 的交互成本 c(g) 与证据语义 p(y|g,o) 都是**规范的函数**，而规范 κ 恰恰是系统看不见的潜变量。
>
> 更尖锐的是，R69 用来防投毒的「k 个正交证据源一致」（引理 18）会被**文化共识**伪造：面部、语气、姿态都被同一个文化先验 κ 过滤，它们不是 k 票，而是同一个先验的 k 个投影——**k_eff 崩塌，共识不等于验证**。
>
> 核心命题：**把「上下文」从噪声升级为语义框架 γ=(m,κ)；显式建模、主动辨识、事务化切换，并只在规范地板内适应。** 检测不到框架变更时，才允许按旧框架行动；辨识不了时，退化为最小安全控制器。命名 **PROTEAN-RAS**（Policy Re-framing under Ontology/embodiment Transitions & Enacted Adaptive Norms）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我的身体还是我以为的那具吗？我的问题在对方那里还是同一个意思吗？**」——上下文不是可以忽略的背景，而是决定动作含义的框架本身。

## 0. 直觉与动机

**灵感 1（可重构机构 → 身体不是常量，动作语义随形态而变）**
直觉：R69 的流匹配策略把动作块 ξ 当作固定维度的向量。可机器人一旦重构——轮换腿、模块增删、拓扑改变——同一个关节指令可能变成另一个动作，甚至根本不可达。这不是「同分布的数值漂移」，而是**动作字母表本身变了**：R69 聚出来的模态里，有的在新形态下不存在，有的新模态还没被采样到。因此重构瞬间的 U_epi 是**结构性错误**，不是「置信度不准」。正确做法不是重训大脑，而是把策略学在**意图商**（任务效果等价类）上：策略产出「要做什么」，解码器按当前形态 m 产出「这具身体怎样做」。重构 = 换解码器 + 校验等变缺陷，而不是换大脑。

**灵感 2（可重构机构 → 重构既是最强的信息动作，也是最大的不连续）**
直觉：伸出一根杆把相机送近一点、换一个抓取器去够狭窄处——这是**用身体做实验**，本质是 R69 的信息动作，只是成本极高、半不可逆。所以重构应进入同一个 VoI 账本。但另一面，重构会瞬移式改变自由度与安全包络，直接违反 R69 定理 17 承诺的「控制连续、无突变」。解法不是假装连续，而是**承认跳变、把跳变事务化**：经过安全钳位中间态 m†，过渡期只跑最小安全控制器，自模型辨识收敛前绝不签发新证书。

**灵感 3（文化适应性 → 交互成本与证据语义是规范的函数）**
直觉：R69 的 MINT 优化 VoI(g)−c(g)，却把 c(g) 当成纯物理成本。但「直接问一句『你还好吗』」在某些规范里是关心，在另一些里是冒犯；长注视是专注还是威胁；沉默是尊重还是回避。c(g;κ) 与 p(y|g,o,κ) 都随规范 κ 变。用自己文化的成本表去另一个文化里算 VoI，会**系统性地把昂贵当便宜**，做出被审计为「不礼貌甚至危险」的主动交互。

**灵感 4（文化适应性 → 文化共识会伪造「正交证据」，k_eff 崩塌）**
直觉：R69 引理 18 的抗投毒上界依赖各证据源欺骗相关 ρ<1。但文化先验 κ 是**共同偏差**：脸、声音、姿态由同一套规范解释，高度相关。此时「三个源都同意」可能只是「一个先验被数了三次」。这不是对抗性共谋，而是**非对抗的文化共谋**，却同样击穿证据纪律。必须估计**有效独立源数** k_eff，而不是数源头的个数；并用稳健 VoI（对 κ 取最坏情形）代替点估计——**文化谦逊 = 不确定时假设别人的成本更高，而不是假设别人和你一样**。

**灵感 5（二者统一 → 上下文是框架的变化，不是噪声的增加；检测—辨识—认证—适应/退避）**
直觉：形态改变动作的物理含义，文化改变动作的社会含义，但它们共享同一个抽象：**它们改的不是数值，是解释动作与观测的语义框架**。于是 R70 的主线不是再堆一个模块，而是给闭环补一个「框架层」：框架变更监测（我还在对的框架里吗）→ 自模型/规范辨识（我现在在哪个框架）→ 事务化切换与认证（换框架安全吗）→ 规范地板内的适应，否则退避。理论姿态延续 R66–R69 的传统：框架固定且已知时，PROTEAN 逐指令退化为 FLUID；再叠加「不交互」则退化为 R68。**新层必须严格包含旧层，否则每加一层就多一个独立要信任的黑箱。**

## 1. 形式化定义（增量：定义 310–324）

**定义 310（PROTEAN-RAS 总览与三不变式）** PROTEAN-RAS = (MSI, MTE, RTP, NCM, NIR, ECC, NFG, RAS-WM‡)，上下文元组 γ = (m, κ) ∈ ℳ × 𝒦。三不变式：
(i) **上下文显式化**：任何动作/观测都在显式 γ 下解释，禁止隐式默认「身体不变、文化通用」；
(ii) **重构事务性**：过渡期不签发任何新证书，自模型辨识收敛前只运行最小安全控制器（MSC，fail-safe）；
(iii) **规范地板**：文化适应只在允许流形 𝒩_permit 内进行，硬规范 H 跨文化不变。

**定义 311（形态状态与可采纳重构）** m ∈ ℳ =（运动学树 G，自由度 d，传感集 S，执行包络 U）。重构 ρ: m → m′ 可改变 d 与拓扑。ρ 可采纳 ⇔ 存在经**安全钳位中间态** m† 的两阶段路径，且过渡物理风险 ≤ ε_reconf。

**定义 312（意图商与形态迁移）** 效应映射 φ_m: 𝒜(m) → ℐ（任务空间效果/意图），φ_m 为 L_φ-Lipschitz。意图商 𝒜/∼ 中 ξ ∼ ξ′ iff φ_m(ξ) = φ_{m′}(ξ′)（同任务效果）。迁移 T_{m′|m} = φ_{m′}^{-1} ∘ φ_m（在可达像上）。等变缺陷 e_equiv(m,m′) = sup_ξ W₂((T_{m′|m})_# π_θ(·|o,m), π_θ(·|o,m′))。策略学在意图商上、解码器随形态换装；签发证书要求 e_equiv ≤ ε_eq。

**定义 313（自模型后验与形态不确定性）** 形态可能部分未知（模块被换/半插/被遮挡），观测 o 只能给出后验 b(m|o)。形态不确定性 U_morph = H(b)。U_morph > τ_m ⇒ 不签发证书，运行 MSC。

**定义 314（规范上下文变量）** κ ∈ 𝒦 为规范/文化语境潜变量，不可直接观测，只能由行为代理（近距学 proxemics、轮次转换 turn-taking、直接性、正式度、沉默/注视含义）推断，且个体偏离显式建模。κ 调制三件事：交互成本 c(g;κ)、信号语义 p(y|g,o,κ)、证据相关结构 Corr_κ(ℰ)。**κ 不是人口学标签，禁止用身份标签直接赋值。**

**定义 315（规范感知交互 NIR 与稳健 VoI）** VoI_κ(g) = H(M|o,κ) − E_{y~p(·|g,o,κ)}[H(M|o,y,κ)]。κ 不确定时用可信集 K，稳健 VoI：VoI_rob(g) = min_{κ∈K}[VoI_κ(g) − c(g;κ)]。选 g* = argmax_g VoI_rob(g) s.t. risk(g) ≤ ε_int ∧ 规范地板。若 max VoI_rob ≤ 0 ⇒ 不交互（文化谦逊：不确定时假设成本更高，而非套用自己文化）。

**定义 316（有效独立性 / 文化共谋）** R69 引理 18 依赖 ρ<1 的正交证据。规范先验 κ 给所有源注入共同偏差。设证据相关矩阵在 κ 下等相关 ρ_κ，则有效独立源数 **k_eff(κ) = k / (1 + (k−1)ρ_κ)**，饱和于 1/ρ_κ。若 k_eff < k_min ⇒ 证据纪律失效（文化共识不是独立验证）。文化共谋 = 非对抗性的、由共享先验造成的一致性。

**定义 317（重构作为宏观信息动作 RIA）** 重构 ρ 可作为信息动作（伸长传感器、换视角、增自由度）。其 VoI 同定义 298，但成本 c(ρ) 含时间、能量与不可逆性，并须过定义 311 的事务性安全。仅当 VoI(ρ) − c(ρ) > 0 且超时 τ(ρ) 可接受时采纳。

**定义 318（事务性重构协议 RTP）** 状态机 PRE → TRANSITION(m†, MSC, 零学习写) → IDENTIFY（自模型辨识 + 等变校验）→ COMMIT（签发 J_PROTEAN(m′)）/ ABORT（回滚 m）。TRANSITION 期间禁止在任何旧证书下运行任务策略；任何失败/超时 ⇒ ABORT。

**定义 319（规范地板治理 NFG）** 适应只在 𝒩_permit 上允许；硬规范 H = {物理安全, 人的尊严, 非欺骗, 非操纵, 知情同意} 跨文化不变。若推断 κ 会授权违反 H 的行为，投影回最近的安全规范并记录；不允许「入乡随俗」越过 H。

**定义 320（反刻板印象守卫 ASG）** κ_eff 由群体先验 κ_pop 与个体证据按贝叶斯合成，且保留个体后验不确定性。任何硬承诺（交互方式选择/信号解读）必须在**个体后验**下可行，而不是在群体众数下可行；禁止仅由群体众数做不可逆决策。

**定义 321（框架变更监测 FCM）** 监测当前 γ=(m,κ) 是否仍成立：对近期残差与交互结果做一致性检验，框架分 F = D_KL(p_obs ‖ p_θ(·|o,γ))（结合 R69 FMA 行为似然通道 + 交互结果的「语义惊讶」）。F > τ_F 且持续 ⇒ 判定框架变更，触发重辨识（回 RTP / κ 重估），而非在旧框架下继续加码。

**定义 322（证书 J_PROTEAN）** J_PROTEAN = (J_FLUID, m_hash, U_morph, e_equiv, k_eff, K_κ, normative_floor_ok, adaptation_log_hash, protean_ver)。Valid ⇔ Valid(J_FLUID) ∧ U_morph ≤ τ_m ∧ e_equiv ≤ ε_eq ∧ k_eff ≥ k_min ∧ normative_floor_ok。

**定义 323（威胁模型 AIC-PROTEAN）** ℰ_PROTEAN = ℰ_FLUID × ℰ_morph × ℰ_cult。ℰ_morph：恶意模块替换、半重构/部分失败、传感器套件欺骗、等变缺陷被利用；ℰ_cult：规范操纵、文化 gaslighting（诱导系统怀疑自己的规范地板）、谄媚陷阱（只奖励顺从）、禁忌陷阱（以「适应」为名诱导越界）。并入对抗训练与审计。

**定义 324（过度适应界）** 设真实个体效用依赖 κ*；过度适应 = 所选行为在估计 κ 下最优、却在 H 的某邻域外。sycophancy gap = U_true(κ*, a_adapt) − U_true(κ*, a_floor)。要求 gap ≤ ε_syc，且适应不得降低 H 满足度——**适应是优化，不是投降**。

## 2. 关键算法骨架

```python
# IP-264/273/275 PROTEAN 主闭环：框架层包裹 R69 FLUID 内环
def PROTEAN_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(o)   # 继承 R69
    # 1) 框架变更监测（定义 321）：身体/规范是否还是旧的 γ=(m,κ)
    F = M.fcm.frame_score(obs, gamma=M.gamma)                  # KL / 行为似然 + 语义惊讶
    if F > TAU_F:
        M.rtp.begin(M.gamma.m)                                 # 进入事务：先退到 MSC
        m_new, U_morph = M.msi.identify(obs)                   # 自模型辨识（定义 313）
        if U_morph > TAU_M:  return M.msc.step(obs)            # fail-safe，不签发证书
        if M.rtp.equiv_defect(M.gamma.m, m_new) > EPS_EQ:
            return M.rtp.abort_or_commit(m_new)                # 等变不过 → ABORT / 降级
        M.gamma = (m_new, M.gamma.k)                           # COMMIT 形态
    # 2) 规范辨识（定义 314）：从行为代理推断 κ 的可信集 K
    K = M.ncm.credible_set(obs, prior=M.gamma.k)               # 保留个体偏离
    # 3) 有效独立源数（定义 316）：文化共识会伪造正交
    k_eff = M.ecc.effective_count(M.evidence_sources(), K)
    # 4) 稳健 VoI（定义 315）：对 κ 取最坏，而非取均值
    g = M.nir.choose_robust(M.aud.modes, o, K, k_eff, M.budget)
    if g is not None and not M.nfg.within_floor(g):
        g = M.nfg.project_to_floor(g)                          # 规范地板，H 不可越
    # 5) 内层仍是 R69 FLUID：迁移后的策略 + 交互 + 似然第二意见
    if g is not None and k_eff >= K_MIN:
        U_epi_after = M.cia.execute_and_update(g, k_eff)       # 文化下也需有效独立
    else:
        U_epi_after = M.aud.U_epi                              # 未消解 → 走保守
    xi = M.mte.transport(M.fmp.sample(o, K=adaptive_K(M, z)), frm=M.gamma.m)
    lam = max(M.efs.risk_scale(...), lam_floor(M.aud.U_ale + U_epi_after))
    k = M.c_ras_wm.certified_prefix(xi)
    # 6) 审计 + 证书（定义 322）
    M.vqa_p.submit(g, F, k_eff, K, M.gamma)
    return k, lam, xi, M.certificate(M.gamma, U_morph, k_eff, K)
```

## 3. 推导

**引理 19（形态迁移的次优界）** 设 φ_m 为 L_φ-Lipschitz，代价泛函 J 关于动作分布在 W₂ 下 L_J-Lipschitz。则 |J(π_{m′}) − J(T_{m′|m} π_m)| ≤ L_J·e_equiv + L_J·W₂(不可达质量)。要点：**迁移误差来自「等变缺陷」与「旧意图在新形态下不可达」两部分**；前者靠意图商学习压低，后者必须由 RTP 的 IDENTIFY 阶段显式检测，不能靠策略泛化硬扛。

**引理 20（文化共谋下的有效证据数）** 等相关 ρ_κ 时 k_eff = k/(1+(k−1)ρ_κ)，随 k 单调饱和于 1/ρ_κ。故 R69 的投毒上界 δ_p ρ^{k−1} 应替换为 δ_p ρ_κ^{k_eff−1}；k→∞ 时误差地板不趋于 0，而趋于 δ_p ρ_κ^{1/ρ_κ−1}。系：**在共享文化先验下「多找几个源」不再有用，必须找真正不共享先验的源，或降低对共识的信任**——这正是 ECC 门控 k_eff 而非 k 的理由。

**引理 21（规范不确定下的稳健 VoI 遗憾界）** 设可信集 K 的直径为 D，VoI 与成本对 κ 分别 L_v、L_c-Lipschitz。则稳健规则相对真实 κ* 的遗憾 ≤ (L_v+L_c)·D，且永不选择真实 [VoI−c] < −(L_v+L_c)·D 的交互。要点：**稳健 VoI 只能把规范误判的伤害限制在可信集直径内，不能消除它**——这既给出保护，也直接指向本轮最大风险。

**引理 22（框架变更检测延迟）** 对 γ→γ′ 的持续变点，CUSUM 型 FCM 的平均检测延迟 ~ O(log(1/α) / D_KL(p_γ′‖p_γ))，误报率 ≤ α。系：框架变更越隐蔽（KL 越小），越晚被发现，期间越依赖事务化的 fail-safe 而非检测本身。

**定理 18（PROTEAN 严格包含 FLUID 与 R68）** 当 γ 固定且已被正确辨识（m=m₀、K={κ₀}、k_eff ≥ k_min、无重构）时，PROTEAN 逐指令等于 R69 FLUID；再叠加「不交互」则逐指令等于 R68。因此 R68 ⊂ R69 ⊂ R70。安全侧永不更弱：过渡期 fail-safe、规范地板钳制、框架变更回退三条路径都只会增加保守性。

**定理 19（重构与规范适应下的安全）** 在 RTP + NFG + FCM 下：重构期间与之后的物理风险 ≤ ε_reconf，且系统永不在过期证书下运行；规范适应永不违反 H；任何超出可信集的框架变更都触发回退且保守性单调不降。与 R69 定理 17（连续无突变）不同，本轮**接受一个有界跳变**，用「认证过的安全钳位中间态」替代「连续」作为安全保证。

def PROTEAN_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(o)   # 继承 R69
    # 1) 框架变更监测（定义 321）
    F = M.fcm.frame_score(obs, gamma=M.gamma)                  # KL / 行为似然 + 语义惊讶
    if F > TAU_F:
        M.rtp.begin(M.gamma.m)                                 # 进入事务：先退到 MSC

            return M.rtp.abort_or_commit(m_new)                # 等变不过 → ABORT / 降级
        M.gamma = (m_new, M.gamma.k)
    # 2) 规范辨识（定义 314）
    K = M.ncm.credible_set(obs, prior=M.gamma.k)
    # 3) 有效独立源数（定义 316）：文化共识会伪造正交
    k_eff = M.ecc.effective_count(M.evidence_sources(), K)
    # 4) 稳健 VoI（定义 315）
    g = M.nir.choose_robust(M.aud.modes, o, K, k_eff, M.budget)
    if g is not None and not M.nfg.within_floor(g):
        g = M.nfg.project_to_floor(g)                          # 规范地板，H 不可越
    # 5) 内层仍是 R69 FLUID
    if g is not None and k_eff >= K_MIN:
        U_epi_after = M.cia.execute_and_update(g, k_eff)
    else:
        U_epi_after = M.aud.U_epi
    xi = M.mte.transport(M.fmp.sample(o, K=adaptive_K(M, z)), frm=M.gamma.m)
    lam = max(M.efs.risk_scale(...), lam_floor(M.aud.U_ale + U_epi_after))
    k = M.c_ras_wm.certified_prefix(xi)
    # 6) 审计 + 证书
    M.vqa_p.submit(g, F, k_eff, K, M.gamma)
    return k, lam, xi, M.certificate(M.gamma, U_morph, k_eff, K)

## 4. 推导

**引理 19（形态迁移的次优界）** φ_m 为 L_φ-Lipschitz、J 对动作分布 W₂-L_J-Lipschitz 时，|J(π_{m′}) − J(T_{m′|m}π_m)| ≤ L_J·e_equiv + L_J·W₂(不可达质量)。系：迁移误差 = 等变缺陷 + 旧意图不可达；前者靠意图商压低，后者必须由 RTP 显式检测。

**引理 20（文化共谋下的有效证据数）** 等相关 ρ_κ 时 k_eff=k/(1+(k−1)ρ_κ)→1/ρ_κ；R69 上界 δ_p ρ^{k−1} 应替换为 δ_p ρ_κ^{k_eff−1}，k→∞ 时地板不趋 0 而趋 δ_p ρ_κ^{1/ρ_κ−1}。系：共享先验下「多找几个源」无用，必须考 k_eff 或换非共享先验的源。

**引理 21（规范不确定下的稳健 VoI 遗憾界）** 可信集直径 D、VoI/成本对 κ 为 L_v/L_c-Lipschitz 时，稳健规则遗憾 ≤ (L_v+L_c)·D，且永不选择真实 [VoI−c] < −(L_v+L_c)·D 的交互。系：稳健 VoI 把误判伤害限制在 D 内，但不能消除——直接指向最大风险。

**引理 22（框架变更检测延迟）** 对 γ→γ′ 持续变点，CUSUM 型 FCM 平均检测延迟 ~ O(log(1/α)/D_KL(p_γ′‖p_γ))，误报 ≤ α。系：变更越隐蔽发现越晚，期间更依赖事务化 fail-safe 而非检测。

**定理 18（PROTEAN 严格包含 FLUID 与 R68）** γ 固定且已辨识（m=m₀、K={κ₀}、k_eff≥k_min、无重构）时 PROTEAN 逐指令等于 R69 FLUID；再叠加「不交互」等于 R68。故 R68 ⊂ R69 ⊂ R70，安全侧永不更弱。

**定理 19（重构与规范适应下的安全）** RTP+NFG+FCM 下，重构期间/之后物理风险 ≤ ε_reconf、永不运行于过期证书下；规范适应永不违反 H；超可信集的框架变更触发回退且保守性单调不降。用「认证过的安全钳位中间态」替代 R69 的「连续」作为安全保证。

**次级风险与缓解**：框架辨识不可识别（可信集+稳健 VoI 仅限伤害于直径内，引理 21，需主动辨识与保守地板兜底）；半重构/形态欺骗（RTP fail-safe + 自模型后验 + ℰ_morph 对抗训练，E303/E305）；文化共谋击穿证据纪律（以 k_eff 而非 k 门控，k_eff<k_min 退回保守，定义 316、引理 20、E308）；过度适应/谄媚（NFG + ASG + sycophancy gap 上界，定义 319–320、324）；框架变更发现过晚（检测延迟与 KL 成反比，期间靠 fail-safe，引理 22）。
