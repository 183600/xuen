# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化证据承诺」IP-133~138；新灵感循环第 1 轮；本轮灵感：「UniBot世界挑战赛」×「评测指标」）

> 前 57 轮把机器人做成了一个"会自证"的系统：承诺前要证据、证据要校准、要跨模态对账、要人机信任有界。但所有这些自证都指向一个隐含裁判——真实世界。UniBot 世界挑战赛把这个裁判换成一个**公开但不可见的评测函数**：任务分布只给描述不给采样、指标是聚合的、排行榜只返回一个名次或一个标量。于是出现前 57 轮没有正面处理的问题：机器人不仅要"做对"，还要能"说对它将被如何打分"。评测指标既是目标也是信息通道：把它当唯一目标会触发 Goodhart，把它当完全不可知又无法自我改进。本轮把第 57 轮"证据说可信"再抬一层，提出 **"评测说可信"**：机器人持有一份可校准、可被漂移检测、可抗博弈的**评测契约**，并据此决定"做哪些任务、提交哪些结果、选哪个候选策略"。支点为评测契约（EC）、自评校准（SEC）、抗 Goodhart 鲁棒选择（GRS），护栏为评测漂移检测（ESD）、对抗性指标审计（AMA），交付物为竞赛证据证书（CEC）。第 57 轮的 J_p 证书由此升级为"**能证明分数的分数**"。

核心矛盾：
- **H29（目标 vs 代理 / Goodhart）**：排行榜指标只是能力的聚合代理；任何对固定指标的直接优化都会降低它与真实能力的相关性。优化越强，名次越不可信；公开榜/私有榜的反复提交更把这种过拟合加速成"对评测函数的对抗搜索"。
- **H30（自评 vs 隐藏测试）**：自评校准只在可交换的自评分布上有效；挑战赛的隐藏测试恰恰是为分布外设计的，校准区间可能在最需要覆盖的时候最窄——"越陌生的任务越自信"。
- **H31（单一名次 vs 多目标）**：排行榜把成功率、安全、时间、人工干预压成一个数，掩盖 Pareto 权衡；一个成功率略高但安全违规更多的策略可能排前，而名次无法反推原因，导致错误的学习信号。

## 0. 直觉与动机

**灵感 1（UniBot 世界挑战赛 → 一份多方签署的评测契约）**
直觉：世界挑战赛不是一次闭卷考试，而是一份**契约**：主办方定义任务分布、指标、预算与披露规则；参赛方提交策略与逐回合结果；排行榜是契约的裁决。既然前 57 轮已经让机器人对每一次接触写出证据证书，为什么不把它提升一层，对**每一次提交**写一份"评测证据证书"？让"我得了多少分"本身成为可复核的命题，而不是一个只能相信的数字。多数队伍优化分数，我们同时优化"分数声称的可验证性"——这在需要复现与申诉的世界赛里是差异化优势，也让安全壳从"防止撞坏"扩展到"防止虚报"。

**灵感 2（评测指标 → 可分解的聚合代理，而不是神谕）**
直觉：指标不是黑箱，而是一棵可分解的树：总分 A(·) 聚合子指标 m_i，子指标又由可观测事件估计。把指标拆成"我能观测、能影响、能核验"的部分与"隐藏的混淆部分"，只对前者做优化，对后者做保守界。于是优化发生在可解释的子空间里，而不是对名次的盲目爬坡。提出**指标分解树（MDT）**与**可核验子指标集**：凡是不能被我观测或核验的子指标，一律以最坏值进入选择。

**灵感 3（自评校准 → 带共形保底的分数承诺）**
直觉：机器人应能在提交前说："这类任务我的主指标落在 [L,U] 内，覆盖 1−α；下界低于门槛的任务我不提交。" 用 Mondrian 共形预测按任务类分层，输出多指标联合区间；用早期回合信号在线更新。自评不是自我表扬，而是一份**可证伪的分数承诺**：说窄了会被覆盖回归打脸，说宽了会因过度弃权丢名次，两端都有代价，才有诚实的激励。

**灵感 4（抗 Goodhart → 鲁棒选择 + 差分测试）**
直觉：候选策略不止一个（不同 checkpoint、不同训练配方、不同 sim2real 设置）。选择准则不是"自评均值最高"，而是"在隐藏分布偏移下的**主指标下置信界**最高，且安全/干预等次指标的上置信界不越界"。再加**指标利用检测**：对无关变换（任务顺序、场景重命名、随机种子、传感器噪声）做差分测试——真正的能力应当不变，分数却变了，说明它在薅指标而不是在长本事。这也直接对冲公开榜/私有榜的过拟合。

**灵感 5（对抗性指标审计 + 竞赛证据证书 → 把评测本身当成被保护的对象）**
直觉：主动红队自己的指标：搜索"高分但违背任务意图"的轨迹，量化 gaming gap，再给指标打补丁（加约束、取已知攻击集上的最坏值）。最终交付 CEC：环境哈希、种子、逐回合日志、自评区间、校准集摘要、利用审计报告、复现脚本。名次会骗人，可复现的证书不会。更进一步，把"评测协议设计"本身当成参赛的创新贡献：一个抗 Goodhart 的指标，会让真正有能力的队伍而不是最会钻空子的队伍赢。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（评测契约 EC）** 评测契约 E=(𝒯,Φ,A,B,𝒟_hidden,𝒟_self,R_disc)。𝒯 为任务分布（公开描述但采样隐藏），Φ 为任务语义规约（intended capability，含成功/安全/干预约束），A:(R^p)^n→R 为排行榜聚合（可含截断、归一化、超时惩罚），B 为预算（时间/能量/接触次数），𝒟_hidden 为隐藏测试分布，𝒟_self 为自评分布，R_disc 为披露规则。官方分数 S(π)=E_{τ~𝒟_hidden}[A(m(τ,π))]。契约要求任何分数声称附带可复核 CEC，否则不可申诉。鲁棒分数 S_rob(π)=inf_{Q∈𝒬(𝒟_self,ε)} E_Q[A(m(·,π))]，𝒬 为以 𝒟_self 为中心的 Wasserstein/χ² 模糊集。

**定义 140（自评校准 SEC / 自评分证书）** 按任务类 c（任务族×本体×场景类型）分层，校准集 𝒞_c={(τ_i,y_i)}，y_i 为官方指标在自评留出集上的代理值；非一致性分数 s_i=‖ŷ_i−y_i‖/scale_c。Mondrian 共形区间 C_c(τ)={y:‖ŷ(τ)−y‖≤q_{1−α_c}(s_c)}，在类内可交换性下 P(y∈C_c)≥1−α_c。多指标用 Bonferroni（α_c=α/p）或多元共形。证书附带 (n_c, α_c, 交换性检验 p 值, 覆盖回归斜率, 区间宽度)。SEC 直接作为提交门：可提交 ⇔ C.lower ≥ θ_submit ∧ 安全 UCB ≤ B_safe。

**定义 141（评测漂移检测 ESD）** 统计量二选一或并联：(a) 密度比 ŵ(τ)=p̂_hidden(τ)/p̂_self(τ)，由域分类器（分类两样本检验）估计；(b) 残差漂移 H_t=max(0,H_{t−1}+e_t−ν)，e_t=y_t^obs−ŷ_t（Page-Hinkley/CUSUM）。触发条件 ŵ>θ_w 或 H_t>θ_H ⇒ 进入 SHIFT 态：区间有界膨胀 C←C⊕λ·H（保形在偏移下的显式膨胀界），提交阈值上调 θ_submit(shift)，候选策略切换为 S_rob。在声明偏移幅度内，漏检概率 ≤δ_esd。

**定义 142（抗 Goodhart 鲁棒选择 GRS）** 候选集 Π={π_1..π_K}。对每个 π 估计主指标下界 LCB_{1−α}(S_primary(π)) 与次指标上界 UCB_{1−β_j}(S_j(π))。选择 π*=argmax_π LCB s.t. UCB_j≤B_j ∀j。排名感知版本：用任务 bootstrap 估计 P(rank(π)≤r)，取 argmax_π min{r:P(rank≤r)≥1−γ}（最靠前的高置信名次），避免为偶然高分赌上稳定性。差分测试：对无关变换 g∈G（任务置换、场景重命名、随机种子、传感器噪声）要求 |S(π)−S(g·π)|≤η；否则标记 exploit 并降权。

**定义 143（对抗性指标审计 AMA）** gaming gap G(Φ)=max_{π}[S(π)−S_intended(π)]，其中 S_intended 按 Φ 评估语义正确性。红队搜索产生攻击集 E={e_1..e_M}（进化搜索/RL/规则 fuzz）。补丁指标 S_patch(π)=min_{e∈E}[S_e(π)] 或加约束惩罚；输出攻击面报告 AS=(利用类别, 触发条件, 分数影响, 修复建议)。AMA 既用于自审，也作为对主办方的公开贡献——评测协议本身可以成为一个创新点。

**定义 144（竞赛证据证书 CEC）** CEC=(env_hash, seeds, episode_logs, metric_estimates, SEC 区间, calibration_summary, exploit_audit, repro_manifest, J_p 引用)。验证函数 Verify(CEC,S_claim)∈{valid, invalid(reason)}：按种子重放得到一致指标（容差 ε_rep）、区间覆盖回归通过、无未披露 exploit。规则：无 CEC 的分数不被采信；任何名次申诉必须附 CEC。

## 2. 关键算法伪代码（完整版见产物区）

```python
def metric_aware_submit(policy, task, E, sec, esd):
    c = task_class(task)                              # 任务族×本体×场景
    yhat, C = sec.predict(policy, task, c)            # Mondrian 共形区间
    w, H = esd.update(task, yhat)                     # 密度比 + 残差漂移
    if w > E.theta_w or H > E.theta_H:                # 进入 SHIFT 态
        C = inflate(C, lam=H)                         # 有界膨胀
        theta, policy = E.theta_submit_shift, select_robust(E.candidates, E, sec)
    else:
        theta = E.theta_submit
    if C.lower < theta or sec.safety_ucb(policy, task) > E.B_safe:
        return ('abstain', C, 'below_threshold')      # 宁可弃权不虚报
    return ('submit', C, 'ok')

def sec_update(sec, yhat, y, c):
    sec.residuals[c].append(abs(yhat - y)); sec.n[c] += 1
    sec.q[c] = conformal_quantile(sec.residuals[c], sec.alpha[c])
    return sec

def select_robust(candidates, E, sec):
    best = None
    for pi in candidates:
        lcb = conformal_lcb(sec, pi, 'primary')
        if any(conformal_ucb(sec, pi, j) > E.B[j] for j in E.secondary):
            continue                                  # 次指标越界即淘汰
        r = rank_lcb_bootstrap(sec, pi, E, gamma=E.gamma)
        if best is None or (lcb, r) > (best.lcb, best.r):
            best = Candidate(pi, lcb, r)
    return best.pi

def differential_test(policy, E, G):
    for g in G:                                       # 无关变换不应改分
        if abs(E.score(policy) - E.score(g(policy))) > E.eta:
            return 'exploit_suspect'
    return 'ok'

def metric_audit(candidates, Phi, E):
    exploits = red_team_search(candidates, Phi, budget=E.audit_budget)
    gap = max(E.score(p) - E.score_intended(p) for p in exploits)
    AS = [(classify(p), trigger(p), impact(p), fix(p)) for p in exploits]
    return gap, AS, lambda p: min(E.score(e) for e in exploits)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| EC | O(1) 解析 | O(\|E\|) | 契约字段完整、披露合规 |
| SEC | 查询 O(1)；重拟合 O(Σn_c log n_c) | O(Σn_c) | 类条件覆盖、交换性检验 |
| ESD | O(1)/步 + O(N) 域分类器 | O(window) | 漏检 ≤δ_esd、膨胀有界 |
| GRS | O(K·(n_boot+B)) | O(K) | 下界有效、约束概率 ≥1−β |
| AMA | O(audit_budget) | O(\|E\|) | gaming gap 估计诚实、补丁可复算 |
| CEC | O(\|episodes\|) | O(\|episodes\|) | 重放一致、不可否认 |

**正确性定理（Metric-Aware Prediction Soundness, MAPS 概要）**：在 A41–A43 下——(A41) 类内可交换或偏移被 ESD 以 ≥1−δ_esd 检出；(A42) 自评校准集对声明任务类有代表性；(A43) AMA 已覆盖声明的攻击面、CEC 重放容差 ε_rep 诚实。则：(i) 自评覆盖：类条件 P(S∈C)≥1−α；未检出偏移下覆盖损失 ≤Δ(λ,H)；(ii) 不虚报：P(S_claim>S_true+ε)≤α+δ_esd+δ_audit；(iii) 鲁棒选择：真实主指标 S(π*)≥LCB 的概率 ≥1−α−δ_sel，且安全约束成立概率 ≥1−β−δ_sel；(iv) 提交诚实：CEC valid ⇒ 声称分数可复现到 ε_rep，invalid ⇒ 拒收。部署界：P(诚实且安全提交)≥1−Σ_ep(α+δ_esd+δ_sel+δ_audit+δ_repro)。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| Goodhart 上移：自评器被优化成又窄又自信 | 高 | 独立留出校准集、禁止用隐藏反馈调 SEC、覆盖回归审计、漂移检测 |
| 隐藏测试偏移幅度超出声明 | 高 | ESD + 有界膨胀 + 保守弃权；要求主办方披露偏移上界 |
| 指标补丁被反向利用（构造"看起来难"的任务） | 中 | AMA 持续红队、S_patch 取最坏、保留 held-out exploit 集 |
| 过度弃权导致名次低 | 中 | 弃权带成本模型，按期望名次而非单一硬下界决策 |
| CEC 泄露配方/被抄袭 | 中低 | 哈希承诺 + 延迟披露 + 区间零知识证明 |

## 6. 本轮最大风险

**一句话**：把评测指标内化为可优化目标，会把 Goodhart 从排行榜搬进机器人自己的自评器——SEC 可能被训练得又窄又自信，ESD 的阈值也可能在"提高名次"的压力下被悄悄放松，于是系统恰好在隐藏测试分布上最自信、也最失真；必须以独立留出校准、不可用隐藏反馈调参的 SEC、有界膨胀的漂移回退和 CEC 重放校验四道锁，保证"分数越低越敢说，而不是名次越近越敢说"。

```python
def parse_contract(spec):
    E = EvalContract(
        tasks     = spec.task_distribution,        # 任务族 + 采样规则描述
        phi       = spec.intended_capability,      # 成功/安全/干预的语义规约

        disc      = spec.disclosure_rules)
    E.mdt = metric_decomposition_tree(E.aggregate)  # 拆到可观测叶子
    E.observable = [leaf for leaf in E.mdt.leaves if leaf.observable]
    E.opaque     = [leaf for leaf in E.mdt.leaves if not leaf.observable]
    return E

def robust_score(pi, E, Q):
    obs = E.score_observable(pi)                   # 只对可观测子指标优化
    worst = worst_in_ambiguity_set(E.opaque, Q)    # 不可观测者取最坏
    return E.aggregate(obs, worst)
```

### IP-140 SEC（Mondrian 共形自评校准）

```python
def sec_fit(calib, E, alpha):
    sec = {}
    for c, rows in group_by(calib, key=task_class):
        sec[c] = {'res': [abs(predict(r.task) - r.y) / scale(c) for r in rows],
                  'alpha': alpha / len(E.metrics),     # Bonferroni 多指标
                  'n': len(rows)}
    return sec

def sec_predict(sec, pi, task, c):
    if c not in sec:                               # 无校准的类：拒绝自评
        return None, Interval(-inf, +inf)
    q = conformal_quantile(sec[c]['res'], sec[c]['alpha'])
    yhat = predict(pi, task)
    return yhat, Interval(yhat - q * scale(c), yhat + q * scale(c))

def sec_audit(sec, heldout):
    return {c: coverage(sec[c], heldout[c]) for c in sec}  # 覆盖回归
```

### IP-141 ESD（评测漂移双检测）

```python
def esd_update(esd, task, yhat):
    esd.w = domain_ratio(esd.classifier, task)     # 分类两样本检验
    e = esd.last_obs - yhat
    esd.H = max(0.0, esd.H + e - esd.nu)           # Page-Hinkley
    esd.shift = (esd.w > esd.theta_w) or (esd.H > esd.theta_H)
    return esd.w, esd.H

def esd_inflate(C, H, lam):
    return Interval(C.lo - lam * abs(H), C.hi + lam * abs(H))  # 有界膨胀
```

### IP-142 GRS（抗 Goodhart 鲁棒选择）

```python
def goodhart_robust_select(candidates, E, sec, G):
    feasible = []
    for pi in candidates:
        if differential_test(pi, E, G) != 'ok':
            continue                               # 差分测试不通过直接淘汰
        lcb = conformal_lcb(sec, pi, 'primary')
        if any(conformal_ucb(sec, pi, j) > E.B[j] for j in E.secondary):
            continue                               # 安全/干预越界淘汰
        r = rank_lcb_bootstrap(sec, pi, E, gamma=E.gamma)
        feasible.append(Candidate(pi, lcb, r))
    return max(feasible, key=lambda x: (x.lcb, x.r)).pi if feasible else None

def rank_lcb_bootstrap(sec, pi, E, gamma, n=1000):
    ranks = []
    for _ in range(n):
        sample = resample_tasks(sec, pi)
        ranks.append(rank_of(pi, sample, E))
    return quantile(ranks, gamma)
```

### IP-143 AMA（对抗性指标审计）

```python
def adversarial_metric_audit(candidates, Phi, E, budget):
    attacks = []
    while budget.left:
        p = red_team_step(candidates, Phi, E)      # 进化/RL/规则 fuzz
        if E.score_intended(p) < E.score(p) - E.gap_eps:
            attacks.append(p)
        budget.spend()
    gap = max(E.score(p) - E.score_intended(p) for p in attacks)
    AS  = [(classify(p), trigger(p), impact(p), patch_suggestion(p)) for p in attacks]
    S_patch = lambda pi: min(E.score(p) for p in attacks)  # 已知攻击集上的最坏值
    return gap, AS, S_patch
```

### IP-144 CEC（竞赛证据证书）

```python
def build_cec(pi, E, sec, esd, audit, run):
    return CEC(
        env_hash          = hash_env(run.env),
        seeds             = run.seeds,
        episode_logs      = run.logs,
        metric_estimates  = run.metrics,

        exploit_audit     = audit.AS,

        jp_ref            = run.jp)

def verify_cec(cec, claim, E, eps_rep):
    replay = reproduce(cec.repro_manifest, cec.seeds)
    if max_abs_diff(replay.metrics, cec.metric_estimates) > eps_rep:
        return ('invalid', 'replay_mismatch')
    if not coverage_ok(cec.sec_intervals, cec.metric_estimates):
        return ('invalid', 'coverage_regression')
    if claim.score > quantile_upper(cec.metric_estimates) + eps_rep:
        return ('invalid', 'overclaim')
    return ('valid', cec)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| EC | O(1) 解析；MDT O(\|tree\|) | O(\|E\|+\|tree\|) | 契约字段完整、可观测/不可观测叶子划分诚实 |
| SEC | 查询 O(1)；拟合 O(Σn_c log n_c) | O(Σn_c) | Mondrian 类条件覆盖 ≥1−α（A41） |
| ESD | O(1)/步 + O(N) 训练 | O(window) | 漏检 ≤δ_esd、膨胀有界（A41） |
| GRS | O(K·(n_boot+B)) | O(K) | 主指标 LCB 有效、次指标约束概率 ≥1−β（A42） |
| AMA | O(audit_budget) | O(\|E\|) | gaming gap 估计诚实、S_patch 可复算（A43） |
| CEC | O(\|episodes\|·T_replay) | O(\|episodes\|) | 重放一致、不可否认（A43） |

**正确性定理（MAPS, Metric-Aware Prediction Soundness）**
假设 A22–A32（第 53–55 轮）、A33–A36（第 56 轮）、A37–A40（第 57 轮）成立；新增：
**(A41)** 类内可交换或偏移被 ESD 以概率 ≥1−δ_esd 检出，且膨胀系数 λ 有限；
**(A42)** 自评校准集对声明任务类有代表性；GRS 的下界与约束估计用同一留出协议，选择过程不偷看隐藏反馈；
**(A43)** AMA 覆盖声明的攻击面，CEC 重放容差 ε_rep 诚实，且隐藏反馈不用于调 SEC。
则：
1. **自评覆盖**：类条件 P(S∈C_c)≥1−α；未检出偏移下覆盖损失 ≤Δ(λ,H)，可随 H 有界。
2. **不虚报**：P(S_claim > S_true + ε) ≤ α + δ_esd + δ_audit。
3. **鲁棒选择**：真实主指标 S(π*) ≥ LCB 的概率 ≥1−α−δ_sel；安全/干预约束成立概率 ≥1−β−δ_sel。
4. **提交诚实**：Verify(CEC,S_claim)=valid ⇒ 声称分数可复现到 ε_rep；invalid ⇒ 拒收（无 CEC 不采信）。
5. **部署界**（对提交回合取联合界）：

```
P(诚实且安全提交) ≥ 1 − Σ_ep (α + δ_esd + δ_sel + δ_audit + δ_repro + δ_f + δ_probe)
```

关键：**指标给方向、共形给下限、漂移检测给回退、审计给补丁**——四者把"优化分数"这个 inherently Goodhart 的动作，约束成"在可核验子空间里提高一个下置信界"。第 57 轮"一切判定器走隔离"在本轮推广为"**一切分数声称走证书**"。

## 6. 本轮最大风险

**一句话**：把评测指标内化为可优化目标，会把 Goodhart 从外部排行榜搬进机器人自己的自评器——SEC 可能被训练得又窄又自信、ESD 阈值可能在"冲名次"的压力下被悄悄放松，系统于是恰好在隐藏测试分布上最自信也最失真；必须以独立留出校准、隐藏反馈不得回流 SEC、有界膨胀的漂移回退、CEC 重放校验四道锁，确保"分数越低越敢说，而不是名次越近越敢说"。
