# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「ROS2」×「上下文理解」）

> R69 给闭环装上了「嘴」：看不清就凑近看，拿不准就问，摸不透就触；并把不确定性拆成 aleatoric 与 epistemic，用 VoI 决定值不值得求证。但 R69 有一个从未被审视的默认前提——**参与对话的各方共享同一个上下文**。它问「左边能走吗」，前提是「左边」在问者与答者心里是同一个左边；它把证书 J_FLUID 签给一个动作，前提是这张证书知道自己是在哪个任务阶段、哪类环境、对谁、依据哪份证据签的。真实部署里，这个前提恰恰最先碎掉。
>
> 当闭环落成 ROS2 系统——感知、定位、规划、安全监控、人机接口是各自独立、各自带 QoS、各自有时钟与生命周期的节点——没有哪个节点拥有全局上下文：感知节点只知道「画面里有人」，规划节点只知道「任务处于交接阶段」，人机接口只知道「用户刚说了左」，安全监控只看到一串带时间戳的 topic。它们各自局部正确，拼起来却可能指向一个谁都没看见的世界。
>
> 本轮两个灵感正好补上两块缺口：
> - **ROS2** 提供的不只是通信总线，而是一套**可检验的证据契约**：reliability / durability / deadline / lifespan / liveliness 其实都在承诺「这条证据有多新、多完整、在发布者掉线或晚加入时还算不算数」。QoS 是伪装成中间件参数的认知契约。
> - **上下文理解** 提供的不是更大的观测向量，而是**一组让模型与证书得以成立的假设**：任务阶段、人的意图与角色、环境类别、历史与因果版本。理解上下文，就是知道哪些假设成立、哪些只是被默认、以及自己何时不知道。
>
> 核心命题：**任何安全断言都必须携带它的上下文假设；上下文在 ROS2 上是分布式、部分可观、可能被伪造的，因此假设必须能接地、能证伪、能组合、能审计；只有当假设被认证时才允许「上下文奖励」（清零上下文债务），否则一律退到最坏情形上下文——把 R68/R69 作为单上下文边界严格包含。** 命名 **FABRIC-RAS**（Federated Assumption-Based Runtime Inter-node Certification：联邦假设-保证的运行时节点间认证）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我们说的是同一个世界吗，我的结论在谁的上下文里成立**」。

## 0. 直觉与动机

**灵感 1（上下文是假设，不是特征）**
直觉：把上下文做成一个更大的输入向量喂给策略，只会得到又一个黑箱。真正让「上下文化」有用的是：一条控制律、一张安全证书、一个风险阈值，本质上都是一个**带前提的命题**——「在人远离、地面干燥、任务处于搬运阶段的上下文里，以 1.2 m/s 通过是安全的」。丢掉前提，证书就从定理退化成了口号；而把前提写死，证书又会在环境变化时悄悄过度声明。
形式化：把上下文看成假设空间 𝒦 上的一个区域 A；证书只在 A 上成立。R68/R69 的证书其实是 `A = 𝒦`（无前提）这一最弱、也最容易过度声明的特例。本轮把证书改成作用域化的 `(A, G)`，并把「运行时是否真的落在 A 里」变成一个可监控、可组合、可审计的问题。

**灵感 2（ROS2 QoS 是认知契约）**
直觉：`reliable` + `transient_local` + `deadline=50ms` 不是性能选项，而是一句承诺：「这条上下文证据可靠送达、晚加入者也能拿到、且每 50ms 内更新」。如果一条证据是以 `best_effort` 送来的、已经超过 lifespan、或发布者的 liveliness 刚丢，它就不该和一条满足契约的证据等价——哪怕数值看起来一样。事故复盘里最常见的「topic 里明明有人」正是这一类：数值是对的，证据资格是失效的。
形式化：把 QoS 策略 q 映射到信任等级 τ(q) 与有效期 L(q)；证据 e 只有在 `τ(q_e) ≥ τ_req(A)` 且 `age(e) ≤ L(q_e)` 且无违约时才可用于放电假设 A。τ 对 QoS 强度单调：削弱传输只能降低、不能提高被信任的置信度（引理 19）。这让中间件层第一次成为安全证书的正式输入，而不是脚注。

**灵感 3（分布式上下文没有全局真值，只有发散度）**
直觉：单机上「当前上下文」是一个变量；ROS2 上它是**多个节点的多个版本**。网络延迟、时钟偏斜、节点重启、DDS 发现抖动，都会让两个节点对同一假设给出不同答案。这不是偶发 bug，而是分布式系统的常态。危险的不是分歧本身，而是**分歧不可见**：规划节点以为人已离开，安全节点以为人还在，两边各自都通过了自己的检查，系统却在两种世界模型之间撕裂。
形式化：每个节点维护上下文版本向量 v_i；对共享假设变量定义发散度 `d_ij = Σ_x w_x·1[val_i(x)≠val_j(x)] + β·skew_ij`，系统发散 `D = max_ij d_ij`。`D > τ_div` 判为上下文脑裂，立即撤销上下文奖励并退到最坏情形。注意：发散度只在**被假设词表覆盖的变量**上可测——这既是它的能力，也是它的盲区（第 6 节）。

**灵感 4（假设-保证组合：局部正确必须能拼成全局正确）**
直觉：每个 ROS2 节点都可以局部地「正确」：感知保证「如果我看到的人框可信，则人在 3m 外」，规划保证「如果人在 3m 外，则轨迹安全」，安全监控保证「如果轨迹安全，则不越包络」。但这些保证要串起来，必须逐条对齐：后一个节点的假设要恰好被前一个节点的保证所蕴含。少对齐一条，系统就得到一个**每步都合理、整体却错误**的证明。
形式化：节点 i 的契约 `C_i=(A_i,G_i)`；组合 `C_i ⊗ C_j` 仅在 `G_i ⇒ A_j` 且 `G_j ⇒ A_i` 时定义，组合后 `A=A_i∧A_j, G=G_i∧G_j`。在无环放电序（A107）下，逐边放电给出全局安全（定理 19）。这使 R69 的「单节点证书」升级为「可组合的系统级证书」，也让「谁该为哪条假设负责」第一次写进证书。

**灵感 5（上下文既是新能力，也是新攻击面）**
直觉：R69 说「会问」会带来投毒；R70 的「会理解上下文」带来一个更根本的攻击面：**谁控制上下文，谁就控制证书**。只要伪造一条「现场无人」的上下文，或重放一段旧的「任务未开始」rosbag，或把支撑假设的 topic QoS 悄悄从 reliable 降成 best_effort，就能让一个本来不安全、或至少不该被认证的动作**通过认证**。R69 的风险是「问错人」，R70 的风险是「看错世界，而且所有节点一起看错」。
形式化：新增干扰集 ℰ_ctx = {伪造/注入上下文 topic，重放或陈旧上下文，QoS 降级/伪装，假设洗白（assumption laundering），时钟偏斜诱导假一致，跨节点共谋，上下文词表走私（注入一个使假设放松的未声明变量）}；`ℰ_FABRIC = ℰ_FLUID × ℰ_ctx`。缓解不是「再加一个模型」，而是：假设最小化、来源正交、证伪见证、组合放电，以及把「上下文一致」与「上下文正确」明确分开。

**灵感 6（严格包含：新层必须是旧层的边界）**
直觉：如果上下文是单点、完全可观、QoS 完美、无发散，那么 FABRIC 必须逐指令退化成 FLUID-RAS；如果上下文不可认证，它必须至少和 R68 一样保守。否则每加一层，就多一个需要独立信任的模型——而安全系统最付不起的就是「信任层数」。
形式化：定义上下文债务 `U_ctx`：认证通过时为 0，否则为上下文后验熵与最坏情形风险跨度的上界。统一退避 `λ = λ_floor(U_ale + 未消解 U_epi + U_ctx)`。于是 R68 是 `U_ctx>0` 且不交互的边界，R69 是 `U_ctx=0` 的边界（定理 18）。安全侧永不让步，效率只在被认证的上下文区域里赚取。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（FABRIC-RAS 总览与四不变式）** `FABRIC-RAS = (CAG, QTM, AGC, CDM, CGL, AFW, CSC, RAS-WM†)`。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；上下文学习只在离线/影子模式）；
(ii) **假设局部性**：任何证书必须显式携带假设集 A 与上下文身份 h(κ)，禁止无假设证书；
(iii) **组合可靠性**：系统级证书仅在放电成立、覆盖度达标、发散度低于阈值且 TTL 有效时签发；
(iv) **上下文保守性**：只有被认证的上下文才能清零 U_ctx；未认证、被投毒或超时一律按最坏情形上下文退避。

**定义 311（上下文对象、上下文图与身份）** 上下文对象 `κ=(E,R,φ,ι,ρ,ω,[t0,t1],π,c)`：实体 E、关系 R、任务阶段 φ、意图假设 ι、社会角色 ρ、环境类别 ω、时间窗、来源映射 π、置信 c。上下文图 `G_κ=(V,E)` 为带类型、带时间戳、带来源的有向图。上下文身份 `h(κ)=H(canonical(κ)‖v)`，其中 v 为因果版本向量（定义 324），H 为抗碰撞哈希。上下文区域 `K⊆𝒦` 是满足某组约束的 κ 集合。

**定义 312（上下文假设与强度格）** 假设 A 是 𝒦 上的谓词，含语义子句 A_sem（阶段/意图/角色/环境）与传输子句 A_qos（reliability/durability/deadline/lifespan/liveliness 下界）。定义强度序 `A⊑B ⇔ (A⇒B)`（A 不弱于 B）。证书所需假设记为 `A_req(ξ)`，节点实际提供的记为 `A_prov(ξ)`；仅当 `A_prov⊑A_req` 才可放电。用更弱假设冒充更强假设（`A_req⇏A_prov` 却声明满足）称**假设洗白**，可由假设哈希与来源链检出（定义 325）。

**定义 313（QoS 信任映射 QTM 与证据有效性）** 映射 `τ: QoS→{0,1,2,3}` 与有效期 `L: QoS→ℝ_{≥0}`。证据 `e=(topic, payload, t, q_e, publisher, seq)`。有效性 `valid(e,A)=1[τ(q_e)≥τ_req(A)]·1[age(e)≤L(q_e)]·1[¬violation(e)]`，其中 violation 含错过 deadline、liveliness 丢失、durability 不满足晚加入需求、序列断裂。τ 与 L 对 QoS 强度单调不增：`q'⪯q ⇒ τ(q')≤τ(q), L(q')≤L(q)`。

**定义 314（上下文条件风险与可信集）** 风险 `r(s,a|κ)`；上下文信念 `b(κ|E)`（E 为可用证据）。可信集 `𝒫_b={p: p 与证据 E 及已知硬约束一致}`。最坏情形风险 `R_wc(s,a;𝒫_b)=sup_{p∈𝒫_b} E_p[r(s,a|κ)]`。认证上下文区域 K_cert 时用 `R_wc(s,a;K_cert)`；否则用 𝒫_b 全支撑。安全判据始终是 `R_wc ≤ ε`，而非某个点估计下的 r。

**定义 315（假设-保证契约 AGC）** 节点 i 的契约 `C_i=(A_i,G_i)`，A_i 为上下文 + QoS 假设，G_i 为保证（安全包络、λ 上界、证书谓词、动作模态约束）。运行时满足 `C_i@κ ⇔ (κ⊨A_i ⇒ 系统_i 在 κ 下满足 G_i)`。契约签名绑定 `h(A_i)` 与组件版本，防止事后替换假设。

**定义 316（契约组合与放电）** 拓扑 `𝒢=(𝒩,ℰ)`。对边 (i,j)，若 `G_i ⇒ A_j` 则称 i 向 j 放电；双向放电时 `C_i⊗C_j` 有定义，`A=A_i∧A_j, G=G_i∧G_j`。**无环放电序**指存在拓扑序 π 使所有放电沿 π 正向；有环时只允许引入显式全局监督契约 C_0（其假设为空、保证为系统安全包络），否则拒绝签发系统证书。组合证书 `J_comp=(𝒢,{h(A_i),h(G_i)},放电见证,topo_order)`。

**定义 317（上下文发散与脑裂 CDM）** 节点 i 对假设变量 x 的取值/置信为 `(val_i(x), c_i(x))`，共享变量集 `S_ij=vars(A_i)∩vars(A_j)`。`d_ij=Σ_{x∈S_ij} w_x·m_x + β·skew_ij`，其中 m_x 为取值不一致（或置信区间不相交）指示，w_x 由契约敏感度给出，skew_ij 为版本向量的因果偏斜。系统发散 `D=max_ij d_ij`（或加权 max）。`D>τ_div` ⇒ 脑裂告警，撤销上下文奖励、进入最坏情形上下文。未列入任何 A 的变量不参与 D——称**上下文词表盲区**（第 6 节）。

**定义 318（假设驱动接地与覆盖度 CGL）** 活跃假设集 `A_active=⋃_i A_i`。对每个假设变量 x，选最小证据集 `E_x⊆Topics`（可跨节点）使后验满足 `P(x|E_x)≥τ_g` 且来源链完整；接地成本 `c_gr(x)=|E_x|·c_e`。覆盖度 `cov(A)=Σ_{x∈A_active} w_x·1[grounded(x)] / Σ w_x`。只接地被活跃契约引用的变量（假设驱动），不建全量世界模型。未接地变量保持未知，进入 U_ctx。

**定义 319（假设证伪见证 AFW）** 对高影响假设 `w_x>w_0`，在执行上下文奖励前必须有一次证伪尝试：用 R69 的信息动作选 `g_x^*=argmax_g IG(x;y|g)`（优先正交于现有证据的来源），观测 y，计算似然比 `Λ_x=p(y|x)/p(y|¬x)`。见证 `W_x=(g_x^*,y,Λ_x,t,source_orthogonality)`。假设「存活」当 `Λ_x≤τ_Λ`。独立证伪 k 次后假假设赔率 `≤ 先验赔率·∏Λ_x`（引理 22）；仅同意而无证伪不构成见证。不可被任何允许动作区分的变量记为**不可证伪**，直接进 U_ctx。

**定义 320（上下文作用域证书 J_FABRIC）** `J_FABRIC=(node_ids,{J_FLUID^i},{h(κ_i)},{h(A_i),h(G_i)},qos_summary,cov(A),{h(W_x)},D,h(J_comp),ttl,fabric_ver)`。`Valid ⇔ ∀i Valid(J_FLUID^i) ∧ J_comp 放电校验通过 ∧ cov(A)≥τ_cov ∧ D≤τ_div ∧ 无 ℰ_ctx 标记 ∧ now≤ttl`。证书只在 `A=∧_i A_i` 与 TTL 内有效；离开区域或过期即自动失效，不存在跨上下文复用。

**定义 321（上下文债务与统一退避）** `U_ctx=0` 若 J_FABRIC Valid；否则 `U_ctx=H(κ|E)+osc(𝒫_b)`，其中 osc 为可信集上风险跨度的上界。统一有效不确定性 `U_eff=U_ale+U_unresolved_epi+U_ctx`。风险缩放 `λ=max(λ_task, λ_floor(U_eff))`；若 `U_ctx>0` 还须 `k≤k_wc(K_plausible)`（按最坏上下文缩短认证前缀）。⇒ R69 是 `U_ctx=0` 的边界；R68 是 `U_ctx>0` 且不交互的边界。**上下文奖励仅指 U_ctx 被认证清零，绝不表示安全阈值本身被放宽。**

**定义 322（上下文投毒干扰集 ℰ_ctx）** `ℰ_ctx = {伪造/注入上下文 topic，rosbag 重放或陈旧上下文，QoS 降级/伪装，假设洗白，时钟偏斜诱导假一致，跨节点共谋，上下文词表走私（context smuggling：注入一个使假设放松的未声明变量）}`。`ℰ_FABRIC=ℰ_FLUID×ℰ_ctx`。对抗训练与审计必须覆盖「合法数值 + 非法来源」这一类，而不能只测数值异常。

**定义 323（上下文切换与无突变再认证 CST）** 上下文切换 κ→κ' 仅在**安全切换集** `S_sw={s: v(s)≤v_sw, f(s)≤f_sw}` 内提交；提交前必须完成 κ' 的 J_FABRIC 再认证。若不满足，保持旧上下文并单调提高 λ、缩短 k，直到可在安全集内切换。切换本身不改变任务动作的连续性约束（继承 R69 定理 17）。

**定义 324（因果上下文版本与时钟纪律）** 版本向量 `v_i[x]` 记录节点 i 已知的变量 x 的来源更新；上下文身份包含 v。物理时钟只用于 age/TTL 与 lifespan，不用于因果排序；跨节点比较只认可因果可判定关系，不可比即视为潜在发散。禁止用「墙钟相等」推断上下文一致。

**定义 325（分布式参与式审计 VQAuditor-X）** 审计对象：假设由谁提出、由哪条证据接地、由哪个信息动作证伪、被哪张证书依赖、在组合中向谁放电；检查假设洗白链、QoS 降级、重放、共谋与词表盲区。结论写入跨节点 AuditBuf，作为下一轮接地/证伪预算的先验；**词表盲区只能由外部红队或离线审计补充**（承认内部不可自证）。

## 2. 关键算法骨架

```python
# IP-264 CAG：上下文对象/图与身份（增量更新，不重建）
class ContextGraph:
    def update(self, topics, t):                      # 增量：只处理 Δ
        for e in topics:                              # e=(topic,payload,ts,qos,node)
            if not qtm.valid(e, A_active_hint(e)):    # QoS 认知门
                self.mark_stale(e); continue
            self.apply_delta(e, t)                    # 实体/关系/阶段/角色
        self.prune(ttl=self.ttl)
        return self.hash()                            # h(κ)，含版本向量

# IP-265 QTM：QoS → 信任等级与有效期
def qos_trust(q):  return TAU[q.reliability, q.durability]   # 单调表
def evidence_ok(e, A):
    return (qos_trust(e.qos) >= tau_req(A) and
            age(e) <= lifespan(e.qos) and not e.violation)

# IP-266 AGC：契约监控与放电
def check_contract(C_i, kappa):
    return implies(kappa, C_i.A)                       # κ 是否落在 A_i
def discharge(C_i, C_j):
    return implies(C_i.G, C_j.A)                       # 保证蕴含对方假设
def compose(contracts, topo):
    proof = []
    for i in topo:                                     # 无环放电序
        for j in children(i):
            if not discharge(contracts[i], contracts[j]): return None
            proof.append((i, j, hash_pair(contracts[i].G, contracts[j].A)))
    return J_comp(proof, topo)

# IP-267 CDM：版本向量 + 共享变量发散
def divergence(nodes, A):
    D = 0.0
    for i, j in edges(nodes):
        S = vars(A[i]) & vars(A[j])
        d = sum(w[x] * mismatch(nodes[i], nodes[j], x) for x in S)
        d += beta * causal_skew(nodes[i].v, nodes[j].v)
        D = max(D, d)
    return D

# IP-268 CGL：假设驱动接地（只接地被引用的变量）
def ground(A_active, evidence_index):
    E, cov = {}, 0.0
    for x in A_active:
        E[x] = min_evidence_set(evidence_index[x], conf=TAU_G)
        cov += w[x] * (E[x] is not None)
    return E, cov / weight_sum(A_active)

# IP-269 AFW：证伪见证（复用 R69 MINT 的信息动作）
def falsify(x, evidence):
    g = argmax(info_actions(x), key=lambda g: IG(x; y | g, evidence))
    y = execute_info(g)                                # 看/问/触，过安全认证
    return Witness(g, y, likelihood_ratio(y, x), orthogonality(g, evidence))

# IP-270 CSC + IP-271 CBE：系统证书与两级退避
def certify(nodes, kappa, ttl):
    local = all(node.j_fluid.valid for node in nodes)
    E, cov = ground(active_assumptions(nodes), node_evidence(nodes))
    D = divergence(nodes, active_assumptions(nodes))
    W = [falsify(x, E[x]) for x in high_impact(active_assumptions(nodes))]
    jc = compose([n.contract for n in nodes], topo(nodes))
    ok = (local and cov >= TAU_COV and D <= TAU_DIV and jc
          and all(w.survives for w in W))
    J = J_FABRIC(nodes, cov, D, W, jc, ttl)
    U_ctx = 0.0 if ok else entropy(kappa, E) + osc(plausible_set(E))
    return J, U_ctx

# IP-276 主闭环（双速率：控制 1kHz 读缓存，上下文层 20Hz 刷新）
```

## 3. 推导

**引理 19（QoS 证据单调性）** 若 `q'⪯q`（q' 在可靠性/持久性/时效性上不强于 q），则对任意假设 A，`valid(e(q'),A) ⇒ valid(e(q),A)`，且被信任置信度 `conf(e|A)` 不增。系：削弱传输不能「制造」可放电证据；best_effort 的观测永远无法单独放电要求 reliable 的假设——这为 QoS 降级攻击提供了结构性防线（不是靠检测，而是靠不可能）。

**引理 20（发散的因果可检测性）** 设节点用版本向量比较共享变量，消息延迟 D_p99 与时钟偏斜 S_p99 有界。则「两节点对同一假设给出冲突取值却互不可见」的概率 `≤ P(delay>T_stale)+P(skew>T_stale)+P(变量未进词表)`。前两项由 TTL/staleness 约束，第三项不可由内部监控消除。系：发散监控的保证只在假设词表内成立；词表外的一致性没有意义（第 6 节最大风险）。

**引理 21（假设覆盖的失效上界）** 若每个活跃假设的接地/证伪失败概率 `≤ε_i`，且各节点失效事件以相关系数 ρ 相关，则系统级证书错误签发概率 `≤ max_i ε_i + (1−ρ)·Σ_{i≠argmax} ε_i + ε_comp`。当 `ρ→1`（共同盲区）时上界退化为 `max_i ε_i`，监控看到的「一致」不提供任何额外保证。系：**上下文覆盖的风险是「最大项」而非「平均项」**；一个被所有节点共同漏掉的变量，足以让其余证据全部失效。这解释了为什么缓解必须包含独立词表红队，而不能只靠节点间互证。

**引理 22（证伪见证的贝叶斯收紧）** 对假设 x 的独立证伪观测 `y_1..y_k`，若 `Λ_t=p(y_t|x)/p(y_t|¬x)`，则后验赔率 `O_k=O_0·∏Λ_t`。若证伪动作与已有证据来源正交（条件独立），则每步期望 `log Λ` 为负；若不正交（同一 topic 同源），则不提供新信息。系：证伪见证的收益取决于**来源正交性**，不是「又问了一次」。这复用并强化了 R69 引理 18 的证据纪律。

**定理 18（FABRIC 严格包含 R68 与 R69）** 在 A108–A110（单上下文、QoS 完美、无发散、无投毒）下，FABRIC 与 FLUID-RAS 逐指令相同；当 `U_ctx>0` 时，FABRIC 的 λ 与 k 均不弱于 FLUID/R68（λ 单调不降、k 单调不增），且不交互时退回 R68。证：`U_ctx=0` 时退避式与 R69 定义 307 完全一致；`U_ctx>0` 时 `λ_floor` 单调且额外叠加最坏上下文风险，故安全侧支配。因此 R69 是「上下文已认证」的边界、R68 是「上下文未认证且不交互」的边界，两者都是被包含而非被替代。

**定理 19（组合安全）** 若放电图存在无环拓扑序 π，所有 `A_i` 在运行时可被接地证据满足，QoS 证据有效（引理 19），`D≤τ_div`，无 ℰ_ctx 标记，且 TTL 未过期，则系统在 `A=∧A_i` 上满足 `∧G_i`，最坏风险 `≤ max_i ε_i + ε_comp`。证：沿 π 归纳，先证首节点在其假设下满足保证，再由放电 `G_i⇒A_j` 传递到后继；运行时监控保证每条假设在观测上下文里成立；引理 21 给出概率界剩余项。**注意**：这是「相对上下文词表」的条件安全，不是绝对安全——定理 19 的前提本身无法被定理 19 证明。

**定理 20（上下文切换无突变）** 在安全切换集 S_sw 内、且 κ' 通过再认证后才提交切换，则控制输入序列连续（或分段连续且跳变有界），安全包络在切换前后均成立；若再认证失败，λ 单调上升、k 单调缩短，系统退化为最坏情形而非产生不安全跳变。证：切换前后都由合法契约约束，S_sw 限制了切换时刻的运动状态，λ/k 的单调性由定义 321/323 直接给出；结合 R69 定理 17 的认证前缀连续性。

## 6. 本轮最大风险

**一句话**：FABRIC-RAS 把信任从「证书」整体搬到了「上下文假设的完备性」——**若假设词表漏掉了真正决定安全的变量，所有节点会在同一个盲区上「一致地正确」：发散监控因相关盲区而失效，组合证明因共享前提而虚假成立；更糟的是，上下文成为新的攻击面，伪造、重放或降级一条上下文，就能把不安全动作认证成安全。上下文一致，不等于上下文正确；对上眼，不等于看对世界。**

**次级风险与缓解**：
1. **词表盲区（最大危险的根源）** → 引理 21 明确其内部不可消除；只能靠独立红队、跨源异构传感与离线审计回灌词表，并在证书上显式标注「相对词表」的条件性；
2. **上下文投毒 / 假设洗白** → ℰ_ctx 对抗训练 + 假设哈希绑定 + 来源正交 + VQAuditor-X 责任链（定义 312/322/325）；
3. **QoS 伪装与降级** → 引理 19 的结构性单调性，弱证据物理上不可放电强假设；
4. **组合环与假放电** → 强制无环拓扑序或显式全局监督契约，否则拒签（定义 316）；
5. **实时性** → 双速率：控制环只读 O(1) 缓存，上下文层 20Hz；TTL 过期即保守回退；
6. **上下文切换抖动** → 安全切换集 + 再认证 + λ 单调抬升（定义 323、定理 20）。

**定义 311–312（上下文与假设格）** `κ` 为带来源/时间/版本的有类型上下文图；`h(κ)=H(canonical(κ)‖v)`。假设 A 含语义与 QoS 子句；强度序 `A⊑B ⇔ A⇒B`；仅 `A_prov⊑A_req` 可放电，否则为假设洗白。

**定义 313（QTM）** `τ:QoS→{0,1,2,3}`、`L:QoS→ℝ≥0`；`valid(e,A)=1[τ(q_e)≥τ_req(A)]·1[age(e)≤L(q_e)]·1[¬violation]`；τ、L 对 QoS 强度单调不增（引理 19）。

**定义 314（上下文条件风险）** 安全判据为最坏可信集风险 `R_wc=sup_{p∈𝒫_b} E_p r(s,a|κ) ≤ ε`；认证区域 K_cert 时收缩 𝒫_b，否则用全支撑。

**定义 315–316（AGC 与组合）** `C_i=(A_i,G_i)`，运行时 `κ⊨A_i ⇒ 系统满足 G_i`。边 (i,j) 放电当 `G_i⇒A_j`；`C_i⊗C_j` 仅在双向放电时定义，`A=A_i∧A_j, G=G_i∧G_j`。仅接受无环放电序，否则需显式全局监督契约 C_0，否则拒签。

**定义 317（CDM）** `d_ij=Σ_{x∈S_ij} w_x·m_x+β·skew_ij`，`D=max_ij d_ij`；`D>τ_div` ⇒ 脑裂，撤销上下文奖励。未进任何 A 的变量不参与 D，即词表盲区。

**定义 318（CGL）** `A_active=⋃A_i`；对每个 x 选最小证据集 `E_x` 使 `P(x|E_x)≥τ_g`；`cov(A)=Σ w_x·1[grounded]/Σw_x`；只接地被引用变量。

**定义 319（AFW）** 高影响假设须证伪：`g*=argmax_g IG(x;y|g)`，见证 `(g,y,Λ,orth)`；存活当 `Λ≤τ_Λ`；独立 k 次后假假设赔率 `≤O_0·∏Λ`（引理 22）；不可证伪变量直接进 U_ctx。

**定义 320–321（证书与债务）** `J_FABRIC=(node_ids,{J_FLUID^i},{h(κ_i)},{h(A_i),h(G_i)},qos,cov,D,{h(W_x)},h(J_comp),ttl,ver)`；Valid 需局部合法+放电+覆盖+发散+无投毒+TTL。`U_ctx=0`（Valid）或 `H(κ|E)+osc(𝒫_b)`；`U_eff=U_ale+U_unresolved_epi+U_ctx`，`λ=max(λ_task,λ_floor(U_eff))`，`U_ctx>0` 时 `k≤k_wc`。

**定义 322（ℰ_ctx）** 伪造/重放/陈旧/QoS 降级/假设洗白/时钟假一致/共谋/词表走私；`ℰ_FABRIC=ℰ_FLUID×ℰ_ctx`。

**定义 323–325（切换/时钟/审计）** 切换只在 `S_sw` 内且 κ' 再认证通过后提交，否则 λ 单调升、k 单调降。版本向量用于因果排序，墙钟只用于 age/TTL。VQAuditor-X 审计假设责任链、洗白、降级、重放、共谋、词表盲区；词表盲区只能外部红队补充。

## 3. 关键算法伪代码

```python
# IP-264 CAG + IP-265 QTM：增量上下文图与 QoS 认知门
def context_update(topics, A_active, t):
    for e in topics:                                  # e=(topic,payload,ts,qos,node)
        if not (qos_trust(e.qos) >= tau_req(A_active) and
                age(e) <= lifespan(e.qos) and not e.violation):
            mark_stale(e); continue                   # 弱证据不可放电强假设
        graph.apply_delta(e, t)                       # 实体/关系/阶段/角色
    graph.prune(ttl=TTL); return graph.hash()          # h(κ) 含版本向量

# IP-266 AGC：契约监控 + 放电 + 无环组合
def compose_and_check(contracts, topo):
    proof = []
    for i in topo:
        for j in children(i):
            if not implies(contracts[i].G, contracts[j].A): return None  # 拒签
            proof.append((i, j, hash_pair(contracts[i].G, contracts[j].A)))
    return J_comp(proof, topo)

# IP-267 CDM：共享假设上的加权发散 + 因果偏斜
def context_divergence(nodes, A):
    D = 0.0
    for i, j in edges(nodes):
        S = vars(A[i]) & vars(A[j])
        d = sum(w[x]*mismatch(nodes[i], nodes[j], x) for x in S)
        D = max(D, d + beta*causal_skew(nodes[i].v, nodes[j].v))
    return D

# IP-268 CGL：假设驱动接地（不建全量世界模型）
def ground(A_active, index):
    E, cov = {}, 0.0
    for x in A_active:
        E[x] = min_evidence_set(index[x], conf=TAU_G)
        cov += w[x] * (E[x] is not None)
    return E, cov / weight_sum(A_active)

# IP-269 AFW：复用 R69 MINT 的证伪动作（来源正交优先）
def falsify(x, evidence):
    g = argmax(info_actions(x), key=lambda g: IG(x; y | g, evidence))
    y = execute_info(g)                               # 看/问/触，过 C-RAS-WM 认证
    return Witness(g, y, likelihood_ratio(y, x), orthogonality(g, evidence))

# IP-270/271/276：系统证书 + 统一退避 + 双速率主闭环
def certify(nodes, kappa, ttl):
    E, cov = ground(active_assumptions(nodes), node_evidence(nodes))
    D = context_divergence(nodes, active_assumptions(nodes))
    W = [falsify(x, E[x]) for x in high_impact(active_assumptions(nodes))]
    jc = compose_and_check([n.contract for n in nodes], topo(nodes))
    ok = (all(n.j_fluid.valid for n in nodes) and cov >= TAU_COV
          and D <= TAU_DIV and jc and all(w.survives for w in W))
    U_ctx = 0.0 if ok else entropy(kappa, E) + osc(plausible_set(E))
    return J_FABRIC(nodes, cov, D, W, jc, ttl), U_ctx

def FABRIC_RAS_round(M, obs, kappa_cached):           # 控制路径 1kHz
    J, U_ctx = kappa_cached.j_fabric, kappa_cached.u_ctx     # O(1) 读缓存
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, obs, M.o_cal)
    slow = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    g = (M.mint.choose_interaction(modes, o, M.budget)
         if (U_epi > TAU_EPI and not slow) else None)
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    U_eff = U_ale + (U_epi if g is None else 0.0) + U_ctx
    lam = max(M.efs.risk_scale(...), lam_floor(U_eff))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    if U_ctx > 0 or slow:
        lam = max(lam, LAMBDA_WC); k = min(k, k_wc(plausible_set(...)))
    return k, lam, select_mode(modes, U_epi, lam), (U_ale, U_epi, U_ctx), J

def context_tick(M, topics):                          # 上下文层 20Hz
    h = context_update(topics, active_assumptions(M.nodes), now())
    J, U_ctx = certify(M.nodes, M.cag.kappa, TTL)
    publish_certified_context(h, J, U_ctx)             # 控制路径 O(1) 读取
```

## 4. 推导

**引理 19（QoS 证据单调性）** `q'⪯q ⇒ valid(e(q'),A) ⇒ valid(e(q),A)`，且被信任置信度不增。系：削弱传输不能制造可放电证据；best_effort 观测无法单独放电 reliable 假设，QoS 降级攻击被结构性阻断。

**引理 20（发散的因果可检测性）** 用版本向量比较共享变量，冲突不可见概率 `≤P(delay>T_stale)+P(skew>T_stale)+P(变量未进词表)`；前两项由 TTL 约束，第三项内部不可消除。系：发散监控只在假设词表内成立。

**引理 21（假设覆盖的失效上界）** 各假设失败概率 `≤ε_i`、相关性 ρ 时，证书错误签发概率 `≤ max_i ε_i+(1−ρ)Σ_{i≠argmax}ε_i+ε_comp`；`ρ→1` 时退化为 `max_i ε_i`。系：上下文覆盖风险是最大项而非平均项，共同盲区足以使全部互证失效。

**引理 22（证伪见证的贝叶斯收紧）** 独立证伪后 `O_k=O_0·∏Λ_t`；只有来源正交（条件独立）才提供新信息，同源反复询问不增加证据。

**定理 18（严格包含 R68/R69）** 单上下文、QoS 完美、无发散、无投毒时 FABRIC 与 FLUID-RAS 逐指令相同；`U_ctx>0` 时 λ 不降、k 不增，不交互退回 R68。安全侧支配，效率侧仅在认证上下文中获 bonus。

**定理 19（组合安全）** 无环拓扑序 + 假设接地 + QoS 有效 + `D≤τ_div` + 无投毒 + TTL 有效 ⇒ 系统在 `A=∧A_i` 上满足 `∧G_i`，风险 `≤max_i ε_i+ε_comp`。注意：这是「相对上下文词表」的条件安全，前提本身不可由该定理证明。

**定理 20（切换无突变）** 在安全切换集内且再认证通过后切换，控制连续、包络保持；再认证失败则 λ 单调升、k 单调降，退化为最坏情形而非不安全跳变。

## 7. 本轮最大风险

**一句话**：FABRIC-RAS 把信任从「证书」整体搬到了「上下文假设的完备性」——**若假设词表漏掉了真正决定安全的变量，所有节点会在同一个盲区上「一致地正确」：发散监控因相关盲区而失效，组合证明因共享前提而虚假成立；更糟的是，上下文成为新的攻击面，伪造、重放或降级一条上下文，就能把不安全动作认证成安全。上下文一致，不等于上下文正确；对上眼，不等于看对世界。**

**次级风险与缓解**：词表盲区（引理 21 证明内部不可消除，靠独立红队/异构传感/离线审计回灌，并在证书上标注条件性）；上下文投毒/假设洗白（ℰ_ctx + 假设哈希绑定 + 来源正交 + VQAuditor-X）；QoS 伪装/降级（引理 19 结构性单调性）；组合环与假放电（无环拓扑序或显式全局监督契约，否则拒签）；实时性（双速率 + O(1) 缓存 + TTL 保守回退）；切换抖动（安全切换集 + 再认证 + λ 单调抬升）。
