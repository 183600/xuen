# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS」IP-287~294；灵感循环第 1 轮；本轮灵感：「决策规划」×「UniBot」）

> R72 把 GAUGE 从「认知层算法」下沉为**具身实时闭环**：REG 调度契约使「计量不阻塞控制」成为时序定理，IRL 把意图 z 纳入联合后验 b_t(s,z) 并进入风险分母，DMEM 把灵巧手证据升级为带接触模式 c 的计量证据，EREFLEX/ERVOI 合算三层反作用预算，S2R-UQ 把仿真参数不确定度传播进 WCET 与 λ_floor。它回答的是：**「我的测量链在实时调度、意图模糊、灵巧接触下，还能逐指令兑现风险界吗？」**
>
> 但 R72 仍把两件最关键的「上游」当成给定：
>
> - **决策规划缺口**：R72 的 `ach.propose_ctrl` 与 `certified_prefix` 只认证**被选中的那条前缀**，不认证**选择本身**。它没有回答：为什么是这条计划而不是另一条？计划在长时程上是否还有进展？什么时候应该继续执行、什么时候应该修复、什么时候必须重规划、什么时候应该停止思考？一个「可认证前缀」完全可以是一个局部安全但全局无进展的死胡同；把「认证前缀长度」当目标，更会奖励「原地不动」这种平凡可认证行为。**R72 认证了轨迹，却没有认证「规划器凭什么说这条轨迹值得执行」。**
> - **UniBot 缺口**：真实机器人上的候选动作很少由手写控制器给出，而越来越多来自 UniBot 这类**跨本体通用动作块策略**（UniBot-V1 公开接口：54 维动作 / 60 维状态 / H=30 / 30Hz，支持多种本体与二指/五指末端）。它给出的是「未来约 1 秒的动作块」而非「计划」。把它直接接到 R72 的认证前缀上，会同时引入四类新风险：
>   1. **接口规范风险**：54 维共享动作是一个**坐标图（chart）**，不是物理动作。同一个共享向量经不同本体的解码器 `D_e` 会变成不同的关节/末端运动；mask、归一化、版本漂移都会让「在 A 本体认证过的块」在 B 本体上语义改变。**动作接口是汇率，不是物理量。**
>   2. **选择偏差风险**：从 K 个采样块里挑「分数最高」的那一个，是一个**统计选择问题**。每个块的得分都有噪声，取最大会产生赢家诅咒（winner's curse）；被选中块的真实成功率系统性地低于它的估计值。**对随机块校准，不等于对被选中的块校准。**
>   3. **时序承诺风险**：H=30 @ 30Hz ≈ 1 秒开环承诺，证据在承诺之后才到达。块越长，观测越陈旧、拼接越不连续、不可逆接触越难回滚；块越短，推理与重规划开销越大。**动作块不是更长的动作列表，而是一份带期限的批量承诺。**
>   4. **提案者与验证者共因风险**：UniBot 的置信度、价值头、动作先验与下游 critic 可能共享同一训练分布、同一具身偏差、同一语义幻觉。若用 UniBot 自己的置信度去证明 UniBot 的提案，就形成「自证循环」。**通用策略不是规划器，只是一个高覆盖、低可解释的提案源。**
>
> 本轮两个灵感正好构成一对：**UniBot 把「候选动作」变成可大规模采样的提案分布；决策规划把「选哪个、承诺多长、何时重规划、何时停止思考」变成可审计的决策问题。** 两者相乘，核心矛盾是：
>
> **通用策略让「生成候选」变得便宜，却让「证明候选值得执行」变得更贵；决策层不能把证书外包给提案者，必须自己承担选择、组合、承诺与终止的全部责任。**
>
> 核心命题：**不再只问「测量链能否兑现风险界」，而问「当候选计划来自一个跨本体的通用动作块策略，而决策层必须自己选择/组合/承诺/重规划时，证书能否覆盖『选择』本身，而不只是覆盖被选中的那条轨迹？」** 把 R72 的具身证书升级为 **CHOICE-GAUGE-RAS**（**C**hunked **H**orizon **O**ption **I**nterface **C**ertified **E**xecution：块级选项 × 决策规划 × 接口规范 × 证书执行）——**决策规划审计闭环**。其中 UniBot 只作提案源，决策层对「提案 → 选项 → 前缀 → 重规划」整条链负责。

## 0. 直觉与动机

**灵感 1（决策规划 → 安全不是「局部可认证」，而是「有进展的可认证」）**
直觉：一个只会原地微调的机器人，其每一步都可以被认证为「零碰撞、零超力、零滑移」，但它永远到不了目标。R72 的 `certified_prefix` 若以「最长可认证前缀」为目标，最优解就是**不动**。真正的计划必须同时满足三件事：(i) 局部安全；(ii) 朝目标有下界进展；(iii) 在有限时间内要么完成、要么明确失败并安全停止。**证书必须防两种坏：不安全的动作，和「安全地什么都不做」。** 这就是决策规划视角对 R72 的第一刀：把「轨迹认证」升级为「**选项级计划认证 + 进展活性**」。

**灵感 2（UniBot → 动作块是一份带期限的承诺，不是一步动作）**
直觉：UniBot 一次输出 H=30 步的动作块，机器人执行时观测已经落后于决策。块内是开环的：接触前、抓取中、松手前，任何一次证据变化都只能在块边界或守卫点被处理。块越长，摊销了推理成本，却积累了**陈旧观测风险**与**拼接不连续**；块越短，响应更快，却提高了推理频率与决策抖动。正确的做法不是选一个固定 H，而是把块拆成**可撤销前缀 / 守卫点 / 不可逆后缀**：在不可逆接触之前必须留出重新决策的机会。**动作块的安全性取决于「可撤销性结构」，而不只取决于块内动作有多保守。**

**灵感 3（UniBot → 共享动作空间是规范（gauge），不是物理事实）**
直觉：UniBot 的 54 维动作被设计成跨本体统一接口：末端相对 SE(3)、基座、手、下肢通道加有效性 mask。但「统一」只意味着**坐标可对齐**，不意味着**物理等价**。同一个共享向量在二指夹爪上是「闭合 2 指」，在五指手上可能是「闭合 5 指中的 3 指」；同一个归一化力矩在不同减速比、不同负载下产生不同加速度。若证书只记录共享向量 `a`，它就没有记录**实际执行了什么物理动作**。必须把解码契约 `a_phys = D_e(a; m)`、本体标识、mask、版本哈希一起写进证书；安全断言必须在 `a_phys` 上成立，而不是在 `a` 上成立。**跨本体接口带来的是可迁移的坐标，不是可迁移的安全。**

**灵感 4（决策规划 → 选择 K 个提案是一个统计决策，存在赢家诅咒）**
直觉：UniBot 是随机策略。采样 K 个块，用 critic 打分，取最高分，看起来天经地义；但每个分数都是带噪声的估计，取最大会系统性高估被选中块的真实价值。K 越大，选择偏差越大。更糟的是，若 critic 与 UniBot 共享偏差，选择过程会主动挑出「最符合偏差」的块，而不是「最可能成功」的块。正确做法是：对**选择程序**做校准（selection-aware conformal / 下置信界 / 多重比较惩罚），并保留一个独立验证通道；否则「多样本采样」会把系统从「偶尔错」推向「自信地挑最坏的错」。

**灵感 5（决策规划 → 思考本身也有成本，何时停止思考是决策）**
直觉：R72 的 ERVOI 只决定「要不要问人」。现在还要决定「要不要再多采样一个块」「要不要重规划」「要不要继续执行当前块」。这些都是**元推理（metareasoning）**：多采一个提案的边际收益递减，而延迟、能耗、观测陈旧与决策抖动成本递增。存在一个有限的最优采样数 K* 与最优承诺长度 k*，不是超参数。**一个不会停止思考的规划器，和不会停止走路的机器人一样危险。**

**灵感 6（决策规划 → 计划是选项的组合，不是单块的拼接）**
直觉：长时程任务（「收拾桌面」）不能靠一个 1 秒块完成，也不能靠把块首尾相接硬拼。需要**选项（option）**：每个选项有前置条件、后置条件、进展、代价、终止条件。选项之间要有前置/后置链，跨块要有重叠与守卫。UniBot 负责在选项内部生成运动块；决策层负责选择选项序列、验证前置/后置、检查进展、决定修复或重规划。**块是运动提案，选项是计划单元；把两者混为一谈，就会得到「局部平滑、全局迷路」的行为。**

**灵感 7（失效归因 → 块失败不是「策略不行」，必须分清接口、提案、执行、感知、计划）**
直觉：一个块失败，可能是：(a) 共享动作在本体上解码错了（接口/规范）；(b) UniBot 的提案分布 OOD 或模式坍塌（提案）；(c) 执行器跟踪不上（执行）；(d) 状态估计错了（感知）；(e) 选项前置条件不满足或组合错误（计划）。若不归因就重试，系统会反复用同一个错误假设；若错误地归因，又会把好模块降级。必须维护**块失败台账**，用独立残差签名归因，并让归因结果反馈到门控/校准，而不是只反馈到「再来一次」。

## 1. 形式化定义（增量：定义 366–385）

**定义 366（CHOICE-GAUGE-RAS 总览与五不变式）** CHOICE-GAUGE-RAS = (UIM, CPS, OPC, CHT, META, DFA, R72†)。五不变式：
(i) **提案与计划分离**：UniBot 只产生提案 `C ~ P_θ(C | o, g)`；任何提案在被决策层认证前不得进入控制域；决策层对选择、组合、承诺、终止负责；
(ii) **规范完整**：每条共享动作必须携带 `(embodiment_id, mask, iface_ver, decode_hash, gauge_hash, support_score)`；缺少任一字段即视为不可认证；
(iii) **选择感知校准**：证书覆盖整个选择程序（K、打分规则、去重规则、验证集），而不只覆盖被选中的块；
(iv) **时序承诺完整**：每个块必须给出可撤销前缀 `k_rev`、守卫点集 `G`、不可逆后缀、陈旧观测阈值与拼接残差上界；
(v) **进展活性与严格退化**：任何计划证书必须含进展下界 `p_min` 与有限时间完成/停止条件；任一新层失效即逐指令退化到 R72/R68，安全侧只增不减。

**定义 367（UniBot 接口规范与物理解码）** 共享动作空间 `𝒜 ⊂ ℝ^54`，共享状态空间 `𝒮_u ⊂ ℝ^60`，块长 `H=30`，目标帧率 `fps=30`。本体 `e ∈ ℰ` 的解码器
`a^phys = D_e(a; m_e)`，其中 `a ∈ 𝒜`，`m_e ∈ {0,1}^54` 为有效性 mask，`a^phys ∈ 𝒜_e` 为本体物理动作（关节位置/速度/力矩、末端位姿增量、手部通道等）。定义规范等价关系
`a ~_e a' ⇔ ‖D_e(a;m_e) − D_e(a';m_e)‖_{G_e} ≤ ε_e`，
其中 `G_e` 为按物理单位与安全敏感度加权的度量。**接口证书只对 `(e, m_e, iface_ver, D_e)` 的等价类负责；原始共享向量 `a` 不是安全断言的对象。** 定义接口支撑度
`supp_e(a) = min( support_θ(a), 1 − OOD_e(a), valid_mask_e(a) ) ∈ [0,1]`。

**定义 368（动作块提案与提案集）** 一次提案
`C = (a_{t:t+H}, m, h, meta)`，其中 `a_{t:t+H} ∈ 𝒜^H`，`m` 为 mask 序列，`h ∈ [1,H]` 为建议承诺长度，`meta` 含 UniBot 版本、采样温度、token 似然、本体标识、任务语境嵌入。给定观测 `o_t` 与目标 `g`，提案分布为
`P_θ(C | o_t, g)`。采样 K 个提案并按规范等价去重（定义 367），得到
`𝒞_K = {C_1,…,C_K}`，去重后有效模式数为 `K_eff ≤ K`。**K 是决策变量，不是固定超参**（见定义 374）。

**定义 369（动作块时序契约）** 块契约
`T_C = (pre, a_{t:t+H}, post, k_rev, G, suffix, Δprog, r_res, τ_stale, ε_stitch)`：
- `pre`：前置条件（状态/意图/接触/工作空间/权限）；
- `k_rev ∈ [1,H]`：可撤销前缀长度；前 `k_rev` 步必须可在不产生不可逆后果的情况下中止/回滚；
- `G = {g_1 < … < g_m} ⊂ (k_rev, H]`：守卫点；到点必须重新检查证据、允许提前终止；
- `suffix`：不可逆后缀（如闭合接触、松手、插入、焊接）；进入前必须满足证据充分性；
- `Δprog`：块完成时的最小进展下界；
- `r_res`：块执行后残余风险上界；
- `τ_stale`：允许的最大观测年龄；
- `ε_stitch`：与上一块拼接时的状态/动作不连续上界。
**性质**：若 `k_rev = H`，块完全可撤销；若 `k_rev = 1`，块退化为单步承诺；`suffix ≠ ∅` 时，进入后缀必须通过守卫点证据门。

**定义 370（选项抽象与块图）** 选项
`ω = (pre_ω, Π_ω, post_ω, Δprog_ω, c_ω, r_ω, β_ω)`，
其中 `Π_ω` 是可由 UniBot 提案或解析控制器实现的运动块族，`post_ω` 为后置条件，`β_ω` 为终止/成功判据。块图 `G_ω = (Ω, E_ω)`：边 `(ω, ω')` 存在当且仅当 `post_ω ⇒ pre_{ω'}` 且跨块拼接满足 `ε_stitch ≤ ε_max`。计划是选项序列 `π = (ω_1,…,ω_n)`，其证书必须逐边验证前置/后置链与进展累加。

**定义 371（决策级计划与进展活性）** 在 R72 的信念 `b_t(s,z)` 上定义选项级计划价值
`V_π(b) = E[ Σ_i (Δprog_{ω_i} − λ_c c_{ω_i} − λ_r r_{ω_i}) − λ_s·stale(π) − λ_d·deliberation(π) ]`，约束：
(i) `risk(π, z) ≤ ε` 对所有 `z ∈ supp(b_t(z))`；
(ii) `Σ_i Δprog_{ω_i} ≥ p_min`（进展下界）；
(iii) 存在有限 `T_done` 使计划完成或进入显式失败/安全停止（活性）。
**计划证书 `J_PLAN` 不得只记录「前缀长度」；它必须记录进展下界、活性条件与失败出口。**

**定义 372（提案校准与选择偏差）** 对块 `C` 定义条件成功率
`p_succ(C | o, g, e) = P(task succeeds | execute C, o, g, e)`。
估计器输出 `(p̂_succ, ECE_prop, coverage_prop)`。选择规则
`C* = Select(𝒞_K; score)`，其中 `score` 必须来自与 UniBot 价值头**独立**的 critic 或独立验证数据。定义选择偏差
`b_sel(K) = E[ p_succ(C*) − p̂_succ(C*) ]`。
**要求**：证书使用选择感知下界 `p_lcb(C*) = p̂_succ(C*) − b_sel_upper(K, δ) − ECE_margin`，或用与选择程序完全相同的 held-out 程序做 conformal 校准；**对随机块的校准不能直接用于被选中的块。**

**定义 373（提案支撑、OOD 与模式覆盖）** 定义本体距离 `d_emb(e, e_train)`、任务距离 `d_task(g, g_train)`、观测距离 `d_obs(o, o_train)`。提案风险门：
`OOD_prop = max( d_emb/τ_emb, d_task/τ_task, d_obs/τ_obs, 1 − supp_e(a) )`。
若 `OOD_prop > 1` 或 `K_eff < K_min`（模式坍塌/去重后无多样性），则提案失效，决策层必须拒绝采样结果并切换到 R72 的保守提案源。**「有 K 个样本」不等于「有 K 个不同计划」。**

**定义 374（ deliberation 元推理）** 定义多采一个提案的边际价值、重规划的边际价值与继续执行的边际价值：
`VoI_sample(K) = E_{C_{K+1}}[V(Select(𝒞_K ∪ {C_{K+1}}))] − V(Select(𝒞_K)) − c_sample`；
`VoI_replan = E[V(Plan(b_{t+1}))] − V(Plan(b_t)) − c_replan`；
`VoI_commit(k) = V(continue k steps) − V(replan now) − c_switch`。
决策规则：选择 `argmax` 且只在边际价值 > 0 时执行；`K*` 为首次 `VoI_sample ≤ 0` 的采样数；`k*` 为首次 `VoI_commit ≤ VoI_replan` 的承诺长度。**元推理与 R72 的 ERVOI 同构：思考/询问/执行/重规划统一在同一个价值尺度上比较。**

**定义 375（决策级风险缩放 D-RISK）** 在 R72 `E-RISK` 基础上加入决策层不确定度：
`λ_D = max( risk_scale(U_ale, U_epi, H_z, u_tac, U_prop, U_iface, U_sel, U_stale, U_comp),
            λ_floor(U_ale + U_epi + H_z + u_tac + U_prop + U_iface + U_sel + U_stale + U_comp) )`，
其中
`U_prop`：提案分布不确定度（OOD、K_eff、模式熵）；
`U_iface`：接口规范/解码/mask 不确定度；
`U_sel`：选择偏差上界 `b_sel_upper`；
`U_stale`：观测年龄与拼接残差；
`U_comp`：选项组合/前置后置链不确定度。
**任一维度失控都抬高 λ_D，强制缩短承诺、降低速度、增加守卫或拒绝提案。**

**定义 376（块失败归因 DFA）** 失效假设集
`ℋ_D = {H_iface, H_prop, H_exec, H_percept, H_plan, H_unknown}`。
给定块残差签名
`ρ_C = (e_iface, e_track, e_prop, e_state, e_progress, e_stitch)`，
后验 `P(H | ρ_C) ∝ p(ρ_C | H) P(H)`。归因规则：
- `H_iface`：解码后物理动作与预期不符、mask/版本异常 ⇒ 拒绝该接口，膨胀 `U_iface`；
- `H_prop`：提案 OOD、模式坍塌、独立 critic 与 UniBot 价值头分歧大 ⇒ 降低提案权重，增大 K/切换提案源；
- `H_exec`：跟踪误差/饱和/延迟超阈 ⇒ 缩短前缀，降级执行；
- `H_percept`：状态 innovation 超阈 ⇒ 退回 R72 证据审计；
- `H_plan`：前置/后置链断裂、进展为负、拼接超阈 ⇒ 触发选项重规划/修复；
- `H_unknown`：所有已知假设拟合差 ⇒ 不重试，进入安全停止/人工接管。
**每条归因必须写入台账 `L_DFA`，并影响下一轮门控；禁止「不明原因重试」。**

**定义 377（决策级指标 D-MIB）** 在 R72 E-MIB 上新增：
- **提案族**：`ECE_prop`、`coverage_prop`、`K_eff`、模式熵、OOD 率、选择偏差 `b_sel`、独立 critic 分歧；
- **接口族**：解码一致性、mask 有效率、版本漂移、跨本体物理等价误差、`U_iface`；
- **时序/承诺族**：`k_rev/H`、守卫命中率、陈旧观测年龄、拼接残差、不可逆后缀进入前的证据充分性；
- **决策族**：计划完成率、进展下界达成率、重规划频率、修复/重规划比、思考时延、元推理收益、失败归因准确率；
- **活性族**：无进展窗口长度、振荡/往返频率、证书 Goodhart 指标（前缀长度与进展的秩相关）。

**定义 378（决策级 IVG 扩展 D-IVG）** 在 R72 E-IVG 上新增失效条件：
- 提案：`ECE_prop > τ_ece_prop`、`coverage_prop < 1−α`、`K_eff < K_min`、`OOD_prop > 1`、`b_sel > τ_sel`；
- 接口：解码一致性 < 阈值、mask 有效率 < 阈值、`iface_ver` 不匹配、跨本体等价误差 > `ε_e`；
- 承诺：`k_rev = 0` 且进入不可逆后缀、观测年龄 > `τ_stale`、拼接残差 > `ε_stitch`；
- 决策：进展下界未达、无进展窗口 > `W_max`、重规划频率 > `f_max`、元推理超预算。
任一成立 ⇒ 相关模块降级：提案失效 ⇒ R72 保守提案；接口失效 ⇒ 拒绝 UniBot；承诺失效 ⇒ 缩短到单步/退回 R68；决策失效 ⇒ 停止并进入安全出口。

**定义 379（决策级证书 J_CHOICE）**
`J_CHOICE = (J_EMB, iface_ver, gauge_hash, embodiment_id, proposal_calib_hash, selection_rule, K, b_sel_upper, option_graph_hash, J_PLAN, chunk_contract_hash, progress_audit, stale_monitor, dfa_ledger_hash, choice_ver)`。
`Valid(J_CHOICE) ⇔ Valid(J_EMB) ∧` 接口规范匹配 ∧ 提案选择感知校准有效 ∧ `J_PLAN` 有效（前置/后置/进展/活性）∧ 块契约有效（`k_rev`、守卫、不可逆门）∧ 无未解决 D-IVG 失效 ∧ 台账一致。
**证书必须能回答四个问题：候选从哪来、为什么选它、承诺多长、失败后归因到谁。**

**定义 380（威胁模型 AIC-CHOICE）** `ℰ_CHOICE = ℰ_EMB × ℰ_iface × ℰ_prop × ℰ_decision`：
- `ℰ_iface`：接口版本投毒、mask 篡改、归一化漂移、跨本体解码错配、共享动作伪装；
- `ℰ_prop`：UniBot 对抗样本、动作 token 投毒、模式坍塌诱导、提案分布偏移、价值头与 critic 共因污染；
- `ℰ_decision`：选择规则操纵（刷分）、K 预算耗尽、重规划振荡、进展下界绕过、证书重放、守卫点跳过；
- `ℰ_EMB`：继承 R72 的调度/意图/接触/仿真投毒威胁。

**定义 381（严格退化包含链）** CHOICE 在以下条件下逐指令等价：
- 接口失效 ⇒ 拒绝 UniBot，使用 R72 的原生 `ach`/固定技能库；
- 提案失效 ⇒ 固定单提案 + R72 认证前缀（无选择偏差）；
- 计划/选项失效 ⇒ R72 认证前缀 + 局部进展监控；
- 承诺/守卫失效 ⇒ 单步动作 + R68 硬安全包络；
- 决策/元推理失效 ⇒ 固定 K 与固定短承诺；
- 全失效 ⇒ R68。
**安全侧只增不减：任何退化都保留 R68 的硬安全包络与 λ_floor。**

**定义 382（四域分离与决策域）** 在 R72 三域基础上新增**决策域（D 域）**：事件触发 1–10Hz、软实时、可抢占、允许分配、anyonetime；优先级 70–85、截止 100–200ms。决策域只写「已认证计划/块契约快照」，控制域只读；决策域不得直接写控制指令。四域通信仍为单向无锁环形缓冲 + 版本号，因此 R72 定理 25 的无死锁/无优先级反转结论保持。

**定义 383（选项修复与重规划）** 给定当前计划 `π` 与新证据，定义：
- `repair(π)`：保留已认证前缀，替换尾部选项，只重新认证受影响边；代价 `c_repair`；
- `replan(π)`：从当前信念重新搜索选项图；代价 `c_replan`；
- `continue`：继续当前块直到下一守卫点；代价 `c_continue`。
选择规则：若 `c_repair + ε_reaudit ≤ c_replan` 且修复后 `J_PLAN` 有效，则修复；否则重规划；若两者都不可行，进入安全出口。**修复不得绕过认证。**

**定义 384（规范不变安全断言）** 对本体 `e`，安全断言 `Safe(e, a, s)` 必须满足：
`∀ a' ~_e a, Safe(e, a', s)`（规范等价类内安全）；
且若存在本体重参数化 `h: ℰ → ℰ` 使 `D_{h(e)} = R_h ∘ D_e`，则证书中的安全裕度应按 `R_h` 的 Lipschitz 常数变换，而不是假设不变。
**任何只在共享坐标上成立、在物理解码后失效的断言，不得进入 J_CHOICE。**

**定义 385（反 Goodhart 进展契约）** 对任意执行窗口 `W`，计划必须满足：
`progress(W) ≥ p_min(W)` 或进入显式 `NoProgress` 状态并给出原因/安全出口；且
`corr( certified_prefix_length, progress ) ≥ ρ_min`（证书长度与真实进展不能脱钩）。
**若系统通过来回振荡、重复探测或选择「最容易认证」的块来刷证书，则进展审计必须将其判为失效。**

# 第 73 轮产物 · 创新点清单 v1：CHOICE-GAUGE-RAS（Chunked Horizon Option Interface Certified Execution：块级选项 × 决策规划 × 接口规范 × 证书执行；UIM×CPS×OPC×CHT×META×DFA×R72†）

> 承接第 72 轮 IP-287~294（EMBODIED-GAUGE-RAS）。R72 完成了「具身层」的计量审计：REG 调度契约、IRL 意图联合后验、DMEM 接触条件证据、EREFLEX 三层反作用、ERVOI 具身 VoI、S2R-UQ、四域/三域分离。但 R72 仍把**候选计划的来源**与**决策层**当成给定：
> - **决策规划缺口**：`ach.propose_ctrl` 只给出候选前缀，`certified_prefix` 只认证被选中的轨迹；系统没有显式回答「为什么选这条」「承诺多长」「何时重规划」「如何保证有进展」。以「可认证前缀长度」为目标会奖励原地不动；局部安全不等于全局有进展。
> - **UniBot 缺口**：通用动作块策略（UniBot-V1：54 维动作 / 60 维状态 / H=30 / 30Hz）提供跨本体提案，但共享动作是**坐标图**而非物理动作；块是**约 1 秒开环承诺**；多样本选择存在**赢家诅咒**；提案者置信度与下游 critic 可能**共因**；长时程需要选项组合与重规划。
>
> 本轮把 UniBot **降格为提案源**，把决策层升级为**对选择、组合、承诺、终止负责**的证书生产者：
> - **UIM**：接口规范计量——解码契约、mask、版本、物理等价类、支撑度/OOD；
> - **CPS**：选择感知的提案校准——K 个块、独立 critic、下置信界、选择偏差上界、模式覆盖；
> - **OPC**：选项级计划认证——前置/后置、块图、进展下界、活性、计划证书 `J_PLAN`；
> - **CHT**：块级时序契约——可撤销前缀、守卫点、不可逆后缀、陈旧观测、拼接残差；
> - **META**：元推理——多采样/重规划/继续执行的统一 VoI 与有限停止；
> - **DFA**：块失败归因——接口/提案/执行/感知/计划/未知六类台账；
> - **D-RISK/D-IVG/D-MIB**：决策层风险缩放、门控与指标；
> - **CHOICE Pipeline + J_CHOICE**：四域分离下的完整闭环与证书。
>
> 核心命题：**从「我的测量链能否兑现风险界」进化为「当候选来自通用动作块策略时，我的决策层能否为『选择』本身兑现风险界，并且在长时程上既有进展又不把证书刷成原地不动？」** 理论姿态延续：**新层是旧层的严格泛化；UniBot 只作提案源；安全侧只增不减；退化链逐指令等价。**

## 2. 形式化定义（要点版）

**定义 366（总览与五不变式）** 见想法区。核心：提案/计划分离、规范完整、选择感知校准、时序承诺完整、进展活性与严格退化。

**定义 367（UniBot 接口规范与物理解码）** 共享动作 `a∈ℝ^54`，状态 `s∈ℝ^60`，`H=30`，`fps=30`；`a^phys=D_e(a;m_e)`。规范等价 `a~_e a' ⇔ ‖D_e(a;m_e)−D_e(a';m_e)‖_{G_e}≤ε_e`。**安全断言只对 `(e,m_e,iface_ver,D_e)` 的等价类负责；原始共享向量不是断言对象。**

**定义 368（动作块提案与提案集）** `C=(a_{t:t+H},m,h,meta)`，`C~P_θ(C|o,g)`；采样 K 个并按规范等价去重得 `𝒞_K`，`K_eff` 为模式数。**K 是决策变量。**

**定义 369（块级时序契约）** `T_C=(pre,a,post,k_rev,G,suffix,Δprog,r_res,τ_stale,ε_stitch)`。前 `k_rev` 步可撤销；`G` 为守卫点；进入 `suffix` 前必须通过证据门；`τ_stale` 限制观测年龄；`ε_stitch` 限制跨块拼接残差。

**定义 370（选项与块图）** 选项 `ω=(pre,Π,post,Δprog,c,r,β)`；边 `(ω,ω')` 存在当 `post_ω⇒pre_{ω'}` 且 `ε_stitch≤ε_max`。计划 `π` 必须逐边验证前置/后置链与进展累加。

**定义 371（决策级计划与进展活性）** `V_π(b)=E[Σ(Δprog−λ_c c−λ_r r)−λ_s·stale−λ_d·deliberation]`，约束：全意图支撑风险 ≤ε；`ΣΔprog≥p_min`；存在有限完成或显式失败/安全停止。**J_PLAN 记录进展下界、活性条件、失败出口，不只记录前缀长度。**

**定义 372（提案校准与选择偏差）** `p_succ(C|o,g,e)`；估计 `(p̂_succ,ECE_prop,coverage_prop)`。选择 `C*=Select(𝒞_K;score)`；`score` 必须来自独立 critic/验证数据。`b_sel(K)=E[p_succ(C*)−p̂_succ(C*)]`。**证书使用选择感知下界 `p_lcb(C*)`，不能把随机块校准直接用于被选中块。**

**定义 373（提案支撑、OOD 与模式覆盖）** `OOD_prop=max(d_emb/τ_emb,d_task/τ_task,d_obs/τ_obs,1−supp_e(a))`。`OOD_prop>1` 或 `K_eff<K_min` ⇒ 提案失效，切换 R72 保守提案源。**K 个样本不等于 K 个不同计划。**

**定义 374（元推理）** `VoI_sample(K)`、`VoI_replan`、`VoI_commit(k)`；只在边际价值 >0 时执行；`K*` 为首个 `VoI_sample≤0`；`k*` 为首个 `VoI_commit≤VoI_replan`。**思考/询问/执行/重规划统一价值尺度。**

**定义 375（D-RISK）** `λ_D=max(risk_scale(U_ale,U_epi,H_z,u_tac,U_prop,U_iface,U_sel,U_stale,U_comp), λ_floor(Σ))`。任一维度失控都抬高 λ_D，强制缩短承诺、降速、加守卫或拒绝提案。

**定义 376（DFA）** `ℋ_D` 六类；残差 `ρ_C=(e_iface,e_track,e_prop,e_state,e_progress,e_stitch)`；后验 `P(H|ρ_C)`。归因必须写入 `L_DFA` 并影响下一轮门控；禁止不明原因重试。

**定义 377（D-MIB）** 提案族（ECE_prop/coverage/K_eff/模式熵/OOD/b_sel/critic 分歧）；接口族（解码一致性/mask/版本漂移/跨本体等价误差/U_iface）；承诺族（k_rev/H/守卫命中/观测年龄/拼接残差/不可逆门证据）；决策族（完成率/进展达成/重规划频率/修复比/思考时延/元推理收益/归因准确率）；活性族（无进展窗口/振荡频率/证书长度与进展秩相关）。

**定义 378（D-IVG）** 提案、接口、承诺、决策任一失效 ⇒ 对应降级：提案→R72 保守提案；接口→拒绝 UniBot；承诺→单步/R68；决策→停止并安全出口。

**定义 379（J_CHOICE）** `Valid ⇔ Valid(J_EMB) ∧` 接口规范匹配 ∧ 选择感知校准有效 ∧ `J_PLAN` 有效 ∧ 块契约有效 ∧ 无未解决 D-IVG ∧ 台账一致。**证书回答：候选从哪来、为什么选它、承诺多长、失败归因到谁。**

**定义 380（AIC-CHOICE）** `ℰ_CHOICE=ℰ_EMB×ℰ_iface×ℰ_prop×ℰ_decision`。新增：接口投毒、mask 篡改、跨本体解码错配、动作 token 投毒、模式坍塌诱导、选择规则操纵、K 预算耗尽、重规划振荡、进展下界绕过、证书重放。

**定义 381（严格退化包含链）** 接口失效→拒绝 UniBot；提案失效→固定单提案+R72；计划失效→R72 前缀+进展监控；承诺失效→单步+R68；决策失效→固定 K/短承诺；全失效→R68。**安全侧只增不减。**

**定义 382（四域分离）** 控制域（1kHz，硬实时，只读）/ 计量域（50Hz，软实时，写快照）/ 决策域（1–10Hz，软实时，anyonetime，写计划快照）/ 感知域（Best-effort，异步）。四域单向无锁缓冲+版本号；决策域不得直接写控制指令。

**定义 383（修复/重规划/继续）** `repair` 保留已认证前缀、只重认证受影响边；`replan` 从当前信念重搜选项图；`continue` 执行到下一守卫点。选择规则：`c_repair+ε_reaudit≤c_replan` 且修复后 `J_PLAN` 有效 ⇒ 修复；否则重规划；都不可行 ⇒ 安全出口。**修复不得绕过认证。**

**定义 384（规范不变安全断言）** `Safe(e,a,s)` 必须对 `a~_e a'` 成立；本体重参数化 `D_{h(e)}=R_h∘D_e` 时，安全裕度按 `R_h` 的 Lipschitz 常数变换。**只在共享坐标成立、解码后失效的断言不得进入 J_CHOICE。**

**定义 385（反 Goodhart 进展契约）** 任意窗口 `W` 满足 `progress(W)≥p_min(W)` 或进入 `NoProgress` 并给原因/安全出口；且 `corr(certified_prefix_length, progress)≥ρ_min`。**振荡、重复探测、选择最容易认证的块来刷证书，必须被判失效。**

```python
    embodiment_id: str
    iface_ver: str
    mask: np.ndarray            # [54] bool

    gauge_hash: bytes

class UniBotInterfaceMetrology:
    def __init__(self, decoders, support_model, eps_e):
        self.decoders, self.support, self.eps = decoders, support_model, eps_e

    def decode(self, a_shared, spec, s_shared):
        # 1) 版本/mask 硬检查：不匹配直接拒绝，不做“尽力解码”
        if spec.iface_ver != self.expected_ver(spec.embodiment_id):
            return InterfaceResult(ok=False, reason="iface_ver_mismatch")
        if not valid_mask(a_shared, spec.mask):
            return InterfaceResult(ok=False, reason="mask_violation")

        # 2) 物理解码：安全断言的对象是 a_phys，不是 a_shared
        a_phys = self.decoders[spec.embodiment_id](a_shared, spec.mask)

        # 3) 支撑度/OOD：模型没见过的共享动作不能靠“统一接口”自动合法
        supp  = self.support.score(a_shared, s_shared, spec)
        ood   = self.support.ood(a_shared, s_shared, spec)
        ok    = (supp >= SUPP_MIN) and (ood <= OOD_MAX)
        return InterfaceResult(ok=ok, a_phys=a_phys, supp=supp,
                               ood=ood, gauge_hash=spec.gauge_hash,
                               decode_hash=spec.decode_hash)

    def equivalent(self, a, a2, spec):
        # 规范等价：只比较物理解码后的差异
        da = self.decoders[spec.embodiment_id](a,  spec.mask)
        db = self.decoders[spec.embodiment_id](a2, spec.mask)
        return weighted_norm(da - db, spec.G_e) <= self.eps[spec.embodiment_id]
```

### IP-296 CPS：选择感知的提案采样与校准

```python
class CalibratedProposalSelector:
    def __init__(self, unibot, critic, conformal, iface, K_max):
        self.unibot, self.critic = unibot, critic
        self.conformal, self.iface = conformal, iface
        self.K_max = K_max

    def propose(self, obs, goal, spec, K):
        # 1) UniBot 只产生提案；不把它的价值头当成功率
        raw = [self.unibot.sample_chunk(obs, goal, temperature=τ)
               for _ in range(K)]

        # 2) 接口规范过滤：mask/版本/支撑度不合格的块不进入选择池
        pool = []
        for c in raw:
            dec = self.iface.decode(c.a, spec, obs.s)
            if not dec.ok:
                continue
            c.a_phys = dec.a_phys
            c.supp, c.ood = dec.supp, dec.ood
            pool.append(c)
        if not pool:
            return ProposalResult(ok=False, reason="no_valid_proposal")

        # 3) 规范等价去重：K 个样本可能只有 K_eff 个不同计划
        pool = dedupe_by_equivalence(pool, self.iface, spec)
        K_eff = len(pool)

        # 4) 独立 critic 打分：与 UniBot 价值头隔离（不同数据/不同头）
        for c in pool:
            c.score, c.p_succ_hat, c.risk_hat = self.critic(obs, goal, c)
        C_star = max(pool, key=lambda c: c.score)

        # 5) 选择感知校准：对“选择程序”校准，而非对随机块校准
        p_lcb = self.conformal.selected_lcb(
            C_star, K=K, K_eff=K_eff, pool=pool,
            alpha=α, selection_rule="max_score")
        b_sel_upper = self.conformal.selection_bias_upper(
            K=K, K_eff=K_eff, sigma=self.critic.noise_scale(), delta=δ)

        ok = (K_eff >= K_min and C_star.ood <= OOD_MAX
              and p_lcb >= P_MIN and b_sel_upper <= B_SEL_MAX)
        return ProposalResult(ok=ok, chosen=C_star, pool=pool, K=K,
                              K_eff=K_eff, p_lcb=p_lcb,
                              b_sel_upper=b_sel_upper,
                              calib_hash=self.conformal.hash())
```

### IP-297 OPC：选项级计划与 `J_PLAN`

```python
class OptionPlanCertifier:
    def __init__(self, option_graph, chunk_eval, progress_floor):
        self.graph, self.chunk_eval = option_graph, chunk_eval
        self.p_min = progress_floor

    def plan(self, belief, goal, budget):
        # A*/Dijkstra over options；边代价含风险、不确定度、思考成本
        open_set = priority_queue()
        open_set.push(self.graph.start(goal), priority=0.0)
        best = {self.graph.start(goal): 0.0}
        parent = {}
        while open_set:
            ω = open_set.pop()
            for ω2, edge in self.graph.successors(ω):
                if not self.precondition_holds(ω2, belief): continue
                if edge.stitch > EPS_STITCH_MAX: continue
                c = edge.cost + LAMBDA_RISK * edge.risk \
                    + LAMBDA_UNC * edge.uncertainty
                if best.get(ω2, INF) > best[ω] + c:
                    best[ω2] = best[ω] + c
                    parent[ω2] = (ω, edge)
                    open_set.push(ω2, priority=best[ω2])

        # 选择满足进展下界与活性的最小代价计划
        candidates = [n for n in best if self.graph.done(n)
                      and self.graph.progress(n) >= self.p_min]
        if not candidates:
            return PlanResult(ok=False, reason="no_progress_feasible")
        goal_node = min(candidates, key=lambda n: best[n])
        π = reconstruct(parent, goal_node)
        J_plan = self.certify(π, belief)
        return PlanResult(ok=J_plan.valid, plan=π, J_plan=J_plan)

    def certify(self, π, belief):
        # 逐边验证 pre/post 链、拼接、进展、活性、失败出口
        for (ω, ω2, edge) in edges_of(π):
            if not implies(ω.post, ω2.pre): return JPlan.invalid("pre_post_break")
            if edge.stitch > EPS_STITCH_MAX: return JPlan.invalid("stitch")
        if sum(ω.progress for ω in π) < self.p_min:
            return JPlan.invalid("progress_floor")
        if not finite_time_termination(π):
            return JPlan.invalid("liveness")
        return JPlan(valid=True, seq=π, progress_lb=self.p_min,
                     evidence=evidence_pointers(π),
                     fallback=self.graph.safe_exit(π),
                     hash=hash_plan(π, belief))
```

### IP-298 CHT：块时序契约与守卫监控

```python
@dataclass
class ChunkContract:
    pre: Predicate
    post: Predicate
    k_rev: int                 # 可撤销前缀长度
    guards: List[int]          # 守卫步
    suffix: List[int]          # 不可逆后缀
    delta_prog: float
    r_residual: float
    tau_stale: float
    eps_stitch: float

class ChunkHorizonController:
    def __init__(self, monitor, evidence_gate):
        self.monitor, self.gate = monitor, evidence_gate

    def commit(self, chunk, contract, now):
        # 不可逆后缀前必须有新鲜证据与守卫通过
        if contract.suffix and not self.gate.ready(chunk, contract):
            return CommitResult(ok=False, reason="irreversible_gate")
        # 观测年龄超阈：即使块本身“安全”，也不得继续开环承诺
        if now - chunk.obs_time > contract.tau_stale:
            return CommitResult(ok=False, reason="stale")
        # 只承诺可撤销前缀；后缀等待守卫点
        k = contract.k_rev
        if self.monitor.stitch_error(chunk) > contract.eps_stitch:
            return CommitResult(ok=False, reason="stitch")
        return CommitResult(ok=True, k=k, guards=contract.guards,
                           stop_hook=self.make_stop_hook(contract))

    def step(self, state, contract):
        # 守卫点：重新检查证据；任何超阈立即早停/修复/重规划
        if state.k in contract.guards:
            if not self.gate.check(state, contract):
                return GuardResult(trigger=True, action="abort_or_repair")
        if state.tracking_error > TRACK_MAX:
            return GuardResult(trigger=True, action="shorten_prefix")
        return GuardResult(trigger=False)
```

### IP-299 META：元推理与有限停止

```python
def deliberation_decision(belief, pool, K, budget, planner):
    # 1) 多采一个提案的价值
    voi_sample = expected_value_of_extra_sample(pool, K, budget) - sample_cost()
    # 2) 重规划 vs 继续当前块
    v_now      = planner.value_of_commit(belief, pool.chosen, horizon=1)
    v_replan   = planner.value_of_replan(belief) - replan_cost()
    voi_replan = v_replan - v_now
    # 3) 承诺长度：守卫点上的边际风险 vs 继续价值
    k_star = 1
    for k in range(2, pool.chosen.H + 1):
        if planner.marginal_commit_value(k) <= planner.marginal_commit_risk(k):
            break
        k_star = k
    # 4) 停止：所有边际价值非正 → 执行当前最优或安全停止
    if voi_sample <= 0 and voi_replan <= 0:
        return MetaResult(mode="commit", k=k_star)
    if voi_replan > max(voi_sample, 0):
        return MetaResult(mode="replan", k=1)
    if voi_sample > 0 and K < budget.K_max:
        return MetaResult(mode="sample", K=K + 1)
    return MetaResult(mode="stop", reason="no_positive_voi")
```

## 4. 推导

**引理 33（接口规范非不变性）** 若证书只在共享向量 `a` 上断言安全，而不记录 `(e,m_e,iface_ver,D_e)`，则存在两个本体 `e_1,e_2` 与同一 `a`，使 `D_{e_1}(a)` 与 `D_{e_2}(a)` 的物理动作/风险不同。证明：共享动作空间是多个物理动作空间的商/嵌入，`D_e` 的核不同；取使某一通道在 `e_1` 有效、在 `e_2` 被 mask 的 `a` 即可。系：**跨本体可迁移的是坐标，不是安全；证书必须携带物理解码与规范等价类。**

**引理 34（选择偏差的赢家诅咒下界）** 设每个块的得分估计 `p̂_i=p_i+ε_i`，`ε_i` 独立次高斯（尺度 `σ`），选择 `i*=argmax_i p̂_i`。则
`E[p_{i*}] ≤ E[p̂_{i*}] − σ√(2 ln K) + O(σ/√(ln K))`（在 K 较大、`p_i` 接近时）。证明：`max_i p̂_i ≥ max_i p_i + E[max_i ε_i]`，而 `E[max_i ε_i] ≥ σ√(2 ln K) − σ/(√(2 ln K))`。系：**K 越大，未修正的最高分越高估；必须使用选择感知下置信界或对选择程序做 held-out conformal。**

**引理 35（块承诺的有限最优长度）** 设在块内第 k 步的瞬时风险/陈旧成本 `h(k)` 单调不减，继续执行的边际进展收益 `g(k)` 单调不增，且 `h(1)<g(1)`。则存在有限 `k*` 使 `g(k*)≥h(k*)` 且 `g(k*+1)<h(k*+1)`；超过 `k*` 的承诺期望净收益为负。若前 `k_rev` 步可撤销，则 `k_rev` 提供额外的期权价值，最优承诺不早于 `k_rev` 但不必等于 H。系：**块长不是固定超参；守卫点应放在边际收益/风险交叉附近。**

**引理 36（进展下界消除平凡认证器）** 若目标函数仅为「最大化可认证前缀长度」，则「零位移/原地保持」是全局最优（零新风险、零未知进入）。加入 `progress(W)≥p_min(W)` 或显式 `NoProgress` 出口后，零位移不再是可行计划；若进一步要求 `corr(prefix_length, progress)≥ρ_min`，则「靠振荡/重复探测刷前缀」也被排除。系：**反 Goodhart 不是正则项，而是证书的可行性约束。**

**引理 37（选项组合的可靠性）** 若计划 `π=(ω_1,…,ω_n)` 的每条边满足 `post_{ω_i}⇒pre_{ω_{i+1}}`、拼接残差 `ε_stitch≤ε_max`、每段风险 `r_i≤ε_i`，且 `Σr_i≤ε`，则组合执行的风险 ≤ε；若某条边的前置条件在真实状态中被违反，则计划证书必须在执行前失效，而不是在执行中「边做边猜」。证明：对边做归纳；跨块误差由 `ε_stitch` 吸收，前置/后置链保证状态进入下一选项的有效域。系：**块图上的局部证书可以组合成计划证书，但组合的充分条件是前置/后置链与拼接界，不是「每块都安全」。**

**引理 38（元推理的有限停止）** 若每次采样的成本 `c_sample>0`，`VoI_sample(K)` 随 K 单调不增（边际收益递减），则存在有限 `K*` 使 `VoI_sample(K*)≤0`；同理，若重规划成本 `c_replan>0` 且继续执行的价值随陈旧度递减，则存在有限 `k*` 使继续执行不再优于重规划。系：**「何时停止思考」可证明有限，不是调参。**

**引理 39（规范不变安全断言的迁移半径）** 若 `Safe(e,a,s)` 对 `a~_e a'` 成立，且本体重参数化满足 `D_{h(e)}=R_h∘D_e`，`R_h` 为 `L_h`-Lipschitz，则 `e` 上的安全裕度 `m` 迁移到 `h(e)` 时满足
`m_{h(e)} ≥ m_e / L_h − ε_e`。
证明：物理动作差异被 `L_h` 放大，规范等价类内误差被 `ε_e` 吸收。系：**跨本体迁移的安全半径必须按解码映射的 Lipschitz 常数收缩；不能假设「统一接口」自动带来统一下界。**

**定理 27（严格包含与风险单调）** 在 A111–A116（接口规范可验证、提案选择感知校准有效、选项图前置/后置可检查、块契约可执行、元推理成本有界、R72 假设仍成立）下：CHOICE 在定义 381 的退化条件下逐指令等于 R72/R68；且对任意有效执行，决策级风险界 ≤ R72 风险界（在 R72 风险界上增加选择/接口/承诺/组合项，但所有新项非负）。**安全单调不减；效率只在「接口可信、提案可校准、承诺可撤销、决策有进展」时获益。**

**定理 28（J_CHOICE 有效 ⇒ 决策级风险界）** 若一次执行通过 `J_CHOICE`，则：
(i) `J_EMB` 有效 ⇒ R72 的具身风险界成立；
(ii) 接口规范匹配且支撑度/OOD 通过 ⇒ 共享动作到物理动作的解码在有效域内；
(iii) 选择感知校准有效且 `b_sel_upper` 被扣除 ⇒ 被选中块的真实成功率下界成立；
(iv) `J_PLAN` 有效 ⇒ 前置/后置链、拼接、进展下界、活性成立；
(v) 块契约有效 ⇒ 不可逆后缀前有新鲜证据与守卫；
(vi) 无未解决 D-IVG ⇒ 失败归因已进入台账并触发相应降级。
综上，**决策级执行风险 ≤ ε_choice（相对接口/提案/计划模型）**。证明重量落在「独立 critic 真实独立」与「选择感知 conformal 在分布外仍覆盖」上。

**定理 29（四域无死锁且决策域不阻塞控制域）** 控制域只读计划快照、不等待、不回写；决策域只写计划快照与请求位；计量域只写证据快照；感知域异步写缓冲。由单向无锁环形缓冲 + 版本号，不存在循环等待、优先级反转或活锁。决策域 miss 截止时间只会使控制域继续使用上一份未过期前缀或 `safe_hold`，不会阻塞 1kHz 控制环。**决策可以慢，控制不能等。**

**定理 30（进展活性与安全停止）** 在公平守卫（每个守卫点都被检查）、有限重规划预算、进展审计开启的条件下，执行序列不会无限期停留在 `NoProgress`：若窗口 `W` 内进展低于 `p_min`，系统必须在有限步内进入 `repair`/`replan`/`SAFE_STOP` 之一；若三者都不可行，则 `J_CHOICE` 失效并触发 R68。**「安全地什么都不做」不是合法终止状态；它必须变成一个显式的、可审计的失败出口。**

## 7. 本轮最大风险

**一句话**：CHOICE-GAUGE-RAS 把安全从「相信测量链」转移到「相信 **UniBot 提案分布与独立 critic 在分布外仍可校准**、相信 **54 维共享动作在本体上解码后仍物理等价**、相信 **选择感知 conformal 的覆盖率在赢家诅咒与共因污染下仍成立**、相信 **选项图的前置/后置与进展审计没有被证书目标本身污染**」——如果 UniBot 的提案与 critic 共享同一个训练分布/具身偏差，导致「挑出来的块」恰好是最符合偏差而非最可能成功的块；或者接口版本/mask 在新型号手上静默漂移，使同一共享向量物理语义改变而证书仍显示有效；或者决策层通过振荡、重复探测、选择最容易认证的块把 `progress` 与 `prefix_length` 同时刷高——系统会用一套「每一步都通过认证、每个块都有归因、每份证书都可复算」的决策，在长时程里自信地原地打转、抓错物体或撞上人，事后发现「提案校准当时在有效域内、接口版本当时匹配、进展审计当时通过」，这就是**决策层面的「自信地错自己的选择」**。

次级风险与缓解：

1. **提案者与验证者共因** → 独立 critic 使用不同数据/不同模态/不同本体；随机 held-out 审计；单源提案不定案；共因检测（残差相关、校准同时漂移）触发 `H_unknown` 与拒绝 UniBot。
2. **选择偏差/赢家诅咒被低估** → 选择感知 conformal、下置信界、K 的多重比较惩罚；在线记录 `b_sel`，超阈即增大验证样本或缩短 K。
3. **接口规范/版本漂移** → 强制 `iface_ver + gauge_hash + decode_hash`；跨本体物理等价回放；版本不匹配直接拒绝，不做「尽力解码」。
4. **开环块陈旧/拼接失败** → `k_rev` 可撤销前缀、守卫点、`τ_stale`、`ε_stitch`；不可逆后缀前独立证据门；延迟注入压测。
5. **进展 Goodhart** → 进展下界 + 活性 + `corr(prefix,progress)` 审计 + 外部任务监控；振荡/重复探测判失败；零位移不是合法终止。
6. **元推理失控/决策抖动** → 有限 K、有限承诺、边际 VoI 停止、决策滞回与证书锁定期；决策域 anytime，超时用旧前缀或安全停。
7. **选项组合爆炸** → `|Ω|≤64`、`|E_ω|≤256`、每选项最多 3 个块族；复杂度纳入审计指标。
8. **未知故障被强行归因** → `H_unknown` 开集门；拟合优度/后验熵不足即安全停止；禁止「不明原因重试」。

## 8. 与前序轮次的关系

- **R60 TAGE** 处理「动作块 + VLA 语义接地」，但假设块由单一策略给出、且没有跨本体共享接口；本轮把「块」升级为「选项计划中的运动提案」，并显式处理 **选择偏差/接口规范/决策元推理**。
- **R66 BRIDGE** 用 UniBot-V1 的 54/60 接口做**跨世界配对**；本轮不把 UniBot 当孪生接口，而把它当**跨本体提案源**，重点是「提案 → 选择 → 承诺」的决策审计，而非 sim2real 间隙归因。
- **R70 TELOS-RAS** 处理「意图理解 × 决策规划」；本轮承接其决策价值思想，但把决策对象从「要不要问」扩展到「要不要多采样/承诺多长/何时重规划」，并把 UniBot 提案作为新的不确定性源。
- **R72 EMBODIED-GAUGE-RAS** 提供具身计量与实时执行底座；本轮在其上加**决策域**与**选择/承诺/归因**层，退化时逐指令回到 R72/R68。
