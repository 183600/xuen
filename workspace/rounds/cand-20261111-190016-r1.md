# 第 55 轮（承接第 54 轮 v16+++；新一轮灵感循环第 1 轮；本轮灵感：「论文发表」×「视觉感知」）

> 第 54 轮把技能组合提升为动作-鲁棒性双证书，但所有证书的证据来源仍是**视觉感知**。视觉是整条证据链最脆弱的前端：一个被光照、遮挡、运动模糊或压缩击穿的检测器，会让上游的动作兼容性与鲁棒性谱全部失真。本轮借助「论文发表」这一人类最成熟的主张-证据-审稿-复现-撤稿协议，把视觉感知主张变成 **可预注册、可对抗评审、可复现、可引用、可撤稿** 的工程对象。核心矛盾：**H22**：感知主张的“通过测试”常是审稿分布过拟合（reviewer overfitting），而非真实视觉域鲁棒；**H23**：证书一旦签发就被当作永久真值，但视觉世界会漂移，缺少撤稿与引用边界。

## 0. 直觉与动机

**灵感 1（感知主张 = 投稿：先预注册，再测量）**
直觉：论文发表最值钱的不是结果，而是**在看见数据之前冻结假设与评测协议**。同样，视觉感知不应先跑实验再挑一个好看的指标宣称“鲁棒”，而应先把 `(主张, 视觉域, 指标, 协议, 种子, 多重比较校正)` 写进不可篡改的预注册账本。这样“鲁棒”就不再是事后叙事，而是一个可被审稿人复算的预测。

**灵感 2（审稿人 = 语义保持的视觉扰动董事会）**
直觉：同行评审的本质是“有预算的对抗检查”，不是随机加噪。审稿人施加的扰动必须**保持任务语义不变**（遮挡不能把猫变成狗，模糊不能改变标签），否则就是无效审稿。更进一步，双盲评审对应 **披露预算**：审稿人只回传失败的语义描述（“逆光下小目标漏检”），不直接给原始反例帧，迫使作者做通用修复，而不是记住特定样本。

**灵感 3（复现徽章 = 可复现工件）**
直觉：论文的复现徽章把“我相信”变成“你能重跑”。感知证书也应附带 manifest、种子集、回放轨迹与跨机器校验和；在独立环境重跑偏差超过容差的结果，一律不得签发证书。这直接对抗视觉论文里最常见的“单机单种子最优指标”。

**灵感 4（rebuttal = 修订算子 + 隐藏元审稿人）**
直觉：rebuttal 若只是针对已披露反例打补丁，就会产生 **reviewer overfitting**：在审稿集上通过，在未见视觉扰动上崩溃。因此修订后必须由一组**未参与原审、扰动族不相交的元审稿人**复验；只有“披露反例提升”与“隐藏反例提升”的泛化差足够小，修订才被接受。这把第 53 轮的 Explain 反向解释升级为“有审稿纪律的修复”。

**灵感 5（引用与撤稿 = 证书的生命周期）**
直觉：论文发表不只管“录用”，还管“引用边界”与“撤稿”。感知证书同理：`RPC` 只能在其主张视觉域内被其他任务**引用**（跨域引用视为学术不端/无效迁移）；运行时一旦检测到反例或视觉漂移越过预算，立即**撤稿**并触发降级策略。证书因此有半衰期 `TTL`，而不是一次性永久真值。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（视觉感知主张）**
感知主张 `C = (μ, D_v, φ, θ, α)`：`μ : X → Y` 为感知模型，`D_v` 为视觉条件空间（光照、遮挡、模糊、视角、天气、压缩、传感器噪声、仿真-现实偏移等），`φ(μ,d) = E_{x∼P_{X|d}}[score(μ(x), y)]` 为条件 `d` 下的期望表现。主张断言：
```
P_{d∼D_v}[ φ(μ,d) ≥ θ ] ≥ 1 - α.
```
安全关键子主张可要求逐点形式 `inf_{d∈D_v} φ(μ,d) ≥ θ`。

**定义 122（预注册账本）**
预注册账本 `L = ⟨(h_i, C_i, Π_i, t_i)⟩`，其中 `C_i` 为第 `i` 个子主张，`Π_i` 为冻结的评测协议（数据划分、种子、指标、多重比较校正、停止规则），`t_i` 为时间戳。哈希链
```
h_i = H(h_{i-1} ‖ C_i ‖ Π_i),  h_0 = GENESIS.
```
规则：未出现在 `L` 中的主张不得参与录用；`t_i` 之后修改 `Π_i` 必须作为 **amendment** 追加并重新审稿，否则该主张失效。

**定义 123（语义保持审稿人与审稿董事会）**
扰动 `τ ∈ T` 是**语义保持**的，当且仅当存在任务语义 oracle `O`，使 `O(τ(x)) = O(x)` 对所有评测样本成立。审稿人 `r_τ` 在预算 `B`（`L∞`、LPIPS 或物理可实现约束）内施加 `τ`。审稿董事会 `R = {τ_1,...,τ_m}` 是一组多样性受控的语义保持扰动。判决 `v_r(C) ∈ {accept, minor, major, reject}`。**披露预算** `τ_disc` 限制回传给作者的原始反例数量/分辨率。

**定义 124（审稿覆盖与审稿功效）**
称 `R` 是 `D_v` 的 `(ε, p)`-覆盖，若
```
P_{d∼D_v}[ min_{r∈R} dist(d, d_r) ≤ ε ] ≥ p,
```
其中 `dist` 为视觉-语义度量。审稿功效 `power(R) = sup_{τ∈T_valid} P(τ 被发现 | φ(μ,τ) < θ)`。覆盖管“看得全”，功效管“抓得住”。

**定义 125（可复现工件）**
可复现工件 `A = (M, S, Trace, hash, ε_rep, δ_rep)`：`M` 为环境 manifest，`S` 为种子集，`Trace` 为确定性回放轨迹。称 `C` 关于 `A` 可复现，若在至少 `k` 个独立环境中重跑满足
```
P[ |φ̂(μ,d) - φ(μ,d)| ≤ ε_rep ] ≥ 1 - δ_rep.
```

**定义 126（反驳-修订算子与元审稿）**
修订算子 `Rev : (μ, C, E_rej) → (μ', C')`，`E_rej` 为审稿反例证据，`C'` 为账本中的 amendment。定义修订泛化差
```
Δ_gen = φ_{μ'}(disclosed E_rej) - φ_{μ'}(R_meta),
```
其中 `R_meta` 为与 `R` 扰动族不相交的隐藏元审稿人集。仅当 `Δ_gen ≤ ε_gen` 且 `φ_{μ'}(R_meta) ≥ θ` 时修订有效。

**定义 127（可审稿感知证书 RPC 与撤稿/引用条件）**
```
RPC = (C, L.hash, V, A, ρ, CE, RevHistory, D_claim, TTL, revoke_on, cite_scope)
```
其中 `V` 为审稿判决集合，`CE` 为反例集，`ρ` 为第 53 轮鲁棒性谱，`D_claim ⊆ D_v` 为主张域，`TTL` 为漂移半衰期，`revoke_on` 为撤稿谓词，`cite_scope` 为可引用域。部署条件：
```
accepted_after_FWER(V) ∧ reproducible(A) ∧ cover(R,D_claim) ≥ p_min
∧ Δ_gen ≤ ε_gen ∧ ¬revoke_on(current_world)
```
当运行时发现 `d ∉ D_claim` 或 `φ(μ,d) < θ` 或漂移超过 `Δ_drift`，RPC 进入 `retracted` 状态并触发降级；其他任务只能在 `cite_scope` 内引用 `RPC`，跨域引用必须重新走完整 PAPER 流程。

## 2. 关键算法 伪代码

### IP-121 PRG（Pre-Registration Gate）

```python
def preregister(claim_desc, taxonomy, metrics, seeds, alpha, m):
    subclaims = decompose(claim_desc, taxonomy)          # 按视觉扰动维度拆子主张
    protocol = freeze({
        'splits': split_hash(claim_desc),                # 数据划分先冻结
        'seeds': seeds,
        'metrics': metrics,
        'correction': 'holm',
        'alpha': alpha,
        'stopping_rule': f'fixed_m={m}',                 # 禁止"跑到显著为止"
    })
    h, ledger = H(GENESIS), []
    for c in subclaims:
        h = H(h + c.serialize() + protocol.serialize())
        ledger.append((h, c, protocol, now()))
    commit(ledger)                                       # 外部时间戳/哈希上链
    return ledger
```

### IP-122 ARB（Adversarial Reviewer Board）

```python
def review_board(mu, D, m, oracle, budget, claim):
    R = select_diverse_cover(D, m)                       # 目标 (epsilon,p)-覆盖 + 多样性
    reviews, counterexamples = [], []
    for tau in R:
        xs = sample_conditions(D)
        if not all(oracle.label(tau(x)) == oracle.label(x) for x in xs):
            R.append(resample_semantic_preserving(tau)); continue   # 无效审稿丢弃
        phi = evaluate(mu, [tau(x) for x in xs], claim.metrics)
        verdict = judge(phi, claim.theta, claim.alpha, budget)
        reviews.append((tau.id, phi, verdict))
        if verdict == 'reject':
            ce = min_counterexample(mu, tau, xs)
            counterexamples.append(disclose(ce, budget=claim.tau_disc))  # 只披露语义
    return reviews, counterexamples, coverage_estimate(R, D)
```

### IP-123 REP（Reproducibility Engine）

```python
def reproducibility_audit(mu, artifact, envs, eps_rep):
    phi_hat = [replay(mu, artifact.manifest, artifact.seeds, env) for env in envs]
    spread = max(phi_hat) - min(phi_hat)
    return spread <= eps_rep, {
        'spread': spread, 'hash': artifact.hash,
        'envs': [e.id for e in envs],
    }
```

### IP-124 RBT（Rebuttal with hidden meta-review）

```python
def rebut_and_revise(mu, claim, ce, meta_reviewers, eps_gen):
    mu2 = repair(mu, ce, budget=claim.revision_budget)   # 修复/再训练，不直接记忆反例
    phi_disc = evaluate(mu2, disclosed_conditions(ce))
    phi_meta = evaluate(mu2, meta_reviewers)             # 未披露的隐藏扰动族
    gap = phi_disc - phi_meta
    if phi_meta < claim.theta or gap > eps_gen:
        return ('reject', 'reviewer_overfit', phi_disc, phi_meta, gap)
    return ('revise', mu2, amend_claim(claim, amendment_hash=H(ce, mu2)))
```

### IP-125 RPC Issuer

```python
def issue_rpc(claim, ledger, reviews, rep, rho, meta, drift_model):
    pvals = [review_pvalue(r) for r in reviews]
    if not holm_reject_all(pvals, alpha=claim.alpha):
        return ('reject', 'fwer_unmet')
    if not rep.reproducible:
        return ('reject', 'irreproducible')
    if coverage_estimate(reviews, claim.D_claim) < claim.p_min:
        return ('reject', 'coverage_gap')
    if meta.gap > claim.eps_gen or meta.phi < claim.theta:
        return ('reject', 'overfit_review')
    ttl = drift_model.half_life(claim.D_claim, claim.theta, quantile=0.95)
    return ('accept', RPC(claim, ledger.hash, reviews, rep, rho,
                          ce=collect_ce(reviews), domain=claim.D_claim,
                          ttl=ttl, revoke_on=drift_predicate(claim, drift_model),
                          cite_scope=claim.D_claim))
```

### IP-126 RRC（Runtime Retraction Contract）

```python
def runtime_monitor(rpc, stream, drift_detector, fallback):
    for x, t in stream:
        d = drift_detector(x)
        if d not in rpc.D_claim or confidence(x) < rpc.theta:
            append_retraction_ledger(rpc, evidence=(x, d, t))   # 哈希链追加，不可撤销
            fallback.activate()
            return ('retracted', d, t)
        if t - rpc.issued_at > rpc.ttl:
            fallback.activate()
            return ('expired', t)
    return ('valid',)
```

### IP-127 CXT（Citation Transfer）

```python
def cite_certificate(rpc, target_task, phi_target, delta_domain):
    scope = rpc.cite_scope & target_task.D_claim
    if coverage_estimate(scope, target_task.D_claim) < rpc.p_min:
        return ('reject', 'out_of_scope_citation')
    drift = alignment_drift(rpc.D_claim, phi_target)
    if drift > delta_domain:
        return ('reject', 'citation_drift')
    return ('accept', Citation(rpc, target_task, scope, drift))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| PRG | O(|C|·|Π|) | O(|C|) | 哈希链不可篡改、协议先于数据 |
| ARB | O(m·N·|τ|) | O(m·N) | 语义保持审计、覆盖与多样性 |
| REP | O(k·T_replay) | O(k·|Trace|) | 独立环境、种子集封闭 |
| RBT | O(T_rev + m_meta·N) | O(|μ|+N) | 元审稿族不相交、泛化差有界 |
| RPC | O(m·|C| + |𝔇_ρ|) | O(|C|+|𝔇_ρ|) | FWER 校正、覆盖门槛、TTL |
| RRC | O(1) 摊销/帧 | O(|stream|) | 撤稿即时、降级可执行 |
| CXT | O(|D_scope|) | O(|D_scope|) | 引用域封闭、漂移有界 |

**正确性定理（Reviewable Perception Soundness）**
在以下假设下：
**(A29)** 对固定 `μ`，`φ(μ,·)` 关于视觉度量 `dist` 是 `L`-Lipschitz；
**(A30)** 审稿董事会 `R` 是 `D_v` 的 `(ε,p)`-覆盖；
**(A31)** 语义保持审计通过率 `≥ 1-β_sem`，每个审稿人的误接受率 `≤ α_r`；
**(A32)** 复现审计在 `k` 个独立环境中偏差 `≤ ε_rep` 的概率 `≥ 1-δ_rep`；
**(A33)** 预注册账本不可篡改，修订以 amendment 记录，且元审稿人扰动族 `R_meta` 与 `R` 不相交。

若主张 `C` 以 **margin `θ + Lε`**（即所有被审稿点 `φ ≥ θ + Lε`）通过 `R`、通过 Holm FWER `α`、通过复现、且 `Δ_gen ≤ ε_gen`，则对新鲜视觉条件 `d ∼ D_v`：
```
P[ φ(μ,d) ≥ θ ] ≥ p·(1-β_sem)·(1 - Σ_r α_r)·(1-α) - δ_rep - P(drift > Δ_drift).
```
**证明梗概**：由 (A30)，以概率 `p` 存在审稿点 `d_r` 满足 `dist(d,d_r) ≤ ε`；由 (A29) 与 margin 假设，`φ(d) ≥ φ(d_r) - Lε ≥ θ`。审稿判决的可信度由 (A31) 与 Holm 联合控制，复现与漂移由 (A32)、(A33) 扣除。**关键推论**：证书的 soundness 不是来自“测得多”，而是来自“覆盖得全 + 语义没被审稿人改坏 + 隐藏元审稿没被过拟合 + 世界没漂移”。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 审稿人过拟合（Goodhart） | 高 | 隐藏元审稿 + 轮换审稿池 + 披露预算 τ_disc |
| 语义保持审计失效 | 高 | 任务 oracle 集成 + 人工抽检 + 物理可实现约束 |
| 预注册被绕过/HARKing | 中 | 哈希链 + 第三方时间戳 + amendment 强制重审 |
| 复现剧场 | 中 | 独立环境 + 隐藏种子 + artifact evaluation |
| 视觉世界漂移使证书过期 | 高 | TTL + 漂移监测 + 即时撤稿 + 再认证 |
| 审稿开销拖慢实时闭环 | 中 | 离线全审 + 在线轻量监测的分层审稿 |

## 6. 本轮最大风险

**一句话**：PAPER 协议把视觉感知从“测过就算”提升为“可预注册、可审稿、可复现、可撤稿”，但其 soundness **同时依赖审稿董事会构成视觉扰动域的真实 ε-覆盖、语义保持审计不被绕过、以及隐藏元审稿能拦住披露反例过拟合**；一旦系统把“通过审稿董事会”当成目标而非“在真实视觉世界成立”的手段，就会产出大量 *accepted-but-wrong* 的感知证书，故必须以 **隐藏元审稿 + 语义保持人工抽检 + 运行时撤稿** 三道护栏，宁可不签发，也不把审稿通过当作视觉鲁棒本身。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim + PAPER-Percept（PRG×ARB×REP×RBT×RPC×RRC×CXT）

> 承接第 54 轮产物 v31。本轮把「论文发表」的认知协议工程化，叠加在视觉感知前端之上，形成 **可审稿感知层（Reviewable Perception Layer, RPL）**：
> - **PRG（Pre-Registration Gate）**：主张与评测协议先冻结、后测量；
> - **ARB（Adversarial Reviewer Board）**：语义保持、有预算、可覆盖视觉扰动域的审稿董事会；
> - **REP（Reproducibility Engine）**：跨环境、跨种子的可复现工件；
> - **RBT（Rebuttal with hidden meta-review）**：只做通用修复，隐藏元审稿防 overfitting；
> - **RPC（Reviewable Perception Certificate）**：带 FWER、覆盖率、TTL 与撤稿条件的感知证书；
> - **RRC（Runtime Retraction Contract）**：运行时撤稿与降级；
> - **CXT（Citation Transfer）**：证书的引用域与跨域迁移校验。
>

| `L = ⟨(h_i,C_i,Π_i,t_i)⟩` | 预注册账本（哈希链） |
| `Π_i` | 冻结的评测协议（划分/种子/指标/校正/停止规则） |
| `τ`, `O` | 语义保持扰动、任务语义 oracle |
| `R = {τ_1..τ_m}` | 审稿董事会 |
| `B`, `τ_disc` | 审稿预算、披露预算 |
| `(ε,p)`-覆盖 | `P[min_r dist(d,d_r) ≤ ε] ≥ p` |
| `A = (M,S,Trace,hash,ε_rep,δ_rep)` | 可复现工件 |
| `Rev`, `R_meta`, `Δ_gen` | 修订算子、隐藏元审稿人、修订泛化差 |
| `RPC = (C,L.hash,V,A,ρ,CE,RevHistory,D_claim,TTL,revoke_on,cite_scope)` | 可审稿感知证书 |
| `retracted / expired` | 撤稿 / 过期状态 |

```python
def preregister(claim_desc, taxonomy, metrics, seeds, alpha, m):
```

### IP-122 ARB

```python
def review_board(mu, D, m, oracle, budget, claim):
    R = select_diverse_cover(D, m)
    reviews, ce = [], []
    for tau in R:
        xs = sample_conditions(D)
        if not all(oracle.label(tau(x)) == oracle.label(x) for x in xs):
            R.append(resample_semantic_preserving(tau)); continue
        phi = evaluate(mu, [tau(x) for x in xs], claim.metrics)
        verdict = judge(phi, claim.theta, claim.alpha, budget)
        reviews.append((tau.id, phi, verdict))
        if verdict == 'reject':
            ce.append(disclose(min_counterexample(mu, tau, xs), claim.tau_disc))
    return reviews, ce, coverage_estimate(R, D)

def select_diverse_cover(D, m):
    # 贪心最大化 min-distance + 特征空间熵；目标 (epsilon,p)-覆盖
    return greedy_farthest_point(D, m)
```

### IP-123 REP

```python
def reproducibility_audit(mu, artifact, envs, eps_rep):
    phi_hat = [replay(mu, artifact.manifest, artifact.seeds, e) for e in envs]
    spread = max(phi_hat) - min(phi_hat)
    return spread <= eps_rep, {'spread': spread, 'hash': artifact.hash,
```

### IP-124 RBT

```python
def rebut_and_revise(mu, claim, ce, meta_reviewers, eps_gen):
    mu2 = repair(mu, ce, budget=claim.revision_budget)   # 通用修复，不记忆反例
    phi_disc = evaluate(mu2, disclosed_conditions(ce))
    phi_meta = evaluate(mu2, meta_reviewers)
    gap = phi_disc - phi_meta
    if phi_meta < claim.theta or gap > eps_gen:
        return ('reject', 'reviewer_overfit', phi_disc, phi_meta, gap)
    return ('revise', mu2, amend_claim(claim, amendment_hash=H(ce, mu2)))
```

```python
def issue_rpc(claim, ledger, reviews, rep, rho, meta, drift_model):
    pvals = [review_pvalue(r) for r in reviews]
    if not holm_reject_all(pvals, alpha=claim.alpha):
        return ('reject', 'fwer_unmet')
    if not rep.reproducible:
        return ('reject', 'irreproducible')
    if coverage_estimate(reviews, claim.D_claim) < claim.p_min:
        return ('reject', 'coverage_gap')
    if meta.gap > claim.eps_gen or meta.phi < claim.theta:
        return ('reject', 'overfit_review')
    ttl = drift_model.half_life(claim.D_claim, claim.theta, quantile=0.95)
    return ('accept', RPC(claim, ledger.hash, reviews, rep, rho,
                          ce=collect_ce(reviews), domain=claim.D_claim,
                          ttl=ttl, revoke_on=drift_predicate(claim, drift_model),
                          cite_scope=claim.D_claim))
```

```python
def runtime_monitor(rpc, stream, drift_detector, fallback):
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PRG | O(\|C\|·\|Π\|) | O(\|C\|) | 哈希链不可篡改、协议先于数据 |
| ARB | O(m·N·\|τ\|) | O(m·N) | 语义保持、`(ε,p)`-覆盖、多样性 |
| REP | O(k·T_replay) | O(k·\|Trace\|) | 独立环境、种子封闭 |
| RBT | O(T_rev + m_meta·N) | O(\|μ\|+N) | 元审稿族不相交、`Δ_gen` 有界 |
| RPC | O(m·\|C\| + \|𝔇_ρ\|) | O(\|C\|+\|𝔇_ρ\|) | FWER、覆盖门槛、TTL |
| RRC | O(1) 摊销/帧 | O(\|stream\|) | 撤稿即时、降级可执行 |
| CXT | O(\|D_scope\|) | O(\|D_scope\|) | 引用域封闭、漂移有界 |

**正确性定理（Reviewable Perception Soundness）**
假设 (A29)–(A33) 成立：`φ(μ,·)` 为 `L`-Lipschitz；`R` 为 `(ε,p)`-覆盖；语义保持审计通过率 `≥1-β_sem`、审稿误接受 `≤α_r`；复现偏差 `≤ε_rep` 的概率 `≥1-δ_rep`；账本不可篡改且 `R_meta` 与 `R` 不相交。若主张以 margin `θ+Lε` 通过审稿、Holm FWER、复现与元审稿，则
```
P[φ(μ,d) ≥ θ] ≥ p·(1-β_sem)·(1-Σ_r α_r)·(1-α) - δ_rep - P(drift > Δ_drift).
```
关键：**覆盖**给出“审到即代表”，**语义保持**保证审稿有效，**隐藏元审稿**切断 reviewer overfitting，**运行时撤稿**处理分布漂移。

## 7. 本轮最大风险

**一句话**：PAPER 协议把视觉感知从“测过就算”提升为“可预注册、可审稿、可复现、可撤稿”，但其 soundness **同时依赖审稿董事会构成视觉扰动域的真实 ε-覆盖、语义保持审计不被绕过、以及隐藏元审稿能拦住披露反例过拟合**；一旦系统把“通过审稿董事会”当成目标而非“在真实视觉世界成立”的手段，就会产出大量 *accepted-but-wrong* 的感知证书，故必须以 **隐藏元审稿 + 语义保持人工抽检 + 运行时撤稿** 三道护栏，宁可不签发，也不把审稿通过当作视觉鲁棒本身。
