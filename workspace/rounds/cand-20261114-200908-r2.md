# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「少样本学习」×「上下文理解」）

> R69 问出了「我该向谁求证、还能问什么」，把不确定性一分为二（aleatoric / epistemic），用流匹配多模态策略 + 主动交互去消解歧义。但它仍默认一件未经检验的事：**条件编码 z_t 已经是一个可信的「任务」**。R69 的全部模态分解、VoI 交互与流似然第二意见，都是**以 z_t 为条件**计算的——它度量的是「给定这个任务后，动作有多歧义」，而不是「这个任务本身有多可信」。
>
> 少样本部署恰恰击穿这个前提。z_t 不是从无限数据里学来的任务，而是由 k 个示范 S 和一段上下文 C 诱导出来的**一个点**。两个都完美符合这 k 个示范、却对查询给出相反动作的任务解释，会被同一个 z_t 糊成一个「多模态分布」；R69 的 K 个流采样全部来自同一个 h，于是 K 越大，它只会越自信地描绘**错误的那个任务**下的模态结构。这不是采样不足，而是**结构性的盲区**：**条件错了，条件内的校准再好也没用**。
>
> 本轮两个灵感正好补上这块：
> - **少样本学习**告诉我们：支撑集是任务的一次**抽样**，不是任务本身；少样本的 posterior 主要由**先验**决定，所以必须把「多少来自示范、多少来自先验」显式计量，而不是把 k-shot 微调后的点估计当成学会了；
> - **上下文理解**告诉我们：上下文是**带相关结构的证据集合**，不是一段连续字符串；长度不等于信息，高归因也不等于因果——必须用「归因 × 扰动不变性」把**因果上下文**与**捷径上下文**分开。
>
> 核心命题：**把「任务假设」的不确定性独立成第三通道。U_ale（噪声）沿用 R68 铁律；U_epi（给定任务后的动作模态歧义）交给 R69 的流策略与交互；U_task（支撑集/上下文诱导的任务假设歧义）交给「任务假设后验 + 上下文归因/充分性 + 支撑集影响界 + 主动请求示范/检索」消解。三者正交、分通道处置；只有 U_task 在预算内消解，才继承 R69 的 resolution bonus，否则把未消解项并入 floor，三层退化回 FLUID/R68。** 命名 **SPARC-RAS**（Support-set Posterior with Attribution, Retrieval and Calibration）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我凭什么相信我看到的上下文？我学到的是任务，还是这几个样本的运气？**」——不确定性不只是刹车、提问或注视，也可以是一句「**请再示范一次，而且请示范这个能区分两种解释的例子**」。

## 0. 直觉与动机

**灵感 1（少样本学习 → 支撑集是样本，不是任务）**
直觉：给人看三张猫的图，他学到的是「猫」还是「这三张图的背景」？k 越小，后验越被先验和归纳偏置主导。少样本系统最危险的时刻不是「不会」，而是**用先验的捷径冒充从示范学到的规律**：它会在训练分布内表现完美，因为先验早就猜对了；一旦查询落在这个捷径的边界上，它依然自信。R69 的 z_t 正是这样一个点估计——它把「几个例子支持的多个可能任务」压成了一个条件向量。正确的对象是一个**任务假设后验** q(h|S,C)：不是「我学会了任务」，而是「在这些示范下，哪些任务解释仍然可能，它们在哪里分歧」。
严谨：h ∈ ℋ 表示任务规格 + 接地映射 + 噪声模型的联合假设；q(h|S,C) 由 tempered posterior / in-context particles 表示；查询上的后验预测 disagreement 即 U_task。k 小 ⇒ q 由先验 p_0(h|C) 主导 ⇒ 需要一个「支撑证据质量」m_S 来量化「后验究竟被数据移动了多少」。

**灵感 2（上下文理解 → 上下文是证据集合，不是一段字符串）**
直觉：长上下文里真正决定动作的可能只有两三个 span，其余是 distractor；更糟的是，模型可能高归因地依赖一个**虚假相关**的 span（比如背景颜色、指令的措辞风格），它在原始上下文里看起来很关键，但只要做一次保持语义的改写就崩掉。人类说「我理解了」时，指的是「把关键证据和无关噪声分开了，而且换个说法我仍然懂」，不是「我记住了这段字」。所以「上下文理解」的可操作定义必须同时包含两件事：**归因**（哪些 span 在起作用）与**不变性**（作用是否经得起语义保持的扰动）。
严谨：对上下文分段 {c_m}，归因 a_m 用 KL / Shapley 计量；上下文稳健度 R_ctx 用一组 nuisance 变换 𝒯 下的预测漂移上确界计量。二者构成 2×2 诊断：高归因 + 高不变 = 因果证据；高归因 + 低不变 = 捷径；低归因 + 低不变 = 无关；低归因 + 低不变但查询仍错 = 证据不足，应请求更多示范。

**灵感 3（三通道 → R69 的 K 采样对任务歧义结构性失明）**
直觉：R69 的「歧义就多采样」隐含假设：歧义都在**同一个任务内部**。但如果歧义在**任务之间**，多采样只是把一个错误任务的模态结构画得更精细。就像你让一个听错指令的人「再仔细听一遍自己说的话」——他会更清楚地重复同一个错误。要发现「听错了」，必须换一个信息源：更多示范、一次判别性示范、或一段真正相关的上下文，而不是在同一条件上多采样。
严谨：层次模型 h ~ q(·|S,C)，ξ ~ π_h(·|o)。熵的链式分解给出 H(ξ|o,S,C) = E_h[H(ξ|h,o)] + I(H;ξ|o,S,C)。前者是 R69 能估计的（U_ale + U_epi），后者是 U_task；K 个样本来自**同一个 h**，对 I(H;ξ) 的估计恒为 0，故 ∂Û_task/∂K = 0。这是本轮最重要的结构性结论：**K 解决不了先验错误**。

**灵感 4（主动少样本 → 最好的信息动作可能是「请求一次判别性示范」）**
直觉：R69 的信息动作是看、问、触。但在少样本场景里，最值钱的动作常常是「**能不能就这个例子再做一次给我看**」或「**去记忆里取回那段相关经历**」。这不是被动地多要数据，而是主动选择**最能区分剩余任务假设的那个查询**——问一个 yes/no 可能只排除一个假设，而对一个精心选定的 x* 求一次示范，可能一次性把假设空间砍半。上下文检索同理：不是把上下文变长，而是把**对当前歧义最有判别力的那一段**取回来。
严谨：任务级 VoI 定义为 H(H|S,C) − E_y[H(H|S∪y,C')]；示范查询选择 x* = argmax_x I(H;Y_x|S,C)。条件熵的信息增益对查询集合是**次模**的，贪心达到 (1−1/e) 近似（引理 22）。R69 的 MINT 是「H 退化为单点、动作只含 gaze/probe/ask」的特例。

**灵感 5（双刃剑 → 少样本 + 上下文带来新的投毒面与「自证陷阱」）**
直觉：k 小意味着**单个示范的杠杆极大**：一条投毒示范就能把后验收买；一段藏在长上下文里的注入指令就能改写任务；而最阴险的是「自证」——系统用自己选出的少数样本来估计「影响界」和「上下文充分性」，再用这些估计给自己盖章。**少样本的自信会伪装成上下文理解**。因此必须同时交付：支撑集影响界（单个样本不得决定结论）、归因-不变性交叉验证（高归因不等于因果）、上下文/支撑预算与安全优先序、以及「单次示范/单段上下文不得单独定案」的证据纪律。否则 R70 不是进步，而是给 R69 装了一个**用几个例子就能骗过的认证器**。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（SPARC-RAS 总览）** SPARC-RAS = (TBP, UTD, CAA, CFP, SIB, AIR, TCG, CBG, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **上下文/支撑预算硬约束**：支撑集 k ≤ k_max、上下文长度 L ≤ L_max、检索条数 r ≤ r_max、请求示范 ≤ 1 次/单位时间，且所有信息动作必须通过与任务动作相同的 C-RAS-WM‡ 认证；
(iii) **证据纪律（继承并扩展）**：单个示范、单段上下文、单次检索不得单独改变认证动作模式；需影响界（定义 317）与至少两个正交证据源一致；
(iv) **安全优先序**：safety spec ≻ 指令 ≻ 示范 ≻ 上下文先验；任何冲突只允许向安全侧退化（定义 323）。

**定义 311（少样本上下文）** 支撑集 S = {(x_i, y_i, c_i)}_{i=1}^{k} ~ p_task，查询为 (x_q, c_q)；上下文 C = (I, c_q, M)，其中 I 为指令/规格、M 为可检索记忆。任务假设 h ∈ ℋ 表示「任务规格 + 观察→动作的接地映射 + 噪声模型」的一个联合解释。编码器 Φ 不再输出点 z，而是输出 q(h|S,C) 的参数化或粒子表示。

**定义 312（任务假设后验 TBP）** 采用温度后验
q(h|S,C) ∝ p_0(h|C) · exp( Σ_{i=1}^{k} ℓ(h; x_i, y_i, c_i) / T )，
其中 p_0 为先验、T 为温度（T>1 抑制少样本过拟合，对应 singular/tempered posterior）；亦可用 deep ensemble / last-layer Laplace / in-context particles 实现。每个粒子 h_j 诱导 R69 的流策略条件 z_j = Φ_{h_j}(S,C) 与模态分布 π_{h_j}(ξ|o)；后验预测 p(ξ|o,S,C) = E_{h~q}[π_h(ξ|o)]。

**定义 313（三通道不确定性分解 UTD）** 在层次模型 h ~ q(·|S,C)、ξ ~ π_h(·|o) 下：
- **U_ale** = E_h E_{m~w_h} H(ξ | h, m)（模态内噪声；高斯近似下即 R69 的 Σ_k ŵ_k tr Σ_k）；
- **U_epi** = E_h H(M | h)（给定任务后的动作模态歧义；R69 的 H_mode·g(Δ_min)）；
- **U_task** = I(H; ξ | o, S, C)（任务假设歧义；跨粒子的后验预测 disagreement）。
熵的链式分解严格给出 H(ξ|o,S,C) = U_ale + U_epi + U_task（同一模态粒度下）。**结构盲区**：R69 的 K 个样本是在**同一 h** 下的独立采样，只能估计前两项；对第三项，∂Û_task/∂K = 0。降低 U_task 只能靠：增加有效支撑、请求判别性示范、检索相关上下文，或降低先验的过度自信。

**定义 314（上下文归因 CAA）** 把 C 分成 span {c_m}_{m=1}^{M}。归因
a_m = E_{h~q}[ KL( p(ξ|o,S,C) ‖ p(ξ|o,S,C_{−m}) ) ]，
或用满足效率性的 Shapley 值 φ_m。上下文有效质量 ρ_eff = (Σ_{m∈TopK} a_m) / (Σ_m a_m)，归因熵 H_attr = −Σ_m (a_m/Σa) log(a_m/Σa)。ρ_eff 高且 H_attr 低 ⇒ 上下文由少数关键片段支撑；H_attr 高 ⇒ 证据弥散，可能被大量 distractor 稀释。

**定义 315（上下文脆弱性探针 CFP）** 令 𝒯_nuis 为一组**保持任务语义**的上下文变换（改写、重排、注入 distractor、风格迁移、拼接无关长文）。定义上下文稳健度
R_ctx = 1 − sup_{t∈𝒯_nuis} D( p(ξ|o,S,C) ‖ p(ξ|o,S,t(C)) ) / D_max。
R_ctx < τ_ctx ⇒ 判「spurious context reliance」：高归因但一变就崩，说明上下文只是捷径而非因果证据。**归因-不变性对偶**（引理 21）：因果证据 = 高 a_m ∧ 高 R_ctx；捷径证据 = 高 a_m ∧ 低 R_ctx；无关上下文 = 低 a_m；重要但证据不足 = 低 a_m ∧ 低 R_ctx（应请求更多示范）。

**定义 316（上下文充分性证书 CSC）** 对查询而言，上下文充分需同时满足：
(a) **稳健**：R_ctx ≥ τ_ctx；
(b) **集中**：ρ_eff ≥ ρ_min；
(c) **支撑证据质量**：m_S = 1 − H(q(h|S,C)) / H(p_0(h|C)) ≥ m_min（后验相对先验的熵降比例；m_S 小 ⇒ 结论由先验而非示范决定）；
(d) **低冲突**：不存在两个后验质量均 > w_conf 的假设 h, h'，其在查询上的预测显著不同（定义 323）。
任一不满足 ⇒ U_task 不可在本次上下文内消解，走三层退避（定义 322）。

**定义 317（支撑集影响界 SIB）** 对每个示范 i，定义影响
I_i = E_{h~q(·|S)}[ KL( p(ξ|o,S,C) ‖ p(ξ|o,S\i,C) ) ]（或预测分布的 Cook 距离 / BIF）。
SIB 要求 max_i I_i ≤ τ_infl，且 held-out 探针（留出一个示范作伪验证）上的后验预测漂移 ≤ τ_hold。越界 ⇒「支撑集脆弱」：一个样本决定了结论，不能认证；优先请求额外示范，或退回 R69。**注意**：影响界本身也是估计量，必须用留一 + bootstrap + 外部探针交叉核验，不能只看训练样本上的自报值。

**定义 318（少样本威胁集 ℰ_support）** 投毒示范（标签/动作被篡改）、后门触发器（支撑集中植入特定视觉/语言触发）、上下文注入（在长上下文或记忆中植入指令）、矛盾上下文、记忆投毒。并入 AIC：ℰ_SPARC = ℰ_FLUID × ℰ_support（继承 R69 的 ℰ_CALM × ℰ_poison × ℰ_flow）。

**定义 319（主动少样本交互 AIR）** 扩展信息动作 g ∈ {g_gaze, g_probe, g_ask, g_demo, g_retrieve}。g_demo(x*) 请求人类对选定查询 x* 给一次示范；g_retrieve(m) 从记忆取回 span c_m。任务级 VoI：
VoI_task(g) = H(H|S,C) − E_{y~p(·|g)}[ H(H | S∪y, C') ]。
选择 g* = argmax_g [ VoI_task(g) + VoI_mode(g) − c(g) ]，s.t. 预算与认证。示范查询 x* = argmax_x I(H; Y_x | S,C)（贪心，次模，引理 22）。R69 的 MINT 是「H 退化为单点、g 只含 gaze/probe/ask」的严格特例。

**定义 320（上下文/支撑预算 CBG）** 联合预算 B = (k_max, L_max, r_max, n_int_max, c_max)；AIR 在预算内最大化期望 U_task 下降。任何 g_demo / g_retrieve 都计入 R69 的交互预算并过 C-RAS-WM‡。**上下文长度不是目标**：仅当 VoI_ctx(m) = ΔU_task(m) − c_retrieve(m) > 0 时才检索；更长的上下文可能引入更多捷径与攻击面。

**定义 321（任务后验校准门 TCG）** 校准 q(h|S,C) 与后验预测：ECE_task ≤ τ_ece_task；有效样本量 n_eff = (Σ_i w_i)² / Σ_i w_i² ≥ n_min（w_i 为支撑样本的后验权重/影响归一化）；支撑证据质量 m_S ≥ m_min。任一越界 ⇒ 禁用 AIR 的任务级决策，退化为 R69 的 FLUID（只用 z_t 的模态层），U_task 按未消解处理。

**定义 322（三层保守退避与风险耦合）**
- U_task 在预算内消解（CSC 通过、AIR 成功、SIB/TCG 通过）⇒ λ = λ_floor(U_ale)（同时获得 task 与 mode 的 resolution bonus，但绝不低于 R69 的安全）；
- U_task 未消解但 U_epi 已消解 ⇒ λ = λ_floor(U_ale + U_task)；
- 两者都未消解 / CSC 失败 / SIB 越界 / TCG 越界 / 冲突 ⇒ λ = λ_floor(U_ale + U_epi + U_task)，并进一步退 R69 → R68。
安全侧：**未消解的量一律并入 floor，λ 单调不减**；任何不确定只向保守方向退化。

**定义 323（上下文冲突与优先序）** 若 safety spec 与指令/示范/上下文冲突，safety 胜；若指令与示范冲突且无法消解，向指令与安全侧退化，示范进入隔离缓冲；若两个上下文 span 支持相反动作且后验质量接近，标 conflict，不执行模态选择，请求澄清或退保守。**绝不用示范覆盖安全规格**（这是 R68 换装不变式的上下文版）。

**定义 324（证书 J_SPARC）** J_SPARC = (J_FLUID, n_eff, m_S, U_task_before/after, influence_max, R_ctx, ρ_eff, H_attr, demo_cost, conflict_flag, sparc_ver)。Valid ⇔ Valid(J_FLUID) ∧ TCG 通过 ∧ SIB 通过 ∧（若使用任务级消歧）CSC 通过 ∧ 证据纪律满足 ∧ 上下文/支撑预算未越界。

**定义 325（参与式上下文审计 VQAuditor-X）** 审计对象新增：单个示范是否决定性、上下文归因是否集中在虚假 span、示范请求是否诱导/越权、检索是否带毒、示范是否与安全规格冲突。结论回灌 AuditBuf，成为下一轮 AIR 的成本先验与 TCG 的先验。

**定义 326（严格包含与自适应门控）** 当 k→∞ 且 CSC 通过时，q(h|S,C) → δ(h*)，U_task → 0，AIR 的 VoI_task ≤ 成本 ⇒ SPARC 逐指令退化为 FLUID；当 TCG/SIB/CSC 失败时，逐指令退化为 FLUID 或 R68。默认 P=1（单粒子）常规路径，仅当廉价的 task_head 预测 U_task > TAU_TASK 时升 P=4/8；归因/脆弱性/影响界仅在触发时**异步**计算，保证 P99 实时预算。

## 2. 关键算法骨架

```python
# IP-264/265 TBP + UTD：任务后验与三通道分解
class TaskPosterior:
    def __init__(self, prior, encoder, flow, P=1):
        self.prior, self.enc, self.flow = prior, encoder, flow
        self.P = P

    def particles(self, S, C, P):
        # 温度后验 / in-context particles：返回 h_j 诱导的条件 z_j
        return [self.enc(h, S, C) for h in sample_posterior(self.prior, S, C, P)]

    def predictive(self, o, S, C, P):
        return mixture([self.flow.sample(o, z=z_j) for z_j in self.particles(S, C, P)])

    def decompose(self, o, S, C, P, K):
        zs = self.particles(S, C, P)
        U_ale = mean(within_mode_entropy(self.flow.sample(o, z, K)) for z in zs)
        U_epi = mean(mode_entropy(self.flow.sample(o, z, K)) for z in zs)
        U_task = mutual_info_H_xi(zs, o, S, C)   # 跨粒子，与 K 无关
        return U_ale, U_epi, U_task

# IP-266/267 CAA + CFP：归因与不变性
def context_audit(predictive, S, C, spans, nuisances):
    base = predictive(S, C)
    a = [kl(base, predictive(S, C.without(m))) for m in spans]
    rho = top_mass(a, topk=3)
    R = 1.0 - max(distance(base, predictive(S, t(C))) for t in nuisances)
    return a, rho, R

# IP-268 SIB：支撑集影响界（留一 + bootstrap）
def influence_bound(predictive, S, C, o):
    infl = [kl(predictive(S, C, o), predictive(S.without(i), C, o))
            for i in range(len(S))]
    hold = holdout_drift(predictive, S, C, o)    # 留一个示范做伪验证
    return max(infl), hold

# IP-269 AIR：任务级 VoI 选择（示范 / 检索 / 看 / 问 / 触）
def choose_info_action(particles, modes, S, C, o, budget):
    cands = list(info_actions(modes))                       # R69: gaze/probe/ask
    cands += [demo(x) for x in discrim_queries(particles, C)]  # 判别性示范
    cands += [retrieve(m) for m in memory_spans(C)]            # 检索相关上下文
    best = None
    for g in cands:
        if not budget.allow(g):                    continue
        if not c_ras_wm.certify_info(g, o):        continue
        score = (mi_task(particles, g) + mi_mode(modes, g)) - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-275 主闭环（默认 = R69；仅任务歧义时插入 SPARC 层）
def SPARC_round(M, obs, S, C):
    z, o   = M.mtm.forward(...); M.cof.step(...)
    K      = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(o, K), z)
    # 1) 廉价任务歧义门；默认 P=1 与 R69 完全一致
    P      = 1 if M.tbp.task_head(z) < TAU_TASK else 8
    U_task = M.tbp.decompose(o, S, C, P, K)[2]
    resolved_task = False
    if U_task > TAU_TASK:
        # 2) 触发式上下文审计（异步可接受）
        a, rho, R = M.caa.audit(M.tbp, S, C)
        m_S       = M.tbp.evidence_mass(S, C)
        infl, hold = M.sib.influence(M.tbp, S, C, o)
        csc = (R >= TAU_CTX and rho >= RHO_MIN and m_S >= M_MIN and not M.conflict(S,C))
        # 3) 只在证书全部通过时才主动消歧
        g = None
        if csc and infl <= TAU_INFL and M.tcg.ok(S, C):
            g = M.air.choose(M.tbp.particles(S,C,P), modes, S, C, o, M.budget)
        if g is not None:
            S, C = M.air.execute(g)                 # 示范或检索，带认证
            U_task = M.tbp.decompose(o, S, C, P, K)[2]
            resolved_task = (U_task <= TAU_TASK)
    # 4) 三层退避：未消解项一律并入 floor
    if resolved_task:
        U_floor = U_ale                              # task + mode resolution bonus
    elif U_epi <= TAU_EPI:
        U_floor = U_ale + U_task                     # 仅 task 未消解
    else:
        U_floor = U_ale + U_epi + U_task             # 都未消解 → R69/R68
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    A   = M.ach.propose(x_prime, H=M.vista.H)
    k   = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if not (resolved_task or M.tcg.ok(S, C)):        # 证书失败：最保守
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(A, M.cal))
    # 5) 审计与证书
    M.vqa_x.submit_async(g, U_task, infl, R, rho, m_S)
    return k, lam, (U_ale, U_epi, U_task), resolved_task
```

## 3. 推导

**引理 19（三通道精确分解与采样盲区）** 在 h ~ q(·|S,C)、ξ ~ π_h(·|o) 的层次模型下，熵的链式法则给出
H(ξ|o,S,C) = E_h[H(ξ|h,o)] + I(H; ξ|o,S,C) = U_ale + U_epi + U_task。
若 R69 用同一条件 z（对应单一 h）采 K 个样本，则其对 U_task 的估计恒为 0 且与 K 无关（∂Û_task/∂K = 0）；增加 K 只能压低 U_ale/U_epi 的估计方差。系：**R69 的自适应 K 对任务歧义结构性失明**——先验错了，多采样只会把错误画得更清楚；要降低 U_task，必须增加跨 h 的证据（支撑、示范、检索或先验修正）。

**引理 20（支撑影响界 ⇒ 少样本投毒鲁棒）** 设后验预测对单个示范的对数似然扰动满足有界影响，且 max_i I_i ≤ τ_infl。若 S 中至多有 m 个示范被投毒/篡改，则干净与投毒后验预测之间的 TV 距离 ≤ 2m·τ_infl（KL 版本 ≤ 2m·τ_infl）；当 2m·τ_infl 小于模态分离裕度时，认证动作模态不变。反之，若某示范影响无界（典型后门触发器），单个投毒样本即可把后验质量任意搬移，任何证书都不成立。系：**SIB 把 R69 的「k 源一致」从证据源扩展到了样本扰动维度**，是少样本投毒的第一道可证界；但它必须用留一/外部探针估计，不能用训练样本自报值（见本轮最大风险）。

**引理 21（归因-不变性对偶）** 设 t ∈ 𝒯_nuis 只改变 nuisance 属性而保持任务语义。若 span c_m 的影响经由因果机制，则 p(ξ|o,S,C) 在 t 下不变，其归因 a_m 保持；若影响经由 nuisance 捷径，则 t 会显著改变预测而 a_m 仍高。因此二元组 (a_m, R_ctx) 可把「高归因的捷径」与「高归因的因果证据」分开：仅用 attention/Shapley 会被捷径骗过，必须加扰动不变性做第二意见。系：与 R68「残差通道 + 行为似然通道」、R69「模态 + 流似然」同构——**任何单通道的「重要性」都不可信，必须有一条不变性通道交叉验证**。

**引理 22（主动示范的次模性与样本复杂度）** 对任意 H 上的分布，信息增益 I(H; Y_x) 关于查询集合是次模的；贪心选择示范查询达到最优熵降的 (1−1/e) 近似（Nemhauser–Wolsey）。若要以误差 ≤ ε 区分 |ℋ| 个假设，任何自适应方案至少需要 Ω(log|ℋ|/ε) 比特证据；在有界噪声下贪心在 log 因子内最优。系：**一次精心选择的判别性示范，胜过多次无判别力的「是/否」提问**；AIR 的查询选择是次模优化，不是启发式。

**定理 18（SPARC 严格包含 FLUID/R68）** 在定义 310 的不变式下：当 k→∞ 且 CSC 通过时，q(h|S,C) → δ(h*)、U_task → 0，AIR 的任务级 VoI ≤ 成本而不触发，SPARC 的三层 floor 严格退化为 R69 的两层 floor，且逐指令相同；当 TCG/SIB/CSC 任一失败时，SPARC 把未消解项并入 floor 并退化为 FLUID 或 R68。故任意状态上的期望风险 ≤ FLUID ≤ R68，安全侧单调不弱，效率侧在可认证时获得 resolution bonus。

**定理 19（少样本投毒安全与证据纪律）** 在 SIB（max influence ≤ τ_infl）、证据纪律（单示范/单 span 不得定案）与 TCG 同时成立时，m 个被投毒/篡改的支撑项只有在其累积影响 m·τ_infl 超过模态分离裕度时，才可能改变认证动作模态；否则证书无效并退 R69/R68。若各证据源欺骗相关 ρ<1、采用 k 个正交源多数一致，则认证错误模态的概率 ≤ δ_p·ρ^{k−1} + ε_σ（继承 R69 引理 18）。故**单发后门不能被「认证」**。

**定理 20（上下文冲突的安全优先与无突变）** 在优先序 safety ≻ 指令 ≻ 示范 ≻ 上下文先验下，任何会选出更低安全模态的冲突都被拒绝；AIR 的示范/检索动作经 C-RAS-WM‡ 认证后物理风险 ≤ ε_int；当冲突/SIB/TCG 失败时，λ 单调不降地退向 R68。故少样本/上下文自适应永不扩张安全包络，且保持 R69 定理 17 的控制连续性与换装不变式 ⇒ 无突变。

## 6. 本轮最大风险

**一句话**：SPARC 的证书是用它要认证的那几个样本自己算出来的——**当 k 很小时，影响界、归因与证据质量 m_S 的估计方差大于它们要界定的效应，系统会把「样本巧合 + 编码器先验捷径」认证成「上下文充分、支撑稳健」；于是它不是用上下文理解任务，而是用少样本的自信伪造出「我已经理解了」**。R69 的风险是「问错比不问更危险」，R70 的风险是「**看得越少，越敢盖章**」：一个其实来自先验偏见的动作，被盖上「可验证、上下文充分」的章。

**次级风险与缓解**：
1. **任务后验被先验主导**（k 小，粒子退化为先验采样）→ m_S / n_eff 显式计量 + TCG 门 + 温度后验 + 先验外审；
2. **归因器自身有捷径**（把 spurious span 当成因果）→ 归因-不变性交叉验证（定义 315）+ 外部红队 + 人类研究 E304；
3. **影响界估计方差大/可被共谋隐藏** → 留一 + bootstrap + held-out 探针 + 多评审，不用训练样本自报值；
4. **少样本投毒 / 上下文注入** → ℰ_support 对抗训练 + SIB + 证据纪律 + 单发后门不可认证（定理 19）；
5. **长上下文实时预算被击穿** → task_head 廉价门控 + 自适应 P + 归因/CFP/SIB 全部异步；
6. **示范请求越权或社交成本过高** → CBG 预算 + C-RAS-WM‡ 认证 + 安全优先序（定理 20）。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** SPARC-RAS = (TBP, UTD, CAA, CFP, SIB, AIR, TCG, CBG, RAS-WM‡)；继承 R69 零学习实时写操作；上下文/支撑预算硬约束（k/L/r/示范次数）；证据纪律（单示范、单 span、单次检索不得定案，需影响界 + 正交源一致）；安全优先序 safety ≻ 指令 ≻ 示范 ≻ 上下文先验。

**定义 311–312（少样本上下文与 TBP）** S 与 C 诱导 `q(h|S,C) ∝ p_0(h|C)·exp(Σ_i ℓ(h;x_i,y_i,c_i)/T)`；每个粒子 h_j 诱导 z_j 与 π_{h_j}(ξ|o)；后验预测 `p(ξ|o,S,C)=E_h[π_h(ξ|o)]`。点条件 z_t 被后验分布替代。

**定义 313（UTD 三通道分解）** `H(ξ|o,S,C)=U_ale+U_epi+U_task`；`U_task=I(H;ξ|o,S,C)`。R69 的 K 采样来自同一 h：`∂Û_task/∂K=0`，只能降 U_ale/U_epi 的估计方差——**K 解决不了先验错误**。

**定义 314–315（CAA + CFP）** `a_m=E_h[KL(p(ξ|C)‖p(ξ|C_{−m}))]`，`ρ_eff=TopK 质量占比`，`H_attr=归因熵`；`R_ctx=1−sup_{t∈𝒯} D(p(ξ|C)‖p(ξ|t(C)))/D_max`。归因-不变性对偶：高 a_m+高 R_ctx=因果；高 a_m+低 R_ctx=捷径；低 a_m=无关/证据不足。

**定义 316（CSC 上下文充分性）** 需同时满足：稳健 `R_ctx≥τ_ctx`；集中 `ρ_eff≥ρ_min`；支撑证据 `m_S≥m_min`；低冲突（无两个高后验质量假设在查询上显著分歧）。任一不满足 ⇒ U_task 未消解。

**定义 317（SIB 支撑影响界）** `I_i=E_h[KL(p(ξ|S)‖p(ξ|S\i))]`；要求 `max_i I_i≤τ_infl` 且 held-out 探针漂移 `≤τ_hold`。越界 ⇒ 支撑集脆弱，单样本决定结论，不可认证。

**定义 318–320（威胁/主动/预算）** `ℰ_SPARC=ℰ_FLUID×ℰ_support`；信息动作 `g∈{gaze,probe,ask,g_demo,g_retrieve}`，`g*=argmax[VoI_task+VoI_mode−c]`；示范查询 `x*=argmax_x I(H;Y_x|S,C)`（次模贪心）；联合预算 `B=(k_max,L_max,r_max,n_int_max,c_max)`，仅当 `VoI_ctx(m)−c_retrieve(m)>0` 才检索。

**定义 321（TCG 校准门）** `ECE_task≤τ_ece_task`、`n_eff≥n_min`、`m_S≥m_min`；越界即禁用 AIR 的任务级决策，退回 FLUID，U_task 按未消解处理。

**定义 322（三层退避）** task 消解 ⇒ `λ=λ_floor(U_ale)`；仅 epi 消解 ⇒ `λ=λ_floor(U_ale+U_task)`；都未消解/证书失败/冲突 ⇒ `λ=λ_floor(U_ale+U_epi+U_task)` 再退 R69/R68。未消解项一律并入 floor，λ 单调不减。

**定义 323–326（冲突/证书/审计/包含）** safety spec 冲突时胜；示范不得覆盖安全规格；`J_SPARC` 并入 n_eff、m_S、U_task±、influence_max、R_ctx、ρ_eff、H_attr、conflict_flag；VQAuditor-X 审「单示范决定性 / 归因捷径 / 诱导示范 / 带毒检索」；`k→∞ ∧ CSC` ⇒ 逐指令退化为 FLUID，证书失败 ⇒ 退回 FLUID/R68；默认 P=1，仅 task_head 触发时升 P=4/8。

def context_audit(predictive, S, C, spans, nuisances):
    base = predictive(S, C)
    a    = [kl(base, predictive(S, C.without(m))) for m in spans]
    rho  = top_mass(a, topk=3)

## 4. 推导

**引理 19（三通道精确分解与采样盲区）** 层次模型下 `H(ξ|o,S,C)=E_h[H(ξ|h,o)]+I(H;ξ|o,S,C)=U_ale+U_epi+U_task`。同一 h 下的 K 个流采样对第三项的估计恒为 0 且与 K 无关（`∂Û_task/∂K=0`）；增加 K 只压低前两项的估计方差。系：**R69 的自适应 K 对任务歧义结构性失明**，先验错了，多采样只会把错误画得更清楚。

**引理 20（支撑影响界 ⇒ 少样本投毒鲁棒）** 若有界影响且 `max_i I_i≤τ_infl`，至多 m 个投毒示范使后验预测 TV 漂移 `≤2m·τ_infl`；当该值小于模态分离裕度时认证动作模态不变。反之影响无界（后门触发器）时，单个样本即可任意搬移后验质量。系：SIB 把 R69 的「k 源一致」扩展到样本扰动维度；但影响界必须用留一/外部探针估计，不能用训练样本自报值。

**引理 21（归因-不变性对偶）** 语义保持扰动 t∈𝒯 只改 nuisance 属性：因果 span 的预测在 t 下不变、a_m 保持；捷径 span 的预测在 t 下显著变化而 a_m 仍高。故 `(a_m,R_ctx)` 可分离因果/捷径/无关/证据不足；仅用 attention/Shapley 会被高归因捷径骗过。

**引理 22（主动示范的次模性）** 信息增益 `I(H;Y_x)` 对查询集合次模，贪心达到最优熵降的 `(1−1/e)`；区分 |ℋ| 个假设至少需 `Ω(log|ℋ|/ε)` 比特证据。系：一次判别性示范胜过多次无判别力的 yes/no 提问，AIR 的查询选择是次模优化而非启发式。

**定理 18（SPARC 严格包含 FLUID/R68）** `k→∞ ∧ CSC` 时 `q→δ, U_task→0`，AIR 不触发，三层 floor 退化为 R69 两层 floor 且逐指令相同；TCG/SIB/CSC 任一失败时未消解项并入 floor 并退回 FLUID/R68。故期望风险 ≤ FLUID ≤ R68，安全侧单调不弱，可认证时获得 resolution bonus。

**定理 19（少样本投毒安全）** SIB + 证据纪律 + TCG 同时成立时，m 个投毒项只有累积影响 `m·τ_infl` 超过模态分离裕度才可能改变认证模态；否则证书无效并退回。k 个正交源（欺骗相关 ρ<1）多数一致时错误认证率 ≤ `δ_p·ρ^{k−1}+ε_σ`（继承 R69 引理 18）。单发后门不能被认证。

**定理 20（上下文冲突的安全优先与无突变）** 优先序 safety ≻ 指令 ≻ 示范 ≻ 先验下，任何选出更低安全模态的冲突被拒绝；AIR 动作经 C-RAS-WM‡ 认证后物理风险 ≤ ε_int；冲突/证书失败时 λ 单调不降退向 R68；保持 R69 定理 17 的控制连续性与换装不变式 ⇒ 无突变。

## 7. 本轮最大风险

**一句话**：SPARC 的证书是用它要认证的那几个样本自己算出来的——**当 k 很小，影响界、归因与 m_S 的估计方差大于它们要界定的效应，系统会把「样本巧合 + 编码器先验捷径」认证成「上下文充分、支撑稳健」；它不是用上下文理解任务，而是用少样本的自信伪造出「我已经理解了」**。R69 的风险是「问错比不问更危险」，R70 的风险是「**看得越少，越敢盖章**」。

**次级风险与缓解**：任务后验被先验主导（m_S/n_eff + TCG + 温度后验 + 先验外审）；归因器自身有捷径（归因-不变性交叉验证 + 外部红队 + E304）；影响界方差大/可被共谋隐藏（留一 + bootstrap + held-out 探针 + 多评审）；少样本投毒/上下文注入（ℰ_support + SIB + 证据纪律 + 定理 19）；长上下文实时预算（task_head 门控 + 自适应 P + 全部异步）；示范请求越权/社交成本（CBG + C-RAS-WM‡ + 安全优先序，定理 20）。
