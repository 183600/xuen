# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；灵感循环第 2 轮；本轮灵感：「模型蒸馏」×「应用落地」）

> 第 59 轮已经把「执行层物理」接进了安全论证链：BUQ 在线辨识电机结构性不确定性，ERTC 把嵌入式时序不确定性契约化，EEIS 把高层 δ_f 编译成阻抗参数与证书，CLEP 让执行实测作为第 5 个模态回传证据层。但这一整套仍是**「研究态的教师」**：它假定算力无限、每次接触都能跑 UKF+μ 分析+跨模态对账，假定证据只在单次任务内有效、联合界 `P_safe ≥ 1 − Σ_cp(...)` 只在一次运行里成立，假定证书一旦签出就永远为真。真实落地会同时击穿这三点：**（1）边缘机器人没有算力跑完整教师，必须蒸馏成小模型——但朴素蒸馏只模仿输出、不搬运证书，尾部区域「证书蒸发」；（2）部署地平线 H 是 10⁶ 次接触、数年、成百上千台机器人，逐检查点联合界线性膨胀到毫无意义，实验室几百个 episode 无法为「车队年」背书；（3）数据飞轮（现场数据→重训→蒸馏→OTA）是增长引擎，但每次 OTA 都在静默改变学生、让证书失效，分布漂移又让已认证区域 R_cert 悄悄收缩——飞轮可能变成「安全债累积机」**。本轮两个灵感精准对应：**「模型蒸馏」**要求把教师的能力**连同证书一起**压缩到可部署学生；**「应用落地」**要求把「单次证明」升级为**任意时间有效、持续续约、可审计、可召回**的运行安全论证。核心命题：**「蒸馏的是证书而不是输出；落地的是持续有效的论证而不是一次性的分数；每一次更新都必须过证书门，且商业成本永远只能在安全底线之上经营。」**

核心矛盾：

- **H32（蒸馏抽象泄漏·证书蒸发）**：朴素蒸馏最小化训练分布上的输出 MSE/KL，学生只在「演示分布」上像教师；一旦进入训练稀疏的尾部（高刚度接触、低电流死区、突发扰动），学生输出**不再落在 K_safe**，而教师的安全证书（μ 分析、共形覆盖、ERTC 硬界）并不会自动转移给学生。结果是**「学生演示很稳、部署尾部失效」**——这是第 59 轮执行抽象泄漏在部署维度的重演。
- **H33（部署地平线·联合界失效）**：第 59 轮的 `P_safe ≥ 1 − Σ_cp(...)` 是一次运行的联合界；部署地平线 H 上接触数是 10⁶~10⁸ 量级，线性求和使下界变成负数。用实验室 E182–E186（数百 episode）去认证车队年，等于用一次性体检证明终身健康。**必须把「逐次联合界」换成「任意时间有效的序贯证据」+「运行设计域（ODD）分域认证」+「安全论证有 TTL、到期续约」**。
- **H34（更新即风险·飞轮变安全债）**：数据飞轮每转一圈就产生一个**新学生版本**，每个版本都可能改变 R_cert、改变尾部行为；若 OTA 不做证书感知门控，则「越更新越不安全」且无人察觉。漂移还会让现场分布缓慢离开认证域，若不检测就「带着过期证书裸奔」。**更新不是免费的增长，而是从安全预算里支取的安全债**，必须记账、限额、可回滚、可召回。

## 0. 直觉与动机

**灵感 1（模型蒸馏 → 证书保持蒸馏 CPD）**
直觉：教师 `π_T`（完整 CLEP+EEIS 管线）是「会做且知道为什么安全」的专家；学生 `π_S` 是「跑得动」的学徒。普通蒸馏只让学徒模仿专家的**动作**，却把专家**为什么安全的那本证书**留在实验室。正确的做法是让学徒同时继承三样东西：**动作、置信区间、以及「什么时候该闭嘴交给专家」的弃权能力**。形式化地，教师在认证区域 `R_cert` 上签过字（每个点 `x_i` 有证书余量 `m_i = dist(π_T(x_i), ∂K_safe)`），学生的局部 Lipschitz 常数为 `L_S`，于是以 `x_i` 为心、半径 `m_i/L_S` 的球内，学生的输出**必然**仍在 `K_safe` 内——这就是**证书的区间搬运**（interval/Lipschitz transfer）。球覆盖不到的地方，学生必须弃权（abstain），由教师（云端）接管或安全停。**蒸馏的目标函数因此从「像不像」变成「在可认证区域内像，且证书可证明地转移；区域外诚实地弃权」。**

**灵感 2（模型蒸馏 → 不确定性蒸馏与共形弃权）**
直觉：安全决策需要的不是一个点估计，而是**「我有多不确定」**。第 59 轮的 BUQ 教师能给出结构化后验协方差，学生若只学均值，就会「自信地错」。因此要把**分位数/区间**蒸馏进学生（quantile distillation），并用**共形校准**给学生装一个「弃权头」：在留出的现场型校准集上，保证 `P(学生输出不安全 | 未弃权) ≤ δ_accept`。弃权不是失败，而是**把不可证明的判断交还给可证明的教师**——这正是「应用落地」中「降级/人工接管」的技术底座。

**灵感 3（应用落地 → 运行安全论证 OSC 与 ODD 分域）**
直觉：实验室里「本 episode 安全」是一个命题；落地后「这支车队在未来一年、在这些场景、这套维护流程下安全」是一个**论证（safety case）**，由目标、策略、假设、证据、反驳共同构成。它有三个实验室里没有的维度：**运行设计域 ODD**（哪些场景被认证、哪些必须拒绝）、**有效期 TTL**（论证会过期，必须用新证据续约）、**分域**（办公室/工厂/户外各有一套证书，不能用一个平均分数糊弄）。落地不是「证明一次」，而是**「持续证明，并在证明不了时收缩 ODD 或降级」**。

**灵感 4（应用落地 → 任意时间有效的连续证据监控 CEM）**
直觉：第 59 轮的联合界是「一次性预算」，接触越多越松；但落地监控每天要看一百万次接触，需要一个**「任何时候看都不会因多看而误报」**的统计工具。答案是**e-process / test martingale**：维护一个非负的「证据资本」`E_t`，在认证为真的零假设下它是上鞅，由 Ville 不等式，`P(∃t: E_t ≥ 1/α) ≤ α`——**无论你看多少次、什么时候看**。于是「认证的每接触失效率 ε₀ 是否被现场突破」变成一个**序贯检验**：`E_t` 越过 `1/α` 就判定证书漂移（CERT_DRIFT），触发重新认证或收缩 ODD。这把「部署期安全」从「点估计」变成「可持续监视的假设检验」。

**灵感 5（双灵感合流 → 证书感知 OTA 飞轮 + 成本-安全前沿 + 责任链）**
直觉：现场数据→重训/重蒸馏→影子验证→OTA 是增长飞轮，但必须给飞轮装**五道闸门**：影子运行无异常、CPD 证书可重验、现场与训练分布无显著漂移、回滚随时可用、安全债未超限。通过才热切换，否则拒绝/回滚。与之耦合的是**部署经济学**：学生容量 `C` 越小越便宜，但认证蒸馏误差 `δ_distill(C)` 越大、吃掉越多安全预算；于是存在**最低可部署容量 `C_min(δ_f^req)`**——若目标 SKU 算力不足，诚实结论是「此 SKU 不可部署该任务」，而不是偷偷降标准。最后，事故必须能通过 `J_dep` 账本**定位到被违反的假设并确定召回范围**（同学生版本/同硬件批次/同 ODD 域），让「责任链」在工程上可执行。

## 1. 形式化定义（增量：定义 153–160）

**定义 153（证书保持蒸馏 CPD）** 教师 `T=(π_T, Cert_eeis, R_cert, Σ_exec)`，学生 `S=(π_S, q_S, z_S)`：`π_S: X→A` 为动作（阻抗参数或证据动作），`q_S: X→{[l,u]}` 为预测区间，`z_S: X→{0,1}` 为弃权头。认证区域 `R_cert ⊆ X`（教师证书成立且输入在 ODD 内）。CPD 需同时满足：
```
(C1) 安全加权保真:  sup_{x∈R_cert} ρ(π_S(x), π_T(x)) ≤ δ_distill
     （ρ 为力响应加权度量，非朴素 L2）
(C2) 证书区间搬运:  ∀x∈R_cert^ver, π_S(x) ∈ K_safe(x)
     （Lipschitz 搬运: 若锚点 x_i 的教师证书余量 m_i，学生局部 Lipschitz 常数 L_S，
       则球 B(x_i, m_i/L_S) ⊆ {x: π_S(x)∈K_safe}；R_cert^ver = ⋃_i B(x_i, m_i/L_S)）
(C3) 校准弃权:  P(π_S 不安全 | z_S=0) ≤ δ_accept
     （在留出现场型校准集上用共形预测校准）
(C4) 不确定性覆盖:  P(π_T(x) ∈ q_S(x) | x∈R_cert) ≥ 1−α_cov
```
输出 `Cert_distill=(δ_distill, R_cert^ver, L_S, δ_accept, α_cov, teacher_ver, student_ver, hash)`。`R_cert^ver = ∅` 或 `δ_distill` 超预算 ⇒ 蒸馏失败，**拒绝部署**（不得静默降标准）。

**定义 154（运行安全论证 OSC 与 ODD 分域）** `SC=(G,S,A,E,J,ODD,TTL)`：`G` 为部署目标 `P_safe(H) ≥ 1−ε_H`；`S` 为论证策略；`A` 为假设集（含 A22–A63）；`E` 为证据集（实验室 E182–E191 + 现场遥测 + 认证）；`J` 为反驳/未决项；`ODD={O_1,…,O_m}` 为运行设计域分域，每域独立证书与假设；`TTL` 为论证有效期。运行域分类器 `κ: x→O_i` 须满足共形覆盖 `P(κ(x)=真域) ≥ 1−α_odd`；`x` 落出所有域或 `κ` 低置信 ⇒ **域外拒绝**。论证到期或域漂移 ⇒ 收缩 ODD 或降级，**不得默认续期**。

**定义 155（连续证据监控 CEM / 任意时间有效）** 现场违例流 `X_t∈{0,1}`。零假设 `H_0: p ≤ ε_0`（ε_0 为认证的每接触失效率上界）。投注 e-process：
```
E_t = ∏_{s≤t} (1 + λ_s (X_s − ε_0)),   λ_s ∈ [−1/(1−ε_0), 1/ε_0]
```
在 `H_0` 下 `E_t` 为上鞅，Ville 不等式给出 `P_{H_0}(∃t: E_t ≥ 1/α) ≤ α`（**与接触次数无关**）。对 `λ` 取混合（hedged capital）提升功效；若真实违例率 `ε_1>ε_0`，检测时间期望 `E[τ] ≤ log(1/α)/D(ε_1‖ε_0)`（KL 散度）。`E_t ≥ 1/α` ⇒ 判定 **CERT_DRIFT**：证书与实际不符，立即重新认证 / 收缩 ODD / 降级。

**定义 156（证书感知 OTA 与数据飞轮 DDF）** 更新 `u=(π_S^new, 训练数据, 版本)`。OTA 门 `G_ota(u)` 同时要求：
```
(a) 影子: 在 N_shadow 个现场型 episode 上，违例率经 CEM 检验 ≤ ε_req（e-value ≥ 1/α_shadow）
(b) 证书: CPD 重验通过，R_cert^ver ≠ ∅ 且 δ_distill ≤ B_distill
(c) 漂移: 现场 vs 训练 两样本检验 D_drift ≤ θ_drift（MMD/e-value）
(d) 回滚: 上一版本证书仍有效且可在 T_rollback 内恢复
(e) 安全债: S_debt + δ_add(u) ≤ S_debt_max
```
五者全过才热切换；任一失败 ⇒ 拒绝/回滚。**安全债记账**：每次接受的更新记入期望风险增量 `δ_add(u)`，每次现场无事故 episode 按认证速率偿付；`S_debt` 只增不减到偿付为止，**不可挪用、不可因业务压力豁免**。

**定义 157（部署成本-安全帕累托 DCP）** 学生容量 `C`（参数量/FLOPs/内存）。认证蒸馏误差上界 `δ_distill(C) ≤ ε_approx(C) + O(√(complexity(C)/n))`（逼近误差 + 估计误差/Rademacher）。部署可行性：
```
Feasible(C) ⇔ δ_distill(C) + δ_exec + δ_ertc + δ_cpd_cal + δ_regime + δ_rollback + δ_debt ≤ δ_f^req(H)
```
`C_min(δ_f^req)=min{C: Feasible(C)}`。在 `(cost(C), risk(C))` 上取 Pareto 前沿。若目标 SKU 无 `C ≥ C_min` ⇒ **诚实结论**：改用云端教师（承受延迟）、收缩 ODD、或拒绝部署——**绝不靠调大 δ 假装可部署**。

**定义 158（人机部署与责任链 HLD）** 角色能力格扩展：`{operator, maintainer, safety_officer, OEM, regulator}`，每个角色对 `δ_floor, F_abs, ε_traj, ODD, OTA, recall` 有不同权限（继承第 53 轮能力格与 L2 协商）。事故处理：`incident → J_dep 账本回放 → 根因归因到被违反的假设 A_i → 召回范围 = {同学生版本} ∪ {同硬件批次} ∪ {同 ODD 域}`。责任链不可篡改、可外部审计。

**定义 159（部署证书 J_dep / Merkle 账本）** `J_dep=(SC, CPD_cert_chain, ODD_map, CEM_state, OTA_log, incident_log, fleet_map, attribution, version, ts)`，以 Merkle 哈希链 append-only 存储。验证：版本单增、父哈希对齐、CPD 证书与 OTA 时戳对齐、CEM 状态可重放、归因指向已登记假设。防篡改、可回溯、支持外部审计。

**定义 160（部署预算 B_dep 与 PCE++++）** `B_dep=(S_debt, C_compute, N_ota, H_attention, E_regulatory)`：安全债、算力、OTA 次数、人工注意力、监管证据预算。PCE++++ 在 VOI 中引入长期折现与安全债影子价格：
```
voi_dep(π) = Σ_{t} γ^t · VOI_meta_pessimistic(π_t) − λ_E·cost_evidence − λ_C·cost_compute
             − λ_debt·ΔS_debt(π)
```
**关键约束**：安全债影子价格 `λ_debt→∞` 当 `S_debt→S_debt_max`；安全底线约束的乘子不可被任何有限商业价值购买——**商业只能经营底线之上的可靠性档位，不能给安全定价**。

### IP-152 CPD（证书保持蒸馏）

```python
class CertificatePreservingDistiller:
    def __init__(self, teacher, student, safety_metric):
        self.teacher = teacher          # CLEP+EEIS 完整管线 + 证书
        self.student = student          # 输出 (action, interval, abstain_logit)
        self.rho = safety_metric        # 力响应加权度量

    def certified_anchors(self, data, cert_eeis):
        """从教师证书提取锚点 (x_i, m_i)，m_i = 到 K_safe 边界的余量"""
        anchors = []
        for x in data:
            a_T = self.teacher.action(x)
            m = self.teacher.certificate_margin(a_T, cert_eeis)  # 安全余量
            if m > 0:
                anchors.append((x, m))
        return anchors

    def distill(self, data, delta_f_req, budget):
        anchors = self.certified_anchors(data, self.teacher.cert_eeis)
        # (C1) 安全加权保真 + (C4) 区间/分位数蒸馏 + (C3) 弃权目标
        for epoch in range(budget.epochs):
            loss = 0.0
            for x, m in anchors:
                a_T = self.teacher.action(x)
                a_S = self.student.action(x)
                loss += self.rho(a_S, a_T)                        # C1
                loss += quantile_loss(self.student.interval(x),   # C4
                                      self.teacher.interval(x))
                loss += bce(self.student.abstain_logit(x), 0.0)   # 区域内不弃权
            for x_out in budget.out_of_cert_stream:               # 区域外弃权
                loss += bce(self.student.abstain_logit(x_out), 1.0)
            train_step(self.student, loss)

        # (C2) 证书区间搬运（IBP + Lipschitz）
        cert = self.verify_transfer(anchors)
        if cert is None or cert.delta_distill > budget.B_distill:
            return None                                       # 拒绝部署
        # (C3) 共形弃权校准
        cert.delta_accept = self.conformal_abstention(budget.calib_field)
        if cert.delta_accept > budget.delta_accept_max:
            return None
        return cert

    def verify_transfer(self, anchors):
        L_S = lipschitz_upper_bound(self.student)             # 网络谱范数上界
        verified, delta_sup = [], 0.0
        for x_i, m_i in anchors:
            r_i = m_i / max(L_S, 1e-9)
            lo, hi = ibp(self.student.action, ball(x_i, r_i))  # 区间界传播
            if subset(lo, hi, self.teacher.K_safe(x_i)):       # 音完备包含
                verified.append((x_i, r_i))
            delta_sup = max(delta_sup,
                            self.rho(self.student.action(x_i),
                                     self.teacher.action(x_i)))
        if not verified:
            return None
        return CertDistill(delta_distill=delta_sup, R_cert_ver=verified,
                           L_S=L_S, teacher_ver=self.teacher.version)
```

### IP-153 OSC（运行安全论证与 ODD 分域）

```python
class OperationalSafetyCase:
    def __init__(self, goal, assumptions, odss, ttl):
        self.G, self.A = goal, assumptions       # P_safe(H) ≥ 1−ε_H
        self.ODD = odss                          # {O_i: (cert, assumptions, evidence)}
        self.TTL = ttl
        self.last_renewal = now()
        self.regime_clf = ConformalRegimeClassifier(alpha=0.05)

    def admit(self, x):
        """运行时准入：域内 + 论证未过期 + 该域证书有效"""
        if now() - self.last_renewal > self.TTL:
            return 'DENY', 'safety_case_expired'
        regime, covered = self.regime_clf.predict(x)
        if not covered or regime not in self.ODD:
            return 'DENY', 'outside_odd'          # 域外拒绝，不赌
        if not self.ODD[regime].cert.valid():
            return 'DENY', 'regime_cert_invalid'
        return 'ALLOW', regime

    def renew(self, regime, new_evidence, cem):
        """续约：只有新证据 + CEM 未漂移才延长 TTL"""
        if cem.state(regime) == 'CERT_DRIFT':
            self.ODD[regime].cert = self.shrink(self.ODD[regime])
            return False
        self.ODD[regime].evidence |= new_evidence
        self.last_renewal = now()
        return True

    def shrink(self, regime_cert):
        """收缩 ODD：降低速度/力上限、减少可接受场景，宁小勿假"""
        return regime_cert.restrict(speed_max=0.8*regime_cert.speed_max,
                                    F_max=0.9*regime_cert.F_max)
```

### IP-154 CEM（任意时间有效连续证据监控）

```python
class AnytimeValidMonitor:
    def __init__(self, eps0, alpha=0.01, betas=None):
        self.eps0 = eps0                      # 认证每接触失效率上界
        self.alpha = alpha
        self.log_E = 0.0                      # log e-process（混合投注）
        self.betas = betas or np.linspace(0.05, 0.95, 19)

    def _log_e_one(self, x, beta):
        lam = beta / (1 - self.eps0) if beta < 1 else 1.0/self.eps0
        return np.log1p(lam * (x - self.eps0))

    def update(self, violation):
        # 对 λ 混合（hedged capital）：E_t = (1/|B|) Σ_β exp(Σ log(1+λ_β(X−ε0)))
        terms = [np.exp(self.log_E + self._log_e_one(violation, b))
                 for b in self.betas]
        self.log_E = np.log(np.mean(terms))  # 递推需存分量子过程，工程上并行维护
        return 'CERT_DRIFT' if np.exp(self.log_E) >= 1.0/self.alpha else 'OK'

    def time_to_detect(self, eps1):
        from scipy.stats import entropy
        return np.log(1.0/self.alpha) / max(entropy([eps1, 1-eps1],
                                                     [self.eps0, 1-self.eps0]), 1e-9)
```

```python
class DeploymentLedger:
    def __init__(self):
        self.chain = []                    # append-only
        self.root = b'\x00' * 32

    def append(self, record):
        h = sha256(self.root + canonical_json(record))
        self.chain.append((record, h))
        self.root = h

    def verify(self):
        root = b'\x00' * 32
        for rec, h in self.chain:
            if sha256(root + canonical_json(rec)) != h:
                return False
            root = h
        return root == self.root
```

### IP-152 CPD（证书保持蒸馏）

```python
class CertificatePreservingDistiller:
    def __init__(self, teacher, student, safety_metric):
        self.teacher, self.student, self.rho = teacher, student, safety_metric

    def certified_anchors(self, data):
        out = []
        for x in data:
            a_T = self.teacher.action(x)
            m = self.teacher.certificate_margin(a_T, self.teacher.cert_eeis)
            if m > 0:
                out.append((x, m))
        return out

    def distill(self, data, budget):
        anchors = self.certified_anchors(data)
        for _ in range(budget.epochs):
            loss = 0.0
            for x, m in anchors:
                loss += self.rho(self.student.action(x), self.teacher.action(x))
                loss += quantile_loss(self.student.interval(x),
                                      self.teacher.interval(x))
                loss += bce(self.student.abstain_logit(x), 0.0)
            for x_out in budget.out_of_cert_stream:
                loss += bce(self.student.abstain_logit(x_out), 1.0)
            train_step(self.student, loss)

        cert = self.verify_transfer(anchors)
        if cert is None or cert.delta_distill > budget.B_distill:
            return None
        cert.delta_accept = self.conformal_abstention(budget.calib_field)
        if cert.delta_accept > budget.delta_accept_max:
            return None
        return cert

    def verify_transfer(self, anchors):
        L_S = lipschitz_upper_bound(self.student)
        verified, delta_sup = [], 0.0
        for x_i, m_i in anchors:
            r_i = m_i / max(L_S, 1e-9)
            lo, hi = ibp(self.student.action, ball(x_i, r_i))
            if subset(lo, hi, self.teacher.K_safe(x_i)):
                verified.append((x_i, r_i))
            delta_sup = max(delta_sup,
                            self.rho(self.student.action(x_i),
                                     self.teacher.action(x_i)))
        if not verified:
            return None
        return CertDistill(delta_distill=delta_sup, R_cert_ver=verified,
                           L_S=L_S, teacher_ver=self.teacher.version)

    def conformal_abstention(self, calib):
        """split-conformal：用非弃权样本的不一致分数定阈值，控制 P(unsafe|accept)"""
        scores = []
        for x, unsafe in calib:
            if self.student.abstain_logit(x) < 0:          # 未弃权
                scores.append(self.student.unsafe_score(x))
        q = np.quantile(scores, 1 - self.alpha_accept) if scores else 0.0
        return self.estimate_unsafe_rate(q, calib)
```

### IP-153 OSC（运行安全论证）

```python
class OperationalSafetyCase:
    def __init__(self, goal, assumptions, odss, ttl):
        self.G, self.A, self.ODD, self.TTL = goal, assumptions, odss, ttl
        self.last_renewal = now()
        self.regime_clf = ConformalRegimeClassifier(alpha=0.05)

    def admit(self, x):
        if now() - self.last_renewal > self.TTL:
            return 'DENY', 'safety_case_expired'
        regime, covered = self.regime_clf.predict(x)
        if not covered or regime not in self.ODD:
            return 'DENY', 'outside_odd'
        if not self.ODD[regime].cert.valid():
            return 'DENY', 'regime_cert_invalid'
        return 'ALLOW', regime

    def renew(self, regime, new_evidence, cem):
        if cem.state(regime) == 'CERT_DRIFT':
            self.ODD[regime].cert = self.shrink(self.ODD[regime])
            return False
        self.ODD[regime].evidence |= new_evidence
        self.last_renewal = now()
        return True

    def shrink(self, c):
        return c.restrict(speed_max=0.8*c.speed_max, F_max=0.9*c.F_max)
```

### IP-154 CEM（任意时间有效监控）

```python
class AnytimeValidMonitor:
    def __init__(self, eps0, alpha=0.01, betas=None):
        self.eps0, self.alpha = eps0, alpha
        self.betas = betas or np.linspace(0.05, 0.95, 19)
        self.sub = np.zeros(len(self.betas))    # 各投注分量的 log 值

    def update(self, x):
        for j, b in enumerate(self.betas):
            lam = b / (1 - self.eps0)
            self.sub[j] += np.log1p(lam * (x - self.eps0))
        log_E = logsumexp(self.sub) - np.log(len(self.betas))  # 混合
        return 'CERT_DRIFT' if log_E >= -np.log(self.alpha) else 'OK'

    def time_to_detect(self, eps1):
        from scipy.stats import entropy
        kl = entropy([eps1, 1-eps1], [self.eps0, 1-self.eps0])
        return np.log(1/self.alpha) / max(kl, 1e-9)
```

```python
class DeploymentLedger:
    def __init__(self):
        self.chain, self.root = [], b'\x00' * 32

    def append(self, record):
        h = sha256(self.root + canonical_json(record))
        self.chain.append((record, h))
        self.root = h

    def verify(self):
        root = b'\x00' * 32
        for rec, h in self.chain:
            if sha256(root + canonical_json(rec)) != h:
                return False
            root = h
        return root == self.root
```

设 A22–A55 成立，并新增：**(A56)** CPD 的 IBP/Lipschitz 界音完备、`δ_distill` 诚实、弃权共形覆盖 `≥1−α_accept`；**(A57)** ODD 分域完备、域分类器漏检 `≤δ_regime`、TTL 内有效；**(A58)** CEM 投注有界、`E_t` 为上鞅、Ville 成立、真实突破有限时间检出；**(A59)** 影子样本代表现场、漂移检验音完备、回滚在 `T_rollback` 内成功；**(A60)** `δ_distill(C)` 诚实且容量-误差单调；**(A61)** 角色能力格正确、归因回放音完备；**(A62)** J_dep 防篡改；**(A63)** 安全债单调、不可挪用、底线处 `λ_debt→∞`。则：

1. **证书保持性**：`∀x∈R_cert^ver`，`π_S(x)∈K_safe(x)`；未弃权时部署每接触失效率 `≤δ_f^req+δ_accept`；`x∉R_cert^ver` 必转教师或安全停，无「学生自信越界」静默通道。
2. **任意时间有效性**：认证成立时 CEM 误报 `≤α`（与接触数无关）；真实违例率 `>ε_0` 时期望检测时间 `≤log(1/α)/D(ε_1‖ε_0)`，把第 59 轮线性联合界替换为不随接触数膨胀的序贯保证。
3. **更新安全性**：`G_ota=ACCEPT` 在 A59 下不降低部署安全界；`REJECT` 即回滚且旧证书有效；飞轮只能偿付安全债或持平，不能凭空透支。
4. **长期部署界**：`P_safe(H) ≥ 1−α_CEM−δ_regime−δ_rollback−δ_debt−P(影子不具代表性)`，不随接触数线性增长。
5. **可部署性诚实**：DCP 要么给出 `C_min` 与可行证书，要么证明目标 SKU 不可部署；无「调大 δ 通过」路径。
6. **责任可追溯**：事故可由 J_dep 回放定位被违反假设 `A_i`，召回范围 `={学生版本}∪{硬件批次}∪{ODD域}`。
