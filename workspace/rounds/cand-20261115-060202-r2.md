# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配×主动多模态交互的不确定性二分闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「技术路线图」×「任务规划」）

> R69 把「不确定性」拆成 aleatoric 与 epistemic，用流匹配策略显式呈现动作模态，用主动交互去消解歧义，并给出了一个漂亮的安全姿态：消解不了就退回 R68 的纯保守。但它的作用域仍然是**一个动作块、一次交互、当前状态**。当任务变成「先穿过人群，再打开抽屉，取出杯子，放到桌上」时，R69 会逐个动作地问「我现在该走哪个模态、要不要看一眼」，却回答不了三个更高层的问题：
>
> 1. **这些动作能不能被组合成一个任务？** 每个技能单独有证书，不代表它们的假设能同时成立——移动底盘的「地面平整、低速」与机械臂的「基座固定」放在同一个计划里可能直接冲突。
> 2. **我有没有资格使用某个能力？** R69 的证书是「这一步安全」，不是「这个能力在当前场景、当前本体、当前维护状态下仍然可信」。证书会过期、会腐化、会被跨场景误用。
> 3. **缺的能力该按什么顺序补？** 如果计划需要「开抽屉」但该技能尚未资格化，R69 只能拒绝或原地提问；它不会把「获得开抽屉的资格」本身当成一个可规划、可预算、可认证的子目标。
>
> 本轮两个灵感正好补上这三块：
> - **技术路线图**不是甘特图，而是一张**带假设集、证书、有效期与依赖边的能力 DAG**——它给出「已认证前沿」「义务前沿」「关键证据链」三个可计算对象；
> - **任务规划**不是找一条动作序列，而是**构造一棵能把根证书推导出来的证明树**——计划可行的充要条件不是「有动作」，而是「根证书可推导」；不可推导时，规划器输出的不是失败，而是**资格化义务**。
>
> 核心命题：**不要直接规划任务，而要规划「任务 × 能力证据」的联合演化**：用证书代数保证组合可靠，用义务感知规划器把缺失证据变成子目标，用证据索引在预算内选择最值钱的资格化动作，用假设监视器让证书随现实腐烂。命名 **RAMP-RAS**（Roadmap-Aware Mission Planning for Risk-Adaptive Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这张能力地图上哪些路真的能走、走之前还欠哪张证书、先补哪一张**」——从「一步的安全」升级为「一条任务的可推导性」。

## 0. 直觉与动机

**灵感 1（技术路线图 → 不是甘特图，是带假设集的证书 DAG）**
直觉：工程里的路线图常被画成时间轴，但真正决定能不能落地的是另一件事：每一条「我们会做 X」的主张，背后都有一组**成立条件**（context）、一组**假设**（assumption）、一份**证据**（certificate）、一个**有效期**（decay）和一个**风险上界**（risk bound）。地图上的路不是承诺，路会封、会塌、会因车型不同而不可走。路线图真正有用的输出不是「图」，而是三个可计算集合：
- **已认证前沿**：当前上下文下证书仍有效的能力节点；
- **义务前沿**：让目标计划可推导所缺的最小证据集合；
- **关键证据链**：按依赖关系排序后，最便宜的那条「先补什么」的路径。

这把「能力清单」变成「能力资格」：系统不因为「模型里有这个技能」就使用它，而因为「这个技能在当前场景下有可验证的证书」才使用它。

**灵感 2（任务规划 → 计划是证书推导树，不是动作序列）**
直觉：一个计划本质上是一句复合主张：「在当前场景下，按这个分解执行，能达到目标且风险不超过 ε」。这句话要有证书，就必须由子计划的证书**组合**出来。组合不是把风险相加这么简单：两个技能各自的假设可能冲突。比如导航证书假设「地面平坦、基座可移动、速度 < 0.3 m/s」，抓取证书假设「基座固定、桌面水平、物体质量 < 1 kg」；单独都成立，放在「移动底盘上伸手抓杯子」这个计划里，假设集并不自动同时成立，需要一张**桥证书**（例如「底盘已锁定」「物体质量已称重」）来清偿冲突。若没有桥证书，计划不是「差一点」，而是**根本不可推导**。
因此规划器的输出应该有两种：`(π, D)`（计划及其证书推导）或 `(π_partial, F)`（部分计划与义务前沿）。第二种输出把「缺什么证据」显式交给下一层，而不是让系统在「拒绝执行」和「盲目尝试」之间二选一。

**灵感 3（规划与路线图互相驱动 → 任务产生证据需求，证据改写路线图）**
直觉：路线图不是规划器的静态约束；任务会反过来告诉路线图「你缺哪张证书」。当计划需要节点 n 而 n 未认证时，系统可以生成一个**资格化子计划** q：它的目标不是完成任务，而是把 n 的证据补到可推导。关键纪律是**非循环**：q 只能使用当前已认证的节点或独立测量仪器，不能用一个待证节点去证明它自己；否则「资格化」会退化成「先信后测」。
这条纪律也直接回应 R69 的最大风险：R69 会「问」，但问出来的自然语言回答未必能映射到任何可验证的能力主张。RAMP 要求**每次交互都必须绑定路线图里的证据模式**：问句可以自由生成，但只有能写进某节点证据账本、带上下文哈希与来源的回答，才被承认为证书；否则它只是未验证的提示。这样「追问幻影」最多浪费一次预算，不会给幻影盖章。

**灵感 4（证书会腐烂，也会被投毒）**
直觉：证书是易腐品。传感器会漂移，场景会变，评测集会被过拟合，证据可能被伪造或跨场景重放。R69 的 COF/FMA 原本只是安全信号；在 RAMP 里它们还是**假设证据**：如果动作似然异常升高而传感器残差很低，系统不应只说「有故障」，而应进一步归因到「哪一条假设被违反了」（基座在动？物体比标称重？地面摩擦变了？），并让依赖该假设的节点进入腐化状态。
此外，路线图本身是新的攻击面：伪造证书、重放别的场景的证书、偷偷插入一条依赖边、把窄上下文证据洗成宽上下文主张。必须把「证据溯源」「上下文哈希」「不可洗白」「依赖审计」写进证书语义，而不是当作工程补丁。

**灵感 5（新层必须严格包含旧层）**
直觉：RAMP 不取代 R69，而是把它当作**单步执行器**。当路线图只有一个节点、计划只有一步、没有义务、没有假设时，RAMP 的选择必须与 FLUID 在该步的选择逐指令相同；当 VoI ≤ 成本、无需交互时，再退化为 R68。安全侧的关键是：RAMP 从不执行没有证书的叶子，资格化动作使用与 R69 相同的交互预算和 C-RAS-WM 认证，计划更新只发生在安全切换点。这样新增的是「长程可组合性」，不是「新的冒险通道」。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（RAMP-RAS 总览）** RAMP-RAS = (R, C, T, Q, E, RAS-WM†)，其中 R 为能力路线图，C 为证书代数，T 为义务感知任务规划器，Q 为资格化规划器，E 为证据账本，RAS-WM† 继承 R69。三不变式：
(i) **可推导才可执行**：任何被执行的计划前缀 π[:k] 都存在证书推导 D(π[:k])；无证书叶子不得执行；
(ii) **资格化不越权**：资格化子计划 q 的信息/物理动作消耗 R69 的交互预算，且必须通过 C-RAS-WM 认证；不得用待证节点自身提供其证据；
(iii) **假设显式清偿**：每次组合必须做上下文合流与假设一致性检查；跨上下文复用必须附桥证书，禁止静默泛化。

**定义 311（能力节点）** 节点 n = (κ, φ, ψ, A, cert, τ, ρ, c)。κ 为技能/策略；φ 为上下文谓词（场景、本体、负载、地面、光照、通信等）；ψ 为性能主张（例如「在 φ 下成功率 ≥ 1−ε」）；A 为假设集；cert 为证据证书；τ 为有效期/衰减常数；ρ 为风险上界；c 为使用成本。同一个 κ 可以有多个节点，对应不同 φ；节点是**主张**，不是代码。路线图 R 是带依赖边的 DAG：n → m 表示 m 的证书依赖 n。

**定义 312（证书）** cert_n = (id, claim, ctx_hash, sources, e_value, issuer, t0, τ, A, deps, signature)。证书在上下文 ctx 下有效，当且仅当：φ_n(ctx) 为真、A 在 ctx 下成立、t − t0 < τ、证据源未过期、来源与签名可验证。证书不是「一次通过」，而是「在声明上下文与有效期内可被追溯的通过」。

**定义 313（证书代数与假设合流）** 对证书 c1, c2，令 φ12 = φ1 ⊓ φ2（上下文交集/最弱共同环境）。若 φ12 不可满足，则二者**不可组合**。若 Sat(A1 ∪ A2)，则 c1 ⊕ c2 有定义，风险为 ρ1 + ρ2 + ρ_comp，假设为 A1 ∪ A2，上下文为 φ12。若 ¬Sat(A1 ∪ A2)，则必须存在桥证书 b，其主张 ψ_b 使 Sat(A1 ∪ A2 ∪ {ψ_b})，且 b 的证据能证明该兼容条件；此时记 c1 ⊕_b c2。**没有桥证书就没有组合证书**——即使两个节点各自完全认证。这是「组合安全缺口」的形式化。

**定义 314（计划即证书推导）** 分层任务网络计划 π = (s_1, …, s_n) 的每个分解方法 m 带有子目标与组合规则；叶子要么映射到路线图节点，要么是证据动作。D(π) 是证书推导树，内部节点为 ⊕/⊕_b，叶子为证书。`⊢_R π` 当且仅当根主张可由 D(π) 推出。义务集 O(π) 包含：缺失证书、过期证书、上下文不匹配、假设冲突未清偿。计划风险 R(π) = Σρ_leaf + Σρ_bridge + ρ_comp + ρ_assump。

**定义 315（路线图信念与腐化）** 对节点 n，b_n(t) = P(n 有效 | 上下文、证据、时间)。无新证据时按 b_n(t+Δt) = b_n(t)·e^{−Δt/τ_n} 衰减；收到监视器信号后用 Bayes 更新。路线图不确定性 U_road(π) = 1 − Π_{n∈leaves} b_n（或计划叶子中期望失效节点数）。**腐化闭包** rot(n)：若 m 完全依赖 n 且无独立证据，则 b_m ≤ b_n；依赖链上的失效沿 DAG 向下传播。

**定义 316（资格化义务与前沿）** 义务 o = (n, gap, Δe)，表示节点 n 还差 Δe 的证据。资格化计划 q 是一个以「提高 e_n」为目标的计划；q 只能使用当前已认证节点或独立测量仪器，**不得使用 n 自身**。资格化前沿 F(π) 是使 `⊢_R π` 成立所需清偿义务的最小反链。记成本 c(q)、风险 ρ(q)、价值 VoI(q) = ΔP(计划可行)·V_mission。

**定义 317（RAMP 任务规划器）** 求解
`max_{π,q} E[U(π)] − λR(π) − c(q)`，
s.t. `⊢_{R⊕q} π`，`R(π) + ρ(q) ≤ ε_mission`，`c(q) ≤ B`。
若不存在完整可行解，返回 `(π_partial, F)`——一个带义务前沿的部分计划，而不是静默失败。规划器是 anytime 的：每次迭代改进下界，并始终保留当前最好的已认证前缀。

**定义 318（证据索引与次模贪心）** 对证据动作集合 S，定义覆盖函数
`F(S) = Σ_o [1 − Π_{e∈S}(1 − p_{o,e})]`，
其中 p_{o,e} 是证据动作 e 清偿义务 o 的概率。若各证据源条件独立，则 F 单调次模。按索引 `I_e = Δ_eF(S)/c_e` 在预算内贪心选择，直到覆盖目标或预算耗尽。

**定义 319（假设监视器 AM）** 对每个节点 n 的假设变量 v ∈ vars(A_n)（接触状态、负载、地面摩擦、场景运动、通信延迟、人是否在场等）估计违反概率。运行时用 R69 的通道做归因：`v* = argmax_v IG(v; a_score, r_res)`，即哪个假设变量的变化最能解释「行为似然异常而传感器残差正常」；随后使所有 `v* ∈ vars(A_n)` 的节点降权或失效。这样 R69 的慢变故障检测不只是报警，而是路线图维护的输入。

**定义 320（路线图投毒与证据溯源）** 威胁包括：伪造证书、跨上下文重放证书、评测过拟合、恶意插入节点/隐藏依赖边、把窄上下文证据洗成宽上下文主张。防御包括：签名与来源链、上下文哈希、外部 holdout/挑战集、有效期、正交证据源、依赖边审计。ℰ_RAMP = ℰ_FLUID × ℰ_cert × ℰ_roadmap。

**定义 321（证书不可洗白）** 组合后的上下文只能取子节点上下文的合流：φ_parent = ⊓ φ_child；证据不能向上泛化到更宽环境；桥证书只能清偿被命名的假设，不能顺带扩大 φ。这样「在实验室桌面上认证」不能被洗成「在任意桌面上可用」。

**定义 322（前缀认证与任意时刻执行）** 每个计划前缀 π[:k] 都必须有证书与安全回退；计划更新只允许发生在**安全切换点**（当前前缀完成、机器人处于可认证的静止/安全状态、关键假设稳定）。若重规划超过截止时间，继续执行当前已认证前缀或退回安全状态，绝不执行未认证动作。该不变式继承并强化 R69 定理 17。

**定义 323（路线图版本化与单调更新）** 路线图按版本 R_t 管理；证据更新产生带签名的 diff。削弱或删除一个主张必须附**弃用证书**，并使依赖它的计划/证书进入失效或待复核状态。实时控制环路不做学习写操作（继承 R68 定义 276-i），路线图更新只在离线/换装/安全停靠阶段提交。

**定义 324（J_RAMP）** J_RAMP = (J_FLUID, road_version, plan_derivation_hash, assumption_join_proof, obligations_before/after, qualification_log_hash, rot_state, evidence_provenance, ramp_ver)。Valid ⇔ Valid(J_FLUID) ∧ `⊢_R π` ∧ 所有假设已清偿 ∧ 无过期证书 ∧ 风险/预算约束满足。

**定义 325（风险-证据对偶预算）** 任务风险预算 ε_mission = ε_task + ε_qual + ε_bridge；证据预算 B = B_ask + B_probe + B_time。只有当资格化带来的计划风险下降满足 `ΔR_plan ≥ κ·ρ(q)` 且 `ρ(q) ≤ ε_qual` 时，才允许「花风险买证据」；κ 是风险-证据交换率。这样资格化不会变成无底洞，也不会为了补一张证书而把系统置于更大风险。

**定义 326（与 FLUID/R68 的边界）** 若 R 只有一个节点、π 只有一步、O = ∅、A = ∅、F = ∅，则 RAMP 在该步与 FLUID 的选择逐指令相同；若进一步 VoI ≤ c、无需交互，则退化为 R68。若计划无义务且不触发交互，执行序列与 FLUID 的逐步执行完全一致。

```python
# IP-264/265：路线图与证书代数
class Roadmap:
    def certified_frontier(self, ctx):
        return {n for n in self.nodes if self.cert(n).valid(ctx)}

    def compose(self, c1, c2):
        phi = meet(c1.phi, c2.phi)
        if not satisfiable(phi):
            return None                       # 上下文互斥，直接不可组合
        if satisfiable(c1.A | c2.A):
            return Cert(claim=compose_claim(c1, c2), phi=phi,
                        A=c1.A | c2.A,
                        rho=c1.rho + c2.rho + comp_risk(c1, c2))
        b = self.find_bridge(c1, c2)          # 桥证书：证明冲突假设可同时成立
        if b is None:
            return None                       # 无桥 → 无证书（组合安全缺口）
        return Cert(claim=compose_claim(c1, c2), phi=phi,
                    A=discharge(c1.A | c2.A, b.claim),
                    rho=c1.rho + c2.rho + b.rho + comp_risk(c1, c2))

# IP-266：计划作为证书推导（AND/OR + HTN，返回义务而非失败）
def derive_plan(goal, R, ctx):
    best = None
    for pi in htn_candidates(goal, R, ctx):
        tree, obligations = derive(pi, R, ctx)   # 递归做 ⊕/⊕_b
        if tree is None:
            continue
        score = expected_utility(pi) - lam * plan_risk(tree)
        if best is None or score > best.score:
            best = (score, pi, tree, obligations)
    if best is None:
        return partial_plan(goal, R, ctx)         # 返回义务前沿，不静默失败
    return best

# IP-267/268：资格化前沿 + 次模证据索引
def qualify(obligations, R, ctx, budget):
    S = set()
    while obligations and budget.remaining > 0:
        candidates = [e for e in evidence_actions(ctx)
                      if c_ras_wm.certify_info(e, ctx)
                      and non_circular(e, S, R)]  # 不得用待证节点自证
        if not candidates:
            break
        e = max(candidates, key=lambda x: marginal_coverage(x, S, obligations)
                / cost(x))
        execute(e); S.add(e)
        obligations = discharge(obligations, e)
        budget.spend(e)
    return schedule(S) if not obligations else None

# IP-276：主闭环（快环仍是 R69，慢环做路线图与规划）
def RAMP_round(M, mission):
    ctx = M.perception.context()
    R = M.roadmap.current()
    # 1) 只在慢环规划；快环继续 R69 的 2.6ms 控制
    plan = rams_plan(mission.goal, R, ctx, M.budget, M.epsilon)
    # 2) 计划不可行时，先补最小义务前沿，而不是盲目执行
    if plan.obligations:
        q = qualify(plan.obligations, R, ctx, M.budget)
        if q is None:
            return M.safe_stop(reason='unqualified_capability')
        R = M.roadmap.apply_evidence(q)        # 版本化更新，回灌证书
        plan = rams_plan(mission.goal, R, ctx, M.budget, M.epsilon)
    # 3) 前缀认证执行：每一步仍走 R69 的 FLUID 单步闭环
    for k, step in enumerate(plan.prefix):
        if not R.prefix_derivable(plan.pi[:k+1], ctx):
            return M.safe_stop(reason='certificate_rot')
        if M.assumption_monitor.invalidated(ctx):
            plan = M.replan_or_safe_stop()      # 仅在安全切换点更新
            break
        M.fluid_step(step)                      # R69：FMP + AUD + MINT + FMA
    return plan
```

## 3. 推导

**引理 19（证书组合的可靠性）** 设计划 π 的推导树叶子为 n_1,…,n_m，桥证书为 b_1,…,b_l；若上下文合流 φ(π)=⊓φ_i 非空、假设集 A=∪A_i 可满足（或有桥证书逐项清偿），则对任意满足 φ(π) 与 A 的执行，R(π) ≤ Σρ_i + Σρ_b + (m+l−1)ρ_comp。若 A 不可满足且不存在桥证书，则不存在统一的计划证书：可构造两个世界 w1⊨A_1、w2⊨A_2，它们分别使一个子计划成立而使另一个失败，且在所有共享证据上不可区分。证：对推导树归纳，内部节点用上下文合流保证子证书同时生效，用假设一致性保证存在共同模型，用风险联合界合并；冲突情形用模型分离构造反例。

**引理 20（资格化的非循环性）** 在有限 DAG 上，若资格化计划 q 使用节点 n 来证明 n 自身，则证书依赖关系出现环，不存在拓扑序，因而不存在有限推导；故任何合法 q 只能使用已认证节点或独立仪器。系：资格化搜索在有限路线图上终止，且不会把「先信后测」伪装成「资格化」。

**引理 21（证据覆盖的次模性）** 在证据源条件独立时，`F(S)=Σ_o[1−Π_{e∈S}(1−p_{o,e})]` 单调且次模：加入 e 的边际收益 `Σ_o p_{o,e}Π_{e'∈S}(1−p_{o,e'})` 随 S 增大而不增。证：每个义务的覆盖函数是 `1−乘积`，其边际随已选证据增加而递减，求和保持次模性。

**引理 22（腐化传播）** 若节点 m 的证书完全依赖 n 且没有独立证据，则 b_m(t) ≤ b_n(t)；因此 n 的失效会沿依赖 DAG 向下传播，直到遇到有独立证据的节点。证：由定义 312 的 deps 与定义 315 的 Bayes 更新，m 的有效性以 n 的有效性为前提；独立证据相当于在分解中引入一个不经过 n 的新叶子，故可阻断传播。

**定理 18（RAMP 严格包含 FLUID-RAS 与 R68）** 在 A99–A101 下，RAMP 的每个执行步仍是一个 FLUID 步（计划只选择已认证叶子，资格化动作是 R69 的信息动作）；当 R 为单节点、π 为一步、O=∅、A=∅、F=∅ 时，RAMP 与 FLUID 在该步逐指令相同；当进一步 VoI ≤ c 时，与 R68 逐指令相同。安全侧：RAMP 不执行任何无证书叶子，资格化受同一交互预算与 C-RAS-WM 约束，计划更新只在安全切换点，故单步风险不高于 FLUID，边界处相等。效率侧：RAMP 通过证书复用与义务排序获得长程组合收益，但不以降低单步安全为代价。

**定理 19（条件计划安全）** 若（i）路线图证书在其声明上下文中真实，（ii）假设监视器能在执行前检出所有会违反 A 的变化，（iii）证书组合满足引理 19，则任何被 RAMP 执行的计划满足 `R(π)+ρ(q) ≤ ε_task+ε_qual+ε_bridge = ε_mission`；且重规划不会提高瞬时风险。证：对计划前缀归纳；每步由 R69 定理 17 保证控制连续与安全包络，组合风险由引理 19 给出，资格化风险由定义 325 的预算约束控制；安全切换点保证新旧前缀的证书不会在跨越瞬间同时失效。

**定理 20（资格化贪心的近似保证）** 在引理 21 的独立性与次模性下，单位成本贪心达到 `(1−1/e)·OPT` 的覆盖；在任意成本预算下使用 cost-benefit 贪心，达到 `(1−1/e)/2·OPT`（标准次模最大化结果）。因此达到目标覆盖所需预算不超过相应最优解的常数倍；当义务间存在强正相关时，次模性变弱，退化为启发式，需在 E311 中实测。

**命题 1（自证边界）** 若节点 n 的全部证据都只在 φ_n 内生成、且没有外部挑战集，则对任何证书，总存在两个世界：它们在所有已生成证据上一致，但在 φ_n 之外一个使 ψ_n 成立、另一个使 ψ_n 失败。因此证书无法证明自己「覆盖了正确的上下文」；外部 holdout、主动假设检验或人工审计是必要而非可选的。这是 RAMP 最大风险的严格版本：路线图可以证明「在它自己的世界里可推导」，但不能独自证明「这个世界就是现实」。

## 6. 本轮最大风险

**一句话**：RAMP-RAS 的最大风险是把「路线图里可推导」误当成「现实里可完成」——**证书体系越自洽，越可能只是在证明自己没出界；一旦假设集本身是错的、过时的或被投毒的，规划器会拿着一份完美的证书，执行一个错误的任务**。

**次级风险与缓解**：
1. **假设监视器不完备**（未检出的假设漂移让证书带病有效）→ 外部 holdout + 多源正交证据 + 定期回归证书（E305/E313）；
2. **证书洗白/重放/伪造**（窄上下文证据被当成宽上下文使用）→ 定义 321 的不可洗白、上下文哈希、签名与来源链（E306）；
3. **路线图投毒**（恶意节点或隐藏依赖边）→ 依赖审计、版本化 diff、关键节点双人复核（E307）；
4. **慢环阻塞或规划爆炸**→ anytime + 前缀认证 + 义务前沿剪枝 + 安全停靠；
5. **资格化成本失控**→ 次模索引、风险-证据对偶预算、机会成本上界（E304/E311）；
6. **过度保守**（只走已认证路，永远不探索）→ 把资格化作为一等公民，用有限探索预算换取新证书，但探索本身仍受 R69 安全包络约束。

**定义 323（版本化）** 路线图按 R_t 管理；削弱/删除主张需弃用证书并使依赖计划失效；实时控制环路零学习写操作（继承 R68）。

**定义 326（边界）** 单节点、一步、O=∅、A=∅、F=∅ ⇒ 与 FLUID 逐指令相同；再满足 VoI≤c ⇒ 与 R68 逐指令相同。

## 3. 关键算法伪代码

```python
# IP-264/265：路线图 + 证书代数
class Roadmap:
    def certified_frontier(self, ctx):
        return {n for n in self.nodes if self.cert(n).valid(ctx)}

    def compose(self, c1, c2):
        phi = meet(c1.phi, c2.phi)
        if not satisfiable(phi):
            return None                        # 上下文互斥
        if satisfiable(c1.A | c2.A):
            return Cert(claim=compose_claim(c1, c2), phi=phi,
                        A=c1.A | c2.A,
                        rho=c1.rho + c2.rho + comp_risk(c1, c2))
        b = self.find_bridge(c1, c2)           # 桥证书：证明冲突假设可同时成立
        if b is None:
            return None                        # 无桥 ⇒ 不可组合
        return Cert(claim=compose_claim(c1, c2), phi=phi,
                    A=discharge(c1.A | c2.A, b.claim),
                    rho=c1.rho + c2.rho + b.rho + comp_risk(c1, c2))

# IP-266：计划 = 证书推导树；不可行时返回义务前沿
def derive_plan(goal, R, ctx):
    best = None
    for pi in htn_candidates(goal, R, ctx):
        tree, obligations = derive(pi, R, ctx)  # 递归 ⊕ / ⊕_b
        if tree is None:
            continue
        score = expected_utility(pi) - lam * plan_risk(tree)
        if best is None or score > best.score:
            best = (score, pi, tree, obligations)
    return best if best else partial_plan(goal, R, ctx)

# IP-267/268：资格化前沿 + 次模贪心（非循环）
def qualify(obligations, R, ctx, budget):
    S = set()
    while obligations and budget.remaining > 0:
        cands = [e for e in evidence_actions(ctx)
                 if c_ras_wm.certify_info(e, ctx)
                 and non_circular(e, S, R)]
        if not cands:
            break
        e = max(cands, key=lambda x: marginal_coverage(x, S, obligations)
                / cost(x))
        execute(e); S.add(e)
        obligations = discharge(obligations, e); budget.spend(e)
    return schedule(S) if not obligations else None

# IP-276：慢环规划 + 快环 R69 控制
def RAMP_round(M, mission):
    ctx = M.perception.context()
    R = M.roadmap.current()
    plan = rams_plan(mission.goal, R, ctx, M.budget, M.epsilon)
    if plan.obligations:
        q = qualify(plan.obligations, R, ctx, M.budget)
        if q is None:
            return M.safe_stop(reason='unqualified_capability')
        R = M.roadmap.apply_evidence(q)        # 版本化回灌
        plan = rams_plan(mission.goal, R, ctx, M.budget, M.epsilon)
    for k, step in enumerate(plan.prefix):
        if not R.prefix_derivable(plan.pi[:k+1], ctx):
            return M.safe_stop(reason='certificate_rot')
        if M.assumption_monitor.invalidated(ctx):
            plan = M.replan_or_safe_stop()    # 仅在安全切换点
            break
        M.fluid_step(step)                    # R69：FMP + AUD + MINT + FMA
    return plan
```

## 4. 推导

**引理 19（组合可靠性）** 若推导树各叶子的上下文合流非空、假设集可满足（或有桥证书逐项清偿），则 `R(π) ≤ Σρ_leaf + Σρ_bridge + (m+l−1)ρ_comp`。若假设冲突且无桥，则不存在统一计划证书：可构造两个世界分别满足两组假设、在所有共享证据上不可区分，却使一个子计划成功、另一个失败。证：对推导树归纳 + 风险联合界 + 模型分离。

**引理 20（资格化非循环）** 若 q 使用待证节点 n 来证明 n 自身，则证书依赖关系成环，不存在有限拓扑序，故无合法推导。系：资格化在有限 DAG 上终止，不会把「先信后测」伪装成「资格化」。

**引理 21（证据覆盖次模性）** 条件独立时 `F(S)=Σ_o[1−Π_{e∈S}(1−p_{o,e})]` 单调次模；加入 e 的边际收益随 S 增大而递减。证：每个义务的 `1−乘积` 函数边际递减，求和保持次模。

**引理 22（腐化传播）** 若 m 完全依赖 n 且无独立证据，则 `b_m ≤ b_n`；失效沿 DAG 向下传播，遇到独立证据节点被阻断。证：由证书 deps 与 Bayes 更新，m 的有效性以 n 为前提；独立证据引入一条不经过 n 的新叶子。

**定理 18（严格包含 FLUID-RAS 与 R68）** RAMP 的每个执行步仍是 FLUID 步；单节点、一步、O=∅、A=∅、F=∅ 时逐指令相同；再满足 VoI≤c 时与 R68 逐指令相同。安全侧不弱于 FLUID：无证书叶子不执行，资格化受同一预算与 C-RAS-WM 约束，计划更新只在安全切换点。

**定理 19（条件计划安全）** 若证书在其声明上下文中真实、假设监视器能检出所有会违反 A 的变化、组合满足引理 19，则被执行计划满足 `R(π)+ρ(q) ≤ ε_mission`，重规划不提高瞬时风险。证：前缀归纳 + R69 定理 17 + 引理 19 + 定义 325 的预算约束。

**定理 20（资格化贪心近似）** 独立义务与次模覆盖下，单位成本贪心达到 `(1−1/e)OPT`；任意成本预算下 cost-benefit 贪心达到 `(1−1/e)/2·OPT`。因此达到目标覆盖的预算不超过最优解的常数倍；强相关时退化为启发式，需 E311 实测。

**命题 1（自证边界）** 若 n 的全部证据只在 φ_n 内生成且无外部挑战集，则总存在两个世界：它们在所有已生成证据上一致，但在 φ_n 之外一个使 ψ_n 成立、另一个使其失败。故证书无法自证「上下文覆盖正确」；外部 holdout、主动假设检验或人工审计是必要的。这是「路线图—现实失配」的严格形式。

## 7. 本轮最大风险

**一句话**：RAMP-RAS 的最大风险是把「路线图里可推导」误当成「现实里可完成」——**证书体系越自洽，越可能只是在证明自己没出界；一旦假设集本身是错的、过时的或被投毒的，规划器会拿着一份完美的证书，执行一个错误的任务**。

**次级风险与缓解**：假设监视器不完备 → 外部 holdout + 正交证据 + 定期回归（E305/E313）；证书洗白/重放/伪造 → 不可洗白定义、上下文哈希、签名与来源链（E306）；路线图投毒 → 依赖审计、版本化 diff、关键节点复核（E307）；慢环阻塞 → anytime + 前缀认证 + 义务前沿剪枝；资格化成本失控 → 次模索引 + 风险-证据对偶预算（E304/E311）；过度保守 → 把资格化作为一等公民，用有限探索预算换证书，但探索仍受 R69 安全包络约束。
