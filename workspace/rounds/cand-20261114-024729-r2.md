# 第 71 轮（承接第 70 轮「BELIEF-RAS」IP-264~274；灵感循环新循环第 2 轮；本轮灵感：「力矩传感」×「主动交互」）

> R70 把 epistemic 从「动作模态」抬到「世界状态后验」b_t(s)，用贝叶斯 VoI 选择看/问/触，用边缘化流似然做标定不可吸收的第二意见。理论链条 R68 ⊂ FLUID ⊂ BELIEF 基本闭合。但它有三个从未写进假设、却决定成败的前提：
> 1. **观测是外源的**：R70 的信息动作只改变「从哪里取观测」，不改变世界对动作的力学响应。可在接触丰富的任务里，最关键的不确定量——负载质量/质心/惯量、摩擦、接触刚度、关节摩擦、工具动力学——在被动观测下根本不进入观测方程的主脊。你盯着看一万年，也看不出这个杯子是 300g 还是 500g。
> 2. **传感器是可信的**：R70 把标定残差当成一个通道，却没有处理**力矩传感器自身的偏置、尺度与温漂**。更糟的是，力矩偏置与负载参数在受限运动下是共线的：分不清「东西重了」还是「手感偏了」。这是 R68「缓变故障被标定吸收」在力域的翻版。
> 3. **信息动作不改变世界**：R69/R70 认证信息动作「不越出安全包络」，默认它不改变世界状态。但物理探针会留下位移、磨损、甚至不可逆的接触状态改变。
>
> 本轮两个灵感正好补上三块缺失：
> - **力矩传感**提供唯一一条「信息由我们自己的动作产生」的通道：τ = Y(q,q̇,q̈)θ + D(q)β_τ + Jᵀ f_ext + n。参数 θ 能不能被看见，取决于我们**怎么动**；而偏置 β_τ 与 θ 常常共线。
> - **主动交互**给出「让参数变得可辨识」的手段：既然被动看不够，就主动做一次可逆的物理提问——轻压、轻晃、轻抬、轻滑、手把手带一下。它不是「多取一个观测」，而是「设计一个激励」。
>
> 核心命题：**把 epistemic 再切一刀——U_obs（被动可约，R70 管）、U_act（只有主动激励可约，本轮新增）、U_struct（任何可逆激励都不可约，只能当风险）；建「世界 × 力学参数 × 力矩偏置」的联合信念；用可逆探针的最大期望信息增益选择「怎么摸」；用可逆性证书保证「摸完能回来」；再用三通道残差（传感器残差 / 流似然 / 力矩残差）把「世界变了」「传感器偏了」「模型错了」分开。** 命名 **HAPTIC-RAS**（Haptic Active Probing with Torque-Identifiability Certification）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「我相信哪个世界状态」，R71 问「**我该怎样轻推这个世界一下，才能分清是世界重了、还是我的手感偏了，而且推完还能收回来**」——不确定性不只是提问和注视，也可以是一次有设计、有证书、可撤回的触碰。

## 0. 直觉与动机

**灵感 1（力矩传感 → 信息由动作生成，观测因此是内生的）**
直觉：相机和麦克风是「外源」传感器——你不动，世界照样朝你辐射光子与声波。力矩不是。关节力矩传感器测的是 `τ = M(q)q̈ + C(q,q̇) + g(q) + Jᵀf_ext + b_τ + n`：没有动作、没有接触，就没有可辨识的力学信息。这意味着「能不能看见 θ」不是传感器属性，而是**动作的属性**。同一台机器人，沿着一条平滑轨迹走，可能对负载质量一无所知；换一个方向轻晃两下，信息量立刻不同。R70 的 VoI 是在「已有观测分布里重新加权」，HAPTIC 的 VoI 是在「改变观测分布本身」。这是从**选择观测**到**制造观测**的一步。

**灵感 2（主动交互 → 主动激励是把「不可辨识」变成「可辨识」的唯一出路）**
直觉：控制理论里这叫持续激励（persistent excitation）。若回归矩阵 Φ(ξ) 对参数 η=(θ,β_τ) 的 Fisher 信息秩亏，那么再长的被动数据也只在可辨识子空间里打转，零空间里的不确定性**永远不会缩小**。此时唯一有效的信息动作是：设计一段轨迹，让 Φ(ξ) 在零空间方向上获得能量。物理上就是「换个姿势再感受一下」：竖直抬一下分离质量，绕腕转一下分离惯量，切向滑一下分离摩擦，轻叩一下分离刚度，换两个静态姿态分离重力补偿偏置。**「摸得久」不如「摸得不一样」。** 这把主动交互从「信息动作库里的一个选项」升级为「可辨识性的构造性条件」。

**灵感 3（偏置-负载共线 → 力矩是「会撒谎的证人」）**
直觉：最危险的 epistemic 不是「不知道」，而是「知道了但归错了因」。若力矩传感器有一个与姿态相关的偏置 b_g(q)，而负载质量 m 的回归列在受限运动里恰好与 b_g(q) 共线，那么观测只约束组合 `m + c·b_g`，无法分别估计。系统会自信地把「传感器偏了」解释成「物体变重了」，或者反过来——这与 R68 的缓变故障被标定吸收、R70 的后验「自信地错」是同一个病，只是病灶搬到了力域。解法不是更复杂的滤波器，而是**主动去激励那个能把两列分开的方向**：静态双姿态、空载/负载对照、自由空间/接触对照。于是「主动交互」同时是估计器的一部分：**实验设计就是可辨识性证明。**

**灵感 4（物理交互不可逆 → 信息动作必须带可逆性证书）**
直觉：R69 的「看一眼、问一句」最坏只是浪费一次机会；物理探针最坏会把物体推下桌子、把关节顶到限位、把易碎件压裂。所以「信息动作过安全认证」不够，必须回答一个更强的问题：**推完能不能回来？** 需要在探针执行前就证明：冲量有界、抓取力矩裕度足够、接触模式不进入不可逆分支、存在一个经过认证的恢复策略把状态带回可恢复集。只有「可逆的提问」才允许被执行；不可逆的物理问题，即使信息量再大，也只能当作结构性风险来处理。

**灵感 5（三通道 → 把「世界/传感器/模型」三类错误分开）**
直觉：R70 有两条冗余通道：传感器残差 r_res 测「测量自洽」，流似然 Δa 测「行为自洽」。力矩给出第三条：τ_res = τ_meas − τ_pred(η̂) 测「动力学自洽」。三者在故障下有不同签名：力矩传感器偏置让 τ_res 独自升高；真实负载变化会让 τ_res 升高但在 η̂ 收敛后回落；流模型错误只让 Δa 升高；接触环境突变则 τ_res 与 Δa 同时升高。**三维签名把「我被骗了」「世界变了」「我的模型错了」从一根标量里拆开。** 这也是对 R70 最大风险的直接回应：后验再自信，也逃不过三条独立通道的联合检验。

## 1. 形式化定义（增量：定义 331–347）

**定义 331（HAPTIC-RAS 总览与三不变式）** HAPTIC-RAS = (TSB†, TOA, U3, AEP, RCC, DBD, TRC, TCG, HPI, TTS, VQAuditor-IV, RAS-WM†)。三不变式：
(i) **实时控制路径零学习写操作**（继承 R70 定义 310-i）；
(ii) **探针预算硬约束**：单位时间物理探针 ≤ 1 次，单次冲量 ≤ I_max、接触力 ≤ f_max、任务中断时长 ≤ T_p,max，且探针与任务动作共用 C-RAS-WM 认证；
(iii) **可逆性纪律**：任何物理探针必须携带可逆性证书；无证书 ⇒ 不得执行，U_act 保持未消解并走 R70 兜底。

**定义 332（扩展状态与力矩观测模型）** 状态 s = (s_sem, θ, β_τ)：s_sem 为 R70 的语义世界状态；θ ∈ ℝ^{d_θ} 为力学参数（负载质量/质心/惯量、粘滞/库仑摩擦、接触刚度/阻尼、关节摩擦、间隙/背隙、工具参数）；β_τ ∈ ℝ^{d_β} 为力矩传感器偏置/尺度/重力补偿误差。观测：
τ_t = Y(q_t,q̇_t,q̈_t) θ + D(q_t,q̇_t) β_τ + J_c(q_t)ᵀ f_ext(t) + n_τ(t),  n_τ ~ 𝒩(0,Σ_τ)。
在窗口 ξ 上堆叠：τ = Φ(ξ) η + n，η = (θ, β_τ)，Φ(ξ) = [Y(ξ), D(ξ)]。注意 Φ 显式依赖动作轨迹 ξ——这是 HAPTIC 与所有「观测外生」框架的分水岭。

**定义 333（力矩可观测性与 TOI）** 线性高斯下 Fisher 信息 FIM(ξ) = Φ(ξ)ᵀ Σ_τ^{-1} Φ(ξ)。可辨识子空间 = range(FIM)，结构性零空间 = null(FIM)。定义**力矩可观测性指数** TOI(ξ) = λ_min⁺(FIM) / λ_max(FIM)（最小正特征值 / 最大特征值）；TOI 越小，越接近不可辨识。rank(FIM) < d_θ+d_β 时称参数**结构性不可辨识**。

**定义 334（主动可辨识性与不确定性三分）** 设 𝒢_adm 为可逆探针集合（定义 335）。定义：
U_obs = H[s | 被动观测]（R70 已处理的、被动可约部分）；
U_act = min_{g∈𝒢_adm} E_{τ'~p(·|g)} H[s | o, τ', g]（只有主动激励才能压下去的部分）；
U_struct = H[s | 任何 g∈𝒢_adm 的最优激励]（可逆激励也压不下去的部分，只能当风险）。
三者满足 H[s] ≤ U_obs + U_act + U_struct（链式分解上界）。**HAPTIC 的全部主张是：把 R70 误并入「不可约」或「无信息」的 U_act 单独识别出来，并用可逆激励消解它。**

**定义 335（可逆探针空间）** 探针 g = (c, n, w(·), K_p, π_rec, primitive)，其中 c 为接触点/接触区域，n 为施力方向，w(·) 为力/力矩剖面（幅值 ≤ f_max、冲量 ≤ I_max），K_p 为阻抗参数，primitive ∈ {press, tap, slide, lift, wiggle, rotate, hand-guide}，π_rec 为恢复策略。𝒢_adm 为通过定义 341 认证的探针子集。

**定义 336（可恢复集与可逆性证书 RCC）** 定义任务相关的可恢复集 ℛ：从其中任一状态出发，存在认证恢复策略 π_rec 使系统在 T_rec 内回到任务可继续的 ε-管，且不违反安全包络。探针 g 的可逆性证书为三元组 Cert_rev(g) = (I(g) ≤ I_max, γ_grasp(s) ≥ ε_grasp ∧ τ ≤ τ_max, s_{t+T_p} ∈ ℛ)。三项全部满足才允许执行；任一失败 ⇒ g 作废。

**定义 337（主动激励规划 AEP）** EIG(g) = H[b_t] − E_{τ'~p(·|g)} H[b_{t+1}(τ')]。在线性高斯近似下 EIG(g) ≈ ½ log det(I + FIM(g) Σ_η)，其中 Σ_η 为 η 的后验协方差。选择
g* = argmax_{g∈𝒢_adm} [ EIG(g) − λ_c c(g) − λ_r risk(g) ]，s.t. 预算未超、Cert_rev(g) 有效。
若最优值 ≤ 0 或 𝒢_adm 在零空间方向上无激励能力 ⇒ 不探针，U_act 转入 U_struct，走 R70 兜底。

**定义 338（偏置-负载解耦 DBD）** 称 (θ,β_τ) 在被动集 ξ_0 上**共线混淆**，若 D(ξ_0) = Y(ξ_0) C 对某 C 成立，此时只有 η' = θ + Cβ_τ 可辨识。DBD 构造激励基：
- 双静态姿态（重力方向不同）→ 分离重力补偿偏置与负载质量；
- 空载 / 负载对照 → 分离工具惯量与负载惯量；
- 自由空间 / 接触对照 → 分离关节摩擦与外接触力；
- 动态 / 准静态对照 → 分离粘滞摩擦与库仑摩擦。
称上述组合为**解耦激励基**；只要探针在至少一个基方向上产生能量，rank(Φ) 严格增加，β_τ 的相应分量变为可辨识。

**定义 339（力矩残差与三通道故障签名）** τ_res = τ_meas − τ_pred(η̂, ξ)。三通道 χ = (r_res, Δa, τ_res)（分别继承 R68 标定残差、R69/R70 流似然异常、本轮力矩残差）。定义故障签名矩阵 S：行 = {力矩偏置/尺度漂移, 负载变化, 接触环境突变, 流模型误差, 关节摩擦突变}，列 = {r_res, Δa, τ_res}，元素为期望响应方向。三通道联合分布用于故障分类与「信心崩塌」定位。

**定义 340（力矩校准门 TCG）** 用可靠图与 ECE_τ 校准 η̂ 的后验可靠性，并用 κ_τ 表示力矩模型置信度（由残差白度、跨工况一致性、仿真-现实差异估计）。若 ECE_τ > τ_τ 或 κ_τ < κ_min ⇒ 关闭力矩通道与探针规划，逐指令退化为 R70。

**定义 341（物理交互安全认证）** 探针 g 须同时满足：wrench cone（|f_t| ≤ μ f_n）、关节力矩上限、抓取力矩裕度 γ_grasp ≥ ε_grasp、冲量上界、接触模式不进入不可逆分支、恢复策略可执行。认证通过才可交给 C-RAS-WM 做前缀认证；两道认证是「与」关系。

**定义 342（人类物理交互 HPI）** hand-guide 探针中人类是信息源，也可能是不确定扰动源。设人类意图 u∈{引导, 抵抗, 无关扰动, 恶意}，用阻抗观测与轨迹一致性估计 p(u|τ_human)。仅当 p(引导) 高且与另一正交证据源一致时才采纳为信息；否则按扰动处理并触发安全退让。

**定义 343（两时间尺度调度 TTS）** 快环（≥1kHz）：TSB† 力矩观测更新、安全认证、控制输出，预算 ≤ 0.4ms；慢环（10–20Hz）：TOA/AEP/DBD 规划，预算 ≤ 5ms，独立线程、有界队列、过期计划直接丢弃。慢环永不阻塞快环。

**定义 344（两级退避† 与 U_act resolution bonus）** λ = λ_floor(U_ale + α_obs·U_obs + α_act·U_act + α_struct·U_struct)。若 U_act 在预算内被可逆探针消解，则 α_act=0（获得 resolution bonus，比 R70 更不保守但不更低安全）；若未消解、超时、被投毒、RCC 失败或 TCG 越界，则 α_act=1（未消解的主动可约不确定性视同不可约），逐指令退化为 R70，再退化为 R68。

**定义 345（证书 J_HAPTIC）** J_HAPTIC = (J_BELIEF, TOI_min, ECE_τ, κ_τ, U_act_before, U_act_after, probe_reversibility_rate, τ_res_p95, fault_signature_id, probe_log_hash, haptic_ver)。Valid ⇔ Valid(J_BELIEF) ∧ TOI_min ≥ τ_toi ∧ ECE_τ ≤ τ_τ ∧ κ_τ ≥ κ_min ∧ 可逆性纪律满足 ∧ 探针预算未越界。

**定义 346（干扰集 AIC-HAPTIC）** ℰ_HAPTIC = ℰ_BELIEF × ℰ_torque × ℰ_contact × ℰ_probe，其中 ℰ_torque = {偏置漂移, 尺度误差, 温漂, 饱和/削顶, 量化噪声}，ℰ_contact = {打滑, 冲击, 形变/粘弹, 不可逆位移}，ℰ_probe = {探针诱导致动, 恢复失败, 人类恶意 hand-guide, 探针库外工况}。

**定义 347（参与式审计 VQAuditor-IV）** 审计对象新增：探针是否必要（EIG 是否为正）、可逆性证书是否真实、偏置-负载归因是否有对照、恢复策略是否被实际执行、人类 hand-guide 是否被单源采纳。结论回灌 AuditBuf，成为下一轮 AEP 的成本先验与探针库剪枝依据。

## 2. 关键算法骨架

```python
# IP-275 TSB†：力矩结构化信念（物理主干 + 学习残差，硬约束投影）
class TorqueStructuredBelief:
    def __init__(self, dyn, residual_net, tau_model, N=500):
        self.dyn, self.res, self.tau = dyn, residual_net, tau_model
        self.N = N

    def predict(self, b_prev, q, qd, qdd, last_xi):
        s = [self.dyn.propagate(x, q, qd, qdd, last_xi) for x in b_prev.particles]
        return Belief(s, b_prev.weights)

    def update(self, b_pred, tau_meas):
        logw = []
        for x in b_pred.particles:
            tau_hat = self.tau.predict(x, b_pred.ctx) + self.res(x, b_pred.ctx)
            logw.append(b_pred.logp(x) - 0.5 * mahalanobis(tau_meas, tau_hat, b_pred.Sigma_tau))
        return reweight_normalize_resample(b_pred, logw)

    def param_posterior(self, b):                    # η = (θ, β_τ)
        return gaussian_moment(b, key=lambda x: x.eta)

# IP-276 TOA：力矩可观测性分析（FIM / TOI / 零空间）
def torque_observability(tau_model, xi_candidates, eta_posterior):
    out = []
    for g in xi_candidates:
        Phi = tau_model.regressor(g)                 # [Y(g), D(g)]
        F   = Phi.T @ inv(tau_model.Sigma_tau) @ Phi
        w, V = eigh(F)
        w_pos = w[w > 1e-9]
        toi = (w_pos.min() / w.max()) if len(w_pos) else 0.0
        null = V[:, w <= 1e-9]                        # 结构性不可辨识方向
        out.append(ProbeInfo(g, F, toi, null))
    return out

# IP-277/278 U3 + AEP：三分不确定性 + 可逆探针规划
def plan_probe(b_t, tau_model, probe_lib, budget, rcc, tcg):
    if not tcg.trustworthy(b_t):                      # 力矩不可信 → 回 R70
        return None, U3(U_obs=tcg.U_obs(b_t), U_act=0.0, U_struct=entropy(b_t))
    eta = b_t.param_posterior()
    infos = torque_observability(tau_model, probe_lib, eta)
    best = None
    for info in infos:
        g = info.g
        if not budget.allow(g):                              continue
        if not rcc.certify_reversible(g, b_t):               continue   # 不可逆 → 禁问
        if not c_ras_wm.certify_info(g, b_t):                continue
        eig = 0.5 * logdet(np.eye(len(eta.mu)) + info.F @ eta.Sigma)
        score = eig - lambda_c * cost(g) - lambda_r * risk(g)
        if best is None or score > best.score:
            best = (g, eig, score, info)
    if best is None or best[2] <= 0:
        return None, U3(..., U_act=0.0, U_struct=entropy(b_t))
```

## 3. 推导

**引理 23（信息由激励生成）** 高斯观测下 EIG(g) = ½ log det(I + FIM(g) Σ_η)。若被动轨迹的 FIM_0 在方向 v 上为零（v ∈ null(FIM_0)），则任意长被动观测对 v 方向的后验方差不变；若存在 g∈𝒢_adm 使 vᵀFIM(g)v > 0，则沿 v 的 CRLB 方差严格下降，且随激励样本数 N 以 O(1/N) 收敛。系：**对零空间方向，「看得更久」的 VoI 恒为 0，「动得不同」的 VoI 为正**——这正是 R70 与 HAPTIC 的分界。

**引理 24（偏置-负载主动解耦）** 若被动运动集上 D(ξ_0) = Y(ξ_0) C，则 Φ(ξ_0)η = Y(ξ_0)(θ + Cβ_τ)，只有 η' = θ + Cβ_τ 可辨识，β_τ 落在零空间中。任取探针 g 使 [Y(g), D(g)] 在第 (θ_j, β_k) 对上产生非共线列，则 rank(Φ([ξ_0;g])) ≥ rank(Φ(ξ_0)) + 1，相应 β_k 与 θ_j 可分；双静态姿态使重力方向改变，D 的差列不在 Y 的常值列张成内，故质量与重力补偿偏置可分。系：**解耦不是估计器技巧，而是激励设计问题；没有对照激励，任何后验都会把二者混为一谈。**

**引理 25（可逆探针安全界）** 若探针 g 满足冲量上界 I_max、接触模式的逆可达、恢复策略在可恢复集 ℛ 上收缩（V(s') ≤ ρV(s), ρ<1），则探针引起的任务相关状态偏差被 B(I_max) 界定，并在 T_rec 内回到 ε-管；因此「探针导致不可逆任务失败」的概率 ≤ δ_rev，且不高于同任务下 R70 认证动作的风险上界。系：**可逆性证书把「主动摸」的风险约束在「不摸」的量级**，使信息收益可以净计入。

**引理 26（三通道故障可分）** 在 A103（三通道噪声条件独立、故障签名矩阵 S 列满秩）下，{力矩偏置、负载变化、接触突变、流模型误差、关节摩擦突变} 五类故障两两可分；最小可分辨信噪比由 S 的最小奇异值给出。特别地，**力矩偏置**的签名是 (r_res≈0, Δa≈0 或弱, τ_res↑)，而**真实负载变化**在 η̂ 收敛后 τ_res 回落，因此「偏置 vs 变重」可由 τ_res 的时间形态与 DBD 对照组区分。

**定理 20（HAPTIC 严格包含 BELIEF 包含 FLUID 包含 R68）** 在 A102–A104 下，HAPTIC 的期望风险 ≤ BELIEF ≤ FLUID ≤ R68；且当探针预算为 0、𝒢_adm 无可逆解、EIG ≤ 成本、TCG 越界或故障签名要求保守时，HAPTIC 与 BELIEF **逐指令相同**。因此 R71 不是替代 R70，而是把「物理可约」这一维显式补进 R70 的退化边界：安全侧层层不让步，效率侧获得 U_act resolution bonus。

**定理 21（两时间尺度实时性）** 快环只做 TSB† 更新与认证（≤0.4ms），慢环 AEP 规划有界队列且过期即丢，不被快环等待；因此控制路径最坏延迟 ≤ R70 + 0.4ms，探针规划对 P99 无贡献。若慢环超时，则本轮不探针、α_act=1，退化为 R70——**实时性失败只损失效率，不损失安全**。

## 6. 本轮最大风险

**一句话**：HAPTIC-RAS 的全部收益押在「力矩模型与接触模型足够真、可逆性证书足够保守」这两个前提上——**若力矩信号被未建模的摩擦/背隙/温漂主导，或接触动力学在仿真里学不准，那么主动探针既可能「摸不出」真实参数，又可能「摸坏」物体或进入恢复策略也救不回来的状态；此时系统会用一个错误的物理模型，自信地执行一次不可逆的提问**——主动去摸，可能比不摸更危险。

**次级风险与缓解**：
1. **力矩传感器自证偏置**（偏置被估计成负载、负载又被用来解释偏置）→ 定义 338 解耦激励基 + 引理 24 + E323 对照实验；
2. **仿真-现实接触差距** → TCG 置信度门 + 域随机化 + 只允许低冲量探针 + E326/E337；
3. **探针不可逆或恢复失败** → RCC 双重认证 + 可恢复集 + 引理 25 + E324/E334；
4. **人类物理交互欺骗** → HPI 意图推断 + 证据纪律（单次 hand-guide 不定案）+ E329；
5. **慢环规划击穿实时性** → TTS 有界队列、过期即丢、失败退 R70 + 定理 21、E335。

## 2. 形式化定义（要点版）

**定义 331（总览与三不变式）** HAPTIC-RAS 继承 BELIEF 全部组件（† 升级），新增 TOA/U3/AEP/RCC/DBD/TRC/TCG/HPI/TTS。三不变式：(i) 快环零学习写操作；(ii) 探针预算硬约束（≤1 次/单位时间、I≤I_max、f≤f_max、中断≤T_p,max）；(iii) 可逆性纪律（无 Cert_rev 不探针）。

**定义 332（扩展状态与观测）** s=(s_sem,θ,β_τ)；τ=Φ(ξ)η+n_τ。Φ 显式依赖动作，故「可观测性」是动作的函数而非传感器常量。

**定义 333（TOI 与结构性不可辨识）** FIM=ΦᵀΣ_τ^{-1}Φ；可辨识子空间=range(FIM)，零空间=null(FIM)；TOI=λ_min⁺/λ_max；rank(FIM)<d_θ+d_β ⇒ 结构性不可辨识。

**定义 334（不确定性三分）** U_obs=H[s|被动观测]；U_act=min_{g∈𝒢_adm}E[H[s|τ',g]]；U_struct=H[s|最优可逆激励]；H[s] ≤ U_obs+U_act+U_struct。

**定义 335（可逆探针）** g=(c,n,w(·),K_p,π_rec,primitive)，primitive∈{press,tap,slide,lift,wiggle,rotate,hand-guide}，w(·) 受 f_max/I_max 约束。

**定义 336（可恢复集与 RCC）** s_{t+T_p}∈ℛ，且存在认证 π_rec 在 T_rec 内回到 ε-管、不越安全包络；Cert_rev=(冲量、抓取裕度/力矩上限、可恢复性) 三项全满足。

**定义 337（AEP）** g*=argmax_{g∈𝒢_adm}[EIG(g)−λ_c c(g)−λ_r risk(g)]；EIG≈½logdet(I+FIM(g)Σ_η)；最优值≤0 ⇒ 不探针，U_act→U_struct。

**定义 338（DBD 解耦激励基）** 双静态姿态（分离重力补偿偏置/m）、空载-负载（分离工具/负载惯量）、自由空间-接触（分离关节摩擦/外力）、动态-准静态（分离粘滞/库仑摩擦）。

**定义 339（三通道故障签名）** χ=(r_res,Δa,τ_res)；故障签名矩阵 S 覆盖 {力矩偏置、负载变化、接触突变、流模型误差、关节摩擦突变}。

**定义 340（TCG）** 由 ECE_τ 与 κ_τ（残差白度、跨工况一致性、sim-real 差异）门控；越界即关力矩通道与探针，逐指令退 R70。

**定义 341（物理交互安全认证）** wrench cone、关节力矩、抓取裕度、冲量、接触模式可逆、恢复可执行；与 C-RAS-WM 前缀认证为「与」关系。

**定义 342（HPI）** 人类意图 u∈{引导,抵抗,无关扰动,恶意}，用阻抗/轨迹一致性估计 p(u|τ_human)；仅当 p(引导) 高且与另一正交源一致才采纳。

**定义 343（TTS）** 快环 ≥1kHz（TSB†+认证+控制，≤0.4ms）；慢环 10–20Hz（TOA/AEP/DBD，≤5ms），有界队列、过期丢弃、永不阻塞快环。

**定义 344（两级退避†）** 消解 U_act ⇒ α_act=0（resolution bonus）；未消解/超时/投毒/RCC 失败/TCG 越界 ⇒ α_act=1，逐指令退 R70 再退 R68。

**定义 345（J_HAPTIC）** 见符号表；Valid ⇔ J_BELIEF 有效 ∧ TOI_min≥τ_toi ∧ ECE_τ≤τ_τ ∧ κ_τ≥κ_min ∧ 可逆纪律与预算满足。

**定义 346（AIC-HAPTIC）** ℰ_HAPTIC=ℰ_BELIEF×ℰ_torque×ℰ_contact×ℰ_probe；覆盖偏置/尺度/温漂/饱和、打滑/冲击/形变/不可逆、探针致动/恢复失败/恶意 hand-guide。

**定义 347（VQAuditor-IV）** 审计探针必要性（EIG>0）、证书真实性、偏置-负载归因、恢复执行、hand-guide 单源采纳；回灌探针库剪枝与成本先验。

```python
# IP-275 TSB†：力矩结构化信念
def tsb_update(b_prev, o, tau_model, residual_net):
    b_pred = propagate_physics(b_prev, o.q, o.qd, o.qdd, b_prev.last_xi)
    logw = []
    for x in b_pred.particles:
        tau_hat = tau_model.regressor(x, o) @ x.eta + residual_net(x, o)
        logw.append(b_pred.log_prior(x) - 0.5 * mahalanobis(o.tau, tau_hat, b_pred.Sigma_tau))
    b = reweight_normalize_resample(b_pred, logw)
    b.eta = gaussian_moment(b, key=lambda x: x.eta)      # (θ, β_τ)
    return b

# IP-276/277/278 TOA + U3 + AEP
def aep_plan(b, probe_lib, budget, rcc, tcg):
    if not tcg.trustworthy(b):
        return None, U3(U_obs=entropy(b), U_act=0.0, U_struct=0.0)
    eta = b.eta
    best = None
    for g in probe_lib:
        if not budget.allow(g) or not rcc.certify(g, b) or not c_ras_wm.certify(g, b):
            continue
        Phi = regressor(g)
        F   = Phi.T @ inv(Sigma_tau) @ Phi
        w, V = eigh(F); w_pos = w[w > 1e-9]
        toi = w_pos.min() / w.max() if len(w_pos) else 0.0
        eig = 0.5 * logdet(np.eye(len(eta.mu)) + F @ eta.Sigma)
        score = eig - lambda_c * cost(g) - lambda_r * risk(g)
        if best is None or score > best.score:
            best = ProbeChoice(g, eig, score, toi, V[:, w <= 1e-9])
    if best is None or best.score <= 0:
        return None, U3(U_obs=entropy(b), U_act=0.0, U_struct=entropy(b))
    return best.g, U3(U_obs=0.0, U_act=entropy(b) - best.eig,
                    U_struct=structural_entropy(best.null))

# IP-279 RCC：可逆性证书
def certify_reversible(g, b):

    if grasp_margin(b) < EPS_GRASP:                return False
    if joint_torque_peak(g, b) > TAU_MAX:          return False
    if contact_mode_graph.enters_irreversible(g):  return False
    return contact_mode_graph.recoverable(g, g.pi_rec, b)

# IP-280 DBD：偏置-负载解耦激励基
def decoupling_probes():
    return rank_greedy([
        *static_pose_pairs(),          # 重力方向差 → 分 b_g 与 m
        *free_space_vs_contact(),      # 分关节摩擦与外接触
        *load_free_vs_loaded(),        # 分工具/负载惯量
        *dynamic_vs_quasi_static(),    # 分粘滞/库仑摩擦
    ])

# IP-281 TRC：三通道故障签名
def signature(r_res, delta_a, tau_res):
    if tau_res > T_TAU and delta_a <= T_A and r_res <= T_R: return "torque_bias_scale_drift"
    if tau_res > T_TAU and delta_a >  T_A:                  return "contact_or_payload_change"
    if tau_res <= T_TAU and delta_a >  T_A:                 return "flow_model_error"
    if r_res > T_R and tau_res > T_TAU:                     return "joint_friction_backlash"
    return "nominal"

# IP-287 HAPTIC 主闭环（快慢两时间尺度）
def HAPTIC_RAS_round(M, o):

    b = M.tsb.update(M.b_prev, o, M.tau_model, M.residual_net)      # 快环

        else:
            g = None
    sig = M.trc.signature(M.last_r_res, M.fma.anomaly(...), M.trc.tau_res(b))
    slow = sig in {"torque_bias_scale_drift", "contact_or_payload_change"}
    lam = max(M.efs.risk_scale(...), lam_floor(u3.floor(slow)))
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
```

## 4. 推导

**引理 23（激励生成信息）** EIG(g)=½logdet(I+FIM(g)Σ_η)。若 v∈null(FIM_0)，被动数据对 v 方向后验方差不变；若 ∃g∈𝒢_adm: vᵀFIM(g)v>0，则沿 v 的 CRLB 方差 O(1/N) 下降。系：R70 的被动 VoI 对零空间方向恒为 0；HAPTIC 的 U_act 正是这块。

**引理 24（偏置-负载主动解耦）** 若 D(ξ_0)=Y(ξ_0)C，则只有 η'=θ+Cβ_τ 可辨识；探针使 [Y,D] 非共线 ⇒ rank 增加 ≥1 ⇒ β 相应分量可辨识。双静态姿态令 D 差列离开 Y 常值列张成，故重力补偿偏置与质量可分。系：解耦是激励设计问题，不是滤波器问题。

**引理 25（可逆探针安全界）** 冲量 ≤ I_max + 接触模式逆可达 + 恢复策略在 ℛ 上收缩 ⇒ 状态偏差 ≤ B(I_max)，T_rec 内回 ε-管，不可逆失败概率 ≤ δ_rev，且不高于 R70 认证动作风险上界。系：可逆性证书让「摸」的风险回到「不摸」量级。

**引理 26（三通道可分）** A103（噪声条件独立、签名矩阵列满秩）下五类故障两两可分；力矩偏置签名为 (r_res≈0, Δa 弱, τ_res↑)，真实负载变化在 η̂ 收敛后 τ_res 回落，故「偏置 vs 变重」由时间形态 + DBD 对照区分。

**定理 20（HAPTIC ⊃ BELIEF ⊃ FLUID ⊃ R68）** A102–A104 下期望风险 ≤；预算 0 / 无可逆解 / EIG≤成本 / TCG 越界 / 故障签名要求保守时，HAPTIC 与 BELIEF 逐指令相同。安全侧不让步，效率侧获 U_act resolution bonus。

**定理 21（两时间尺度实时性）** 快环 ≤0.4ms；慢环有界队列、过期即丢；控制路径最坏延迟 ≤ R70+0.4ms；慢环超时只损失效率（α_act=1，退 R70），不损失安全。

## 7. 本轮最大风险

**一句话**：HAPTIC-RAS 把全部筹码押在「力矩/接触模型的保真度」与「可逆性证书的保守性」上——**若力矩信号被未建模的摩擦、背隙、温漂主导，或接触动力学跨域失真，主动探针就可能既摸不出真实参数，又摸进恢复策略也救不回的不可逆状态；此时系统会用一个错误的物理模型，自信地完成一次不可撤回的提问**——主动摸，可能比不摸更危险。
