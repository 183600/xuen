# 第 10 轮（新灵感循环第 1 轮；本轮灵感：「放置」×「Gazebo」）

> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**物理接地 + 放置安全 + 计算放置**。两个灵感词不是任务域的偶然漂移，而是对 v9 最大软肋的正面回应：v9 的块证书只由学习前向模型 F̂ 担保，而 F̂ 的误差恰在域偏移时最大、DA-ML 的 20 帧滑窗又恰好最慢，于是"最需要安全时证书最不可信"。Gazebo 提供一条**独立于 F̂ 的物理证据通道**；「放置」提供**接触、摩擦、支撑**这一最容易击穿学习模型的场景；「放置」的第二义（算力放置）则约束这条新通道不得侵占 50Hz 主环预算。所有新组件仍服从 v9 的中立元纪律：任一环节不可用 ⇒ 注入中立元，逐位等价退回 ACMD。

## 0. 直觉与动机

**灵感 1（Gazebo → 在线物理裁判，而不是离线训练工厂）**
直觉：v9 把中块安全押在冻结 LSTM-MPC 代理 F̂ 上。F̂ 是"从数据里学来的物理"，熟悉域好用，陌生域最不可信。Gazebo 是"写下来的物理"（刚体、接触、摩擦、重力）。我们**不**把 Gazebo 当训练数据工厂（离线、慢、需要 sim2real 迁移），而把它当作**在线、异步、低占空比的物理裁判**：在 5Hz 块边界，把数字孪生状态与候选动作块丢进 headless Gazebo 世界快进回放，得到物理轨迹 F_G；F̂ 与 F_G 的分歧 Δ_sim 就是**独立于 DA-ML 滑窗的第二信任源**。F̂ 开始说谎时，通常它先与物理引擎吵架。核心创新：**物理影子回放器（PhysicsShadowRollout, PSR）** 与 **数字孪生保真契约（DigitalTwinWorld, DTW）**。

**灵感 2（放置 → 释放之后才开始的危险）**
直觉：放置是家庭机器人最典型的"软约束密集"动作——搬运与接近阶段一切正常，释放瞬间物体可能滑落、倾倒或卡死。v9 的块证书只覆盖"执行轨迹中"的软指标，**不覆盖释放动作之后**的稳定性。核心创新：**放置证书（PlacementCertificate, PC）**：支撑多边形余量、有界扰动下质心投影余量、摩擦锥余量、释放期间隙余量；四项均在参数假设集上取**最坏值**。若证书不成立，释放退化为**放置保持（place-and-hold）**：保持夹持、回撤到预放置位；宁可"未完成放置"，也绝不"放掉"。这给释放通道一个**吸收式中立元** a_hold（与 v9 定义 536 对 AC 停驻端口的处理同构），而非常规恒等元。

**灵感 3（「放置」的第二义 → 影子的算力放置）**
直觉：PSR 每次回放 N 个参数假设 × K 步 × 物理子步，是重计算；若抢占 50Hz 主环，就会重演 v9 竭力消灭的算力债。把"Gazebo 放在哪"（专用核 / 共享核 / GPU / 机外）升级为一等契约：**计算放置契约（ComputePlacement, CP）**，带预算 B_GPO、截止期 D_rollout ≤ 200ms（一个块周期）与失败中立元。PSR 永远是可选增强：放不下就不放，退回 v9 的 Δ_dom 单信任源，而不是拖慢主环。

**方法论核心：为什么必须是"集合回放"而非"单点回放"**
如果 PSR 与 F̂ 使用同一套（错误的）质量/摩擦估计，二者会"一起错"，Δ_sim 反而很小——这既是本轮的洞见，也是本轮的命门。因此 PSR 不做单点回放，而在**参数假设集** H_t = {h₁..h_N} 上做集合回放，覆盖质量、摩擦、质心、几何的合理不确定域；证书要求**最坏假设**下仍安全。Gazebo 检验的不再是"我猜的物理对不对"，而是"在我不确定的物理中，最坏的那个会不会翻、滑、撞"。这把"仿真保真度"问题转化为"假设集覆盖度"问题——后者可被 E581 直接证伪。

## 1. 研究问题（轮次升级版）

- **Q1（影子可信边界）**：在什么假设下 Δ_sim 能在 DA-ML 滑窗之前检测到 F̂ 失效？当真实物理不在 Gazebo 模型类内（h* ∉ H_t）或 F̂ 与影子共享同一参数错误时，二者会否一起失明？如何在线识别这种"共同无知"？
- **Q2（放置安全边界）**：放置证书的四项最坏余量在准静态刚体、有界扰动下是否充分？place-and-hold 能否把"释放失败"从"掉物/损坏"降级为"未完成"，且不破坏 v8/v9 的安全不变式？
- **Q3（计算放置与退化）**：PSR 的算力放置如何接入 v9 的契约中间件与 EDF 预算，使 50Hz 主环 WCET 不变；资源不足时如何严格退化到 v9 而无可观测行为漂移？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 物理影子接地律（Physics-Shadow Grounding, PSR）**
在块边界对候选块生成**参数集合物理影子**：∀h∈H_t 回放得 F_h，取最坏指标与模型-物理分歧 Δ_sim；影子结果与 F̂ 的块证书**联合**决定 K_eff，且影子永不阻塞 50Hz 主环（异步、最多一个在途请求、过期结果丢弃）。

**P14 放置证书律（Placement Certificate, PC）**
放置类块必须以四元证书 φ_place=(m_sup, m_com, m_fric, m_clr) 在 H_t 上取最坏值为前提；任一项越界 ⇒ 释放动作替换为 a_hold（保持夹持、回撤），且 a_hold 具有吸收性（未重新认证前不得再次释放）。

**P15 计算放置与保真退化律（Compute Placement & Fidelity, CP）**
PSR 的执行位置 π_GPO 与其预算 (B_GPO, D_rollout) 必须作为契约声明并经部署期可行性校验；共享放置需准入控制 ΣŴ ≤ B。任一条件不满足 ⇒ 注入 v^⊥（Δ_sim≡0、H_t 收缩为点估计、PC 关闭），系统逐位等价退回 v9。

## 3. 与基线的接口（如何退化）

- **GPO/DTW 失效**（同步超时、Rollout 超时、孪生漂移越界）⇒ v^⊥：Δ_sim≡0、H_t←{ĥ}、K_eff=K_eff^v9，等价 v9 的 Δ_dom 单信任源；
- **PC 失效**（放置证书模块不可用）⇒ 释放策略回退 v9 的通用块结束语义，但保留"无法认证即保持"的保守兜底（安全侧单调）；
- **CP 失效**（专用核/GPU/机外均不可用）⇒ 影子降频或直接跳过（v^⊥），主环不受影响；
- v9 的 AC/MW/ID 失效 ⇒ 沿用 v9 的 Level-1/2/3；
- v8 的 DA/SPR/Cal 失效 ⇒ 中立元注入，等价 v7；
- 全部失效 ⇒ 完整退回 MetricVoiceGauge-OTL-GC-ER v7，再退回 v6。

## 4. 预期贡献

1. **物理影子回放**框架：用参数集合上的 Gazebo 集合回放，把"学习模型的信任"变成"最坏假设下的物理可接受性"，给块证书提供独立第二证据源；
2. **放置证书与放置保持**：把安全性从"执行轨迹中"延伸到"释放之后"，并用吸收式中立元把释放失败安全降级为未完成；
3. **共同无知的显式边界**：明确提出并实验证伪"影子与 F̂ 共享参数错误时会一起失明"（E581），拒绝把仿真当万能裁判；
4. **计算放置契约**：让重计算影子可被放置、可被预算、可被降级，使 50Hz 主环 WCET 与 v9 持平；
5. E571–E590 覆盖孪生保真、检测时延、放置稳定性、集合覆盖、算力隔离、退化等价与端到端放置任务。

## 5. 本轮最大风险

**一句话**：Gazebo 影子与学习模型 F̂ 共享同一套物体参数估计，域偏移时新物体的质量/摩擦/几何对二者**同时未知**——Δ_sim 可能很小而二者一起错；影子的提前检测只在"真实参数落在假设集 H_t 内"时成立，若 h* ∉ H_t，物理裁判会在最需要它的时刻与 F̂ 一起失明。

## 1. 符号体系增量（定义 540–547）

**新增定义 540（放置动作 PlacementAction）** π_place = (g, w, ρ)。g 为夹持状态（开/合、夹持力 F_g），w 为目标位姿（位置 + 朝向），ρ 为释放策略。放置成功 ⇔ 释放后物体在 w 处稳定驻留 ≥ T_hold=0.5s、位姿误差 ≤ ε_w、释放过程中与场景无碰撞。ρ=hold 时**不释放**，止于预放置位 φ_pre；ρ=preplace_then_release 允许先到 φ_pre 再二次认证后释放。

**新增定义 541（放置证书 PlacementCertificate）** 对给定 π_place 与假设 h，定义四项正规余量：
```
m_sup  = signed_dist( proj_xy(CoM), ∂SupportPolygon )        # 质心投影到支撑多边形边界的有符号距离
m_com  = min_{W_ext ∈ 𝒲} margin( CoM 在 W_ext 下仍可平衡 )   # 有界外力矩集 𝒲 下的质心稳定余量
m_fric = min_{c∈Contacts} ( μ_c·N_c − |F_t,c| ) / N_c        # 摩擦锥归一化余量
m_clr  = min_{t∈release} dist( object ∪ gripper, O \ support )  # 释放期间隙
```
证书在最坏假设上有效 ⇔ `min_{h∈H_t} min(m_sup,m_com,m_fric,m_clr) ≥ (ε_sup,ε_com,ε_fric,ε_clr)`。任一项越界 ⇒ ρ 强制置为 hold。

**新增定义 542（参数假设集 HypothesisSet）** H_t 由三源维护：(i) 视觉质量/尺寸先验（物体类别 + 单目尺度）；(ii) 在线交互辨识（抬升力矩估质量、滑移事件估 μ、抓取点估质心）；(iii) 无先验时的域随机化先验。H_t 必须包含**保守极值**（μ 取下分位、m 取上分位、c 取最不利象限）。若后验退化（样本 < n_min 且无先验），H_t 坍缩为 {ĥ} 并置 PC 为"不可认证"，由 P14 触发 hold。

**新增定义 543（物理影子回放 PhysicsShadowRollout）** 在每个块边界对候选块 ζ=(a^{1:K},Ĉ,P) 与每个 h∈H_t，从数字孪生快照 s_t 出发做 headless Gazebo 回放，得 F_h。定义：
```
ĝ_min^sim = min_{h,k} F_h^clearance(k)
ê_max^sim = max_{h,k} F_h^effort(k)
Σ_sim     = max_{h,k,j} |F_h^metric(k) − F_j^metric(k)|
Δ_sim     = max_k |F̂^metric(k) − F_{h₀}^metric(k)|       # h₀ 为当前点估计
place_sim = min_{h} 1[ placed_stable_h ∧ ¬slip_h ∧ ¬topple_h ]
```
影子"接地"有效 ⇔ Δ_sim ≤ β_sim ∧ Σ_sim ≤ τ_spread ∧ place_sim = 1 ∧ 最坏指标仍满足安全界。工程上预 spawn N 个影子世界（N=8），每块仅用 set_model_state 批量复位 + 定步长快进，避免重复加载世界。

**新增定义 544（数字孪生与保真契约 DigitalTwinWorld / FidelityContract）** DTW=(机器人关节、物体位姿与速度、障碍网格、摩擦参数、时间戳 τ_sync)。契约 κ_GPO=(D_sync,Ŵ_sync,D_roll,Ŵ_roll,B_GPO,v^⊥,π_GPO)。v^⊥="无影子"：Δ_sim≡0、Σ_sim≡0、H_t←{ĥ}、PC 关闭。部署期校验 D_sync+D_roll ≤ 块周期 200ms（允许跨块复用）与 B_GPO 不侵占决策 20ms 预算。

**新增定义 545（影子信任门控 ShadowTrustGate）**
```
K_sim(t) = 1                                        若 Δ_sim > β_sim ∨ Σ_sim > τ_spread ∨ place_sim = 0
         = max(1, ⌊K_max·(1 − Δ_sim/β_sim)⌋)        否则
K_eff(t) = min( K_eff^v9(t), K_sim(t) )
```
即影子只能**收紧** v9 的块长，永不放宽；Δ_sim 越大块越短，极端回到 K=1 的 v8 逐步语义。同一 Δ_sim 越阈信号也可在中块触发 p* 中止（预占通道，见骨架）。

**新增定义 546（放置保持 PlaceHold）** a_hold =（从当前位置回撤至预放置位 φ_pre，保持夹持力 F_g ≥ F_min，禁止释放）。吸收性：一旦进入 a_hold，后续 release 请求必须重新通过定义 541 认证，否则持续 hold；a_hold 不是恒等元而是安全吸收元，故单独验证（区别于恒等元 v_m^⊥）。

**新增定义 547（计算放置契约 ComputePlacement）** π_GPO ∈ {dedicated_core, shared_core, gpu_offboard, offboard}。契约含预算 B_GPO 与最迟完成 D_roll；共享放置需准入控制 Σ_m Ŵ_m ≤ B_shared。任一放置不可用 ⇒ v^⊥（跳过影子，退回 v9），且**不得**以延长主环周期为代价换取影子执行。

```
δ_trigger = {σ < τ_safe ∧ γ_grasp valid ∧ Δ_dom < τ_dom ∧ risk_SLAM < τ_SLAM
```

## 3. 关键算法骨架

```python
# IP-359 DigitalTwinWorld：数字孪生同步与影子世界复位
class DigitalTwinWorld:
    def __init__(self, shadow_worlds, sync_contract):
        self.worlds = shadow_worlds          # N 个预热 headless Gazebo world（专用核/GPU）
        self.contract = sync_contract

    def sync(self, M, obs):
        """从 SLAM/检测/关节状态写入孪生；返回快照 s_t 与时间戳"""
        s_t = Snapshot(
            joints=M.get_joint_states(),
            objects=obs.detected_objects(),          # 位姿、速度、类别先验
            obstacles=M.slam_backend.get_local_map(),
            friction=obs.friction_posterior(),       # 均值 + 区间
            t=now_ms(),
        )
        for w in self.worlds:                        # set_pose 批量复位，不重载世界
            w.set_model_states(s_t)
        return s_t

    def rollout(self, world, s_t, actions, h, sim_dt=0.004):
        world.reset_to(s_t)
        world.set_parameters(h)                      # mass / mu / com / geom_scale
        traj = []
        for a in actions:
            world.apply_action(a)
            for _ in range(int(0.02 / sim_dt)):      # 一个控制步 = 20ms 物理子步
                world.step()
            traj.append(world.metrics())             # clearance/effort/contact
        return traj, world.placement_outcome()


# IP-357 PhysicsShadowOracle：参数集合物理影子回放
class PhysicsShadowOracle:
    def __init__(self, dtw, hypotheses, beta_sim=0.03, tau_spread=0.05, N=8):
        self.dtw, self.H = dtw, hypotheses
        self.beta_sim, self.tau_spread = beta_sim, tau_spread
        self.pending = None                          # 最多一个在途请求

    def request(self, s_t, chunk, h0):
        if self.pending is not None:
            return None                              # 背压：丢新请求，绝不阻塞主环
        self.pending = (s_t, chunk, h0)
        return self

    def poll(self):
        """非阻塞取回；过期结果丢弃（时间戳早于本块边界则作废）"""
        if self.pending is None:
            return None
        s_t, chunk, h0 = self.pending
        self.pending = None
        trajs, outcomes = {}, {}
        for i, h in enumerate(self.H[:len(self.dtw.worlds)]):
            trajs[h], outcomes[h] = self.dtw.rollout(self.dtw.worlds[i], s_t, chunk.actions, h)
        delta_sim = max(abs(chunk.forecast[k] - trajs[h0][k]) for k in range(len(chunk.actions)))
        spread = max(max(t[k] - min(trajs[h2][k] for h2 in trajs) for t in trajs.values())
                     for k in range(len(chunk.actions)))
        place_sim = int(all(outcomes[h] == 'stable' for h in outcomes))
        return ShadowEvidence(delta_sim, spread, place_sim, trajs, outcomes)


# IP-358 PlacementCertifier：放置证书与放置保持
class PlacementCertifier:
    def __init__(self, eps=(0.03, 0.02, 0.15, 0.05)):
        self.eps_sup, self.eps_com, self.eps_fric, self.eps_clr = eps

    def certify(self, s_t, pi_place, H):
        for h in H:
            m_sup  = support_polygon_margin(s_t, pi_place.w, h)
            m_com  = com_margin_under_disturbance(s_t, pi_place.w, h)
            m_fric = friction_cone_margin(s_t, pi_place, h)
            m_clr  = release_clearance(s_t, pi_place.w, h)
            if (m_sup < self.eps_sup or m_com < self.eps_com
                    or m_fric < self.eps_fric or m_clr < self.eps_clr):
                return INVALID                        # 任最坏假设不成立
        return VALID

    def release_policy(self, s_t, pi_place, H):
        return 'release' if self.certify(s_t, pi_place, H) == VALID else 'hold'


def shadow_gate(K_eff_v9, evidence, K_max=10, beta_sim=0.03, tau_spread=0.05):
    if evidence is None:                              # 影子不可用 ⇒ v^⊥
        return K_eff_v9
    if evidence.delta_sim > beta_sim or evidence.spread > tau_spread or not evidence.place_sim:
        return 1
    return min(K_eff_v9, max(1, int(K_max * (1 - evidence.delta_sim / beta_sim))))
```

## 4. 推导

**引理 87（影子的提前检测边界）** 设真实物理可由 Gazebo 模型类表示，真实参数 h*∈H_t，孪生状态误差 ‖s_t−s_t*‖ ≤ δ_s，Gazebo 相对真值的指标误差 ≤ ε_g，且 F̂ 的误差 e_F(t) 在偏移期间以速率 ρ>0 增长。则
```
Δ_sim(t) ≥ e_F(t) − ε_g − L·δ_s,
```
故 Δ_sim > β_sim 的检测时刻满足 `t_detect ≤ t₀ + (β_sim + ε_g + L·δ_s − e_F(t₀))/ρ + τ_sync + τ_roll`。当 τ_sync+τ_roll + 上式松弛 < DA-ML 的 20 帧窗（400ms）时，影子严格早于 v9 的域检测。**Remark（边界）**：若 h*∉H_t 或 F̂ 与影子共享同一错误参数，则 e_F 与影子的系统偏差同向，Δ_sim 可保持很小，引理不成立——此即 E581 要证伪的"共同无知"。

**引理 88（集合放置安全的充分性）** 设物体为刚体、接触准静态、外力矩集 𝒲 有界且已计入 m_com。若对 ∀h∈H_t 都有 m_sup>0（质心投影严格在支撑多边形内）、m_fric>0（所有接触力在摩擦锥内）、m_com ≥ ε_com（可平衡 𝒲 中任意扰动）、m_clr ≥ ε_clr，则存在一组满足摩擦锥与单侧接触约束的接触力平衡重力与 W_ext，放置后物体处于静态平衡，不发生滑移或倾覆。若证书不成立且执行 a_hold，则夹持力 F_g ≥ F_min = m_max·g/(2μ_g,min)+margin 保证不脱手；因此"释放失败"至多降级为"保持未完成"，不会降级为"掉落"。∎

**引理 89（PSR/PC/CP 中立元退化与 v9 逐位等价）** 取 v^⊥：Δ_sim≡0（恒 ≤β_sim）、Σ_sim≡0、H_t←{ĥ}、place_sim≡1、PC 关闭并把释放交还 v9 语义。则 K_sim≡K_max，K_eff=min(K_eff^v9,K_max)=K_eff^v9；影子契约不执行任何回放，主环调用序列与 v9 完全一致。加之 v9 的引理 83（MW 中立元逐位等价），对每个周期取值集合不变，故 v10 在 v^⊥ 下逐位等价 v9 ACMD。∎

**引理 90（计算放置隔离与 50Hz 守恒）** 若 π_GPO=dedicated_core 且 B_GPO 独立于决策核，或 π_GPO=shared_core 且经准入 ΣŴ ≤ B_shared，且每块至多一个在途影子请求（定义 543 的背压），则影子对主环的阻塞时间为 0；过期结果按时间戳丢弃，队列长度 ≤ 1。因此每周期总执行仍为"感知 ≤2ms + 决策 ≤20ms"，50Hz 保持；影子算力被放置到主环之外，摊销成本 ≤ B_GPO/K 每周期。若任一放置不可用 ⇒ v^⊥（引理 89），仍不延长周期。∎

**引理 91（集合回放的保守性与代价）** 最坏值聚合对 ∀h∈H_t 的上界成立，故当 H_t 覆盖真值时，证书保守有效；代价为 O(N·K·S_phys)（S_phys=20ms/sim_dt 子步），每块一次、摊销到 K 个周期为 O(N·S_phys)。若 H_t 过宽，保守性导致 K_eff 频繁收缩至 1，退化为 v9 逐步语义（安全不损失、算力收益下降）；若 H_t 过窄且漏掉真值，保守性失效（引理 87/88 前提破坏），由 E573/E581 监测覆盖率与实际失效率的偏差。∎

## 8. 本轮最大风险

**一句话**：Gazebo 影子与学习模型 F̂ 共享同一套物体参数估计，域偏移时新物体的质量/摩擦/几何对二者**同时未知**——Δ_sim 可能很小而二者一起错；影子的提前检测只在"真实参数落在假设集 H_t 内"时成立，若 h* ∉ H_t，物理裁判会在最需要它的时刻与 F̂ 一起失明。
