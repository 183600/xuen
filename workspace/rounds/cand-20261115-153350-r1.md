# 第 8 轮（灵感循环重启后的第 1 轮；本轮灵感：「情感语音」×「柔顺控制」）

> **基线**：第 7 轮 MetricVoiceGauge-OTL-GC-ER v7（定义 493–525；引理 69–76；实验 E493–E525）。
> 本轮纪律：**情感只调风格、不改目标；柔顺只在证书内变化；任一模块失效可单跳退回 v7**。
> 与 v7 的差别：v7 让情感去调“软奖励权重”，误识别会移动价值函数；本轮把情感限制在“执行风格通道”，用柔顺控制这一物理可证书的旋钮承载它。

## 0. 直觉与动机

**灵感 1（情感语音 → 控制相关的副语言先验）**
直觉：同一句“把杯子递给我”，语速慢、基频抖动大、能量低时，人听起来是犹豫/焦虑；语速快、基频高、能量强时，听起来是自信/急促。现有 v7 只把这类信号汇成 `emo(s)` 去改奖励权重，等于让“听错情绪”直接改“想要什么”。更稳妥的做法是：把副语言通道单独抽出来，只用来调节**执行风格**——机器人仍然去执行原来的语义目标，只是在焦虑时更柔、更慢、更让力，在自信时略硬、略快，但**力上限与硬约束完全不动**。核心创新：**情感-风格分离（Affect–Style Separation）**。

**灵感 2（柔顺控制 → 连续、有界、可证书的顺应旋钮）**
直觉：导纳/阻抗控制给出的是 `M_d ẍ + D_d ẋ + K_d x = F_ext` 这样的连续参数族。它天然适合承载“情感风格”：顺应指数 κ 从 0（硬）连续滑到 1（很软），既不会像离散档位那样跳变，也能把参数关进一个认证多面体。但时变参数会注入能量，必须用**能量罐/无源观测器**守住无源性，否则“温柔模式”可能变成振荡源。核心创新：**有界柔顺阶梯（Bounded Compliance Ladder, BCL）+ 无源时变插值**。

**交叉直觉（两尺度闭环）**
情感语音是慢信号（秒级、带噪、会误判），柔顺控制是快信号（毫秒级、要稳定）。所以做**双时间尺度**：慢层 10 Hz 估计情感并输出 κ 与置信度；快层 1 kHz 在认证参数集内执行导纳控制。慢层永远不能直接写低层力矩，只能写“参数目标”；快层有权拒绝越界目标。这样把“情绪误判”的最坏后果，从“改任务”压缩成“在柔顺多面体内换一个同样安全的参数点”。

## 1. 研究问题

- **Q1（风格-目标分离）**：如何形式化保证情感语音的任意扰动都不改变语义目标 g 与硬约束 M₀，只改变执行风格 s？
- **Q2（有界柔顺映射）**：如何设计从情感坐标到顺应指数 κ、再到 `(M_d, D_d, K_d, v_max)` 的单调、Lipschitz、可证书映射，并保证力上限 F_max 与情感无关？
- **Q3（时变无源性）**：当 κ(t) 随情感连续变化时，如何保证导纳闭环仍无源、不因参数切换而振荡？
- **Q4（不确定性与退化）**：情感置信度低、说话人域偏移、或柔顺层故障时，如何连续退化回名义刚度并最终等价于 v7？

## 2. 设计原则（P10–P14）

**P10 风格-目标分离（Style–Goal Separation, SGS）**
语音管道拆成两条互不写穿的信道：
```
g = NLI(ASR(u))            # 目标信道：只由文本语义决定
s = AffectStyle(paraling(u))  # 风格信道：只由副语言决定
command = (g, s),  s 不可写 g，不可写 M₀
```
情感模块的返回值在类型上就没有“目标”字段，从接口层面杜绝“情绪改任务”。

**P11 有界柔顺阶梯（Bounded Compliance Ladder, BCL）**
顺应指数 κ ∈ [0,1] 由情感坐标单调映射，并被限幅与限速：
```
κ_raw = κ₀ + α_c·caution − α_u·urgency
κ(t)  = slew(clip(κ_raw, κ_min, κ_max), δκ)
```
`caution` 越大越柔（κ↑，K↓、D↑、v_max↓）；`urgency` 只允许在**力上限不变**的前提下小幅降 κ、提 v_max。

**P12 认证参数多面体（Certified Compliance Polytope, CCP）**
```
C = { (M_d, D_d, K_d) : M_d∈[M⁻,M⁺], K_d∈[K⁻,K⁺], D_d ≥ 2ζ_min·√(M_d·K_d) }
```
所有 κ 的插值结果必须落在 C 内；`F_max`、`v_max` 的硬上界不参与情感映射。

**P13 无源时变插值（Passivity-Preserving Interpolation, PPI）**
维护能量罐 `E_t`；参数变化时用罐中能量补偿参数注入项，罐空则**冻结 κ**并注入耗散，绝不允许参数继续朝增能方向变化。

**P14 置信门控与迟滞（Confidence Gate + Hysteresis）**
仅当 `conf_emo ≥ τ_emo` 且后验熵 `H(p) ≤ H_max` 时才更新 κ；否则保持上一值并缓慢回名义 κ₀。用迟滞带与保持时间抑制“情绪抖动 → κ 抖动 → 机器人抖动”。

## 3. 与基线的接口（如何退化）

- 情感语音模块失效/低置信 ⇒ κ ← κ₀，s ← s₀，**语义目标与硬约束不变**，等价于“固定名义柔顺”的 v7；
- 柔顺控制层故障/无源观测器触发 ⇒ 冻结 κ（或切安全保持/急停），控制权交回 v7 的刚性安全路径；
- 两模块同时不可用 ⇒ 完整退回 v7 的 MetricVoiceGauge-OTL-GC-ER，行为一致。

## 4. 预期贡献

1. **风格-目标分离不变式**：把情感从“价值函数修改器”降格为“执行风格参数”，给出可检查的类型级与形式化约束；
2. **有界柔顺阶梯**：情感坐标 → 认证阻抗参数族的单调 Lipschitz 映射，力上限与硬约束对情感完全免疫；
3. **无源时变导纳控制**：能量罐 + 参数限速，保证 κ(t) 连续变化下闭环无源；
4. **完整双尺度闭环**：E526–E540 覆盖情感识别校准、风格分离、柔顺映射、无源验证、接触安全与退化等价。

## 5. 本轮最大风险

**一句话**：情感语音的后验在跨说话人/噪声下可能系统性偏移，而“迟滞 + 限速 + 有界多面体”只能限制其后果、不能消除误判本身——若校准集与真实操作员分布错配，系统可能长期停在“过度温柔”或“过度强硬”的一个安全但低效的角落，且用户难以察觉这种隐性风格漂移。

# 第 8 轮产物 · 创新点清单 v8：**MetricVoiceGauge-ECL**（Emotional-Compliance-Ladder）

> 背景：第 7 轮 MetricVoiceGauge-OTL-GC-ER v7（定义 493–525；引理 69–76；实验 E493–E525）。
> 本轮灵感：「情感语音」×「柔顺控制」
> **继承纪律**：v7 的六不变式（CVC 闭环、SpatialCert、RT-CVC 任务模型、FaultCert、PrimitiveGraph 接地、严格退化链）与 v7 三增强（OTL/GCT/ER）全部保留。本轮新增组件均为**风格层可选增强**：任一失效 ⇒ 退回 v7（其中情感重权 ER 失效 ⇒ β=0）。
> **实现修正**：同时修正 v7 骨架的三处不一致：`self.η` → `self.eta`；`geo_thresholds` 的 `width/depth/force` 与 `max_width` 键混用；50 Hz 预算下“WCET ≤ 22ms”口径改为“周期 20ms，主路径 ≤ 17ms，新增分支 ≤ 3ms”。

## 1. 符号体系增量（定义 526–535）

| 符号 | 含义 |
|---|---|
| `u` | 一次语音语句（音频 + 可选文本） |
| `φ(u)` | 副语言特征向量：`f0_mean, f0_std, energy, rate, jitter, shimmer, HNR`（归一化） |
| `p(a∣φ)` | 情感后验，`a ∈ A = {calm, anxious, confident, urgent, frustrated}` |
| `conf_emo = max_a p(a∣φ)` | 情感置信度 |
| `H(p)` | 情感后验熵，用于门控 |
| `caution, urgency ∈ [−1,1] / [0,1]` | 控制相关情感坐标 |
| `κ ∈ [0,1]` | 顺应指数：0=最硬，1=最柔 |
| `κ₀` | 名义顺应指数（基线值） |
| `(M_d, D_d, K_d)` | 导纳/阻抗参数：虚拟质量、阻尼、刚度 |
| `C` | 认证柔顺多面体（见定义 531） |
| `F_max` | 接触力硬上限（**情感不变**） |
| `E_t` | 能量罐能量 |
| `s = (κ, v_max)` | 风格向量；不含目标、不含硬约束 |
| `g` | 语义目标（v7 的指令规格 ι 的目标子集） |
| `SCC` | 柔顺软证书 `SoftComplianceCert` |
| `Φ_ECL` | 情感-柔顺双尺度闭环标识 |

**定义 526（情感语音观测 EmotionalSpeechObservation）**
一次语句 `u` 被拆成两条信道：
```
O(u) = (text, conf_asr, φ(u))          # 语义信道 + 副语言信道
p(a∣φ) = CalibratedEmotionClassifier(φ(u)),  a ∈ A
```
其中分类器必须经过温度缩放或等渗回归校准；输出的是**后验**而非 logits。

**定义 527（控制相关情感坐标 Control-Relevant Affect Coordinates）**
只在“影响执行风格”的两个方向上投影，避免用整个情感向量直接驱动控制：
```
caution = clip( p(anxious) + p(frustrated) − p(confident), −1, 1 )
urgency = clip( p(urgent), 0, 1 )
```
直觉：`caution` 高 → 更柔更慢；`urgency` 高 → 允许略硬略快，但力上限不变。

**定义 528（风格-目标分离不变式 Style–Goal Separation Invariant, SGSI）**
对任意语句 `u` 与任意副语言扰动 `φ, φ'`：
```
g = NLI(ASR(u))     与 φ 无关
s = Style(φ(u))     不含 g，也不写 M₀
exec = π(g, s),     且 ∂M₀/∂s ≡ 0，∂g/∂s ≡ 0
```
类型级实现约束：`Style` 对象不允许携带 `goal / intent / constraint` 字段；`g` 的构造路径不读 `φ`。

**定义 529（有界柔顺阶梯 Bounded Compliance Ladder, BCL）**
```
κ_raw = κ₀ + α_c · caution − α_u · urgency
κ(t)  = slew( clip(κ_raw, 0, 1), δκ, Δt )
v_max(t) = V_MAX_HARD − κ(t) · (V_MAX_HARD − V_MIN)
F_max(t) = F_HARD                                  # 与 κ 无关，恒等
(M_d, D_d, K_d)(t) = Interp_C(κ(t))
```
要求 `|∂κ/∂caution| = α_c`、`|∂κ/∂urgency| = α_u` 有界，因而是 Lipschitz 的。

**定义 530（认证柔顺多面体 Certified Compliance Polytope, CCP）**
```
C = { (M_d, D_d, K_d) : M_d ∈ [M⁻, M⁺], K_d ∈ [K⁻, K⁺],
      D_d ∈ [D⁻, D⁺],  D_d ≥ 2 ζ_min √(M_d K_d) }
```
`Interp_C` 是 `[0,1] → C` 的连续映射；超出部分投影回 C（而不是直接放行）。

**定义 531（情感-柔顺闭环 Emotional-Compliance Loop）**
```
Φ_ECL = φ(u) → (caution, urgency, conf_emo) → κ(t) → (M_d, D_d, K_d)
        → x_c(t) → F_ext(t) → 能量罐/无源观测器 → κ 冻结或续调
```

**定义 532（柔顺软证书 SoftComplianceCert）**
```
SCC = (κ, conf_emo, E_t, force_margin = F_max − ‖F_ext‖,
       passive ∈ {true,false}, trigger ∈ {∅, "force", "passivity", "confidence"})
```

**定义 533（迟滞与保持 Hysteresis-Hold）**
仅当 `|κ_raw − κ_prev| > h` 或同一方向持续 `T_hold` 时更新；否则保持。用于抑制情绪抖动引起的机械抖动。

**定义 534（置信门控 Confidence Gate）**
```
usable(p) ⇔ conf_emo ≥ τ_emo ∧ H(p) ≤ H_max
```
不可用时执行“向 κ₀ 的限速回退”，而不是立即跳回 κ₀。

**定义 535（柔顺退化桥 Compliance Degradation Bridge）**
```
δ_ECL =
  affect_unusable      ⇒ κ ← slew(κ, κ₀)
  passivity_exhausted  ⇒ freeze(κ); inject_damping()
  force_violation      ⇒ F_cmd ← clip(F_cmd, −F_max, F_max); trigger_safety()
  any_layer_fault      ⇒ v7_fallback()
```

## 2. 形式化定义（要点）

**定义 526（情感语音观测）**：见上。强调输出为**校准后验**；未校准的 softmax 不得进入控制。

**定义 527（控制相关情感坐标）**：只保留 `caution/urgency` 两个自由度，降低误识别对控制的影响维度。

**定义 528（SGSI）**：这是本轮的核心安全不变式。它把“情感误判”的最坏影响限制在风格空间，而风格空间又被 C 与 `F_max` 夹住。

**定义 529（BCL）**：κ 的单调语义为“越 caution 越柔”；`F_max` 明确写成与 κ 无关的常量项。

**定义 530（CCP）**：`D_d ≥ 2ζ_min√(M_d K_d)` 是 LTI 导纳的阻尼下界，保证固定参数下无源且非振荡。

**定义 531（Φ_ECL）**：慢层只写“参数目标”，快层有权拒绝越界目标；这是双尺度架构的关键权限划分。

**定义 532（SCC）**：证书与 v7 的 SpatialCert 并列发布，任一为 false 都必须触发对应退化。

**定义 533（迟滞）**：与定义 534 一起，把“情感抖动”转成“风格低频漂移”。

**定义 534（置信门控）**：低置信不是“猜一个”，而是“回名义”。

**定义 535（退化桥）**：每一行都能对应到 v7 的一个具体入口，保证单跳退化。

## 3. 关键算法骨架

```python
import math

K_MIN, K_MAX = 50.0, 800.0      # N/m
D_MIN, D_MAX = 5.0, 120.0       # N·s/m
M_MIN, M_MAX = 0.5, 2.0         # kg
ZETA_MIN = 0.7
F_HARD = 40.0                   # N，情感不变
V_MIN, V_MAX_HARD = 0.02, 0.25  # m/s


def clip(x, lo, hi):
    return max(lo, min(hi, x))


class Style:
    """仅含执行风格；类型上没有 goal/intent 字段，落实 SGSI。"""
    def __init__(self, kappa, v_max, conf, gated=False):
        self.kappa = kappa
        self.v_max = v_max
        self.conf = conf
        self.gated = gated

    @staticmethod
    def nominal(kappa0=0.5):
        return Style(kappa0, V_MAX_HARD - kappa0 * (V_MAX_HARD - V_MIN), 1.0, True)


# IP-351：情感语音 → 风格
class EmotionalSpeechStyleEstimator:
    def __init__(self, classifier, tau_emo=0.75, H_max=0.6,
                 kappa0=0.5, alpha_c=0.35, alpha_u=0.20,
                 delta_kappa=0.05, hysteresis=0.02):
        self.clf = classifier
        self.tau_emo = tau_emo
        self.H_max = H_max
        self.kappa0 = kappa0
        self.alpha_c = alpha_c
        self.alpha_u = alpha_u
        self.delta_kappa = delta_kappa
        self.hysteresis = hysteresis
        self.kappa_prev = kappa0

    def _prosody(self, utterance):
        # 归一化后的 f0_mean/f0_std/energy/rate/jitter/shimmer/HNR
        return utterance.paralinguistic

    @staticmethod
    def _coordinates(p):
        caution = (p.get("anxious", 0.0) + p.get("frustrated", 0.0)
                   - p.get("confident", 0.0))
        urgency = p.get("urgent", 0.0)
        return clip(caution, -1.0, 1.0), clip(urgency, 0.0, 1.0)

    def infer(self, utterance):
        phi = self._prosody(utterance)
        p = self.clf.predict_proba(phi)              # dict over A
        conf = max(p.values())
        H = -sum(v * math.log(v + 1e-12) for v in p.values() if v > 0.0)

        # 定义 534：置信门控 → 限速回名义
        if conf < self.tau_emo or H > self.H_max:
            step = clip(self.kappa0 - self.kappa_prev,
                        -self.delta_kappa, self.delta_kappa)
            self.kappa_prev = clip(self.kappa_prev + step, 0.0, 1.0)
            return Style(self.kappa_prev, self._v_max(self.kappa_prev), conf, gated=True)

        caution, urgency = self._coordinates(p)
        kappa_raw = clip(self.kappa0 + self.alpha_c * caution
                         - self.alpha_u * urgency, 0.0, 1.0)

        # 定义 533：迟滞 + 限速
        if abs(kappa_raw - self.kappa_prev) <= self.hysteresis:
            kappa = self.kappa_prev
        else:
            step = clip(kappa_raw - self.kappa_prev,
                        -self.delta_kappa, self.delta_kappa)
            kappa = clip(self.kappa_prev + step, 0.0, 1.0)
        self.kappa_prev = kappa
        return Style(kappa, self._v_max(kappa), conf)

    @staticmethod
    def _v_max(kappa):
        return V_MAX_HARD - kappa * (V_MAX_HARD - V_MIN)


# IP-352：κ → 认证多面体内的阻抗参数
class BoundedComplianceScheduler:
    def __init__(self, kappa0=0.5):
        self.kappa0 = kappa0

    def to_impedance(self, kappa):
        kappa = clip(kappa, 0.0, 1.0)
        K_d = K_MAX - kappa * (K_MAX - K_MIN)        # κ↑ → K↓
        D_d = D_MIN + kappa * (D_MAX - D_MIN)        # κ↑ → D↑
        D_floor = 2.0 * ZETA_MIN * math.sqrt(M_MIN * K_d)
        D_d = max(D_d, D_floor)
        M_d = M_MIN
        # 投影回 CCP（定义 530）
        M_d = clip(M_d, M_MIN, M_MAX)
        K_d = clip(K_d, K_MIN, K_MAX)
        D_d = clip(D_d, D_MIN, D_MAX)
        return M_d, D_d, K_d

    def in_polytope(self, M_d, D_d, K_d):
        return (M_MIN <= M_d <= M_MAX and K_MIN <= K_d <= K_MAX
                and D_MIN <= D_d <= D_MAX
                and D_d >= 2.0 * ZETA_MIN * math.sqrt(M_d * K_d))


# IP-353：无源时变导纳内环（1 kHz）
class PassivityAwareAdmittance:
    def __init__(self, scheduler, E0=10.0, E_min=0.5, E_max=20.0,
                 delta_kappa=0.05, dt=0.001):
        self.sched = scheduler
        self.E_t = E0
        self.E_min = E_min
        self.E_max = E_max
        self.delta_kappa = delta_kappa
        self.dt = dt
        self.kappa = scheduler.kappa0
        self.frozen = False

    def step(self, x, xd, x_r, F_ext, kappa_cmd):
        # 1) 参数限速（快层仍拒绝大跳变）
        dk = clip(kappa_cmd - self.kappa, -self.delta_kappa, self.delta_kappa)
        kappa_next = clip(self.kappa + dk, 0.0, 1.0)

        # 2) 能量罐记帐（P13）
        power_in = sum(f * v for f, v in zip(F_ext, xd))
        M_d, D_d, K_d = self.sched.to_impedance(kappa_next)
        dissipation = D_d * sum(v * v for v in xd)
        self.E_t = clip(self.E_t + (power_in - dissipation) * self.dt,
                        0.0, self.E_max)

        # 3) 罐空 → 冻结参数并注入耗散（绝不放行增能方向）
        extra_d = 0.0
        if self.E_t <= self.E_min:
            self.frozen = True
            kappa_next = self.kappa
            M_d, D_d, K_d = self.sched.to_impedance(kappa_next)
            n2 = sum(v * v for v in xd)
            if n2 > 1e-9:
                extra_d = max(0.0, -min(0.0, power_in) / n2)
        else:
            self.frozen = False

        # 4) 导纳动力学：M ẍ + (D+extra) ẋ + K(x−x_r) = F_ext
        xdd = [(f - (D_d + extra_d) * v - K_d * (xi - xr))
               / M_d for f, v, xi, xr in zip(F_ext, xd, x, x_r)]
        self.kappa = kappa_next
        return xdd, kappa_next, self.E_t


# IP-354：风格/目标分离管道
class StyleGoalCommand:
    def __init__(self, asr, nli, estimator, tau_voice=0.85, g0=None):
        self.asr = asr
        self.nli = nli
        self.estimator = estimator
        self.tau_voice = tau_voice
        self.g0 = g0

    def parse(self, utterance):
        text, conf = self.asr.recognize(utterance.audio)
        # 目标信道：只读文本语义（SGSI）
        g = self.g0 if conf < self.tau_voice else self.nli.parse(text)
        # 风格信道：只读副语言
        s = self.estimator.infer(utterance)
        # 类型级保险：风格对象不得携带目标字段
        assert not hasattr(s, "goal") and not hasattr(s, "intent")
        return g, s


# IP-355：柔顺软证书
class SoftComplianceCert:
    def __init__(self, f_hard=F_HARD):
        self.f_hard = f_hard

    def issue(self, kappa, conf, E_t, F_norm):
        margin = self.f_hard - F_norm
        if margin < 0.0:
            trigger = "force"
        elif E_t <= 0.5:
            trigger = "passivity"
        elif conf < 0.75:
            trigger = "confidence"
        else:
            trigger = None
        return {"kappa": kappa, "conf": conf, "E_tank": E_t,
                "force_margin": margin, "passive": E_t > 0.5,
                "trigger": trigger}


# IP-356：主闭环集成（示意；v7 主体不变）
def metricvoicegauge_round_8(M, s, obs, utterance=None, ecl=None):
    # 1) 语义/风格分离
    if utterance is not None and ecl is not None and not ecl.fault:
        g, style = ecl.command.parse(utterance)
    else:
        g, style = M.default_goal, Style.nominal()

    # 2) 有界柔顺调度
    if ecl is not None and not ecl.fault:
        M_d, D_d, K_d = ecl.scheduler.to_impedance(style.kappa)
    else:
        M_d, D_d, K_d = None, None, None          # 退回 v7 刚性路径

    # 3) v7 主路径只消费 g；风格不进入奖励、不进入硬约束
    C, spatial_cert, claims, metrics, rewards = M.v7_round(g, s, obs)

    # 4) 快层导纳由独立 1 kHz 线程执行（ecl.controller.step），
    #    并在每个控制周期发布柔顺证书
    scc = ecl.cert.issue(style.kappa, style.conf,
                         ecl.controller.E_t, M.last_force_norm) if ecl else None
    return C, spatial_cert, claims, metrics, rewards, scc
```

## 4. 推导

**引理 77（情感误判的安全上界）**
在 SGSI（定义 528）成立时，任意情感后验误差 `‖p̂ − p‖₁ ≤ ε` 只能通过 `(caution, urgency)` 改变 κ，进而改变 C 内的阻抗参数；语义目标 `g` 与硬约束 `M₀` 对误差的敏感度为 0。且由 BCL 的 Lipschitz 性，
```
|Δκ| ≤ α_c·ε + α_u·ε = (α_c + α_u)·ε
```
因此最坏情况下执行参数偏移不超过 `diam(C)·min(1,(α_c+α_u)ε)`。
*证明要点*：SGSI 给出 `∂g/∂s = 0, ∂M₀/∂s = 0`；BCL 给出 κ 对情感坐标的线性有界依赖；CCP 给出 κ→参数的连续像的直径上界。∎

**引理 78（时变参数下的无源性）**
设导纳存储函数
```
V = ½ ẋᵀ M_d ẋ + ½ (x − x_r)ᵀ K_d (x − x_r) + E_t
```
若 `(M_d, D_d, K_d)(t) ∈ C` 且参数变化率满足 `|κ̇| ≤ δκ`，则在 IP-353 的能量罐规则下，对任意有界 `F_ext` 有 `V(t) ≤ V(0) + ∫ F_extᵀ ẋ dt`，即 `F_ext → ẋ` 无源；当 `E_t → E_min` 时冻结 κ，参数注入项归零，仅余 `−ẋᵀ D_d ẋ ≤ 0` 的耗散。
*证明要点*：对 V 求导，参数变化项 `(∂V/∂θ)θ̇` 由罐能量补偿；罐非负是唯一约束；冻结后 θ̇=0，退化为 LTI 导纳，由 `D_d ≥ 2ζ_min√(M_dK_d)` 保证正阻尼。∎

**引理 79（连续退化与 κ₀ 回退）**
置信门控关闭时，κ 以每步 ≤ `δκ` 的速率回到 κ₀，故 `κ(t) → κ₀` 且过程中始终在 C 内；当情感模块整体故障时直接置 κ=κ₀，与“固定名义柔顺”的 v7 在参数层等价。
*证明要点*：回退是限速的一阶过程，单调收敛；κ₀∈[0,1] 且 `Interp_C` 连续，故轨迹不越出 C。∎

**引理 80（双尺度 WCET 可组合性）**
慢层情感推断以 10 Hz 运行、单次预算 ≤ 20 ms；快层导纳 1 kHz、单步 ≤ 0.3 ms；两者与 v7 的 50 Hz 主路径通过有界队列解耦。若慢层超时则丢弃本次更新（保持 κ），故 50 Hz 主路径的 WCET 不受慢层抖动影响，控制周期 20 ms 内主路径 ≤ 17 ms、风格分支 ≤ 3 ms。
*证明要点*：慢层只写“最新 κ 目标”这一单槽寄存器，快层读取是 O(1) 且无锁；超时丢弃保证写侧不会阻塞读侧；主路径不等待慢层完成。∎

**推论 81（柔顺证书的组合单调性）**
若 `SCC.passive=true ∧ SCC.force_margin≥0`，则 v7 的 SpatialCert 不被柔顺层削弱；反之任一为 false 时，δ_ECL 触发对应退化，使系统回到 v7 的已验证安全包络。

## 9. 本轮最大风险

**一句话**：情感语音的后验在跨说话人/噪声下可能系统性偏移，而“迟滞 + 限速 + 有界多面体”只能限制其后果、不能消除误判本身——若校准集与真实操作员分布错配，系统可能长期停在“过度温柔”或“过度强硬”的一个安全但低效的角落，且用户难以察觉这种隐性风格漂移。
