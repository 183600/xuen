# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；新灵感循环第 1 轮；本轮灵感：「MuJoCo」×「柔顺控制」）

> 第 54 轮把技能组合从“能力匹配”推进到动作空间剖面 `α_S`、组合图 `G_S`、云边映射 `γ_ce` 与联合证书 `J`。本轮继续向物理层下沉：MuJoCo 代表“接触动力学可计算”，柔顺控制代表“稳定性可证明”。核心矛盾：**H22**：位置动作空间把接触模式的不连续性与力约束抹平，`α_S` 在接触边界处会给出虚假覆盖；**H23**：柔顺技能可局部稳定而组合后失稳，鲁棒性谱 `ρ` 缺少“无源裕度”这一可传递维度，云边力闭环又引入未建模时延。

## 0. 直觉与动机

**总直觉**：上一轮的技能 `S` 是一个“能覆盖哪些位置动作”的集合；本轮把它改成“在哪些接触模式下、以多大阻抗、还能保持无源”的三元对象。MuJoCo 提供接触模式与接触力的可计算近似，柔顺控制提供把力/能量纳入证书的语言。先给直觉，再给严谨定义。

**灵感 1（MuJoCo 的接触软约束 → 动作空间不是平面，而是分层流形）**
直觉：在 MuJoCo 中，同一个位置指令在 `free / stick / slide / impact` 四种接触模式下力学后果完全不同。只在位置坐标上算 Jaccard，会把“末端能到位置”误判为“任务能完成”。严谨落点：把动作空间写成接触分层空间 `A = ⊔_{c∈C} A_c`，技能剖面变为 `α_S(a,c)`，覆盖检查必须按模式分层，并对接触边界 `B` 单独计测度。

**灵感 2（柔顺控制 → 阻抗是动作的第二坐标，无源性是可传递的鲁棒性维度）**
直觉：柔顺不是“把增益调小”，而是给每个动作配一个阻抗包络 `(K,D,M,f_max)`；只保证位置轨迹安全的证书，在插孔、擦拭、开门这类接触任务里没有意义。更进一步，阻抗控制可用能量罐给出稳定性证书：只要能量罐不耗尽，闭环就保持无源。严谨落点：定义柔顺剖面 `κ_S(a,c)` 与无源裕度 `ε_pass`，并把 `ε_pass` 作为 `ρ` 之外的新可传递维度。

**灵感 3（MuJoCo + 柔顺 → 接触可信半径与 sim-to-real 证书）**
直觉：MuJoCo 的摩擦系数、`solref/solimp`、执行器延迟都是拟合参数；在接触任务中，仿真里 1 mm / 1 N 的误差就足以改变接触模式。因此证书必须携带“接触可信半径 `r_c`”，而不是宣称“仿真等于现实”。严谨落点：用贝叶斯系统辨识得到接触参数后验，把后验传播为接触力误差上界与模式误判概率；仅当任务力容差 `δ_f^* ≥ r_c` 时才允许认证。

**灵感 4（云边协同的柔顺版本 → 云端排阻抗，边端守无源）**
直觉：云端不应只发位置轨迹，而应发阻抗时序（stiffness schedule）；边端不应只跟踪位置，而应实时监控能量罐与接触模式。发生打滑、力饱和或意外碰撞时，`Explain` 的根因从“动作越界”变为“接触模式切换/能量异常注入”。严谨落点：云边契约从 `γ_ce: A_c→A_e` 扩展为 `γ_ce^κ: (A_c,K_c,D_c)→(A_e,K_e,D_e)`，并加入力反馈回传与阻抗重规划。

**灵感 5（金字塔再加一层 → 接触-柔顺层 ℂ）**
直觉：第 54 轮的 `𝔸` 层解决了“动作占用”，但没有回答“这个占用在接触物理下是否稳定”。本轮在 `𝔸` 之上叠加 `ℂ` 层：`ℂ_0` 接触/执行器物理，`ℂ_1` 阻抗剖面，`ℂ_2` 接触模式组合，`ℂ_3` 云边力闭环。跨层传递证书需同时包含动作、鲁棒性、柔顺与无源裕度，形成 **三证书体系**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（分层接触动作空间）**
接触模式集合 `C = {free, stick, slide, impact}`，动作空间分解为 `A = ⊔_{c∈C} A_c`，`A_c` 为模式 `c` 下物理可行的动作集合；接触边界 `B = ∪_{c≠c'}(cl A_c ∩ cl A_{c'})`。技能 `S` 的接触条件动作剖面 `α_S : A×C → [0,1]`，`α_S(a,c)` 表示在模式 `c` 下执行 `a` 且摩擦锥、法向力上下界、穿透约束均满足的置信度。**接触覆盖**定义为：
```
cover(S,A_T)=1 ⇔ ∃ 可测选择 c(·): A_T→C,
  ∀a∈A_T: α_S(a,c(a)) ≥ θ_cov  ∧  ν(B∩A_T) ≤ θ_b
```
其中 `ν` 为接触边界附近的不确定性/采样厚度。这把“位置可达”升级为“模式一致可达”。

**定义 122（柔顺/阻抗剖面）**
技能 `S` 的柔顺剖面 `κ_S : A×C → 2^{𝒫}`，其中
```
𝒫 = {(K,D,M,f_max) | 0 ≺ K_min ⪯ K ⪯ K_max,
     0 ≺ D_min ⪯ D ⪯ D_max, 0 < M ≤ M_max,
     ||f|| ≤ f_max ≤ f_act}
```
`K,D,M` 分别为笛卡尔刚度、阻尼、惯量矩阵，`f_act` 为执行器力上限。`κ_S(a,c)` 为技能在 `(a,c)` 下可安全维持的阻抗集合。给定任务柔顺需求 `κ_T(a,c)`，**柔顺覆盖**为 `κ_T(a,c) ⊆ κ_S(a,c)`。位置剖面回答“到得了吗”，柔顺剖面回答“以多硬/多软、能出多大力”。

**定义 123（接触模式证书）**
接触模式证书 `C_contact = (c, n, μ_margin, λ_n, π_mj, δ_c, evidence)`：
- `n` 为接触法向，`λ_n` 为法向力；
- 摩擦锥裕度 `μ_margin = 1 - ||f_t||/(μ_s λ_n) ≥ μ_min`；
- `π_mj` 为 MuJoCo 约束残差/穿透量，要求 `π_mj ≤ π_max`；
- `δ_c` 为在接触参数后验内模式 `c` 保持不变的参数半径；
- `evidence` 至少包含接触点、求解器迭代数与参数后验样本。
若 `μ_margin < 0` 或 `π_mj > π_max`，证书失效。

**定义 124（无源裕度证书）**
对阻抗控制技能 `S`，设能量罐储能为 `E_t(t)`，闭环满足 `Ė_t = P_in - E_diss`。定义无源裕度
```
ε_pass(S) = inf_{t∈[0,T]} inf_{d∈𝒟} (E_t(t) - E_min - E_req(d,t))
```
`ε_pass(S) > 0` 表示在所有允许扰动 `𝒟` 下能量罐不耗尽，控制器保持无源。两个技能通过力端口耦合时，组合裕度满足
```
ε_pass(S_i⊗S_j) ≥ ε_pass(S_i) + ε_pass(S_j) - E_couple(i,j)
```
其中 `E_couple(i,j)` 为耦合端口交换能量上界。

**定义 125（柔顺技能组合图）**
柔顺组合图 `G_S^κ = (V,E^κ)`，边 `(i,j)` 存在当且仅当：
```
compat_A(S_i,S_j) ≥ θ_a
∧ P(c_j | c_i, a) ≥ 1-δ_c
∧ c_imp(K_i,K_j) = ||log(K_i K_j^{-1})||_F + λ_D||D_i-D_j||_F ≤ τ_imp
∧ ||f_i^max - f_j^max|| ≤ θ_f
∧ ε_pass(S_i) + ε_pass(S_j) - E_couple(i,j) ≥ ε_min
```
边证书 `C_comp^κ = (A_overlap, c_trans, c_imp, ρ_comp, ε_comp, γ_ce^κ)`。

**定义 126（接触-柔顺联合证书）**
联合证书 `J^κ = (ρ, α_S, κ_S, C_contact, ε_pass, r_c, γ_ce^κ, δ_a, evidence)`，其中 `r_c` 为接触可信半径（接触力误差上界），`δ_f^*` 为任务允许力误差。部署条件：
```
cover(S,A_T)=1 ∧ κ_T⊆κ_S ∧ ε_pass≥ε_min
∧ r_c≤δ_f^* ∧ Σ_e c_imp(e)≤τ_imp^budget
∧ δ_a≤Θ_a ∧ P(mode misclass)≤β_c
```
满足则记 `dom_{J^κ}(T)=in`；否则拒绝部署或降级为位置控制并显式标注“无接触保证”。

## 2. 关键算法 伪代码

### IP-121 KPC（Contact-Stratified Compliance Profile）

```python
def contact_profile(skill, A, C, K_grid, mj_model):
    alpha, kappa, certs = {}, {}, {}
    for c in C:
        for a in stratified_sample(A, c, boundary=True):
            res = mj_impedance_probe(skill, a, c, K_grid, mj_model)
            alpha[(a, c)] = res.feasibility
            if res.feasible:
                kappa[(a, c)] = res.pareto_admissible
            certs[(a, c)] = ContactCert(c, res.mu_margin,
                                        res.penetration, res.delta_c)
    return ContactProfile(alpha, kappa, certs)
```

`stratified_sample` 用接触雅可比与边界不确定性主动加密采样；`mj_impedance_probe` 在 MuJoCo 中注入阻抗控制并读取接触力、穿透与约束残差。

### IP-122 MCC（MuJoCo Contact Calibration）

```python
def calibrate_contact(model, real_rollouts, prior, budget, delta):
    post = prior
    while budget > 0:
        r = select_probe(real_rollouts, post, criterion='contact_boundary_info')
        sim = rollout(model, r.ctrl, post.map)
        post = bayes_update(post, r.observed, sim)
        budget -= 1
    r_c = quantile_force_error(post, 1 - delta)
    beta_c = expected_mode_misclassification(post)
    return ContactCalibration(post, r_c, beta_c)
```

### IP-123 PEC（Passivity Energy Certificate）

```python
def passivity_certify(skill, profile, disturbances, dt, E_min):
    eps = float('inf')
    for d in disturbances:
        tank = EnergyTank(E0=skill.E0)
        for state in simulate_impedance(skill, d, dt):
            tank.integrate(power_in=state.f.T @ state.v,
                           dissipated=state.dissipation)
            if tank.E < E_min:
                return ('reject', 'energy_exhausted', state, tank.E)
            eps = min(eps, tank.E - E_min)
    return ('ok', eps)
```

### IP-124 WSC（Wrench-aware Skill Composition）

```python
def build_compliance_graph(skills, profiles, theta_a, tau_imp, eps_min):
    G = nx.DiGraph()
    for i, s1 in enumerate(skills):
        for j, s2 in enumerate(skills):
            if i == j:
                continue
            if compat(profiles[i].alpha, profiles[j].alpha) < theta_a:
                continue
            if transition_prob(s1.contact, s2.contact) < 1 - delta_c:
                continue
            c_imp = impedance_gap(s1.kappa, s2.kappa)
            eps = compose_passivity(s1.eps, s2.eps,
                                    coupling_bound(s1, s2))
            if c_imp <= tau_imp and eps >= eps_min:
                G.add_edge(i, j,
                           C_comp_kappa=(s1.alpha & s2.alpha,
                                         transition(s1, s2),
                                         c_imp, eps))
    return G
```

### IP-125 CIC（Cloud-Edge Impedance Coordination）

```python
def cloud_compliance_plan(task, G, kappa_T):
    cost = lambda e: (w_a * (1 - e.compat)
                      + w_imp * e.c_imp
                      + w_eps * (1 - e.eps))
    path = a_star(G, start='root', goal=task, heuristic=cost)
    return [(n, A_c[n], K[n](t), D[n](t), c_expected[n])
            for n in path]

def edge_compliance_execute(P_c, gamma_ce_kappa, monitor, passivity_obs):
    for sid, a_c, K_c, D_c, c_exp in P_c:
        a_e, K_e, D_e = gamma_ce_kappa(a_c, K_c, D_c)
        if not impedance_cover(skill_lib[sid].kappa, a_e, K_e, D_e):
            return ('replan', explain_contact(skill_lib[sid], a_e))
        set_impedance(K_e, D_e)
        obs = passivity_obs.step()
        cm = monitor.contact_mode()
        if obs.margin < eps_min or cm.mode != c_exp:
            return ('replan', explain_contact(skill_lib[sid], a_e, cm, obs))
    return ('ok',)
```

### IP-126 CCC（Contact-Compliance Certificate）

```python
def contact_compliance_certificate(seq, calib, budgets):
    A_core = intersect([s.alpha for s in seq])
    eps = compose_passivity_chain([s.eps for s in seq],
                                  coupling_bounds(seq))
    contact = merge_contact_certs([s.contact for s in seq])
    if calib.r_c > budgets.delta_f:
        return ('reject', 'contact_fidelity', calib.r_c)
    if eps < budgets.eps_min:
        return ('reject', 'passivity', eps)
    if sum(e.c_imp for e in seq) > budgets.tau_imp:
        return ('reject', 'impedance_budget')
    return ('ok', J_kappa(seq, A_core, contact, eps, calib.r_c))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| KPC | `O(|C|·|A|·|K_grid|·T_mj)` | `O(|A|·|C|·|K_grid|)` | 接触分层完备、边界采样覆盖 |
| MCC | `O(N_probe·T_mj + |θ|^3)` | `O(|θ|^2)` | 后验校准、力误差分位数 sound |
| PEC | `O(|𝒟|·T/Δτ)` | `O(|𝒟|)` | 能量罐初值与扰动集闭合 |
| WSC | `O(|S|^2·|A|·|C| + |E|·T_pass)` | `O(|S|^2+|E|)` | 模式转移概率、无源预算可加 |
| CIC | `O(|V| log|V| + |E| + |P|·T_loop/Δτ)` | `O(|V|+|E|)` | 调度 C¹ 连续、力闭环时延有界 |
| CCC | `O(|S|·|A| + |C|·|S|)` | `O(|A|+|C|)` | 联合证书 sound、预算闭合 |

**正确性定理（Contact-Compliance Composition Soundness）**
假设第 54 轮 `(A22)–(A28)` 成立；新增：
- **(A29)** 接触分层有限且校准：`sup|α_S-α_real| ≤ δ_α`，`P(mode misclass) ≤ β_c`；
- **(A30)** MuJoCo 接触参数后验给出 `P(||f_sim-f_real|| ≤ r_c) ≥ 1-δ_f`；
- **(A31)** 每个技能在给定能量罐初值下无源，`ε_pass` 按定义 124 计算且耦合能量有界；
- **(A32)** 云边力闭环时延 `≤ τ_loop`，阻抗调度 `C¹` 且 Lipschitz；
- **(A33)** 任务力容差 `δ_f^* ≥ r_c`。

则部署成功概率满足：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a) - P(compat<θ_a)
            - β_c - P(ε_pass<ε_min) - P(r_c>δ_f^*) - β_loop
```
该界是并集界，最脆弱项是 `β_c` 与 `P(r_c>δ_f^*)`：认证必须显式携带接触参数后验，而不能把 MuJoCo 当成真值。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 接触参数不可辨识 | 高 | 主动探测 + 后验采样 + 保守 `r_c` + 多种接触模型交叉验证 |
| 无源证书过保守导致任务失败 | 高 | 任务感知 `ε_min` + 能量罐整形 + 分级降级策略 |
| 阻抗切换不连续/抖振 | 中 | `C¹` 插值 + 无源保持混合 + 切换死区 |
| MuJoCo 软接触参数非物理 | 高 | 力台/真机标定 + 参数后验 + 残差监控 |
| 云边力闭环时延 | 高 | 边端本地无源回退 + watchdog + 阻抗冻结 |
| 接触模式组合爆炸 | 中 | 分层剪枝 + 模式哈希 + 只展开任务相关模式 |
| 证书与真实不一致 | 高 | 运行时接触监控 + 证书衰减 + 失败即降级 |

## 6. 本轮最大风险

**一句话**：把 MuJoCo 接触后验、柔顺阻抗包络与无源裕度纳入证书，能把“位置安全”升级为“接触稳定”，但整套 soundness 最终押在 **接触参数后验的覆盖性** 与 **能量罐扰动集的可枚举性** 上；一旦真实接触出现未建模的塑性变形、摩擦滞回或延迟突变，证书会从“保守”瞬间变成“虚假保证”，因此必须以 **在线接触残差监控 + 证书实时衰减 + 无源回退** 作为最后一道绊线，宁可降级为位置控制，也不把接触可信半径之外的稳定性当作可部署结论。

```python
def contact_profile(skill, A, C, K_grid, mj_model):
    alpha, kappa, certs = {}, {}, {}
    for c in C:
        for a in stratified_sample(A, c, boundary=True):
            res = mj_impedance_probe(skill, a, c, K_grid, mj_model)
            alpha[(a, c)] = res.feasibility
            if res.feasible:
                kappa[(a, c)] = res.pareto_admissible
            certs[(a, c)] = ContactCert(c, res.mu_margin,
                                        res.penetration, res.delta_c)
    return ContactProfile(alpha, kappa, certs)
```

### IP-122 MCC

```python
def calibrate_contact(model, real_rollouts, prior, budget, delta):
    post = prior
    while budget > 0:
        r = select_probe(real_rollouts, post, criterion='contact_boundary_info')
        sim = rollout(model, r.ctrl, post.map)
        post = bayes_update(post, r.observed, sim)
        budget -= 1
    r_c = quantile_force_error(post, 1 - delta)
    beta_c = expected_mode_misclassification(post)
    return ContactCalibration(post, r_c, beta_c)
```

### IP-123 PEC

```python
def passivity_certify(skill, profile, disturbances, dt, E_min):
    eps = float('inf')
    for d in disturbances:
        tank = EnergyTank(E0=skill.E0)
        for state in simulate_impedance(skill, d, dt):
            tank.integrate(power_in=state.f.T @ state.v,
                           dissipated=state.dissipation)
            if tank.E < E_min:
                return ('reject', 'energy_exhausted', state, tank.E)
            eps = min(eps, tank.E - E_min)
    return ('ok', eps)
```

### IP-124 WSC

```python
def build_compliance_graph(skills, profiles, theta_a, tau_imp, eps_min):
    G = nx.DiGraph()
    for i, s1 in enumerate(skills):
        for j, s2 in enumerate(skills):
            if i == j:
                continue
            if compat(profiles[i].alpha, profiles[j].alpha) < theta_a:
                continue
            if transition_prob(s1.contact, s2.contact) < 1 - delta_c:
                continue
            c_imp = impedance_gap(s1.kappa, s2.kappa)
            eps = compose_passivity(s1.eps, s2.eps,
                                    coupling_bound(s1, s2))
            if c_imp <= tau_imp and eps >= eps_min:
                G.add_edge(i, j,
                           C_comp_kappa=(s1.alpha & s2.alpha,
                                         transition(s1, s2),
                                         c_imp, eps))
    return G
```

### IP-126 CCC

```python
def contact_compliance_certificate(seq, calib, budgets):
    A_core = intersect([s.alpha for s in seq])
    eps = compose_passivity_chain([s.eps for s in seq],
                                  coupling_bounds(seq))
    contact = merge_contact_certs([s.contact for s in seq])
    if calib.r_c > budgets.delta_f:
        return ('reject', 'contact_fidelity', calib.r_c)
    if eps < budgets.eps_min:
        return ('reject', 'passivity', eps)
    if sum(e.c_imp for e in seq) > budgets.tau_imp:
        return ('reject', 'impedance_budget')
    return ('ok', J_kappa(seq, A_core, contact, eps, calib.r_c))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| KPC | `O(|C|·|A|·|K_grid|·T_mj)` | `O(|A|·|C|·|K_grid|)` | 接触分层完备，边界采样覆盖 ≥ 95% |
| MCC | `O(N_probe·T_mj + |θ|^3)` | `O(|θ|^2)` | 后验覆盖，`r_c` 分位数 sound |
| PEC | `O(|𝒟|·T/Δτ)` | `O(|𝒟|)` | 能量罐不耗尽，扰动集闭合 |
| WSC | `O(|S|^2·|A|·|C| + |E|·T_pass)` | `O(|S|^2+|E|)` | 模式转移概率 sound，无源预算可加 |
| CIC | `O(|V| log|V| + |E| + |P|·T_loop/Δτ)` | `O(|V|+|E|)` | 阻抗调度 C¹，力闭环收敛 |
| CCC | `O(|S|·|A| + |C|·|S|)` | `O(|A|+|C|)` | 联合证书 sound，预算闭合 |

**正确性定理（Contact-Compliance Composition Soundness）**
假设第 54 轮 `(A22)-(A28)` 成立；新增 `(A29)` 接触分层有限且 `sup|α_S-α_real|≤δ_α`、`P(mode misclass)≤β_c`；`(A30)` 接触参数后验给出 `P(||f_sim-f_real||≤r_c)≥1-δ_f`；`(A31)` 每个技能无源且 `ε_pass` 按定义 124 计算；`(A32)` 云边力闭环时延 `≤τ_loop` 且阻抗调度 Lipschitz；`(A33)` `δ_f^*≥r_c`。则：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a) - P(compat<θ_a)
            - β_c - P(ε_pass<ε_min) - P(r_c>δ_f^*) - β_loop
```
关键：**先按接触模式认证，再按力容差认证，最后按无源裕度认证**；任一项越界即降级。

## 6. 本轮最大风险

**一句话**：接触-柔顺三证书把技能组合推进到力与能量层面，但其 soundness 押在 **MuJoCo 接触参数后验的覆盖性** 与 **能量罐扰动集的可枚举性** 上；一旦真实接触出现未建模的塑性变形、摩擦滞回或时延突变，`r_c` 与 `ε_pass` 会从保守估计退化为虚假保证，故必须以 **在线接触残差监控 + 证书实时衰减 + 无源回退** 作为最终护栏，宁可降级为位置控制，也不把接触可信半径之外的稳定性当作可部署结论。
