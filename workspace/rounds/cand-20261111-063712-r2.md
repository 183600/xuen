# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 2 轮；本轮灵感：「力矩控制」×「快速原型」）

> 第 54 轮把技能组合推进到「动作空间剖面 α_S + 鲁棒性谱 ρ + 云边联合证书 J」，但仍暗含两个"上层建筑式"假设：(i) 动作可行性 α_S 由几何/仿真给定，仿佛动作只受运动学约束；(ii) 证书是慢工出细活的产物，而研究循环本身却在追求快速迭代。本轮用「力矩控制」追问动作空间的**物理地基**，用「快速原型」追问证据生产的**迭代节拍**。核心矛盾：**H24**：任何高层动作最终都要编译成关节力矩，饱和、摩擦、热降额与接触无源性会让"运动学上可行"的动作在真实边端**力矩不可实现**，从而产生只在高负载/接触段暴露的虚假兼容；**H25**：快速原型能以极低成本快速给出证据，但其保真度低、系统性偏差高、且会随时间失效，把原型证据当成完整验证会制造"证据剧场"；而拒绝原型、坚持全量验证又会让认证延迟超过迭代周期，使证书永远追不上原型。

## 0. 直觉与动机

**灵感 1（力矩控制 → 动作空间有物理地板）**
直觉：第 54 轮的 `α_S(a)` 像是在问"这个动作在几何上做不做得到"，但机器人真正执行的是 `τ(t)`。同一段末端轨迹，空载时可执行，加上负载或接触后某个关节就可能撞上饱和面；电机还会因连续大扭矩热降额。也就是说，`α_S` 只是**运动学上界**，真实可执行域是它被**力矩可实现包络**切掉一块后的子集。把每个动作的"到饱和还剩多少余量"记为力矩剖面 `β_S(a,c)`，则有效动作剖面应为 `α̃_S(a)=α_S(a)·1[β_S(a,c)≥m_min]`。动作空间从此有了物理地板，组合的第一性约束不再只是"交集非空"，而是"交集内处处有力矩余量"。

**灵感 2（阻抗/无源性 → 力矩够大不等于接触稳定）**
直觉：接触丰富技能（插拔、旋拧、擦洗）不是"力矩越大越好"。纯力矩控制下，若阻抗参数与环境刚度失配，即使每个关节都在饱和面内，也可能出现接触振荡、能量注入乃至失稳。因此除力矩幅值外，还需一个**无源性能量罐裕度 `π_S`** 与**接触力旋量裕度**，把"力够不够"和"接触稳不稳"拆成两个独立判据。一个动作只有在 `(m_S, π_S, w_S)` 三者同时过关时，才算力矩-接触双重可实现。

**灵感 3（快速原型 → 原型是"证据预言机"，不是"缩小版部署"）**
直觉：快速原型的价值不在于它像真机，而在于它**便宜、快、可并行**。应把它定义为带保真度 `f_p`、成本 `c_p`、转移间隙 `g_p` 的**证据预言机**：一次原型实验只产出一个带不确定度的证据项 `(ŷ, ε, f, coverage, t)`，其中 `ε` 必须显式包含测量误差、原型到部署的转移间隙、以及共同模式偏差 `b_p`。原型越便宜，`f_p` 越低、`g_p` 越大、证据越"短命"。这样"快速原型"从口号变成可记账的**证据成本-保真度-新鲜度**三维预算。

**灵感 4（证据组合 → 廉价原型 + 少量高保真锚点）**
直觉：如果只信廉价原型，共同模式偏差会让所有原型一起错；如果只信昂贵真机，认证延迟爆表。正解是**证据组合账本**：大量廉价原型负责快速扫边界，少量高保真锚点负责给整个组合一个独立下界。对能力量 `y`，每条证据给出区间 `[ŷ−ε, ŷ+ε]`，取 `y_lb = max_i(ŷ_i−ε_i) − b_common`；若各区间交集为空，说明原型之间互相矛盾，必须升级到锚点裁决。这把"要不要再验一次"变成可判定的组合与冲突检测。

**灵感 5（边界感知的原型调度 → 把预算花在判据边界上）**
直觉：原型预算有限，均匀采样最浪费。真正决定组合可行性的是**判据边界带** `∂_εA = {a : |β_S(a)−m_min| ≤ ε}`：远离边界的动作，验不验都不改变结论；边界附近，一次实验就能翻转接受/拒绝。因此用信息价值 `VOI(p)` 在边界带上调度原型，并强制至少保留一个与廉价原型**统计独立**的高保真锚点。这把"快速原型"从盲目堆样本次数，升级为**认证实验设计**。

**灵感 6（金字塔再加两层 → 力矩层 𝕋 与证据层 ℙ）**
直觉：在第 54 轮动作协同层 `𝔸` 之下插入 **力矩层 `𝕋`**（`𝕋_0` 执行器极限，`𝕋_1` 关节力矩可实现，`𝕋_2` 接触/无源性，`𝕋_3` 任务级力交互），在 `𝔸` 之上叠加 **证据层 `ℙ`**（`ℙ_0` 单原型证据，`ℙ_1` 转移间隙标定，`ℙ_2` 证据组合账本，`ℙ_3` 租约化部署证书）。跨层证书必须同时携带 `ρ, A_cert, τ_cert, E_cert`，任何一层的预算越界都触发否决或降级为临时证书。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（力矩可实现集与力矩剖面）**
关节空间 `(q,q̇)`，上下文 `c`（负载/温度/接触）。力矩可实现集
`T_adm(q,q̇,c) = { τ : |τ_j| ≤ τ_j^max(q̇_j,c) ∧ (q,q̇,τ) 满足加速度/热/摩擦约束 }`。
技能 `S` 在动作 `a` 下沿标称轨迹 `χ_S(a)` 的力矩需求为
`τ_req = ID(q,q̇,q̈,w_ext)`。**力矩可实现裕度**
`m_S(a,c) = min_{t∈χ_S(a)} min_j [τ_j^max(q̇_j,c) − |τ_req,j(t)|] / τ_j^max(q̇_j,c)`。
**力矩剖面** `β_S(a,c) = m_S(a,c)`，**有效动作剖面** `α̃_S(a) = α_S(a) · 1[β_S(a,c) ≥ m_min, ∀c∈C_active]`。

**定义 122（接触-阻抗可实现性与无源性裕度）**
技能 `S` 的阻抗策略 `Z_S=(K_d,D_d)`，采样数据下能量罐 `E_tank(t)`。**无源性裕度**
`π_S(a,c) = min_t E_tank(t)`，**接触旋量裕度** `w_S(a,c) = 1 − max_t ||w(t)|| / ||w_max(μ)||`，其中 `w_max(μ)` 为摩擦锥允许的最大接触旋量。力矩-接触可实现判据：
`β_S(a,c) ≥ m_min ∧ π_S(a,c) ≥ π_min ∧ w_S(a,c) ≥ w_min`。
关键：`m_S ≥ 0` 只说明力矩不饱和，**不蕴含** `π_S ≥ 0`；接触稳定性是独立约束。

**定义 123（快速原型证据项）**
原型 `p=(rig_p, sensor_p, domain_p, f_p, c_p)`，其中 `f_p∈[0,1]` 为保真度、`c_p` 为单次成本。一次实验 `(S,a,metric)` 产出估计 `ŷ_p`、测量不确定度 `u_p`、转移间隙 `g_p` 与共同模式偏差预算 `b_p`，满足
`P(|y_real − ŷ_p| ≤ u_p + g_p + b_p) ≥ 1−δ_p`。
**证据项** `e_p = (metric, ŷ_p, ε_p = u_p+g_p+b_p, f_p, coverage_p, t_p, δ_p)`。

**定义 124（证据组合下界与冲突检测）**
证据组合账本 `E={e_p}`。对指标量 `y`，逐项区间 `[lo_p, hi_p]=[ŷ_p−ε_p, ŷ_p+ε_p]`，则
`y_lb(E) = max_p(lo_p) − b_common`，`y_ub(E) = min_p(hi_p)`；
**证据冲突**当且仅当 `max_p(lo_p) > min_p(hi_p)`。冲突时必须引入保真度 `f_p ≥ f_anchor` 的**独立锚点**裁决，禁止用加权平均抹平矛盾。只有在无冲突且 `y_lb(E) ≥ m_min` 时，力矩能力才可被证书引用。

**定义 125（证书租约、认证延迟与迭代节拍）**
原型证据新鲜度按 `A_E(t)=A_E(t_0)·exp(−λ_p(t−t_0))` 衰减。**租约** `L=(A_min, t_exp, coverage_req)`；证书有效需 `A_E(t) ≥ A_min ∧ t ≤ t_exp ∧ coverage ≥ coverage_req`。**认证延迟** `L_cert` 指从提出认证到签发的时间，迭代周期 `T_iter`，**认证滞后比** `γ_cert = L_cert/T_iter`。`γ_cert > 1` 时只允许签发**临时证书 `J_τ^prov`**，临时证书不得授权接触丰富/高负载部署。

**定义 126（原型预算与边界信息价值）**
原型总预算 `B_p`。判据边界带 `∂_εA = {a : |β_S(a,c)−m_min| ≤ ε}`。原型 `p` 的信息价值
`VOI(p) = E[ℓ(决策|b_t)] − E[ℓ(决策|b_t, e_p)]`，
调度目标为 `max Σ_p VOI(p)/c_p`，约束 `Σ c_p ≤ B_p`、边界带覆盖率 ≥ `η_cov`、且至少一个锚点 `f_p ≥ f_anchor` 与廉价原型统计独立。

**定义 127（力矩感知组合兼容性）**
`compat_τ(S_i,S_j) = compat(S_i,S_j) · 1[m_{S_i},m_{S_j} ≥ m_min] · 1[Δτ_handoff ≤ τ_slew] · 1[π_handoff ≥ π_min]`。
力矩感知转换成本 `c_trans^τ = c_trans + w_τ·Δτ_handoff + w_π·max(0, π_min−π_handoff)`，组合图 `G_S^τ=(V,E^τ)` 的边必须同时满足 `compat_τ ≥ θ_a` 与 `c_trans^τ ≤ τ_e`。

**定义 128（力矩-证据联合证书）**
`J_τ = (ρ, A_cert, τ_cert, E_cert, γ_ce, δ_a, L)`，其中
- `τ_cert = (m_core, T_adm_core, π_core, τ_slew)`：核心动作子集上的力矩-接触证书；
- `E_cert = (E, y_lb, A_E, conflict)`：证据组合及其保守下界；
- `L`：租约。若 `dom(T)=in`、`δ_a<Θ_a`、`m_core≥m_min`、`π_core≥π_min`、`y_lb≥m_min`、`conflict=false` 且租约有效，则 `J_τ` 可部署；否则只可签发临时证书或拒绝。

## 2. 关键算法 伪代码

### IP-121 TSC（Torque Space Characterization）

```python
def torque_profile(skill, actions, contexts, dyn_model, m_min):
    beta = {}
    for a in actions:
        for c in contexts:
            traj = skill.plan(a, c)
            tau_req = inverse_dynamics(dyn_model, traj, contact=True)
            tau_max = actuator_limit(traj.q, traj.qdot, c)   # 含热降额
            m = min((tau_max[j] - abs(tau_req[j])) / tau_max[j]
                    for j in range(len(tau_max)))
            beta[(a, c)] = m
    return beta

def effective_action_profile(alpha, beta, m_min):
    return {a: alpha[a] * float(all(beta[(a, c)] >= m_min for c in contexts))
            for a in alpha}
```

### IP-122 TAC（Torque-Aware Composition）

```python
def torque_aware_compose(skill_seq, beta, pi, w, m_min, pi_min, w_min, tau_slew):
    for s in skill_seq:
        if min(beta[s].values()) < m_min:   return ('reject', 'torque_saturation', s)
        if min(pi[s].values())   < pi_min:  return ('reject', 'passivity', s)
        if min(w[s].values())    < w_min:   return ('reject', 'contact_wrench', s)
    for s1, s2 in zip(skill_seq, skill_seq[1:]):
        if handoff_torque_jump(s1, s2) > tau_slew:
            return ('reject', 'torque_discontinuity', (s1, s2))
        if handoff_passivity(pi[s1], pi[s2]) < pi_min:
            return ('reject', 'handoff_instability', (s1, s2))
    return ('ok', skill_seq)
```

### IP-123 RPE（Rapid Prototype Evidence）

```python
def mint_evidence(prototype, skill, a, metric, delta):
    y_hat, u = prototype.measure(skill, a, metric)
    g = transfer_gap(prototype, skill, a, delta)   # 原型→部署间隙
    b = prototype.common_mode_bias(metric)
    eps = u + g + b
    return Evidence(metric=metric, y_hat=y_hat, eps=eps,
                    fidelity=prototype.fidelity, coverage=prototype.coverage,
                    timestamp=now(), delta=delta)
```

### IP-124 EPL（Evidence Portfolio Ledger）

```python
def evidence_lower_bound(ledger, metric, b_common):
    items = [e for e in ledger if e.metric == metric and not e.expired()]
    if not items:
        return (-math.inf, False)
    lo = max(e.y_hat - e.eps for e in items)
    hi = min(e.y_hat + e.eps for e in items)
    conflict = (max(e.y_hat - e.eps for e in items) > hi)
    return (lo - b_common, conflict)

def admissible_evidence(ledger, metric, m_min, b_common, a_min):
    y_lb, conflict = evidence_lower_bound(ledger, metric, b_common)
    fresh = all(e.assurance(now()) >= a_min for e in ledger if e.metric == metric)
    return (not conflict) and fresh and (y_lb >= m_min)
```

### IP-125 PBO（Prototype Budget Optimization）

```python
def schedule_prototypes(candidates, budget, boundary, anchor_fidelity):
    chosen, remaining = [], budget
    while remaining > 0:
        scored = [(p, boundary_voi(p) / p.cost) for p in candidates
                  if p not in chosen and p.cost <= remaining]
        if not scored: break
        p, score = max(scored, key=lambda x: x[1])
        if score <= 0: break
        chosen.append(p); remaining -= p.cost
        update_belief(p)
    if not any(p.fidelity >= anchor_fidelity and p.independent for p in chosen):
        chosen.append(cheapest_independent_anchor(candidates))
    return chosen, budget - remaining
```

### IP-126 TJC（Torque-Evidence Joint Certificate）

```python
def issue_torque_certificate(skill_seq, beta, pi, w, ledger, lease, budgets):
    ok, why = torque_aware_compose(skill_seq, beta, pi, w, budgets.m_min,
                                   budgets.pi_min, budgets.w_min, budgets.tau_slew)
    if not ok:
        return ('reject', why)
    m_core = min(min(beta[s].values()) for s in skill_seq)
    y_lb, conflict = evidence_lower_bound(ledger, 'torque_margin', budgets.b_common)
    if conflict or y_lb < budgets.m_min:
        return ('reject', 'insufficient_torque_evidence', (y_lb, conflict))
    if certification_lag(ledger) > budgets.T_iter:
        return ('provisional', JointCertTau(m_core, pi, w, y_lb,
                                            lease=short_lease(lease)))
    return ('ok', JointCertTau(m_core, pi, w, y_lb, lease=lease))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| TSC | O(|A|·|C|·T·n_j) | O(|A|·|C|) | 逆动力学模型误差有界、采样覆盖边界 |
| TAC | O(|S|·|A| + |S|) | O(|S|) | 力矩/无源/旋量三重判据 sound |
| RPE | O(1)/证据 | O(|E|) | 转移间隙与共同模式偏差可标定 |
| EPL | O(|E| log|E|) | O(|E|) | 区间覆盖正确、冲突不掩盖 |
| PBO | O(B_p·|P|²) | O(|P|) | VOI 估计无偏、锚点独立性 |
| TJC | O(|S|·|A|+|E| log|E|) | O(|S|+|E|) | 租约新鲜度、临时证书降级 |

**正确性定理（Torque-Evidence Grounded Composition Soundness）**
假设第 53–54 轮 (A22)–(A28) 成立；**(A29)** 力矩模型误差有界：`||τ_req−τ_true||∞ ≤ e_τ`，且摩擦/热模型误差并入 `e_τ`；**(A30)** 每条原型证据按定义 123 标定，且共同模式偏差不超过 `b_common`；**(A31)** 采样数据无源性条件（`π_S≥π_min`）蕴含接触稳定；**(A32)** 证据账本至少含一个与廉价原型统计独立、`f_p≥f_anchor` 的锚点。
则当 `J_τ` 被签发时，真实部署失败概率满足
```
P_fail ≤ Σ_d (1−ρ_min(d)) + β_E + P(δ_a>Θ_a)
         + e_τ/τ_max + b_common + Σ_{p∈E} δ_p
         + P(租约在执行期内过期)
```
且力矩相关的虚假兼容概率
```
P(m_true < m_min | J_τ 签发) ≤ e_τ/τ_max + b_common + Σ_{p∈E} δ_p
```
关键：**证据下界必须扣掉共同模式偏差**，**接触稳定性必须由无源性单独证明**，**临时证书不得授权高负载/接触任务**。

```python
def torque_profile(skill, actions, contexts, dyn_model, m_min):
    beta = {}
    for a in actions:
        for c in contexts:
            traj = skill.plan(a, c)
            tau_req = inverse_dynamics(dyn_model, traj, contact=True)
            tau_max = actuator_limit(traj.q, traj.qdot, c)   # 含热降额
            beta[(a, c)] = min((tau_max[j] - abs(tau_req[j])) / tau_max[j]
                               for j in range(len(tau_max)))
    return beta

def effective_action_profile(alpha, beta, contexts, m_min):
    return {a: alpha[a] * float(all(beta[(a, c)] >= m_min for c in contexts))
            for a in alpha}
```

### IP-122 TAC

```python
def torque_aware_compose(skill_seq, beta, pi, w, budgets):
    for s in skill_seq:
        if min(beta[s].values()) < budgets.m_min:  return ('reject', 'torque_saturation', s)
        if min(pi[s].values())   < budgets.pi_min: return ('reject', 'passivity', s)
        if min(w[s].values())    < budgets.w_min:  return ('reject', 'contact_wrench', s)
    for s1, s2 in zip(skill_seq, skill_seq[1:]):
        if handoff_torque_jump(s1, s2) > budgets.tau_slew:
            return ('reject', 'torque_discontinuity', (s1, s2))
        if handoff_passivity(pi[s1], pi[s2]) < budgets.pi_min:
            return ('reject', 'handoff_instability', (s1, s2))
    return ('ok', skill_seq)

def torque_aware_edge(s1, s2, alpha, beta, pi, K, budgets):
    compat = jaccard(alpha[s1], alpha[s2])
    if min(beta[s1].values(), beta[s2].values()) < budgets.m_min: return None
    if handoff_passivity(pi[s1], pi[s2]) < budgets.pi_min:        return None
    dtau = handoff_torque_jump(s1, s2)
    if dtau > budgets.tau_slew: return None
    rho_comp = compose_robustness(s1.rho, s2.rho, K)
    cost = transition_cost(s1, s2) + budgets.w_tau * dtau
    return Edge(compat=compat, cost=cost, rho_comp=rho_comp, dtau=dtau)
```

### IP-124 EPL

```python
def evidence_bounds(ledger, metric, b_common):
    items = [e for e in ledger if e.metric == metric and not e.expired()]
    if not items: return (-math.inf, math.inf, True)
    lo = max(e.y_hat - e.eps for e in items)
    hi = min(e.y_hat + e.eps for e in items)
    return (lo - b_common, hi, lo > hi)     # (y_lb, y_ub, conflict)

def admissible_evidence(ledger, metric, m_min, b_common, a_min):
    y_lb, _, conflict = evidence_bounds(ledger, metric, b_common)
    fresh = all(e.assurance(now()) >= a_min for e in ledger if e.metric == metric)
    anchored = any(e.fidelity >= ANCHOR_F and e.independent for e in ledger)
    return (not conflict) and fresh and anchored and (y_lb >= m_min)
```

### IP-125 PBO

```python
def schedule_prototypes(candidates, budget, boundary, anchor_fidelity):
    chosen, remaining = [], budget
    while remaining > 0:
        scored = [(p, boundary_voi(p) / p.cost) for p in candidates
                  if p not in chosen and p.cost <= remaining]
        if not scored: break
        p, score = max(scored, key=lambda x: x[1])
        if score <= 0: break
        chosen.append(p); remaining -= p.cost
        update_belief(p)
    if not any(p.fidelity >= anchor_fidelity and p.independent for p in chosen):
        chosen.append(cheapest_independent_anchor(candidates))
    return chosen, budget - remaining
```

**正确性定理（Torque-Evidence Grounded Composition Soundness）**
假设第 53–54 轮 (A22)–(A28) 成立；**(A29)** `||τ_req−τ_true||∞ ≤ e_τ`（摩擦/热误差并入）；**(A30)** 每条证据按定义 123 标定，共同模式偏差 ≤ `b_common`；**(A31)** `π_S≥π_min` 蕴含接触稳定；**(A32)** 账本含与廉价原型独立的 `f_p≥f_anchor` 锚点。
则 `J_τ` 签发后的真实失败概率
```
P_fail ≤ Σ_d(1−ρ_min(d)) + β_E + P(δ_a>Θ_a)
         + e_τ/τ_max + b_common + Σ_{p∈E}δ_p
         + P(租约执行期内过期)
```
力矩虚假兼容概率
```
P(m_true<m_min | J_τ) ≤ e_τ/τ_max + b_common + Σ_{p∈E}δ_p
```
要点：**证据下界必须扣共同模式偏差**；**接触稳定由无源性独立证明**；**`γ_cert>1` 只发临时证书**。
