# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「结构优化」×「放置」）

> R69 把不确定性一分为二（aleatoric / epistemic），并给 epistemic 配了「问」的能力：看、问、触，VoI 定价，单源不定案。但它有三个结构层面的盲点：
> 1. **结构盲**：无论当前风险集中在哪，FLUID 都跑同一条五层流水线（FMP→AUD→MINT→CIA→FMA）；R69 自陈的实时预算「K=4 时允许一次性超支」，本质是结构没有随负载重分配，而是整体加厚。
> 2. **放置盲**：R69 的「问」只回答 *what*（问什么、看哪、触哪一类），不回答 *where/when*——探针放在哪个位姿、问句放在哪个时刻、注视放在哪个持续时间，全被折叠进一个软提示向量，信息量最大的那部分设计空间被扔掉了。
> 3. **信任回流**：R69 的最大风险是「模态分布不可信 → VoI 在错误信念上计算 → 自信地追问幻影」。要害在于：**R69 用来决定『问什么』的那个模型，正是它怀疑不可信的那个模型**；这是一个自指闭环，越问越可能把模型的幻觉坐实。
>
> 本轮两个灵感正好把这三个盲点一次补齐：
> - **放置**：把「求证」拆成 **瞬态探针**（看/问/触，一次性、由学习模型生成、收益即时）与 **持久锚点**（基准标记、支撑点、固定传感器/已知几何体，一次性投入、跨时程摊销、**测量的是物理世界而非模型信念**）。持久锚点是 R69 自指闭环的出口：当你不信任模型时，不要问它该问谁，而是**放一个物理上可验证的东西**，让歧义在之后很多步里自己消失。
> - **结构优化**：把证据/验证流水线看成一个**承力结构**——不确定性是载荷，安全保证是刚度，算力/时延/风险是重量。结构优化的第一性原理不是「每根杆都加粗」（R69 的做法），而是**把材料放到应力最高的节点、把冗余放到最可能失效的接头、把低应力杆剪掉**。于是 R70 用「最小充分证据集」动态剪枝 + 「高应力关节冗余」，在**不比 R69 更不安全**的前提下，把常规路径做得更稀疏、更便宜。
>
> 核心命题：**R69 的「问」是一次性、结构盲、且由被怀疑的模型驱动的；R70 把求证升级为「证据结构的最优分配」×「瞬态探针与持久锚点的联合放置」，并用持久锚点这条模型无关通道绕过模型不可信时的自指困境。安全侧仍是约束而非权衡：结构只剪信息冗余，绝不剪安全核；放置先过安全认证再谈信息量。** 命名 **ANCHOR-RAS**（Amortized structural verificatioN and Certified Heterogeneous Observation Reallocation）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**把求证放在哪里、什么时候放、值不值得一直放着**」——不确定性不只是刹车踏板、也不只是一句提问，还可以是一枚钉子、一个支点、一块贴纸。

## 0. 直觉与动机

**灵感 1（结构优化 → 证据流水线是一个承力结构，而不是一串模块）**
直觉：桁架优化的结果常常反直觉——不是均匀加粗，而是把材料搬到少数关键路径上，其余杆件细到极限甚至删掉；同时在最可能断裂的接头处布置冗余。R69 的 FLUID 恰好是「均匀加粗」：FMP、AUD、MINT、CIA、FMA 每层都常开，K=4 时整体超支。但风险在空间/时间上极不均匀：大多数时刻只有一个模态、标定健康、流似然正常，跑全套是浪费；少数时刻风险集中在「标定-似然接缝」或「模态可分性」上，那里才需要冗余。于是把闭环重写为一个**证据图**：节点是证据源（含锚点），边是条件依赖，节点有成本/时延/风险/信息向量。结构优化的目标不是「最小延迟」也不是「最大信息」，而是**在安全可行域内，用最小结构达到充分可辨识性**。关键约束：**安全核（触发保守退避的那些节点）不可剪**；可剪的只有信息冗余。这样剪枝只降低「知道多少」，不降低「保证多少」。

**灵感 2（放置 → 探针的位姿与时序，本身就是决策变量）**
直觉：人类解决歧义很少只靠「再看一眼」，而是**挪动自己去获得更好的视角**：蹲下、侧身、把物体转过来、把手先搭上去稳住再摸、把可疑物放到有背景参照的桌面上。R69 把这一切压成一个 info-action 向量，丢掉了最关键的自由度——**位置与时刻**。放置有三层：
- **空间放置**：注视方向/停留、探针接触点与力、支撑点、基准标记贴在哪；
- **时间放置**：先问还是先做、在证据最可分时问、在预算最宽时问；
- **结构放置**：把冗余/验证节点放在证据图的哪个接头上。
三者本质是同一个问题：**在「收益随位置变化」的场里，把有限的信息获取能力放到边际收益最高的地方**。这天然是一个（受安全约束的）最优实验设计 / 传感器选择问题，而不是一个分类问题。

**灵感 3（持久 vs 瞬态 → 「放置」是投资，「探针」是消费）**
直觉：R69 的每次交互都是**消费**——问完就没了，下一步还要再问。而贴一枚 fiducial、架一个固定相机、把物体放到可复现的支撑构型，是**投资**：一次付出，之后每一步都在收利息。用贴现和表达：瞬态探针价值 ≈ 单步信息增益 − 单次成本；持久锚点价值 ≈ Σ γ^t·每步增益 − 一次性成本。于是存在一个**视界交叉点**：短视界、一次性歧义 → 用瞬态探针（R69）；长视界、反复出现的同类歧义 → 用持久锚点（R70 新增）。这把「要不要交互」升级为「**要不要把交互固化成结构**」。但投资有投资的危险：瞬态错误只错一步，持久错误会错很多步——这正是本轮最大风险的来源。

**灵感 4（模型无关通道 → 正面回应 R69 的自指困境）**
直觉：R69 的三条通道里，r_res 由标定层解释、a_score 由策略密度定义，**两者都建立在学习模型之上**。当模型本身不可信时，用模型去决定「向谁求证」是自指。持久锚点提供第三条、**模型无关**的通道：物理标记在世界系中的位姿由几何/身份校验给出，不经过 flow 模型，也不经过标定映射。它不能告诉你「下一个动作该是什么」，但能告诉你「世界是不是你以为的那个世界」。在 R68 的 (r_res↓) 与 R69 的 (Δa↑) 之外加入 (r_anchor↑)，三通道的盲区两两不同：标定吸收 r_res，训练分布主脊可以容纳 Δa 的部分漂移，而锚点的身份/几何失配**无法被这两者吸收**。这就是「放一个东西」比「问一句」更抗自欺的原因。

**灵感 5（结构性过度自信 → 新威胁模型：放置攻击与冗余被剪）**
直觉：一旦系统会「放置」，攻击面从「撒谎的回答」扩展到「**伪造的确定性**」：贴一张假 fiducial、移动一个被信任的标记、用镜面/遮挡制造几何一致但语义错误的锚点、把系统诱导到「看起来被钉死、其实钉在错的东西上」。更隐蔽的是结构优化自身的副作用：为了让常规路径更稀疏，它**剪掉了本可以在锚点失效时揭穿它的冗余通道**。所以 R70 必须同时交付：放置安全认证（支撑/可达/遮挡/力/社交）、锚点完整性契约（身份+有效期+自检）、放置信息模型的校准门（预测增益 vs 实现增益）、以及「**剪枝不得剪到能揭穿锚点的那条冗余**」的结构约束。否则 R70 不是把 R69 的自指闭环打开，而是给它焊死。

## 1. 形式化定义（增量：定义 310–322）

**定义 310（ANCHOR-RAS 总览）** ANCHOR-RAS = (SEG, SAT, PEP, AMV, SAB, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **放置硬约束**：任何放置 p 必须先通过 C-RAS-WM‡ 认证（支撑多边形/可达/无自遮挡/力包络/社会成本），再进入信息量比较；放置与探针共用同一安全包络；
(iii) **锚点完整性契约**：持久锚点携带可校验身份与有效期，任何决策只有在锚点完整性于有效窗口内被认证时才可依赖它；完整性不可判定 ⇒ 视为不存在。

**定义 311（结构证据图 SEG）** 证据图 G_t = (V_t, E_t) 为有向无环图：节点 v ∈ V_t 是证据源（r_geo, r_sync, r_zero, r_emo, r_wm, a_score，以及锚点证据 r_anchor），携带 (cost_v, latency_v, risk_v, Fisher 信息 F_v, safety_critical_v)；边 (u→v) ∈ E_t 表示 v 的条件依赖 u（如 r_wm 以 z_t 为条件）。一次决策的证据图是 G_t 的一个**活跃子图**，而非固定流水线。

**定义 312（结构可辨识性与最优性准则）** 对决策变量 M（模态身份，R69 定义 296），活跃子图 𝒢 的总 Fisher 信息 F(𝒢) = Σ_{v∈𝒢} F_v + Σ_{(u,v)∈E} C_{uv}（C 为条件交叉项）。结构目标是 **D-最优**：max_{𝒢} log det F(𝒢)，s.t. Σ cost_v ≤ B_struct、安全核 K ⊆ 𝒢（K = {v : safety_critical_v}，永不被剪）。A-最优（min tr F^{-1}）作为对照。Cramér–Rao 给出：模态估计误差下界 Var(M̂) ⪰ tr F(𝒢)^{-1}——**结构直接控制可辨识性，而不只是控制延迟**。

**定义 313（瞬态探针 vs 持久锚点）** 瞬态探针 g = (g_gaze, g_probe, g_ask)（继承 R69 定义 294），只影响当前步观测。持久锚点 a = (type, pose_w, validity)（type ∈ {fiducial, support, fixed_sensor, known_landmark}），其存在改变**未来 H_a 步的观测模型**：y_t = h(x_t; a) + n_t，t ∈ [t_0, t_0+H_a]。因此锚点把 F(𝒢) 从「当前子图」扩展为「带持续证据的子图」：F(𝒢; a) = F(𝒢) + Σ_{t} F_{a,t}。

**定义 314（摊销边际信息价值 AMV）** 设单步信息增益 i(p) = I(M; y | p, o)，成本 c(p)，风险 risk(p)，贴现 γ：
AMV(p) = i(p)·(1−γ^{H_p})/(1−γ) − c(p) − risk(p)。
瞬态探针为 H=1 的特例（AMV = i − c − risk），与 R69 定义 298 的 VoI−成本逐项一致。选择 p* = argmax_p AMV(p) s.t. 安全认证通过、预算未越界；AMV(p*) ≤ 0 则不放置、退 R69。

**定义 315（最小充分证据集 MSES）** 给定上下文 c（由 z_t 与风险画像给出）、充分性阈值 δ ∈ (0,1)：
E*(c) = argmin_{K ⊆ E ⊆ V} Σ_{v∈E} cost_v，s.t. log det F(E) ≥ (1−δ)·log det F(V)。
即：**在安全核之外，允许用 (1−δ) 的可辨识性换取结构的稀疏**。δ 是该上下文的风险预算，由 R68 的 U_cal 与 R69 的 U_epi 联合决定：越危险，δ 越小（越接近全图）。

**定义 316（放置空间与安全认证）** 放置 p = (x_w, t, τ, type) 的有效域由支撑多边形 stab(p) ≥ s_min、可达性 reach(p)=1、无自遮挡 occ(p)=0、力/位包络 ‖f(p)‖ ≤ f_max、社交成本 soc(p) ≤ c_s 共同界定。认证函数 Cert_place(p) 由 C-RAS-WM‡ 给出；不通过 ⇒ p 作废，且不得以「信息量大」为由豁免（**安全是约束，信息是目标**，字典序）。

**定义 317（锚点完整性与再放置）** 锚点 a 的完整性由三重签名联合判定：id_match(a, o_t)（身份/编码匹配）、geo_consist(a, o_t)（同一锚点在多视角/多时刻下的几何自洽）、force_sig(a, o_t)（若为支撑/接触锚点，力签名一致）。任一项越界或超出 validity 窗口 ⇒ a 失效。SAB 维护集合 A_t；失效触发**再放置**（PEP 重新规划）或**降级**（退 R69 瞬态 / R68 保守）。

**定义 318（放置信息模型校准门 PCG）** 放置规划依赖预测增益 î(p)。用回归校准（可靠图 + ECE）检验 î 与实现增益 i_real 的一致性；若 ECE > τ_pcg，禁用 PEP 的持久锚点分支（只保留 R69 瞬态探针），并在证书中标记 `placement_uncalibrated`。与 R69 的 MCG 同构，但作用在「位置的信息量」而非「模态的权重」上。

**定义 319（放置–标定–似然三通道对偶）** 定义三个残差：
- r_res：传感器自洽残差（R68，可被标定映射吸收）；
- a_score：动作在策略密度下的负对数似然（R69，由学习策略定义）；
- r_anchor：观测与持久锚点的几何/身份/力签名失配（R70，**模型无关**）。
三者构成对偶观测 (r_res, a_score, r_anchor)。设计目标是**盲区不相交**：标定吸收 r_res；训练主脊可容纳部分 a_score 漂移（R69 A98）；r_anchor 不经过二者，故不能被二者吸收。联合判据可分离「真漂移 / 缓变故障 / 记忆漂移 / 锚点投毒」。

**定义 320（证书 J_ANCHOR）** J_ANCHOR = (J_FLUID, structure_sparsity, det_ratio, anchor_integrity, amv_pred, amv_real, placement_risk, anchor_log_hash, anchor_ver)。Valid ⇔ Valid(J_FLUID) ∧ det_ratio ≥ 1−δ ∧ anchor_integrity 在有效窗口内 ∧ PCG 未越界 ∧ 放置风险 ≤ ε_place。

**定义 321（放置威胁模型 ℰ_ANCHOR）** 并入 R69 的 ℰ_FLUID：诱饵锚点（decoy fiducial）、被移动的可信锚点、镜面/遮挡制造的几何假一致、以「提供参照」为名的社交工程、锚点与新场景的语义错配（几何一致但语义错误）。ℰ_ANCHOR = ℰ_FLUID × ℰ_decoy × ℰ_geometry_spoof × ℰ_semantic_mismatch。

**定义 322（三级保守退避）** 若持久锚点通过认证且 AMV > 0：λ = λ_floor(U_ale)（结构 bonus）；若不可放置/PCG 越界/锚点失效：退 **R69**（瞬态探针，λ = λ_floor(U_ale + 未消解 U_epi)）；若瞬态也不可行或 R69 判定不交互：退 **R68**（λ = λ_floor(U_ale + U_epi)）。三级 λ 单调不降，且逐级**逐指令**落到上一轮的策略上。⇒ R69/R68 分别是「禁用持久放置」「禁用一切交互」的边界。

## 2. 关键算法骨架

```python
# IP-265 SAT：结构证据图优化（安全核不可剪 + 子模贪心）
def optimize_structure(V, budget, context):
    K = {v for v in V if v.safety_critical}          # 安全核：永不被剪
    F = fisher_information(K)                        # 起始信息
    chosen = set(K)
    info = [v for v in V if not v.safety_critical]
    F_full = fisher_information(V)
    delta = risk_budget(context, U_cal, U_epi)       # 越危险 delta 越小
    while cost(chosen) < budget and set(info) - chosen:
        best = max(set(info) - chosen, key=lambda v: logdet(F + F_v) - logdet(F))
        if logdet(F + F_best) < (1 - delta) * logdet(F_full):
            break                                    # 达到充分性即停（稀疏）
        chosen.add(best); F = F + F_best
    return subgraph(chosen)                          # 最小充分证据集 E*(c)

# IP-266 PEP：瞬态探针 + 持久锚点联合放置（安全先行，信息随后）
def plan_placement(modes, graph, scene, budget, pcg):
    cands = transient_candidates(modes) + anchor_candidates(scene)
    best = None
    for p in cands:
        if not Cert_place(p, scene): continue        # 支撑/可达/遮挡/力/社交
        if not budget.allow(p):      continue
        if p.kind == 'anchor' and not pcg.calibrated(): continue  # IP-318 校准门
        ig  = marginal_info_gain(p, graph)           # 基于校准信息模型
        val = amortized_voi(ig, p.horizon, p.cost, p.risk)
        if best is None or val > best.val: best = (p, val)
    return best if best and best.val > 0 else None   # 无利可图 → R69

# IP-267 AMV：摊销边际信息价值（瞬态 = H=1 的特例）
def amortized_voi(ig, H, cost, risk, gamma=0.98):
    return ig * sum(gamma**t for t in range(H)) - cost - risk

# IP-268 SAB：锚点完整性维持与再放置
def maintain_anchors(A_t, o_t, t):
    for a in list(A_t):
        ok = (id_match(a, o_t) and geo_consist(a, o_t)
              and force_sig(a, o_t) and t <= a.valid_until)
        if not ok:
            A_t.remove(a)
            if not replan_anchor(a):                 # 再放置失败
                return A_t, 'degrade'                # 触发降级
    return A_t, 'ok'

# IP-264 主闭环（三级退避：结构锚点 → 瞬态探针 → R68 保守）
def ANCHOR_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K  = M.fmp.mode_head(z)
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(o, M.k_for(K)), z)
    # 1) 结构优化：按上下文剪出最小充分证据集（安全核保留）
    G = M.sat.optimize_structure(M.seg, M.budget, context=z)
    # 2) 第三通道：锚点几何一致性（模型无关）
    M.sab.update(M.anchors, o)                        # IP-268
    r_anchor = anchor_consistency(M.anchors, o)       # IP-319
    fault3 = (r_anchor > TAU_ANCHOR) and (M.last_r_res < TAU_RES)
    # 3) 放置规划：优先持久锚点（摊销），否则瞬态探针（R69）
    p = None
    if U_epi > TAU_EPI and not fault3 and M.pcg.calibrated():
        p = M.pep.plan_placement(modes, G, M.scene, M.budget, M.pcg)
    if p is None:
        return M.fluid_round(obs)                     # 退化 R69（定义 322）
    info = M.sab.query(p, o) if p.kind == 'anchor' else M.cia.execute(p)
    U_epi_after = M.cia.update_belief(modes, info)
    # 4) 风险缩放：只对 aleatoric + 未消解 epistemic 收紧（继承 R69）
    U_floor = U_ale + (U_epi_after if p is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    if fault3:                                        # 锚点失配 = 最保守
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(..., U_cal))
    mode = select_mode(modes, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_p.submit_async(p, G, r_anchor, U_epi, U_epi_after)
    return k, lam, mode, (U_ale, U_epi_after, G)
```

## 3. 推导

**引理 19（结构稀疏的 D-最优界）** log det F(·) 在节点集合上是单调子模的；在预算约束下，SAT 的贪心解 𝒢_g 满足 log det F(𝒢_g) ≥ (1−1/e)·OPT（子模最大化标准界）。结合 Cramér–Rao，模态估计误差下界满足 tr Var(M̂) ≳ tr F(𝒢_g)^{-1}；当 min_eig F(𝒢_g) ≥ η（充分激励）时，模态误选概率 ≤ exp(−η·Δ_min²/2)（高斯尾部）。系：**只要保留充分激励，稀疏化只损失常数因子内的信息，不改变误选概率的指数阶**——这就是「剪信息冗余不降安全」的解析根据。

**引理 20（摊销 vs 瞬态的视界交叉）** 设持久锚点单步增益 i_a、一次性成本 c_a、可维持 H 步；瞬态探针单步净收益 i_g − c_g。则持久锚点优于瞬态当且仅当
i_a(1−γ^H)/(1−γ) − c_a > i_g − c_g。
故存在交叉视界 H*；H > H* 用放置（投资），H < H* 用探针（消费）。系：**歧义持续越久，越应该把一次交互『固化』成结构**；反之，一次性歧义用 R69 更省。注意风险项：锚点被投毒时风险乘 H（见定理 20），因此 H* 必须用**风险调整后**的 i_a 计算，而非名义增益。

**引理 21（三通道盲区不相交）** 在 A99（标定映射只吸收与传感器零偏同子空间的慢变分量；策略密度对条件 Lipschitz；锚点几何残差独立于前两者）下，存在慢变故障 f 使 r_res ≈ 0 且 Δa 有界（落在训练主脊内），但 r_anchor = ‖proj_{a}(o − ĥ(o; a))‖ 随 f 单调上升。故任一被单通道吸收的故障，若进入锚点可观测子空间，必被 r_anchor 捕获。系：**模型无关通道不是第三条冗余，而是一条与学习模型正交的坐标轴**；它是 R69 自指闭环的出口。

**引理 22（稳定性–可观测性 Pareto）** 放置的信息量 log det F(p) 与稳定性余量 stab(p) 一般不同向（把手伸到更远处能看得更清楚，但支撑变差）。在安全可行域 S = {p : stab(p) ≥ s_min, reach, occ=0, ‖f‖ ≤ f_max} 上，Cert_place 先做**可行域投影**，再在 S 内最大化信息量。于是最优放置 p* = argmax_{p∈S} AMV(p) 恒满足 stab(p*) ≥ s_min：**安全是硬约束，信息是目标，二者不是可交换的加权和**。系：任何以「信息增益高」为由放宽 s_min 的规划都应被证书判为非法。

**定理 18（ANCHOR 严格包含 FLUID 与 R68）** 在 A95–A99 下，三级策略（结构锚点 → 瞬态探针 → 保守）在任意状态上的期望风险 ≤ R69 ≤ R68；且当无持久放置可用（PEP 返回 None 或 PCG 越界）时逐指令等于 R69，当 R69 亦判定不交互时逐指令等于 R68（定义 322）。因此 R69/R68 分别是本轮在「禁用持久放置」「禁用一切交互」边界上的退化：安全侧不做任何让步，效率侧获得结构稀疏 + 摊销双重 bonus。

**定理 19（结构剪枝不降安全）** 设风险上界可分解为 R(𝒢) = R_safety(K) + R_info(𝒢)，其中 K 为安全核（不可剪）、R_info 由可辨识性控制。若 log det F(𝒢) ≥ (1−δ) log det F(V)，则 R_info(𝒢) ≤ R_info(V) + c·δ（一阶展开，c 为 Fisher 曲率常数）；而 R_safety(K) 逐项不变。故 SAT 剪枝只影响信息侧风险、且影响被 δ 有界；安全核完全不变 ⇒ 认证安全包络不降。**这是「结构优化」在本框架里合法的前提，也是它唯一的合法性来源。**

**定理 20（锚点投毒下的退化安全）** 在 ℰ_ANCHOR 下，设诱饵/篡改先验概率 δ_a、完整性校验功效 η（三重签名联合），则系统依赖被污染锚点作出决策的概率 ≤ δ_a·(1−η)^3；一旦 SAB 判定完整性不可保，三级退避使 λ 单调不降地落到 R69/R68，且放置节点被移出 F(𝒢)。系：**锚点的收益随视界 H 线性增长，但其被投毒的风险也随 H 线性增长**——这就是为什么定义 310-iii 要求有效期，而不是「贴上就永久信任」。

## 6. 本轮最大风险

**一句话**：结构优化与持久放置把「一次性的错误」升级为「**结构性的、被复利的错误**」——一旦锚点被投毒或放置信息模型失准，系统会沿着一个错误的世界参照**自信地稀疏化**，而 SAT 为省算力亲手剪掉了本可在下一时刻揭穿该锚点的冗余通道；**放错，比不问更危险；更危险的是，结构优化让纠错的那条路也一起消失了。**

**次级风险与缓解**：
1. **锚点投毒/诱饵/几何假一致** → 定义 317 三重签名 + 定理 20 上界 + 定义 321 对抗训练 + E306；
2. **剪掉揭穿锚点的冗余** → 定义 311 安全核硬保留 + 定理 19 的安全/信息风险分解 + 「完整性通道恒在 𝒢」结构约束；
3. **放置信息模型失准** → 定义 318 PCG 校准门，越界即禁用持久锚点、逐指令退 R69；
4. **放置本身不安全** → 定义 316 认证 + 引理 22 可行域投影，安全是约束不是加权项；
5. **视界/贴现误设** → 引理 20 的风险调整 H* + E308 校准，避免把短期歧义过度投资成长期结构。

```python
# IP-266 SAT：结构证据图优化（安全核不可剪 + 子模贪心）
def optimize_structure(V, budget, context, U_cal, U_epi):
    K, F = {v for v in V if v.safety_critical}, None
    chosen = set(K); F = fisher_information(K)
    info, F_full = [v for v in V if not v.safety_critical], fisher_information(V)
    delta = risk_budget(context, U_cal, U_epi)      # 越危险 delta 越小
    while cost(chosen) < budget and set(info) - chosen:
        best = max(set(info) - chosen, key=lambda v: logdet(F + F_v) - logdet(F))
        if logdet(F + F_best) < (1 - delta) * logdet(F_full): break
        chosen.add(best); F = F + F_best
    return subgraph(chosen)                        # E*(c)

# IP-267 PEP：瞬态探针 + 持久锚点联合放置（安全先行）
def plan_placement(modes, graph, scene, budget, pcg):

    for p in transient_candidates(modes) + anchor_candidates(scene):

    return best if best and best.val > 0 else None  # 无利可图 → R69

    M.sab.update(M.anchors, o)
    r_anchor = anchor_consistency(M.anchors, o)                      # 第三通道
    fault3   = (r_anchor > TAU_ANCHOR) and (M.last_r_res < TAU_RES)
    p = (M.pep.plan_placement(modes, G, M.scene, M.budget, M.pcg)
         if (U_epi > TAU_EPI and not fault3 and M.pcg.calibrated()) else None)
    if p is None: return M.fluid_round(obs)                          # 退 R69
    info = M.sab.query(p, o) if p.kind == 'anchor' else M.cia.execute(p)
    U_epi = M.cia.update_belief(modes, info)
    U_floor = U_ale + (U_epi if p is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    if fault3: lam = max(lam, 0.8); k = min(k, k_cal_shrink(..., U_cal))
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_p.submit_async(p, G, r_anchor, U_epi)
    return k, lam, mode, (U_ale, U_epi, G)
```

## 4. 推导

**引理 19（结构稀疏的 D-最优界）** `log det F(·)` 单调子模；预算下贪心解 `𝒢_g` 满足 `log det F(𝒢_g) ≥ (1−1/e)OPT`。结合 Cramér–Rao，`tr Var(M̂) ≳ tr F(𝒢_g)^{-1}`；当 `min_eig F ≥ η` 时模态误选概率 `≤ exp(−η·Δ_min²/2)`。系：稀疏化只损失常数因子信息，不改变误选概率的指数阶——剪信息冗余不降安全。

**引理 20（摊销 vs 瞬态视界交叉）** 持久锚点优于瞬态 iff `i_a(1−γ^H)/(1−γ) − c_a > i_g − c_g`；存在交叉视界 `H*`。系：歧义持续越久越应「固化」成结构；一次性歧义用 R69 更省。`H*` 必须用风险调整后的增益计算。

**引理 21（三通道盲区不相交）** 在 A99 下存在慢变故障使 `r_res≈0` 且 `Δa` 有界，但 `r_anchor` 单调上升。被单通道吸收的故障，若进入锚点可观测子空间，必被 `r_anchor` 捕获。系：模型无关通道是与学习模型正交的坐标轴，是 R69 自指闭环的出口。

**引理 22（稳定性–可观测性 Pareto）** 信息量与稳定余量一般不同向；`Cert_place` 先做可行域投影 `S`，再在 `S` 内最大化 AMV。故最优放置恒满足 `stab ≥ s_min`：安全是硬约束、信息是目标，不是可交换的加权和。

**定理 18（ANCHOR 严格包含 FLUID 与 R68）** A95–A99 下三级策略期望风险 ≤ R69 ≤ R68；无持久放置时逐指令等于 R69，R69 亦不交互时逐指令等于 R68。安全不让步，效率获结构稀疏 + 摊销双重 bonus。

**定理 19（结构剪枝不降安全）** 若 `R(𝒢)=R_safety(K)+R_info(𝒢)` 且 `log det F(𝒢) ≥ (1−δ)log det F(V)`，则 `R_info(𝒢) ≤ R_info(V)+c·δ`，而 `R_safety(K)` 逐项不变。故 SAT 剪枝只影响有界的信息侧风险，安全包络不降——这是结构优化在本框架中唯一的合法性来源。

**定理 20（锚点投毒下退化安全）** 诱饵先验 `δ_a`、三重完整性功效 `η`，则依赖污染锚点的概率 `≤ δ_a(1−η)^3`；SAB 判定完整性不可保时三级退避使 λ 单调不降地落 R69/R68，放置节点移出 `F(𝒢)`。系：收益与风险都随视界 `H` 线性增长，故必须有有效期而非永久信任。

## 7. 本轮最大风险

**一句话**：结构优化与持久放置把「一次性的错误」升级为「**结构性的、被复利的错误**」——一旦锚点被投毒或放置信息模型失准，系统会沿一个错误的世界参照**自信地稀疏化**，而 SAT 为省算力亲手剪掉了本可在下一时刻揭穿该锚点的冗余通道；**放错，比不问更危险；更危险的是，结构优化让纠错的那条路也一起消失了。**

**次级风险与缓解**：锚点投毒/诱饵/几何假一致（定义 317 三重签名 + 定理 20 + ℰ_ANCHOR 对抗训练 + E306）；剪掉揭穿锚点的冗余（安全核硬保留 + 定理 19 风险分解 + 「完整性通道恒在 𝒢」约束）；放置信息模型失准（定义 318 PCG 门，越界退 R69）；放置本身不安全（定义 316 认证 + 引理 22 可行域投影）；视界/贴现误设（引理 20 风险调整 `H*` + E308）。
