# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC / IP-153~160；灵感循环第 7 轮；本轮灵感：「机械臂抓取」×「演示数据」）

> 第 60 轮的 SERC 把「场景→意图→约束→阻抗→执行→EV-exec→场景」闭了起来，但仍有一个**根本性的冷启动问题**：所有先验（π_scene、ϕ_intent、K_safe 初值）都是**人工设定或在线试出来的**，第 60 轮本身也承认 B_probe/B_exec 会被反复试探消耗。与此同时，现实中的机器人其实早已拥有大量**高质量的人类演示数据**——只是这些数据被当作「模仿学习的轨迹」，而不是「执行合规的接地证据」。本轮引入两条灵感：
> 1. **演示数据**：人类演示是**离线证据**，携带隐式的安全裕度与接触不变量；但它**只有成功样本、且分布极窄**，直接模仿会把「幸存者偏差」当成「安全保证」。
> 2. **机械臂抓取**：抓取不是一个阻抗参数，而是一串**接触模态**（接近→接触→力闭合→抬升→搬运→放置→释放），每个模态的物理与风险都不同；抓取失败往往不是 K 选错，而是**模态切换的时机错了**。

## 0. 直觉与动机

**灵感 1（演示数据 → 演示证据编译器 DEC）**
直觉：一段示教视频告诉机器人「怎么做」，却没有告诉它「什么绝对不能发生」。人做演示时手指会自然地留出安全裕度：不捏碎、不打滑、不别劲——这些裕度藏在**力/触觉遥测**里，而不是藏在轨迹形状里。关键洞见：**示教不是模仿轨迹，而是编译不变量**。把演示按接触模态分段，从成功段里抽取摩擦锥裕度、滑移上界、阻抗包络，再用保形分位数（conformal quantile）把经验裕度「膨胀」成高概率安全集，输出可执行契约 C_demo=(前置条件, 不变量, 后置条件, 裕度, K 包络)。
直觉一句话：演示给出的是**软证据**，DEC 把它编译成**硬契约**。

**灵感 2（机械臂抓取 → 抓取接触模态图 GCMG）**
直觉：抓取像一场「有剧本的接力」：接近阶段要柔（低刚度、避免碰撞冲击），接触瞬间要警觉（检测力突变），力闭合阶段要稳（摩擦锥内、抓取质量 Q 足够），抬升阶段才能真正验证是否抓牢（打滑只会在这时暴露），搬运要抗扰动，放置要缓慢卸载。关键洞见：**不存在覆盖全过程的单一 K_safe**；应该在模态图上为每个模态配独立契约，并为每条边配「接力证书」。抓取失败常是**模态切换时机**错误（过早抬升→滑落；过晚闭合→压坏），所以边上的守卫 g_e 比节点上的参数更关键。
直觉一句话：抓取安全 = **模态序列正确 + 每次切换都有证据守卫**。

**灵感 3（演示数据 × 抓取 → 演示胜任域 DCR）**
直觉：演示只覆盖了少数物体、少数质量、少数摩擦、少数位姿。把演示策略用到分布外（一个更重、更滑、位姿更偏的物体）时，策略不是「变差」，而是**失效且不自知**——这正是抽象泄漏最危险的形态。关键洞见：**技能的有效性不是全局的，而是有边界的**。给每个认证技能附带胜任域 Θ_cert（由 kNN 密度 + 保形 OOD p 值估计），域外一律拒绝部署或转入主动试探，而不是硬套演示先验。
直觉一句话：**没有边界的技能不是技能，是幻觉**。

**灵感 4（三灵感合流 → 演示接地抓取闭环 DGGL）**
直觉：DEC 给契约，GCMG 给模态序列，DCR 给有效性边界，三者合成一个闭环：场景+任务 → 检索技能 σ → 查胜任域 → 编译 K → 沿模态图执行 → 逐模态收集 EV → 演示-执行一致性检查 → 更新信任/触发再认证。关键洞见：**演示先验与在线证据必须双向接地**——演示给冷启动一个高信息量的先验，在线 EV 拥有对演示的**一票否决权**；演示先验永远不能覆盖实时证据。这样既省掉冷启动的空探，又不把「人类成功过」误当成「机器人一定安全」。
直觉一句话：**演示负责「起跑不瞎试」，证据负责「跑偏就刹车」**。

**灵感 5（PCE+++++ → 演示/抓取预算）**
直觉：第 60 轮的认知预算 B_scene/B_intent/B_ros/B_exec 缺少「使用演示」和「执行抓取」本身的成本：检索+对齐+扰动再认证+回放要算 B_demo；模态切换、触觉采样、滑移检测要算 B_grasp。若 B_demo 耗尽 ⇒ 退化到保守预置技能或遥操作；若 B_grasp 耗尽 ⇒ 进入 safe-hold；若信任 t_σ 低于阈值 ⇒ 先试探后部署。**预算必须和信任一起花**：高信任技能优先、低信任技能必须留出试探预算。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（演示证据编译 DEC）** 演示数据集 D = {(τ_i, o_i, θ_i, y_i)}_{i=1}^{M}，其中 τ_i 为轨迹（关节/位姿/力/触觉），o_i 为遥测观测，θ_i∈Θ 为任务参数（物体质量 m、摩擦 μ、位姿不确定度 σ_p、尺寸 ℓ），y_i∈{success, failure, recovery}。编译器 DEC: D → {C_m}：
1. **模态分段**：τ_i ↦ {(m, [t_a,t_b])}，与 GCMG 的模态对齐。
2. **不变量抽取**：对模态 m，特征 φ(τ)=(f_n, f_t, v_slip, w_contact, K_eff, Δpose)；不变量集合 Inv_m = { 所有成功段均满足的约束 }，例如 μf_n−|f_t| ≥ 0、|v_slip| ≤ v̄。
3. **保守膨胀**：对安全裕度 m_i，令 m_safe = Q_α({m_i})/(1+γ)，其中 Q_α 为 α-下分位数、γ>0 为膨胀系数；在可交换性假设下，新执行满足 margin ≥ m_safe 的概率 ≥ 1−α（保形保证）。
4. **契约输出**：C_m = (Pre_m, Inv_m, Post_m, m_safe, [K_m^lo, K_m^hi], J_demo)。
**关键约束**：仅用成功样本会破坏可交换性（幸存者偏差）；D 必须包含**扰动负样本/失败恢复样本**，否则 DEC 的保形保证在分布外不成立——这正是四重护栏的第一道。

**定义 162（抓取接触模态图 GCMG）** G = (M, E, g, K, Cert)。M = {m_a 接近, m_c 接触, m_f 力闭合, m_l 抬升, m_t 搬运, m_p 放置, m_r 释放, m_h safe-hold}。每条边 e=(m→m′) 带守卫 g_e: EV → {go, hold, abort} 与接力契约 H_e。
- 力闭合质量 Q_grasp = min_{contacts} (μ f_n − |f_t|)/(μ f_n)；wrench w 需落在摩擦锥 FC 内。
- 边守卫示例：g_{c→f} = [w∈FC] ∧ [Q_grasp ≥ τ_Q] ∧ [|v_slip| ≤ τ_slip]。
- 接力证书 J_e：P(切换后模态安全 | g_e=go) ≥ 1−β。

**定义 163（演示胜任域 DCR）** 任务参数 θ∈Θ；演示支撑 S_D。胜任度
c(θ) = exp(−d_k(θ,D)/h) · k̂(θ)/k̂_max，
其中 d_k 为 k-近邻距离、k̂ 为 KDE、h 为带宽。认证域 Θ_cert = {θ : c(θ) ≥ τ_c}。
保形 OOD 检验：p(θ) = (1 + #{θ_i: d(θ_i,θ) ≤ d(θ,D)})/(M+1)；若 p(θ) < α_ood 判为分布外。
胜任证书 J_cert = (Θ_cert, coverage=P_D(Θ_cert), α_ood)。**域外不认证**：只能拒绝、遥操作或试探。

**定义 164（认证抓取技能 CGS）** σ = (π_σ, G_σ, {C_m}, Θ_cert^σ, J_demo^σ, J_cert^σ, t_σ)。π_σ 为运动原语（DMP/ProMP），G_σ 为模态子图，t_σ∈[0,1] 为信任。技能**可部署**当且仅当 θ∈Θ_cert^σ ∧ J_demo^σ 有效 ∧ J_cert^σ 有效 ∧ t_σ ≥ τ_t。

**定义 165（演示-执行一致性 DECC）** 对技能 σ 与在线 EV-exec，定义演示流形距离
d_DECC(EV,σ) = min_m ||z(EV) − μ_m^demo||_{Σ_m^{−1}}（马氏距离）+ 不变量违反指示。
一致 iff d_DECC ≤ τ_d ∧ Inv_m 全满足。不一致 ⇒ 立即冻结、信任衰减、触发再认证或 safe-hold。**在线证据对演示先验一票否决**。

**定义 166（信任校准融合 TCF）** 贝叶斯更新
t_σ^+ = (t_σ·L_succ(EV)) / (t_σ·L_succ(EV) + (1−t_σ)·L_fail(EV))，
其中 L_succ = exp(−d_DECC²/(2σ_dec²))。用保形风险控制校准部署阈值：P(unsafe | t_σ ≥ τ_t) ≤ ε。演示=先验，EV-exec=似然，信任=门控。

**定义 167（演示接地抓取闭环 DGGL）** 算子 DGGL(M, obj, task)：
```
① SSM: z ← R_scene.update(telemetry)
② Retrieve: σ ← SkillLib.retrieve(obj, z, task)
③ Guard: if θ ∉ Θ_cert^σ or t_σ < τ_t: return probe_or_teleop()
④ Compile: K_m ← EEIS.compile_with_demo_prior(σ.C_m, δ_f), ∀m
⑤ Load: ERTC.load_contract(σ.C_m)
⑥ For m in G_σ.trajectory:
     EV_m ← execute_mode(m, K_m)
     if ¬DECC.consistent(EV_m, σ): trust.decay; safe_hold; return recertify(σ)
     if g_e(EV_m)=hold/abort: return safe_hold()
     ERTC.handover(H_e)
⑦ trust.update(σ, {EV_m}); EPIR.append(build_ev_exec({EV_m}))
⑧ return (σ, K_m, {EV_m}, t_σ, Θ_cert^σ)
```

**定义 168（演示/抓取预算 PCE+++++）** B_demo=(B_retrieve, B_align, B_perturb, B_replay)，B_grasp=(B_transition, B_tactile, B_slip)。成本：
cost_demo = λ_r·Retrieve + λ_a·Align + λ_p·Perturb + λ_y·Replay；
cost_grasp = λ_m·#transitions + λ_t·Tactile_sampling + λ_s·Slip_check。
降级：B_demo[retrieve]=0 ⇒ 预置技能；B_demo[perturb]=0 ⇒ 冻结胜任域；B_grasp[slip]=0 ⇒ safe-hold；B_grasp[transition]=0 ⇒ 直接 abort 至安全位。

## 2. 关键算法伪代码

### IP-161 DEC（演示证据编译）

```python
class DemoEvidenceCompiler:
    def __init__(self, alpha=0.05, gamma=0.2, min_segs=5):
        self.alpha, self.gamma, self.min_segs = alpha, gamma, min_segs

    def compile(self, demos):
        # demos: {tau, telemetry, task, outcome}, 必须含扰动负样本
        library = {}
        for mode, segs in self.segment_by_mode(demos).items():
            succ = [s for s in segs if s.outcome == 'success']
            if len(succ) < self.min_segs:
                continue
            margins = np.array([self.margin(s) for s in succ])  # 摩擦锥/力裕度
            m_safe = np.quantile(margins, self.alpha) / (1 + self.gamma)
            K_lo, K_hi = self.impedance_envelope(succ)
            library[mode] = DemoContract(
                pre=self.preconditions(succ),
                inv=self.extract_invariants(succ),
                post=self.postconditions(succ),
                margin=m_safe,
                K_env=(K_lo, K_hi),
                support=self.support_estimate(succ),
            )
        return library
```

### IP-163 DCR（演示胜任域）

```python
class DemoCompetenceRegion:
    def __init__(self, demos, k=10, h=0.2, tau_c=0.6, alpha_ood=0.05):
        self.X = np.array([d.task_vector for d in demos])
        self.tree = KDTree(self.X)
        self.k, self.h = k, h
        self.tau_c, self.alpha_ood = tau_c, alpha_ood
        self.kde_max = self.kde(self.X).max()

    def competence(self, theta):
        d, _ = self.tree.query(theta, k=min(self.k, len(self.X)))
        return float(np.exp(-np.mean(np.atleast_1d(d)) / self.h)
                     * self.kde(theta) / self.kde_max)

    def conformal_pvalue(self, theta):
        d_theta, _ = self.tree.query(theta)
        dists, _ = self.tree.query(self.X)
        return (1 + np.sum(dists <= d_theta)) / (len(self.X) + 1)

    def certified(self, theta):
        return (self.competence(theta) >= self.tau_c
                and self.conformal_pvalue(theta) >= self.alpha_ood)
```

### IP-167 DGGL（演示接地抓取闭环）

```python
def demo_grounded_grasp_loop(M, obj, task):
    scene = M.scene_model.update(M.telem_force, M.telem_pos)
    sigma = M.skill_lib.retrieve(obj, scene, task)

    if not M.dcr.certified(task.theta) or sigma.trust < M.tau_trust:
        return M.probe_or_teleop(obj, task)          # 域外拒绝/试探

    K = M.eeis.compile_with_demo_prior(sigma.contracts, task.delta_f)
    M.ertc.load_contract(sigma.contracts)
    mode, log = sigma.gcmg.start, []
    while mode not in ('release', 'safe_hold'):
        ev = M.execute_mode(mode, K[mode])
        log.append(ev)
        if not M.decc.consistent(ev, sigma):
            M.trust.decay(sigma, ev); M.safe_hold()
            return M.recertify(sigma, ev)            # 在线证据一票否决
        nxt, handover = sigma.gcmg.advance(mode, ev)
        if handover:
            M.ertc.handover(handover)
        mode = nxt
    M.trust.update(sigma, log)
    M.epir.append(build_ev_exec(log))
    return M, log, sigma.trust
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DEC | O(M·T + M log M) 离线 | O(M·d) | 保形安全：域内不变量违反率 ≤ α+β |
| GCMG | O(deg) / 次切换 | O(\|E\|) | 切换守卫为充分统计量，接力证书 ≥ 1−β |
| DCR | O(log M) 查询 | O(M) | 保形 OOD 有效，域外不认证 |
| DECC | O(d) / 模态 | O(1) | 异常在一个控制周期内冻结 |
| TCF | O(1) | O(1) | 信任 ECE ≤ ε，部署风险 ≤ ε |
| DGGL | O(#modes·(exec+d)) | 复用 | 冷启动试探成本显著下降 |

**正确性定理（DGGC）**：若 A66–A71 成立——(A66) 域内演示与部署可交换且含负样本；(A67) GCMG 守卫为切换安全的充分统计量；(A68) DCR 支撑估计一致；(A69) 演示流形覆盖正常执行；(A70) TCF 似然模型正确且经保形校准；(A71) B_demo/B_grasp 单调消耗——则：
1. **安全性**：θ∈Θ_cert 时，新抓取不变量违反概率 ≤ α+β；
2. **拒绝安全性**：θ∉Θ_cert 时不允许认证部署，风险由试探策略显式承担；
3. **在线否决**：执行一旦脱离演示流形，DECC 在一个控制周期内冻结，演示先验无法造成无界伤害；
4. **信任校准**：部署阈值使 P(unsafe | t_σ ≥ τ_t) ≤ ε；
5. **预算安全**：任一 B_demo/B_grasp 耗尽触发对应保守降级。

## 5. 本轮最大风险

**一句话**：演示数据天然带幸存者偏差与极窄分布，若把「人类成功过」直接当作「机器人安全」，DEC 会把错误先验认证成高置信契约，在分布外造成「证据层高度确定、执行层灾难性失效」；必须以「扰动负样本+保形 α」「DCR 域外拒绝」「DECC 在线一票否决」「TCF 信任门控」四重护栏，确保演示先验永远不能覆盖实时证据。

### IP-161 DEC（演示证据编译）

```python
class DemoEvidenceCompiler:
    def __init__(self, alpha=0.05, gamma=0.2, min_segs=5):
        self.alpha, self.gamma, self.min_segs = alpha, gamma, min_segs

    def compile(self, demos):
        library = {}
        for mode, segs in self.segment_by_mode(demos).items():
            succ = [s for s in segs if s.outcome == 'success']
            if len(succ) < self.min_segs:
                continue
            margins = np.array([self.margin(s) for s in succ])
            m_safe = np.quantile(margins, self.alpha) / (1 + self.gamma)
            K_lo, K_hi = self.impedance_envelope(succ)
            library[mode] = DemoContract(
                pre=self.preconditions(succ),
                inv=self.extract_invariants(succ),
                post=self.postconditions(succ),
                margin=m_safe,
                K_env=(K_lo, K_hi),
                support=self.support_estimate(succ),
            )
        return library
```

### IP-162 GCMG（抓取接触模态图）

```python
class GraspContactModeGraph:
    MODES = ['approach', 'contact', 'force_closure',
             'lift', 'transport', 'place', 'release', 'safe_hold']

    def __init__(self, contracts, tau_Q=0.3, tau_slip=0.01):
        self.contracts = contracts
        self.tau_Q, self.tau_slip = tau_Q, tau_slip
        self.edges = self._build_guarded_edges()

    def advance(self, mode, ev):
        for e in self.edges[mode]:
            verdict = e.guard(ev)              # go / hold / abort
            if verdict == 'go':
                return e.next_mode, e.handover_cert(ev)
            if verdict == 'abort':
                return 'safe_hold', None
        return 'safe_hold', None               # 证据不足，保守停留

    def guard_contact_to_closure(self, ev):
        in_cone = (ev.wrench @ ev.normal
                   >= np.cos(np.arctan(ev.mu)) * np.linalg.norm(ev.wrench))
        Q = min(ev.mu * ev.f_n - abs(ev.f_t)) / max(ev.mu * ev.f_n, 1e-6)
        return 'go' if (in_cone and Q >= self.tau_Q
                        and ev.slip_v <= self.tau_slip) else 'hold'
```

### IP-163 DCR（演示胜任域）

```python
class DemoCompetenceRegion:
    def __init__(self, demos, k=10, h=0.2, tau_c=0.6, alpha_ood=0.05):
        self.X = np.array([d.task_vector for d in demos])
        self.tree = KDTree(self.X)
        self.k, self.h = k, h
        self.tau_c, self.alpha_ood = tau_c, alpha_ood
        self.kde_max = self.kde(self.X).max()

    def competence(self, theta):
        d, _ = self.tree.query(theta, k=min(self.k, len(self.X)))
        return float(np.exp(-np.mean(np.atleast_1d(d)) / self.h)
                     * self.kde(theta) / self.kde_max)

    def conformal_pvalue(self, theta):
        d_theta, _ = self.tree.query(theta)
        dists, _ = self.tree.query(self.X)
        return (1 + np.sum(dists <= d_theta)) / (len(self.X) + 1)

    def certified(self, theta):
        return (self.competence(theta) >= self.tau_c
                and self.conformal_pvalue(theta) >= self.alpha_ood)
```

### IP-165 DECC + IP-166 TCF（一致性否决与信任校准）

```python
class DemoExecutionConsistency:
    def __init__(self, tau_d=3.0, sigma_dec=1.0):
        self.tau_d, self.sigma_dec = tau_d, sigma_dec

    def distance(self, ev, sigma, mode):
        mu, Sigma_inv = sigma.manifold[mode]
        return float(np.sqrt((ev.z - mu) @ Sigma_inv @ (ev.z - mu)))

    def consistent(self, ev, sigma, mode):
        return (self.distance(ev, sigma, mode) <= self.tau_d
                and sigma.invariants_satisfied(mode, ev))

    def update_trust(self, t, ev, sigma, mode):
        d = self.distance(ev, sigma, mode)
        log_lik = -0.5 * (d / self.sigma_dec) ** 2
        prior = np.log(t / (1 - t + 1e-9))
        return float(np.clip(1 / (1 + np.exp(-(prior + log_lik))),
                             1e-3, 1 - 1e-3))
```

### IP-167 DGGL（演示接地抓取闭环）

```python
def demo_grounded_grasp_loop(M, obj, task):
    scene = M.scene_model.update(M.telem_force, M.telem_pos)
    sigma = M.skill_lib.retrieve(obj, scene, task)

    if not M.dcr.certified(task.theta) or sigma.trust < M.tau_trust:
        return M.probe_or_teleop(obj, task)

    K = M.eeis.compile_with_demo_prior(sigma.contracts, task.delta_f)
    M.ertc.load_contract(sigma.contracts)
    mode, log = sigma.gcmg.start, []
    while mode not in ('release', 'safe_hold'):
        ev = M.execute_mode(mode, K[mode])
        log.append(ev)
        if not M.decc.consistent(ev, sigma, mode):
            M.trust.decay(sigma, ev)
            M.safe_hold()
            return M.recertify(sigma, ev)
        nxt, handover = sigma.gcmg.advance(mode, ev)
        if handover:
            M.ertc.handover(handover)
        mode = nxt
    M.trust.update(sigma, log)
    M.epir.append(build_ev_exec(log))
    return M, log, sigma.trust
```

class DemoGraspBudget:
    def __init__(self, demo_budget, grasp_budget):
        self.B_demo = demo_budget     # retrieve/align/perturb/replay

def demo_cost(action):

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| DEC | O(M·T + M log M) 离线 | O(M·d) | 域内不变量违反率 ≤ α+β |
| GCMG | O(deg)/切换 | O(\|E\|) | 切换安全 ≥ 1−β |
| DCR | O(log M) 查询 | O(M) | 保形 OOD 有效，域外不认证 |
| DECC | O(d)/模态 | O(1) | 一周期内冻结 |
| TCF | O(1) | O(1) | ECE ≤ ε，部署风险 ≤ ε |
| DGGL | O(#modes·(exec+d)) | 复用 | 冷启动成本显著下降 |

**正确性定理（DGGC）**：若 A66–A71 成立，则：
1. θ∈Θ_cert 时，新抓取不变量违反概率 ≤ α+β；
2. θ∉Θ_cert 时不允许认证部署，风险由试探策略显式承担；
3. 执行脱离演示流形时，DECC 在一个控制周期内冻结，演示先验无法造成无界伤害；
4. 部署阈值使 P(unsafe | t_σ ≥ τ_t) ≤ ε；
5. 任一 B_demo/B_grasp 耗尽触发对应保守降级。

**证明直觉**：DEC 用保形分位数把「经验裕度」转成「分布无关下界」（A66 保证可交换），GCMG 把「全过程安全」分解为「逐模态不变量 × 逐边守卫」（A67 保证守卫是充分统计量）；DCR 把「先验可信」限制在支撑内（A68）；DECC 提供在线反例，打破「演示=真理」的错误等价（A69）；TCF 用似然把在线证据折算成信任（A70）。四者共同把「演示成功」与「执行安全」解耦。

## 5. 本轮最大风险

**一句话**：演示数据天然带幸存者偏差与极窄分布，若把「人类成功过」直接当作「机器人安全」，DEC 会把错误先验认证成高置信契约，在分布外造成「证据层高度确定、执行层灾难性失效」；必须以「扰动负样本+保形 α」「DCR 域外拒绝」「DECC 在线一票否决」「TCF 信任门控」四重护栏，确保演示先验永远不能覆盖实时证据。
