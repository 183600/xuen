# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「力觉传感」×「流匹配策略」）

> R69 把不确定性一分为二：aleatoric 收紧，epistemic 交给「流匹配多模态策略 + 主动看/问/触」去消解。它把信息动作写成 `g ∈ {注视, 探针, 问句}`，用 `VoI(g) = H(M|o) − E[H(M|o,y)]` 选动作，再用 `risk(g) ≤ ε_int` 兜底。但这套写法默认了一件从未被检验的事：**测量是「读」，不是「写」**——探针读完，世界还是原来的世界。
>
> 力觉传感把这个默认击穿了。接触不是观测，是**干预**：你不施力就测不到刚度；你施力，接触状态就可能从 stick 跳到 slip、从 elastic 跳到 plastic、从完好跳到破裂。**为了知道答案而施加的力，会改变答案本身。** 这是 R69 的 `VoI`（Pearl 因果阶梯第一层）与 `ε_int`（一个与状态无关的常数包络）同时失效的地方。
>
> 流匹配策略则暴露出第二个隐患：R69 的 rectified flow 用**光滑速度场**生成动作，而接触事件（碰、滑、脱、断）在力轨迹上近似**跳变**。光滑流场会把跳变「抹平」——采样出的是温柔的、平均化的接触，恰好系统性低估滑移与冲击；**多模态分布不是被保留了，而是被平滑成了一个不存在的折中模态**。
>
> 核心命题：**把接触显式建模为 `do(g)`——用介入式信息价值（IVoI）替代观测式 VoI，用「可逆接触集 + 介入式控制屏障 + 力随不确定性降额」替代常数安全包络；用「连续力轨迹 + 离散接触模态」的跳流（jump flow）替代光滑流，使接触事件不被抹平；用「物理挑战-响应」把力通道升级为不可廉价伪造的接触见证。** 命名 **FORCE-RAS**（Flow-matching, Observational–interventional gap, Risk-constrained Contact Exploration）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我这一问，会不会把被问的东西改掉？我还能不能收得回来？**」——在接触里，提问本身就是一次不可完全撤回的写入。

## 0. 直觉与动机

**灵感 1（力觉传感：接触是干预，不是观测）**
直觉：隔着一层海绵摸不出软硬，必须压下去；想知道杯子滑不滑，得让它受一点切向力；想知道果皮会不会破，最诚实的测法是……把它压破——而那就不是「测」了，是「毁」。所以接触信息天然分成两类：**可逆探询**（弹性形变、微滑未发生、能量可回收）与**不可逆探询**（塑性、宏观滑移、断裂）。R69 的 `g_probe` 只写了「方向 + 力度 ≤ f_max」，把这两类混在一起，用一个静态 `ε_int` 兜底，这是本轮要拆开的第一个范畴错误。

**灵感 2（流匹配策略：光滑流场会消灭接触事件）**
直觉：rectified flow 学的是「从噪声到动作」的速度场，本质是一个连续 ODE。接触物理是**分段光滑 + 事件驱动**的：自由空间、接触、黏着、滑移、脱离、断裂，每一段内部光滑，段与段之间是跳。用单一光滑场拟合，最优解就是各段的加权平均——于是「抓稳」和「滑落」两个真模态之间会被填进一个「半滑不滑」的幻觉模态。生成模型越强，越会自信地生成这个不存在的中间态。正确表示不是更多采样步数，而是**混合系统**：连续段用流，模态切换用强度 + guard 的跳过程。

**灵感 3（介入式信息价值：R69 的 VoI 是 U_do=0 的退化）**
直觉：R69 算的是「如果我能看到 y，我对 M 会确定多少」，这是 `I(M;Y|g)`。但在接触里，y 是在 `do(g)` 之后才产生的，而且 `do(g)` 还顺手改了 M 相关状态。正确量是因果信息增益 `I(M;Y|do(g))`，再减掉**干预代价**：副作用的不确定度 `U_do`（你越不了解物体，你越不知道这一下会把它怎样）与尾部伤害风险 `R_do`。当 `do(g)=observe(g)`（看/问、非接触）时，`U_do=R_do=0`，公式逐项退回 R69——**R69 不是被推翻，而是「探询不改变世界」这一理想边界**。

**灵感 4（力是物理见证：不可廉价伪造的独立通道）**
直觉：R69 的「k 个正交源一致」在力觉上第一次可以做到**物理级独立**：其他通道（视觉、语言）可以被重放、被合成、被社交工程，但一个真实物体的**反作用力**必须遵守无源性（不能凭空输出能量）、互易性（Y_ij=Y_ji）和能量守恒。于是可以主动做一次**物理挑战-响应**：施加一段已知随机相位的小抖动，测闭环响应，检查无源/互易/能量残差。**重放的力信号无法对一个新的 nonce 作出正确的闭环响应；伪造的力信号会违反无源性。** 力因此不只是「又一个传感器」，而是一个能把「看起来对」升级成「物理上对」的见证。

**灵感 5（不确定性感知的安全：越不确定，越要轻）**
直觉：R68 的铁律是「不确定 → 收紧」。在接触里「收紧」有精确物理含义：**力上限应随接触参数的后验方差下降**。不知道物体多硬，就不要用可能压碎它的力去测它多硬；这既安全，也更可能保留下一次测量的机会。把 `f_max(θ̂) = f_nom − β·σ(θ̂)` 做成硬约束，并配合可逆集与 I-CBF，本轮的「保守」不再是一个标量 λ，而是**一条随知识增长的力包络**。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（FORCE-RAS 总览）** FORCE-RAS = (JFMP, CID, IVoI, PCR, I-CBF/RBG, CMCG, CRG, VQAuditor-C, RAS-WM†)。五条不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **介入语义**：一切接触信息动作建模为 `do(g)`，信息价值在干预分布上计算，绝不以观测分布冒充；
(iii) **可逆性**：信息动作必须落在可逆接触集 `ℛ` 内；不可逆状态改变只能作为带任务级授权的任务动作，**永不以「查询」名义发生**；
(iv) **物理见证**：力通道证据只有在物理挑战-响应通过后才进入法定人数；
(v) **证据纪律**（继承 R69 定义 293-iii）：单源/单次交互不得定案，且要求源在因果上独立（定义 320）。

**定义 311（增广动作与接触通道）** 任务动作 `a = (a_task, a_wrench)`，`a_wrench = (f*, K_d, τ_f)` 为力设定、阻抗与力矩前馈。信息动作 `g = (g_gaze, g_contact, g_ask)`，其中 `g_contact = (n, f_d, T_d)` 为抖动方向、幅值与时长。增广动作 `ξ = (a, g) ∈ 𝒜_+`。关键：`a_wrench` 同时是**动作**与**观测量**的来源——这是接触的双向性，也是 R69 动作空间未显式编码的。

**定义 312（接触模态与跳流 JFMP）** 接触模态 `c ∈ 𝒞 = {free, approach, stick, slip, elastic, plastic, fracture}`。JFMP 是一个分段确定马尔可夫过程（PDMP）：
- 段内：`dx/ds = v_θ(x, s, c | o_t)`（连续力/位姿轨迹）；
- 切换：`c → c'` 的强度 `λ_{cc'}(x, s | o_t)`，跳核 `J_{cc'}(· | x)`；
- 事件面：guard `Γ_{cc'}(x)=0`。

训练目标 `L_JFMP = L_FM + L_mode + L_int + L_jump`：`L_FM` 为段内流匹配，`L_mode` 为接触模态交叉熵（事件由力信号自监督分割，少量标注校准），`L_int` 为 Poisson 强度负对数似然（时间逆变换），`L_jump` 为跳幅回归。采样用 thinning + Heun，`E[#events] ≤ 2`。问句解码仍由冻结 LLM 完成（继承 R69 定义 295，梯度不回传语言模型）。

**定义 313（接触参数与可辨识性）** 接触参数 `θ_c = (μ, k, b, m_eff, f_slip, E_strain, …)`，力观测 `y_w = h(θ_c, a_wrench, s) + ε`。探针 `g` 的 Fisher 信息 `ℐ_F(θ_c; g)`；定义**可辨识度** `ρ_id(g) = rank_eff(ℐ_F)/dim(θ_c)`。关键事实：纯法向静态探针对切向摩擦/滑移块的 Fisher 信息秩亏——**再安全的法向探询也测不出摩擦**；要辨识 μ 必须做切向动态激励（有滑移风险），否则只能借助视觉/语言或保持保守。

**定义 314（不确定性三分）** `U_ale = E[tr Σ_noise]`（力/触觉噪声，不可约）；`U_epi = H(c|o) · sep_factor + H(θ_c|o)`（接触模态与参数歧义，可约）；`U_do(g) = Var_{θ_c~p(·|o)}[ΔS(g, θ_c)]`（**内生不确定性**：由于不了解物体，这一下探询会把世界改成什么样是不确定的；它不是「信息」，而是「风险溢价」）。三者语义不同，不简单相加；`R_do(g) = CVaR_α[ℓ_damage(S')]` 为尾部伤害风险。

**定义 315（介入式信息价值 IVoI）**
`IVoI(g) = I(M; Y | do(g), o) − λ_do·U_do(g) − λ_r·R_do(g) − c_phys(g) − c_soc(g)`。
选择 `g* = argmax_g IVoI(g)`，s.t. `g ∈ ℛ`（定义 316）、I-CBF 认证（定义 317）、预算未超。`IVoI(g*) ≤ 0` 则不探询。当 `p(y|do(g),o)=p(y|g,o)` 且 `U_do=R_do=0`（非接触的看/问），`IVoI` 逐项等于 R69 的 `VoI`——**这是本轮的理论锚点：R69 是「探询不改变世界」的边界情形**。

**定义 316（可逆接触集与不可逆预算 RBG）** 接触轨迹可逆，当且仅当：形变弹性可恢复、无超过 `δ_s` 的宏观滑移、无断裂、终止位姿在容差内。不可逆度 `I(g) = P(fracture) + E[plastic_strain]/ε_p + E[slip_dist]/δ_s`。信息动作要求 **`I(g)=0` 严格成立**；不可逆改变必须走任务动作并显式分配风险预算 `B_irr`。一句话：**永远不要用一种会永久改变答案的力去问答案。**

**定义 317（介入式控制屏障 I-CBF 与力降额）** 安全集 `𝒮 = {s : h_j(s) ≥ 0}`（力/能量/无滑移裕度）。对 `do(g)` 要求离散 CBF：`h_j(s') ≥ (1−γ)h_j(s)`。力包络随认知收紧：
`f_max(θ̂) = f_nom − β·σ(θ̂) − β_g·gap_t`，
其中 `gap_t` 为接触现实差距（定义 325）。越不确定 → 力越小；这既是安全约束，也是保留未来可测性的策略。

**定义 318（物理挑战-响应 PCR）** 生成随机 nonce，施加已知谱的小抖动 `δf(t)`，测闭环响应 `δy(t)`，在线辨识导纳 `Ŷ(ω)`。见证分：
`W_c = σ(a − b·r_pass − c·r_recip − d·r_nonce)`，
其中 `r_pass` 为无源性残差（`Re Ŷ ≥ −ε`）、`r_recip` 为互易性残差、`r_nonce` 为对 nonce 的闭环响应残差。重放/注入无真实被控对象时无法同时满足三者；柔顺掩盖（软垫藏硬物）会在高频段暴露导纳异常。`W_c` 是「物理在场」的证书，不是「物体身份」的证书。

**定义 319（接触模态校准门 CMCG）** 校准 `p(c|o)`、力噪声与 IVoI 分位；`ECE_c` 越界（>`τ_ece`）则禁用接触信息动作，退回 R69 的非接触交互（看/问）或纯保守。这是 R69 定义 306（MCG）在接触通道上的镜像。

**定义 320（因果独立证据与法定人数）** 见证 `W = {force, vision, language, proprio}`。`i,j` 因果独立，当且仅当给定共同原因（同一次接触事件/同一接触参数）后其误差项 d-分离。法定人数要求 `k` 个**因果独立**源一致：`force` 与 `proprio` 通常共享接触事件这个共同原因，只算一个；`force` 可以验证 `vision/language`，但不能与它们合成虚假的多数。

**定义 321（三级降级级联）** L0：完整 FORCE（接触探询 + 物理见证）；L1：禁用接触探询、保留 R69 的看/问（逐指令 R69）；L2：全交互关闭、纯保守（逐指令 R68）。触发：CMCG 越界 / PCR 失败 / `B_irr` 耗尽 / CRG 告警 / 力饱和。

**定义 322（威胁模型 AIC-FORCE）** `ℰ_FORCE = ℰ_FLUID × ℰ_contact`。`ℰ_contact`：力信号注入/重放、柔顺掩盖（软垫藏硬物）、滑移陷阱（诱导探针制造宏观滑移）、力饱和/削顶、对抗纹理（改变触觉摩擦读数）、遥操作冒充、仿真-现实接触伪影。

**定义 323（证书 J_FORCE）** `J_FORCE = (J_FLUID, contact_mode_ece, IVoI_ratio, reversibility_margin, passivity_residual, intervention_cost, contact_witness_digest, sim2real_gap, force_ver)`。Valid ⇔ `Valid(J_FLUID)` ∧ CMCG 通过 ∧ 可逆性不变式 ∧ PCR 见证 ∧ 降级级联未被触发。

**定义 324（参与式审计 VQAuditor-C）** 审计对象新增：该次接触查询是否可逆、力证据是否被单源采纳、PCR 是否有效、干预副作用是否被低估、是否存在「本可以问/看却选择压」的越界。结论回灌 `AuditBuf`，成为下一轮 `IVoI` 的 `U_do/R_do` 先验。

**定义 325（接触现实差距监控 CRG）** 用 PCR 的实测响应与学习接触模型的预测响应之差估计 `gap_t`。`gap_t` 大 ⇒ 膨胀 `U_do`、收缩 `ℛ`、下调 `f_max`；超过阈值直接禁用 `IVoI`（因为此时「干预后果」的因果模型本身不可信）。CRG 是对本轮最大风险（因果模型循环依赖）的唯一在线止血阀。

**定义 326（总体目标与严格包含）** 策略优化
`max_π E[U_task − λ_risk·Risk − λ_do·U_do − λ_r·R_do − c_int − c_irr]`，
s.t. 定义 310 的五条不变式。当 `do(g)=observe(g)`、`U_do=R_do=0`、`gap_t=0` 时，目标与 R69 逐项一致；当接触探询被禁用时，整个闭环逐指令退化为 R69。

```python
# IP-264 JFMP：连续力轨迹 + 离散接触模态的跳流
class JumpFlowPolicy:
    def __init__(self, trunk, v_net, jump_head, intensity_head, guard, llm):
        self.trunk, self.v = trunk, v_net
        self.jump, self.inten, self.guard = jump_head, intensity_head, guard
        self.llm = llm                        # 冻结，仅解码问句

    def sample(self, o_t, K=1, N_step=2):
        z = self.trunk(o_t)
        xs = randn(K, D)
        cs = self.mode_prior(z, K)            # 每样本的接触模态初值
        events = []
        for i in range(N_step):
            s = i / N_step
            for k in range(K):
                # 事件检测：guard 过零 + 强度 thinning
                c_next, t_jump = self.thinning(cs[k], xs[k], s, z, self.inten)
                xs[k] = xs[k] + (1.0/N_step) * self.v(xs[k], s, cs[k], z)
                if c_next != cs[k]:
                    xs[k] = self.jump(xs[k], cs[k], c_next, z)
                    events.append((k, t_jump, cs[k], c_next))
                    cs[k] = c_next
        return [self.decode(x) for x in xs], events

# IP-265 CID：不确定性三分（ale / epi / do）
def decompose(samples, events, z):
    modes = cluster_trajectories(samples)          # 连续动作模态
    cpost = contact_mode_posterior(events, z)      # p(c|o)，来自跳流事件
    U_ale = sensor_noise_trace(z)
    U_epi = entropy(cpost) * sep_factor(modes) + param_entropy(z)
    return U_ale, U_epi, cpost, modes              # U_do 在 IVoI 内按 g 现算

# IP-266 IVoI：do(g) 而非 g，且只在可逆集内
def interventional_voi(modes, cpost, o, budget, crg):
    best = None
    for g in contact_candidates(modes):
        if not budget.allow(g):                       continue
        if not reversible(g, cpost, crg):             continue   # 定义 316
        if not i_cbf.certify(g, o, crg):              continue   # 定义 317
        info  = mutual_info_do(modes, g, o)                       # I(M;Y|do(g))
        u_do  = endogenous_dispersion(g, cpost)                   # 定义 314
        risk  = cvar_damage(g, cpost, crg)                        # 尾部伤害
        score = info - LAM_DO*u_do - LAM_R*risk - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None              # 无利可图 → R69

# IP-267 PCR：物理挑战-响应见证（力内环 1kHz，决策层用 20ms 窗摊销）
def passivity_witness(force_loop, o, nonce):
    f_chirp = dither(nonce)                     # 已知谱、随机相位
    y       = force_loop.excite_and_measure(f_chirp)
    Y_hat   = identify_admittance(f_chirp, y)
    return witness_score(passivity_residual(Y_hat),
                         reciprocity_residual(Y_hat),
                         nonce_response_residual(y, nonce))

# IP-274 主闭环（继承 R69，在不确定性处置处替换为介入语义）
def FORCE_RAS_round(M, obs):
    z, o = M.mtm.forward(...)
    c, U_cal, thr = M.cof.step(...)                       # R68 标定
    K = 1 if M.jfmp.mode_head(z) < TAU_MODE else 4
    samples, events = M.jfmp.sample(o, K)                 # 跳流，保留接触事件
    U_ale, U_epi, cpost, modes = M.cid.decompose(samples, events, z)
    # 物理见证 + 接触现实差距
    W   = M.pcr.passivity_witness(M.force_loop, o, M.nonce())
    gap = M.crg.update(W, M.force_loop.last_response)
    # 只有校准可信、见证可信、差距可控时才允许接触探询
    g = None
    if (not M.cmcg.blocked(cpost)) and (W >= TAU_W) and (not M.crg.alarm(gap)):
        g = M.ivoi.choose(modes, cpost, o, M.budget, M.crg)
    if g is not None:
        f_cap = M.icbf.derate(cpost, gap)                 # 越不确定力越小
        ans   = M.contact.execute(g, f_cap, force_loop=M.force_loop)  # 可逆集内
        U_epi_after = M.cid.update(modes, ans, W)
    else:
        U_epi_after = U_epi
    # 风险缩放：仅未消解的 epistemic 进入 R68 兜底
    U_floor = U_ale + (U_epi_after if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if M.crg.alarm(gap) or W < TAU_W:                     # 不可信 → 退回 R68 最保守
        lam = max(lam, 0.8); g = None
    k = M.c_ras_wm.certified_prefix(...)
    mode = select_mode(modes, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vq_c.submit_async(g, W, gap, U_do, U_epi_after)     # 参与式审计
    return k, lam, mode, (U_ale, U_epi_after, W, gap)
```

## 3. 推导

**引理 19（观测式 VoI 的介入偏差）** 设 `p_g(y)=p(y|g,o)`、`p_do(g)(y)=p(y|do(g),o)`，二者总变差为 `ε_g`。则
`|I(M;Y|g) − I(M;Y|do(g))| ≤ 2ε_g log|𝒴| + h_2(ε_g)`，
而 R69 决策忽略了 `−λ_do U_do − λ_r R_do`。故当 `ε_g` 或 `U_do/R_do` 不可忽略时，R69 会**系统性地高估接触探询的价值**，选择「看起来信息量大、实际在改变世界」的动作。系：接触越软、越接近滑移边界，偏差越大——**越需要小心的探询，越容易被观测式 VoI 高估**。

**引理 20（接触参数的可辨识性下界）** 纯法向静态探针的 Fisher 信息在切向块为零（`ℐ_F^{ττ}=0`），因此 `ρ_id` 上界由法向块秩决定；摩擦/滑移参数 `μ, f_slip` 在任何 `I(g)=0` 的探针下不可辨识。系：**存在「安全但信息为空」的探询**——此时 `IVoI ≤ 0` 是正确结论，系统应转向视觉/语言或保守，而不是加大法向力（那只会增加 `R_do`，不增加关于 μ 的信息）。

**引理 21（光滑流场对接触事件的抹平）** 设真实轨迹在 `s*` 处有跳幅 `Δ`，速度场 `L`-Lipschitz，`N` 步积分。光滑流在事件附近的最小逼近误差 `≥ Δ/2 − O(L/N)`，事件时刻被量化到 `O(1/N)`；跳流用强度 `λ` 与精确 thinning 表示事件，事件时刻无量化偏差，强度估计误差 `O(N^{-1/2})`。故：**在接触任务上，增加 N 不能消除模态抹平；必须换表示（跳流），否则滑移/冲击模态会被系统性低估**——这直接解释 R69 的 FMP 为何在接触丰富场景会「只会温柔地碰」。

**引理 22（PCR 的重放不可伪造性）** 在无源性与互易性约束下，无真实被控对象的攻击者对一个新鲜 nonce 的闭环响应，其能量残差分布与实际响应至少相隔 `δ_e`；用 `T` 时长激励，误接受概率 `≤ exp(−T·KL(ν_attack ‖ ν_real))`。柔顺掩盖攻击改变高频导纳，在带宽足够时 `r_pass` 可检。系：**力通道的独立性来自物理定律，而不是来自硬件多样性**；但 PCR 只证明「接触是真的」，不证明「物体就是你以为的那个」。

**定理 18（FORCE 严格包含 R69）** 当只使用非接触信息动作（看/问）时 `do(g)=observe(g)`、`U_do=R_do=0`，`ℛ` 与 I-CBF 不激活，FORCE 的决策与 R69 逐指令相同；当接触探询被 CMCG/PCR/CRG 禁用时，闭环逐指令退化为 R69。且由于可逆集约束严格强于 R69 的常数 `ε_int`、力包络 `f_max ≤ f_nom`，安全侧不做任何让步；效率侧仅从**可逆、物理见证通过**的探询获得 resolution bonus。

**定理 19（接触信息动作的安全与无不可逆损害）** 在 I-CBF（定义 317）与可逆性不变式（定义 316）下，任何信息动作的瞬时不可逆损害概率 `≤ δ_cert`，整段累计 `≤ B_irr`；力设定在模态切换处以 CBF 滤波后的连续插值下发，故控制连续、无突变；探询失败/超时/见证失败时 `λ` 单调不降地退化为 R69/R68。

**定理 20（接触投毒的采纳上界）** 单源采纳力证据的错误率 `≥ δ_p`；采用「PCR 见证 + 因果独立法定人数 `k`」后，错误率 `≤ δ_p·ρ^{k−1} + ε_PCR + ε_gap`，其中 `ε_gap` 由 CRG 给出。若 `gap_t` 越界则 `IVoI` 被禁用、退回保守，故**最坏情况不劣于「从不接触探询」**。

## 6. 本轮最大风险

**一句话**：FORCE-RAS 的全部安全性押在「可逆集 `ℛ` 与介入后果 `U_do` 的因果模型是可信的」这一前提上，而**接触模型恰恰是它想通过探询去改进的东西**——这是一个循环：要算 `IVoI(g)` 必须先知道 `do(g)` 会把世界怎样；要降低这个未知又只能去做 `do(g)`。若模型把不可逆接触误判为可逆（未知材料、仿真-现实差距、力传感器饱和），系统就会在「安全探询」的名义下做出不可撤销的破坏——**它不是在用错误的信念提问，而是在用错误的信念动手**。

**次级风险与缓解**：
1. **因果循环（`IVoI` 依赖它要改进的模型）** → CRG 在线估计接触差距，差距大即收缩 `ℛ`、膨胀 `U_do`、禁用 `IVoI`；最坏退回「从不接触探询」；
2. **可逆性误判** → 保守下界 + 力随方差降额（`f_max`）+ 不可逆预算硬约束 `B_irr`；
3. **跳流训练不稳（事件强度/跳核难学）** → 事件由力信号自监督分割 + 少量标注 + 强度用时间逆变换训练；失败即退回 R69 的连续流（但会损失滑移模态）；
4. **PCR 被真实但恶意的接触欺骗（如滑移陷阱）** → PCR 只证明物理在场，不证明善意；用 I-CBF + 可逆集 + 定理 20 的采纳上界兜底；
5. **多速率工程复杂度** → 力内环复用 R68 低层执行器，策略层只做 20ms 摊销决策，严格分离安全关键路径与非关键路径。

## 2. 形式化定义（要点版）

**定义 310（总览与五不变式）** 实时零学习写（继承）；介入语义（接触信息动作一律 `do(g)`）；可逆性（信息动作 `I(g)=0`，不可逆只走任务授权）；物理见证（力证据须过 PCR）；因果独立证据纪律（继承 R69 并升级）。

**定义 311–312（增广动作与 JFMP）** `ξ=(a_wrench,g_contact)`；JFMP 为 PDMP：段内 `dx/ds=v_θ(x,s,c|o)`，切换强度 `λ_{cc'}`、跳核 `J_{cc'}`、guard `Γ_{cc'}=0`；训练 `L_FM+L_mode+L_int+L_jump`；thinning+Heun 采样，`E[#events]≤2`。事件标签由力信号自监督分割。

**定义 313（可辨识性）** `θ_c` 的 Fisher 信息秩决定 `ρ_id`。纯法向静态探针对切向摩擦/滑移块秩亏——**存在「安全但信息为空」的探询**，此时正确结论是 `IVoI≤0` 并转向视觉/语言或保守，而不是加大法向力。

**定义 314–315（三分与 IVoI）** `U_do(g)=Var_{θ_c}[ΔS(g,θ_c)]` 是「询问本身会怎样改世界」的不确定性；`R_do` 为尾部伤害。`IVoI(g)=I(M;Y|do(g))−λ_do U_do−λ_r R_do−c`，在 `ℛ`、I-CBF、预算约束下取 max；`≤0` 不探询。`do(g)=observe(g) ∧ U_do=R_do=0` 时逐项退回 R69 VoI。

**定义 316–317（可逆集与介入安全）** 可逆 = 弹性可恢复 ∧ 无宏观滑移 ∧ 无断裂 ∧ 终止位姿在容差内；不可逆度 `I(g)`，信息动作要求 `I(g)=0`，总不可逆预算 `B_irr`。I-CBF：`h_j(s')≥(1−γ)h_j(s)`；力包络随后验方差与 `gap_t` 收缩（`f_max=f_nom−βσ−β_g gap`）——**越不确定，越轻**。

**定义 318（PCR）** 随机 nonce → 已知谱抖动 → 辨识导纳 `Ŷ(ω)` → 无源/互易/nonce 残差 → `W_c`。重放/注入无法对一个新鲜 nonce 给出正确闭环响应；柔顺掩盖在高频段暴露。PCR 证明「物理在场」，不证明「物体身份」或「善意」。

**定义 319–321（门控、因果独立、降级）** CMCG 校准 `p(c|o)` 与力噪声，越界即禁用接触探询；法定人数要求误差项在共同接触事件下 d-分离，力与本体感受通常只算一个证人；三级降级 L0→L1(R69)→L2(R68)，触发条件为 CMCG/PCR/`B_irr`/CRG/力饱和。

**定义 322–325（威胁、证书、审计、CRG）** `ℰ_FORCE=ℰ_FLUID×ℰ_contact`；`J_FORCE` 新增接触校准、IVoI 比、可逆裕度、无源残差、干预成本、sim2real 差距；VQAuditor-C 审计「是否本可以看/问却选择压」；CRG 用 PCR 实测与接触模型预测之差在线估计 `gap_t`，差距大即收缩 `ℛ`、禁用 IVoI。

**定义 326（总体目标与严格包含）** `max_π E[U_task−λ_risk Risk−λ_do U_do−λ_r R_do−c_int−c_irr]`，s.t. 五不变式；`do=observe ∧ U_do=R_do=0 ∧ gap=0` 时与 R69 逐项一致。

## 3. 关键算法伪代码

```python
# IP-264 JFMP：连续力轨迹 + 离散接触模态的跳流
class JumpFlowPolicy:
    def sample(self, o_t, K=1, N_step=2):
        z, xs, cs = self.trunk(o_t), randn(K, D), self.mode_prior(z, K)
        events = []
        for i in range(N_step):
            s = i / N_step
            for k in range(K):
                c_next, t_jump = self.thinning(cs[k], xs[k], s, z, self.inten)
                xs[k] = xs[k] + (1.0/N_step) * self.v(xs[k], s, cs[k], z)
                if c_next != cs[k]:
                    xs[k] = self.jump(xs[k], cs[k], c_next, z)
                    events.append((k, t_jump, cs[k], c_next)); cs[k] = c_next
        return [self.decode(x) for x in xs], events      # ξ=(a,g)，保留接触事件

# IP-265 CID：不确定性三分（U_do 在 IVoI 内按 g 现算）
def decompose(samples, events, z):
    modes = cluster_trajectories(samples)
    cpost = contact_mode_posterior(events, z)
    U_ale = sensor_noise_trace(z)
    U_epi = entropy(cpost) * sep_factor(modes) + param_entropy(z)
    return U_ale, U_epi, cpost, modes

# IP-266 IVoI：do(g) 而非 g，只在可逆集 + I-CBF 内
def interventional_voi(modes, cpost, o, budget, crg):
    best = None
    for g in contact_candidates(modes):
        if not budget.allow(g):                    continue
        if not reversible(g, cpost, crg):          continue   # 定义 316
        if not i_cbf.certify(g, o, crg):           continue   # 定义 317
        info  = mutual_info_do(modes, g, o)                   # I(M;Y|do(g))
        u_do  = endogenous_dispersion(g, cpost)               # 定义 314
        risk  = cvar_damage(g, cpost, crg)
        score = info - LAM_DO*u_do - LAM_R*risk - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None          # 无利可图 → R69

# IP-267 PCR：物理挑战-响应（力内环 1kHz，决策层 20ms 摊销）
def passivity_witness(force_loop, o, nonce):
    f_chirp = dither(nonce)
    y = force_loop.excite_and_measure(f_chirp)
    Y_hat = identify_admittance(f_chirp, y)
    return witness_score(passivity_residual(Y_hat),
                         reciprocity_residual(Y_hat),
                         nonce_response_residual(y, nonce))

# IP-274 主闭环（继承 R69）
def FORCE_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.jfmp.mode_head(z) < TAU_MODE else 4
    samples, events = M.jfmp.sample(o, K)
    U_ale, U_epi, cpost, modes = M.cid.decompose(samples, events, z)
    W   = M.pcr.passivity_witness(M.force_loop, o, M.nonce())
    gap = M.crg.update(W, M.force_loop.last_response)
    g = None
    if (not M.cmcg.blocked(cpost)) and (W >= TAU_W) and (not M.crg.alarm(gap)):
        g = M.ivoi.choose(modes, cpost, o, M.budget, M.crg)
    if g is not None:
        f_cap = M.icbf.derate(cpost, gap)         # 越不确定力越小
        ans   = M.contact.execute(g, f_cap, force_loop=M.force_loop)
        U_epi = M.cid.update(modes, ans, W)
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if M.crg.alarm(gap) or W < TAU_W: lam = max(lam, 0.8); g = None
    k = M.c_ras_wm.certified_prefix(...)
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vq_c.submit_async(g, W, gap, U_do, U_epi)
    return k, lam, mode, (U_ale, U_epi, W, gap)
```

## 4. 推导

**引理 19（观测式 VoI 的介入偏差）** `|I(M;Y|g)−I(M;Y|do(g))| ≤ 2ε_g log|𝒴|+h_2(ε_g)`，且 R69 忽略 `−λ_do U_do−λ_r R_do`。故接触越软、越接近滑移边界，R69 越会高估探询价值——**越需要小心的探询，越容易被观测式 VoI 高估**。

**引理 20（可辨识性下界）** 纯法向静态探针的切向 Fisher 块为零，`μ,f_slip` 在任何 `I(g)=0` 的探针下不可辨识。系：存在「安全但信息为空」的探询，此时应转向视觉/语言/保守，而非加大法向力。

**引理 21（光滑流对接触事件的抹平）** 跳幅 `Δ`、`L`-Lipschitz、`N` 步下，光滑流的事件附近误差 `≥Δ/2−O(L/N)`，事件时刻量化到 `O(1/N)`；跳流用精确 thinning，事件无量化偏差、强度误差 `O(N^{-1/2})`。故增加采样步数不能消除模态抹平，必须换表示。

**引理 22（PCR 重放不可伪造）** 无源/互易约束下，无真实对象者对新鲜 nonce 的响应能量残差与实际至少相隔 `δ_e`，误接受 `≤exp(−T·KL(ν_attack‖ν_real))`；柔顺掩盖在高频导纳可检。

**定理 18（FORCE 严格包含 R69）** `do=observe ∧ U_do=R_do=0` 时逐项等于 R69 VoI；禁用接触探询时闭环逐指令退化为 R69。可逆集严格强于常数 `ε_int`、`f_max≤f_nom`，安全侧不让步，效率侧仅从可逆且见证通过的探询获得 resolution bonus。

**定理 19（接触信息动作安全）** I-CBF + 可逆性 + 力降额 ⇒ 单次信息动作不可逆损害概率 `≤δ_cert`、累计 `≤B_irr`；力设定在模态切换处以 CBF 滤波连续插值，控制连续无突变；失败时 `λ` 单调不降。

**定理 20（接触投毒上界）** 单源错误率 `≥δ_p`；PCR + 因果独立 `k` 一致后 `≤δ_p·ρ^{k−1}+ε_PCR+ε_gap`；`gap_t` 越界即禁用 IVoI，最坏不劣于「从不接触探询」。

## 8. 本轮最大风险

**一句话**：FORCE-RAS 的全部安全性押在「可逆集 `ℛ` 与干预后果 `U_do` 的因果模型可信」这一前提上，而**接触模型正是它想通过探询去改进的东西**——要算 `IVoI(g)` 必须先知道 `do(g)` 会怎样改世界，要降低这个未知又只能去做 `do(g)`；一旦模型把不可逆接触误判为可逆（未知材料、sim2real 差距、力传感器饱和），系统就会在「安全探询」的名义下做出不可撤销的破坏——**它不是在用错误的信念提问，而是在用错误的信念动手**。

**次级风险与缓解**：因果循环（CRG 在线估差距，差距大即收缩 `ℛ`、禁用 IVoI，最坏退回从不接触探询）；可逆性误判（保守下界 + 力随方差降额 + `B_irr` 硬约束）；跳流训练不稳（事件自监督 + 少量标注 + 时间逆变换，失败退回连续流但损失滑移模态）；真实恶意接触（PCR 只证物理在场，用 I-CBF + 可逆集 + 定理 20 兜底）；多速率工程复杂度（力内环复用 R68 低层，策略层 20ms 摊销，安全关键路径隔离）。
