# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感驱动研究循环第 1 轮；本轮灵感：「动作空间」×「轮足机器人」）

> 第 54 轮把技能组合提升为「动作剖面 α_S + 组合图 G_S + 云边映射 γ_ce + 联合证书 J」的可判定体系。但该体系默认动作空间是一个**单一、静态、欧氏的**动作集 A。轮足机器人恰恰违反这一默认：它的动作空间是**接触模式索引的混合空间** `A = ⊔_{m∈M} A_m`，不同模式维数不同、动力学不同、可行动作随地形与接触状态漂移；轮式与腿式的切换还引入离散守卫与时序约束。本轮把第 54 轮的「平面动作剖面」升级为「混合自动机上的剖面 + 切换证书」，并处理轮足驱动冗余带来的动作商空间。核心矛盾：H22 **模式覆盖断层**——单一 α_S 在模式边界把「模式不可达」误判为「动作不可覆盖」；H23 **切换不可判定**——组合证书在零测度的切换瞬间失效（Zeno、抖动、落脚滑移）；H24 **驱动冗余**——动作→任务多对一，不约化则组合图爆炸，且鲁棒性证书无法区分同一任务的不同动作实现。

## 0. 直觉与动机

**灵感 1（接触模式 = 动作空间的分片）**
直觉：轮足机器人能做哪些动作，首先由「谁在接触地面」决定。四轮着地时有轮速/轮转矩通道但没有摆腿自由度；双足支撑时有腿关节通道却受支撑多边形约束；轮腿混合支撑时两类通道并存但互相耦合。因此动作空间不是 `A`，而是按模式分片的 `A = ⊔_{m∈M} A_m`，技能剖面应写成 `α_S(a|m)`。**模式切换不是动作空间内的小扰动，而是换了一个动作空间**；地形则决定哪些模式可用。

**灵感 2（技能 = 混合自动机，组合 = 自动机乘积）**
直觉：一个轮足技能（如「上台阶」）本质是「轮式接近 → 抬腿 → 腿式蹬踏 → 轮式落地」的模式序列，而不是一个连续映射。把技能建模为带守卫、不变式、驻留约束的混合自动机 `H_S`；两技能组合 `S1⊗S2` 就是乘积自动机，只有同时满足两边不变式、守卫一致、共享致动维度上动作相容才保留节点。组合可判定性从「图上找路径」升级为「乘积自动机中是否存在一条覆盖任务模式序列且无 Zeno 的运行」。

**灵感 3（切换证书：守卫-驻留-滑移余量）**
直觉：第 54 轮的联合证书 `J` 只约束了「模式内」的动作覆盖与鲁棒性，完全没有约束「模式间」那一瞬。切换失败往往发生在最危险的临界瞬间：支撑多边形尚未建立、轮子已离地、落脚点滑移。必须显式证明每次切换的 `pre ⊆ Inv_m`、`post ⊆ Inv_{m'}`、守卫裕度 `γ ≥ γ_min`、驻留 `τ ≥ τ_min`、滑移上界 `Δ_slip ≤ Θ_slip`，并排除无限快切换（Zeno）。

**灵感 4（动作商空间：冗余的约化）**
直觉：轮转矩与腿关节都能产生机身运动，很多动作在任务效果上等价（`Eff(a)=Eff(a')`）。若不约化，组合图被大量等价动作撑爆，且两个「看似冲突」的动作其实只是同一任务的不同实现。定义 ε-等价 `a ~ a'`，在商空间 `A/~` 上组合，并取**鲁棒性最优的代表元** `a* = argmax_{a∈[a]} ρ_S(a)`。证书只记录代表元，既压缩搜索又消除证书歧义。

**灵感 5（地形-模式包络 + 云边重剖分）**
直觉：地形分类器给出候选地形集；为安全起见，不能取并集，而应取**可信地形上安全模式的交集**作为保守包络 `M̂_θ = ∩_{τ: conf(τ)≥θ_ter} M̂(τ)`。云端在包络的粗模式上规划技能序列，边端在细模式上校验；若边端观测到实际模式 `m ∉ M̂_θ`，立即把地形证据回传、降级到安全模式（如四轮低重心），并触发 `reprofile(M)`。这把第 54 轮的「云规划-边校验-反向解释-重剖分」闭环改造成**模式级**闭环，联合证书随之扩展为 `J_hyb`。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（混合接触模式）**
接触模式 `m = (σ_m, ω_m, τ_m, φ_m)`：
- `σ_m ⊆ {FL,FR,RL,RR}`：支撑脚集合；
- `ω_m ∈ {0,1}`：轮-地接触标志；
- `τ_m ∈ 𝒯`：地形类别（平地、坡面、粗糙、台阶、边沿等）；
- `φ_m ∈ [0,1)`：步态相位（腿式模式有效）。
模式集合 `M` 有限。每个模式有不变式 `Inv_m ⊆ X`（支撑多边形内的质心投影、机身倾角、轮速上限、关节限位等）。模式内的连续动力学为 `x_{t+1} = f_m(x_t, u_t)`。

**定义 122（模式索引动作空间）**
`𝒜 = ⊔_{m∈M} 𝒜_m`，`𝒜_m ⊆ ℝ^{n_m}`，动作写作 `a = (m, u_m)`。维数 `n_m` 随模式变化（纯轮式无摆腿自由度，纯腿式无轮转矩通道）。模式间的离散转移由守卫-重置对 `(g_{m→m'}, R_{m→m'})` 给出：
```
g_{m→m'} : X × 𝒜_m → {0,1},     R_{m→m'} : X → X
```
一条动作-模式序列 `π = ((m_0,u_0),…,(m_k,u_k))` 可行，当且仅当存在状态轨迹使 `x_t∈Inv_{m_t}`、`x_{t+1}=f_{m_t}(x_t,u_t)`，且每次切换满足守卫与重置。

**定义 123（模式索引动作剖面与覆盖断层）**
`α_S : 𝒜 → [0,1]`，`α_S(m,u_m) = Pr[技能 S 在模式 m 下可执行并完成该模式局部子目标]`，由模式化结构化仿真校准。对任务动作-模式序列 `π_T`：
```
cover(S,π_T)=1  ⇔  ∀(m,u)∈π_T: α_S(m,u) ≥ θ_cov
                    ∧ 相邻模式守卫裕度 γ ≥ γ_min
                    ∧ 驻留 τ ≥ τ_min
```
**覆盖断层** `cliff(S) = max_{m→m'∈M_S} | max_u α_S(m,u) − max_{u'} α_S(m',u') |`，刻画模式边界处能力跳变。`cliff` 大意味着不能用单一剖面跨模式外推，必须逐模式校准。

**定义 124（混合动作自动机技能）**
```
H_S = (M_S, X, 𝒜, Init, Inv, →, Guard, Reset),   → ⊆ M_S × M_S
```
一条运行（trace）是满足守卫与驻留的状态-模式交替序列。技能组合 `S1⊗S2` 为乘积自动机：
- `M_{12} = {(m1,m2) ∈ M_1×M_2 : 动作剖面相容且守卫一致}`；
- `Inv_{12}(m1,m2) = Inv_1(m1) ∩ Inv_2(m2)`；
- 守卫按合取合成 `Guard_{12} = Guard_1 ∧ Guard_2`；
- 动作在共享致动维度上取交集、其余取各自投影：
```
𝒜_{12}(m1,m2) = { a : a|_{𝒟_1}∈𝒜_{m1} ∧ a|_{𝒟_2}∈𝒜_{m2} }
```
组合可行 ⇔ 乘积自动机存在一条覆盖 `π_T`、满足全部守卫/驻留、且无 Zeno 的运行。

**定义 125（模式切换守卫-驻留证书）**
```
G_cert(m→m') = (pre, post, γ, τ_min, Δ_slip, evidence)
```
- `pre ⊆ Inv_m`、`post ⊆ Inv_{m'}`：切换前后必须成立的状态约束；
- `γ = min_{x∈pre} margin(g_{m→m'}, x) > γ_min`：守卫裕度；
- `τ_min ≥ τ_crit`：驻留下界，`τ_crit` 由 Zeno 条件导出；
- `Δ_slip ≤ Θ_slip`：切换窗口内滑移上界；
- `evidence`：切换反例轨迹与地形标定日志。
可切换 ⇔ 以上全部成立，且重置后 `post` 成立的概率 `≥ 1−β_sw`。

**定义 126（轮足动作商空间）**
任务效果映射 `Eff_S : 𝒜_m → 𝒴`（机身 twist + 末端位姿 + 接触力）。给定 `ε_y, ε_ρ`：
```
a ~ a'  ⇔  ||Eff(a)−Eff(a')||_𝒴 ≤ ε_y  ∧  |ρ_S(a)−ρ_S(a')| ≤ ε_ρ
```
商空间 `𝒜/~`。代表元 `a*(C) = argmax_{a∈C} ρ_S(a)`（鲁棒性最优的等价动作）。证书只记录代表元，组合图节点数降至 `|𝒜/~|`。

**定义 127（地形-模式包络）**
地形分类器 `c : 𝒵_terrain → 𝒯` 输出类别与置信度 `conf`。给定阈值 `θ_ter`，单类安全模式集
```
M̂(τ) = { m : margin_stability(m,τ) ≥ Γ_min  ∧  actuator_feasible(m,τ) }
```
部署包络取**可信地形上的交集**（欠近似安全集，保守）：
```
M̂_θ = ∩_{τ : conf(τ) ≥ θ_ter} M̂(τ)
```
只有 `m ∈ M̂_θ` 才允许进入；若边端观测到实际模式 `m ∉ M̂_θ`，立即回传地形证据并降级到安全模式。

**定义 128（混合动作-鲁棒性联合证书）**
```
J_hyb = (ρ, ρ_sw, {A_core(m)}_{m∈M}, γ_ce, δ_a, G_cert, q*, M̂_θ, evidence)
```
- `ρ`：各模式鲁棒性谱（承接第 53 轮）；
- `ρ_sw(m→m')`：模式切换鲁棒性（扰动下切换成功概率）；
- `A_core(m)`：模式 `m` 下保证覆盖的核心动作子集；
- `γ_ce`：云边映射（模式序列也须一致）；
- `δ_a`：动作/模式对齐误差；
- `G_cert`：模式序列上每条切换的守卫-驻留证书；
- `q*`：商空间代表元映射；
- `M̂_θ`：地形-模式包络；
- `evidence`：模式剖面校准样本、切换反例、地形标定日志。
可部署 ⇔
```
∀m∈π_T: A_core(m)≠∅ ∧ ρ(m) ≥ ρ_min
∧ ∀ switch: G_cert valid ∧ ρ_sw ≥ ρ_sw,min
∧ pi_T ⊆ M̂_θ ∧ q* 在容差内 ∧ δ_a < Θ_a
∧ 云边模式序列版本一致
```

## 2. 关键算法 伪代码

### IP-121 CMAP（Contact-Mode Action Profiling）

```python
def mode_indexed_profile(skill, M, sampler, n=64):
    alpha = {}
    for m in M:
        for _ in range(n):
            x0 = sample_invariant(m)
            u  = skill.mode_action(m, x0)
            ok, conf = sampler.rollout(skill, m, x0)
            alpha[(m, u)] = max(alpha.get((m, u), 0.0), conf if ok else 0.0)
    cliff = max(abs(max_prof(alpha, m) - max_prof(alpha, m2))
                for m, m2 in mode_edges(M))
    return alpha, cliff
```

### IP-122 HSC（Hybrid Skill Composition）

```python
def hybrid_compose(H1, H2, pi_T, theta_cov, gamma_min, tau_min):
    H = product_automaton(H1, H2)          # 模式对 + 不变式交 + 守卫合取
    for m in list(H.modes):
        A12 = action_intersection(H1.A[m[0]], H2.A[m[1]])
        if not A12:
            H.remove(m); continue
        H.A[m] = [a for a in A12
                  if cover_check(H1.alpha, m[0], a, theta_cov)
                  and cover_check(H2.alpha, m[1], a, theta_cov)]
    path = search_trace(H, pi_T)           # 需覆盖任务模式序列
    if path is None:
        return ('reject', 'no_trace')
    for m, m2 in zip(path, path[1:]):
        if not guard_dwell_ok(m, m2, gamma_min, tau_min):
            return ('reject', 'guard_or_dwell', (m, m2))
    if has_zeno(path):
        return ('reject', 'zeno', path)
    return ('ok', H, path)
```

### IP-123 AQR（Action Quotient Reduction）

```python
def action_quotient(skill, mode, eps_y, eps_rho):
    clusters = metric_cluster(skill.A[mode],
                              key=lambda a: Eff(skill, a),
                              radius=eps_y)
    reps = {}
    for C in clusters:
        if spread_rho(C) <= eps_rho:
            reps[frozenset(C)] = max(C, key=lambda a: robustness(skill, a))
        else:
            for a in refine(C):            # 过度异质簇先分裂，避免误合并
                reps[frozenset([a])] = a
    return reps
```

### IP-124 TME（Terrain-Mode Envelope）

```python
def terrain_mode_envelope(classifier, terrain_grid, theta_ter, Gamma_min):
    plausible = conservative_terrain_set(classifier, terrain_grid, theta_ter)
    envelope = None
    for tau in plausible:
        safe = {m for m in M
                if stability.margin(m, tau) >= Gamma_min
                and actuator.feasible(m, tau)}
        envelope = safe if envelope is None else (envelope & safe)  # 交集=保守
    if not envelope:                       # 包络为空：降级到最保守模式
        envelope = {safest_mode(M)}
    return envelope
```

### IP-125 HMC（Hybrid Mode Certificate）

```python
def guard_dwell_certificate(trace, H, gamma_min, tau_min, slip_max):
    certs = []
    for (m, m2), t in zip(trace.pairs, trace.switch_times):
        pre, post = H.pre(m, m2), H.post(m, m2)
        gamma = min_guard_margin(H, pre)
        dwell = trace.dwell(m)
        slip  = slip_bound(H, m, m2)
        if (not pre.subset(H.Inv[m]) or not post.subset(H.Inv[m2])
                or gamma < gamma_min or dwell < tau_min or slip > slip_max):
            return ('reject', m, m2, gamma, dwell, slip)
        certs.append(G_cert(m, m2, pre, post, gamma, dwell, slip))
    if has_zeno(trace):
        return ('reject', 'zeno')
    return ('ok', certs)
```

### IP-126 HJC（Hybrid Joint Certificate）

```python
def hybrid_joint_certificate(skill_seq, pi_T, gamma_ce, budgets):
    for m in modes_of(pi_T):
        if not cover_check(skill_seq, m, pi_T[m], budgets.theta_cov):
            return ('reject', 'coverage_gap', m)
        if min(robustness(m).values()) < budgets.rho_min:
            return ('reject', 'robustness', m)
        if mean_switch_robustness(m) < budgets.rho_sw_min:
            return ('reject', 'switch_robustness', m)
    ok, certs = guard_dwell_certificate(trace_of(pi_T), H,
                                        budgets.gamma_min, budgets.tau_min,
                                        budgets.slip_max)
    if not ok:
        return ('reject', 'guard_dwell', certs)
    if not set(modes_of(pi_T)).issubset(budgets.envelope):
        return ('reject', 'outside_envelope')
    q = [action_quotient(s, m, budgets.eps_y, budgets.eps_rho)
         for s, m in zip(skill_seq, modes_of(pi_T))]
    delta_a = max_alignment_error(gamma_ce, pi_T)
    if delta_a > budgets.delta_a:
        return ('reject', 'alignment', delta_a)
    return ('ok', J_hyb(rho_of(pi_T), switch_rho(pi_T), core_actions(pi_T),
                        gamma_ce, delta_a, certs, q, budgets.envelope,
                        evidence=collect_evidence()))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CMAP | O(|M|·|𝒜_m|·n) | O(|M|·|𝒜_m|) | 逐模式校准、`cliff` 保守截断 |
| HSC | O(|M_1||M_2|·|𝒜|² + |V|log|V|+|E|) | O(|M_1||M_2|) | 守卫一致、无 Zeno、路径覆盖 |
| AQR | O(N log N + N·|𝒴|) | O(N) | `ε_y/ε_ρ` 保真、异质簇分裂 |
| TME | O(|𝒯_p|·|M|·N_grid) | O(|𝒯_p||M|) | 取交集=欠近似安全集 |
| HMC | O(|π_T|·(|Inv|+|Guard|)) | O(|π_T|) | 守卫裕度、驻留下界、滑移界 |
| HJC | O(|π_T|·|𝒜| + Σ 上式) | O(|π_T|+|𝒜/~|) | 证书 sound、包络与版本一致 |

**正确性定理（Hybrid Action-Skill Composition Soundness）**
承接第 54 轮 (A22)–(A28)。新增：
**(A29)** `α_S` 在每个模式上由模式化仿真校准，模式边界按 `cliff` 保守截断；
**(A30)** 所有切换满足守卫裕度 `γ ≥ γ_min`、驻留 `τ ≥ τ_min`，且运行无 Zeno；
**(A31)** 地形-模式包络为可信地形上安全模式的交集（欠近似安全集），实际地形误判概率 `≤ β_T`；
**(A32)** 商空间约化满足 `||Eff(a*)−Eff(a)|| ≤ ε_y` 且鲁棒性差 `≤ ε_ρ`。
则任务-模式序列 `π_T` 的部署成功概率满足
```
P_success(π_T) ≥ 1 − Σ_m Σ_d (1−ρ_min(d|m))
                   − Σ_{switch} (1−ρ_sw)
                   − P(cliff > Θ_c)
                   − β_T − β_E − P(δ_a > Θ_a)
```
其中 `P(cliff>Θ_c)` 是模式覆盖断层导致的组合误判概率。关键：**模式是可行动作的前提，守卫是可切换的前提，包络是地形安全的前提，商空间是可搜索的前提**——四者缺一，`J_hyb` 不成立。

## 4. 实验设计 E162–E166

平台：MuJoCo/Isaac Sim 的轮足模型（四轮+四腿、可锁轮/可抬腿）+ 实机（轮足底盘 ± 机械臂）。对手：第 54 轮 `J`（单剖面）、纯轮式、纯腿式基线。

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 模式剖面校准 | 逐模式 `|α_S − α_real|`；`cliff` 估计误差 | MAE ≤ 0.05；cliff 误差 ≤ 0.08 |
| E163 模式切换安全 | 切换成功率；Zeno 次数；平均驻留开销 | 成功率 ≥ 98%；Zeno=0；开销 < 15% |
| E164 地形-模式包络 | 不安全模式误准入率；OOD 地形降级成功率 | 误准入 ≤ 1%；降级成功 ≥ 95% |
| E165 动作商空间约化 | 组合图节点降幅；任务成功率损失 | 节点 ↓ ≥ 40%；损失 ≤ 2% |
| E166 混合联合证书有效性 | 成功率 vs 消融（单剖面+无守卫）；漏报率 | 提升 ≥ 15%；漏报 ≤ 1% |

消融设计：`−CMAP`（单一 α 跨模式外推）、`−HSC`（忽略守卫/驻留）、`−AQR`（不约化）、`−TME`（用并集包络）、`−HMC`（只查模式内 ρ）。E166 需报告每种消融下的具体失败模式（模式错判 / 切换抖动 / 落脚滑移 / 网格爆炸）。

### IP-121 CMAP

```python
def mode_indexed_profile(skill, M, sampler, n=64):
    alpha = {}
    for m in M:
        for _ in range(n):
            x0 = sample_invariant(m)
            u  = skill.mode_action(m, x0)
            ok, conf = sampler.rollout(skill, m, x0)
            alpha[(m, u)] = max(alpha.get((m, u), 0.0), conf if ok else 0.0)
    cliff = max(abs(max_prof(alpha, m) - max_prof(alpha, m2))
                for m, m2 in mode_edges(M))
    return alpha, cliff

def cover_check(alpha, m, u, theta_cov):
    return alpha.get((m, u), 0.0) >= theta_cov
```

### IP-122 HSC

```python
def hybrid_compose(H1, H2, pi_T, theta_cov, gamma_min, tau_min):
    H = product_automaton(H1, H2)          # 模式对 + Inv 交 + Guard 合取
    for m in list(H.modes):
        A12 = action_intersection(H1.A[m[0]], H2.A[m[1]])
        if not A12:
            H.remove(m); continue
        H.A[m] = [a for a in A12
                  if cover_check(H1.alpha, m[0], a, theta_cov)
                  and cover_check(H2.alpha, m[1], a, theta_cov)]
    path = search_trace(H, pi_T)
    if path is None:
        return ('reject', 'no_trace')
    for m, m2 in zip(path, path[1:]):
        if not guard_dwell_ok(m, m2, gamma_min, tau_min):
            return ('reject', 'guard_or_dwell', (m, m2))
    if has_zeno(path):
        return ('reject', 'zeno', path)
    return ('ok', H, path)
```

### IP-123 AQR

```python
def action_quotient(skill, mode, eps_y, eps_rho):
    clusters = metric_cluster(skill.A[mode],
                              key=lambda a: Eff(skill, a), radius=eps_y)
    reps = {}
    for C in clusters:
        if spread_rho(C) <= eps_rho:
            reps[frozenset(C)] = max(C, key=lambda a: robustness(skill, a))
        else:
            for a in refine(C):            # 异质簇先分裂
                reps[frozenset([a])] = a
    return reps
```

### IP-124 TME

```python
def terrain_mode_envelope(classifier, terrain_grid, theta_ter, Gamma_min):
    plausible = conservative_terrain_set(classifier, terrain_grid, theta_ter)
    envelope = None
    for tau in plausible:
        safe = {m for m in M
                if stability.margin(m, tau) >= Gamma_min
                and actuator.feasible(m, tau)}
        envelope = safe if envelope is None else (envelope & safe)  # 交集=保守
    return envelope or {safest_mode(M)}
```

### IP-125 HMC

```python
def guard_dwell_certificate(trace, H, gamma_min, tau_min, slip_max):
    certs = []
    for (m, m2), t in zip(trace.pairs, trace.switch_times):
        pre, post = H.pre(m, m2), H.post(m, m2)
        gamma, dwell, slip = (min_guard_margin(H, pre),
                              trace.dwell(m),
                              slip_bound(H, m, m2))
        if (not pre.subset(H.Inv[m]) or not post.subset(H.Inv[m2])
                or gamma < gamma_min or dwell < tau_min or slip > slip_max):
            return ('reject', m, m2, gamma, dwell, slip)
        certs.append(G_cert(m, m2, pre, post, gamma, dwell, slip))
    return ('reject', 'zeno') if has_zeno(trace) else ('ok', certs)
```

```python
def hybrid_joint_certificate(skill_seq, pi_T, gamma_ce, budgets):
    for m in modes_of(pi_T):
        if not cover_check(skill_seq, m, pi_T[m], budgets.theta_cov):
            return ('reject', 'coverage_gap', m)
        if min(robustness(m).values()) < budgets.rho_min:
            return ('reject', 'robustness', m)
        if mean_switch_robustness(m) < budgets.rho_sw_min:
            return ('reject', 'switch_robustness', m)
    ok, certs = guard_dwell_certificate(trace_of(pi_T), H,
                                        budgets.gamma_min, budgets.tau_min,
                                        budgets.slip_max)
    if not ok:
        return ('reject', 'guard_dwell', certs)
    if not set(modes_of(pi_T)).issubset(budgets.envelope):
        return ('reject', 'outside_envelope')
    q = [action_quotient(s, m, budgets.eps_y, budgets.eps_rho)
         for s, m in zip(skill_seq, modes_of(pi_T))]
    delta_a = max_alignment_error(gamma_ce, pi_T)
    if delta_a > budgets.delta_a:
        return ('reject', 'alignment', delta_a)
    return ('ok', J_hyb(rho_of(pi_T), switch_rho(pi_T), core_actions(pi_T),
                        gamma_ce, delta_a, certs, q, budgets.envelope,
                        evidence=collect_evidence()))
```

**正确性定理（Hybrid Action-Skill Composition Soundness）**

```
P_success(π_T) ≥ 1 − Σ_m Σ_d(1−ρ_min(d|m))
                   − Σ_switch(1−ρ_sw)
                   − P(cliff>Θ_c) − β_T − β_E − P(δ_a>Θ_a)
```
关键：**模式是可行动作的前提，守卫是可切换的前提，包络是地形安全的前提，商空间是可搜索的前提**。
