# 第 62 轮（承接第 61 轮「具身语义进化闭环」ESEC / IP-173~182；灵感循环第 1 轮；本轮灵感：「动作分块」×「主动交互」）

> 第 61 轮的 ESEC 把场景、意图、阻抗、证据统一到 USR，用 MEL 做零样本物理推断、用 DMS 做多轮对话、用 SRT-Dual 解耦语义流与实时流。但它仍留下**四个结构性缺口**：
> 1. **单帧语义锚点的时间不一致性**：SRT-Dual 只保证锚点「新鲜」，不保证「连贯」。语义流 ~10-100Hz 产出单点阻抗先验，实时流 ~1-10kHz 反复重编译，导致阻抗参数在相邻周期抖动（chattering）；大模型每帧独立推理，跨帧无承诺、无平滑、无动量。
> 2. **没有承诺视界（commitment horizon）**：EEIS/ERTC 把每个实时瞬间当作独立决策，既不能摊销 MEL 的推理成本，也没有「一段动作已承诺、何时可撤销」的形式化语义——于是既抖又脆：平滑性差，异常反应又只能靠逐帧阈值。
> 3. **信息获取完全被动**：MEL 等观测、DMS 等 EV-exec 触发。不确定性 U 只被用来「向安全区内收缩」，从未被用来「主动消除」。机器人不会为了降低摩擦/刚度不确定性而**主动探一下**，也不会为消解语义歧义而**主动问一句**——探测（physical probe）与询问（social query）没有被建模为一等决策变量。
> 4. **交互成本缺失**：没有「人的注意力预算」与「探测风险预算」。缺少统一成本模型时，DMS 要么过度追问（烦人），要么在关键歧义上沉默（危险）；探测要么不敢做（信息不足），要么乱做（引入风险）。

## 0. 直觉与动机

**灵感 1（动作分块 → 阻抗动作分块 IAC）**
直觉：人抓杯子不会每毫秒重算一次握力，而是先承诺一个短促的「动作基元」，接触后再修正。把这一直觉搬到阻抗控制：语义流不再只输出单点 `K_prior`，而是输出一段**阻抗轨迹分块** `κ = (K_0, …, K_{C-1})`（视界 τ_c 约 0.2–1s，C≈10–50）。实时流在分块内做 C¹ 插值，跨重叠分块做时间集成。关键收益有三：**①** MEL 的 ~200ms 延迟被 C 步摊销，实时流不再每个 tick 等语义；**②** 阻抗轨迹天然平滑，抖动被分块的连续性约束压住；**③** 分块成为可审计的「时间契约」——可以整块签发证书，也可以整块撤销。

**灵感 2（动作分块 → 安全保持的时间集成 TSE）**
直觉：分块重叠时，最朴素的做法是把多个分块加权平均（ACT 式 temporal ensemble）。但**两个各自安全的控制器，其平均值未必安全**（安全集一般不封闭于平均）。关键洞见：若把安全集定义为**凸的保守多面体** `C_safe(t)`，并只对「同一时刻均落在 `C_safe(t)` 内」的分块做**凸组合**，则集成的结果仍安全。这把「平滑」从工程技巧升级为**可证明的安全性质**；一旦某个分块证书失效或被撤销，就退回「已认证中位数 + 保守扩张」，绝不把未认证的分块混进来。

**灵感 3（主动交互 → 主动信息获取 AIA）**
直觉：不确定性是一种可以被「花代价换掉」的资源。面对未知材质，机器人可以：**①** 直接猜（零成本、高风险）；**②** 用很小的力**探一下**（物理信息动作，花时间、担风险，但得到触觉证据）；**③** **问一句**「这是易碎品吗？」（社会信息动作，花人的注意力、但能消解视觉不可观测的语义）。把探测与询问统一为**信息动作集** `A_info = A_probe ⊎ A_query`，用决策论意义的价值信息量 `VOI(a) = E_o[V(b')] − V(b) − cost(a)` 来选择——注意是「对决策有用的信息量」，而非纯粹的熵减：不改变动作的信息，VOI 应为 0。

**灵感 4（两灵感合流 → 分块中断策略 CIP）**
直觉：分块给了稳定性，却牺牲了反应性；主动交互又会在分块执行途中注入新信息。二者的真正耦合点是：**何时值得撕毁剩余分块？** 若新信息使「剩余分块的价值」显著低于「重规划 + 可能的信息动作」的价值，就中断；否则继续执行以保住平滑性。于是「分块」与「主动」不再是两个并列模块，而是一个**承诺-撤销**的闭环：分块是承诺，中断是主动性的时间出口。

**灵感 5（预算扩展 → PCE-AC：主动-分块认知预算）**
直觉：第 61 轮的六维预算缺两项——**分块/重规划预算** `B_chunk`（重规划频率、视界上下界、切换成本）与**信息预算** `B_info`（探测时间/风险、人的注意力、每任务询问上限）。二者共同决定「平滑 vs 反应」「探/问 vs 直接做」的资源配置。VOI 不再只是模式选择器，而成为**预算的分配器**：当 `B_info` 耗尽，询问/探测的 VOI 门槛自动抬高；当 `B_chunk` 耗尽，系统冻结在长视界+保守扩张，以稳定换反应。

## 1. 形式化定义（增量：定义 173–184）

**定义 173（阻抗动作分块 IAC）** 设阻抗动作空间 `A_K ⊂ ℝ^m`（分量如 K_p, K_d, F_max, …），分块长度为 C，实时步长 Δt_rt。
- **分块**：`κ = (a_0, …, a_{C-1}) ∈ A_K^C`，物理视界 `τ_c = C·Δt_rt`
- **分块策略**：`π_chunk: (b_t, Anchor_t, H_diag) → P(A_K^C)`，以 `f_chunk ≤ f_sem` 的频率发射
- **元数据**：`κ.meta = (g, s, C, Δt_rt, conf, cert)`，g 为代际号，s 为起始墙钟时刻
- **实时重建**：`a_t = Interp(κ, t)`，采用最小加加速度（min-jerk）或 C¹ 三次插值，保证分块边界处位置/一阶导连续
- **承诺前缀**：只有 `κ.cert` 认证通过的前缀 `κ[0:o*]` 可被执行；`o*` 为首个未认证偏移

**定义 174（安全保持时间集成 TSE）** 设时刻 t 的**凸保守安全集** `C_safe(t) ⊂ A_K`（由参数上下界、`F_max ≤ μN` 等线性约束张成的多面体）。
- **重叠分块集**：`J(t) = {j : 0 ≤ t − s_j < C_j·Δt_rt, cert_j 有效}`
- **凸权重**：`w_j(t) ≥ 0, Σ_{j∈J(t)} w_j(t) = 1`，取 `w_j(t) ∝ exp(−λ_age·(t−s_j))·conf_j`
- **集成**：`a_t^ens = Σ_{j∈J(t)} w_j(t)·κ_j(t−s_j)`
- **安全引理（TSE-Safe）**：若 `∀j∈J(t): κ_j(t−s_j) ∈ C_safe(t)` 且 `C_safe(t)` 凸，则 `a_t^ens ∈ C_safe(t)`
- **回退**：若 `J(t)=∅` 或某分块证书被撤销，则退回「最近已认证分块的中位数」并做保守扩张；若仍无，则纯保守编译（不做集成）

**定义 175（分块级证书与承诺 CCC）** 分块证书
```
cert(κ) = ∀o∈[0,C): [ κ(o) ∈ C_safe(s+o·Δt_rt)
                     ∧ ‖κ(o+1)−κ(o)‖ ≤ Δa_max
                     ∧ jerk(κ,o) ≤ J_max
                     ∧ 预测接触力 ∈ [0, F_env(s+o·Δt_rt)] ]
          ∧ (g 单调) ∧ (s 与实时流时钟偏差 ≤ δ_clk)
```
- 验证复杂度 O(C)；证书可按偏移**部分有效**（前缀有效）
- **撤销条件**：EV-exec 越过预测力包络、或投影误差超限、或新信息使证书前提失效 ⇒ 撤销 `κ[o:]`

**定义 176（分块-锚点一致性协议 CACP）** 扩展第 61 轮 SACP：
- 锚点携带 `(g, κ, s, checksum)`；实时流按**墙钟**计算偏移 `o = t − s`，而非按帧序号（避免时钟漂移累积）
- **代际单调**：g 为 64 位单调递增；同一代际内不允许跨代混合（TSE 只混合同 g 或显式兼容的相邻代）
- **写入原子性**：CAS 写锚点 + 分块，version 与 g 同步推进；旧代在 C 步后退休
- **一致性检查**：`‖a_t^ens − Π(Anchor.scene+intent)‖ ≤ ε_chunk`，否则触发重规划

**定义 177（主动信息获取 AIA）** 设信念 `b` 为对潜变量 `θ = (φ_phys, z_scene, intent)` 的后验。
- **信息动作集**：`A_info = A_probe ⊎ A_query`；`A_probe` 为物理探索动作（低力点触、轻擦、叩击），`A_query` 为对话询问
- **决策论 VOI**：`VOI(a|b) = E_{o∼p(o|b,a)}[V_{π}(b')] − V_{π}(b) − cost(a)`
  - `cost(a) = λ_t·time(a) + λ_r·risk(a) + λ_h·human_attention(a)`
  - 纯熵减形式 `H(b)−E[H(b')]` 仅作近似；**不改变最优动作的信息 VOI 应为 0**
- **选择**：`a* = argmax_{a∈A_act∪A_info} [Q_act(b,a) + VOI(a|b)]`，并附**硬安全否决** `risk(a) ≤ R_max`

**定义 178（物理探测 vs 社会询问的统一选择 UIO）** 
- **探测设计（最优实验设计）**：`p* = argmax_{p∈A_probe} I(φ_phys; o | p)`，s.t. `p ∈ C_safe`, `F_probe ≤ F_max^probe`；可用 D-最优/Fisher 信息近似
- **询问选择（决策相关）**：`q* = argmax_{q∈A_query} E_{r∼p(r|b,q)}[V(b')] − V(b)`，s.t. `human_attention ≤ B_info.attention_left`
- **统一规则**：优先探测当且仅当 `∂VOI_probe/∂cost > ∂VOI_query/∂cost` 且探测风险在预算内；优先询问当歧义是**语义不可观测**的（如「易碎」「先别动」）且 `VOI_query > c_attention`；否则直接行动
- **禁止项**：不得用探测去获取物理上不可观测的语义（如用户偏好）；不得用询问去替代本可低成本探测的物理量（浪费人的注意力）

**定义 179（分块中断策略 CIP）** 中断谓词
```
I_t = 1[ ¬cert_valid(κ, t)
        ∨ safety_veto(EV_exec_t)
        ∨ ΔV_info(t) > θ_int · V_remain(κ, t) ]
```
其中 `ΔV_info(t)` 为「此刻获得的新信息」带来的决策价值增量，`V_remain` 为继续执行剩余分块的价值。中断即撤销 `κ[t:]`，重建分块（可能先插入信息动作）。`θ_int` 越小越反应、越大越平滑。

**定义 180（自适应分块视界 AHC）** 
```
C* = argmax_{C∈[C_min,C_max]} [ J_task(C) − λ_sw·(1/C) − λ_risk·Risk(C) ]
```
等价工程判据：取满足「分块末端预测后验不确定性 ≤ ε_unc」且「视界内预测接触事件概率 ≤ p_event」的**最短** C；若都不满足，取 `C_min` 并强制在末端插入信息动作。

**定义 181（主动-分块认知预算 PCE-AC）** 
```
B_cog⋆ = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_chunk, B_info)
B_chunk = (replan_per_sec_max, C_min, C_max, switch_cost)
B_info  = (probe_time_left, probe_risk_left, human_attention_left, queries_left)
```
- 成本：`cost⋆ = cost_cog5 + λ_chunk·(replan_rate/replan_max + switch_cost) + λ_info·(probe_time/time_max + queries/queries_max)`
- **降级**：`B_info` 耗尽 ⇒ 关闭探测，询问阈值抬高为 `2×c_attention`；`B_chunk` 耗尽 ⇒ 冻结为 `C_max` 长视界 + 保守扩张（稳定优先）；二者同时耗尽 ⇒ 纯保守编译 + 只读锚点

**定义 182（分块索引的主动信念）** `b_{t|o,g}`：信念不仅索引时间 t，还索引「当前分块内偏移 o」与代际 g。其状态含 `(后验 θ, 开放环承诺 κ, 预期信息到达)`。更新只在信息事件（新观测/探测结果/用户回复/EV-exec）时发生，而非每帧发生——这使信念更新频率与语义事件率对齐。

**定义 183（CASE 闭环算子）** `CASE = CIP ∘ TSE ∘ IAC ∘ AIA ∘ ESEC`：
```
语义节拍:  b ← AIA.select / probe / query 更新 → IAC.emit(κ) → cert(κ) → commit(Anchor,κ)
实时节拍:  a_t ← TSE.blend(重叠κ) → EEIS.compile(a_t, φ_phys) → ERTC.dispatch
事件节拍:  CIP.should_interrupt? → 撤销+重规划；EV-exec → USR.evidence → XMC+++
```

**定义 184（主动-分块联合证书 J_ac）** 
```
J_ac = (J_sem_exec, g, κ_id, cert_prefix, VOI_decision, info_action, interrupt_reason, B_info_snapshot)
Valid(J_ac) ⇔ Valid(cert_prefix) ∧ Valid(J_sem_exec) ∧ info_ok(budget,risk) ∧ audit_complete
```

## 2. 本轮最大风险

**一句话**：时间集成会把「危险信号」一起平滑掉（跨分块平均可能掩盖突发的滑移/力尖峰），而主动探测本身引入真实物理风险、主动询问又可能因 VOI 估计偏差而过度打扰或该问不问，因此最大风险是「系统很平滑、很自信、很有礼貌，却在关键时刻把危险平均成了安全」——必须以「凸认证安全集内的集成 + 分块证书前缀硬约束 + 探测风险硬上限 + 中断安全否决优先于 VOI」构建护栏，确保平滑与主动永不越过安全红线。

### IP-183 IAC（阻抗动作分块）

```python
class ImpedanceChunk:
    def __init__(self, K_seq, start, dt, generation, confidence, cert=None):
        self.K_seq = K_seq            # list[A_K], len = C
        self.start = start            # 墙钟起始
        self.dt = dt
        self.C = len(K_seq)
        self.g = generation
        self.conf = confidence
        self.cert = cert

    def at(self, t):
        o = (t - self.start) / self.dt
        return interp_min_jerk(self.K_seq, o)   # 越界则 clamp

    def certified_prefix(self):
        return self.cert.valid_len if self.cert else 0


class ImpedanceChunkEmitter:
    def __init__(self, projector, safe_set, C_min=10, C_max=50, dt=0.01):
        self.projector = projector
        self.safe_set = safe_set
        self.C_min, self.C_max, self.dt = C_min, C_max, dt
        self.gen = 0

    def emit(self, belief, anchor, ev_ctx):
        C = self.choose_horizon(belief, ev_ctx, anchor)     # IP-190
        K_seq = []
        for o in range(C):
            phase = o / max(1, C - 1)
            a_o = self.projector(anchor.scene_emb, anchor.intent_emb,
                                 anchor.phys_prior, phase)
            K_seq.append(self.safe_set.project(a_o, anchor.timestamp))
        self.gen += 1
        kappa = ImpedanceChunk(K_seq, start=now(), dt=self.dt,
                               generation=self.gen, confidence=anchor.confidence)
        kappa.cert = self.certify(kappa)                    # IP-185
        return kappa

    def certify(self, kappa):
        first_bad = None
        for o, a in enumerate(kappa.K_seq):
            t = kappa.start + o * kappa.dt
            if not self.safe_set.contains(a, t):
                first_bad = o; break
            if o > 0 and norm(kappa.K_seq[o] - kappa.K_seq[o-1]) > DELTA_A_MAX:
                first_bad = o; break
            if jerk(kappa.K_seq, o) > J_MAX:
                first_bad = o; break
            if not self.force_envelope_ok(a, kappa, o):
                first_bad = o; break
        if first_bad == 0:
            return ChunkCert(valid=False, valid_len=0)
        return ChunkCert(valid=True, valid_len=first_bad or kappa.C)
```

### IP-184 TSE（安全保持时间集成）

```python
class SafetyPreservingEnsemble:
    """凸安全集内的多分块集成：凸组合保安全性（TSE-Safe 引理）。"""
    def __init__(self, safe_set, lam_age=8.0, eps_chunk=0.05):
        self.safe_set = safe_set
        self.lam_age = lam_age
        self.eps_chunk = eps_chunk

    def blend(self, chunks, t):
        active = [c for c in chunks
                  if c.cert and c.cert.valid_len > 0
                  and 0 <= (t - c.start) < c.cert.valid_len * c.dt
                  and self._compatible(c, chunks)]
        if not active:
            return None, 'no_certified_chunk'

        # 数据驱动初始化，再按代际分组（禁止跨代混合）
        g_now = max(c.g for c in active)
        active = [c for c in active if c.g == g_now]

        w = softmax([-self.lam_age * (t - c.start) + log(c.conf + 1e-6)
                     for c in active])
        a_ens = sum(wi * c.at(t) for wi, c in zip(w, active))

        # 集成本身必须仍在安全集内（引理保证，但保留数值校验）
        if not self.safe_set.contains(a_ens, t):
            a_ens = self.safe_set.project(a_ens, t)          # 保守投影
            return a_ens, 'projected'

        # 一致性：集成结果 vs 当前语义锚点投影
        anchor = active[0].anchor
        a_sem = self.projector(anchor.scene_emb, anchor.intent_emb, anchor.phys_prior, 0.0)
        if norm(a_ens - a_sem) > self.eps_chunk:
            return a_ens, 'semantic_drift'
        return a_ens, 'ok'
```

```python
def revoke_on_evidence(kappa, ev_exec, t):
    """事件驱动撤销：任何越界都立即缩短承诺前缀。"""
    o = int((t - kappa.start) / kappa.dt)
    reasons = []
    if ev_exec.force > kappa.predicted_force(o) * FORCE_MARGIN:
        reasons.append('force_envelope')
    if ev_exec.slip_detected:
        reasons.append('slip')
    if ev_exec.vibration > kappa.predicted_vib(o) + VIB_MARGIN:
        reasons.append('vibration')
    if reasons:
        kappa.cert.valid_len = max(0, min(kappa.cert.valid_len, o))
    return reasons
```

### IP-186 CACP（分块-锚点一致性）

```python
class ChunkAnchorBus:
    def __init__(self, delta_clk=1e-4):
        self.delta_clk = delta_clk

    def commit(self, anchor, kappa):
        assert kappa.g == anchor.g, "代际必须一致"
        return self.cas_write({'anchor': anchor, 'chunk': kappa,
                               'version': next_version64()})

    def read(self, t):
        snap = self.latest()
        if snap is None:
            return None, 'empty'
        a, k = snap['anchor'], snap['chunk']
        if abs(t - k.start) > k.C * k.dt + self.delta_clk:
            return snap, 'stale'
        if (t - k.start) < 0:
            return snap, 'not_started'
        return snap, 'fresh'
```

### IP-187 AIA（主动信息获取）

```python
class ActiveInformationAcquisition:
    def __init__(self, action_set, value_fn, obs_model, budget):
        self.A = action_set
        self.V = value_fn          # V(b) 下游最优价值（可用 rollout 近似）
        self.O = obs_model         # p(o | b, a)
        self.budget = budget

    def voi(self, b, a):
        v0 = self.V(b)
        exp = 0.0
        for o, p in self.O(b, a):
            exp += p * self.V(self.update(b, a, o))
        cost = (LAM_T * a.time + LAM_R * a.risk + LAM_H * a.human_attention)
        return exp - v0 - cost

    def select(self, b):
        best, best_score = None, -1e18
        for a in self.A:
            if a.risk > self.budget.probe_risk_left:
                continue                              # 硬安全否决
            if a.is_query and self.budget.queries_left <= 0:
                continue
            if a.is_probe and self.budget.probe_time_left < a.time:
                continue
            score = (self.Q_act(b, a) if not a.is_info else 0.0) + self.voi(b, a)
            if score > best_score:
                best, best_score = a, score
        return best
```

### IP-188 UIO（探测 vs 询问）

```python
class UnifiedInformationOrientedSelector:
    def choose(self, b, ai, budget):
        probe = self.best_probe(b, budget)   # argmax I(φ;o|p), s.t. safe & F<=F_probe
        query = self.best_query(b, budget)   # argmax decision-relevant value, s.t. attention

        candidates = []
        if probe is not None:
            candidates.append((ai.voi(b, probe) / (probe.time + EPS), probe, 'probe'))
        if query is not None:
            candidates.append((ai.voi(b, query) / (query.human_attention + EPS), query, 'query'))

        # 语义不可观测的歧义：询问优先（探测无信息）
        if self.is_semantic_ambiguity(b) and query is not None:
            return query
        # 物理量可低成本探测：探测优先
        if self.is_physical_uncertainty(b) and probe is not None:
            return probe
        if not candidates:
            return None
        return max(candidates, key=lambda c: c[0])[1]

    def best_probe(self, b, budget):
        best = None
        for p in self.probe_candidates(b):
            if p.risk > budget.probe_risk_left or p.force > F_PROBE_MAX:
                continue
            info = mutual_information(b, p)       # D-最优 / Fisher 近似
            if best is None or info > best[0]:
                best = (info, p)
        return best[1] if best else None
```

```python
class ChunkInterruptionPolicy:
    def __init__(self, theta_int=0.3):
        self.theta_int = theta_int

    def should_interrupt(self, kappa, b, ev_exec, t):
        if kappa.cert is None or kappa.cert.valid_len <= int((t-kappa.start)/kappa.dt):
            return True, 'cert_invalid'
        if safety_veto(ev_exec):
            return True, 'safety_veto'
        dv_info = self.info_value_now(b)          # 新信息的决策价值增量
        v_remain = self.remaining_value(kappa, t, b)
        if dv_info > self.theta_int * max(v_remain, EPS):
            return True, 'info_gain'
        return False, None
```

### IP-192 CASE（主闭环）

```python
def case_step(M, obs, delta_f_req, t):
    # ---------- 语义/事件节拍（10-100Hz） ----------
    if M.event_pending(obs):
        a_info = UIO.choose(M.belief, M.aia, M.budget)
        if a_info is not None and a_info.is_probe:
            M.active_probe = start_probe(a_info)          # 物理探测分块
            M.budget.used['probe_time'] += a_info.time
            M.budget.used['probe_risk'] += a_info.risk
        elif a_info is not None and a_info.is_query:
            M.dms.emit_query(a_info)                      # 社会询问
            M.budget.used['queries'] += 1
            M.budget.used['attention'] += a_info.human_attention
        M.belief = M.aia.update(M.belief, obs)

    # 需要（重）发分块？
    need_new = (M.chunk is None
                or CIP.should_interrupt(M.chunk, M.belief, M.ev_exec, t)[0])
    if need_new:
        M.chunk = M.emitter.emit(M.belief, M.anchor, M.ev_ctx)
        M.bus.commit(M.anchor, M.chunk)
        M.budget.used['replan'] += 1

    # ---------- 实时节拍（1-10kHz） ----------
    a_t, status = M.tse.blend(M.active_chunks, t)
    if a_t is None:
        a_t = M.safe_set.conservative(M.anchor, t)        # 回退
    K_safe = EEIS.compile_with_chunk(delta_f_req, a_t, M.anchor.phys_prior)
    cert = ERTC.dispatch(K_safe)

    # ---------- 事件反馈 ----------
    M.ev_exec = wait_contact()
    revoke_on_evidence(M.chunk, M.ev_exec, t)
    M.usr.push_evidence(build_evidence(M.ev_exec))
    M.J_ac = build_joint_cert(M.chunk, M.anchor, M.ev_exec, cert,
                              M.belief, M.budget, M.last_info_action)
    return K_safe, M.ev_exec, M.J_ac
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| IAC | O(C·d_us) 生成 + O(C) 插值 | O(C·m) 每分块 | 分块前缀可执行；插值 C¹ 连续 |
| TSE | O(|J|·m)，|J| ≤ 窗口内分块数 | O(|J|·C·m) | 凸集内凸组合保安全（TSE-Safe） |
| CCC | O(C) | O(1) | 证书单调收紧，撤销只减不增 |
| CACP | O(1) 读写 | O(1) 共享内存 | 64 位代际单调、无跨代混合、无撕裂读 |
| AIA/UIO | O(|A_info|·采样数) | O(belief) | 风险硬上限；VOI<0 不选 |
| CIP | O(1) | O(1) | 中断只撤销未执行前缀，不改写历史 |
| AHC | O(C_max/C_step) | O(1) | 视界有界，退化有下界 |
| PCE-AC | O(1) | O(1) | 预算单调消耗，耗尽必降级且安全不退化 |

**正确性定理（CASE-Sound）**：在 A61–A70 与下列假设下：
- **(A71)** Σ_safe(t) 在每个 t 上是凸保守多面体，且真实安全阻抗集 ⊆ C_safe(t)（保守性）
- **(A72)** 分块证书可靠：`cert(κ)` 有效 ⇒ 在预测模型误差界内，前缀每个动作满足安全/平滑/力包络
- **(A73)** TSE 只混合同代际、凸权重、且每个参与分块在对应偏移处已认证
- **(A74)** VOI 估计器无偏或乐观有界；查询响应模型校准；探测满足 `risk≤R_max, F≤F_probe`
- **(A75)** CIP 单调：中断仅缩短承诺前缀，不修改已执行动作；代际 g 严格递增
- **(A76)** 预算单调消耗，降级优先保安全而非保性能

则：
1. **分块安全**：任意被执行的 `a_t` 要么是某认证前缀的插值，要么是凸集成；由 A71/A73 与 TSE-Safe 引理，`a_t ∈ C_safe(t)`，故执行阻抗在保守安全集内。
2. **平滑性**：分块内 C¹ 插值 + 跨块凸集成 ⇒ 边界处无位置/一阶导跳变；加加速度上界 `J_max` 由 CCC 强制，抖动有界。
3. **反应性**：最坏中断延迟 ≤ 一个实时周期 + 一次重规划；`θ_int→0` 时退化为逐帧反应，`θ_int→∞` 时退化为全分块开环，二者由 CIP 连续插值。
4. **信息效率**：AIA 永不选择 `VOI<0` 的信息动作；在平稳假设下，主动取证的累积遗憾不超过「纯被动 + 保守扩张」策略的遗憾（因后者等价于固定探测预算为 0）。VOI 门槛随剩余 `B_info` 单调升高。
5. **预算安全**：任一维耗尽触发对应降级；`B_info` 耗尽只影响信息获取速率，不影响安全；`B_chunk` 耗尽冻结长视界+保守扩张仍满足 A71。
6. **可审计**：`J_ac` 覆盖分块证书前缀、代际、VOI 决策、信息动作与中断原因，任一执行动作可回溯到「哪一块、哪一代、基于什么信息、是否中断」。

## 4. 实验设计 E201–E209

| 实验 | 指标 | 目标（vs 第 61 轮 ESEC） |
|---|---|---|
| E201 IAC | 阻抗轨迹抖动（jerk RMS）、跨块边界跳变 | jerk −50%；边界跳变 ≈ 0（C¹） |
| E202 TSE | 集成越界率、证书失效回退率、平滑度 | 越界率 = 0（凸集内）；回退率 ≤ 5% |
| E203 CCC/CACP | 证书前缀正确率、撤销及时性、代际冲突数 | 100% 正确；撤销延迟 ≤ 1 实时周期；冲突 = 0 |
| E204 AIA | VOI 选择后悔值、信息动作命中率 | 后悔值 ≤ 0.1×任务价值；命中率 ≥ 80% |
| E205 主动探测 | 摩擦/刚度估计误差下降、探测风险 | μ/k 误差再降 ≥ 20%；风险 ≤ 预算 |
| E206 主动询问 | 澄清轮次、任务完成率、打扰率 | 轮次 −30%；完成率 ≥ 95%；打扰率 ≤ 0.3 次/任务 |
| E207 CIP | 中断后恢复时间、无效中断率、平滑-反应曲线 | 恢复 ≤ 200ms；无效中断 ≤ 10% |
| E208 AHC | 视界自适应与不确定性的相关性、重规划频率 | ρ ≥ 0.7；重规划 ≤ 10 次/s |
| E209 端到端 | 抖动、零样本成功率、交互成本、安全违规 | 抖动 −50%；零样本 +20%；交互成本 −30%；违规 = 0% |

**关键消融**：
- **IAC 去掉分块**（退回单帧）→ 预期抖动显著上升，验证分块的时间一致性价值。
- **TSE 改为朴素平均**（不做凸集约束）→ 预期出现偶发越界/不安全集成，验证「凸集」是安全关键而非工程修饰。
- **AIA 退化为被动**（关闭探测与询问）→ 预期零样本误差与澄清轮次上升，验证主动取证的信息价值。
- **CIP 关闭**（不中断）→ 预期反应性下降、异常恢复变慢，验证中断是「主动性的时间出口」。

## 5. 本轮最大风险

**一句话**：时间集成会把「危险信号」一起平滑掉（跨分块平均可能掩盖突发滑移/力尖峰），而主动探测引入真实物理风险、主动询问又可能因 VOI 偏差而过度打扰或该问不问，因此最大风险是「系统很平滑、很自信、很有礼貌，却在关键时刻把危险平均成了安全」；必须以「凸认证安全集内集成 + 分块证书前缀硬约束 + 探测风险硬上限 + 安全否决优先于 VOI + 中断事件驱动」构建护栏，确保平滑与主动永不越过安全红线。
