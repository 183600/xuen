# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「长程任务」×「协同控制」）

> R69 把不确定性一分为二，并教会系统「问」：aleatoric 收紧、epistemic 去交互消解。但它藏着两个短视假设：**（时间上）只问「现在值不值得问」，不问「现在问还是以后问、会不会自己就清楚了」；（空间上）只问「我该怎么问世界」，不问「队友是不是早就知道、该由谁去问、问了会不会被队友的同一种偏见骗过」。**
>
> - **长程任务**把不确定性从「一次性开销」变成「跨时间的资产组合」：有的歧义会被未来观测免费消解（φ），有的会随世界漂移而**过期**（半衰期 τ），有的会**卡住很多下游决策**（因果杠杆 χ）。R69 的单步贪心 VoI 在这三者之间没有时间结构，必然在错误的时间花掉预算：要么过早承诺（本可以等它自己变清楚），要么无限拖延（直到安全裕度耗尽）。
> - **协同控制**把不确定性从「个体信念」变成「网络上的分布式证据」：最该被问的人往往不是最不确定的人；队友的动作是**免费观测**；而「k 个正交证据源」在共享观测、共享先验的团队里会退化成「k 个相关的回声」——**共识被误当成验证**。
>
> 核心命题：**把消歧从「单步贪心的一次性决策」升级为「长程、分布式的不确定性调度」——用 restless bandit / Whittle 指数给每个未解歧义排优先级（何时问），用协同信息图 + 分布式 VoI 决定问谁 / 告诉谁（问谁），用证据半衰期与独立性审计保证问到的是新鲜且真正正交的证据（信不信）。R69 是本轮在「单步、单智能体、源独立」边界上的严格退化。** 命名 **CONCERT-RAS**（Cooperative Non-myopic Calibrated Epistemic Resolution over Time）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**什么时候问、问谁、值不值得现在就知道**」——在长程与协同里，不确定性是一份要跨时间、跨队友调度的资产组合，而不是当下的一次性开销。

## 0. 直觉与动机

**灵感 1（长程 → 不确定性有时间结构）**
直觉：短跑时「看不清就停下来问」是对的；马拉松时这会让你永远跑不完。同一个歧义，在任务早期可能毫无影响（离决策还远、也许自己就清楚了），在临近决策时却致命；反过来，一个现在很急的歧义，可能三秒后摄像头一转就免费消失了。人类不是「随时问」，而是「在岔路口前问」——**消歧的时机本身是一个需要规划的量**。R69 的 MINT 只回答「此刻问不问」，缺少「此刻 vs 以后」的坐标系。

**灵感 2（免费信息 → 等待是有收益的）**
直觉：R69 的 VoI 只算「问了能降多少熵」，没算「不问、继续做，未来观测也会降熵」。在长程任务里，未来观测是免费的、且几乎总会到来。把免费信息折现掉之后，很多「现在看起来值钱的问题」其实应该等；把这种「等」显式建模，就得到**认知期权（epistemic option）**——「晚点再决定」的权利本身有价值。盲目贪心 = 提前行权 = 烧预算。

**灵感 3（过期 → 信息有半衰期）**
直觉：长程几乎必然非平稳：人换了意图、物体被挪动、队友换了策略。昨天问到的答案今天可能已经错了。R69 把交互结果当成永久事实写进后验；长程里这等于用**过期的证据**做**自信的决策**。所以每条证据都要带时间戳与半衰期，连证书也要会「过期」。这正好接上 R68「我的测量还准吗」——现在多问一句「**我的答案还新吗**」。

**灵感 4（协同 → 问谁比问什么更重要）**
直觉：在团队里，你最不确定的事，往往正是队友已经看见的事。R69 的 MINT 向「世界」提问；但更便宜、更准的做法是**向最互补的队友要**，或者干脆**观察队友的动作**（隐式信息）。于是分布式 VoI 变成一个匹配问题：谁有信息 × 谁需要信息 × 通道多快多可信。最该被问的不是最自信的队友，而是**与我最不相关（误差最正交）的队友**——自信但和我看同一个方向的人，只会复述我的偏见。

**灵感 5（回声室 → R69 的证据纪律在团队里会失效）**
直觉：R69 用「k 个正交源一致」对抗投毒，但它默认「不同源 ⇒ 独立」。在协同团队里，N 个智能体可能共享同一段观测、同一个预训练先验、同一个标定偏差——此时它们的一致**信息量为零**，却长着 N 张选票。更糟的是，幻影模态会沿信任边传播：一个智能体幻觉出的模态被第二个「确认」，再被第三个「确认」，长程里滚成一场**集体幻觉**。所以本轮必须把「正交」从「来源不同」改写成「**因果独立**」，并给出幻影传播的遏制条件。

**灵感 6（三层统一 → 时间、空间、证据都是「信息预算分配」）**
直觉：把上述五条压成一句话——**长程问「何时花」，协同问「向谁花」，独立性问「花得值不值」**。三者其实是同一个资源分配问题的三个坐标轴：时间轴（何时）、网络轴（向谁）、可信轴（是否独立）。这解释了为什么本轮不是给 R69 打补丁，而是换了一个更一般的目标函数：R69 是它在 T=1、N=1、κ=0 上的截面。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（CONCERT-RAS 总览）** CONCERT-RAS = (FMP, HUD, DOS, CIG, DVA, EID, ICA, RAS-WM‡)。五不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **联合预算守恒**：整个时域内信息动作总量 ≤ B、通信总量 ≤ C，按 token-bucket 摊销，单位时间仍 ≤ 1 次；
(iii) **独立性纪律**：团队共识只统计**因果独立**的证据源，共享观测/共享先验的一致不计票（定义 320）；
(iv) **无悬崖延迟**：任何被推迟的决策，在未来每个时刻都必须保留可行的安全回退（定义 326）；
(v) **来源与时效**：每条证据携带 `(source, t_obs, τ)`，过期证据不得当作新鲜证据使用（定义 319）。

**定义 311（长程任务与信念状态）** 时域 T、折扣 γ，回报 J = Σ_{t=0}^{T} γ^t r_t。信念 b_t = (p(z_t), {U_epi,k(t)}, {age_k(t)})。扩充动作 ξ = (a, g, μ) ∈ 𝒜_task × 𝒜_info × ℳ，其中 μ 为对外消息（提问 / 告知 / 广播）。策略 π_θ(ξ_{t:t+H} | b_t)，H 为规划视界（H ≤ T）。

**定义 312（不确定性时间演化 HUD）** 对每个未解歧义 k，其认知状态沿标称计划演化：
U_epi,k(t+1) = (1 − φ_k(t))·U_epi,k(t) + η_k(t) − ζ_k(t)，
其中 φ_k 为**免费消解率**（未来计划内观测带来的熵降比例），η_k ≥ 0 为**漂移注入**（非平稳世界新增的歧义），ζ_k 为主动交互带来的消解。记免费信息算子 Φ_free 与漂移算子 D_drift，HUD 输出预测 `Û_epi,k(t'|b_t, plan)` 及其置信区间。

**定义 313（认知期权与延迟价值）** 对歧义 k，令 V_now 为立即消歧后的期望长程回报，V_wait 为推迟到下一个自然决策点（期间接受免费信息）后的期望回报。**认知期权值** OV_k(t) = V_wait − V_now。这是一个最优停止问题：当且仅当 OV_k(t) > 0 时，推迟严格更优。R69 的贪心隐含假设 OV ≡ 0。

**定义 314（任务相关歧义与因果杠杆）** 只关心会改变行动的那部分歧义：U_epi^task = 限制在「至少存在一个下游决策，其 argmax 动作随模态身份改变」的子空间。**因果杠杆** χ_k(t) = Σ_{t'>t} γ^{t'−t} · P(决策 t' 的最优动作依赖 M_k)。高 χ 的歧义应在**它卡住第一个下游决策之前**解决；低 χ 的歧义即使熵很高也可以不管。

**定义 315（非短视消歧调度 DOS）** 调度 σ = {(g_i, t_i)}，目标为在联合预算与安全约束下最大化期望长程回报。实现为**restless multi-armed bandit**：每个未解歧义是一支臂，其状态 U_epi,k 即使不被选择也随 HUD 演化（免费消解 + 漂移）；「拉臂」= 执行信息动作 g_k，成本 c_k，收益为 χ_k 加权的长程损失下降。用 **Whittle 指数** W_k(t) 排序，在预算内选指数最高者；可证明（在 indexability 下）该策略对松弛问题最优、对原问题近似最优。**R69 的 MINT 恰为「只看即时收益、令 φ=η=χ=常数、H=1」的退化特例。**

**定义 316（协同信息图 CIG）** 团队图 G = (V, E)，V 为 N 个智能体，边 (i,j) 带四元属性：(ℓ_ij 时延, b_ij 带宽, ρ_ij 可信度, κ_ij 因果重叠)。每个智能体持有私有信念 b_t^i 与私有证据集 ℰ_i。CIG 是 DVA 与 ICA 的共同输入；κ_ij 由「共享观测 / 共享先验 / 共享标定偏差」估计。

**定义 317（分布式信息价值分配 DVA）** 消息 i→j 关于歧义 k 的净价值：
VoI_net(i→j,k) = ΔH_epi,k^team(i→j) − c_comm(ℓ_ij, b_ij)，
其中 ΔH 必须按**有效独立源数** k_eff（定义 320）计入，不能按发送者数量计。分配解一个带预算与截止期的最大权匹配 / 拍卖：
max_{x} Σ_{i,j,k} x_{ijk}·VoI_net(i→j,k)，s.t. 每智能体发送/接收预算、ℓ_ij ≤ deadline_k。
准则：**问最互补（κ 最小）的队友，而不是最自信的队友**。

**定义 318（隐式协同证据）** 队友动作 a_j(t) 是「其信念 + 其策略」的一次观测：p(a_j | b_j, π_j)。它提供**免费信息**，但被策略混淆——只有当 π_j 已知/可建模时才可解码；否则只能作为弱证据（低权重、低独立性），不得与显式回答合并成「两个源」。

**定义 319（证据半衰期 EID）** 证据 e 在 t 时刻的权重 w_e(t) = exp(−(t − t_e)/τ_k)。半衰期 τ_{1/2,k} = τ_k·ln2。证书各分量（尤其 ECE 与模态权重校准）也带到期时间；过期即失效。最优重查节奏见引理 22。

**定义 320（因果独立与回声室判据）** 两源因果独立当且仅当 κ_ij < κ_max。N 个源的有效独立数用**有效样本量**：
k_eff = (Σ_i w_i)² / (Σ_i Σ_j w_i w_j κ_ij)，其中 κ_ii = 1。
团队共识按 k_eff 计票，而非按 N 计票。**回声室极限**：κ→1 ⇒ k_eff→1 ⇒ 共识信息量为零；这正是 R69 引理 18 在「共享观测团队」上的失效点，也是本轮必须显式建模的漏洞。

**定义 321（幻影模态传播 PPC）** 单位暴露的感染概率 β = δ_p·ρ·(1 − κ_cut)，有效再生数 R_ph = β·⟨out-degree⟩。R_ph ≥ 1 ⇒ 幻影模态可在团队内流行；遏制条件 R_ph < 1，或由 ICA 切断 κ > κ_max 的边 + 强制 provenance 标签。长程下幻影会沿时间与网络二维传播，故 R_ph 需按「时空接触率」计算。

**定义 322（协同安全证书 J_CONCERT）** J_CONCERT = (J_FLUID, schedule_hash, budget_ledger, k_eff_consensus, evidence_expiry_set, deferral_margin, phantom_R, concert_ver)。Valid ⇔ Valid(J_FLUID) ∧ 预算未越界 ∧ k_eff 达到证据纪律阈值 ∧ 无过期证据被当新鲜证据 ∧ 延迟裕度恒正 ∧ R_ph < 1。

**定义 323（长程协同审计 VQAuditor-H）** 新增审计项：**时机**（是否该早问却拖了 / 是否该等却抢跑）、**对象**（问的人是否足够互补、是否被最自信者垄断）、**独立性**（是否把相关源当独立）、**时效**（是否用了过期答案）、**传播**（是否追问了幻影、幻影是否沿信任边扩散）。结论回灌 DOS 的指数先验与 DVA 的成本表。

**定义 324（层叠严格包含与回溯阶梯）** 失效时逐级回退：
CONCERT —(HUD 不可信 / 预算耗尽 / 独立性破裂)→ FLUID —(VoI ≤ 成本 / ECE 越界)→ CALM —(标定失败)→ 纯保守。
每一级在其退化边界上**逐指令相同**；安全侧单调不弱，效率侧才拿增量收益。这把 R68–R70 组织成一个可证明的包含塔，而不是三个并列黑箱。

**定义 325（联合预算守恒与通信节流 BCT）** 总信息预算 B、通信预算 C 按 token-bucket 摊销；单位时间硬上限仍 ≤ 1 次信息动作，但允许在关键岔路口前「攒着用」。高 χ 的歧义优先占用额度；低价值广播被节流，防止 gossip storm 耗尽带宽与信任。

**定义 326（联合安全包络与延迟裕度 TSE）** 团队安全集 S_team，延迟裕度
m_t = dist(b_t, ∂S_team) − max_{t'∈[t, t+H]} worst-case drift bound(t,t')。
仅当整个视界内 m_t > 0 才允许推迟；若 m_t 触零，必须就地消歧或回退到 FLUID/CALM 的保守动作。这给出「等」的硬边界，直接回应「无限拖延」风险。

```python
# IP-264 HUD：不确定性时间演化（免费信息 + 漂移）
def hud_forecast(b_t, plan, H):
    U = b_t.U_epi.copy()
    traj = []
    for t in range(H):
        phi = free_resolution_rate(plan[t], b_t)       # 未来观测带来的熵降比例
        eta = drift_bound(b_t, t)                       # 非平稳注入（上界）
        U   = (1 - phi) * U + eta
        traj.append(U)
    return traj                                        # Û_epi(t'|b_t), 单调性由 phi,eta 保证

# IP-265 DOS：restless bandit + Whittle 指数（贪心 MINT 是 H=1 特例）
def whittle_schedule(arms, budget, H):
    order = []
    for t in range(H):
        idx = [whittle_index(arm, t) for arm in arms]  # χ 加权收益 / 成本，含 φ,η,γ
        order.append(sorted(range(len(arms)), key=lambda k: -idx[k]))
        arms = [hud_step(arm) for arm in arms]         # 不拉也演化（restless）
    return allocate_under_budget(order, budget)        # token-bucket 摊销

# IP-266/269 CIG + 独立性审计：有效源数
def effective_sources(weights, kappa):                 # kappa_ii = 1
    S = sum(weights)
    return S * S / sum(w_i * w_j * kappa[i][j]
                       for i, w_i in enumerate(weights)
                       for j, w_j in enumerate(weights))

def is_orthogonal(consensus, kappa_max):
    return effective_sources(consensus.w, consensus.kappa) >= consensus.k_required

# IP-267 DVA：问最互补的队友（最大权匹配，不是问最自信的）
def allocate_messages(agents, target_modes, budget, deadline):
    edges = []
    for i in agents:
        for j in agents:
            if i == j or latency[i][j] > deadline: continue
            for k in target_modes:
                voi = info_gain(target_modes[k], ask=i, tell=j)
                voi *= (1 - overlap[i][j])              # 越独立越值钱
                edges.append((voi - comm_cost(i, j), (i, j, k)))
    return max_weight_matching(edges, budget)           # 每智能体收发预算

# IP-268 EID：证据衰减 + 证书到期
def evidence_weight(evidence, t):
    return exp(-(t - evidence.t_obs) / evidence.tau)

def filter_fresh(evidence_set, t, tau_expire):
    return [e for e in evidence_set if t - e.t_obs < tau_expire[e.kind]]

# IP-270 PPC：幻影传播遏制
def phantom_reproduction(delta_p, trust, overlap, out_deg, kappa_cut):
    beta = delta_p * trust * (1 - kappa_cut)
    return beta * out_deg                             # R_ph < 1 才允许交互式追问

# IP-277 主闭环（继承 R69，替换「何时/向谁」两层）
def CONCERT_RAS_round(M, b_t):
    # 1) 短视层先做一次廉价判定（R69 原样，作为下界）
    modes, U_ale, U_epi = M.fluid.perceive(b_t)        # FMP + AUD
    # 2) 长程层：给每个未解歧义算时间结构
    arms = [make_arm(k, U_epi[k], chi=M.causal_reach(k, b_t),
                     phi=M.hud.free_rate(k), eta=M.hud.drift(k))
            for k in unresolved(U_epi)]
    schedule = M.dos.whittle_schedule(arms, M.budget, M.horizon)
    # 3) 协同层：问谁 / 告诉谁（独立性优先）
    msgs = M.dva.allocate(arms, M.cig, M.budget, M.deadline)
    # 4) 独立性与时效门（R69 的证据纪律在这里被加强）
    if not M.ica.is_orthogonal(msgs.consensus, M.kappa_max) \
       or not M.eid.fresh(msgs.evidence, M.now):
        schedule = M.fluid.fallback(schedule)          # 退化 FLUID / CALM
    # 5) 延迟安全：无悬崖
    if M.tse.deferral_margin(b_t, M.horizon) <= 0:
        schedule = resolve_now(schedule)               # 就地消歧或保守
    # 6) 执行 + 幻影遏制 + 审计
    if M.ppc.reproduction(msgs) >= 1.0:
        Msgs = block_broadcast(msgs)
    mode = M.fluid.select_mode(modes, U_epi, M.lam)
    M.auditor_h.submit(schedule, msgs, b_t)
    return mode, schedule
```

## 3. 推导

**假设 A99–A102**：A99 世界漂移 Lipschitz 有界（HUD 预测误差有界）；A100 通信时延有界、图最终连通；A101 独立性 κ 可估且估计误差有界；A102 任务损失对模态身份 Lipschitz，因果杠杆 χ 可计算。

**引理 19（短视 VoI 的次优性下界）** 存在长程任务实例，使 R69 的单步贪心调度相对最优调度的期望回报差
Regret_greedy ≥ max{ φ·c·N_amb , (1−γ^{D})/(1−γ)·Δ_min·(1−e^{−ΔH}) }。
第一项来自「本可免费消解却提前付费」（免费信息被浪费），第二项来自「该早解却拖延导致下游连锁损失」（因果杠杆被忽略）。系：**只有当 φ→0、χ 与所有下游解耦、且 T=1 时，贪心才无损失**——这正是 R69 的适用域。

**引理 20（延迟安全的可行性判据）** 在 A99 下，若对调度视界内每个可达 t' 都有 m_{t'} > 0（定义 326），则推迟决策不使状态逸出安全集 S_team；反之若 ∃t' 使 m_{t'} ≤ 0，则必须在该时刻前消歧或回退。证明：对 S_team 的可行性核（viability kernel）取最坏漂移下的前向可达集，m 恰为其到边界的距离；m>0 等价于存在保持安全的策略，m≤0 时任何策略都可能在 t' 前触界。

**引理 21（相关源共识的错误上界）** 设单源欺骗率 δ_p、有效独立源数 k_eff（定义 320）、各源平均误差相关 ρ = 1 − 1/k_eff。k_eff 源多数一致后的错误采纳率
P_err ≤ δ_p·ρ^{k_eff−1} + ε_σ = δ_p·(1 − 1/k_eff)^{k_eff−1} + ε_σ。
当 κ→1（共享观测 / 共享先验）时 k_eff→1，右端退回 δ_p——**团队共识不提供任何抗投毒增益**；当 κ→0 时 k_eff→N，恢复 R69 引理 18。系：**「换个队友问」在相关源上等价于「问同一个人第二遍」**。

**引理 22（信息半衰期与最优重查节奏）** 设证据价值随时间按 v(t) = v_0·e^{−t/τ} 衰减、单次查询成本 c。最优重查间隔
s* = τ·ln(1 + v_0·τ/c) = τ·ln(v_0·τ/c) + O(c/(v_0τ))。
即 s* 随半衰期 τ 单调增、随查询成本 c 单调减。系：长程预算应按「各歧义的 τ_k / c_k」做注水式分配，而非平均摊派。

**定理 18（三层严格包含：CALM ⊂ FLUID ⊂ CONCERT）** 在 A99–A102 下，任意状态上
E[Risk_CONCERT] ≤ E[Risk_FLUID] ≤ E[Risk_CALM]；
且当 HUD 不可信 / 预算耗尽 / 独立性破裂时 CONCERT 与 FLUID 逐指令相同；当 VoI ≤ c 或 ECE 越界时 FLUID 与 CALM 逐指令相同。因此 R68、R69 分别是本轮在「不调度」「不协同」边界上的严格退化，安全侧不做任何让步。

**定理 19（幻影模态的遏制）** 若 ICA 切断所有 κ > κ_max 的边、要求 provenance 且 R_ph < 1，则幻影模态在团队内的期望感染规模 ≤ 1/(1 − R_ph)，且不会经由「确认」回环自我强化。当 R_ph ≥ 1 时，幻影可在长程内覆盖整个连通分量——故 R_ph < 1 必须写进证书的 Valid 条件。

**定理 20（长程协同安全与无突变）** 调度与通信只改变「何时、向谁获取证据」，不改变底层安全包络；延迟由引理 20 的可行性核保证；独立性/时效/R_ph 任一失败时，λ 沿定义 324 的阶梯**单调不降**地回退到 FLUID/CALM；R68 的提交/换装不变式（定理 15）在每一级保持 ⇒ 控制连续、无突变。

## 6. 本轮最大风险

**一句话**：CONCERT-RAS 的全部收益押在两张「地图」是真的——HUD 对「未来会免费知道多少」的预测、以及 CIG 对「谁与谁因果独立」的估计；**若系统高估免费信息，它会把决策无限期往后拖（procrastination），直到安全裕度耗尽；若它把共享同一观测/先验的队友误判为独立源（k_eff 虚高），团队共识就会把一个共同的歧义盖章成「已被 N 个源验证」，而长程复合会把这一次错误滚成整条任务链的自信错误——共识被误当成验证，比一个人犯错更难纠正。**

**次级风险与缓解**：
1. **非平稳漂移快于证据更新** → EID 半衰期 + 证书到期 + 引理 22 的重查节奏；
2. **HUD 过度乐观导致拖延** → 定义 326 的延迟裕度硬门 + 引理 20 可行性核；
3. **回声室 / 相关源被当独立** → 定义 320 的 k_eff 计票 + ICA 切断 + E306；
4. **幻影沿信任边传播** → 定义 321 的 R_ph<1 写进证书 + provenance + 定理 19；
5. **通信预算被 gossip 击穿** → 定义 325 token-bucket 节流 + 高 χ 优先 + E311；
6. **协同带来的责任稀释**（谁都以为别人会查）→ VQAuditor-H 审计「时机/对象/独立性」并回灌调度先验。

```python
# IP-264 HUD：不确定性时间演化
def hud_forecast(b_t, plan, H):
    U, traj = b_t.U_epi.copy(), []
    for t in range(H):
        U = (1 - free_resolution_rate(plan[t], b_t)) * U + drift_bound(b_t, t)
        traj.append(U)                                  # Û_epi(t'|b_t)

# IP-265 DOS：Whittle 指数调度（R69 贪心 = H=1 特例）
def whittle_schedule(arms, budget, H):
    order = []
    for t in range(H):
        idx = [whittle_index(a, t) for a in arms]       # χ 加权收益/成本，含 φ,η,γ
        order.append(sorted(range(len(arms)), key=lambda k: -idx[k]))
        arms = [hud_step(a) for a in arms]              # restless：不拉也演化
    return allocate_under_budget(order, budget)

# IP-269 ICA：有效独立源数（回声室判据）
def effective_sources(w, kappa):                        # kappa_ii = 1
    S = sum(w)
    return S*S / sum(w[i]*w[j]*kappa[i][j]
                     for i in range(len(w)) for j in range(len(w)))

# IP-267 DVA：问最互补的队友
def allocate_messages(agents, modes, budget, deadline):
    edges = [(info_gain(modes[k], i, j)*(1-overlap[i][j]) - comm_cost(i,j), (i,j,k))
             for i in agents for j in agents if i != j
             and latency[i][j] <= deadline for k in modes]
    return max_weight_matching(edges, budget)

# IP-268 EID：证据衰减 + 过期过滤
def filter_fresh(evidence, t, tau_expire):
    return [e for e in evidence if t - e.t_obs < tau_expire[e.kind]]

def phantom_reproduction(delta_p, trust, overlap, out_deg, kappa_cut):
    return delta_p * trust * (1 - kappa_cut) * out_deg    # R_ph < 1 才追问
```

## 4. 推导

**假设 A99–A102**：世界漂移 Lipschitz 有界；通信时延有界、图最终连通；独立性 κ 可估且误差有界；任务损失对模态 Lipschitz、因果杠杆可计算。

**引理 19（短视 VoI 的次优性下界）** 存在实例使 `Regret_greedy ≥ max{φ·c·N_amb, (1−γ^D)/(1−γ)·Δ_min·(1−e^{−ΔH})}`。第一项是「本可免费消解却提前付费」，第二项是「该早解却拖延导致下游连锁损失」。系：只有 φ→0、χ 与下游解耦、T=1 时贪心无损——正是 R69 的适用域。

**引理 20（延迟安全的可行性判据）** A99 下，若视界内每个可达 t' 都有 `m_{t'}>0`，则推迟不逸出 S_team；若存在 `m_{t'}≤0`，必须在该时刻前消歧或回退。证明：对 S_team 的可行性核取最坏漂移下的前向可达集，m 为其到边界的距离。

**引理 21（相关源共识的错误上界）** 单源欺骗率 δ_p、有效独立源数 k_eff、平均相关 ρ=1−1/k_eff 时，多数一致后的错误率 `P_err ≤ δ_p·(1−1/k_eff)^{k_eff−1}+ε_σ`。κ→1 ⇒ k_eff→1 ⇒ 退回 δ_p（团队共识零增益）；κ→0 ⇒ 恢复 R69 引理 18。系：「换个队友问」在相关源上等价于「问同一个人第二遍」。

**引理 22（半衰期与最优重查节奏）** 证据价值 `v(t)=v_0 e^{−t/τ}`、查询成本 c 时，最优重查间隔 `s* = τ ln(1+v_0τ/c) ≈ τ ln(v_0τ/c)`；随 τ 单调增、随 c 单调减。系：长程预算按各歧义 τ_k/c_k 注水式分配，而非平均摊派。

**定理 18（三层严格包含：CALM ⊂ FLUID ⊂ CONCERT）** A99–A102 下 `E[Risk_CONCERT] ≤ E[Risk_FLUID] ≤ E[Risk_CALM]`；HUD 不可信/预算耗尽/独立性破裂时 CONCERT 与 FLUID 逐指令相同；VoI≤c 或 ECE 越界时 FLUID 与 CALM 逐指令相同。R68、R69 是本轮在「不调度」「不协同」边界上的严格退化。

**定理 19（幻影遏制）** ICA 切断 κ>κ_max、要求 provenance 且 R_ph<1 时，期望感染规模 ≤ `1/(1−R_ph)`，且不会经「确认」回环自我强化；R_ph≥1 时长程内可覆盖整个连通分量，故 R_ph<1 必须写进证书。

**定理 20（长程协同安全与无突变）** 调度与通信只改「何时、向谁取证据」，不改安全包络；延迟由引理 20 保障；独立性/时效/R_ph 任一失败时 λ 沿阶梯单调不降地回退；R68 提交/换装不变式每级保持 ⇒ 控制连续、无突变。

## 7. 本轮最大风险

**一句话**：CONCERT-RAS 的全部收益押在两张「地图」是真的——HUD 对「未来会免费知道多少」的预测、以及 CIG 对「谁与谁因果独立」的估计；**若系统高估免费信息，它会把决策无限期往后拖（procrastination）直到安全裕度耗尽；若它把共享同一观测/先验的队友误判为独立源（k_eff 虚高），团队共识就会把一个共同的歧义盖章成「已被 N 个源验证」，而长程复合会把这一次错误滚成整条任务链的自信错误——共识被误当成验证，比一个人犯错更难纠正。**

**次级风险与缓解**：非平稳漂移快于证据更新（EID + 证书到期 + 引理 22 重查节奏）；HUD 过度乐观导致拖延（TSE 延迟裕度硬门 + 引理 20 可行性核）；回声室/相关源被当独立（k_eff 计票 + ICA 切断 + E306）；幻影沿信任边传播（R_ph<1 写进证书 + provenance + 定理 19）；通信预算被 gossip 击穿（BCT 节流 + 高 χ 优先 + E311）；协同责任稀释（VQAuditor-H 审计并回灌先验）。
