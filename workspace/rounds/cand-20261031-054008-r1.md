# 第 13 轮（新循环第 1 轮）· STAF-SERVO：把 CHUNK-SERVO 的“单帧目标 + 固定增益”升级为“时空融合 + 风险感知 + 接触关键微调”

> 检索/复核日期：**2026-10-31（UTC）**。赛事身份不变：宇树 **UniBot 世界挑战赛**（unibot.unitree.com），G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API。本轮是新灵感循环第 1 轮，研究线承接第 10 轮 FACT-VLA、第 11 轮 GEO-RESIDUAL、第 12 轮 CHUNK-SERVO。三个灵感词是「微调」「传感器融合」「时空推理」。本轮不推倒 CHUNK-SERVO 的“30 步规划 + 5 步伺服”，而是补它最薄的一层：**CHUNK-SERVO 把反馈周期从 1 秒降到 167 毫秒，但没有回答“这 167 毫秒里看到的目标到底有多可信、延迟多少、下一帧会不会变”。**

## 0. 先给结论：反馈频率不是全部，反馈质量才是下一层瓶颈

第 12 轮的诊断是对的：30 步开环 chunk 让接触发生在“看不见”的 1 秒里；把 chunk 切成 5 步，确实能把最后 3 厘米纳入闭环。但第 12 轮的伺服有一个隐含假设：**每一帧都能给出一个可信的目标位姿，而且这个位姿的噪声、延迟和模态切换可以用固定增益和硬阈值处理。**

这个假设在真实系统里不成立：

1. **头双目在 0.5–1.0 m 的深度噪声是毫米到厘米级。** 基线 58.25 mm、焦距约 282 px；1 px 视差在 0.5 m 处约 15.2 mm，在 1.0 m 处约 60.8 mm。最后 2 mm 的插入，靠头双目单独看深度不够。
2. **腕部 color 其实有内参。** 第 12 轮写“腕部没有内参”是错的；本轮复核 HangCup 的 `meta/info.json`，左腕 color 的 `fx≈436.41`、`fy≈435.92`、`cx≈323.92`、`cy≈242.93`，还有 inverse Brown-Conrady 畸变。真正缺的是**腕部相机到 EE 的手眼外参**，需要一次性标定。腕部近距横向分辨率远高于头双目（0.1 m 处 1 px≈0.23 mm），但单目深度不可观，必须和头双目/本体运动融合。
3. **三路信息是异步、异频、异噪声的。** 头双目给全局位姿但可能被手臂挡；腕部给高分辨率局部但可能被夹爪挡；本体给精确 EE 位姿和运动，但不给物体状态。第 12 轮用“远 PBVS、近 IBVS”的硬切换，等于把一个多传感器估计问题降级成“选一个模态”。
4. **固定增益在延迟下要么振荡、要么迟钝。** 第 12 轮已经意识到 RTT 会吃掉增益裕度，但只用 Smith 预测和降档做补丁；没有把“目标速度”和“估计协方差”显式建模。
5. **微调是第 12 轮唯一没有真正展开的学习层。** 33k 演示里，接触前后几帧只占很小比例；均匀采样会让 action head 把大部分容量花在自由空间，而最后 3 厘米的样本被淹没。微调应该“把算力花在接触上”，而不是“把所有帧一视同仁”。

所以本轮的押注是 **STAF-SERVO**（Spatio-Temporal Adaptive Fusion for Servo）：

> **用一个固定窗口的 SE(3) 因子图，把头部双目位姿、腕部 2D 特征、本体 EE 位姿和抓持约束融合成带协方差的时空状态；用这个协方差同时做三件事：模态加权（自动从 PBVS 过渡到 IBVS）、风险感知的增益/限幅、以及延迟预测；用 NIS/CUSUM 在残差序列上检测接触、滑移和人为编辑；最后用同一套融合状态离线标注 33k 演示的“接触关键窗口”，对官方 WLA 的 action head 做加权微调 + 时间一致性正则。全程只有一个学习模型；融合器和控制器都是确定性算法。**

三个可验证创新点：

1. **STAF 估计器**：固定窗口 SE(3) 因子图 + 鲁棒核 + 协方差调度；用后验协方差自动决定“信头还是信腕”，替代第 12 轮的硬切换。验证：G0–G2。
2. **风险感知伺服 + 时空变化点**：机会约束限幅、基于目标速度的延迟预测、NIS/CUSUM 接触-滑移-编辑检测。验证：G3–G5。
3. **接触关键微调**：用融合状态给演示帧打“接触关键性”权重，加权流匹配 + 目标相对轨迹的时间一致性正则；同一 checkpoint、同一推理图。验证：G6/G9。

三个灵感词怎么落到方案里：

| 灵感词 | 落到哪里 | 不做什么 |
|---|---|---|
| **传感器融合** | 头双目位姿 + 腕部 2D 特征 + 本体 EE + 抓持约束的 SE(3) 因子图；协方差调度自动加权；单目深度不可观时显式膨胀协方差 | 不训多模态大模型；不做像素级深度融合；不假设腕部有手眼外参 |
| **时空推理** | 恒速 SE(3) 运动模型 + 固定窗口平滑；延迟 τ 的位姿/协方差预测；NIS/CUSUM 接触-滑移-编辑检测；计划-状态时间一致性监控 | 不做完整 TAMP；不做世界模型视频预测；不做 30Hz 广域网高增益 |
| **微调** | 用融合状态离线标接触关键帧；加权流匹配 + 时间一致性正则；传感器 dropout 增强；任务平衡采样 | 不训第二个模型；不改推理架构；不做逐任务策略；不在测试时在线学习 |

## 1. 这轮怎么想：三个词是一条因果链

### 1.1 传感器融合：不是“多一路输入”，而是“让每一路带着自己的不确定性说话”

第 12 轮的 PBVS/IBVS 切换有一个物理直觉：远距离看全局，近距离看局部。这个直觉没有错，但实现方式太硬——用一个距离阈值决定“现在信谁”，等于假设两路传感器的误差是二值的：要么可信，要么不可信。

真实的误差是连续的、各向异性的：

- 头双目的深度误差随 `Z²` 增长，横向误差随 `Z` 增长；在 0.5 m 处深度可能差 5–15 mm，但横向只有约 1–2 mm。
- 腕部相机的横向误差在 0.1 m 处约 0.2 mm/px，但它对深度几乎不可观；一旦目标被夹爪挡住，整路失效。
- 本体 EE 位姿很准，但它只告诉你“手在哪”，不告诉你“目标在哪”；只有在抓持约束成立时，它才间接给出目标状态。

所以正确的做法不是“选模态”，而是**把每一路的测量写成带协方差的因子，放进同一个状态估计里**。当双目深度因子变弱，腕部横向因子自然占主导；当腕部被挡，它的因子被门控掉，双目和运动模型接管。切换不是 `if distance < d_c`，而是后验协方差在某个方向上的相对大小。这就是本轮的 STAF 估计器。

### 1.2 时空推理：不是“加一个 LSTM”，而是“残差序列本身就是信号”

第 12 轮用 `d_t`、`r_static`、`r_grasp`、`edit_score` 做接触/编辑检测。这些量有物理意义，但阈值是手调的，而且只看当前帧。接触是一个**时间事件**：目标从“独立运动”切换到“跟随夹爪”，这个切换会在残差序列里留下持续的特征，而不是某一帧的瞬时值。

所以本轮把检测做成**变化点检测**：

- 用归一化新息平方（NIS）监控“测量是否还符合模型”；
- 用 CUSUM 累积“持续偏离”，而不是单帧阈值；
- 用“自由运动 vs 刚性抓持”两个假设的似然比检测接触；
- 用目标速度做 `τ` 步预测，补偿 RTT；
- 用 VLA 计划隐含的目标相对轨迹和融合状态做一致性检查，发现“计划以为到了、世界说没到”。

这仍然是确定性的，不需要第二个学习模型。它把第 12 轮的“接触相位”从手工标签升级成可检验的统计决策。

### 1.3 微调：不是“再训一遍”，而是“把容量花在接触上”

第 12 轮说要用官方 WLA 做 action-head 微调，但没有说怎么选数据。33k 演示、18.28M 帧里，真正决定成败的是接触前后的一小段：插入、挂、叠、拉链、拧盖。均匀采样会让这些帧被自由空间的帧淹没。

本轮用 STAF 估计器离线跑一遍演示，得到每个时刻的：

- 接触/预接触标签；
- 目标到夹爪的距离 `d_t`；
- 融合协方差 `Σ_t`（哪些帧的估计不可靠）；
- 模态健康度（腕部是否可见、双目是否有效）。

然后给微调样本加权：接触窗口、近距离、高不确定性、模态退化的帧权重更高；每个任务内部归一化，避免长任务主导。损失仍然是官方 action head 的流匹配/去噪目标，只把权重乘进去；再加一个**时间一致性正则**：预测的 5 步 EE 轨迹应该与融合状态给出的“目标相对轨迹”一致。这个正则只在训练时用，不改推理图。

这就是「微调」这个词的落点：不是换模型，而是**用传感器融合和时空推理的产物，决定微调看哪些帧、信哪些帧**。

### 1.4 为什么是现在：三个事实让这条链可行

1. **腕部内参可用**（本轮复核）：`K_W` 已知，2D 特征可以反投影；缺的只是手眼 `T_EW`，一次标定可解决。
2. **官方 WLA 支持 action-head 微调**（第 12 轮已核实）：冻结 VLM，单张 24GB GPU 可跑；我们只改数据权重和辅助损失，不改推理架构。
3. **5 步 chunk 的 167 ms 预算足够**：因子图在 K=8、12 维状态/节点下是亚毫秒到毫秒级；特征提取是大头，但仍远小于 167 ms。融合不会吃掉伺服的预算。

## 2. 严谨形式化

### 2.1 符号

| 符号 | 含义 |
|---|---|
| `B, T, E, H, W` | base、目标、EE、头左目、腕部相机坐标系 |
| `X_t = T_BT(t) ∈ SE(3)` | 目标在 base 系的位姿 |
| `V_t ∈ R^6` | 目标体坐标系速度（twist） |
| `Y_t = T_BE(t)` | 本体给的 EE 位姿 |
| `G = T_TE*` | 从成功演示检索的“目标→EE”相对目标 |
| `z_t^H ∈ SE(3)` | 头双目估计的目标位姿 |
| `z_t^W ∈ R^{2m}` | 腕部 `m` 个特征点的像素 |
| `p_T ∈ R^3` | 目标上的已知特征点（来自演示/模型） |
| `T_EW` | 腕部相机在 EE 系的外参（手眼，待标定） |
| `K_W` | 腕部 color 内参（已知） |
| `Σ_t ∈ R^{6×6}` | `X_t` 的后验协方差 |
| `τ` | 端到端延迟（RTT + 推理 + 图像） |
| `H_c, f_c` | chunk 步数、控制频率；默认 5、30 Hz |
| `w_t` | 微调样本权重 |
| `c_t` | 接触关键性分数 |

### 2.2 状态与因子图

状态序列 `χ = {X_i, V_i}_{i=t-K+1}^t`。固定窗口 MAP：

```math
\begin{aligned}
J(\chi)=&
\left\|\log(\hat X_{t-K+1}^{-1}X_{t-K+1})\right\|^2_{P_{t-K+1}}
+
\left\|V_{t-K+1}-\hat V_{t-K+1}\right\|^2_{P_v} \\
&+\sum_{i=t-K+1}^{t-1}
\left[
\left\|\log\left((X_i\exp(V_i\Delta t))^{-1}X_{i+1}\right)\right\|^2_{Q_x}
+
\left\|V_{i+1}-(1-\alpha)V_i\right\|^2_{Q_v}
\right] \\
&+\sum_{i\in\mathcal H}\rho\left(\left\|\log\left((z_i^H)^{-1}X_i\right)\right\|^2_{R_H}\right) \\
&+\sum_{i\in\mathcal W}\rho\left(\left\|\pi\left(K_WT_{EW}^{-1}Y_i^{-1}X_i p_T\right)-z_i^W\right\|^2_{R_W}\right) \\
&+\mathbf 1[\text{attached}]\sum_i
\rho\left(\left\|\log\left(C^{-1}Y_i^{-1}X_i\right)\right\|^2_{R_c}\right).
\end{aligned}
```

其中 `ρ` 是 Huber 鲁棒核；`C = Y_c^{-1}X_c` 是接触时刻估计的“EE→目标”刚性偏移。`α ∈ [0,1]` 是速度阻尼：目标静止时 `α→1`，运动时 `α→0`。

**输出**：窗口最新状态 `X̂_t`、`V̂_t`，以及其 6×6 边缘协方差 `Σ_t`。

### 2.3 协方差调度：自动的 PBVS→IBVS

头双目位姿因子的协方差按深度和视差建模：

```math
\sigma_p \approx \frac{Z^2\sigma_d}{f b\sqrt{N_{\text{inlier}}}}+\sigma_{\text{cal}},
\qquad
R_H=\operatorname{diag}(\sigma_p^2 I_3,\ \sigma_r^2 I_3).
```

腕部 2D 因子的协方差用跟踪残差：

```math
R_W=\sigma_{\text{pix}}^2 I_{2m},
\qquad
\sigma_{\text{pix}}^2=\operatorname{median}_j\|\pi(\cdot)-z_j\|^2.
```

后验信息矩阵 `Λ = J^\top WJ`，`Σ_t = (Λ^{-1})_{X_tX_t}`。**伺服用的是 `X̂_t`，不是“选出来的模态”**；当双目深度方向方差大、腕部横向方差小时，`Σ_t` 在横向小、深度大，控制律自然更信腕部横向、头双目深度。硬切换被后验协方差替代。

### 2.4 风险感知控制与延迟预测

设执行延迟 `τ`，预测：

```math
\hat X_{t+\tau}=\hat X_t\exp(\tau\hat V_t),\qquad
\Sigma_{t+\tau}=\Sigma_t+\tau^2\Sigma_V+Q_\tau.
```

期望 EE 位姿 `Y^d = X̂_{t+τ}G`，误差 `e = log(Y_t^{-1}Y^d) ∈ R^6`。控制：

```math
\Delta=\operatorname{clip}\left(Ke+D\dot e,\ \pm\delta_t\right),
\qquad
\delta_t=\max(0,\delta_{\max}-\kappa_\alpha\sqrt{\lambda_{\max}(\Sigma_{t+\tau})}),
```

```math
K=\frac{K_0}{1+\operatorname{tr}(\Sigma_{t+\tau})/\sigma_0^2}.
```

`κ_α` 取 6 维高斯范数的 `1-α` 分位数（α=0.05 时约 3.55）。这是机会约束

```math
\Pr\left(\|e_{\text{true}}\|\le\varepsilon\right)\ge 1-\alpha
```

在局部线性高斯近似下的保守实现：估计误差越大，允许的修正步长越小；不确定时宁可慢，不要自信地错。

### 2.5 时空变化点

NIS：

```math
d_i^2=r_i^\top S_i^{-1}r_i,\qquad
S_i=H_iP_iH_i^\top+R_i.
```

CUSUM：

```math
g_i=\max\left(0,\ g_{i-1}+\frac{d_i^2-m}{\sqrt{2m}}-\nu\right),
\qquad
\text{alarm if }g_i>h.
```

接触用两个假设的似然比：

```math
\Lambda_i=\frac12\left[
r_{\text{free}}^\top P_i^{-1}r_{\text{free}}
-r_{\text{att}}^\top R_c^{-1}r_{\text{att}}
+\log\frac{\det P_i}{\det R_c}
\right],
```

对 `Λ_i` 再做 CUSUM。`r_att = log(C^{-1}Y_i^{-1}X_i)`；`r_free` 是运动模型残差。报警时令 `C=Y_i^{-1}X̂_i`，进入 CONTACT。

编辑检测：NIS 报警且自由/抓持两个假设都解释不了 → 停、膨胀 `P`、重定位；目标丢失则请求 VLA 重规划。滑移：CONTACT 下 `r_att` 连续超门限 → 停切向、重抓。

### 2.6 接触关键微调

离线用 STAF 跑演示，得到 `C_t`（接触/预接触）、`d_t`、`Σ_t`、模态健康度。权重：

```math
w_t=1+\lambda_c\mathbf 1[t\in C]+\lambda_d e^{-d_t/\lambda_s}
+\lambda_u\sqrt{\operatorname{tr}(\Sigma_t)/\sigma_u^2},
```

每个任务内部归一化，避免长任务主导。加权流匹配/去噪损失：

```math
\mathcal L_{\text{wfm}}
=\mathbb E_{t,\tau,\epsilon}\left[
w_t\left\|v_\theta(a_t^\tau,\tau,o_t)-(a_t-\epsilon)\right\|^2
\right].
```

时间一致性正则（仅训练时）：

```math
\mathcal L_{\text{tc}}
=\frac1{H_c}\sum_{k=1}^{H_c}
\rho\left(\log\left((\hat X_tG)^{-1}\hat Y_{t+k}\right)\right),
```

`Ŷ_{t+k}` 是把预测的相对动作 compose 到当前 EE 后的绝对轨迹。总损失 `L = L_wfm + λ_tc L_tc`。冻结 VLM，只训 action head + robot-state projector；同一 checkpoint、同一推理图。

## 3. 与第 12 轮的关系：保留骨架，替换最薄的三层

| 层 | 第 12 轮 | 本轮 | 为什么 |
|---|---|---|---|
| 规划 | 30 步 VLA | 保留 | 官方 WLA 已做好 |
| 执行 | 5 步 chunk | 保留 | 167 ms 是合理折中 |
| 相对目标 | 演示检索 `G` | 保留 | 抗位置/人为干扰 |
| 目标估计 | 单帧 PBVS/IBVS | STAF 因子图 | 异步、噪声、遮挡 |
| 模态切换 | 距离阈值 | 后验协方差调度 | 连续、可解释 |
| 增益 | 固定 P/D | 风险感知 + 延迟预测 | 稳定域 |
| 接触/编辑 | 手调阈值 | NIS/CUSUM + 似然比 | 统计决策 |

## 4. 实验与门（摘要）

| 门 | 问题 | 通过标准 | 失败动作 |
|---|---|---|---|
| G0 | 腕部内参/手眼能否标定？ | 内参重投影 ≤1 px；手眼 ≤3 px、平移 ≤5 mm、旋转 ≤2°；双目深度偏差 ≤5 mm@0.5 m | 只用双目 PBVS；腕部仅 2D 粗对齐 |
| G1 | 融合是否一致？ | held-out 位姿 RMSE ≤5 mm/2°；NIS 在 χ² 带内；95% CI 覆盖 90–98% | 重标 `R`；加保守膨胀；回退 EKF |
| G2 | 模态退化是否安全？ | 遮挡一路 ≤2 s，位姿误差 ≤10 mm；透明/反光能检测并回退，不差于第 12 轮 | 这些任务关闭腕部；只用双目+本体 |
| G3 | 伺服是否收敛？ | 横向 ≤2 mm、深度 ≤3 mm、2 s ≥95%；RTT 0–150 ms 无极限环 | 降增益/加 chunk/只做 PBVS |
| G4 | 变化点是否可靠？ | 接触延迟 ≤3 帧；误报 ≤1/min；滑移 ≤5 帧 | 调 CUSUM；保留启发式兜底 |
| G5 | 人为编辑能否恢复？ | 检测 ≤200 ms；仿真恢复 ≥70% | 只做离线标注；不线上触发 |
| G6 | 单任务是否涨点？ | 5 任务配对 A/B，≥3/5 +10pp；FoldTowel 不回归 >5pp | 不提交 STAF 版本 |
| G7 | 延迟是否可接受？ | p99 ≤150 ms；因子图 <1 ms；无 timeout | 降 K、EKF 回退、降分辨率 |
| G8 | 全量是否稳定？ | N 端口隔离、reset 干净、内存不涨 | 回退基线 |
| G9 | 微调是否有效？ | 接触关键加权/时间一致性至少一项为正，held-out 不回归 >2pp | 保留均匀微调；只用估计器 |

## 5. 已知风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| 手眼标定误差 | 腕部因子有偏，融合“自信地错” | 一次性标定；`R_W` 膨胀；NIS 监控；超门限关腕部 |
| 协方差标定不准 | 风险感知限幅过松或过紧 | 用新息在线校准 `R`；取保守 `κ_α` |
| 透明/反光/变形 | 特征跟踪失败 | inlier 门控；膨胀协方差；回退双目/本体 |
| 夹爪遮挡腕部 | 近距目标丢失 | 双目 + 预测位姿；抓持因子接管 |
| 运动模型失配 | 人为编辑后滤波器滞后 | CUSUM；膨胀 `P`；重定位 |
| 微调过拟合接触窗口 | 非接触任务回归 | 任务平衡；held-out；小 `λ_tc` |
| 数据泄漏 | 离线指标虚高 | 按 session/物体/背景划分 |
| 单模型解释 | 被判定第二个模型 | 融合器/控制器无学习权重；微调同一 checkpoint；写清合规 |
| 评测噪声 | +1–2pp 假阳性 | 配对 A/B、bootstrap、10 次/任务；不吹小效应 |

## 6. 一句话押注

**用带协方差的 SE(3) 时空融合替代单帧目标估计和硬模态切换，用风险感知与延迟预测替代固定增益，用接触关键加权微调替代均匀微调——把 CHUNK-SERVO 的 167 ms 闭环从“有反馈”升级为“知道反馈有多可信、该信多少、该等多久”。**

**当前方案最大的风险**：融合器的协方差一旦标定不准，腕部手眼误差或透明物体会让估计器“过度自信”，风险感知控制器会把错误目标当成低不确定性目标执行，产生比开环更稳定的错误。

### 1.2 双目深度噪声（B，推导）

头双目基线 `b=58.2526 mm`，左目 `f≈282.37 px`。视差 `d = f b / Z`，深度不确定度：

```math
\sigma_Z \approx \frac{Z^2}{f b}\sigma_d.
```

`f b ≈ 16.45 px·m`。

| 距离 `Z` | `σ_Z`（`σ_d=1 px`） | `σ_Z`（`σ_d=0.3 px`） | 腕部横向 1 px 对应 |
|---:|---:|---:|---:|
| 0.5 m | 15.2 mm | 4.6 mm | 1.15 mm（`f_W=436`） |
| 0.7 m | 29.8 mm | 8.9 mm | — |
| 1.0 m | 60.8 mm | 18.2 mm | — |
| 0.1 m（腕部） | — | — | 0.23 mm |
| 0.2 m（腕部） | — | — | 0.46 mm |

结论：**远距靠双目全局，近距靠腕部横向 + 双目/运动提供深度**。这正是协方差调度要表达的事，不需要硬切换。

## 2. 问题形式化

### 2.1 符号表

| 符号 | 含义 |
|---|---|
| `B, T, E, H, W` | base、目标、EE、头左目、腕部相机坐标系 |
| `T_AB` | 把 B 系点变换到 A 系的位姿；`p_A = T_AB p_B` |
| `X_t = T_BT(t) ∈ SE(3)` | 目标在 base 系的位姿 |
| `V_t ∈ R^6` | 目标体坐标系速度（twist，`(ρ,φ)` 顺序） |
| `Y_t = T_BE(t)` | 本体给的 EE 位姿 |
| `G = T_TE*` | 演示检索的“目标→EE”相对目标 |
| `C = T_ET` | 接触时刻的“EE→目标”刚性偏移 |
| `z_t^H ∈ SE(3)` | 头双目估计的目标位姿 |
| `z_t^W ∈ R^{2m}` | 腕部 `m` 个特征点像素 |
| `p_T ∈ R^3` | 目标上的已知特征点 |
| `K_W, T_EW` | 腕部内参（已知）、腕部相机在 EE 系的外参（待标定） |
| `P_t, Σ_t` | 预测协方差、后验边缘协方差 |
| `τ` | 端到端延迟（RTT + 推理 + 图像 + 计算） |
| `H_c, f_c` | chunk 步数、控制频率；默认 5、30 Hz |
| `K` | 固定窗口长度；默认 8 帧 |
| `w_t, c_t` | 微调权重、接触关键性分数 |

约定：`log: SE(3)→R^6` 是 SE(3) 对数映射，`exp: R^6→SE(3)` 是指数映射；`||r||^2_P = r^\top P^{-1}r`；`π` 是含畸变的针孔投影。`H` 只表示头左目相机坐标系，抓持偏移统一记作 `C`。

### 2.2 状态空间模型

```math
X_{t+1}=X_t\exp(V_t\Delta t)\exp(\epsilon_t),
\qquad
V_{t+1}=(1-\alpha)V_t+\eta_t,
```

```math
\epsilon_t\sim\mathcal N(0,Q_x),\qquad
\eta_t\sim\mathcal N(0,Q_v),\qquad
\alpha\in[0,1].
```

- `α=0`：恒速目标（传送带、被人移动）。
- `α→1`：静止目标（桌面受器），速度快速衰减，避免滤波器在静止时漂移。
- 接触后：`X_t = Y_t H`，目标位姿由 EE 位姿和刚性偏移决定；运动模型让位于抓持因子。

### 2.3 测量模型

**头双目位姿**：

```math
z_t^H=X_t\exp(\epsilon_H),\qquad
\epsilon_H\sim\mathcal N(0,R_H),
```

```math
R_H=\operatorname{diag}(\sigma_p^2I_3,\sigma_r^2I_3),\qquad
\sigma_p\approx\frac{Z^2\sigma_d}{f b\sqrt{N_{\text{inlier}}}}+\sigma_{\text{cal}}.
```

**腕部 2D 特征**：

```math
z_t^W=\pi\left(K_WT_EW^{-1}Y_t^{-1}X_tp_T\right)+\epsilon_W,
\qquad
\epsilon_W\sim\mathcal N(0,R_W),
```

```math
R_W=\sigma_{\text{pix}}^2I_{2m},\qquad
\sigma_{\text{pix}}^2=\operatorname{median}_j\|\pi(\cdot)-z_j\|^2.
```

**抓持约束**（接触后）：

```math
X_t=Y_tC\exp(\epsilon_c),\qquad
\epsilon_c\sim\mathcal N(0,R_c).
```

### 2.4 估计目标

固定窗口 `χ = {X_i,V_i}_{i=t-K+1}^t` 的 MAP：

```math
\begin{aligned}
J(\chi)=&
\left\|\log(\hat X_{t-K+1}^{-1}X_{t-K+1})\right\|^2_{P_{t-K+1}}
+
\left\|V_{t-K+1}-\hat V_{t-K+1}\right\|^2_{P_v} \\
&+\sum_{i=t-K+1}^{t-1}
\left[
\left\|\log\left((X_i\exp(V_i\Delta t))^{-1}X_{i+1}\right)\right\|^2_{Q_x}
+
\left\|V_{i+1}-(1-\alpha)V_i\right\|^2_{Q_v}
\right] \\
&+\sum_{i\in\mathcal H}\rho\left(\left\|\log\left((z_i^H)^{-1}X_i\right)\right\|^2_{R_H}\right) \\
&+\sum_{i\in\mathcal W}\rho\left(\left\|\pi\left(K_WT_{EW}^{-1}Y_i^{-1}X_i p_T\right)-z_i^W\right\|^2_{R_W}\right) \\
&+\mathbf 1[\text{attached}]\sum_i
\rho\left(\left\|\log\left(C^{-1}Y_i^{-1}X_i\right)\right\|^2_{R_c}\right).
\end{aligned}
```

`ρ` 为 Huber 核；`P_{t-K+1}` 是上一窗口对最老状态的边缘先验（Schur 补或上一次 Laplace 近似）。输出最新状态的边缘：

```math
\hat X_t,\hat V_t,\Sigma_t
=
\left(\Lambda^{-1}\right)_{X_tX_t},
\qquad
\Lambda=\left.J^\top WJ\right|_{\hat\chi}.
```

### 2.5 控制目标

在延迟 `τ` 下，最小化期望位姿误差并满足机会约束：

```math
\min_{\Delta}\ \mathbb E\left[\left\|e_{t+1}\right\|^2\right]
\quad\text{s.t.}\quad
\Pr\left(\left\|e_{t+1}\right\|\le\varepsilon\right)\ge 1-\alpha,
\qquad
\|\Delta\|\le\delta_{\max}.
```

`e_t = log(Y_t^{-1}X_{t+\tau}G)`。由于 `e` 非线性、`Σ` 只是局部近似，本报告采用“估计 + 保守限幅”的实现，而不是求解完整随机最优控制。

### 2.6 可观测性条件

- **仅头双目**：`z^H` 直接给 6-DoF 位姿；只要 ROI 有足够非共线点且非退化，`rank(H)=6`。
- **腕部 + 已知目标模型**：单帧 PnP 给 6-DoF（平面目标有标准二义性）；`m≥4` 个非共线点。
- **腕部 + 未知目标模型**：单帧只有 2D，尺度不可观；需要窗口内的已知 EE 运动提供基线。若 `rank(H)<6`，协方差在零空间膨胀，控制器不得在该子空间运动。
- **抓持后**：`C` 提供强约束；目标位姿由 `Y_tC` 决定，腕部/双目只用于校核。
- **透明/反光/被夹爪挡住**：特征 inlier 不足 → 门控掉该因子 → 回退双目/本体/上一有效位姿；不硬做 IBVS。

### 2.7 与第 12 轮的形式化差异

第 12 轮的切换可写成：

```math
\text{mode}=
\begin{cases}
\text{PBVS}, & d_t>d_c,\\
\text{IBVS}, & d_t\le d_c,
\end{cases}
```

其中 `d_t` 是夹爪到目标的距离。本轮把它替换成：

```math
\hat X_t=\arg\min_X \sum_j \|r_j(X)\|^2_{R_j},
\qquad
\Sigma_t=\left(\sum_j J_j^\top R_j^{-1}J_j\right)^{-1},
```

模态的权重由 `R_j` 和 `J_j` 决定，不再由单一距离阈值决定。`d_t` 只作为先验/调试量，不作为硬开关。

## 3. 算法：STAF-SERVO

### 3.1 总览

```text
                    ┌──────────────────────────────────────────────┐
                    │  Evaluator (N ports 8765..8765+N-1)          │
                    └──────────────────┬───────────────────────────┘
                                       │ websocket: obs / 5-step chunk
                                       ▼
                    ┌──────────────────────────────────────────────┐
                    │  Per-port PolicyService (CPU)                │
                    │  ├─ STAF estimator (fixed-window factor graph)│
                    │  ├─ change-point detector (NIS/CUSUM)        │
                    │  ├─ risk-aware servo + delay predictor       │
                    │  ├─ goal retrieval (demo library, cached)    │
                    │  ├─ plan cache (30-step VLA plan)            │
                    │  └─ action adapter (WLA 54D → API 21D)       │
                    └──────────────────┬───────────────────────────┘
                                       │ async, batched
                                       ▼
                    ┌──────────────────────────────────────────────┐
                    │  Shared VLA server (GPU)                     │
                    │  UnifoLM-WLA-1.0, 30-step plan               │
                    └──────────────────────────────────────────────┘
```

- 每个端口独立 `PolicyService`、独立 `reset()`、独立窗口和 goal 状态。
- 融合/检测/伺服是 CPU 线程；VLA 异步、可批处理。
- 共享 VLA server 用 session ID 区分端口；权重只有一份。

### 3.2 STAF 估计器

#### 3.2.1 因子与残差

| 因子 | 残差 | 维度 | 协方差 |
|---|---|---:|---|
| 最老状态先验 | `log(X̂_{t-K+1}^{-1}X_{t-K+1})` | 6 | `P_{t-K+1}` |
| 最老速度先验 | `V_{t-K+1}-V̂_{t-K+1}` | 6 | `P_v` |
| 运动 | `log((X_i exp(V_iΔt))^{-1}X_{i+1})` | 6 | `Q_x` |
| 速度阻尼 | `V_{i+1}-(1-α)V_i` | 6 | `Q_v` |
| 头双目 | `log((z_i^H)^{-1}X_i)` | 6 | `R_H` |
| 腕部 2D | `π(K_W T_EW^{-1}Y_i^{-1}X_i p_T)-z_i^W` | `2m` | `R_W` |
| 抓持 | `log(C^{-1}Y_i^{-1}X_i)` | 6 | `R_c` |

#### 3.2.2 鲁棒核与门控

Huber（按残差范数）：

```math
\rho(s)=
\begin{cases}
s, & \sqrt{s}\le\delta,\\
2\delta\sqrt{s}-\delta^2, & \sqrt{s}>\delta,
\end{cases}
\qquad
w(s)=
\begin{cases}
1, & \sqrt{s}\le\delta,\\
\delta/\sqrt{s}, & \sqrt{s}>\delta.
\end{cases}
```

IRLS 权重 `w(s)` 乘进信息矩阵。另外做卡方门控：

```math
r_i^\top R_i^{-1}r_i>\chi^2_{m_i,0.99}
\;\Rightarrow\;
\text{downweight or reject}.
```

门控不是永久删除：连续 `K_g` 帧超门限才标记该模态失效；单帧异常只降权。

#### 3.2.3 固定窗口与边缘化

1. 用上一窗口的后验边缘作为最老状态先验（`P_{t-K+1}`、`P_v`）。
2. 高斯-牛顿 3–5 次迭代；每次解稀疏法方程。
3. 输出最新状态 `X̂_t, V̂_t, Σ_t`。
4. 丢弃最老状态，窗口向前滑动。
5. 若数值失败/超时 → 回退 EKF（同一模型，递归更新）。

#### 3.2.4 协方差调度：自动 PBVS→IBVS

后验信息矩阵：

```math
\Lambda=\sum_j J_j^\top R_j^{-1}J_j,
\qquad
\Sigma_t=\left(\Lambda^{-1}\right)_{X_tX_t}.
```

- 远距：`R_H` 小（双目位姿可信），`R_W` 大或腕部不可见 → `X̂_t` 主要由双目决定。
- 近距：`R_H` 的深度分量随 `Z²` 变大，腕部 2D 因子的横向约束变强 → `X̂_t` 的横向主要由腕部决定，深度由双目/运动/抓持决定。
- 遮挡：腕部 inlier 不足 → 门控 → 双目接管。
- 抓持：`R_c` 小 → `X_t≈Y_tC`，本体接管。

**这不是“切换”，是同一估计器在不同方向上的可信度变化。** 第 12 轮的 `d_c` 阈值可以保留为调试/先验，但不作为控制开关。

#### 3.2.5 EKF 回退

当 CPU 预算不足或窗口求解失败：

```math
\begin{aligned}
\bar X_{t+1}&=\hat X_t\exp(\hat V_t\Delta t),\\
\bar V_{t+1}&=(1-\alpha)\hat V_t,\\
\bar P_{t+1}&=F_t\bar P_tF_t^\top+Q,\\
K_t&=\bar P_tH_t^\top(H_t\bar P_tH_t^\top+R_t)^{-1},\\
\hat X_t&=\bar X_t\exp(K_t r_t),\\
\hat P_t&=(I-K_tH_t)\bar P_t.
\end{aligned}
```

EKF 是固定窗口的递归近似；精度略低，但亚毫秒级。

### 3.3 风险感知伺服与延迟补偿

#### 3.3.1 延迟预测

```math
\hat X_{t+\tau}=\hat X_t\exp(\tau\hat V_t),
\qquad
\Sigma_{t+\tau}=\Sigma_t+\tau^2\Sigma_V+Q_\tau.
```

`τ` 由时间戳/RTT 测量；若未知，用保守上界 `τ_max`。目标静止时 `V̂≈0`，预测退化为当前位姿；目标被传送带/人移动时，速度项提供前馈。

#### 3.3.2 机会约束

局部线性高斯近似下，`e_true = e_est + δ`，`δ~N(0,Σ_e)`。要 `Pr(||e_true - BΔ||≤ε)≥1-α`，一个保守充分条件是：

```math
\left\|e_{\text{est}}-B\Delta\right\|+
\kappa_\alpha\sqrt{\lambda_{\max}(\Sigma_e)}
\le\varepsilon,
\qquad
\kappa_\alpha=\sqrt{\chi^2_6(1-\alpha)}.
```

α=0.05 时 `κ≈3.55`；α=0.01 时 `κ≈4.10`。实现上用步长限幅做代理：

```math
\delta_t=\max\left(0,\delta_{\max}-\kappa_\alpha\sqrt{\lambda_{\max}(\Sigma_{t+\tau})}\right).
```

这不是全局保证；它是“估计越不确定，单步越保守”的工程实现。报告必须如实标注。

#### 3.3.3 增益调度与修正

```math
K=\frac{K_0}{1+\operatorname{tr}(\Sigma_{t+\tau})/\sigma_0^2},
\qquad
\Delta=\operatorname{clip}\left(Ke+D\dot e,\pm\delta_t\right).
```

- `K_0`：名义比例增益；`D`：微分增益；`σ_0`：名义不确定度尺度。
- `δ_max`：每块最大平移 1 cm / 旋转 0.05 rad（与第 12 轮一致）。
- 连续 3 块 `||Δ||>0.8δ_max` → 判定目标估计/标定异常 → 重定位或回退 VLA。

#### 3.3.4 5 步修正轨迹

VLA 给出 5 步相对动作 `a_ff,1..5`，compose 成绝对前馈 `Y_ff,k`。对每一步预测目标 `X̂_{t+kΔt+τ}`，算 `e_k`，再：

```math
Y_{\text{cmd},k}=Y_{\text{ff},k}\exp(\Delta_k),
\qquad
\Delta_k=\operatorname{clip}(K e_k+D\dot e_k,\pm\delta_t).
```

5 步内不重新估计；下一步 chunk 再闭环。这样修正是一条平滑轨迹，不是块边界跳变。

#### 3.3.5 接触段法向/切向

```math
\Delta=\Delta_n+\Delta_t,
\qquad
\Delta_n\leftarrow\beta\Delta_n,\quad \beta\in[0.3,0.5],
```

`Δ_n` 低通；`Δ_t` 保留。法向用表面法向 `n_t`（第 11 轮 GEO-RESIDUAL 的米制表面距离）；没有力/触觉，用 `d_t`、`r_static`、`r_grasp` 作为代理。抓持因子 `R_c` 突变 → 滑移 → 停切向、重抓。

### 3.4 时空变化点检测

#### 3.4.1 NIS/CUSUM

```math
d_i^2=r_i^\top S_i^{-1}r_i,\qquad
S_i=H_iP_iH_i^\top+R_i.
```

H0 下 `d_i^2~χ^2_m`，均值 `m`、方差 `2m`。归一化增量 `(d_i^2-m)/√(2m)` 均值 0、方差 1。CUSUM：

```math
g_i=\max\left(0,g_{i-1}+\frac{d_i^2-m}{\sqrt{2m}}-\nu\right),
\qquad
\text{alarm if }g_i>h.
```

`ν` 是漂移容差（如 0.5），`h` 控制平均运行长度（ARL）。误报率随 `h` 指数下降；检测延迟约 `h/μ`（`μ` 是偏离漂移）。

#### 3.4.2 接触似然比

两个假设：

- `H_free`：目标按运动模型自由运动，残差 `r_free`，协方差 `P_i`。
- `H_att`：目标刚性跟随夹爪，`X_i=Y_iC`，残差 `r_att`，协方差 `R_c`。

```math
\Lambda_i=\frac12\left[
r_{\text{free}}^\top P_i^{-1}r_{\text{free}}
-r_{\text{att}}^\top R_c^{-1}r_{\text{att}}
+\log\frac{\det P_i}{\det R_c}
\right].
```

对 `Λ_i` 做 CUSUM；报警时令 `C=Y_i^{-1}X̂_i`，进入 CONTACT，膨胀 `R_c` 以反映刚接触的不确定。

#### 3.4.3 滑移

CONTACT 下监控 `r_att`：

```math
\|r_{\text{att}}\|^2_{R_c^{-1}}>\chi^2_{6,0.99}
\text{ for }K_s\text{ frames}
\;\Rightarrow\;
\text{slip}.
```

动作：停切向、保持夹持、请求重抓/加大夹持；若连续失败，回退 VLA 重规划。

#### 3.4.4 人为编辑

NIS 报警且 `H_free`/`H_att` 都解释不了 → 外部编辑：

```text
hold position
inflate P (×10)
re-localize X with head stereo
if target visible: update goal, resume with conservative gain
else: request VLA re-plan
```

不识别“人”，只识别“场景动了，而且不是我的动作/抓持能解释的”。这比第 12 轮的 `edit_score` 阈值更少误报，因为它要求持续偏离。

#### 3.4.5 计划-状态一致性

VLA 计划隐含目标相对轨迹：

```math
\hat G_k=\hat X_{t+k}^{-1}Y_{\text{ff},k}.
```

与检索目标 `G` 比较：

```math
r_{\text{plan},k}=\log(G^{-1}\hat G_k).
```

在接近/接触相位，若 `||r_plan,k||` 连续超门限 → 计划与世界不一致 → 重检索/重规划。这个监控只作为触发，不直接改动作；避免和伺服打架。

### 3.5 接触关键微调

#### 3.5.1 离线标注

对每个演示 episode：

1. 用 STAF 跑一遍（离线可用真值 EE 位姿；双目/腕部图来自数据集）。
2. 输出每帧：接触/预接触标签 `C_t`、目标距离 `d_t`、协方差 `Σ_t`、模态健康度。
3. 关键帧选择：首次接触前 1–3 帧、接触稳定后 1 帧、目标进入腕部视野且 `d_t<5cm` 的帧。
4. 按 session/物体/背景划分 train/val，相邻帧不跨 split。

#### 3.5.2 权重

```math
w_t=1+\lambda_c\mathbf 1[t\in C]+\lambda_d e^{-d_t/\lambda_s}
+\lambda_u\sqrt{\operatorname{tr}(\Sigma_t)/\sigma_u^2}.
```

设计初值：`λ_c=2`、`λ_d=1`、`λ_s=2cm`、`λ_u=0.5`。每个任务内部归一化：

```math
\tilde w_t=w_t\cdot\frac{T}{\sum_{s\in\text{task}}w_s},
```

保证每个任务总权重相同；批采样再按任务平衡。`λ` 在验证集上调，不在测试任务上调。

#### 3.5.3 加权流匹配/去噪

官方 action head 若用 flow matching：

```math
\mathcal L_{\text{wfm}}
=\mathbb E_{t,\tau,\epsilon}\left[
\tilde w_t\left\|v_\theta(a_t^\tau,\tau,o_t)-(a_t-\epsilon)\right\|^2
\right].
```

若官方用 DDPM 预测噪声，则把 `\tilde w_t` 乘到噪声 MSE 上。**不改网络、不改推理步数。**

#### 3.5.4 时间一致性正则

```math
\mathcal L_{\text{tc}}
=\frac1{H_c}\sum_{k=1}^{H_c}
\rho\left(\log\left((\hat X_tG)^{-1}\hat Y_{t+k}\right)\right),
\qquad
\mathcal L=\mathcal L_{\text{wfm}}+\lambda_{\text{tc}}\mathcal L_{\text{tc}}.
```

`Ŷ_{t+k}` 是把预测的相对动作 compose 到当前 EE 后的绝对轨迹；`ρ` 为 Huber。只在接近/接触相位启用，`λ_tc` 取小值（如 0.05–0.1），避免压过演示动作。

#### 3.5.5 传感器 dropout 增强

训练时以概率 `p_w` 把腕部图替换为黑图/上一帧，以 `p_h` 把头部图替换为单目/上一帧，模拟遮挡和背景变化。`p_w≈0.1`、`p_h≈0.05`，在验证集上确认不破坏基线。推理时不做 dropout。

#### 3.5.6 防泄漏

- 按 session/物体/背景分组划分；同一 episode 的相邻帧不跨 split。
- 32 个任务分别留 10% episode 做验证。
- 接触关键帧的权重统计只在 train split 上算。
- 不用测试任务调 `λ`、`K`、`H_c`。

### 3.6 运行时状态机

```text
INIT ──first obs──▶ PLAN ──plan ready──▶ SERVO
  ▲                   ▲                    │
  │                   │                    ├─ contact LLR alarm ──▶ CONTACT
  │                   │                    │                         │
  │                   │                    │                         ├─ slip ──▶ REGRASP
  │                   │                    │                         └─ release ──▶ SERVO
  │                   │                    │
  │                   └── replan ◀── RECOVER ◀── NIS/edit alarm
  │                                      │
  └──────────────────────────────────────┘
任意状态 ──success / max steps / timeout──▶ DONE
```

- `SERVO`：自由接近；风险感知增益；双目 + 腕部融合。
- `CONTACT`：抓持因子接管；法向缩幅；滑移监控。
- `REGRASP`：停切向、保持/加大夹持、重估 `H`。
- `RECOVER`：停、膨胀协方差、重定位；目标可见→更新 goal；不可见→VLA 重规划。
- 任何异常 → 返回上一组合法 chunk 或安全 hold；绝不返回 NaN/错误形状。

### 4.1 在线 `get_action`

```python
class STAFServoPolicy:
    def get_action(self, obs):
        self._tick(obs)                  # proprio buffer, timestamps
        self._maybe_request_plan(obs)    # async VLA, non-blocking

        st = self.staf.update(obs)       # X_hat, V_hat, Sigma, residuals
        mode = self.change_point.update(st)   # FREE/CONTACT/REGRASP/EDIT

        if mode == "EDIT":
            return self._recover_or_hold(obs)

        if self.plan is None:
            self.plan = self.vla.predict(obs)     # cold start only
            self.plan_idx = 0

        a_ff = self.plan[self.plan_idx:self.plan_idx + self.H_c]
        a_cmd = self._servo(a_ff, st, mode)

        self.plan_idx += self.H_c
        if self.plan_idx >= len(self.plan):
            self.plan = None
            self.plan_idx = 0

        return self.adapter.to_api(a_cmd, obs, self.token)
```

### 4.2 `STAF.update`

```python
def update(self, obs):
    self.window.push(
        Y=obs.ee_pose,
        zH=self._head_pose(obs) if self._head_valid(obs) else None,
        zW=self._wrist_features(obs) if self._wrist_valid(obs) else None,
    )
    if len(self.window) < 2:
        return self._init_state(obs)

    chi = self.window.states()
    for _ in range(self.gn_iters):
        r, J, W = self._linearize(chi)
        dx = solve_sparse(J.T @ W @ J + self.damping, J.T @ W @ r)
        chi = self._retract(chi, dx)

    X_hat, V_hat = chi[-1]
    Sigma = self._marginal(chi, index=-1)
    self.window.set_prior(chi[0], Sigma[0])
    return State(X_hat, V_hat, Sigma, self._residuals())
```

### 4.3 变化点

```python
def update(self, st):
    nis = st.nis                      # per modality
    self.g_nis = max(0, self.g_nis + (nis - st.m) / sqrt(2 * st.m) - self.nu)

    if self.attached:
        r_att = log(self.C.inv() @ st.Y.inv() @ st.X)
        if norm2(r_att, self.Rc.inv()) > chi2(6, 0.99):
            self.slip_count += 1
        else:
            self.slip_count = 0
        if self.slip_count >= self.Ks:
            return "REGRASP"
        return "CONTACT"

    llr = self._contact_llr(st)
    self.g_llr = max(0, self.g_llr + llr - self.nu_c)
    if self.g_llr > self.h_c:
        self.C = st.Y.inv() @ st.X
        self.attached = True
        return "CONTACT"

    if self.g_nis > self.h_nis:
        return "EDIT"

    return "FREE"
```

### 4.4 伺服

```python
def _servo(self, a_ff, st, mode):
    Y_ff = compose_absolute(self.current_ee, a_ff)   # (H_c, 6)
    out = []
    for k, Yk in enumerate(Y_ff, start=1):
        X_pred, Sigma = self._predict(st, tau=self.tau, horizon=k / self.fc)
        e = log_se3(Yk.inv() @ X_pred @ self.goal)
        K = self.K0 / (1 + trace(Sigma) / self.sigma0**2)
        delta = clip(K @ e + self.D @ (e - self.e_prev), self.delta_max)
        delta = clip_by_uncertainty(delta, Sigma, self.kappa)
        if mode == "CONTACT":
            delta = self._normal_tangent_shrink(delta, st.normal)
        out.append(Yk @ exp_se3(delta))
        self.e_prev = e
    return out
```

## 5. 复杂度分析

### 5.1 在线

- 状态维度：每节点 `6 (X) + 6 (V) = 12`；窗口 `K=8` → 96 变量。
- 稀疏链式法方程：`O(K · 12³) ≈ 1.4×10⁴` flops/迭代；3–4 次迭代 < 6×10⁴。
- 稠密上界：`O((12K)³) ≈ 8.8×10⁵` flops/迭代；仍 < 1 ms（现代 CPU 单核）。
- 特征提取：腕部 128×128 光流/ORB 约 1–2 ms/路；头双目 ROI 块匹配约 3–5 ms。总 < 10 ms。
- 5 步 chunk 执行 167 ms；融合只占 <6% 预算，留足 RTT 和推理。

### 5.2 离线

- 微调与官方 action-head 微调同量级；权重和辅助损失只增加前向/反向的常数项。
- 离线跑 STAF 标注 33k episodes：每 episode 6–38 s、30 fps；因子图离线可批处理，预计 1–2 GPU-day 或 1 CPU-day 量级（取决于特征提取实现）。
- 目标库/演示索引：第 12 轮已估算 <1 GB；本轮不增加大模型。

### 5.3 内存

- 每端口：窗口 8×12×12 协方差 + 特征 + 图像 ROI < 1 MB；N 端口线性。
- 共享 VLA：6B bf16 约 12 GB；一张 24–40 GB GPU 可服务多端口，取决于 batch。

### 5.4 延迟预算

| 项 | 估计 |
|---|---:|
| 图像解码 + resize | 2–5 ms |
| 腕部特征 | 2–4 ms |
| 头双目 ROI | 3–5 ms |

## 6. 正确性论证

### 6.1 估计器

**命题 1（固定窗口 MAP）**：在运动/测量模型正确、噪声高斯、先验为上一窗口真实边缘的假设下，`J(χ)` 的极小值点是窗口后验的众数；`Σ_t=(Λ^{-1})_{X_tX_t}` 是 Laplace 近似协方差。

**证明 sketch**：`J` 是负对数后验加常数；高斯-牛顿在局部收敛到驻点；`Λ` 是负对数后验的 Hessian。固定窗口丢弃更老状态，等价于对更老状态做边缘化；若用精确 Schur 补先验，窗口后验与全后验的边缘一致。实践中用上一次 Laplace 近似，误差随窗口重叠衰减。

**命题 2（鲁棒性）**：Huber 核的 IRLS 权重有界，单个测量对估计的影响被限制在 `δ` 量级；卡方门控进一步拒绝大 outlier。

**证明 sketch**：Huber 的影响函数有界；IRLS 收敛到 M-estimator 的驻点。门控不是概率保证，但能防止单帧特征错配把状态拉飞。

### 6.2 可观测性

**命题 3（秩条件）**：设窗口内所有因子的堆叠 Jacobian 为 `H`。若 `rank(H)=6`，则 `X_t` 局部可观测；若 `rank(H)=r<6`，则零空间方向不可观测，`Σ_t` 在该方向发散，控制器不得在该方向施加修正。

**证明 sketch**：Fisher 信息矩阵 `Λ=H^T R^{-1}H`；`rank(Λ)=rank(H)`；零空间对应无信息方向。头双目位姿因子单独给满秩 6；腕部单目 + 未知目标模型给秩 ≤5（尺度零空间）；已知 EE 运动提供基线后秩可恢复；抓持因子给 6。

**推论**：G0 的手眼标定和 G1 的 NIS 检查不是可选项；它们决定 `H` 是否满秩、`R` 是否可信。

### 6.3 风险约束

**命题 4（保守限幅）**：若 `e_true=e_est+δ`、`δ~N(0,Σ_e)`，且 `||e_est-BΔ||+κ_α√λ_max(Σ_e)≤ε`，则 `Pr(||e_true-BΔ||≤ε)≥1-α`，其中 `κ_α=√χ²_6(1-α)`。

**证明 sketch**：`||e_true-BΔ||≤||e_est-BΔ||+||δ||`；`||δ||²` 是 6 维高斯二次型，`Pr(||δ||≤κ√λ_max)≥1-α`（保守用最大特征值）。三角不等式给出充分条件。限幅 `δ_t` 是该条件的步长代理，不是精确解；报告明确标注这是局部近似。

### 6.4 变化点

**命题 5（CUSUM 的 ARL/延迟）**：H0 下归一化增量均值 0、方差 1；CUSUM 阈值 `h` 使误报平均运行长度随 `h` 指数增长；对漂移 `μ>0`，检测延迟约 `h/μ`（Lorden 的渐近最优性）。

**证明 sketch**：标准 CUSUM 理论；这里只引用，不重复证明。实际 `ν,h` 用仿真/离线残差调，不假设高斯完全成立。

### 6.5 微调

**命题 6（加权风险）**：加权流匹配损失是加权风险的无偏估计；时间一致性项是正则项，不改变最优解的可行性，只改变解的偏好。

**证明 sketch**：样本权重乘在损失上，期望线性；辅助项非负，权重 `λ_tc→0` 时退化为官方损失。**没有**测试成功率保证；G9 只验证方向和回归。

### 6.6 安全与回退

- 任何估计失败（秩亏、NIS 持续报警、超时）→ 回退 EKF/上一有效位姿/VLA 开环。
- 任何动作异常（NaN、形状错、超限）→ 返回上一组合法 chunk 或安全 hold。
- 单模型合规：融合器/控制器无学习权重；微调同一 checkpoint；辅助损失仅训练时。
- 最大重试/最大恢复次数；超限 fail gracefully，不无限重试。

### 6.7 局限

- 高斯/线性近似不是全局保证；协方差可能 miscalibrated。
- 目标模型/关键点对变形、透明、反光物体不可靠；这些任务应关闭腕部 3D 因子，只用 2D/双目。
- 手眼标定漂移会引入系统偏差；需要 G0 复核和 NIS 监控。
- 微调的收益可能小于 320 trials 的噪声；不能把 +1–2pp 当结论。
- 变化点检测有检测延迟；人为编辑如果发生在视野外，仍会漏检。

### 7.7 统计功效

- 单任务 5 次配对只能看方向；不要报 p 值。
- 全量 320 trials、`p≈0.25` 时 `SE(S)≈2.4pp`；配对设计可降低方差，但仍需 bootstrap CI。
- 不把 +1–2pp 当结论；只把 ≥5pp 且 CI 不跨 0 的变化当信号。
- 多任务多重比较：用分层 bootstrap 或预注册主要终点（A 档 5 任务）。

## 8. 风险与合规

### 8.1 风险表

| 风险 | 影响 | 缓解 |
|---|---|---|
| 手眼标定误差 | 腕部因子有偏，融合“自信地错” | 一次性标定；`R_W` 膨胀；NIS 监控；超门限关腕部 |
| 协方差标定不准 | 风险限幅过松/过紧 | 新息在线校准 `R`；保守 `κ_α`；G1 覆盖检查 |
| 透明/反光/变形 | 特征失败、深度失败 | inlier 门控；膨胀协方差；回退双目/本体；变形任务禁用 3D 因子 |
| 夹爪遮挡腕部 | 近距目标丢失 | 双目 + 预测位姿；抓持因子接管 |
| 运动模型失配 | 人为编辑后滞后 | CUSUM；膨胀 `P`；重定位 |
| 目标模型缺失 | 腕部 2D 无法反投影 | 只用 2D 对齐/双目；不假设 6D |
| 微调过拟合 | 非接触任务回归 | 任务平衡；held-out；小 `λ_tc`；早停 |
| 数据泄漏 | 离线指标虚高 | session/物体/背景划分 |
| 单模型解释 | 被判定第二个模型 | 确定性融合/控制；同一 checkpoint；写清合规 |
| 延迟/算力 | p99 超门限 | 因子图 <1 ms；EKF 回退；EKF 亚毫秒 |
| 评测噪声 | 小效应假阳性 | 配对 A/B、bootstrap、10 次/任务 |
| `pivot` 语义不一致 | 动作被拒/机器人不动 | 先用 `example_env.py` 验证；零 pivot 回退 |

### 8.2 合规模式

| 模式 | 做法 | 风险 | 建议 |
|---|---|---|---|
| C1 离线标注 | STAF 只离线生成接触权重；在线只用 VLA + 确定性伺服 | 最低 | 保守首选 |
| C2 确定性融合 | STAF 在线运行，但无学习权重；VLA 唯一学习模型 | 低；需说明 | 主推 |
| C3 同 checkpoint 特征 | 若需学习描述子，用 VLA 同一 encoder | 低–中 | 非必要不用 |

禁止：第二个学习策略、残差网络、独立视觉编码器做在线决策、测试时在线学习。

### 8.3 回退树

```text
固定窗口 MAP
  ├─ 数值失败/超时 → EKF
  ├─ 秩亏/门控 → 双目 + 本体 PBVS
  ├─ 双目也失败 → 上一有效位姿 + VLA 开环
  ├─ NIS 持续报警 → EDIT：停/重定位/重规划
  └─ 任何动作异常 → 上一合法 chunk / hold
```

## 10. 一句话押注与最大风险

**一句话押注**：用带协方差的 SE(3) 时空融合替代单帧目标估计和硬模态切换，用风险感知与延迟预测替代固定增益，用接触关键加权微调替代均匀微调——把 CHUNK-SERVO 的 167 ms 闭环从“有反馈”升级为“知道反馈有多可信、该信多少、该等多久”。

**最大风险**：融合器的协方差一旦标定不准，腕部手眼误差或透明物体会让估计器“过度自信”，风险感知控制器会把错误目标当成低不确定性目标执行，产生比开环更稳定的错误。
