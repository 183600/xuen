### 第 2 轮灵感驱动研究记录（新循环；继承 CADVS-v4）

**灵感词**：可重构机构、语义地图

**继承关系**：第 4 轮 CADVS-v4（IP-489~492）在 v3 五锚点（3DCF / MSRG / HICK / EEK / LTEM + FFA）之上追加价值锚 VACK 与平衡锚 BCK，形成七硬门 kc_evidence_forged_v4 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem ∧ kc_val ∧ kc_bal，fail-closed；软评分 ECS_v4 = ECS_v3 · η_val · η_bal；执行集 Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ … ⊆ Exec_v29。v4 隐含两个从未被挑战的前提：(P1) 机器人本体结构固定，运动学模型 K 不随任务改变；(P2) 世界只以几何占据表达，覆盖 = 几何可达。本轮用「可重构机构」打破 P1，用「语义地图」打破 P2，形成 CADVS-v5（IP-493~496），九硬门。执行集在「固定形态 / 固定语义」的纤维内继续单调收缩；跨形态 / 跨语义更新时改用「证书输运闭合」替代朴素包含——这是本轮最重要的理论修正。

**直觉与动机**：

1. **可重构机构：证书必须「随形态走」，而不是悬在空中**。可重构机构（可锁关节、模块化自重构、可换末端、变拓扑）让同一台机器人在任务中改变运动学结构。v4 的覆盖 / 物理 / 末端 / 平衡证书都是针对某个固定运动学模型 K 铸造的；换形态后，旧证书可能指向一个已不存在的连杆或一个不可达区域，属于「跨形态误用」。直觉上，证书不该是绝对真值，而应携带一个**有效域** D——它在哪些形态、哪些构型、哪些世界状态下被证据支持。换形态时，能沿路径「搬运」的证书直接复用，不能搬运的必须重铸。这既避免误用，也避免每次都全量重算。

2. **语义地图：覆盖从「几何可达」升级为「语义-可供性可达」**。v4 的 3DCF 只回答「这个空间点被传感器看过吗」。语义地图回答「那是什么、能对它做什么（affordance）、标签有多确定」。于是覆盖问题变成：任务需要的可供性 A_task，能否在语义地图中某个高置信物体上、由当前形态的可达构型实现？这引入三类新误差：标签错（把插头当开关）、接地错（语义位姿与点云/几何不一致）、漂移错（物体被移动但地图没更新）。三者都会把「看得见」误判为「可安全操作」。

3. **两词的交叉才是关键：形态-可供性匹配**。语义地图给出「世界提供什么可供性」，可重构机构给出「本体能实现什么可供性」。安全执行要求二者在**同一构型纤维**上匹配。可重构的价值恰在于：当某可供性在当前形态不可达时，机器人可以换形态去够到它；但换形态本身必须重新认证。这把「重构」从机械自由度问题提升为「证据在纤维丛上是否可输运」的问题。

**关键洞见**：v1~v4 把机器人身体当常量、把世界当几何；v5 把二者都变成变量，于是证据不再是布尔命题，而是**定义在「语义世界 × 形态构型」纤维丛上的一个带有效域的截面（section）**。安全 = 执行路径始终落在证书有效域内；重构 / 语义更新 = 沿路径做证书输运，出域即失效、必须重铸。由此得到一条可发表的主线：**证书输运演算 + 分层不变性（base-invariant / fiber-invariant / coupled）+ 形态-可供性匹配的完备性**。

**形式化目标（增量）**：
1. 定义证据纤维丛 𝔈 = ⊔_{m∈𝔐}(𝔅 × Q_m)，投影 π:𝔈→𝔐；状态 e=(b,m,q)（世界语义 b、形态 m、构型 q）。
2. 定义构型索引证书 CIC c=(φ,D,prov,τ_c,ttl)，D⊆𝔈 为认证有效域；活性 live(c,e,t)。
3. 定义输运算子 T_γ 与可输运性；证明输运可靠性定理（γ⊆D ⇒ 证据在 γ(1) 仍成立）。
4. 定义分层不变性：base-invariant（语义 / 价值 / 记忆 / 物体物理）、fiber-invariant（形态 / 自模型 / 标定）、coupled（覆盖 / 末端 / 平衡 / 匹配），并给出各类在重构 / 语义更新下的失效规则。
5. 定义形态证书 MCC 与硬门 kc_morph = (e_self ≤ ε_self) ∧ (e_cal ≤ ε_cal) ∧ (μ_sing ≥ μ_min) ∧ (T_A ⊆ R_A(m))。
6. 定义语义证书 SGC 与硬门 kc_sem = (C_α ⊆ L_safe) ∧ (g_cons ≥ τ_g) ∧ (H_sem ≤ H_max) ∧ (d_drift ≤ d_max) ∧ (A_task ⊆ A_real)，其中 C_α 为保形标签集。
7. 定义形态-可供性匹配证书 MMC；构造反例证明 kc_morph ∧ kc_sem（仅位置可达版本）不足以保证匹配，必须用可供性条件可达性 R_A。
8. 定义语义失效传播与依赖追踪；证明失效完备性（更新后无活跃证书引用已变区域）。
9. 定义 EFA-v5 九硬门与软评分 ECS_v5 = ECS_v4 · η_morph · η_sem；纤维内 Exec_v5 ⊆ Exec_v4，跨纤维用输运闭合替代包含。
10. 给出实验：重构中任务、语义歧义、地图漂移、对抗误标；指标含误用率、陈旧证书率、活性、重铸成本。

**本轮最大风险**：语义漂移与拓扑切换叠加，使证书有效域 D 的精确刻画极难——保守估计会让执行集塌缩到「什么都不做」（活性丧失），乐观估计则让过期证书跨形态 / 跨语义更新被误用（把安全变成误动）。

### IP-493 MACK：形态适配证书（重构 / 换末端时，离线重建 + 在线 O(1) 查询）

```python
@dataclass
class MorphologyAdaptationCertificateKernel:
    """MACK：自模型 + 标定迁移 + 奇异裕度 + 可供性可达；kc_morph 硬门"""
    eps_self: float = 0.005       # 自模型残差阈值 (m)
    eps_cal: float = 0.003        # 标定迁移误差阈值
    mu_min: float = 0.05          # 奇异裕度下限 σ_min/σ_max
    registry: MorphologyRegistry = None
    reach_cache: dict = field(default_factory=dict)   # morph_id -> R_A 体素哈希

    def on_reconfigure(self, m_prev: Morphology, m_new: Morphology,
                       q_cal: np.ndarray, fiducials: np.ndarray, t_now: float) -> MCC:
        # 1) 标定迁移：共享连杆 / 关节继承 θ_cal，新模块标记为未标定
        e_cal = self._transport_calibration(m_prev, m_new)
        # 2) 自模型残差：标定位姿下 FK 预测 vs 视觉 / 编码器实测
        e_self = self._self_model_residual(m_new, q_cal, fiducials)
        # 3) 奇异裕度：任务相关构型上的最小 σ_min/σ_max
        mu_sing = self._min_singularity_margin(m_new, q_cal)
        # 4) 可供性条件可达性：离线体素化 (x, a) + 哈希；重构时重建
        R_A = self._affordance_reachability(m_new)
        return MCC(m=m_new, e_self=e_self, e_cal=e_cal, mu_sing=mu_sing,
                   R_A=R_A, t=t_now)

    def kc_morph(self, mcc: MCC, task_affordances: frozenset) -> bool:
        """引理 43：通过 ⟹ 自模型 / 标定可信、非奇异、任务可供性可达"""
        return (mcc.e_self <= self.eps_self
                and mcc.e_cal <= self.eps_cal
                and mcc.mu_sing >= self.mu_min
                and task_affordances <= mcc.R_A)

    def _transport_calibration(self, m_prev, m_new) -> float: ...
    def _self_model_residual(self, m, q_cal, fiducials) -> float: ...
    def _min_singularity_margin(self, m, q_cal) -> float: ...
    def _affordance_reachability(self, m) -> frozenset: ...
```

### IP-494 SGAK：语义接地与可供性（规则准入 / 语义更新时，~1–10 ms）

```python
@dataclass
class SemanticGroundingAffordanceKernel:
    """SGAK：保形标签集 + 接地一致 + 语义熵 + 漂移 + 可供性；kc_sem 硬门"""
    alpha_target: float = 0.05    # 保形目标误覆盖率
    alpha: float = 0.05           # 当前工作误覆盖率（ACI 自适应）
    gamma: float = 0.01           # ACI 步长
    tau_g: float = 0.8            # 接地一致度阈值
    H_max: float = 0.5            # 语义熵上限 (nats)
    d_max: float = 0.1            # 语义-几何漂移上限
    calibrator: ConformalCalibrator = None
    dep_index: DependencyIndex = None

    def observe(self, sem_map: SemanticMap, geo_map: GeometricMap,
                region: Region, task: Task, t_now: float) -> SGC:
        C_alpha = self.calibrator.predict_sets(sem_map, region, self.alpha)
        g_cons = self._grounding_consistency(sem_map, geo_map, region)
        H_sem = self._semantic_entropy(sem_map, region)
        d_drift = self._drift(sem_map, region, t_now)
        A_real = self._realizable_affordances(sem_map, region)
        return SGC(C_alpha=C_alpha, g_cons=g_cons, H_sem=H_sem,
                   d_drift=d_drift, A_real=A_real, t=t_now)

    def kc_sem(self, sgc: SGC, safe_labels: frozenset,
               task_affordances: frozenset) -> bool:
        """引理 44：通过 ⟹ 真标签以 ≥1−α 落在安全集内，且可供性可接地实现"""
        return (sgc.C_alpha <= safe_labels
                and sgc.g_cons >= self.tau_g
                and sgc.H_sem <= self.H_max
                and sgc.d_drift <= self.d_max
                and task_affordances <= sgc.A_real)

    def invalidate(self, changed: Region) -> list[str]:
        """语义失效传播：返回依赖集与 changed 相交的全部证书 id（定理 8）"""
        return self.dep_index.query(changed)

    def adapt_alpha(self, err_t: float) -> None:
        """自适应保形 ACI：分布漂移下维持长期误覆盖率 ≤ alpha_target + o(1)"""
        self.alpha = float(np.clip(
            self.alpha + self.gamma * (self.alpha_target - err_t), 0.0, 1.0))

    def _grounding_consistency(self, sem, geo, region) -> float: ...
    def _semantic_entropy(self, sem, region) -> float: ...
    def _drift(self, sem, region, t) -> float: ...
    def _realizable_affordances(self, sem, region) -> frozenset: ...
```

### IP-495 BUNCALC：纤维丛证书演算与核心定理（离线理论，不在控制环）

```python
@dataclass(frozen=True)
class CIC:
    """构型索引证书：谓词 + 有效域 + 证据来源 + 铸造时刻 + 存活期 + 分层标签"""
    phi: str
    D: Domain                    # 世界区域 × 形态 × 构型集
    prov: str
    tau_c: float
    ttl: float
    inv: str                     # 'base' | 'fiber' | 'coupled'

class BundleCalculus:
    @staticmethod
    def live(c: CIC, e: State, t: float, invalidated: bool) -> bool:
        return (c.D.contains(e) and (t - c.tau_c) <= c.ttl and not invalidated)

    @staticmethod
    def transport(c: CIC, gamma: Path) -> Optional[CIC]:
        """输运可靠性：路径完全落在有效域内才可搬运，否则 ⊥（必须重铸）"""
        if gamma.contained_in(c.D):
            return replace(c, tau_c=gamma.t_end)   # 同一证据，刷新时刻
        return None

    @staticmethod
    def invalidate_on_world_change(certs, changed_region, dep_index):
        """base + coupled 中依赖命中者失效；fiber-invariant 保留（定理 8）"""
        return [c for c in certs
                if c.inv != 'fiber' and dep_index.intersects(c, changed_region)]

    @staticmethod
    def invalidate_on_reconfigure(certs, m_old, m_new):
```

### IP-496 EFA-v5：九硬门 + 软评分 + 证据铸造流水线 v5

```python
@dataclass
class EvidenceForgingAssemblerV5:
    """EFA-v5：九硬门 fail-closed；软评分 ECS_v5 = ECS_v4 · η_morph · η_sem"""
    scf: SpatialCoverageFieldKernel
    msrg_cache: dict
    hic: HumanIntentCertificateKernel
    eek: EndEffectorFidelityKernel
    ltem: LongTermEpisodicMemory
    vack: ValueAlignmentCertificateKernel
    bck: BalanceControlKernel
    mack: MorphologyAdaptationCertificateKernel
    sgak: SemanticGroundingAffordanceKernel
    mu_S: float = 0.75
    w: tuple = (0.4, 0.4, 0.2)

    def hard_gate(self, x, t_now, rule_id, hic, eec, bcc, mcc, sgc,
                  object_class, geo_sig, theta_domain_fp,
                  traj, context, task_affordances) -> tuple[bool, str]:
        # 优先级：HIC veto > 其余八硬门（并行评估，任一失败即拒）
        if self.hic.veto_active(hic):                 return False, 'HIC_STOP'
        if not self.scf.kc_coverage(x, t_now):        return False, 'COVERAGE_BLIND'
        s2rc = self.msrg_cache.get(rule_id)
        if s2rc is None or s2rc.verdict != 'accept' or s2rc.mu_pass < self.mu_S:
            return False, 'PHYSICS_UNPROVEN'
        if not self.eek.kc_ee(eec):                   return False, 'EE_UNPROVEN'
        if not self.bck.kc_bal(bcc):                  return False, 'BALANCE_UNSTABLE'
        if not self.mack.kc_morph(mcc, task_affordances):
            return False, 'MORPHOLOGY_INVALID'
        if not self.sgak.kc_sem(sgc, context.safe_labels, task_affordances):
            return False, 'SEMANTIC_UNGROUNDED'
        pass_mem, eta_mem, novelty = self.ltem.query(
            object_class, geo_sig, theta_domain_fp, rule_id)
        if not pass_mem:                              return False, 'MEMORY_REJECT'
        vac = self.vack.evaluate(traj, context, t_now)
        if not self.vack.kc_val(vac):                 return False, 'VALUE_MISALIGNED'
        return True, 'FORGED' + ('|NOVELTY' if novelty else '')

    def ecs_v5(self, x, t_now, rule_id, A_att=0.0, eta_mem=0.5,
               eta_val=0.5, eta_bal=0.5, eta_morph=0.5, eta_sem=0.5) -> float:
        base = (self.scf.gamma3d(x, t_now)**self.w[0]
                * getattr(self.msrg_cache.get(rule_id), 'mu_pass', 0.0)**self.w[1]
                * (1 + self.w[2]*A_att))
        return base * eta_mem * eta_val * eta_bal * eta_morph * eta_sem
```

## 4. 正确性论证（增量更新）

### 引理 43（形态硬门的可靠性界）

**陈述**：设自模型残差估计噪声 ≤ σ_self、标定迁移估计噪声 ≤ σ_cal、奇异裕度估计噪声 ≤ σ_sing。若 kc_morph 通过，则真实自模型误差 ≤ ε_self + σ_self、真实标定迁移误差 ≤ ε_cal + σ_cal、任务构型最小奇异裕度 ≥ μ_min − σ_sing，且任务所需可供性在当前形态下真实可达（在可达体素分辨率内）。

**证明**：各量由标定位姿 / 视觉 / 编码器实测估计，估计误差有界；硬门对各估计量取保守阈值，三角不等式给出真实值上界；可达性由离线体素化采样给出，分辨率误差计入 σ_sing / R_A 边界。∎

**工程含义**：把「换形态后能不能用」从人工经验变成可计算的证书；不可迁移的标定必须重标，而不是带病复用。

### 引理 44（语义硬门的保形可靠性）

**陈述**：设语义标定集与在线物体可交换，split conformal 给出 P(Y ∈ C_α) ≥ 1−α。若 kc_sem 通过且 C_α ⊆ L_safe，则 P(Y ∈ L_safe) ≥ 1−α；结合接地一致与漂移界，语义导致的错误准入率 ≤ α + P(接地失败) + P(漂移越界)。在 ACI 下，分布漂移时长期平均误覆盖率收敛到 α_target + o(1)。

**证明**：保形边际覆盖直接给出第一项；接地 / 漂移为确定性门，失败即拒绝，故错误准入被三者并集界住；ACI 更新为在线梯度下降，标准长期覆盖结论。∎

**工程含义**：语义不是「检测器说什么就是什么」，而是「以可校准的置信度说它安全」；未知 / 歧义标签默认拒绝或回退几何保守规则。

### 引理 45（形态-可供性匹配的必要性）

**陈述**：仅用位置可达性 R_pos(m)（而非可供性条件可达性 R_A(m)）时，kc_morph ∧ kc_sem 不能保证可执行。反例：语义地图高置信标注「带柄杯子（可供性 grasp_handle）」，任务要求抓柄；形态 m 的末端位置可达杯柄（(x, grasp_handle) ∈ R_pos），但其夹爪最大开度小于柄径，故 (x, grasp_handle) ∉ R_A(m)。两门均通过，执行必失败。

**证明**：构造上述反例即得；R_A 显式编码 (位置, 可供性) 对，故 kc_morph 的 T_A ⊆ R_A(m) 排除了该反例。∎

**工程含义**：语义与形态必须在「可供性」这一共同语言上匹配，而不是各自独立通过；这也是可重构机构的价值所在——换形态可把不可达的可供性变为可达。

### 定理 v5（纤维内严格收缩 + 跨纤维输运闭合 + 九锚点完备）

**陈述**：在 (B1)~(B7) 下：
(i) 固定 (b,m) 时 Exec_CADVS-v5(b,m) ⊆ Exec_CADVS-v4(b,m)（严格，若新硬门非恒真）；
(ii) 跨形态 / 跨语义更新时，全局包含关系一般不成立，但任何被准入的规则要么在目标状态重铸、要么由有效域覆盖该路径的证书输运而来，故不存在未认证准入（安全性保持）；
(iii) 语义导致的非法准入率由定理 7 界；形态误用率由引理 43 界；形态-可供性匹配由引理 45 保证；
(iv) 语义更新后陈旧证书误用率为 0（定理 8，依赖追踪完备时）；
(v) 九锚点互补完备（定理 9）。

**证明**：(i) 由定理 5；(ii) 由定理 6；(iii) 由引理 43/44/45 与定理 7；(iv) 由定理 8；(v) 由定理 9 反例构造。∎

**诚实声明**：(B7) 语义可交换性在开放世界中经常不成立（新物体、新场景、对抗误标），保形覆盖会退化；缓解为 ACI + 漂移监测 + 分布外拒识 + 几何保守回退。(B6) 可重构机构的柔性 / 间隙 / 装配误差难以建模，自模型残差可能被低估；缓解为多标定位姿、力觉一致性检验与鲁棒边际放大。此外，定理 6 明确放弃了「全局单调收缩」这一前几轮的漂亮性质——这是为了不欺骗读者：形态一变，世界就变了。

| R59 | **九锚点维护负债**（接口 / 测试 / 文档 / 故障模式指数增长） | 中 | 模块化契约测试 + 统一证书总线 + 自动故障注入矩阵 | 复杂度持续上升 |

## 7. 本轮最大风险（最终确认）

**一句话**：**语义漂移与拓扑切换叠加，使证书有效域 D 的精确刻画极难——保守估计会让执行集塌缩到「什么都不做」（活性丧失），乐观估计则让过期证书跨形态 / 跨语义更新被误用（把安全变成误动）。**
