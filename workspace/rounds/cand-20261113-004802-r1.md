# 第 3 轮迭代（灵感循环 v3：「语言指令」×「仿真训练」）—— 指令即合同，仿真即课程

> 承接 v2 的 UIP-01′~15。v2 打通了「人为干扰=反向撤回」这条规则事实，并给出 Gazebo 计分神谕（UIP-11）与扰动-恢复数据工厂（UIP-12）。但 v2 留了两个未闭合的接缝：① **验证器/计分谓词靠逐任务手写**（32 任务 × 2–5 步，写全且写对几乎不可能）；② **扰动脚本靠逐条 `human_*` 手工翻译**（组合与未见的干扰覆盖不了）。本轮两个灵感词正好补这两道缝：**语言指令**是唯一能自动生成「规格」的低维信号；**仿真训练**是把规格变成「稠密监督」的最廉价方式。合起来是一句可执行的口号：**用语言把任务编译成合同，再用仿真按合同生成课程与标签。**

## 0. 本轮直觉（先结论，后定义）

直觉上，UniBot 真正稀缺的不是「动作」，而是「**判定**」：你无法在家知道「这一步到底算不算完成」，也无法知道「人把进度撤回了没有」。而这两件事的答案，**已经写在评测方的自然语言里**——`observation.language` 是任务身份，`info.json.score_steps` 是分步自然语言，`generalization.human_*` 是干扰自然语言。v2 把它们当「提示」；本轮把它们当「**可执行规格**」。

一个跨学科类比：编译器把高级语言编译成机器码；我们把「任务自然语言 + 分步文本 + 干扰文本」编译成三样东西——**子目标 DAG、几何谓词、扰动文法**。有了这三样，仿真就不再只是「离线裁判」（v2 的 GSO），而是「**课程生成器 + 自动标注器**」：它按扰动文法造出 `(正常 → 撤回 → 恢复)` 的 episode，并用精确的几何真值给验证器打标签。于是 v2 的「手工写谓词 / 手工造干扰 / 手工标数据」三个瓶颈，被同一条 **语言→合同→仿真** 的流水线一次性打通。

信息论直觉（可检验）：设 `S` 为最终步骤分，`L` 为语言指令，`O_t` 为单帧观测。单帧图像对「这是 32 个桌面任务中的哪一个」高度歧义，而语言几乎唯一确定任务身份与步骤权重，故 `I(L;S) ≫ I(O_t;S)`。这不是玄学，E204 用「打乱/置空指令」的消融直接测。

## 2. 上轮清单诊断（v2 → v3）

- **升级**：UIP-01′ → **01″**（验证器从「手写几何谓词」改为「合同编译 + 仿真训练」）；UIP-11 GSO → **11′ 监督神谕**（不只打分，还产标签）；UIP-12 DRF → **12′ 文法驱动**（扰动脚本由 grammar 生成）；UIP-14 MSGR → **14′**（技能图由合同的子目标 DAG 推导，而非手搭）。
- **合并/封存**：UIP-05 LCAG 并入 **UIP-16 L2C**（语言→可供性本就是合同编译的一支）；UIP-09′ DCR-R 并入 **UIP-18 LGV + 01″** 的 `regress` 分支；UIP-02′ 的计分调度并入合同的权重 `w`。
- **修剪**：UIP-13 ACS 的「投机预计算」**删除**——它与扰动机制在原理上冲突：投机预计算假设 `o_{t+1}` 可由 `o_t` 预测，而「反向撤回」的定义就是 `o_{t+1}` 违反该预测；二者负相关。只保留「阶段自适应 k」。
- **新增**：UIP-16 L2C（语言→合同编译器）、UIP-17 STC（仿真训练课程/自动标注）、UIP-18 LGV（语言接地验证器 + 撤回转移估计）、UIP-19 CPA（合同先验审计）。

## 3. 两个灵感词的解读

1. **语言指令**：三层用法——(a) **合同索引**：用 `language` 在 32 份合同里定位；(b) **顺序与权重**：`score_steps` 的编号/动词天然给出 DAG 与 `w_v`；(c) **干扰算子的来源**：`human_*` 文本里的「再/回来/翻开/拉开/拿走/拿下/放回/拔起」直接对应反向算子 `ρ`。关键工程约束：**解析全部在离线编译期完成**，运行期只做「文本嵌入查表 + 主骨干编码」——从而规避「外部大模型 = 非单模型」的合规风险。
2. **仿真训练**：从「用仿真评估」升级为「用仿真监督」。仿真能提供 `φ_v` 的**精确真值**（物体位姿、接触、包含、拉链闭合比例），因此验证器可以**自动获得稠密标签**，不需要人工标注；扰动文法让仿真生成「撤回」这种真机数据里为零的事件；域随机化覆盖视觉/物理 gap。

## 4. 严谨定义

**定义 1（任务合同）**。合同 `C = (O, G, w, Φ, Δ, Λ)`：
- `O = {o_1,…,o_m}`：对象符号，带属性 `attr(o) ⊂ {color, shape, material, category}` 与可供性；
- `G = (V,E)`：子目标 DAG，`V={v_1..v_n}` 按拓扑序编号，`E ⊆ V×V` 为严格先后；
- `w: V → R_{≥0}`，`Σ_v w_v = 100`，与 `score_steps` 对齐；
- `Φ = {φ_v}`：每个子目标的**可测谓词** `φ_v: (I_t, X_t) → {0,1}`，`I_t` 为图像观测、`X_t` 为仿真特权状态（位姿/接触）；由分步文本 `π_v` 经模板库实例化；
- `Δ`：扰动文法（定义 4）；
- `Λ`：语言指令及其改写的嵌入键集合。

编译算子 `Compile: (l, {π_v}, {human_*}) → C`，离线执行一次，逐任务人工抽检。

**定义 2（进度向量与前沿）**。`p_t(v) = φ_v(I_t, X_t)`；进度向量 `p_t ∈ {0,1}^{|V|}`。按拓扑序定义前沿 `f_t = min{i : p_t(v_i)=0}`（全完成则 `n+1`）。**假设 A1（评分时点）**：官方按 episode 结束时的状态计分（否则「撤回」对分数无意义）；若实际是「曾达成即得分」，则 `reverse` 干扰只会浪费动作、不会扣步骤分——E206 专门区分这两种模式。

**定义 3（撤回是一个转移，不是一个状态）**。相邻决策步的进度转移
`T_t = regress`，若 `∃v: p_{t-1}(v)=1 ∧ p_t(v)=0`；
`T_t = advance`，若 `∃v: p_t(v)=1 ∧ p_{t-1}(v)=0`；
否则 `T_t = stay`。同时发生则 **regress 优先**。撤回集 `R_t = {v: p_{t-1}(v)=1 ∧ p_t(v)=0}`。这样定义的好处：验证器只需估计一个三分类转移，而不必直接回归「被撤回」这个稀疏标签。

**定义 4（扰动文法）**。`Δ = (A, Rules, s_0)`：
- 原子算子 `α = (type, target, trigger, params)`，`type ∈ {translate, invalidate, reverse, remove, replace, occlude}`，`trigger` 是进度/时间上的谓词；
- 产生式 `Rules` 把原子算子组合成序列 `δ = α_1…α_k`；`L(Δ)` 为生成的语言；
- 文本映射：`reverse` ← 「再/回来/翻开/拉开/拿走/拿下/放回/拔起/拧回」；`translate` ← 「向前/向后/向左/向右/向上/向下移动」；`invalidate` ← 「抓…之后/中途/马上…挪」；`remove` ← 「把…拿走/拿下」；`replace` ← `unseen_object_*`。

**定义 5（合同条件课程与联合目标）**。采样 `δ ~ D_Δ`、初态 `s_0 ~ D_0`，仿真产生含 `X_t` 的轨迹。联合目标
`J(θ) = E_{δ~D_Δ} Σ_t [ BCE(V_θ(I_t,l,v), p_t(v)) + λ_1 CE(T_θ(I_t,I_{t-1},l), T_t*) + λ_2 L_policy(π_θ(I_t,l,f_t), a_t*) ]`。
关键：**同一个合同 `C` 同时提供验证器标签 `p_t`、转移标签 `T_t*` 和策略条件 `f_t`**，三者共享监督，避免三套手工标注。

**命题（语言的边际价值）**。在可加计分模型 `S = Σ_v w_v p_v` 下，
`H(S|I_t) = H(S|I_t,C) + I(C;S|I_t)`。
`C` 由 `L` 与任务元数据确定，故语言消掉的是「任务身份 + 权重/顺序」的不确定性，留下的是「感知真值」的不确定性。E204 通过置空/打乱 `L` 直接估计上式右端第二项；若接近 0，则语言假设不成立，应回退到纯视觉路线。

## 5. 瓶颈假设（更新）

- **H1（编译覆盖率是天花板）**：若 `φ_v` 无法从分步文本自动实例化，下游（仿真标签、验证器、状态机）全部失效。先测「30 个有泛化字段的任务里，多少子目标能被模板库实例化」。
- **H2（仿真标签精确但有偏）**：仿真真值在 `X_t` 上精确，却在视觉/接触外观上与真机有 gap；纯学习验证器会把仿真纹理当捷径。故采用**规则先验 + 学习残差**的混合验证器，而不是纯端到端。
- **H3（撤回检测是转移估计）**：误报 `regress` 会导致「反复重做」；漏报会导致「步骤分被悄悄扣掉」。用「置信度门限 + 最大重做次数 + 延迟预算」三重护栏（UIP-15）。
- **H4（指令分布漂移）**：若评测改写指令或出现同义动词，精确字符串查表会失效；用主骨干文本嵌入做最近邻，并保留模板语法回退。
- **H5（合规）**：任何在运行期调用外部 VLM/LLM 的方案都可能被判「非单模型」；语言解析必须留在离线编译期。

## 6. 候选合并 → v3 清单（详见产物区）

v2 的 15 项中保留 10 项、合并 3 项、修剪 1 项，新增 4 项：**UIP-16 L2C**（语言→合同）、**UIP-17 STC**（仿真训练课程）、**UIP-18 LGV**（语言接地验证器）、**UIP-19 CPA**（合同审计）。旗舰从 v2 的「扰动恢复闭环」上移一层，变成 **「语言合同 → 仿真监督 → 撤回恢复」的闭环**：L2C 产规格，STC 产标签，LGV 做判定，01″ 做调度，CPA 做质检。

## 7. 本轮最大风险

**一句话**：合同编译错误会被仿真**自动放大**——一个错接的谓词会让仿真生成错误标签、训练出错误验证器，再用错误验证器去「纠正」策略，形成闭环自欺；而唯一的真相锚点（真机步骤分）恰恰最稀缺。因此本轮把 **UIP-19 CPA（合同审计）** 与「规则先验 + 学习残差」的混合验证器列为一等公民，而不是事后补丁。

## 1. 旗舰闭环：UIP-16 L2C → UIP-17 STC → UIP-18 LGV → UIP-01″

```
language / score_steps / human_*
        │  UIP-16 L2C（离线编译）
        ▼
   Contract C = (O, G, w, Φ, Δ, Λ)
        │  UIP-17 STC（仿真课程 + 自动标签）
        ▼
   (I_t, p_t, T_t*, a_t*)  稠密监督
        │  训练
        ▼
   UIP-18 LGV（V 头 + T 头）  ──►  UIP-01″ 运行时状态机
        │                              │
        └──── UIP-19 CPA 审计 ◄────────┘
```

- **与 v2 的本质差异**：v2 的验证器是「人写谓词 + 人写规则」；v3 的验证器是「文本编译出谓词模板 → 仿真产生真值 → 学习残差」。v2 的 GSO 只做**评价**；v3 的 STC 做**监督**。
- **可行性**：分步文本已存在（`score_steps` 双语），无需自造标注；仿真标签在 `X_t` 上精确；运行期只多两个轻量头，共享主骨干。
- **落地顺序**：① 在 3 个代表任务（T19 拉链、T27 叠碗、T26 插网线）上手工验证 16→17→18 全链路；② 扩到 8 个 reverse 任务；③ 再扩到 30 个有泛化字段的任务；④ T31/T32 无泛化字段，先只做合同与验证器，不做扰动课程。
- **风险**：见 §10，核心是「错谓词被仿真放大」。

## 3. 编译器 L2C 与覆盖率

```python
import re

TEMPLATES = {
    "grab":     [("grab {X}",              lambda b: holds(b["X"]))],
    "place":    [("place {X} in {Y}",      lambda b: inside(b["X"], b["Y"])),
                 ("put {X} on {Y}",        lambda b: on(b["X"], b["Y"]))],
    "stack":    [("stack {X} onto {Y}",    lambda b: stacked_on(b["X"], b["Y"]))],
    "fold":     [("fold {X}",              lambda b: fold_count(b["X"]) >= 1)],
    "zip":      [("zip up {X}",            lambda b: zipper_closed(b["X"]) >= 0.95),
                 ("unzip {X}",             lambda b: zipper_closed(b["X"]) <= 0.05)],
    "insert":   [("plug {X} into {Y}",     lambda b: insert_depth(b["X"], b["Y"]) > D)],
    "straighten":[("straighten {X}",       lambda b: axis_angle(b["X"]) <= 10)],
}

def compile_step(text, objects):
    text = text.lower().strip(" .")
    for verb, cands in TEMPLATES.items():
        if not text.startswith(verb):
            continue
        for pattern, pred in cands:
            b = bind(pattern, text, objects)     # 文本 → 对象绑定
            if b is not None:
                return CompiledPredicate(pred, b, confidence=1.0)
    return LearnedFallback(text, objects, confidence=0.0)  # 低置信，需 CPA 抽检

def compile_contract(task, template_db):
    O = parse_objects(task)                          # 属性/可供性
    V, E, w = parse_steps(task["score_steps"])       # 顺序 + 权重
    Phi = {v: compile_step(v.text, O) for v in V}
    Delta = compile_disturbances(task.get("generalization", {}), O, V)
    return Contract(task["language"], O, (V, E), w, Phi, Delta)

def compile_disturbances(gen, O, V):
    ops = []
    for key, note in gen.items():
        if not key.startswith("human_"):
            continue
        if any(k in note for k in ["再", "回来", "翻开", "拉开", "拿走",
                                   "拿下", "放回", "拔起", "拧回"]):
            ops.append(Delta("reverse", target=match_object(note, O),
                             trigger=parse_trigger(note, V)))
        elif any(k in note for k in ["之后", "中途", "马上"]):
            ops.append(Delta("invalidate", target=match_object(note, O),
                             trigger=parse_trigger(note, V)))
        else:
            ops.append(Delta("translate", target=match_object(note, O),
                             trigger="always", params=parse_dir(note)))
    return ops
```

**覆盖率**：`Cov(C) = (1/|V|) Σ_v 1[φ_v 由模板实例化]`。目标：30 个有泛化字段任务上 ≥ 90%（E201）；若 < 70%，L2C 的自动化收益不足以抵消人工抽检成本，应退回 v2 的手写谓词路线。

## 4. 扰动文法与四类任务

```python
class Delta:
    ATOMS = {"translate", "invalidate", "reverse", "remove", "replace", "occlude"}
    def sample(self, rng):
        # 以 0.55 概率只采 human_1、0.45 只采 human_4；再以 0.2 概率组合两条
        seq = []
        if rng.random() < 0.2:
            seq = [self.pick("human_1"), self.pick("human_4")]
        else:
            seq = [self.pick("human_1" if rng.random() < 0.55 else "human_4")]
        return seq
    def triggered(self, seq, p, t):
        return all(trigger_holds(a.trigger, p, t) for a in seq[:self.idx])
```

| 类型 | 任务 | 运行时正确反应 |
|---|---|---|
| `translate`（16） | T01,T02,T03,T04,T06,T07,T09,T13,T15,T18,T20,T21,T22,T23,T28,T30 | 重新定位 → 继续当前子目标（不需要回退） |
| `invalidate`（6） | T05,T08,T11,T25,T26,T29 | 当前子目标置为未完成 → `redo` 当前步 |
| `reverse`（8） | T10,T12,T14,T16,T17,T19,T24,T27 | `p(v)` 由 1→0 → 前沿回退 → `redo` 被撤回步 |
| `none`（2） | T31,T32 | 无文本可编译；只做合同与验证器，不生成扰动课程 |

> **关键**：四类干扰的「正确反应」不同。v2 把所有干扰都当 `reverse` 处理，会在 16 个 `translate` 任务上过度回退、白丢步骤分。v3 用 grammar 的类型区分，这是「语言→规格」带来的直接收益。

## 5. STC：仿真训练课程与自动标注

```python
def stc_episode(C, sim, expert):
    X = sim.reset(C.O)
    seq = C.Delta.sample(sim.rng)
    idx, labels = 0, []
    for t in range(C.max_steps):
        I = sim.render(X)
        p = {v: C.phi[v](I, X) for v in C.V}        # 精确真值
        # 转移标签由前后 p 计算（regress 优先）
        T = transition(prev_p, p) if t else "stay"
        labels.append((I, p, T))
        # 注入干扰
        while idx < len(seq) and trigger_holds(seq[idx].trigger, p, t):
            X = sim.apply(X, seq[idx]); idx += 1
        # 恢复示范：脚本规划器或从数据集回放
        a_star = expert.action(X, C, target=current_frontier(p))
        X = sim.step(X, a_star)
        prev_p = p
    return labels

def transition(p0, p1):
    if any(p0[v] == 1 and p1[v] == 0 for v in p0): return "regress"
    if any(p0[v] == 0 and p1[v] == 1 for v in p0): return "advance"
    return "stay"
```

联合训练目标：

`J(θ) = E Σ_t [ BCE(V_θ(I_t,l,v), p_t(v)) + λ₁ CE(T_θ(I_t,I_{t-1},l), T_t*) + λ₂ L_policy(π_θ(I_t,l,f_t), a_t*) ]`

- **验证器标签**来自 `φ_v`（精确、免费、稠密）；**转移标签**由 `φ_v` 的前后差分定义（稀疏但可由 `T_t*` 三分类平衡）；**策略标签**来自脚本恢复示范或数据集回放。
- **域随机化**：光照/纹理/相机位/摩擦/质量/延迟；干扰的**时机、速度、轨迹**随机化，避免「仿真干扰形态」过拟合。
- **不声称**：STC 训练出的策略不是真机策略；E205 专门量 sim-to-real 的秩相关。

## 6. LGV：语言接地验证器与转移估计

结构（全部共享主骨干 `B`，满足单模型）：

```
I_t ─► B ─┬─► V_θ (per-subgoal sigmoid, |V| 个输出) ─► p̂_t, conf
          └─► T_θ (mean-pool 后接 GRU over H 帧) ─► P(advance/stay/regress)
l ──► B.text ─┘（FiLM 条件化到 V_θ 与 T_θ）
```

- **混合先验**：`V_θ = σ( w·φ_rule(I_t) + (1-w)·f_θ(I_t,l) )`，`φ_rule` 是轻量几何/颜色判据（无需学习），`f_θ` 是学习残差。mismatch 时输出高不确定性，触发 `stay` 而非误触发 `regress`。
- **校准**：温度缩放 + reliability diagram；只有 `conf > τ` 才允许 `advance/regress`，否则 `stay`（宁可慢，不可乱）。
- **运行期拿不到 `X_t`**，只有 `I_t`：所以 `V_θ` 必须从像素估计 `φ_v`；STC 用 `X_t` 产标签、但训练输入只给 `I_t`（特权信息仅用于标签，不进推理）。

## 7. UIP-01″ 运行时状态机（按开环块接口修正）

> v2 伪代码把 `get_action` 返回单步动作；实际接口是**返回整块、评测端整块执行后才回调**。因此验证频率 = `1/k`，`regress` 的检测延迟上界 = `k` 步。这是 UIP-13′ 存在的根本原因。

```python
class ContractPolicy:                      # UIP-16/18/01″/13′/15
    def __init__(self, backbone, vhead, thead, C, K_MAX=8,
                 tau=0.6, max_redo=2, budget_ms=200):
        ...
    def reset(self):
        self.prev_p = None; self.f = 0; self.redo = 0; self.buf = []

    def get_action(self, obs):
        p_hat, conf = self.vhead(self.backbone(obs), self.C.l)
        T = self.thead(self.prev_p, p_hat, conf) if self.prev_p else "stay"

        if T == "regress" and conf >= self.tau and self.redo < self.max_redo:
            self.f = max(0, self.f - 1); self.redo += 1; self.buf = []
        elif T == "advance" and conf >= self.tau:
            self.f = min(self.f + 1, len(self.C.V) - 1); self.redo = 0; self.buf = []

        if not self.buf:
            k = self.C.phase_k(self.f, self.K_MAX)   # 接触密集→小 k
            self.buf = list(self.policy(obs, self.C, self.f, k))[:k]

        block, self.buf = self.buf, []               # 整块返回
        self.prev_p = p_hat
        return block
```

**k 的选择有一个可推导的最优**：设当前子目标权重 `w_f`、该阶段发生撤回的先验 `π_f`、动作块长 `k`、单步延迟成本 `α`，则
`k*(f) ≈ argmin_k [ α·k + w_f·π_f·(k / T_ep) ]`。
`w_f·π_f` 越大（末步 + 高撤回先验），`k*` 越小；T19 的「拉上后拉开」、T27 的「叠第二后拿下第二」应取 `k=1~2`。这把 v2 的「固定小 k」升级成**有代价模型的调度**。

## 8. UIP-11′/12′/14′/15/08′ 的更新点

- **UIP-11′ 监督神谕**：GSO 增加 `dump(X_t)` 接口，把每个子目标的 `φ_v` 真值、接触事件、对象位姿写回，供 STC 训练；仍只当「结构/顺序」裁判，不当像素级成败裁判。
- **UIP-12′ 文法工厂**：用 §4 的 `Delta` 替代手工脚本；新增「组合干扰」（`translate + reverse`）与「干扰时机随机化」。
- **UIP-14′ MSGR**：技能图节点由合同 `G` 的动词聚类得到（抓/放/插/倒/拉链/折叠/堆叠/分拣/开合/挑取），边由 `E`，不再手工建图；单骨干 + 技能适配器。
- **UIP-15 CSG**：护栏参数显式依赖 `conf` 与 `π_f`：`max_redo = ceil(1/(1-conf))` 封顶，延迟超预算则强制 `stay`。
- **UIP-08′ LAT-ENG**：按合同阶段预取不同分辨率的 obs（接触密集步用 `image_resize` 保细节，自由空间步降采样），减少 JPEG 往返。

## 9. 一个必须先证伪的前提：A1 评分时点

v2/v3 的「撤回=最大得分缺口」全部依赖 **A1：官方按 episode 结束时的状态计分**。若实际是「曾经达成即得分」，则 `reverse` 干扰只浪费动作、不扣步骤分——旗舰应从 `reverse` 转向 `invalidate`（6 个）与 `translate`（16 个）的感知重定位。两种模式的可观测差异：

| 模式 | 撤回后不重做 | 撤回后重做 | 应先攻 |
|---|---|---|---|
| 终态计分（A1 真） | 步骤分损失 `w_v` | 恢复 `w_v` | reverse + invalidate |
| 曾达成即得分（A1 假） | 步骤分不损失 | 只多耗动作 | translate（感知）+ invalidate（时序） |

E206 用「同一任务、同一干扰、撤回后是否重做」的受控 rollout 来判别；在真机不可得时，至少先在 GSO 代理里确认合同谓词能区分两种计分逻辑。

## 11. 合规、资源与时间线

**合规**
- 运行期只有一条骨干 + 一个验证头 + 一个转移头 + 技能适配器；**无外部 VLM/LLM 调用**。
- 语言解析全部离线；若用开源 LLM 辅助编译，记录为「离线工具」，并在提交说明中声明不参与推理。
- 谓词以规则模板为主、学习残差为辅；低置信时回退规则，避免「黑盒验证器」既不合规又不可审计。
- T31/T32 无 `generalization`：不生成扰动课程，只做合同与验证器；不假装有数据。

**资源**
- 离线：CPU 级 headless Gazebo 多实例 + 1 张推理卡训练验证头。
- 运行期：主骨干显存 + `|V|` 个 sigmoid + 小 GRU，增量可忽略。

**时间线（粗排）**
- 第 1–2 周：3 个代表任务的 L2C + CPA（T19/T27/T26）。
- 第 3–4 周：STC 扰动课程 + LGV 训练；E201–E203。
- 第 5–6 周：扩到 8 个 reverse 任务 + 6 个 invalidate 任务；E207/E208。
- 第 7–8 周：UIP-14′ 技能图 + UIP-13′ 阶段 k + UIP-08′ 多端口压测。
- 第 9 周起：真机锚点校准（E205），据 A1 判定切换旗舰靶点。

## 12. 本轮最大风险与押注

**一句话**：合同编译错误会被仿真自动放大——错谓词 → 错标签 → 错验证器 → 用错验证器「纠正」策略，形成闭环自欺；而唯一的真相锚点（真机步骤分）最稀缺。

**→ 押注：UIP-16 L2C × UIP-17 STC × UIP-18 LGV 组成的「语言合同 → 仿真监督」闭环，由 UIP-19 CPA 做质检、UIP-01″ 做运行时调度**。它把 v2 里三处手工瓶颈（谓词、干扰、标签）收敛为一条可审计的流水线；若 E204 的语言消融与 E205 的 sim-to-real 校准同时成立，这就是本轮相对榜单其余方案最可复用的结构性优势。
