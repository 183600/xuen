# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「多任务学习」×「对比实验」）

> R69 让闭环学会了「问」：把不确定性拆成 aleatoric / epistemic，用流匹配多模态策略呈现歧义，用「看 / 问 / 触」主动消解，预算不够才退回 R68 的保守铁律。但 R69 有一个从未写进证书的**认识论漏洞**：判断「这里有没有歧义」、「歧义值不值得查」、「查完是不是真消解了」——三件事全部由**同一个模型**给出。模态权重是它自己算的，VoI 是它自己估的，回答是它自己解释的。于是 R69 的 epistemic 机制**原则上不可被证伪**：它永远可以自信地说「我消解了」，而没有任何独立通道能反驳它。R69 自陈的最大风险（流模型幻觉出不存在模态、把真模态坍缩掉）正是这个漏洞的症状。
>
> 更尖锐的是 R69 的实验方法：E286–E300 是一张**离线消融表**。FLUID 比 R68 多采样了 K 个轨迹、多跑了一个 mode_head、多了一次交互——「交互收益 +12%」到底是交互带来的，还是**多花的算力、多跑的采样**带来的？没有匹配预算的对照，这个数字是不可归因的。R68 的缓变漂移也会同时污染 treatment 与 control，把「效果」和「漂移」混在一起。
>
> 本轮两个灵感正好补这两块：
> - **多任务学习**给出一种**内建复现**：同一个世界状态歧义，应当同时在多个任务头上显形（共同因子）；而模型幻觉出的模态只会出现在单个任务头上（特质噪声）。多任务不是「多训几个 head」，而是**把「同一现象在多个独立任务上复现」变成不确定性的有效性检验**——就像多实验室复现。
> - **对比实验**给出一种**可证伪的行动认识论**：系统可以对自己做**匹配对照试验**——空探针（sham）vs 信息探针（treatment）、时间块随机化（switchback）、双重差分（DiD）消漂移、always-valid 置信序列、试验预注册。把「问有没有用」从表格里的一个数字，变成一个有 p 值（准确说是 e-value）、可审计、可被推翻的因果陈述。
>
> 核心命题：**R70 不再新增一层「不确定性」，而是给 R69 的不确定性加一层「可被证伪的实验认识论」。** 命名 **TRIAL-RAS**（Task-Replicated Interactive Attribution & Learning，任务复现 × 交互归因 × 学习；RAS 为风险自适应闭环）。它同时问三件事：**这个歧义是真的吗（复现）？这个交互真的有用吗（对照）？我的「有用」结论本身可信吗（任意时刻有效推断）？**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我的求证本身可信吗——我拿什么对照，凭什么下结论**」——不确定性不只是刹车踏板（R68）、也不只是提问（R69），还可以是一场**预先注册、随机对照、可复现的自我试验**。

## 0. 直觉与动机

**灵感 1（多任务学习 → 复现是廉价的证伪）**
直觉：一个实验室报出「新效应」，最省的验证不是重做更贵的实验，而是看**别的实验室能不能复现**。多任务系统天然有多个「实验室」：导航头、抓取头、社交头共享同一个世界表征 z_t，却各自从不同侧面接触同一个世界状态。若「前面那个物体是杯子还是花瓶」是真歧义，它应当**同时**让抓取头犹豫（该用哪种抓法）与导航头犹豫（该不该靠近）；若只是抓取头自己幻觉出一个模态，导航头不会有反应。于是「跨任务 epistemic 一致性」是一个**不需要额外标签、不需要额外传感器**的复现检验。这把 R69 的模态权重从「必须相信的输入」降级为「待检验的假设」。

**灵感 2（多任务学习 → 不确定性要分「共享」与「特质」）**
直觉：心理测量学里，观测分数 = 共同因子 + 任务特质因子 + 噪声。R69 只做了 aleatoric / epistemic 二分，却没问 epistemic 是**关于世界的**（共享，问一次所有任务都受益）还是**关于某个任务读数的**（特质，问了也只帮一个头）。这直接决定交互该不该做：共享 epistemic 的 VoI 是**跨任务求和**（一次探针解决多个头的犹豫，正迁移）；特质 epistemic 的交互常常是**零和甚至负和**（探针改变了世界、抢占了注意预算、打扰了人，帮 A 害 B）。多任务把 R69 的标量 VoI 升级为一个**带干扰矩阵的向量值决策**。

**灵感 3（对比实验 → 空探针是「共模抑制」）**
直觉：电子工程里，差分放大器用一个「共模」参考把两路共同的噪声减掉。R69 无法区分「这个模态是真的」与「这个模态是模型自洽地编出来的」，因为两者都会让模型在收到任意输入后「自信地消解」。**造一个与真探针在成本、运动学、观测通道上都匹配、但先验上不含信息的空探针 g0**，然后看「真探针的增益 − 空探针的增益」。模型自洽产生的幻觉是**共模的**，在差分里抵消；只有真正来自世界的证据是**差模的**，留在 ΔVoI 里。这不是又加一个校准器，而是让两次测量互为参照——**用对照把不可观测的模型偏差变成可扣除的公共项**。

**灵感 4（对比实验 → 同一状态不能既处理又对照，所以用 switchback + DiD）**
直觉：物理系统里，你不可能在同一个岔口同时「问」和「不问」——问了世界就变了。这就要求**时间上的随机化**：把时间切成块（cluster），块内策略一致，块间随机切换 treatment/control（switchback），用**双重差分** (treat_after−treat_before)−(control_after−control_before) 把缓变漂移（正是 R68 最怕的、也是 R69 标定层可能吸收的东西）从处理效应里减掉。DiD 的识别假设「平行趋势」恰好是 R68 标定假设的可检验版本：如果 treatment 与 control 的 pre-trend 不平行，漂移已经在发生，试验当场作废。这把 R68 的「标定可能骗我」变成一个**可被统计检验抓住**的诊断。

**灵感 5（对比实验 → 连续决策下 p 值会撒谎，必须用 anytime-valid 证据）**
直觉：R69 每个控制周期都在看数据、随时可能「觉得够了就停」。经典 p 值在**可选停止**下会系统性高估显著性（p-hacking 的连续时间版），系统会不断「发现」其实不存在的交互收益。正解不是更严的阈值，而是换推断工具：**e-process / 置信序列**（Ville 不等式给出任意停止时刻都有效的错误控制）。再叠加**试验预注册**（在随机化前把假设、主终点、停止规则、分析计划哈希上链/入审计日志），把「先做后找解释」堵死。对比实验的严谨性不是靠事后统计，而是靠**事前承诺 + 全程有效推断**。

**灵感 6（多任务 + 对照的双刃剑 → 试验伦理与试验疲劳）**
直觉：一旦系统会「做实验」，它就在**拿真实用户/真实世界当被试**。空探针若对人撒谎，就是把 R69 的「问错」升级为「骗着问」；频繁 switchback 会让行为抖动（用户能感觉到「这机器今天怎么忽快忽慢」）；把安全否决（safety veto）的样本悄悄剔除，会制造幸存者偏差，让试验自我美化。所以本轮必须同时交付：**非欺骗性空探针约束、意图治疗（ITT）分析、veto 作为结局而非剔除、试验饱和预算、以及「对照也必须过安全认证」**。否则 TRIAL 不是科学，而是给偏见装了一个统计学外壳。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（TRIAL-RAS 总览）** TRIAL-RAS = (MTX, XUD, RPT, CVA, NCT, CMC, RSW, SEQ, PRG, RAS-WM†)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；试验结论只写 AuditBuf / 试验台账，离线才改策略）；
(ii) **交互预算与安全硬约束**（继承 R69 定义 293-ii；对照动作 g0 与处理动作 g1 同等过 C-RAS-WM 认证）；
(iii) **试验纪律**：任何「交互有效」的结论必须来自**预注册的随机化对照**，且用任意时刻有效的证据度量；单次观测、事后挑选、剔除 veto 样本，均不得写入证书。

**定义 311（多任务集成与共享表征）** 任务集 𝒯，|𝒯|=T。共享编码器 Φ 产生 z_t = Φ(o_t)；任务头 h_τ 产生任务决策 a_τ；流匹配速度场以任务嵌入 e_τ 条件化：v_θ(x_s, s | z_t, e_τ)。世界状态的一个「解释」记为 h ∈ ℋ（假设空间，例如物体身份/意图类别）。每个任务 τ 的模态 m 通过任务似然 p_τ(y_τ | h) 投影到 ℋ，从而**跨任务的模态可对齐到同一假设索引**（这是复现检验可定义的前提）。

**定义 312（跨任务不确定性分解 XUD）** 对每个任务 τ 由 R69 定义 296–297 得 (U_ale^τ, U_epi^τ)，并得模态后验 p_τ(M|o)。把 epistemic 指示量（中心化对数后验比）记为 φ_τ ∈ ℝ^{K−1}，建立**单因子模型** φ_τ = λ_τ f + ε_τ，其中 f 为世界级共同歧义因子，ε_τ 为任务特质项。定义
- `U_epi^shared = Var(f)`（跨任务可共享、一次交互可同时消解）；
- `U_epi^spec,τ = Var(ε_τ)`（只在任务 τ 内可约）；
- `U_ale^τ` 不变（定义 297）。
分解满足 `U_epi^τ = λ_τ² U_epi^shared + U_epi^spec,τ`（正交因子假设 A99）。

**定义 313（复现检验 RPT）** 检验 H0：φ_τ 之间无共同因子（歧义是模型特质/幻觉）；H1：存在共同因子（歧义关于世界）。统计量取跨任务相关矩阵 R = Corr(φ_·) 的第一特征值 λ₁(R)，或用平均两两相关 `ρ̄ = mean_{τ<τ'} corr(φ_τ, φ_{τ'})`。零分布由**任务标签置换**（block permutation，保持每个 φ_τ 的时序自相关）得到；p_rep = P_perm(ρ̄* ≥ ρ̄)。拒绝 H0 当 p_rep < α_rep。T=1 时检验退化为真空真（pass=1），以保证严格包含（定理 18）。

**定义 314（跨任务 VoI 与干扰矩阵 CVA）** 信息动作 g 的收益向量 `VoI_τ(g) = H(M_τ|o) − E[H(M_τ|o,y_g)]`。执行 g（本为任务 τ 发起）对任务 τ' 的**干扰**定义为 `I_{ττ'}(g) = H(M_{τ'}|o) − H(M_{τ'}|o, do(g))`（含信息副作用与物理副作用）。聚合决策：
`g* = argmax_g Σ_τ ω_τ·VoI_τ(g) − c(g)`，s.t. `max_{τ'} (Δrisk_{τ'}(g)) ≤ ε_int` 且 `I_{ττ'}(g) ≥ −δ_neg`（负迁移禁入）且预算未超。
其中 ω_τ 为风险权重（可由 CVaR 或任务关键度给出）。共享 epistemic 使 `VoI_τ` 在多个 τ 上同时为正（正迁移被显式吃进目标）；特质 epistemic 往往只有单个 τ 为正，扣掉 c(g) 后自动不划算。

**定义 315（空探针 / 处理探针对 NCT）** 处理探针 g1 ∈ 𝒜_info 与空探针 g0 ∈ 𝒜_info 构成**匹配对**，要求：成本 |c(g1)−c(g0)| ≤ ε_c、运动学/时长 |Δkin| ≤ ε_k、观测通道相同（同传感器、同自由度），且 g0 先验上**对 h 不含信息**：`I(h; y_{g0} | o) = 0`（实现方式：读取一个与当前信念冗余的已知基准，如已知静态标定物、已知答案的环境问句）。g0 **不得对人使用欺骗**（定义 322）。

**定义 316（对比信息增益与模态有效性 CMC）** `ΔVoI(g1; g0) = VoI_measured(g1) − VoI_measured(g0)`。在 A100（模型自洽幻觉对 g0、g1 的响应同分布）下：若歧义是幻觉，`E[ΔVoI | H0] = 0`；若歧义关于世界，`E[ΔVoI | H1] = I(h; y_{g1} | o) − 0 > 0`。模态有效性分 `v_mode = ΔVoI / (|VoI(g1)| + |VoI(g0)| + ε)` ∈ [−1,1]，用于把「共模幻觉」从「差模证据」中分离。

**定义 317（随机 switchback 设计 RSW）** 时间轴按上下文分层（context stratum s）切成块（cluster）b=1..B；每块内对「是否使用被检验交互」以概率 p(通常 0.5) 随机（Bernoulli 或成对 ABBA），安全 veto 可在块内提前终止但**不改变其随机分配标签**（intention-to-treat）。目标是让 treatment/control 在分层内可交换；不允许按结果挑块。

**定义 318（双重差分估计 DiD）** 结局 Y 取任务 regret 或成功率。对每个 stratum s 与块 b，`DiD = (Ȳ_{treat,post} − Ȳ_{treat,pre}) − (Ȳ_{control,post} − Ȳ_{control,pre})`。识别假设 A101：无条件平行趋势（treatment 与 control 的反事实漂移相同）。若 pre-trend 显著不平行（placebo test），该 stratum 的 DiD 作废——**这正是 R68「标定吸收漂移」的可检验镜像**。

**定义 319（任意时刻有效证据 SEQ）** 对 DiD 增量构造 e-process `E_n = Π_{i≤n} (1 + λ_i (X_i − μ0))`（X_i 有界，λ_i 预注册且可预测），Ville 不等式给出 `P(sup_n E_n ≥ 1/α) ≤ α` 在 H0（无效应）下成立，与可选停止无关；或等价地维护置信序列 `CS_n`（如 Howard 等的 mixture boundary）。只有当 `CS_n` 的下界 > 0（或 `E_n ≥ 1/α`）才允许在证书中写下「交互有效」。

**定义 320（联合认证规则）** 交互 g1 被认证为「有效」当且仅当：
(a) RPT 拒绝幻觉 H0（p_rep < α_rep，且 T ≥ 2）；
(b) CMC 的 `ΔVoI` 置信下界 > 0（对照分离）；
(c) SEQ 的 `CS_n` 下界 > 0（因果效应任意时刻有效）；
(d) 试验已在 PRG 预注册（哈希一致）；
(e) 安全与预算未越界。
任一不满足 ⇒ 不得宣称有效；g1 可继续作为 R69 的探索性动作，但**不进证书、不进策略更新**。

**定义 321（交互退役与证伪日程）** 每个交互假设 g 维护 e-value `E_g(n)`；当 `E_g` 达到拒绝阈值则标记「已认证」；当 `CS_n` 上界 < ε_effect 且样本量达到最小可检测效应所需，则标记「已证伪/无效」并从 MINT 候选集中**离线**移除（实时流仍只读）。这使系统能主动**放弃**无效交互，而不是无限追问。

**定义 322（试验伦理与安全不变式）** (i) **非欺骗**：面向人的 g0 不得提供虚假信息或诱导；不满足则不得作为对照，只允许观察性估计（并显式降级因果声明）。(ii) **对照同等安全**：g0 与 g1 都过 C-RAS-WM 前缀认证；不得为凑对照而制造风险。(iii) **ITT**：安全 veto/中止保留其分配标签进入分析，不作事后剔除；veto 率作为结局上报。(iv) **试验饱和**：单位时间随机化块 ≤ 1，用户可感知的行为抖动上限 ≤ ε_jitter。(v) **审计留痕**：所有随机种子、分配、veto、结局写入不可篡改试验台账。

**定义 323（干扰感知的试验预算分配）** 在每个控制周期，把有限试验预算 b_t 分给任务集：`max Σ_τ u_τ(b_τ) s.t. Σ b_τ ≤ b_t, I_{ττ'} 约束, max_τ Δrisk ≤ ε_int`，采用注水（water-filling）近似；共享 epistemic 高的任务获得更高边际价值（正迁移），负迁移对强制互斥。目标是在 T 个任务间取得**总证据增益最大**而非单任务最优。

**定义 324（威胁模型与审计 ℰ_TRIAL）** `ℰ_TRIAL = ℰ_FLUID × ℰ_design`，新增设计层攻击：**漂移伪装**（用非平行趋势伪造处理效应）、**块选择攻击**（只报告有利块）、**veto 操控**（让 control 块更容易被 veto 从而剔除坏样本）、**预注册篡改**（事后改主终点）、**对照污染**（让 g0 意外携带信息）。VQAuditor-X 审计：随机化平衡性、pre-trend、veto 率、预注册哈希、g0 的信息泄漏检验。

**定义 325（证书 J_TRIAL 与预注册）** `J_TRIAL = (J_FLUID, trial_id, prereg_hash, design, n_blocks, p_rep, did_effect, did_cs_lcb, e_value, veto_rate, interference_ratio, ethics_flag, trial_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ 预注册一致 ∧ (若宣称有效：定义 320 全满足) ∧ ITT 完整`。`ethics_flag` 记录是否使用过非欺骗性对照；若为 observation-only，则证书中所有因果措辞自动降级为相关。

**定义 326（两级退化与严格包含链）** 当 T=1（RPT 真空真）或试验证据不足/被污染时，TRIAL 的动作选择与 FLUID **逐指令相同**（仅多出只读台账开销）；当 FLUID 的 `VoI(g*) ≤ c(g*)` 时退化为 R68。故严格包含链 **R68 ⊆ FLUID ⊆ TRIAL**：安全侧不做任何让步，新增的只是「对自身因果声明的可证伪性」。任何退化都由 `evidence_status ∈ {certified, exploratory, inconclusive, falsified}` 显式标注，绝不把 exploratory 冒充 certified。

```python
# IP-264 MTX：多任务骨干（共享 trunk + 任务头 + 跨任务不确定性账本）
class MultiTaskBackbone:
    def __init__(self, trunk, heads, flow, mode_head):
        self.trunk, self.heads = trunk, heads            # τ -> h_τ
        self.flow, self.mode_head = flow, mode_head      # 条件于 (z, e_τ)
    def forward(self, o_t):
        z = self.trunk(o_t)
        return z, {tau: self.heads[tau](z) for tau in self.heads}

# IP-265/266 XUD + RPT：共享/特质 epistemic 分解 + 复现检验
def decompose_cross_task(z, o, tasks, K):
    phi, Uale, Uepi = {}, {}, {}
    for tau in tasks:
        modes = cluster_trajectories(sample_flow(z, o, tau, K))
        phi[tau] = centered_logpost(modes)
        Uale[tau], Uepi[tau] = aleatoric(modes), epistemic(modes)
    f, load = factor_analysis(phi)                    # 单因子模型（定义 312）
    U_shared = var(f)
    U_spec = {tau: Uepi[tau] - load[tau]**2 * U_shared for tau in tasks}
    p_rep = permutation_test(phi, stat='mean_pairwise_corr',
                             blocks='task_label', n_perm=256)   # 定义 313
    return U_shared, U_spec, Uale, p_rep

# IP-267 CVA：带干扰矩阵的跨任务 VoI
def choose_interaction_cross_task(g_cands, beliefs, interfere, budget, omega):
    best = None
    for g in g_cands:
        if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
        if max(interfere.risk(g).values()) > EPS_INT:         continue
        if any(interfere.I[g][t][tp] < -DELTA_NEG
               for t in beliefs for tp in beliefs if tp != t): continue
        score = sum(omega[t] * voi(t, g) for t in beliefs) - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-268/269 NCT + CMC：匹配空探针 + 对比增益（共模抑制）
def contrastive_gain(g1, o, world, mode_post):
    g0 = design_matched_sham(g1, o)          # 同通道/同成本，I(h;y_g0)=0
    if not (c_ras_wm.certify_info(g0) and ethics.non_deceptive(g0)): 
        return None                           # 非法对照 -> 只做观察性估计
    y1, y0 = world.probe(g1), world.probe(g0)
    d_voi = (entropy(mode_post) - post_entropy(mode_post, y1)) \
          - (entropy(mode_post) - post_entropy(mode_post, y0))
    return d_voi, mode_validity(d_voi, g1, g0)

# IP-270/271 RSW + SEQ：switchback 随机化 + DiD + 任意时刻有效证据
class TrialEngine:
    def assign(self, stratum, block):
        self.prereg.assert_unchanged()              # IP-272 预注册
        arm = self.rng.balanced_bernoulli(stratum)  # ABBA 平衡
        return arm                                  # 'treat' | 'control'
    def observe(self, stratum, arm, y, veto=False):
        self.log.append(dict(stratum, arm, y, veto, ts=now()))   # ITT 保留
        for s in self.strata:
            self.did[s].update(stream=self.log, stratum=s)        # 定义 318
            self.cs[s].update(self.did[s].delta)                  # 定义 319
    def evidence(self, s):
        return dict(did=self.did[s], cs_lcb=self.cs[s].lower(),
                    e=self.cs[s].e_value, pretrend_ok=self.did[s].placebo())

# IP-274 主闭环（继承 R69，只在「不确定性可信度」处插入 TRIAL 层）
def TRIAL_RAS_round(M, obs):
    z, heads = M.mtx.forward(obs)
    U_shared, U_spec, Uale, p_rep = M.xud.decompose_cross_task(z, obs, M.tasks, K=4)
    # 1) 先证伪：这个歧义是真的吗？
    real_ambiguity = (p_rep < M.alpha_rep) and (M.tasks.__len__() >= 2)
    # 2) 跨任务 VoI / 干扰约束
    g1 = (M.cva.choose_interaction_cross_task(info_cands(z), heads, M.interfere,
                                              M.budget, M.omega)
          if real_ambiguity else None)
    # 3) 对照：匹配空探针 -> 差模增益（共模幻觉被扣掉）
    gain = M.cmc.contrastive_gain(g1, obs, M.world, M.modes) if g1 else None
    # 4) 随机化块：只在允许做试验且预注册一致时执行 treatment
    arm = (M.rsw.assign(M.stratum(obs), M.block)
           if (g1 is not None and M.prg.allows(g1)) else 'control')
    a = M.mint.execute(g1) if arm == 'treat' else M.r68_baseline(obs)
    y, veto = M.world.step(a)
    M.rsw.observe(M.stratum(obs), arm, y, veto)
    # 5) 认证门槛（定义 320）：不过门 -> 只作探索，不进证书
    ev = M.rsw.evidence(M.stratum(obs))
    certified = (real_ambiguity and gain is not None and gain[0] > 0
                 and ev['cs_lcb'] > 0 and ev['pretrend_ok']
                 and M.prg.check(g1))
    # 6) 保守退避链：certified -> FLUID；否则逐级退化
    lam = M.fluid_lambda(heads, g1 if certified else None)   # R69 定义 307
    if not real_ambiguity or ev['pretrend_ok'] is False:
        lam, k = M.r68_fallback(obs)                         # R68 最保守
    k = M.c_ras_wm.certified_prefix(a, lam, M.wm_preds)
    M.vqa_x.submit_async(arm, gain, ev, veto, M.prg.hash())
    return k, lam, certified, ev
```

## 3. 推导

**引理 19（复现的可检出性）** 设真实歧义使每个任务以载荷 λ_τ 共享共同因子 f，特质项方差 σ²，T 个任务、每任务 N 个独立决策点。则平均两两相关 `ρ̄ ≈ ρ_f · mean(λ_τλ_{τ'})`（ρ_f = U_shared 占总方差比）；在 H0（λ=0）下置换检验的假阳性率 ≤ α_rep。要点：**真实歧义的复现能力随 T 与 ρ_f 单调增强，而幻觉模态的 ρ̄ 期望为 0**。系：多任务不是免费午餐——任务越多，复现检验越有力，但也越容易把「真正共享的模型偏差」（如共同的表征坍缩）误判为世界歧义；因此 RPT 必须与 CMC 的对照联用，不能单独立案。

**引理 20（对比增益的共模抑制）** 在 A100 下，任意仅由模型自洽产生的「消解量」在 g1 与 g0 上同分布，故对 `ΔVoI` 的期望贡献为 0；而真实世界证据只出现在 g1 的似然比中，贡献为 `I(h; y_{g1}|o)`。因此 `E[ΔVoI] = I(h;y_{g1}|o)·1[H1]`，且 `Var(ΔVoI)` 至少不高于直接使用 `VoI(g1)` 的方差（两测量共享的模型偏差被差分消去）。系：R69 最担心的「幻觉模态诱发无效追问」在本层被**结构性**拦截——幻觉没有差模分量。

**引理 21（DiD 消去缓变漂移）** 设结局 `Y = τ_treat·effect + drift(t) + ε`。若 drift(t) 在 treatment 与 control 间相同（平行趋势），则 DiD 中 drift 项相消，`E[DiD] = effect`。若漂移在两组间差异为 δ(t)，则 `bias(DiD) ≤ max_t |δ(t)|`，且该偏差可由 placebo/pre-trend 检验以功效 1−β 检出。系：**R68 的「标定吸收缓变故障」在本层留下可检验的指纹**（非平行趋势），与 R69 的 Δa 通道形成互补：Δa 测行为侧，pre-trend 测时间侧。

**引理 22（任意时刻有效证据的误证控制）** 对任意可预测的 λ_i 与有界增量，非负 e-process `E_n` 在 H0 下是上鞅，Ville 不等式给出 `P(∃n: E_n ≥ 1/α) ≤ α`，与停止规则无关。故「看数据决定何时停」不再授予系统额外的假阳性；门槛 `1/α` 一次预注册、全程有效。

**定理 18（严格包含链与安全单调）** 在 A99–A101 下，TRIAL 的期望风险 ≤ FLUID ≤ R68；且当 T=1、`VoI(g*)≤c(g*)`、pre-trend 失败、预注册不一致或证据未过门槛时，三者**逐指令相同**（仅多只读台账）。安全侧不做任何让步：新增的只是对因果声明的可证伪性与退役能力。因此 R70 是 R69 的**认识论加层**，不是新替代层。

**定理 19（试验证书的任意时刻误证控制）** 在预注册一致、ITT 完整、且认证严格遵循定义 320 的前提下，系统在**任意自适应停止策略**下把「无效交互」误证为「有效」的概率 ≤ α（由引理 22 与 RPT 的置换有效性联合给出，Bonferroni 或 e-value 合并控制多重性）。推论：不允许事后挑 stratum、挑终点、剔除 veto；否则上界失效——这正是审计要检查的。

**定理 20（多任务交互预算的干扰有界与正迁移下界）** 若 CVA 满足干扰约束 `max_{τ'}Δrisk_{τ'} ≤ ε_int` 与负迁移禁入 `I_{ττ'} ≥ −δ_neg`，则任何被执行的交互都不会使任一任务的瞬时风险增加超过 ε_int；且当共享 epistemic 载荷 λ_τ 同号时，单次探针的聚合收益 `Σ_τ ω_τ VoI_τ(g) ≥ max_τ ω_τ VoI_τ(g)`，即正迁移带来不低于单任务最优的聚合收益下界。系：多任务把「一次探针」的价值从「单点」提升到「共享因子覆盖的整簇任务」，前提是 λ 同号——异号载荷（任务对世界的解释相反）必须由负迁移约束拦下。

## 6. 本轮最大风险

**一句话**：TRIAL-RAS 的全部结论都押在「随机化可交换、对照无泄漏、试验可被审计」这一前提上——**若 treatment/control 因安全 veto、漂移或人类对探针的适应而不再可交换，DiD 与 anytime-valid 证据就会在错误的样本上给出正确得可怕的置信区间，系统会用统计学给一个有害交互盖章；而一旦它开始拿真实用户做试验，错误不再只是「问错」，而是「拿对照过、有 p 值的方式持续做错」**。

**次级风险与缓解**：
1. **空探针泄漏信息 / 欺骗**（g0 意外含信息或对人撒谎）→ 定义 315 的 `I(h;y_g0)=0` 可测检验 + 定义 322 非欺骗约束 + E302/E309；
2. **漂移破坏平行趋势** → 定义 318 的 placebo/pre-trend 检验 + 引理 21，失败即作废该 stratum；
3. **可选停止/事后挑选导致误证** → 定义 319 的 e-process/CS + 定义 321 预注册 + 定理 19 + E304；
4. **设计层攻击（veto 操控、块选择）** → 定义 322 ITT + 定义 324 审计 + E310；
5. **多任务负迁移/表征坍缩被误认成共享歧义** → 定义 314 干扰约束 + 引理 19 系（RPT 不可单独立案）+ MCG 校准门；
6. **试验疲劳与行为抖动** → 定义 322-iv 饱和预算 + E314；试验只在离线改策略（零实时学习写操作）。

## 2. 形式化定义（要点版）

**定义 310（总览与三不变式）** TRIAL-RAS = (MTX, XUD, RPT, CVA, NCT, CMC, RSW, SEQ, PRG, RAS-WM†)；零实时学习写操作继承；对照动作与处理动作同等过 C-RAS-WM 认证；试验纪律（预注册 + 随机对照 + anytime-valid + ITT；单次观测不得定案）。

**定义 311–312（多任务集成与跨任务分解）** 共享编码 `z_t=Φ(o_t)`，任务头 `h_τ`，流场条件于 `(z_t,e_τ)`；模态经 `p_τ(y_τ|h)` 对齐到 ℋ。单因子模型 `φ_τ=λ_τ f+ε_τ`，`U_epi^τ = λ_τ²U_epi^shared + U_epi^spec,τ`（A99 正交因子）。

**定义 313（复现检验 RPT）** H0：无共同因子（幻觉/特质）；H1：有共同因子（世界歧义）。统计量 `ρ̄` 或 `λ₁(R)`，任务标签 block permutation 得零分布，`p_rep<α_rep` 拒绝 H0；T=1 时真空真，保证包含。

**定义 314（跨任务 VoI 与干扰 CVA）** `g* = argmax_g Σ_τ ω_τVoI_τ(g) − c(g)`，s.t. `max_{τ'}Δrisk_{τ'}≤ε_int`、`I_{ττ'}≥−δ_neg`、预算未超。共享 epistemic ⇒ 多任务同时正收益；特质 epistemic 扣成本后自动不划算。

**定义 315–316（空探针对照与共模抑制）** g0 与 g1 成本/运动学/观测通道匹配，且 `I(h;y_{g0}|o)=0`、对人非欺骗；`ΔVoI=VoI(g1)−VoI(g0)`。A100 下幻觉项共模相消，`E[ΔVoI]=I(h;y_{g1}|o)·1[H1]`。

**定义 317–318（switchback 与 DiD）** 按上下文分层切时间块，块内 Bernoulli/ABBA 随机 treatment；安全 veto 不改变分配标签（ITT）。`DiD=(Ȳ_{treat,post}−Ȳ_{treat,pre})−(Ȳ_{control,post}−Ȳ_{control,pre})`；A101 平行趋势，pre-trend 失败即作废该 stratum。

**定义 319–321（anytime-valid、联合认证、退役）** `E_n=Π(1+λ_i(X_i−μ0))`，Ville 保证 `P(sup E_n≥1/α)≤α`。认证 g1 需：RPT 拒绝 H0、CMC 下界 >0、SEQ 下界 >0、预注册一致、安全预算未越界（定义 320 全满足）。无效交互达最小可检测效应后被证伪并**离线**退役（定义 321）。

**定义 322–323（伦理安全与预算）** 非欺骗空探针；对照同等安全；ITT 不剔除 veto；试验饱和 ≤1 块/单位时间、抖动 ≤ε_jitter；试验台账留痕。干扰感知 water-filling 分配跨任务试验预算，正迁移优先、负迁移禁入。

**定义 324–325（威胁、证书与预注册）** `ℰ_TRIAL=ℰ_FLUID×ℰ_design`（漂移伪装/块选择/veto 操控/预注册篡改/对照污染）；`J_TRIAL=(J_FLUID, trial_id, prereg_hash, design, n_blocks, p_rep, did_effect, cs_lcb, e_value, veto_rate, interference_ratio, ethics_flag, trial_ver)`；observation-only 时因果措辞自动降级。

**定义 326（严格包含链）** T=1 或证据不足/被污染时逐指令退化为 FLUID；`VoI≤c` 时退化为 R68；`evidence_status` 显式标注，exploratory 不得冒充 certified。故 **R68 ⊆ FLUID ⊆ TRIAL**，安全单调。

## 3. 关键算法伪代码

```python
# IP-264/265/266 MTX + XUD + RPT
def decompose_cross_task(z, o, tasks, K):
    phi, Uale, Uepi = {}, {}, {}
    for tau in tasks:
        modes = cluster_trajectories(sample_flow(z, o, tau, K))
        phi[tau] = centered_logpost(modes)
        Uale[tau], Uepi[tau] = aleatoric(modes), epistemic(modes)
    f, load = factor_analysis(phi)                        # 单因子（定义 312）
    U_shared = var(f)
    U_spec = {tau: Uepi[tau] - load[tau]**2 * U_shared for tau in tasks}
    p_rep = permutation_test(phi, stat='mean_pairwise_corr',
                             blocks='task_label', n_perm=256)   # 定义 313
    return U_shared, U_spec, Uale, p_rep

# IP-267 CVA：带干扰矩阵的跨任务 VoI
def choose_interaction(g_cands, beliefs, interfere, budget, omega):
    best = None
    for g in g_cands:
        if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
        if max(interfere.risk(g).values()) > EPS_INT:          continue
        if any(interfere.I[g][t][tp] < -DELTA_NEG
               for t in beliefs for tp in beliefs if tp != t): continue
        score = sum(omega[t]*voi(t, g) for t in beliefs) - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-268/269 NCT + CMC：匹配空探针 -> 共模抑制
def contrastive_gain(g1, o, world, mode_post):
    g0 = design_matched_sham(g1, o)          # 同通道/同成本，I(h;y_g0)=0
    if not (c_ras_wm.certify_info(g0) and ethics.non_deceptive(g0)):
        return None                           # 非法对照 -> 观察性估计
    y1, y0 = world.probe(g1), world.probe(g0)
    d = (entropy(mode_post) - post_entropy(mode_post, y1)) \
      - (entropy(mode_post) - post_entropy(mode_post, y0))
    return d, d / (abs(voi(g1)) + abs(voi(g0)) + 1e-8)

# IP-270/271 RSW + SEQ：switchback + DiD + anytime-valid
class TrialEngine:
    def assign(self, stratum, block):
        self.prereg.assert_unchanged()        # IP-272 预注册
        return self.rng.balanced_bernoulli(stratum)   # ABBA 平衡
    def observe(self, stratum, arm, y, veto=False):
        self.log.append(dict(stratum, arm, y, veto, ts=now()))  # ITT 保留
        for s in self.strata:
            self.did[s].update(self.log, s)   # 定义 318
            self.cs[s].update(self.did[s].delta)   # 定义 319
    def evidence(self, s):
        return dict(did=self.did[s], lcb=self.cs[s].lower(),
                    e=self.cs[s].e_value, pretrend_ok=self.did[s].placebo())

# IP-274 主闭环（继承 R69，仅在可信度处插入 TRIAL 层）
def TRIAL_RAS_round(M, obs):
    z, heads = M.mtx.forward(obs)
    U_shared, U_spec, Uale, p_rep = M.xud.decompose_cross_task(z, obs, M.tasks, K=4)
    real_amb = (p_rep < M.alpha_rep) and (len(M.tasks) >= 2)   # 先证伪
    g1 = (M.cva.choose_interaction(info_cands(z), heads, M.interfere,
                                   M.budget, M.omega) if real_amb else None)
    gain = M.cmc.contrastive_gain(g1, obs, M.world, M.modes) if g1 else None
    arm = (M.rsw.assign(M.stratum(obs), M.block)
           if (g1 is not None and M.prg.allows(g1)) else 'control')
    a = M.mint.execute(g1) if arm == 'treat' else M.r68_baseline(obs)
    y, veto = M.world.step(a)
    M.rsw.observe(M.stratum(obs), arm, y, veto)
    ev = M.rsw.evidence(M.stratum(obs))
    certified = (real_amb and gain is not None and gain[0] > 0
                 and ev['lcb'] > 0 and ev['pretrend_ok'] and M.prg.check(g1))
    lam = M.fluid_lambda(heads, g1 if certified else None)      # R69 定义 307
    if (not real_amb) or (ev['pretrend_ok'] is False):
        lam, k = M.r68_fallback(obs)                            # R68 最保守
    k = M.c_ras_wm.certified_prefix(a, lam, M.wm_preds)
    M.vqa_x.submit_async(arm, gain, ev, veto, M.prg.hash())
    return k, lam, certified, ev
```

## 4. 推导

**引理 19（复现可检出性）** 真实歧义下 `ρ̄ ≈ ρ_f·mean(λ_τλ_{τ'})`，H0 下置换检验假阳性 ≤ α_rep；复现力随 T 与共享比 ρ_f 单调增强，幻觉的 ρ̄ 期望为 0。系：RPT 不能单独立案——任务越多越易把「共享的模型偏差」（表征坍缩）误判为世界歧义，须与 CMC 对照联用。

**引理 20（对比增益的共模抑制）** A100 下自洽幻觉对 g1、g0 响应同分布，对 ΔVoI 的期望贡献为 0；真实证据贡献 `I(h;y_{g1}|o)`。故 `E[ΔVoI]=I(h;y_{g1}|o)·1[H1]`，且误差方差不高于直接用 VoI(g1)。幻觉模态被**结构性**拦截。

**引理 21（DiD 消漂移）** `Y=τ_treat·effect+drift(t)+ε`，平行趋势下 drift 相消，`E[DiD]=effect`；组间漂移差 δ(t) 使 `bias≤max_t|δ(t)|`，且由 pre-trend 检验以 1−β 检出。系：R68「标定吸收缓变故障」在此留下非平行趋势指纹，与 R69 的 Δa 行为通道互补。

**引理 22（anytime-valid 误证控制）** 非负 e-process 在 H0 下为上鞅，Ville 给出 `P(∃n:E_n≥1/α)≤α`，与停止规则无关；「看数据决定何时停」不再带来额外假阳性。

**定理 18（严格包含链与安全单调）** A99–A101 下 TRIAL 风险 ≤ FLUID ≤ R68；当 T=1、`VoI≤c`、pre-trend 失败、预注册不一致或证据未过门槛时三者逐指令相同（仅多只读台账）。R70 是 R69 的认识论加层，非替代层。

**定理 19（试验证书 anytime 误证控制）** 在预注册一致、ITT 完整、严格遵循定义 320 时，任意自适应停止策略下把无效交互误证为有效的概率 ≤ α（RPT 置换有效性 + 引理 22 + 多重性校正）。推论：事后挑 stratum/终点/剔 veto 会使上界失效，正是审计必查项。

**定理 20（干扰有界与正迁移下界）** 满足 `max_{τ'}Δrisk_{τ'}≤ε_int` 与 `I_{ττ'}≥−δ_neg` 时，任何交互不使任一任务瞬时风险增加超过 ε_int；λ_τ 同号时 `Σ_τ ω_τVoI_τ(g) ≥ max_τ ω_τVoI_τ(g)`。异号载荷必须由负迁移约束拦下。

## 7. 本轮最大风险

**一句话**：TRIAL-RAS 的全部结论押在「随机化可交换、对照无泄漏、试验可审计」上——**若安全 veto、漂移或人类对探针的适应破坏可交换性，DiD 与 anytime-valid 证据会在错误样本上给出正确得可怕的置信区间，系统就用统计学给有害交互盖章；它不再只是「问错」，而是「以有对照、有 p 值的方式持续做错」**。

**次级风险与缓解**：空探针泄漏/欺骗（定义 315 零信息可测检验 + 定义 322 非欺骗 + E302/E309）；漂移破坏平行趋势（pre-trend/placebo + 引理 21，失败即作废）；可选停止/事后挑选（e-process/CS + 预注册 + 定理 19 + E304）；设计层攻击（ITT + 定义 324 审计 + E310）；负迁移/表征坍缩被误认共享歧义（干扰约束 + RPT 不可单独立案 + MCG 校准门）；试验疲劳与抖动（饱和预算 + E314，策略只离线更新）。
