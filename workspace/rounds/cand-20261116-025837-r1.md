# 第 10 轮（新灵感循环第 1 轮；本轮灵感：「位姿估计」×「场景理解」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**感知地基认证**。v9 把算力债、集成债、叙事债都治理了，却仍把「位姿正确」「场景已观测」当作免费前提——块证书 Ĉ_t、SpatialCert、间隙指标全部建立在它之上。本轮把这两个最底层假设升级为可认证、可退化的一等公民，并用**耦合不确定性的最大不动点**解决「位姿靠场景、场景靠位姿」的循环依赖。

## 0. 直觉与动机

**灵感 1（位姿估计 → 带证书的位姿区间）**
直觉：机器人所有以「米/弧度」计的指标，都是先有一个位姿、再把局部观测搬到世界系里量出来的。位姿误差不是白噪声，而是**系统性、随距离放大、在某些场景退化到不可观**的。若系统只拿点估计位姿算间隙，它会在「位姿悄悄漂了 3cm、而间隙余量正好 2cm」时给出虚假安全，而这类失效不会出现在任何现有日志里。核心创新：**位姿证书（PoseCertificate, PC）**——不输出单点位姿，而输出一个保守误差集（SE(3) 球 T̂·Exp(B_ε)）＋退化标志＋来源标签；所有下游指标用**区间算术**求下界，安全只信下界。位姿越远、越退化，ε 越大，安全余量自动变厚——这是「把不确定性显式买进安全预算」。

**灵感 2（场景理解 → 认知型场景证书）**
直觉：几何点云只知道「这里有东西」，场景理解还知道「那是什么、危险吗、我看到的地方之外是什么」。但场景理解的错误是**结构性**的：漏检（玻璃、透明、反光物体对深度相机近乎隐形）、误分类，以及最危险的——生成式补全把**没看见的区域幻觉成可通行**。核心创新：**认知场景证书（SceneCertificate, SC）**——把空间显式分成 known-free / known-occupied / **unknown**，对 unknown 施加「未知即占据」的认知保守律；对生成式补全的预测区一律隔离为 unknown，除非被真实观测佐证。安全论证不再假设「没检测到 = 没有」。

**综合洞察（灵感 1×2 → 地基不动点）**
直觉：位姿和场景互为因果——视觉里程计用场景特征定位姿，场景理解又用位姿把物体放进世界。二者误差会**相互放大**：位姿越糊，数据关联越乱，场景越不确定；场景越不确定，可用地标越少，位姿越糊。这是一个循环论证。核心创新：**地基不动点（GroundingFixedPoint, GFP）**——把「位姿不确定度 ε ↦ 场景膨胀 δ ↦ 新的 ε」写成一个单调算子 Φ，证明它在完备格上从「全不确定」向下迭代必收敛到**最大不动点**，且该不动点对真实误差是保守上界。于是循环依赖不但不是漏洞，反而给出一个可计算的、最坏情况的安全地基；同时提供**地基一致性监视器（GCM）**，用位姿-场景互证残差 ρ 侦测「自信地错」的病态。

## 1. 研究问题（轮次升级版）

- **Q1（位姿证书保守性）**：如何在 SE(3) 上定义可组合、随距离正确放大、且对退化可检测的保守误差集，使任何基于它的间隙下界永不高估真实间隙？
- **Q2（认知场景可靠性）**：「未知即占据」在什么传感器漏检界 δ_fn 与覆盖率假设下是安全的？如何隔离生成式补全的幻觉而不牺牲过多效率？
- **Q3（耦合不动点）**：位姿-场景循环不确定性传播算子是否单调、其最大不动点是否对真值保守？GCM 能否在有限时延内把「自信地错」降级回 v9？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 位姿区间律（Certified Pose Interval, PC）**
位姿输出为证书 P_t=(T̂_t, ε_t, deg_t, prov_t)，且真位姿 T_t ∈ T̂_t·Exp(B_{ε_t})。任何以「米/弧度」计的安全量 q 必须用区间下界判定：q_lo = q(T̂) − Lip_q·η(ε_t, r_max)，其中 η=ε_lin+ε_rot·r。安全只信 q_lo；q_hi 仅用于探索收益估计。位姿退化（可观性最小特征值 < λ_min）使 ε 膨胀并触发 K_eff 收紧。

**P14 认知场景律（Epistemic Scene, SC）**
场景信念 S_t=(F,O,U) 分为已知自由/已知占据/未知；安全自由空间 F_safe=F∖U，且 **U 一律按占据处理**；生成式补全区 P 未经观测佐证一律并入 U。known-free 内的漏检概率受传感器模型界 δ_fn 约束，故间隙另加 δ_fn 风险缓冲。

**P15 地基不动点律（Grounding Fixed-Point, GFP）**
耦合传播 Φ:U↦U 在不确定集完备格（⊑=包含）上单调；从 ⊤ 向下迭代得最大不动点 U*，对任意真实一致解 U_true 有 U_true ⊑ U*。GCM 用 ρ=Σ w_i·‖r_i‖（重投影＋语义-位姿＋回环）侦测不一致；ρ>τ_ρ、ε>ε_max 或近场覆盖率 < c_min 都破坏地基信任域 U_t^g，立即 K_eff←1 并可请求主动感知。

## 3. 与基线的接口（如何退化）

- PC 失效 ⇒ ε←0（回到 v9 点估计位姿，可靠性仍由 v9 SPR risk_SLAM 兜底），指标区间塌缩为点，等价 v9；
- SC 失效 ⇒ unknown 合并进几何自由空间、关闭语义层，退化为 v9 点云间隙，等价 v9；
- GCM/GFP 失效 ⇒ 不确定性传播只迭代一次、关闭一致性门控，等价 v9；
- 三者全失效 ⇒ 完整退回 MetricVoiceGauge-ACMD v9（引理 92）；
- v9 组件失效 ⇒ 按 v9 契约链继续退到 v8/v7/v6。

## 4. 预期贡献

1. **位姿证书与区间度量**：把位姿不确定性从隐性噪声变成显式、可组合、随距离放大的保守安全预算；
2. **认知场景证书**：把「未知即占据」与「幻觉隔离」做成可退化安全层，正面处理透明/反光漏检；
3. **地基不动点理论**：用单调算子最大不动点严谨解决位姿↔场景循环不确定性，给出最坏情况保守地基；
4. **地基退化链**：新增 PC/SC/GCM 三个可选增强，任一失效严格回退 v9；E571–E590 覆盖校准、退化、幻觉、耦合、对抗与端到端。

## 5. 本轮最大风险

**一句话**：整套保守性都押在「位姿证书确实包住真值、场景漏检确实受 δ_fn 约束」上；一旦位姿滤波器**过度自信**（误差界系统性偏小），区间下界会高估真实间隙，最危险时刻反而给出虚假安全的证书——感知根基的过度自信比决策层的乐观更致命。

**新增定义 540（位姿证书 PoseCertificate）** 位姿以 SE(3) 球而非点输出：
```
T_true ∈ T̂ · Exp(B_ε),   B_ε = { ξ ∈ se(3) : ‖ξ‖ ≤ ε }
```
对距离机器人 r 的世界点 x，位移上界 ‖T_true x − T̂ x‖ ≤ η(ε,r) = ε_lin + ε_rot·r + O(ε²)。**组合律**：两段独立证书级联时 ε_total ≤ ε₁ ⊕ ε₂（三角不等式在 exp 坐标下的直接推论），故 PC 可沿运动/标定链逐级传播而不需要重估。**退化标志** deg_t=1 当位姿优化信息矩阵最小特征值 λ_min(H)<λ_min⁰（纹理缺失走廊、白墙、玻璃幕墙），此时 ε 置为 `ε_floor/√λ_min(H)`，随可观性下降而膨胀。

**新增定义 541（区间度量 IntervalMetric）** 对任一安全量 q（间隙、力矩、抓取裕度），定义
```
q_lo(t) = min_{T∈P_t} q(T,S_t),   q_hi(t) = max_{T∈P_t} q(T,S_t)
```
若 q 关于位姿是 L_q-Lipschitz（SE(3) 度量下），则 q_lo ≥ q(T̂) − L_q·ε_t，且 **q_lo 永不高估真实 q**。判定律：安全通过 ⇔ q_lo ≥ 阈值；q_hi<阈值时提前判负；其余落入不确定区，由 AC 的 β 余量吸收。

**新增定义 542（认知场景证书 SceneCertificate）** 场景信念按证据强度三分：
```
S_t = (F_t 已知自由, O_t 已知占据, U_t 未知, π_t 占据概率)
F_safe = F_t ∖ U_t          # 未知即占据
```
传感器模型界：在已观测单元上 P(漏检|已观测) ≤ δ_fn。覆盖率 c(Ω)=|obs∩Ω|/|Ω|。安全律：任何穿越 F_safe 的路径，其真实碰撞概率 ≤ δ_fn + 风险缓冲；故间隙判定再加 buffer(δ_fn)=δ_fn·d_cell 的保守外扩。

**新增定义 543（幻觉隔离 HallucinationQuarantine）** 生成式场景补全（占据/自由预测）输出区域 P_t 永不直接进 F_t；一律先并入 U_t，仅当被真实观测连续 n_verify=3 帧佐证才晋升为 F_t 或 O_t。**预测的自由不等于自由**。

**新增定义 544（耦合不确定性算子 CoupledOperator）** 位姿不确定度 ε 与场景膨胀 δ 的相互传播：
```
位姿→场景: δ' = δ_sem ⊕ η(ε, r_max)                     # 世界系物体不确定性 = 语义形状 ⊕ 位姿球
场景→位姿: ε' = ε_filter ⊕ g(δ')                        # 数据关联/地标位置误差反过来抬高位姿界
Φ(ε,δ) = (ε', δ'),   对 (ε,δ) 逐分量单调不减
```
在分量不确定度构成的有界/余有界完备格上（⊑ 为包含/≤），Φ 单调。定义收紧迭代 U_{k+1}=U_k ⊓ Φ(U_k)（逐分量取 min），从 U₀=⊤（全不确定）出发，序列单调下降且被 floor 有界，收敛到**最大后不动点** U*。

**新增定义 545（地基信任域 GroundingTrustDomain）**

```
U_t^g = { ε_t ≤ ε_max  ∧  c(Ω_near) ≥ c_min  ∧  ρ_t ≤ τ_ρ  ∧  Ĉ_t^g valid }
```
Ω_near 为未来 K_eff 步扫掠体邻域。U_t^g 不成立 ⇒ K_eff←1、AC 只允许单步候选，并可插入主动感知动作（定义 548）。

```python
class CertifiedPoseEstimator:
    def __init__(self, backend, eps_floor=2e-3, r_ref=1.0, lam_min=1e-3):
        self.backend, self.eps_floor = backend, eps_floor
        self.r_ref, self.lam_min = r_ref, lam_min

    def estimate(self, obs):
        T_hat, H = self.backend.solve(obs)          # 位姿 + 信息矩阵
        lam = smallest_eig(H)                       # 可观性
        eps_lin = self.eps_floor / sqrt(max(lam, self.lam_min))
        eps_rot = eps_lin / self.r_ref
        return PoseCert(T_hat, eps_lin, eps_rot,
                        deg=(lam < self.lam_min),
                        prov=self.backend.provenance())

    def displace_bound(self, cert, r):
        return cert.eps_lin + cert.eps_rot * r      # η(ε,r)


# IP-358 SceneCertificate：认知场景 + 幻觉隔离
class EpistemicScene:
    def __init__(self, completion_net, delta_fn=1e-3, n_verify=3):
        self.F, self.O, self.U = set(), set(), set()
        self.completion, self.delta_fn, self.n_verify = completion_net, delta_fn, n_verify
        self.verify_count, self.predicted = defaultdict(int), set()

    def update(self, obs, pose_cert):
        seen = raycast(obs, pose_cert.T)             # 已观测单元
        self.F |= seen.free; self.O |= seen.occupied
        self.U |= seen.unobserved                    # 未观测永不进 F
        pred = self.completion.predict(self.O)       # 生成式补全
        self.predicted = pred.free_region
        self.U |= (self.predicted - seen.free)       # 幻觉隔离（定义 543）
        for c in seen.free & self.predicted:         # 观测佐证则晋升
            self.verify_count[c] += 1
            if self.verify_count[c] >= self.n_verify:
                self.U.discard(c)

    def free_safe(self):
        return self.F - self.U                        # 未知即占据

    def clearance_lower(self, pose_cert, omega, d_cell):
        g = min_dist(self.free_safe(), omega)         # 几何下界
        g -= self.displace_bound(pose_cert, omega.r_max)
        g -= self.delta_fn * d_cell                    # 漏检风险缓冲
        return g


# IP-359a：地基不动点（最大后不动点 = 保守地基）
def grounding_fixed_point(phi, eps0=float('inf'), delta0=float('inf'),
                          floor=1e-3, tol=1e-4, max_iter=8):
    eps, delta = eps0, delta0                     # 从 ⊤（全不确定）向下
    for _ in range(max_iter):
        ne, nd = phi(eps, delta)                  # 由当前上界推出更紧界
        ne = min(eps, max(ne, floor))             # 收紧（⊓）且受 floor 保护
        nd = min(delta, max(nd, floor))
        if abs(ne - eps) < tol and abs(nd - delta) < tol:
            return ne, nd
        eps, delta = ne, nd
    return eps, delta


# IP-359b：地基一致性监视
class GroundingMonitor:
    def __init__(self, tau_rho=0.5, W=5, eps_max=0.05, c_min=0.6):
        self.ema, self.tau_rho, self.W = 0.0, tau_rho, W
        self.eps_max, self.c_min, self.bad = eps_max, c_min, 0

    def residual(self, pose, scene, obs):
        r_rep = median_reproj_error(obs, pose.T)
        r_sem = semantic_pose_residual(scene, pose.T)
        r_lc  = loop_closure_residual(obs)
        return 0.5*r_rep + 0.3*r_sem + 0.2*r_lc

    def update(self, pose, scene, obs, coverage):
        rho = self.residual(pose, scene, obs)
        self.ema = 0.8*self.ema + 0.2*rho
        trust = (pose.eps_lin <= self.eps_max and coverage >= self.c_min
                 and self.ema <= self.tau_rho)
        self.bad = self.bad + 1 if not trust else 0
        return trust and self.bad < self.W
```

## 4. 推导

**引理 87（位姿球包裹与间隙下界可靠性）** 设 T_true ∈ T̂·Exp(B_ε)。则对任意世界点 x 与障碍点 o，有 ‖T_true x − T̂ x‖ ≤ η(ε,‖x‖) = ε_lin+ε_rot‖x‖+O(ε²)，从而真实间隙 d(T_true x,o) ≥ d(T̂ x,o) − η。因此定义 541 的 g_lo = g(T̂) − L_g·η 满足 g_lo ≤ d_true，**永不高估**真实间隙。证明：Exp 映射局部 Lipschitz（‖T̂Exp(ξ)x−T̂x‖ ≤ ‖ξ‖·(1+‖x‖)+O(‖ξ‖²)），拆分量即得；再由度量三角不等式传递。∎

**引理 88（认知场景可靠性）** 设 (A1) 已观测单元漏检率 ≤ δ_fn；(A2) 真实占据 ⊆ O∪U（即「未观测不漏进 F」）。则任何位于 F_safe=F∖U 的路径，其与真实障碍相撞概率 ≤ δ_fn + buffer 余量/(路径长度)。证明：(A2) 排除「未见即自由」导致的漏障；剩余风险只来自 (A1) 的漏检，按并集界与缓冲外扩覆盖。∎

**引理 89（地基不动点保守性 / 循环去环）** 设 Φ 在分量不确定度格上单调不减，floor 使其下有界。从 U₀=⊤ 取 U_{k+1}=U_k⊓Φ(U_k)。则 {U_k} 单调下降、有下界，必收敛到最大后不动点 U*；且对任意与观测一致的真空不确定度 U_true（U_true ⊑ Φ(U_true)），有 U_true ⊑ U*。证明：单调算子 + 完备格上的 Knaster–Tarski 不动点定理；⊓ 收缩保证下降链，U₀=⊤ 保证只在所有可能解的交集中收紧，故最大后不动点仍是所有一致解的上界。∎

**引理 90（地基块证书可靠性）** 若 AC 以 Ĉ^g（定义 533 v10）接受块，且引理 87–89 成立，则块内真实间隙 ≥ ĝ_min^g、真实力矩 ≤ ê_max^g，块在 δ_fn 风险预算内安全；与 v9 引理 82 结合，覆盖「位姿误差 + 未知空间 + 前向模型误差」三种不确定性，无「块内软通过硬失」空洞。∎

**引理 91（GCM 侦测与降级时延）** 若真实位姿-场景出现超过 τ_ρ 的严重不一致并持续，则 EMA 残差在 W 帧内越过 τ_ρ（遗忘因子 0.8 使阶跃响应 ≤ W 帧到 1−(0.8)^W 的置信），触发 Level-0：K_eff←1、PC/SC 中立元注入，系统在 W 帧内回到 v9 语义。∎

**引理 92（v10→v9 中立元逐位等价）** PC 关闭 ⇒ ε≡0 ⇒ 定义 541 区间塌缩为点 q_lo=q_hi=q(T̂)，与 v9 点估计指标逐位一致；SC 关闭 ⇒ U⊆F、δ_fn 缓冲置 0 ⇒ 间隙等于 v9 几何点云间隙；GCM/GFP 关闭 ⇒ trust_g≡trust_v9、单次传播。三者独立且可叠加，故全关闭后流水线与 v9 逐位等价。∎

**引理 93（主动感知单调性）** 增加一次真实观测只会在 Φ 中增加约束（对应不确定集的 meet 更小）⇒ 最大后不动点 U* 逐分量不增；故定义 547 的 sensing chunk 不会增大任何安全量的保守界，且未知体积 vol(U∩Ω_near) 单调不增。证明：Φ 单调、⊓ 吸收观测约束，由引理 89 的收敛性得 U*(观测+) ⊑ U*(观测)。∎
