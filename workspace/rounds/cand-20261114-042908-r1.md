# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配×主动交互的不确定性二分」IP-253~263；灵感循环第 3 轮；本轮灵感：「末端执行器控制」×「SLAM」）

> R69 给不确定性"分成两类"（aleatoric/epistemic），也给了消解它的动作（看/问/触）。但它有一个未言明的前提：**动作就是动作，世界就是世界，坐标就是坐标**。两个新灵感各戳破一层：
> - **末端执行器控制**：策略输出的 ξ 并不直接作用在世界之上，它要先穿过"身体"——正运动学、雅可比、奇异位形、关节限位、接触/阻抗。同一个数值的动作不确定度，远离奇异处无害，奇异处致命。R69 的 Δ_min 与 VoI 都在**原始动作坐标**里量，等于用一把会被身体拉伸的尺子量距离。
> - **SLAM**：机器人所在的"世界坐标系"本身是估计出来的、会漂移的；回环会**追溯性改写**地图与坐标系。R69 假设 o_t 的参考系固定、交互即时；但 SLAM 的信息收益是**延迟**的（要走过一段"信息荒漠"才能回环），且回环会让"已经认证过的动作"重新不安全。
>
> 核心命题：**R69 让不确定性有了"形状"，R70 要给不确定性一把"尺子"——而且这把尺子本身是位形相关（身体雅可比）且会漂移（SLAM 帧）的。任何比较（VoI、模态可分性、保守缩放）都必须先把不确定性经执行映射与地图协方差拉回（pullback）到统一的"任务-世界度量"下才能进行。** 命名 **SEAM-RAS**（Singularity- and map-aware End-effector Action Metric for risk-adaptive closed loops）——"seam"既是身体与世界的接缝，也是回环把地图缝合起来的那条缝。
>
> 一句话定位：R66 问"谁控制"，R67 问"未来怎样"，R68 问"我的测量还准吗"，R69 问"我该向谁求证"，R70 问"**我量出来的不确定，在世界里到底有多危险**"——不确定性不是标量、不是形状，而是一张被身体和地图扭曲的度量张量。

## 0. 直觉与动机

**灵感 1（末端执行器 → 不确定性必须先被"身体"翻译）**
直觉：两个动作在关节空间差 1°，在指尖可能差 0.1mm，也可能差 10cm，取决于你在哪。这就是雅可比：它把"电机的差别"翻译成"指尖的差别"。R69 在动作轨迹空间用 Wasserstein 距离算模态间距 Δ_min、用熵算 VoI，等于默认这把翻译是恒等映射。而机器人最危险的地方恰是翻译最不均匀的地方——奇异位形附近 σ_min(J)→0，为修正 1mm 任务误差需要巨大的关节运动（‖J⁺Δx‖ ≥ ‖Δx‖/σ_min）。于是 R69 会在最该保守处觉得"歧义不大、不值得问"，却在无害处大喊大叫。修正方向：所有不确定性都先经 pullback 度量 G = Jᵀ M_task J 投影到任务空间，再比较。

**灵感 2（SLAM → 坐标系会漂移，回环会追溯改历史）**
直觉：你在长走廊里走，地图在慢慢弯；回到起点回环一下，整张地图"啪"地对齐，却**追溯性**改变了过去所有地标的位置。R69 的认证是"此刻有效即永久有效"，这在 SLAM 下是错的：3 秒前认证的动作可能因一次回环而落进墙里。所以证书必须带 `map_version`，回环触发**追溯性重认证**；且必须有"地图陈旧度"上限，过期证书不得执行。此外，主动 SLAM 的信息收益是**延迟**的：为了回环，得先走进一段没有新特征的走廊（期间地图熵不降反升）。R69 的近视 VoI 永远算不过账，于是永远不探索。R70 要引入带折扣的**非近视 VoI** 与回合级信息调度。

**灵感 3（统一 → 安全度量与信息度量是同一雅可比的两张脸）**
直觉：末端执行器控制关心 J（动作→任务位移），SLAM/视觉伺服关心交互矩阵 L（动作→观测特征位移）。二者都从关节速度推出，只是投影到不同空间。于是"这个动作有多危险"与"这个动作能看多清"是同一局部几何的两个二次型：风险 = ‖g‖²_{G_safe}，信息 = ‖g‖²_{G_info}。最有价值的信息动作，是在**单位风险下信息最大**的方向——这不是枚举候选，而是一个广义特征值问题 max gᵀG_info g / gᵀG_safe g。非显然推论：奇异位形既是动作最危险处，往往也是观测最敏感处（相机在末端时），**最该看清的地方恰恰是最不该动的地方**——安全与信息共享同一个病态方向。

**灵感 4（三通道 → 再补一条不能被吸收的冗余）**
直觉：R68 用传感器残差 r_res 测"测量自洽"，R69 用动作似然 Δa 测"行为自洽"。但还有一条：**传出的指令穿过身体后，真的产生了预期的末端运动吗？** 比较"命令动作经身体模型+地图预测的末端位姿"与"实测末端位姿"（本体感觉融合视觉伺服）得到 r_eff。它能抓住前两条都抓不到的：运动学标定错、工具磨损、接触滑移、以及动作被执行到地图里的错误位置。三条通道盲区不同，取并集才逼近完备。

**灵感 5（尺子也会坏 → 必须校准尺子本身）**
直觉：最尖锐的风险不是"不确定"，而是"你把不确定乘错了系数"。雅可比在奇异附近病态，SLAM 协方差可能**过度自信**（一致但错误的回环），此时度量给你的不是安全，而是**有恃无恐**。所以 R70 必须自带度量校准门：一旦运动学/外参/位姿图协方差的校准误差越界，就禁用度量修正，回退到 R69 的各向同性保守——宁可把危险的尺子换成最钝的尺子。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（SEAM-RAS 总览与四不变式）** SEAM-RAS = (JAM, SLAM-Σ, MAM, RID, FME, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **度量一致性**：所有不确定性比较必须在同一 pullback 度量下进行，禁止跨度量直接比较熵或距离；
(iii) **地图版本新鲜性**：任何执行中的证书必须引用当前 map_version 且陈旧度 ≤ τ_map，回环事件触发追溯重认证；
(iv) **退化安全**：度量不可信（MCG-G 越界）时逐指令退化为 FLUID/R68 的保守路径。

**定义 311（执行映射与位形相关度量）** 配置 q∈ℝⁿ，末端雅可比 J(q)∈ℝ^{6×n}。动作扰动 δξ 经执行映射 E(q) 变为末端 twist 偏差 δx=E(q)δξ（ξ 为关节量时 E=J，为任务量时 E=I）。SLAM 给出机器人与目标在**活动子图**内的相对位姿协方差 Σ_rel(q)（6×6，见定义 316），任务度量 M_task(q)=blkdiag(Σ_rel,pos^{-1}, Σ_rel,rot^{-1})（可加正则）。定义 **pullback 度量**
G(q)=E(q)ᵀ M_task(q) E(q) ⪰ 0。
物理意义：‖δξ‖²_G = δxᵀ M_task δx，即"该动作误差换算成任务/世界里的代价"。G 的谱刻画身体如何拉伸不确定性。

**定义 312（度量修正的不确定性二分）** 给定模态 {m_k, ŵ_k, Σ_k}：
U_ale^G = Σ_k ŵ_k tr(G Σ_k)（模态内、经度量加权的不可约不确定）；
Δ_min^G = min_{i≠j} d_G(ξ̄_i, ξ̄_j)，d_G 为 G 下测地距离；
U_epi^G = H_mode · φ(Δ_min^G / σ_in^G)，σ_in^G = sqrt(mean_k tr(GΣ_k))。
R69 的 U_ale/U_epi 是 G=I 的特例。可分性必须在**代价**里量：靠奇异方向分开的模态任务代价小，值不值得问也小；沿良态方向分开的模态才值得交互。

**定义 313（SEAM-VoI：任务后果加权的信息价值）** 误选代价 ℓ_G(a; m*) = min_k ‖a−ξ̄_k‖²_G。后验期望损失 L_G(w)=Σ_k w_k ℓ_G(ξ̄_k; m*)。信息动作 g 的后果加权信息价值
VoI_G(g)=L_G(w) − E_{y∼p(·|g,o)}[L_G(w′)]，
w′ 为观测 y 后的后验。选择 g*=argmax_g[VoI_G(g)−c(g)]，s.t. 预算与几何约束（定义 315/322）。VoI_G≤0 ⇒ 不交互，退化为 FLUID。它严格是 R69 VoI（均匀 0/1 代价）的推广。

**定义 314（风险归一化信息方向 RID）** 观测特征 s∈ℝ^m，交互矩阵 L(q)∈ℝ^{m×n}，观测信息 M_obs=Σ_obs^{-1}，信息度量 G_info(q)=L(q)ᵀ M_obs L(q)。取风险度量 G_safe(q)=G(q)+ε_g I（含执行代价）。**风险归一化信息方向**为广义特征问题
G_info v = λ G_safe v
的最大特征向量 v₁，λ_max=ρ(G_safe^{-1}G_info) 即"单位风险可得的信息"。信息动作取 g*∝v₁（按预算缩放），替代 R69 的候选枚举；当 L∝J 时二者共享同一病态方向。

**定义 315（末端执行器几何门控 JAM）** 可操作度 μ(q)=sqrt(det(JJᵀ))，条件数 κ(q)=σ_max(J)/σ_min(J)。若 κ>κ_max 或 μ<μ_min，触发**几何放大**：λ_geo = 1 + α(κ/κ_max −1)⁺，并令 U_ale^G ← λ_geo·U_ale^G。理由：奇异附近无论 VoI 多高、模态多分明，都要先按放大后的物理代价保守——此时"小歧义"物理上并不小，而"问"本身要动、要动就可能越过奇异。

**定义 316（SLAM 局部一致性度量）** 位姿图给出关键帧位姿协方差；执行点只需活动子图内的相对协方差
Σ_rel = Σ_base + Σ_target − 2Cov(base,target)（Schur 补边际）。
全局漂移在相关项里抵消；只有未闭合、跨子图的目标才暴露大 Σ_rel。定义局部一致性指标 λ_LC = sqrt(tr Σ_rel / tr Σ_global,naive)：λ_LC<1 表示"局部比全局更可信"，允许局部用更紧的度量——这既是回环前能安全工作的原因，也是回环后会突然收紧的原因。

**定义 317（前向模型 / 传出副本残差 FME）** 命令 ξ 经身体模型（正运动学 + 接触/阻抗模型）与当前地图预测末端位姿轨迹 x̂_ee(t)；实测末端位姿（本体感觉融合视觉伺服）x_ee(t)。r_eff = RMSE_t( x_ee(t) ⊖ x̂_ee(t) )，按 G 加权。r_eff 度量"身体与世界是否如我所信"，能捕获运动学失准、工具磨损、接触滑移、以及动作落在错误地图位置。

**定义 318（三通道盲区矩阵）** 三类故障 f∈{传感标定漂移, 策略分布漂移, 身体/地图失配}。通道 r=(r_res, Δa, r_eff)，灵敏度矩阵 S[i,j]=∂r_i/∂f_j。要求 rank(S) 与每行零空间记录于证书；**三通道联合盲区 = ∩ᵢ ker(S_i)** 须显著小于任一单通道盲区（A99 可辨识性假设）。设计目标：没有任何单一故障类型同时落在三条通道的零空间。

**定义 319（非近视主动 SLAM 与信息调度）** 信息动作 g_map（移动/回访/回环轨迹）收益延迟：
VoI_π(g_map)=E[Σ_{t'=t}^{t+H_g} γ^{t'−t} ΔH_map(t')] − c(g_map)，γ<1。
回合级调度在预算 B_ep 下最大化 Σ VoI_π；近视控制器是 H_g=1 的退化。允许"先付代价后收益"，但收益必须超过**预先声明的探索押金**，否则视为赌博而非信息。

**定义 320（帧失效与追溯认证）** 每次回环/重定位使 map_version←v+1 并给出帧变换 T_Δ（协方差 Σ_Δ）。每个执行证书携带 (map_version, target_pose, margin)。回环后对在途证书：若 ‖T_Δ⊖target‖_G > margin，进入失效集 I(closure) 强制重认证；重认证不通过则撤销。陈旧度 age(v)=now−v_time > τ_map 的证书**一律不得执行**。这把"已认证"从永久属性变为**版本化、可撤销**属性。

**定义 321（接触条件化度量与接触模态）** 接触态 c∈{free, stick, slip}。接触约束把有效自由度投影到约束雅可比 J_c=J N_c（N_c 为零空间基）。度量 G_c=J_cᵀ M_task J_c；接触模态本身作为离散模式并入 {m_k}（"推得动/推不动""会滑/不会滑"是必须消歧的模态）。滑移检测用 r_eff 的切向分量突变。

**定义 322（几何安全包络）** 认证前缀除 C-RAS-WM 外，须在整条预测前缀上满足 κ(q(s))≤κ_max 且 μ(q(s))≥μ_min（奇异规避），否则截断 k 或重规划；若不存在满足约束的前缀，判为不可行，走三级退避（定义 326）。信息动作同样受此约束（探针/注视不得把末端带入奇异）。

**定义 323（度量校准门 MCG-G）** 监控三类度量质量：运动学/外参标定残差、Σ_rel 的协方差一致性（NEES/χ² 检验）、J 的条件数与数值秩。任一越界 ⇒ 禁用度量修正与 RID，令 G←I、M_task←I，退化为 FLUID/R69 各向同性保守；严重越界（如检测到过度自信回环）⇒ 回退 R68。直觉：**尺子坏了就换最钝的尺子，而不是继续用它量。**

**定义 324（干扰集 ℰ_seam）** 假回环/感知别名（走廊互似、反光面）导致追溯错误对齐；运动学/外参欺骗（标定被投毒）；奇异陷阱（把目标摆在奇异附近诱使放大）；信息荒漠诱骗（引诱长时间探索耗尽预算）；接触欺骗（假滑移）。并入 AIC：ℰ_SEAM = ℰ_FLUID × ℰ_frame × ℰ_metric。

**定义 325（证书 J_SEAM）** J_SEAM=(J_FLUID, map_version, age(v), tr Σ_rel, κ_p95, μ_min, λ_LC, r_eff_p95, rid_λmax, metric_calib, seam_ver)。Valid ⇔ Valid(J_FLUID) ∧ age≤τ_map ∧ 度量校准通过 ∧ 三通道盲区表已记录 ∧ 几何包络满足。

**定义 326（三级退避与 SEAM 主闭环）** 三级：(1) 信息可消解且度量可信 → λ=λ_floor(U_ale^G)，获 resolution bonus；(2) 度量放大/奇异/接触不确定 → λ=λ_floor(λ_geo·U_ale^G + 未消解 U_epi^G) 且截断 k（几何保守）；(3) 帧失效/度量不可信/slow_fault → λ=λ_floor(全部) 且回 R68 最保守，撤销在途动作。三级 λ 单调不降，安全侧永不弱于 FLUID/R68。

# IP-264 JAM：执行映射与 pullback 度量（位形相关的尺子）
def seam_metric(q, target_id, slam):
    J  = fk_jacobian(q)                        # 6×n，复用 R68 运动学缓存
    S  = slam.active_submap_cov(q, target_id)  # 活动子图相对协方差（定义 316）
    Mt = inv_blockdiag(S)                      # 任务-世界度量 M_task
    G  = J.T @ Mt @ J                          # pullback 度量
    return normalize(G), condition_number(J), manipulability(J), S

# IP-265 MAM：度量修正的 aleatoric / epistemic 分解
def decompose_G(samples, G, mode_head):
    modes = cluster_trajectories(samples, metric=G)   # 度量下的 Fréchet/DTW
    w     = mode_weights(modes)
    U_ale = sum(w[k] * trace(G @ cov(modes[k])) for k in modes)
    dmin  = min_geodesic_distance(modes, G)           # Δ_min^G
    U_epi = entropy(w) * sep_factor(dmin, G)
    return U_ale, U_epi, modes

# IP-266 SEAM-VoI + IP-267 RID：后果加权 + 风险归一化信息方向
def choose_info_action(modes, G, J, L, budget):
    best = argmax_candidate(modes, G, budget)          # 先走 R69 兼容的候选路径
    if best and best.score > 0 and budget.allow(best.g):
        return best.g
    Gs = G + EPS_G * np.eye(G.shape[0])
    Gi = L.T @ M_OBS @ L
    v  = top_generalized_eigvec(Gi, Gs)                # G_info v = λ G_safe v
    g  = scale_to_budget(v, budget)
    return g if c_ras_wm.certify_info_geom(g, J, q) else None

# IP-268 JAM-gate：几何放大
def geometric_inflation(J, kappa_max=20.0, mu_min=1e-3):
    k, mu = condition_number(J), manipulability(J)
    if k > kappa_max or mu < mu_min:
        return 1.0 + ALPHA * max(0.0, k / kappa_max - 1.0)
    return 1.0

# IP-269 FME：传出副本残差（第三条不可吸收通道）

# IP-270 帧失效与追溯重认证
def on_loop_closure(M, T_delta):
    M.map.bump_version()
    for cert in M.certs.in_flight():
        if norm_G(T_delta.apply(cert.target) - cert.target) > cert.margin:
            M.certs.invalidate(cert)                   # 进入 I(closure)

                M.certs.revoke(cert)                   # 撤销，不得执行
    M.certs.drop_stale(tau_map=TAU_MAP)                # 陈旧证书一律失效

    reff  = M.fme.efference_residual(M.last_action, q, obs, G, M.slam)
    fault = M.blind.check(r_res, da, reff)             # 定义 318 盲区矩阵
    # 3) 后果加权 VoI + 几何约束
    g = None
    if U_epi > TAU_EPI and not fault.slow:
        g = M.mint_g.choose_info_action(modes, G, M.jac(q),
                                        M.interaction_matrix(q), M.budget)
    if g is not None:
        U_epi = M.cia.update_belief(modes, M.cia.execute(g),
                                    discipline='k_orthogonal')
    # 4) 度量修正 + 几何放大 + 三级退避
    lam_geo = M.jam.geometric_inflation(M.jac(q))
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(lam_geo * U_floor))
    # 5) 几何安全包络下的认证前缀
    k = M.c_ras_wm.certified_prefix_geom(M.ach.propose(...), q,
                                         kappa_max=K_MAX, mu_min=MU_MIN)
    if fault.frame_invalid or fault.metric_untrusted or fault.slow:
        lam = max(lam, 0.8); k = min(k, M.k_cal_shrink(...))
        M.certs.revoke_stale()
    # 6) 版本化证书 + 三通道审计
    cert = M.certs.issue(k, lam, M.map.version, target=M.target_pose(),
                         margin=M.margin, triple=(r_res, da, reff), G_trace=trace(G))
    M.vqa_i.submit_async(g, cert, fault)
    return k, lam, cert
```

## 3. 推导

**引理 19（度量放大：1/σ_min 律）** 设 J(q)=UΣVᵀ，σ_min 为最小非零奇异值。若需沿 u_min 在任务空间修正 ‖Δx‖，最小范数关节解 q*=J⁺Δx 满足 ‖q*‖=‖Δx‖/σ_min；故风险 ≈ ‖q*‖²_{G_safe} ≥ (M_task,min/σ_min²)·‖Δx‖²，随 σ_min→0 发散。系：R69 在原始动作坐标里量出的"小模态间距/低 VoI"，在奇异附近可能对应巨大任务风险；必须用 Δ_min^G 与 VoI_G，而非 Δ_min 与 H_mode。

**引理 20（RID 最优性与安全-信息张力）** 若 G_safe≻0、G_info⪰0 对称，则 (G_info,G_safe) 的广义特征对为实；λ_max=ρ(G_safe^{-1}G_info)，v₁ 使单位风险信息最大。当 L=cJ 时，v₁ 同时落在 G_safe 的最危险方向附近，λ_max 由 J 的谱决定：**越靠近奇异，单步信息增益越大，但绝对风险也越大**。故 RID 必须被几何门控（定义 315）截住——探索最值钱处即最危险处。

**引理 21（三通道不可吸收与盲区收缩）** 存在故障基使得：传感标定漂移 f₁ 对 r_res 可被标定吸收（∂r_res=0）但 ∂r_eff≠0（末端预测偏差）；策略分布漂移 f₂ 进入 Δa 而不进 r_res；身体/地图失配 f₃ 主要进 r_eff。若灵敏度矩阵 S 行满秩（A99），则三通道联合盲区 ∩ker(S_i) 严格小于任一单通道盲区；特别地，不存在同时被标定、策略自适应与身体模型吸收的故障。故第三通道把 R68/R69 各自最脆弱的缓变故障从"不可见"变为"联合可见"。

**定理 18（严格嵌套 SEAM ⊃ FLUID ⊃ CALM）** 当 J 正交、M_task=I、Σ_rel=0、无接触且无回环时 G=I，SEAM 的 (U^G, VoI_G, RID, FME) 逐项退化为 FLUID 的 (U, VoI, MINT, FMA)，故 SEAM≡FLUID；再令永不交互即得 R68。于是 SEAM 在退化边界上安全与行为逐指令一致，仅在非各向异性几何/漂移地图上获得额外保守（几何）或额外收益（resolution bonus）。

**定理 19（回环追溯安全与无突变）** 在定义 320 的版本化认证与陈旧度约束下，任意被执行动作在**当前**地图下与认证目标偏差 ≤ margin；失效集 |I(closure)| 小于等于由漂移/回环幅度决定的关键帧数，因而有界；回环后 λ 单调不降（只可能从 (1) 升到 (2)/(3)）⇒ 控制连续、无突变；被撤销证书数量有限且事件触发，不进入实时主循环 ⇒ 实时性不变。

**定理 20（非近视探索的必要性）** 构造"信息荒漠"场景：唯一含新特征的回环点在长度 d 的低信息走廊之后；走廊内每步近视 VoI≤0，故近视控制器永不进入；而非近视折扣 VoI_π>0 当且仅当 γ^d ΔH_loop 超过累积成本。该差距随 d 指数增大。故 SLAM 型信息动作必须回合级调度；近视 MINT 在此类场景系统性失败。

                M.certs.revoke(cert)

# IP-276 SEAM 主闭环（嵌套 FLUID/R68）
def SEAM_RAS_round(M, obs):
    q, o = M.mtm.forward(...)
    G, kappa, mu, S = M.jam.seam_metric(q, M.target_id, M.slam)
    if M.mcg_g.unreliable(q, S): return M.fluid_round(obs)
    K = 1 if M.fmp.mode_head(o) < TAU_MODE else 4
    U_ale, U_epi, modes = M.aud_g.decompose_G(M.fmp.sample(o, K), G, M.fmp.mode_head)
    r_res = M.cof.last_residual()
    da    = M.fma.flow_anomaly(M.fmp, M.last_action, obs, M.cof.corrected(obs))
    reff  = M.fme.efference_residual(M.last_action, q, obs, G, M.slam)
    fault = M.blind.check(r_res, da, reff)
    g = None
    if U_epi > TAU_EPI and not fault.slow:
        g = M.mint_g.choose_info_action(modes, G, M.jac(q),
                                        M.interaction_matrix(q), M.budget)
    if g is not None:
        U_epi = M.cia.update_belief(modes, M.cia.execute(g),
                                    discipline='k_orthogonal')
    lam_geo = M.jam.geometric_inflation(M.jac(q))
    lam = max(M.efs.risk_scale(...),
              lam_floor(lam_geo*(U_ale + (U_epi if g is None else 0.0))))
    k = M.c_ras_wm.certified_prefix_geom(M.ach.propose(...), q,
                                         kappa_max=K_MAX, mu_min=MU_MIN)
    if fault.frame_invalid or fault.metric_untrusted or fault.slow:
        lam = max(lam, 0.8); k = min(k, M.k_cal_shrink(...)); M.certs.revoke_stale()
    cert = M.certs.issue(k, lam, M.map.version, target=M.target_pose(),
                         margin=M.margin, triple=(r_res, da, reff), G_trace=trace(G))
    M.vqa_i.submit_async(g, cert, fault)
    return k, lam, cert
```

## 4. 推导

**引理 19（1/σ_min 放大律）** J=UΣVᵀ。沿 u_min 修正 ‖Δx‖ 时 `‖J⁺Δx‖=‖Δx‖/σ_min`，风险 `≈‖Δx‖²M_task,min/σ_min²` 随 σ_min→0 发散。⇒ R69 的原始坐标 Δ_min/VoI 在奇异附近严重低估危险，必须改用 Δ_min^G、VoI_G。

**引理 20（RID 最优性与安全-信息张力）** `G_safe≻0, G_info⪰0` ⇒ 广义特征对实，`λ_max=ρ(G_safe⁻¹G_info)`，v₁ 使单位风险信息最大。`L∝J` 时 v₁ 逼近 G_safe 最危险方向：**越近奇异，单步信息越大、绝对风险也越大**，故 RID 必须几何门控。

**引理 21（三通道盲区收缩）** 存在故障基使 f₁（标定漂移）进 r_eff 不进 r_res、f₂（策略漂移）进 Δa、f₃（身体/地图失配）主要进 r_eff。S 行满秩（A99）⇒ `∩ker(S_i)` 严格小于任一单通道盲区，不存在被三条通道同时吸收的故障。

**定理 18（严格嵌套 SEAM⊃FLUID⊃CALM）** `J` 正交、`M_task=I`、`Σ_rel=0`、无接触无回环 ⇒ G=I，SEAM 各组件逐项退化为 FLUID；再令永不交互即 R68。退化边界安全与行为逐指令一致；仅在非各向异性几何/漂移地图上额外保守或获 resolution bonus。

**定理 19（回环追溯安全与无突变）** 版本化认证 + `age≤τ_map` ⇒ 任意执行动作在当前地图下与目标偏差 ≤ margin；`|I(closure)|` 有界；回环后 λ 单调不降（(1)→(2)/(3)）⇒ 控制连续无突变；重认证事件触发、不入实时主循环 ⇒ 实时性不变。

**定理 20（非近视探索必要性）** "信息荒漠"长 d：走廊内每步近视 VoI≤0，近视永不动；非近视 `VoI_π>0 ⇔ γ^dΔH_loop>累积成本`，差距随 d 指数增大。⇒ SLAM 型信息动作必须回合级调度，近视 MINT 系统性失败。

## 7. 本轮最大风险

**一句话**：SEAM-RAS 把安全押在"尺子本身准确"上——**奇异位形处雅可比度量恰在最需要它时病态/不可信，SLAM 回环又会让世界坐标系与度量发生不连续跳变；错误的尺子既能让你在必须动时僵死（λ_geo 爆炸、无可行前缀），也能让你在坐标系已漂移时自信地执行一个"追溯性不安全"的动作**——量错，比不量更危险。
