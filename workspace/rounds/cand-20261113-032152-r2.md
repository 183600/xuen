# 第 64 轮（承接第 63 轮「LIRO 几何-技能-干扰闭环」IP-193~202；灵感循环 II 第 3 轮；本轮灵感：「路径规划」×「对比实验」）

> 第 63 轮构建了 LIRO：LSF 稠密几何融合、USL 通用技能库 + CSP 组合规划、DIR 干扰不变表征 + AIC 认证、SSB 空间场景银行、OLP-Geo/WCV-Geo/Shield-Skill/OCB-Skill 原位升级。但第 63 轮自述的最大风险暴露了一个**结构性缺陷**：
> **LIRO 把几何坍缩成单点估计 `g`，并把由它导出的 `φ̂_0` 与 `𝒢(g)` 当作硬先验使用**。一旦 E_geo 在透明/镜面/强吸光/新拓扑物体上产生系统性幻觉几何，`r_0` 会因"几何清晰度"被错误缩小、`𝒢(g)` 会过度自信、DIR 会在"错误的干净视图"上做对比——**几何先验从"压缩不确定性"反转为"注入确定性错误"**（A77 单点假设），而 LIRO 没有任何机制去**主动检验、主动证伪、或花动作去消歧**这一先验。
>
> 本轮用两个灵感各补一刀：
> 1. **「路径规划」**：规划不该只回答"如何从 A 到 B"，还应回答"**走哪条路能最快证伪我最担心的几何假设**"。引入 belief-space / dual-control 式规划：把低力、可逆的**探测技能**（tap/press/swipe/edge-trace/lift-test）插入路径前缀，先探测后承诺（probe-then-commit）；并用鲁棒管道（tube）包住名义路径，保证假设束内所有几何都不违反摩擦锥。
> 2. **「对比实验」**：既然幻觉无法由单帧感知自证，就用**配对反事实对比**做因果归因——同初始状态、同随机种子，在多个几何假设下成对 rollout，比较安全裕度；若执行残差在所有假设下都像离群点，则判定为幻觉而非执行失败。对比实验同时升级为**离线评估协议**（预注册、配对设计、ATE/CATE、非劣性/等价检验、多重比较校正）。
>
> 合流得到 **PACE（Probing-Audited Comparative Exploration，探测-审计-对比探索闭环）**：LIRO 的"几何→技能→干扰"三层不动，新增**几何信念层**与**对比审计层**，使系统从"信任几何"升级为"**用规划检验几何、用对比审计规划**"。

## 0. 直觉与动机

**灵感 1（路径规划 → EPP：Epistemic Probing Path Planner 认知探测路径规划）**
直觉：第 63 轮 CSP 只做技能序列搜索，代价里只有任务代价与切换代价，**没有"信息"这一项**。但机器人恰恰可以通过动作获取信息：轻触一下就能测出法向符号，慢速侧滑就能区分曲率正负。路径规划的对偶控制（dual control）思想指出：**最优动作应同时"利用"（完成任务）与"探索"（降低关键不确定性）**。于是把规划目标改为 `J(τ) = 任务代价 + λ_r·CVaR_ε(风险) − λ_I·EIG(τ) + λ_s·切换代价`，其中 `EIG(τ)=I(B_g; Y_τ)` 是路径对几何信念束的期望信息增益。规划器在**高歧义 × 下游动作不可逆**的位置自动插入探测前缀，把不可逆的抓取/插入推到"歧义已消解"之后。关键：探测技能低力、可逆、代价小，因此"多走几步"换取"少一次灾难性错误"是划算的。

**灵感 2（对比实验 → CCT + HAD：反事实对比检验 + 幻觉归因检测）**
直觉：第 63 轮的 AIC 只对**干扰**做认证，却默认"几何假设本身为真"。对比实验的核心是**控制变量 + 配对比较**：把"采用某几何假设下的规划"当作处理组，把"保守兜底规划"当作对照组，在**同一初始条件、同一噪声种子**下配对执行/仿真，看处理组是否**非劣**于对照组。若成对差值显著为负，则拒绝该几何假设。更进一步，执行后把观测残差与各假设下的预测残差做**反事实比较**：若"没有任何假设能解释观测"，则不是执行失败，而是**感知幻觉/OOD**（HAD）。这把"对比实验"从离线论文表格变成了**在线可执行的证伪器**。

**灵感 3（合流 → PACE：几何信念 × 探测规划 × 对比审计）**
三者咬合：GBB 把单点几何变成**带权假设束**（覆盖真实几何的概率 ≥ 1−α_b）；EPP 用探测路径**主动降低假设束熵**，且只在 CCT 通过后执行不可逆技能；CCT 用配对非劣性检验**为承诺把关**；HAD 在执行后**归因**失败并回写信念/场景银行；WCV-B 与 AIC-C 把安全认证从"单球最坏"升级为"假设束最坏 + 配对审计"。闭环：几何歧义↑ → EPP 插探测 → 信念熵↓ → WCV-B 球更紧更真 → 不可逆技能经 CCT 放行 → 执行残差经 HAD 归因 → SSB-P 记录"探测-修正"轨迹 → 下一轮规划更敢承诺。**第 63 轮是"用几何压缩不确定性"，PACE 是"用动作和对比验证几何"**。

**灵感 4（LIRO 组件的原位升级）**
- **LSF → LSF-B**：几何编码输出 `K` 个模式假设 + 权重 + 歧义头，经 conformal 校准保证覆盖；不再输出单点 `g`。
- **USL → USL-P**：技能库加入**探测原语**（可逆、低力、带信息效应模型），并为每个技能标注 `irreversible` 标志。
- **CSP → CSP-B**：在信念空间搜索，目标含 `EIG` 项；仅在 `irreversible` 技能前设 CCT 门；EIG 是单调子模，探测子集可用贪心 `(1−1/e)` 近似。
- **WCV-Geo → WCV-B**：对假设束取最坏（`min_k`），并非对单球取最坏；球半径 `r_k` 逐假设给出。
- **OLP-Geo → OLP-B**：仅对低歧义样本更新（按 `exp(−H(B_g))` 加权），避免从幻觉中学习。
- **SSB → SSB-P**：场景签名增入**歧义签名**与**探测结果**，支持"同场景、不同几何解释"的检索。
- **AIC → AIC-C**：认证输出配对非劣性 `p` 值与假设束覆盖率，扩展为 `J_pace`。
- **OCB-Skill → OCB-P**：臂空间加入"探测预算档位"（0/1/2 次探测），按信息收益/算力调度。

## 1. 形式化定义（增量：定义 201–216）

- **定义 201（PACE 闭环）**：PACE = (LIRO, GBB, LSF-B, USL-P, CSP-B, EPP, RTP, CCT, HAD, WCV-B, OLP-B, SSB-P, AIC-C, J_pace)。定位：LIRO 的"几何信念化 + 规划信息化 + 审计对比化"升级；所有新增组件挂载于 LIRO 骨架，不推翻既有接口。
- **定义 202（GBB 几何信念束）**：`B_g = {(g_k, w_k)}_{k=1}^K`，`Σ_k w_k = 1`，`K∈{4,8}`；`g_k = E_geo^B(P_cloud)_k` 为第 k 个几何模式嵌入，`w_k` 为其后验权重；`H(B_g) = −Σ w_k log w_k` 为信念熵；conformal 校准保证 `P[g* ∈ B_g] ≥ 1−α_b`（α_b=0.05）。
- **定义 203（LSF-B 多假设几何融合）**：E_geo^B 共享 3D 骨干 + `K` 个模式头，输出 `{(g_k, w_k)}` 与歧义 logits `a`；`x' = Σ_k w_k·CrossAttn(x, g_k, g_k)` 为信念加权融合；`amb = H(B_g)` 与 `max_k w_k` 共同构成幻觉风险信号。
- **定义 204（USL-P 探测技能库）**：`USL-P = USL ∪ {σ_probe}`，`σ_probe = (name, pre, eff_info, π_σ, cost, reversible=True)`；探测观测模型 `y = h_probe(φ*) + ε_probe`，似然 `p(y | g_k)` 用于信念更新；`eff_info` 形式化为 `H(B_g) − H(B_g | y)`。
- **定义 205（CSP-B 信念空间技能规划）**：给定目标 `G`，搜索 `τ=[σ_1,...,σ_H]` 使 `pre_σ1(B_g)` 成立、`eff_σi ⊨ pre_σ{i+1}`、`eff_σH ⊨ G`，且 `∀i π_σi ∈ 𝒫_feas^B(B_g)`；不可逆技能 `σ_i` 还须通过 CCT 门。
- **定义 206（EPP 认知探测路径规划）**：`τ* = argmin_τ [ Σ_t cost(σ_t) + λ_r·CVaR_ε(risk(τ; B_g)) − λ_I·EIG(τ) + λ_s·switch(τ) ]`，`EIG(τ) = H(B_g) − E_{Y_τ}[H(B_g | Y_τ, τ)] = I(B_g; Y_τ)`；求解器为 anytime belief-A*/MCTS，`EIG` 子模 → 探测子集贪心近似。
- **定义 207（RTP 鲁棒管道路径）**：名义路径 `ξ` 配管道半径 `ρ_tube(s) = Q_{1−α_b}(‖Proj_n(φ* − φ̂_0(s))‖)`；验证 `∀g_k∈B_g, ∀δ∈Tube(ρ_tube): friction_cone ∧ collision_free ∧ τ_ext ≤ τ_max`；失败则缩管或插探测。
- **定义 208（CCT 反事实对比检验）**：对计划 `τ`，在假设 `g_k` 下做**同种子配对** rollout 得裕度 `m_k`，对照组为保守兜底 `m_0`，配对差 `d_k = m_k − m_0`；非劣性检验 `H_0: min_k m_k < −δ_n` vs `H_1: min_k m_k ≥ −δ_n`（δ_n=0.05），配对 bootstrap + Holm 校正；通过才允许承诺不可逆技能。
- **定义 209（HAD 幻觉归因检测）**：执行残差 `r_obs = τ_ext^obs − τ_pred`；在假设 `g_k` 下预测残差分布 `N(μ_k, Σ_k)`，马氏距离 `d_k = (r_obs−μ_k)ᵀΣ_k^{-1}(r_obs−μ_k)`；若 `min_k d_k > τ_conf`（conformal 阈值）则判 `hallucination=True`，并以 `argmin_k d_k` / "无假设可解释"做归因。
- **定义 210（WCV-B 信念鲁棒编译）**：`ρ_rob^B = min_k ρ_rob^k`，其中 `ρ_rob^k` 在 `B(φ̂_0^k, r_k)∩𝒢_k` 上做 CVaR 最坏搜索；若存在 `k` 使交集为空或 `ρ_rob^k<0`，路由至探测/兜底。
- **定义 211（OLP-B 歧义感知在线投影）**：`W_{t+1} = P_𝒲(W_t − η_t·ω_t·∇_W ℓ̃_t)`，`ω_t = exp(−β·H(B_g))·𝟙[agreement]`；高歧义样本不进入几何相关子块的更新。
- **定义 212（SSB-P 空间-歧义场景银行）**：`scene_sig = (V_sig, T_sig, fp_cloud, φ_sig, dyn_annot, amb_sig, probe_log)`，`amb_sig=(H(B_g), max_k w_k, mode_hist)`；Mine 按 `fp_cloud ⊕ amb_sig` 检索；Mut 增加"歧义保持/歧义翻转"两类几何变异。
- **定义 213（AIC-C 对比审计认证器）**：`J_dir^C = (ρ_dir^B, ℰ_spec, cct_p, coverage_est, cert_hash)`，其中 `ρ_dir^B = min_{η∈ℰ} min_k min_t margin`；`cct_p` 为 CCT 非劣性检验 p 值；覆盖率由 conformal 校准给出。
- **定义 214（J_pace 扩展证书）**：`J_pace = (J_liro, belief_ver, K_eff, coverage_est, probe_plan_hash, cct_p, hallucination_flag, tube_hash, amb_sig)`；`Valid(J_pace) ⇔ Valid(J_liro) ∧ coverage_est ≥ 1−α_b ∧ (cct_p < α_cct ∨ 无不可逆动作) ∧ ¬unresolved_hallucination`。
- **定义 215（BelUpdate 信念更新算子）**：`w_k^+ ∝ w_k·p(y_probe | g_k)·p(r_obs | g_k)`；若 `min_k d_k > τ_conf`，则以 SSB-P 最近邻为新生假设 `g_new` 做"开集更新"，并将 `hallucination_flag` 写入审计链。
- **定义 216（对比实验协议 CEP）**：离线下，对 PACE（处理）与 LIRO（对照）做**配对随机区组设计**：区组=几何歧义分层（低/中/高），同初始位姿、同随机种子、同算力预算；估计 `ATE = E[Y(T)−Y(C)]` 与 `CATE(stratum)`；推断用配对 bootstrap（BCa, 10k）+ 非劣性/TOST 等价检验 + Holm-Bonferroni（10 项）；预注册主/次终点与证伪阈值。

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 5（信念覆盖 ⇒ 承诺安全）**：若 `P[g*∈B_g] ≥ 1−α_b` 且对每个 `g_k` 的规划裕度 `ρ_k ≥ 0`，则一次承诺的执行安全概率 `≥ 1−α_b − ε_cal`（`ε_cal` 为 conformal 校准误差）。**几何不再需要"猜对"，只需"覆盖 + 最坏情况安全"**。
- **引理 6（探测的信息价值下界）**：设裕度对信念后验是 `L_m`-Lipschitz，则一次探测带来的期望风险下降 `Δrisk ≤ L_m·√(2·I(B_g;Y))`，其收益 `≥ λ_r·Δrisk − c_probe`；当 `I(B_g;Y) > c_probe²/(2λ_r²L_m²)` 时探测严格划算。**这给出了"何时值得多走一步"的判据**。
- **定理 4（CCT 非劣性检验有效性）**：在配对可交换性下，Holm 校正的 `K` 个单侧非劣性检验控制族错误率 `≤ α_cct`；若真实最坏裕度比兜底低 `Δ>δ_n`，则 `n ≥ 2log(2K/β)/(Δ−δ_n)²` 对配对足以达到功效 `1−β`。集合信念覆盖 `1−α_b`，**承诺不安全概率 ≤ α_cct + α_b**。
- **定理 5（HAD 检测与延迟）**：若幻觉残差分布与标称分布 KL 为 `D_KL`，`n` 次独立观测下 Chernoff–Stein 误检率 `≤ exp(−nD_KL)`；conformal 阈值把虚警控制在 `α_h`，检测延迟 `~ log(1/β)/D_KL`。**"无假设可解释"是可判定的幻觉信号**。
- **定理 6（安全-代价权衡）**：`T` 轮累积期望违规 `≤ T·(α_cct+α_b) + O(√(T log K))`；任务代价超支 `≤ λ_I·Σ EIG + c_probe·N_probe`；探测集因 `EIG` 单调子模，贪心达到最优的 `(1−1/e)`。**安全提升有可量化的代价上界，而非无限探测**。
- **实时性**：实时流仅增加信念查表（<0.1ms）与 WCV-B 的 `K_eff`（权重剪枝后通常 2–3）并行编译（<1.2ms），总 `≤ 2ms` 契约不破（A75/A82 继承）。

# 第 64 轮产物 · 创新点清单 v4：PACE（Probing-Audited Comparative Exploration：几何信念束 × 探测路径规划 × 反事实对比审计，GBB×LSF-B×USL-P×CSP-B×EPP×RTP×CCT×HAD×WCV-B×OLP-B×SSB-P×AIC-C×J_pace）

> 承接第 63 轮 IP-193~IP-202（LIRO：LSF×USL×CSP×DIR×AIC×SSB×OLP-Geo×WCV-Geo×Shield-Skill×OCB-Skill）。本轮不推翻 LIRO，而是修补其**最致命的单点假设 A77**：E_geo 一旦产生系统性幻觉几何，单点 `g → φ̂_0 → 𝒢(g)` 会注入"确定性的错误"。PACE 把几何从**点估计**升级为**带权假设束**，把规划从**纯任务代价**升级为**任务 + 探测信息增益 + 鲁棒风险**，把认证从**单球最坏**升级为**假设束最坏 + 配对反事实非劣性检验**。
>
> 一句话定位：**LIRO 用几何压缩不确定性；PACE 用动作检验几何、用对比审计承诺。**
>
> IP 编号：IP-203~IP-212（共 10 个），全部为 LIRO 组件的原位升级或挂载式新增。

## 2. 形式化定义（完整版）

**定义 201（PACE 闭环）** PACE 是 LIRO 的"几何信念化 × 规划信息化 × 审计对比化"升级：在 LIRO 的"语义流 ∘ 实时流"骨架上挂载 GBB/LSF-B（几何信念）、USL-P（探测技能）、CSP-B/EPP（信念空间探测规划）、RTP（鲁棒管道）、CCT（反事实非劣性检验）、HAD（幻觉归因）、SSB-P（歧义场景银行）、AIC-C（对比审计认证），并原位升级 WCV→WCV-B、OLP→OLP-B、OCB→OCB-P。不变式：**全部学习、探测决策、对比检验、认证只发生在语义流与低频线程；实时路径只做信念查表、信念加权融合前向、WCV-B 的 `K_eff` 并行编译、首技能展开派发**。几何不再被"信任"，而是被"检验"。

**定义 202（GBB 几何信念束）** 对点云 `P_cloud`，E_geo^B 输出 `B_g = {(g_k, w_k)}_{k=1}^K`：
- `g_k ∈ ℝ^{d_g}` 为第 k 个几何模式嵌入（`d_g=128`，K=8）；
- `w_k = softmax(a_k)`，`a_k` 为歧义头 logits；
- 信念熵 `H(B_g) = −Σ_k w_k log w_k`，最大权重 `w_max = max_k w_k`；
- **覆盖校准**：在留出场景集上取非一致性分数 `s(O) = min_k ‖g_k(O) − g*(O)‖`（或其物理投影 `min_k ‖φ̂_0^k − φ*‖`），split-conformal 取 `q_{1−α_b}`；若新样本 `s(O) > q_{1−α_b}`，触发开集扩束（加入 SSB-P 最近邻模式或局部优化新模式）。保证 `P[g* ∈ B_g] ≥ 1−α_b`（在可交换性下）。
- 若点云缺失：`B_g = {(0, 1)}`，`H(B_g)=1`（最大歧义），`geo_degraded=True`。

**定义 203（LSF-B 多假设几何融合）** 共享 3D 骨干（ResNet3D-18，冻结）+ `K` 个模式头 + 1 个歧义头：
`B_g = E_geo^B(P_cloud)`；`x' = Σ_k w_k·CrossAttn(x, g_k, g_k)`，`x'∈ℝ^{d_us'}`（d_us'=384）。歧义信号 `amb = (H(B_g), w_max)` 同时喂入 EPP（决定探测需求）、WCV-B（决定是否放宽半径）、AIC-C（决定覆盖声明）。E_geo^B 离线训练：多假设 WTA 重构损失 + 歧义头温度标定 + conformal 覆盖校准；部署后骨干冻结，仅 CrossAttn 投影矩阵参与 OLP-B 在线更新。

**定义 204（USL-P 探测技能库）** `USL-P = USL ∪ {σ_probe}`。探测原语集合（均可逆、低力、力控安全）：
- `tap`：法向轻触（0.5 N），用于判定接触面法向符号与是否存在表面；
- `press_slow`：法向缓慢加载（0→1 N，200 ms），用于估计接触刚度与法向；
- `swipe`：切向侧滑（0.5 N，短行程），用于估计摩擦锥与切向柔顺；
- `edge_trace`：沿候选边缘低速跟踪，用于区分曲率正负与边缘拓扑；
- `lift_test`：2 mm 微抬升，用于验证抓取是否建立（抓取后信息确认）。
每个 `σ_probe = (name, pre, eff_info, π_σ, cost, reversible=True)`，`eff_info` 定义为 `H(B_g) − H(B_g | y)`；观测模型 `y = h_probe(φ*) + ε_probe`，似然 `p(y|g_k)` 用于 BelUpdate。承诺类技能（grasp/insert/hand_over）标注 `irreversible=True`。

**定义 205（CSP-B 信念空间技能规划）** 给定目标谓词 `G`（DMS 解析），搜索 `τ=[σ_1,...,σ_H]`、`θ_bind=[θ_1,...,θ_H]`：
- 硬约束：`pre_σ1(B_g, x')`；`∀i<H, eff_σi ⊨ pre_σ{i+1}`；`eff_σH ⊨ G`；
- 鲁棒可行：`∀i, π_σi(·;θ_i) ∈ 𝒫_feas^B(B_g) = {π: ∀g_k∈B_g, ∀φ∈B(φ̂_0^k,r_k), ERTC ∧ pre ∧ ρ_k ≥ 0}`；
- 准入门：若 `σ_i` 为不可逆技能，则须 `CCT(τ_{1:i}, B_g) = commit`；
- 软目标：`Σ cost + λ_s·switch ≤ budget`；
- 求解：belief-A* 高层 + L-BFGS 低层（pre/eff 软化为 hinge，EIG 作为负代价项）；anytime，超时回退 `safe_idle`。实时只展开首技能。

**定义 206（EPP 认知探测路径规划）** 
`τ* = argmin_τ [ Σ_t cost(σ_t) + λ_r·CVaR_ε(risk(τ; B_g)) − λ_I·EIG(τ) + λ_s·switch(τ) ]`，约束 `τ ∈ CSP-B` 可行集。
- `risk(τ; B_g) = max_k risk_k(τ)`，`CVaR_ε` 取 worst-ε 尾均值；
- `EIG(τ) = I(B_g; Y_τ)`，用 Monte Carlo 估计：`EIG ≈ H(B_g) − (1/M)Σ_m H(B_g | y^{(m)})`，`y^{(m)}` 由 `p(y|g_k)` 采样；
- **探测插入规则**：在信念熵高且下一技能不可逆的路径位置插入探测前缀；探针选择用贪心最大化边际 EIG/代价，因 `EIG` 在给定几何下条件独立观测时是**单调子模**，贪心达 `(1−1/e)` 近似；
- 规划器：anytime belief-A*/MCTS，启发式 = 任务代价下界 + 风险下界（可采纳）；`λ_I` 由 OCB-P 预算档位决定。

**定义 207（RTP 鲁棒管道路径）** 给定名义路径 `ξ: [0,1] → 𝒳`，管道半径
`ρ_tube(s) = Q_{1−α_b}(‖Proj_n(φ*(s) − φ̂_0(s))‖)`（沿接触法向/切向投影的几何误差分位数）。
验证：`∀g_k∈B_g, ∀δ∈Tube(ρ_tube): friction_cone(f, n, μ_k) ∧ collision_free(ξ+δ) ∧ ‖τ_ext‖ ≤ τ_max`。
- 若验证失败：先缩管道（步长减半，管道 MPC 式），仍失败则在最大歧义位置插入探测；
- 管道鲁棒正不变：若 `Tube_{t+1} ⊆ Tube_t` 在束内最坏转移下成立，则沿路径递归安全；
- 输出 `tube_hash` 写入 `J_pace`，供审计复现。

**定义 208（CCT 反事实对比检验）** 对候选计划 `τ`（处理 T）与保守兜底 `π_0 = safe_idle/K_baseline`（对照 C）：
- 配对执行/仿真：同一初始位姿、同一随机种子 `seed`、同一噪声序列，对每个 `g_k ∈ B_g` 得裕度 `m_k`；对照组得 `m_0`；
- 配对差 `d_k = m_k − m_0`，检验 `H_0: min_k m_k < −δ_n` vs `H_1: min_k m_k ≥ −δ_n`；
- 对每个 k 做单侧配对 bootstrap（BCa，10k）得下置信界 `L_k`，Holm 校正族错误率 `α_cct`；
- **准入规则**：`commit` 当且仅当 `∀k, L_k ≥ −δ_n` 且 `p_max < α_cct`；否则返回 `probe`（插探测）或 `retreat`（兜底）；
- 若各假设下预测分歧过大（`max_k m_k − min_k m_k > Δ_model`），视为模型不可信，**不采信仿真结论，直接走真实探测**。

**定义 209（HAD 幻觉归因检测）** 执行后得残差 `r_obs = τ_ext^obs − τ_pred`（6 维力/力矩或任务空间误差）：
- 每个假设下预测残差 `r_obs | g_k ~ N(μ_k, Σ_k)`，马氏距离 `d_k`；
- 阈值 `τ_conf` 由标称残差的 split-conformal 分位数给出（虚警 ≤ `α_h`）；
- 若 `min_k d_k > τ_conf`：`hallucination=True`，归因 `k* = argmin_k d_k`；若所有 `d_k` 都极大，则"无假设可解释"，归因为**开集新几何**；
- 触发：`BelUpdate` 降权/扩束；`SSB-P` 创建带 `amb_sig` 的新场景；`J_pace.hallucination_flag=True`；必要时 `ask_clarify`/安全撤退。

**定义 210（WCV-B 信念鲁棒编译）** 对 `B_g` 中 `w_k ≥ w_min` 的每个假设：
- 球心 `φ̂_0^k = GeoInit(g_k)`，半径 `r_k = r_base·γ_geo(g_k)`；
- 在 `B(φ̂_0^k, r_k) ∩ 𝒢_k` 上做 CVaR 最坏搜索，得 `K_safe^k, ρ_rob^k`；
- 束级：`ρ_rob^B = min_k ρ_rob^k`，`K_safe^B = ∩_k K_safe^k`；
- 跳过质量 `Σ_{w_k<w_min} w_k` 若超过 `α_b`，**禁止跳过**（否则覆盖声明失效）；若任一假设可行集为空或 `ρ_k<0`，路由 EPP 探测或兜底。
- **关键差异**：第 63 轮在单球 `B(φ̂_0, r_0)` 上最坏搜索；PACE 在**假设束的并集**上取最坏，`r` 不再是"盲人摸象"的自信半径，而是随 `H(B_g)` 诚实放大。

**定义 211（OLP-B 歧义感知在线投影）** 
`W_{t+1} = P_𝒲(W_t − η_t·ω_t·∇_W ℓ̃_t)`，`ω_t = min(1/exp(−β·H(B_g)), ω_max)·𝟙[agreement]`（逆倾向加权，`ω_max=10`，避免高歧义样本主导，同时不引入选择偏差）。
- 几何相关子块（CrossAttn 投影）仅在 `H(B_g) ≤ H_max` 且 `w_max ≥ 0.6` 时更新；
- 任务相关子块照常更新；
- 遗憾界：记歧义样本占比 `q`、重要性权重二阶矩 `ν`，则 `R_T^skill ≤ D_skill·G̃_skill·√(ν·T)`；当 `q→1`（长期歧义）时退回 LIRO 的 `√T` 界，但**不会从幻觉中学到"自信的错误"**。

**定义 212（SSB-P 空间-歧义场景银行）** 扩展 SSB：
- `scene_sig = (V_sig, T_sig, fp_cloud, φ_sig, dyn_annot, amb_sig, probe_log)`；
- `amb_sig = (H(B_g), w_max, mode_hist)`；`probe_log` 记录每次探测的原语、观测、熵降 `ΔH`、时间；
- `Mine`：先按 `fp_cloud` 汉明距离 < 8 检索，再按 `amb_sig` 余弦相似度做二级匹配；同一点云指纹但不同 `amb_sig` 视为"同场景不同几何解释"，单独成簇（这正是幻觉高发区）；
- `Mut`：继承第 63 轮几何变异，新增① 歧义保持变异（保持 `H` 与 `mode_hist`，仅扰动低权重模式）；② 歧义翻转变异（法向/曲率符号翻转，强制生成"相反解释"）；③ 探测可分辨性变异（让两个假设在探测观测上更接近，压测 EIG 的有效性）。
- 所有险情/幻觉/探测修正均 100% 记账；簇数封顶 64。

**定义 213（AIC-C 对比审计认证器）** 
`J_dir^C = (ρ_dir^B, ℰ_spec, cct_p, coverage_est, cert_hash)`：
- `ρ_dir^B = min_{η∈ℰ} min_{k} min_t margin(π_σt(·;η), B_g)`（四类干扰继承第 63 轮 ℰ；新增几何假设维度）；
- `cct_p` 为定义 208 的 Holm 校正后最大 p 值；
- `coverage_est` 为 GBB 的 conformal 经验覆盖率（滚动窗口）；
- 认证有效条件：`ρ_dir^B ≥ 0 ∧ coverage_est ≥ 1−α_b ∧ cct_p < α_cct`（若存在不可逆动作）。

**定义 214（J_pace 扩展证书）** 
`J_pace = (J_liro, belief_ver, K_eff, coverage_est, probe_plan_hash, cct_p, hallucination_flag, tube_hash, amb_sig)`。
验证规则：`Valid(J_pace) ⇔ Valid(J_liro) ∧ coverage_est ≥ 1−α_b ∧ (cct_p < α_cct ∨ 无不可逆动作) ∧ ¬unresolved_hallucination ∧ tube_hash 有效`。
审计链：`belief_ver` 追溯几何信念版本；`probe_plan_hash` 追溯探测路径；`cct_p` 追溯对比检验；`hallucination_flag` 追溯是否发生归因修正；`tube_hash` 追溯鲁棒管道。

**定义 215（BelUpdate 信念更新算子）** 给定探测观测 `y_probe` 与执行残差 `r_obs`：
- 贝叶斯更新：`w_k^+ ∝ w_k·p(y_probe | g_k)·p(r_obs | g_k)`，归一化；
- 若某模式权重跌破 `w_min`，合并/淘汰；若 `min_k d_k > τ_conf`，开集新增 `g_new`（SSB-P 最近邻初始化 + 局部优化 `min_g d(g; r_obs)`），权重 `w_new = α_b/K` 与旧权重混合；
- 熵变化 `ΔH = H(B_g) − H(B_g^+)` 记入 `probe_log`，作为 EPP 的在线信息模型校准信号；
- 定期（每 100 步或覆盖率下降 > 0.05）重跑 conformal 校准，更新 `q_{1−α_b}`；
- 若连续 `L` 次更新仍 `H(B_g) > H_max`，标记 `persistent_ambiguity`，强制保守模式（只执行可逆技能 + ask_human）。

**定义 216（CEP 对比实验协议）** 离线评估协议：
- **处理**：PACE（GBB+EPP+CCT 全开）；**对照**：第 63 轮 LIRO；**消融**：2³ 因子（GBB/EPP/CCT on/off，共 8 组）；
- **设计**：配对随机区组。区组 = 几何歧义分层（低 `H<0.3` / 中 `0.3≤H<0.7` / 高 `H≥0.7`）；每区内处理/对照顺序随机（消除顺序效应），同初始位姿、同随机种子、同算力预算、同训练数据；
- **估计量**：`ATE = E[Y(T) − Y(C)]`；按区组的 `CATE(stratum)`；主终点=任务成功率与约束违规率，次终点=完成时间、能耗、探测次数、幻觉检测延迟；
- **推断**：配对 bootstrap（BCa，10k）95% CI；非劣性检验（margin `δ=5%`）；"不更差"用 TOST 等价检验；10 项实验用 Holm-Bonferroni 控制 FWER；报告 Cohen's `d_z` 效应量；
- **证伪阈值**（预注册）：CCT type-I > 10% 或 HAD AUROC < 0.8 或 GBB 覆盖率 < 90% ⇒ 拒绝 PACE 主张；
- **可复现**：所有随机种子、配置、失败运行全量归档；预注册主/次终点，禁止事后挑选。

class BeliefGeometryFusion:
    """多假设几何编码 + 信念加权跨模态融合。前半 < 0.4ms，融合 < 0.2ms。"""
    def __init__(self, d_us=256, d_g=128, d_out=384, K=8, voxel=32):
        self.K = K
        self.voxelize = DifferentiableVoxelize(voxel)
        self.backbone = FrozenResNet3D18(out_dim=256)          # 冻结共享骨干
        self.mode_heads = nn.ModuleList([nn.Linear(256, d_g) for _ in range(K)])
        self.amb_head = nn.Linear(256, K)                      # 歧义 logits
        self.cross_attn = CrossAttention(d_us, d_g, d_out, heads=4)
        self.q_conf = None                                     # conformal 阈值（离线校准）
        self.g_cache, self.w_cache = None, None

    def update_geometry(self, P_cloud):
        if P_cloud is None:
            self.g_cache, self.w_cache = torch.zeros(self.K, 128), None
            return GeometricBelief.zero(self.K)                # geo_degraded
        h = self.backbone(self.voxelize(P_cloud))
        gs = torch.stack([head(h) for head in self.mode_heads])  # (K, d_g)
        w = torch.softmax(self.amb_head(h), dim=-1)             # (K,)
        B_g = GeometricBelief(gs, w, entropy(w))
        if self.q_conf is not None and B_g.nonconformity() > self.q_conf:
            B_g = B_g.open_set_expand()                        # 触发扩束
        self.g_cache, self.w_cache = gs, w
        return B_g

    def fuse(self, x, B_g):
        xp = sum(w * self.cross_attn(x.unsqueeze(0),
                                     g.unsqueeze(0), g.unsqueeze(0))
                 for g, w in zip(B_g.gs, B_g.ws)).squeeze(0)
        return xp                                               # (d_out,)
```

class ProbeSkill(Skill):

    irreversible = False

        self.direction, self.info_target, self.cost = direction, info_target, cost

            post_H.append(B_g.posterior(y, self.likelihood).entropy())

class BeliefSkillPlanner:
    """信念空间 anytime A* + 探测前缀贪心插入。语义流 < 40ms。"""
    def __init__(self, usl_p, max_horizon=6, lambda_I=1.0, lambda_r=2.0,
                 lambda_s=0.5, delta_n=0.05):
        self.usl_p, self.H = usl_p, max_horizon
        self.lambda_I, self.lambda_r = lambda_I, lambda_r
        self.lambda_s, self.delta_n = lambda_s, delta_n

    def plan(self, goal, xp, B_g, budget=100.0):
        feasible = [s for s in self.usl_p.skills
                    if s.robust_feasible(B_g, xp)]
        open_set = [(0.0, 'start', [], [])]     # (f, curr, seq, theta)
        best, best_f = None, float('inf')
        while open_set and time_left() > 5e-3:
            f, curr, seq, thetas = heapq.heappop(open_set)
            if goal.holds(seq[-1].eff if seq else None, B_g, xp):
                cand = self._opt_params(seq, xp, B_g)
                tau = self.insert_probes(seq, B_g, xp)          # EPP 前缀
                return tau, cand
            if len(seq) >= self.H:
                continue
            for nxt in self.usl_p.successors(curr):
                if nxt not in feasible:
                    continue
                if nxt.irreversible:
                    gate = CCT().gate(seq + [nxt], B_g, FALLBACK_MARGIN,
                                      self.delta_n)
                    if gate != 'commit':
                        nxt = PROBES[best_probe_for(nxt, B_g)]   # 先探测
                eig = nxt.information_gain(B_g, xp) if nxt.reversible else 0.0
                risk = cvar_risk(seq + [nxt], B_g)
                step = (nxt.cost + self.lambda_s * (seq and seq[-1].name != nxt.name)
                        + self.lambda_r * risk - self.lambda_I * eig)
                heapq.heappush(open_set, (f + step, nxt, seq + [nxt], thetas))
        return [self.usl_p.skills['safe_idle']], [None]

    def insert_probes(self, seq, B_g, xp):
        """在不可逆技能前贪心插入探测，直到边际 EIG/代价低于阈值。"""
        out = []
        for i, s in enumerate(seq):
            if s.irreversible and B_g.entropy() > H_AMB:
                while True:
                    cands = [p for p in PROBES.values() if p.pre(B_g, xp)]
                    if not cands:
                        break
                    gains = [(p.information_gain(B_g, xp) / p.cost, p)
                             for p in cands]
                    g_best, p_best = max(gains, key=lambda z: z[0])
                    if self.lambda_I * g_best < PROBE_THRESH:
                        break
                    out.append(p_best)
                    B_g = B_g.simulate_probe(p_best)             # 规划期近似
            out.append(s)
        return out
```

### IP-208 CCT 反事实对比检验

```python
class CounterfactualComparativeTest:
    def __init__(self, n_boot=10000, delta_n=0.05, alpha=0.05):
        self.n_boot, self.delta_n, self.alpha = n_boot, delta_n, alpha

    def gate(self, tau, B_g, fallback_margin, seed):
        diffs, margins = [], []
        for g_k in B_g.gs:
            m_k = paired_rollout(tau, g_k, seed=seed).margin   # 同种子配对
            margins.append(m_k)
            diffs.append(m_k - fallback_margin)
        if max(margins) - min(margins) > DELTA_MODEL:
            return 'probe'                                     # 模型不可信
        # Holm 校正的单侧配对 bootstrap
        pvals, lowers = [], []
        for d_k in diffs:
            boot = paired_bootstrap(d_k, self.n_boot)          # BCa
            lowers.append(np.quantile(boot, self.alpha / len(diffs)))
            pvals.append(one_sided_p(d_k, -self.delta_n))
        p_holm = holm(max(pvals for _ in [0]), pvals, self.alpha)
        if all(L >= -self.delta_n for L in lowers) and p_holm < self.alpha:
            return 'commit'
        return 'probe'
```

## 4. 推导

**引理 5（信念覆盖 ⇒ 承诺安全）** 设 GBB 满足 `P[g* ∈ B_g] ≥ 1−α_b`（conformal 校准误差 `ε_cal`），且对每个 `g_k∈B_g`，WCV-B 编译的计划裕度 `ρ_k ≥ 0`（即在该假设的真实物理下不违反 ERTC/摩擦锥/碰撞）。则一次承诺的执行不安全概率
`P[unsafe] ≤ P[g*∉B_g] + Σ_k P[g*=g_k]·P[unsafe|g_k] + ε_cal ≤ α_b + 0 + ε_cal`。
即**几何无需"猜对"，只需"覆盖 + 束内最坏安全"**。相比第 63 轮 `P[unsafe] ≤ 1[g*∉ball(φ̂_0,r_0)] + ε`，PACE 把"是否落在球内"这一不可验证事件替换为**可校准的覆盖率**。∎

**引理 6（探测的信息价值界与判据）** 设风险泛函 `R(w) = E_{g~w}[risk(g)]` 对后验 `w` 是 `L_m`-Lipschitz（w.r.t. 全变差/`W_1`）。一次探测得到 `Y`，后验 `w^+ = P(g|Y)`。由 Pinsker 与 Jensen：
`E_Y[W_1(P_{g|Y}, P_g)] ≤ √(2·I(B_g;Y))`，
故 `E_Y|R(w^+) − R(w)| ≤ L_m·√(2·I(B_g;Y))`。
探测的净收益 `Δ ≥ λ_r·L_m·√(2I) − c_probe`；当 `I(B_g;Y) > c_probe²/(2λ_r²L_m²)` 时严格为正。**这给 EPP 的 `λ_I` 一个可解释标定：`λ_I` 应设为风险敏感度与探测代价的比值。** ∎

**命题（EIG 子模性 ⇒ 探测贪心近似）** 若给定几何后各探测观测条件独立（`Y_a ⊥ Y_b | g`），则集合函数 `I(B_g; Y_S)` 关于 `S` 单调子模：边际增益随已选探测增多而递减。故在探测数量预算 `B_probe` 下，贪心选探针达到最优 EIG 的 `(1−1/e)`。∎

**定理 4（CCT 非劣性检验有效性）** 在配对可交换性（同种子、同初始条件、处理/对照仅计划不同）下，每个单侧配对检验在 `H_0` 下有效；Holm 校正控制族错误率 `≤ α_cct`。若真实最坏裕度低于兜底 `Δ > δ_n`，配对差 `d` 的 Hoeffding 界给出所需配对数
`n ≥ 2·log(2K/β)/(Δ−δ_n)²`
即可达功效 `1−β`。再与引理 5 的覆盖概率 union，承诺不安全概率 `≤ α_cct + α_b + ε_cal`。**这是"对比实验"从描述性表格升级为可执行准入证的数学依据。** ∎

**定理 5（HAD 检测率与延迟）** 设标称残差分布 `P_0` 与幻觉残差分布 `P_1` 的 KL 为 `D_KL(P_1‖P_0)`。Chernoff–Stein 引理给出 `n` 次独立观测下误判概率 `≤ exp(−n·D_KL)`；conformal 阈值 `τ_conf` 把虚警控制在 `α_h`（有限样本）。检测延迟（期望观测数）`~ log(1/β)/D_KL`。对开集新几何，HAD 的"无假设可解释"分支等价于对 `∪_k N(μ_k,Σ_k)` 的离群检验，虚警同样由 conformal 控制。∎

**定理 6（安全-代价权衡）** 设每轮承诺不安全概率 `≤ α := α_cct + α_b + ε_cal`（定理 4）。则 `T` 轮累积期望违规 `E[Σ violation] ≤ α·T + O(√(T log K))`（估计噪声与信念更新波动）。探测带来的任务代价超支
`Δcost ≤ λ_I·Σ_t EIG_t + c_probe·N_probe`；
由于 EIG 单调子模（命题），在预算 `B_probe` 下贪心使用探针，`Σ EIG ≥ (1−1/e)·OPT`，因此**安全提升的代价有显式上界**，不会退化为"无限探测"。∎

**命题（WCV-B 不会比单球更乐观）** 对任意 `B_g`、`r_k`，若 `g*∈B_g`，则 `ρ_rob^B = min_k ρ_k ≤ ρ_{k*}`，其中 `k*` 为真实几何模式。故 PACE 的鲁棒裕度是真实几何裕度的**保守下界**；第 63 轮的单球 `ρ_rob` 仅在 `g*∈ball` 时才是下界，而 PACE 把这个前提变成可校准概率。∎

**命题（OLP-B 不学幻觉）** 高歧义样本的几何子块梯度被 `ω_t≤1` 降权（IPS 无偏、截断控制方差），因此 `E[∇̂_geom] = E[ω·∇_geom] = ∇_geom`（在倾向得分正性下）。即使 E_geo 系统性幻觉，几何子块的期望更新方向不被幻觉样本主导；代价是有效样本量下降 `~ν` 倍，遗憾界相应放大 `√ν`。∎

**正确性定理（PACE-Complete）** 假设第 62 轮 A61–A76、第 63 轮 A77–A82（其中 A77 由 A83 取代）及：
- **(A83)** GBB conformal 覆盖：`P[g*∈B_g] ≥ 1−α_b`（α_b=0.05），校准误差 `ε_cal ≤ 0.01`；`δ_geo,k < δ_bias`。
- **(A84)** 探测观测模型 `p(y|g_k)` 标定良好，给定几何后各探针条件独立；探测可逆且力 ≤ `F_safe`。
- **(A85)** EPP 的 anytime 搜索返回可行路径或安全兜底；EIG 满足单调子模（A84 下）。
- **(A86)** CCT 配对可交换：同种子、同初始条件、处理/对照仅计划不同；rollout 模型在 `Δ_model` 内可信。
- **(A87)** HAD conformal 阈值有效；标称与幻觉残差分布可区分（`D_KL > 0`）。
- **(A88)** RTP 验证采样充分（16 点/管道截面 × K），且 `ρ_tube` 分位数覆盖真实几何误差。
- **(A89)** BelUpdate 满足贝叶斯一致性；开集扩束的最近邻初始化在 `SSB-P` 覆盖范围内。
- **(A90)** 实时路径新增组件总延迟 ≤ 2.1ms（典型 ≤1.6ms），零学习写操作。

则：
1. **几何不再被盲信**：承诺不安全概率 `≤ α_cct + α_b + ε_cal`（定理 4 + 引理 5）。
2. **探测有价值判据**：探测期望收益 `≥ λ_r L_m √(2I) − c_probe`，EPP 只在正收益处插探测（引理 6）。
3. **幻觉可检测、可归因**：HAD 在 `n` 次观测后误判 `≤ exp(−nD_KL)`，虚警 `≤ α_h`（定理 5）。
4. **安全-代价有界**：累积违规 `≤ αT + O(√(T log K))`，任务代价超支受 `λ_I` 与子模贪心界控制（定理 6）。
5. **认证链完整**：`Valid(J_pace)` 同时蕴含 LIRO 证书有效、信念覆盖达标、CCT 通过、无未决幻觉（定义 214）。
6. **实时性可控**：典型 `K_eff≤3` 时实时路径 `< 1.6ms`，最坏 `< 2.1ms`，继承零学习写操作。

## 7. 对比实验协议（CEP）细则

> 本节直接回应本轮灵感「对比实验」：不仅要"跑两组看谁高"，而要给出**可复现、可证伪、控制混杂**的因果比较。

**7.1 科学假设（预注册）**
- H1：GBB 覆盖率 ≥ 95%，显著优于第 63 轮单点几何的"隐式覆盖"（用 `g*∈ball` 的代理指标）。
- H2：EPP 相比 `λ_I=0` 的任务贪心，单位能量信息增益提升 ≥ 2×，且成功率非劣。
- H3：CCT 在 `α_cct=0.05` 下 type-I ≤ 5%，power ≥ 80%。
- H4：HAD 在透明/镜面/遮挡集上 AUROC ≥ 0.90。
- H5：PACE 相对 LIRO 的成功率提升 ≥ 30%，灾难违规为 0（配对非劣性反向检验）。
- H6：探测带来的时间开销 ≤ 20%（非劣性上界）。
- 证伪：任一主假设在 Holm 校正后不成立，则拒绝对应主张（不做事后挑选）。

**7.2 设计**
- **配对随机区组**：区组按 GBB 歧义分层（低/中/高），每区组内对同一场景生成处理 PACE 与对照 LIRO；随机化执行顺序以消除学习/磨损效应。
- **控制变量**：同初始位姿、同随机种子、同噪声序列、同训练数据、同算力预算（对照若少探测，则用等价算力做多次重规划，避免"多算即赢"）。
- **因子消融**：`2³` 设计（GBB on/off × EPP on/off × CCT on/off = 8 组），估计主效应与交互；混合效应模型 `Y ~ treat + GBB*EPP*CCT + (1|scene)`。
- **盲评**：成功/违规由独立脚本判定，避免人工主观；幻觉归因由独立标注者双盲复核。

**7.3 估计量与推断**
- `ATE = E[Y(T) − Y(C)]`；`CATE(s) = E[Y(T) − Y(C) | stratum=s]`；配对差 `d_i`。
- 配对 bootstrap（BCa，10k）95% CI；非劣性 margin `δ=5%`；"不更差"用 TOST（`p<0.05` 且 CI 落在 `±δ`）。
- 10 项实验做 Holm-Bonferroni；报告 `d_z`、CI、`p`、`N`、所有失败运行；预注册链接入档。
- **敏感性分析**：E-value 评估未观测混杂；对种子/场景做 leave-one-scene-out 稳健性检查。

**7.4 与"对比实验"名字的呼应**
- 每一轮在线 CCT 都是一次**微型配对实验**（处理=当前计划，对照=兜底），因此离线 CEP 与在线 CCT 共享同一估计量语言；
- `J_pace.cct_p` 即在线实验的 p 值，可被审计；
- 离线 CEP 的证伪阈值反过来校准在线 `α_cct` 与 `δ_n`，避免"在线检验过松"。

## 9. 已知风险

**一句话（本轮最大风险）**：若假设束 `B_g` 的支撑集遗漏真实几何（bundle misspecification），或用于 CCT 的预测模型与 E_geo 共享同一幻觉偏置（**共模误差**），那么 CCT 会在"自洽的错误世界"里给出高置信度的非劣性认证——**对比实验从"识别幻觉"退化为"合法化幻觉"**，这是本轮所有"探测-审计"论证共同依赖的新的单点假设（A83/A86）。

**次级风险与缓解**：
1. **探测本身不安全**：探测需接触未知表面，可能触发不稳定/易碎物体 → 力上限硬约束（`F_safe`）、可逆性验证、力/位混合的被动柔顺、探测前视觉-触觉一致性预检。
2. **假设束爆炸**：K 增大导致实时编译变慢 → `K_eff` 权重剪枝 + 分层束（粗模式 4 + 细模式按需展开）+ 跳过质量 > α_b 时禁止剪枝。
3. **CCT 的仿真-现实差距**：rollout 模型偏差使对比结论失真 → `Δ_model` 分歧检测 + 真实探测优先 + 在线用执行数据校准模型 + 定期"已知安全"对照校准。
4. **EIG 估计方差大**：MC 估计噪声导致探测决策抖动 → 增加 MC 样本 + 控制变量/共同随机数 + 对 EIG 做下限置信（悲观规划）。
5. **HAD 误报导致过度保守**：把执行噪声误判为幻觉 → conformal 阈值 + 连续 L 次一致才升级 + 人工复核通道 + 误报代价入 OCB-P 奖励。
6. **对比实验多重比较与 p-hacking**：→ 预注册、Holm 校正、全量归档、独立复现、E-value 敏感性分析。
7. **OLP-B 的 IPS 方差**：逆倾向权重截断引入偏差 → 用自归一化 IPS + 双重稳健估计 + 监控几何子块梯度范数。
