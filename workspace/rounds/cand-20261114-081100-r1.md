# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS」IP-287~294；新灵感循环第 1 轮；本轮灵感：「自监督学习」×「域随机化」）

> R72 把 GAUGE 从「认知层算法」下沉为「具身实时系统」：REG 调度契约、意图隐变量 z、灵巧手接触模式 c、三层反作用与 S2R-UQ 桥接，并确立了「安全侧只增不减、逐指令退化」的姿态。但 R72 有两根**没有写进契约的拐杖**：
> - **标定拐杖（标签依赖）**：SEAL 审计集、ECE_intent、接触模式校准、S2R 残差 Δ，全都默认「有人类标签/已标定数据」。在开放世界里，标签稀缺、长尾、昂贵；而**分布漂移是开放式的**，你无法预先标好一个「未来」。
> - **仿真拐杖（分布给定）**：域随机化分布 P_φ 与残差 Δ 被当作「已知输入」。但**谁设计了 P_φ？怎么知道它覆盖了真实？** 如果 P_φ 只覆盖了「我们想得到的扰动」，那么 S2R-UQ 的 u_sim 就是一个漂亮但无效的数字。
>
> 本轮两个灵感正好补这两根拐杖，且它们天然对偶：
> - **自监督学习（SSL）**：从**无标签**的真实数据流中学习表示与不变量。SSL 的关键是「什么变换应该不变」——这恰恰就是计量学里的 **gauge（规范）**：对 nuisance 不变，对 semantic 敏感。但 SSL 的损失函数**不知道**自己把哪一类变换错分成了 nuisance；正负样本构造错了，loss 照样下降。于是「学到的规范」可能是**假的**：要么欠不变（nuisance 泄漏），要么过不变（语义坍缩）。
> - **域随机化（DR）**：在仿真里**随机化环境参数**，制造大量带真值的「反事实」。DR 的真正价值不是「数据增广」，而是**它提供了真实世界无法提供的干预**：在仿真里可以固定 y、只改 nuisance（测试不变性），也可以固定 nuisance、只改 y（测试语义敏感性）。但 DR 也不是免费午餐：随机化错了轴（把任务相关信息随机掉）= **信息销毁**；只覆盖想得到的扰动 = **覆盖幻觉**。
>
> 核心命题：**不再问「我能不要标签吗」，而问「我用哪些可以被审计的假设去替换标签？」**。R72 的测量链是「标签校准的」；R73 要把它变成「**自监督学表示、域随机化造干预、稀疏锚点钉绝对标尺**」的**可审计三角**——**SELF-GAUGE-RAS**（Self-supervised, Environment-randomized, Label-sparse, Foundation-anchored GAUGE for RAS；自监督 × 域随机化 × 稀疏锚点的可审计计量闭环）。
>
> 一句话立场：**自监督不是「免费的监督」，而是「把监督从标签转移到假设」；域随机化不是「更多数据」，而是「可控的干预」。审计的成败，取决于这些假设本身能否被独立审计。**

## 0. 直觉与动机

**灵感 1（自监督学习 → 数据增强就是规范群，正负样本就是规范声明）**
直觉：对比学习里，`f(x)` 与 `f(augment(x))` 被拉近，`f(x)` 与 `f(另一张图)` 被推远。**「哪些变换算同一个东西」不是训练出来的，是人事先声明的**。你声明「光照/纹理/相机位姿是 nuisance」，网络就学会对它们不变；你声明「物体身份/接触模式/人的意图是 semantic」，网络就应当对它们敏感。因此 **augmentation 集合 𝒢 就是测量系统的 gauge group**，而 `ι = E d(f(x), f(gx))` 正是 R71/R72 一直在用的「gauge 不变性间隙」的**可计算版本**。问题在于：训练损失对「𝒢 声明错了」完全无感。把「滑移」误当 nuisance，网络会对滑移不变——于是它**看不见滑移**，而不是「学会了忽略滑移的噪声」。**自监督的自信来自一致性，但一致性可能是对一个错误规范的完美服从。**

**灵感 2（域随机化 → 不是数据增广，而是反事实干预发生器）**
直觉：真实世界里你没法把「红色杯子」瞬间变成「蓝色杯子」而保持其他一切不变；仿真里可以。所以 DR 的核心资产是**带真值的干预对** `(x, do(a))`，而不是样本量。用这些干预对，才能审计 SSL 的不变性：**固定 y、扰 nuisance** 应不变（否则欠不变）；**固定 nuisance、变 y** 应敏感（否则过不变/坍缩）。但 DR 有两个反向风险：其一，**覆盖幻觉**——P_φ 只覆盖工程师想得到的扰动，真实世界的长尾在支撑集之外，u_sim 系统性低估；其二，**信息销毁**——把任务真正依赖的参数（如物体质量、接触刚度）也随机化，策略会学会「忽略质量」，在真实任务里就失效。**随机化轴选错，等于主动教模型变瞎。**

**灵感 3（对偶：SSL 学规范，DR 造干预，锚点钉标尺——标定三角）**
直觉：三者单独都不成立：
- **只有 SSL**：不变性无法验证（没有反事实真值），可能把语义当 nuisance 学没了；
- **只有 DR**：覆盖无法验证（仿真真值不等于真实真值），可能自娱自乐；
- **只有锚点**：标签太少，学不了表示，但**足够校准**。
把它们拼成一个三角：
- **边 E1（覆盖）**：随机化仿真分布 P_φ 覆盖真实分布 P_real；
- **边 E2（不变性迁移）**：SSL 在仿真/多模态上学到的规范，在真实无标签流上仍然成立；
- **边 E3（锚点校准）**：用少量真实锚点做保形校准，给出有限样本覆盖保证。
三条边同时成立，才允许把「自监督数字」升级为「计量数字」。**标签没有被消灭，只是被压缩成 O(log(1/δ)/ε²) 个锚点。**

**灵感 4（最深的陷阱：自证计量与元级 Goodhart）**
直觉：如果 ADR-G 用**被审计的那套 SSL 特征**去选择随机化分布，再用这个分布去生成审计集，再用同一批锚点做校准——三条边会**互相迎合、同时「通过」**。这不是普通的过拟合，而是**审计闭环的自证**：模型不仅拟合数据，还拟合了「审计它的那把尺子」。R71 说「自信地错自己的认知」，R72 说「自信地错自己的可执行性」，R73 必须直面：**自信地错自己的可审计性**。因此本轮把「审计独立性」提升为一等公民（SEAL-ANCHOR）：锚点必须与模型选择历史**统计独立**，且要能检测「DR 支撑集被选择偏差裁剪」这种结构性作弊。

**灵感 5（标签复杂度：不是免费，而是维度无关）**
直觉：表示学习需要的是**数据**，校准需要的是**覆盖**。保形预测的 DKW 界告诉你，要把覆盖率误差压到 ε、失败概率压到 δ，只需要 `n = ⌈log(2/δ)/(2ε²)⌉` 个独立锚点——**与表示维度无关**。所以「label-sparse」是可以严格量化的：SSL 省掉的是「表示层的标签」，锚点承担的是「绝对标尺」。任何声称「完全零标签且仍然可审计」的方案，都在偷偷使用某个更强的假设（同分布、增强正确、仿真正确）。

## 1. 形式化定义（增量：定义 366–385）

**定义 366（标定三角 LCT）** 记三个数据源：真实无标签流 P_U、随机化仿真 P_S(φ)（带真值与可干预性）、真实锚点集 P_A（少量标签）。标定三角 LCT = (P_U, P_S, P_A, E1, E2, E3, Ind)，三条边与一条独立性约束：
- **E1 覆盖**：`κ(P_S, P_real) ≤ ε_cov`（定义 371）；
- **E2 不变性迁移**：仿真上通过的双侧规范证书（定义 367）在真实流上的间隙 `Δ_ι ≤ ε_transfer`；
- **E3 锚点校准**：在 P_A 上做保形校准，有限样本覆盖 `≥ 1−α`（定义 369）；
- **Ind 审计独立**：`P_A ⟂ (模型选择历史, φ 选择历史, 特征选择历史)`，泄漏量 `Λ ≤ τ_Λ`（定义 375）。
**LCT 有效 ⇔ E1 ∧ E2 ∧ E3 ∧ Ind 全部成立。** 缺任一边，对应能力严格退化（定义 381）。

**定义 367（双侧规范证书 GGAUGE）** 设规范群 𝒢 = {g_θ}（nuisance 变换：光照、纹理、相机位姿、传感器噪声…），语义群 𝒮（改变任务标签的变换：物体身份、意图类别、接触模式）。编码器 f: 𝒳→𝒵，度量 d。定义
- **欠不变间隙**：`ι_under(f,𝒢) = E_{x~P, g~𝒢} d(f(x), f(gx))`；
- **语义敏感度**：`σ_sem(f,𝒮) = inf_{s∈𝒮} E_{x~P} d(f(x), f(sx))`；
- **表示充分性**：存在预测器 h，使 `Risk(h∘f) ≤ ε_suff`（在仿真真值+锚点上估计）。
**双侧证书 G(f) 有效 ⇔ `ι_under ≤ ε_i` ∧ `σ_sem ≥ δ_s` ∧ `Risk ≤ ε_suff`。** 单侧证书（只压 ι）恰恰会奖励坍缩：常值编码器 ι=0、σ=0。**不变性与语义敏感性必须同时被约束，缺一即为退化解。**

**定义 368（反事实短路扫描 SHORTCUT-SCAN）** 对每个候选属性轴 a，用 DR 生成两类干预对：
- **y-保持干预** `x → x_{a←a'}`（只改 a，标签不变）：`CS_a^⊥ = E d(p̂(y|x), p̂(y|x_{a←a'}))`；
- **y-改变干预** `x → x_{a←a*}`（改 a 且标签改变）：`CS_a^∥ = E d(p̂(y|x), p̂(y|x_{a←a*}))`。
**轴 a 被判为短路 ⇔ `CS_a^⊥ > τ_sh`**（对不该影响预测的属性过度敏感）；**语义轴失效 ⇔ `CS_a^∥ < τ_sem`**。SHORTCUT-SCAN 输出短路谱 `{(a, CS_a^⊥, CS_a^∥)}`。**关键：只有仿真能提供「只改 a 而保持 y」的干预，这就是 DR 与 SSL 的对偶价值。**

**定义 369（自监督保形校准 SCAL）** 设一致性分数 `s(x,y)`（由 SSL 表示 + 少量锚点上的线性探针/距离给出，越大越不像）。在独立锚点集 `D_cal={(x_i,y_i)}_{i=1}^n` 上定义保形 p 值
`p(x,y) = (1 + Σ_i 𝟙[s(x_i,y_i) ≥ s(x,y)]) / (n+1)`，
预测集 `C_α(x) = {y : p(x,y) ≥ α}`。交换性下 `P(Y∈C_α(X)) ≥ 1−α`。协变量漂移已知密度比 `w(x)=dP_real/dP_cal` 时用**加权保形**；漂移未知时用 **ACI**：`α_{t+1} = α_t + γ(α − err_t)`，`err_t = 𝟙[Y_t∉C_t]`，维护长程覆盖率。**SCAL 只把「自监督分数」当排序信号，绝不把其原始数值当概率。**

**定义 370（锚点预算 ANCHOR-BUDGET）** 要在覆盖率上以精度 ε、置信 1−δ 成立（DKW），所需独立锚点数
`n_anchor(ε,δ) = ⌈ log(2/δ) / (2ε²) ⌉`。
**性质**：n 与表示维度、状态维度无关；因此「标签成本」随目标精度平方反比增长，而不是随模型规模增长。**锚点少≠假设少：省下的标签必须由 E1/E2 的假设来偿还。**

**定义 371（域随机化覆盖证书 DRC）** 随机化分布 P_φ 诱导参数 θ~P_φ。对任一下游统计量 T（风险、位姿误差、接触状态、残差）定义
- **分布覆盖间隙**：`κ(φ) = sup_t |F_{P_S(φ)}(t) − F_{P_real}(t)|`（KS 距离，用锚点/无标签分位数估计并给置信带）；
- **支撑覆盖**：对锚点 a 计算其在 P_S(φ) 下的保形 p 值，要求 `P_{a~P_A}[p_φ(a) ≥ α] ≥ 1−ε_sup`；
- **保守度预算**：`V(φ) = Var_{θ~P_φ}[T(θ)] ≤ V_max`（防止把一切随机化到无信息）。
**DRC 有效 ⇔ `κ ≤ ε_cov` ∧ 支撑覆盖成立 ∧ `V ≤ V_max`。** 注意第三项：**覆盖越大越安全，但也越无能；DR 必须同时被「覆盖」和「保守度」双向约束。**

**定义 372（审计驱动的自适应随机化 ADR-G）** 在每个离线/回合间迭代：
`φ_{k+1} = argmin_φ [ E_{θ~P_φ} Risk + ρ·κ̂(φ) + μ·V(φ) ]`
s.t. `κ(φ) ≤ ε_cov`、`V(φ) ≤ V_max`、**支撑轴 ⊆ 𝒜_causal**（只允许随机化经计量先验确认的 nuisance 轴，禁止随机化任务相关轴）。
其中 `κ̂` 来自 DRC；未覆盖的真实样态由**对抗搜索**（找一个真实但落在 P_φ 尾部的环境）加入下一轮随机化。**ADR-G 不是「自动调参」，而是「在因果轴约束下的覆盖-效用前沿上找拐点」。**

**定义 373（跨模态自监督 sim2real 残差 CMS2R）** 模态 m ∈ {vision, touch, proprio, language}，编码器 h_m。物理状态一致性残差
`r_{ij} = d(h_i(m_i), h_j(m_j))`。
仿真给出参考分布 `P_S(r_{ij})`；真实无标签流给出 `P_real(r_{ij})`；残差漂移
`Δ_{ij} = OT(P_real(r_{ij}), P_S(r_{ij}))`（或分位数差/保形间隙）。
**可辨识性条件**：至少存在一个**锚模态**（传感器模型经外部标定的模态，如力/力矩），否则多模态可以「一起错」——**共模失效**。定义共模可辨识指标 `ρ_cm = 1 − min_i Corr(残差_i, 锚模态残差)`，要求 `ρ_cm ≥ ρ_min`。
**CMS2R 只估计残差分布，不声称消除残差；它把 Δ 送入 R72 的 S2R-UQ 链，替换「必须有实机标签」的步骤。**

**定义 374（不确定度洗白防护 LAUNDER-GUARD）** 设 `c_SSL` 为自监督置信（如 1−归一化模态分歧）。**规则**：
`u_eff = u_cal + (1−ρ_audit)·u_penalty`，其中 `u_cal` 是经 SCAL 校准的保形不确定度，`ρ_audit ∈ [0,1]` 是锚点审计通过率。
- 若 `ρ_audit ≥ ρ_min`：`c_SSL` 仅可作**排序信号**进入 `u_cal` 的构造，不可直接缩放 λ；
- 若 `ρ_audit < ρ_min`：`c_SSL` **完全惰性**（`u_penalty = u_cap`），λ 不得因其下降而软化。
**定义洗白**：把未校准的 `c_SSL` 当作 `p(y|x)` 使用。**LAUNDER-GUARD 保证：没有任何自监督量可以在未通过外部锚点的情况下降低 λ_floor。**

**定义 375（审计独立性与自证不可能）** 设审计数据 D_A、模型选择过程 Sel（含 φ 选择、特征选择、超参选择）。**审计泄漏** `Λ = TV( P(D_A | Sel), P(D_A) )`（或等价的选择偏差项）。要求 `Λ ≤ τ_Λ`，且 `D_A ⟂ Sel` 在可验证的统计意义下成立。
**自证不可能性**（引理 37）：若 D_A 同时用于选择与校准，则存在选择过程使「经验覆盖率 = 1 而真实覆盖率 = 0」。**因此独立密封锚点不是工程洁癖，而是覆盖保证的前提。** 操作化：承诺-揭示哈希、时间留出、第三方注入、每次部署前重新密封。

**定义 376（自监督指标扩展 S-MIB）** 在 R72 E-MIB 基础上新增四族，均遵循定义 332 六元组 (φ,m,u,D,τ,I⊥) 与 333 DAG 分层：
- **规范族**：`ι_under`、`σ_sem`、短路谱 `CS_a^⊥/CS_a^∥`、坍缩指数 `CI = σ_sem/(ι_under+ϵ)`、谱间隙；
- **校准族**：锚点覆盖率、预测集平均大小、ACI 长程覆盖率、洗白比 `c_SSL/u_cal`；
- **随机化族**：`κ`、支撑覆盖、保守度 `V`、因果轴合规率、未覆盖环境率；
- **跨模态族**：残差漂移 `Δ_{ij}`、共模可辨识 `ρ_cm`、锚模态健康度。

**定义 377（自监督 IVG 扩展 S-IVG）** 新增失效条件：
- 规范：`ι_under > τ_i`、`σ_sem < τ_s`、`CI < τ_CI`、短路谱存在 `CS_a^⊥ > τ_sh` 且 `CS_a^∥ < τ_sem`；
- 校准：锚点覆盖 `< 1−α−ε`、预测集尺寸异常、ACI 长程覆盖不达标、洗白比超阈；
- 随机化：`κ > ε_cov`、支撑覆盖失败、`V > V_max`、因果轴违规；
- 跨模态：`ρ_cm < ρ_min`、锚模态失效、残差漂移超预算；
- 独立性：`Λ > τ_Λ`、锚点复用于选择。
**任一成立 ⇒ 对应能力失效，严格退化（定义 381）。**

**定义 378（自监督风险缩放 S-RISK）** 在 R72 E-RISK 基础上，只允许**校准后的**不确定度进入分母：
`λ = max( risk_scale(U_ale, U_epi, H[b_t(z)], u_tac, u_cal), λ_floor(Σ) )`，
其中 `u_cal` 由 SCAL 给出，且经 LAUNDER-GUARD 过滤。**自监督原始置信 `c_SSL` 不出现在 λ 的任何位置。** 覆盖/规范证书失效时，`u_cal` 被替换为 R72 的保守后验（退回标签校准）。

**定义 379（自监督证书 J_SELF）** `J_SELF = (J_EMB, gauge_hash, coverage_hash, anchor_hash, adr_hash, cms2r_hash, independence_proof, ver)`。
**Valid ⇔** `Valid(J_EMB)` ∧ 双侧规范证书有效 ∧ DRC 有效 ∧ SCAL 保形覆盖有效 ∧ 审计独立 ∧ 无洗白 ∧ 锚点预算达标。

**定义 380（威胁模型 AIC-SELF）** `ℰ_SELF = ℰ_EMB × ℰ_ssl × ℰ_dr × ℰ_anchor × ℰ_meta`：
- `ℰ_ssl` = {正负样本投毒（假负样本→语义坍缩）、增强后门（只在训练分布存在的变换）、短路注入（背景与标签虚假相关）、表示探测};
- `ℰ_dr` = {随机化轴误声明（把任务相关变量随机掉）、覆盖测试投机（选一个能藏住不匹配的统计量 T）、支撑集投毒、对抗环境落在尾部};
- `ℰ_anchor` = {少量锚点投毒（高杠杆）、锚点选择偏差、时间漂移破坏交换性、锚点泄漏进训练};
- `ℰ_meta` = {自证计量（选择与校准共用数据）、审计指标 Goodhart、ADR 与 SSL 共谋迎合审计}。

**定义 381（严格退化链）**
- 全有效 ⇒ SELF-GAUGE-RAS 完整；
- 锚点不足/覆盖失效 ⇒ 退回 R72 的标签校准 S2R-UQ（保守 u）；
- 规范证书失效（欠不变/过不变/短路）⇒ 弃用 SSL 表示，退回 R72 手工增强 + 监督探针；
- DRC 失效 ⇒ 退回 R72 的保守残差上界 + 人工随机化模板；
- CMS2R 不可辨识（共模）⇒ 退回 R72 的实机标定；
- 独立性/洗白失败 ⇒ 全系统视为「未校准」，退回 R71；再失效 ⇒ R68。
**安全侧只增不减：任何退化都保留 R72 的 λ_floor、非补偿否决与 R68 硬包络。**

**定义 382（与 R72 三域执行图的集成）** SSL 前向、SHORTCUT-SCAN、CMS2R 运行在**感知域**（Best-effort，可丢帧）；SCAL 分数计算与 ACI 更新在**计量域**（软实时 50Hz）；规范证书、DRC、ADR-G 在**离线/回合间**；控制域**只读取预先算好的标量** `(u_cal, gate_bits)`，**不新增任何在线自适应**。**自监督的全部计算不得侵入控制域——这是 R72 调度契约的不变式。**

**定义 383（ACI 在线覆盖监控器）** 计量域维护 `α_t` 与滑动窗口覆盖率 `ĉ_t`；当 `ĉ_t < 1−α−ε` 连续 W 个窗口，触发 S-IVG 校准失效并退化。**覆盖不是一次性证明，而是被持续监控的运行时属性。**

**定义 384（保守度-效用前沿）** 定义 DR 效用 `U(φ) = E_{P_real}[task_success] − λ_c·V(φ)`。可接受随机化集合 `Φ_adm = {φ : κ≤ε_cov, V≤V_max, 轴合规}`；选择 `φ* = argmax_{Φ_adm} U(φ)`（或前沿拐点）。**明确拒绝「为通过覆盖测试而无限随机化」——安全但不能干活的策略不是解。**

**定义 385（密封锚点协议 SEAL-ANCHOR）** 锚点集在部署前由**独立于建模团队**的流程生成，以承诺-揭示哈希锁定；训练/调参/ADR 全程不可见；部署时一次性揭示并计算 SCAL/覆盖率；之后立即作废并重新密封。**审计独立性被写成协议，而不是口号。**

## 2. 关键算法骨架

```python
# IP-296 GGAUGE：双侧规范证书（离线训练态审计）
def gauge_certificate(f, G, S, sim_pairs, anchors, eps_i, delta_s, eps_suff):
    iota_under = mean(d(f(x), f(g(x))) for x, g in sim_pairs.nuisance_pairs)
    sigma_sem  = min(mean(d(f(x), f(s(x)))) for x, s in sim_pairs.semantic_pairs)
    risk_suff  = probe_risk(f, anchors)          # 少量锚点上的监督探针
    ok = (iota_under <= eps_i) and (sigma_sem >= delta_s) and (risk_suff <= eps_suff)
    return GaugeCert(ok=ok, iota=iota_under, sigma=sigma_sem,
                     collapse_index=sigma_sem/(iota_under+1e-9), risk=risk_suff)

# IP-297 SHORTCUT-SCAN：用 DR 的 y-保持/y-改变干预测短路
def shortcut_scan(f, predictor, axis_list, dr):
    spectrum = []
    for a in axis_list:
        pairs_keep = dr.intervene(a, keep_label=True)    # x -> x_{a<-a'}
        pairs_flip = dr.intervene(a, keep_label=False)   # x -> x_{a<-a*}
        cs_perp = mean(dist(predictor(x), predictor(x2)) for x, x2 in pairs_keep)
        cs_par  = mean(dist(predictor(x), predictor(x2)) for x, x2 in pairs_flip)
        spectrum.append((a, cs_perp, cs_par))
    return ShortcutSpectrum(spectrum,
                            shortcuts=[a for a,p,q in spectrum if p > TAU_SH and q < TAU_SEM])

# IP-298 SCAL：自监督保形校准 + ACI 在线覆盖
class SelfSupervisedConformal:
    def __init__(self, score_fn, alpha, gamma=0.01):
        self.s, self.alpha, self.gamma = score_fn, alpha, gamma
    def calibrate(self, anchors):
        self.scores = sorted(self.s(x, y) for x, y in anchors)
        self.q = quantile(self.scores, 1 - self.alpha, interpolation='higher')
    def predict_set(self, x):
        return {y for y in candidate_labels(x) if self.s(x, y) <= self.q}
    def aci_update(self, x, y_true):
        err = 0 if y_true in self.predict_set(x) else 1
        self.alpha = clip(self.alpha + self.gamma * (self.alpha_target - err), 0, 1)
        return err

# IP-299 DRC：域随机化覆盖证书（KS + 支撑 + 保守度）
def dr_coverage_certificate(phi, T_real_samples, anchors, alpha, eps_cov, V_max):
    T_sim = [T(theta) for theta in sample(phi, N=2000)]
    kappa = ks_distance(T_sim, T_real_samples)
    pvals = [conformal_pvalue(T_sim, T(a)) for a in anchors]
    support_ok = mean(p >= alpha for p in pvals) >= 1 - eps_cov
    V = variance(T_sim)
    return DRCert(kappa=kappa, support_ok=support_ok, V=V,
                  ok=(kappa <= eps_cov and support_ok and V <= V_max))

# IP-300 ADR-G：因果轴约束下的覆盖-效用前沿
def adr_g_step(phi, risk_fn, kappa_hat, V, causal_axes, eps_cov, V_max, rho, mu):
    best, best_obj = None, inf
    for phi_new in propose(phi, axes=causal_axes):
        k, v = kappa_hat(phi_new), V(phi_new)
        if k > eps_cov or v > V_max: continue
        obj = risk_fn(phi_new) + rho * k + mu * v
        if obj < best_obj: best, best_obj = phi_new, obj
    # 对抗搜索：找真实但落在 P_phi 尾部/未覆盖的环境，加入下一轮
    uncovered = adversarial_search(phi=best, target='real_like_outside_support')
    return best, uncovered

# IP-301 CMS2R：跨模态自监督残差（含共模可辨识检查）
def cms2r_residual(model, real_stream, anchor_modality, rho_min):
    r_sim  = model.residual_distribution_sim()
    r_real = [d(model.h_i(m_i), model.h_j(m_j)) for m in real_stream for i, j in pairs]
    delta  = optimal_transport(r_real, r_sim)
    rho_cm = common_mode_identifiability(model, anchor_modality)
    ok = (rho_cm >= rho_min)
    return Sim2RealResidual(delta=delta, rho_cm=rho_cm, ok=ok,
                            u_real=calibrated_quantile(delta, 0.999))

# IP-302 LAUNDER-GUARD：不确定度洗白防护
def launder_guard(c_ssl, u_cal, rho_audit, rho_min, u_cap):
    if rho_audit < rho_min:
        return u_cal + u_cap            # 自监督置信完全惰性
    return u_cal + (1 - rho_audit) * u_cap   # 只允许按审计通过率折价

# IP-304 SELF-GAUGE 主闭环（与 R72 三域对齐，控制域零新增自适应）
def SELF_GAUGE_round(M, obs, audio, tac_frame, anchor_ctx):
    # ===== 控制域（1kHz，只读快照，无 SSL/无自适应）=====
    snap = M.snapshot.read_latest()
    u_cal = snap.u_cal if snap.calib_valid else M.r72_conservative_u()
    u_eff = launder_guard(snap.c_ssl, u_cal, snap.rho_audit, RHO_MIN, U_CAP)
    lam = s_risk_scale(snap.U_ale, snap.U_epi, snap.H_z, snap.u_tac, u_eff)
    k = M.ctrl.step(lam)
    M.last_action = k

    # ===== 计量域（50Hz，软实时）=====
    if M.clock.due_metric():
        # SCAL 校准 + ACI 覆盖监控
        y_set = M.scal.predict_set(normalize(obs))
        err = M.scal.aci_update(normalize(obs), M.anchor_ctx.peek_label())
        cover_ok = M.aci_monitor.push(err)
        # 规范/覆盖/跨模态门控（只读离线证书 + 在线 ACI）
        gate = M.s_ivg.check(M.registry, M.gauge_cert, M.drc, cover_ok,
                             M.cms2r, M.seal_anchor.rho_audit)
        if not gate.valid:
            M.mode = gate.fallback      # R72 / R71 / R68
        M.snapshot.write(U_ale=..., U_epi=..., H_z=..., u_tac=...,
                         u_cal=y_set.uncertainty, c_ssl=M.ssl_conf(obs),
                         rho_audit=M.seal_anchor.rho_audit, calib_valid=gate.calib_ok)

    # ===== 感知域（Best-effort，可丢帧）=====
    M.ssl_embedding = M.encoder(obs) if M.encoder_healthy() else None
    M.shortcut_scan.maybe_update(M.dr.get_interventions())
    M.cms2r.maybe_update(tac_frame, obs, audio)

    # ===== 离线/回合间（不在控制回路）=====
    # GGAUGE、DRC、ADR-G、SEAL-ANCHOR 重密封
    return k, lam, J_SELF(M, gate)
```

## 3. 推导

**引理 33（双侧不变性的必要性）** 设真实风险 `R(f) = E[ℓ(f(x), y)]`。
(i) 若欠不变（存在 nuisance g 使 `d(f(x),f(gx))` 大），则 nuisance 进入表示，`R` 随 nuisance-标签相关性增加；
(ii) 若过不变（存在 semantic s 使 `f(x)=f(sx)` 而 `y` 不同），则存在 `x, sx` 同表示异标签，任何 `h∘f` 的 Bayes 风险 ≥ 该轨道内的最小错误率 > 0。
**证明要点**：(i) 由 nuisance 与 y 的互信息非零时表示的额外方差导致；(ii) 数据 processing：`Y — X — f(X)`，若 f 在轨道上常值，则 `I(f(X);Y) ≤ I(X;Y) − I(X;Y|f)`，且轨道内标签不可分 ⇒ 严格正风险。
系：**只压 ι 的「单侧不变性」会奖励坍缩；必须同时约束 σ_sem。**

**引理 34（保形覆盖与其承重假设）** 若 `(X_i,Y_i)` 与 `(X,Y)` 可交换，则 split-conformal 满足 `P(Y∈C_α(X)) ≥ 1−α`。若协变量漂移且密度比 `w` 已知，加权保形在 `w`-加权分布下仍有覆盖；若漂移未知但有界，ACI 在合适步长下给出长程覆盖 `liminf (1/T)Σ err_t ≤ α`（up to 有界漂移项）。
**系：保形保证的承重假设是交换性/密度比正确性，而不是模型好坏。** 因此 S-IVG 必须监控交换性（漂移检测），不能只报一次覆盖率。

**引理 35（锚点标签复杂度）** 由 DKW 不等式，n 个独立样本的经验 CDF 以概率 `1−δ` 一致逼近真实 CDF 误差 `≤ √(log(2/δ)/(2n))`。令其为 ε 得 `n = ⌈log(2/δ)/(2ε²)⌉`。**锚点需求与表示维度无关**；故 SSL 省的是表示标签，不是校准样本。

**引理 36（DR 覆盖 ⇒ sim2real 风险界）** 若 `κ = sup_t |F_S(t)−F_real(t)| ≤ ε_cov` 且损失 `ℓ` 有界于 `[0,B]`，则对任意阈值决策 `E_real[ℓ] ≤ E_S[ℓ] + B·ε_cov`。更一般地，`|E_real[φ(T)]−E_S[φ(T)]| ≤ 2·Lip(φ)·W_1 ≤ 2·Lip(φ)·diam(T)·κ`（KS 控制 W1 的常用界）。**证明要点**：用 KS 的耦合构造把真实与仿真的 T 对齐，再对指示函数取期望。
**系：覆盖证书把「仿真真值」换算成「真实风险上界」；没有 κ，DR 上的低风险毫无意义。**

**引理 37（自证不可能性）** 设审计集 D_A 同时被用于模型选择与校准。则存在选择过程 Sel，使得对任意 α，Sel 选出的模型在 D_A 上经验覆盖率为 1，而在独立测试集上的真实覆盖率可为 0。
**证明要点**：Sel 可以让模型对 D_A 中的样本「记忆」其标签（例如在 D_A 上过拟合的保形分数），D_A 上分数全对；独立样本上则无保证。形式化为选择偏差项 `Λ = TV(P(D_A|Sel),P(D_A))`，覆盖下界退化为 `1−α−Λ`。
**系：审计独立性是覆盖保证的必要条件；SEAL-ANCHOR 是这条引理的工程化。**

**引理 38（保守度单调性与前沿拐点）** 对固定任务，`E_real[success]` 随 `V(φ)` 增大而非增（信息被随机化稀释），而 `κ(φ)` 随支撑扩大而非增。存在 Pareto 前沿；过度随机化落在「覆盖高、效用低」的退化端。**ADR-G 的目标是前沿拐点，不是端点。**

**定理 27（标定三角有效 ⇒ 有界真实风险）** 若 LCT 满足 E1（`κ≤ε_cov`）、E2（双侧规范证书 + 迁移间隙 `Δ_ι≤ε_transfer`）、E3（独立锚点保形覆盖 `≥1−α`）、Ind（`Λ≤τ_Λ`），则真实风险
`R_real ≤ R_S + B·ε_cov + ε_suff + ε_transfer + ε_cal(α, n_anchor) + Λ·B`，
其中 `ε_cal` 由引理 35 给出。**证明**：把风险分解为「仿真风险 + 覆盖差（引理 36）+ 表示不充分（E2）+ 校准误差（引理 34/35）+ 选择偏差（引理 37）」，逐项由一条边控制。
**系：R73 的安全不是「自监督很强」，而是「三角的每条边都被独立约束」。**

**定理 28（自监督严格包含与安全单调）** 在 A111–A116（规范双侧可审计、覆盖证书有效、锚点独立且预算达标、ACI 漂移有界、共模可辨识、ADR 轴因果合规）下：SELF-GAUGE 在退化条件下逐指令等于 R72/R71/R68（定义 381）；且对任意有效执行，其风险界 ≤ R72 的风险界。**安全单调不减，效率只在「三角闭合」时获益。**

**定理 29（无免费不变性 / 锚点必要性）** 若规范群 𝒢 中存在改变标签的变换（`∃g∈𝒢, P(Y(gx)≠Y(x))>0`），则任何严格 𝒢-不变编码器都不能是 Y-充分的：`I(f(X);Y) ≤ I(X;Y) − I(X;Y|𝒢-orbits) < I(X;Y)`。要恢复充分性，必须引入**轨道外信息**（监督/锚点/语义干预）。因此「零标签 + 严格可审计」不可能同时成立；锚点预算存在信息论下界。
**证明要点**：数据 processing + 轨道内标签不可分。**系：label-free 最多是 label-sparse；任何「零标签且可审计」的宣称都在偷用更强的同分布/增强正确假设。**

**定理 30（审计 Goodhart）** 若审计指标族 S-MIB 本身被优化（ADR 最大化覆盖、SSL 最小化 ι、训练最大化 σ_sem），且所有指标在同一仿真分布上测量，则存在退化解：常值编码器（ι=0）、无信息随机化（覆盖完美、效用为 0）、或在仿真上 σ_sem 高而真实 σ_sem 低的「规范错配」解，使全部指标通过而真实效用为 0。
**系：每个正向指标必须配一个反向效用/保守度指标，且至少一个锚点来自**独立于优化过程**的密封集。否则审计只是另一个可被优化的损失函数。**

## 6. 本轮最大风险

**核心风险**：SELF-GAUGE 把安全从「相信标签校准」转移到「相信 **仿真覆盖真实、增强规范正确、少量锚点独立且可交换**」——而这三个假设恰好是**最难被证伪**的结构性假设。如果 ADR-G 用被审计的 SSL 特征去选随机化分布、DRC 又用同一个分布生成覆盖证书、锚点又只覆盖一个狭窄的真实切片，那么 **E1/E2/E3 会互相迎合并同时「通过」**：系统会拿着一份 J_SELF 盖章证书，在一个它自己制造的、因果上错误的世界模型里自信地行动——**不是过拟合数据，而是过拟合了审计它的那把尺子**。这就是「自证计量」：审计本身成为被优化的目标，Goodhart 上升到了元层。

次级风险与缓解：
1. **自证/选择偏差** → 强制 SEAL-ANCHOR：锚点独立生成、承诺-揭示、时间留出、部署前重密封；把 `Λ` 作为一等否决指标（定义 375）。
2. **DR 覆盖幻觉** → DRC 三件套（KS 间隙、支撑保形 p 值、保守度上界）+ 对抗搜索未覆盖环境；覆盖不达标即退回 R72 保守上界。
3. **过不变/语义坍缩** → 双侧证书 + 坍缩指数 `CI` + SHORTCUT-SCAN 的 y-改变干预；单侧不变性一律否决（引理 33）。
4. **把自监督置信当概率（洗白）** → LAUNDER-GUARD：无独立锚点时 `c_SSL` 完全惰性；λ 只接受 `u_cal`。
5. **共模失效（多模态一起错）** → 至少一个外部标定的锚模态（力/力矩）+ `ρ_cm` 可辨识检查；不可辨识则不使用 CMS2R。
6. **非平稳漂移破坏交换性** → ACI 在线覆盖监控 + 漂移检测 + 定期重密封锚点；覆盖连续 W 窗不达标即退化。
7. **计算侵入控制域** → 定义 382：SSL/SCAN/CMS2R 全在感知域，控制域只读标量；不新增在线自适应。
8. **复杂度/指标膨胀** → 每族至多 4 个 veto 指标，每个指标一条可复算证明；指标总数上限 48，复杂度本身进审计。

**一句话：本轮方案的最大风险是「三角自证」——当仿真覆盖、规范证书与锚点校准不再相互独立、而是被同一个优化过程同时塑造时，系统会用一份完全合规的 J_SELF 证书，自信地执行一个它在因果上根本误解的世界模型，且事后审计发现每条边当时都「通过」了。**

## 2. 形式化定义（要点版）

**定义 366（标定三角 LCT）** LCT 有效 ⇔ E1 覆盖 `κ≤ε_cov` ∧ E2 不变性迁移 `Δ_ι≤ε_transfer` ∧ E3 独立锚点保形覆盖 `≥1−α` ∧ Ind 审计独立 `Λ≤τ_Λ`。**标签被压缩而非消灭。**

**定义 367（双侧规范证书 GGAUGE）** `G(f)` 有效 ⇔ `ι_under≤ε_i` ∧ `σ_sem≥δ_s` ∧ `Risk(h∘f)≤ε_suff`。**单侧不变性会奖励常值坍缩；必须双侧约束。**

**定义 368（短路扫描 SHORTCUT-SCAN）** 用仿真干预：y-保持改 a 的敏感度 `CS_a^⊥`（应≤τ_sh）、y-改变改 a 的敏感度 `CS_a^∥`（应≥τ_sem）。**DR 提供真实世界无法提供的反事实。**

**定义 369（自监督保形校准 SCAL）** 保形 p 值 + 预测集 `C_α`；交换性下 `P(Y∈C_α)≥1−α`；已知密度比用加权保形，未知漂移用 ACI 维持长程覆盖。**自监督分数只做排序，不做概率。**

**定义 370（锚点预算 ANCHOR-BUDGET）** `n_anchor=⌈log(2/δ)/(2ε²)⌉`，维度无关。**标签成本随精度平方反比，不随模型规模增长。**

**定义 371（DR 覆盖证书 DRC）** 有效 ⇔ `κ≤ε_cov` ∧ 支撑覆盖成立 ∧ `V≤V_max`。**覆盖与保守度双向约束，防止「安全但无能」。**

**定义 372（审计驱动自适应随机化 ADR-G）** 在 causal-axis 约束下最小化 `E_S[Risk]+ρκ+μV`；对抗搜索未覆盖真实样态加入下一轮。**不是自动调参，而是覆盖-效用前沿找拐点。**

**定义 373（跨模态自监督残差 CMS2R）** `Δ_{ij}=OT(P_real(r_ij),P_S(r_ij))`；需锚模态与 `ρ_cm≥ρ_min` 防共模失效。**只估残差，不声称消除。**

**定义 374（洗白防护 LAUNDER-GUARD）** `u_eff=u_cal+(1−ρ_audit)u_cap`；`ρ_audit<ρ_min` 时 `c_SSL` 完全惰性。**无独立锚点，任何自监督量不得降低 λ。**

**定义 375（审计独立与自证不可能）** 要求 `D_A⟂Sel`、`Λ≤τ_Λ`；引理 37 证明「选择与校准共用数据」可使经验覆盖 1 而真实覆盖 0。

**定义 376–377（S-MIB / S-IVG）** 新增规范族、校准族、随机化族、跨模态族指标；任一 veto 超阈 ⇒ 对应能力失效并严格退化。

**定义 378（S-RISK）** `λ=max(risk_scale(U_ale,U_epi,H_z,u_tac,u_cal), λ_floor(Σ))`；`c_SSL` 不进入 λ。

**定义 379（自监督证书 J_SELF）** `Valid ⇔ J_EMB 有效 ∧ 规范 ∧ 覆盖 ∧ 锚点 ∧ 独立 ∧ 无洗白 ∧ 锚点预算达标`。

**定义 380（威胁模型 AIC-SELF）** `ℰ_SELF=ℰ_EMB×ℰ_ssl×ℰ_dr×ℰ_anchor×ℰ_meta`：正负样本投毒、增强后门、短路注入、随机化轴误声明、覆盖测试投机、锚点投毒、自证/元 Goodhart。

**定义 381（严格退化链）** 锚点失效→R72 标签校准；规范失效→R72 手工增强；DRC 失效→R72 保守上界；CMS2R 不可辨识→R72 实机标定；独立性/洗白失败→R71；再失效→R68。**安全单调不减。**

**定义 382（三域集成）** SSL/SCAN/CMS2R 感知域；SCAL/ACI 计量域；GGAUGE/DRC/ADR 离线；控制域只读标量、零新增自适应。

**定义 383（ACI 在线覆盖监控器）** 滑动窗口覆盖连续 W 窗低于 `1−α−ε` 即退化。**覆盖是运行时属性，不是一次性证明。**

**定义 384（保守度-效用前沿）** `Φ_adm={φ: κ≤ε_cov, V≤V_max, 轴合规}`，`φ*=argmax U(φ)`。**拒绝无限随机化。**

**定义 385（密封锚点协议 SEAL-ANCHOR）** 独立生成 + 承诺-揭示 + 时间留出 + 部署前重密封。**审计独立是协议，不是口号。**

```python
# IP-295/296 LCT + GGAUGE：三角有效性 + 双侧规范证书
def lct_valid(cov_cert, gauge_cert, calib_cert, independence_cert):
    return (cov_cert.ok and gauge_cert.ok and calib_cert.ok
            and independence_cert.leakage <= TAU_LAMBDA)

def gauge_certificate(f, nuisance_pairs, semantic_pairs, anchors):
    iota_under = mean(d(f(x), f(gx)) for x, gx in nuisance_pairs)
    sigma_sem  = min(mean(d(f(x), f(sx))) for x, sx in semantic_pairs)
    risk_suff  = supervised_probe_risk(f, anchors)   # 少量锚点上的探针
    return GaugeCert(
        ok=(iota_under <= EPS_I and sigma_sem >= DELTA_S and risk_suff <= EPS_SUFF),
        iota=iota_under, sigma=sigma_sem,
        collapse_index=sigma_sem / (iota_under + 1e-9))

# IP-297 SHORTCUT-SCAN：DR 的两种干预
def shortcut_scan(predictor, axes, dr):
    out = []
    for a in axes:
        keep = dr.intervene(a, keep_label=True)     # 只改 a，y 不变
        flip = dr.intervene(a, keep_label=False)    # 改 a 且 y 改变
        cs_perp = mean(dist(predictor(x), predictor(x2)) for x, x2 in keep)
        cs_par  = mean(dist(predictor(x), predictor(x2)) for x, x2 in flip)
        out.append(AxisReport(a, cs_perp, cs_par,
                              shortcut=(cs_perp > TAU_SH and cs_par < TAU_SEM)))
    return out

# IP-298 SCAL：保形校准 + ACI
class SelfSupervisedConformal:
    def __init__(self, score_fn, alpha):
        self.s, self.alpha, self.alpha_target = score_fn, alpha, alpha
    def calibrate(self, anchors):
        self.scores = sorted(self.s(x, y) for x, y in anchors)
        self.q = empirical_quantile(self.scores, 1 - self.alpha)
    def predict_set(self, x):
        return {y for y in labels(x) if self.s(x, y) <= self.q}
    def aci_update(self, x, y, gamma=0.01):
        err = 0 if y in self.predict_set(x) else 1
        self.alpha = clip(self.alpha + gamma * (self.alpha_target - err), 0.0, 1.0)
        self.q = empirical_quantile(self.scores, 1 - self.alpha)
        return err

# IP-299 DRC：KS + 支撑 + 保守度
def dr_coverage_certificate(phi, T_real, anchors, alpha):
    T_sim = [T(theta) for theta in sample(phi, N=2000)]
    kappa = ks_distance(T_sim, T_real)
    support_ok = mean(conformal_pvalue(T_sim, T(a)) >= alpha for a in anchors) >= 1 - EPS_SUP
    V = variance(T_sim)
    return DRCert(kappa=kappa, support_ok=support_ok, V=V,
                  ok=(kappa <= EPS_COV and support_ok and V <= V_MAX))

# IP-300 ADR-G：因果轴约束 + 对抗搜索
def adr_g_step(phi, risk_fn, kappa_fn, var_fn, axes_causal):
    best, best_obj = phi, inf
    for cand in propose(phi, axes=axes_causal):
        k, v = kappa_fn(cand), var_fn(cand)
        if k > EPS_COV or v > V_MAX:
            continue
        obj = risk_fn(cand) + RHO * k + MU * v
        if obj < best_obj:
            best, best_obj = cand, obj
    uncovered = adversarial_search(best, target='real_like_outside_support')
    return best, uncovered

# IP-301 CMS2R：跨模态残差 + 共模可辨识
def cms2r_residual(encoders, real_stream, anchor_modality):
    r_sim  = sim_residual_distribution(encoders)
    r_real = [d(encoders[i](m[i]), encoders[j](m[j]))
              for m in real_stream for i, j in modality_pairs]
    delta  = optimal_transport(r_real, r_sim)
    rho_cm = 1 - min(corr(r_real_i, anchor_modality.residual()) for r_real_i in r_real)
    return Sim2RealResidual(delta=delta, rho_cm=rho_cm, ok=(rho_cm >= RHO_MIN),
                            u_real=quantile(delta, 0.999))

        return u_cal + U_CAP                       # 完全惰性
    return u_cal + (1 - rho_audit) * U_CAP

                             cover_ok, M.cms2r, M.anchor.rho_audit)
        if not gate.valid:
            M.mode = gate.fallback               # R72 / R71 / R68

                         u_cal=pred.uncertainty, c_ssl=M.ssl_conf(obs),
                         rho_audit=M.anchor.rho_audit, calib_ok=gate.calib_ok)

    # ===== 感知域 30–100Hz：可丢帧 =====
    M.ssl_embedding = M.encoder(obs) if M.encoder_healthy() else None
    M.shortcut_scan.maybe_update(M.dr.interventions())
    M.cms2r.maybe_update(tac_frame, obs, audio)

    # ===== 离线/回合间（不在控制回路）=====
    # GGAUGE / DRC / ADR-G / SEAL-ANCHOR 重密封
    return k, lam, J_SELF(M, gate)
```

## 4. 推导

**引理 33（双侧不变性的必要性）** 欠不变 ⇒ nuisance 进入表示，风险随 nuisance-标签相关性上升；过不变 ⇒ 轨道内同表示异标签，任何 `h∘f` 在轨道内的 Bayes 风险 > 0。证明用数据 processing 与轨道不可分性。**系：单侧不变性会奖励坍缩。**

**引理 34（保形覆盖与承重假设）** 交换性下 split-conformal 覆盖 `≥1−α`；已知密度比用加权保形；未知漂移用 ACI 维持长程覆盖。**承重假设是交换性/密度比，不是模型好坏。**

**引理 35（锚点标签复杂度）** DKW ⇒ `n=⌈log(2/δ)/(2ε²)⌉`，维度无关。**SSL 省表示标签，不省校准样本。**

**引理 36（DR 覆盖 ⇒ sim2real 风险界）** `κ≤ε_cov`、损失有界 B ⇒ `E_real[ℓ] ≤ E_S[ℓ] + B·ε_cov`；一般地 `|E_real φ − E_S φ| ≤ 2 Lip(φ) W_1`。**没有 κ，DR 低风险毫无意义。**

**引理 37（自证不可能性）** 选择与校准共用 D_A 时，存在模型使 D_A 经验覆盖 1、独立真实覆盖 0；覆盖下界退化为 `1−α−Λ`。**系：审计独立是覆盖保证的必要条件。**

**引理 38（保守度单调性与前沿拐点）** 成功率随 V 非增、覆盖随支撑扩大非减 ⇒ Pareto 前沿；过度随机化落在「覆盖高、效用低」端。**ADR-G 找拐点而非端点。**

**定理 27（三角有效 ⇒ 有界真实风险）** LCT 有效 ⇒ `R_real ≤ R_S + B·ε_cov + ε_suff + ε_transfer + ε_cal(α,n) + Λ·B`。证明把风险分解为仿真风险、覆盖差、表示不充分、校准误差、选择偏差五部分，各由一条边控制。**系：安全来自每条边被独立约束，而非「SSL 很强」。**

**定理 28（自监督严格包含与安全单调）** 在 A111–A116 下，SELF-GAUGE 逐指令等于 R72/R71/R68（定义 381），且风险界 ≤ R72。**安全单调不减，效率仅在三角闭合时获益。**

**定理 29（无免费不变性 / 锚点必要性）** 若 `∃g∈𝒢` 改标签，则任何严格 𝒢-不变 f 都有 `I(f(X);Y) < I(X;Y)`；恢复充分性必须引入轨道外信息（监督/锚点/语义干预）。**系：label-free 最多是 label-sparse；零标签且可审计不可能。**

**定理 30（审计 Goodhart）** 若 S-MIB 指标在同一仿真分布上被同时优化，则存在常值编码器、无信息随机化、仿真-真实规范错配等退化解，使全部指标通过而真实效用为 0。**系：每个正向指标须配反向效用/保守度指标，且至少一个锚点来自独立密封集。**

## 7. 本轮最大风险

**核心风险**：SELF-GAUGE 把安全从「相信标签校准」转移到「相信 **仿真覆盖真实、增强规范正确、少量锚点独立且可交换**」——而这三个恰恰是最难被证伪的**结构性假设**。如果 ADR-G 用被审计的 SSL 特征去选随机化分布、DRC 用同一分布生成覆盖证书、锚点又只覆盖狭窄真实切片，则 E1/E2/E3 会互相迎合并同时「通过」。系统会拿着一份盖章的 J_SELF，在它自己制造的、因果上错误的世界模型里自信行动——**不是过拟合数据，而是过拟合了审计它的那把尺子**。这是「自证计量」：审计本身成为被优化的目标，Goodhart 上升到元层。

次级风险与缓解：
1. **自证/选择偏差** → SEAL-ANCHOR：独立生成、承诺-揭示、时间留出、部署前重密封；`Λ` 作为一等否决指标。
2. **DR 覆盖幻觉** → DRC 三件套（KS/支撑/保守度）+ 对抗搜索未覆盖环境；不达标退回 R72 保守上界。
3. **过不变/语义坍缩** → 双侧证书 + 坍缩指数 `CI` + SHORTCUT-SCAN 的 y-改变干预；单侧不变性一律否决。
4. **自监督置信洗白** → LAUNDER-GUARD：无独立锚点时 `c_SSL` 完全惰性，λ 只接受 `u_cal`。
5. **共模失效** → 至少一个外部标定锚模态（力/力矩）+ `ρ_cm` 检查；不可辨识则弃用 CMS2R。
6. **非平稳漂移破坏交换性** → ACI 在线覆盖监控 + 漂移检测 + 定期重密封；连续 W 窗不达标即退化。
7. **计算侵入控制域** → 定义 382：全部自监督计算留在感知/计量/离线；控制域只读标量。
8. **指标膨胀/复杂度** → 每族 ≤4 个 veto 指标，总计 ≤48，每个一条可复算证明，复杂度进审计。

**一句话：本轮方案的最大风险是「三角自证」——当仿真覆盖、规范证书与锚点校准不再相互独立、而是被同一个优化过程同时塑造时，系统会用一份完全合规的 J_SELF 证书，自信地执行一个它在因果上根本误解的世界模型，且事后审计发现每条边当时都「通过」了。**
