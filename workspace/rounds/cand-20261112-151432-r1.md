# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC、IP-153~160；灵感循环第 7 轮；本轮灵感：「原型验证」×「开源生态」）

> 第 60 轮用 SSM/CIEC/EPIR/SERC 把「认知先行」接入了场景-执行闭环，但**三个结构性局限**仍未触及：
> 1. **断言远多于见证**：系统已累积到 160 条定义、A1–A65 假设与一串「若假设成立则结论成立」的正确性定理。定理只是把风险整体搬进了假设，整个研究仍**没有一个能跑起来的原型**能同时兑现「场景先验收敛 K_safe」「意图 2s 内锁定约束」「ROS 丢包证据链不断」。我把这个缺口称为**验证债（Validation Debt）**：高风险断言中未被可复现实验见证过的比例。
> 2. **闭环只在自己系统内闭合**：SSM/CIEC/EPIR 都用自己的证据验证自己，没有独立复现、没有外部反例、没有第三方替换实现。这是**自我确认闭环**，不是科学验证闭环。
> 3. **缺少生态接口与安全版本语义**：当前 IP 是一组单体定义，无法被第三方按契约替换、审计、组合。一旦接入真实 ROS2/ros2_control/MoveIt 栈，任何实现升级都可能在不声明的情况下改变安全包络，使 J_exec/J_chunk 证书悄悄失效。

## 0. 直觉与动机

**灵感 1（原型验证 → 原型保真度阶梯 PFL）**
直觉：形式定理的每一条假设都是一张「待兑现的支票」。原型不是定理之外附加的 demo，而是给每条断言兑现一张**带保真度标签的见证（witness）**。定义阶梯 L0=纸面证明、L1=仿真、L2=硬件在环 HIL、L3=真机单场景、L4=真机跨场景长时。把「系统是否可信」从布尔判断升级为**在保真度 ℓ 上的、按风险加权的覆盖率 cov_ℓ**，未被兑现的高风险断言即验证债 VD_ℓ = 1 − cov_ℓ。关键洞见：**先声明「哪些断言在什么保真度上没有被见证」，比再证明一条定理更有价值**。

**灵感 2（原型验证 → 最小可证原型 MVP）**
直觉：既然不可能一次验证全部 160 条定义，就应选**覆盖关键断言所依赖接口的最小可执行子集**——一条从「场景→意图→阻抗→执行→证据→证书」的垂直切片。既不是演示级 demo，也不是全栈仿真，而是「每条被选断言都带预注册、可判真假的 acceptance test」的最小集合。关键洞见：**原型选型本身是一个优化问题（断言-接口超图上的加权集合覆盖），不是工程直觉**。

**灵感 3（开源生态 → 可复现证据协议 ERP）**
直觉：开源的核心不是「代码可见」，而是「他人能在自己的机器上得到同一证据」。把每次原型运行封装为内容寻址的运行清单 m=(code_commit, container_digest, model_hash, config_hash, calib_hash, seed, scene_set)，连同 EPIR 证据链根 R 与复现等级 ρ（bit-exact / tolerance-exact / statistical）一起发布。EPIR 保证**单机内因果完整**，ERP 保证**跨机可重放**。关键洞见：**证据不仅要「不丢」，还要能被陌生人重放**。

**灵感 4（开源生态 → 能力插件接口 EPI 与安全语义版本 SSV）**
直觉：生态不是把单体拆成很多包，而是定义「可替换而不破坏安全」的契约。每个 IP 作为插件，携带 capability contract=(签名, 前置, 后置, 安全包络, 性能)；替换必须满足 **behavioral refinement**：前置不更强、后置不更弱、安全包络不扩大、副作用不增加。版本号必须**安全语义化**：MAJOR=改变安全包络或后置，MINOR=新增能力且保持契约偏序，PATCH=实现修复不改契约。关键洞见：**安全证书必须对「实现替换」保持不变，否则生态的每次升级都是一次未声明的安全回归**。

**灵感 5（开源生态 → 生态对抗验证 EAV）**
直觉：开源把「一个团队的红队」放大成「一群人的红队」。外部攻击者提交的每个反例都带可复现 witness + manifest，通过验证后直接进入回归池；可复现执行证书必须在反例池上存活，否则被撤销。反例池单调增长。关键洞见：**生态的价值不是「更多代码」，而是「更多反例」**——反例是唯一不会自我确认的证据。

**灵感 6（合流 → TPEL 可信原型演化闭环 + PCE++++++ 验证预算）**
直觉：闭环从第 60 轮的「认知驱动执行」升级为「**断言→原型→外部见证→反例硬化**」：断言图 → MVP 选型 → 按保真度运行 → 生成签名清单与证据 → 发布到开源证据公地 → 社区红队与插件替换 → 反例回归 → 重认证。预算在原四维认知预算上新增第五维验证预算 B_val=(B_fidelity, B_replicate, B_redteam, B_regress, B_env)；用 VOI_val = 期望验证债下降量 − 验证成本 决定下一笔验证投入。关键洞见：**验证本身也要算投入产出比，而不是无限堆实验**。

## 1. 形式化定义（增量：定义 161–169）

**定义 161（原型保真度阶梯 PFL 与验证债 VD）** 保真度阶梯 L={L0,L1,L2,L3,L4}，L0≺L1≺…≺L4。断言集合 C，每条断言 c∈C 有风险权重 risk(c)、容差 tol(c)、所需保真度 ℓ_req(c)。见证函数 w(c)=(ℓ_c, test_c, manifest_hash, passed)。在保真度 ℓ 上的**风险加权覆盖率**：
```
cov_ℓ = Σ_{c∈C} risk(c)·1[w(c).ℓ ≥ ℓ ∧ w(c).passed] / Σ_{c∈C} risk(c)
VD_ℓ = 1 − cov_ℓ
```
**验证债**定义为 VD_ℓ 中风险高于 τ_crit 的断言子集：VD_ℓ^crit = {c : risk(c) ≥ τ_crit ∧ w(c) 未在 ℓ 上通过}。关键约束：**不允许用低风险断言的高覆盖率掩盖高风险断言的零见证**，报告必须分层披露。

**定义 162（最小可证原型 MVP）** 断言-接口二部超图 H=(C, I, E)，E⊆C×I，边 (c,i) 表示「见证断言 c 必须触及接口 i」。组件集合 Comp，组件 g 提供接口 Int(g)⊆I、成本 cost(g)。**最小可证原型**是加权集合覆盖：
```
S* = argmin_{S⊆Comp} Σ_{g∈S} cost(g)
     s.t. ∀c∈C_crit: I_c ∩ (∪_{g∈S} Int(g)) ≠ ∅
```
（NP-hard；贪心按「新增覆盖断言风险 / 成本」择优，给出 H_n 近似。）**垂直切片** = 在 H 上从场景接口到证书接口的最短可执行路径。可证性要求：∀c∈S 覆盖的断言，存在**预注册**的可判定 acceptance test A_c 与容差 tol(c)，运行前不得修改。

**定义 163（内容寻址证据与可复现清单 ERP）** 运行清单：
```
m = (code_commit, container_digest, model_hash, config_hash, calib_hash, seed, scene_set)
```
证据 e=(seq_id, timestamp, hash, payload)，证据链根 R=HashChain(e_1,…,e_n)。复现等级 ρ∈{bit-exact, tolerance-exact, statistical}。**复现判定** VerifyRepro(m, R, run', ρ, ε_env)=true 当且仅当：
(i) run'.manifest_hash = H(m)；(ii) run'.chain_root = R；(iii) ρ-match(run'.evidence, reference, tol)；(iv) 环境差异 |Δ_env| ≤ ε_env。**跨机一致性**要求 ρ 与 ε_env 在运行前声明，禁止事后挑选宽松等级。

**定义 164（生态能力插件接口 EPI 与安全语义版本 SSV）** 能力契约 C=(Sig, Pre, Post, Env, Perf)，其中 Sig 为接口签名、Pre/Post 为前后置条件、Env 为安全包络、Perf 为性能下界。**行为精化** A⊑_C B 当且仅当：
```
B.Sig = C.Sig
∧ Pre_B ⇒ Pre_A          （前置不更强，允许更宽容的输入）
∧ Post_A ⇒ Post_B        （后置不更弱，保证更多性质）
∧ Env_B ⊆ Env_A          （安全包络不扩大）
∧ SideEffect_B ⊆ SideEffect_A
```
**安全语义版本 SSV**：(MAJOR, MINOR, PATCH) 中，MAJOR 改变 Env/Post（必须重新认证）；MINOR 增加能力且保持 A⊑_C B（可条件兼容）；PATCH 仅实现修复且契约等价（自动兼容）。兼容矩阵 M_compat[v_i][v_j]∈{safe, conditional, unsafe}，任何 `unsafe` 组合在加载期硬拒绝。

**定义 165（生态对抗验证 EAV 与反例池）** 反例 x=(scene, input, config, observed_violation, witness, manifest)。x 被接纳当且仅当 witness 可独立重放且 manifest 校验通过。反例池 P 与回归套件 R 单调增长：
```
P_t ⊆ P_{t+1},  R_t ⊆ R_{t+1}
cert_survives(J, R) = ∀x∈R: ¬violates(x, J)
```
若 cert_survives=false，则证书被撤销（REVOKED），并触发对应断言的保真度回退。**逃逸率** escape(R)=在 R 上通过却在留出攻击集上失败的证书比例，作为硬化效果的度量。

**定义 166（可复现执行证书 J_repro）** J_repro 是第 59 轮 J_exec 与第 61 轮 J_chunk 的**跨机扩展**：
```
J_repro = (Cert_eeis, J_exec/J_chunk, H(m), R,
           cov_ℓ, VD_ℓ^crit, substitute_witness, redteam_witness)
```
可验证谓词：证书有效 ⇔ (i) 底层执行证书有效；(ii) 存在第三方在 ρ 等级上复现成功；(iii) 见证覆盖率不低于声明值；(iv) 所有已替换插件满足 EPI 精化；(v) 证书在已接纳反例池上存活。

**定义 167（五维验证预算 PCE++++++）** B_val=(B_fidelity, B_replicate, B_redteam, B_regress, B_env)。验证动作 π_val 的净价值：
```
voi_val(π) = E[ΔVD_ℓ^crit(π)] − cost_val(π)
cost_val = λ_fid·Σ run_cost(ℓ) + λ_rep·Replicate_cost(ρ)
         + λ_rt·Redteam_cost + λ_reg·Regression_cost + λ_env·Env_match_cost
```
选择 argmax_π voi_val；当 B_val 任一维耗尽：**冻结证书在当前覆盖率**、显式标注 VD、禁止提升声明等级（不得把 L1 的见证写成 L3 的结论）。

**定义 168（断言-契约追溯矩阵 PCM）** 追溯矩阵 T：C → 2^{Tests} × 2^{Interfaces} × L × {owner}。两条完整性不变量：
```
无孤儿断言：∀c∈C_crit, T(c).Tests ≠ ∅ ∧ T(c).Interfaces ≠ ∅
无孤儿测试：∀t∈Tests, ∃c∈C_crit: t∈T(c).Tests
```
PCM 是原型验收、开源审计与反例回归的**唯一事实源**；任何新增 IP 若未在 PCM 登记，视为未验证，不计入 cov_ℓ。

**定义 169（可信原型演化闭环 TPEL 算子）** TPEL(M, target_ℓ, B_val)：
```
① CLAIM:  C, H, T ← M.claim_graph.load()             # 断言、接口超图、追溯矩阵
② SELECT: S*, debt ← mvp_select(H, M.components, B_val.B_fidelity)   # 集合覆盖
③ RUN:    for ℓ in ladder_up_to(target_ℓ):
              ev ← M.run_prototype(S*, ℓ, pre_registered_tests(T))
              m  ← build_manifest(M.repo, M.cfg)
              R  ← M.epir.append_chain(ev)
④ CERT:   J  ← M.repro_certify(m, R, ev, cov_ℓ, debt)
⑤ PUBLISH:M.commons.publish(m, ev, J)                  # 开源证据公地，内容寻址
⑥ SUBST:  for g in M.commons.poll_plugins(H.interfaces):
              if refines(g, contract_of(g)): M.substitute(g)
              else: M.registry.mark_unsafe(g)
⑦ REDTEAM:for x in M.commons.poll_counterexamples(m, B_val.B_redteam):
              if M.adversarial.admit(x): M.regression.add(x)
⑧ REPRO:  if B_val.B_replicate>0: rep ← M.replicate(m, ρ); B_val.B_replicate−=1
              if not rep.match: return (REPRO_FAILED, VD_ℓ)
⑨ SURVIVE:if not cert_survives(J, M.regression): return (CERT_REVOKED, VD_ℓ)
⑩ return (J, cov_ℓ, VD_ℓ^crit, M.commons.status)
```
任何一步失败都**显式降低声明等级**，而不是继续输出「已验证」结论。

## 2. 关键算法伪代码

### IP-161 / IP-168 PFL + PCM（保真度阶梯与追溯矩阵）

```python
class ClaimGraph:
    def __init__(self, claims, interfaces, edges):
        self.C, self.I, self.E = claims, interfaces, edges
        self.witness = {}                    # claim_id -> Witness(level, test, manifest, passed)
        self.trace = {}                      # claim_id -> Trace(tests, interfaces, level, owner)

    def coverage(self, level, risk=None):
        num = sum((risk or {}).get(c.id, c.risk) for c in self.C
                  if self.witness.get(c.id)
                  and self.witness[c.id].level >= level
                  and self.witness[c.id].passed)
        den = sum((risk or {}).get(c.id, c.risk) for c in self.C)
        return num / den

    def validation_debt(self, level, tau_crit=0.8):
        return {c.id for c in self.C
                if c.risk >= tau_crit
                and not (self.witness.get(c.id)
                         and self.witness[c.id].level >= level
                         and self.witness[c.id].passed)}

    def check_no_orphans(self):
        return all(self.trace.get(c.id)
                   and self.trace[c.id].tests
                   and self.trace[c.id].interfaces
                   for c in self.C if c.critical)
```

### IP-162 MVP（最小可证原型选择）

```python
def mvp_select(graph, components, budget):
    uncovered = {c.id for c in graph.C if c.critical}
    chosen, spent = [], 0.0
    while uncovered and spent < budget:
        best, best_gain = None, 0.0
        for g in components.values():
            if g.id in chosen:
                continue
            gain = graph.risk_mass(graph.claims_covered_by(g.interfaces, uncovered))
            if gain / g.cost > best_gain:
                best, best_gain = g, gain / g.cost
        if best is None or spent + best.cost > budget:
            break
        chosen.append(best.id)
        spent += best.cost
        uncovered -= graph.claims_covered_by(best.interfaces, uncovered)
    return chosen, uncovered        # uncovered 必须原样写入 VD_ℓ^crit，不得隐藏
```

@dataclass
class ReproManifest:

def build_manifest(repo, cfg):
    return ReproManifest(

        container_digest=image_digest(cfg.image),

def verify_repro(manifest, chain_root, run2, rho, eps_env):
    if run2.manifest_hash != manifest.digest():      return False
    if run2.chain_root != chain_root:                return False
    if not rho_match(rho, run2.evidence, run2.reference): return False
    return env_distance(run2.env, manifest) <= eps_env

### IP-164 SSV（插件精化与安全语义版本）

```python
class SafetySemVer:
    def bump(self, old, new):
        if new.envelope != old.envelope or new.post != old.post:
            return 'MAJOR'          # 必须重新认证
        if new.capabilities > old.capabilities and old.refines(new):
            return 'MINOR'
        return 'PATCH'

class PluginRegistry:
    def load(self, plugin, contract, certs):
        if not refines(plugin, contract):
            raise SafetyViolation('not a behavioral refinement')
        if self.compat(plugin.version) == 'unsafe':
            raise SafetyViolation('unsafe version pair')
        return all(c.valid_under(plugin) for c in certs)
```

### IP-165 EAV（生态红队与反例回归）

```python
class AdversarialPool:
    def __init__(self):
        self.regression, self.quarantine = [], []

    def admit(self, x):
        ok = verify_witness(x.witness) and verify_manifest(x.manifest)
        (self.regression if ok else self.quarantine).append(x)
        return ok

    def certificate_survives(self, cert, suite):
        return all(not violates(x, cert) for x in suite)
```

### IP-169 TPEL（可信原型演化闭环）

```python
def tpel_loop(M, target_level, budget):
    graph = M.claim_graph
    assert graph.check_no_orphans()
    for level in ladder_up_to(target_level):
        mvp, debt = mvp_select(graph, M.components, budget.B_fidelity)
        ev = M.run_prototype(mvp, level, pre_registered_tests(graph))
        manifest = build_manifest(M.repo, M.cfg)
        chain = M.epir.append_chain(ev)

        graph.witness(ev.claims, level, ev.tests, chain.root)
        cert = M.repro_certify(manifest, chain, ev,
                               graph.coverage(level), debt)
        M.commons.publish(manifest, ev, cert)

        for plugin in M.commons.poll_plugins(graph.interfaces):
            if refines(plugin, graph.contract_of(plugin)):
                M.substitute(plugin)
            else:
                M.registry.mark_unsafe(plugin)

        for x in M.commons.poll_counterexamples(manifest, budget.B_redteam):
            M.adversarial.admit(x)

        if not M.adversarial.certificate_survives(cert, M.adversarial.regression):
            return {'status': 'CERT_REVOKED',
                    'debt': graph.validation_debt(level)}

        if budget.B_replicate > 0:
            rep = M.replicate(manifest, rho='tolerance_exact')
            budget.B_replicate -= 1
            if not rep.match:
                return {'status': 'REPRO_FAILED',
                        'debt': graph.validation_debt(level)}

    return {'status': 'CERTIFIED', 'cert': cert,
            'coverage': graph.coverage(target_level)}
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PFL/PCM | O(\|C\|) 聚合/报告 | O(\|C\|+\|E\|) | 覆盖率按风险加权，高风险断言分层披露 |
| MVP | O(\|Comp\|·\|C_crit\|·H_n) 贪心 | O(\|Comp\|+\|C_crit\|) | 覆盖目标达成或显式留下 debt |
| ERP | O(n) 链校验，SHA256 线性 | O(n) 证据 | 清单内容寻址，跨机重放可判定 |
| EPI/SSV | O(1) 契约检查，O(\|cert\|) 证书 | O(\|plugins\|) | 行为精化保证证书对替换不变 |
| EAV | O(\|R\|) 证书生存检验 | O(\|R\|) | 反例池单调，证书可撤销 |
| J_repro | O(1) 组合验证 | O(1) | 五谓词合取，任一失败即无效 |
| TPEL | O(闭环) | 复用 | 端到端「无见证不声明」 |

**正确性定理（TPEC）**：假设 A71–A76 成立。
- (A71) 断言图有限，每条关键断言有预注册、可判定的 acceptance test 与容差。
- (A72) MVP 贪心覆盖关键接口超图；未被覆盖的关键断言被原样记入 VD_ℓ^crit。
- (A73) 运行清单内容寻址且字段完备（code/image/model/config/calib/seed/scene），哈希碰撞概率可忽略。
- (A74) 行为精化 ⊑_C 对契约是传递且可靠的（behavioral subtyping）。
- (A75) 反例接纳器可靠：只接纳可独立重放的违规 witness；回归套件单调。
- (A76) 验证预算单调消耗；任一维耗尽即冻结声明等级。

则：
1. **见证完整性**：每条关键断言 c 要么在 ℓ 上被见证（cov_ℓ 计入），要么显式出现在 VD_ℓ^crit——不存在「被静默跳过」的断言。
2. **复现可靠性**：VerifyRepro=true ⇒ 独立第三方在 ρ 与 ε_env 内得到与参考一致的证据；EPIR 的因果完整性与 ERP 的跨机可重放共同保证证据链不被「本地正确、异地失败」击穿。
3. **替换安全性**：若 B⊑_C A 且证书在 A 下有效，则证书在 B 下仍有效——开源生态的实现替换不会以「兼容」之名扩大安全包络。

### IP-161 / IP-168 PFL + PCM（保真度阶梯与追溯矩阵）

```python
class ClaimGraph:
    def __init__(self, claims, interfaces, edges):
        self.C, self.I, self.E = claims, interfaces, edges
        self.witness = {}                    # claim_id -> Witness(level, test, manifest, passed)
        self.trace = {}                      # claim_id -> Trace(tests, interfaces, level, owner)

    def coverage(self, level, risk=None):
        num = sum((risk or {}).get(c.id, c.risk) for c in self.C
                  if self.witness.get(c.id)
                  and self.witness[c.id].level >= level
                  and self.witness[c.id].passed)
        den = sum((risk or {}).get(c.id, c.risk) for c in self.C)
        return num / den

    def validation_debt(self, level, tau_crit=0.8):
        return {c.id for c in self.C
                if c.risk >= tau_crit
                and not (self.witness.get(c.id)
                         and self.witness[c.id].level >= level
                         and self.witness[c.id].passed)}

    def check_no_orphans(self):
        return all(self.trace.get(c.id)
                   and self.trace[c.id].tests
                   and self.trace[c.id].interfaces
                   for c in self.C if c.critical)
```

### IP-162 MVP（最小可证原型选择）

```python
def mvp_select(graph, components, budget):
    uncovered = {c.id for c in graph.C if c.critical}
    chosen, spent = [], 0.0
    while uncovered and spent < budget:
        best, best_gain = None, 0.0
        for g in components.values():
            if g.id in chosen:
                continue
            gain = graph.risk_mass(graph.claims_covered_by(g.interfaces, uncovered))
            if gain / g.cost > best_gain:
                best, best_gain = g, gain / g.cost
        if best is None or spent + best.cost > budget:
            break
        chosen.append(best.id)
        spent += best.cost
        uncovered -= graph.claims_covered_by(best.interfaces, uncovered)
    return chosen, uncovered        # uncovered 必须原样写入 VD_ℓ^crit，不得隐藏
```

### IP-169 TPEL（可信原型演化闭环）

```python
def tpel_loop(M, target_level, budget):
    graph = M.claim_graph
    assert graph.check_no_orphans()
    for level in ladder_up_to(target_level):
        mvp, debt = mvp_select(graph, M.components, budget.B_fidelity)
        ev = M.run_prototype(mvp, level, pre_registered_tests(graph))
        manifest = build_manifest(M.repo, M.cfg)
        chain = M.epir.append_chain(ev)

        graph.witness(ev.claims, level, ev.tests, chain.root)
        cert = M.repro_certify(manifest, chain, ev,
                               graph.coverage(level), debt)
        M.commons.publish(manifest, ev, cert)

        for plugin in M.commons.poll_plugins(graph.interfaces):
            if refines(plugin, graph.contract_of(plugin)):
                M.substitute(plugin)
            else:
                M.registry.mark_unsafe(plugin)

        for x in M.commons.poll_counterexamples(manifest, budget.B_redteam):
            M.adversarial.admit(x)

        if not M.adversarial.certificate_survives(cert, M.adversarial.regression):
            return {'status': 'CERT_REVOKED',
                    'debt': graph.validation_debt(level)}

        if budget.B_replicate > 0:
            rep = M.replicate(manifest, rho='tolerance_exact')
            budget.B_replicate -= 1
            if not rep.match:
                return {'status': 'REPRO_FAILED',
                        'debt': graph.validation_debt(level)}

    return {'status': 'CERTIFIED', 'cert': cert,
            'coverage': graph.coverage(target_level)}
```
