# 第 56 轮（承接第 55 轮语义-接触生存核 / 第 54 轮 v31；灵感循环第 1 轮；本轮灵感：「视觉-语言-动作模型」×「可重构机构」）

> 第 55 轮把“接触在语义上是否可信”写进了全身可行性核 `K(Σ)`，但它默认了一件事：**身体是固定的**。可重构机构把这个默认前提本身变成变量——拓扑、自由度、工作域会随一次对接/解锁而离散切换；VLA 则提供“看-说-做”的跨任务先验。两者相撞产生本轮三个核心矛盾：**H24**：VLA 的动作块只在训练时那具身体上有确定语义，形态一换，同一动作 token 的物理含义就漂移，语言越泛化、动作越不可直接执行；**H25**：重构是离散、接触丰富、常不可逆的“宏动作”，连续可行性核在切换瞬间失效，系统会穿过一段不属于任何单一形态的“形态奇点”；**H26**：VLA 只优化任务成功，而重构是在押上未来可选项，它会把“现在能做”误当成“值得做”。

## 0. 直觉与动机

**灵感 1（VLA → 语义先验，而不是可执行策略）**
直觉：VLA 最值钱的地方不是“输出动作”，而是“把一句含糊的话落到任务约束上”：它知道“从缝隙里把杯子递过来”意味着要穿过狭窄通道、保持杯子直立、末端朝向人。但它对这具身体的拓扑一无所知——训练分布里的身体是固定的。因此正确的定位是：**VLA 输出 `(任务约束 Φ(ℓ), 形态提议 m̂, 动作块 â)`，其中 `m̂` 与 `â` 都是不可信先验，只有 `Φ(ℓ)` 相对可信**。形态必须先被投影到合法形态流形、再经证书校验，动作块必须经重定向与接地缺陷检查后才能进入控制。一句话：**VLA 负责“想做什么”，证书负责“这具身体能不能做、做完还回不回得来”。**

**灵感 2（可重构机构 → 动作空间本身是变量）**
直觉：在固定机构上，动作空间 `A` 是常量；在可重构机构上，`A(m)` 随形态 `m` 改变，且形态切换 `m→m'` 是一个**离散宏动作**。于是系统不是“连续控制 + 偶发重置”，而是一个**混合切换系统**：连续流形 `K(m)` 之间由转移流形 `K_trans(e)` 连接。最危险的不是任何一个 `K(m)` 内部，而是转移过程中那段**既不属于 m 也不属于 m'** 的中间态——称之为**形态奇点** `K_mid(e)`。这里没有现成的生存核可依，必须给转移本身单独设计不变式与机械兜底。

**灵感 3（形态距离 → 接地误差的可证上界）**
直觉：VLA 的动作块在“训练形态”与“目标形态”之间做重定向时，误差不应是拍脑袋的经验值，而应随两具身体的**形态距离**增长。若形态距离可以用图编辑 + 工作域 Hausdorff 度量，并且重定向算子是 Lipschitz 的，那么“这个动作块在这具新身体上还能不能用”就变成一个**可计算的阈值问题**：`L_g·d_M(m,m_ref)·||â|| > δ_max` 就拒绝，而不是等到执行失败。这把“跨形态泛化”从玄学变成可判定的接地预算。

**灵感 4（不可逆重构 → 可选性预算，而非只算任务收益）**
直觉：对接、锁死、拆分往往是不可逆或半不可逆的下注。VLA 的语言目标只看到“任务成功”，看不到“我把未来的形态选项押掉了”。一次为了钻缝而拆掉一条腿，可能让后续“搬运重物”永远不可达。因此重构决策必须带**选项价值**：`V_opt(m,x)` 度量当前还能到达多少种形态/任务，重构要消耗**承诺预算** `commit = Σ(1-r_e)w_e`。护盾在所有“任务可行”的候选里，优先选**承诺最小、选项损失最小**的那一个——这不是保守，而是防止 VLA 用短期成功换取长期锁死。

**灵感 5（云 VLA ↔ 边证书 → 形态反例回传触发重提议）**
直觉：云端可以跑大 VLA 做全局语言 grounding 与形态提议，边端只做两件它最擅长的事：**验证转移与接地是否真能在这台物理样机上成立**，以及在失败时回传**形态反例**（“你提议的 `m'` 在这里根本对接不上 / 重定向后末端偏了 7cm”）。云端据此重新提议形态或改写任务分解。这把第 55 轮的“语义边界重分割”升级为**形态-动作联合重提议**：不仅问“你看对了吗”，还问“你以为的身体是这样吗”。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（可重构形态空间与形态距离）**
形态空间 `𝓜 = {m = (V_m, E_m, J_m)}`，每个形态给出关节空间 `Q_m`、正运动学 `φ_m: Q_m → SE(3)`、任务工作域 `W_m`、接触流形 `∂C_m` 与动力学 `f_m`。重构图 `G_M = (𝓜, E)`，边 `e=(m,m')` 携带转移时长 `τ_e`、能耗、转移成功率 `p_e` 与**可逆度** `r_e∈[0,1]`（`r_e=0` 表示不可逆）。形态距离
`d_M(m,m') = d_edit(m,m')/|E_m∪E_m'| + λ_W·d_H(W_m,W_m')/diam(W)`，
其中 `d_edit` 为图编辑距离、`d_H` 为工作域 Hausdorff 距离。该度量只需满足伪度量性质即可用于阈值判定。

**定义 128（VLA 的形态条件动作语义与接地缺陷）**
VLA 策略 `π_VLA: (o,ℓ) → (Φ(ℓ), m̂, â_{1:H})`，`m̂` 为形态 token 序列，`â` 为动作块。对参考形态 `m_ref` 定义接地算子 `Γ_{m'}: A → Ξ_{m'}`（把任务空间/关节 token 重定向到形态 `m'` 的轨迹）。接地缺陷
`δ_g(â,m') = sup_t [ d_task(Γ_{m'}(â)_t, Γ_{m_ref}(â)_t) + λ_J·1[关节/接触违约] ]`。
**接地 Lipschitz 假设 (A33)**：`δ_g(â,m') ≤ L_g·d_M(m',m_ref)·||â||_A`。

**定义 129（语言-形态可实现性）**
指令 `ℓ` 解析为时序约束 `Φ(ℓ)`（reach / grasp / avoid / through-gap / orient 等）。形态 `m` 的**语言可实现度**
`A_ℓ(m) = inf_{ξ∈Ξ_m} σ_{Φ(ℓ)}(ξ)`（用轨迹集合上的置信下界，而非均值）。语言可达形态集
`R(ℓ) = {m' | ∃ 从 m_0 出发的 G_M 路径, A_ℓ(m') ≥ θ_L}`。
若 `R(ℓ)=∅`，结论不是“选错形态”，而是**该语言任务在当前形态图内物理不可实现**，必须回问语言层改目标，而不是让 VLA 硬做。

**定义 130（转移核、可重构生存核与形态奇点）**
转移核 `K_trans(e) = {x | ∃u: τ_e 内完成转移 ∧ p_e(x) ≥ 1-ε_e ∧ x_{t+τ_e}∈K_R(m',Σ)}`。
可重构生存核定义为算子 `T` 的最大不动点：
`K_R(m,Σ) = {x | (∃u: x_{t+1}∈K_R(m,Σ) ∧ supp(λ)⊆C^+(Σ) ∧ x_{t+1}∈𝒳_safe) ∨ (∃e=(m,m'): x∈K_trans(e) ∧ post∈K_R(m',Σ))}`，
并要求每个 `K_R(m,Σ)` 含非空**回退集** `F_m`（安全制动/机械自锁）。转移中间态
`K_mid(e) = K_trans(e) \ (K_R(m,Σ) ∪ K_R(m',Σ))` 称为**形态奇点**，由转移控制器的不变式 `Inv_e` 单独守护，且 `Inv_e ⊆ K_trans(e)`。

**定义 131（重构承诺证书与承诺预算）**
`C_rec = (π_M, {margin_e}, δ_g^max, ρ_trans, commit, fallback)`：
- `π_M = m_0→m_1→…→m_k`，每条边 `margin_e = dist(x_pre, ∂K_trans(e))`；
- `δ_g^max = max_e δ_g(â,m_e)`，`ρ_trans = min_e p_e`；
- `commit = Σ_e (1-r_e)·w_e` 为不可逆性预算消耗，`w_e` 为任务关键度权重；
- `fallback` 为每步可回到的 `F_{m_e}`。
可部署当且仅当：`∀e, margin_e≥θ_e`，`δ_g^max≤δ_max`，`ρ_trans≥ρ_min`，`commit≤B_r`，且每个节点 `A_ℓ(m_e)≥θ_L`。

**定义 132（VLA-重构联合护盾）**
给定 VLA 提议 `(m̂,â)`，护盾求
`(m*,u*) = argmin_{m∈𝓜∪{m_0}} min_u [ ||â-Γ_m(â)||²_W + λ_c·d_M(m,m_0) + λ_r·commit(m_0→m) + λ_o·ΔV_opt(m) ]`
s.t. `x_{t+1}∈K_R(m,Σ)`、`supp(λ)⊆C^+(Σ)`、摩擦锥/关节限位、`C_rec` 有效。
若候选集为空：保持 `m_0`，执行最小风险制动并退入 `F_{m_0}`。护盾的时序原则是 **“先证转移，再许切换”**，绝不允许“先切换、后检验”。

## 2. 关键算法 伪代码

### IP-127 MAG（Morphology-Action Grounding）

```python
def morphology_action_grounding(o, l, pi_vla, M, m_ref):
    Phi, m_hat, a_hat = pi_vla(o, l)        # language constraints + untrusted proposal
    m_proj = project_to_manifold(m_hat, M)  # nearest legal morphology
    d = d_M(m_proj, m_ref)
    if d > theta_topo:
        return ('reject', 'topology_too_far', d)
    a_m = retarget(a_hat, m_ref, m_proj)
    if a_m is None:
        return ('reject', 'no_ik_under_target_morphology')
    delta_g = grounding_defect(a_hat, m_ref, m_proj)
    if delta_g > delta_max:
        return ('reject', 'grounding_budget_exceeded', delta_g)
    return m_proj, a_m, Phi, delta_g
```

### IP-128 MRT（Morphology Retargeting）

```python
def retarget(a_hat, m_ref, m_tgt, solver):
    xi, q_prev = [], None
    for a_t in a_hat:
        p_star, R_star = forward_task(m_ref, a_t)
        q = solver.ik(m_tgt, p_star, R_star, seed=q_prev)
        if q is None or violates_limits(m_tgt, q) or in_collision(m_tgt, q):
            return None
        xi.append(q); q_prev = q
    return xi
```

### IP-129 RCG（Reconfiguration Certificate Graph）

```python
def recon_certificate_graph(x0, m0, Sigma, goal, budgets):
    best = None
    for path in k_shortest_paths(G_M, m0, goal, K=budgets.K_path):
        x, margins, commit, ok = x0, [], 0.0, True
        for e in path_edges(path):
            if x not in K_trans(e):
                ok = False; break
            margins.append(distance_to_boundary(x, K_trans(e)))
            commit += (1 - r_e[e]) * w_e[e]
            x = transition_simulate(x, e)          # must land in K_R(m')
            if x not in K_R(e.head, Sigma):
                ok = False; break
        if not ok or commit > budgets.B_r:
            continue
        cert = Cert(path, margins, commit, rho_trans=min(p_e[e] for e in path_edges(path)))
        if best is None or cert.dominates(best):
            best = cert
    return best or ('reject', 'no_certified_reconfiguration')
```

### IP-130 RAS（Reconfiguration-Aware Shield）

```python
def reconfig_shield(a_hat, x, m0, M, Sigma, W):
    cands = []
    for m in [m0] + [m for m in M if d_M(m, m0) > 0]:
        if m is not m0:
            e = edge(m0, m)
            if e is None or x not in K_trans(e):
                continue
        a_m = retarget(a_hat, m0, m)
        if a_m is None:
            continue
        u = qp_solve(H=W, g=-W @ a_m,
                     constraints=[viability(x, u, K_R(m, Sigma)),
                                  contacts(u, C_plus(Sigma)),
                                  friction_cone(u, mu),
                                  joint_limit(u, m)])
        if u is not None:
            cost = (quad(u, a_m) + lambda_c * d_M(m, m0)
                    + lambda_r * commit(m0, m) + lambda_o * delta_option_value(m))
            cands.append((cost, m, u))
    if not cands:
        return safe_brake(x), m0, 'shield_infeasible'
    return min(cands, key=lambda t: t[0])
```

### IP-131 LMA（Language-Morphology Alignment）

```python
def language_morphology_alignment(Phi, M, monitor):
    feasible = []
    for m in M:
        lb = min(monitor.satisfaction_lower_bound(Phi, m, xi)
                 for xi in monitor.trajectory_ensemble(m))
        if lb >= theta_L:
            feasible.append((m, lb))
    if not feasible:
        return ('reject', 'language_unrealizable_in_M', Phi)
    return ('ok', feasible)
```

### IP-132 MRC（Morphology-Robustness Certificate）

```python
def morphology_robustness_certificate(plan, Sigma, eps_g, eps_e):
    rho_g = worst_case_grounding_success(plan, eps_g)
    rho_t = min(p_e[e] * transition_robustness(e, eps_e) for e in plan.edges)
    commit = sum((1 - r_e[e]) * w_e[e] for e in plan.edges)
    opt_loss = max(0.0, V_opt(plan.start) - V_opt(plan.goal))
    if rho_g < budgets.rho_min or rho_t < budgets.rho_min:
        return ('reject', 'morph_robustness_fail', rho_g, rho_t)
    if commit > budgets.B_r or opt_loss > budgets.delta_opt:
        return ('reject', 'commitment_budget_exceeded', commit, opt_loss)
    return ('ok', MRC(plan, rho_g, rho_t, commit, opt_loss, evidence=plan.evidence))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| MAG | O(\|A\|·IK + \|𝓜\|·d_M) | O(\|𝓜\|) | 形态流形投影、接地 Lipschitz 标定 |
| MRT | O(H·IK) | O(H·\|Q\|) | IK 可行或显式失败，碰撞/限位硬约束 |
| RCG | O(K·\|E\|·QP) | O(\|𝓜\|+\|E\|) | 转移核 sound、路径枚举覆盖、commit 可加 |
| RAS | O(\|𝓜\|·QP) | O(\|A\|) | 先证转移、QP 不可行即回退 |
| LMA | O(\|𝓜\|·\|Φ\|·N) | O(\|𝓜\|·N) | 下界而非均值、约束可监控 |
| MRC | O(\|π\|·N) | O(\|π\|) | 最坏情形可复现、预算闭合 |

**正确性定理（Morphology-Conditioned VLA Soundness）**
假设第 55 轮 (A29)–(A32) 与第 54 轮 (A26)–(A28) 成立；并假设 **(A33)** `d_M` 为伪度量且 `Γ` 满足接地 Lipschitz；**(A34)** 转移成功率 `p_e` 经分层校准，且 `Inv_e ⊆ K_trans(e)`；**(A35)** `Φ(ℓ)` 可由监控器判定，`A_ℓ` 采用下界；**(A36)** 云侧重提议延迟 `≤ τ_vla` 且重提议收敛。则部署后单步安全概率
```
P_safe ≥ 1 - P(δ_g > δ_max) - Σ_e P(transition e fails)
          - P(Φ monitor error) - P(K_out \ K_in ≠ ∅)
          - P(commit > B_r) - P(fallback fails)
```
任务成功概率另需 `P_success ≥ 1 - P(R(ℓ)=∅) - Σ_e P(fail_e) - P(δ_g>δ_max)`。
关键：**VLA 只提供语言约束与不可信提议；形态提议必须投影+接地+转移三重校验；不可逆性进预算；形态奇点由转移不变量而非形态核守护。**

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 形态空间组合爆炸、证书搜索慢 | 高 | 分层形态图 + 按需展开 + 转移核缓存 |
| 形态奇点超出所有形态核 | 高 | 转移控制器不变式 `Inv_e` + 机械自锁/限位 + 预演转移 |
| VLA 形态幻觉/训练形态偏置 | 高 | 形态 token 对齐 + 接地 Lipschitz 校验 + 反例回传重提议 |
| 不可逆承诺过度 | 高 | 选项价值惩罚 + 硬性 `commit ≤ B_r` + 最保守可行解 |
| 重构接触丰富的仿真-现实差 | 高 | 分层 `p_e` 校准 + 在线更新 + 转移保守裕度 |
| 语言任务在形态图内不可实现 | 中 | LMA 显式拒绝并回问语言层，禁止硬做 |

## 6. 本轮最大风险

**一句话**：VLA-重构体系把“语言先验”与“会变的身体”接在一起，但其 soundness 取决于**形态奇点是否被转移不变量真正守住、`p_e` 与接地 Lipschitz 是否跨形态校准、以及不可逆承诺是否被硬预算约束**；一旦转移中间态逃出所有 `K_R(m)` 而护盾仍按“自认为合法”的形态放行，系统就会被 VLA 的一步“合理提议”推进一个不可逆的形态奇点——因此必须以 **转移预演 + 机械兜底 + 承诺预算** 三重护栏，宁可停在当前形态，绝不把语言上的“能做”当作身体上的“可逆可做”。

# 第 56 轮产物 · 创新点清单 v32：ReconVLA-GroundEdge（MAG×MRT×RCG×RAS×LMA×MRC）

> 承接第 55 轮“语义-接触生存核”与第 54 轮产物 v31（GroundEdge-GenSim+++）。本轮把“身体固定”这一隐藏假设显式打破：VLA 给出的语言约束、形态提议与动作块统一进入一条 **提议—投影—接地—转移—承诺** 的验证链。
> 核心新增算子：
> - **MAG（Morphology-Action Grounding）**：把 VLA 形态 token 投影到合法形态流形，并计算动作块接地缺陷；
> - **MRT（Morphology Retargeting）**：训练形态 → 目标形态的任务空间重定向，失败显式返回而非静默退化；
> - **RCG（Reconfiguration Certificate Graph）**：在重构图 `G_M` 上搜索带转移裕度与回退的证书路径；
> - **RAS（Reconfiguration-Aware Shield）**：先证转移、再许切换的联合护盾，含承诺与选项价值惩罚；
> - **LMA（Language-Morphology Alignment）**：判定语言任务在当前形态图内是否物理可实现；
> - **MRC（Morphology-Robustness Certificate）**：接地鲁棒性 × 转移鲁棒性 × 承诺预算的联合证书。
>
> IP 编号：IP-127~IP-132（共 6 个新增）；升级第 55 轮 IP-121~126 的语义层，使其输出接入形态层。

## 1. 符号体系增量（新增定义 127–132）

| 符号 | 含义 |
|---|---|
| `𝓜 = {m=(V_m,E_m,J_m)}` | 可重构形态空间（拓扑/关节/模块） |
| `G_M=(𝓜,E)` | 重构图，边 `e=(m,m')` |
| `d_M(m,m')` | 形态距离 = 图编辑 + 工作域 Hausdorff |
| `r_e∈[0,1]` | 边可逆度，`r_e=0` 不可逆 |
| `π_VLA: (o,ℓ)→(Φ(ℓ),m̂,â)` | VLA 输出：语言约束 + 不可信形态/动作提议 |
| `Γ_{m'}` | 到形态 `m'` 的接地/重定向算子 |
| `δ_g(â,m')` | 接地缺陷（任务空间偏差 + 违约） |
| `A_ℓ(m)` | 形态 `m` 的语言可实现度（置信下界） |
| `R(ℓ)` | 语言可达形态集 |
| `K_trans(e)` | 转移核（转移可执行且落回目标核的前态集） |
| `K_mid(e)` | 形态奇点 = `K_trans \ (K_R(m)∪K_R(m'))` |
| `K_R(m,Σ)` | 可重构生存核（最大不动点） |
| `C_rec` | 重构承诺证书 `(π_M, margin, δ_g, ρ_trans, commit, fallback)` |
| `commit` | 不可逆预算 `Σ(1-r_e)w_e`，上限 `B_r` |
| `V_opt(m,x)` | 选项价值（仍可达的形态/任务集合度量） |

## 2. 关键算法 伪代码

### IP-127 MAG

```python
def morphology_action_grounding(o, l, pi_vla, M, m_ref, theta_topo, delta_max):
    Phi, m_hat, a_hat = pi_vla(o, l)
    m_proj = project_to_manifold(m_hat, M)
    d = d_M(m_proj, m_ref)
    if d > theta_topo:
        return ('reject', 'topology_too_far', d)
    a_m = retarget(a_hat, m_ref, m_proj)
    if a_m is None:
        return ('reject', 'no_ik_under_target_morphology')
    delta_g = grounding_defect(a_hat, m_ref, m_proj)
    if delta_g > delta_max:
        return ('reject', 'grounding_budget_exceeded', delta_g)
    return ('ok', m_proj, a_m, Phi, delta_g)
```

### IP-128 MRT

```python
def retarget(a_hat, m_ref, m_tgt, solver):
    xi, q_prev = [], None
    for a_t in a_hat:
        p_star, R_star = forward_task(m_ref, a_t)
        q = solver.ik(m_tgt, p_star, R_star, seed=q_prev)
        if q is None or violates_limits(m_tgt, q) or in_collision(m_tgt, q):
            return None
        xi.append(q); q_prev = q
    return xi
```

### IP-129 RCG

```python
def recon_certificate_graph(x0, m0, Sigma, goal, budgets):
    best = None
    for path in k_shortest_paths(G_M, m0, goal, K=budgets.K_path):
        x, margins, commit, ok = x0, [], 0.0, True
        for e in path_edges(path):
            if x not in K_trans(e):
                ok = False; break
            margins.append(distance_to_boundary(x, K_trans(e)))
            commit += (1 - r_e[e]) * w_e[e]
            x = transition_simulate(x, e)
            if x not in K_R(e.head, Sigma):
                ok = False; break
        if not ok or commit > budgets.B_r:
            continue
        cert = Cert(path, margins, commit,
                    rho_trans=min(p_e[e] for e in path_edges(path)),
                    fallback=[F_m for m in path])
        if best is None or cert.dominates(best):
            best = cert
    return best or ('reject', 'no_certified_reconfiguration')
```

### IP-130 RAS

```python
def reconfig_shield(a_hat, x, m0, M, Sigma, W):
    cands = []
    for m in [m0] + [m for m in M if d_M(m, m0) > 0]:
        if m is not m0:
            e = edge(m0, m)
            if e is None or x not in K_trans(e):
                continue
        a_m = retarget(a_hat, m0, m)
        if a_m is None:
            continue
        u = qp_solve(H=W, g=-W @ a_m,
                     constraints=[viability(x, u, K_R(m, Sigma)),
                                  contacts(u, C_plus(Sigma)),
                                  friction_cone(u, mu),
                                  joint_limit(u, m)])
        if u is not None:
            cost = (quad(u, a_m) + lambda_c * d_M(m, m0)
                    + lambda_r * commit(m0, m) + lambda_o * delta_option_value(m))
            cands.append((cost, m, u))
    if not cands:
        return safe_brake(x), m0, 'shield_infeasible'
    return min(cands, key=lambda t: t[0])
```

### IP-131 LMA

```python
def language_morphology_alignment(Phi, M, monitor):
    feasible = []
    for m in M:
        lb = min(monitor.satisfaction_lower_bound(Phi, m, xi)
                 for xi in monitor.trajectory_ensemble(m))
        if lb >= theta_L:
            feasible.append((m, lb))
    if not feasible:
        return ('reject', 'language_unrealizable_in_M', Phi)
    return ('ok', feasible)
```

### IP-132 MRC

```python
def morphology_robustness_certificate(plan, Sigma, eps_g, eps_e):
    rho_g = worst_case_grounding_success(plan, eps_g)
    rho_t = min(p_e[e] * transition_robustness(e, eps_e) for e in plan.edges)
    commit = sum((1 - r_e[e]) * w_e[e] for e in plan.edges)
    opt_loss = max(0.0, V_opt(plan.start) - V_opt(plan.goal))
    if rho_g < budgets.rho_min or rho_t < budgets.rho_min:
        return ('reject', 'morph_robustness_fail', rho_g, rho_t)
    if commit > budgets.B_r or opt_loss > budgets.delta_opt:
        return ('reject', 'commitment_budget_exceeded', commit, opt_loss)
    return ('ok', MRC(plan, rho_g, rho_t, commit, opt_loss, evidence=plan.evidence))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| MAG | O(\|A\|·IK + \|𝓜\|·d_M) | O(\|𝓜\|) | 形态投影合法、`δ_g` 上界可证 |
| MRT | O(H·IK) | O(H·\|Q\|) | IK/碰撞/限位硬约束，失败显式 |
| RCG | O(K·\|E\|·QP) | O(\|𝓜\|+\|E\|) | 转移核 sound、commit 可加、路径覆盖 |
| RAS | O(\|𝓜\|·QP) | O(\|A\|) | 先证转移、不可行即回退 |
| LMA | O(\|𝓜\|·\|Φ\|·N) | O(\|𝓜\|·N) | 用下界判定，语言不可实现显式拒绝 |
| MRC | O(\|π\|·N) | O(\|π\|) | 最坏情形可复现、三重预算闭合 |

**正确性定理（Morphology-Conditioned VLA Soundness）**
假设第 55 轮 (A29)–(A32) 与第 54 轮 (A26)–(A28) 成立；再加：
**(A33)** `d_M` 为伪度量，`Γ` 满足 `δ_g(â,m') ≤ L_g·d_M(m',m_ref)·||â||_A`；
**(A34)** 转移成功率 `p_e` 分层校准，`Inv_e ⊆ K_trans(e)`，且每个 `K_R(m)` 含非空回退集 `F_m`；
**(A35)** `Φ(ℓ)` 可监控且 `A_ℓ` 取轨迹集合下界；
**(A36)** 云侧重提议延迟 `≤ τ_vla` 且重提议收敛。
则部署后：
```
P_safe ≥ 1 - P(δ_g > δ_max) - Σ_e P(transition e fails)
          - P(Φ monitor error) - P(K_out \ K_in ≠ ∅)
          - P(commit > B_r) - P(fallback fails)
P_success ≥ 1 - P(R(ℓ)=∅) - Σ_e P(fail_e) - P(δ_g>δ_max)
```
关键：**语言只给约束、VLA 提议不可信、形态必须投影+接地+转移三重校验、不可逆性硬进预算、形态奇点由 `Inv_e` 而非任何单一形态核守护。**

## 6. 本轮最大风险

**一句话**：ReconVLA-GroundEdge 把“语言先验”与“会变的身体”接成一条可验证链，但其 soundness **三重依赖形态奇点被 `Inv_e` 真正守住、`p_e`/接地 Lipschitz 跨形态校准、以及不可逆承诺被硬预算约束**；一旦转移中间态逃出所有 `K_R(m)` 而护盾仍放行 VLA 的“合理提议”，系统就会被推进一个不可逆的形态奇点——因此必须坚持 **转移预演 + 机械兜底 + 承诺预算**，宁可停在当前形态，绝不把语言上的“能做”当作身体上的“可逆可做”。
