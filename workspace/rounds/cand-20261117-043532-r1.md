# 第 1 轮（UniBot 线 · 本轮灵感：「抓取」×「真实世界泛化」）· UniBot-TRACE：把「抓住没有」变成可泛化、可担保的物理量

> **承接与重基线**：上稿 UniBot-SAGE（「抓取 × 技能学习 × 地形适应」，定义 U1–U12 / 引理 L1–L7 / 实验 E601–E618）已把"抓握是隐变量"确立为主线，并自陈其**最大风险**：抓握伪标签依赖"抬起后物体随动"这一间接代理，在未见物品上分布漂移——**最需要它的泛化场景恰是它最不可信的地方**。本轮把两灵感的交集（**抓取 × 真实世界泛化**）作为唯一主攻方向，正面拆解该风险：以**共动标签（物理结果）**替代视觉启发式标签，以**因果不变表征**剥离场景混淆，以**无分布假设的风险控制**替代会漂移的固定阈值。旧编号封存；本线启用定义 **I1–I12**、引理 **R1–R8**、实验 **E901–E924**。

## 1. 直觉：先给画面，再给定义

### 1.1 灵感一「抓取」——泛化的抓手不是"物体身份"，而是"抓握余量"

想象蒙眼去抓桌上的一个物体。你不知道它是杯子、球还是瓶子，但你能靠**相对几何 + 闭合反馈**抓住它：手张得多大、从哪个面接近、物体在手心里是否随手动。人类跨物体泛化抓取，靠的不是"识别出这是什么"，而是"**开度−物宽余量 + 接近法向 + 质心偏移**"这几样**跨越物体类别仍然成立**的物理量。

第一性原理：**抓握成功是接触几何与摩擦的函数，不是物体语义的函数**。物体从"见过的杯子"换成"没见过的杯子"，语义变了，但"夹爪开度 5 cm、物宽 4 cm、接近面法向对齐、质心在两指中间"这套物理描述**没变**。所以抓取泛化的正确抽象，是把决策建立在**无量纲的抓握余量**上：
`m = (开度 − 物宽) / 物宽`、接近轴与局部法向的夹角 `α`、质心横向偏移比 `c`。
这三个量对背景、光照、纹理、任务身份**不变**，而对"能不能抓住"**充分**。这正是"笨办法"却最稳的地方。

**但单自由度夹爪加了一道硬约束**：有些抓法物理上不可能（拧盖、捏细线、插钥匙）。所以"抓取"的第一性原理还包含**可行性判定**：在 `m < 0` 或 `α` 超过摩擦锥允许角时，正确动作不是"更努力地抓"，而是换抓法或改用非抓取原语——这一点上稿已识别，本轮把它作为**不变的几何判据**继承下来。

### 1.2 灵感二「真实世界泛化」——泛化失败不是"见得太少"，而是"依赖了错的东西"

常见的默认假设是：泛化差 ⇒ 数据不够 ⇒ 加数据 / 加域随机化。但真实世界泛化失败的机制往往相反：模型**把场景里的伪相关当成了因果**。训练集里"红色杯子-木桌-某背景"总是成对出现，模型于是用背景/颜色去"认"物体；测试时背景一换，它依赖的那根支柱断了。

用一个更锋利的说法：**泛化不是让模型看得更多，而是让它对无关变化依赖得更少、对误差的担保更硬。** 前者是数据问题（已被所有队伍摊薄），后者是**归纳偏置 + 决策保证**问题（几乎无人系统做）。而这恰好可以在这个赛制里离线做、部署时零标签地用。

更进一步的跨学科直觉来自**选择性预测（selective prediction）与控制论的余量思想**：在支持不足（没见过这类物体几何）的地方，最诚实的策略不是"猜一个"，而是**弃权并原样执行基线**。弃权保证"不伤害"，而"猜"只保证"平均意义上也许不差"。对一个以成功率排名、且失败代价不对称（漏判=空夹爪跑到超时）的比赛，**"最坏情况等于基线"比"平均略好"更值钱**。

### 1.3 两灵感的合成：三重不变性 + 一层有界修复

把两个第一性原理拧在一起，得到一个**四段式**方案（UniBot-TRACE）：

1. **标签不变（label invariance）**：抓握真值由"物体是否随夹爪共动"这一**物理结果**给出，而非由"看起来像抓住"的视觉标注给出。这样标签在未见物体上**依然有效**，因为它只依赖运动学，不依赖物体身份。
2. **表征不变（representation invariance）**：只把**物理充分**的几何量（余量 `m`、对齐 `α`、偏心 `c`、以及它们的时序变化）喂给判定器，显式惩罚"能预测场景/背景"的信息。不变性只加在**干扰变量**上，绝不可加在**因果变量**（物宽、质量代理）上——这是本轮最容易做错、也最重要的一条。
3. **决策不变（decision invariance）**：不追求一个"好看的 AUROC"，而追求一个**无分布假设的风险上界**：在任意测试组上，把"误判为未抓住而乱介入"的比例控制在 `α` 以内；支持不足的组**直接弃权、原样走基线**。
4. **有界修复（bounded repair）**：对"真实世界泛化"的另一半——策略本身的抓取位姿在未见物体上偏移——用一个**局部抓握成功场**在很小的信赖域内修正位姿，且只在"预测提升超过校准误差"时才执行。修正幅度有界 ⇒ 最坏损失有界。

一句话：**TRACE 不给"更强的抓取器"，而给"在没见过的东西上不会乱来、且能被证明不会乱来"的抓取决策。**

### 1.4 直觉之后：把画面写成定义（完整形式见产物区 §3）

- **抓握结果** `Y∈{0,1}`：在抬起窗口内，物体相对夹爪位姿的**变化幅度**低于阈值且完成最小抬升，即为稳定抓握（I1）。
- **共动残差** `ρ`：抬起窗口内物体在夹爪坐标系中的位置标准差；`D` 为抬升位移（I2）。
- **充分不变表征** `Φ`：满足"`Y ⟂ 干扰环境 | Φ`"且"相对原始几何几乎不损失 `Y` 的信息"的表征（I3）。
- **抓握余量** `μ=(m, α, c)`：无量纲、跨物体类别成立的物理量（I5）。
- **选择性风险** `SR(λ)=P(Y=1 | 触发介入)`：**在真的抓住了却去介入**的条件概率——本轮唯一要求被担保的量（I9）。
- **风险受控阈值** `λ̂`：在标定集上用共形风险控制取到的最大阈值，使 `SR` 的置信上界 ≤ `α`（I10）。
- **安全弃权/直通** `PASS`：不介入时**逐位相同地**返回基线动作，保证最坏等于基线（I12）。

## 2. 瓶颈在哪里：从"看不见"转向"没支持"

上稿的量化结论仍然成立且本轮直接继承：计分近共线（只优化终态成功）；任务间专长近正交（技能路由有上界）；最难任务集中在插入/旋转/细粒度摆放（断点在最后一环）；时长无红利。**本轮不重复这些，而是把它们翻译成"泛化"的语言：**

| 上稿观测 | 泛化解读（本轮新增） | 推出的动作 |
|---|---|---|
| 最难任务 = 插入/旋转/细摆放 | 这些任务的成功强依赖**低余量**（`m→0`、`α→`摩擦锥边界）的抓握 | 决策必须**在低余量区弃权**，不能硬判（IP-13/14） |
| 抓握伪标签在未见物品上漂移 | 漂移集中在**低余量 + 低支持**区，正是最该判准的地方 | 标签改为**共动**（IP-11），并对共动不可辨的样本**弃权** |
| 跨任务专长近正交 | 泛化不是"一个更强的通用抓取"，而是"每类几何各有一档可靠的余量判据" | 余量特征 `μ` 做**几何条件化**，而非任务硬路由 |
| 计分只认终态成功 | 介入的收益必须落到"最后一环被完成"；**误介入的代价不对称** | 用**选择性风险**而非 AUROC 做验收（IP-14） |

**本轮的瓶颈判断（一句话）**：约束已经不在"抓握感知精度"（同分布下抓握成功率本就不低），而在**支持不足处的决策**——未见物体几何、极端位姿、遮挡/反光这些"低支持区"，正是视觉伪相关最诱人、伪标签最不可信、也最需要正确决策的地方。因此杠杆是**三重不变性**，而不是再堆一个更大的抓取检测器。

**一个示意性的代价账（假设值，非实测，仅用于说明为何要风险控制）**：设真实失败时重抓可回收 `g=0.35`，误介入造成不可恢复损失的期望 `ℓ=0.5`；则由引理 R2，介入净收益为正需 `SR < g/(g+ℓ) ≈ 0.41`；若掉落不可恢复（`ℓ≈0.9`），则需 `SR < 0.28`。**这说明"能不能介入"不该由拍脑袋阈值决定，而应由一个可校准、可担保的 `α` 决定**——这正是 IP-14 存在的理由。

## 3. 研究问题（本轮）

- **Q1（标签）**：在只有 1 维开度、无触觉、chunk 语义未声明的条件下，能否用"共动残差"造出**不依赖物体身份**的抓握标签，并把标签误差用几何量（`D/δ` 信噪比）**显式界定**，而不是假设它很小？
- **Q2（表征）**：能不能把"物理充分"与"场景不变"**分开检验**？即：既测"丢掉环境信息后掉多少抓握预测力"（充分性），又测"表征还能不能反推环境"（不变性），并给出一个可辩驳的判据？
- **Q3（决策）**：在 5 类偏移、且目标组可能**零标定数据**的情况下，能否给出**非渐近**的选择性风险上界？零支持组的诚实行为是什么（弃权还是带界先验）？
- **Q4（策略）**：对策略输出的抓取位姿做**有界修复**，能否在不伤害已成功抓握的前提下，提升未见物体上的成功率？"有界"能否给出可证的下降界？
- **Q5（工程与合规）**：这套东西能否塞进**单 checkpoint、单 API、同一 `get_action`**，不训练于评测反馈，且延迟仍在预算内、可一键回退到基线？

## 4. 设计原则（本轮生效）

- **A1 物理量优先于外观**：决策变量必须是可解释的几何/运动学量，外观只作为估计这些量的手段。
- **A2 标签即实验**：训练标签必须来自"闭合—抬升—观察"这一**干预结果**，而不是人工或启发式标注。
- **A3 不变性只给干扰**：不变性只能施加在 `E_nuis`（背景/光照/干扰物/纹理）上；对 `E_rel`（物宽、质量代理、摩擦代理）**必须敏感**，否则就是把因果信息一起扔掉。
- **A4 无支持即弃权**：无法标定、无法判定的组，原样返回基线动作；**弃权必须逐位直通**，不允许"顺手修一下"。
- **A5 担保优于点精度**：验收看风险上界与覆盖，不看单一 AUROC；宁可低召回，不可高误伤。
- **A6 单模型、单 API、可回退**：TRACE 是基线策略外面的一层**有界中间件**；任何模块失效都必须能退化为纯基线。

## 5. 最小可提交闭环（MVP）与退化链

**MVP = 基线 VLA + IP-11（共动标签）+ IP-13（几何/尺度）+ IP-14（风险门 + 安全直通）+ IP-16 的最小版（无标签偏移探测）**。
理由：这条链**不重训主干**，只用官方数据离线标定，就能验证"三重不变性"是否真的能在偏移下**不伤害**基线；这是信息价值最高、风险最低的一步。

**严格退化链（逐级回退，且每级都有客观判据）**：
- L0 偏移探测失效（无法判组）⇒ 退到**全局**风险标定（更保守）；
- L1 共动标签覆盖不足（多数样本弃权）⇒ 只用"高信噪比"子集标定，其余弃权；
- L2 尺度/立体不可用 ⇒ 退化为**仅开度比**的尺度不变特征（E906/E922 测损失）；
- L3 风险门失败（查表超时/权重发散）⇒ **全部弃权**（等于基线）；
- L4 任一环节异常 ⇒ **纯基线直通**（安全网，永远保留）。

## 6. 预期贡献（可验收）

1. **把抓握真值"去物体身份化"**：给出共动标签的构造、误差的几何界定（R1）、以及覆盖率—噪声曲线——这是对"伪标签在未见物体上漂移"的直接修复。
2. **提出并可检验的"充分不变性"判据**：把"泛化"拆成"丢环境后掉多少预测力（充分性）"与"表征还能否反推环境（不变性）"两个**可独立证伪**的量（R4、E903/E905）。
3. **把抓取决策从"点精度"升级为"风险担保"**：在 5 类偏移上给出选择性风险的分组覆盖保证，并明确零支持组的诚实行为（R3/R7）。
4. **有界的抓取位姿修复**，带可证的下降界（R5）与"最坏等于基线"的直通保证（R6）。
5. **一个可复用的偏移压力评测**：在官方数据上构造可控的 5 轴偏移切分 + 真机小样本锚点，使后续每轮不依赖真机时段即可排序。

## 7. 本轮最大风险

**一句话**：TRACE 的全部担保都是**条件担保**——它们只对"基线策略真的去尝试过的那一类抓握"成立；而在最需要泛化的未见物体上，恰恰是我们**没有交互支持**（基线根本没抓过这类几何），于是共动标签无覆盖、密度比无标定、风险门只能弃权——**它最诚实的结局是"证明自己不会更差"，而不是"证明自己会更好"**，一旦把"不可伤害"误读成"必然提升"，整条线的价值叙事就会崩塌。

## 0. 本轮结论摘要

**一句话路线**：把"抓取在真实世界能否泛化"重述为**三重不变性 + 一层有界修复**：
**标签不变**（共动结果，不依赖物体身份）→ **表征不变**（几何充分量，剥离场景伪相关）→ **决策不变**（无分布假设的选择性风险控制 + 安全弃权）→ **有界修复**（局部抓握成功场内的位姿微调）。

| 关键判断 | 依据（结构事实 / 演绎） | 推出的设计 |
|---|---|---|
| 抓握真值不能来自"看起来像抓住" | 手部仅 1 维开度、无触觉（接口事实） | **共动标签**（IP-11）：闭合—抬升—看物体是否随动 |
| 米制物宽与距离只能从立体 + 开度获得 | 观测无深度、无速度、无力（接口事实） | **几何/尺度层**（IP-13）：头部立体三角化 + 夹爪开度作尺子，退化到开度比 |
| 泛化失败常源于伪相关而非数据不足 | 归纳偏置可离线改、部署零标签可用 | **充分不变表征**（IP-12）：不变性只给 `E_nuis`，敏感度留给 `E_rel` |
| 失败代价不对称（漏判=空夹爪跑到超时） | 计分只认终态成功 + episode 有上限 | **非对称风险控制**（IP-14）：担保 `P(真抓住却介入) ≤ α` |
| 支持不足处任何"猜"都不可担保 | 无目标组标签时的不可识别性（R7） | **安全弃权/逐位直通**（I12）：最坏等于基线 |
| 策略位姿在未见物体上会偏 | 跨任务专长近正交（上稿） | **有界修复**（IP-15）：只在预测提升 > 校准误差时执行 |

**合规红线（继承 A6/P5）**：单 checkpoint、单 API；**不用评测反馈训练**；不做任务名硬编码分支；不读取评测侧私有信息；弃权时**逐位直通**基线动作。

## 2. 创新点详述

### IP-11 · CO-MOTION LABEL 共动标签 + 弃权区（P0）

- **动机**：上稿用"抬起后物体随臂运动"作为抓握代理标签，但没定义"怎么判、判错多严重、判不了的怎么办"。在未见物体上，外观贴合度会骗人（透明、反光、纹理贫乏），而**运动学共动**只依赖物理结果，天然不依赖物体身份。
- **与现有方案的差异**：现有抓取数据集多用"给定抓取矩形/位姿 + 成功标注"或仿真标签；我们直接用官方 32 个数据集的**自身交互轨迹**造标签，并用**几何信噪比**界定可辨性，不可辨即弃权（不污染训练）。
- **技术可行性**：高。观测有左右腕 RGB + 头部 stereo + 臂/EE 位姿 + 夹爪标量；闭合后抬升窗口内，物体在夹爪系中的位置应近似不变。
- **落地步骤**：①用头部立体对（或腕部单目 + 视差近似）逐帧估计物体质心 `x_o(t)`；②在夹爪系中算共动残差 `ρ`（I2）；③按 R1 的"分离集"规则打 0/1，其余弃权；④人工抽检 5% 估标签噪声；⑤输出覆盖率—噪声曲线，作为后续一切训练的**置信权重**。
- **风险**：①物体不可跟踪（透明/反光/出画）⇒ 弃权而非硬判；②柔性物/滑移使"刚性共动"假设失效 ⇒ 中间带一律弃权；③chunk 执行语义未知导致时间对齐错位 ⇒ 先复刻 `run_client` 语义再定窗口。

### IP-12 · GEO-INV 充分不变几何表征（P0）

- **动机**：真实世界泛化失败常因模型学到"背景/颜色→物体"的伪相关；本赛道 5 类偏移正好系统性地打这些伪相关。最有效的不是加数据，而是**只给它不会漂移的量**。
- **与现有方案的差异**：现有抓取检测（如 GG-CNN/GraspNet 类）以图像块回归抓取质量，靠大规模物体集覆盖来"期望"泛化；我们把**不变性当作显式约束**：惩罚表征里"可预测环境"的成分（环境对抗/GRL），同时用充分性检验确保没把因果信息扔掉（R4）。
- **技术可行性**：中–高。输入是 `μ`（余量/对齐/偏心）的时序 + 少量视觉残差；环境标签可由数据元信息（任务/场景/背景）或自动聚类得到。
- **落地步骤**：①构造环境分组 `E_nuis`（背景/光照/干扰物/相机位姿）与 `E_rel`（物宽/质量代理/摩擦代理）；②`Φ` 由几何特征 + 轻量视觉编码组成；③损失 `BCE(Y) + λ·CE(E_nuis)`（Gradient Reversal）+ `λ2·CE(E_rel)` 的**负**权重（即鼓励保留 `E_rel`）；④做"充分性—不变性"二维消融（E903/E905）；⑤固定 `Φ` 给 IP-14。
- **风险**：①不变性施加过强会连 `E_rel` 一起抹掉（R4 的直接后果）⇒ 必须显式保留因果变量；②环境标签本身有噪声 ⇒ 用弱监督 + 多组鲁棒聚合；③几何估计误差传导 ⇒ 给 `μ` 加噪训练。

### IP-13 · METRIC-MARGIN 尺度/余量提取（P0）

- **动机**：抓握的物理判据是**无量纲余量** `m=(a−w)/w`，不是像素宽度。没有米制，`m` 就无从谈起；而接口**无深度**，唯一米制线索是头部立体对与夹爪开度。
- **与现有方案的差异**：多数策略隐式地从图像学尺度，导致跨距离/跨物体尺寸的泛化脆弱；我们把尺度**显式**化，并把"夹爪开度当尺子"做自标定。
- **技术可行性**：中。若头部两路已标定同步，三角化即可；否则用"已知开度 `a` 时图像中夹爪视宽"反解尺度，或用单目尺度不变特征降级。
- **落地步骤**：①标定/验证头部立体对；②以夹爪开度为**参考尺**估计场景尺度；③估计物体可视宽度 `w` 与接近面法向，得 `m, α, c`；④做"米制 vs 仅开度比"的降级 A/B（E922）；⑤输出尺度置信度，低置信时降低不变性权重。
- **风险**：①立体标定缺失/不同步 ⇒ 降级到开度比（可接受但损失精度）；②遮挡下物宽低估 ⇒ 用多帧 + 腕部视角融合；③开度单位若非米制 ⇒ 只能做相对余量，需在 E906 明确。

### IP-14 · RISK-GATE 分组加权共形风险门（P0）

- **动机**：抓握误判代价不对称。一个"高 AUROC"的判定器，在偏移下校准可能整体漂移，恰好把"真抓住却介入"的比例抬高——这是最伤成绩的错误。要用**无分布假设、有限样本**的方式管住它。
- **与现有方案的差异**：现有做法是固定阈值 / 温度缩放 / 事后校准；我们做**选择性子集的风险控制**：目标不是全体错误率，而是"被介入子集里的假介入率"，并用加权共形处理协变量偏移。
- **技术可行性**：高–中。共形风险控制（CRC / Learn-then-Test）是成熟工具，计算量 O(n log n) 一次性；部署时只是阈值查表。
- **落地步骤**：①用 IP-11 标签构造标定集；②按 IP-16 的偏移族分组；③每组取 `λ̂_g` 使 `UCB_δ(SR_g) ≤ α`，样本不足回退全局，全局也不足则弃权；④协变量偏移下用密度比 `ŵ`（裁剪到 `[1/M,M]`）加权；⑤弃权时**逐位直通**基线（I12）；⑥审计导出每组 `λ̂`、样本量、覆盖上界。
- **风险**：①零支持组无担保（R7）⇒ 诚实弃权而非假装有保证；②权重估计不稳 ⇒ 强裁剪 + 回退全局；③标定集与测试集的偏移族划分不一致 ⇒ 用无标签探测而非任务名硬分。

### IP-15 · FIELD-REPAIR 有界抓握位姿修复（P1）

- **动机**：真实世界泛化的另一半是**策略本身**：VLA 在未见物体上给出的抓取位姿可能系统性偏移（偏前/偏侧/朝向不对）。与其重训大模型，不如在部署时做**小的、可信的**修正。
- **与现有方案的差异**：现有"grasp refinement"多在专用抓取系统里做全空间搜索；我们把它限制在**VLA 位姿附近的信赖域**内，并用共动数据学一个**局部成功场** `f(r,o)`，只在预测提升超过校准误差时执行（R5）。
- **技术可行性**：中。局部场可用小头或核回归；搜索空间小（位移 ≤ `δ`、旋转 ≤ `θ`）。
- **落地步骤**：①在共动标签上训练局部成功场；②采样小邻域候选；③输出 `r*` 当且仅当 `f(r*)−f(r0) ≥ γ` 且运动学/碰撞可行；④`δ,γ` 由 R5 与 E912/E913 标定；⑤失败即直通。
- **风险**：①成功场外推不可靠 ⇒ 信赖域小 + 保守 `γ`；②修复引入抖动 ⇒ 只在抓取相位触发一次；③与 IP-12 冲突（修复用到了可能漂移的特征）⇒ 成功场输入只用心跳几何量。

### IP-16 · SHIFT-PROBE 无标签偏移探测（P1）

- **动机**：IP-14 需要"组"，但测试时没有标签、也可能没有任务名。必须从**无标签观测**推断当前属于哪类偏移，并估计标定/测试密度比。
- **与现有方案的差异**：多数方案假设测试同分布或靠任务名；我们用域分类器 + 密度比，且**只用于选择标定组/权重**，不用于直接预测成功（避免新的伪相关）。
- **技术可行性**：中–高。域分类器在小特征上训练，成本低。
- **落地步骤**：①从 `Φ` 的**环境可预测部分**训练偏移族分类器；②用 `h/(1−h)` 估密度比并裁剪；③把族与权重喂给 IP-14；④监控漂移（族置信度低 ⇒ 回退全局/弃权）。
- **风险**：①域分类器本身学到伪相关 ⇒ 只用 AF 特征并做交叉验证；②偏移族与标定族不匹配 ⇒ 保守回退。

### IP-17 · SHIFT-FAILTAX 偏移感知失败分解（P1）

- **动机**：上稿六因子分解没有区分"哪种偏移打坏哪个因子"。区分开，才能把有限算力投到正确的因子。
- **与现有方案的差异**：把 5 类偏移 × 6 因子做成矩阵，定位"偏移—因子"交互，而不是只给一条总成功率。
- **技术可行性**：中。依赖 IP-11 的阶段/结果标签 + 代理评测。
- **落地步骤**：①按 5 类偏移构造可控切分；②复用六因子标注；③产出偏移×因子热图与 bootstrap 置信；④作为 IP-12/14/15 的排序器。
- **风险**：因子标签噪声 ⇒ 双标注 + 一致性门。

### IP-18 · PROV-AUDIT 标签/标定溯源审计（P2）

- **动机**：本方案的卖点是"担保"，担保必须**可复核**，否则只是口号。
- **与现有方案的差异**：多数提交只报成功率；我们把标签来源、覆盖率、噪声界、阈值、样本量、覆盖上界全部导出。
- **落地步骤**：①每个标签记录 `(episode, 窗口, ρ, D, 判定)`；②每个 `λ̂` 记录标定集、组、`α, δ, n`、权重裁剪；③导出审计包。
- **风险**：审计数据量 ⇒ 用摘要统计 + 哈希索引。

## 3. 符号与定义（I1–I12）

| 符号 | 含义 |
|---|---|
| `Y∈{0,1}` | 稳定抓握结果（闭合后经最小抬升仍保持） |
| `x_o(t), T_g(t)` | 物体质心、夹爪位姿 |
| `ρ, D` | 共动残差、抬升位移 |
| `E_nuis, E_rel` | 干扰环境（背景/光照/干扰物/相机位姿）、因果相关环境（物宽/质量代理/摩擦代理） |
| `Φ(·)` | 几何充分不变表征 |
| `μ=(m,α,c)` | 抓握余量、对齐角、偏心比 |
| `a, w` | 夹爪开度、物体可视宽度 |
| `f_θ(r,o)` | 局部抓握成功场（相对位姿 `r`） |
| `g(x)` | `P(Y=1|x)` 的估计（抓握置信） |
| `A_λ` | 介入集 `{x: g(x)<λ}` |
| `SR(λ)` | 选择性风险 `P(Y=1 | A_λ)` |
| `ŵ` | 标定/测试密度比估计 |

**定义 I1（稳定抓握结果）** `Y=1` 当且仅当：闭合时刻 `t_c` 之后存在抬升窗口 `τ=[t_c+τ_s, t_c+τ_e]`，在该窗口内 `‖Δ(T_g^{-1}x_o)‖ ≤ ε_ρ` 且抬升位移 `D ≥ D_min`；否则 `Y=0`。**`Y` 是物理结果，不涉及物体身份。**

**定义 I2（共动残差与共动标签）** `ρ(τ) = std_{t∈τ} ‖ W_g(t)^{-1} x_o(t) ‖`（`W_g(t)` 为夹爪系到世界系的变换）。标签 `ℓ`：
- `ℓ=1` 若 `ρ ≤ τ_ρ` 且 `D ≥ D_min`；
- `ℓ=0` 若物体在世界系近似静止（`‖Δx_o‖ ≤ ε_s`）且夹爪抬升 `D ≥ D_min`；
- 否则 `ℓ=⊥`（**弃权**，不入训练、不计指标）。

**定义 I3（充分不变表征）** `Φ` 满足：
(i) **不变性**：对任意 `e,e'∈E_nuis`，`|E[Y|Φ,e] − E[Y|Φ,e']| ≤ ε_inv`；
(ii) **充分性**：`I(Φ;Y) ≥ I(G;Y) − ε_suf`，其中 `G` 为原始几何+视觉特征。
记可行集 `𝔽(ε_inv,ε_suf)`。

**定义 I4（不变性—预测力目标）** `min_Φ  R_pred(Φ) + λ R_inv(Φ)`，其中 `R_pred` 为交叉熵/校准误差，`R_inv = max_{e,e'∈E_nuis} |E[ℓ|Φ,e] − E[ℓ|Φ,e']|`。**`E_rel` 不出现在 `R_inv` 中**（A3）。

**定义 I5（抓握余量）** `m=(a−w)/max(w,ε_w)`；`α = arccos⟨n_approach, n_surface⟩`；`c = |offset_lateral| / (w/2)`；`μ=(m,α,c)`。

**定义 I6（可抓性）** 给定最大开度 `A_max` 与摩擦锥半角 `α_max`：可抓当 `w ≤ A_max − 2δ_skin` 且 `α ≤ α_max`；否则输出非抓取原语 `Π`（推/扫/倾倒/钩）。

**定义 I7（局部抓握成功场）** `f_θ(r,o) ≈ P(Y=1 | r,o)`，只在共动标签上训练，输入只含 `Φ`（不引入会漂移的场景特征）。

**定义 I8（有界修复）** `r* = argmax_{r∈B_Σ(r0,δ), K(r)=1, C(r)=0} f_θ(r,o)`，其中 `K` 为运动学可达、`C` 为碰撞可行；仅当 `f_θ(r*)−f_θ(r0) ≥ γ` 时执行 `r*`，否则执行 `r0`。

**定义 I9（选择性风险）** `SR(λ) = E[ 1{Y=1} | x∈A_λ ]`；目标 `SR ≤ α`（`α` 为可容忍的"真抓住却介入"比例）。

**定义 I10（风险受控阈值）** `λ̂ = max{ λ : UCB_δ(SR(λ); D_cal, ŵ) ≤ α }`（共形风险控制/学习—检验；加权版见 R3）。

**定义 I11（偏移族与权重）** `h(x)→P(族|Φ_nuis(x))`；`ŵ(x)=h(x)/(1−h(x))` 裁剪到 `[1/M, M]`；组 `=argmax h`。

**定义 I12（安全弃权/直通）** 若 `n_g < n_min` 或 `λ̂` 不存在或任何异常，返回**基线动作的完全拷贝**（数值逐位一致），记 `abstain`；**禁止在弃权路径上做任何修改**。

        return ABSTAIN

# ===== IP-12：环境对抗 + 因果保留 =====
def train_phi(phi, data, lam_inv=0.3, lam_rel=0.3):
    for batch in data:
        z = phi.encode(batch.x)
        y_logit = phi.y_head(z)
        e_nuis_logit = grad_reverse(phi.e_nuis_head(z))   # 惩罚可预测干扰
        e_rel_logit = phi.e_rel_head(z)                    # 鼓励保留因果
        loss = bce(y_logit, batch.y) \
             + lam_inv * ce(e_nuis_logit, batch.e_nuis) \
             - lam_rel * ce(e_rel_logit, batch.e_rel)
        loss.backward()

def fit_risk_gate(scores, labels, groups, weights, alpha, delta):
    gates = {}
    for gname in set(groups):
        idx = [i for i, x in enumerate(groups) if x == gname]
        if len(idx) < N_MIN:
            gates[gname] = ("global",)            # 回退全局
            continue
        gates[gname] = crc_threshold(
            scores[idx], labels[idx], weights[idx], alpha, delta)
    return gates

def intervene(self, g, fam, w):

# ===== IP-15：有界位姿修复 =====
def bounded_repair(r0, geo, field, delta, gamma):
    best, best_f = None, field(r0, geo)
    for r in local_samples(r0, delta):
        if not kinematics_ok(r) or collides(r, geo):
            continue
        fr = field(r, geo)
        if fr > best_f:
            best, best_f = r, fr
    if best is None or (best_f - field(r0, geo)) < gamma:
        return None
    return best

## 5. 推导（引理 R1–R8）

**R1（共动标签的分离集与噪声界）** 设物体与夹爪位置逐帧误差各 ≤`δ`，抬升位移为 `D`（忽略旋转力臂，或把力臂项并入 `δ`）。
(a) 若刚性抓握成功，相对位姿为常量，估计变化 `ρ ≤ 2δ`；
(b) 若未抓住而物体在世界系静止，抬升后相对位移达 `≥ D − 2δ`，故 `ρ ≥ D − 2δ`。
取阈值 `τ_ρ ∈ (2δ, D−2δ)`，其存在的充要条件是 `D > 4δ`。在满足该条件的样本上标签**零误差**；否则（`D ≤ 4δ`）全部弃权。⇒ **标签噪声被几何信噪比 `D/δ` 显式控制，而非被假设很小。** ∎

**R2（介入的净收益与风险门条件）** 设介入集 `A` 的选择性风险 `r_A=P(Y=1|A) ≤ α`，真实失败时的回收增益期望 `g`，误介入的损失期望 `ℓ`。则介入带来的期望成功率变化
`Δ = P(A)·[(1−r_A)·g − r_A·ℓ] ≥ P(A)·[(1−α)·g − α·ℓ]`。
故 `Δ ≥ 0` 的充分条件为 `α < g/(g+ℓ)`。⇒ **把"要不要介入"从调参问题变成一个可核查的不等式。** ∎

**R3（协变量偏移下的加权共形覆盖）** 在协变量偏移且标定/测试可加权交换（weighted exchangeability）下，使用精确密度比 `w` 的加权共形风险控制给出 `P(SR(λ̂) ≤ α) ≥ 1−δ`。若 `ŵ` 的估计误差（总变差）为 `ε_w`，则风险上界相应膨胀 `O(ε_w)`；裁剪到 `[1/M,M]` 以控制方差。⇒ **零标签也能把风险担保"搬"到偏移组，但代价是权重误差项。** ∎（标准加权共形结论的推论。）

**R4（充分不变性的边界）** 若 `Φ` 关于 `Y` 充分（`Y ⟂ G | Φ`），则任何不减少 `I(Φ;Y)` 的不变性约束都保持 Bayes 最优抓握预测风险不变；反之，若对某个**因果变量**（如物宽、摩擦代理）施加不变性，则 `I(Φ;Y)` 严格下降、Bayes 风险严格上升。⇒ **不变性只能给 `E_nuis`；给 `E_rel` 等于自毁。** ∎

**R5（有界修复的下降界）** 设成功场误差 `|f_θ(r,o) − P(Y=1|r,o)| ≤ ε`。修复执行条件 `f_θ(r*) − f_θ(r0) ≥ γ`。则真实成功概率变化
`p(r*) − p(r0) ≥ [f_θ(r*)−f_θ(r0)] − 2ε ≥ γ − 2ε`。
又由信赖域 `‖r−r0‖≤δ` 与 `f` 的 Lipschitz 性，`|p(r*)−p(r0)| ≤ Lδ + 2ε`。
⇒ **取 `γ > 2ε` 即保证真实不下降；下降风险被 `δ` 与校准误差 `ε` 双重约束。** ∎

**R6（弃权即不伤害）** 若弃权路径返回基线动作的**完全拷贝**，则整条轨迹与基线逐位相同，成功率与基线**恒等**（不引入额外延迟的前提下）。⇒ **TRACE 的最坏情况是基线，而非更差。** ∎（前提：延迟不越界；见 E916 的延迟预算检查。）

**R7（零支持组的不可担保性）** 对任意抓握判定器，存在一个与标定集在 `Φ` 上**边缘同分布**、但 `P(Y|Φ)` 被反转的目标分布（标签偏移/对抗偏移），使任何基于标定集的阈值都无法保证 `SR ≤ α`。⇒ **在无目标组标签且无"有界密度比/协变量偏移"假设时，"担保"不可得；唯一诚实行为是弃权或带界先验。** ∎

**R8（成功场局部可辨识率）** 对 `d` 维局部邻域、带宽 `h` 的核/局部多项式估计，`N` 个样本的均方误差为 `O((Nh^d)^{-1} + h^4)`，最优带宽下 `O(N^{-4/(4+d)})`。⇒ **样本应优先采在"低余量、高不确定"区**，否则修复场的误差在未见区不可控。 ∎

## 11. 本轮最值得押注的创新点（一句话）

**押注 IP-14（风险门 + 安全直通），而不是 IP-12/IP-15 这类"让抓得更准"的模块：因为在真实世界泛化的赛场上，决定名次的往往不是"多抓对几个"，而是"少把本来能成的局搞砸"——一个能证明"最坏等于基线、且在高支持区确实能救回失败"的决策层，比任何精度提升都更稳、更可辩护。**

**本轮最大风险（一句话）**：所有担保都是**条件担保**——只对"基线真的尝试过的那类抓握"成立；在最需要泛化的未见几何上，交互支持趋近于零，标签无覆盖、权重无标定、风险门只能弃权，因此这条线最诚实的产物是"证明自己不会更差"，若把它误读为"必然更好"，价值叙事就会在最关键处坍塌。
