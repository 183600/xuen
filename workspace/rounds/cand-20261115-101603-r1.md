# 第 5 轮（灵感循环第 1 轮重启；本轮灵感：「动力学」×「多模态融合」）

> **基线**：第 4 轮 InstructGauge-WR（IP-328–333；定义 448–467；引理 59–62；实验 E457–E467）。第 3 轮 InstructGauge、第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。动力学与多模态融合各只升级一条轴；任一环节不可用都必须能一键退回 v4 的「几何-时空一致性」，再退回 v3 的「指令条件化分块」。两项增强都不是 v4 的依赖项。

## 0. 直觉与动机

**灵感 1（动力学：把「块内没有回执」改写成「块内有可被预测否决的轨迹管」）**

直觉：v4 的腕部相机 + TF 只能回答「几何上是否还在预期位姿附近」，回答不了「接触是否已经发生、力是否已经超限、系统是否已经进入另一条动力学分支」。而分块真正危险的不是位姿漂移，是**接触模式切换**：自由空间里 8 步开环通常没事，一旦碰到物体，同样的 8 步会把「轻触」变成「压碎」。动力学的价值不是再做一个更准的预测器去替代回执，而是给出一个**带误差管的预测轨迹**：只要真实多模态观测落在管外，就触发否决。这里有一条关键的认识论约束——**预测只能否决，不能放行**（one-sided veto）：预测命中不增加信任，预测失配才触发截断；否则模型偏差会变成虚假的安全感。

严谨化的方向：把机器人-物体-环境写成混合动力学系统 `(X, U, Q, f_q, G, R)`，`q ∈ Q` 是接触模式；用参数区间/集成模型给出一步过近似 `f̂_q`，沿块滚动得到轨迹管 `T_0 … T_K`；把观测建模为集合 `U_t^⊕`，定义「观测集与预测管不相交」为硬违背。再用**收缩性**把「块长」变成可计算的量：若模式内误差满足 `‖e_{t+1}‖ ≤ ρ‖e_t‖ + w`，则 K 步后误差有闭式上界；给定安全阈值 `ε_safe`，可解出 `K_safe`，再扣除检测延迟 `L` 得到 `K_eff`。这把 v3 的「块长 = 证据陈旧窗口」从定性风险变成一个可校准的预算。

**灵感 2（多模态融合：不是平均，而是校准不确定性集合的交集）**

直觉：视觉、关节编码器、触觉、力矩、音频的失效模式不同：遮挡打瞎视觉，反光骗过深度，但触觉和力矩仍能感知接触；网络抖动会同时延迟 ROS 话题，却不会伪造接触事件。朴素的加权平均会把一个坏模态的偏差摊进所有模态，还会在模态冲突时给出「看起来很小」的方差。正确做法是把每个模态的输出看成**经共形校准的不确定性集合**，融合即求这些集合的**最小外接球（Chebyshev 中心）**；交集为空就是显式的「模态冲突」，必须降级而不是硬融合。再叠加**事件时间三角定位**：接触切换在触觉 / 音频 / 力矩上留下不同延迟的瞬态，用区间交集估计切换时刻，比任何单模态都更早、更可审计。

严谨化的方向：对每个模态 `m` 与接触模式层 `q` 分别做共形校准，得到半径 `ε_m(α, τ_m)`，其中 `τ_m` 是消息时延，半径随时延膨胀（陈旧感知）；融合集 `U^⊕ = ∩_m U_m`，其半径即「融合残差」。若 `U^⊕ = ∅`，返回冲突而不是伪造一个折中点；若共享链路（ROS 心跳、供电、时钟）异常，则对所有半径乘以共同原因膨胀因子 `γ`。覆盖保证用并集界 `1 − Σα_m`，它不要求模态独立，因此对相关失效仍然成立，只是会偏保守。

**灵感 3（耦合：接触模式屏障，把「动力学放大」压成「模式同质块」）**

直觉：动力学与融合最危险的耦合，是「融合把一次接触误判成自由空间」+「长块继续开环执行」。解法不是禁用分块，而是要求每个块在**预测的接触模式上是同质的**：块内只要可能跨过一次 guard（接触 / 脱离 / 滑移），就强制在该 guard 前切开，跨 guard 的那一步退化为 `K=1` 并要求独立回执交叉验证。这与 v3 的不可逆屏障同构：不可逆动作不被分块捆绑，**模式切换也不被分块捆绑**。由此，动力学的放大效应被限制在单一模式内，而单一模式内可以用收缩性给出可计算的块长上界。

严谨化的方向：定义「模式同质块」为块内所有步的预测模式相同、且 guard 穿越概率低于阈值；定义「接触模式屏障」为跨 guard 强制单步 + 独立回执。屏障不是新增的物理约束，而是把 v4 的「不可逆屏障」从**材料不可逆性**推广到**动力学分支不可逆性**：一旦进入接触/滑移分支，后续动作的代价结构已经改变，必须用新回执重新决策。

## 1. 研究问题（本轮要回答什么）

- **Q1（动力学的可证伪性）**：动力学预测能否成为安全的否决信号，而不是新的幻觉来源？在模型失配、接触参数未知时，什么条件下「预测失配 ⇒ 截断」是可靠的？
- **Q2（融合的校准与冲突）**：多模态融合怎样在遮挡、延迟、相关失效下保持覆盖保证，并把「模态冲突」显式暴露，而不是平均成一个虚假的高置信估计？
- **Q3（耦合的安全边界）**：块长能否由收缩率、扰动界与检测延迟共同界定？接触模式屏障能否把「一次误判放大成 K 步不可逆动作」压回到单步？

## 2. 三条设计原则（雏形，正式化见产物区定义 468–487）

**P4 预测只否决（One-Sided Predictive Veto）**

动力学预测不得用于放行或延长块长，只允许在「观测落在预测管外」或「预测模式与观测模式不一致」时触发截断。形式化方向：否决是一个适应于观测流的停时；未触发时证书只记录「未发现反证」，不提升任何信任等级。这样即使模型有偏，最坏后果是保守截断，而不是虚假放行。

**P5 校准交集融合（Calibrated Intersection Fusion）**

每个模态先独立校准成不确定性集合，再做交集；交集为空即冲突，必须显式降级。形式化方向：`U^⊕ = ∩_m U_m`，融合估计取 Chebyshev 中心，融合残差取集合半径；共同原因异常时用膨胀因子 `γ` 保守化。覆盖用并集界，不依赖模态独立性。

**P6 模式同质分块 + 接触模式屏障（Mode-Homogeneous Chunking）**

一个块只能停留在单一预测接触模式内；预测跨 guard 时必须切开，跨 guard 的那一步强制 `K=1` 并要求独立回执。形式化方向：块的模式轨迹 `q_0 … q_K` 必须常值且 guard 穿越概率低于阈值；否则在首个 guard 前截断，屏障后的动作只走单步路径。

## 3. 与基线的接口（如何退化）

- 动力学模型 / 残差监控不可用，或收缩证书无法校准 ⇒ `K_eff = 1`，并退回 v4 `SpatialCert` 的纯几何一致性；
- 多模态融合缺失、冲突或共同原因告警 ⇒ 逐模态剔除，最差只剩腕部相机 ⇒ 退回 v4 单模态时空一致性；
- 接触模式证据不足或预测跨 guard ⇒ 强制 `K=1`，退回 v3 的不可逆屏障语义；
- 分层共形样本不足 ⇒ 退回全局阈值或保守固定半径；
- v4 失效 ⇒ v3 InstructGauge；v3 失效 ⇒ ToolGauge；ToolGauge 失效 ⇒ LeanGauge 纯数值路径；LeanGauge 失效 ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个**单侧预测否决**口径：动力学模型只负责「找反证」，不负责「发通行证」，把模型偏差的后果限制为保守截断；
2. 一个**校准交集融合**算子：把多模态从加权平均改成不确定性集合交集 + Chebyshev 中心，并显式输出模态冲突与共同原因告警；
3. 一个**收缩-时延联合块长界**：`K_safe` 由 `(ρ, w, ε_safe)` 解出，再扣除反应滞后 `L` 得到 `K_eff`，使「分块放大误差」成为可计算、可预注册的预算；
4. 一个**接触模式屏障**：把 v3 的不可逆屏障推广到动力学分支切换，使块内模式切换不被分块捆绑；
5. 一条完整可证伪路径：E468–E483 覆盖残差检测、收缩覆盖、融合覆盖、模式切换、预测否决、遮挡 / 延迟 / 相关失效、sim-to-real 与 50Hz 时序保全。

## 5. 本轮最大风险

**一句话**：多模态校准与动力学管都建立在「模态各自可校准、模型管能过近似真实动力学」的前提上，而真实系统最常见的失效恰恰是**相关失效 + 接触参数漂移**——一旦共同原因让多个模态同时偏、或接触模式在管外悄悄切换，融合会给出「交集非空」的虚假一致，长块仍可能把一次漏检放大成 K 步物理动作。

## 2. 形式化定义

**定义 468（混合接触动力学模型）**
系统为带 guard 的混合系统
```
x_{t+1} = f_{q_t}(x_t, u_t) + w_t,   w_t ∈ W,
q_{t+1} = R_{q_t→q'}(x_t, u_t)  若 (x_t, u_t) ∈ G_{q_t→q'}。
```
用参数区间或集成模型得到一步过近似 `f̂_q`，满足
```
f_q(T, u) ⊆ f̂_q(T, u) ⊕ W,   ∀T ⊆ X。
```
这是后面「预测管」与「单侧否决」的可靠性前提（假设 A1）。

**定义 469（多模态观测束）**
```
O_t = {(y_t^m, t − τ_m, σ_m)}_{m∈M},
y_t^m = h_m(x_t) + v_m,   m ∈ M = {vis, prop, tac, ft, aud, depth}。
```
`τ_m` 为消息时延，`σ_m ∈ {ok, degraded, lost}` 为健康标记。有效时延 `τ_eff = max_m τ_m`；融合与残差计算只能使用 `t − τ_eff` 之前已到达的观测。

**定义 470（陈旧感知分层共形集）**
对每个模态 `m` 与模式层 `q`，用校准分数 `s_i^m = ‖y_i^m − ŷ_i^m‖_{Σ_m^{-1}}` 得到分位数 `ε_m(α)`。时延为 `τ` 时半径膨胀为
```
ε_m(α, τ) = ε_m(α) + λ_m · τ,   λ_m ≥ 0，
U_t^m(α) = { y : ‖y − ŷ_t^m‖_{Σ_m^{-1}} ≤ ε_m(α, τ_m) }。
```
`λ_m` 由分块共形 / 自适应共形推断（ACI）在线估计，以应对时延与分布漂移。覆盖目标为 `P(y_t^m ∈ U_t^m) ≥ 1 − α_m`。

**定义 471（校准交集融合）**
```
U_t^⊕ = ∩_{m: σ_m = ok} U_t^m。
```
若 `U_t^⊕ = ∅`，返回 **Conflict**，不产生折中点，并降级到可用单模态。若 `U_t^⊕ ≠ ∅`，取
```
ŷ_t^⊕ = ChebyshevCenter(U_t^⊕),   r_t^⊕ = ChebyshevRadius(U_t^⊕)。
```
共同原因监控 `c_t`（ROS 心跳、时钟偏移、供电、共享总线延迟）触发时，对所有 `ε_m` 乘 `γ > 1` 后再求交，记 `common_mode_flag = 1`。

**定义 472（动力学残差与硬违背）**
设预测管截面 `T_t`，其观测像为 `H_m(T_t)`。定义
```
r_t^dyn = d_H( U_t^⊕, ∩_m H_m(T_t) ) / ( rad(T_t) + rad(U_t^⊕) + δ ),
hard_violation(t) ⇔ U_t^⊕ ∩ ( ∩_m H_m(T_t) ) = ∅。
```
`d_H` 为 Hausdorff 距离，`δ > 0` 为数值正则项。`hard_violation` 是唯一致命的动力学信号；`r_t^dyn` 只用于排序与告警，不单独放行。

**定义 473（收缩证书）**
在模式 `q` 内，若误差 `e_t = x_t − x̂_t` 满足
```
‖e_{t+1}‖ ≤ ρ_q ‖e_t‖ + w_q,   ρ_q < 1，
```
称 `(ρ_q, w_q)` 为收缩证书。`ρ_q, w_q` 不取点估计，而取校准集上的共形上界 `(ρ̂_q, ŵ_q)`，置信度 `1 − β`。若 `ρ̂_q ≥ 1`，该模式视为**非收缩**，直接 `K_safe = 1`。

**定义 474（有效安全块长）**
给定安全阈值 `ε_safe > 0`，定义
```
K_safe = max{ K ≥ 1 : ρ̂_q^K ‖e_0‖ + ŵ_q (1 − ρ̂_q^K)/(1 − ρ̂_q) ≤ ε_safe }。
```
再扣除反应滞后
```
L = ⌈τ_eff / Δt⌉ + L_fuse,   K_eff = max(1, K_safe − L)。
```
直观：若第 `t` 步发生违背，观测最早在 `t + L` 才可用于否决；因此证书只能覆盖 `K_eff` 步，剩余 `L` 步是「检测盲区」，必须靠更短的块或屏障消除。

**定义 475（DynaCert 动力学一致性证书）**
```
DynaCert(C) = (T_seq, U^⊕_seq, q_trace, {r_t^dyn}, hard_violations,
               (ρ̂_q, ŵ_q), K_safe, L, K_eff, common_mode_flags, mode_evidence)。
```
v4 的 `SpatialCert` 是 `DynaCert` 在「只保留几何分量、关闭动力学与模式分量」时的投影。

**定义 476（接触模式证据与切换时刻三角定位）**
每个模态 `m` 的事件检测器给出切换时刻区间 `I_m = [t_m^-, t_m^+]`（触觉起始、力矩阶跃、音频瞬态、视觉接触）。融合证据为
```
I^⊕ = ∩_{m: σ_m = ok} I_m。
```
若 `I^⊕ ≠ ∅`，取其中点作为切换估计，`|I^⊕|` 为不确定度；若 `I^⊕ = ∅` 或 `|I^⊕| > δ_mode`，记 **mode_ambiguous = 1**。模式证据 `κ_t(q)` 为各模态对模式 `q` 的校准似然的鲁棒聚合（中位数 / 截尾均值），不使用未校准的 softmax。

**定义 477（模式同质块与接触模式屏障）**
块 `C = (a_1 … a_K)` 模式同质，当且仅当
```
ModeHomog(C) ⇔ (∀t ∈ [1,K], argmax_q κ_t(q) = q_0) ∧ (∀t, Pr[G_{q_0→q'}(x_t,a_t)] < δ_guard)。
```
屏障规则：若 `¬ModeHomog(C)`，在首个「预测 guard 穿越概率 ≥ δ_guard」的步骤之前截断；跨 guard 的那一步强制 `K=1`，并要求 `tac` 与 `ft` 的独立回执交叉验证通过后才允许继续。跨不可逆动作时，v3 的不可逆屏障继续优先于本规则。

**定义 478（单侧预测否决）**
```
Veto(t) ⇔ hard_violation(t) ∨ mode_ambiguous(t) ∨ (argmax_q κ_t(q) ≠ q_0)。
```
否决只产生截断 `C ← C.truncate(t−1)`，不产生「延长块」「降低阈值」「提升信任」三种动作。形式化地，`Veto` 是适应于已到达观测流的停时；未触发时证书状态只记 `no_counterexample`，信任等级不高于 v4 基线。

**定义 479（DynaFuse-7C 闭环）**
```
W（接地）→ R（假设）→ C（模式同质分块）→ E（执行）
        → D/M（动力学残差 + 模式否决）→ S（SpatialCert 复核）→ U（绑定主张）
```
相对 v4 的 WRC-ROS-7C，新链路插在 `E` 与 `Spatial-C` 之间；`W/R/C` 与 50Hz 主路径不变，新增计算异步完成，主循环只读取最近一次已认证结果。

**定义 480（退化映射）**
```
关 DRM            → DynaCert 的动力学分量置空，SpatialCert 原样       = v4
关 CMF            → 只用 wrist_cam 单模态，等价 v4 时空一致性           = v4
ρ̂ ≥ 1 或 CHP 失校 → K_eff = 1，逐步执行                               = v3
关 CMB            → 仅保留 v3 不可逆屏障                               = v3
关 DynaFuse-7C    → WRC-ROS-7C                                        = v4
```

# IP-334 Dynamics-Residual Monitor
class DynamicsResidualMonitor:
    def __init__(self, model, W, eps_safe, dt):
        self.model, self.W = model, W
        self.eps_safe, self.dt = eps_safe, dt

    def rollout_tube(self, x_interval, actions, mode):
        T = [x_interval]
        for a in actions:
            T.append(minkowski(self.model.f_hat[mode](T[-1], a), self.W))
        return T

    def residual(self, fused_set, tube, mode):
        image = intersect_all([self.model.h[m](tube) for m in fused_set.modalities])
        if is_empty(intersect(fused_set.region, image)):
            return float("inf"), True          # hard violation
        d = hausdorff(fused_set.region, image)
        scale = radius(tube) + fused_set.radius + 1e-9
        return d / scale, False

# IP-335 Calibrated-Multimodal Fusion
class CalibratedMultimodalFusion:
    def __init__(self, alpha, lambda_stale, common_mode_monitor):
        self.alpha, self.lam = alpha, lambda_stale
        self.cm = common_mode_monitor

    def calibrated_set(self, m, y, tau):
        eps = self.quantile[m] + self.lam[m] * tau
        return Ball(y, eps)

    def fuse(self, obs, t):
        sets = [self.calibrated_set(m, y, tau)
                for m, (y, tau, health) in obs.items() if health == "ok"]
        if not sets:
            return None, Conflict(reason="all_modalities_lost")
        if self.cm.triggered(t):
            sets = [inflate(s, self.cm.gamma) for s in sets]
        inter = intersect_all(sets)
        if is_empty(inter):
            return None, Conflict(reason="empty_intersection")
        return Fused(region=inter,
                     center=chebyshev_center(inter),
                     radius=chebyshev_radius(inter),
                     modalities=len(sets),
                     common_mode=self.cm.triggered(t)), None

# IP-336 Contraction-Horizon Planner
def effective_horizon(e0, rho_hat, w_hat, eps_safe, tau_eff, dt,
                      L_fuse=1, K_cap=64):
    if rho_hat >= 1.0:
        return 1
    L = int(math.ceil(tau_eff / dt)) + L_fuse
    K = 1
    while K <= K_cap:
        bound = rho_hat**K * e0 + w_hat * (1 - rho_hat**K) / (1 - rho_hat)
        if bound > eps_safe:
            break
        K += 1
    return max(1, min(K_cap, K - 1 - L))

# IP-337 Contact-Mode Barrier
class ContactModeBarrier:
    def split_at_guard(self, C, mode):
        for t, (a, prob) in enumerate(self.guard_probs(C, mode)):
            if prob >= self.delta_guard:
                return C.truncate(t), t
        return C, None

    def mode_changed(self, fused, t):
        return self.evidence.argmax(t) != self.evidence.baseline_mode

    def require_single_step(self):
        self.force_K1_until_receipt = True

# IP-338/339 DynaFuse-7C 主闭环
def dynamicsgauge_round(M, s, ell=None):
    # 1) v4：接地 + 假设
    iota = M.nlib.ground(ell, M.scene, M.ontology) if ell else M.default_iota
    H = M.lbox.hypothesize(s, M.dbox.R[s], iota)

    # 2) 收缩块长 + 模式同质分块
    rho, w = M.dyn.certified_contraction(M.env.mode())
    K_eff = effective_horizon(M.err0, rho, w, M.eps_safe,
                              M.fusion.tau_eff(), M.dt)
    C = M.iac.plan_chunk(iota, H, M.tools,
                         K=min(M.budget_left(s), K_eff),
                         drift_bound=M.drift_bound(s))
    C, guard = M.cmb.split_at_guard(C, M.env.mode())

    # 3) v4 刚体前缀封闭复核；失败退 K=1
    if not M.kloop.verify_prefix_closed(C)[0]:
        C = M.iac.plan_chunk(iota, H, M.tools, 1, M.drift_bound(s))

    # 4) 预测管（只用于否决）
    tube = M.dyn.rollout_tube(M.state_interval(), C.actions, M.env.mode())
    dyn_violations, mode_trace = [], []

    # 5) 执行：v4 检查 + 动力学/模式单侧否决
    for t, a in enumerate(C.actions):
        if not M.cvc.joint_pre(a) or not still_grounded(iota, M.env):
            break
        if not M.spatial_ok(a):                  # v4 SpatialCert
            break
        M.env.apply(a)
        mode_trace.append(M.env.mode())

        fused, conflict = M.fusion.fuse(M.observe(), M.env.time())
        if conflict is not None:
            C = C.truncate(t)                    # 显式降级，不硬融合
            break
        r_dyn, hard = M.dyn.residual(fused, tube[t + 1], M.env.mode())
        if hard or r_dyn > M.r_dyn_threshold:
            dyn_violations.append(t)
            C = C.truncate(t)                    # Veto(t)
            break
        if M.cmb.mode_changed(fused, t) or M.cmb.guard_imminent(tube, t):
            C = C.truncate(t)                    # 接触模式屏障
            M.cmb.require_single_step()
            break

    # 6) DynaCert + v4 SpatialCert
    spatial_cert = generate_spatial_cert(C, M.wristcam.get_spatial_trajectory(
        M.env.time(), M.env.time() + C.duration()), M.epsilon_vis)
    dyn_cert = DynaCert(tube=tube, fused_trace=M.fusion.trace,
                        mode_trace=mode_trace, residuals=M.dyn.trace,
                        violations=dyn_violations, rho=rho, w=w,
                        K_safe=K_eff + int(math.ceil(M.fusion.tau_eff()/M.dt)) + 1,
                        K_eff=K_eff, common_mode=M.fusion.cm.flags)

    # 7) ROS 声明式发布（沿用 v4 消息，新增 DynaCert 字段）
    M.ros_cvc.publish_cvc(C.id, len(C.actions), C.actions,
                          C.pre_conditions, C.post_conditions,
                          [spatial_cert], dyn_cert)

    # 8) 绑定主张
    claims = bind_claims(C, iota, M.tcv.get_receipts(), dyn_cert)
    return C, spatial_cert, dyn_cert, claims

## 4. 推导

**引理 63（交集融合的覆盖下界）** 若对每个可用模态 `m` 有 `P(y_t^m ∉ U_t^m) ≤ α_m`，则
```
P(y_t ∉ U_t^⊕) ≤ Σ_m α_m，
```
与模态间是否独立无关；当共同原因监控触发、半径乘 `γ` 后，覆盖下界仍成立（半径更大，失效概率不增）。

*证明*：`y_t ∉ ∩_m U_t^m ⇔ ∃m, y_t ∉ U_t^m`，对并集用次可加性即得；放大半径只会使每个 `U_t^m` 变大，事件 `{y_t ∉ U_t^m}` 不增。

**引理 64（收缩块长的误差上界）** 若 `‖e_{t+1}‖ ≤ ρ‖e_t‖ + w` 且 `ρ < 1`，则
```
‖e_K‖ ≤ ρ^K ‖e_0‖ + w (1 − ρ^K)/(1 − ρ)。
```
因此 `K_safe` 可由闭式上界反解；`K_safe` 关于 `ρ`、`w` 单调不增，关于 `ε_safe` 单调不减。

*证明*：对递推式展开并求几何级数和；单调性由偏导符号直接得到。

**引理 65（反应滞后修正）** 若第 `t` 步的违背最早在 `t + L` 才被否决，则在 `K_eff = max(1, K_safe − L)` 的块上，任何已执行步都落在证书覆盖范围内。

*证明*：从 `t` 到 `t+L` 共执行 `L` 步开环；若块长不超过 `K_safe − L`，则违背发生时证书仍覆盖到 `t+L`，故不存在「已执行但未被证书覆盖」的步。若 `K_safe ≤ L`，只能 `K_eff = 1`。

**引理 66（模式屏障的单步约束）** 若真实模式切换发生在块内第 `t_g` 步，且至少一个健康模态在 `t_g + 1` 之前给出非空事件区间，则屏障在 `t_g` 之后至多执行一个新模式动作；若切换不可检测（所有 `I_m` 为空），则无此保证。

*证明*：检测到切换即触发 `Veto`，截断到最后已认证前缀；`K=1` 要求独立回执，故新模式动作不超过一步。不可检测情形下 `Veto` 不触发，反例成立，故必须把可检测性作为假设 A2 显式写出。

**引理 67（退化等价性）** 关闭 DRM 时 `DynaCert` 的动力学分量为空，`hard_violation ≡ false`，`Veto` 只剩 v4 几何一致性；关闭 CMF 时融合退化为腕部相机单模态，与 v4 定义 448 的 `spatial_consistency` 相同；`ρ̂ ≥ 1` 时 `K_eff = 1`，与 v3 逐步执行逐字等价。

*证明*：逐项代入定义 475、471、474 与 480 即得。

**命题 68（非保证的边界）** 引理 63–67 的可靠性依赖 A1（预测管过近似）与 A2（模式切换可检测）。若 A1 被违反，`hard_violation` 可能漏报；若 A2 被违反，模式屏障可能不触发。二者都是**可证伪假设**，必须在实验中单独检验，而不能由上述引理自动继承。

## 8. 本轮最大风险

**一句话**：整套增强把可靠性押在「预测管确实过近似真实动力学」和「模态失效可被健康标记/共同原因监控捕获」这两个假设上，而接触参数漂移与共享链路的相关失效会同时破坏二者——一旦漏检的模式切换发生在长块内，融合的「非空交集」会伪装成一致性，把一次误判放大成 K 步已执行的物理动作。
