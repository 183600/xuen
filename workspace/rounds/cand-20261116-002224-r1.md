# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「可靠性」×「柔顺控制」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**可靠标定 + 无源柔顺 + 单调退化**。两个灵感治理 v9 的两处结构性缺口：(1) v9 的块证书把安全寄托在确定性假设 ‖F̂−F‖∞ ≤ β 上，β 靠经验误差 ×1.2 拍定，且默认"通道越多越安全"，忽视安全通道共享传感器/动力学导致的**共因失效**——「保证债」；(2) v9 的五级退化全在计算域，默认底层控制器不变且"停"总是安全，但在接触丰富/人机共享空间中硬停可能更危险——「物理债」。本轮坚持**单调安全**：新通道只允许更早变软/更早收缩，绝不放大可行动作集；任一新模块失效注入中立元，严格逐位退回 v9。

## 0. 直觉与动机

**灵感 1（可靠性 → 证书的"保证强度"，而非"保守程度"）**
直觉：v9 的块证书是一个**布尔式确定性不等式**：只要 ‖F̂−F‖∞ ≤ β，证书就"有效"。但 β 是拿经验误差 ×1.2 拍出来的，既没有有限样本保证，也没有回答"这条保证在部署分布上以多大概率成立"。更隐蔽的是，v9 默认"模块越多越安全"——可安全通道共享同一批关节编码器、同一路电源、同一套刚体动力学模型，失效高度相关；三条相关通道的可靠度可能远低于一条独立通道，这就是可靠性工程里的**共因失效**。真正缺的不是更保守的 β，而是一个**带置信度、可审计、承认相关性的概率保证**。核心创新：**可靠性标定证书（Reliability-Calibrated Certificate, RCC）**：每条安全通道 m 携带危险率 λ_m(t)、可靠度 R_m(t)=exp(−∫λ_m)、以及由 conformal prediction 给出的有效性概率 p_m（有限样本覆盖 1−α，无需分布假设）；系统安全函数写成串并联 RBD，用 Fréchet/Hoeffding 界在仅知边缘与相关系数时给出**可靠度下界**；再引入共因因子 γ_cc 与**可靠性预算** ε_total = Σε_m + ε_cc，用 Birnbaum 重要度 I_m=∂R_sys/∂R_m 分配冗余与算力。v9 的"β 余量"由此升级为"可审计的概率保证"，并明确回答"哪个模块真正提高可靠性"。

**灵感 2（柔顺控制 → 物理层的安全执行器）**
直觉：v9 的五级退化全部发生在**计算域**：少算、降块长、注入中立元。它默认底层控制器固定不变，且"停"总是安全的。但在接触丰富或人机共享空间里，硬停反而可能更危险：储存的动能释放、夹持、卡死、回弹。柔顺控制给出另一条**物理层**的安全路径：阻抗/导纳控制 + 能量罐（energy tank）保证无源性，接触力被自然限制，冲击被耗散。核心创新：**无源能量证书（Passivity Energy Certificate, PEC）**：虚拟能量罐 E(t) ≥ 0，阻抗控制器只能从罐中取能，无源性保证 ∫vᵀf_ext ≤ E(0)+补给，故交互能量有界、接触稳定、力有上限——而这个保证**不依赖前向模型**，与 v9 的模型证书失效模式正交（可靠性工程意义上的"多样性冗余"）。配合**柔顺退化梯（Compliance Degradation Ladder, CDL）**：ℓ0 任务阻抗 → ℓ1 低刚度高阻尼 → ℓ2 力限导纳 → ℓ3 重力补偿自由漂浮 → ℓ4 受控停驻；每次降级都做能量罐交接以保持无源。

**灵感 3（合成 → 可靠柔顺包络：不确定时"变软"优先于"急停"）**
直觉：可靠性回答"该信多少"，柔顺回答"不信时怎么做"。二者合成一个**可靠柔顺安全包络（Reliability-Calibrated Compliant Envelope, RCCE）**：当系统可靠度下界跌破 1−ε、或能量罐跌破 E_min、或接触被判定异常时，策略不是立即急停，而是**沿柔顺梯下降一级**并同步收缩可行动作集；只有在自由空间且制动距离充足时才允许直接停驻。这是一个显式的决策论选择：ℓ* = argmin_ℓ E[harm] = P(contact)·harm_contact(ℓ) + P(free)·harm_free(ℓ)。接触概率高时"软"比"停"伤害更小，自由空间时"停"最优。三个时间尺度嵌套：1kHz 无源/能量守卫（模型无关）→ 50Hz 块证书 + 接触分类 → 5Hz 可靠性重标定（conformal/ACI）。

## 1. 研究问题（轮次升级版）

- **Q1（证书可靠性的有限样本下界）**：在仅有有限标定样本、且失效相关结构只知部分信息时，如何给出系统安全性的分布无关、有限样本下界？分布漂移破坏可交换性时，覆盖如何用 ACI 维持？
- **Q2（无源柔顺的安全边界）**：能量罐证书在何种传感/观测器条件下仍严格模型无关？柔顺梯的逐级降级能否在能量交接处保持无源、且不引入新的接触失稳？
- **Q3（可靠柔顺仲裁的良构性）**："变软优先于急停"在什么伤害模型下严格优于"不确定即停"？如何保证 v10 的可行动作集与刚度沿退化链**单调收缩**到 v9？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 可靠性标定律（Reliability-Calibrated Certificate, RCC）**
任何安全声明都必须附带覆盖概率 1−α 与标定样本量 n_cal，不得只给确定性不等式。系统安全函数按 RBD 合成，仅知边缘可靠度时取 Fréchet 下界；共因失效用 γ_cc 显式建模，不允许把相关通道当独立通道相乘。可靠性预算 ε_total 按 Birnbaum 重要度分配到通道，**没有预算的通道不得计入安全论证**。

**P14 无源柔顺律（Passivity-Preserving Compliance, PPC）**
底层控制一律为能量罐阻抗/导纳控制，任意时刻 E(t) ≥ E_min；柔顺参数变更必须通过能量交接，禁止瞬时跳变刚度。力上限 f_safe 按 ISO/TS 15066 的准静态/瞬态接触限值取；能量证书只依赖关节力矩/速度测量与无源结构，**不引用前向模型 F̂**。

**P15 可靠柔顺单调律（Reliability-Compliance Monotonicity, RCM）**
不确定度上升只允许：沿柔顺梯**下降**（更软）与可行动作集**收缩**；绝不允许增加刚度、提高块长或扩大动作集。形式化：A_v10(t) ⊆ A_v9(t)，且 K_p^{ℓ+1} ≤ K_p^{ℓ}、K_d^{ℓ+1} ≥ K_d^{ℓ}、f_safe^{ℓ+1} ≤ f_safe^{ℓ}。恢复需双阈迟滞 + 驻留时间，防抖振。

## 3. 与基线的接口（如何退化）

- RCC 失效（标定集不足/可交换性破坏且 ACI 未收敛）⇒ 回退 v9 确定性 β 证书（β 取标定集最大经验误差，最保守），等价 v9；
- PEC 失效（力矩传感/动量观测器故障、E 观测不可信）⇒ 关闭能量通道，仅用 v9 运动学中止；CDL 锁定 ℓ0 = 固定任务阻抗，等价 v9 底层控制器；
- CDL 失效（能量交接失败/参数不可信）⇒ 固定 ℓ0 阻抗，不降级，等价 v9；
- 共因相关系数未知 ⇒ 取最坏 γ_cc=1（完全相关），可靠度下界退化为最保守单通道值；
- 伤害模型未知 ⇒ c≡1 保守取"接触可能"，仅允许变软、不允许停驻以外的冒险；
- AC/MW/ID/DA/SPR/Cal 失效 ⇒ 沿用 v9 五级退化；
- 全部失效 ⇒ v9 → v8 → v7 → v6。

## 4. 预期贡献

1. **可靠性标定证书**：conformal 有限样本覆盖 + RBD 可靠度下界 + 共因失效建模，把"β 余量"升级为"可审计的概率保证"，并给出可靠性预算的 Birnbaum 分配；
2. **无源能量证书**：1kHz、模型无关、与学习前向模型失效模式正交的物理安全通道，直接补 v9 在域偏移下"证书最不可靠"的软肋；
3. **柔顺退化梯**：把"停"扩展为"先变软、再停"的物理层退化链，能量交接保持无源，接触场景下比硬停更安全；
4. **可靠×柔顺×分块×蒸馏四向耦合**：E571–E590 覆盖覆盖性、共因、能量无源、力限、梯降平滑、可靠重要度与蒸馏资格、接触盲区与端到端任务。

## 5. 本轮最大风险

**一句话**：可靠标定假设标定集与部署分布可交换、且失效相关结构已知，而柔顺梯的"变软"恰恰在接触丰富域同时破坏这两个前提——越软越难从力/能量残差中辨识缓慢累积的接触力，于是系统在最需要可靠性的接触区既高估可靠度、又低估接触力。

**新增定义 540（安全通道可靠度 Safety Channel Reliability）** 安全通道 m ∈ 𝓜 的危险率 λ_m(t) ≥ 0 由失效计数/Weibull 拟合给出，可靠度 R_m(t)=exp(−∫_0^t λ_m(s)ds)。标定集 D_m={(x_i,y_i)}_{i=1}^{n_m} 上的非一致性得分 s_i = |y_i − ŷ_i|（回归）或 1[y_i ∉ Ĉ_i]（分类）。

**新增定义 541（conformal 可靠性证书 Reliability-Calibrated Certificate）** 对通道 m，取 split conformal 分位数
```
q̂_m = Quantile_{⌈(n_m+1)(1−α_m)⌉/n_m}({s_i})
```
证书 Ĉ_m^rel = (ĝ_min, q̂_m, α_m, n_m)，其中 ĝ_min = min_{k≤K} F̂_g − q̂_m（把 v9 定义 533 的 β 替换为数据驱动分位数）。若标定样本与部署样本可交换，则 P(g ≥ ĝ_min) ≥ 1−α_m（引理 87）。分布漂移下用 ACI 更新 α_{m,t+1}=α_{m,t}+γ(α_target−err_t)，维持长期覆盖。

**新增定义 542（安全 RBD 与共因失效 Safety RBD）** 系统安全函数 S 表示为串并联可靠性框图：串联（全部须工作）、并联（至少一个工作）、k-out-of-n。仅知边缘可靠度时取 Fréchet 下界：
```
R_sys^{LCB} = max(0, Σ_m R_m − (|𝓜|−1))          （串联，任意相关）
R_sys = Π_m R_m                                  （串联，独立）
R_sys = Σ_{j=k}^n C(n,j) R^j (1−R)^{n−j}         （k-out-of-n，独立）
```
共因失效：有效独立通道数 n_eff = n(1−γ_cc)+γ_cc；γ_cc=1 时全部退化为单一通道，禁止"堆通道"虚增可靠度。

**新增定义 543（可靠性预算与重要度 Reliability Budget & Importance）** ε_total = Σ_m ε_m + ε_cc（union bound）。Birnbaum 重要度 I_m = ∂R_sys/∂R_m。在算力预算 B 下分配冗余/采样率：
```
max_{Δ_m} R_sys   s.t.  Σ_m cost_m(Δ_m) ≤ B,   Σ_m ε_m + ε_cc ≤ ε_total
```
贪心按 I_m/cost_m 排序（R_sys 对 R_m 单调且近似子模）。与 v9 的 ID 耦合：I_m 高而贡献 c_m 低的模块**不得休眠**，即 φ_m^elig ← φ_m^elig ∧ (I_m < I_crit)。

**新增定义 544（虚拟能量罐 Passivity Energy Tank）** 能量罐动力学
```
Ė(t) = −P_out(t) + P_in(t),   P_out = vᵀ f_cmd,   E(t) ≥ 0
```
阻抗控制 f_cmd = −K_p(x−x_d) − K_d ẋ + f_ff；当 E 低时按 E/E_ref 缩放 K_p（能量调度）。闭环相对端口 (f_ext, v) 无源：∫_0^T vᵀf_ext dt ≤ E(0)+∫P_in dt。

**新增定义 545（无源能量证书 Passivity Energy Certificate）** K_E = (E_min, E_horizon, f_safe)。块内证书有效 ⇔
```
min_{k≤K} E(t_k) ≥ E_min  ∧  ‖f_ext‖ ≤ f_safe  ∧  ‖τ_res − Jᵀ ŵ_ext‖ ≤ δ_o
```
其中 τ_res 由广义动量观测器给出（v10 可选复用 v9 候选的力矩通道）。关键性质：证书只引用关节力矩/速度测量与无源控制结构，**不引用前向模型 F̂**，故与 v9 块证书失效模式正交（引理 89）。

**新增定义 546（柔顺退化梯 Compliance Degradation Ladder）** 级别 ℓ∈{0,1,2,3,4}，参数 Z_ℓ=(K_p^ℓ,K_d^ℓ,f_safe^ℓ)：
- ℓ0 任务阻抗：(K_p^0, K_d^0)，正常操作；
- ℓ1 低刚度高阻尼：K_p↓、K_d↑，更耗散；
- ℓ2 力限导纳：K_p→小，导纳控制，f_safe 硬限；
- ℓ3 重力补偿自由漂浮：K_p≈0、K_d 高，可被轻推；
- ℓ4 受控停驻：制动 + 位置保持。
单调约束：K_p^0 ≥ K_p^1 ≥ … ≥ 0，K_d^0 ≤ K_d^1 ≤ …，f_safe^0 ≥ f_safe^1 ≥ …。仅允许相邻级迁移；每次降级做能量交接 E_{ℓ+1} ← E_ℓ − ΔE_handover ≥ E_min。

**新增定义 547（期望伤害仲裁 Expected Harm Arbitration）** harm(ℓ;c) = c·harm_contact(ℓ) + (1−c)·harm_free(ℓ)，其中 harm_contact 含冲击能、力超限与夹持风险，harm_free 含制动距离不足与任务失败。策略
```
ℓ* = argmin_{ℓ} harm(ℓ;c)   s.t.  passivity(Z_ℓ) ∧ E_ℓ ≥ E_min
```
自由空间 c≈0 时 ℓ4（停）最优；接触概率高 c→1 时 ℓ2/ℓ3（软）最优。此即"变软优先于急停"的形式化。

**新增定义 548（可靠柔顺仲裁与迟滞 Reliability-Compliance Arbitration）** 触发（任一）：R_sys^{LCB} < 1−ε_total、E < E_min+margin、接触判 anomalous、PEC 无效。动作：ℓ ← min(ℓ+1,4)，A ← A ∩ {passivity-admissible}，K_eff ← min(K_eff, K_ℓ)。恢复：需 R_sys^{LCB} ≥ 1−ε_total+δ、E ≥ E_min+2margin 且持续 T_dwell，才升一级；双阈防抖。

**新增定义 549（快慢可靠柔顺闭环 Fast-Slow Reliability-Compliance Loop）** 1kHz 能量守卫（PEC + 梯仲裁）→ 50Hz 块证书（v9 AC）+ 接触分类 → 5Hz 可靠性重标定（conformal/ACI + RBD 更新 + 预算重分配）→ 0.2Hz 离线失效模式/相关系数更新。快通道只可收缩、慢通道只可重分配，二者经中立元严格退回 v9。

# IP-358 ReliabilityCalibrator：conformal + RBD + 预算分配
class ReliabilityCalibrator:
    def __init__(self, alpha=0.05, eps_total=1e-3, gamma_cc=0.0):
        self.alpha, self.eps_total = alpha, eps_total
        self.gamma_cc = gamma_cc
        self.scores = defaultdict(list)       # 每通道非一致性得分
        self.alpha_t = defaultdict(lambda: alpha)   # ACI 自适应 alpha

    def calibrate(self, channel, residuals):
        self.scores[channel].extend(residuals)
        n = len(self.scores[channel])
        if n < self.n_min:                    # 标定不足 → 返回 None（回退 v9）
            return None
        k = math.ceil((n + 1) * (1 - self.alpha_t[channel]))
        q_hat = sorted(self.scores[channel])[min(k, n) - 1]
        return RelCert(q_hat, self.alpha_t[channel], n)   # 定义 541

    def aci_update(self, channel, err):
        a = self.alpha_t[channel]
        self.alpha_t[channel] = a + 0.01 * (self.alpha - err)  # 长期覆盖

    def rbd_lower_bound(self, R, structure='series'):
        n = len(R)
        if structure == 'series':
            return max(0.0, sum(R) - (n - 1))            # Fréchet 任意相关
        if structure == 'parallel':
            return 1.0 - prod(1.0 - r for r in R)
        # k-out-of-n with common cause
        n_eff = n * (1 - self.gamma_cc) + self.gamma_cc
        return sum(comb(n, j) * (n_eff/n)**j * (1-n_eff/n)**(n-j)
                   for j in range(self.k, n + 1))

    def allocate_budget(self, channels, cost_fn, B):
        # Birnbaum 重要度 I_m = ∂R_sys/∂R_m；贪心 I_m/cost
        order = sorted(channels,
                       key=lambda m: self.importance(m) / cost_fn(m),
                       reverse=True)
        alloc, spent = {}, 0.0
        for m in order:
            c = cost_fn(m)
            if spent + c <= B:
                alloc[m] = c; spent += c
        return alloc


# IP-357 PassivityEnergyCertifier：1kHz 无源能量证书
class PassivityEnergyCertifier:
    def __init__(self, E0, E_min=0.05, f_safe=50.0, dt=0.001):
        self.E, self.E_min, self.f_safe = E0, E_min, f_safe
        self.dt = dt

    def tank_step(self, v, f_cmd, P_in):
        P_out = float(v @ f_cmd)
        self.E = max(0.0, self.E + (P_in - P_out) * self.dt)
        return self.E

    def scale_stiffness(self, Kp, E_ref):
        return Kp * min(1.0, self.E / E_ref)           # 能量调度（定义 544）

    def certify(self, E_horizon, f_ext, tau_res, w_ext, J):
        ok = (self.E >= self.E_min and
              norm(f_ext) <= self.f_safe and
              norm(tau_res - J.T @ w_ext) <= self.delta_o)
        return EnergyCert(ok, self.E, self.E_min, self.f_safe)


# IP-359 ComplianceLadderController：柔顺退化梯 + 伤害仲裁
class ComplianceLadderController:
    def __init__(self, ladder, dwell=50):
        self.ladder = ladder            # ℓ -> Z_ℓ，单调参数（定义 546）
        self.level = 0
        self.dwell, self.hold = dwell, 0

    def arbitrate(self, c_contact, E, r_lcb, eps_total):
        trig = (r_lcb < 1 - eps_total or E < self.ladder[self.level].E_min
                or c_contact > 0.5)
        if trig and self.level < 4:
            self.level += 1                              # 只降级（变软）
            self.hold = 0
            return self.level
        if self.can_recover(E, r_lcb, eps_total):
            self.hold += 1
            if self.hold >= self.dwell:
                self.level = max(0, self.level - 1)      # 双阈迟滞
                self.hold = 0
        return self.level

    def can_recover(self, E, r_lcb, eps_total):
        return (r_lcb >= 1 - eps_total + 0.01 and
                E >= self.ladder[self.level].E_min * 2)

    def handover_energy(self, E):
        dE = self.ladder[self.level].dE_handover
        return E - dE if E - dE >= self.ladder[self.level].E_min else None

    def apply(self, E):
        if self.level > 0:
            E2 = self.handover_energy(E)
            if E2 is None:
                return self.ladder[0], E      # 交接失败 → 锁 ℓ0（等价 v9）
            return self.ladder[self.level], E2
        return self.ladder[0], E


# IP-360 ReliabilityImportanceAllocator：与 ID 的耦合
class ReliabilityImportanceAllocator:
    def __init__(self, rc, I_crit=0.05):
        self.rc, self.I_crit = rc, I_crit

    def eligible(self, module, base_phi):
        I = self.rc.importance(module)          # ∂R_sys/∂R_m
        return base_phi and I < self.I_crit     # 可靠关键模块永不休眠

## 4. 推导

**引理 87（conformal 有限样本覆盖）** 设标定样本与测试样本可交换，q̂_m 为 split conformal 的 ⌈(n+1)(1−α)⌉/n 分位数，则 P(g ≥ ĝ_min) ≥ 1−α（有限样本，无需分布假设）。分布漂移破坏可交换性时，ACI 更新 α_{t+1}=α_t+γ(α−err_t) 给出长期覆盖 liminf_T (1/T)Σ_t 1[err_t ≤ α_t] ≥ 1−α−o(1)。证明：标准 split conformal 秩论证 + ACI 的在线学习界。∎

**引理 88（RBD 可靠度下界与共因不虚增）** 对任意相关结构，串联 R_sys ≥ max(0,ΣR_m−(|𝓜|−1))（Fréchet）；独立时取乘积；k-out-of-n 用二项式。共因 γ_cc 将有效通道数压到 n_eff=n(1−γ_cc)+γ_cc，且 R_sys 关于 n_eff 单调不减，故 γ_cc 越大下界越低。因此 v10 声明的可靠度永不超过真实下界（无过度自信）。∎

**引理 89（无源能量证书的模型无关性）** 若底层为能量罐阻抗控制且 E(t)≥0，则对任意外部力 f_ext，闭环无源：∫_0^T vᵀf_ext dt ≤ E(0)+∫P_in dt + 耗散项。故交互能量有界；‖f_ext‖ 超限必先耗尽 E 或触发 f_safe。证明仅用能量平衡与无源性，不引用 F̂，故与 v9 块证书的模型误差失效模式正交。∎

**引理 90（柔顺梯单调安全与 A_v10⊆A_v9）** 相邻降级满足 K_p 非增、K_d 非减、f_safe 非增，能量交接 E≥E_min；故刚度与可行动作集单调收缩，接触冲击能上界不增。又 A_v10 = A_v9 ∩ {passivity-admissible} ∩ {未触发降级约束}，故 A_v10 ⊆ A_v9；v9 引理 80–86 的安全性传递成立。∎

**引理 91（可靠柔顺退化到 v9）** 令 RCC 失效 ⇒ 用 v9 的 β=max 经验误差；PEC 失效 ⇒ 关闭能量通道；CDL 失效 ⇒ 锁 ℓ0 = v9 固定阻抗；γ_cc 未知 ⇒ 取 1。此时判据、动作集、日志与 v9 逐位一致。证明：逐行构造中立元映射，中立元恒等性保证端口读数不变。∎

**引理 92（可靠性预算可行性）** 若各通道独立标定且 Σε_m+ε_cc ≤ ε_total，则 P(安全违背) ≤ ε_total（union bound）。Birnbaum 贪心在固定算力下近似最小化 P_fail（R_sys 对 R_m 单调、近似子模，贪心有 1−1/e 保证）。将 I_m 高者置为不可休眠，避免蒸馏削弱可靠性。∎

**引理 93（仲裁无 Zeno 与恢复安全）** 双阈（降级阈 1−ε_total，恢复阈 1−ε_total+δ）+ 驻留 T_dwell + 每次降级至少需一次触发 ⇒ 相邻迁移间隔 ≥ T_dwell，有限时间迁移有限。恢复仅在两通道均清除且能量储备翻倍后发生，故恢复路径仍在 A_v9 内。∎

**引理 94（接触盲区下界）** 在持续接触、无自由相参考时，缓慢力偏差 b(t) 与真实接触力不可分离：最小不可检出碰撞满足 ‖f_coll‖ ≤ |b| + 2(ε_model+√trΣ_c)；若自由相占比 → 0，则盲区随 |b| 无界增长。故柔顺梯越软（力反馈增益越低）盲区越大，必须由能量累积项补足（E 的单调下降可作为偏差的间接证据）。∎
