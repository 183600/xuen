# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「行为克隆」×「关节空间控制」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**演示只提议、不授权；关节空间只做表示、不做安全论证；协变量门控必须快慢双时标**。行为克隆治理 v9 的"样本效率债"，关节空间控制治理 v9 的"动作表示债"；而两者合成出的新债——演示分布外的虚假自信——必须由关节-任务双侧包络与协变量证书偿还。所有新模块失效 ⇒ BC 权重置 0，严格退回 v9 的 AC 采样与证书路径。

## 0. 直觉与动机

**灵感 1（行为克隆 → 摊销式演示先验，而非策略替代）**
直觉：v9 的 AC 每个决策块要从通用策略采 64 条候选再逐条前向模型 rollout，样本效率低、块生成吃满 12ms。人类示范本身就是高价值先验：在演示覆盖的状态上，BC 能一步给出接近最优的关节动作块，把候选数从 64 降到 16 而不掉成功率。但 BC 的经典病灶是协变量漂移与复合误差：一旦执行进入演示未覆盖的状态，策略误差按 O(T²ε) 放大。因此本文不把 BC 当策略，而只当**提议分布（proposal prior）**：它只决定"从哪里采样"，绝不决定"什么可以执行"。核心创新：**关节空间行为先验（JointSpaceBehaviorPrior, JBP）**。

**灵感 2（关节空间控制 → 便宜精确的盒约束 + 昂贵保守的任务安全包络）**
直觉：任务空间动作要处理逆运动学奇异与非凸约束；关节空间动作的硬约束是关节位置/速度/加速度/力矩的**盒约束**，投影便宜且精确——这正是关节空间表示的诱人之处。但它把安全论证的难度转移了：M₀ 安全（间隙、力、抓取）定义在任务空间，而 BC 的误差在关节空间。小关节误差经雅可比映射到任务空间会放大 σ_max(J) 倍；更关键的是，执行一个任务空间修正所需的关节速度被 1/σ_min(J) 放大——接近奇异时"关节空间看起来平滑，任务空间却无权限修正"。核心创新：**关节-任务双侧包络证书（JointTaskEnvelope, JTE）**：前向用 σ_max 界任务误差，反向用 1/σ_min 界控制权限，两侧同时成立才认证。

**灵感 3（二者合成 → 快慢双时标的协变量门控）**
直觉：v9 最大的风险是 DA-ML 的 20 帧滑窗滞后于真实分布跳变，K_eff 在失效块上仍取大值。BC 的集成分歧 u_BC 与演示覆盖 ρ 是**单步、状态级**信号，能在分布跳变的第一个周期报警；DA-ML 则是慢而稳的确认。两者不是替代而是**双时标**：快信号管"立刻收缩"，慢信号管"持续信任与迟滞"。合成物为**协变量证书与门控（CovariateShiftGate, CSG）**，w_BC = w_max·1[JTE]·1[CSG]，任一失效即 w_BC=0，逐位退回 v9。这把 BC 的全局 T² 复合误差界换成"每块重认证 + 每周期门控"的一串局部可验证界。

## 1. 研究问题（轮次升级版）

- **Q1（演示先验的安全性）**：BC 只改提议分布时，如何证明可执行动作集合只减不增（安全单调），并用 fallback 保住活性？JTE 的前向/反向包络能否给出"关节误差 ε_q ⇒ 任务证书余量扣减"的可加界？
- **Q2（关节空间表征的边界）**：σ_max 有界而 1/σ_min 无界——在什么奇异度阈值 τ_sing 下，关节空间自主执行不再可认证？盒约束投影的精确性如何与任务空间保守包络组合，而不产生"关节过、任务不过"的空洞？
- **Q3（快慢门控的有效性）**：集成分歧作为 OOD 检测器的功效上界是什么？如何用覆盖/密度比与迟滞避免"一致地自信"与"门控抖振"？快信号能把 v9 的 20 帧滞后暴露压缩到多大？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 演示只提议不授权律（Demonstration-Proposes-Not-Authorizes, DPNA）**
BC 仅改变 AC 的提议分布 π_agg=(1−w)π_v9 + w·π_BC；任何动作仍须通过 v9 块证书 Ĉ、M₀ 硬检查与 JTE。安全集合单调不增；当 BC 提议无认证候选时回退 v9 全量采样以保活性。BC 永不写入安全论证。

**P14 关节-任务双侧包络律（Joint-Task Two-Sided Envelope, JTE）**
前向：|φ(f(q+Δq))−φ(f(q))| ≤ L_φ·Λ_f(q)‖Δq‖，Λ_f=sup σ_max(J) 有界。反向：实现任务位移 δx 的最小关节速度满足 ‖q̇‖ ≤ Λ_J(q)‖δx‖，Λ_J=1/σ_min(J) 无界。仅当两侧均满足且 σ_min ≥ τ_sing 才认证关节空间自主；否则 K_eff←1 或安全停驻。**单看 σ_max 不够，必须同时看 1/σ_min。**

**P15 快慢双时标协变量门控律（Two-Timescale Covariate Gate, CSG）**
快信号 F_t=(u_BC, ρ, σ_min) 每周期评估；慢信号 S_t=(Δ_dom, risk_SLAM) 沿用 v9。信任 trust=trust_fast∧trust_slow，带 Schmitt 迟滞；w_BC=w_max·1[JTE]·1[trust]；任一失效 ⇒ w_BC=0，逐位等价 v9。证书必须同时记录快慢两侧读数，禁止只报慢信号。

## 3. 与基线的接口（如何退化）

- JBP 失效 / 无覆盖（u_BC>τ_u ∨ ρ<τ_ρ）⇒ w_BC←0，提议退回 π_v9，等价 v9 AC；
- JTE 失效 / 奇异（σ_min<τ_sing ∨ 关节权限不足）⇒ w_BC←0 且 K_eff←1，等价 v9 逐步；
- CSG 失效 ⇒ w_BC←0，仅保留 DA-ML 慢门控，等价 v9；
- BC 提议无认证候选 ⇒ 单块回退 v9 全量采样（活性），安全语义不变；
- 关节盒投影可行集为空 ⇒ 注入 v^⊥=安全停驻（速度衰减到 0），等价 v9 停车路径；
- v9 的 AC/MW/ID 任一失效 ⇒ 按 v9 引理 83–86 继续退化至 v8/v7。

## 4. 预期贡献

1. **演示先验的安全单调性**：证明 BC 只提议不授权，把 BC 的复合误差 O(T²ε) 换成块局部可验证界，安全永远由 v9 证书兜底；
2. **关节-任务双侧包络**：显式刻画 σ_max（任务误差）与 1/σ_min（控制权限）的不对称，给出奇异度门控与"关节平滑但任务危险"的可认证判据；
3. **快慢双时标协变量门控**：用 BC 集成分歧/覆盖作为单步 OOD 信号，直接给 v9 的 20 帧滞后风险上保险，并用迟滞防抖；
4. **样本效率与算力**：BC 提议使候选数 64→16、块生成 12ms→~4ms，释放的预算反哺 v9 的 DA/SPR/Cal；E571–E590 覆盖演示规模、协变量压力、奇异注入、包络紧致性、快慢检测与端到端任务。

## 5. 本轮最大风险

**一句话**：BC 先验的可靠性以「部署状态落在演示支撑内且集成分歧能感知分布外」为前提；但所有集成成员共享同一演示盲区时会一致地自信，最需要报警的陌生状态反而分歧最小——快信号在最危险的时刻给出虚假把握，慢信号又滞后，证书因此失效。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-JBC**（Joint-space Behavior-Cloning prior with Certified Joint–Task Envelopes）

> 背景：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮灵感：「行为克隆」×「关节空间控制」
> **继承纪律**：MetricVoiceGauge 九不变式（CVC-闭环、SpatialCert、RT-CVC、FaultCert、PrimitiveGraph、严格退化链、OTL、GCT、ER）与 v9 的 AC/MW/ID 全部保留。新组件一律为**可选增强**：JBP/JTE/CSG 任一不可用 ⇒ w_BC←0，注入"无演示偏置"，提议与证书逐位退回 v9（引理 91）。安全永远由 v9 证书兜底，BC 只影响样本效率。

## 1. 符号体系增量（定义 540–549）

**新增定义 540（关节动作空间与盒约束）** 关节空间动作 a_q = q̈^des，dt=20ms。硬约束
```
A_J = { a_q : q ⊕ (q̇dt + ½a_q dt²) ∈ [q⁻,q⁺],
              q̇ + a_q dt ∈ [−q̇⁺,q̇⁺],
              |a_q| ≤ q̈⁺,
              |τ(q,q̇,a_q)| ≤ τ⁺ }
```
其中 τ = M(q)a_q + C(q,q̇)q̇ + g(q)。Π_J 先做盒投影，再做力矩校验；校验失败即判该动作不可行。盒约束的投影非扩张：‖Π_J(a)−Π_J(b)‖₂ ≤ ‖a−b‖₂。

**新增定义 541（关节空间行为先验 JBP）** 冻结集成 π_BC^ens(a_q|s)，输入状态与 H=4 步历史：
```
μ_BC(s) = (1/K) Σ_k μ_k(s)
u_BC(s) = (1/K) Σ_k ‖μ_k(s) − μ_BC(s)‖² + (1/K) Σ_k tr Σ_k(s)
```
u_BC 是"集成分歧 + 单成员方差"的归一化标量。JBP 只提供 sample_sequences(state,K,n) 与 coverage(s)；不输出任何执行许可。

**新增定义 542（演示支撑与覆盖 ρ）** 以演示状态拟合 GMM 或 kNN 流形，定义
```
d_M²(s) = min_{s_D ∈ D} (s − s_D)ᵀ Σ_D^{-1} (s − s_D)
ρ(s) = exp(−½ d_M²(s))
```
ρ ≥ τ_ρ 视为"在演示支撑内"。ρ 只用于门控，不作为安全证明。

**新增定义 543（关节-任务前向包络）** 设任务指标 φ（间隙 g 或末端位置 x）对 x 满足 L_φ-Lipschitz，则对任意 Δq：
```
|φ(f(q+Δq)) − φ(f(q))| ≤ L_φ · Λ_f(q) · ‖Δq‖,
Λ_f(q) = sup_{q' ∈ B(q,r)} σ_max(J(q'))
```
块证书的间隙项因此扣减为
```
ĝ_min^{JBC} = ĝ_min − β − L_g · Λ_f(q) · ε_q
```
仅当 ĝ_min^{JBC} ≥ d_safe 才认证。**关节空间误差直接吃掉任务证书余量**。

**新增定义 544（关节-任务反向权限包络）** 执行任务空间修正 δx 的最小范数关节速度为 q̇ = J⁺(q)δx，故
```
‖q̇‖₂ ≤ Λ_J(q) · ‖δx‖₂,   Λ_J(q) = 1/σ_min(J(q))
```
权限可行 ⇔ Λ_J(q)‖δx‖ ≤ v⁺ 且力矩校验通过。定义 τ_sing = δx_cert/v⁺，当 σ_min < τ_sing 时判定"关节空间无权限完成任务空间修正"，即使前向误差界仍然成立。奇异处 Λ_f 有界而 Λ_J 无界，二者不可互相替代。

**新增定义 545（协变量证书 B_t）**
```
B_t = [u_BC(s_t) ≤ τ_u] ∧ [ρ(s_t) ≥ τ_ρ] ∧ [ε_cs(t) ≤ τ_cs]
      ∧ [JTE 前向与反向均有效] ∧ [v9 块证书 Ĉ_t valid]
```
ε_cs 为演示分布与部署状态的判别器总变差估计（held-out，带置信区间）。B_t 的组织方式为合取；任何一项为假即整张证书无效。

**新增定义 546（快慢信任与迟滞）**
```
trust_slow(t) = [Δ_dom(t) < τ_dom] ∧ [risk_SLAM(t) < τ_SLAM]          # v9 语义
trust_fast(t) = [u_BC(t) ≤ τ_u] ∧ [ρ(t) ≥ τ_ρ] ∧ [σ_min(t) ≥ τ_sing]
trust(t)      = trust_slow(t) ∧ trust_fast(t)                          # 合取
```
trust 的进入/退出使用 Schmitt 迟滞（τ_on > τ_off，连续 N_on/N_off 个周期确认），迟滞只作用于慢信号；快信号可立即撤销信任（安全优先、允许单向抖振）。

**新增定义 547（BC 提议混合与权重）**
```
π_agg(a_q|s) = (1 − w_BC(s)) · π_v9(a_q|s) + w_BC(s) · π_BC(a_q|s)
w_BC(s) = w_max · 1[B_t] · 1[trust(t)] · 1[JTE valid]
```
聚合算子 ⊕ 为凸混合，其**右中立元**为 w=0（π_agg=π_v9）。JTE 是 w_BC 的守卫依赖：JTE 不可用 ⇒ w_BC≡0，而非"忽略包络继续用 BC"。

**新增定义 548（块局部协变量界）** 对长度 K 的执行块，若每周期重新评估快信号且块边界重规划，则定义块局部误差与越界概率：
```
E_block ≤ L_φ (Λ_f ε_q + v⁺ dt K) + O(dt²)
Pr[块末状态离开演示支撑] ≤ K · ε_cs
```
该界替代经典开环 BC 的 O(T²ε) 全局界；v10 只对**当前块**负责，块末必须重认证。

**新增定义 549（演示刷新缓冲 DRB，可选）** 在 B_t 失效且系统处于安全停驻/慢速守卫时，记录 (s, a_expert) 修正对；仅在回合间离线加入 D 并重训集成。DRB 不参与在线执行路径，不改变任何证书。

## 2. 形式化定义（要点与升级）

**定义 493/495/521/524/526–530** 继承 v9 不变。
**升级定义 532（动作块）** a^{1:K} 现在可取自关节空间 A_J；块仍为 ζ=(a^{1:K}, Ĉ, P)，但 Ĉ 增加 JTE 项。
**升级定义 533（块证书）** 间隙项改为 ĝ_min^{JBC}（定义 543），力矩项加关节盒校验；有效 ⇔ ĝ_min^{JBC} ≥ d_safe ∧ ê_max^{JBC} ≤ τ_eff ∧ γ̂_grasp valid ∧ JTE 反向权限成立。
**升级定义 534（中止点）** 停车不变式不变；增加"若 JTE 权限失效则最近中止点优先于继续执行"。
**升级定义 539（有效块长门控）** trust 由 v9 的 trust_slow 扩展为 trust_slow ∧ trust_fast；σ_min<τ_sing 直接使 U_t 不成立、K_eff=1。
**升级定义 496（软证书触发 δ_trigger）** 增加两项：B_t valid 与 JTE 反向权限成立；即
```
δ_trigger = {σ < τ_safe ∧ γ_grasp valid ∧ Δ_dom < τ_dom
             ∧ risk_SLAM < τ_SLAM ∧ Ĉ_t valid ∧ B_t valid ∧ 权限成立}
```
升级后与 v9 一样，任一软条件失配都立即触发 M₀ 硬检查，不存在"块内软过、硬失"的空洞。

# IP-357 JointSpaceBehaviorPrior：关节空间行为先验（只提议）
class JointSpaceBehaviorPrior:
    def __init__(self, ensemble, sigma_D, tau_rho=0.5, hist=4):
        self.models, self.Sigma_D, self.tau_rho, self.hist = \
            ensemble, sigma_D, tau_rho, hist
        self.K = len(ensemble)

    def infer(self, state, history):
        x = featurize(state, history[-self.hist:])
        mus = [m.mean(x) for m in self.models]            # 关节加速度均值
        Sig = [m.cov(x) for m in self.models]
        mu = mean(mus)
        u = mean([norm2(mk - mu) for mk in mus]) + mean([trace(S) for S in Sig])
        return mu, u

    def coverage(self, state):
        d2 = min(mahalanobis2(state, sD, self.Sigma_D) for sD in self.demo_states)
        return math.exp(-0.5 * d2)

    def sample_sequences(self, state, history, K, n):
        mu, u = self.infer(state, history)
        # 以集成分布为提议；n=16（v9 为 64）
        return [self._roll_joint(mu, self._sigma(u), K) for _ in range(n)]


# IP-358 JointTaskEnvelopeCertifier：关节-任务双侧包络
class JointTaskEnvelopeCertifier:
    def __init__(self, fk, L_phi, d_safe, v_max, eps_q, delta_x_cert):
        self.fk, self.L_phi, self.d_safe = fk, L_phi, d_safe
        self.v_max, self.eps_q, self.delta_x = v_max, eps_q, delta_x_cert
        self.tau_sing = delta_x_cert / v_max              # 定义 544 导出

    def cert(self, q, eps_q, g_hat_min, beta, tau_eff):
        J = jacobian(self.fk, q)
        smin, smax = singular_values_2(J)                 # n<=7，SVD <0.1ms
        lam_f, lam_J = smax, (1.0 / smin if smin > 1e-12 else inf)
        g_cert = g_hat_min - beta - self.L_phi * lam_f * eps_q     # 定义 543
        forward_ok = g_cert >= self.d_safe
        authority_ok = (smin >= self.tau_sing) and \
                       (lam_J * self.delta_x <= self.v_max)        # 定义 544
        return forward_ok and authority_ok, g_cert, lam_f, lam_J, smin


# IP-359 CovariateShiftGate：快慢双时标协变量门控
class CovariateShiftGate:
    def __init__(self, tau_u=0.2, tau_rho=0.5, tau_cs=0.1,
                 tau_dom=0.3, tau_slam=0.4, w_max=0.8):
        self.tau_u, self.tau_rho, self.tau_cs = tau_u, tau_rho, tau_cs
        self.tau_dom, self.tau_slam, self.w_max = tau_dom, tau_slam, w_max

    def fast(self, jbp, jte, state, history, q):
        mu, u = jbp.infer(state, history)
        rho = jbp.coverage(state)
        J = jacobian(jte.fk, q); smin = singular_values_2(J)[0]
        ok = (u <= self.tau_u and rho >= self.tau_rho
              and smin >= jte.tau_sing)
        return ok, u, rho, smin

    def weight(self, fast_ok, jte_ok, eps_cs, delta_dom, risk_slam):
        slow_ok = (delta_dom < self.tau_dom and risk_slam < self.tau_slam)
        trusted = fast_ok and slow_ok and (eps_cs <= self.tau_cs) and jte_ok
        return self.w_max if trusted else 0.0            # w=0 ⇒ 等价 v9

## 4. 推导

**引理 87（关节-任务双侧包络）** 设 f 为前向运动学、J(q)=∂f/∂q，φ 对 x 满足 L_φ-Lipschitz。
(i) 对任意 Δq，|φ(f(q+Δq))−φ(f(q))| ≤ L_φ·Λ_f(q)‖Δq‖，Λ_f=sup_{B(q,r)}σ_max(J) 有限；
(ii) 实现任务位移 δx 的最小范数关节速度 q̇=J⁺δx 满足 ‖q̇‖ ≤ Λ_J(q)‖δx‖，Λ_J=1/σ_min(J)；
(iii) 当 σ_min<τ_sing=δx_cert/v⁺ 时，存在任务修正 δx（‖δx‖=δx_cert）使必需关节速度超过 v⁺，即**前向误差界成立但反向权限失效**。
证明：(i) 中值定理 Δf = J(q+ξ)Δq，取诱导 2-范数并用 σ_max 上界；(ii) J⁺=VΣ⁺Uᵀ 且 Σ⁺ 的最大奇异值为 1/σ_min；(iii) 取 δx 沿最小奇异值对应的左奇异向量方向，则 ‖J⁺δx‖=δx/σ_min>v⁺。∎

**数值探针（可复现，2 连杆平面臂）** L₁=L₂=0.4m，q₁=45°，关节误差 ε_q=0.01rad，任务修正 δx=5mm，取 v⁺=2rad/s：

| q₂ | σ_min | σ_max=Λ_f | 前向任务误差界 L_gΛ_fε_q | 反向需求 v_req=Λ_Jδx | 权限 |
|---:|---:|---:|---:|---:|:---:|
| 90° | 0.2472 | 0.6472 | 6.47 mm | 0.020 rad/s | ✓ |
| 30° | 0.0925 | 0.8652 | 8.65 mm | 0.054 rad/s | ✓ |
| 5° | 0.0156 | 0.8936 | 8.94 mm | 0.320 rad/s | ✓ |
| 1° | 0.0031 | 0.8944 | 8.94 mm | 1.601 rad/s | 临界 |
| 0.1° | 0.0003 | 0.8944 | 8.94 mm | 16.01 rad/s | ✗ |

前向任务误差界始终 <9mm，看似"安全"；反向权限需求却从 0.02 飙到 16rad/s，远超 v⁺。这量化了"关节平滑但任务无权限修正"：**必须双侧认证**。取 τ_sing=δx_cert/v⁺=0.0025，则 q₂≈1° 尚可、0.1° 必须 K_eff=1。

**引理 88（提议单调性与安全不回退）** 设 A_exec^{v9}(s)={a∈A_J : Cert_v9(a,s)} 为 v9 可执行集，v10 的可执行集 A_exec^{v10}(s)={a∈Proposal_w(s) : Cert_v9(a,s) ∧ JTE(a,s)}。
(i) A_exec^{v10}(s) ⊆ A_exec^{v9}(s)，故安全集合单调不增，BC 不能引入未认证动作；
(ii) 当 w_BC=0 时 Proposal=π_v9 且 JTE 项被守卫关闭，A_exec^{v10}=A_exec^{v9}，逐位等价；
(iii) 若 BC 提议在有限样本 n 下无认证候选，fallback 到 v9 全量采样，活性不劣于 v9 的采样失败概率下界。
证明：(i) 由交集/子集关系；(ii) 定义 547 的右中立元；(iii) 回退分支显式触发。∎
注：安全性单调，但**最优性不保证**——BC 提议可能只找到次优的认证候选，故成功率需 E572 实测；这不是安全问题。

**引理 89（块局部界替代全局 T² 界）** 在每块重认证、每周期评估快信号的执行下，对任一实际执行的块：
```
E_block ≤ L_φ(Λ_f ε_q + v⁺ dt K) + O(dt²),   Pr[块末离开演示支撑] ≤ K ε_cs。
```
经典开环 BC 的 O(T²ε) 界要求全程不修正；v10 不依赖该界，只对当前块负责，块末强制重认证/回退。
证明：对块内每步用引理 87(i) 累积关节误差并以速度上限放大；离开支撑为每步事件的并集，用 union bound。∎

**引理 90（快慢融合对 v9 滞后的条件消除）** 令 S_fast(t)={u_BC>τ_u ∨ ρ<τ_ρ ∨ σ_min<τ_sing}。由于 trust 要求 ¬S_fast，任何快信号报警的周期都有 w_BC=0 且不执行 BC 自主块。若快信号对真实分布外状态满足召回 ≥1−δ_f（假设 A_fast），则"在 OOD 上执行 BC"的概率 ≤δ_f，**与 DA-ML 的 20 帧滞后无关**；v9 的滞后暴露由此被 δ_f 取代。反之，若共享盲区使 A_fast 不成立，则本引理不提供保证——这正是本轮最大风险。
证明：trust 为合取，w_BC 含 1[trust]；由假设 A_fast 对 OOD 事件取补。∎

**引理 91（退化合成与 v9 等价）** 定义 547 中 w_BC 含守卫 1[JTE]·1[trust]；JBP、JTE、CSG 任一失效 ⇒ w_BC=0 ⇒ π_agg=π_v9、JTE 附加项关闭、中块快信号检查失效，系统逐位回到 v9 AC 路径。关节盒可行集为空时注入 v^⊥=安全停驻，等价 v9 停车路径。故 v10 的退化链是 v9 退化链的严格细化，v9 引理 82–86 全部可传递，安全不依赖 BC。∎

## 8. 本轮最大风险

**一句话**：BC 先验的可靠性以「部署状态落在演示支撑内且集成分歧能感知分布外」为前提；但所有集成成员共享同一演示盲区时会一致地自信，最需要报警的陌生状态反而分歧最小——快信号在最危险的时刻给出虚假把握，慢信号又滞后，证书因此失效。
