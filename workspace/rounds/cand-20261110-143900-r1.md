# 第 44 轮（新循环第 1 轮） · Energy-Cert × Action-Space：把「续航」升为证书维度、把「动作空间」变成能量参数化的可验证流形（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形仅边际覆盖 + 多用户契约空集」，但它压着一个更底层、从未被检查的假设：**(H0) 动作空间 A 是常量、能量只是软成本**。真实具身系统里，电量下降会**单调收缩**可行动作空间 A(b)，而几何/安全证书的「可恢复性」恰恰依赖 A(b) 中的逃生动作——于是 v20 在满电下证明 sound 的证书，会在低电时**静默失效**；更隐蔽的是，**证书计算本身耗电**，续租（v20 的新鲜度机制）会反过来消耗维持「不搁浅」所需的能量。本轮灵感词「续航能力」「动作空间」精确命中 H0：续航是**不可逆资源**，动作空间是**能量的函数**。二者耦合导出一个反直觉命题——**「让你更安全的证书，也可能耗尽让你保持安全的那块电池」**。

## 0. 直觉与动机

**灵感 1（续航 → 不是成本，而是安全证书）**：常规做法把电量当奖惩项里的标量成本，于是"没电"被建模成一种差结果，而不是一种**违例**。但机器人在危险位形处搁浅，和越过安全界在后果上等价。因此把续航提升为一等证书维度：定义**返航能量** E_safe(x)（从 x 回到安全港所需的最小能量），并强制**不搁浅不变式** b_t ≥ E_safe(x_t) + ε_res。它和几何不变式并列，参与守卫、参与组合、参与压力测试。一句话：**电量和位形一样，要进证书，而不是进损失函数**。

**灵感 2（动作空间 → 能量参数化的单调流形）**：把动作空间写成 A(b)，并假设其**单调收缩**（b_1 ≤ b_2 ⇒ A(b_1) ⊆ A(b_2)）：电量越高，可用动作只会更多。由此导出**证书的能量单调性引理**：认证安全集 V(b) 随 b 单调不减（b_1≤b_2 ⇒ V(b_1)⊆V(b_2)），因为低电下的可行见证策略在高电下仍然可行、且不搁浅约束更松。这条单调性既是正确性保证，又是工程杠杆：离线按电量分层预计算 (A(b_k), V(b_k), margin)，在线退化为 **O(1) 分层查表**（复用 IP-56 的 L0/L1），低电时只是"向下跳到更保守的一层"，而不是重新证明。动作空间由此从"给定输入"变成"可预计算、可审计、可单调降级"的**能量分层流形**。

**灵感 3（耦合 → 认证能耗悖论 + 能量分层覆盖）**：v20 的租约把"测量时刻"和"使用时刻"解耦，但默认认证不耗电。真实系统里每次 re-certify 都要跑 VLM/几何/监控，都是电池上的负载。于是出现**认证能耗悖论**：租约越新鲜越安全，但续租越频繁越耗电，越可能搁浅——两个"安全"目标互相拆台。必须显式建模**能量-新鲜度帕累托前沿**，并允许一条零在线认证电的退路（纯分层查表 + 粗租约）。同时，共形覆盖的旧风险获得一个具体触发器：**电量分层协变量漂移**——仿真常在满电下采样，低电动作空间被系统性欠采样，于是"边际覆盖达标"掩盖了"低电条件覆盖崩塌"。这把 v20 的 E88 从抽象风险变成可测的能量分层红线。

**耦合升级**：EACE（续航证书引擎）把电量编译成返航能量、能量分层证书表与双时钟租约；EART（能量-动作运行时）用可生存核做动作门控、用 E-HI 模式在续航逼近返航阈值时先砍耗电的语义/投机、用刷新节奏优化器守住认证能耗预算；ASVV（动作空间可行性验证器）在仿真里对低电动作空间、能量模型对抗、能耗悬崖与能量分层覆盖做压力测试。四层架构由此从 v8 的"人格-并发证书闭环"升级为 v9 的"**人格-并发-能量三维证书闭环**"。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（能量增广状态与能量参数化动作空间）**：联合状态 y=(x,b)，x∈X 为位形/状态，b∈[0,B_max] 为可用能量。动作空间是能量的函数 A(b)⊆A，满足**单调性** b_1≤b_2 ⇒ A(b_1)⊆A(b_2)。能量动力学：b_{t+1} = b_t − c(a_t, x_t) − c_cert(compute_t) + r_t，其中 c 为运动能耗（依赖地形/负载/温度），c_cert 为证书计算能耗，r_t 仅在对接充电时为正。**关键**：除充电外 b 单调不增——能量是**不可逆资源**，证书不能"等一等再恢复"。

**定义 45（返航能量与不搁浅不变式）**：给定安全港集合 S_safe（充电桩/静止安全位形），**返航能量** E_safe(x) 定义为在**沿路动作集随电量收缩**的条件下，从 x 抵达 S_safe 的最小能量（Bellman 不动点，见定义 49 的共归纳处）。**不搁浅不变式** NS：(x_t,b_t) 满足 b_t ≥ E_safe(x_t) + ε_res，ε_res>0 为硬安全储备。**命题**：若 NS 在每步精确保持，则任何轨迹永不搁浅；若 E_safe 被**保守上界**估计，则 NS 是 sound 的（宁可早返航，不可晚）。

**定义 46（能量分层证书与单调性引理）**：**能量分层证书** C_b(x) 表示"仅使用 A(b) 中的动作、且每步保持 NS 仍能无限期安全"这一性质；定义认证安全集 V(b) = {x : C_b(x) 成立}，其守卫 margin 记为 m(x,b)。**单调性引理**：b_1≤b_2 ⇒ V(b_1)⊆V(b_2) 且 m(x,b_1)≤m(x,b_2)。**证明直觉**：b_1 下的见证策略所用动作均在 A(b_1)⊆A(b_2) 中，且更高电量使 NS 更易满足，故同一策略在 b_2 下仍见证。**推论（分层查表）**：只需在有限电量层 {b_k} 上离线求 V(b_k) 与 m(x,b_k)，在线按当前 b 取"最近的下层"即可——低电只会更保守，绝不越界。

**定义 47（双时钟证书租约）**：租约 ℓ=(m, τ, b_τ, λ_t, λ_b, κ)，m 为测量边际下界，τ/b_τ 为测量时刻/测量电量，λ_t 为时间衰减率，λ_b 为**能量衰减率**（边际随电量下降的敏感度）。**双时钟新鲜度判据**：m − λ_t·(t−τ) − λ_b·(b_τ−b_t) ≥ θ 才可用于守卫。**命题**：若真实边际变化满足 |Δm| ≤ L_m·v_max·Δt + L_b·(c_max+c_cert)·Δb，取 λ_t=L_m·v_max、λ_b=L_b·(c_max+c_cert) 则该判据 sound。**注**：能量项**单向变差**（b 只减），因此第二项只会使结论更保守——这是并发+续航下最便宜、最可静态审计的新鲜度契约。

**定义 48（能量-新鲜度帕累托与认证能耗预算）**：设租约刷新间隔为 Δ，单次认证能耗 e_cert。时间跨度 T 内的认证能耗 E_comp(Δ)=e_cert·(T/Δ)。**认证能耗约束**：b − E_comp(Δ) ≥ E_safe(x) + ε_res。**命题（可刷新性）**：存在可行 Δ 的充要条件是最大可承受认证能耗 e_cert ≤ (b − E_safe(x) − ε_res)·Δ_min/T；若不可行，则必须切换到**零在线认证电**路径（纯能量分层查表 + 最长允许租约）。这把"新鲜度 vs 续航"显式变成一条带约束的单调优化，而不是隐式的工程直觉。

**定义 49（能量可生存核与动作门控）**：**能量可生存核** K ⊆ X×[0,B_max] 是最大的集合，使得从 K 中任一点出发存在策略（每步动作∈当时 A(b)）永远留在安全集内并保持 NS；它是"安全"与"能量"耦合的**最大不动点**（共归纳定义，天然处理"证书要电、电要靠证书"的循环）。**动作门控**：A_gate(x,b) = {a∈A(b) : (x_{t+1}, b−c(a,x)) ∈ K 且 (b−c(a,x))−E_safe(x_{t+1}) ≥ ε_res}。在线选择退化为：a* = argmax_{a∈A_gate ∩ 证书有效集 ∩ Π_u} score(a)。**命题**：若 K 由保守能量模型求得，则 A_gate 非空 ⇒ 执行后仍可无限期安全不搁浅；A_gate 为空 ⇒ 立即触发返航/协商，绝不静默放行。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 ENERGY-ACTION-CERT-ENGINE（续航证书引擎 EACE）
1. **保守能量模型**：对地形/负载/温度/电池老化给出**能耗上界包络** c_max(a,x)；宁可高估耗电，保证 E_safe 是上界、NS 是 sound。
2. **返航能量求解**：在能量层网格上对 E_safe 做 Bellman 不动点，动作集随电量收缩（定义 45），输出 E_safe 表。
3. **能量分层证书表**：离线按层 {b_k} 计算 A(b_k)、V(b_k)、m(x,b_k)，利用定义 46 单调性做自低向高的增量扩张；表结构复用 IP-56 L0/L1。
4. **双时钟租约签发**：随证书签发 (m,τ,b_τ,λ_t,λ_b,κ)，λ_b 由 ∂m/∂b 与最大能耗率保守界出；低电层自动取更长租约以省认证电（定义 48）。
5. **E-HI 触发与不搁浅守卫**：当 b−E_safe(x) 低于阈值 τ_E 时进入 E-HI，先砍语义/投机（最耗认证电）再保安全监控。

### 2.2 IP-61 ENERGY-ACTION-RUNTIME（能量-动作运行时 EART）
1. **联合守卫**：margin ← min(L0 查表 m(x,b), 时间租约衰减, 能量租约衰减, persona 上限)，并强制 NS 检查；任一不足即单调降级。
2. **可生存核动作门控**：在线只用 A_gate（定义 49），把"动作是否可行"从几何判断升级为"执行后是否仍可无限期安全不搁浅"。
3. **能量感知混合关键级**：E-HI 模式下只保留 κ≥geometry，硬隔离安全监控预算不变；与 v20 的过载 HI 正交合并（取两者更保守的模式）。
4. **认证能耗记账与刷新节奏**：维护认证能耗账本，按定义 48 求可行 Δ；不可行即退回零在线认证电的分层查表。
5. **能耗悬崖规避**：预计算 A(b) 丢失关键逃生动作的临界电量 b*(x)，在 b 接近 b* 前**主动收缩**到更保守的动作集（提前进入可生存核的内层），避免"突然需要高能耗逃生却已无电可用"的悬崖。

### 2.3 IP-62 ACTION-SPACE-VIABILITY-VALIDATOR（动作空间可行性验证器 ASVV）
1. **能量分层动作空间 fuzz**：在低电/临界电量处枚举 A(b) 的收缩，测 A_gate 空集率与悬崖触发率。
2. **能量模型对抗测试**：注入电池老化、超载、低温、颠簸地形，检验 NS 在模型误差下的实际 sound 率（这是"看不见的搁浅"的唯一照妖镜）。
3. **能耗悬崖与单调性审计**：静态检查 V(b)/m(x,b) 是否违反定义 46 单调性；定位 b*(x) 并核对主动收缩是否提前触发。
4. **能量分层共形覆盖**：把电量层作为协变量，测**条件覆盖**（v20 的 E88 升级为能量分层版），检出低电欠采样导致的覆盖崩塌。
5. **长时程续航压力**：多充放电循环 + 老化曲线，测 100h 级别的搁浅/可用性联合曲线。

## 4. 实验设计（E95–E102 硬门槛，承接 E87–E94）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E95 续航证书 soundness | 实机搁浅事件（危险位形处能量耗尽）；E_safe 保守度（估计/实测） | 0 起；≥1.0 且 <1.5 |
| E96 能量分层共形覆盖 | 各电量层条件覆盖率；低电扩张后违例；分层漂移检出率 | ≥1−α(α=0.1)；0 起；≥95% |
| E97 动作空间单调性 | V(b)/m(x,b) 单调性违例；A_gate 空集率；不可行返航率 | 0；<2%；<1% |
| E98 双时钟租约 | 能量时钟 sound 率；快放电下陈旧边际误用；p99 决策延迟 | 100%；0 起；<150μs |
| E99 E-HI 模式 | 切换时延；放电过载下安全违例；返航成功率 | <100ms；0 起；≥99% |
| E100 认证能耗-新鲜度帕累托 | 认证致搁浅事件；相对 v20 的可用性-安全联合前沿 | 0 起；不劣于 v20 且前沿外扩≥5% |
| E101 能耗悬崖规避 | 悬崖触发次数；主动收缩提前率；可用性损失 | 0；≥90%；<5% |
| E102 长时程续航 | 100h/≥500 循环搁浅；老化后覆盖失效；可用性 | 0 起；0；≥95% |

**回退**：E95 能量模型失真 → 放大 ε_res 与 c_max 包络并提高返航阈值（牺牲可用性保安全）；E96 低电覆盖崩塌 → 关闭低电认证扩张，只保留高电层证书；E97 单调性违例 → 冻结动作分层，退回单一最保守动作集；E98 能量时钟失真 → 缩短租约并禁用低电长租约优化；E100 认证致搁浅 → 全量切零在线认证电的分层查表；E101 悬崖无法规避 → 提前 20% 电量强制返航；任何红线失败 → 全链路熔断回退 v20。

## 5. 本轮最大风险

**一句话**：整套"不搁浅"保证的 soundness 完全押注在**保守能量模型**上——一旦地形/负载/低温/电池老化导致真实能耗超出 c_max 包络，NS 会**静默失效**且失效点恰在"已无法返航"的危险位形（此时任何补救都来不及），因此 E95（能量模型 soundness + E_safe 保守度）与 E102（老化长时程）必须设为最高优先级红线，并默认保留"放大储备 + 提前强制返航 + 零在线认证电查表"这条永不失 sound、只损可用性的底线。

## 1. 符号体系（增量：定义 44–49 符号）

| 符号 | 含义 | 定义 |

## 2. 关键算法（伪代码）

### IP-60 EACE：返航能量、分层证书与双时钟租约
```
def energy_safe(x, tiers, model):
    # Bellman 不动点；动作集随电量收缩；model.c 返回保守上界
    E = { (x,b): INF for (x,b) in joint_states }
    for s in SAFE_HARBOR: E[s] = 0
    repeat until fixpoint:
        for (x, b) in reverse_reachable_order:
            best = E[(x, b)]
            for a in action_space(b):
                x2 = step(x, a)
                cost = model.c_upper(a, x)        # 地形/负载/温度/老化 上界
                b2 = b - cost
                if b2 >= 0:
                    best = min(best, cost + E[(x2, b2)])
            E[(x, b)] = best
    return E                                    # 保守 => NS sound（宁可早返航）

def build_energy_tier_table(xs, tiers, C_global, E_safe):
    table = {}
    for b in sorted(tiers):                     # 自低向高，单调性支持增量扩张
        A_b = action_space(b)
        V_b = viability_kernel(xs, A_b, E_safe, reserve=EPS_RES)  # 最大不动点
        table[b] = (A_b, V_b, margins(V_b, A_b))
    return table                                # b1<=b2 => V_b1 ⊆ V_b2（引理）

def acquire_lease_energy(x, b, theta, kappa, table):
    tier = nearest_lower_tier(b)                # 低电取更保守层
    row  = table[tier].lookup(x)
    lam_t = L_m * v_max_bound(x)                # 时间衰减（承 v20 定义 41）
    lam_b = L_b * (c_max + C_CERT)              # 能量衰减（∂m/∂b 保守界 * 最大耗电率）
    return Lease(m=row.m_lo, tau=now(), b_tau=b,
                 lam_t=lam_t, lam_b=lam_b, kappa=kappa)

def lease_valid2(lease, theta, t, b, E_safe_x):
    fresh = (lease.m
             - lease.lam_t * (t - lease.tau)
             - lease.lam_b * (lease.b_tau - b)) >= theta
    nostrand = (b - E_safe_x) >= EPS_RES        # 不搁浅不变式
    return fresh and nostrand
```

### IP-61 EART：动作门控、联合守卫、能量关键级与刷新节奏
```
def energy_action_gate(x, b, K, E_safe, model):
    out = []
    for a in action_space(b):
        x2 = step(x, a); b2 = b - model.c_upper(a, x)
        if (x2, b2) in K and (b2 - E_safe(x2)) >= EPS_RES:
            out.append(a)
    return out                                 # 空集 => 立即返航/协商

def eart_guard(e, x, b, cert, persona, lease, t, K, E_safe):
    theta = cert.theta[e]
    m = min(cert.lookup(x, b).m_lo,
            lease.m - lease.lam_t*(t-lease.tau)
                    - lease.lam_b*(lease.b_tau-b),
            persona_cap[e](persona))        # 四源取 min，只收缩
    gated = energy_action_gate(x, b, K, E_safe, model)
    ok = (m >= theta) and lease_valid2(lease, theta, t, b, E_safe(x)) and bool(gated)
    return ok, gated

def ehi_trigger(b, E_safe_x, thresh):
    return (b - E_safe_x) < thresh             # 剩余续航逼近返航所需

def schedule_energy_criticality(tasks, b, E_safe_x, thresh, overload):
    ehi = ehi_trigger(b, E_safe_x, thresh)
    if ehi or overload:                        # 两种模式取更保守
        tasks = [t for t in tasks if t.kappa >= K_GEOMETRY]  # 先砍语义/投机（省认证电）
        reserve_budget(SAFETY_MONITOR, B_safe) # 安全预算硬隔离，不随模式缩
    return edf_with_rta(tasks)

def choose_refresh(horizon, e_cert, b, E_safe_x, staleness_cost):
    # 认证能耗预算（定义 48）：b - e_cert*horizon/delta >= E_safe + res
    feasible = [d for d in REFRESH_GRID
                if b - e_cert*horizon/d >= E_safe_x + EPS_RES]
    if not feasible:
        return None                            # 退回零在线认证电：分层查表 + 最长租约
    return min(feasible, key=staleness_cost)   # 可行域内最小陈旧代价
```

### IP-51/56 升级：续航-动作空间感知的守卫与证书栈

def car_transition_guard_v3(e, x, b, cert_obj, persona, lease, t, E_safe):
    theta = cert_obj.alpha_e[e] * cert_obj.theta_sim[e]
    m_lookup = cert_obj.lookup(x, b).m_lo[e]                 # 分层查表
    m_time   = lease.m - lease.lam_t * (t - lease.tau)
    m_energy = lease.m - lease.lam_b * (lease.b_tau - b)
    m_cap    = persona_cap[e](persona)
    ns_ok    = (b - E_safe(x)) >= EPS_RES
    return min(m_lookup, m_time, m_energy, m_cap) >= theta and ns_ok

def certify_light_v4(x, b, guards, persona, budget_us, criticality, E_safe):
    tier = nearest_lower_tier(b)
    row  = energy_table[tier].lookup(x)          # T-1: 分层查表（零在线认证电）
    lease = acquire_lease_energy(x, b, row.theta, criticality, energy_table)
    U = undecided_guards(row, guards)
    if not U and lease_valid2(lease, row.theta, monotonic_now(), b, E_safe(x)):
        return row, lease, -1
    if budget_us < 110 or criticality < K_GEOMETRY:
        return downgrade_monotone(row), lease, -1  # 低关键或低预算：只降不升
    status, margin = monitor_step_INT8(quantize_obs(x))         # 耗电，计入 e_cert
    row.m_lo = min(row.m_lo, margin)
    U = undecided_guards(row, guards)
    return (row, lease, 0) if not U else (downgrade_monotone(row), lease, 0)

### IP-62 ASVV：悬崖检测与能量分层覆盖
```
def detect_cliffs(tiers, table, E_safe):
    cliffs = []
    for b1, b2 in consecutive(tiers):
        for x in overlap(table[b1].V, table[b2].V):
            # 定义 46 要求 m、V 单调；任一违例即为"悬崖/不一致"
            if table[b1].margin(x) > table[b2].margin(x):
                cliffs.append((x, b1, b2, "monotonicity"))
        lost = table[b2].A - table[b1].A
        crit = [a for a in lost if is_escape_action(a, x)]
        if crit: cliffs.append((x, b2, b1, "escape_action_loss"))
    return cliffs

def energy_stratified_coverage(H_alpha, alpha, battery_tier):
    # v20 E88 升级：按电量层测条件覆盖，暴露低电欠采样
    return {tier: empirical_coverage(H_alpha[tier]) for tier in battery_tier}
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性保证 |
|---|---|---|---|
| IP-60 E_safe 不动点 | O(\|X×b\|·\|A\|) 迭代至收敛（离线） | O(\|X×b\|) | 保守 c_max ⟹ E_safe 为上界 ⟹ NS sound |
| IP-60 分层证书表 | O(#tier·\|X\|·\|A\|) 离线，增量扩张 | O(#tier·\|X\|) | 单调性引理 ⟹ 低电只会更保守 |
| IP-60 双时钟租约签发 | O(log N) 分层查表 + O(1) | 每任务 O(1) | λ_t,λ_b 保守界 ⟹ 判据 sound；能量项单向变差 ⟹ 只会更保守 |
| IP-61 动作门控 | O(\|A(b)\|) 每步 | O(1) | A_gate 非空 ⟹ 执行后仍∈K 且保 NS |
| IP-61 联合守卫 | O(\|E\|) 四源比较 + NS | 同 L0+租约 | 四源取 min ⟹ 无漏报；NS 硬检查 ⟹ 不静默搁浅 |
| IP-61 能量关键级调度 | EDF+RTA O(k log k) | 预算表 O(k) | HI/E-HI 只删不增 ⟹ 切换点不变式保持 |
| IP-61 刷新节奏 | O(\|REFRESH_GRID\|) | O(1) | 可行域空 ⟹ 退零在线认证电 ⟹ 不因认证致搁浅 |
| IP-62 悬崖检测 | O(#tier·\|X\|·\|A\|) 离线 | O(#cliff) | 定位 b*(x)；主动收缩提前于悬崖 |
| IP-62 能量分层覆盖 | O(#tier·N) | O(#tier) | 暴露条件覆盖崩塌（低电欠采样） |

**核心正确性定理（续航-动作安全）**：若 (1) 能量模型 c_upper 是真实能耗的保守上界；(2) E_safe 由定义 45 的 Bellman 不动点求得且为保守上界；(3) 每步执行的动作 a_t ∈ A_gate(x_t,b_t)；(4) 守卫 margin 满足四源取 min 且 ≥θ——则对任意轨迹，NS 恒成立且永不搁浅。**证明要点**：门控保证后继 ∈K 且保 NS；保守模型保证真实电量不低于模型电量；K 是最大不动点，其内存在无限期安全策略；归纳即得。**失效模式**：仅当能量模型被真实能耗突破（c_max 低估）时定理失效，这正是 E95/E102 红线要拦截的唯一漏洞。

## 6. 本轮最大风险

**一句话**：整套"不搁浅"保证的 soundness 完全押注在**保守能量模型**上——一旦地形/负载/低温/电池老化导致真实能耗超出 c_max 包络，NS 会**静默失效**且失效点恰在"已无法返航"的危险位形（此时任何补救都来不及），因此 E95（能量模型 soundness + E_safe 保守度）与 E102（老化长时程）必须设为最高优先级红线，并默认保留"放大储备 + 提前强制返航 + 零在线认证电查表"这条永不失 sound、只损可用性的底线。
