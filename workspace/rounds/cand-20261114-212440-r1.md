# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「低成本方案」×「力矩传感」）

> R69 让闭环学会了「问」——把 epistemic 歧义交给流匹配多模态策略 + 主动多模态交互去消解。但它默认了一件昂贵的事：**证据是免费的**。K=4 采样、冻结 LLM 问句、主动注视/探针，这些都不便宜；更糟的是，R69 自陈的最大风险恰恰是「流模型会幻觉出不存在的模态」——于是系统可能自信地追问一个幻影，或把人类一句误导性回答盖上「已验证」的章：**问错，比不问更危险**。
>
> 本轮两个灵感把它往「可落地」推了一大步：
> - **低成本方案**：真实系统里决定性的传感器（关节力矩传感器）贵、重、脆；可负担的替代（电流×K_t、动量观测器、串联弹性）便宜但**系统性有偏**。所以问题不只是「该做什么动作」，而是「**该买哪条证据、花多少钱、便宜的证据能信到什么程度**」——测量本身有价格。
> - **力矩传感**：力矩/力是**物理承诺的唯一直接通道**。视觉说「那里有个杯子」，力矩说「你确实握住了它、握力是这么多」。它局部、瞬时、因果，是 R69 的视觉残差 / 流似然都缺的第二（第三）个正交证人。
>
> 核心命题：**把「不确定性消解」从「把后验建得更准」重构成「买最便宜且足以承载决策的证据」**——代价排序的测量级联（cheap first，昂贵只在未决时升级）+ **信任反转**（低容量的物理通道拥有否决权，高容量的生成模型只能提议）。命名 **LEVER-RAS**（Leverage-grounded, Elastic-verified, Value-of-information Escalation Regime）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我该用什么去测、值不值得买这条证据、谁拥有最终否决权**」——给我一根足够便宜、足够可靠的杠杆和一个站得住的地方，我就能撬动整个昂贵闭环的安全不确定性。

## 0. 直觉与动机

**灵感 1（低成本方案 → R69 的 MINT 把「成本」看窄了）**
直觉：R69 的 VoI 决策里减去了社交/物理成本，却把「传感与计算」当成免费——好像总能负担 K 个流样本、一次 LLM 问句、一次主动注视。但具身系统的真实约束是：决定性的关节力矩传感器昂贵、易损；能装得起的电流/观测器估计又带系统性偏置。于是「信息值不值」必须扩展为「**信息每元**（information per dollar）」：既要选动作，也要选仪器；既要比收益，也要比这个收益是哪条通道、用什么代价换来的。这把 R69 的 MINT 从「动作选择器」升级为「测量经济学」。

**灵感 2（力矩传感 → 物理承诺的唯一直接通道）**
直觉：视觉/语言回答的是「世界看起来怎样」，力矩回答的是「你与世界发生了怎样的物理交换」。接触是否成立、抓取是否在滑、关节是否过载、碰撞是否发生——这些**承诺性事实**只在力矩/力里直接可见，而且它由动作引起、与动作同步（action–reaction）。因此力矩是天然的**因果证人**：它不预测未来，也不描述外观，只报告「刚刚真的发生了什么」。这正好补上 R69 三条通道（r_res 传感器自洽、Δa 行为自洽、视觉证据）都缺少的物理接地。

**灵感 3（信任反转 → 低容量做否决，高容量只做提议）**
直觉：R69 的最大风险是高容量流模型幻觉出模态。最自然的修法不是「把流模型做得更好」，而是引入一个**低容量到无法编故事**的物理通道：一个力矩符号/阈值测试很「笨」，但它物理接地、几乎不会凭空造出一个接触。于是把通常的信任顺序倒过来——**聪明的模型负责提议，笨而硬的物理通道负责否决**。便宜、低容量在这里不是缺点，而是抗幻觉的结构性优势：参数越少，能虚构的东西越少。

**灵感 4（力矩偏置的可辨识性 → 便宜代理能回答什么、不能回答什么）**
直觉：廉价扭矩代理可写成 `y_τ = A·τ + b + η`，其中 `A ≻ 0` 是摩擦/温漂/标定带来的慢变正增益，`b` 是加性漂移。绝对量值被 `A、b` 污染，**不可直接信**；但若 `A` 在一个采样窗内慢变，则 `sign(dy_τ/dt) ≈ sign(τ̇)`——**导数的符号对正缩放免疫，对常数漂移免疫**。这意味着便宜扭矩能可靠回答「接触是否**开始**、负载是否**上升**、是否在**打滑**」这类事件/趋势问题，却不能认证「力到底是 37N 还是 42N」。便宜通道的可信域由此被精确刻画：**事件与否决可信，量值认证不可信**。

**灵感 5（弹性即传感即安全 → 物理低通与机械证书）**
直觉：串联弹性执行器（SEA）用一根便宜的弹簧同时买到「力矩测量」和「被动柔顺」：`τ = k_s(θ_m − θ_l)`。更关键的是，弹簧的物理极限天然给出 `|τ| ≤ τ_sat`——这是一条**不经过任何学习模型、控制器再怎么错也越不过去**的硬约束，是一张「机械证书」。代价是引入二阶动力学、限制力控带宽。于是得到一个可量化的三难：**带宽、柔顺安全、低成本，三者不可同时最优**。这为「安全要么花钱买传感，要么花敏捷买机械」提供了定量表述。

**灵感 6（级联/早退 → R69 只是「测量免费且无损」的边界）**
直觉：把检验按成本排序，便宜的先做，只有「未决」才升级到昂贵层——这就是代价敏感的序贯检验（SPRT/Wald）。在通道条件独立、成本可加时，按「信息每元」排序的级联在给定风险下期望成本最小。R69 恰好是 `c≡0、A=I、无否决` 的边界：级联永远升级，于是它退化为「总是运行昂贵模型」。LEVER 不是替代 R69，而是把它**包成一个高预算特例**：该升级时安全不打折，能早退时省下真金白银。

**命题的总姿态**：R69 用「更好的模型」对抗不确定性；R70 用「更便宜的物理证据 + 更硬的否决」对抗它。前者赌模型不会骗人，后者赌物理不会骗人——而物理通常更值得赌。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（LEVER-RAS 总览与三不变式）** LEVER-RAS = (TEC, DRO, SEC, MIC, TIV, ELAST, FMP†)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **廉价优先的测量预算**：单位时间成本（货币/功率/延迟/维护）≤ B，任何昂贵通道（金标准力矩传感、K=4 流采样、LLM 交互）只在廉价级联返回「未决」时启用；
(iii) **低容量否决至上**：廉价物理通道组成否决集 V，高容量 FMP 只能提议，其输出必须落在 `⋂_{v∈V} Safe_v` 内，否决不可被生成模型覆盖。

**定义 311（扭矩证据通道 TEC）** 观测 `y_τ ∈ ℝ^{n_j}`，结构化偏置模型
`y_τ = A(θ,T,v,w)·τ + b(q,q̇,T) + η`，
`A ≻ 0` 为慢变正定增益（摩擦、温漂、标定），`b` 为加性漂移，`η` 为噪声。区分**金标准** `τ`（应变式扭矩传感器 / 高分辨率 SEA）与**廉价代理** `ŷ_τ`（电机电流×K_t、动量/扰动观测器 DOB、低分辨率弹性偏转）。TEC 输出 `(ŷ_τ, Â, b̂, 置信掩码)`，其中掩码只在 `S_id`（定义 313）上为真。

**定义 312（外力矩与动力学残差 DRO）** 仅用本体感知（编码器 + 电流）估计外力矩
`τ_ext = τ_act − [M(q)q̈ + C(q,q̇)q̇ + g(q) + f(q̇)]`；
策略/世界模型给出期望外力矩 `τ_ext^π`（自由空间预期为 0，接触任务预期为规划接触力）。定义动力学残差
`r_dyn = τ_ext − τ_ext^π`，及其白化范数 `‖r_dyn‖_{Σ_dyn^{-1}}`。DRO 不引入任何额外传感器。

**定义 313（可辨识扭矩子空间）** 把扭矩空间分解为 `S_id ⊕ S_cf`：
- `S_id = span{重力一致方向、慢变符号/导数方向}`（便宜代理可信）；
- `S_cf = span{绝对增益、摩擦高频、热漂移}`（便宜代理不可信）。
定义可辨识条件数 `κ_id = σ_max(P_id A)/σ_min(P_id A)`。**符号-导数前提（A100）**：`A ≻ 0` 且 `A、b` 在采样窗内慢变 ⇒ `sign(d y_τ/dt) = sign(τ̇)`。TEC 的决策输出必须显式标注它落在 `S_id` 还是 `S_cf`。

**定义 314（低成本代理充分性证书 SEC）** 代理 `ŷ_τ` 获证，当且仅当：
(a) 在 `S_id` 上与金标准一致：`‖P_id(ŷ_τ − τ)‖ ≤ ε_id`；
(b) 偏置在 `S_cf` 上可在线辨识：激励秩 `≥ r_min`；
(c) 与 R68 的 `r_res`、R69 的 `Δa` 条件独立：`I(ŷ_τ; r_res, Δa) ≤ ε_ind`。
证书随 `J_LEVER` 发布；**未获证 ⇒ 该通道只能做「事件提示」，不得做「量值认证」**。

**定义 315（测量成本与预算）** 每个通道 c 有成本向量 `c_c = (货币, 功率, 质量, 延迟, 维护)`，加权标量 `cost(c)`；单位时间预算 `B`。测量选择是带预算的序列决策：`min E[risk] s.t. Σ cost ≤ B`。成本可随状态变化（如高速时延迟成本上升）。

**定义 316（分级测量级联 MIC）** 级联 `C = (T_1 → T_2 → …)`，每级检验把状态分为「安全 / 未决 / 危险」三区；**仅「未决」升级到下一级**。阈值由代价敏感 SPRT 给出：`Λ_i = log[p(y|H_1)/p(y|H_0)]`，接受/拒绝阈值 `(A_i, B_i)` 由漏检/误报代价比与 `cost_i` 决定。级联按「信息每元」`IV_i` 降序排列；预算耗尽即返回「危险」（保守）。

**定义 317（信任反转否决 TIV）** 定义通道容量 `cap(c)`（假设空间复杂度/参数量）与安全权限 `priv(c)`。**TIV 规则**：`priv(c)` 随 `cap(c)` 单调不增；低容量通道组成否决集 V。FMP 提出的模态 `m_k` 可执行 ⟺ 对所有 `v∈V`，`m_k` 不触发 `v` 的危险区。即可行集
`𝒜_safe = 𝒜_FMP ∩ ⋂_{v∈V} Safe_v`。

**定义 318（力矩门控的 FLUID 调度）** 升级谓词
`esc(o) = [r_dyn 超阈] ∨ [廉价事件检测到接触/滑移/负载突变] ∨ [决策依赖量值但 TEC 未获证]`。
仅当 `esc` 为真才升 K、启动 MINT 交互；否则走廉价路径（R69 K=1 + 力矩事件守护）。⇒ R69 的「总是买昂贵证据」是高预算边界。

**定义 319（弹性元件与机械证书 ELAST）** 串联弹性 `τ = k_s(θ_m − θ_l)`，被动饱和 `|τ| ≤ τ_sat`（弹簧/限位极限）。一阶近似下闭环力带宽 `ω_b ∝ √(k_s/J)`，柔顺裕度与峰值力随 `1/√k_s` 改善。定义**机械证书** `MC = (k_s, τ_sat)`：无论控制器输出如何，`|τ| ≤ τ_sat` **物理上不可越界**。这是不依赖任何学习模型的硬否决。

**定义 320（力矩条件化的证据融合）** 扩展 R69 证据集 `ℰ_LEVER = ℰ_FLUID ∪ {r_dyn, y_τ, MC}`；模态后验
`p(m_k | o, y_τ) ∝ p(m_k|o) · p(P_id y_τ | m_k)`，
其中廉价通道只在 `S_id` 上更新，`S_cf` 上的分量被边缘化。证据纪律升级为「k 个正交源一致」，扭矩是其中一源；**单靠扭矩符号不得单独定案**（防低级欺骗）。

**定义 321（低成本通道的威胁模型 ℰ_frugal）** 力注入 / 磁干扰 / 电流欺骗（直接伪造 `y_τ`）、共振注入（利用无模型频段）、弹性元件老化（`k_s` 漂移使机械证书失效）、以及「便宜即可信」的社会工程（诱导系统只信廉价通道）。并入 AIC：`ℰ_LEVER = ℰ_FLUID × ℰ_frugal`。防御：`r_dyn` 与 `y_τ` 的动力学一致性交叉检验 + 弹性证书定期在线辨识。

**定义 322（廉价 VoI / 信息每元）** 定义 `IV(g, c) = VoI(g) / cost(c)`（信息每单位成本）；级联按 IV 降序排列。选择
`g* = argmax_g VoI(g)  s.t. cost(g) ≤ B 且安全认证通过`；
若所有 `IV < τ_iv`，只用廉价通道并走 R69 保守退化。

**定义 323（证书 J_LEVER）** `J_LEVER = (J_FLUID, SEC, r_dyn_p95, event_f1, veto_log_hash, escalation_ratio, cost_per_decision, elastic_MC, frugal_ver)`。
Valid ⇔ `Valid(J_FLUID)` ∧ SEC 获证或显式降级标注 ∧ 否决日志完整 ∧ 测量成本未越界。

**定义 324（退化边界：LEVER ⊇ FLUID）** 当所有通道免费且无偏（`cost≡0, A=I, b=0`）、否决集 `V=∅`、弹性极限 `τ_sat=∞` 时，MIC 恒升级、TIV 恒放行、DRO 不改变可行集 ⇒ LEVER-RAS ≡ FLUID-RAS。即 R69 是「测量免费且无损」边界；LEVER 在有限预算下以额外安全约束的方式包含它。

# IP-264 TEC：廉价扭矩代理 + 结构化偏置去偏（只信 S_id）
class TorqueEvidenceChannel:
    def __init__(self, Kt, observer, bias_model):
        self.Kt, self.obs, self.bias = Kt, observer, bias_model

    def measure(self, q, dq, ddq, i_motor, T):
        tau_proxy = self.obs.update(self.Kt * i_motor, q, dq, ddq)   # DOB/动量观测器
        alpha, beta = self.bias.predict(T, dq)                       # 慢变正增益+漂移
        tau_hat = (tau_proxy - beta) / alpha.clamp_min(1e-3)         # 去偏
        mask = self.bias.identifiable_mask(q, dq)                    # S_id 上为真
        return tau_hat, alpha, beta, mask

# IP-265 DRO：仅用本体感知的外力矩残差（第三条正交证人）
def dynamics_residual(q, dq, ddq, tau_act, tau_ext_pi, model):
    tau_ext = tau_act - model.inverse_dynamics(q, dq, ddq)           # M qdd + C dq + g + f
    return whiten(tau_ext - tau_ext_pi, model.Sigma_dyn)             # 白化 r_dyn

# IP-266 SEC：便宜代理的可辨识性证书
def certify_proxy(proxy, gold, q, dq, T, window):
    P_id = identifiability_projector(q, dq)                          # S_id 投影
    err  = rel_err(P_id @ proxy, P_id @ gold)
    rank = excitation_rank(q, dq, window)                            # 偏置激励秩
    indep = mutual_info(proxy, last_r_res, last_da)                  # 与 R68/R69 正交
    return SEC(err <= EPS_ID and rank >= R_MIN and indep <= EPS_IND)

# IP-267 MCB+MIC：代价敏感分级测量级联（安全/未决/危险）
def measurement_cascade(o_t, budget, stages):
    for st in sorted(stages, key=lambda s: s.cost / s.info_gain):    # 信息每元降序
        if not budget.allow(st): return ('danger', None)             # 预算耗尽→保守
        verdict = st.test(o_t)                                       # safe/undecided/danger
        if verdict == 'danger': return ('danger', st)                # 廉价即可否决
        if verdict == 'safe' and st.certified_for_safe:              # 仅硬证书可早退
            return ('safe', st)
        # undecided（或未获证的 safe）→ 升级到下一（更贵）级
    return ('danger', None)

# IP-268 TIV：低容量物理通道的否决权（容量越低越优先）
def trust_inversion_veto(mode, veto_channels):
    for v in sorted(veto_channels, key=lambda c: c.capacity):
        if v.in_danger_region(mode): return False                    # FMP 不能覆盖否决
    return True

# IP-270 主闭环（继承 R69，插入廉价前端）
def LEVER_RAS_round(M, obs):
    q, dq, ddq, i = obs.proprio
    y_tau, a_hat, b_hat, mask = M.tec.measure(q, dq, ddq, i, obs.T)
    r_dyn = M.dro.dynamics_residual(q, dq, ddq, M.tec.tau_act, obs.tau_ext_pi, M.dyn)
    # 1) 廉价级联：先看物理承诺，再决定是否买昂贵证据
    verdict, stage = M.mic.run(obs, M.budget,
                               stages=[M.event_gate, M.dyn_gate, M.flow_gate])
    if verdict == 'danger':
        return M.safe_stop()                                         # 廉价否决，零学习
    # 2) 仅在未决时升级到 R69 的昂贵层
    K = 4 if M.mic.escalated else 1
    samples = M.fmp.sample(obs, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, ...)
    # 3) 信任反转：高容量模态必须先过低容量物理否决
    feasible = [m for m in modes if M.tiv.veto(m, M.veto_channels)]
    if not feasible:
        return M.safe_stop()                                         # 全被否决 → 保守
    # 4) 余下同 R69：VoI 交互、FMA 第二意见、λ 两级退避
    g = M.mint.choose_interaction(feasible, obs, M.budget)
    U_epi = M.cia.update_belief(feasible, M.cia.execute(g)) if g else U_epi
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + (U_epi if g is None else 0.0)))
    mode = select_mode(feasible, U_epi, lam)
    M.vqa_f.submit_async(y_tau, r_dyn, stage, SEC=M.sec, cost=M.budget.spent)
    return M.mic.escalated, lam, mode, (U_ale, U_epi)

## 3. 推导

**引理 19（符号-导数鲁棒性）** 设 `y_τ = A τ + b + η`，`A ≻ 0`，且在采样窗内 `‖Ȧ‖, ‖ḃ‖ ≤ ε_s`。则对 `τ̇` 的符号判定错误率上界为 `O(ε_s/(|τ̇| − ε_s)) + O(σ_η/|τ̇|)`；特别地，接触起始、滑移起始、负载突变等「事件」可在不辨识绝对量值的条件下被廉价代理可靠检测。系：**便宜扭矩天然适合「否决/事件」，不适合「量值认证」**——正缩放 `α>0` 保序，常数漂移在求导后消失。

**引理 20（动力学残差的正交性）** `r_dyn` 只依赖本体感知与刚体模型，与 `r_res`（传感器自洽）和 `Δa`（策略行为似然）在真实故障下条件独立（A99）。故三者构成 `k=3` 的正交证据源，满足 R69 定义 293-iii 的证据纪律。特别地，缓变负载/接触故障可能在 `r_res` 中被标定吸收、在 `Δa` 中因策略自信而不显著，但在 `r_dyn` 中保留——因为牛顿-欧拉约束不能被标定层改写。

**引理 21（信任反转的幻觉抑制界）** 设低容量否决通道的漏报率 `≤ δ_v`（与其容量无关，仅由物理阈值/弹性极限决定），则 R69 的「幻觉模态被接受」概率从 `δ_hall`（随 FMP 容量增长而上升）降为 `≤ δ_v`；即使 FMP 完全幻觉，物理否决仍保证危险模态不被执行。系：**便宜不等于弱，低容量是抗幻觉的结构性优势**。

**引理 22（弹性元件的带宽-安全下界）** 对 SEA，被动饱和保证 `|τ| ≤ τ_sat`；同时闭环力带宽与刚度满足 `ω_b ≤ c√(k_s/J)`，最大超调能量 `∝ τ_sat²/k_s`。故「带宽 × 柔顺安全裕度」存在下界：不可能用零成本弹性元件同时获得高带宽与高柔顺。这是「安全要么花钱买传感，要么花敏捷买机械」的定量表述。

**定理 18（级联的成本-风险最优性）** 在通道条件独立、成本可加、阈值可调的假设下，按 `IV_i = IG_i/cost_i` 升序排列的级联，在所有序列策略中达到给定风险下的最小期望成本（代价敏感 SPRT 的推广）；其风险不高于单级昂贵检验，期望成本不高于任一级昂贵通道。`B→∞` 时退化为「总是运行最贵通道」。

**定理 19（LEVER 严格包含 FLUID）** 在 `cost≡0, A=I, b=0, V=∅, τ_sat=∞` 时，MIC 恒升级、TIV 恒放行 ⇒ LEVER 与 FLUID 逐指令相同。对任意有限预算与有偏代理，若**「安全」早退只由满足 A100 的硬证书（机械饱和 / 保守单侧阈值）授权**（A101），则 LEVER 在危险事件上的期望风险不高于 FLUID——廉价否决是额外的安全约束，且未决时仍升级到完整 R69。故 R69 是「测量免费无损」边界。

## 6. 本轮最大风险

**一句话**：LEVER-RAS 把安全押在「廉价扭矩通道的偏置可辨识 + 刚体/摩擦模型准确」上——**若动力学模型本身错了（负载变化、软接触、磨损、弹性老化），`r_dyn` 会被模型误差污染，而信任反转又让一个「自信但失准」的廉价通道拥有否决权，系统会否决正确的高容量提案、或用错误的物理阈值放行真实危险**；此时「便宜」不是鲁棒，而是把一个未建模的偏差升格成了最终裁判——**一个被信任的错误否决，比没有否决更危险**。

**次级风险与缓解**：
1. **单点否决**（低容量通道故障/被欺骗 → 系统瘫痪）→ 否决集多样性 + 机械证书 + 周期 SEC；
2. **模型误差污染 `r_dyn`** → 在线联合辨识摩擦/负载，只在已知区（自由空间、准静态）用 `r_dyn`；
3. **级联假安全早退** → 只允许机械饱和/保守单侧阈值授权「安全」（定理 19 的 A101）；
4. **弹性带宽下降影响任务** → 可切换刚度 / 仅安全关键关节加弹性；
5. **成本模型误设** → 在线校准成本权重，用 E303/E309 的 Pareto 前沿监督。

## 3. 关键算法伪代码

```python
# IP-264 TEC：廉价扭矩 + 结构化偏置（只信 S_id）
def measure_torque(Kt, observer, bias, q, dq, ddq, i, T):
    tau_proxy = observer.update(Kt * i, q, dq, ddq)          # 电流/DOB 代理
    alpha, beta = bias.predict(T, dq)                        # 慢变增益/漂移
    tau_hat = (tau_proxy - beta) / alpha.clamp_min(1e-3)
    return tau_hat, bias.identifiable_mask(q, dq)            # S_id 掩码

# IP-265 DRO：仅本体感知的动力学残差（第三正交证人）
def dynamics_residual(q, dq, ddq, tau_act, tau_ext_pi, model):
    tau_ext = tau_act - model.inverse_dynamics(q, dq, ddq)
    return whiten(tau_ext - tau_ext_pi, model.Sigma_dyn)

# IP-267 MIC：廉价优先的代价敏感级联
def measurement_cascade(o_t, budget, stages):
    for st in sorted(stages, key=lambda s: s.cost / s.info_gain):
        if not budget.allow(st): return ('danger', None)     # 预算耗尽→保守
        v = st.test(o_t)                                     # safe/undecided/danger
        if v == 'danger': return ('danger', st)              # 廉价即可否决
        if v == 'safe' and st.certified_for_safe: return ('safe', st)
        # 否则未决 → 升级
    return ('danger', None)

# IP-268 TIV：低容量通道否决，高容量只提议
def trust_inversion_veto(mode, veto_channels):
    return all(not v.in_danger_region(mode)
               for v in sorted(veto_channels, key=lambda c: c.capacity))

# IP-270 主闭环（继承 R69，前置廉价层）
def LEVER_RAS_round(M, obs):
    y_tau, mask = measure_torque(..., obs)
    r_dyn = dynamics_residual(..., obs.tau_ext_pi, M.dyn)
    verdict, stage = measurement_cascade(obs, M.budget,
                                         [M.event_gate, M.dyn_gate, M.flow_gate])
    if verdict == 'danger': return M.safe_stop()
    K = 4 if M.mic.escalated else 1
    samples = M.fmp.sample(obs, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, ...)
    feasible = [m for m in modes if trust_inversion_veto(m, M.veto_channels)]
    if not feasible: return M.safe_stop()
    g = M.mint.choose_interaction(feasible, obs, M.budget)
    U_epi = M.cia.update_belief(feasible, M.cia.execute(g)) if g else U_epi
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + (U_epi if g is None else 0.0)))
    mode = select_mode(feasible, U_epi, lam)
    M.vqa_f.submit_async(y_tau, r_dyn, stage, SEC=M.sec, cost=M.budget.spent)
    return M.mic.escalated, lam, mode, (U_ale, U_epi)
```

## 4. 推导

**引理 19（符号-导数鲁棒性）** `y_τ=Aτ+b+η`、`A≻0`、`‖Ȧ‖,‖ḃ‖≤ε_s` 时，`sign(τ̇)` 判定错误率 `O(ε_s/(|τ̇|−ε_s))+O(σ_η/|τ̇|)`；接触/滑移/负载突变等事件可廉价可靠检测。系：便宜扭矩适合「事件/否决」，不适合「量值认证」。

**引理 20（动力学残差正交性）** `r_dyn` 仅依赖本体感知与刚体模型，与 `r_res`、`Δa` 在真实故障下条件独立（A99），构成 k=3 正交证据源；缓变负载/接触故障在 `r_res` 被标定吸收、在 `Δa` 可能不显著，却在 `r_dyn` 保留（牛顿-欧拉约束不可被标定层改写）。

**引理 21（信任反转幻觉抑制界）** 低容量否决漏报率 `≤δ_v`，则 R69 的幻觉模态接受概率从随容量增长的 `δ_hall` 降为 `≤δ_v`；即使 FMP 完全幻觉，物理否决仍拦住危险模态。系：低容量是抗幻觉的结构性优势。

**引理 22（弹性带宽-安全下界）** SEA 被动饱和保证 `|τ|≤τ_sat`；`ω_b≤c√(k_s/J)`，超调能量 `∝τ_sat²/k_s`；「带宽 × 柔顺安全裕度」有下界——安全要么买传感，要么买机械敏捷。

**定理 18（级联成本-风险最优性）** 条件独立、成本可加下，按 `IG/cost` 排序的级联达到给定风险的最小期望成本（代价敏感 SPRT 推广）；风险不高于单级昂贵检验，`B→∞` 退化为总是运行最贵通道。

**定理 19（LEVER 严格包含 FLUID）** `cost≡0,A=I,b=0,V=∅,τ_sat=∞` ⇒ 两者逐指令相同；有限预算下若「安全」早退只由满足 A100 的硬证书授权（A101），则 LEVER 危险事件期望风险不高于 FLUID。R69 是「测量免费无损」边界。

## 7. 本轮最大风险

**一句话**：LEVER-RAS 把安全押在「廉价扭矩通道偏置可辨识 + 刚体/摩擦模型准确」上——**若动力学模型本身错了（负载变化、软接触、磨损、弹性老化），r_dyn 会被模型误差污染，而信任反转又让一个「自信但失准」的廉价通道拥有否决权：系统会否决正确的高容量提案、或用错误的物理阈值放行真实危险**；「便宜」于是不是鲁棒，而是把未建模偏差升格成最终裁判——**一个被信任的错误否决，比没有否决更危险**。

**次级风险与缓解**：单点否决（否决集多样性 + 机械证书 + 周期 SEC）；模型误差污染 r_dyn（在线联合辨识摩擦/负载，仅在已知区使用）；级联假安全早退（仅硬证书授权「安全」，定理 19 的 A101）；弹性带宽下降（可切换刚度 / 仅关键关节加弹性）；成本模型误设（在线校准 + E303/E309 Pareto 监督）。
