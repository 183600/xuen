### 第 4 轮灵感驱动研究记录（承接状态文件中的第 3 轮 CADVS-v3）

**灵感词**：模型蒸馏、研究空白

**继承关系**：第 3 轮 CADVS-v3（IP-485~488）在 v2 三锚点（3DCF/Γ_3D、MSRG/S2RC、HICK/HIC）之上追加末点锚 EEK（kc_ee）与记忆锚 LTEM（kc_mem），并以 FFA 做联邦先验，形成五硬门 kc_evidence_forged_v3 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem。执行集 Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。本轮不推翻 v3，而是用「模型蒸馏」把沉重的证据铸造栈压成可在控制环内预筛的轻量学生，用「研究空白」把「证据缺口」提升为一等、可度量、可调度的对象，形成 CADVS-v4（IP-489~492），执行集进一步收缩为 Exec_CADVS-v4 ⊆ Exec_CADVS-v3。

**直觉与动机**：

1. **模型蒸馏：把「教师证据栈」蒸馏成「学生预筛器」，但只允许学生说「不」**。v3 的五硬门每控制周期/每规则准入都要跑 3DCF + MSRG + HICK + EEK + LTEM，成本高、耦合重、难以在 1 kHz 边缘算力上全量展开。可以训练轻量学生 S_θ 拟合教师输出（各门通过概率与 ECS_v3），但关键不是让学生替代教师，而是**单边蒸馏（one-sided distillation）**：学生拒绝 ⇒ 直接拒（fail-closed）；学生接受 ⇒ 仍必须走完 v3 五硬门。于是蒸馏只可能缩小执行集，不可能放宽安全边界——把「蒸馏会丢保证」的经典担忧，转化为「蒸馏只损失可用性」的可控代价。

2. **研究空白：把「哪里没有证据」变成可优化的闭环目标**。过去各锚点只回答「此处证据是否通过」，从不回答「证据缺口在哪里、有多大、下一次该去哪里补」。定义六类 gap（空间覆盖洞、物理域洞、人因意图洞、末点标定漂移、记忆冷启动/低样本、舰队非 IID 分歧），构成 gap 向量 G(x,t,r)；kc_gap 在 gap 过大时拒绝，gap 调度器按「单位成本期望 gap 缩减」选择探索、教师查询、实机回灌与联邦轮次，把研究空白从描述性概念变成可调度的控制量。

3. **研究空白（文献层）：本轮明确指出的三个空白**。(i) 证书/安全框架缺少「知识蒸馏安全性」的形式化，通常默认学生与教师等价；(ii) 没有把「证据缺口」作为一等、可度量、可调度的对象，gap 只作为实验讨论而非在线变量；(iii) 联邦证书聚合只做参数或充分统计量平均，忽视非 IID 个性化，且蒸馏会把毒化从「可检测的统计量异常」压缩成「难追溯的软标签偏置」。v4 以单边蒸馏、gap 调度、联邦蒸馏聚合分别填补这三个空白。

**关键洞见**：教师负责「保证」，学生负责「省算力」；蒸馏只能是拒绝侧的加速器，不能是接受侧的授权器。研究空白不是失败的注脚，而是下一次采集的指令；把 gap 作为一等公民后，安全门与探索策略共享同一套证据坐标系，系统才能既守得住又学得动。

**形式化目标（增量）**：
1. 定义学生证书预测器 S_θ: (x,t,r) → (p_cov, p_phys, p_hum, p_ee, p_mem, ECS_hat)，蒸馏损失 L_distill = Σ_g BCE(p_g, y_g) + λ·MSE(ECS_hat, ECS_v3) + μ·KL(q_teacher ‖ q_student)。
2. 定义单边蒸馏门 kc_distill：若学生拒绝置信度 ≥ κ_rej 则拒；否则「不表态」并 pass-through 给教师。kc_distill 从不输出「授权」。
3. 定义蒸馏差异证书 DDC = (n_cal, frr, δ_distill, enabled)：在标定集上测「学生误拒率」frr；仅当 frr ≤ δ_distill 时启用学生，否则退回教师直通。
4. 定义研究空白向量 G = (g_cov, g_phys, g_hum, g_ee, g_mem, g_fleet) 与硬门 kc_gap = (‖G‖_∞ ≤ g_tol)。
5. 定义 gap 调度器：在动作集 A 上最大化 E[ΔG(a)]/cost(a)，证明期望 gap 缩减关于动作子集子模，贪心给 (1−1/e) 近似。
6. 定义联邦蒸馏聚合器 FDA：各站保留本地学生，在公共代理集上蒸馏全局教师软标签（FedDF 式），替代/补充 FFA 的原始充分统计量平均。
7. 定义 EFA-v4 硬门 = v3 五门 ∧ kc_distill ∧ kc_gap，且 kc_distill 单边，故 Exec_CADVS-v4 ⊆ Exec_CADVS-v3。

**本轮最大风险**：**单边蒸馏与 gap 门共同制造「安全但不可用」的坍塌**——若校准集/代理集不具代表性（恰是本轮要检测的研究空白），学生与 gap 估计会系统性误拒，机器人几乎拒绝一切，运维为恢复产能而绕过安全层，反而把「只缩不涨」的形式安全变成实际的不安全。

## 2. 关键算法骨架

### IP-489 CDK：单边蒸馏证书（控制环内，O(|θ|) 前向）

```python
@dataclass
class CertificateDistillationKernel:
    """CDK：五门教师 → 轻量学生；kc_distill 单边，只拒不放"""
    theta: StudentNet
    kappa_rej: float = 0.9          # 学生高置信拒绝阈值
    delta_distill: float = 0.05     # 允许的学生误拒率上界
    lambda_ecs: float = 0.5
    mu_kl: float = 0.1

    def predict(self, x, t_now, rule_id) -> GateProbs:
        out = self.theta(x, t_now, rule_id)
        return GateProbs(
            p_gate={g: sigmoid(out[g]) for g in GATES},
            ecs_hat=out["ecs"],
            reject_conf=out["reject_conf"],   # 学生「应拒」的校准后置信度
        )

    def kc_distill(self, p: GateProbs) -> tuple[bool, str]:
        """单边：只有高置信拒绝才拦截；其余一律不表态交给教师"""
        if p.reject_conf >= self.kappa_rej:
            return False, 'DISTILL_REJECT'
        return True, 'DISTILL_PASSTHROUGH'   # 注意：不等于授权

    def distill_loss(self, batch, teacher) -> float:
        y_gate, ecs_teacher, q_teacher = teacher.label(batch)
        p = self.predict(batch.x, batch.t, batch.rule_id)
        bce = sum(binary_cross_entropy(p.p_gate[g], y_gate[g]) for g in GATES)
        return (bce
                + self.lambda_ecs * mse(p.ecs_hat, ecs_teacher)
                + self.mu_kl * kl_div(q_teacher, p.soft))

    def build_ddc(self, calib_set, teacher) -> DDC:
        """蒸馏差异证书：只测误拒率（影响可用性，不影响安全性）"""
        fr = sum(1 for x in calib_set
                 if (not self.kc_distill(self.predict(x))[0])
                 and teacher.hard_gate(x)[0])
        n = max(len(calib_set), 1)
        frr = fr / n
        return DDC(n_cal=n, frr=frr,
                   enabled=(frr <= self.delta_distill))
```

### IP-490 RGMS：研究空白映射与调度（慢时域 + 准入时 O(1) 查询）

```python
@dataclass
class ResearchGapMapperScheduler:
    """RGMS：把证据缺口变成可度量、可调度的向量 G"""
    g_tol: float = 0.3
    w: np.ndarray = np.array([0.25, 0.20, 0.15, 0.15, 0.10, 0.15])

    def gap_vector(self, x, t_now, rule_id, hic, eec, ltem, fleet) -> GapVector:
        g_cov   = 1.0 - self.scf.gamma3d(x, t_now)                  # 覆盖亏空
        g_phys  = 1.0 - getattr(self.msrg_cache.get(rule_id), 'mu_pass', 0.0)
        g_hum   = self.hic.entropy(hic) / H_MAX                     # 意图不确定
        g_ee    = self.eek.calibration_drift(eec)                    # 末点标定漂移
        g_mem   = ltem.beta_posterior_var(rule_id, ctx)              # 低样本/冷启动
        g_fleet = fleet.site_disagreement(rule_id)                   # 非 IID 分歧
        return GapVector(g_cov, g_phys, g_hum, g_ee, g_mem, g_fleet)

    def kc_gap(self, G: GapVector) -> bool:
        return float(np.max(G.as_array())) <= self.g_tol

    def schedule(self, G: GapVector, A: list, budget: float) -> list:
        """贪心最大化 E[ΔG(a)]/cost(a)；E[ΔG] 子模 ⇒ (1-1/e) 近似"""
        chosen, remaining = [], budget
        while remaining > 0:
            a = max((a for a in A if cost(a) <= remaining),
                    key=lambda a: expected_gap_reduction(G, a) / cost(a),
                    default=None)
            if a is None or expected_gap_reduction(G, a) <= 0:
                break
            chosen.append(a); remaining -= cost(a)
            G = G.after(a)          # 更新缺口后继续
        return chosen
```

### IP-491 FDA：联邦蒸馏聚合器（异步、慢时域，不在控制环）

```python
@dataclass
class FederatedDistillationAggregator:
    """FDA：代理集软标签蒸馏 + 鲁棒聚合，替代原始统计量平均"""
    n_sites: int
    proxy_set: list                 # 公共/脱敏代理集 P
    epsilon: float = 1.0
    delta: float = 1e-5
    mu_kd: float = 0.5
    trim_frac: float = 0.2          # 修剪聚合，限制单站影响

    def local_distill(self, local_model, global_teacher, local_data):
        """本地学生 = 本地监督 + 全局教师在 P 上的软标签（本地数据不离站）"""
        for x in self.proxy_set:
            soft = global_teacher.soft(x)
            local_model.update(x, soft, weight=self.mu_kd)
        return local_model

    def aggregate_soft(self, site_models) -> dict:
        """服务器只在 P 上聚合软标签；逐点修剪均值，单站影响力 ≤ 1/n_sites"""
        agg = {}
        for x in self.proxy_set:
            vals = sorted(m.soft(x) for m in site_models)
            k = int(len(vals) * self.trim_frac)
            kept = vals[k: len(vals) - k] if k else vals
            agg[x] = np.mean(kept, axis=0)
        return agg

    def dp_soft(self, agg: dict) -> dict:
        sigma = np.sqrt(2 * np.log(1.25 / self.delta)) / self.epsilon
        return {x: v + np.random.normal(0, sigma, size=np.shape(v))
                for x, v in agg.items()}
```

### IP-492 EFA-v4：v3 五门 + 单边蒸馏 + 缺口门

```python
@dataclass
class EvidenceForgingAssemblerV4:
    """EFA-v4：教师不可绕过；学生与 gap 只可能提前拒绝"""
    v3: EvidenceForgingAssemblerV3
    cdk: CertificateDistillationKernel
    rgms: ResearchGapMapperScheduler
    ddc: DDC

    def hard_gate(self, x, t_now, rule_id, hic, eec, ctx) -> tuple[bool, str]:
        # 1) 学生单边预筛：高置信拒绝才拦截，接受不授权
        if self.ddc.enabled:
            ok, why = self.cdk.kc_distill(self.cdk.predict(x, t_now, rule_id))
            if not ok:
                return False, why                 # DISTILL_REJECT
        # 2) 缺口门：gap 过大拒绝
        G = self.rgms.gap_vector(x, t_now, rule_id, hic, eec,
                                 self.v3.ltem, ctx.fleet)
        if not self.rgms.kc_gap(G):
            return False, 'GAP_TOO_LARGE'
        # 3) 教师五门（v3，不可绕过）
        return self.v3.hard_gate(x, t_now, rule_id, hic, eec,
                                 ctx.object_class, ctx.geo_sig,
                                 ctx.theta_domain_fp)
```

## 4. 正确性论证（增量更新）

### 引理 41（单边蒸馏的执行集单调性）

**陈述**：kc_distill 仅在高置信拒绝时返回拒绝，从不返回「授权」；kc_gap 仅在 ‖G‖_∞ > g_tol 时拒绝。则对任意 (x,t,r)，若 EFA-v4 通过，则 EFA-v3 必通过。因此 Exec_CADVS-v4 ⊆ Exec_CADVS-v3，且蒸馏与 gap 门只可能移除路径、不可能新增路径。

**证明**：EFA-v4 的接受条件是「(ddc 启用时) kc_distill 未拦截」∧「kc_gap 通过」∧「v3 五门全部通过」。前两项都是纯合取式的额外必要条件；去掉它们得到 v3 的接受条件。故 v4 的接受集合是 v3 接受集合的子集。∎

**工程含义**：学生再差、gap 估计再偏，也不会让 v4 接受 v3 会拒绝的路径；蒸馏的安全性不依赖学生精度，只依赖「从不授权」这一结构约束。

### 引理 42（误拒率界与 DDC 门控）

**陈述**：设标定集 D_cal 由部署分布 i.i.d. 采样，n_cal = n。经验误拒率 frr_n = (1/n)Σ 1[学生拒 ∧ 教师受]。则对任意 ε>0，P(|frr_n − frr| ≥ ε) ≤ 2exp(−2nε²)（Hoeffding）。DDC 仅在 frr_n ≤ δ_distill 时启用学生；因此启用后的真实误拒率以高概率不超过 δ_distill + ε。

**证明**：误拒指示变量有界于 [0,1]，独立同分布，直接应用 Hoeffding 不等式；DDC 的 enabled 条件即 frr_n ≤ δ_distill。∎

**工程含义**：蒸馏带来的可用性损失可被显式测量与门控；一旦标定集不再代表部署分布（frr 漂移），DDC 自动退回教师直通，避免学生持续误拒。

### 引理 43（gap 调度子模性与近似比）

**陈述**：设 f(S) = E[G_before − G_after(S)] 为执行动作子集 S 后的期望 gap 缩减。若每个动作对 gap 的边际收益随已选动作增加而递减（覆盖、标定、记忆样本均满足边际递减），则 f 单调子模；贪心调度在预算约束下达到 (1−1/e) 的近似最优（基数约束）或标准成本-收益近似。

**证明**：边际递减即子模性定义；贪心对单调子模函数在基数约束下的 (1−1/e) 近似为经典结果（Nemhauser–Wolsey–Fisher）；成本约束下用密度贪心给相应近似界。∎

**工程含义**：不必穷举探索/查询组合，按「单位成本期望 gap 缩减」贪心即可接近最优，且可在线增量更新。

### 引理 44（联邦蒸馏的隐私与单站影响界）

**陈述**：FDA 在代理集 P 上只交换软标签，经高斯机制 (ε,δ)-DP 扰动，并以 trim_frac 修剪聚合。则 (a) 单站对聚合软标签的影响至多 O(1/((1−2·trim_frac)·n_sites))；(b) 原始感知数据与本地充分统计量不离站；(c) 本地学生保留本地数据，故非 IID 个性化不被平均抹平。

**证明**：(a) 修剪均值在剔除两端后，单点替换对均值的影响被 1/(保留点数) 约束；(b) 交换内容仅为 P 上的软标签；(c) 本地学生参数不被服务器覆盖，服务器只提供软标签正则。∎

**工程含义**：相比 FFA 对原始 Δ_i 的 FedAvg，FDA 把「毒化统计量」换成「毒化软标签」，单站影响更易被修剪与 DP 限制；但代理集 P 的代表性成为新的系统级依赖。

### 定理 v4（执行集再收缩与蒸馏-缺口补全）

**陈述**：在以下假设下：(C1) 引理 41 的单边结构成立；(C2) DDC 标定集与部署分布同分布或漂移被 DDC 检出；(C3) gap 向量各分量可观测且 gap 缩减关于动作子集子模；(C4) 代理集 P 对舰队分布具有代表性或偏差被审计检出；(C5) 继承 v3 的 (B1)~(B4)。则：
(i) Exec_CADVS-v4 ⊆ Exec_CADVS-v3（严格收缩，严格性由 kc_distill/kc_gap 在 v3 未拒处关闭路径保证）；
(ii) 蒸馏不降低安全性：v4 的假接受率相对 v3 不增加（引理 41）；
(iii) 启用学生后的真实误拒率以高概率 ≤ δ_distill + ε（引理 42）；
(iv) gap 调度在预算下达到 (1−1/e) 近似（引理 43）；
(v) FDA 满足 (ε,δ)-DP，单站影响受修剪与 DP 双重约束，且保留本地个性化（引理 44）。

**证明**：(i)(ii) 由引理 41 的子集关系直接得；(iii)~(v) 分由引理 42、43、44；v3 五门未被修改，其保证原样继承。∎

**诚实声明**：(C2) 与 (C4) 是本轮最脆弱假设。学生与 gap 估计都以「标定集/代理集代表部署分布」为前提；而这恰恰是本轮要检测的研究空白本身，存在循环依赖。若标定集系统性偏离部署（例如只在理想光照下采集），学生会对真实部署高置信误拒，gap 估计也会低估真实缺口。缓解：DDC 漂移检测、代理集多源审计、gap 指标留出集交叉验证、以及「教师直通」降级模式。

## 7. 本轮最大风险（最终确认）

**一句话**：**单边蒸馏与 gap 门共同制造「安全但不可用」的坍塌**——若校准集/代理集不具代表性（恰是本轮要检测的研究空白），学生与 gap 估计会系统性误拒，机器人几乎拒绝一切，运维为恢复产能而绕过安全层，反而把「只缩不涨」的形式安全变成实际的不安全。
