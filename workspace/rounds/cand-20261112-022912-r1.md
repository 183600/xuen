# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化证据承诺」IP-133~138；新灵感循环第 1 轮；本轮灵感：「安全交互」×「抓取」）

> 第 53–57 轮把"该不该落下这一脚"越做越深：语义护盾 → 证据地图 → 证据承诺 → 少样本/跨模态/个性化。但它们共享一个隐含前提——**接触是可回收的**：落脚错了可以卸力、抬脚、绕行，代价被"自身摔倒"这一可交易项吸收。本轮两个灵感正好击穿这个前提。**「抓取」**引入新的不可逆性：一旦提升，物体可能滑落、破碎、或把机器人拽倒；更尖锐的是，**抓取既是探测也是伤害**——不施加力就测不出摩擦，而施加的力本身就可能压碎它，第 56–57 轮"非破坏探针 → 承诺"的干净二分在这里塌缩。**「安全交互」**引入一类**不可交易的第三方**：人的安全不能与机器人自损、物体破损放进同一个概率和里做期望优化；而且被抓取的对象可能是人递来的，甚至人本身就是交互对象。于是本轮把核心命题由"证据说可信"升级为 **"接触即契约：只有能证明存在安全力/能量走廊、且失败可回收、对人有硬包络的接触才可承诺"**。第 57 轮"一切判定器走隔离"进一步推广为"**一切不可逆接触走契约**"。

核心矛盾：
- **H29（探与诺同体）**：抓取中"测摩擦"与"冒压损"是同一个动作；证据经济学的"先探后诺"假设失效，探针的代价不再是时间而是不可逆损伤，因而必须区分**可回收探针**与不可回收动作，并证明前者的最坏结果仍在可恢复集内。
- **H30（走廊存在性 vs 不确定性）**：安全抓取等价于存在非空力区间 [F_lo,F_hi]（上界避压碎、下界避滑落）；但两端由同一组隐变量（摩擦、柔顺、质心）决定，且常由同一路滑移-力传感观测。不确定性既可让走廊被**误判为空**（过度保守、拒抓可用物），也可让走廊被**误判非空**（最危险：把"屈服"看成"滑动"）。
- **H31（人的非概率权利）**：人因风险不能进入 P_safe 的可交易求和项；但纯硬约束在感知不确定下无法直接执行，必须落在"认证保守模型 + 物理柔顺/反射层"上，而不是落在置信度上。

## 0. 直觉与动机

**灵感 1（抓取 → 力走廊而非单点力）**
直觉：抓取不是"合上手指再抬"，而是先证明**存在一条既高于打滑、又低于压碎的力带**。F_lo 来自摩擦锥/质量估计，F_hi 来自柔顺/脆性/内部结构；安全抓取 = 走廊非空且能被计划轨迹持续占据。走廊为空不是参数没调好，而是一个可判定的"此物此刻不可抓"结论——拒抓是正解而非失败。

**灵感 2（抓取即探测 → 可回收探针）**
直觉：既然不能先无损探测再抓，就把危险动作拆成**可回收的渐进接触**：准静态力斜坡、微抬升、微剪切，让"滑移起始"这一事件成为最富信息的观测；每一步的最坏结果都必须仍落在可回收集内（松手放回台面/被另一手接住）。探针不是免费的，但它的代价被"可回收"封顶。

**灵感 3（安全交互 → 非对称账本 + 能量预算）**
直觉：把风险分成三本账——机器人自身（可交易）、物体（可交易但受物主价值约束）、人（**不可交易**）。人只以**硬包络**出现：相对速度、接触力、距离在任何结果下都不能越界；再用**交互能量预算**把"接近速度-接触力-柔顺"统一成一个屏障函数，而不是三套独立阈值互相打架。

**灵感 4（交接 → 无处可落的物体不变量）**
直觉：人机共同操作时，最危险的不是抓空，而是**交接瞬间双方都以为对方拿着**。把交接建模成 custody 状态机与一条分布式不变量：任意时刻物体要么被某个持有有效证书的 custodian 支撑，要么稳定放在支撑面上；违反即最高级安全停。

**灵感 5（合流 → 反射层与契约层双层）**
直觉：走廊算得再准也晚于滑移。需要一个**不被上层覆盖**的反射层：滑移→在不超过 F_hi 的前提下向 F_target 收紧；出现屈服/损伤迹象→退回 F_lo；持续滑移或走廊失效→松手并支撑。上层规划只能在反射层保证的可回收集内活动。所有新机制仍只经"信念更准"或"动作更保守"两个安全通道起作用。

## 1. 形式化定义（增量：定义 139–146）

**定义 139（抓取力走廊证书 GCC）** 物体隐参数 θ_g=(m,c_cm,μ,κ,p_struct)（质量/质心/摩擦/柔顺/内部结构脆性）。抓取位形 g 的接触映射 G(g)、接触力/力矩 f。定义抗滑下界 F_lo(θ_g,g)=min{f: P_slip(f;θ_g,g)≤δ_slip}、抗损上界 F_hi(θ_g,g)=max{f: P_dmg(f;θ_g,g)≤δ_dmg}，走廊 C_g(θ_g)=[F_lo,F_hi]。**GCC(g) 成立** ⇔ P_{θ_g|E}(F_lo<F_hi)≥1−α_grasp 且存在轨迹 f(t)⊂C_g 覆盖计划动作（提升/移动/交接）。走廊为空或置信不足 ⇒ 判 **unliftable**；不可逆动作要求更小的 δ_slip、δ_dmg 与 α_grasp。GCC 是"此抓取此刻可承诺"的唯一凭据。

**定义 140（可回收抓取探针 GRP, Grasp-to-Sense）** 探针 a（力斜坡/微抬升/微剪切）在抓取 g 上**可回收** ⇔ 执行 a 的最坏结果存在策略 π_rel 在 τ_rec 内把物体送回支撑态（台面/原支撑/另一手/人），且转移过程对物体与人注入能量 ≤E_rec。可回收集记 A_rec(g)。**滑移起始事件** s\*=argmin_t (dτ/dt>0 ∧ 切向位移>ε_s)：在粘-滑转变处观测最富信息。GRP 规则：只在 A_rec(g) 内选探针；观测 s\* 后更新 θ_g 而非直接加力；若 A_rec(g)=∅，只能"放置/支撑/请求协助"，禁止提升。

**定义 141（非对称交互风险 AHR）** 风险目分三类：self（可交易）、object（可交易，受物主价值权重 v_obj 约束）、human（**不可交易**）。对人定义硬安全包络 H={(v_rel,F_c,d): v_rel≤v_max(d), F_c≤F_safe, d≥d_min(v_rel)}，基于认证保守人体模型与物理柔顺/反射层，**不依赖感知置信度**、不进入 P_safe 求和。执行规则：若动作在任意感知后验下可能违反 H，则动作不可执行（约束满足优先于期望优化）；个性化/任务激励/信任等级均无权放宽 H。

**定义 142（交互能量预算 IEB）** 交互能量 E_int=½m_eff·v_rel²+∫F_c dx+E_elastic（含接触做功与弹性储能）。按对象分级 E_budget(obj)（脆性/人体部位/刚性/柔性容器）。控制屏障 h_E(o)=E_budget(obj)−E_int，安全 ⇔ h_E≥0 ∧ ḣ_E≥−γ·h_E。接近速度、抓取力、柔顺增益统一按 h_E 缩放：**安全交互 = 一个能量预算同时约束速度、力与柔顺**，而非三套阈值。

**定义 143（交接 custody 契约 HOC）** custody∈{robot,human,shared,surface}。**不变量 INV-O**：任意时刻 ∃ 支撑方 s，使物体处于支撑状态且 s 持有有效证书（robot⇒GCC；human⇒显式 hold 信号且 H 满足；surface⇒稳定放置）。协议：giver 发 release-intent；receiver 仅在持有 GCC 或已进入 shared 双支撑态时才可接收；否则回 support/refuse。超时 ⇒ 双方回 shared 或放置；检测到 INV-O 可能违反 ⇒ 最高级安全停。

**定义 144（抓取反射与监督 GRC）** 反射层延迟 ≤τ_refl，事件到动作：slip ⇒ f←min(F_target,F_hi) 收紧（**绝不超过 F_hi**）；yield/damage 迹象 ⇒ f←F_lo 下退；持续 slip 或走廊失效 ⇒ open&support（进入 A_rec 的终态）。上层（PCE++）只能规划在反射层保证的可回收集内，且**不得覆盖**反射；不存在"为防滑而越上限"的指令。

**定义 145（接触契约证据门 CCE 与证书 J_c）** 证据类扩展：EV-grasp（GCC 成立且可执行轨迹存在）、EV-slip-onset（可回收探针观测到 s\* 且此后稳定）、EV-custody（INV-O 保持）、EV-human-envelope（H 在认证模型下成立）。不可逆抓取必要证据集 = EV-grasp ∧ (EV-slip-onset ∨ EV-margin) ∧（涉及人 ⇒ EV-human-envelope）；禁止以 EV-visit/EV-xmodal 单独支撑不可逆抓取。J_c 继承 J_p，新增 gcc、θ_g 后验、probe_corridor、energy_log、custody_log、human_envelope_log、reflex_log。

**定义 146（接触契约算子 PCE++）** 在 PCE+ 每检查点后插入抓取子过程：①由先验/视觉/微探更新 θ_g 并估走廊；②在 A_rec(g) 内按 VOI 选可回收探针；③尝试构造非空走廊：空 ⇒ 换抓取点/换策略/请人协助/拒抓；④提升前要求 GRC 报 safe 且 CCE 通过；⑤涉及人走 HOC 与 AHR。终止态扩展为 {承诺, 绕行, L2 协商, 安全停, 拒抓/改抓, 交接/支撑}。

## 2. 关键算法伪代码（完整版见产物区）

```python
def grasp_corridor_cert(theta_post, g, plan):
    lo = min_force(lambda f: slip_prob(f, theta_post, g) <= delta_slip)
    hi = max_force(lambda f: dmg_prob(f, theta_post, g)  <= delta_dmg)
    p_ne = prob(theta_post, lambda th: F_lo(th, g) < F_hi(th, g))
    if p_ne < 1 - alpha_grasp or lo >= hi:
        return Cert(ok=False, reason='empty_corridor')     # unliftable
    return Cert(ok=True, C=[lo, hi], covers=traj_in(plan, lo, hi))

def recoverable_probe(g, theta_post, A_rec):
    cands = [a for a in A_rec if a.max_energy <= E_rec]    # 可回收封顶
    if not cands: return theta_post, 'support_only'
    a = argmax(cands, key=lambda a: voi(a, theta_post) - cost(a))
    obs = execute_with_reflex(a, g)                        # GRC 监督执行
    return update_theta(theta_post, obs.slip_onset), 'ok'
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| GCC | O(n_θ·\|C\|)/抓取估计 | O(\|Θ_g\|) | 走廊判定保守、δ 诚实 |
| GRP | O(\|A_rec\|·T_ramp) | O(\|A_rec\|) | 最坏结果 ∈ R、τ_rec 有界 |
| AHR/IEB | O(1)/控制周期 | O(1) | H 不依赖置信度（A43） |
| HOC | O(1)/事件 | O(\|custody\|) | INV-O 可检测（A44） |
| GRC | O(1)/事件，≤τ_refl | O(1) | 不越过 F_hi、不被上层覆盖 |
| CCE+PCE++ | O(\|CP\|·(k_p+k_c+k_g)) | O(\|V\|+\|σ\|) | 无证书不提升、走廊空即拒 |

**正确性定理（Safe Contact Covenant Soundness, SCCS 概要）**：在 A37–A40 上加 (A41) θ_g 区间后验与力/滑移传感校准诚实、F_lo<F_hi 判定可靠；(A42) 可回收探针最坏结果 ∈ R 且 τ_rec 有界、反射层延迟 ≤τ_refl 且不可被上层覆盖；(A43) 人体硬包络基于认证保守模型且不依赖感知置信度；(A44) 交接支撑/持有信号诚实；(A45) 能量预算分级保守。则：(i) 提升发生在 GCC 有效期内 ⇒ P(滑落∨压损) ≤ δ_slip+δ_dmg+α_grasp+δ_sense；(ii) A_rec 内探针失败以 ≥1−δ_rec 概率回到支撑态，不产生不可逆后果；(iii) 在 A42/A43 下 H 违反概率为 0 且不随感知/个性化/激励变化；(iv) 若 HOC 执行且 A44 成立，则 INV-O 恒成立、超时回双支撑；(v) 五项新机制仅经"更准的 θ_g / 更保守的可回收集 / 更小的能量预算"起作用。

## 6. 本轮最大风险

**一句话**：本轮把"接触是否安全"压成一条力走廊 [F_lo,F_hi]，而走廊两端由同一隐变量（柔顺/摩擦/质心）驱动、又常由同一路滑移-力传感观测——最危险的不是走廊算错，而是物体屈服时"看起来像在滑"：抗滑反射与抗损上限被同一个错误柔顺估计同时欺骗，系统一边通过全部证书检查、一边把力螺旋推过断裂点；必须以独立通道交叉校验柔顺、把"未知柔顺"直接视为走廊为空，并默认只支撑不提升。

### IP-139 GCC（抓取力走廊证书）

```python
def grasp_corridor_cert(theta_post, g, plan, deltas):
    lo = min_force(lambda f: slip_prob(f, theta_post, g) <= deltas.slip)
    hi = max_force(lambda f: dmg_prob(f, theta_post, g)  <= deltas.dmg)

    if p_ne < 1 - deltas.alpha or lo >= hi:
        return Cert(ok=False, reason='empty_corridor')    # unliftable
    if not traj_within(plan, lo, hi):
        return Cert(ok=False, reason='plan_exceeds_corridor')
    return Cert(ok=True, C=[lo, hi], p_nonempty=p_ne)
```

### IP-140 GRP（可回收抓取探针 / 抓取即探测）

```python
def grasp_to_sense(g, theta_post, A_rec, E_rec):
    cands = [a for a in A_rec(g) if worst_energy(a) <= E_rec]
    if not cands:
        return theta_post, 'support_only'                # 无可回收探针
    a = argmax(cands, key=lambda a: voi(a, theta_post) - cost(a))
    obs = execute_with_reflex(a, g)                      # GRC 监护执行
    theta_post = bayes_update(theta_post, obs.slip_onset, obs.force)
    return theta_post, 'ok'
```

```python
def grasp_reflex(force, corridor, obs, tau_refl):
    assert latency(obs) <= tau_refl
    if obs.slip and force < corridor.hi:
        return min(corridor.target, corridor.hi)         # 收紧但封顶
    if obs.yield_evidence or obs.damage:

    return force
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| GCC | O(n_θ·\|C\|)/抓取估计 | O(\|Θ_g\|) | 走廊判定保守、δ 诚实（A41） |
| GRP | O(\|A_rec\|·T_ramp) | O(\|A_rec\|) | 最坏结果 ∈ R、τ_rec 有界（A42） |
| AHR/IEB | O(1)/控制周期 | O(1) | H 不依赖置信度（A43） |
| HOC | O(1)/事件 | O(\|custody\|) | INV-O 可检测、超时回退（A44） |
| GRC | O(1)/事件，≤τ_refl | O(1) | 不越 F_hi、不被上层覆盖（A42） |
| CCE+PCE++ | O(\|CP\|·(k_p+k_c+k_g)) | O(\|V\|+\|σ\|) | 无证书不提升、走廊空即拒、六态完备 |

**正确性定理（Safe Contact Covenant Soundness, SCCS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** θ_g 区间后验与力/滑移传感校准诚实，F_lo<F_hi 判定可靠；**(A42)** 可回收探针最坏结果 ∈ R 且 τ_rec 有界，反射层延迟 ≤τ_refl 且不可被上层覆盖；**(A43)** 人体硬包络基于认证保守模型且不依赖感知置信度；**(A44)** 交接支撑/持有信号诚实；**(A45)** 能量预算分级保守。则：

1. **抓取健全性**：提升发生在 GCC 有效期内 ⇒ P(滑落∨压损) ≤ δ_slip + δ_dmg + α_grasp + δ_sense。
2. **可回收性**：A_rec 内探针失败以 ≥1−δ_rec 概率回到支撑态，不产生不可逆后果。
3. **非对称安全**：在 A42/A43 下，H 被违反的概率为 0，且不随感知置信度、个性化授权、任务激励变化——人因项**不进入可交易概率和**。
4. **交接不变量**：若 HOC 执行且 A44 成立，则 INV-O 恒成立；超时回双支撑，不产生"无支撑物体"。
5. **交互单调性延续**：GCC/GRP/AHR/IEB/HOC/GRC 只能经"更准的 θ_g、更保守的可回收集、更小的能量预算、更早的反射"影响系统，不存在升险路径。

**部署界**（人因项作为硬约束独立成立，不参与求和）：

```
P_safe ≥ 1 − Σ_cp (δ_slip + δ_dmg + α_grasp + δ_rec + δ_sense + δ_grasp_probe)
             − P(走廊估计陈旧未检出) − P(反射超时) − P(交接信号失效)
约束： P(H 违反) = 0  （在 A42/A43 下）
```

关键：**走廊给可决断性**（非空即可承诺、为空即可拒抓，把"抓不抓"变成可判定命题）；**可回收性给不可逆动作封顶**（探针可以失败，但失败不越过不可逆边界）；**非对称账本给伦理边界**（人的安全不是概率项，个性化与激励无权放宽）；**反射层给时间维度**（决策慢于滑移，物理反射必须独立且保守）。

## 6. 本轮最大风险

**一句话**：本轮把"接触是否安全"压成一条力走廊 [F_lo,F_hi]，而走廊两端由同一隐变量（柔顺/摩擦/质心）驱动、又常由同一路滑移-力传感观测——最危险的不是走廊算错，而是物体屈服时"看起来像在滑"：抗滑反射与抗损上限被同一个错误柔顺估计同时欺骗，系统一边通过全部证书检查、一边把力螺旋推过断裂点；必须以独立通道交叉校验柔顺、把"未知柔顺"直接视为走廊为空，并默认只支撑不提升。
