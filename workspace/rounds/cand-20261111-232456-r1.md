# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++（v31）；灵感循环第 6 轮；本轮灵感：「双足机器人」×「少样本学习」）

> 第 54 轮已把技能组合提升为动作空间剖面 + 云边联合证书。本轮把平台切换到 **双足机器人**：引入 **步态相位 φ、接触模式 σ、可行性核 V**；同时用 **少样本学习** 处理新地形/新扰动下的快速适配。核心矛盾：**H22**：双足技能是相位-接触条件化的，第 54 轮的静态动作剖面 `α_S(a)` 会在支撑相/摆动相之间产生"同名动作、不同物理含义"的虚假兼容；**H23**：少样本适配依赖小支持集，平均鲁棒性谱 ρ 无法约束 **跌倒这类不连续灾难事件**，且元先验可能在 query 任务的某些相位-接触区域整体 OOD。

## 0. 直觉与动机

**灵感 1（双足 → 技能是相位与接触的函数，而非动作集合）**
直觉：对双足，同一个关节轨迹在"支撑相"意味着承重与地面反力（GRF），在"摆动相"意味着抬脚与避障；静态动作集合上的 Jaccard 兼容性会把二者误判为同一动作。因此技能应建模为 `α_S(a, φ, σ) : 𝔄 → [0,1]`，其中 `φ` 为步态相位、`σ` 为接触模式（左/右单支撑、双支撑、腾空）。动作空间不是集合，而是 **相位-接触流形** `𝔄 = ⊔_{σ∈Σ} (A_σ × S¹)`。这把第 54 轮的 ACS 从"静态占用"升级为"随相位与接触滑动的占用"。

**灵感 2（接触调度 → 组合是接触模式的拼接，边界必须物理连续）**
直觉：双足技能组合不是"动作交集非空"即可，而是 `S_i` 结束时的接触模式与落脚点必须能接到 `S_j` 的起始接触模式；落脚点、CoM 速度、捕获点（capture point）在边界处要连续，且捕获点仍落在可支撑域内。于是把第 54 轮组合图升级为 **接触调度图**，边权同时惩罚速度差、落脚差、相位差与捕获点跳变：`c_contact = w_v||v⁻-v⁺|| + w_p||p_foot⁻-p_foot⁺|| + w_φ d_S¹(φ⁻,φ⁺) + w_ξ||ξ⁻-ξ⁺||`。

**灵感 3（少样本 → 元先验把"新地形适配"变成任务后验，而非从零学习）**
直觉：双足面对冰面/碎石/斜坡时，可用真实经验极少（跌倒即终止）。元先验 `π_θ` 在仿真地形分布 `p(𝔗)` 上做 episodic 训练，边端用 `k` 次支持试验得到任务嵌入 `z_T`，再查询/适配技能参数。少样本的关键不是拟合支持集，而是 **支持集对 query 相位-接触流形的覆盖**：若 `k` 次试验只覆盖单支撑，query 里的双支撑转换就是 OOD，此时正确动作是 **弃权** 而不是硬适配。

**灵感 4（双证书 → 少样本泛化界管"平均"，可行性核管"灾难"）**
直觉：平均 regret/PAC-Bayes 界管不住跌倒，因为跌倒是低概率、高代价、不连续事件。必须把保证拆成两份：(a) **元适配证书** 用 PAC-Bayes + 支持覆盖给 query 平均风险界 `ε_meta(k,δ)`；(b) **可行性核证书** 用捕获点裕度 `m_cp` 与 N-step capturability 给"不跌倒"的尾部保证。更进一步，少样本的每次支持试验都被安全盾约束在 `V_N` 内，避免"为采样而摔"。

**灵感 5（金字塔扩展 → 元-相位层 𝕄）**
直觉：在 `𝕃`（鲁棒性）与 `𝔸`（动作-协同）之上叠加 `𝕄`：`𝕄_0` 混合动力学/接触，`𝕄_1` 相位-接触剖面，`𝕄_2` 接触调度组合，`𝕄_3` 少样本元适配。跨层证书同时携带 `ρ(·;k)`、`C_S`、`z_T`、`V_cert`，形成 **相位-接触-元适配三证书**，与第 53/54 轮的 ρ 与 A_cert 相容（ρ 是其在固定 φ,σ 下的切片）。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（相位-接触动作流形）**
接触模式集合 `Σ`（单支撑、双支撑、腾空），步态相位 `φ ∈ S¹`。双足动作空间
```
𝔄 = ⊔_{σ∈Σ} (A_σ × S¹)
```
技能 `S` 的剖面容差 `α_S : 𝔄 → [0,1]`，`α_S(a,φ,σ)` 为在相位 φ、接触 σ 下执行 a 的可执行置信度。任务 `T` 为相位标注轨迹 `A_T = {(a_t,φ_t,σ_t)}_{t=1}^{H}`。**相位覆盖**
```
cover(S, A_T) = 1 ⟺ ∀ t ∈ [1,H], α_S(a_t,φ_t,σ_t) ≥ θ_cov
```

**定义 122（接触调度与相位兼容）**
技能 S 的接触调度 `C_S = ((σ_1,[0,τ_1)), (σ_2,[τ_1,τ_2)), …, (σ_m,[τ_{m-1},τ_m)))`。组合边界兼容
```
compat_C(S_i,S_j) = 1 ⟺ σ_m(S_i)=σ_1(S_j)
                     ∧ d_S¹(φ_end(S_i), φ_start(S_j)) ≤ ε_φ
                     ∧ ||p_foot^end(S_i) - p_foot^start(S_j)|| ≤ ℓ_step
```
边界转移成本
```
c_contact(S_i,S_j) = w_v||v⁻-v⁺|| + w_p||p⁻-p⁺|| + w_φ d_S¹(φ⁻,φ⁺) + w_ξ||ξ⁻-ξ⁺||
```
其中 `ξ = c + ċ/ω`（捕获点，`ω=√(g/h)`）。

**定义 123（接触调度组合图）**
`G_C = (V,E_C)`，`E_C = {(i,j) | compat_C(S_i,S_j) ∧ c_contact(S_i,S_j) ≤ τ_e}`。每条边附带 **相位组合证书**
```
C_comp^φ = (A_overlap^φ, C_boundary, ρ_comp(·;k), V_cert, z_T)
```
组合路径必须在每个相位边界满足定义 122，路径总成本最小化 `Σ c_contact`。

**定义 124（少样本任务分布与元先验）**
任务分布 `p(𝔗)`（地形、负载、外部扰动）。元先验 `π_θ` 由 episodic 训练得到。新任务 `T∼p(𝔗)` 给支持集 `S_T={(x_i,y_i)}_{i=1}^{k}` 与查询集 `Q_T`。适配算子 `𝒜_k: (π_θ,S_T) ↦ φ_T`。**支持覆盖** 用相位-接触核度量：
```
cov(S_T,Q_T) = (1/|Q_T|) Σ_{q∈Q_T} max_{s∈S_T} exp(-d_𝔄(q,s)²/(2σ_c²))
```
`cov ≥ θ_cov` 才允许查询；否则弃权（OOD）。

**定义 125（元鲁棒性谱与适配曲线）**
`ρ_S(d;k)` 为用 k 个支持试验适配后、在扰动维度 d 上的鲁棒性裕度。**适配效率** `η(k) = (ρ_S(d;k)-ρ_S(d;0))/(k·ρ_∞)`；**少样本后悔** `Regret_k = E_{T∼p(𝔗)}[sup_{φ∈Φ} R_T(φ) - R_T(𝒜_k(π_θ,S_T))]`。

**定义 126（可行性核与跌倒证书）**
捕获点 `ξ = c + ċ/ω`，`ω=√(g/h)`。N-step 可行集
```
V_N = { x_0 | ∃ u_{0:N-1}, ξ_N ∈ 𝒮_safe }
```
`𝒮_safe` 为带裕度 `m_cp` 的支撑多边形。**跌倒证书** `V_cert = (V_N, m_cp, d_max)`：若对任务轨迹 `∀t, ξ_t ∈ V_N` 且 `dist(ξ_t, ∂𝒮_safe) ≥ m_cp`，则该任务 fall-free。安全盾 `shield(a) = Π_{V_N}(a)` 把动作投影回可行域。

**定义 127（元-相位迁移证书）**
```
J_meta = (ρ(·;k), C_S, C_comp^φ, z_T, V_cert, ε_meta, evidence)
```
可部署条件：
```
cov(S_T,Q_T) ≥ θ_cov  ∧  ε_meta(k,δ) ≤ ε̄  ∧  V_cert 成立  ∧  compat_C 成立
```
`evidence` 至少包含：支持试验的相位-接触覆盖热图、query 的捕获点裕度轨迹、元先验训任务分布摘要。

## 2. 关键算法 伪代码

### IP-121 PGC（Phase-Gait Characterization）

```python
def phase_contact_profile(skill, phases, contacts, sampler):
    alpha = {}
    for phi in phases:
        for sigma in contacts:
            for a in skill.action_grid(sigma):
                feas, conf = sampler.query(skill, a, phi, sigma)
                alpha[(a, phi, sigma)] = conf if feas else 0.0
    return alpha

def cover_phase(alpha, A_T, theta_cov=0.8):
    return all(alpha.get((a, phi, sigma), 0.0) >= theta_cov
               for (a, phi, sigma) in A_T)
```

### IP-122 CSG（Contact-Schedule Graph）

```python
def build_contact_graph(skills, eps_phi, ell_step, tau_e, k):
    G = nx.DiGraph()
    for i, s1 in enumerate(skills):
        for j, s2 in enumerate(skills):
            if i == j: continue
            if not compat_contact(s1, s2, eps_phi, ell_step):
                continue
            c = contact_cost(s1, s2)
            if c > tau_e:
                continue
            V_cert = viability_certificate(s2, d_max, dt, N)
            rho_k = meta_robustness(s1, s2, k)
            G.add_edge(i, j, cost=c, rho_k=rho_k,
                       C_boundary=boundary(s1, s2), V_cert=V_cert)
    return G
```

### IP-123 FMA（Few-shot Meta Adaptation，安全版）

```python
def safe_few_shot_adapt(pi_theta, task, k, V_cert, theta_cov):
    S = []
    for _ in range(k):
        # 支持试验被安全盾投影到 V_N，保证"采样不摔"
        traj = rollout(task, pi_theta, mode='support',
                       shield=lambda a: project_to_VN(a, V_cert.V_N))
        if not V_cert.holds(traj):
            return ('abstain', 'support_unsafe', traj)
        S.append(traj)
    z_T = encode_task(S)
    phi_T = adapt(pi_theta, z_T)
    cov = support_coverage(S, task.query_manifold)
    if cov < theta_cov:
        return ('abstain', 'ood_query', cov)
    return ('ok', phi_T, z_T, cov)
```

### IP-124 VKC（Viability Kernel Certificate）

```python
def viability_certificate(skill, d_max, dt, N):
    V = backward_reachable_safe_set(skill.hybrid_dynamics, d_max, dt, N)
    m = min_margin(V, support_polygon(skill))
    return VCert(V, m, d_max, holds=(m >= m_cp))
```

### IP-125 MAC（Meta Adaptation Certificate）

```python
def meta_certificate(phi_T, S, Q, pi_theta, delta):
    emp = empirical_risk(phi_T, Q)
    kl = kl_divergence(phi_T, pi_theta)
    eps_meta = emp + sqrt((kl + log(2 * len(S) / delta)) / (2 * len(S)))
    return MetaCert(eps_meta, delta,
                    coverage=support_coverage(S, Q))
```

### IP-126 MTC（Meta-Phase Transfer Certificate）

```python
def meta_phase_transfer_certify(J_prev, skills, k, task, delta, eps_bar):
    G = build_contact_graph(skills, task.eps_phi, task.ell_step, task.tau_e, k)
    path = a_star(G, start=task.start, goal=task.goal,
                  heuristic=lambda n: contact_cost_heuristic(n, task))
    if path is None:
        return ('reject', 'no_contact_schedule')
    adapt = safe_few_shot_adapt(task.meta_prior, task, k,
                                path.V_cert, theta_cov)
    if adapt.status != 'ok':
        return ('reject', adapt.reason)
    comp = compose_phase_certificates(path, adapt)
    if not comp.V_cert.holds or comp.cov < theta_cov:
        return ('reject', 'viability_or_coverage')
    mac = meta_certificate(adapt.phi_T, adapt.S, task.Q,
                           task.meta_prior, delta)
    if mac.eps_meta > eps_bar:
        return ('reject', 'meta_bound')
    return ('ok', JMeta(comp.rho_k, comp.C_S, comp.C_comp_phi,
                        adapt.z_T, comp.V_cert, mac.eps_meta))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| PGC | O(\|Σ\|·\|Φ\|·\|A_σ\|) | O(\|𝔄\|) | 相位-接触采样覆盖 |
| CSG | O(\|S\|²·\|Σ\|) | O(\|S\|²) | 接触边界 sound、捕获点连续 |
| FMA | O(k·H + \|z\|) | O(k·H) | 安全盾投影、支持覆盖 |
| VKC | O(\|X\|·N) | O(\|X\|) | 反向可达 sound、裕度保守 |
| MAC | O(\|Q\|·\|φ\|) | O(\|φ\|) | PAC-Bayes 先验有效 |
| MTC | O(\|V\| log\|V\| + \|E\| + kH) | O(\|V\|+\|E\|+kH) | 三证书闭合 |

**定理 1（Phase-Contact Composition Soundness）**
假设 (A29) `α_S` 由混合动力学仿真校准且 `cover` 可判定；**(A30)** 接触调度边界满足 `ξ ∈ V_N`；**(A31)** 边界转移模型在 `d_max` 扰动下 Lipschitz。则若 `G_C` 上存在路径且每个边界 `compat_C=1`，执行时的相位-接触序列与规划一致，且无边界失稳。

**定理 2（Few-shot Fall-free Meta Adaptation）**
设元先验 `π_θ` 在 `p(𝔗)` 上训练，支持集大小 `k`，安全盾把支持试验限制在 `V_N`，且 `cov(S_T,Q_T) ≥ θ_cov`。则对 query 任务 `T`，以概率 `1-δ`：
```
P(fall-free ∧ success | deploy)
  ≥ 1 - ε_meta(k,δ) - P(ξ ∉ V_N) - P(compat_C = 0) - P(cov < θ_cov)
```
其中
```
ε_meta(k,δ) = R̂_{S_T}(φ_T) + sqrt( (KL(φ_T‖π_θ) + ln(2k/δ)) / (2k) )
```
关键：**平均风险由 PAC-Bayes 界管，灾难跌倒由 V_N 管，OOD 由支持覆盖拒识管**，三者互不替代。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 相位-接触剖面维数爆炸 | 高 | 相位分箱 + 接触模式因子化 + 主动采样 |
| 接触边界在地形突变处不连续 | 高 | 捕获点裕度约束 + 安全盾 + 边界回滚 |
| 元先验过拟合仿真、真实迁移失效 | 高 | 域随机化 + 真实-仿真校准 + OOD 弃权 |
| PAC-Bayes 界过松 | 中 | 数据相关先验 + 支持覆盖条件收紧 |
| 支持试验本身跌倒风险 | 高 | 安全盾投影 + 影子仿真预演 + 人工急停 |

## 6. 本轮最大风险

**一句话**：双足 × 少样本把方案从"动作-鲁棒性"推进到"相位-接触-元适配"，但其 soundness **三重依赖相位-接触剖面的可判定性、可行性核在真实接触扰动（打滑/绊倒）下的保守性、以及少样本支持集对 query 流形的覆盖**；一旦支持集只覆盖单支撑而 query 含双支撑转换，或 `V_N` 在未建模接触下被高估，安全盾就会给出"假性 fall-free"，故必须以 **接触模式因子化的主动采样 + V_N 的对抗扰动校准 + 支持覆盖 OOD 弃权** 三重护栏，宁可弃权不部署，绝不把少样本的"适配成功"当作接触安全的证明。

# 第 55 轮产物 · 创新点清单 v32：BipedMeta-GroundEdge（PGC×CSG×FMA×VKC×MAC×MTC）

> 承接第 54 轮产物 v31。本轮把平台推进到 **双足机器人 + 少样本学习**，在动作-协同层之上增加 **相位-接触层与元适配层**：

| `V_N` | N-step 可行性核 |
| `ξ = c + ċ/ω` | 捕获点 |
| `V_cert = (V_N,m_cp,d_max)` | 跌倒证书 |
| `J_meta` | 元-相位迁移联合证书 |

## 2. 关键算法 伪代码

### IP-121 PGC

```python
def phase_contact_profile(skill, phases, contacts, sampler):
    alpha = {}
    for phi in phases:
        for sigma in contacts:
            for a in skill.action_grid(sigma):
                feas, conf = sampler.query(skill, a, phi, sigma)
                alpha[(a, phi, sigma)] = conf if feas else 0.0
    return alpha

def cover_phase(alpha, A_T, theta_cov=0.8):
    return all(alpha.get((a, phi, sigma), 0.0) >= theta_cov
               for (a, phi, sigma) in A_T)
```

### IP-122 CSG

```python
def compat_contact(s1, s2, eps_phi, ell_step):
    return (s1.contact[-1] == s2.contact[0]
            and phase_dist(s1.phi_end, s2.phi_start) <= eps_phi
            and norm(s1.foot_end - s2.foot_start) <= ell_step)

def contact_cost(s1, s2):
    return (w_v*norm(s1.v_end - s2.v_start)
            + w_p*norm(s1.foot_end - s2.foot_start)
            + w_phi*phase_dist(s1.phi_end, s2.phi_start)
            + w_xi*norm(capture(s1) - capture(s2)))

def build_contact_graph(skills, eps_phi, ell_step, tau_e, k, d_max):
    G = nx.DiGraph()
    for i, s1 in enumerate(skills):
        for j, s2 in enumerate(skills):
            if i == j or not compat_contact(s1, s2, eps_phi, ell_step):
                continue
            c = contact_cost(s1, s2)
            if c > tau_e:
                continue
            G.add_edge(i, j, cost=c,
                       rho_k=meta_robustness(s1, s2, k),
                       C_boundary=boundary(s1, s2),
                       V_cert=viability_certificate(s2, d_max, dt, N))
    return G
```

### IP-123 FMA

```python
def safe_few_shot_adapt(pi_theta, task, k, V_cert, theta_cov):
    S = []
    for _ in range(k):
        traj = rollout(task, pi_theta, mode='support',
                       shield=lambda a: project_to_VN(a, V_cert.V_N))
        if not V_cert.holds(traj):
            return ('abstain', 'support_unsafe', traj)
        S.append(traj)
    z_T = encode_task(S)
    phi_T = adapt(pi_theta, z_T)
    cov = support_coverage(S, task.query_manifold)
    if cov < theta_cov:
        return ('abstain', 'ood_query', cov)
    return ('ok', phi_T, z_T, cov)
```

### IP-124 VKC

```python
def viability_certificate(skill, d_max, dt, N):
    V = backward_reachable_safe_set(skill.hybrid_dynamics, d_max, dt, N)
    m = min_margin(V, support_polygon(skill))
    return VCert(V, m, d_max, holds=(m >= m_cp))

def project_to_VN(action, V_N):
    # 安全盾：把动作投影到可行性核内的最近可行动作
    return argmin_{a' in V_N} cost(action, a')
```

### IP-125 MAC

```python
def meta_certificate(phi_T, S, Q, pi_theta, delta):
    emp = empirical_risk(phi_T, Q)
    kl = kl_divergence(phi_T, pi_theta)
    eps_meta = emp + sqrt((kl + log(2 * len(S) / delta)) / (2 * len(S)))
    return MetaCert(eps_meta, delta, coverage=support_coverage(S, Q))
```

### IP-126 MTC

```python
def meta_phase_transfer_certify(J_prev, skills, k, task, delta, eps_bar):
    G = build_contact_graph(skills, task.eps_phi, task.ell_step,
                            task.tau_e, k, task.d_max)
    path = a_star(G, start=task.start, goal=task.goal,
                  heuristic=lambda n: contact_cost_heuristic(n, task))
    if path is None:
        return ('reject', 'no_contact_schedule')
    adapt = safe_few_shot_adapt(task.meta_prior, task, k,
                                path.V_cert, theta_cov)
    if adapt.status != 'ok':
        return ('reject', adapt.reason)
    comp = compose_phase_certificates(path, adapt)
    if not comp.V_cert.holds or comp.cov < theta_cov:
        return ('reject', 'viability_or_coverage')
    mac = meta_certificate(adapt.phi_T, adapt.S, task.Q,
                           task.meta_prior, delta)
    if mac.eps_meta > eps_bar:
        return ('reject', 'meta_bound')
    return ('ok', JMeta(comp.rho_k, comp.C_S, comp.C_comp_phi,
                        adapt.z_T, comp.V_cert, mac.eps_meta))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PGC | O(\|Σ\|·\|Φ\|·\|A_σ\|·\|S\|) | O(\|𝔄\|) | 相位-接触采样覆盖 ≥ 95% |
| CSG | O(\|S\|²·\|Σ\|) | O(\|S\|²+\|E\|) | 边界兼容 sound、路径最优 |
| FMA | O(k·H + \|z\|) | O(k·H) | 安全盾投影、覆盖可判定 |
| VKC | O(\|X\|·N) | O(\|X\|) | 反向可达 sound、裕度保守 |
| MAC | O(\|Q\|·\|φ\|) | O(\|φ\|) | PAC-Bayes 先验有效 |
| MTC | O(\|V\|log\|V\|+\|E\|+kH) | O(\|V\|+\|E\|+kH) | 三证书闭合、可弃权 |

**定理 1（Phase-Contact Composition Soundness）**
假设第 54 轮 (A26)-(A28) 成立；**(A29)** `α_S` 由混合动力学仿真校准且 `cover` 可判定；**(A30)** 接触边界满足 `ξ ∈ V_N`；**(A31)** 边界转移在 `d_max` 扰动下 Lipschitz。若 `G_C` 上存在路径且每个边界 `compat_C=1`，则执行相位-接触序列与规划一致且无边界失稳。

**定理 2（Few-shot Fall-free Meta Adaptation）**
设元先验 `π_θ` 在 `p(𝔗)` 上训练，支持集大小 `k`，安全盾限制支持试验于 `V_N`，且 `cov(S_T,Q_T) ≥ θ_cov`。则对 query 任务 `T`，以概率 `1-δ`：
```
P(fall-free ∧ success | deploy)
  ≥ 1 - ε_meta(k,δ) - P(ξ ∉ V_N) - P(compat_C = 0) - P(cov < θ_cov)
```
```
ε_meta(k,δ) = R̂_{S_T}(φ_T) + sqrt( (KL(φ_T‖π_θ) + ln(2k/δ)) / (2k) )
```
关键：**平均风险由 PAC-Bayes 管，灾难跌倒由可行性核管，OOD 由支持覆盖弃权管**；三者不可互相替代，且弃权是合法输出（宁可拒绝部署）。

## 5. 迭代对照（v31 → v32）

| 维度 | v31（第 54 轮） | v32（本轮） | 变化原因 |
|---|---|---|---|
| 动作单元 | 静态 `α_S(a)` | 相位-接触 `α_S(a,φ,σ)` | 双足同名动作跨相位语义不同 |
| 组合条件 | 动作 Jaccard + 转换成本 | 接触边界 + 落脚/捕获点连续 | 双足组合的物理可行性在接触边界 |
| 部署保证 | 鲁棒性谱 ρ + A_cert | ρ(·;k) + V_cert + 覆盖弃权 | 跌倒是灾难事件，均值界不够 |
| 适配方式 | 无（离线技能库） | 少样本元适配 `𝒜_k` | 新地形可交互样本极少 |
| 失败模式 | 负迁移/动作错位 | 假性 fall-free / OOD 硬适配 | 安全盾与元先验可能同时失效 |

## 6. 本轮最大风险

**一句话**：双足 × 少样本把方案从"动作-鲁棒性"推进到"相位-接触-元适配"，但其 soundness **三重依赖相位-接触剖面的可判定性、可行性核在真实接触扰动（打滑/绊倒）下的保守性、以及少样本支持集对 query 流形的覆盖**；一旦支持集只覆盖单支撑而 query 含双支撑转换，或 `V_N` 在未建模接触下被高估，安全盾就会给出"假性 fall-free"，故必须以 **接触模式因子化的主动采样 + V_N 的对抗扰动校准 + 支持覆盖 OOD 弃权** 三重护栏，宁可弃权不部署，绝不把少样本的"适配成功"当作接触安全的证明。
