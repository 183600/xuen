# 第 2 轮（UniBot 线 · 第 2 轮；本轮灵感：「决策规划」×「通用操作」）

> **续线声明**：本轮不重新基线化。延续第 1 轮 UniBot-SAGE 的 U1–U12 / L1–L7 / E601–E618；本轮新增 U13–U24 / L8–L14 / E619–E638。第 1 轮的 P0（IP-02 抓握确认、IP-03 chunk 缝合、IP-06 代理评测）保留；本轮把 IP-01（技能 MoE）与 IP-04（在线适配）降为 P1/P2，理由见 §6。

## 0. 情报增量（检索日期 2026-11-18）

**赛事情报（复核）**：
1. 官网排行榜页与运行记录页在 2026-11-18 仍显示「即将发布 / Coming Soon」；`leaderboard_data.json` 仍是唯一有结构的 teaser 占位表。故本轮继续只把 teaser 当**规格说明书**，不当成绩真值。
2. 重新逐条核对官方 `unibot_submission` README（2026-11-18）：接口没有公开 **episode 最大时长/超时**；但明确记录 **per-step 响应延迟及其波动、返回动作的统计规律性**，并可能并入可信度评估；`action_chunk_size` 完全由选手声明；每 episode 调 `reset()`；N 台机器人、N 个连续端口、每个端口独立全流程。
3. **关键空白**：README 仍未说明 chunk 在评测端的执行语义（是否缓存、是否插值、是否与上一 chunk 拼接），也未给出单 episode 硬超时。这两个空白直接决定「规划层」能有多激进（见 Q6、Q9）。
   - **接口审计修正（本轮必做）**：README 明确 `action_chunk_size` 是握手期声明的**固定整数**，每个返回动作的首维必须恒等于它 ⇒ 第 1 轮 U8「运行时按相位自适应 chunk 长度」在接口上不成立，必须降级为「固定 `T_a` 下的相位相关**重规划节奏**」。这不是小修：它把决策粒度的物理约束暴露出来了——`T_a` 同时决定「开环多久」与「每次调用可用的 deliberation 预算」，因此本轮的核心决策单位只能是 option，而不是单步。

**文献增量（test-time decision 已成拥挤赛道）**：
4. VLA-ATTC（arXiv 2605.01194，ICML 2026）提出不确定性触发的 "cognitive clutch" + Relative Action Critic，并行采样摊销 VLM 计算，20.8 Hz，真机成功率 +17.3%。
5. MG-Select（ICLR 2026）用 condition-masking 的 KL 置信度做 **verifier-free** best-of-N；RoboMonkey（PMLR 2025）证明动作误差随采样数近似指数幂律，并用 VLM verifier；Guided Action Flow（arXiv 2607.02092）明确指出 **critic 的 OOD 泛化是中心瓶颈**；E-TTS（arXiv 2606.27268）与 WCM（arXiv 2607.29613）分别从具身 TTS 与世界 critic 两侧推进。
6. **由此得到的硬结论**：如果第 2 轮只是"多采样 + 绝对价值 critic 选最好"，那只是跟随 2025–2026 的公共做法，既不新也不够稳。真正的空位在：**决策粒度（option 级而非 action 级）× 风险语义（分布无关下界而非期望分）× 信息动作（把"看清楚"当一等公民）× 赛制约束（deadline、单 checkpoint、可信度审计）**。

## 1. 直觉：两个灵感各自的第一性原理

**灵感 1 ·「决策规划」——问题不是"想得不够多"，而是"没有可以停下来的状态"**

第一性原理：VLA 的默认形态是一条**反射弧**：看到观测，吐一个 chunk，执行，再看。它没有显式的"我现在走到哪一步、还差什么、还要不要继续"的状态，更没有"什么时候该放弃当前做法"的仲裁器。于是失败不是"某一步动作不够准"，而是**错误一旦发生就没有被识别和止损**：空抓之后继续搬运、插不进去仍反复顶、物体掉了还在原轨迹上走。第 1 轮把"抓住没有"变成了带置信度的隐变量；本轮要把它升级成**决策问题**：在 chunk 边界，用有限的剩余时间，选择 继续 / 重试 / 换技能 / 主动感知 / 终止。

第二性原理：本赛制有一个别人没有的交换比——**时长几乎不计分**（第 1 轮实测任务内 corr(dur, succ) ≈ −0.011，episode 43.7–45.2 s），但**延迟的稳定性会被审计**。这意味着：想得久一点通常不扣分，但不能让延迟抖动、不能让动作统计异常。所以正确的形态不是"每步都重规划"，而是**截止时间感知的 anytime 仲裁**：默认策略永远先有一份可执行输出，deliberation 只在预算内改进它，超时就退回默认。

**灵感 2 ·「通用操作」——通用不是"参数更多"，而是"可复用的组合语法"**

第一性原理：32 个桌面任务不是 32 个独立函数。人类之所以能迁移，是因为把任务分解为三类可复用要素：**(a) 接触模式**（夹、推、扫、倒、钩）、**(b) 空间关系**（支撑、容纳、对齐、旋转、插入）、**(c) 物体 affordance**（可抓区、可支撑面、开口、把手）。"通用"= 在这三者上的**组合泛化**，而不是在 32 个任务上把同一个大模型多训几遍。第 1 轮已经从榜单统计推出"通用是 32 维技能向量"；本轮把它再降一维：**技能向量可以由一个小的、带前后条件的 option 库 + 共享 affordance 表示生成**。

**合成（本轮主线）**：
**感知层（affordance field）→ 技能层（typed options）→ 规划层（deadline-aware semi-MDP 仲裁 + 校准 critic）→ 执行层（VLA chunk + 缝合）**。
第 1 轮是"接地 + 技能 + 适应"三层栈；本轮不是推倒，而是在技能层与适应层之间插入**规划层**，并把"适应"从权重更新改成"用信息动作吸收不确定性"。一句话：**第 1 轮学会抓稳，第 2 轮学会什么时候该换招、以及凭什么说这套招法是通用的。**

## 2. 从第 1 轮证据到本轮三个可被推翻的假设

| 假设 | 陈述 | 为什么可信 | 如何被推翻（预注册） |
|---|---|---|---|
| **H1 规划红利集中在 last-mile** | option 级仲裁的收益主要落在插入/旋转/放置的 6 个难任务，而不是全任务均匀提升 | 第 1 轮：step≈1.337·succ，终态成功是唯一货币；失败集中在最后对齐/插入；前段动作即使不够优雅也能到终态 | 若规划在 reach/transport 相位的触发次数与收益不低于 align/insert 相位（收益比 <1.2），则 H1 不成立，规划应退化为"全局噪声抑制"而非 last-mile 专项 |
| **H2 组合泛化 > 单体泛化** | 在 leave-one-object / relation / primitive 的 OOD 切分上，option 分解的泛化 gap 显著小于同参数量单体 VLA | "通用"在数据上是可复用要素的组合；5 类泛化场景中"未见物品"最接近 leave-one-object | 若组合 OOD 相对单体的 gap 改善 <3 个百分点，则"通用=组合"在 UniBot 上不成立，砍掉符号层，只保留 critic + 规划环 |
| **H3 critic 的 OOD 校准是瓶颈** | 绝对价值回归在分布偏移下会过度自信；relative critic + conformal 下界 + 拒答能显著降低"错误自信" | 2026 年多篇 TTS 工作（VLA-ATTC、Guided Action Flow）独立报告 critic 泛化是中心问题；校准误差比排序误差更致命 | 若 relative critic 与绝对 critic 在组合 OOD 上的决策错误率差异 <2 个百分点，则 H3 不迁移到 UniBot，砍掉 relative 头，简化 |

> 这三个假设合起来构成本轮的"可证伪骨架"：H1 决定**在哪花算力**，H2 决定**通用性叙述是否成立**，H3 决定**critic 是否可信到能参与决策**。任何一条被推翻，都对应一条明确的剪枝动作，而不是"再调调参"。

## 3. 与现有 test-time scaling 工作的差异（必须说清，否则本轮不成立）

| 维度 | 2026 主流 TTS（VLA-ATTC / MG-Select / RoboMonkey / E-TTS） | 本轮 SAGE² |
|---|---|---|
| 决策粒度 | action / token 级 best-of-N，每个控制步选一个动作或动作块 | **option / 半 MDP 级**：在 chunk 边界选"继续当前 option / 换 option / 探测 / 终止"，动作级采样只是 option 内部子程序 |
| 价值语义 | 最大化 verifier score / 相对偏好 | **分布无关风险控制**：用 group-conditional conformal 下界，只在"错判代价不对称"时介入 |
| 信息动作 | 通常没有；观测是给定的 | **把主动感知当一等 option**：移动腕相机、后退、换视角，用 value-of-information 决定是否探测 |
| 工程约束 | 追求吞吐/帧率 | **截止时间感知**：默认输出永远先存在；规划是 anytime 的增量改进；p99 延迟与动作规律性可审计 |
| 通用性 | 主要报 OOD 平均成功率 | **组合泛化的因子化度量**：leave-one-object / relation / primitive 的 gap + option 复用率 |

**定位一句话**：别人在"一步动作"上想得更久；我们在"下一步做什么技能"上想得更久，而且用可校准的风险下界来决定何时**不该**想。

## 4. 本轮研究问题 Q6–Q10

- **Q6（决策粒度与触发）**：在相同延迟预算下，option 级仲裁相对 action 级 best-of-N 的收益/成本比是否更高？"认知离合"的触发能否由「critic 不确定度 + 剩余时间 slack + 相位风险」三元组决定，而不是固定每步都规划？
- **Q7（critic 的可信度）**：在没有大规模真机标签的条件下，如何给 progress/success critic 一个**在组合 OOD 下仍然可用**的下置信界？conformal 的 exchangeability 在"未见物品 / 人为干扰"下不成立，能否用 group-conditional + 密度比加权 + OOD 拒答做成"三层闸门"？
- **Q8（通用操作的度量）**：如何定义并测量组合泛化？option 复用率与 OOD gap 是否存在可检验的标度关系（复用越多，gap 越小）？如果不存在，"通用=组合"就只是叙事。
- **Q9（信息获取的边界）**：active perception 的 probe 何时净收益为正？在"时长不计分但可能存在隐藏超时"的不确定下，如何用剩余时间 slack 与信息增益估计做 VOI 决策而不把可救的 episode 拖成超时？
- **Q10（规划与抓握/缝合的接口）**：第 1 轮的 `g_t`（抓握隐变量）与 `Ψ`（chunk 缝合）如何成为 planner 的观测与动作？三者组合是否产生"决策抖动"（同一相位反复切换 option），以及如何用滞回与最小驻留时间抑制？

## 5. 设计原则增量 P7–P10

- **P7 默认保留（default-preserving）**：planner 永远先拿到默认策略的 chunk；只有在**校准下界**意义下严格优于默认、且动作在信任域内时，才允许覆盖。任何不确定 ⇒ 原样执行默认。这把"规划"从"替换策略"降级为"受约束的改进"。
- **P8 时间预算显式化**：任何 deliberation / probe 都要从"剩余时间 slack"扣预算；没有 slack 就不规划、不探测。预算不是墙钟常量，而是 `T_a·Δ − ε` 与 episode 剩余估计的较小者。
- **P9 通用性以复用计量**：新 option 必须在 ≥3 个任务或 ≥2 个物体类别上被复用才允许进库；单任务专用分支一律退化为 VLA 内部行为，不进 option 库（延续并强化第 1 轮 P3）。
- **P10 校准先于精度**：critic 必须先过可靠性/覆盖率门槛，才允许参与"终止 / 重试"这类不可逆决策；排序精度高但校准差的 critic 只能用于候选排序，不能用于止损。

## 6. 本轮 MVP 与退化链（含对第 1 轮优先级的修剪）

**MVP2 = IP-10 ProgressCritic（relative + conformal LCB + OOD 拒答） + IP-09 PlanLoop（option 级四选一） + IP-11 OptionGrammar（小库：grasp / place / insert / push / sweep / probe / retract） + 第 1 轮 IP-02 / IP-03。**

**为什么把 IP-01（技能 MoE）与 IP-04（在线适配）降级**：
- IP-01 的最大障碍是**合规定义**（单 checkpoint 内多专家是否算单模型），而不是技术；在组委会书面答复前，它不应占据 P0 的注意力。
- IP-04 的跨 episode 更新同样有合规疑问，且第 1 轮已给出"episode 内上下文调制"的零风险版本；本轮的 probe option 已经能在 episode 内吸收一部分不确定性，边际收益更高。
- 反过来，IP-09/10/11 **不触碰"单模型"定义**（仍是同一个 checkpoint、同一个 `get_action`），却直接对准 last-mile 断点，合规风险最低、信息价值最高。

**严格退化链（逐级回退，不允许漂移）**：
- Level-0 critic 覆盖率不达标 ⇒ planner 只保留 `continue`，等价于默认策略；
- Level-1 relative critic 在 OOD 上失效 ⇒ 只用绝对 critic 的排序，不做终止/重试；
- Level-2 option 前置条件不确定 ⇒ 退回"VLA 原语 + 相位先验"，不做符号组合；
- Level-3 probe 无 slack 或 VOI ≤ 0 ⇒ 不探测；
- Level-4 组合 OOD 不优于单体 ⇒ 砍掉 IP-11 的符号层，只保留 IP-09/10；
- Level-5 整条规划链路超时 ⇒ 返回默认 chunk（P7），审计记一次 degraded，但**绝不返回空动作或异常动作**。

## 7. 本轮最大风险

**一句话**：本轮把收益押在"校准后的 critic 能让 planner 在最后一环做对 continue/retry/switch"上，而 conformal 的 exchangeability 在"未见物品 / 人为干扰"这类最需要它的场景下恰恰不成立——一旦 critic 系统性过度自信，planner 会用一套"看起来保守"的规则做出系统性错误决策（过早终止或反复重试），把第 1 轮已经守住的基线成功率反而拖低。

## 8. 下一轮迭代计划（深化与修剪）

- **深化**：把 option 的前后条件从手工谓词升级为 **affordance-conditioned 的可学习模型**；把 conformal 从静态校准升级为 **"分布偏移检测 + 密度比加权 + 拒答"三层闸门**；若官方 runs 页发布，立即用真实运行视频做 critic 的外部锚点。
- **修剪预案**：若 H1 不成立（规划收益不集中在 last-mile）⇒ 把 PlanLoop 降为"全局低置信触发"，不再做相位特化；若 H2 不成立（组合 OOD 无改善）⇒ 砍掉 OptionGrammar 符号层，只保留 affordance field 作为辅助表示；若 H3 不成立（relative 无优势）⇒ 砍掉 relative 头，回到单绝对 critic + 更强校准。
- **保留项**：IP-10（决策的可信度底座）、IP-09（唯一直接兑现"想得久不扣分"的赛制红利）、IP-11 的 probe option（信息动作）、第 1 轮 IP-02/IP-03/IP-06。

## 0. 本轮结论摘要

**一句话路线**：把"决策规划"与"通用操作"编译成一个**D-A-O 环**——
**Detect（affordance / 相位 / 抓握 / 不确定度）→ Arbitrate（option 级四选一：continue / switch / probe / terminate，用校准下界与不对称代价）→ Optimize（被选中 option 内部的 anytime best-of-N）**，
并把它作为第 1 轮 SAGE 的"规划层"插入，而不是替换原有抓握与缝合。

**三条本轮决策（均由证据逼出）**：

| 证据 | 推出的设计 |
|---|---|
| 2026 年 best-of-N + critic 已拥挤（VLA-ATTC / MG-Select / RoboMonkey / E-TTS），且多篇独立报告 critic 的 OOD 泛化是中心瓶颈 | **不在 action 级重复造轮子**；把决策上移到 option 级，并把"校准"而非"排序精度"作为第一门槛（IP-10 / IP-09） |
| 第 1 轮：step≈1.337·succ（R²=0.9955），时长与成功无关（corr≈−0.011） | 时长不计分 ⇒ **信息动作近乎免费**；但延迟稳定性会被审计 ⇒ deliberation 必须 anytime、default-preserving（P7/P8） |
| 官方 README：`action_chunk_size` 是**握手期固定整数**，不是运行时可变 | 第 1 轮 U8「自适应 chunk 长度」**接口不成立**，修正为 U8′「固定 `T_a` 下的 option 边界重规划节奏」；决策单位被迫上移到 option（§0.5） |
| 5 类泛化场景 = 位置 / 干扰物 / 背景 / 未见物品 / 人为干扰 | "通用"必须用 **leave-one-factor-out 的组合 gap** 度量，而不是平均成功率（U23 / E627） |

**本轮 MVP2**：IP-10（校准 critic）+ IP-09（PlanLoop）+ IP-11（OptionGrammar 小库 + probe）+ 第 1 轮 IP-02/IP-03。

## 0.5 接口审计修正（本轮必须显式记录的两处"上一轮错误"）

> 研究循环的价值不在于每轮都加东西，而在于**敢于把上一轮写错的接口假设撤回**。本轮复核官方 README（2026-11-18）后发现两处必须修正：

### 修正 1：`action_chunk_size` 是固定整数 ⇒ U8 失效

README §3 原文：`action_chunk_size` 是 "an `int` ≥ 1: the leading time-axis length of every action array returned by `get_action`"；每个动作数组形状为 `(T_a, …)`。这意味着：

- **不能在运行时按相位改变 `T_a`**；第 1 轮 U8 `T_a(z_phase)` 与接口冲突，实验 E607「自适应 chunk」作废，替换为 **U8′（固定 `T_a` 下的重规划节奏）** 与 **E624b（`T_a` 扫描）**。
- `T_a` 同时决定两个物理量：**开环时长** `T_a·Δ`（越长，反馈越慢）与**每次调用的 deliberation 预算** `D = T_a·Δ − ε`（越长，越能想）。因此 `T_a` 是一个**全局权衡参数**，不是相位参数。
- 推论：想让"高精度相位用短 chunk"在接口内合法，只能**全局选小 `T_a`**，代价是 `D` 变小、规划空间变窄。这正是本轮把决策单位放到 option 的原因：**一个 option 可以跨多个 chunk，而 deliberation 只发生在 option 边界**。

### 修正 2：`reset()` / `get_action(obs)` 没有端口参数 ⇒ 隔离必须由"每端口包装器"承担

README §1 的签名是 `reset()` 与 `get_action(obs)`，没有 `port` 形参；§5 又要求"每个端口的 `reset` 与历史状态互相隔离"。因此第 1 轮伪代码里的 `reset(port=None)` / `get_action(obs, port=None)` 是**错误的**。正确形态：

- **每端口一个轻量 `PortPolicy` 包装器**（持有该 episode 的 `Session`），内部把无状态计算转发给**共享后端**；
- 共享后端只持有模型权重，不持有 episode 状态；`Session` 只存在于包装器内；
- 这样既满足官方签名，又满足并发与隔离要求（对应第 1 轮 IP-08 的工程要求）。

## 2. 创新点详述

### IP-09 · PlanLoop：截止时间感知的 option 级仲裁（P0）

- **动机**：反射式 VLA 的失败不是"动作不够准"，而是**没有止损状态**：空抓后继续搬运、插不进仍反复顶、物体掉了仍沿原轨迹走。第 1 轮把"抓住没有"变成隐变量；本轮把它变成**决策变量**。
- **与现有方案的差异**：VLA-ATTC / MG-Select / RoboMonkey 在 action/token 级做 best-of-N；PlanLoop 在 **option 级**做四选一，动作级采样只是被选中 option 的内部子程序。这样在相同延迟下，候选空间的"语义跨度"更大（换抓法 vs 换一个微小动作），而候选数更少。
- **技术可行性**：中–高。①option 库小（7–9 个）；②每个 option 由同一个 trunk + option embedding + FiLM 条件化，**仍是一个 checkpoint、一个 `get_action`**；③所有评分头都是轻量 MLP/CNN，可在预算内跑 4–8 个候选。
- **落地步骤**：
  1. 用 `run_server.py` + `run_client.py` 复刻评测闭环，确认 chunk 执行语义与 `T_a` 的真实时序（Q5 遗留）；
  2. 实现 `PortPolicy` 包装器 + 共享后端（修正 2）；
  3. 先只做 `continue` vs `retry` 二选一（最小闭环），再扩到 `switch` / `probe` / `terminate`；
  4. 接入 IP-10 的 LCB 与 IP-11 的前置条件；
  5. 做 `T_a ∈ {1,2,4,8}` 扫描，确定"决策节奏—开环—预算"的甜点（E624b）。
- **风险**：①默认策略本身很强时，override 可能画蛇添足 ⇒ P7 默认保留 + E631 专项；②option 边界与相位边界错位 ⇒ 用滞回与最小驻留（L14）；③决策抖动 ⇒ switches/ep 上限与审计（IP-14）。

### IP-10 · ProgressCritic：相对比较 + 分组 conformal 下界 + OOD 拒答（P0）

- **动机**：2026 年的 TTS 工作反复暴露同一个问题：**绝对价值/critic 的 OOD 泛化差**（Guided Action Flow 直接把它列为中心瓶颈）。而"终止 / 重试"是**不可逆决策**，比"选哪个动作"更怕过度自信。因此不能只用排序，必须给出**风险下界**。
- **设计（三层）**：
  1. **相对头** `C_ψ(o,ω_a,ω_b)`：只用两两偏好（成功轨迹 vs 失败轨迹、同轨迹后段 vs 前段、恢复 vs 继续），Bradley–Terry 训练；避免绝对尺度不稳。
  2. **绝对头** `V_θ(o,ω)`：给 conformal 提供点估计；只在"终止/重试"用，且必须过校准门槛（P10）。
  3. **分组 conformal**：按 `g=(任务簇, 相位)` 校准，得到 `L_g(o)`；当组样本不足或 OOD 分数超阈值时**拒答**（返回 `L=None`，planner 退回默认）。分布偏移下用密度比加权 conformal，权重不可估则拒答（L10）。
- **与现有方案的差异**：现有 verifier 追求"选得准"；我们要求"**敢不敢用来止损**"。这是风险语义的差异，也是本轮的学术空位。
- **落地步骤**：①从官方 32 数据集构造偏好对（无需人工标注；用成功/失败、时序先后、恢复片段）；②训练相对头；③训练绝对头并做可靠性图；④按任务簇 × 相位做分组 conformal；⑤接入拒答与回退；⑥在组合 OOD 上做 risk–coverage 曲线。
- **风险**：①conformal 的 exchangeability 在未见物品/人为干扰下不成立（本轮最大风险，见 §9）；②分组太细导致样本不足 ⇒ 层级回退（细组→任务簇→全局）；③偏好对构造有偏（失败轨迹里也有好动作）⇒ 只在"同相位、同任务"内配对，并用恢复片段做正例。

### IP-11 · OptionGrammar：带软前后条件的可复用技能库（P0）

- **动机**：32 个任务不是 32 个函数。通用性来自 (a) 接触模式、(b) 空间关系、(c) affordance 的组合。把技能写成带前后条件的 option，才能让"未见物品 / 未见关系"有结构可迁移。
- **技能库（初版 8 个）**：`grasp`（接触 + 闭合）、`place`（支撑/容纳）、`insert`（对齐 + 插入）、`push`（接触 + 平移）、`sweep`（接触 + 横向扫）、`topple`（施力 + 倾倒）、`probe`（信息动作）、`retract`（安全回收）。
- **软前后条件**：`Pre_ω(A,o)`、`Post_ω(A,o) ∈ [0,1]`，定义在 IP-12 的 affordance 场上；用 product/min t-norm 组合。规划深度 ≤2、beam ≤K，只有当整条链的 `Pre/Post` 分数与 critic 下界都过门槛才执行；否则退回 VLA 原语。
- **通用性约束（P9）**：每个 option 至少在 3 个任务或 2 个物体类别上被复用；否则不进库。用 U24 的复用率做审计，防止退化成 32 个专用分支。
- **与现有方案的差异**：现有 VLA 把技能隐式地存在权重里；我们把**可复用结构显式化**，并用组合 OOD 切分来检验它是否真的通用，而不是只看平均分。
- **风险**：①软谓词可能只是"手工特征 + 阈值"，在未见物体上失效 ⇒ 用 affordance field 学习、并保留纯 VLA 回退；②符号层与 VLA 的接口不一致（符号说可行、VLA 做不出）⇒ 每条 option 都必须有可执行的 VLA 头，符号层只做排序/门控；③深度 2 的搜索仍可能错过长程组合 ⇒ 只作为"局部换招"，不做全局任务规划。

### IP-12 · AffordanceField（P1，支撑 IP-11）

- **内容**：从 4 路相机预测 6 通道（可抓 / 可支撑 / 可容纳 / 可对齐 / 可旋转 / 易碎）的多视角热图，物体无关、实例无关。
- **用途**：①option 的软前后条件；②抓握判定器 `g_t` 的几何输入（强化第 1 轮 IP-02）；③planner 的"关系状态"估计。
- **验收**：affordance AUROC ≥0.85；作为共享表示接入后，组合 OOD 成功率 ≥ +1.5 分。

### IP-13 · ProbeOption：主动感知是一等 option（P1）

- **直觉**：本赛制时长几乎不计分 ⇒ "先看清楚"的成本极低；但可能存在隐藏超时，且移动可能扰动场景，所以必须用 VOI 而非"总是探测"。
- **probe 集合**：`rotate_wrist`（转腕看侧面）、`backoff`（后退看全貌）、`lateral_shift`（侧移看遮挡）、`top_view`（俯视看容器口）。
- **决策**：`VOI(ρ) = E_{z∼ρ}[max_ω U(ω|z)] − max_ω U(ω) − c_ρ`；仅当 `VOI>0`、`duration < slack`、`disturbance_risk < τ_d` 时执行。
- **验收**：probe 净收益 ≥0；超时率 <1%；probe 后抓握判定 AUROC ≥ +0.05。

### IP-14 · DecisionAudit（P2）

- **内容**：逐决策 trace：`t, phase, candidates, LCB, chosen, override?, probe?, degraded?, latency`；汇总 switches/ep、jerk、p99 延迟、拒答率。
- **用途**：对齐官方 §6 的可信度口径；也是我们自己的调试器（定位"规划抖动"与"错误自信"）。
- **验收**：报告可导出；`switches/ep ≤2`；无异常离群动作告警。

## 3. 符号与定义（U13–U24）

| 符号 | 含义 |
|---|---|
| `Ω` | option 库 |
| `ω=(I_ω,π_ω,β_ω)` | option：启动集 / 策略 / 终止概率 |
| `A_t` | affordance field（U15） |
| `Pre_ω, Post_ω` | option 的软前/后条件 ∈[0,1] |
| `ρ(ω)` | option 的关系类型 ∈{contact,support,contain,align,rotate} |
| `V_θ` | 成功概率/进度值 ∈[0,1] |
| `C_ψ` | 相对 critic：P(a 优于 b) |
| `L_g` | 分组 conformal 下界 |
| `G_ℓ` | 语言指令对应的目标谓词 |
| `U(·)` | 不对称效用（U20） |
| `D(t)` | 当前调用剩余预算（U22） |
| `S_slack` | episode 剩余时间 slack |
| `Δ_comp` | 组合 OOD gap（U23） |
| `reuse(ω)` | option 复用计数（U24） |

**定义 U13（option / 半 MDP）** `ω=(I_ω,π_ω,β_ω)`，其中 `I_ω: O→[0,1]` 为软启动集，`π_ω(a_{1:T_a}|o,ℓ,z_task,z_phase,c)` 为动作块策略，`β_ω: O→[0,1]` 为终止概率。执行器在每次 `get_action` 后按 `β_ω` 与 planner 的抢占信号决定是否结束当前 option。

**定义 U14（option 语法与软规划）** 每个 `ω` 有软前后条件 `Pre_ω(A_t,o_t)`、`Post_ω(A_t,o_t)` 与关系类型 `ρ(ω)`。给定目标谓词 `G_ℓ`，规划为
`π_plan = argmax_{ω_1..ω_H, H≤2} [ Σ_h log Pre_{ω_h} + Σ_h log Post_{ω_h} + λ_v V_θ(o,ω_H) ]`，
约束 `Post_{ω_H} ⊨ G_ℓ`（软满足度 ≥τ_g）。若最优分数 <τ_plan，则退回 VLA 原语。

**定义 U15（affordance field）** `A_t = f_A(o_t) ∈ [0,1]^{6×H×W}`，6 通道 = {graspable, support, containable, alignable, openable, fragile}；多视角融合；**不输入实例 ID / 任务 ID**，以保证物体无关性。

**定义 U16（进度/成功值）** `V_θ(o,ℓ) ≈ P(Y=1 | o,ℓ)`，`Y` 为终态成功；另设剩余时间头 `R_θ(o,ℓ)` 估计 `E[T_remaining]`，仅用于 slack（不进入计分目标）。训练时用 `Φ=V_θ` 做 potential-based shaping（L8），决策时只用校准后的 `L_g`。

**定义 U17（相对 critic）** `C_ψ(o,ω_a,ω_b)=σ(g_ψ(φ(o),e_{ω_a},e_{ω_b}))`，输出"在状态 `o` 下 `ω_a` 优于 `ω_b`"的概率；训练目标 `−E[log C_ψ(o,ω^+,ω^-)]`（Bradley–Terry）。相对头只用于候选排序，不用于止损。

**定义 U18（分组 conformal 下界）** 给定校准集 `D_g`（组 `g=(任务簇,相位)`），非一致性分数 `s_i = V̂(o_i) − Y_i`，取
`q_g = Quantile_{\lceil (n_g+1)(1−α)\rceil / n_g}({s_i})`，
`L_g(o) = clip(V̂(o) − q_g, 0, 1)`。
在组内可交换假设下，`P(Y ≥ L_g(o)) ≥ 1−α`；等价地，**当 `L_g>τ` 时宣称"进展/成功"的假阳性率 ≤α**。当 `n_g<n_min` 时向父组回退；当 OOD 分数 `>τ_ood` 时返回 `None`（拒答）。

**定义 U19（默认保留的 override 准则）** 设默认动作为 `a^0`（基础 VLA 输出）。仅当同时满足：
① `L_g(a^*) − L_g(a^0) ≥ δ`；
② 动作信任域 `d_M(a^*,a^0) ≤ ε`（Mahalanobis，用训练分布估计）；
③ `U(a^*) − U(a^0) > 0`；
④ 不在 OOD 拒答区；
才用 `a^*` 覆盖 `a^0`；否则原样执行 `a^0`。

**定义 U20（不对称效用）** `U = p·G − (1−p)·C_hard − λ·c_op`，其中 `G=1`（成功率是唯一计分货币），`C_hard` 为"硬失败"代价（空抓继续、掉物、顶死），`c_op` 为操作/延迟成本。取 `C_hard ≫ G`，体现"漏判比误判更贵"。

**定义 U21（probe 的 value-of-information）** 对 probe `ρ`：
`VOI(ρ) = E_{z∼ρ}[ max_ω U(ω|z) ] − max_ω U(ω) − c_ρ`，
其中 `z` 为 probe 后的观测摘要，`c_ρ` 为时间与扰动成本。仅当 `VOI(ρ)>0`、`dur(ρ)<S_slack`、`risk_disturb(ρ)<τ_d` 时执行。

**定义 U22（deliberation 预算）** 控制周期 `Δ=1/30 s`，固定 chunk 长度 `T_a`，单次调用预算
`D = T_a·Δ − ε_io`，并与 episode 剩余 slack 取小：`D_eff = min(D, S_slack)`。
anytime planner 维护当前最优；若"再评估一个候选的估计耗时" `> D_eff − elapsed`，立即停止并提交当前最优（或默认）。

**定义 U23（组合 OOD 与 gap）** 五类切分：
`O1` 留出同类别未见实例；`O2` 留出未见物体类别；`O3` 留出未见关系（如训练无 insert，测试需 insert）；`O4` 留出未见原语（如训练无 push，测试需 push）；`O5` 留出背景/位置/干扰物组合。
`Δ_j = succ_ID − succ_{O_j}`，`Δ_comp = mean_j Δ_j`。组合 gap 的比较对象是**同参数量、同数据、同训练步数的单体 VLA**。

**定义 U24（复用与通用性）** `reuse(ω)=|{任务 t: ω 在 t 上被选中且终态成功}|`；覆盖率 `cov = |{(t,ω) 实际使用}| / (32·|Ω|)`；通用性指标 `Gen = mean_ω log(1+reuse(ω))`。预注册要求：每个进库 option `reuse(ω) ≥3`（或跨 ≥2 物体类别）。

### 4.2 PlanLoop：默认保留 + anytime 四选一

```python
DT, EPS_IO = 1/30.0, 0.010

def act(self, obs, s):
    t0 = time.perf_counter()

    # (1) 默认输出永远先存在（P7）
    feat = self.trunk.encode(obs)                 # 一次昂贵前向，候选共享
    a0   = self.trunk.decode(feat, option=None, T_a=self.T_a)

    # (2) 状态估计：相位 / 抓握 / affordance / 任务簇
    A  = self.aff(obs)                            # U15
    ph = self.phase(obs, A)                       # U3
    g  = self.grasp_prob(obs, A)                  # U4
    grp = (self.task_cluster(obs["observation.language"]), ph)

    # (3) 候选 option：continue + 软前置条件通过者
    cands = [W_CONTINUE] + [w for w in self.opt
                            if self.opt.pre(w, A, obs) >= TAU_PRE]

    # (4) anytime 评分：相对头排序 + conformal 下界止损
    best = Incumbent(a0, lcb=self.cal.lcb(self.critic.v(feat, obs), grp), u=0.0)
    D_eff = min(self.T_a * DT - EPS_IO, self.slack(obs))
    for w in cands[1:]:
        if self.eta(w) > D_eff - (time.perf_counter() - t0):
            break                                  # U22：预算不够就停
        aw = self.trunk.decode(feat, option=w, T_a=self.T_a)
        lcb = self.cal.lcb(self.critic.v(feat, obs, w), grp)
        if lcb is None:                            # OOD 拒答
            continue
        u = self.utility(lcb, w, g, ph, s)         # U20
        if self.override_ok(aw, a0, lcb, best.lcb, u, best.u):
            best = Incumbent(aw, lcb, u)

    # (5) probe：只在 VOI>0 且 slack 足够时（IP-13）
    rho = self.pick_probe(g, A, ph)
    if rho and self.voi(rho, g, A, grp) > 0 and self.dur(rho) < self.slack(obs):
        best.a = self.probe_chunk(rho)
        s.n_probe += 1

    # (6) 缝合 + 审计 + 形状断言（T_a 必须恒定）
    a = self.stitch(best.a, s.last_chunk)          # 第 1 轮 U7
    a = self.audit.clamp_and_log(a, obs, t0, D_eff)
    s.last_chunk = a[-1]
    assert a.shape[0] == self.T_a                  # 修正 1 的硬校验
    return self.pack(a)
```

### 4.3 分组 conformal 校准与拒答

```python
class GroupConformalCalibrator:
    def __init__(self, alpha=0.10, n_min=200, tau_ood=None):
        self.alpha, self.n_min, self.tau_ood = alpha, n_min, tau_ood
        self.scores = defaultdict(list)            # group -> [V_hat - Y]

    def fit(self, calib):
        for o, y, grp in calib:
            self.scores[grp].append(self.model.v(o) - y)

    def lcb(self, v_hat, grp):
        if self.ood_score(grp) > self.tau_ood:     # 分布外：拒答
            return None
        g = grp
        while len(self.scores[g]) < self.n_min:    # 层级回退
            g = self.parent(g)
        s = sorted(self.scores[g])
        k = math.ceil((len(s) + 1) * (1 - self.alpha))
        q = s[min(k, len(s)) - 1]
        return max(0.0, min(1.0, v_hat - q))
```

def build_preference_pairs(dataset):

    # (b) 同轨迹：后段（更接近终态）vs 前段

### 4.5 Option 软规划（深度 ≤2）

```python
def plan(A, G, obs, critic):
    best = None
    for w1 in OPTIONS:
        if PRE(w1, A, obs) < TAU_PRE: continue
        if POST(w1, A, obs) >= TAU_GOAL and G.satisfied_by(w1):
            cand = [w1]
        else:
            for w2 in OPTIONS:                       # 深度 2
                if PRE(w2, A, obs) < TAU_PRE: continue
                if not COMPOSE(w1, w2): continue     # 关系类型兼容
                if POST(w2, A, obs) >= TAU_GOAL:
                    cand = [w1, w2]
        if cand:
            score = sum(math.log(PRE(w,A,obs)) for w in cand) \
                  + sum(math.log(POST(w,A,obs)) for w in cand) \
                  + LAMBDA_V * critic.lcb(obs, cand[-1])
            best = max(best, (score, cand), key=lambda x: x[0])
    return best[1] if best and best[0] >= TAU_PLAN else None
```

## 5. 推导（L8–L14）

**引理 L8（potential-based shaping 不改变最优策略）** 若奖励加 `F(s,s')=γΦ(s')−Φ(s)`，则任意 MDP 的最优策略不变（Ng, Harada & Russell, 1999）。本轮取 `Φ=V_θ` 仅用于**训练期稠密化**；同一次策略改进内 `Φ` 固定。若 `V_θ` 在改进过程中更新，则必须在每次更新后重新满足"固定势函数"条件，否则不变性不成立。∎

**引理 L9（默认保留的风险单调性）** 设对默认 `a^0` 与候选 `a^*` 各有 conformal 下界 `L^0,L^*`，覆盖事件 `E={Y≥L}` 的概率 ≥`1−α`。由 union bound，两者同时覆盖的概率 ≥`1−2α`。在 `E` 成立时，若 `L^*>L^0+δ` 且执行 `a^*`，则其真实结果的**下界**不低于 `a^0` 的下界加 `δ`；因此 override 相对默认的最坏期望损失 ≤`2α·C_hard + (δ_est−δ)`，其中 `δ_est` 为估计误差。取 `δ>δ_est` 即可把"因估计误差导致的退化"压到 `2α·C_hard` 量级。∎

**引理 L10（分组 conformal 在组内可交换下的覆盖率；偏移下的失效）** 在组 `g` 内样本可交换时，U18 的 `L_g` 满足 `P(Y<L_g)≤α`。若测试分布相对校准分布有协变量偏移，且密度比 `w(o)=p_test(o)/p_cal(o)` 已知且 `w≤M`，则加权 conformal 用权重 `w(o_i)` 可恢复 `1−α` 覆盖率（Tibshirani et al., 2019）；若 `w` 未知，只能估计 `ŵ`，覆盖率保证变为条件于 `ŵ=w`。因此本方案在 `ŵ` 不可信或 `ŵ>w_max` 时**拒答**，把"无保证的决策"降级为"默认执行"。∎

**引理 L11（不对称代价下的重试阈值）** 设继续的 LCB 成功率为 `p`，重试后的可恢复成功率为 `r`，硬失败代价为 `c=C_hard/G`，重试成本为 `k=c_op/G`。则
`U_cont = p − (1−p)c`，`U_retry = r − (1−r)c − k`。
`U_retry > U_cont ⇔ p < r − k/(1+c)`。
当 `c→∞`（硬失败极贵）时阈值趋于 `r`：**只有在"继续的成功率低于重试可恢复率"时才重试**，天然给出高精度、低召回的介入。这与第 1 轮 L3 的保守介入一致，但把"阈值"从拍脑袋变成了效用推导。∎

**引理 L12（probe 的净收益条件）** 由 U21，probe 的净收益 `VOI(ρ)` 为正时执行。由于第 1 轮实测"时长与成功无关"（corr≈−0.011），在**无硬超时**的区间内 `c_ρ` 只含扰动风险与信息处理开销，`VOI` 近似等于"信息增益 × 决策价值 − 扰动风险"。若存在硬超时 `T_max`，则额外约束 `P(T_remaining < dur(ρ)+T_exec) ≤ ε_timeout`；用 `R_θ` 的保守分位数估计 `T_remaining`，不满足则不探测。∎

**命题 L13（复用—泛化的标度假设，可检验）** 在共享参数线性化、各任务数据同分布的简化模型下，一个被 `n` 个任务复用的 option，其共享参数的有效样本量随 `n` 增长，组合 OOD gap 预期以 `O(n^{-1/2})` 下降。**这不是定理，而是可证伪的标度预测**：若在官方 32 任务上拟合 `log Δ_comp` 对 `log reuse` 的斜率，得不到显著负斜率（或 Spearman >−0.4），则"复用→通用"的叙述不成立，应砍掉 IP-11 的符号层（对应 E628）。∎

**引理 L14（滞回抑制决策抖动）** 设切换需满足"新 option 的效用超过当前 option 至少 `h`"，且有最小驻留时间 `τ_min`。则 episode 内切换次数 ≤`T/τ_min`；若效用估计噪声上界 `ε<h/2`，则真实差距小于 `h−2ε` 的两个 option 之间不会发生切换。∎
