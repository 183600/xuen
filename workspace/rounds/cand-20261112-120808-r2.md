# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 7 轮；本轮灵感：「个性化交互」×「多端口部署」）

> 第 60 轮的 SGEC 已把「场景→意图→约束→阻抗→执行→EV-exec→场景更新」闭起来：SSM 场景语义、CIEC 意图约束、EPIR 因果隔离、SERC 场景闭环、PCE++++ 认知预算。但**三个更深的结构性问题**仍在：
> 1. **个性化交互的「平均人」假设**：CIEC 的意图-约束映射 ϕ 是全局固定表，SSM 的 π_scene 也是全体共享。可是同一句「轻触」，新手与老练用户、健康用户与手部受限用户、甚至同一用户在不同疲劳/信任状态下的含义差异可达一个数量级。缺少**用户条件化**，系统只能服务「统计平均人」，个性化被硬编码在规则里而非可学习的后验里。
> 2. **多端口部署的「单一端口」假设**：SERC 的预算、场景库、EPIR 同步节奏、ROS 假设都隐式绑定了同一台边端 + 同一套 ROS + 同一网络。但真实产品要同时部署到工作站、边缘盒、云端、不同机械臂/传感器、ROS1/ROS2/DDS 多端口——算力、时延、丢包、模态、场景经验全不同，靠人工逐端口调参不可维护，且**没有任何证书保证「抽象安全语义」在每个端口仍成立**。
> 3. **个性化与多端口的「锤子-钉子」耦合**：在 A 端口学到的用户偏好搬到 B 端口可能因硬件动力学不同而失效；把 A 端口用户数据直接同步到 B 端口又会泄露隐私；反过来为了跨端口一致而锁死参数，又会把个性化抹平。缺一个**「可移植安全语义」与「个性化实现」分离**的架构。

## 0. 直觉与动机

**灵感 1（个性化交互 → 用户条件意图映射 UCM）**
直觉：个性化不是给用户换一套安全规则，而是给**映射参数 θ 一个层级后验**。全局语义 θ_0 定义「轻触」的公共含义；端口偏移 δ_p 吸收某台机器人/某套传感器的系统性差异；用户偏移 e_u 吸收个体差异。于是 θ_{u,p} = θ_0 + δ_p + e_u，冷启动时 e_u→0 自动回退端口先验，样本增多再逐步「长出自己的个性」。个性化强度 α_u（用户授权度 × 任务风险度）决定个体偏好能推动约束多远。
关键洞见：**个性化只进入「约束增量」ΔC(θ_u, I) 的软参数，不进入安全可行集 S_abs**——安全是端口无关的硬不变量，个性化只能在安全集内选点。

**灵感 2（个性化交互 → 偏好-安全投影 PSP）**
直觉：用户说「再快一点」，但真的会快出安全边界。直接执行是危险的，粗暴拒绝是糟糕的交互。正确做法是把偏好**投影**到安全可行集：C_safe = Π_{S_safe}(C_pref)，当偏好离安全集太远（d > δ_pref）时，给出「最接近的安全实现 + 一条可解释的拒绝理由」。
关键洞见：投影 Π 是非扩张的（non-expansive），且 S_safe ⊆ S_abs，因此**个性化永远不会扩大安全域**；它只会把用户偏好「拉回」到可安全执行的点。

**灵感 3（多端口部署 → 端口契约 DPC + 可移植性编译 PCC）**
直觉：同一套认知-执行栈装到工作站、边缘盒、云端、不同机械臂/传感器/ROS 版本上，行为会漂移。端口不该被当作「环境噪声」，而应被当作**可协商的契约** Sig(p) = (算力, 中间件, 网络, 传感, 场景库)。可移植性编译器把抽象 IR 编译成端口实例 Inst_p，并签发**可移植性证书 J_port = (不变量保持, 预算可行, 降级映射)**。
关键洞见：**「可移植语义」与「端口实现」分离**——像编译器把 IR 降到目标代码；安全不变量是 IR 级、跨端口同一，具体参数是端口级、允许异构。

**灵感 4（多端口部署 → 跨端口一致性 XPC）**
直觉：多端口不要求参数一模一样，而要求**抽象不变量一模一样**：意图语义一致、响应时限、证据链完整性、安全域不扩张、隐私合规。端口漂移（ROS 升级、网络变差、传感器缺失）用「声明签名 vs 观测签名」的距离检测；超阈值就重协商、重编译。
关键洞见：**一致性 = 不变量一致 + 实现异构同义**。把「参数相同」误当「语义一致」是多端口部署最隐蔽的陷阱。

**灵感 5（合流 → PACE+ 个性化多端口闭环、FPL 联邦个性化、PCE+++++）**
直觉：每个端口本地学用户，跨端口只共享**差分隐私摘要**（后验均值、精度、样本数），既提升冷启动又不泄露原始对话；再给预算加 B_pers（个性化算力/画像内存/消歧时延）、B_port（编译/迁移/同步）、B_priv（隐私预算 ε）。风险在于：**个性化漂移 × 端口漂移叠加**，会让 J_port 依据一份过时的端口签名「证明」一个并不成立的安全不变量。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（用户条件意图映射 UCM）** 层级可加模型 θ_{u,p} = θ_0 + δ_p + e_u，其中：
- **全局语义**：θ_0 ~ p(θ_0)，定义意图到约束的公共映射；
- **端口偏移**：δ_p ~ N(0, Σ_port)，吸收端口硬件/中间件/传感器的系统性差异；
- **用户偏移**：e_u ~ N(0, Σ_user)，吸收个体偏好、技能、信任、疲劳；
- **约束生成**：C_pref(I, u, p) = C_base(I) + α_u · ΔC(θ_{u,p}, I)，α_u ∈ [0,1] 为个性化强度（用户授权度 × (1−任务风险度)）；
- **后验更新**：θ_{u,p} ← update(θ_{u,p} | D_u, EV-exec)，以经验贝叶斯收缩，样本 n_u < n_min 时 e_u ≡ 0（冷启动回退端口先验）；
- **漂移可分性**：δ_p 只随端口能力变化，e_u 只随用户变化，便于跨端口迁移用户偏好时只搬运 e_u。

**定义 162（偏好-安全投影 PSP）** 给定用户偏好约束 C_pref、安全可行集 S_safe（由第 59 轮 ERTC/EEIS 与端口预算共同给出）、加权度量 W：
- **投影算子**：Π_{S_safe}(C_pref) = argmin_{C∈S_safe} ‖C − C_pref‖_W；
- **安全包含**：S_safe ⊆ S_abs（S_abs 为端口无关的抽象安全集）；
- **可解释拒绝**：若 d_W(C_pref, S_safe) > δ_pref，返回 (C_safe, r)，其中 r = argmin_{binding constraint} 违反主因，C_safe 为最近安全点；
- **个性化程度**：π_pers = 1 − d_W(C_safe, C_base) / (d_W(C_pref, C_base) + ε)；
- **非扩张性**：‖Π(x) − Π(y)‖_W ≤ ‖x − y‖_W，保证个性化不会放大约束。

**定义 163（部署端口契约 DPC）** 端口 p 的能力签名 Sig(p) = (H_p, M_p, N_p, S_p, L_p, B_port)：
- H_p：算力/实时性（CPU/GPU、WCET）；
- M_p：中间件与 ROS 版本（ROS1/ROS2、DDS 配置、QoS）；
- N_p：网络（RTT、丢包率、抖动、带宽）；
- S_p：传感模态集合（力/视觉/触觉/关节电流…）；
- L_p：本地场景库与历史经验；
- B_port = (WCET, Bus_bw, Thermal, Msg_reliability) 为该端口可承诺的预算。
抽象 IR 的需求 Req(IR) = (WCET_max, Middleware_set, Min_sensors, RTT_max, Loss_max)。**准入**：Sig(p) ⊒ Req(IR) 逐分量满足则 admit，否则 adapt（降级：减模态、降频率、本地闭环）或 reject。

**定义 164（可移植性编译与证书 PCC）** 抽象中间表示 IR = (Φ_sem, I_abs, pipeline)：
- **可移植不变量集**：I_abs = {意图语义等价, τ_response ≤ τ_deadline, EV-exec 证据链完整, 安全域不扩张, 隐私合规}；
- **编译**：PCC：IR × Sig(p) → (Inst_p, J_port)；
- **证书**：J_port = (invariants_ok, budget_ok, degradation_map, ρ_p)，其中 ρ_p 为可移植性得分：
  ρ_p = |I_abs 保持| / |I_abs| − λ_deg·|degradation|/|IR| − λ_mig·migration_cost；
- **端口安全**：若 invariants_ok ∧ budget_ok，则 Inst_p 在端口 p 上满足 I_abs。

**定义 165（跨端口一致性 XPC）** 端口图 G_port = (P, E)：
- **抽象一致性**：∀p,q ∈ P：I_abs(Inst_p) = I_abs(Inst_q)，但允许 Inst_p ≠ Inst_q（异构同义）；
- **行为距离**：D(p,q) = ‖Ŝig(p) − Ŝig(q)‖（同一测试套件下的观测签名差）；
- **漂移检测**：drift(p) = ‖Ŝig(p) − Sig(p)‖；若 drift(p) > θ_drift，标记 p 为 stale，触发 renegotiate/recompile；
- **修复时限**：T_detect ≤ 1 个控制周期，T_repair ≤ τ_deadline，期间该端口降级到本地闭环。

**定义 166（联邦个性化学习 FPL）** 端口间不共享原始对话/原始 EV-exec，只共享差分隐私摘要：
- **本地摘要**：s_u = (mean(θ_{u,p}), precision, n_u)；
- **隐私机制**：M(s_u) = s_u + Lap(Δs/ε_u)，满足 (ε_u, 0)-DP；
- **聚合**：θ_0' = Σ_u n_u·mean_dp(θ_{u,p}) / Σ_u n_u；
- **相似度传输**：只在低维投影空间共享 e_u 的方向，不共享用户身份；
- **隐私预算**：B_priv = (ε_total, aggregation_rounds)，ε_total = Σ_u ε_u ≤ ε_max。

**定义 167（个性化多端口闭环 PACE+）** 算子 PACE+(M, p, u, scene, intent, δf_req)：
```
① DPC:  Sig(p) ← registry.signature(p);           admit/adapt ⊥ Req(IR)
② PCC:  (Inst_p, J_port) ← compile(IR, Sig(p));   若 ¬J_port.invariants_ok → DEGRADE_PORT
③ UCM:  θ_{u,p} ← ucm.update(p, u, D_u, EV-exec)
④ PSP:  C_pref ← ϕ_{θ_{u,p}}(intent);  (C_safe, r) ← Π_{S_safe}(C_pref)
⑤ Lock: ERTC.lock_constraints(C_safe);  若 r≠∅ → explain(u, r)
⑥ SERC: (M, fused, D⁺, EV-exec, cert) ← scenario_evolution_loop(M, scene, intent, δf_req)
⑦ EPIR: S_shadow.append(EV-exec); S_sync.push()
⑧ 回灌: ucm.update(p, u, D_u, EV-exec)        # 执行结果进入用户后验
⑨ FPL:  if B_priv > 0: push(M(s_u))
⑩ XPC:  drift ← detect(M.ports, Sig_declared, Ŝig_observed)
         if stale: registry.renegotiate(stale); PCC.recompile(stale)
```

**定义 168（PCE+++++ 个性化-端口预算）** B_total = (B_cog, B_pers, B_port, B_priv)：
- **B_pers** = (adaptation_ops, profile_memory, disambiguation_latency)；
- **B_port** = (compile_time, migration_bw, cross_port_sync)；
- **B_priv** = (ε_total, aggregation_rounds)；
- **B_cog/B_exec** 沿用第 60/59 轮。

### IP-161 UCM + IP-162 PSP（个性化映射与安全投影）

```python
class UserConditionedMapping:
    def __init__(self, d_theta=8, n_min=5):
        self.theta_0 = np.zeros(d_theta)                      # 全局语义基线
        self.delta_p = defaultdict(lambda: np.zeros(d_theta)) # 端口偏移 δ_p
        self.e_u = defaultdict(lambda: np.zeros(d_theta))     # 用户偏移 e_u
        self.n_u = defaultdict(int)
        self.Sigma_p = np.eye(d_theta) * 0.10
        self.Sigma_u = np.eye(d_theta) * 0.05
        self.n_min = n_min

    def theta(self, port, user):
        return self.theta_0 + self.delta_p[port] + self.e_u[user]

    def update(self, port, user, dialogue, ev_exec):
        target = self._infer_theta_target(dialogue, ev_exec)
        self.n_u[user] += 1
        if self.n_u[user] < self.n_min:                       # 冷启动：回退端口先验
            self.delta_p[port] = self._shrink(target, self.theta_0, self.Sigma_p)
            return self.theta_0 + self.delta_p[port]
        lam = self.n_u[user] / (self.n_u[user] + self._prior_strength())
        resid = target - self.theta_0 - self.delta_p[port]
        self.e_u[user] = (1 - lam) * self.e_u[user] + lam * resid
        return self.theta(port, user)

    def map_intent(self, port, user, intent, ctx, alpha_u):
        dC = self._constraint_delta(intent, ctx, self.theta(port, user))
        return C_base(intent) + alpha_u * dC                  # α_u ∈ [0,1]

def preference_safety_projection(C_pref, S_safe, W, delta_pref=0.25):
    C_safe, dist = project_qp(C_pref, S_safe, W)              # argmin ||C−C_pref||_W
    if dist <= delta_pref:
        return C_safe, None
    reason = explain_binding_constraint(C_pref, S_safe)       # 违反主因
    return C_safe, {'refused': True, 'reason': reason, 'closest_safe': C_safe}
```

### IP-163 DPC + IP-164 PCC（端口契约与可移植性证书）

```python
REQ = {'wcet_max': 8.0, 'middleware': {'ros1', 'ros2'},
       'sensors': {'force'}, 'rtt_max': 50.0, 'loss_max': 0.05}

def admit_port(sig, req=REQ):
    checks = {
        'wcet':       sig['wcet'] <= req['wcet_max'],
        'middleware': sig['middleware'] in req['middleware'],
        'sensors':    req['sensors'] <= set(sig['sensors']),
        'network':    sig['rtt'] <= req['rtt_max'] and sig['loss'] <= req['loss_max'],
    }
    return all(checks.values()), [k for k, ok in checks.items() if not ok]

def compile_portability(ir, sig):
    ok, missing = admit_port(sig)
    if not ok:
        ir = apply_degradation(ir, missing)      # 减模态/降频率/本地闭环
    inst = lower_ir_to_target(ir, sig)           # IR → 端口参数
    J_port = {
        'invariants_ok': check_invariants(inst, ir.I_abs),
        'budget_ok':     check_budget(inst, sig['B_port']),
        'degradation':   missing,
        'score':         portability_score(inst, ir.I_abs, missing),
    }
    return inst, J_port
```

### IP-165 XPC（跨端口一致性）

```python
def cross_port_consistency(ports, sig_declared, sig_observed, theta_drift=0.2):
    drift = {p: capability_distance(sig_observed[p], sig_declared[p]) for p in ports}
    stale = [p for p, d in drift.items() if d > theta_drift]
    inv_ok = all(check_invariants(inst[p], I_abs) for p in ports)   # 不变量一致 ≠ 参数一致
    return {'invariants_consistent': inv_ok, 'stale_ports': stale, 'drift': drift}
```

```python
def federated_aggregate(summaries, eps):
    noisy = {}
    for u, (mu, prec, n) in summaries.items():       # 绝不上传原始对话/原始证据
        scale = 1.0 / (eps * max(n, 1))
        noisy[u] = (mu + np.random.laplace(0, scale, size=mu.shape), prec, n)
    total = sum(n for _, _, n in noisy.values())
    theta_0_new = sum(mu * n for mu, _, n in noisy.values()) / total
    return theta_0_new                              # 只回传聚合后验，不泄漏单用户
```

### IP-167 PACE+（个性化多端口闭环）

```python
def personalized_adaptive_cognition_execution(M, port, user, scene, intent, delta_f_req):
    sig = M.port_registry.signature(port)
    inst_p, J_port = compile_portability(M.ir, sig)
    if not J_port['invariants_ok']:
        return DEGRADE_PORT(port, J_port)

    theta = M.ucm.update(port, user, M.dialogue_buf, M.last_ev_exec)
    C_pref = M.ucm.map_intent(port, user, intent, M.ctx, alpha_u=M.profile[user].alpha)
    C_safe, refusal = preference_safety_projection(C_pref, M.ertc.safe_set, M.W)
    if refusal:
        M.explain(user, refusal)
    M.ertc.lock_constraints(C_safe)

    M, fused, D_plus, EV_exec, cert = scenario_evolution_loop(
        M, scene, intent, delta_f_req)             # 第 60 轮 SERC，约束已被 PSP 投影

    epir_msg = M.epir.append(EV_exec.__dict__)
    M.ucm.update(port, user, M.dialogue_buf, EV_exec)  # 执行反馈回灌用户后验

    if M.budget.B_priv > 0:
        M.fpl.push(dp_summary(theta, eps=M.budget.eps))

    xpc = cross_port_consistency(M.ports, M.sig_declared, M.sig_observed)
    if xpc['stale_ports']:
        M.port_registry.renegotiate(xpc['stale_ports'])
        for p in xpc['stale_ports']:
            M.inst[p], M.J_port[p] = compile_portability(M.ir, M.port_registry.signature(p))

    return M, inst_p, EV_exec, cert, J_port, xpc
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| UCM | O(d²) 后验更新/O(1) 映射 | O(\|P\|d + \|U\|d) | 冷启动 ≤ n_min 次交互回退端口先验；个性化满意度 ≥ 25% |
| PSP | O(\|C\|²) 凸二次投影 | O(\|C\|) | 安全域扩张 = 0；拒绝解释与被绑约束一致率 ≥ 95% |
| DPC/PCC | O(\|Req\|) 准入 / O(\|IR\|) 编译 | O(\|IR\|) | 证书有效；端口准入率 ≥ 90% |
| XPC | O(\|P\|²) 测试对账 | O(\|P\|²) | 不变量一致率 100%；漂移检测 ≤ 1 周期 |
| FPL | O(\|U\|d) 聚合 | O(\|U\|d) | (ε,0)-DP；无原始数据外泄 |

**正确性定理（PHEC：Personalized Heterogeneous Execution Consistency）**：

```python
class UserConditionedMapping:
    def __init__(self, d_theta=8, n_min=5):
        self.theta_0 = np.zeros(d_theta)
        self.delta_p = defaultdict(lambda: np.zeros(d_theta))
        self.e_u = defaultdict(lambda: np.zeros(d_theta))
        self.n_u = defaultdict(int)
        self.Sigma_p = np.eye(d_theta) * 0.10
        self.Sigma_u = np.eye(d_theta) * 0.05
        self.n_min = n_min

    def theta(self, port, user):
        return self.theta_0 + self.delta_p[port] + self.e_u[user]

    def update(self, port, user, dialogue, ev_exec):
        target = self._infer_theta_target(dialogue, ev_exec)
        self.n_u[user] += 1
        if self.n_u[user] < self.n_min:                       # 冷启动：回退端口先验
            self.delta_p[port] = self._shrink(target, self.theta_0, self.Sigma_p)
            return self.theta_0 + self.delta_p[port]
        lam = self.n_u[user] / (self.n_u[user] + self._prior_strength())
        resid = target - self.theta_0 - self.delta_p[port]
        self.e_u[user] = (1 - lam) * self.e_u[user] + lam * resid
        return self.theta(port, user)

    def map_intent(self, port, user, intent, ctx, alpha_u):
        dC = self._constraint_delta(intent, ctx, self.theta(port, user))
        return C_base(intent) + alpha_u * dC

def preference_safety_projection(C_pref, S_safe, W, delta_pref=0.25):
    C_safe, dist = project_qp(C_pref, S_safe, W)
    if dist <= delta_pref:
        return C_safe, None
    reason = explain_binding_constraint(C_pref, S_safe)
    return C_safe, {'refused': True, 'reason': reason, 'closest_safe': C_safe}
```

```python
def federated_aggregate(summaries, eps):
    noisy = {}
    for u, (mu, prec, n) in summaries.items():
        scale = 1.0 / (eps * max(n, 1))
        noisy[u] = (mu + np.random.laplace(0, scale, size=mu.shape), prec, n)
    total = sum(n for _, _, n in noisy.values())
    theta_0_new = sum(mu * n for mu, _, n in noisy.values()) / total
    return theta_0_new
```
