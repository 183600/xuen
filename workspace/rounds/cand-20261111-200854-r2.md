# 第 56 轮（承接第 55 轮 v31 GroundEdge-GenSim+++；灵感循环第 2 轮；本轮灵感：「创新点挖掘」×「数据集构建」）

> 第 55 轮把“语义标签”升级为“可执行的接触约束”，但其 soundness 三重依赖校准、跨材质迁移与生存核紧致性——这三者本质上是**证据问题**，不是建模问题。本轮把视角从“再造一个方法”抬到元层：**创新点本身如何被系统地挖出来，以及用什么数据集证明它不是一个自我实现的叙事**。核心矛盾：**H24**：真正稀缺的不是模型组件，而是“能力格 × 未满足约束”碰撞出的高杠杆点，且其价值只有在能被一个可构造的见证数据集证伪时才成立；**H25**：数据集不是样本的堆积，而是一份可执行的证伪论证，其辨识力由覆盖、边界难度与反事实三要素决定。

## 0. 直觉与动机

**灵感 1（创新点挖掘 → 在“能力格 × 未满足约束”里找碰撞，而非凭空发明）**
直觉：v16+++ 已经积木成山，新的创新往往不是从零发明一个模块，而是把一个已有能力 `c` 撞上一个一直没被满足的部署约束 `u`（如“边界语义不可信”“接触跨材质迁移失败”）。把创新候选写成 `I = C × U`，用 **碰撞势** `Φ(c,u)` 排序：新颖（离已有组合远）× 杠杆（解决高频/高代价失败）× 可证伪（能在预算内造出能杀死它的数据集）。挖掘 = 在这个乘积空间上做带预算的次模搜索。

**灵感 2（数据集构建 → 数据集是“证伪论证”，不是“样本集合”）**
直觉：一个只有正样本的数据集只能确认，不能证伪。为每个创新声明 `ψ` 配一个 **见证集** `W = (W⁺, W⁻, W∂)`：正见证说它成立；**负见证是“看起来该成立但实际不成立”的伪阳性陷阱**；边界见证贴着失败边界。数据集的价值不在大小，而在 **辨识力**——它能不能把 `ψ` 与“最强基线 + 零假设”区分开。

**灵感 3（创新-数据对偶 → 每个创新点绑定一份数据集契约）**
直觉：创新是“断言”，数据集是“对断言的检验”，两者互为对偶。把二者绑成 **创新-数据契约** `IDC = (c,u,ψ,D(ψ),Φ,status)`。没有见证集的创新只能标记为 `mined`，永远不能升级为 `confirmed`；反过来，没有创新假设驱动的数据集构建就只是暴力采样。**MineCert 的硬规则：任何 `confirmed` 状态都必须携带功率达标的负见证。**

**灵感 4（数据辨识力 → 覆盖 × 边界难度 × 反事实）**
直觉：大而均匀的数据集在创新边界处几乎是盲的。定义数据集三要素：**覆盖**（声明作用域 `Ω_ψ` 被覆盖多少，按关键度加权）、**边界难度**（`W∂` 贴着 `∂Ω_ψ` 或生存核边界 `∂K` 的密度，直接复用第 55 轮的语义边界与生存核边界）、**反事实**（同一输入下“有创新 / 无创新”配对，使边际贡献可识别）。这把“构建数据集”从采集问题变成 **实验设计问题**。

**灵感 5（主动见证采样 → 沿失败边界猎取，而不是均匀撒点）**
直觉：既然第 55 轮最大的风险在语义边界 `∂Ω` 与生存核边界 `∂K(Σ)`，那么数据就该在那里主动采样：材质过渡带、遮挡边界、玻璃/反光/地毯覆盖空洞等“伪支撑陷阱”。用贝叶斯优化最大化“声明成立/失败”后验的熵减，即 **边界猎取**。

**灵感 6（反事实孪生 + 创新账本 → 防止“僵尸创新”与确认偏误）**
直觉：要声称“这是创新”，必须在**同一见证集**上与消融孪生比较：把 κ 抹平、把边界裕度去掉、把语义换回纯几何。配对差 `Δ(ψ)` 才是可归因的边际贡献。再用 **创新账本** 跨轮记录每个 IDC 的 `status` 与多重检验校正，防止“讲得很好但从未被证伪”的僵尸创新越滚越多。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（创新候选与碰撞势）**
能力格 `C`（承接第 54 轮），UniBot 未满足约束集 `U`（来自失败案例库）。候选 `I = C × U`。碰撞势
`Φ(c,u) = N(c,u)^α · L(c,u)^β · F(c,u)^γ · exp(-λ·Cost(c,u))`，
其中 `N` 为相对已部署组合的新颖度（联合嵌入空间到最近邻的距离，并按“该约束是否已被解决”折减），`L` 为杠杆（`P(当前失败|u) × freq(u) × severity(u)` 的期望增益），`F∈[0,1]` 为**可证伪性**（能否在预算 `B_D` 内造出功率 ≥ `θ_pow` 的见证集），`Cost` 为实现 + 数据成本。

**定义 128（见证集与数据集契约）**
对声明 `ψ`，见证集 `W(ψ) = (W⁺, W⁻, W∂)`；数据集契约 `D(ψ) = (W, Cov, Pow, B_D)`。`W⁻` 必须是**伪阳性陷阱**：在“零假设成立”时会触发声明的样本。契约要求 `W⁻ ≠ ∅` 且 `W∂ ≠ ∅`，否则 `D` 记为不可证伪。

**定义 129（数据集辨识力）**
覆盖 `Cov(D,ψ) = ∫_{Ω_ψ} w(x)·1[x∈W] dx / ∫_{Ω_ψ} w(x) dx`，`w` 为关键度（失败代价密度）。辨识力（证伪功效）
`Pow(D,ψ) = min_{ψ'∈Alt(ψ)} Φ_eff( m_D(ψ,ψ')·√|W| )`，
其中 `m_D(ψ,ψ') = (μ_W[s_ψ - s_{ψ'}]) / σ_pooled` 为效应量，`Φ_eff` 为效应量到功效的单调映射，`Alt(ψ) ⊇ {null, 最强基线}`。

**定义 130（创新-数据契约 IDC 与接受规则）**
`IDC = (c,u,ψ,D(ψ),Φ,status)`，`status ∈ {mined, underpowered, confirmed, refuted}`。只有当 `Φ ≥ θ_Φ ∧ Cov ≥ θ_cov ∧ Pow ≥ θ_pow` 时方可进入 `confirmed` 候选；否则只能停留在 `mined` 或 `underpowered`。**不存在没有见证集的 confirmed。**

**定义 131（主动见证采样 / 边界猎取）**
采样策略 `π` 选择 `x* = argmax_x { I_ψ(x) + λ_b·(1/dist(x, ∂Ω_ψ ∪ ∂K(Σ))) }`，`I_ψ(x)` 为对“ψ 成立/失败”后验的互信息（熵减）。即把采样预算优先投在声明最可能崩的地方。

**定义 132（反事实孪生与归因）**
对同一输入 `x` 构造孪生 `x^ab`（消融创新因子：κ 抹平 / 边界裕度关闭 / 语义退化为纯几何）。配对边际 `Δ(ψ) = E_W[metric(ψ)] - E_W[metric(ψ^ab)]`。若配对检验显著且孪生可交换（同一场景、只改创新因子），则称 `ψ` **因果支撑**。

## 2. 关键算法 伪代码

### IP-127 IPM（Innovation Point Miner）

```python
def mine_innovations(C, U, budget, theta_phi):
    cand = []
    for c in C:
        for u in U:
            Phi = collision_potential(c, u)          # N,L,F,Cost
            if Phi >= theta_phi:
                cand.append(Candidate(c, u, Phi))
    # 子模 + 多样性：每次选中后，其覆盖到的 u 使后续边际增益下降
    sel, covered = [], set()
    while budget > 0 and cand:
        best, gain = None, -inf
        for c_i in cand:
            g = c_i.Phi * novelty_penalty(c_i, sel) * (1 - cover_frac(c_i.u, covered))
            if g > gain:
                best, gain = c_i, g
        if best.Cost > budget:
            cand.remove(best); continue
        sel.append(best); covered |= constraint_region(best.u)
        budget -= best.Cost; cand.remove(best)
    return sel          # 每个候选仍须 bind_contract 才能升级
```

### IP-128 IDC（Innovation-Data Contract）

```python
def bind_contract(cand, budget_D):
    psi = formalize_claim(cand)                  # claim + 作用域 Omega_psi + 可测结果 y
    W = witness_constructor(psi, budget_D)       # IP-129
    Cov, Pow = dataset_power(W, psi)             # IP-130
    status = 'mined'
    if W.neg == []:
        status = 'unfalsifiable'                 # 没有伪阳性陷阱
    elif Pow < theta_pow or Cov < theta_cov:
        status = 'underpowered'
    return IDC(cand.c, cand.u, psi, D=(W, Cov, Pow, budget_D),
               Phi=cand.Phi, status=status)
```

### IP-129 WSC（Witness Set Constructor）

```python
def witness_constructor(psi, budget_D):
    W_pos, W_neg, W_bd = [], [], []
    prior = failure_surface_prior(psi)           # 失败概率面
    while budget_D > 0:
        x = argmax_x(mutual_info(prior, x) + lam_b * boundary_proximity(psi, x))
        y = oracle_or_sim(x)                     # 接触/任务真值
        if psi.predict(x) and y.ok:
            W_pos.append((x, y))
        elif psi.predict(x) and not y.ok:
            W_neg.append((x, y))                 # 伪阳性陷阱
        elif near_boundary(psi, x):
            W_bd.append((x, y))
        prior = update(prior, x, y); budget_D -= cost(x)
    return WitnessSet(W_pos, W_neg, W_bd)
```

### IP-130 DPP（Dataset Power Profiler）

```python
def dataset_power(W, psi, alts):
    Cov = weighted_coverage(W, psi.scope)
    Pow = 1.0
    for psi_alt in alts:                         # 含 null 与最强基线
        effect = effect_size(W, psi, psi_alt)
        Pow = min(Pow, power_from_effect(effect, len(W.all)))
    return Cov, Pow
```

### IP-131 CFT（Counterfactual Twin Fabricator）

```python
def twin_dataset(W, psi):
    pairs = []
    for x, y in W.all:
        x_ab = ablate(x, psi.factor)             # 抹平 κ / 关边界裕度 / 退化为几何
        y_ab = oracle_or_sim(x_ab)
        pairs.append((x, y, x_ab, y_ab))
    return PairedSet(pairs)                      # 供配对检验归因
```

### IP-132 MCL（Mining-Certificate Ledger）

```python
def ledger_update(ledger, idcs, alpha):
    # Holm 校正的多重检验：只有通过校正的 confirmed 才入账
    pvals = [paired_test(i.twins) for i in idcs]
    for i, keep in holm(pvals, alpha):
        i.status = 'confirmed' if keep else 'refuted'
        ledger.append(snapshot(i))
    return ledger
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| IPM | O(\|C\|·\|U\| + K·\|I\|) 贪心 | O(\|I\|) | 子模 + 多样性，贪心 (1-1/e) |
| IDC | O(\|W\|) 绑定 | O(\|ψ\|) | `W⁻` 非空、功率阈值 |
| WSC | O(B_D·cost) | O(\|W\|) | 边界覆盖、陷阱样本有效 |
| DPP | O(\|W\|·\|Alt\|) | O(1) | `Alt` 含 null 与最强基线 |
| CFT | O(\|W\|·\|A\|) | O(\|W\|) | 孪生配对可交换 |
| MCL | O(K·\|W\|) | O(K) | 多重检验校正、可追溯 |

**正确性定理（创新-数据联合 soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** 碰撞势在挖掘预算下单调次模、贪心选择有 (1-1/e) 下界；**(A34)** 每个契约的 `W⁻` 非空且 `Alt(ψ) ⊇ {null, 最强基线}`，`Pow ≥ θ_pow`；**(A35)** 反事实孪生配对且可交换，满足 SUTVA；**(A36)** 多创新比较经 Holm 校正于水平 `α`。则
```
P(错误接受一个 confirmed 创新) ≤ α + P(Alt 设定错误) + P(孪生不可交换)
```
关键：**创新必须携带可证伪的见证集、数据功率必须对 null 与最强基线达标、归因必须配对**。任何一层缺失，`status` 最多是 `mined/underpowered`，绝不会被账本升级为创新。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 碰撞势高估、挖出“伪创新” | 高 | 强制 `W⁻` + 功率门槛，未达功率不得 confirmed |
| `Alt(ψ)` 设定过弱导致自证 | 高 | 强制纳入最强基线与 null，外部红队审阅 |
| 边界猎取陷入局部、覆盖塌缩 | 中 | 覆盖-难度双目标 + 分层采样配额 |
| 反事实孪生不可交换（混杂） | 高 | 同场景配对、随机化创新因子顺序 |
| 多重检验下过度保守、全被拒 | 中 | 预注册 + 分层 α 分配 + 先导功率分析 |

## 6. 本轮最大风险

**一句话**：MineCert 把“灵感”变成可搜索的碰撞势、把“数据集”变成可证伪的见证契约，但其 soundness **三重依赖碰撞势的诚实估计、替代假设集 `Alt(ψ)` 的完备性、以及反事实孪生的可交换性**；一旦 `Alt(ψ)` 漏掉真正强的基线，数据集功率就会只对“自己设定的稻草人”达标，把确认偏误包装成 `confirmed`——因此必须以 **红队基线清单 + 预注册功率分析 + 配对孪生** 三重护栏，宁可把创新标为 underpowered，也绝不把“能骗过自己的见证集”当作创新已被证明。


### IP-132 MCL

```python
def ledger_update(ledger, idcs, alpha):
    pvals = [paired_test(i.twins) for i in idcs]
    for i, keep in holm(pvals, alpha):
        i.status = 'confirmed' if keep else 'refuted'
        ledger.append(snapshot(i))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| IPM | O(\|C\|·\|U\| + K·\|I\|) | O(\|I\|) | 次模贪心 (1-1/e)，多样性惩罚 |
| IDC | O(\|W\|) | O(\|ψ\|) | `W⁻` 非空、功率阈值 |
| WSC | O(B_D·cost) | O(\|W\|) | 边界覆盖 + 陷阱有效 |
| DPP | O(\|W\|·\|Alt\|) | O(1) | `Alt ⊇ {null, 最强基线}` |
| CFT | O(\|W\|·\|A\|) | O(\|W\|) | 配对可交换（SUTVA） |
| MCL | O(K·\|W\|) | O(K) | Holm 校正、可追溯 |

**正确性定理（Innovation-Data Joint Soundness）**
假设 (A29)–(A32) 成立；**(A33)** 碰撞势单调次模、贪心 (1-1/e)；**(A34)** `W⁻≠∅ ∧ Alt(ψ)⊇{null,最强基线} ∧ Pow≥θ_pow`；**(A35)** 孪生配对且满足 SUTVA；**(A36)** Holm 校正在 `α`。则
```
P(错误接受 confirmed 创新) ≤ α + P(Alt 缺项) + P(孪生不可交换)
```
关键在于 **没有负见证就没有创新**：功率不足者一律留在 `underpowered`，账本拒绝把它升级。

## 4. 首个数据库实例：SCWD（Semantic-Contact Witness Dataset）

**目标声明 `ψ₁`**：第 55 轮 v31 的“语义可供性 κ + 边界裕度 `m_s` + 生存核 `K(Σ)`”在语义扰动 `ε_s` 下满足 `ρ_sem ≥ ρ_min`，且接触失败率显著低于纯几何基线。

**替代假设集 `Alt(ψ₁)`**（必须全部纳入 DPP）：
1. `null`：v31 相对纯几何无显著增益；
2. 几何基线：仅深度/平面，无语义；
3. 纯分割：有标签、无接触可供性 κ；
4. 有 κ 无边界裕度：去掉 `m_s` 保守膨胀。

**分层与见证角色**

| 层 | 内容 | 见证角色 |
|---|---|---|
| L0 常规场景 | 清晰语义、标准支撑面 | `W⁺` 正见证 |
| L1 材质过渡带 | 草地→水泥、瓷砖→地毯、湿滑地面 | `W∂` 边界 |
| L2 伪支撑陷阱 | 印刷地纹、玻璃桌沿、地毯覆盖空洞、镜面地板 | `W⁻` 伪阳性陷阱 |
| L3 语义边界对抗 | 遮挡边界、细杆扶手、透明/反光物 | `W∂` 边界 |
| L4 全身耦合压力 | 单脚支撑、抓取同时重心偏移 | `W⁺/W∂` |

**采集与标注**：RGB-D + 分割软标签 + 材质标签 + 力/IMU/接触真值（真值平台与仿真双轨）。

**构建协议（WSC 实例化）**：采样优先级 = 失败后验熵 + 边界邻近（`∂Ω` 与 `∂K(Σ)`）+ 材质过渡；各层配额固定，防止覆盖塌缩。孪生按 CFT 生成：同场景分别做“κ 抹平 / 关边界裕度 / 语义换几何”。

**质量门**：每层 `Cov ≥ θ_cov`；`Pow` 对最强基线（纯分割 + 几何）≥ `θ_pow`；`W⁻` 至少覆盖 4 类伪支撑陷阱。

**预期结论（允许否定自己）**：若 SCWD 显示 v31 相对纯分割的提升不显著，则把 v31 从 `confirmed` 降级为 `underpowered`。这正是本轮元方法的价值：**先杀死自己的旧创新，再谈新创新。**

## 6. 本轮最大风险

**一句话**：MineCert 把创新点挖掘与数据集构建绑成“断言-证伪”对偶，但其 soundness **三重依赖碰撞势的诚实估计、`Alt(ψ)` 的完备性、以及孪生的可交换性**；一旦替代假设集漏掉真正强的基线，数据功率就只会对稻草人达标，账本会把确认偏误盖上 `confirmed` 印章——因此必须用 **红队基线清单 + 预注册功率分析 + 配对孪生** 三重护栏，宁可承认旧创新 underpowered，也绝不让能骗过自己的数据集冒充证明。
