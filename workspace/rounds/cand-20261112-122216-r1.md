# 第 58 轮（承接第 57 轮「少样本元推断×跨模态对账×个性化有界信任」IP-133~138；灵感循环第 1 轮（双灵感）；本轮灵感：「语音交互」×「LoRA」）

> 第 57 轮把安全押在"少样本可校准、跨模态可对账、个性化有界的证据承诺"上，用元先验给效率、共形给保底；但它留下的三个隐忧正好被本轮两个灵感正面击中：**(a)** 个性化被做成一个人格状态机 s_o，仍是"全局单一策略 + 几个标量"，无法表达"同一操作者在不同场地、不同方言、不同疲劳阶段"的细粒度差异——个性化要么太粗，要么就得重训整个模型；**(b)** 所有"更聪明"的更新都假定走云端全量模型，边端既载不动，也无法逐条审计"到底是哪条证据改变了哪个决策"；**(c)** 语音只是解释渲染的一个候选模态（MXI 的 voice 摘要），被当成"输出通道"而非"输入-协商通道"，既浪费了摩擦最低的人类接口，也回避了语音独有的可伪造与橡皮章加速风险。本轮两个灵感互补：**LoRA** 把个性化/适配从重训降为**有界、可组合、可回滚的低秩证据增量**；**语音交互**把"人"从末端确认按钮变成**贯穿全程的保守单向阀**。核心命题由"个性化有界的证据承诺"升级为 **"适配可审计、语音只保守的证据承诺"**。

核心矛盾：
- **H29（低秩 ≠ 低风险）**：LoRA 的安全直觉是"参数少所以改得少"，但安全相关的量是**承诺边界上的行为差**，不是参数范数；一个 rank-1 适配器就足以在特定区域翻转决策边界，而它看起来"只动了万分之一的参数"。
- **H30（低摩擦 vs 可伪造）**：语音把确认成本压到接近零，橡皮章与疲劳被同步放大；同时语音可重放、可合成，**任何"用声音证明我是谁"的授权都会变成可复制凭证**——最快的通道恰恰是最不可信的通道。
- **H31（适配的证伪与归因）**：当每个区域/操作者/方言都挂着自己的适配器并持续更新，"谁对这个决策负责"变得弥散；第 57 轮的事后证伪回溯必须能**精确摘除**某条证据对应的参数增量，而适配器的合并与非交换性让精确回滚成为难题。

## 0. 直觉与动机

**灵感 1（LoRA → 适配不是重训，而是可回滚的"证据增量"）**
直觉：把"个性化"理解为一次全量微调，是把大象塞进边端；LoRA 指出，真正需要的改动往往只落在一个低维子空间——一类新材质的摩擦特性、一个操作者的方言口音、一片冰面的视觉偏置，都是相对基座模型的**小方向修正**。但更关键的不是省参数，而是**形状**：ΔW=BA 是一个能被签名、被版本化、被 diff、被整块摘除的**对象**。于是"信任/适配"从"悄悄改了黑箱里的权重"变成"账本上多了一笔可追溯的增量"：每条证据产生一个低秩分量，证据被证伪就按句柄精确回滚。适配不再是训练事件，而是**带证据句柄的账本事件**。

**灵感 2（语音交互 → 只降不升的保守单向阀）**
直觉：语音是人在紧张、戴手套、双手被占用时唯一还空着的通道，所以它首先应当是"停 / 慢 / 再说一遍"的通道——这类意图即使误检，后果也只是让系统更保守，代价可控。但同一通道又最容易说出"确认"，而语音可被重放、合成、模仿。于是把语音意图三分：保守类 𝒱⁻（只减动作集）、查询类 𝒱⁰（只读）、授权类 𝒱⁺（**语音永远无权**，必须换到身份绑定的物理/签名通道）。这不是限制语音，而是给语音一条**单调性保证**：无论识别错、被伪造、被噪声污染，语音能造成的后果只能落在"更安全"那一侧。低摩擦被保留在安全方向上，危险方向被移出该通道。

**灵感 3（合流 → 安全核冻结、适配只住外围）**
直觉：要同时拿到 LoRA 的效率与语音的单向性，架构上必须把系统劈成两层：**认证核（certification core）**——OOD 门、共形带、证据门硬规则、风险头、L2 授权裁决——永久冻结、独立版本、不可热更；**适配外设（adaptable periphery）**——候选提议排序、区域嵌入、VOI 估计、界面渲染与语音理解——只在这里挂 LoRA。外设只能**重排候选**，任何候选仍必须穿过冻结的认证核才能承诺。于是"低秩≠低风险"被结构性堵住：低秩可以改变"先试哪个"，不能改变"什么算够格"。个性化住在接口与提议里，永远不住在政策里。

**灵感 4（合流 → 从单点证书到"组合证书 + 回滚态"）**
直觉：单个适配器都过检，不代表它们的和过检；单个动作都保守，不代表组合后仍保守。因此证书必须从 J_p 升级为**组合证书 J_q**：不仅逐项验证，还要验证加性风险界、两两干扰、秩预算与"冻结核未被触碰"的哈希。并引入一个新的运行态——**待回滚态（pending-rollback）**：一旦证伪事件到达，系统在下一个检查点前拒绝新承诺，先摘除对应分量再继续。这样"坏证据长寿"被压到最多一次到访。

**灵感 5（PCE++ → 语音约束与影子适配进入同一个闭环）**
直觉：语音的保守意图不是"建议"而是**约束**（硬插入动作集收缩）；适配器更新不是"立即生效"而是**影子候选**（在探针流上跑、过行为差测试与组合证书才转正）。两者遵守同一条交互单调性：只经"动作更保守"或"信念更准（含加宽/延迟）"两个通道影响系统。于是探-诺-演闭环从"元 VOI + 共识探针"扩展为"元 VOI + 共识探针 + 语音约束 + 影子适配"。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（有界低秩适配器 BLA）** 冻结基座 W，模块集划分为**安全核 K_safe**（OOD 门、共形带、证据门、风险头、L2 裁决）与**外设 W_per**（提议排序、区域嵌入、VOI、渲染、语音理解）。适配只作用于 W_per：ΔW=(α/r)BA，rank(ΔW)≤r_max，核范数 ≤κ_p。可采纳性不是参数约束而是**行为契约**（版本化承诺边界校准集 𝒞_cal）：(a) **保拒性**：∀c∈𝒞_cal，若基座拒绝承诺或返回 OOD 带，则 W+ΔW 也必须拒绝；(b) **保守偏移界**：TV(π_{W+ΔW}(·|c),π_W(·|c))≤ε_beh；(c) **保守锥**：∇_W R̂(c)·vec(ΔW)≤0（R̂ 为风险的可证上界，由区间传播/Lipschitz 界给出）。支持集约束：supp(ΔW)∩K_safe=∅（A41）。

**定义 140（适配证据账本 AEL）** 每个增量是一个账本项 ℓ_i=(ΔW_i,e_i,v_i,handle_i,sig_i)：e_i 为产生它的证据集（probe/xmodal/verdict id），v_i 为定义 139 的行为证书，handle_i 为**可证伪句柄**（何种观测将使 ℓ_i 失效）。活动适配 ΔW_Σ=Σ_i ΔW_i，各分量按 Gram 矩阵正交化；**正交债** ρ_orth=1−‖Σ_i P_i‖/‖Σ_i‖（P_i 为分量投影），ρ_orth>θ_orth 触发**重基**（对全部已认证分量重新做低秩分解，重基本身过审计）。证伪事件按 e_i 定位分量并**精确摘除**；正交化保证摘除不改动其他分量，残差 ≤ε_orth。

**定义 141（语音保守门 VCG）** 意图三分：𝒱⁻={STOP,SLOW,RECHECK,UNSURE,MORE_EXPLAIN}，𝒱⁰={ASK_WHY,ASK_STATE}，𝒱⁺={APPROVE_CONTACT,RAISE_AUTH,WAIVE_CORROB}。语音管线 u_voice=(ASR∘intent) 带错误矩阵 E_v；对 𝒱⁻ 用**高召回非对称阈值**（漏检代价 ≫ 误检代价），对 𝒱⁺ **恒拒**并要求身份绑定通道（物理按键 + 挑战-应答 + 承诺回读 + 速率限制）。抢话（barge-in）用与 ASR 解耦的副语言能量触发，τ_voice<τ_int，停机生效 ≤τ_stop；**硬件急停始终并联**（语音不是唯一停机通道）。伪造检测只作用于**身份声明**，不作用于保守意图——被伪造的"停"只会让我们更安全。

**定义 142（接口-政策分离 IPS）** 决策 D=Core(σ(x))，σ 为语义归一化内容；个性化适配器（说话人/方言/术语/渲染）只能挂在 audio→σ 与 Exp→render 两条**接口映射**上，其输出不得进入 Core 的输入表征，只能以"已归一化语义内容 + 接口误差模型"进入。安全相关感知（vig、OOD、证据核验、风险头）**冻结不可适配**（A44）。因此个性化只能改变"怎么听懂、怎么解释"，不能改变"怎么裁决"。

**定义 143（组合认证证书 CCC / J_q）** 给定活动适配集 {ΔW_i} 与冻结核哈希 h(K_safe)：组合可采纳 ⇔ (i) 每项 ∈𝒦 且加性证书 Σ_i ΔR̂_i≤0；(ii) 校准集上两两干扰 |I_ij(c)|≤ε_int；(iii) Σrank≤R_max 且核范数总额≤κ_Σ；(iv) h(K_safe) 与基线一致；(v) 每项都有 handle_i。若不满足则**不组合**，退回"基座 + 第 57 轮共形带"安全降级。J_q=(J_p,h(K_safe),{ℓ_i},ΔW_Σ,Cert_comp,ρ_orth,fallback_state,voice_state,rollback_state)。

**定义 144（语音-适配闭环 PCE++）** 在 PCX 每检查点：①元推断（ID 摊销 / OOD 共形，均走冻结核）；②对账 + 共识探针（继承第 57 轮）；③**语音约束**：若收到 𝒱⁻ 立即收缩动作集，并在 τ_stop 内执行安全动作；④**影子适配**：候选 ΔW 在探针流影子运行，过行为差测试与 J_q 才转正；若处于 pending-rollback，先摘除再承诺；⑤承诺门仍由冻结的 FSE 判定；⑥探尽→绕行→降档→L2 协商（语音只能触发 L2，不能批准 L2）。

## 2. 关键算法伪代码（完整版见产物区）

```python
def adapter_admissible(W, dW, cal, core_hash):         # IP-139/143
    if hash_modules(core_support(dW)) != core_hash:
        return False, 'touches_safety_core'
    if dW.rank > r_max or nuclear(dW) > kappa_p:
        return False, 'param_budget'
    for c in cal:
        if base_rejects(W, c) and not base_rejects(W + dW, c):
            return False, 'widens_commit'              # 保拒性
        if tv(pi(W + dW, c), pi(W, c)) > eps_beh(c):
            return False, 'behavioral_drift'
    return (gradR_upper(W, cal) @ vec(dW) <= 0), 'conservative_cone'

def voice_gate(u):                                     # IP-141: 单向下行
    intent, conf = asr_intent(u)
    if intent in V_MINUS:                              # 高召回：低置信也接受
        return 'constrain', shrink_actions(intent)     # 只能更保守
    if intent in V_ZERO:
        return 'answer', intent
    if intent in V_PLUS:                               # 语音永远无权
        return 'reject', 'voice_cannot_authorize'
    return 'ignore', None

def commit_with_ledger(cp, M, ledger, persona):        # IP-140/144
    if ledger.rollback_state == 'pending':             # 先摘除再承诺
        ledger.apply_rollback(); return ('defer', 'rollback_pending')
    if voice_gate.pending_constraint():                # 语音约束优先
        return ('defer', execute_conservative(voice_gate.constraint))
    if not few_shot_evidence_gate(cp, M, persona):     # 冻结核（第57轮）
        return ('reject', 'evidence_insufficient')
    return ('ok', commit(cp, compose(ledger.active, W_base)))
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| BLA | 前向 O(d_out·r)；验证 O(\|𝒞_cal\|·d) | O((d_out+d_in)·r) | 保拒性 + 保守锥 + 支持集不碰安全核 |
| AEL | 摘除 O(r·d)；重基 O(Σr·d) 摊销 | O(Σ(d·r)) | 正交化保证精确回滚、句柄完备 |
| VCG | O(1)/语句；抢话 O(1) | O(1) | 𝒱⁺ 语音恒拒、τ_stop、硬件急停并联 |
| IPS | O(1) 路由 | O(\|适配器\|) | 语义内容与政策输入隔离 |
| CCC | O(\|𝒞_cal\|·\|{ΔW}\|²) 离线 | O(\|{ΔW}\|²) | 加性界 + 干扰项 + 秩预算 |
| PCE++ | O(\|CP\|·(k_p+k_c)·(C_VOI+d_φ)+离线影子) | O(\|V\|+\|σ\|) | 语音约束优先、影子不占回路 |

**正确性定理（Voice-and-LoRA Certified Assurance & Soundness, VCAS 概要）** 在 A22–A40 之上加：(A41) **冻结核**：安全核模块在任何适配下哈希不变、不可热更；(A42) **适配可采纳性与组合证书**：每项满足行为契约，组合满足加性风险界、两两干扰 ≤ε_int 与秩/核范数预算，R̂ 在基座点满足 L-Lipschitz 平滑；(A43) **语音单向阀**：𝒱⁺ 经语音接受率为 0，保守意图高召回，τ_stop 内生效，硬件急停并联；(A44) **接口-政策分离**：政策只消费归一化语义内容，安全相关感知不可适配；(A45) **账本完备性**：每项有句柄且可精确摘除，pending-rollback 期间零新承诺。则：
(i) **安全下界不变**：适配只作用于外设候选排序，所有承诺仍过冻结核，故 ID 路径失效率 ≤ 第 57 轮界 + ε_int + ε_if；J_q 不成立时退回第 57 轮 OOD 界（安全降级而非冒险组合）；
(ii) **语音单调性**：加入 VCG 不增加 P_fail；任意对抗语音（重放/合成/噪声）只能触发 𝒱⁻/𝒱⁰ 或被拒识，𝒱⁺ 经语音接受率恒为 0；语音的唯一残余风险是"该停没停"（漏检 δ_vm），由硬件急停兜底；
(iii) **组合健全性**：若各 ΔW_i∈𝒦 且加性界成立，则 ΣΔW_i∈𝒦（锥的凸性 + 线性）；计入 Lipschitz 干扰项后 P_fail ≤ 基座界 + ΣΔR̂_i + L·‖ΔW_Σ‖² + ε_int；超预算即拒绝组合并降级；
(iv) **回滚有界暴露**：证伪到摘除的暴露窗 ≤ 1 检查点，pending-rollback 期间零新承诺；正交债越阈时重基，而非带病继续；
(v) **终止/时延**：影子适配离线摊销、不占控制回路，语音约束在 τ_stop 内生效，闭环仍在 k_probes+k_cons 内终止于 {承诺, 绕行, L2 协商, 安全停}。

## 6. 本轮最大风险

**一句话**：本轮把"个性化"从一个人格状态机下放为一批可组合的低秩适配器——最大风险从"坏先验普遍"变成"**参数有界而行为无界**"：每个 rank-r 适配器都通过了单体验证，却可能在组合、影子转正与语音加速确认下共同越过承诺边界，且事后难以把责任精确归到某条证据；必须靠冻结安全核、组合证书 J_q、证据句柄精确回滚与语音单向阀四重结构，保证任何"变聪明"只能发生在安全核之外、任何"变快"只能发生在保守方向。

## 2. 关键算法伪代码

### IP-139 BLA（有界低秩适配器，行为契约）

```python
def core_support(dW):
    return touched_modules(dW)                     # ΔW 支持集所在模块

def adapter_admissible(W, dW, cal, core_hash):
    if hash_modules(core_support(dW)) != core_hash:
        return False, 'touches_safety_core'        # A41 硬约束
    if dW.rank > r_max or nuclear(dW) > kappa_p:
        return False, 'param_budget'
    for c in cal:                                  # 行为契约，而非范数
        if base_rejects(W, c) and not base_rejects(W + dW, c):
            return False, 'widens_commit'          # (a) 保拒性
        if tv(pi(W + dW, c), pi(W, c)) > eps_beh(c):
            return False, 'behavioral_drift'       # (b) 保守偏移界
    if gradR_upper(W, cal) @ vec(dW) > 0:
        return False, 'escapes_conservative_cone'  # (c) 保守锥
    return True, 'admissible'
```

### IP-140 AEL（适配证据账本，精确回滚）

```python
def ledger_add(ledger, dW, evidence, cert):
    item = LedgerItem(dW=dW, e=evidence, v=cert,
                      handle=bind_falsifier(evidence),
                      sig=sign(dW, evidence))
    ledger.items.append(orthogonalize(item, ledger.gram))
    ledger.gram = update_gram(ledger.gram, item)
    ledger.rho_orth = orthogonality_debt(ledger)
    if ledger.rho_orth > theta_orth:
        ledger.rebase()                            # 重基并重认证
    return ledger

def ledger_falsify(ledger, bad_evidence):
    hits = [it for it in ledger.items if it.handle.matches(bad_evidence)]
    for it in hits:
        ledger.items.remove(it)                    # 正交化 ⇒ 精确摘除
    ledger.rollback_state = 'pending' if hits else 'idle'
    return ledger, hits
```

```python
def voice_gate(u, persona):
    intent, conf = asr_intent(u, adapter=persona.speaker_lora)  # 接口适配
```

### IP-143 CCC（组合认证证书 J_q）

```python
def composition_cert(ledger, W_base, cal, core_hash):
    if hash_modules(safety_core(W_base)) != core_hash:
        return False, 'core_hash_changed'
    if sum(it.dW.rank for it in ledger.items) > R_max:
        return False, 'rank_budget'
    if sum(nuclear(it.dW) for it in ledger.items) > kappa_sum:
        return False, 'nuclear_budget'
    if any(not it.handle for it in ledger.items):
        return False, 'missing_falsifier'
    if sum(it.cert.dR for it in ledger.items) > 0:
        return False, 'additive_bound_violated'
    for c in cal:                                      # 两两干扰
        for a, b in pairs(ledger.items):
            if abs(interference(a.dW, b.dW, c)) > eps_int:
                return False, 'interference'
    return True, 'certified'                           # 否则 fallback
```

### IP-144 PCE++（语音-适配闭环）

```python
def probe_commit_evolve_plus(x0, M, task, budget, consent, personas, ledger):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        inf = meta_few_shot_infer(M, cp.region, M.obs[cp.region], meta)   # 冻结核
        M.b[cp.region] = inf.post if inf.cls == 'ID' else worst_in(inf.belt)
        sigma = foothold_schedule(x0, cp, M); R = schedule_risk(sigma, M)
        while select_gait(R) == 'halt' and budget.probes_left > 0:
            if (vc := voice_gate.pending()):           # ③ 语音约束优先
                return safe_action(vc, tau_stop)
            cands = admissible_probes(cp, M, F_abs)
            if not cands: break
            p = argmax(cands, key=lambda q: voi_meta_pessimistic(q, M, inf) - cost(q))
            if voi_meta_pessimistic(p, M, inf) < theta_voi: break
            M, _, D = xmodal_fuse(M, cp.region, execute_probe(p, cap=F_abs))
            if D > theta_D and 'consensus' not in cp.done:

                cp.done.add('consensus')
            sigma = reselect_footholds(x0, cp, M); R = schedule_risk(sigma, M)

        if ledger.rollback_state == 'pending':         # ④ 先摘除再承诺

                                                  personas, ledger)[0] == 'ok':
            sched.append(commit(sigma, g)); log.append(tag_evidence_p(sigma, M, lv)); continue

        if alt and select_gait(schedule_risk(alt, M)) != 'halt': route = alt; continue

                                 tau_int=tau_int(personas.active.auth))
    return sched, log, M

def shadow_promote(dW, evidence, ledger, M):
    for probe in shadow_stream(M):                     # 影子模式，不占承诺路径
        dW.eval(probe)
    ok, why = adapter_admissible(W_base, sum_dW(ledger) + dW, CAL, CORE_HASH)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| BLA | 前向 O(d_out·r)；验证 O(\|𝒞_cal\|·d) | O((d_out+d_in)·r) | 保拒性 + 保守锥 + 不碰安全核（A41/A42） |
| AEL | 摘除 O(r·d)；重基 O(Σr·d) 摊销 | O(Σ d·r) | 正交化精确回滚、句柄完备（A45） |
| VCG | O(1)/语句；抢话 O(1) | O(1) | 𝒱⁺ 语音恒拒、τ_stop、急停并联（A43） |
| IPS | O(1) 路由 | O(\|适配器\|) | 政策只消费归一化语义（A44） |
| CCC | O(\|𝒞_cal\|·\|{ΔW}\|²) 离线 | O(\|{ΔW}\|²) | 加性界 + 干扰 + 秩预算（A42） |
| PCE++ | O(\|CP\|·(k_p+k_c)·(C_VOI+d_φ)+离线影子) | O(\|V\|+\|σ\|) | 语音约束优先、影子离线、四态完备 |

**正确性定理（Voice-and-LoRA Certified Assurance & Soundness, VCAS）**
假设 A22–A32（53–55 轮）、A33–A36（56 轮）、A37–A40（57 轮）成立；且 **(A41)** 安全核冻结：OOD 门/共形带/证据门/风险头/L2 裁决模块在任何适配下哈希不变且不可热更；**(A42)** 适配可采纳性与组合证书：每项满足定义 139 行为契约，组合满足加性风险界 ΣΔR̂_i≤0、两两干扰 ≤ε_int 与秩/核范数预算，风险上界 R̂ 在基座点 L-Lipschitz；**(A43)** 语音单向阀：𝒱⁺ 经语音接受率恒 0，保守意图高召回，停机 ≤τ_stop，硬件急停并联；**(A44)** 接口-政策分离：政策只消费归一化语义内容，安全相关感知不可适配；**(A45)** 账本完备性：每项有可证伪句柄且可精确摘除，pending-rollback 期间零新承诺。则：

1. **安全下界不变**：适配只改变外设候选排序，全部承诺仍穿过冻结核，故 ID 路径 P(fail) ≤ δ_f + ε_meta(k) + δ_probe + ε_h + ε_int + ε_if；J_q 不成立时退回基座 + 第 57 轮共形带，界不劣于第 57 轮 OOD 路径。
2. **语音单调性**：系统加入 VCG 后 P(fail) 不增；任意对抗语音（重放/合成/环境噪声）只能触发 𝒱⁻/𝒱⁰ 或被拒识；𝒱⁺ 的语音接受率为 0；语音残余风险仅为"该停没停"的漏检 δ_vm，由硬件急停兜底，不与语音识别质量耦合。
3. **组合健全性**：若各 ΔW_i∈𝒦 且加性界成立，则 ΣΔW_i∈𝒦（锥凸性 + 线性）；计入平滑干扰项后 P(fail) ≤ 基座界 + ΣΔR̂_i + L·‖ΔW_Σ‖² + ε_int；超预算即拒绝组合并降级，不存在"逐项安全、组合越界"的升险路径。
4. **回滚有界暴露**：证伪到摘除的暴露窗 ≤ 1 检查点；pending-rollback 期间承诺数为 0；正交债超阈触发重基而非带病运行，重基后组合证书重新校验。
5. **终止/时延**：影子适配在离线探针流摊销，不进入控制回路；语音约束在 τ_stop 内生效；闭环仍在 k_probes+k_cons 内终止于 {承诺, 绕行, L2 协商, 安全停}。
6. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1])
             − ε_int − ε_if − δ_vm − P(重基失败) − P(核哈希校验失败)
```

关键：**低秩给效率、冻结核给底**（行为契约与安全核隔离，使"参数有界"升级为"行为有界"）；**语音给速度、单向阀给界**（最快的通道只通向更保守的动作集）；**组合给能力、证书给终止**（逐项安全 ≠ 组合安全，J_q 把干扰与预算显式化）；**账本给可归因**（每条证据有句柄，精确回滚把坏证据暴露压到一次到访）。

## 6. 本轮最大风险

**一句话**：本轮把"个性化"从一个人格状态机下放为一批可组合的低秩适配器——最大风险从"坏先验普遍"变为"**参数有界而行为无界**"：每个 rank-r 适配器都通过了单体验证，却可能在组合、影子转正与语音加速确认下共同越过承诺边界，且事后难以把责任精确归到某条证据；必须靠冻结安全核、组合证书 J_q、证据句柄精确回滚与语音单向阀四重结构，保证任何"变聪明"只能发生在安全核之外、任何"变快"只能发生在保守方向。
