# 第 43 轮（新循环第 3 轮） · 从「单任务证书飞轮」到「多任务可迁移证书」：共享安全表征 × 分布鲁棒迁移界 × 防负迁移机制（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR）。第 42 轮自陈最大风险是「仿真偏差累积 + 检索幻觉」——两者本质是同一个病：**用单任务的点估计去外推一个多任务、跨域的安全声明**。本轮灵感词「仿真到现实迁移」「多任务学习」正好补上两块缺失的理论地基。「仿真到现实迁移」要求把 v19 的 α_e 从「单点 W_1 乘 Lipschitz 再乘阈值」升级为**分布鲁棒的有限样本迁移证书**（Wasserstein DRO + conformal 校准），并修正 v19 中「状态级 Lipschitz × 轨迹级 W_1」的量纲错配；「多任务学习」要求把 v19「一次一个任务、证书靠检索拼接模板」升级为**共享安全表征 + 任务头**的多任务证书，让 N 个任务共享一个安全骨干，从而同时降低样本复杂度、边缘内存与冷启动成本——但必须用群组鲁棒与梯度冲突检测挡住**负迁移**这条新失效链。

## 0. 直觉与动机

**灵感 1（仿真到现实迁移 → 从「点估计修正」到「带置信度的迁移证书」）**：v19 的直觉是「实机边际 ≈ 仿真边际 − L_m·W_1」，再给阈值乘一个 α_e。这在小扰动下好用，但它把三件不同的事压成了一个标量：(a) 仿真与实机**支撑集**的差异（协变量偏移）；(b) 动力学参数差异导致的**转移核**差异；(c) 有限标定样本的**统计误差**。直觉上，安全的迁移声明不该问「W_1 是多少」，而该问「在一个多大的分布球内我的证书仍成立，以及这个球有多大概率覆盖真实分布」。于是本轮把 α_e 换成两层：**外层**用 Wasserstein DRO 给出球半径 ρ 内最坏分布的证书，**内层**用实机少量标定样本做 conformal 校准，给出有限样本、分布无关的覆盖保证。迁移不再是魔法系数，而是 (ρ, δ) 两个可审计、可标定的量。这也直接回应第 41 轮的「可用性崩塌」：δ 是显式的可用性—保守性旋钮。

**灵感 2（多任务学习 → 共享安全表征，一次学「怎么不安全」，而不是学 N 次「这个任务怎么安全」）**：v19 每个任务独立合成证书，任务间共性（同一机器人本体、同一类接触动力学、同一套传感器）只能靠 RAG 检索「相似模板」间接复用，粒度粗且不可微。多任务学习的直觉是：**安全是有共享结构的**——同一个机械臂在不同抓取任务里，关节限位、奇异位形、接触力约束的形式高度相似，只是权重不同。于是提出**共享安全表征 Φ(s)** + 每任务低秩头 w_i，证书边际 h_i(s) = Φ(s)·w_i。共享 Φ 等价于把 N 个任务的仿真数据「合并训练」，样本效率按任务数摊薄；边缘端只存一个共享 INT8 编码器 + N 个小头，内存几乎不随任务数线性增长。代价是**负迁移**：共享特征可能学到「仿真里对任务 A 安全、对任务 B 致命」的捷径，因此需要梯度冲突检测 + 群组 DRO。

**灵感 3（把两者接起来：多任务撑大仿真的有效覆盖，却也放大任务级分布外风险）**：多任务带来更多样的仿真数据，等价于把 D_sim 的支撑集撑大，理论上能让迁移球半径 ρ 更小；但任务越多，共享表征越容易在某个任务方向被「平均掉」，形成**任务级分布外（task-OOD）**。所以本轮的耦合不是简单叠加，而是**用多任务覆盖降低 ρ，用任务群组 DRO 与负迁移检测约束共享**：迁移界负责「域」的不确定性，多任务负责「任务」的不确定性，二者在同一套证书里联合优化。这是对第 42 轮「仿真偏差 + 检索幻觉」两条失效链的结构性回应——不再靠更好看的检索，而是靠可证明的覆盖与可检测的冲突。

## 1. 形式化定义（增量：定义 38–44）

**定义 38（任务族与多任务证书）**：任务族 T = {τ_1,…,τ_N}，每个 τ_i = (目标 g_i, 约束 c_i, 任务分布 P_i(s))。多任务证书 Π = (Φ, {w_i}, {θ_i})，其中共享安全表征 Φ: S → R^d 为 L_Φ-Lipschitz，任务头 w_i ∈ R^d，证书函数 h_i(s) = Φ(s)·w_i。多任务有效域 C_mt = {s : h_i(s) ≥ θ_i, ∀ i ∈ A(s)}，A(s) 为当前活跃任务集。N=1 时严格退化为 v19 的单任务证书，保证向后兼容。

**定义 39（迁移差距的正确分解）**：把 v19 的标量 W_1 拆成三项 Δ_transfer = Δ_domain + Δ_task + Δ_est，其中 Δ_domain = W_1(D_real, D_sim)（环境/协变量偏移），Δ_task = E_{i,j} d(P_i, P_j)（任务分布差异），Δ_est 为标定样本有限性带来的估计误差。**关键修正**：v19 的 m_real ≥ m_sim − L_m·W_1 混淆了「状态空间 Lipschitz」与「轨迹分布 W_1」。对任意 h_i，若 h_i 关于 s 为 L_i-Lipschitz，正确的一阶形式是
|E_{P_real}[h_i] − E_{P_sim}[h_i]| ≤ L_i · W_1(D_real, D_sim) + Lip(∇h_i)·O(W_1²)，
它只界住**期望**而非逐点下界。要得到逐点安全下界，必须叠加 DRO（定义 40）或 conformal（定义 41），这是 v19 的 soundness 缺口。

**定义 40（分布鲁棒迁移证书 DRTC）**：给定仿真分布 D_sim 与半径 ρ，在最坏分布球 B_ρ(D_sim) = {Q : W_1(Q, D_sim) ≤ ρ} 上定义
m_rob(s) = inf_{Q∈B_ρ(D_sim)} E_Q[φ_s(h(s))]，
其中 φ_s 为逐点边际的凸表示。由 Wasserstein DRO 对偶，m_rob 可写成「经验均值 − λ·ρ − λ·Lipschitz 项」的惩罚形式，λ 为对偶变量，且当 h 关于环境参数 Lipschitz 时是**可求解的凸问题**。**命题（soundness）**：若 D_real ∈ B_ρ(D_sim)，则 m_real(s) ≥ m_rob(s)。因此 ρ 的正确性比估计精度更关键——ρ 欠估是本轮最危险的失效。

**定义 41（Conformal 迁移校准与有限样本保证）**：取实机标定样本 {(s_k, m_k)}_{k=1..n}，定义非一致性分数 r_k = m_rob(s_k) − m_k，取 (1−δ) 分位数 q̂ = Quantile_{⌈(n+1)(1−δ)⌉/n}({r_k})。则在可交换性下，对新实机状态 s，
P(m(s) ≥ m_rob(s) − q̂) ≥ 1 − δ（分布无关，仅需可交换）。
这把 v19 的 α_e 替换为**可计算、可审计的 q̂**，并显式暴露 δ 的代价：δ 越小 q̂ 越大、证书越保守。注意：机器人长时运行非平稳，可交换性会被破坏，需用自适应 conformal（定义 42 的漂移触发）兜底。

**定义 42（共享表征的负迁移界）**：设任务 i、j 共享 Φ。任务 i 的边际相对其独立训练版本 h_i^⋆ 的退化满足
h_i(s) − h_i^⋆(s) ≤ L_Φ·||w_i − w_i^⋆|| + ε_share·||∇Φ||，
其中 ε_share 为共享特征在两任务数据支撑集交汇处的冲突上界，可用共享参数上任务梯度的最小余弦相似度估计。**负迁移判据**：若平均梯度余弦 cos(g_i, g_j) < −κ，或退化界超过任务容差 η_i，则触发「部分共享」（层共享/软共享/低秩隔离）或该任务退化为单任务。

**定义 43（多任务证书的群组鲁棒优化）**：训练目标
min_{Φ,{w_i}} Σ_i λ_i·[L_task_i + β·L_cert_i] + γ·max_i risk_i，
其中 risk_i 为任务 i 在 Wasserstein 球内的最坏证书违例，λ_i 由 Group-DRO 动态上调（最差任务权重增大）。该目标保证「不被简单任务主导」，是从优化层抑制负迁移的手段，与定义 42 的检测层互为双保险。

**定义 44（证书任务算术与组合 soundness）**：任务头可做凸组合 w_comb = Σ α_i w_i（α_i ≥ 0, Σα_i = 1），得组合证书 h_comb = Φ·w_comb。若各任务活跃域 A_i 在接口契约下相容，且 θ_comb = Σα_i θ_i，则由凸性 h_comb(s) ≥ θ_comb 当且仅当各分量约束满足。这为 IP-47 乘积自动机提供**可微的任务组合**，而不只是模板字符串拼接。

## 2. 四大产出设计（增量 IP-57/58/59 + 升级 IP-54/55/56/51/52/49/50/47）

### 2.1 IP-57 TRANS-CERT（TC，分布鲁棒 + Conformal 迁移证书器）
1. **三项差距分解**：分别估 Δ_domain（环境/传感器特征 W_1）、Δ_task（任务分布离散度）、Δ_est（bootstrap 估计误差），合并为保守球半径 ρ = ρ_dom + ρ_task + ρ_est。
2. **DRO 对偶求解**：在仿真训练好的多任务证书上，求 B_ρ 内最坏期望，输出对偶变量 λ 与 m_rob(s) 的解析/半解析形式，避免逐点重解。
3. **Conformal 校准**：少量实机标定样本（n≈200）计算 q̂，输出证书四元组 (m_rob, q̂, ρ, δ)；α_e 仅作为 q̂/θ 的等价实现保留，不再独立拍脑袋。
4. **非平稳兜底**：滑窗 conformal + 漂移触发重校准（接 IP-56 偏移监控），当经验覆盖跌破 1−δ 时扩大 ρ 或降级档位。

### 2.2 IP-58 MULTI-CERT（MC，共享安全表征 + 多任务证书头）
1. **强先验共享 Φ**：以「本体运动学 + 接触图」的 SE(3)/图等变编码为骨干，先验越强、负迁移越小；只在语义层留可学习自由度。
2. **低秩任务头**：w_i = w_0 + U v_i（U∈R^{d×r}, r≪d），进一步降低样本需求与边缘内存，并使任务算术（定义 44）在低秩子空间内良定义。
3. **负迁移守卫**：梯度余弦监控 + 退化界（定义 42）+ Group-DRO（定义 43）三层防护；触发即部分共享或单任务回退。
4. **多任务课程**：任务按「梯度冲突小、证书覆盖增量大」排序进入训练，等价于把 v19 的课程引擎从「任务内相位」扩展到「任务间编排」。

### 2.3 IP-59 EDGE-SHARED-BACKBONE（ESB，多任务边缘运行时）
1. **一骨干多头**：一个共享 INT8 编码器 + N 个 8-bit 低秩头；内存 = 1×encoder + N×head，而 v19 的 N 个独立模型为 N×(encoder+head)，N=8 时约省 5–7 倍。
2. **活跃任务路由**：由 CAR 上下文给出 A(s)，只算活跃头；共享编码一次、按需解头，WCET 随任务数近常数。
3. **与 L0 查表融合**：查表键增 task_id，表值 = 共享 m_lo 基底 + 任务残差，进一步把多任务推理压到查表级。
4. **单点故障隔离**：共享编码器损坏时，回退到 v19 的单任务 L0/L1 表（版本化保留），保证降级路径仍在。

## 5. 本轮最大风险

**一句话**：最大风险是「多任务把安全压成平均」——共享表征在任务交汇处学到仿真成立、实机不成立的捷径（负迁移 + 任务级 OOD），同时 conformal 的可交换性假设被非平稳长跑破坏，使迁移证书在名义 δ 之外**静默失效**；因此 E90（负迁移检测）与 E87（conformal 覆盖）必须作为红线，任一不达标即关闭共享、切回 v19 单任务可迁移证书。

## 1. 符号体系（增量：定义 38–44）

| B_ρ(D_sim) | Wasserstein 球 | {Q: W_1(Q,D_sim) ≤ ρ}；ρ=ρ_dom+ρ_task+ρ_est |
| m_rob(s) | 鲁棒证书边际 | inf_{Q∈B_ρ} E_Q[φ_s(h(s))]，DRO 对偶可解 |
| q̂ | Conformal 校准量 | (1−δ) 分位非一致性分数；实机下界 = m_rob − q̂ |
| ε_share | 共享冲突上界 | 任务梯度最小余弦估计，进入负迁移界 |
| w_i = w_0 + U v_i | 低秩任务头 | U∈R^{d×r}，r≪d；支持任务算术 |
| C_mt = {s: h_i(s)≥θ_i, ∀i∈A(s)} | 多任务有效域 | 逐活跃任务约束的交 |

## 2. 关键算法（伪代码）

### IP-57 TC：分布鲁棒 + Conformal 迁移证书
```
def fit_transfer_certificate(Pi_sim, D_sim, calib_real, delta=0.05):
    # 1) 三项差距分解（保守相加）
    rho_dom  = estimate_w1(calib_real.env_feats, D_sim.env_feats)
    rho_task = estimate_task_dispersion(Pi_sim.tasks)   # 任务分布离散度
    rho_est  = bootstrap_error(calib_real, n_boot=200)
    rho = max(rho_dom, 1e-9) + rho_task + rho_est

    # 2) Wasserstein DRO 对偶：最坏期望 = 均值 - 对偶惩罚
    lam = solve_dro_dual(Pi_sim, rho)      # 凸问题，输出对偶变量
    m_rob = lambda s: dro_value(Pi_sim, s, lam, rho)

    # 3) Conformal 校准（可交换性下分布无关）
    scores = [m_rob(s) - m for (s, m) in calib_real]
    q_hat = conformal_quantile(scores, delta)

    return TransferCert(m_rob=m_rob, q_hat=q_hat, rho=rho, delta=delta,
                        tasks=[t.id for t in Pi_sim.tasks])

def conformal_quantile(scores, delta):
    n = len(scores)
    k = math.ceil((n + 1) * (1 - delta))
    if k > n:                      # 样本不足以支撑该 delta
        return float('inf')        # 保守：拒绝颁发迁移证书
    return sorted(scores)[k - 1]

def transfer_margin_for_task(cert, s, task_id):
    # 多任务：共享 m_rob + 任务残差（IP-59 表值也复用此式）
    base = cert.m_rob(s)
    return base - cert.q_hat - cert.task_residual[task_id](s)

def online_recalibrate(cert, window, delta_ewma=0.05):
    # 非平稳兜底：滑窗 conformal，覆盖跌破 1-delta 则扩 rho 重解
    cover = empirical_coverage(window, cert)
    if cover < 1 - delta_ewma:
        cert.rho *= 1.5
        cert.lam = solve_dro_dual(cert.Pi_sim, cert.rho)
        cert.q_hat = conformal_quantile(window.scores, delta_ewma)
    return cert
```

### IP-58 MC：共享安全表征 + 多任务证书 + 防负迁移
```
def train_multitask_certificate(tasks, D_sim, r=4, max_steps=100k, kappa=0.3):
    Phi   = EquivariantEncoder(dim=d)      # SE(3)/接触图等变骨干，强先验
    w0    = init_shared_head()
    U     = randn(d, r); v = {i: zeros(r) for i in tasks}
    lam   = {i: 1.0/len(tasks) for i in tasks}   # Group-DRO 权重

    for step in range(max_steps):
        grads = {}
        for i in tasks:
            w_i = w0 + U @ v[i]
            g_i = grad(L_task_i + beta * L_cert_i, [Phi, w0, U, v[i]])
            grads[i] = g_i

        # 负迁移检测：共享参数 Phi 上的成对梯度余弦
        cos_mat = pairwise_cosine(grads, key='Phi')
        if min_offdiag(cos_mat) < -kappa:
            Phi = partial_share(Phi, tasks)      # 层共享/软共享/低秩隔离
            log_negative_transfer(tasks, cos_mat)

        # Group-DRO：抬高最差任务权重
        risk = {i: eval_risk_in_ball(i, Phi, w0, U, v, D_sim) for i in tasks}
        lam = group_dro_update(lam, risk, eta=0.05)

        update([Phi, w0, U, v], grads, weights=lam, lr=3e-4)

    return MultiCert(Phi=Phi, w0=w0, U=U, v=v, thetas=calibrate_thetas(...))

def negative_transfer_bound(i, j, Phi, w_i, w_j, L_Phi, eps_share):
    # 定义 42：h_i - h_i* <= L_Phi||w_i-w_i*|| + eps_share||grad Phi||
    return L_Phi * norm(w_i - w_j) + eps_share * grad_norm(Phi)

def task_arithmetic(cert, alpha):
    # 定义 44：凸组合任务头，低秩子空间内良定义
    w_comb = cert.w0 + cert.U @ sum(a * cert.v[i] for i, a in alpha.items())
    return Certificate(head=w_comb,
                       theta=sum(a * cert.thetas[i] for i, a in alpha.items()))
```

## 6. 本轮最大风险

**一句话**：最大风险是「多任务把安全压成平均」——共享表征在任务交汇处学到仿真成立、实机不成立的捷径（负迁移 + 任务级 OOD），同时 conformal 的可交换性假设被非平稳长跑破坏，使迁移证书在名义 δ 之外**静默失效**；因此 E90（负迁移检测）与 E87（conformal 覆盖）必须作为红线，任一不达标即关闭共享、切回 v19 单任务可迁移证书。
