# 第 1 轮 · 灵感「对比实验」×「全身控制」

> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v23 + IP-431–439（HDL / ACSC / DCSC / HPC-E / CFC+++ / CESC / FSVC / IPAM / HPC-E+）。其上承 v22 分层 PGEV（P37/P41/P42）、v21 语义-规范层（SDC/CAC/DCL/GIC）、v20 联邦感知证书（PCA/CTS/CFC/HPC/CFCtrl）、v19 证书体系（DCM/OGCC/CCV/DRS/OGC）与 v17 感知链（CLP/S2C/HCG/PSV/APS/AMC）。全部保留，不推倒。
> 本轮纪律：**证书不是"逐部件的拼贴"，而是"整身耦合 + 因果可归因"的实验主张**。本轮只做一件事：给 v23 的证书塔装上两样它从未有过的东西——**整身（whole-body）耦合证书**（修正"部件证书合成谬误"）与**反事实对照实验**（把"每层都有贡献"从信念变成带置信区间的因果测量，并用交互效应把"相关失效"变成可检验的量）。

## 0. 直觉与动机

**灵感 1（全身控制 → 从"逐部件安全"到"整身耦合安全"）**
直觉：v23 的证书是"分件开票"的——底座有几何证书，机械臂有配空间证书 ACSC，感知有 SDC/CAC。但一台移动操作臂在物理上是一个**运动学/动力学耦合的单一体**：手臂伸出去会改变整机的有效包络与转动惯量，底座一动又会改变臂可达集。两个各自"安全"的部件证书，拼在一起未必安全——这是**合成谬误 (composition fallacy)**。而且两个方向的错误是对称而危险的：耦合**收缩**（臂伸展 → 整机扫掠包络变大 → 真实安全集比部件交集更小）时，部件交集是**乐观的、不安全的**；耦合**扩张**（底座重定位让臂够到原本够不到的安全区）时，部件交集是**悲观的、损失活性的**。全身控制（WBC）的 task-priority QP 恰好给了统一语言：把**安全与稳定性写成零优先级硬约束**（只允许对任务松弛，永不对安全松弛），把义务/能量写成带监控松弛的低优先级项。核心创新：**整身证书 (Whole-Body Certificate, WBC)**——以 Q_wb = Q_base × Q_torso × Q_arm 上的前向运动学扫掠体 + 速度耦合修正项 κ_coup 作为唯一合法的碰撞证据；**整身分层 QP 门 (Whole-Body QP Gate, WBQ)**——安全/稳定硬约束 + 义务/能量软约束的字典序过滤器；以及一个被 v23 完全忽略的新失效模式：**碰撞安全但重心失稳倾覆**，故新增**质心稳定性证书 (Centroidal Stability Certificate, CSC)**（ZMP / 捕获点）。关键反直觉点：**"更精细的整身模型"在这里不是为了让机器人更激进，而是为了把一个隐藏的乐观假设（部件独立）收紧成可证明的整身约束**；耦合扩张带来的活性只允许在反事实证据下"有偿释放"，绝不默认打开。

**灵感 2（对比实验 → 从"自证安全"到"因果可归因的对照审计"）**
直觉：v17→v23 是一座证书塔，每层都宣称"我降低了风险"。但这套体系从头到尾只有**自证 (self-attestation)**，没有**对照 (control)**：没有任何证据表明抽掉某一层后风险真的上升。这就是**证书剧场 (certificate theater)**——模块在自洽地签发证书，却可能对安全毫无因果贡献；更危险的是**相关失效**：几个模态因为同一个根因（同一相机、同一逆光、同一分布漂移）同时"投 SAFE 票"，CFC+++ 把它们当成独立证据计数，于是"众口铄金"。对照实验补的正是这块：对每个候选计划 π，构造一个**匹配的反事实对照** π^C（消融某模块、或在影子/数字孪生里用同一初始状态与共同随机数滚动的替代计划），用**差分中的差分 (DiD)** 估计该模块的**边际因果安全效应** Δ_i，并给 conformal 置信区间。若 Δ_i 的置信下界 ≤ 0，则该模块是"剧场"或"有害"，必须被审计标记。更妙的是**交互效应** I_{ij} = Δ_{ij} − Δ_i − Δ_j：I_{ij} ≪ 0 正是"两模态冗余、会一起失效"的可测签名——于是 CFC 的"模态数 ≥2"从**结构假设**升级为**经验可检验的独立计数**（有效模态数 M_eff）。关键反直觉点：**真实机器人上不能跑不安全的对照组（伦理与合规不允许），所以对照必须在影子模式/数字孪生里跑**；由此引入**反事实差距证书 (Counterfactual-Gap Certificate, CGC)**，用 conformal 界定 sim-to-real 偏差，差距过大则对照证据失效、整体退回 v23（不依赖反事实的那一层）。这同时把"对比实验"变成**可预注册、可审计、可防 p-hacking** 的协议（CEAP）。

**两者如何统一**
统一为一个判据：**一个整身动作只有在"整身硬约束可行 ∧ 稳定 ∧ 其安全贡献经反事实对照可归因且非退化"时才被准入**。WBC/WBQ/CSC 回答"整身物理上安不安全、稳不稳"，CPEC/CEAP/CGC 回答"凭什么说这套证书真的在起作用、这些证据是不是彼此独立的"。二者共同封堵 v23 的最大风险（云边/覆盖共振崩塌）：**共振 = 多模块同根失效，而交互效应 I_{ij} 正是它的可测指纹**；整身耦合则堵住另一个同源风险——**部件独立假设下的"局部都安全、整体却撞/翻"**。共享状态扩展为 `ζ_wb = ζ_ce ∪ (q_wb, ẋ_wb, W_t, ξ_t, Δ_i, I_{ij}, M_eff, ε_gap, exp_registry)`。统一准入门 **HPC-E++ = HPC-E+ ∩ Fil_wb ∩ Fil_stab ∩ Fil_cf**，并维持 `Exec_v24 ⊆ Exec_v23 ⊆ …`。

## 1. 研究问题（轮次升级版）

- **Q12（整身耦合的可靠界与合成谬误修正）**：如何标定速度耦合修正 `κ_coup = L_FK·‖q̇_wb‖·Δt` 使整身扫掠体以 ≥1−δ 概率包含真实机体？部件安全集的笛卡尔积 `S_base × S_arm` 与真实整身安全集 `S_wb` 之间何时是上近似（耦合收缩，乐观）、何时是下近似（耦合扩张，悲观）？能否给出一个可机械复核的**耦合符号判据**，使得只在"耦合收缩"方向强制收紧，而"耦合扩张"方向的活性释放必须走反事实证据？

- **Q13（整身分层 QP 的可行性与递归活性）**：字典序 QP 的零优先级（安全碰撞 + 稳定性 + DCL 的 F 规则）如何保证**恒可行**（SafeStop 冻结动作永远在可行域内）？约束集随感知/规则/人距变化时如何保持**递归可行**而不在层级间来回振荡（chattering）？整身 QP 的硬约束与 v22 三层 PGEV 过滤器、v23 HDL 三层义务链如何对齐成同一条字典序，而不是三套互相打架的优先级？

- **Q14（反事实对照的因果有效性与 sim-to-real）**：在**不能于真机运行不安全对照组**的伦理约束下，如何用影子模式 + 数字孪生 + 匹配（同状态分层、共同随机数、倾向加权）无偏地估计 `Δ_i = R(π^{C_i}) − R(π^{T})`？反事实差距 `ε_gap = sup |R_sim − R_real|` 如何用 conformal 界定，并在 `ε_gap` 超阈值时失效安全地退回 v23？在线 50Hz 控制路径如何只做 O(1) 查询，而把昂贵的对照滚动放到异步离线？

- **Q15（独立性、有效模态数与可审计性）**：交互效应 `I_{ij}` 如何从有限对照样本中估计，并转成有效模态数 `M_eff` 供 CFC+++ 的计数阈值使用？多模块同时检验时如何用 alpha-spending 控制族错误率（FWER），防止"多试几个模块总有一个显著"？预注册哈希 + merkle 实验登记如何防止事后挑选对照（p-hacking）？对照证据与 v23 的 CESC 版本一致性、FSVC 覆盖硬约束如何叠加而不互相污染？

## 2. 设计原则（在 P37–P42 基础上新增 P43–P46）

**P43 整身不可分解律（Whole-Body Non-Decomposability）**
碰撞证据必须在整身配置空间 `Q_wb = Q_base × Q_torso × Q_arm` 上生成，而不是逐部件开票后取交。整身扫掠体为 `Sweep_wb(t) = inflate(FK_wb(Q_wb(t)), ε_loc + κ_coup)`，其中 `κ_coup = L_FK · ‖q̇_wb‖ · Δt` 覆盖速度耦合。部件交集 `S_base × S_arm` 仅在附加**耦合修正证书**（给出上/下近似的方向与界）后才可作为证据；任何方向不明的耦合一律按收缩处理（收紧）。耦合扩张的活性**不得默认释放**，只能经 CPEC 的释放证书且仍受 v23 上界约束。

**P44 稳定即硬约束律（Stability-as-Hard-Constraint）**
整身控制编译为字典序过滤器：L0 = 碰撞整身证书 ∧ 关节/力矩限 ∧ 稳定性证书 CSC ∧ DCL 的 F 规则（**硬，无松弛**）；L1 = DCL 的 O 义务（带期限，软但受监控）；L2 = PGEV 能量预算（软）；L3 = 任务跟踪（软）。松弛变量只允许出现在 L≥1。L0 不可行 → 触发可审计 SafeStop（冻结动作恒在 L0 可行域内），**绝不为满足任务而松弛 L0**。故 `Fil_wb` 只可能收缩 v23 的执行域。

**P45 反事实归因律（Counterfactual Attribution）**
任何被用于共识或准入的安全证据，其**边际因果贡献**必须可测：对每个模块 i（或模态 m）构造匹配对照并估计 `Δ_i` 及其 conformal 置信区间；置信下界 ≤ 0 的证据标记为"剧场/有害"并降权或拒绝用于准入。模态独立性不靠结构声明，而靠**交互效应** `I_{ij} = Δ_{ij} − Δ_i − Δ_j` 检验：`I_{ij} ≪ 0` 表示冗余（同根失效），据此折算 `M_eff`。CFC+++ 的计数阈值以 `M_eff` 而非原始模态数计。

**P46 对照审计律（Controlled-Experiment Audit）**
所有对照实验须**预注册**（假设、样本量、停止规则、匹配协变量）并写入 merkle 实验登记后方可开跑；采用匹配对 + 共同随机数 + DiD 估计；多模块检验用 alpha-spending 控制 FWER。真实机只允许在影子模式运行**已被 v23 证明安全**的计划作为对照，禁止把不安全对照上真机。反事实差距 `ε_gap` 超阈值时，全部对照证据失效，系统退回不依赖反事实的 v23 层。

## 3. 与基线的接口（如何退化）

- WBC 失效（整身 FK/标定不可信）⇒ 退回 v23 的部件证书交集，并**按收缩方向**额外膨胀 κ_coup ⇒ 比 v23 更保守；
- WBQ 失效（QP 求解器超时/崩溃）⇒ 冻结当前安全动作（SafeStop）⇒ 子集；
- CSC 失效（IMU/足底力估计不可信）⇒ 视为"可能失稳"⇒ 禁止任何改变支撑多边形的整身动作 ⇒ 子集；
- CPEC 失效（对照无法构造/差距过大）⇒ 不用于准入，退回 v23 的自证证书 ⇒ `Exec_v24 = Exec_v23`（不增不减，不依赖反事实）；
- CEAP 失效（审计链断裂/预注册被篡改）⇒ 对照证据视为不可信 ⇒ 同上退回 v23；
- CGC 失效（`ε_gap` 无法界定）⇒ 对照证据失效 ⇒ 退回 v23；
- 全部失效 ⇒ 完全回退 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`。
- **安全继承的诚实修正**：v23 的部件交集其实是在"部件独立"假设下的**乐观上近似**；WBC 的整身收紧正是把这个隐藏假设显式化，因此 `Exec_v24 ⊆ S_wb^true ⊆ Exec_v23^claimed`——单调链不是被打破，而是被**修正回真实安全集**。耦合扩张的活性释放被刻意延后（不在本轮扩展执行域），以保住 `⊆` 链。
- **事件接入**：WBC/CSC 以 50Hz 状态查询接入控制环（O(1)），CPEC/CEAP 以异步影子滚动接入 v17 APS 新鲜度阶梯，证据带时间戳与 TTL，过期即降权。

## 4. 预期贡献

1. **整身耦合证书**：首次把 v23 的"逐部件开票"识别为合成谬误，给出整身扫掠体 + 速度耦合修正 κ_coup 的可证明收紧，并用耦合符号判据区分"必须收紧"与"可有偿释放"两个方向；
2. **稳定性证书**：把"碰撞安全但倾覆"这一 v23 盲区变成与碰撞并列的硬约束（ZMP/捕获点证书），并纳入整身字典序 QP；
3. **反事实归因证书**：把"每层都降险"从自证变成带 conformal 区间的边际因果测量，定义并检测"证书剧场"与"有害模块"；
4. **经验独立性检验**：用交互效应 `I_{ij}` 把 CFC 的模态独立假设变成可测的 `M_eff`，直接给出 v23 共振风险的可计算指纹；
5. **可审计对照协议**：预注册 + merkle 登记 + 匹配对/CRN/DiD + FWER 控制，并配 sim-to-real 反事实差距证书，保证对照既因果有效又伦理合规；
6. **HPC-E++ 统一准入门**：`HPC-E+ ∩ Fil_wb ∩ Fil_stab ∩ Fil_cf`，闭环 `Exec_v24 ⊆ Exec_v23 ⊆ …`。

## 5. 本轮最大风险

**一句话**：整身耦合修正 κ_coup 与反事实差距 ε_gap 都是**上界估计**，两者会沿"整身收紧 × 对照不可信"两个方向同时挤压活性；一旦标定偏保守或 sim-to-real 偏差被低估，系统要么因整身膨胀而近乎冻结（活性坍缩），要么因误信数字孪生而把"仿真里安全、真机里相关失效"的模块当成已被因果验证——即**"被过度收紧的整身"与"被过度信任的对照"之间的活性-可信度两难**。

# ============================================================
# IP-440 Whole-Body Certificate (WBC) — 整身耦合几何证书
# ============================================================
@dataclass
class WholeBodyCertificate:
    q_wb: np.ndarray          # (n_wb,)
    qdot_wb: np.ndarray
    eps_loc: float            # 感知定位误差界（来自 DCSC conformal）
    L_FK: float               # FK Lipschitz 上界（离线标定）
    dt: float = 0.02          # 控制周期

    def coupling_correction(self) -> float:
        """速度耦合修正：覆盖 [t, t+dt] 内整身运动导致的扫掠膨胀"""
        return self.L_FK * float(np.linalg.norm(self.qdot_wb)) * self.dt

    def sweep(self) -> 'Geometry':
        kappa = self.coupling_correction()
        geo = FK_wb(self.q_wb)                  # 各连杆几何并集
        return inflate(geo, self.eps_loc + kappa)

    def coupling_sign(self, S_base: 'Set', S_arm: 'Set',
                      sampler: 'ConfigSampler') -> int:
        """判定部件交集相对真实整身安全集的方向。
        在 Q_wb 上采样，比较 proj 后的安全性与部件交集：
          - 若存在 q_wb 使部件各自安全但整身不安全 → 收缩 (−1)
          - 若存在整身安全但被部件交集排除   → 扩张 (+1)
          - 否则 0。保守：不确定一律返回 −1。"""
        saw_shrink = saw_expand = False
        for q_wb in sampler.sample(n=4096):
            whole_safe = not collides(self.sweep_at(q_wb), obstacles())
            part_safe = (in_safe(q_wb[Q_B], S_base) and
                         in_safe(q_wb[Q_A], S_arm))
            if part_safe and not whole_safe:
                saw_shrink = True
            if whole_safe and not part_safe:
                saw_expand = True
        if saw_shrink:
            return -1
        if saw_expand:
            return +1
        return 0

    def admits(self, obstacles, S_base, S_arm) -> tuple[bool, dict]:
        sign = self.coupling_sign(S_base, S_arm, ConfigSampler())
        # 收缩方向：必须用整身扫掠体，禁止退回部件交集
        if sign <= 0:
            ok = not collides(self.sweep(), obstacles)
            return ok, {"sign": sign, "mode": "whole_body"}
        # 扩张方向：默认不释放活性，仍按整身扫掠体（保守）；释放需 CPEC
        ok = not collides(self.sweep(), obstacles)
        return ok, {"sign": sign, "mode": "whole_body_conservative"}


# ============================================================
# IP-441 Whole-Body QP Gate (WBQ) — 字典序硬约束门
# ============================================================
class WholeBodyQPGate:
    """字典序：L0 安全/稳定/F 硬约束 > L1 义务 > L2 能量 > L3 任务。
    松弛变量只允许出现在 L>=1；L0 恒包含 SafeStop 冻结动作。"""

    def solve(self, q_wb, qdot_wb, task_ref, wbc, csc, dcl_state, energy) -> 'Control':
        # ---- L0 硬约束（无松弛）----
        A0, b0 = [], []
        # 1) 整身碰撞：线性化 Sweep_wb 的分离超平面约束
        A0.append(wbc.linearized_collision_jacobian())
        b0.append(wbc.linearized_collision_bound())
        # 2) 关节/力矩限
        A0.append(np.vstack([np.eye(len(q_wb)), -np.eye(len(q_wb))]))
        b0.append(np.concatenate([q_max, -q_min]))
        # 3) 稳定性证书 CSC（ZMP/捕获点）
        A0.append(csc.zmp_jacobian(q_wb, qdot_wb))
        b0.append(csc.zmp_bound(margin_stab))
        # 4) DCL 的 F 规则（禁区/禁行）
        for rule in dcl_state.forbidden_rules:
            A0.append(rule.jacobian())
            b0.append(rule.bound())
        # 5) 冻结动作恒可行（SafeStop 兜底）
        if not self._feasible(A0, b0):
            return SafeStop(reason="L0_infeasible", audit=dcl_state.proof())
        # ---- L1/L2/L3 软目标（带松弛）----
        cost, A_soft, b_soft = self._stack_soft_levels(
            task_ref, dcl_state.obligations, energy)
        u = solve_lexicographic_qp(A0, b0, A_soft, b_soft, cost)
        return u

    def _feasible(self, A, b) -> bool:
        return lp_feasible(A, b)   # 含 SafeStop 恒可行项，理论上恒 True

# IP-442 Centroidal Stability Certificate (CSC)

class CentroidalStabilityCertificate:
    def zmp(self, q_wb, qdot_wb, qddot_wb) -> np.ndarray:
        M = centroidal_mass_matrix(q_wb)
        h = centroidal_momentum(q_wb, qdot_wb)
        hdot = centroidal_momentum_rate(q_wb, qdot_wb, qddot_wb)
        return zmp_from_centroidal(M, h, hdot)

    def capture_point(self, q_wb, qdot_wb) -> np.ndarray:
        x_com = center_of_mass(q_wb)
        v_com = com_velocity(q_wb, qdot_wb)
        omega = math.sqrt(GRAVITY / max(x_com[2], 1e-6))
        return x_com[:2] + v_com[:2] / omega

    def admits(self, q_wb, qdot_wb, qddot_wb, margin_stab) -> bool:
        zmp_ok = point_in_polygon_shrunk(
            self.zmp(q_wb, qdot_wb, qddot_wb), P_support(q_wb), margin_stab)
        cp_ok = self.capture_point(q_wb, qdot_wb) in CAPTURE_SAFE_SET
        return bool(zmp_ok and cp_ok)


# ============================================================
# IP-443 Counterfactual Paired-Evidence Certificate (CPEC)
# ============================================================
class CounterfactualPairedEvidence:
    def __init__(self, twin: 'DigitalTwin', modules: list[str],
                 alpha: float = 0.01, n_pairs: int = 200,
                 horizon: int = 100):
        self.twin = twin
        self.modules = modules
        self.alpha = alpha
        self.n_pairs = n_pairs
        self.horizon = horizon

    def _matched_rollout(self, state, module_set, crn_seed) -> float:
        """同一初始状态分层 + 共同随机数，滚动得风险样本"""
        traj = self.twin.rollout(state, enabled=module_set,
                                 seed=crn_seed, horizon=self.horizon)
        return risk(traj)   # 碰撞/近失/规范违反的 0-1 风险

    def estimate(self, state_strata) -> dict:
        """对每个模块 i 估计 Δ_i；对每对 (i,j) 估计 Δ_ij。
        state_strata: 匹配后的状态分层（同协变量，不同扰动）。"""
        deltas, joint = {}, {}
        for stratum, seed in state_strata:
            r_T = self._matched_rollout(stratum, set(self.modules), seed)
            for m in self.modules:
                r_C = self._matched_rollout(
                    stratum, set(self.modules) - {m}, seed)
                deltas.setdefault(m, []).append(r_C - r_T)
            for i in range(len(self.modules)):
                for j in range(i + 1, len(self.modules)):
                    mi, mj = self.modules[i], self.modules[j]
                    r_Cij = self._matched_rollout(
                        stratum, set(self.modules) - {mi, mj}, seed)
                    joint.setdefault((mi, mj), []).append(r_Cij - r_T)
        return {
            "delta": {m: conformal_ci(v, self.alpha) for m, v in deltas.items()},
            "joint": {k: conformal_ci(v, self.alpha) for k, v in joint.items()},
        }

    def interaction_effects(self, est: dict) -> dict:
        I = {}
        for (i, j), (dij, _) in est["joint"].items():
            di = est["delta"][i][0]
            dj = est["delta"][j][0]
            I[(i, j)] = dij - di - dj
        return I

    def effective_modalities(self, I: dict, M: int, eps=1e-3) -> float:
        M_eff = float(M)
        for (i, j), Iij in I.items():
            di = max(abs(I[(i, j)]), eps)  # 归一化基准（保守）
            rho = max(0.0, min(1.0, -Iij / (di + eps)))
            M_eff -= rho
        return max(1.0, M_eff)

    def admissible_evidence(self, est: dict) -> dict:
        """Δ_i 置信下界 ≤ 0 → 剧场/有害，标记降权"""
        flags = {}
        for m, (d, lo, hi) in est["delta"].items():
            flags[m] = "theater_or_harmful" if lo <= 0 else "attributed"
        return flags

# IP-444 Controlled-Experiment Audit Protocol (CEAP)
# ============================================================
class ControlledExperimentAuditProtocol:
    def __init__(self, registry: 'ExpRegistry'):
        self.registry = registry

    def preregister(self, hypothesis: str, n_pairs: int,
                    stopping_rule: str, covariates: list[str]) -> str:
        """开跑前把假设/样本量/停止规则/协变量写入 merkle 登记"""
        payload = {
            "hypothesis": hypothesis, "n_pairs": n_pairs,
            "stopping_rule": stopping_rule, "covariates": covariates,
        }
        h = sha256(canonical_json(payload))
        self.registry.append(h)          # merkle 链
        return h

    def difference_in_differences(self, pre_T, post_T, pre_C, post_C) -> float:
        return (post_T - pre_T) - (post_C - pre_C)

    def alpha_spending(self, k_modules: int, alpha: float,
                       spent: list[float]) -> list[float]:
        """O'Brien-Fleming 型序贯 alpha-spending，控 FWER ≤ alpha"""
        return obrien_fleming_bounds(k_modules, alpha, spent)

    def verify(self, hypothesis_hash: str) -> bool:
        return self.registry.contains(hypothesis_hash)

# IP-445 Counterfactual-Gap Certificate (CGC)
# ============================================================
class CounterfactualGapCertificate:
    def __init__(self, eps_crit: float = 0.02, alpha: float = 0.05):
        self.eps_crit = eps_crit
        self.alpha = alpha
        self.eps_gap = float("inf")

    def bound(self, sim_rollouts, real_shadow_rollouts) -> float:
        """仅在真机影子模式运行已被 v23 证明安全的计划，估计 sim-to-real 差距"""
        diffs = [abs(r_sim - r_real)
                 for r_sim, r_real in zip(sim_rollouts, real_shadow_rollouts)]
        # conformal 上分位数作为差距上界
        self.eps_gap = conformal_upper(diffs, self.alpha)
        return self.eps_gap

    def admissible(self) -> bool:
        return self.eps_gap <= self.eps_crit

# IP-446 HPC-E++ 统一四层准入门
# ============================================================
@dataclass
class HPCEPlusPlus:
    hpc_e_plus: 'HPCEPlus'
    wbc: WholeBodyCertificate
    csc: CentroidalStabilityCertificate
    cpec: CounterfactualPairedEvidence
    cgc: CounterfactualGapCertificate
    ceap: ControlledExperimentAuditProtocol

    def admits(self, plan, x, v, z, E_res, margin_req, modules,
               q_wb, qdot_wb, qddot_wb, obstacles, S_base, S_arm,
               evidence_enabled=True) -> tuple[bool, dict]:
        # 1) v23 基线：HPC-E+（物理接地 + 云边 + 少样本 + IP）
        if not self.hpc_e_plus.admits(plan, x, v, z, E_res,
                                      margin_req, modules):
            return False, {"layer": "v23"}
        # 2) Fil_wb：整身耦合几何
        ok_wb, info_wb = self.wbc.admits(obstacles, S_base, S_arm)
        if not ok_wb:
            return False, {"layer": "wb", **info_wb}
        # 3) Fil_stab：稳定性硬约束
        if not self.csc.admits(q_wb, qdot_wb, qddot_wb, margin_stab=0.02):
            return False, {"layer": "stab"}
        # 4) Fil_cf：反事实归因（可选，失效则退回 v23 自证）
        if evidence_enabled and self.cgc.admissible():
            est = self.cpec.estimate(current_state_strata())
            flags = self.cpec.admissible_evidence(est)
            if any(f == "theater_or_harmful" for f in flags.values()):
                return False, {"layer": "cf", "flags": flags}
            M_eff = self.cpec.effective_modalities(
                self.cpec.interaction_effects(est), M=len(modules))
            if M_eff < 2.0:      # 有效独立证据不足，无法构成共识
                return False, {"layer": "cf", "M_eff": M_eff}
        return True, {"layer": "ok"}

## 3. 正确性论证

### 引理 5（整身耦合修正的安全性——合成谬误修正）
**陈述**：若 `κ_coup ≥ L_FK·‖q̇_wb‖·Δt`，则整身扫掠体 `Sweep_wb(t) = inflate(FK_wb(q_wb(t)), ε_loc + κ_coup)` 覆盖真实机体在 `[t, t+Δt]` 内的所有位置；且当 `sgn_coup = −1` 时 `S_wb^true ⊂ S_base × S_arm`，故 v23 的部件交集是**乐观且不安全**的，v24 的整身膨胀将其修正为真实安全集的超集。

**证明**：
1. 由 FK 的 Lipschitz 性，`‖FK(q(t+s)) − FK(q(t))‖ ≤ L_FK·‖q̇_wb‖·s ≤ κ_coup`（`s ≤ Δt`）；叠加感知误差 `ε_loc` 得扫掠包含性。
2. 若存在整身构型使部件各自安全而整身碰撞（`sgn_coup=−1` 的构造），则 `S_wb^true` 中不存在该构型，而 `S_base × S_arm` 含之，故后者是严格上近似。
3. v24 只在整身扫掠体上判定碰撞，故其接受集 ⊆ 真实安全集；v23 的接受集在收缩方向可越界。∎

### 引理 6（WBQ 硬约束的安全性与递归可行性）
**陈述**：若 L0 可行，WBQ 输出 `u` 满足整身碰撞、关节/力矩、CSC、DCL-F；若 L0 不可行，输出 SafeStop 且 SafeStop 恒在 L0 可行域内。故 `Exec_v24 ⊆ Fil_wb ⊆ Exec_v23`。约束收紧时递归可行性保持。

**证明**：
1. L0 约束全部为硬约束（无松弛），QP 可行解必满足之；松弛仅作用于 L≥1，不影响 L0 满足性。
2. SafeStop（冻结当前关节）是零加速度动作，只要当前状态在 L0 内（归纳假设），冻结在 `Δt` 内保持 L0 满足（碰撞扫掠退化、ZMP 不越支撑多边形），故 L0 恒可行。
3. 约束集随感知/规则变化时只会因新增 F 规则或收紧碰撞而**单调收缩**；收缩后 SafeStop 仍可行，故递归可行，不会在层级间振荡。∎

### 引理 7（反事实归因的一致性与覆盖）
**陈述**：在匹配协变量 `X` 满足条件可忽略性 `(π^T ⟂ 风险) | X`、共同随机数消除方差、DiD 消除可加混杂的条件下，`Δ̂_i` 是 `Δ_i` 的一致估计；其 conformal 区间以 ≥1−α 覆盖真值。

**证明**：
1. 分层匹配使处理/对照在同一 `X` 层内比较，条件可忽略性下层内差异无混杂。
2. 共同随机数使同一随机扰动作用于处理与对照，方差项在差分中抵消。
3. DiD 进一步消去与时间/场景相关的可加偏置。
4. conformal 分位数在可交换性下给出有限样本覆盖 ≥1−α。∎

### 引理 8（交互效应检测相关失效与有效模态数）
**陈述**：若模态 `i,j` 完全冗余（同一根因、失效事件相同），则 `I_{ij} ≤ 0` 且 `M_eff ≤ M−1`；若两者独立可加，则 `I_{ij} ≈ 0`、`M_eff ≈ M`。故 `M_eff` 是"有效独立证据数"的保守下界估计。

**证明**：
1. 令风险为失效事件的并集概率。完全冗余时，同时消融 `i,j` 与单独消融其一的风险相同，即 `Δ_{ij} = Δ_i = Δ_j`，故 `I_{ij} = Δ_{ij} − Δ_i − Δ_j = −Δ_i ≤ 0`（`Δ_i ≥ 0`）。
2. 独立可加时 `Δ_{ij} ≈ Δ_i + Δ_j`，故 `I_{ij} ≈ 0`。
3. `M_eff = M − Σ ρ_red`，冗余对使 `ρ_red > 0`，故冗余越多 `M_eff` 越小；完全冗余对至少减 1。∎

### 引理 9（v24 单调退化链）
**陈述**：任意单点/组合失效下，`Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18` 恒成立。

**证明**：
- WBC 失效 ⇒ 退回部件交集并按收缩方向额外膨胀 `κ_coup` ⇒ 更保守 ⊆。
- WBQ 失效 ⇒ SafeStop ⇒ 子集。
- CSC 失效 ⇒ 禁止改变支撑多边形动作 ⇒ 子集。
- CPEC/CEAP/CGC 任一失效 ⇒ `evidence_enabled=False` 或差距超阈 ⇒ 退回 v23 自证 ⇒ `Exec_v24 = Exec_v23`。
- 全部失效 ⇒ 完全回退 v23 ⇒ 链成立；各层均为交/过滤/失效向保守，归纳得全链。∎

### 定理（HPC-E++ 整身-因果准入门的安全性-稳定性-可归因完备性）
**陈述**：对任意计划 π，`HPCEPlusPlus.admits(π) = True` ⟺ π 同时满足：
(1) v23 的物理接地安全（几何∧规范∧负信息∧能量∧差距）与云边/少样本/IP 条件；
(2) 整身耦合几何安全（含速度耦合修正）；
(3) 质心稳定性（ZMP/捕获点）；
(4) 参与共识的模块其边际因果贡献非退化（Δ 置信下界 > 0）且有效独立模态数 `M_eff ≥ 2`。

**证明**：由 `HPCEPlusPlus.admits` 的四段连言与引理 5–9 直接可得。必要性：任一条件缺失对应一类未被缓解的风险（合成谬误 / 倾覆 / 证书剧场 / 相关失效）。充分性：四条件全满足时，整身硬约束保证物理可行、稳定性保证不倾覆、因果归因保证证据真实且独立，构成完整闭环。∎

## 4. 已知风险与缓解

| 风险编号 | 描述 | 严重度 | 缓解措施 | 剩余风险 |
|---|---|---|---|---|
| R6 | κ_coup 由 Lipschitz 上界给出，过度保守导致整身膨胀吞掉全部活性 | 最高 | 1) 离线标定分速度段的多档 L_FK；2) 用整身扫掠的真实凸包做紧化；3) 活性监控触发自适应重标定 | 高速+大臂展时保守性仍可能使共享区近乎冻结 |
| R7 | 数字孪生与真机偏差使 Δ_i 的因果结论失真（仿真安全、真机相关失效） | 最高 | 1) CGC 强制 ε_gap ≤ ε_gap^crit；2) 真机影子模式仅跑 v23 已证明安全计划；3) 差距超阈即关闭对照证据 | 罕见工况（镜面/强逆光/新人体型）落在影子覆盖外，ε_gap 被低估 |
| R8 | WBQ 的 L0 硬约束在极端约束集下数值不可行，频繁 SafeStop 造成活性抖动 | 高 | 1) SafeStop 恒可行兜底；2) 约束松弛只作用于 L≥1；3) 加滞回与最短停留时间抑制 chattering | 高频感知抖动下仍可能出现 SafeStop 抖动 |
| R9 | 交互效应 I_ij 在小样本、非平稳流下方差大，M_eff 估计不稳导致误判独立/冗余 | 高 | 1) alpha-spending 控 FWER；2) 匹配分层 + CRN 降方差；3) M_eff 取下界并用 TTL 平滑 | 长尾冗余（偶发同根失效）在小样本下可能漏检 |
| R10 | 预注册/merkle 登记与在线 CESC 版本切换耦合，版本切换后旧对照证据被误用 | 中 | 1) 对照证据携带 `V` 版本号，跨版本不继承；2) 切换窗口内冻结对照准入；3) 登记表按版本分片 | 快速连续切换时证据频繁失效，活性短期下降 |

## 5. 实验设计（对比实验为主轴）

### 5.1 实验原则
- **预注册**：每个假设（如"H_WB: 整身证书使近失率下降 ≥30%"）连同样本量、停止规则、匹配协变量写入 merkle 登记，开跑后不可更改；登记哈希随证书链留档。
- **匹配对 + 共同随机数**：每个"处理"场景配一个同协变量分层的"对照"场景，使用相同随机种子；对照在**影子模式/数字孪生**中运行，真机只跑 v23 已证明安全的计划（伦理约束）。
- **差分中的差分（DiD）**：`DiD = (R_T^post − R_T^pre) − (R_C^post − R_C^pre)`，消除场景/时间可加偏置。
- **FWER 控制**：多模块同时检验用 O'Brien-Fleming 型 alpha-spending，保证族错误率 ≤ α。
- **反事实差距**：`ε_gap` 由真机影子对照的 conformal 上分位数给出，超过 `ε_gap^crit=0.02` 即判定对照证据不可用。

### 5.2 验证指标

| 指标 | 基线 (v23) | 目标 (v24) | 测试协议（对照实验） |
|---|---|---|---|
| 整身碰撞率（含臂-底座耦合工况） | 部件交集假设，未量化 | 0（在 κ_coup 覆盖下） | 匹配对：同状态、臂伸展/底座运动耦合扰动 vs 对照；1000 对 |
| 倾覆/失稳事件率 | 未建模 | 0 | ZMP/捕获点故障注入，CSC 硬约束前后 DiD |
| 证书剧场检出率（Δ_i 置信下界≤0 的模块） | 0（无对照） | ≥95% 已知退化模块被标记 | 人为消融/退化一个模块，检验 CPEC 是否检出 |
| 相关失效检出（I_ij≪0 → M_eff 下降） | 结构假设，不可测 | 同根故障下 M_eff 下降 ≥1 | 让两模态共享同一相机故障，检验交互效应 |
| 有效模态数估计误差 | N/A | \|M̂_eff − M_eff\| ≤ 0.5 | 已知独立/冗余配置的合成实验 |
| 反事实差距 ε_gap | N/A | ≤0.02 时可准入，超阈自动关闭 | sim-to-real 影子对照，conformal 上界 |
| 端到端单步延迟 (P99) | <20ms | <20ms（含 WBQ） | 50Hz 实测，n_wb=50 |
| 安全单调性违反次数 | 0 | 0 | 故障注入：WBC/CSC/CPEC/CGC 组合失效 |
| SafeStop 抖动率 | N/A | <1 次/小时 | 高频感知抖动注入，统计 SafeStop 切换频率 |

### 5.3 关键对照实验（示例）
1. **整身 vs 部件（合成谬误验证）**：在同一批臂伸展+底座运动耦合工况上，分别用"部件交集"与"整身扫掠体"判定，统计前者漏判的整身碰撞数。预期前者 >0、后者 0，从而**实证** v23 的乐观假设。
2. **有对照 vs 无对照（证书剧场验证）**：人为把某一感知模块替换为"恒投 SAFE"的退化版本，比较 CFC+++ 在有/无 CPEC 时是否仍准入。预期无对照时被"众口铄金"接纳，有对照时 Δ_i 置信下界 ≤0 被拒。
3. **相关失效注入**：令两个模态共享同一故障源，检验 `I_{ij}` 显著为负、`M_eff` 从 2 降至 1，CFC+++ 因 `M_eff<2` 拒绝共识。这是对 v23 最大风险（共振崩塌）的直接证伪实验。
4. **耦合扩张的活性释放（延后验证）**：在受控仿真中比较"默认不释放"与"经 CPEC 释放"的活性-风险前沿，为下一轮的"有偿释放"提供数据，但本轮不接入执行域。

## 6. 本轮最大风险（最终确认）

**一句话**：整身耦合修正 κ_coup 与反事实差距 ε_gap 都是**上界估计**，二者沿"整身收紧 × 对照不可信"两个方向同时挤压活性；一旦标定偏保守或 sim-to-real 偏差被低估，系统要么因整身膨胀而近乎冻结（活性坍缩），要么因误信数字孪生而把"仿真里安全、真机里相关失效"的模块当成已被因果验证——即**"被过度收紧的整身"与"被过度信任的对照"之间的活性-可信度两难**。
