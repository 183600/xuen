# 第 10 轮（新灵感循环第 1 轮；本轮灵感：「语义分割」×「场景理解」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**语义只收紧、不放松**；**缺席 ≠ 无知**；**保证可追溯**。语义分割与场景理解不是“再加一个感知模块”，而是把 v9 的几何证书从“障碍在哪里”升级为“障碍是什么、还藏着什么、这个任务该离多远”。任一新模块失效时注入**缺席元** ⊥（max 的恒等元），严格等价退回 v9（引理 96）；而“语义说不知道”注入的是**无知元** ⊤（max 的吸收元），是一个显式更保守的收紧，两者绝不能混同。

## 0. 直觉与动机

**灵感 1（语义分割 → 风险化的占据证书）**
直觉：v9 的 `dist(s,O)` 把世界看成无类型的点云。但 2cm 的电缆在几何上可忽略、语义上致命；玻璃门在深度图里“不存在”、在 RGB 分割里“存在”；人不是障碍物，是需要 0.8m 社交距离的主体。核心创新：**语义占据证书器（SemanticOccupancyCertifier, SOC）**——把分割输出经**风险格**映射为“类别安全边距” d_safe(c)，再用**风险控制的分割阈值**（逐类 FNR ≤ ε、置信 1−δ）保证漏检有上界。语义净空 g_sem = min_r [dist(s,r) − d_safe(c_r)] ≤ g_geo——**只收紧**（引理 87）。玻璃/镜面/细线由 RGB 语义补几何盲区，这是 v9 最直接的安全增量。

**灵感 2（场景理解 → 任务条件的场景图与遮挡推理）**
直觉：场景理解的价值不在“多认几个物体”，而在**关系**与**不可见部分**：杯子在玻璃柜里（containment）、电缆在椅子后面（occlusion）、孩子正跑向机器人（social entity）。几何证书只看可见表面，**遮挡区是安全证明的黑洞**。核心创新：**任务条件场景图（SceneGraphReasoner, SGR）** 给出 G_t^τ 与类别-任务边距；**非模态场景补全器（AmodalSceneCompleter, ASC）** 预测被遮挡空间里“可能有什么”，把中止点条件从 `dist(s,O_visible)` 升级为 `dist(s, O_visible ∪ Ô_amodal)`，并用集合值覆盖（真占据集以 ≥1−α 概率被预测集包含）约束“脑补”的幻觉。于是 v9 的中块守卫第一次能对“拐角后突然出现的物体”提前留出刹车距离。

**灵感 3（两者相乘 → 语义-几何仲裁与保证清单）**
直觉：语义会错，几何也会错（玻璃、反光、稀疏点云），两者的错误还**相关**。核心创新：**语义-几何仲裁器（SemanticGeometricArbiter, SGA）** 在安全通道取**并集/max**——任何一方说危险就危险，冲突只能收紧不能放松；**保证监督器（GuaranteeSupervisor, SGS）** 维护**保证清单**，把“当前哪些安全保证仍然成立”作为与控制信号正交的侧信道显式记录，避免 v9 中立元退化把“保证悄悄失效”伪装成“一切正常”。这是对 v9 “失效与退化在日志上不可区分”的一个必要补丁：**行为可逐位等价，但保证必须可追溯**（引理 95）。

## 1. 研究问题（轮次升级版）

- **Q1（语义漏检的风险控制）**：逐类 FNR 风险控制 + 空间膨胀，能否给出“真实危害 ≤ 证书危害”的高概率上界？类别不平衡、透明物、小目标下该上界是否仍可陈述？
- **Q2（遮挡与非模态幻觉）**：非模态补全的集合覆盖保证在域偏移下如何失效？把“未知遮挡”作为 ⊤ 注入，能否在 liveness（可行走）与 safety（不撞隐藏物）之间给出可审计的折中？
- **Q3（退化与相关失效）**：SOC/ASC/SGR/SGA/SGS 任一失效能否严格退回 v9（缺席 ⊥）？当 SOC 与 ASC 共享训练偏差、**相关漏检**时，`max` 融合的保守性还成立吗？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P17）

**P13 语义单向收紧律（Semantics Tighten-Only）**
安全通道中语义只能增加危害：h ← max(h_geo, h_sem, h_amodal, h_conflict)。语义永不删去几何障碍、永不放宽 v9 的中止点；任何“放松”（如窗帘不是障碍）只能走独立的**语义豁免**性能通道，且其失效只回到 v9 的保守，不进入安全证明。

**P14 缺席-无知二分律（Absence ≠ Ignorance）**
模块失效/休眠/超时注入缺席元 ⊥（max 的恒等元），得到精确 v9；分割器**正常运行但输出 unknown 类**或置信不足时注入无知元 ⊤（大安全边距/膨胀），这是一个显式收紧，必须进入保证清单并触发减速/查询。绝不把“没有输出”当成“没有危险”，也绝不把“不知道”当成“可以走”。

**P15 保证可追溯律（Guarantee Provenance）**
控制行为通道 B(t) 与保证通道 G(t) 分离：B 在缺席退化下逐位等价 v9；G 记录每条安全声明（语义覆盖、非模态覆盖、新鲜度、仲裁一致）的 active/inactive 状态与证据。任一被任务声明为必需的声明失效 ⇒ 外层 SGS 只能收紧（限速、K_eff←1、请求帮助），不许静默放行。

**P16 新鲜度有界律（Freshness-Bounded Semantics）**
重语义在 5Hz 异步 worker 上运行，50Hz 只消费**带时间戳**的语义场与轻量跟踪传播；证书边距随陈旧度 s(t) 膨胀 γ·s(t)，超过类别相关的 T_sem(c) 的高风险区域注入 ⊤。过期语义不得冒充新鲜语义（这是 v9 Δ_dom 滑窗滞后风险的语义版）。

**P17 遮挡保守律（Occlusion Conservatism）**
不可见空间默认不是“空”，而是“可能被风险物体占据”：ASC 给出集合值补全；补全覆盖失效或超时时，按风险区域注入 ⊤（或受限的完全保守占据），中止点必须按“可见 ∪ 补全 ∪ 未知”三者的并集计算。

## 3. 与基线（v9）的接口（如何退化）

- SGS 失效 ⇒ 撤掉收紧包络，行为回到 v9 语义（安全声明丢失被记录）；
- SGA 失效 ⇒ 退回纯几何仲裁（O_sem=∅, O_amodal=∅），等价 v9；
- SOC 失效/超时 ⇒ 注入缺席 ⊥（O_sem=∅），等价 v9 几何证书；若任务要求语义声明，SGS 收紧；
- ASC 失效 ⇒ O_amodal=∅，等价 v9（v9 本来不含遮挡谨慎）；高风险遮挡环境下 SGS 收紧；
- SGR 失效 ⇒ 统一边距 d_safe0、任务子图取全集，等价 v9；
- SFC 失效 ⇒ 不主动查询，未解析区域按 ⊤ 处理或由 SGS 决定；
- 全部语义模块缺席 ⇒ 精确 v9 ACMD；再沿 v9 链退到 v8/v7/v6。

## 4. 预期贡献

1. **语义风险证书**：把分割的漏检用逐类风险控制变成可陈述的危害上界，首次让“透明/细小物体”进入 v9 的证书体系；
2. **遮挡感知的非模态证书**：把安全证明从中块可见表面扩展到遮挡空间，中止点条件统一为“可见 ∪ 补全 ∪ 未知”；
3. **两分退化代数**：区分缺席 ⊥ 与无知 ⊤，解决 v9 中立元框架无法表达“我知道我不知道”的结构性缺陷；
4. **保证溯源**：行为逐位等价 v9 的同时，保证清单使“哪天丢了哪条安全声明”可审计；E571–E590 覆盖透明物、遮挡突现、冲突、相关失效与端到端。

## 5. 本轮最大风险

**一句话**：语义层最需要发挥作用的透明/遮挡场景，恰恰是分割与非模态补全共享同一训练偏差、漏检**相关**最高的场景——`max` 并集只在“至少一条通道看见”时才保守，而在这里两条通道会一起、高置信地漏检，系统既失去语义增量、又被保证清单的“active”误导，最终退回 v9 的几何盲区而不自知。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-SSC**（Semantic Scene Certificates with conservative semantic extension）

> 背景：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮灵感：「语义分割」×「场景理解」
> **继承纪律**：MetricVoiceGauge 九不变式（CVC-闭环、SpatialCert、RT-CVC、FaultCert、PrimitiveGraph、严格退化链、OTL、GCT、ER）全部保留；v9 的 AC/MW/ID 三模块原样继承。新组件一律为**可选增强**：任一环节不可用 ⇒ 注入缺席元 ⊥，严格等价退回 v9 ACMD（引理 96），而非行为漂移。**新增的第二类失效语义**——“模块运行但语义无知”——注入无知元 ⊤，是显式收紧，不是退化（定义 541/引理 88）。

**新增定义 540（语义风险格 Semantic Risk Lattice）** 类别集 C = {free, negotiable, deformable, fragile, rigid, person, animal, unknown}，(C, ⊑) 为有限偏序（默认 free ⊑ negotiable ⊑ deformable ⊑ fragile ⊑ rigid ⊑ person，animal 与 person 同级偏社会风险，unknown 为类内最保守），风险赋值 ρ: C×T → R_{≥0} 对 ⊑ 单调。缺省边距 d_base：

| 类别 | free | negotiable | deformable | fragile | rigid | animal | person | unknown |
|---|---|---|---|---|---|---|---|---|
| d_base (m) | 0.00 | 0.05 | 0.10 | 0.15 | 0.20 | 0.60 | 0.80 | max_{c∈C_τ} d_safe(c) |

**关键**：unknown 不是“中立”，而是“类型信息缺失”，其边距取**当前任务可行类别集 C_τ 上的最坏值**；C_τ 由场景图给出，SGR 失效时 C_τ=C（最保守）。

**新增定义 541（两分证据代数 Two-Sorted Evidence Algebra）** 每个语义通道对区域 r 的输出是二元组：**缺席** ⊥，或**危害场** h(r)∈R。融合算子 ⊔ 为逐点 max，满足
```
⊥ ⊔ h = h        （缺席是恒等元，精确退回 v9）
⊤ ⊔ h = ⊤        （无知是吸收元，显式更保守）
```
其中 ⊤ 表示保证监督器在“覆盖失效/过期/无法解析”区域注入的**无知场**（h=H_max，实现为触发停驻/限速的大边距）。**区分三种状态**：(a) 没输出=⊥；(b) 输出 unknown 类=有限但保守的危害场；(c) 输出不可信/过期=⊤。v9 的中立元框架只有 (a)，v10 把 (b)(c) 提升为一等公民。

**新增定义 542（风险控制标签集 Risk-Controlled Label Set）** 分割器输出逐像素类概率 p(c|r)。对每类 c 校准阈值 λ_c，令
```
L_r = { c : p(c|r) ≥ λ_c } ∪ ( {unknown}  若 max_c p(c|r) < λ_unk )
```
λ 由**分布无关风险控制**选取：定义帧级漏检危害
```
L(λ) = max_{i ∈ I_t \ Î_t} [ d_safe(c_i,τ) − dist(s_t, R_i) ]_+
```
（I_t 为真实非自由实例集，Î_t 为被预测为非自由的实例集），在独立校准集上用 Hoeffding/固定序列检验选 λ，使 E[L] ≤ ε_sem 且置信 1−δ_sem；并取上置信界版本以支撑单帧硬判据。边界不确定处按 r_α 膨胀，r_α 由校准集边界误差的 1−α 分位数给出。**保证陈述**：在可交换性/校准分布下，真实漏检危害以 ≥1−δ_sem 概率不超过证书危害加 ε_sem。

**新增定义 543（语义净空与危害场 Semantic Clearance）**
```
g_sem(s) = min_{r : L_r ∩ (C\{free}) ≠ ∅} ( dist(s,r) − max_{c∈L_r} d_safe(c,τ) )
h_sem(s) = −g_sem(s)
```
空集约定 g_sem=+∞（中立）。语义证书有效 ⇔ g_sem ≥ 0。注意 `max_{c∈L_r}` 对标签不确定性取最坏，`min_r` 对所有区域取最坏，故 g_sem ≤ g_geo 当 d_safe ≥ d_base 时成立（引理 87）。

**新增定义 544（类别-任务安全边距 Category-Task Margin）**
```
d_safe(c,τ) = d_base(c) + Δ_task(c,τ) + Δ_social(c) + γ_fresh · s(t)
```
Δ_task 只允许对安全关键任务**增大**边距（如“端热汤”把 person 边距提到 1.0m、把 fragile 提到 0.3m）；Δ_social 对 person/animal 追加社交项；γ_fresh·s(t) 为陈旧膨胀（定义 549）。任务切换若降低边距，必须经 SGS 显式降级声明，不能隐式发生。

**新增定义 545（任务条件场景图 Task-Conditioned Scene Graph）**
```
G_t = (V, E),  v = (class, pose, extent, material, affordance, uncertainty)
E ⊆ V×V×{support, containment, occlusion, proximity, ownership, social}
```
任务 τ 选出子图 G_t^τ 与可行类别集 C_τ。**安全闭包** C_safe(τ) = {person, animal, unknown} ∪ ({fragile} 若任务涉及易碎物) ∪ ({deformable} 若任务涉及柔性物) 永远保留，任务相关性过滤只能剔除低风险节点；高危节点误分类属于定义 542 的漏检风险，不属于图过滤风险（引理 92）。

**新增定义 546（非模态场景补全 Amodal Scene Completion）** 非模态网络由可见几何与语义预测遮挡空间逐体素占据概率 p_occ(v) 与类别分布。占据集
```
Ô_α = { v ∈ Occ : p_occ(v) ≥ 1 − α_occ }
```
在含隐藏物真值的仿真校准集上做 split-conformal/风险控制，使
```
P( O_true ∩ Occ ⊆ Ô_α ) ≥ 1 − α_occ
```
并输出区域级遮挡置信。**非模态**意味着补全被遮挡物体，而非仅补全可见表面；其幻觉风险由“集合值 + 覆盖保证 + 超时注入 ⊤”三重约束。

**新增定义 547（遮挡危害与中止点升级 Occlusion Hazard & Abort Upgrade）**
```
g_occ(s) = min_{v ∈ Ô_α} ( dist(s,v) − d_safe(c_v,τ) − β_occ )
d_brake(v_p) + d_safe + β_occ ≤ dist(s_p, O_geo ∪ O_sem ∪ Ô_α) − |traj_{p:K}|
```
后式是 v9 定义 534 的直接升级；当 Ô_α=∅ 且 O_sem=O_geo 时逐项退化为 v9。于是“拐角后突然出现”的物体在块生成时已被折入刹车距离，中块守卫只需检测**新出现**与**补全失配**。

**新增定义 548（语义-几何仲裁 Semantic-Geometric Arbitration）**
```
O_safe = O_geo ∪ O_sem ∪ Ô_α ,     g_safe = min_{o ∈ O_safe} (dist(s,o) − d_safe(c_o,τ))
```
冲突标志：
- κ₁：g_geo ≥ 0 > g_sem（几何说可走、语义说危险）⇒ 采信语义（保守）；
- κ₂：g_sem ≥ 0 > g_geo（语义说可走、几何说危险）⇒ 采信几何（保守）；
- κ₃：SOC 与 SGR 对同一区域类别不一致 ⇒ 取二者最大边距。
融合恒为 max 危害/并集占据，**永不取 min**。可选“语义豁免”（如窗帘被识别为可穿行柔性物）走独立性能通道，需接触力/材质证书，且**不进入安全证明**；其失效只回到 v9 的保守。

**新增定义 549（语义新鲜度与陈旧膨胀 Freshness）**
```
s(t) = t − t_last_cert(c) ,     r_α(t) = r_0 + v_max · s(t)
d_safe^s(c,τ) = d_safe(c,τ) + γ_fresh · s(t)
```
类别相关预算 T_sem(c)：person/animal 0.2s、movable 0.5s、rigid/fragile 1.0s、static 2.0s。s(t) > T_sem(c) 的高风险区域注入 ⊤；manifest 记录 `FRESH(c)=expired`。陈旧场只允许用于**静态**类，动态类必须刷新，否则按 ⊤ 处理。

**新增定义 550（主动语义聚焦 Active Semantic Focus）**
```
q* = argmax_{q ∈ Q_views}  E[ ΔH(q) | history ] / cost(q) ,    s.t. Σ cost ≤ Q_max
```
ΔH 为查询后高风险 unknown/遮挡区域危害不确定性的期望下降。每次查询必须严格降低至少一个区域的不确定性，否则被信息增益过滤器拒绝；预算耗尽仍未解析 ⇒ 该区域注入 ⊤（引理 94 终止性）。

**新增定义 551（保证清单 Guarantee Manifest）**
```
G(t) = { (claim_id, scope, state ∈ {active, expired, violated}, evidence, expiry) }
claims = { SEM_COV(ε_sem,δ_sem), AMODAL_COV(α_occ), FRESH(c),
           CONFLICT_FREE, GRAPH_CONSISTENT }
```
G(t) 是与控制行为正交的侧信道：它不改变 B(t)，只供 SGS 读取。任务要求 R_τ ⊆ active(G(t)) 不满足 ⇒ SGS 收紧（定义 553）。这样“行为逐位等价 v9”与“保证丢失可审计”同时成立（引理 95）。

**新增定义 552（语义可承受块长 Semantic Effective Chunk Length）**
```
K_eff^sem(t) = max { k ≤ K_max : g_safe(k) ≥ 0 ∧ coverage_ok ∧ freshness_ok
                     ∧ no_unresolved_conflict }
K_eff(t) = min( v9 定义 539 的 K_eff(Δ_dom, risk_SLAM), K_eff^sem(t) )
```
高风险 unknown/遮挡 ⇒ K_eff^sem ≤ 2；任一冲突未解析 ⇒ K_eff^sem=1。语义不确定性因此直接收缩块长，把 v9 的“域越陌生块越短”推广为“场景越不确定块越短”。

**新增定义 553（任务声明要求 Task Claim Requirement）**
```
R_τ = ( required_claims, max_staleness, risk_tier )
```
例：开放杂物中抓取 ⇒ {SEM_COV, AMODAL_COV, FRESH(person)}；端易碎物 ⇒ {SEM_COV, FRESH(fragile)} 且 fragile 边距 ≥0.3m；社交导航 ⇒ {FRESH(person), CONFLICT_FREE}；摆桌 ⇒ {GRAPH_CONSISTENT, AMODAL_COV}。R_τ 是 SGS 的唯一输入，使“任务语境”变成可审计的保证需求，而不是隐含假设。

# IP-357 SemanticOccupancyCertifier：语义占据证书器
class SemanticOccupancyCertifier:
    def __init__(self, segmenter, alpha=0.05, delta=0.05,
                 r0=0.03, unk_margin_mode="task"):
        self.seg = segmenter
        self.alpha, self.delta, self.r0 = alpha, delta, r0
        self.lam = None                      # 逐类阈值 λ_c（定义 542）
        self.unk_margin_mode = unk_margin_mode

    def calibrate(self, calib_loader):
        # 在独立校准集上做分布无关风险控制：E[L(λ)] ≤ alpha, 置信 1-delta
        self.lam = fit_thresholds_by_risk_control(
            calib_loader, self.seg, alpha=self.alpha, delta=self.delta)
        self.r_alpha = boundary_quantile(calib_loader, 1 - self.alpha)
        return self

    def label_set(self, probs):
        L = {c for c, p in probs.items() if p >= self.lam[c]}
        if max(probs.values()) < self.lam.get("unk", 0.3):
            L.add("unknown")                 # 运行但无知：有限保守危害，非 ⊥
        return L or {"unknown"}

    def margin(self, c, task, C_tau):
        if c == "unknown":
            return max(d_base(x) for x in C_tau)   # C_τ 由 SGR 给出，失效时 C
        return d_base(c) + task.delta_task(c) + social_delta(c)

    def certify(self, rgbd, pose, task, C_tau, now):
        logits = self.seg(rgbd)
        Ls = {r: self.label_set(logits[r]) for r in regions_of(logits)}
        # 定义 543：min over regions of (dist - max_{c in L_r} margin)
        g = min((distance(pose, r) - max(self.margin(c, task, C_tau) for c in Ls[r])
                 for r in Ls if Ls[r] & NONFREE), default=float("inf"))
        h = -g
        return SemanticField(h, Ls, stamp=now, r_alpha=self.r_alpha,
                             coverage=self.ucb_coverage())

class SemanticGeometricArbiter:

# IP-362 SemanticFocusController：主动语义聚焦
class SemanticFocusController:
    def __init__(self, budget=3):
        self.budget = budget

    def propose(self, uncertainty_map, available_views):

        scored = [s for s in scored if s[0] > 0]

## 4. 推导

**引理 87（语义单向收紧 / Tighten-Only）** 设 O_geo ⊆ O_safe、d_safe(c,τ) ≥ 0，且 L_r 只增不减（标签集随证据增加而扩张）。则 g_safe ≤ g_geo，且对任意标签集细化 L_r ⊆ L'_r 有 g_sem(L'_r) ≤ g_sem(L_r)。证明：g_safe 是对超集取 min、对标签集取 max 的复合，min 在超集上不增、max 在超集上不减、d_safe≥0，故单调；于是任何在 g_safe 下可行的动作在 g_geo 下可行。∎

**引理 88（缺席-无知二分与保守退化）** 注入缺席 ⊥ 时 h=h_geo，系统逐位等价 v9。注入无知 ⊤ 时对任意通道有 h ⊔ ⊤ = ⊤ ≥ h_geo，故证书至少与 v9 同样保守；且 manifest 区分 `inactive`（缺席）与 `active_but_ignorant`（无知），二者不可混同。因此“没有输出”不会伪装成“没有危险”，“不知道”也不会伪装成“可以走”。∎

**引理 89（风险控制语义危害界）** 若 λ 由分布无关风险控制选出，使 E[L(λ)] ≤ ε_sem 且以 ≥1−δ_sem 概率有 L(λ) ≤ ε_sem（上置信界版本），则对任意状态
```
h_true(s) ≤ h_cert(s) + ε_sem     （在覆盖事件内）
```
其中 h_cert 由定义 543 的标签集与边距计算，空间膨胀 r_α 覆盖边界误差。证明：L(λ) 正是“未被 Î_t 捕获的真实危害”的上确界；h_cert 对每个被捕获区域取 max_{c∈L_r} d_safe ≥ 真实 d_safe（覆盖事件内），对未捕获区域由 L(λ) 补偿；三角不等式给出上式。∎

**引理 90（非模态遮挡安全，双层保证）** 若覆盖事件 O_true∩Occ ⊆ Ô_α 成立（概率 ≥1−α_occ），则定义 547 的中止点条件保证从 p* 停驻时对可见与隐藏障碍均留出 d_safe。若覆盖失效或 ASC 超时，SGS 注入 ⊤（完全保守占据）或按“到最近遮挡区距离”限制速度，使刹车距离 ≤ 该距离；此路径**不含统计假设**，是逐帧硬保证。故遮挡安全有“统计覆盖（性能）+ 无条件保守（兜底）”双层结构。∎

**引理 91（并集融合无洞 / Union Fusion No-Hole）** 若至少一条通道检测到危害区域 R，则 O_safe 包含 R，故 g_safe 不会在 R 上“误判自由”。形式化：漏检事件 M = ∩_m M_m，故
```
P(M) = P(∩_m M_m) ≤ min_m P(M_m)
```
独立时 P(M)=∏_m P(M_m)；正相关时只能退到下界 min_m P(M_m)。因此**并集融合的保守性依赖通道误差的弱相关假设**，见命题 1 与第 8 节风险。∎

**命题 1（相关失效盲区）** 若各通道共享同一失效模式（如透明玻璃在分割与补全训练集中均稀缺），则 P(∩_m M_m) ≈ P(M_common)，而非 ∏_m P(M_m)。此时逐通道 FNR 上界无法推出端到端漏检上界；`max` 融合在最需要它的场景退化为“最弱通道”甚至“共同盲区”。∎

**引理 92（场景图安全闭包）** 任务条件化只能剔除低风险节点，C_safe(τ) 恒含 person/animal/unknown 及任务相关的高危类。故 G_t^τ 过滤不会移除任何可参与 M₀ 硬约束的节点；高危节点若被误分类为低风险，属定义 542 的漏检风险，已由引理 89 处理，不是图过滤引入的新风险。∎

**引理 93（新鲜度与保证衰减）** 陈旧 s 的语义场加上膨胀 r(t)=r_0+v_max·s 与边距 γ_fresh·s，覆盖了任何速度 ≤v_max 的物体在 s 时间内的可达集。故 s ≤ T_sem(c) 时证书对当前时刻仍保守；s > T_sem(c) 时保证过期，SGS 注入 ⊤ 或限速。于是不存在“过期语义被当作新鲜语义”的静默信任。∎

**引理 94（主动聚焦终止 / 无 Zeno）** 每次查询必须使至少一个区域的不确定性严格下降，否则被信息增益过滤器拒绝；预算 Q_max 有限，故每块查询数有限；耗尽后未解析区域注入 ⊤。因此聚焦循环终止，不会出现无限查询/无限减速的 Zeno 行为。∎

**引理 95（保证可追溯与行为等价）** 行为通道 B(t) 仅是控制输入与当前危害场的函数；manifest G(t) 是侧信道，仅在 SGS 启用时通过“增加约束”的包络影响 B，故 B 始终在 v9 可行集内。SGS 关闭且全部语义缺席时，B 逐位等于 v9。manifest 使 claim 丢失可观测而不改变 B 的等价性。∎

**引理 96（完整退化到 v9）** 令 SOC/ASC/SGR/SGA/SFC 全部缺席（⊥）且 SGS 关闭：定义 543 退化为 g_geo；定义 547 中 Ô_α=∅ 退化为 v9 定义 534；定义 544 退化为 d_base；定义 552 退化为 K_max；定义 551 的 manifest 为空。逐项代入主闭环，所有新增项消失，系统行为与 v9 ACMD 逐位一致；再复合 v9 引理 83 得到 v8→v7→v6 的完整退化链。∎

| 决策侧合计 | 在线 | 典型 ≤8.6ms，p99 ≤20ms（重型语义在独立核） | — | v9 引理 86 + 本表 |
| 语义 worker 预算 | 软实时 | 5Hz ≤16ms/次；超时 ⇒ 新鲜度衰减/L0 | — | 定义 549 |

**关键工程约束**：重型语义（SOC/ASC/SGR）**不得进入 50Hz 硬实时链**，而是 5Hz 软实时 worker + 无锁 latest-result 缓冲；50Hz 主环只做跟踪传播、并集融合与保证检查。这样 v9 的 50Hz 守恒（引理 86）不被语义推理打破。

## 8. 本轮最大风险

**一句话**：语义层最需要发挥作用的透明/遮挡场景，恰恰是分割与非模态补全共享同一训练偏差、漏检**相关**最高的场景——`max` 并集只在“至少一条通道看见”时才保守（引理 91 的下界退化为 min_m P(M_m)，命题 1），而在这里两条通道会一起、高置信地漏检，系统既失去语义增量、又被保证清单的“active”误导，最终退回 v9 的几何盲区而不自知。
