### 第 6 轮灵感驱动研究记录

**灵感词**：抓取规划、仿真到现实迁移

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）把提议升级为条件流匹配（FMPP）、记忆升级为嵌入+固化（LMEM-v2）、人因升级为情感调制（FAMK），并以定理 5~8 证明「提议可换、门不可换」的证书不变性与 Exec_v5 ⊆ Exec_v4。本轮不推翻 v5，只补两个结构性盲区：(a) v5 的候选 x=(pose,wrench) 默认「抓取方式已给定」，抓取模式（接触点、摩擦锥、接触状态）藏在上下文里且没有证书——一旦抓取本身不可行，七门全部在错误前提上运算；(b) v5 的七门都在仿真模型上求值，证书只是「模型内为真」，仿真到现实的动力学/感知/摩擦差异没有被显式计入。两个灵感词统一为主题「可迁移的抓取证书」（Transferable Grasp Certification, TGC），形成 CADVS-v6（IP-497~500）。本轮自律：**硬门数量仍不增**（维持七门）；抓取证书是 MSRG/EEK 的**内部细化**，迁移鲁棒性是**阈值收紧**；执行集升级为 Exec_v6 ⊆ Exec_v5 ⊆ … ⊆ Exec_v29。

**直觉解释（先讲人话）**：

1. **抓取规划 = 把「怎么抓」提升为一等公民，而不是隐含假设**。v5 像一位只检查「动作是否优雅」的考官，却默认「你抓得住」；若抓取点落在低摩擦区域，或所需力旋量超出摩擦锥张成的空间，轨迹再合规，现实里也会打滑。直觉上，抓取是离散的「接触模式选择」，轨迹是连续的「运动」，真实候选空间是二者的乘积。于是先给每个抓取模式发一张「力闭包证书」：接触点、法向、摩擦锥能否张成所需力旋量空间，且留有多大 Ferrari-Canny 边际；只有抓取证书过硬，才允许轨迹进入后续门。抓取证书不是第八道门，而是把物理门（MSRG）本来就该问、却一直没问的前提补上。

2. **仿真到现实迁移 = 先扣安全垫，再发证书**。仿真与现实的差距可拆成四类误差预算：动力学（质量/惯量/摩擦/延迟）、感知（物体位姿/点云噪声）、几何（网格重建/抓取点偏移）、接触（软指/形变）。与其祈祷误差很小，不如显式量化一个迁移半径 r_trans，并从每个门的通过边际 m_i 里扣掉它：只有 m_i ≥ τ_i + r_trans,i 才算通过。r_trans 一半来自模型（Lipschitz 传播的误差上界），一半来自现实标定（保形分位数）。这等于把「在仿真里为真」改写成「在现实里以至少 1−α 概率为真」，代价是执行集收缩——这是可接受、且必须诚实标出的代价。

**严谨定义（形式化目标，增量）**：

1. **抓取模式** g = ({p_i, n_i, μ_i, σ_i}_{i=1}^{n_c}, gripper_pose, finger_cfg)，σ_i ∈ {stick, slip, free}。抓取证书 kc_grasp(g, Δ) 为两部分合取：
   - 鲁棒力闭包：ε_FC(g; Δ) = min_{δ∈Δ} max{ε : ε·B_6 ⊆ conv(∪_i FC_{μ_i(δ)}(n_i(δ)))} ≥ τ_FC；
   - 鲁棒力旋量包含：∀δ∈Δ, w_req(x; δ) ∈ (1−κ_w)·GWS(g; δ)，κ_w 为旋量安全裕度。
2. **不确定集** Δ = Δ_dyn × Δ_perc × Δ_geo × Δ_fric，以区间/椭球/场景集表示，半径向量 ε = (ε_dyn, ε_perc, ε_geo, ε_fric)。
3. **迁移半径** r_trans,i = L_i·(ε_dyn+ε_perc+ε_geo+ε_fric) + q_{α,i}，其中 L_i 为第 i 门边际对扰动的 Lipschitz 常数，q_{α,i} 为现实标定残差 s_i = m_i^sim − m_i^real 的 (1−α) 保形分位数。
4. **鲁棒阈值** τ_i^6 = τ_i^5 + r_trans,i（所有门统一写成「边际 ≥ 阈值」的规范形），故 τ^6 ≥ τ^5，只紧不松。
5. **联合提议**：π_θ^GM(g,x|c) = π_φ^GMK(g|c_g)·π_ψ^FMPP(x|c,g)，先采样抓取模式、再以抓取 token 条件化轨迹流；级联先筛抓取证书，再评轨迹门。
6. **执行集** Exec_v6 = {(g,x) ∈ supp(π^GM) : kc_grasp(g;Δ)=1 ∧ ∧_i kc_i(x,c,g;τ_i^6)=1} ⊆ Exec_v5。

**关键洞见**：v5 回答「提议可换时门是否仍可信」；v6 回答「连抓取前提和仿真模型本身都不可全信时，证书还能信什么」。答案是：把抓取前提变成可证伪的证书，把仿真-现实差距变成显式误差预算并从边际中扣除；门仍不增，嵌套仍保持，但证书从「模型内真」升级为「带分布假设的现实概率真」——并把这个假设本身作为最大风险公开标出。副产品：抓取证书同时为 v5 的 R57（固化自指回路）提供外部真值——只有现实结局验证通过的抓取片段才允许固化，部分打断「自己铸证、自己学习」的闭环。

**本轮最大风险**：**迁移证书的分布假设静默失效**——保形/鲁棒保证依赖「标定与测试同分布（或密度比有界）」与「不确定集 Δ 覆盖真实差距」；一旦新物体、新摩擦、新传感器使真实分布越出假设支撑，覆盖率保证就变成空话，而系统因「有证书」反而更自信，形成比无证书更危险的假安全。

```python
@dataclass
class GraspModeKernel:
    """GMK：抓取模式采样 + 鲁棒力闭包证书。
    红线：kc_grasp 是 MSRG/EEK 的内部合取项，不是第八道硬门。"""
    sampler: Any                 # 抓取模式流/扩散：点云+几何嵌入 → 接触点/夹爪位姿/摩擦假设
    tau_fc: float = 0.15         # 归一化 Ferrari-Canny 边际阈值
    kappa_w: float = 0.1         # 力旋量包含安全裕度
    delta: UncertaintySet        # Δ：场景集 + 区间松弛

    def propose(self, cloud, geo_emb, k_g: int = 6) -> list[GraspMode]:
        gs = self.sampler.sample(cloud, geo_emb, k_g)
        return [project_contacts_to_surface(g, cloud) for g in gs]

    def force_closure_margin(self, g: GraspMode, delta: UncertaintySet) -> float:
        """min_{δ∈Δ} Ferrari-Canny ε：在摩擦锥多面体上最大化最小抗力旋量
        （LP/QP）；Δ 用场景集采样 + 区间最坏情形松弛近似"""
        eps = min(fc_epsilon(g, d) for d in delta.scenarios)
        return eps - delta.interval_slack(g)

    def certify(self, g: GraspMode, x: Trajectory, delta: UncertaintySet) -> GraspCert:
        eps = self.force_closure_margin(g, delta)
        contained = all(
            wrench_in_gws(w_req(x, d), g, d, 1.0 - self.kappa_w)
            for d in delta.scenarios
        )
        ok = (eps >= self.tau_fc) and contained
        return GraspCert(ok=ok, eps=eps, mode=g.mode, witness=delta.witness(g))

    def _fallback(self, g: GraspMode) -> GraspMode:
```

### IP-498 TRK：迁移鲁棒核（离线标定 + 在线 O(1) 阈值）

```python
@dataclass
class TransferRobustnessKernel:
    """TRK：把仿真-现实误差预算折成阈值收紧。
    定理 10：m_sim ≥ τ^5 + r_trans ⇒ m_real ≥ τ^5（概率 ≥ 1−α）"""
    lipschitz: dict              # L_i：第 i 门边际对扰动范数的 Lipschitz 常数
    eps_budget: dict             # {'dyn','perc','geo','fric'} 误差半径
    conformal_q: dict            # 每门标定残差的 (1−α) 分位数 q_i
    alpha: float = 0.05

    def radius(self, gate: str) -> float:
        e = self.eps_budget
        model_part = self.lipschitz[gate] * (e['dyn'] + e['perc'] + e['geo'] + e['fric'])
        return model_part + self.conformal_q[gate]

    def robust_tau(self, tau5: float, gate: str) -> float:
        # 规范形：门 = 1[边际 ≥ 阈值]；只加不减 ⇒ 只紧不松
        return tau5 + self.radius(gate)

        标定集必须按站点/物体族分层，禁止跨域混标"""
```

### IP-499 GMPP：抓取-运动联合提议（乘积空间级联）

```python
@dataclass
class GraspMotionProposal:
    """GMPP：先抓取、后轨迹；抓取 token 条件化轨迹流。"""
    gmk: GraspModeKernel
    fmpp: FlowMatchingProposalPolicyKernel   # IP-493，条件接口扩展 τ(g)

    def propose(self, ctx: Context, k_g: int = 6, k_x: int = 4):
        out = []
        for g in self.gmk.propose(ctx.cloud, ctx.geo_emb, k_g):
            c_g = ctx.with_grasp_token(g)     # 接触点/法向/摩擦/夹爪位姿 → token
            for x in self.fmpp.propose(c_g, k_x):
                out.append((g, x))
        return out
```

### IP-500 EFA-v6：七硬门 + 抓取证书 + 鲁棒阈值 + 两级级联

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：门集合不变；先抓取证书筛，再轨迹级联。
    定理 12：Exec_v6 ⊆ Exec_v5，七锚不变。"""
    gmpp: GraspMotionProposal
    gmk: GraspModeKernel
    trk: TransferRobustnessKernel
    v5: EvidenceForgingAssemblerV5          # 复用 FAMK/VACK/BCK/EEK/LMEM-v2 全套

    def select(self, x0_state, t_now, rule_id, context):
        s_emo = self.v5.famk.observe(context.face, t_now)
        gamma = self.v5.famk.gamma(s_emo)                    # 情感只紧
        tau5 = {i: gamma[i] * TAU4[i] for i in GATES}        # v5 阈值
        tau6 = {i: self.trk.robust_tau(tau5[i], i) for i in GATES}  # 迁移再紧

        cands = self.gmpp.propose(context.with_affect(s_emo), K_g, K_x)

        # 级联第 0 层：抓取证书（LP/QP，~0.2–1 ms/个），先淘汰不可抓
        cert = [(g, x) for (g, x) in cands if self.gmk.certify(g, x, self.gmk.delta).ok]
        if not cert:
            return self._fallback_rule_proposal(tau6)        # fail-closed 回退规则抓取+轨迹

        # 级联第 1 层：廉价轨迹门（coverage/physics/memory/novelty，O(1)~O(log|M|)）
        surv = [(g, x) for (g, x) in cert if self._cheap_gates(x, g, tau6)]
        if not surv:
            return self._fallback_rule_proposal(tau6)

        # 级联第 2 层：VACK 仅评 ≤3 幸存者（预筛省昂贵调用）
        surv.sort(key=lambda gx: self._prefilter_score(*gx), reverse=True)
        finals = []
        for g, x in surv[:3]:
            vac = self.v5.v4.vack.evaluate(x, context.with_grasp(g, s_emo), t_now)
            if self.v5.v4.vack.kc_val(vac, tau=tau6['val']):
                finals.append((g, x))

        # 级联第 3 层：BCK 轨迹预览（事件触发 QP + 缓存证书内插）
        ok = [(g, x) for (g, x) in finals if self._bck_preview(x, g, tau6)]
        if not ok:
            return False, None, 'ALL_CANDIDATES_REJECTED'

        best = max(ok, key=lambda gx: certified_margin(*gx))  # 通过者中取边际最大者
        return True, best, 'FORGED_TGC'

    def ecs_v6(self, ..., eps_fc: float, r_trans: float) -> float:
        eta_grasp = sigmoid(eps_fc - B_FC)
        eta_trans = min(exp(-r_trans / t) for t in TAU5.values())
        return self.v5.ecs_v5(...) * eta_grasp * eta_trans
```

## 4. 正确性论证（增量更新）

### 引理 45（Ferrari-Canny 边际 Lipschitz）

**陈述**：对接触点 p_i、法向 n_i、摩擦系数 μ_i 的有界扰动，|ε_FC(g;δ) − ε_FC(g;0)| ≤ L_fc·(‖Δp‖+‖Δn‖+‖Δμ‖)，L_fc = O(n_c·max(1,μ_max)/σ_min(G))。**证明**：摩擦锥多面体顶点对参数连续，线性规划值函数在凸紧集上 Lipschitz。∎

### 引理 46（力旋量边际扰动传播）

**陈述**：‖w_req(x;δ) − w_req(x;0)‖ ≤ L_w·‖δ‖，L_w 由质量矩阵、雅可比与接触力上界给出；故力旋量包含边际的扰动 ≤ L_w·‖δ‖。∎

### 定理 9（抓取细化可靠性 / 前提闭合）

**陈述**：令 kc_phys^6 = kc_phys^5 ∧ kc_grasp^robust，kc_ee^6 = kc_ee^5 ∧ kc_reach，则 (i) Exec_v6 ⊆ Exec_v5；(ii) 七锚集合不变；(iii) (g,x)∈Exec_v6 ⇒ g 鲁棒力闭包且 w_req ∈ (1−κ_w)GWS。**证明**：合取引入只减不增；kc_grasp 位于 MSRG/EEK 内部，不构成新锚。∎

### 定理 10（鲁棒迁移保证）

**陈述**：在 (T1) Lipschitz 传播、(T2) 真实边际下界含标定残差 s_i、(T3) ‖δ_true‖ ≤ ‖ε‖_1 下，若 m_i^sim ≥ τ_i^5 + L_i‖ε‖_1 + q_i，则 P(m_i^real ≥ τ_i^5) ≥ 1−α_i；七门并集界给出单次决策真实违例 ≤ Σ_i α_i。**证明**：三角不等式逐项扣减 + 保形分位数定义 + 并集界。∎

**诚实边界**：保证条件于 (T2)(T3)。L_i 由最坏情形推出，通常偏保守；Δ 若漏掉真实 δ_true（新摩擦律、软指形变、未建模延迟），保证静默失效。因此 assume_check 必须在每次跨域部署时重跑，不通过则退回固定安全因子模式。

### 定理 11（保形覆盖与漂移边界）

**陈述**：(i) 可交换 ⇒ split conformal 覆盖 ≥ 1−α（有限样本、无分布假设）；(ii) 协变量漂移且密度比 w ≤ W ⇒ 加权保形覆盖 ≥ 1−α，n_eff ≈ n/W²；(iii) 支撑不匹配或 W 无界 ⇒ 保证为空。**证明**：标准 split conformal + 加权分位数 + 有效样本量。∎

**诚实边界**：仿真-现实一般不满足交换性，q_α 只能作为按站点/物体族重标定的先验，不是关于现实的定理；部署域必须重新标定并报告 n_eff 与经验覆盖率。

### 定理 12（v6 总装：双重收紧与嵌套）

**陈述**：在 v5 (B1)~(B7) 与 (T1)~(T3) 下：(i) Exec_v6 ⊆ Exec_v5 ⊆ … ⊆ Exec_v29；(ii) 抓取证书闭合前提空洞但不增锚；(iii) τ^6 ≥ τ^5，γ≡1 且 r_trans≡0 时精确退化 v5；(iv) 单次决策真实违例 ≤ Σ_i α_i + P(δ_true ∉ Δ)；(v) 七锚完备性保持；(vi) 保守性由 ρ 量化。**证明**：(i)(iii) 合取与阈值单调；(ii)(v) 定理 9/8；(iv) 定理 10/11 并集界。∎

**诚实声明**：(a) 迁移保证是条件性的，最大风险是 Δ 漏掉真实差距导致静默失效；(b) 抓取证书假设点接触 + 线性化摩擦锥，软指/形变/非点接触下模型失配；(c) 鲁棒化会收缩执行集（ρ 随误差预算增大），过度保守在狭窄场景可能拒绝所有候选而频繁回退；(d) 保形标定需要每站点足量且同分布的现实验证数据，冷启动站点无法给出保证；(e) v5 的加性价值假设 (B4) 与固化博弈残余风险继续继承。

## 7. 本轮最大风险（最终确认）

**一句话**：**迁移证书的分布假设静默失效**——保形/鲁棒保证依赖「标定与测试同分布（或密度比有界）」与「不确定集 Δ 覆盖真实差距」，一旦新物体、新摩擦、新传感器使真实分布越出假设支撑，覆盖率保证就变成空话，而系统因「有证书」反而更自信，形成比无证书更危险的假安全。
