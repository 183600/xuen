# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感驱动研究循环第 2 轮；本轮灵感：「数据集构建」×「服务设计」）

> 第 54 轮把技能组合升级为动作-鲁棒性双证书（α_S、ρ、A_cert、γ_ce、δ_a），但所有证书的“真值”都来自数据集与仿真：α_S 由采样校准，ρ 由仿真维度谱估计，Explain 由反例驱动。本轮追问一个更上游的问题：**这些数据从哪来、为谁而建、如何被服务消费**。核心矛盾：H22：数据集覆盖的是“可采集动作”，而非“服务所需动作”，数据集-服务错配会让证书在真实服务边界失效；H23：服务设计（SLA / 用户旅程 / 前台后台）与机器级证书（ρ / A_cert）之间缺少可翻译的契约，导致“证书通过但服务不可用”。

## 0. 直觉与动机

**灵感 1（数据集即证书：每个数据点都是动作空间的覆盖见证）**
直觉：第 54 轮的 α_S 与 ρ 都需要数据来“作证”。与其把数据集看成训练原料，不如把每个数据点看成动作空间 `A` 上的一个覆盖见证（witness）。数据集 `D` 因此拥有自己的覆盖剖面 `δ_D(a)` 与覆盖证书 `C_D=(A_cover, δ_min, H_D, π_D)`。只有当 `C_D` 覆盖某技能的 `A_core` 时，该技能的 `ρ/A_cert` 才有资格被签发。这把“数据够不够”从主观判断变成**可验证的覆盖证明**。

**灵感 2（服务蓝图化：前台服务、后台技能、支撑过程、证据通道）**
直觉：服务设计学把系统拆成 front-stage（用户可见服务）、back-stage（技能/云边执行）、support processes（数据、校准、证书）、evidence（用户可感知的证据）。把第 54 轮能力体系映射为服务蓝图 `B_S=(F,K,P,E)`：前台暴露“服务”，后台由技能组合图 `G_S` 支撑，支撑过程正是数据集构建与证书签发，证据通道是 Explain 与证书。服务设计因此不是 UI 包装，而是**证书到用户承诺的映射层**。

**灵感 3（数据-服务飞轮：服务遥测回流数据集，但必须带反事实探索配额）**
直觉：部署后的服务产生遥测，天然是下一轮数据集。若只用成功轨迹回流，会形成“幸存者偏差闭环”：服务越常用某动作，数据越偏向该动作，证书越自信，服务越倾向该动作。为此飞轮必须强制 **反事实探索配额 ε_t**：每轮至少 ε_min 比例的数据来自低覆盖动作格，否则拒绝更新证书。飞轮状态 `(D_t, θ_t, S_t)` 的稳定性由覆盖单调性与漂移上界保证。

**灵感 4（服务级证书：把 ρ/A_cert 翻译成用户可感知的 SLO）**
直觉：机器级 ρ 说“在扰动维度 d 上成功率为 0.93”，但用户只关心“任务成功、响应及时、不伤人、体感平顺”。需要一个单调的服务质量转移 `ψ: ρ → q`，并用保形预测（conformal）校准 SLO：`P(q_j ≥ q_j^min) ≥ 1-ε_j`。服务级证书 `SLC=(q, ρ, A_cert, γ_ce, SLA, conf)` 才是可对用户/监管承诺的东西；机器证书是它的证据，不是它的替代。

**灵感 5（数据集构建的服务化：数据服务契约 DSC）**
直觉：把数据集构建当成一种内部服务：数据提供方对消费方（技能认证器）承诺 `DSC=(A_req, θ_d, T_fresh, β_bias, π_req)`。认证器不直接信任数据集，而是验证 `C_D` 是否覆盖 `A_core`。这把数据工程与证书体系用“服务契约”解耦，支持多方数据供给与可审计的供应链。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（数据集覆盖剖面与覆盖证书）**
数据集 `D = {(x_i, a_i, y_i, p_i)}`，`a_i∈A` 为动作格，`p_i` 为溯源标签。去重后的有效样本数 `n_eff(a)`，覆盖剖面
```
δ_D(a) = 1 - exp(-n_eff(a)/n_0)
```
`A_cover = {a | δ_D(a) ≥ θ_d}`。覆盖证书 `C_D = (A_cover, δ_min, H_D, π_D)`，其中 `δ_min = min_{a∈A_cover} δ_D(a)`，`H_D` 为动作格覆盖熵（衡量均衡性），`π_D` 为溯源 DAG。称 **D 支持技能 S** 当且仅当
```
A_core(S) ⊆ A_cover  ∧  min_{a∈A_core(S)} δ_D(a) ≥ θ_d
```

**定义 122（数据集-动作对齐与分布漂移）**
加权对齐度
```
align(D,S) = Σ_a min(δ_D(a), α_S(a)) / Σ_a max(δ_D(a), α_S(a))
```
分布漂移 `W_1(D, P_deploy) ≤ ε_shift`（一阶 Wasserstein）。证书在部署域有效当且仅当
```
align(D,S) ≥ θ_align  ∧  W_1(D,P_deploy) ≤ ε_shift
```

**定义 123（服务蓝图）**
`B_S = (F, K, P, E)`：
- `F` 前台服务集合，每个 `f∈F` 附带契约 `(T_f, SLA_f, cert_ref(f))`；
- `K ⊆ G_S` 后台技能子图；
- `P` 支撑过程：数据构建、校准、证书签发；
- `E = {C_D, J, SLC, Explain}` 证据通道。

**蓝图一致性**：`∀f∈F`，`cert_ref(f)` 的 `A_core` 覆盖 `A_req(f)`，且其 SLO 由 `SLC` 兑现；否则蓝图不一致，服务不可发布。

**定义 124（服务级证书 SLC）**
```
SLC = (q, ρ, A_cert, γ_ce, SLA, conf)
```
`q = ψ(ρ, A_cert)` 为单调服务质量转移（ψ 在每个分量上非减）；`SLO_j: P(q_j ≥ q_j^min) ≥ 1-ε_j`；`conf` 为保形校准集上的经验覆盖。发布条件：所有 SLO 满足且证书链 `C_D → J → SLC` 完整可验。

**定义 125（数据服务契约 DSC）**
```
DSC = (A_req, θ_d, T_fresh, β_bias, π_req)
```
提供方承诺：`∀a∈A_req, δ_D(a) ≥ θ_d`；数据陈旧度 `staleness(D) ≤ T_fresh`；覆盖不均衡 `imbalance(C_D) ≤ β_bias`；溯源满足 `π_req`。消费方（技能认证器）验证失败即拒绝，不进入证书链。

**定义 126（数据-服务飞轮与探索配额）**
状态 `(D_t, θ_t, S_t)`，更新
```
D_{t+1} = D_t ∪ Tel(S_t) ∪ Explore(ε_t)
```
其中 `Tel(S_t)` 为服务遥测，`Explore(ε_t)` 强制从低覆盖动作格采样的比例 `≥ ε_min`。**飞轮稳定条件**：
```
A_req ⊆ A_cover(D_{t+1})  ∧  W_1(D_{t+1},P_deploy) ≤ ε_shift  ∧  revalidate(C_D, θ_{t+1}) = pass
```
若任一条不满足，则冻结证书更新并回滚到上一稳定态。

## 2. 关键算法 伪代码

### IP-121 DCC（Dataset Coverage Certificate）

```python
def coverage_gain(D, skill, x, theta_d):
    a = x.action_cell
    if a not in skill.A_core: return 0.0
    return max(0.0, min(theta_d, delta_D(D, a) + x.weight) - delta_D(D, a))

def build_dataset(candidates, skills, budget, theta_d):
    D = []
    while budget > 0 and candidates:
        x = max(candidates, key=lambda x: coverage_gain(D, x.skill, x, theta_d) / x.cost)
        D.append(x); candidates.remove(x); budget -= x.cost
    C_D = dataset_certificate(D, skills, theta_d)
    return D, C_D   # 次模贪心，覆盖增益 ≥ (1-1/e) 最优
```

### IP-122 SBD（Service Blueprint Design）

```python
def design_blueprint(services, G, certs, A_req):
    F = services
    K = select_backstage(G, required=union(A_req[f] for f in F))
    P = [dataset_pipeline, calibration, certifier]
    E = [certs['C_D'], certs['J'], certs['SLC'], Explain]
    for f in F:
        if not subset(A_req[f], certs[f.cert_ref].A_core):
            return ('reject', 'blueprint_inconsistent', f)
        if not slo_implied(certs[f.cert_ref], f.SLA):
            return ('reject', 'slo_not_implied', f)
    return ('ok', Blueprint(F, K, P, E))
```

### IP-123 DSF（Data-Service Flywheel）

```python
def flywheel_step(D, theta, S, eps_min):
    tel = collect_telemetry(S)
    low = low_coverage_cells(D, theta, top_k=0.2)
    n_explore = int(eps_min * len(tel) / (1 - eps_min))
    explore = sample_counterfactual(low, n_explore)
    D_new = D + tel + explore
    C_D = dataset_certificate(D_new, theta.skills)
    if not revalidate(C_D, theta) or drift(D_new, P_deploy) > EPS_SHIFT:
        return ('freeze', rollback(D))
    theta_new = recalibrate(theta, D_new)
    return ('ok', D_new, theta_new, C_D)
```

### IP-124 SLT（Service-Level Translation）

```python
def service_level_certificate(rho, A_cert, psi, calib_set, alpha):
    q = psi(rho, A_cert)                       # 单调转移
    q_lo = {j: conformal_lower(q[j], calib_set[j], alpha) for j in q}
    if any(q_lo[j] < SLA[j].q_min for j in q):
        return ('reject', 'slo_unreachable', q_lo)
    return ('ok', SLC(q, q_lo, rho, A_cert, SLA, conf=1-alpha))
```

### IP-125 DSC（Data Service Contract Verify）

```python
def verify_dsc(D, dsc):
    C_D = dataset_certificate(D, skills_of(dsc.A_req))
    if not subset(dsc.A_req, C_D.A_cover): return ('reject', 'coverage')
    if staleness(D) > dsc.T_fresh:        return ('reject', 'freshness')
    if imbalance(C_D) > dsc.beta_bias:    return ('reject', 'bias')
    if not provenance_ok(C_D.pi, dsc.pi_req): return ('reject', 'provenance')
    return ('accept', C_D)
```

### IP-126 CSD（Counterfactual Service Data）

```python
def counterfactual_augment(D, policy, propensities):
    # 逆倾向加权，修正服务策略导致的选择偏差
    w = [1.0 / max(propensities[rec.action | rec.context], P_FLOOR) for rec in D]
    w = clip_normalize(w, W_MAX)
    return WeightedDataset(D, weights=w)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| DCC | O(|C|·|A_core|) 贪心 | O(|D|) | 次模性、覆盖增益下界 1-1/e |
| SBD | O(|F|·|K| + |E|) | O(|F|+|K|) | 蓝图一致性可判定 |
| DSF | O(|D|+|Tel|+|Explore|) / 轮 | O(|D|) | 探索配额、漂移上界 |
| SLT | O(|calib|·|q|) | O(|calib|) | ψ 单调、保形覆盖 |
| DSC | O(|A_req|) | O(1) | 契约 sound、四条件合取 |
| CSD | O(|D|) | O(|D|) | 倾向正确时 IPS 无偏 |

**正确性定理（Data-Service Certificate Soundness）**
假设第 54 轮 (A26)–(A28) 成立；新增 **(A29)** `C_D` 的 `n_eff` 去重可靠、`δ_D` 为有效样本密度的下界；**(A30)** 服务遥测采样与部署分布满足协变量重叠（overlap）；**(A31)** `ψ` 单调且保形校准在名义水平 `1-α` 下有效；**(A32)** 探索配额 `ε_t ≥ ε_min > 0` 长期成立。
则对任一前台服务 `f`，其 SLO 满足
```
P(∀j: q_j ≥ q_j^min) ≥ 1 - Σ_j ε_j - P(W_1(D,P_deploy) > ε_shift) - P(bias(D) > β_bias)
```
关键：**数据集覆盖先于证书签发**，**服务承诺由证书链兑现**，**飞轮靠反事实配额防自证循环**。

## 4. 实验设计 E162–E166

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 覆盖-证书有效性曲线 | `δ_D` 阈值 vs 下游证书有效率 | δ_D ≥ 0.8 时有效率 ≥ 95% |
| E163 数据集构建效率 | 单位标注预算覆盖增益 vs 均匀采样 | 覆盖增益 ≥ +30% |
| E164 服务蓝图一致性检测 | 前台 SLO 违约的检出率 / 误报率 | 检出 ≥ 90%，误报 ≤ 5% |
| E165 飞轮漂移与探索配额消融 | 有/无 ε_min 的长期性能与覆盖熵 | 偏差导致退化降低 ≥ 40% |
| E166 服务级证书校准 | 经验 SLO 覆盖 vs 名义覆盖 | 偏差 ≤ 0.03 |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 覆盖证书被 Goodhart 刷分 | 高 | 外部 holdout + 反事实探索 + 溯源审计 |
| 服务蓝图过度抽象、不可执行 | 中 | 每层强制证书引用 + 蓝图可执行化检查 |
| 飞轮选择偏差 / 幸存者偏差 | 高 | IPS 加权 + ε_min 探索配额 + 冷启动锚点 |
| ψ 服务质量转移误设 | 高 | 保形校准 + 分段单调性检验 + 人因实验 |
| 数据供应链投毒 | 中 | 溯源 DAG + 数据签名 + 影响函数筛查 |

## 6. 本轮最大风险

**一句话**：数据集-服务飞轮让“覆盖证书”与“服务级证书”互相背书，但其 soundness **同时依赖数据覆盖的真实性、服务遥测的重叠性、以及 ψ 转移的保形有效性**；一旦覆盖指标被当作优化目标而脱离真实部署分布（Goodhart），且飞轮只回流成功轨迹（幸存者偏差），系统会收敛到一个自洽却对部署无效的“证书气泡”，故必须以 **反事实探索配额 + 外部留出集 + 溯源审计** 三重护栏，宁可证书保守失效，也绝不让数据集与服务的互相印证替代真实世界证据。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-ServeData（DCC×SBD×DSF×SLT×DSC×CSD）

> 承接第 54 轮产物 v31（GroundEdge-GenSim+++）。本轮在动作-鲁棒性双证书之上，补齐**数据的上游来源**与**服务的下游承诺**，新增六个算子：

## 2. 关键算法 伪代码

### IP-121 DCC

```python
def delta_D(D, a, n0):
    n_eff = provenance_dedup_count(D, a)
    return 1.0 - math.exp(-n_eff / n0)

def dataset_certificate(D, skills, theta_d):
    A_cover = {a for a in action_cells(D) if delta_D(D, a, N0) >= theta_d}
    delta_min = min((delta_D(D, a, N0) for a in A_cover), default=0.0)
    H_D = entropy(coverage_distribution(D, A_cover))
    pi_D = provenance_dag(D)
    return CoverageCert(A_cover, delta_min, H_D, pi_D)

def build_dataset(candidates, skills, budget, theta_d):
    D = []
    while budget > 0 and candidates:
        x = max(candidates, key=lambda x: coverage_gain(D, x.skill, x, theta_d) / x.cost)
        D.append(x); candidates.remove(x); budget -= x.cost
    return D, dataset_certificate(D, skills, theta_d)
```

```python
    return ('ok', SLC(q, q_lo, rho, A_cert, SLA, conf=1 - alpha))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DCC | O(|C|·|A_core|) 贪心 | O(|D|) | 次模贪心覆盖 ≥ (1-1/e)·OPT |
| SBD | O(|F|·|K| + |E|) | O(|F|+|K|) | 蓝图一致性 sound、SLO 可蕴含 |
| DSF | O(|D|+|Tel|+|Explore|) / 轮 | O(|D|) | 探索配额 + 漂移上界 + 冻结回滚 |
| SLT | O(|calib|·|q|) | O(|calib|) | ψ 单调 + 保形覆盖 1-α |
| DSC | O(|A_req|) | O(1) | 四条件合取 sound |
| CSD | O(|D|) | O(|D|) | 倾向正确时 IPS 无偏、ESS 可监控 |

**正确性定理（Data-Service Certificate Soundness）**
假设第 54 轮 (A26)-(A28) 成立；新增 **(A29)** `n_eff` 去重可靠、`δ_D` 为有效密度下界；**(A30)** 遥测采样与部署分布满足协变量重叠；**(A31)** `ψ` 单调且保形校准名义水平 `1-α` 有效；**(A32)** `ε_t ≥ ε_min > 0` 长期成立。
则对任一前台服务 `f`：
```
P(∀j: q_j ≥ q_j^min) ≥ 1 - Σ_j ε_j - P(W_1(D,P_deploy) > ε_shift) - P(bias(D) > β_bias)
```
关键：**数据集覆盖先于证书签发**（DCC/DSC），**服务承诺由证书链兑现**（SBD/SLT），**飞轮靠反事实配额防自证循环**（DSF/CSD）。

## 5. 本轮最大风险

**一句话**：数据集-服务飞轮让“覆盖证书”与“服务级证书”互相背书，但其 soundness **同时依赖数据覆盖的真实性、服务遥测的重叠性、以及 ψ 转移的保形有效性**；一旦覆盖指标被当作优化目标而脱离真实部署分布（Goodhart），且飞轮只回流成功轨迹（幸存者偏差），系统会收敛到一个自洽却对部署无效的“证书气泡”，故必须以 **反事实探索配额 + 外部留出集 + 溯源审计** 三重护栏，宁可证书保守失效，也绝不让数据集与服务的互相印证替代真实世界证据。
