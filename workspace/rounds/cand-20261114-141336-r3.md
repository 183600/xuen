# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「深度学习」×「VLA」）

> R69 把不确定性一分为二，并让 epistemic 去「问」。但它默认了一件事：**生成模态、生成问题、解释答案的，是同一个学出来的模型**。深度学习最基本的一条经验恰恰是：神经网络可以**自洽地、自信地错**——置信度不等于胜任度，错误是**系统性相关**的，而不是独立噪声。R69 的模态熵度量的是「模型内部自洽」，不是「对世界的正确」；一旦模型对世界的表示本身错了（M-open / 误设定），再多的采样、再礼貌的提问，都只是在**错误的信念空间里自我确认**——你不能靠反复采样一个错模型，把自己采样出错误。
>
> VLA 同时放大了这份能力与这份危险：视觉—语言—动作共享一个潜空间，泛化因此极强，但**一处接地（grounding）错误会同时污染看、说、做，连「该问什么」都被污染**。模型可能用自己错误的本体论去问一个诱导性问题，人类出于合作在模型的框架内作答，模型再用自己错误的似然把回答读成「确认」——**交互诱发的确认坍缩**。这正是 R69 最大风险（模态分布不可信 → 追问幻影 / 把误导回答认证）的**真正根因**：问题不在「问得够不够多」，而在「提问与解释的通道和犯错的是同一个模型」。
>
> 核心命题：**把 R69 的 epistemic 再三分——U_amb（模型内有能力消解的歧义）、U_ign（模型外的无知）、U_mis（系统性误设定 / 虚假接地）；只有 U_amb 交给 R69 的交互；U_ign 必须弃权 / 升级 / 交接；U_mis 只能用「与模型错误不相关的外生通道」（去相关集成分歧 + 反事实干预稳定性 + 独立验证器）来发现并隔离，绝不允许模型用自己的问题去确认自己。** 命名 **JURIS-RAS**（Jurisdiction-aware Uncertainty Routing with Independent Scrutiny）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我的知识管到哪、越界时谁说了算**」——不确定性不只需要一个提问，还需要一张**管辖边界**和一位**不能由被审者兼任的法官**。

## 0. 直觉与动机

**灵感 1（深度学习 → 自信地错）**
直觉：R69 的「多模态」来自同一个流模型对同一观测的多次采样。但这些模态共享同一套权重、同一套表示、同一套盲点。深度学习反复证明：在分布外或长尾，单个网络会给出**低熵却错误**的预测（overconfidence），且错误在样本间相关——一次错往往一片错。因此「模态熵低」不等于「我对」，只等于「我自己不矛盾」。R69 用熵算 VoI，等于**用一个可能系统偏斜的仪表去估计纠正这个偏斜的收益**：测量者与被测者同源。

**灵感 2（VLA → 共享潜空间是双刃剑，也是语言探针）**
直觉：VLA 把图像、指令、动作压进同一潜空间，带来组合泛化（「把红色的杯子放到盘子的左边」）。但这也意味着接地错误**跨模态传播**：把「红」错绑到「杯子」上，会同时污染视觉注意、语言指代、抓取动作，甚至污染它生成的问句。反过来，语言又给出一把**可执行的组合探针**：改一个不该改变答案的词（同义改写）、换一个该改变答案的属性（红→蓝）、调一个该保持答案的关系——若动作随之乱动，说明接地依赖的是虚假相关而非因果属性。这把「深度学习可解释性」变成了**可认证的反事实干预**。

**灵感 3（M-open / 误设定 → epistemic 也要分家，并落到「辖区」）**
直觉：R69 把 epistemic 当成「模型能表示、能通过信息消解的歧义」。但在统计上，若真分布不在假设类里（M-open），后验不确定性收敛到真值在模型类上的**投影**，残余偏差是模型自己「看不见」的——它的熵可以趋零，而误差仍大。这就是「过度自信的无知」。于是必须区分：**可消解的歧义**（问一下就好）、**模型外的无知**（问也没用，得学或交接）、**系统性误设定**（模型自信地错，问还会加剧）。更进一步，与其问「我有多确定」，不如问「**我有没有资格在这个区域下结论**」——把状态/指令空间划成「已认证胜任 / 歧义 / 无知 / 误设定」，且辖区是**模型 × 具身**的：同一潜动作在不同机器人上能力不同，跨具身迁移必须重新认证。

**灵感 4（集成 / OOD → 独立分歧是唯一外生第三意见）**
直觉：R69 的 FMA 用同一个流模型算「第二意见」，但同源模型的似然也带着同源盲点。真正的第三意见必须**错误不相关**：语言条件 VLA + 纯几何/模型-based 校验器 + 经典规划器，用不同归纳偏置「看」同一件事。分歧 δ 高 ⇒ 至少有一个错（充分但不必要）；结合 OOD energy 与「认证辖区」，才能在模型自报「低熵」时识破「自信地错」。一句可形式化的直觉：**模型内的采样与交互无法降低模型级无知，只有外生通道能。**

**灵感 5（自举 / 模型坍缩 → 交互确认坍缩）**
直觉：R69 让同一个模型既生成问题又解释答案。深度学习里「用自己输出训练自己」会导致 model collapse（分布收窄、多样性丧失）。交互有同构的病：模型用自己错误的本体论**预注册**了一个诱导性问题，人类在合作压力下顺着框架回答，模型用自己错误的似然把回答读成「确认」，后验反而更窄、更自信——「问错，比不问更危险」的机制就在这里。解药不是「少问」，而是**提问与解释必须去相关**：问题来自独立问题策略或预注册的、与当前信念无关的信息最大化码本；解释由独立验证器完成；且「问之前先登记问什么、答什么算支持/反对」，防止事后拟合。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（JURIS-RAS 总览）** JURIS-RAS = (KJM, DDA, CIL, GPL, OIQ, CCG, AEL, CDM, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **辖区标签不变式**：每个动作/信念必须携带辖区证书（模型版本 × 具身 × 时间戳）；无标签即视为不可信；
(iii) **独立证据纪律**：任何 U_mis 判定必须由与主模型错误**条件独立**的通道佐证；**禁止自证**——同一模型生成的问题与解读的答案不得单独定案；
(iv) **权柄单调不变式**：弃权/升级/交接只会降低或保持权柄，绝不提高；任何兜底路径下 λ 不低于 R69 同状态取值。

**定义 311（认知三分）** 在模型族 M、真分布 p*、辖区 J 下，把 R69 的 U_epi 拆为三项（语义不同，不求和）：
- **U_amb** = R69 的模态间可约熵（定义 297），**仅当** o∈J、集成分歧 δ≤τ_δ、干预不稳定度 ι≤τ_ι 时保留；
- **U_ign** = 1[o∉J] · H(M|o)：模型无资格表示的部分（M-open 残余），不可由模型内信息消解；
- **U_mis** = 1[δ>τ_δ ∨ ι>τ_ι]：系统性误设定/虚假接地的显式标记。
只有 U_amb 进入 R69 的 MINT（定义 298）；U_ign 进入 AEL 的弃权/升级；U_mis 进入隔离与重认证。

**定义 312（知识辖区图 KJM）** J = {(o) : δ_ens(o)≤τ_δ ∧ ι_CIL(o)≤τ_ι ∧ ECE(o)≤τ_ece ∧ s_energy(o)≤τ_e}，带标签 (model_ver, embodiment, timestamp)。辖区半径 ρ_J(o) = min 扰动使证书失效的幅度。辖区以**格/原型**存储，查询 O(1)。

**定义 313（去相关分歧通道 DDA）** 去相关集成 ℰ = {M_VLA, M_geo, M_plan, …}，两两**归纳偏置**不同（架构/输入模态/训练目标不同，而非仅随机种子）。分歧 δ(o) = 归一化成对动作距离（Fr_échet / W₂ 的均值）。energy 分数 s_energy 作廉价前置 OOD 探针。A100：给定真值，各成员错误条件独立（用于引理 19 的上界，也标注其可被打破的风险）。

**定义 314（反事实干预阶梯 CIL）** 最小干预集 T = {paraphrase π、attribute swap σ、relation swap ρ、distractor swap κ}。不稳定度 ι(o) = E_{τ∈T}[D(π_θ(·|o), π_θ(·|τ(o)))]。因果接地判据是**双向**的：对**保义**干预（π）要求变化 ≈0（不变性），对**变义**干预（σ,ρ）要求变化方向正确（敏感性）。只满足不变性而无敏感性 ⇒ 退化为忽略输入的捷径，同样判 U_mis。

**定义 315（接地溯源账本 GPL）** 账本 L: (symbol / referent) → (来源集合、独立性类、认证证据、时间戳、辖区标签)。动作 a 的权柄上限 cap(a) = min{cap(s) : s ∈ grounded(a), s 未认证}。未认证接地驱动的动作被降权；一条坏接地不得通过"总体似然高"洗白。

**定义 316（正交质询与预注册 OIQ）** 问题来源 Q_ind 必须与当前信念去相关：或来自**独立问题策略**、或来自与 o 无关的**信息最大化码本**。交互前**预注册**记录 (待验假设、各模态下的期望回答、支持/反对的判定规则)，提交后不可改写。执行后才允许读取回答——防止事后拟合（HARKing）。

**定义 317（确认坍缩卫兵 CCG）** 确认度 C = 回答对先验模态的支持度 − 独立先验下的期望支持度。若问题被判为诱导、或回答"过于确认"（预注册规则下不可伪证）、或回答在独立验证器下的似然比不足，则**不得采纳**，升级为弃权/交接。C 高不是好消息，而是"可能被自己的问题骗了"的警报。

**定义 318（弃权-升级阶梯 AEL）** 权柄级 L0 执行 / L1 执行+R69 兜底 / L2 安全探询或弃权 / L3 交接或请求人类授权。映射 (U_amb,U_ign,U_mis) → L 单调：U_ign>0 或 U_mis>0 时至少 L2；无独立证书不得回退到 L0/L1。交接携带完整溯源与不确定性证据，而非只报"我不确定"。

**定义 319（标定漂移监控 CDM）** 持续微调会使标定随表示漂移而失效（遗忘的"标定版"）。CDM 跟踪表示漂移与 ECE 对时间的变化；漂移 >τ_drift 或 ECE 越界即**吊销辖区**（时间戳失效），要求重认证。辖区不是永久执照。

**定义 320（辖区门控交互 MINT†）** 仅当 o∈J ∧ δ≤τ_δ ∧ ι≤τ_ι ∧ ECE≤τ_ece 且问题来自 OIQ 时，才允许 R69 的 MINT；回答的整合必须经**独立验证器**（定义 321），禁止用主模型自身似然更新。

**定义 321（去偏 VoI）** VoI_ind(g) = H(M|o) − E_{y~p_ind(·|g,o)}[H(M|o,y)]，其中 p_ind 为独立验证器（或与主模型错误条件独立的成员）的预测。决策用 VoI_ind − c(g) > 0；R69 的 VoI（在主模型 p_M 下计算）只是其"p_ind = p_M"的退化特例。二者之差 D(p_M‖p_ind) 即确认偏置的度量。

**定义 322（证书 J_JURIS）** J_JURIS = (J_FLUID, jurisdiction_id, δ_p95, ι_p95, energy_p95, gpl_coverage, confirmation_rate, authority_level, cdm_ver, juris_ver)。Valid ⇔ Valid(J_FLUID) ∧ 辖区未过期 ∧ GPL 覆盖执行动作 ∧ 独立证据纪律满足。

**定义 323（威胁模型 AIC-JURIS）** 辖区伪造（把 OOD 做成"看起来在辖区内"）、认证集投毒（污染留出集，使盲区被"认证"为胜任）、诱导性问题注入、**集成共谋**（所有成员共享同一偏置 ⇒ δ≈0 但全错）、溯源伪造。并入 AIC：ℰ_JURIS = ℰ_FLUID × ℰ_juris × ℰ_ensemble。

**定义 324（参与式审计 VQAuditor-J 与辖区对偶）** 审计辖区判定、确认率、GPL 缺口、升级是否恰当；结论回灌 AuditBuf 成为下一轮阈值先验。**辖区对偶**：自洽度（模态熵/似然）测「模型是否自相矛盾」，外生分歧 δ 测「模型是否可能在错误里自洽」；(自洽↑, δ↓) 是胜任，(自洽↑, δ↑) 是**自信地错**，(自洽↓, δ↓) 是无知，(自洽↓, δ↑) 是混乱——四象限可分离，构成 R69 的 (r_res, Δa) 对偶在"知识层"的镜像。

```python
# IP-264 KJM + IP-271 认知三分
def epistemic_partition(o, M, ens, cil, J):
    delta = ens.disagreement(o)              # 去相关集成
    iota  = cil.instability(M, o)            # 改写/属性/关系/干扰 探针
    in_j  = J.contains(o, model=M.ver, embodiment=M.emb, ece=M.ece)
    e     = M.aud.epistemic_entropy(o)       # R69 U_epi 的模型内估计
    U_amb = e if (in_j and delta <= T_D and iota <= T_I) else 0.0
    U_ign = e if not in_j else 0.0           # 模型外的无知
    U_mis = 1.0 if (delta > T_D or iota > T_I) else 0.0
    return U_amb, U_ign, U_mis, delta, iota

# IP-265 DDA：去相关集成（架构/模态/目标不同，非仅 seed）
class DecorrelatedEnsemble:
    def disagreement(self, o):
        acts = [m.act(o) for m in self.members]      # VLA / geo / planner
        return pairwise_w2(acts)                      # 归一化

# IP-266 CIL：双向干预稳定性
def instability(policy, o):
    stable_ok = mean(dist(policy(o), policy(t(o))) for t in [paraphrase, distractor])
    sensitive = mean(directional_ok(policy(o), policy(t(o)))
                     for t in [attr_swap, relation_swap])
    return instab(stable_ok) + instab(1.0 - sensitive)   # 任一失败 → 高 ι

# IP-267 GPL：接地溯源 → 动作权柄上限
class ProvenanceLedger:
    def authority_cap(self, action):
        caps = [self.cap(s) for s in action.grounded_symbols if not self.certified(s)]
        return min(caps) if caps else 1.0

# IP-268/269/321 OIQ + CCG + 去偏 VoI
def orthogonal_interaction(modes, o, budget, verifier):
    rec = preregister(modes, o)                    # 先登记判定规则，不可改
    q = independent_question_policy(o)             # 与当前信念去相关
    if not budget.allow(q) or not c_ras_wm.certify_info(q, o):
        return ('NONE', None)
    y = execute(q)
    if verifier.confirmation_risk(rec, y) > TAU_CONF:   # 诱导 / 不可伪证
        return ('ESCALATE', y)
    if voI_ind(modes, q, verifier) - cost(q) <= 0:      # 去偏 VoI 判据
        return ('NONE', None)
    return ('ACCEPT', verifier.update(modes, y))        # 独立似然，非主模型

# IP-276 主闭环（先过知识辖区门，再回落到 R69）
def JURIS_RAS_round(M, obs):
    o = M.mtm.forward(...); M.cof.step(...)
    U_amb, U_ign, U_mis, delta, iota = epistemic_partition(o, M, M.ens, M.cil, M.J)
    # 1) 知识层先行：越界/误设定 ⇒ 禁止自证交互，fail-closed
    if U_ign > 0 or U_mis > 0:
        lvl = M.ael.level(U_amb, U_ign, U_mis)          # 至少 L2
        lam = LAM_MAX
        if lvl == 3: return M.ael.handoff(o, evidence=(delta, iota, U_amb))
        return M.ael.safe_probe(o), lam                 # 安全探询/弃权，不走 MINT
    # 2) 辖区内、无系统性风险 ⇒ 逐指令回落到 R69 的 U_amb 处置
    g = (M.mint.choose_interaction(...) if U_amb > T_EPI else None)
    if g is not None:
        tag, ans = orthogonal_interaction(...)          # OIQ + CCG + 去偏 VoI
        U_amb   = M.cia.update_belief(...) if tag == 'ACCEPT' else U_amb
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + (U_amb if g is None else 0.0)))
    k   = M.c_ras_wm.certified_prefix(...)
    # 3) 权柄受接地溯源与辖区约束
    k   = min(k, int(k * M.gpl.authority_cap(mode.a)))
    lam = max(lam, 1.0 - M.gpl.authority_cap(mode.a))
    # 4) 漂移监控：吊销过期辖区，强制重认证
    M.cdm.observe(o, M, M.J)
    M.vqa_j.submit_async(U_amb, U_ign, U_mis, delta, iota, tag)
    return k, lam, mode, (U_amb, U_ign, U_mis)
```

## 3. 推导

**引理 19（分歧是误设定的可靠证人）** 在 A100（给定真值，各成员错误条件独立）下，两个成员同时正确时不可能分歧，故 δ>0 ⇒ 至少一个成员错。因此**分歧是 U_mis 的充分证人（sound）**。但 δ=0 不证明正确（两成员可共享同一偏置），故必须由辖区 J 提供"必要性"侧的认证。系：DDA 只能"报警"，不能"担保"；担保只能来自独立留出集上的辖区认证。

**引理 20（模型内不可约的无知）** 设真分布 p* 不在假设类 M 内（M-open）。对任何保持信念在 M 内可表示的更新（含自采样、以 p_M 为似然的自我提问），在模型外区域上的期望误差有一个模型自身熵无法反映的**投影偏置** B_M>0。故以 p_M 计算的 VoI 可以为正，而真实期望误差下降 ≤0。系：**模型内的采样与交互不能降低模型级无知**；这正是 R69 把 U_ign 误当 U_amb 时会"越问越自信"的根源。

**引理 21（确认坍缩与去偏）** 若问题由 M 生成、回答以 p_M 为似然解释，则对任意回答，p_M 下的期望对数似然增益 ≥0（KL≥0），即使该模态为假；人类的合作性回答被 p_M 的错误本体论过滤，真实似然增益可 ≤0。改用与信念去相关的码本 Q_ind（Q_ind ⊥ M）与独立验证器 p_ind 后，期望真实增益 = I(M;Y|Q_ind) ≥ 0，且确认偏置被 D(p_M‖p_ind) 界定；预注册消除了事后拟合的自由度。故**去偏 VoI_ind 是真实增益的下界（至多差估计误差）**。

**定理 18（JURIS 严格包含 R69 / FLUID）** 当 o∈J、δ≤τ_δ、ι≤τ_ι、ECE 合规，且**取 Q_ind := R69 的问题策略并关闭预注册**时，U_ign=U_mis=0、U_amb=U_epi^{R69}，JURIS 与 R69 逐指令相同（同一 MINT、同一 λ、同一模态选择）。反之，当 U_ign>0 或 U_mis>0 时 JURIS 弃权/升级，而 R69 会继续交互；由引理 20 该交互无法降低真实误差、由引理 21 还可能抬高它，故 JURIS 期望风险 ≤ R69，且在越界区严格更小。结合权柄单调不变式，安全侧永不让步。⇒ **R69 是 JURIS 在「单一胜任模型、且信任自身质询」边界上的退化。**

**定理 19（弃权安全与无制度突变）** AEL 映射单调且 fail-closed：任一子模块（DDA/CIL/OIQ）超时、被覆盖、不可用时，λ→LAM_MAX、级至少升到 L2，绝不降权；L3 交接保持完整证据链。继承 R68 定理 15 的提交/换装不变式 ⇒ 控制连续、无突变。辖区吊销（CDM）只降低权柄，不改变安全包络。

**命题 20（辖区认证的循环性——本轮最大风险的严格版）** 辖区 J 由留出集 S 上的经验正确性与集成分歧共同定义。若 S 的抽样分布与模型共享同一虚假相关（或 covariate shift 下 OOD 检测本身不可靠），则存在 o∉supp(S) 使 J 误判 o 为"胜任"。从系统内部**无法**验证 S 与模型捷径的独立性；因此 J 的保证只在"S 独立于模型捷径"这一外部前提下成立。这决定了 JURIS 的安全上界不是定理 18 的无条件形式，而是一个**条件保证**。

## 6. 本轮最大风险

**一句话**：JURIS-RAS 的全部安全押在「辖区证书可信」这一前提上——但证书来自留出集与去相关集成，而**认证数据完全可能与模型共享同一个盲点**（covariate shift 下的 OOD 检测本身是深度学习未解问题，集成成员也可能共谋）：于是系统会在恰好吃错的地方**自信地宣布自己「在辖区内」**——**边界是用它本该检查的那张地图画出来的**（命题 20 的认证循环性）。此时定理 18 的无条件安全退化为条件安全，"越界即弃权"沦为"自认为没越界就继续猜"。

**次级风险与缓解**：
1. **集成共谋 / 同源偏置**（所有成员一起错 ⇒ δ≈0）→ 强制架构/模态/训练目标去相关 + GPL 交叉校验 + 辖区认证区误差上界（E310）；
2. **认证集投毒 / 辖区伪造**（把盲区认证成胜任）→ 留出集独立性审计 + 投毒检测 + E311 + ℰ_JURIS 对抗训练；
3. **诱导性问题注入**（OIQ 码本本身被攻破）→ 预注册不可改 + 独立验证器 + 单次交互不定案（引理 21）；
4. **弃权/交接的延迟与权柄落差**（L3 人类接管不及时）→ 无突变保证（定理 19）+ 安全包络不依赖交接 + E308 交接延迟压测；
5. **算力/延迟**（集成 + 4 探针）→ 异步协处理器 + 仅在可疑路径触发 + 主环 fail-closed 当拍生效。

```python
def epistemic_partition(o, M, ens, cil, J):
    delta = ens.disagreement(o); iota = cil.instability(M, o)
    in_j  = J.contains(o, model=M.ver, embodiment=M.emb, ece=M.ece)
    e     = M.aud.epistemic_entropy(o)

    U_ign = e if not in_j else 0.0

    if voI_ind(modes, q, verifier) - cost(q) <= 0:    return ('NONE', None)
    return ('ACCEPT', verifier.update(modes, y))      # 独立似然

# IP-276 主闭环（先辖区门，再回落 R69）
def JURIS_RAS_round(M, obs):
    o = M.mtm.forward(...); M.cof.step(...)
    U_amb, U_ign, U_mis, delta, iota = epistemic_partition(o, M, M.ens, M.cil, M.J)
    if U_ign > 0 or U_mis > 0:                          # 1) 越界 ⇒ fail-closed
        lvl = M.ael.level(U_amb, U_ign, U_mis)
        lam = LAM_MAX
        if lvl == 3: return M.ael.handoff(o, evidence=(delta, iota, U_amb))
        return M.ael.safe_probe(o), lam                 # 不走 MINT
    g = (M.mint.choose_interaction(...) if U_amb > T_EPI else None)   # 2) 回 R69
    if g is not None:
        tag, ans = orthogonal_interaction(...)
        U_amb = M.cia.update_belief(...) if tag == 'ACCEPT' else U_amb
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + (U_amb if g is None else 0.0)))
    k   = M.c_ras_wm.certified_prefix(...)
    k   = min(k, int(k * M.gpl.authority_cap(mode.a)))  # 3) 接地限权
    lam = max(lam, 1.0 - M.gpl.authority_cap(mode.a))
    M.cdm.observe(o, M, M.J)                            # 4) 吊销过期辖区
    M.vqa_j.submit_async(U_amb, U_ign, U_mis, delta, iota, tag)
    return k, lam, mode, (U_amb, U_ign, U_mis)
```

## 4. 推导

**引理 19（分歧是误设定的可靠证人）** A100（给定真值错误条件独立）下，两成员同时正确不可能分歧 ⇒ `δ>0 ⇒ 至少一个错`。故分歧是 U_mis 的**充分（sound）**证人；但 `δ=0` 不证明正确（可共享偏置），"必要性"只能由辖区 J 的留出认证提供。系：DDA 只能报警，不能担保。

**引理 20（模型内不可约的无知）** 真分布 `p*∉M`（M-open）时，任何保持信念在 M 内可表示的更新（自采样/以 `p_M` 为似然的自我提问）在模型外区域的期望误差存在模型自身熵无法反映的投影偏置 `B_M>0`；以 `p_M` 算的 VoI 可为正而真实误差下降 ≤0。系：模型内采样/交互不能降低模型级无知——R69 把 U_ign 当 U_amb 就会"越问越自信"。

**引理 21（确认坍缩与去偏）** 问题由 M 生成、回答以 `p_M` 解释时，`p_M` 下期望对数似然增益 ≥0（KL≥0），即使模态为假；合作性回答被 `p_M` 的本体论过滤，真实增益可 ≤0。改用 `Q_ind⊥M` 与独立验证器 `p_ind`：期望真实增益 `=I(M;Y|Q_ind)≥0`，确认偏置被 `D(p_M‖p_ind)` 界定；预注册消除事后拟合。故 `VoI_ind` 是真实增益的下界（至多差估计误差）。

**定理 18（JURIS 严格包含 R69 / FLUID）** 当 `o∈J ∧ δ≤τ_δ ∧ ι≤τ_ι ∧ ECE` 合规，且取 `Q_ind:=R69 问题策略`、关闭预注册时，`U_ign=U_mis=0`、`U_amb=U_epi^{R69}`，与 R69 **逐指令相同**。反之当 `U_ign>0 ∨ U_mis>0`，JURIS 弃权/升级而 R69 继续交互；由引理 20 该交互不能降低真实误差、由引理 21 还可能抬高它 ⇒ JURIS 期望风险 ≤ R69，越界区严格更小。结合权柄单调 ⇒ 安全侧不让步。**R69 = 「单一胜任模型 + 信任自身质询」边界**。

**定理 19（弃权安全与无制度突变）** AEL 单调且 fail-closed：任一子模块超时/被覆盖/不可用 ⇒ `λ→LAM_MAX`、级至少 L2，绝不降权；L3 交接保留完整证据链；继承 R68 定理 15 的提交/换装不变式 ⇒ 控制连续、无突变；辖区吊销只降权、不改安全包络。

**命题 20（辖区认证循环性——最大风险的严格版）** J 由留出集 S 上的经验正确性与集成分歧共同定义。若 S 与模型共享同一虚假相关（或 covariate shift 下 OOD 检测不可靠），则存在 `o∉supp(S)` 被误判为"胜任"。系统内部**无法**验证 S 与模型捷径的独立性；J 的保证仅在此外部前提下成立——定理 18 的无条件形式因此退化为**条件安全**。

## 7. 本轮最大风险

**一句话**：JURIS-RAS 的全部安全押在「辖区证书可信」上——但证书来自留出集与去相关集成，而**认证数据完全可能与模型共享同一个盲点**（covariate shift 下 OOD 检测本身是深度学习未解问题，集成成员也可能共谋）：于是系统会在恰好吃错的地方**自信地宣布自己「在辖区内」**——**边界是用它本该检查的那张地图画出来的**（命题 20 的认证循环性）；定理 18 的无条件安全退化为条件安全，"越界即弃权"沦为"自认为没越界就继续猜"。

**次级风险与缓解**：集成共谋/同源偏置（强制去相关 + GPL 交叉校验 + 认证区误差上界，E310）；认证集投毒/辖区伪造（留出集独立性审计 + E311 + ℰ_JURIS）；诱导问句注入（预注册不可改 + 独立验证器 + 单次交互不定案，引理 21）；弃权/交接延迟与权柄落差（无突变保证定理 19 + 安全包络不依赖交接 + E308）；算力/延迟（异步协处理器 + 仅可疑路径触发 + 主环 fail-closed 当拍生效）。
