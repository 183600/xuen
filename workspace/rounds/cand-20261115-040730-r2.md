# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「语音合成」×「模仿学习」）

> R69 做了一个漂亮的二分：aleatoric 收紧、epistemic 去问。但它有两个隐而未决的假设。
>
> 第一，**VoI 是在「模态后验」上算的**——而 R69 自己在最大风险里承认，模态后验可能未校准（幻觉模态 / 模态坍缩）。在一个错的信念上算出的 VoI，会把「去问一个幻影」当成划算买卖。
> 第二，**人只是一个「会回答的观测源」**——R69 把回答当带毒观测，用 k 源一致去洗；但它没有模型去回答「这个人面对这个问题会怎么说」「他有没有可能把自己的策略伪装成对的样子」。
>
> 本轮两个灵感正好补这两块：
> - **语音合成**给出「分析-综合」(analysis-by-synthesis) 的范式与一个**通信信道模型**：机器人可以把「若世界是 h₁ 我会听到什么、若是 h₂ 又会听到什么」先合成出来，用**合成的可分辨性**去验证问题本身值不值得问，而不是假设它值得。语音合成还逼出一个 R69 完全忽略的物理事实：问句要经过 TTS→空气→ASR 这条会失真的信道，语义上再好的问题，若两个候选回答在声学上不可分，就等于没问。
> - **模仿学习**给出一个更根本的视角：R69 的 FMA 似然通道，本质就是一个**模仿学习的分布外检测器**；而它失效的方式，正是模仿学习的原罪——**协变量偏移 (covariate shift)**：策略一旦偏离专家流形，密度估计就不可信，且误差沿时程按 T² 复合。模仿学习还给出解药：**交互式模仿 (DAgger)**——不要在漂移处继续「问」，而要在漂移处「请人示范」，把 T² 复合压回 T。
>
> 核心命题：**把「问」升级为「先综合验证、再问、问不到就请示范」；把「人」从被动的答案源升级为有模型、可能非平稳、可能策略性的教师；并用交互式模仿直接压缩 R69 依赖的似然通道所受的协变量偏移——即从内部修补 R69 的最大风险，而不是在外围再加一层。** 命名 **MIRROR-RAS**（Model-based Imitation & Response Rendering for Oracle Reliability）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我凭什么相信我的求证方式本身？——先照一面镜子，再开口，必要时请对方做给我看**」——不确定性可以由提问消解，但提问本身也需要被验证。

## 0. 直觉与动机

**灵感 1（语音合成 → 提问可以被「预演」）**
直觉：语音合成最深的范式不是「把文字念出来」，而是 **analysis-by-synthesis**：要判断一个假设，就把它生成出来，再看生成物是否符合观测。R69 的 MINT 用 VoI 选问题，但 VoI 依赖对「回答分布」的猜测；一旦猜错（模态未校准），问题设计就建在沙滩上。MIRROR 把它倒过来：先训练一个**应答者替代模型 (RSM)**——一个模仿这位人类「面对问题 g、相信 h 时会怎么说」的生成模型；于是在真正开口前，机器人可以对每个候选问题做**反事实合成**：把 h₁ 下的回答和 h₂ 下的回答都合成出来，量它们的可分性。问句不再靠「相信 VoI 的估计」，而是靠「亲眼看见两种世界会给出不同的话」。这把 R69 的「估计信息增益」变成「验证信息增益」。

**灵感 2（语音合成的信道 → 好问题也可能被信道吃掉）**
直觉：语音合成天然带一个信道模型：文本 → 声码器 → 波形 → 噪声/混响 → ASR → 文本。两个语义上天差地别的回答，如果合成到声学上只差一个易混音素（「左」/「右」在噪声里、「是」/「四」），那么这个问题在真实信道下的信息增益会**被打折**。R69 完全在语义层算 VoI，相当于假设了一个无噪、无损、无限带宽的理想信道。MIRROR 引入**声学-语义联合可辨性**：问题只有在「候选回答经过合成+信道后仍可分」时才算 admissible。这是语音合成给出的、纯语义推理给不出的约束。

**灵感 3（模仿学习 → R69 的似然通道就是 OOD 检测器，而 OOD 就是协变量偏移）**
直觉：R69 的 FMA 用 −log p_θ(ξ|o) 做「行为自洽」第二意见。用模仿学习的语言重述：流策略是在专家示范分布上做行为克隆，−log p_θ 低 ⇔ 动作在专家流形附近；一旦策略被条件在「错的世界」上，动作滑出专家流形，似然升高。这正是**协变量偏移**。但模仿学习早就知道，单靠 BC 的误差会随步数 **T²** 复合（Ross–Bagnell）：偏离—再偏离。所以 R69 用似然「检测」漂移是对的，但**检测到之后只是更保守**，这是消极的；模仿学习给的积极解药是**在漂移状态上请求专家修正**（DAgger），把复合从 T² 降到 T。

**灵感 4（模仿学习 → 人不是答案机，是可被模仿、也会被模仿影响的教师）**
直觉：R69 把回答当成「可能被投毒的观测」。但人不是被动观测源：他有一个**应答策略**（可以如实、可以含糊、可以撒谎、可以迎合），而且**他知道机器在模仿他**。这带来 R69 没有的两种新故障：其一，**教师能力非平稳**（疲劳、分心、随时间漂移、对机器人产生适应）；其二，**策略性示范 / 应试教学 (teaching-to-the-test)**——教师若知道自己的示范会被克隆，可能只在被问到的状态上演示「看起来对」的动作，而在未问到的状态上留下陷阱。MIRROR 必须同时建模「教师会说谎」和「教师会应付考试」。

**灵感 5（三层严格包含 → 不能每加一层就多一个黑箱）**
直觉：R68 是「永不交互」，R69 是「可问」，R70 是「可问、可请示范」。三者必须是**一条链上的退化关系**，而不是三个并列方案。MIRROR 必须满足：应答者模型不可信（ECE 越界 / 教师能力低）→ 关闭「问」退回 FLUID；无示范预算或教师示范不安全 → 关闭「请示范」退回 FLUID；两者都不可用 → 逐指令等于 R68。**新层若不能在边界上退化为旧层，它就不是进步，而是给旧层加了一个需要独立信任的黑箱。**

## 1. 形式化定义（增量：定义 310–326）

**定义 310（MIRROR-RAS 总览）** MIRROR-RAS = (RSM, QBS, AVC, TCM, CSG, CDI, SIL, RAS-WM‡)。四条不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i / R68 定义 276-i）：替代模型与教师能力的更新只发生在审计离线阶段，实时环只读；
(ii) **交互预算硬约束**（继承 R69 定义 293-ii），并**拆分**为问答预算 B_ask 与示范预算 B_show，二者竞争同一物理/社交成本上限；
(iii) **证据纪律**（继承 R69 定义 293-iii），并升级为「教师×信道」正交：单次回答 / 单次示范不得定案；
(iv) **安全优先于模仿**：任何被模仿的示范先过 C-RAS-WM 认证，不过则丢弃并记为不安全教师样本（SIL，定义 318）。

**定义 311（增广动作空间再扩展）** 在 R69 的 ξ=(a,g) 上，把信息动作细分为 g = (g_ask, g_show, g_wait)：g_ask 为问句软提示（定义 294），g_show 为「请在该状态示范」的请求（包含目标状态 s_req、示范模态、时长上限），g_wait 为观察等待。示范返回一条人类轨迹 τ_h ∈ 𝒯_demo。预算约束：B_ask(g_ask) + B_show(g_show) ≤ B_total。

**定义 312（应答者替代模型 RSM）** 对每个潜在模态/意图 h ∈ {h_1..h_K} 与上下文 c，学习 **p_ψ(y | g, h, c)**，其中 y 为「回答」的多模态表示（语义 token + 声学特征）。RSM 本身由交互日志上的模仿学习得到（对人做条件行为克隆，条件里含「假设意图 h」）。它是 R69 模态后验的**前向生成对偶**：R69 用后验 p(h|o) 消歧，R70 用前向 p_ψ(y|g,h) 预演。

**定义 313（合成式提问 QBS / 反事实可辨性）** 对候选问题 g，定义合成回答混合 p̃(y|g) = Σ_h p̃(h) p_ψ(y|g,h)。定义
- 合成信息增益 VoI_syn(g) = H(p̃(H)) − E_{y~p̃}[H(p̃(H|y))]；
- 反事实可辨性 Sep(g) = E_h E_{h'≠h} D_JS( p_ψ(·|g,h) ‖ p_ψ(·|g,h') )。
问题 admissible ⇔ VoI_syn(g) − c(g) > 0 ∧ Sep(g) ≥ τ_sep ∧ 定义 314 的声学可辨性达标。选 g* = argmax。**与 R69 的区别**：R69 的 VoI 用真实 p(y|g)，只能估；R70 用可采样的 p_ψ 去**合成反事实并实测**可分性，同时用 Sep 挡住「诚实答案与欺骗答案可互相冒充」的情况（对定义 304 投毒的前向防御）。

**定义 314（声学-语义信道与可辨性 AVC）** 信道 𝒞：文本 q →ᵀᵀˢ 波形 w →⁺ⁿ 观测 →ᴬˢᴿ 文本 ŷ。候选回答对 (y_a, y_b) 的**声学混淆率** C_ac(y_a,y_b) = P(ASR(𝒞(TTS(y_a))) = ASR(𝒞(TTS(y_b))))。定义有效可辨性折扣 κ(g) = 1 − max_{h≠h'} C_ac(y_h, y_h')。问题在真实信道下的有效增益 = κ(g)·VoI_syn(g)。κ 过低 ⇒ 该问题「问了也白问」，即使语义 VoI 很高。

**定义 315（教师能力模型 TCM）** 教师最优性 β_t(s) = P(教师示范在状态 s 上落入专家 ε-邻域)，用 Beta / 高斯过程在 (状态簇, 时间窗) 上学。非平稳：β_t 随时间缓变，且对「被问频率」敏感（疲劳/适应）。信任权重 w_T(s,t) = clip(β_t(s), 0, 1)。示范模仿损失按 w_T 加权；w_T < β_min ⇒ 不模仿该示范，仅记为证据。

**定义 316（协变量偏移治理 CSG）** 定义策略状态分布与专家分布的不匹配 d_t = TV(ρ_{π_θ,t}, ρ_{π*,t})，用 FMA 的 a_score 与 mode_head 的联合分位数做在线代理：d̂_t = f(a_score_t, H_mode,t)。若 d̂_t > τ_shift，进入「请示范」通道；并给出 ask/show 的预算分配：单位成本下，若 ∂/∂b_show [期望代价下降] > ∂/∂b_ask [期望代价下降]，则把预算从问移向请示范（引理 19）。

**定义 317（纠正性示范模仿 CDI）** 在漂移状态 s_req 上请求示范后，得到 τ_h。更新不是无差别 BC，而是**加权、带安全过滤的 DAgger 步**：L_CDI = w_T(s_req)·ℓ(π_θ(s_req), a_h) + λ_reg·‖θ−θ₀‖²，且仅当 τ_h 过 SIL（定义 318）才进缓冲。实时环不训练（不变式 i），CDI 只产出「下一轮离线更新条目」。

**定义 318（安全模仿层 SIL）** 对示范轨迹 τ_h 做 C-RAS-WM 前缀认证与安全包络检查；若 τ_h 在任一前缀越界，则不作为模仿目标（拒绝），并计入 ℰ_teacher 的「不安全教师」样本。SIL 保证模仿只会**收缩**可达策略集，不会把安全包络撑大（对应 shielding / safe DAgger）。

**定义 319（教师博弈与策略性应答）** 推广定义 304：教师可能（a）如实，（b）含糊/不答，（c）欺骗，（d）**应试示范**：在 s_req 上给出接近最优的示范，但在与 s_req 相关的邻域状态上系统性次优。定义检测统计量：对示范轨迹做**留出状态一致性**检验（在未请求的邻域状态上重放 τ_h 的局部策略，与全局专家似然比较）；不一致 ⇒ 判为应试示范，降权并触发反事实提问。

**定义 320（正交证据纪律升级）** R69 的「k 个正交源一致」升级为「**k 个正交教师×信道一致**」：证据源至少跨 {不同人类/传感器, 不同信道(语音/视觉/触觉), 不同时间窗} 三类中的两类；且任两源的**合成可辨性** Sep 与声学可辨性 κ 都达标，防止「多源共谋且声学可冒充」。单次 ask / 单次 show 只提供似然、不定案。

**定义 321（参与式审计 VQAuditor-T）** 在 R69 的 VQAuditor-I 上新增审计对象：问题是否**诱导**（leading）、示范是否**应试**（teaching-to-the-test）、替代模型是否**自我确认**（RSM 与策略互相印证却不与真实人类印证）、示范是否被单源采纳。结论回灌 AuditBuf，成为下一轮 QBS 的 τ_sep 先验与 TCM 的 β 先验。

**定义 322（MIRROR 干扰集 ℰ_MIRROR）** ℰ_MIRROR = ℰ_FLUID × ℰ_teacher × ℰ_channel，其中 ℰ_teacher = {误导回答, 应试示范, 非平稳教师, 共谋}；ℰ_channel = {TTS 合成伪影, ASR 同音混淆, 信道噪声致 κ 塌缩}。用于对抗训练与审计回放。

**定义 323（证书 J_MIRROR）** J_MIRROR = (J_FLUID, rsm_ece, sep_min, kappa_min, beta_min, shift_d_hat, cdi_accept_rate, teacher_audit_hash, mirror_ver)。Valid ⇔ Valid(J_FLUID) ∧ rsm_ece ≤ τ_ece' ∧ κ ≥ κ_min ∧ 证据纪律满足 ∧ 预算未越界。

**定义 324（三级保守退避）** 三态：
- 「问」可用（RSM 校准 ∧ Sep/κ 达标 ∧ B_ask 未超）→ 沿用 R69 的 resolution bonus；
- 「问」不可用但「示范」可用（β ≥ β_min ∧ τ_h 过 SIL ∧ B_show 未超）→ 用 CDI 降低 d_t，获得 **shift-reduction bonus**；
- 二者皆不可用 / 超时 / 被投毒 / 审计否决 → 逐指令退化为 R69，再退化为 R68。
安全侧永不弱于 R68；效率侧按「问 > 示范 > 保守」的可用性逐级获得 bonus。

**定义 325（教师样本的因果隔离）** 为避免「策略—替代模型」自我确认闭环，要求：RSM 的训练数据与策略当前部署数据**时间上错开**（held-out 教师集），且 CDI 的验收必须在**未参与 RSM 训练**的状态上评估。这是防「镜子照镜子」的硬约束。

**定义 326（与 R69/R68 的包含关系）** 令 RSM 退化为不提供信息的均匀回答（Sep≡0，VoI_syn≡R69 的 VoI 估计）、B_show≡0、SIL 始终接受、TCM 恒为 1，则 MIRROR ≡ FLUID。再令 VoI≤成本，则 ≡ R68。包含关系是本轮第一位的正确性要求。

```python
# IP-264 RSM：应答者替代模型（对"人面对问题如何回答"做条件行为克隆）
class RespondentSurrogate:
    def __init__(self, enc, dec, tts, asr):
        self.enc, self.dec = enc, dec      # 条件编码 / 回答生成
        self.tts, self.asr = tts, asr      # 声学信道两侧
    def logp(self, y, g, h, c):            # 语义 + 声学联合似然
        return self.dec.logp(y, self.enc(g, h, c))
    def sample(self, g, h, c, n=8):        # 反事实合成
        return [self.dec.sample(self.enc(g, h, c)) for _ in range(n)]

# IP-265/314 QBS+AVC：合成式提问（反事实可分 + 声学可辨）
def design_question(modes, w, rsm, channel, budget):
    best = None
    for g in question_candidates(modes):
        if not budget.allow_ask(g) or not c_ras_wm.certify_info(g, o_t): continue
        S = {h: rsm.sample(g, h, c) for h in modes}             # 预演两个世界
        p_tilde = mixture(S, w)
        voi_syn = entropy(w) - expected_entropy(w, p_tilde)
        sep = min(js_div(S[h], S[h2]) for h in modes for h2 in modes if h2 != h)
        kappa = 1.0 - max(channel.confusability(y1, y2)       # TTS->噪声->ASR 实测
                          for h in modes for h2 in modes if h2 != h
                          for y1 in S[h] for y2 in S[h2])
        score = kappa * voi_syn - cost(g)
        if sep >= TAU_SEP and kappa >= KAPPA_MIN and score > 0:
            if best is None or score > best.score: best = (g, score, sep, kappa)
    return best                                                # None => 不开口

# IP-267/318 CDI+SIL：在漂移状态请示范，过滤后作为离线更新条目
def request_demo(policy, s_req, teacher, sil, tcm, budget):
    if not budget.allow_show(s_req): return None
    tau = teacher.demonstrate(s_req, budget.modality)          # 人为/仿真教师
    if not sil.certify(tau):                                   # 安全包络不过 => 拒收
        audit.log_unsafe_teacher(tau); return None
    if tcm.beta(s_req) < BETA_MIN:                             # 能力不足 => 只当证据
        return {'evidence_only': True, 'tau': tau}
    return {'target': tau, 'w': tcm.weight(s_req)}            # 下一轮加权 BC 用

# IP-274 主闭环（继承 R69，仅在"不确定性处置"处升级）
def MIRROR_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_calibrated)
    slow = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    d_hat = M.csg.shift_estimate(a_hat, entropy_of(modes))     # 协变量偏移代理
    # 1) 预算分配：先问还是先请示范（引理 19 的边际收益比较）
    act = M.csg.allocate(U_epi, d_hat, M.budget)               # 'ask' | 'show' | 'none'
    U_epi_after = U_epi
    if act == 'ask' and not slow:
        q = M.qbs.design_question(modes, o, M.rsm, M.channel, M.budget)
        if q is not None:
            ans = M.cia.execute(q)                              # 带认证 + 证据纪律
            U_epi_after = M.cia.update_belief(modes, ans,
                                              discipline='k_teacher_channel_agree')
    elif act == 'show' and not slow:
        demo = M.cdi.request_demo(M.fmp, M.cs_req_state(o), M.teacher, M.sil, M.tcm, M.budget)
        if demo and 'target' in demo:
            M.cdi.enqueue_offline(demo)                         # 实时不学习
            d_hat = M.csg.expected_shift_after(d_hat, demo)     # shift-reduction bonus
    # 2) 风险缩放：三级退避（定义 324）
    U_floor = U_ale + (U_epi_after if act == 'none' else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if slow: lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, U_cal))
    mode = select_mode(modes, U_epi_after, lam)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_t.submit_async(act, q, demo, U_epi, U_epi_after, a_hat, d_hat)  # 审计
    return k, lam, mode, (U_ale, U_epi_after)
```

## 3. 推导

**引理 19（示范的协变量偏移增益）** 设行为克隆策略在专家分布上的单步误差为 ε，时程 T。无修正时期望代价上界 O(T²ε)；若在首次偏离专家流形的状态 s₁ 上获得一次专家示范，并在收缩映射假设（A99：偏离衰减因子 γ<1）下重训，则上界降到 O(Tε)。故「在漂移处请示范」的边际收益约为 O((T²−T)ε/T)，而「在漂移处继续提问」只降低 ε 的一个加性子项。系：**当 d̂_t 高且 T 大时，show 严格优于 ask**；这就是定义 316 预算分配的判据。

**引理 20（合成 VoI 的乐观偏差与校准门）** 令真实回答分布 p(y|g,h)、替代模型 p_ψ。一般地 |VoI_syn − VoI_true| ≤ √(2·ECE_ψ·log|Y|)·H(H)（KL 与校准误差的 Pinsker 型界）。故 ECE_ψ > τ_ece' ⇒ 合成增益的置信区间覆盖 0 ⇒ 关闭 QBS，退 R69。这为定义 323 的 rsm_ece 门提供理论依据。

**引理 21（声学可辨性折扣）** 设语义最优问题的候选回答在信道下混淆率 C_ac ≤ 1−κ。则执行该问题后的有效后验熵 H_eff ≥ H_sem + h_b(1−κ)，其中 h_b 为二元熵。故有效增益 ≤ κ·VoI_syn；当 κ→1/(#modes)（完全混淆）时有效增益→0。**语义上完美的提问，可以被声学信道抹成一个白问**——这是 R69 纯语义 VoI 的系统性高估。

**引理 22（非平稳/策略性教师下的模仿误差界）** 加权 BC 的期望误差 ≤ E_s[w_T(s)·ℓ*(s)] + E_s[(1−w_T(s))·ℓ(π_θ, a_h)] + 分布失配项。若 β_t(s) < β_min 在测度 μ 的状态上成立，则第二项 ≥ (1−β_min)μ·ℓ_min > 0，即**模仿一个能力不足的教师会主动抬高误差**。应试示范（定义 319）等价于在留出邻域上 β_t→低，被留出一致性检验捕获。故 TCM 门与应试检测是模仿不出错的必要条件。

**定理 18（MIRROR 严格包含 FLUID 与 R68）** 在 A95–A99 下，MIRROR 的三态策略在任意状态的期望风险 ≤ FLUID ≤ R68；且当 (i) Sep<τ_sep 或 ECE_ψ>τ_ece' 或 B_ask 用尽，且 (ii) β<β_min 或 B_show 用尽或示范未过 SIL，或 (iii) slow_fault_suspect 时，MIRROR 逐指令等于 FLUID；再令 VoI≤成本则等于 R68。因此 R69 是 MIRROR 在「示范不可用」边界上的退化，R68 是最外层退化。

**定理 19（安全模仿与无突变）** SIL 只接受过 C-RAS-WM 认证的示范，故 CDI 产生的更新不扩张认证安全集；三态切换由可用性谓词（单调）决定，切换时 λ 单调不降地趋于保守，提交/换装不变式（R68 定理 15）保持 ⇒ 控制连续、无突变；实时环零学习写操作（定义 310-i）保证更新只经审计离线生效。

## 6. 本轮最大风险

**一句话**：MIRROR 的全部收益押在「应答者替代模型与教师能力模型忠实刻画了一个**非平稳、可能策略性**的人」这一前提上——若这个模型错了，analysis-by-synthesis 就是在**对着一个虚构的人**验证问题，交互式模仿则把机器人和它的「教师影子」关进一个**互相印证的自洽闭环**（镜子照镜子）：两者一致，但都与真实世界不一致；**你以为在模仿教师，其实在模仿你对教师的模型——镜子让你自信，不让你正确**，而「问错/学错」比 R68 的「不问不学」更危险，因为它带着被合成的、伪造的证据。

**次级风险与缓解**：
1. **自我确认闭环**（RSM 与策略互证）→ 定义 325 时间错开 + 留出状态验收 + E312；
2. **应试示范/策略性教师** → 定义 319 留出一致性检验 + VQAuditor-T + ℰ_teacher 对抗训练；
3. **声学信道在真实噪声下 κ 崩塌** → AVC 在线估计 + κ_min 门 + 不达标即不问（引理 21）；
4. **教师非平稳被误判为稳定** → TCM 用 Beta 过程 + 变化点检测；β<β_min 只当证据不模仿（引理 22）；
5. **模仿扩张安全包络** → SIL 认证先于模仿（定理 19），零扩张是硬指标（E308）；
6. **实时预算被反事实合成击穿** → RSM 嵌入缓存 + 离线 AVC 查表 + 三态门控（复杂度表）。

```python
class RespondentSurrogate:
    def sample(self, g, h, c, n=8):
        return [self.dec.sample(self.enc(g, h, c)) for _ in range(n)]

# IP-265/266 QBS+AVC：合成式提问
def design_question(modes, w, rsm, channel, budget):
    best = None
    for g in question_candidates(modes):
        if not budget.allow_ask(g) or not c_ras_wm.certify_info(g, o_t): continue
        S = {h: rsm.sample(g, h, c) for h in modes}
        voi = entropy(w) - expected_entropy(w, mixture(S, w))
        sep = min(js_div(S[h], S[h2]) for h in modes for h2 in modes if h2 != h)
        kap = 1 - max(channel.confusability(a, b)
                      for h in modes for h2 in modes if h2 != h
                      for a in S[h] for b in S[h2])
        if sep >= TAU_SEP and kap >= KAPPA_MIN and kap*voi - cost(g) > 0:
            if best is None or kap*voi - cost(g) > best.score:
                best = (g, kap*voi - cost(g))
    return best

# IP-267/270 CDI+SIL：漂移处请示范，安全过滤后入离线队列
def request_demo(policy, s_req, teacher, sil, tcm, budget):

    tau = teacher.demonstrate(s_req, budget.modality)
    if not sil.certify(tau): audit.log_unsafe(tau); return None
    if tcm.beta(s_req) < BETA_MIN: return {'evidence_only': True, 'tau': tau}
    return {'target': tau, 'w': tcm.weight(s_req)}

    d_hat = M.csg.shift_estimate(a_hat, modality_entropy(modes))
    act = M.csg.allocate(U_epi, d_hat, M.budget)            # ask | show | none
```

## 7. 本轮最大风险

**一句话**：收益全部押在「RSM 与教师能力模型忠实刻画了一个非平稳、可能策略性的人」上——若错，analysis-by-synthesis 是在对着虚构的人验证问题，交互式模仿把机器人与「教师影子」关进互相印证的自洽闭环；**你以为在模仿教师，其实在模仿你对教师的模型——镜子让你自信，不让你正确**，而带着伪造证据的「问错/学错」比「不问不学」更危险。

**次级风险与缓解**：自我确认闭环（定义 325 时间错开 + 留出验收 + E312）；应试示范（定义 319 + VQAuditor-T + ℰ_teacher）；信道 κ 崩塌（在线 AVC + κ_min 门，引理 21）；教师非平稳误判（Beta 过程 + 变化点检测，β<β_min 只当证据，引理 22）；模仿扩张安全包络（SIL 先认证，定理 19，E308）；实时预算（嵌入缓存 + 离线查表 + 三态门控）。
