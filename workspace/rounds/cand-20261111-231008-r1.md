# 第 57 轮（承接第 56 轮「证据地图×主动探询×信任协商」IP-127~132；灵感循环第 1 轮；本轮灵感：「小样本学习」×「基线复现」）

> 第 56 轮把"模型置信"升级为"证据承诺"：护盾不再只问模型有多确信，而问这次接触有没有探针/到访/裕度/人工的证据类。但它的证据是"逐区域、多到访"攒出来的——新区域 `n_visits≈0` 时，证据门要么退化为安全停，要么只能借一个从未被检验的元先验；更隐蔽的是，它宣称相对第 55 轮的改进（E167–E171）**从未先复现第 55 轮基线**，种子、算力、指标口径都可能不匹配。于是"证据说可信"这句话本身还缺证据。本轮两个灵感各补一刀：**小样本学习**把"少证据"变成"有有限样本保证的证据迁移"（元先验 + 保形预测 + 负迁移门），**基线复现**把"改进声明"变成"先复现、再比较"的可证伪流程（预注册 + 复现门 + 负对照）。核心命题由"证据说可信"升级为 **"可迁移、可复现的证据才可信"**。

核心矛盾：
- **H26**：第 56 轮的证据门依赖逐区域多访积累，但部署首先遇到的恰恰是 `n_visits≈0` 的新区域；无先验的逐区域贝叶斯是空证据，而可迁移的元先验若无有限样本保证，就会把"别处的经验"当成"此处的证据"，一次负迁移足以击穿安全。
- **H27**：第 56 轮相对第 55 轮的增益声明本身不可复现——基线可能被削弱、种子可能被挑选、算力与指标口径不匹配；不可复现的安全结论等于把"证据"降格为修辞，也让后续所有消融失去意义。

## 0. 直觉与动机

**灵感 1（小样本学习 → 新区域是一个 K-shot 任务，不是一张白纸）**
直觉：每个新区域不是从零开始，而是"任务分布中的一个任务"：支撑集是 K 次探针，查询集是真正的落脚与承载。用历史上大量区域做元训练，学一个接触参数的元先验 `p0(θ)`；到新区域只做 K 次探针的后验更新。少样本不是"少保证"——关键在于别用点估计 + ECE，而用**保形预测**：它给出有限样本、分布无关的覆盖保证，K=1 也成立，只是预测集更宽、更保守；K 增大则集变窄、更高效。少样本买的是"效率随 K 增长"，而"安全"由集宽不足时回退到停/多探来守。

**灵感 2（保形预测 → 把"校准假设"换成"可检验的覆盖"）**
直觉：第 56 轮的 soundness 挂着 A33（ECE ≤ ε_cal），而 ECE 是渐近、依赖分箱、且对尾部不敏感——边界处最危险的恰是尾部。保形把假设换成可操作的命题：在任务可交换下，真实参数以 ≥1−α 的概率落在预测集 `C_α` 内。于是承诺不再问"点估计的失效概率"，而问"**预测集里最坏参数**的失效概率"是否仍 ≤ δ_f。这是一个更保守、但可被数据直接审计的判据。

**灵感 3（负迁移门 → 元先验不是免费午餐）**
直觉：元先验只在"新区域与元训练同分布"时有用。遇到分布漂移（材质、坡度、磨损、光照），迁移来的 μ/F_bear 可能系统性偏乐观，这比无先验更危险。故加 **OOD 门**：先测新证据与元训练分布的差异，超阈就把元先验权重置零、退回保守参考先验，并追加探针或直接停。安全界因此不依赖"迁移一定成功"，只依赖"漂移能被检出"。

**灵感 4（基线复现 → 先复现第 55 轮，再谈改进）**
直觉：任何"成功率 +10% / 跌倒 −40%"都必须先在同一协议下复现第 55 轮置信基线：固定种子集、数据划分、算力预算、指标定义与失效记账口径，并预注册分析计划。复现门不过，比较声明作废；复现门过了，才允许报告带置信区间的效应量。**最强基线**原则防止"复现一个被削弱的对手"。

**灵感 5（少样本评测 → 用 episode 而不是一次跑分）**
直觉：少样本能力必须在 N-way K-shot episode 上评：每个 episode 重新抽支撑/查询、分层覆盖风险等级，跨 ≥10 个种子报告均值 ± CI、效应量与种子方差。再加负对照（随机探针、纯置信基线、oracle），证明增益来自机制而非调参。这样"改进"才是可复现的统计陈述，而不是一次幸运的跑分。

**灵感 6（合并 → 可迁移性与可复现性是同一枚硬币）**
直觉：保形保证"跨区域可迁移"，复现门保证"跨实验可复现"；一个防"别处的证据冒充此处"，一个防"这次的跑分冒充规律"。两者都必须以证书形式固化，否则都会在部署压力下被悄悄绕过。

## 1. 形式化定义（增量：定义 133–138）

**定义 133（少样本接触任务与元先验）** 任务分布 `p(𝒯)` 上的任务 `T_r=(C_r,S_r,Q_r)`：上下文 `C_r`、支撑集 `S_r={e_1..e_K}`（K 次探针）、查询集 `Q_r`（真实落脚/承载）。接触参数 `θ_r=(label, μ, k, F_bear)∈Θ`。元先验 `p0(θ|C_r)` 由元训练任务分层贝叶斯/元学习得到；少样本后验 `b_r^K(θ) ∝ p0(θ|C_r)·∏_{i=1}^K p(e_i|θ)`。要求 `p0` 为正常预测分布且其构造过程可审计（A37）。

**定义 134（保形接触预测集）** 评分 `s(θ,e)`（如负对数似然或残差）。取与测试任务可交换的校准任务集 `D_cal`，`q_{1-α}` 为其评分的 `⌈(n+1)(1-α)⌉/n` 分位。`C_α(r)={θ: s(θ, evidence_r) ≤ q_{1-α}}`，满足 `P(θ_r∈C_α(r)) ≥ 1-α`（边缘覆盖；协变量漂移下用密度比加权保形）。**保形失效** `P_fail^conf(r,p,F)=sup_{θ∈C_α(r)} P_fail(θ)`；承诺 ⇔ `P_fail^conf ≤ δ_f(g)`。注意这是"集内最坏"判据，保守但可审计。

**定义 135（负迁移门 NTG）** OOD 分 `d(r)=D(evidence_r, D_meta)`（能量分/MMD/密度比）。门控 `λ(r)=0` if `d(r)>θ_ood` else `1`；回退先验 `p_ref`（保守、非信息或仅物理约束）。负迁移量 `Δ_nt(r)=E[P_fail|p0]−E[P_fail|p_ref]` 可正；门控保证：检出门触发时安全界不含 `p0`，漏检时界内加 `ε_ood`（A38）。

**定义 136（可复现基线协议 RBP）** `Π=(B0,D,S,C,M,A,h)`：最强可复现基线 `B0`、数据/划分 `D`、种子集 `S`、算力预算 `C`、指标定义 `M`、预注册分析 `A`、哈希 `h`。复现门：在 `Π` 下以 `S` 重跑 `B0`，得 `CI_{1-β}(m_B0)`；通过 ⇔ 报告值落在 CI 内 ∧ `h` 一致 ∧ `M/A` 未事后更改。仅通过才签发比较许可。

**定义 137（少样本评测 episode）** `Episode=(D_meta, S_r(K), Q_r)`，N-way K-shot，按风险等级分层。主指标预注册，次指标标注为探索性；报告均值、自助 CI、效应量（Cohen's d / Cliff's δ）与种子方差。负对照 `{random-probe, confidence-only, oracle}`。基线在**同一 K-shot 口径**下复现，避免"全数据基线 vs 少样本方法"的不公平比较。

**定义 138（复现-证据证书 J_repro）** `J_repro=(J_m, repro_gate, coverage_audit, ood_log, seed_manifest, compute_manifest, neg_controls, prereg_hash)`。拒绝条件：复现门失败、经验覆盖 `<1-α-ε`、OOD 日志不全、种子/算力清单缺失、预注册哈希不符。它在第 56 轮 MEC 之上再加"证据本身可复现"这一层。

## 2. 关键算法伪代码（完整版见产物区）

### IP-133 FCA（Few-shot Contact Adaptation）

```python
def few_shot_adapt(r, M, meta_prior, K, F_abs):
    ev = []
    for i in range(K):
        p = argmax(admissible_probes(r, M, F_abs), key=lambda q: voi_pess(q, M, meta_prior))
        ev.append(execute_probe(p, cap=F_abs))       # 非破坏性继承 A34
    return posterior(meta_prior, ev), ev             # b_r^K
```

```python
def conformal_viability(sigma, C_alpha, gait):

    return Feasible(...)
```

### IP-135 NTG（Negative Transfer Gate）

```python
def negative_transfer_gate(r, ev, meta):
    d = ood_score(ev, meta.train_stats)
    if d > theta_ood: return 'ref_prior', d      # 丢弃元先验
    return 'meta_prior', d
```

### IP-136 RBP（Reproducible Baseline Protocol）

```python
def reproduction_gate(B0, Pi, reported):
    runs = [run(B0, seed=s, protocol=Pi) for s in Pi.seeds]
    ci = bootstrap_ci(runs, alpha=Pi.beta)
    ok = Pi.hash_ok and Pi.metrics_unchanged and (ci.lo <= reported <= ci.hi)
    return ('pass' if ok else 'fail'), ci
```

### IP-137 FSE（Few-shot Evaluation）

```python
def few_shot_eval(policy, Pi, episodes):
    rows = [evaluate(policy, ep) for ep in episodes]   # 主指标 + 种子
    return bootstrap_ci(rows), effect_size(rows, Pi.B0), seed_var(rows), neg_controls(policy)
```

### IP-138 REC（Reproducibility-Evidence Certificate）

```python
def repro_evidence_certificate(sched, log, M, repro, cov, ood, man):
    if repro.status != 'pass':            return ('reject','baseline_not_reproduced')
    if cov.empirical < 1-alpha-eps_cov:   return ('reject','coverage_audit')
    if not ood.complete:                  return ('reject','ood_log')
    if not (man.seeds and man.compute and man.prereg): return ('reject','manifest')
    return ('ok', J_repro(M.core, repro.ci, cov, ood, man))
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| FCA | O(K·(C_probe+d_θ)) | O(K·d_e+d_θ) | 元先验可审计、非破坏探针（A34/A37） |
| CPC | O(\|σ\|·\|C_α\|·d) | O(\|σ\|·\|C_α\|) | 集内最坏、覆盖可审计（A37） |
| NTG | O(d·\|D_meta\|) | O(d) | 检出率与误报界（A38） |
| RBP | 离线 O(\|S\|·cost(B0)) | O(\|S\|) | 最强基线、哈希与口径冻结（A39） |
| FSE | O(\|E\|·(K+\|Q\|)) | O(\|E\|) | episode 分层、CI/效应量（A40） |
| REC | O(\|σ\|+\|log\|) | O(\|σ\|) | 复现门+覆盖审计，缺一即拒 |

**正确性定理（Few-shot Calibrated & Reproducible Soundness, FCRS）**：在 A29–A36 基础上加 **(A37)** 校准/测试任务可交换（或加权可交换）且元先验构造诚实；**(A38)** OOD 门检出率 `≥1-ε_ood`、误报 `≤ε_fp`；**(A39)** 复现门使用最强基线、协议冻结、种子/算力匹配、预注册；**(A40)** 覆盖审计与负对照完备。则：

1. **少样本承诺健全性**：任意 `K≥1`，以概率 `≥1-α-ε_ood`，每个承诺接触满足 `P_fail ≤ δ_f + δ_probe + ε_h`；`α` 取代第 56 轮的 `ε_cal`，且是有限样本量；
2. **效率单调性（期望意义）**：在 A37 与有信息似然下，`E|C_α(r)|` 随 K 非增，达到同一 `δ_f` 所需探针数随 K 下降；安全界不随 K 变松，集过宽时回退停/多探；
3. **负迁移安全**：检出门触发即用 `p_ref`，安全界不含元先验；漏检时界内加 `ε_ood`，故"迁移失败"被显式计价；
4. **可复现性**：比较声明 `Claim(Δ>0)` 仅在 `repro_gate=pass ∧ CI(Δ)∌0 ∧ 负对照支持机制` 时成立；复现门失败则声明作废（不是"弱证据"，是"无许可"）；
5. **部署界**：`P_safe ≥ 1−Σ_cp(δ_f+α+ε_ood+δ_probe+ε_h)−P(陈旧未检出)−P(护盾回退失败)−P(复现协议失效)`。

关键：**保形把"相信校准"换成"审计覆盖"；复现门把"相信改进"换成"先复现再比较"**。但边缘覆盖不等于条件覆盖，这一点必须写进风险而非藏在假设里。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 保形只有边缘覆盖，个别区域被系统性低覆盖 | 高 | 按风险等级 Mondrian/分组保形 + 在线 ACI + 分区覆盖审计 |
| 复现门被"削弱基线 + 欠定义协议"骗过 | 高 | 最强基线原则 + 预注册哈希 + 负对照 + 外部审计 |
| 元先验负迁移且 OOD 漏检 | 高 | 保守 `p_ref` 回退 + 加权保形 + 漂移区强制多探/停 |
| 集内最坏过保守 → 永远停 | 中 | 保形分位数/风险控制替代全集 sup；按裕度自适应加密 |
| 复现受软硬件漂移影响，误判通过/失败 | 中 | 环境钉扎 + 清单留痕 + CI 容差 + 多机复跑 |

## 6. 本轮最大风险

**一句话**：本轮用"保形覆盖"和"基线复现"给证据加了双重保证，但保形是**任务分布上的边缘覆盖**而非每个新区域的**条件覆盖**，复现门又可能被"被削弱的基线 + 欠定义协议"满足——两者叠加会制造"既保形又复现"的虚假安全感：某个具体新区域可能被系统性低覆盖，而比较基线从来不是公平对手；因此必须以分组/在线保形（Mondrian+ACI）、最强基线+预注册哈希、负对照与分区覆盖审计作为不可省的三重护栏。

```python
    ev = []
    for i in range(K):
        cands = admissible_probes(r, M, F_abs)          # 继承 A34 非破坏性过滤
        if not cands: break
        p = argmax(cands, key=lambda q: voi_pessimistic(q, M, meta_prior) - cost(q))
        e = execute_probe(p, cap=F_abs)                 # 力帽：探针不改写被测世界
        ev.append(e)
        M, _ = map_fuse(M, [e])                         # 探针证据入图（IP-127）
        budget.spend(p)
    if len(ev) < K_min:
        return None, ev, 'insufficient'                 # 证据不足 → 多探/停
    return posterior(meta_prior, ev), ev, 'ok'          # b_r^K(θ)
```

### IP-134 CPC（Conformal Predictive Commitment）

```python
def worst_case_fail(C_alpha_r, r, p, F):
    best_pf, witness = -1.0, None
    for theta in C_alpha_r:                             # 顶点/分位近似
        pf = P_fail(theta, r, p, F)
        if pf > best_pf: best_pf, witness = pf, theta
    return best_pf, witness

def conformal_viability(x, sigma, M, C_alpha, gait):
    df = delta_f_of_gait(gait)
    pf_max = 0.0
    for (r, p, F) in sigma:
        pf, wit = worst_case_fail(C_alpha[r], r, p, F)
        pf_max = max(pf_max, pf)
        if pf > df:
            return KernelInfeasible(pf, witness=wit)    # 反例参数可解释
    feas, u, lam = solve_contact_dynamics(
        x, sigma, FC(conformal_lower_conf(C_alpha)))     # 保形下界进动力学
    return KernelApprox(feas=feas, pf_max=pf_max,
                        margin=dist_to_chance_boundary(x, sigma, C_alpha))
```

### IP-137 FSE（Few-shot Evaluation）

```python
def few_shot_eval(policy, Pi, episodes):
    rows = []
    for ep in episodes:                                 # N-way K-shot，风险分层
        rows.append(evaluate(policy, support=ep.S, query=ep.Q))
    ci = bootstrap_ci(rows, alpha=Pi.beta)

        ci=ci,
        effect=effect_size(rows, Pi.B0),                # Cohen's d / Cliff's δ
        seed_var=variance(rows),
        neg={k: evaluate(v, episodes)                   # random-probe/conf-only/oracle
             for k, v in Pi.neg_controls.items()})
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| FCA | O(K·(C_probe+d_θ)) | O(K·d_e+d_θ) | 元先验可审计、非破坏探针（A34/A37） |
| CPC | O(\|σ\|·\|C_α\|·d + QP-SOCP) | O(\|σ\|·\|C_α\|) | 集内最坏、覆盖可审计（A37） |
| NTG | O(d·\|D_meta\|) | O(d) | 检出率 `≥1-ε_ood`、误报 `≤ε_fp`（A38） |
| RBP | 离线 O(\|S\|·cost(B0)) | O(\|S\|) | 最强基线、哈希与口径冻结（A39） |
| FSE | O(\|E\|·(K+\|Q\|)) | O(\|E\|) | episode 分层、CI/效应量（A40） |
| REC | O(\|σ\|+\|log\|) | O(\|σ\|) | 复现门+覆盖审计，缺一即拒 |

**正确性定理（Few-shot Calibrated & Reproducible Soundness, FCRS）**
假设 A22–A28（第 53/54 轮）、A29–A36（第 55/56 轮）成立；**(A37)** 校准/测试任务可交换（或加权可交换）且元先验 `p0` 构造诚实、其训练集与测试集无泄漏；**(A38)** OOD 门检出率 `≥1-ε_ood`、误报 `≤ε_fp`；**(A39)** 复现门使用最强可复现基线、协议冻结、种子/算力匹配、预注册未改；**(A40)** 覆盖审计与负对照完备。则：

1. **少样本承诺健全性**：任意 `K≥1`，以概率 `≥1-α-ε_ood`，PCE 承诺的每个接触满足
   `P(fail) ≤ δ_f + δ_probe + ε_h`；
   其中 `α` 取代第 56 轮的 `ε_cal`，且为有限样本、分布无关（A37）。
2. **效率单调性（期望意义）**：在 A37 与有信息似然下，`E|C_α(r)|` 随 K 非增，达到同一 `δ_f` 所需探针数随 K 下降；安全界不随 K 变松，集过宽时回退到多探/停。
3. **负迁移安全**：门控触发即用 `p_ref`，安全界不含元先验；漏检时界内加 `ε_ood`——"迁移失败"被显式计价，而非隐含假设。
4. **可复现性**：比较声明 `Claim(Δ>0)` 仅在
   `repro_gate=pass ∧ CI(Δ)∌0 ∧ 负对照支持机制`
   时成立；复现门失败则声明作废（不是"弱证据"，是"无许可"）。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + α + ε_ood + δ_probe + ε_h)
             − P(𝓜 陈旧 > τ_stale 未检出) − P(护盾回退失败)
             − P(τ_int 超时 ∧ 安全停失效) − P(复现协议失效)
```

关键：**保形把"相信校准"换成"审计覆盖"；复现门把"相信改进"换成"先复现再比较"**。注意定理 1 的覆盖是**边缘**的——它对"随机抽一个任务"成立，对"某个被反复访问的具体区域"不必然成立；这正是本轮风险条目的核心。

## 6. 本轮最大风险

**一句话**：本轮用"保形覆盖"和"基线复现"给证据加了双重保证，但保形是**任务分布上的边缘覆盖**而非每个新区域的**条件覆盖**，复现门又可能被"被削弱的基线 + 欠定义协议"满足——两者叠加会制造"既保形又复现"的虚假安全感：某个具体新区域可能被系统性低覆盖，而比较基线从来不是公平对手；因此必须以分组/在线保形（Mondrian+ACI）、最强基线+预注册哈希、负对照与分区覆盖审计作为不可省的三重护栏。
