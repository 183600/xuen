# 第 56 轮（承接第 55 轮语义-接触生存核与 v31 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「MuJoCo」×「强化学习」）

> 第 54 轮把可行性判定推进到“动作-鲁棒性双证书”，第 55 轮把它下探到“语义-接触生存核”。但有一个从未被审计的前提：**生存核、护盾与策略都在同一个仿真器里产生——核是 MuJoCo 算的，策略是 RL 在 MuJoCo 里学出来的**。MuJoCo 的接触是软约束 + 摩擦锥凸近似，RL 又天生会榨干仿真器的每一点漏洞。于是“证书说可行”很可能只是“MuJoCo 说可行”。本轮的核心动作：**把仿真器保真度（fidelity）与 RL 的策略搜索一起写进证书，并把护盾从部署补丁变成训练回路的一等公民。** 核心矛盾：**H24**：接触模型的误差是结构化、状态相关的，未必落在任何范数球内，而证书恰恰假设它可被有界扰动包住；**H25**：RL 的策略搜索与证书的保守性目标相反——策略会主动寻找“证书边界上的漏洞”，使证书的 soundness 在训练中被对抗性侵蚀。

## 0. 直觉与动机

**灵感 1（MuJoCo 接触模型 → 保真度包络，而非“真值”）**
直觉：MuJoCo 用 `solref/solimp/margin/μ` 的软接触与凸摩擦锥近似真实接触，法向柔度、切向滑移与回弹都与真实存在系统性偏差。与其假装“仿真接触=真实接触”，不如承认“仿真接触=真实接触的一个受约束代理”：`λ_real = λ_sim(θ_s) + Δλ`，`||Δλ||_W ≤ δ_f`。于是第 55 轮的生存核从 `K(Σ)` 升级为 **保真度鲁棒生存核** `K_F(Σ)`——不是对名义接触可行，而是对最坏接触失真仍可行。

**灵感 2（RL 不只学策略，还应学可达性）**
直觉：第 55 轮用采样 + QP 求生存核，维数一高就爆炸。强化学习里的值函数本质就是“从这点出发还能不能活”的摊销估计。把生存核当作 **鲁棒 Hamilton–Jacobi 可达性值函数** `V_φ(x,Σ)` 来学：正=核内，负=核外，幅值近似到边界的距离。WBV 从“离线枚举 QP”变成“在线摊销前向”，这是把 RL 从“策略优化器”重新定位为“安全几何的求解器”。

**灵感 3（护盾必须在训练回路里，但入回路会反噬）**
直觉：若训练时策略随便探索、只在部署时挂护盾，策略会学到“反正有护盾兜底”的动作，甚至主动顶着护盾边界去换奖励。护盾必须 **进入训练回路**，但入回路立即带来两个新病：**护盾利用**（策略把脏活全推给投影）与 **评论家污染**（价值估计建立在被护盾改写过的转移分布上）。因此需要 **护盾残差 + 安全评论家 + 名义动作自身的安全惩罚**，逼迫策略自己提出安全动作，而非依赖投影。

**灵感 4（MJX 大规模并行 → 保真度鲁棒性谱）**
直觉：MuJoCo 的 GPU 版 MJX 能同时跑成千上万个随机化模型。把第 55 轮的语义鲁棒谱 `ρ_sem` 再张一根 **保真度轴** `ρ_fid(ε_f)`：在 `(Σ, θ_s, Δλ)` 的联合扰动球里取最坏可行保持概率。这让“域随机化”从训练技巧升级为 **证书证据生成器**：随机化不再只为了提高成功率，而是为了给证书提供最坏情形样本。

**灵感 5（接触系统辨识 → 证书重认证闭环）**
直觉：真实触觉/力/力矩数据 `D_real` 会给求解器参数一个后验 `p(θ|D)`。只要证书声明 `P(θ∈Θ_cert | D_real) ≥ 1-α`，就可部署；一旦后验漂出包络，就触发 **重认证/重训练**。这把 sim-to-real 从“一次性迁移”升级为“持续证书维持”，也让第 54 轮的联合迁移证书有了可执行的在役监测语义。

**灵感 6（保真度不是标量而是谱 → 证书要“分频段”声明）**
直觉：MuJoCo 在高频碰撞（落脚冲击）与低频支撑（静立）上的误差结构完全不同，用一个 `δ_f` 概括会既过度保守又漏掉冲击段。把接触扰动按频段 `b` 分解 `Δλ = Σ_b Δλ_b`，每段独立给预算 `δ_f^{(b)}`，证书声明“在冲击频段 `b*` 上仍满足 `K_margin`”。这对应真实系统里“静态稳、落地砸穿”的典型失效。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（接触保真度包络）**
求解器参数 `θ_s ∈ Θ_s`（solref, solimp, margin, μ, 时间步）。仿真接触力 `λ_sim(θ_s)`，真实接触力 `λ_real`。按频段 `b∈B` 分解后，保真度包络
`F(δ_f, Θ_s) = { (θ_s, Δλ) | θ_s∈Θ_s, ||Δλ_b||_{W_b} ≤ δ_f^{(b)} }`，
并要求 `λ_real = λ_sim(θ_s) + Σ_b Δλ_b`。各段预算 `δ_f^{(b)} = Quantile_{1-α_b}(||λ_real - λ_sim||_{W_b} | b)`，即按频段做分位数校准，而非单一全局范数。

**定义 128（保真度鲁棒生存核）**
全身动作 `A_WB = A_b×A_a×A_l×A_t`，接触力 `λ∈FC(μ)`。生存核
`K_F(Σ) = { x | ∃u∈A_WB, ∀(θ_s,Δλ)∈F : supp(λ)⊆C^+(Σ) ∧ λ+Δλ∈FC(μ) ∧ f(x,u,λ+Δλ) 一步可达 𝒳_safe }`。
注意量词结构是 `∃u ∀Δλ`：护盾要在最坏接触失真下仍可行，而非名义接触下可行。

**定义 129（神经可达性核 NVK）**
学习 `V_φ : X×Σ → ℝ` 逼近到边界的符号距离 `dist(x, ∂K_F(Σ))`（内正外负）。训练含三项：
1. 鲁棒 HJ 不动点：`V_φ(x) ≈ max_{u} min_{(θ_s,Δλ)∈F} γ V_φ(f(x,u,λ+Δλ))`（有限时域/生存版）；
2. 可行性标签：对采样态用短时域 MPC/QP 给 `sign(V)` 标签，做排序 + 分类损失；
3. 证书一致性：要求 `V_φ(x) > 0 ⇒ 数值 QP 以概率 ≥ 1-ε_V 可行`，用对偶间隙惩罚“乐观前向”。
核近似 `K_in={V_φ ≥ τ_in}`、`K_out={V_φ ≥ -τ_out}`，要求在采样网格上 `K_in ⊆ K_F ⊆ K_out`（sound 的外/内包）。

**定义 130（证书引导的护盾强化学习 CG-SRL）**
策略 `π_θ`，护盾 `S(x,u_nom) = argmin_u ||u-u_nom||²_W s.t. V_φ(f(x,u,λ+Δλ))≥τ_in, supp(λ)⊆C^+(Σ), λ+Δλ∈FC(μ)`。训练目标
`max_θ E[r(x,u)] - β·max(0, C_safe(π_θ)-d) - η·E[||S(x,π_θ(x))-π_θ(x)||²]`。
第三项是 **护盾一致性惩罚**：逼迫策略自身提出安全动作，压低护盾投影幅值（防 shield exploitation）。另训 **安全评论家** `Q_s(x,u)` 估计“经护盾后仍失败”的概率，作为 `C_safe` 的估计器，并只用护盾未改写转移的样本做去偏更新。

**定义 131（保真度-语义联合鲁棒性谱）**
`ρ_fid(ε_f, ε_s) = inf_{ ||Σ-Σ̂||_∞≤ε_s, (θ_s,Δλ)∈F(ε_f) } P( viable(x,Σ,θ_s,Δλ) )`。
与第 55 轮 `ρ_sem`、第 53 轮 `ρ` 共用谱框架；`ρ_fid` 由 MJX 批并行估计，作为证书里“仿真器保真度维”的证据。

**定义 132（保真度校准证书与在役维持）**
`J_f = (Σ_core, C_core, K_margin, ρ_fid, ρ_sem, δ_f, Θ_cert, evidence)`：
- `Σ_core, C_core` 核心语义与核心接触集（继承第 55 轮）；
- `Θ_cert` 已认证的求解器参数集（含各频段预算）；
- `δ_f = {δ_f^{(b)}}` 实测量的分段保真度残差；
- `evidence` 含真实接触残差、最坏扰动反例、MJX 谱、辨识后验。
部署条件：`P(θ_s∈Θ_cert | D_real) ≥ 1-α`、`K_margin ≥ θ_K`、`ρ_fid ≥ ρ_min`、`δ_f^{(b)} ≤ Θ_f^{(b)}` 且 `ρ_sem ≥ ρ_sem^min`。
**在役维持**：每收集一批 `D_real` 更新后验，若 `P(θ_s∈Θ_cert | D_real) < 1-α` 则证书失效，触发重认证（重估 `δ_f`）或重训练（重学 `V_φ` 与 `π_θ`）。

## 2. 关键算法 伪代码

### IP-127 FEC（Fidelity Envelope Calibration）

```python
def fidelity_envelope(real_logs, sim_model, bands, alphas):
    # real_logs: [(x, u, lambda_real)]；sim_model 可注入 theta_s
    delta_f, theta_grid = {}, build_theta_grid(sim_model)
    for b in bands:
        residual = []
        for (x, u, lam_real) in real_logs:
            lam_sim = sim_model.contact_force(x, u, band=b)
            residual.append(project_band(lam_real - lam_sim, b))
        delta_f[b] = quantile(norm_W(residual), 1 - alphas[b])
    theta_cert = {th for th in theta_grid
                  if coverage(sim_model, real_logs, th, delta_f) >= 1 - alphas['cov']}
    return FidelityEnvelope(delta_f, theta_cert)
```

### IP-128 NVK（Neural Viability Kernel）

```python
def train_nvk(sampler, env_family, F, phi, tau_in, tau_out):
    for it in range(N):
        x, Sigma = sampler.sample()
        # (1) 鲁棒 HJ 不动点：对 u 取 max、对 (theta_s,dlam) 取 min
        u = policy_proposal(x, Sigma)
        v_fp = min(gamma * V(phi, env_family.step(x, u, theta_s, dlam), Sigma)
                   for (theta_s, dlam) in F.sample_worst(x, u))
        # (2) 短时域 QP 给可行性标签
        label = 1.0 if short_horizon_qp_feasible(x, Sigma, F) else -1.0
        # (3) 证书一致性：V>0 必须 QP 可行
        dual_gap = qp_duality_gap(x, Sigma, F, u)
        loss = huber(V(phi, x, Sigma), v_fp) \
             + rank_loss(V(phi, x, Sigma), label) \
             + consistency_penalty(V(phi, x, Sigma), dual_gap, tau_in)
        update(phi, loss)
    return KernelApprox(K_in=lambda x: V(phi,x) >= tau_in,
                        K_out=lambda x: V(phi,x) >= -tau_out)
```

### IP-129 CG-SRL（Certificate-Guided Shielded RL）

```python
def cg_srl_train(env, pi, V, F, C_plus, beta, eta, d):
    Qs = init_safety_critic()
    for ep in range(E):
        x = env.reset(); done = False
        while not done:
            u_nom = pi(x).sample()
            u_sh, gap = shield_with_worstcase(x, u_nom, V, F, C_plus)   # ∃u ∀Δλ
            r, x2, done = env.step(u_sh)
            # 护盾一致性惩罚：压低对投影的依赖
            penalty = eta * gap**2
            # 拉格朗日安全约束：用安全评论家估计的失败概率
            safety_cost = Qs(x, u_nom)
            reward = r - penalty
            pi.update(reward, safety_lagrangian(beta, safety_cost - d))
            # 安全评论家只用“护盾未改写”的样本做去偏更新（importance weight）
            if gap < 1e-6:
                Qs.update(x, u_nom, failure_indicator(x2, done))
            x = x2
    return pi, Qs
```

### IP-130 MFRS（MJX Fidelity-Robustness Spectrum）

```python
def mjx_fidelity_spectrum(Sigma_hat, eps_s, F, batch, n_mc):
    worst = 1.0
    for _ in range(n_mc):
        Sigma = sample_ball(Sigma_hat, eps_s, worst_case=True)
        theta_s = sample_params(F.theta_cert)
        dlam = sample_worst_band(F.delta_f)
        env = mjx.make_batch(batch, Sigma, theta_s, dlam)   # GPU 批并行
        p = mjx.empirical_viable(env).min()
        worst = min(worst, p)
    return worst
```

### IP-131 FCR（Fidelity-Calibrated Certificate）

```python
def fidelity_certificate(traj, Sigma, F, posterior, budgets):
    K_margin = min(signed_distance(V, x, Sigma) for x in traj)
    delta_f = measure_residual(traj, F)
    if posterior.mass(F.theta_cert) < 1 - budgets.alpha:
        return ('reject', 'solver_out_of_envelope', posterior)
    if K_margin < budgets.theta_K or any(delta_f[b] > budgets.Theta_f[b] for b in delta_f):
        return ('reject', 'fidelity_budget_exceeded', K_margin, delta_f)
    rho_fid = mjx_fidelity_spectrum(Sigma, budgets.eps_s, F, budgets.batch, budgets.n_mc)
    if rho_fid < budgets.rho_min:
        return ('reject', 'fidelity_robustness_fail', rho_fid)
    return ('ok', FidelityCert(Sigma.core, traj.contacts, K_margin, rho_fid, delta_f,
                               F.theta_cert, evidence=traj.evidence))
```

### IP-132 CIL（Contact Identification Loop）

```python
def contact_identification_loop(cert, real_stream, sim_model):
    posterior = cert.posterior
    while True:
        x, u, lam_real = real_stream.next()
        posterior = bayes_update(posterior, likelihood(sim_model, x, u, lam_real))
        if posterior.mass(cert.Theta_cert) < 1 - cert.alpha:
            # 先尝试保守重标定；不行再重训练
            if recalibrate(cert, posterior, real_stream.recent()):
                return ('recertified', cert)
            return ('retrain_required', posterior, collect_contact_evidence(real_stream))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| FEC | O(|D_real|·|B| + |Θ_s|·|D_real|) | O(|B|) | 分段分位数校准、包络覆盖检验 |
| NVK | O(N·(|F|·T + QP)) 训练 / O(1) 推理 | O(|φ|) | HJ 不动点收敛、`K_in⊆K_F⊆K_out` sound |
| CG-SRL | O(E·T·(|F|·QP)) | O(|φ|+|ψ|) | 拉格朗日约束、护盾残差有界、评论家去偏 |
| MFRS | O(n_mc·batch·T)（GPU 批并行） | O(batch·T) | 最坏样本覆盖、MC 误差可控 |
| FCR | O(|轨迹|·|φ| + n_mc·batch) | O(|φ|) | 后验质量、分段预算闭合 |
| CIL | O(|D_real|·|Θ_s|) | O(|Θ_s|) | 后验校准、重认证收敛 |

**正确性定理（Fidelity-Aware Semantic-Contact Soundness）**
假设第 55 轮 (A29)–(A32) 成立；并设
**(A33)** `λ_real - λ_sim(θ_s)` 在频段 `b` 上以概率 `≥1-p_f` 落在 `B(δ_f^{(b)})` 内；
**(A34)** NVK 在采样网格上的泛化误差使 `P(∃x∈K_in \ K_F) ≤ p_V`；
**(A35)** 护盾不可行时回退 `u_stop∈𝒳_safe` 且失败概率 `≤ p_fb`；
**(A36)** MFX 对 `ρ_fid` 的 MC 估计误差 `≤ ε_mc`（概率 `≥1-p_mc`）；
**(A37)** 后验校准使 `P(θ_s∈Θ_cert | D_real) ≥ 1-α`。
则部署后单步安全概率
```
P_safe ≥ 1 - p_s - p_f - p_V - p_fb - p_mc - α
```
其中 `p_s` 为第 55 轮语义失配概率。关键：**保真度包络吸收仿真器误差、NVK 保守包含吸收学习误差、护盾兜底吸收残余、辨识后验把“在役漂移”变成可检测事件**，四层任一层失守都不允许把“MuJoCo 可行”当作“真实可行”。

## 6. 本轮最大风险

**一句话**：把 MuJoCo 保真度与 RL 策略搜索一并纳入证书，能把“仿真可行”升级为“在保真度包络内可行”，但其 soundness **三重依赖接触误差可被包络、NVK 不产生乐观假阳性、护盾入训练后不被策略利用**；一旦接触误差是结构化且状态相关的（尤其落脚冲击段）、或 NVK 在接触边界给出假阳性，证书会把“MuJoCo 说可行”当成“真实可行”，策略又会在训练中主动顶着证书边界换奖励，最终在最坏接触失真下由护盾放行一次不可逆跌倒——因此必须以 **状态依赖扰动集 + 证书一致性保守训练 + 真实力反馈绊线** 三重护栏，宁可保守制动，绝不把仿真器的“高置信可行”当作现实的“已证实可行”。

# 第 56 轮产物 · 创新点清单 v32：FidelityCert-GenSim（FEC×NVK×CG-SRL×MFRS×FCR×CIL）

> 承接第 55 轮语义-接触生存核与 v31 GroundEdge-GenSim+++。本轮在“语义-接触证书”之上增加 **仿真器保真度** 与 **强化学习训练回路** 两个维度：
> - **FEC（Fidelity Envelope Calibration）**：把 MuJoCo 接触误差标定成分段保真度包络 `{δ_f^{(b)}}`；
> - **NVK（Neural Viability Kernel）**：用鲁棒 HJ 值函数摊销化生存核，替代离线 QP 枚举；
> - **CG-SRL（Certificate-Guided Shielded RL）**：护盾入训练回路，配合护盾一致性惩罚与去偏安全评论家；
> - **MFRS（MJX Fidelity-Robustness Spectrum）**：用 GPU 批并行生成保真度鲁棒性谱 `ρ_fid`；
> - **FCR（Fidelity-Calibrated Certificate）**：把保真度包络、语义、核裕度写进统一部署证书；
> - **CIL（Contact Identification Loop）**：真实接触数据驱动后验更新与证书重认证/重训练。
>
> IP 编号：IP-127~IP-132（共 6 个新增），升级 IP-122/123/125/126 以纳入保真度维。

## 2. 关键算法 伪代码

### IP-127 FEC

```python
def fidelity_envelope(real_logs, sim_model, bands, alphas):
    delta_f, theta_grid = {}, build_theta_grid(sim_model)
    for b in bands:
        residual = [project_band(lam_real - sim_model.contact_force(x, u, b), b)
                    for (x, u, lam_real) in real_logs]
        delta_f[b] = quantile(norm_W(residual), 1 - alphas[b])
    theta_cert = {th for th in theta_grid
                  if coverage(sim_model, real_logs, th, delta_f) >= 1 - alphas['cov']}
    return FidelityEnvelope(delta_f, theta_cert)
```

### IP-128 NVK

```python
def train_nvk(sampler, env_family, F, phi, tau_in, tau_out):
    for it in range(N):
        x, Sigma = sampler.sample()
        u = policy_proposal(x, Sigma)
        v_fp = min(gamma * V(phi, env_family.step(x, u, theta_s, dlam), Sigma)
                   for (theta_s, dlam) in F.sample_worst(x, u))
        label = 1.0 if short_horizon_qp_feasible(x, Sigma, F) else -1.0
        dual_gap = qp_duality_gap(x, Sigma, F, u)
        loss = huber(V(phi, x, Sigma), v_fp) \
             + rank_loss(V(phi, x, Sigma), label) \
             + consistency_penalty(V(phi, x, Sigma), dual_gap, tau_in)
        update(phi, loss)
    return KernelApprox(lambda x: V(phi,x) >= tau_in,
                        lambda x: V(phi,x) >= -tau_out)
```

### IP-129 CG-SRL

```python
def cg_srl_train(env, pi, V, F, C_plus, beta, eta, d):
    Qs = init_safety_critic()
    for ep in range(E):
        x = env.reset(); done = False
        while not done:
            u_nom = pi(x).sample()
            u_sh, gap = shield_with_worstcase(x, u_nom, V, F, C_plus)
            r, x2, done = env.step(u_sh)
            reward = r - eta * gap**2
            pi.update(reward, safety_lagrangian(beta, Qs(x, u_nom) - d))
            if gap < 1e-6:
                Qs.update(x, u_nom, failure_indicator(x2, done))
            x = x2
    return pi, Qs
```

### IP-130 MFRS

```python
def mjx_fidelity_spectrum(Sigma_hat, eps_s, F, batch, n_mc):
    worst = 1.0
    for _ in range(n_mc):
        Sigma = sample_ball(Sigma_hat, eps_s, worst_case=True)
        theta_s = sample_params(F.theta_cert)
        dlam = sample_worst_band(F.delta_f)
        env = mjx.make_batch(batch, Sigma, theta_s, dlam)
        worst = min(worst, mjx.empirical_viable(env).min())
    return worst
```

### IP-131 FCR

```python
def fidelity_certificate(traj, Sigma, F, posterior, budgets):
    K_margin = min(signed_distance(V, x, Sigma) for x in traj)
    delta_f = measure_residual(traj, F)
    if posterior.mass(F.theta_cert) < 1 - budgets.alpha:
        return ('reject', 'solver_out_of_envelope', posterior)
    if K_margin < budgets.theta_K or any(delta_f[b] > budgets.Theta_f[b] for b in delta_f):
        return ('reject', 'fidelity_budget_exceeded', K_margin, delta_f)
    rho_fid = mjx_fidelity_spectrum(Sigma, budgets.eps_s, F, budgets.batch, budgets.n_mc)
    if rho_fid < budgets.rho_min:
        return ('reject', 'fidelity_robustness_fail', rho_fid)
    return ('ok', FidelityCert(Sigma.core, traj.contacts, K_margin, rho_fid, delta_f,
                               F.theta_cert, evidence=traj.evidence))
```

### IP-132 CIL

```python
def contact_identification_loop(cert, real_stream, sim_model):
    posterior = cert.posterior
    while True:
        x, u, lam_real = real_stream.next()
        posterior = bayes_update(posterior, likelihood(sim_model, x, u, lam_real))
        if posterior.mass(cert.Theta_cert) < 1 - cert.alpha:
            if recalibrate(cert, posterior, real_stream.recent()):
                return ('recertified', cert)
            return ('retrain_required', posterior, collect_contact_evidence(real_stream))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| FEC | O(|D_real|·(|B|+|Θ_s|)) | O(|B|+|Θ_s|) | 分段分位数校准、包络覆盖检验 sound |
| NVK | O(N·(|F|·T+QP)) 训练 / O(1) 推理 | O(|φ|) | HJ 不动点收敛、`K_in⊆K_F⊆K_out` |
| CG-SRL | O(E·T·|F|·QP) | O(|φ|+|ψ|) | 拉格朗日约束、护盾残差有界、评论家去偏 |
| MFRS | O(n_mc·batch·T)（GPU 并行） | O(batch·T) | 最坏样本覆盖、MC 误差 ≤ ε_mc |
| FCR | O(|轨迹|·|φ| + n_mc·batch) | O(|φ|) | 后验质量、分段预算闭合 |
| CIL | O(|D_real|·|Θ_s|) | O(|Θ_s|) | 后验校准、重认证收敛 |

**正确性定理（Fidelity-Aware Semantic-Contact Soundness）**
假设第 55 轮 (A29)–(A32) 成立；并设
**(A33)** `λ_real-λ_sim(θ_s)` 在频段 `b` 上以概率 `≥1-p_f` 落在 `B(δ_f^{(b)})`；
**(A34)** NVK 泛化误差使 `P(∃x∈K_in\K_F) ≤ p_V`；
**(A35)** 护盾不可行时回退 `u_stop∈𝒳_safe`，失败概率 `≤ p_fb`；
**(A36)** MJX 对 `ρ_fid` 的 MC 估计误差 `≤ ε_mc`（概率 `≥1-p_mc`）；
**(A37)** 后验校准使 `P(θ_s∈Θ_cert|D_real) ≥ 1-α`。
则部署后单步安全概率
```
P_safe ≥ 1 - p_s - p_f - p_V - p_fb - p_mc - α
```
关键：**保真度包络吸收仿真误差、NVK 保守包含吸收学习误差、护盾兜底吸收残余、辨识后验把在役漂移变成可检测事件**。

## 5. 本轮最大风险

**一句话**：保真度包络与 NVK 把“仿真可行”升级为“包络内可行”，但 soundness **三重依赖接触误差可被分段包络、神经核不产生乐观假阳性、护盾入训练后不被策略利用**；一旦接触误差是结构化且状态相关的（尤其落脚冲击段）、或 NVK 在接触边界误报可行，证书会把“MuJoCo 说可行”当成“真实可行”，而策略会在训练中主动顶着证书边界换奖励，最终在最坏接触失真下由护盾放行一次不可逆跌倒——故必须以 **状态依赖扰动集 + 证书一致性保守训练 + 真实力反馈绊线** 三重护栏，宁可保守制动，绝不把仿真器的“高置信可行”当作现实的“已证实可行”。
