# 第 67 轮（承接第 66 轮「RAS 情绪驱动闭环」IP-224~233；灵感循环第 1 轮；本轮灵感：「移动底盘」×「多机协作」）

> 第 65 轮 VISTA 回答了「哪一层坏了」，第 66 轮 RAS 回答了「谁控制、控制多少」。但两者共享两个从未被检验的前提：**风险由一台固定底盘的机器人独自承担**，且**不同主体的故障彼此独立**。移动底盘与多机协作恰好同时击穿这两个前提。
>
> 移动底盘让「身体」变成可移动的安全资源：一台车可以后退、拉开、占位、接力；它既能消耗邻居的逃逸空间，也能替邻居创造逃逸空间。于是安全不再是单机的静态属性，而是**可被运动重构的空间资源**。多机协作则让安全变成**关系属性**：i 的安全取决于 j 将出现在哪里，而 j 的预测又取决于通信是否及时、双方的世界模型是否一致。更麻烦的是，同一块湿滑地面、同一段 WiFi 盲区会让多台车**同时**失效——在最需要保证的时刻，独立拼接局部证书恰恰是错的。
>
> 本轮命题是：
>
> **把多移动底盘车队的协作安全，重新表述为「局部证书在通信图上的可拼接性（sheaf gluing）+ 环路和乐（holonomy）+ 航位推算黑障时域」的联合问题；并把「移动」本身提升为消除协同障碍的恢复动作。** 框架名 **CARAVAN**（Certified Adaptive Reconfiguration And Velocity Allocation for Networked mobile manipulators，认证式可重构移动车队）。
>
> CARAVAN 问的不再是「哪层坏了」「该控制多少」，而是「**谁为哪一段共享时空的安全负责，以及在拓扑失效时车队能否用移动把证书重新拼起来**」。它在 VISTA（故障层）与 RAS（意图层）之上补上第三层——**协同责任层**，构成「故障层 ⊂ 意图层 ⊂ 协同责任层」的三闭环嵌套。

## 0. 直觉与动机

**灵感 1（移动底盘 → 安全是可重构的空间资源）**
直觉：固定底盘的机器人，安全裕度是「几何分配」的结果：机械臂够不到、护栏挡得住，风险就是一个局部标量。移动底盘把这件事变成了「时空协商」：在一条窄走廊里，两台车能否通过，不取决于任何一台单独是否「安全」，而取决于**谁先退、退多少、退到哪里**。更关键的是，底盘速度是**邻居安全裕度的一阶输入**：i 向 j 靠近 10cm，j 的可用逃逸空间就少 10cm，哪怕 j 原地不动。因此必须引入「风险转移」与「责任归属」：同一个动作，对 i 是前进，对 j 是风险。移动底盘因此既是风险源，也是风险消除器——这正是恢复动作的物理基础。

**灵感 2（多机协作 → 局部证书的拼接问题）**
直觉：每台车都能给出「我在我的坐标系里安全」的局部证书，但把 N 份局部证书直接取合取（AND）是未经证明的。它们在重叠时空上必须**一致**：i 相信 j 在 A 点，j 相信 i 在 B 点，若两个信念在环路上不能闭合，车队就共享了一个自相矛盾的世界。把每台车对邻居的相对位姿信念看作通信图边上的「移动标架」，沿环路复合就得到**和乐（holonomy）**：和乐非单位，就存在一个无法被任何全局一致的位姿分配满足的环路——这就是**协同故障**，它与 VISTA 的单机故障正交。一个耐人寻味的权衡是：树形拓扑没有环路、和乐恒为零，但存在单点失效；网状拓扑鲁棒，却天然容纳和乐。CARAVAN 的核心任务就是在这个拓扑权衡上做认证决策。

**灵感 3（通信中断 → 黑障时域与航位推算）**
直觉：协同的前提是「还能交换信息」。一旦通信进入黑障（盲区、拥塞、干扰），车队无法再拼接新证书，只能执行一段**在航位推算下仍然安全**的前缀。此时移动底盘引出了一个新的物理事实：轮式里程计的漂移会随行驶距离增长，打滑会放大它；**车开得越远、越快、越盲，邻居间相对位置的不确定性膨胀得越快**。于是「移动」第一次直接进入安全证书的时间维度：不是「能不能动」，而是「在失去通信的情况下，还能安全地动多久」。这把移动底盘、通信、认证前缀三者绑成了一个可计算的黑障安全界。

**灵感 4（共因故障 → 独立性的幻觉）**
直觉：多机系统最危险的失效不是「一台坏、其他好」，而是「一起坏」：同一块油污让四台车同时打滑，同一段网络让整队同时失联，同一个感知模型在同一类反光地面上同时误检。此时局部证书各自的 α_i 都成立，但它们**不再是独立事件**。由 Fréchet–Hoeffding 界，仅知道边缘概率时，车队至少以 max_i α_i 的概率失效，而不是 1-∏(1-α_i)；盲目的独立拼接会把「几乎必然的共因失效」认证成「极低概率事故」。因此必须显式估计一个共因隐变量，并对最坏共因做鲁棒认证，而不是对边缘概率做乘法。

**灵感 5（灵感合流 → CARAVAN 十件套）**
CARAVAN = (MBC, CSG, CFA, CCM, DBH, TRR, AHA, RAC, AIC-F, FSC)：
1. **MBC Mobile-Base Coupling**：把底盘运动对邻居裕度的影响写成耦合系数与责任矩阵；
2. **CSG Certificate Sheaf over Graph**：局部证书、重叠限制映射、环路和乐与协同障碍；
3. **CFA Coordination Fault Attribution**：把协同故障、共因、权限错配加入假设集，定位最小责任环/责任割；
4. **CCM Common-Cause Monitor**：估计共因隐变量，输出相关膨胀与鲁棒风险上界；
5. **DBH Dead-reckoning Blackout Horizon**：在给定的里程计漂移模型下计算黑障安全前缀；
6. **TRR Topology Reconfiguration & Rendezvous**：用后退、分散、接力、绕行等移动动作消除障碍；
7. **AHA Authority Handoff Algebra**：领导权/接力权/操作权的两阶段认证交接，杜绝分裂脑；
8. **RAC Risk-Aware Convoy control**：带延迟预测的分布式 CBF/QP 控制，保证间距与可通行；
9. **AIC-F Interference & Byzantine 扩展**：节点、边、共因、拜占庭四类干扰的统一刻画；
10. **FSC Fleet Safety Certificate**：把上述证据合成为可验证的车队证书 J_CARAVAN。

**灵感 6（与 VISTA/RAS 的关系：三层嵌套，而非替代）**
- VISTA 回答「哪一层坏了」（技术故障归因，~10ms 级）；
- RAS 回答「谁控制、控制多少」（意图/风险闭环，~100ms 级）；
- **CARAVAN 回答「谁为哪段共享时空负责、拓扑失效时如何重构」（协同责任层，~1s 级）**。
三层是不同时间尺度的嵌套：CARAVAN 只消费各机的 `J_VISTA`、`J_RAS` 与共享信念，输出舰队级权限与认证前缀；它**不得改写**单机的故障归因与风险缩放。反过来，任何单机降级都必须触发一次重新拼接（re-gluing），否则局部降级会被拓扑上的旧证书「掩盖」。这与第 66 轮「实时流只早停、语义流做归因」的分离原则同构。

## 1. 形式化定义（增量：定义 251–268）

- **定义 251（CARAVAN 总览）**：`CARAVAN = (MBC, CSG, CFA, CCM, DBH, TRR, AHA, RAC, AIC-F, FSC)`。定位：在 VISTA（故障层）与 RAS（意图层）之上新增**协同责任层**。不变式：所有信念融合、和乐计算、共因估计、重构规划只在语义流；实时流只做 CBF-QP 投影、黑障界早停、权限令牌校验，零学习写操作。
- **定义 252（异构车队状态）**：车队 `V = {1,…,N}`，机器人 i 的状态 `x_i = (b_i, q_i, u_i)`，其中 `b_i ∈ SE(2)` 为平面底盘位姿（可扩展到 SE(3)），`q_i ∈ Q_i` 为机械臂构型，`u_i ∈ U_i(x_i)` 为可行速度集。异构底盘（差速/全向/轮腿）的差异全部编码进能力多面体 `U_i`。车队状态 `x = (x_1,…,x_N)`。
- **定义 253（时变通信图）**：`G_t = (V, E_t, ℓ_t)`，`(i,j) ∈ E_t` 当且仅当双向时延 `ℓ_ij(t) ≤ ℓ_max` 且两机时空邻域有重叠。由于底盘移动会改变邻接关系，**拓扑本身是控制变量**：`E_{t+1}` 依赖于 `u_t`。
- **定义 254（成对裕度与移动底盘耦合）**：成对安全裕度
  ```
  h_ij(x) = ||b_i - b_j|| - d_min(χ_i, χ_j) - τ_safe·||v_i - v_j||
  ```
  其中 `χ_i` 为底盘类型, `v_i` 为底盘速度。`h_ij ≥ 0` 表示成对安全。耦合系数与责任矩阵：
  ```
  κ_ij = ||∂h_ij/∂b_i||,   R_ij = κ_ij / (κ_ij + κ_ji + ε) ∈ [0,1],   Σ_i R_ij = 1
  ```
  `R_ij` 回答「这段裕度主要由谁造成」，是责任账本与公平重构的基础。
- **定义 255（证书层与限制映射）**：给每台机分配局部安全集 `C_i = {x_i : h_i(x_i) ≥ 0}`，给每条边分配重叠安全集 `C_ij = {(x_i,x_j) : h_ij ≥ 0}`，限制映射 `ρ_i : C_i → C_ij` 为投影。车队证书是一个截面 `s ∈ Γ(G_t, C)`，满足 `s|_{C_ij}` 在重叠上一致。**协同障碍** `o(G_t) = δ(s) ∈ H^1(G_t; C)`；`o = 0` 当且仅当局部证书可拼接。
- **定义 256（协同故障假设）**：`ℋ_coord = {H0 正常, H_edge 边失效, H_cycle 环路不自洽, H_common 共因, H_handoff 权限错配}`。后验 `P(H_coord | o, G_t, e) ∝ p(o | H_coord) P(H_coord)`，与 VISTA/RAS 的假设做联合：
  ```
  P(H_vista, H_ras, H_coord | ρ, face, o) ∝ p(ρ | H_vista) · p(face | H_ras) · p(o | H_coord) · P(H_vista, H_ras, H_coord)
  ```
- **定义 257（边残差与环路和乐）**：机上信念用相对位姿表示。i 对 j 的信念为 `T̂_i^j`，j 对 i 的信念为 `T̂_j^i`。边残差：
  ```
  e_ij = log_SE2( (T̂_i^j)^{-1} · T̂_j^i ) ∈ ℝ^3
  ```
  对基本环 `C = (i_1 → i_2 → … → i_k → i_1)`，和乐
  ```
  g_C = exp(e_{i_1 i_2}) ⊕ exp(e_{i_2 i_3}) ⊕ … ⊕ exp(e_{i_k i_1}),   o_C = ||log_SE2(g_C)||
  ```
  协同障碍 `o(G_t) = max_C o_C`，最小责任环 `C* = argmax_C o_C`。树形图无基本环，故 `o ≡ 0`，但边失效会变成割点风险。
- **定义 258（共因隐变量与相关膨胀）**：`c_t ∈ {floor, network, model, adversary, none}`。对每台机的局部失效指示 `F_i`，定义
  ```
  β(c) = P(∩_i F_i | c) / ∏_i P(F_i | c) ≥ 1
  ```
  为共因相关膨胀。车队失效上界取最坏共因：
  ```
  B_F = max_c [ P(c) · P(∪_i F_i | c) ],   要求 B_F ≤ δ_common
  ```
  仅凭边缘 `P(F_i)` 无法把 `B_F` 压到 `Σ_i P(F_i)` 以下（见定理 12 的 Fréchet 论证）。
- **定义 259（航位推算协方差与黑障安全界）**：黑障区间 `[t, t+D]` 内，底盘位姿按 `b̂_i(t+s)` 航位推算，协方差
  ```
  Σ_i(s) = Σ_i(0) + s·Q_i + s²·Q_slip(χ_i, terrain)
  ```
  相对协方差 `Σ_ij(s) = Σ_i(s) + Σ_j(s)`。相对预测裕度 `m_ij(s) = ||b̂_i(s) - b̂_j(s)|| - d_min`。违约概率用 sub-Gaussian 上界
  ```
  P_viol(s) ≤ 2·exp( -m_ij(s)² / (2·tr Σ_ij(s)) )
  ```
  **黑障安全前缀** `k_D = max{ k : ∀s ≤ k, max_{ij} P_viol(s) ≤ δ_b }`，且 `k·Δt ≤ D`。
- **定义 260（重构机动）**：机动集合 `Π = {STOP, SEPARATE, RELAY, REJOIN, DETOUR, HANDOFF}`。每个机动 `π` 有代价
  ```
  J(π) = w_t·T(π) + w_e·E(π) + w_r·R(π)
  ```
  且其**过渡段本身必须可认证**。规划：
  ```
  π* = argmin_{π∈Π} J(π)   s.t.  o(G_{t+T(π)}) = 0,   k*_fleet ≥ T(π)/Δt
  ```
  `STOP` 永远可行，但可能死锁；活性由定理 13 的附加条件保证。
- **定义 261（权限交接代数）**：权限令牌 `A ∈ {LEAD(i), MESH, RELAY(i→j), AUTONOMOUS}`。交接是两阶段协议：`propose → ack(quorum) → commit`，令牌携带单调递增的 `token_id` 与 `J_CARAVAN` 摘要。安全条件：同一连通分量内至多一个 `LEAD`；`token_id` 严格单调；提交失败时幂等回滚到上一持有者。
- **定义 262（车队认证前缀）**：`k*_fleet = min{ k_VISTA/RAS, k_D, k_MIC, k_handoff }`，并要求对每个 `s ≤ k*_fleet` 存在一致的拼接见证 `w_s`。只派发 `A[:k*_fleet]`。
- **定义 263（RAC 分布式控制律）**：给定名义控制 `u_i^0`，每台机解
  ```
  u_i = argmin ||u_i - u_i^0||²
        s.t.  u_i ∈ U_i
              ḣ_ij + α·h_ij ≥ 0,   ∀ j ∈ N(i)
  ```
  其中 `ḣ_ij` 用延迟预测 `ℓ_ij` 后的邻居状态估计，`α > 0` 为 CBF 增益。该 QP 可按边分解，用分布式对偶求解。
- **定义 264（异构能力归一）**：把各底盘映射为能力多面体 `U_i`。若 `U_i ⊆ U_j`，则用 j 的能力替换 i 得到的是**保守但可靠**的证书；证书在包含序下单调。这使差速、全向、轮腿可在同一证书框架内比较。
- **定义 265（AIC-F 干扰集）**：`ℰ_F = ℰ_node × ℰ_edge × ℰ_common × ℰ_byz`：节点故障（打滑、传感器坏）、边故障（时延、丢包、分区）、共因故障（同源环境/模型）、拜占庭故障（机器人广播伪造状态）。若至多 `f` 台拜占庭且图 `(f+1)`-连通，则权限与信念的鲁棒一致性可保。
- **定义 266（责任账本）**：`L_ij = ∫ R_ij(t)·[h_ij(t)]_- dt` 记录 i 对边 (i,j) 累积的「风险债」。它既用于事后归因，也用于重构时的公平性约束 `|L_ij - L_ji| ≤ ε_fair`。
- **定义 267（形成/编队语义）**：编队 `F = (G_t, {h̄_ij})` 只规定图结构与期望边裕度；`LEAD` 只是权限令牌的一种，不改变物理模型。于是 leader-follower 与 mesh 是同一框架下的两种拓扑实例，可被 TRR 连续切换。
- **定义 268（三层嵌套不变式）**：任何 TRR 重构、AHA 交接、拓扑切换都必须保持 VISTA 故障归因的有效性（不得掩盖单机故障）与 RAS 风险缩放的安全性（不得放宽风险上界）；反之，单机 VISTA/RAS 的降级不得在未重新拼接的情况下静默改变舰队拓扑语义。`J_CARAVAN` 的有效性以该不变式为前提。

import numpy as np
from itertools import combinations


class MobileBaseCoupling:                       # IP-234 MBC
    def margin(self, x, i, j):
        d = np.linalg.norm(x[i].p - x[j].p)
        return d - d_min(x[i].chassis, x[j].chassis) \
                 - tau_safe * np.linalg.norm(x[i].v - x[j].v)

    def coupling(self, x, i, j):
        k_i = np.linalg.norm(finite_diff(self.margin, x, i, j, axis=i))
        k_j = np.linalg.norm(finite_diff(self.margin, x, i, j, axis=j))
        return {'kappa_i': k_i, 'kappa_j': k_j,
                'R_ij': k_i / (k_i + k_j + 1e-9)}


class CertificateSheaf:                         # IP-235 CSG
    """局部证书在通信图上的拼接；基本环和乐即协同障碍。"""
    def __init__(self, G, beliefs):
        self.G, self.beliefs = G, beliefs
        self.tree = spanning_tree(G)            # BFS/DFS 生成树
        self.cycles = fundamental_cycles(G, self.tree)

    def edge_residual(self, i, j):
        # i 对 j 的信念 vs j 对 i 的信念，取逆后落到 se(2)
        T_i_j = self.beliefs[i].pose_of(j)
        T_j_i = self.beliefs[j].pose_of(i)
        return log_se2(np.linalg.inv(T_i_j) @ T_j_i)

    def holonomy(self, cycle):
        g = np.eye(3)
        for i, j in cycle:
            g = g @ exp_se2(self.edge_residual(i, j))
        return np.linalg.norm(log_se2(g))

    def glue(self):
        scores = {C: self.holonomy(C) for C in self.cycles}
        if not scores:
            return 0.0, None                # 树：无环，无和乐
        C_star = max(scores, key=scores.get)
        return scores[C_star], C_star       # (o, 最小责任环)


class CoordinationFaultAttribution:             # IP-236 CFA
    def attribute(self, o, C_star, edge_res, local_posts):
        post = {}
        post['H0'] = float(o <= tau_holonomy)
        post['H_cycle'] = float(o > tau_holonomy)
        post['H_edge'] = max(edge_res.values(), default=0.0)
        post['H_common'] = self.ccm.posterior('common')
        post['H_handoff'] = float(self.authority.split_brain)
        return normalize(post), C_star


class CommonCauseMonitor:                       # IP-238 CCM
    def update(self, evidence):
        # 证据：地面摩擦估计、RSSI/丢包率、同模型残差相关性
        self.prior = bayes_update(self.prior, evidence)
        c_hat = argmax(self.prior)
        beta = self.correlation_inflation[c_hat]
        return {'c_hat': c_hat, 'beta': beta,
                'B_F': self.worst_case_union_bound(self.prior)}


class BlackoutHorizon:                          # IP-239 DBH  (定义 259)
    def safe_prefix(self, sched, Sigma0, Q, Q_slip, delta_b, h):
        lo, hi = 0, len(sched) - 1
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if self.max_violation(sched, mid, Sigma0, Q, Q_slip) <= delta_b:
                lo = mid
            else:
                hi = mid - 1
        return lo

    def violation(self, m, Sigma):
        return 2.0 * np.exp(-(m ** 2) / (2.0 * np.trace(Sigma) + 1e-12))


class ReconfigurationPlanner:                   # IP-240 TRR
    MANEUVERS = ['STOP', 'SEPARATE', 'RELAY', 'REJOIN', 'DETOUR', 'HANDOFF']

    def plan(self, G, o, C_star, budget):
        best = None
        for pi in self.MANEUVERS:
            if not self.transition_certifiable(pi):
                continue                        # 过渡段也必须认证
            J = self.cost(pi)                   # w_t·T + w_e·E + w_r·R
            if self.eliminates(pi, G, C_star) and (best is None or J < best[1]):
                best = (pi, J)
        return best[0] if best else 'STOP'      # STOP 是安全兜底


class AuthorityHandoff:                          # IP-241 AHA
    def handoff(self, src, dst, token):
        if not self.quorum_ok(dst):
            return self.rollback(token)
        ack = self.send(dst, token.next(dst), phase='PROPOSE', timeout=self.t)
        if not ack:
            return self.rollback(token)
        return self.broadcast(token.commit(dst), phase='COMMIT')


class FleetRound:
    def step(self, M, fleet_obs):
        # 1) 各机局部 VISTA / RAS（并行、只产出本地证书）
        local = [M[i].vista_ras_round(obs_i) for i, obs_i in enumerate(fleet_obs)]

        # 2) 信念融合 + 时变通信图
        beliefs = [M[i].belief.update(obs_i) for i, obs_i in enumerate(fleet_obs)]
        G = build_comm_graph(beliefs, latency=obs_latency(fleet_obs))

        # 3) MBC：成对裕度与责任
        margins = {(i, j): M.mbc.margin(fleet_obs, i, j)
                   for i, j in G.edges}

        # 4) CSG：拼接与协同障碍
        o, C_star = M.sheaf(G, beliefs).glue()

        # 5) CCM：共因
        cc = M.ccm.update(common_cause_evidence(fleet_obs))

        # 6) 可拼接且共因可控：算黑障前缀并派发 RAC
        if o <= M.tau_holonomy and cc['B_F'] <= M.delta_common:
            k_D = M.dbh.safe_prefix(M.sched, M.Sigma0, M.Q, M.Q_slip,
                                    M.delta_b, M.dt)
            k = min(min(l.k_local for l in local), k_D, M.k_handoff)
            A = M.vista.dispatch_prefix(k)
            u = M.rac.solve(A, margins, beliefs, latency=obs_latency(fleet_obs))
            return {'mode': 'NOMINAL', 'k': k, 'o': o,
                    'u': u, 'J': M.fsc.issue(local, o, cc, k)}

        # 7) 不可拼接：归因 → 用移动重构 → 只执行认证过渡段
        post, C_star = M.cfa.attribute(o, C_star, M.edge_res, local)
        pi = M.trr.plan(G, o, C_star, M.budget)
        k = M.trr.certified_transition_len(pi)
        M.execute_reconfiguration(pi, k)
        return {'mode': pi, 'k': k, 'o': o, 'post': post,
                'J': M.fsc.issue(local, o, cc, k, maneuver=pi)}
```

## 3. 推导

**引理 11（环路和乐刻画协同障碍）** 设通信图 `G_t` 的圈秩为 `μ = |E_t| - |V| + 1`。则协同障碍空间维数不超过 `μ·dim(SE(2)) = 3μ`；`o(G_t) = 0` 当且仅当所有基本环的和乐为单位。若 `G_t` 为树（`μ = 0`），则 `o ≡ 0`，但任一边失效即产生割点，协同风险从「和乐」转为「连通性」。**证明要点**：沿生成树传播信念可唯一确定所有节点信念；每条非树边产生一个基本环，环上复合残差即该边的和乐；所有环的和乐由基本环线性生成，故只需检查 `μ` 个基本环。树无基本环，故无障碍。□

**引理 12（黑障安全界的单调性与可计算性）** 在定义 259 的随机游走漂移模型下，`P_viol(s)` 关于 `s` 单调不减，故 `k_D` 可由二分搜索在 `O(log(D/Δt)·|E|)` 内求得。若两机以相对速度 `v_rel` 继续接近且 `m_ij(0) > 0`，则近似有
```
k_D ≈ ( m_ij(0)² ) / ( 2·tr(Q_rel) + 2·v_rel·Δt·m_ij(0) )
```
即黑障安全时长与初始裕度平方成正比、与相对漂移率成反比。**证明要点**：`m_ij(s)` 随 `s` 递减、`tr Σ_ij(s)` 随 `s` 递增，故违约概率上界单调；对 sub-Gaussian 尾界解出 `m² ≥ 2 trΣ·ln(2/δ_b)` 即得。□

**引理 13（共因下独立拼接不可行）** 设各机边缘失效概率均为 `α`。仅由边缘概率，车队联合失效概率的可行区间为 `[α, min(1, Nα)]`（Fréchet–Hoeffding）。当共因使失效完全正相关时，实际值取到上端 `min(1, Nα)`；此时独立拼接给出的 `1-(1-α)^N` 严重低估风险。**证明要点**：联合分布的边缘固定后，`P(∪F_i)` 的下界由 `max_i P(F_i)` 给出（完全正相关），上界由 `min(1, Σ P(F_i))` 给出；共因隐变量把质量集中到「全坏/全好」两个原子，故逼近上界。□

**定理 11（车队证书的可靠性）** 若对前缀内每个 `s ≤ k*_fleet` 有：(i) 各机 `J_VISTA^i, J_RAS^i` 有效；(ii) 和乐 `o_s ≤ τ_holonomy`；(iii) 黑障违约概率 `≤ δ_b`；(iv) 共因上界 `B_F ≤ δ_common`；(v) 每个连通分量至多一个权限持有者；则在该前缀内，车队发生碰撞或分裂脑的概率不超过
```
N·α_local + δ_b + δ_common
```
其中 `α_local` 为单机局部证书的失效概率。**证明要点**：碰撞由 RAC 的 CBF 约束逐边保证；和乐条件保证所有机对同一共享时空使用一致的相对位姿预测，故 CBF 约束不会因预测分歧而互相矛盾；黑障条件覆盖通信缺失时的航位推算误差；权限唯一性由令牌单调性与两阶段提交保证；共因项用引理 13 的鲁棒上界替代独立拼接。□

**定理 12（可重构活性与安全兜底）** 在能力多面体有界、单步机动可认证、且存在一个可达的可拼接配置的假设下，TRR 在有限步内到达该配置；若不存在可达的可拼接配置，则 TRR 输出 `STOP`，并以认证的制动前缀使全队停在一个成对安全但不保证任务完成的配置。**证明要点**：`Π` 有限，每个机动的代价严格正；TRR 只在 `o` 不降时拒绝该机动，故代价序列在可行机动上单调下降，不会无限循环；`STOP` 的过渡段由 CBF 制动保证，故兜底安全。□

**定理 13（权限交接无分裂脑）** 在异步网络、任意消息延迟但最终可达的假设下，AHA 的两阶段令牌协议保证同一连通分量内任一时刻至多一个 `LEAD`；交接失败时回滚到上一持有者，且该回滚是幂等的。**证明要点**：`token_id` 全序 + 提交需要 `dst` 所在重叠区 quorum；两个候选 `LEAD` 若同时存在，其 `token_id` 必可比较，较小者因缺少 quorum 无法提交；回滚携带旧 `token_id`，重复执行不改变状态。□

**定理 14（异构归一化的保守性）** 若 `U_i ⊆ U_j`，则以 `U_j` 替换 `i` 得到的能力上界不会低估 `i` 的实际可达集，故证书在包含序下单调且保守。**证明要点**：CBF-QP 的可行域随能力集扩大而扩大，故替换只会放宽约束；对安全性而言，放宽的是「i 能做什么」而非「i 被要求做什么」，因此原证书仍然成立。□

## 6. 本轮最大风险

**一句话**：CARAVAN 把「通信黑障期间仍能靠航位推算保持间距」当作可认证前提，但**底盘打滑/磁场畸变与通信盲区往往同源共发**（同一段湿滑隧道、同一片金属反射区），此时 `Σ_slip` 被系统性低估、`k_D` 被系统性高估，车队会在「已认证」的自信中把安全前缀执行到物理冲突——本方案的全部可靠性都押在「共因隐变量可被及时识别、漂移模型在盲区内仍成立」这一假设上。

**次级风险与缓解**：
1. **和乐误判**：时延造成的暂时残差被当成拓扑故障 → 对 `e_ij` 做时间一致性滤波，并要求 `o` 连续多帧超限才触发 TRR；
2. **共因不可观**：地面摩擦、RSSI、模型残差可能拿不到 → 用多源弱证据做贝叶斯融合，并在证据缺失时把 `B_F` 设为悲观上界、自动缩短 `k_D`；
3. **重构代价过高**：频繁后退/绕行导致任务不可用 → 给 `J(π)` 加任务进度项，并设最小重构间隔；
4. **拓扑抖动**：移动引起 `E_t` 频繁变化 → 对拓扑切换做滞回（hysteresis）与令牌版本号，避免和乐与权限同时抖动；
5. **拜占庭与共因叠加**：坏机器人可伪造「和乐为零」→ 用 `(f+1)`-连通 + 多路径交叉校验，权限只授予通过独立路径验证的节点；
6. **异构标定偏差**：不同底盘的 `d_min` 与轮径标定误差会污染 `h_ij` → 在线标定 + 证书中显式携带标定不确定度，纳入 `Σ_i`。

```
`R_ij` 表示边 (i,j) 的裕度主要由谁造成，用于责任归因与公平重构。

**定义 255（证书层与限制映射）** 局部安全集 `C_i={x_i:h_i≥0}`，重叠集 `C_ij={(x_i,x_j):h_ij≥0}`，限制映射 `ρ_i:C_i→C_ij`。车队证书是截面 `s∈Γ(G_t,C)`；协同障碍 `o(G_t)=δ(s)∈H^1`，`o=0` 当且仅当可拼接。

**定义 256（协同故障假设）**
```
ℋ_coord = {H0 正常, H_edge 边失效, H_cycle 环路不自洽, H_common 共因, H_handoff 权限错配}
P(H_vista,H_ras,H_coord | ρ,face,o) ∝ p(ρ|H_vista)·p(face|H_ras)·p(o|H_coord)·P(·)
```

**定义 257（边残差与环路和乐）**
```
e_ij = log_SE2( (T̂_i^j)^{-1} · T̂_j^i ) ∈ ℝ^3
g_C  = exp(e_{i1i2}) ⊕ exp(e_{i2i3}) ⊕ … ⊕ exp(e_{ik i1})
o(G_t) = max_C ||log_SE2(g_C)||,   C* = argmax_C o_C
```
树形图 `μ=|E|-|V|+1=0`，故 `o≡0`；但任一边失效形成割点，协同风险从「和乐」转为「连通性」。

**定义 258（共因与相关膨胀）**
```
β(c) = P(∩_i F_i | c) / ∏_i P(F_i | c) ≥ 1
B_F  = max_c [ P(c) · P(∪_i F_i | c) ],   要求 B_F ≤ δ_common
```

**定义 259（黑障协方差与安全界）**
```
Σ_i(s) = Σ_i(0) + s·Q_i + s²·Q_slip(χ_i, terrain)
m_ij(s) = ||b̂_i(s)-b̂_j(s)|| - d_min
P_viol(s) ≤ 2·exp( -m_ij(s)² / (2·tr(Σ_i(s)+Σ_j(s))) )
k_D = max{ k : ∀s≤k, max_ij P_viol(s) ≤ δ_b },   k·Δt ≤ D
```

**定义 260（重构机动）**
```
J(π) = w_t·T(π) + w_e·E(π) + w_r·R(π)
π* = argmin_{π∈Π} J(π)  s.t.  o(G_{t+T(π)})=0,  k*_fleet ≥ T(π)/Δt
```
每个机动的过渡段本身必须可认证；`STOP` 是安全兜底但可能死锁。

**定义 261（权限交接代数）** `A∈{LEAD(i),MESH,RELAY(i→j),AUTONOMOUS}`；两阶段 `propose→ack(quorum)→commit`，令牌含单调 `token_id` 与 `J_CARAVAN` 摘要；同一连通分量至多一个 `LEAD`，失败幂等回滚。

**定义 262（车队认证前缀）**
```
k*_fleet = min{ k_VISTA/RAS, k_D, k_MIC, k_handoff }
```
并要求 `∀s≤k*_fleet` 存在一致拼接见证 `w_s`；只派发 `A[:k*_fleet]`。

**定义 263（RAC 控制律）**
```
u_i = argmin ||u_i-u_i^0||²   s.t.  u_i∈U_i,  ḣ_ij+α·h_ij ≥ 0, ∀j∈N(i)
```
`ḣ_ij` 用延迟 `ℓ_ij` 后的邻居状态预测；可按边分解、分布式对偶求解。

**定义 264（异构能力归一）** 各底盘映射为 `U_i`；`U_i⊆U_j` 时以 `U_j` 替换 `i` 得保守可靠证书，证书在包含序下单调。

**定义 265（AIC-F 干扰集）**
```
ℰ_F = ℰ_node × ℰ_edge × ℰ_common × ℰ_byz
```
若至多 `f` 台拜占庭且图 `(f+1)`-连通，则鲁棒一致性可保。

**定义 266（责任账本）** `L_ij = ∫ R_ij(t)·[h_ij(t)]_- dt`，用于事后归因与公平约束 `|L_ij-L_ji|≤ε_fair`。

**定义 267（编队语义）** 编队 `F=(G_t,{h̄_ij})` 只规定图结构与期望边裕度；`LEAD` 仅是权限令牌的一种。leader-follower 与 mesh 是同一框架的两种拓扑实例。

**定义 268（三层嵌套不变式）** 任何 TRR/AHA/拓扑切换不得掩盖 VISTA 单机故障、不得放宽 RAS 风险上界；反之，单机降级必须触发重新拼接，不得静默改变舰队拓扑语义。

# IP-234 MBC：移动底盘耦合与责任
class MobileBaseCoupling:
    def margin(self, x, i, j):
        return (norm(x[i].p - x[j].p)
                - d_min(x[i].chassis, x[j].chassis)
                - tau_safe * norm(x[i].v - x[j].v))

    def coupling(self, x, i, j):
        k_i = norm(grad(self.margin, x, i, j, wrt=i))
        k_j = norm(grad(self.margin, x, i, j, wrt=j))
        return k_i, k_j, k_i / (k_i + k_j + 1e-9)


# IP-235 CSG：证书拼接与和乐
class CertificateSheaf:
    def __init__(self, G, beliefs):
        self.tree = spanning_tree(G)
        self.cycles = fundamental_cycles(G, self.tree)
        self.beliefs = beliefs

    def edge_residual(self, i, j):
        return log_se2(inv(self.beliefs[i].pose_of(j))
                       @ self.beliefs[j].pose_of(i))

    def holonomy(self, cycle):
        g = eye(3)
        for i, j in cycle:
            g = g @ exp_se2(self.edge_residual(i, j))
        return norm(log_se2(g))

    def glue(self):
        scores = {C: self.holonomy(C) for C in self.cycles}
        if not scores:
            return 0.0, None
        C_star = max(scores, key=scores.get)
        return scores[C_star], C_star


# IP-238 DBH：黑障安全前缀
class BlackoutHorizon:
    def violation(self, m, Sigma):
        return 2.0 * exp(-(m**2) / (2.0 * trace(Sigma) + 1e-12))

    def safe_prefix(self, sched, Sigma0, Q, Q_slip, delta_b, dt):
        lo, hi = 0, len(sched) - 1
        while lo < hi:
            mid = (lo + hi + 1) // 2
            Sigma = Sigma0 + mid*Q + (mid*dt)**2 * Q_slip
            if max(self.violation(m, Sigma) for m in sched[:mid+1]) <= delta_b:
                lo = mid
            else:
                hi = mid - 1
        return lo


# IP-239 TRR：用移动消除协同障碍
class ReconfigurationPlanner:
    MANEUVERS = ['STOP', 'SEPARATE', 'RELAY', 'REJOIN', 'DETOUR', 'HANDOFF']

    def plan(self, G, o, C_star, budget):
        best = None
        for pi in self.MANEUVERS:
            if not self.transition_certifiable(pi):
                continue
            if not self.eliminates(pi, G, C_star):
                continue
            J = self.cost(pi)          # w_t·T + w_e·E + w_r·R
            if best is None or J < best[1]:
                best = (pi, J)
        return best[0] if best else 'STOP'


# IP-240 AHA：两阶段权限交接
class AuthorityHandoff:
    def handoff(self, src, dst, token):
        if not self.quorum_ok(dst):
            return self.rollback(token)
        if not self.send(dst, token.next(dst), phase='PROPOSE', timeout=T):
            return self.rollback(token)
        return self.broadcast(token.commit(dst), phase='COMMIT')


# IP-241 RAC：带延迟预测的分布式 CBF-QP
def rac_step(u_nominal, margins, beliefs, latency, alpha, U):
    constraints = []
    for j, h in margins.items():
        h_dot = predicted_h_dot(beliefs, j, latency)
        constraints.append(h_dot + alpha * h >= 0)
    return solve_qp(u_nominal, constraints, U)


# IP-243 FSC：车队闭环
def CARAVAN_round(M, fleet_obs):
    local = [M[i].vista_ras_round(obs) for i, obs in enumerate(fleet_obs)]
    beliefs = [M[i].belief.update(obs) for i, obs in enumerate(fleet_obs)]
    G = build_comm_graph(beliefs, latency=obs_latency(fleet_obs))

    margins = {(i, j): M.mbc.margin(fleet_obs, i, j) for i, j in G.edges}
    o, C_star = M.sheaf(G, beliefs).glue()
    cc = M.ccm.update(common_cause_evidence(fleet_obs))

    if o <= M.tau_holonomy and cc['B_F'] <= M.delta_common:
        k_D = M.dbh.safe_prefix(M.sched, M.Sigma0, M.Q, M.Q_slip,
                                M.delta_b, M.dt)
        k = min(min(l.k_local for l in local), k_D, M.k_handoff)
        u = rac_step(M.nominal, margins, beliefs,
                     obs_latency(fleet_obs), M.alpha, M.U)
        return ('NOMINAL', k, u, M.fsc.issue(local, o, cc, k))

    post, C_star = M.cfa.attribute(o, C_star, M.edge_res, local)
    pi = M.trr.plan(G, o, C_star, M.budget)
    k = M.trr.certified_transition_len(pi)
    M.execute_reconfiguration(pi, k)
    return (pi, k, None, M.fsc.issue(local, o, cc, k, maneuver=pi))

## 4. 推导与正确性论证

**引理 11（和乐判定协同障碍）** 圈秩 `μ=|E|-|V|+1`，障碍空间维数 `≤3μ`；`o=0` 当且仅当所有基本环和乐为单位。树形图 `μ=0 ⇒ o≡0`，但边失效产生割点风险。*证明*：生成树唯一确定节点信念，每条非树边产生一个基本环；环空间由基本环生成。□

**引理 12（黑障界单调可算）** `P_viol(s)` 关于 `s` 单调不减，`k_D` 可二分求得；近似
```
k_D ≈ m_ij(0)² / ( 2·tr(Q_rel) + 2·v_rel·Δt·m_ij(0) )
```
即安全时长与初始裕度平方成正比、与相对漂移率成反比。*证明*：`m_ij(s)` 递减、`trΣ_ij(s)` 递增；对 sub-Gaussian 尾界解出 `m²≥2trΣ·ln(2/δ_b)`。□

**引理 13（共因下独立拼接不可行）** 边缘失效概率均为 `α` 时，联合失效概率的 Fréchet 可行区间为 `[α, min(1,Nα)]`；完全正相关时取上端，独立拼接的 `1-(1-α)^N` 严重低估。*证明*：固定边缘后，并集概率下界为 `max_i P(F_i)`、上界为 `min(1,Σ_i P(F_i))`；共因把质量集中到「全坏/全好」原子。□

**定理 11（车队证书可靠性）** 若前缀内 (i) 各机 `J_VISTA/J_RAS` 有效；(ii) `o_s≤τ_holonomy`；(iii) 黑障违约 `≤δ_b`；(iv) `B_F≤δ_common`；(v) 每个连通分量至多一个权限持有者，则碰撞或分裂脑概率 `≤ N·α_local + δ_b + δ_common`。*证明*：RAC 逐边 CBF 保证碰撞约束；和乐保证共享时空预测一致，使 CBF 不因分歧矛盾；黑障覆盖通信缺失；令牌单调保证权限唯一；共因用引理 13 的鲁棒上界。□

**定理 12（可重构活性与安全兜底）** 在能力集有界、单步机动可认证、且存在可达可拼接配置时，TRR 有限步到达；否则输出 `STOP` 并以认证制动前缀使全队停在成对安全配置。*证明*：`Π` 有限、代价正；TRR 拒绝不降 `o` 的机动，可行机动上代价单调下降，故不循环；`STOP` 由 CBF 制动保证。□

**定理 13（权限交接无分裂脑）** 异步、最终可达网络下，两阶段令牌协议保证同一连通分量任一时刻至多一个 `LEAD`；失败回滚幂等。*证明*：`token_id` 全序 + quorum 提交；两个候选的令牌必可比较，较小者缺 quorum；回滚携带旧 `token_id`，重复执行状态不变。□

**定理 14（异构归一化保守性）** `U_i⊆U_j` 时以 `U_j` 替换 `i` 不低估可达集，故证书在包含序下单调保守。*证明*：CBF-QP 可行域随能力集扩大而扩大；放宽的是「能做什么」而非「被要求做什么」。□

## 7. 本轮最大风险

**一句话**：CARAVAN 把「黑障期间靠航位推算保间距」当作可认证前提，但底盘打滑/磁场畸变与通信盲区常常同源共发，导致 `Σ_slip` 被低估、`k_D` 被高估，车队会在「已认证」的自信中把安全前缀执行到物理冲突——全部可靠性押在「共因可及时识别、漂移模型在盲区内仍成立」这一假设上。

**次级风险与缓解**：
1. **和乐误判**：时延造成暂时残差 → 时间一致性滤波 + 连续多帧超限才触发 TRR；
2. **共因不可观**：证据缺失时 `B_F` 取悲观上界并自动缩短 `k_D`；
3. **重构代价高**：`J(π)` 加任务进度项，设最小重构间隔；
4. **拓扑抖动**：拓扑切换做滞回 + 令牌版本号，避免和乐与权限同时抖动；
5. **拜占庭叠加**：`(f+1)`-连通 + 多路径交叉校验，权限只授予独立路径验证通过的节点；
6. **异构标定偏差**：在线标定，证书显式携带标定不确定度并纳入 `Σ_i`。
