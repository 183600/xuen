# 第 62 轮（承接第 61 轮「具身语义进化闭环」ESEC IP-173~182；新灵感循环第 1 轮；本轮灵感：「角色一致性」×「腕部相机」）

> 第 61 轮构建了 ESEC：USR 把场景/意图/阻抗/证据映射到共享语义空间，MEL 提供多模态零样本物理推断，DMS 实现执行接地的多轮对话，SRT-Dual 用语义流-实时流解耦大模型时序，PCE+++++ 做六维预算兜底。但**四个更深的局限**仍未被触及：
> 1. **只有「语义一致」，没有「身份一致」**：USR 让 scene_emb、intent_emb、impedance_emb、evidence_emb 在向量空间彼此靠近，却没有任何变量刻画「机器人是谁、应如何行动」这一**跨时间、跨视角、跨对话轮次保持不变的持久主体**。语义可以处处对齐，行为人格却可以逐周期漂移——第 61 轮的机器人可能在第 1 秒是「温柔助手」，第 10 秒变成「莽撞夹爪」，而所有语义锚点都是「新鲜且一致」的。
> 2. **MEL 是「第三人称」感知，恰好在关键瞬间失明**：全局相机在机械臂接近目标、发生接触时被自身连杆**严重自遮挡**；而这正是最需要物理证据（形变、滑移、微纹理）的时刻。第 61 轮的物理属性推断在「接触前」很准，在「接触中」反而退化。
> 3. **DMS 的「角色」只活在语言层**：DMS 可以声明「我是谨慎助手」，但没有任何机制把这句话翻译成**可验证的执行契约**；语言承诺与阻抗轨迹之间缺少一条可审计的绑定关系。
> 4. **证书只证明「语义-执行一致」，不证明「身份-行为一致」**：J_sem_exec 能证明 K_safe 靠近语义融合，却不能证明「这次执行仍然属于用户授权的那个角色」。长时任务里最危险的不是单步越界，而是**角色漂移（role drift）**——每一步都只偏一点点，累积成完全不同的行为人格。

## 0. 直觉与动机

**灵感 1（角色一致性 → 角色一致性空间 RCS）**
直觉：动画里的「角色一致性」指同一个角色在不同镜头、不同姿态、不同剧情下仍被认成同一个人；对应到具身智能，**角色（role）不是一次分类标签，而是一条慢变流形上的持久状态 r_t**。机器人在任务开始时被授权一个角色（如「轻触助手」「精密装配工」「稳健搬运者」），此后它的感知、对话、阻抗参数都应围绕这个角色展开。关键洞见：把角色显式建模为低维嵌入 r ∈ M_role（d_role ≈ 64），并给它**惯性（role inertia）**——r_t 只能缓慢演化，任何跳变都必须经过一次**可授权的角色切换事件**；这样「一致性」就从一句形容词变成可度量、可约束、可审计的动力学不变量。

**灵感 2（腕部相机 → 近场自视角编码 WNE）**
直觉：腕部相机（eye-in-hand）是机器人的「第一人称眼睛」。它看得见自己的夹爪、看得见接触面的微纹理与形变、看得见滑移产生的光流，也看得见全局相机被遮挡时最关键的近场细节。第 61 轮的 MEL 只有「旁观者视角」，本轮补上「行动者视角」。关键洞见：腕部相机的价值不只是多一路图像，而是它同时提供了三样全局相机给不了的东西——**(i) 近场物理证据 z_near**（微纹理/接触形变/滑移流）、**(ii) 自我观测 z_self**（夹爪位姿与外观，用于自模型一致性）、**(iii) 视角质量元数据**（运动模糊、遮挡、光照），让系统知道「此刻该信谁」。

**灵感 3（角色一致性 × 腕部相机 → 跨视角角色对账 CVRC）**
直觉：角色一致性天然是**跨视角**的——同一个角色，从观众（全局相机）看和从演员自己（腕部相机）看，应该推断出同一个「我是谁、我在做什么、我面对的是什么物理世界」。若两路视角在 USR 中给出显著不同的 scene_emb / φ_phys / role 后验，就说明要么感知错了，要么角色漂移了。关键洞见：把「腕部-全局」的语义分歧 D_view 作为角色一致性的**早期报警器**；在全局被遮挡时按不确定性加权信任腕部，在腕部运动模糊时回退全局，并在分歧超阈值时触发 MEL 重推理或角色再确认。

**灵感 4（角色契约 → 可验证的执行人格 RCC）**
直觉：如果角色只是隐变量，它仍然可能被模型「口头保持、行为违背」。因此给每个角色配一份**角色契约（Role Contract）**：明确承诺的行为边界（如「温柔」⇒ K_p 上界、F_max 上界、接近速度上界；「精密」⇒ 高刚度、高阻尼、低超调；「稳健」⇒ 中刚度、大安全裕度）。契约把语言承诺翻译成阻抗参数空间里的**可容许集 K_role**，执行证据必须落在其中。关键洞见：一致性不再靠「看起来像」，而靠**契约满足度 D_contract** 来判定；J_sem_exec 升级为角色一致性证书 RCC，使「人格」第一次成为可形式化验证的对象。

**灵感 5（角色惯性 + 安全例外 → 角色切换协议 RSP）**
直觉：一致性不能变成僵化。真实任务中角色必须能切换（从「轻触」切到「急停搬运」），但切换本身必须**有授权、有路径、有迟滞、有凭证**。关键洞见：设计角色切换协议，优先级从高到低为 **安全例外 > 用户显式指令 > DMS 提议 > 漂移自动恢复**；角色切换在 M_role 上走测地路径，带迟滞避免抖动，切换前后旧角色证书封存、新角色证书开启，形成完整的角色谱系（role lineage）。同时明确：**当安全与一致性冲突时，安全永远优先，一致性让路**——这正是本轮最大风险的解药。

**灵感 6（七维预算 → PCE++++++）**
直觉：第 61 轮 B_cog5 已有六个维度，但「角色维护」本身也消耗认知资源：角色编码、跨视角对账、契约验证、切换审计都需要算力与注意力。拓展为 **B_cog6 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_role)**，其中 B_role = (切换配额、对账频率、契约容差、视角同步频率)。关键洞见：预算耗尽时**冻结在最后一个已认证角色**，绝不因预算不足而放松契约或放行未授权切换；安全例外通道不计入切换配额。

**灵感 7（三灵感合流 → 角色一致性具身闭环 RCEC）**
直觉：把上述模块嵌入第 61 轮 ESEC：语义流新增「腕部近场编码 → 跨视角对账 → 角色更新 → 契约验证 → 角色锚点」；实时流消费的 anchor 除 scene_emb/intent_emb 外新增 role_emb，投影头变为角色条件投影 Π_role。闭环变为：**MEL/WNE 感知 → CVRC 对账 → RCS 角色更新 → RCA 角色锚点 → RCIP 角色条件投影 → EEIS 编译 → 执行 → EV-exec → RCM 一致性度量 → RCC 证书 →（漂移则）RDR 恢复**。角色一致性由此成为贯穿感知、语言、控制、审计的**第一等不变量**。

## 1. 形式化定义（增量：定义 173–184）

**定义 173（角色一致性空间 RCS）** 角色一致性空间 R = (M_role, E_role, ρ, τ_role, η_role, g_role)。其中：
- **角色流形**：M_role ⊆ ℝ^{d_role}（d_role = 64），由原型角色 {r^(1), …, r^(m)} 张成的低维光滑子流形
- **角色编码器**：E_role: (H_diag, TaskCtx, ExecCtx) → M_role，将对话历史、任务上下文、执行上下文映射为角色嵌入 r_t
- **角色度量**：ρ(r, r') = 1 - cos(r, r') ∈ [0, 2]，或 M_role 上的测地距离 d_M(r, r')
- **角色惯性**：无授权时 ρ(r_{t+1}, r_t) ≤ η_role（默认 0.05/周期）
- **角色条件可容许集**：g_role: M_role → 2^{K}，把角色映射为阻抗参数的可容许闭集 K_role(r)
- **角色漂移**：未授权的累积距离 Δ_role(t) = Σ_{τ} ρ(r_τ, r_{τ-1}) 超过阈值

**定义 174（腕部近场编码器 WNE）** WNE = (Enc_tex, Enc_flow, Enc_def, Enc_self, Enc_qual)。输入腕部图像序列 I_w^{t-k:t}、触觉 T_t、本体 P_t；输出三元组 (z_near, z_self, q_view)：
- **微纹理编码**：Enc_tex: I_w^t → z_tex ∈ ℝ^{d_tex}（接触面材质/粗糙度线索）
- **光流编码**：Enc_flow: I_w^{t-k:t} → z_flow ∈ ℝ^{d_flow}（滑移、相对运动、接触点漂移）
- **形变编码**：Enc_def: (I_w^t, T_t) → z_def ∈ ℝ^{d_def}（软材料压痕、接触面积变化）
- **近场语义**：z_near = Fuse(z_tex, z_flow, z_def) ∈ ℝ^{d_near}
- **自我观测**：Enc_self: (I_w^t, P_t) → z_self ∈ ℝ^{d_self}（夹爪位姿/外观预测残差，用于自模型一致性）
- **视角质量**：q_view = (blur, occlusion, illumination, confidence) ∈ ℝ⁴

**定义 175（角色一致性锚点 RCA）** 扩展第 61 轮语义锚点：
```
Anchor_t^role = (scene_emb, intent_emb, phys_prior,
                 role_emb, role_contract_id, role_version,
                 z_near, z_self, q_view,
                 timestamp, version, U_mel, checksum)
```
其中 role_emb 与 role_contract_id 必须来自**同一次已认证的角色状态**；写入仍采用 CAS，version 64 位单调递增，checksum 覆盖 role 字段以防撕裂读。

**定义 176（角色条件阻抗投影 RCIP）** Π_role: ℝ^{d_us} × M_role × Contract → K_role：
```
K_prior = Π_role(fused_sem, r_t, contract)
约束：
  (i)   K_prior ∈ K_role(r_t)                # 角色可容许集
  (ii)  ‖Π_role(x,r) - Π_role(y,r)‖ ≤ L_π‖x-y‖   # 对语义 Lipschitz
  (iii) d_M(r,r') ≤ δ ⇒ ‖Π_role(x,r) - Π_role(x,r')‖ ≤ L_r·δ  # 对角色 Lipschitz
  (iv)  K_role(r) ⊆ K_safe^envelope           # 契约必须是安全包络的子集
```
实现上用 FiLM 把 role_emb 注入投影 MLP，再用**安全滤波器**（闭集投影）保证 (i)(iv)；滤波器不参与梯度回传，只做输出校正。

**定义 177（角色一致性度量 RCM）** 角色一致性分数：
```
D_time     = d_M(r_t, r_{t-w})                       # 时间一致性
D_view     = ‖E_scene^near(z_near) - E_scene^global(z_global)‖
           + ‖φ_phys^near - φ_phys^global‖           # 跨视角一致性
D_contract = dist(K_safe^{t-w:t}, K_role(r_t))
           + max(0, F_max^realized - F_max^promised)
           + max(0, v_max^realized - v_max^promised) # 契约满足度
D_diag     = ‖r_t - E_role(H_diag)‖                  # 语言-行为一致性
C_role     = exp( -(λ_t·D_time + λ_v·D_view + λ_c·D_contract + λ_d·D_diag) / σ_role ) ∈ [0,1]
```
默认 λ_t=0.35, λ_v=0.25, λ_c=0.25, λ_d=0.15, σ_role=0.5。C_role ≥ τ_role（默认 0.8）视为角色一致。

**定义 178（角色契约 Role Contract）** Contract = (role_id, promised_traits, K_role, switch_policy, signature)。其中：
- **承诺特质** promised_traits = {gentle, precise, robust, rapid, …} 的量化版本
- **可容许阻抗集** K_role = {K : K_p ∈ [K_p^lo, K_p^hi], K_d ∈ [K_d^lo, K_d^hi], F_max ≤ F^promise, v_max ≤ v^promise, …}
- **切换策略** switch_policy = (allowed_targets, min_dwell, max_transition_time, requires_user_confirm)
- **签名** signature 由任务规划器签发，运行时只读；DMS 只能提议切换，不能改写契约
- **示例**：gentle ⇒ K_p ≤ 0.6·K_p^nominal，F_max ≤ 0.5·F_max^nominal，v_max ≤ 0.3·v_max^nominal；precise ⇒ K_p ≥ 0.8·K_p^nominal，K_d ≥ 1.2·K_d^nominal，超调 ≤ 5%。

**定义 179（角色切换协议 RSP）** 角色切换是一个带凭证的状态转移：
```
switch(r_old → r_new, authority) 合法 ⇔
  (a) authority ∈ {safety_override, user_explicit, dms_proposal, drift_recovery}
  (b) r_new ∈ M_role 且 contract(r_new) 已认证
  (c) 若 authority ≠ safety_override：
        dwell_time(r_old) ≥ min_dwell
        ∧ ρ(r_old, r_new) ≤ max_step
        ∧ switch_quota_remaining > 0
  (d) 存在 M_role 上的测地路径 γ: [0,1] → M_role，γ(0)=r_old, γ(1)=r_new
  (e) 旧角色证书封存、新角色证书开启，记录 (authority, timestamp, proposer, contract_hash)
```
**优先级**：safety_override ≻ user_explicit ≻ dms_proposal ≻ drift_recovery。安全例外通道不受配额、迟滞、契约切换策略约束，且必须在 ≤ 100ms 内完成。

**定义 180（跨视角角色对账 CVRC）** 给定全局嵌入 z_global、近场嵌入 z_near、自我观测 z_self 及各自不确定性：
```
w_g = 1/(U_global + ε) · 1[q_global.occlusion < τ_occ]
w_n = 1/(U_near   + ε) · 1[q_view.blur < τ_blur]
z_fused = (w_g·z_global + w_n·z_near)/(w_g + w_n)
D_view = ‖E_scene^near(z_near) - E_scene^global(z_global)‖ + ‖φ_near - φ_global‖
若 D_view > τ_view：标记 'view_divergence'，按“遮挡/模糊/角色漂移”三选一归因
若 z_self 与预期夹爪外观/位姿残差 > τ_self：标记 'self_model_violation'（可能标定漂移或被遮挡）
```
归因规则：q_global.occlusion 高 ⇒ 信任腕部；q_view.blur 高 ⇒ 信任全局；两者都健康却持续分歧 ⇒ 优先怀疑角色漂移，触发 RDR。

**定义 181（角色一致性证书 RCC）** 扩展第 61 轮 J_sem_exec：
```
RCC = (J_sem_exec,
       role_id, role_version, contract_hash,
       C_role, D_time, D_view, D_contract, D_diag,
       view_quality, switch_provenance, view_divergence_flag)
验证规则：
  Valid(RCC) ⇔ Valid(J_sem_exec)
             ∧ C_role ≥ τ_role
             ∧ role_id 与 contract_hash 匹配且已认证
             ∧ 无未授权切换（switch_provenance.authority 合法）
             ∧ D_contract ≤ τ_contract
             ∧ anchor.role_version 单调且无回绕
```
审计要求：RCC 的 role 字段与 switch_provenance 必须能沿角色谱系回溯到任务开始时的初始授权。

**定义 182（七维认知-角色预算 B_cog6 与 PCE++++++）** B_cog6 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_role)。其中：
- **B_role** = (Switch_quota, Check_freq, View_sync_freq, Contract_tol, Switch_latency_budget)
- **成本扩展**：
```
cost_cog6 = cost_cog5
          + λ_role·(Check_freq_used/Check_freq
                  + Switch_used/Switch_quota
                  + D_contract/Contract_tol)
```
- **降级策略**：
  - B_role.check 耗尽 ⇒ 降低一致性检查频率，改用缓存 C_role（仍保留契约硬校验）
  - B_role.view_sync 耗尽 ⇒ 冻结跨视角对账，退化为单视角 + 保守扩展
  - B_role.switch_quota 耗尽 ⇒ **拒绝一切非安全切换**，冻结在最后已认证角色
  - **安全例外通道永远不受任何预算约束**

**定义 183（角色一致性具身闭环 RCEC）** 在第 61 轮 ESEC 上增加角色层：
```
RCEC(M, V_g, V_w, T, P, L, delta_f_req):
  # ---------- 语义流（10-100Hz） ----------
  z_near, z_self, q_view ← WNE.encode(V_w, T, P)
  z_global, φ_global, z_scene, U_mel ← MEL.infer(V_g, T, P, L, ...)
  z_fused, view_flag, D_view ← CVRC.reconcile(z_global, z_near, z_self, q_view)
  r_new, switched ← RCS.update(H_diag, TaskCtx, ExecCtx, authorized_switch)
  if switched: contract ← RCS.contracts[r_new.id]; RSP.log(switch_event)
  anchor ← RCA.commit(z_fused, E_intent(b_intent), φ_fused, r_new, contract.id, ...)
  # ---------- 实时流（1-10kHz） ----------
  anchor, fresh ← USR.read_latest_anchor()
  K_prior ← RCIP(anchor.fused_sem, anchor.role_emb, contract)
  K_safe ← EEIS.compile_with_role_prior(delta_f_req, fused, ξ_exec, Z_env, K_prior, φ_phys)
  dispatch(K_safe); EV_exec ← wait_contact()
  # ---------- 角色一致性闭环 ----------
  C_role, D ← RCM.compute(r_hist, z_global, z_near, contract, K_safe, EV_exec)
  RCC ← RCC.build(J_sem_exec, C_role, r_new, D, switch_provenance)
  if RDR.detect(C_role, D): RDR.recover(level, safety_priority=True)
  return M, K_safe, EV_exec, RCC
```

**定义 184（角色漂移检测与恢复 RDR）** 用 CUSUM 检测 D_role = λ_t·D_time + λ_v·D_view + λ_c·D_contract + λ_d·D_diag 的缓慢上升：
```
S_t = max(0, S_{t-1} + (D_role - ν))     # ν 为基线漂移率
若 S_t > h ⇒ 触发漂移告警
恢复阶梯：
  L1 重推理：MEL/WNE 重新编码，检查是否感知瞬时错误
  L2 角色再确认：DMS 向用户发起确认（“检测到行为与‘轻触助手’不一致，是否切换？”）
  L3 角色冻结：拒绝进一步非安全角色演化，收紧 K_role 契约
  L4 安全停：若同时出现契约硬违规或力超限，立即安全停
```
恢复阶梯只能逐级上升，降级需连续 w 个周期 C_role ≥ τ_role 且 D_contract ≤ τ_contract；**安全例外可跨级直接到 L4**。

## 2. 关键算法伪代码

### IP-183 RCS（角色一致性空间）

```python
class RoleConsistencySpace:
    def __init__(self, d_role=64, eta_role=0.05, max_step=0.2):
        self.d_role = d_role
        self.eta_role = eta_role
        self.max_step = max_step
        self.role_encoder = RoleEncoder(d_role)
        self.manifold = RoleManifold(d_role)      # 原型 + 切空间投影
        self.contracts = {}                       # role_id -> RoleContract
        self.r_t = None
        self.role_version = 0
        self.switch_log = []

    def update(self, H_diag, task_ctx, exec_ctx, authorized_switch=None):
        r_raw = self.manifold.project(self.role_encoder(H_diag, task_ctx, exec_ctx))
        if self.r_t is None:
            self.r_t = r_raw
            self.role_version = 1
            return self.r_t, True
        d = self.manifold.geodesic(self.r_t, r_raw)
        if authorized_switch is not None:
            r_new = self.manifold.geodesic_step(self.r_t, r_raw,
                                                 step=min(1.0, d / max(d, 1e-6)))
            self.role_version += 1
            self.switch_log.append(('switch', authorized_switch, self.role_version))
            self.r_t = r_new
            return self.r_t, True
        if d <= self.eta_role:
            self.r_t = self.manifold.retract(0.9 * self.r_t + 0.1 * r_raw)
            return self.r_t, False
        # 未授权漂移：强惯性抑制，只允许极小演化，同时抛出漂移信号
        self.r_t = self.manifold.retract(0.98 * self.r_t + 0.02 * r_raw)
        return self.r_t, False

    def contract_of(self, r):
        rid = self.manifold.nearest_prototype(r)
        return self.contracts[rid]
```

```python
class RoleSwitchProtocol:
    PRIORITY = {'drift_recovery': 0, 'dms_proposal': 1,
                'user_explicit': 2, 'safety_override': 3}

        self.max_transition = max_transition
        self.quota = quota
        self.used = 0

    def request(self, r_old, r_new, authority, contract_reg, dwell, safety=False):
        if safety or authority == 'safety_override':
            return True, self._transition(r_old, r_new, authority, bypass=True)
        if r_new not in contract_reg:

            return False, 'switch_quota_exhausted'
        if contract_reg[r_new].requires_user_confirm and authority != 'user_explicit':
            return False, 'need_user_confirmation'
        self.used += 1
        return True, self._transition(r_old, r_new, authority, bypass=False)

        # 在 M_role 上走测地路径，过渡期同时收紧新旧契约的交集
        path = geodesic(r_old, r_new, steps=10)
        envelope = intersect(contract(r_old).K_role, contract(r_new).K_role)

                'authority': authority, 'bypass': bypass,
                'cert_old': 'sealed', 'cert_new': 'opened'}
```

```python
class RoleDriftRecovery:
    def __init__(self, nu=0.05, h=3.0, window=20):

        self.S = 0.0
        self.level = 0
```

**正确性定理（RCEC-Role-Safe）**：
假设第 61 轮 A61–A70 成立，并新增：
- **(A71)** 角色流形 M_role 光滑紧致，E_role 为 L_e-Lipschitz；原型角色覆盖任务角色集。
- **(A72)** 腕部-全局相机已完成时空标定，无遮挡且无运动模糊时 D_view ≤ δ_view。
- **(A73)** 每个角色契约满足 K_role(r) ⊆ K_safe^envelope，且契约运行时只读。
- **(A74)** RSP 的优先级与迟滞保证：非安全切换不会在 min_dwell 内反复；安全例外可在 ≤100ms 内完成。
- **(A75)** RCM 的 D_contract 计算覆盖所有硬约束（力、速度、刚度上下界），无漏检。
- **(A76)** B_role 降级只会减少检查/对账频率，不会放宽契约或放行未授权切换。

则：
1. **角色一致性**：若 RCC 有效（C_role ≥ τ_role ∧ D_contract ≤ τ_contract ∧ 无未授权切换），则执行轨迹以 ≥ 1-α 概率落在角色契约 K_role(r) 的 ε_role-邻域内，角色人格在该检查窗口内保持一致。
2. **跨视角鲁棒性**：若全局视角被遮挡（q_global.occlusion > τ_occ）而腕部视角健康，则 CVRC 融合后的 scene/φ_phys 误差不大于纯全局视角误差；反之亦然。持续健康却分歧时，RDR 在有限延迟内触发角色再确认。
3. **漂移可检测**：在 D_role 的均值漂移 δ > ν 下，CUSUM 的平均检测延迟 ≤ h/(δ-ν)，虚警率随 h 指数下降。
4. **安全支配**：任何时刻 K_safe ∈ K_role(r) ⊆ K_safe^envelope；安全例外可越过一致性、配额与迟滞，优先执行安全停/安全角色。
5. **实时性**：角色层（WNE/RCS/CVRC/RCM/RCC）全部位于语义流；实时流仅读取 role_emb 并执行 O(1) 的 RCIP 投影与安全滤波，周期抖动 ≤ 0.2ms。

### IP-183 RCS（角色一致性空间）

```python
class RoleConsistencySpace:
    def __init__(self, d_role=64, eta_role=0.05, max_step=0.2):
        self.d_role = d_role
        self.eta_role = eta_role              # 无授权角色惯性
        self.max_step = max_step              # 单次测地切换步长上界
        self.role_encoder = RoleEncoder(d_role)
        self.manifold = RoleManifold(d_role)  # 原型角色 + 切空间投影
        self.contracts = {}                   # role_id -> RoleContract
        self.r_t = None
        self.role_version = 0
        self.switch_log = []

    def update(self, H_diag, task_ctx, exec_ctx, authorized_switch=None):
        r_raw = self.manifold.project(
            self.role_encoder(H_diag, task_ctx, exec_ctx))
        if self.r_t is None:
            self.r_t = r_raw
            self.role_version = 1
            return self.r_t, True
        d = self.manifold.geodesic(self.r_t, r_raw)
        if authorized_switch is not None:
            r_new = self.manifold.geodesic_step(self.r_t, r_raw, self.max_step)
            self.role_version += 1
            self.switch_log.append(('switch', authorized_switch,
                                    self.role_version))
            self.r_t = r_new
            return self.r_t, True
        if d <= self.eta_role:
            self.r_t = self.manifold.retract(0.9 * self.r_t + 0.1 * r_raw)
            return self.r_t, False
        # 未授权漂移：强惯性抑制 + 抛出漂移信号（由 RDR 接管）
        self.r_t = self.manifold.retract(0.98 * self.r_t + 0.02 * r_raw)
        return self.r_t, False

    def contract_of(self, r):
        rid = self.manifold.nearest_prototype(r)
        return self.contracts[rid]
```

```python
class RoleConditionedProjector(nn.Module):
    def __init__(self, d_us=256, d_role=64, d_k=8):
        super().__init__()
        self.trunk = nn.Sequential(nn.Linear(d_us, 128), nn.GELU(),
                                   nn.Linear(128, 128))
        self.film = FiLM(d_role, 128)                 # role -> (gamma, beta)
        self.out = nn.Linear(128, d_k)                # Kp,Kd,Fmax,vmax,...

    def forward(self, fused_sem, role_emb, contract):
        h = self.film(self.trunk(fused_sem), role_emb)
        K = self.out(h)
        return contract.safe_filter(K)                # 闭集投影，保证 K∈K_role
```

### IP-186 RCM（角色一致性度量）

```python
class RoleConsistencyMetric:
    def __init__(self, sigma=0.5, lambdas=(0.35, 0.25, 0.25, 0.15), window=20):
        self.sigma = sigma
        self.lt, self.lv, self.lc, self.ld = lambdas
        self.window = window

    def compute(self, r_hist, z_global, z_near, contract,
                K_traj, EV_exec, H_diag):
        D_time = self.manifold.geodesic(r_hist[-1], r_hist[-self.window])
        D_view = self.cross_view_distance(z_global, z_near)
        D_contract = contract.violation(K_traj[-self.window:], EV_exec)
        D_diag = self.dialogue_distance(r_hist[-1], H_diag)
        D = (self.lt * D_time + self.lv * D_view
             + self.lc * D_contract + self.ld * D_diag)
        return math.exp(-D / self.sigma), (D_time, D_view, D_contract, D_diag)

    def contrastive_loss(self, r_anchor, r_pos, r_neg, margin=0.3):
        # 时间/视角正样本拉近；不同角色负样本推远
        return F.triplet_margin_loss(r_anchor, r_pos, r_neg, margin=margin)
```

### IP-187 RSP（角色切换协议）

```python
class RoleSwitchProtocol:
    PRIORITY = {'drift_recovery': 0, 'dms_proposal': 1,
                'user_explicit': 2, 'safety_override': 3}

    def __init__(self, min_dwell=2.0, max_transition=0.5, quota=2):
        self.min_dwell = min_dwell
        self.max_transition = max_transition
        self.quota = quota
        self.used = 0

    def request(self, r_old, r_new, authority, contract_reg, dwell,
                safety=False):
        if safety or authority == 'safety_override':
            return True, self._transition(r_old, r_new, authority, bypass=True)
        if r_new not in contract_reg:
            return False, 'unregistered_role'
        if dwell < self.min_dwell:
            return False, 'dwell_not_met'
        if self.used >= self.quota:
            return False, 'switch_quota_exhausted'
        if (contract_reg[r_new].requires_user_confirm
                and authority != 'user_explicit'):
            return False, 'need_user_confirmation'
        self.used += 1
        return True, self._transition(r_old, r_new, authority, bypass=False)

    def _transition(self, r_old, r_new, authority, bypass):
        path = geodesic(r_old, r_new, steps=10)        # M_role 上测地路径
        envelope = intersect(contract(r_old).K_role,
                             contract(r_new).K_role)   # 过渡期取交集
        return {'path': path, 'envelope': envelope,
                'authority': authority, 'bypass': bypass,
                'cert_old': 'sealed', 'cert_new': 'opened'}
```

### IP-188 CVRC（跨视角角色对账）

```python
class CrossViewRoleReconciler:
    def __init__(self, tau_view=0.3, tau_self=0.2):
        self.tau_view, self.tau_self = tau_view, tau_self

    def reconcile(self, z_global, z_near, z_self, U_global, U_near, q_view):
        w_g = 1.0 / (U_global + 1e-6)
        w_n = 1.0 / (U_near + 1e-6)
        if q_view[1] > 0.7:   w_n *= 0.3      # 腕部运动模糊 -> 降权
        if q_global[1] > 0.7: w_g *= 0.1      # 全局自遮挡 -> 降权
        z_fused = (w_g * z_global + w_n * z_near) / (w_g + w_n)
        D_view = torch.norm(z_near - z_global) + self.phys_gap(z_near, z_global)
        flag = 'ok'
        if D_view > self.tau_view:
            if q_global[1] > 0.7:  flag = 'global_occluded'
            elif q_view[0] > 0.7:  flag = 'wrist_blurred'
            else:                  flag = 'suspected_role_drift'
        if self.expected_self(z_self) > self.tau_self:
            flag = 'self_model_violation'
        return z_fused, flag, D_view
```

```python
class CognitiveRoleBudget:
    def __init__(self, base_budget, switch_quota=2, check_freq=5,
                 view_sync_freq=10, contract_tol=0.1, switch_latency=0.1):
        self.base = base_budget
        self.B_role = {'switch_quota': switch_quota,
                       'check_freq': check_freq,
                       'view_sync_freq': view_sync_freq,
                       'contract_tol': contract_tol,
                       'switch_latency': switch_latency}
        self.used = {'switch': 0, 'check': 0, 'view_sync': 0}
        self.mode = 'full'

    def can_switch(self, safety_override=False):
        if safety_override:
            return True                       # 安全例外不计配额
        return self.used['switch'] < self.B_role['switch_quota']

    def role_step(self, D_contract, checked, synced):
        if checked: self.used['check'] += 1
        if synced:  self.used['view_sync'] += 1
        if self.used['check'] >= self.B_role['check_freq']:
            self.mode = 'cached_role'         # 仍保留契约硬校验
        if self.used['view_sync'] >= self.B_role['view_sync_freq']:
            self.mode = 'single_view'         # 单视角 + 保守扩展

    def cost_role(self, D_contract):
        return (self.used['check'] / max(1, self.B_role['check_freq'])
                + self.used['switch'] / max(1, self.B_role['switch_quota'])
                + D_contract / max(1e-6, self.B_role['contract_tol']))
```

```python
def RCEC_step(M, obs, delta_f_req):
    # ---------- 语义流（10-100Hz） ----------
    z_near, z_self, q_view, U_near = M.wne.encode(
        obs.wrist, obs.tactile, obs.proprio)
    z_global, phi_g, z_scene, U_mel = M.mel.infer(
        obs.global_view, obs.tactile, obs.proprio, obs.utterance,

        M.H_diag, M.task_ctx, M.exec_ctx, M.pending_switch)
    contract = M.rcs.contract_of(r_new)
    M.anchor = M.usr.commit_anchor(
        z_fused, M.usr.intent_encoder.encode(M.b_intent),

    # ---------- 实时流（1-10kHz） ----------
    anchor, fresh = M.usr.read_latest_anchor()
    K_prior = M.rcip(anchor.fused_sem, anchor.role_emb, contract)
    K_safe = M.eeis.compile_with_role_prior(
        delta_f_req, M.fused, M.xi_exec, M.Z_env,
        K_prior, anchor.phys_prior)
    M.ertc.dispatch(K_safe)
    EV_exec = wait_contact_and_build_evidence()

    # ---------- 角色一致性闭环 ----------
    C_role, D = M.rcm.compute(

    return M, K_safe, EV_exec, rcc
```

### IP-192 RDR（角色漂移检测与恢复）

```python
class RoleDriftRecovery:
    def __init__(self, nu=0.05, h=3.0, window=20):
        self.nu, self.h, self.window = nu, h, window
        self.S = 0.0
        self.level = 0

    def detect(self, C_role, D):
        D_role = sum(D) / 4.0
        self.S = max(0.0, self.S + (D_role - self.nu))
        return self.S > self.h or C_role < 0.5

    def recover(self, level, safety_priority=False):
        if safety_priority:
            self.level = max(self.level, 3)
        else:
            self.level = min(4, self.level + 1)
        actions = {1: 're_infer', 2: 'ask_user_confirm',
                   3: 'freeze_role', 4: 'safe_stop'}
        return actions[self.level]
```

**正确性定理（RCEC-Role-Safe）**：
假设第 61 轮 A61–A70 成立，并新增：
- **(A71)** 角色流形 M_role 光滑紧致，E_role 为 L_e-Lipschitz，原型角色覆盖任务角色集。
- **(A72)** 腕部-全局相机完成时空标定；无遮挡、无运动模糊时 D_view ≤ δ_view。
- **(A73)** 每个角色契约满足 K_role(r) ⊆ K_safe^envelope，且契约运行时只读。
- **(A74)** RSP 优先级与迟滞保证：非安全切换在 min_dwell 内不反复；安全例外 ≤100ms 完成。
- **(A75)** RCM 的 D_contract 覆盖所有硬约束（力、速度、刚度上下界），无漏检。
- **(A76)** B_role 降级只减少检查/对账频率，不放宽契约、不放行未授权切换。

则：
1. **角色一致性**：若 RCC 有效（C_role ≥ τ_role ∧ D_contract ≤ τ_contract ∧ 无未授权切换），则执行轨迹以 ≥1-α 概率落在 K_role(r) 的 ε_role-邻域，角色人格在检查窗口内保持一致。
2. **跨视角鲁棒性**：全局被遮挡而腕部健康时，CVRC 融合误差不大于纯全局误差；反之亦然；持续健康却分歧时 RDR 在有限延迟内触发再确认。
3. **漂移可检测**：当 D_role 均值漂移 δ > ν 时，CUSUM 平均检测延迟 ≤ h/(δ-ν)，虚警率随 h 指数下降。
4. **安全支配**：任意时刻 K_safe ∈ K_role(r) ⊆ K_safe^envelope；安全例外可越过一致性、配额、迟滞，优先安全停/安全角色。
5. **实时性**：角色层全部位于语义流；实时流仅读取 role_emb 并执行 O(1) 的 RCIP 投影与安全滤波，周期抖动 ≤0.2ms（E195 基线）。

## 5. 本轮最大风险

**一句话**：角色一致性可能退化为「角色僵化」——当环境确实要求角色改变（如从「轻触」转为「急停搬运」）时，过强的 role inertia、契约闭集与切换配额会压制必要的策略切换，使系统固执地保持人设而错过安全窗口；因此必须把「安全例外通道」设计为高于一致性、高于配额、高于迟滞的最高优先级，并让 RDR 的安全停不受任何角色预算约束。
