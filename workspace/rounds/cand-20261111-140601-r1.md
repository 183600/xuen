# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；新一轮灵感循环第 1 轮；本轮灵感：「真实世界泛化」×「SLAM」）

> 第 54 轮已把技能组合提升为动作空间剖面 `α_S`、云边映射 `γ_ce` 与动作-鲁棒性联合证书 `J`。但这套体系默认了一个从未被显式审查的前提：**证书所依附的地图是已知、稳定、且仿真分布覆盖真实世界的**。本轮把 SLAM 从“定位建图模块”提升为“证书的搬运介质”，把真实世界泛化从“更多仿真纹理”重构为“地图扰动下的证书稳定性”。核心矛盾：**H22（地图相对性）**——所有动作剖面与鲁棒性谱都是地图的函数，SLAM 误差是结构化的、非 i.i.d. 的，同一动作在漂移后的地图里会落到不同局部几何，证书可能系统性失真；**H23（结构新颖性）**——外观多样性不等于结构泛化，新拓扑、新可通行性、感知别名才是 SLAM 失效且证书最被需要的地方；**H24（探索-选择反馈）**——主动 SLAM 在降低地图不确定性的同时改变了被评估的分布，证书可能因为“专挑好走的地方”而虚假变好。

## 0. 直觉与动机

**灵感 1（SLAM 地图是证书的搬运介质，不是背景坐标系）**
直觉：第 54 轮的证书 `J` 本质上是地图 `M` 的函数：`α_{S|M}`、`ρ_{S|M}`、`A_cert(M)`。仿真里给出的是 `J(M_sim)`，部署时真正需要的是 `J(M_real)`；而机器人只有估计 `\hat M`。因此部署不是“把仿真结论搬过去”，而是**沿地图估计做一次证书的拉回（pullback）**。如果 `J` 对地图是 `L_c`-Lipschitz 的，那么
`r(M_real) ≤ r(\hat M) + L_c · d_M(M_real, \hat M)`。
真实世界泛化于是变成一个可计算的**证书传输误差**：不是问“像不像训练集”，而是问“地图扰动能否把证书推出有效域”。这把泛化从视觉相似性判断，变成地图空间上的稳定性分析。

**灵感 2（真实世界泛化 = 结构不变量留存，而不是外观多样性）**
直觉：纹理、光照、季节会变，但可通行拓扑、回环结构、局部几何尺度、地面粗糙度的统计量在很多真实场景里更稳定。定义**结构指纹** `Φ(M)`：可通行图 Laplacian 谱、回环空间的持续同调特征、曲率/粗糙度直方图、尺度比。泛化域 `D_struct(δ)` 就是 `Φ(M)` 落在校准带内的地图族。关键判断：**外观新颖既不是结构域外的充分条件，也不是必要条件**——一条换了墙纸但拓扑相同的走廊仍可泛化；一条外观相同但多了一扇“假门”的走廊可能已是结构域外。

**灵感 3（回环闭合是泛化的断点，而非普通更新）**
直觉：SLAM 的回环闭合会让整张地图发生**跳变**：昨天的走廊今天被拉直，原本不连通的区域突然连通。证书没有时间维度，跳变会让 `J(\hat M^-)` 与 `J(\hat M^+)` 之间出现不连续。必须定义**证书不连续度**与**有效视界**：地图跳变超过阈值、或地点识别后验高度歧义时，立即挂起证书，做局部重认证，而不是继续用旧证书执行。感知别名（perceptual aliasing）应被当作“高风险的域外信号”，而不是普通定位噪声。

**灵感 4（证书驱动的主动 SLAM：探索是为了压低部署风险上界）**
直觉：主动 SLAM 常用的信息增益（熵减）并不等于任务风险下降。应该选择那样的动作：它最能降低**证书风险上界** `R_t = max_{M∈ℳ_t} r(J(M))`，同时不回避任务真正需要的结构区域。定义**期望证书风险下降 ECRR** 作为探索目标，并加任务覆盖约束，防止“只测好走的地方”把证书刷漂亮。这把第 54 轮的动作空间从“执行动作”扩展到“取证动作”。

**灵感 5（泛化是一本在线风险账本，不是一次性声明）**
直觉：真实世界会漂移，仿真证据会过期。把每次部署的“结构桶 × 结果”写入**泛化账本**，用按结构桶分层的在线保形推断维护风险分位数。见过的桶给出有限样本覆盖；没见过的桶不假装知道，而是回退到保守先验并要求主动探索。这样“泛化”不是一句承诺，而是一条**可被证伪、会随部署更新**的风险曲线。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（SLAM 地图、可信集与地图相对证书）**
地图 `M = (G_M, X_M, Σ_M, c_M)`：地点图 `G_M`、度量嵌入 `X_M`、语义标签 `Σ_M`、局部可通行性 `c_M`。估计器在时刻 `t` 输出 `\hat M_t` 与可信集
`ℳ_t = { M : d_M(M, \hat M_t) ≤ ε_t }`，
其中地图距离分解为
`d_M(M,M') = w_g·d_G(G_M,G_M') + w_x·d_H(X_M,X_M')/s + w_σ·d_Σ(Σ_M,Σ_M')`，
`d_G` 为归一化图编辑距离，`d_H` 为度量嵌入的 Hausdorff 距离，`d_Σ` 为标签不一致率，`s` 为场景尺度。技能 `S` 的地图相对剖面与鲁棒性谱为 `α_{S|M}(a)`、`ρ_{S|M}(d)`，证书 `J(M)=(ρ_{S|M}, A_cert(M), r(M))`。

**定义 122（结构指纹、结构桶与泛化域）**
结构指纹
`Φ(M) = (spec(L_{G_M}), pers(H_1(Tr(M))), hist(κ_M), hist(τ_M), s)`，
其中 `L` 为可通行图 Laplacian，`Tr(M)` 为可通行复形，`κ` 为局部曲率，`τ` 为粗糙度。结构桶 `β(M)=quantize(Φ(M))`。给定校准族 `ℳ_cal`，结构泛化域
`D_struct(δ) = { M : min_{M_i∈ℳ_cal} d_struct(Φ(M), Φ(M_i)) ≤ δ }`。
技能 `S` 的**泛化半径** `R_gen(S) = sup { r : ∀M, d_struct(Φ(M),Φ(ℳ_cal)) ≤ r ⇒ J(M) 有效 }`。

**定义 123（证书传输与 Lipschitz 风险上界）**
若对任意 `M,M'∈D_struct`，`|r(M)-r(M')| ≤ L_c·d_M(M,M')`，则称证书 `J` 是 `L_c`-Lipschitz 的。由三角不等式与可信集，在 `P(M_real∈ℳ_t) ≥ 1-α_map` 下有
`r(M_real) ≤ r(\hat M_t) + L_c·ε_t`。
这是本轮的核心不等式：**泛化误差 = 地图估计误差 × 证书敏感度**。

**定义 124（回环跳变、证书不连续度与有效视界）**
回环闭合算子 `U_LC` 作用为 `\hat M_t^- → \hat M_t^+`，跳变 `Δ_LC = d_M(\hat M_t^-, \hat M_t^+)`。证书不连续度
`D_c(J) = sup_{M,M'} |r(J(M))-r(J(M'))| / d_M(M,M')`。
**有效视界** `H_J = min { t : d_M(\hat M_t, \hat M_{t_recert}) > δ_re ∨ Δ_LC(t) > Θ_LC ∨ H_place(t) > Θ_p }`，其中 `H_place` 为地点识别后验熵。`t > H_J` 时证书挂起。

**定义 125（证书驱动的主动 SLAM 与 ECRR）**
在动作空间 `A_c × A_e` 上增加取证动作 `u`（新视点、回环验证、局部重扫）。地图信念 `b_t` 下的风险上界 `R_t = max_{M∈ℳ_t} r(J(M))`。期望证书风险下降
`ECRR(u) = E_{z∼p(·|b_t,u)}[R_t - R_{t+1}] - λ_c·cost(u) - λ_o·OOD_penalty(u)`。
探索策略 `π_u` 最大化 `ECRR`，并满足任务结构覆盖约束 `cov_β(b_t) ≥ κ`（防止只探索易测区域）。

**定义 126（泛化账本与分桶在线保形证书）**
账本 `L_t = {(M_i, T_i, β_i, y_i)}_{i≤t}`，`y_i` 为部署残差（失败指示或归一化风险）。对每个结构桶 `β` 维护分位数 `q_{β,t}`，用自适应保形更新
`q_{β,t+1} = Proj_{[0,1]}( q_{β,t} + η·(α - 1[y_{t+1} > q_{β,t}]) )`。
部署证书 `J_gen = (r_ub, β, q_β, Δ_LC, evidence)`，部署判据：
`r_ub + q_β ≤ r_max ∧ Δ_LC ≤ Θ_LC ∧ (β 已见 ∨ 探索预算足够)`。

## 2. 关键算法 伪代码

### IP-121 MGC（Map-Grounded Certificate）

```python
def map_grounded_certificate(skill, M_hat, U_M, J_sim, L_c):
    eps = calibrated_radius(U_M, alpha_map=0.05)
    r_hat = evaluate_risk(J_sim, M_hat, skill)
    r_ub = r_hat + L_c * eps
    alpha_lo = min_profile_over_ball(skill, M_hat, eps, J_sim)
    cover_ok = all(alpha_lo[a] >= theta_cov for a in skill.task_actions)
    return ('ok' if cover_ok else 'reject', r_ub, alpha_lo, eps)
```

### IP-122 SFP（Structural Fingerprint / OOD）

```python
def structural_fingerprint(M):
    L = traversability_laplacian(M)
    spec = smallest_eigenvalues(L, k=16)
    pers = persistent_h1(traversability_complex(M))     # 回环/障碍的同调特征
    kappa = curvature_histogram(M.X)
    tau = roughness_histogram(M.c)
    return concatenate(spec, pers, kappa, tau, [M.scale])

def structural_bucket(M, cal_fingerprints, delta):
    phi = structural_fingerprint(M)
    d = min(norm(phi - f) for f in cal_fingerprints)
    return ('known', quantize(phi), d) if d <= delta else ('ood', quantize(phi), d)
```

### IP-123 LCG（Loop-Closure Guard）

```python
def loop_closure_guard(M_prev, M_curr, place_post, delta_re, theta_lc):
    jump = map_distance(M_prev, M_curr)
    entropy = place_posterior_entropy(place_post)
    if jump > theta_lc or entropy > theta_p:
        changed = affected_submap(M_prev, M_curr, jump)
        suspend_certificates(intersect_support(changed))
        return ('recert', changed)            # 局部重认证，不做全库重算
    return ('valid', None)
```

### IP-124 CAS（Certificate-driven Active SLAM）

```python
def certificate_active_slam(belief, candidates, J, task_buckets, kappa):
    R = worst_case_risk(belief, J)
    best = None
    for u in candidates:
        dR = expected_risk_reduction(belief, u, J) - lambda_c*cost(u) - lambda_o*ood_penalty(u)
        if coverage_delta(belief, u, task_buckets) + current_cov < kappa:
            continue
        if best is None or dR > best.dR:
            best = (u, dR)
    return best
```

### IP-125 GCL（Generalization Conformal Ledger）

```python
def update_ledger(ledger, bucket, residual, alpha, eta, q):
    q_new = clip(q[bucket] + eta*(alpha - (residual > q[bucket])), 0.0, 1.0)
    q[bucket] = q_new
    ledger.append((bucket, residual, q_new))
    return q_new

def generalization_quantile(bucket, q, seen, unseen_prior, delta_struct):
    return q[bucket] if seen else min(1.0, unseen_prior + delta_struct)
```

### IP-126 GRC（Generalization Risk Contract）

```python
def generalization_contract(skills, M_hat, U_M, J_sim, ledger, cfg):
    eps = calibrated_radius(U_M)
    r_ub, beta, q_beta = 0.0, None, 0.0
    for s in skills:
        status, r, _, _ = map_grounded_certificate(s, M_hat, U_M, J_sim, cfg.L_c)
        if status == 'reject':
            return ('reject', 'action_cover', s.id)
        r_ub = max(r_ub, r)
    kind, beta, d = structural_bucket(M_hat, cfg.cal_fingerprints, cfg.delta_struct)
    if kind == 'ood':
        return ('reject', 'structural_ood', d)
    q_beta = generalization_quantile(beta, ledger.q, beta in ledger.seen,
                                     cfg.unseen_prior, d)
    if r_ub + q_beta > cfg.r_max:
        return ('reject', 'risk_budget', r_ub + q_beta)
    return ('ok', J_gen(r_ub, beta, q_beta, cfg.lc_state, evidence=ledger))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| MGC | O(|A|·|ℳ_t|) 采样近似，区间界 O(|A|) | O(|A|) | 可信集覆盖、Lipschitz 常数标定 |
| SFP | O(|G|+k|V|+n log n) | O(|G|+n) | 结构不变量跨环境稳定 |
| LCG | O(1)/次更新 + O(|G_changed|) 重认证 | O(|G|) | 跳变可检、局部影响域可靠 |
| CAS | O(|A|·N_h·|G|)（可贪心降阶） | O(N_h·|G|) | ECRR 估计无偏、覆盖约束不被绕过 |
| GCL | O(1)/样本 | O(|B|) | 分桶稳定、漂移可跟踪 |
| GRC | O(|S|·|A|) | O(|S|+|A|) | 各门联合 sound |

**正确性定理（Map-Grounded Generalization Soundness）**
在承接第 54 轮 (A26)–(A28) 的基础上，假设：**(A29)** 地图可信集 `ℳ_t` 覆盖真值，`P(M_real∈ℳ_t) ≥ 1-α_map`；**(A30)** 证书在 `D_struct` 上 `L_c`-Lipschitz；**(A31)** 结构 OOD 检测的漏检率 `≤ β_ood`；**(A32)** 分桶保形更新在缓变漂移下长期误覆盖 `≤ α_conf`；**(A33)** 回环守卫对超过 `Θ_LC` 的跳变不漏报，漏报率 `≤ β_LC`。则所有门均通过的部署满足
`P(fail) ≤ q_β + L_c·ε_t + α_conf + β_ood + β_LC`。
证明要点：可信集把真值地图限制在 `ε_t` 球内；Lipschitz 把地图误差线性传到风险；结构桶把非平稳部署切成近似同分布块，保形给出块内风险分位数；回环守卫截断不连续跳变。四项分别对应地图、结构、统计、时间四类失效来源。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| SLAM 在别名/新场景处过度自信，可信集偏小 | 高 | 多假设地图 + 协方差重标定 + 红队别名注入 |
| 结构指纹过粗导致 OOD 漏检，过细导致全拒 | 高 | 多尺度指纹 + 分桶保形 + 保守回退 |
| 回环守卫过度保守，系统频繁挂起 | 中 | 局部影响域重认证 + 渐进恢复 + 冷启动锚点 |
| 主动 SLAM 把评估分布收窄，证书虚假变好 | 高 | 任务覆盖约束 + 留出任务审计 + 反事实探索 |
| 真实世界非平稳，保形交换性失效 | 中 | ACI + 漂移检测 + 桶级重置 |

## 6. 本轮最大风险

**一句话**：把 SLAM 地图当作证书的搬运介质后，泛化的 soundness 完全取决于“地图不确定性与回环跳变是否被诚实估计”；一旦 SLAM 恰在感知别名与新拓扑处过度自信，Lipschitz 传输会给出一个看起来紧致、实则失效的泛化上界，因此必须以**多假设可信集 + 回环挂起 + 未见结构桶保守回退**三重护栏，绝不把外观相似当作结构泛化的证据。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-RealSLAM（MGC×SFP×LCG×CAS×GCL×GRC）

> 承接第 54 轮产物 v31。本轮把第 54 轮的动作-鲁棒性双证书 `J` 从“仿真坐标系”搬到一个**地图相对、结构分层、可在线更新**的泛化体系上：
> - **MGC（Map-Grounded Certificate）**：沿 SLAM 地图估计做证书拉回，给出 Lipschitz 风险上界 `r_ub = r(\hat M) + L_c·ε_t`；
> - **SFP（Structural Fingerprint）**：用可通行拓扑/回环同调/几何统计定义结构指纹与泛化域；
> - **LCG（Loop-Closure Guard）**：把回环跳变与感知别名变成证书挂起与局部重认证事件；
> - **CAS（Certificate-driven Active SLAM）**：用 ECRR 选择取证动作，并用任务结构覆盖约束反探索偏置；
> - **GCL（Generalization Conformal Ledger）**：按结构桶维护在线保形风险分位数；
> - **GRC（Generalization Risk Contract）**：把地图、结构、统计、时间四类风险合成统一部署判据。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-118（AEC）为地图相对联合证书，升级 IP-120（JTC）为带地图可信集的跨环境迁移。

| `D_struct(δ)`, `R_gen(S)` | 结构泛化域、技能泛化半径 |
| `L_c` | 证书对地图的 Lipschitz 常数 |
| `Δ_LC`, `D_c`, `H_J` | 回环跳变、证书不连续度、有效视界 |
| `R_t`, `ECRR(u)` | 风险上界、期望证书风险下降 |
| `L_t`, `q_β` | 泛化账本、结构桶风险分位数 |
| `J_gen` | 泛化风险证书 `(r_ub,β,q_β,Δ_LC,evidence)` |

## 2. 关键推导：证书传输不等式

设真实地图 `M_real`、估计 `\hat M_t`、可信集 `ℳ_t={M:d_M(M,\hat M_t)≤ε_t}`。若 `J` 在 `D_struct` 上 `L_c`-Lipschitz，则对任意 `M∈ℳ_t`：

```
r(M_real) ≤ r(\hat M_t) + |r(M_real)-r(\hat M_t)|
          ≤ r(\hat M_t) + L_c·d_M(M_real,\hat M_t)
          ≤ r(\hat M_t) + L_c·ε_t        (以概率 ≥ 1-α_map)
```

三项含义清晰：`r(\hat M_t)` 是当前地图下的名义风险；`L_c` 是技能/证书对地图错误的敏感度；`ε_t` 是 SLAM 诚实度。**泛化失败可归因**：要么技能太敏感（`L_c` 大），要么地图不可信（`ε_t` 大），要么结构出域（`β` 未见）。这正好把第 54 轮的 `Explain` 从“动作维度根因”扩展到“地图-结构维度根因”。

进一步，地图距离分解给出可解释的四类根因：

```
d_M ≈ w_g·Δtopo + w_x·Δgeo + w_σ·Δsem
```

- `Δtopo` 大：地点图结构错（漏检回环、错连通）→ 触发 LCG；
- `Δgeo` 大：尺度/位姿漂移 → 增大 `ε_t` 或触发局部重扫；
- `Δsem` 大：语义标签错（门/障碍混淆）→ 触发 SFP 与主动验证；
- 结构桶 `β` 未见：外观可能正常但结构出域 → GRC 直接保守拒绝。

### IP-121 MGC

```python
def map_grounded_certificate(skill, M_hat, U_M, J_sim, L_c, theta_cov):
    eps = calibrated_radius(U_M, alpha_map=0.05)
    r_hat = evaluate_risk(J_sim, M_hat, skill)
    r_ub = r_hat + L_c * eps
    # 在可信集内取动作覆盖的下界，避免“平均地图上能走”被当成“真实地图上能走”
    alpha_lo = min_profile_over_ball(skill, M_hat, eps, J_sim)
    if not all(alpha_lo.get(a, 0.0) >= theta_cov for a in skill.task_actions):
        return ('reject', 'action_cover_under_map_uncertainty', r_ub)
    return ('ok', r_ub, alpha_lo, eps)
```

### IP-122 SFP

```python
def structural_fingerprint(M, k=16):
    L = traversability_laplacian(M.G)
    spec = smallest_eigenvalues(L, k)
    pers = persistence_pair(persistent_h1(traversability_complex(M)))
    kappa = curvature_histogram(M.X, bins=32)
    tau = roughness_histogram(M.c, bins=32)
    return concat(spec, pers, kappa, tau, [M.scale])

def structural_bucket(M, cal_fingerprints, delta):
    phi = structural_fingerprint(M)
    dist = min(norm(phi - f) for f in cal_fingerprints)
    beta = quantize(phi)
    return ('known', beta, dist) if dist <= delta else ('ood', beta, dist)
```

### IP-123 LCG

```python
def loop_closure_guard(M_prev, M_curr, place_post, delta_re, theta_lc, theta_p):
    jump = map_distance(M_prev, M_curr)
    entropy = place_posterior_entropy(place_post)
    ambiguous = entropy > theta_p
    if jump > theta_lc or ambiguous:
        changed = affected_submap(M_prev, M_curr, jump)
        suspend_certificates(intersect_support(changed))        # 只挂起受影响技能
        return ('recert', changed, jump, entropy)
    return ('valid', None, jump, entropy)
```

### IP-124 CAS

```python
def certificate_active_slam(belief, candidates, J, task_buckets, kappa, cfg):
    R = worst_case_risk(belief, J)
    best = None
    for u in candidates:
        dR = expected_risk_reduction(belief, u, J)
        score = dR - cfg.lambda_c*cost(u) - cfg.lambda_o*ood_penalty(u, J)
        if current_cov(belief, task_buckets) + coverage_delta(belief, u) < kappa:
            continue                                             # 反探索偏置：必须覆盖任务结构
        if best is None or score > best.score:
            best = (u, score, dR)
    return best
```

### IP-125 GCL

```python
def generalization_quantile(bucket, seen, q, unseen_prior, delta_struct, alpha, eta):
    if not seen:
        return min(1.0, unseen_prior + delta_struct)             # 未见桶不假装知道
    return q[bucket]

def update_ledger(ledger, bucket, residual, alpha, eta):
    q_old = ledger.q.get(bucket, 0.5)
    q_new = clip(q_old + eta*(alpha - float(residual > q_old)), 0.0, 1.0)
    ledger.q[bucket] = q_new
    ledger.seen.add(bucket)
    ledger.records.append((bucket, residual, q_new))
    return q_new
```

### IP-126 GRC

```python
def generalization_contract(skills, M_hat, U_M, J_sim, ledger, cfg):
    eps = calibrated_radius(U_M)
    r_ub = 0.0
    for s in skills:
        status, r, _, _ = map_grounded_certificate(s, M_hat, U_M, J_sim, cfg.L_c, cfg.theta_cov)
        if status == 'reject':
            return ('reject', 'action_cover', s.id, r)
        r_ub = max(r_ub, r)

    kind, beta, d_struct = structural_bucket(M_hat, cfg.cal_fingerprints, cfg.delta_struct)
    if kind == 'ood':
        return ('reject', 'structural_ood', d_struct, beta)

    q_beta = generalization_quantile(beta, beta in ledger.seen, ledger.q,
                                     cfg.unseen_prior, d_struct, cfg.alpha, cfg.eta)
    if cfg.lc_state != 'valid':
        return ('reject', 'loop_closure_pending', cfg.lc_state, q_beta)
    if r_ub + q_beta > cfg.r_max:
        return ('reject', 'risk_budget', r_ub + q_beta, beta)
    return ('ok', J_gen(r_ub, beta, q_beta, cfg.lc_state, evidence=ledger))
```

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| MGC | O(|A|·|ℳ_t|) 采样 / O(|A|) 区间界 | O(|A|) | 可信集覆盖、Lipschitz 常数标定 |
| SFP | O(|G|+k|V|+n log n) | O(|G|+n) | 结构不变量稳定、桶可分 |
| LCG | O(1)/更新 + O(|G_changed|) 重认证 | O(|G|) | 跳变不漏报、影响域局部性 |
| CAS | O(|A|·N_h·|G|) 可贪心降阶 | O(N_h·|G|) | ECRR 近似无偏、覆盖约束硬性 |
| GCL | O(1)/样本 | O(|B|) | ACI 长期误覆盖 ≤ α_conf |
| GRC | O(|S|·|A|) | O(|S|+|A|) | 四门联合 sound、拒绝可解释 |

**正确性定理（Map-Grounded Generalization Soundness）**
假设第 54 轮 (A26)–(A28) 成立，并新增：**(A29)** `P(M_real∈ℳ_t) ≥ 1-α_map`；**(A30)** `J` 在 `D_struct` 上 `L_c`-Lipschitz；**(A31)** 结构 OOD 漏检率 `≤ β_ood`；**(A32)** 分桶 ACI 在缓变漂移下长期误覆盖 `≤ α_conf`；**(A33)** 回环守卫漏报率 `≤ β_LC`。则所有门通过的部署满足：

```
P(fail) ≤ q_β + L_c·ε_t + α_conf + β_ood + β_LC
```

证明：由 A29 将真值地图约束在 `ε_t` 球内；由 A30 将地图误差线性传给风险；由 A32 将非平稳部署切成结构桶并给出桶内风险分位数；由 A31/A33 处理结构出域与回环跳变两个非统计事件；四项取并集即得。**关键**：`q_β` 负责“见过的世界”，`L_c·ε_t` 负责“当前地图有多不确定”，`β_ood` 负责“世界结构是否变了”，`β_LC` 负责“地图是否刚刚跳变”。

## 8. 本轮最大风险

**一句话**：本方案的 soundness 压在一个诚实假设上——**SLAM 的可信集 `ℳ_t` 与回环跳变 `Δ_LC` 必须被真实估计**；若 SLAM 恰在感知别名与新拓扑处过度自信，`r_ub = r(\hat M)+L_c·ε_t` 会给出一个看似紧致、实则失效的泛化上界，因此必须以多假设可信集、回环挂起、未见结构桶保守回退三重护栏，绝不把外观相似当作结构泛化的证据。
