# 第 44 轮（本轮灵感循环第 2 轮） · LiDAR-Blind × Tactile-Contact：把「感知盲区」与「接触严重度」纳入可验证证书闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形只保边际覆盖 + 多用户契约求交为空」。但它仍压着一个更底层的单点假设：**(H1) 几何证书把「没检测到」当成「不存在」**——IP-49 的 m_lo 被默认为真实障碍距离的下界，而 LiDAR 对玻璃、纯黑、镜面、细线、雨雾尘是**按材质/几何结构性失明**的；**(H2) 安全被定义为「不接触」**——于是接触被当成纯失败，而触觉这一唯一能提供**接触后验真值**的模态被整个浪费。本轮灵感词「激光雷达」「触觉感知」精确命中：**激光雷达**迫使我们把感知从「标称点云」升级为带**盲区集合 U 的集合值证书**（未知 ≠ 安全）；**触觉**迫使我们把「接触」从禁区分级为**可持证的严重度约束事件**，从而在盲区里以受限速度合法前进。二者耦合点正是本轮真正的新问题：**预测证书（远程、先验）与反应证书（接触、后验）的交接**——何时把未知区的控制权从「避免接触」切到「受限接触」，以及交接点是否仍然 sound。

## 0. 直觉与动机

**灵感 1（LiDAR → 「看不清」必须显式建模，未知不是安全）**：LiDAR 的失效不是随机噪声，而是**按材质/几何结构化**的：透明玻璃几乎无回波、黑色哑光大量吸收、镜面产生鬼影（同时带来保守虚警与漏检）、细线因光束发散漏检、雨雾尘产生伪回波、量程外直接真空、扫描期自运动带来点云畸变。因此正确的几何证书不是一个标量 m_lo，而是三元组 (A, m, U)：**在 A\U 上 sound，在 U 上只能是 unknown**。核心纪律：**U 必须是被证明的过近似（over-approximation）**——拿不准就标未知，绝不把未知当空。这把第 43 轮的共形思想从「人意图」推广到「感知本身」：输出一个**共形 clear 集合**，保证 P(障碍存在 | 认证为清) ≤ α。一句话：**缺省不假设安全，缺省标未知。**

**灵感 2（触觉 → 接触不是失败，是可持证的受限事件）**：若坚持「永不进入 U」，玻璃桌、软物、暗处会直接把可用性打穿（第 41 轮可用性崩塌的重演）。触觉提供了唯一的**接触后验真值**：它能测力/滑移/局部几何。于是把接触分级：只要**接触前速度、峰值力、冲量**落在该材质的良性包络内，这次接触就是「可持证事件」而非违例。物理抓手是**阻抗/导纳控制 + 未知区限速**：v ≤ v_safe*(m) 使得到达边界时的剩余动能与冲量都在良性界内。但必须加一条铁律：**材质严重度未知 ⇒ 禁触**（等价于 U 视为占用），否则就是把「未知」偷换成「大概能摸」。一句话：**收缩（不进 U）永远安全；进入 U 必须降速、持接触包络证书、且材质已判良性。**

**灵感 3（耦合 → 预测-反应双证书交接 + 触觉即校准）**：LiDAR 是**预测性**（接触前、可规划），触觉是**反应性**（接触时、不可撤销）。二者盲区互补但时序不可交换：你不能「先摸到再决定别撞」。因此需要一个显式**交接状态机** PREDICTIVE→BUFFER→REACTIVE，其 soundness 需要三条同时成立：(i) 预测证书在缓冲外有效；(ii) 反应包络在缓冲内有效；(iii) 到达 U 边界前能降到 v_safe*（交接/减速可行性）。更强的是：每次接触是**极贵、极稀疏但带真值的标签**，可校正 LiDAR 的 clear 预测与盲区图，并回灌 CKB/SCV；但接触采样有**幸存者偏差**（你只摸到你摸到的，摸不到的盲区永远不产生标签），必须用**加权共形**修正协变量漂移，否则覆盖率保证会在最危险处悄悄失效。一句话：**接触既消耗风险，也生产校准；但校准样本必须去偏。**

**耦合升级**：BAGC（盲区感知几何证书）把点云变成 (A,m,U)；CGRC（接触门控反应证书）把 U 内的运动变成受限速度 + 力/冲量包络；TCAC（触觉校准主动认证）用接触标签做去偏共形校准并驱动主动探测。四层架构由 v8 的「人格 × 并发」升级为 v9 的「人格 × 并发 × **双模态证书交接**」。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（模态证书与盲区集合）**：模态 M 的证书 C_M=(A_M, m_M, U_M, α_M)：A_M ⊆ X 为认证可行域，m_M 为结构边际下界，U_M ⊆ X 为盲区/未知集，α_M 为残差风险。**Soundness**：∀x∈A_M\U_M，安全谓词以概率 ≥1−α_M 成立。**过近似纪律**：真实盲区 B_M ⊆ U_M（只能多标，不能少标）。**clear 算子**：D_M(x)=clear 仅在共形集值预测的障碍集 Ĉ_obs=∅ 时成立，保证 P(∃障碍 ∧ D_M=clear) ≤ α_M。**关键区分**：「未检测到」是观测，不是「不存在」这一事实；证书在 U_M 上返回 unknown 而非 safe。

**定义 45（预测证书与停止走廊）**：给状态 (x,v)，预测证书 P_L 成立当且仅当存在策略使得到完全停止前的所有位置都落在 A_L\U_L 内，且停止距离满足 d_stop(v)=v·T_react+v²/(2a_max)。**命题**：若 v≤v_max 且 dist(x,U_L) ≥ d_stop(v)+δ_margin，则 P_L 成立（保守充分条件）。

**定义 46（接触门控反应证书、材质严重度与受限速度）**：材质 m 的严重度 s(m)∈{benign, tolerable, forbidden}，**未知材质约定 s=forbidden**。良性接触谓词 benign(m) 仅在 s(m)≠forbidden 时定义：v_contact ≤ v_safe(m) ∧ F_peak ≤ F_max(m) ∧ J=∫F dt ≤ J_max(m)。反应包络 R_T 指阻抗控制器在接触缓冲 B_U={dist(x,U_L)<w_B} 内对任意到达接触保证 benign。**未知区限速**：v_safe*(m)=max{ v : decel_dist(v→v_safe)≤w_B ∧ J(v)≤J_max(m) }。**命题**：若 s(m)≠forbidden 且以 v≤v_safe*(m) 进入 U_L，则任意接触 benign（依赖接触模型与控制器 WCET）；若 s(m)=forbidden，则 U_L 等价于 occupied，只许预测式避让。

**定义 47（证书交接状态机与组合 soundness）**：状态 q∈{PREDICTIVE, BUFFER, REACTIVE}。转移：dist(x,U_L)≤d_stop(v) 时 PREDICTIVE→BUFFER（减速、武装反应、检查交接可行性）；越过 U_L 边界或检测到接触时 BUFFER→REACTIVE（限速 + 力控）；断触且退出 U_L 时 REACTIVE→BUFFER/PREDICTIVE。**交接可行性**：w_B ≥ (v²−v_safe*²)/(2a_max)+δ。**交接定理**：若 (i) 缓冲外 P_L 成立；(ii) 缓冲内 R_T 成立；(iii) 交接可行性成立且 T_handoff < T_contact_min=w_B/v_max；(iv) U_L 为过近似、且进入 U_L 的材质均 s≠forbidden，则组合证书 sound：全程无越界且无非良性接触。

**定义 48（触觉校准的去偏共形保证）**：接触事件 e=(位置, 力剖面, 重建局部几何, 材质估计) 是 clear 谓词的标签，但采样分布 q 有幸存者偏差（只覆盖被接触过的区域）。令目标分布 p、似然比 w(x)=p(x)/q(x)≤R。**加权共形命题**：按（材质 × 几何 × 距离）分层并以 w 加权分位数取阈值，则在协变量漂移下有 P(障碍∈Ĉ) ≥ 1−α−O(√(R·log n/n))；样本去偏需记录采样分布 q 并拒绝 w 超界样本。**推论**：接触可补充第 43 轮的信任预算 τ_u，但**只有去偏后的有效样本**才计入；未覆盖区域的盲区不会被接触证据“证明安全”（可见性偏差）。

**定义 49（主动认证与证书熵）**：感知动作空间 S（LiDAR 视点/多回波/波束、合规末端探测轨迹）。证书熵 H(C)=−Σ_cells p log p，p∈{certified, unknown, occupied}。**目标**：s* = argmax_s E[ Δmeasure(A(s)\U(s)) − λ_risk·Risk(s) − λ_c·Cost(s) ]。**命题**：次模性成立时贪心 next-best-view 达到 (1−1/e) 近似；**约束**：探测动作自身必须留在当前认证域内（含其 U 的反应包络），否则「为看清而靠近」会制造新风险。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 BLINDSPOT-AWARE GEOMETRIC CERTIFICATE（BAGC）
1. **材质条件共形 clear 预测**：按材质/距离 Mondrian 分层，用回波强度、回波数、入射角特征预测「可能存在障碍」集合 Ĉ_obs；仅当 Ĉ_obs=∅ 才判 clear。
2. **盲区过近似器**：融合无回波/低强度/量程外/高入射角/多回波缺失/未验证材质 → U_L；任何不确定单元一律标 unknown（sound）。
3. **证书三元组导出**：(A_L, m_L, U_L, α_L) 送入 IP-49/IP-51；m_L 只在 A_L\U_L 上可信。
4. **保守膨胀兜底**：若材质先验缺失或校准不足，则 U_L 膨胀为「全部未验证区域」，用可用性换 sound。

### 2.2 IP-61 CONTACT-GATED REACTIVE CERTIFICATE（CGRC）
1. **交接状态机**：PREDICTIVE/BUFFER/REACTIVE，携带进入条件、武装标志、交接可行性检查与断触回退。
2. **未知区限速器**：v_safe*(m) 由减速距离 + 冲量界实时求解；超限即强制单调减速（不可逆）。
3. **力/冲量包络监控**：阻抗控制 + 峰值力/冲量/滑移监测；越界触发单调降级或安全停机。
4. **接触事件日志**：记录 (t, 位置, v_c, F 剖面, J, 材质假设, benign 判定)，打硬件单调时间戳，供 TCAC/审计。

### 2.3 IP-62 TACTILE-CALIBRATED ACTIVE CERTIFICATION（TCAC）
1. **去偏共形校准**：用接触标签按材质×几何分层、似然比加权，更新 clear 预测与 α；检测漂移与采样偏差。
2. **信任预算补给**：仅当去偏有效样本增加且影子证书零违例时 τ_u 回升（接第 43 轮定义 39）。
3. **主动探测规划**：next-best-view（多视点 LiDAR）+ 受控探测（合规指/软末端）；动作必须留在当前认证域与反应包络内。
4. **盲区图回灌**：接触重建局部几何 → 更新 U_L 与材质指纹 → 回灌 IP-55 CKB 与 IP-54 SCV。

```

    → IP-44 蒸馏 + IP-50 材质对抗课程 → RCA 重颁 → 契约热更新
运行期：clear 仅在 ∀cell∉U → 预测式运动；接近 U → 减速武装、检查交接可行性；
        进入 U(仅 s≠forbidden) → 限速 + 力控；接触 → 记录/判 benign/去偏校准/回灌；
        过载 → HI 模式保安全力控与监控预算
```

回退：E95 失败 → U 全膨胀（全部未验证区视为占用），牺牲可用性换 sound；E96/E97 失败 → 禁入 U_L（Buffer 边界停机），退化为纯预测；E98 失败 → 关闭接触校准，τ_u 不回升；E99 无收益 → 关闭主动探测，退回被动；E100 失败 → 两证书取严格交，不做并集扩张；E101 失败 → 传感串行化并加大保守 margin；任何红线失败 → 熔断回退 v20。

## 5. 本轮最大风险

**一句话**：反应证书把「未知」合法化为「可容忍接触」，其 soundness 完全押在**未经证明的接触严重度模型**（F_max/J_max/柔顺性）与**触觉校准的幸存者偏差**上——一旦模型在玻璃/锐器/人手这类高严重度对象上失真，我们只是把「静默感知失效」换成了「静默接触失效」；因此 E95（盲区过近似）与 E97（最坏接触）必须是红线，默认底线仍是「不进 U_L + 严格预测证书」。

# 第 44 轮产物 · 创新点清单 v21：BAGC × CGRC × TCAC × 双模态证书交接闭环（四层架构 v9）

> 承接第 43 轮产物 v20。本轮**增量插入** IP-60/61/62，并升级 IP-45/47/49/50/51/52/53/54/55/56/57；不推倒任何既有层级。核心是把 v20 的「个性化安全 × 并发安全」飞轮，升级为同时满足 **感知盲区可证（未知≠安全）** 与 **接触可证（受限接触持包络证书）** 的双模态证书闭环。

## 2. 关键算法（伪代码）

### IP-60 BAGC：共形 clear、盲区过近似、三元组证书
```
def conformal_clear(x, material_hint, alpha):
    scores = calib_scores[material_hint]          # Mondrian: 按材质分层
    q = weighted_quantile(scores, 1 - alpha)      # 去偏加权分位阈值
    obs = predict_possible_obstacles(x)           # 集值预测
    C_obs = inflate(obs, q)                       # 共形膨胀
    A = workspace - C_obs
    U = blind_region_overapprox(x)                # 只能多标，不能少标
    return Cert(A=A, m=min_surface_dist(A), U=U, alpha=alpha)

def blind_region_overapprox(x):
    U = empty
    for cell in cells(x):
        if (no_return(cell) or low_intensity(cell) or range_out(cell)
                or grazing(cell) or multi_echo_missing(cell)
                or unvalidated_material(cell)):
            U.add(cell)                           # 不确定 => unknown
    return U

def clear_predicate(x, cert):
    return (x in cert.A) and (x not in cert.U) and (cert.m >= theta)
```

### IP-61 CGRC：限速、交接状态机、力/冲量守卫与接触日志
```
def v_safe_star(material, w_B, Jmax, v_hi):
    # 最大 v，使得到边界前可减速到良性接触速度且冲量不超界
    lo, hi = 0.0, v_hi
    for _ in range(20):                           # 二分
        v = 0.5 * (lo + hi)
        decel_ok = decel_dist(v, v_contact_benign(material)) <= w_B
        impulse_ok = impulse_bound(v, material) <= Jmax
        if decel_ok and impulse_ok: lo = v
        else: hi = v
    return lo

def handoff_step(state, x, v, cert, material):
    if s(material) == FORBIDDEN:                  # 未知/高危 => 永不进 U
        return PREDICTIVE, stop_before(cert.U)
    if state == PREDICTIVE and dist(x, cert.U) <= d_stop(v):
        if not handoff_feasible(v, v_safe_star(material, w_B(cert), Jmax[material]):
            return PREDICTIVE, stop_before(cert.U) # 交接不可行 => 只能停
        state = BUFFER; arm_reactive()
    if state == BUFFER and (x in cert.U or contact_detected()):
        state = REACTIVE
    if state == REACTIVE:
        v = min(v, v_safe_star(material, w_B(cert), Jmax[material]))
        set_impedance(F_max=Fmax[material])
    return state, v

def reactive_guard(contact):
    benign = (contact.v <= v_safe_star(contact.material, ...)
              and contact.F_peak <= Fmax[contact.material]
              and contact.J <= Jmax[contact.material])
    if not benign:
        return monotone_downgrade_or_safestop()
    return record_contact_event(contact)          # 打硬件单调时间戳
```

### IP-62 TCAC：去偏共形校准、信任补给与主动探测
```
def tactile_calibrate(events, p_target, alpha):
    # 幸存者偏差修正：按 (材质×几何×距离) 分层，似然比加权，截断 w≤R
    for stratum in strata(events):
        ev = [e for e in events if e.stratum == stratum]
        W  = [min(R, likelihood_ratio(e, p_target)) for e in ev]
        scores = merge(calib_scores[stratum], [score(e) for e in ev], W)
        calib_scores[stratum] = weighted_quantile_update(scores, 1 - alpha)
    if drift_detected(events):
        mark_material_fragile(); U.inflate()      # 漂移 => 保守膨胀
    return calib_scores

def trust_replenish(tau_u, debiased_gain, shadow_ok):
    if shadow_ok and debiased_gain > 0:
        return min(1.0, tau_u + eta * debiased_gain)   # 仅去偏有效样本
    return tau_u

def next_best_view(cert, budget):
    best, best_val = None, -inf
    for s in feasible_sensing_actions(cert):
        if not action_safe(s, cert):              # 动作须留在当前认证域
            continue
        gain = measure(unknown(cert, s)) - measure(unknown(cert))
        val = gain - lambda_c * cost(s) - lambda_r * risk(s)
        if val > best_val and cost(s) <= budget:
            best, best_val = s, val
    return best

def fuse_certificates(C_L, C_T, material_map):
    # 只做「有条件的并集」：U_L 中仅当材质 s≠forbidden 才由反应包络接管
    A = C_L.A - C_L.U
    for cell in C_L.U:
        if s(material_map[cell]) != FORBIDDEN and reactive_envelope_covers(cell):
            A.add(cell)
    return Cert(A=A, m=min_surface_dist(A),
                U=U_L - A, alpha=max(C_L.alpha, C_T.alpha))
```

## 6. 本轮最大风险

**一句话**：反应证书把「未知」合法化为「可容忍接触」，其 soundness 完全押在**未经证明的接触严重度模型**（F_max/J_max/柔顺性）与**触觉校准的幸存者偏差**上——一旦模型在玻璃/锐器/人手这类高严重度对象上失真，我们只是把「静默感知失效」换成了「静默接触失效」；因此 E95（盲区过近似）与 E97（最坏接触）必须是红线，默认底线仍是「不进 U_L + 严格预测证书」。
