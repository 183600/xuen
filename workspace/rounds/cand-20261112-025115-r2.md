# 第 58 轮（承接第 57 轮「少样本-跨模态-个性化证据承诺」IP-133~138；灵感循环第 4 轮；本轮灵感：「零样本泛化」×「步态规划」）

> 第 57 轮把安全的赌注从"模型置信"换成"证据承诺"，再用元先验 + 共形带把"证据质量"做到少样本可校准；但它同时留下一个结构性口子：**所有证据都要求"先看见/先摸到"**。MFSL 的 OOD 分支只是"承认自己没看见"，共形带只对与历史残差可交换的世界有覆盖；一旦面对**从未探过、且组合方式也新**的地形，系统只剩"拒绝"或"用带内最坏值硬撑"。零样本泛化要回答的正是这个口子：**在没有该区域任何接触证据时，凭什么敢迈第一步？** 本轮的回答是把问题从"世界是什么"翻转成"**哪种动作对一类可能世界都安全**"：不再要求先预测地形再规划，而是构造地形歧义集 𝒲(r)，在 𝒲 上求**鲁棒步态证书**，把承诺单元从"一个接触点"提升为"带切换与恢复的步态片段"；再用**认知步态**把"迈步"本身变成实验，用每步的有界风险换信息；用**任意时间有效的在集监控**把"歧义集漏掉真值"从不可见风险变成可检测、可回退、可回溯的事件。核心命题由"证据说可信"升级为 **"动作对声明的世界集合鲁棒、越界可监控、迈步即探询的零样本可信"**。

核心矛盾：
- **H29（零样本 vs 证书）**：零样本不是"不需要证据"，而是把证据对象从"世界身份"换成"动作对世界集合的鲁棒性"；证书只保证"集合内安全"，集合是否含真值是不可证的最小假设——风险从"坏先验"变成"坏支撑集"。
- **H30（稳健 vs 可观测）**：越稳的步态（低重心/宽支撑/慢速）越安全，却越小激励、越不可观测；越激进的步态信息多但风险高。零样本泛化必须显式交易"信息增益/风险增量"，否则要么原地不动，要么用高风险换信息。
- **H31（复合 vs 新物理）**：复合零样本假设"新地形 = 已知原语的组合"；真实世界可能存在不可分解的新机制。组合闭包会制造"看起来覆盖、实则外推"的虚假证书——这是本轮最危险的自我欺骗。
- **H32（切换 vs 失稳）**：把承诺单元从点变成步态片段后，最脆弱的往往不是片段内部，而是**切换瞬态**（支撑多边形切换、动量重分配、落脚冲击）。步态代数若只证明端点安全而不证明瞬态，灵活性反而变成新的失稳源。

## 0. 直觉与动机

**灵感 1（零样本泛化 → 动作侧歧义集，而不是世界侧点预测）**
直觉：蒙眼走一段陌生楼梯，不是先猜准每级台阶的高度，而是用小步、低重心、宽支撑、可随时停的步态，保证"只要台阶落在 10~18cm、摩擦不为零、能承重"这一族世界里，我都不会摔。零样本的安全来自"我的动作对这一族世界都成立"，不是"我猜中了世界"。
形式化上，把世界写成属性向量 w=(μ,κ,α,h,g,F_bear) 的歧义集 𝒲(r)，用原语库 + 复合闭包 + 支撑声明 Γ 构造它；安全证书是**最坏世界上的裕度** min_{w∈𝒲} margin(σ,w)。这与第 57 轮 MFSL 的关键区别是：**证书不要求元后验校准，只要求集合含真值**——效率仍可借元先验，安全不再押在元先验上。
但"集合含真值"不可证明。所以零样本必须附带第二件东西：**越界可监控**。我们不宣称 𝒲 一定对，而宣称"若真值在 𝒲 外，它必须在造成不可逆后果前被看见"。这把不可证的假设变成可度量的检测延迟与虚警率。

**灵感 2（步态规划 → 承诺单元从"点"到"带恢复的片段"）**
直觉：单个落脚点是否安全，在未知地形上几乎无法保证；但"600ms 的步态片段 + 两个已验证的切换出口 + 一个站立/爬行回退"可以在整族 𝒲 上保持支撑裕度与捕获点裕度。步态天然是"带策略的承诺"：它承诺的不是"这块石头能踩"，而是"在这段时间里，无论踩到什么，我都有下一步可退"。
形式化：步态 σ=(接触调度, 相位, 占空比, 步长/抬腿, 质心策略, 切换图)，承诺 = 承诺一个处于鲁棒可行性核 V_K(𝒲) 内的策略，而不是一个接触点。这样安全性与"知道世界"解耦：不知道世界，也可以在"对所有可能世界都安全"的子空间里行动。
需要注意，这不是把风险消灭，而是把风险**从"深接触的不可逆后果"搬到"浅接触的可恢复后果"**；首段视界 H_zs、首步步长、落速与回退距离必须同时受限，否则"可逆"只是口号。

**灵感 3（步态即实验 → 认知步态 EGP）**
直觉：同样是踩，脚尖轻点是测刚度，低速横移是测摩擦，重踏是测承载，单腿试探是测可落脚性。步态参数直接改变"世界对机器人的可见性"。第 57 轮的探针是"点状"的，本轮把探针升级为"**步态**"：一步既是动作也是实验。
形式化：给定步态条件观测模型 y=h(w,σ)+噪声，用 Fisher 信息/期望信息增益 EIG(σ) 度量"这个步态能把 𝒲 缩小多少"，用 ΔR(σ) 度量"相对当前回退策略增加多少最坏风险"，选 argmax EIG/(ΔR+ε) 且 ΔR≤ΔR_max 的步态。零样本不是一次预测，而是"用有界风险的首步把 𝒲 收紧，再决定是否深接触"。
这里有一个硬边界：若某个越界机制在所选步态的观测通道上**不可区分**（例如薄而硬的表皮下面全是空洞，轻踏与实心地面响应同分布），再好的规划也无法在深接触前发现它。零样本安全最终受**可观测性**而非算力限制。

**灵感 4（三灵感合流 → 复合-认证-探询闭环与第六类证据 EV-zero）**
直觉：先由几何/语义/历史构造 𝒲；用步态代数组合候选；在 𝒲 上求鲁棒证书并检查是否在 V_K 内；能证就迈"认证步态片段"，不能证就迈"认知步态"去缩小 𝒲；每步都用任意时间有效的在集监控看守；越界就回退、注新原语、回溯作废依赖旧集合的证书。证据门新增 **EV-zero**，但它只证明"动作鲁棒"，不证明"世界身份"，因此**只可用于 L0/L1，永不进入不可逆 L2 的必要证据集**。
用一张证据象限表说明本轮贡献：

| | 世界身份已知/可推断 | 世界身份未知 |
|---|---|---|
| 动作可对集合认证 | 第 57 轮：EV-probe*/EV-margin | **本轮：EV-zero（仅 L0/L1）** |
| 动作不可认证 | 绕行/重规划/降档 | 认知步态探询，否则拒绝或协商 |

第 57 轮"元先验错 ∧ OOD 漏检 ∧ 跨模态无一致 ∧ 无裕度 ∧ 人也错"的击穿链，被改写成"支撑集漏 ∧ 监控漏 ∧ 回退不可用 ∧ 切换瞬态失稳"。这多了监控与回退两个可工程化环节，但"支撑集漏"本身仍是不可证的核心假设。

**灵感 5（PCE++ → 探-诺-演从"点探针"升级为"步态级探询"）**
直觉：第 57 轮 PCE+ 在检查点做点状探针；本轮把预算花在"步态片段"上：VOI 变成"这个认知步态能把 𝒲 缩到可认证体积的概率 × 收益 − 风险成本"；承诺前插入**切换可行性检查**；若 𝒲 无法在预算内收紧到可认证，则退回站立/爬行/绕行/协商。零样本、步态、监控三机制仍只经"集合更小"或"动作更保守（裕度更大/回退更近/视界更短）"两个安全通道起作用。
必须强调：相对第 57 轮，本轮**新增了一种在未知地形上行动的许可**（EV-zero），因此不能声称全局风险单调下降。正确说法是：**用可逆层的新许可换未知地形上的可行动性，并用 L2 硬禁令与有界首步把新增风险隔离在可恢复层**。

## 1. 形式化定义（增量：定义 139–144）

约定：第 57 轮的 𝒲 记号在本轮专指**地形属性歧义集**（而非权重集合）；⪯ 表示"更保守"：约束更强、集合更小、回退更近、视界更短。

**定义 139（复合地形歧义集 CAS）** 属性 w=(μ,κ,α,h,g,F_bear)（摩擦/柔顺/坡度/粗糙/颗粒/承载）。原语库 𝒫={p_i=(w_i,Σ_i,sig_i)}，复合闭包 C(𝒫) 由有限积、区间盒、凸包与物理约束 Φ 生成。给定区域 r 的**无接触上下文** z_r（地图坡度、视觉材质类、语义先验）与第 57 轮观测 o_{1:k}，歧义集
𝒲(r)={w∈C(𝒫) ⊕ U(r) : supp(z_r,o_{1:k};w)≥1−α_w}，
其中 U(r) 是显式的"未知松弛盒"（半径 ρ_ext），防止把库外世界静默当成库内组合。支撑声明
Γ(r)=(所用原语, 复合深度 d_c, 外推半径 ρ_ext, 未覆盖轴/耦合, 已知不可分解性标记, 可区分性缺口声明)。
**诚实性要求**：Γ 必须逐轴披露"内插/外推"，并给出零样本覆盖缺陷声明 ε_zs(r)（允许写 "unknown"，不得伪报为 0）。CAS 的输出是 (𝒲,Γ,ε_zs)，不是点估计。

**定义 140（鲁棒步态证书 ZGC）** 步态 σ=(S_σ,φ,β,l,c_l,h_b,π_σ,T_σ)。对 w∈𝒲，滚动 x_{t+1}=f(x_t,u_t,w)，安全泛函 g(x,u,w)=(m_stab,m_slip,v_td,τ_ratio,reach) 各分量须 ≥ 阈值。定义
z(σ,𝒲)=min_{w∈𝒲} min_{t≤H} g(x_t,u_t,w)，ρ_zs(σ)=最大集合半径使 z≥0。
σ **零样本可认证** ⇔ z(σ,𝒲)≥0 ∧ 所有切换边经定义 141 认证 ∧ s_g∈V_K(𝒲)（定义 142）∧ 监控在效（定义 143）∧ 可区分性缺口 ≤δ_sep。证书只声明"对所有 w∈𝒲 安全"，**不声明 r 的真实身份**；ρ_zs 是"离已知原语多远仍安全"的可比较半径，可作为零样本泛化能力的部署指标。

**定义 141（复合步态代数 CGA）** 原语：stand/crawl/walk/trot/pace/bound/pronk/tap/weight-shift/slip-test/step-up-down。复合算子：⊕_φ（相位交织）、⊕_β（占空比调制）、⊕_supp（支撑多边形加宽/降重心）、⊕_step（步长/抬腿/落速）、⊕_rec（追加恢复原语）。文法 σ∈L(G) 要求占空比可行、同时摆动腿数受限、落点可达。**切换证书**：边 (σ,σ') 安全 ⇔ 存在瞬态 τ，使端点与瞬态同时满足 g≥0；否则插入中间原语（优先四足支撑）或触发急停。只证端点不证瞬态者，一律不算认证。

**定义 142（鲁棒可行性核 RVK）** 步态状态 s_g=(相位, 支撑集, 质心速度, 落点, 𝒲)。在"最坏 w∈𝒲 + 存在控制策略"的博弈语义下，
V_K(𝒲)={s_g : ∃π ∀w∈𝒲 ∀t≤H, g(x_t,π,w)≥0 且 t=H 可达安全站立}。
零样本可行动 ⇔ s_g∈V_K(𝒲)。在线只允许使用**保守内近似** V_K^inner⊆V_K（宁可漏判可行，不可误判可行）；判定超时按不可行处理。回退格 ℒ_fb 是由 stand/wide-crawl/lean/stop 组成的 DAG，每条边须有切换证书；V_K 成员资格要求至少一条到 ℒ_fb 的可达路径。

**定义 143（认知步态与在集监控 EGM）** 步态条件观测 y=h(w,σ)+ν，Fisher 信息 J_h(σ)，先验 π(𝒲)，EIG(σ)=H(π)−E_y[H(π|y,σ)]。风险增量 ΔR(σ)=最坏裕度相对当前回退策略的下降。**IGR(σ)=EIG(σ)/(ΔR(σ)+ε)**。选
σ*=argmax IGR(σ) s.t. ΔR(σ)≤ΔR_max ∧ σ 可安全执行到首个观测点。
监控用任意时间有效 e-过程：在 H0: w∈𝒲 下构造非负上鞅 e_t（例如分裂共形鞅），Ville 不等式给出 P(sup_t e_t≥1/α_set)≤α_set。若 e_t≥1/α_set，判**集合越界**：立即切回退、注入"未知原语"扩 𝒲、回溯作废依赖旧 𝒲 的 EV-zero 证书，并记录越界证据供云端补盲。**可区分性前提**：对所选步态序列 σ_{1:H}，要求 in-set 与危险 out-set 的观测分布可分离度 δ_sep(σ_{1:H})≥δ_sep_min；该量对真正未知的机制无法计算，只能声明并在实验中用留出集审计。

**定义 144（零样本证据门 ZSG 与证书 J_z）** 在定义 137 证据门上新增 **EV-zero**：
EV-zero ⇔ (i) z(σ,𝒲)≥0；(ii) s_g∈V_K^inner(𝒲)；(iii) 至少一条认证回退路径；(iv) 监控在效且无越界；(v) 仅 L0/L1；(vi) 首段视界 H_zs、首步步长、落速与回退距离受限；(vii) 不得替代不可逆 L2 必要证据集；(viii) δ_sep 声明成立。
J_z=(𝒲,Γ,ε_zs,σ,z,ρ_zs,VK_witness,ℒ_fb,transition_certs,monitor_log,e_value,refutation_log)，继承 J_p 全检。PCE++ 的承诺条件：∃g 使 R≤δ_f(g) ∧ (FSE 过 ∨ EV-zero 过)；L2 仍只认 {EV-probe*∨EV-margin}∪佐证。换句话说：**零样本可以让你"先走起来"，但不能让你"先赌下去"**。

## 2. 关键算法伪代码（完整版见产物区）

```python
def build_cas(r, M, z_ctx, primitives):
    parts = consistent_primitives(z_ctx, M.posterior[r], primitives)  # 无接触上下文筛选
    W, support = compose_closure(parts, ops=(product, interval_box, hull),
                                 unknown_slack=rho_ext(r))
    Gamma = declare_support(parts, depth=dc(W), extrapolated=axes_out(W),
                            separable_gap=estimate_sep_gap(z_ctx))
    return CAS(W=W, Gamma=Gamma, eps_zs=declare_zs_defect(Gamma))

def certify_gait(sigma, W, H):
    worst = enum_worst_cases(W)                    # 区间/场景/边界枚举，保守
    z = min(worst_rollout_margin(sigma, w, H) for w in worst)
    ok_edges = all(transition_certified(e, W) for e in sigma.transitions)
    return Cert(ok=(z >= 0 and ok_edges), z=z, radius=robust_radius(sigma, W))

def epistemic_gait(cp, W, current_fallback, risk_cap):
    cands = [s for s in gait_grammar(W) if exec_risk(s, W) <= risk_cap]
    return max(cands, key=lambda s: EIG(s, W) / (delta_risk(s, current_fallback) + EPS))

def in_set_monitor(e_prev, y, W, alpha_set):
    e = e_prev * likelihood_ratio(y, W)            # 任意时间有效 e-过程
    if e >= 1 / alpha_set:                          # 越界：回退 + 注新原语 + 回溯
        return Monitor(flag='SET_MISS', broaden=True, refute=True, e=e)
    return Monitor(flag='IN_SET', broaden=False, refute=False, e=e)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| CAS | O(\|𝒫\|·d_w) 构造；O(\|𝒲\|) 采样 | O(\|𝒫\|·d_w) | 支撑声明诚实、未知松弛不被吞掉 |
| ZGC | 离线 O(N_W·H·d_x)；在线查表/内近似 | O(N_W·H) | 只允许保守内近似、切换瞬态入证 |
| CGA | O(\|G\|·\|T\|) 组合与切换检查 | O(\|G\|) | 文法可行、瞬态证书完备 |
| RVK | 离线 O(\|S_g\|·\|A\|·N_W)；在线 O(1)~O(log) | O(\|S_g\|) | 内近似不乐观、超时即不可行 |
| EGM | O(\|G\|·N_particles·(EIG+rollout)) | O(N_particles) | IGR 风险封顶、e-过程 anytime-valid |
| ZSG | O(\|σ\|) 证据门检查 | O(\|σ\|) | EV-zero 永不进 L2 必要集 |

**正确性命题（ZSR, Zero-shot Robustness Soundness 概要）**：在 A37–A40 上加
(A41) 支撑声明诚实：ε_zs 不伪报，外推轴与不可分解性披露完整；
(A42) 证书内近似保守、模型/数值误差 ≤δ_model；
(A43) 切换瞬态证书完备（端点 ∧ 瞬态 ∧ 回退路径）；
(A44) 监控 anytime-valid 且越界后回退可用（失败概率 ≤δ_fb）。
则：
(i) **集合内路径**：若 w*∈𝒲 且内近似可靠，L1 零样本承诺失败 ≤δ_model。
(ii) **集合外路径**：若 w*∉𝒲，失败仅当监控在首次 L1 承诺前未检出，概率 ≤ε_zs·δ_det + δ_fb，其中 δ_det 由可区分度 δ_sep 与检测视界决定。
(iii) **保守序**：𝒲 变大、Γ 更不诚实、回退格更小、视界更长，都只会使证书更难通过；不存在"扩张歧义集反而更容易认证"的通道。EV-zero 是新的**可逆层许可**，不是对 L2 约束的放松。
(iv) **终止性**：每个认知步态必须带来 ≥ε_info 的 EIG 或触发回退；有限文法与视界下 PCE++ 在 K_gait 个步态片段内终止于 {认证承诺, 回退, 绕行, 协商, 停止}。

**与第 57 轮的关系**：第 57 轮保证"有证据才承诺"；本轮保证"无证据时，只承诺一个对声明的世界集合鲁棒、越界可监控、后果可恢复的**动作**"。前者是**认识论安全**，后者是**行动论安全**；两者用 L2 硬边界隔开，不可互相冒充。

```python
def build_cas(r, M, z_ctx, primitives, alpha_w, rho_ext):
    # 1) 无接触上下文 + 第57轮观测，筛出与证据不矛盾的属性区域
    parts = consistent_primitives(z_ctx, M.posterior[r], primitives)

    W = compose_closure(parts, ops=('product', 'interval_box', 'hull'),
                        constraints=PHYS_COUPLINGS)

    W = minkowski(W, U(r, radius=rho_ext))
    W = {w for w in W if support_score(z_ctx, M.obs[r], w) >= 1 - alpha_w}
    # 4) 支撑声明：逐轴披露内插/外推、复合深度、不可分解性、可区分性缺口
    Gamma = declare_support(parts, depth=composition_depth(W),
                            extrapolated=axes_outside_library(W),
                            indivisible_flags=scan_indivisible(W),
                            sep_gap=estimate_sep_gap(z_ctx))
    eps_zs = declare_zs_defect(Gamma)          # 允许 'unknown'，禁止伪报 0
    return CAS(W=W, Gamma=Gamma, eps_zs=eps_zs)

def shrink_cas(W, evidence, modality_reliability):
    # 第57轮 XMC 的属性分账在多模态证据上做贝叶斯收缩；只收缩、不扩张
    for m in evidence.modalities:
        W = condition(W, evidence[m], w=modality_reliability[m])
    return W

def inflate_cas_unknown(W, miss_event):
    # 集合越界后注入未知原语，并把该轴标记为不可分解/高外推
    p_unknown = UnknownPrimitive(axis=miss_event.axis, box=miss_event.residual_box)
    return compose_closure([W, p_unknown], ops=('union', 'interval_box'))
```

```python
def certify_gait(sigma, W, H, theta_g):
    # 只做保守枚举/区间分支定界；禁止用点预测替代最坏世界

                z=z,
```

```python
    if op == 'phase':  return interleave_contacts(g1, g2, phi=choose_phase(g1, g2))
    if op == 'duty':   return modulate_duty(g1, beta=choose_duty(g1, g2))

def plan_gait_sequence(cp, W, grammar):
    cands = [s for s in grammar if well_formed(s)]
    certs = {s: certify_gait(s, W, H_zs, theta_g=0) for s in cands}
    ok = [s for s in cands if certs[s].ok and fallback_reachable(s, cp.fallback)]
    if not ok:
        return None
    # 优先高鲁棒半径，其次低切换数，最后低时间成本
    return min(ok, key=lambda s: (-certs[s].radius, len(s.transitions), duration(s)))

def transition_certified(edge, W):
    g1, g2 = edge.src, edge.dst
    # 瞬态必须显式建模：支撑多边形切换、动量重分配、落脚冲击
    for tau in transient_candidates(g1, g2, prefer='four_support'):
        if all(margin(tau, t, w) >= 0 for w in enum_worst_cases(W) for t in tau.times):
            return True
    # 无安全瞬态则插入四足支撑中间原语；仍不行则拒绝该边
    return False
```

```python
def viability_inner(s_g, W, fallback, H):
    # 区间分支定界求保守内近似：unknown 一律按不可行处理
    if fallback_reachable(s_g, fallback):
        return VKResult(member=True, witness=fallback.path(s_g))
    for a in admissible_actions(s_g):
        succ = robust_successors(s_g, a, W)          # 最坏世界下的后继集合
        if all(margin(s, w) >= 0 for s in succ for w in enum_worst_cases(W)):
```

```python
                alt = reroute(M, cp, risk_model)
                if alt: route = alt; continue
                return negotiate_or_stop(cp, M, None, None, consent,
                                         tau_int=tau_int(personas.active.auth))
        # 执行一个步态片段；每一步更新在集监控
        for step in execute_snippet(sigma, cap=F_abs):
            mon = monitor_update(log.e, step.obs, W, alpha_set)
            log.record(mon)
            if mon.flag == 'SET_MISS':
                refute_ev_zero(log, mon)
                W = inflate_cas_unknown(W, mon)
                sigma = choose_epistemic_gait(cp, W, cp.fallback, risk_cap=DELTA_R_MAX)
                break
            if evidence_gate_z(core_contact(cp, step), M, personas, ood_reg)[0] != 'ok':
                break
        else:
            # 片段内未越界且证据门通过 → 承诺该片段
            if evidence_gate_z(core_contact(cp, sigma), M, personas, ood_reg)[0] == 'ok':
                sched.append(commit(sigma)); log.append(tag_evidence_z(sigma, W))
                continue
        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, M)) != 'halt':
            route = alt; continue
        return negotiate_or_stop(cp, M, sigma, schedule_risk(sigma, M), consent,
                                 tau_int=tau_int(personas.active.auth))
    return sched, log, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CAS | O(\|𝒫\|·d_w) 构造；O(\|𝒲\|) 采样 | O(\|𝒫\|·d_w) | Γ 诚实、未知松弛不被吞掉（A41） |
| ZGC | 离线 O(N_W·H·d_x)；在线查表/内近似 | O(N_W·H) | 只做保守内近似、切换瞬态入证（A42/A43） |
| CGA | O(\|G\|·\|T\|) 组合与切换检查 | O(\|G\|) | 文法可行、瞬态证书完备（A43） |
| RVK | 离线 O(\|S_g\|·\|A\|·N_W)；在线 O(1)~O(log) | O(\|S_g\|) | 内近似不乐观、超时即不可行（A42） |
| EGM | O(\|G\|·N_p·(EIG+rollout)) | O(N_p) | IGR 风险封顶、e-过程 anytime-valid（A44） |
| ZSG | O(\|σ\|) 证据门检查 | O(\|σ\|) | EV-zero 永不进 L2 必要集（硬禁令） |
| PCE++ | O(\|CP\|·(\|G\|·N_p·H + K_gait·d_x)) | O(\|V\|+\|G\|+\|ℒ_fb\|) | 有限文法/视界 + EIG 下界终止 |

**正确性定理（ZSR, Zero-shot Robustness Soundness）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 支撑声明诚实：ε_zs 不伪报为 0，外推轴、复合深度与不可分解性披露完整；**(A42)** 证书内近似保守且模型/数值误差 ≤δ_model，判定超时按不可行处理；**(A43)** 切换瞬态证书完备（端点 ∧ 瞬态 ∧ 回退路径），不存在未建模的同时摆动；**(A44)** 监控为 anytime-valid e-过程（H0 下 E[e_t]≤1），越界后回退可用且失败概率 ≤δ_fb。则：

1. **集合内健全性**：若 w*∈𝒲 且内近似可靠，则 L1 零样本承诺失败概率 ≤ δ_model。
2. **集合外界定**：若 w*∉𝒲，失败只可能发生在"监控未在首次 L1 承诺前检出"或"回退失败"，故
   P(fail) ≤ ε_zs·δ_det + δ_fb，其中 δ_det=sup_{w∉𝒲} P_w(no detect before commit | w)。
3. **保守序（不是全局单调性）**：对固定动作，𝒲 越大、Γ 越不诚实、回退格越小、视界越长，证书只会更难通过：若 𝒲1⊆𝒲2，则 z(σ,𝒲2)≤z(σ,𝒲1) 且 ρ_zs(σ,𝒲2)≤ρ_zs(σ,𝒲1)。EV-zero 是**可逆层的新许可**，不是对第 57 轮 L2 约束的放松；因此本轮不宣称相对 PCE+ 的全局风险单调下降。
4. **终止性**：每个认知步态必须产生 ≥ε_info 的 EIG 或触发回退；在有限文法与 H_zs 下，PCE++ 在 K_gait 个片段内终止于 {认证承诺, 回退, 绕行, 协商, 停止}。
5. **部署界**（对检查点与步态片段取联合界）：

```
P_safe ≥ 1 − Σ_snippet (δ_model + ε_zs·δ_det + δ_fb)
             − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1])
             − P(𝓜 陈旧未检出) − P(护盾回退失败)
             − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
```

**可用性界（与安全界分开）**：虚警只造成保守回退，不造成失稳；每片段虚警概率 ≤α_set，故
P(至少一次虚假回退) ≤ Σ_snippet α_set。E178 必须同时报告"安全界"与"可用性界"，否则会把"因为总是回退所以从不摔倒"误读为零样本能力强。

**关键设计原则**
- **效率与安全再次解耦**：元先验/CAS 只负责"把集合造得尽量小"（效率），证书只负责"在集合上最坏情况安全"（安全）；元先验错只让集合变大、证书更难，不会让证书变假。
- **动作证据与世界证据正交**：EV-zero 不回答"这是什么"，只回答"这样走是否对 𝒲 内所有世界都安全"；因此 L2 仍必须回到第 57 轮 FSE 的世界证据。
- **越界是事件，不是沉默**：e-过程 + 回退格 + 回溯作废，使"支撑集漏真值"从不可见的系统性风险变成可记录、可补盲、可审计的工程事件。
- **步态是承诺单元**：承诺 σ 而非单点，安全来自"片段内裕度 + 瞬态裕度 + 回退可达"三者同时成立。
