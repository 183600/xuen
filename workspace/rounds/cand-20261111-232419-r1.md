# 第 57 轮（承接第 56 轮「证据地图×主动探询×信任协商」IP-127~132；本轮灵感：「多视角视觉」×「传感器融合」）

> 第 56 轮把"单帧置信"升级为"证据承诺"，并给证据一个持久的家（𝓜）；但它只问"有没有证据"，没问"证据是否彼此独立"。一次分割、三次不同角度的相机、再加一条云端先验，看似四票，实则可能共享同一个失效模式（同一模型偏差、同一光照、同一外参误差）——**相关证据被当成独立证据，融合只会把同一条错误放大成不容置疑的"高置信"**。本轮用「多视角视觉」补上"几何见证"（语义必须被视差、极线、三角化验证，而不是再投一票），用「传感器融合」补上"失效模式多样性"（相机、LiDAR、IMU、力/触觉各有不同的坏法，只有异质通道才能互相作证）。核心命题由"证据说可信"升级为 **"独立证据说可信"**：安全不能建立在证据数量上，只能建立在失效模式的去相关上。

核心矛盾：

- **H26**：第 56 轮 SMM 的 Bayes 融合隐含条件独立假设；但同源/同模态证据的误差高度相关，`N` 次视角不提供 `N` 份信息，反而制造虚假自信。证据门 `EV-probe/visit/...` 因此可被"相关重复"刷满——看三次同一块反光地面，不会比看一次更接近真相。
- **H27**：多视角与多传感器不是免费的：外参标定是所有视觉通道的共模失效点，融合又引入"冲突时该信谁"的新决策；把"更多传感器"直接等同"更安全"，会把系统推向**相关性盲区**与**融合幻觉**，甚至比单目更危险。

## 0. 直觉与动机

**灵感 1（多视角视觉 → 语义是假设，几何是否证器，视差是证据的"汇率"）**
直觉：单帧分割给出的是"这里像地面"，多视角给出的是"这里的三维结构是否真能支撑这个标签"。极线残差、视差基线、跨视角光度一致性构成一组**可否证的几何检验**：若语义说"连续平台"而三角化出 8 cm 的台阶，则应否决语义，而不是让分割置信再投票一次。更关键的是，视角数量不是信息量——**两个共享同一外参偏差、同一光照、同一模型偏置的视角，等价于一个视角**；真正的增益来自基线角、尺度、成像机理的差异。因此"换视角"要从第 56 轮的"补一次分割"升级为"补一个几何见证"，并主动选择**去相关增益最大**的下一最佳视角（NBV）。

**灵感 2（传感器融合 → 异质失效模式才是冗余，冲突本身是信息）**
直觉：相机怕反光/透明/弱纹理，LiDAR 怕浓雾/高反材料，IMU 怕积分漂移，力/触觉怕标定偏置与滑移——它们的"坏法"不同，才是真正的冗余来源。经典 Kalman 融合假设通道独立、误差高斯；一旦相关性未知，正确做法是协方差交叉（CI）/分裂 CI 这类保守融合，而不是把协方差当独立直接相加。更进一步，Dempster 冲突质量 `K` 不是要平滑掉的噪声，而是一条**警报**："至少有一个通道在说谎"，此时正确动作是**诊断性探询**（用第三种模态去区分嫌疑源），而不是各打五十大板地平均。

**灵感 3（见证对 → 从"证据计数"到"失效模式覆盖"）**
直觉：一次不可逆接触，视觉只能证明"表面看起来在哪"，力/触觉才能证明"它实际承受了什么"。因此证据门应从"有证据类"升级为"有**见证对**"：至少两条证据的失效模式签名不相交，且相关性有上界。对不可逆承诺，还要求至少一条**物理独立通道**（力/触觉，或经标定的关节电流/足端压力）参与——不允许纯视觉证据单独放行不可逆接触。这不是不信任视觉，而是承认视觉的共模失效无法由视觉自身证伪。

**灵感 4（有效样本量 → 信息有上限，相关重复不能买来确定性）**
直觉：把每条证据看成一次"观测"，相关性 `ρ` 决定它能折算成多少个独立观测。`N` 条完全相关证据的有效样本量仍是 1；融合后的后验方差不可能低于 `σ²/N_eff`。所以地图信念的更新必须按 `N_eff` 膨胀协方差、按 `N_eff` 计算证据门，而不是按条目数。**多样性预算**（同一失效模式至多贡献多少权重）应和探针预算、能量预算一样，成为一等资源。

**灵感 5（冲突驱动诊断 → 探询的目标是"分辨谁错"，不只是"看得更清"）**
直觉：第 56 轮的 VOI 问"再探一次能降多少风险"；本轮要问"再探一次能**区分哪两个互斥假设**"。当视觉与触觉冲突时，最有价值的动作可能不是再看一眼，而是轻加载、换模态、或做一次自标定。于是探询空间从 `{view,tap,shift,revisit}` 扩展为 `{diverse-view, cross-modal, self-calib, load-test, revisit}`，其价值函数显式惩罚与已用证据的相关性、奖励对冲突假设的判别力。

## 1. 形式化定义（增量：定义 133–138）

**定义 133（证据溯源图与有效独立性）** 证据图 `D = (E, φ, ρ, w)`：每条证据 `e` 带失效模式签名 `φ(e) ⊆ Φ`，`Φ = {光照, 反光/透明, 弱纹理, 运动模糊, 外参标定, 内参标定, 分割模型偏差, 接触滑移, 传感器退化}`；`ρ(e_i,e_j) ∈ [0,1]` 为失效相关性上界（未知一律取 1，而非 0）。有效样本量
`N_eff = (Σ_i w_i)² / (Σ_{i,j} w_i w_j ρ_ij)`，`ρ_ii = 1`；
信息上限：融合后验满足 `Var(b_post) ≥ Var(like)/N_eff`，或等价地 `D_KL(b_post‖b_prior) ≤ N_eff · I_max`。**相关重复不得增加置信**。

**定义 134（多视角几何见证）** 对语义假设 `h=(r, label, μ, k, F_bear)` 与视角集 `V={v_1..v_m}`：
`W_geo(h,V) = 1[ max_{i<j} ε_epi(v_i,v_j) ≤ ε_epi* ∧ max_{i,j} β(v_i,v_j) ≥ β_min ∧ c_photo ≤ c* ∧ trace(U_cal) ≤ θ_cal ]`，
其中 `β` 为基线张角，`U_cal` 为外参后验协方差。若三角化表面在接触尺度上的不连续度 `disc(surf) > δ_h`，则**几何否证** `h`：`W_falsify(h)=1`，无论分割置信多高。见证同时输出深度协方差 `Σ_depth`，经 `contact_params_map` 传播为 `(μ,k,F_bear)` 的协方差下界。

**定义 135（失效模式覆盖与见证对）** 对承诺接触的证据集 `S`：
(i) **反支配**：`∀m∈Φ, Σ_{e:m∈φ(e)} w_e / Σ_e w_e ≤ θ_dom`；
(ii) **覆盖**：`|Clusters(φ(S))| ≥ 2`；
(iii) **见证对**：`∃ e_i,e_j: φ(e_i)∩φ(e_j)=∅ ∧ ρ_ij ≤ ρ_max`。
覆盖率信念按簇而非条目合成：`Corr(S) = 1 − ∏_{c∈Clusters(φ(S))} (1 − p_c)`。**同一失效模式内的重复证据只计一次。**

**定义 136（相关性感知融合 CAF）** 将第 56 轮的朴素 Bayes 更新 `b_r ← Bayes(b_r, like(e))` 替换为相关性感知算子：
`b_r ← CI-Fuse(b_r, like(e); ω, ρ̄)`，权重膨胀 `w_eff = w / (1 + (m_eff−1)·ρ̄)`，`m_eff` 为该失效模式内已有证据数；协方差按 `ρ̄` 上界膨胀（保守）。冲突质量 `K = 1 − Σ_A m_1(A)m_2(A)`。若 `K > θ_c`，**不更新向任何一方**，区域标记 `contested`，`κ_𝓜` 取保守下界 `κ_lo`，并触发定义 137 的诊断探询。

**定义 137（主动多视角/多模态探询 NBV）** 动作 `π=(v, sensor, mode)`，`mode∈{diverse-view, cross-modal, self-calib, load-test, revisit}`。去相关信息价值
`VOI_div(π) = E[H(b_r) − H(b_r|e_π)] · D_φ(π; E_used) · (1 − ρ̄(π, E_used)) − λ·corr_penalty(π) − cost(π)`，
其中 `D_φ = |φ(π) \ ∪_{e∈E_used} φ(e)| / |φ(π)|` 为**新增失效模式覆盖**。选择 `argmax VOI_div ≥ θ_voi`；同一失效模式至多 `k_mode` 次探询。自标定探针在 `trace(U_cal) > θ_cal` 时强制可行。

**定义 138（多样性-证据证书 DMC）** `J_d = (𝓜_core, D, N_eff, W_geo, conflict_log, health_log, consent_log, evidence)`。证据门升级为 `EV-geo`（多视角几何见证）、`EV-xmodal`（去相关见证对）、`EV-contact`（力/触觉实测）、`EV-visit`、`EV-margin`、`EV-human`。承诺规则：普通可逆接触需满足定义 135 的见证对；**不可逆接触额外要求 `EV-contact` 或经认证的非视觉物理见证**。无见证对即拒绝；冲突未决即拒绝；标定后验失效即拒绝（先自标定）。

## 2. 关键算法伪代码（完整版见产物区）

### IP-133 DEG（Decorrelation Evidence Graph）

```python
def deg_add(D, e, w):
    phi = failure_signature(e)                 # 光照/反光/弱纹理/标定/模型/退化...
    for e2 in D.items:                         # 未知相关一律保守取 1
        D.rho[e, e2] = conservative_corr(e, e2, phi, e2.phi)
    D.add(e, w, phi)
    D.N_eff = (sum(D.w))**2 / sum(D.w[i]*D.w[j]*D.rho[i, j]
                                  for i in D.items for j in D.items)
    return D, info_cap(D.N_eff)
```

### IP-134 MVG / NBV（Multi-view Geometric Witness + Next-Best-View）

```python
def geometric_witness(h, views, cal):
    if trace(cal.U) > theta_cal: return ('invalid', 'self_calibrate')
    if max(epipolar_residual(a, b, h) for a, b in pairs(views)) > eps_epi:
        return ('reject', 'epipolar')
    if max_baseline_angle(views) < beta_min: return ('weak', 'need_baseline')
    surf = triangulate(views)
    if disc(surf) > delta_h: return ('reject', 'geometry_falsifies_label')
    return ('accept', {'depth_cov': cov(surf), 'params': contact_params_map(h, surf)})

def next_best_view(M, r, used, budget):
    return argmax(admissible_views(r, F_abs),
                  key=lambda v: voi_div(v, M, r, used) - cost(v)
                                - lambda_corr*max_corr(v, used))
```

### IP-135/137 CAF + CDP（相关感知融合 + 冲突驱动诊断）

```python
def caf_fuse(b, like, D, e):
    K = conflict(b, like)                       # Dempster 冲突质量
    if K > theta_c:
        return contested(b, kappa_lower(b)), 'conflict'   # 不向任何一方更新
    w_eff = D.w[e] / (1 + (D.m_eff[e.phi] - 1) * D.rho_upper[e])
    post = bayes_update(b, like, weight=w_eff)
    return inflate_cov(post, D.rho_upper[e]), 'ok'

def diagnose(r, M, D, budget):
    suspects = top_failure_modes(D, r)          # 冲突双方的失效模式
    return argmax(admissible_probes(r, M, F_abs),
                  key=lambda p: conflict_reduction(p, suspects)
                                - cost(p) - lambda_corr*corr(p, D))
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| DEG | O(\|E\|²) 增量维护（可稀疏化） | O(\|E\|²) | `ρ` 为上界、未知取 1，`N_eff ≤ N_true` |
| MVG/NBV | O(\|V\|²·N_pix + \|C\|·C_voi) | O(\|V\|·N_pix) | 外参后验有效、几何否证阈值 sound |
| CAF | O(d_b²)+O(\|Φ\|) | O(d_b²) | 冲突不融合、协方差只膨胀不收缩 |
| CDP | O(k_d·(C_diag+\|Φ\|)) | O(\|Φ\|) | 诊断预算终止、优先独立模态 |
| DMC | O(\|σ\|+\|D\|) | O(\|σ\|+\|D\|) | 无见证对即拒绝、不可逆需物理见证 |
| SMH | O(1)+O(H) | O(\|Φ\|) | 退化通道先降权到 `w_min` 再传播 |

**正确性定理（Diversity-Grounded Commitment Soundness, DGCS）**：在第 56 轮 A29–A36 基础上加 **(A37)** 相关性估计保守：`ρ̂ ≥ ρ_true` ⇒ `N_eff̂ ≤ N_true`，融合信息不超估；**(A38)** 多视角几何见证 sound：`P(几何误接受) ≤ δ_geo`，外参后验有效；**(A39)** 冲突检测 `P(K>θ_c | 真冲突) ≥ 1−δ_conf`，冲突路径只降不升；**(A40)** 传感器健康监测在 `τ_h` 内把退化通道权重压到 `w_min`。则：
(i) 承诺接触失效率 `≤ δ_f + ε_cal(N_eff) + δ_geo + δ_probe + ε_h + δ_health`；
(ii) **反膨胀引理**：任意共享失效模式的证据集，其后验置信增益被 `N_eff` 封顶，相关重复不能把风险降到 `δ_f` 以下；
(iii) **保守单调引理**：冲突、几何否证、健康降权、标定失效四条路径只能触发更保守的动作（重探/自标定/降档/停），不存在升险交互路径；
(iv) PCE+CDP 在 `k_probes+k_diag` 内终止于 {承诺, 绕行, 协商, 安全停}。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| `ρ` 被低估 → "多样性剧场"，比朴素融合更过度自信 | 高 | `ρ` 取上界、未知取 1；对抗性共因注入测试；`N_eff` 外部审计 |
| 外参标定是全体视觉通道的共模失效点 | 高 | 标定后验入证据门；`trace(U_cal) > θ_cal` 强制自标定；几何见证带标定不确定度 |
| 不可逆接触缺乏物理独立通道（无触觉平台） | 高 | 退化到 `EV-contact` 替代（关节电流/足端压力）；否则禁止不可逆承诺，只允许保守步态 |
| 冲突阈值过低 → 频繁停/警报疲劳；过高 → 静默错融 | 中 | 冲突分级 + 诊断优先 + 确认率监控；阈值按可逆性分档 |
| 多视角+CI+NBV 在边缘端算力超预算 | 中 | 稀疏证据图、仅对 contested 区域开 MVG、缓存标定、异步健康监测 |

## 6. 本轮最大风险

**一句话**：本轮把安全赌注从"证据数量"换到"证据独立性"，但独立性 `ρ` 与几何见证所依赖的外参标定，都是**从同一批可能相关的数据里估出来的**——一旦 `ρ` 被低估或标定发生共模漂移，"多样性证书"就会退化为"多样性剧场"，让系统以比朴素融合更自信的姿态为同一个错误放行；因此必须以 `ρ` 保守上界+未知取 1、对抗性共因注入、标定后验硬门、以及不可逆接触必须由物理独立通道见证，四重护栏把"伪独立"挡在承诺之前。

# 第 57 轮产物 · 创新点清单 v33：VeriFuse-Diverse（去相关证据×多视角几何见证×异质传感器融合，DEG×MVG×CAF×CDP×SMH×DMC）

> 承接第 56 轮 IP-127~132（SMM/PCE/BVK/ISE/TAF/MEC）与第 55 轮 IP-121~126。第 56 轮把"单帧置信"升级为"证据承诺"，却默认证据彼此条件独立；本轮把部署前提再升级为 **"独立证据承诺"**：每一条证据先过 **失效模式去相关**，语义假设必须过 **多视角几何否证**，异质传感器按 **未知相关** 做保守融合，冲突被当作 **诊断探询的触发器** 而非噪声。核心机制一句话：**不等权平均更多传感器，而是让不同"坏法"的传感器互相作证。**
> IP 编号：IP-133~IP-138（共 6 个新增），升级 IP-127/128/129/132 以纳入相关性、几何见证与物理独立通道。

### IP-133 DEG（Decorrelation Evidence Graph）

```python
def failure_signature(e):
    phi = set()
    if e.src == 'seg':      phi |= {'分割偏差'}; phi |= model_bias_modes(e.model)
    if e.type == 'view':    phi |= {'光照', '反光透明', '弱纹理', '运动模糊'} & e.cond
    if e.type in ('tap','shift','load'): phi |= {'接触滑移'}
    if e.cal is not None and trace(e.cal.U) > theta_cal: phi |= {'外参'}
    if e.health.score < h_min: phi |= {'传感器退化'}
    return phi

def conservative_corr(e1, e2):
    # 不估计"有多相关"，只估计"至少有多相关"；未知/跨源不可证一律 1
    if e1.channel == e2.channel:            return 1.0
    if e1.model is not None and e1.model == e2.model: return max(0.8, cal_overlap(e1,e2))
    if e1.cal is not None and e2.cal is not None and same_rig(e1,e2):
        return max(corr_from_cal(e1,e2), 0.5)   # 共享外参 → 至少半相关
    return corr_upper_bound(e1,e2)          # 默认保守上界

def deg_add(D, e, w):
    phi = failure_signature(e)
    for e2 in D:
        D.rho[e, e2] = conservative_corr(e, e2)
        D.rho[e2, e] = D.rho[e, e2]
    D.add(e, w=w, phi=phi)
    W = D.w; R = D.rho
    D.N_eff = (sum(W.values())**2) / sum(
        W[i]*W[j]*R[i, j] for i in D for j in D)
    D.m_eff = {m: sum(w for x, w in D.w.items() if m in D.phi[x])
               for m in Phi}
    return D, InfoCap(N_eff=D.N_eff, I_max=D.I_max)
```

### IP-134 MVG（Multi-view Geometric Witness）

```python
def geometric_witness(h, views, cal):
    # h = (region, label, mu, k, F_bear) 语义-接触假设
    if trace(cal.U) > theta_cal:
        return Witness('invalid', reason='calibration', action='self_calibrate')
    if len(views) < 2:
        return Witness('weak', reason='no_baseline', action='need_diverse_view')

    epi = max(epipolar_residual(a, b, h.ref) for a, b in pairs(views))
    beta = max_baseline_angle(views)
    photo = max_photometric_inconsistency(views, h)
    if epi > eps_epi:       return Witness('reject', 'epipolar')
    if photo > c_star:      return Witness('reject', 'photometric')
    if beta < beta_min:     return Witness('weak', 'need_baseline')

    surf, cov = triangulate_with_cov(views)
    if disc(surf) > delta_h:
        # 语义说连续支撑面，几何说断裂：几何可否证语义（Popper 式）
        return Witness('reject', 'geometry_falsifies_label', surf=surf)
    params = contact_params_map(h, surf, cov)
    return Witness('accept', 'ok', depth_cov=cov, params=params,
                   geo_score=geo_confidence(epi, beta, photo, cov))

def next_best_view(M, r, used, budget):
    cands = [v for v in admissible_views(r, F_abs)      # 视角运动本身须安全
             if not destructive(v, M, F_abs)]
    def score(v):
        fresh = |phi(v) - union(phi(e) for e in used)| / |phi(v)|
        return (expected_info_gain(v, M, r) * fresh
                * (1 - max_rho(v, used)) - cost(v))
    return argmax(cands, key=score) if score else None
```

### IP-135 CAF（Correlation-Aware Fusion）

```python
def caf_fuse(b, like, D, e):
    # 1) 冲突检测：先判"是否该融合"
    K = dempster_conflict(b, like)
    if K > theta_c:
        # 冲突不是噪声：不向任何一方更新，标 contested，触发诊断
        b_c = contested(b, kappa=kappa_lower(b))
        return b_c, FusionResult('conflict', K=K, escalate=True)

    # 2) 权重按有效独立性膨胀，协方差只膨胀不收缩
    m = D.m_eff[dominant_mode(e)]           # 该失效模式内已有证据数
    rho = D.rho_upper[e]                    # 相关上界（未知=1）
    w_eff = D.w[e] / (1 + max(m - 1, 0) * rho)
    post = bayes_update(b, like, weight=w_eff)
    post = inflate_cov(post, factor=1 + (m - 1) * rho)
    # 3) 信息上限硬约束：不得低于按 N_eff 的概率界
    if info_gain(post, b) > D.info_cap:
        post = clip_to_info_cap(post, D.info_cap)
    return post, FusionResult('ok', w_eff=w_eff, N_eff=D.N_eff)

def covariance_intersection(P1, P2, omega):
    # 未知相关下的保守融合（DEG 证据权重映射为 omega）
    P = inv(omega * inv(P1) + (1 - omega) * inv(P2))
    return P, omega
```

### IP-136 SMH（Sensor Health Monitor）

```python
def sensor_health(ch, hist):
    r = innovation(ch, hist)                 # 新息残差
    cusum = hist.cusum + (abs(r) - k_sigma * ch.sigma)
    score = 1 / (1 + exp(-(cusum - h0) / h1))
    flags = set()
    if score < h_min:            flags |= {'传感器退化'}
    if consistency(ch, hist) < c_min: flags |= {'时序不一致'}
    return Health(score=score, flags=flags,
                  action='downweight' if flags else 'ok')

def health_apply(D, ch, health):
    if health.action == 'downweight':
        for e in D.by_channel(ch):
            D.w[e] = min(D.w[e], w_min)      # 先降权，再允许进入融合
    return D
```

### IP-137 CDP（Conflict-Driven Probing）

```python
def conflict_reduction(p, suspects):
    # 期望把互斥假设的冲突质量降到多少
    H = [h for h in suspects]
    return expected_disagreement_drop(p, H)

def diagnose(r, M, D, budget):
    suspects = top_failure_modes(D, r)
    cands = admissible_probes(r, M, F_abs)           # cross-modal/self-calib/load-test
    cands = [p for p in cands if not destructive(p, M, F_abs)]
    while budget.diag_left > 0 and cands:
        p = argmax(cands, key=lambda q: conflict_reduction(q, suspects)
                                     * independence_bonus(q, D)
                                     - cost(q))
        if conflict_reduction(p, suspects) < theta_diag: break
        e = execute_probe(p, cap=F_abs)
        D, _ = deg_add(D, e, weight_of(e))
        if e.modality not in {x.channel for x in D}:
            return 'resolved_by_independent_channel', e   # 独立通道一票定谳
        budget.diag_left -= 1
    return 'unresolved', None                        # 未决 → 保守停/升级协商
```

### IP-138 DMC（Diversity Map-Evidence Certificate）

```python
def diversity_gate(contact, S, D, irreversibility):
    # 1) 反支配 + 覆盖 + 见证对（定义 135）
    if any(D.mass(m) > theta_dom for m in Phi): return ('reject','mode_dominated')
    if len(D.clusters(S)) < 2:                  return ('reject','no_coverage')
    if not any(phi(a).isdisjoint(phi(b)) and D.rho[a,b] <= rho_max
               for a,b in pairs(S)):            return ('reject','no_witness_pair')
    # 2) 不可逆承诺必须物理独立见证（相机/分割互相不算）
    if irreversibility == 'low':
        phys = [e for e in S if e.type in ('force','tactile','foot_pressure','joint_torque')]
        if not phys: return ('reject','irreversible_without_physical_witness')
    # 3) 几何与标定硬门
    if contact.ev == 'EV-geo' and not contact.witness.accepted:
        return ('reject','geo_witness_failed')
    if trace(contact.cal.U) > theta_cal:        return ('reject','calibration_stale')
    return ('ok', None)

def diversity_map_certificate(sched, D, M, consent_log, health_log, budgets):
    for c in contacts(sched):
        S = evidence_set(c, D)
        ok, why = diversity_gate(c, S, D, reversibility(c))
        if not ok: return ('reject', why, c)
        if c.ev not in {'EV-geo','EV-xmodal','EV-contact','EV-visit','EV-margin','EV-human'}:
            return ('reject', 'no_evidence_class', c)
    if min(x.K_margin for x in sched) < budgets.theta_K:  return ('reject','K_margin')
    if rho_sem(sched, M) < budgets.rho_min:               return ('reject','rho_sem')
    if any(h.flags for h in health_log):                  return ('reject','sensor_degraded')
    if not all(l2.resolved for l2 in consent_log):        return ('reject','consent_open')
    return ('ok', DiversityCert(
        M.core, core_contacts(sched), D.N_eff, D.rho_upper,
        geo_witnesses(sched), conflict_log(D), health_log,
        probe_log(D), consent_log))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DEG | O(\|E\|²) 增量（稀疏图近 O(\|E\|·k)） | O(\|E\|²) | `ρ̂ ≥ ρ_true` ⇒ `N_eff̂ ≤ N_true`，信息不超估（A37） |
| MVG | O(\|V\|²·N_pix + \|C\|·C_voi) | O(\|V\|·N_pix) | 几何误接受 ≤ `δ_geo`；标定后验有效（A38） |
| CAF | O(d_b² + \|Φ\|) | O(d_b²) | 冲突不融合、协方差只膨胀、信息上限硬截断 |
| SMH | O(1)+O(H) | O(\|Φ\|) | 退化通道先降至 `w_min`，时延 ≤ `τ_h`（A40） |
| CDP | O(k_d·(C_diag+\|Φ\|)) | O(\|Φ\|) | 诊断预算终止、独立通道优先（A39） |
| DMC | O(\|σ\|·\|E\|) | O(\|σ\|+\|E\|) | 无见证对/无物理见证即拒绝、日志完备 |

**正确性定理（Diversity-Grounded Commitment Soundness, DGCS）**
假设 A22–A28（第 53/54 轮）、A29–A36（第 55/56 轮）成立；并补充：
**(A37) 相关保守性**：`ρ̂(e_i,e_j) ≥ ρ_true(e_i,e_j)`，因而 `N_eff̂ ≤ N_eff_true`，融合信息增益满足 `D_KL ≤ N_eff·I_max`；
**(A38) 几何见证 sound**：在标定后验有效时，`P(W_geo=accept | h 假) ≤ δ_geo`，且几何否证不因分割置信被覆盖；
**(A39) 冲突可检测**：`P(K>θ_c | 真冲突) ≥ 1−δ_conf`，冲突分支只产生 `contested` 或更保守动作；
**(A40) 健康监测及时**：退化通道在 `τ_h` 内被压到 `w_min`，且降权只减少其信息贡献。
则：

1. **承诺健全性**：每个被承诺接触满足
`P(fail) ≤ δ_f + ε_cal(N_eff) + δ_geo + δ_probe + ε_h + δ_health`；
2. **反膨胀引理**：对任意共享失效模式的证据集，后验置信增益被 `N_eff`（而非条目数）封顶；相关重复不能把风险压到 `δ_f` 以下；
3. **保守单调引理**：冲突、几何否证、健康降权、标定失效四条路径只经（a）保守降权或（b）触发更保守动作（重探/自标定/降档/停）影响系统，不存在升险路径；
4. **物理见证不可绕过**：不可逆承诺若缺少物理独立通道（力/触觉/足端压力/关节电流），DMC 直接拒绝，纯视觉证据无法单独放行；
5. **终止性**：PCE+CDP 在 `k_probes + k_diag` 内终止于 {承诺, 绕行, 协商, 安全停}；
6. **部署界**：
```
P_safe ≥ 1 − Σ_cp (δ_f + ε_cal(N_eff) + δ_geo + δ_probe + ε_h + δ_health)
             − P(标定共模漂移未检出) − P(冲突未检出) − P(健康监测超时∧保守停失效)
```
关键：**第 56 轮防的是"坏证据"，本轮防的是"伪独立证据"**；单点模型偏差不再能靠多看几次刷成确定，必须由不同坏法的通道交叉作证。

## 6. 本轮最大风险

**一句话**：本轮把安全赌注从"证据数量"换到"证据独立性"，但独立性上界 `ρ` 与几何见证所依赖的外参标定，都是从同一批可能相关的数据中估出来的——一旦 `ρ` 被低估或标定发生共模漂移，"多样性证书"就会退化为"多样性剧场"，使系统比朴素融合更自信地为同一个错误放行；必须以 `ρ` 保守上界（未知取 1）、对抗性共因注入测试、标定后验硬门、不可逆接触强制物理独立见证四重护栏，把"伪独立"挡在承诺之前。
