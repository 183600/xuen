# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「路径规划」×「热管理」）

> R69 让系统学会了「问」，但它把每一次决策都当成**一次性、瞬时结清的交易**：不确定性是当前的，交互预算是「单位时间 ≤ 1 次」的瞬时上限，执行是 horizon H 内的动作块。真实的长时程任务不是这样结账的——**热量会累积，资源会耗尽，路线选择会锁死未来几十秒的产热曲线**。R69 的「不确定就问」隐含了一个从未写下的前提：**问是免费的**。但看/问/触都要算力与作动，它们都在**发热**；而发热又改变传感器标定，让下一次判断更不确定。于是存在一个 R66–R69 都没命名的正反馈：**不确定 → 多算/多问 → 升温 → 传感器漂移 → 更不确定**。
>
> 本轮两个灵感正好各补一半：
> - **路径规划**给出「全局、长时间、可锁定」的决策层——不只是「这一步选哪个模态」，而是「整条路线属于哪个同伦类」（绕左还是绕右是不可连续变形的两类）；路线一旦选定，就决定了未来的**产热签名**。
> - **热管理**给出「带记忆的资源约束」——热量不能瞬时清零，有热惯性与累积剂量；于是预算不是「每步 ≤」，而是「整条轨迹的积分 ≤」。
>
> 核心命题：**把「路径」与「热量」看成同一个有限预算的两种投影。planning 选择产热签名，thermal 限定签名可行域，二者在三个时间尺度上分层耦合；同时用「温度」这个可测状态去解释（而非放任）R68 的标定漂移——把一部分不可约的 epistemic 不确定性，降级为可预测的状态估计。** 命名 **THERMO-RAS**（Thermal-Homotopy Energy-budgeted Mission-oriented Risk-Adaptive System）。
>
> 一句话定位：R66 问谁控制，R67 问未来怎样，R68 问测量还准吗，R69 问该向谁求证，R70 问 **「我还能走多远、还能撑多久」——不确定性之外，还有一个会积累、会反馈、会被伪装成正常解释的资源问题。**

## 0. 直觉与动机

**灵感 1（路径规划 → 从「选模态」到「锁定同伦类」）**
直觉：R69 每步重采样 K 条动作、聚类、选一条，但下一步又重来——这在岔口会**抖动（mode flicker）**：左一下右一下，平均下来既不左也不右。人类不这样：一旦决定绕左，就沿左侧走廊走到底，除非遇到新证据才在**岔口**改主意。路径规划的语言正好描述这件事：绕左与绕右属于**不同同伦类**（在自由空间里不能连续变形互达）；正确的对象不是单步动作，而是「承诺一个同伦类 + 只在认证切换点重规划」。这把 R69 的多模态从「每步犹豫」升级为「全局承诺 + 带滞回的可证切换」。

**灵感 2（热管理 → 预算有记忆、会积累、会反馈）**
直觉：R69 的预算形如「每秒最多问一次」，是**瞬时速率**约束，擦掉历史。但热不是这样：结温取决于过去一段时间产热与散热的**积分**，有热惯性（时间常数从秒级到分钟级），还有**累积剂量**（长期高温加速老化，Arrhenius 型）。一个在瞬时安全、但持续满载的轨迹，会在几分钟后过热。热管理给出的正确约束是**轨迹级积分约束**：峰值温度 ≤ T_max，且累积热剂量 ≤ A_max。更关键：R69 的看/问/触本身要算力与作动，是**会发热**的——「问」不是免费的。

**灵感 3（耦合 → 路径即产热签名，产热即路径代价）**
直觉：不同路线产热不同：绕远但平缓的路 vs 抄近但急加速急转的路，前者能耗高、后者峰值热高。所以「哪条路好」不能只在几何空间里算最短路，要在 **(时间, 能量, 峰值热, 累积剂量)** 的多目标里算，并且**路线选择会锁死未来几十秒的热轨迹**。反过来热状态也约束路径：热余量低时，只能选「低产热但更慢/更远」的类。规划与热管理不是两个模块，是同一个约束的两个面。

**灵感 4（耦合的阴暗面 → 热-认知正反馈 TEFS）**
直觉：把 R69 和 R70 接起来会得到一个危险的环：越不确定越想多采样/多交互 → 算力与作动增加 → 结温上升 → 传感器热漂移（R68 的标定参数本就随温度变）→ 观测更差 → 更不确定。这是一个**正反馈**；若环增益 ≥ 1，系统会「越努力越糊涂」，最后过热且过保守。R70 的严肃任务之一，就是把这个环写出来、定义它的增益、并给出「必须在哪个工作域内保证增益 < 1」的稳定条件——否则 R69 的「问」在热应力下是**自毁**的。

**灵感 5（把热漂移从「不可约不确定」降级为「可预测状态」——以及它的反噬）**
直觉：R68 把缓慢标定漂移当作要兜底的 epistemic 风险，R69 用 Δa 去嗅探「被标定吸收的故障」。但热漂移有**物理原因**：温度变了，零偏/增益就变。若我们能测/估温度 T，就能**前馈**预测漂移 c(T)，把一大块「未知的漂移」变成「已知的状态」。这是正面的：热给标定提供**先行指标**，也给 R69 的 Δa 一个「良性物理解释」。反噬在于——**「这是热的锅」可以成为最完美的借口**：一个真实故障/攻击只要伪装成热漂移的形状，就会被系统温柔地解释掉。所以 R70 必须同时交付**反洗白（anti-laundering）**：用能量守恒做物理审计，让「热解释」不能被单通道伪造。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（THERMO-RAS 总览与四不变式）** THERMO-RAS = (HCP, TO, HGM, TCL, TAD, CRA, HAL, TBR, ThC, FLUID-RAS†)。继承 R69 全部不变式，并增加：
(i) **轨迹级热约束**：峰值 T_i(t) ≤ T_max,i 且累积剂量 A(t) ≤ A_max；
(ii) **承诺稳定**：同伦类切换仅发生在认证切换点，且满足最小驻留时间 τ_dwell（无 Zeno 抖动）；
(iii) **热-认知稳定**：标称工作域内闭环增益 g_TEFS < 1（定义 320）；
(iv) **反洗白**：任何「热解释」须通过能量守恒审计（定义 324）才可降级异常。

**定义 311（热状态与观测器 TO）** 集总 RC 多节点模型：C_i Ṫ_i = Σ_j G_ij(T_j−T_i) − G_{i,amb}(T_i−T_amb) + q_i(t)。离散化 T_{t+1}=A T_t + B q_t + d_t，参数 (C,G) 带不确定集 Θ。观测器输出**区间** [T_lo, T_hi]（对 Θ 取最坏情形，或 EKF + 椭球投影）。安全用 T_hi，进取用 T_lo（resolution bonus 的热版本）。

**定义 312（产热模型 HGM）** q_t = q_act(a_t) + q_comp(K,N_step) + q_int(g_t) + q_env。q_act = vᵀR_v v + τᵀR_τ τ + q_static；q_comp ∝ K·N_step·D·f（算力发热）；q_int 为注视/探针/问句的作动与推理发热。故 R69 的交互预算同时是**热预算**的一部分。

**定义 313（路径、同伦类与产热签名）** 计划 P=(h, waypoints, 时间参数化 σ)，h ∈ ℋ 为自由空间基本群 π₁(C_free) 上的同伦类（绕左/绕右/穿越为不同字）。产热签名 Q(P)=∫ q(P(t)) dt ∈ ℝ^m（峰值、积分、剂量）。**签名只依赖 (h, σ) 与执行**，是规划层的分段可加量。

**定义 314（热可行计划与代价）** 给定当前热状态区间 [T_lo,T_hi] 与资源 (E_rem, A_rem)，计划 P 热可行 ⇔ 预测峰值 T_hi(P) ≤ T_max 且 A_rem − A(P) ≥ 0 且 E_rem − E(P) ≥ 0。代价 J(P)=(w_E E(P), w_τ τ(P), w_T peak(P), w_A A(P))，在可行集上取优；不可行类直接剪枝（热余量低时剪掉高产热的急行类）。

**定义 315（累积资源预算与热债）** 能量预算 E(t)、热剂量 A(t)=∫₀ᵗ exp(−E_a/(k_B T(τ)))dτ。定义**热余量** M(t)=T_max − T_hi(t)、**热债** D(t)=∫ (q_in−q_diss)₊ dτ。任务可完成性要求全轨迹上 M ≥ ε_T 且 A ≤ A_max；M 与 (E,A) 共同构成「带记忆预算」，区别于 R69 的瞬时预算。

**定义 316（分层分配与契约 HAL）** 三时钟：
- 慢钟（~1Hz，分钟级）：HCP 选同伦类 h，按段分配能量/热额度 (e_i, a_i, m_i)；
- 中钟（~10Hz）：在 h 内做热感知时间参数化 σ（「减速散热 / 加速过窗」）；
- 快钟（~400Hz）：R69 FLUID 环在段内执行。
**契约**：快钟不得超出本段分配额度；超出须向慢钟发**预算再协商请求**（定义 321），否则以 R69 兜底。时间尺度比 ρ=τ_fast/τ_slow≪1，据此用奇异摄动论证分层合理性。

**定义 317（热-标定耦合 TCL）** 标定参数随温度：c(t)=c₀ + K_T(T(t)−T_ref) + O(ΔT²) + ν。定义温度条件化残差 r_res^T = r_res − r_cal,T(T)。R68 的 COF 由「盲标定」升级为「热条件标定」，把可预测分量前馈扣除（引理 20）。

**定义 318（热异常判别 TAD）** 给定 R69 的异常证据 (r_res↓, Δa↑) 与热估计 T：
- 若异常落在热模型预测的**解释锥** 𝒞_T={δ: ‖δ−K_T ΔT‖_{Σ⁻¹} ≤ κ} 内 → 判「良性热漂移」，不触发 R68 故障告警，但记账；
- 否则 → 判「非热异常（真故障/攻击）」，触发 R68/R69 保守。
判别须有**独立确认**（至少一个非温度源），单靠温度不得定案（防温度本身被投毒）。

**定义 319（同伦承诺与认证重规划 CRA）** 承诺类 h_t；仅当出现认证切换点（两类的可行连接状态存在、连接代价 ≤ 本段额度、且 C-RAS-WM 前缀认证通过）且滞回裕度 Δ_h 被超过、且驻留时间 ≥ τ_dwell 时，才允许 h_t→h′。切换计数与代价进证书；禁止在非切换点跳类 ⇒ 无 Zeno 抖动。

**定义 320（热感知风险缩放与 TEFS 稳定）** λ_T = max(λ_FLUID(U), λ_floor(U)+μ_T·(1−M/M_ref)₊)；热余量低 ⇒ λ 上调、K 下调、交互降温。定义**热-认知闭环增益** g_TEFS = (∂U/∂T)(∂T/∂q)(∂q/∂I)(∂I/∂U)，I 为算力/交互强度。稳定性要求工作域内 g_TEFS < 1；若观测到 g_TEFS ≥ 1，强制**热降级**：关交互、K=1、λ→λ_floor，切断反馈（退回 R69/R68）。

**定义 321（热预算再协商 TBR）** 快钟请求 (Δe,Δa,Δm)；慢钟在全局可行域内重解并回授，带**单调安全**：协商失败或超时 ⇒ 该请求作废、快钟按最保守额度执行（λ 不降）。再协商频率同样受限，防止用协商绕过预算。

**定义 322（热证书 J_THERMO）** J_THERMO = (J_FLUID, T_hi_p95, A_used/A_max, E_used/E_max, homotopy_class_hash, switch_count, g_TEFS_hat, tcl_residual, energy_balance_residual, thermo_ver)。Valid ⇔ Valid(J_FLUID) ∧ 峰值/剂量/能量未越界 ∧ 承诺稳定 ∧ g_TEFS<1 ∧ 反洗白审计通过。

**定义 323（热威胁模型 ℰ_thermo）** (a) **热逼迫**：环境诱导高作动路径/高频交互把系统烤到熔断阈值，逼其降级到 R68 后制造机会；(b) **热传感欺骗**：谎报低温以解除节流；(c) **热洗白**：真实故障伪装成热漂移形状，利用定义 318 的解释锥逃避告警。并入 AIC：ℰ_THERMO = ℰ_FLUID × ℰ_thermo。

**定义 324（反洗白：能量守恒审计）** 设实测温升 ΔT_meas 与由电/机械功率积分预测的 ΔT_pow，功率平衡残差 p_bal=‖C ΔT_meas − ∫(q_in−q_diss)‖。**若某「热解释」要成立，必须存在与之匹配的真实能量流**；单靠篡改温度读数会产生 p_bal 失配。故：把异常降级为「热漂移」当且仅当 **p_bal ≤ τ_bal 且至少一个独立通道（功率/振动/多测点梯度）一致**。伪造解释需同时伪造能量守恒（受物理限制）或多通道共谋（引理 21）。

**定义 325（严格包含与退化边界）** 当热观测不可信（区间宽度 > τ_T）、或资源充裕（M≫ε_T 且 A_rem≫）、或 g_TEFS 无法认证时，THERMO 层整体旁路，逐指令等价于 FLUID-RAS（进而 R68）。故 R70 是 R69 的严格泛化。

# IP-264 TO：带不确定性的热观测器（区间/椭球）
def thermal_observe(T_prev, q_hist, Theta, meas):
    T, P = rc_predict(T_prev, q_hist, Theta)          # A T + B q + d，Θ 取包络
    T, P = kalman_or_ellipsoid_update(T, P, meas)
    return T, sqrt(diag(P))                            # -> [T_lo, T_hi]

# IP-265 HGM：产热（动作/算力/交互）
def heat(q_act, K, N_step, g):
    return q_act + c_comp*K*N_step*D*f + q_interaction(g)

# IP-266 HCP：同伦类热可行规划（分段可加，剪枝）
def plan_homotopy(start, goal, T_hi, E_rem, A_rem, budget):
    best = None
    for h in homotopy_classes(start, goal):            # 绕左/绕右/...
        for sigma in time_param_candidates(h):         # 热感知时间参数化
            P = (h, sigma)
            if not thermally_feasible(P, T_hi, E_rem, A_rem): continue
            if not c_ras_wm.certify_plan(P): continue
            J = (wE*E(P), wtau*tau(P), wT*peak(P), wA*A(P))
            if best is None or J < best.J: best = (P, J)
    return best                                        # 无可行情 -> 报不可完成

# IP-267 TBE：累积预算估计（能量/剂量/热债）
def thermal_budget(q_hist, T_hist):
    return E_rem(q_hist), A_used(T_hist), debt(q_hist, T_hist)

# IP-269 TCL：热条件化标定
def calibrate_with_T(o, T):
    c_T = c0 + K_T*(T - T_ref)                         # 前馈预测漂移
    r   = residual(o, c_T)
    return c_T, r - r_cal_pred(T)                      # r_res^T，可预测分量已扣

# IP-270 TAD + 反洗白：良性热漂移 vs 真故障/攻击
def thermal_anomaly(r_res, da, T, power_log, indep_channels):
    explained  = mahalanobis(da - K_T*(T-T_ref), Sigma) <= kappa
    balance_ok = power_balance_residual(T, power_log) <= tau_bal
    agree      = orthogonal_agree(indep_channels, k=2)  # 至少 2 源一致
    if explained and balance_ok and agree:
        return "benign_thermal"                          # 记账，不告警
    return "true_anomaly"                                # -> R68/R69 保守

# IP-271 CRA：承诺 + 认证切换（滞回，防 Zeno）
def maybe_replan(h_committed, state, plan, budget):
    if dwell_time(state) < tau_dwell: return h_committed
    if not certified_switch_point(state, h_committed): return h_committed
    h_new = replan(state)                                # D*lite 风格增量重规划
    if homotopy_gain(h_new, h_committed) <= Delta_h: return h_committed
    if not plan_switch_certified(state, h_committed, h_new): return h_committed
    return h_new                                          # 仅在认证点切换

# IP-276 主闭环（三时钟；快钟内嵌 R69 FLUID 环）
def THERMO_RAS_mission(M, obs_stream):
    P  = M.hcp.plan_homotopy(...); h = P.class_
    for obs in obs_stream:
        T_hi, T_lo = M.to.step(M.to.prev, M.hgm.history, obs)
        # 中钟：热感知时间参数化
        if M.clock.medium():
            P = M.hcp.retime(P, T_hi=T_hi)
        # 快钟：R69 FLUID 执行，交互要扣「热价」
        U_ale, U_epi, modes, _ = M.fluid.decompose(...)
        g = M.mint.choose_interaction(modes, obs, M.budget,
                                      heat_price=M.heat_price(T_hi))
        # 热-认知稳定门：增益失控则切断反馈
        M.g_tefs.update(...)
        if M.g_tefs.hat >= 1.0:
            g, K = None, 1                               # 热降级：不问、少算
        lam = max(M.fluid.lam(U_ale, U_epi, g),
                  lam_floor_T(U_ale, U_epi, T_hi))
        k   = M.c_ras_wm.certified_prefix(...)
        # 热预算超支 -> 再协商或保守
        if M.hal.over_budget(T_hi, k):
            k = M.tbr.renegotiate_or_conservative(k, T_hi)
        # 承诺与重规划（慢钟事件）
        if M.clock.slow():
            h = M.cra.maybe_replan(h, obs, P, M.budget)
        M.thc.submit(M.fluid.cert, T_hi, h, M.g_tefs.hat)
    return h

## 3. 推导

**引理 19（产热签名的分段可加性与规划剪枝）** 若产热签名按段时间可加，则 E(P)=Σ e_i、A(P)≤Σ a_i（凸性下取等），峰值受段间热惯性平滑。故「整条轨迹热可行」可由「逐段额度 + 段边界热状态」递推判定，规划层可用标签设置法在 O(|ℋ|·N_seg) 内剪枝；不可行类在进入前即被删除。

**引理 20（热条件化降低漂移方差）** 设漂移 = 热可解释部分 K_TΔT + 余项。扣除前馈后，残差方差 Var(r_res^T) ≤ Var(r_res) − ‖Cov(r_res,ΔT)‖²/Var(ΔT)。即 TCL 把一部分 epistemic 方差变成可测状态，等价于给 R68 的故障检测**提高有效信噪比**；Δa 同理。

**引理 21（热洗白的能量审计下界）** 设真实异常幅度 δ，若想用「热解释」使其落进解释锥，则必须使观测温升与功率积分同时自洽。仅篡改温度传感需附加功率失配 p_bal ≥ c_δ·δ；仅篡改功率需与多测点温度梯度矛盾。故反洗白把单通道伪造的代价提高到「要么物理注入能量（可被总量预算发现），要么两路独立共谋」，错误洗白率 ≤ δ_p·ρ + ε_bal。

**定理 18（THERMO 严格包含 FLUID/R68）** 在 A99–A102（热模型 Lipschitz、签名可加、TCL 线性余项有界、切换点存在）下，THERMO 的任意状态期望风险 ≤ FLUID ≤ R68；当热观测不可信/资源充裕/未认证时两者逐指令相同（定义 325）。安全侧不做让步；效率侧通过「热余量换 resolution bonus + 路线优化」获益。

**定理 19（承诺稳定与无 Zeno）** 在滞回裕度 Δ_h>0、最小驻留 τ_dwell>0、切换仅在认证点下，同伦类切换序列在有限时间内有限次，平均切换率 ≤ 1/(τ_dwell+τ_switch)；控制连续、无抖动，且每次切换的代价计入预算、不破坏热可行（定义 319、引理 19）。

**定理 20（热-认知闭环稳定性）** 若工作域内 g_TEFS<1，且热降级动作（关交互、K=1、λ→λ_floor）能在 τ_safe 内把 q_comp+q_int 压到 q_diss 以下，则不确定性与温度变量在 Lyapunov 意义下有界，不发生 TEFS 失控；反之若 g_TEFS≥1 且无法降级，则存在参数使二者发散（故定义 320 的强制热降级不是保守，而是**稳定性的必要条件**）。

## 6. 本轮最大风险

**一句话**：R70 最危险的不是热失控，而是**「解释得太好」**——一旦系统学会用温度解释标定漂移，任何真实故障（或攻击）只要披上「热漂移」的外衣，就会被 TAD 温柔降级、被 TCL 前馈扣掉、被证书盖上「良性」的章；**热解释成了洗白通道，系统在物理上越来越热、在认知上越来越自信地错下去**——这比 R69 的「问错」更隐蔽，因为它伪装成了「理解」。

**次级风险与缓解**：
1. **热模型/观测器失配**（老化、未建模热源、稀疏测温）→ 区间包络 + 保守峰值 + E313/E315；

5. **三时钟实时性被慢规划拖累** → 规划非阻塞 + 事件触发 + E304。

## 4. 推导

**引理 19（签名分段可加与剪枝）** 签名分段可加 ⇒ E(P)=Σe_i、A(P)≤Σa_i，峰值受热惯性平滑；「整条轨迹热可行」可由段额度 + 段边界热状态递推判定，O(|ℋ|·N_seg) 内剪枝不可行类。

**引理 20（热条件化降方差）** 扣除热前馈后 `Var(r_res^T) ≤ Var(r_res) − ‖Cov(r_res,ΔT)‖²/Var(ΔT)`：TCL 把一部分 epistemic 方差变成可测状态，提升 R68 故障检测信噪比。

**引理 21（热洗白的能量审计下界）** 用「热解释」把幅度 δ 的异常洗白，须使温升与功率积分同时自洽；仅篡改温度需功率失配 ≥ c_δδ，仅篡改功率与多测点梯度矛盾。故错误洗白率 ≤ δ_p·ρ+ε_bal，单通道伪造可被捕获。

**定理 18（严格包含 FLUID/R68）** A99–A102 下 THERMO 任意状态期望风险 ≤ FLUID ≤ R68；热观测不可信/资源充裕/未认证时逐指令相同（旁路）。安全不让步，效率获「热余量 resolution bonus + 路线优化」。

**定理 19（承诺稳定无 Zeno）** Δ_h>0、τ_dwell>0、仅认证点切换 ⇒ 有限时间有限次切换，平均切换率 ≤ 1/(τ_dwell+τ_switch)；控制连续、无抖动，切换代价入预算且不破坏热可行。

**定理 20（热-认知闭环稳定）** `g_TEFS<1` 且降级能在 τ_safe 内把 q_comp+q_int 压到 q_diss 以下 ⇒ 不确定性与温度 Lyapunov 有界；`g_TEFS≥1` 且无法降级时存在发散参数。故强制热降级是**稳定性必要条件**，非过度保守。

## 7. 本轮最大风险

**一句话**：R70 最危险的不是热失控，而是**「解释得太好」**——一旦系统学会用温度解释标定漂移，任何真实故障（或攻击）只要披上「热漂移」的外衣，就会被 TAD 温柔降级、被 TCL 前馈扣掉、被证书盖上「良性」的章；**热解释成了洗白通道，系统在物理上越来越热、在认知上越来越自信地错下去**——比 R69 的「问错」更隐蔽，因为它伪装成了「理解」。

**次级风险与缓解**：热模型/观测器失配（区间包络 + 保守峰值 + E313/E315）；热-认知正反馈失控（g_TEFS 门 + 强制热降级 + 定理 20）；热传感欺骗与热逼迫（反洗白能量审计 + 多通道一致 + ℰ_thermo 对抗训练）；契约被协商绕过（TBR 频率/总量双限 + 单调安全）；三时钟实时性（规划非阻塞 + 事件触发 + E304）。
