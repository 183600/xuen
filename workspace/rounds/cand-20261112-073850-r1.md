# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化证据承诺」IP-133~138；新一轮灵感循环第 1 轮；本轮灵感：「轻量化设计」×「联邦学习」）

> 第 57 轮把承诺前提升级为“少样本可校准、跨模态可对账、个性化有界”，但它仍暗含两个未言明的部署前提：**(i)** 元推断 q_φ、共形带、跨模态对账与 VOI 都能在控制回路里以可忽略的算力/能量实时跑完；**(ii)** 元语料与云端更新可以集中汇聚、集中审计。轻量化设计首先击穿 (i)：量化、剪枝、蒸馏、早退最先伤害的恰是尾部校准与 OOD 边界——平均 ECE 好看，安全切片已经失守；联邦学习击穿 (ii)：数据不出场、客户端非独立同分布、消息可被投毒、隐私保护又恰好遮蔽了安全审计所需的信息。最危险的组合是“把整个安全栈一起压缩 + 把元模型一起联邦平均”：压缩借走了尾部裕度，联邦把不同世界平均成一个自信的共识。本轮的关键转向是**非对称**：**压缩只允许作用于提议器（proposer），永不允许作用于裁决器（verifier）；联邦只允许承载“单向可迁移证据”（错了也只会更保守），永不承载“这里安全”的正证据**。于是轻量化与联邦化的失效被赶进**可用性界**，而不是**安全界**。核心命题由“证据说可信”升级为 **“提议可压缩、联邦只增保守、裁决不可压缩的证据说可信”**。

核心矛盾：
- **H29（压缩 vs 校准）**：校准误差在状态空间里不均匀；量化/剪枝/早退最先破坏的是决策阈值附近与 OOD 边界的尾部。平均 ECE 是“平均人的体温”，安全需要的是“重症病房的体温”。压缩若花的是校准裕度尚可，花到安全裕度就是向尾部借高利贷。
- **H30（联邦 vs 非IID/投毒/隐私）**：联邦的前提是某种可交换性与共识，但机器人活在不同的物理世界；平均出的“共识先验”可能是“一群互不相容的世界的委员会”。拜占庭客户端可操纵均值，隐私保护（安全聚合/DP）又让审计看不见单项贡献——**安全需要可审计，隐私要求不可见**，这是结构性冲突。
- **H31（轻量 vs 证据纵深）**：第 57 轮的安全来自纵深（元推断∧OOD∧共形∧跨模态∧人），每一层都要吃时延/能量。实时控制天然有“删层”压力；若均匀压缩，最先被删的往往是最不该删的裁决层。轻量化必须是**结构性的**（保留不可压缩内核、压缩外围提议），不能是**均匀的**。

## 0. 直觉与动机

**灵感 1（轻量化设计 → 非对称压缩：提议可错，裁决不可错）**
直觉：足式机器人身上，算力与电池本身就是“负载”；轻量化不是把所有模块等比例缩小，而是识别**哪个模块错了只会变慢、哪个模块错了会变危险**。提议器（元推断、探针排序、VOI、解释渲染、地图分辨率）错了，最坏结果是漏掉一次探针或排序变差——裁决器看到证据不足，拒绝承诺、降档或安全停，损失的是**可用性**。裁决器（证书检查、共形覆盖核验、不可逆接触硬禁令、资源预留检查）错了，才会把“不安全”判成“安全”——它必须是**不可压缩内核**：小、确定性、可形式化、独立进程、固定预算、版本哈希钉死。一句话：**压缩提议器换速度，保留裁决器换安全；宁可慢，不可错。**

**灵感 2（联邦学习 → 单向可迁移证据：负证据出门，正证据留家）**
直觉：联邦学习最诱人的是“别人踩过的坑我也能学到”。但“某地安全”是强上下文相关的正证据，跨体迁移会把别人的安全当成自己的安全；“某地出过事/某类残差高/某材质是 OOD”是负证据，即使迁移错了，最坏也只是让接收方**更保守**——多探一次、绕一段、降一档。于是定义一个只允许单向作用的证据类 **OTE（One-sided Transferable Evidence）**：负事件、OOD 原型、残差高分位、校准证书可以联邦；正安全结论、放行判定、降低阈值的更新一律不许出门。联邦从此**只学“哪里别去”，不学“哪里能去”**。拜占庭投毒的最好结果不是“骗过安全”，而是“让舰队变得过度谨慎”——攻击从安全性问题降级为可用性问题。

**灵感 3（联邦共形 → 本地校准优先，联邦只给先验且只能加宽）**
直觉：共形预测的覆盖保证依赖可交换性；跨机器人、跨工地恰恰破坏可交换性。把各站点的残差分位数直接平均，会得到一个“谁都不覆盖”的全局分位数。正确做法是**本地校准为主、联邦分位数只作先验且只许加宽**：按地形/材质簇分享 DP 分位数草图；客户端聚类未知或本地校准样本不足时，取所有簇分位数的最大值（最保守）；覆盖目标按 \(1-\alpha-\Delta_{het}\) 记账。联邦可以帮你**更快找到该宽到哪里**，但不能替你**把区间收窄**——收窄必须由本地数据自己挣。

**灵感 4（联邦聚合 → 谨慎格上的单调 meet：只能更保守）**
直觉：普通联邦平均是“把参数平均”；安全系统需要的是“把谨慎取并”。定义谨慎偏序 \(\sqsupseteq\) 与 meet \(\sqcap\)：聚合算子 \(A\) 合法当且仅当对任意本地状态与任意消息（含恶意消息）都有 \(A(S,\{m_i\})\sqsupseteq S\)。实现上分两条单行道：**快车道 Widen** 直接施加 OTE（只加宽、只提高探针需求）；**慢车道 Relax** 不是联邦操作，而是本地操作——必须通过本地影子验证（ECE 不劣化、OOD 召回不下降、假承诺率不上升）、有界影响、独立簇超多数、限速，才允许放松。于是“联邦投毒只伤可用性、不伤安全性”从口号变成算子性质；代价是必须有**本地回退（local-only）**与**可用性 SLO**，否则舰队会被过度谨慎拖死。

**灵感 5（轻量化×联邦×证据资源 → 统一的“每焦耳证据”）**
直觉：第 57 轮的预算是“探针数”；真实部署里探针、算力、能量、带宽是同一个预算池的四种货币。把 VOI 从“每次探针的期望信息增益”推广为“**每单位资源的失效概率下降**”：全量提议、早退提议、追加探针、联邦同步、绕行、降档、安全停都在同一张动作表里按性价比排序。硬约束是**裁决器预算不可挪用**与**安全停必须在截止期内完成**。轻量化设计在这里获得严格含义：不是“模型越小越好”，而是“把有限资源优先给不可压缩的裁决内核，再给能提高可用性的提议器”。

**灵感 6（三机制合流 → 安全界与可用性界解耦）**
直觉：第 57 轮的安全界里含有 \(\varepsilon_{meta}\)、\(\delta_{ood}\)、\(\delta_{xm}\) 等“新机制误差项”。本轮把结构改成：**裁决器继承第 57 轮原版且不压缩、不联邦**，提议器与联邦只改变“在截止期内能否找到足够证据”。因此安全界**不新增** \(\delta_{comp}\) 与 \(\delta_{fed}\)，新增项全部落到可用性界。这不是说新机制没有风险，而是把风险**换了账户**：从“可能撞人”换成“可能走不动”。本轮所有设计都围绕守住这条账户边界。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（非对称证据栈 PVS, Proposer-Verifier Split）** 证据栈 \(S=(P,V)\)：提议器 \(P:({\cal M},r,o,\rho)\mapsto(\text{候选探针},\text{VOI},\text{解释草稿})\)；裁决器 \(V:(\text{证书},\text{证据集},\text{接触级别})\mapsto\{\text{ok},\text{reject}(\text{reason})\}\)。压缩算子 \(C\) 只作用于 \(P\)：\(S_C=(C(P),V)\)，且 \(V\) 运行在**预留预算** \(B_V\) 上、使用钉死哈希的确定性/可形式化实现。**轻量化契约**：\(\forall\) 输入，\(S_C\) 允许的承诺集 \(\subseteq S\) 允许的承诺集；\(P\) 无写证书权限；\(V\) 超时/预算尽 \(\Rightarrow\) 安全停。压缩许可证 \(L_C=(\Delta ECE^P,\Delta OOD^P,\text{proposer miss rate},L,E,S)\) 只用于效率与回退调度，**不进入安全界**。

**定义 140（单向可迁移证据 OTE 与联邦残差账本 FRL）** 客户端消息 \(m_i=(\text{负事件描述子 }z,\text{OOD 原型},\text{残差高分位草图},\text{本地校准证书},\text{模型版本},\text{签名})\)。消息合法当且仅当存在**加宽算子** \(W_m\)，使接收方 \((b,p_{fail})\mapsto(b',p'_{fail})\) 满足 \(b'\sqsupseteq b\) 且 \(p'_{fail}\ge p_{fail}\)，且 \(m_i\) **不得**向不可逆接触必要证据集添加任何证据。正安全结论、放行判定、降低阈值的更新一律拒收。传输用安全聚合 + 本地 DP + 范围证明（描述子裁剪、计数有界、范数有界），账本只记 Merkle 根与版本承诺。**EV-fleet\(_{neg}\) 不是证据类**，只触发加宽或探针优先级。

**定义 141（联邦共形校准 FCC）** 本地残差集 \(R_i\)，地形/材质簇 \(c\)。各客户端上传按簇的 DP 分位数草图 \(q_i(\tau)\)。客户端校准规则：
\[
q_i^\star=\max\Big(q^{local}_i(\alpha),\ \max_{c'\in{\cal C}(z_i)} q^{global}_{c'}(\alpha-\Delta_{het})\Big),
\]
其中 \({\cal C}(z_i)\) 在簇可识别时取单簇，不可识别时取全部簇（最大宽度）。覆盖记账 \(\ge 1-\alpha-\Delta_{het}\)，\(\Delta_{het}\) 量化簇错分/不可交换性；本地样本 \(<n_{\min}\) 时取全局最大宽度。**联邦只能初始化或加宽，永不在本地数据之外收窄区间。**

**定义 142（单调保守聚合 MCA）** 谨慎格 \(({\cal S},\sqsupseteq)\)，meet \(\sqcap\)。聚合 \(A\) 合法 \(\iff \forall S,\{m_i\}:A(S,\{m_i\})\sqsupseteq S\)。实现：快车道 \(A_{widen}=\sqcap_j W_{m_j}\) 直接施加；慢车道 Relax 为**本地算子**，需同时满足：①本地影子验证通过（ECE 不劣化 ∧ OOD 召回不降 ∧ 假承诺率不升）；②有界影响 \(\|\Delta\|\le b_{agg}\)、单客户端权重 \(\le w_{\max}\)；③独立簇超多数；④限速 \(\le\Delta_{relax}/T\)。拜占庭客户端只能制造过度谨慎或触发 local-only，不能降低谨慎度。安全性依赖诚实多数与身份/簇多样性；否则降级本地模式。

**定义 143（轻量联邦证据门 LFE 与证书 \(J_l\)）** 证据类：EV-probe\*（裁决器签发；提议器可压缩）/EV-visit/EV-margin/EV-xmodal（限 L1）/EV-human/EV-fleet\(_{neg}\)（非证据类，仅加宽与探针优先级）。不可逆接触必要证据集仍为 \(\{\text{EV-probe}^\*\vee\text{EV-margin}\}\cup\text{佐证}\)，**不含 EV-xmodal，也不含 EV-fleet**。证书
\[
J_l=(J_p,\ L_C,\ P/V\ \text{版本与哈希},\ \text{fed\_ledger\_root},\ \text{ote\_log},\ \text{local\_cal\_cert},\ \text{agg\_proof},\ \text{resource\_log},\ \text{liveness\_state}).
\]

**定义 144（证据-资源协同控制器 ERC）** 资源向量 \(r=(T,E,C,B)\)（时延/能量/算力/带宽）。每检查点动作集 \(\Pi=\{\text{全量 }P,\text{早退 }P,\text{追加探针},\text{联邦同步},\text{绕行},\text{降档},\text{安全停}\}\)。硬约束：控制截止 \(T_{cp}\)、裁决预留 \(B_V\) 不可挪用、安全停须在 \(T_{stop}\) 内完成。目标：
\[
\pi^\star=\arg\max_{\pi\in\Pi}\ \frac{\Delta \mathbb E[p_{fail}\downarrow]}{\text{resource}(\pi)}\quad\text{s.t.}\quad \text{feasible}(\pi;T_{cp},B_V),
\]
并带谨慎下限。截止到达时返回**已认证的最保守动作**；\(B_V\) 耗尽则安全停；联邦同步仅在“OOD 相关性 × 每字节期望加宽量”超过 \(\theta_{fed}\) 时触发。

## 2. 关键算法伪代码（完整版见产物区）

```python
def build_stack(full, budget):
    P = compress(full.P, budget)              # 只压提议器：元推断/VOI/渲染/地图分辨率
    V = full.V                                # 裁决器不压缩、不联邦、哈希钉死
    return Stack(P=P, V=V, license=certify(P), B_V=budget.reserve(V))

def ote_update(S, msgs):
    ote = [m for m in msgs if not m.claims_positive_safety and m.range_proof_ok()]
    W = robust_meet(ote)                      # 谨慎格上的 meet：只加宽
    S.b, S.p_fail = W(S.b, S.p_fail)
    S.ood = merge(S.ood, W.ood)
    if S.liveness < L_MIN: S.mode = 'local_only'
    return S
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| PVS | \(O(d_\phi^{\downarrow})+O(|\sigma|)\) | 压缩提议器 + 常驻裁决器 | 裁决器不压缩、预算预留、超时安全停 |
| OTE/FRL | \(O(N\log N)\) 鲁棒 meet | \(O(N\cdot d_{sketch})\) | 加宽算子单行道、范围证明、Merkle 承诺 |
| FCC | \(O(N_{cal}+|{\cal C}|B)\) | \(O(|{\cal C}|B)\) | 本地优先、未知簇取最大宽度、覆盖记账 |
| MCA | \(O(N)\) 聚合 + \(O(|V|)\) 加宽 | \(O(|V|)\) | \(\sqsupseteq\) 单调、Relax 仅本地、有界限速 |
| LFE | \(O(|\sigma|)\) | \(O(|\sigma|)\) | EV-fleet 非证据类、不可逆集不变 |
| ERC | \(O(|\Pi|C_{VOI})\) | \(O(|V|)\) | \(B_V\) 不可挪用、截止返回保守动作 |

**正确性定理（LCFS 概要）**：在 A37–A40 上加 **(A41)** 裁决器完整性与预算预留（不压缩、不联邦、哈希钉死、超时安全停）；**(A42)** OTE 符号约束（只经加宽算子、正证据不出门、范围证明）；**(A43)** FCC 簇条件可交换与覆盖记账；**(A44)** MCA 单调性与 Relax 本地验证/有界/限速；**(A45)** ERC 硬截止与预留预算。则：
1. **安全界继承**：\({\cal F}_{C,OTE}\subseteq{\cal F}_{57}\)，故 \(P_{unsafe}\le P_{unsafe}^{57}\)——压缩与联邦**不新增安全误差项**，只新增可用性损失项；
2. **可用性界**：\(P(\text{任务按期完成})\ge 1-f(\text{proposer miss},\text{OTE 误报},\beta,\text{带宽})\)，local-only 回退给出第 57 轮可用性减资源开销的下界；
3. **单调性**：快车道只加谨慎，慢车道放松必须本地挣得，拜占庭投毒只伤可用性；
4. **终止性**：PCE++ 在 \(k_{probes}+k_{cons}+k_{fed}\) 与资源预算内终止于 {承诺, 绕行, 降档, L2 协商, 安全停}。

## 6. 本轮最大风险

**一句话**：本轮把安全性全部押在“提议器可错、裁决器不可错”这条非对称边界上——若裁决器本身被性能压力悄悄轻量化、被联邦更新或版本漂移污染，或 OTE 的符号约束在工程实现中被绕过，那么“轻量化只伤速度、联邦投毒只伤可用性”的定理就是纸面保证，系统会退化到甚至劣于第 57 轮；因此裁决器必须是一个**不压缩、不联邦、预算预留、哈希钉死、独立验证的不可压缩内核**，而不是又一层可被优化的模型。

### IP-140 OTE/FRL（单向可迁移证据与联邦残差账本）

```python
def make_ote_message(client, local_log):
    return Msg(
        neg=local_log.hard_negatives(descriptor='coarse'),      # 失败/近失/高残差
        ood=local_log.ood_prototypes(clip=eps_z),               # 裁剪后的 OOD 原型
        q=local_log.residual_upper_quantiles(),                 # 高分位，不上传原始序列
        cal=local_log.local_cal_cert(),                         # 本地校准证书

def ote_filter(msg):
    if msg.claims_positive_safety:                 return None   # 正证据不出门
    if not msg.range_proof_ok():                   return None   # 有界性证明
    if not within_clip(msg.descriptor, msg.count): return None
    return Widen(neg=msg.neg, ood=msg.ood, q=msg.q, w=trust_weight(msg.client))

def federated_update(S, inbox, ledger):
    ote = [w for m in inbox if (w := ote_filter(m)) is not None]
    W = robust_meet(ote, method='trimmed_median')               # 谨慎格 meet
    S.b, S.p_fail = W.widen(S.b, S.p_fail)                      # 只加宽/只升风险下界
    S.ood = merge_protos(S.ood, W.ood)
    ledger.append(root=merkle_root([m.sig for m in inbox]),
                   ote_digest=digest(ote), version=S.ver)
    if S.liveness.estimate() < L_MIN:
        S.mode = 'local_only'                                   # 防“联邦冻死”
    return S
```

**原则**：**负证据出门，正证据留家**。联邦学到的是“哪里别去/哪里要更小心”，而不是“哪里能去”。因此即使消息恶意或来自不同世界，接收方最坏也只是更保守。

### IP-141 FCC（联邦共形校准：本地优先、联邦只加宽）

```python
def federated_conformal(local_res, z, sketch_db, alpha, delta_het, n_min):
    c = sketch_db.cluster_of(z) or 'unknown'
    clusters = [c] if c != 'unknown' else sketch_db.all_clusters()
    q_global = max(sketch_db.quantile(c2, 1 - alpha + delta_het)
                   for c2 in clusters)
    if len(local_res) < n_min:
        return max(q_global, local_quantile(local_res, 1 - alpha))  # 样本少→取宽
    q_local = local_quantile(local_res, 1 - alpha)
    return max(q_local, q_global)                                   # 联邦不越权收窄

def coverage_accounting(q_star, local_res, alpha, delta_het):
    emp = empirical_coverage(q_star, local_res)
    return emp >= 1 - alpha - delta_het, emp
```

**要点**：共形覆盖依赖可交换性；跨站点/跨地形不满足时，用簇条件可交换 + 最大宽度回退记账。联邦分位数是**先验与上界**，不是本地覆盖的替代品。

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PVS | \(O(d_\phi^{\downarrow})+O(|\sigma|)\) | 压缩提议器 + 常驻裁决器 | 裁决器不压缩、预算预留、超时安全停（A41） |
| OTE/FRL | \(O(N\log N)\) 鲁棒 meet | \(O(N\cdot d_{sketch})\) | 加宽算子单行道、范围证明、Merkle 承诺（A42） |
| FCC | \(O(N_{cal}+|{\cal C}|B)\) | \(O(|{\cal C}|B)\) | 本地优先、未知簇最大宽度、覆盖记账（A43） |
| MCA | \(O(N)\) 聚合 + \(O(|V|)\) 加宽 | \(O(|V|)\) | \(\sqsupseteq\) 单调、Relax 仅本地（A44） |
| LFE | \(O(|\sigma|)\) | \(O(|\sigma|)\) | EV-fleet 非证据类、不可逆集不变 |
| ERC | \(O(|\Pi|C_{VOI})\) | \(O(|V|)\) | \(B_V\) 不可挪用、截止返回保守动作（A45） |
| PCE++ | \(O(|CP|(k_p+k_c+k_f)(C_{VOI}+d_\phi^{\downarrow})+|CP|A^*)\) | \(O(|V|+|\sigma|)\) | 三类预算终止、四态完备 |

**正确性定理（LCFS, Lightweight-Conservative-Federated Soundness）**

假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；新增：

- **(A41) 裁决器完整性**：\(V\) 不压缩、不接收联邦参数、版本哈希钉死；运行在预留预算 \(B_V\) 上；超时或预算耗尽必触发安全停；\(P\) 无签发证书权限。
- **(A42) OTE 符号约束**：所有联邦消息只能经加宽算子 \(W_m\) 进入本地状态；正安全结论/放行判定/降阈更新被拒收；消息带范围证明与有界范数。
- **(A43) FCC 异质性记账**：簇内条件可交换，簇错分/不可交换的覆盖损耗由 \(\Delta_{het}\) 上界；未知簇取全簇最大宽度。
- **(A44) MCA 单调性**：快车道满足 \(\forall S:A_{widen}(S)\sqsupseteq S\)；Relax 仅本地、仅恢复第 57 轮全量模型已认证的动作、通过影子验证、有界影响、独立簇超多数、限速。
- **(A45) ERC 资源硬约束**：控制截止 \(T_{cp}\)、裁决预留 \(B_V\)、安全停截止 \(T_{stop}\) 均被调度器硬性检查；anytime 只返回已认证动作。

则：

1. **安全界继承（核心）**：令 \({\cal F}_{57}\) 为第 57 轮裁决器允许的承诺集。对任意压缩 \(C\)，承诺仍由未压缩的 \(V_{57}\) 检查，故 \({\cal F}_{C}\subseteq{\cal F}_{57}\)；对任意 OTE 消息 \(m\)，\(W_m\) 只加宽信念并抬高 \(p_{fail}\) 下界，而 \(V_{57}\) 的接受条件对“更宽/更高风险”单调不增，故 \({\cal F}_{C,OTE}\subseteq{\cal F}_{C}\subseteq{\cal F}_{57}\)；Relax 只在本地验证通过后恢复 \({\cal F}_{57}\) 内已认证的动作，不创造新动作类别。因此
   \[
   P_{unsafe}\le P_{unsafe}^{57}.
   \]
   **压缩与联邦不新增安全误差项**；它们只改变“能否在截止期内找到承诺”。

2. **可用性界**：设提议器漏检率 \(\mu_P\)、OTE 误报率 \(\mu_O\)、拜占庭比例 \(\beta\)、联邦同步预算 \(k_{fed}\)。则
   \[
   P(\text{按期完成})\ge 1-f(\mu_P,\mu_O,\beta,k_{fed},T_{cp},B_V),
   \]
   其中 \(f\) 随 \(\mu_P,\mu_O,\beta\) 单调不增；local-only 回退给出第 57 轮可用性减去本地资源开销的下界。直观：提议器漏一次 → 多探一次或绕行；OTE 误报一次 → 多一次探针；联邦被投毒 → local-only 变慢。**失效被记账到“走不动”，而不是“撞上去”。**

3. **单调性**：快车道只加谨慎；慢车道放松必须本地挣得；拜占庭客户端无法降低谨慎度。形式化地，\(A_{widen}=\sqcap_j W_{m_j}\) 是谨慎格上的 meet，故任意消息序列的作用都不小于原状态。

4. **终止性**：每检查点探针 \(\le k_{probes}\)、共识探针 \(\le k_{cons}\)、联邦同步 \(\le k_{fed}\)；资源约束 \(T_{cp}\) 与 \(B_V\) 为硬截止；PCE++ 必在有限步内终止于 {承诺, 绕行, 降档, L2 协商, 安全停}。

5. **部署界**：
```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1])
            − P(裁决器完整性失效) − P(本地 Relax 审计失效)
```
注意：与第 57 轮相比，**没有**新增 \(\delta_{comp}\) 或 \(\delta_{fed}\) 项；新增的两项完全由 A41/A44 承担。这正是本轮的结构性收益，也是最大的单点风险来源。

**关键推论（安全/可用性分离）**：轻量化与联邦化不是“更安全的机制”，而是“把安全机制做得跑得动、让舰队经验可迁移”的机制。它们的安全性来自**权限隔离**（提议器不能签证书）与**符号约束**（联邦只能加宽），而不是来自压缩算法或聚合算法本身的统计质量。统计质量只决定可用性。

## 4. 实验设计 E177–E181

| 实验 | 指标 | 目标 |
|---|---|---|
| E177 非对称压缩 | 压缩提议器 vs 全量栈的假承诺率/ECE/尾部风险；时延/能量；proposer miss 对任务时间的影响；早退触发率 | 安全指标不劣于第 57 轮（假承诺率 Δ≤0.1pp）；时延 ↓≥50%、能量 ↓≥40%；miss≤5% 时任务仅慢≤10% |
| E178 OTE 联邦与非IID | 跨工地新材质 OOD 召回；负证据可迁移率；每机器人每日字节数；误报导致的额外探针；DP 预算 | OOD 召回 +≥20%；≤8 KB/机器人/日；额外探针 ≤1/检查点；ε_DP≤8/日 |

| E180 联邦共形覆盖 | 各客户端经验覆盖、区间宽度 vs 本地-only/全局-only、簇错分敏感性、未知簇回退宽度 | 每客户端 ≥1−α−2%；宽度增幅 ≤15%；未知簇覆盖不降 |
| E181 舰队端到端 | 5 台四足、4 周工地：成功率/每安全承诺能耗/首访承诺时延/人工干预/停机时长/OTA 版本回滚次数 | 成功率 +5%；能耗 −30%；首访 −20%；干预 −25%；回滚 ≤1 |

**基线**：第 57 轮单机全量栈 + 集中式元语料。**消融**：(a) 全栈压缩（应显示安全退化，验证“非对称”必要性）；(b) 联邦平均正证据（应显示跨站点负迁移，验证“单向”必要性）；(c) 无预留裁决预算（应显示截止压力下的安全退化）；(d) 无 local-only 回退（应显示投毒导致的任务冻死）。

## 7. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 裁决器被偷偷压缩/联邦更新污染 → 分离定理失效 | 高 | 独立进程 + 预留预算 + 版本哈希钉死 + 运行时证明 + 形式化小内核 + 红队 + 启动自检 |
| OTE 符号约束被实现绕过（正证据伪装成负事件） | 高 | 单一 `Widen` API、类型级禁止正证据、性质测试、范围证明、审计回放、双人复核 |
| 过度谨慎导致舰队“冻死”，操作者绕过安全层 | 中高 | local-only 回退、可用性 SLO、Relax 本地验证、带审计的人工降档、任务级超时协商 |
| 非IID 簇错分 → 共形带过宽/覆盖失真 | 中 | 未知簇取最大宽度、簇发现、逐客户端覆盖监控、回退本地 |
| DP 噪声/重复查询泄露或过度加宽 | 中 | 隐私预算记账、裁剪、最小描述子、聚合后发布、限制查询次数 |
| Sybil/诚实多数假设被破 | 中 | 身份与簇多样性、有界影响、超多数、检测到即 local-only、账本审计 |
| 提议器版本漂移/回退失败 | 中低 | 影子验证、版本账本、金丝雀、快速回滚、双版本共存 |
| “安全/可用性分离”被误读为“新机制无风险” | 中 | 在论文/文档中显式声明：分离只在 A41–A45 成立时有效；把裁决器完整性作为一级安全目标 |

## 8. 本轮最大风险

**一句话**：本轮把安全性全部押在“提议器可错、裁决器不可错”这条非对称边界上——若裁决器本身被性能压力悄悄轻量化、被联邦更新或版本漂移污染，或 OTE 的符号约束在工程实现中被绕过，那么“轻量化只伤速度、联邦投毒只伤可用性”的定理就是纸面保证，系统会退化到甚至劣于第 57 轮；因此裁决器必须是一个**不压缩、不联邦、预算预留、哈希钉死、独立验证的不可压缩内核**，而不是又一层可被优化的模型。
