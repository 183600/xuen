# 第 8 轮（灵感循环 R1）· KAM：手眼标定是锚，关节空间是关键帧，记忆检索是恢复

> 检索/复核日期：2026-10-26（UTC）。赛事身份确认不变：用户所指是宇树科技的 **UniBot 世界挑战赛**（unibot.unitree.com），G1 + Dex1、32 项桌面任务、通才单模型赛道、选手自部署 + 官方远程真机 API 评测。按用户本轮定义，这是新「灵感驱动研究循环」的第 1 轮；按状态文件延续，这是总第 8 轮，承接第 7 轮 PILOT-GPR。本轮三个灵感词是「手眼标定」「记忆检索」「关节空间控制」。我先各自钉到本轮核实到的官方事实与 2026 年文献上，再合成主判断：**当前约 30% 的天花板不是语义理解天花板，而是“物理执行/状态跟踪”天花板；三个灵感词恰好对应三个缺失的不变量——度量不变（手眼标定）、时间不变（记忆检索）、运动学不变（关节空间控制）。三者可以统一成一个更锋利的抽象：机器人自己的运动学链，是唯一跨五条泛化轴都稳定的坐标系。** 因此本轮主押注从第 7 轮的“终局放置优先”升级为 **KAM-GPR：以在线手眼标定为锚、以关节空间关键帧为记忆值、以 FK 一致的双空间动作为出口，把“看—记—做”统一到机器人自己的运动学链上。**

## 0. 本轮先核实：六个新事实与一个必须纠正的旧推断

### 0.1 官方手册给出了 10 次/任务的精确泛化设计，且排名是“成功率优先”

本轮第一次拿到参赛手册正文（[S1]）：

- 每个任务执行 **10 次独立运行**；10 次中 **5 种泛化类型各出现 2 次**（位置、干扰物、桌面背景、未见物品、人为干扰）。不是“每轴若干次随机”，而是精确的 2/轴/任务。
- 单次真机执行上限 **180 秒**，超时记失败，并按步骤给过程分。
- 排名规则：**按 32 个任务的总平均成功率排序；成功率相同才看总平均步骤分；仍相同则提交日期早者靠前**。
- 只设通才模型赛道；必须同一模型完成全部 32 任务，不得混合多个模型；模型类型不限（World Model、VLA 均可）。
- 每队可获得 32 任务的全部真机数据（外部数据是否允许，手册该页未展开，标“未核实”）。

这条事实改变了资源算术：**成功率是主排序键，步骤分只是平局键**。第 7 轮把“步骤分大头”当作主收益之一，方向没错，但优先级要降一档；真正的主收益是“把整条 episode 做穿”。同时，320 个计分 trial（32×10）在 p≈0.3 时的标准误约 **2.56pp**，单轴 64 trial 约 **5.7pp**，单任务 10 trial 约 **14.5pp**。这意味着：**榜单上 1–2pp 的差距基本是噪声；只有跨轴、跨任务的大效应（≥8–10pp）才值得押注**。第 7 轮“+3pp 约 80% 概率排名更高”的说法过于乐观，本轮修正。

  2. 各模型对 32 任务的难度排序与榜首的 rank 相关只有 **-0.12–0.27**（DM0 为 -0.12）；如果是真实评测，不同模型应共享相当一部分任务难度结构。

- Collection 仍是 32 个数据集（[S8]）；官方任务页写 32,000 episodes / 169h（[S9]）；HangCup 实测 **1,043 条 / 194,564 帧 / 30fps**，`lastModified = 2026-10-14`（[S10]）。
- `meta/info.json` 的字段比 API 更富：除四路 RGB、14 个臂关节、夹爪、15 维 lower_body 外，还有 **`observation.state.state_torso`（torso 在 base 的 6D 位姿）**、**`observation.state.state_d435`（头部 D435 相机在 base 的 6D 位姿）**、EE 位姿的 base/torso 两套坐标、以及 joint/EE 两套主 action（另有 torso/d435/pivot/lower_body 等辅助 action；[S11]）。
- 但 **API 不暴露 `state_d435` / `state_torso`，也不暴露任何相机内参/外参**（[S12]）。这意味着：训练时我们能拿到头部相机位姿，推理时只能靠“本体感知 + 运动学”重建；腕部相机外参则必须靠离线/在线标定。**这正是“手眼标定”从工程细节变成研究切口的接口根源。**

### 0.5 提交接口的核心约束没有变，但“绝对关节目标”是可用的

- 观测：4 路 RGB（左右高位 + 左右腕部，480×640）、14 个臂关节、左右 EE 位姿（base 系）、夹爪、15 维 lower_body、单字符串语言（[S12]）。
- 动作：`control_space` 二选一，`joint` 返回左右臂 7 维**目标关节位置**；`ee` 返回左右 6D EE 目标位姿；共享 `action.pivot`（7 维）与左右夹爪。动作 chunk 自定（[S12]）。
- 服务：N 台机器人对应 N 个连续端口（8765 起），每端口独立 episode、独立状态；`reset()` 每 episode 一次；token 双处校验（[S12]）。
- 结论：**关节空间不是“内部表示”，而是可以直接下发的动作接口**；这对“关节空间关键帧记忆”和“运动学可行过滤”是结构性利好。API 没有力/触觉，也没有外参，因此“精确接触”只能靠几何、视觉伺服和运动学约束，而不是力矩闭环。

### 0.6 WLA-1.0-Base 仍是可用的单模型底座

- 6B、Apache-2.0、约 2,500 小时真机数据、64 任务、支持 joint/EE 与两种夹爪；提供 LoRA/action expert 微调代码（[S13][S14]）。
- 官方统一动作是 54 维（含 EE 相对位姿、关节、腰、腿、base），状态 60 维；动作 chunk 长度 H 可选；本报告以 30 步（约 1 秒）为起点（[S15]）。挑战赛 API 是它的一个子集；把 14 臂关节 + 夹爪 + pivot 映射过去是可行的。

## 1. 三个灵感词，各自钉到“缺失的不变量”上

### 1.1 手眼标定：缺的是“度量不变”

**事实链**：
- API 不给外参；四路相机里两路腕部相机随关节运动；评测跨多台 G1，安装误差不可避免。
- WARP-VLA 给出量级：腕部视角扰动下，π0.5 只有 **39.2%**，WARP-VLA 恢复到 **78.3%**（[P1]）。这说明腕部外参/视角不是小噪声，是能吞掉一半成功率的变量。
- CamVLA 把“相机系动作 + 6DoF hand-eye 矩阵”分解，用确定性变换合成 base 系动作，做到 calibration-free；但它只做单目单视角，**不处理多相机里的腕部视角扰动**（[P2]）。这是空位。
- G^3VLA 把标定几何注入 VLA 的视觉 token，证明“正确相机几何”有增益，且在轻度标定扰动下稳定（[P3]）；ForeAct3D 把腕部相机位姿锚定到 EE 运动学，用物理一致性约束共享表示（[P4]）；AtlasVLA 在单腕相机下维护持久 world-ego 状态，并显式使用 hand-eye 矩阵 `T_h2e`（[P5]）。
- 传统侧，DRHeC 用 RGB 可微分渲染做无 marker 手眼标定（[P6]）；Continual Hand-Eye 处理开放场景的标定漂移/灾难遗忘（[P7]）。

**本轮的切口**：不是“再做一个离线标定工具”，而是 **推理时的自校准 + 置信度感知**：
1. 离线用数据集的 `state_d435`/`state_torso` 和已知运动学，标定头部相机与腕部相机（腕部用 eye-in-hand AX=XB，或利用腕部视野中的夹爪几何）。
2. 在线用机器人自身的微小运动 + 腕部/头部共视静态点，持续 refine 腕部外参；输出一个带置信度的相机 token。
3. 置信度低时，策略自动降权腕部视图、回退到头部视图 + 名义外参；置信度高时，用腕部做最后 3cm 的精确插入/放置。
4. 训练时对相机 token 做扰动增强，让策略学会“用 token 校正视角”，而不是死记某个安装角度。

这条线比“再训练一个更强的 VLA”便宜得多，而且直接吃 API 的结构性缺口。

### 1.2 记忆检索：缺的是“时间不变”

**事实链**：
- 评测是逐步调用 `get_action`，`reset()` 只在新 episode 调用；模型天然可以维护 episode 内状态。但主流 VLA 是 Markov 的，当前观测一走开就忘。
- 人类干扰轴恰好是“移动物体/撤销已完成步骤”（T27 叠了第二个再拿走、T19 拉上再拉开、T14 拧开再拧回、T10 插上再拔起、T12 中途把锁拿走；[S5][S6]）。这不是长程语义问题，是 **“世界状态被外部改了，模型要发现并恢复”**。
- 记忆侧证据很强：MemBodied 固定大小 episodic memory 在 5 个 RMBench 任务上达到 stateless 的 **7.81×**，LIBERO-Long 90.6%（[P8]）；Dual-Stream Memory 在 RoboMME 49.22% vs 44.51%，真机 62.5% vs 37.5%，但明确指出“杯子被换掉时的身份跟踪仍未解决”（[P9]）；GeoMem-VLA 把 3D 几何监督压进 temporal memory（[P10]）；WholeBodyMem 在 **Unitree G1** 上把真机成功率从 36.7% 提到 88.3%（[P11]）；EventSync 用“完成证据”驱动记忆更新，RoboMME 64.5%（+20pp）（[P12]）；HELM 把 episodic memory + verifier + rollback 串起来，LIBERO-Long 58.4→81.5（[P13]）；KEMO 用关节运动显著性选关键帧，真机双臂任务成功率 +23.6%（[P14]）；SafeLoop 用关节空间 rollback 把危险案例降约 70%（[P15]）。
- 但现有记忆的“值”几乎都是图像 keyframe、文本摘要、或 Cartesian 轨迹；它们要么在背景/视角变化下不稳，要么需要 IK 才能执行。

**本轮的切口**：**关节空间关键帧记忆（Kinematic Keyframe Memory, KKM）**。键是“标定后的物体在 base 的位姿 + 阶段 + 双臂关系”；值是“当时那一帧的关节配置 + 夹爪 + 局部动作 chunk + 结果”。检索出来的不是一张图，而是一组**可直接下发、运动学可行、保留整臂姿态**的关节目标。人在中途把物体挪走时，记忆检测到预测/观测不一致，回滚到最近的关节关键帧并重新查询策略。

这把“记忆检索”从“给策略看历史”变成“给策略一个可执行的恢复点”。

### 1.3 关节空间控制：缺的是“运动学不变”

**事实链**：
- API 的 `joint` 模式直接下发目标关节位置；`ee` 模式下发 6D 位姿。二者互斥。
- GRASP 直接用 joint-space flow policy，绕过部署时 IK；并用可微分 FK 监督 TCP 位姿与双臂相对位姿，证明“关节空间 + 运动学先验”能补上关节误差的物理后果（[P16]）。
- Impedance Cloning 在接触丰富任务上用关节空间 equilibrium point / stiffness，从双边遥操作演示里提取，10 种杯子抓放 84/100，优于固定阻抗 74/100（[P17]）。
- Post-Grasp Kinematic Repair 指出：抓取姿态本身可能让插入路径不可行（奇异/关节限位），需要 post-grasp 重定向；这是“EE 规划看着对、关节执行做不到”的直接证据（[P18]）。
- EmbodiSteer 在推理时把 Cartesian 扩散采样抬到目标机器人关节空间做碰撞引导，碰撞率降 46.1%、成功率 +28.5%（原文以 % 表述；[P19]）。
- 但“Demystifying Action Space Design”用 13,000+ 真机 rollout、500+ 模型给出一个必须正视的 trade-off：**delta 动作稳定优于 absolute；joint-space 在数据/算力充足的标准场景更好，task-space 在跨本体/迁移等泛化场景更好**（[P20]）。挑战赛恰恰是 OOD 泛化场景，所以不能盲目“全关节空间”。

**本轮的切口**：**双空间动作专家（Dual-Space Action Expert, DSAE）**：
- 共享 trunk 同时预测 **EE delta** 与 **joint delta**；
- 用可微分 FK 做一致性损失：joint 预测经 FK 后的 TCP 必须与 EE 预测一致；再加双臂相对位姿损失；
- 推理时默认输出 joint（无 IK、可过滤、可回滚），但保留 EE 头作为“泛化兜底”；若 joint 头在 held-out 上回归，则切回 EE 输出 + 关节空间过滤；
- 用“delta 预测 + 绝对目标下发”同时吃到 delta 的稳定性和 API 的绝对目标格式。

这不是“选关节还是选 EE”，而是**把两者的互补性做成一个可验证的双头结构**。

### 1.4 三者的合成：运动学链是唯一跨五轴稳定的坐标系

把三个切口写成一条失败链：

```text
相机外参/腕部视角漂移
        ↓
物体位姿与记忆键漂移（位置/背景/未见物品轴恶化）
        ↓
检索到的动作/关键帧在当前机器人上不可行（奇异、限位、碰撞）
        ↓
终局放置/插入失败；人被干扰后无法恢复
```

对应的三个不变量：

| 不变量 | 灵感词 | 作用轴 | 失败表现 |
|---|---|---|---|
| 度量不变 | 手眼标定 | 位置、背景、未见物品、多机 | 抓偏、放偏、插不进 |
| 时间不变 | 记忆检索 | 人为干扰、遮挡、长程 | 忘了做到哪、被撤销后重复/放弃 |
| 运动学不变 | 关节空间控制 | 双手协调、接触丰富、所有轴 | IK 失败、奇异、碰撞、关键帧不可执行 |

**统一抽象**：`T_B^E`（EE 在 base 的位姿）和关节角 `q` 是评测里唯一**不随背景、物体外观、人干扰变化**的量。把四路相机、物体记忆、动作都锚到这个运动学链上，就得到一个跨轴稳定的“几何外壳”。这就是 KAM-GPR 的核心。

## 2. 本轮主判断：从“终局放置优先”升级为“物理执行层优先”

### 2.1 为什么不是继续在单个泛化轴上抠点

第 7 轮的“终局放置是跨轴杠杆”在结构上仍成立：32/32 任务的终局步骤是成功闸门，终局步骤合计约 39.8% 的步骤分。但本轮必须补一句：**我们不知道真实失败具体发生在哪一步**，因为榜单是预览/合成。能确定的是，无论失败发生在抓取、插入、放置还是闭合，它们都共享同一个依赖——**当前帧的几何/运动学状态是否可信**。手眼标定、记忆、关节空间控制正好是这个共享依赖的三个面。

### 2.2 为什么这比“再换一个更大的 VLA”更划算

- 8 个不同模型家族在预览榜上挤在 20.5–29.7%，说明共享瓶颈更像接口/物理执行，而不是某个架构的语义能力（弱推断，标“未核实”）。
- 32k 数据、6B 底座、8 周时间，靠“更大模型/更多数据”很难拉开代差；靠“把接口里缺失的几何与状态补上”更可能在跨轴评测里产生 5–10pp 的可见效应。
- 三个模块都可以做成**确定性/轻量**：标定用经典几何，记忆用检索+统计，关节过滤用 QP；唯一的学习模型仍是 WLA/GPR-VLA 一个 checkpoint，符合单模型规则。

### 2.3 可证伪的四个假设

| 编号 | 假设 | 验证 | 失败条件 |
|---|---|---|---|
| H1 | 在线腕部标定误差可降到 <5mm / <1°，并提升插入/放置类任务 | 离线重投影 + 调试槽 T10/T27 | 误差 >5mm/1° 或无增益 → 砍 CAL 在线部分，只留离线 |
| H2 | 关节空间关键帧记忆比图像/Cartesian 记忆更能恢复人为干扰 | 离线扰动回放 + 调试槽 | 恢复率提升 <5pp → 降级为普通 episodic memory |
| H3 | 双空间 joint 输出在 OOD 上不输 EE，且运动学可行性更好 | held-out 32 任务 + 消融 | joint 比 EE 低 >3pp → 改用 EE 输出 + 关节过滤 |
| H4 | 三者组合的增益大于各自之和（标定让记忆键更稳，记忆让关节回滚有目标） | 2×2 消融 | 交互项 ≈0 → 退回单模块 |

### 2.4 本轮修剪

- **撤销**“榜单任务级难度可用来选任务”的用法；只保留“榜首约 30%”的总量级。
- **降级**独立的 ICR（demo 检索）——并入 KKM，不再单列。
- **保留** SSG、PGL/OPT、SVL、NRB、L2L、DebugLoop，但升级其几何/记忆/执行底座。
- **继续砍**：全 32 任务高保真孪生、自由仿真数据、运行时仿真/MPC、仿真 RL、布料/拉链/透明全物理、WMA-0 进主路径、每任务 LoRA。

## 3. KAM-GPR 轮廓（细节在产物区）

```text
语言(160条复述) ──► SSG 评分步骤图 ──► 当前步骤 s、阶段标签 p
        │
        ├─► CAL：头部/腕部手眼标定（离线 + 在线 refine）
        │      └─► 相机 token（位姿 + 内参 + 置信度）
        │
        ├─► KKM：关节空间关键帧记忆
        │      键 = 任务/阶段 + 标定后的物体在 base 的位姿 + 双臂关系 + 夹爪
        │      值 = q(14臂+腰/pivot) + 夹爪 + 局部动作 chunk + 结果
        │      检索 K 条 → 记忆 token + 关节目标先验
        │
        ├─► DSAE：双空间动作专家
        │      EE delta 头 + joint delta 头 + 可微分 FK 一致性 + 双臂相对位姿
        │      推理默认 joint；EE 头作泛化兜底
        │
        └─► SVL：关节空间落点闭环
               伺服 → 缓放 → 稳定/谓词校验 → 关节空间 rollback / 重抓 / 重试
```

一句话：**用运动学链把“看—记—做”锚在同一个 base 系里；标定负责把视觉变可信，记忆负责把历史变可执行，关节空间负责把动作变可行。**

## 4. 风险与合规（先立后破）

- **标定可观测性**：腕部相机可能看不到足够静态特征；用夹爪几何/头部共视/名义外参回退，绝不把标定失败静默成错误动作。
- **记忆身份跟踪**：未见物品/同色物体可能换错；用语言 + 空间连续性 + 物体外观特征三路投票，接受“mem 失败但 policy 仍能重试”的降级。
- **关节空间 OOD**：文献明确 task-space 在泛化场景可能更好；必须做 joint/EE/dual 三路 A/B，不能默认 joint 胜出。
- **榜单合成风险**：不再用任务级榜单调参；用官方 score_steps + 调试槽做真机验证。
- **单模型审计**：CAL 用经典几何、KKM 用检索+统计、SVL 用 QP；推理期不引入 SAM/CLIP 等第二模型。若用学习组件，全部放进唯一 checkpoint 并在模型卡披露。
- **外部数据**：手册该页未明确；L2L 默认 OFF，邮件确认后再开。
- **延迟**：4 路相机 + 6B 模型；用 chunk（30 步≈1s）、图像 resize、检索缓存、共享后端 + N 端口状态隔离。
- **统计噪声**：320 trial、单轴 64、单任务 10；只追 ≥8pp 的效应，优先配对/跨任务聚合。

## 5. 一句话押注

**最值得押注：KAM——以在线手眼标定为锚、以关节空间关键帧为记忆值、以 FK 一致的双空间动作为出口，把“看—记—做”统一到机器人自己的运动学链上；它同时修接口缺外参、评测有人为干扰、关节动作可直接下发这三个结构性缺口，且不依赖更大的模型。**

# KAM-GPR 技术报告：手眼标定是锚，关节空间是关键帧，记忆检索是恢复

> 目标赛事：宇树科技 **UniBot 世界挑战赛**（unibot.unitree.com），G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API 评测。检索/复核日期：**2026-10-26（UTC）**。本报告承接第 7 轮 PILOT-GPR，按用户本轮定义的「灵感循环 R1」重写；三个灵感词是「手眼标定」「记忆检索」「关节空间控制」。本报告的核心不是再换一个更大的 VLA，而是把评测接口里缺失的三个不变量补上：**度量不变（CAL）**、**时间不变（KKM）**、**运动学不变（DSAE）**，并用机器人自己的运动学链把三者统一起来。

## 摘要

当前公开页面的榜首约 **29.7%** 成功率、步骤分 39.0；8 个模型家族挤在 20.5–29.7%。这个量级更像“物理执行/状态跟踪”天花板，而不是“语义理解”天花板。与此同时，官方 API 有三个结构性缺口：

1. **不给相机外参**，而两路腕部相机随关节运动；跨多台 G1 的安装误差会直接改变细粒度几何线索。
2. **不给跨 episode 记忆**，但 32 任务里有大量“先做 A、再做 B、B 依赖 A 的结果”以及官方人为干扰（移动物体、撤销已完成步骤）。
3. **joint / ee 二选一**；joint 可直接下发绝对关节目标，但 OOD 泛化下关节空间可能不如 task-space；ee 则要依赖部署端 IK。

本报告提出 **KAM-GPR = KAM（Kinematic Anchor Memory）+ GPR-VLA（Geometry-Pose Representation）**：

- **CAL（Confidence-Aware Hand-Eye Calibration）**：离线 + 在线、无 marker、多相机的手眼自标定；输出带置信度的相机 token；腕部标定用夹爪几何 + 头部共视，不引入第二个深度模型。
- **KKM（Kinematic Keyframe Memory）**：键 = 任务/阶段 + 标定后的物体在 base 的位姿 + 双臂关系 + 夹爪；值 = **关节空间关键帧 q + 夹爪 + 局部 action chunk + 结果**；支持人为干扰检测与关节空间回滚。
- **DSAE（Dual-Space Action Expert）**：共享 trunk 的 EE delta 头 + joint delta 头；可微分 FK 一致性 + 双臂相对位姿损失；推理默认 joint，EE 头作泛化兜底；用 QP 做限位/奇异/碰撞过滤。
- **SSG / PGL / OPT / SVL / NRB**（沿用第 7 轮命名）：评分步骤图、标定后的 3D 物体位姿、settle/verify/rollback、官方 human 备注剧本；保留第 7 轮的 L2L、DebugLoop、GPR-VLA/WLA。

目标不是承诺一个数字，而是给出可证伪的路径：若 CAL 把腕部标定误差压到 <5mm/<1°，KKM 在人为干扰回放上恢复率 +5pp，DSAE 的 joint 输出不输 EE，则三者组合有机会把总成功率从约 30% 推到 35–40% 区间；若任一门控失败，按预设规则砍掉对应模块，不把工程复杂度当研究收益。

- 位置/背景/未见物品：标定后的度量 3D 让物体位姿不随视角/外观漂移；
- 人为干扰：关节空间关键帧让“被撤销/被移动”有可执行的恢复点；
- 双手/接触丰富：FK 一致的双空间动作让 EE 目标在当前机器人上可行。

## 3. 相关工作：三个缺口与本轮差异

### 3.1 手眼标定 / 相机几何

| 工作 | 关键事实 | 与本轮的关系 |
|---|---|---|
| WARP-VLA [P1] | 腕部视角扰动下 π0.5 39.2% → WARP 78.3%；真机 π0.5 canonical 78% → perturbed 36.7%，WARP 80% → 48.7% | 证明腕部视角是能吞掉一半成功率的变量；但 WARP 是 MoE 视图适配，不输出可解释外参 |
| CamVLA [P2] | 相机系动作 + 6DoF hand-eye 矩阵，确定性变换到 base；calibration-free、单目 | 证明“动作与几何解耦”有效；但不处理多相机腕部扰动，也不做在线置信度 |
| G^3VLA [P3] | 正确 K,T：87.0/97.0；随机 K,T 推理：79.2/90.6；小扰动仅 -0.4/-0.3 | 证明“正确几何”有增益、轻度误差可容忍；但它假设外参已知，且主要改视觉 token |
| ForeAct3D [P4] | 腕部相机位姿锚定 EE 运动学；真实放置/插入/顺序任务 6.7%→37.8% | 与本轮“运动学锚”最接近；但它是未来世界建模，不做在线标定/记忆 |
| AtlasVLA [P5] | 单腕相机 + 持久 world-ego；显式 `T_h2e`；LIBERO-Long +9.4、真机长程 +17.5 | 证明 hand-eye + 持久状态有效；但单腕、无多机标定/置信度 |
| DRHeC [P6] | RGB 可微分渲染、无 marker；UR5e 抓取 88.9%、插入 57.4% | 说明无 marker 标定可行；但离线、算力重，不适合在线 |
| Continual Hand-Eye [P7] | 开放场景标定漂移/灾难遗忘；空间回放 + 双蒸馏 | 说明“标定会漂移”；本轮用轻量在线 refine 而非持续学习 |

### 3.2 记忆 / 长程 / 恢复

| 工作 | 关键事实 | 与本轮的关系 |
|---|---|---|
| MemBodied [P8] | 固定大小 episodic memory；RMBench 7.81× stateless；LIBERO-Long 90.6% | 证明“小记忆”有效；值是学习到的关联状态，不是可执行关节关键帧 |

| VLA-Corrector [P21] | 视觉 latent 偏差检测 + 截断 + 重规划；无需重训 backbone | 与本轮“偏差检测”互补；但它不做几何/记忆 |

**缺口**：现有记忆的“值”几乎都是图像 keyframe、文本、或 Cartesian 轨迹；它们需要 IK/重规划才能执行，且在跨机器人/关节限位下可能不可行。KKM 的差异是：**键用标定后的几何，值用关节空间关键帧 + 局部 chunk**，检索出来就是可下发、可过滤、可回滚的动作先验。

### 4.3 为什么是“运动学链”而不是“世界坐标系”

四路相机、物体外观、背景、人的干扰都在变；但 `T_B^E(q)`（EE 在 base 的位姿）和关节角 `q` 在评测中是**由机器人自身定义**的。只要：

1. 把视觉观测标定到 `T_B^E`；
2. 把记忆的键/值都写成 `T_B^E`/`q` 的函数；
3. 把动作约束在 `q` 的可行域；

就得到一个跨背景、跨外观、跨安装、跨干扰都稳定的“几何外壳”。这就是 KAM 的“锚”。

## 5. CAL：置信度感知的在线手眼标定

### 5.1 离线标定

**头部相机**：数据里有 `state_d435`（头相机在 base 的 6D 位姿）与 `state_torso`。离线直接拟合：

```text
T_B^H = T_B^T(q_w) · T_T^H
```

其中 `T_B^T(q_w)` 由腰部关节 + URDF 得到，`T_T^H` 是固定安装。若 `state_d435` 与 `T_B^T · T_T^H` 的残差在阈值内，则确认“头部相机固定在 torso 上”的假设；否则把 `T_T^H` 放宽为随头部 DOF 变化，但在桌面任务中仍按固定处理（标记为假设，调试槽验证）。

**腕部相机**：eye-in-hand，标定 `T_E^W`（腕相机在 EE 的固定变换）。两种无 marker 方式：

1. **运动法 AX=XB**：用数据里不同 `q` 下的腕部图像做特征匹配，得到相机运动 `B = T_{W_i}^{W_j}`；EE 运动 `A = T_{E_i}^{E_j}`；解 `A X = X B`（Tsai-Lenz / 对偶四元数），RANSAC 去外点。
2. **夹爪几何法**：腕相机能看到夹爪指尖；指尖在 EE 系的 3D 位置由 URDF 已知。用 2D-3D 对应（PnP）直接解 `T_E^W`，不需要额外标定板。这是本轮首选的“无 marker 目标”。

离线输出：`T_E^W` 初值、内参 `K`、重投影误差、每个任务/相机的置信度。若数据集没有内参，用一次标定板/已知图案做一次性标定；API 的 480×640 固定分辨率下，内参可复用。

### 5.2 在线 refine

每个 `get_action`（或每 N 步）：

1. 用当前 `q` 算 `T_B^E(q)`；
2. 在头部与腕部图像里提取静态特征（ORB/光流；不用 SAM/CLIP）；
3. 用头部相机做参考，三角化/深度化得到腕部共视点的 3D 位置；
4. 用 RANSAC + PnP/ICP 解 `T_E^W` 的增量；
5. 用鲁棒卡尔曼/滑动平均更新，输出 `T_E^W` 与置信度；
6. 若内点不足/视差太小/重投影大，保持上一次值并把 `conf` 降到低档。

**置信度定义**（示例）：

```text
conf = min(1, n_inlier / n_min)
     · exp(-e_reproj / σ_e)
     · exp(-cond(J) / κ_0)
     · 1[parallax > p_min]
```

`conf` 三档使用：

- 高：腕部视图权重正常，做最后 3cm 的精确插入/放置；
- 中：腕部权重降半，头部 + 名义外参为主；
- 低：腕部视图几乎不用，只用头部 + EE 运动学；同时触发“慢速/重观察”剧本。

### 5.3 相机 token 与训练增强

每相机 token（内参与模型输入分辨率一致；若 resize，则同步缩放 `f/cx/cy`）：

```text
c = [t(3), r6d(6), f(1), cx(1), cy(1), conf(1)]  # 13 维
```

- 经小 MLP 投影到模型维度，作为该相机视觉 token 的加性/拼接条件；
- 训练时对 `t/r6d/K/conf` 做扰动：平移 ±1cm、旋转 ±2°、焦距 ±2%、主点 ±2px、conf 随机 dropout；
- 让策略学会“用 token 校正视角”，而不是死记某个安装角度；
- 头部相机 token 可由 `state_torso` + 腰部 FK 估计；若 API 不暴露 torso，用 lower_body 的腰关节 + 固定头安装近似。

### 5.4 与单模型规则的关系

CAL 是**经典几何 + 鲁棒估计**，不是第二个神经网络；不引入 SAM/GroundingDINO/CLIP。若使用可学习的特征提取器，必须放在同一个 checkpoint 内，并在模型卡披露。这样既符合“单模型”，又避免外部模型的延迟/合规风险。

## 6. KKM：关节空间关键帧记忆

### 6.1 键与值

**键**：

```text
k = [task_id, step_id, phase,
     vec(P)  (M×9, 物体在 base 的 xyz + r6d，带 mask),
     vec(R)  (9, 双臂相对位姿),
     g       (2, 夹爪)]
```

- `task_id/step_id/phase` 来自 SSG，是硬过滤；
- `P` 来自 PGL/OPT 的标定后 3D 位姿；缺失物体用 mask + 惩罚；
- `R = T_L^{-1} T_R` 是双臂相对位姿，对双手任务关键；
- `g` 是夹爪开合。

**值**：

```text
v = [q (14, 绝对关节目标), pivot (7), g (2),
     a_{1:H} (H×16, 局部 joint chunk),
     y (1, 该关键帧之后是否成功/推进),
     t (1), conf (1)]
```

存储的是**可下发的关节配置 + 局部动作**，不是图像。检索出来可以直接作为 `q_prior`/动作先验；即使策略不用，也可以用于回滚。

### 6.2 检索距离

```text
d(k,k') = ∞ · 1[task≠task'] + ∞ · 1[step≠step']
        + w_p · 1[phase≠phase']
        + Σ_m w_o · ||p_m - p'_m||²_{Σ_m^{-1}}
        + w_r · d_R(R, R')
        + w_q · ||q - q'||²_{Σ_q^{-1}}
        + w_g · ||g - g'||²
```

- 物体项用马氏距离，按物体尺寸/深度噪声设 `Σ_m`；
- 双臂项用 SO(3) 测地距离；
- `q` 是查询时的当前关节，不写入存储键；它只用于候选重排，避免跨构型误配；
- 关节项只在同一机器人构型下用；跨任务不混；
- 返回 top-K=4，按阶段/时间去重；`q_prior = Σ softmax(-d_i/τ) q_i`。

### 6.3 写入策略

在以下时刻写入：

- SSG 的 step 谓词从 0→1（完成一个评分步骤）；
- 物体位姿变化 >2cm 或姿态变化 >10°；
- 每 C=20 步的检查点；
- 检测到人为干扰/失败时，写入“恢复前”的关键帧（用于学习）。

上限：每 episode 20–30 个关键帧；全量 32k episodes × 12 ≈ 384k；HNSW 索引 ≈1GB；检索 <5ms。

### 6.4 人为干扰检测与关节空间回滚

**检测**：

```text
Δp = ||p_obs - p_pred||
ΔR = d_R(R_obs, R_pred)
disturbed = (Δp > τ_p) or (ΔR > τ_R) or (V(s_t)=1 and V(s_{t+1})=0)
```

`p_pred` 是上一次动作对物体的预测（可用简单的 constant-velocity/几何模型；也可用模型内的未来 token）。`V` 是 SSG 的步骤谓词。

**恢复**：

1. 标记当前记忆为 invalid；
2. 在 KKM 里检索“同一 task/step、干扰前最近、conf 高”的关键帧；
3. 关节空间回滚到该关键帧的 `q`（只回滚到安全域内，见 6.5）；
4. 重新观测；若谓词仍为 0，重新查询策略（带“物体被移动”的记忆 token）；
5. 若连续两次恢复失败，进入 SVL 的慢速重试/放弃。

官方 human 备注给了现成剧本（第 7 轮抓取）：T27 叠第二个后再拿走、T19 拉上再拉开、T14 拧开再拧回、T10 插上再拔起、T12 中途把锁拿走。这些正好是 KKM 的训练/评测靶子。

### 6.5 回滚的可行域

```text
q_rb = argmin_{q ∈ Q_safe} ||q - q_ckpt||²
Q_safe = {q : q_min ≤ q ≤ q_max,
              |q - q_prev| ≤ Δq_max,
              m(q) ≥ m_min,
              d(q) ≥ d_min}
```

- `m(q)` 是可操作性（Yoshikawa）；
- `d(q)` 是胶囊/盒子碰撞距离（小臂 vs 桌面/物体/自身）；
- 用序列二次规划（SQP）/局部线性化 QP 解（`m(q)`、`d(q)` 是非线性约束，不能直接当线性 QP）；工程上也可用采样 + 投影。若不可行，先放松 `m_min/d_min` 10–20%，再不行则改为“保持当前 q + 重观察”，不强行回滚。

回滚不是“倒放视频”，而是**回到一个关节空间安全点，再让策略重新决策**；这避免了 Cartesian 回滚在奇异/限位处的不可行。

### 6.6 记忆与“单模型”审计

- KKM 是检索索引 + 统计先验，不是第二个策略；它不产生独立动作，只提供 `q_prior`/token；
- 索引只从官方 32k 数据构建，不用外部数据；
- 若审计要求“所有学习组件在同一 checkpoint”，把记忆编码器/门控做成 checkpoint 内的小头；索引本身作为数据文件披露。

## 7. DSAE：双空间动作专家

### 7.1 双头结构

共享 trunk（WLA/GPR-VLA 的视觉-语言-动作骨干）之上：

- **EE 头**：预测 `ΔT_t^E ∈ SE(3)`（6D 参数化，定义在 EE 局部系、右乘）+ 夹爪；
- **joint 头**：预测 `Δq_t ∈ R^{14}` + 夹爪；
- 两个头都可用 flow matching / diffusion；共享视觉/语言/记忆 token；
- 训练时同时监督；推理时默认 joint，EE 头作兜底/对照。

### 7.2 delta 预测、绝对执行

挑战赛 API 要绝对目标关节位置；但文献显示 delta 预测更稳（[P20]）。做法：

```text
q_target = q_t + Δq_t
T_target = T_t^E · ΔT_t^E
```

损失作用在 `q_target` / `T_target` 上；网络输出的是 delta。这样既吃到 delta 的优化优势，又满足 API 的绝对目标格式。

### 7.3 损失

**Flow matching**：

```text
L_fm = E_{τ,ε} || v_θ(a_τ, τ, c) - (a_1 - a_0) ||²
```

**FK 一致性**：

```text
L_FK = || FK(q_t + Δq_t) - T_t^E · ΔT_t^E ||²_W
     + λ_R · d_R(R_FK, R_EE)
```

`FK(·)` 用 URDF，可微分；`W` 对平移/旋转分别加权；`d_R` 是 SO(3) 测地距离。

**双臂相对位姿**：

```text
L_rel = || (T_L^{-1} T_R) - (T_L^{ref,-1} T_R^{ref}) ||²
```

`ref` 来自检索到的关键帧或同阶段 demo；对双手任务（T27、T10、T12 等）重要。

**平滑/夹爪**：

```text
L_s = || Δq_t - Δq_{t-1} ||²
L_g = BCE(g_t, g_t^*) 或连续回归
```

总损失：

```text
L = L_fm + λ_1 L_FK + λ_2 L_rel + λ_3 L_s + λ_4 L_g
```

### 7.4 推理时的 QP 过滤

```text
min_q  ||q - q_des||²_W + λ||q - q_pref||²
s.t.   q_min ≤ q ≤ q_max
       |q - q_prev| ≤ Δq_max
       m(q) ≥ m_min
       d(q) ≥ d_min
```

- `q_des = q_t + Δq_t`；
- `q_pref` 来自 KKM 的 `q_prior` 或上一个关键帧；
- `m(q)` 可操作性；`d(q)` 碰撞距离；
- 14 维 SQP/局部线性化 QP，单次 <1ms 量级；每个 chunk 起点解一次，chunk 内插值；
- 不可行时按 6.5 的顺序放松；仍不可行则用 EE 头 + IK（以 `q_prev` 为种子），再过滤；IK 失败则保持当前 q + 重观察。

### 7.5 部署选择：joint 还是 ee

`control_space` 是提交元数据，不能每步切换。策略：

1. 用同一 checkpoint 导出两套服务：joint 服务、EE 服务；
2. 离线 held-out + 调试槽做 A/B；
3. 只提交表现更好的那套；
4. 若 joint 在 OOD 上低 >3pp，提交 EE 服务，但保留 joint 头的 QP 过滤作为“EE 目标可行性检查”（IK 前先检查关节可行域）。

### 7.6 与“运动学不变”的关系

DSAE 不是“关节空间一定更好”，而是**让两种表示在同一个模型里互相约束**：

- joint 头负责可执行性（限位/奇异/碰撞/回滚）；
- EE 头负责泛化（跨本体/跨视角/任务空间）；
- FK 一致性把两者绑在同一个物理后果上；
- QP 把“预测”变成“可行”。

## 8. SSG / PGL / SVL / NRB 的升级

### 8.1 SSG：评分步骤图

- 32 个任务图；节点 = 官方 score_steps；边 = 先后/依赖；
- 语言：5 条英文复述 → task_id/step；用字符串相似度 + checkpoint 内轻量文本嵌入，不引入外部 VLM；
- 谓词：标定后的物体位姿 + 夹爪 + 关节状态 + 视觉变化；规则优先，学习头只在 checkpoint 内；
- 输出：`s_t, p_t`，以及“当前步骤是否完成”的置信度；
- 用途：KKM 的硬过滤、SVL 的验证、NRB 的剧本触发。

### 8.2 PGL/OPT：标定后的 3D 物体位姿

- 头部双目：若左右高位相机同步，则立体匹配得到度量深度；若不同步，则用模型内单目深度头/几何先验；腕部单目同理；
- 物体 6D 位姿：颜色/深度聚类 + 任务先验 + ICP refine；不引入 SAM/CLIP；
- 若分割不可靠，退化到“EE 位姿 + 阶段 + 夹爪”键；
- 输出给 KKM、DSAE 的 `L_rel`、SVL 的谓词。

### 8.3 SVL：settle / verify / rollback

- 接近目标后进入 **settle**：低速、短行程、夹爪保持；
- **verify**：SSG 谓词 + 物体位姿稳定性 + 关节误差；
- 失败 → **rollback** 到最近关节关键帧 / 重抓 / 重试；
- 最后 3cm 用视觉伺服（腕部高置信度时）或关节误差/夹爪反馈微调；
- 时间预算：settle ≤0.5s，rollback ≤1.5s，避免 180s 超时。

### 8.4 NRB：官方 human 备注剧本

- 每任务 2 条官方 human 备注（`human_1/human_4`；另有位置/未见物品备注），整理成“干扰类型 → 检测信号 → 恢复动作”；
- 训练时 rehearsal：在 demo 的关键帧后注入“撤销/位移”状态，训练 KKM 检测 + SVL 恢复；
- 推理时只做检测/恢复，不做“预测人会怎么做”；
- 与 KKM 的分工：NRB 提供剧本先验，KKM 提供可执行恢复点。

### 8.5 保留的工程模块

- **L2L**：外部实验室数据合作；默认 OFF，邮件确认规则后再开；
- **DebugLoop**：不计分单任务通道；每次 release 只改一个变量；T10（插入）优先，T27（堆叠）次之；
- **GPR-VLA/WLA**：6B 底座 + LoRA/action expert；单 checkpoint；
- **TLE/ACP/GF**：保留为训练/数据检查单，不再作为主创新。

## 9. 数据引擎

### 9.1 数据桶

| 桶 | 来源/方法 | 规模（目标） | 作用轴 | 风险 |
|---|---|---:|---|---|
| Nominal | 官方 32k episodes | 32k | 全部 | 官方数据分布 |
| Position | demo 物体位姿 + 平移/旋转扰动 | 3–5k | 位置 | 扰动过大导致不可能 |
| Distractor | 从其他任务搬入物体 | 3–5k | 干扰物 | 遮挡/碰撞 |
| Background | 桌布颜色/纹理替换 | 3–5k | 背景 | 颜色偏移影响分割 |
| Unseen object | 同类不同颜色/形状/材质 | 2–4k | 未见物品 | 资产有限 |
| Human | 官方 human 备注剧本 + 调试槽真机 | 2–4k | 人为干扰 | 仿真不真实 |
| Calibration | 相机外参/内参扰动 + 置信度 dropout | 4–6k | 标定鲁棒 | 扰动分布要覆盖真机 |
| Recovery | 失败/回滚/重抓片段 | 3–5k | 恢复 | 失败样本少 |

> 说明：人为干扰优先用官方备注 + 调试槽真机回放；仿真只做几何/关节可行性，不做视觉主训练。外部数据默认 OFF。

### 9.2 关键帧提取

- 用关节速度局部极小 + score_steps 边界 + 物体位姿变化选关键帧；
- 每 episode 10–20 个；存 `q, pivot, g, a_{1:H}, y, t, conf`；
- 物体位姿从头部双目/腕部深度 + 颜色聚类估计；无可靠分割时退化键；
- 全量索引：384k–640k keyframes；HNSW；磁盘 ≈1–2GB；
- 训练时对关键帧做时间抖动/动作噪声，避免“背关键帧”。

### 9.3 校准数据

- 用 `state_d435`/`state_torso` 作为离线真值，验证 `T_E^W`/`T_T^H`；
- 对每个 episode 随机抽 10–20 帧做重投影检查；
- 统计每个任务/相机的误差分布；低于阈值的相机才给高置信度 token；
- 调试槽真机采 20–50 帧做 domain check。

| joint 头 OOD | 中 | 成功率下降 | 双头 A/B；EE 兜底；QP 过滤 |
| FK/URDF 与真机偏差 | 中 | 一致性损失误导 | 用真机数据校准；损失权重低；以成功率为准 |
| 单模型审计 | 中 | 取消资格 | CAL/KKM/SVL 确定性；学习组件同一 checkpoint；披露 |
| 外部数据违规 | 低 | 取消资格 | L2L 默认 OFF；邮件确认 |
| 延迟/显存 | 中 | 超时/掉线 | chunk 30；resize；bf16；共享后端；压测 |
| 调试槽不足 | 中 | 无法门控 | 优先 T10；离线回放；一次只改一个变量 |
| 统计噪声 | 高 | 误判 | 320 trial；配对；只追 ≥8pp |
| 人为干扰剧本不匹配 | 中 | 恢复无效 | 通用检测 + 官方备注先验；不硬编码单一剧本 |
| 回滚浪费时间 | 中 | 180s 超时 | 限次数/时限；失败则放弃 |

**合规要点**：

- 同一 checkpoint 完成 32 任务；不混合多个模型；
- 推理期不调用 SAM/GroundingDINO/CLIP 等第二模型；CAL 用经典几何；
- 若使用学习式分割/深度头，放在同一 checkpoint，并在模型卡说明；
- KKM 索引只从官方数据构建；外部数据默认 OFF；
- 不把预览榜数字写进提交材料当“真实排名”。

## 16. 开放问题（按优先级）

1. 榜单到底是真实评测还是预览？`gen_leaderboard.py`/占位视频/线性步骤分三者如何解释？→ 已按预览处理；仍需官方确认。
2. 评测指令是否严格从 5 条英文复述采样？是否混中文？→ 训练覆盖 160 条 + 中文映射。
3. 评测机器人数量 N？每台是否统一标定？`state_d435` 是否在服务端可用于调试？→ 影响 CAL 的 domain gap。
4. 调试槽次数/成本/是否可指定任务？→ 决定 W5/W6 门控。
5. 外部数据/预训练权重（LAION/ ego4D 等）是否允许？→ L2L 默认 OFF。
6. 评测端如何执行 joint 目标？PD 增益/速度限制/是否插值？→ 影响 QP 的 `Δq_max`。
7. `action.pivot` 在桌面任务中是否必须？能否保持常量？→ 本轮默认常量。
8. 官方 human 备注是否就是评测干扰剧本？→ 做通用检测，不硬编码。
9. 步骤分是按 step 谓词还是按人工评分？→ 影响 SSG 的权重。
10. 单模型审计的边界：检索索引/确定性 QP/标定是否算“模型”？→ 提前披露，保守实现。

## 17. 一句话押注

**最值得押注：KAM——以在线手眼标定为锚、以关节空间关键帧为记忆值、以 FK 一致的双空间动作为出口，把“看—记—做”统一到机器人自己的运动学链上；它同时修接口缺外参、评测有人为干扰、关节动作可直接下发这三个结构性缺口，且不依赖更大的模型。**
