# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 2 轮；本轮灵感：「开源软件」×「结构优化」）

> R69 把不确定性做成了有形状、可询问的对象，第一次让系统会「问」。但它默认了两件事：**（P1）我依赖的整套组件出自同一个作者、同一版本、可信且不会变**；**（P2）安全边际应当均匀地加在每一个环节上**。真实部署里两者都不成立：感知、世界模型、流策略、标定、交互模块来自不同上游（开源权重、第三方 SDK、车队共享技能、个人微调 fork），会静默打补丁、会版本漂移、会以「接口一样但权重不同」的替换品混进来；而 R69 每轮都在**均匀地**加 λ，既昂贵，又没有区分「到底是哪个接口吃掉了安全余量」。
>
> 本轮两个灵感正好补上这两块：
> - **开源软件**教给我们的不是「免费」，而是四件工程制度：**内容寻址的来源清单（SBOM/PBOM）、接口契约、可复现构建、分叉/合流与差量审查**。把策略栈变成一个可被第三方重建、审计、替换的供应链，而不是一个不可名状的黑箱。
> - **结构优化**（拓扑优化/桁架）教我们：不要把材料均匀涂在结构上，而要**按载荷路径分布**——哪里应力大就在哪里加筋，哪里不吃力就挖空。把「安全边际」当成材料，把「风险」当成载荷，把「接口」当成节点，安全架构本身就成了一个可优化、可验证的结构。
>
> 核心命题：**把安全论证的对象从「这个系统」升级为「这条可复现的供应链 + 这个受损伤容限约束的结构」；用差量再认证替代全量重训，用载荷感知的逐接口 λ 分配替代 R69 的均匀 λ。但结构优化天然趋向集中，开源供应链天然分散，二者构成对偶——所以必须把 n−1 容限与来源独立容限写成硬约束，否则优化出来的「高效结构」只是把整座桥压在一根被共享的上游腿上。** 命名 **FORGE-RAS**（Forkable Open-source Reproducible Governance-Enforced Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我依赖的这些东西是谁造的、还能不能重建、坏了会不会一起坏**」——安全的边界不再是系统的边界，而是**供应链与载荷路径的边界**。

## 0. 直觉与动机

**灵感 1（开源软件 → 安全论证的最小单位不是系统，而是来源清单）**
直觉：开源生态真正的发明不是「代码免费」，而是让一个陌生人的产物可以被另一个人**独立重建、审查、替换**。SBOM 记录「我装了什么」，内容寻址保证「名字不能骗我」，可复现构建保证「我拿到的东西能再算一遍」，签名与来源保证「出了事能追到哪一次提交」。对具身智能而言，一套策略从来不是单一模型：权重、代码、tokenizer、标定数据、LLM 提示、安全盾牌、交互策略各自有上游。没有来源清单，系统连「昨晚那台机器人为什么变了」都答不出来。**证书的第一性要求因此从「我声称安全」变成「你可以自己重建并复核」**。

**灵感 2（接口契约 → 组合比单体更难，也更需要形式化）**
直觉：开源软件绝大多数事故不在单个库内部，而在**接缝**：ABI 不兼容、版本冲突、单位/坐标系不一致、超时语义不同、许可证冲突。单体模型可以靠端到端训练吞掉这些；模块化策略栈不行。于是每个组件必须交付一份机器可读的**安全契约**：我在什么输入域成立（pre）、我保证什么（post）、我假设了什么（assume）、我已知会怎么坏（fail）。组合时做类型检查：上游的 post 必须蕴含下游的 pre。更重要的是**契约不能是空洞的**——一个「假设一切反例都不在域内」的契约逻辑上永远成立、工程上毫无用处；必须用对抗测试度量其非空洞性。

**灵感 3（分叉/合流与差量审查 → 再认证应当是差量的）**
直觉：开源规模化的关键是「按 diff 审查 + 影响分析 + 回归测试选择」，而不是每次改动都从头审一遍。策略栈更新同理：换掉一个感知权重，不需要重跑整条链路的所有评估，只需要重认证它的**信任锥**（所有下游消费者），并且测试选择必须覆盖所有穿过被改契约路径的用例。再用**安全语义版本**区分「内部实现变化（PATCH）」「新增能力（MINOR）」「安全保证被削弱/假设被放宽/ODD 被扩张（MAJOR）」：只有 PATCH 可以自动合流，MAJOR 必须全量 + 人类复核 + 影子部署。这样车队共享与个人微调（fork）才不会把认证体系拖垮。

**灵感 4（结构优化 → 安全边际是有载荷路径的）**
直觉：R69 把 λ 均匀地乘在动作上，相当于把钢材均匀地糊满整座桥——安全，但浪费，且掩盖了真正的薄弱接口。拓扑优化的做法是：给定外载荷与体积预算，求「哪里放材料」，使结构在最危险节点仍不失效。把不确定性当载荷 q_j、把安全机制（冗余证据通道、标定门、盾牌、回退控制器、交互预算）当候选杆件、把接口当节点，就得到一个**风险约束 + 预算约束下的边际分配问题**；用 SIMP 式连续松弛 + 伴随敏感度求解，再离散化成可验证的有限档。必须警惕拓扑优化的经典病：**checkerboard**（交替的微小余量）在名义评估上通过、实际不可制造/不可验证；以及**优化器把载荷集中到一条最省材料的路径**。

**灵感 5（两个灵感的对偶 → 优化的集中 vs 开源的分散）**
直觉：这是本轮最关键的一击。结构优化为了省预算，天然会把安全能力**集中**到少数高效通道；而开源供应链意味着这些通道所依赖的上游恰好是**最容易被替换、被静默补丁、被投毒**的。更糟的是，表面上的「双冗余」可能共享同一个上游根（同一份开源库、同一个基础模型、同一个标定数据源），于是 n−1 冗余只是同一座客房挂了两块门牌。**冗余的独立性必须由供应链图定义，而不是由结构图定义**。因此本轮把「n−1 成员容限」升级为「n−1 来源根容限」，并把来源多样性作为 STO 的硬约束。

**灵感 6（制度而非概率 → 可复现位与合流门是不可被置信度收买的）**
直觉：R68/R69 的保证最终都落在「模型输出的置信/校准」上；但供应链安全不能靠模型自证。可复现位（repro bit）、哈希锁、合流门、人工 quorum 是**制度性**约束：即使模型 99.9% 自信，只要重建不一致、来源签名缺失、MAJOR 契约被静默合并，证书就直接作废。同理，「多双眼睛」是经验证据而不是定理——Linus 定律不是数学保证，所以审计要把 review 覆盖度与维护者多样性当作**有相关性的证据源**，而不是当作证明。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（FORGE-RAS 总览）** FORGE-RAS = (PBOM, SCD, SCCG, DRC, STO, DTA, FMS, RAS-WM‡)。六不变式：
(i) 继承 R69 的**实时流零学习写操作**（定义 276-i）与交互预算/证据纪律；
(ii) **内容寻址不可变**：进入部署的每个组件由 PBOM 根哈希唯一确定，运行期禁止无记录的原地替换；
(iii) **契约先于组合**：组件仅在安全契约通过组合类型检查后才允许拼装，且契约必须通过非空洞性检验；
(iv) **差量再认证**：组件变更只重认证受影响信任锥，但测试选择必须覆盖所有穿过被改契约依赖路径的用例；
(v) **结构可验证**：任何边际分配结果必须通过离散化与损伤容限检验，连续松弛解不得直接部署；
(vi) **分叉受限合流**：本地 fork 可带 `local_only` 降域运行，但只有通过合流门才能进入上游或群体共享。

**定义 311（PBOM 策略物料清单）** 一个有向无环图，节点 c_i = (h_i, ver_i, K_i, E_i, prov_i, lic_i, usage_i)。h_i = Hash(weights, code, tokenizer, config, calibration-data) 为内容哈希；K_i 为安全契约；E_i 为评估清单；prov_i 为签名与上游 lineage；lic_i/usage_i 为许可证与允许使用域（ODD）。根 r = MerkleRoot(PBOM)。部署栈 = Build(PBOM)，要求**可复现**：两台独立机器/容器从同一 PBOM 构建，产物与评估指标逐位一致，否则 repro_bit = 0。名字（tag）永远不被信任，只有哈希被信任。

**定义 312（安全契约 SCD）** K_i = (pre_i, post_i, assume_i, calib_i, fail_i, cost_i)。pre_i：输入/环境/单位/坐标系/时序域；post_i：可验证保证（认证前缀长度、风险上界、误差条、ECE、作用域）；assume_i：外部假设；fail_i：已知失效模式与检测器；cost_i：计算/延迟/社会成本。**非空洞性** NV(K_i) = 在域内对抗测试上 post 成立的比例；要求 NV ≥ τ_nv，且存在至少一个「放宽 assume 即失败」的可证伪用例。空洞契约 = 未认证。

**定义 313（供应链组合图 SCCG）** 有向图 G = (V, E)。节点为组件与安全机制；边 e_{ij} 携带组合条件 post_j ⊆ pre_i（含单位、坐标系、时序、ODD、许可证兼容）。组合类型检查：对每条边验证蕴含关系；不满足时插入带自身契约的适配器/盾牌，否则拒绝组合。**信任锥** Down(c) = {v : c →* v}。

**定义 314（差量再认证 DRC）** 组件 c(h) 换成 c(h′)。契约差 δK ∈ {refinement（post 强化、assume 收缩）, internal（实现变、契约不变）, widening（post 减弱、assume 放宽、ODD 扩张）}。受影响集 A = Down(c) ∪ contract_consumers(c)。测试选择 S = { t : path(t) ∩ A ≠ ∅ }（路径覆盖准则）。若 δK = refinement 且 S 全过 → 快速路径；若 δK = widening → 全量测试 + DTA + 人类复核；任何与 A 相交的测试都不得被跳过。

**定义 315（安全结构的地面结构）** 候选安全成员 m ∈ M（冗余证据通道、标定门、交互预算、安全盾牌、回退控制器、主动查询）。设计变量 ρ_m ∈ [0,1] 表示该成员的「风险刚度/边际档位」。刚度 K(ρ) = Σ_m ρ_m^p K_m（SIMP，p ≥ 3）。风险载荷 q_j 为接口/ODD 区域 j 的不确定性需求；残差风险「位移」u(ρ) = K(ρ)^{-1} q。**结构优化目标**：
min_ρ Σ_j w_j q_jᵀ u(ρ)_j + α Σ_m c_m ρ_m，
s.t. Σ_m b_m ρ_m ≤ B，R_j(ρ) ≤ R_j^max，0 ≤ ρ ≤ 1。
敏感度用伴随法 ∂/∂ρ_m；加密度过滤 + 投影抑制 checkerboard。

**定义 316（结构风险与逐接口 λ 分配）** R_j(ρ) = ∫ loss_j(u(ρ), o) dP(o) 为接口 j 的期望失效损失。R69 的全局 λ_floor 被改为**负荷感知**：λ_j = λ_floor(U_j / s_j(ρ))，其中 s_j(ρ) ≥ 1 是结构在接口 j 提供的风险刚度（随 ρ 增加）。结构不可行/未通过离散化/来源多样性不足时，回退 λ_j = λ_floor(U_j) 的全局均匀形式（R69 边界）。

**定义 317（损伤容限 DTA）** 设计 ρ 满足**成员级 n−1 容限**：∀m，R_j(ρ \ {m}) ≤ R_j^fail（放宽但有限）。更强，满足**来源根级 n−1 容限**：∀provenance root r，R_j(ρ \ {m : prov_m = r}) ≤ R_j^fail。后者防范共因失效。

**定义 318（来源多样性约束）** 对每个接口 j，承载其风险的活跃成员集合所具有的独立 provenance 根数 ≥ d_min，且这些根由独立签名者/维护者背书。这是把结构优化的「多路径」约束改用**供应链图**而非几何来定义。

**定义 319（分叉—合流语义 FMS）** fork：本地分支 PBOM_b，带 `local_only` 标记，运行域限制为 D_b ⊂ D，禁止自动上推；merge gate 需同时满足：(a) DRC 通过；(b) DTA 与来源多样性通过；(c) 契约 semver——PATCH 可自动，MINOR 需双人复核，MAJOR（假设放宽/post 减弱/ODD 扩张）需人类委员会 + 全量评估 + 影子部署；(d) 上游回归套件全过。**安全契约的 MAJOR 变更不允许静默合并**。

**定义 320（可复现评估构建 PEB）** 评估清单固定数据集哈希、随机种子、框架版本、硬件预算。两次独立构建（不同机器/容器）产出逐位相同的指标才算 repro_bit = 1；repro_bit = 0 时 J_FORGE 直接无效。为反刷榜，额外维护不公开的 held-out 对抗探针集，其哈希进入 PBOM 但不进入上游可见评估。

**定义 321（参与式审计 VQAuditor-S）** 审计对象新增：契约非空洞性、来源签名完整性、DRC 选择是否覆盖完整信任锥、STO 是否把风险推到未测试角落、fork 是否降域上推、合并是否绕过 MAJOR 门。记录 review quorum 与维护者多样性，但明确「多双眼睛」是**证据**而非**证明**——相关性高的评审不能按独立证据计数。

**定义 322（供应链威胁模型 ℰ_FORGE）** 替换攻击（同接口、不同权重）、静默补丁/版本漂移、依赖混淆与抢注、恶意上游、契约漂移（宣称保证与实现不符）、评测过拟合/刷榜、分叉谄媚（fork 为过测而删测试）、共因失效（冗余共享同一上游）。并入对抗集：ℰ_FORGE = ℰ_FLUID × ℰ_supply × ℰ_structural。

**定义 323（证书 J_FORGE）** J_FORGE = (J_FLUID, PBOM_root, repro_bit, contract_composition_proof, nonvacuity_vector, DRC_scope + verdict, DTA_witness, provenance_diversity, STO_design_hash + sensitivity, fork_lineage, forge_ver)。Valid ⇔ J_FLUID 有效 ∧ repro_bit = 1 ∧ 组合类型安全 ∧ NV ≥ τ_nv ∧ DRC 完备 ∧ DTA 通过 ∧ 来源多样性达标 ∧ 预算未越界。

**定义 324（结构性回退与单调性）** 若 STO 不可行、离散化失败、检测出不可验证的 checkerboard、或来源多样性不足，则退回 R69 的均匀 λ 与固定结构；回退时证书降级但安全不降，λ_j 单调不降。结构优化只允许在「可验证且可替换」的流形内买效率。

**定义 325（结构—供应链对偶）** STO 的「材料集中」与 OSS 的「信任分散」构成对偶张力：优化降冗余（集中），供应链要求独立冗余（分散）。定义 317 的强容限与定义 318 的多样性是这对偶的显式约束；它是 R69 对偶通道（定义 309）在结构层的镜像——残差与似然互为第二意见，结构与来源互为第二意见。

**定义 326（时序与增量求解）** STO 在慢时间尺度（离线/小时级）求解；运行期只做 λ_j 查表、DRC 快速路径与哈希锁校验；PBOM 哈希在认证窗口内锁定，合流与上游更新只能在维护窗口进行。保证实时环零求解、零训练写操作。

```python
# IP-265 PBOM 验证 + 可复现构建
def verify_pbom(root):
    seen = {}
    for h in closure(root):                       # 只信内容哈希，不信 tag
        comp = load_by_hash(h)
        if not verify_signature(comp) or not license_ok(comp.lic): return False
        seen[h] = comp
    b1 = reproducible_build(seen)
    b2 = reproducible_build(seen, other_host=True)
    return hash(b1) == hash(b2)                   # repro_bit

# IP-266/267 契约非空洞 + 组合类型检查
def contract_ok(K, suite):
    nv = mean(K.post(x) for x in suite if K.pre(x))
    falsifiable = any(not K.post(x) for x in relax_assume(K, suite))
    return nv >= TAU_NV and falsifiable

def compose_typecheck(G):
    for (i, j) in G.edges:
        if not implies(K[j].post, K[i].pre):       # 单位/坐标系/时序/ODD/许可
            if not insert_certified_adapter(i, j): # 适配器自身也要有契约
                return False
    return True

# IP-268 差量再认证（路径覆盖选择的 RTS）
def differential_recert(old, new, G):
    A = downstream_cone(G, new.id) | contract_consumers(G, new.id)
    d = contract_diff(old.K, new.K)               # refinement / internal / widening
    if d == 'refinement' and run_suite(select(A, G)):
        return 'fast'                             # 强化契约：旧证据仍成立
    if d == 'widening':
        assert run_suite(FULL_SUITE) and dta(G)
        require_human_review()
    return 'full' if run_suite(select(A, G)) else 'reject'

# IP-269 结构拓扑优化（SIMP + 伴随敏感度 + 过滤投影）
def structural_optimize(ground, q, R_max, budget, p=3):
    rho = 0.5 * ones(len(ground))
    for _ in range(N_IT):
        rho = projection(density_filter(rho))
        K   = assemble_K(rho, p)
        u   = solve(K, q)
        g   = adjoint_sensitivity(K, u, q, rho, p) + alpha * cost_grad(rho)
        rho = projected_gradient(rho - eta * g, budget)
    rho_d = discrete_round(rho)                   # 可验证的二值/有限档
    if not dta_check(rho_d) or provenance_diversity(rho_d) < d_min:
        return None                               # 回退 R69 均匀结构
    return rho_d

# IP-270 成员级 + 来源根级损伤容限
def dta_check(rho, G):
    for m in active_members(rho):
        if risk(rho, remove={m}) > R_fail: return False
    for root in provenance_roots(rho, G):         # 防共因失效
        if risk(rho, remove=members_with_root(root)) > R_fail: return False
    return True

# IP-271 合流门（semver + 差量认证 + DTA）
def merge_gate(branch, upstream):
    if branch.local_only: raise Forbidden("local fork cannot auto-merge")
    d = contract_semver(branch.K, upstream.K)
    if d == 'MAJOR' and not (human_committee() and shadow_deploy()): return 'reject'
    if d == 'MINOR' and review_quorum(branch) < 2: return 'reject'
    ok = differential_recert(upstream, branch, G) in ('fast', 'full')
    return 'accept' if ok and dta_check(branch.rho, G) else 'reject'

# IP-276 主闭环：STO 慢环 + R69 快环
def FORGE_RAS_round(M, obs):
    # 认证窗口内哈希锁定，拒绝静默补丁
    assert M.pbom.lock_hash == M.pbom.root and M.pbom.repro_bit == 1
    # ---- R69 快环 ----
    z, o = M.mtm.forward(obs); c, U_cal, _ = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_calibrated)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    g = (M.mint.choose_interaction(modes, o, M.budget)
         if (U_epi > TAU_EPI and not slow) else None)
    if g is not None:
        U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    # ---- FORGE：慢环优化出的逐接口 λ 查表 ----
    js = M.sccg.interface_of(o)
    if M.sto.design is None or slow:
        lam = lam_floor(U_ale + U_epi)             # 结构回退 = R69
    else:
        lam = max(lam_floor(U_ale / M.sto.s(js)), M.efs.risk_scale(...))
    lam = max(lam, lam_floor(U_ale + (U_epi if g is None else 0.0)))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_s.submit_async(g, U_epi, a_hat, M.pbom.root, M.sto.design_hash)
    return k, lam, mode, (U_ale, U_epi)
```

## 3. 推导

**引理 19（契约组合的可靠性与非空洞必要性）** 设 A99：每个组件的契约在自身域内可靠；每条边满足 post_j ⊆ pre_i。则对 SCCG 的任意拓扑序做归纳，组合系统满足组合后置条件 post_root = compose(post_叶)。但若某 K_i 空洞（assume_i 把所有反例排除在域外），上述推理仍成立却毫无工程意义；A100 要求 NV ≥ τ_nv 且可证伪，才把证明从「逻辑真空」中救出。系：**组合安全性 = 契约可靠性 × 非空洞性 × 边蕴含**，三者缺一不可。

**引理 20（DRC 的健全性与快速路径）** 若 S 覆盖所有与 A 相交的执行路径（A102），则全量套件中任何失败 t 必与 A 相交（否则其路径不含被改组件，旧结果不变），故 t ∈ S；于是 S 通过 ⇒ 全量通过（健全）。快速路径：若 δK = refinement（post 强化、assume 收缩），则旧测试的通过结论仍然成立且新保证更强，故无需重跑即可保持证书。⇒ 差量再认证与全量等价，成本 ∝ |A| 而非 |V|。

**引理 21（结构优化不弱于 R69）** 在 A103（风险函数对 ρ 凸、预算线性）下，STO 的可行解 ρ* 满足 R_j(ρ*) ≤ R_j^max ∀j；由 s_j(ρ*) ≥ 1 得 λ_j = λ_floor(U_j / s_j(ρ*)) ≤ λ_floor(U_j)，故保守性不高于 R69。若 STO 不可行、离散化失败、checkerboard 不可验证或来源多样性不足，回退均匀结构，逐指令等于 R69。因此 **结构优化只买效率，不买安全**；安全由 R69 兜底。

**引理 22（n−1 成员容限 ≠ 来源容限）** 设「冗余」成员 m1、m2 共享上游根 r。移除 m1 或 m2 单独，系统仍通过成员级 n−1；但 r 被替换/投毒时 m1、m2 同时失效，越过 n−1 模型。故必须使用定义 317 的来源根级容限。系：**冗余的独立性由供应链图定义，而非结构图**；这是本轮最容易漏、也最致命的坑。

**定理 18（FORGE 严格包含 FLUID/R69）** 在静态 PBOM、无 fork、地面结构退化为单成员（ρ 固定）时，J_FORGE 的附加字段为常量，DRC/STO/DTA 不改变动作，主闭环逐指令等于 R69；一般情况下 FORGE 只增加约束（来源独立容限、组合类型、可复现位），不放松任何 R69 保证。故 R68 ⊂ R69 ⊂ FORGE，链条在安全侧保持单调。

**定理 19（单点故障爆炸半径有界）** 若 ρ 通过成员级与来源根级 DTA（A104），则任意单个成员或单个 provenance root 的替换/失效，使风险向量增量 ≤ ΔR_fail 且不越过紧急包络 R_emerg；结合 R69 认证前缀（定理 17），控制仍停留在安全集内且连续、无突变。系：**可替换性（fork/升级）与安全性可以同时成立**——这正是「开源」进入安全关键系统所必需的性质。

**定理 20（合流不降域）** 通过 merge gate 的合并，其证书域至少覆盖父分支域与上游域的交集；MAJOR 变更因强制全量评估与影子部署，其域缩减必须显式写入 K；`local_only` 分支不得自动上推。故合流不会让一个未验证的弱化契约悄悄成为群体默认。证明由定义 319 的四道门与引理 20 的差量健全性直接得到。

## 6. 本轮最大风险

**一句话**：FORGE-RAS 把安全论证从「这个系统安全」升级为「这条供应链安全」，但它最大的风险是**结构优化为了省预算，会把安全边际集中到少数「高效」接口与单一上游，而开源供应链恰恰意味着这些被集中的节点最可能被替换、静默补丁或投毒**——于是引以为豪的 n−1 冗余，可能只是同一座上游客房里挂了两块门牌；优化器越省，单点崩塌越致命。

**次级风险与缓解**：
1. **契约空洞化**（假设吞掉所有反例）→ 非空洞性 NV + 可证伪测试 + VQAuditor-S 审查；
2. **可复现 ≠ 安全**（精确重建一个坏构建）→ repro_bit 只作必要条件，仍需 J_FLUID 与 DTA；
3. **checkerboard/不可验证结构** → 密度过滤 + 离散化 + DTA 检验，失败即回退 R69；
4. **共因失效伪装成冗余** → 来源根级 n−1 + 来源多样性硬约束（定义 317–318）；
5. **「多双眼睛」被高估** → 评审只作为有相关性的证据源，不计为独立证明；
6. **实时环被 DRC 击穿** → STO/DRC 全部移到维护窗口，运行期只查表与哈希校验。

```python
def verify_pbom(root):
    seen = {h: load_by_hash(h) for h in closure(root)}
    ok = all(verify_signature(c) and license_ok(c.lic) for c in seen.values())
    b1, b2 = reproducible_build(seen), reproducible_build(seen, other_host=True)

def differential_recert(old, new, G):

    d = contract_diff(old.K, new.K)                     # refinement/internal/widening
    if d == 'refinement' and run_suite(select(A, G)): return 'fast'

        assert run_suite(FULL_SUITE) and dta(G)
        require_human_review()
    return 'full' if run_suite(select(A, G)) else 'reject'

def structural_optimize(ground, q, R_max, budget, p=3):
    rho = 0.5 * ones(len(ground))
    for _ in range(N_IT):
        rho = projection(density_filter(rho))
        u = solve(assemble_K(rho, p), q)
        rho = projected_gradient(
            rho - eta * (adjoint_sensitivity(rho, u, q, p) + alpha * cost_grad(rho)),
            budget)
    rho_d = discrete_round(rho)
    return None if (not dta_check(rho_d) or
                    provenance_diversity(rho_d) < d_min) else rho_d

def dta_check(rho, G):
    if any(risk(rho, remove={m}) > R_fail for m in active_members(rho)): return False
    if any(risk(rho, remove=members_with_root(r)) > R_fail
           for r in provenance_roots(rho, G)): return False   # 共因失效
    return True

def merge_gate(branch, upstream):
    if branch.local_only: raise Forbidden("local fork cannot auto-merge")
    d = contract_semver(branch.K, upstream.K)
    if d == 'MAJOR' and not (human_committee() and shadow_deploy()): return 'reject'
    if d == 'MINOR' and review_quorum(branch) < 2: return 'reject'
    ok = differential_recert(upstream, branch, G) in ('fast', 'full')
    return 'accept' if ok and dta_check(branch.rho, G) else 'reject'

def FORGE_RAS_round(M, obs):
    assert M.pbom.lock_hash == M.pbom.root and M.pbom.repro_bit == 1
    z, o = M.mtm.forward(obs); c, U_cal, _ = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_calibrated)
    slow = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    g = (M.mint.choose_interaction(modes, o, M.budget)
         if (U_epi > TAU_EPI and not slow) else None)
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    if M.sto.design is None or slow:
        lam = lam_floor(U_ale + U_epi)                  # 结构回退 = R69
    else:
        lam = max(lam_floor(U_ale / M.sto.s(M.sccg.interface_of(o))),
                  M.efs.risk_scale(...))
    lam = max(lam, lam_floor(U_ale + (U_epi if g is None else 0.0)))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    mode = select_mode(modes, U_epi, lam)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_s.submit_async(g, U_epi, a_hat, M.pbom.root, M.sto.design_hash)
    return k, lam, mode, (U_ale, U_epi)
```

## 4. 推导

**引理 19（契约组合与非空洞必要性）** A99 下，边满足 `post_j ⊆ pre_i` 且各契约可靠，则组合系统满足组合后置条件（对 DAG 归纳）。但空洞契约（assume 吞掉所有反例）使证明真空化，故需 A100：NV ≥ τ_nv 且可证伪。系：组合安全性 = 契约可靠性 × 非空洞性 × 边蕴含。

**引理 20（DRC 与全量等价）** 若 RTS 覆盖所有穿过受影响集 A 的路径（A102），则全量中任何失败测试必在 S 中，故 S 通过 ⇒ 全量通过。refinement 契约下旧证据仍成立，可走快速路径。成本 ∝ |A| 而非 |V|。

**引理 21（STO 不弱于 R69）** A103 下可行解满足 R_j(ρ*) ≤ R_j^max；因 s_j(ρ*) ≥ 1，有 `λ_floor(U_j/s_j) ≤ λ_floor(U_j)`，保守性不高于 R69。不可行/离散化失败/checkerboard/多样性不足时回退均匀结构，逐指令等于 R69。**结构优化只买效率，不买安全。**

**引理 22（成员 n−1 ≠ 来源 n−1）** 若冗余成员 m1、m2 共享上游根 r，则单独移除任一仍通过，但 r 被替换时二者同时失效，越过 n−1 模型。故必须用来源根级容限（定义 317 强版）。系：冗余独立性由供应链图定义。

**定理 18（FORGE 严格包含 FLUID/R69）** 静态 PBOM、无 fork、单成员地面结构时，附加字段为常量，动作逐指令等于 R69；一般情形只增约束不放松保证。故 R68 ⊂ R69 ⊂ FORGE。

**定理 19（爆炸半径有界）** 通过成员级与来源根级 DTA 的 ρ，任意单成员或单 provenance root 失效/替换只使风险增量 ≤ ΔR_fail，且不越过 R_emerg；结合 R69 认证前缀，控制连续无突变。系：可替换性与安全性同时成立。

**定理 20（合流不降域）** 通过 merge gate 的合并，证书域覆盖父分支域与上游域交集；MAJOR 强制全量 + 影子部署且域缩减显式入契约；`local_only` 不得上推。故弱化契约不会静默成为群体默认。

## 7. 本轮最大风险

**一句话**：FORGE-RAS 把安全论证升级为「供应链安全」，但**结构优化为省预算会把安全边际集中到少数高效接口与单一上游，而开源供应链恰恰使这些集中节点最易被替换、静默补丁或投毒**——n−1 冗余可能只是同一座上游客房的两块门牌；优化器越省，单点崩塌越致命。

**次级风险与缓解**：契约空洞化（NV + 可证伪 + 审计）；可复现 ≠ 安全（repro 仅必要条件，仍需 J_FLUID 与 DTA）；checkerboard 不可验证（过滤 + 离散化 + DTA，失败即回退 R69）；共因失效伪装冗余（来源根级 n−1 + 多样性硬约束）；「多双眼睛」被高估（评审仅作相关证据）；实时环被 DRC 击穿（慢环离线，运行期只查表与哈希锁）。
