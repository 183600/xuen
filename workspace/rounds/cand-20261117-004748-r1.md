# 第 11 轮（新灵感循环第 3 轮；本轮灵感：「基准测试」×「通用操作」）
> **基线**：第 10 轮 MetricVoiceGauge-LRC（定义 540–549；引理 87–93；实验 E571–E590）。
> 本轮纪律：**以测定包络 + 以基代例 + 未测不宣称**。两个灵感各治 v10 的一处债——「基准测试」治**紧度债/自证债**（v10 的 L0 松紧靠手调，改进只在固定赛道上验证，无法区分“真变好”与“对赛道过拟合”），「通用操作」治**泛化债**（v10 在整任务分布上评估与发证，样本昂贵、长尾不可见、证书无法复用到未见任务）。仍以中立元退化保证：基准失效退回 v10 手工包络，覆盖失效退回 v10 整任务证书，全失效退回 v10→v9→v8→v7→v6。

## 0. 直觉与动机

**灵感 1（基准测试 → 评测协议作为一等运行时产物）**
直觉：v10 最大的未言明假设是“我调出来的 L0 包络在部署域也够紧”，而它只有一张一次性实验表作证据（E571/E577/E581）。基准测试给的第一性原理不是“多跑几个 benchmark”，而是**把评测协议做成可版本化、留出、预注册、防污染的运行时对象**：任何“更紧/更好”的宣称都必须绑定一个操作、一个已认证的包络、一个测得的覆盖率与一个留出泛化间隙；模块晋升要过统计非劣性门，基准要轮换来对抗 Goodhart。关键技巧是**只在“可证明保守”的包络族里按基准挑最紧的那个**——基准再错也只能让系统更保守，不能让系统不安全。这样“基准”不是排行榜，而是**测量债的记账器**。

**灵感 2（通用操作 → 以有限操作基替代无限任务例）**
直觉：v10 在“整任务”粒度上评测与发证：每个新任务都要重跑证书与基准，长尾永远覆盖不到。通用操作给的第一性原理是**任务无关的可复用原子**：把任务空间压成有限操作基 𝒪（接近/抓取/搬运/放置/开门/倾倒/推/交接……），每个原子带类型化前后条件、参数包络与可证明包络族；任务 = 原子上的类型化组合。于是证书、基准、退化契约都可在原子层复用，少量基准通过“原子 × 组合深度 × 接口对”获得组合式覆盖；未见任务只要落在基内且接口可验，就继承原子的可靠性。代价是：基不完备、组合有隐藏耦合——这两点必须被显式记账，而不是假装不存在。

**灵感 3（合成：操作索引的基准账本）**
直觉：把两者相乘，得到一张**操作索引的账本**：每个操作 o 绑定 (i) 一族可证明保守的包络 E_o^{(0)} ⊇ … ⊇ E_o^{(C)} ⊇ 真实可达集，(ii) 一份预注册的三层基准（同分布 I / 平移 S / 留出组合 H）与污染防护，(iii) 一个覆盖向量（原子、组合深度、接口对）。运行期先分解、再查覆盖：只有 level-2（基准认证）才敢用最紧包络，未覆盖就诚实地退回 v10 整任务证书。核心创新：**通用操作基（OB）**、**操作基准台（OBench）**、**基准标定包络（BCE）**、**覆盖账本（CL）**、**基准回归门（BGate）**。

## 1. 研究问题

- **Q1（标定不放宽）**：有限基准样本下，如何从可证明保守的包络族中选出最紧者，并给出有效的违背概率上界（Clopper–Pearson / 保形）？
- **Q2（组合式泛化）**：原子级可靠性在什么条件下传递到未见组合任务？覆盖账本能否把“未覆盖”变成显式保守而非隐性冒险？
- **Q3（反 Goodhart）**：如何用留出组合层 + 基准轮换 + 非劣性门，使“晋升”既不误升也不无限增加评测成本？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 测得其所（Benchmark-What-You-Deploy）**
任何“更紧/更好”的宣称只在基准覆盖支撑内有效；基准版本化、留出、预注册、防污染；未覆盖一律降级为保守，绝不把基准内结论外推为基外结论。

**P17 以基代例（Basis-over-Instances）**
任务 = 有限操作基上的类型化组合；证书与基准以“原子 + 接口”为复用单位；基外任务不宣称，退回整任务证书。组合必须过接口匹配与联合不变式。

**P18 标定不放宽（Calibrate-within-Sound-Family）**
基准只在已证明保守的包络族内选择紧度；标定失败（违背概率上界 > α）即取最保守成员，绝不越出可证族。基准的统计误差只能买来“更紧”，不能买来“更真”。

## 3. 与基线的接口（如何退化）

- 基准台不可用 / 版本哈希不符 ⇒ 冻结上一已认证包络，退回 v10 手工包络（仍 sound）；
- BCE 标定失败 ⇒ 取 E^{(0)} 最保守成员（性能退、安全不退）；
- 覆盖账本判未覆盖（基外原子 / 超深组合 / 接口未验 / 联合不变式不满足）⇒ 退回 v10 整任务 LWC/RL 证书；
- BGate 拒绝 ⇒ 不晋升，保持 v10 配置；
- v10 任一失效 ⇒ 按 v10 七级链退回 v9；全失效 ⇒ v10→v9→v8→v7→v6。

## 4. 预期贡献

1. **操作基 + 覆盖账本**：把小样本基准变成组合式覆盖，未覆盖可审计、可保守回退；
2. **基准标定包络**：在同一可证族内用统计选择换紧度，直接治 v10 的 K=1 回退（预估 22%→≤10%）；
3. **基准回归门 + 轮换**：模块晋升有统计门，Goodhart 有经验缓解且边界被诚实声明；
4. **实验 E591–E610** 覆盖标定有效性、组合泛化、反过拟合、污染与端到端。

## 5. 本轮最大风险

**一句话**：操作基是人为选定的有限基、基准也只看基内原子与有限深度组合——真实长尾一旦落在基外或出现“接口匹配但联合动力学不匹配”的隐藏耦合，覆盖账本要么诚实地退回保守（性能债），要么在统计接口检查放行时把“基准内正确”误当“基外也正确”（泛化债），系统于是越在基准上变强、越在基准外变盲。

## 1. 符号体系增量（定义 550–559）

**新增定义 550（通用操作基 General Operation Basis）** 操作原子
```
o = (π_o, pre_o, post_o, E_o, {E_o^(c)}_{c=0..C}, κ_o)
```
其中 π_o 为参数化技能，pre_o/post_o 为带类型的谓词，E_o 为参数包络，κ_o=(deadline, priority, budget, 证书模板) 沿用 v10 契约。任务 τ 被分解为类型化组合计划 π = (o_{i₁},…,o_{i_K})，边集 ℰ(π) 给出前后依赖；分解失败返回 ⊥（不宣称、走 v10 整任务路径）。

**新增定义 551（操作契约与覆盖式接口）** 接口对 (o_i,o_j) 已证明当且仅当
```
post_{o_i} ⇒ pre_{o_j}    且    Ξ_{ij}（对象同一、执行器互斥、接触连续）成立
```
证明可由离线定理检查/保守静态分析给出；仅有统计支持的接口记为“统计接口”，只允许 level-1 声明。𝒱 为已证明接口对集合。

**新增定义 552（三层基准协议 Three-Stratum Benchmark）** 对每个 o，预注册
```
ℬ_o = ( I_o: 包络内 iid 采样,  S_o: 平移族（光照/摩擦/负载/噪声，严重度 s）,  H_o: 留出组合任务 )
版本 h_B = H(seeds, generator, instance_manifest)
```
污染防护：(i) H 不参与任何选择/调参，只用于审计与回归门；(ii) 测试实例不得进入训练、ID 归因或覆盖账本；(iii) 每次晋升使用新版本（轮换），旧版本降级为回归集；(iv) 任一版本哈希不符即冻结。

**新增定义 553（可证包络族 Provably-Sound Envelope Family）** 由区间细分、可达集多面体/椭圆外近似、不同膨胀系数构造
```
E_o^(0) ⊇ E_o^(1) ⊇ … ⊇ E_o^(C) ⊇ Reach_o^true
```
每个成员都附带机器可检的保守性证明（区间算术/多面体包含），加载时校验；因此**任意成员**作为 L0 硬界都满足 ĝ⁰ ≤ g_min^true。档位 c 增大只表示“更紧”，不表示“更真”。

**新增定义 554（基准标定包络 BCE 选择规则）**
```
c*_o = max { c ∈ [0,C] : U_CP(k_c, n_c; δ_b/(C+1)) ≤ α_b }
若集合为空 ⇒ c*_o = 0（最保守）
```
其中 k_c 为在 ℬ_cal = I_o ∪ S_o 上使用 E_o^(c) 时的“不安全接受”次数，n_c 为样本数。H_o 不参与选择。运行时 L0 使用 E_o^(c*)，证书其余部分仍按 v10 定义 540/541 计算。

**新增定义 555（校准有效性与样本复杂度）** 采用 Clopper–Pearson 单侧上界 U_CP；对 C+1 个档位做并集校正 δ_b/(C+1)。若无违背（k=0），保证 U_CP ≤ α_b 所需样本量
```
n ≥ log((C+1)/δ_b) / α_b
```
这是保守的零违背计划量；有违背时按 CP 上界判定。校准保证是在 ℬ_cal 抽样分布下、对“该档位不被选入错误接受”的保证，不外推到 H 或基外。

**新增定义 556（覆盖向量与声明等级）** 对任务 τ 的计划 π
```
cov(τ) = ( A(π) ⊆ A_cov,  depth(π) ≤ D_cov,  ℰ(π) ⊆ 𝒱,  Ξ(π) = true )
level(τ) = 2  若 cov 全成立（基准认证）
          = 1  若 A(π) ⊆ A_cov 且仅深度/统计接口越界（统计支撑）
          = 0  其余（未覆盖）
```
只有 level 2 允许使用 c*_o > 0 的最紧包络；level 1 只用 c=0 并保留 v10 的 L1/L2 收紧；level 0 退回 v10 整任务证书。

**新增定义 557（组合规则与联合不变式）** 组合计划 π=o_1∘…∘o_K 的硬界取
```
ĝ⁰_π = min_{k} ĝ⁰_{o_k},   ê⁰_π = max_k ê⁰_{o_k}
```
若每个原子硬界 sound、每条边接口已证明、且 Ξ(π) 成立，则组合 sound（引理 97）。若接口仅统计支持，则组合只具 1−α_stat 的统计可靠性，并按边数做并集校正。隐藏耦合（如两原子共享同一物体但对象同一性未验证）直接令 Ξ 失败 ⇒ level 0。

**新增定义 558（基准回归门 BenchmarkGate）** 候选模块 M' 相对在位 M 晋升，当且仅当
```
∀o ∈ 𝒪:  TOST_{δ_gate, α_gate/|𝒪|}( score_{M'}(o) , score_M(o) ) 成立
且  U_safety(M',o) ≤ U_safety(M,o)        （安全严格不劣）
```
并在新轮换版本 h_B' 上复测；任一条件失败即拒绝晋升（保持 v10 配置）。门只保证“基准可检测的退化不被放行”，不保证基外不退化（见引理 98）。

**新增定义 559（基外监控与退化 Out-of-Benchmark Guard）** 在线以覆盖/保形检验计算 ρ_shift（例如对操作参数与观测特征做密度比或 conformal p 值）；当 ρ_shift < α_oob 判为基外，立即把 level 降为 0 并走 v10 整任务路径。该监控的漏检率无对抗性保证，故只作为**保守触发器**而非安全证明（引理 99）。

## 2. 关键算法骨架

```python
# IP-361 通用操作基：有限原子 + 可证包络族 + 类型化组合
@dataclass
class OpContract:
    name: str
    pre: Callable; post: Callable
    family: list          # E^(0) ⊇ ... ⊇ E^(C) ⊇ Reach_true，含证明
    kappa: Contract
    C: int

class OperationBasis:
    def __init__(self, ops, verified_ifaces):
        self.ops = {o.name: o for o in ops}
        self.V = set(verified_ifaces)          # 已证明接口对
    def decompose(self, task):
        plan = planner.decompose(task, self.ops)   # 类型化组合；基外返回 None
        return plan

# IP-362 操作基准台：三层 + 版本 + 污染防护 + CP 上界
class OperationBench:
    def calibrate(self, o, c, alpha_b, delta_b):
        n = math.ceil(math.log((o.C + 1) / delta_b) / alpha_b)
        xs = self.sample(o, env=o.family[c], strata=('I', 'S'),
                         n=n, version=self.version)   # H 不参与选择
        k = sum(not safe_accept(o, o.family[c], x) for x in xs)
        return (clopper_pearson_upper(k, n) <= alpha_b), k, n

    def audit(self, o, c):                    # 只在 H 上做审计，不回流选择
        return self.metrics(o, env=o.family[c], strata=('H',))

    def rotate(self):                         # 抗 Goodhart：换版本
        self.version = hash_manifest(new_seeds(), generator=self.gen)
        return self.version

# IP-363 基准标定包络：只在可证族内选紧度
class BenchmarkCalibratedEnvelope:
    def select(self, o):
        for c in range(o.C, -1, -1):
            ok, _, _ = bench.calibrate(o, c, alpha_b, delta_b)
            if ok:
                return o.family[c]            # 最紧且通过校准
        return o.family[0]                    # 全部失败 ⇒ 最保守

# IP-364 覆盖账本：把“未覆盖”变成显式保守
class CoverageLedger:
    def claim(self, plan):
        if plan is None:
            return Claim(0, 'no-decomposition')
        if not plan.atoms <= self.A_cov:
            return Claim(0, 'atom-out-of-basis')
        if plan.depth > self.D_cov:
            return Claim(1, 'depth')
        if not all(e in self.V for e in plan.edges):
            return Claim(0, 'interface-unverified')
        if not plan.joint_invariant_ok():     # 定义 557 的 Ξ
            return Claim(0, 'hidden-coupling')
        return Claim(2, 'benchmark-certified')

# IP-365 基准回归门：非劣性 + 安全不劣 + 轮换
class BenchmarkGate:
    def promote(self, cand, inc):
        for name, o in basis.ops.items():
            a = alpha_gate / len(basis.ops)   # 逐操作并集校正
            if not tost_non_inferior(cand, inc, o, delta_gate, a):
                return False
            if safety_upper(cand, o) > safety_upper(inc, o):
                return False
        return bool(bench.audit_all(strata=('H',)))

# 主闭环集成：MetricVoiceGauge-GOB
def metricvoicegauge_round_11(M, s, task, obs, ...):
    plan = basis.decompose(task)
    claim = ledger.claim(plan)

    if claim.level == 2:
        certs = []
        for o in plan.atoms:
            env = bce.select(basis.ops[o.name])          # L0 用最紧已认证档
            cert, ok = certifier.certify(
                s, o, env=env,
                budget_level=schedule.level_budget(o.name))
            if not ok:
                return M.v10_full_task_path(s, task, ...)  # 原子失败 ⇒ 整任务
            certs.append(cert)
        if compose_sound(certs, plan):                     # 定义 557
            return execute_via_v10_lwc_rl(plan, certs)
    return M.v10_full_task_path(s, task, ...)              # level 0/1

# 基外监控（50Hz，O(1) 摊销）：只触发保守回退，不作安全证明
if oob.rho_shift(live_obs) < alpha_oob:
    current_claim = Claim(0, 'out-of-benchmark')
    fallback_to_v10_full_task()
```

## 3. 推导

**引理 94（标定选择的可靠性不放宽）** 对任意 o 与任意档位 c∈[0,C]，E_o^(c) ⊇ Reach_o^true，故由定义 541 计算的 ĝ⁰(c) ≤ g_min^true。BCE 只从该族中选 c*，因此基准选择、基准污染、基准过拟合**都不能使 L0 由 sound 变为 unsound**；最坏后果是选到过紧档以至于保守性证明被违反——而这一点由加载时的证明校验排除。∎

**引理 95（标定的样本复杂度与紧度增益）** 设档位 c 的真实违背概率 p_c。以 n_c 个 IID 样本与 Clopper–Pearson 上界 U_CP，对 C+1 档做并集校正 δ_b 后，事件“存在被选中档位而 p_c > α_b”的概率 ≤ δ_b。若 p_c=0，则 U_CP=1−δ'^{1/n}，令其 ≤ α_b 得 n ≥ log((C+1)/δ_b)/α_b。故每操作校准样本量 O((C/α_b)·log(C/δ_b))；随 n 增大可选 c* 单调不减（同一样本路径下），紧度 θ_o(c*) 单调改善，直到触及 p_c>α_b 的档位或 c=C。∎

**引理 96（覆盖的保守性与“无免费泛化”）** 覆盖账本对未覆盖任务只返回 level 0/1，不产生 level-2 宣称；因此所有 level-2 结论按构造落在基准支撑内。在 H 层内若实例可交换，则 level-2 的组合任务以 1−δ_b 的置信继承校准违背界；但账本**不能**约束基外任务的测度——若任务分布把质量放在基外，系统只保证“不错误宣称”，不保证“高性能”。这是设计上的诚实边界，而非可修复的统计细节。∎

**引理 97（组合可靠性）** 若 (i) 每个原子硬界 sound（ĥ⁰_k ≤ g_min,k^true），(ii) 每条边接口已证明（post_i ⇒ pre_j 且 Ξ_ij），(iii) Ξ(π) 成立，则组合真实可达轨迹必落在原子可达集乘积内，且
```
ĝ⁰_π = min_k ĝ⁰_k ≤ min_k g_min,k^true = g_min,π^true
```
故组合硬界 sound。若接口只有统计支持，其失败概率按边做并集校正，组合仅具统计可靠性；若 Ξ 失败（如对象同一性未验、执行器冲突、接触模式跳变），必须拆计划或令 level=0，不能以“接口谓词通过”掩盖耦合。∎

**引理 98（回归门的统计保证与其边界）** 逐操作 TOST 在水平 α_gate/|𝒪| 下，任何“显著变差”的候选被误升的概率 ≤ α_gate；安全严格不劣提供确定性一票否决。基准轮换与 H 留出降低对固定赛道的过拟合，但**不提供对抗性 Goodhart 保证**：若候选专门拟合生成器而 H 采样不足，门仍可能误升。该边界由 E596/E602 显式测量，不得写成“已解决”。∎

**引理 99（基外监控的角色）** ρ_shift 触发只把声明降为 level 0，因此监控的假阴性不会引入不安全接受，最多保留一次未检出的性能退化；假阳性只造成保守回退（性能债）。在无密度比假设时无法给出漏检率上界，故 OOB 是**失效安全触发器**，不是 soundness 证明的一部分。∎

## 8. 本轮最大风险

**一句话**：操作基是人为选定的有限基、基准也只看基内原子与有限深度组合——真实长尾一旦落在基外或出现“接口匹配但联合动力学不匹配”的隐藏耦合，覆盖账本要么诚实地退回保守（性能债），要么在统计接口检查放行时把“基准内正确”误当“基外也正确”（泛化债），系统于是越在基准上变强、越在基准外变盲。
