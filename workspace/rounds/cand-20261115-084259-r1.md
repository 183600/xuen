# 第 4 轮（灵感循环第 4 轮；本轮灵感：「基线复现」×「视觉伺服」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。基线复现回答「世界还是不是校准时那个世界」，视觉伺服回答「执行是不是真的在收敛」；二者都是**证书型增强**，任一不可用都能一键退回 InstructGauge。

## 0. 直觉与动机

**灵感 1（基线复现 → 先证明「能复现」，再允许「去改进」）**
直觉：实验科学里，任何「新方法更好」的结论都以「基线能被复现」为前提；计量学里，每次测量前都要重新建立参考基准（gauge R&R：repeatability & reproducibility）。R3 的 InstructGauge 有一个隐藏假设：**当前的感知—执行栈仍处在校准时的工作域（regime）内**。一旦灯源老化、镜头污染、姿态偏移、温度漂移，这个假设就静默失效，而所有下游证书（CVC、共形覆盖、主张绑定）都建立在它之上。因此需要一道**空实验（null experiment）门**：在允许任何契约更新、校准更新或不可逆动作之前，先在一个已知真值的参考件上复现一个预注册签名；只有复现通过，当前工作域才被认证为「与校准时同源」。这把「分布漂移」从一个无法检验的哲学问题，变成一个**有 α、有功效、可 anytime 停止**的统计检验。必须诚实：复现保证的是**一致**，不是**正确**；一致性只是必要条件，正确性仍需外部标准（见第 5 节风险）。

**方法论层面的第二重含义**：本轮所有增益（相对 R3）必须先在同一硬件上**复现 R3 的 E441–E456 基线**，否则「提升」不可解释。故实验协议把「基线复现」写成硬前置，而不是一句口号——这也是灵感词在元层面的直接落地。

**灵感 2（视觉伺服 → 用图像闭环把证据陈旧窗口从 K 压到 1 帧，但把风险转移到 Jacobian）**
直觉：R3 的动作分块是**开环**执行 K 步，块内没有新证据来否决——证据陈旧窗口等于 K。视觉伺服恰好是对偶解：用图像特征误差 `e = s − s*` 构造反馈 `u = −λ L̂⁺ e`，每一步都用新图像纠偏，把有效陈旧窗口压到「相机延迟 + 控制周期」量级。但闭环不是免费的：`L̂`（交互矩阵 / 图像 Jacobian）本身是**估计出来的**，当标定有误或工作域漂移时，错误的 `L̂` 会让闭环**发散**——这比开环更危险，因为它会以更大的增益、更自信的方式冲向错误目标。故伺服的收益必须用**证书**换：交互矩阵误差界、可见性裕度、时延上界、饱和余量，缺一不可。

**灵感 3（两者耦合 → 复现认证伺服，伺服残差反哺复现；最危险的是同源互证）**
直觉：视觉伺服的稳定性直接依赖 `L̂`，而 `L̂` 是否仍然可信，正是基线复现要回答的问题——于是「复现」天然成为「伺服」的准入前提。反过来，伺服运行时的残差 `‖e(t)‖` 是一串高频、连续的「在线复现」：如果实际收敛速率与 `L̂` 预测的系统性偏离，就说明基准 / 标定已经变了。二者构成一个漂亮的**双向闭环**：慢时间尺度（复现，百毫秒级）认证世界，中时间尺度（分块，十毫秒级）决定意图，快时间尺度（伺服，毫秒级）保证收敛。但这里埋着一个致命的结构性风险：如果复现门与伺服残差**共享同一个可错通道**（同一台未标定相机、同一个磨损基准件），它们会**同向地**把系统性误差认证成「一致且收敛」——即**同源互证幻觉（co-certification illusion）**。因此本轮真正的结构支柱不是复现门本身，而是**非同源证据**：至少一条与图像通道不共因的第三通道（独立基准标尺、力 / 触觉回执、外部计量）来打破互证。

## 1. 研究问题（本轮要回答什么）

- **Q1（复现的门限）**：如何把「世界仍在校准域内」变成一个 anytime-valid、有明确功效、且不因频繁检查而虚警的检验？复现失败时系统应如何**优雅降级**而不是直接停摆？
- **Q2（伺服的稳定边界）**：在交互矩阵有界误差、相机时延、可见性受限的条件下，视觉伺服的稳定域如何解析刻画？收益（陈旧窗口收缩）与风险（错误 Jacobian 放大）的交换边界在哪里？
- **Q3（同源互证）**：当复现与伺服共享故障源时，联合误证概率如何被抬高？需要多强的独立通道、以何种证书形式，才能把联合误证压回可接受上界？

## 2. 三条设计原则（雏形，正式化见产物区定义 448–466）

**P1 先复现，后改动（Reproduction Before Mutation, RBM）**
任何契约热替换、共形阈值更新、不可逆动作、以及「相对基线的改进」声明，都必须以当前工作域的复现证书 `BRC = PASS` 为前置。复现失败 ⇒ 冻结更新、展宽区间、禁止不可逆动作；系统退化为「只读 / 保守」模式，而非直接停机。**一致性是改动的前置，不是正确性的证明。**

**P2 证书化伺服（Certified Servo, CS）**
视觉伺服只在 `SVC` 通过时启用：`ε_L < ε_crit`、可见性裕度 `ρ_vis > ρ_min`、时延 `τ < π/(2λ)`、指令在权威包线 `U_auth` 内。任一不满足 ⇒ 关闭伺服，退回 R3 的开环分块；再不行 `K=1` 退回 ToolGauge 逐步。**闭环不是无条件更好，只有带证书的闭环才更好。**

**P3 非同源证据（Non-Common-Cause Evidence, NCCE）**
复现通道与伺服通道的联合认证，必须附加一条**条件独立**的第三通道；若不存在可用的第三通道，则不得把「二者一致」当作正确性证据，只能当作「自洽性」证据，并把置信度按共因风险 `κ_co` 折减。

**P4 三层证书偏序（Multi-Timescale Veto）**
慢（复现）可以否决中（分块）与快（伺服）；中可以否决快；快不可越级否决慢。否决是**单向**的：快层发现异常只能触发慢层**重新复现**，不能自行改写基线或提高增益。这防止「用快环的局部成功去洗白慢环的域漂移」。

## 3. 与基线的接口（如何退化）

- 复现不可行 / 预算不足 / 无参考件 ⇒ 跳过 BRG，等价于 InstructGauge（R3），但显式标注「未认证工作域」；
- 伺服证书不通过（`ε_L` 超界 / 可见性不足 / 时延超界 / 饱和）⇒ 关闭 CVS，退回 R3 开环分块；再不行 `K=1` 退回 ToolGauge；
- 无独立第三通道 ⇒ ICC 降级为「自洽性声明」，共形阈值按 `κ_co` 保守展宽；仍不行 ⇒ 只做可逆动作；
- WCC 样本不足 ⇒ 回退 R3 的分层共形；再不足 ⇒ 全局共形；
- 基准件健康证书失败 ⇒ 冻结该参考件、升级到更高一级标准，绝不用可疑基准认证世界；
- ToolGauge 失效 ⇒ LeanGauge 纯数值路径；LeanGauge 失效 ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个 **anytime-valid 的基线复现门**（e-process），把「工作域漂移」变成有 α / 功效 / 停止时间保证的可检验命题，并给出复现失败时的保守降级语义；
2. 一个 **有解析稳定域的证书化视觉伺服**，把交互矩阵误差、时延、可见性显式写进稳定性条件，并用 `K_eff` 量化「闭环替代开环分块」的真实收益；
3. 一个 **非同源证据证书 ICC / 共因风险 κ_co**，首次把「复现与伺服互相认证」的循环论证风险变成可度量、可拒绝的设计约束；
4. 一个 **复现加权共形校准**，把 regime shift 下的覆盖损失分解为「共形松弛 + 漂移概率 + 域内残差」三项；
5. 一个 **基准健康证书 BHC / 可追溯链**，防止参考件自身老化伪装成世界漂移；
6. 一条完整可证伪路径：E457–E474 覆盖复现功效、Jacobian 稳定阈值、时延、陈旧窗口、共因误证、加权覆盖、基准老化、周期摊销与端到端迁移。

## 5. 本轮最大风险

**一句话**：复现门与伺服残差若共享同一个可错观测通道（同一台未标定相机 / 同一个磨损基准件），它们会**同向地**把系统性误差认证成「一致且收敛」——系统越自信、闭环越稳，越可能把一个错误基准稳定地驱动到错误目标；因此最大的残余风险不是门限选择，而是「独立第三通道在部署现场是否可得」，得不到就必须在安全与可用之间被迫二选一。

## 2. 形式化定义（要点）

**定义 448（基线 β 与复现探针 π_ref）** `β = (A_ref, π_ref, z_ref, θ₀, δ_rep)`。`A_ref` 为参考件（已知几何 / 材质 / 真值），`π_ref` 为**预注册**的复现探针序列（不得在看到数据后修改），`z_ref` 为校准工作域 `θ₀` 下 `π_ref` 的签名分布（均值 / 协方差或分位带），`δ_rep` 为容差预算。签名 `z = φ(I_{1:T}, r_{1:T})` 由图像与回执共同构成，`φ` 亦预注册。

**定义 449（复现残差与见证统计）** `r_rep = d(z, z_ref)` 用于诊断与可视化；为避免事后挑选统计量，另预注册**见证标量** `w(z)`，零假设（工作域未变）下 `E_{H₀}[w] = μ₀` 且次高斯参数为 `σ`。只有 `w` 进入检验，`r_rep` 不进入。

**定义 450（复现 e-process 与 BRC）** `E_t = ∏_{i=1}^{t} exp(λ_i (w_i − μ₀) − λ_i²σ²/2)`，`λ_i` 预注册且有界。`BRC = (β, E_t, decision, τ_stop, m_rep)`，`PASS ⇔ sup_{s≤t} E_s ≥ 1/α_rep`；由 Ville 不等式，**任意数据依赖的停止时刻**虚警 `≤ α_rep`。`m_rep = log E_t`。关键：监控中「检查多少次」由数据决定，固定样本 p 值在此无效，必须用 e-process / 测试鞅。

**定义 451（工作域与复现域）** `θ` 含光照、姿态、温度、镜头状态、传感器增益等。`D_rep = {θ : 在预算内 BRC(θ)=PASS}`。`D_rep` 是**统计**域：`P(θ∈D_rep | H₀) ≥ 1−α_rep`，不是几何多面体；其边界的不确定性必须显式保留。

**定义 452（视觉伺服：特征、交互矩阵、控制律）** `s = f(I) ∈ R^m`，目标 `s*`，`e = s − s*`；`ṡ = L(s) v`，`L ∈ R^{m×k}` 为交互矩阵；`v = −λ L̂⁺ e`（阻尼伪逆），一步动作 `u = v Δt`。

**定义 453（伺服证书 SVC）** `SVC = (L̂, ε_L, ρ_vis, τ_lat, V_max)` 要求四条同时成立：
(i) `‖L̂ − L‖₂ ≤ ε_L < ε_crit`；
(ii) `ρ_vis = dist(s, ∂S_vis) > ρ_min` 且一步预测 `s⁺ ∈ S_vis`；
(iii) `τ_lat < π/(2λ)`；
(iv) `‖v‖_∞ ≤ V_max` 且未触饱和。
任一失败 ⇒ `SVC = FAIL`，禁用伺服。

**定义 454（伺服权威包线 U_auth）** `U_auth = {u : u ∈ A_adm, φ_pre(u), u 不越 M_phys, u 不缩短不可逆屏障}`；下发 `u† = Π_{U_auth}(u)`。若 `‖u − u†‖ > δ_auth` ⇒ 这本身记为 `SVC=FAIL` 证据（「模型想做的动作物理上做不了」），而不是静默裁剪。

**定义 455（有效证据陈旧窗口 K_eff）** 设相机周期 `Δt_c`、控制周期 `Δt`、端到端视觉时延 `τ_lat`，`K_eff = ⌈(τ_lat + Δt_c)/Δt⌉`。R3 开环分块 `K_eff = K`；闭环伺服把 `K_eff` 降到约 1–3，代价是引入 `L̂` 依赖。`G_K = K − K_eff` 为以步计的陈旧收益。

**定义 456（非同源证书 ICC 与共因风险 κ_co）** 复现通道 `C1`、伺服通道 `C2`，共享潜在故障源集合 `Z`（相机内参、镜头、基准件、光源）。`κ_co = sup_{z∈Z} P(C1=PASS, C2=PASS | z 失效)`。`ICC` 要求第三通道 `W`（力 / 触觉、独立基准标尺、外部计量、已知图案 fiducial）满足 `W ⟂⊥ (C1,C2) | Z`，且对共享失效有功效 `P(W=FAIL | z) ≥ 1−δ_W`。`ICC = (W, κ_co, δ_W)`。

**定义 457（复现-伺服双向闭环 RSL）** 状态机 `S0 →(BRC PASS)→ S1(Servo) →(residual alarm)→ S2(Re-Reproduce) → S0/S1`。`S1` 内每 `N_servo` 帧检查 `r_servo`；进入 `S2` 的转移**不得**直接改写 `β` 或 `L̂`，只能产出「重新标定请求」或降级。

**定义 458（伺服残差与再复现触发）** `r_servo(t) = ‖e(t)‖²`；`R₀(t)` 为 `L̂` 预测的收敛包络（由引理 60 给出）。触发条件：`r_servo(t) > R₀(t) + η_servo` 连续 `q` 帧，或 `‖e(t)‖` 未按预测速率下降。触发后进入 `S2`，**而非提高增益**。

**定义 459（复现加权共形 WCC）** 校准样本 `i` 权重 `ω_i ∝ exp(ξ·ψ(θ_i))`（`ψ` 为工作域特征，`ξ` 由复现似然比估计）；加权分位 `q_ω = inf{q : Σ_{i: score_i ≤ q} ω_i / Σ_i ω_i ≥ 1−α}`。工作域失配的样本自动降权。

**定义 460（基准健康证书 BHC 与可追溯链）** `BHC = (A_ref, A_std, drift_A, k_tier)`：周期用高一级标准 `A_std` 校验 `A_ref`，`drift_A = d(φ(A_ref), φ_std(A_std))`；`drift_A > δ_A` ⇒ 隔离 `A_ref` 并升级，不得继续用其认证世界。形成 `A_std → A_ref → 被测件` 的可追溯链，层数 `k_tier` 有限且每层有独立健康证书。

**定义 461（复现周期与预算）** `N_rep` 为两次计划复现之间的最大周期；触发式复现（温漂、残差报警、换件）不受此限。`B_rep = c_rep/N_rep + c_trig·h_θ`，与 R3 的 `B_chunk` 共用总预算 `B_total`。

**定义 462（三层证书偏序与单向否决）** `Cert = (BRC, ChunkCert, SVC)`，偏序 `BRC ≻ ChunkCert ≻ SVC`（`≻` 表示可否决）。`BRC=FAIL ⇒` 其余不得为 PASS；`SVC=FAIL` 只能触发 `BRC` 重检或降级，**不得**反向修改 `BRC` 的参考件或阈值。

**定义 463（双通道不变量）** 运行不变量：(i) 无 `BRC=PASS` 不得有 `ChunkCert=PASS` 的契约更新；(ii) 无 `SVC=PASS` 不得有图像闭环动作；(iii) 无 `ICC=PASS` 时，`BRC∧SVC` 只能声明「自洽」而非「正确」；(iv) 不可逆动作要求 `BRC∧SVC∧ICC` 同时 PASS 且独立回执验证。

**定义 464（ServoGauge-8C 闭环）** `I→R→H→C→E(servo/chunk)→C→V→U`：`I` 指令接地（R3）；`R` 复现门；`H` 假设；`C` 分块 / 伺服规划；`E` 执行（快环伺服 + 中环分块）；`C` 证书复核（SVC + ChunkCert）；`V` 校验 / 共形；`U` 更新（仅 `q_quiesce` 且 `BRC=PASS`）。

**定义 465（退化映射 δ_SG）** `δ_SG(BRG→∅) = InstructGauge`；`δ_SG(CVS→∅) =` 开环分块 InstructGauge；`δ_SG(BRG,CVS→∅) = ToolGauge`；`δ_SG(WCC→∅) =` R3 分层共形；`δ_SG(ICC→自洽模式)`：保留运行但置信度乘 `(1−κ_co)` 且禁止不可逆动作。

**定义 466（审计证书 RepairCert″）** `RepairCert″(s) = (ι, C, ChunkCert, BRC, SVC, ICC, BHC, receipts, claims)`，把 R3 的四级证据链扩成「基准→工作域→指令→动作→回执→主张」六级，审计者可逐级重放。

# IP-328 BRG：预注册探针 + anytime-valid e-process
class BRG:
    def reproduce(self, beta, env, budget):
        z = []
        for a in beta.pi_ref:                     # 预注册探针，不可临场改
            env.apply(a); z.append(env.signature())
        w = beta.witness(z)                       # 预注册标量
        self.E = e_process_update(self.E, w, beta.mu0, beta.sigma, self.lam)
        if self.E >= 1 / beta.alpha:
            return BRC("PASS", self.E, env.regime())
        if budget.exhausted():
            return BRC("FAIL_CLOSED", self.E, env.regime())
        return BRC("PENDING", self.E, env.regime())

# IP-329 CVS：四元证书 + 权威包线 + 残差监控
class CVS:
    def certify(self, Lhat, Lplus, s, Svis, lam, tau, Vmax):
        if norm(Lhat - self.L) > 1 / (2 * norm(Lplus)): return "FAIL:jacobian"
        if dist(s, boundary(Svis)) <= self.rho_min:      return "FAIL:visibility"
        if tau >= pi / (2 * lam):                        return "FAIL:latency"
        if max(abs(self.v)) > Vmax:                      return "FAIL:saturation"
        return "PASS"

    def step(self, s, s_star, Lhat, Uauth, lam, dt):
        v  = -lam * pinv(Lhat) @ (s - s_star)
        u  = v * dt
        u2 = project(Uauth, u)
        if norm(u - u2) > self.delta_auth:
            return "FAIL:authority", None           # 越权即失败，不静默裁剪
        return "PASS", u2

# IP-330 ICC：没有独立通道就只声明自洽
class ICC:
    def check(self, c1, c2, W):
        if W is None:
            return "SELF_CONSISTENT_ONLY"
        if not independent(W, (c1, c2)):
            return "CO_CERTIFIED_RISK"
        kappa = self.estimate_kappa(c1, c2)
        ok = (W.fail_power >= 1 - self.delta_W) and (kappa <= self.kappa_max)
        return "PASS" if ok else "FAIL"

# IP-331 RSL：三层单向否决
class RSL:
    def tick(self, brc, svc, r_servo, R0, env):
        if brc != "PASS": return "read_only"            # 冻结更新
        if svc != "PASS": return "open_loop_chunk"      # 退回 R3 分块
        if r_servo > R0 + self.eta and env.frames >= self.q:
            return "re_reproduce"                       # 只请求重检，不加增益
        return "servo"

# IP-334 8C 闭环（50Hz 主路径不变集）
def servogauge_8c(M, s, ell):
    brc  = M.brg.reproduce(M.beta, M.env, M.budget)
    out  = M.nlib.ground(ell, M.scene, M.ontology)      # R3
    iota = out[0] if out else M.default_iota
    H    = M.lbox.hypothesize(s, M.dbox.R[s], iota)
    C    = M.iac.plan_chunk(iota, H, M.tools,
                            M.budget_left(s), M.drift_bound(s))
    if brc == "PASS" and M.cvs.certify(*M.cvs_state(H)) == "PASS":
        cert = M.cvs.step_loop(C, M.env, M.Uauth)        # 快环：K_eff 帧
    else:
        cert = M.cvc.commit(C, M.env, iota)              # 退回 R3 开环块
    icc = M.icc.check(brc, cert.svc, M.third_channel())
    if icc != "PASS":
        cert = cert.as_self_consistent(kappa=M.icc.kappa)
    receipts = cert.receipts
    if len(receipts) < n_min(s):
        return stub_and_red(s, "insufficient")
    mu, Sig = M.wcc.calibrate(receipts, H, s, M.regime_weights())
    new_ec  = M.apcal.update_contract(M.dpe, mu, Sig, s)
    if not contract_regression(new_ec):
        return stub_and_red(s, "regression")
    if brc == "PASS":                                    # RBM：先复现后改动
        M.mreg.hot_replace_at_quiescence(M.dpe, new_ec, cert.boundary)
    bind_claims(cert, iota, receipts)
    return RepairCert2(iota, C, cert, brc, icc, M.bhc, receipts)

# IP-335 主闭环
def ServoGauge_round(M, obs, audio, tac, depth, det, ell=None):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s)

## 4. 推导

**引理 59（复现 e-process 的错误率与检测时延）** 零假设下 `P(∃t: E_t ≥ 1/α_rep) ≤ α_rep`（Ville），与检查次数 / 停止规则无关。若备择下见证均值偏移 `Δ>0`、次高斯参数 `σ`、取 `λ = Δ/σ²`（有界），则 `E[τ_stop] ≤ 2σ² log(1/α_rep)/Δ²`（至多常数因子）。故复现门的虚警与「发现漂移所需样本数」都能预注册。*证明骨架*：`exp(λw − λ²σ²/2)` 在 `H₀` 下是上鞅，Ville 给任意停时界；备择下漂移使对数 e-process 的期望增速为 `λΔ − λ²σ²/2`，取最优 `λ` 即得停止时间。由 E457 检验。

**引理 60（有界 Jacobian 误差下的伺服指数稳定）** 设 `‖L̂−L‖ ≤ ε_L`、`‖L⁺‖ = ℓ`、`ε_L ℓ < 1/2`。则 `L L̂⁺ = I + L(L̂⁺−L⁺)`，且 `‖L̂⁺−L⁺‖ ≤ ℓ²ε_L/(1−ε_Lℓ)`，故 `‖L L̂⁺ − I‖ ≤ ℓε_L/(1−ε_Lℓ) ≤ 2ℓε_L < 1`。取 `V = ½eᵀe`，沿 `ė = −λ L L̂⁺ e` 得 `V̇ ≤ −λ(1−2ℓε_L)‖e‖²`，指数收敛，速率 `λ(1−2ℓε_L)`。阈值 `ε_crit = 1/(2ℓ)` 由此给出；接近阈值时速率→0 而非突然发散，故工程上应留 2× 余量。由 E459 检验。

**引理 61（时延稳定性）** 对一阶伺服 `ė(t) = −λ e(t−τ)`，特征方程 `s + λ e^{−sτ} = 0` 的根实部全负当且仅当 `λτ < π/2`。故 `SVC` 的时延条件不能省；`λτ` 接近 `π/2` 时相位裕度→0。MIMO 情形用更保守的小增益充分条件 `λτ·‖L L̂⁺‖ < 1`。由 E460 检验。

**引理 62（陈旧窗口收缩与收益边界）** 开环 K 步内误差按 `‖e(t)‖ ≤ ‖e(0)‖e^{L_K t} + b` 增长；闭环把 `K_eff` 降到 `⌈(τ_lat+Δt_c)/Δt⌉`，误差由引理 60 的速率夹住。`G_K = K − K_eff > 0`，但**仅当** `ε_L`、`τ_lat` 满足引理 60/61 才成立；否则错误增益会使闭环误差增长快于开环，此时最优是退回 `K_eff = K`。这给出「闭环不是无条件更好」的可证伪边界。由 E461 检验。

**引理 63（共因误证上界）** 若 `C1,C2` 在共享失效 `Z=z` 下条件独立且各自通过概率 `p1,p2`，联合通过为 `p1p2`；但若二者由同一 `Z` 驱动（伺服残差由同一图像算出），联合通过 `= min(p1,p2) ≥ p1p2`。`κ_co` 正是该上界的度量；ICC 的第三通道 `W` 把上界降到 `min(p1p2, 1−P(W=FAIL|z))`。故**没有 ICC 时，联合通过不能当独立证据**——这把「循环论证」写成了不等式。由 E464 检验。

**引理 64（复现加权共形的覆盖分解）** 在给定 `θ` 下可交换、且 `ω` 反映 `θ` 的似然时：
`P(Y∉C) ≤ α + P(θ∉D_rep) + ½E|ω−1| + TV(P_θ, P_{θ₀})`。
四项分别是共形松弛、复现域逃逸、权重失配、域内漂移。对比 R3 未加权分层共形，后者在 `θ` 偏移时只能靠 `TV` 项兜底，覆盖可远低于 `1−α`。由 E465 检验。

**引理 65（基准健康与可追溯归约）** 若 `BHC` 保证 `drift_A ≤ δ_A`，则 `r_rep` 可分解为 `r_world + r_artifact` 且 `‖r_artifact‖ ≤ δ_A`；当 `r_rep > δ_rep + δ_A` 时可**排除**「纯基准老化」解释，判定世界漂移。反之若 `BHC=FAIL`，`r_rep` 的任何解释都不可靠，必须升级到 `A_std`。这把「基准老化伪装成世界漂移」从不可检测变为可分离。由 E466 检验。

**引理 66（复现周期的最优性与对偶）** 设漂移到达率 `h_θ`、单次复现成本 `c_rep`、漏检代价 `c_fail`，周期 `N` 的期望代价 `C(N) ≈ c_rep/N + c_fail·h_θ·N/2`，一阶条件给 `N* = sqrt(2c_rep/(c_fail h_θ))`。这与 R3 引理 53 的块长 `K*` 形式对偶（`c_rep ↔ c_d`，`c_fail h_θ ↔ ε c_f`）：**「多久复现一次」与「一次执行多长」是同一个摊销-风险交换在两个时间尺度上的实例**。由 E467 检验。

**引理 67（严格退化等价）** `BRG/CVS/ICC/WCC/BHC` 全关时，`ServoGauge-8C` 逐指令等价于 `InstructGauge-7C`；再关 `IAC` 退 `ToolGauge`；再关 `ToolGauge` 退 `LeanGauge`；再退 `MODGAUGE`。所有新增证书与 `claims` 均为纯投影，不改变数值路径。故本轮是**严格增强**而非替换。由 E471/E472 检验。

## 8. 本轮最大风险

**一句话**：复现门与伺服残差若共享同一个可错观测通道（同一台未标定相机 / 同一个磨损基准件），它们会**同向地**把系统性误差认证成「一致且收敛」——系统越自信、闭环越稳，越可能把一个错误基准稳定地驱动到错误目标；缓解只能依赖 ICC 的独立第三通道、BHC 的可追溯链与「无 ICC 禁不可逆」的硬规则，而真正的残余风险是「独立通道在部署现场是否可得」，得不到就必须在安全与可用之间被迫二选一。
