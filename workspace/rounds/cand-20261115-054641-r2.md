# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「轻量化结构」×「联邦学习」）

> R69 把不确定性一分为二，让机器人学会「问」：流匹配策略给出有形状的多模态动作，VoI 决定看/问/触，证据纪律防止被单次回答骗。但它留下两笔未付的账。**第一，这套东西太重**：多步 ODE、K=4 采样、Hutchinson 散度、冻结 LLM 解码，P99 2.6ms 的预算在真实边缘板上是绷紧的；要让「会问」成为出厂默认能力，必须能压进一颗廉价大脑。**第二，这套东西只在一个部署里学**：哪些模态真实存在、权重多大、人会不会撒谎，这些都要从大量机器人身上学；但交互证据——人脸、声音、提问记录、人的回答——恰恰是最不能上传的隐私数据。
>
> 本轮两个灵感正好对应这两笔账：**轻量化结构**回答「怎么把会问的大脑压小」，**联邦学习**回答「怎么让很多个它在不上传证据的前提下共同校准『问什么、信谁』」。
>
> 但危险恰在这里。R69 的全部收益押在「模态分布可信」上，而**压缩和联邦平均都是破坏模态分布的操作**：朴素蒸馏只保均值动作，会把两个近邻模态合并、把稀有模态删掉；朴素 FedAvg 在多模态策略上撞上**模态置换对称**——A 机器人的模态 1 与 B 机器人的模态 1 未必是同一个模态，跨置换平均会在两真模态之间凭空造出一个「幽灵模态」，或抹掉一个真模态。于是 R69 最怕的「幻觉模态诱发自信追问」，被压缩与聚合**系统性地、规模化地**制造出来。
>
> 核心命题：**把 R69 的模态层当作唯一需要被压缩、被联邦、被审计的对象。** 压缩不压轨迹细节，而保模式几何（原型、权重、间距、协方差）；联邦不平均速度场，而先做模态对齐（OT）再加权聚合；交互证据永不出本地，只有经 DP 加噪的模式摘要和证书上行。命名 **MOSAIC-RAS**（Mode-Ordered Structure-Aware federated Interactive Calibration）。运行时决策路径与 R69 **逐指令相同**——MOSAIC 只改「模式从哪来」，不改「模式怎么用」。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**很多个一起学的时候，这张便宜的副本、和这一群人，还看得见同一处歧义吗**」——不确定性不只是刹车、也不只是提问，它还是一个**可压缩、可共享、但其几何必须在压缩与平均下存活的物件**。

## 0. 直觉与动机

**灵感 1（轻量化结构 → 用「结构」本身做压缩原语）**
直觉：把大流模型蒸成小流模型，是在错的坐标系里压缩——学生为了降低平均动作误差，最容易牺牲的恰好是**低概率的少数模态**，而 R69 的 H_mode、Δ_min 全靠这些模态撑着。正确做法不是「小一号的速度场」，而是**显式的模式库**：K_B 个原型 + 权重 + 对角协方差 + 一个极小的单步残差速度场。轻量对象**就是** R69 需要的结构本身。这是率失真视角的重排：比特优先花在「有几个模态、各占多少、彼此多远」，而不是花在轨迹的高频细节上。

**灵感 2（联邦学习 → 模态置换是 FedAvg 在多模态策略上的原罪）**
直觉：多模态策略的模态没有天然编号。把两个客户端的速度场直接平均，等于把 A 的「绕左」和 B 的「绕右」当成同一个方向相加，得到一个谁也没想过的「直冲」；在密度上表现为两真模态之间出现一个**幽灵峰**。这不是数值噪声，是**对称性破缺没做**。因此联邦的第一步不是聚合，是**对齐**：在原型空间用最优传输/Hungarian 求置换，再对权重做鲁棒聚合、对原型做 Wasserstein 重心。对齐错了，后面越鲁棒越糟。

**灵感 3（结构保持蒸馏 → 决策误差由几何误差界住，而不是由动作 MSE 界住）**
直觉：我们真正在意的是「学生会不会把歧义看错」。VoI 是 (H_mode, Δ_min) 的函数，只要学生的模式几何与老师相差 ≤ ε_geo、且模态权重校准（ECE）过关，VoI 决策的后悔就有界；而动作 MSE 小并不蕴含几何小（两模态对称合并到中点，MSE 甚至更好）。所以蒸馏损失必须显式含**模式几何项**：模式集 OT 距离、权重 KL、Δ_min 与 H_mode 匹配、模态召回。轻量化由此从「精度换尺寸」变成「**用几何契约换尺寸**」。

**灵感 4（联邦 × 隐私 → 证据不出门，摘要才上行）**
直觉：交互证据（问句、回答、脸、声音、操作日志）是最敏感的数据，必须留在机器人本地。上行的只能是**模式摘要**：原型、权重、支撑数、似然分位数，且要 DP 加噪、小模态抑制（support 太小不上传——顺带挡掉单点幽灵）。这同时带来一个新风险：模式摘要本身会泄露成员信息（membership inference），所以「联邦」不是免费隐私，是有预算的隐私。

**灵感 5（联邦 × 投毒 → 幽灵模态可以被「串谋」伪装成有支撑）**
直觉：R69 担心人类撒谎；到了联邦，一个恶意客户端可以直接往全局库里**注入一个幽灵模态**，或压低一个真模态的权重。更糟的是**串谋**：几个客户端注入**同一个**幽灵原型，让「支撑投票」以为它被广泛证实。防御不能只看「多少人支持」，要看**支持的独立性**（来源/行为是否相关）+ 几何合理性（是否与既有模态在 Δ_min 内可疑重叠）+ 交互探针的答案一致性。R69 的「k 个正交证据源」由此升级为「k 个独立支撑源」。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（MOSAIC-RAS 总览）** MOSAIC-RAS = (FMP†, AUD†, MINT†, FLB, SPD, MAA, RBA, FMD, DPMS, VQA-F, J_MOSAIC)。三不变式：
(i) 运行时零学习写操作 + 决策路径与 R69 逐指令相同（继承 R69 定义 293-i 与定理 16）；
(ii) **离线/空闲写**：联邦只更新模式库，绝不进入实时控制环；运行时读一份冻结的 bank_version；
(iii) **几何契约**：任何部署的轻量学生必须通过模式几何证书（定义 314）才被允许驱动 MINT；不通过则退回本地 R69 / R68。

**定义 311（模式库 Mode Bank）** B = {(w_k, ξ̄_k, Σ_k, support_k, prov_k)}_{k=1}^{K_B}，其中 w_k 为权重（Σw=1）、ξ̄_k 为原型轨迹、Σ_k 为模态内协方差、support_k 为独立支撑源计数、prov_k 为来源哈希。B 是联邦共享对象，也是轻量学生的显式先验；体量 O(K_B·d)。

**定义 312（轻量代理 L-Student）** π_ℓ = (B, r_φ, mode_head_ℓ)，参数 ≤ P_max（默认 ≤ 老师 5%）。采样：k ~ w；ξ = ξ̄_k + Σ_k^{1/2}z + r_φ(z, k, o)（**单步**），不再多步 ODE。显式模态 + 单步残差是「结构即压缩」的落地。

**定义 313（结构保持蒸馏 SPD）** L_SPD = L_task + α·L_mode + β·L_cal，其中 L_mode = W_2²(混合高斯模式集) + KL(w^T‖w^S) + |Δ_min^T−Δ_min^S|/Δ_min^T + |H_mode^T−H_mode^S|；L_cal 为 ECE 代理。关键：不以平均动作 MSE 为主项（它会主动合并/删除模态）。

**定义 314（模式几何证书）** 对 (π^T, π^S)：G = (W_mode, ΔΔ_min/Δ_min, mode_recall, ECE)。Valid ⇔ W_mode ≤ ε_geo ∧ |ΔΔ_min|/Δ_min ≤ ρ_geo ∧ mode_recall ≥ 1−ε_r ∧ ECE ≤ τ_ece。仅 Valid 学生可驱动 MINT；否则退化（定义 324）。

**定义 315（DP 模式摘要 DPMS）** 客户端 c 本地得 B_c，计算摘要 S_c = (原型, 权重, 支撑, a_score 分位, 几何统计)，以 (ε_dp, δ_dp)-DP 加噪，support_k < s_min 的模态**不上传**（小模态抑制）。原始交互证据永不出本地。

**定义 316（模式对齐 MAA）** 以参考库 B^{ref}（上一轮全局库或服务器锚点）为准，求置换 π_c = argmin_{π} Σ_k W_2²(ξ̄_k^c, ξ̄_{π(k)}^{ref})（Hungarian / 熵正则 OT）；原型聚合用 W_2 重心，权重在对齐后聚合。对齐是聚合的前置条件，不是后处理。

**定义 317（鲁棒拜占庭聚合 RBA）** 对齐后：权重用坐标修剪均值/中位数；原型用 W_2 几何中位数；模式入全局库需 support_k ≥ m 且来自 ≥ m 个**独立**来源。恶意客户端 < f 时给出全局权重/原型误差上界（定理 19）。

**定义 318（幽灵模态检测 FMD）** phantom_score(k) = f(独立支撑数, 跨客户端原型散度, 与既有模态的可疑重叠, 交互探针答案一致性)。分数越界 ⇒ 降权/驱逐，且**禁止 MINT 花预算去追问该模态**——绝不把交互预算投给一个没有独立支撑的假设。

**定义 319（联邦证据纪律）** 全局模态只是**假设**，不是证据；跨客户端支撑只能作为结构先验，不能替代本地的 k 个正交答案。严禁把「很多人也这么以为」洗成「已证实」。

**定义 320（全局-局部分解）** w_k^c = softmax(g_k + h_k^c)：g_k 为全局任务族先验（联邦），h_k^c 为本地传感器/人类校准（本地）。全局管「有哪些模态」，本地管「这台机器上它有多大概率」。

**定义 321（联邦审计 VQA-F）** 客户端本地审计交互决策（继承 R69 VQAuditor-I）；服务器审计**贡献**：某客户端的库是否在不抬高 phantom_score、不劣化全局几何/校准的前提下改善全局。贡献被证明有害的客户端降权；证书哈希链，支持安全聚合。

**定义 322（证书 J_MOSAIC）** J_MOSAIC = (J_FLUID, G, ε_dp_spent, alignment_perm_hash, support_vector, phantom_p95, bank_version)。Valid ⇔ Valid(J_FLUID) ∧ G.Valid ∧ DP 预算未超 ∧ phantom_p95 ≤ τ_ph。

**定义 323（运行时安全继承）** 运行时只读冻结 bank，走 R69 的 FMP/AUD/MINT/CIA/FMA；MOSAIC 不改变 R69 定理 16/17 的任何前提，故其安全/无突变结论逐条保持。

**定义 324（退化路径 FIFO）** 几何证书失败 / DP 预算耗尽 / 幻影可疑 / 客户端未认证 ⇒ 该客户端运行**本地未认证 R69**（不弱于 R68）或 R68 纯保守；联邦整体关闭时仍可独立运行。R68 是最内层边界。

**定义 325（通信/计算预算）** 每轮上行/下行 ≤ b_max（摘要体量），本地计算 ≤ 边缘预算，允许异步（陈旧度 ≤ τ_stale）。聚合对象是库，不是梯度。

**定义 326（组合攻击：串谋幽灵 + 隐私推断）** 新对抗面：多个客户端注入**同一**幽灵原型使支撑投票失真；或对上传摘要做成员推断。防御：独立支撑（provenance/行为相关度）+ 几何合理性 + 交互探针 + DP + 支撑阈值。

## 2. 关键算法骨架

```python
# IP-264 ModeBank：显式模式库（既是联邦对象，也是轻量学生的先验）
class ModeBank:
    def __init__(self, K_B): self.w, self.mu, self.cov, self.sup, self.prov = ...
    def sample(self, k=None):                        # O(K_B) 采样，无 ODE
        k = sample_categorical(self.w) if k is None else k
        return self.mu[k] + chol(self.cov[k]) @ randn(d)
    def entropy(self): return -sum(w * log(w) for w in self.w)
    def delta_min(self): return min_w2_dist(self.mu) / sqrt(max_trace(self.cov))

# IP-265/266 L-Student + 结构保持蒸馏 SPD
class LightStudent:
    def __init__(self, bank: ModeBank, r_phi, mode_head):
        self.bank, self.r, self.h = bank, r_phi, mode_head   # 参数 <= 5% 老师

    def sample(self, o_t):
        k = sample_categorical(self.bank.w)              # 显式模态
        return self.bank.mu[k] + chol(self.bank.cov[k]) @ randn(d) + self.r(randn(d), k, o_t)  # 单步

def spd_loss(teacher, student, batch):
    L_task = task_loss(student, batch)                   # 不以它为唯一主项
    L_mode = w2_mixture(teacher.modes, student.bank) \
           + kl(teacher.w, student.bank.w) \
           + abs(teacher.delta_min - student.bank.delta_min) / teacher.delta_min \
           + abs(teacher.H_mode - student.bank.entropy())
    L_cal  = ece_surrogate(student, batch)
    return L_task + ALPHA * L_mode + BETA * L_cal

# IP-267 DPMS：本地算摘要，DP 加噪，小模态抑制
def dp_summary(local_bank, eps_dp, delta_dp, s_min):
    keep = [k for k in local_bank if local_bank.sup[k] >= s_min]  # 小模态不出门
    noisy_w  = clip_and_noise(local_bank.w[keep], eps_dp, delta_dp)
    noisy_mu = [add_gaussian(local_bank.mu[k], sigma(eps_dp, delta_dp)) for k in keep]
    return Summary(noisy_mu, noisy_w, prov_hash=hash(local_bank))

# IP-268/269 MAA + RBA：先对齐（置换），再鲁棒聚合
def mosaic_aggregate(summaries, ref_bank, f_byz):
    aligned = []
    for s in summaries:
        perm = hungarian([w2_sq(mu, r) for mu in s.mu for r in ref_bank.mu])  # 模态对齐
        aligned.append(apply_perm(s, perm))
    w_global = trimmed_mean([a.w for a in aligned], f_byz)      # 权重鲁棒聚合
    mu_global = [wasserstein_barycenter([a.mu[k] for a in aligned]) for k in range(K_B)]
    support   = independent_support(aligned)                    # 独立来源计数，非简单票数
    return ModeBank(w_global, mu_global, ..., sup=support)

# IP-270 FMD：幽灵模态检测（永不追一个无独立支撑的假设）
def phantom_score(bank, summaries, probe_answers):
    for k in bank:
        disp  = cross_client_dispersion(summaries, k)
        over  = overlap_with_existing(bank.mu[k], bank.mu, exclude=k)
        agree = answer_consistency(probe_answers, k)
        score[k] = fuse(bank.sup[k], disp, over, agree)
    return score

# IP-274 MOSAIC：离线联邦（写库）与在线 R69（用库）严格分离
def MOSAIC_offline(clients, ref_bank):
    summaries = [dp_summary(c.local_bank, EPS, DELTA, S_MIN) for c in clients]
    bank = mosaic_aggregate(summaries, ref_bank, F_BYZ)
    ph   = phantom_score(bank, summaries, run_probes(bank))
    bank = evict_or_downweight(bank, ph, TAU_PH)               # 幽灵降权/驱逐
    return bank, J_MOSAIC(bank, ph, ...)

def MOSAIC_round(M, obs):                                       # 在线：与 R69 逐指令相同
    bank = M.bank_frozen                                      # 只读冻结库
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K, prior=bank)                  # 先验来自库
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_calibrated)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    g = (M.mint.choose_interaction(modes, o, M.budget)
         if (U_epi > TAU_EPI and not slow and not M.fmd.blocked(modes)) else None)
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if slow: lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, U_cal))
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
```

## 3. 推导

**引理 19（几何误差界住决策后悔）** 设学生与老师的模式集满足定义 314 的 G，且 Δ_min ≥ 3σ_in（R69 A95）。则对任意状态，基于学生模态分布计算的 VoI 与老师之差 ≤ L_V·(W_mode + |ΔΔ_min|/Δ_min + |ΔH_mode|)，其中 L_V 为 VoI 对 (H_mode, Δ_min) 的 Lipschitz 常数。⇒ **压缩的损害由几何误差界定，而非由动作 MSE 界定**：一个动作 MSE 很小但合并了两模态的学生，可以在几何证书上明显失败、被拒绝上岗。

**引理 20（跨置换平均制造幽灵模态）** 设两客户端各为单模态、原型 ξ_A、ξ_B，Δ = ‖ξ_A−ξ_B‖。朴素 FedAvg 的速度场等价于对两模态做等权混合，其密度在连接 ξ_A、ξ_B 的测地线中点存在额外质量，且 W_2²(平均分布, 真并分布) ≥ c·Δ²（c>0）。即：**不对齐的聚合至少以 Δ² 的量级制造一个两真模态之间的幽灵峰**——Δ 越大（歧义越明显），幽灵越靠中、越像一个「合理的折中动作」。

**引理 21（对齐后聚合的收缩）** 在 MAA 对齐正确且客户端异质性有界（本地原型离参考 ≤ δ_h）时，W_2 重心原型的误差 ≤ δ_h/√C + 估计噪声，权重误差由 RBA 的修剪界给出。对齐是充分条件：若置换估错一對，误差下界回到引理 20 的 c·Δ²。

**引理 22（几何证书的可检验性与隐私张力）** G 可由一小份公开探针集上的抽样估计，估计误差 O(1/√n_probe)；但探针集若与客户端分布相关会泄露信息，故探针必须跨客户端共享且与训练数据去相关——**可认证性与隐私在这里天然对立**，需要独立探针预算。

**定理 18（MOSAIC 严格包含 R69 与 R68）** 运行时路径与 R69 逐指令相同（定义 323），故 R69 定理 16/17 的风险上界与无突变结论不变；当几何证书失败/DP 耗尽/幽灵可疑/未认证时 FIFO 退化为本地 R69 或 R68（定义 324）。因此任意状态下 MOSAIC 的安全侧不弱于 R69，R68 是「不联邦」边界。

**定理 19（拜占庭 + 幽灵上界）** 设客户端数 C、恶意 < f，支撑投票要求来自 ≥ m 个**独立**来源，权重用坐标修剪均值、原型用 W_2 几何中位数。则全局权重误差 ≤ O(f/C + DP 噪声)，任何未被 ≥ m 个独立源支持的幽灵模态的全局权重 ≤ 1/(m+1)（驱逐后为 0）；MINT 追到幽灵模态的概率 ≤ δ_ph（由定义 318 的 blocked 门控与定理 18 的退化共同保证）。

**定理 20（DP 隐私-效用）** (ε_dp, δ_dp)-DP 的模式摘要使模式权重误差达到 O(√(log(1/δ_dp))/(ε_dp·s_min))，原型加噪使 Δ_min 的估计偏差 ≤ O(σ_dp/Δ_min)；只要 ε_dp 使该偏差 ≤ ρ_geo 预算，几何证书仍可满足。原始交互证据零上传 ⇒ 成员推断优势 ≤ e^{ε_dp}−1（标准 DP 界）。**结论：隐私不是免费的，它直接消耗几何预算**。

## 6. 本轮最大风险

**一句话**：MOSAIC-RAS 把「问得对」押在**不共享原始数据也能把模态对齐对**这一前提上——一旦客户端高度异构或存在串谋，OT 对齐的参考锚点与置换本身就可能错位，而鲁棒聚合仍会产出一个几何上自洽、语义上错误的全局模式库；轻量学生又会**忠实地**把这个错误几何压缩下来、逐指令复用——**压缩与联邦合谋，让「问错」变得又便宜又一致**。

**次级风险与缓解**：
1. **DP 噪声吃掉 Δ_min**（近邻模态被噪声合并，对齐失败）→ 支撑阈值 + 自适应 ε_dp + 几何证书在噪声下重新标定（定理 20）；
2. **串谋幽灵伪装支撑** → 独立支撑（provenance/行为相关度）+ 几何合理性 + 交互探针（定义 318、定理 19）；
3. **对齐锚点被单个坏参考带偏** → 多锚点投票 + 以历史全局库为参考 + 置换置信门控；
4. **几何探针泄露/漂移** → 独立探针预算 + 去相关采样（引理 22）；
5. **全局-局部冲突（负迁移）** → 局部 head 可完全覆盖全局先验，FIFO 退化为本地 R69（定义 324）。

## 4. 推导

**引理 19（几何误差界住决策后悔）** A95（`Δ_min ≥ 3σ_in`）下，学生对老师的模式几何误差（`W_mode`, `ΔΔ_min/Δ_min`, `ΔH_mode`）经 VoI 的 Lipschitz 常数 `L_V` 界住决策后悔：`|VoI_S − VoI_T| ≤ L_V·(W_mode + |ΔΔ_min|/Δ_min + |ΔH_mode|)`。**压缩损害由几何误差界定，而非动作 MSE**——MSE 小但合并两模态的学生会在证书上失败。

**引理 20（跨置换平均制造幽灵）** 两客户端单模态原型 `ξ_A, ξ_B`，`Δ=‖ξ_A−ξ_B‖`。朴素 FedAvg 等价等权混合，在测地线中点生成额外质量，且 `W_2²(平均, 真并) ≥ c·Δ²`。⇒ 不对齐的聚合至少以 `Δ²` 制造两真模态间的幽灵峰；`Δ` 越大，幽灵越像「合理折中」。

**引理 21（对齐后聚合收缩）** MAA 对齐正确且异质性有界（`≤ δ_h`）时，`W_2` 重心误差 `≤ δ_h/√C + 噪声`；一旦置换估错一对，误差下界回到 `c·Δ²`（引理 20）。

**引理 22（证书可检验性与隐私张力）** `G` 可由共享、去相关的公开探针集估计，误差 `O(1/√n_probe)`；探针若与客户端分布相关则泄露信息，故**可认证性与隐私天然对立**，需独立探针预算。

**定理 18（严格包含 R69/R68）** 运行时逐指令同 R69 ⇒ 定理 16/17 保持；证书失败/DP 耗尽/幽灵可疑/未认证 ⇒ FIFO 退本地 R69 或 R68。任意状态安全侧不弱于 R69，R68 = 「不联邦」边界。

**定理 19（拜占庭 + 幽灵上界）** 恶意 `< f`、独立支撑 + 修剪均值 + `W_2` 几何中位数下，全局权重误差 `≤ O(f/C + DP 噪声)`；未被 `≥ m` 独立源支持的幽灵权重 `≤ 1/(m+1)`（驱逐后 0），MINT 追到幽灵概率 `≤ δ_ph`。

**定理 20（DP 隐私-效用）** `(ε_dp, δ_dp)`-DP 摘要使权重误差 `O(√(log(1/δ_dp))/(ε_dp·s_min))`、`Δ_min` 估计偏差 `O(σ_dp/Δ_min)`；原始证据零上传 ⇒ 成员推断优势 `≤ e^{ε_dp}−1`。**隐私直接消耗几何预算**。

## 7. 本轮最大风险

**一句话**：MOSAIC-RAS 把「问得对」押在**不共享原始数据也能把模态对齐对**这一前提上——客户端高度异构或遭串谋时，OT 对齐的参考锚点与置换本身就可能错位，而鲁棒聚合仍产出几何自洽、语义错误的全局库；轻量学生又**忠实**压下这个错误几何并逐指令复用——**压缩与联邦合谋，让「问错」变得又便宜又一致**。

**次级风险与缓解**：DP 噪声吃掉 Δ_min（支撑阈值 + 自适应 ε_dp + 噪声下重标证书）；串谋幽灵（独立支撑 + 几何合理性 + 交互探针，定理 19）；对齐锚点被坏参考带偏（多锚点投票 + 历史参考 + 置换置信门控）；探针泄露/漂移（独立探针预算 + 去相关采样，引理 22）；全局-局部负迁移（局部 head 可覆盖先验，FIFO 退本地 R69）。
