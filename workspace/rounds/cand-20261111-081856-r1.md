# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「模型蒸馏」×「移动操作」）

> 第 54 轮把技能组合推进为「动作剖面 α_S + 云边协同 γ_ce + 动作-鲁棒性联合证书 J」。本轮引入 **模型蒸馏** 与 **移动操作**：蒸馏不再被视为「把大模型压小」的工程手段，而是把云端技能及其证书 **编译** 到边端学生的过程；移动操作则暴露了蒸馏最危险的盲区——基座运动使教师（常在静态基座或仿真先验下训练）与边端真实部署分布系统性错位。核心矛盾：H22：蒸馏以平均动作误差为目标，而移动操作的鲁棒性损失集中发生在接触瞬间、关节极限、高速基座运动等低概率尾部区域；H23：教师证书在蒸馏后不自动成立，学生可能继承「平均能力」却丢失「尾部鲁棒性」，使证书从证据退化为假设。

## 0. 直觉与动机

**灵感 1（蒸馏 = 证书编译器，而非能力压缩器）**
直觉：第 54 轮的云边映射 `γ_ce` 是手工/解析的；本轮把它升级为 **学习得到的蒸馏编译器** `Π_dist: (π_T, ρ_T, A_cert_T) → (π_S, ρ_S, A_cert_S)`。普通蒸馏只对齐动作 `π_S≈π_T`，而证书编译器还必须对齐 **鲁棒性谱 ρ** 与 **动作占用证书 A_cert**。只对齐动作的后果是：学生在「平均动作」像教师，却在教师本就脆弱的动作区更脆弱——鲁棒性被蒸馏掉了，而账面上看不出来。

**灵感 2（移动操作的动作空间是耦合的，漂移不均匀）**
直觉：移动操作动作 `a=(v_b, q, g)`，基座速度 `v_b` 改变机械臂可达性、接触几何与动力学。教师若在静态基座数据上训练，教师状态分布 `p_T(s|a)` 与部署分布 `p_D(s|a)` 的差异 `Δ_mob(a)` 在 **高速基座、伸展构型、接触瞬间** 处最大。故蒸馏保真度不能是一个标量精度，而应是动作空间上的 **剖面 β(a)**，与第 54 轮 `α_S(a)` 同构，两者相乘才构成「真实可继承的能力」。

**灵感 3（证书保持蒸馏：没有免费的鲁棒性）**
直觉：学生证书必须由教师证书 **保守扣除蒸馏退化** 得到：`ρ_S(d) ≥ ρ_T(d) - ε_ρ(d)`，且只在保真度足够高的动作子域上继承。任何「学生比教师更鲁棒」的宣称都必须有独立证据，不能由蒸馏自动推出。这把第 54 轮的联合证书 J 扩展为 **蒸馏联合证书 `J_dist`**，其 evidence 必须包含「教师证书引用 + 保真剖面 + 移动漂移」。

**灵感 4（难动作挖掘：把蒸馏预算花在尾部）**
直觉：均匀采样蒸馏把算力浪费在师生都很稳的「简单动作」上。应优先在 **低 β、高 `∂ρ/∂a`、高 `Δ_mob`** 的动作区采样与蒸馏（hard action mining），等价于对鲁棒性谱尾部做主动覆盖。这与第 54 轮的主动剖面采样同一方法论，但目标从「覆盖」变为「保真」。

**灵感 5（移动操作的整体耦合：动作对了不等于能执行）**
直觉：移动操作技能不能只由手臂动作描述，还需 `C_mob = (可操作度椭球, 支撑/稳定裕度, 接触力锥可行裕度)`。基座运动若使可操作度低于阈值或破坏接触锥，即使蒸馏动作误差很小，技能也**不可执行**。因此蒸馏必须在移动耦合可行域内进行，证书也必须在 `A_mm^feas` 上声明。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（移动操作动作空间与耦合可行域）**
移动操作动作 `A_mm = T_b × Q_arm × G`，`a=(v_b,q,g)`，其中 `T_b` 为基座旋量、`q` 为手臂构型、`g` 为抓取参数。整体雅可比 `J_wb(q)`，可操作度 `w(q)=sqrt(det(J_wb J_wb^T))`，接触力锥 `F(q,g)`，稳定裕度 `m(a)`。**耦合可行域**
```
A_mm^feas = { a | w(q) ≥ w_min, m(a) ≥ m_min, F(q,g) ⊆ FC(a), ||v_b||_∞ ≤ v_max }
```
`FC(a)` 为接触约束允许的力锥。只有 `a∈A_mm^feas` 的动作才允许作为证书的 `A_core`。

**定义 122（移动诱发分布漂移）**
教师分布 `p_T(·|a)`（训练时基座/场景先验）与部署分布 `p_D(·|a)` 的漂移
```
Δ_mob(a) = D_f( p_D(·|a) || p_T(·|a) ) · κ(a)
```
`D_f` 为 f-散度（实现用配对仿真的状态/接触统计），`κ(a)` 为基座运动强度因子。取 `Δ_mob(a) = E_{s~p_D}[ d_s( w(q), contact, m ) ]` 作为可计算代理。漂移在 `A_mm^feas` 边界处最大。

**定义 123（蒸馏保真剖面）**
教师 T 与学生 S 的蒸馏保真剖面 `β_{T→S}: A_mm → [0,1]`
```
β_{T→S}(a) = exp( -λ_a · E_{s~p_D(·|a)}[ d_π(π_T(s),π_S(s)) ] - λ_ρ · |ρ_T(a) - ρ_S(a)| )
```
`d_π` 为归一化动作距离。**可继承域** `A_β(θ) = { a ∈ A_mm^feas | β_{T→S}(a) ≥ θ }`。β 与 α 的关系：真实可继承动作占用为 `α_S^dist(a) = α_S(a) · β(a)`，这是第 54 轮 `α_S` 的蒸馏修正。

**定义 124（证书保持蒸馏 CPT）**
学生 S 在域 `A_core_T` 上相对教师 T 是 `(θ_β, ε_ρ)`-**证书保持** 的，若：
```
(i)  A_core_S ⊇ A_core_T ∩ A_β(θ_β)                    （继承而非缩水的动作核心）
(ii) ∀d: ρ_S(d) ≥ ρ_T(d) - ε_ρ(d),  ε_ρ(d)=sup_{a∈A_core_T} (1-β(a))·L_ρ(d)  （鲁棒性保守扣除）
(iii) ∀a∈A_core_T∩A_β(θ_β): cover(S,a) 成立且 C_mob(a) 可行 （动作与耦合双可行）
```
其中 `L_ρ(d)` 为鲁棒性对动作扰动的 Lipschitz 常数。条件 (ii) 是「无免费鲁棒性」原则的形式化：学生证书只能从教师证书**减去**蒸馏退化，不能凭空增加。

**定义 125（蒸馏联合证书）**
```
J_dist = (ρ_S, α_S^dist, A_cert_S, β, Δ_mob, teacher_ref, δ_dist, C_mob, evidence)
```
- `teacher_ref`：被蒸馏教师证书的哈希与版本，保证可追溯；
- `δ_dist`：蒸馏对齐误差，`δ_dist = max_{a∈A_core_S} min(1-β(a), Δ_mob(a))`；
- `C_mob`：定义 127 的移动耦合证书；
- `evidence`：保真剖面采样记录、移动漂移配对仿真、教师原始证书。
判定：`dom_{J_dist}(T)=in` 当且仅当 `β(a)≥θ_β ∀a∈A_core_S`、`Δ_mob(a)≤Δ_max`、`ρ_S(d)≥ρ_min ∀d`、且 `C_mob` 可行。

**定义 126（蒸馏感知技能组合）**
两技能的蒸馏感知兼容性
```
compat_dist(S_i,S_j) = ∫ min(α_i β_i, α_j β_j) da / ∫ max(α_i β_i, α_j β_j) da
```
组合链的保真度按 `β_chain = min_k β_k`（最弱环节），鲁棒性按第 53 轮 `compose_robustness` 后再扣除 `Σ_k ε_ρ^{(k)}`。于是第 54 轮组合图的边权由 `(compat, c_trans, ρ_comp)` 升级为 `(compat_dist, c_trans, ρ_comp - Σε_ρ, β_chain)`。

**定义 127（移动耦合证书）**
```
C_mob = ( w(q), m(a), cone_slack(a), phase(v_b,q) )
```
`cone_slack` 为接触力锥的剩余裕度，`phase` 为基座-手臂运动相位一致性（避免基座运动与手臂补偿同相放大）。组合与部署要求 `C_mob(a)∈C_mob^feas`，且当 `v_b` 超过阈值时强制降速或切换「停基座-再操作」的相位策略。

## 2. 关键算法 伪代码

### IP-121 DFP（Distillation Fidelity Profiling）

```python
def fidelity_profile(teacher, student, A_probe, sim, lam_a, lam_rho):
    beta = {}
    for a in A_probe:
        d_pi, d_rho = 0.0, 0.0
        for s in sim.rollout_paired(teacher, student, a, drift=True):
            d_pi  += action_distance(teacher.act(s), student.act(s))
            d_rho += abs(teacher.rho[a] - student.rho[a])
        n = max(1, sim.n_paired)
        beta[a] = math.exp(-lam_a*d_pi/n - lam_rho*d_rho/n)
    return beta
```

### IP-122 HAM（Hard Action Mining）

```python
def hard_action_mining(beta, rho_grad, drift, budget):
    score = {a: (1.0 - beta.get(a,0.0)) * rho_grad.get(a,0.0)
                * (1.0 + drift.get(a,0.0)) for a in beta}
    return sorted(score, key=score.get, reverse=True)[:budget]
```

### IP-123 MDC（Mobile-aware Distillation Compiler）

```python
def distill_with_certificate(T, A_core, theta_beta, theta_a, budgets):
    S = init_student(T)
    beta = {a: 1.0 for a in A_core}
    drift = estimate_mobility_drift(A_core, sim)          # 定义 122
    for it in range(budgets.rounds):
        hard = hard_action_mining(beta, rho_grad(T), drift, budgets.mine)
        probe = uniform(A_core, budgets.cover) + hard
        S = distill_step(S, T, probe, weights=1.0 - beta)  # 向低保真区加权
        beta = fidelity_profile(T, S, probe, sim, 1.0, 1.0)
        A_core = {a for a in A_core
                  if beta[a] >= theta_beta and feasible_mobile(a)}  # 定义 121
    rho_S = certify_robustness(S, A_core)
    eps = {d: max((1.0-beta[a])*L_rho[d] for a in A_core) for d in dims}
    delta = max(min(1.0-beta[a], drift[a]) for a in A_core)
    if delta > budgets.delta_dist or any(rho_S[d] < rho_min for d in dims):
        return ('reject', 'certificate_not_preserved', eps, delta)
    return ('ok', S, J_dist(rho_S, A_core, beta, drift, T.cert, delta))
```

### IP-124 DSC（Distilled Skill Composition）

```python
def compose_distilled(skills, theta_a, beta_min, K):
    G = nx.DiGraph()
    for i, s1 in enumerate(skills):
        for j, s2 in enumerate(skills):
            if i == j: continue
            a1 = {a: s1.alpha[a]*s1.beta[a] for a in s1.alpha}
            a2 = {a: s2.alpha[a]*s2.beta[a] for a in s2.alpha}
            compat = weighted_jaccard(a1, a2)          # 定义 126
            if compat >= theta_a and min(s1.beta_min, s2.beta_min) >= beta_min:
                rho = compose_robustness(s1.rho, s2.rho, K)
                rho = subtract_degradation(rho, s1.eps, s2.eps)
                G.add_edge(i, j, compat=compat,
                           cost=cost_align(s1, s2), rho_comp=rho,
                           beta_chain=min(s1.beta_min, s2.beta_min))
    path, cost = a_star(G, start='root', goal=task_desc)
    return path, cost, chain_certificate(path, G)
```

### IP-125 MCG（Mobile Coupling Gate）

```python
def mobile_gate(a, C_mob, v_threshold):
    if not (C_mob.w >= w_min and C_mob.margin >= m_min
            and C_mob.cone_slack >= 0):
        return ('reject', 'coupling_infeasible', C_mob)
    if norm(a.v_b) > v_threshold and C_mob.phase != 'decelerate_or_stop':
        return ('reject', 'base_arm_phase_mismatch', C_mob.phase)
    return ('ok', a)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| DFP | O(|A_probe|·N_pair·C_roll) | O(|A_probe|) | 配对仿真同初态、漂移覆盖 |
| HAM | O(|A_probe| log |A_probe|) | O(|A_probe|) | 打分单调、尾部可发现 |
| MDC | O(R·(|A_probe|·N_pair + |A_core|·|S|)) | O(|A_core|+|S|) | β 校准、ε_ρ 上界 sound |
| DSC | O(|S|²·|A| + |E|) | O(|S|²) | compat_dist 阈值 sound、退化可加 |
| MCG | O(|A|·(cost J_wb + cone)) | O(1) | 耦合可行域判定完备 |

**正确性定理（Certificate-Preserving Distillation Soundness）**
假设第 53/54 轮 (A22)–(A28) 成立；**(A29)** `β` 在 `A_core` 上由配对仿真校准，覆盖 ≥ 1-δ_β；**(A30)** 移动漂移对动作局部 Lipschitz，`Δ_mob ≤ Δ_max`；**(A31)** 教师证书 `teacher_ref` 本身 sound；**(A32)** `C_mob` 判定在采样网格上完备。则边端学生部署成功概率：
```
P_success(S) ≥ 1 - Σ_d(1-ρ_T(d)) - Σ_d ε_ρ(d) - P(β<θ_β 于 A_T)
                 - P(Δ_mob>Δ_max) - P(C_mob infeasible) - δ_β
```
关键：教师鲁棒性只在 `β≥θ_β` 的动作子域上可继承，且继承时必须扣除 `ε_ρ` 与移动漂移；证书的 soundness 是**条件性**的，不能把教师证书直接复制给学生。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 保真剖面在尾部分辨率不足 | 高 | 配对仿真 + 难动作主动采样 + 分箱置信区间 |
| 移动漂移随场景 OOD 放大 | 高 | 场景分层漂移上界 + 在线漂移监测 + 保守降速 |
| 证书退化项 ε_ρ 低估 | 高 | Lipschitz 上界 + 反例搜索 + 三重冗余证据 |
| 难动作挖掘过拟合少数场景 | 中 | 场景重加权 + 留出集尾部验证 |
| 移动耦合门控误拦截 | 中 | 软约束 + 回滚相位策略 + 人工复核样本 |

## 6. 本轮最大风险

**一句话**：把蒸馏当作「证书编译器」能让学生继承教师的动作与鲁棒性，但其 soundness 依赖 **保真剖面 β 在尾部的可测性、移动漂移 Δ_mob 的有界性、以及 ε_ρ 退化的保守估计**；一旦 β 在接触/极限/高速基座区域欠采样而被高估，学生就会拿到一张「看起来可继承、实际已失真」的证书，在尾部工况系统性失效且无法被账面指标发现，故必须以 **配对仿真难动作采样 + 漂移在线监测 + ε_ρ 反例审计** 三重护栏，宁可拒绝继承，也不让教师证书在蒸馏中被悄然伪造。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（MDC×DFP×CPT×HAM×DSC×MCG）

> 承接第 54 轮产物 v31（ACS×SCOM×CEC×AEC×JTC）。本轮在「动作-鲁棒性双证书」之上，增加 **证书保持蒸馏** 与 **移动操作耦合** 两大算子族：

## 2. 关键算法 伪代码

### IP-121 DFP

```python
def fidelity_profile(teacher, student, A_probe, sim, lam_a, lam_rho):
    beta = {}
    for a in A_probe:
        d_pi = d_rho = 0.0
        for s in sim.rollout_paired(teacher, student, a, drift=True):
            d_pi  += action_distance(teacher.act(s), student.act(s))
            d_rho += abs(teacher.rho[a] - student.rho[a])
        n = max(1, sim.n_paired)
        beta[a] = math.exp(-lam_a*d_pi/n - lam_rho*d_rho/n)
    return beta
```

### IP-124 HAM

```python
def hard_action_mining(beta, rho_grad, drift, budget):
    score = {a: (1.0-beta.get(a,0.0))*rho_grad.get(a,0.0)
                *(1.0+drift.get(a,0.0)) for a in beta}
    return sorted(score, key=score.get, reverse=True)[:budget]
```

### IP-122/123 MDC + CPT

```python
def distill_with_certificate(T, A_core, theta_beta, budgets):
    S = init_student(T)
    beta = {a: 1.0 for a in A_core}
    drift = estimate_mobility_drift(A_core, sim)
    for _ in range(budgets.rounds):
        hard = hard_action_mining(beta, rho_grad(T), drift, budgets.mine)
        probe = uniform(A_core, budgets.cover) + hard
        S = distill_step(S, T, probe, weights=1.0-beta)
        beta = fidelity_profile(T, S, probe, sim, 1.0, 1.0)
        A_core = {a for a in A_core
                  if beta[a] >= theta_beta and feasible_mobile(a)}
    rho_S = certify_robustness(S, A_core)
    eps = {d: max((1.0-beta[a])*L_rho[d] for a in A_core) for d in dims}
    delta = max(min(1.0-beta[a], drift[a]) for a in A_core)
    if delta > budgets.delta_dist or any(rho_S[d] < rho_min for d in dims):
        return ('reject', 'certificate_not_preserved', eps, delta)
    return ('ok', S, J_dist(rho_S, A_core, beta, drift, T.cert, delta))
```

### IP-125 DSC

```python
def compose_distilled(skills, theta_a, beta_min, K):
    G = nx.DiGraph()
    for i, s1 in enumerate(skills):
        for j, s2 in enumerate(skills):
            if i == j: continue
            a1 = {a: s1.alpha[a]*s1.beta[a] for a in s1.alpha}
            a2 = {a: s2.alpha[a]*s2.beta[a] for a in s2.alpha}
            compat = weighted_jaccard(a1, a2)
            if compat >= theta_a and min(s1.beta_min, s2.beta_min) >= beta_min:
                rho = compose_robustness(s1.rho, s2.rho, K)
                rho = subtract_degradation(rho, s1.eps, s2.eps)
                G.add_edge(i, j, compat=compat, cost=cost_align(s1, s2),
                           rho_comp=rho, beta_chain=min(s1.beta_min, s2.beta_min))
    return a_star(G, start='root', goal=task_desc)
```

### IP-127 JDC

```python
def issue_joint_distill_certificate(S, T, A_core, beta, drift, delta_budget, rho_min):
    eps = {d: max((1.0-beta[a])*L_rho[d] for a in A_core) for d in dims}
    rho_S = {d: T.rho[d] - eps[d] for d in dims}     # 保守继承
    if any(rho_S[d] < rho_min for d in dims):
        return ('reject', 'robustness_below_floor', rho_S)
    delta = max(min(1.0-beta[a], drift[a]) for a in A_core)
    if delta > delta_budget:
        return ('reject', 'drift_budget_exceeded', delta)
    A_cert = (intersection([a for a in A_core if beta[a] >= theta_beta]),
              buffer_zone(A_core, delta))
    return ('ok', J_dist(rho_S, A_cert, beta, drift, T.cert_ref, delta))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DFP | O(|A_probe|·N_pair·C_roll) | O(|A_probe|) | 配对同初态，漂移覆盖 |
| HAM | O(|A_probe| log |A_probe|) | O(|A_probe|) | 尾部打分单调可发现 |
| MDC | O(R·(|A_probe|·N_pair+|A_core|·|S|)) | O(|A_core|+|S|) | β 校准、ε_ρ 上界 sound |
| DSC | O(|S|²·|A|+|E|) | O(|S|²) | compat_dist sound、退化可加 |
| MCG | O(|A|·(J_wb+cone)) | O(1) | 耦合可行域判定完备 |

**正确性定理（Certificate-Preserving Distillation Soundness）**
假设第 53/54 轮 (A22)–(A28) 成立；**(A29)** `β` 在 `A_core` 上由配对仿真校准，覆盖 ≥ 1-δ_β；**(A30)** 移动漂移局部 Lipschitz 且 `Δ_mob ≤ Δ_max`；**(A31)** 教师证书 `teacher_ref` sound；**(A32)** `C_mob` 判定在采样网格上完备。则：
```
P_success(S) ≥ 1 - Σ_d(1-ρ_T(d)) - Σ_d ε_ρ(d) - P(β<θ_β 于 A_T)
                 - P(Δ_mob>Δ_max) - P(C_mob infeasible) - δ_β
```
关键：**教师证书只在 `β≥θ_β` 的动作子域上可继承**，继承时必须扣除 `ε_ρ` 与移动漂移；证书 soundness 是**条件性**的，禁止把教师证书原样复制给学生。

## 5. 本轮最大风险

**一句话**：证书保持蒸馏让学生可审计地继承教师能力，但其 soundness 依赖 **β 在接触/极限/高速基座尾部的可测性、Δ_mob 的有界性、以及 ε_ρ 的保守估计**；一旦 β 在尾部欠采样被系统性高估，学生将获得一张「可继承」的假证书，在真实移动操作尾部工况失效而账面指标仍显示健康，故必须以 **配对仿真难动作采样 + 漂移在线监测 + ε_ρ 反例审计** 三重护栏，宁可拒绝继承，也不让教师证书在蒸馏中被悄然伪造。
