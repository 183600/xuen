# 第 66 轮（承接第 65 轮「VISTA 视觉知情安全时序归因」IP-214~223；新一轮灵感循环第 1 轮；本轮灵感：「在线学习」×「跌倒恢复」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述的最大风险一针见血：**归因依赖「故障属于有限假设集、且视觉与几何失效相互独立」；未知复合故障会被强行归入最近假设、只膨胀错误的球，而系统因「已经归因」更自信地继续执行。** 本轮不再增加第 7 个故障假设，也不再只问「谁坏了」，而是换两个更靠近部署现实的问题：第 65 轮问「**执行时坏没坏**」，REBOUND 问「**在部署中不断改变自己策略/世界模型时，证书还成立吗？如果真的跌倒了，系统能不能有界地恢复，而不是只会在原地停机？**」本轮核心命题是：
>
> **把安全从「不进入坏状态」升级为「不进入不可恢复状态」，把在线学习从「越学越好」重新定义为「每次更新都必须携带一张更新后仍可恢复、且可回滚的证书」；恢复本身是一个分阶段、深度有界、可被在线学习、但只能在可恢复域内学习的技能。**

## 0. 直觉与动机

**灵感 1（在线学习 → 学习是证书的受控扰动，不是免费的改进）**
直觉：第 65 轮的证书、conformal 覆盖、故障先验与可辨识性，全都默默条件化在一个固定策略/世界模型 θ 上。可部署时的在线学习（持续学习、在线微调、从自身执行数据更新世界模型）恰恰在改变这个 θ。于是出现两个极端：完全冻结，浪费在线适应能力；自由学习，则每步都在让昨天签发的证书失效，且自生成数据会带来反馈回路、灾难性遗忘与投毒。正确姿势不是「学不学」，而是**把每次更新当成一次受控扰动**：只有在函数空间信任域内、更新后仍能重签证书、且保留可回滚锚点时，才允许热替换。学习既是风险源，也是恢复手段——故障后快速适应可以救场，但在故障状态下学习会把故障学进去，所以学习必须被「可恢复性」门控。

**灵感 2（跌倒恢复 → 安全不是永不跌倒，而是跌倒可恢复且损伤有界）**
直觉：双足机器人/人的运动控制里，安全从来不是绝对不跌倒；而是跌倒前能踉跄一步、跌倒时能保护性着地、跌倒后能站起来。恢复策略越好，允许进入的「坏状态」就越多——**可恢复集是由恢复策略定义的，不是固定安全集的补集**。这直接冲击第 65 轮「技能前置条件 + 停机」式降级：`safe_idle` 只是把风险冻结在当前状态，若当前状态本身在缓慢恶化（滑移、失稳、能耗、被夹持），停机不是恢复。要把恢复做成第一等的、分阶段的技能：前兆（踉跄/抓扶）→ 进行（保护性跌倒/卸力）→ 完成（起身/重定位/重标定）；并且恢复会失败，所以需要**恢复的恢复**——一条深度有界、终态为受保护姿态的「恢复阶梯」。

**灵感 3（两者耦合 → 只能在已经可恢复的地方学习恢复）**
直觉：这是本轮最硬的直觉。我们想用在线学习提升恢复能力，但学习需要恢复数据，而恢复数据来自失败；如果为了收集失败而进入不可恢复区，就是用不可逆伤害换训练样本。于是形成自举难题：**恢复策略只能从「已经可恢复的失败」里学，而要扩大可恢复域又需要更好的恢复策略**。破局不是忽略它，而是显式的「恢复性课程」：先从仿真/遥操作/保护性约束中的可恢复演示起步，逐步扩张可恢复核，每一步都要求新策略在旧可恢复核上不退化；不可恢复的失败永远只作硬负约束，绝不作探索目标。

**灵感 4（合流 → REBOUND：Recoverability-Enveloped Bounded Online Updates with Nested Diagnostics）**
闭环：可恢复包络 REF 估计「哪里跌倒还能站起来」（可恢复核 `K_rec`、恢复视界 `h_rec`、恢复裕度 `ρ_rec`）→ 恢复策略阶梯 RPP 提供深度有界的恢复技能 → 跌倒检测与诊断 FDD 在 VISTA 的 FIR 上增 `H_learn`/`H_recovery` → 可恢复性门控的在线学习 RIL 只接受保持证书的更新 → 证书保持重认证 CPR 每次热替换都重签 `J_rebound` → 回滚锚 RBK 让「模型跌倒」也能恢复 → 跌倒课程 FCP 只在可学习失败上探索 → CSC-R 把认证前缀截断在恢复视界内并内嵌恢复交接 → RSC-R/WCV-R 增加 `r_learn`/`r_rec` 并在 `K_rec` 上求交 → CSP-R/TSL-recovery 在块图上加恢复边 → AIC-R 认证分布漂移、反馈投毒、恢复失配 → `J_rebound` 记录可恢复裕度、恢复深度、可塑性预算与回滚锚。第 65 轮是「故障可归因」，REBOUND 是「**归因之后还要活得下去：证书要能经受学习，失败要能恢复**」。

**灵感 5（VISTA 组件的原位升级）**
- **FIR → FDD / FIR-R**：故障假设增 `H_learn`（在线更新导致退化/遗忘/反馈投毒）与 `H_recovery`（恢复策略失配）；跌倒三阶段（前兆/进行/完成）成为新的时间签名维。
- **CSC → CSC-R**：`k* ≤ min(m, h_rec)`；块内每步都要有「失败后可恢复」的交接点；abort 不再等于停机，而是触发 RPP。
- **RSC-V → RSC-R**：半径拆为 `r_geo/r_force/r_model/r_learn/r_rec`；只膨胀被归因者；搜索域与 `K_rec` 求交。
- **WCV-V → WCV-R**：尾部采样同时在「物理不确定」与「恢复不确定」上取最坏；`K_rec` 为空时不是硬执行，而是规划受控、有界、损伤最小化的保护性跌倒。
- **CSP-V → CSP-R / TSL-recovery**：块边增「恢复可达」前置条件；插入 `recovery_probe`/`recovery_rehearsal`/`rollback` 元技能。
- **AFA → AFA-R**：判别探针增「自测试探针」（在安全子空间诱发可恢复失稳，测恢复裕度），目标从故障互信息改为「故障 + 可恢复性」的联合信息。
- **AIC-V → AIC-R**：干扰集增分布漂移、自训练反馈回路、回放污染、恢复动作失配、恢复传感器失效。
- **J_vista → J_rebound**：证书增 `recoverability_margin`、`recovery_depth`、`h_rec`、`plasticity_budget_used`、`rollback_anchor_hash`、`forget_risk`、`anchor_coverage`。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（REBOUND 闭环）**：REBOUND = (VISTA, REF, RPP, FDD/FIR-R, RIL, CPR, RBK, FCP, CSC-R, RSC-R/WCV-R, CSP-R, AIC-R, J_rebound)。定位：VISTA 的「可恢复性 + 有界在线学习」升级。不变式：**所有学习写操作、可恢复核估计、重认证、课程规划只在语义流/低频线程；实时流只做跌倒前兆检测、预编译恢复反射、恢复交接与安全前缀执行，零学习写操作。** 附加不变式：**不可恢复状态不得作为探索目标；未通过 CPR 的更新不得热替换。**
- **定义 234（状态、安全集、损伤与跌倒）**：状态 `x∈𝒳`，动作 `a`，扰动 `w`。安全集 `S_safe⊂𝒳`；损伤场 `D(x,a,w)∈[0,D_max]`（含冲击、夹持力、滑移、物体破坏）；跌倒事件 `F={D>0}∪{x∉S_safe}`，按损伤与可恢复性分级，而非二值。
- **定义 235（可恢复核 K_rec）**：给定恢复策略族 `Π_rec`，`K_rec^{Π_rec}={x: ∃π_rec∈Π_rec, ∃T≤h_rec, P(到达 S_safe by T ∧ 累计损伤≤d_budget ∧ 期间不再发生不可逆事件 | x,π_rec)≥1−ε_rec}`。关键：**K_rec 由恢复策略定义**；改进 `π_rec` 即扩张 `K_rec`。
- **定义 236（恢复视界、恢复裕度与恢复价值）**：`h_rec(x)` 为最短期望恢复时间；`ρ_rec(x)` 为到 `K_rec` 边界的 signed margin（含损伤预算）；恢复价值 `V_rec(x)=E[恢复代价]`。`ρ_rec>0` 才允许把 x 当作「可接受的风险状态」。
- **定义 237（跌倒风险场与可恢复性感知的 Q）**：`p_fall(x,a)`、`V_rec(x)`；安全价值 `Q_R=Q_task−λ_f·p_fall·V_rec−λ_d·E[D]`。因此**在 K_rec 内部可以接受风险，在边界附近必须保守**——安全不再是全局二值约束，而是有位置依赖的风险定价。
- **定义 238（恢复阶梯与级联失效界）**：恢复策略层级 `π_rec^0,…,π_rec^{d_rec}`：踉跄/抓扶 → 保护性着地 → 卸力/柔顺 → 起身 → 重定位/重标定 → 受保护静止（终态，无需再恢复）。第 l 层失败以概率 `ε_l` 触发第 l+1 层；终态保证不再产生不可逆损伤。级联概率 `P_cascade≤Σ_{l=0}^{d_rec}ε_l`。
- **定义 239（恢复技能集与恢复签名）**：`RPP={stumble_step,protective_compliance,load_shed,kneel,get_up,re_localize,re_calibrate,safe_posture}`；每技能带前置条件、恢复动作签名 `σ_rec`（前兆/进行/完成三阶段的可观测量）与成功似然。恢复签名进入 FDD，与 VISTA 的阶段签名拼接。
- **定义 240（在线更新与函数空间信任域）**：更新算子 `U:θ→θ′`。允许更新需 `d_func(π_θ,π_θ′)≤δ_θ`（认证状态分布上的动作 KL / 谱范数界）且训练批满足支撑条件；否则进入 shadow 模式（不派发、只记录反事实）。
- **定义 241（证书保持重认证 CPR）**：更新必须附一张新证书 `Valid(J_rebound(θ′))`，并满足**证书单调性** `min_{x∈B_ε(x_t)}[ρ_rec^{θ′}(x)−ρ_rec^{θ}(x)]≥−δ_margin` 且 `forget_risk(θ′)≤f_max`。不满足则拒绝更新并回滚。热替换采用「双缓冲」：旧 θ 保持可回退，新 θ′ 先在 shadow/低风险子空间试用。
- **定义 242（可恢复性门控学习 RIL）**：接受更新当且仅当 (i) 信任域；(ii) 证书单调性；(iii) 回放锚点占比 `≥γ`（防自生成数据反馈投毒/遗忘）；(iv) 可塑性预算 `B_θ` 未耗尽；(v) 当前状态在 `K_rec` 内（或更新只影响 non-certified 通道）。任一不满足 → 排队/回滚/只做语义流离线训练。
- **定义 243（回滚锚与模型跌倒恢复 RBK）**：保存已认证快照 `θ_k`、其 `J_rebound`、锚点数据与随机种子；用锚点集上的 e-process 监控退化，`e_t≥1/α` 判「模型跌倒」，回滚到最近认证锚点并记录 `rollback_anchor_hash`。回滚本身就是一次模型层面的有界恢复。
- **定义 244（可学习失败 vs 不可学习失败）**：失败 f 可学习 ⇔ `x_f∈K_rec` ∧ 损伤 `≤d_budget` ∧ 可在安全约束下可重复诱发；不可恢复失败只进入**硬负约束/障碍函数**，不进入探索分布（探索掩码 `M_explore(x)=1[x∈K_rec]`）。
- **定义 245（跌倒课程 FCP）**：课程是任务序列 `{T_1⊂T_2⊂…}`，每步满足：在旧 `K_rec` 上不退化（CPR）、有认证恢复演示覆盖、新引入的失败都在 `K_rec` 内；可恢复核按 `K_rec^{(i+1)}⊇K_rec^{(i)}` 单调扩张（或显式记录收缩并拒绝）。
- **定义 246（恢复感知认证前缀 CSC-R）**：`k*≤min(m,h_rec(π))`；对前缀内任意步 s，若失败，必须存在可用恢复策略且 `h_rec≤剩余时间预算`；块携带 abort→recover 交接点与所需恢复技能。避免第 65 轮「abort=停机」的冻结式降级。
- **定义 247（RSC-R / WCV-R）**：半径增 `r_learn`（模型/策略更新不确定）与 `r_rec`（恢复成功不确定），融合 `r=√(r_geo²+r_force²+r_model²+r_learn²+r_rec²)`；搜索域 `B(φ̂,r)∩𝒢∩K∩ℱ∩𝒱∩K_rec`。若 `K_rec=∅` 或恢复裕度不足，不硬执行，而是规划**受控、有界、损伤最小化的保护性跌倒**（主动进入已知可恢复的终态）。
- **定义 248（AIC-R 与 J_rebound）**：干扰集 `ℰ_R=ℰ_V×ℰ_learn×ℰ_fall`；`ℰ_learn` 含分布漂移、自训练反馈回路、回放投毒、灾难性遗忘、伪装成正常数据的漂移；`ℰ_fall` 含恢复策略失配、恢复传感器失效、级联恢复失败、受限空间/易损物体下的恢复不可行。`J_rebound=(J_vista,ρ_rec,h_rec,recovery_depth,plasticity_budget_used,rollback_anchor_hash,forget_risk,anchor_coverage,curriculum_ver,aic_r_ver)`。`Valid(J_rebound)⇔Valid(J_vista)∧ρ_rec≥ρ_min∧(更新已通过 CPR ∨ 本次无更新)∧回滚锚可用∧恢复阶梯深度有界且终态可达∧学习在 K_rec 内进行`。

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（可恢复核的单调扩张与证书收缩）**：若 `π_rec` 改进使 `K_rec` 扩张，则安全操作域单调增；但任一在线更新 `θ→θ′` 可同时改变 π、`g_vis` 与 `π_rec`，故必须用证书单调性约束其收缩量；否则「学到了」可能以缩小可恢复域为代价。
- **引理 10（有界更新的证书漂移界）**：若恢复裕度 `ρ_rec` 对策略的 Lipschitz 常数为 L，则 `|ρ_rec^{θ′}−ρ_rec^{θ}|≤L·d_func(π_θ,π_θ′)`；取 `d_func≤δ_margin/L` 即可在更新后保持 Valid。conformal 给出其概率版本（覆盖 `≥1−α_learn`）。
- **引理 11（恢复阶梯的级联界）**：深度 `d_rec`、逐层失败概率 `ε_l` 的恢复阶梯，其到达受保护终态前发生不可逆损伤的概率 `≤Σε_l`；终态是吸收态，故恢复不会无限递归。
- **定理 11（REBOUND 端到端可恢复安全）**：在 A100–A107 下，`Valid(J_rebound)` ⇒ 执行不进入不可恢复集 ∧ 若发生可恢复失败则以 `≥1−Σε_l` 的概率回到 `S_safe` 且损伤 `≤d_budget` ∧ 在线更新不降低证书 ∧ 不可恢复失败不被探索。
- **定理 12（安全-可塑性前沿）**：设更新带来的任务收益为 `ΔJ_task`，证书侵蚀代价为 `λ_c·δ_margin` 与遗忘风险 f，则接受更新当且仅当 `ΔJ_task>λ_c·δ_margin+λ_f·f`；非平稳环境下的最优是**双时间尺度**——恢复反射/证书检查快，学习慢且带锚点回放与回滚。
- **命题（恢复扩大安全域）**：有恢复策略时可行域从不变安全集 `S_inv` 扩到 `K_rec⊇S_inv`；体积增益正是「允许进入但仍可生还」的状态。风险补偿因此是真实收益，但必须被 `ρ_rec` 定价。
- **实时性**：前兆检测、恢复反射、CSC-R 早停、e-process 更新均在实时流（目标 `≤2.8ms`）；可恢复核估计、CPR、FCP、AIC-R 在语义流。

## 2. 形式化定义（完整版）

**定义 233（REBOUND 闭环）** REBOUND 是 VISTA 的「可恢复性 + 有界在线学习」升级：在 VISTA 的「语义流 ∘ 实时流」骨架上挂载 REF（可恢复包络）、RPP（恢复阶梯）、FDD（跌倒诊断，FIR-R）、RIL（可恢复性门控学习）、CPR（证书保持重认证）、RBK（回滚锚）、FCP（跌倒课程），并原位升级 CSC→CSC-R、RSC-V→RSC-R、WCV-V→WCV-R、CSP-V→CSP-R、AIC-V→AIC-R、J_vista→J_rebound。不变式：**所有学习写操作、可恢复核估计、重认证、课程规划只发生在语义流/低频线程；实时流只做前兆检测、预编译恢复反射、恢复交接、安全前缀执行与早停，零学习写操作。** 附加不变式：**不可恢复状态不得作为探索目标；未通过 CPR 的更新不得热替换；恢复阶梯必须有吸收终态。**

**定义 234（状态、安全集、损伤与跌倒）** 状态 `x∈𝒳`，动作 `a`，扰动 `w`。安全集 `S_safe⊂𝒳`。损伤场 `D(x,a,w)∈[0,D_max]` 综合冲击、夹持力、滑移距离、物体破坏与关节超限。跌倒不是二值事件，而是分级集合
`F={x:D(x)>0}∪{x∉S_safe}`，
并按 `(D, 可恢复性, 恢复代价)` 分级。**只有不可恢复的跌倒才是硬禁止；可恢复跌倒是有预算的风险状态。**

**定义 235（可恢复核 K_rec）** 给定恢复策略族 `Π_rec`，
`K_rec^{Π_rec}={x: ∃π_rec∈Π_rec, ∃T≤h_rec, P(到达 S_safe by T ∧ ΣD≤d_budget ∧ 期间无不可逆事件 | x,π_rec) ≥ 1−ε_rec}`。
两条结论：(i) **K_rec 由恢复策略定义**，改进 `π_rec` 即扩张 `K_rec`；(ii) K_rec 不是不变集，允许其内部状态暂时不安全，但要求可生还。`S_inv⊆K_rec`。

**定义 236（恢复视界、恢复裕度与恢复价值）** `h_rec(x)=inf_{π_rec}E[T_recover(x,π_rec)]`；`ρ_rec(x)` 为 `x` 到 `K_rec` 边界的 signed margin，按损伤预算与成功概率共同缩放；`V_rec(x)=E[恢复代价|π_rec]`。`ρ_rec(x)>0` 才允许把 x 当作可接受风险状态；`ρ_rec(x)≤0` 即不可恢复，只能进入硬安全模式或受控保护性跌倒。

**定义 237（跌倒风险场与可恢复性感知 Q）** 学得/标定 `p_fall(x,a)` 与 `V_rec(x)`，定义
`Q_R(s,a)=Q_task(s,a)−λ_f·p_fall(x,a)·V_rec(x)−λ_d·E[D(x,a,w)]`。
这把安全从全局二值约束变成位置依赖的风险定价：**K_rec 内部可冒险，边界附近必须保守**。注意：这是把风险补偿显式定价，而不是否认它。

**定义 238（恢复阶梯与级联失效界）** 恢复层级 `π_rec^0,…,π_rec^{d_rec}`：
`π_rec^0` 踉跄/抓扶/迈步；`π_rec^1` 保护性着地/柔顺卸力；`π_rec^2` 负荷卸载/松开夹持；`π_rec^3` 起身/跪起；`π_rec^4` 重定位/重标定；`π_rec^{d_rec}` 受保护静止（吸收终态，不再产生不可逆损伤）。第 l 层失败以概率 `ε_l` 触发第 l+1 层。由联合界 `P_cascade≤Σ_{l=0}^{d_rec}ε_l`；终态吸收保证不无限递归。

**定义 239（恢复技能集与恢复签名）**
`RPP={stumble_step,protective_compliance,load_shed,kneel,get_up,re_localize,re_calibrate,safe_posture}`。
每技能 `σ` 带前置条件 `Pre_σ`、恢复动作签名 `σ_rec`（前兆/进行/完成三阶段的可观测量：失稳方向、接触构型、冲击峰值、恢复进度、重定位残差）与成功似然。恢复签名与 VISTA 的阶段证据拼接，供 FDD 归因 `H_recovery`。

**定义 240（在线更新与函数空间信任域）** 更新算子 `U:θ→θ′`。允许更新需
`d_func(π_θ,π_θ′)=sup_{x∈𝒟_cert}KL(π_θ(·|x)‖π_θ′(·|x)) ≤ δ_θ`
（或等价的谱范数/动作偏差界），且训练批满足支撑条件（见定义 242）。不满足则进入 shadow 模式：不派发动作，只记录反事实与损失，供语义流离线评估。

**定义 241（证书保持重认证 CPR）** 每次热替换必须附新证书 `Valid(J_rebound(θ′))`，并满足证书单调性
`min_{x∈B_ε(x_t)}[ρ_rec^{θ′}(x)−ρ_rec^{θ}(x)] ≥ −δ_margin`
且 `forget_risk(θ′)≤f_max`。不满足则拒绝并回滚。热替换采用双缓冲：旧 θ 保持可回退，新 θ′ 先在 shadow / 低风险子空间试用，逐步提升可派发比例。**证书不是一次性证明，而是随 θ 迁移的运行时前提。**

**定义 242（可恢复性门控学习 RIL）** 接受更新当且仅当：
(i) `d_func≤δ_θ`（信任域）；
(ii) CPR 的证书单调性成立；
(iii) 回放锚点占比 `≥γ`，其中锚点来自已认证分布，防止自生成数据反馈投毒与灾难性遗忘；
(iv) 可塑性预算 `B_θ` 未耗尽（限制累计函数空间位移）；
(v) 当前状态 `x_t∈K_rec`，或更新仅影响不参与当前证书的通道。
任一不满足 → 更新排队、shadow 化、或回滚；绝不把学习写操作塞进实时路径。

**定义 243（回滚锚与模型跌倒恢复 RBK）** 保存已认证快照 `θ_k`、其 `J_rebound`、锚点数据、随机种子与优化器状态。用锚点集上的 e-process 监控退化：
`e_t≥1/α_rollback ⇒ 模型跌倒`，
回滚到最近认证锚点并把 `rollback_anchor_hash` 写入新证书。回滚是有界恢复：它不保证模型变好，但保证不继续在退化轨迹上累积不可逆损失。

**定义 244（可学习失败 vs 不可学习失败）** 失败 f 可学习 ⇔
`x_f∈K_rec ∧ D_f≤d_budget ∧ 可在安全约束下重复诱发`。
不可恢复失败只进入硬负约束/障碍函数/保守屏障，不进入探索分布。探索掩码 `M_explore(x)=1[x∈K_rec]`；FCP 只优化 `M_explore=1` 的样本，从而避免「用不可逆伤害换训练样本」。

**定义 245（跌倒课程 FCP）** 课程是任务序列 `{T_1⊂T_2⊂…}`，每步满足：
(i) 在旧 `K_rec` 上不退化（CPR 检查）；
(ii) 有认证恢复演示覆盖新引入的失败模式；
(iii) 新失败都在 `K_rec` 内，或由保护性约束转为安全演示；
(iv) `K_rec^{(i+1)}⊇K_rec^{(i)}`，若检测到收缩则拒绝该课程步并记录。
课程不是「从易到难」的启发式，而是**在证书约束下的可恢复域单调扩张**。

**定义 246（恢复感知认证前缀 CSC-R）** 对块 `A_t` 与前缀 k，
`k*≤min(m,h_rec(π))`。
对前缀内任意步 s，若发生失败，必须存在可用恢复策略且 `h_rec≤剩余时间预算`；块携带 abort→recover 交接点与所需 RPP 技能。CSC-R 的越界预算改为
`P[∃s≤k*: 越界且不可恢复] ≤ α_chunk+δ_fi+α_vis+Σε_l`。
与第 65 轮的关键区别：abort 不再等于 `safe_idle`，而是**交接到恢复阶梯**。

**定义 247（RSC-R / WCV-R）** 半径增 `r_learn`（模型/策略更新不确定）与 `r_rec`（恢复成功不确定）：
`r=√(r_geo²+r_force²+r_model²+r_learn²+r_rec²)`。
搜索域 `B(φ̂,r)∩𝒢(g)∩K(μ̂)∩ℱ(f_lim)∩𝒱∩K_rec`。CVaR 尾部同时在物理不确定与恢复不确定上取最坏。若 `K_rec=∅` 或 `ρ_rec<ρ_min`，不硬执行；规划**受控、有界、损伤最小化的保护性跌倒**（主动进入已知可恢复终态），并把该决策写入证书。

**定义 248（AIC-R 与 J_rebound）** 干扰集
`ℰ_R=ℰ_V×ℰ_learn×ℰ_fall`。
`ℰ_learn` 含分布漂移、自训练反馈回路、回放投毒、灾难性遗忘、伪装成正常数据的渐变漂移；`ℰ_fall` 含恢复策略失配、恢复传感器失效、级联恢复失败、受限空间/易损物体下恢复不可行。`ρ_dir` 在 `ℰ_R` 上重算（n_cert 160→192，32 用于学习/跌倒/共因）。
`J_rebound=(J_vista,ρ_rec,h_rec,recovery_depth,plasticity_budget_used,rollback_anchor_hash,forget_risk,anchor_coverage,curriculum_ver,aic_r_ver)`。
`Valid(J_rebound)⇔Valid(J_vista)∧ρ_rec≥ρ_min∧(更新已通过 CPR ∨ 本次无更新)∧回滚锚可用∧recovery_depth≤d_max∧终态吸收∧学习在 K_rec 内进行`。

## 3. 关键算法伪代码

### IP-224 REF（可恢复包络与恢复裕度）

```python
class RecoverabilityEnvelope:
    """离线 HJ/学习 critic 估计 V_rec 与 K_rec；线上用 conformal 校准裕度。"""
    def __init__(self, critic, q_rec, h_rec_max, d_budget, eps_rec):
        self.critic, self.q_rec = critic, q_rec
        self.h_rec_max, self.d_budget, self.eps_rec = h_rec_max, d_budget, eps_rec

    def margin(self, x, pi_rec):
        v = self.critic.value(x, pi_rec)            # 期望恢复代价（时间+损伤）
        rho = (self.d_budget - v.damage) / self.d_budget \
              - max(0.0, v.time - self.h_rec_max) / self.h_rec_max
        return float(rho - self.q_rec)              # conformal 下界

    def in_kernel(self, x, pi_rec):
        return self.margin(x, pi_rec) > 0.0

    def fallback(self, x, rpp):
        # 不可恢复：规划受控、有界、损伤最小化的保护性跌倒
        return rpp.plan_protective_fall(x)
```

### IP-227/228 RIL + CPR + RBK（有界在线更新）

```python
class RecoveryInformedLearner:
    def __init__(self, theta, delta_theta, delta_margin, gamma, budget,
                 forget_max, rbk):
        self.theta, self.delta_theta, self.delta_margin = theta, delta_theta, delta_margin
        self.gamma, self.budget, self.forget_max, self.rbk = gamma, budget, forget_max, rbk
        self.used = 0.0

    def admit(self, U, x_t, rho_now, anchor_frac):
        if U.d_func > self.delta_theta:              return False, 'trust_region'
        if self.used + U.d_func > self.budget:        return False, 'plasticity_budget'
        if anchor_frac < self.gamma:                  return False, 'anchor_starved'
        if rho_now <= 0.0 and not U.non_certified_only:
            return False, 'outside_K_rec'
        return True, 'ok'

    def step(self, U, x_t, cpr, anchor_frac):
        ok, why = self.admit(U, x_t, cpr.rho_now, anchor_frac)
        if not ok:
            return self.theta, why                    # shadow / queue
        theta_new = apply_update(self.theta, U)
        cert = cpr.recertify(theta_new, x_t)         # 证书单调性 + 遗忘风险
        if not cert.valid:
            theta_new = self.rbk.rollback()           # 模型跌倒恢复
            return theta_new, 'rollback'
        self.used += U.d_func
        self.rbk.checkpoint(theta_new, cert)         # 新认证快照
        return theta_new, 'swapped'


class CertificatePreservingRecertifier:
    def recertify(self, theta_new, x_t):
        rho_new = ref.margin(x_t, theta_new.pi_rec)
        delta = rho_new - self.rho_old(x_t)
        forget = estimate_forgetting(theta_new, self.anchor_val)
        valid = (delta >= -self.delta_margin and forget <= self.forget_max
                 and ref.in_kernel(x_t, theta_new.pi_rec))
        return Cert(valid, rho_new, forget, delta)
```

class RecoveryAwareCSC:
    def certified_prefix(self, A, post, m, h_rec, alpha_chunk):
        horizon = min(m, int(h_rec))
        support = {h: p for h, p in post.items() if p >= self.delta}
        for k in range(1, horizon + 1):
            if any(safety_margin(A[s], h) < 0 for h in support for s in range(k)):
                return k - 1
            if self.recovery_affordable(A, k, post) is False:
                return k - 1
            if self.violation_prob(A[:k], support) > alpha_chunk:
                return k - 1
        return horizon

    def recovery_affordable(self, A, k, post):
        # 每步失败后都必须在剩余预算内可恢复（且恢复阶梯终态可达）
        return all(ref.margin(x_after(A, s), pi_rec) > 0 for s in range(k))

## 4. 推导

**引理 9（可恢复核的单调扩张与证书收缩）** 设 `K_rec` 由恢复代价 `V_rec` 的次水平集定义：`K_rec={x: V_rec(x)≤v_max}`。若改进 `π_rec` 使 `V_rec^{π′}(x)≤V_rec^{π}(x)` 对所有 x 成立，则 `K_rec^{π′}⊇K_rec^{π}`，安全操作域单调扩张。反之，在线更新 `θ→θ′` 同时改变任务策略 π、世界模型 `g_vis` 与恢复策略 `π_rec`，因此更新可能提高任务性能却**收缩** `K_rec`。故仅比较任务损失不够，必须显式约束 `ρ_rec` 的变化（定义 241）。∎

**引理 10（有界更新的证书漂移界）** 设 `ρ_rec` 作为策略的函数在认证状态分布 `𝒟_cert` 上对 `d_func` 满足 Lipschitz：
`|ρ_rec^{θ′}(x)−ρ_rec^{θ}(x)| ≤ L·d_func(π_θ,π_θ′), ∀x∈𝒟_cert`。
则取 `δ_θ=δ_margin/L` 可保证证书单调性；若 L 只能从标定集估计，则用 split-conformal 在余量 `|Δρ|−L·d_func` 上取上分位数 `q_L(α_learn)`，得概率版本
`P[ρ_rec^{θ′}−ρ_rec^{θ} ≥ −δ_margin] ≥ 1−α_learn`。
这把「学习步子多大才安全」从调参变成可计算预算。∎

**引理 11（恢复阶梯的级联界）** 恢复阶梯每层失败以 `ε_l` 进入下一层，终态 `π_rec^{d_rec}` 为吸收态（不再产生不可逆损伤）。定义 `E_l` 为第 l 层失败事件，则到达终态前发生不可逆损伤需至少发生一次「终态前所有层均失败」的级联，概率由联合界 `P_cascade≤Σ_{l=0}^{d_rec}ε_l`。注意 `ε_l` 须用 Clopper-Pearson 上界估计，否则稀有恢复失败会被低估。∎

**定理 11（REBOUND 端到端可恢复安全）** 在 A100–A107 下：
1. **不进入不可恢复集**：执行前检查 `ρ_rec≥ρ_min`；搜索域与 `K_rec` 求交（定义 247）。故若证书有效，执行步骤不会落入 `𝒳∖K_rec`。
2. **可恢复失败有界生还**：若发生 `F` 但 `x∈K_rec`，恢复阶梯以 `≥1−Σε_l` 概率到达 `S_safe` 且累计损伤 `≤d_budget`（引理 11）。
3. **在线学习不降低证书**：每次热替换通过 CPR 的证书单调性与遗忘风险检查（定义 241、引理 10），否则回滚（定义 243）。故学习不是证书的静默否定。
4. **不可恢复失败不被探索**：探索掩码 `M_explore=1[x∈K_rec]` 与 FCP 的单调扩张约束（定义 244/245）保证课程不会为采样进入不可恢复区。
5. **优雅降级**：恢复传感器失效 → 直接进入终态保护姿态；`K_rec=∅` → 受控保护性跌倒；学习退化 → 回滚到认证锚点。
6. **实时性**：前兆检测、恢复反射、CSC-R 早停、e-process 更新在实时流，`≤2.8ms`，零学习写操作。

综合即 `Valid(J_rebound)` 蕴含上述五条安全结论。∎

**定理 12（安全-可塑性前沿）** 设一次更新带来的任务收益为 `B(Δθ)`，其证书侵蚀代价为
`C(Δθ)=λ_c·L·d_func(π_θ,π_θ′) + λ_f·forget(Δθ) + λ_r·max(0, −ΔVol(K_rec))`，
则最优更新策略是
`Δθ*=argmax_{d_func≤δ_θ} [B(Δθ)−C(Δθ)]`，
即只在 `B>C` 时热替换。非平稳环境下，恢复反射/证书检查的时间尺度远快于学习（后者受可塑性预算 `B_θ` 与锚点回放限制），这解释了双时间尺度结构的必要性：**若学习与恢复同速，学习造成的证书漂移会与恢复动作竞争同一实时预算，导致两者都来不及。** ∎

**命题（恢复扩大安全域，但必须被定价）** 有恢复策略时可行域从 `S_inv` 扩到 `K_rec⊇S_inv`，体积增益对应「允许进入但仍可生还」的状态。若把 `p_fall·V_rec` 从 Q 中删去，系统会表现出风险补偿（Peltzman 效应），把恢复能力误读为免费的风险额度；REBOUND 通过 `Q_R` 显式定价，使扩张只在期望收益为正时发生。∎

**假设 A100–A107**：
A100 `ρ_rec` 可被 conformal 校准且估计误差有界；A101 恢复阶梯深度有限且终态吸收；A102 `d_func` 可测、`ρ_rec` 对策略 Lipschitz；A103 锚点占比≥γ 且锚点覆盖认证状态分布；A104 不可恢复失败可识别，或保守地一律按不可恢复处理；A105 损伤场可观测/可上界；A106 恢复期传感器可用，失效则进入终态保护；A107 实时预算内可完成前兆检测与恢复交接。

## 7. 已知风险

**一句话**：REBOUND 的可恢复核 `K_rec` 是由正在被在线更新的同一套策略/世界模型自评的，恢复演示又来自同一策略的失败分布——这会形成「自我认证的乐观恢复」：模型学到的是「我相信我能站起来」，而不是「我真的能站起来」；一旦长尾恢复失败（恰是数据最少之处），系统早已因「可恢复」被允许进入坏状态，跌倒恢复便从安全网变成风险补偿（risk compensation）的许可证，这是本轮全部证书、课程与在线学习论证共同依赖的隐藏假设（A100）。

**次级风险与缓解**：
1. **自我认证 / 乐观恢复 critic**：`K_rec` 与 `π_rec` 同源同分布更新，critic 会拟合自己的失败偏差；缓解：用独立的恢复仿真/物理锚点、对抗恢复测试、e-process 监控 critic 校准，估计不足即收紧 `K_rec`。
2. **风险补偿（Peltzman 效应）**：可恢复性被误当免费风险额度；缓解：`Q_R` 显式对 `p_fall·V_rec` 定价，恢复能力提升不等于允许更高跌倒率。
3. **恢复长尾数据稀缺**：最危险的恢复失败恰恰样本最少；缓解：保护性跌倒作为已知终态、保守的 Clopper-Pearson 上界、恢复深度有限、宁可直接进入终态。
4. **受限空间/易损物体下恢复不可行**：起身可能撞到环境或压坏物体；缓解：`K_rec` 显式条件化到环境与物体约束，不可行时只做受控保护性跌倒并标记证书。
5. **灾难性遗忘与反馈投毒**：在线学习把自身误差学进模型；缓解：锚点回放占比 γ、冻结认证通道、e-process 回滚、定期离线重认证。
6. **非平稳下 conformal 失准**：`q_rec` 与 `ρ_rec` 的覆盖名不副实；缓解：分场景/分视界校准、漂移检测触发重标定、`distribution_shift=True` 时收紧 `δ_margin`。
7. **恢复期传感器失效**：跌倒中视觉/IMU 可能损坏；缓解：开环预编译的保护性反射 + 终态吸收，不依赖在线估计。
8. **CPR 计算开销与更新频率冲突**：重认证可能阻塞热替换；缓解：低频、异步、双缓冲、只在小状态子空间重认证，其余保持旧策略。
9. **课程扩张的安全性**：`K_rec` 单调扩张依赖恢复演示覆盖；缓解：每个课程步强制 CPR 与恢复签名 OOD 检测，收缩即拒绝。
10. **终态本身不安全**：`safe_posture` 对易损物体/夹持场景可能造成二次伤害；缓解：终态按任务参数化并纳入 AIC-R，禁止把「静止」默认等同于「安全」。
