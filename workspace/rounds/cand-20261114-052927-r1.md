# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「跌倒恢复」×「运动规划」）

> R69 问出「我该向谁求证、还能问什么」，但它默认了三件在真实身体上都不成立的事：
> 1. **有时间问**——从失衡到不可恢复往往只有 200–600ms，而「看/问/触」的闭环延迟常常同量级；
> 2. **问本身不改变安全性**——为了看清反光而转头、为了探明摩擦而伸脚，恰恰可能把身体推出平衡域；
> 3. **不确定就收紧（λ_floor）总是安全的**——在跌倒过程中，「慢下来」常常等于放弃迈步/支撑/翻滚的时机，**不确定时更需要果断承诺一个恢复动作**，而不是继续犹豫。
>
> 这正是 R68→R69 这条「越不确定越保守」路线的盲区：它把安全当成一个**标量速度约束**，而真实的安全是一个**有时限的可行性问题**。**跌倒恢复**送来三件东西：可行性核（viability kernel）、捕获点/恢复可达集，以及「跌倒不是失败，未受保护的跌倒才是」这一安全观的翻转；**运动规划**送来另外三件：非短视的信念空间规划、带约束的轨迹/管（tube）优化，以及把「应急恢复」作为计划的一部分而非事后补丁。
>
> 核心命题：**在 R69 的 aleatoric/epistemic 二分之上，再加一条与它们正交的「可行性/时限」轴：一个 epistemic 歧义只有在「存在一条既保持身体在恢复可达管内、又能在不可返回点（PONR）之前完成的观测-运动联合计划」时才是可问的；否则必须认知弃权，果断交给经证书认证的恢复策略。恢复不再是否定项，而是与任务动作同源生成、同等认证的一等计划模态。** 命名 **VITAL-RAS**（Viability-aware Information-gathering with Time-bounded Active Learning for Risk-Adaptive Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我还来得及问吗？问的代价会不会让我连站都站不住？来不及的时候，我该怎样体面地倒、并重新站起来**」。

## 0. 直觉与动机

**灵感 1（跌倒恢复 → 安全不是「永不跌倒」，而是「跌倒可控、可恢复」）**
直觉：把「跌倒」当作唯一失败，会让系统在临界状态下做出最坏选择——为了不倒下而死撑，结果以更差姿态、更高能量摔倒。真正的跌倒恢复研究关心的是：capture point、恢复步、支撑、团身/翻滚（breakfall），以及冲击后的再起身。**受控跌倒（strategic fall）是一个合法动作**：当所有「保持站立」的可控轨迹的最坏伤害都大于一次受控倒地的伤害时，最优策略就是主动倒。这把 R68/R69 的「安全 = 更慢 / 更紧」彻底翻转：安全是一个**伤害-可恢复性**的联合判据，而不是一个单调的保守标量。

**灵感 2（运动规划 → 信息动作是有路径、有期限、有管子的）**
直觉：R69 的 VoI 是**一步**的：问一次能降多少熵。但真实观测往往需要先「走到能看清的位置」——这一步本身没有信息增益，却打开了后续观测的选项，这就是主动感知 / next-best-view 的非短视规划。更关键的是，规划是在**可达集与恢复管**里做的：一条观测轨迹不仅要「能到」，还要在任意时刻都留有一条**回到可行性核的逃生管**（tube）。于是 VoI 必须与「消耗多少可行性裕度」「多久能完成」一起算，而不是一个与身体无关的标量。

**灵感 3（PONR → R69 的边界条件被时间击穿）**
直觉：R69 只在「VoI ≤ 成本」时退化保守，隐含 TTV=∞。但有身体就有**不可返回点**：一旦越过 PONR，再好的恢复策略也只能减小伤害，不能回到安全集。若观测的完成时间 τ_res 大于 PONR，那么它的信息价值在决策意义上是 **0**——你会在拿到答案之前先摔倒。所以 R69 的 MINT 需要一个**期限折现**：DVoI = E[ΔH · 1{τ_res < PONR}]。这条判断必须发生在选择信息动作之前，而不是之后。

**灵感 4（两套风险态度 → 「慢」与「果断」各有其合法制度）**
直觉：R69 的 λ_floor 在标称（nominal）制度下是对的：不确定 → 留裕度 → 慢。但在 pre-fall / falling 制度下，**迟疑本身就是风险**：你可能需要在信息不足时立刻迈出恢复步或团身。于是风险算子必须**随制度切换**：λ_nom 沿用 R69 的单调保守；λ_rec 则是「承诺算子」——在候选恢复动作中选择最坏伤害最小者，并允许更高速度 / 更大动作幅度。两种态度不能混用，也不能无滞回地来回切；需要 dwell time + 迟滞 + 一个始终拥有抢占权的**运行时保障守卫（RA-Guard）**。

**灵感 5（跌倒也是标定的断裂点 → 恢复后不能假装什么都没发生）**
直觉：跌倒 / 撞击会改变传感器安装、接触状态、力偏置，R68/R69 的标定证书与 FMA 基线在摔倒瞬间失效；更危险的是，把摔倒后的异常残差继续喂给旧标定，会把「身体已经换了一个世界」解释成「噪声」。所以恢复必须包含**跌倒感知的标定重置（FCR）**：进入 reset 制度、重新收集标定证据、重新认证 J_CALM，之后才允许回到标称。否则 R69 的「缓变故障被标定吸收」会在一次跌倒后变成「急性故障被当作正常复位」。

**灵感 6（交互的时限攻击 → 新的威胁模型）**
直觉：R69 担心「问错」，R70 还要担心「**问得太慢**」。对手不需要给错误答案，只需拖到 PONR 之后——一句「正在处理，请稍候」就足以让系统错过恢复窗口；也可以制造「歧义陷阱」，诱导系统把可行性裕度耗尽在无收益的探询上；还可以伪造「恢复已就绪」信号让守卫解除。因此 AIC 需要新增**时间投毒（temporal poisoning）**与**假恢复信号**两个维度。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（VITAL-RAS 总览）** VITAL-RAS = (VM, RPM, DVOI, BIMP, RAL, FMP-R, CREC, FCR, FMA-R, RA-Guard, RAS-WM†)。继承 R69 定义 293 的实时流零学习写操作、交互预算与证据纪律；新增四条不变式：
(i) **可行性硬约束**：任何信息动作 g 必须存在一条恢复可达管 T_g ⊆ R_rec，使执行 g 的全过程 x(t) ∈ T_g；不满足则 g 不是「低收益」，而是**不可执行**；
(ii) **期限纪律**：若 g 的完成时间 τ_res(g) ≥ PONR(x)，则 DVoI(g) := 0，系统必须认知弃权并承诺一个经验证的恢复 / 标称动作；
(iii) **制度切换安全**：制度切换必须经迟滞 + dwell time + 认证守卫；守卫在任意 tick 拥有抢占规划器的最高权限；
(iv) **恢复一等性**：恢复动作由与任务动作相同的流策略生成、经同一 C-RAS-WM† 前缀认证，并额外持有恢复证书 CREC；不允许「事后补丁式」的应急控制器。

**定义 311（可行性核与恢复可达集）** 安全集 S_safe = {x | damage(x) ≤ d_max ∧ task_constraints}；可行性核 Viab(S_safe) 为 S_safe 在给定控制族与扰动界内的最大受控不变子集。恢复策略族 Π_rec = {π_step, π_brace, π_squat, π_roll, π_breakfall}。恢复可达集 R_rec = {x | ∃π ∈ Π_rec，使从 x 出发的闭环轨迹在 t_rec(x) 内以概率 ≥ 1−δ_rec 到达 Viab，且全程预测伤害 ≤ s_max}。显然 Viab ⊆ R_rec。

**定义 312（可行性裕度、TTV、PONR）** 在扰动界 𝒲 下定义管状裕度 m(x) = min_{w∈𝒲} dist(x, ∂Viab)；TTV(x) = inf{t ≥ 0 | 名义 + 最坏扰动轨迹离开 Viab}；最晚恢复启动时刻 PONR(x) = TTV(x) − t_rec(x)。PONR(x) ≤ 0 表示「已只能执行恢复」。所有量用 VSP 的下置信界（LCB）进入规划（定义 321）。

**定义 313（决策期限与可行信息动作集）** 歧义 M 的决策期限 D(x) = min(PONR(x), task_deadline, social_deadline)。信息动作 g 的完成时间 τ_res(g) = τ_reach(g) + τ_acquire(g) + τ_process(g) + τ_update。可行集 G_feas(x) = {g ∈ 𝒜_info | τ_res(g) ≤ D(x) − τ_margin ∧ tube_ok(x, g)}。

**定义 314（期限折现 VoI 与认知弃权）** DVoI(g) = E[ΔH(M; y_g) · 1{τ_res(g) < PONR(x)}] − c_task(g) − c_margin(g)，其中 c_margin(g) = κ · (m(x) − min_{t≤τ_res(g)} m(x(t) | g)) 为消耗的可行性裕度成本。选择 g* = argmax_{g∈G_feas} DVoI(g)。若 G_feas = ∅ 或 max DVoI ≤ 0 ⇒ **认知弃权**：停止一切信息动作，交给 RAL 承诺恢复 / 最安全标称动作。⇒ R69 的 MINT 是 PONR=∞、c_margin=0 的特例。

**定义 315（恢复增强动作空间）** ξ = (a, g, r) ∈ 𝒜_task × 𝒜_info × ({∅} ∪ Π_rec)，并补充一个**策略性跌倒**宏 r_sf ∈ Π_rec（团身 / 侧滚 / 受控接触）。计划层选择 r；执行层由 FMP-R 生成连续轨迹。

**定义 316（制度状态机）** 制度集合 ℛ = {N 标称, P 前跌倒, F 跌倒中, R 跌倒后 / 恢复}。观测制度 e_t = φ(m(x), TTV_LCB(x), FMA-R 分数, 接触状态)。转移采用双阈值迟滞 h 与最小驻留 τ_dwell：仅当越过 (θ_up, θ_down) 且驻留足够久才切换。初始从 R 回到 N 必须持有重新认证的 J_CALM（定义 323）。

**定义 317（制度依赖风险算子 Λ）** 标称制度：λ_nom(U) = λ_floor(U)（继承 R69 定义 307，单调保守）。恢复制度：λ_rec 是承诺算子——在候选 (r, ξ) 上最小化最坏伤害：
r* = argmin_{r∈Π_rec, CREC(r) valid} max_{w∈𝒲} severity(exec(r, w))，
并且**不施加「更慢」约束**；其「保守性」体现在提高恢复动作的认证门槛与冲击上界，而不是降低速度。制度内 λ 单调，跨制度由 RPM 认证切换。

**定义 318（恢复条件流策略 FMP-R）** 在 FMP（定义 295）上加制度 token e_t 与恢复宏 r 的条件：v_θ(x_s, s | z_t, e_t, r)。训练数据由标称轨迹 + 跌倒 / 恢复轨迹（含策略性跌倒）增广；损失仍为流匹配。推理时生成 K 个候选，**只有通过 CREC 的恢复模态可进入执行**。

**定义 319（恢复证书 CREC）** CREC(r) = (r_id, entry_set, invariant_tube T_r, t_rec, severity_bound s_max, δ_rec, VSP_version, calibration_version)。Valid ⇔ T_r ⊆ R_rec 且 T_r 正向不变（在扰动界内）且 C-RAS-WM† 前缀认证通过且 TTV_LCB 的共形覆盖率达标。**它是可被审计、可被撤销的证书，不是一个布尔标签。**

**定义 320（信念空间信息-运动联合规划 BIMP）** 在信念 b_t 与状态 x_t 上规划 π = {(a, g, r)_{t:t+H}}：
π* = argmax E[Σ_k γ^k (R_task + DVoI_k) − c_exec]，
s.t. x_k ∈ R_rec ∀k，Σ cost ≤ B_info，且每个决策节点要么选 g ∈ G_feas 要么 commit。包含「走到有利观测位姿」这类**即时 VoI 为零但期权价值为正**的动作。用 belief-RRT* / 带恢复管约束的 MPC 求解；算力不足时退化为 R69 MINT + 一步可行性检查（定义 314）。⇒ 非短视性来自「先移动再观测」的期权价值，而不是更复杂的熵估计。

**定义 321（可行性预测器 VSP）** TTV / PONR 学习预测器，输出共形下置信界 TTV_LCB = TTV_hat − q_α，满足 P(TTV < TTV_LCB) ≤ α。OOD 检测触发时使用**最保守先验**（TTV_LCB = 0，直接进入恢复制度），绝不乐观外推。

**定义 322（运行时保障守卫 RA-Guard）** 双速率 Simplex 结构：高频（≥500Hz）守卫 G 只读 m(x)、TTV_LCB、e_t，拥有抢占权；低频（≤20Hz）BIMP 只提议。抢占规则：若 m(x) ≤ m_trigger 或 PONR(x) ≤ 0 或 FMA-R 判为失控跌倒，则强制 r ← RAL.select(x)，并冻结信息动作。守卫本身不学习、不写参数，只执行已验证的阈值逻辑。

**定义 323（跌倒感知标定重置 FCR）** 跌倒 / 冲击事件使 J_CALM 与 FMA 基线失效：进入 R 制度后，(a) 冻结旧标定，不再用其吸收新残差；(b) 在已知参照下采集新鲜标定证据；(c) 重新计算 J_CALM 与 FMA 基线；(d) 仅当重新认证通过才允许 N 制度。禁止把冲击残差解释为「噪声」而直接复位。

**定义 324（恢复感知异常 FMA-R）** 跌倒起始分 = w1 · (−log p_θ(ξ_obs | o))（R69 FMA）+ w2 · (m(x) 的塌缩速率) + w3 · (非计划接触)。若存在 CREC-valid 且被计划执行的 r，则判为**受控跌倒**；否则为**失控跌倒**。只有失控跌倒触发急停、FCR 与审计升级；受控跌倒是合法制度，不得惩罚。

**定义 325（时间投毒与假恢复威胁 AIC-VITAL）** ℰ_VITAL = ℰ_FLUID × ℰ_temporal × ℰ_physical × ℰ_false：
- ℰ_temporal：延迟回答越过 PONR、用「处理中」耗尽决策期限、制造无收益歧义陷阱；
- ℰ_physical：湿滑 / 推搡 / 绊索等外部扰动，直接压缩 TTV；
- ℰ_false：伪造「恢复路径可行 / 守卫已解除」的传感器或通信信号。
证据纪律扩展为**时限证据纪律**：过期证据一律按缺失处理；恢复就绪信号必须由本体证据（接触 / 姿态 / 能量）独立验证。

**定义 326（证书 J_VITAL）** J_VITAL = (J_FLUID, regime_log_hash, TTV_LCB_p50/p95, PONR_min, margin_min, recovery_id, CREC_valid, severity_bound, dvoi_before/after, preemption_log_hash, fcr_version)。Valid ⇔ J_FLUID 有效 ∧ 全程 x(t) ∈ R_rec ∧ 无守卫违规 ∧ 期限纪律满足 ∧ 恢复证书可撤销且未过期。

**定义 327（受控跌倒与伤害预算）** 策略性跌倒 r_sf 可采纳，当且仅当：(a) CREC(r_sf) 有效且 severity_bound ≤ s_max；(b) 对所有「保持站立」的可控轨迹，其最坏伤害 > severity_bound(r_sf)；(c) r_sf 之后存在恢复可达路径回到 Viab。**「永不跌倒」不是安全不变式；「每一次跌倒都被计划、被认证、可恢复」才是。**

```python
# IP-264 VM：可行性监控（每个控制 tick 都跑，极轻）
class ViabilityMonitor:
    def margin(self, x):
        return min_dist_to_boundary(x, self.dist_bound)      # 管状裕度
    def ponr(self, x, vsp, t_rec):
        return vsp.ttv_lcb(x) - t_rec                        # 不可返回点

# IP-265 RPM：制度状态机（迟滞 + 最小驻留）
def regime_update(prev, x, vm, fma_r, now, last_switch):
    e = classify_regime(x, vm, fma_r)
    if e == prev: return prev
    if now - last_switch < TAU_DWELL: return prev
    if not crosses_hysteresis(prev, e, x, HYST): return prev
    return e

# IP-266 DVOI：期限折现的信息价值；不可行即弃权
def deadline_voi(cands, w, x, vm, t_rec):
    D, best = vm.ponr(x, t_rec), None
    for g in cands:
        if not vm.tube_ok(x, g):                 continue   # 硬可行性
        if tau_res(g) >= D - TAU_MARGIN:          continue   # 来不及
        score = expected_info_gain(w, g) - cost(g) - vm.margin_cost(x, g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None       # None = 认知弃权

# IP-269 FMP-R：恢复条件流策略（复用 R69 trunk）
class RecoveryFlowPolicy:
    def sample(self, o_t, K, regime, r=None, N_step=2):
        z  = self.trunk(o_t)
        c  = cond_token(z, regime, r)                      # 制度 + 恢复宏
        xs = randn(K, D)
        for i in range(N_step):
            xs = xs + (1.0/N_step) * self.v(xs, i/N_step, c)
        return [self.decode(x) for x in xs]                # ξ=(a,g,r)

# IP-268 RAL：恢复动作选择（最坏伤害最小 + 证书）
def select_recovery(x, cands):
    ok = [r for r in cands if CREC(r).valid(x)]
    return min(ok, key=lambda r: CREC(r).severity_upper(x), default=None)

# IP-267 BIMP：非短视信息-运动规划（预算不足退化 R69 MINT）
def bimp_plan(belief, x, budget, vm):
    if budget.left() < B_PLAN:
        return myopic_r69(belief, x)                       # 含一步可行性检查
    tree = belief_rrt_star(root=(belief, x), keeper=vm)    # 只在恢复管内扩展
    while not budget.exhausted():
        node = tree.sample_and_extend()                    # (a,g) 或 commit
        if vm.tube_ok(node) and all(CREC(r).valid(node) for r in node.rs):
            tree.rewire(node, value=task_value + DVOI)
    return tree.best_plan_with_commit_path()

# IP-273 RA-Guard：高频抢占（Simplex）
def ra_guard(x, proposed, vm, fma_r):
    if vm.margin(x) <= M_TRIGGER or vm.ponr(x) <= 0 or fma_r.uncontrolled(x):
        return RecoveryAction(select_recovery(x, RAL.all()), preempt=True)
    return proposed

    # 标称 / 前跌倒：R69 的 epistemic 机制 + 期限门
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(o, K))
    g = None
    if U_epi > TAU_EPI:
        g = M.dvoi.choose(modes, x, M.vm, M.vsp)           # 来不及则返回 None
    if g is not None:
        U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    plan   = M.bimp.plan(modes, x, M.budget, M.vm)         # 含恢复管约束
    action = M.ra_guard(x, plan.action, M.vm, M.fma_r)     # 守卫有最终否决权
    if action.preempt:
        M.fcr.on_impact(x);  M.vqa_p.submit(...)
    return action
```

## 3. 推导

**引理 19（期限折现的信息无价值与恢复窗口单调收缩）** 设跌倒过程中可恢复集 𝒦(t) 随 t 单调收缩（能量 / 动量不可逆），且恢复启动延迟 Δ 使最坏伤害下界增加至少 c·Δ（c>0 由动力学决定）。若对所有 g 有 τ_res(g) ≥ PONR(x)，则 DVoI(g) ≤ 0，继续观测的期望伤害严格高于立即承诺恢复。故 R69 的「不确定 → 慢 / 问」在 PONR 之后被支配；R70 的弃权不是保守，而是**时间上的最优**。系：TTV / τ_res 比值给出了「可问性」的硬阈值。

**引理 20（恢复管不变式与抢占可行性）** 若 CREC(r) 有效，即 T_r ⊆ R_rec 且 T_r 在扰动界 𝒲 下正向不变，且 t_rec 内可达 Viab，则从任意 x ∈ T_r 执行 r 都不会离开 R_rec，并以 ≥1−δ_rec 的概率在 t_rec 内回到 Viab。若 BIMP 维持 m(x) ≥ m_safe > m_trigger，则守卫触发时 x 仍在 T_r 内，抢占必可行且不会引入新的不可恢复状态。证明：受控不变性归纳 + T_r 的包含关系。

**引理 21（制度切换无抖振与单调安全）** 双阈值迟滞 + 最小驻留 τ_dwell 使制度切换次数在任意有限时间窗内有界，且不会在阈值附近无限振荡。N 制度内 λ_nom 继承 R69 的单调性；F / R 制度内 λ_rec 由最坏伤害最小化定义，其输出对新增不确定性不一定单调减小动作幅度，但对最坏伤害单调不增。跨制度时，守卫触发集 ⊆ 下一制度入口集，故不存在「切到无守卫状态」的窗口。系：允许「快而果断」而不破坏安全单调性，前提是制度边界由守卫而非策略自行决定。

**定理 18（VITAL 对 R69 的严格包含与恢复制度支配）** 当 TTV=∞、R_rec 非空、e=N 时，PONR=∞、G_feas=𝒜_info、c_margin=0、守卫不触发，VITAL 退化为 R69（MINT↔DVOI，BIMP 预算为 0 时↔MINT）。因此 R69 是 VITAL 在「无时间压力、无恢复制度」边界上的严格退化。反之，在 e∈{P,F,R} 时，VITAL 的最坏伤害 ≤ R69；只要 R69 的观测完成时间超过 PONR 或其轨迹离开 R_rec，则严格更小。故 VITAL 在标称侧保持 R69 的效率保证，在恢复侧获得 R69 结构上不可能拥有的安全保证。

**定理 19（信息动作不诱发不可控跌倒）** 在 RA-Guard 与 CREC 同时有效的条件下，任何被执行的信息动作都满足全程 x(t) ∈ R_rec，且守卫在 m_trigger 处仍持有可行恢复；故 P(信息动作导致失控跌倒) ≤ δ_rec + δ_pred + δ_switch，其中 δ_pred 为 VSP 的共形误判率、δ_switch 为切换误判率。若 VSP 检测到 OOD 则 TTV_LCB=0，直接进入恢复，概率上界进一步收紧。

**定理 20（策略性跌倒的最坏伤害最优性）** 若存在状态 x 使所有保持站立的可控轨迹最坏伤害 > s_max，而存在 CREC-valid 的 r_sf 使 severity_upper(r_sf) ≤ min_{stand} worst_severity，则 r_sf 在最小-最大伤害意义下最优；因此「永不跌倒」不是安全不变式。系：把跌倒纳入动作空间不是放弃安全，而是把安全判据从「是否跌倒」升级为「伤害与可恢复性」。

## 6. 本轮最大风险

**一句话**：VITAL-RAS 把安全完全押在「TTV/PONR 预测与恢复可达管在分布偏移下仍然正确」这一前提上——**一旦 VSP 乐观误判（TTV 估大、恢复管估宽），系统会一边自信地问问题一边越过不可返回点，守卫也在错误的时间才触发，把 R69 的「问错」升级为「问到来不及站起来」；反之若过度悲观，则会频繁误触发恢复、把可完成的任务做成不必要的跌倒**。

**次级风险与缓解**：
1. **假恢复证书 / 恢复策略被滥用**（用「策略性跌倒」逃避困难任务）→ CREC 可撤销 + 独立审计 + 定理 20 的最坏伤害判据 + E304/E309；
2. **制度抖振导致执行不连续** → 双阈值迟滞 + 最小驻留 + 守卫单一权威 + E306；
3. **时间投毒与假恢复信号** → 时限证据纪律 + 本体证据独立验证 + E310；
4. **跌倒后标定被冲击污染** → FCR 强制重置 + 禁止旧标定吸收 + E308；
5. **仿真到真机的可行性核偏差** → VSP 共形保守 + OOD 直接恢复 + E314，且守卫永不依赖学习模块。

**定义 312（裕度 / TTV / PONR）** `m(x)=min_w dist(x,∂Viab)`；`TTV(x)=inf{t | 名义+最坏扰动离开 Viab}`；`PONR(x)=TTV(x)−t_rec(x)`；规划一律使用 VSP 的 `TTV_LCB`。

**定义 314（DVOI 与认知弃权）** `DVoI(g)=E[ΔH·1{τ_res<PONR}]−c_task−c_margin`，`c_margin=κ·(m(x)−min_t m(x(t)|g))`；`G_feas=∅` 或 `max DVoI ≤ 0` ⇒ 认知弃权、交给 RAL。R69 MINT 是 `PONR=∞, c_margin=0` 的特例。

**定义 315（恢复增强动作空间）** `ξ=(a,g,r)∈𝒜_task×𝒜_info×({∅}∪Π_rec)`；`r_sf∈Π_rec` 为策略性跌倒宏（团身 / 侧滚 / 受控接触）。

**定义 318（FMP-R）** `v_θ(x_s,s|z_t,e_t,r)`；条件 flow matching；训练集含跌倒 / 恢复 / 策略性跌倒；推理只允许 CREC-valid 模态进入执行。

**定义 319（CREC）** `CREC(r)=(r_id,entry_set,T_r,t_rec,s_max,δ_rec,VSP_version,calibration_version)`；Valid ⇔ `T_r⊆R_rec` ∧ `T_r` 正向不变 ∧ C-RAS-WM† 前缀认证通过 ∧ TTV_LCB 共形覆盖达标；可审计、可撤销。

**定义 320（BIMP）** `π*=argmax E[Σ γ^k(R_task+DVoI_k)−c_exec]`，s.t. `x_k∈R_rec`、预算未越界、每个节点选 `g∈G_feas` 或 commit；包含即时 VoI=0 但期权价值 >0 的「移动到有利位姿」；预算不足退 R69 MINT + 一步可行性检查。

**定义 321（VSP）** TTV/PONR 学习预测器 + 共形下界 `TTV_LCB=TTV_hat−q_α`，`P(TTV<TTV_LCB)≤α`；OOD ⇒ `TTV_LCB=0`，直接恢复，绝不乐观外推。

**定义 322（RA-Guard）** 双速率 Simplex：≥500Hz 守卫只读 `m,TTV_LCB,e_t` 并拥有抢占权；≤20Hz BIMP 只提议；`m≤m_trigger` 或 `PONR≤0` 或失控跌倒 ⇒ 强制 `r←RAL.select`，冻结信息动作；守卫不学习、不写参数。

**定义 323（FCR）** 跌倒 / 冲击使 `J_CALM` 与 FMA 基线失效；进入 R 后冻结旧标定 → 已知参照下重采集 → 重算 `J_CALM`/FMA 基线 → 重新认证通过才允许 N；禁止把冲击残差解释为噪声直接复位。

**定义 324（FMA-R）** 跌倒起始分 `= w1·(−log p_θ(ξ_obs|o)) + w2·(m 的塌缩速率) + w3·(非计划接触)`；有 CREC-valid 且被计划执行的 r ⇒ 受控跌倒；否则失控跌倒，触发急停 + FCR + 审计升级。

**定义 325（AIC-VITAL）** `ℰ_VITAL=ℰ_FLUID×ℰ_temporal×ℰ_physical×ℰ_false`；时限证据纪律：过期证据按缺失处理；恢复就绪信号须由本体证据（接触 / 姿态 / 能量）独立验证。

**定义 326（J_VITAL）** `(J_FLUID, regime_log_hash, TTV_LCB_p50/p95, PONR_min, margin_min, recovery_id, CREC_valid, severity_bound, dvoi_before/after, preemption_log_hash, fcr_version)`；Valid ⇔ `J_FLUID` 有效 ∧ 全程 `x∈R_rec` ∧ 无守卫违规 ∧ 期限纪律满足 ∧ CREC 未过期。

**定义 327（受控跌倒与伤害预算）** `r_sf` 可采纳 ⇔ CREC 有效 ∧ `severity_bound≤s_max` ∧ 所有站立轨迹最坏伤害 > 该界 ∧ 之后存在回到 Viab 的恢复路径；「永不跌倒」不是安全不变式。

```python
# IP-264 VM：可行性监控（每 tick，极轻）
class ViabilityMonitor:
    def margin(self, x):
        return min_dist_to_boundary(x, self.dist_bound)       # 管状裕度
    def ponr(self, x, vsp, t_rec):
        return vsp.ttv_lcb(x) - t_rec                          # 不可返回点

# IP-265 RPM：制度状态机（迟滞 + 最小驻留）
def regime_update(prev, x, vm, fma_r, now, last_switch):
    e = classify_regime(x, vm, fma_r)
    if e == prev: return prev
    if now - last_switch < TAU_DWELL: return prev
    if not crosses_hysteresis(prev, e, x, HYST): return prev
    return e

# IP-266 DVOI：期限折现的信息价值；不可行即弃权
def deadline_voi(cands, w, x, vm, t_rec):
    D, best = vm.ponr(x, t_rec), None
    for g in cands:
        if not vm.tube_ok(x, g):             continue     # 硬可行性
        if tau_res(g) >= D - TAU_MARGIN:      continue     # 来不及
        score = expected_info_gain(w, g) - cost(g) - vm.margin_cost(x, g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None         # None = 认知弃权

# IP-269 FMP-R：恢复条件流策略（复用 R69 trunk）
class RecoveryFlowPolicy:
    def sample(self, o_t, K, regime, r=None, N_step=2):
        z  = self.trunk(o_t);  c = cond_token(z, regime, r)
        xs = randn(K, D)
        for i in range(N_step):
            xs = xs + (1.0/N_step) * self.v(xs, i/N_step, c)
        return [self.decode(x) for x in xs]                   # ξ=(a,g,r)

# IP-268 RAL：恢复动作选择（最坏伤害最小 + 证书）
def select_recovery(x, cands):
    ok = [r for r in cands if CREC(r).valid(x)]
    return min(ok, key=lambda r: CREC(r).severity_upper(x), default=None)

# IP-267 BIMP：非短视信息-运动规划（预算不足退化 R69 MINT）
def bimp_plan(belief, x, budget, vm):
    if budget.left() < B_PLAN:
        return myopic_r69(belief, x)                          # 含一步可行性检查
    tree = belief_rrt_star(root=(belief, x), keeper=vm)       # 只在恢复管内扩展
    while not budget.exhausted():
        node = tree.sample_and_extend()                       # (a,g) 或 commit
        if vm.tube_ok(node) and all(CREC(r).valid(node) for r in node.rs):
            tree.rewire(node, value=task_value + DVOI)
    return tree.best_plan_with_commit_path()

# IP-273 RA-Guard：高频抢占（Simplex）
def ra_guard(x, proposed, vm, fma_r):
    if vm.margin(x) <= M_TRIGGER or vm.ponr(x) <= 0 or fma_r.uncontrolled(x):
        return RecoveryAction(select_recovery(x, RAL.all()), preempt=True)
    return proposed

# IP-276 主闭环（继承 R69）
def VITAL_RAS_round(M, obs):
    z, o = M.mtm.forward(...);  x = M.state_est.update(o)
    e    = M.rpm.update(x, M.vm, M.fma_r, now)
    if e in (FALLING, POST_FALL):                             # 恢复制度：不再问
        return M.exec(M.ral.select(x), x)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(o, K))
    g = M.dvoi.choose(modes, x, M.vm, M.vsp) if U_epi > TAU_EPI else None
    if g is not None:
        U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    plan   = M.bimp.plan(modes, x, M.budget, M.vm)            # 含恢复管约束
    action = M.ra_guard(x, plan.action, M.vm, M.fma_r)        # 守卫最终否决
    if action.preempt:
        M.fcr.on_impact(x);  M.vqa_p.submit(...)
    return action
```

## 4. 推导

**引理 19（期限折现的信息无价值）** 设可恢复集随跌倒时间单调收缩，恢复延迟 Δ 使最坏伤害下界增加 ≥ c·Δ（c>0）。若对所有 g 有 `τ_res(g) ≥ PONR(x)`，则 `DVoI(g)≤0`，继续观测的期望伤害严格高于立即承诺恢复。故 R69 的「不确定 → 慢 / 问」在 PONR 之后被支配；R70 的弃权是时间上的最优，而非保守。

**引理 20（恢复管不变式与抢占可行性）** 若 `CREC(r)` 有效（`T_r⊆R_rec` 且扰动界下正向不变，`t_rec` 内可达 Viab），则从任意 `x∈T_r` 执行 r 不离开 `R_rec`，并以 ≥`1−δ_rec` 概率在 `t_rec` 内回到 Viab。若 BIMP 维持 `m(x)≥m_safe>m_trigger`，守卫触发时仍在 `T_r` 内，抢占必可行，不引入新的不可恢复状态。

**引理 21（制度切换无抖振与单调安全）** 双阈值迟滞 + 最小驻留使制度切换次数在有限时间窗内有界，阈值附近无无限振荡。N 内 `λ_nom` 继承 R69 单调性；F/R 内 `λ_rec` 对最坏伤害单调不增（不要求动作幅度单调）。守卫触发集 ⊆ 下一制度入口集，故无「切到无守卫状态」窗口。

**定理 18（VITAL 严格包含 R69 且恢复制度支配）** 当 `TTV=∞, R_rec≠∅, e=N` 时，`PONR=∞`、`G_feas=𝒜_info`、`c_margin=0`、守卫不触发，VITAL 退化为 R69（MINT↔DVOI，BIMP 预算为 0 时↔MINT）。故 R69 是「无时间压力、无恢复制度」边界上的严格退化。在 `e∈{P,F,R}` 时，VITAL 最坏伤害 ≤ R69；若 R69 的观测完成时间超过 PONR 或其轨迹离开 `R_rec`，则严格更小。

**定理 19（信息动作不诱发不可控跌倒）** RA-Guard 与 CREC 同时有效时，任何被执行的信息动作满足全程 `x(t)∈R_rec`，且守卫在 `m_trigger` 处仍持有可行恢复；故 `P(信息动作→失控跌倒) ≤ δ_rec + δ_pred + δ_switch`。VSP 检出 OOD 时 `TTV_LCB=0` 直接恢复，上界进一步收紧。

**定理 20（策略性跌倒的最坏伤害最优性）** 若存在状态使所有站立轨迹最坏伤害 > `s_max`，而某个 CREC-valid `r_sf` 的 `severity_upper` 不大于所有站立方案的最坏伤害，则 `r_sf` 在最小-最大伤害意义下最优；故「永不跌倒」不是安全不变式，安全判据应从「是否跌倒」升级为「伤害与可恢复性」。

## 7. 本轮最大风险

**一句话**：VITAL-RAS 把安全完全押在「TTV/PONR 预测与恢复可达管在分布偏移下仍正确」这一前提上——**一旦 VSP 乐观误判，系统会一边自信地问问题一边越过不可返回点，守卫也在错误的时间才触发，把 R69 的「问错」升级为「问到来不及站起来」；反之过度悲观则频繁误触发恢复，把可完成的任务做成不必要的跌倒**。

**次级风险与缓解**：假恢复证书 / 策略性跌倒被滥用（CREC 可撤销 + 独立审计 + 定理 20 最坏伤害判据 + E304/E309）；制度抖振（双阈值迟滞 + 最小驻留 + 守卫单一权威 + E306）；时间投毒与假恢复信号（时限证据纪律 + 本体证据独立验证 + E310）；跌倒后标定被冲击污染（FCR 强制重置 + 禁止旧标定吸收 + E308）；仿真到真机的可行性核偏差（VSP 共形保守 + OOD 直接恢复 + E314，守卫永不依赖学习模块）。
