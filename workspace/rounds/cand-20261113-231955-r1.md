# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「中间件」×「技术路线图」）

> R69 给闭环装上了「嘴」：把不确定性拆成 aleatoric / epistemic，用流匹配策略显式呈现多个动作模态，用主动多模态交互（看/问/触/等）去消解歧义，并用流似然作为「标定不可吸收」的第二意见。它的回答是「我该向谁求证、还能问什么」。
>
> 但 R69 也把系统推到了一个更危险的结构位置：闭环现在是 **FMP × AUD × MINT × CIA × FMA × MCG × VQAuditor-I** 的层层叠加，每一层都有自己的局部保证，**而「这些局部保证能否在运行时同时成立」只由散文担保**。R69 自陈的最大风险（模态权重不可信 → 追问幻影/给误导回答盖章）本质上不是某一个模型的问题，而是 **组合问题**：某个模块在某个成熟度上、在某个契约假设下、与另一模块耦合时，是否还被允许影响执行器？没有运行时实体回答这个问题。于是每加一层，就多一个「必须整体信任」的黑箱——**研究越进步，系统越不可审计**。
>
> 本轮两个灵感正好补上这块结构性缺失：
> - **中间件**：不是消息总线，而是 **契约与证据的仲裁层**——跨组件边界的每个信号都携带来源、时效、置信与认证等级；中间件按任务风险预算决定它能否进入执行路径，做时间隔离、影子运行与降级路由。
> - **技术路线图**：把「本轮严格包含上一轮」从散文承诺变成 **可执行的路线图**——能力 DAG + 成熟度等级 + 晋升/降级谓词；运行时在 DAG 上解析出一条「当前证据允许走的路」，审计则用 **元 VoI** 决定下一轮该验证什么、升级什么、弃用什么。
>
> 核心命题：**把研究史变成可执行路线图，把架构集成变成有契约的中间件；任何新层默认以影子（L0）进入，只能被「永远有效」的证据逐级晋升，组合风险默认按最坏相关性合成。** 命名 **ROUTE-RAS**（Roadmap-Orchestrated, cOntract-based, Uncertainty-aware Trust Engine）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我此刻被允许信任哪个能力、以什么组合、在什么成熟度上——以及下一个该验证什么**」。
>
> 理论姿态不变：**R69（以及 R68）是 ROUTE 在「单一路由、全部 L2、无影子、无中间件调度」边界上的严格退化**；安全侧不做任何让步，新增的是可组合性、可演进性与可审计性。

## 0. 直觉与动机

**灵感 1（中间件 → 安全不是一个模型的性质，而是一组边界的性质）**
直觉：R68 的 C-RAS-WM 管住了「动作→世界」，R69 的 C-RAS-WM† 管住了「信息动作→世界」，但没有人管「**模块→模块**」。工程上，中间件（DDS/ROS2、服务网格、agent tool-middleware）解决的恰恰是这类问题：异质组件彼此不知道对方存在，只通过一套契约交换消息；中间件负责寻址、QoS、时效、隔离、版本与降级。把它抬到安全层，就是：**每个跨边界信号都是一个「证据包」**（值 + 来源 + 时间戳 + 新鲜度 + 置信 + 认证等级 + 版本 + 签名），中间件按任务声明的风险预算做准入：能直接影响执行器的，必须是「已认证且在包络内」的证据；否则只能进影子通道。这样 R69 定义 293-iii 的「k 个正交证据源一致」从一个局部规则升级为**架构级不变量**——不是靠每个模块自觉，而是靠边界强制执行。
两种读法其实同一件事：(a) 系统中间件（实时 pub/sub、QoS、deadline）；(b) agent 中间件（guardrail、工具路由、权限）。二者都可归约为 **契约 + 来源 + 准入**。
直觉结论：**把「信任」做成中间件的一项服务，而不是每个模块的一种美德。**

**灵感 2（技术路线图 → 研究史必须能被运行时读懂）**
直觉：过去几轮的「新层包含旧层」是一句人类可读的路线图承诺，但运行时并不知道「这一层现在成熟到哪、允许影响什么」。真实的技术路线图有 TRL（成熟度）、里程碑、依赖、门禁与弃用计划；我们把它形式化：**能力单元（capability unit）构成 DAG，每个单元有证据谓词与成熟度等级 L0–L3**。新模块（如 R69 的 FMP/MINT）**从 L0 影子进入**，先只读、只记录、只审计；只有当「永远有效」的统计证据（不是一次性离线指标）证明它在分布内、不劣于基线、且组合风险不越界时，才晋升 L1（受保护执行）/L2（包络内认证）/L3（可组合认证）。
直觉结论：**路线图不是给评审看的 PPT，而是运行时的一张「通行证」；没有通行证的模块可以运行，但不能掌舵。**

**灵感 3（递归 → 路线图规划本身就是 R69 的 VoI 问题，只是抬升了一层）**
直觉：R69 用 VoI 选择「哪个信息动作最能降低模态不确定性 / 成本」。那么「下一轮该做哪个实验、验证哪个能力、升级哪个门」本质上也是同一道题：**哪个验证动作最能降低「我对系统安全论证的 epistemic 不确定性」/ 成本**。于是路线图不是静态文档，而是被审计证据不断重规划的活对象：`MRP`（元 VoI 规划器）在能力 DAG 上选择下一个「实验性信息动作」。这是本轮最漂亮的结构闭合——**系统在运行时如何对待不确定性，就该如何对待自身演进的不确定性**。同一套数学，上下两层。

**灵感 4（组合数学 → 「无证据不得假设独立」）**
直觉：R69 的定理 16 说 FLUID 期望风险 ≤ R68，但这类结论通常隐含「各通道失效独立」。真实系统里，传感器漂移、标定错误、策略幻觉、人类误导往往**同源相关**；把相关性当 0 会系统性低估组合风险。中间件正好是强制这条纪律的地方：**默认按最坏相关（comonotone，ρ=1）合成；只有测得了相关结构，才允许下调 ρ，并且下调本身要有证据包。** 这不是保守主义的美德，而是 Fréchet–Hoeffding 界给出的硬事实：在只知道边际风险时，ρ=1 给出合法上界，ρ<1 需要额外信息。

**灵感 5（路线图与中间件都是双刃剑 → 新的「证书剧场」威胁）**
直觉：一旦引入门禁与晋升，就有了新的攻击面与新的自欺方式：**Goodhart**——指标被优化成「通过门」而不是「真的安全」；**能力冒充**——低成熟度模块伪造证据包或版本号；**降级攻击**——把系统逼到旧版本/低等级以便利用已知漏洞；**中间件本身成为单点**——它若延迟或失序，整个实时环被拖垮。最阴险的是 **证书剧场**：每层都通过了门，但门的谓词、证据留出集、合成假设从未被独立审计；于是系统带着一叠漂亮证书运行一个从未被真正验证过的组合。R70 必须交付「审计审计者」的机制，否则中间件只是给 R69 的黑箱加了个带公章的封条。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（ROUTE-RAS 总览）** ROUTE-RAS = (TRUSTBUS, CRL, AGC, TIG, RRS, PDC, MRP, CIG, VQAuditor-M, RAS-WM‡)。五不变式：
(i) **无契约不执行**：任何跨组件边界的信号都必须落在某条已注册边 e=(u→v) 的契约 C_e 内；无契约边默认拒绝；
(ii) **无证据不掌舵**：能力单元 ℓ 的成熟度必须 ≥ 任务要求 ℓ_req(mission) 才可进入执行路径；否则只能影子；
(iii) **风险预算守恒**：路线 r 的组合风险 r_comp(r) ≤ ε_mission − margin，否则解析器必须降级到可行路线（兜底路线 r0 恒可行）；
(iv) **时间隔离**：任何组件不得侵占其他组件的 deadline；K 升采样等一次性开销必须由显式 slack 准入；
(v) **版本可溯源**：每个执行决策可追溯到 (roadmap_epoch, component_ver, evidence_ref)，账本只追加不删改。

**定义 311（证据包 EP）** EP = (payload, prov, t_src, t_exp, conf, ev_ref, cap_id, lvl, epoch, σ)。其中 prov 为来源链，t_exp 为过期时刻，ev_ref 指向账本证据，lvl 为产生该证据的能力成熟度，σ 为中间件签名。payload 可为观测、动作、风险估计、证书或拒绝理由。

**定义 312（契约边界与授权）** 有向边 e=(u→v) 的契约 C_e = (A_e, G_e, resource_e, risk_e, fmt_e)。授权谓词 authz(EP,e) ⇔ fresh(EP) ∧ signed(EP) ∧ cap(EP)∈dom(e) ∧ lvl(EP) ≥ ℓ_req(e) ∧ conf(EP) ≥ c_e。不满足即被 TRUSTBUS 丢弃并记一条 reject 审计，而不是「尽力送达」。

**定义 313（能力单元 CU）** CU = (id, req, modes, ev_pred, ℓ, wcet, jitter, cost, deps, ver, dep_t)。req 为前置能力集；modes 为该能力可运行的模式（data/shadow/guarded/active）；ev_pred 为晋升证据谓词；ℓ∈{L0,L1,L2,L3}；wcet/jitter 供时间准入；dep_t 为弃用窗口。

**定义 314（路线图 DAG 与路线）** 路线图 G = (CU, ≺)，≺ 为依赖偏序。路线 r ⊆ CU 是**下闭集**（若 u∈r 且 v≺u 则 v∈r），且满足任务需求集合。路线还固化版本组合 ver(r)。「路线」既是技术路线图上的一条路径，也是中间件上的一组路由表——两个「路线」在此统一。

**定义 315（成熟度等级与任务要求）** L0 影子（只读、只审计，永不执行）；L1 受保护执行（执行但必须有兜底且影响有界，‖Δu‖≤δ_L1）；L2 包络内认证（R68/FLUID 证书有效）；L3 可组合认证（L2 + 契约义务被 AGC 证明已 discharge + 组合风险留有余量）。任务需求 ℓ_req 由风险等级给出；R68/FLUID 的常规任务默认为 L2。

**定义 316（假设-保证契约）** 组件 i 的契约 C_i = (A_i, G_i, W_i, ρ_i)：在假设 A_i 下保证 G_i，资源/时序约束 W_i，内禀风险 ρ_i。组合规则：若对每条边 u→v 有 G_u ⇒ A_v，则称该组合 **契约闭合**；否则必须插桩或拒绝该路线。

**定义 317（组合风险与相关性纪律）** 多通道风险合成 r_comp = Σ_i r_i + Σ_{i<j} ρ_ij √(r_i r_j)，其中 r_i 为分量风险上界。**纪律：无独立证据时 ρ_ij = 1（comonotone 最坏相关）**；由 Fréchet–Hoeffding 界，任意未知相依结构下该值给出合法上界。仅当有可审计的相关性证据包时，才允许 ρ_ij<1，且 ρ 的估计误差必须计入 margin。这条规则直接反驳「默认独立」的常见隐性假设。

**定义 318（时间准入 TIG）** 每个 CU 声明 (wcet_i, jitter_i, prio_i)。调度器对候选活跃集 S 计算 E2E 响应上界 R(S)；准入条件 R(S) ≤ D_mission − slack_reserve。一次性多采样（R69 的 K=4）必须作为「可抢占的可选任务」申请预算，未获预算即回落 K=1，而不是「尽力而为」。

**定义 319（路线解析 RRS）** 给定任务 m 与当前证据账本 E，解析 r* = argmax_{r 可行} V(r;m)，s.t. r_comp(r) ≤ ε_mission − margin、时间准入通过、ver(r) 已注册。可行路线族至少含兜底路线 r0（= R68/FLUID 基线，全部 L2、无影子、单路由）。解析在任务开始时做一次，运行中仅在证书失效/漂移/降级事件触发时重解析。

**定义 320（影子与序贯背离检验）** L0 能力的提议动作 a^sh 与活跃路线动作 a^act 计算背离统计量（动作空间 + 风险估计 + 模态分布的三联检验）。用 **always-valid e-process / 时间一致置信序列** 而非固定样本 p 值，保证「任意时刻查看」下的误晋升概率 ≤ α。影子不写执行器，只写账本。

**定义 321（晋升/降级 PDC）** 晋升 u: ℓ→ℓ+1 当且仅当：(a) e-process 拒绝「不优于基线」；(b) 对安全指标的下置信界 > 0；(c) 组合后 r_comp 仍满足预算；(d) 独立审计签署。降级立即发生（无滞回）于：证书失效、漂移检出（R68/FLUID 通道）、契约违约、或相关性能证据过期。防振荡靠「晋升慢、降级快」的非对称滞回，而非对称阈值。

**定义 322（元 VoI 路线图规划 MRP）** 把「下一项验证」视为信息动作 e：MetaVoI(e) = H_safety(C | E) − E_{y~p(·|e,E)}[H_safety(C | E,y)]，选择 e* = argmax [MetaVoI(e) − cost(e)]，s.t. 预算；停止规则：若 max(MetaVoI − cost) ≤ 0，则冻结路线图，只做在线监控。这把 R69 的 MINT 从「运行时问谁」抬升为「研发期验什么」，且共享同一套 VoI 语义。

**定义 323（契约完整性 CIG / 反博弈）** 证据必须满足：留出集与训练/调参集不相交、由独立审计者签名、门谓词定期轮换（防过拟合门）、指标包含「对抗性/分布外」分量。定义 **Goodhart 上界**：若门谓词族的 VC 维/容量有限且证据来自独立留出分布，则可博弈增益被限制在 O(√(capacity/n)) + δ_adversarial。无独立留出的证据只能把能力推到 L1，绝不能到 L2+。

**定义 324（中间件攻击面）** 新增威胁：证据包伪造/重放（无 nonce/epoch 单调）、版本混淆与降级攻击、能力冒充（低 ℓ 伪造高 ℓ）、路由表投毒（把执行流量导到 L0 节点）、拒绝服务式门禁（拖慢 deadline）。对策：单调 epoch + 签名 + 版本钉扎 + 最小权限路由 + 每边独立密钥 + 拒绝即审计。

**定义 325（证书 J_ROUTE）** J_ROUTE = (J_FLUID, route_id, ver(r), {ℓ_i}, contract_discharge_hash, r_comp_margin, shadow_divergence_p95, roadmap_epoch, middleware_hash, auditor_sig)。Valid ⇔ Valid(J_FLUID) ∧ 契约闭合 ∧ r_comp ≤ ε_mission − margin ∧ 时间准入通过 ∧ 账本可复现。J_ROUTE 是「组合级」证书，取代此前「单模块级」证书的简单并列。

**定义 326（溯源账本与路线图纪元）** 账本 L 为只追加的 (时间, EP 摘要, 能力, 等级变更, 证据引用, 审计签名)。roadmap_epoch 每次晋升/降级/弃用递增。任何历史决策可用账本重放：**可复现性是 ROUTE 的一等公民**，也是「审计审计者」的原料。

**定义 327（路线图债与弃用）** 每个能力有弃用窗口 dep_t；超期仍被路线引用即记「路线图债」。债预算 B_debt：超过则禁止新任务使用该路线，强制迁移。技术债和金融债一样，必须有上限与到期日，否则「临时兼容」会变成永久攻击面。

**定义 328（严格包含 FLUID/R68）** 令 r_0 为单一路线、全部组件 L2、无影子、TIG 不干预（总 slack 充足）、ρ 取 FLUID 内部假设的基线值，则 ROUTE 的决策分布与 FLUID 逐指令一致。因此 FLUID/R68 是 ROUTE 在「路线图退化为单点、中间件透明」边界上的退化。

## 2. 关键算法骨架

```python
# IP-264 TRUSTBUS：证据包中间件（拒绝即审计，绝不「尽力送达」）
class TrustBus:
    def __init__(self, routes, ledger):
        self.routes, self.ledger = routes, ledger          # 当前路线 r* 的路由表

    def publish(self, ep, e):
        if not self.authorized(ep, e):                     # fresh/signed/cap/lvl/conf
            self.ledger.reject(ep, e); return False
        if not self.tig.admit(e, ep):                      # 时间准入（IP-267）
            self.ledger.reject(ep, e, reason='deadline'); return False
        return self.deliver(ep, e)

    def authorized(self, ep, e):
        c = self.routes[e]
        return (ep.t_src <= now <= ep.t_exp and verify(ep.sig)
                and ep.cap_id in c.domain and ep.lvl >= c.lvl_req
                and ep.conf >= c.conf_min)

# IP-265 CRL：能力账本 + 路线图 DAG（只追加；版本钉扎）
def register_capability(cu, ledger):
    assert deps_registered(cu, ledger)                     # 下闭性
    ledger.append(('CAP_REG', cu.id, cu.ver, cu.lvl, cu.ev_pred))

def downward_closure(route, G):                            # 路线必须下闭
    return {u for u in G if all(v in route for v in ancestors(u))}

# IP-266 AGC：假设-保证契约合成 + 最坏相关风险
def compose(route, contracts):
    for u, v in edges(route):
        if not implies(contracts[u].G, contracts[v].A):
            return None                                    # 契约不闭合 → 路线无效
    r = sum(c.rho for c in contracts.values())
    for i, j in pairs(route):                              # 默认 ρ=1：无证据不假设独立
        rho = measured_rho(i, j) or 1.0
        r += rho * sqrt(contracts[i].rho * contracts[j].rho)
    return r

# IP-267 TIG：deadline 准入（K=4 多采样是可选任务，不是特权）
def admit(S, mission):
    R = e2e_response_bound(S + mission.active)             # wcet/jitter/prio 分析
    return R <= mission.deadline - mission.slack_reserve

# IP-268 RRS：在能力 DAG 上解析「证据允许走的路」
def resolve_route(mission, G, ledger):
    feasible = [r for r in downward_closed_routes(G, mission)
                if versions_registered(r) and tig.admit(r, mission)
                and compose(r, ledger.contracts) <= mission.eps - mission.margin]
    if not feasible: return BASELINE_ROUTE                 # r0 恒可行（定理 18）
    return max(feasible, key=lambda r: mission.value(r))

# IP-269 PDC：always-valid 影子检验 → 晋升慢、降级快
def shadow_gate(a_sh, a_act, eprocess, alpha):
    eprocess.update(divergence(a_sh, a_act))
    return eprocess.reject_null(alpha)                     # 任意时刻有效，误晋升 ≤ α

def promote_or_demote(cu, evidence, ledger):
    if certificate_invalid(cu) or drift_detected(cu) or contract_violated(cu):
        return demote(cu)                                  # 立即，无滞回
    if shadow_gate(*evidence.shadow, cu.eprocess, ALPHA) and evidence.lcb_safety > 0:
        return promote(cu, require=('holdout', 'auditor_sig'))  # 最高到 L2/L3

# IP-270 MRP：元 VoI——下一项验证也是信息动作
def plan_next_experiment(route, safety_posterior, budget):
    gains = {e: (entropy(safety_posterior)
                 - expected_entropy(safety_posterior, e)) - cost(e)
             for e in candidate_experiments(route)}
    best = max(gains, key=gains.get)
    return best if gains[best] > 0 else None               # 无利可图 → 冻结路线图

# IP-275 主闭环：R69 的 FLUID 决策被包在「路线 + 中间件」里
def ROUTE_RAS_round(M, mission, obs):
    r = M.rrs.route                                    # 任务开始时解析一次
    eps = {u: M.bus.pack(u, obs) for u in r.active}    # 每个信号都是证据包
    fl = M.fluid.step(M, eps)                          # R69：模态/交互/似然第二意见
    # 能力晋升只通过中间件放行；L0 只能影子
    ep = M.bus.pack('fluid_decision', fl)
    if not M.bus.publish(ep, edge=('fluid', 'actuator')):
        fl = M.rrs.baseline_step(M, eps)               # 拒绝即回退，不等价于「重试」
    if M.pdc.should_recheck(fl): M.pdc.update(fl, M.ledger)
    if M.rrs.invalidated(M.ledger):
        r = M.rrs.resolve_route(mission, M.G, M.ledger)
    return fl, r, M.jroute.sign(fl, r, M.ledger)
```

## 3. 推导

**引理 19（最坏相关上界）** 设各通道风险上界 r_i，真实失效事件 E_i。由 Fréchet–Hoeffding 不等式，任意联合分布下 P(∪E_i) ≤ min(1, Σ_i P(E_i))，而 comonotone 构造达到该上界；故在缺乏相依证据时取 ρ_ij=1 不会低估组合风险。系：定义 317 的「无证据不得假设独立」是唯一可辩护的默认值。

**引理 20（影子门的有界影响）** 若执行路径只接受 ℓ ≥ ℓ_req 的能力，且 L0 仅写账本、L1 影响满足 ‖Δu‖ ≤ δ_L1，则任意时刻系统的执行风险 ≤ r_comp(r*) + δ_L1·1[存在 L1 活跃]。证明要点：未被放行的提议不改变执行器输入；被放行的 L1 影响有界。系：**影子运行把「新模块风险」从「可能致命」降为「可审计的有界扰动」**。

**引理 21（Goodhart 受限）** 若门谓词族容量有限、证据取自与调参独立的留出分布、且含对抗分量，则通过博弈门获得的表观增益与真实增益之差 ≤ O(√(V/n)) + δ_adv。证明要点：一致收敛 + 对抗项三角不等式。系：定义 323 要求「无独立留出只能到 L1」，否则晋升不可辩护。

**定理 18（ROUTE 严格包含 R68/FLUID）** 在定义 310–328 与 A99（契约闭合、时间分析可靠）下：(a) 兜底路线 r0 恒可行，故任意任务总有安全解；(b) 当 r=r0、TIG 不干预、无影子、ρ 取 FLUID 基线时，ROUTE 与 FLUID 逐指令一致；(c) 对任意路线，r_comp ≤ ε_mission ⇒ 期望任务风险 ≤ ε_mission。因此安全侧不弱于 R69，且获得可组合性与可演进性。证明：由 (b) 得退化一致；由 AGC 与引理 19 得 (c)。

**定理 19（时间隔离 ⇒ 无 deadline 击穿）** 若每个活跃组件满足 wcet/jitter 约束且准入集 S 满足 R(S) ≤ D − slack，则端到端响应上界不超过 D；K=4 多采样等一次性开销因未获准入而无法抢占控制周期。系：R69 的「实时预算被 K 采样击穿」风险由架构而非统计运气消除。

**定理 20（晋升的 anytime 可靠性）** 采用 e-process/时间一致置信序列做影子检验，则对任意停止时刻 τ（由数据/审计/人为决定），P(在 τ 之前错误晋升) ≤ α。证明：e-process 的 Ville 不等式 / 混合鞅可选停止定理。系：**晋升决策本身不再需要「跑完固定样本量」的童话**，可随时审计、随时叫停。

**引理 22（路线可行性单调）** 若路线 r 可行，则其任意下闭子路线 r' ⊆ r 可行（在风险与时间预算上单调更省）；故降级永远有解，不存在「降级后无路可走」的死锁。系：安全兜底不是特例而是偏序结构的下界。

**定理 21（可组合证书）** 若 (i) 每条边契约闭合，(ii) 各能力证书有效，(iii) r_comp ≤ ε_mission − margin，则 J_ROUTE 有效且组合期望风险 ≤ ε_mission。证明：由 AGC 的 assume-guarantee 传递性与引理 19 的风险上界直接得到。系：**证书第一次是「组合级」而非「并列级」的**——这正是 R69 缺失的那块。

## 4. 复杂度分析

| 组件 | 时间 | 空间 | 正确性保证 |

## 6. 本轮最大风险

**一句话**：ROUTE-RAS 把安全押在「中间件的能力账本与契约合成规则本身正确且不可被博弈」上——**一旦合成假设（尤其相关性默认值）、时间分析或晋升门被静默证伪，系统就会带着一叠合法证书运行一个从未被真正验证过的组合；此时「已认证」不是保护色，而是最危险的保护色。** 中间件还同时引入了单点故障、额外延迟与全新攻击面，若 TIG/签名/版本钉扎任一失效，前四轮的安全边际会被一次性吃掉。

## 2. 形式化定义（要点版）

**定义 310（总览与五不变式）** 无契约不执行；无证据不掌舵（ℓ ≥ ℓ_req 才能进执行路径）；风险预算守恒（r_comp ≤ ε−margin，兜底 r0 恒可行）；时间隔离（不得侵占他者 deadline）；版本可溯源（决策可追溯至 roadmap_epoch/component_ver/evidence_ref）。

**定义 313–315（能力单元 / 路线图 DAG / 成熟度）** 能力单元声明依赖、模式、证据谓词、ℓ、WCET、成本、版本、弃用窗口；路线 r 为下闭集且固化版本；L0 影子、L1 受保护执行（影响 ≤ δ_L1）、L2 包络内认证、L3 可组合认证。

**定义 316–317（契约合成与相关性纪律）** 契约 `C_i=(A_i,G_i,W_i,ρ_i)`；对每条边 u→v 需 `G_u ⇒ A_v` 才算契约闭合。风险 `r_comp=Σr_i+Σ_{i<j}ρ_ij√(r_i r_j)`；**默认 ρ=1（comonotone 上界，Fréchet–Hoeffding）**，ρ<1 需可审计相关证据并计入估计误差。

**定义 318（时间准入）** 依 wcet/jitter/prio 计算 E2E 响应上界 R(S)，要求 `R(S) ≤ D − slack_reserve`；K=4 是可选任务，未获预算即回落 K=1。

**定义 319（路线解析）** 选 `r*=argmax V(r;m)`，s.t. 契约闭合、`r_comp≤ε−margin`、时间准入、版本已注册；可行族含 r0；仅在证书失效/漂移/降级时重解析。

**定义 320–321（影子检验与晋升/降级）** 影子背离用 always-valid e-process，任意时刻误晋升 ≤ α；晋升需「优于基线的下置信界 > 0 + 契约闭合 + 风险余量 + 独立审计签名」；降级立即（证书失效/漂移/违约/证据过期），晋升慢降级快以防振荡。

**定义 322（元 VoI 路线规划）** `e*=argmax[MetaVoI(e)−cost(e)]`，`MetaVoI` 定义为安全论证后验熵的期望下降；无利可图即冻结路线图、只做在线监控。运行时的 MINT 与研发期的 MRP 是同一 VoI 语义的两层实例。

**定义 323（反博弈 / CIG）** 证据须独立留出、审计签名、门谓词轮换、含对抗/OOD 分量；Goodhart 表观-真实增益差受 `O(√(V/n))+δ_adv` 限制；无独立留出的证据只能升到 L1。

**定义 324（中间件攻击面）** 伪造/重放（单调 epoch+nonce）、版本混淆/降级（版本钉扎）、能力冒充（ℓ 签名）、路由投毒（最小权限 + 每边密钥）、门禁 DoS（deadline 预算）。对策：拒绝即审计、失败即降级，绝不「尽力送达」。

**定义 325–327（证书 / 账本 / 债）** `J_ROUTE=(J_FLUID, route_id, ver, ℓ, contract_hash, margin, shadow_p95, epoch, mw_hash, sig)`；账本只追加、可重放；能力超弃用窗口仍被引用即记路线图债，超 `B_debt` 禁止该路线承新任务。

**定义 328（严格包含）** r=r0、TIG 不干预、无影子、ρ 取 FLUID 基线时，ROUTE 与 FLUID 逐指令一致；故 R68/R69 是「路线图退化为单点、中间件透明」的下界退化。

## 3. 关键算法伪代码

```python
# IP-264 TRUSTBUS：证据包中间件（拒绝即审计，不做「尽力送达」）
class TrustBus:
    def publish(self, ep, e):
        c = self.routes[e]
        ok = (fresh(ep) and verify(ep.sig) and ep.cap_id in c.domain
              and ep.lvl >= c.lvl_req and ep.conf >= c.conf_min)
        if not ok or not self.tig.admit(e, ep):
            self.ledger.reject(ep, e); return False
        return self.deliver(ep, e)

# IP-265 CRL：能力账本 + 路线图 DAG
def register_capability(cu, ledger):
    assert deps_registered(cu, ledger)                     # 路线必须下闭
    ledger.append(('CAP_REG', cu.id, cu.ver, cu.lvl, cu.ev_pred))

# IP-266 AGC：契约闭合 + 最坏相关风险
def compose(route, contracts):
    for u, v in edges(route):
        if not implies(contracts[u].G, contracts[v].A):
            return None                                    # 不闭合 → 路线无效
    r = sum(c.rho for c in contracts.values())
    for i, j in pairs(route):
        rho = measured_rho(i, j) or 1.0                    # 无证据不假设独立
        r += rho * sqrt(contracts[i].rho * contracts[j].rho)
    return r

# IP-267 TIG：deadline 准入（K=4 是可选任务，不是特权）
def admit(S, mission):
    return e2e_response_bound(S + mission.active) <= mission.deadline - mission.slack_reserve

# IP-268 RRS：解析「证据允许走的路」
def resolve_route(mission, G, ledger):
    feasible = [r for r in downward_closed_routes(G, mission)
                if versions_registered(r) and tig.admit(r, mission)
                and compose(r, ledger.contracts) <= mission.eps - mission.margin]
    return max(feasible, key=lambda r: mission.value(r)) if feasible else BASELINE_ROUTE

# IP-269 PDC：always-valid 影子检验；晋升慢、降级快
def promote_or_demote(cu, evidence, ledger):
    if certificate_invalid(cu) or drift_detected(cu) or contract_violated(cu):
        return demote(cu)                                  # 立即，无滞回
    if shadow_gate(cu.eprocess, ALPHA) and evidence.lcb_safety > 0:
        return promote(cu, require=('holdout', 'auditor_sig'))

# IP-270 MRP：元 VoI——下一项验证也是信息动作
def plan_next_experiment(route, safety_posterior, budget):
    gains = {e: entropy(safety_posterior) - expected_entropy(safety_posterior, e) - cost(e)
             for e in candidate_experiments(route)}
    best = max(gains, key=gains.get)
    return best if gains[best] > 0 else None               # 无利可图 → 冻结路线图

# IP-275 主闭环：R69 的 FLUID 决策被包在「路线 + 中间件」里
def ROUTE_RAS_round(M, mission, obs):
    r = M.rrs.route                                        # 任务开始解析一次
    eps = {u: M.bus.pack(u, obs) for u in r.active}        # 每个信号都是证据包
    fl = M.fluid.step(M, eps)                              # R69：模态/交互/似然
    if not M.bus.publish(M.bus.pack('fluid_decision', fl), ('fluid', 'actuator')):
        fl = M.rrs.baseline_step(M, eps)                   # 拒绝即回退，不重试
    if M.pdc.should_recheck(fl): M.pdc.update(fl, M.ledger)
    if M.rrs.invalidated(M.ledger):
        r = M.rrs.resolve_route(mission, M.G, M.ledger)
    return fl, r, M.jroute.sign(fl, r, M.ledger)
```

## 4. 推导

**引理 19（最坏相关上界）** 任意联合分布下 `P(∪E_i) ≤ min(1, Σ P(E_i))`，comonotone 构造达到上界；故无相依证据时 `ρ_ij=1` 不低估组合风险。系：「无证据不得假设独立」是唯一可辩护默认值。

**引理 20（影子门有界影响）** 若执行路径只接受 `ℓ ≥ ℓ_req`，且 L0 仅写账本、L1 满足 `‖Δu‖ ≤ δ_L1`，则任意时刻执行风险 ≤ `r_comp(r*) + δ_L1·1[存在 L1 活跃]`。系：影子把新模块风险从「可能致命」降为「可审计的有界扰动」。

**引理 21（Goodhart 受限）** 门谓词族容量有限、证据为独立留出且含对抗分量时，表观-真实增益差 ≤ `O(√(V/n)) + δ_adv`。系：无独立留出只能晋升到 L1。

**引理 22（可行性单调 / 无降级死锁）** 若 r 可行，其任意下闭子路线 r'⊆r 风险与时间预算单调更省，故可行；降级永远有解，兜底 r0 是偏序下界。

**定理 18（ROUTE 严格包含 R68/FLUID）** A99（契约闭合、时间分析可靠）下：r0 恒可行；r=r0 且 TIG 不干预、无影子、ρ 取基线时逐指令一致；任意路线 `r_comp ≤ ε` ⇒ 期望任务风险 ≤ ε。安全侧不弱于 R69，并获得可组合性与可演进性。

**定理 19（时间隔离 ⇒ 无 deadline 击穿）** 每个活跃组件满足 wcet/jitter 且准入集满足 `R(S) ≤ D − slack`，则 E2E 响应 ≤ D；K=4 等一次性开销因未获准入无法抢占控制周期。系：R69 的「K 采样击穿预算」由架构消除，不靠统计运气。

**定理 20（晋升 anytime 可靠）** 用 e-process/时间一致置信序列做影子检验，则对任意停止时刻 τ，`P(τ 前错误晋升) ≤ α`（Ville / 混合鞅可选停止）。系：晋升无需「跑完固定样本量」的童话，可随时审计叫停。

**定理 21（可组合证书）** 若 (i) 每条边契约闭合、(ii) 各能力证书有效、(iii) `r_comp ≤ ε−margin`，则 J_ROUTE 有效且组合期望风险 ≤ ε。证明：assume-guarantee 传递性 + 引理 19。系：证书第一次是「组合级」而非「并列级」——这正是 R69 缺失的部分。

## 7. 本轮最大风险

**一句话**：ROUTE-RAS 把安全押在「中间件的能力账本与契约合成规则本身正确且不可被博弈」上——**一旦合成假设（尤其相关性默认值）、时间分析或晋升门被静默证伪，系统就会带着一叠合法证书运行一个从未被真正验证过的组合；此时「已认证」不是保护色，而是最危险的保护色。** 中间件还引入了单点故障、额外延迟与全新攻击面，若 TIG/签名/版本钉扎任一失效，前四轮的安全边际会被一次性吃掉。
