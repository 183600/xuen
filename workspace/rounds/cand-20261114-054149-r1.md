# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；本轮灵感：「语义建图」×「避障控制」）

> R69 教会系统「问」，但它对世界的表征仍是一张**平的**地图：几何占据 + 被融合进来的语义标签。它从未追问：地图上的一个标签，是测量，还是**断言**？是谁写的、什么时候写的、凭什么可信、错了会怎样？在避障里，这不是哲学问题，而是碰撞问题：玻璃门被标成墙，该停不停；人被标成模特，该让不让；窗帘被标成墙，能过不过；湿地被标成干地，该慢不慢；对手往地图里注入一条「可通行」，直接撞。
>
> 本轮两个灵感正好把这个问题拆开：
> - **语义建图**告诉我们，语义地图不应是「世界的样子」，而应是一组**带空间索引、带出处、带时间戳、可被反驳的断言**；
> - **避障控制**告诉我们，安全集必须对**所有尚未被反驳的语义假设**取交集——语义可以加约束，但不能成为安全的唯一底座；只有在断言通过认证并被安全「释放」后，才允许扩大安全集。
>
> 核心命题：**把语义地图从确定性真值降格为「语义假设账本」；用语义鲁棒控制屏障函数（SR-CBF）在所有可信假设上求安全集交集；语义只在「可恢复释放证书」下扩大安全集；主动建图按决策相关 VoI 而非地图熵分配预算；地图投毒作为一等威胁建模。** 命名 **ATLAS-RAS**（Adaptive Trust-aware Layered Avoidance with Semantics）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我脚下这块地，真的像地图说的那样吗？如果地图错了，我还安全吗**」。

## 0. 直觉与动机

**灵感 1（语义建图 → 地图不是世界，而是一组可错的断言）**
直觉：传统占据栅格把世界压成「占据/空闲」两态，语义层再把类别贴上去，仿佛标签是免费的真理。但语义标签是**推断**，不是测量：它依赖光照、视角、遮挡、训练分布和标注偏差。人会看错，模型会幻觉，地图会被别人改写。更合理的类比是法律账本：每条断言都有**证人（传感器/模型/人/其他机器人）**、**签发时间**、**证据链**和**可撤销记录**；冲突断言并存，直到有足够证据将其中的一条「退休」。地图因此不再是 `f(x)=label`，而是一个**假设分布 + 出处账本**。

**灵感 2（避障控制 → 安全集必须对假设取交，而不是对标签取信）**
直觉：如果地图说「前面是墙」，控制器就绕；如果地图说「前面是窗帘」，控制器就穿。问题在于，地图可能同时收到两条互相矛盾的断言。正确的做法不是选一个最像的标签，而是**把所有尚未被反驳的假设对应的安全集取交集**：既按「墙」的几何约束，又按「窗帘」的可通行约束，再按「未知」的最坏情况约束。这样，语义只在**增加约束**的方向上是安全的；想**减少约束**（例如把墙改判为可穿过的窗帘），必须让「墙」这个假设先被认证地退休。避障因此从「按标签规划」变成「按假设集做鲁棒控制」。

**灵感 3（语义不确定性的空间稀疏性 → 只建「会改变动作」的地图）**
直觉：语义建图的传统目标是降低全图熵或提高 mIoU，但避障只关心少数**决策边界**：走廊拐角的那块反光地面、门口那个一动不动的「人」、窗帘后面那条可能存在的通道。把整张地图都建准，既昂贵又无关；真正该问的是：**如果我现在把这块区域看清楚，我的避障动作会变吗？** 如果不会，它的语义不确定性对控制价值为零。于是主动建图的目标从「地图熵」改为「决策相关不确定性」——只建会改变动作的那几块地图。

**灵感 4（affordance → 语义可以扩大安全集，但必须带可恢复的牵引绳）**
直觉：语义不只是「这是什么」，更是「我能对它做什么」：窗帘可推开、草地可穿越、湿地要减速、人的个人空间要尊重、玻璃是硬障碍但透明。affordance 让语义有可能**扩大**机器人的可行域，这是效率的来源；但一旦判错（把玻璃当门、把人当模特），扩大可行域就等于把安全集扩进真实障碍。因此任何「语义释放」都必须满足两个条件：证据足够强（有限样本风险上界），以及**物理上可恢复**（万一错了，能在承诺视界内退回几何安全集）。释放不是宣称真理，而是一笔有上限、可回滚的赌注。

**灵感 5（地图是时间对象 → 陈旧、漂移、变更与版本）**
直觉：语义地图会过期：椅子被挪走、门被关上、临时展板被放倒、地面被水浸湿。地图不是一次性产物，而是一个持续被重写的版本化对象。控制若读到半更新的地图，或在用三秒前的语义做毫秒级避障，就会产生「地图说能过，世界说不能」的错位。于是必须引入**快照、版本、年龄上界**：控制读不可变快照，语义层异步更新；超龄断言降级为未知；语义漂移要能被检测，而不是被平滑掉。

**灵感 6（地图是攻击面 → 投毒的危害方向应被结构性地限制为 DoS）**
直觉：一旦地图可以被外部写入（多机器人共享、云端地图、人机交互标注），就有了新的攻击面：注入假障碍（让系统瘫痪）、删除真障碍（让系统撞）、重放旧地图（用合法哈希描述过时世界）、冻结更新（让系统永远相信旧世界）、语义共谋（多源一起撒谎）。好的架构不应承诺「不会被骗」，而应保证**被骗的方向是有界的**：注入假障碍只会让系统更保守（可用性损失）；想通过投毒**扩大**安全集，必须同时攻破多个正交证据源、通过一致性检查、并满足可恢复性——这条路径的概率由证据纪律和审计压到可声明的小量。

**灵感 7（与 R69 的关系 → 把二分从「动作模态」下沉到「世界标签」）**
直觉：R69 把不确定性分成 aleatoric/epistemic，并用交互消解动作模态的歧义；但它的 epistemic 只关于「我该选哪个动作」，不关于「世界到底是什么」。R70 把同一套纪律下沉一层：语义假设是新的 epistemic 对象，地图是新的交互界面，避障是新的决策后果。R69 的 MINT（VoI 交互）、FMA（流似然第二意见）、MCG（校准门）、证据纪律都被复用，只是作用对象从动作模态换成空间语义断言。理论姿态不变：**新层必须严格包含旧层**——语义通道关闭时，ATLAS 必须逐指令退化为 R69 的几何避障；语义通道可信时，才获得「少停、能过、懂社交」的 resolution bonus。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（ATLAS-RAS 总览）** ATLAS-RAS = (HMap, STL, SRC, REL, DRV, ASM, SMC, SMT, LRF, AIC-ATLAS, VQAuditor-M)。继承 R69 定义 293 的实时零学习写操作、非阻塞语义、交互预算与证据纪律，新增五条不变式：
(i) **语义非底座**：安全关键动作的认证只依赖几何/动力学与**所有未退休假设**的约束；语义不能单独把动作认证为安全，只能增加约束，或在 REL 下进行有界、可恢复的释放；
(ii) **假设单调性**：无有效 REL 时，可信假设集只增不减，`C_cons` 只缩不扩；REL 只能局部、显式、可审计地退休假设；
(iii) **决策相关注意**：主动建图预算优先给 `U_dec` 高的区域，而非全图熵；保留一个很小的探索下限以防「未知的未知」；
(iv) **出处与原子性**：每条断言带来源、时间、哈希、版本；控制只读不可变地图快照；
(v) **退避单调性**：信任下降时安全集逐级收缩到几何基线，绝不因语义通道故障而扩大。

**定义 311（语义假设地图 HMap）** 地图 `M_t = {(r, H_r, π_r, E_r, c_r)}`，其中 `r ∈ ℛ` 是物体实例或空间区域；`H_r` 是有限假设集，`h = (class, affordance, dynamics, geom)` 描述类别、可操作性、动态性与几何参数；`h_∅` 为「未知/其他」假设，**永远保留**；`π_r ∈ Δ(H_r)` 为当前权重；`E_r` 为证据集；`c_r` 为断言记录。地图查询 `Q(r) = (H_r, π_r)`，快照 `Snapshot()` 返回不可变版本。HMap 不是标签图，而是**假设图**。

**定义 312（语义信任账本 STL）** 断言 `c = (r, h, src, t_q, t_r, hash, parent, ver)`。账本只追加，不静默删除；冲突通过「退休/撤销」记录表达。信任分
`T(c,t) = σ(θ·φ(c,t))`，
其中 `φ = [cal(src, age), agree(c,E), geo_cons(c), dyn_cons(c), reputation(src), −age/A_max, −anomaly(c), −poison(c)]`。
`T` 只做**门控**，不冒充真实概率；释放决策另用 conformal risk control 给出有限样本风险上界（定义 315）。权重由离线单调校准得到，且对「年龄」与「来源」分别校准。

**定义 313（可信假设集与未知假设）** 在时刻 `t`，
`H_r^cred(t) = {h ∈ H_r : T(c_h,t) ≥ τ_trust ∧ π_r(h) ≥ π_min ∧ age(c_h,t) ≤ A_max(r)} ∪ {h_∅}`。
`h_∅` 的屏障函数 `b_{h_∅}` 取**最坏情况**：未知区域按占据 + 安全膨胀处理。于是即使真实类别不在 `H_r` 中（开放世界），系统仍按「未知 = 障碍」保守处理。只有当 `r` 获得有效 REL 时，才允许在 `r` 上局部退休 `h_∅` 或与之冲突的假设。

**定义 314（语义鲁棒安全集 SRC）** 对每个 `h`，`C_h = {x : b_h(x) ≥ 0}`，`b_h` 编码碰撞几何、社交距离、易碎性、可通行性等约束。几何基线 `C_base` 为占据 + 未知膨胀 + 动态最坏情况。定义
`C_cons(t) = C_base ∩ ⋂_{h ∈ H_r^cred(t)} C_h`，
`C_sem(t) = C_cons(t) ∪ R_rel(t)`。
控制求解多假设 CBF-QP：
`min ||u − u_ref||²`，s.t. 对所有 `h ∈ H_r^cred`，
`L_f b_h + L_g b_h u + α_h(b_h) ≥ 0`，
并对 `R_rel` 中的释放区域附加「回退到 `C_cons` 的逃逸约束」。若 QP 不可行，进入 LRF 退避（定义 324）。注意：无 REL 时 `C_sem ⊆ C_base`，语义只能让系统更保守；REL 是唯一能扩大安全集的出口。

**定义 315（语义释放证书 REL）** `REL_r = (r, h_pass, E_rel, ε_rel, h_e, esc_r)`。有效当且仅当：
(1) `h_pass` 至少由 `k` 个正交证据源支持（视觉/几何/触觉/语言/其他机器人），且 SMC ≥ `τ_smc`；
(2) **有限样本风险控制**：用 conformal risk control 在留出集上校准「退休错误假设」的概率，使 `P(h*_r ∉ 保留集) ≤ ε_rel`，置信度 `1−δ`；
(3) 出处链有效、未命中投毒/重放标记、地图版本为当前；
(4) **可恢复性**：存在逃逸策略 `esc_r`，能在 `h_e` 内退回 `C_cons`，且不进入不可逆区域；`esc_r` 过 R69 的 C-RAS-WM 认证。
满足后，`r` 加入 `R_rel`，冲突假设被局部退休并记入账本。REL 不是「真理证书」，而是「有界风险 + 可回滚」的许可。

**定义 316（决策相关语义不确定性 DRU）** 设 `a*(x,H)` 为当前 CBF-QP 的解，`L(x,u)` 为任务代价 + 风险。对区域 `r` 与每个候选 `h ∈ H_r`，令 `H|h = (H \ H_r) ∪ {h}`，
`Δ_r(h) = L(x, a*(x,H)) − L(x, a*(x,H|h))`，
`U_dec(r) = Σ_h π_r(h) · [Δ_r(h)]_+`。
它度量「若知道 `r` 的语义身份，控制代价能降多少」。若解析 `r` 不改变当前动作或主动约束集，则 `U_dec(r)=0`。等价的信息论版本可用 `I(H_r; A_active | x)`，其中 `A_active` 是 QP 的活跃约束集。

**定义 317（决策相关 VoI，DR-VoI）** 对候选信息动作 `g`（下一最佳视角、探针、问句、等待、查询其他机器人），
`DR-VoI(g) = E_{y~p(·|g)}[U_dec(r) − U_dec(r|y)] − c(g) − c_risk(g)`，
s.t. `g` 过 R69 定义 302 的信息动作安全认证、预算未超、且不阻塞实时环。选择 `g* = argmax`；若最大收益 ≤ 0，则不建图、不查询，按当前假设保守执行。`r` 的选择由决策前沿 `F_t = {r : U_dec(r) ≥ τ_dec}` 给出；对从未观测的区域加一个很小的探索项 `β·H(H_r)`，防止永久忽略。

**定义 318（主动语义建图 ASM）** 在地图节拍（低频、异步）上，计算敏感度 `S(r) = U_dec(r)/(c_obs(r)+ε)`，按 `DR-VoI` 贪心选择下一最佳视角/探针/查询，并保留覆盖率下限以处理未知未知。所有物理信息动作复用 R69 的 MINT 预算与安全认证；所有地图更新以原子快照发布。ASM 的目标不是「建全图」，而是「把决策边界建准」。

**定义 319（语义-几何一致性与漂移 SMC）** 对每条断言计算一致性
`SMC(r) = w_g·geo_cons + w_d·dyn_cons + w_c·cross_modal + w_t·temporal_cons`，
其中 `geo_cons` 比较语义边界与占据/自由空间，`dyn_cons` 比较预测运动与观测，`cross_modal` 比较视觉/语言/触觉/其他机器人，`temporal_cons` 用 R69 的 FMA 流似然与残差做变更检测。语义漂移
`D_r(t) = || P(s_t | M_{t−1}, a) − o_t^{sem} ||`。
若 `SMC < τ_smc` 或 `D_r > τ_drift`：分裂假设、衰减信任、撤销该区域的 REL，并调度重观测。R69 的 `(r_res↓, Δa↑)` 模式在这里用于区分「世界变了」与「地图一开始就错了」。

**定义 320（地图投毒威胁模型 AIC-ATLAS）** `ℰ_ATLAS = ℰ_FLUID × ℰ_map × ℰ_sem`。
`ℰ_map = {inject, delete, replay, freeze, salami}`：注入假障碍/假可通行、删除真障碍、重放旧地图块、阻止更新、小步协同漂移。
`ℰ_sem = {adversarial patch/sticker, spoofed sign, cross-modal collusion, social lie, Byzantine map update}`。
假设 A102：最多 `f` 个共谋源，哈希不可伪造，版本单调。威胁模型的核心不是「杜绝欺骗」，而是**限制欺骗能造成的危害方向**。

**定义 321（参与式地图审计 VQAuditor-M）** 审计对象新增：断言出处链、释放时的 `k` 源一致性、被退休假设在回放中的真伪、语义后悔（是否有更安全但被忽略的假设）、陈旧地图块、异常编辑模式。结论回灌 STL 的来源信誉与 SMT 阈值，成为下一轮建图的信任先验。

**定义 322（证书 J_ATLAS）** `J_ATLAS = (J_FLUID, map_version, |H^cred|, release_count, max ε_rel, SMC_violation_rate, U_dec_p95, provenance_hash, semantic_ECE, fallback_level, atlas_ver)`。
Valid ⇔ `Valid(J_FLUID)` ∧ `semantic_ECE ≤ τ_ece` ∧ 每次释放都有 REL ∧ 快照年龄 ≤ `A_map` ∧ (`fallback_level ≤ 1` 或已认证)。

**定义 323（语义地图信任门 SMT）** 按来源与区域维护校准与异常检测。若某来源/区域的 ECE > `τ_ece`、或检测到重放/冻结/漂移，则关闭释放通道：只允许语义**加约束**（L1）；若异常严重，则忽略语义、回到几何基线（L2）。这是 R69 MCG 在地图层上的对应物：不让不可信的语义分布驱动释放。

**定义 324（分层退避 LRF）** 四级：
L0：完整 ATLAS（约束 + 释放 + DR-VoI 建图）；
L1：禁释放，只用 `C_cons`（语义只能加约束）；
L2：忽略语义，几何基线 `C_base`（R69/R68 路径）；
L3：几何/感知退化，最小风险机动（停/退）。
安全集随级别单调收缩：`C_sem(L0) ⊇ C_sem(L1) ⊇ C_sem(L2) ⊇ C_sem(L3)`。升级用 CBF 裕度调度保证连续；降级必须重新认证，不能因一条新标签就自动扩大安全集。

**定义 325（地图快照、版本与原子更新）** `M_t = (V_t, τ_t, hash_t)`。控制读不可变快照；更新用双缓冲原子切换；版本号单调。快照年龄超过 `A_map` 时，撤销所有 REL（约束可保留），因为「旧的释放」比「旧的约束」危险得多。审计可在版本回滚时定位污染源。

**定义 326（语义漂移与投毒的时序判别）** 定义时序签名 `(SMC(t), Δa(t), provenance_anomaly)`：
- **漂移/世界变化**：插入时一致，随后 `SMC` 平滑下降、`Δa` 随年龄上升、出处正常；
- **投毒/重放**：插入时即与几何/动态不一致，或出处/版本异常，`SMC` 低而 `Δa` 高；
- **冻结**：长期无新证据、`SMC` 不降但探索覆盖停滞。
用该签名决定「重观测」「隔离」「撤销 REL」还是「仅降权」，而不是把所有不一致都当成同一种故障。

## 2. 关键算法骨架

# IP-264 HMap：语义假设地图（未知假设永远保留）
class HypothesisMap:
    def query(self, r):
        return self.regions[r].H, self.regions[r].pi

    def snapshot(self):
        return Snapshot(self.version, self.tau, self.hash, self.regions)

    def apply(self, claims):
        for c in claims:
            self.ledger.append(c)
            self.regions[c.r].reweight(c)
        self.version += 1
        self.publish_atomic(self.snapshot())

# IP-265 STL：信任账本（只追加、可撤销、不可静默删除）
def trust(claim, t, evidence):
    phi = [cal(claim.src, t - claim.t_q),
           agreement(claim, evidence),
           geo_consistency(claim),
           dyn_consistency(claim),
           reputation(claim.src),
           -(t - claim.t_q) / A_max(claim.r),
           -anomaly(claim),
           -poison_score(claim)]
    return sigmoid(dot(theta, phi))

# IP-266 SRC：多假设 CBF-QP（语义只能加约束）
def semantic_robust_qp(x, u_ref, H_cred, C_base, R_rel):
    cons = [cbf_constraint(b_h, x, u) for h in H_cred]
    cons += [escape_constraint(r, x, u) for r in R_rel]
    return solve_qp(min_norm(u - u_ref), cons,
                    input_bounds=True, baseline=C_base)

# IP-267 REL：可恢复的语义释放证书
def try_release(r, h_pass, evidence, escape_plan):
    if trust(h_pass, now, evidence) < TAU_TRUST:       return None
    if not cross_modal_agree(h_pass, evidence, k=2):   return None
    if not smc_ok(r, evidence):                         return None
    if not escape_plan.feasible(r, horizon=h_e):        return None
    eps = conformal_release_risk(r, h_pass, alpha=EPS_REL)
    return REL(r, h_pass, evidence, eps, h_e, escape_plan)

# IP-268 DR-VoI：只建会改变避障动作的地图
def decision_relevant_voi(x, H, candidates):
    a0 = semantic_robust_qp(x, u_ref(x), H, C_base, R_rel)
    best = None
    for g in candidates:
        gain = 0.0
        for h, p in hypotheses(H):
            Hh = resolve(H, h)
            ah = semantic_robust_qp(x, u_ref(x), Hh, C_base, R_rel)
            gain += p * max(0.0, loss(x, a0) - loss(x, ah))
        score = gain - cost(g) - risk_cost(g)
        if best is None or score > best.score:
            best = (g, score)
    return best if best and best.score > 0 else None

# IP-270 SMC：一致性、漂移与投毒时序判别
def semantic_health(obs, M):
    smc, drift = {}, {}
    for r in M.regions:
        smc[r] = (w_g * geo_consistency(r, obs)
                  + w_d * dyn_consistency(r, obs)
                  + w_c * cross_modal_consistency(r, obs)
                  + w_t * temporal_consistency(r, obs))
        drift[r] = world_model_semantic_residual(r, obs)
    stale = [r for r in M.regions if age(r, now) > A_max(r)]
    return SMCResult(smc, drift, stale)

# IP-276 ATLAS 主闭环（异步建图，实时只读快照）
def ATLAS_round(x, obs):
    M = map_bus.snapshot()                         # 原子快照 + 版本
    H_cred = credible_hypotheses(M, obs, t)        # 含 h_∅

    if health.requires_quarantine():
        M = quarantine(M, health.regions)          # 撤销 REL，只留约束
    if trust_gate.closed(M, health):
        return LRF_level_up(x)                     # 只收紧，绝不扩大

    u_ref = policy(x, obs)
    u = semantic_robust_qp(x, u_ref, H_cred,
                           C_base(M), R_rel(M))
    if not u.feasible:
        return LRF_level_up(x)                     # 不可行即退避

    g = decision_relevant_voi(x, H_cred, info_candidates)
    if g is not None:
        async_submit(g)                            # 复用 R69 MINT，非阻塞
        audit.submit_async(M.version, H_cred, u, g)
    return u

## 3. 推导

假设：
- **A99**：世界模型语义预测误差有界，`D_sem ≤ L_w·age + ε_w`；
- **A100**：每个 `b_h` 是合法 CBF（可微、class-K、Lipschitz）；真实假设 `h*_r ∈ H_r`（`h_∅` 兜底）；
- **A101**：语义来源按区域/年龄校准，conformal 风险控制给出有限样本上界；
- **A102**：最多 `f` 个共谋源，哈希不可伪造，版本单调；
- **A103**：释放区域存在可认证的逃逸策略，`h_e` 内可退回 `C_cons`；
- **A104**：地图快照原子，更新延迟有界，控制环有硬截止。

**引理 19（语义鲁棒安全性）** 在 A100 下，若控制器对所有 `h ∈ H^cred` 满足 CBF 条件，且没有有效 REL 退休真实假设 `h*_r`，则 `x(t) ∈ C_{h*_r}` 对所有 `t` 成立。系：未消解的语义歧义只会**增加**约束，可能造成保守、绕路或死锁，但不会造成违反真实约束的碰撞。

**引理 20（DRU 的稀疏性与上界）** 设 `L` 对动作 `L_a`-Lipschitz、对语义参数 `L_h`-Lipschitz，则
`U_dec(r) ≤ L_a·E[||a*(H) − a*(H|h)||]`，
且当 `r` 不在 QP 的活跃约束边界上、解析它不改变活跃集时，`U_dec(r)=0`。因此
`Σ_r U_dec(r) ≤ L_h·Σ_{r∈F_t} diam(H_r) + ε_a`，
其中 `F_t` 是决策前沿。全图熵 `H(M)` 可以任意大于 `Σ U_dec`：建准一块与避障无关的墙，对控制价值为零。系：主动建图的最优预算应集中在 `F_t`，而非全图均匀覆盖。

**引理 21（释放风险的累积上界）** 在 A101/A103 下，若第 `i` 次释放的假退休概率 ≤ `ε_rel,i`、逃逸失败概率 ≤ `ε_esc,i`，则 `N_rel` 次释放造成的累计风险 ≤ `Σ_i (ε_rel,i + ε_esc,i)`（联合界），且每次释放后都存在回到 `C_cons` 的可恢复路径。取 `ε_rel,i = budget/(2N_rel)`、`ε_esc,i = budget/(2N_rel)`，则总释放风险 ≤ `budget`。系：释放预算是一个**可声明、可审计**的安全开销，而不是隐含在语义模型精度里的未知量。

**引理 22（地图投毒的方向性）** 在 A102 下：
(1) 只**增加**约束的投毒（假障碍、假「不可通行」）只能缩小 `C_cons`：造成可用性损失（绕路、停车），不会直接造成碰撞；
(2) 想通过投毒**扩大**安全集，必须让一条假「可通行」断言通过 `k` 源共识、SMC、并拿到有效 REL；其成功概率 ≤ `δ_map·ρ^{k−1} + ε_hash + ε_smc`，其中 `ρ<1` 为源间欺骗相关；
(3) 删除/冻结/重放主要影响可用性与新鲜度，审计可通过版本/出处/时序签名定位。
系：**投毒的默认危害是 DoS，不是碰撞**；只有多源共谋 + 一致性欺骗 + 可恢复性失败三者同时发生，才升级为安全事件。

**定理 18（ATLAS 对 R69 的严格包含）** 在 A99–A104 下：
- L2（忽略语义）与 R69 的几何避障逐指令相同；
- L1（只加约束）满足 `C_cons ⊆ C_base`，安全性不低于 R69，可用性不高于 R69；
- L0（允许释放）只在 `R_rel` 上把安全集扩到 `C_base` 之外，每次释放附带 `ε_rel + ε_esc` 的可声明风险，且受释放预算约束；
- 当释放预算为 0 时，L0 逐指令退化为 L1。
因此 R69 是 ATLAS 在「零释放、语义不可信」边界上的退化；ATLAS 的安全侧不让步，效率侧通过 resolution bonus 获得「少停、能过 affordance、懂社交距离」的收益。

**定理 19（语义地图闭环的一致性与无突变）** 在 A103/A104 下，原子快照 + CBF 裕度调度保证：地图更新、释放、撤销、版本回滚引起的控制变化是连续的（由 class-K 函数界定，不产生跳变）；信任门关闭时，系统在有限时间内单调进入 L1/L2，且安全集只缩不扩；释放/撤销事件不会让控制器在同一个控制周期内同时看到新旧两个版本。

## 6. 本轮最大风险

**一句话**：ATLAS-RAS 的全部效率收益都押在「语义释放证书」上——一旦一条被自信签发、实际错误的释放（玻璃门被当成可通行、人被当成模特、湿地被当成干地）把安全集扩进真实障碍，鲁棒 CBF 的保证就在**被退休的假设**之外失效，语义建图会把避障从「保守但安全」变成「高效但会撞」——**信错，比不信更危险**。

**次级风险与缓解**：
1. **多假设 CBF 过保守/不可行**（窄通道、多人场景）→ 硬/软约束分层、软约束加 slack、DR-VoI 优先消解导致不可行的区域、L3 最小风险机动兜底；
2. **校准的尾部风险**（平均 ECE 不代表释放区域）→ 按区域/年龄/来源条件校准 + conformal 风险控制 + 硬性释放预算；
3. **地图投毒/重放/冻结** → STL 出处链 + k 源共识 + SMC 一致性 + 审计；结构性限制为 DoS；
4. **主动建图的观测动作本身危险**（探头、靠近、转身注视）→ 复用 R69 信息动作认证 + 逃逸包络；
5. **开放世界新语义** → `h_∅` 永远可信且按障碍处理；释放未知需更强证据；
6. **实时性被多假设 QP 击穿** → 假设数上限、异步建图、快照读、QP 热启动。

**定义 310（总览与五不变式）** `ATLAS-RAS = (HMap, STL, SRC, REL, DRV, ASM, SMC, SMT, LRF)`。继承 R69 零学习写操作、非阻塞语义、交互预算、证据纪律；新增：(i) 语义非底座——安全认证只依赖几何/动力学 + 所有未退休假设，语义只能加约束或走 REL；(ii) 假设单调性——无 REL 时可信集只增不减、`C_cons` 只缩不扩；(iii) 决策相关注意——建图预算按 `U_dec` 分配，保留探索下限；(iv) 出处与原子性——每条断言有来源/时间/哈希/版本，控制只读快照；(v) 退避单调性——信任下降时安全集逐级收缩到几何基线。

**定义 311（HMap）** `M_t = {(r,H_r,π_r,E_r,c_r)}`；`H_r` 含类别、affordance、动态、几何参数；`h_∅` 永远保留；`π_r∈Δ(H_r)`；查询 `Q(r)`，快照 `Snapshot()` 不可变。**地图是假设图，不是标签图。**

**定义 312（STL）** 断言 `c=(r,h,src,t_q,t_r,hash,parent,ver)`；账本只追加，退休/撤销显式记录。`T(c,t)=σ(θ·φ)`，`φ` 含校准、跨模态一致、几何/动态一致、来源信誉、年龄、异常、投毒分。`T` 只做门控；释放用 conformal risk control 给有限样本上界。

**定义 313（可信假设集）** `H_r^cred(t)={h:T≥τ_trust ∧ π≥π_min ∧ age≤A_max} ∪ {h_∅}`；`h_∅` 按最坏情况（未知=障碍）处理。开放世界也能安全兜底。

**定义 314（SRC）** `C_h={x:b_h(x)≥0}`；`C_base` 为几何基线；`C_cons=C_base∩⋂_{h∈H^cred}C_h`；`C_sem=C_cons∪R_rel`。控制解多假设 CBF-QP：对所有 `h∈H^cred`，`L_f b_h+L_g b_h u+α_h(b_h)≥0`；释放区域加逃逸约束；不可行则 LRF 退避。无 REL 时 `C_sem⊆C_base`。

**定义 315（REL）** `REL_r=(r,h_pass,E_rel,ε_rel,h_e,esc_r)`。有效条件：(1) `h_pass` 由 `k` 个正交源支持且 `SMC≥τ_smc`；(2) conformal 风险控制满足 `P(h*_r∉保留集)≤ε_rel`；(3) 出处/版本/投毒标记通过；(4) 存在 `esc_r` 在 `h_e` 内退回 `C_cons` 且过 R69 C-RAS-WM 认证。REL 不是真理证书，而是有界风险 + 可回滚的许可。

**定义 316–317（DRU 与 DR-VoI）** `Δ_r(h)=L(x,a*(x,H))−L(x,a*(x,H|h))`，`U_dec(r)=Σ_h π_r(h)[Δ_r(h)]_+`；解析 `r` 不改变动作/活跃约束集则 `U_dec=0`。`DR-VoI(g)=E[U_dec(r)−U_dec(r|y)]−c(g)−c_risk(g)`，s.t. 过 R69 信息动作认证与预算；最大收益 ≤0 则不建图。

**定义 318（ASM）** 敏感度 `S(r)=U_dec(r)/(c_obs+ε)`；按 `DR-VoI` 贪心选下一最佳视角/探针/问句/他机查询；保留覆盖率下限；异步发布原子快照。目标不是建全图，而是把决策边界建准。

**定义 319（SMC）** `SMC(r)=w_g·geo_cons+w_d·dyn_cons+w_c·cross_modal+w_t·temporal_cons`；漂移 `D_r(t)=||P(s_t|M_{t−1},a)−o_t^{sem}||`。越界则分裂假设、衰减信任、撤销 REL、重观测。复用 R69 `(r_res↓,Δa↑)` 区分世界变化与地图初始错误。

**定义 320（AIC-ATLAS）** `ℰ_ATLAS=ℰ_FLUID×ℰ_map×ℰ_sem`；`ℰ_map={inject,delete,replay,freeze,salami}`；`ℰ_sem={patch,spoofed sign,cross-modal collusion,social lie,Byzantine update}`。A102：最多 `f` 个共谋源、哈希不可伪造、版本单调。

**定义 321–323（审计 / 证书 / 信任门）** VQAuditor-M 审出处链、k 源一致、退休真伪、语义后悔、异常编辑；J_ATLAS 在 J_FLUID 上加地图版本、可信假设数、释放次数/风险、SMC 违规、`U_dec_p95`、`semantic_ECE`、`fallback_level`；SMT 按来源/区域/年龄校准，ECE 或异常越界即关闭释放（L1），严重则 L2。

**定义 324–326（退避 / 快照 / 时序判别）** LRF：L0 完整、L1 只加约束、L2 忽略语义、L3 最小风险机动，安全集单调收缩；降级需重新认证。快照 `M_t=(V_t,τ_t,hash_t)`，双缓冲原子切换，超龄撤销 REL。时序签名 `(SMC,Δa,provenance)` 区分漂移（先一致后不一致）、投毒（插入即不一致/出处异常）、冻结（无新证据且覆盖停滞）。

# IP-264/265 HMap + STL
class HypothesisMap:
    def query(self, r):            return self.regions[r].H, self.regions[r].pi
    def snapshot(self):            return Snapshot(self.version, self.tau, self.hash, self.regions)
    def apply(self, claims):

        self.version += 1; self.publish_atomic(self.snapshot())

def trust(claim, t, evidence):
    phi = [cal(claim.src, t - claim.t_q), agreement(claim, evidence),
           geo_consistency(claim), dyn_consistency(claim),
           reputation(claim.src), -(t - claim.t_q) / A_max(claim.r),
           -anomaly(claim), -poison_score(claim)]
    return sigmoid(dot(theta, phi))

# IP-266 SRC：多假设 CBF-QP（语义只能加约束）
def semantic_robust_qp(x, u_ref, H_cred, C_base, R_rel):
    cons  = [cbf_constraint(b_h, x, u) for h in H_cred]
    cons += [escape_constraint(r, x, u) for r in R_rel]
    return solve_qp(min_norm(u - u_ref), cons, input_bounds=True, baseline=C_base)

# IP-267 REL：可恢复的语义释放证书
def try_release(r, h_pass, evidence, escape_plan):
    if trust(h_pass, now, evidence) < TAU_TRUST:      return None
    if not cross_modal_agree(h_pass, evidence, k=2):  return None
    if not smc_ok(r, evidence):                        return None
    if not escape_plan.feasible(r, horizon=h_e):       return None
    eps = conformal_release_risk(r, h_pass, alpha=EPS_REL)
    return REL(r, h_pass, evidence, eps, h_e, escape_plan)

# IP-268 DR-VoI：只建会改变避障动作的地图
def decision_relevant_voi(x, H, candidates):
    a0 = semantic_robust_qp(x, u_ref(x), H, C_base, R_rel)
    best = None
    for g in candidates:
        gain = 0.0
        for h, p in hypotheses(H):
            ah = semantic_robust_qp(x, u_ref(x), resolve(H, h), C_base, R_rel)
            gain += p * max(0.0, loss(x, a0) - loss(x, ah))
        score = gain - cost(g) - risk_cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-276 ATLAS 主闭环（异步建图，实时只读快照）
def ATLAS_round(x, obs):
    M = map_bus.snapshot()                          # 原子快照 + 版本
    H_cred = credible_hypotheses(M, obs, t)         # 含 h_∅
    health = semantic_health(obs, M)                # IP-270 SMC
    if health.requires_quarantine():
        M = quarantine(M, health.regions)           # 撤销 REL，只留约束
    if trust_gate.closed(M, health):
        return LRF_level_up(x)                      # 只收紧，绝不扩大
    u_ref = policy(x, obs)
    u = semantic_robust_qp(x, u_ref, H_cred, C_base(M), R_rel(M))
    if not u.feasible:
        return LRF_level_up(x)                      # 不可行即退避

## 4. 推导

假设 A99–A104：世界模型语义误差有界；`b_h` 为合法 CBF；真实假设 `h*_r∈H_r`（`h_∅` 兜底）；语义来源按区域/年龄校准且 conformal 有界；最多 `f` 个共谋源；释放存在可认证逃逸；快照原子、更新有界。

**引理 19（语义鲁棒安全性）** 若控制器对所有 `h∈H^cred` 满足 CBF 条件，且无有效 REL 退休真实假设，则 `x(t)∈C_{h*_r}`。系：未消解歧义只会增加约束，可能保守/绕路/死锁，但不会违反真实约束。

**引理 20（DRU 稀疏性与上界）** `U_dec(r) ≤ L_a·E||a*(H)−a*(H|h)||`；`r` 不在活跃约束边界、解析不改变活跃集时 `U_dec=0`。故 `Σ_r U_dec(r) ≤ L_h·Σ_{r∈F_t} diam(H_r)+ε_a`，而全图熵可任意更大。系：建图预算应集中在决策前沿 `F_t`。

**引理 21（释放风险累积上界）** 若第 `i` 次释放假退休概率 ≤ `ε_rel,i`、逃逸失败概率 ≤ `ε_esc,i`，则 `N_rel` 次释放累计风险 ≤ `Σ_i(ε_rel,i+ε_esc,i)`，且每次释放后可退回 `C_cons`。取 `ε_rel,i=ε_esc,i=budget/(2N_rel)`，总风险 ≤ `budget`。系：释放预算是可声明、可审计的安全开销。

**引理 22（投毒方向性）** (1) 只加约束的投毒只能缩小 `C_cons`，造成可用性损失，不直接碰撞；(2) 想扩大安全集必须让假「可通行」通过 `k` 源共识 + SMC + REL，成功概率 ≤ `δ_map·ρ^{k−1}+ε_hash+ε_smc`；(3) 删除/冻结/重放主要影响可用性与新鲜度，可由版本/出处/时序签名定位。系：**投毒默认是 DoS，不是碰撞**；升级为安全事件需多源共谋 + 一致性欺骗 + 可恢复性失败同时发生。

**定理 18（ATLAS 对 R69 的严格包含）** L2 与 R69 几何避障逐指令相同；L1 满足 `C_cons⊆C_base`，安全性不低于 R69、可用性不高于 R69；L0 只在 `R_rel` 上以 `ε_rel+ε_esc` 的可声明风险扩张，受释放预算约束；释放预算为 0 时 L0 逐指令退化为 L1。故 R69 是「零释放 + 语义不可信」边界，ATLAS 安全侧不让步，效率侧获得 resolution bonus。

**定理 19（闭环一致性与无突变）** 原子快照 + CBF 裕度调度保证地图更新/释放/撤销/回滚引起的控制变化连续；信任门关闭时系统有限时间内单调进入 L1/L2，安全集只缩不扩；同一控制周期不会同时看到新旧地图版本。

## 7. 本轮最大风险

**一句话**：ATLAS-RAS 的全部效率收益都押在「语义释放证书」上——一旦一条被自信签发、实际错误的释放（玻璃门被当成可通行、人被当成模特、湿地被当成干地）把安全集扩进真实障碍，鲁棒 CBF 的保证就在**被退休的假设**之外失效，语义建图会把避障从「保守但安全」变成「高效但会撞」——**信错，比不信更危险**。

**次级风险与缓解**：多假设 CBF 过保守/不可行（硬/软约束分层 + slack + DR-VoI 消解 + L3 兜底）；校准尾部风险（按区域/年龄/来源条件校准 + conformal + 硬释放预算）；地图投毒/重放/冻结（STL + k 源 + SMC + 审计，结构性限制为 DoS）；观测动作危险（R69 信息动作认证 + 逃逸包络）；开放世界新语义（`h_∅` 按障碍 + 更强释放证据）；实时性（假设数上限 + 异步建图 + 快照 + QP 热启动）。
