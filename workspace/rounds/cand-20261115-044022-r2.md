# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「成本控制」×「状态估计」）

> R69 做了两件大事：把不确定性拆成 aleatoric/epistemic，并让系统学会「问」。但它悄悄引入了两个未经检验的假设：
> 1. **成本是已知标量**：`VoI(g) − c(g)` 里的 `c(g)` 被当作常数或可离线标定的价签。真实系统里，成本是**隐状态**——人的耐心、电池、热预算、社交信用、时延都在变，且只能通过「花了之后」间接观测。价格估错，信息决策就系统性错：低估 → 预算破产，高估 → 信息瘫痪。
> 2. **状态估计是各向同性的**：`U_epi` 是一个标量，仿佛所有歧义方向都同样「一问可解」。但真实估计器有可观测子空间：某些方向一个探针就清楚，另一些方向问一百次也没信息。把标量 `U_epi` 当可解性，会把预算花在不可观测的方向上。
>
> 本轮两个灵感正好补上这两块：
> - **成本控制**：成本是慢变隐状态，必须与系统状态**联合估计**，并用风险敏感的价格（LCB/CVaR）而非点估计做门控；预算不是事后记账，而是事前配速与储备。
> - **状态估计**：用 Fisher 信息 / 可观测 Gramian 把 epistemic 不确定性变成**方向场**，用 NEES 一致性检验给估计器本身发证书；信息获取的收益是「方向 × 可观测性 ÷ 成本」。
>
> 核心命题：**把 R69 的「不确定性二分」升级为「不确定性-成本-可观测性三分」：epistemic 只在可观测方向上、且价格经风险调整后仍划算时才去消解；内部计算（更多流采样/更多粒子）与外部交互（看/问/触）共享同一个预算，由统一的价值/成本比分配；估计器不一致或成本不可辨识时，退化为 R69/R68 的保守边界。** 命名 **LEDGER-RAS**（Latent-cost Estimation, Directional Gain & Expenditure Regulation for Risk-adaptive Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「该向谁求证」，R70 问「**这次求证值多少钱，我的估计器本身还自洽吗**」——不确定性不仅是刹车和提问，也是一张必须对账的预算表。

## 0. 直觉与动机

**灵感 1（成本控制 → 成本是隐状态，不是常数）**
直觉：R69 的 `c(g)` 像一个贴在货架上的价签，可真实世界的信息价格是活的：深夜问人比白天贵，电池低时算力比平时贵，连续追问会让人的耐心（社交信用）非线性贬值。更麻烦的是，这些价格**没有传感器直接读数**，只能从「花了多少、还剩多少、对方反应如何」反推。于是成本控制本质上是一个**状态估计问题**；把它当常数，等于用一个偏置的观测做最优控制。R44 的 Cost-Cert 已经建立了成本向量与台账（IP-60 CCL），但那是「可测成本的记账」；R70 要跨出的一步是：**成本参数 θ 本身不可直接测，必须在线联合估计，并且估计成本要花预算**。

**灵感 2（状态估计 → 不确定性有方向，可观测性决定可解性）**
直觉：R69 的 `U_epi` 是模态熵乘可分性，一个标量。但「歧义大」不等于「问得清」。如果两个模态的差异落在估计器的零空间（摄像头看不到被遮挡的背面、力矩传感器对某个接触方向不敏感），再大的歧义也无法通过该信息动作消解。状态估计的语言给出正确对象：**Fisher 信息矩阵 / 可观测 Gramian** 描述每个方向能被观测多少；**NEES/ANISES** 描述估计器是否自洽。于是「值不值得问」应写成：**在可观测方向上的模态间方差 ÷ 单位成本**，而不是总方差。

**灵感 3（对偶 → 成本与状态互相估计，形成反馈环）**
直觉：估计成本要花钱，花钱改变预算，预算反过来限制估计——这是一个**成本-状态对偶反馈**。它可以是良性的（花一点钱校准价格，之后省很多），也可以是恶性的（为了搞清成本而不断花钱，成本越来越高，最后预算崩溃）。R69 没有这个环，所以不需要稳定性分析；R70 必须给出环增益条件与阻尼机制，否则「更聪明地分配预算」会变成「更优雅地烧预算」。

**灵感 4（统一预算 → VoI 与 VoC 是同一枚硬币）**
直觉：R69 有两套预算逻辑：外部交互用 `VoI−成本`，内部多采样用 `mode_head` 门控（自适应 K）。但多采一个流样本、多跑一次 ODE、多放一个粒子，和「多看一眼」在经济学上是同一件事：**用资源换决策质量**。把它们分开，就会出现「外部交互很省、内部计算狂烧」或相反的局部最优。R70 用**信息价值（VoI）+ 计算价值（VoC）**的统一目标，在同一个预算向量下分配，R69 的 `mode_head` 只是 VoC 的一个廉价探针。

**灵感 5（退化包含 → R69 是「成本已知、各向同性、预算充裕」的边界）**
直觉：任何新层必须能被旧层检验。当 θ 后验退化为点质量、可观测性各向同性、ECG 通过且预算无约束时，LEDGER 的门控与分配必须逐指令等价于 FLUID 的 MINT+自适应 K。否则每加一层就多一个不可解释的自由度。本轮把「严格包含」写成可证伪条件（定义 327 与定理 18），并设计 E308 做逐指令一致性检验。

**与已有工作的关系（R44 / R62 / R69）**
R44 把成本升为证书维度，做的是**可测成本的静态记账**；R62 做的是成本与异常检测的耦合；R69 做的是信息动作的 VoI 决策但把价格当常数。R70 的新意是把三者接成一条链：**成本参数 → 在线联合估计 → 风险敏感定价 → 方向性信息获取 → 预算配速 → 对偶稳定性**。它不是再加一个成本表，而是承认「价格本身也是被估计出来的状态」。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（LEDGER-RAS 总览）** LEDGER-RAS = (CSDE, DEM, CAIG, UBA, ASE, ECG, BLP, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i / R69 定义 293-i）；
(ii) **预算硬约束**：所有信息获取（外部交互 `g` 与内部计算 `κ`）共享一个多资源预算向量 `R_t`；任何动作不得使 `R` 越过安全下限 `R_min`，且必须为剩余时域保留储备；
(iii) **价格一致性**：任何 VoI/VoC 决策必须使用经 ECG 认证的状态后验与经可辨识性检查的成本后验；成本不可辨识或估计器不一致时，必须用保守上界定价或退回 R69/R68。

**定义 311（预算增广状态）** `b_t = (b^x_t, b^θ_t, p(R_t))`，其中 `x_t ∈ ℝ^{n_x}` 为系统状态，`θ ∈ Θ ⊂ ℝ^{n_c}` 为慢变成本参数，`R_t ∈ ℝ_+^m` 为剩余预算（算力、时延、能量、社交信用等）。支出 `e_t = E(ξ_t; θ) + ν_t`，预算更新 `R_{t+1} = R_t − e_t`。成本向量 `e(ξ) = (e_comp, e_lat, e_energy, e_social, …)` 逐分量非负。

**定义 312（成本-状态对偶估计 CSDE）** 
`b^θ_{t+1} ∝ b^θ_t · L(e_t | θ, ξ_t)^{γ_t}`（遗忘因子 `γ_t ≤ 1` 处理非平稳）；
`b^x_{t+1} = Filter(b^x_t, o_t, ξ_t)`；
联合边缘用 Rao-Blackwellized 粒子（θ 粒子 + 条件 Kalman/流滤波）。
**成本可辨识性**：令 `Φ_t = [e(ξ_1), …, e(ξ_t)]` 为支出回归矩阵；若 `rank(Φ_t) = n_c` 则 θ 局部可辨识；否则只有投影 `Π_{span(Φ_t)} θ` 可辨识，其余方向只能用集员上界 `θ ∈ [θ_lo, θ_hi]`。可辨识性秩是证书字段（定义 324）。

**定义 313（多资源账本与影子价格）** 账本 `L_t = (cum_spend, reserve, burn_rate, per_resource)`。影子价格 `w_t ≥ 0` 为预算约束的拉格朗日乘子，由对偶更新 `w_{t+1} = [w_t + η(spend_t − ρ_t R_t)]_+`（`ρ_t` 为配速目标）。成本标量化 `c_w(e) = w_t^T e`。与 R44 的静态 CCL 不同，这里的价格随预算紧张程度在线变化。

**定义 314（方向性 epistemic 度量 DEM）** 模态间散布矩阵 `G = Σ_k ŵ_k (ξ̄_k − ξ̄)(ξ̄_k − ξ̄)^T`；方向 `u` 上的歧义 `U_epi(u) = H_mode · (u^T G u)/(u^T u)`。信息动作 `g` 对方向 `v` 的 Fisher 信息 `I_g(v) = v^T M_g v`；可观测对齐度 `ρ_g(u) = (u^T M_g u)/(‖M_g‖·‖u‖²)`。R69 的标量 `U_epi` 被替换为方向场 `U_epi(·)`；只有 `ρ_g(u) ≥ ρ_min` 的方向才允许进入交互候选。

**定义 315（成本归一化方向增益）** 
`𝒢(g,u) = [U_epi(u) − U_epi⁺(u | g)] / c_w(e(g))`，
其中 `U_epi⁺` 为执行 `g` 后的期望残余歧义，`c_w` 为影子价格下的成本。选择 `(g*,u*) = argmax 𝒢`。R69 的 VoI 从标量升级为「方向 × 可观测性 × 价格」的三元对象；`c_w` 用风险敏感上界（定义 316），不用点估计。

**定义 316（风险敏感信息门 CAIG）** 净信息价值 `N(g) = VoI(g) − c_w(e(g))`。R69 用 `E[N]`；LEDGER 用下置信界 / CVaR：
交互 `⇔ LCB_α[N(g)] = Q_α^-[VoI] − Q_{1−α}^+[c_w] > 0`（或 `max CVaR_α[N] > 0`），`α` 为风险预算。
当成本不可辨识时，用可行集上确界 `sup_{θ∈[θ_lo,θ_hi]} c_w(e(g))` 定价。该门把 R69 的「期望划算」改为「在坏分位下仍划算」。

**定义 317（统一信息预算分配 UBA）** 内部计算 `κ ∈ 𝒦`（流采样数 K、ODE 步数、粒子数、滤波迭代）与外部信息动作 `g` 共享预算。总价值 `V(a) = VoI(g) + VoC(κ)`，成本 `c_w(e(a)) = w_t^T(e(g)+e(κ))`。分配
`a* = argmax_{a=(g,κ)} [VoI(g) + VoC(κ) − c_w(e(a))]`，s.t. `R_t − e(a) ≥ R_min + r_t` 且 CAIG 通过。
R69 的 `mode_head` 自适应 K 是 `𝒦` 中最便宜的 VoC 探针特例。

**定义 318（预算化信息背包 BIK）** 当候选信息动作需组合选择且 `VoI(·)` 边际递减（单调子模）时，解
`max_{S⊆G} Σ_{g∈S} VoI(g)`，s.t. `Σ_{g∈S} e(g) ≤ R_t − R_min − r_t`。
用影子价格贪心 / 连续贪心；基数约束下贪心 `(1−1/e)`，背包约束下 `(1−1/e)/2`（Khuller 等），成本近均匀时成本归一化贪心保持序。R69 的 MINT 是「单位成本、单动作」的贪心特例。

**定义 319（随时状态估计 ASE）** 估计器可随时中断，返回 `(x̂, P, κ_x, residual_bound)`；VoC 用后验损失（如 `tr(P)` 或任务损失）下降量除以已用算力。任何时刻中断都必须返回当前最优估计与证书，禁止把半成品（未收敛的粒子/未完成的滤波迭代）写回闭环。

**定义 320（估计器一致性门 ECG）** 用 NEES：`e_t = x_t − x̂_t`，`NEES_t = e_t^T P_t^{-1} e_t`；窗口 `N` 的 `N·mean(NEES) ~ χ²_{N·n_x}`。若统计量落在 `[χ²_{α/2}, χ²_{1−α/2}]` 之外 ⇒ **估计器不一致**：禁用 epistemic 消解与成本门，退回 R69/R68，并触发重初始化或鲁棒滤波。该门与 R69 的 MCG（只管模态权重校准）正交，专治滤波器发散与协方差虚报。

**定义 321（预算储备与配速 BLP）** 储备 `r_t = κ_r · R_t · (H_t/H_0)`（`H_t` 为剩余时域）；可花上限 `spend_t ≤ R_t − R_min − r_t`。配速目标 `ρ_t` 由剩余时域与期望价值率决定，满足机会约束 `P(R_T ≥ R_min) ≥ 1−δ`。配速用于防止前 10% 时间花掉 90% 预算的「信息暴食」。

**定义 322（经济威胁模型 ℰ_econ）** 成本膨胀攻击（抬高信息价格 → 诱发信息瘫痪/否认服务）、成本通缩攻击（压低价格 → 诱发预算耗尽/资源枯竭）、账本篡改、影子价格操纵、伪造成本观测的共谋。并入 AIC：`ℰ_LEDGER = ℰ_FLUID × ℰ_econ`。

**定义 323（预算审计 VQAuditor-B）** 审计每笔支出是否有可追溯的 VoI/VoC 依据、影子价格是否异常、是否存在「花大钱买小信息」、成本膨胀/通缩模式、储备是否被击穿。结论回灌账本，成为下一轮 `w_t` 的先验。继承 R69 的 VQAuditor-I，但审计对象从「交互决策」扩展到「预算决策」。

**定义 324（证书 J_LEDGER）** `J_LEDGER = (J_FLUID, θ_posterior_entropy, cost_identifiability_rank, ECG_NEES, budget_solvency_margin, shadow_price_norm, spend_audit_hash, ledger_ver)`。
Valid `⇔` Valid(J_FLUID) ∧ ECG 通过 ∧ 预算偿付裕度 `≥ 0` ∧ 审计无重大异常。

**定义 325（三级成本-状态退避）** 
L0（正常）：ECG 通过且 θ 可辨识 → 风险敏感门 + 统一分配（获得 cost-aware resolution bonus，效率高于 R69 但不降低安全）。
L1（不可辨识/不一致）：冻结 epistemic 消解，用 θ 可行集上界的纯保守定价；等价于 R69 的 λ 兜底。
L2（预算将破）：强制停止所有非必要信息获取，`λ = λ_floor(U_ale + U_epi)`，退回 R68 最保守。
退避是**单调**的：L0 → L1 → L2 只能使 λ 增大、信息动作减少，不能反向跳变。

**定义 326（对偶反馈稳定性）** 双估计环增益 `L = ‖∂θ̂/∂spend‖ · ‖∂spend/∂θ̂‖ · γ`。若 `|L| < 1`，成本-状态双估计局部指数稳定；`|L| ≥ 1` 或审计检测到振荡 ⇒ 阻尼（降低信息动作频率）、提高储备、退回 L1。`∂spend/∂θ̂` 是「价格估计对实际支出的敏感度」，`∂θ̂/∂spend` 是「支出观测对参数估计的增益」，二者乘积过大时，系统会陷入「花更多钱去确认钱不够」的自我强化。

**定义 327（与 R69 的严格包含条件）** 当 (a) θ 后验退化为点质量（成本已知），(b) 可观测各向同性（`ρ_g(u)` 与方向无关），(c) ECG 通过且预算无约束时，LEDGER 的 CAIG+UBA 逐指令等价于 FLUID 的 MINT+自适应 K。故 R69 是 LEDGER 在「成本已知、各向同性、预算充裕」边界上的退化；安全侧不做任何让步。

```python
# IP-264 CSDE：成本-状态对偶估计（Rao-Blackwellized：θ 粒子 + 条件状态滤波）
class CostStateEstimator:
    def __init__(self, state_filter, theta_particles, forgetting=0.995):
        self.fx, self.particles, self.gamma = state_filter, theta_particles, forgetting

    def update(self, o, e, xi):
        self.particles = bayes_update_cost(self.particles, e, xi, self.gamma)  # 慢变
        self.bx = self.fx.update(o, xi)                                       # 条件状态
        return self.bx, self.particles

    def identifiable(self):
        return rank(regressor_matrix(self.e_hist, self.xi_hist)) == n_c

    def cost_ucb(self, g, alpha):                 # 不可辨识时用可行集上确界
        return quantile_cost(self.particles, g, q=1 - alpha)

# IP-265 DEM：方向性 epistemic + 可观测对齐（拒绝不可观测方向）
def directional_gain(modes, w, btheta, ledger, candidates):
    G = between_mode_scatter(modes, w)            # 模态间散布
    best = None
    for g in candidates:
        M    = observation_fisher(g)              # 信息动作的可观测信息矩阵
        cost = ledger.price(g, btheta)            # 影子价格 × 风险上界
        for u in principal_directions(G):
            rho = quad(u, M) / (norm(M) * norm(u)**2)
            if rho < RHO_MIN:                     # 该方向不可观测，问了也白问
                continue
            gain = (quad(u, G) - quad_after(u, G, g, M)) / max(cost, EPS)
            if best is None or gain > best.gain:
                best = (g, u, gain)
    return best

# IP-266 CAIG：风险敏感信息门（LCB / CVaR，替代 R69 的期望净值）
def risk_sensitive_gate(g, btheta, alpha):
    voi_lcb  = quantile_voi(g, q=alpha)            # 对模态后验取保守分位
    cost_ucb = quantile_cost(btheta, g, q=1 - alpha)
    return voi_lcb > cost_ucb

# IP-267 UBA：外部 VoI 与内部 VoC 的统一预算分配
def allocate(modes, btheta, R, horizon, ledger):
    cands  = [('external', g) for g in info_candidates(modes)]
    cands += [('internal', k) for k in compute_levels(R)]
    best = max(cands, key=lambda a: value(a, modes, btheta) - ledger.price(a, btheta))
    return best if ledger.feasible(best, R, horizon) else None

# IP-268 BIK：预算化组合选择（单调子模 + 背包）
def select_bundle(candidates, R, horizon, ledger):
    budget = R - R_MIN - reserve(R, horizon)
    return budgeted_submodular_max(candidates, cost=ledger.price,
                                   budget=budget, value=voi)  # (1-1/e)/2 近似

# IP-270 ECG：估计器一致性门（NEES 窗口检验）
def ecg_consistent(err_hist, P_hist, window):
    nees = [e @ inv(P) @ e for e, P in zip(err_hist[-window:], P_hist[-window:])]
    stat = window * mean(nees)
    return chi2_low(window * n_x, ALPHA) <= stat <= chi2_high(window * n_x, ALPHA)

# IP-275 LEDGER-RAS 主闭环（继承 R69，只在不确定性处置处插入成本-状态层）
def LEDGER_RAS_round(M, obs):
    # 0) 成本-状态联合估计 + 一致性检查
    b_x, b_theta = M.csde.update(obs.o, obs.spend, obs.xi)
    consistent   = M.ecg.check(obs.err_hist, obs.P_hist, WINDOW)
    ident        = M.csde.identifiable()
    w            = M.ledger.shadow_prices()

    # 1) 方向性歧义（廉价 mode_head 决定是否升 K）
    K = M.uba.k_hint(b_x)
    modes = M.fmp.sample(obs.o, K)
    U_ale, U_epi, G = M.dem.decompose(modes, b_x, w)

    # 2) 三级退避：只有 L0 才允许主动信息获取
    a, lam = None, None
    if consistent and ident and M.ledger.solvent(obs.R, M.vista.H):
        a = M.uba.allocate(modes, b_theta, obs.R, M.vista.H, M.ledger)
        if a is not None and a.kind == 'external' \
           and not M.caig.gate(a.g, b_theta, RISK_ALPHA):
            a = None                                   # 风险门拒绝，L1 兜底
    if a is None:
        lam = lam_floor(U_ale + U_epi)                 # L1：R69 兜底
        if not consistent:
            lam = max(lam, 0.8)                        # L2：R68 最保守
    else:
        info = M.execute_info(a) if a.kind == 'external' else M.execute_compute(a)
        U_epi_after = M.cia.update_belief(modes, info)
        U_ale, U_epi = M.dem.recompute(modes, U_epi_after, w)
        lam = max(M.efs.risk_scale(...), lam_floor(U_ale))   # resolution bonus
        if a.kind == 'external':
            k = M.c_ras_wm.certified_prefix((a.g,), obs)     # 信息动作也认证

    # 3) 记账、配速、审计（任何路径都必须对账）
    spend = M.ledger.charge(a, b_theta) if a is not None else zeros(m)
    M.blp.pace(obs.R, spend, M.vista.H)
    M.vqa_b.submit_async(a, spend, w, b_theta, consistent, ident)

    # 4) 执行选出的任务模态（继承 R69）
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    return k, lam, mode, (U_ale, U_epi), M.ledger.snapshot()
```

## 3. 推导

假设 A99–A104：
A99（成本可辨识投影）：在可辨识子空间上 `Φ_t` 满秩，或使用集员上界；
A100（成本后验校准）：风险分位数 `Q_α` 的估计误差 ≤ ε_θ；
A101（状态估计一致性）：ECG 通过时 NEES 落在 χ² 区间，否则被 ECB 拦截；
A102（VoI 子模性）：候选信息动作的 `VoI(·)` 单调子模；
A103（对偶 Lipschitz）：`∂θ̂/∂spend`、`∂spend/∂θ̂` 有界，环增益 `< 1`；
A104（储备正性）：`R_min + r_t < R_t`。

**引理 19（方向性增益与标量盲区）** 设 `G` 可特征分解，标量规则用 `tr(G)` 排序候选 `g`。若真实可观测方向为 `u_obs`，方向规则用 `u_obs^T G u_obs / c_w`。当 `G` 的主方差落在不可观测方向 `u_null`（`ρ_g(u_null) < ρ_min`）时，标量规则会选到增益近零的动作；方向规则至少获得 `λ_obs(G)/c_w` 的增益，其中 `λ_obs` 为可观测子空间上的最大特征值。系：**U_epi 的大小不等于可解性；可解性 = 方向 × 可观测性 ÷ 价格**。

**引理 20（风险敏感门的分位控制与保守代价）** 在 A100 下，CAIG 门满足 `P(真实 N(g) < 0) ≤ α + ε_θ`；而 plug-in 门 `E[VoI] − E[c] > 0` 在成本重尾时可使 `P(N<0)` 任意接近 1。代价界：当成本后验变窄时两门差 → 0；当成本后验宽时，LEDGER 相对 plug-in 牺牲的 VoI ≤ `Q_{1−α}^+[c] − E[c]`。系：风险预算 `α` 是「信息瘫痪 vs 预算破产」的显式旋钮，可被审计与调参。

**引理 21（预算化选择的近似保证）** 在 A102 下，基数约束的贪心选择达到 `(1−1/e)` 最优；背包约束的贪心达到 `(1−1/e)/2`；当各动作成本近均匀时，成本归一化贪心与按 VoI 排序同序。系：R69 的 MINT（单动作、单位成本）是 `|G|=1` 的精确解。

**引理 22（经济攻击的可检测性与损害界）** 成本膨胀/通缩攻击若使账本残差超过 `3σ_e`，则被 VQAuditor-B 检测；若未被检测（攻击幅度 ≤ `3σ_e`），CAIG 仍保证超支概率 ≤ `α + ε_θ`，信息瘫痪造成的期望价值损失 ≤ 攻击幅度 × `Q_{1−α}^+[c] − E[c]`。系：经济攻击从「静默操纵」变成「要么被检测、要么损害有界」。

**定理 18（LEDGER 严格包含 FLUID/R69）** 在 A99–A104 下，LEDGER 的期望风险 ≤ FLUID；当定义 327 的三个退化条件成立时，两者**逐指令相同**。证明要点：退化时 `G` 各向同性 ⇒ 方向增益排序退化为标量排序；θ 点质量 ⇒ CAIG 的 LCB = plug-in；预算无约束 ⇒ UBA 的可行域全空间，且 `κ` 的最优解就是 R69 的 `mode_head` 门控。故 R69 是 LEDGER 在「成本已知、各向同性、预算充裕」边界上的严格退化；安全侧不让步，效率侧获得 cost-aware resolution bonus。

**定理 19（预算偿付与配速）** 在 A104 下，确定性配速 `spend_t ≤ R_t − R_min − r_t` 保证 `R_t ≥ R_min` 对所有 `t` 成立。随机成本下，CAIG 的 α 门 + 储备使 `P(R_T < R_min) ≤ δ`（由 α 与储备联合设定）。相对无配速策略，配速导致的期望价值损失 ≤ `O(√H)`（标准在线配速界）。系：预算约束不是事后惩罚，而是事前可行域；R69 的「无预算约束」是 `R_min = −∞` 的边界。

**定理 20（对偶反馈稳定性与安全退化）** 在 A101、A103 下，若环增益 `|L| < 1`，则 `(θ̂, R)` 双估计局部指数稳定，成本估计误差与预算偏差有界。若 `|L| ≥ 1`，存在周期振荡或发散；ECG/审计检测到后按定义 325 冻结信息获取并退回 L1/L2，λ 单调不降，故控制量与预算仍有界。证明要点：把双估计写成 `z_{t+1} = F(z_t)`，`F` 的 Jacobian 谱半径 = `|L|`；`|L|<1` 时 Banach 不动点；`|L|≥1` 时检测器把闭环切换到保守分支，保守分支无信息获取，环断开，故有界。

## 6. 本轮最大风险

**一句话**：LEDGER-RAS 的全部收益押在「成本参数 θ 可辨识且成本后验可信」这一前提上——**若价格只在支出中弱可观测、或被非平稳漂移与对抗性观测污染，风险敏感门就会用错误的价格给信息定价：高估导致信息瘫痪（永不提问），低估导致预算破产（优雅地烧光资源），而成本-状态对偶反馈会把这种定价误差放大成振荡**；更糟的是，经济攻击可以故意扭曲成本观测，把「更聪明的预算分配」武器化成「更精确的自毁」——**把刹车换成价格标签，若价格本身是幻觉，系统会精确地开向悬崖**。

**次级风险与缓解**：状态估计器发散（ECG + NEES，退回 R69/R68）；方向增益估计偏差（DEM 用保守 Fisher 下界 + E303）；预算配速过度保守（自适应 `κ_r` + E305）；成本不可辨识（集员上界 + L1 退避，绝不点估计冒险）；对偶反馈振荡（环增益监测 + 阻尼，定理 20）；审计开销（异步 + 采样审计，E315）。

# 第 70 轮产物 · 创新点清单 v1：LEDGER-RAS（Latent-cost Estimation, Directional Gain & Expenditure Regulation for Risk-adaptive Systems：成本-状态对偶估计 × 方向性信息获取 × 统一预算闭环；CSDE×DEM×CAIG×UBA×ASE×ECG×BLP×RAS-WM‡）

>

## 2. 形式化定义（要点版）

**定义 310（总览与三不变式）** `LEDGER-RAS = (CSDE, DEM, CAIG, UBA, ASE, ECG, BLP, RAS-WM‡)`；零学习写操作继承；预算硬约束（外部交互 + 内部计算共享 `R_t`，不得越过 `R_min + r_t`）；价格一致性（未通过 ECG/可辨识性检查不得用点估计定价）。

**定义 311–312（预算增广状态与 CSDE）** `b_t=(b^x,b^θ,p(R))`；`b^θ_{t+1} ∝ b^θ_t·L(e_t|θ,ξ_t)^{γ_t}`；`b^x_{t+1}=Filter(b^x_t,o_t,ξ_t)`；Rao-Blackwellized；成本可辨识 `⇔ rank(Φ_t)=n_c`，否则只用可辨识投影 + 集员上界。

**定义 313（账本与影子价格）** `L_t=(cum_spend,reserve,burn_rate,per_resource)`；`w_{t+1}=[w_t+η(spend_t−ρ_tR_t)]_+`；`c_w(e)=w_t^T e`。价格随预算紧张度在线变化（区别于 R44 的静态 CCL）。

**定义 314–315（方向性度量与成本归一化增益）** 模态间散布 `G`；方向歧义 `U_epi(u)`；可观测对齐 `ρ_g(u)`；`𝒢(g,u)=[U_epi(u)−U_epi⁺(u|g)]/c_w(e(g))`；只在 `ρ_g(u)≥ρ_min` 的方向上选 `(g*,u*)`。

**定义 316（风险敏感门 CAIG）** `N(g)=VoI(g)−c_w(e(g))`；交互 `⇔ LCB_α[N]>0`（或 `max CVaR_α[N]>0`）；不可辨识时用 `sup_{θ∈[θ_lo,θ_hi]} c_w`。把「期望划算」改为「坏分位仍划算」。

**定义 317–318（UBA 与 BIK）** 外部 `g` 与内部 `κ` 共享预算：`a*=argmax[VoI+VoC−c_w]`，s.t. 预算与 CAIG；组合选择解预算化子模背包，基数 `(1−1/e)`、背包 `(1−1/e)/2`；R69 MINT 是单动作单位成本特例。

**定义 319–320（ASE 与 ECG）** 估计器随时可中断，返回 `(x̂,P,κ_x,residual_bound)`；NEES 窗口 `N·mean(NEES)~χ²_{N·n_x}`；越界 ⇒ 冻结 epistemic 消解与成本门，退回 R69/R68 + 重初始化/鲁棒滤波。

**定义 321（BLP）** 储备 `r_t=κ_rR_t(H_t/H_0)`；可花上限 `spend_t≤R_t−R_min−r_t`；机会约束 `P(R_T≥R_min)≥1−δ`，防止信息暴食。

**定义 322–324（威胁/审计/证书）** `ℰ_LEDGER=ℰ_FLUID×ℰ_econ`；VQAuditor-B 审支出依据、价格异常、大钱买小信息、储备击穿；`J_LEDGER=(J_FLUID, θ_entropy, ident_rank, NEES, solvency_margin, ‖w‖, audit_hash, ver)`，Valid `⇔` J_FLUID ∧ ECG ∧ 偿付裕度 ≥0 ∧ 审计无重大异常。

**定义 325–327（三级退避 / 对偶稳定性 / 严格包含）** L0 正常（ECG+可辨识）→ L1 不可辨识/不一致（集员上界，等价 R69）→ L2 预算将破（R68）；退避单调。环增益 `L`，`|L|<1` 局部稳定，否则阻尼/退避。当成本点质量、各向同性、预算无约束时，LEDGER 逐指令等价 FLUID。

## 3. 关键算法伪代码

```python
# IP-264 CSDE：成本-状态对偶估计（θ 粒子 + 条件状态滤波）
class CostStateEstimator:
    def update(self, o, e, xi):
        self.particles = bayes_update_cost(self.particles, e, xi, self.gamma)
        self.bx = self.fx.update(o, xi)
        return self.bx, self.particles

    def identifiable(self):
        return rank(regressor_matrix(self.e_hist, self.xi_hist)) == n_c

# IP-265 DEM：方向性 epistemic（拒绝不可观测方向）
def directional_gain(modes, w, btheta, ledger, candidates):
    G = between_mode_scatter(modes, w)
    best = None
    for g in candidates:
        M, cost = observation_fisher(g), ledger.price(g, btheta)
        for u in principal_directions(G):
            if quad(u, M) / (norm(M)*norm(u)**2) < RHO_MIN:
                continue
            gain = (quad(u, G) - quad_after(u, G, g, M)) / max(cost, EPS)
            if best is None or gain > best.gain:
                best = (g, u, gain)
    return best

# IP-266 CAIG：风险敏感门（LCB / CVaR）
def risk_sensitive_gate(g, btheta, alpha):
    return quantile_voi(g, q=alpha) > quantile_cost(btheta, g, q=1-alpha)

# IP-267 UBA：外部 VoI + 内部 VoC 统一分配
def allocate(modes, btheta, R, horizon, ledger):
    cands  = [('external', g) for g in info_candidates(modes)]
    cands += [('internal', k) for k in compute_levels(R)]
    best = max(cands, key=lambda a: value(a, modes, btheta) - ledger.price(a, btheta))
    return best if ledger.feasible(best, R, horizon) else None

# IP-270 ECG：NEES 一致性门
def ecg_consistent(err_hist, P_hist, window):
    stat = window * mean(e @ inv(P) @ e
                         for e, P in zip(err_hist[-window:], P_hist[-window:]))
    return chi2_low(window*n_x, ALPHA) <= stat <= chi2_high(window*n_x, ALPHA)

# IP-275 主闭环（继承 R69）
def LEDGER_RAS_round(M, obs):
    b_x, b_theta   = M.csde.update(obs.o, obs.spend, obs.xi)
    consistent     = M.ecg.check(obs.err_hist, obs.P_hist, WINDOW)
    ident          = M.csde.identifiable()
    w              = M.ledger.shadow_prices()
    modes          = M.fmp.sample(obs.o, M.uba.k_hint(b_x))
    U_ale, U_epi,G = M.dem.decompose(modes, b_x, w)
    a = None
    if consistent and ident and M.ledger.solvent(obs.R, M.vista.H):
        a = M.uba.allocate(modes, b_theta, obs.R, M.vista.H, M.ledger)
        if a and a.kind == 'external' and not M.caig.gate(a.g, b_theta, RISK):
            a = None
    if a is None:
        lam = lam_floor(U_ale + U_epi)                 # L1：R69 兜底
        if not consistent: lam = max(lam, 0.8)         # L2：R68 最保守
    else:
        info = M.execute(a)
        U_epi = M.cia.update_belief(modes, info)
        lam = max(M.efs.risk_scale(...), lam_floor(U_ale))  # resolution bonus
    spend = M.ledger.charge(a, b_theta) if a else zeros(m)
    M.blp.pace(obs.R, spend, M.vista.H)
    M.vqa_b.submit_async(a, spend, w, b_theta, consistent, ident)
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    return k, lam, mode, (U_ale, U_epi), M.ledger.snapshot()
```

## 4. 推导

**引理 19（方向性增益与标量盲区）** 若 `G` 主方差落在不可观测方向 `u_null`（`ρ<ρ_min`），标量 `tr(G)` 排序会选到增益近零的动作；方向规则至少获得可观测子空间最大特征值 `λ_obs/c_w` 的增益。系：**U_epi 大 ≠ 可解；可解性 = 方向 × 可观测性 ÷ 价格**。

**引理 20（风险敏感门的分位控制）** A100 下 CAIG 满足 `P(N(g)<0) ≤ α+ε_θ`；plug-in 门在成本重尾时可使该概率任意接近 1。代价 ≤ `Q_{1−α}^+[c]−E[c]`。系：`α` 是「信息瘫痪 vs 预算破产」的显式旋钮。

**引理 21（预算化选择近似）** A102 下，基数约束贪心 `(1−1/e)`、背包贪心 `(1−1/e)/2`；成本近均匀时成本归一化贪心与 VoI 排序同序。R69 MINT 为单动作单位成本精确解。

**引理 22（经济攻击损害界）** 攻击使账本残差 >`3σ_e` 时被审计检出；未检出时 CAIG 仍保证超支概率 ≤ `α+ε_θ`，信息瘫痪损失 ≤ 攻击幅度 × `(Q_{1−α}^+[c]−E[c])`。系：成本攻击要么被检测、要么损害有界。

**定理 18（LEDGER 严格包含 FLUID/R69）** A99–A104 下期望风险 ≤ FLUID；定义 327 三条件成立时**逐指令相同**（各向同性 ⇒ 方向退化为标量；θ 点质量 ⇒ LCB=plug-in；预算无约束 ⇒ UBA 全空间且 κ* 即 mode_head 门控）。R69 为「成本已知、各向同性、预算充裕」边界。

**定理 19（预算偿付与配速）** 确定性配速保证 `R_t≥R_min`；随机成本下 α 门 + 储备使 `P(R_T<R_min)≤δ`；相对无配速的期望价值损失 ≤ `O(√H)`。预算约束是事前可行域，R69 的「无约束」是 `R_min=−∞` 的边界。

**定理 20（对偶反馈稳定性与安全退化）** A101/A103 下，`|L|<1` 时 `(θ̂,R)` 双估计局部指数稳定；`|L|≥1` 时振荡/发散被 ECG/审计检测，按定义 325 冻结信息获取，环断开，λ 单调不降，故控制与预算有界。

## 7. 本轮最大风险

**一句话**：LEDGER-RAS 的全部收益押在「成本参数 θ 可辨识且成本后验可信」这一前提上——**若价格只在支出中弱可观测、或被非平稳漂移与对抗性观测污染，风险敏感门就会用错误的价格给信息定价：高估导致信息瘫痪（永不提问），低估导致预算破产（优雅地烧光资源），而成本-状态对偶反馈会把这种定价误差放大成振荡**；更糟的是，经济攻击可以故意扭曲成本观测，把「更聪明的预算分配」武器化成「更精确的自毁」——**把刹车换成价格标签，若价格本身是幻觉，系统会精确地开向悬崖**。

**次级风险与缓解**：状态估计器发散（ECG+NEES，退回 R69/R68）；方向增益估计偏差（Fisher 下界 + E303）；配速过度保守（自适应 `κ_r` + E305）；成本不可辨识（集员上界 + L1，绝不点估计冒险）；对偶振荡（环增益监测 + 阻尼，定理 20）；审计开销（异步 + 采样，E315）。
