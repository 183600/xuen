# 第 4 轮（灵感循环第 4 轮；本轮灵感：「参数高效微调」×「在线学习」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。参数高效微调沿「模型如何改」这条轴升级 InstructGauge，在线学习沿「何时改」这条轴升级；任一环节失效都必须能一键退回第 3 轮静态版，再沿既有退化链回退。适配器与在线更新都是增强项，不是依赖项。

## 0. 直觉与动机

**灵感 1（参数高效微调 → 把「可编辑子空间」做小，而不是把「改动幅度」做小）**
直觉：每遇到一个新的盲区类别就重训 VLA / 接地器既贵又危险——一次全参数更新可能同时改坏了旧类别的行为。PEFT 的正确读法不是「省算力」，而是**把可编辑自由度限制在一个低维子空间里**：冻结骨干 `W`，只学秩 `r` 的增量 `ΔW = BA`。这带来三个结构性好处：(a) 回滚只需要保存 `(B, A)`，代价 `O(r(d+k))`；(b) 可以为每个盲区 stratum 训练互不干扰的小适配器；(c) 只要**安全头（类型检查 / 安全盾 / 不可逆屏障）永久冻结**，适配器就只能在「已经可采纳的动作集」内部重排分数——更新无法扩张能力边界。注意这里的第一直觉陷阱：**参数范数小 ≠ 行为变化小**。秩 1 的改动足以在某个稀有但高后果的输入上翻转决策；真正该约束的是函数空间里的行为散度，不是 `‖Δθ‖`。

**灵感 2（在线学习 → 用回执流持续校正，但自己制造了分布）**
直觉：盲区与场景在漂移，批量重训的延迟不可接受；用每条新回执在线更新阈值 / 适配器，可以把适应延迟从「小时级」压到「回执级」，并用自适应共形（ACI）在非可交换流上维持长期覆盖。但在线学习在闭环系统里有一个根本问题：**更新用的数据分布由系统自己的动作决定**。系统越不去探某个区域，就越收不到那里的回执；越收不到回执，适配器在该 stratum 上就越自信——这不是学习，是**自我确认**。再叠加回执可能被污染（错标、对抗注入），在线更新会沿着「证据最稀薄、后果最大」的方向静默漂移。

**灵感 3（两者耦合 → 便宜且连续的「专业化」，是最危险的涌现性质）**
直觉：PEFT 提供「改哪里」（低维可编辑子空间），在线学习提供「何时改」（流式调度）。耦合后的收益是真实的：新盲区只需几十条回执即可局部适配，旧能力靠冻结骨干 + 回放保留。但耦合后的风险也是新的：**低成本 + 高频率的更新，会让模型恰好在数据最少的地方变得最自信**；而共形的**边缘**覆盖可以被完美的长程数字掩盖，分层覆盖却已经塌掉；影子评估若只看平均损失，会漏掉「稀有层大幅变差、多数层小幅变好」的抵消。因此不能靠调参，必须上结构：**更新闭包**（安全路径不参与适配）、**函数空间信任域**（按行为散度而非参数范数准入）、**影子门控晋升 + 静默点回滚**（坏适配器永远不上线，上线也可瞬时撤销）、**校准锁**（提交—验证窗口内禁止改模型）、**分层在线共形 + 变化点重置**。

## 1. 研究问题（本轮要回答什么）

- **Q1（更新的安全性）**：参数高效微调能否给出**结构级**安全保证（冻结安全路径 ⇒ 任意适配器状态都不越权），还是仅仅是算力节省？需要什么形式的「更新闭包」才成立？
- **Q2（在线性的代价）**：在线更新把适应延迟压低，但引入了内生分布、非可交换与投毒面；在什么条件下长期覆盖 / 遗憾仍有界？安全探索的代价能否被压到 0？
- **Q3（耦合的暗面）**：低成本连续专业化是否会让模型「在最稀薄的证据上最自信」？能否用影子门控、分层在线覆盖与回滚把「静默变坏」变成「可检测、可撤销」？

## 2. 三条设计原则（雏形，正式化见产物区定义 448–464）

**P1 更新闭包（Update Closure, UC）**
适配器只允许修改「已可采纳动作集内部的评分与排序」，**安全头（类型检查 Γ、安全盾、不可逆屏障 Barrier）的代码与参数永久冻结**。形式化方向：对任意适配器状态 `θ`，`support(π_θ) ⊆ 𝔸_adm(ι)`，且安全相关函数对 `θ` 的偏导恒为 0。这样第 3 轮的安全不变量对**所有**适配器状态成立——安全性不再是「训练得好不好」的问题，而是类型/结构问题。

**P2 函数空间信任域 + 影子门控（Function-Space Trust Region + Shadow Gate）**
准入不看 `‖Δθ‖`，而看**分层探针集**上的行为散度 `D_beh`（决策翻转率 + 输出分布 TV）。候选适配器先只在「影子流」上评估（不接管执行），须同时满足：影子遗憾 `≤ ρ`、最差层覆盖 `≥ 1−α−δ`、旧层保留 `≥ 1−η`、`D_beh ≤ ε_beh`，且只在**静默点**晋升，并保留可 `O(r)` 回滚的快照。

**P3 校准锁 + 分层在线覆盖（Calibration Lock + Stratified Online Coverage）**
在「提交一个动作/块」到「用回执验证它」之间，**禁止更新任何会影响该验证的适配器或阈值**——否则验证器与被验证对象同源漂移，证据失去意义。在线共形按 stratum 分别维护，检测到变化点就重置；样本不足的层回退第 3 轮 SC-Cal，再回退全局阈值。

## 3. 与基线的接口（如何退化）

- 适配器秩 `r = 0` / 信任域拒绝 / 影子门控失败 / 回滚 ⇒ 冻结在上一晋升版本，等价于第 3 轮静态 InstructGauge；
- 在线共形不稳定、检测到无法界定的漂移、或 stratum 样本不足 ⇒ 回退第 3 轮 SC-Cal 全局阈值；
- 回执来源不可信 / 鲁棒聚合失效 ⇒ 停止在线更新，转离线批量校准（第 3 轮）；
- 校准锁获取失败 ⇒ 本次不更新（只读执行），安全不变；
- InstructGauge 失效 ⇒ 沿用第 3 轮退化链：ToolGauge ⇒ LeanGauge ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个**更新闭包**口径：把「适配器不会扩权」从经验观察提升为对任意 `θ` 成立的结构不变量（引理 59）；
2. 一个**函数空间信任域 + 影子门控晋升**机制：把「参数改动小所以安全」的错误保证替换为「行为散度可测、坏适配器不上线、上线可瞬时回滚」（引理 60/62/63）；
3. 一个**分层在线共形 + 变化点重置**方案，在非可交换闭环流上同时守住长期覆盖与逐层覆盖（引理 61/66）；
4. 一个**抗投毒鲁棒聚合 + 更新预算**方案，量化「多少坏回执能让适配器偏多远」以及「在线更新何时才划算」（引理 65/68）；
5. 一条可证伪路径：E457–E472 覆盖闭包安全、参数范数反例、在线覆盖、晋升/回滚、遗忘、适配器干扰、投毒、时延与长期稳定性。

## 5. 本轮最大风险

**一句话**：参数高效微调把「改模型」变得太便宜、在线学习把「改模型」变得太频繁，二者叠加会让系统在**证据最稀薄、后果最大**的 stratum 上持续地、静默地变得更自信；而低秩与「只改 0.1% 参数」会制造虚假的安全感——真正的残余风险是**行为漂移恰好落在没有探针、没有回执、也没有覆盖保证的盲区交集里**。

# 第 4 轮产物 · 创新点清单 v4：**AdaptGauge**（Online, Parameter-Efficient Adaptive Probing Metrology）

> 背景：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）；第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架不变。
> 本轮灵感：「参数高效微调」×「在线学习」
> **继承纪律**：MODGAUGE 五不变式、4CV 骨架、ToolGauge-6C、InstructGauge-7C、严格退化链全部保留。新组件一律为**可选增强**：适配器秩 `r=0` 或门控失败 ⇒ 冻结上一版本（= InstructGauge 静态版）⇒ 再沿既有链退化。

## 2. 形式化定义（要点）

**定义 448（冻结骨干低秩适配器与更新闭包 UC）** 适配器作用为 `f_θ(x)=Wx+B A x`，`rank(BA)≤r`，`W` 冻结。更新闭包要求：(i) 安全头 `Safety=(Γ, shield, Barrier)` 的参数与代码与 `θ` 正交，`∂Safety/∂θ ≡ 0`；(ii) 适配器只作用于 `𝔸_adm(ι)` 上的**评分与排序**，输出经 `Π_adm(ι)` 投影；(iii) `r=0 ⇒ ΔW=0 ⇒ f_θ=f_W`。**要点**：UC 是关于「谁能被改」的类型约束，不是关于「改了多少」的数值约束。

**定义 449（行为散度与函数空间信任域）** 给定分层探针集 `P={P_s}`，定义
`D_beh(θ) = max_s max_{x∈P_s} [ flip(π_θ, π_ref; x) + λ·TV(π_θ(·|x), π_ref(·|x)) ]`。
信任域 `Θ_ε = { θ : D_beh(θ) ≤ ε_beh ∧ Safety_delta(θ)=0 }`。参数范数 `‖Δθ‖` 仅作为 Lipschitz 上界下的**充分**条件；在输入范数无界处它**不充分**（引理 60 给出反例）。

**定义 450（在线自适应共形 OAC/ACI）** 第 `s` 层第 `t` 步：`err_t = 1[h*_t ∉ H_t(q_t^s)]`；
`q_{t+1}^s = Π_{[Q_LO,Q_HI]}( q_t^s + γ(α − err_t) )`。
与静态共形的区别：不假设可交换性，允许 `err_t` 与更新历史相关；代价是覆盖只保证**长期平均**而非逐步条件覆盖。

**定义 451（分层变化点检测与重置）** 对每层维护 Page–Hinkley 统计量 `PH_s`。若 `PH_s > h_s`，判定变化点：`q_s ← q_global`、清空该层 ACI 累积量并标记「需重新接地」；重置后的瞬态由引理 61 的 reset 项界定。

**定义 452（影子评估与晋升证书）** 候选 `θ'` 只在影子流 `𝒮_sh` 上评估（不接管执行）：
`PromotionCert(θ') = [ R_sh(θ') ≤ ρ ] ∧ [ min_s Cov_s^{sh}(θ') ≥ 1−α−δ ] ∧ [ BWT(θ') ≥ −η ] ∧ [ D_beh(θ') ≤ ε_beh ]`。
四项全过才允许晋升；影子遗憾定义为 `R_sh = (1/m)Σ_t (ℓ_t(θ')−ℓ_t(θ_ref))^+`，只计「比现状更差」的部分。

**定义 453（版本快照与回滚）** `V_t = (θ_t, q_t, replay_t)`，大小 `O(r(d+k)+|strata|)`。`Rollback(V_t)` 恢复 `θ, q, replay` 并在下一静默点生效。**回滚是精确的**（确定性快照），不是「近似撤销」。

**定义 454（稳健回执聚合与破坏点）** 对回执损失 `{ℓ_i}` 取截尾均值 `trim_β`（去掉上下各 `β/2` 分位）或中位数均值。破坏点 `β_max ≥ β`：只要污染比例 `< β_max`，聚合估计的偏置有界 `|bias| ≤ 2β_max·L_max`。签名/来源校验是聚合前的硬门；`infl_i` 为单条回执的影响，超过阈值即隔离。

**定义 455（分层适配器路由与正交合并）** 路由 `g_s(ι)` 选择层 `s` 的适配器；需要合并时 `Δ_merge=Σ_s g_s Δ_s`。定义干扰
`I_interf = ‖Σ_{i≠j} g_i g_j (Δ_i Δ_j^T + Δ_j Δ_i^T)‖₂`。
合并前对 `{Δ_s}` 做子空间正交化（Gram–Schmidt on `col(B_s)`）；若 `I_interf > ε_int` 则**不合并**，改为硬路由（同一时刻只激活一个适配器），再退化为单一全局适配器。

**定义 456（回放保留与遗忘界）** 维护分层回放 `replay`（按旧层覆盖度配比）。后向迁移 `BWT = (1/|R_old|)Σ_s [perf_s(θ_T)−perf_s(θ_s)]`。约束 `BWT ≥ −η`；否则提高回放比例或拒绝该次晋升。回放只用于评估与重放，不改变 UC。

**定义 457（更新预算与摊销 ROI）** 单次更新代价 `c_up = O(r(d+k))`，评估需 `n_upd` 条回执。仅当 `c_up/n_upd + c_verify ≤ budget_slack` 且 `n_upd ≥ n_min` 时准入更新，保证在线更新净收益为正（引理 68）。

**定义 458（校准锁 Lock_cv）** 对每个在途提交 `(C, receipts)`，在 `[commit(C), verify(receipts)]` 窗口内禁止更新任何影响验证的适配器与阈值。形式化：`Lock_cv` 持有期间 `θ` 与 `q` 只读。违反将导致「验证器与被验证对象同源漂移」，使证据失效。

**定义 459（受限安全探索与支撑不变）** 适配器只能重排 `𝔸_adm(ι)` 内动作，**不能扩大支撑**：`∀θ, Supp(π_θ) ⊆ 𝔸_adm(ι)`。因此安全遗憾 `R_safety ≡ 0`：在线探索不产生越权动作；探索的代价只体现在信息增益与遗憾，不体现在安全约束违反。

**定义 460（回执信任模型与投毒）** 回执 `r` 带签名 `Sig(r)` 与来源 `prov(r)`。污染模型：最多 `β` 比例回执被任意篡改；聚合前先验签，验签失败即丢弃。对通过验签但语义错误（错标）的回执，由 RRA 的截尾机制提供 `β_max` 级鲁棒性。

**定义 461（在线遗憾分解）** `R_T = Σ_t [ℓ_t(θ_t)−ℓ_t(θ*)]`，分解为
`R_T ≤ R_stat(T) + R_drift(T) + R_gate + R_safety`，其中 `R_stat=O(√T)`（或 `O(√(rT))`），`R_drift` 由变化点数与重置代价给出，`R_gate` 由影子评估样本量给出，`R_safety=0`（定义 459）。这个分解是本轮的可证伪核心。

**定义 462（分层覆盖状态）** `Cov_s(T) = 1 − (1/T_s)Σ_{t∈s} err_t`。要求**逐层** `|Cov_s(T)−(1−α)| ≤ δ_cov`，而不仅是边缘 `|Cov(T)−(1−α)| ≤ δ_cov`。边缘达标但逐层塌陷被视为失败（正是本轮要防的「平均掩盖稀有层」）。

**定义 463（适配证书 RepairCert″）** `RepairCert″(s) = (RepairCert′(s), adapter_ver, update_cert, q_state, rollback_ptr)`，使审计可沿「指令 → 块 → 回执 → 主张 → 适配器版本 → 校准状态」六级证据链复现，并可一键回到 `rollback_ptr`。

**定义 464（晋升静默点）** `q_quiesce ∧ Lock_cv=free ∧ 无待处理不可逆动作`。晋升与热替换只允许发生在此联合静默点；任何在途块先 drain 或按 `abort` 截断补偿（与第 3 轮引理 57 同一口径）。

## 3. 关键算法骨架

```python
# IP-328：冻结骨干 + 安全头冻结；只学低秩增量
class FrozenLowRankAdapter:
    def __init__(self, W, d, k, r):
        self.W = freeze(W)                    # 骨干永久冻结
        self.A = zeros(r, k); self.B = zeros(d, r)
        self.safety = freeze(SafetyHead())    # Γ / shield / Barrier：永不更新

    def forward(self, x, iota):
        delta = self.B @ (self.A @ x)         # rank <= r
        return self.safety.scan(self.W(x) + project(delta, admissible_subspace(iota)))

    def snapshot(self):
        return (self.A.copy(), self.B.copy())  # O(r(d+k))

    def restore(self, snap):
        self.A, self.B = snap                  # 精确回滚

# IP-329：函数空间信任域（行为散度，不是参数范数）
def fsr_admit(cand, ref, probes, eps_beh):
    if cand.safety_delta() != 0:               # 安全头被动过 => 直接拒绝
        return False, "safety_head_touched"
    d_beh = max(
        behavior_divergence(cand, ref, s, x)
        for s in probes for x in probes[s]
    )
    return (d_beh <= eps_beh), d_beh

# IP-330：分层在线自适应共形 + 变化点重置
class OAC:
    def update(self, s, err):
        self.q[s] = clip(self.q[s] + GAMMA * (ALPHA - err), Q_LO, Q_HI)
        self.ph[s] = max(0.0, self.ph[s] + (err - ALPHA - self.delta_ph))
        if self.ph[s] > self.h[s]:             # 变化点
            self.q[s] = self.q_global
            self.ph[s] = 0.0
            self.need_reground.add(s)
        if self.n[s] < N_MIN:                  # 低样本优雅回退
            return self.q_global               # => 第 3 轮 SC-Cal
        return self.q[s]

# IP-332：鲁棒回执聚合
def robust_aggregate(receipts, beta):
    good = [r for r in receipts if verify_sig(r)]          # 硬门：验签
    losses = sorted(loss(r) for r in good)
    lo, hi = int(beta/2 * len(losses)), len(losses) - int(beta/2 * len(losses))
    return mean(losses[lo:hi]) if hi > lo else median(losses)  # trim_beta

# IP-334：8C 闭环 = 7C + 在线更新 + 影子门控 + 静默晋升
def adaptgauge_8c(M, s, ell):
    ok = instructgauge_7c(M, s, ell)       # 第 3 轮 7C 原样，不改一行
    if not ok:
        return False

    with M.lock_cv.acquire(s):             # 校准锁：验证窗口内禁止改模型
        receipts = M.last_receipts(s)
        clean    = robust_aggregate(receipts, BETA)   # 验签 + 截尾
        err      = int(not M.covered(s))              # 该层覆盖错误
        M.oac.update(s, err)                          # 只改阈值状态

        cand = M.adapter.step(clean, s)               # rank-r 在线一步
        ok_tr, d_beh = fsr_admit(cand, M.adapter.ref, M.probes[s], EPS_BEH)
        if not ok_tr:
            return False                              # 信任域拒绝 => 保持旧版

        cert = M.sgp.shadow_eval(cand, M.shadow[s])   # 影子流，不接管执行
        if not cert.pass_all(rho=RHO, delta=DELTA, eta=ETA):
            return False                              # 门控失败 => 不晋升

        if not M.quiesce.is_quiet(s):                 # 只在联合静默点晋升
            return False

        M.snapshot.push(M.adapter.snapshot(), M.oac.state())   # 先存快照
        M.mreg.hot_replace(M.dpe, cand)                        # 再切换
        M.audit.emit(RepairCert__(s, cand, cert, M.oac.state()))
    return True

# IP-335：主闭环（50Hz 不变）
def AdaptGauge_round(M, obs, audio, tac, depth, det, ell=None):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s)
            submit_async(adaptgauge_8c, M, s, ell)    # 全异步
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 4. 推导

**引理 59（更新闭包 ⇒ 安全不变）** 若 UC 成立（安全头冻结、适配器只重排 `𝔸_adm(ι)` 内动作），则对**任意**适配器状态 `θ`（包括在线学到的、被投毒的、超参数的），第 3 轮的安全不变量 `Inv`（前缀封闭截断、不可逆屏障、能力闭包）仍成立。故 `P(越权动作) = 0` 与在线学习的统计行为**无关**。
*证明骨架*：`Inv` 只依赖 `Γ`、`shield`、`Barrier` 与动作支撑。UC 给出 `∂Safety/∂θ ≡ 0` 且 `Supp(π_θ) ⊆ 𝔸_adm(ι)`；对任意 `θ`，安全头输出与静态情形逐位相同，盾归纳（引理 52）不受影响。适配器只能改变同一可采纳集内的偏好序，不能改变可行性。

**引理 60（参数范数不充分、行为散度才准入）** 设网络 `L`-Lipschitz。则 `‖f_{θ+Δθ}(x)−f_θ(x)‖ ≤ L‖ΔW‖₂‖x‖`：参数范数只在输入范数有界时给出行为界。**反例**：取秩 1 的 `ΔW=ε u v^T`，在 `v` 方向且 `‖x‖=1/ε` 的输入上输出偏移为 `O(1)`，可翻转决策，而 `‖Δθ‖=ε` 可任意小。故「参数高效」不能替代「行为受控」；FSR 必须在分层探针（含压力/分布外探针）上实测 `D_beh`，Lipschitz 界仅作兜底（E458 检验）。

**引理 61（非可交换流上的分层长期覆盖）** 在 `err_t∈[0,1]`、`q_t∈[Q_LO,Q_HI]` 下，ACI 更新满足
`|(1/T)Σ_t err_t − α| ≤ (Q_HI−Q_LO+γ)/(γT)`。
有 `k` 个变化点且每点重置时，附加瞬态项 `O(k·(Q_HI−Q_LO)/(γT))`；分层的联合覆盖由 `|S|` 层 Bonferroni 修正给出 `δ_cov/|S|` 每层。与静态共形不同，这里**不要求**层内可交换，代价是只保证长期平均而非条件覆盖。
*证明骨架*：把更新式对 `t` 求和并望远镜化，`q_T−q_0 = γ(αT − Σ err_t − 累积裁剪项)`，移项并用 `q` 的有界性即得；变化点把求和分段，每段重新应用同一界。

**引理 62（影子门控晋升的可靠性）** 若影子流与部署流同分布、影子样本 `m` 条、损失有界 `L_max`，则候选晋升后真实遗憾 `R ≤ R_sh + L_max√(2ln(1/δ)/m)`，且「真实更差却被晋升」的概率 `≤ δ`。结合回滚，晋升窗口内的下行风险被 `ρ + 回滚延迟代价` 夹住。
*证明骨架*：对影子遗憾做 Hoeffding 双侧界；晋升只取 `R_sh ≤ ρ` 且四门槛全过者，故坏适配器被拒的概率至少 `1−δ`；回滚保证窗口内最坏损失不超过旧版加一次切换代价。

**引理 63（静默点回滚的精确等价）** 若回滚只在 `q_quiesce ∧ Lock_cv=free` 执行，则恢复的 `(θ,q,replay)` 与快照逐位相同，在途块已 drain 或按 `abort` 截断补偿，没有任何块观察到「混合适配器/混合契约」。故回滚后的系统与「从未晋升」的第 3 轮静态版**逐指令等价**。
*证明骨架*：快照是 `(A,B,q,replay)` 的深拷贝；静默点保证无在途块读取新适配器；与第 3 轮引理 57 同一论证，把「混合契约」替换为「混合适配器」。

**引理 64（低秩在线遗憾与算力）** 在秩 `r` 子空间上做投影在线梯度，凸损失下 `R_stat = O(√T)`（若最优比较器落在秩 `r` 球内；否则加一项近似误差 `O(√(rT)·dist)`）。每步代价 `O(r(d+k))`，对比全参数更新 `O(dk)`，当 `r ≪ min(d,k)` 时节省 `min(d,k)/r` 倍。由 E466 检验。

**引理 65（鲁棒聚合的破坏点）** 采用 `β`-截尾均值时，只要污染比例 `< β/2`，聚合偏置 `|bias| ≤ 2βL_max`；中位数均值把破坏点提高到 `1/2` 但方差更大。验签作为硬门可把「伪造回执」的污染面先削掉，只剩「通过验签但语义错误」的软污染。故 `β_max` 是设计参数，不是事后观察。

**引理 66（回放保留的遗忘界）** 设旧层数据占回放比例 `p_s`，则旧层损失上界随 `p_s` 增大而下降；在标准在线学习假设下 `BWT ≥ −O(1/(p_min·n))`。约束 `BWT ≥ −η` 等价于要求 `p_min ≥ Ω(1/(η n))`——即「要不忘，必须按旧层覆盖度配比回放」。低样本旧层自动获得更高回放权重，防止被新层挤掉（E463 检验）。

**引理 67（多适配器合并的干扰界）** 线性部分 `Δ_merge=Σ g_s Δ_s` 的干扰 `I_interf` 由交叉项给出。若各 `Δ_s` 的列空间正交（`Δ_iΔ_j^T=0`），则 `I_interf=0`，合并无干扰；对非线性骨干，残留为二阶项 `O(‖Δ_i‖‖Δ_j‖)`。因此 AMR 先正交化再合并，超阈值则硬路由（一次只激活一个），保证「要么可证无干扰、要么根本不合并」。

**引理 68（更新摊销与时延保全）** 单次更新 `c_up=O(r(d+k))`，需 `n_upd` 条回执；当 `c_up/n_upd + c_verify ≤ budget_slack` 时在线更新净收益为正。更新全异步、只在静默点生效，故 50Hz 主路径新增周期 `< 0.2ms`，继承第 3 轮引理 58 与 ToolGauge 引理 50 的硬实时结论。
