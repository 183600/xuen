# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；灵感循环第 2 轮；本轮灵感：「扩散策略」×「场景落地」）

> 第 59 轮把「执行层物理」全面纳入安全论证链：BUQ 辨识电机结构性不确定性、ERTC 把嵌入式时序变成硬契约、EEIS 把概率安全界编译成阻抗证书、CLEP 让执行实测成为第 5 个对账模态。但它仍默默假设了三件事：**(i) 承诺的对象是「单条轨迹/一组阻抗参数」**，因此 EEIS 可以对一个参数包签发证书；**(ii) 场景是「已知且平稳」的检查点集合**，因此共形校准的交换性成立、证书一次签发长期有效；**(iii) 部署是「一次性发布」**，发布之后系统照常运行。本轮两个灵感精准击中这三个隐含假设：**扩散策略**把动作从「单点」变成「多模态轨迹分布 + 随机迭代采样」，可验证性与实时性同时被挑战；**场景落地**把系统从实验室推到非平稳、长尾、有人、要运维、要合规的真实世界，校准交换性与证书时效性同时破裂。本轮核心命题：**「把扩散策略的随机轨迹分布，编译成场景条件下带统计保证的轨迹管；把场景落地的分布漂移与长尾，反编译成证书有效性域与部署门」**——从「执行接地」升级为「场景接地」。

核心矛盾：
- **H32（生成式承诺的可验证性鸿沟）**：扩散策略输出的是条件分布 π_θ(a_{t:t+H}|o,φ)，不是一条轨迹；第 59 轮的 K_safe 是「阻抗参数集」，无法直接约束一条被采样出来的动作块。采样方差、模式坍缩、条件 OOD 让证书只覆盖训练分布内的样本；更糟的是，安全过滤若放在「采样之后」，会破坏多模态并浪费算力，若放在「采样之中」，投影又改变了分布、使共形校准失效。**证书不能签给分布，只能签给「被投影后的轨迹 + 一个共形管」**。
- **H33（场景交换性破裂与长尾风险）**：共形校准假设「校准集与部署场景可交换」；真实落地中地面摩擦、负载、光照、人距、网络、任务类型持续漂移，长尾场景样本稀少但风险集中。全局一个分位数会「用平均场景的宽带宽掩盖长尾场景的窄带宽」——在长尾处名义覆盖 1−α，实际覆盖可能远低。**必须把「场景」变成一等公民：指纹、覆盖度、条件共形、漂移检测、有效性域**。
- **H34（部署运维与责任链断裂）**：策略版本、固件版本、场景分布、负载配置任一变化都会使旧证书失效；影子/金丝雀/全量/回滚没有形式化门与证据链；「发布」是一次性动作而非持续过程。**证书需要有效期与再认证触发器，发布需要状态机与可审计的部署证据 J_deploy**。

## 0. 直觉与动机

**灵感 1（扩散策略 → 从「点承诺」到「分布承诺」SCDP）**
直觉：第 59 轮的承诺是一个阻抗参数包 (K_p,K_d,F_max,ω_traj) 或一条名义轨迹，EEIS 对它发证书。但真实接触任务是**多模态**的：绕过障碍可以从左也可以从右，推门可以先推后拉，抓取可以从上方也可以侧向。单峰策略会把两个模态平均成「撞向中间」的坏解。扩散策略把动作块 a_{t:t+H} 建模为 p_θ(a|c) 的迭代去噪分布，天然表达多模态、时序相关、可组合的轨迹。关键洞见：**分布承诺比点承诺更诚实，但也更难验证**——于是承诺对象升级为三元组 (a^{(0)}, T(a,ρ), Cert)，其中 T(a,ρ) 是由共形校准给出半径 ρ 的轨迹管。

**灵感 2（扩散策略 → 安全引导去噪 SGDP）**
直觉：扩散采样是「从纯噪声中逐步雕刻轨迹」。如果在每个去噪步都用当前干净估计 â_0 做安全投影（CBF 约束、力限幅、EEIS 稳定性证书、可达集），就能把不可行样本拉回可行域；但投影会改变分布，产生**投影残差**。把残差纳入共形校准，就得到**带统计保证的轨迹管**。关键设计选择：不是「采样后过滤」（浪费样本、杀掉多样性），而是「去噪中引导 + 鲁棒收紧投影」——既保持多模态，又让最终样本满足鲁棒安全约束。

**灵感 3（场景落地 → 场景覆盖流形 SCM 与长尾治理）**
直觉：实验室校准假设「校准场景 = 部署场景」。真实落地里地面摩擦、负载、光照、人距、网络、任务都在变；长尾场景样本少但风险高。需要给每个部署上下文一个**场景指纹** φ，度量它到校准集的**新颖度/覆盖度**，把「证书在哪些场景有效」显式写出来；并用**风险加权覆盖**驱动主动场景采集——去哪里采数据最能降低长尾风险。

**灵感 4（场景落地 → 场景条件共形 SCC 与漂移）**
直觉：把共形从「全局一个分位数」升级为「按场景分层的条件分位数」；协变量偏移用密度比加权；漂移检测（MMD/新颖度率）触发带宽膨胀或证书失效。证书不再永久有效，而是有**有效性域 V** 与**再认证触发器**。这相当于给第 59 轮的执行证书加了一个「地理围栏 + 保质期」。

**灵感 5（合流 → 部署孪生闭环 DTL + 部署证据 DPX + PCE++++ 场景预算）**
直觉：发布不是一次性动作，而是 回放→影子→金丝雀→全量→监控→回滚 的状态机；每阶段有量化门（成功率、违例率、风险加权覆盖、长尾风险、p99 时延、漂移量）；全过程留部署证据链 J_deploy。资源上新增 **B_scene**（校准样本、影子次数、覆盖赤字、长尾风险预算），VOI 显式含「覆盖增益 − 长尾风险」。于是「场景落地」不再是工程口号，而是可计算、可审计、可回滚的闭环。

## 1. 形式化定义（增量：定义 153–160）

**定义 153（场景指纹与覆盖流形 SCM）** 场景指纹
```
φ_scene = (μ_floor, m_payload, L_light, d_human, τ_task, s_health, T_env, q_net, e_scene) ∈ Φ
```
其中前 8 维为可解释物理量（地面摩擦、负载、光照、人距、任务类型、传感器健康、环境温度、网络质量），e_scene 为学习到的场景嵌入。给定校准场景集 D_cal={φ_i}，新颖度 ν(φ)=‖φ−φ_(k)‖_M（度量 M 下第 k 近邻距离）；覆盖指示 cov(φ)=1[ν(φ)≤τ_cov]。风险加权覆盖与长尾风险：
```
Cov_w(D_cal) = ∫ w(φ)·cov(φ)·p_scene(dφ) / ∫ w(φ)·p_scene(dφ)
L_tail(π)    = E_{φ~p_scene}[ w(φ)·(1−cov(φ))·R(π,φ) ]
```
w(φ) 为场景风险权重（人距近、地面滑、负载大权重高），R(π,φ) 为策略在该场景的风险（违例/失败/力超限的加权和）。SCM 的目标不是「覆盖所有 φ」（不可能），而是**诚实报告覆盖边界并把边界外的行为强制降级**。

**定义 154（场景条件扩散策略 SCDP）** 前向加噪 q(a^{(k)}|a^{(0)})=N(√ᾱ_k·a^{(0)},(1−ᾱ_k)I)，k=1..N；反向去噪
```
p_θ(a^{(k−1)}|a^{(k)}, c) = N( μ_θ(a^{(k)},k,c), Σ_θ(a^{(k)},k,c) )
c = (o_t, φ_scene, b_r, K_safe)          # 观测、场景指纹、信念、执行层安全参数集
```
策略输出为动作块分布 π_θ(a_{t:t+H}|o_t,φ,b_r)，采样 K 条候选轨迹后由 SGDP 投影并择优选一条。SCDP 的「场景条件」不是简单拼接 φ，而是用 **FiLM/交叉注意力把 φ 注入每个去噪步**，使不同场景下的去噪轨迹可分离（避免「平均场景」）。

**定义 155（安全引导去噪 SGDP 与认证轨迹管）** 第 k 步的干净估计
```
â_0^{(k)} = ( a^{(k)} − √(1−ᾱ_k)·ε_θ(a^{(k)},k,c) ) / √ᾱ_k
```
鲁棒安全集（对轨迹管半径 ρ 做收紧）：
```
A_safe^ρ(φ) = { a | x_{t+1}=f(x_t,a_t); g(x_t,a_t) ≤ −ρ·L_g;
                    |F_t| ≤ F_max − ρ·L_F;  h_CBF(x_t) ≥ ρ·L_h;
                    K_safe(φ) ≠ ∅ }
```
安全引导去噪（每步先梯度引导、再投影）：
```
a^{(k−1)} = Π_{A_safe^ρ}( μ_θ(a^{(k)},k,c) − η_k·∇_a C_safe(â_0^{(k)}) )
r_proj    = ‖ a^{(0)}_proj − a^{(0)}_raw ‖_∞
```
其中 Π 为到安全集的投影（逐时刻 QP：CBF/力限/速度限/关节限），C_safe 为安全代价（屏障违反量 + 力超限 + 稳定性余量缺口）。若某步投影不可行，则丢弃该样本重采；连续 K_retry 次不可行 ⇒ 触发 DEGRADE。最终输出**认证轨迹管**
```
T(a,ρ) = { a' | max_t ‖a'_t − a_t‖_∞ ≤ ρ }
```
保证 P(a_exec ∈ T(a,ρ) | φ) ≥ 1−α−δ_proj−δ_shift−δ_drift，ρ 由 SCC（定义 156）给出。关键：**投影用的是收紧后的 A_safe^ρ，因此只要执行落在管内，鲁棒约束就不会被突破**。

**定义 156（场景条件共形 SCC）** 场景分层 s=κ(φ)（对 φ 聚类/分箱）。分层校准分数
```
s_i = sup_t ‖ a_i^{exec} − a_i^{plan} ‖_∞        # 执行-计划偏差（含跟踪误差）
q_s = WeightedQuantile_{1−α}( {s_i}_{i∈D_cal(s)}, {w_i}_{i∈D_cal(s)} )
```
w_i 为密度比权重 p_deploy(φ_i)/p_cal(φ_i)（估计并截断到 ρ_max）。预测集 C(a)=T(a,q_s)。条件覆盖保证：
```
P( a_exec ∈ C(a) | φ∈s ) ≥ 1 − α − δ_shift − δ_drift
```
漂移量 Δ_drift = MMD(Φ_deploy, Φ_cal)（或新颖度率）。若 Δ_drift>τ_drift ⇒ 令 α_eff=α−δ_drift 膨胀带宽，或直接判证书失效。**证书有效性域**
```
V_cert = { φ | ν(φ) ≤ τ_cov ∧ Δ_drift(φ) ≤ τ_drift ∧ w(φ) ≤ ρ_max }
```
φ∉V_cert ⇒ 不得使用该证书，强制回退到第 59 轮的保守阻抗预设 + 安全监视。

**定义 157（扩散计算契约 DP-ERTC）** 去噪 N 步的计算成本与预算
```
WCET_diff(N) = c_enc + N·c_step + c_dec
WCET_budget  = WCET_slack − WCET_other
N* = max{ N | WCET_diff(N) ≤ WCET_budget }
```

轨迹管半径 ρ(N) 随 N 单调不增（更多去噪步 ⇒ 更接近专家分布 ⇒ 更紧的管），质量 q(N)=1−ρ(N)/ρ_max。契约要求 q(N*) ≥ q_min。若不足则降级为**蒸馏单步策略** π_distill（一致性模型/渐进蒸馏），并诚实膨胀管半径 Δρ_distill；若仍不可行则回退第 59 轮阻抗预设或安全停。输出 Cert_diff=(N*, q(N*), ρ(N*), fallback_level, WCET_measured)。

### IP-152 SCM（场景覆盖流形）

```python
class ScenarioCoverageManifold:
    def __init__(self, calib_scenarios, metric, tau_cov, k=5):
        self.D_cal = calib_scenarios            # List[φ]
        self.metric = metric                    # 归一化马氏/欧氏
        self.tau_cov = tau_cov
        self.k = k
        self.kdtree = build_kdtree(calib_scenarios, metric)

    def fingerprint(self, obs, ctx):
        phi_phys = np.array([ctx.floor_friction, ctx.payload_mass, ctx.light,
                             ctx.human_distance, ctx.task_id, ctx.sensor_health,
                             ctx.temperature, ctx.net_qos])
        e_scene = self.scene_encoder(obs, ctx)   # 学习嵌入
        return normalize(np.concatenate([phi_phys, e_scene]))

    def novelty(self, phi):
        dists, _ = self.kdtree.query(phi, k=self.k)
        return float(np.mean(dists))             # k-NN 平均距离

    def coverage(self, phi):
        return 1.0 if self.novelty(phi) <= self.tau_cov else 0.0

    def risk_weighted_coverage(self, phis, w_fn):
        w = np.array([w_fn(p) for p in phis])
        c = np.array([self.coverage(p) for p in phis])
        return float((w * c).sum() / (w.sum() + 1e-9))

    def tail_risk(self, phis, policy, risk_fn, w_fn):
        return float(np.mean([w_fn(p) * (1 - self.coverage(p)) * risk_fn(policy, p)
                              for p in phis]))

    def mine(self, candidate_pool, policy, risk_fn, w_fn, budget):
        """主动场景采集：按「单位样本长尾风险下降」排序"""
        scored = []
        for phi in candidate_pool:
            if self.coverage(phi):       # 已覆盖场景优先级低
                continue
            gain = w_fn(phi) * risk_fn(policy, phi) / (1 + self.novelty(phi))
            scored.append((gain, phi))
        scored.sort(key=lambda x: -x[0])
        return [phi for _, phi in scored[:budget]]
```

### IP-153 SCDP（场景条件扩散策略）

```python
class ScenarioConditionedDiffusionPolicy:
    def __init__(self, eps_theta, scene_encoder, horizon=16, n_diffusion=50):
        self.eps_theta = eps_theta
        self.scene_encoder = scene_encoder
        self.H = horizon
        self.N = n_diffusion

    def encode_condition(self, obs, phi, belief, K_safe):
        # FiLM/交叉注意力注入场景，避免「平均场景」
        return Condition(obs=obs, phi=phi, belief=belief, K_safe=K_safe)

    def sample_candidates(self, cond, n_samples, N=None):
        N = N or self.N
        samples = []
        for _ in range(n_samples):
            a = torch.randn(1, self.H, self.action_dim)
            for k in reversed(range(1, N + 1)):
                eps = self.eps_theta(a, k, cond)
                a = ddim_step(a, eps, k, N)      # 确定性 DDIM 步
            samples.append(a)
        return samples                       # 多模态候选，交由 SGDP 投影
```

### IP-154 SGDP（安全引导去噪 + 认证轨迹管）

```python
class SafetyGuidedDiffusionProjector:
    def __init__(self, policy, scc, eeis, cbf, eta_schedule):
        self.policy = policy
        self.scc = scc
        self.eeis = eeis
        self.cbf = cbf
        self.eta = eta_schedule

    def denoise_and_certify(self, obs, phi, belief, K_safe, N, max_retry=3):
        cond = self.policy.encode_condition(obs, phi, belief, K_safe)
        for attempt in range(max_retry):
            a = torch.randn(1, self.policy.H, self.policy.action_dim)
            residuals, ok = [], True
            for k in reversed(range(1, N + 1)):
                eps = self.policy.eps_theta(a, k, cond)
                mu = self.policy.mu_theta(a, k, cond)
                a0_hat = clean_estimate(a, eps, k)
                grad = grad_safety_cost(a0_hat, phi, K_safe, self.cbf)
                proposal = mu - self.eta[k] * grad
                a_proj, r = self.project_safe(proposal, a0_hat, phi, K_safe)
                if a_proj is None:
                    ok = False
                    break
                residuals.append(r)
                a = a_proj
            if ok:
                rho = self.scc.radius(phi)          # 场景条件共形半径
                if not np.isfinite(rho):
                    return None, "cert_invalid_out_of_domain"
                return CertifiedTrajectory(a, rho, max(residuals)), residuals
        return None, "projection_infeasible"

    def project_safe(self, proposal, a0_hat, phi, K_safe):
        """逐时刻 QP：min ||a - proposal||^2 s.t. 鲁棒 CBF/力限/速度限/关节限"""
        rho = self.scc.radius(phi) if np.isfinite(self.scc.radius(phi)) else 0.0
        constraints = build_robust_constraints(a0_hat, phi, K_safe,
                                               rho, self.cbf)   # 已含 ρ 收紧
        a_proj, feasible = solve_qp(proposal, constraints)
        if not feasible:
            return None, np.inf
        return a_proj, float(np.max(np.abs(a_proj - proposal)))
```

### IP-155 SCC（场景条件共形）

```python
class ScenarioConditionedConformal:
    def __init__(self, alpha, tau_drift, tau_cov, rho_max):
        self.alpha = alpha
        self.tau_drift = tau_drift
        self.tau_cov = tau_cov
        self.rho_max = rho_max
        self.q = {}                    # stratum -> radius
        self.calib_phis = []
        self.drift = 0.0

    def stratum(self, phi):
        return self.scene_cluster.assign(phi)

    def calibrate(self, scores_by_stratum, weights_by_stratum, phis):
        self.calib_phis = phis
        for s, scores in scores_by_stratum.items():
            w = weights_by_stratum[s]
            self.q[s] = weighted_quantile(scores, 1 - self.alpha, w)

    def update_drift(self, deploy_phis):
        self.drift = mmd(deploy_phis, self.calib_phis)

    def radius(self, phi):
        if not self.in_validity_domain(phi):
            return float("inf")            # 证书失效
        s = self.stratum(phi)
        return self.q.get(s, float("inf"))

    def in_validity_domain(self, phi):
        return (novelty(phi) <= self.tau_cov and
                self.drift <= self.tau_drift and
                density_ratio(phi) <= self.rho_max)
```

### IP-156 DP-ERTC（扩散实时计算契约）

```python
class AnytimeDiffusionScheduler:
    def __init__(self, wcet_model, quality_curve, q_min):
        self.wcet = wcet_model            # N -> WCET 上界
        self.quality = quality_curve      # N -> q(N) = 1 - rho(N)/rho_max
        self.q_min = q_min

    def schedule(self, budget):
        N = 0
        for n in range(self.wcet.max_steps, 0, -1):
            if self.wcet(n) <= budget.wcet_slack - budget.wcet_other:
                N = n
                break
        if N > 0 and self.quality(N) >= self.q_min:
            return DiffusionPlan(N=N, mode="full",
                                 quality=self.quality(N),
                                 rho=self.wcet.rho(N))
        if budget.wcet_slack >= self.wcet.distill_cost():
            return DiffusionPlan(N=1, mode="distill",
                                 quality=self.quality(1) - DELTA_DISTILL,
                                 rho=self.wcet.rho(1) + DELTA_RHO_DISTILL)
        return DiffusionPlan(N=0, mode="fallback_impedance",
                             quality=0.0, rho=float("inf"))
```

**正确性定理（Scenario-Grounded Deployment Soundness, SGDS）**
假设 A22–A55（第 53–59 轮）成立；**(A56)** SCM：场景指纹度量忠实反映风险相关差异，新颖度估计误差 ≤δ_cov，覆盖指示诚实；**(A57)** SCDP：扩散模型对真实条件分布的 TV 距离 ≤ε_diff，场景条件注入不丢失模态；**(A58)** SGDP：投影算子 Π 音完备（不可行 ⇔ 真不可行），鲁棒收紧量 ρ·L 覆盖轨迹管扰动，投影残差被 SCC 校准；**(A59)** SCC：分层内校准集与部署场景可交换，密度比有界且估计误差 ≤δ_shift，漂移检测漏检率 ≤δ_drift；**(A60)** DP-ERTC：WCET_diff(N) 为诚实上界，质量曲线 q(N) 单调，蒸馏膨胀量 Δρ_distill 诚实；**(A61)** DTL：各阶段门指标诚实、阶段隔离有效；**(A62)** DPX：部署证据链防篡改、版本哈希一致、再认证触发器完备。则：

1. **场景条件覆盖**：对任意 φ∈V_cert，P(a_exec∈T(a,ρ)|φ) ≥ 1−α−δ_proj−δ_shift−δ_drift−δ_cov；φ∉V_cert 时证书被拒绝而非误用。
2. **生成策略安全性**：经 SGDP 投影并执行于鲁棒轨迹管内，接触力/稳定性/关节限违反概率 ≤ α+δ_proj+δ_model；投影连续不可行 ⇒ 触发降级而非冒险执行。
3. **实时可执行性**：N* 满足 WCET_diff(N*) ≤ WCET_slack−WCET_other；若 q(N*)<q_min 则降级为蒸馏/阻抗预设，且降级被写入 Cert_diff 与 J_deploy。
4. **部署门健全性**：只有全部门 G_i 通过才进入 S3/S4；任一阶段失败 ⇒ S5 回滚；未通过再认证的证书不得在 φ∉V_cert 或版本不匹配时使用。
5. **单向保守性**：漂移增大、覆盖赤字增大、长尾风险升高、场景预算耗尽，只能导致轨迹管加宽、证书域收缩、动作更保守，绝不导致证书更宽或探针更少。
6. **终止性**：SCDP 采样 + SGDP 重试在 K_retry 内终止；DTL 在有限状态机内终止于 {released, rolled_back}；PCE++++ 在五预算内终止于 {承诺(带 Cert_diff+Cert_eeis), 绕行, 降档, L2 协商, 安全停, 场景域收缩停}。
7. **部署界**（对检查点与场景取联合界）：
```
P_safe ≥ 1 − Σ_cp [ δ_f + ε_meta(k) + δ_probe + δ_exec + δ_ertc + δ_eeis
                    + δ_diff(ε_diff) + δ_proj + δ_shift + δ_drift + δ_cov
                    + δ_tail·1[φ∉V_cert] + δ_anytime·1[N*<N_min] ]
         − P(场景指纹失真未检出) − P(漂移漏检) − P(部署门误判) − P(回滚失败)
```

关键：**SCDP 把「点承诺」升级为「分布承诺」**——多模态轨迹不再被平均成坏解；**SGDP 把「采样随机性」变成「可校准的投影残差 + 鲁棒轨迹管」**——证书签给被投影的轨迹而非整个分布；**SCC 把「共形交换性」升级为「场景条件共形 + 有效性域」**——证书有地理围栏和保质期；**DP-ERTC 把「去噪步数」变成「实时可执行的 anytime 契约」**；**DTL/DPX 把「发布」变成「带门与证据链的持续过程」**。三条安全单向通道延续并加强：**信念更准（场景条件）、不确定性更大（漂移/长尾/覆盖赤字）、动作更保守（管加宽/域收缩/降级）**。

### IP-152 SCM（场景覆盖流形）

```python
from dataclasses import dataclass
import numpy as np

@dataclass
class ScenarioFingerprint:
    mu_floor: float; m_payload: float; L_light: float; d_human: float
    tau_task: int; s_health: float; T_env: float; q_net: float
    e_scene: np.ndarray

class ScenarioCoverageManifold:
    def __init__(self, calib_phis, metric, tau_cov, k=5, tau_tail=2.0):
        self.D_cal = np.asarray(calib_phis)
        self.metric = metric
        self.tau_cov = tau_cov
        self.k = k
        self.tau_tail = tau_tail
        self.tree = build_kdtree(self.D_cal, metric)

    def fingerprint(self, obs, ctx, scene_encoder):
        phys = np.array([ctx.floor_friction, ctx.payload_mass, ctx.light,
                         ctx.human_distance, ctx.task_id, ctx.sensor_health,
                         ctx.temperature, ctx.net_qos], dtype=float)
        emb = scene_encoder(obs, ctx)
        return normalize(np.concatenate([phys, emb]))

    def novelty(self, phi):
        d, _ = self.tree.query(phi, k=self.k)
        return float(np.mean(d))

    def coverage(self, phi):
        return 1.0 if self.novelty(phi) <= self.tau_cov else 0.0

    def risk_weighted_coverage(self, phis, w_fn):
        w = np.array([w_fn(p) for p in phis])
        c = np.array([self.coverage(p) for p in phis])
        return float((w * c).sum() / (w.sum() + 1e-12))

    def tail_risk(self, phis, policy, risk_fn, w_fn):
        vals = [w_fn(p) * (1.0 - self.coverage(p)) * risk_fn(policy, p) for p in phis]
        return float(np.mean(vals))

    def mine(self, pool, policy, risk_fn, w_fn, budget):
        scored = []
        for phi in pool:
            if self.coverage(phi):
                continue
            gain = (w_fn(phi) * risk_fn(policy, phi)) / (1.0 + self.novelty(phi))
            scored.append((gain, phi))
        scored.sort(key=lambda t: -t[0])
        return [phi for _, phi in scored[:budget]]

    def is_long_tail(self, phi):
        return (not self.coverage(phi)) and (self.novelty(phi) > self.tau_tail)
```

### IP-154 SGDP（安全引导去噪 + 认证轨迹管）

```python
class SafetyGuidedDiffusionProjector:
    def __init__(self, policy, scc, cbf, eta_schedule, retries=3):
        self.policy = policy
        self.scc = scc
        self.cbf = cbf
        self.eta = eta_schedule
        self.retries = retries

    def denoise_and_certify(self, obs, phi, belief, K_safe, N):
        cond = self.policy.encode_condition(obs, phi, belief, K_safe)
        for _ in range(self.retries):
            a = torch.randn(1, self.policy.H, self.policy.action_dim, device=cond.device)
            residuals, ok = [], True
            for k in reversed(range(1, N + 1)):
                eps = self.policy.eps_theta(a, k, cond)
                mu = self.policy.mu_theta(a, k, cond)
                a0_hat = clean_estimate(a, eps, k)
                grad = grad_safety_cost(a0_hat, phi, K_safe, self.cbf)
                proposal = mu - self.eta[k] * grad
                a_proj, r = self.project_safe(proposal, a0_hat, phi, K_safe)
                if a_proj is None:
                    ok = False
                    break
                residuals.append(r)
                a = a_proj
            if ok:
                rho = self.scc.radius(phi)
                if not np.isfinite(rho):
                    return None, "cert_invalid_out_of_domain"
                return CertifiedTrajectory(a=a, rho=rho,
                                           max_residual=max(residuals),
                                           safety_cost=safety_cost(a, phi, K_safe)), residuals
        return None, "projection_infeasible"

    def project_safe(self, proposal, a0_hat, phi, K_safe):
        rho = self.scc.radius(phi)
        rho = 0.0 if not np.isfinite(rho) else rho
        constraints = build_robust_constraints(
            a0_hat, phi, K_safe, rho, self.cbf
        )  # CBF: h(x) >= rho*L_h; |F| <= F_max - rho*L_F; 速度/关节限同理
        a_proj, feasible = solve_qp(proposal, constraints)
        if not feasible:
            return None, np.inf
        return a_proj, float(np.max(np.abs(a_proj - proposal)))
```

```python
class ScenarioConditionedConformal:
    def __init__(self, alpha, tau_drift, tau_cov, rho_max, clusterer):
        self.alpha = alpha
        self.tau_drift = tau_drift
        self.tau_cov = tau_cov
        self.rho_max = rho_max
        self.clusterer = clusterer
        self.q = {}
        self.calib_phis = None
        self.drift = 0.0

    def stratum(self, phi):
        return self.clusterer.assign(phi)

    def calibrate(self, scores_by_stratum, weights_by_stratum, calib_phis):
        self.calib_phis = np.asarray(calib_phis)
        for s, scores in scores_by_stratum.items():
            w = np.asarray(weights_by_stratum[s], dtype=float)
            self.q[s] = weighted_quantile(np.asarray(scores), 1 - self.alpha, w)

    def update_drift(self, deploy_phis):
        self.drift = float(mmd(np.asarray(deploy_phis), self.calib_phis))

    def in_validity_domain(self, phi):
        return (novelty(phi) <= self.tau_cov and
                self.drift <= self.tau_drift and
                density_ratio(phi) <= self.rho_max)

    def radius(self, phi):
        if not self.in_validity_domain(phi):
            return float("inf")        # 证书失效，禁止使用
        return self.q.get(self.stratum(phi), float("inf"))
```

```python
class AnytimeDiffusionScheduler:
    def __init__(self, wcet_model, quality_curve, q_min,

        self.quality = quality_curve

        self.delta_rho_distill = delta_rho_distill

        N = 0

        if budget_left >= self.distill_cost:

                                 self.quality(1) - self.delta_distill,
                                 self.wcet.rho(1) + self.delta_rho_distill)
        return DiffusionPlan(0, "fallback_impedance", 0.0, float("inf"))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SCM | 建树 O(N_cal log N_cal)；查询 O(log N_cal·d_φ) | O(N_cal·d_φ) | 新颖度/覆盖误差 ≤δ_cov；长尾风险诚实上界 |
| SCDP | O(K·N·C_ε) | O(K·H·d_a) | TV(π_θ,π*)≤ε_diff；多模态保留 |

| DP-ERTC | O(1) | O(1) | WCET_diff(N*)≤预算；质量不足即降级 |
| DTL | O(Σ 阶段回放) | O(场景库+门记录) | 门失败即回滚；有限状态机可达 |

| PCE++++ | O(\|CP\|·(k_p+k_c+k_ft+k_ux+k_exec+k_scene)·(C_VOI+C_ε+C_QP)) | O(\|V\|+\|σ\|+\|𝒢\|+N_cal) | 五预算单调、互不挪用、耗尽即保守 |

**正确性定理（Scenario-Grounded Deployment Soundness, SGDS）**
假设 A22–A55（第 53–59 轮）成立；**(A56)** SCM：场景指纹度量忠实反映风险相关差异，新颖度估计误差 ≤δ_cov，覆盖指示诚实；**(A57)** SCDP：扩散模型对真实条件分布 TV 距离 ≤ε_diff，场景条件注入不丢失模态；**(A58)** SGDP：投影算子 Π 音完备（不可行 ⇔ 真不可行），鲁棒收紧量 ρ·L 覆盖轨迹管扰动，投影残差被 SCC 校准；**(A59)** SCC：分层内校准集与部署场景可交换，密度比有界且估计误差 ≤δ_shift，漂移检测漏检率 ≤δ_drift；**(A60)** DP-ERTC：WCET_diff(N) 为诚实上界，质量曲线 q(N) 单调，蒸馏膨胀量 Δρ_distill 诚实；**(A61)** DTL：各阶段门指标诚实、阶段隔离有效；**(A62)** DPX：部署证据链防篡改、版本哈希一致、再认证触发器完备。则：

1. **场景条件覆盖**：对任意 φ∈V_cert，P(a_exec∈T(a,ρ)|φ) ≥ 1−α−δ_proj−δ_shift−δ_drift−δ_cov；φ∉V_cert 时证书被拒绝而非误用。
2. **生成策略安全性**：经 SGDP 投影并执行于鲁棒轨迹管内，接触力/稳定性/关节限违反概率 ≤ α+δ_proj+δ_model；投影连续不可行 ⇒ 触发降级而非冒险执行。
3. **实时可执行性**：N* 满足 WCET_diff(N*) ≤ WCET_slack−WCET_other；若 q(N*)<q_min 则降级为蒸馏/阻抗预设，且降级被写入 Cert_diff 与 J_deploy。
4. **部署门健全性**：只有全部门 G_i 通过才进入 S3/S4；任一阶段失败 ⇒ S5 回滚；未通过再认证的证书不得在 φ∉V_cert 或版本不匹配时使用。
5. **单向保守性**：漂移增大、覆盖赤字增大、长尾风险升高、场景预算耗尽，只能导致轨迹管加宽、证书域收缩、动作更保守，绝不导致证书更宽或探针更少。
6. **终止性**：SCDP 采样 + SGDP 重试在 K_retry 内终止；DTL 在有限状态机内终止于 {released, rolled_back}；PCE++++ 在五预算内终止于 {承诺(带 Cert_diff+Cert_eeis), 绕行, 降档, L2 协商, 安全停, 场景域收缩停}。
7. **部署界**（对检查点与场景取联合界）：
```
P_safe ≥ 1 − Σ_cp [ δ_f + ε_meta(k) + δ_probe + δ_exec + δ_ertc + δ_eeis
                    + δ_diff(ε_diff) + δ_proj + δ_shift + δ_drift + δ_cov
                    + δ_tail·1[φ∉V_cert] + δ_anytime·1[N*<N_min] ]
         − P(场景指纹失真未检出) − P(漂移漏检) − P(部署门误判) − P(回滚失败)
```

关键：**SCDP 把「点承诺」升级为「分布承诺」**——多模态轨迹不再被平均成坏解；**SGDP 把「采样随机性」变成「可校准的投影残差 + 鲁棒轨迹管」**——证书签给被投影的轨迹而非整个分布；**SCC 把「共形交换性」升级为「场景条件共形 + 有效性域」**——证书有地理围栏和保质期；**DP-ERTC 把「去噪步数」变成「实时可执行的 anytime 契约」**；**DTL/DPX 把「发布」变成「带门与证据链的持续过程」**。三条安全单向通道延续并加强：**信念更准（场景条件）、不确定性更大（漂移/长尾/覆盖赤字）、动作更保守（管加宽/域收缩/降级）**。

**一句话**：本轮把「扩散策略的分布承诺」与「场景落地的非平稳性」同时纳入安全链，但**整条链的可信度最终押在「场景指纹 + 覆盖/漂移估计」是否忠实**——若长尾场景被指纹映射到已覆盖区域、或密度比估计在极端协变量偏移下失真，那么「场景条件共形」会给出名义 1−α、实际远低的覆盖，证书有效性域会悄悄缩回实验室而系统仍自认为安全；必须以「φ∉V_cert 即拒绝证书并保守回退」「漂移漏检率独立审计」「长尾场景强制人工/仿真双签」「投影不可行即停」四重护栏，宁可频繁收缩场景域导致「又慢又笨」，绝不允许「证书显示覆盖、真实长尾失效」。
