# 第 58 轮（承接第 57 轮「少样本×多模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「物体泛化」×「闭环控制」）

> 第 57 轮把安全赌注从"模型置信"一路换成"证据承诺"，再换成"少样本可校准、跨模态可对账、个性化有界的证据承诺"。但它的风险自陈指出：赌注最终仍押在**元先验对世界的覆盖**上——语料盲区会让 OOD 门识别不了的新模式里长出高度自信的错误后验（"坏先验普遍"）。本轮两个灵感各改一次问法：**物体泛化**把泛化单位从"区域"换成"物体"，用因子化（几何×材质×位姿×支撑×可供性）的组合泛化替代区域记忆，并明确承认"类别先验不是全知"；**闭环控制**不满足于"接触前预测更准"，而把安全改写为"接触后能否纠正"——承诺从静态证据谓词变成一份带收缩证书与恢复时限的**闭环契约**。核心命题由"证据说可信"升级为 **"泛化说像不像，闭环说救不救得回"**。

核心矛盾：
- **H29（泛化 vs 诚实）**：物体级泛化把"见过椅子"变成"敢坐新椅子"，但类别先验越强，"同形异质"的新物体（外观像木凳、实为薄壳塑料）上自信错误的代价越大；诚实地把"没见过的组合"标为未知，又会退化成几乎不泛化。泛化能力与泛化诚实之间的张力无法靠调参消除。
- **H30（闭环 vs 权限）**：闭环可恢复性依赖控制权限（摩擦、支撑反力、执行器余量、同意阈值），而这些权限恰恰在地形最差、最需要恢复时最稀缺。契约证书可能在最危险处给不出，在安全处又过度保守——安全预算的"购买力"随位置变化。
- **H31（自适应 vs 证书）**：闭环辨识能在线修正物体模型、把"泛化误差"变成"已观测"；但自适应会改写被认证的对象本身，认证与学习互相追尾，可能出现"证书在被逐步掏空"的漂移，甚至边学边失守。

## 0. 直觉与动机

**灵感 1（物体泛化 → 从区域记忆到因子化组合泛化）**
直觉：第 57 轮的泛化单位是"区域"——见过这个坡就敢走这个坡。可现实中的风险单位是"物体"：同一把椅子出现在十个区域，或一个从未见过的"箱子"出现在已探明的区域。物体泛化的关键不是记住更多实例，而是把物体拆成可组合的因子：几何 g、材质 m、位姿 p、支撑 s、可供性 a。于是"新物体"常常是"旧因子 × 新组合"——摩擦未知但几何熟悉，或几何陌生但材质可辨认。但组合泛化不是免费的：**越能组合，越可能组合错**（同形异质）。因此泛化必须自带诚实：给出**对象泛化证书 R_gen**，把"像但不确定"与"真的见过"分开，并让 unknown-object 只能走"闭环可恢复"通道，绝不冒充 known。

**灵感 2（闭环控制 → 承诺是契约，不是预言）**
直觉：此前所有轮次都在问"接触前能不能证明安全"，本质是开环预测问题。闭环控制换一个问法：**就算预测错了，我能不能在撞坏之前把它拉回来？** 一把椅子承重未知，先坐三分力、感到下沉就立刻卸力——安全性不由"θ 估得多准"保证，而由"偏差被多快检测、恢复被多快执行"保证。于是承诺 = 一份闭环契约 κ=(π_fb,K,ρ,ℛ,τ_rec,e_max)：存在反馈策略，使模型误差在 e_max 内时轨迹仍收缩、仍留在安全集、且能在 τ_rec 内回到认证安全域。**不可逆接触必须"证据门过 ∧ 契约门过"，二者不可互替。**

**灵感 3（合流 → 泛化-闭环汇率）**
直觉：证据和闭环都在为同一个东西付账——模型误差。证据买"精度"（把 ê_model 压低），闭环买"容错"（把 e_max 抬高）；安全余额是二者之和 Γ=e_max+Δe_ev−ê_model≥0。这条"汇率"给出清晰的经济学：当对象陌生（ê_model 大）时，要么多探针买精度，要么用更软的接触、更短的恢复时限买容错；当控制权限稀缺（e_max 小）时，只能用证据补。关键纪律是**两个通道不可互相伪装**：证据不能声称"我让闭环更强"，闭环不能声称"我让先验更准"；两者只有各自如实入账，汇率才成立。

**灵感 4（有界自适应闭环辨识 → 边接触边缩小未知，但不掏出证书）**
直觉：很多泛化误差不必在接触前解决——第一次轻接触就能测出真实刚度。但"边学边用"是控制里最老的陷阱：自适应会改变被控对象模型，模型又支撑着安全证书。解法是给学习上三道锁：步长有界、参数投影有界（界由契约 e_max 给出）、激励不足/残差跳变/接近安全边界即冻结并重认证；重认证不过就切模型无关的保守回退。学习只能让系统更保守地变聪明，不能让它更冒险地变聪明。

**灵感 5（恢复守卫执行 → 双层控制 + 原子切换）**
直觉：高性能策略负责"走得好看"，保守回退负责"保证不摔"。恢复守卫执行维护两条回路：π_hi 用当前（可能错的）物体模型，π_safe 只用模型无关的保守控制律（如限力、限速、支撑面退让）。安全函数 h 接近阈值就原子切换到 π_safe，并要求切换延迟 τ_det 加恢复时间 τ_rec 不超过预算。要点：**π_safe 绝不复用在线辨识参数**，否则回退只是把同一个错误模型再赌一次。

**灵感 6（证据门与证书升级 → 从"会预测"到"会恢复"）**
直觉：证据门新增两类：EV-contraction（存在通过验证的闭环契约）与 EV-recovery（存在验证过的恢复轨迹/回退策略）；但 EV-recovery 只能用于降档和 L1，**不得替代不可逆接触的必要证据**——能救回来不等于值得去撞。证书 J_c 把对象泛化、契约、汇率、自适应与切换日志一并封存，使"为什么敢碰"与"碰了怎么退"都可审计。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（对象因子化与泛化证书 OGC）** 对象实例 o 的因子表示为 z_o=(g_o,m_o,p_o,s_o,a_o)：几何（尺寸/形状类/曲率）、材质（摩擦/刚度/透明度）、位姿（重力相关/可支撑性）、支撑（承载与连接关系）、可供性签名（可行交互集合及其风险等级）。对类别原语 𝒞_c 定义组合距离
d_comp(z_o,𝒞_c)=min_{z∈𝒞_c}[w_g d_g+w_m d_m+w_p d_p+w_s d_s]。
泛化风险证书 R_gen(o)=α·d_comp(z_o,𝒞_c)+β·H(a_o|z_o,𝒞_c)+γ·ECE_obj(c)∈[0,1]，其中 H 为可供性后验熵，ECE_obj 为对象级先验校准误差。对象 OOD 门 n_obj(o)=−log p̂_ψ(z_o|𝒞_c)。声明：n_obj≤θ_obj ∧ R_gen≤ε_gen 时对象先验才可进入承诺证据；否则登记为 **unknown-object**，只允许"闭环可恢复的 L1 接触"或绕行。类内跨实例证据只更新 a_o 的后验，**永不把 d_comp 直接置零**。

**定义 140（闭环契约 CLC）** 给定对象先验 θ̂ 与状态 x（姿态/速度/接触力），闭环契约是六元组 κ=(π_fb,K,ρ,ℛ,τ_rec,e_max)：反馈策略、收缩度量、标称收缩率、认证安全域、恢复时限、认证可容忍模型误差。契约成立 ⟺ 对 ∀Δ∈𝒟_e={‖Δ‖≤e_max}，沿闭环 ẋ=f(x,π_fb(x);θ̂+Δ) 满足
(a) **收缩性**：d/dt‖x−x*‖_K ≤ −ρ‖x−x*‖_K+σ(e_max)，σ 单调且 σ(0)=0；
(b) **前向不变**：V(x)≤V̄ ⇒ x∈S_safe，且存在恢复控制使 τ_rec 内回到 ℛ；
(c) **时限**：τ_sw+τ_rec≤τ_budget。
承诺可采纳规则：不可逆接触必须 **证据门过 ∧ 契约门在 e_max≥ê_model−Γ_ev 上成立**；两者不可互替。

**定义 141（泛化-闭环汇率 GCL）** 模型误差有两条来源：泛化残差 ê_model 与闭环可吸收上界 e_max(π_fb)。认证余量
Γ(o,π_fb)=e_max(π_fb)+Δe_ev(evidence)−ê_model(o)，
其中 Δe_ev 是证据使误差上界收缩的量。承诺 iff Γ≥0。汇率映射 Ξ:(Δe_ev,e_max)→Γ 满足 ∂Γ/∂Δe_ev≥0、∂Γ/∂e_max≥0，且**两通道不可互相伪装**：证据只能经"缩小 ê_model"入账，闭环只能经"增大可容忍误差"入账；二者是相加的充分条件，不是"取最大"。直觉：证据买精度、闭环买容错，安全余额是两者之和；但两者都不能凭空印钞。

**定义 142（有界自适应闭环辨识 BAC）** 自适应律 θ̂_{t+1}=Proj_Θ(θ̂_t+η_t φ(x_t,e_t))，η_t≤η_max；投影集 Θ 紧且由契约 e_max 定界；仅当持续激励（信息矩阵 λ_min≥θ_pe）时允许更新。自适应期间安全由鲁棒 CBF 约束
ḣ(x,u)≥−α(h(x))−‖∂h/∂x‖·e_max。
冻结规则：残差跳变>θ_r、λ_min<θ_pe、或 h<θ_b 时冻结，当前 θ̂ 送重认证；重认证未过即切 π_safe。

**定义 143（恢复守卫执行 RGE / simplex）** 双层控制 π_hi（高性能）与 π_safe（模型无关保守回退）。切换函数 s(x)=1[h(x)≤θ_sw ∨ V(x)>V̄]。要求：(a) 检测延迟≤τ_det；(b) 切换原子性，切换后 π_safe 在 τ_rec 内把 x 带入 ℛ；(c) **π_safe 不使用在线辨识参数**。RGE 的可证安全不依赖 π_hi 的模型精度，只依赖 π_safe 的保守性与 h 的 Lipschitz 下界。

**定义 144（闭环证据门 CSE 与证书 J_c）** 证据类由五类扩为七类：EV-probe\*（须附 OGC 泛化证书）、EV-visit、EV-margin、EV-xmodal（限 L1）、EV-human、**EV-contraction**（存在已验证且 Γ≥0 的 κ）、**EV-recovery**（存在已验证恢复轨迹/回退策略）。不可逆接触必要证据集={EV-probe\*∨EV-margin∨EV-contraction}∪佐证；EV-recovery 只可降低接触等级或在 L1/L2 触发降档，**不得替代**不可逆接触的必要证据。J_c=(M_core,C_core,K_margin,ρ_sem,δ_s,probe_log,consent_log,evidence,meta_cal_log,xmodal_log,auth_log,ood_reg,obj_reg,κ,K_contract,τ_rec_log,adapt_log,switch_log)，继承 J_p 全检。

## 2. 关键算法伪代码（完整版见产物区）

```python
def object_generalize(M, o):                        # IP-139 OGC
    z = factorize(o)                                # g,m,p,s,a
    c = nearest_class(z, M.classes)
    n_obj = -log p_psi(z, c)
    R = alpha*d_comp(z, M.classes[c]) + beta*entropy(a_post(z)) + gamma*ece_obj(c)
    if n_obj > theta_obj or R > eps_gen:
        M.obj_reg.register(o, 'unknown'); return Inf(cls='UNKNOWN', z=z, R=R)
    return Inf(cls='KNOWN', prior=M.classes[c], R=R)

def closed_loop_contract(M, o, inf):                # IP-140/141 CLC×GCL
    e_model = model_error_bound(inf)
    for fb in candidate_feedback(M, o):
        e_max = authority_bound(fb)                 # 摩擦/支撑/执行器/同意
        K, rho, R_roa, tau_rec = certify_contraction(fb, e_model, e_max)
        Gamma = e_max + evidence_shrink(inf) - e_model
        if Gamma >= 0 and tau_sw + tau_rec <= tau_budget:
            return Contract(fb, K, rho, R_roa, tau_rec, e_max, Gamma)
    return None                                     # 无契约 → 禁不可逆接触

def bounded_adaptive_identify(theta, x, e, contract, cbf):   # IP-142 BAC
    if not persistently_exciting(x, e) or residual_jump(e) > theta_r \
       or cbf.h(x) < theta_b:
        freeze(theta); return theta, 'frozen'
    theta = project(theta + eta * phi(x, e), Theta(contract.e_max))
    if not re_certify(theta, contract):
        return theta, 're_certify_fail'             # → 切 pi_safe
    return theta, 'ok'

def recovery_guarded_exec(x, u_hi, contract, cbf): # IP-143 RGE
    if cbf.h(x) <= theta_sw or contract.V(x) > Vbar:
        return pi_safe(x), 'recover'                # 原子切换 ≤ tau_det
    return u_hi, 'nominal'
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| OGC | O(\|𝒞\|·d_z)/对象 | O(\|𝒞\|·d_z) | 组合距离诚实、unknown 不冒充 known |
| CLC | O(n·d_x+certify)/对象 | O(d_x²) | 收缩在 𝒟_e 上一致成立 |
| GCL | O(1) | O(1) | 两通道单调、不可互掩 |
| BAC | O(d_θ)/步 | O(d_θ) | 投影有界、冻结完备、重认证原子 |
| RGE | O(1)+O(τ_rec/Δt) | O(1) | 切换原子、π_safe 模型无关 |
| CSE | O(\|σ\|) | O(\|σ\|) | 无契约即拒、EV-recovery 不越级 |

**正确性定理（GCCS 概要）**：在 A22–A40 上加 (A41) 泛化证书诚实（R_gen 上界成立、unknown 不冒充、OOD 漏检≤δ_obj）；(A42) 闭环契约在 𝒟_e 上一致成立，且 e_max 由独立证伪数据下界估计、不得自引；(A43) 有界自适应（投影有界、η≤η_max、冻结与重认证原子）；(A44) 恢复守卫（τ_det 可证、π_safe 模型无关、τ_sw+τ_rec≤τ_budget）。则：(i) 承诺失败率 ≤P(Δ∉𝒟_e)+P(τ_det 失效)+P(切换失败)+δ_fb；(ii) 汇率单调且不可伪造：证据与权限各自入账，不存在"用乐观 e_max 补偿证据缺口"而不改 𝒟_e 的路径；(iii) BAC 在鲁棒 CBF 下保持 S_safe 前向不变，重认证失败即回退；(iv) RGE 在 τ_det+τ_rec 内要么进入 ℛ、要么安全停，PCE++ 检查点四态完备。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 自证式收缩：证书对错模型自洽 | 高 | e_max 由独立证伪数据下界；π_safe 模型无关；证书到期重认证 |
| unknown-object 被类别先验冒充 | 高 | 对象 OOD 门 + R_gen 硬阈值 + unknown 只走可恢复 L1 |
| 自适应掏空证书 | 高 | 步长/投影有界 + 冻结规则 + 重认证原子绑定 |
| 契约在最危险处无解 → 任务不可用 | 中 | 汇率显式化：补证据或降档；给出"拒绝"作为一等结果 |
| 切换延迟进入执行回路 | 中 | 硬件级 watchdog + τ_det 实测 + 限速限力兜底 |

## 6. 本轮最大风险

**一句话**：本轮把安全赌注从"证据质量"移到"闭环可恢复性"，风险也随之前移为**自证式收缩**——收缩证书是对模型写的，若模型本身系统性失真（新物体），证书依然可解，但它保证的只是"在这个假模型里能恢复"，而回退控制器若复用同一模型，恢复性就成了循环论证；再叠加在线自适应不断改写被认证对象，可能出现"证书被逐步掏空"的漂移。必须以独立证伪数据下界 𝒟_e、模型无关的 π_safe、自适应与重认证的原子绑定、以及证书到期制四道护栏，宁可在没有诚实契约时拒绝接触，也不接受"在错误世界里证明自己安全"。

## 2. 关键算法伪代码

### IP-139 OGC（对象因子化与泛化证书）

```python
def object_generalize(M, o, meta):
    z = factorize(o)                                  # g, m, p, s, a
    c = nearest_class(z, M.classes)
    n_obj = -log p_psi(z, c)                          # 对象 OOD 门
    R = alpha * d_comp(z, M.classes[c]) \
        + beta * entropy(a_posterior(z, M.classes[c])) \
        + gamma * ece_obj(c)
    if n_obj > theta_obj or R > eps_gen:
        M.obj_reg.register(o, cls='unknown', z=z, R=R)
        return Inf(cls='UNKNOWN', z=z, R=R)           # 只可走可恢复 L1
    # 类内证据只更新 affordance 后验，不把 d_comp 置零
    a_post = update_affordance(M.classes[c].a, z)
    return Inf(cls='KNOWN', z=z, prior=M.classes[c], a_post=a_post, R=R,
               ece_obj=ece_obj(c))
```

### IP-140/141 CLC × GCL（闭环契约与泛化-闭环汇率）

```python
def closed_loop_contract(M, o, inf, budget):
    e_model = model_error_bound(inf)                  # 由 R_gen/共形带给出
    d_ev = evidence_shrink(inf)                       # 证据收缩量（留出集估计）
    for fb in candidate_feedback(M, o):
        e_max = authority_bound(fb)                   # 摩擦/支撑/执行器/同意
        cert = certify_contraction(fb, e_model, e_max)
        if cert is None:
            continue
        K, rho, R_roa, tau_rec, sigma = cert
        Gamma = e_max + d_ev - e_model                # GCL 安全余额
        if Gamma >= 0 and tau_sw + tau_rec <= tau_budget:
            return Contract(fb=fb, K=K, rho=rho, R_roa=R_roa,
                            tau_rec=tau_rec, e_max=e_max, Gamma=Gamma,
                            D_e=ball(e_max))
    return None                                       # 无契约 → 禁不可逆接触

def certify_contraction(fb, e_model, e_max):
    # 在 D_e 上数值/解析求收缩度量与不变域；失败返回 None
    K = solve_contraction_metric(fb, e_max)
    if K is None: return None
    rho, sigma = contraction_rate(fb, K, e_max)
    R_roa, Vbar = invariant_region(fb, K, rho, sigma)
    tau_rec = recovery_time(fb, K, rho, sigma)
    if rho <= 0 or tau_rec > tau_budget: return None
    return K, rho, R_roa, tau_rec, sigma
```

### IP-142 BAC（有界自适应闭环辨识）

```python
def bounded_adaptive_identify(theta, x, e, contract, cbf, adapt):
    if information_matrix(x, e).lam_min < theta_pe \
       or residual_jump(e) > theta_r \
       or cbf.h(x) < theta_b:
        adapt.freeze(theta)                           # 冻结并保留旧证书
        return theta, 'frozen'
    eta = min(adapt.eta_max, adapt.schedule(x, e))
    theta_new = project(theta + eta * phi(x, e), Theta(contract.e_max))
    # 自适应期间鲁棒 CBF：hdot >= -alpha(h) - ||dh/dx|| * e_max
    if not robust_cbf_ok(x, theta_new, cbf, contract.e_max):
        adapt.freeze(theta); return theta, 'cbf_blocked'
    if not re_certify(theta_new, contract):           # 重认证原子绑定
        return theta_new, 're_certify_fail'           # 调用方切 pi_safe
    return theta_new, 'ok'
```

### IP-143 RGE（恢复守卫执行）

```python
def recovery_guarded_exec(x, u_hi, contract, cbf, budget):
    if cbf.h(x) <= theta_sw or contract.V(x) > contract.Vbar:
        u = pi_safe(x)                                # 模型无关，不用 theta_hat
        return u, 'recover'                           # 原子切换，<= tau_det
    return u_hi, 'nominal'

def pi_safe(x):
    # 保守限定：限力/限速/支撑面退让/主动泄压，不依赖在线辨识参数
    return conservative_control(x, force_cap=F_abs, speed_cap=v_safe)
```

### IP-144 CSE（闭环证据门 + 证书 J_c）

```python
def closed_loop_evidence_gate(c, M, persona, ood_reg, obj_reg):
    if c.ev == 'EV-probe*':
        ok = (c.inf.cls == 'KNOWN' and c.inf.R <= eps_gen
              and c.inf.ece_k <= eps_meta(c.k)) or \
             (c.inf.cls == 'OOD' and c.region in ood_reg.certified)
    elif c.ev == 'EV-contraction':
        ok = c.contract is not None and c.contract.Gamma >= 0
    elif c.ev == 'EV-recovery':
        ok = c.recovery_verified and c.level != 'L2'  # 只降档，不越级
    elif c.ev == 'EV-xmodal':
        ok = c.level == 'L1' and c.indep_declared and D(c.region) <= theta_D
    elif c.ev == 'EV-human':
        ok = persona[c.op].auth >= 'A1' and \
             c.corrob >= quarantine_exit(persona[c.op].auth)
    elif c.ev in ('EV-visit', 'EV-margin'):
        ok = round56_checks(c, M)
    else:
        return ('reject', 'no_evidence_class', c)

    if not ok:
        return ('reject', 'evidence_insufficient', c)
    if c.irreversible:
        # 不可逆接触必须证据门 ∧ 契约门，EV-recovery 不得替代
        if c.ev == 'EV-xmodal':
            return ('reject', 'xmodal_on_irreversible', c)
        if c.contract is None or c.contract.Gamma < 0:
            return ('reject', 'no_closed_loop_contract', c)
    return ('ok', c)

def closed_loop_certificate(sched, log, M, consent_log, auth_log,
                            ood_reg, obj_reg, adapt_log, switch_log):
    for c in contacts(sched):
        st = closed_loop_evidence_gate(c, M, persona_of(c), ood_reg, obj_reg)
        if st[0] != 'ok': return st
    if min(x.K_margin for x in sched) < budgets.theta_K: return ('reject', 'K_margin')
    if rho_sem(sched, M) < budgets.rho_min:             return ('reject', 'rho_sem')
    if semantic_perturbation(M.core) > budgets.Theta_s: return ('reject', 'delta_s')
    if not all(l2.resolved for l2 in consent_log):      return ('reject', 'consent_open')
    if any(x.contract is None for x in irreversible(sched)):
        return ('reject', 'missing_contract')
    return ('ok', Jc(M.core, core_contacts(sched), K_margin, rho_sem,
                     probe_log, consent_log, meta_cal_log, xmodal_log,
                     auth_log, ood_reg, obj_reg, contracts, tau_rec_log,
                     adapt_log, switch_log))
```

### IP-138→PCE++（探-诺-演++：契约门与恢复守卫接入主循环）

```python
def probe_commit_evolve_plusplus(x0, M, task, budget, consent, personas):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        inf = meta_few_shot_infer(M, cp.region, M.obs[cp.region], meta)
        obj = object_generalize(M, cp.object, meta)        # IP-139
        M.b[cp.region] = inf.post if inf.cls == 'ID' else worst_in(inf.belt)
        sigma = foothold_schedule(x0, cp, M); R = schedule_risk(sigma, M)

        while select_gait(R) == 'halt' and budget.probes_left > 0:
            cands = admissible_probes(cp, M, F_abs)
            if not cands: break
            p = argmax(cands, key=lambda q: voi_meta_pessimistic(q, M, inf) - cost(q))
            if voi_meta_pessimistic(p, M, inf) < theta_voi: break
            M, _, D = xmodal_fuse(M, cp.region, execute_probe(p, cap=F_abs))
            if D > theta_D and 'consensus' not in cp.done:
                p2 = most_disagreeing_modality_probe(M, cp.region)
                M, _, D = xmodal_fuse(M, cp.region, execute_probe(p2, cap=F_abs))
                cp.done.add('consensus')
            sigma = reselect_footholds(x0, cp, M); R = schedule_risk(sigma, M)
            budget.spend(p)

        g = select_gait(R)
        lv = contact_level(cp)                             # L0/L1/L2
        contract = closed_loop_contract(M, cp.object, obj) # IP-140/141
        ev = tag_evidence_p(sigma, M, lv, obj, contract)

        if g != 'halt' and closed_loop_evidence_gate(
                core_contact(cp, contract), M, personas, ood_reg, obj_reg)[0] == 'ok':
            sched.append(commit(sigma, g)); log.append(ev); continue

        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, M)) != 'halt': route = alt; continue
        return negotiate_or_stop(cp, M, sigma, R, consent,
                                 tau_int=tau_int(personas.active.auth))

    # 执行期：恢复守卫 + 有界自适应
    def runtime_step(x, u_hi):
        u, st = recovery_guarded_exec(x, u_hi, contract_of(x), cbf, budget)
        if st == 'recover': adapt.freeze()
        return u, st
    return sched, log, M, runtime_step
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| OGC | O(\|𝒞\|·d_z)/对象 | O(\|𝒞\|·d_z) | 组合距离诚实、unknown 不冒充 known（A41） |
| CLC | O(n·d_x+certify)/对象 | O(d_x²) | 收缩在 𝒟_e 上一致成立（A42） |
| GCL | O(1) | O(1) | 两通道单调且不可互掩（A42） |
| BAC | O(d_θ)/步 | O(d_θ) | 投影有界、冻结完备、重认证原子（A43） |
| RGE | O(1)+O(τ_rec/Δt) | O(1) | 切换原子、π_safe 模型无关（A44） |
| CSE | O(\|σ\|) | O(\|σ\|) | 无契约即拒、EV-recovery 不越级 |
| PCE++ | O(\|CP\|·(k_p+k_c)·(C_VOI+d_φ+d_z)+certify) | O(\|V\|+\|σ\|) | 契约门∧证据门、四态完备 |

**正确性定理（Generalization–Contraction Closed-loop Soundness, GCCS）**
假设 A22–A32（第 53–55 轮）、A33–A36（第 56 轮）、A37–A40（第 57 轮）成立；**(A41)** 泛化证书诚实：R_gen 是真实泛化风险上界、unknown 不冒充 known、对象 OOD 漏检率 ≤δ_obj；**(A42)** 闭环契约与汇率：对 ∀Δ∈𝒟_e 契约一致成立，e_max 由**独立证伪数据**下界估计（不得由同一模型自引），Δe_ev 由留出探针共形估计；**(A43)** 有界自适应：投影有界、η≤η_max、冻结与重认证原子绑定；**(A44)** 恢复守卫：τ_det 可证、π_safe 模型无关、τ_sw+τ_rec≤τ_budget。则：

1. **契约承诺健全性**：对每个检查点，若证据门与契约门均通过，则
   P(不可恢复失败) ≤ P(Δ∉𝒟_e)+P(τ_det 失效)+P(切换失败)+δ_fb+δ_probe+ε_h。
   若对象为 unknown，则只允许 L1，失败率上界再加 δ_gen，但不可进入不可逆接触。
2. **泛化-闭环汇率单调性与不可伪造性**：Γ 对 Δe_ev 与 e_max 均单调不减；且不存在仅靠"乐观地声明 e_max"而不改变 𝒟_e 的独立证据，就能补偿证据缺口的路径（否则违反 A42）。
3. **自适应安全**：在 A43 与鲁棒 CBF 下，BAC 保持 S_safe 前向不变；重认证失败即冻结并切 π_safe，不存在"边学边失守"的合法轨迹。
4. **恢复与终止**：RGE 在 τ_det+τ_rec 内要么把状态带入 ℛ，要么安全停；PCE++ 在 k_probes+k_cons 内终止于 {承诺, 绕行, L2 协商, 安全停}。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp [ P(Δ∉𝒟_e) + δ_fb + δ_probe + ε_h + δ_obj·1[KNOWN]
                    + P(τ_det 失效) + P(切换失败) + P(重认证漏检) ]
             − P(𝓜 陈旧未检出) − P(护盾回退失败) − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
```

关键：**元先验给效率、共形给保底、闭环给容错**——三者解耦，任意一层的失败不再单独决定结局；**EV-recovery 只能降档，不能替代不可逆接触的必要证据**（能救回≠值得撞）；**π_safe 模型无关**切断"回退复用同一错误模型"的循环论证；**契约有到期时间**，自适应每次改写对象都必须重认证。

## 6. 本轮最大风险

**一句话**：本轮把安全赌注从"证据质量"移到"闭环可恢复性"，风险也随之前移为**自证式收缩**——收缩证书是对模型写的，若模型系统性失真（新物体），证书依然可解，但它保证的只是"在这个假模型里能恢复"，而回退控制器若复用同一模型，恢复性就是循环论证；再叠加在线自适应不断改写被认证对象，可能出现"证书被逐步掏空"的漂移。必须以独立证伪数据下界 𝒟_e、模型无关的 π_safe、自适应与重认证的原子绑定、以及证书到期制四道护栏，宁可在没有诚实契约时拒绝接触，也不接受"在错误世界里证明自己安全"。
