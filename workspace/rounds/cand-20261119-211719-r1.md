# 第 14 轮（新灵感循环第 5 轮；本轮灵感：「ROS」×「多模态融合」）

> **基线**：第 13 轮 MetricVoiceGauge-NCD-HUTDH v15（SCD/DSD/DCA/EDC，IP-378–401，定义 607–626，引理 125–130，实验 E661–E670）。
> 本轮纪律：**时基即证书前提 + 缺席即最保守 + 节点只交不许并**。不推倒 v15：v15 的技能扩散与数据集证书、v14 的 HDT/HBR/HATD/NCP、v13 的 AIO/RTIC/CPD/DGC/DDL/RTCR、v12 的 USG/TGC/BAA/GAGP/UC、v11 及更早的九不变式与全部退化链均保留。四个新组件——CTS（时基切片证书）、QGA（QoS 保证准入）、MCF（模态证书融合，含 MGC）、DCC（分布式证书共识）——一律以**中立元**接入；任一失效即严格退回 v15，再沿 v15→v14→…→v6 退化。本轮只做三件事：把"多模态融合"从特征/决策平均改写为**同一可证时空切片上的证书融合**、把"模态缺失/迟到"从插补改写为**未校准子集一律禁用**、把"分布式 ROS 节点"从权限合并改写为**证书取交**。

## 0. 直觉与动机

**灵感 1（ROS → 时基与 QoS 是证书的前提，不是工程细节）**
直觉：v15 的所有证书都默认拿到一个"同步的 obs 快照"。但 ROS 2 图里没有快照，只有带时间戳、各走各的 QoS、各经各的延迟的消息流：`message_filters` 的近似同步允许 slop，tf2 在缺帧时外推，best-effort 主题会静默丢包，rosbag 循环会让 `/clock` 倒退。于是最危险的错误不是"某个模态看错了"，而是**两个模态从未在同一时刻共存**——新鲜触觉与陈旧视觉可以合成一个物理上从未存在的接触状态（时基嵌合体，temporal chimera）。这种融合在每条单模态证书下都"有证"，在联合状态上却根本没有支撑。核心创新：**时基切片证书（Certified Time Slice, CTS）+ QoS 保证准入（QoS Guarantee Admission, QGA）**。CTS 要求所有参与联合证书的模态共享一个同时落在新鲜窗口内的公共时间切片 `I*`，并把 tf2 外推视为证书作废；QGA 把 ROS QoS 剖面翻译成"哪些模态是保证到达的"。关键反直觉点：**模态迟到/丢失时，正确动作不是插补或平滑，而是把它从联合证书中删除并退回一个已校准的更小子集；若该子集未校准，则直接安全回退，绝不做临时交集拼凑**。

**灵感 2（多模态融合 → 一致性是唯一能购买额外授权的货币）**
直觉：注意力/拼接式融合在平均精度上几乎总是更好，但它在薄边界上会制造**过度自信**：当多个模态的误差相关时，联合置信度会远高于真实可靠性——四个都看错的模态可以"一致地"把一个不安全动作说成安全。普通共形校准只保证单模态边际覆盖，联合分布上的保证不能由边际拼接得到。核心创新：**模态证书融合（Modality-Certificate Fusion, MCF）+ 模态间隙证书（Modality Gap Certificate, MGC）**。融合只在两种模式之一下工作：(i) **交集模式**——动作必须被所有在场模态各自认证；(ii) **一致性增益模式**——只有当在场模态子集 `S` 有**联合共形校准**、且子集族满足单调嵌套 `S'⊆S ⇒ Acc^{S'}⊆Acc^{S}` 时，才允许用联合分数购买比交集更大的授权。增益不是免费的：它是用联合校准数据买的，且被 MGC 的乐观上界 `U_MGC` 约束；子集不在校准族内时增益为空，直接回退。于是**"融合变强"与"融合可证"被显式解耦**：不能把平均精度的提升自动兑换成安全授权。

**灵感 3（ROS×多模态 → 分布式只取交，不取并）**
直觉：真实机器人不是单进程，而是感知、规划、安全监控、驱动等多个 ROS 节点各自持有一部分证据与证书。工程上最容易犯的错是"融合多个节点的判断以提升覆盖率"——把两个各自 80% 安全的节点合并成"更聪明"的联合决策。但在证书语义下，节点合并只能取**交集**：执行器门接受的动作必须被每个在场且证书新鲜的节点认证；任一节点（哪怕被攻陷或错误校准）都不能单方面扩张授权。核心创新：**分布式证书共识（Distributed Certificate Consensus, DCC）**。它不是拜占庭共识的替代品，而是把"授权"与"活性"分开：授权取交（绝不变大），活性靠 quorum（不够就 `a_ask`/安全停）。时钟跳变（系统/仿真时间切换、bag 循环）使所有旧 epoch 证书作废，必须先建立新的 clock epoch 再谈融合。

**三者如何统一**
统一为 **v15 语义之上的证据层**：v15 回答"在给定时限内哪个技能档可执行"（`Exec_v15`），v16 回答"这些技能所依赖的多模态证据，是否来自同一可证时空切片、由哪些保证在线的节点共同作证"（`Exec_v16`）。CTS 给时间前提，QGA 给在场前提，MCF/MGC 给融合前提，DCC 给分布式前提。共享状态 `ζ_mm = (I*, M_cert, S_g, Acc_fuse^{S}, U_MGC, quorum, clock_epoch, mode)`。四者都不新增授权：CTS 只删模态，QGA 只减在场集，MCF 只在校准子集上给可证增益，DCC 只取交；`Exec_v16 ⊆ Exec_v15` 由引理 137 保证。

## 1. 研究问题（轮次升级版）

- **Q1（时基的可证语义）**：如何定义公共时间切片与新鲜度，才使"联合证书"继承各模态的覆盖保证？tf2 外推、传输抖动、不同传感器时钟、系统/仿真时间切换与 rosbag 循环，分别应映射为"删模态"还是"作废整个 epoch"？`Δ_max` 与 `Δ_fresh` 如何与 v15 的 p99≤22ms 预算联立？
- **Q2（融合增益的可证边界）**：联合共形分数如何在模态相关、边界样本稀缺、模态子集组合爆炸下仍可校准？子集族单调嵌套在有限校准集上如何检验并保持？MGC 能否给出"联合比最宽单模态乐观多少"的单侧上界？当误差高度相关时，`U_MGC` 是否必然膨胀到禁用增益？
- **Q3（QoS 与分布式的活性）**：如何把 ROS QoS（reliability/durability/deadline/liveliness/history）映射为保证到达集 `S_g`，并证明不确定集的最坏情形就是 `S_g`？DCC 的 quorum 如何在"授权取交"下不饿死活性？crash-fault 与 Byzantine 的边界在哪里，签名/冗余何时必要？
- **Q4（与 v15 的兼容与退化）**：未校准子集的回退频率是否会导致频繁 `a_ask` 与任务完成率塌缩？DCC 的交集是否常常为空？所有新模块失效时能否精确退回 v15，且守住 50Hz/p99≤22ms 与 `Exec_v16⊆Exec_v15`？

## 2. 设计原则（在 P22–P24 基础上新增 P25–P27）

**P25 时基即证书前提律（Time-Base as Certificate Precondition）**
任何联合证书必须绑定一个公共时间切片 `I* = (⋂ I_m) ∩ [t_now−Δ_fresh, t_now]`。若 `I*` 为空、宽度超过 `Δ_max`、或任一模态依赖 tf2 外推，则该模态不得进入联合证书。时钟 epoch 改变（跳变、仿真时间切换、bag 回退）时，所有旧证书一律作废，不得跨 epoch 拼接时间戳。

**P26 缺席即最保守律（Absence Is Conservative, Never Impute）**
模态缺失/迟到/丢包时，禁止插补、平滑或临时构造交集来"补位"。在场子集 `S` 必须属于已联合校准且通过单调嵌套检查的族 `𝒮_cal`；否则融合结果为空集，只能执行 v15 的认证回退或 `a_ask`。删除模态只能取消一致性增益并退回更小或空集，绝不允许因缺席而扩张授权。

**P27 节点只交不许并律（Nodes May Intersect, Never Union）**
分布式执行器门对每个在场且证书新鲜的节点授权集取交集：`Acc_cons = ⋂_{n∈Q} Acc_n`。任一节点不能单方面扩张授权，也不得用"多节点投票/并集"替代交集。活性由 quorum 独立管理；quorum 不足或证书过期时只能安全回退，不能放宽交集。

## 3. 与基线的接口（如何退化）

- CTS 失效 ⇒ 所有模态视为共享同一时基，去掉切片门与 epoch 检查，**等价 v15 的同步 obs 假设**；
- QGA 失效 ⇒ 所有主题视为保证到达：`S_g = S_u`，只保留 MCF 的交集/联合校准模式，**等价"无 QoS 假设的 v15 + 融合"**；
- MCF 失效 ⇒ 无联合增益：`Acc^{S}=⋂_{m∈S}Acc_m`，仅交集模式，**等价 v15 的多传感器逐项校验**；
- MGC 失效 ⇒ `U_MGC≡0`，无法禁用过度乐观增益，强制退回交集模式，**等价纯交集融合**；
- DCC 失效 ⇒ 单节点证书直接作为 v15 输入，**等价 v15 单进程路径**；
- 全部失效 ⇒ MetricVoiceGauge-NCD-HUTDH v15，再沿 v15→v14→…→v6 退化链退回；
- **安全继承**：CTS 只删不可证模态，QGA 只缩小在场集，MCF 的每种模式都再与 `Exec_v15` 取交，DCC 只取交。四端口都不能新增授权或放宽阈值；`Exec_v16⊆Exec_v15` 由引理 137 保证。

## 4. 预期贡献

1. **时基切片证书**：把"多模态融合"从"对齐特征"改写为"先证同一时刻共存，再谈联合"，消除时基嵌合体这一类在单模态证书下完全隐形的假安全；
2. **QoS 不确定性的最坏情形约简**：证明在单调证书族下，QoS 不确定集上的授权交集恰好等于"只保留保证到达模态"的授权，使 ROS 工程参数第一次直接进入证书语义；
3. **一致性增益证书**：把融合增益做成必须用联合校准数据购买、受 MGC 约束、且子集单调嵌套的可证对象，填补"融合在安全关键系统里不可证"的空白；
4. **分布式只交不并**：把多节点 ROS 的授权问题与活性问题解耦，给出 crash-fault 下的交集安全界与 quorum 活性界；E671–E680 覆盖时基、QoS、子集嵌套、分布式故障、clock 跳变、端到端与消融。

## 5. 本轮最大风险

**一句话**：CTS/QGA/MCF/DCC 都只在"各自前提成立"的层面上取证，而在真实 ROS 图里，时间戳可能被驱动伪造、QoS 统计可能被短窗口掩盖、模态误差可能在分布漂移下高度相关；当这些前提同时"看起来成立"时，联合共形会在一个从未被联合校准覆盖的边界上给出过宽的 `U_MGC`，最终在"时间一致、QoS 保证、每模态有证、联合覆盖达标"的表象下执行了一个所有模态共同错判的动作——即**时基自洽、模态共识、却绝对错误的安全决定**。

# IP-402 Certified Time Slice：先证共存，再谈融合
class CertifiedTimeSlice:
    def __init__(self, delta_fresh, delta_max):
        self.delta_fresh = delta_fresh
        self.delta_max = delta_max

    def slice(self, perceptions, t_now, epoch):
        # perceptions: {modality: Percept(interval, extrapolated, epoch, covered)}
        M_cert = set()
        for m, p in perceptions.items():
            if p.extrapolated:          # tf2 外推 -> 无联合证书
                continue
            if p.epoch != epoch:        # 跨时钟世代不可比较
                continue
            if p.interval[1] < t_now - self.delta_fresh:
                continue                # 过期
            if not p.covered:           # v15 DCA/EDC 判定的支撑外
                continue
            M_cert.add(m)

        I = (t_now - self.delta_fresh, t_now)
        for m in M_cert:
            I = self._intersect(I, perceptions[m].interval)
            if I is None:
                break
        if I is None or (I[1] - I[0]) > self.delta_max:
            return SliceResult(M_cert=M_cert, I=None, joint_ok=False)
        return SliceResult(M_cert=M_cert, I=I, joint_ok=True)

    def _intersect(self, a, b):
        lo, hi = max(a[0], b[0]), min(a[1], b[1])
        return (lo, hi) if lo <= hi else None


# IP-403 QoS Guarantee Admission：把 QoS 剖面翻译成"保证在场"
class QoSGuaranteeAdmission:
    def __init__(self, window=1.0, loss_tol=0.0, latency_margin=1.2):
        self.window = window
        self.loss_tol = loss_tol
        self.latency_margin = latency_margin

    def guaranteed(self, topics):
        Sg = set()
        for t in topics:
            q = t.qos
            # 只有 RELIABLE + deadline + liveliness 才有资格进入保证集
            if q.reliability != "RELIABLE":
                continue
            if q.deadline is None or q.liveliness is None:
                continue
            if q.history == "KEEP_LAST" and q.depth <= 0:
                continue
            if t.stats.loss(self.window) > self.loss_tol:
                continue
            if t.stats.latency_p99(self.window) > self.latency_margin * q.deadline:
                continue
            Sg.add(t.modality)
        return Sg

    def uncertainty(self, topics):
        return set(t.modality for t in topics)   # S_u


# IP-404 Modality-Certificate Fusion：交集 / 一致性增益双模式
class ModalityCertificateFusion:
    def __init__(self, cal_family, single_certs, exec_v15, umgc_max):
        self.cal = cal_family              # S -> JointConformal(score, q_S, candidates)
        self.single = single_certs         # m -> v15 单模态证书 (Acc_m, q_m)
        self.exec_v15 = exec_v15           # v15 语义授权集
        self.umgc_max = umgc_max

    def fuse(self, x, M_cert, S_g, joint_ok):
        S = frozenset(M_cert & S_g)
        # 未校准子集 / 时基不成立：禁用融合，返回空集 -> v15 回退或 a_ask
        if (not joint_ok) or (S not in self.cal):
            return FuseResult(acc=frozenset(), mode="fallback", U_MGC=0.0, S=S)

        joint = self.cal[S]
        acc = set()
        for a in joint.candidates(x):
            if joint.score(x, a) <= joint.q_S:
                acc.add(a)
        acc &= self.exec_v15              # 语义层始终由 v15 把关
        umgc = max(0.0, joint.q_S - max(self.single[m].q for m in S))

        if umgc > self.umgc_max:          # 增益过乐观：退回交集
            return FuseResult(
                acc=self._intersection(M_cert, x), mode="intersection", U_MGC=umgc, S=S)
        return FuseResult(acc=frozenset(acc), mode="joint", U_MGC=umgc, S=S)

    def _intersection(self, M_cert, x):
        sets = [self.single[m].acc(x) for m in M_cert if m in self.single]
        return frozenset.intersection(*sets) & self.exec_v15 if sets else frozenset()


# IP-406 Subset Nesting Gate：部署期一次性校验，不满足即删子集
class SubsetNestingGate:
    def __init__(self, cal_family, samples):
        self.cal = cal_family
        self.samples = samples             # 覆盖边界的代表性样本

    def validate(self):
        calibrated = sorted(self.cal.keys(), key=len)
        removed = set()
        for i, S in enumerate(calibrated):
            for Sp in calibrated[:i]:
                if Sp < S:                 # Sp 是 S 的真子集
                    for x in self.samples:
                        if not (self.cal[Sp].acc_set(x) <= self.cal[S].acc_set(x)):
                            removed.add(Sp)
                            break
        for Sp in removed:
            self.cal.pop(Sp, None)         # 删除后该子集映射为空集
        return self.cal


# IP-407 Distributed Certificate Consensus：授权取交，活性靠 quorum
class DistributedCertificateConsensus:
    def __init__(self, quorum, delta_fresh):
        self.quorum = quorum
        self.delta_fresh = delta_fresh

    def gate(self, node_certs, t_now, epoch):
        fresh = [
            c for c in node_certs
            if c.epoch == epoch
            and abs(c.t - t_now) <= self.delta_fresh
            and self._verify(c)
        ]
        if len(fresh) < self.quorum:
            return ConsensusResult(acc=frozenset(), alive=False)
        acc = frozenset.intersection(*[c.Acc for c in fresh])
        return ConsensusResult(acc=acc, alive=True)

    def _verify(self, c):
        return c.verify_signature()          # crash-fault 下防伪造；Byzantine 需额外冗余


# IP-408 Clock-Epoch Guard：跳变/bag 循环即换代
class ClockEpochGuard:
    def __init__(self, delta_jump):
        self.delta_jump = delta_jump
        self.epoch = 0
        self.last_t = None

    def check(self, t_now, ros_clock):
        jumped = ros_clock.jumped() or (
            self.last_t is not None and t_now < self.last_t - self.delta_jump)
        if jumped:
            self.epoch += 1
        self.last_t = t_now
        return self.epoch


# 主闭环集成：MetricVoiceGauge-NCD-HUTDH-ROS v16
def metricvoicegauge_round_16_ros_multimodal(
        M, s, obs, perceptions=None, topics=None, node_certs=None, ...):
    # ---- v15 主路径原样保留（NGE→HCC→HDT→SCD→DSD→DCA→EDC→守卫）----
    results = middleware.run_cycle(runners={...}, ctx=ctx)
    nge.update_belief(obs)
    hcc.update_identification(obs.motor_enc, obs.joint_enc, obs.current)

    # ---- IP-408 CEG：先确定时钟世代 ----
    epoch = ceg.check(obs.t_now, ros_clock)

    # ---- IP-402 CTS：建立公共时间切片 ----
    sl = cts.slice(perceptions or obs.perceptions, obs.t_now, epoch)

    # ---- IP-403 QGA：保证到达集 ----
    Sg = qga.guaranteed(topics or ctx.topics)

    # ---- IP-404/405 MCF/MGC：融合与增益证书 ----
    fused = mcf.fuse(
        x=obs, M_cert=sl.M_cert, S_g=Sg,
        joint_ok=sl.joint_ok and (fused_umgc_state := True))

    # ---- IP-407 DCC：与各安全节点取交 ----
    cons = dcc.gate(node_certs or ctx.node_certs, obs.t_now, epoch)

    acc = fused.acc & cons.acc
    if not cons.alive:
        execute(ctx.safe_ask)              # quorum 不足：安全回退
    elif acc:
        a_hat = select_best(acc, fused, obs)
        execute(a_hat)                     # 联合证书 + 分布式交集同时成立
    else:
        execute(v15_rung0_or_ask(ctx))     # 未校准子集 / 空交：严格 v15 回退

    # ---- v15 守卫：沿用原 chunk_guard 与技能阶梯 ----
    verdict, k_next = chunk_guard(
        current_chunk, k_exec, live_obs, nge.b, hcc, ...)
    if verdict == 'abort':
        current_chunk.execute_transfer_safe_abort(k_next)
        current_chunk = None
    elif verdict == 'degrade':
        current_chunk = scd.rung(0)
    elif verdict == 'recover':
        execute_recovery(nge.epistemic_recovery())
    else:
        execute(current_chunk.skills[k_next])

    # ---- 低频异步：联合共形重校准 + 子集族重检验 ----
    if cycle_idx % T_fuse_cal == 0:
        dataset.calibrate(new_obs_buffer)
        mcf.cal = joint_conformal.fit(dataset.calibrated, alpha_family)
        mcf.cal = sng.validate()

    # ---- v15 继承路径 ----
    C, spatial_cert, claims, metrics, rewards = M.inherited_v15_path(ctx)
    return C, spatial_cert, claims, metrics, rewards

## 2. 推导（引理 131–137）

**引理 131（时基切片的证书有效性）** 设每个模态 m 的单模态证书 `(Acc_m, m_m)` 只在其观测有效期 `I_m` 上与当前决策相关，联合分数 `S_fuse` 只在公共切片 `I*` 上有定义。若 `I* = ∅` 或 `width(I*) > Δ_max`，则任何使用 `S_fuse` 的放行都不能继承各模态的覆盖保证；此时必须禁止联合，只能退到未校准/单模态回退。证明：联合共形的可交换性要求校准样本与测试样本来自同一联合观测分布；`I*` 为空意味着"同一时刻的联合观测"不存在，测试点落在联合校准支撑之外，联合分位失去意义。单模态证书只依赖各自 `I_m`，故删除联合不破坏单模态 soundness。∎ 推论：**时基不是预处理，而是证书的定义域**；先对齐再融合的顺序不可交换。

**引理 132（子集单调 ⇒ 缺席安全）** 若 `𝒮_cal` 满足嵌套单调：对任意 `S'⊆S`（两者均在 `𝒮_cal`），有 `Acc^{S'}⊆Acc^{S}`；未校准子集映射为空集 `∅`。则当前有证集从 `S` 收缩到 `S'`（模态缺失）时授权只减不增：`Acc^{S'}⊆Acc^{S}`。证明：已校准情形由单调性直接得到；未校准情形 `∅⊆Acc^{S}`。∎ 推论：**"缺席即最保守"不需要插补**；禁止临时构造交集只是把未校准子集显式映射为空集，从而把"缺席"变成可检查的部署期条件。

**引理 133（QoS 不确定集的约简）** 给定 QoS 剖面 `Q`，保证到达集 `S_g`、可能到达集 `S_u`，不确定集 `𝒰(Q)={S : S_g⊆S⊆S_u}`。若 `𝒮_cal` 在 `𝒰(Q)` 上嵌套单调，则
```
⋂_{S∈𝒰(Q)} Acc^{S} = Acc^{S_g} .
```
证明：`∀S∈𝒰`，`S_g⊆S`，由单调性 `Acc^{S_g}⊆Acc^{S}`，故 `Acc^{S_g}⊆⋂`；又 `S_g∈𝒰`，故 `⋂⊆Acc^{S_g}`。∎ 推论：**QoS 不确定性的最坏情形就是"只保留保证到达的模态"**；best-effort 模态只有在到达被提升为保证（或具备独立冗余）时才计入授权，否则其丢失只能取消增益，不能改变最坏情形。

**引理 134（联合共形与 MGC 的乐观上界）** 对校准子集 `S`，设联合非一致性分数 `S_fuse(x,a) = max_{m∈S} S_m(x,a) + λ·D_S(x)`，其中 `D_S` 为模态间分歧。取联合校准集 `C_S` 上 `⌈(1−α_S)(|C_S|+1)⌉` 阶经验分位 `q_S`。若测试点与 `C_S` 可交换，则联合证书 `Acc^{S}={a : S_fuse(x,a) ≤ q_S}` 的边际假接受率不超过 `α_S`；且 `U_MGC(S)=max(0, q_S−max_{m∈S} q_m)` 给出"联合相对最宽单模态"的乐观上界，当 `|S|=1` 时 `U_MGC=0`。证明：标准 split-conformal 覆盖性；`D_S` 只增大分数、不破坏可交换性；`U_MGC` 由定义直接得到。∎ 推论：**相关性越大，`D_S` 与 `q_S` 同向膨胀，`U_MGC` 随之增大并触发增益禁用**——这正是"一致但共同错判"的结构性刹车。

**引理 135（分布式交集不扩张 + 活性分离）** 设节点 `n∈Q` 的证书 `C_n=(Acc_n, t_n, epoch_n)`，执行器门接受
```
Acc_cons = ⋂_{n∈Q, epoch_n=epoch, |t_n−t_now|≤Δ_fresh} Acc_n .
```
则对每个参与节点有 `Acc_cons⊆Acc_n`，故任一节点（含被攻陷节点）不能单方面扩张授权；若有效节点数 `< q` 或全部超时，则门返回 `a_ask`。证明：交集定义；quorum 只决定是否进入交集，不参与授权计算。∎ 注：该结论对 crash-fault 与诚实节点成立；Byzantine 需签名、冗余与可验证证书，见风险 4。

**引理 136（时钟跳变与 bag 循环的作废语义）** 若 `ros_clock` 跳变（系统/仿真时间切换、`/clock` 回退、bag loop）使 `t_now < t_last − Δ_jump`，则所有旧 epoch 签发的证书作废，`M_cert:=∅`，只能执行与历史无关的安全回退。证明：证书的时间戳语义在跳变后不可比较，新鲜度与可交换性前提同时失效；跨 epoch 拼接会产生负延迟或未来数据的伪新鲜。∎ 推论：**证书必须绑定 clock epoch / watermark，而不是裸时间戳**；否则一次 bag 循环即可让整套融合回到"有证但错误"的过去。

**引理 137（v16 的退化与安全继承）** 若 CTS/QGA/MCF/DCC 任一失效并注入对应中立元，则 `Exec_v16⊆Exec_v15`；四者全失效即精确退回 v15 的 SCD/DSD/DCA/EDC 路径，再沿 v15→v14→…→v6 退化链退回。证明：CTS 失效 ⇒ 视全模态同基，仅取单模态交集，仍是 v15 授权子集；QGA 失效 ⇒ `S_g=S_u`，只缩小在场集；MCF 失效 ⇒ `Acc^{S}=⋂_{m∈S}Acc_m` 且必与 `Exec_v15` 取交；DCC 失效 ⇒ 单节点证书即 v15 输入。每个中立元都不新增授权。∎

## 6. 已知风险与失效模式

1. **时间戳伪造与驱动延迟**：驱动可能打上错误或过早的时间戳，使 `I_m` 看起来新鲜。缓解：硬件时间戳、单调 clock、与 `/clock` 交叉校验、异常延迟检测、拒绝回退时间戳。

2. **tf2 外推被误当有效**：缺帧时 tf2 可能返回外推变换，空间证书看似成立。缓解：显式检查 `extrapolated` 标志、设置最大外推时长、外推即删模态并触发空间证书重算。

3. **QoS 统计被短窗口掩盖**：突发丢包在平滑窗口内不可见，导致 `S_g` 高估。缓解：滑动窗口 + 最坏窗口取小、EWMA 与硬计数并用、QoS 剖面变更即重算、保守 `loss_tol=0`。

4. **Byzantine 节点与共谋**：DCC 的交集只对 crash-fault 与诚实节点成立；恶意节点可伪造/延迟证书。缓解：签名与可验证证书、冗余节点、诚实多数假设显式化、关键场景保留单节点硬件安全回路。

5. **子集族组合爆炸**：`|M|` 增大时 `2^{|M|}` 个联合校准子集不可行。缓解：只用可部署子集族（按任务/硬件枚举）、层级共享骨干、未枚举子集一律空集回退。

6. **联合共形在相关误差下过宽**：模态高度相关时 `D_S` 与 `q_S` 同向膨胀可能掩盖共同错判。缓解：相关感知加权、`U_MGC` 硬阈、对抗相关样本、EVT 尾部分位、漂移时禁用增益。

7. **一致性增益退化为无用的交集**：`U_MGC` 长期超阈会退回交集，融合增益名存实亡。缓解：分层校准、增加独立模态、任务条件化增益、把假拒绝显式计入预算。

8. **DCC 交集饥饿活性**：节点证书各异导致交集为空，频繁 `a_ask`。缓解：共享校准基线、节点角色分工（只让相关节点参与交集）、quorum 与交集解耦、任务级降级。

9. **时钟 epoch 频繁切换**：频繁仿真/真实切换使证书反复作废，系统长期处于回退。缓解：稳定时钟源、epoch 切换成本建模、预热期、切换时直接安全停。

10. **多重间隙相加**：时基间隙 `U_time`、模态间隙 `U_MGC`、v15 的蒸馏间隙 `U_gap` 与分布间隙 `U_dis` 可能同向偏低。缓解：四预算加性上界、任一间隙失效即触发最低档、双重漂移检测、联合三角界。

## 7. 本轮最大风险

**一句话**：CTS/QGA/MCF/DCC 都只在"各自前提成立"的层面上取证，而真实 ROS 图里时间戳可能被驱动伪造、QoS 统计可能被短窗口掩盖、模态误差可能在分布漂移下高度相关；当这些前提同时"看起来成立"时，联合共形会在一个从未被联合校准覆盖的边界上给出过宽的 `U_MGC`，最终在"时间一致、QoS 保证、每模态有证、联合覆盖达标"的表象下执行了一个所有模态共同错判的动作——即**时基自洽、模态共识、却绝对错误的安全决定**。
