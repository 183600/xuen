# 第 47 轮（本循环第 2 轮；承接第 46 轮 v23 / 四层 v10；本轮灵感：LoRA × 痛点分析） · PALG：痛点排序驱动的 LoRA 局部适配 × 适配租约与证书守卫（五层架构 v11）

> 承接第 46 轮 v23 Memory-Safety-Voice。v10/v23 已把能量、姿态、记忆、语音、安全队列纳入证书与 fail-closed 体系，但隐含假设 H5：**模型与校准器在部署时固定，痛点靠“继续加模块/加证书”解决**。它没有回答三个工程真问题：该先修哪个痛点、能用多便宜的改动去修、修完在哪些输入上还成立。现实是 UniBot 每个部署站点/用户/任务分布都有异质且重尾的痛点；重训或全参微调 VLM 成本高、难回滚，且会整体移动决策边界。两个灵感词精确命中 H5：**痛点分析**给出数据驱动、代价加权、且必须区分“被说出来的痛点”与“沉默的安全痛点”的排序；**LoRA**给出便宜、局部、可插拔、可回滚的改法。二者耦合出新问题：**如何把有限的适配预算投到最痛的区域，并保证 LoRA 只在被审计覆盖的支撑域内生效、越界即退回基座 + 保守证书，且多个适配器组合不会互相干扰而静默破坏证书 soundness**。

## 0. 直觉与动机

**灵感 1（痛点分析 → 代价加权的痛点场，而不是 bug 列表）**
直觉：痛点是“会让人或系统付出代价的偏离”，不是所有报错。把 telemetry（干预、重问、中止、任务耗时、近失事件、证书宽度）聚成定义在 (c, ω, φ) 上的痛点场 Π。关键是它有两类：**voiced pain**（用户说/操作暴露的）与 **silent pain**（用户没吭声，但证书很宽、发生近失或覆盖空洞）。只看 voiced pain，会系统性漏掉最危险的那一类。再用代价（安全 > 可用 > 效率）加权，并按**保守下界**排序，避免把噪声或选择偏差当成痛点。

**灵感 2（LoRA → 便宜的局部手术刀，不是免费的正确性）**
直觉：LoRA 用低秩 ΔW=BA 只动少量参数，可为每个痛点区域训练一个小适配器，内存/能耗低、可插拔、可回滚，天然适合“站点级/任务级/用户级”特化。但低秩不等于局部：适配器会把决策边界在**整个定义域**上轻微移动，在其训练支撑之外可能“更自信地错”。因此适配器必须带“支撑域 + 校准覆盖 + 秩/范数预算 + 过期时间”的租约，只在租约有效处替换基座行为。

**灵感 3（二者耦合 → 风险厌恶的适配预算分配）**
直觉：痛点排序决定适配目标，适配租约决定适配能兑现的安全边界。于是形成闭环：痛点场（含 silent 先验）→ 选择目标与秩/范数预算 → 训练小 LoRA → 在独立审计集上校准支撑域与覆盖面 → 部署时按上下文门控激活 → 收集新痛点 → 再排序。硬边界与 v10/v23 一致：**适配只能在其支撑域内“收窄证书”，绝不能抬高全局失败预算 α_safe；越界一律 fail-closed 回基座**。

**耦合升级**：在 v10 四层（根信任 / L1 几何 / L2 上下文 / L3 守卫 / L4 采集，v23 又叠加记忆-语音-安全）之上新增第五层 **AGL（Adaptation Governance Layer，适配治理层）**。PPM 挖痛点并做风险厌恶排序；TAP 在“适配预算 × 安全预算”下选择适配目标、秩与范数；ALG 为每个适配器签发租约，做支撑域门控、组合干扰控制与回滚。ECPS / 上下文预测器 / PSE / DCL / CCA / CAR / 记忆与语音链路全部接 AGL。

## 1. 形式化定义（增量：定义 59–64）

**定义 59（痛点场与 voiced/silent 分解）**
对 episode e ~ D 与位置 (c, ω, φ)，代价加权痛点场
Π(c,ω,φ) = E_e[ w_i·1[干预] + w_r·1[重问] + w_a·1[中止] + w_t·T_e/T_max + w_c·1[cert_width > τ_w] + w_n·1[近失] ]，
并分解 Π = Π_v + Π_s：
Π_v 由可观测交互事件（干预/重问/中止/耗时）构成；
Π_s = w_c·P(cert_width>τ_w | c,ω,φ) + w_n·P(near-miss | c,ω,φ)，
用证书宽度与近失作为**沉默失败**的代理——因为这类失败不会出现在 voiced 通道里。

**定义 60（风险厌恶痛点排序）**
对候选适配目标 z=(region, module)，估计其痛点降低 ΔΠ_z。用 bootstrap 或在线 A/B 得到样本，取置信下界
score(z) = LCB_{1-δ}[ΔΠ_z] / (cost_a(z) + λ_m·mem(z) + λ_l·lat(z))。
仅当 LCB>0 且支撑域可审计时进入 backlog；这就是**风险厌恶痛点排序**，显式对抗把噪声/选择偏差当作痛点。

**定义 61（适配器租约）**
适配器 a 的租约 ℓ_a=(S_a, α_a, r_a, β_a, τ_a, I_a)，其中 S_a⊆C×Ω 为支撑域，1-α_a 为其在审计集 I_a 上的校准覆盖，r_a 为秩，β_a=‖BA‖_* 为范数预算，τ_a 为过期时间。**租约 soundness**：
∀x∈S_a，P(error(x, f_base+Δ_a) ≤ rad_a) ≥ 1-α_a；x∉S_a ⇒ 租约作废，退回基座。

**定义 62（支撑域条件化证书）**
证书半径
rad_t = 1[x_t∈S_a ∧ lease valid]·rad_a(x_t) + 1[¬(x_t∈S_a ∧ lease valid)]·rad_base(x_t)，
并要求在 S_a∩审计集上 rad_a ≤ rad_base。即**只在可证处收窄**；适配器越界时不产生任何证书收益。

**定义 63（组合干扰与串行化）**
k 个适配器组合 ΔW_Σ=Σ_i λ_i B_i A_i，组合干扰定义为
I_comp(x) = | f_Σ(x) - f_base(x) - Σ_i λ_i(f_i(x)-f_base(x)) |。
要求 sup_{x∈审计集} I_comp ≤ ε_I，且组合模型在并支撑上的经验覆盖 ≥ 1-α；否则**串行化**（同一时刻只激活优先级最高的一个）或丢弃低优先级适配器。

**定义 64（痛点导向的适配分配目标）**
max_{Z,{r_a,β_a},{λ_a}} Σ_{z∈Z} LCB[ΔΠ_z]·1[z 已部署]
s.t. Σ_a cost_a ≤ B_a；每个 ℓ_a 有效；I_comp ≤ ε_I；Σ_ω π_ω α_ω ≤ α_safe；各 S_a 覆盖约束。
**硬约束**：适配不得抬高 α_safe，只能在支撑域内收窄证书；预算不足时宁可少适配，不可扩大全局失败预算。

## 2. 新增产出与既有 IP 升级

**IP-69 PPM（Pain Point Miner）**
- telemetry 归一化与 episode 对齐
- voiced/silent 分解、代价加权、按 (c × ω × φ) 聚类成痛点区域
- bootstrap/LCB 排序，选择偏差校正（IPW，以及由证书宽度/新颖度给出的“未观测缺陷先验”）
- 输出 ranked backlog + 每个目标的支撑域候选与样本量

**IP-70 TAP（Targeted Adaptation Planner）**
- 在适配预算 B_a 与全局 α_safe 下选择目标、秩 r_a、范数 β_a
- 秩预算与痛点复杂度匹配：低秩不足时标记“需采集/需全参”，而不是硬塞一个欠拟合适配器
- 输出训练任务、预期证书收窄量与影子评估计划

**IP-71 ALG（Adapter Lease Governor）**
- 支撑域估计：OOD 分数 + 共形校准
- 租约签发/续期/过期/回滚；漂移监控
- 组合干扰检测与串行化
- 越界 fail-closed 回基座，并输出可解释原因（哪条租约、哪个支撑条件不满足）

**既有 IP 升级**
IP-65 CONTEXT PREDICTOR：把 silent-pain 特征（证书宽度、近失率）加入上下文特征
IP-63 ECPS：痛点排序可触发“适配训练/深度预热”的资源分配
IP-60 PSE：按支撑域条件化证书签发，适配器仅在可证处收窄
IP-61 DCL：采集任务优先覆盖痛点高且支撑不稳的区域
IP-62 CCA：新增适配越界激活、组合干扰、痛点选择偏差红队
IP-51 CAR：守卫检查租约有效性与 I_comp，越界 fail-closed
IP-66/67/68：记忆复用与语音决策同样要过适配租约（历史记忆可能来自旧适配器）

## 3. 算法骨架

PALG 控制/训练周期：
1. PPM 聚合 telemetry → 痛点场 Π，分解 voiced/silent，LCB 排序
2. TAP 在适配预算 B_a 与全局 α_safe 下选 top 目标，定 r_a、β_a
3. 训练 LoRA（离线/影子），在独立审计集校准 S_a、α_a、rad_a
4. ALG 签发租约，影子期对比基座（coverage + 干扰）
5. 部署：每帧判断 x∈S_a 且租约有效 → 用适配证书；否则基座证书
6. 组合：若 I_comp>ε_I → 串行化/降级
7. 在线监控 drift/近失 → 续期或回滚；新痛点回流 1

## 4. 本轮最大风险

**一句话**：痛点排序若被“被说出来的痛点”主导，LoRA 会把有限预算特化到最吵但不最危险的区域，而适配器在其校准支撑之外静默激活又会收窄本已不成立的证书，直接破坏 soundness；因此必须用含 silent 先验的风险厌恶 LCB 排序、把适配器绑定到经审计的支撑租约，并在越界时 fail-closed 回基座。

## 2. 关键算法 伪代码

### IP-69 PPM
```
def build_pain_field(episodes, W):
    # episode: (c, omega, phi, intervention, reask, abort, T_e, cert_width, near_miss)
    grid = defaultdict(list)
    for e in episodes:
        key = (discretize(e.c), e.omega, e.phi)
        pain_v = (W.i*e.intervention + W.r*e.reask + W.a*e.abort
                  + W.t*e.T_e/T_max)
        pain_s = (W.c*(e.cert_width > tau_w) + W.n*e.near_miss)
        grid[key].append(pain_v + pain_s)
    return {k: (mean(v), std(v), len(v)) for k, v in grid.items()}

def rank_targets(pain, adapt_cost, delta=0.05, eps=1e-9):
    backlog = []
    for z, (mu, sd, n) in pain.items():
        # 风险厌恶：用 LCB 而非点估计，防止把噪声/选择偏差当痛点
        lcb = mu - z_score(1-delta) * sd / sqrt(max(n, 1))
        if lcb > 0:
            backlog.append((z, lcb / (adapt_cost(z) + eps), lcb, n))
    return sorted(backlog, key=lambda t: -t[1])
```

### IP-70 TAP
```
def plan_adaptation(backlog, B_adapt, rank_set, calib, tau_gain):
    chosen, spent = [], 0.0
    for z, score, lcb, n in backlog:
        for r in sorted(rank_set):              # 优先低秩，省预算
            cost = train_cost(z, r)
            if spent + cost > B_adapt:
                continue
            gain = shadow_gain(z, r, calib)      # 影子集上的证书收窄
            if gain.rad_reduction < tau_gain:
                continue                          # 低秩不足，不硬塞
            chosen.append((z, r, norm_bound(z, r), gain))
            spent += cost
            break
        else:
            # 所有秩都收窄不足：转 IP-61 DCL 采集，或标记需全参
            mark_collect_or_fullparam(z)
    return chosen, spent
```

### IP-71 ALG
```
def estimate_support(adapter, audit, alpha_a):
    in_scores = [ood_score(x) for x in audit.in_support]
    q = conformal_quantile(in_scores, alpha_a)
    return lambda x: ood_score(x) <= q

def issue_lease(adapter, audit, alpha_a, tau_a):
    S = estimate_support(adapter, audit, alpha_a)
    if empirical_coverage(adapter, audit, S) < 1 - alpha_a:
        return None                              # 覆盖不达标，不签发
    return Lease(S=S, alpha=alpha_a, rank=adapter.r,
                 beta=adapter.norm, expiry=tau_a, drift=0.0)

def interference(adapters, x):
    f_sum = adapters[0].apply_composed(x)
    add = sum(a.delta_output(x) for a in adapters)
    return abs(f_sum - add)                      # 非线性交互残差

def certify(x_t, base, adapters, leases, eps_I):
    active = [a for a in adapters
              if leases[a].valid(t) and leases[a].support(x_t)]
    if not active:
        return base.certificate(x_t), 'base'     # 越界 fail-closed
    if interference(active, x_t) > eps_I:
        active = serialize_by_priority(active)   # 串行化，只留最高优先级
        if interference(active, x_t) > eps_I:
            return base.certificate(x_t), 'base'
    rad = min(base.rad(x_t), min(leases[a].rad(x_t) for a in active))
    return Certificate(rad), 'adapted'
```

### AGL 治理闭环
```
def palg_cycle(telemetry, adapters, leases, base, budgets):
    pain = build_pain_field(telemetry, W)
    backlog = rank_targets(pain, adapt_cost)
    plan, spent = plan_adaptation(backlog, budgets.B_a, rank_set, calib, tau_gain)
    for z, r, beta, gain in plan:
        a = train_lora_shadow(z, r, beta)
        if shadow_beats_base(a, base, audit) and interference_with_active(a) <= eps_I:
            leases[a] = issue_lease(a, audit, alpha_a, tau_a)
            adapters.append(a)
    # 运行时门控由 certify() 完成；漂移/近失回流
    return certify_next_frame, backlog
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PPM 痛点场 | O(|E|) 聚合 | O(#regions) | 痛点排序为经验估计，仅用于分配，不作安全担保 |
| TAP 规划 | O(|backlog|·|rank_set|) | O(|plan|) | 低秩不足则拒配；不改 α_safe |
| ALG 支撑判定 | O(d) 每帧 | O(|audit|) | x∉S_a 或租约失效 ⇒ 回基座，证书 soundness 不依赖适配器 |
| 组合证书 | O(k) | O(k) | I_comp ≤ ε_I 才组合，否则串行化/fail-closed |
| 全链路 | O(|E| + |backlog|·r) 每轮 | O(|M|) | 适配只在支撑域内收窄，全局 α_safe 单调不升 |

**正确性定理**：设每个适配器租约 ℓ_a 在审计集上满足 1-α_a 覆盖，且组合干扰 I_comp≤ε_I。则对任意帧 x_t：若不存在有效且支撑命中的适配器，证书由基座签发，其 soundness 只继承 v10/v23 的基座保证；若存在，则 rad_t ≤ rad_base 且覆盖约束在 S_a 上经验成立，故适配不会降低该帧证书覆盖率。全局上因 Σπ_ω α_ω ≤ α_safe 不变，适配只可能改变收窄效率，不能抬高失败预算。于是系统整体保持 v10/v23 的 soundness，额外收益是支撑域内的证书收窄与痛点下降。

## 4. 实验设计 E115–E120

| 实验 | 指标 | 门槛 |

| E116 支撑域门控 | OOD 误接纳率、支撑内激活占比 | 误接纳 ≤ 1%；支撑内激活 ≥ 95% |
| E117 适配证书收窄 | 支撑域内半径下降、审计覆盖 | 半径降 ≥ 20%；覆盖 ≥ 1-α |

| E119 闭环痛点下降 | 干预/重问/任务耗时、近失率 | 三项降 ≥ 25%；近失不上升 |
| E120 100h 多站点 | 回滚时延、租约过期处理、沉默证书违例 | 回滚 ≤ 1s；沉默违例 = 0 |

回退策略：E115 排序不稳定 → 退回均匀/人工排序，仅做保守适配；E116 误接纳 > 2% → 收紧 S_a（更小支撑）并提高 OOD 阈值；E117 收窄不达标 → 提升秩或转 DCL 采集；E118 干扰超限 → 强制串行化；E119/E120 出现近失或沉默违例 → 立即回滚相关适配器并全局切基座。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 痛点排序被 voiced pain 主导，漏掉 silent 安全痛点 | 高 | 强制加入证书宽度/近失先验；LCB 排序；专家抽样复核 |
| 适配器在支撑域外静默激活、更自信地错 | 高 | OOD + 共形校准支撑域；越界 fail-closed 回基座 |
| 多适配器组合互相干扰 | 高 | I_comp 上限；超限串行化或丢弃低优先级 |
| 低秩欠拟合被误当成“已修复” | 中 | 影子集证书收窄门槛；不足则拒配并转采集 |
| 站点漂移使租约过期仍被使用 | 中 | 漂移监控 + 强制过期 + 自动回滚 |
| 适配训练数据本身有偏 | 中 | 独立审计集、IPW 校正、CCA 红队选择偏差 |

## 6. 本轮最大风险

**一句话**：痛点排序若被“被说出来的痛点”主导，LoRA 会把有限预算特化到最吵但不最危险的区域，而适配器在其校准支撑之外静默激活又会收窄本已不成立的证书，直接破坏 soundness；因此必须用含 silent 先验的风险厌恶 LCB 排序、把适配器绑定到经审计的支撑租约，并在越界时 fail-closed 回基座。
