# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环第 2 轮；本轮灵感：「异常检测」×「人机协作」）

> R68 问「传感器还自洽吗」，R69 问「行为还自洽吗」，并用交互去消除策略层面的歧义。可这两层共享一个从未被点破的隐含前提：**「自洽」总是相对于一个已知、可信、且不动的参考系而言的。** R69 的交互由 U_epi 驱动，而 U_epi 度量的是动作模态之间的分歧。现实里最危险的状态却是另一种：**单峰、锐利、低方差、动作飞快**——只不过它建立在「世界仍遵循训练分布」这个错误前提上。流策略越确定，越说明它把当前观测解释得越顺；而一个足够偏离的世界，恰恰可能被编码器「顺滑地」映射到一个看似熟悉的动作上。于是 U_epi 很小、VoI 近零，系统会以最快、最自信的方式执行一个错误动作。这是「置信度」与「胜任度」的错位，也是 R69 从未测量的那一维。
>
> 本轮两个灵感正好补上这块，但各自都带着反噬：
> - **异常检测**给出「世界是否仍落在许可范围内」的计量——可它自带一个更深的陷阱：分数只有相对于某个参考系才有意义，而检测器无法用自己被训练的分布去认证自己「正常域」的安全；
> - **人机协作**给出模型之外唯一可能的作证者——人。但人不是 oracle：人会疲劳、会过度信任自动化、会与机器共享同一个错误前提，甚至会被社会工程；而「问人」这个动作本身还会消耗人这个检测器。
>
> 核心命题：**异常不是「分数过阈值」，而是「一个带显式参考系、覆盖域与授权来源的许可边界被跨越」；检测器不能自证正常域，因此异常裁决必须是「机器检测器 + 可安全干预 + 人类互补检测器」的三方证据；而信任必须与检测阈值一起在线校准——过信会把异常吸收成正常（normalization of deviance），欠信会把告警变成噪声（alarm fatigue）。** 命名 **VIGIL-RAS**（Vigilance-aware Interactive Grounded anomaly detection with Licensed boundaries：警觉感知、交互接地、带许可边界的异常检测闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我还知道自己在哪儿吗——以及，此刻我该信谁**」。

## 0. 直觉与动机

**灵感 1（异常检测 → 最危险的不是「不确定」，是「自信地错」）**
直觉：R69 把「不确定」拆成 aleatoric / epistemic，并用交互去解 epistemic。但这套机制有一个盲区：**它以「策略自己承不承认歧义」为触发条件**。一个训练充分的策略，在分布外输入上可能收敛到一个低方差、高置信的模态——它不是「犹豫」，而是「斩钉截铁地错」。这时的 U_epi ≈ 0，MINT 不会去问，λ 不会被收紧，VISTA 还会给出一个看起来很稳的预测。异常检测提供的是与「动作歧义」正交的另一条轴：不是「我该做哪个动作」，而是「我有没有资格用这个策略来回答当前这个问题」。**置信度回答「我有多确定」，胜任度回答「我有没有被授权在这里确定」。R69 缺的正是后者。**

**灵感 2（异常检测 → 分数没有意义，「参考系」才有意义）**
直觉：「这个点异常分 0.93」——相对于什么？相对训练集？相对哪台身体？相对哪个环境包络？异常检测最常见的塌陷，是把「相对 D_ref 的新颖」偷偷说成「绝对的危险」。在开放世界协作里，参考分布本身会漂移（环境变、任务变、身体换件），于是同一个观测昨天正常、今天异常。所以本轮的第一条纪律不是设计更强的评分器，而是**强制每个分数携带它的参考系、覆盖域与授权来源**；越出声明域时，正确的标签不是「异常」，而是「无参考，拒绝判断」。**「无参考」与「异常」必须分开**，否则检测器会把「我没见过」和「这很危险」混为一谈。

**灵感 3（异常检测 → 被动不可辨识，必须干预）**
直觉：只看着，你永远分不清眼前这次失配是**新情况（novel）**、**故障（fault）**、**噪声（noise）**还是**慢漂移（drift）**——这四种东西在一段被动观测上可以完全同分布。唯一能把它们分开的是**施加一个安全激励，看因果响应**：新情况的响应仍服从某个一致的世界模型；故障的响应破坏本体物理规律（例如执行器增益突变、回差跳变）；噪声的响应不随激励系统性变化；漂移则随累积激励显形。这把 R69 的信息动作从「消歧动作模态」升级为「**辨识世界假设**」——同样的看/问/触，优化目标从后验熵换成了因果假设与响应之间的互信息。异常检测由此从「被动打分」变成「**主动做实验**」。

**灵感 4（人机协作 → 人是模型之外唯一的作证者，但人不是 oracle）**
直觉：引理 19 会给出一个不舒服的结论：**只用 D_ref 训练的检测器，无法认证自己 in-区域的安全**——因为 D_ref 里所有点按定义都叫「正常」，而 in-区域是评分的下水平集，它比 D_ref 大得多，多出来的部分从没被标注过。要跳出这个循环，参考系必须来自检测器之外。人类是现成的外部参考：专家能在「说不清哪里不对」的层面嗅到尾部异常（thin-slicing），这恰是机器最弱、人最强的地方。但人类也有类别相关的盲区、会被工作负荷与疲劳压垮、会过度信任自动化、也会撒谎。所以本轮把人类建模成**一个带类别混淆矩阵、状态会漂移、且观测成本会反噬其自身的传感器**，而不是全知 oracle。

**灵感 5（人机协作 → 信任校准与阈值校准是同一个问题的两张脸）**
直觉：异常检测的阈值设错，会「把新正常当异常」（误警）或「把异常吸收进正常」（漏检）；人机协作的信任设错，会「欠信 → 告警疲劳」或「过信 → 异常正常化」。这其实是**同一个潜变量——「许可边界」——的两侧估计**：机器的检测器估计「世界是否越界」，人的信任估计「我是否接受机器说没越界」。二者失配时最危险的不是某一方错了，而是**机器沉默、人也沉默，双方都以为对方在看着**。所以本轮监测的核心对象不是单侧异常，而是**共同基底分歧 SCD**：机器许可边界与人接受边界之间的距离，以及这个距离是否在无人察觉时持续扩大。

**灵感 6（人机协作 → 告警是消耗人类检测器的动作）**
直觉：告警不是免费的。每一次升级都在消耗人的注意力，而人的警觉会随时间单调衰减（vigilance decrement）。于是「多加告警」在后期不但无效，还会制造**告警洪泛攻击面**：攻击者先用大量低危告警把人打疲，再在噪声里做真正的事。安全设计因此不能只问「该不该报警」，还要问「**什么时候报警会把人这个检测器用坏**」，以及「是不是该换人/休息，而不是更响」。

**灵感 7（统一姿态 → 新层必须是旧层的严格泛化）**
直觉：前几轮反复强调「新层不能是并列的另一个黑箱」。VIGIL 必须满足：当所有异常分都落在 in（无有据异常）、人类可靠度达标、共同基底分歧不越界时，它与 R69 逐指令相同。异常检测与协作只被允许做两件事——**在 und 区补外部证据，或向更保守方向降落**；它绝不能成为放宽安全的理由。这条约束把「新增一层」从风险变成可审计的增量。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（VIGIL-RAS 总览）** VIGIL-RAS = (LBR, CAD, AID, HRM, TCD, SCD, VAM, RAS-WM§)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **无参考不异常**：任何异常分必须绑定一个显式许可边界 B（参考分布 + 覆盖域 + 授权来源）；无参考的分数不得触发任何安全动作，只能作为「待定」；
(iii) **失败闭合与单调降级**：异常若无法在预算内被裁决 ⇒ 只能向更保守方向降落（继承 R66–R69 降级梯），**异常检测永远不能成为放宽安全的理由**。

**定义 311（许可边界 LBR）** 许可边界 B = (D_ref, h_ref, E_env, E_task, w)，其中 D_ref 为参考分布（训练/验证/在线校准数据），h_ref 为其上的评分函数，E_env / E_task 为声明的环境与任务包络，w 为授权来源（厂商标定 / 在线校准 / 人类连署 / 社区复现）。B 定义「正常」的**外延**。当 x 落在 E_env ∪ E_task 之外时，B 失效——此时正确标签是「无参考」（定义 314 的 out-of-scope），不是「异常」。**授权来源可被多方连署，但不可被单方扩写。**

**定义 312（共形异常分与 p 值 CAD）** 评分 s(x) = h_ref(x)；在独立标定集上取经验分位。共形 p 值：
p(x) = (1 + #{i : s_i ≥ s(x)}) / (n + 1)。
异常 ⇔ p(x) ≤ α。性质：在可交换性假设下 P(p(X) ≤ α) ≤ α（误报率受控），且与 h_ref 的具体形式无关。**这只给「相对 D_ref 的新颖性」保证，不给「新颖即危险」保证**（引理 19）。为抗单点伪影，至少用两个不同归纳偏置的评分器（如密度比 + 重构残差），要求二者**同向**才记为候选。

**定义 313（有据异常 WAn）** 有据异常 = (p(x) ≤ α, B, w, c_cov)，且通过覆盖性检查：x 在 B 声明的 E_env/E_task 内、各传感器在可观测域内、至少两个正交评分器一致、且标定集本身通过可复现性校验。**没有有据异常，就没有升级**——这防止「模型幻觉出一个异常，然后按异常处理」（R69 的幻影模态攻击在检测层的镜像）。

**定义 314（三值裁决）** 裁决 d(x) ∈ {in, out, und}：
- in：p(x) > α_hi，继续任务（走 R69 路径）；
- out：p(x) ≤ α_lo 且（有据 ∧ 可安全处置），执行降级/停（定义 325）；
- und：中间带，或证据不足，或落在 B 作用域边缘——进入主动诊断（定义 315）或人类升级（定义 317）。
相比二值检测，und 把「异常检测自身的不确定性」显式化：**拒判不是失败，而是一种可分配的动作。** 三个区域都必须是「有参考系的」，out-of-scope 单独记作 `oos`，不并入 out。

**定义 315（主动分离诊断 AID）** 被动不可辨识，故施加安全激励 g ∈ 𝒜_probe（复用 R69 定义 294 的信息动作，但目标改为因果辨识）。假设集 ℋ = {novel, fault, noise, drift}，响应 y。选择
g* = argmax_g [ I(ℋ ; y | g, o) − c(g) ]，
受 C-RAS-WM 前缀认证（继承 R69 定义 302）与交互预算约束。诊断后后验 argmax 若仍不显著（最大后验 < τ_hyp），und 交给人类。**激励本身必须是「可逆、有界、不改变安全包络」的**；这与 R69「信息动作也要过认证」一脉相承。

**定义 316（人类可靠度模型 HRM）** 人类信号 h ∈ {approve, reject, unknown, unavailable}。可靠度不是常数：对异常类别 c，
sens_h(c), spec_h(c) = f(workload, expertise, vigilance(t), explanation_quality, c)。
用分层贝叶斯在线估计（按类别共享先验，个体后验），并显式维护**类别相关混淆矩阵**。禁止把人类当 oracle：`unknown` 是一等公民（人有权说不知道），`unavailable` 触发 VAM 的预算检查而非强行升级。

**定义 317（信任校准让步 TCD）** 机器人对人类的让步权重 β ∈ [0,1]。定义双失败的非对称损失：
L(β) = λ_o · P(漏检 | β) + λ_u · P(误警 | β) + c_esc · E[升级次数]，
其中过信（β 过大）导致漏检、欠信（β 过小）导致误警。选 β* = argmin L(β)。**β 随人类可靠度后验上升、随环境危险度下降**；且过信侧代价随危险度增长快于欠信侧（引理/定理 20）。R69 的 `slow_fault_suspect` 与 λ floor 是 β 被固定为 0 的一个特例。

**定义 318（反向异常：人也会异常）** 人类本身可能异常：疲劳、分心、对抗、被社会工程、或与机器人**共享同一个错误前提**（共谋错误）。定义人的异常分 s_h（反应时偏离、与机器人证据的背离、历史一致性、可选生理代理）。关键姿态：**不能把「人是最可靠的异常源」当作公理**——必须有一条反向通道监测协作对象；但该监测受定义 322 的隐私/信任预算约束，不能滑向「为安全而全面监控人」。

**定义 319（共同基底分歧 SCD）** 令 B_r 为机器人许可边界，B_h 为从人类行为/语言反推的**人类接受边界**。定义
D = d(B_r, B_h) —— 在共同状态空间上的边界距离 / 不一致测度（可用两边界分歧样本的对称差测度）。
**协作异常** = D 在双方都未察觉时持续增长（沉默分歧），或 D 被系统性压制（自动化偏见 / 过度顺从）。这类故障比单侧异常更危险：**系统与人一起错，且互相为对方背书。**

**定义 320（警觉衰减与告警预算 VAM）** 人类警觉度 v(t) 随连续单调监测衰减、随休息/换岗恢复。监控资源是共享预算：升级、解释、打断都消耗人的注意力。VAM 选择何时升级、何时批处理、何时要求换人/休息；目标是在给定人力预算下最小化加权漏检。形式化为一个带状态 v(t) 的随机调度：动作 ∈ {escalate, batch, defer, rotate}。**告警不是免费信息，而是消耗人类检测器寿命的动作。**

**定义 321（解释即校准 XC）** 解释 e 的目标不是「说服人」，而是**降低人-机边界的互信息缺口**，使人的后验与机器证据一致：
e* = argmax_e [ I(B_h ; evidence | e) − γ · persuasion_bias(e) ]。
区分「解释」与「劝说」：前者让人更准，后者让人更信。解释质量以**校准（可靠性图 / Brier / ECE）**度量，而非满意度。R69 的语言问句若只追求「让人同意」，就是本定义要禁止的劝说。

**定义 322（互惠监测与隐私预算 RMP）** 机器人监测人类、人类监督机器人，二者结构对称但不对称授权：人类监督机器人不设深度上限（透明性），机器人监测人类仅限**与安全相关的最小充分统计量**，且有硬预算。这防止「为了安全而全面监控人」的滑坡——那本身就是一种人机协作失败。

**定义 323（异常洗白与告警洪泛）** 对抗面：(a) **异常洗白**：把攻击拆成逐个都「接近正常」的小步，使每步 p 值都 > α（慢速漂移 / boiling frog）；(b) **告警洪泛**：制造大量低危异常耗尽人类注意力，再在噪声里发动真正攻击（去敏感化）；(c) **共谋欺骗**：人与环境一起演，误导机器人边界。并入 AIC：
ℰ_VIGIL = ℰ_FLUID × ℰ_launder × ℰ_flood × ℰ_collude。

**定义 324（累积证据账本 CEL）** 单步 p 值合法不等于轨迹合法。对每步定义 e-value e_t（如 1/p_t 的截断版），累积 E_T = Π_t e_t，用**随时有效（anytime-valid）**的 e-process 控制整条轨迹误报：在无异常假设下 sup_t E[E_t] ≤ 1 ⇒ 对任意停时 τ，P(∃t≤τ: 告警) ≤ α。这样能检出单步不可见、但累积可见的洗白攻击。**单步 p 值不可叠加，e-value 可叠加**——这是对定义 323-a 的正面回应。

**定义 325（单调降级梯 §）** 在 R66–R69 的降级梯上增加一级：若 und 无法在预算内裁决，或 SCD 越界，或人类可靠度后验低于阈值，则进入 **VIGIL-fallback**：只执行有证书的最低能力策略（在 R69 定义 307 的 λ floor 上再乘保守因子 γ_v ≤ 1），并把「无法裁决」写入证书。安全侧单调不升。

**定义 326（证书 J_VIGIL）** J_VIGIL = (J_FLUID, boundary_hash, conformal_coverage, fdr_hat, triage_distribution, trust_state(β), human_reliability_posterior, scd, escalation_log_hash, vigilance_state, vigil_ver)。Valid ⇔ Valid(J_FLUID) ∧ 覆盖性检查通过 ∧ 人类可靠度 ≥ τ_h ∧ SCD ≤ τ_scd ∧ 预算未越界。

# IP-264/265 LBR+CAD：带参考系的共形三值判定
def licensed_triage(x, boundaries, scorers, alpha_hi, alpha_lo):
    B = select_boundary(x, boundaries)            # 作用域匹配；多个则取最保守
    if B is None or not in_scope(x, B):           # 越出 E_env/E_task
        return "oos", None                        # 无参考 ≠ 异常
    ps = [conformal_p(scorer, x, B.calib) for scorer in scorers]
    if not agree_direction(ps): return "und", B   # 单评分器伪影 → 待定
    p = min(ps)                                   # 取最保守（最小 p）需多评分器一致
    if p > alpha_hi: return "in", B
    if p <= alpha_lo and warranted(x, B): return "out", B
    return "und", B

# IP-266 AID：安全激励分离 novel/fault/noise/drift
def active_diagnosis(x, o, hypotheses, budget):
    best = None
    for g in probe_candidates(x, o):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o): continue
        ig = mutual_info(hypotheses, response_model(g, o))
        score = ig - cost(g)
        if best is None or score > best.score: best = (g, score)
    if best is None or best.score <= 0: return None, hypotheses
    y = execute_safe_probe(best.g)                # 可逆、有界、不改安全包络
    return best.g, bayes_update(hypotheses, y)

# IP-267/268 HRM+TCD：按类别可靠度决定让步，而非固定「人优先」
def calibrated_deference(p_anom, h_signal, hrm, risk_level):
    sens, spec = hrm.predict(h_signal.cls, h_signal.workload, h_signal.vigilance)
    # 非对称损失：危险环境漏检代价 >> 误警代价
    lam_o = base_loss * risk_level
    best_beta, best_L = 0.0, inf
    for beta in grid(0, 1, 0.05):
        p_miss = (1 - beta) * p_anom * (1 - sens) + beta * p_anom * (1 - sens) * spec
        p_fa   = (1 - beta) * (1 - p_anom) * spec + beta * (1 - p_anom) * (1 - spec)
        L = lam_o * p_miss + 1.0 * p_fa + 0.1 * beta      # 升级成本
        if L < best_L: best_beta, best_L = beta, L
    return best_beta, best_L

# IP-269 SCD：监测共同基底分歧，而非只看单侧
def collaboration_anomaly(B_r, B_h_history, window):
    D = boundary_distance(B_r, B_h_history[-window:])
    silent = D.trend > tau_trend and not any_escalated(window)
    return D, silent                              # 沉默扩大 = 协作异常

# IP-273 CEL：随时有效的累积证据，抗洗白
def update_ledger(ledger, p_t):
    ledger.E *= min(1.0 / max(p_t, 1e-12), 1e6)   # 截断防爆
    if ledger.E >= 1.0 / alpha:                    # e-process 触发
        return "cumulative_anomaly"
    return "ok"

# IP-276 主闭环（继承 R69，仅在裁决处插入 VIGIL 层）
def VIGIL_RAS_round(M, obs):

## 3. 推导

**引理 19（无自证 / 参考系不可内生化）** 设检测器 h 仅由 D_ref 训练，其 in-区域 I_h = {x : p_h(x) > α}。则存在一个联合分布 P′，使 P′ 在 I_h 上的边缘与由 D_ref 诱导的边缘在 h 的检验统计量下不可分，但任务失败率可显著不同；任何只依赖 (h, D_ref) 的决策都无法区分二者。要点：D_ref 中所有点按构造都标为正常，而 I_h ⊋ D_ref；I_h \ D_ref 从未被标注，却被 h **隐式认证为正常**。故「正常」必须由外部参考（人类 / 主动干预 / 物理先验）补足。**系：人机协作不是交互设计问题，而是异常检测的可辨识性条件。**

**引理 20（三值裁决的贝叶斯最优性与 und 带宽）** 在「漏检代价 λ_c、升级代价 λ_e、误警代价 λ_f」的损失下，给定人类可靠度，最优裁决是对 p 值（或后验异常概率）的两阈值规则；und 带宽度随 λ_e/λ_c 与人类可靠度变化：λ_e → 0 时 und 带变宽（多问），人类可靠度 → 0 时 und 带收缩为直接保守。**系：R69「只问歧义、不问胜任度」等价于把 α_hi = α_lo = 0 且不允许 und——它把「自信地错」排除在决策空间之外。**

**引理 21（累积证据的 anytime 有效性）** 若每个无异常步的 e-value 满足条件期望 ≤ 1，则对任意停时 τ，P(∃t≤τ : E_t ≥ 1/α | 无异常) ≤ α（Ville 不等式）。故定义 324 能以受控误报检出洗白式慢漂移；而单步 p 值的朴素多重比较会随 T 线性膨胀误报。**系：异常检测必须「记账」，不能只看当下这一帧。**

**定理 18（VIGIL 对 FLUID 的严格包含）** 当所有观测落在有据 in 区（d = in、无累积告警、SCD ≤ τ_scd、人类可靠度 ≥ τ_h）时，VIGIL 与 R69 逐指令相同（γ_vigil(in) = 1）；一般情形下，VIGIL 的期望风险 ≤ R69，因为它在 und 处只增加外部证据（主动诊断/人类）或单调降级，且降级不改变 R69 的安全包络、只收紧 λ。**R69 是「异常检测永远沉默且人类永远可靠」的边界退化。**

**定理 19（人机互补的可检测性）** 设机器检测器对异常类 c 的敏感度为 se_m(c)、人类为 se_h(c)，二者漏检事件相关 ρ_c < 1。则并联（OR，任一方报警即升级）漏检率 ≤ (1−se_m)(1−se_h) + ρ_c·min(se_m, se_h)，串联（AND，双方一致才放行）误报率 ≤ …。**系：存在一个按类别分配的「谁来判」规则——把每类异常交给更敏感且更可靠的一方，优于任何固定的「人优先/机优先」；这是协作优于单方的形式化来源，也解释了为什麼 β 必须按类别而非全局设定。**

**定理 20（信任校准的安全-效率前沿）** 在非对称损失 L(β) 下，若人类可靠度属于 (0,1) 且危险度有限，则最优让步 β* 为内点解，且 ∂β*/∂se_h > 0、∂β*/∂(环境危险度) < 0；过信侧（β > β*）的风险对危险度的导数大于欠信侧。**系（告警预算）：** 给定人力预算 M 与警觉衰减 v(t)，最优策略是「把升级分配给边际漏检下降/注意力成本最大的类别」，且当 v(t) 低于阈值时最优动作是换人/休息而非加大告警强度——**在疲劳后期加密告警，期望漏检不降反升（去敏感化）。**

## 6. 本轮最大风险

**一句话**：VIGIL-RAS 的全部收益押在「人类是一个与机器错误不相关的外部参考」这一前提上——**若人本身系统性失准、被工作负荷压垮、或与机器共享同一个错误前提，那么「已向人类求证」只会把一次未被发现的异常，升格为一次被社会性背书的异常；系统会从「自信地错」变成「有见证人地错」，而共同基底分歧监测本身也依赖对这个人边界的估计，形成二阶自指**。

**次级风险与缓解**：
1. **检测器自证幻觉**（把 in-区域当成安全域）→ 引理 19 的结构性约束 + 主动干预作外部参考 + oos 与 out 分离；
2. **异常洗白/慢性漂移** → CEL anytime-valid e-process（定义 324、引理 21）+ 累积账本入证书；
3. **告警洪泛与警觉衰减** → VAM 告警预算 + 换人/休息优先于加大告警（定理 20 系）；
4. **过度监测人类（隐私/尊严滑坡）** → RMP 最小充分统计量硬预算（定义 322）+ E314 审计；
5. **解释退化为劝说** → XC 以校准而非满意度度量（定义 321）+ E308 人类研究；
6. **实时预算被评分器集成击穿** → 共形查询 O(1)、先裁决后采样、und 才触发诊断与升级。

**定义 313–314（有据异常与三值裁决）** `WAn=(p≤α,B,w,c_cov)` 且通过覆盖性检查，否则不升级；裁决 `d∈{in,out,und}`，`und`（拒判）是一等动作，`oos` 独立。

**定义 315（AID）** 被动不可辨识；安全激励 `g*=argmax[I(ℋ;y|g)−c]`，过后 C-RAS-WM 认证与预算；最大后验 < τ_hyp 则升级人类。

**定义 316–317（HRM 与 TCD）** 人类按类别有混淆矩阵且漂移；让步 `β*=argmin[λ_o·P(漏检|β)+λ_u·P(误警|β)+c_esc·E[升级]]`；`∂β*/∂se_h>0`、`∂β*/∂危险度<0`。

**定义 318–319（反向异常与 SCD）** 人也会异常（疲劳/对抗/共谋），设反向通道但受预算；协作异常 = `D=d(B_r,B_h)` 沉默扩大或被压制（自动化偏见）。

**定义 320–321（VAM 与 XC）** 警觉 `v(t)` 衰减；调度 `{escalate,batch,defer,rotate}`；解释以校准 `I(B_h;evidence|e)−γ·persuasion` 度量，非满意度。

**定义 322–323（RMP 与威胁）** 互监对称、授权不对称，机器人监测人限最小充分统计量；`ℰ_VIGIL=ℰ_FLUID×ℰ_launder×ℰ_flood×ℰ_collude`（洗白/洪泛/共谋）。

**定义 324–326（CEL / 降级梯 / 证书）** e-process anytime-valid 抗洗白；und 未裁决或 SCD 越界或人不可靠 ⇒ `VIGIL-fallback`（λ floor × γ_v≤1）；J_VIGIL 并入边界哈希、覆盖、信任态、HRM 后验、SCD、警觉态。

## 3. 关键算法伪代码

```python
# IP-264/265 许可边界 + 共形三值裁决（先于策略：胜任度先于歧义）
def licensed_triage(x, boundaries, scorers, a_hi, a_lo):
    B = select_boundary(x, boundaries)
    if B is None or not in_scope(x, B): return "oos", None    # 无参考 ≠ 异常
    ps = [conformal_p(s, x, B.calib) for s in scorers]
    if not agree_direction(ps): return "und", B               # 单评分器伪影
    p = min(ps)
    if p > a_hi: return "in", B
    if p <= a_lo and warranted(x, B): return "out", B
    return "und", B

# IP-266 主动分离诊断：安全激励区分 novel/fault/noise/drift
def active_diagnosis(x, o, hyp, budget):
    best = max(((g, mutual_info(hyp, response_model(g, o)) - cost(g))
                for g in probe_candidates(x, o)
                if budget.allow(g) and c_ras_wm.certify_info(g, o)),
               key=lambda t: t[1], default=None)
    if best is None or best[1] <= 0: return None, hyp
    return best[0], bayes_update(hyp, execute_safe_probe(best[0]))

# IP-267/268 按类别可靠度做让步（非固定「人优先」）
def calibrated_deference(p_anom, sig, hrm, risk):
    se, sp = hrm.predict(sig.cls, sig.workload, sig.vigilance)
    lam_o = base * risk
    return min(((beta, lam_o*((1-beta)*p_anom*(1-se) + beta*p_anom*(1-se)*sp)
                 + (1-p_anom)*sp + 0.1*beta) for beta in grid(0, 1, .05)),
               key=lambda t: t[1])                    # → (β*, L*)

# IP-269 共同基底分歧（监测协作本身是否异常）
def scd(B_r, B_h_hist):
    D = boundary_distance(B_r, B_h_hist[-W:])
    return D, (D.trend > tau_trend and not any_escalated(B_h_hist[-W:]))

# IP-273 累积证据（随时有效，抗洗白）
def update_ledger(E, p_t, alpha):
    E *= min(1.0 / max(p_t, 1e-12), 1e6)
    return E, (E >= 1.0 / alpha)

# IP-276 主闭环（继承 R69）
def VIGIL_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    d, B = licensed_triage(obs, M.lbr.boundaries, M.cad.scorers, A_HI, A_LO)
    E, cum = update_ledger(M.cel.E, M.cad.p(obs), ALPHA)
    if d == "out" or cum: return M.vigil_fallback(...)          # 单调降级
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    if d == "und":
        g, hyp = M.aid.active_diagnosis(obs, o, M.aid.hypotheses, M.budget)
        if hyp is None or max(hyp.values()) < TAU_HYP:
            beta, _ = M.tcd.calibrated_deference(1 - M.cad.p(obs),
                                                 M.hrm.signal(o), M.hrm, M.risk)
            if beta > TAU_BETA and M.vam.can_escalate():
                ans = M.vam.escalate(explain=M.xc.build(...)); M.hrm.update(ans)
    D, silent = M.scd(M.lbr.current, M.hrm.bh_history)
    if silent or D > TAU_SCD:
        M.vam.request_recalibration(); return M.vigil_fallback(...)
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor)) * gamma_vigil(d)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa.submit_async(d, g, D, M.tcd.state, M.hrm.posterior)
    return k, lam, mode, (U_ale, U_epi, d)
```

## 4. 推导

**引理 19（无自证 / 参考系不可内生化）** 仅由 D_ref 训练的检测器 h 的 in-区域 `I_h={p_h>α}` 是评分的下水平集，`I_h ⊋ D_ref`；`I_h\D_ref` 从未被标注，却被 h 隐式认证为正常。故存在在 h 统计量下与 D_ref 不可分、但任务风险显著不同的世界 P′，任何只依赖 (h, D_ref) 的决策都无法区分。**系：人机协作是可辨识性条件，而非交互设计。**

**引理 20（三值裁决最优性与 und 带宽）** 漏检代价 λ_c、升级代价 λ_e 下的最优裁决是两阈值规则；`λ_e→0` 时 und 带变宽，人类可靠度 → 0 时 und 带收缩为直接保守。**系：R69「只问歧义、不问胜任度」等价于禁用 und。**

**引理 21（累积证据 anytime 有效）** 无异常步 `E[e_t|F_{t-1}]≤1` ⇒ 对任意停时 τ，`P(∃t≤τ:E_t≥1/α)≤α`（Ville）。故 e-process 能以受控误报检出洗白慢漂移；单步 p 值朴素多重比较则误报随 T 线性膨胀。

**定理 18（VIGIL 严格包含 FLUID）** 全 in 且人可靠、`SCD≤τ_scd` 时 VIGIL≡R69（`γ_vigil(in)=1`）；一般情形期望风险 ≤ R69，因为异常层只在 und 补外部证据或单调降级，只收紧 λ、不改安全包络。R69 = 「检测永远沉默且人永远可靠」边界退化。

**定理 19（人机互补可检测性）** 机器/人类对类 c 敏感度 `se_m, se_h`，漏检相关 `ρ_c<1`；并联漏检 `≤(1−se_m)(1−se_h)+ρ_c·min(se_m,se_h)`。**系：按类别分配「谁来判」优于任何固定人优先/机优先，解释了 β 必须按类别设定。**

**定理 20（信任校准安全-效率前沿）** 非对称损失下 β* 为内点解，`∂β*/∂se_h>0`、`∂β*/∂危险度<0`，过信风险对危险度的导数更大。**系（告警预算）：** 给定预算 M 与 `v(t)`，升级应分配给边际漏检下降/注意力成本最大的类；`v(t)` 低于阈值时最优是换人/休息，加密告警在疲劳后期期望漏检不降反升。

## 7. 本轮最大风险

**一句话**：VIGIL-RAS 的全部收益押在「人类是与机器错误不相关的外部参考」这一前提上——**若人系统性失准、被负荷压垮、或与机器共享同一个错误前提，「已向人类求证」只会把一次未被发现的异常升格为一次被社会性背书的异常；系统从「自信地错」变成「有见证人地错」，而 SCD 监测本身也依赖对这个人类边界的估计，形成二阶自指**。

**次级风险与缓解**：检测器自证幻觉（引理 19 + 主动干预 + oos/out 分离）；异常洗白（CEL e-process + 入证书）；告警洪泛/警觉衰减（VAM 预算 + 换人优先）；过度监测人类（RMP 最小充分统计量 + E314）；解释退化为劝说（XC 校准度量 + E308）；实时预算被评分器集成击穿（共形 O(1) 查询 + 先裁决后采样）。
