# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「腕部相机」×「多视角视觉」）

> R69 问出「我该向谁求证、还能问什么」，把不确定性拆成 aleatoric/epistemic，并让信息动作 g=(g_gaze, g_probe, g_ask) 与任务动作 a 一起生成。但它把 g 放进了乘积空间 𝒜_task × 𝒜_info，隐含假设「看」是一个**自由变量**；而且 VoI 是在一个**学习得到的模态后验**上算的——这恰是 R69 自陈最大风险（流模型幻觉模态 → 自信地追问幻影）的根源。
>
> 本轮两个灵感从**物理侧**拆掉这两个假设：
> - **腕部相机**把视点装在末端执行器上：视点不是独立传感器，而是**同一个手臂动作的结果**。想换视角，就必须动那只正在干活的手；
> - **多视角视觉**给出**几何的**（而非学习的）信息量：视差、三角化、对极一致性。VoI 因此可由物理量闭式计算，不再依赖可能幻觉的模态分布。
>
> 核心命题：**视角不是观测通道，而是一个有代价、有副作用的动作；当视角腕载时，「看」与「做」共享同一组自由度，信息与控制是 Pareto 耦合而非可加。** 命名 **PARALLAX-RAS**（Parallax-Aware Risk-adaptive Active eXploration）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我该站在哪里看、值不值得移动身体去换这一点信息**」——视差既是几何量，也是世界观的位移。

## 0. 直觉与动机

**灵感 1（腕部相机 → 视点即动作）**
直觉：外部相机是「上帝视角」，看与做天然解耦；腕部相机是「第一人称」，它的位姿 T_w(t)=FK(q_t)·T_mount 完全由手臂构型决定。你无法「只转头不动手」——手腕一动，末端执行器就动，抓取可能失败、碰撞可能发生、任务进度可能倒退。于是 R69 的乘积假设破了：信息动作不是独立的 g，而是任务动作在配置流形上的一个**分量**。这把「主动感知」从「增加一个注视自由度」变成「**在任务轨迹上做信息—进度折中**」。旧问题「看哪里」被替换成更难也更真的问题「**动多少身体去看**」。

**灵感 2（多视角 → 视差是物理信息，不是学习后验）**
直觉：单目深度有尺度歧义；两视角一有基线 b，深度由视差 δ=f·b/d 确定，三角化方差 σ_d²∝d⁴/(f²b²)。于是「移动手腕能换来多少深度信息」有**闭式答案**：IG=½log(σ_d²(b₀)/σ_d²(b₁))。它不经过任何学习到的模态分布，因此 R69 的「幻觉模态驱动错误追问」在几何子问题上被**结构性绕过**。R69 的 VoI 是「相信模型」，R70 的 VoI 是「相信三角学」。这是本轮最重要的理论收益：把一部分 epistemic 从「学出来的信念」迁移到「量出来的几何」。

**灵感 3（时空统一 → 单腕相机 + 运动 = 时间多视角）**
直觉：不必装多台相机。腕部相机随手臂运动，天然在时间上形成一串视点，等价于一个**移动基线立体**（structure-from-motion）。空间多视角（外置相机，静态基线 b_e）与时间多视角（腕相机运动，动态基线 b_t=‖p(t₁)−p(t₂)‖）是同一件事的两个端点。于是「多视角视觉」被推广为**由机器人自身运动生成的空—时视角流形**——而生成这个流形的控制变量，正是我们本来就要优化的动作轨迹。这一点让「视角规划」与「任务规划」不是两个模块，而是同一次轨迹优化的两个目标。

**灵感 4（对偶通道 → 第三个正交证据源）**
直觉：R68 用时间残差 r_res 测「传感器自洽」，R69 用流似然 Δa 测「行为自洽」，两者都可能被缓变故障以不同方式骗过。多视角给出第三条正交通道：**空间几何自洽** ρ_pcs（对极残差 + 去除可解释视差后的重投影残差）。单台相机被标定偏移时，它与其他视角的对极几何会对不上——这是时间残差与策略似然都测不到的。三通道 (r_res, Δa, ρ_pcs) 的联合签名，能把「噪声 / 策略 OOD / 外参漂移 / 单视角失效」分开，并且**定位到哪一台相机坏了**。

**灵感 5（双刃剑 → 退化视觉区域制造「虚假确定性」）**
直觉：几何信息不是免费的真理。无纹理、透明、反光、重复纹理、自遮挡会让匹配**悄悄失败**：对极残差很小，但对应点是错的——系统得到「一致性很好」的假象，于是自信地把手腕移到一个什么也看不清的位置，还把幻影深度三角化出来。这正是 R69「问错比不问更危险」的视觉版：**看得见不等于看得清；看不清时的「看起来一致」，比不一致更危险**。本轮必须同时交付：退化度估计、本体像素屏蔽、最小基线约束、以及「几何证据不得由单视角/单次移动单独定案」的纪律。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（PARALLAX-RAS 总览）** PARALLAX-RAS = (WAC, MVG, ABV, ECC, PCS, DAR, VMB, RAS-WM†)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **视角—动作不可分**：不存在自由漂浮的信息动作；任何视角变化都是配置变化，必须计入任务状态、碰撞包络与交互预算（R69 的交互预算被强化为**配置预算**）；
(iii) **几何证据纪律**：跨视角一致性结论必须条件于退化度估计；只有通过纹理/视差/遮挡/自遮挡检查的**有效几何 VoI** 才能驱动视角动作；单视角、单次移动不得单独定案。

**定义 311（具身观测模型）** 腕相机位姿 T_w(t)=FK(q_t)·T_mount∈SE(3)，外置相机位姿 T_e 固定。观测 o_t={I_t^w, I_t^e}。关键：I_t^w 是已执行配置历史 q_{t−H:t} 的**泛函**，故
o_t^w = Render(Scene; FK(q_{t−H:t})·T_mount)，
即**观测依赖动作历史**。因此信息动作不属于独立的 𝒜_info，而是任务动作在配置流形上的提升：g ∈ T𝒜_task，`𝒜_info ⊂ T𝒜_task`。R69 的 `ξ=(a,g)∈𝒜_task×𝒜_info` 只在其为积空间的边界成立。

**定义 312（视差与解析信息量）** 场景点深度 d、基线 b、焦距 f、像素噪声 σ_pix：视差 δ=f·b/d；三角化深度方差
σ_d²(d,b) = d⁴ σ_pix² / (f² b²)。
从基线 b₀ 移动到 b₁（外置相机给静态 b_e，腕部运动给动态基线增量）对深度/尺度的信息增益
IG_geo(b₀→b₁) = ½ log(σ_d²(b₀)/σ_d²(b₁)) = log(b₁/b₀)。
这是**闭式、可测、无需学习后验**的 VoI；对角点/位姿等其他几何量，用相应 Fisher 信息 / 协方差传播替换即可。

**定义 313（退化度）** 退化度 D∈[0,1] 由无纹理（低梯度能量）、重复纹理（自相似）、透明/反光、运动模糊、遮挡比例、光照突变回归得到。有效信息量
IG_eff(a) = IG_geo(a) · (1 − D(o_t))。
当 D→1，几何 IG 不可信；此时**不许**用 IG 驱动视角动作（对应 R69 的 MCG 门，但门控对象从「模态 ECE」换成「几何可辨识度」）。

**定义 314（主动基线视角规划 ABV）** 以任务轨迹 τ 为变量，联合优化
max_τ  E[Σ_t R_task(s_t,a_t)] + β·IG_eff(subgoal; τ)
s.t.  a_t∈𝒜_safe(q_t),  配置预算 ‖q_{t:t+H}−q_t‖ ≤ ε_q,  耦合干扰 ≤ ε_intr。
由于信息与任务进度不可无损标量化，保留小规模 Pareto 集 Π_ε，用风险规则（CVaR 或最坏情形）在 Π_ε 上选点，而非固定加权和。

**定义 315（对极跨视角标定 ECC）** 对匹配点对 x_i^w、x_i^e，对极残差 r_epi,i = (x_i^e)ᵀ F x_i^w，其中 F=F(K_e, T_e⁻¹T_w(t), K_w)。用鲁棒（Huber/IRLS）最小化 Σρ(r_epi,i) 在线估计腕部外参扰动 δT_mount∈se(3)（机械柔顺导致的慢漂移）。ECC 输出外参估计与其协方差，供 PCS 与安全包络使用。

**定义 316（视差一致性分 PCS / 第三意见）** 用预测深度/视差把腕视角 warp 到外置视角，先减掉**可解释视差**，再取鲁棒重投影残差：
ρ_pcs = RobErr( W(I^w; d̂, T_w→e) − I^e ) ⊕ ‖r_epi‖。
ρ_pcs 只度量「几何解释不了的部分」。三通道判据：
- r_res 低、Δa 高、ρ_pcs 低 → 传感器与几何都自洽，疑似策略/OOD；
- r_res 低、Δa 低、ρ_pcs 高 → **外参漂移/单视角失效**（R68/R69 都看不见）；
- r_res 高、Δa 低、ρ_pcs 低 → 观测噪声（aleatoric）；
- 三者皆高 → 场景退化或多源共谋，退回最保守。

**定义 317（深度/尺度歧义消解 DAR）** 单目腕视角下深度只到尺度 s：d=s·d̂，属**感知层 epistemic**（可约，不是噪声）。当动态/静态基线满足
b ≥ b_min(d) = d·σ_pix/(f·ε_d)
时，深度相对误差 ≤ε_d，U_epi^d 视为消解（resolution bonus）。移动手腕因此是「向场景提一个度量问题」：用任务自由度换尺度可辨识性。

**定义 318（视角—运动成本 VMB）** c_view(a) = λ_task·ΔR_task(a) + λ_e·E(a) + λ_c·CollisionRisk(a) + λ_s·Social(a)。净信息价值
VoI_net(a) = IG_eff(a) − c_view(a)。
只有当 VoI_net>0 且非退化时才执行额外视角运动；否则视点保持，走 R69/R68 兜底。注意这与 R69 的 `VoI(g)−c(g)` 形式相似但语义不同：c_view 含**任务进度损失**，因为视角运动就是任务运动。

**定义 319（三通道故障辨识）** 在 A100（给定故障类别时三通道条件独立）下，联合签名 s=(r_res,Δa,ρ_pcs) 可区分四类：观测噪声、策略 OOD、外参漂移、单视角感知失效。用后验 argmax P(fault|s) 或专家规则实现，并输出**可解释的故障定位**（哪一台/哪一自由度）。

**定义 320（自遮挡与幻影几何守卫）** 用本体分割掩码 M_self 屏蔽机器人自身像素；只在非本体像素上算匹配与 PCS。若本体像素占比 >τ_self，或基线 <b_min，或 D>τ_deg，则本次视角动作作废（U_epi^d 保持未消解）。禁止把「手臂在画面里移动」误当作场景视差去三角化幻影结构。

**定义 321（参与式审计 VQAuditor-V）** 审计对象新增视角决策：视角移动是否由退化校正后的真实 IG 驱动、是否误把自遮挡/重复纹理当一致、是否单视角过度信任、是否越配置预算。结论回灌 AuditBuf，成为下一轮 ABV 的成本先验。

**定义 322（退化视觉干扰集 ℰ_degen）** 无纹理、反光/透明、重复纹理、动态遮挡、自遮挡、光照突变、外参柔性漂移、快速腕动下的卷帘快门。并入 AIC：ℰ_PARALLAX = ℰ_FLUID × ℰ_degen。

**定义 323（证书 J_PARALLAX）** J_PARALLAX = (J_FLUID, degeneracy_p95, epi_res_p95, IG_eff_used, phantom_parallax_flag, config_budget_used, cross_view_ece, parallax_ver)。Valid ⇔ Valid(J_FLUID) ∧ 退化门通过 ∧ 幻影几何守卫未触发 ∧ 配置预算未越界。

**定义 324（自适应门控与两级退避）** 若退化（D>τ_deg）或 VoI_net≤0 或 PCS 不可信：禁用 ABV，视点冻结，λ 与 R69 完全相同（未消解 epistemic 视同 aleatoric）。若视角动作成功且 PCS 通过：获得 resolution bonus，U_epi^d 下降、λ 可放松但不低于 R68 的 λ_floor(U_ale)。⇒ R69/R68 是「视点冻结」边界，安全侧永不更弱。

**定义 325（时间多视角）** 单腕相机在时刻 t₁,t₂ 的位姿差给动态基线 b_t=‖p(t₁)−p(t₂)‖（p 为相机光心）。沿轨迹累积的几何信息
IG_traj = ½ Σ_t log(1 + b_t²/(d² σ_pix² f⁻²))，
即运动本身在生成多视角。ABV 的变量因此是轨迹，而非某一帧的注视方向——这是「多视角」从**设备属性**升级为**行为属性**。

**定义 326（严格包含 R69/R68）** 当视角—动作解耦（仅用外置相机，或腕部运动落在任务零空间）时，`T𝒜_task` 分解为独立因子，ABV 退化为 R69 的 `(a,g)` 积空间与 `VoI(g)−c(g)`；当退化/无利可图/预算耗尽时，两者逐指令相同。故 PARALLAX 是 R69 在「视点可自由且几何可信」边界上的退化，安全侧不做让步。

```python
# IP-264 WAC：腕部视角—动作耦合（观测是动作历史的泛函）
def wrist_obs(robot, q_hist):
    T_w = robot.fk(q_hist[-1]) @ robot.T_mount      # 视点由构型决定
    return robot.render_wrist(T_w)                  # 不是自由变量

# IP-265 MVG：解析几何信息量（不经过学习后验）
def geo_information(depth, b0, b1, f, sigma_pix, D):
    sig2 = lambda b: depth**4 * sigma_pix**2 / (f**2 * b**2)
    ig   = 0.5 * math.log(max(sig2(b0), 1e-12) / max(sig2(b1), 1e-12))
    return ig * (1.0 - D)                           # 退化折扣

# IP-266 ABV：主动基线视角规划（信息与任务同一次轨迹优化）
def plan_active_baseline(policy, obs, budget, D):
    if D > TAU_DEG:                                 # 退化 → 不许用几何驱动
        return policy.nominal_plan(obs), None
    cands = policy.sample_trajectories(obs, K=8)
    pareto = pareto_front(cands, key_task_ret, key_ig=lambda t: IG_eff(t, D))
    tau = risk_rule_select(pareto, cvar=0.9)        # 不固定加权和
    a   = tau.first_action()
    if VoI_net(a, D) <= 0 or not budget.allow_config(a):
        return policy.nominal_plan(obs), None       # 无利可图 → 冻结视点
    return tau, a

# IP-267 ECC：在线腕部外参标定（对极残差）
def epipolar_calibrate(matches, T_e, T_w, K_e, K_w):
    def residual(xw, xe, dT):
        F = fundamental(K_e, T_e.inv() @ (T_w @ dT), K_w)
        return xe.T @ F @ xw
    return robust_min(residual, matches, huber=1.345)   # → δT_mount, cov

# IP-268 PCS：去可解释视差后的几何残差（第三意见）
def parallax_consistency(I_w, I_e, depth, T_w2e, matches):
    warp = warp_with_parallax(I_w, depth, T_w2e)    # 解释掉视差
    photo = robust_error(warp, I_e)                  # 只剩不可解释部分
    epi   = robust_norm([x_e.T @ F @ x_w for xw, xe in matches])
    return fuse(photo, epi)                          # ρ_pcs

# IP-269 DAR：尺度歧义消解（移动手腕 = 向场景提度量问题）
def depth_ambiguity(depth_hat, b_now, f, sigma_pix, eps_d):
    b_min = depth_hat * sigma_pix / (f * eps_d)
    return b_min - b_now                            # <=0 表示已消解

# IP-270 主闭环（继承 R69，仅在「视角动作」处插入 PARALLAX 层）
def PARALLAX_RAS_round(M, obs):
    z, o = M.mtm.forward(...)                        # R69 一次前向
    # 1) 三通道证据：时间残差 / 行为似然 / 空间几何
    r_res = M.cof.residual(...)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_cal)
    dT, cov = M.ecc.epipolar_calibrate(M.matches(o), M.T_e, M.T_w, ...)
    rho   = M.pcs.consistency(o.wrist, o.ext, M.depth, M.T_w2e, M.matches(o))
    fault = M.fault_id.classify(r_res, a_hat, rho)   # 定义 319
    # 2) 退化估计 + 自遮挡屏蔽（幻影几何守卫）
    D = M.degen.estimate(o)
    if M.selfmask.fraction(o.wrist) > TAU_SELF or D > TAU_DEG:
        g_plan, a_view = None, None                  # 视点冻结
    else:
        g_plan, a_view = M.abv.plan_active_baseline(M.fmp, o, M.budget, D)
    # 3) 无利可图/超预算 → R69/R68 兜底（视点冻结边界）
    if a_view is not None:
        R_task, U_epi_d = M.dar.resolve(M.depth, M.baseline(), ...)
        lam = M.efs.risk_scale(...)                  # resolution bonus
    else:
        U_epi_d = M.dar.ambiguity(M.depth)
        lam = max(M.efs.risk_scale(...), lam_floor(M.U_ale + U_epi_d))
    # 4) 安全认证与执行（视角动作也过 C-RAS-WM 前缀认证）
    A = g_plan.trajectory if a_view is not None else M.ach.propose(...)
    k = M.c_ras_wm.certified_prefix(A, ..., M.wm_preds)
    if fault in ("extrinsic_drift", "single_view_failure") or M.phantom_flag:
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(A, cov))   # 最保守
    # 5) 参与式审计 + 证书
    M.vqa_v.submit_async(a_view, D, rho, dT, a_hat, M.budget.used)
    return k, lam, A, (D, rho, fault)

# IP-271 三通道故障辨识
def classify(r_res, d_a, rho):
    if r_res < T_RES and d_a > T_A and rho < T_R: return "policy_ood"
    if r_res < T_RES and d_a < T_A and rho > T_R: return "extrinsic_drift"
    if r_res > T_RES and d_a < T_A and rho < T_R: return "sensor_noise"
    return "degenerate_or_compound"
```

## 3. 推导

**引理 19（解析几何信息增益）** 在 A99（朗伯表面、有纹理、刚性场景）下，深度估计的 Fisher 信息 J_d = f²b²/(d⁴σ_pix²)，故从基线 b₀ 增至 b₁ 的 IG 为 ½log(σ_d²(b₀)/σ_d²(b₁))=log(b₁/b₀)，与定义 312 一致；且 ∂IG/∂b>0、∂²IG/∂b²<0：**信息随基线对数增长，边际递减**。系：视角运动存在最优基线 b*，超过 b* 后继续移动手腕只增加任务代价、不增加多少信息——这解释了为何「看得更仔细」不等于「动得更多」。

**引理 20（退化区域的虚假确定性）** 在退化度 D 高的区域（重复纹理/无纹理/透明），正确匹配与错误匹配的像素残差分布重叠，误匹配可给出**更小**的对极残差（孔径问题/自相似）。因此 PCS 的观测误差下界被 D 抬高：E[ρ_pcs | 误匹配] 可低于 E[ρ_pcs | 正确匹配]。结论：**未被退化门控的 ρ_pcs 不可作为一致性证据**；必须先做 D 折扣与本体屏蔽（定义 313、320），否则系统会在「看起来最一致」处得到最错的几何。

**引理 21（视角—动作耦合的信息/进度下界）** 设腕部为增加基线移动 Δ，任务回报的局部损失满足 ΔR_task ≥ κ·Δ（κ 由抓取/接触状态决定，接触越紧 κ 越大）。则任一视角动作的净收益
VoI_net(a) ≤ log(1+Δ/b₀) − λ_task·κ·Δ，
其最优 Δ* ≈ b₀·(λ_task κ)⁻¹ − b₀（当且仅当 λ_task κ b₀<1 时内点存在）。系：**接触/精细操作阶段 κ 大，主动视角几乎总是亏本**——此时应利用「事前的自由空间运动」建立基线，而不是在抓取瞬间抖手腕。这给出一条可执行的设计原则：**把看的时间放在做的间隙，而不是做的时候**。

**引理 22（三通道可辨识性）** 在 A100（给定故障类别时 r_res、Δa、ρ_pcs 条件独立，且各类别的通道均值分离）下，三通道联合似然的最大后验能唯一区分四类故障；二维通道 (r_res, Δa) 无法区分「外参漂移」与「策略 OOD」（二者都表现为 r_res 低、Δa 高），必须引入空间几何 ρ_pcs 才能分离。系：多视角不是 R69 的冗余输入，而是**故障可辨识性的必要条件**。

**定理 18（PARALLAX 严格包含 R69/R68）** 在 A99–A100 下，PARALLAX 在任意状态的期望风险 ≤ R69；且当视角—动作解耦、或 VoI_net≤0、或 D>τ_deg、或配置预算耗尽时，两者逐指令相同（定义 324、326）。因此 R69/R68 是 PARALLAX 在「视点可自由或必须冻结」边界上的退化；安全侧不做让步，效率侧获得解析的 resolution bonus。

**定理 19（幻影几何安全性）** 若本体像素屏蔽、最小基线 b≥b_min、退化门 D≤τ_deg 同时成立，则被接受的三角化深度满足 E[‖d̂−d‖]≤ε_d，且「把手臂自运动误判为场景视差」的概率 ≤ε_phant（由屏蔽掩码召回率与退化门决定）；当任一守卫不成立时视角动作作废、U_epi^d 保持未消解并走 R69 兜底。⇒ 幻影几何不能进入控制，只会退化为保守。

**定理 20（视角动作的无突变性）** 视角动作 g 经 C-RAS-WM 前缀认证（继承 R69 定义 302，并计入配置预算与碰撞包络）后，其物理风险 ≤ε_intr；视角变化只改变**几何证据与模态选择**，不改变安全包络；当 ECC 报外参漂移、PCS 报单视角失效或守卫触发时，λ 单调不降地退化为最保守；提交/换装不变式（R68 定理 15）保持 ⇒ 控制连续、无突变。

## 6. 本轮最大风险

**一句话**：PARALLAX-RAS 把效率收益押在「几何信息模型在真实视觉条件下可信」这一前提上——**几何不是真理，退化区域（无纹理、透明、反光、重复纹理、自遮挡）会让匹配悄悄失败并给出「看起来一致」的假象，于是系统自信地移动身体去「看」，却三角化出幻影深度、在错误的几何上放松 λ；更糟的是，为了看而移动手腕本身可能破坏正在进行的抓取——看得更多，反而做得更糟**。

**次级风险与缓解**：
1. **观察—动作纠缠导致抓取失败** → 引理 21 的 κ 门 + 「在动作间隙建立基线」策略 + E306；
2. **退化区域虚假一致性** → 定义 313 退化门 + 引理 20 + E307，D 越界即冻结视点；
3. **自遮挡/自运动幻影几何** → 定义 320 本体像素屏蔽 + 最小基线 + 定理 19；
4. **外参柔性漂移被吸收** → ECC 在线标定 + PCS 第三通道 + 引理 22；
5. **实时预算被轨迹采样击穿** → ABV 复用 R69 FMP、K=8、仅歧义路径触发 + E313；
6. **过度自信的几何 VoI** → 解析 IG 永远以退化折扣 (1−D) 与配置代价 c_view 封顶，绝不裸用。

```python
        plan, a_view = M.abv.plan_active_baseline(M.fmp, o, M.budget, D)
    if a_view is not None:
        lam = M.efs.risk_scale(...)                          # resolution bonus
    else:
        lam = max(M.efs.risk_scale(...),
                  lam_floor(M.U_ale + M.dar.ambiguity(M.depth)))
    A = plan.trajectory if a_view is not None else M.ach.propose(...)
    k = M.c_ras_wm.certified_prefix(A, ..., M.wm_preds)
    if fault in ("extrinsic_drift", "single_view_failure") or M.phantom_flag:
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(A, cov))
    M.vqa_v.submit_async(a_view, D, rho, dT, a_hat, M.budget.used)
    return k, lam, A, (D, rho, fault)
```

## 4. 推导

**引理 19（解析几何信息增益）** A99 下深度 Fisher 信息 `J_d=f²b²/(d⁴σ_pix²)`，故 `IG=log(b₁/b₀)`，关于 b 单调递增且边际递减。系：存在最优基线 `b*`，超过后继续移动手腕只付任务代价、换不到多少信息——「看得更仔细」≠「动得更多」。

**引理 20（退化区域的虚假确定性）** 无纹理/重复纹理/透明处正确与错误匹配的残差分布重叠，误匹配可给出**更小**的对极残差；故 `E[ρ_pcs|误匹配]` 可低于 `E[ρ_pcs|正确匹配]`。结论：未门控的 PCS 不可信——系统会在「看起来最一致」处得到最错几何。

**引理 21（视角—动作耦合的信息/进度下界）** 增加基线移动 Δ 使任务回报局部损失 `ΔR_task≥κΔ`（接触越紧 κ 越大），故 `VoI_net≤log(1+Δ/b₀)−λ_taskκΔ`，内点 `Δ*≈b₀/(λ_taskκ)−b₀`（仅当 `λ_taskκ b₀<1`）。系：**接触期应冻结视点，把「看」放到动作间隙**。

**引理 22（三通道可辨识性）** A100 下三类通道条件独立且类均值分离，`(r_res,Δa,ρ_pcs)` 的 MAP 可唯一区分四类故障；二维 `(r_res,Δa)` 无法分离「外参漂移」与「策略 OOD」。系：多视角不是冗余输入，而是故障可辨识性的**必要条件**。

**定理 18（PARALLAX 严格包含 R69/R68）** A99–A100 下期望风险 ≤ R69；当视角—动作解耦、或 `VoI_net≤0`、或 `D>τ_deg`、或配置预算耗尽时逐指令相同。R69/R68 是「视点冻结」边界；安全不让步，效率获解析 resolution bonus。

**定理 19（幻影几何安全性）** 本体屏蔽 + `b≥b_min` + `D≤τ_deg` 同时成立时，接受深度满足 `E‖d̂−d‖≤ε_d`，且自运动被误判为场景视差的概率 ≤`ε_phant`；任一守卫失败则视角动作作废、`U_epi^d` 未消解并走 R69 兜底 ⇒ 幻影几何不能进入控制。

**定理 20（视角动作无突变性）** 视角动作过 C-RAS-WM 前缀认证（含配置预算与碰撞包络）后物理风险 ≤ε_intr；视角只改证据与模态选择、不改安全包络；ECC/PCS/守卫触发时 λ 单调不降；换装不变式（R68 定理 15）保持 ⇒ 控制连续、无突变。

## 7. 本轮最大风险

**一句话**：PARALLAX-RAS 把效率收益押在「几何信息模型在真实视觉条件下可信」这一前提上——**退化区域（无纹理、透明、反光、重复纹理、自遮挡）会让匹配悄悄失败并给出「看起来一致」的假象，系统于是自信地移动身体去「看」，却三角化出幻影深度、在错误几何上放松 λ；而且为看而移动手腕本身可能破坏正在进行的抓取——看得更多，反而做得更糟**。

**次级风险与缓解**：观察—动作纠缠（引理 21 κ 门 + 动作间隙建基线 + E306）；退化虚假一致性（定义 313 退化门 + 引理 20 + E307，D 越界冻结视点）；自遮挡/自运动幻影（定义 320 本体屏蔽 + 最小基线 + 定理 19）；外参柔性漂移（ECC + PCS 第三通道 + 引理 22）；实时预算被轨迹采样击穿（复用 R69 FMP、K=8、仅歧义触发 + E313）；过度自信几何 VoI（永远以 (1−D) 与 c_view 封顶，绝不裸用）。
