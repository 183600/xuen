# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；灵感循环第 6 轮；本轮灵感：「视觉问答」×「SLAM」×「机械臂」）

> 第 59 轮解决了「执行侧」的抽象泄漏：把 BLDC 结构性不确定性、嵌入式时钟域鸿沟、阻抗参数安全编译、双向契约闭环、四重预算耦合全部形式化，实现了**「证据层概率安全界 ⇄ 执行层确定性硬约束」**的双向编译。但还有一个更隐蔽、更根本的抽象泄漏：**感知侧**。证据层假设「观测 = 似然 + 已知噪声」，实则：
> - **视觉问答 (VQA)** 输出「语义标签 + 置信度」，但置信度**未经校准**、与证据层的 ECE/共形带体系**不兼容**；VQA 的注意力图、推理链、反事实解释从未被证据层利用。
> - **SLAM** 输出「位姿 + 协方差」，但协方差**仅在局部度量空间一致**，全局存在回环漂移、退化方向、动态物体污染；拓扑语义地图与证据层的区域信念 **坐标系不统一、不确定性不互通**。
> - **机械臂** 在操作中产生「接触力/力矩/触觉/本体」的高维时序观测，但这些**操作感知**从未被纳入证据门体系——第 59 轮的 EV-exec 仅覆盖「腿部接触执行」，**臂端操作感知**是全新的证据模态。
> 本轮核心命题：**「把语义-几何-操作三元感知，统一编译为证据层的结构化观测模型；把证据层的信念不确定性，反编译为感知层的主动观测策略」**——实现**感知-证据双向契约 (PEBC)**。

核心矛盾：
- **H32（语义置信度未校准·证据似然失配）**：VQA 输出 softmax 分布 p(y|x)，但 **ECE(VQA) ≫ 0.1** 且随域偏移剧增；证据层用此作似然会导致后验「过度自信」或「过度保守」；VQA 的**注意力热力图、检索增强证据、思维链推理**蕴含结构化不确定性，**未被证据层结构化似然 (MFSL+) 捕获**。
- **H33（度量-拓扑不确定性鸿沟·信念锚定失效）**：SLAM 给 SE(3) 位姿协方差 Σ_pose ∈ ℝ⁶ˣ⁶，证据层信念定义在 **拓扑区域图 𝒢=(V,E)** 上。**坐标变换不确定性传播**未建模：Σ_pose 如何映射为区域信念的 Dirichlet 参数 α？**回环检测延迟**导致位姿修正滞后于证据决策——「信念锚定在旧坐标系」成为新的证据陈旧性来源。
- **H34（操作感知缺位·接触证据不完备）**：机械臂操作（抓取、推动、组装、工具使用）产生 **6D 力/力矩、高频触觉、指尖视觉、关节本体**——这些是**操作特有的证据模态**，与第 59 轮的腿部 EV-exec 形式不同（前者是主动探索、后者是被动承载）；**工具使用**引入**运动学链扩展**、**动力学参数辨识**、**接触模式切换**——证据层无相应证据门、无结构化似然、无跨模态对账。
- **H35（感知计算预算未显式·主动观测无约束）**：VQA 大模型推理、SLAM 后端优化、触觉信号处理**争抢同一 GPU/NPU/CPU**，证据层的 VOI 计算从未纳入**感知计算成本**；**「看哪里、怎么看、看多久」**应由证据层信念不确定性驱动，但无形式化接口。

## 0. 直觉与动机

**灵感 1（视觉问答 → 语义证据校准 SEC）**
直觉：VQA 不是「分类器」，而是**可解释的语义推理器**。其输出包含：答案分布 p(ans|img,q)、注意力图 Attn(img,q)、检索到的知识条目、思维链 CoT 推理步骤。关键洞见：**这些中间产物可被「编译」为证据层的结构化似然修正**——把 VQA 的「未校准置信度」经**语义共形校准**映射为 **诚实的似然区间**；把 Attention/CoT 解析为 **语义不确定性分解**：aleatoric（视觉模糊/遮挡）vs epistemic（知识缺失/推理跳跃）。于是证据层获得**「语义模态」的诚实似然 L_sem(obs|θ) = [L_low, L_high]**，并能针对 epistemic 部分发起**主动视觉提问**（如「请看左上角」）。

**灵感 2（SLAM → 几何证据锚定 GEA）**
直觉：SLAM 不是「定位器」，而是**带不确定性的度量-拓扑映射器**。前端给帧间相对位姿约束、后端给全局一致位姿、回环给拓扑约束、语义 SLAM 给物体级地标。关键洞见：**把 SLAM 的不确定性「推」到证据层的拓扑区域信念**——利用**李群上的不确定性传播**（SE(3) 协方差经 Adjoint 映射到区域概率单纯形）；利用**回环检测触发的「信念重锚定」事件**作为证据层的 **结构化证据 EV-slam**（含位姿修正量、协方率缩减率、退化方向投影）。于是证据层的区域信念获得**「几何模态」的度量级校准**，且能感知「定位退化 ⇒ 信念扩散」。

**灵感 3（机械臂 → 操作证据合成 MES）**
直觉：机械臂操作不是「轨迹执行」，而是**主动触觉探索与接触推理**。抓取前的「预触觉靠近」、抓取时的「力/力矩特征演化」、工具使用中的「传递阻抗辨识」、组装中的「配合误差分布」——每个阶段都产生**高维、时序、模态耦合**的观测。关键洞见：**把操作过程建模为「证据采集 POMDP」**，每个动作原语（reach, grasp, push, insert, tool-use）对应一个**结构化观测模型** L_manip(obs|θ, ξ_arm)，其中 ξ_arm 包含：末端阻抗参数、工具运动学、接触模式、触觉传感器标定。于是证据层获得**「操作模态」作为第 6/7 个模态**，并能触发**「主动操作探针」**（如「轻推测试刚度」「换指尖触觉传感器」）。

**灵感 4（三灵感合流 → 感知-证据双向契约 PEBC）**
直觉：SEC 给语义似然区间、GEA 给几何锚定证据、MES 给操作观测模型 → 统一接入 **MFSL+++（元小样本推断++）** 与 **XMC+++（跨模态对账+++）**。反向：证据层的 **信念熵 H(b[region])、分歧 D⁺、OOD 状态、探针预算 B_probe** → 编译为感知层的 **主动观测策略**：VQA 提问模板选择、SLAM 关键帧/回环优先级、机械臂探索动作序列。形成闭环：**信念不确定 → 主动感知 → 结构化观测 → 信念更新 → 不确定性降低**。

**灵感 5（PCE++++ → 五重预算耦合：探针/微调/解释/执行/感知）**
直觉：第 59 轮已有 B_probe, B_ft, B_ux, B_exec；本轮新增 **B_percep（感知预算：GPU/NPU 算力、内存带宽、相机/激光/触觉带宽、注意力时隙）**。PCE++++ 在 VOI 中显式扣除 **感知成本**：voi_percep = VOI_meta_pessimistic − cost_percep(active_vqa, active_slam, active_manip)；若感知预算不足，自动退向「低分辨率/低帧率/仅本体感知」的**降级感知模式**，并同步膨胀证据层共形带。

## 1. 形式化定义（增量：定义 153–160）

**定义 153（语义证据校准 SEC）** VQA 系统 VQA_θ：输入 (img, question) → 输出 (ans_dist, attn_map, cot_steps, retrieved_docs)。语义共形校准器 SCC：在标定集上学习 **非共形分位数** q_α(sem_type) ——按语义类型（物体/属性/关系/空间/计数）分层校准。结构化似然输出：
```
L_sem(obs|θ) = [ L_low(θ), L_high(θ) ]  // 似然区间，而非点估计
L_low(θ) = max(0, p_calib(ans|θ) − q_α(sem_type))
L_high(θ) = min(1, p_calib(ans|θ) + q_α(sem_type))
```
其中 p_calib 为温度缩放+共形校准后的分布。不确定性分解：
```
U_aleatoric = Entropy(p_calib) − MI(attn_map, cot_steps)   // 视觉固有模糊
U_epistemic = MI(attn_map, cot_steps) + retrieved_docs_divergence  // 知识/推理不确定
```
OOD 判定：U_epistemic > θ_epi_ood ⇒ 触发「语义 OOD 证据」→ 共形保底带 + 主动提问。

**定义 154（几何证据锚定 GEA）** SLAM 系统 SLAM_φ：输出 (poses_graph, cov_poses, loop_closures, semantic_landmarks)。几何-拓扑不确定性传播算子 Γ_GE：
```
α_region = Γ_GE(Σ_pose, region_mesh, 𝒢_topology)
```
其中 α_region ∈ ℝ^{|V|} 为区域信念的 Dirichlet 浓度参数。实现：对每个区域顶点 v，取其 3D 网格顶点集 {p_i}，计算 p_i 在当前位姿分布下的落区概率，聚合为 α_v。退化方向检测：SLAM 协方差特征分解 Σ = UΛU^T，若 λ_min/λ_max < θ_degen ⇒ **定位退化**，触发 EV-slam.degraded=true，证据层对受影响区域信念 **乘性膨胀** α_v ← α_v / (1+κ_degen)。回环修正事件：检测到回环 ⇒ 生成 EV-slam = (Δpose, Δcov_ratio, affected_regions, degraded_flag)，作为**结构化证据**参与 XMC+++。

**定义 155（操作证据合成 MES）** 机械臂操作原语集 𝒪 = {reach, pregrasp, grasp, lift, push, insert, tool_use, handover}。每个原语 o ∈ 𝒪 关联结构化观测模型：

其中 ξ_arm = (K_imp, tool_kin, contact_mode, tactile_cal, joint_friction) 为**臂端执行不确定性状态**（类比第 59 轮 ξ_exec）。在线辨识器 UKF_ξ_arm：过程模型 ξ_{t+1}=ξ_t+w_t，观测模型 y_t=(F_6d, τ_joint, tactile_img, q_joint)。操作证据 EV-manip = (primitive, phase, force_tracking_q99, tactile_consistency, contact_mode_stability, ξ_arm_residual, tool_identified)。模态集扩展 ℳ⁺⁺ = ℳ⁺ ∪ {manip_force, manip_tactile, manip_prop}。

### IP-153 SEC（语义证据校准）

```python
class SemanticEvidenceCalibrator:
    def __init__(self, vqa_model, calib_data):
        self.vqa = vqa_model
        self.scc = SemanticConformalCalibrator(calib_data)
        # 语义类型分类器
        self.sem_type_clf = SemanticTypeClassifier()
    
    def infer_with_calibration(self, img, question):
        # 1. VQA 前向
        ans_logits, attn_map, cot_steps, retrieved = self.vqa(img, question, return_intermediates=True)
        ans_dist = F.softmax(ans_logits / self.temp, dim=-1)
        
        # 2. 语义类型分类
        sem_type = self.sem_type_clf.classify(question, cot_steps)
        
        # 3. 语义共形校准
        p_calib = self.scc.calibrate(ans_dist, sem_type)  # 温度缩放 + 分层共形
        q_alpha = self.scc.get_quantile(sem_type, alpha=0.05)
        
        # 4. 似然区间
        L_low = torch.clamp(p_calib - q_alpha, min=0)
        L_high = torch.clamp(p_calib + q_alpha, max=1)
        
        # 5. 不确定性分解
        H_total = Categorical(p_calib).entropy()
        MI_attn_cot = self.compute_mi(attn_map, cot_steps)
        U_aleatoric = H_total - MI_attn_cot
        U_epistemic = MI_attn_cot + self.retrieved_divergence(retrieved)
        
        # 6. OOD 判定
        is_ood = U_epistemic > self.theta_epi_ood
        
        return SemanticEvidence(
            likelihood_interval=(L_low, L_high),
            p_calib=p_calib,
            sem_type=sem_type,
            attn_map=attn_map,
            cot_steps=cot_steps,
            U_aleatoric=U_aleatoric,
            U_epistemic=U_epistemic,
            is_ood=is_ood,
            q_alpha=q_alpha
        )
    
    def compute_mi(self, attn, cot):
        # 互信息近似：注意力熵与推理步骤一致性
        return (attn * -torch.log(attn+1e-8)).sum() * cot_consistency(cot)
    
    def retrieved_divergence(self, retrieved):
        # 检索文档与当前上下文的 KL 散度
        return kl_div(retrieved.embedding, self.context_embedding)
```

### IP-154 GEA（几何证据锚定）

```python
class GeometricEvidenceAnchor:
    def __init__(self, topo_graph, region_meshes):
        self.G = topo_graph  # 拓扑区域图 (V,E)
        self.meshes = region_meshes  # region_id -> Trimesh
        self.se3_to_topo = SE3ToTopoProjector(self.G, self.meshes)
    
    def propagate(self, pose_graph, cov_poses, cp_region):
```

```python
class ActivePerceptionCompiler:
    def __init__(self, vqa_templates, slam_policies, arm_primitives):
        self.vqa_templates = vqa_templates      # List[VQATemplate]
        self.slam_policies = slam_policies      # List[SlamPolicy]
        self.arm_primitives = arm_primitives    # List[ArmPrimitive]
    
    def compile(self, fused, D_plus_plus, B_percep):
        # 1. 计算每个区域的 VOI/成本
        candidates = []
        
        # VQA 模板候选
        for tmpl in self.vqa_templates:
            for region in fused.regions:
                voi = self.estimate_voi_vqa(tmpl, region, fused, D_plus_plus)
                cost = self.estimate_cost_vqa(tmpl)
                if cost <= B_percep.gpu_slack and voi > 0:
                    candidates.append(('vqa', tmpl, region, voi, cost))
        
        # SLAM 策略候选
        for pol in self.slam_policies:
            voi = self.estimate_voi_slam(pol, fused, D_plus_plus)
            cost = self.estimate_cost_slam(pol)
            if cost <= B_percep.mem_slack and voi > 0:
                candidates.append(('slam', pol, None, voi, cost))
        
        # 臂原语候选
        for prim in self.arm_primitives:
            for region in fused.regions:
                if region.reachable_by_arm:
                    voi = self.estimate_voi_arm(prim, region, fused, D_plus_plus)
                    cost = self.estimate_cost_arm(prim)
                    if cost <= B_percep.arm_slack and voi > 0:
                        candidates.append(('arm', prim, region, voi, cost))
        
        # 2. 贪心选择：按 VOI/成本比排序
        candidates.sort(key=lambda x: x[3] / max(x[4], 1e-6), reverse=True)
        
        plan = ActivePerceptionPlan()
        remaining = B_percep.get_snapshot()
        
        for ctype, obj, region, voi, cost in candidates:
            if self.can_afford(ctype, cost, remaining):
                plan.add(ctype, obj, region)
                remaining = self.deduct_cost(ctype, cost, remaining)
        
        return plan
    
    def estimate_voi_vqa(self, tmpl, region, fused, D_pp):
        # 近似：区域信念熵 × 语义分歧贡献
        H = fused.belief[region].entropy()
        D_sem = D_pp.get_modality_divergence('sem', region)
        return H * (1 + D_sem) * tmpl.informativeness
    
    def estimate_voi_slam(self, pol, fused, D_pp):
        # 定位不确定性 × 几何分歧
        geo_uncert = fused.get_geo_uncertainty()
        D_geo = D_pp.get_modality_divergence('geo', 'global')
        return geo_uncert * (1 + D_geo) * pol.coverage_gain
    
    def estimate_voi_arm(self, prim, region, fused, D_pp):
        # 接触不确定性 × 操作分歧
        contact_uncert = fused.belief[region].contact_entropy()
        D_manip = D_pp.get_modality_divergence('manip', region)
        return contact_uncert * (1 + D_manip) * prim.info_gain
```

```python
def xmodal_fuse_plus_plus_plus(M, region, inf, EV_exec, EV_slam, EV_manip):
    """XMC+++：9 模态跨模态对账"""
    modalities = ['vis', 'sem', 'geo', 'manip', 'exec', 'tap', 'prop', 'acou']
    
    # 1. 贝叶斯更新每个模态
    for m in modalities:
        if m in inf.likelihoods:
            if m == 'sem':
                # 语义似然区间：取中点更新，宽度记入不确定性
                lik = inf.likelihoods[m].midpoint()
                width = inf.likelihoods[m].width()
                M.b[region][m] = bayes_update_with_interval(M.b[region][m], lik, width, w=M.rho[m])
            elif m == 'geo':
                # 几何 Dirichlet：直接作为先验浓度参数更新
                M.b[region][m] = dirichlet_update(M.b[region][m], inf.likelihoods[m].alpha, w=M.rho[m])
            else:
                M.b[region][m] = bayes_update(M.b[region][m], inf.likelihoods[m], w=M.rho[m])
    
    # 2. 执行模态证据融合
    M.b[region]['exec'] = bayes_update_from_evidence(M.b[region]['exec'], EV_exec, w=M.rho_exec)
    
    # 3. SLAM 证据融合
    if EV_slam.degraded_flag:
        M.b[region]['geo'] = inflate_belief(M.b[region]['geo'], factor=1.5)
    if EV_slam.loop_closure_detected:
        M.b[region]['geo'] = relocate_belief(M.b[region]['geo'], EV_slam.delta_pose)
    
    # 4. 操作证据融合
    M.b[region]['manip'] = bayes_update_from_evidence(M.b[region]['manip'], EV_manip, w=M.rho_manip)
    
    # 5. 融合
    fused = Fuse({m: M.b[region][m] for m in modalities}, 
                 {m: M.rho[m] for m in modalities})
    
    # 6. 分歧计算（含所有模态）
    D_pp = disagreement_plus_plus(M.b[region], M.rho)
    
    return M, fused, D_pp

def disagreement_plus_plus(beliefs, rho):
    modalities = ['vis', 'sem', 'geo', 'manip', 'exec', 'tap', 'prop', 'acou']
    D = 0.0
    for i, m1 in enumerate(modalities):
        for m2 in modalities[i+1:]:
            if m1 in beliefs and m2 in beliefs:
                tv = tv_distance(beliefs[m1].label_dist, beliefs[m2].label_dist)
                q_diff = abs(beliefs[m1].quantile(0.99) - beliefs[m2].quantile(0.99))
                w = max(rho.get(m1, 1.0), rho.get(m2, 1.0))
                D += w * (tv + q_diff / MU_SCALE)
    return D
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SEC | VQA 前向 O(L·d²) + 校准 O(1) | O(模型大小) | 语义分层共形覆盖率 ≥ 1−α；U_epistemic 单调于域偏移 |

| MES | UKF_arm O(15³) + 原语似然 O(1) | O(15²) | ξ_arm 辨识收敛契约；操作证据似然诚实包含真实观测 |

### IP-152 BVK（平衡可行性核）

```python
class BalanceViabilityKernel:
    def __init__(self, dyn, sched, alpha_bal=0.01):
        self.dyn, self.sched, self.alpha_bal = dyn, sched, alpha_bal
        self.V_grid = self._offline_viability_grid()   # 离线最大不动点近似

    def _offline_viability_grid(self):
        V = self._safe_set()                            # ZMP/CP/摩擦/关节约束
        while True:
            V_new = self._pre_image(V) & V
            if self._grid_dist(V_new, V) < 1e-3:
                return V_new                            # V̂ ⊆ V：始终偏保守
            V = V_new

    def update(self, x_b, sigma_c, cfg):
        cp = x_b.c + x_b.cdot / cfg.omega0              # 捕获点
        cp_lo, cp_hi = self._conformal_interval(cp, x_b.cov, self.alpha_bal)
        P_viable = self._monte_carlo_viability(x_b, sigma_c, cfg.N, cfg.n_samples)
        m_bal = self._signed_dist_to_capture_boundary(cp_hi, sigma_c)
        is_viable = (cp_hi in self._capture_region(sigma_c)
                     and self.V_grid.contains(x_b, tol=cfg.tol))
        return BalanceEstimate(m_bal, P_viable, cp, (cp_lo, cp_hi),
                               is_viable, self.alpha_bal)
```

### IP-153 BCC（平衡证书编译器）

```python
class BalanceCertificateCompiler:
    def __init__(self, motor, joint_model, env_model, bvk, gait_lib):
        self.motor, self.joint, self.env = motor, joint_model, env_model
        self.bvk, self.gait_lib = bvk, gait_lib
        self.version = 0

    def compile(self, delta_f_bal, x_b, xi_exec, xi_joint, b_r):
        # Boole 风险分配
        d_bal, d_traj, d_zmp = 0.4*delta_f_bal, 0.3*delta_f_bal, 0.3*delta_f_bal
        feasible = []
        for sigma in self.contact_scheduler.candidates(x_b, b_r):
            for gait in self.gait_lib.feasible(sigma, self.motor):
                m = self._check(x_b, sigma, gait, d_bal, d_traj, d_zmp,
                                xi_exec, xi_joint)
                if m is not None:
                    feasible.append((sigma, gait, m))
        if not feasible:
            return None, None                            # Cert_bal=∅ ⇒ BAL_DEGRADE
        sigma, gait, m = max(feasible, key=lambda c: (c[2].progress, c[2].comfort))
        self.version += 1
        cert = BalanceCertificate(
            sigma=sigma, gait=gait, m_bal=m.m_bal, epsilon_zmp=m.eps_zmp,
            P_viable=m.P_viable, horizon=m.N, mu_verified=m.mu,
            alpha_bal=m.alpha, delta_bal=d_bal, xi_exec=xi_exec,
            xi_joint=xi_joint, version=self.version,
            env_hash=hash(str(self.env)), timestamp=time.monotonic())
        return (sigma, gait), cert

    def _check(self, x_b, sigma, gait, db, dt, dz, xe, xj):
        est = self.bvk.update(x_b, sigma, gait)
        if est.P_viable < 1.0 - db: return None
        zmp = self._zmp(x_b, gait)
        if not self._polygon_contains(sigma.support, zmp, margin=dz): return None
        for leg in sigma.active:
            f = self._leg_force(leg, x_b, gait)
            if abs(f.t) > self.mu*f.n or f.n < self.motor.f_min: return None
        if self._angular_momentum_rate(x_b, gait) > self.motor.Ldot_max: return None
        if self._joint_torque_max(gait, xj) > self.motor.tau_max: return None
        if self._tracking_quantile(gait, xj) > dt: return None
        return Margin(progress=gait.progress, comfort=gait.comfort,
                      m_bal=est.m_bal, eps_zmp=dz, P_viable=est.P_viable,
                      N=gait.N, mu=self._mu_analysis(sigma, gait),
                      alpha=est.alpha_bal)
```

```python
class BalanceGate:
    def __init__(self, bvk, m_min, delta_bal, tau_bal):
        self.bvk, self.m_min = bvk, m_min
        self.delta_bal, self.tau_bal = delta_bal, tau_bal

    def gate(self, Pi_H, cert_bal, x_b):
        if cert_bal is None:
            return self._veto(Pi_H, "no_cert")
        if time.monotonic() - cert_bal.timestamp > self.tau_bal:
            return self._veto(Pi_H, "stale_cert")
        est = self.bvk.update(x_b, cert_bal.sigma, cert_bal.gait)
        if est.m_bal < self.m_min:
            return self._veto(Pi_H, "margin_low")
        if est.P_viable < 1.0 - self.delta_bal:
            return self._veto(Pi_H, "viability_low")
        return GateResult(PASS, Pi_H)

    def _veto(self, Pi_H, reason):
        # 否决作用域 = 整条时域，而非当前检查点
        return GateResult(VETO, Pi_H, reason,
                          ["widen_stance", "lower_com", "slow_down",
                           "replan_footsteps", "sit_or_stop"])
```

### IP-155 FCP（可证伪承诺协议）

```python
@dataclass(frozen=True)
class FalsificationCommitment:
    claim: str; benchmark_id: str; heldout_hash: str
    statistic: str; threshold: float; alpha: float; power: float
    n_min: int; stopping_rule: str; retraction: str
    prereg_id: str; t_reg: float

class FalsificationRegistry:
    def __init__(self, ledger):              # 仅追加、不可篡改
        self.ledger = ledger

    def preregister(self, claim, bench, h, T, tau, alpha, power,
                    n_min, stop, retract):
        fcp = FalsificationCommitment(claim, bench, h, T, tau, alpha, power,
                                      n_min, stop, retract, uuid4().hex, time.time())
        self.ledger.append(("PREREG", fcp))
        return fcp

    def evaluate(self, fcp, result, cert_bench):
        if not cert_bench.valid:
            return self._retract(fcp, "benchmark_invalid")
        if not self._heldout_matches(fcp, result):
            return self._retract(fcp, "heldout_hash_mismatch")
        if not self._stop_rule_satisfied(fcp, result):
            return Result("inconclusive")
        p = self._test(fcp.statistic, result)
        if p <= fcp.alpha and result.effect >= fcp.threshold:
            self.ledger.append(("CONFIRM", fcp, p, result))
            return Result("confirmed", p)
        return self._retract(fcp, "test_failed")

    def _retract(self, fcp, reason):
        self.ledger.append(("RETRACT", fcp, reason, time.time()))
        return Result("retracted", reason=reason)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| BVK | 离线 `O(|X|·|U|·\|σ\|)`；在线 `O(N·n_samples)` | `O(\|X\|)` 压缩格点 | 近似核 `V̂⊆V` 偏保守；`P(x_b∈V)≥1−α_bal`；N 步校准 |

| BVM | `O(\|B_test\|·d)` | `O(\|B\|)` | 污染/Goodhart/裁判/跨基准阈值化，失效即全批降级 |
| BBCL | `O(BVK+BCC+第59轮+评测)`/检查点 | 复用+账本 | 平衡门优先、确认/撤回二值、预算单调 |

**正确性定理（Balance-Benchmark Grounded Soundness, BBGS）**
假设 A22–A55 成立；**(A56)** BVK 近似核对真实动力学音保守（`V̂⊆V`），状态不确定性经鲁棒/共形膨胀，跌倒检测无漏报。**(A57)** BCC 约束编译音完备，`Cert_bal` 非空 ⇒ 全时域约束满足且 `P_viable≥1−δ_bal`。**(A58)** BBG 先于所有局部证据门且不可旁路，VETO 作用域为 `Π_H`，局部证据不能放宽 `m_min/δ_bal`。**(A59)** FCP 预注册不可篡改、留出集不相交、统计量/α/功效/停止规则事前固定、失败自动撤回。**(A60)** BVM 各有效性度量诚实，`valid=false` 自动降级为探索性。**(A61)** 五预算单调、互不挪用，`cost_bench` 诚实上界，耗尽只能撤回/降级。则：

1. **全局平衡安全性**：`Cert_bal` 有效且 BBG 通过 ⇒ 时域 `[0,N]` 内 `P_fall ≤ δ_bal+δ_est+δ_ertc`；因跌倒为吸收态，该界对整条轨迹成立。
2. **局部-全局不可越权**：局部承诺即使通过全部局部证据门也不能使 `m_bal<m_min` 或 `P_viable<1−δ_bal`；VETO 时局部承诺全部失效；反之不成立。
3. **可证伪性**：确认性承诺一类错误 `≤α`、功效 `≥1−β`；失败或基准失效 ⇒ 自动撤回，撤回后不得再作佐证。
4. **反 Goodhart**：`Δ_goodhart>θ` 或污染超阈 ⇒ `Cert_bench.valid=false`，该基准上的成功不得升级为确认性证据。
5. **单向保守性**：BBG 只能更保守，基准失效只能降级/撤回；二者不能放松安全边界或减少探针/佐证需求。
6. **终止性**：PCE++++ 在 `k_probes+k_cons+k_ft+k_ux+k_bench` 内终止于 `{承诺(带 Cert_bal/Cert_bench), BAL_DEGRADE, 绕行, 降档, L2 协商, 安全停, 撤回}`。
7. **部署界**：
```
P_safe ≥ 1 − [ δ_bal + δ_est + δ_viab·1[核近似] + δ_ertc·1[契约违例]
             + Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf
                     + δ_xm·1[L1] + δ_ft·1[回滚窗口] + δ_kg·1[检索失败]
                     + δ_ux·1[μ_mis>θ_mis] + δ_exec·1[ξ_exec漂移])
             + δ_bench·1[Cert_bench 失效] + δ_goodhart·1[Δ>θ] ]
         − P(核结构性错误未检出) − P(护盾回退失败)
         − P(τ_int 超时 ∧ 安全停失效) − P(平衡降级失效)
```

## 6. 本轮最大风险

**一句话**：本轮把「平衡可行性」与「基准有效性」同时抬为顶层，但可行性核依赖接触/动力学模型（模型误差、接触时序不确定、非马尔可夫扰动会让近似核不再保守），基准有效性监视本身也可能被污染或被策略间接瞄准（影子泄漏、裁判耦合、留出种子复用）；一旦两套证书同时形式正确而实质失效，就会陷入「有证可依却摔倒 / 有分可刷却未泛化」的双重自欺——必须以「近似核永远偏保守 `V̂⊆V` + 在线可行性回测 + 核外即降级」「平衡门覆盖整条时域且不可旁路」「留出哈希上链 + 独立裁判 + 影子隔离 + 污染/Goodhart 超阈即整批撤回」四重护栏，宁可频繁加宽站姿/坐下/撤回承诺，绝不允许证书齐全却实际跌倒或基准过拟合。
