# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「步态规划」×「长程任务」）

> 第 57 轮把证据门做成五类（EV-probe\*/visit/margin/xmodal/human），并把"跨模态一致"升格为证据；但它有两个从未被写进假设的前提：**(a) 承诺是"点"的、可原地停的**——每个检查点独立判定，判不过就 halt；**(b) 视界是"短"的、可逐点拼的**——每步的失效率用一个常数 δ_f 做联合界即可。**步态规划**恰恰揭穿 (a)：足式/人形机器人的承诺是一条由支撑相、摆动相、触地冲击、离地组成的**混杂轨迹**，你不能在半步腾空时"停"，上一模式的收缩证书会在触地重置（reset）瞬间被放大，逐点安全 ≠ 逐段安全；安全要靠**步级证书的跨模式合成**（reset 包含、guard 正裕度、步到步收缩 ρ<1）。**长程任务**恰恰揭穿 (b)：把 δ_f 对 N 步做 union bound，N=10³ 时保证就真空化；而误差会经 reset 映射累积，短视的逐点 VOI 会先把不可逆预算花在早期，再在后面走进死胡同。本轮两个灵感各补一条腿：**步态规划**把证据从"点"升格为**可合成的步级混杂证书**（SGC）；**长程任务**把"安全"从"每步都不出错"改写成**可随时记账的风险预算**（HRL）＋**非短视探询**（NPV）＋**证据时效**（ETV）。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据承诺"升级为 **"步态可合成、长程可预算、证据有时效的证据承诺"**——**你只能承诺你的步级证书能跨模式合成、且你的风险预算在剩余视界内仍然偿付的量**。

核心矛盾：
- **H32（逐点安全 vs 逐段安全）**：第 57 轮证据门在每个接触点独立判定，隐含"可原地停 + 各点风险可加"；但步态是混杂系统，危险藏在触地重置与支撑切换的瞬间，逐点证书不合成，一次 reset 就能把上一模式的收缩成果放大。
- **H33（短视承诺 vs 长程预算）**：逐检查点贪心承诺 + 常数 δ_f 联合界，在长视界下要么真空（保证失效）要么挥霍（早期花光不可逆预算）；VOI 短视看不见"现在探一次能救后面十步"的期权价值，也看不见"再走两步就是死胡同"。
- **H34（证据新鲜 vs 视界腐蚀）**：证据与地图都会过期；长程任务里，第 1 步的探针证到第 100 步可能已因材质/载荷/季节漂移而失效，但没有机制为"过期"定价，系统仍拿旧证据做新承诺。

## 0. 直觉与动机

**灵感 1（步态规划 → 证书必须跨步合成，而不是逐点拼贴）**
直觉：走路的承诺不是"每一步都踩稳"，而是"这一步踩完之后，下一步一定还接得住"。步态规划给出的正是这条**离散骨架**：接触时序 σ(τ)、落脚点 F、相位 φ。把每个模式内的安全不变集、接触可行性裕度、触地重置映射 R 串起来，才有资格说"这条步态安全"。逐点证据门像"每块砖都合格"，但桥塌不塌取决于**砖怎么搭**——reset 后是否落进下一模式的安全集、guard 穿越是否有正裕度、误差经 R 是否被收缩。于是新增**步级证书**与一种新证据：不是"这个区域可信"，而是"**这条转移可合成**"。

**灵感 2（长程任务 → 安全是预算，不是逐项否决）**
直觉：长视界下"每一步都不许失败"的保证会变得越来越贵（联合界随 N 线性膨胀）。更聪明的问法是：给整段任务预注册一个**可失败质量预算** δ_total，每一步花掉一小块，花超了就降档/缩短视界/受控停。若步态是收缩的（ρ<1），预算可按几何级数分配，尾部自动收敛——**视界再长，预算也有界**（O(1/(1−ρ)) 而非 O(N)）。而且账本要用**随时有效**的记账（Ville/风险超鞅），这样"边走边看证据、随时可能停"不会把统计错误率悄悄抬高。

**灵感 3（长程任务 → 非短视探询与不可逆令牌）**
直觉：第 57 轮的 VOI 是"此刻探一次值不值"，但长程任务里探针的真正价值常常是**期权**：现在多探一次，后面某个不可逆承诺就不必赌；或者现在探一次能提前发现"再走两步就是死胡同"。把 VOI 换成带前瞻的 NPV，并给不可逆接触一个单独的**令牌预算**——不是所有"能过证据门"的不可逆动作都该花，长程要留着令牌给真正没有替代路径的地方。

**灵感 4（证据时效 → 证据会腐烂，复用要过转移算子）**
直觉：证据不是永久资产，而是**会腐烂的库存**。每条证据带三元 scope：适用模式集 Σ_e、适用区域集 R_e、有效期 h_e。跨 scope 复用要过**转移算子**：只有模式兼容且收缩成立，旧证据才打折可用；否则视为空证据。这样"第 1 步的探针"不会被无声地拿去给第 100 步背书，陈旧证据也不能单独过门，只能作为被膨胀的先验。

**灵感 5（合流 → 证据门从五类到七类，PCE+ 升级为路径级）**
直觉：新增 **EV-stride**（存在可合成的步级证书）与 **EV-horizon**（剩余风险账本在剩余视界内仍偿付）。不可逆接触的必要证据集升级为 {EV-probe\*∨EV-margin} ∪ **EV-stride** ∪ 佐证，EV-xmodal 仍限 L1。PCE+ 从"逐检查点探-诺-演"升级为**路径级探-诺-演**：先分配视界预算，再用非短视 VOI 提前探询，承诺时同时检查步级合成、账本偿付与证据新鲜；不偿付就**在承诺之前**降档或缩短视界，而不是走进去再停。安全仍只有两条通道：**信念更准（合成/新鲜/前瞻）**或**动作更保守（更慢步态、更短视界、更早受控停）**。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（步级混杂证书 SGC）** 步态 g=(σ,F,φ)：σ(τ)∈{0,1}^{n_c} 为分段常值接触时序，F={p_i} 为落脚序列，φ∈[0,1) 为相位；对应混杂自动机 H_g=(Σ,X,U,E,G,R,φ)，模式 σ∈Σ 内 ẋ=f_σ(x,u)，E 为模式边，G_{i→i+1}={x:g_i(x)=0, ġ_i<0} 为 guard，R_{i→i+1} 为触地/离地 reset。步级证书 C_i=(V_i,h_i,α_i,ρ_i)：V_i⊆X 为模式 i 的安全不变集（h_i≥0 为 barrier/CBF 证书）；guard 裕度 α_i=min_{x∈G_i}h_{i+1}(R_i(x))≥0（reset 后落进下一模式安全集）；步到步收缩 ρ_i=L_{R,i}·e^{−κ_i T_i}（L_{R,i}=R_i 的 Lipschitz 常数，κ_i=模式内收缩率，T_i=驻留时间）。合成证书 C_g=(C_1..C_N, ρ_g=∏ρ_i, α_g=min_i α_i) 通过 ⇔ ρ_g<1 ∧ α_g≥0 ∧ 非 Zeno（T_i≥T_min）。**证据是模式条件的**：第 57 轮的点证书不含 reset/guard 信息，不能替代 C_g 进入承诺。

**定义 140（长程风险账本 HRL）** 整段任务预注册总失败预算 δ_total∈(0,1)。对剩余 N 段按收缩几何分配 δ_i=δ_total·(1−ρ_g)·ρ_g^{i−1}（ρ_g<1 ⇒ Σ_{i=1}^∞δ_i=δ_total，**与视界无关**）。记账 ℓ_t=1−Σ_{i≤t}r_i/δ_total 为剩余偿付能力，r_i 为第 i 段承诺的**可审计风险上界**（由证据门给出）。承诺许可 ⇔ r_i≤ℓ_{t−1}·δ_total。在安全假设下 E[r_i|F_{i−1}]≤δ_i，故 {Σr_i−Σδ_i} 为超鞅，Ville 不等式给出 P(∃t:Σ_{i≤t}r_i>δ_total)≤δ_total：**无需预知 N、允许随时看随时停**（anytime-valid）。账本枯竭 ⇒ 必须在承诺前补证据（降 r）或降档/缩短视界（降 N），**不得透支**。

**定义 141（证据时效 ETV）** 证据 e=(类, 估计, scope)，scope=(Σ_e 适用模式, R_e 适用区域, h_e 有效期, T_e 转移算子)。新鲜 fresh(e,t)⇔t−t_e≤h_e ∧ 无 change event（材质/载荷/季节漂移检测触发即失效）。陈旧证据不得单独过门，只能作为先验并以膨胀因子 λ_stale(Δ) 加宽风险。跨 scope 复用 e→(r′,σ′) 仅在 σ′∈Σ_e ∨ 兼容(σ,σ′) 且 T_e 残差界 ≤ 预算时成立，否则 scope 为空。刷新记成本 c_refresh，纳入 NPV。

**定义 142（非短视探询价值 NPV）** 前瞻窗口 L 上的探针计划 π 满足
NPV(π|cp_i)=Σ_{j=i}^{i+L} γ_d^{j−i}·[Δr_j^{pess}(π)+λ_opt·O_j(π)+λ_dead·D_j(π)]−Σ_{p∈π}c(p)，
Δr_j^{pess} 为对第 j 段风险上界的保守下降，O_j 为期权价值（少花一个不可逆令牌/少一次 L2），D_j 为死胡同规避价值（提前发现剩余路由不可行），γ_d 为与 ETV 一致的时效折扣。约束：探针预算 k_p、不可逆令牌预算 B_irr、破坏预算 B_destr。NPV 取下置信界做悲观估计，只选 NPV_lcb≥θ_voi 的探针。

**定义 143（可合成证据门 CEG，证据门七类）** 每条证据带 scope 与新鲜度。七类：EV-probe\*（须 ECE_{k_eff}≤ε_meta ∧ scope 新鲜，承 57）、EV-visit、EV-margin、EV-xmodal（限 L1 ∧ 模式兼容 ∧ 新鲜）、EV-human（承 57）、**EV-stride**（∃ 可合成 C_g 覆盖该转移：ρ_g<1 ∧ α_g≥0 ∧ 两端模式兼容）、**EV-horizon**（∃ 剩余路由使 HRL 在剩余视界内可偿付：ℓ_t≥0 ∧ δ 尾部可控）。**不可逆接触必要证据集={EV-probe\*∨EV-margin}∪EV-stride∪佐证**；EV-xmodal 永不进入；EV-horizon 为路径级提交的必要条件。无新鲜证据即拒。

**定义 144（路径级探-诺-演 LHPCE / PCE★）** ①在路由上选步态库并预注册 δ_total 的几何分配；②每检查点：元推断（承 57）→ 步级审计（SGC）→ 时效审计（ETV）→ 前瞻探询（NPV，含刷新与依赖解锁）；③**承诺前**检查：∃g 使 C_g 合成 ∧ 七类证据门过 ∧ 账本偿付 ∧ EV-horizon 覆盖剩余；④不满足：能探则探（NPV_lcb≥θ_voi）→ 不能探则用未花令牌改道（保留账本）→ 降步态档/缩短视界 → L2 协商（τ_int(auth)）→ **受控安全停（绝不在腾空/单支撑相硬停）**；⑤账本每段更新；若预测"剩余路由将透支"，**在当前位置**就降档/缩视界，不把问题推给未来。

## 2. 关键算法伪代码（完整版见产物区）

```python
def stride_certificate(gait, model):                  # IP-139: 跨步合成
    C = []
    for i, (mode, T, R) in enumerate(gait.strides):
        V, h, kappa = solver.invariant(mode, model)    # 模式内安全不变集
        alpha = min_barrier(gait.guard[i], R, V_next)   # reset 后落入下一安全集
        rho_i = model.L_R[i] * exp(-kappa * T)          # 步到步收缩
        if alpha < 0 or rho_i >= 1 or T < T_min: return None
        C.append((V, h, alpha, rho_i))
    return Cert(C, rho_g=prod(c.rho for c in C),        # 合成才可进承诺
                alpha_g=min(c.alpha for c in C))

def ledger_admit(led, r_i):                             # IP-140: 随时有效
    if r_i > led.remaining(): return False
    led.spent += r_i; led.audit.append(r_i)             # Ville 超鞅记账
    return True

def evidence_fresh(e, t, change_det):                   # IP-141
    return (t - e.t <= e.h_e) and not change_det.hit(e.scope)

def npv_probe(route, i, L, led, irr_tokens, budget):    # IP-142: 前瞻 VOI
    best = None
    for pi in probe_plans(route[i:i+L], budget=k_p):
        v = sum(gamma_d**(j-i) * (dr_pess(pi, j)
                + lam_opt*option(pi, j, irr_tokens)
                + lam_dead*deadend(pi, j)) for j in range(i, i+L))
        v -= sum(cost(p) for p in pi)
        if lcb(v) >= theta_voi and v > (best.v if best else -inf):
            best = (pi, v)
    return best

def long_horizon_pce(route, M, meta, personas, budget):  # IP-144
    gait = select_gait_library(route, M)
    Cg = stride_certificate(gait, dynamics)
    led = horizon_ledger_init(budget.delta_total, Cg.rho_g if Cg else 1.0, len(route))
    for i, cp in enumerate(route.checkpoints):
        if not residual_route_feasible(route[i:], led, budget):   # 死胡同前瞻
            route = shorten_or_reroute(route, i, M); continue
        M = meta_infer(M, cp, meta)                                # 承 57
        while (pi := npv_probe(route, i, L, led, budget.irr, budget)):
            M, led = run_probes(M, cp, pi); refresh_stale_evidence(M, cp)
        Cg = stride_certificate(local_gait(cp), dynamics)
        if Cg is None or not ceg_gate(cp, Cg, M, personas, led):
            route = degrade_or_reroute(route, i, M); continue      # 承诺前降档
        if not ledger_admit(led, risk_upper_bound(cp, Cg, M, personas)):
            return controlled_stop(cp, M, reason='budget')         # 受控停
        execute_stride(cp, Cg); M = update_map(M, cp)
    return schedule_complete(M, led)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| SGC | O(N·(T_solve+d_x³)) | O(N·d_x) | reset 包含、guard 正裕度、ρ 诚实（A41） |
| HRL | O(1)/段，初始化 O(N) | O(N) 账本 | δ_total 预注册、Ville anytime-valid（A42） |
| ETV | O(\|E\|) 新鲜度；O(\|E\|²) 转移 | O(\|E\|) | 时效/漂移模型诚实、转移保守（A43） |
| NPV | O(L·\|Π\|·C_VOI) | O(L) | 悲观 LCB、死胡同检测 sound（A44） |
| CEG | O(\|σ\|+N) | O(\|σ\|) | 无新鲜证据即拒、EV-stride 必需 |
| LHPCE | O(N·(k_p·C_NPV+\|Π\|·T_solve)+N·A\*) | O(N+\|σ\|) | 账本单调、探针有界、受控停完备 |

**正确性定理（Gait-composable Horizon-budgeted Soundness, GHS）**：在 A33–A40（第 56–57 轮）之上加 (A41) 步级证书健全：reset 包含、guard 裕度、L_R/κ 诚实且模型误差有界；(A42) 账本预注册且 anytime-valid：δ_total 在任务前固定、E[r_i|F_{i−1}]≤δ_i、不禁后验调账；(A43) 时效与转移诚实：change detector 漏检率 ≤δ_cd、λ_stale 保守；(A44) NPV 用下置信界且死胡同检测 sound。则：
(i) **视界无关的承诺健全性**：P(任意段失败) ≤ δ_total + Σ_i(ε_meta+δ_probe+ε_h)·∏_{j>i}ρ_j ≤ δ_total + (ε_meta+δ_probe+ε_h)/(1−ρ_g)，**当 ρ_g<1 时对 N 一致有界**；
(ii) **暂时有效性**：连续监控与随时停止不抬高第一类错误（Ville/超鞅）；
(iii) **终止性与无死胡同**：每检查点探针 ≤k_p，账本逐段单调下降，故必在有限步内到达 {完成, 改道, 降档, L2, 受控停}；死胡同在不可逆承诺前被检出；
(iv) **交互单调性**：SGC/ETV/NPV/HRL 只经 (a) 更准/可合成的信念或 (b) 更保守动作（更慢步态、更短视界、更早受控停、更少不可逆令牌）影响系统，无升险路径。

## 5. 风险与缓解

## 6. 本轮最大风险

### IP-139 SGC（步级混杂证书与跨步合成）

```python
def stride_certificate(gait, model, slack):
    # gait.strides[i] = (mode_i, T_i, R_i, guard_i)
    C = []
    for i, (mode, T, R, guard) in enumerate(gait.strides):
        V, h, kappa = solver.invariant(mode, model)          # 模式内安全不变集
        V_next = solver.invariant(gait.strides[(i+1) % N].mode, model)
        alpha = min_barrier(guard, R, V_next)                # reset 后落入下一安全集
        L_R = model.lipschitz(R) * (1 + slack.model)         # 保守上界
        rho_i = L_R * exp(-kappa * T) * (1 + slack.rho)
        if alpha < 0 or rho_i >= 1 or T < T_min:
            return None                                       # 不可合成，拒绝进承诺
        C.append(StrideCert(V, h, alpha, rho_i))
    return GaitCert(C, rho_g=prod(c.rho for c in C),
                    alpha_g=min(c.alpha for c in C),
                    non_zeno=all(s.T >= T_min for s in gait.strides))

def reset_inclusion_monitor(x, C_i, model):                   # 在线护栏（缓解 A41 失配）
    ok = C_i.V_next.contains(model.R(x))                     # 实际 reset 是否仍落进安全集
    if not ok:
        model.slack.bump('reset_mismatch')                   # 收紧 ρ 上界并触发降档
    return ok

def stride_transfer(e, mode_from, mode_to):                  # 证据只在模式兼容时跨段
    if not compatible(mode_from, mode_to): return None
    return inflate(e, lam_mode(mode_from, mode_to))
```

### IP-140 HRL（长程风险账本与 anytime-valid 记账）

```python
def horizon_ledger_init(delta_total, rho_g, N):
    delta_total = preregister('delta_total', delta_total)    # 预注册，禁止后验加码
    w = [(1 - rho_g) * rho_g ** (i - 1) for i in range(N)]   # 几何分配，尾部收敛
    return Ledger(delta_total=delta_total, weights=w, spent=0.0,
                  audit=[], log=[])

def ledger_admit(led, r_i, t):
    if r_i > led.delta_total - led.spent:
        return False                                          # 不透支
    led.spent += r_i
    led.audit.append((t, r_i))
    # anytime 有效性：Ville 监控 Σr_i/δ_total，超 1 即触发降档/受控停
    if led.spent / led.delta_total >= 1.0:
        led.log.append(('budget_exhausted', t))
    return True

def residual_route_feasible(route_rest, led, budget):
    # 悲观预测：剩余每段最小可能风险之和是否仍可偿付
    lb = sum(min_achievable_risk(cp, budget) for cp in route_rest.checkpoints)
    return led.delta_total - led.spent >= lb
```

def evidence_fresh(e, t, change_det):
    within = (t - e.t) <= e.scope.h_e
    drifted = change_det.hit(e.scope.region, e.scope.modes)
    return within and not drifted

def transfer(e, r2, mode2, t):                               # 跨 scope 复用

        return None                                          # scope 为空
    if not evidence_fresh(e, t, change_det):
        return None                                          # 陈旧不得单独过门

def npv_probe(route, i, L, led, irr_tokens, budget):
    best = None
    for pi in probe_plans(route[i:i+L], budget=k_p):
        v = 0.0
        for j in range(i, i+L):
            dr   = dr_pess(pi, j)                 # 对第 j 段风险上界的保守下降
            opt  = option(pi, j, irr_tokens)      # 少花一个不可逆令牌/少一次 L2
            dead = deadend(pi, j)                 # 提前发现剩余路由不可行
            v += gamma_d ** (j - i) * (dr + lam_opt*opt + lam_dead*dead)
        v -= sum(cost(p) for p in pi) + sum(c_refresh(p) for p in pi)
        if lcb(v) >= theta_voi and v > (best.v if best else -inf):
            best = (pi, v)
    return best

def option(pi, j, irr_tokens):
    # 现在探针使第 j 段"无需动用不可逆令牌"的概率增益 × 令牌稀缺价格
    return prob_avoid_irreversible(pi, j) * irr_tokens.shadow_price(j)

def long_horizon_pce(route, M, meta, personas, budget, consent):
    gait = select_gait_library(route, M)
    Cg   = stride_certificate(gait, dynamics, slack)
    led  = horizon_ledger_init(budget.delta_total, Cg.rho_g if Cg else 1.0,
                               len(route.checkpoints))
    sched = []
    for i, cp in enumerate(route.checkpoints):
        # ① 死胡同前瞻：剩余路由在剩余预算下不可偿付 → 当前位置就改道
        if not residual_route_feasible(route[i:], led, budget):
            route = shorten_or_reroute(route, i, M); continue
        # ② 元推断（承第 57 轮）
        inf = meta_few_shot_infer(M, cp.region, M.obs[cp.region], meta)
        M.b[cp.region] = inf.post if inf.cls == 'ID' else worst_in(inf.belt)
        # ③ 非短视探询 + 证据刷新
        while budget.probes_left > 0 and budget.irr_left > 0:
            pi = npv_probe(route, i, L, led, budget.irr, budget)
            if pi is None: break
            M, led = run_probes(M, cp, pi); budget.spend(pi)
            M = refresh_stale_evidence(M, cp, budget)
        # ④ 步级审计：本地步态必须可合成
        local = local_gait(cp, M)
        Cg = stride_certificate(local, dynamics, slack)
        if Cg is None:
            route = degrade_or_reroute(route, i, M); continue    # 承诺前降档
        # ⑤ 承诺前：七类证据门 + 账本偿付 + EV-horizon 覆盖
        st = ceg_gate(core_contact(cp), Cg, M, personas, led, budget.t)
        if st[0] != 'ok':
            route = degrade_or_reroute(route, i, M); continue
        r_i = risk_upper_bound(cp, Cg, M, personas)
        if not ledger_admit(led, r_i, budget.t):
            return controlled_stop(cp, M, reason='ledger')       # 受控停，不硬停
        # ⑥ 执行并向下一段传播 reset 包含监控
        if not reset_inclusion_monitor(cp.x, Cg, dynamics):
            return controlled_stop(cp, M, reason='reset_mismatch')
        execute_stride(cp, Cg); sched.append(cp); M = update_map(M, cp)
    return schedule_complete(sched, M, led)

def controlled_stop(cp, M, reason):
    # 选择最近的稳定支撑构型，而非在摆动/单支撑相硬停
    stance = nearest_stable_stance(cp, M)
    return brake_to(stance), ('stop', reason, cp, M.ver)

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SGC | O(N·(T_solve+d_x³)) | O(N·d_x) | reset 包含、guard 正裕度、ρ 保守（A41） |
| HRL | O(1)/段，初始化 O(N) | O(N) | δ_total 预注册、Ville anytime-valid（A42） |
| ETV | O(\|E\|) 新鲜度；O(\|E\|²) 转移 | O(\|E\|) | 时效/漂移诚实、转移保守（A43） |
| NPV | O(L·\|Π\|·C_VOI) | O(L) | 悲观 LCB、死胡同 sound（A44） |
| CEG | O(\|σ\|+N) | O(\|σ\|) | 无新鲜证据即拒、不可逆需 EV-stride |
| LHPCE | O(N·(k_p·C_NPV+\|Π\|·T_solve)+N·A\*) | O(N+\|σ\|) | 账本单调、探针有界、受控停完备 |

**正确性定理（Gait-composable Horizon-budgeted Soundness, GHS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 步级证书健全：reset 包含 R_i(V_i)⊆V_{i+1}、guard 裕度 α_i≥0、L_{R,i}/κ_i 声明诚实且模型误差有界、非 Zeno；**(A42)** 账本预注册且 anytime-valid：δ_total 在任务前固定，E[r_i|F_{i−1}]≤δ_i，禁止后验调账，ℓ_t 单调；**(A43)** 时效与转移诚实：漂移检测漏检率 ≤δ_cd，λ_stale(Δ) 保守，转移算子残差界诚实；**(A44)** NPV 用下置信界、死胡同检测 sound、不可逆令牌不可透支。则：

1. **视界无关的承诺健全性**：P(任意段失败) ≤ δ_total + Σ_i(ε_meta+δ_probe+ε_h)·∏_{j>i}ρ_j ≤ δ_total + (ε_meta+δ_probe+ε_h)/(1−ρ_g)。当 ρ_g<1，该界**对 N 一致有界**；ρ_g≥1 时证书直接拒绝，不允许退化到逐点 union bound 冒充。
2. **暂时有效性（anytime）**：{Σ_{i≤t}r_i−Σ_{i≤t}δ_i} 在安全假设下为超鞅，Ville 不等式给出连续监控/随时停止下的 P(∃t:Σr_i>δ_total)≤δ_total，不存在"偷看抬 α"。
3. **终止性与无死胡同**：每检查点探针 ≤k_p，账本每段严格花掉 r_i>0，故有限步内到达 {完成, 改道, 降档, L2, 受控停}；残余路由可行性在不可逆承诺前检查，杜绝"走进去才发现预算不够"。
4. **交互单调性**：SGC/ETV/NPV/HRL 只经 (a) 更准或可合成的信念，或 (b) 更保守动作（更慢步态、更短视界、更早受控停、更少不可逆令牌）影响系统；`Δ_auth`、`w_h`、`τ_int` 等个性化硬界不变，无升险路径。
5. **部署界**（对视界与检查点取联合界）：

```
P_safe ≥ 1 − δ_total
             − Σ_i (ε_meta + δ_probe + ε_h)·∏_{j>i}ρ_j
             − P(ρ_g≥1 未检出) − P(reset 包含失配未检出)
             − P(漂移漏检)·δ_cd − P(受控停失败)
```

关键：**步级证书给"可合成的安全"，风险账本给"视界无关的预算"，时效与前瞻给"不老化的证据与不短视的探询"**；三者把第 57 轮"逐点证据承诺"提升为"路径级、可随时停止而不失控的承诺"。

其中新增：`C_g/ρ_g/α_g` 步级合成证书；`δ_total/δ_i/ℓ_t` 风险账本；`scope(E)` 证据有效期与转移；`NPV_log` 前瞻探询日志；`stale_log` 证据腐烂与刷新记录；`Jh` 步级-视界证书。

云边协议 CEB++ → **CEB+++**：云端下发的元模型/步态库/时序模型同样走隔离区，且新增**视界回归测试**——影子运行必须同时满足 (ECE 不劣化 ∧ OOD 检出率不降 ∧ ρ_g 预测不乐观 ∧ anytime 误报率 ≤δ_total ∧ 漂移检测召回不降) 才可接管；边端回传 reset 失配、guard 裕度、漂移事件与账本消耗轨迹，作为云端模型误差裕度与 step 级校准的补充。第 58 轮把"**一切判定器走隔离**"进一步推广为"**一切视界承诺走隔离：先在影子路由上跑完整段，再接管真实承诺**"。

## 6. 本轮最大风险

**一句话**：本轮把长程安全押在"混杂模型在整条视界上忠实"这一前提上——ρ_g 与 reset 包含只要有一处模型失配（一次打滑、一块软地、一次外力推挤），跨步合成就会在那一刻断裂，而账本的 anytime 保证会因单次未建模事件变成空头支票；必须以在线 reset 包含监控、ρ 的保守上界与模型误差裕度、以及受控停回退三重护栏，宁可把视界缩短成"能证明的一段"，绝不承诺"模型里没有的下一步"。
