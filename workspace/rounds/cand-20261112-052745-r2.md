# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；灵感循环第 2 轮；本轮灵感：「群体智能」×「路径规划」）

> 第 59 轮把「单体的证据承诺」焊到了物理执行层：BUQ 辨识电机结构性不确定、ERTC 把实时约束契约化、EEIS 把 δ_f 编译成带证书的阻抗参数、CLEP 让执行实测回传为第 5 模态、PCE+++ 四预算保证绝不冒险。但整条证据链始终有一个未言明的前提——**只有一个身体、一张地图、一个证据源**。本轮两个灵感正好撕开这个前提：**群体智能**告诉我们「多体」不是数量的线性叠加，而是带来 stigmergy（间接通信）、正反馈、分工、共识，同时带来**相关性、信息级联、羊群效应与拜占庭故障**；**路径规划**告诉我们「移动」本身就是一种观测策略——走哪条路，决定了你能看见什么、以什么独立性去对账、在什么时刻承诺。合流后的核心命题：**把「路径」从几何最优重定义为证据最优，把「群体」从多副本重定义为去相关的分布式证据网络；用局部规则换取可扩展性，用独立性图谱与鲁棒融合守住「共识 ≠ 真理」的底线。**

核心矛盾：
- **H32（共识幻觉·相关证据冒充独立佐证）**：N 个 agent 报告一致，看似是 N 份证据；但若它们共享模型权重、固件版本、传感器批次、训练数据、上游信念，甚至是同一条通信链路上的「回音」，则有效独立样本 `n_eff ≪ N`。把 N 当独立证据做贝叶斯相乘，会系统性高估置信度、低估 δ_f——这正是第 57 轮「跨模态独立性」必须升级为「**跨体独立性**」的原因。共识本身不产生信息，去相关的共识才产生信息。
- **H33（群体病理·正反馈锁死与陈旧证据场）**：stigmergy 的正反馈会让路径规划收敛到次优甚至危险路径；信息级联与群体极化让错误信念自我强化；通信延迟与带宽限制让 agent 在「陈旧证据场」上规划；少数被污染的 deposit 可以诱发整群绕行或误入险区。**没有病理护栏的群体智能，就是一台高效的群体犯错机器。**
- **H34（路径即证据策略·几何最优 ≠ 证据最优）**：传统路径规划优化长度/能耗/平滑度；在证据受限环境下，最优路径应同时是**证据采集与搬运策略**——走哪条路决定能观测什么、以何种独立性对账、把「探针/承诺」从检查点局部决策提升为**路径级序贯决策**。路径不再只是「到达」，而是「带着可验证证据到达」。

## 0. 直觉与动机

**灵感 1（群体智能 → 群体证据场 SEF 与认识独立性图谱 EIG）**
直觉：蚂蚁不共享全局地图，只在环境里留下会挥发的信息素（stigmergy）。这给了一个极自然的类比：**把「证据」做成会衰减、带来源、可被他人读写的空间场**——不是标量信息素，而是带 provenance 的 credence deposit：谁留下的、属于哪类证据、校准状态如何、什么时候留下的、与哪些 agent 共享信息源。路径规划读这个场，就用「证据密度/新鲜度/可信度」而不是「信息素浓度」来偏置采样。但群体智能的第一杀手是**相关证据冒充独立佐证**：所有 agent 用同一套模型，它们的一致只是「同一副眼镜的重复」。因此必须配一张**认识独立性图谱 EIG**：节点是 agent，边是共享信息通道（同模型哈希、同固件、同传感器批次、同上游信念、通信导致的相关），并据此计算**有效独立样本数** `n_eff = 1ᵀR⁻¹1 ∈ [1,N]`。法定人数（quorum）必须用 `n_eff` 而不是原始计数。

**灵感 2（路径规划 → 证据感知路径规划 SEAP）**
直觉：经典 A*/RRT*/D* 在已知代价地图上找最优；但在「证据未定」的环境里，代价地图本身就是随机变量。正确对象是**信念空间规划**：状态 = (各 agent 位置, 群体证据场 Φ, 各 agent 执行状态 ξ_exec)，动作 = (运动基元 + 探针选择)，代价 = 几何代价 + 风险代价 + 执行代价 + **通信代价** − **期望信息增益**。于是「最优路径」自动变成「信息性价比最高的绕路」：为了用两个独立模态确认一块落脚点，多走 3 米可能是值得的；为了省一次通信同步而在陈旧场上冒进则可能是致命的。多 agent 时还要解决**证据采集的任务分配**：同一检查点由哪个 agent 去探、用哪个模态、能带来多少**独立**信息。

**灵感 3（两灵感合流 → 群体证据闭环 SPEC 与五预算 PCE++++）**
直觉：把第 59 轮的单体 CLEP 升维到群体：SEF 给出共享证据场 → EIG 给出独立性折扣 → SEAP 给出路径级探针/承诺序列 → 每段路径由各 agent 的 ERTC 契约执行 → 执行实测回传更新 SEF 与 ξ_exec → 群体承诺协议 SCP 以 `n_eff` 法定人数决定是否承诺。第 59 轮的四预算（B_probe / B_ft / B_ux / B_exec）新增 **B_comm（通信预算：带宽、时延、同步频率）**：同步越频繁，证据越新鲜但通信成本越高；同步越稀疏，证据场越陈旧、规划越可能基于过期信念。通信预算与证据鲜度形成显式张力。

**灵感 4（群体病理 → 防羊群护栏与拜占庭鲁棒融合 BEF）**
直觉：正反馈 + 信息级联 = 群体放大器。必须显式注入**负反馈与多样性**：信息素正反馈封顶、探索下限（novelty bonus / ε-exploration）、认识多样性配额（不允许所有 agent 收敛到同一模态）；对 deposit 做拜占庭鲁棒聚合（中位数 / Krum / median-of-means）；对 SEF 做污染检测（deposit 分布与独立模态的 TV 距离异常即触发隔离）。**「共识」只作为警报，不作为证明；只有去相关且通过鲁棒聚合的共识，才可升格为证据。**

**灵感 5（云边协同 → 影子群体与群体数字孪生 SDS）**
直觉：群体协调策略（SEF 衰减率、法定人数阈值、分配规则）一旦上线，错误会被 N 倍放大。沿用第 59 轮隔离区思想，把它升级为**影子群体**：新协调策略先在数字孪生 + N_shadow 个影子 agent 上跑，校验「路径成功率、n_eff 估计偏差、羊群锁死率、拜占庭污染检出率」达标后才热切换；失败即回滚。边端回传：SEF 摘要、n_eff 估计、承诺证书链、污染事件。

## 1. 形式化定义（增量：定义 153–160）

**定义 153（群体证据场 SEF）** 群体证据场 Φ_t 把空间-区域映射到证据沉积集合：
```
Φ_t: X×K → 2^𝔻
d = (id_agent, e_class∈{vis,tap,prop,acou,exec,human}, ŷ, Σ, τ_d, indep_key, credence, prov_hash)
```
沉积权重（挥发性 + 可信度 + 鲜度 + 独立性折扣）：
```
w_d(t) = w_d^0 · exp(−λ_decay·(t−τ_d)) · κ_cred(ECE_d, OOD_d) · κ_fresh(τ_d; C_rt.Renewal_period) · κ_indep(d)
```
场聚合：对同一 (cell, e_class) 的沉积做**带相关阵 R 的精度加权融合**
`ŷ_Φ = (1ᵀR⁻¹ŷ)/(1ᵀR⁻¹1)`，`Σ_Φ = σ²/n_eff`，`n_eff=1ᵀR⁻¹1`。沉积准入规则：未达校准阈（ECE>ε_meta）或执行降级的沉积只能以 `ρ_min` 权重进入，且标记 `tainted`；负证据（危险）不得被正反馈抵消，只能由独立负/正证据比更新。

**定义 154（认识独立性图谱 EIG）** EIG 为带权无向图 `G_ind=(A,E,ρ)`，`A` 为 agent 集，`ρ_ij∈[0,1]` 为共享通道导致的最大相关性：
```
ρ_ij = max{ ρ_model·1[同一模型哈希], ρ_fw·1[同一固件/ERTC 版本],
             ρ_sensor·1[同一传感器批次], ρ_comm·1[共享上游信念/回音],
             ρ_env·1[同一视角/同一训练数据] }
```
相关阵 `R∈ℝ^{N×N}` 对称半正定，`R_ii=1`，`R_ij=ρ_ij`。有效独立样本数 `n_eff = 1ᵀR⁻¹1 ∈ [1,N]`（等相时 `=N/(1+(N−1)ρ)`）。工程上用带不确定性的估计取**下置信界** `n_eff^LCB`（保守）：任何依赖 `n_eff` 的承诺都用 LCB，绝不用点估计。相关性融合：
```
ŷ_fused = (1ᵀR⁻¹ŷ)/(1ᵀR⁻¹1),  Var(ŷ_fused)=σ²/n_eff
```
**关键**：`n_eff` 只衡量「独立性」，不衡量「能力」；能力由各 agent 的 ECE、执行契约、OOD 状态单独加权。

**定义 155（群体证据感知路径规划 SEAP）** 多 agent 信念空间 MDP：
```
状态 s_t = ({x_i}, Φ_t, {ξ_exec^i}, b_t)   动作 a_t = ({(motion_i, probe_i)})
代价 J(π) = E[ Σ_k ( c_geo + c_risk(b_k) + Σ_i c_exec(ξ_exec^i, C_rt^i)
                        + c_comm(Δ_sync) − λ_info·IG(b_k, a_k) ) ]
约束：每段承诺满足 SCP 法定人数 n_eff^LCB ≥ q_eff；
      每 agent 执行满足 ERTC 契约；
      场鲜度 τ_field ≤ C_rt.Renewal_period；
      B_comm 不被越界。
```
路径级 VOI：`VOI(π) = E[ΔH_hazard + λ_r·ΔRisk] − c_geo − c_exec − c_comm`；承诺只在 `VOI≥θ_VOI` 且约束满足时发生。多 agent 分配用**势博弈/分布式拍卖**求解：agent i 对检查点 c 出价 `bid_i(c)=VOI_i(c)/cost_i(c) ∝ 独立信息增益/执行+通信成本`，同一检查点的边际价值随已分配 agent 的 `ρ` 递减，天然抑制「一窝蜂去同一个点」的羊群冗余。

**定义 156（拜占庭鲁棒证据融合 BEF）** 存在 `f` 个故障/被污染 agent（传感器退化、模型漂移、恶意沉积）。在 `N ≥ 3f+1` 下用鲁棒聚合 `Agg_rob`（逐坐标中位数 / Krum / median-of-means），并用共形包装维持覆盖率：
`Pr[θ ∈ C_rob(x)] ≥ 1−α − δ_byz`。污染检测：对区域 deposit 的标签分布与独立模态做 TV 距离，`TV > θ_poison` 的 agent deposit 进入隔离区并回溯。**前提诚实声明**：拜占庭鲁棒性只有在「故障与其他 agent 去相关」时才成立；EIG 的 `ρ` 估计错误会直接击穿该保证。

**定义 157（群体承诺协议 SCP：法定人数/响应阈值）** 承诺证书
```
Cert_swarm = (region, ŷ_Φ, Σ_Φ, n_eff^LCB, q_met, byz_ok,
              field_hash, τ_field, participants, coord_version, timestamp)
q_met ⇔ n_eff^LCB ≥ q_eff(δ_f^req) ∧ 各类证据门通过（沿用七类证据门）
```
承诺动作由响应阈值模型触发：agent i 在累积证据强度超过个体阈值 `θ_i` 时「响应」；`θ_i` 依角色（scout/committer/porter）与能力设定，用**法定人数**而非「最先响应者」做最终承诺，避免速度竞赛诱发冒险。

**定义 158（五预算 PCE++++）** `B = (B_probe, B_ft, B_ux, B_exec, B_comm)`，新增
```
B_comm = (bw_slack, delay_slack, sync_credit)
```
VOI 显式扣除通信成本：`voi = VOI_meta_pessimistic − cost_exec − cost_comm(Δ_sync)`。同步频率 `f_sync` 的选择是一个小规模优化：
```
max_{f_sync}  E[−c_comm(f_sync) − λ_stale·P(τ_field>Renewal_period|f_sync)]
```
任一预算耗尽 ⇒ 动作更保守（减少探针/暂停承诺/退化为单体模式），绝不挪用其他预算。

**定义 159（群体证据证书 J_swarm）** 
```
J_swarm = (SEF_snapshot_chain, EIG(t), n_eff_trajectory, SCP_cert_chain,
           BEF_audit_log, poison_events, SEAP_plan_log, {J_exec^i}, coord_version, timestamp)
```

**定义 160（群体病理护栏与影子群体 SDS）** 护栏集合
`G_swarm = {正反馈封顶, 探索下限 ε, 认识多样性配额, 法定人数用 n_eff^LCB, 拜占庭鲁棒聚合, 场鲜度硬约束, 污染隔离}`。影子群体：新协调策略先在数字孪生与 `N_shadow` 影子 agent 上运行，通过「成功率、n_eff 偏差、锁死率、污染检出率」四门后才热切换。

## 2. 关键算法伪代码（骨架）

### IP-152 SEF（群体证据场）

```python
class SwarmEvidenceField:
    def __init__(self, decay=0.05, renewal=0.05):
        self.deposits = defaultdict(list)   # (cell, e_class) -> [Deposit]
        self.decay, self.renewal = decay, renewal

    def deposit(self, cell, d, ece, ood, degraded, independence_weight):
        k_cred = 1.0 if (ece <= EPS_META and not ood) else RHO_MIN
        k_fresh = math.exp(-max(0.0, now() - d.tau) / self.renewal)
        d.w0 = d.w0 * k_cred * k_fresh * independence_weight
        self.deposits[(cell, d.e_class)].append(d)

    def fuse(self, cell, e_class, EIG):
        ds = [d for d in self.deposits[(cell, e_class)] if d.alive(now(), self.decay)]
        R = EIG.correlation_matrix([d.id_agent for d in ds])
        y = np.array([d.y for d in ds]); w = np.array([d.w for d in ds])
        precision = np.linalg.inv(R)
        n_eff = float(np.ones(len(ds)) @ precision @ np.ones(len(ds)))
        y_fused = (np.ones(len(ds)) @ precision @ y) / n_eff
        return y_fused, SIGMA2 / max(n_eff, 1e-9), n_eff
```

### IP-153 EIG（认识独立性图谱）

```python
class EpistemicIndependenceGraph:
    def correlation_matrix(self, agents):
        R = np.eye(len(agents))
        for i, a in enumerate(agents):
            for j in range(i + 1, len(agents)):
                rho = self.rho(a, agents[j])          # 共享通道最大相关
                R[i, j] = R[j, i] = rho
        return nearest_psd(R)

    def effective_independence(self, agents):
        R = self.correlation_matrix(agents)
        n_eff = float(np.ones(len(agents)) @ np.linalg.inv(R) @ np.ones(len(agents)))
        return self.lower_confidence_bound(n_eff, len(agents))   # 保守 LCB
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SEF | O(沉积数·d) 融合/查询 | O(沉积数·d + 网格) | 挥发性衰减、可信/鲜度/独立性折扣、负证据不可被正反馈抵消 |
| EIG | O(N²)/更新，`n_eff` O(N³) | O(N²) | `n_eff∈[1,N]`、LCB 保守、`R≽0` 投影 |
| SEAP | O(\|采样\|·K·(N+C)) | O(\|V\|·\|Φ\|) | 风险/执行/通信约束、VOI 下界、终止于有限预算 |
| BEF | O(N log N)/融合 | O(N·d) | `N≥3f+1` 下抵抗 f 拜占庭；诚实前提：故障去相关 |
| SCP | O(融合+审计) | 复用 SEF/EIG | 法定人数用 `n_eff^LCB`，承诺证书可审计 |
| PCE++++ | O(\|CP\|·K·(C_VOI+N³+C_comm)) | O(\|V\|+\|Φ\|+N²) | 五预算单调、互不挪用、耗尽即保守 |

**正确性定理（Swarm Evidence-Grounded Soundness, SEGES）** 假设 A22–A55（第 53–59 轮）与新增 **(A56)** EIG 的相关性估计是**保守上界**（`ρ̂ ≥ ρ_true`，从而 `n_eff^LCB ≤ n_eff^true`）；**(A57)** SEF 沉积诚实（未校准/降级沉积必被降权标记）；**(A58)** BEF 在 `N≥3f+1` 且故障去相关时满足鲁棒聚合界；**(A59)** SEAP 的 VOI 估计诚实（信息增益不高于真实增益，成本不低于真实成本）；**(A60)** 场鲜度硬约束被执行；**(A61)** 影子群体四门检验完备；**(A62)** 群体承诺只由 `n_eff^LCB` 与七类证据门共同触发。则：

1. **反共识幻觉**：任何群体承诺的有效证据量 ≤ `n_eff^true`；把 `N` 当独立证据的高估被 EIG 的保守 LCB 消除，后验过度自信被系统性抑制。
2. **群体部署界**：`P_safe ≥ 1 − Σ_cp (δ_f + ε_meta + δ_probe + δ_byz·1[污染] + δ_indep·1[n_eff 高估] + δ_stale·1[场陈旧] + δ_exec + δ_ertc + δ_eeis) − P(羊群锁死未检出) − P(影子回滚失败)`。

@dataclass
class Deposit:
    id_agent: int
    e_class: str                 # vis/tap/prop/acou/exec/human
    y: np.ndarray                # 证据内容（力/几何/标签/credence）
    cov: np.ndarray
    tau: float                   # 沉积时间
    indep_key: tuple             # (model_hash, fw, sensor_batch, upstream)
    credence: float
    prov_hash: str
    w0: float = 1.0
    tainted: bool = False

    def weight(self, now, decay, renewal):
        k_fresh = math.exp(-max(0.0, now - self.tau) / renewal)
        k_taint = RHO_MIN if self.tainted else 1.0
        return self.w0 * math.exp(-decay * (now - self.tau)) * self.credence * k_fresh * k_taint

class SwarmEvidenceField:
    def __init__(self, decay=0.05, renewal=0.05):
        self.deposits = defaultdict(list)      # (cell, e_class) -> [Deposit]
        self.decay, self.renewal = decay, renewal
        self.poison_quarantine = set()

    def deposit(self, cell, d, ece, ood, degraded):
        # 准入：未校准 / OOD / 执行降级 只能以 tainted 低权重进入
        if ece > EPS_META or ood or degraded:
            d.tainted = True
        if d.id_agent in self.poison_quarantine:
            d.tainted = True
        self.deposits[(cell, d.e_class)].append(d)

    def alive(self, cell, e_class, now):
        return [d for d in self.deposits[(cell, e_class)]
                if d.weight(now, self.decay, self.renewal) > W_MIN]

    def fuse(self, cell, e_class, eig, now):
        ds = self.alive(cell, e_class, now)
        if not ds:
            return None
        agents = [d.id_agent for d in ds]
        R = eig.correlation_matrix(agents)                  # 相关阵
        R = nearest_psd(R)
        P = np.linalg.inv(R)
        y = np.array([d.y for d in ds])
        w = np.array([d.weight(now, self.decay, self.renewal) for d in ds])
        # 相关阵 + 沉积权重：n_eff = wᵀPw 的归一化有效样本数
        n_eff = float((w @ P @ w) / max(w.sum() / len(w), 1e-9))
        y_fused = (w @ P @ y) / max(w @ P @ w, 1e-12)
        var = SIGMA2 / max(n_eff, 1e-9)
        return FieldEstimate(y_fused, var, n_eff, agents)

    def freshness(self, cell, now):
        return max((now - d.tau) for d in self.deposits[cell]) if self.deposits[cell] else float('inf')

    def field_hash(self):
        return sha256(sorted(d.prov_hash for ds in self.deposits.values() for d in ds))
```

@dataclass
class AgentDescriptor:
    id: int
    model_hash: str
    fw_version: str
    sensor_batch: str
    upstream_belief_hash: str
    viewpoint_id: str

class EpistemicIndependenceGraph:
    def __init__(self, rho_model=0.9, rho_fw=0.7, rho_sensor=0.5,
                 rho_comm=0.8, rho_env=0.6):
        self.rho_params = dict(rho_model=rho_model, rho_fw=rho_fw,
                               rho_sensor=rho_sensor, rho_comm=rho_comm, rho_env=rho_env)

    def rho(self, a: AgentDescriptor, b: AgentDescriptor):
        r = 0.0
        if a.model_hash == b.model_hash:      r = max(r, self.rho_params['rho_model'])
        if a.fw_version == b.fw_version:      r = max(r, self.rho_params['rho_fw'])
        if a.sensor_batch == b.sensor_batch:  r = max(r, self.rho_params['rho_sensor'])
        if a.upstream_belief_hash == b.upstream_belief_hash:
            r = max(r, self.rho_params['rho_comm'])
        if a.viewpoint_id == b.viewpoint_id:  r = max(r, self.rho_params['rho_env'])
        return r

    def correlation_matrix(self, agents):
        ids = list(agents)
        desc = {a.id: a for a in agents} if isinstance(agents, dict) else {a.id: a for a in agents}
        N = len(ids)
        R = np.eye(N)
        for i in range(N):
            for j in range(i + 1, N):
                r = self.rho(desc[ids[i]], desc[ids[j]])
                R[i, j] = R[j, i] = r
        return nearest_psd(R)   # 保证半正定

    def effective_independence(self, agents):
        R = self.correlation_matrix(agents)
        n_eff = float(np.ones(len(agents)) @ np.linalg.inv(R) @ np.ones(len(agents)))
        return self.lower_confidence_bound(n_eff, len(agents))

    def lower_confidence_bound(self, n_eff_hat, N, alpha=0.05):
        # 相关性估计有误差：取显著保守的下界，绝不高估独立性
        se = math.sqrt(2.0 * N) / max(N, 1)
        return max(1.0, n_eff_hat - norm.ppf(1 - alpha) * se)

    def update_from_observations(self, agents, agreement_matrix):
        # 用历史一致率反推相关（一致≠独立；同错也是相关）
        for i, j in combinations(range(len(agents)), 2):
            agree = agreement_matrix[i, j]
            implied_rho = max(0.0, 2 * agree - 1)   # 粗校准
            self.rho_params['rho_comm'] = max(self.rho_params['rho_comm'], implied_rho)
```

### IP-154 SEAP（群体证据感知路径规划）

```python
def swarm_evidence_aware_plan(swarm, field, task, budgets, eig):
    # 1) 在证据场上做风险感知采样（RRT*/RRG），代价含风险与不确定性
    graph = risk_aware_rrg(swarm, field, task,
                           cost=lambda seg: geom_cost(seg) + risk_cost(field, seg))
    best = None
    for path in extract_paths(graph, task):
        total_voi, feasible_all = 0.0, True
        for segment in split_segments(path):
            cps = segment.checkpoints
            # 2) 分布式拍卖：谁去采证据，边际价值随相关性递减
            assign = distributed_auction(swarm, cps, field, eig, budgets)
            if assign is None:
                feasible_all = False; break
            ig = expected_information_gain(field, assign, eig)   # 独立信息增益
            c_geo = geom_cost(segment)
            c_risk = risk_cost(field, segment)
            c_exec = sum(exec_cost(a, segment) for a in assign)   # 复用第 59 轮 ERTC
            c_comm = comm_cost(assign, budgets.B_comm)
            voi = ig - (c_geo + c_risk + c_exec + c_comm)
            if voi < THETA_VOI:
                feasible_all = False; break
            total_voi += voi
        if feasible_all and total_voi > 0:
            cand = (path, total_voi)
            best = cand if (best is None or cand[1] > best[1]) else best
    return best

def distributed_auction(swarm, cps, field, eig, budgets):
    assign = defaultdict(list)
    for cp in cps:
        bids = []
        for a in swarm.available():
            # 边际独立信息：若已有同源 agent 覆盖，则折扣
            marginal = eig.independence_discount(a, assign[cp])
            ig_i = expected_information_gain(field, {a} | set(assign[cp]), eig) - \
                   expected_information_gain(field, set(assign[cp]), eig)
            cost_i = exec_cost(a, cp) + comm_cost({a}, budgets.B_comm)
            bids.append((max(0.0, marginal * ig_i) / max(cost_i, 1e-9), a))
        if not bids:
            return None
        bids.sort(reverse=True)
        assign[cp] = [a for _, a in bids[:K_PER_CP]]   # 保留至多 K_PER_CP 个且需去相关
    return assign

def expected_information_gain(field, agents, eig):
    # 证据独立性越高、现有不确定性越大，信息增益越高
    H_before = field.entropy()
    H_after = field.projected_entropy(agents, eig)
    return max(0.0, H_before - H_after)
```

def robust_fuse(deposits, f):
    pts = np.array([d.y for d in deposits])

def swarm_commit(field, region, delta_f_req, eig, participants, byz_f):

    if est is None:
        return None
    n_eff_lcb = eig.effective_independence(participants)

@dataclass
class SwarmBudget:

    ft_budget: int
    ux_budget: int

                not self.single_agent_fallback and
                self.exec_snapshot.is_viable_for_contact() and
                self.comm.bw_slack > 0 and self.comm.sync_credit > 0)

    def exec_cost(self, wcet, bus, power):
        s = self.exec_snapshot
        return (max(0, wcet - s.wcet_slack) * LAMBDA_WCET +

                max(0, power - s.thermal_slack) * LAMBDA_THERM)

        c = self.comm
        return (max(0, record_bytes - c.bw_slack) * LAMBDA_BW +
                max(0, latency - c.delay_slack) * LAMBDA_DELAY +
                self.comm.sync_penalty(record_bytes))

def choose_sync_frequency(field, budgets):
    best_f, best_val = None, -float('inf')
    for f_sync in SYNC_GRID:

        stale_prob = field.estimate_staleness_prob(delta_sync)
        val = -budgets.comm_cost_sync(f_sync) - LAMBDA_STALE * stale_prob

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SEF | 融合 O(k·d³)（k=沉积数，d=维）；查询 O(k·d) | O(k·d + 网格) | 衰减+可信+鲜度+独立性折扣；负证据不可被正反馈抵消 |
| EIG | O(N²)/更新；n_eff O(N³) | O(N²) | `n_eff∈[1,N]`；LCB 保守；R≽0 |
| SEAP | O(\|采样\|·K·(N+C)) | O(\|V\|·\|Φ\|) | 风险/执行/通信约束；VOI 下界；有限预算终止 |
| BEF | O(N log N)/融合 | O(N·d) | `N≥3f+1` 抗 f 拜占庭；诚实前提：故障去相关 |

| PCE++++ | O(\|CP\|·K·(C_VOI+N³+C_comm)) | O(\|V\|+\|Φ\|+N²) | 五预算单调、互不挪用、耗尽即保守/退化单体 |
| J_swarm | O(1)/事件追加 | O(事件数) | n_eff 不得承诺前突增；证书链完整；鲜度达标 |

**正确性定理（Swarm Evidence-Grounded Soundness, SEGES）**
假设 A22–A55（第 53–59 轮）成立；新增：

## 6. 本轮最大风险

**一句话**：本轮最大的风险是**把「相关共识」误当成「独立证据」**——EIG 的相关性估计一旦偏乐观、或通信本身制造了它试图测量的相关性，群体就会以被高估的 `n_eff` 自信地收敛到错误甚至危险的路径上，使 `1−δ_f` 的安全承诺整体坍塌；因此必须坚持「相关性估计只取保守上界、法定人数只用 LCB、共识只作警报不作证明、拜占庭鲁棒融合与认识多样性配额不可关闭」四重护栏，宁可群体显得「迟钝、低效、频繁退化为单体」，也绝不允许「群体一致但证据其实是同一副眼镜的重复」。
