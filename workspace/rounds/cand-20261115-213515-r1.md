# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「ROS」×「双臂协作」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**分布式契约 + 双臂协同**。v9 把退化从代码变成单进程内的契约表，但仍隐含两个单点假设：其一，所有模块跑在同一进程、同一时钟，"超时"因此是一个干净事件；其二，只有一个操作臂，空间证书与中止点都是一元的。ROS 灵感拆掉第一个假设，双臂协作拆掉第二个。新模块一律为可选增强：任一失效 ⇒ 局部注入中立元并退回 v9（分布式），或退回 leader-follower（协同），不得行为漂移。

## 0. 直觉与动机

**灵感 1（ROS → 契约的分布式投射）**
直觉：v9 的 MW 是一张"上帝视角"的进程内契约表，而真实机器人是一张 ROS 2 节点图：模块是节点，端口是 topic，时限是 QoS deadline，失联是 liveliness。把 κ_m 投射为 (QoS, lifecycle)，"超时注入 v^⊥"就变成订阅端本地的 neutral-selector：一个端口在 D_m 内没收到合格消息，就地并入 v^⊥，而不必等中央调度器发号施令。收益是分布式退化（任一节点掉线只影响其下游端口）与组合可验证性；代价是引入 v9 没有的三类故障：时钟偏差、消息丢失/重放、网络分区。核心创新：**ROS 契约桥（ROSContractBridge, RCB）**，把 v9 表 536 升级为可部署的 QoS 契约图，并给出"分布式退化与集中式退化双模拟"的判据（引理 87）。

**灵感 2（双臂协作 → 相对证书与联合中止）**
直觉：单臂的 SpatialCert 是"臂-障碍"的绝对间隙；双臂一旦共同夹持物体，系统多出一条**闭运动链**，安全就不再是"两臂各自安全"的合取，而是"相对位姿 + 闭链残差 + 互撞间隙"的联合性质。好消息是：两臂共享的 SLAM 漂移是**共模**的，相对位姿 r=T_L^{-1}T_R 中解析抵消，故相对证书对共模误差天然鲁棒（引理 88）。坏消息是：v9 的中止点集是一元的——一臂单独刹车会拉断闭链或撞上另一臂。核心创新：**双臂相对证书器（BimanualRelativeCertifier, BRC）** 与**联合中止点集 P_t^{LR}**：中止必须是"成对可停或合规保持"，并由**协同屏障（CoordinationBarrier, CB）**保证两块落在同一决策纪元、同一时钟尺度。

**灵感 3（二者的耦合 → 时间一致性成为新安全前提）**
直觉：ROS 拆散了时钟，双臂又要求同一瞬间的相对状态；于是"分布式"与"协同"相乘，安全性第一次显式依赖 δ（两臂时钟 + 传输偏差）。这不是工程细节，而是一条新的不变式：可用安全裕度 = d_safe − v_max·δ − β_rel。δ 吃掉裕度，所以 v10 的核心不是"更好的控制律"，而是**把时间偏差变成可测、可门控、可退化的一等公民**。

## 1. 研究问题（轮次升级版）

- **Q1（分布式退化等价）**：在时钟偏差 δ ≤ δ_max、信道有损的条件下，订阅端本地注入中立元的分布式契约图，何时与 v9 集中式 MW 退化链**可观测等价**？双模拟需要哪些 stutter 与幂等条件？
- **Q2（双臂相对安全）**：相对证书在共模漂移抵消下，能否给出比"两臂绝对证书之交"更紧的互撞界？闭链残差 ρ_t 与打滑/内力之间能否建立可检验的阈值关系？
- **Q3（协同中止与时间）**：联合中止点集与协同屏障在 δ 越界、单臂失联、消息重放下的安全性与活性边界是什么？"先降 leader-follower、再降单臂"的退化序是否严格扩大安全裕度？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 ROS 契约同构律（ROS-Contract Isomorphism, RCB）**
每个 κ_m 投射为 π_ROS(κ_m)=(node, topics, QoS_m, lifecycle_m)，其中 QoS deadline≡D_m、liveliness lease≡故障判定、history/ownership 表达端口语义。订阅端维护 neutral-selector：窗口内无合格消息 ⇒ 并入 v_m^⊥（幂等，重复缺失不叠加）。退化是**局部的**：一个端口失效只改变其所在聚合算子的一项，不重排全局调度。

**P14 双臂相对证书律（Bimanual Relative Certificate, BRC）**
安全证书分解为 C_t = C_t^{abs} ⊓ C_t^{rel}：前者管"臂-环境"绝对间隙（继承 v9），后者管"臂-臂"互撞间隙、闭链残差 ρ_t 与相对抓取有效性。相对量在物体/相对系中表达，共模 SLAM 漂移解析抵消；门控量 risk_SLAM^{rel} 由相对协方差给出，而非两臂绝对协方差之和。

**P15 协同中止律（Coupled Abort & Barrier, CA）**
双臂块 ζ_t^{LR}=(a_L^{1:K}, a_R^{1:K}, Ĉ_t^{rel}, P_t^{LR})；p∈P_t^{LR} 需两臂在同一 τ_sync 内可停、或转入合规保持且 ρ_t 不越界。块生成走两阶段协同屏障：两臂同纪元且 δ≤δ_max 才提交，否则退回 leader-follower（从臂跟踪主臂相对轨迹）。

## 3. 与基线的接口（如何退化）

- 协同级失效（闭链残差越界 / 联合中止点为空 / 屏障超时）⇒ **leader-follower**：从臂以主臂相对轨迹为参考，等价于"刚性协同"降级；
- ROS 桥失效（QoS 映射错误 / DDS 不可用）⇒ 退回 v9 进程内 MW，等价集中式契约；
- 单臂失联 / 网络分区 ⇒ 该臂注入 v^⊥（安全停驻 a^⊥），另一臂按单臂 v9 继续，等价 v9；
- δ > δ_max ⇒ 强制 K_eff=1 且禁闭链（Coupled→Independent），等价两臂各跑 v9；
- BRC 失效 ⇒ 弃用相对证书，退回两臂绝对证书之交（保守但可用），等价 v9 单臂证书的笛卡尔积；
- 再往下：v9 五级退化 ⇒ v8 ⇒ v7 ⇒ v6。

## 4. 预期贡献

1. **ROS 契约桥**：退化链的分布式部署形态，中立元注入从中央调度降为订阅端局部算子（引理 87 双模拟），使 v9 的代数性质可在真实节点图上保持；
2. **双臂相对证书**：共模漂移抵消 + 闭链残差 + 联合中止点集，把"双臂协同"从任务层叙事变成空间证书层的可证性质（引理 88–89）；
3. **把时间一致性作为安全一等公民**：δ-裕度侵蚀的显式界与协同屏障活性证明（引理 90–91）；
4. **E571–E590** 覆盖 QoS 等价、时钟扫描、互撞注入、闭链、网络分区、长跑与对抗时序。

## 5. 本轮最大风险

**一句话**：双臂协同证书以"两臂状态属于同一时刻"为前提，而 ROS 2 的分布式时钟偏差与传输延迟恰好让两臂在"各自认为安全"的不同瞬间共同越过边界——最需要协同的中止时刻，联合中止点集却建立在互不一致的时间戳上。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-DARC**（Dual-Arm Relative Certificates & ROS QoS-Contracts）

> 背景：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮灵感：「ROS」×「双臂协作」
> **继承纪律**：MetricVoiceGauge 九不变式与 v9 的 AC/MW/ID 全部保留；新增 RCB/BRC/CB 均为**可选增强**。任一失效 ⇒ 局部中立元或模式降级，严格退回 v9 或 leader-follower（引理 87、92），不得行为漂移。

**退化链声明（v10 契约化六模式）：**
- **Mode-Coupled**（默认）：双臂闭链协同，C^{abs}⊓C^{rel} + 联合中止；
- **Mode-LeaderFollower**：协同失效（P^{LR}=∅ / ρ 越界 / 屏障超时）⇒ 从臂跟踪主臂相对轨迹；
- **Mode-Independent**：δ>δ_max 或禁闭链 ⇒ 两臂各跑 v9，K_eff=1；
- **Mode-SingleArm**：一臂失联/分区 ⇒ 该臂 a^⊥ 停驻，另一臂按 v9；
- **Mode-v9**：ROS 桥或 BRC 失效 ⇒ 进程内 MW（集中式契约，等价 v9）；
- **Mode-v9→v8→v7→v6**：继承 v9 五级退化。

## 1. 符号体系增量（定义 540–549）

| 符号 | 含义 |
|---|---|
| π_ROS(κ_m) | ROS 契约投影：节点、收发 topic、QoS 配置、lifecycle 状态 |
| QoS_m=(R,Du,Deadline,Liveness,History,Ownership) | 端口服务质量；Deadline≡D_m，Liveness≡故障租约 |
| ⊕_{j} / v_m^⊥ | 订阅端 j 的聚合算子与端口中立元（x⊕v^⊥=x） |
| δ_κ(t) | 契约时偏：两臂时钟差 + 传输延迟上界 |
| r_t=(T_L^W)^{-1}T_R^W | 双臂相对位姿（世界系），或物体系表达 |
| Ĉ_t^{rel} | 相对证书：(相对最小间隙, 相对最大力/速度, 闭链残差界, 相对抓取有效) |
| ρ_t | 闭链残差（SE(3) 对数范数） |
| P_t^{LR} | 联合中止点集 |
| τ_sync, T_bar | 两臂停驻时差上限 / 协同屏障超时 |
| M_co | 协同模式格 {Coupled, LeaderFollower, Independent, SingleArm} |

**新增定义 540（ROS 契约投影 ROSContractProjection）** 对每个模块契约 κ_m，定义
```
π_ROS(κ_m) = (node_m, In_m^topic, Out_m^topic, QoS_m, lifecycle_m)
QoS_m = (Reliability, Durability, Deadline=D_m, Liveliness=L_m, History=h_m, Ownership)
```
约定 Deadline 对应契约截止期 D_m，Liveliness lease 对应故障判定窗口；lifecycle_m∈{unconfigured,inactive,active,finalized}，其中 inactive 与 v9 的 dormant 语义对齐。

**新增定义 541（分布式中立元注入 DistributedNeutralInjection）** 订阅端 j 每周期聚合
```
x_j(t) = ⊕_{m∈In(j)} ( valid_m(t) ? x_m(t) : v_m^⊥ )
valid_m ⇔ [D_m 内收到 m] ∧ [seq/CRC 合格] ∧ [lifecycle_m=active]
```
注入**幂等**：valid_m=false 重复成立不改变 x_j；失败只在本地端口的聚合项上体现，故不同订阅端可独立退化。

**新增定义 542（契约时偏 ContractSkew）** δ_κ(t)=|τ_L(t)−τ_R(t)|+λ_max，λ_max 为单跳传输延迟上界。协同安全要求 δ_κ ≤ δ_max；δ_max 由引理 90 的裕度侵蚀界反解得到。

**新增定义 543（双臂相对位姿与相对风险）** r_t=(T_L^W)^{-1}T_R^W；相对间隙 g^{rel}、相对速度 v^{rel}；相对协方差 Σ_rel ≈ J(Σ_L+Σ_R)J^T。当两臂误差以共模 e_c 为主时，Σ_rel 中 e_c 项解析相消，故 risk_SLAM^{rel} 用 Σ_rel 而非 Σ_L+Σ_R 计算。

**新增定义 544（相对证书 RelativeCertificate）**
```
ĝ_min^{rel} = min_{k≤K} F̂^{rel}_clearance(...) − β_rel
ê_max^{rel} = max_{k≤K} F̂^{rel}_effort(...) + β_rel
```
证书有效 ⇔ ĝ_min^{rel} ≥ d_safe^{rel} ∧ ê_max^{rel} ≤ τ_eff ∧ ρ̂_chain ≤ ρ_max ∧ γ̂_grasp^{rel}=valid。总证书 C_t=C_t^{abs} ⊓ C_t^{rel}，二者缺一不可（臂-障碍仍需绝对证书）。

**新增定义 545（闭链残差 ClosedChainResidual）** 闭链激活时
```
ρ_t = ‖ log( (r_t^g)^{-1} · r_t ) ‖_∨        （SE(3) 对数范数）
```
r_t^g 为抓取建立时的相对位姿；ρ_max 由末端柔顺与打滑实验标定（E579）。ρ_t>ρ_max 视为闭链破裂，立即降 Mode-LeaderFollower。

**新增定义 546（联合中止点 CoupledAbortPoint）** p∈P_t^{LR} 当且仅当
```
(i)  两臂各自单臂停车不变式成立（继承定义 534）
(ii) 若闭链激活：|t_stop^L(p) − t_stop^R(p)| ≤ τ_sync
     且停驻全过程 ρ_t ≤ ρ_max（刹车或合规保持）
```
执行时取 ≤ 当前步的最大 p*；若 P_t^{LR}=∅ 则拒绝该块并降 Mode-LeaderFollower。

**新增定义 547（协同屏障 CoordinationBarrier）** 每决策纪元 e 执行两阶段：
```
propose(e, δ̂) → 两臂各自确认 → commit(e)
commit 成功 ⇔ 两臂确认 ∧ δ̂ ≤ δ_max ∧ ρ̂_chain ≤ ρ_max
```
状态机终态 {committed, aborted, timeout}；δ̂>δ_max 或超时 T_bar 则 commit 失败并降级。

**新增定义 548（双臂动作块 BimanualActionChunk）** ζ_t^{LR}=(a_L^{1:K}, a_R^{1:K}, Ĉ_t^{rel}, P_t^{LR})，5Hz 生成，逐周期成对执行；50Hz 守卫须同时检查两臂的证书有效性与停车不变式。

**新增定义 549（协同模式格 CoordinationMode）** M_co∈{Coupled ≺ LeaderFollower ≺ Independent ≺ SingleArm}，从左到右耦合约束单调减弱、安全裕度单调不减；每次降级不得跳级回退，只允许逐级降解（引理 92）。

# IP-357 ROSContractBridge：契约 → ROS 2 QoS/lifecycle，订阅端本地中立元注入
class ROSContractBridge:
    def __init__(self, contracts, clock):
        self.contracts = {c.name: c for c in contracts}
        self.clock = clock
        self.last_valid = {}                      # port -> (seq, t_recv)

    def to_qos(self, c):
        return QoSProfile(
            reliability=RELIABLE if c.critical else BEST_EFFORT,
            durability=TRANSIENT_LOCAL if c.stateful else VOLATILE,
            deadline=Duration(seconds=c.deadline_ms / 1000.0),
            liveliness=LivelinessPolicy.MANUAL_BY_TOPIC,
            liveliness_lease_duration=Duration(seconds=c.lease_ms / 1000.0),
            history=KEEP_LAST(depth=c.history_depth))

    def neutral_selector(self, port, msg, now):
        c = self.contracts[port]
        if msg is None or msg.seq <= self.last_valid.get(port, (0,))[0]:
            return c.fail_value                  # 定义 541：缺失/重放 → v^⊥
        if (now - msg.stamp) > c.deadline_ms:
            return c.fail_value                  # deadline 违约 → v^⊥
        self.last_valid[port] = (msg.seq, now)
        return msg.value

    def aggregate(self, port_values):
        acc = NEUTRAL[port_values.port]          # 恒等元起手，保证幂等
        for v in port_values:
            acc = acc ⊕ v                        # 本地聚合，失败项已替换
        return acc


# IP-358 BimanualRelativeCertifier：相对证书 + 联合中止点
class BimanualRelativeCertifier:
    def __init__(self, F_rel, beta_rel=0.015, d_safe_rel=0.12,
                 rho_max=0.02, tau_sync=0.03):
        self.F, self.beta_rel = F_rel, beta_rel
        self.d_safe_rel, self.rho_max, self.tau_sync = d_safe_rel, rho_max, tau_sync

    def relative_cert(self, poseL, poseR, grasp_ref, actionsL, actionsR):
        r = poseL.inverse() @ poseR
        pred = self.F.rollout(poseL, poseR, actionsL, actionsR)  # 相对指标轨迹
        g_rel = pred.min_rel_clearance - self.beta_rel           # 定义 544
        e_rel = pred.max_rel_effort + self.beta_rel
        rho = se3_log(grasp_ref.inverse() @ r).norm()            # 定义 545
        valid = (g_rel >= self.d_safe_rel and rho <= self.rho_max)
        return RelativeCert(g_rel, e_rel, rho, valid)

    def coupled_abort_points(self, state, cert, pred):
        pts = []
        for p in range(1, len(state.actionsL)):
            if not single_arm_stop_invariant(state.L, p):        # 定义 546(i)
                continue
            if not single_arm_stop_invariant(state.R, p):
                continue
            dt = abs(pred.t_stop_L[p] - pred.t_stop_R[p])
            rho_ok = max(pred.rho[p:]) <= self.rho_max           # 定义 546(ii)
            if dt <= self.tau_sync and rho_ok:
                pts.append(p)
        return pts                                              # 空集 → 降级

    def pair_guard(self, chunk, k_exec, liveL, liveR):
        if not chunk.cert_still_valid(liveL, liveR):
            return self.nearest_coupled_abort(chunk, k_exec)
        if not (stop_inv(liveL, chunk, k_exec) and stop_inv(liveR, chunk, k_exec)):
            return self.nearest_coupled_abort(chunk, k_exec)
        return ('continue', k_exec + 1)


# IP-359 CoordinationBarrier：两阶段同纪元屏障（超时本地判定，无死锁）
class CoordinationBarrier:
    def __init__(self, tau_sync=0.03, T_bar=0.05):
        self.tau_sync, self.T_bar = tau_sync, T_bar

    def sync(self, epoch, delta_hat, rho_hat):
        if delta_hat > self.tau_sync or rho_hat > self.rho_max:
            return 'aborted'                       # 立即降级，不等对端
        self.send_propose(epoch, delta_hat)
        deadline = now() + self.T_bar
        while now() < deadline:
            if self.peer_ack(epoch):
                return 'committed'
        return 'timeout'                           # 本地定时器终态（引理 91）


# 主闭环集成：MetricVoiceGauge-DARC
def metricvoicegauge_round_10(M, s, obs, armL, armR, ...):
    now = clock.now()
    values = {p: bridge.neutral_selector(p, subs[p].recv(), now)
              for p in bridge.ports}               # 定义 541，逐端口本地退化
    delta = abs(armL.clock.offset(armR.clock)) + transport_latency()
    rho_hat = relative_residual(armL.pose, armR.pose)

    if delta > M.delta_max or rho_hat > M.rho_max:
        mode = 'LeaderFollower'                    # 定义 549：先降协同
    else:
        mode = 'Coupled'

    if mode == 'Coupled':
        verdict = barrier.sync(epoch, delta, rho_hat)
        if verdict != 'committed':
            mode = 'LeaderFollower'
            chunk = follower_chunk(armL, armR)     # 从臂跟踪相对轨迹
        else:
            chunk = brc.generate_dual_chunk(
                armL.state, armR.state, delta, M.tau_dom, trust_ok(M))
        v, k = brc.pair_guard(chunk, k_exec, obs.L, obs.R)
        if v == 'abort':
            execute_coupled_stop(chunk, k) or mode = 'LeaderFollower'
    elif mode == 'SingleArm':
        armL.execute(safe_stop())
        chunk = ac.generate_chunk(armR.state, ...)  # 等价 v9 单臂
    else:
        chunk = follower_chunk(armL, armR)

    execute_dual(chunk, mode)
    C, cert, claims, metrics, rewards = M.inherited_v9_path(obs, mode)
    return C, cert, claims, metrics, rewards

## 4. 推导

**引理 87（分布式退化双模拟）** 设 δ_κ≤δ_max、注入幂等、且信道在有限丢失下最终触发 deadline。则 RCB 契约图的"失败→注入"可观测序列与 v9 集中式 MW 退化链在 stutter 意义下双模拟，故 v9 引理 83 的逐位等价在端口级成立。证明：定义关系 R 把集中式每周期状态与分布式每周期状态按端口配对；消息丢失/延迟映射为集中式"该模块本期超时"；注入幂等保证重复丢失只对应一次 stutter；lifecycle inactive 对齐 dormant。对周期数归纳，R 保持可观测标签集合。∎

**引理 88（相对证书的共模抵消与保守性）** 设绝对位姿误差分解为共模 e_c 与差模 e_d。若前向模型在信任域内一致且 ‖e_rel‖≤β_rel，则 ĝ_min^{rel} 是真实相对间隙的下界；且 Σ_rel ≼ J(Σ_L+Σ_R)J^T，当 e_c 主导时 Σ_rel ≪ Σ_abs，相对证书严格更紧。但臂-障碍间隙仍需 C_t^{abs}，故总证书取合取不可省。∎

**引理 89（联合中止可行性）** 若 P_t^{LR}≠∅，则存在协同安全停驻；若 P_t^{LR}=∅，则 K_eff=1 且降 Mode-LeaderFollower（或合规保持）仍保证 ρ≤ρ_max。证明：P_t^{LR} 的 (i)(ii) 直接给出两臂各自可停且相对残差有界；空集分支由模式格的保守性（引理 92）与从臂刚性跟踪的残差界保证。∎

**引理 90（时偏裕度侵蚀界）** 若用存在真实时偏 δ 的时间戳评估相对证书，则两臂状态不一致导致的最坏位置误差 ≤ v_max·δ。故仅当 d_safe^{rel} > v_max·δ_max + β_rel 时引理 88 的结论才成立；一旦 δ>δ_max，相对证书不再可靠，必须降 Mode-Independent 且 K_eff=1。∎

**引理 91（协同屏障活性/无死锁）** 两阶段屏障在超时 T_bar 与有限重传下，最迟 2T_bar 进入 committed 或 aborted，不会出现双臂互等。证明：状态机三终态吸收；超时由本地定时器判定，不依赖对端消息，故单侧永远可推进。∎

**引理 92（退化单调性与安全传递）** 沿格 Coupled→LeaderFollower→Independent→SingleArm，每步的可用安全裕度非减、耦合约束非增。证明：LeaderFollower 把相对约束降为跟踪误差界；Independent 取消闭链并取 K_eff=1；SingleArm 只保留单臂 v9 证书。逐步代入引理 88–90，可知每步可行域包含前一步，故安全性由 v9 引理 80–86 传递。∎

## 8. 本轮最大风险

**一句话**：双臂协同证书以"两臂状态属于同一时刻"为前提，而 ROS 2 的分布式时钟偏差与传输延迟恰好让两臂在"各自认为安全"的不同瞬间共同越过边界——最需要协同的中止时刻，联合中止点集却建立在互不一致的时间戳上。
