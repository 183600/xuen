# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧」IP-253~263；灵感循环第 2 轮；本轮灵感：「传感器融合」×「位姿估计」）

> R69 把不确定性一分为二：aleatoric 沿用 R68 铁律，epistemic 交给「流匹配多模态策略 + 主动多模态交互」去问、去看、去触。它问出了「**我该向谁求证**」，却仍站在一个从未被质疑的假设上：**每一条残差、每一个流似然、每一份模态权重，都产生于「我所认为的那个坐标系」里**。R68 的标定只估传感器外参；可智能体自身的位姿、以及「世界帧到底在哪」这一隐藏变量，错了也没人知道。R69 自陈的最大风险（模态权重不可信 → 自信地追问幻影）与 R68 自陈的最大风险（缓变故障被标定吸收）其实是同一个病：**帧错了，下游所有推理都自洽地错**。
>
> 本轮两个灵感正好补上这一层：
> - **传感器融合**告诉我们：多个传感器「都同意」不等于「独立」。若误差共模（起雾、强磁、结构化混叠），融合 N 个传感器只得到 1 个证据。独立性不是数出来的，是**估**出来的。
> - **位姿估计**告诉我们：不确定性长在 SE(3) 流形上，天然有「连续（协方差）」与「离散（多假设/混叠）」两部分——这恰好是 R69 的 aleatoric/epistemic 二分在几何层的**第二个实例**，而不是另起炉灶。
>

>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我此刻站的位置，真是我以为的那个位置吗**」——几何是所有更上层问题的地基；地基塌了，问得越主动，错得越自信。

## 0. 直觉与动机

**灵感 1（传感器融合 → 独立性的幻觉）**
直觉：R69 的证据纪律是「k 个正交证据源一致才可定案」。但正交性是训练环境的偶然性质，不是物理保证。雾天里 N 个相机看到的是同一团雾；强磁附近所有磁力计一起偏；重复走廊里所有视觉特征一起混叠。把它们融合，方差不会按 1/N 收缩，而会趋向单传感器水平。把「有多少个传感器」换成「**有效独立证据数 N_eff**」，R69 的纪律才真正成立：`N_eff = σ_max²·1ᵀΣ_ε⁻¹1`，等相情况下恰为 `N/(1+(N−1)ρ)`。当 ρ→1，N_eff→1——此时「多传感器一致」不能作为任何重新锚定/交互定案的依据。

**灵感 2（位姿估计 → 不确定性有两个几何形态）**
直觉：位姿误差不是一个标量。连续部分是某个假设内的协方差（Cramér–Rao 下界，噪声不可约）；离散部分是「我到底在哪个假设里」（重复房间、对称走廊、镜面、周期结构）。前者对应 R69 的 `U_ale`，后者对应 `U_epi`，可约性则取决于假设之间的**流形间距** `Δ_min^geo`。因此 R70 不是给 R69 再叠一个黑箱，而是把同一套二分**下移到几何层**：几何是语义的条件，语义是几何的下游。这保持「新层必须是旧层的严格泛化」这一理论姿态。

**灵感 3（视角即信息 → 会撒谎的嘴 vs 不会撒谎的腿）**
直觉：R69 解决歧义靠「问」，但问会被投毒、会被社交工程。位姿估计给出另一类信息动作：**移动以获得基线（baseline）**。三角化的深度不确定度 ∝ 1/b，回环消歧的增益随基线超线性增长。关键是：**运动不能被语义欺骗**（环境可以骗你的标签，却很难同时骗过视差与里程计的一致性）。代价是运动**不可逆**（问错了可以再问，走错了回不来）、且必须过安全认证。于是 R70 的交互优化不是「问 vs 不看」，而是「**问 vs 走**」——廉价但可被投毒 vs 昂贵但物理可验证。

**灵感 4（依赖顺序 → 几何未定则语义免谈）**
直觉：若位姿混叠未消解，R69 的模态权重是在一个错误帧里算出来的，VoI 再精确也无意义。所以必须有一个**几何门（FCS）**：几何未定 → 冻结帧、禁用重锚定、禁用 R69 的语义交互，退化为纯保守。这直接复用了 R69 的 MCG 思路（ECE 越界即退回 R68），形成一致的「信任层级」：**几何 → 语义 → 动作**。

**灵感 5（新攻击面 → 混叠是「自信地错」）**
直觉：R69 的新风险是「问错」。R70 的新风险更阴险：**对称环境下的假回环**。一个重复的走廊会给出与真值统计上无法区分的位姿假设；若系统自信接受，它会把一个本来正确的标定「修正」坏，或者为了视差主动走进一个对称陷阱。**看得更清，可能要求你走到一个会骗你的地方**。所以本轮必须交付：混叠集显式化、回环门、`N_eff` 证据门、视差运动的安全认证、以及「几何通道与语义通道的零空间必须不相交」这一可检验命题。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（PARALLAX-RAS 总览）** PARALLAX-RAS = (SE3-UQ, FGF, NEB, ECR, GAF, PAA, GSD, RAS-WM‡)。三条不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **几何预算硬约束**：单位时间视差位移 ≤ b_max、重锚定/重标定 ≤ 1 次/窗口，且任一几何信息动作必须通过与任务动作相同的 C-RAS-WM 认证（在**混叠并集**上认证，见定义 320）；
(iii) **几何证据纪律**：任何帧重锚定/外参重估须同时满足 `N_eff ≥ k_min`（定义 314）、混叠集已收敛（定义 315）、ECR 未越界（定义 316），否则帧保持不变、走保守兜底。

**定义 311（帧图与鲁棒融合 FGF）** 变量 `X = {T_wb(t)} ∪ {T_bs}_{s∈S} ∪ {p_l}`，其中 `T_wb ∈ SE(3)` 为机体位姿、`T_bs` 为传感器外参、`p_l` 为路标。因子残差 `r_k = log((T_i^{-1}T_j)^{-1}Z_k)^∨`，用鲁棒核 ρ（Huber/Cauchy/GM）做固定滞后平滑（fixed-lag smoother）。MAP：`X* = argmin_X Σ_k ρ(‖r_k‖²_{Σ_k})`。增量求解只在关键帧或触发时进行（定义 324）。

**定义 312（SE(3) 不确定性二分 SE3-UQ）** 在当前线性化点取 `H = JᵀWJ`，`Σ_ale = (H + λI)^{-1}`（边际协方差用 Schur 补消去路标）。多假设 `H = {(T^{(m)}, Σ^{(m)}, w_m)}`（回环/对称产生的局部极小）。定义：
`U_ale^geo = Σ_m w_m · tr(Σ^{(m)})`（假设内、连续、不可约）；
`U_epi^geo = H_mode^geo · g(Δ_min^geo)`，`H_mode^geo = −Σ_m w_m log w_m`，`Δ_min^geo = min_{m≠m'} ‖log((T^{(m)})^{-1}T^{(m')})‖ / √(λ_max(Σ^{(m)})+λ_max(Σ^{(m')}))`（假设间、离散、可约）。
——这与定义 296–297 同构：**几何层是 R69 二分的一个忠实实例**，不是加和项。

**定义 313（共模传感器融合）** 传感器噪声分解 `ε = Bz + η`，`z ~ N(0,Σ_z)` 为共模因子，`B` 为载荷矩阵，`η` 为独立噪声。融合协方差 `Σ_ε = BΣ_zBᵀ + D`。共模相关性用「去运动后的跨传感器残差相关」在线估计，避免把真实运动误判为共模。鲁棒核吸收离群；共模项**不被鲁棒核吸收**（它是协方差结构，不是离群）。

**定义 314（有效独立证据数 NEB）** `N_eff = σ_max² · 1ᵀΣ_ε⁻¹1`，`σ_max² = max_s Σ_{ε,ss}`。等相 `Σ_ε = σ²[(1−ρ)I+ρ11ᵀ]` 时 `N_eff = N/(1+(N−1)ρ)`。证据纪律升级为：`N_eff ≥ k_min`（默认 2），而非「传感器个数 ≥ k」。**R69 的 k-正交纪律是 `ρ=0` 的特例**。

**定义 315（混叠集 GAF）** `A(o;ε_alias) = {T^{(m)} : −log p(o|T^{(m)}) ≥ max_{m'} −log p(o|T^{(m')}) − ε_alias}`。`|A|>1` ⇔ 几何混叠（对称/重复结构/镜像）。混叠集在对称群 `G_sym` 下不变；其李代数 `g_sym = Lie(G_sym)` 称为**不可辨方向**。

**定义 316（等变一致性残差 ECR）** 对 SE(3)-等变的动作头 π（或流策略的等变分量），取群样本 `T_g`：
`ECR(o) = E_{T_g}[ d_{SE(3)}(π(T_g·o), T_g·π(o)) ]`。
标称下 `ECR ≤ ε_eq`。设策略学到的等变稳定子 `I_π = {δ : π(exp(δ)·o)=exp(δ)·π(o), ∀o}`；则非稳定子方向的外参漂移 δ 满足 `ECR ≳ c·‖δ_{⊥I_π}‖`。**标定能吸收 r_res，却无法同时对所有传感器恢复群作用**——除非漂移是整个传感刚体的全局运动。这是继 R68 残差、R69 流似然之后的**第三条独立通道**。

**定义 317（视差信息动作 PAA）** 几何信息动作 `g_geo = ΔT ∈ SE(3)`（短时程位移/转视角）。信息增益
`VoI_geo(ΔT) = H(M|o) − E_{z~p(·|ΔT,o)}[H(M|o,z)]`，
其中 M 为几何假设（含混叠身份）。约束：`risk(ΔT) ≤ ε_p`、`baseline(ΔT) ≥ b_min`（若需三角化）、位移 ≤ b_max、且必须过 C-RAS-WM 认证。**关键性质：若 `ΔT ∈ g_sym`（沿不可辨方向移动），则 `VoI_geo(ΔT)=0`**——沿对称轴走再远也消不了混叠，必须朝商空间方向（横向）移动。

**定义 318（联合获取控制器 MINT-G）** 候选 `𝒢 = 𝒜_info^sem ∪ 𝒜_info^geo`（问/看/触 ∪ 视差/重定位）。以**联合互信息** `I(M_sem, M_geo; y | g, o)` 计增益，避免语义与几何对同一假设重复计费。选择
`g* = argmax_{g∈𝒢} [VoI_joint(g) − c(g) − η_irr(g)]`，s.t. 安全与预算；
其中 `η_irr(g)` 为不可逆惩罚（运动 > 询问）。`VoI_joint ≤ 成本` ⇒ 不获取、直接保守。**当两条通道增益相当时，优先几何通道**：它不可被语义投毒。

**定义 319（标定不可吸收性 / 零空间判据）** 设 `A = ker(∂r_single/∂δ)` 为单传感器残差不变的标定可吸收子空间，`L = ∂r_loop/∂δ` 为回环残差灵敏度，`G = ker L ∩ ker(∂r_single/∂δ)` 为全局刚体规范（不可观测）。命题：在非退化运动与传感器配置下 `A ∩ ker L = G`。于是任何**非全局**漂移必落在 (单传感器残差通道) ∪ (回环通道) 的并集里：标定能骗过前者，骗不过后者。

**定义 320（帧感知安全 GSD）** 视差运动、帧重锚定、外参重估必须以**混叠并集包络** `E(A) = ⋃_{T∈A} E(T)` 做安全认证；`|A|>1` 时取最坏情形。视差运动风险 ≤ ε_p；不可逆运动的认证标准比可逆信息动作严格一档。任一不过 ⇒ 该几何动作作废，帧保持，U_epi^geo 视为未消解。

**定义 321（帧一致门 FCS 与两级退避）** 几何门判据
`geo_unresolved := (U_epi^geo > τ_geo) ∨ (|A| > 1) ∨ (ECR > τ_ecr) ∨ (N_eff < k_min)`。
若 `geo_unresolved`：冻结最近一次**已认证**帧 `T*`，禁用重锚定与外参重估，**并禁用 R69 的语义 VoI 交互**（模态权重在错误帧下无意义），风险缩放
`λ = λ_floor(U_ale^geo + U_epi^geo + U_ale + U_epi)`；
若几何已消解（预算内、证据纪律满足）：允许语义交互与重锚定，且
`λ = λ_floor(U_ale^geo + U_ale)`（获得**几何 resolution bonus**）。
⇒ R69（乃至 R68）是本层「永不视差 / 无混叠 / `N_eff<k_min`」边界上的逐指令退化，安全侧永不变弱。

**定义 322（证书 J_PARALLAX）** `J_PARALLAX = (J_FLUID, N_eff, |A|, U_epi^geo_before/after, ecr_p95, loop_res_p95, frame_anchor_hash, geo_budget_used, parallax_ver)`。Valid ⇔ Valid(J_FLUID) ∧ `N_eff ≥ k_min`（凡执行了几何动作）∧ 无未收敛混叠 ∧ `ECR ≤ τ_ecr` ∧ 认证包络一致。

**定义 323（干扰模型与审计 AIC-PARALLAX / VQAuditor-G）** `ℰ_PARALLAX = ℰ_FLUID × ℰ_geo`，`ℰ_geo` 含：帧欺骗（对抗标签/路标）、重放攻击、**共模注入**（雾/尘/强磁/电磁干扰使多传感器同时相关）、**假回环**（利用对称结构制造高似然错误位姿）、**视差陷阱**（诱使智能体走入对称区域以制造混叠）。VQAuditor-G 审计：是否在混叠未收敛时接受回环、是否高估 `N_eff`、视差运动是否按并集包络认证、重锚定是否被单一模态驱动。

**定义 324（几何健康门控与自适应预算）** 廉价 `geo_head(z_t, r_res)` 预测几何健康度；仅当 `geo_head` 报警或 `ECR/回环残差` 越界时运行多假设平滑与完整 GAF；否则只维护单假设固定滞后平滑。视差预算按「几何熵下降速率 / 位移成本」动态分配，保证 P99 实时。

```python
# IP-264 SE3-UQ：流形上的不确定性二分（与 R69 定义 296-297 同构）
def decompose_geo(Sigma, hyps):
    U_ale = sum(h.w * trace(h.Sigma) for h in hyps)       # 假设内、Cramér-Rao
    U_epi = entropy([h.w for h in hyps]) * sep_geo(hyps)  # 假设间、混叠
    return U_ale, U_epi

# IP-265/266 FGF + NEB：共模感知融合与有效独立证据数
class GeometricFusion:
    def step(self, obs, odo, trigger):
        T, Sigma, hyps = self.smoother.update(obs, odo, full=trigger)  # 固定滞后
        Neff = self.common_mode.effective_count(self.residuals)
        alias = self.alias_set(obs, hyps, self.eps_alias)
        return T, Sigma, hyps, Neff, alias

def effective_count(Sigma_eps):
    sigma_max2 = max(diag(Sigma_eps))
    return sigma_max2 * ones @ inv(Sigma_eps) @ ones          # 定义 314

# IP-267 ECR：等变一致性（标定不可吸收的第二意见，第三通道）
def ecr(policy, o, group_samples):
    return mean(se3_dist(policy(T * o), T * policy(o)) for T in group_samples)

# IP-268 PAA + MINT-G：视差 vs 询问的联合 VoI 选择
def choose_acquisition(hyps, sem_modes, o, budget):
    best = None
    for g in sem_info_actions(sem_modes) + parallax_candidates(hyps, g_sym):
        if not budget.allow(g): continue
        if not c_ras_wm.certify(g, o, envelope=alias_union(hyps)): continue
        score = (joint_mutual_info(hyps, sem_modes, g, o)
                 - cost(g) - irreversibility(g))             # 运动不可逆惩罚
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-269 GAF 回环门：混叠未收敛 + 证据不足 + ECR 越界 → 拒绝重锚定
def guard_reanchor(candidate, alias, Neff, e):
    return (len(alias) == 1) and (Neff >= K_MIN) and (e <= TAU_ECR)

# IP-270 PARALLAX-RAS 主闭环（继承 R69，仅在几何层插入门控）
def PARALLAX_RAS_round(M, obs, odo):
    trig = M.geo_head(M.z_t, M.last_r_res) > TAU_GH
    T, Sigma, hyps, Neff, alias = M.fgf.step(obs, odo, trig)
    U_ale_g, U_epi_g = decompose_geo(Sigma, hyps)
    e = M.ecr.eval(M.fmp, obs, M.group_samples) if trig else 0.0
    geo_unresolved = (U_epi_g > TAU_GEO) or (len(alias) > 1) \
                     or (e > TAU_ECR) or (Neff < K_MIN)

    # R69 语义层（仅在几何可信时启用）
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(obs, K=M.k), M.z_t, M.fmp.mode_head)
    g = (M.mintg.choose_acquisition(hyps, modes, obs, M.budget)
         if (not geo_unresolved and U_epi > TAU_EPI) else None)
    if g is not None:
        ans = M.cia.execute(g)
        if is_geometric(g) and guard_reanchor(ans, alias, Neff, e):
            M.fgf.reanchor(ans, envelope=alias_union(hyps))   # 仅当三重证据齐备
        U_epi_after = M.cia.update_belief(modes, ans)
    else:
        U_epi_after = U_epi

    # 两级退避：几何未定则把几何 + 语义 epistemic 一并视为不可约
    if geo_unresolved:
        U_floor = U_ale_g + U_epi_g + U_ale + U_epi_after
        lam = max(M.efs.risk_scale(...), lam_floor(U_floor), 0.8)
        frame = M.last_certified_frame
    else:
        U_floor = U_ale_g + U_ale
        lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
        frame = T
    A = M.ach.propose(frame, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds, envelope=alias_union(hyps))
    M.vqa_g.submit_async(g, Neff, alias, U_epi_g, e, lam)
    return k, lam, frame, (U_ale, U_epi_after, U_ale_g, U_epi_g)
```

## 3. 推导

**引理 19（共模下的有效独立证据数）** 设 N 个等方差 σ²、相关系数 ρ 的传感器估计同一标量，GLS 估计方差 `Var = σ²(1+(N−1)ρ)/N`，故 `N_eff = N/(1+(N−1)ρ)`。推论：ρ→1 时 `N_eff→1`，与 N 无关；R69 的「k 个正交源」纪律仅在 ρ=0 时成立，必须替换为 `N_eff ≥ k_min`。这也解释了为何「多传感器一致」在共模攻击下是伪证据。

**引理 20（几何反吸收：三通道零空间不相交）** 设 δ 为传感器 s 的外参慢漂移。若被 R68 标定吸收，则单传感器残差不变，`δ ∈ A`。回环残差连接两个经不同传感器锚定的位姿，其灵敏度 `L` 对非全局 δ 非零（回环乘积中 `T_bs T_ss'` 随 δ 变化，除非 δ 同时作用于整个刚体，即 δ∈G）。故 `A ∩ ker L = G`。结合 R68 的 `r_res`（测单传感器自洽）与 R69 的 `Δa`（测行为自洽），三通道零空间两两不同、交为规范 ⇒ **任何非全局漂移至少被一条通道看见**。这是对 R68/R69 最脆弱处的闭合，而非叠加。

**引理 21（视差消歧增益与对称退化）** 设混叠集 A 在 `G_sym` 下不变，`g_sym = Lie(G_sym)`。若 `ΔT ∈ g_sym`，则对任意假设 `T^{(m)},T^{(m')}∈A` 有 `p(o'|T^{(m)},ΔT)=p(o'|T^{(m')},ΔT)`，故 `VoI_geo(ΔT)=0`。反之，若 `ΔT` 在商空间方向的投影为 `b_⊥`，对间距为 `Δ` 的两假设，正确消歧概率下界为 `1−exp(−c·b_⊥²Δ²/σ²·(1−ρ_cm))`。系：**消歧增益是「横向基线与有效独立性」的函数**；沿对称轴移动既浪费预算又可能深入混叠区（视差陷阱）。

**引理 22（ECR 对外参漂移的敏感性）** 若 π 在标称下 SE(3)-等变，则 `ECR=0`；对非稳定子方向漂移 δ，`ECR ≥ c·‖δ_{⊥I_π}‖`。per-sensor 漂移无法被单一全局外参修正同时消除（各传感器群作用不一致），故 ECR 残差持续存在。⇒ ECR 是既不被标定吸收、也不被策略训练吸收（除非策略显式学了该漂移，此时定义 316 的 `I_π` 将其识别为「已学不变性」，并触发更强的几何审计）。

**定理 18（PARALLAX 严格包含 FLUID/R68）** 在 A95–A99、定义 314/319/321 下，PARALLAX 的任意状态期望风险 ≤ FLUID ≤ R68；当 `U_epi^geo ≤ τ_geo`、`|A|=1`、`N_eff ≥ k_min`、`ECR ≤ τ_ecr` 且无视差预算时，三者**逐指令相同**。R68/R69 是本层在「永不视差、无混叠、完全独立」边界上的退化。

**定理 19（帧感知安全与无突变）** 视差运动与重锚定在混叠并集包络 `E(A)` 上认证后，物理风险 ≤ ε_p；帧在 `geo_unresolved` 时冻结、λ 单调不降地退化到保守；提交/换装不变式（R68 定理 15）保持 ⇒ 控制连续、无突变。

**定理 20（几何证据可靠性）** 若每次重锚定都满足 `|A|=1 ∧ N_eff ≥ k_min ∧ ECR ≤ τ_ecr`，则单一共模注入或单次假回环导致错误重锚定的概率 ≤ `f(δ_geo, N_eff)`，且随 `N_eff` 指数下降；单模态/单次观测永不单独重锚定。系：**几何层把「多数传感器同意」升级为「有效独立 + 混叠收敛 + 等变自洽」的三重门**。

## 6. 本轮最大风险

**一句话**：PARALLAX-RAS 的全部新增能力押在「回环与视差给出的几何证据是对的」这一前提上——但**位姿估计最危险的失败恰恰是「自信地错」**：对称/重复结构可产生与真值统计上无法区分的假回环，系统一旦据此重锚定或重标定，会**把一个本来正确的帧改坏**；更糟的是，为获得视差而主动移动，可能把智能体从安全区带进对称陷阱——**看得更清，要求你走到一个会骗你的地方**。几何层的引入因此不是消除 R69 的「问错」，而是把「问错」升级为「**走错**」，后者的不可逆性更高。

**次级风险与缓解**：
1. **假回环/对称混叠** → 混叠集显式化 + `|A|=1` 才允许重锚定 + 横向视差验证（引理 21、定理 20）；
2. **共模注入伪独立** → `N_eff` 替代传感器计数 + 共模在线估计 + E311 对抗训练；
3. **视差运动不安全/不可逆** → 混叠并集包络认证 + 不可逆惩罚 + 定理 19；
4. **ECR 被策略「学会」吸收** → 监控 `I_π` 增长、把「学到的漂移不变性」纳入审计，定期用独立几何通道复核；
5. **实时预算被几何层击穿** → `geo_head` 门控 + 仅触发多假设 + 自适应视差预算（定义 324）。

```python
         if (not geo_unresolved and U_epi > TAU_EPI) else None)
    if g is not None:
        ans = M.cia.execute(g)
        if is_geometric(g) and guard_reanchor(ans, alias, Neff, e):
            M.fgf.reanchor(ans, envelope=alias_union(hyps))
        U_epi = M.cia.update_belief(modes, ans)

    if geo_unresolved:
        U_floor = U_ale_g + U_epi_g + U_ale + U_epi
        lam = max(M.efs.risk_scale(...), lam_floor(U_floor), 0.8)
        frame = M.last_certified_frame
    else:
        lam = max(M.efs.risk_scale(...), lam_floor(U_ale_g + U_ale))
        frame = T
    k = M.c_ras_wm.certified_prefix(M.ach.propose(frame, M.vista.H), ...,
                                    wm_preds, envelope=alias_union(hyps))
    M.vqa_g.submit_async(g, Neff, alias, U_epi_g, e, lam)
    return k, lam, frame, (U_ale, U_epi, U_ale_g, U_epi_g)
```

## 4. 推导

**引理 19（共模有效独立证据数）** N 个等方差、相关系数 ρ 的传感器，GLS 融合方差 `σ²(1+(N−1)ρ)/N`，故 `N_eff=N/(1+(N−1)ρ)`；ρ→1 时 `N_eff→1`。故 R69 的「k 个正交源」只在 ρ=0 成立，必须改为 `N_eff ≥ k_min`。

**引理 20（几何反吸收，三通道零空间不相交）** 被标定吸收的漂移 `δ∈A=ker(∂r_single/∂δ)`；非全局 δ 使回环灵敏度 `Lδ≠0`（除非作用于整个刚体，即 `δ∈G`），故 `A∩kerL=G`。结合 R68 的 `r_res` 与 R69 的 `Δa`，三通道交为规范 ⇒ 非全局漂移至少被一条看见。

**引理 21（视差增益与对称退化）** 若 `ΔT∈g_sym`，则对 `A` 中各假设观测分布相同，`VoI_geo=0`；若横向投影为 `b_⊥`，正确消歧概率下界 `1−exp(−c·b_⊥²Δ²(1−ρ_cm)/σ²)`。系：消歧增益依赖横向基线与有效独立性；沿对称轴移动既浪费预算又可能深入陷阱。

**引理 22（ECR 敏感性）** 标称等变 ⇒ `ECR=0`；非稳定子漂移 `ECR≥c‖δ_{⊥I_π}‖`；per-sensor 漂移无法被单一全局外参修正同时消除，故残差持续。⇒ ECR 是标定/策略都难以吸收的第三通道。

**定理 18（严格包含）** A95–A99 下，PARALLAX 期望风险 ≤ FLUID ≤ R68；当 `U_epi^geo≤τ_geo ∧ |A|=1 ∧ N_eff≥k_min ∧ ECR≤τ_ecr` 且无视差预算时，三者逐指令相同。R68/R69 是「永不视差、无混叠、完全独立」边界上的退化。

**定理 19（帧感知安全与无突变）** 视差/重锚定在并集包络 `E(A)` 上认证后风险 ≤ ε_p；`geo_unresolved` 时帧冻结、λ 单调不降退化；提交/换装不变式保持 ⇒ 控制连续无突变。

**定理 20（几何证据可靠性）** 若每次重锚定满足 `|A|=1 ∧ N_eff≥k_min ∧ ECR≤τ_ecr`，则单次共模注入或单次假回环致错重锚定概率 ≤ `f(δ_geo,N_eff)`，随 `N_eff` 指数下降；单模态/单观测永不单独重锚定。

## 7. 本轮最大风险

**一句话**：PARALLAX-RAS 的新增能力押在「回环与视差给出的几何证据是对的」之上，但位姿估计最危险的失败是「**自信地错**」——对称/重复结构可给出与真值统计不可区分的假回环，系统据此重锚定或重标定会**把正确的帧改坏**；而为获得视差主动移动，可能把智能体从安全区带进对称陷阱。几何层不是消除 R69 的「问错」，而是把「问错」升级为不可逆的「**走错**」——**看得更清，要求你走到一个会骗你的地方**。

**次级风险与缓解**：假回环/混叠（混叠集 + `|A|=1` 才重锚 + 横向视差验证）；共模伪独立（`N_eff` + 共模在线估计 + E311）；视差运动不安全/不可逆（并集包络认证 + `η_irr` + 定理 19）；ECR 被策略学会吸收（监控 `I_π` + 独立几何复核）；实时预算（`geo_head` 门控 + 触发式多假设 + 自适应视差预算）。
