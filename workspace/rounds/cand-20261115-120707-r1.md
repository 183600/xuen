# 第 1 轮（新灵感循环；基线继承第 5 轮 InstructGauge-RTDI）

> **基线**：InstructGauge-RTDI（IP-334–339；定义 468–492；引理 63–68；实验 E473–E492）。更早的 ToolGauge / InstructGauge / LeanGauge / MODGAUGE 退化链继续继承不变。
> 本轮纪律：**换域不换骨**。任务域从「盲区探测式工具使用」转到「接触丰富抓取 + 全身跌倒恢复」，但复用 CVC 契约、前缀封闭分块、不可逆屏障与严格退化链；新组件一律为**可选增强**，任一环节不可用都必须能一键退回。

## 0. 直觉与动机

**灵感 1（机械臂抓取 = 一串不可逆性递增的承诺）**
直觉：抓取不是「合拢手指」，而是接近 → 接触 → 闭合 → 载荷转移 → 抬起 → 搬运 → 释放的承诺链。每前进一步，可撤回的动作集合就缩小一点：接触前可自由改道，载荷转移后松手就可能摔坏物体。真正决定成败的不是末端位姿误差，而是**力闭合裕度**与**滑移前还能否安全退出**。这把「抓取」从纯位姿规划问题改写成**支撑/可恢复性问题**：抓取质量的核心指标是「在不确定性下仍能维持支撑、或在失去支撑前安全降级」。

**灵感 2（跌倒恢复 = 与冲击赛跑的分段保护）**
直觉：跌倒最危险的不是倒下，而是**冲击那一刻不可逆**。因此最优策略不是「倒得快、起得快」，而是把恢复提前到跌倒之前：先用捕获点/支撑多边形判断还能不能救，救不了就转为受控下降（收臂、护头、选着陆面、保护手中物体），落地后再分段自撑起。恢复不是一个策略，而是一条**带阶段门与不可逆点的策略链**；每个阶段的前置条件、后置条件与最坏执行时间都必须可审计。

**灵感 3（对偶与耦合：抓取失败是局部跌倒，跌倒是全身支撑失败）**
直觉：物体滑落是物体相对手的「支撑丢失」，机器人跌倒是质心相对支撑多边形的「支撑丢失」，二者共享同一个抽象——**支撑裕度跌破边界 + 事后恢复代价**。但必须克制：力闭合裕度（扳手空间、接触力学）与 CoM/捕获点裕度（位姿空间、全身动力学）**量纲不同、动力学不同**，不能粗暴合成一个标量阈值。正确的统一是**统一接口、统一门控逻辑、统一退化路径**，而不是统一数值。最尖锐的耦合场景是「抱着物体跌倒」：此时人安全 ≻ 物体完整 ≻ 自身结构 ≻ 任务完成，且「松手」与「触地」都是不可逆承诺，必须单步执行并交叉回执。

## 1. 研究问题（本轮要回答什么）

- **Q1（可恢复性的可测性）**：可恢复性能否在线估计，并给出**有校准保证**的下界，而不是一个无法验证的置信分数？
- **Q2（分块长度的边界治理）**：动作分块的块长能否由「到支撑边界的剩余时间」而非固定 K 或启发式决定，从而把证据陈旧窗口压到边界之内？
- **Q3（抓取—跌倒的统一口径）**：抓取与跌倒的支撑裕度能否共享同一门控与退化逻辑，同时避免错误合并不可通约的物理量？
- **Q4（耦合故障的分层恢复）**：「抱物跌倒」这类耦合故障下，分层安全序与不可逆屏障能否给出可审计、可复现的恢复选择？

## 2. 四条设计原则（正式化见产物区定义 493–508）

**P1 可恢复性优先（Recoverability First）**
契约的后置条件不再只写「任务成功」，而必须写「`ρ_LB(x) ≥ ρ_min` 且支撑裕度逐通道非负」。任务收益只能在可恢复核内优化；这相当于把 safety 与 objective 的分层从「动作级」提升到「恢复能力级」。

**P2 边界驱动承诺（Boundary-Governed Commitment）**
设 `τ*` 为按最坏导数界估计的「到最近支撑边界时间」，则块长满足 `K ≤ ⌊(τ* − T_react)/T_cycle⌋`，且块前缀封闭。直观：**证据陈旧窗口不得超过失效预警窗口**；一旦边界临近，分块自动退化为单步或保护动作。

**P3 不可逆屏障 + 分层安全序（Irreversibility Barrier + Lexicographic Safety）**
释放、触地、人体接触等不可逆动作强制 `K=1`，且需至少两个独立模态的回执交叉验证；恢复选择按 `人安全 ≻ 物体完整 ≻ 自身结构 ≻ 任务完成 ≻ 时间` 的字典序进行。该顺序只改变偏好，不扩大工具集，继承能力闭包。

**P4 分层校准（Regime-Conditioned Calibration）**
跌倒与滑移是稀有事件，且抓取/跌倒/抱物跌倒的分布显著不同；可恢复性下界必须按 regime 分别校准，并在目标 regime 与标定 regime 重叠不足时**拒绝给出保证**、退回保守几何裕度护盾，而不是外推一个虚假的置信度。

## 3. 与基线的接口（如何退化）

- 可恢复核估计器（RKE）不可用 ⇒ 仅用几何支撑裕度阈值护盾，等价于 SpatialCert 式截断；
- 边界驱动分块器（BGCG）不可用 ⇒ 固定小 K 执行，等价于 RTDI 分块；
- 分段恢复库（SRL）不可用 ⇒ 保护性停机或最近落点的受控放置；
- 失效预报器（FF）不可用 ⇒ 纯反应式截断，无预警保护，等价于 RTDI；
- 跌倒/抱物跌倒的 regime 校准样本不足或重叠检验失败 ⇒ 提高 `ρ_min`、强制 `K=1`、必要时转人机共管；
- 再往下：GFG 失效 ⇒ RTDI ⇒ InstructGauge-WR ⇒ InstructGauge v3 ⇒ ToolGauge ⇒ LeanGauge 纯数值路径 ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 把**可恢复性**提升为一等契约项，并给出 regime 条件共形下界与「无重叠则拒绝保证」的诚实口径；
2. 一个**边界驱动分块器**：块长由到支撑边界的剩余时间决定，给出「块内不越过边界」的充分条件与可证截断安全性；
3. 一个**统一但不合并**的抓取—跌倒支撑裕度接口，以及对应的分段恢复库与「抱物跌倒」字典序安全选择；
4. 一条完整可证伪路径：E493–E512 覆盖尾部校准、边界分块、滑移预警、受控跌倒、自撑起、sim-to-real、退化等价与 1kHz/50Hz 时序保全。

## 5. 本轮最大风险

**一句话**：可恢复性下界恰恰在最需要的「支撑边界附近」和「跌倒稀有样本」处最不可靠，sim-to-real 的动力学差异会系统性**高估**可恢复性，使护盾在真正临界时失效——这是尾部校准过自信的风险，而不是某个组件缺失的风险。

# 第 1 轮产物 · 创新点清单 v6：**GraspFall-Gauge（GFG）**——抓取—跌倒统一可恢复性门控

> 背景：第 5 轮 InstructGauge-RTDI（IP-334–339；定义 468–492；引理 63–68；实验 E473–E492）。
> 本轮灵感：「机械臂抓取」×「跌倒恢复」。
> **继承纪律**：CVC 契约、前缀封闭分块、不可逆屏障、能力闭包、SpatialCert、严格退化链全部保留。新组件一律为**可选增强**：任一环节不可用 ⇒ 退回 InstructGauge-RTDI ⇒ 退回 InstructGauge-WR ⇒ 退回 InstructGauge v3 ⇒ 退回 ToolGauge。

## 2. 形式化定义

**定义 493（抓取—跌倒混合系统）**
系统 `M = (X, U, W, f, Δ, S_safe, F_irr)`，其中
```
X = X_body × X_obj × X_contact
f: X × U × W → X        （含接触切换与摩擦/碰撞不确定性）
Δ ⊆ X × X               （接触建立、滑移、触地等离散跳变）
S_safe = {x : ∀i, σ̃_i(x) ≥ 0  ∧  dist(human, robot∪payload) ≥ d_keepout}
F_irr  = ImpactSet ∪ ReleaseSet   （进入后不可撤销）
```
`S_safe` 是「尚未失去支撑且未侵入人体禁入区」的闭集；`F_irr` 是冲击与释放两类不可逆事件的集合。

**定义 494（五通道支撑裕度）**
```
σ_bal(x)   = min{ dist(CMP(x), ∂P_sup(x)), dist(ξ(x), ∂P_sup(x)) } / L_ref
σ_grasp(x) = ε_FC(c(x)) / (‖w_ext(x)‖ + ε_0)          // Ferrari–Canny 力闭合裕度
σ_pay(x)   = min{ (f_grip − f_min(m, μ))/f_scale,
                  (f_max^frag − f_grip)/f_scale,
                  (τ_lim − ‖τ‖)/τ_scale }
σ_kin(x)   = min{ d(q, ∂Q_limit)/q_scale,  w(x)/w_scale }   // 关节限位 + 可操作度
σ_hum(x)   = (dist(human, robot∪payload) − d_keepout)/L_ref
```
其中 `CMP` 为质心动量枢轴，`ξ` 为捕获点，`P_sup` 为支撑多边形，`w_ext` 为外载荷扳手，`ε_FC` 为力闭合安全因子。**注意**：`σ_grasp` 在扳手空间，`σ_bal` 在位姿空间，二者不可通约，因此不定义「总裕度」。

**定义 495（归一化与门控）**
给定逐通道下限 `σ_i^min` 与尺度 `s_i > 0`，定义 `σ̃_i = (σ_i − σ_i^min)/s_i`。安全门控为
```
Gate(x) = 1  ⇔  min_i σ̃_i(x) ≥ 0
```
`min_i σ̃_i` 仅用于报警与可视化，**不作为**跨通道的安全判据；安全判据始终是逐通道合取。

**定义 496（到边界剩余时间与安全块长）**
沿候选策略 `π` 与扰动集 `W`，设 `L_i(x) ≥ 0` 为 `dσ̃_i/dt` 的已认证上界。定义
```
τ_i(x, π) = σ̃_i(x) / max(0, −L_i(x))   若 L_i(x) < 0；否则 +∞
τ*(x, π)  = min_i τ_i(x, π)
T_react   = T_detect + T_decide + T_actuate
H_safe    = max(0, τ* − T_react)
K_max     = ⌊H_safe / T_cycle⌋
```
`K_max` 是「在监控与否决仍来得及的前提下」允许的最大开环块长。

**定义 497（可恢复价值与可恢复核）**
设恢复目标集 `S_rec ⊆ S_safe`（稳定站立、稳定抓持、或已认证落点上的受控放置），恢复时域 `H_rec`，代价预算 `B_rec`。定义
```
V_rec^π(x) = Pr[ ∃t ≤ H_rec : x_t ∈ S_rec ∧ cost(π) ≤ B_rec | x_0 = x, w ∼ W ]
V_rec(x)   = sup_π V_rec^π(x)
K_ρ        = {x : V_rec(x) ≥ ρ}
```
与「安全停机」区分：`S_safe` 只要求不失去支撑/不伤人，`S_rec` 还要求任务可继续或物体已安全安置。

**定义 498（regime 条件共形下界）**
将状态按 `g ∈ {grasp-free, grasp-loaded, perturbed, falling, grounded, payload-fall}` 分层。对每层标定集 `D_g = {(x_j, y_j)}`（`y_j = 1[恢复成功]`），令 `V̂_rec` 为价值模型，非一致性分数 `s_j = V̂_rec(x_j) − y_j`，取共形分位数 `q_g = Quantile_{1−α}({s_j})`，输出
```
ρ_LB(x; g) = V̂_rec(x) − q_g
```
若目标 regime 与标定 regime 不满足重叠假设，则使用加权共形（密度比 `w`）或**拒绝保证**，退回定义 494 的几何裕度门控。

**定义 499（可恢复性屏障证书）**
函数 `B: X → R` 称为 `γ`-松弛可恢复性屏障证书，若
```
(1) x ∈ K̂_ρ            ⇒ B(x) ≥ 0
(2) x ∉ K̂_ρ \ N_γ      ⇒ B(x) < 0
(3) B(x) ≥ −γ ∧ u ∈ U_adm ⇒ ∀w ∈ W, B(f(x,u,w)) ≥ −γ
```
其中 `N_γ` 是证书误差邻域。条件 (3) 保证：只要护盾只执行 `U_adm` 内动作，`K̂_ρ` 在 `γ` 意义下前向不变。

**定义 500（承诺等级与不可逆屏障）**
动作承诺等级 `κ: A → {R, S, I}`：
```
R：接近、预成形、闭合、平衡步、自撑起中间相
S：载荷转移、受控下降、物体换手
I：释放、触地/冲击、人体接触、不可恢复的抓取点切换
```
不可逆屏障要求：任何含 `I` 级动作的块必须 `K=1`，且执行前后均需至少两个独立模态回执（腕部相机、力/力矩、关节编码器）交叉验证；**开环块内禁止出现 `I` 级动作**。

**定义 501（受护动作块）**
块 `C = (a_1…a_K)`，鲁棒可达管 `Γ_tube(x, C) = {X_1, …, X_K}`。称 `C` 为 `(ρ_min, γ)`-受护块，若
```
K ≤ K_max
且 ∀t ≤ K, ∀x ∈ X_t :
    Gate(x) = 1  ∧  ρ_LB(x; g(x)) ≥ ρ_min  ∧  B(x) ≥ −γ
```
若整块不可行，则取满足条件的**最大前缀**；若空前缀可行，则进入应急保护模式。

**定义 502（失效预报）**
预报器输出
```
F̂(x_t, history) = (mode ∈ {none, slip, balance, payload, multi}, T_lead, p_fail)
```
当 `p_fail > p_warn` 且 `T_lead ≤ H_prepare` 时触发预警保护（收臂/减速/加大抓取力/选择落点）。预报器需给出 lead-time 可靠性曲线，而不只是分类准确率。

**定义 503（字典序安全选择）**
结果向量 `O = (o_hum, o_pay, o_self, o_task, o_time)`，按
```
o_hum ≻ o_pay ≻ o_self ≻ o_task ≻ o_time
```
做字典序比较。恢复预案选择为
```
RP* = argmin_{RP ∈ SRL} LexMin( E[O | RP, x] )
```
该序只改变目标权重与候选排序，不改变工具集，继承能力闭包 `tools(RP) ⊆ T₀`。

**定义 504（分段恢复预案）**
```
RP = (stage, pre: Φ, post: Ψ, tools ⊆ T₀, WCET, κ, fallback)
```
抓取链阶段：`approach → contact → closure → load-transfer → lift → transport → release`；
跌倒链阶段：`perturb → capture-step → protective-descent → impact → grounded → self-right → stand → re-grasp`。
组合 `RP₁ ⊕ RP₂` 当且仅当 `Ψ₁ ⇒ Φ₂`，且 `κ(RP₁ ⊕ RP₂) = max(κ₁, κ₂)`；恢复预案自身也必须满足定义 501 的受护性（递归安全）。

**定义 505（负载安全契约）**
```
PSC = (m, com, I, fragility, keepout, drop_zones, f_min, f_max, a_max)
```
约束：`f_min(m,μ) ≤ f_grip ≤ min(f_max, fragility)`；`‖a‖ ≤ a_max`；仅在 `drop_zones` 内且 `dist(human, drop) ≥ d_safe` 时允许 `I` 级释放；跌倒过程中优先保持物体在人体之外并限制冲击姿态。

**定义 506（GFG-9C 闭环）**
```
W: 感知（腕部相机、力/力矩、关节编码器、IMU、足底/基座支撑）
R: 推理（任务/指令解析、场景与物体假设）
C: 契约规划（IAC + Kinematic-Loop + RT-CVC + PSC）
E: 执行（边界驱动分块；不可逆动作 K=1）
M: 监视（1kHz 五通道支撑裕度 + 屏障证书）
F: 预报（滑移/失衡/负载失效模式与 lead time）
G: 保护与恢复（SRL 分段恢复 + 字典序选择 + 人体禁入）
V: 验证（CVC + SpatialCert + 恢复证书 + 回执交叉验证）
U: 更新（Dbox、主张绑定、regime 校准集与原语统计）
```

**定义 507（尾部风险判据）**
对风险水平 `α` 与 regime `g`，定义尾部覆盖事件
```
TailCov(g) = Pr[ V_rec(x) ≥ ρ_LB(x; g) | x 属于 D_g 的最低 ⌈α·|D_g|⌉ 分位 ]
```
要求 `TailCov(g) ≥ 1 − α − δ_tail`，其中 `δ_tail` 为预注册的尾部容差；若样本量不足以估计该分位，则直接判定「不可保证」并强制保守模式。

**定义 508（混合关键性降级）**
GFG 主路径为高关键性（安全执行），RKE/FF/SRL 为低关键性增强。当计算或时间预算被挤压时，按
```
安全执行 > 人体禁入 > 不可逆屏障 > 恢复预案 > 失效预报 > 可恢复性优化
```
逐级丢弃低关键性任务，且每次降级都必须保持定义 495 的逐通道门控不变。

class SupportMarginMonitor:
    def __init__(self, L_ref, sigma_min, scales):
        self.L_ref, self.sigma_min, self.scales = L_ref, sigma_min, scales

    def read(self, state):
        raw = {
            "bal": self._balance_margin(state),
            "grasp": self._grasp_margin(state),
            "pay": self._payload_margin(state),
            "kin": self._kin_margin(state),
            "hum": self._human_margin(state),
        }
        return {k: (raw[k] - self.sigma_min[k]) / self.scales[k] for k in raw}

    def gate(self, state):
        m = self.read(state)
        return all(v >= 0 for v in m.values()), m

    def _balance_margin(self, s):
        cmp_pt, cap_pt = centroidal_moment_pivot(s), capture_point(s)
        poly = support_polygon(s)
        return min(dist(cmp_pt, poly.boundary), dist(cap_pt, poly.boundary)) / self.L_ref

    def _grasp_margin(self, s):
        return ferrari_canny_margin(s.contacts, s.object, s.w_ext)

    def _payload_margin(self, s):
        f_lo, f_hi = payload_force_bounds(s.m, s.mu)
        return min((s.f_grip - f_lo) / s.f_scale,
                   (f_hi - s.f_grip) / s.f_scale,
                   (s.tau_limit - norm(s.tau)) / s.tau_scale)

    def _kin_margin(self, s):
        return min(joint_limit_distance(s.q) / s.q_scale,
                   manipulability(s.q) / s.w_scale)

    def _human_margin(self, s):
        return (dist(s.human, s.robot_union_payload) - s.d_keepout) / self.L_ref


class RecoveryKernelEstimator:
    def __init__(self, value_model, alpha=0.1, n_min=200):
        self.value_model, self.alpha, self.n_min = value_model, alpha, n_min
        self.calibrators, self.support = {}, {}

    def calibrate(self, regime, xs, ys):
        scores = [self.value_model(x) - y for x, y in zip(xs, ys)]
        self.calibrators[regime] = ConformalQuantile(scores)
        self.support[regime] = {
            "n": len(xs),
            "overlap_ok": self._overlap_test(xs),
        }

    def rho_lb(self, x, regime):
        cal = self.calibrators.get(regime)
        if cal is None or self.support[regime]["n"] < self.n_min \
                or not self.support[regime]["overlap_ok"]:
            return None
        return self.value_model(x) - cal.quantile(1 - self.alpha)

    def _overlap_test(self, xs):
        return density_ratio_bound(xs, self.calibrators.get("pooled")) is not None


class FailureForecaster:
    def __init__(self, hazard_model, p_warn=0.2, H_prepare=0.3):
        self.hazard_model, self.p_warn, self.H_prepare = hazard_model, p_warn, H_prepare

    def forecast(self, x, margins, history):
        mode, lead, p = self.hazard_model.predict(x, margins, history)
        return {"mode": mode, "lead": lead, "p": p,
                "trigger": p > self.p_warn and lead <= self.H_prepare}


class BoundaryGovernedChunkGovernor:
    def __init__(self, model, rke, monitor, rho_min, T_react, T_cycle):
        self.model, self.rke, self.monitor = model, rke, monitor
        self.rho_min, self.T_react, self.T_cycle = rho_min, T_react, T_cycle

    def govern(self, plan, x, regime):
        C = plan.chunk(x)
        k_max = self._k_max(x, C)
        C = C.prefix(min(len(C.actions), k_max))
        tube = self.model.reachable_tube(x, C)
        good = 0
        for t in range(1, len(C.actions) + 1):
            if not self._prefix_admissible(tube[t], regime):
                break
            good = t
        C = C.prefix(good)
        if any(a.commitment == "I" for a in C.actions):
            C = self._split_irreversible(C)
        return C

    def _k_max(self, x, C):
        tau = self.model.time_to_boundary(x, C)
        return int(max(0.0, tau - self.T_react) / self.T_cycle)

    def _prefix_admissible(self, tube_t, regime):
        for x in tube_t:
            ok, _ = self.monitor.gate(x)
            rho = self.rke.rho_lb(x, regime)
            if not ok or rho is None or rho < self.rho_min:
                return False
            if self.model.barrier(x) < -self.model.gamma:
                return False
        return True

    def _split_irreversible(self, C):
        out, buf = [], []
        for a in C.actions:
            if a.commitment == "I":
                if buf:
                    out.append(Chunk(buf))
                    buf = []
                out.append(Chunk([a]))
            else:
                buf.append(a)
        if buf:
            out.append(Chunk(buf))
        return out[0]


def select_recovery(fault, x, lib, psc, model):
    opts = lib.match(fault.mode, x)
    ranked = sorted(opts, key=lambda rp: lex_key(rp.predict(x), ORDER))
    for rp in ranked:
        if not rp.pre(x) or not psc.satisfied_by(rp, x):
            continue
        if not model.recursively_admissible(rp, x):
            continue
        if any(a.commitment == "I" for a in rp.actions):
            if not cross_modal_receipts(x, rp):
                continue
        return rp
    return lib.protective_stop(x)


def gfg_loop(M, task, ell=None):
    iota = M.pgraph.parse_instantiate(ell) if ell else M.default_iota
    if not M.pgraph.capability_closure([iota]):
        iota = M.default_iota
    H = M.lbox.hypothesize(M.obs, M.dbox.R, iota)

    while not M.env.done(task):
        x = M.env.state()
        regime = M.regime.classify(x)
        plan = M.iac.plan(iota, H, M.budget(x), M.drift(x))
        C = M.bgcg.govern(plan, x, regime)

        if not M.kloop.prefix_closed(C)[0]:
            C = C.prefix(1)
        if not M.rt_model.rta_ok(C):
            C = M.rt_model.fallback_k1(C)
        if not M.spatial.precheck(C, M.eps_vis):
            C = M.rt_model.fallback_k1(C)

        for t, a in enumerate(C.actions):
            if a.commitment == "I" and not cross_modal_receipts(x, a):
                break
            if t in C.preempt_points and M.sched.pending_higher():
                M.sched.preempt(C, C.prefix_state(t))
                break
            M.env.apply(a)
            ok, margins = M.smm.gate(M.env.state())
            fc = M.ff.forecast(M.env.state(), margins, M.history)
            if not ok or fc["trigger"]:
                fault = M.diagnoser.diagnose(margins, fc, C, iota)
                rp = select_recovery(fault, M.env.state(), M.srl, M.psc, M)
                M.sched.run_recovery(rp)
                if not rp.succeeded:
                    C = C.truncate(t)
                break

        cert = M.cvc.certify(C, M.smm, M.rke, regime)
        M.ros.publish(cert)
        M.dbox.update(C, cert)
        M.regime.update_calibration(regime, C, cert)

## 4. 推导

**引理 69（边界块安全性）**
设沿块 `C` 的扰动集 `W` 有 `|dσ̃_i/dt| ≤ L_i`，监控周期 `T_mon ≤ T_react`，且起始 `σ̃_i(x_0) > 0`。若 `K·T_cycle ≤ τ* − T_react`，则在块执行期间每个通道的裕度始终 `≥ L_i·T_react > 0`，不会在无可否决机会的情况下越过支撑边界。
证明：由 `τ*` 定义，最坏情况下到边界的剩余时间为 `τ*`；执行耗时至多 `τ* − T_react` 后仍有 `T_react` 的余量。最坏下降速率 `L_i` 给出剩余裕度下界 `L_i·T_react`。监控周期不大于 `T_react`，故至少在余量耗尽前有一次采样；该采样可触发截断或保护动作。∎

**引理 70（护盾不变式）**
若 `B` 满足定义 499 的 `γ`-松弛屏障证书，且护盾只执行 `U_adm` 内动作，则从 `x_0 ∈ K̂_ρ` 出发，所有可达状态满足 `B(x_t) ≥ −γ`，即系统保持在 `K̂_ρ` 的 `γ` 邻域内。
证明：对时间归纳。初始 `B(x_0) ≥ 0 ≥ −γ`。若 `B(x_t) ≥ −γ` 且 `u_t ∈ U_adm`，由条件 (3) 得 `B(x_{t+1}) ≥ −γ`；护盾拒绝任何使 `B < −γ` 的动作，故归纳成立。∎

**引理 71（前缀截断安全性）**
若块 `C` 的每个前缀都按定义 501 单独检查为受护，则在任意 `t` 处截断得到的前缀仍受护，且从 `x_t` 出发存在满足 `ρ_LB ≥ ρ_min` 的恢复策略。
证明：受护性是对每个前缀的合取性质；截断取的是已检查前缀，故其所有更短前缀也已检查。末尾状态 `x_t ∈ X_t` 满足 `ρ_LB(x_t) ≥ ρ_min`，由定义 497 存在恢复策略。∎

**引理 72（regime 条件覆盖与不可外推性）**
在同一 regime 内可交换且目标—标定重叠成立的条件下，定义 498 的共形下界满足 `Pr[V_rec(x) ≥ ρ_LB(x;g)] ≥ 1−α`。若重叠不成立，则任何仅依赖标定集的下界都无法保证目标 regime 的覆盖；此时必须退回几何裕度门控，安全仍由引理 69 保证，但可恢复性优化失效。
证明：前段是标准分割共形结论；后段由分布偏移下共形保证的反例（支撑集不重叠）直接得到。∎

**引理 73（不可逆屏障可靠性）**
若所有 `I` 级动作均以 `K=1` 执行并经过至少两个独立模态的回执交叉验证，且开环块内不含 `I` 级动作，则不存在「未经观测即已发生的不可逆转移」。
证明：`I` 级动作单步执行，执行前后均有回执；开环块内无 `I` 级动作，故块内不可能跨过承诺边界。结合定义 500 的回执要求，任何不可逆转移都在下一步决策前被观测并认证。∎

**引理 74（字典序选择不扩权）**
定义 503 的恢复选择满足 `tools(RP*) ⊆ T₀`，且结果向量比较只改变候选排序，不改变可行动作集。
证明：SRL 预注册时已要求每个 `RP.tools ⊆ T₀`；组合算子取工具并集且要求前置/后置兼容，不引入新工具；字典序仅作用于候选排序。∎

**引理 75（退化等价性）**
- RKE 不可用 ⇒ `ρ_LB` 置为 `+∞` 之外的保守分支被跳过，护盾仅用 `Gate` 与 `B`，行为等价于 SpatialCert 式截断；
- FF 不可用 ⇒ 仅在 `Gate` 失败后截断，无预警分支，等价于 RTDI 的反应式截断；
- BGCG 不可用 ⇒ `K` 固定为 RTDI 的默认块长，其余检查不变；
- SRL 不可用 ⇒ 恢复分支替换为保护性停机，等价于 v5 的截断/降级；
- 全部关闭 ⇒ 主路径与 InstructGauge-RTDI 的 `instructgauge_rtdi` 逐行等价。

## 6. 场景走查：抱着玻璃烧杯在湿滑地面跌倒

1. `SMM` 检测到 `σ_grasp` 因摩擦系数下降而快速降低，同时 `σ_bal` 因地面打滑进入负趋势；
2. `FF` 输出 `(multi, T_lead≈0.12s, p≈0.7)`，触发预警保护；
3. `PSC` 禁止在此刻松手（烧杯易碎、下方有人），`BGCG` 将块长压到 `K=1`；
4. `SRL` 按字典序选择「收臂 + 护住烧杯 + 选择远离人的侧向着陆」的受控跌倒链；触地动作 `I` 级，单步执行并交叉回执；
5. 落地后 `SMM` 进入 `grounded` regime，`RKE` 若对该 regime 无重叠保证则拒绝给出 `ρ_LB`，只允许几何可行的自撑起；
6. 自撑起分段执行，最后重新定位烧杯并尝试 `re-grasp`；若 `re-grasp` 的 `ρ_LB` 不足，则退回「保护性停机 + 请求人类接管」。

## 8. 可证伪预测（本轮未执行实验，不伪造结果）

- **H1**：边界驱动分块在保持 0 未否决越界的同时，决策开销下降 ≥ 40%；若下降 < 20%，则「分块收益来自摊销」的动机不成立。

- **H4**：sim-to-real 后 `ρ_LB` 的系统性乐观偏差 ≤ 0.10；若 > 0.20，则必须引入在线自适应校准或强制人机共管。

## 10. 本轮最大风险

**一句话**：可恢复性下界在最需要的「支撑边界附近」与「跌倒稀有样本」处最不可靠，sim-to-real 的动力学差异会系统性高估可恢复性，使护盾在真正临界时失效；缓解必须依赖「无重叠即拒绝保证 + 几何门控兜底 + 不可逆动作人机共管」，而不能依赖更大的价值模型。
