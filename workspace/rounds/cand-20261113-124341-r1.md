# 第 67 轮（承接第 66 轮「RAS 情绪驱动闭环」IP-224~233；灵感循环第 4 轮；本轮灵感：「用户画像」×「仿真训练」）

> 第 66 轮 RAS 把「被动故障响应」升级为「主动意图感知」：用面部表情捕获风险态度，用标量 `λ_risk` 缩放控制量，用 ERS 沿情绪风险梯度做局部整形。但 RAS 有一个从未被追问的前提：**「表情→风险」的映射是普适的**。它把所有用户压进同一个 `R_emotion` 权重、同一条 `λ_risk` 曲线、同一组情绪阈值。现实里，两个人同样皱眉：一个可能是「过度表达型」新手（其实很安全），另一个是「沉默忍耐型」老手（其实已接近极限）。RAS 无法区分，只能取「平均用户」的保守折中——对前者误降级，对后者漏保护。
>
> 本轮灵感的核心命题是：
>
> **用户画像是风险闭环的「个体化先验」，仿真训练是风险闭环的「反事实排练」。二者合流，把 RAS 的「平均人闭环」升级为「具体人闭环」——PACE（Persona-Aware Certified Empathy）。**
>
> PACE 的第一原则不是「更懂你」，而是「**懂错你也不会更危险**」：画像默认只能收紧安全约束；只有同时拿到仿真覆盖、保形 sim2real、画像置信、反欺骗四重证据，才允许放宽。这把「画像错误」从安全风险降级为效率损失。

## 0. 直觉与动机

**灵感 1（用户画像 → 从「平均人」到「先验族」）**
直觉：安全闭环真正需要的不是「用户是谁」这个硬标签，而是「这个人的风险生成过程与总体差多少」。画像应被建模为**隐变量 `z` 上的后验**，而不是一个 `profile_id`：
- `z_r`：风险偏好与疼痛耐受；
- `z_e`：表达幅度（stoic ↔ expressive）；
- `z_p`：生理基线（心率、皮肤电、疲劳）；
- `z_c`：文化显示规则与场景上下文。

`λ_risk` 从标量升级为 `λ(z)`。先验来自人群 `p(z)`，后验来自个体 `p(z | D_{1:t})`，二者用分层贝叶斯缝合。画像的每一维都对应一个**可干预、可解释**的物理量，而不是不可审计的特征向量。

**灵感 2（仿真训练 → 不是数据增强，而是反事实干预）**
直觉：真实世界永远看不到「如果机器人再靠近 5 cm，这位用户会不会紧张到松手」——我们不能拿人做重复的危险实验。但仿真里可以对**动作** `a` 做 `do(a)` 干预：固定「真实风险状态 `ρ`」，随机化动作，观察风险如何变化。这解决了一个真实数据无法解决的因果混杂：现实中机器人看到紧张表情就会减速，于是 `表情 → 动作 → 风险` 形成反馈环，观测数据只能学到相关，学不到因果。**仿真给的不是更多样本，而是反事实。**

**灵感 3（合流 → PACE：Persona-Aware Certified Empathy）**
PACE 复用 RAS 的时序骨架，但把每个组件「个体化 + 因果化 + 可证书化」：
1. **UPM User Persona Manifold**：分层贝叶斯画像流形；
2. **PCM Persona-Conditioned Measurement**：画像条件化情绪测量（温度/偏置反解）；
3. **DSR Digital-Subject Rehearsal**：画像参数化数字主体仿真排练 + `do(a)` 随机化；
4. **CIT Counterfactual Identifiability Training**：带干预的反事实风险头；
5. **PRC Persona-Robust Certification**：画像球上的最坏情况认证；
6. **ACT Asymmetric Certificate Trust**：非对称信任闸门（默认只收紧，放宽需证书）；
7. **PCR Persona-Conditioned C-RAS**：画像条件化认证前缀；
8. **PAA Persona Adaptation/Assay**：在线画像后验更新与漂移检测；
9. **SGA Sim-Gap Auditor**：仿真-现实差距审计 + 反画像欺骗 + 隐私预算；
10. **J_PACE**：整合证书。

**灵感 4（非对称信任 → 本轮最关键的「反脆弱」设计）**
直觉：画像最危险的方向不是「太保守」，而是「太自信地放宽」。因此把画像的作用做成**单向阀**：
- 任何**未经证书验证**的画像结论，只能让 `λ_eff ≤ λ_RAS`（更保守）；
- 只有「画像置信度 `φ(z)`、仿真覆盖度 `γ(z)`、保形 sim2real 差距 `Δ_sim(z)`、反欺骗审计 `D_game(z)`」四项同时通过，才允许 `λ_eff > λ_RAS` 去回收效率。

于是「画像错误」在最坏情况下只损失任务效率，而不会侵蚀安全包络。这是 PACE 相对 RAS 的范式增量。

**灵感 5（与 RAS 组件的逐项对照）**
- **ERG → PCM**：情绪分类前先做画像反解（温度 `T(z_e)`、偏置 `β(z_c)`），消除 expressive/stoic 的测量偏差；
- **EFS → CIT**：风险不再是手调先验权重，而是 `do(a)` 干预下的因果函数 `R_cf`；
- **λ_risk → λ(z) ∧ ACT**：从标量缩放升级为「带非对称闸门的画像条件缩放」；
- **C-RAS → PCR**：认证前缀需对画像球内所有 `z` 成立，并受 persona 无关回退下界保护；
- **FAS → SGA + PAA**：主动探针从「情绪探针」升级为「画像校准探针」（最小交互最大信息增益）；
- **J_RAS → J_PACE**：证书增加 `persona_posterior`、`sim_coverage`、`conformal_gap`、`anti_gaming`、`privacy_budget`。

## 1. 形式化定义（增量：定义 251–265）

- **定义 251（PACE 总览）**：`PACE = (UPM, PCM, DSR, CIT, PRC, ACT, PCR, PAA, SGA, J_PACE)`。定位：把 RAS 的「平均人情绪闭环」升级为「具体人因果闭环」。不变式：实时流只做画像码本查表、温度/偏置校准、闸门判定、认证前缀早停，零学习写操作；全部训练与画像更新在离线语义流；画像只保存差分隐私统计量。

- **定义 252（画像隐变量与分层先验）**：`z_u = (z_r, z_e, z_p, z_c) ∈ 𝒵 ⊂ ℝ^d`，`d ≈ 16–32`。分层先验 `z_u ~ N(μ_pop, Σ_pop)`，超参 `(μ_pop, Σ_pop)` 由经验贝叶斯在人群语料上估计。个体后验 `p(z | D_{1:t}) ∝ p(D_t | z) p(z | D_{1:t-1})`。

- **定义 253（画像条件化测量 / 温度-偏置反解）**：观测情绪为
  `π_t = softmax( f_θ(x_t) / T(z_e) + β(z_c) + ξ_t )`，其中 `T(z_e) > 0` 为表达温度（stoic 用户 `T` 大、分布平坦），`β(z_c)` 为显示规则偏置。校准对数几率
  `ℓ_t = T(z_e) ⊙ (log π_t − β(z_c))`，`p(e | π_t, z) = softmax(ℓ_t)`。
  该式的意义：同一张「皱眉」在 expressive 用户上被降温，在 stoic 用户上被升温，从而把**风格差异**从**风险信号**中剥离。

- **定义 254（结构因果模型与反事实风险）**：SCM 为
  `ρ ~ p(ρ | z_r)`（真实风险状态），`π = g(ρ, z_e, a, U_π)`（表情是测量），`a = π_pol(π, z)`（机器人反馈策略），`r = h(ρ, z_r, a, U_r)`（风险结果）。
  定义**画像条件反事实风险**
  `R_cf(a, z) = E_{ρ ~ p(ρ|z_r)}[ h(ρ, z_r, a, U_r) ] = E[r | do(a), z]`。
  注意 `a` 在观测数据里由 `π_pol(g(ρ))` 决定，因此 `P(r|a) ≠ R_cf(a,z)`——动作与风险被反馈环混杂。`R_cf` 只能在仿真中通过 `do(a)` 识别。

- **定义 255（数字主体仿真排练 DSR）**：仿真器 `Sim(z, θ)` 对每个画像 `z`：采样 `ρ ~ p(ρ|z_r)`；对动作做**干预采样** `a ~ do(𝒜)`（而非由当前策略生成）；再生成 `π = g(ρ, z_e, a)`、`r = h(ρ, z_r, a)`。输出反事实三元组 `(z, a, π, r)`。仿真覆盖度
  `γ(𝒵_c) = ∫_{𝒵_c} min(p_sim(z), p_real(z)) dz`（重叠系数，∈[0,1]）。

- **定义 256（反事实可辨识训练 CIT）**：风险头 `R̂_θ(ρ̂, z, a)`，其中 `ρ̂ = PCM(π, z)` 为风险状态后验均值。训练目标
  `L_CIT = E[(R̂_θ(ρ̂,z,a) − r)²] + λ_inv · MMD( R̂_θ(·,z,a) ; z_e )`。
  第二项惩罚「同一风险状态下、仅因表达风格 `z_e` 不同而预测漂移」，把表达风格约束为**非因果变量**。

- **定义 257（画像鲁棒证书 PRC）**：给定画像分布经验估计 `P̂_z` 与 Wasserstein 球 `B_ε(P̂_z)`，或有限画像码本 `𝒞_ε = {z_1, …, z_C}`（覆盖半径 `ε_z`），定义最坏情况风险
  `R_worst = sup_{z ∈ B_ε} R_cf(a, z)`。
  若风险函数对 `z` 满足 `L_z`-Lipschitz，则 `R_worst ≤ max_{c} R_cf(a, z_c) + L_z ε_z`。实时用码本查表，离线用对抗画像搜索扩张码本。

- **定义 258（保形 sim2real 差距 SGA）**：在真实校准集 `{(z_i, a_i, r_i)}_{i=1}^n` 上定义非一致性分数 `s_i = |R̂_θ(ρ̂_i, z_i, a_i) − r_i|`，取分裂保形分位数 `Δ_sim = q_{⌈(n+1)(1−δ)⌉}`。则在可交换性下 `P(s ≤ Δ_sim) ≥ 1−δ`。按画像码本做**分组保形**，得到每簇 `Δ_sim(z_c)`；某簇样本不足即视为「未证」。

- **定义 259（画像条件风险缩放）**：令 `R̄_pop = E_{z~p_real}[R_cf(a,z)]`，
  `λ(z) = clip( λ_RAS · exp(−γ_p · (R_cf(a,z) − R̄_pop)), λ_min, λ_max )`。
  若该用户真实风险高于人群（`R_cf > R̄`），`exp` 项 < 1，`λ` 变小（收紧）；反之变大（回收效率）。`λ_min = 0.5`，`λ_max = 1.2`。

- **定义 260（非对称信任闸门 ACT）**：闸门
  `g(z) = 1[ φ(z) ≥ τ_conf ∧ γ(z) ≥ τ_cov ∧ Δ_sim(z) ≤ τ_gap ∧ D_game(z) ≤ τ_game ]`。
  有效缩放
  ```
  λ_eff(z) = clip( λ_RAS · exp(−γ_p·(R_cf(z) − R̄_pop)),  λ_min, λ_max )      if g(z)=1
           = clip( λ_RAS · exp(−γ_p·max(R_cf(z) − R̄_pop, 0)), λ_min, λ_RAS )  if g(z)=0
  ```
  即 `g=0` 时 `λ_eff ≤ λ_RAS`：画像只能收紧，不能放宽。

- **定义 261（画像条件认证前缀 PCR）**：对块 `A_t`，
  `k*_PACE = max{ k : ∀s ≤ k, ∀z ∈ 𝒵_cert(ε), margin_s(z)·λ_eff(z) ≥ 0 }`，
  且 `k*_PACE ≤ m_PACE = min(m_RAS, m_persona)`。若画像球内任一 `z` 未获证书，则回退 `k*_PACE = k*_RAS`（persona 无关下界）。

- **定义 262（画像后验自适应 PAA）**：后验递推 `p(z|D_{1:t}) ∝ p(D_t|z)p(z|D_{1:t-1})`。漂移统计量用 CUSUM：`S_t = max(0, S_{t-1} + (−log p(π_t|z)) − κ_drift)`；若 `S_t > τ_drift` 或最近窗口与历史窗口的 `MMD(π)` 超阈，则膨胀后验方差 `Σ ← Σ + σ²I`、置 `g = 0`、并回退到人群先验。

- **定义 263（反画像欺骗与隐私）**：反欺骗散度
  `D_game(z_decl) = sup_t | R̂(a_t, z_decl) − R̂(a_t, ẑ_obs) |`，其中 `ẑ_obs` 为由行为-表情耦合反推的画像。若用户申报「低风险画像」但行为表现回避/迟疑，`D_game` 增大 → `g=0`。隐私侧：上传 `z̃ = z + Lap(Δ_sens/ε_dp)`；证书裕度按 Lipschitz 膨胀 `L_z·E||z̃−z||`，`ε_dp` 越小、证书越保守。

- **定义 264（公平性约束）**：对任意两个受保护群体 `A, B`，要求
  `| E[λ_eff(z) | z ∈ A] − E[λ_eff(z) | z ∈ B] | ≤ δ_fair`，
  防止画像把群体先验固化为系统性歧视。

- **定义 265（J_PACE 证书与安全不变式）**：
  ```
  J_PACE = ( J_RAS, persona_posterior, persona_hash,
             sim_coverage, conformal_gap, anti_gaming_score,
             privacy_budget, fair_gap, pace_ver )
  ```
  `Valid ⇔ Valid(J_RAS) ∧ λ_eff ≥ λ_min ∧ (g=1 ⇒ Δ_sim ≤ τ_gap) ∧ fair_gap ≤ δ_fair`。
  **安全不变式**：`g=0 ⇒ SafetySet(PACE) ⊇ SafetySet(RAS)`；`g=1 ⇒` 以概率 `≥ 1−δ`，真实风险 `≤ R_worst + L_z ε_z + L_z·E||z̃−z||`。

```python
# UPM：分层贝叶斯画像 + 码本查表
class UserPersonaModel:
    def __init__(self, mu_pop, Sigma_pop, codebook):
        self.mu, self.Sigma, self.cb = mu_pop, Sigma_pop, codebook

    def posterior(self, z_prev, obs):
        # 共轭近似：高斯后验，观测似然由 PCM 提供
        mu, S = gaussian_update(z_prev, obs)
        return mu, S

    def embed(self, obs):
        mu, S = self.posterior((self.mu, self.Sigma), obs)
        c = nearest_codebook(mu, self.cb)          # 实时 O(C·d)
        phi = 1.0 / (1.0 + trace(S) / self.Sigma_trace0)
        return c, mu, phi

    def drift(self, loglik_hist, pi_window):
        cusum = max(0, loglik_hist + (-loglik_hist) - self.kappa)
        mmd = mmd_rbf(pi_window, self.hist_window)
        return cusum > self.tau_drift or mmd > self.tau_mmd


# PCM：温度-偏置反解，剥离表达风格
class PersonaCalibratedMeasurement:
    def calibrate(self, pi, z):
        T    = torch.exp(self.mlp_T(z[..., :d_e]))     # >0
        beta = self.mlp_beta(z[..., d_e:])
        logits = T * (torch.log(pi + 1e-8) - beta)
        return torch.softmax(logits, dim=-1)

    def risk_state(self, pi, z):
        e = self.calibrate(pi, z)
        return self.rho_head(e, z)                     # ρ̂ 的后验均值


# DSR：数字主体仿真排练（关键：对 a 做 do 干预）
class DigitalSubjectSimulator:
    def rehearse(self, z, n=4096):
        for _ in range(n):
            rho = sample_rho(z)                        # 真实风险状态
            a   = sample_do_action()                   # do(a)，切断反馈环
            pi  = self.g(rho, z, a)                    # 表情 = 测量
            r   = self.h(rho, z, a)                    # 风险 = 结果
            yield z, a, pi, r


# CIT：反事实风险头 + 表达不变性
class CausalRiskHead:
    def fit(self, sim_loader, real_calib):
        for z, a, pi, r in sim_loader:
            rho_hat = self.pcm.risk_state(pi, z)
            loss = mse(self.net(rho_hat, z, a), r)
            loss += self.lam_inv * mmd_style(self.net, z)   # 惩罚 z_e 漂移
        self.conformal = fit_conformal(self, real_calib)    # SGA 分组保形

    def predict(self, pi, z, a):
        return self.net(self.pcm.risk_state(pi, z), z, a)


# ACT：非对称信任闸门
class AsymmetricTrustGate:
    def __init__(self, tau_conf, tau_cov, tau_gap, tau_game):
        self.t = (tau_conf, tau_cov, tau_gap, tau_game)

    def gate(self, phi, gamma, delta_sim, d_game):
        tc, tv, tg, ta = self.t
        return (phi >= tc) and (gamma >= tv) and (delta_sim <= tg) and (d_game <= ta)

    def lam_eff(self, lam_ras, R_cf, R_pop, g):
        delta = R_cf - R_pop
        if g:
            return clip(lam_ras * exp(-self.gp * delta), LAM_MIN, LAM_MAX)
        return clip(lam_ras * exp(-self.gp * max(delta, 0.0)), LAM_MIN, lam_ras)


# PCR：画像球上的认证前缀 + persona 无关回退
class PersonaRobustCertifier:
    def certified_prefix(self, A, z_cells, lam_eff, eps_z):
        k_best = 0
        for k in range(1, min(len(A), self.m_PACE) + 1):
            ok = all(
                self.safety_margin(A[k-1], z) * lam_eff(z) - self.Lz * eps_z >= 0
                for z in z_cells
            )
            if ok:
                k_best = k
            else:
                break
        return k_best

    def fallback(self, A, k_ras):
        return min(k_ras, self.m_PACE)


# 主闭环
def PACE_round(M, obs):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs

    # 1) RAS 前向（几何/视觉/情绪）
    M.lsf.update_geometry(P_cloud)
    x_prime  = M.lsf.fuse(M.usr.fuse(V, T, P, L))
    y_vis    = M.f_vis(img, depth, flow)
    pi       = M.er.classify(img)

    # 2) UPM + PCM：画像后验与校准测量
    z_cell, z_mu, phi = M.upm.embed(M.obs_hist)
    pi_cal  = M.pcm.calibrate(pi, z_mu)
    rho_hat = M.pcm.risk_state(pi, z_mu)

    # 3) CIT：画像条件反事实风险
    A        = M.vista.ach.propose(x_prime, H=M.vista.H)
    R_cf     = M.cit.predict(pi_cal, z_mu, A[0])
    R_pop    = M.pop_risk

    # 4) SGA：分组保形差距 + 反欺骗
    delta_sim = M.sga.conformal_gap(z_cell)
    d_game    = M.sga.anti_gaming(z_mu, M.obs_hist)

    # 5) ACT：非对称闸门
    gamma = M.dsr.coverage(z_cell)
    g     = M.act.gate(phi, gamma, delta_sim, d_game)
    lam   = M.act.lam_eff(M.ras.lam_risk(pi), R_cf, R_pop, g)

    # 6) PCR：画像球认证前缀
    z_cells = M.prc.expand(z_cell, eps_z=M.prc.eps_from(delta_sim))
    k_pace  = M.prc.certified_prefix(A, z_cells, lambda z: lam)
    k_ras   = M.ras.certified_prefix(A)
    k       = k_pace if k_pace > 0 else M.prc.fallback(A, k_ras)

    # 7) 分发 + 漂移检测
    tau_cmd = M.vista.pi_sigma.prefix_dispatch(A[:k]) * lam
    if M.upm.drift(M.loglik_hist, M.pi_window):
        M.upm.reset_to_prior(); g = 0

    return k, lam, g, z_cell, pi_cal
```

## 3. 推导

**引理 11（画像信息增益非负）** 设真实风险状态为 `ρ`，观测表情为 `π`。则
`H(ρ | π) − H(ρ | π, z) = I(ρ ; z | π) ≥ 0`。
等号成立当且仅当 `z ⊥ ρ | π`。故画像只在「同一表情下不同人的真实风险确有差异」时有用；若 `I(ρ;z|π) ≈ 0`，引入画像只增加成本、不增加判别力。这给了「何时值得画像」的可检验判据。

**引理 12（反馈环下反事实可辨识）** 在 SCM 中，`a = π_pol(g(ρ))`，即动作是风险状态的下游确定函数，观测分布中 `π` 与 `a` 互为混杂。对 `a` 施加 `do(a)` 后，所有指向 `a` 的边被切断，`a` 的外生父节点仅为 `(z, U_r)`；故
`R_cf(a,z) = E_{ρ|z_r}[h(ρ,z_r,a)]` 可由仿真干预分布识别。
这意味着：**仿真不是 RAS 的可选加速器，而是因果风险量唯一可辨识的通道**；纯真实数据训练只能学到相关。

**定理 11（非对称安全单调性）** 在 ACT 下，当 `g=0` 时 `λ_eff(z) ≤ λ_RAS` 对所有 `z` 成立。若安全裕度 `margin(λ)` 关于 `λ` 单调不减（控制量随 `λ` 收缩），则
`A_PACE ⊆ A_RAS`（PACE 的可执行集合是 RAS 的子集）。
故**画像错误、漂移、冷启动在 `g=0` 时只能降低任务效率，不能降低安全性**。当 `g=1` 时，放宽量被 `exp(−γ_p Δ)` 与保形阈值双重限幅，且仅在 `1−δ` 覆盖内有效。

**定理 12（画像鲁棒有限样本保证）** 设画像码本有 `C` 个簇，第 `c` 簇真实校准样本 `n_c`。对每簇做分裂保形风险控制，取 `α_c = q_{⌈(n_c+1)(1−δ_c)⌉}`，则
`P( R_cf(z) ≤ α_c, ∀z ∈ cell_c ) ≥ 1 − δ_c`。
对 `C` 簇做并集界，整体覆盖 `≥ 1 − Σ_c δ_c`。叠加 Wasserstein 画像球后，最坏风险上界膨胀 `L_z ε_z`。取 `δ_c = δ/(2C)`，则总保证为 `1 − δ/2`；样本量 `n_c = O((1/δ_c)·log(1/δ_c))` 即可让每簇间隙收敛。

**定理 13（sim2real 迁移的条件性）** 若画像 `z` 落在仿真覆盖集内且保形差距为 `Δ_sim(z)`，则
`| R_true(a,z) − R_cert(a,z) | ≤ Δ_sim(z) + L_z ε_z + L_z·E||z̃ − z||`。
若 `γ(z) < τ_cov` 或 `z ∉ 𝒵_cert`，则上式无有限界，证书**必须**回退（`g=0`）。这把「仿真能否用」从工程直觉变成了可证伪的前置条件。

## 6. 本轮最大风险

**一句话**：PACE 的画像先验与仿真器往往由**同一批有偏数据**拟合，仿真会「自洽地确认」错误的画像，使 `g=1` 的证书在仿真内部完美成立、却在真实分布外失效——这是一种**画像-仿真同源偏置的认知循环**，也是本轮所有保证的共同前提：`p_sim(z)` 必须真正覆盖 `p_real(z)`、且真实校准集与用户群体可交换。

**次级风险与缓解**：
1. **冷启动无画像**：新用户 `g=0`，自动回退到 RAS 保守包络，随交互逐步解锁；
2. **画像漂移**：PAA 的 CUSUM/MMD 检测 + 方差膨胀，漂移时强制 `g=0`；
3. **仿真同源偏置**：引入独立来源的真人研究数据、跨站点保形校准、分布外检测（OOD score 超阈即回退）；
4. **反欺骗与隐私冲突**：`ε_dp` 越小越难欺骗但也越保守，用可调 `privacy_budget` 显式标定；
5. **公平性**：加入 `fair_gap ≤ δ_fair` 约束与群体分层审计，防止画像固化群体先验；
6. **仿真训练成本**：只在离线做对抗画像搜索与覆盖扩张，实时仅查表。

## 2. 形式化定义（完整版）

**定义 251（PACE 总览）** PACE 是 RAS 的「平均人情绪闭环」升级为「具体人因果闭环」：
```
PACE = (UPM, PCM, DSR, CIT, PRC, ACT, PCR, PAA, SGA, J_PACE)
```
不变式：实时流只做画像码本查表、温度/偏置校准、闸门判定、认证前缀早停，零学习写操作；训练与画像更新离线完成；画像只持久化差分隐私统计量。

**定义 252（画像隐变量与分层先验）**
```
z_u = (z_r, z_e, z_p, z_c) ∈ 𝒵 ⊂ ℝ^d,  d ≈ 16–32
z_u ~ N(μ_pop, Σ_pop)
p(z | D_{1:t}) ∝ p(D_t | z) · p(z | D_{1:t-1})
```

**定义 253（画像条件化测量）**
```
π_t = softmax( f_θ(x_t)/T(z_e) + β(z_c) + ξ_t )
ℓ_t = T(z_e) ⊙ (log π_t − β(z_c))
p(e | π_t, z) = softmax(ℓ_t)
```
`T(z_e)` 为表达温度，`β(z_c)` 为显示规则偏置。校准把「风格差异」从「风险信号」中剥离。

**定义 254（结构因果模型与反事实风险）**
```
ρ ~ p(ρ | z_r)                      # 真实风险状态
π = g(ρ, z_e, a, U_π)               # 表情 = 测量
a = π_pol(π, z)                     # 机器人反馈策略
r = h(ρ, z_r, a, U_r)               # 风险 = 结果
R_cf(a, z) = E_{ρ|z_r}[ h(ρ, z_r, a, U_r) ]
```
观测数据中 `a` 是 `ρ` 的下游函数，`P(r|a) ≠ R_cf(a,z)`；只有仿真 `do(a)` 能识别因果量。

**定义 255（数字主体仿真排练 DSR）** `Sim(z,θ)` 对每个 `z`：采样 `ρ ~ p(ρ|z_r)`，对动作做干预采样 `a ~ do(𝒜)`，再生成 `π, r`。覆盖度
```
γ(𝒵_c) = ∫_{𝒵_c} min(p_sim(z), p_real(z)) dz
```

**定义 256（反事实可辨识训练 CIT）** 风险头 `R̂_θ(ρ̂, z, a)`，`ρ̂ = PCM(π,z)`：
```
L_CIT = E[(R̂_θ(ρ̂,z,a) − r)²] + λ_inv · MMD( R̂_θ(·,z,a) ; z_e )
```
第二项强制「同一风险状态下，表达风格不改变风险预测」。

**定义 257（画像鲁棒证书 PRC）** 画像码本 `𝒞_ε = {z_1,…,z_C}`（覆盖半径 `ε_z`）或 Wasserstein 球 `B_ε(P̂_z)`：
```
R_worst = sup_{z ∈ B_ε} R_cf(a, z) ≤ max_c R_cf(a, z_c) + L_z ε_z
```

**定义 258（保形 sim2real 差距 SGA）** 真实校准集上 `s_i = |R̂_θ(ρ̂_i,z_i,a_i) − r_i|`，分裂保形分位数
```
Δ_sim = q_{⌈(n+1)(1−δ)⌉},   P(s ≤ Δ_sim) ≥ 1 − δ
```
按画像簇做分组保形，某簇样本不足即视为「未证」。

**定义 259（画像条件风险缩放）**
```
R̄_pop = E_{z~p_real}[R_cf(a,z)]
λ(z) = clip( λ_RAS · exp(−γ_p·(R_cf(a,z) − R̄_pop)), λ_min, λ_max )
```
`λ_min = 0.5`，`λ_max = 1.2`。

**定义 260（非对称信任闸门 ACT）**
```
g(z) = 1[ φ(z) ≥ τ_conf ∧ γ(z) ≥ τ_cov ∧ Δ_sim(z) ≤ τ_gap ∧ D_game(z) ≤ τ_game ]

λ_eff(z) = clip(λ_RAS·exp(−γ_p(R_cf−R̄_pop)), λ_min, λ_max)                 if g=1
         = clip(λ_RAS·exp(−γ_p·max(R_cf−R̄_pop, 0)), λ_min, λ_RAS)          if g=0
```
`g=0` 时画像只能收紧，不能放宽。

**定义 261（画像条件认证前缀 PCR）**
```
k*_PACE = max{ k : ∀s≤k, ∀z∈𝒵_cert(ε), margin_s(z)·λ_eff(z) ≥ 0 },  k*_PACE ≤ m_PACE
```
任一 `z` 未获证书即回退 `k*_PACE = min(k_RAS, m_PACE)`。

**定义 262（画像后验自适应 PAA）** 后验递推 + CUSUM：
```
S_t = max(0, S_{t-1} + (−log p(π_t|z)) − κ_drift)
```
若 `S_t > τ_drift` 或窗口 `MMD(π) > τ_mmd`，则 `Σ ← Σ + σ²I`、`g ← 0`、回退人群先验。

**定义 263（反画像欺骗与隐私）**
```
D_game(z_decl) = sup_t | R̂(a_t, z_decl) − R̂(a_t, ẑ_obs) |
z̃ = z + Lap(Δ_sens/ε_dp)
```
证书裕度按 Lipschitz 膨胀 `L_z·E||z̃−z||`。

**定义 264（公平性约束）**
```
| E[λ_eff(z) | z∈A] − E[λ_eff(z) | z∈B] | ≤ δ_fair
```

**定义 265（J_PACE 证书与安全不变式）**
```
J_PACE = (J_RAS, persona_posterior, persona_hash, sim_coverage,
          conformal_gap, anti_gaming_score, privacy_budget, fair_gap, pace_ver)
Valid ⇔ Valid(J_RAS) ∧ λ_eff ≥ λ_min ∧ (g=1 ⇒ Δ_sim ≤ τ_gap) ∧ fair_gap ≤ δ_fair
安全不变式： g=0 ⇒ SafetySet(PACE) ⊇ SafetySet(RAS)
             g=1 ⇒ P(true risk ≤ R_worst + L_z ε_z + L_z·E||z̃−z||) ≥ 1−δ
```

```python
    A       = M.vista.ach.propose(x_prime, H=M.vista.H)

    R_cf = M.cit.predict(pi_cal, z_mu, A[0])
    delta_sim = M.sga.conformal_gap(cell)
    d_game    = M.sga.anti_gaming(z_mu, M.obs_hist)
    g         = M.act.gate(phi, M.dsr.coverage(cell), delta_sim, d_game)
    lam       = M.act.lam_eff(M.ras.lam_risk(pi), R_cf, M.pop_risk, g)

    z_cells = M.prc.expand(cell, eps=M.prc.eps_from(delta_sim))
    k_pace  = M.prc.certified_prefix(A, z_cells, lambda z: lam)
    k       = k_pace if k_pace > 0 else M.prc.fallback(A, M.ras.certified_prefix(A))

    tau_cmd = M.vista.pi_sigma.prefix_dispatch(A[:k]) * lam
    if M.upm.drift(M.loglik, M.pi_window):
        M.upm.reset_to_prior(); g = 0

    return k, lam, g, cell, pi_cal
```

## 4. 推导

**引理 11（画像信息增益非负）** `H(ρ|π) − H(ρ|π,z) = I(ρ;z|π) ≥ 0`，等号当且仅当 `z ⊥ ρ | π`。画像只在「同表情下不同人真实风险确有差异」时有价值。

**引理 12（反馈环下反事实可辨识）** 观测中 `a = π_pol(g(ρ))` 使 `π` 与 `a` 混杂；施加 `do(a)` 后指向 `a` 的边被切断，`a` 的外生父节点仅为 `(z,U_r)`，故 `R_cf(a,z)=E_{ρ|z_r}[h(ρ,z_r,a)]` 可识别。仿真因此是因果风险量的**必要**通道。

**定理 11（非对称安全单调性）** `g=0 ⇒ λ_eff(z) ≤ λ_RAS, ∀z`；若 `margin(λ)` 关于 `λ` 单调不减，则 `A_PACE ⊆ A_RAS`。画像错误、漂移、冷启动在最坏情况下只损失效率，不侵蚀安全。`g=1` 时放宽量被 `exp(−γ_pΔ)` 与保形阈值双重限幅。

**定理 12（画像鲁棒有限样本保证）** 每簇保形取 `α_c = q_{⌈(n_c+1)(1−δ_c)⌉}`，并集界给 `P(R_cf(z) ≤ α_c, ∀z∈cell_c) ≥ 1 − Σδ_c`；叠加画像球膨胀 `L_z ε_z`。取 `δ_c = δ/(2C)` 即得 `1 − δ/2`。

**定理 13（sim2real 迁移条件性）** 若 `z ∈ 𝒵_cert` 且覆盖 `γ(z) ≥ τ_cov`，则
`|R_true − R_cert| ≤ Δ_sim(z) + L_z ε_z + L_z·E||z̃−z||`；否则无有限界，证书必须回退（`g=0`）。

## 6. 本轮最大风险

**一句话**：PACE 的画像先验与仿真器常由同一批有偏数据拟合，仿真会「自洽地确认」错误画像，使 `g=1` 的证书在仿真内部完美成立、却在真实分布外失效——这是**画像-仿真同源偏置的认知循环**；本轮全部保证的共同前提是 `p_sim(z)` 真正覆盖 `p_real(z)`，且真实校准集与用户群体可交换。

**次级风险与缓解**：
1. **冷启动无画像**：新用户 `g=0`，自动回退 RAS 保守包络，随交互逐步解锁；
2. **画像漂移**：PAA 的 CUSUM/MMD 检测 + 方差膨胀，漂移即锁闸；
3. **仿真同源偏置**：独立来源真人数据、跨站点保形校准、OOD 检测超阈即回退；
4. **反欺骗与隐私冲突**：可调 `privacy_budget` 显式标定；
5. **公平性**：`fair_gap ≤ δ_fair` + 群体分层审计；
6. **仿真训练成本**：对抗画像搜索与覆盖扩张只在离线，实时仅查表。
