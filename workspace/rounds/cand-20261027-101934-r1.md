# 第 1 轮 · SPARC：缺的不是更大的 VLA，而是跨机器人稳定的任务坐标系

> 检索/复核日期：**2026-10-27（UTC）**。赛事身份确认不变：用户所指是宇树科技的 **UniBot 世界挑战赛**（unibot.unitree.com），G1 + Dex1、32 项桌面任务、通才单模型赛道、选手自部署 + 官方远程真机 API 评测。本轮三个灵感词是「点云配准」「协同控制」「语义地图」。先把此前候选遗留的事实错误纠正，再把三个词分别钉到官方规则/数据/接口上，最后合成主判断：**评测里最贵的失败不是"不会抓"，而是"抓到了却放不进同一个任务坐标系"——跨机器人、跨桌面、跨物体位置、跨背景、跨人为移动，都会让演示里的释放位姿失效；点云配准提供度量对齐，语义地图提供可更新的对象/槽位/进度，协同控制提供容器系里的相对执行。三者不是三个模块，而是同一个"任务坐标系"的三种视图。** 方案名 **SPARC-GPR**（Semantic Point-cloud Atlas + Registration + Coordination）。

## 0. 先把事实钉死（否则后面全错）

### 0.1 排名是字典序：成功率 > 步骤分 > 提交时间

官方手册原文：实时榜单按 32 个任务的**总平均成功率**排序；成功率相同按**总平均步骤分**；仍相同按**提交日期更早**。多次完整计分评测取最好的一次 [S5][S6]。

这条修正很重要：步骤分只是 tie-break，不是与成功率加权。上一轮"终局放置占 ~60% 步骤分"的方向仍对（终局是成功闸门），但不能为了步骤分牺牲成功率；任何"把 0 分变 1 分"的整条 episode 恢复，优先于"把 60 分变 80 分"的部分分优化。

### 0.2 每任务 10 次 = 5 轴 × 2；32 任务 = 320 episodes

- 每任务 **10 次独立运行**；位置/干扰物/桌面背景/未见物品/人为干扰 **5 类各 2 次** [S5][S6]。
- 单次真机最长 **180s**，超时算失败，按完成情况给步骤分。
- 全部 32 任务必须用**同一模型**完成，不得混合多个模型；架构不限 [S5][S6]。
- 多台机器人评测；不同任务随机分配到各台机器人；同一泛化场景的重复测试也可能换机器人 [S6]。
- 每队**每日仅 1 个测试时段**（计分与不计分单任务调试都算）；未按时接入/参赛方原因失败**不补测** [S5][S6]。
- 场景由赛事方测试人员**实时布置**；人为干扰是真人现场操作，不是固定脚本 [S5][S6]。

### 0.3 榜单仍是占位，不能拿它分析头部

`leaderboard_data.json` 的 `generated_from` 仍是 `gen_leaderboard.py`；8 个模型/256 条 task_metrics 是脚本生成；`runs.html` 也是 256/256 占位 [S3][S4]。MolmoAct2 29.7/39.0、WALL-OSS-0.5 28.5/38.9、DreamZero 27.9/37.9 只能当"难度弱先验"，不能反推真实头部方案或轴级瓶颈。**"榜首 <30%"不是真实结论。**

### 0.4 数据：33,276 episodes、18,282,246 帧、169.28h、四路相机、无 depth

- collection 里 32 个数据集合计 **33,276 episodes / 18,282,246 帧 / 169.28h**（30fps 折算）；HangCup 1,043 episodes / 194,564 帧，`lastModified` 2026-10-14 [S8][S9]。
- 四路 640×480：`head_stereo_left/right`、`wrist_left/right`；`video.is_depth_map: false`，**没有深度图** [S9]。
- 字段：`left/right_arm[7]`、grippers[1]、`lower_body[15]`、`left/right_ee_pose_gripper_base[6]` 与 `_torso[6]`、`state_torso[6]`、`state_d435[6]`、`waist_state_joint[3]`、`recomputed_ee_valid[1]`；action 同名双空间 [S9]。
- 本轮用 datasets-server first-rows 验证：`lower_body[15] = left_leg[6] + right_leg[6] + waist[3]`；`lower_body[12:15]` 就是 waist 三关节 [S9]。
- 我们检查左右目内参/校正关系后测得：head stereo 已校正，基线约 **58.25mm**，左目 `fx≈282.4`、右目 `fx≈281.9`；`state_d435[6]` 按字段名与数值范围判断是头部 D435 相机位姿（官方未逐字解释，标为推断）[S9]。

### 0.5 提交 API：只有 4 路 RGB + 本体，时延被记录，N 个端口

- `metadata`：`control_space("joint"/"ee")`、`obs_delta_indices`（声明传哪些观测 + 每键堆叠帧数）、`image_resize`、`action_chunk_size`、`token`；`get_action(obs)` / `reset()` [S7]。
- 观测只有 4 路 RGB、双臂关节、双臂 EE 位姿（base 系）、夹爪开度、`lower_body[15]`、language；**没有 depth、没有力/力矩/触觉/电流** [S7]。
- 评测记录每步 `get_action` 的**时延及其波动**、动作统计规律性，可能随成绩展示；要求平滑稳定、无异常离群 [S7]。
- 评测跨 N 台机器人，需暴露 `8765..8765+N-1` 连续端口，端口间 reset/历史状态严格隔离 [S7]。

### 0.6 32 任务：3200 分、终局 1275 分（39.8%）、15 个任务可能需要双手

- 32 任务满分 100，合计 3200；终局步骤合计 **1275（39.8%）**；12 Easy / 12 Medium / 8 Hard；步骤数 2–5 [S12]。
- 32 个终局步骤里 28 个是放置/插入/堆叠/闭合/挂取类；4 个是拔出/取出/翻转/倾倒类（T05/T11/T12/T14），但前置步骤里同样有大量放置/对准 [S12]。
- 官方 brief 明确把**双手协调**列为三大能力维度之一 [S2][S6]；按步骤文本与任务描述，至少 15 个任务很可能需要"一臂持稳 + 一臂操作"：T03/T05/T09/T10/T12/T14/T16/T17/T18/T19/T23/T26/T28/T29/T31（我们的分类，非官方标注）[S12]。
- T05/T26 的评分步骤直接写 "Hold the network port, then grip/insert..."；T19/T31 拉链、T16 折毛巾、T18/T23 装包拉链都是典型双手任务 [S12]。

### 0.7 WLA-1.0-Base 已开源，可作为唯一学习底座

2026-09-28 发布 **UnifoLM-WLA-1.0-Base**：6B，约 2,500h 真机数据、64 任务，Apache-2.0；Qwen-VL 主干 + DiT action expert；官方提供 LoRA/全参/从零微调，默认单卡 24GB 路径 [S10][S11]。这解决"底座从哪来"，本轮不再把"训一个大 VLA"当创新。

### 0.8 事实与推断分界

- **事实**：排名规则、10 次/320、单模型、多机器人、单日一槽、180s、四路无 depth、33,276/169.28h、`lower_body` 分解、API 字段、WLA 发布、榜单占位。
- **推断**：head stereo 可用于立体匹配；`state_d435` 是头部相机位姿；`lower_body[12:15]` 是 waist；15 个双手任务；测试 API 的 waist 顺序与演示一致。
- **未核实**：步骤分聚合公式、调试槽成本、N 的具体值、备注编号含义、外部数据/离线标注工具是否合规。

## 1. 三个灵感词，各自钉到官方事实上

### 1.1 点云配准：不是"估物体 6D 位姿"，是"把当前场景对齐到演示的任务坐标系"

官方不给 depth，但给了**已校正的 head stereo**、`state_d435`（按字段名/数值范围判断为演示里的头部相机位姿，待复核）和 `lower_body[12:15]`（waist）。这意味着我们可以：

1. 用 SGBM/WLS 从左右目重建桌面点云；
2. 用演示里的 `state_d435` + waist 拟合"waist 关节 → 头部相机位姿"的标定；
3. 测试时用 `lower_body[12:15]` + 拟合标定得到相机位姿，再用桌面平面/背景配准消除残差；
4. 把当前点云与演示 atlas 配准，得到 **table frame** 和 **object/container frame**。

关键不是"识别物体"，而是**配准本身同时给出 identity、pose 和 cross-robot alignment**：把当前桌面上分割出的每个几何簇，配准到 atlas 里的对象模板；匹配最好的模板给出语义角色与 6D 位姿，配准残差给出置信度。这样不需要在推理期再加载一个学习型检测/分割模型，符合单模型约束。

证据链：6D Assembly Pose 用点云配准直接回归装配位姿 [S22]；IMOP 用不变性匹配做 one-shot 模仿 [S23]；RiEMann 用 SE(3)-equivariant 点云策略做到 5–10 条演示 [S24]；PointACT 把点云动作专家用于接触丰富操作 [S15]；Scene Retargeting 把"布局安排"跨场景迁移 [S20]；PlaceIt3D 用 3D 场景做语言引导放置 [S21]。这些工作共同支持：**点云不是辅助观测，而是任务坐标系的载体。**

### 1.2 语义地图：不是"场景图可视化"，是"语言—演示—控制的共享索引"

官方 5 个泛化轴里，位置/干扰物/背景/未见物品/人为干扰，本质上都在问同一件事：**对象还在不在？在哪？和谁相邻？下一步该对谁做什么？** 一个对象中心的语义地图（节点=对象/容器/槽位/支撑面；边=contain/on/left-of/inside；属性=颜色/形状/角色/置信度/last-seen；状态=held/placed/occluded）正好承载这些关系。

- **POT-VLA** 用 persistent 3D object tokens + predicate verifier，在多个任务上把成功率从 39/80 提到 71/80、37/50 提到 44/50（摘要数据）[S13]——说明"持久对象状态"本身就是大杠杆。
- **SuperMap**（RSS 2026）用 training-free 的语义 SLAM 维护持久语义世界模型 [S14]；ConceptGraphs 一类工作把对象关系图用于开放词汇操作。
- 语义地图还天然处理**人为干扰**：每个控制周期把新点云与地图做差，检测对象被移动/拿走/翻转，更新节点状态并触发重规划；这比"把人类备注当固定剧本回放"更通用。

### 1.3 协同控制：不是"再训一个双臂 VLA"，是"一臂做夹具、一臂做相对运动"

官方把双手协调列为能力维度，且至少 15 个任务需要"持稳 + 操作" [S2][S6][S12]。但双臂 VLA 的数据效率低、相对漂移难消；DuoBench 明确指出非对称支撑（一臂稳定、一臂操作）是当前策略的主要失败轴 [S16]；TwinVLA 用两个单臂 VLA 组合成双臂 [S17]；Dual-Level Structural Decomposition 把协调/单臂通路分开 [S18]；Dexora 用"先协同后单臂"的课程 [S19]。

SPARC 的选择更轻：**不新增学习模型**，在动作 chunk 之后加一个确定性协调层 CCL：

- 根据任务图给两臂分配 **anchor（夹具）** 与 **actor（操作）** 角色；
- anchor 保持容器/支撑物稳定；actor 在 **anchor 系** 里执行相对位姿；
- 用视觉伺服修正 anchor 漂移，actor 跟随相对目标；
- 插入类任务在相对系里做螺旋/直线微搜索，用几何配合度停止（无力传感器）；
- 安全状态机（继承 SAGE 的 AEG）限制速度/工作空间，检测异常运动。

这样既利用 WLA 的语义/抓取能力，又把"双手相对关系"从开环模仿变成度量闭环，且不违反单模型。

## 2. 本轮主判断：失败的主因是"任务坐标系漂移"

### 2.1 一个更锋利的失败模型

| # | 失败模式 | 触发轴 | 现有方案的盲点 | SPARC 对策 |
|---|---|---|---|---|
| F1 | 跨机器人/桌面偏移：相机外参、桌高、机器人个体差异 | 隐藏的跨机器人轴 + 位置轴 | 纯图像策略把桌面位置当纹理；演示的 base 系动作不可迁移 | RCA 重置标定 + table-frame 配准 |
| F2 | 容器/槽位移动：碗、杯子、插排、袋子被人或位置泛化移动 | 位置/人为干扰 | 只估目标物，不估容器；释放位姿相对 base 系失效 | OSM 容器节点 + 容器系释放位姿 |
| F3 | 背景/光照/纹理变化 | 背景轴 | 外观检索/分割漂移；点云特征也受纹理影响 | 几何配准为主、颜色为辅；table frame 消背景 |
| F4 | 未见物体/透明/遮挡：同类不同外观、透明杯、反光 | 未见物品轴 | 类别级 6D 位姿模型泛化差 | 几何簇 + atlas 多模板；透明/布料降级到 VLA+相位先验 |
| F5 | 双臂相对漂移：一手持稳时另一手越做越偏 | 双手任务 + 人为干扰 | 两臂独立 chunk，误差各走各的 | CCL anchor/actor 相对空间控制 |
| F6 | 执行后无度量校验：掉了/歪了/没插进去但以为完成 | 所有轴 | 只依赖策略置信度或语言自评 | RPV 配准残差 + 任务谓词 + 重试 |

六类里 F1/F2/F5 是"坐标系"问题，F3/F4 是"几何 vs 外观"问题，F6 是"闭环"问题。三个灵感词正好覆盖前五类；RPV 覆盖第六类。

### 2.2 榜首可能的技术瓶颈（占位榜不可分析，以下只是假设）

榜单仍是占位，不能从 29.7% 这类数字反推真实头部。但按公开模型的共性和评测规则，可以列出**待验证的瓶颈假设**：

| # | 假设 | 为什么可能 | 如果成立，SPARC 的对策 |
|---|---|---|---|
| H1 | 语义强、度量弱：VLA 能选对物体，但最后 1–3cm 的释放/插入靠隐式图像 token | 图像策略没有持久 3D 状态；动作头在 base 系，跨桌高/机器人偏 | RPT 容器系释放位姿 + RPV 度量校验 |
| H2 | 数据覆盖 ≠ 坐标覆盖：33k 演示覆盖任务，但每任务的布局/相机/机器人组合有限 | 官方多机器人、实时布置场景；训练集不是这些组合 | RCA + table/object frame 配准，在线消偏 |
| H3 | 双手被当成"两臂联合动作"而非"相对关系" | 双臂数据少、独立 chunk 漂移；DuoBench 指非对称支撑是失败轴 | CCL anchor/actor 相对空间控制 |
| H4 | 失败感知弱：做完但没成（掉了/歪了/没插进去） | 成功率是闸门；VLA 置信度不等于几何成功 | RPV 配准残差 + 谓词 + 重试 |
| H5 | 检索/记忆外观化：背景/位置一变就失效 | 视觉检索键含全局纹理；官方背景/位置轴专门打这个 | 几何 atlas + 语言/颜色只做排序 |
| H6 | 测试时计算/世界模型延迟不划算 | 180s/30Hz、时延被记录、单日一槽 | 几何/控制确定性、低延迟；WLA 只做一次前向 |
| H7 | 跨机器人标定/接口差异被低估 | N 台机器人、相机位姿不直接给 | RCA 拟合 + 平面精化 + 残差门控 |

如果真实榜首是 WLA/π0.5/GR00T 这类端到端 VLA，最可能 plateau 在 **H1+H3+H4**；如果是检索/世界模型类，最可能在 **H5+H6**。SPARC 的赌注是：**H1–H4 是共同底座，且都能用同一个任务坐标系解决。**

### 2.3 为什么上一轮 PILOT 和 SAGE 都会在这里 Plateau

- **PILOT-GPR** 把终局放置当第一目标，方向对；但它的 OPT 仍假设"容器可以被稳定定位"，且释放位姿是离线统计，遇到容器移动/跨机器人偏移就退化。它缺一个**持续更新的任务坐标系**。
- **SAGE-GPR** 把安全/恢复做成运行时信号，能救近失败；但它是**反应式**的：先检测异常，再恢复。它不解决"为什么一开始会偏"；而且恢复动作仍要在某个坐标系里执行。
- SPARC 不是替代它们，而是补上它们共同的底座：**一个可配准、可更新、可被语言查询的任务坐标系**。SAGE 的 AEG 状态机保留为安全外壳；PILOT 的 SSG/放置先验保留为任务图与初始化。

### 2.4 与第 7/8 轮的关系（深化与修剪，不推倒）

- **保留**：WLA-1.0-Base 单 checkpoint、SSG 评分步骤图、GPR-VLA 目标残差接口、NRB 人类备注恢复、Endurance Governor、Compliance Compiler、FLEET 工程检查单。
- **升级**：OPT（离线位姿统计）→ **RPT**（配准 + 容器系位姿 + 局部接近轨迹迁移）；PGL（2D 锚点）→ **OSM**（对象中心语义地图 + 槽位/关系）；SVL（落点校验）→ **RPV**（配准残差 + 谓词）；SAGE 的 AEG → **安全外壳**。
- **新增**：RCA（reset 标定）、DPA（演示点云 atlas）、CCL（协同控制层）、MTA（可选 map token adapter）。
- **修剪**：把"再训一个双臂 VLA"砍掉；把"推理期加载 SAM2/FoundationPose/独立世界模型"砍掉（只允许离线标注）；把"全 32 任务高保真孪生"降级为 3 个代表性任务的孪生；把"纯外观检索"降级为语言/颜色先验。

## 3. 方案轮廓：SPARC-GPR（细节在产物区）

```text
语言(160条复述之一) ──► SSG 评分步骤图 ──► 当前步骤 s、角色(anchor/actor)、槽位
                                      │
4×RGB ──► RCA 立体/相机标定 ──► 桌面点云 ──► OSM 对象中心语义地图
                                      │         （节点/边/状态/置信度/last-seen）
                                      ▼
                          DPA 演示 atlas（table/object frame 的点云 + 释放位姿
                                      + 末端接近轨迹 + 夹爪宽度）
                                      │
                          RPT 配准：当前对象/容器 ↔ atlas 模板
                                      │  → T_table^current, T_container^target
                                      │  → 释放位姿 + 局部接近先验
                                      ▼
   WLA-1.0-Base（唯一学习模型）──► 双臂 action chunk
                                      │
                          CCL 协同控制：anchor 持稳 + actor 相对运动
                                      │  视觉伺服、螺旋微搜索、限速/限域
                                      ▼
                          RPV 放置校验：配准残差 + 谓词 + 稳定性
                                      │  通过→下一步；失败→nudge/regrasp/retry
                                      ▼
                          SAGE AEG 安全外壳：Nominal/Cautious/Protective/Recover/SafeStop
```

一句话：**用点云配准把"演示"对齐到"当前桌面"，用语义地图把"当前桌面"变成"可查询的任务状态"，用协同控制把"任务状态"变成"容器系里的相对动作"，用配准残差把"动作完成"变成"可验证的成功"。**

## 4. 为什么现在可行

- **数据够**：33k 演示、四路相机、`state_d435` + waist，足以离线构建 atlas 与标定；不需要外部数据。
- **底座够**：WLA-1.0-Base 6B 已开源，单卡 24GB 可微调；我们只需在它外面加确定性几何/控制，不必从零训 VLA。
- **算力可控**：离线 atlas 构建用 1×A100 约 1–2 周；在线只跑 SGBM（320×240，5–10Hz）+ Open3D FPFH/ICP（1–2Hz）+ 轻量控制，p99 目标 <100ms。
- **合规可控**：推理期只有一个学习 checkpoint（WLA）；SAM2/GroundingDINO/CREStereo 只用于离线标注/质检，不随提交部署；外部实验室数据默认 OFF。
- **可证伪**：先用 leave-one-demo-out 离线测"配准→释放位姿"误差；如果刚性物体中位误差 >2cm/10°，RPT 假设不成立，回退到"OSM+CCL+手写锚点"。

## 5. 主要风险与先手

| 风险 | 影响 | 先手 |
|---|---|---|
| 立体深度噪声/透明反光 | 点云配准失败 | 只用 head stereo 建粗图；透明/布料任务降级到 VLA+相位先验；腕部特写做最终对准 |
| 测试 API 的 waist 顺序/相机安装与演示不一致 | RCA 标定偏 | 用桌面平面 + 背景配准在线修正；RCA 只做初值；记录重投影误差 |
| 推理期分割需要学习模型 | 违反单模型 | 用几何聚类 + atlas 配准做 identity；离线标注不部署 |
| CCL 与 VLA 冲突 | 动作抖动/超时 | anchor 只做低增益保持；actor 相对修正限幅；异常时退回纯 VLA |
| 地图更新错误 | 选错对象/槽位 | 置信度门控；低置信度回到 VLA；RPV 失败触发重观测 |
| 单日一槽/不补测 | 调试机会稀缺 | 离线 leave-one-demo-out + 3 任务孪生为主；调试槽只做发布门 |
| 外部数据/离线工具合规未明 | 违规风险 | 默认 OFF；只使用官方数据；向主办方书面确认 |

## 6. 验收标准（先写死，避免自嗨）

- **RPT 离线**：刚性物体释放位姿中位误差 **<1cm/5°**；堆叠类 **<2cm/10°**；配准成功率 **>90%**；单帧配准 **<200ms**。
- **OSM**：目标/容器角色选择 **>90%**；人为移动后 1 个控制周期内检测到并更新；遮挡恢复后能重新关联。
- **CCL 孪生**：anchor 被扰动 ±2cm/±5° 时，插入成功率相对纯 VLA **+20pp**；相对位姿误差方差下降 **>50%**。
- **RPV**：失败检测 AUC **>0.9**；误报 **<5%**；从失败到重试 **<3s**。
- **端到端**：3 个调试任务终局步骤 **+10pp**，无安全终止；官方 320 trials 在 p≈0.3 时 SE≈2.56pp，因此对外只报 **+3–5pp** 的保守目标。
- **合规**：提交进程只加载 WLA 一个学习模型；所有几何/控制模块可解释、可关闭；无外部数据、无测试时训练。

## 7. 一句话押注

**把"跨机器人/跨场景稳定的任务坐标系"当作第一性缺口：用点云配准把演示 atlas 对齐到当前桌面，用语义地图承载对象/槽位/关系/进度/被人移动，用一臂 fixture + 一臂 actor 的协同控制在容器系里执行，从而把终局放置和双手任务从开环模仿变成度量闭环；这比再训一个更大的 VLA 更便宜，也比只做失败恢复更根本。**

## 2. 问题形式化：任务坐标系漂移

### 2.1 坐标系

- `B`：机器人 base frame（EE 位姿/动作的坐标）。
- `C`：head camera frame（`state_d435` 记录，测试时由 waist 标定估计）。
- `T`：table frame（桌面平面 + 边缘/背景朝向）。
- `O_i`：object/container frame（第 i 个对象，由点云簇 + atlas 配准定义）。
- `E_l, E_r`：左右 EE frame。

所有变换写作 `T_A^B`（把 B 中的点变到 A），满足 `T_A^C = T_A^B T_B^C`。

### 2.2 立体重建

校正后的左右目像素 `(u_l, v)`、`(u_r, v)`，视差 `d = u_l − u_r`：

```text
Z = f_x * b / d
X = (u_l − c_x) * Z / f_x
Y = (v − c_y) * Z / f_y
```

其中 `b≈58.25mm`，`f_x≈282`（640×480 下）。输出 `P_C ∈ R^{N×3}`；再用 `T_B^C` 变到 base/table：

```text
P_B = T_B^C * P_C
```

工程细节：

- 只在桌面 ROI 做 SGBM（320×240，`numDisparities=64/128`，`blockSize=5`），WLS 滤波；输出 5mm 体素降采样。
- 左右目一致性检查（`|I_l − I_r|`、左右视差一致性）；低纹理/透明区域标记为无效，不参与配准。
- 腕部相机只做末端特写/视觉伺服，**不参与全局点云**（手眼外参未标定，避免引入误差）。

### 2.3 RCA：从 waist 到相机位姿

演示里有 `state_d435[6]`（头部相机位姿）和 `waist_state_joint[3]`。离线拟合：

```text
T_B^C ≈ F(q_waist),  q_waist = lower_body[12:15]
```

`F` 用两种实现：

1. **运动学**：如果有 G1 URDF/头部安装外参，直接 FK；这是首选。
2. **数据拟合**：若无 URDF，用 32 任务 × 200 条演示的 `(q_waist, T_B^C)` 拟合线性/二次回归 + 残差修正；验证集重投影误差 <5mm/0.5° 才用。

测试时没有 `state_d435`，但有 `lower_body[15]`。用 `F(q_waist)` 得初值，再用桌面平面 + 背景几何精化：

```text
T_B^C* = argmin_T || plane(T * P_C) − plane_expected ||^2 + λ ||T − F(q)||^2
```

精化只调 6DoF 的小残差（±2cm/±2°），避免陷入错误局部解。若精化残差 >阈值，标记 RCA 不可信，退回"纯 VLA + 腕部伺服"。

### 2.4 Table frame

对 `P_B` 做 RANSAC 平面：

```text
n^T p + d = 0,  |n|=1
```

取桌面法向为 `z_T = −n`（指向桌外），原点 `o_T` 为桌面点云质心在平面上的投影；`x_T` 由桌面边缘/背景主方向或机器人 base 的投影确定；`y_T = z_T × x_T`。得到 `T_B^T`。

用途：

- 消除桌面高度/机器人 base 高度差；
- 给 OSM 一个全局参考；
- 给 RPT 一个全局初值；
- 给 CCL 一个工作空间/安全平面。

### 2.5 OSM：对象中心语义地图

节点：

```text
node_i = {id, role, label, T_T^i, P_i (point cloud template),
          state ∈ {free, held, placed, occluded, missing},
          confidence, last_seen, relations}
```

边：`contain(i,j)`、`on(i,j)`、`left_of(i,j)`、`inside(i,j)`、`near(i,j)`、`support(i,j)`。

更新（每个控制周期或每 2–3 帧）：

1. 新点云 `P_T` 去桌面、聚类（Euclidean，5–10mm）；
2. 每个簇与 atlas 模板配准，得到 `(template_id, T_T^i, residual)`；
3. 数据关联：与已有节点按 `T_T^i` 距离/点云 overlap 匹配；
4. 匹配成功 → 更新 pose/confidence/last_seen；残差大 → 标记 moved；
5. 匹配失败 → 新节点（低置信度）或 missing（超时）；
6. 关系图按几何重算（contain/on/left_of…）；
7. 语言查询：从 SSG 当前步骤取角色（target/container/support/slot），在图中找对应节点；颜色/序数/方位作为软约束。

**关键**：OSM 不依赖学习型分割器。对象 identity 由"几何簇 ↔ atlas 模板配准"给出；颜色/语言只做候选排序。未见物体配准失败时，节点以"几何簇 + 语言角色"存在，降级给 WLA；不强行给语义标签。

### 2.6 DPA：演示点云 atlas

对每个任务/步骤，从成功演示中抽取关键帧：

- 步骤开始（物体在初始位姿）；
- 接近前（EE 距目标 10–15cm）；
- 释放前（EE 距目标 1–3cm）；
- 释放瞬间；
- 释放后（物体稳定）。

对每帧：

1. 用 `state_d435` + stereo 重建 `P_B`；
2. 转 table frame `P_T`；
3. 离线用 SAM2/GroundingDINO 标注目标/容器/支撑面（**只用于离线数据生产，不部署**）；人工抽检 5%；
4. 以对象/容器为中心，裁剪 15–25cm 立方体，5mm 体素降采样，得到模板点云；
5. 记录 `T_T^object`、`T_object^release`、`T_container^release`、夹爪宽度、接近方向、最后 K 个 EE 位姿（object frame）；
6. 多演示聚类：同一任务/步骤的模板按几何相似度聚类，保留 3–8 个代表模板（不同形状/颜色/尺寸），每个模板附统计量（释放位姿均值/协方差、夹爪宽度中位数）。

atlas 规模：32 任务 × 100 条演示 × 5 关键帧 ≈ 16k 帧；每帧 10k 点 × 3 通道 × float16 = 60KB，总量 16k × 60KB ≈ 960MB；加模板/索引 <2GB。可接受。

### 2.7 RPT：配准与位姿迁移

给定当前簇 `P_cur`（table frame）和 atlas 模板 `P_tpl`（table/object frame）：

```text
T* = argmin_{T∈SE(3)} Σ_i ||T p_i − q_{π(i)}||^2
```

流程：

1. 5mm 体素降采样；法向估计；
2. FPFH 特征 + RANSAC 全局配准（初值可由 table frame / 上一帧位姿给出）；
3. ICP（point-to-plane）精化；
4. 置信度：

```text
c = inlier_ratio * overlap * exp(−residual/σ)
```

5. 若 `c < c_min`，尝试多模板/多初值；仍失败 → 降级。

位姿迁移（三种模式，按任务选）：

- **table 模式**：`T_B^release = T_B^T * T_T^release`；适合物体相对桌面没动、只是桌面/机器人变了。
- **object 模式**：`T_B^release = T_B^O * T_O^release`；适合目标物被移动/旋转，容器不动。
- **container 模式**：`T_B^release = T_B^C * T_C^release`；适合容器被移动、目标物相对容器不变（插头/网线/碗堆叠）。

组合：

```text
T_B^release = T_B^T * T_T^O * T_O^release
            = T_B^T * T_T^C * T_C^release
```

实际按置信度选择：容器配准置信度高 → container 模式；否则 object → table。输出附协方差/置信度，供 CCL/RPV 使用。

**局部接近轨迹迁移**（RPT 的第二个输出，不只是释放点）：

atlas 存最后 K 个 EE 位姿 `{T_O^E(k)}`（相对目标/容器）。当前场景：

```text
T_B^E(k) = T_B^O * T_O^E(k)
```

只用于**最后 0.5–1.5s / 最后 10–20% 的接近段**，作为 WLA action chunk 的先验/残差目标，不复制整条轨迹。融合权重：

```text
w_k = clamp(c * phase_gain(k), 0, 0.8)
a_final = (1−w_k) a_VLA + w_k a_RPT
```

`phase_gain` 在接近前低、释放前高；`c` 低时 `w=0`，完全退回 VLA。这样保留 VLA 的适应能力，只用配准修最后几厘米。

### 2.8 CCL：一臂夹具、一臂相对运动

角色分配（来自 SSG/任务文本）：

- `anchor`：持稳容器/支撑物（插排、袋口、盒身、碗堆、网口）。
- `actor`：抓取/插入/拉链/放置。
- 单臂任务也可用另一臂做 `stabilizer`（轻扶），但只在置信度高时启用。

相对目标：

```text
T_B^actor_target = T_B^anchor * T_anchor^actor_target
```

`T_anchor^actor_target` 来自：

- RPT 的容器系释放位姿；
- 任务先验（插入方向、拉链路径）；
- WLA 输出的 actor 目标经 anchor 系变换。

控制：

```text
e = log( (T_B^actor_current)^{-1} * T_B^actor_target ) ∈ se(3)
v = clamp(K_p e, v_max),  ω = clamp(K_r e_r, ω_max)
```

- anchor 用低增益保持 + 视觉伺服（容器特征/点云质心），避免硬顶；
- actor 在相对系里跟踪，修正 anchor 漂移；
- 插入：在相对系做螺旋搜索（半径 0–5mm，步长 0.5mm，平面内螺旋 + 轴向微压），用点云配合度/视觉对齐停止；无力传感器，禁止大力顶死；
- 拉链/布料：不用刚性配准，改用相位先验 + 视觉伺服 + 小步往返；
- 安全：工作空间盒、桌面平面、速度/加速度/jerk 限幅；异常运动 → SAGE AEG 降级。

### 2.9 RPV：配准校验

释放后 0.2–0.5s 重建点云，估计物体位姿 `T_B^O*`，与期望 `T_B^O,exp` 比较：

```text
r_t = || trans( (T_B^O,exp)^{-1} T_B^O* ) ||
r_r = angle( (T_B^O,exp)^{-1} T_B^O* )
```

再加：

- 支撑/接触：物体底部点是否在支撑面/容器内；穿透/悬空；
- 稳定性：释放后 0.5s 内位姿漂移 <阈值；
- 任务谓词：碗嵌套深度、相框直立、插头插入深度（几何）、拉链闭合长度（视觉）；
- 地图一致性：OSM 节点状态是否变为 placed；关系是否满足。

判定：

```text
success = (r_t < τ_t) ∧ (r_r < τ_r) ∧ predicate ∧ stable
```

失败动作：nudge（小位移）、regrasp（重抓）、retry（重走接近）、abort（切下一步/安全停）。阈值按任务分桶：刚性放置 1cm/5°，堆叠 2cm/10°，插入 5mm/5°（几何近似）。

### 2.10 地图差分与人类干扰

每个控制周期比较 OSM 节点预测点云与当前观测：

```text
moved_i = 1[ ||T_new − T_old|| > δ_t  or  overlap_new < δ_o ]
missing_i = 1[ no match for > T_missing ]
```

- moved → 更新节点，重算关系，触发 RPT/CCL 重规划；
- missing → 标记 missing；若当前步骤需要它，触发搜索/等待/安全停；
- 新手出现（人手/工具）→ 低置信度节点 + 减速/让行（SAGE AEG）；
- 人类把已完成步骤撤销（官方备注里的 undo）→ 谓词从 true 变 false，回退步骤。

这比"按备注回放固定剧本"更通用，且直接利用官方"人为干扰"轴。

## 3. 架构与伪代码

### 3.1 总览

```text
                     ┌─────────────────────────────────────────────┐
语言 ──► SSG ───────►│ 任务图：步骤/角色/槽位/谓词                  │
                     └───────────────┬─────────────────────────────┘
                                     │
4×RGB ──► RCA ──► 点云 ──► OSM ──────┤
                     │               │
                     ▼               ▼
              DPA atlas ──► RPT ──► 目标位姿/接近先验
                                     │
                     WLA-1.0-Base ───┤──► 双臂 chunk
                                     │
                              CCL ◄──┘  anchor/actor 相对控制
                                     │
                              RPV ───┴──► 成功/失败/重试
                                     │
                              SAGE AEG 安全外壳
```

**SSG（Score-Step Graph）**：把官方 `score_steps` 变成有向步骤图；每个节点带 `role`（target/container/support/slot）、`predicate`（完成判据）、`weight`、`bimanual` 标记；边表示顺序/可选回退。`OSM/RPV` 只更新节点状态，语言只负责选根节点；这样"下一步做什么"不靠 VLA 自由发挥。

### 3.2 在线伪代码

```python
def reset():
    state.clear()
    rca.reset()
    osm.reset()
    ccl.reset()
    rpv.reset()

def get_action(obs):
    # 1. 语言/任务图
    task = parse_language(obs["observation.language"])
    step = ssg.current_step(task, osm)

    # 2. 几何（低频，异步）
    cloud = stereo_to_cloud(obs["cam_left_high"], obs["cam_right_high"])
    T_B_C = rca.estimate(obs["lower_body"][12:15], cloud)
    cloud_B = transform(cloud, T_B_C)
    T_B_T = table_frame(cloud_B)
    osm.update(cloud_B, T_B_T, atlas, task, step)
    target = osm.query(step.role, step.slot, task)

    # 3. 配准（中频，异步）
    reg = rpt.register(target, atlas[task][step], T_B_T)
    release = rpt.transfer_pose(reg)
    approach = rpt.transfer_approach(reg)

    # 4. 策略（唯一学习模型）
    chunk = wla.predict(obs, task, release, approach, osm.tokens())

    # 5. 协同控制（高频）
    chunk = ccl.constrain(chunk, osm, reg, step)

    # 6. 安全
    chunk = aeg.filter(chunk, osm, cloud_B, T_B_T)

    # 7. 校验（异步，不阻塞当前 chunk）
    if step.is_terminal and rpv.ready():
        ok, diag = rpv.verify(cloud_B, osm, release, step)
        if not ok:
            ccl.request_recovery(diag)

    return chunk
```

时序预算（chunk=16 @30Hz ≈ 533ms）：

- 立体 320×240：20–30ms；
- 平面/聚类/OSM：30–50ms；
- FPFH+RANSAC+ICP（降采样后 5–10k 点）：100–300ms，1–2Hz 异步；
- WLA 6B：50–150ms（取决于部署）；
- CCL/AEG：<10ms；
- 目标：控制/几何 p99 <50ms；完整 `get_action` p99 <200ms；不出现 >500ms 尖峰。

### 3.3 关键接口

- `WLA` 输入：4 路 RGB（可 resize）、language、本体；输出 joint 或 EE chunk。若用 EE，CCL 直接作用；若用 joint，CCL 先 FK→EE，再 IK 回 joint。
- `OSM` 输出：结构化 token（对象中心、位姿、角色、置信度、关系），供 MTA（可选）或规则使用。
- `RPT` 输出：`T_B^release`、`T_B^approach(k)`、置信度、残差、模板 id。
- `RPV` 输出：`ok`、`r_t/r_r`、谓词、建议动作（nudge/regrasp/retry/abort）。

## 4. 数据引擎

### 4.1 点云重建

- 对 32 任务各抽 100–200 条成功演示（优先覆盖不同物体颜色/形状/桌面），共 3.2k–6.4k episodes。
- 每条抽 8–12 个关键帧（步骤开始、接近、释放、释放后），共 30k–70k 帧。
- 用 SGBM + WLS 重建；与演示 `state_d435` 对齐；5mm 体素降采样；保存 table/object/container 三种坐标。
- 质检：平面拟合残差、左右目一致性、释放点附近点云覆盖率；不合格帧丢弃。

### 4.2 atlas 构建

- 离线标注：SAM2/GroundingDINO 在关键帧上分割目标/容器/支撑面；人工抽检 5%；**不部署**。
- 模板：每个任务/步骤 3–8 个代表模板；记录点云、释放位姿、接近轨迹、夹爪宽度、协方差。
- 失败演示不进入 atlas 的释放位姿统计，但可用于 RPV 负样本（掉落/歪斜/未插入）。
- 版本化：atlas 与 WLA checkpoint、SSG 版本绑定，避免训练/推理不一致。

### 4.3 标定

- 每个任务/机器人：用 `state_d435` + `waist_state_joint` 拟合 `F`；留出 20% 验证重投影误差。
- 桌面平面/相机外参：用 100 帧取中位数，RANSAC 阈值 5mm。
- 夹爪宽度：从演示统计开合范围；CCL 限幅。

### 4.4 扰动数据（离线/孪生）

- 位置：对象/容器平移 ±10cm、旋转 ±20°；
- 背景：换桌布颜色/纹理（用其他任务背景合成）；
- 干扰物：插入 3–5 个几何簇；
- 未见物体：替换同类不同尺寸/颜色（几何模板留一）；
- 人为移动：在轨迹中间把容器平移 2–5cm 或拿走；
- 相机：外参 ±2cm/±2°，深度噪声/遮挡。

这些扰动只用于离线评估/孪生，不并入官方训练（除非确认合规）。

### 4.5 训练数据（可选 MTA）

- 官方 33k 演示 + 我们计算的 table/object 位姿、OSM 伪标签（由配准生成，非人工）。
- 输入：4 路 RGB + language + 本体 + 8–16 个 map tokens（对象中心/位姿/角色/置信度）。
- 输出：action chunk（joint 或 EE）。
- 只用官方数据；不引入外部数据。

## 5. 训练配方

### 5.1 最小可行版（training-free，先做）

1. WLA-1.0-Base 直接推理/官方微调；
2. 外挂 RCA + OSM + DPA + RPT + CCL + RPV；
3. 不改 WLA 结构，不做 MTA；
4. 目标：2–3 周内跑通离线 + 孪生 + 1 个调试任务。

这是本轮的主路径：**先证明"任务坐标系层"有效，再决定是否把地图注入模型。**

### 5.2 表框动作规范化（TFA，训练期，低成本）

- 对每条演示，计算 `T_B^T`；把 EE 动作/位姿变到 table frame：

```text
T_T^E = (T_B^T)^{-1} T_B^E
```

- 训练 WLA 预测 table-frame 动作；输入加 `T_B^T` 的 6D token（或 9D 旋转矩阵）。
- 推理：预测 `T_T^E`，再变回 `T_B^E` 执行。
- 目的：让策略对桌面/机器人 base 的平移旋转近似等变；位置/跨机器人轴直接受益。
- 风险：WLA 原动作头在 base frame 训练；改 frame 需要微调；先在小数据上验证。

### 5.3 MTA（可选，第二阶段）

- 8–16 个 map token：每个 token = [object center (3), 6D rotation (6), role embedding (8), confidence (1)]；经 MLP 投影到 WLA 的 token 维度。
- 在 WLA 的视觉 token 后拼接；LoRA 微调 cross-attention/action expert；冻结视觉主干。
- 训练目标：action chunk + 辅助对象位姿/存在性（可选）。
- 显存：6B + LoRA + 8–16 token，24–48GB；官方 24GB 路径需梯度检查点/8-bit。
- 合规：MTA 是 WLA checkpoint 的一部分，不引入第二个模型。

### 5.4 超参建议

- action chunk：16（30Hz 下 533ms）；长程任务 32。
- 图像：head 320×240，wrist 160×120（省带宽）；`obs_delta_indices`：当前帧 + 2 帧历史。
- LoRA rank 32–64；lr 1e-4；batch 8–16；1–2 epoch。
- 数据增强：颜色/亮度/背景替换；几何扰动仅用于鲁棒性，不改变动作标签。
- 监控：训练/验证 action MSE、release pose error、RPV 成功率。

## 6. 实验设计

### 6.1 离线：leave-one-demo-out

- 每个任务留出 20% 演示；atlas 用其余 80% 构建。
- 查询帧：留出演示的"接近前/释放前"帧；用其点云做配准。
- 指标：释放位姿平移/旋转误差、配准成功率、模板检索 top-1、运行时间。
- 基线：
  1. 最近邻演示位姿（不配准）；
  2. 只 table frame；
  3. 只 object frame；
  4. 无 atlas（VLA 直接输出）；
  5. oracle segmentation + 真值容器位姿。
- 扰动：对象/容器平移 ±10cm、旋转 ±20°、背景替换、遮挡 20–40%。

### 6.2 孪生：CCL 插头/网线/碗堆

- MuJoCo/Isaac 搭 G1 双臂 + 桌面 + 插排/网口/碗；用脚本 actor 产生带噪声的 VLA chunk。
- 对比：无 CCL（两臂独立）vs CCL（anchor/actor）。
- 扰动：anchor 平移 ±2cm、旋转 ±5°；actor 初始误差 ±1cm。
- 指标：插入成功率、相对位姿误差、完成时间、安全终止。
- 目标：CCL +20pp；方差 −50%。

### 6.3 真机：3 个代表任务

- T27 StackBowls（堆叠、位置/人为干扰）；
- T10 PlugCharger（插入、双手/容器移动）；
- T19 ZipUp 或 T26 PlugInEthernet（拉链/网口，双手）。
- 每任务 10 trials，A/B（WLA baseline vs +SPARC）；用不计分单任务调试槽，每天 1 槽，分 3 天。
- 指标：终局步成功率、步骤分、时间、安全终止、p50/p99 时延。
- 注意：调试槽稀缺，先离线/孪生筛掉明显失败配置；每次只改一个模块。

### 6.4 官方计分

- 在离线/孪生/调试通过后，跑一次完整 320 trials；报告成功率/步骤分/时延；不刷榜。
- 统计：320 trials、p≈0.3 时 SE≈2.56pp；对外只报 +3–5pp 保守目标；用配对 McNemar 检验 A/B。

### 6.5 消融

| 消融 | 验证 |
|---|---|
| 去 RCA | 跨机器人/桌高是否崩 |
| 去 OSM | 容器移动/干扰物是否崩 |
| 去 RPT（只 table） | 物体位置泛化是否崩 |
| 去 CCL | 双手/插入是否崩 |
| 去 RPV | 假完成/掉落是否增加 |
| 只用几何 vs 几何+颜色 | 背景/未见物体权衡 |
| 模板数 1/3/8 | 配准成功率/存储 |
| 体素 2/5/10mm | 精度/延迟 |

### 6.6 失败诊断

- 配准失败：inlier/overlap/残差；可视化；
- 地图错误：节点 id/关系；人工抽检；
- CCL 振荡：相对误差/速度；调增益；
- RPV 误报：阈值/点云覆盖；分任务校准；
- 时延：各模块 p50/p99；降采样/异步。

## 7. 创新点清单

### I1 任务坐标系漂移的形式化（新增，押注）

- **动机**：5 个泛化轴 + 跨机器人，本质都是坐标系变化；现有 VLA 把动作绑在 base frame/外观上。
- **差异**：不是"再估一个 6D 位姿"，而是把 table/object/container 三种 frame 作为一等公民，统一解释 F1–F6。
- **可行性**：官方数据有 stereo + `state_d435` + waist；WLA 提供动作底座。
- **资源**：1 人 2 周做形式化 + 标定。
- **步骤**：定义 frame → 拟合 RCA → 离线验证。
- **风险**：测试 API 的 waist 顺序/相机安装不一致。
- **状态**：主路径。

### I2 立体视觉构建任务坐标系（新增，押注）

- **动机**：API 无 depth，但 head stereo 已校正；不利用等于浪费。
- **差异**：不是"用深度模型"，而是 SGBM + 标定 + 平面/配准，确定性、低延迟、单模型合规。
- **可行性**：640×480 双目、58mm 基线、桌面 0.5–1m，深度误差 ~mm–cm 级。
- **资源**：1×A100 离线重建；在线 CPU/GPU 20–30ms。
- **步骤**：SGBM → 点云 → 平面 → 对象簇。
- **风险**：透明/反光/低纹理；用分桶回退。
- **状态**：主路径。

### I3 对象中心演示点云 atlas（新增，押注）

- **动机**：视频检索受背景/外观影响；点云 atlas 是几何的、可配准的、跨机器人。
- **差异**：不是"检索动作块"，而是检索"对象模板 + 释放位姿 + 局部接近轨迹"。
- **可行性**：32 任务、每任务 100–200 条演示；离线标注一次。
- **资源**：~2GB 存储；1–2 周构建。
- **步骤**：关键帧 → 点云 → 模板聚类 → 统计。
- **风险**：标注误差；用人工抽检/多模板。
- **状态**：主路径。

### I4 RPT：配准迁移释放位姿 + 局部接近轨迹（新增，押注）

- **动机**：PILOT 的 OPT 只做离线位姿统计，容器移动/跨机器人就失效。
- **差异**：在线配准到 atlas，输出容器系位姿 + 最后 0.5–1.5s 接近先验；只修最后几厘米，不复制整条轨迹。
- **可行性**：FPFH+RANSAC+ICP 在 5–10k 点上 100–300ms；1–2Hz 足够。
- **资源**：Open3D + 1 人 3 周。
- **步骤**：配准 → 置信度 → 三种 frame 模式 → 融合权重。
- **风险**：配准失败/多解；用多模板/多初值/回退。
- **状态**：主路径。

### I5 OSM：语言—演示—控制的共享索引（新增，押注）

- **动机**：语言、演示、控制各自为政；需要同一套对象/槽位/关系。
- **差异**：不是可视化 scene graph，而是控制回路里的可查询状态；节点由几何簇 + atlas 配准产生，不依赖学习分割器。
- **可行性**：32 桌面任务、对象数 3–10；规则 + 几何足够。
- **资源**：1 人 3 周。
- **步骤**：节点/边 schema → 数据关联 → 语言查询 → map diff。
- **风险**：遮挡/透明；用置信度/回退。
- **状态**：主路径。

### I6 CCL：一臂夹具、一臂相对运动（新增，押注）

- **动机**：官方双手维度 + 15 个可能双手任务；双臂 VLA 数据效率低、相对漂移。
- **差异**：不新增学习模型；在 action chunk 后做确定性相对控制；anchor 视觉伺服 + actor 螺旋微搜索。
- **可行性**：EE 位姿/关节都有；无力传感器但可用几何配合度。
- **资源**：1 人 3 周 + 孪生环境。
- **步骤**：角色分配 → 相对目标 → 增益/限幅 → 插入搜索。
- **风险**：与 VLA 冲突/振荡；限幅/低增益/回退。
- **状态**：主路径。

### I7 RPV：配准校验 + 谓词（新增，押注）

- **动机**：成功=所有步骤完成；VLA 置信度不可靠；掉落/歪斜/未插入常见。
- **差异**：用配准残差 + 任务谓词 + 稳定性，不训练失败分类器。
- **可行性**：释放后点云可重建；阈值可分任务校准。
- **资源**：1 人 2 周。
- **步骤**：残差 → 谓词 → 稳定性 → 恢复动作。
- **风险**：点云遮挡/透明；多模态校验/回退。
- **状态**：主路径。

### I8 RCA：reset 自校准（新增，中优先）

- **动机**：跨机器人/桌高是隐藏轴；API 不给相机外参。
- **差异**：用 waist FK/拟合 + 桌面平面精化，不用额外标定板/动作。
- **可行性**：演示有 `state_d435` + waist；测试有 `lower_body[12:15]`。
- **资源**：1 人 2 周。
- **步骤**：拟合 F → 平面精化 → 残差门控。
- **风险**：测试 waist 顺序不一致；用平面/背景兜底。
- **状态**：主路径。

### I9 Map diff 人类干扰检测（新增，中优先）

- **动机**：官方人为干扰是真人现场操作；固定剧本不够。
- **差异**：用 OSM 节点位姿/存在性变化检测移动/拿走/撤销，触发重规划。
- **可行性**：点云配准 + 关系图；无需人物检测模型。
- **资源**：1 人 1–2 周。
- **步骤**：差分 → 状态机 → 恢复。
- **风险**：遮挡误判；时间一致性与置信度。
- **状态**：第二阶段。

### I10 配准置信度作为 OOD 信号（新增，中优先）

- **动机**：SAGE 的异常监测需要信号；配准残差天然是"当前场景是否在演示流形上"的度量。
- **差异**：不训练 OOD 检测器；用 inlier/overlap/残差 + 时序。
- **可行性**：RPT 已输出置信度。
- **资源**：1 人 1 周。
- **步骤**：校准 → 阈值 → 触发 Cautious/Recover。
- **风险**：透明/遮挡导致误报；分桶。
- **状态**：第二阶段。

### I11 表框动作规范化（TFA，新增，中优先）

- **动机**：动作绑 base frame，跨桌高/机器人不可迁移。
- **差异**：训练期把动作变到 table frame，推理反变换；让策略近似等变。
- **可行性**：只需 `T_B^T`；WLA 可微调。
- **资源**：1 人 2 周 + 1 次微调。
- **步骤**：变换 → token → 微调 → 验证。
- **风险**：WLA 原动作头分布改变；小学习率/短训练。
- **状态**：第二阶段（可选）。

### I12 MTA：map token adapter（新增，低优先）

- **动机**：让 WLA 直接"看到"地图，而不是只靠外挂规则。
- **差异**：轻量 adapter + LoRA，不引入第二个模型。
- **可行性**：WLA 支持微调；24–48GB。
- **资源**：2 人 3–4 周 + 8×H100 数天。
- **步骤**：token schema → 投影 → LoRA → 联合训练。
- **风险**：过拟合/破坏原能力；先 A/B。
- **状态**：第三阶段（可选）。

### I13 SAGE AEG 安全外壳（保留）

- **动机**：安全终止不补测；一次鲁莽可能浪费当天唯一时段。
- **差异**：保留 SAGE 的状态机/限幅，但作为 SPARC 的外壳，不抢主路径。
- **可行性**：确定性控制，<10ms。
- **资源**：复用第 8 轮。
- **步骤**：接入 CCL/RPV。
- **风险**：过度保守导致超时；分级。
- **状态**：保留。

### I14 数据引擎（新增，工程）

- 离线重建/标注/atlas 版本化；只使用官方数据；外部数据默认 OFF。
- 资源：1×A100 1–2 周；~2GB atlas。
- 风险：标注误差/存储；抽检/降采样。
- 状态：主路径。

### I15 评测协议（新增，工程）

- leave-one-demo-out + 扰动 + 孪生 + 3 任务调试 + 1 次官方计分。
- 统计：320 trials SE≈2.56pp；只报保守增益。
- 风险：调试槽稀缺；先离线筛。
- 状态：主路径。

## 8. 风险、合规与开关

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| 立体深度在透明/反光/低纹理上失败 | 高 | RPT 失效 | 分桶：只对刚性物体配准；透明/布料用 VLA+相位；腕部特写 |
| 测试 API waist 顺序/相机安装不一致 | 中 | RCA 偏 | 平面/背景精化；残差门控；回退纯 VLA |
| 配准多解/对称物体 | 中 | 位姿错 | 多模板/多初值；语义/颜色排序；RPV 兜底 |
| OSM 分割/关联错误 | 中 | 选错对象 | 几何簇 + atlas；置信度；RPV 重试 |
| CCL 与 VLA 冲突 | 中 | 抖动/超时 | 低增益/限幅；异常回退；只 anchor 修正 |
| RPV 误报/漏报 | 中 | 重试/假完成 | 分任务阈值；多模态；稳定性窗口 |
| 时延尖峰 | 中 | 评测记录/超时 | 异步；降采样；chunk 16；p99 预算 |
| 单日一槽/不补测 | 高 | 迭代慢 | 离线/孪生为主；调试槽发布门 |
| 单模型合规解释 | 中 | 取消资格 | WLA 唯一学习模型；几何/控制确定性；写模型卡 |
| 外部数据/离线工具合规 | 中 | 违规 | 默认 OFF；只用官方数据；书面确认 |
| 过拟合调试任务 | 高 | 官方泛化差 | 3 任务/多轴；离线留出；不按任务调参 |

合规开关：

- `ALLOW_EXTERNAL_DATA=0`（默认）；`ALLOW_OFFLINE_LLM_LABEL=1` 仅离线；`DEPLOY_LEARNED_SEG=0`；`DEPLOY_SECOND_MODEL=0`；`USE_MTA=0/1`；`USE_TFA=0/1`。
- 提交模型卡写明：唯一学习模型 WLA；其他为确定性几何/控制；离线工具不随提交；无测试时训练；无外部数据。
- 安全：速度/加速度/jerk 限幅；工作空间盒；桌面平面；异常运动/人手 → 减速/让行/停；不大力顶死。

## 12. 一句话押注

**把"跨机器人/跨场景稳定的任务坐标系"当作第一性缺口：用点云配准把演示 atlas 对齐到当前桌面，用语义地图承载对象/槽位/关系/进度/被人移动，用一臂 fixture + 一臂 actor 的协同控制在容器系里执行，从而把终局放置和双手任务从开环模仿变成度量闭环；这比再训一个更大的 VLA 更便宜，也比只做失败恢复更根本。**
