# 第 66 轮（承接第 65 轮「VISTA 故障可归因四层闭环」IP-214~223；灵感循环新周期第 1 轮；本轮灵感：「论文发表」×「模型蒸馏」）

> 第 65 轮用三阶段签名把「几何可证伪」升级为「故障可归因」，其自述的最大风险是一个无法靠再叠加模态解决的制度性缺口：**故障假设集有限、且视觉与几何的失效被假定相互独立；真实故障常是未知类型的组合，透明/镜面/对抗 patch 又让视觉与几何共享同一个分布外失效源。此时 FIR 会把未知复合故障强行归入最近假设、只膨胀错误的球，而系统因为「已经归因」反而更自信地继续执行。** 第 65 轮的问题不是「证据不够多」，而是「**没有人有资格否决这个归因**」。本轮借用两个看似与机器人无关的词——论文发表与模型蒸馏——来补这个资格问题：
>
> **把一次性归因升级为「可同行评审、可预注册、可撤稿、可蒸馏」的证据制度：慢语义流是作者，独立评审团是审稿人，实时学生只是未经评审的预印本；系统从此允许「拒稿 / 独立性不足 / 撤稿」三种诚实的失败，而不是被迫把未知故障塞进最近假设。**

## 0. 直觉与动机

**灵感 1（论文发表 → 从「作者自信」到「评审 + 预注册 + 撤稿」）**
直觉：科学界早就知道单个作者的结论不可信，所以有同行评审、预注册、可复现工件和撤稿。第 65 轮的 FIR 恰恰像一个从不被审稿、却越来越自信的作者：它只有一个输出「最可能的 H」，没有「我拒绝归因」这一合法出口。于是给每条安全主张配一套论文式制度：**主张（claim）+ 证据（evidence）+ 局限（limitations）+ 可复现工件（reproducibility artifact）+ 独立评审（reviewers）+ 预注册（pre-registration）+ 撤稿（retraction）**。只有「已发表」的主张才获得执行授权；新证据与已发表主张冲突时必须撤稿，并回溯失效所有依赖它的证书与动作。

但这里有个反直觉的要害：**评审的有效性取决于评审人的错误独立性，而不是意见一致性。** 第 65 轮的最大风险正是视觉与几何共因失效；如果三个「审稿人」共享同一个 OOD 源，那么「全票通过」恰恰是最危险的信号。因此必须给评审团发一张「独立性证书」，当独立性无法证明时，系统必须判「无法评审」并退回保守模式——这才是把第 65 轮隐藏假设 A88 变成运行时可见量。

**灵感 2（模型蒸馏 → 把慢评审蒸馏成会拒答的实时学生）**
直觉：语义流的评审太慢（几十到上百 ms），无法塞进 2.5ms 实时环。于是把教师（评审团 + 世界模型 + CSC）蒸馏成一个实时学生，直接预测故障后验、k* 与是否拒答。但蒸馏有两个坏性质：学生会继承教师的偏差；而且学生在分布外往往比教师**更自信**。所以必须做「可拒答蒸馏」：学生只在「教师-学生决策一致 + conformal 覆盖」满足时快速表态，否则把样本退回教师。这把延迟变成可证明的「拒答率-延迟」权衡，而不是拍脑袋的加速。

**灵感 3（合流 → 学生只能做减法，不能做加法）**
最关键的设计约束不是「学生多准」，而是「学生被允许做什么」。**学生只能提前停、缩短前缀、预取下一块（减法/安全方向），绝不能延长前缀或授权新动作（加法/危险方向）；任何加法都必须教师发表。** 这样实时性来自「执行上一轮已发表的短前缀 + 学生并行预取」，安全方向不依赖学生正确，而危险方向永远回到慢评审。这与第 65 轮「长预测、短执行」严丝合缝：长预测用于前瞻，短执行用于承诺，学生只是把前瞻提前。

**灵感 4（三源合流 → PEER：Publication-grade Epistemic Evidence Regime）**
闭环：阶段签名 ρ → 学生预印本（preprint，只提建议）→ 预注册主张哈希（防止事后合理化）→ 独立评审团打分 → 独立性证书（M_eff）→ FIR-P 四结果判决（发表 / 拒稿 / 歧义 / 独立性不足）→ 发表则 CSC-P 认证前缀并执行 → 执行后撤稿监视器比对预注册主张 → 冲突则撤稿并按依赖 DAG 回溯失效 → AIC-P 做「评审共谋 + 蒸馏投毒」对抗认证。第 65 轮是「几何-技能-干扰-接触-归因」，PEER 在其上再加一层「**证据制度**」：它不产生新信息，只决定「谁有资格签字、签错了怎么撤回」。

**灵感 5（GRIP/VISTA 组件的原位升级）**
- **FIR → FIR-P**：输出从「argmax 假设」扩为四结果 `publish / reject / ambiguous / independence_failure`；未知复合故障不再被迫归类，而是合法拒稿。
- **CSC → CSC-P**：只认证「已发表」主张；学生可缩短 k*（安全方向），延长必须等待发表。
- **AIC-V → AIC-P**：干扰集增「评审共谋」（所有评审人共享 OOD 源）与「蒸馏投毒」（师生共错）。
- **RSC-V/WCV-V → RSC-P/WCV-P**：独立性不足时不再假装定向膨胀，而是显式进入「不知道」的保守联合膨胀或 safe_idle。
- **J_vista → J_peer**：证书增 claim_id、prereg_hash、reviewer_set_hash、M_eff、distill_gap、relative_to_teacher、retraction_log_hash。
- **新增**：REV（评审团）、IDC（独立性证书）、DSN（蒸馏学生）、DEFER（拒答门）、PP/PB（预印本-发表分离）、RL（撤稿账本）、PR（预注册与复现工件）。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（PEER 闭环）**：PEER = (VISTA, PR, REV, IDC, DSN, DEFER, PP/PB, RL, AIC-P, J_peer)。不变式：**世界模型、评审、预注册、发表、撤稿只在语义流；实时流只执行已发表前缀、学生只做减法（停/缩）、采集证据、触发撤稿告警，零学习写。**
- **定义 234（安全主张与论文式记录）**：claim c=(φ_claim, scope, evidence, limitations, repro)。φ_claim 是可判定的执行谓词（如「前缀 k 步内在 supp_δ(post) 上 ρ_safe≥0」）；scope 为状态域/技能/时间窗；repro 含模型哈希、种子、标定集版本与环境指纹。
- **定义 235（评审团）**：R={r_1,…,r_M}，r_i:(claim,evidence)→(score_i,features_i)。评审人按**模态子集、架构、先验、标定集、时间窗**分化；聚合评审判定为 (decision, margin, disagreement)。
- **定义 236（评审独立性证书 IDC）**：在共因 OOD 标定集 ℰ_common 上取各评审人的错误指示 e_i∈{0,1}，相关矩阵 C_ij=corr(e_i,e_j)；令 λ 为 C 的特征值，定义有效独立评审人数 `M_eff=(Σλ)²/Σλ²`（参与率）。IDC=(M_eff, ρ̄, pass=M_eff≥M_min)。**独立性约束的是错误相关，不是输出一致；一致但共错恰恰是 M_eff→1。**
- **定义 237（预印本-发表分离 PP/PB）**：学生输出 pre_t=(ĥ,k̂*,d_pre,defer)。**发表**需 REV 接受 ∧ IDC 通过 ∧ 主张已预注册；只有已发表主张携带执行授权。预印本仅可用于 (i) 提前安全停机/缩短、(ii) 预取下一块供异步评审、(iii) 排定评审优先级，**不得签字**。
- **定义 238（可拒答蒸馏与蒸馏间隙）**：g_D(s)=d_dec(f_S(s),f_T(s))，d_dec 对相同决策为 0、否则含后验 TV 距离；用 split-conformal 取 q_D(α) 使 P[g_D≤q_D(α)]≥1−α。接受集 A={g_D≤q_D} 上满足 P[f_S=f_T|A]≥1−α。**这是相对教师保证，不是绝对安全**；J_peer 必记 `relative_to_teacher=True`。
- **定义 239（拒答门 DEFER 与选择性风险）**：当 g_D>q_D 或 H(post_S)>h_max 或学生特征 OOD 时 defer，退回异步教师；若 τ_defer 内教师未回则 safe_idle。风险-覆盖曲线 R_sel(q) 与期望延迟 E[L]=p_defer·L_T+(1−p_defer)·L_S 共同决定 q_D：在 E[L]≤B 下最小化 R_sel。
- **定义 240（FIR-P 四结果归因）**：decide 返回 ∈{publish(H*), reject, ambiguous, independence_failure}。reject 由评审分歧/后验熵越界触发→AFA；independence_failure 由 IDC 失败触发→保守联合膨胀或 safe_idle，**不允许定向膨胀**；只有 publish 才进入执行。**未知复合故障自此有「拒稿」这一诚实出口。**
- **定义 241（依赖性校正的证据聚合）**：log P(H|ρ)=Σ_i w_i log p_i(ρ|H)+log prior，权重满足 Σ_i w_i=M_eff（如 w_i∝1/(1+(M−1)ρ̄)）。等价于把 M 个相关评审折成 M_eff 个独立评审；ρ̄→1 时退化为单一评审，杜绝「全票=强证据」的假象。
- **定义 242（撤稿协议与依赖 DAG）**：claim 在执行前记录预注册哈希 h_pre。执行后证据 z 若使 φ_claim 以超过 q_ret 的置信被否证，则撤稿：沿依赖 DAG D 失效该 claim 的所有后代（缓存 CSC 证书、技能参数、WCV 编译结果），写入 RL=(claim, z, reason, timestamp, descendants)，后代必须重新评审。**执行中的前缀因 k*≤m 可在不可逆点前被截断，因此撤稿是可行动的而非仅存档。**
- **定义 243（预注册与复现工件 PR）**：执行前把 h_pre=H(φ_claim,scope,k*,reviewer_set,evidence_summary,timestamp,nonce) 写入只追加日志。执行后任何归因/解释必须引用一个已预注册哈希，否则标 `post_hoc_rationalization=True` 且该主张不可信——直接封堵「事后挑一个能通过的假设」。
- **定义 244（AIC-P 评审共谋与蒸馏投毒对抗认证）**：ℰ_P=ℰ_V×ℰ_collude×ℰ_distill。ℰ_collude 含评审人共享 OOD 源、对抗性一致；ℰ_distill 含蒸馏投毒、师生共错。认证要求：在 ℰ_P 下，要么 IDC 失败被检出，要么撤稿在一个周期内触发。J_dir 增 reviewer_error_corr、distill_poison_ver。
- **定义 245（制度性降级 RSC-P/WCV-P）**：independence_failure 时不伪装归因，置 `epistemic_state=independence_failure`，做全球联合膨胀或 safe_idle；reject 走 AFA；撤稿则回滚到最近已发表且未撤稿的证书。**把「我们知道自己不知道」与「我们以为自己知道」在状态机层面分开。**
- **定义 246（师生证书链 J_peer）**：J_peer=(J_vista, claim_id, prereg_hash, reviewer_set_hash, M_eff, idc_ver, preprint_hash, distill_gap, defer_flag, relative_to_teacher, retraction_log_hash, aic_p_ver)。Valid ⇔ Valid(J_vista) ∧ 已发表 ∧ M_eff≥M_min ∧ k*≥1 ∧ 已预注册 ∧ 无未决撤稿。**Valid 表示「可审计」，不表示「为真」。**
- **定义 247（实时预算与延迟）**：学生 L_S<0.3ms，语义评审 L_T∈[20,80]ms，defer 概率 p_d。E[L]=p_d L_T+(1−p_d)L_S；要求 E[L]≤B 且 P[L>τ_defer]≤δ。执行始终跑上一轮已发表前缀，学生在旁预取下一块，故实时环不等评审。
- **定义 248（PEER 闭环算子）**：语义流 [VISTA 语义→构造 claim→预注册→DSN 预印本→REV→IDC→FIR-P→发表/CSC-P→执行 k*→EV_exec→撤稿检查 RL→RSC-P/OLP/DIR/SSB→AIC-P]；实时流 [采集证据→学生预印本→defer 判定→已发表前缀派发→早停/撤稿告警→预取]。

## 2. 关键算法骨架

```python
# FIR-P：四结果，而不是被迫 argmax
decision = fir_p.decide(review, M_eff, idc)
if decision == 'publish':            # 已预注册 + 评审接受 + 独立性通过
    csc_p.certify_and_execute(claim, k_star)
elif decision == 'reject':           # 评审分歧/熵高
    afa.choose_probe(post, phi_hat, f_safe)
elif decision == 'independence_failure':
    wcv_p.conservative_union(balls)  # 不伪装定向膨胀
    or safe_idle()
# ambiguous -> AFA；撤稿 -> RL.retract(claim) 沿 DAG 失效

# 学生只做减法
pre = dsn.preprint(state)
if pre.defer or pre.k_hat < published_k:
    published_k = min(published_k, pre.k_hat)   # 缩短永远安全
# 延长/新动作必须等待 teacher publish，学生无权
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（相关评审的证据折扣）**：若评审人 log-likelihood 贡献两两相关 ρ，则总 Fisher 信息仅相当于 `M_eff=M/(1+(M−1)ρ)` 个独立评审；ρ→1 时 M_eff→1。故「全票通过」在共因失效下等同于一个评审，必须由 IDC 显式暴露。
- **引理 10（可拒答蒸馏的相对安全）**：在接受集 A 上，conformal 保证学生决策与教师一致的概率 ≥1−α；学生只能在安全方向（停/缩）自由行动，因此**实时性不引入新的危险方向风险**。但学生绝不能比教师更「正确」，只能更快。
- **定理 9（PEER 的诚实拒绝）**：在 IDC 与撤稿协议下，未知复合故障不会被视为最近假设继续执行：要么因评审分歧被 reject、要么因共因失效被 independence_failure、要么成为可撤稿的已发表主张。第 65 轮的「自信地错误归因」被替换为「可检测的拒绝或可审计的主张」；但**正确性仍受限于评审团信息，PEER 不创造信息**。
- **定理 10（拒答阈值的最优性）**：选择性风险 R_sel(q) 随覆盖单调不增、期望延迟 E[L](q) 随覆盖单调增；在 E[L]≤B 下存在最优 q* 使 R_sel 最小，且无论 q 取何值，因学生只能做减法，安全不变式不被破坏。
- **命题（撤稿新鲜度）**：依赖 DAG 保证任何撤稿 claim 的后代在下次派发前失效；结合 k*≤m，撤稿在越过不可逆点前生效。**命题（无免费信息）**：若所有评审人错误相关系数为 1，则 M_eff=1、IDC 必失败——这正是第 65 轮隐藏假设 A88 的显式化，也是本轮贡献的边界：它是证据治理，不是新传感。

## 5. 本轮最大风险

**一句话**：PEER 把「通过评审」制度化为可信徽章，但评审团与蒸馏学生可能共享同一个错误世界（M_eff 被高估 + 学生的分布外过度自信），于是错误共识被加速、被合法化，而撤稿又是事后机制、无法撤销已经发生的不可逆物理伤害——「制度性自信」取代了第 65 轮的单点故障，成为更隐蔽的新单点故障。

# 第 66 轮产物 · 创新点清单 v4：PEER（Publication-grade Epistemic Evidence Regime：论文发表 × 模型蒸馏 驱动的「可评审-可预注册-可撤稿-可蒸馏」安全证据制度；REV×IDC×PP/PB×DSN/DEFER×FIR-P×CSC-P×RL×PR×AIC-P×RSC-P×WCV-P×J_peer）

> 承接第 65 轮 IP-214~223（VISTA：VPG×ACH×FIR×VCV×VSP/AFA×CSC×RSC-V×WCV-V×CSP-V×AIC-V×J_vista）。第 65 轮把几何先验从「可证伪」推进到「可归因」，但它把所有赌注押在「归因正确」上，且其最大风险已指出：**故障假设集有限、视觉与几何可能共因失效，未知复合故障会被强行归入最近假设，只膨胀错误的球，而系统因「已经归因」更自信地继续执行。** 本轮不做第 6 个传感器，也不假设故障可枚举，而是补一个更根本的缺口——**没有机制有资格否决那个归因**。于是把科学共同体的证据制度借进来：**预注册、同行评审、发表、撤稿**；再把慢评审**蒸馏**成会拒答的实时学生。核心实现目标是 **「允许诚实地说不知道，并让每一次『知道』都留下可撤稿的签字链」**。

## 2. 形式化定义（完整版）

**定义 233（PEER 闭环）** PEER 是 VISTA 的「证据制度」升级：在 VISTA 的「语义流 ∘ 实时流」骨架上挂载 PR（预注册）、REV（评审团）、IDC（独立性证书）、DSN/DEFER（可拒答蒸馏学生）、PP/PB（预印本-发表分离）、RL（撤稿账本）、AIC-P（共谋/投毒认证），并原位升级 FIR→FIR-P、CSC→CSC-P、RSC-V/WCV-V→RSC-P/WCV-P、J_vista→J_peer。不变式：**所有评审、预注册、发表与撤稿只发生在语义流与低频线程；实时流只执行已发表前缀、采集证据、触发早停与撤稿告警、预取下一块，零学习写操作。学生预印本永不单独获得执行授权。**

**定义 234（安全主张与论文式记录）** 一条主张
c=(φ_claim, scope, evidence, limitations, repro)，
其中 φ_claim 是关于执行轨迹的可判定谓词（例：∀s≤k，∀H∈supp_δ(post)，ρ_safe(s;H)≥0）；scope 为状态域、技能与时间窗；evidence 为阶段签名 ρ、各评审人打分、独立性证书；limitations 显式记录 `visual_unobservable`、M_eff、蒸馏间隙与教师相对性；repro 含模型哈希、随机种子、标定集版本、环境指纹。**主张不是「系统相信什么」，而是「系统愿意为之签字、并接受撤稿的东西」。**

**定义 235（评审团 REV）** R={r_1,…,r_M}，每个 r_i:(c,evidence)→(score_i, features_i)。评审人沿五轴分化：模态子集（视觉/力/本体/几何）、架构（GMM/归一化流/树集成）、先验（均匀/保守/历史）、标定集（不同工况切片）、时间窗（不同块长度）。聚合评审判定为 (decision, margin, disagreement)：margin=|top1−top2|，disagreement 为评审人决策的成对不一致率。**评审团的价值不在「更多模型」，而在「错误尽量不相关」。**

**定义 236（评审独立性证书 IDC）** 在共因 OOD 标定集 ℰ_common（透明/镜面/对抗 patch/未知物体）上记录每个评审人的错误指示 e_i∈{0,1}，计算错误相关矩阵 C_ij=corr(e_i,e_j) 与特征值 λ_1≥…≥λ_M，定义
M_eff=(Σλ)²/Σλ²。
等相关 ρ 时 M_eff=M/(1+(M−1)ρ)：ρ=0 得 M，ρ=1 得 1。IDC=(M_eff,ρ̄,pass)，pass ⇔ M_eff≥M_min。**注意独立性约束的是错误相关而非输出一致：三个评审人永远同票但共同出错时，M_eff=1，IDC 必失败。** 这正是第 65 轮最大风险 A88 的显式化。

**定义 237（预印本-发表分离 PP/PB）** 学生输出
pre_t=(ĥ, k̂*, d_pre, defer)。
「发表」需同时满足：REV 接受、IDC 通过、主张已预注册。只有已发表主张携带执行授权。预印本仅可用于：(i) 提前安全停机或缩短前缀（减法）；(ii) 预取下一块供异步评审；(iii) 排定评审优先级。**学生无权延长前缀、无权授权新动作、无权改变技能——所有加法必须等待教师发表。** 这一条把「实时」和「安全」解耦：实时执行的是上一轮已发表前缀，学生只是提前准备。

**定义 238（可拒答蒸馏与蒸馏间隙）** 教师 f_T（评审团聚合 + 世界模型 + CSC），学生 f_S。定义决策空间间隙
g_D(s)=d_dec(f_S(s), f_T(s))，
相同决策时为 0，否则含后验 TV 距离与 k 差。用 split-conformal 在留出集上取 q_D(α)，使 P[g_D≤q_D(α)]≥1−α（可交换性下）。在接受集 A={g_D≤q_D} 上，P[f_S=f_T|A]≥1−α。**该保证是「相对教师」的，不是绝对安全**：教师错，学生也错；J_peer 必须写 `relative_to_teacher=True`。蒸馏能买到速度，买不到信息。

**定义 239（拒答门 DEFER 与选择性风险）** 满足任一条件即 defer，退回异步教师：
g_D>q_D(α) ∨ H(post_S)>h_max ∨ 学生特征落在 OOD 区。
若 τ_defer 内教师未返回，则 safe_idle。选择性风险 R_sel(q)=P[学生错 | g_D≤q]，期望延迟
E[L](q)=p_defer(q)·L_T+(1−p_defer(q))·L_S。
阈值选择为：在 E[L]≤B 与 P[L>τ_defer]≤δ 下最小化 R_sel。**拒答不是失败，是把「不确定」变成可计量的延迟预算。**

**定义 240（FIR-P 四结果归因）** FIR-P 的判决集扩为
decide(ρ, review, IDC) ∈ {publish(H*), reject, ambiguous, independence_failure}。
- **publish(H*)**：M_eff≥M_min、评审接受、主张已预注册；只膨胀被归因的球（沿用第 65 轮 RSC-V 规则）。
- **reject**：评审分歧高或后验熵越界；不执行、走 AFA 判别探针。
- **ambiguous**：后验不集中但评审无强分歧；走 AFA。
- **independence_failure**：IDC 失败；**禁止定向膨胀**，做保守联合膨胀或 safe_idle。
四结果把第 65 轮「被迫在某假设上继续」的缺陷，改成「**有资格拒绝签字**」。

**定义 241（依赖性校正的证据聚合）** 评审人证据相关时，朴素贝叶斯会过度自信。采用
log P(H|ρ)=Σ_i w_i log p_i(ρ|H)+log prior，Σ_i w_i=M_eff，
取 w_i∝1/(1+(M−1)ρ̄) 或按 C 的主特征向量分配。等价于把 M 个相关评审折算为 M_eff 个独立评审：**「全票通过」在共因下只算一票。** 这也给出 FIR-P 中 reject/independence_failure 的自然阈值来源。

**定义 242（撤稿协议 RL）** 主张 c 在执行前记录预注册哈希 h_pre。执行后获得证据 z；若 φ_claim 被 z 以超过 q_ret 的置信否证，则撤稿：
1. 将 c 标为 `retracted`，写 RL 条目（含 z 摘要、原因、时间、后代列表）；
2. 沿依赖 DAG D 失效所有后代（缓存 CSC 证书、WCV 编译、技能参数、TSL 块签名统计）；
3. 后代在重新评审并重新预注册前不得派发；
4. 若当前正在执行的前缀依赖 c，则在 min(k*,m) 内截断（第 65 轮 m 为不可逆视界）。
**撤稿是可行动的：它不是事后写检讨，而是在不可逆点前把动作停下。**

**定义 243（预注册与复现工件 PR）** 执行前把
h_pre=H(φ_claim,scope,k*,reviewer_set,evidence_summary,timestamp,nonce)
写入只追加日志。执行后任何归因、解释或证书必须引用一个已预注册哈希；否则标 `post_hoc_rationalization=True`，该主张不可信。**这直接封堵 HARKing（看到结果再挑假设）：系统不能事后声称「我早就预测到了」。** 复现工件含模型哈希、种子、标定集版本、环境指纹，使 J_peer 可在另一台机器上重放出同一判决。

**定义 244（AIC-P 评审共谋与蒸馏投毒认证）** 干扰集
ℰ_P=ℰ_V×ℰ_collude×ℰ_distill，
ℰ_collude 含评审人共享 OOD 源、对抗性一致、标定集污染；ℰ_distill 含蒸馏投毒（学生被训练成在危险样本上过度自信）、师生共错。认证要求：在 ℰ_P 下，**要么 IDC 以高概率失败并被检出，要么撤稿在一个评审周期内触发**。J_dir 增 reviewer_error_corr 与 distill_poison_ver；共因下不要求归因正确，只要求被判「独立性不足」并安全降级。

**定义 245（制度性降级 RSC-P/WCV-P）** 认知状态与物理状态分离：
- `independence_failure`：不伪装定向膨胀，置 `epistemic_state=independence_failure`，做全不确定球联合膨胀或 safe_idle；
- `reject`：走 AFA；若探针预算不足则 safe_idle；
- `retracted`：回滚到最近「已发表且未撤稿」的证书，重规划；
- `published`：按第 65 轮 RSC-V 规则正常定向膨胀。
**这条定义的意义是把「我们知道自己不知道」与「我们以为自己知道」在状态机层面彻底分开。**

**定义 246（师生证书链 J_peer）**
J_peer=(J_vista, claim_id, prereg_hash, reviewer_set_hash, M_eff, idc_ver, preprint_hash, distill_gap, defer_flag, relative_to_teacher, retraction_log_hash, aic_p_ver)。
Valid(J_peer) ⇔ Valid(J_vista)
∧ 主张已发表
∧ M_eff≥M_min
∧ k*≥1
∧ 已预注册
∧ 无未决撤稿
∧ aic_p_ver 为当前版本。
**Valid 表示「可审计、可复现、可撤稿」，不表示「物理真理」。** 审计链新增：谁签的字（reviewer_set）、他们有多独立（M_eff）、学生是否只是预印本（preprint_hash）、说法是否先于结果（prereg_hash）、后来是否被推翻（retraction_log）。

**定义 247（实时预算与预取）** 学生 L_S<0.3ms；语义评审 L_T∈[20,80]ms；defer 概率 p_d。要求 E[L]≤B（B 由控制周期给出）且 P[L>τ_defer]≤δ。关键在于**执行不等评审**：实时环始终执行上一轮已发表的前缀 k*，学生并行预取下一块的预印本，评审在语义流异步完成；若评审未在块结束前完成，则执行器安全停或按已发表的保守延续执行。故学生延迟只影响「预取深度」，不影响「当前安全」。

**定义 248（PEER 闭环算子）** 语义流：[VISTA 语义（LSF→USR/MEL→VPG→ACH→阶段切分→VCV→FIR-P）→ 构造 claim → PR 预注册 → DSN 预印本 → REV 评审 → IDC → FIR-P 判决 → 发表 → CSC-P 认证前缀 → Shield/OCB → 派发 k* → EV_exec → RL 撤稿检查 → RSC-P/OLP/DIR/SSB → AIC-P]；实时流：[采集视觉/力/阶段证据 → 学生预印本 → defer 判定 → 已发表前缀派发 → 早停/撤稿告警 → 预取下一块]。

### IP-224/225/228 评审团、独立性证书与四结果判决

```python
class ReviewerEnsemble:
    """多模态/多架构/多先验评审；独立性约束的是错误相关，不是意见一致。"""
    def __init__(self, reviewers, m_min=2.0, delta_rej=0.25):
        self.reviewers, self.m_min, self.delta_rej = reviewers, m_min, delta_rej

    def review(self, claim, evidence):
        scores = {r.name: r.score(claim, evidence) for r in self.reviewers}
        decisions = {r.name: r.decide(claim, evidence) for r in self.reviewers}
        top = max(scores, key=scores.get)
        sorted_s = sorted(scores.values(), reverse=True)
        margin = sorted_s[0] - sorted_s[1] if len(sorted_s) > 1 else 1.0
        disagree = pairwise_disagreement(decisions)
        return Review(decision=top, margin=margin,
                      disagreement=disagree, scores=scores, decisions=decisions)

    def independence_certificate(self, ood_calib):
        E = np.array([r.error_indicator(ood_calib) for r in self.reviewers])  # M×n
        C = np.corrcoef(E) if E.shape[0] > 1 else np.ones((1, 1))
        lam = np.clip(np.linalg.eigvalsh(C), 0.0, None)
        m_eff = float(lam.sum() ** 2 / max((lam ** 2).sum(), 1e-12))
        rho_bar = float((C.sum() - np.trace(C)) / max(C.size - C.shape[0], 1))
        return IDC(m_eff=m_eff, rho_bar=rho_bar, passed=m_eff >= self.m_min)


class FaultIsolationPEER:
    """四结果：允许拒稿与独立性不足，杜绝被迫归入最近假设。"""
    def decide(self, rho, review, idc, post):
        if not idc.passed:
            return Decision('independence_failure', None, post)
        if review.disagreement > DELTA_REJ or entropy(post) > H_MAX:
            return Decision('reject', None, post)
        h_star = max(post, key=post.get)
        if post[h_star] < 1.0 - DELTA_FI:
            return Decision('ambiguous', h_star, post)
        return Decision('publish', h_star, post)

    def dependent_logpost(self, rho, review, idc):
        # 依赖性校正：Σ w_i = M_eff，避免全票=强证据的假象
        M = len(review.scores)
        w = {k: (idc.m_eff / M) for k in review.scores}
        return {h: sum(w[k] * review.scores[k].loglik(h, rho) for k in w) + LOG_PRIOR[h]
                for h in HYP}
```

### IP-226/227 可拒答蒸馏学生（只做减法）

```python
class DistilledStudent:
    """学生是预印本：可提议、可停机、可预取；不可签字、不可延长。"""
    def __init__(self, net, q_D, h_max, tau_defer):
        self.net, self.q_D, self.h_max, self.tau_defer = net, q_D, h_max, tau_defer

    def preprint(self, s):
        h_hat, k_hat, logits = self.net(s)
        post = softmax(logits)
        gap = decision_gap(h_hat, k_hat, teacher_cached(s))   # g_D
        defer = (gap > self.q_D) or (entropy(post) > self.h_max) or is_ood(s)
        return Preprint(h=h_hat, k=k_hat, post=post,
                        gap=gap, defer=defer)

    def apply_to_execution(self, pre, published_k):
        # 减法永远允许；加法永不在这里发生
        if pre.defer:
            return published_k
        return min(published_k, pre.k)      # 只缩不伸


def peer_execute(M, published_prefix, pre, deadline):
    k = M.dsn.apply_to_execution(pre, len(published_prefix))
    for a in published_prefix[:k]:
        dispatch(a)
        if M.retraction.alarm(a):        # 实时撤稿告警
            break
    # 预取下一块；评审未完成则安全停，绝不延长
    M.review_queue.submit(pre)
    if not M.review_queue.done(deadline):
        return SAFE_STOP
```

```python
class PreRegistration:
    def __init__(self, log):
        self.log = log                              # append-only, hash-chained
    def register(self, claim, k_star, reviewer_set):
        h = sha256(claim.canonical(), k_star, reviewer_set, time(), nonce())
        self.log.append({'hash': h, 'claim': claim.fingerprint()})
        return h
    def verify(self, claim, h_pre):
        return self.log.contains(h_pre) and h_pre == claim.hash()


class RetractionLedger:
    """依赖 DAG + 撤稿：不是写检讨，是在不可逆点前停下。"""
    def __init__(self, dag, q_ret=0.99):
        self.dag, self.q_ret, self.entries = dag, q_ret, []

    def check_and_retract(self, claim, post_evidence):
        if self._contradicted(claim, post_evidence, self.q_ret):
            descendants = self.dag.descendants(claim.id)
            self.dag.invalidate(descendants | {claim.id})
            self.entries.append(Retraction(claim, post_evidence,
                                           time(), descendants))
            return True
        return False

    def may_dispatch(self, claim):
        return claim.id not in self.dag.invalid and claim.published


class PEEROperator:
    def round(self, M, obs):
        # —— 语义流：预注册必须在执行之前 ——
        claim = M.build_claim(obs)
        h_pre = M.prereg.register(claim, k_star=M.csc_p.estimate(claim),
                                  reviewer_set=M.rev.names())
        pre = M.dsn.preprint(M.state())
        review = M.rev.review(claim, obs.evidence)
        idc = M.rev.independence_certificate(M.ood_calib)
        post = M.fir_p.dependent_logpost(obs.rho, review, idc)
        d = M.fir_p.decide(obs.rho, review, idc, post)

        if d.kind == 'publish':
            k_star = M.csc_p.certified_prefix(claim, idc, M.m, M.alpha_chunk)
            M.publish(claim, h_pre, review, idc, k_star)     # 签字
            exec_result = peer_execute(M, claim.prefix, pre, M.deadline)
        elif d.kind == 'reject':
            M.afa.choose_probe(post, M.phi_hat, M.f_safe)
        elif d.kind == 'independence_failure':
            M.wcv_p.conservative_union(M.balls)              # 不伪装归因
        else:
            M.afa.choose_probe(post, M.phi_hat, M.f_safe)

        # —— 执行后：撤稿检查 + 在线学习（仅语义流）——
        M.retraction.check_and_retract(claim, obs.post)
        M.olp.online_step(obs.evidence, exec_result.loss_grad)
        return build_j_peer(claim, h_pre, review, idc, pre, exec_result)
```

## 4. 推导

**引理 9（相关评审的证据折扣）** 设评审人 i 的对数似然比贡献 s_i 服从均值 θ、方差 σ² 的分布，两两相关 ρ（等相关近似）。则
Var(Σ_i s_i)=Σ_i Var(s_i)+Σ_{i≠j}Cov(s_i,s_j)=Mσ²+M(M−1)ρσ²=Mσ²(1+(M−1)ρ)。
Fisher 信息与方差成反比，故总信息等价于
M_eff=M/(1+(M−1)ρ)
个独立评审。等相关的错误相关矩阵特征值为 λ_1=1+(M−1)ρ 与 λ_2=…=λ_M=1−ρ，参与率 (Σλ)²/Σλ² 恰为 M²/[(1+(M−1)ρ)²+(M−1)(1−ρ)²]，ρ=0 时为 M，ρ=1 时为 1。后验集中速率由 exp(−M_eff·KL/2) 控制。故「全票通过」在 ρ→1 时只是一票；IDC 必须直接估计错误相关，而不能看意见是否一致。∎

**引理 10（可拒答蒸馏的相对安全）** 以非一致性分数 s_i=g_D(x_i) 做 split-conformal，阈值 q_D 取标定集 ⌈(n+1)(1−α)⌉/n 分位数，则对新样本（可交换）P[g_D≤q_D]≥1−α。接受集 A 上学生与教师决策一致的概率 ≥1−α。由于学生被限制为只做减法（停机/缩短），任何学生的错误只会使执行更保守，不会新增危险动作；延长与新动作必须经教师发表。故实时性不引入新的危险方向风险。但一致性是**相对教师**的：教师系统性错误时学生会继承，故 J_peer 记 `relative_to_teacher=True`，绝对安全仍由教师侧 J_vista 承担。∎

**定理 9（PEER 的诚实拒绝）** 在 IDC 与撤稿协议下，考虑任意未知复合故障 H_unknown。
- 若 H_unknown 使评审团共因失效，则错误相关矩阵近奇异、M_eff→1<M_min，IDC 失败，FIR-P 输出 `independence_failure` → 保守联合膨胀或 safe_idle，**不发生定向误归因**。
- 若评审团错误不相关但意见分歧，则 disagreement 或熵越界，输出 `reject` → AFA 探测或 safe_idle。
- 若评审团一致且独立，则判据由依赖性校正后的后验给出，误判率由 M_eff 控制；即便发布，预注册与撤稿协议保证一旦证据反驳，证书在一周期内失效，且执行前缀 k*≤m 使截断发生在不可逆点前。
因此第 65 轮的「自信地错误归因并继续执行」被替换为「可检测的拒绝 / 独立性不足 / 可撤稿主张」三类诚实结果。**但正确性仍受限于评审团信息：PEER 不创造信息，只治理对信息的使用。** ∎

**定理 10（拒答阈值的最优性）** 设覆盖率 c(q)=P[g_D≤q]，选择性风险 R_sel(q) 随 c 单调不增，期望延迟 E[L](q)=c(q)L_S+(1−c(q))L_T 随 c 单调增（L_T>L_S）。在约束 E[L]≤B、P[L>τ_defer]≤δ 下，可行 q 集是一个区间；R_sel 在该区间上单调，故最优 q* 取可行集边界（最大覆盖满足延迟预算）。又因学生只做减法，任何 q 下安全不变式成立，故 q* 的选取只影响效率与选择性风险，不影响物理安全的下界。∎

**命题（撤稿新鲜度与无陈旧证书）** 撤稿沿依赖 DAG 使所有后代失效，且 `may_dispatch` 在派发前检查 `claim.id ∉ invalid`，故不存在使用陈旧证书的派发。结合 k*≤m，撤稿告警在当前前缀内可触发截断，截断点早于不可逆视界；故撤稿是**可行动的**而非仅存档。∎

**命题（无免费信息 / 制度不产生真值）** 若所有评审人与学生共享同一 OOD 失效源（错误相关 1），则 M_eff=1、IDC 必失败，且学生蒸馏间隙在 OOD 上不可由 conformal 覆盖。故 PEER 不能把错误共识变成正确；其唯一保证是**把「不知道」显式化并阻止其被当作「知道」使用**。这划清了本轮贡献的边界。∎

**命题（预注册阻断 HARKing）** 若执行后归因必须引用执行前写入的 h_pre，且日志为 append-only 哈希链，则系统无法在不被记录的情况下事后更换主张。任何 `post_hoc_rationalization=True` 的证书不被 Valid，故不能用于后续派发。∎

## 7. 已知风险

1. **评审人并非真独立**：多数模型共享训练数据与预训练表征，M_eff 会被系统性高估；缓解：用共因 OOD 标定集估计错误相关（而非输出相关）、引入真正异构的物理通道（本体/IMU）、对 M_eff 取置信上界并保守设 M_min。
2. **蒸馏继承教师偏差且更过度自信**：学生保证是相对教师的；缓解：只允许减法、相对性显式写证书、温度/校准、投毒检测（AIC-P）、高 defer 率即回退教师。
3. **「发表或灭亡」的制度压力**：实时预算会诱导降低 M_min 或提高 q_D 来减少拒答，把「publish or perish」变成机器人的「publish and perish」；缓解：把 M_min 与 q_D 设为证书中的不可协商常量，任何放宽必须触发重新认证。
4. **撤稿太晚**：撤稿是事后机制；若故障在块首且 k*>m，仍可能越过不可逆点；缓解：k*≤m 硬约束、预注册、默认保守、对不可逆动作强制同步评审。
5. **预注册被形式化绕过**：系统可能预注册一个极弱主张使其必通过；缓解：主张强度下界、scope 可审计、独立审计者检查 claim 的非平凡性。
6. **IDC 估计的统计误差**：有限 OOD 样本下 C 与 M_eff 有方差；缓解：用 UCB/置信区间、增大共因标定集、对 M_eff 使用悲观估计。
7. **拒答风暴 / 预取饥饿**：分布漂移时学生大量 defer，语义流排队，实时环只能反复 safe_idle；缓解：优先级队列、按风险分级的评审预算、预取深度自适应。
8. **制度开销与可解释性负担**：证书链、预注册、撤稿账本增加复杂度，错误可能藏在审计工具自身；缓解：复现工件、独立重放、最小可信基。

**一句话（本轮最大风险）**：PEER 把「通过评审」制度化为可信徽章，但评审团与蒸馏学生可能共享同一个错误世界（M_eff 被高估 + 学生的分布外过度自信），于是错误共识被加速、被合法化，而撤稿又是事后机制、无法撤销已经发生的不可逆物理伤害——「制度性自信」取代了第 65 轮的单点故障，成为更隐蔽的新单点故障。
