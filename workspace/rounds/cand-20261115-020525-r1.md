# 第 3 轮（灵感循环第 3 轮；本轮灵感：「服务设计」×「流匹配策略」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440）。
> 本轮纪律：**继续在前人基础上改进，而不是推倒重来**——ToolGauge 的六段闭环 6C、MTC/TCV 工具契约、
> MP-Φ 摊销校准、L-Box 共形假设、MODGAUGE 五不变式、严格退化链与 50Hz 硬实时约束全部保留。
> 本轮只做一件事：把 ToolGauge 的「一批彼此独立的盲区修复作业」升级为
> 「**有承诺、可调度、可中断、可补救的修复服务**」，并用**流匹配**替换单峰摊销后验与固定探测序列；
> 同时审计并修复第 2 轮遗留的 10 处缺陷（见 §5）。

## 双灵感映射（不是换皮，而是换组织方式与表示方式）

| 灵感词 | 第 2 轮对象 | 升级为 | 一句话动机 |
|---|---|---|---|
| 服务设计 | 每个盲区一个独立 6C 作业，先到先修，无承诺、无前台/后台之分 | **S-Box 修复服务蓝图 + 分级 SLA + 分诊队列 + 服务补救 + 人机共创许可** | 修复不是「修完就算」的批处理，而是有服务对象、有承诺、有失败恢复、有可见性的服务过程 |
| 流匹配策略 | AP-Cal 的单峰高斯摊销后验 + 离散工具调用序列 | **FM-Cal 条件流后验 + F-Probe 连续探测流策略 + 流时 anytime 交付** | 修复应是一条可随时中断、逐步逼近、能表达多模态的「流」，而不是一次黑箱前向或一条不可中断的脚本 |

**核心命题**：ToolGauge 问「探测证据可不可信」；ServeFlow 问
「**该先修哪个盲区、向谁承诺到什么程度、被中断时交付什么、失败后如何恢复信任**」。
技术路线是「**服务蓝图化 → 风险分诊 → 流匹配后验/探测 → anytime 交付 → 显式补救**」：
服务层决定「做什么、何时做、给谁看」，流层决定「如何连续地做、中断时停在哪」；
数值真值仍由计量层独占，VLA 仍只做被审计的提假设/选工具/写主张三件事。

**不变式保持声明**：
- MODGAUGE 五不变式（契约完整性、组合单调性、反作用通道完备、主张绑定、严格退化链）全部保留；
- 主张绑定获得**可见性扩展**：前台只能读取「回执绑定投影」后的主张（定义 444），未绑定数值永不越过 line_of_visibility；
- **严格退化链延长为显式服务降级**：ServeFlow（服务+流）⇒ 无流（AP-Cal+服务调度）⇒ 无服务（ToolGauge 6C）
  ⇒ LeanGauge ⇒ MODGAUGE；每次降级都进入 RECOVERY 并前台可见，**禁止静默降级**（定义 448）；
- 流匹配是**表示增强**，不是正确性依赖：流不可用时退回 AP-Cal，单盲区正确性仍由 ToolGauge 保证（定义 449、引理 56）。

## 0. 直觉与动机

**灵感 1（服务设计：修复是一个有前台/后台的服务，而不是一批后台作业）**
直觉：ToolGauge 的 6C 把每个盲区当成独立事务，谁先被 D-Box 发现谁先修；没有优先级、没有承诺、
没有「用户此刻看到什么」的设计。现实中的计量修复恰恰是一个服务系统：
- **前台**（操作者/任务层）只应看到「我在探测 / 已修复 / 降级中 / 为什么」；
- **后台**（计量层）才持有回执、后验与契约草稿；
- **支持过程**（仿真器、人工专家、备用传感器）提供容量与兜底；
- **关键时刻（moment of truth）**是盲区第一次影响任务时：此时用户对系统的信任取决于前台解释是否与后台证据一致；
- **服务补救**决定一次失败是被记成「可恢复事件」还是「系统性不可信」；
- **共创**意味着高风险物理探测必须先获得操作者许可，而不是机器人自行决定敲击或强光扫描；
- **需求与容量管理**意味着不能所有盲区同时进入 PROBING，否则探测工具过热、人机交互拥塞、预算瞬间耗尽。
服务设计给的不是 UI 皮肤，而是一套**承诺、优先级、可见性与失败恢复的组织结构**。

**灵感 2（流匹配策略：把「一次前向」换成「一条可中断的连续输运」）**
直觉：第 2 轮 AP-Cal 用单峰高斯近似后验，隐含假设「后验只有一个模式、误差近似椭圆」。
但盲区根因天然多模态：镜面反射 vs 透明玻璃 vs 形变表面可能给出同样残差的不同解释；
单峰高斯会把两个合理解释平均成一个物理上不存在的「中间材质」，且协方差夹紧只能防过度自信，不能恢复模态。
流匹配（conditional flow matching / rectified flow）给的替代方案是：
(a) 学习从物理先验 p_phys 到后验 p*(u|c) 的速度场，用 ODE 输运样本，**不假设高斯、可保留多模态**；
(b) 输运是连续的，因此天然支持**anytime 交付**：走到流时 τ<1 就停，给出带 W₂ 误差界的一部分后验，
    正好匹配「SLA 到期必须交付，但可以交付一个更保守的估计」；
(c) 同一套机制可用于**探测轨迹**：从「安全静止轨迹」流向「最大信息增益轨迹」，
    用控制障碍函数逐点投影回 Pre_t 包络，把「选工具」升级为「沿一条安全连续路径探测」；
(d) 速度场在上下文扰动下的**一致性**（流一致性）是比「连续 3 次残差同向」更早、更细的 OOD 信号，
    可在一次错误提交前触发回退，替代第 2 轮滞后的 P-Quarantine。

**一句话总览**：ToolGauge 让证据可审计；ServeFlow 让「修复这件事」本身成为可承诺、可中断、可补救的服务，
并用流匹配把后验与探测从「点估计 + 脚本」变成「分布 + 连续路径」。

## 1. 形式化定义（增量：定义 432–449）

**定义 432（修复服务项 RSI）** 盲区 s 的服务项
I_s = (κ_s, w_s, c_s, d_s, D_s, vis_s)：
- κ_s ∈ {SAFETY, TASK, COMFORT, DIAGNOSTIC}：服务等级；
- w_s ∈ [0,1]：盲区被触发时对任务/安全的风险权重；
- c_s：期望总代价（探测 + 计算 + 占用的机会成本）；
- d_s：软截止期（SLA 允许的最晚完成时刻）；
- D_s ⊆ S：依赖的其他盲区（例如共享光照或共享材质假设）；
- vis_s ∈ {SILENT, STATUS, EXPLAIN, CONSENT}：前台可见级别。
服务项是调度的最小单位；同一盲区的重试是同一服务项的新 attempt，不重复计入到达率。

**定义 433（服务蓝图 S-Box）** B = (V, E, stage, λ, ev)：
- V = {DETECT, TRIAGE, APPOINT, PROBE, CALIBRATE, VERIFY, COMMIT, AFTERCARE, RECOVERY, STUB}；
- E ⊆ V×V 为带条件的转移边；stage: V→{FRONT, BACK, SUPPORT}；
- 三条线：line_of_interaction（人–机器人）、line_of_visibility（前台–后台）、
  line_of_internal_interaction（后台–支持过程）；
- ev: E → 2^Artifact 记录每一步的证据（有效回执、修复证书、账本项、许可令牌）。
前台的任何数值主张必须来自 ev 中的有效回执并满足定义 444；后台可以持有未验证假设，
但不得越过 line_of_visibility。蓝图使「谁在何时知道什么」成为可审计对象，而不是实现细节。

**定义 434（修复 SLA 契约）** SLO_s = (τ_s, β_s, ε_s, ρ_s)：
完成时延上限、违约概率上限、契约参数误差上限、补救时延上限。
服务等级 κ 对应预注册模板；系统级 SLO 按等级取加权最坏值。
SLA 是**可审计承诺**而非尽力而为：违约必须进入 RECOVERY 并记账（定义 443），
不允许「后台失败但前台仍宣称已修复」。

**定义 435（分诊指数与调度）** 时刻 t 的服务指数
I_s(t) = w_s · Δ_s(t) / (c_s + λ_d · max(0, t + d_s − now) + λ_r · R_s(t))，
其中 Δ_s(t) 为预计边际风险降低，R_s(t) 为已投入但未兑现的风险，λ_d, λ_r 为预注册权重。
调度器在容量约束下按 I_s 降序服务，同级用 EDF；高等级可抢占低等级，
但**抢占点只允许在流时检查点**（定义 439），以保证中断时仍有一个自洽的部分后验可交付。

**定义 436（服务补救 SR）** 失败或违约时的补救脚本
R_s = (ACK, EXPLAIN, CONTAIN, COMPENSATE, RESTORE, FOLLOWUP)：
- ACK：前台显式声明降级（stub/RED），不伪装成功；
- EXPLAIN：给出回执绑定的原因（定义 444）；
- CONTAIN：把受影响服务项隔离到 cohort（定义 442）；
- COMPENSATE：切换到安全策略、备用传感器或人工接管；
- RESTORE：从上一已提交契约原子恢复；
- FOLLOWUP：进入 AFTERCARE，记录账本并安排重验。
补救质量 q_rec ∈ [0,1] 由六个子项是否按时完成定义；q_rec 进入账本并影响后续服务等级。

**定义 437（人机共创许可）** 高风险工具（tap.percuss、高功率 illum.sweep、任何接触式探测）
需要许可令牌 c = (tool, args_envelope, operator_id, expiry, nonce)：
状态机 C_s: IDLE → REQUESTED → GRANTED → (EXPIRED | REVOKED)。
TCV 在 Pre 检查之外验证 c 与 (tool,args) 匹配且未过期；无令牌 ⇒ 该调用 void，零物理副作用。
许可不是一次性全局开关，而是绑定到具体工具与参数包络；参数越界即失效。

**定义 438（流匹配后验 FM-Cal）** 契约参数 u ∈ ℝ^{d_u}，上下文 c = (H_s, receipts)。
源分布 p_0 = p_phys（物理先验，可为 GP 或仿真先验），目标 p_1 = p*(u|c)。
学习速度场 v_θ(t,u|c)：
L_CFM(θ) = E_{t∼U[0,1], c, u_0∼p_0, u_1∼p_1} ‖v_θ(t,u_t|c) − (u_1 − u_0)‖²，
其中 u_t = (1−t)u_0 + t u_1。推理解 ODE du/dt = v_θ(t,u|c)，u(0)∼p_0，
得 q_1 = (Φ_1)_# p_0；用 K 条轨迹表示后验，不假设高斯。
训练目标 p_1 由仿真后验、校准集或离线 MCMC 提供（flow matching posterior estimation 风格），
物理先验同时作为源分布与支撑锚。
**高斯退化**：若 p_0, p_1 为高斯且插值线性，最优速度场为仿射，q_1 即 GP 后验；
令 K=1、v_θ 线性、τ=1，则 ServeFlow 的校准层逐值等于 AP-Cal（定义 449）。

**定义 439（流时与 anytime 后验）** 定义 q_τ = (Φ_τ)_# p_0，τ∈[0,1]。
流时 τ 是**可承诺的服务进度**：前台可显示「已走完 τ 比例」；
到期若无法完成 τ=1，就交付 q_τ 并标注剩余传输距离（引理 52）。
检查点 τ_j = j/J 是唯一允许的抢占、预算中断与人工审批点，
保证每次中断都停在一个连续、可解释的分布上，而不是半次前向的残片。

**定义 440（流一致性 OOD 分数）**
D(c) = E_{t∼U, u∼q_t}‖v_θ(t,u|c) − v_ref(t,u)‖² + λ_E · ED(q_1, q_ref(c))，
其中 v_ref 为训练分布上的冻结参考流（指数滑动平均），ED 为 energy distance。
阈值 τ_D 由校准集分位数给出；D(c) > τ_D ⇒ 判定上下文 OOD：
暂停 FM-Cal，退回第 1 轮 BP-Cal，并要求额外独立回执。
该分数是「预训练→部署」偏移的在线估计器，替代第 2 轮滞后 3 次的 P-Quarantine。

**定义 441（流探测策略 F-Probe）** 对连续参数工具 t，探测轨迹 a(·):[0,1]→A_t。
源 p_0 = 安全静止轨迹（在 Pre_t 包络内、零净力/最低能量），
目标 p_1 = 预算内最大化期望信息增益的轨迹（离线用贝叶斯实验设计生成）。
学习 v_θ^probe(τ,a|H_s)；运行时采样 K 条轨迹，逐点投影 Π_{Pre_t}（CBF 约束 a′∈Tan_{Pre_t}），
TCV 与许可均通过后才执行。F-Probe 把「选哪个工具」扩展为「沿哪条连续路径安全探测」；
离散工具序列是其分段常值特例。

**定义 442（服务案例隔离与污染图）** 每个服务项在一次 attempt 内拥有私有工作集 W_s
（回执、流样本、校准草稿）。共享对象只有：(i) 只读物理先验 p_phys；
(ii) epoch 快照中的 R/EC；(iii) 已提交契约。污染图 G_c 的边仅当两个服务项共享**可变**对象时存在；
cohort = G_c 的连通分量，cohort 内串行提交、cohort 间并行。
若只共享不可变 p_phys，则 G_c 无跨 cohort 边，后验在给定上下文下因子分解（引理 54）。

**定义 443（风险账本）** L 记录每个服务项的
(predicted Δ, realized Δ, residual, cost, SLA status, recovery quality)。
账本用于：(a) 校准分诊指数 Δ_s；(b) 按 cohort 聚合检测系统性偏差；
(c) 事故复盘与审计。第 2 轮 P-Quarantine 的「连续同向残差」规则被降级为账本上的一个告警特征，
不再是唯一断路器。

**定义 444（前台主张投影）** π_front(EC) 删除所有不满足第 2 轮定义 423 的 claims
（无有效回执引用或引用无效），并删除未通过 SNC 的语义标签；投影是纯函数，不改变任何数值字段。
前台 STATUS/EXPLAIN 只能读取 π_front(EC)、SLA 状态与账本摘要。
**可见性不变式**：任何前台可见的数值都必须能追溯到 ev 中的有效回执。

**定义 445（服务状态机）** DETECTED → TRIAGED → APPOINTED → PROBING → CALIBRATING →
VERIFYING → COMMITTED → AFTERCARE；异常转移到 RECOVERY 或 STUB → RED。
PROBING 继承第 2 轮定义 430（显式态、幅值/力矩限制、全日志、人可见）；
新增 APPOINTED（已分配预算与许可）与 AFTERCARE（提交后监测与重验）。
状态转移必须原子且可重放；非法转移直接进入 RECOVERY。

**定义 446（容量控制器）** 到达率 λ_arr、单服务项平均服务时间 E[T_s]、并发上限 C_max。
控制器用 Little 定律估计积压 L_q = λ_arr · W_q，动态设定准入与并发：
当 P99 修复时延将超过 SLA，或物理探测队列将超过安全上限时，
拒绝新服务项进入 PROBING（保持 DETECTED/TRIAGED，继续被动观测），
避免「修复风暴」造成工具过热、人机交互拥塞或预算瞬间耗尽。

**定义 447（流匹配先验更新与合并门）** 基础速度场 v_base 在一个服务 epoch 内冻结；
每个 cohort 只能训练低秩速度适配器 δv_φ（rank r≪d_u）。
新版本 v′ = v_base + δv_φ 合并前必须在历史回放集 ℋ 上满足：
(a) 风险不劣化；(b) 已提交字段的置信下界不下调；(c) 流一致性 D(c) 不升高超过 δ_D。
否则拒绝合并，私有适配器只保留到该 cohort 结束。
预训练先验因此像「灰度发布」一样可回滚，而不是一次污染全局。

**定义 448（服务退化链）** ServeFlow 的服务/流设施失效时按显式顺序降级：
S4 ServeFlow（服务+流）⇒ S3 无流（AP-Cal + 服务调度）⇒ S2 无服务（ToolGauge 6C）
⇒ S1 LeanGauge ⇒ S0 MODGAUGE。
流不可用（训练/推理失败、OOD 超阈）⇒ S3；调度/许可设施不可用 ⇒ S2；
VLA/工具契约不可用 ⇒ S1/S0。每次降级必须进入 RECOVERY、前台可见并记账；**不得静默降级**。

**定义 449（等价性）** 令服务层退化为单等级、FCFS、无补救、无许可，
流层退化为 K=1、线性速度场、τ=1，则 ServeFlow 与 ToolGauge 在数值路径上逐字段等价。
该等价性是 E455 回归实验与「流是增强项而非依赖项」论证的基础。

## 2. 关键算法骨架

```python
# IP-321 S-Box：服务蓝图、分诊与容量
@dataclass
class ServiceItem:
    sid: str; kappa: str; w: float; cost: float; deadline: float
    deps: set; visibility: str; state: str = "DETECTED"
    attempts: int = 0; private: dict = field(default_factory=dict)

class SBox:
    def triage(self, items, now, capacity):
        for it in items:
            if it.state == "DETECTED":
                it.index = self.index(it, now)          # 定义 435
        ready = sorted((x for x in items if x.state in ("DETECTED", "TRIAGED")),
                       key=lambda x: (x.index, x.deadline), reverse=True)
        return self.admit(ready, now, capacity)         # 定义 446：Little 定律 + 硬顶

    def index(self, it, now):
        slack = max(0.0, it.deadline - now)
        return it.w * self.pred_delta(it) / (
            it.cost + LAM_D * slack + LAM_R * self.unredeemed_risk(it))

# IP-322 FM-Cal：条件流后验 + 流时 + OOD
class FMCal:
    def posterior(self, c, tau=1.0, K=8, J=10):
        u0 = sample(self.p_phys, K)                    # 源 = 物理先验
        for j in range(round(J * tau)):                # 只在检查点允许中断
            u0 = self.step(u0, j / J, c)               # ODE 一步（RK4/Heun）
        q = Mixture(u0)                               # 非参数后验
        return q, self.residual_bound(tau)            # 定义 439、引理 52

    def ood(self, c, q):
        vc = self.velocity_disagreement(c)            # 与冻结参考流比较
        ed = energy_distance(q.samples, self.ref_samples(c))
        return vc + LAM_E * ed                        # 定义 440

# IP-323 F-Probe：连续探测轨迹 + CBF 安全投影
class FProbe:
    def plan(self, H_s, tool, budget, K=4):
        a0 = sample(self.safe_source(tool), K)        # 安全静止轨迹
        for j in range(self.J):
            a0 = self.step(a0, j / self.J, H_s)       # 流向高信息增益
            a0 = cbf_project(a0, tool.pre_envelope)   # 逐点投影回 Pre_t
        return a0, [tool.expected_gain(a) for a in a0]

# IP-324 服务补救 + 共创许可
class Recovery:
    def on_fail(self, it, why, receipts):

        explain = bind_claims_to_receipts(why, receipts)
        contain = isolate_cohort(it)
        restore = ec_store.rollback_to_last_commit(it.sid)
        follow = ledger.schedule_recheck(it.sid)
        return q_rec(ack, explain, contain, restore, follow)   # 定义 436

def consent_ok(token, tool, args):
    return token is not None and token.tool == tool.name \
       and within(token.args_envelope, args) and token.expiry > now()

# IP-325 ServeFlow 服务闭环（在 ToolGauge 6C 外包一层服务语义）
def serveflow_case(M, it):
    it.state = "TRIAGED"
    if not M.sbox.admit_one(it):                       # 容量/预算不足
        return defer(it)                              # 保持被动观测，不探测
    it.state = "APPOINTED"; tok = M.consent.obtain(it)
    H = M.lbox.hypothesize(it.sid, M.snapshot.R[it.sid])
    prog = M.tbox.select(H, M.tools, M.tcv, M.budget_left(it.sid))
    it.state = "PROBING"                              # 定义 430 + 437
    receipts = M.tcv.execute(prog, M.env, consent=tok)
    if len(receipts) < n_min(it.sid):
        return M.recovery.on_fail(it, "insufficient", receipts)
    it.state = "CALIBRATING"
    q, bound = M.fmcal.posterior(featurize_ctx(receipts, H, it.sid))
    if M.fmcal.ood(featurize_ctx(receipts, H, it.sid), q) > TAU_D:
        q, bound = M.apcal.posterior(receipts, H, it.sid)   # 退化到 S3
        M.ledger.flag_ood(it.sid)
    it.state = "VERIFYING"
    if not M.fmcal.cross_validate(q, M.witness(it.sid)):     # 独立见证回执
        return M.recovery.on_fail(it, "cross_failed", receipts)
    it.state = "COMMITTING"
    if not M.commit_gate.check(q, it, receipts):
        return M.recovery.on_fail(it, "invariant", receipts)
    M.mreg.hot_replace(M.dpe, q.to_ec(M.dpe, it.sid))
    M.dbox.update_from_posterior(it.sid, q, bound)
    it.state = "AFTERCARE"; M.ledger.record(it, q, receipts)
    return True

# IP-326 主闭环：50Hz 路径不动，服务调度全异步
def ServeFlow_round(M, obs, audio, tac, depth, det):
    for s in M.dbox.detect_blind_spot():
        M.sbox.submit(ServiceItem.from_blindspot(s))       # 只登记，不立即探测
    for it in M.sbox.triage(M.sbox.pending(), M.clock.now(), M.capacity()):
        if it.sid not in M.inflight:
            M.inflight.add(it.sid)
            submit_async(serveflow_case, M, it)             # 偏离 50Hz 路径
    if M.fmcal.ood_global() > TAU_D:
        M.fmcal.pause(); M.degrade("S3")                    # 显式服务降级
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 3. 推导

**引理 51（FM-Cal 正确性与高斯退化）** 在 CFM 目标达到最优且 p_0 有全支撑时，
q_1 = p_1；若 p_0, p_1 为高斯且插值线性，最优速度场为仿射，q_1 等于 GP/AP-Cal 后验。
证明思路：CFM 的最优解为条件期望 v*(t,u) = E[u_1 − u_0 | u_t = u]，
ODE 的 pushforward 即目标分布；高斯情形下条件期望是 u 的仿射函数。
意义：ServeFlow 不替换第 2 轮校准，而是把它变成流的一个特例，退化链因此闭合。

**引理 52（anytime 流时误差界）** 设 V_max = max_{t,u,c}‖v_θ(t,u|c)‖，
则 W₂(q_τ, q_1) ≤ V_max · (1−τ)。
若流近似直线（rectified），进一步有 W₂(q_τ, q_1) ≤ (1−τ) · E‖u_1 − u_0‖，
仿射流下等号成立。因此给定误差预算 ε，取 τ ≥ 1 − ε/V_max 即可在任意截止期
交付带误差保证的部分后验；流时检查点不改变已交付结果。
意义：SLA 到期时不必「全有或全无」，可交付一个更保守但仍有保证的契约。

**引理 53（多模态保持与共形覆盖）** q_1 是 p_0 在连续 ODE 下的 pushforward，
若 p_1 有 K 个分离模态且 ODE 不合并轨迹，则 q_1 保持 K 个模态（单峰高斯 AP-Cal 不能）。
对 q_1 的 K 个样本做 split-conformal，在可交换性下 P(u* ∈ C_α) ≥ 1−α；
漂移下按第 2 轮引理 48 扣减 2η′。
流本身不保证覆盖，覆盖由共形层保证——表示与校准职责分离。

**引理 54（服务案例隔离的污染界）** 在定义 442 的隔离下，若两个服务项只共享
不可变 p_phys 与只读 epoch 快照，则对任意上下文 c_s, c_s′，
p(u_s, u_s′ | c_s, c_s′) = p(u_s | c_s) · p(u_s′ | c_s′)；
一个服务项的先验错误对另一个的后验影响为 0。
若共享可变适配器，则影响 ≤ W₂(q_s, q_s′) ≤ δ_share，且 cohort 隔离把 δ_share 限制在 cohort 内。
证明思路：条件独立（d-分离）+ ODE 解对初始条件的连续性。
意义：第 2 轮「跨盲区强相关污染」在服务案例隔离下结构性消失，除非 cohort 定义过粗。

**引理 55（分诊近似最优性）** 若风险降低 Δ(S) 是单调子模、代价可加，
则 cost-benefit greedy（按 I_s 降序）在背包预算下至少达到 (1−1/e)/2 的近似；
在可分流体预算下，按边际收益/代价排序是最优的；
在截止期可行条件下，EDF + 指数排序的可行性由利用率 ≤ 1 保证。
意义：分诊不是拍脑袋的启发式，有可审计的竞争比；E442 验证实际增益。

**引理 56（时序、预算与退化保持）** 服务调度、FM-Cal 采样、F-Probe 规划全部位于
50Hz 计量路径之外；50Hz 内联仅增加 O(1) 状态查询与主张投影（< 0.2ms）。
修复时延由流时检查点与 SLA 选择控制；预算耗尽、许可失败、OOD 超阈均触发
显式 RECOVERY 与定义 448 的降级。五不变式与硬实时（第 2 轮引理 45）保持；
退化到 S2 时数值路径逐字段等于 ToolGauge（定义 449）。

**推论 56.1** 由于 RECOVERY 是显式状态，系统在任意时刻都有一个可审计的「当前服务承诺」；
不会出现第 2 轮「后台悄悄失败、前台仍宣称已修复」的状态。

## 6. 本轮最大风险（一句话）

**一句话**：流匹配后验的可靠性完全继承其训练目标分布——若仿真后验族遗漏真实模态或耦合错配，
流会以**多模态的自信**输出系统性偏移的契约，而服务蓝图的前台解释与补救话术会让这种错误
显得更可信、更难被用户质疑；也就是说，**服务化与可解释性可能反而掩盖先验–现实失配**。

**次级风险与缓解**：
1. **训练目标遗漏模态** → E443 多模态压力测试 + 共形覆盖 + OOD 回退 BP-Cal；
2. **流积分误差累积** → Heun/RK4 + 流时误差界 + 最大步数硬顶（引理 52）；
3. **服务分诊误判 w_s/Δ_s** → 账本在线校准 + 保守先验 + E442 消融；
4. **许可流程造成修复延迟** → 低风险工具预授权 + 高风险仅 CONSENT 级 + E449 时延测试；
5. **cohort 定义过粗导致隔离失效** → 写集/先验邻域自动建图 + E447 注入实验；
6. **前台解释过度简化** → π_front 纯投影 + 每条数值可追溯 + E454 人工审计；
7. **流策略在真实物理包络外采样** → CBF 逐点投影 + TCV 前置 + 零副作用收尾（定义 441）；
8. **服务化开销拖慢主路径** → 调度/流/补救全异步，50Hz 内联仅 O(1)（引理 56）。

**定义 436（补救）** 六步脚本；q_rec 量化补救质量，进入账本并影响后续服务等级。
**定义 437（共创许可）** 高风险工具必须持有绑定 (tool,args_envelope,operator,expiry) 的令牌；无令牌调用零副作用。
**定义 438（FM-Cal）** L_CFM = E‖v_θ(t,u_t|c) − (u_1−u_0)‖²，u_t=(1−t)u_0+t u_1；ODE 输运得 q_1；高斯线性情形退化为 AP-Cal。
**定义 439（流时）** q_τ 是任意截止期可交付的部分后验；τ_j 是唯一抢占/审批点；误差界 W₂(q_τ,q_1) ≤ V_max(1−τ)。
**定义 440（流一致性 OOD）** D(c)=速度场与冻结参考流的分歧 + energy distance；超阈退回 BP-Cal 并要求独立回执。
**定义 441（F-Probe）** 从 Pre_t 内的安全源流向高信息增益目标，逐点 CBF 投影；离散工具序列是分段常值特例。
**定义 442（案例隔离）** 每 attempt 私有工作集；只共享只读 p_phys 与 epoch 快照；cohort 内串行、cohort 间并行。
**定义 443（账本）** 记录预测/实际风险降低、残差、代价、SLA、补救质量；用于分诊校准、cohort 偏差检测与审计。
**定义 444（前台投影）** π_front 删除未绑定有效回执的 claims 与未过 SNC 的标签；纯投影，不改数值。
**定义 445（状态机）** PROBING 显式态 + APPOINTED（预算/许可已分配）+ AFTERCARE（提交后监测）；非法转移进 RECOVERY。
**定义 446（容量）** 用 Little 定律估计积压；SLA 或物理队列将超限时拒绝新 PROBING，保持被动观测。
**定义 447（先验更新）** v_base 一 epoch 冻结；cohort 只训低秩 δv；合并门要求风险不劣化、置信底不下调、D(c) 不升高。
**定义 448（退化）** S4→S3→S2→S1→S0，每次显式、可见、记账；不得静默降级。
**定义 449（等价）** 服务层退化为单等级/FCFS/无补救/无许可，流层退化为 K=1/线性/τ=1 ⇒ ServeFlow ≡ ToolGauge。

## 3. 关键算法骨架

```python
# IP-321 S-Box：分诊 + 容量准入
class SBox:
    def triage(self, items, now, capacity):
        for it in items:
            if it.state == "DETECTED":
                it.index = it.w * self.pred_delta(it) / (
                    it.cost + LAM_D * max(0, it.deadline - now)
                    + LAM_R * self.unredeemed_risk(it))
        ready = sorted((x for x in items if x.state in ("DETECTED", "TRIAGED")),
                       key=lambda x: (x.index, x.deadline), reverse=True)
        return self.admit(ready, now, capacity)      # Little 定律 + C_max + 硬顶

# IP-322 FM-Cal：条件流后验 + anytime + OOD
class FMCal:
    def posterior(self, c, tau=1.0, K=8, J=10):
        u = sample(self.p_phys, K)                   # 源 = 物理先验
        for j in range(round(J * tau)):
            u = self.step(u, j / J, c)               # Heun/RK4 一步
        return Mixture(u), self.residual_bound(tau)  # 引理 52
    def ood(self, c, q):
        return self.velocity_disagreement(c) + LAM_E * energy_distance(
            q.samples, self.ref_samples(c))          # 定义 440

# IP-323 F-Probe：连续轨迹 + CBF 安全投影
class FProbe:
    def plan(self, H_s, tool, budget, K=4):
        a = sample(self.safe_source(tool), K)
        for j in range(self.J):
            a = self.step(a, j / self.J, H_s)        # 流向高信息增益
            a = cbf_project(a, tool.pre_envelope)    # 投影回 Pre_t
        return a, [tool.expected_gain(x) for x in a]

# IP-324 补救 + 许可
def recovery(it, why, receipts):
    ack      = front_stage.degrade(it.sid, why)      # 显式降级
    explain  = bind_claims_to_receipts(why, receipts)
    contain  = isolate_cohort(it)                    # 定义 442
    restore  = ec_store.rollback_to_last_commit(it.sid)
    follow   = ledger.schedule_recheck(it.sid)
    return q_rec(ack, explain, contain, restore, follow)

def consent_ok(tok, tool, args):
    return tok is not None and tok.tool == tool.name \
       and within(tok.args_envelope, args) and tok.expiry > now()

# IP-325 ServeFlow 服务闭环
def serveflow_case(M, it):
    it.state = "TRIAGED"
    if not M.sbox.admit_one(it): return defer(it)    # 容量不足：保持被动观测
    it.state = "APPOINTED"; tok = M.consent.obtain(it)
    H = M.lbox.hypothesize(it.sid, M.snapshot.R[it.sid])
    prog = M.tbox.select(H, M.tools, M.tcv, M.budget_left(it.sid))
    it.state = "PROBING"
    receipts = M.tcv.execute(prog, M.env, consent=tok)
    if len(receipts) < n_min(it.sid):
        return recovery(it, "insufficient", receipts)
    it.state = "CALIBRATING"
    q, bound = M.fmcal.posterior(featurize_ctx(receipts, H, it.sid))
    if M.fmcal.ood(featurize_ctx(receipts, H, it.sid), q) > TAU_D:
        q, bound = M.apcal.posterior(receipts, H, it.sid)  # S3
        M.ledger.flag_ood(it.sid)
    it.state = "VERIFYING"
    if not M.fmcal.cross_validate(q, M.witness(it.sid)):
        return recovery(it, "cross_failed", receipts)
    it.state = "COMMITTING"
    if not M.commit_gate.check(q, it, receipts):
        return recovery(it, "invariant", receipts)
    M.mreg.hot_replace(M.dpe, q.to_ec(M.dpe, it.sid))
    M.dbox.update_from_posterior(it.sid, q, bound)
    it.state = "AFTERCARE"; M.ledger.record(it, q, receipts)
    return True

# IP-326 主闭环：50Hz 路径不动，服务全异步
def ServeFlow_round(M, obs, audio, tac, depth, det):
    for s in M.dbox.detect_blind_spot():
        M.sbox.submit(ServiceItem.from_blindspot(s))
    for it in M.sbox.triage(M.sbox.pending(), M.clock.now(), M.capacity()):
        if it.sid not in M.inflight:
            M.inflight.add(it.sid)
            submit_async(serveflow_case, M, it)
    if M.fmcal.ood_global() > TAU_D:
        M.fmcal.pause(); M.degrade("S3")             # 显式服务降级
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 4. 推导

**引理 51（FM-Cal 正确性与高斯退化）** CFM 最优速度 v*(t,u)=E[u_1−u_0|u_t=u]，
其 ODE pushforward 即 p_1；高斯线性插值下 v* 仿射，q_1 等于 GP/AP-Cal 后验。
**引理 52（anytime 误差界）** W₂(q_τ,q_1) ≤ V_max(1−τ)；直线流下 ≤ (1−τ)E‖u_1−u_0‖。
给定 ε 取 τ ≥ 1−ε/V_max 即可按时交付带保证的保守后验。
**引理 53（多模态与覆盖）** 流 pushforward 可保留 K 个分离模态；覆盖由 split-conformal 保证
P(u*∈C_α) ≥ 1−α（漂移下 ≥ 1−α−2η′，引理 48）。表示与校准职责分离。
**引理 54（案例隔离污染界）** 只共享不可变 p_phys 与只读快照时，
p(u_s,u_s′|c_s,c_s′)=p(u_s|c_s)p(u_s′|c_s′)，跨案例影响为 0；
共享可变适配器时影响 ≤ W₂ ≤ δ_share，且被 cohort 边界限制。
**引理 55（分诊近似最优）** Δ 单调子模、代价可加时，cost-benefit greedy ≥ (1−1/e)/2；
可分流体预算下指数排序最优；截止期可行性由 EDF + 利用率 ≤ 1 保证。
**引理 56（时序与退化）** 服务/流/F-Probe 全异步于 50Hz 外，内联仅 O(1)<0.2ms；
修复时延由流时检查点控制；预算/许可/OOD 触发显式 RECOVERY 与 S4→S0 降级；五不变式保持。

## 8. 本轮最大风险

**一句话**：流匹配后验的可靠性完全继承其训练目标分布——若仿真后验族遗漏真实模态或耦合错配，
流会以**多模态的自信**输出系统性偏移的契约，而服务蓝图的前台解释与补救话术会让这种错误
显得更可信、更难被用户质疑；即**服务化与可解释性可能反而掩盖先验–现实失配**。
以 E443/E445/E447/E452 证伪，cohort 隔离（442）、流一致性 OOD（440）、账本（443）与
显式降级（448）四重兜底；但四者都无法替代一个覆盖真实模态的训练目标——这是本轮无法在系统内部
完全消除、只能测量与隔离的残余风险。
