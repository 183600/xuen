# 第 43 轮（新循环第 3 轮） · Demo-Anchored World Model：用演示数据给世界模型上「共形保险」，把证书飞轮从「仿真偏差」推向「三源可信托证」（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR）。第 42 轮自陈最大风险是「仿真偏差累积」与「检索幻觉」：Sim 覆盖不全则 W_1 低估，RAG 检索到不相似模板则静默失效。本轮灵感词「演示数据」「世界模型」正好从两端补上：**演示数据**是真实世界分布的稀疏但可信锚点，把「仿真说了算」改为「实机见证说了算」；**世界模型**是可微、廉价、可反事实 rollout 的证书预言机，把仿真风洞升级为「梦境风洞」。但世界模型会幻觉、演示数据有成功者偏差，二者都不能盲信——因此引入**分组共形校准 + 信任域 + 三源下界融合**，把「幻觉」变成「带有限样本覆盖保证的保守预言」，让证书从「要么仿真、要么实机」的二选一，进化为 Sim（宽而偏）× Demo（真而稀）× WM（密而幻）三源互补的可信飞轮。

## 0. 直觉与动机

**灵感 1（演示数据 → 不只是模仿，更是证书的「阳性见证」）**：第 42 轮的实机信息只以「少量标定轨迹估 W_1」的形式进入系统，用得太浅。演示数据的直觉是：每一条遥操作/示教轨迹本身就是一串**证书见证**——它告诉我们在这些状态、这些接触模式、这些动作下，系统真实地存活并保持了多大安全裕度。于是演示不再只喂给策略做模仿学习，而是被抽成 `(x_t, m_t, contact_mode_t)` 的见证集，直接给出「演示支撑域内的局部 Lipschitz 下界」；它同时是校准世界模型的**真值锚**、是 CAR 守卫的**反例种子库**、也是课程引擎的**相位样板**。一句话：演示数据把「证书从仿真来」校正为「证书从实机见证来」。

**灵感 2（世界模型 → 证书的「梦境风洞」）**：第 42 轮的 Isaac Sim 是「宽但偏、贵但慢」的风洞。世界模型的直觉是再建一个「密但幻、便宜且可微」的**梦境风洞**：在隐空间里做反事实 rollout，对证书边际做梯度下降式对抗搜索，几秒内生成成千上万个「逼近守卫面」的梦境场景。它的价值不在替代仿真，而在于做**反事实提案器**——把仿真预算从「盲采样」集中到「最可能击穿证书」的方向。关键约束：梦境只是提案，不是证据；任何梦境反例必须过「仿真多 seed 复现 + 实机边际差 < τ」的验证闸门才能进 KB，否则进「幻觉账本」用于再训练。

**灵感 3（共形校准 → 给幻觉戴一顶「诚实的帽子」）**：世界模型的失效模式是**乐观幻觉**——它预测的边际高于真实边际。共形预测的直觉是：不要求世界模型准，只要求它的**乐观误差**在留出演示上可度量；取该误差的 \(1-\alpha\) 分位数 \(q\)，则 `m_lo = m_hat - q` 是一个有有限样本覆盖保证的下界。再按接触 regime 分组标定，避免「平坦地面上的准」被错误地推广到「斜面接触」。分布偏移时用加权共形，把实机测试分布相对演示校准分布的重要性权重纳入分位数。

**耦合升级（三源下界取 max，而不是 min 堆叠）**：第 42 轮把 sim 证据当唯一来源，只能靠放大阈值来保安全，于是过度保守、可用性崩塌。本轮的洞察是：Sim、Demo、WM 三源各自都能给出一个**保守下界**；若每个下界都以高概率不高于真实边际，则它们的**逐点最大值仍是合法下界**，而且比任一单源更紧。于是安全不再靠「取最小」，而是靠「各自校准后取最大」——用 Bonferroni 把总风险预算 \(\alpha\) 分摊到三源，既保 soundness，又把第 42 轮丢掉的可用性赚回来。

## 1. 形式化定义（增量：定义 38–43）

**定义 38（演示数据与证书见证）**：演示集 \(D_{demo}=\{(o_{1:T_i}, a_{1:T_i}, c_{1:T_i}, m^{real}_{1:T_i})\}_{i=1}^N\)，其中 \(m_t^{real}\) 由 IP-49 几何证书在**区间算术**下给出的下界（禁止用世界模型给校准集打标，避免循环标定）。见证集 \(W=\{(x_t, m_t, c_t)\}\)。证据密度 \(\rho_{demo}(x)=1/(\mathrm{kNN}_k(x)+\varepsilon)\)，演示支撑域 \(S_{demo}(\kappa)=\{x:\rho_{demo}(x)\ge\kappa\}\)。**局部演示下界**：
\[
m_{lo}^{demo}(x)=\max_{(x_i,m_i,c_i)\in \mathrm{kNN}_k(x)}\big[m_i-L_m\|x-x_i\|\big],
\]
若边际 \(m\) 满足 \(L_m\)-Lipschitz，则在 \(S_{demo}\) 上恒有 \(m_{lo}^{demo}\le m^{real}\)（确定性 sound）。

**定义 39（演示锚定世界模型）**：隐空间模型 \(z_t=e_\theta(o_t)\)，\(z_{t+1}=f_\phi(z_t,a_t)\)，\(\hat o_t=d_\psi(z_t)\)，边际头 \(\hat m_t=g_\omega(z_t)\)。训练集按 Demo:Sim = 7:3 混合，损失
\[
L_{WM}=L_{rec}+L_{dyn}+L_{margin}+\lambda_{opt}\mathbb E[\mathrm{ReLU}(\hat m-m)^2]+\lambda_{con}\mathbb E[\mathrm{ReLU}(m-\hat m)^2],
\]
且 \(\lambda_{opt}\gg\lambda_{con}\)：**对乐观误差重罚**，让模型天然偏保守。用 \(K\) 个集成成员给认知不确定度 \(U(x)=\mathrm{std}_k(\hat m_k)\)；\(h\) 步 rollout 误差记为 \(\varepsilon_{WM}(h)\)，只允许 \(h\le H_{max}\)。

**定义 40（分组共形证书预言机）**：对每个接触 regime \(c\) 与 horizon \(h\)，在留出演示上计算单边非一致性分数 \(s_i=\max_t(\hat m_{t+h}-m^{real}_{t+h})\)，取
\[
q_{h,c}=\mathrm{Quantile}_{1-\alpha_c}\big(\{s_i\}\big),\qquad
m_{lo}^{WM}(x)=\hat m(x)-q_{h,c}(x).
\]
在 regime 内可交换假设下 \(P(m^{real}\ge m_{lo}^{WM})\ge 1-\alpha_c\)。分布偏移时改用加权共形：权重 \(w(x)=dP_{test}/dP_{cal}\)，分位数改为加权分位数。

**定义 41（信任域与三源下界融合）**：\(T_{WM}=\{x: U(x)\le u_{max}(c)\ \wedge\ \rho_{demo}(x)\ge\kappa\ \wedge\ h\le H_{max}\}\)。三源 \(s\in\{sim,demo,WM\}\) 各有 soundness 事件 \(E_s\)，用 Bonferroni 分 \(\alpha_s=\alpha/3\)。融合下界
\[
m_{lo}^{\oplus}(x)=\max_{s:\ x\in T_s} m_{lo}^{s}(x),
\]
若 \(x\notin\bigcup_s T_s\) 则回退 SafeStop/Degraded。**命题**：\(P(\bigcap_s E_s)\ge 1-\sum_s\alpha_s\)；在 \(\bigcap_s E_s\) 下 \(m_{lo}^{\oplus}\le m^{real}\)，且逐点 \(m_{lo}^{\oplus}\ge m_{lo}^{s}\)，故融合只会更紧、不会更松。

**定义 42（反事实梦境与验证闸门）**：梦境反例集
\[
\Xi_{dream}=\Big\{x+\delta^*:\ \delta^*=\arg\min_{\|\delta\|\le\varepsilon,\ x+\delta\in S_{demo}}\min_{h\le H_{max}} m_{lo}^{WM}(\mathrm{rollout}(x+\delta;h))\Big\}.
\]
梦境只是**提案**。验证闸门：对候选 \(x\) 用 SCV 跑 \(\ge 5\) 个 seed，若仿真违例率 \(>0.5\) 且与高保真仿真/实机边际差 \(<\tau\)，才允许写入 KB；未通过的进入「幻觉账本」\(\mathcal H\)，仅用于再训练 WM，不参与证书合成。

**定义 43（演示-世界模型证书飞轮更新）**：触发条件 = 新演示到达 \(\vee\) 偏移统计 \(S_t>\tau_{drift}\) \(\vee\) 覆盖率审计失败。更新顺序：增量抽取见证 \(\rightarrow\) 重训/微调 WM \(\rightarrow\) 重标定 \(q_{h,c}\) \(\rightarrow\) 重算信任域 \(\rightarrow\) 重发布融合表到 ECR。定义**证书债务** \(D_{cert}=\) 自上次校准以来新增演示数 + WM 版本漂移；当 \(D_{cert}>D_{max}\) 时禁用 WM 源，只保 sim+demo，避免「旧校准证书新任务」。

## 2. 产出设计（增量 IP-57/58/59 + 升级 IP-51/52/53/49/50/45/47/54/55/56）

### 2.1 IP-57 DEMO-CERT-ANCHOR（DCA，演示证书锚定器）
1. **演示接入与质量门**：统一时间戳/坐标系，剔除轨迹丢帧、标定漂移、人工接管段；每条轨迹带来源、本体、环境指纹，供 IP-55 溯源。
2. **见证抽取**：逐帧用 IP-49 区间几何证书计算 \(m_t^{real}\) 下界与接触 regime 标签，生成 \(W\)；对关键帧做二次人工抽检。
3. **证据密度图**：kNN/核密度建 \(S_{demo}(\kappa)\) 与覆盖热力图，输出「演示盲区」清单驱动主动采集。
4. **局部演示下界**：kNN + Lipschitz 单边下界，作为第三源接入融合；盲区内不给出结论，交由 sim/WM 或回退。

### 2.2 IP-58 WORLD-MODEL-CERT-ORACLE（WMO，世界模型证书预言机）
1. **混合训练**：Demo 为主（真实锚）、Sim 为辅（覆盖补全），对乐观误差重罚；集成训练给认知不确定度。
2. **分组共形校准**：按接触 regime × horizon 建校准表，输出 \(q_{h,c}\)；支持加权共形应对分布偏移。
3. **信任域计算**：由集成方差、演示密度、horizon 上限三条件联立，离线算成可查表；信任域外强制回退。
4. **反事实梦境搜索**：在隐空间对 \(\delta\) 做梯度下降，批量生成最危险梦境；送给 IP-54 的验证闸门。

### 2.3 IP-59 THREE-SOURCE-CERT-FUSION（TSF，三源证书融合闸门）
1. **风险预算**：\(\alpha\) 按 Bonferroni 分给 sim/demo/WM，各源独立校准，禁止共享校准集。
2. **逐点 max 融合**：在各自信任域内取下界最大值，输出 `(m_lo, source_tag, coverage_guarantee)`；标签随证书下发。
3. **覆盖率审计**：在留出实机轨迹上滚动审计实测覆盖，低于 \(1-\alpha-2\%\) 即触发重标定并临时降级。
4. **硬回退**：无源可信或证书债务超限时回退 SafeStop；任何「源标签缺失」的证书视为无效。

## 3. 四层架构 v8

```
L0: 演示湖 D_demo（采集/回放/质量门/溯源）+ 实机日志 → 见证 W、regime 标签、证据密度 ρ_demo
L1: IP-57 DCA（局部演示下界 + 覆盖图） + IP-58 WMO（集成 WM + 分组共形 q + 信任域 + 梦境提案）
L2: TRI-FUSE(INT8) + IP-49 LIO → 度量语义图 C_ms + 漂移界 B_t + L_m(经验分位)
L3: IP-51 CAR(融合下界守卫) ← IP-56 ECR(融合下界表 + q 表 + 偏移监控)
    → IP-47 组合(检查源标签/信任域交集) → IP-39 规划(CBF margin=m_lo^⊕)
    → IP-45 总线(源标签 + 覆盖率审计 + 证书债务) → IP-48 流匹配 + IP-43 韵律 → IP-53 CMC
L4: IP-54 SCV(仿真 + 梦境验证闸门) ↔ IP-58 WMO(反事实梦境) ↔ IP-55 CKB(见证/q表/幻觉账本)
    → IP-44 蒸馏 + IP-50 课程(演示相位) → RCA 重颁证书(源标签 + 信任域 + 覆盖保证) → 热更新
运行期：L0 查表(融合下界) + L1 INT8 监控 + 偏移/覆盖率/证书债务监控 → 飞轮触发 → WM/Sim 重跑 → 重标定 → 热更新
```

## 4. 实验设计（E87–E94 硬门槛，承接 E79–E86）

| E94 跨体演示迁移 | 新本体 <50 条演示下的安全与任务成功率 | 0 违例；成功率 ≥70% |

## 5. 本轮最大风险

**一句话**：演示数据天然带**成功者偏差**且与测试分布可能不可交换，校准集对危险区近乎零覆盖，共形覆盖保证只在演示分布内成立——世界模型会在「有统计保证」的假象下对未覆盖危险区给出乐观下界，这比第 42 轮的仿真偏差更隐蔽；因此 E89（分 regime 覆盖实测）与 E92（信任域假安全率）必须作为红线，任何一项不达标即关闭 WM 源并回退 sim+demo。

| \(\rho_{demo}(x)\) | 演示证据密度 | kNN 距离倒数；用于定义演示支撑域 |
| \(S_{demo}(\kappa)\) | 演示支撑域 | \(\{x:\rho_{demo}(x)\ge\kappa\}\)，局部演示下界仅在此有效 |
| \(m_{lo}^{demo}(x)\) | 局部演示下界 | kNN + \(L_m\)-Lipschitz 单边下界 |
| \(e,f,d,g\) | WM 编解码/动力学/边际头 | \(z=e(o)\)，\(z'=f(z,a)\)，\(\hat o=d(z)\)，\(\hat m=g(z)\) |
| \(U(x)\) | 认知不确定度 | 集成成员边际预测的标准差 |
| \(q_{h,c}\) | 分组共形分位数 | regime \(c\)、horizon \(h\) 上乐观误差的 \(1-\alpha_c\) 分位 |
| \(m_{lo}^{WM}(x)\) | 共形证书下界 | \(\hat m(x)-q_{h,c}\)，覆盖 \(1-\alpha_c\) |
| \(T_s\) | 源 \(s\) 信任域 | WM 由 \(U,\rho_{demo},H_{max}\) 联立；demo 由 \(S_{demo}\)；sim 由 W_1 界 |
| \(m_{lo}^{\oplus}\) | 三源融合下界 | 各信任域内下界逐点取 max |
| \(D_{cert}\) | 证书债务 | 上次校准后新增演示数 + WM 版本漂移 |

## 2. 关键算法（伪代码）

### IP-57 DCA：演示见证抽取与局部下界
```
def extract_demo_witnesses(D_demo, geometric_cert, L_m):
    W = []
    blind_spots = []
    for traj in D_demo:
        if quality_gate_fail(traj):      # 丢帧/标定漂移/人工接管
            continue
        for t in range(len(traj)):
            # 用区间算术给下界，禁止用 WM 给校准集打标
            m_lo = geometric_cert.interval_margin_lb(traj.o[t], traj.a[t])
            c = contact_regime(traj.o[t])          # 接触模式：自由/接触/滑动...
            W.append((traj.x[t], m_lo, c, traj.source_id))
    index = build_knn_index(W)
    for c in REGIMES:
        if count(W, regime=c) < 200:
            blind_spots.append(c)
    return W, index, blind_spots

def demo_lower_bound(x, W_index, L_m, k=8):
    neigh = W_index.knn(x, k)
    # m 为 L_m-Lipschitz：最近见证给出确定性单边下界
    return max(m_i - L_m * dist(x, x_i) for x_i, m_i, c_i, _ in neigh)

def demo_support_density(x, W_index, k=8, eps=1e-6):
    return 1.0 / (W_index.knn_distance(x, k) + eps)
```

### IP-58 WMO：演示锚定 WM 训练与分组共形
```
def train_world_model(D_demo, D_sim, K=5, lambda_opt=10.0, lambda_con=1.0):
    models = []
    for k in range(K):
        enc, dyn, dec, margin_head = init_networks()
        for batch in mixture(D_demo, D_sim, p_demo=0.7):
            z  = enc(batch.o)
            z2 = enc(batch.o_next)
            loss  = recon_loss(dec(z), batch.o)
            loss += dyn_loss(dyn(z, batch.a), z2)
            loss += margin_loss(margin_head(z), batch.m)
            # 乐观误差（预测边际高于真实）重罚：模型天然偏保守
            err = margin_head(z) - batch.m
            loss += lambda_opt * relu(err).pow(2).mean()
            loss += lambda_con * relu(-err).pow(2).mean()
        models.append((enc, dyn, dec, margin_head))
    return models

def predict_margin(ens, x, h):
    preds = [rollout_margin(m, x, h) for m in ens]
    return mean(preds), std(preds)            # (m_hat, U)

def conformal_calibrate(ens, calib_by_regime, alpha=0.05, H_max=50):
    q = {}
    alpha_c = alpha / (3.0 * len(calib_by_regime))   # Bonferroni 再分到源/regime
    for c, trajs in calib_by_regime.items():
        for h in range(1, H_max + 1):
            scores = []
            for traj in trajs:
                for t in range(len(traj) - h):
                    m_hat, _ = predict_margin(ens, traj, h, start=t)
                    m_real = traj.margin[t + h]
                    scores.append(m_hat - m_real)     # 单边乐观误差
            n = len(scores)
            k = min(n, math.ceil((n + 1) * (1 - alpha_c)))
            q[(c, h)] = sorted(scores)[k - 1]
    return q

def weighted_conformal_q(scores, weights, alpha_c):
    # 分布偏移：w(x) = dP_test / dP_cal；在偏移下恢复覆盖
    order = np.argsort(scores)
    s, w = np.array(scores)[order], np.array(weights)[order]
    cw = np.cumsum(w) / np.sum(w)
    return s[min(len(s) - 1, np.searchsorted(cw, 1 - alpha_c))]
```

### IP-59 TSF：信任域、三源 max 融合与运行时守卫
```
def wm_trust(x, h, ens, W_index, q, rho_min, u_max):
    _, U = predict_margin(ens, x, h)
    rho  = demo_support_density(x, W_index)
    return (h <= H_max) and (U <= u_max) and (rho >= rho_min)

def fused_lower_bound(x, h, cert, W_index, ens, q, alpha=0.05):
    c = contact_regime(x)
    lows = {}
    # 源 1：演示（确定性 Lipschitz 下界，仅在支撑域内）
    if demo_support_density(x, W_index) >= KAPPA:
        lows['demo'] = demo_lower_bound(x, W_index, cert.L_m)
    # 源 2：仿真（W_1 迁移修正后的保守下界）
    if cert.sim_valid(x) and cert.w1_confidence >= 1 - alpha / 3:
        lows['sim'] = cert.m_sim[x] - cert.L_m * cert.eps_w
    # 源 3：世界模型（共形下界，且必须在信任域）
    if wm_trust(x, h, ens, W_index, q, KAPPA, U_MAX):
        m_hat, _ = predict_margin(ens, x, h)
        lows['wm'] = m_hat - q[(c, h)]
    if not lows:
        return NEG_INF, ('SAFE_STOP', None)
    source = max(lows, key=lows.get)          # max：各源均已校准，取最紧
    return lows[source], ('OK', source)

def car_guard(e, x, cert, fused):
    m_lo, tag = fused
    # 源标签必须存在；证书债务超限时禁止 WM 源
    if tag[1] is None or (tag[1] == 'wm' and cert.cert_debt > D_MAX):
        return False
    return m_lo >= cert.alpha_e[e] * cert.theta[e]
```

### IP-58 WMO：反事实梦境与 IP-54 验证闸门
```
def dream_counterexamples(ens, W_index, cert, N=256, steps=40, H=20, eps=0.1):
    proposals = []
    for _ in range(N):
        x0 = W_index.sample_supported()
        delta = torch.zeros_like(x0, requires_grad=True)
        for _ in range(steps):
            traj_margin = min(rollout_margin(ens_k, x0 + delta, h)
                              for ens_k in ens for h in range(1, H + 1))
            loss = traj_margin + 100.0 * relu(delta.norm() - eps)
            loss.backward()
            delta = (delta - 0.01 * delta.grad).detach().requires_grad_(True)
        if traj_margin.item() < cert.theta_min:
            proposals.append((x0 + delta).detach())
    return proposals      # 只是提案，不是证据

def verification_gate(proposals, scv, real_runner, min_seeds=5, tau=0.05):
    accepted, hallucination_ledger = [], []
    for x in proposals:
        sim = scv.run(x, seeds=min_seeds)
        if sim.violation_rate <= 0.5:
            continue
        real = real_runner.run(x, seeds=2) if real_runner.is_safe_to_try(x) else None
        if real is not None and abs(sim.margin_p50 - real.margin_p50) < tau:
            accepted.append((x, sim, real, 'dream_validated'))
        else:
            hallucination_ledger.append((x, sim, 'unconfirmed'))  # 仅用于再训练
    return accepted, hallucination_ledger
```

### 飞轮更新与覆盖率审计
```
def flywheel_update(new_demos, ens, calib, cert, alpha=0.05):
    W, index, blind = extract_demo_witnesses(new_demos, cert.geometric, cert.L_m)
    cert.W_index = merge(cert.W_index, index)
    ens = finetune_world_model(ens, new_demos, hallucination_ledger=cert.hallucinations)
    q = conformal_calibrate(ens, calib.by_regime, alpha=alpha)
    # 覆盖率审计：留出实机轨迹上实测覆盖必须 >= 1 - alpha - 2%
    coverage = empirical_coverage(ens, q, calib.holdout_real, alpha)
    if coverage < 1 - alpha - 0.02:
        cert.disable_source('wm')          # 立即关闭 WM 源
    cert.publish_fused_table(ens, q, certify=True)
    cert.cert_debt = 0
    return ens, q, blind
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性保证 |
|---|---|---|---|
| IP-57 见证抽取 | 离线 \(O(\sum_i T_i)\) 可并行 | 见证索引 \(O(|W|)\) | 区间算术下界 \(\Rightarrow m_t\le m^{real}\)，无循环标定 |
| IP-57 局部演示下界 | 查询 \(O(\log|W|+k)\) | \(O(|W|)\) | \(m\) 为 \(L_m\)-Lipschitz \(\Rightarrow\) 支撑域内 sound |
| IP-58 WM 训练 | 离线 \(O(E\cdot(|D_{demo}|+|D_{sim}|))\) | 参数量 + 回放缓冲 | 乐观误差重罚降低系统性高估；集成给 \(U\) |
| IP-58 共形校准 | \(O(N_{cal}\cdot H_{max})\) | \(q\) 表 \(O(|C|\cdot H_{max})\) | regime 内可交换 \(\Rightarrow\) 覆盖 \(\ge 1-\alpha_c\)；加权共形应对偏移 |
| IP-58 梦境搜索 | 离线 \(O(N_{dream}\cdot steps\cdot H\cdot K)\)，可并行 | 提案缓存 | 仅为提案；经 IP-54 闸门才成证据 |
| IP-59 信任域查询 | \(O(K)\) 前向 + \(O(\log|W|)\) kNN | 同 L0/WM 索引 | 三条件联立 \(\Rightarrow\) 不在支撑/超 horizon 不外推 |
| IP-59 三源融合 | \(O(1)\)（查表后） | 融合表 | 命题 1：\(\max\) 保持 soundness 且更紧 |
| IP-56 边缘运行时 | \(O(\log N)\) 查表 | 融合表 + q 表 | 只下发下界与源标签，边缘不跑 WM，成本不增 |
| 飞轮更新 | 离线 \(O(N_{new}+N_{cal}\cdot H)\) | 版本化快照 | 覆盖审计 + 证书债务上限 \(\Rightarrow\) 旧校准不外推 |

**命题 1（三源 max 融合的 soundness 与紧致性）**：设各源 \(s\) 满足 \(P(m_{lo}^{s}\le m^{real})\ge 1-\alpha_s\)，且 \(\sum_s\alpha_s=\alpha\)。则
\[
P\big(m_{lo}^{\oplus}\le m^{real}\big)\ge 1-\alpha,
\]
且对任意可行 \(x\) 有 \(m_{lo}^{\oplus}(x)\ge m_{lo}^{s}(x)\)。

*证明（要点）*：令 \(E_s=\{m_{lo}^{s}\le m^{real}\}\)，则 \(P(\cap_s E_s)\ge 1-\sum_s\alpha_s=1-\alpha\)（union bound）。在 \(\cap_s E_s\) 上，对每个被纳入的源都有 \(m_{lo}^{s}\le m^{real}\)，故其逐点最大值也 \(\le m^{real}\)；紧致性由 \(\max\) 的定义直接得到。\(\square\)

**注 1（为何必须配信任域）**：若 WM 在支撑域外推，其 \(q_{h,c}\) 不再覆盖，\(E_{WM}\) 失效；此时 max 会被过高的 WM 下界「污染」。因此 \(T_{WM}\) 不是可选项，而是命题 1 的前提。

**注 2（校准集卫生）**：校准集只能用区间算术下的实机见证，禁止用 WM 预测值回填；否则共形分位数会被乐观幻觉自我强化，覆盖保证退化。

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 成功者偏差：演示几乎全是成功轨迹，危险区零覆盖，共形保证在盲区失效 | 高 | 纳入失败/near-miss 演示；对抗式主动采集；kNN 覆盖门控；E89/E92 红线；盲区强制回退 |
| 可交换性破裂：测试分布漂移，历史校准不再覆盖 | 高 | 加权/在线共形；分 regime 分组；漂移触发重标定；留出滚动审计 |
| WM 长时程复合误差：horizon 越长误差越大却仍被采信 | 高 | 设 \(H_{max}\)；\(q_{h,c}\) 随 \(h\) 增长；集成 \(U\) 门控；超 horizon 只走 sim/demo |
| 校准集被 WM 污染：用预测回填真值导致自我强化 | 高 | 校准真值只用区间算术实机见证；禁止 WM 打标；独立审计集 |

| 信任域过窄：WM 源几乎不用，收益归零 | 中 | 主动演示采集扩域；按 regime 报告覆盖率；E92 同时约束覆盖与假安全率 |
| 演示数据治理：隐私、标注质量、本体不一致 | 中 | 来源/同意/本体指纹溯源；异常轨迹剔除；人工抽检关键帧 |
| 多源时间不同步：demo/sim/WM 边际定义不一致 | 中 | 统一边际定义与坐标系；证书对象带源标签与版本；跨源一致性单测 |

## 6. 本轮最大风险

**一句话**：演示数据天然带**成功者偏差**且与测试分布可能不可交换，校准集对危险区近乎零覆盖，共形覆盖保证只在演示分布内成立——世界模型会在「有统计保证」的假象下对未覆盖危险区给出乐观下界，这比第 42 轮的仿真偏差更隐蔽；因此 E89（分 regime 覆盖实测）与 E92（信任域假安全率）必须作为红线，任何一项不达标即关闭 WM 源并回退 sim+demo。
