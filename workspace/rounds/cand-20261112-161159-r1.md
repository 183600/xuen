# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC，IP-153~160；灵感循环第 7 轮；本轮灵感：「视觉编码器」×「通用机器人平台」）

> 第 60 轮把「场景→意图→约束→阻抗→执行→EV-exec→场景更新」闭合成 SERC，并给出四维认知预算 PCE++++。但它隐含两个强假设：**（i）场景只能在接触后由力/位遥测识别；（ii）只有单一具身，`K_safe` 的数值在平台内可比**。本轮从两个灵感词各切一刀：
> 1. **视觉编码器**能把场景识别从「接触后」前移到「接触前」，却带来**视觉-触觉接地鸿沟**：语义相似（都像木桌）不等于阻抗相同（漆面 / 未漆面 / 空腔 / 湿滑覆膜）。
> 2. **通用机器人平台**意味着 N 个异构具身（机械臂 / 人形 / 移动操作手），同一串 `K_safe` 在不同具身上不是同一个物理量，**跨具身不可比**会同时污染先验迁移与证据链。
> 统一解法：**在 canonical（任务级）阻抗空间做视觉接地与证据规范化，在具身空间做执行；任何视觉先验都必须以「集合 + 覆盖保证」的形式进入，而不是以点估计进入。**

## 0. 直觉与动机

**灵感 1（视觉编码器 → 视觉编码器中介先验 VEM）**
直觉：预训练视觉编码器（DINOv2 / CLIP / ViT）已经把「木纹、玻璃、织物、金属」编码进一个语义流形，但它编码的是「看起来像什么」，不是「按下去有多硬」。正确姿势不是用视觉替代力觉，而是**用视觉把场景后验从均匀先验搬到场景邻域，再让力觉在接触后做接地校正**。关键洞见：视觉编码器**冻结**，只学一个极低容量的接地适配器 `g: e ↦ π(K_c)`，并且 `g` 输出的是**阻抗集合** `C_α` 而不是一个点——因为一个会说谎的均值，比一个诚实的集合危险得多。

**灵感 2（通用机器人平台 → 跨具身接地 CEG）**
直觉：平台异构的本质不是「执行器不同」，而是「阻抗参数不在同一坐标系」。若先把阻抗规范化到任务空间 canonical 阻抗 `K_canon`（任务级的质量-弹簧-阻尼语义），再为每个具身学一个**低秩仿射适配器** `A_e: K_canon→K_e`，那么「一套视觉场景先验」就能驱动 N 个具身。关键洞见：**跨具身迁移应发生在 canonical 空间**；`A_e` 的条件数 `cond(W_e)` 直接决定「这个具身的阻抗能否被稳定复现」，因此它是**证据可比性**的度量，而不只是拟合参数。

**灵感 3（视觉-触觉接地鸿沟 → 视觉共形接地 VCG）**
直觉：视觉编码器永远不知道摩擦系数 μ，它只知道「看起来是湿的」。任何视觉→阻抗映射都必然带误差，而且这个误差在跨具身时**非可交换（non-exchangeable）**：标定具身与部署具身的分布不同。用**自适应共形推断（ACI）**在线维护覆盖：让 `C_α` 满足长期 miss 率 ≤ α，即使分布漂移；当连续 miss（覆盖失效）时判定「接地漂移」，无条件回退第 60 轮纯力觉 SSM。关键洞见：**视觉先验的合法性应由覆盖保证背书，而不是由离线精度背书**。

**灵感 4（视觉 × 通用平台合流 → 跨具身视觉接地闭环 VCPL）**
直觉：VEM 出「视觉→canonical 阻抗集合」，CEG 出「canonical→具身 K_e」，执行后用力和位置反馈同时更新**共形残差**与**适配器 A_e 的低秩增量**。闭环变为：**视觉→场景集合→canonical 先验→具身适配→执行→力觉残差→（更新 conformal + 微调 A_e）→视觉先验再校准**。这是第 60 轮 SERC 的外感受扩展：把「接触后才认识」提前为「接触前先给集合，接触后收敛成点」。

**灵感 5（PCE++++ → 五预算 PCE+++++）**
直觉：新增 `B_vis`（编码器算力、嵌入刷新率、校准样本数）与 `B_emb`（具身适配样本、迁移残差预算）。`B_vis` 耗尽 ⇒ 退化为第 60 轮纯力觉 SSM；`B_emb` 耗尽 ⇒ 锁死 canonical 保守集合、拒绝跨具身迁移。任一预算耗尽都必须**可证地**回到第 60 轮安全基线，而不是静默降级。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（视觉编码器中介先验 VEM）** 视觉接地模型 `Γ_vis = (φ_vis, g_θ, C_cal)`。其中：
- **冻结编码器**：`φ_vis: I → R^d`（DINOv2/CLIP 主干，参数冻结，不参与在线梯度更新）
- **接地适配器**：`g_θ: R^d → (μ_c, Σ_c)`，低容量（线性/两层 MLP），输出 canonical 阻抗的高斯参数
- **校准集**：`C_cal = {(I_i, K_i^c)}`，每具身独立收集
- **视觉场景先验**：`π_vis(K_c|I) = N(K_c; μ_c(I), Σ_c(I))`，`(μ_c,Σ_c)=g_θ(φ_vis(I))`
- **视觉置信**：`visual_conf(I) = max_z softmax(⟨φ_vis(I), t_z⟩)`，`t_z` 为场景原型/文本嵌入
- **准入规则**：`π_vis` 只能进入 EEIS 作为「候选收缩域」，且必须与共形集合取交：
  `K_admissible = supp(π_vis) ∩ C_α(I)`；**明令禁止**把 `μ_c` 直接当作约束真值。

**定义 162（跨具身接地 CEG）** canonical 阻抗 `K_c ∈ K_canon ⊂ R^m`；具身 `e` 的适配器
`A_e(K_c) = W_e K_c + b_e`，`W_e ∈ R^{m_e×m}`，`rank(W_e)=r_e ≪ min(m,m_e)`。
- **迁移算子**：`T_{e→e'} = A_{e'} ∘ A_e^{†}`（`W_e` 满列秩时可逆传递）
- **迁移条件数**：`κ_e = cond(W_e) = σ_max(W_e)/σ_min(W_e)`；`κ_e` 越大，`A_e^{†}` 越病态，跨具身证据越不可比
- **低秩增量更新**：`W_e ← W_e + U V^T`（`U,V` 秩 `r_u`），只在新具身标定样本上更新，冻结其余参数
- **规范化证据**：`EV-exec_canonical = (A_e^{†}(K_e^obs), κ_e, W_e 版本号)`

**定义 163（视觉共形接地 VCG）** 非一致性分数
`s(I,K_c) = ||g_θ(φ_vis(I)) − K_c||_{Σ_c^{-1}}`。
验证集阈值 `q_t` 用自适应共形推断在线更新：
```
q_{t+1} = q_t + η(α − 1{K_t ∉ C_t})
C_t = { K_c : s(I_t, K_c) ≤ q_t }
```
- **覆盖保证**（ACI 正则条件下）：`limsup_{T→∞} (1/T) Σ_t 1{K_t∉C_t} ≤ α`
- **接地漂移判定**：若最近 `W_d` 个样本的 miss 率 `> α + δ_d`，判为 `grounding_drift`，强制回退纯力觉 SSM
- **保守性**：`α` 越小集合越大；`α→0` 时 `C_α→K_canon`，退化为「无信息视觉先验」（可证安全）

**定义 164（具身能力清单 CEC）** `Cap(e) = (n_dof, F_max, v_max, F_res, sensor_set, K_range, τ_lat)`。
```
Feas(K_c, e) = 1[ A_e(K_c) ∈ K_range(e) ] ∧ 1[ 动力学可达 ] ∧ 1[ τ_lat ≤ τ_deadline ]
Gap(e, e') = { K_c : Feas(K_c,e)=1 ∧ Feas(K_c,e')=0 }
```
`Gap` 用于拒绝「在 A 机器人可执行、在 B 机器人不可执行」的场景先验，防止跨具身先验迁移把 A 的能力当成 B 的。

**定义 165（跨具身视觉接地闭环 VCPL）** 算子 `VCPL(M, e, I, δ_f^req)`：
```
① e_t = φ_vis(I_t); (μ_c, Σ_c) = g_θ(e_t)
② C_α = conformal_set(s, q_t); π_vis = N(μ_c,Σ_c) ∩ C_α
③ if B_vis 耗尽 or grounding_drift: π_vis ← π_scene^general   # 第60轮
④ K_c^prior = EEIS.compile_canonical(π_vis, δ_f^req)
⑤ K_e^prior = A_e(K_c^prior); if not Feas(K_e^prior, e): return CECD_fallback
⑥ K_e = SERC(M, e, K_e^prior)                                # 第60轮闭环落地
⑦ 执行 → EV-exec(e) → 力/位残差 r_t = K_e^obs − A_e(K_c^prior)
⑧ q_{t+1} ← ACI(q_t, r_t); if samples_enough: W_e ← W_e + U V^T
⑨ K_c^obs = A_e^{†}(K_e^obs); EPIR.append((K_c^obs, κ_e, W_e.version))
⑩ return (K_e, C_α, q_t, κ_e, EV-exec_canonical)
```

**定义 166（五预算 PCE+++++）** `B_cog5 = (B_vis, B_emb, B_scene, B_intent, B_exec)`：
- `B_vis = (Encoder_flops, Embedding_refresh_rate, Calibration_samples)`
- `B_emb = (Adapter_rank_budget, Transfer_samples, κ_e_budget)`
- `B_scene / B_intent / B_exec` 沿用第 60 轮
认知成本与 VOI 扩展：
```
voi_vis(π) = VOI_meta(π) − λ_vis·cost_vis − λ_emb·cost_emb − cost_cog − cost_exec
cost_vis = λ_f·Encoder_FLOPs + λ_r·(1/refresh) + λ_cal·Calibration_cost
cost_emb = λ_rank·rank(W_e) + λ_tr·Transfer_residual(κ_e)
```
**降级序（单调、可证）**：`B_vis` 尽→纯力觉；`B_emb` 尽→canonical 保守集；`B_scene` 尽→通用场景；`B_intent` 尽→默认约束；`B_exec` 尽→第 59 轮降级。

**定义 167（视觉接地三元组 VGT）** 给定视觉场景 `I`、canonical 阻抗 `K_c`、具身 `e`：
```
VGT(I, K_c, e) = (visual_conf(I), coverage(C_α), transfer_ok(K_c, e))
coverage(C_α) = 1 − miss_rate_online
transfer_ok   = 1[ Feas(K_c, e) ∧ κ_e ≤ κ_max ]
```
- **VGT 有效**：`visual_conf ≥ τ_v ∧ coverage ≥ 1−α ∧ transfer_ok = 1`
- **不可比证据标记**：若 `κ_e > κ_max`，该条 `EV-exec` 在证据链上标注 `comparable=false`，禁止跨具身聚合

**定义 168（跨具身协同决策 CECD）** 给定场景序列 `(I_1..I_n)`、具身集合 `E`：
```
C_cand = ⋂_i C_α(I_i) ∩ ⋂_{e∈E} { K_c : Feas(K_c, e) }
if ∃e*: VGT valid and C_cand ≠ ∅:
    e* = argmin_{e∈E} λ·cost_emb(e) + (1−λ)·κ_e       # 迁移代价最小的具身
    return execute( e*, A_{e*}( argmin_{K_c∈C_cand} ω_traj(K_c) ) )
else:
    return SERC_baseline(e_default)                      # 回退第60轮，可证安全
```
决策的关键在于：**先问「这个具身能不能稳定复现该阻抗集合」，再问「哪个阻抗最优」**——顺序反过来会把不可比证据当成可比证据。

### IP-161 VEM（视觉编码器中介先验）

```python
class VisualEncoderMediatedPrior:
    def __init__(self, encoder, adapter, alpha=0.1):
        self.phi = encoder            # frozen
        self.g = adapter              # low-capacity, trained per-embodiment
        self.alpha = alpha
        self.scene_prototypes = {}    # t_z

    def __call__(self, image):
        with torch.no_grad():
            e = self.phi(image)
        mu, sigma = self.g(e)
        visual_conf = self._scene_confidence(e)
        return {'mu_c': mu, 'Sigma_c': sigma,
                'visual_conf': visual_conf, 'embedding': e}

    def _scene_confidence(self, e):
        logits = {z: torch.dot(e, t) for z, t in self.scene_prototypes.items()}
        return torch.softmax(torch.stack(list(logits.values())), dim=0).max().item()
```

### IP-162 CEG（跨具身接地）

```python
class CrossEmbodimentGrounder:
    def __init__(self, canon_dim, kappa_max=10.0):
        self.canon_dim = canon_dim
        self.kappa_max = kappa_max
        self.adapters = {}            # e -> (W_e, b_e, version)

    def register(self, e, n_dof, W, b):
        self.adapters[e] = (W, b, 0)

    def to_embodiment(self, K_c, e):
        W, b, _ = self.adapters[e]
        return W @ K_c + b

    def to_canonical(self, K_e, e):
        W, b, _ = self.adapters[e]
        return np.linalg.pinv(W) @ (K_e - b)

    def condition_number(self, e):
        W, _, _ = self.adapters[e]
        return float(np.linalg.cond(W))

    def transferable(self, e):
        return self.condition_number(e) <= self.kappa_max

    def low_rank_update(self, e, U, V):
        W, b, v = self.adapters[e]
        self.adapters[e] = (W + U @ V.T, b, v + 1)
```

### IP-163 VCG（视觉共形接地）

```python
class VisualConformalGrounding:
    def __init__(self, alpha=0.1, eta=0.01, drift_window=50, delta_d=0.05):
        self.alpha, self.eta = alpha, eta
        self.q = 0.0
        self.misses = deque(maxlen=drift_window)
        self.delta_d = delta_d

    def nonconformity(self, prior, K_c):
        d = K_c - prior['mu_c']
        return float(np.sqrt(d.T @ np.linalg.pinv(prior['Sigma_c']) @ d))

    def set(self, prior, cands):
        return [K for K in cands if self.nonconformity(prior, K) <= self.q]

    def update(self, prior, K_true):
        miss = self.nonconformity(prior, K_true) > self.q
        self.misses.append(1 if miss else 0)
        self.q = max(0.0, self.q + self.eta * (self.alpha - (1 if miss else 0)))
        return miss

    def grounding_drift(self):
        if len(self.misses) < self.misses.maxlen:
            return False
        return np.mean(self.misses) > self.alpha + self.delta_d
```

### IP-164 CEC（具身能力清单）

```python
class EmbodimentCapabilityRegistry:
    def __init__(self):
        self.caps = {}

    def register(self, e, cap):
        self.caps[e] = cap        # n_dof, F_max, v_max, K_range, tau_lat

    def feasible(self, K_c, e, A_e):
        cap = self.caps[e]
        K_e = A_e(K_c)
        in_range = all(lo <= x <= hi for x, (lo, hi) in zip(K_e, cap['K_range']))
        return in_range and cap['tau_lat'] <= cap['tau_deadline']

    def gap(self, e, e2, A_e, A_e2, samples):
        return [K for K in samples
                if self.feasible(K, e, A_e) and not self.feasible(K, e2, A_e2)]
```

### IP-165 VCPL（跨具身视觉接地闭环）

```python
def visual_cross_embodiment_loop(M, e, image, delta_f_req):
    prior = M.vem(image)
    C_alpha = M.vcg.set(prior, M.canonical_candidates)
    if M.budget.B_vis_exhausted() or M.vcg.grounding_drift():
        prior = M.general_scene_prior()          # 回退第60轮
        C_alpha = M.canonical_candidates

    K_c_prior = M.eeis.compile_canonical(prior, C_alpha, delta_f_req)
    K_e_prior = M.ceg.to_embodiment(K_c_prior, e)
    if not M.cec.feasible(K_c_prior, e, M.ceg):
        return M.cecd.fallback(e)

    K_e, cert, EV_exec = M.serc(e, K_e_prior)     # 第60轮闭环
    r = EV_exec.K_obs - K_e_prior
    M.vcg.update(prior, M.ceg.to_canonical(EV_exec.K_obs, e))
    if M.budget.B_emb_allows_update():
        M.ceg.low_rank_update(e, *M.adapter_gradient(r))

    EV_c = {'K_c': M.ceg.to_canonical(EV_exec.K_obs, e),
            'kappa_e': M.ceg.condition_number(e),
            'comparable': M.ceg.transferable(e),
            'W_version': M.ceg.adapters[e][2]}
    M.epir.append(EV_c)
    return K_e, C_alpha, M.vcg.q, EV_c
```

### IP-166 PCE+++++（五预算耦合）

```python
class FiveBudget:
    def __init__(self, vis_ops, emb_samples, cog_budget):
        self.B_vis_ops = vis_ops
        self.B_emb_samples = emb_samples
        self.B_cog = cog_budget          # B_scene/B_intent/B_ros/B_exec
        self.ops_vis = 0
        self.emb_used = 0

    def B_vis_exhausted(self):
        return self.ops_vis >= self.B_vis_ops

    def B_emb_allows_update(self):
        return self.emb_used < self.B_emb_samples

    def spend(self, vis=0, emb=0):
        self.ops_vis += vis
        self.emb_used += emb

    def degrade_mode(self):
        if self.B_vis_exhausted():      return 'force_only_ssm'
        if not self.B_emb_allows_update(): return 'canonical_conservative'
        return 'normal'
```

### IP-167 VGT（视觉接地三元组）

```python
def vgt_valid(prior, C_alpha, K_c, e, ceg, tau_v=0.6):
    coverage = 1.0 - np.mean(ceg.misses) if len(ceg.misses) else 0.0
    transfer_ok = ceg.transferable(e) and ceg.feasible(K_c, e)
    return (prior['visual_conf'] >= tau_v and
            coverage >= 1.0 - ceg.alpha and
            transfer_ok)
```

### IP-168 CECD（跨具身协同决策）

```python
def cross_embodiment_decision(M, scenes, embodiments):
    C_cand = M.canonical_candidates
    for img in scenes:
        prior = M.vem(img)
        C_cand = C_cand ∩ set(M.vcg.set(prior, C_cand))
    C_cand = C_cand ∩ M.feasible_canonical(embodiments)
    if not C_cand:
        return M.serc_baseline(M.default_embodiment)

    valid = [e for e in embodiments if M.vgt_valid(prior, C_cand, e)]
    if not valid:
        return M.serc_baseline(M.default_embodiment)

    e_star = min(valid, key=lambda e: 0.5*M.cost_emb(e) + 0.5*M.ceg.condition_number(e))
    K_c_star = min(C_cand, key=M.omega_traj)
    return M.execute(e_star, M.ceg.to_embodiment(K_c_star, e_star))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| VEM | O(d) 前向 + O(1) 适配 | O(d + m²) | 视觉先验只作候选域，不单独决策 |
| CEG | O(m·m_e) 适配；O(m³) 求逆 | O(m·m_e) | κ_e ≤ κ_max 才允许跨具身迁移 |
| VCG | O(K) 集合构造 / 步 | O(W_d) | ACI 长期 miss ≤ α（正则条件下） |
| CEC | O(1) 可行性判定 | O(1)/具身 | 能力缺口 Gap 被显式拒绝 |
| VCPL | O(第60轮闭环 + 适配) | 复用 | 任一预算耗尽回退第60轮基线 |

**正确性定理（CVGC：Cross-embodiment Visual Grounding Certificate）**  
假设 A66–A71：
- **(A66)** φ_vis 冻结，`g_θ` 在每具身校准集上训练，视觉先验 `π_vis` 与真实 canonical 阻抗的偏差有界；
- **(A67)** ACI 步长 `η` 与分数有界，满足自适应共形推断的收敛正则条件；
- **(A68)** `A_e` 在 `K_range(e)` 上 Lipschitz 连续，`W_e` 列满秩；
- **(A69)** CEC 的能力清单真实（`K_range`、`τ_lat` 不为乐观估计）；
- **(A70)** 第 60 轮 SERC 的 SGEC 结论在「给定 canonical 先验」时仍成立；
- **(A71)** 五预算单调消耗，降级序全序。

则：
1. **视觉先验安全性**：`K_admissible = supp(π_vis) ∩ C_α ⊆ C_α`，且 `C_α` 的长期 miss 率 ≤ α；故视觉先验永不超出共形覆盖域。
2. **跨具身可比性**：若 `κ_e ≤ κ_max`，则 `A_e^{†}` 的算子范数有界，`EV-exec_canonical` 的误差被 `κ_e` 放大上界控制；`comparable=false` 的证据不进入聚合。
3. **能力不夸大**：`K_c ∈ ⋂_e K_feasible(e)` 保证所选 canonical 阻抗在每个候选具身上都可行，`Gap` 非空时决策自动收窄或回退。
4. **可证降级**：`B_vis` 或 `B_emb` 耗尽时，`VCPL` 输出与第 60 轮 SGEC 完全一致（`π_vis←π_scene^general`，跳过 `A_e`），故安全基线不被削弱。

**推论（外感受收益）**：在 A66–A71 下，视觉先验把「接触后首次识别场景」提前为「接触前给出集合」，因此首次接触的 `K_safe` 只需在 `C_α` 内收敛；其收敛所需接触次数的期望不超过第 60 轮，且在最坏情况下相等（视觉无信息时 `C_α=K_canon`）。

### IP-161 VEM（视觉编码器中介先验）

```python
class VisualEncoderMediatedPrior:
    def __init__(self, encoder, adapter, alpha=0.1):
        self.phi = encoder          # frozen, no fine-tune
        self.g = adapter            # low-capacity, per-embodiment calibration
        self.alpha = alpha
        self.scene_prototypes = {}

    def __call__(self, image):
        with torch.no_grad():
            e = self.phi(image)
        mu, sigma = self.g(e)
        return {'mu_c': mu, 'Sigma_c': sigma,
                'visual_conf': self._confidence(e), 'embedding': e}

    def _confidence(self, e):
        logits = torch.stack([torch.dot(e, t)
                              for t in self.scene_prototypes.values()])
        return torch.softmax(logits, dim=0).max().item()
```

### IP-162 CEG（跨具身接地）

```python
class CrossEmbodimentGrounder:
    def __init__(self, kappa_max=10.0):
        self.kappa_max = kappa_max
        self.adapters = {}          # e -> (W_e, b_e, version)

    def to_embodiment(self, K_c, e):
        W, b, _ = self.adapters[e]
        return W @ K_c + b

    def to_canonical(self, K_e, e):
        W, b, _ = self.adapters[e]
        return np.linalg.pinv(W) @ (K_e - b)

    def transferable(self, e):
        W, _, _ = self.adapters[e]
        return float(np.linalg.cond(W)) <= self.kappa_max

    def low_rank_update(self, e, U, V):
        W, b, v = self.adapters[e]
        self.adapters[e] = (W + U @ V.T, b, v + 1)
```

### IP-163 VCG（视觉共形接地）

```python
class VisualConformalGrounding:
    def __init__(self, alpha=0.1, eta=0.01, drift_window=50, delta_d=0.05):
        self.alpha, self.eta = alpha, eta
        self.q = 0.0
        self.misses = deque(maxlen=drift_window)
        self.delta_d = delta_d

    def nonconformity(self, prior, K_c):
        d = K_c - prior['mu_c']
        return float(np.sqrt(d.T @ np.linalg.pinv(prior['Sigma_c']) @ d))

    def set(self, prior, cands):
        return [K for K in cands if self.nonconformity(prior, K) <= self.q]

    def update(self, prior, K_true):
        miss = self.nonconformity(prior, K_true) > self.q
        self.misses.append(1 if miss else 0)
        self.q = max(0.0, self.q + self.eta * (self.alpha - (1 if miss else 0)))
        return miss

    def grounding_drift(self):
        if len(self.misses) < self.misses.maxlen:
            return False
        return np.mean(self.misses) > self.alpha + self.delta_d
```

### IP-164 CEC（具身能力清单）

```python
class EmbodimentCapabilityRegistry:
    def __init__(self):
        self.caps = {}

    def feasible(self, K_c, e, grounder):
        cap = self.caps[e]
        K_e = grounder.to_embodiment(K_c, e)
        in_range = all(lo <= x <= hi for x, (lo, hi) in zip(K_e, cap['K_range']))
        return in_range and cap['tau_lat'] <= cap['tau_deadline']

    def gap(self, e, e2, grounder, samples):
        return [K for K in samples
                if self.feasible(K, e, grounder)
                and not self.feasible(K, e2, grounder)]
```

def visual_cross_embodiment_loop(M, e, image, delta_f_req):
    prior = M.vem(image)
    C_alpha = M.vcg.set(prior, M.canonical_candidates)
    if M.budget.B_vis_exhausted() or M.vcg.grounding_drift():

        C_alpha = M.canonical_candidates

    K_e, cert, EV_exec = M.serc(e, K_e_prior)     # 第60轮闭环

            'comparable': M.ceg.transferable(e),

### IP-166 PCE+++++（五预算耦合）

```python
class FiveBudget:
    def __init__(self, vis_ops, emb_samples, cog_budget):
        self.B_vis_ops = vis_ops
        self.B_emb_samples = emb_samples
        self.B_cog = cog_budget
        self.ops_vis = 0
        self.emb_used = 0

    def B_vis_exhausted(self):
        return self.ops_vis >= self.B_vis_ops

    def B_emb_allows_update(self):
        return self.emb_used < self.B_emb_samples

    def spend(self, vis=0, emb=0):
        self.ops_vis += vis
        self.emb_used += emb

    def degrade_mode(self):
        if self.B_vis_exhausted():          return 'force_only_ssm'
        if not self.B_emb_allows_update():  return 'canonical_conservative'
        return 'normal'
```

### IP-167 VGT（视觉接地三元组）

```python
def vgt_valid(prior, C_alpha, K_c, e, ceg, cec, tau_v=0.6):
    coverage = 1.0 - np.mean(ceg.misses) if len(ceg.misses) else 0.0
    transfer_ok = ceg.transferable(e) and cec.feasible(K_c, e, ceg)
    return (prior['visual_conf'] >= tau_v and
            coverage >= 1.0 - ceg.alpha and
            transfer_ok)
```

```python
def cross_embodiment_decision(M, scenes, embodiments):
    C_cand = M.canonical_candidates
    for img in scenes:
        prior = M.vem(img)
        C_cand = C_cand ∩ set(M.vcg.set(prior, C_cand))
    C_cand = C_cand ∩ M.feasible_canonical(embodiments)
    if not C_cand:
        return M.serc_baseline(M.default_embodiment)

    valid = [e for e in embodiments
             if M.vgt_valid(prior, C_cand, e)]
    if not valid:
        return M.serc_baseline(M.default_embodiment)

    e_star = min(valid, key=lambda e: 0.5*M.cost_emb(e)
                 + 0.5*M.ceg.condition_number(e))
    K_c_star = min(C_cand, key=M.omega_traj)
    return M.execute(e_star, M.ceg.to_embodiment(K_c_star, e_star))
```
