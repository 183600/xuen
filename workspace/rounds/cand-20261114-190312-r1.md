# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「数据集」×「触觉感知」）

> R69 把不确定性一分为二（aleatoric / epistemic），并让系统学会「问」：看、问、触、等。但 R69 的整个推理建立在一个未言明的前提上——**模型知道可能有哪些答案**。所谓 epistemic 歧义，只覆盖「模型已经学到的几个模态之间选哪个」；它无法表达「真正的答案根本没出现在数据集里」。更糟，R69 自陈的最大风险正是模态分布不可信：流模型会幻觉出数据里不存在的模态，或把真模态坍缩掉。而这个问题的**根因不在推理端，在数据端**——数据集缺覆盖、标签有偏、来源被投毒、触觉传感器随磨损漂移。
>
> 本轮两个灵感正好指向根因：
> - **数据集**不是一个静态训练资产，而应被提升为**可观测、可认证、可增补、可回滚的一等状态对象**；数据集的覆盖与溯源，决定了 R69 的模态权重是否有意义。
> - **触觉感知**是唯一必须**物理接触**才能获得、且能对视觉/本体/语言主张做「落地校验」的模态；它同时是最稀缺、最贵、最容易被磨损和 sim-to-real gap 污染的数据来源。于是每一次触摸天然是一件**双重用途**的事：既消解当下的歧义（VoI），又为未来留下一个带溯源的数据点（VoC, value-of-coverage）。
>
> 核心命题：**不确定性要三分——U_ale（噪声，R68 收紧）、U_epi（模型内的模态歧义，R69 交互）、U_data（数据集覆盖不足 / 溯源不可信，R70 才可处理）。U_epi 只在「数据集覆盖区域内」可识别；覆盖之外，再多的采样与提问都只是在错误的假设空间里自我确认。** 命名 **TACIT-RAS**（Tactile-Anchored Coverage-Informed Trust，触觉锚定、覆盖认证的数据信任闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我凭什么相信我知道的？我的知识覆盖到这里了吗？我该去摸哪里，才能让下一次不再不知道？**」

## 0. 直觉与动机

**灵感 1（数据集 = 系统的「记忆边界」，不是背景板）**
直觉：R69 的 mode 是从流模型采样出来的，但流模型的密度形状由训练集决定。若真实世界存在一个从未出现在数据集里的模态，流模型不会「以低概率报告它」，而是根本不生成它——K 再大也没用。这就是 **dataset epistemic**：不是「选错答案」，而是「答案不在选项里」。同理，被投毒的数据会生成一个「幽灵模态」，让 R69 自信地去追问一个不存在的东西。因此，**数据集的覆盖（coverage）与溯源（provenance）必须先于模态权重被认证**；模态权重再准，也只是在一个可能残缺的假设空间里的相对比例。

**灵感 2（触觉 = 唯一能「落地」的基准，也是最贵的数据）**
直觉：视觉可以被遮挡、欺骗、外推；语言可以被诱导。触觉不行——它要求接触，接触给出力、振动、热、形变这些「物理上必须为真」的信号。它因此是校验其他模态的天然 datum（测量基准）。但触觉也是**最昂贵的数据**：每次接触局部、扰动场景、消耗硬件寿命，且触觉数据集远小于视觉/语言数据集，还深受 sim-to-real gap 与传感器个体差异之苦。于是触觉把「数据」这个抽象概念变成一个**必须精打细算的物理预算**：摸哪里、摸多狠、摸几次，本身就是一个受约束的决策问题。

**灵感 3（三分 → R69 是 R70 在「完全覆盖」边界上的退化）**
直觉：R69 的两分隐含假设 coverage=1。把它显式化：U_ale（噪声，问不出来）、U_epi（模型内歧义，问得出来）、U_data（覆盖/溯源问题，只有改数据才解决）。关键纪律：**U_epi 必须在覆盖区域内计算**——覆盖外的模态不是「可约歧义」，而是「不可识别的外推」，应被重新归类为 U_data，而不是拿去驱动 R69 的交互。若数据集完全覆盖、溯源干净，则 U_data=0，R70 逐指令退化为 R69。这样 R68 ⊆ R69 ⊆ R70 形成一条严格包含链，每层都只在旧层的边界外增加能力。

**灵感 4（双用途触摸 → 现在与未来的一次联合决策）**
直觉：R69 的信息动作只为当下服务。但触觉的稀缺性要求我们同时问：这一次触摸**对未来的数据集值不值钱**？定义 VoC（value-of-coverage）：一次触摸预期能补上多少覆盖空洞。选择触摸点时应最大化 VoI_now + β·VoC − 接触成本。这把「主动感知」升级为「主动数据采集」——系统在干活的同时，有策略地替未来的自己攒数据。

**灵感 5（触摸是双刃剑 → 自我确认与数据投毒）**
直觉：如果「假设幽灵模态的模型」自己决定摸哪里、又自己给摸到的结果贴标签，它就可能制造一个**自我确认的数据集**（data incest）：先幻想一个模态，再去采到符合它的数据，最后「证明」自己是对的。这是 R69 交互投毒的「数据版」。所以数据必须过**准入闸门**：多源独立验证、与当前假设的独立性检查（novelty）、可签名溯源、可回滚隔离；并且触摸点要保留 ε-探索，刻意去覆盖「当前模型不关心」的区域。**没有独立性的数据，只会把偏见固化成事实。**

## 1. 形式化定义（增量：定义 310–326）

**定义 310（TACIT-RAS 总览）** TACIT-RAS = (TDL, CCD, DAC, PAG, CAM, FLUID-RAS†)。三不变式：
(i) **实时零学习写**（继承 R68 定义 276-i / R69 定义 293-i）：数据动作只向账本追加记录，不改冻结模型；模型/分位数更新只在离线周期，并以原子换装提交；
(ii) **数据与接触预算**：单位时间/单回合的接触次数、接触位移与扰动能量 ≤ 预算；每次接触必须通过 C-RAS-WM 与「不可逆扰动」认证；
(iii) **数据溯源纪律**：一个数据点进入参考集 D_ref 前，须有完整签名溯源、≥2 个正交通道一致、且通过独立性/新颖性检查；单次触摸不得单独定义或确认一个模态。

**定义 311（触觉数据点与接触描述子）** 触觉观测 y^T = (f, τ, s_vib, T_th, q_contact)（力、力矩、振动谱、温度、接触位姿）；φ: y^T ↦ ℝ^{d_T} 为自监督学到的低维接触描述子。数据点 d = (φ(y^T), x_proprio, o_cross, ℓ_weak, π)，其中 π 为溯源元组（来源 ID、传感器标定版本、时间戳、对抗分、签名）。数据集 D = {d_i}，参考快照 D_ref 冻结供在线认证。

**定义 312（覆盖证书 CCD）** 在接触-动作联合流形上定义非一致性分数 s(o, ξ; D_ref)（k-NN 距离 / 密度比，度量可学习但有证书）。取校准集按 split conformal 得阈值 q_α。覆盖指示 cov(o,ξ) = 1[s ≤ q_α]，覆盖率保证：对与 D_ref 可交换的新点，P(cov=1) ≥ 1−α。**代价**：交换性被触摸扰动破坏时必须改用扰动感知的重加权 conformal（定义 324）。

**定义 313（三分不确定性）** U_ale（模态内噪声，继承 R69 定义 297）；可识别模态集 M_cov = {m_k : cov(ξ̄_k)=1}；U_epi = H(M_cov) 的模态熵（仅在覆盖内）；U_data = 1 − mass(M_cov) + τ·(s(o,ξ)−q_α)_+/q_α（覆盖缺陷 + 超界幅度）。语义：U_ale 问不出、U_epi 问得出、U_data **问不出、只能摸/采/等离线更新**。若 M_cov=全部且溯源可信，U_data=0 ⇒ 逐指令退化为 R69。

**定义 314（双用途触摸 DAC）** 数据动作 g_d = (接触点 p, 力曲线, 时长, 传感配置)。联合价值：
J(g_d) = VoI_now(g_d) + β·VoC(g_d) − c_contact(g_d) − c_irrev(g_d)，
其中 VoI_now 为 R69 定义 298 的模态信息增益；VoC(g_d) = E_{d~p(·|g_d)}[U_data(D_ref) − U_data(D_ref ∪ {d})] 为对参考查询分布的期望覆盖提升；β 为数据价值系数；c_irrev 为不可逆扰动成本。选 g_d* = argmax J，s.t. 接触预算与安全认证；J≤0 则不触摸，退 R69。

**定义 315（自我确认风险与 ε-探索）** 若采点与准入标签都由当前假设 M 决定，则 VoC 会被高估 Δ_self ≈ I(M; 准入决策)。纪律：(a) 采点保留 ε-探索比例，按覆盖缺陷选择、与当前模态假设无关；(b) 独立性检查：新点对当前模型的预测残差须超过阈值（「不能太可预测」），否则视为强化偏见、不进 D_ref。R69 的「证据纪律」由此上移为「数据独立性纪律」。

**定义 316（溯源准入闸门 PAG）** d 被准入 D_ref 当且仅当：(a) 溯源完整且签名有效、对抗分 ≤ τ_adv；(b) ≥2 个正交通道（触觉 + 视觉/本体/力）一致，或来自外部可信标注源；(c) 独立性/新颖性检查通过；(d) 采点动作有接触安全证书。否则进入隔离区 Q（带拒绝理由）。账本支持按 shard 回滚：撤销后重新认证并原子换装。

**定义 317（接触感知监控 CAM）** 对 φ(y^T) 流做序贯漂移检测（conformal martingale / MMD），得 Δ_data。三通道异常模式：
- (r_res↑, Δa↑, Δ_data↑)：真实环境变化或模型失配；
- (r_res↓, Δa↑, Δ_data↑)：传感器/触觉磨损被标定吸收（承接 R69 定义 309）；
- (r_res↓, Δa↓, Δ_data↑)：**数据集/覆盖漂移**——R69 看不到的第三类。
三者联合分离「真漂移 / 传感器漂移 / 数据漂移」。

**定义 318（覆盖证书 J_TACIT）** J_TACIT = (J_FLUID, coverage_ratio, U_data_before/after, provenance_hash, admitted/quarantined, drift_stat, contact_budget_used, tacit_ver)。Valid ⇔ Valid(J_FLUID) ∧ 运行分布上 coverage ≥ 1−α ∧ 无未裁决高危隔离项 ∧ 接触预算未越界。

**定义 319（三级保守退避）**
- 覆盖成立且 U_data=0：完全走 R69（λ = λ_floor(U_ale) 或 λ_floor(U_ale+U_epi)），获得 resolution bonus；
- U_data>0 且可执行认证的采数动作：**在线 λ 仍取 max(R69 λ, λ_floor(U_ale+U_epi+U_data))**——因为冻结模型不会因一次采数立刻变好，**数据是投资，不是即时的安全垫**；采数只为下一版本改善覆盖；
- U_data>0 且不可采数/预算耗尽/被投毒：λ = λ_floor(U_ale+U_epi+U_data)，必要时直接弃权（R68 最保守）。安全侧永不弱于 R69。

**定义 320（离线数据周期与原子换装）** 在安全边界执行：隔离审查 → 多源验证 → 数据集版本化 → 重训/重标定 → 重算 q_α → 原子换装，保持 R68 定理 15 的提交/换装不变式。显式建模数据到模型的时延 Δ_t_data；换装只在安全窗口，保证控制连续。

**定义 321（触觉稀缺与 sim-to-real 覆盖修正）** 触觉数据维度 d_T 高而样本少，覆盖半径随 n 收缩约 O(n^{−1/d_T})（维度灾难）。对策：低维接触描述子 φ + 自监督预训练 + 少样本 conformal 校准 + 用重要性权重修正 sim-to-real 的覆盖偏差；定义「触觉覆盖缺口」为可诊断量。

**定义 322（数据攻击模型 ℰ_data）** 扩展 AIC：标签翻转/后门触发（触觉特定触发）、覆盖饥饿（阻止系统触摸关键区域）、溯源伪造/sybil 重复数据、接触域欺骗（假触觉/重放）。ℰ_TACIT = ℰ_FLUID × ℰ_data。

**定义 323（数据审计 VQAuditor-D）** 审计数据决策：触摸是 VoC 驱动还是自我确认？隔离是否被尊重？幽灵模态是否被挡在 D_ref 外？高杠杆数据点是否被影响函数标记？结论回灌，成为下一轮 β 与准入门槛的先验。

**定义 324（扰动感知 conformal）** 触摸改变世界（碰到 ≠ 没碰过），破坏交换性。以倾向得分/扰动强度对校准集重加权，或把接触动作作为条件协变量做 Mondrian conformal：cov(o,ξ | g_d) 在给定扰动条件下仍有 ≥1−α 保证；不可建模的强扰动直接判「不可认证」。

**定义 325（接触安全与不可逆性）** 在 R69 定义 302 上增加：接触扰动能量 ≤ ε_touch、优先非破坏性接触、对易碎/高温/运动物体设允许/禁止域；不可逆成本 c_irrev 进入 DAC 目标；任何越界 ⇒ g_d 作废且不得产生数据点。

**定义 326（覆盖感知的模态可信与 R69 边界）** 模态 m_k 可信 ⇔ 被覆盖 ∧ 溯源可信 ∧ 未被标记；R69 的「模态可信」恰为本定义在 coverage=1、ledger 干净时的特例。于是 R68 ⊆ R69 ⊆ R70，且每一级仅在上一级的边界外增加能力。

class TactileDataLedger:

# IP-265 CCD：覆盖证书（split conformal + ANN kNN）
def coverage(o, xi, D_ref, q_alpha):
    s = knn_nonconformity(phi(o), xi, D_ref)
    return Coverage(s <= q_alpha, deficit=max(0.0, (s-q_alpha)/q_alpha))

# IP-266 AUD-D：三分不确定性（只在覆盖内算 U_epi）
def decompose3(samples, o, D_ref, q_alpha):
    modes = cluster(samples)
    m_cov = [k for k in modes if coverage(o, modes[k].proto, D_ref, q_alpha).ok]
    w = mode_weights(modes)
    U_ale = sum(w[k]*trace(cov(modes[k])) for k in m_cov)
    U_epi = entropy(reweight(w, m_cov))     # 只在覆盖内
    U_data = 1.0 - mass(w, m_cov) + tau*coverage(o, best_mode(modes), D_ref, q_alpha).deficit
    return U_ale, U_epi, U_data, modes

# IP-267 DAC：双用途触摸（VoI_now + β·VoC − 成本）
def choose_data_action(modes, o, budget, D_ref):
    best = None
    cands = contact_candidates(o) + epsilon_explore(o, D_ref)   # 保留探索
    for gd in cands:
        if not budget.allow(gd) or not contact_safe(gd, o): continue
        J = voi_now(modes, gd, o) + beta*value_of_coverage(gd, D_ref) \
            - c_contact(gd) - c_irrev(gd)
        if best is None or J > best.J: best = (gd, J)
    return best if best and best.J > 0 else None

# IP-268 PAG：溯源准入（多源一致 + 新颖性 + 签名）
def admit(d, bridge):
    if not (d.prov.signed and d.prov.adv_score <= TAU_ADV): return QUARANTINE
    if num_orthogonal_agree(d, bridge) < 2:                 return QUARANTINE
    if d.residual_under_current_model < TAU_NOVEL:          return QUARANTINE  # 太可预测
    return ADMIT

# IP-269 CAM：接触漂移三通道
def drift_triplet(r_res, delta_a, phi_stream, ref):
    delta_data = conformal_martingale(phi_stream, ref)
    if r_res < TAU_RES and delta_a < TAU_FMA and delta_data > TAU_DATA:
        return "DATA_COVERAGE_DRIFT"      # R69 盲区
    if r_res < TAU_RES and delta_a > TAU_FMA and delta_data > TAU_DATA:
        return "SENSOR_WEAR"
    if r_res > TAU_RES and delta_data > TAU_DATA:
        return "WORLD_CHANGE"
    return "NOMINAL"

# IP-270 主闭环（继承 R69；数据层只追加 + 即时安全不依赖新数据）
def TACIT_RAS_round(M, obs):
    z, o = M.mtm.forward(obs)
    samples = M.fmp.sample(o, K=M.budget_K(o))
    U_ale, U_epi, U_data, modes = decompose3(samples, o, M.D_ref, M.q_alpha)
    # 覆盖内：R69；覆盖外：先认账（U_data），再决定是否采数
    g = M.mint.choose_interaction(...) if (U_data == 0 and U_epi > TAU_EPI) else None
    gd = M.dac.choose_data_action(modes, o, M.budget, M.D_ref) \
         if U_data > TAU_DATA else None
    if gd is not None:
        d = M.execute_and_measure(gd)          # 受接触安全认证
        M.ledger.append(d)                     # 仅记账，不学习
        M.pag.enqueue(d)                       # 离线准入
    # 即时安全：数据还没进模型，不得给 resolution bonus
    U_floor = U_ale + U_epi + U_data
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    trip = M.cam.drift_triplet(M.last_r_res, M.fma.last_score, M.tactile_stream,
                               M.D_ref_tactile)
    if trip != "NOMINAL" or U_data > TAU_DATA:
        lam = max(lam, 0.8)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_covered_mode(modes, M.D_ref, lam)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_d.submit_async(g, gd, U_data, trip, d, lam)
    return k, lam, mode, (U_ale, U_epi, U_data)

def TACIT_offline_cycle(M):

## 3. 推导

**引理 19（覆盖—可识别性）** 设模态原型 ξ̄_k 落在 conformal 覆盖域外（s(ξ̄_k) > q_α）。则流模型在该处的密度无数据支撑，其权重估计的偏差不可由增加采样数 K 消除（K→∞ 只收敛到模型自身错误的后验）。因此覆盖外模态必须从 U_epi 的假设空间中剔除并记入 U_data；任何把覆盖外模态当作「可交互消解的歧义」的做法，其期望误差存在与覆盖缺口正相关的下界。系：**R69 的 U_epi 只在 M_cov 上有意义。**

**引理 20（双用途触摸的分解与数据贪心）** 在可交换性与覆盖泛函的次模性（submodularity）下，J(g_d) 的 VoC 项满足边际收益递减，故贪心选择触摸序列对「覆盖增益」有 (1−1/e) 近似保证。若准入不做独立性检查，则 VoC 被高估约 I(M; 准入决策)；ε-探索 + novelty 门槛把该偏差压到 O(ε)。

**引理 21（数据投毒准入上界）** 若单源投毒率 δ_p、各源欺骗相关 ρ<1、采用 k≥2 正交一致 + novelty 检查，则投毒数据被准入的概率 ≤ δ_p·ρ^{k−1} + ε_nov；且单个数据点对某模态覆盖的影响被影响函数界约束为 O(1/n)，高杠杆点可在离线周期被标记并回滚。系：R69 的推理端证据纪律不足以防「训练端植入的幽灵模态」，必须前移到数据准入。

**引理 22（三通道漂移分离）** 设传感器磨损对应 φ(y^T) 上的一个平滑变换，标定层可把其对 r_res 与动作似然的影响部分吸收，但它改变触觉特征分布 → Δ_data↑；真实物体变化则同时抬高 r_res 与 Δ_data；模型/数据集缺失则表现为覆盖收缩（U_data↑）而 r_res、Δa 可正常。于是在 (r_res, Δa, Δ_data) 空间中三类假设可分（在 A99–A100 下有正间隔）。

**定理 18（TACIT 严格包含 FLUID）** 在覆盖成立、账本干净时（A101），TACIT 的每一步与 FLUID 逐指令相同；一般情况下，由于 U_data 只增加保守项、数据动作不改变在线冻结模型，TACIT 的瞬时期望风险 ≤ FLUID，且等号在覆盖边界取得。故 R68 ⊆ R69 ⊆ R70，安全侧逐级不让步，效率侧仅通过「未来的数据版本」获得延迟收益。

**定理 19（数据采集下的在线安全与无突变）** 数据动作经 C-RAS-WM 与接触扰动认证（定义 325）后物理风险 ≤ ε_touch；在线模型冻结 ⇒ 控制仍对同一 WM 认证；U_data>0 时 λ 相对 R69 单调不降；离线换装遵循 R68 定理 15 的提交/换装不变式 ⇒ 控制连续、无突变。**数据带来的收益必须等下个版本，绝不允许用「我刚采了数据」给当下的风险打折。**

**命题 20（覆盖收敛率）** 在贪婪 + ε-探索的采数策略下，每回合预算 b、覆盖泛函次模，则 N 回合后的期望覆盖缺口以 O((1−1/e)^N) 量级衰减（理想化），实际受触觉覆盖半径 O(n^{−1/d_T}) 与分布漂移限制。系：**低维接触描述子不是工程细节，而是决定数据效率的核心理论变量。**

## 4. 推导

**引理 19（覆盖—可识别性）** 覆盖外模态（`s(ξ̄_k)>q_α`）的权重估计偏差不可由增大 K 消除——K→∞ 只收敛到模型自身错误的后验。故覆盖外模态须从 U_epi 假设空间剔除并记入 U_data；把覆盖外模态当「可交互消解的歧义」会带来与覆盖缺口正相关的误差下界。系：R69 的 U_epi 只在 M_cov 上有意义。

**引理 20（双用途分解与贪婪）** 覆盖泛函次模 ⇒ VoC 边际递减，贪婪触摸有 (1−1/e) 覆盖增益保证；若准入不做独立性检查，VoC 被高估约 `I(M;准入)`，ε-探索 + novelty 把偏差压至 O(ε)。

**引理 21（数据投毒准入上界）** 单源投毒率 δ_p、源间相关 ρ<1、k≥2 正交一致 + novelty ⇒ 准入概率 ≤ `δ_p·ρ^{k−1}+ε_nov`；单点对覆盖的影响受影响函数约束为 O(1/n)，高杠杆点可离线标记回滚。系：推理端证据纪律不足以防训练端幽灵模态，必须前移到数据准入。

**引理 22（三通道漂移分离）** 传感器磨损 = φ 上的平滑变换，部分被标定吸收但抬高 Δ_data；真实物体变化同时抬高 r_res 与 Δ_data；数据缺失表现为覆盖收缩（U_data↑）而 r_res/Δa 正常。故 `(r_res,Δa,Δ_data)` 可分离三类（A99–A100 下正间隔）。

**定理 18（TACIT 严格包含 FLUID）** 覆盖成立、账本干净（A101）时 TACIT 与 FLUID 逐指令相同；一般情形 U_data 只增加保守项、数据动作不改在线冻结模型 ⇒ 瞬时期望风险 ≤ FLUID，等号在覆盖边界取得。R68 ⊆ R69 ⊆ R70，安全侧不让步，收益仅经未来数据版本延迟兑现。

**定理 19（数据采集下的在线安全与无突变）** 数据动作过 C-RAS-WM + 接触扰动认证 ⇒ 物理风险 ≤ ε_touch；在线模型冻结 ⇒ 仍对同一 WM 认证；U_data>0 ⇒ λ 相对 R69 单调不降；离线换装遵循 R68 定理 15 ⇒ 控制连续、无突变。**绝不允许用「刚采了数据」给当下风险打折。**

**命题 20（覆盖收敛率）** 贪婪 + ε-探索、每回合预算 b、覆盖次模 ⇒ 期望覆盖缺口约以 `O((1−1/e)^N)` 衰减（理想化），实际受 `O(n^{−1/d_T})` 覆盖半径与分布漂移限制。系：低维接触描述子是数据效率的核心理论变量。

## 7. 本轮最大风险

**一句话**：TACIT-RAS 的可靠性押在「覆盖证书与溯源可信」上，而**触摸本身改变世界、破坏 conformal 交换性**——一旦该假设在非平稳、被对抗、接触即扰动的真实场景失效，证书可能「自信地错」，系统会拿一张**自己签发的通行证**去过度信任被投毒的数据集、或把稀缺接触预算耗在永远无法认证的覆盖空洞上——**当证书自己就是风险源时，越严谨的认证越危险**。

**次级风险与缓解**：(1) 覆盖半径大 → 持续退化 R68（低维描述子 + sim-to-real 重加权 + 主动采数）；(2) 数据到模型时延（冷启动预算 + 安全窗口换装）；(3) 自我确认（ε-探索 + novelty + 多源独立）；(4) 溯源伪造/sybil（签名 + 外部信任锚 + 回滚）；(5) 接触不可逆（扰动包络 + 非破坏优先 + 硬预算）。
