# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配×主动交互消歧」IP-253~263；灵感循环新循环第 4 轮；本轮灵感：「通用机器人平台」×「多机器人协作」）

> R69 给闭环装上了「眼」和「嘴」：把不确定性拆成 aleatoric 与 epistemic，用流匹配策略显式保留多峰动作，用 VoI 决定该不该看、该不该问、该不该触。但它有一个从未写进定义的默认前提——**只有一具身体、一个智能体、一个私有的信念**。所有关于模态、交互、认证、风险缩放的推理都写成了单数：`M` 是给定的，`o_t` 是一个视角的，`U_epi` 是一个脑袋里的，`λ_floor` 是这个脑袋对自己下的命令。
>
> 本轮两个灵感恰好把这三个「单数」同时打破：
> - **通用机器人平台**让「身体」从常量变成变量：同一套策略要服务腿、臂、轮、飞等异构本体，动作的语义、能力边界、动力学参数逐台不同。平台不是「一台更强的机器人」，而是一个**技能底座 + 本体适配 + 能力账本**。
> - **多机器人协作**让「他人」从信息源变成**有自己策略、自己目标、自己安全约束的智能体**：他们的观测既可能是你无法自己获得的新证据，也可能只是与你共享同一个盲区的回声；更要命的是，**他们的动作会反过来改变你的安全前提**。
>
> R69 的两个隐含假设在团队里同时失效：
> 1. **证据可加**：R69 用「k 个正交证据源一致」对抗投毒。团队里证据源就是队友，而队友的误差高度相关——同一模型、同一标定、同一视角、同一次分布偏移。**更多克隆不会更确定，只会更自信**。
> 2. **保守可组合**：R69 的铁律是「不确定就收紧 λ」。单机上收紧只会更慢更稳；团队里，一个机器人独立地「变保守」会破坏队友对它运动的预测，把别人的安全带变成别人的危险。**局部保守不是团队安全的充分条件，甚至不是单调的**。
>
> 核心命题：**把不确定性的单位从「个体」升级为「团队」，把安全的单位从「局部包络」升级为「承诺契约」。** 在 R69 的 (U_ale, U_epi) 之外，显式区分 **U_epi_local（自己可查）**、**U_epi_comp（只有队友能查的互补信息）**、**U_cc（共同原因导致的、加人也不会减少的相关不确定性）** 与 **U_emb（跨本体迁移的具身失配）**；用**相关性折扣融合**保证「人头数」不被误当成「独立证据数」；用**团队 VoI** 决定谁去看/问/触、以及该说什么；用 **assume-guarantee 承诺契约**让风险缩放协同，而不是各自为政；一旦相关性估计、通信新鲜度或拜占庭怀疑越界，退回「去中心化 R69 + 最坏情况分离包络」。命名 **CHORUS-RAS**（Collective Heterogeneous Open-platform Risk-aware Uncertainty-aware System）——像一支合唱团：每个人唱不同的声部才有和声，所有人唱同一句只会变成更响的独唱。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**还有谁在这里，我们看到的到底是不是同一个世界**」——不确定性不是私有财产，而是一个共享的、相关的、需要签约的对象。

## 0. 直觉与动机

**灵感 1（通用机器人平台 → 身体是变量，动作语义是函数）**
直觉：R69 的流匹配策略条件在 `z_t = Φ(o_t)` 上，默认「动作」在某个固定本体上已经有意义。可一旦策略要跨本体复用，`a` 就不再是一个向量，而是「本体 μ 下的一个可实现技能」。同样的 `(Δx, Δy, Δθ)`，对轮式底盘是可达的、对双足是难以精确执行的、对机械臂可能根本不可达。**跨本体迁移最大的风险不是性能下降，而是「身体幻觉」：策略以为自己有某个能力，而目标本体没有。** 所以平台层必须先有一本**能力账本**（capability ledger）：这台机器有哪些模态、哪些自由度、哪些安全包络、哪批标定参数。策略条件在 μ 上，动作先过能力门，再进安全认证。平台的价值不在于「一个模型包打天下」，而在于**让同一个技能在异构本体上的语义可被验证地保持**。

**灵感 2（多机器人协作 → 别人的观测是资源，也是回声）**
直觉：多机器人最诱人的地方是「多一双眼睛」。但多一双眼睛只有在它**看得不一样**时才值钱；如果两台机器人用同一个模型、同一套标定、站在同一个方向，它们的错误是同一场雾，融合只会让雾更浓。可以把队友的信息价值精确地拆成两项：**互补性**（我看不到、你能看到 → 真正的新信息）与**相关性**（我们看到的是同一个错误 → 假装的新信息）。R69 的 VoI 只算了前者，默认了后者为零。团队版 VoI 必须对相关性打折，否则整个队会陷入**回声室**：所有人追问同一个幻影模态，然后互相盖章「多个来源一致」。

**灵感 3（保守不可组合 → R69 的 λ_floor 在团队里可能害人）**
直觉：这是本轮最反直觉、也最重要的一条。单机上「不确定 → 减速」永远安全；团队里，减速会**改变队友的预测前提**。设想两台机器人接近一个路口：A 按 B 的标称速度规划「B 会先通过」；B 因为自己的 epistemic 不确定性独立地执行 λ_floor 降速，却没有通知 A；A 的前提被悄悄破坏，继续通过，于是相撞。这里 B 的每一个动作都符合 R69 的安全证书，事故却发生了——因为**安全证书是局部的，而风险是联合的**。结论不是「别保守」，而是：**保守必须可被预测、可被承诺、可被撤销**。安全接口不该是标量 λ，而应是「我承诺我接下来会落在哪个可达集里」的契约。

**灵感 4（证据纪律的团队版 → 从「k 个源」到「n_eff 个独立源」）**
直觉：R69 用「k 个正交证据源一致」把「问一次」升级为「问到一个可验证的一致」。团队里，源是队友，而队友的误差有相关矩阵 Σ。对相关高斯证据做最优线性融合，其有效独立源数是 `n_eff = 1 / (1ᵀ Σ⁻¹ 1)`；在可交换相关 `ρ` 下退化为 `n_eff = N / (1 + (N−1)ρ)`。当 `ρ→1`，`n_eff→1`：一百个克隆等于一个源。于是 R69 的「k 源一致」自然升级为「**n_eff ≥ k 才可定案**」；相关性不仅是一个统计量，更是**安全阀**——它让系统无法靠堆人头伪造信心。

**灵感 5（严格包含 → N=1 就是 R69，安全侧永不让步）**
直觉：本轮的所有团队机制都必须在「一支只有一个人的合唱团」上逐指令退化为 FLUID-RAS：没有融合、没有通信、契约退化为自身的 C-RAS-WM 前缀认证、`U_cc=U_emb=0`。这个退化不是巧合，而是设计约束：**只有当团队机制在 N=1 时完全消失，我们才有资格说它没有引入新的、需要独立信任的黑箱。** 这也是本轮的理论姿态：CHORUS 是 FLUID 的严格泛化，而不是并列替代。安全侧同样单调：一旦任何团队信任条件不满足，就退回「去中心化 R69 + 最坏情况分离」，只会更保守，不会更激进。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（CHORUS-RAS 总览）** CHORUS-RAS = (MCP, HCG, CEF, TUD, TVoI, AGC, CAA, BFT-E, CHORUS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **团队预算硬约束**：信息动作与通信消息共享一个单位时间预算；消息是动作，必须通过与任务动作相同的 C-RAS-WM 认证；
(iii) **跨智能体证据纪律**：单个智能体的报告（尤其是可能被妥协的智能体）不得单独定案，需 `n_eff ≥ k` 个有效独立源一致；`n_eff` 由相关性折扣（定义 314）计算，而不是人数；
(iv) **契约纪律**：每个智能体在执行前发布其承诺的可达集，任何会缩小该集合的保守化（λ 变化）都必须先发布契约修正并被确认；无确认则只能进入「独立分离模式」（定义 323），不得擅自改变队友的预测前提。

**定义 311（本体描述符与能力账本）** 第 `i` 台机器人的本体描述符 `μ_i = (𝒦_i, 𝒮_i, 𝒰_i, θ_i, c_i, h_i)`：运动学树 𝒦_i、传感器组 𝒮_i、执行器限制 𝒰_i、标定参数 θ_i、能力向量 `c_i ∈ {0,1}^M`（每维表示某技能/模态是否**当前**可执行）、来源哈希 h_i（固件/零件/标定版本）。能力账本 `L = {μ_i}` 是平台级只读登记；`c_i` 的更新属于学习写操作之外的结构变更，必须走离线流程。

**定义 312（本体条件流策略 MCP）** 在 R69 的 FMP 上增加本体条件：速度场 `v_θ(x_s, s | z_t, μ_i)`，主干共享、每本体一个低秩适配器（FiLM/LoRA）。`x_1 = ξ_{t:t+H}` 仍是 R69 的增广动作（任务动作 × 信息动作）。目标 `L_MCP = E‖v_θ(x_s,s|z_t,μ_i) − (x_1−x_0)‖²`。关键约束：采样后先过能力门（定义 313），再进认证；策略输出不得直接进入执行器。

**定义 313（异构能力门 HCG）** 对采样动作 `ξ=(a,g)`，定义可行性投影 `Π_{μ_i}(ξ) = argmin_{ξ' ∈ 𝒜_+(μ_i)} ‖ξ−ξ'‖`，其中 `𝒜_+(μ_i)` 是本体 i 的可实现动作集。若 `dist(ξ, 𝒜_+(μ_i)) > ε_cap`，则该动作被**掩蔽**（不是投影），并把它记为一个 `U_emb` 证据：策略对本体的能力假设出错。能力门是硬约束，不可被任何学习信号软化。

**定义 314（相关性折扣融合 CEF）** 设团队对任务模式 M 的局部证据为 `e_i = log b_i − log b_0`，误差协方差 `Σ`（对角 σ_i²，非对角 ρ_{ij}σ_iσ_j）。融合权重与有效独立源数定义为
`w = Σ⁻¹1 / (1ᵀΣ⁻¹1)`，`n_eff = 1 / (1ᵀΣ⁻¹1)`（σ=1 归一）。
可交换相关 ρ 时 `n_eff = N / (1 + (N−1)ρ)`。团队后验按 `log b_team = log b_0 + n_eff · Σ_i w_i e_i` 更新，且证据计数以 `n_eff` 而非 N 计入定义 310-iii。`ρ→0` 时 `n_eff=N`（独立源全值）；`ρ→1` 时 `n_eff=1`（克隆坍缩为一个源）。这是 R69「k 正交源」的严格推广。

**定义 315（团队不确定性四分）** 在 R69 的 `(U_ale, U_epi)` 之上，把 `U_epi` 按「谁能消解」拆开，并新增一个跨本体项：
- `U_ale`：逐智能体的不可约噪声（继承，按合同合成，见定义 322）；
- `U_epi_local = H(M|o_i)` 中可由 i 自己的信息动作消解的部分（继承 R69 的 MINT 通道）；
- `U_epi_comp = I(M; o_j | o_i)` 中**只有 j 的视角/模态能提供**的互补信息（跨智能体可消解）；
- `U_cc = H(M)` 中在 `N→∞` 克隆极限下仍残留的部分（共同原因/共享模型/共享标定/重叠视角），是相关性造成的**熵地板**；
- `U_emb = H(skill | μ_i, o_i)`：该技能在本体 i 上能否按语义实现的不确定性。
四者语义不同，不做简单加和；`U_cc` 与 `U_emb` 不能靠「再多一个同类队友」消除。

**定义 316（团队 VoI 分配 TVoI）** 给定候选信息动作 `g` 与其执行者 `j`、消息集合 `Y`，团队信息增益
`VoI(j,g) = H(b_team) − E_{y∼p(·|j,g,o)}[H(b_team | y)]`，
其中 `b_team` 由 CEF（定义 314）计算，因此与 `j` 对团队的相关性自动打折。分配
`σ* = argmax_{σ: agents→g∪∅} Σ_i [VoI(i,σ(i)) − c_info(σ(i))] − c_comm(Y)`
s.t. 预算不超、每个 `g` 过定义 313 能力门与定义 318 契约认证。若 `max ≤ 0`：全队不交互，逐机走 R69 兜底。系：**同质队友的边际 VoI 随 ρ 递减**，最优分配会自然倾向「派看得不一样的去」，而不是「所有人都去看」。

**定义 317（assume-guarantee 承诺契约 AGC）** 每个智能体 i 发布契约 `C_i = (A_i, G_i, T_i)`：在假设 `A_i`（对队友可达集的界）下，保证自身在 `T_i` 时域内落在 `G_i`。团队契约一致当且仅当对每个 i，实际队友行为 `⊆ A_i`，且 `∩_i G_i` 与联合危险集 `𝒟` 不相交。契约一经发布即对 `T_i` 生效；修改只能通过「修正—广播—确认」三阶段，确认前旧契约仍然约束自己。

**定义 318（协调不变式）** 任何改变 `λ_i`（保守度）或 `G_i` 的动作，必须满足：要么 `A_i` 对其他智能体**只放宽不放宽到危险**（即 `G_i` 在旧 `A_i` 下仍安全），要么先完成契约修正。禁止「静默降速」：单方面变得更保守也属于对队友预测前提的改变，必须广播。这是「局部保守不可组合」（引理 20）的直接工程回应。

**定义 319（通信即动作 CAA）** 消息 `y_{ij}` 是动作：有大小上界、时间戳、来源认证（h_i 签名）、有效期 `τ_msg`；必须过 C-RAS-WM 的「无害性认证」——任何消息不得诱导接收方进入其无法在自身包络内安全执行的契约。过期消息不得用于认证契约，只能用于降低置信。通信丢包/延迟按定义 323 的分离模式处理。

**定义 320（拜占庭团队模型 BFT-E）** 至多 `f` 个智能体可拜占庭：撒谎、重放、伪造能力、合谋（误差相关 `ρ_B`）、以「多数」名义压迫少数。证据纪律要求 quorum `q > (n+f)/2` 且 `n_eff ≥ k`；在认证通信与有效期内，`n ≥ 3f+1` 是达成一致并容忍 f 个拜占庭的充分条件。F 个合谋者的错误率上界沿用 R69 引理 18 的 `δ_p·ρ_B^{k−1}`，但 `ρ_B` 现在可被人为抬高（共谋），故必须用**来源多样性**（不同厂商/不同模态/不同视角）而不是来源数量来降低它。

**定义 321（多智能体预测适配 CHORUS-WM†）** 在 R68/R69 的世界模型之上增加一个**队友意图/可达集头**：`p(ẑ_{t+1}, A_j | o_i, M, C_j)`。它只预测「队友承诺的可达集与模式」，不预测队友的私有目标；其输出直接进入契约验证。预测不确定性高时，`A_j` 取最坏情况（定义 323），而不是用均值糊过去。

**定义 322（团队风险缩放与两级退避）** 每个智能体的风险缩放
`λ_i = max(λ_floor(U_ale^i + U_epi_local^i + U_epi_comp^i), λ_contract(C_i))`，
其中 `λ_contract` 由契约一致性求解器给出，使得「在 `A_i` 下、且队友遵守各自 `G_j`」时联合风险最小；`U_cc` 不进入单个 λ，而是进入**团队级**的保守决策（定义 323），因为它是共享的、无法由个体动作消解。若团队信息消解成功：`λ` 可低于 R69 的个体 floor（resolution bonus）；若 `n_eff<k`、通信过期、拜占庭怀疑或契约不一致：进入定义 323。

**定义 323（独立分离模式）** 当任何团队信任条件失效时，每个智能体退回「去中心化 R69 + 最坏情况分离包络」：`A_j^{worst} =` 队友在自身证书内的全部可达集（不假设任何合作），`G_i` 取与 `A_j^{worst}` 保持 `d_sep` 的分离集；`λ = λ_floor(U_ale + U_epi_local + U_epi_comp + U_cc + U_emb)`（未消解项全部视同 aleatoric）。该模式不依赖通信、不依赖相关性估计、不依赖队友诚实，因而永远可用；它比 R69 单机更保守，是本轮的安全下界。

**定义 324（分布式证书 J_CHORUS）** `J_CHORUS = (J_FLUID^1..N, contract_set_hash, rho_hat, n_eff, U_cc_before/after, U_emb_flags, comm_log_hash, bft_quorum, chorus_ver)`。Valid ⇔ 每个 `J_FLUID^i` valid ∧ 契约集合一致 ∧ `ρ_hat` 在信任域内 ∧ 通信新鲜 ∧ quorum 达标。

**定义 325（团队攻击族 AIC-CHORUS）** `ℰ_CHORUS = ℰ_FLUID × ℰ_corr × ℰ_cap × ℰ_comm × ℰ_byz`：相关性投毒（伪造独立源）、回声室（同质队友反复确认幻影）、能力伪造（声称自己能做但做不到）、通信延迟/重放/中间人、拜占庭合谋与「少数正确者被多数压」。并入 AIC 作为团队级对抗训练集。

**定义 326（相关性信任域）** 在线估计 `ρ_hat` 必须带分布无关上界：`|ρ_hat − ρ| ≤ ε_ρ(t)`，其中 `ε_ρ` 随有效样本数递减，并受「来源多样性审计」约束（同厂商/同模型/同固件的来源先验相关更高）。`ε_ρ > ε_ρ,max` 或来源多样性低于阈值时，`ρ_hat` 不可信，直接进入定义 323，不允许用可能被投毒的相关性估计去「证明独立」。

class MorphologyConditionedPolicy:
    def __init__(self, trunk, velocity_net, adapter_bank, cap_gate, N_step=2):
        self.trunk  = trunk                    # 复用 R69 MTM / FMP 条件编码
        self.v      = velocity_net             # v(x_s, s, z, mu)
        self.adapt  = adapter_bank             # mu -> LoRA/FiLM 参数
        self.gate   = cap_gate                 # 定义 313 能力门

    def sample(self, o_t, mu, K, N_step=2):
        z  = self.trunk(o_t)
        xs = randn(K, D)
        for i in range(N_step):
            xs = xs + (1.0/N_step) * self.v(xs, i/N_step, z, mu, self.adapt[mu])
        xi = [self.decode(x) for x in xs]
        return [self.gate.filter(x, mu) for x in xi]   # 不可行 -> 掩蔽并记 U_emb

# IP-266 CEF：相关性折扣融合（n_eff 而非人头数）
def correlate_fuse(evidence, Sigma):
    S    = robust_inverse(Sigma)                    # 带信任域收缩的定义 326
    w    = S @ ones / (ones @ S @ ones)
    n_eff= 1.0 / (ones @ S @ ones)                  # 可交换时 N/(1+(N-1)rho)
    return fuse_log_opinions(evidence, w, n_eff), n_eff

# IP-267 TUD：团队不确定性四分（在 R69 AUD 之上）
def team_decompose(per_agent_modes, evidence, Sigma):
    U_ale      = [aleatoric(m) for m in per_agent_modes]
    U_comp     = conditional_mutual_info(evidence)  # I(M; o_j | o_i)
    n_eff      = 1.0 / (ones @ robust_inverse(Sigma) @ ones)
    U_cc       = floor_entropy(Sigma)                # N->inf 仍残留的熵地板
    U_emb      = sum(flag.masked_infeasible)         # 能力门掩蔽证据
    return U_ale, U_comp, U_cc, U_emb, n_eff

# IP-268 TVoI：跨智能体信息动作与消息分配（相关性感知）
def team_voi(agents, modes, Sigma, budget):
    best = None
    for (j, g) in info_action_candidates(agents, modes):   # 看/问/触 + 谁说
        if not budget.allow(g) or not cap_gate.feasible(j, g): continue
        if not c_ras_wm.certify_info(j, g): continue
        voi = team_entropy(Sigma) - expected_team_entropy(Sigma, j, g)
        score = voi - cost(j, g) - comm_cost(j, g)
        if best is None or score > best.score: best = (j, g, score)
    return best if best and best.score > 0 else None        # 无利可图 -> R69

# IP-269 AGC：承诺契约的发布、验证与修正
def propose_contract(i, A_i, G_i, horizon):
    return sign(i, (A_i, G_i, horizon))

def contracts_consistent(C):
    return all(actual_behaviour(j) in C[i].A_i for i in C for j in C if j != i) \
       and disjoint(intersect(c.G for c in C), dangerous_set)

# IP-270 CAA：通信即动作（认证 + 有效期 + 无害性）
def send(i, j, y, t):
    msg = sign(i, (y, t, embodiment_hash(i)))
    if not c_ras_wm.nonhazardous(msg, receiver=j): return DROP
    return transmit(msg)                    # 过期消息只能降置信，不能认证契约

# IP-274 主闭环（继承 R69，团队处插入 CHORUS 层）
def CHORUS_RAS_round(i, obs, team):
    # 0) 团队证据融合：用 n_eff 而非人数决定是否定案
    b_i        = team.local_belief(i, obs)
    b_team,neff= correlate_fuse(team.evidence(), team.Sigma_hat)
    U_ale,U_comp,U_cc,U_emb,neff = team_decompose(...)
    trust_ok   = (neff >= K_MIN) and team.rho_in_trust_region() \
                 and team.comm_fresh() and team.bft_quorum_ok()
    # 1) 跨本体策略 + 能力门（防身体幻觉）
    K   = 1 if team.mode_head(obs) < TAU_MODE else 4
    xi  = team.mcp.sample(obs, team.mu[i], K)      # 不可行动作已被掩蔽
    # 2) 团队 VoI：决定谁去看/问/触、谁发什么消息
    g   = team.tvoi.choose(team.agents, xi, team.Sigma_hat, team.budget) if trust_ok else None
    if g is not None:
        y = team.caa.execute_and_listen(g)          # 认证通信 + 证据纪律
        b_team,neff = team.cef.update(b_team, y)
        U_comp, U_cc = team.tud.after_interaction(...)
    # 3) 契约优先的风险缩放：保守必须可被预测
    C_i = team.agc.propose(i, A_i=team.WM.predict_reachable(team.peers),
                              G_i=team.safe_envelope(xi, U_ale+U_comp))
    if trust_ok and team.agc.contracts_consistent(team.contracts + [C_i]):
        lam = max(team.efs.risk_scale(...),  # R69 效率侧
                  lam_contract(C_i, team.contracts),   # 协调解，可低于个体 floor
                  lam_floor(sum(U_ale) + U_comp + U_cc))  # 未消解项兜底
    else:
        lam = team.separation_mode(i, U_ale, U_comp, U_cc, U_emb)  # 定义 323
        C_i = team.agc.conservative_contract(i, lam)
    # 4) 执行 + 分布式证书
    k   = team.c_ras_wm.certified_prefix(xi, C_i, team.wm_preds)
    mode= team.select_mode(xi, b_team, lam)
    tau = team.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    team.cert.emit(i, J_CHORUS(...))               # 契约哈希 + rho + n_eff
    return k, lam, mode, (U_ale, U_comp, U_cc, U_emb, neff)

## 3. 推导

**引理 19（相关性的信息饱和）** 设 N 个智能体对同一标量的估计误差方差 σ²、两两相关 ρ∈[0,1]，则均值估计方差 `Var = σ²[1+(N−1)ρ]/N`，有效独立源数 `n_eff = N/[1+(N−1)ρ]`，可获得的熵下降 `ΔH ≤ ½ log(1 + n_eff·SNR)`。当 `N→∞`，`Var→ρσ²`，`n_eff→1/(1−ρ)`（ρ<1）或 1（ρ=1）。系：**团队信息增益随人数饱和在相关性地板上**；要越过该地板，唯一途径是降低 ρ（异构模态、异构视角、异构本体、异构供应商），而不是增加同质成员。这直接解释了「多机器人 ≠ 更多信息」。

**引理 20（局部保守不可组合）** 存在两智能体协同场景与安全泛函 `S(λ_1,λ_2)`，使得在某个区域 `∂S/∂λ_i < 0`：单独提高 i 的保守度会降低团队安全性。构造（路口让行）：A 依据 B 的名义速度规划「B 先过」，B 独立执行 `λ_floor` 降速却不广播；A 的假设被破坏，双方同时进入冲突区。要点：安全证书的语义是「给定队友行为」，而独立 λ 改变的正是队友行为的可预测性。推论：团队安全不能靠逐机更保守获得，必须通过契约把「保守」变成**可观测、可承诺、可撤销**的公共信息（定义 317–318）。

**引理 21（能力劫持与能力门）** 若策略条件于 μ 且动作过能力门（定义 313），则「发出本体不可执行动作」的概率为 0；若去掉能力门，存在跨本体迁移场景使共享策略对目标本体赋予正概率的不可行动作（例如把「抓握」迁移到无夹爪本体）。系：`U_emb` 是跨本体迁移的结构性不确定性，只能由能力账本 + 硬门控消除，不能由更多数据平均掉——这与 R69 的 `U_epi` 有本质区别。

**引理 22（拜占庭团队的一致性上界）** 在认证通信、消息有效期内，若 `n ≥ 3f+1` 且 quorum `q > (n+f)/2`，则最多 f 个拜占庭智能体不能使诚实的 `n_eff` 证据被伪造成「一致」；合谋者把 `ρ_B` 抬高时，其有效票数为 `n_eff(ρ_B)` 而非 f，故 `ρ_B→1` 时合谋等价于**一个**欺骗源，由 `n_eff ≥ k` 拦截。系：定义 320 把 R69「k 正交源」升级为「n_eff 独立、且 quorum 过 Byzantine 界」。

**定理 18（契约合成的团队安全）** 若 (a) 所有契约在乘积空间一致，(b) 通信认证且新鲜，(c) `ρ_hat` 在信任域内且 `|ρ_hat−ρ|≤ε_ρ`，则团队碰撞概率 `≤ Σ_i ε_i + ε_comm + ε_ρ·L_ρ`；若 (a)(b)(c) 任一失败，系统在定义 323 的分离模式下运行，团队安全仍成立（以 `d_sep` 与更保守的 λ 为代价）。证明要点：一致契约把联合安全化为逐契约的 assume-guarantee 归纳；失败时最坏情况可达集覆盖一切可能队友行为，故安全性与通信/诚实性解耦。**安全侧永不弱于 R69**，因为分离模式的 λ 包含全部未消解项。

**定理 19（CHORUS 严格包含 FLUID/R69）** 当 `N=1`（或所有队友不可达）时，`Σ` 退化、`n_eff=1`、`U_cc=U_emb=0`、契约退化为自身 C-RAS-WM 前缀认证，CHORUS 逐指令等于 FLUID-RAS；当所有 `ρ=1`（完全同质）时 `n_eff=1`，证据纪律退化为「单源不得定案」，系统自动选择不融合/不交互，等价于 R69 的保守边界。因此 CHORUS 在安全侧是 FLUID 的严格泛化，效率侧仅在「真正独立或互补」的信息上获得 resolution bonus。

**定理 20（团队信息效率的多样性支配）** 在固定通信预算下，TVoI 的最优分配满足：当新增一个与现有成员相关性 ρ 的成员时，其边际团队 VoI 为 `ΔVoI ∝ (1−ρ)/(1+(N−1)ρ)` 量级，单调递减于 ρ 且饱和于 N。故在 `ρ` 高的团队里，最优策略是**换模态/换视角/换本体**，而不是**加人**；这是对「多机器人协作 = 堆数量」的正式否定，也是平台层应当鼓励本体与传感器异构的理论依据。

## 6. 本轮最大风险

**一句话**：CHORUS 的全部效率收益押在「`ρ_hat` 诚实地反映了队友误差的真实相关性」这一前提上——**若团队因共享模型/共享标定/共享视角而高度相关，系统却把彼此当成独立证据（或攻击者投毒相关性估计），融合就会给出一个被人数放大的过度自信后验，全队会同时、自信地错向同一个幻影；契约层还会为这个错误盖上「已协调」的章。** R69 的风险是「问错比不问更危险」，R70 的风险升级为「**一起错，比一个人错更危险**」——回声室是幻影模态的团队版本，而合唱团最可怕的失败不是跑调，是**所有人跑同一个调还以为在和声**。

**次级风险与缓解**：
1. **相关性投毒/回声室** → 定义 326 信任域 + 来源多样性审计 + E303/E305；`ρ` 不可信即进分离模式；
2. **保守不可组合** → 定义 317–318 契约纪律 + 引理 20 + E308，禁止静默降速；
3. **能力伪造/身体幻觉** → 定义 313 硬能力门 + 引理 21 + E301/E302，门控不可学习软化；
4. **拜占庭合谋** → 定义 320 quorum + `n_eff` 证据纪律 + 定理 22/E310；
5. **通信断链/过期** → 定义 319 有效期 + 定义 323 分离模式 + 定理 18，安全与通信解耦。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** CHORUS-RAS = (MCP,HCG,CEF,TUD,TVoI,AGC,CAA,BFT-E,CHORUS-WM†)；零学习写操作继承；团队预算（信息动作与消息共享、消息也过 C-RAS-WM 认证）；跨智能体证据纪律（单源不得定案，需 `n_eff ≥ k`）；契约纪律（保守化必须先广播确认，否则只能进分离模式）。

**定义 311–313（本体描述、MCP、能力门）** `μ_i` 含能力向量与来源哈希；速度场条件于 μ，主干共享 + 低秩适配；采样后先过硬能力门 `Π_{μ_i}`，不可行动作被掩蔽并记为 `U_emb`。门控不可被学习信号软化。

**定义 314（CEF）** 融合权重 `w = Σ⁻¹1/(1ᵀΣ⁻¹1)`，有效独立源 `n_eff = 1/(1ᵀΣ⁻¹1)`；团队后验 `log b_team = log b_0 + n_eff·Σ w_i e_i`；可交换相关时 `n_eff = N/(1+(N−1)ρ)`。证据计数用 `n_eff`，不用人数。

**定义 315（不确定性四分）** `(U_ale, U_epi_local, U_epi_comp, U_cc, U_emb)`；语义不同、分通道处置；`U_cc` 与 `U_emb` 不能靠增加同质队友消除。

**定义 316（TVoI）** `VoI(j,g)=H(b_team)−E[H(b_team|y)]`，以 CEF 后验计算故对相关性自动打折；`σ*=argmax Σ[VoI−c_info]−c_comm`，s.t. 预算/能力门/契约认证；`max≤0` → 全队不交互，走 R69。

**定义 317–318（AGC 与协调不变式）** `C_i=(A_i,G_i,T_i)`；团队一致 ⇔ 实际队友行为 ⊆ A_i 且 `∩G_i ∩ 𝒟 = ∅`；修改走「修正—广播—确认」，确认前旧契约仍约束自己；禁止会破坏队友前提的单方面降速。

**定义 319（CAA）** 消息有大小/频率预算、时间戳、来源签名、有效期 `τ_msg`；须过「无害性认证」，不得诱导接收方越出其契约；过期消息只能降置信、不能认证契约。

**定义 320（BFT-E）** 至多 f 个拜占庭，可撒谎/重放/伪造能力/合谋；`n≥3f+1`、`q>(n+f)/2`、`n_eff≥k`；合谋抬高 `ρ_B` 时按有效票数计，`ρ_B→1` 时合谋等价于单源，被 `n_eff≥k` 拦截。

**定义 321–323（WM、团队 λ、分离模式）** CHORUS-WM† 预测队友可达集/模式而非私有目标；`λ_i=max(λ_floor(U_ale+U_local+U_comp), λ_contract)`；失败时进入去中心化 R69 + 最坏情况分离包络，λ 包含全部未消解项，安全与通信/诚实性解耦。

**定义 324–326（证书、攻击族、信任域）** `J_CHORUS=(J_FLUID^1..N, contract_set_hash, rho_hat, n_eff, U_cc_before/after, U_emb_flags, comm_log_hash, bft_quorum, chorus_ver)`；`ℰ_CHORUS=ℰ_FLUID×ℰ_corr×ℰ_cap×ℰ_comm×ℰ_byz`；`ρ_hat` 必须带分布无关上界与来源多样性审计，越界即进分离模式。

class MorphologyConditionedPolicy:
    def sample(self, o_t, mu, K, N_step=2):
        z  = self.trunk(o_t)
        xs = randn(K, D)
        for i in range(N_step):
            xs = xs + (1.0/N_step) * self.v(xs, i/N_step, z, mu, self.adapt[mu])
        return [self.gate.filter(self.decode(x), mu) for x in xs]   # 不可行 -> 掩蔽 + U_emb

class CapabilityGate:
    def filter(self, xi, mu):
        if dist(xi, A_plus(mu)) > EPS_CAP:
            return MASKED(xi, reason="U_emb")     # 绝不投影成危险近似
        return project(xi, A_plus(mu))

# IP-266 CEF：相关性折扣融合
def correlate_fuse(evidence, Sigma):
    S     = robust_inverse(Sigma)                  # 定义 326 信任域收缩
    w     = S @ ones / (ones @ S @ ones)
    n_eff = 1.0 / (ones @ S @ ones)                # 可交换: N/(1+(N-1)rho)
    return fuse_log_opinions(evidence, w, n_eff), n_eff

# IP-267 TUD：团队不确定性四分
def team_decompose(modes, evidence, Sigma):
    U_ale  = [aleatoric(m) for m in modes]
    U_comp = conditional_mutual_info(evidence)     # I(M; o_j | o_i)
    n_eff  = 1.0 / (ones @ robust_inverse(Sigma) @ ones)
    U_cc   = floor_entropy(Sigma)                  # N->inf 仍残留
    U_emb  = sum(m.masked for m in modes)
    return U_ale, U_comp, U_cc, U_emb, n_eff

# IP-268 TVoI：跨智能体信息动作/消息分配
def team_voi(agents, modes, Sigma, budget):
    best = None
    for (j, g) in info_action_candidates(agents, modes):
        if not budget.allow(g) or not cap_gate.feasible(j, g): continue
        if not c_ras_wm.certify_info(j, g): continue
        score = (team_entropy(Sigma) - expected_team_entropy(Sigma, j, g)) \
                - cost(j, g) - comm_cost(j, g)
        if best is None or score > best.score: best = (j, g, score)
    return best if best and best.score > 0 else None     # 无利可图 -> R69

# IP-269 AGC：承诺契约与协调风险缩放
def propose(i, A_i, G_i, T):
    return sign(i, (A_i, G_i, T))

def contracts_consistent(C):
    return all(actual_behaviour(j) in C[i].A_i for i in C for j in C if j != i) \
       and disjoint(intersect(c.G for c in C), dangerous_set)

def coordinated_lambda(i, C, U):

        return max(efs.risk_scale(...), lam_contract(C[i], C),
                   lam_floor(sum(U.ale) + U.comp))       # 可获 resolution bonus
    return separation_lambda(U)                          # 定义 323

# IP-270 CAA：通信即动作
def send(i, j, y, t):

    if not c_ras_wm.nonhazardous(msg, receiver=j): return DROP
    return transmit(msg)                                 # 过期只降置信，不认证契约

## 4. 推导

**引理 19（相关性信息饱和）** N 个方差 σ²、两两相关 ρ 的估计，均值方差 `σ²[1+(N−1)ρ]/N`，`n_eff = N/[1+(N−1)ρ]`，`ΔH ≤ ½log(1+n_eff·SNR)`；`N→∞` 时 `Var→ρσ²`、`n_eff→1/(1−ρ)`（ρ<1）或 1（ρ=1）。系：团队信息增益饱和在相关性地板上，越过它只能靠降低 ρ（异构模态/视角/本体/供应商），不能靠加同质成员。

**引理 20（局部保守不可组合）** 存在两智能体场景使 `∂S/∂λ_i < 0`：A 依据 B 名义速度规划「B 先过」，B 独立降速且不广播，A 前提被破坏后双方进入冲突区。系：独立 λ_floor 不是团队安全的充分条件，必须把保守变成可观测/可承诺/可撤销的公共信息。

**引理 21（能力劫持与能力门）** 条件于 μ 且过能力门 ⇒ 发出不可行动作的概率为 0；去门控则存在迁移场景使共享策略对目标本体赋予正概率不可行动作。系：`U_emb` 是结构性不确定性，只能由能力账本 + 硬门控消除。

**引理 22（拜占庭一致性上界）** 认证通信 + 有效期内，`n≥3f+1` 且 `q>(n+f)/2` ⇒ f 个拜占庭不能伪造 `n_eff` 一致；合谋抬高 `ρ_B` 时按有效票数计，`ρ_B→1` 时等价单源，被 `n_eff≥k` 拦截。

**定理 18（契约合成的团队安全）** 契约一致 + 通信认证新鲜 + `ρ_hat` 在信任域内 ⇒ 团队碰撞概率 `≤ Σε_i+ε_comm+ε_ρL_ρ`；任一失败则在分离模式下仍安全（代价是 `d_sep` 与更保守 λ）。安全侧永不弱于 R69。

**定理 19（CHORUS 严格包含 FLUID/R69）** `N=1` 或队友不可达时 `Σ` 退化、`n_eff=1`、`U_cc=U_emb=0`、契约为自身前缀认证 ⇒ 逐指令等于 FLUID；`ρ=1`（完全同质）时 `n_eff=1`，证据纪律退化为「单源不得定案」，自动走 R69 保守边界。故 CHORUS 是 FLUID 的严格泛化。

**定理 20（多样性支配）** 固定通信预算下，新增与现有成员相关性 ρ 的成员，其边际 VoI 约 `∝ (1−ρ)/(1+(N−1)ρ)`，递减于 ρ、饱和于 N；故高 ρ 团队的最优策略是换模态/视角/本体，而不是加人。这是「多机器人协作 ≠ 堆数量」的正式表述，也是平台层应鼓励异构的理论依据。

## 7. 本轮最大风险

**一句话**：CHORUS 的全部效率收益押在「`ρ_hat` 诚实反映队友误差的真实相关性」这一前提上——**若团队因共享模型/共享标定/共享视角而高度相关，系统却把彼此当成独立证据（或攻击者投毒相关性估计），融合就会给出一个被人数放大的过度自信后验，全队会同时、自信地错向同一个幻影；契约层还会为这个错误盖上「已协调」的章。** R69 的风险是「问错比不问更危险」，R70 升级为「**一起错，比一个人错更危险**」——回声室是幻影模态的团队版本，合唱团最可怕的失败不是跑调，是所有人跑同一个调还以为在和声。

**次级风险与缓解**：相关性投毒/回声室（定义 326 信任域 + 来源多样性审计 + E303/E305，ρ 不可信即进分离模式）；保守不可组合（定义 317–318 契约纪律 + 引理 20 + E308）；能力伪造/身体幻觉（定义 313 硬门控 + 引理 21 + E301/E302）；拜占庭合谋（定义 320 quorum + `n_eff` 纪律 + 引理 22/E310）；通信断链/过期（定义 319 有效期 + 定义 323 分离模式 + 定理 18，安全与通信解耦）。
