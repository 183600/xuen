# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；灵感循环第 6 轮；本轮灵感：「多模态大模型」×「仿真到现实迁移」）

> 第 59 轮把「证据」一路拽到了物理执行层：BUQ 辨识电机结构性不确定性、ERTC 把嵌入式抖动契约化、EEIS 把高层 δ_f 编译成阻抗硬约束、CLEP 让执行实测成为第 5 个模态并回传执行证据。但整条论证链仍有两个**上游污染源**未治：**多模态大模型（MLLM）**能提供开放世界语义、语言条件化任务理解，却输出**不可证伪的自由文本**（幻觉、谄媚、分布漂移、无校准不确定性）；**仿真到现实迁移（Sim2Real）**能提供近乎无限、廉价、可反事实的证据，其价值却完全取决于**现实鸿沟 Δ_sim→real 的可辨识性与可迁移性**（鸿沟状态相关、任务相关、随磨损漂移）。本轮核心命题：**「把语义先验降级为可证伪提案，把仿真先验降级为带迁移证书的预测；信任不再是融合权重，而是可审计的样本外预测误差；现实探针是唯一裁判」**——实现**先验只能提议、现实负责裁决（prior proposes, reality disposes）**。这标志着系统从「执行接地」升级为「**双重接地（语义接地 + 迁移接地）**」。

核心矛盾：
- **H32（语义 oracle 泄漏·不可证伪性）**：MLLM 的输出是自然语言/标签，不携带可验证语义；把「MLLM 说是海绵」当模态证据，等于把证据层最痛恨的「自洽幻觉」从 KG 搬到了大模型。**幻觉的载体变了，但认识论错误一模一样**。语义必须先被分解为可被物理探针证伪的原子命题，否则只能影响「看哪里/试什么」，绝不能入证据门。
- **H33（仿真证据循环性·现实鸿沟）**：仿真/数字孪生给的是「模型对模型的证明」。若把仿真证据当独立佐证，就是在用同一个建模假设自证；若完全不信仿真，又丢失其最大价值——廉价反事实与危险场景覆盖。唯一的出路是把鸿沟 Δ 当成**可辨识、可认证、需续约**的算子，域内可信、域外降级。
- **H34（先验相关性的伪独立·双重同源）**：MLLM 与仿真的「双重确认」可能只是「**双重同源**」——共享训练数据、共享物理假设、共享盲区。两个同源先验在同一错误上一致，会产生「超证据」的错觉（贝叶斯因子被重复计数），而现实探针预算有限，覆盖不到共识盲区。**独立性的幻觉比单个先验的错误更致命**。

## 0. 直觉与动机

**灵感 1（多模态大模型 → 语义先验的「证伪提案」化 SGC）**
直觉：不要再问「MLLM 说了什么」，而要问「MLLM 这句话能不能被一个物理探针在预算内证伪」。MLLM 真正擅长的是提出**可检验的假设**（「这个物体是可变形海绵，接触应表现为低刚度、大迟滞」），而不是提供证据。于是：把 MLLM 输出经解析器 Π 分解为**原子命题集** P={p_i}，每个命题配一个物理验证器 V_i 与**预注册接受域** A_i；只有能落到 V_i 的命题进入**接地集 G**，其余进入**未接地集 U**，只影响注意/提案（权重 λ_prop），绝不进入信念或证据门。这就是**语义接地契约（SGC）**。接地率 g_sem=|G|/|P| 成为语义可用性的硬指标。

**灵感 2（仿真到现实迁移 → 现实鸿沟算子与迁移证书 RGIT）**
直觉：sim 与 real 的差不是一个标量，而是一个**状态-动作条件化的残差算子** Δ(s,a;θ_gap)：f_real = f_sim + Δ + ε。用**配对探针**（同一 (s,a) 在 sim 与 real 各执行一次，real 侧走第 59 轮 CLEP 执行契约）辨识 θ_gap（GP/BNN 后验），得到**迁移证书** Cert_transfer=(θ_gap, Ω_cert, α_gap, T_renew, version)：在认证域 Ω_cert 内预测误差有界（UCB_Δ≤Δ_max 且配对覆盖密度≥ρ_min），域外仿真证据一律降级为「先验」，只可提议、不作佐证。Δ 随磨损/温度/任务漂移，故证书必须**在线续约**，过期即域外。

**灵感 3（合流 → 可证伪接地假设 FGH）**
直觉：语义先验与仿真先验不是两个「证据源」，而是两个「猜测源」。把它们统一为**可证伪接地假设** h=(P_G, ŷ_sim, τ_test, A_test, R_falsify, cost_ground)：语义提出期望，仿真给出同量纲数值预测，现实探针给出裁判。证据不再是「融合两个模型」，而是**核算两个模型的样本外预测误差**——预测对了信任上升，预测错了精确定位是语义错、仿真错、还是现实异常。假设可执行当且仅当 τ_test 能在接地预算内完成且风险<δ_ground；不可执行者退回提案集。

**灵感 4（信任=样本外预测误差 PEAL）**
直觉：用**预测误差账本**替代「融合权重」。对每个先验源 k∈{sem,sim,learned}，在当前上下文 φ（任务/区域/物体类别）下维护**适当评分规则**（CRPS/log score）的滚动样本外误差 E_k(φ)，信任 w_k(φ)=σ(β(E_ref−E_k))·conf(n_k)，且**证伪时快降、证实时慢升**（非对称，防「一次侥幸全信」）。独立性可被审计：两源在同一探针上的误差序列相关性 ρ_err 高 ⇒ 判为同源，有效独立证据数 n_eff=n/(1+(m−1)ρ_err)，**双重确认不计双倍证据**。

**灵感 5（接地预算 B_ground 与「先杀共识」主动接地）**
直觉：现实探针是唯一裁判但昂贵（时间/风险）。新增**接地预算 B_ground**。主动接地选择**证伪价值/成本**最高的假设优先验证，但反直觉地**优先验证「两先验都同意、风险高、却从未独立验证」的共识命题**——因为分歧本身已暴露不确定性，而共识错误没有任何第二裁判。策略：高风险共识簇（consensus cluster）强制审计配额 + 其余按 GV=falsify_value/cost 排序。B_ground 耗尽 ⇒ 动作切保守，且未审计共识的置信度按审计率 q_audit 打折。

**灵感 6（三/四通道合流 → 双向接地闭环 DGCL）**
直觉：SGC 给接地命题、RGIT 给带证书的预测、FGH 给可证伪假设、PEAL 给信任与去相关、B_ground 给预算——用一个算子串成闭环：**提案 → 主动选探针 → 现实裁决 → 误差入账 → 去相关重估 → 交回 CLEP/EEIS 重编译**。三条安全单向通道延续（信念更准、不确定性更大、动作更保守），并新增一条铁律：**先验一致性不能降低探针/佐证需求；先验只能「提议」，不能「替代」证据**。

## 1. 形式化定义（增量：定义 153–160）

**定义 153（语义接地契约 SGC）** MLLM 输出 y_LLM 经解析器 Π 分解为原子命题集 P=Π(y_LLM)={p_i=(subject, relation, value, context, type)}_{i=1..m}。接地映射 Γ: P→G∪U：p_i∈G 当且仅当存在可执行验证器 V_{type}，且 V 能给出**预注册接受域** A_i（事后不可修改）。接地率 g_sem=|G|/|P|。接地命题的语义似然经 Mondrian 保形校准：
```
L_sem(p_i | θ, ξ) = c_i(p_i),  c_i = 1 − p_value_conformal(p_i, 𝒟_calib, group=type)
```
未接地语义对信念的注入被严格限幅：仅进入提案/注意，总变差影响 ≤ λ_prop·(1−g_sem)，且**不改变任何证据门判定**。

**定义 154（现实鸿沟算子与迁移证书 RGIT）** 残差动力学 Δ: S×A×Θ_gap→ℝ^{n_s}，f_real(s,a)=f_sim(s,a)+Δ(s,a;θ_gap)+ε_gap，ε_gap~N(0,Σ_gap(φ))。配对集 𝒟_pair={(s_j,a_j,x_sim_j,x_real_j)}，θ_gap 用 GP/BNN 后验辨识。迁移证书：
```
Cert_transfer = (θ_gap, Ω_cert, α_gap, T_renew, version)
Ω_cert = { (s,a) : UCB_Δ(s,a;α_gap) ≤ Δ_max ∧ coverage_density(s,a) ≥ ρ_min }
```
`is_transferable(s,a) ⇔ (s,a)∈Ω_cert ∧ age(Cert_transfer) ≤ T_renew`。域外/过期 ⇒ sim 证据降级为先验（权重 λ_sim_prior），**不作佐证、不减少探针需求**。

**定义 155（可证伪接地假设 FGH）** 假设 h=(P_G, ŷ_sim, τ_test, A_test, R_falsify, cost_ground)。P_G⊆G 为接地命题；ŷ_sim 为 sim 对同量纲量的预测（若可映射；不可映射则 ŷ_sim=∅）；τ_test 为现实探针统计量；A_test 为接受域；R_falsify 为预注册证伪判据（如「τ_test 落在 A_test 外的极端分位」）。h 可执行 ⇔ τ_test 可在 B_ground 内完成 ∧ risk(τ_test)≤δ_ground。可执行假设集 H_exec={h}；否则退回提案集。

**定义 156（预测误差账本 PEAL 与有效独立证据数）** 对源 k∈{sem,sim,learned}、上下文 φ，滚动样本外误差：
```
E_k(φ) = rolling_mean( proper_score(y_true, ŷ_k) ),  适当评分规则 ∈ {CRPS, log score}
w_k(φ) = σ( β·(E_ref − E_k(φ)) ) · conf(n_k(φ))
```
非对称更新：证伪事件 ⇒ E_k 立即叠加 EXTREME_PENALTY（w 快降）；证实事件 ⇒ E_k 缓慢向新分数收敛（w 慢升），满足上鞅。源间相关性 ρ_err(φ)=Pearson(E_sem(φ),E_sim(φ))（同一探针上的误差序列）。有效独立证据数：n_eff(φ)=n(φ)/(1+(m−1)·clip(ρ_err,0,ρ_max))，m=2。

**定义 157（双重接地闭环 DGCL）** 算子 DGCL(M, cp, δ_f^req, B_ground)：
```
① SGC   : P ← Π(y_LLM); (G,U) ← Γ(P); g_sem ← |G|/|P|
② RGIT  : Δ, Cert_transfer ← identify_and_certify(𝒟_pair); 
          if age> T_renew or no_pairs: Cert_transfer ← EXPIRED
③ FGH   : H ← build_hypotheses(G, ŷ_sim, Ω_cert, cost_ground)
④ Ground: plan ← active_ground(H, B_ground, PEAL)   # 先高风险共识簇，后按 GV
          if ¬plan: return PRIOR_ONLY_CONSERVATIVE
⑤ Judge : 对 h∈plan 执行 τ_test(h)（走 CLEP 执行契约）; falsify ← R_falsify(τ_test)
⑥ PEAL  : update E_k(φ), w_k(φ), ρ_err; 若「共识被证伪」⇒ trigger DUAL_PRIOR_DEGRADE
⑦ Reconcile: fused ← fuse_with_priors(M, G, PEAL)   # 同源则合并且不累加证据
⑧ Compile : δ_f^req 经 w 与 n_eff 修正 → 交回 CLEP/EEIS 编译
⑨ Return  : (M, fused, Cert_transfer, PEAL, G, falsification_log)
```

**定义 158（语义-仿真扩展对账 XMC++ 与先验模态）** 模态集 ℳ⁺⁺=ℳ⁺∪{sem,sim}，但 sem/sim 为**先验模态（prior modality）**：只参与分歧度 D⁺⁺，其权重由 PEAL 的 w_k 决定；**不得**作为 EV-xmodal/EV-human/EV-exec 的佐证。扩展分歧：
```
D⁺⁺(r) = D⁺(r) + Σ_k w_k(φ)·CRPS_k + penalty(ρ_err)
penalty(ρ_err) = λ_corr·max(0, ρ_err − θ_corr)
```
当 ρ_err>θ_corr：两先验合并为「去相关先验」，融合权重 w_pair ≤ max(w_sem,w_sim)/(1+ρ_err)（显著小于 w_sem+w_sim），且**共识不累加贝叶斯因子**。

**定义 159（接地预算 B_ground 与主动接地价值 GV）** B_ground=(N_probe_real, Risk_budget_ground, Time_budget_ground)。接地价值：
```
GV(h) = P(falsify|h)·Loss(falsify) / cost_ground(h)
Loss(falsify) ∝ 命题风险 × (1 + 1[共识命题])   # 共识错误无第二裁判，损失更高
```
选策：先按「高风险共识簇」各取代表（consensus audit quota，强制），再按 GV 降序。B_ground 耗尽 ⇒ 保守动作，且未审计共识的置信度乘 (1−q_audit) 折扣，q_audit=已审计簇数/共识簇数。

**定义 160（接地证书 J_ground）** J_ground=(P_G, g_sem, Cert_transfer 链, PEAL 账本, FGH 日志, falsification 事件, ρ_err 时间序列, B_ground 快照, q_audit, version)。证书链版本单增、每项 Cert_transfer 有到期时戳、每条证伪事件可追溯到具体探针与预注册判据。

### IP-152 SGC（语义接地契约）

```python
class SemanticGroundingContract:
    def __init__(self, parser, verifier_registry, calib_set):
        self.parse = parser                 # MLLM 输出 -> 原子命题
        self.verifiers = verifier_registry  # type -> V_i
        self.calib = calib_set

    def ground(self, y_llm):
        P = self.parse(y_llm)               # [{subj,rel,val,ctx,type}]
        G, U = [], []
        for p in P:
            V = self.verifiers.get(p['type'])
            if V is not None and V.is_executable(p) and V.has_preregistered_domain(p):
                A = V.pre_registered_acceptance(p)     # 预注册，不可事后改
                c = conformal_p_value(p, self.calib, group=p['type'])
                G.append(GroundedProp(p, V, A, calib_prob=1 - c))
            else:
                U.append(p)                 # 只可提案，不入信念
        return GroundedSet(G, U, g_sem=len(G) / max(1, len(P)))

    def inject(self, belief, grounded, lam_prop=1e-2):
        # 未接地语义仅以极小权重进入提案，绝不进证据门
        for p in grounded.U:
            belief.proposal_only.update(p, weight=lam_prop)
        for gp in grounded.G:
            belief.semantic_prior.update(gp.p, weight=gp.calib_prob)
        return belief
```

### IP-153 RGIT（现实鸿沟辨识与迁移证书）

```python
class RealityGapIdentifier:
    def __init__(self, sim_model, gap_prior):
        self.f_sim = sim_model
        self.gp = GapGP(prior=gap_prior)    # 学习 Delta(s,a;theta_gap)
        self.version = 0

    def paired_probe(self, s, a):
        x_sim = self.f_sim.step(s, a)
        x_real = execute_in_real(s, a)      # 走 CLEP 执行契约，带 ERTC 守界
        self.gp.update((s, a), x_real - x_sim)
        return x_sim, x_real

    def certify(self, domain, alpha=0.05):
        ucb = self.gp.upper_confidence(domain, alpha)
        cov = self.gp.coverage_density(domain)
        omega = {(s, a) for (s, a) in domain
                 if ucb(s, a) <= DELTA_MAX and cov(s, a) >= RHO_MIN}
        self.version += 1
        return TransferCertificate(theta=self.gp.mean(), Omega=omega,
                                   alpha_gap=alpha, T_renew=T_RENEW,
                                   version=self.version, created=time.monotonic())

    def is_transferable(self, cert, s, a):
        return (s, a) in cert.Omega and cert.age() <= cert.T_renew
```

### IP-154/155 PEAL + ActiveGround（预测误差账本 + 主动接地）

```python
class PredictionErrorLedger:
    def __init__(self, sources=('sem', 'sim', 'learned')):
        self.scores = {k: defaultdict(list) for k in sources}
        self.err_seq = defaultdict(list)     # 同一探针上的误差序列（估相关性）

    def proper_score(self, y_true, y_dist):
        return crps(y_true, y_dist)          # 适当评分规则

    def update(self, k, ctx, score, falsified=False):
        buf = self.scores[k][ctx]
        buf.append(score)
        self.scores[k][ctx] = buf[-N_WIN:]
        self.err_seq[k].append(score)
        if falsified:                        # 非对称：证伪快降信任
            self.scores[k][ctx] += [EXTREME_PENALTY] * K_PENALTY

    def trust(self, k, ctx):
        buf = self.scores[k][ctx]
        e = np.mean(buf) if buf else E_PRIOR
        n = len(buf)
        return sigmoid(BETA * (E_REF - e)) * conf_factor(n)

    def correlation(self, ctx):
        s, m = self.err_seq['sem'], self.err_seq['sim']
        L = min(len(s), len(m))
        if L < N_CORR_MIN:
            return RHO_PRIOR                  # 未知即按高相关处理（保守）
        return float(np.clip(np.corrcoef(s[-L:], m[-L:])[0, 1], 0.0, 0.99))

    def n_effective(self, ctx, m=2):
        rho = self.correlation(ctx)
        n = min(len(self.scores['sem'][ctx]), len(self.scores['sim'][ctx]))
        return n / (1 + (m - 1) * rho)


def active_ground(H, budget, ledger):
    # ① 高风险共识簇强制审计（先杀共识）
    plan, clusters = [], cluster_consensus(H)
    for c in clusters:
        if c.risk >= RISK_HIGH and c.audit_count == 0:
            plan.append(max(c.hyps, key=lambda h: h.loss / h.cost))
    # ② 剩余预算按证伪价值降序（后查分歧）
    rest = [h for h in H if h not in plan]
    rest.sort(key=lambda h: (h.loss * h.p_falsify) / h.cost, reverse=True)
    remaining = max(0, budget.N_probe_real - len(plan))
    return (plan + rest)[:len(plan) + remaining]
```

### IP-157 DGCL（双重接地闭环算子）

```python
def dual_grounding_closed_loop(M, cp, delta_f_req, budget):
    # ① SGC
    grounded = M.sgc.ground(M.mllm.query(cp))
    # ② RGIT
    cert = M.rgit.certify(M.domain(cp))
    if cert is EXPIRED:
        return prior_only_conservative(M, cp, "transfer_cert_expired")
    # ③ FGH
    H = build_falsifiable_hypotheses(grounded.G, M.sim.predict, cert, cp)
    # ④ 主动接地（先共识后分歧）
    plan = active_ground(H, budget.ground, M.peal)
    if not plan:
        return prior_only_conservative(M, cp, "ground_budget_exhausted")
    # ⑤ 现实裁决（走 CLEP 执行契约）
    falsifications = []
    for h in plan:
        tau = M.exec_probe(h.test_protocol)        # 含 ERTC + EEIS
        fb = h.falsify(tau)
        M.peal.update('sem', cp.ctx, h.score_sem(tau), falsified=fb.by_sem)
        M.peal.update('sim', cp.ctx, h.score_sim(tau), falsified=fb.by_sim)
        budget.ground.spend(h.cost)
        if fb: falsifications.append((h, fb))
    # ⑥ 共识被证伪：双先验降级
    if any(h.is_consensus for h, _ in falsifications):
        M.trigger_dual_prior_degrade()
    # ⑦ 去相关重估 + 融合
    fused = fuse_with_priors(M, grounded.G, M.peal, cp.ctx)
    # ⑧ 交回 CLEP/EEIS 重编译
    K_safe, cert_eeis = M.eeis.compile(delta_f_req * M.peal.confidence_discount(cp.ctx),
                                       fused, M.buq.ukf.x, M.b_r[cp.region])
```

### IP-152 SGC（语义接地契约）

```python
from dataclasses import dataclass

@dataclass
class GroundedProp:
    p: dict            # {subj,rel,val,ctx,type}
    verifier: object
    acceptance: object # 预注册接受域
    calib_prob: float

@dataclass
class GroundedSet:
    G: list
    U: list
    g_sem: float

class SemanticGroundingContract:
    def __init__(self, parser, verifier_registry, calib_set,
                 lam_prop=1e-2):
        self.parse = parser
        self.verifiers = verifier_registry
        self.calib = calib_set
        self.lam_prop = lam_prop

    def ground(self, y_llm):
        P = self.parse(y_llm)
        G, U = [], []
        for p in P:
            V = self.verifiers.get(p['type'])
            if V is not None and V.is_executable(p) \
               and V.has_preregistered_domain(p):
                A = V.pre_registered_acceptance(p)
                c = conformal_p_value(p, self.calib, group=p['type'])
                G.append(GroundedProp(p, V, A, calib_prob=1.0 - c))
            else:
                U.append(p)
        return GroundedSet(G, U, g_sem=len(G) / max(1, len(P)))

    def inject(self, belief, grounded):
        # 未接地语义只进入提案/注意，绝不入证据门
        for p in grounded.U:
            belief.proposal_only.add(p, weight=self.lam_prop)
        # 接地语义作为先验，权重由校准概率给出
        for gp in grounded.G:
            belief.semantic_prior.add(gp.p, weight=gp.calib_prob)
        return belief

    def leakage_bound(self, grounded):
        # 定理 GST-1 的 TV 影响上界
        return self.lam_prop * (1.0 - grounded.g_sem)
```

### IP-153 RGIT（现实鸿沟辨识与迁移证书）

```python
@dataclass
class TransferCertificate:
    theta: object
    Omega: set
    alpha_gap: float
    T_renew: float
    version: int
    created: float
    def age(self):
        return time.monotonic() - self.created

class RealityGapIdentifier:
    def __init__(self, sim_model, gap_prior,
                 delta_max=0.2, rho_min=3.0):
        self.f_sim = sim_model
        self.gp = GapGP(prior=gap_prior)  # GP/BNN over Delta(s,a)
        self.delta_max = delta_max
        self.rho_min = rho_min
        self.version = 0

    def paired_probe(self, s, a):
        x_sim = self.f_sim.step(s, a)
        x_real = execute_in_real(s, a)   # 走 CLEP：ERTC 守界 + EEIS 编译
        self.gp.update((s, a), x_real - x_sim)
        return x_sim, x_real

    def certify(self, domain, alpha=0.05):
        ucb = self.gp.upper_confidence(domain, alpha)
        cov = self.gp.coverage_density(domain)
        omega = {(s, a) for (s, a) in domain
                 if ucb(s, a) <= self.delta_max and cov(s, a) >= self.rho_min}
        self.version += 1
        return TransferCertificate(
            theta=self.gp.mean(), Omega=omega, alpha_gap=alpha,
            T_renew=T_RENEW, version=self.version, created=time.monotonic())

    def is_transferable(self, cert, s, a):
        return (s, a) in cert.Omega and cert.age() <= cert.T_renew

    def predict(self, cert, s, a):
        if not self.is_transferable(cert, s, a):
            return PriorOnly(self.f_sim.step(s, a))   # 仅先验，不作佐证
        mu = self.f_sim.step(s, a) + self.gp.mean(s, a)
        sigma = self.gp.upper_confidence(s, a, cert.alpha_gap)
```

```python
@dataclass
class FalsifiableHypothesis:
    P_G: list
    y_sim: object            # None 表示不可映射
    tau_test: object         # 探针协议
    A_test: object           # 接受域
    R_falsify: object        # 预注册证伪判据
    cost_ground: float
    risk: float
    is_consensus: bool
    def falsify(self, tau):
        return self.R_falsify.evaluate(tau)

class PredictionErrorLedger:
    def __init__(self, sources=('sem', 'sim', 'learned'),
                 N_win=200, N_corr_min=30):
        self.scores = {k: defaultdict(list) for k in sources}
        self.err_seq = defaultdict(list)
        self.N_win = N_win
        self.N_corr_min = N_corr_min

    @staticmethod
    def proper_score(y_true, y_dist):
        return crps(y_true, y_dist)      # 适当评分规则

    def update(self, k, ctx, score, falsified=False):
        buf = self.scores[k][ctx]
        buf.append(score)
        self.scores[k][ctx] = buf[-self.N_win:]
        self.err_seq[k].append(score)
        if falsified:
            # 非对称：证伪立即大幅上调误差 = 快降信任
            self.scores[k][ctx] += [EXTREME_PENALTY] * K_PENALTY

    def trust(self, k, ctx):
        buf = self.scores[k][ctx]
        e = np.mean(buf) if buf else E_PRIOR
        return sigmoid(BETA * (E_REF - e)) * conf_factor(len(buf))

    def correlation(self, ctx):
        s, m = self.err_seq['sem'], self.err_seq['sim']
        L = min(len(s), len(m))
        if L < self.N_corr_min:
            return RHO_PRIOR             # 未知即按高相关处理（保守）
        return float(np.clip(np.corrcoef(s[-L:], m[-L:])[0, 1], 0.0, 0.99))

    def n_effective(self, ctx, m=2):
        rho = self.correlation(ctx)
        n = min(len(self.scores['sem'][ctx]),
                len(self.scores['sim'][ctx]))
        return n / (1.0 + (m - 1.0) * rho)

    def confidence_discount(self, ctx):
        # 低 n_eff / 高相关 => 风险预算打折（更保守）
        return max(0.1, 1.0 / (1.0 + self.correlation(ctx)))

def build_falsifiable_hypotheses(G, sim_predict, cert, cp):
    H = []
    for gp in G:
        if not gp.verifier.is_executable(gp.p):
            continue
        y_sim = sim_predict(cert, gp.p) if gp.p.get('mappable') else None
        H.append(FalsifiableHypothesis(
            P_G=[gp.p], y_sim=y_sim,
            tau_test=gp.verifier.protocol(gp.p),
            A_test=gp.acceptance, R_falsify=gp.verifier.preregistered_criterion(gp.p),
            cost_ground=gp.verifier.estimate_cost(gp.p),
            risk=cp.region_risk * gp.p.get('impact', 1.0),
            is_consensus=False))
    return mark_consensus_clusters(H)

def active_ground(H, budget, ledger):
    # ① 先杀共识：高风险共识簇强制审计
    plan, clusters = [], cluster_consensus(H)
    for c in clusters:
        if c.risk >= RISK_HIGH and c.audit_count == 0:
            plan.append(max(c.hyps, key=lambda h: h.risk / h.cost_ground))
    # ② 后查分歧：其余按接地价值 GV 降序
    rest = [h for h in H if h not in plan]
    rest.sort(key=lambda h: (h.risk * h.R_falsify.p_falsify()) / h.cost_ground,
              reverse=True)
    remaining = max(0, budget.N_probe_real - len(plan))
    return (plan + rest)[:len(plan) + remaining]
```

```python
def dual_grounding_closed_loop(M, cp, delta_f_req, budget):
    # ① SGC：语义 -> 接地命题
    grounded = M.sgc.ground(M.mllm.query(cp))
    # ② RGIT：迁移证书
    cert = M.rgit.certify(M.domain(cp))
    if cert is EXPIRED or cert is None:
        return prior_only_conservative(M, cp, "transfer_cert_expired")
    # ③ FGH：可证伪假设
    H = build_falsifiable_hypotheses(grounded.G, M.rgit.predict, cert, cp)
    # ④ 主动接地（先杀共识，后查分歧）
    plan = active_ground(H, budget.ground, M.peal)
    if not plan:
        return prior_only_conservative(M, cp, "ground_budget_exhausted")
    # ⑤ 现实裁决（每条探针走 CLEP 执行契约）
    falsifications = []
    for h in plan:
        tau = M.exec_probe(h.tau_test)      # 含 ERTC + EEIS + EV-exec
        fb = h.falsify(tau)
        M.peal.update('sem', cp.ctx, h.score_of('sem', tau), falsified=fb.by_sem)
        M.peal.update('sim', cp.ctx, h.score_of('sim', tau), falsified=fb.by_sim)
        budget.ground.spend(h.cost_ground)
        if fb.any:
            falsifications.append((h, fb))
    # ⑥ 共识被证伪：双先验降级
    if any(h.is_consensus for h, _ in falsifications):
        M.trigger_dual_prior_degrade()      # 两先验同源且同错，权重乘 rho 惩罚
    # ⑦ 去相关重估 + 融合
    fused, D_pp = fuse_with_priors(M, grounded.G, M.peal, cp.ctx)
    # ⑧ 交回 CLEP/EEIS 重编译（风险预算按 n_eff/相关性打折）
    delta_eff = delta_f_req * M.peal.confidence_discount(cp.ctx)
    K_safe, cert_eeis = M.eeis.compile(delta_eff, fused, M.buq.ukf.x,
                                       M.b_r[cp.region])
    # ⑨ 接地证书
    M.J_ground.append(J_ground(grounded, cert, M.peal, falsifications,
                               budget.ground.snapshot()))
    return M, fused, D_pp, cert, M.peal, grounded, falsifications, cert_eeis
```

```python
def fuse_with_priors(M, G, peal, ctx):
    w_sem, w_sim = peal.trust('sem', ctx), peal.trust('sim', ctx)
    rho = peal.correlation(ctx)
    n_eff = peal.n_effective(ctx)
    if rho > THETA_CORR:
        # 同源：合并为一个去相关先验，共识不累加贝叶斯因子
        w_pair = max(w_sem, w_sim) / (1.0 + rho)
        fused = Fuse({**M.belief, 'prior_pair': merge_priors(G, w_pair, n_eff)})

        fused = Fuse({**M.belief, 'sem': w_sem, 'sim': w_sim, 'n_eff': n_eff})

            + lam_corr * max(0.0, rho - THETA_CORR))

    # 先验模态只计入分歧，绝不进入 EV-xmodal/EV-human/EV-exec 佐证

                 crps_term(beliefs[m], beliefs['fused'])
    return D
```
