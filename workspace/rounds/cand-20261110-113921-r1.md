# 第 43 轮（新循环第 3 轮） · 从「物理安全证书」到「时空合规证书」：把伦理约束与法规时效编译成随身携带的规范证明（四层架构 v8）

> 承接第 42 轮 v19（Sim-Cert-RAG 飞轮）。v19 解决了「证书如何持续进化」，但证书语义仍只是**物理安全**：m(x) ≥ θ 回答「此刻此地这个动作会不会撞/失稳」。它无法回答三个越来越硬的问题：**(i) 这个动作在此地此刻是否被允许？**（限速区、禁入区、可观测范围、同意边界）；**(ii) 依据的规范是否还有效？**（法规修订、区域重划、用户撤回同意、标准升版）；**(iii) 一旦出事，能否向监管者/用户独立证明「我们当时是合规的」？** 本轮两个灵感词正好补上两根轴：**「时空推理」**提供规范的形式语言——规范本质是「在哪些空间区域、哪些时间窗口内，对什么样的时空信号施加什么约束」，可用 STL/STL* 的定量语义把「合规」变成可监控、可预测、可反证的鲁棒性信号；**「伦理与合规」**提供规范的来源与治理要求——硬性法律禁令、伦理原则、人类监督、知情同意、数据最小化、可解释与可申辩，以及「举证责任」。两轴相乘得到本轮主张：**安全 ⊥ 合规是两条正交轴；证书必须是「安全-合规乘积」中的元素，而且必须携带证明、可被第三方独立复算**。这把 v19 的「可进化资产」升级为「可审计、带时效、跨辖区可移植的合规资产」。

## 0. 直觉与动机

**灵感 1（时空推理 → 规范不是布尔标签，而是时空鲁棒性信号）**：人理解「医院走廊限速 0.5 m/s」不是记住一句话，而是同时绑定三类坐标：**空间**（哪些区域算走廊）、**时间**（是否探视时段）、**信号**（速度如何随时间变化）。v19 的证书把这些全压进静态状态 x 与标量 θ，天然无法表达「同一地点、不同时段、不同人距下阈值不同」。STL（Signal Temporal Logic）的直觉正是：把规范写成带时间算子的公式 φ = □_{[0,T]}(near_human → speed ≤ v_max(zone,t))，其**定量语义** ρ_φ(ξ,t) 给出「还差多少才违规」的有符号裕度。于是「合规」从一次性验证变成一条可在线更新的**鲁棒性轨迹**：ρ>0 合规、ρ<0 违规、ρ≈0 待定。空间谓词（禁入区、人行道、协作区、隐私区）用几何符号距离定义，时间谓词用区间/周期定义；合规则是 `min_n ρ_n ≥ 0`。更进一步，时空推理让系统能**预测性合规**：对当前规划的未来轨迹 ξ̂ 在视界 H 上算 ρ，若 ρ_lb<0 就提前改规划，而不是撞线后再刹车。

**灵感 2（伦理与合规 → 合规是「举证责任」，不是「自我声称」）**：伦理与合规领域最反直觉的一点：**系统说自己合规几乎没有价值，能向第三方证明才值钱**。法规（ISO/TS 15066、EU AI Act、GDPR、各辖区机器人法规）与伦理要求（不伤害、自主、公平、透明、可问责、人类监督、目的限制、数据最小化、可申辩）共同构成一套**义务与证据标准**。v19 的 RAG 知识库只存技术与反例，没有「规范版本、适用辖区、生效时间、签发人、证据链」。直觉方案：证书必须升级为**证明携带证书（proof-carrying compliance）**——每张证书带一个可独立复算的证明对象：引用的规范版本与哈希、时空适用范围、监控器语义与代码哈希、测试证据集、显式假设、残余风险账本、签发者与时间、签名；并维护从「法条→形式化→测试→证书→部署→运行日志→事故」的**证据链 DAG**。这样出了事，监管者能自己重放日志、复算鲁棒性，而不是听厂商解释。

**灵感 3（两者耦合 → 安全与合规的乘积、冲突与升级）**：安全与合规会打架：避撞要求急停，但「消防通道不得停留」「扶梯口不得停滞」要求继续移动；隐私要求不采集某区域图像，但任务依赖视觉定位。v19 的单目标梯度式取舍在这里是**不可接受**的：不能用安全裕度去换速度，也不能用合规去换任务成功率。直觉方案：把规范分为**硬法律禁令、安全约束、硬义务、软伦理偏好**四级，构造一个**不可权衡的偏序**，只对同级别做优化；跨级出现互斥时，不自动裁决，而是进入 `IrreconcilableConflict → HumanEscalation`，并保留冲突证据。这把「伦理」从一句对齐口号变成一套**可检查的优先级代数 + 显式升级契约**。

**耦合升级**：时空推理提供「规范如何被表达、监控、预测、反证」，伦理合规提供「规范从哪来、谁负责、如何举证」。v19 的 Sim→RAG→Edge→Sim 飞轮被扩展为 **「规范编译 → 证明签发 → 时空监控 → 漂移/撤销 → 重编译重验证」的规范飞轮**：规范变化（新法、区域调整、同意撤回）触发证书挂起与重验证，与分布偏移触发仿真重跑并列。特别地，**规范漂移往往不改变物理世界，却让一张昨天完全 sound 的证书今天失效**——这正是本轮最想暴露、也最容易被平均指标掩盖的失效。

## 1. 形式化定义（增量：定义 38–45）

**定义 38（规范单元与时空适用范围）**：规范 n = (φ_n, Σ_n, Ω_n, src_n, κ_n, σ_n)，其中 φ_n 为含空间谓词的 STL/STL* 公式；Σ_n ⊆ M×ℝ³ 为空间适用范围（语义地图区域/几何围栏）；Ω_n ⊆ ℝ_{≥0} 为时间适用范围（有效期区间或周期调度）；src_n 为带版本与哈希的权威来源（法条/标准/伦理政策/用户同意）；κ_n ∈ {HARD_LAW, SAFETY, HARD_DUTY, SOFT_ETHICS} 为不可权衡等级；σ_n>0 为归一化尺度。**规范活跃**：active(n,x,t) ⟺ x∈Σ_n ∧ t∈Ω_n ∧ applies(机器人类别, 任务模式)。**规范鲁棒性** ρ_n(ξ,t) 用 STL 定量语义，空间原子谓词由几何符号距离定义（如 dist(x, ∂Σ_n)）。

**定义 39（合规裕度与三值合规证书）**：m_norm(ξ,t) := min_{n: active} ρ_n(ξ,t)/σ_n。**合规证书** C_norm := {(ξ,t) : ∀ active n, ρ_n ≥ 0}；带估计不确定性的三值判定：COMPLIANT 若 m_norm ≥ η；VIOLATION 若 m_norm < 0；否则 UNDECIDED（η 为估计/时序误差裕度，见定义 41）。证书的**时空有效域** D = Σ × Ω，跨出 D 即失效。

**定义 40（规范知识图 NKB 与时空索引）**：规范版本为节点 n^{(v)}，边含 supersedes（替代）、refines（细化）、conflicts_with（冲突）、jurisdiction_contains（辖区包含）、temporal_precedes（时序先后）。查询 Q(loc,t,robot,mode) → 活跃规范集 N_active，用时间区间树 + 空间 R-tree/geohash 双索引，O(log|N| + k)。**一致性检查**：同一 (loc,t) 上若两条硬规范给出互斥义务且无显式例外/优先边，则判为规范冲突（交给定义 42）。NKB 是 v19 CKB 的「法规孪生」：CKB 存经验，NKB 存规范，二者以 (φ, ψ, D) 交叉索引。

**定义 41（时空不确定性下的 sound 合规监控）**：设位置估计误差 ‖p̂−p‖ ≤ B_t（复用 IP-49 漂移界）、时间戳误差 |t̂−t| ≤ τ_c、测量误差 ≤ ε_s；空间谓词对位置 L_S-Lipschitz、对时间 L_t-Lipschitz、对测量 L_s-Lipschitz。则真实鲁棒性的保守下界
ρ_lb := ρ_meas − L_S·B_t − L_t·τ_c − L_s·ε_s。
**命题 41.1（无漏报监控）**：若 ρ_lb ≥ 0，则真实轨迹满足 φ_n；以 ρ_lb 判定保证 soundness，代价是边界附近落入 UNDECIDED（保守误报）。这是把 v19 的 Sim-to-Real 迁移界搬到「规范-观测」界：误差越界必须先扩不确定度，而不是假装精确。

**定义 42（安全-合规乘积与规范优先序）**：总证书 Cert_total := Cert_safe ∩ Cert_norm；可执行动作 A_exec := A_safe ∩ A_comp。**不可权衡优先序** ≻：HARD_LAW ≻ SAFETY ≻ HARD_DUTY ≻ SOFT_ETHICS；只有同级可比、可优化，跨级禁止交换（不得用安全裕度换速度，也不得用合规换任务收益）。**不可调和冲突**：若在 (x,t) 上按 ≻ 仍存在互斥硬义务，标记 IrreconcilableConflict，进入 HumanEscalation，禁止自动裁决并留证。

**定义 43（证明携带合规证书 PCC 与独立可核验性）**：证明对象 π := (规范版本与哈希, 时空有效域 D, 监控器代码哈希, 证据集, 显式假设, 残余风险账本, 签发者, 时间戳, 签名)。验证器 Verify(π, logs) ∈ {ACCEPT, REJECT, INCOMPLETE}：从日志复算 ρ_lb、检查假设与哈希链、核对证据覆盖。维护证据链 DAG：`法条 → 形式化 → 测试 → 证书 → 部署 → 运行日志 → 事故`。对 VIOLATION/UNDECIDED 输出**最小违规片段**（STL 反例）与责任链，支持用户申辩与监管审计。

**定义 44（规范漂移与证书时效 TTL）**：规范漂移 N_t := d_N(N_deploy, N_current(t,x))，含新法生效、区域重划、同意撤回、标准升版。若 N_t > τ_norm 或超过 TTL，证书 SUSPENDED，必须重编译/重验证。**TTL 推导**：设规范/环境变化速率 λ_N、规范空间 Lipschitz L_N，则取 TTL ≤ η/(L_N·λ_N)。**定理 44.1（时效 soundness）**：若签发时证书覆盖 D 且 TTL 满足上式，则在 TTL 内规范漂移造成的裕度损失 ≤ η，证书保持 sound。

**定义 45（人类监督与数据治理的时空契约）**：人类监督契约 φ_H := □(Escalation → ◇_{≤t_R} HumanAck) ∧ □(PlanChange → ◇_{≤t_N} HumanNotice) ∧ □(RequestExplanation → ◇_{≤t_E} Explanation)；数据治理契约 φ_D := 目的限制（使用 ⊆ 声明目的） ∧ 最小化（采集字段 ⊆ 必需集） ∧ 保留期（◇_{>τ_ret} ¬stored） ∧ 脱敏级别。二者与运动规范同样编译为 STL，由同一运行时监控器判定；人类监督的**响应时延**本身成为可证伪的合规指标。

## 2. 产出设计（新增 IP-57/58/59 + 升级 IP-51/52/53/54/55/56/49/50/45/47）

### 2.1 IP-57 NORM-COMPILER-GRAPH（NCG，时空规范编译器与规范图）
1. **规范抽取与形式化**：把法规/标准/伦理政策文本拆成「主体-条件-义务-时空范围」四元组；LLM 只做候选形式化，**必须**经确定性检查器（语法、量词、时空域闭合）与人类法务签署；无法形式化的条款显式登记为 `UNFORMALIZED`，禁止默认视为满足。
2. **时空索引与 JIT 规范集**：规范按 (辖区, 生效区间, 空间区域) 建双索引；每次任务/每次跨区时 JIT 编译出 `N_active` 与监控器实例，避免全量规范常驻。
3. **规范一致性检查**：静态检测 supersedes/conflicts 图上的互斥硬义务；动态在 (loc,t) 上做优先序消解，真冲突交 IP-59 升级。
4. **跨辖区可移植**：把规范与证书分离，同一任务在不同辖区只重检索/重编译规范层，复用安全证书与仿真证据。

### 2.2 IP-58 PROOF-CARRYING-COMPLIANCE（PCC，证明携带合规与审计链）
1. **证明对象生成**：证书签发时自动打包规范哈希、时空域、监控器哈希、仿真/实机证据、假设与残余风险账本、签名；任何字段变更导致哈希链断裂即失效。
2. **独立验证器**：只依赖日志 + 证明对象复算 ρ_lb 与证据覆盖，不信任签发方；输出 ACCEPT/REJECT/INCOMPLETE。
3. **最小违规见证与解释**：从 STL 反例提取最小时间片段与最小空间区域，生成人类可读解释与申辩入口（对应用户「要求解释」的权利）。
4. **审计与责任链**：证据链 DAG 支持按时间/区域/规范版本检索；事故调查可回溯到具体规范版本与测试证据。

### 2.3 IP-59 COMPLIANCE-RUNTIME-MONITOR（CRM，时空合规运行时）
1. **定量 STL 监控**：固定点/整数实现的 STL 鲁棒性评估（有界时域、固定窗口），按定义 41 减去不确定度得 ρ_lb；复用 IP-56 的边缘预算与查表思想。
2. **预测性合规**：对规划轨迹在视界 H 上做增量 STL 评估，ρ_lb<0 时向规划器回传「合规梯度」修正候选轨迹，而非事后急停。
3. **人类监督/数据治理监控**：把 φ_H、φ_D 作为并行监控通道；超时未响应即降级或 SafeStop，数据流越界即阻断写入并审计。
4. **规范挂起与撤销监听**：订阅 NKB 版本/辖区/同意状态变更，命中即 `SUSPEND` 当前证书并触发重编译；运行期绝不使用过期证书。

### IP-57 NCG：规范编译与时空活跃集

def compile_norm(source_text, authority):
    clauses = segment_clauses(source_text)   # 主体/条件/义务/时空范围
    specs = []
    for c in clauses:
        phi = llm_propose_stl(c)              # 仅候选，不可信
        if not syntax_and_scope_check(phi):   # 确定性检查：语法/量词/域闭合
            registry.add_UNFORMALIZED(c, reason='parse_fail'); continue
        if not legal_signoff(phi, c, authority):   # 人类法务签署
            registry.add_UNFORMALIZED(c, reason='unsigned'); continue
        specs.append(Norm(
            phi=phi,
            Sigma=extract_region(c),          # 空间谓词 + 几何围栏
            Omega=extract_validity(c),        # 生效/废止/周期
            src=authority.version_hash,
            kappa=classify_priority(c),
            sigma=normalize_scale(c)))
    NKB.insert(specs)
    return specs, registry   # registry 必须随证书一并公开

def active_norms(NKB, loc, t, robot, mode):
    cand = NKB.time_index.query(t) & NKB.space_index.query(loc)   # O(log|N|+k)
    N = [n for n in cand if n.applies(robot, mode) and n.active(loc, t)]
    conflicts = find_hard_conflicts(N)
    return sorted(N, key=lambda n: n.kappa, reverse=True), conflicts

def find_hard_conflicts(N):
    out = []
    for n1, n2 in pairs(N):
        if n1.kappa in (HARD_LAW, SAFETY) and n2.kappa in (HARD_LAW, SAFETY):
            if mutually_exclusive(n1.phi, n2.phi) and not NKB.has_precedence(n1, n2):
                out.append(Conflict(n1, n2, loc=n1.Sigma))
    return out
```

### IP-59 CRM：时空监控、预测与规范漂移
```
def stl_robustness_lb(trace, norms, unc):
    rho = min((stl_quantitative(n.phi, trace) / n.sigma) for n in norms)
    return rho - unc.L_S*unc.B_t - unc.L_t*unc.tau_c - unc.L_s*unc.eps_s

def compliance_step(x, t, norms, unc):
    r = stl_robustness_lb(window(x), norms, unc)
    if r >= unc.eta: return COMPLIANT, r
    if r <  0:       return VIOLATION, r
    return UNDECIDED, r          # 边界区：绝不静默通过

def predictive_compliance(plan, H, norms, unc):
    rhos = [stl_robustness_lb(plan[:k], norms, unc) for k in 1..H]
    grad = d_rho_d_plan(plan)    # 合规梯度回传规划器
    return min(rhos), grad

def monitor_human_contract(event_log, phi_H):
    # □(Escalation -> ◇_{<=t_R} HumanAck) ∧ □(PlanChange -> ◇_{<=t_N} Notice)
    return stl_quantitative(phi_H, event_log)

def monitor_data_contract(flow_log, phi_D):
    # 目的限制 / 最小化 / 保留期 / 脱敏
    return stl_quantitative(phi_D, flow_log)

def norm_drift_check(cert, NKB, t):

def car_transition_guard_v8(e, x, t, safe_cert, norm_cert, NKB, unc):
    status, _ = norm_drift_check(norm_cert, NKB, t)
    if status == SUSPEND:
        return ComplianceSuspend          # 规范变了，旧证书作废
    norms, conflicts = active_norms(NKB, x.pos, t, ROBOT, MODE)
    if any(c.is_irreconcilable() for c in conflicts):
        return HumanEscalation            # 禁止自动裁决

        return ALLOW
    if c == VIOLATION:
        return SAFE_STOP
    if c == UNDECIDED:
        return DEGRADE                    # 保守降级，非静默放行

def certify_compliance_v2(x, t, guards, NKB, unc, budget_us=300):

    if c != COMPLIANT and budget_us < 210:
