# 第 1 轮（新灵感循环第 1 轮；基线 v20；本轮灵感：「行为树」×「多端口部署」）

> **基线**：v20 产出 MetricVoiceGauge-NCD-HUTDH-v20 + IP-420–424（感知层：PCA / CTS / CFC / HPC / CFCtrl；定义 767–820；引理 151–156；实验 E751–E770）。
> 本轮纪律：**组合是纵向的证书精化，部署是横向的证书投影**。不推倒 v20：v17 的 CLP/S2C/HCG/PSV/APS/AMC、v19 的 DCM/OGCC/CCV/DRS/OGC、v20 的 PCA/CTS/CFC/HPC/CFCtrl 全部保留。本轮只做一件事：**把“点状证书”升级为“可在行为树上组合、可在多端口上投影、可原子部署与回滚”的运行时证书结构**。

## 0. 直觉与动机

**灵感 1（行为树 → 安全不是一条线性计划，而是一棵“可回退的证书树”）**
直觉：v17–v20 的计划证书本质上是一条**线性节点序列**：前一个节点的 Post 接后一个节点的 Pre，任何一步失败，整条计划要么截断、要么退回默认路径。真实机器人任务却更像一棵树：抓取失败要换抓法，放置失败要换位置，感知过期要重观测，局部碰撞要绕行。行为树（BT）的 Sequence / Selector / Parallel / Retry / Timeout / Guard 正是这种“失败改道”的自然语言。但行为树不是免费的：两个各自安全的子树，组合后可能因为 **Pre/Post 不衔接、资源叠加、重试副作用、超时边界** 而变得不安全；一个 Selector 甚至会把两条安全路径拼成一条从未被认证过的路径。核心创新：**证书化行为树（Certified Behavior Tree, CBT）** 与 **行为树证书代数（BT Contract Algebra, BTCA）**。每个 BT 节点携带合同 `C_n = (Pre_n, Inv_n, Post_n, Fail_n, Res_n, TTL_n, Abort_n)`；组合算子带**类型规则**，只有类型正确的组合才能编译；每个根到叶的 tick 轨迹还必须携带一条 **v20 计划见证**，证明它只是已有认证计划的精化，而不是新发明的动作序列。关键反直觉点：**行为树的价值不在“分支更多”，而在“每条失败边都有证书化回退”**——没有回退证书的分支越多，越像把风险藏进树里。

**灵感 2（多端口部署 → 证书的可部署性，不是复制粘贴，而是端口投影）**
直觉：多端口部署常被理解为“同一策略复制到 N 台机器人 / N 个控制通道 / N 个网络端点”。但复制一张证书，像把同一张驾照交给不同车型：运动学、动力学、传感器、标定、延迟、资源锁都不同，纸面有效不等于物理有效。一个端口上的 `margin_col`、可达域、关节限位、相机外参，到了另一个端口可能全部改变；更危险的是，多个端口可能共享同一个机械臂、同一个工作空间、同一个时钟、同一条标定链。核心创新：**端口投影证书（Port Projection Certificate, PPC）** 与 **多端口部署编排器（Multi-Port Deployment Orchestrator, MPDO）**。每个端口有签名 `σ_p = (K_p, D_p, S_p, Cal_p, Λ_p, R_p)`；抽象证书经投影 `π_p` 落到端口可实现域，投影**只能收缩、不能扩张**；不可投影的端口一律 fail-closed，而不是“近似一下”。关键反直觉点：**多端口不是“多副本冗余”，而是“多约束交集”**——多一个端口只会让安全域变小，除非端口之间在故障模式上真正独立；把“多端口”当冗余，等于把相关性误认成独立性。

**灵感 3（两者统一 → 部署证书是“行为树 × 端口”上的纤维丛截面）**
直觉：行为树负责**纵向**：把任务分解、把失败改道、把恢复变成一等公民；多端口负责**横向**：把同一棵抽象树投影到不同物理/逻辑端点。两者相乘，得到一张 `(节点, 端口)` 的二部图。安全不是“树对了”或“端口对了”，而是**每个可达的 `(节点, 端口)` 纤维上的局部证书都对，且纤维之间的组合边、投影边、共享资源边也都对**。核心创新：**部署证书（Deployment Certificate, DC）**。把 CBT 的节点合同、PPC 的端口投影、跨端口干扰图、部署原子性统一进一个可审计对象：`DC = (T, {C_n}, {σ_p}, {π_p}, G_int, rollout, merkle_root)`。共享状态 `ζ_btp = (tree, contracts, port_signatures, projection, interference_graph, locks, tick_log, deployment_version, mode_btp)`。统一接口：**CBT 认证 ∧ 端口投影可采纳 ∧ 跨端口互斥/可交换 ∧ 部署原子提交 ⇒ 该 `(节点, 端口)` 进入 `Exec_v21`；任一条件失败，只收缩该纤维，并退回 v20 的单计划、单端口、保守路径**。

**三者如何统一**
v20 回答“给定感知快照，节点 n 在参数 θ 下是否零碰撞”（`Exec_v20`）；v21 回答“把这些已认证节点组织成可恢复的行为树，并投影到多个端口后，哪些 `(节点, 端口)` 组合仍然可执行”（`Exec_v21`）。CBT/BTCA 是组合侧（纵向精化），PPC 是投影侧（横向收缩），MPDO 是编排侧（原子部署），CPIG 是并发侧（资源互斥），DRA 是审计侧（回滚与证明）。五者不是补丁，而是“组合—投影—互斥—部署—回滚”的闭环：**CBT 回答“这条执行路径是否被认证”，PPC 回答“这张证书在这个端口是否还成立”，MPDO 回答“多端口能否原子地上/下线”，CPIG 回答“两个端口能否同时动”，DRA 回答“出错后能否回到上一张已认证的树”**。

## 1. 研究问题（轮次升级版）

- **Q1（行为树组合的可靠性）**：`Pre/Inv/Post/Fail` 如何定义才能让 Sequence / Selector / Parallel / Retry / Timeout / Guard 的组合是**保安全的**？当子节点失败会改写世界状态（物体被推走、夹爪闭合、资源被占用）时，Selector 的“改道”如何保证下一个分支的 Pre 仍然成立？Retry 在什么条件下是安全的（幂等 / 可复位 / 无副作用），什么条件下是“证书化活锁”？

- **Q2（tick 语义与证书新鲜度）**：BT 的 tick 频率（通常 10–50Hz）与底层控制（50–1000Hz）不同步，证书的 TTL 与 v20 CFCtrl 的 `τ_consensus` 如何对齐？节点在 tick 之间发生的扰动如何被 `Inv` 捕获？Timeout / Parallel 的“运行中”状态如何携带一个**可中止的合同**，而不是只在成功/失败时检查？

- **Q3（多端口投影的可判定性）**：端口签名 `σ_p` 如何定义才能既刻画运动学/动力学/传感器/标定/延迟，又不至于不可计算？投影 `π_p` 何时是**可采纳的**（存在、保守、资源相容）？异构端口的标定误差与延迟抖动如何传播到 `margin_col` 而不被点估计吞掉？多个端口共享同一标定链时，投影交集为何可能**不增加**任何安全？

- **Q4（跨端口并发与部署治理）**：两个端口共享机械臂/工作空间/时钟/网络时，如何判定它们可以并发、必须串行、还是必须互斥？锁的顺序如何避免死锁，锁超时如何退回已认证的回退？多端口升级/回滚如何保证**原子性**与**版本偏斜有界**？部分端口失败时，如何只收缩失败纤维而不污染其他端口？

## 2. 设计原则（在 P31–P33 基础上新增 P34–P36）

**P34 证书组合律（Certificate Composition Law）**
每个 BT 节点 `n` 携带合同 `C_n = (Pre_n, Inv_n, Post_n, Fail_n, Res_n, TTL_n, Abort_n)`。组合只在**类型规则**成立时允许：Sequence 要求 `Post_A ⇒ Pre_B`（在帧条件与副作用下）；Selector 要求 `Fail_A ⇒ Pre_B`，否则必须先插入一个已认证的恢复节点；Parallel 要求 `Res_A ∩ Res_B = ∅` 或存在可交换性见证 `Comm(A,B)`；Retry 要求 `Fail_A ⊆ Pre_A` 且存在复位见证 `Reset_A` 把世界状态与资源恢复到 `Pre_A`；Timeout 要求 `Abort_A` 在 `τ` 内可达。**组合只能选择、排序、重试已认证的子合同，不能放宽任何子合同**。没有 v20 计划见证的根到叶轨迹一律不编译。

**P35 端口投影律（Port Projection Law）**
端口 `p` 的签名 `σ_p = (K_p, D_p, S_p, Cal_p, Λ_p, R_p)`。抽象证书 `C` 在端口 `p` 上的投影 `π_p(C)` 必须满足：`π_p(C)` 非空、`ι_p(π_p(C)) ⊆ C`（`ι_p` 为端口状态到抽象状态的嵌入）、标定不确定度与延迟抖动被显式放大、资源足迹落在 `R_p` 内。**投影是纯收缩算子**：`C_p ⊆ C`；不可投影的端口不得用近似、插值或“经验修正”蒙混，必须 fail-closed。多端口安全域定义为 `S_multi = ⋂_{p ∈ P_adm} ι_p(π_p(C))`，因此 `S_multi ⊆ C`；增加端口只会增加交集项，不会扩张域。

**P36 部署互斥律（Deployment Mutual Exclusion Law）**
跨端口共享资源必须进入干扰图 `G_int`。两个端口可以并发，当且仅当 `Res_A ∩ Res_B = ∅`，或存在可交换性见证且双方 `Inv` 对对方的最坏干扰 `I(A,B)` 鲁棒；否则必须串行或互斥。锁按**全序**获取，非阻塞 + 超时；超时后释放全部锁并执行已认证回退，禁止“带锁重试”。部署采用**逐端口两阶段提交**：stage（装载、验证、预热）成功后才 commit（原子切换）；rollback 目标必须是**预先认证过的旧版本**。任何端口不得在未认证状态下运行。

## 3. 与基线的接口（如何退化）

- CBT 失效（合同缺失 / 组合规则不可判定）⇒ 只执行 v20 的单条认证计划 ⇒ 等价 v20（更保守）；
- BT tick 超时或新鲜度失效 ⇒ 冻结当前树并回退 v20 默认路径 ⇒ 等价 v20；
- PPC 失效（端口签名缺失 / 投影不可采纳）⇒ 该端口不上线，只保留本地 v20 路径 ⇒ 等价 v20；
- CPIG 失效（干扰图不可用 / 锁超时）⇒ 禁止并发，全部串行或单端口执行 ⇒ 等价 v20（单端口）；
- MPDO 失效（编排器不可用 / 版本不一致）⇒ 停在上一已认证版本，不切换 ⇒ 等价 v20；
- DRA 失效（审计日志不可写）⇒ 禁止新部署，只运行当前版本 ⇒ 等价 v20；
- 六者全失效 ⇒ 完全退回 v20 的 PCA/CTS/CFC/HPC/CFCtrl；
- **安全继承**：CBT 只组合已认证子合同、PPC 只收缩域、CPIG 只串行化、MPDO 只做原子切换、DRA 只回滚到已认证版本；任意失效都使可执行集收缩，`Exec_v21 ⊆ Exec_v20` 由引理 163 保证。

## 4. 预期贡献

1. **证书化行为树**：首次把行为树从“控制流表示”改写为“带合同的证书代数”，给出 Sequence / Selector / Parallel / Retry / Timeout / Guard 的保安全组合规则，并把“失败回退”提升为一等公民；
2. **组合风险的可判定化**：揭示“子节点各自安全、组合后不安全”的四类机制（Pre/Post 断裂、副作用残留、资源叠加、重试非幂等），给出可机械检查的类型规则与反例；
3. **端口投影证书**：把多端口部署从“复制策略”改写为“证书投影”，给出端口签名、投影可采纳性、投影交集与“多端口≠多冗余”的判据；
4. **跨端口并发安全**：用干扰图、可交换性见证与全序锁，给出“可并发 / 必须串行 / 必须互斥”的三值判定，并证明无死锁与超时回退；
5. **部署—回滚闭环**：用两阶段提交、版本偏斜界与 Merkle 审计，把“多端口上线”变成可验证的部署证书，实现 `Exec_v21 ⊆ Exec_v20` 的运行时安全继承。

## 5. 本轮最大风险

**一句话**：多端口若共享同一标定链与同一时钟，端口投影会把同一系统性误差**复制**到所有端口，而行为树的 fallback 又会在同一误差上**循环重试**；于是每张局部证书都通过、每个端口都“认证”、整棵树却稳定地重复同一个错误——即“组合—投影联合幻觉”。

## 1. 关键算法骨架

```python
from dataclasses import dataclass, field
from typing import Callable, FrozenSet, Optional

Pred = Callable[[WorldState], bool]


@dataclass(frozen=True)
class Contract:
    pre: Pred
    inv: Pred
    post: Pred
    fail: Pred
    res: FrozenSet[str]
    ttl: float
    abort: "AbortPlan"
    pure: bool = False          # 无副作用，才允许 Inverter / 纯条件装饰


@dataclass(frozen=True)
class AbortPlan:
    pre: Pred
    post: Pred
    res: FrozenSet[str]
    ttl: float
    certified: bool


class BTContractAlgebra:
    """组合只在类型规则成立时返回合同；否则抛 CompositionError。"""

    def sequence(self, a: Contract, b: Contract, frame: Frame) -> Contract:
        self.require(entails(a.post, b.pre, frame), "SEQ_POST_PRE_GAP")
        return Contract(
            pre=a.pre,
            inv=lambda s: a.inv(s) and b.inv(s),
            post=b.post,
            fail=lambda s: a.fail(s) or (a.post(s) and b.fail(s)),
            res=a.res | b.res,
            ttl=a.ttl + b.ttl,
            abort=self.chain_abort(a, b, frame),
        )

    def selector(self, a: Contract, b: Contract, frame: Frame) -> Contract:
        # A 失败后必须能进入 B 的 Pre，否则必须先插入已认证恢复节点
        self.require(entails(a.fail, b.pre, frame) or self.has_recovery(a, b),
                     "SEL_FAIL_PRE_GAP")
        return Contract(
            pre=lambda s: a.pre(s) or b.pre(s),
            inv=lambda s: (a.inv(s) if not a.fail(s) else b.inv(s)),
            post=lambda s: a.post(s) or b.post(s),
            fail=lambda s: a.fail(s) and b.fail(s),
            res=a.res | b.res,
            ttl=max(a.ttl, b.ttl),
            abort=self.selector_abort(a, b),
        )

    def parallel(self, a: Contract, b: Contract, comm: Optional["CommWitness"]) -> Contract:
        # 资源不交，或存在可交换性见证且双方 Inv 对对方干扰鲁棒
        self.require(a.res.isdisjoint(b.res) or comm is not None,
                     "PAR_RES_CONFLICT")
        if comm is not None:
            self.require(comm.commutes(a, b) and comm.robust(a, b),
                         "PAR_COMM_INVALID")
        return Contract(
            pre=lambda s: a.pre(s) and b.pre(s),
            inv=lambda s: a.inv(s) and b.inv(s),
            post=lambda s: a.post(s) and b.post(s),
            fail=lambda s: a.fail(s) or b.fail(s),
            res=a.res | b.res,
            ttl=min(a.ttl, b.ttl),
            abort=self.parallel_abort(a, b),
        )

    def retry(self, a: Contract, k: int, reset: Optional["ResetWitness"]) -> Contract:
        # 重试不是免费的：失败集必须仍在 Pre 内，且必须能复位副作用
        self.require(entails(a.fail, a.pre), "RETRY_NOT_RETRYABLE")
        self.require(reset is not None and reset.restores(a), "RETRY_NO_RESET")
        self.require(k * a.ttl <= a.ttl * k and reset.budget <= a.ttl, "RETRY_TTL")
        return Contract(
            pre=a.pre, inv=a.inv, post=a.post, fail=a.fail,
            res=a.res, ttl=k * a.ttl,
            abort=self.retry_abort(a, k, reset),
        )

    def timeout(self, a: Contract, tau: float) -> Contract:
        self.require(a.abort.certified and a.abort.ttl <= tau, "TIMEOUT_ABORT_LATE")
        return Contract(
            pre=a.pre, inv=a.inv,
            post=lambda s: a.post(s) and s.elapsed <= tau,
            fail=lambda s: a.fail(s) or s.elapsed > tau,
            res=a.res, ttl=tau,
            abort=a.abort,
        )

    def guard(self, a: Contract, g: Pred) -> Contract:
        return Contract(
            pre=lambda s: g(s) and a.pre(s), inv=a.inv, post=a.post,
            fail=a.fail, res=a.res, ttl=a.ttl, abort=a.abort,
        )

    def inverter(self, a: Contract) -> Contract:
        # Inverter 只对纯谓词合法；对动作使用是类型错误
        self.require(a.pure, "INVERTER_IMPURE")
        return Contract(
            pre=a.pre, inv=a.inv,
            post=lambda s: not a.post(s),
            fail=a.fail, res=frozenset(), ttl=a.ttl, abort=a.abort, pure=True,
        )
```

```python
# IP-425 Certified Behavior Tree
class CertifiedBehaviorTree:
    def __init__(self, algebra: BTContractAlgebra, v20_exec: "V20ExecSet"):
        self.algebra = algebra
        self.v20_exec = v20_exec
        self.contracts = {}
        self.witnesses = {}

    def certify(self, tree) -> bool:
        # 后序：先认证子节点，再按节点类型组合
        for node in postorder(tree):
            if node.is_action():
                c = node.v20_cert.to_contract()
                w = self.v20_exec.witness_for(node.v20_cert)
                if w is None:
                    return False          # 没有 v20 计划见证，不编译
            elif node.kind == "sequence":
                c = self.algebra.sequence(self.contracts[node.left],
                                          self.contracts[node.right], node.frame)
            elif node.kind == "selector":
                c = self.algebra.selector(self.contracts[node.left],
                                          self.contracts[node.right], node.frame)
            elif node.kind == "parallel":
                c = self.algebra.parallel(self.contracts[node.left],
                                          self.contracts[node.right], node.comm)
            elif node.kind == "retry":
                c = self.algebra.retry(self.contracts[node.child],
                                       node.k, node.reset)
            elif node.kind == "timeout":
                c = self.algebra.timeout(self.contracts[node.child], node.tau)
            elif node.kind == "guard":
                c = self.algebra.guard(self.contracts[node.child], node.guard)
            else:
                raise CompositionError("UNKNOWN_NODE")
            self.contracts[node] = c
            self.witnesses[node] = self.merge_witnesses(node)
        root = self.contracts[tree.root]
        return (entails(root.pre, tree.task_pre)
                and entails(root.post, tree.task_post)
                and entails(root.fail, tree.task_fail_safe)
                and all(self.witnesses[n] is not None for n in tree.actions()))

    def tick(self, tree, world, now):
        """一次 tick：先检查合同新鲜度与 Pre，再派发；失败走父节点回退。"""
        node = self.select_node(tree, world)
        c = self.contracts[node]
        if now - c.stamp > c.ttl:
            return self.abort_to_parent(node, world, "TTL_EXPIRED")
        if not c.pre(world):
            return self.abort_to_parent(node, world, "PRE_VIOLATED")
        if not self.locks.available(c.res):
            return self.abort_to_parent(node, world, "RESOURCE_BUSY")
        return node.step(world)
```

```python
# IP-427 Port Projection Certificate
@dataclass(frozen=True)
class PortSignature:
    K: "KinematicEnvelope"
    D: "DynamicEnvelope"
    S: FrozenSet[str]
    Cal: "CalibrationModel"
    Lambda: "LatencyModel"
    R: FrozenSet[str]


class PortProjector:
    def project(self, c: Contract, p: PortSignature) -> Optional[Contract]:
        # 1. 可实现性：端口必须能覆盖合同的任务域
        if not p.K.covers(c.domain):
            return None
        # 2. 投影：限制到端口域，并按标定/延迟放大裕度
        c_p = c.restrict(p.K.domain)
        c_p = c_p.inflate(p.Cal.uncertainty)
        c_p = c_p.inflate(p.Lambda.worst_case_margin)
        # 3. 资源相容
        if not c_p.res <= p.R:
            return None
        # 4. 保守性：投影回抽象域必须是原合同的子集
        if not entails(p.embed(c_p), c):
            return None
        return c_p

    def admissible_ports(self, c: Contract, ports) -> dict:
        out = {}
        for p in ports:
            cp = self.project(c, p)
            if cp is not None:
                out[p.id] = cp
        return out

    def multi_port_domain(self, c: Contract, ports) -> "SafeSet":
        adm = self.admissible_ports(c, ports)
        if not adm:
            return SafeSet.empty()
        return SafeSet.intersection([
            p.embed(cp) for p, cp in ((self.port_by_id[k], v)
                                      for k, v in adm.items())
        ])
```

```python
# IP-428 Multi-Port Deployment Orchestrator
class MultiPortDeploymentOrchestrator:
    def __init__(self, cbt, projector, cpig, auditor):
        self.cbt = cbt
        self.projector = projector
        self.cpig = cpig
        self.auditor = auditor

    def plan(self, tree, ports) -> "DeploymentPlan":
        if not self.cbt.certify(tree):
            return DeploymentPlan.rejected("CBT_NOT_CERTIFIED")
        contracts = {p.id: self.projector.project(self.cbt.root_contract, p)
                     for p in ports}
        adm = {pid: c for pid, c in contracts.items() if c is not None}
        if not adm:
            return DeploymentPlan.rejected("NO_ADMISSIBLE_PORT")
        # 干扰图与锁序
        g = self.cpig.build_graph(adm)
        order = self.cpig.lock_order(g)
        # canary：先选风险最低且资源独立的端口
        canary = self.cpig.least_coupled(adm, g)
        return DeploymentPlan(tree=tree, contracts=adm, graph=g,
                              lock_order=order, canary=canary,
                              skew_max=1, rollback=self.auditor.last_verified)

    def deploy(self, plan) -> "DeploymentCertificate":
        staged = []
        try:
            for pid in plan.rollout_order():
                if not self.stage(pid, plan):
                    raise DeploymentError("STAGE_FAILED", pid)
                staged.append(pid)
            for pid in staged:
                self.commit(pid, plan)          # 原子切换
                self.auditor.log_deploy(pid, plan.version)
        except DeploymentError:
            for pid in reversed(staged):
                self.rollback(pid)              # 只回滚到预认证版本
            raise
        return DeploymentCertificate(plan=plan,
                                     merkle_root=self.auditor.root())

    def stage(self, pid, plan) -> bool:
        # 装载、合同校验、预热、资源锁预检；不切换运行版本
        return (self.verify_contract(pid, plan)
                and self.warm_up(pid, plan)
                and self.cpig.precheck(pid, plan.graph))
```

```python
# IP-429 Cross-Port Interference Guard
class CrossPortInterferenceGuard:
    def build_graph(self, contracts) -> "InterferenceGraph":
        g = InterferenceGraph()
        for a, ca in contracts.items():
            for b, cb in contracts.items():
                if a >= b:
                    continue
                if ca.res & cb.res:
                    g.add_edge(a, b, weight=self.worst_case_interference(a, b))
        return g

    def can_run_concurrently(self, a, b, ca, cb) -> bool:
        if ca.res.isdisjoint(cb.res):
            return True
        comm = self.comm_witness(a, b)
        return comm is not None and comm.commutes(ca, cb) and comm.robust(ca, cb)

    def acquire(self, pid, resources, deadline) -> Optional[list]:
        # 全序、非阻塞、超时释放全部；禁止带锁重试
        acquired = []
        for r in sorted(resources, key=lambda x: self.order[x]):
            if not self.try_lock(r, deadline):
                for q in reversed(acquired):
                    self.unlock(q)
                return None
            acquired.append(r)
        return acquired
```

## 2. 关键定义与组合规则（定义 821–834）

**定义 821（节点合同）** 节点 `n` 的合同是一个七元组 `C_n = (Pre_n, Inv_n, Post_n, Fail_n, Res_n, TTL_n, Abort_n)`。合同是**可失败**的：它不承诺节点一定成功，只承诺成功时 `Post` 成立、失败时落入 `Fail` 且 `Abort` 已认证。

**定义 822（组合算子）** `Sequence(A,B)`、`Selector(A,B)`、`Parallel(A,B)`、`Retry_k(A)`、`Timeout_τ(A)`、`Guard_g(A)` 是合同上的部分算子；其定义域由 P34 的类型规则给出，值域仍是合同。

**定义 823（CBT 认证）** `Cert(T) = ⋀_{n∈V} ComposeOK(n) ∧ RootOK(T) ∧ ∀a∈Actions(T): W_π(a) ≠ ⊥`。`ComposeOK` 检查当前节点类型的类型规则；`RootOK` 检查根合同蕴含任务合同；`W_π` 是 v20 计划见证。

**定义 824（计划见证）** `W_π(n)` 是一条 v20 已认证计划 `π ∈ Exec_v20`，使得从 `n` 出发的任意 tick 轨迹 `τ` 的动作序列是 `π` 的子序列，且 `τ` 的合同蕴含 `π` 的合同。**没有见证的动作叶不编译**；这是 `Exec_v21 ⊆ Exec_v20` 的关键。

**定义 825（端口签名）** `σ_p = (K_p, D_p, S_p, Cal_p, Λ_p, R_p)`，分别刻画可实现构型/任务域、动力学包络、传感器集合、标定不确定度、延迟抖动、资源足迹。

**定义 826（端口投影）** `π_p(C) = {s_p ∈ S_p | ι_p(s_p) ∈ C ∧ s_p ∈ K_p ∧ res(s_p) ⊆ R_p}`，并在标定与延迟上放大裕度。投影必须满足 `ι_p(π_p(C)) ⊆ C`。

**定义 827（可采纳端口）** `P_adm(C) = {p | π_p(C) ≠ ∅ ∧ ι_p(π_p(C)) ⊆ C ∧ res(π_p(C)) ⊆ R_p}`。不可采纳端口不是“降级使用”，而是**不上线**。

**定义 828（多端口安全域）** `S_multi = ⋂_{p∈P_adm} ι_p(π_p(C))`。因为每个 `ι_p(π_p(C)) ⊆ C`，所以 `S_multi ⊆ C`；增加端口只会增加交集项。

**定义 829（跨端口干扰）** `I(A,B)` 是 A 对 B 的最坏扰动上界；`SafeConcurrent(A,B) = Res_A ∩ Res_B = ∅ ∨ (Comm(A,B) ∧ Inv_A 对 I(B,A) 鲁棒 ∧ Inv_B 对 I(A,B) 鲁棒)`。

**定义 830（部署证书）** `DC = (T, {C_n}, {σ_p}, {π_p}, G_int, rollout, merkle_root)`，其中 `rollout = (order, canary, skew_max)`。`DC` 可被独立验证器机械复核。

**定义 831（部署原子性）** 每个端口 `p` 的部署是 `stage(p,v) → commit(p,v)` 两阶段；`stage` 失败或超时则 `p` 保持旧版本；`commit` 是原子切换；任意时刻 `version_p ∈ {v_old, v_new}`，且 `|version_p - version_q| ≤ skew_max`。

**定义 832（回滚目标）** 回滚只允许到 `last_verified[p]`，且该版本必须携带预认证的 `DC`；禁止回滚到“曾经运行过但未认证”的版本。

**定义 833（Exec_v21）** `Exec_v21 = {(n,p,τ) | Cert(T) ∧ p ∈ P_adm(C_n) ∧ τ ∈ TickTrace(T) ∧ W_π(τ) ∈ Exec_v20 ∧ SafeConcurrent(τ, 其他活动端口) ∧ version_p 已认证}`。

**定义 834（运行模式）** `mode_btp` 按以下全序退化：`NORMAL → SERIAL → SINGLE_PORT → V20_FALLBACK → FROZEN`。任一模式只能使可执行集收缩。

## 3. 推导

**引理 157（行为树组合保安全性）** 若 `Cert(T)` 成立，则对任意 `τ ∈ TickTrace(T)`，`τ` 的每个成功前缀满足对应节点的 `Post`，每个失败前缀落入 `Fail` 且 `Abort` 已认证；因此组合不会把两个安全子节点拼成不安全的执行路径。证明：对树高归纳。动作叶由 v20 合同保证；Sequence 由 `Post_A ⇒ Pre_B` 与帧条件保证；Selector 由 `Fail_A ⇒ Pre_B` 或恢复节点保证；Parallel 由资源不交或可交换性见证保证；Retry 由 `Fail ⊆ Pre` 与 `Reset` 保证；Timeout 由 `Abort` 在 `τ` 内可达保证。∎

**引理 158（重试的幂等/复位条件）** `Retry_k(A)` 保安全，当且仅当 `Fail_A ⊆ Pre_A` 且存在 `Reset_A` 把失败后的世界状态与资源恢复到 `Pre_A`。若缺少复位见证，则存在反例：A 消耗资源或改写物体位置，重试在同一已改变的状态上执行，`Post` 不再成立。∎

**引理 159（端口投影保守性）** 若 `p ∈ P_adm(C)`，则 `ι_p(π_p(C)) ⊆ C`。证明：由定义 826 与定义 827 直接得到；投影只限制域、放大标定/延迟裕度、检查资源，不添加任何新的抽象状态。∎

**引理 160（多端口交集安全性）** `S_multi = ⋂_{p∈P_adm} ι_p(π_p(C)) ⊆ C`。增加端口只增加交集项，故 `S_multi` 单调不增；多端口不会扩张安全域。∎

**引理 161（跨端口并发与死锁自由）** 若锁按全序 `≺` 获取、非阻塞且带超时，则不存在循环等待；超时后释放全部锁并执行已认证回退。若 `SafeConcurrent(A,B)` 成立，则并发执行不破坏双方 `Inv`；否则必须串行或互斥。∎

**引理 162（部署原子性与回滚安全）** 两阶段提交保证每个端口在 `commit` 前保持旧版本、`commit` 后原子切换到新版本；`stage` 失败只影响该端口。回滚目标 `last_verified[p]` 是预认证版本，故任意时刻不存在未认证的运行版本。∎

**引理 163（v21 整体安全继承）** 在同一 v20 快照、同一端口集合下，`Exec_v21 ⊆ Exec_v20`。证明：CBT 只组合已认证子合同且每个动作叶携带 v20 计划见证；PPC 只收缩域；CPIG 只串行化或要求可交换性；MPDO 只做原子切换；DRA 只回滚到已认证版本。五者都是纯收缩/筛选算子，故 `Exec_v21 ⊆ Exec_v20`。∎

## 7. 已知风险与失效模式

1. **合同洗白（contract laundering）**：每个子节点的合同都真，但组合规则没有捕获跨节点的世界状态改写（物体被推走、夹爪闭合、资源未释放），导致“局部真、组合假”。缓解：把世界状态显式纳入 `Pre/Post/Fail` 帧，强制副作用追踪与复位见证。

2. **证书化活锁**：Selector/Retry 在同一感知误差下反复选择同一失败分支，形成“每轮都认证、每轮都失败”的循环。缓解：失败计数器 + 分支冷却 + 强制换分支/换观测；对同一 `Fail` 集的重复进入设置上限。

3. **端口投影的相关性幻觉**：多个端口共享同一标定链、同一时钟、同一相机型号，投影把同一系统性误差复制到所有端口；多端口交集看似更安全，实际只是同一错误的多次确认。缓解：标定链异构、时间源独立、跨模态佐证；把“共享标定”作为负证据而不是冗余。

4. **tick 间盲区**：BT 只在 tick 边界检查合同，tick 之间的扰动可能已经破坏 `Inv`。缓解：缩短 tick、加入连续守卫（硬件看门狗/力阈值）、把关键 `Inv` 下沉到控制层。

5. **资源模型过粗**：`Res` 只记录“机械臂/夹爪”，没有记录工作空间体积、气流、人机共享区，导致干扰图漏边。缓解：引入体积资源与时空占用证书、人在环检测。

6. **锁竞争与活性悬崖**：多端口并发退化为串行后，锁超时频繁触发回退，吞吐骤降。缓解：锁租约 + 优先级 + 非关键路径异步化；对回退率设置活性下界。

7. **版本偏斜与回滚竞态**：一个端口回滚、另一个端口提交，共享资源状态不一致。缓解：部署屏障（barrier）、版本栅栏、资源租约；回滚前先冻结共享资源。

8. **审计日志不完整**：漏记 tick 或合同哈希，导致 Merkle 证明无法复核。缓解：强制日志、批量签名、独立审计端口。

## 8. 本轮最大风险

**一句话**：多端口若共享同一标定链与同一时钟，端口投影会把同一系统性误差**复制**到所有端口，而行为树的 fallback 又会在同一误差上**循环重试**；于是每张局部证书都通过、每个端口都“认证”、整棵树却稳定地重复同一个错误——即“组合—投影联合幻觉”。
