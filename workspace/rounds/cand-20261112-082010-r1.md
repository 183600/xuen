# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「并发推理」×「数据标注」）

> 第 57 轮把安全的赌注从"模型置信"换到"证据承诺"，又用元少样本、跨模态对账、个性化信任把承诺垫高到五层纵深；但它的风险自陈指向一个更基础的地基：**"历史语料"本身是从哪来的？**如果语料是标注出来的，那么"坏先验普遍"其实是"坏标注普遍"的别名。同时，第 57 轮的证据是**串行**采集的：每多一次探针就多一拍延迟，安全与节拍被"一次只问一个问题"绑死。本轮两个灵感各拆一块地基：**并发推理**把串行取证改成"并行投机分支 + 提交时验证"，却立刻暴露一个反直觉事实——同一模型采 K 条链不是 K 份证据，而是同一个先验的 K 次复读；**数据标注**把"语料"从既成事实改成一份被主动获取、带噪声、带谱系、可追溯作废的**标注账本**。两者在同一个地方汇合：**独立性是唯一不可摊销的稀缺资源**。并发若不结构性去相关，只是在放大同一个错误；标注若不谱系化去偏，只是在把选择偏差固化成先验。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据承诺"升级为 **"并发去相关、标注去偏、独立性可计量的证据承诺"**。

核心矛盾：
- **H29（并发 vs 独立）**：K 路并发推理的"自一致"不是证据，而是同一个模型/先验/语料/归纳偏置的 K 次复读；错误相关 ρ_B 把有效票数从 K 折成 K_eff=K/(1+(K−1)ρ̄_B)。并发的收益是**延迟**，不是**信息**；把延迟当信息，就是当代推理系统最危险的幻觉。
- **H30（并发 vs 物理单写）**：信念空间可以并行，物理世界只有一个写者。只读探针能并发，可回滚接触要加锁串行，不可逆接触一旦被"投机执行"就无法回滚。并发必须先把探针分成只读/可回滚/不可逆三类，并让冲突图决定谁可以同时跑。
- **H31（标注 vs 真相与去偏）**：标注是带噪观测，不是世界本身；主动标注"只标不确定处"会制造选择偏差，使语料恰好缺失系统最需要的覆盖，反过来毒化元先验——越主动，越偏。多个标注者/弱标注器若同源同训同班次，错误相关，多数票会把同一个错误抬成"共识"（标注共谋）。

## 0. 直觉与动机

**灵感 1（并发推理 → 投机证据分支 STS）**
直觉：把"一次只问一个问题"改成"同时开 K 条假设线，每条线自带探针计划；只在提交那一刻，要求被选中的那条线独立过完整证据门，其余线随时丢弃。"这像 CPU 的投机执行：并行猜测、提交时校验、猜错回滚。但机器人比 CPU 多一条铁律——**世界只有一个写者**。只读探针可无锁并发；可回滚接触加写锁串行；不可逆接触永不投机。并发真正的收益不是"更多证据"，而是"更早收敛到需要哪一条证据"：投机把最坏延迟从 K·t 压到接近 t，但绝不把 K 个相关猜测变成 K 份独立证据。

**灵感 2（并发推理 → 去相关证书与有效票数）**
直觉：并发分支要产生信息，必须在结构上不同源：不同模态、不同元训练子集、不同物理探针、不同近似阶、不同失效模式。给出**去相关证书**：声明分支间错误相关上界 ρ̄_B 与有效分支数 K_eff=K/(1+(K−1)ρ̄_B)。只有 K_eff 能进证据门；K_eff<2 时，并发只算延迟优化，不产生"共识"这一类证据。这直接继承第 57 轮"同一模态问五遍"的教训，并把它从模态推广到推理与标注：**自一致性必须被折现**。

**灵感 3（数据标注 → 标注是账本不是真相）**
直觉：一条标注是"某人在某时刻、依据某模态、经过某方法、对某事件给出的带噪观测"，它应有价格（获取成本）、有误差模型（标注者×项目难度）、有谱系（由哪些父标注/模型派生）、有保质期（事后实测可作废）。把标注当真相，是把"观测"偷换成"世界"。主动标注不是"想知道什么就问什么"，而是"在分层覆盖约束下、以最小成本降低元后验的悲观 VOI"，且必须用倾向权重 IPW 或预注册抽样偿还"只标不确定处"这笔选择偏差的债。

**灵感 4（数据标注 → 谱系化回溯作废）**
直觉：第 57 轮已有"事后证伪回溯降权某模态"。本轮把它从"模态级"下沉到"标注级"：一条实测判决可以作废它所有后代标注（弱标注、聚合标注、人工修正），触发元模型版本的级联降级与回滚（接第 57 轮 CEB++ 的影子隔离）。语料因此不是只增不减的堆，而是一棵可修剪的 DAG；被污染的子树不能继续给先验供血。

**灵感 5（两灵感合流 → 独立性是会计科目）**
直觉：跨模态一致（第 57 轮 EV-xmodal）、多标注者一致（本轮 EV-annot）、并发分支一致（本轮）本质是同一件事：**消耗"独立性预算"换取佐证**。相关来源共享同一个预算单位。于是证据门从"数票"变成"记独立性的账"：每个佐证声明其有效独立数 n_eff，超过预算的票不计。击穿安全不再需要"K 个来源同时错"，而是要求**所有结构性独立来源同时错**——这才是正确的纵深。

**灵感 6（PCE++ → 并发投机探询 × 主动标注获取 × 提交时验证）**
直觉：检查点上同时开投机探针与标注请求；提交只认被选中分支的**本地账本**（分支可合并信念，永不合并证据）；标注按 VOI 获取、按谱系入账、按随机金标审计；一旦冲突图报告写冲突或 n_eff 跌破阈值，立即降级为串行/绕行。并发只加速"更准（含加宽）或更保守"两条安全通道，绝不开第三条升险通道。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（并发投机证据分支 SCE）** 分支集 B={β_1,…,β_K}，β_k=(θ_k,π_k,E_k,b_k) 为该分支的假设/探针计划/本地证据账本/信念。并发仅在只读探针集上展开。合并算子 ⊔ 只作用于信念 b，**永不作用于证据 E**；若提交分支 β_{k\*} 的账本引用了其他分支的观测，记为跨支复用并按其独立预算扣减。提交时验证：β_{k\*} 必须独立通过 FSE（定义 137 的升级版），未提交分支的信念以投机折扣 λ_spec≤1 只影响探询排序、绝不进入 P_fail。去相关证书：声明 ρ̄_B 的上界与 K_eff=K/(1+(K−1)ρ̄_B)；K_eff<2 时并发不产生共识类证据。

**定义 140（物理单写者与回滚分级 PSR）** 每个探针/接触 p 带写等级 r(p)∈{RO 只读, RV 可回滚, IR 不可逆} 与物理足迹 fp(p)⊆世界格。并发许可：{p_i} 两两 fp 不相交且全为 RO 时可无锁并发；RV 经单写者锁串行并可回滚到检查点；IR 永不投机、永不加锁并发，其证据必须来自已提交分支。冲突图 G_cf=(探针, 足迹相交边) 在冲突时把调度降级为串行；回滚成本 c_rb(p) 计入 VOI，使"投机"在期望上不免费。

**定义 141（主动标注获取 AAL）** 标注预算 B_ann，候选事件 e，采集函数 A(e)=VOI_meta^pess(e)−cost(e)−redundancy(e)。选择策略 π_sel 必须满足分层覆盖约束（材质×季节×坡度每层≥n_min）与探索配额（ε 比例随机标注）。入账用倾向权重 w(e)=1/π_sel(e)（IPW）或预注册抽样，偿还选择偏差；元语料分布 q_corpus 与部署分布 p_deploy 的差异以覆盖审计披露。ε_meta 的声明必须计入标注噪声与 IPW 方差，不能只在 ID 数据上报一个好看的 ECE。

**定义 142（标注谱系与噪声模型 ALN）** 标注 ℓ=(ŷ,a,t,m,method,parents)，父节点可为其他标注/模型输出/实测，形成 DAG。噪声模型 P(ℓ|y,a,d)=Confusion(a,d)；标注者校准 cal_a 由随机注入、标注者不可区分的金标集 G（已知 y）估计准确率/ECE。作废算子 Invalidate(p)：若实测判决 y\* 与某祖先冲突，作废其后代子树、重算聚合标注、并把受影响的元模型版本降级回滚。有效样本 n_eff(e)=n/(1+(n−1)ρ̄_a)，ρ̄_a 为标注者错误相关（同源/同训/同班次可测）。

**定义 143（并发标注仲裁 CAJ 与 EV-annot）** 对同一事件 e 的标注集 {ℓ_{e,a}}，用潜变量真值模型（Dawid–Skene 型）聚合出后验 ŷ_e 与一致度 κ_e，并以 n_eff 折减票数。EV-annot ⇔ 谱系完整 ∧ 标注者在金标上校准达标 ∧ n_eff≥n_min ∧ **非循环**（该标注不是系统仅凭自身不确定性主动选中、且未经 IPW/预注册校正）∧ 仅用于 L1 佐证，不得进入不可逆接触必要证据集。标注共谋检测：若 ρ̄_a>ρ_max 或标注由同一弱标注器派生，则合并为一个独立单位，多数票不增信。

**定义 144（PCE++ 算子与证书 J_s）** 每检查点：①并发投机（RO 分支并行、G_cf 调度、IR 硬禁）；②并发主动标注（按 A(e) 获取、随机金标注入、按谱系入账）；③提交时验证：仅 β_{k\*} 的本地账本过 FSE，EV-probe\*/EV-xmodal/EV-annot 共享独立预算 I_budget；④合并信念但不合并证据；⑤若写冲突/n_eff 不足/账本跨支复用 → 降级串行或绕行；⑥当 R>δ_f 且无证据 → L2 协商或安全停。证书 J_s=(分支账本,G_cf,ρ̄_B/K_eff,标注账本,谱系 DAG,噪声/校准日志,金标审计,IPW 权重,覆盖报告,作废事件)，继承 J_p 全检。

## 2. 关键算法伪代码（完整版见产物区）

```python
def speculative_probe(M, cp, branches, budget):        # IP-139/140 合流
    ready = conflict_schedule(branches, M)             # G_cf: 仅 RO 且足迹不交
    obs = parallel_map(execute_readonly, ready)        # RV 走单写者锁；IR 不进此列
    for b, o in zip(ready, obs):
        b.E.append(o)                                  # 证据只进本地账本
        b.b = bayes_update(b.b, o.like, w=o.w)
    return M, branches                                 # 信念可共享，证据不共享

def active_annotate(M, events, budget, strata):        # IP-141
    for e in events:
        e.pi = clip(pi_selection(e, strata), PI_MIN, 1)  # 覆盖约束 + ε 探索
    while budget.left > 0:
        e = argmax(events, key=lambda x: A(x) - redundancy(x, M))
        if A(e) < theta_ann: break
        ell = acquire_label(e, annotators_pool(e))       # 并发请求、随机插金标
        M = lineage_insert(M, ell, weight=1 / e.pi)      # IPW 入账
        budget.spend(e)
    return M

def commit_verified(M, cp, branches, persona, ood_reg):  # IP-139 提交时验证
    k = argmax(branches, key=lambda b: b.score)
    if any(src not in branches[k].E for src in referenced_evidence(branches[k])):
        return ('reject', 'cross_branch_evidence')      # 证据不可跨支借用
    if K_eff(branches) < 2 and branches[k].ev == 'consensus':
        return ('reject', 'pseudo_consensus')           # 相关分支不算共识
    return few_shot_evidence_gate_p(cp, branches[k], persona, ood_reg)

def invalidate_lineage(M, verdict):                     # IP-142 回溯作废
    root = ancestor(verdict.item_id)
    for node in descendants(root):                      # DAG 子树
        node.weight = 0; M.meta_versions.demote(node)   # 触发元模型回滚
    return M
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| SCE | O(K·t_ro) 墙钟（串行 K·t） | O(K·(\|E\|+\|π\|)) | 证据分支本地、K_eff 折现、IR 不入投机 |
| PSR | O(\|G_cf\|) 调度 | O(\|探针\|²) 冲突图 | 单写者、回滚分级、IR 硬禁 |
| AAL | O(\|E_ann\|·(C_VOI+C_red)) | O(\|标注账本\|+\|分层\|) | IPW/预注册、覆盖约束、ε 探索 |
| ALN | O(\|DAG\|) 插入/作废 | O(\|DAG\|) | 谱系完整、作废传递、金标不可辨 |
| CAJ | O(\|标注\|·\|标注者\|·T) | O(\|标注者\|·\|项目\|) | n_eff 折减、共谋合并、非循环 |
| PCE++ | O(\|CP\|·(K·t_ro+k_c)·(C_VOI+d_φ)) | O(K·\|V\|+\|σ\|+\|DAG\|) | 投机有界、标注预算有限、终止 |

**正确性定理（CIAS 概要）**：在 A33–A40 上加 (A41) 分支去相关证书诚实（ρ̄_B 上界、K_eff 计算）；(A42) 物理单写者被遵守、回滚等级正确、IR 永不投机；(A43) 标注噪声与谱系诚实、金标注入不可被标注者识别、IPW 倾向正确；(A44) 独立性预算核算诚实（相关来源共享一个单位，EV-xmodal/EV-annot 仅限 L1）。则：(i) 提交失效率 ≤ δ_f+ε_meta(k;噪声,IPW)+δ_probe+ε_h+δ_spec(K_eff)，其中 δ_spec 只随 K_eff 下降、不随名义 K 下降；(ii) 并发只影响延迟与探询排序，ρ̄_B=1 时 P_fail 与 K 无关（并发不改变信息量）；(iii) IPW 正确时元语料估计无偏，否则偏差被覆盖缺口显式界住；(iv) 谱系完整时被证伪祖先的后代不能进入任何已提交证据；(v) PCE++ 在投机分支数、共识探针 k_c 与标注预算 B_ann 内终止。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |

## 6. 本轮最大风险

**一句话**：本轮最大的风险是把"并发"与"多标注者"误当作独立证据来源——若推理分支、标注者与弱标注器共享同一个先验、同一段语料或同一个物理世界，n 个相关来源的"共识"只是同一个错误的 n 次复读，而主动标注的选择偏差又恰好把这个错误集中在系统最不确定的地方；必须以 K_eff/n_eff 折现、去相关证书、单写者与谱系作废为四重护栏，宁可放弃并发带来的速度，也不透支"独立性"这项唯一不可摊销的资源。

## 2. 关键算法伪代码

### IP-139 SCE（并发投机证据分支）

```python
def spawn_speculative_branches(M, cp, K, meta):
    thetas = structurally_diverse_hypotheses(M, cp, K)   # 不同模态/子集/近似阶
    branches = [Branch(theta=th,
                       plan=plan_probes(M, cp, th),
                       E=Ledger(), b=init_belief(th)) for th in thetas]
    return branches

def merge_belief_only(branches, weights):                 # ⊔: 只合并信念
    b = mixture([br.b for br in branches], weights)
    return b                                             # 证据账本 E 不合并

def commit_time_verify(branches, cp, gate_ctx):
    k = argmax(range(len(branches)), key=lambda i: branches[i].score)
    bk = branches[k]
    # 1) 证据必须全部来自本分支账本（防跨支复用制造假证据）
    for ev in bk.used_evidence:
        if ev not in bk.E: return ('reject', 'cross_branch_evidence', k)
    # 2) 共识类证据要按有效独立数折现
    if bk.ev == 'consensus' and K_eff(branches) < 2:
        return ('reject', 'pseudo_consensus', k)
    # 3) 未提交分支的信念不进入 P_fail（只影响探询排序）
    return few_shot_evidence_gate_p(cp, bk, gate_ctx)

def K_eff(branches):
    rho = estimate_error_correlation(branches)            # 声明上界 + 实测
    K = len(branches)
    return K / (1 + (K - 1) * rho)
```

### IP-140 PSR（物理单写者与回滚分级）

```python
def conflict_schedule(branches, M):
    probes = [p for br in branches for p in br.plan if p.ready]
    allowed = [p for p in probes if write_level(p) == 'RO']
    # 极大独立集：足迹不相交才允许同批
    batch = greedy_max_independent_set(allowed, conflict_graph(probes))
    for p in probes:
        if write_level(p) == 'RV' and p not in batch:
            p.enqueue(single_writer_lock(p.footprint))    # 串行、可回滚
        if write_level(p) == 'IR':
            p.forbid_speculation()                       # 永不投机、永不并发
    return batch

def execute_readonly_batch(batch):
    return parallel_map(execute_readonly, batch)          # 墙钟并行

def rollback_to(checkpoint):
    assert checkpoint.r == 'RV'                          # IR 不可回滚 → 不可投机
    return restore(checkpoint)
```

### IP-141 AAL（主动标注获取，含 IPW 去偏）

```python
def active_annotation(M, events, budget, strata):
    for e in events:
        raw = pi_base(e, strata)                         # 元先验下的选择倾向
        e.pi = clip(raw, PI_MIN, 1.0)
    while budget.left > 0:
        # 覆盖不足的层优先（防止主动标注把语料越采越偏）
        cands = [e for e in events if coverage_ok(e, strata) or coverage_deficit(strata)]
        if not cands: break
        e = max(cands, key=lambda x: A(x) - redundancy(x, M))
        if A(e) < theta_ann: break
        # 并行请求多个标注者，随机插入金标（不可被识别）
        labels = parallel_label(e, annotators=annotators_pool(e),
                                gold=random_inject(e))
        M = lineage_insert(M, labels, weight=1.0 / e.pi)  # IPW 入账
        budget.spend(e)
    audit_coverage(M, strata)                            # 披露 q_corpus vs p_deploy
    return M
```

### IP-142 ALN（标注谱系、噪声与回溯作废）

```python
def lineage_insert(M, labels, weight):
    for ell in labels:
        ell.parents = resolve_parents(ell)               # 标注/模型输出/实测
        ell.weight = weight * reliability(ell.annotator, ell.item)
        M.dag.add(ell)                                   # DAG 节点
        M.aggregate[ell.item] = latent_truth_posterior(M, ell.item)
    return M

def invalidate_lineage(M, verdict):
    root = ancestor_of(verdict.item_id, M.dag)
    affected = descendants(root)                         # 后代子树
    for node in affected:
        node.weight = 0.0
        for mv in M.meta_versions.depending_on(node):
            mv.demote()                                  # 触发影子回滚
    M.aggregate = recompute_aggregates(M, affected)
    M.audit.log(('invalidate', root.id, len(affected), t_now))
    return M
```

### IP-143 CAJ（并发标注仲裁与 EV-annot）

```python
def adjudicate(item, labels, gold_stats):
    # Dawid–Skene 型：联合估计真值后验与各标注者混淆矩阵
    y_hat, conf = latent_truth_em(labels, priors=gold_stats.confusion)
    kappa = fleiss_kappa(labels)
    rho = estimate_annotator_correlation(labels, gold_stats)
    n = len(labels)
    n_eff = n / (1 + (n - 1) * rho)
    return y_hat, conf, kappa, n_eff

def annot_evidence(item, labels, gold_stats, level):
    y_hat, conf, kappa, n_eff = adjudicate(item, labels, gold_stats)
    if level != 'L1': return None                        # 不可逆接触不可用
    if not lineage_complete(item) or n_eff < n_min: return None
    if not all(calibrated(a, gold_stats) for a in annotators(labels)): return None
    if estimate_annotator_correlation(labels, gold_stats) > rho_max:
        return None                                      # 标注共谋：不增信
    if is_circularly_selected(item): return None         # 主动标注自证循环
    return 'EV-annot'
```

def probe_commit_evolve_plus_plus(x0, M, task, budget, consent, personas, meta):

### IP-137→FSE-II（证据门升级：加入 EV-annot 与独立预算）

```python
def few_shot_evidence_gate_p(c, branch, ctx):
    M, personas, ood_reg = ctx
    if   c.ev == 'EV-probe*':
        ok = (c.inf.cls == 'ID' and c.inf.ece_k <= eps_meta(c.k)) or \
             (c.inf.cls == 'OOD' and c.region in ood_reg.certified)
    elif c.ev == 'EV-xmodal':
        ok = c.level == 'L1' and c.indep_declared and D(c.region) <= theta_D
    elif c.ev == 'EV-annot':
        ok = c.level == 'L1' and c.n_eff >= n_min and c.lineage_complete \
             and not c.circular and c.rho_a <= rho_max
    elif c.ev == 'EV-human':
        ok = personas[c.op].auth >= 'A1' and c.corrob >= quarantine_exit(personas[c.op].auth)
    elif c.ev in ('EV-visit', 'EV-margin'):
        ok = round57_checks(c, M)
    else:
        return ('reject', 'no_evidence_class', c)
    # 独立性预算：相关来源共享一个单位，超出预算的佐证不计
    if not independence_budget_ok(c.indep_units, c.n_eff, branch):
        return ('reject', 'independence_overdrawn', c)
    if c.irreversible and c.ev in ('EV-xmodal', 'EV-annot'):
        return ('reject', 'corroboration_on_irreversible', c)
    if not ok: return ('reject', 'evidence_insufficient', c)
    return ('ok', c)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SCE | O(K·t_ro) 墙钟；串行 O(K·t) | O(K·(\|E\|+\|π\|)) | 证据分支本地、K_eff 折现、IR 不入投机（A41） |
| PSR | O(\|G_cf\|) 调度 | O(\|探针\|²) | 单写者、回滚分级、IR 硬禁（A42） |
| AAL | O(\|E_ann\|·(C_VOI+C_red)) | O(\|账本\|+\|分层\|) | IPW/预注册、覆盖约束、ε 探索（A43） |
| ALN | O(\|DAG\|) 插入/作废 | O(\|DAG\|) | 谱系完整、作废传递、金标不可辨（A43） |
| CAJ | O(\|标注\|·\|标注者\|·T) | O(\|标注者\|·\|项目\|) | n_eff 折减、共谋合并、非循环（A43/44） |
| FSE-II | O(\|σ\|) | O(\|σ\|) | 六类证据、独立预算、L1 硬限 |
| PCE++ | O(\|CP\|·(K·t_ro+k_c)·(C_VOI+d_φ)) | O(K·\|V\|+\|σ\|+\|DAG\|) | 投机有界、标注预算有限、终止 |

**正确性定理（Concurrency–Independence–Annotation Soundness, CIAS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 分支去相关证书诚实：ρ̄_B 为上界、K_eff 按定义计算、结构多样性可审计；**(A42)** 物理单写者被遵守：RO/RV/IR 等级声明正确、IR 永不投机、RV 可回滚、冲突图不漏判；**(A43)** 标注噪声与谱系诚实：Confusion(a,d) 与 cal_a 可测、金标注入对标注者不可辨、IPW 倾向 π_sel 正确；**(A44)** 独立性预算核算诚实：相关来源共享一个预算单位，EV-xmodal/EV-annot 仅限 L1，不进入不可逆接触必要证据集。则：

1. **提交健全性**：对检查点 cp，P(fail) ≤ δ_f + ε_meta(k; 噪声, IPW) + δ_probe + ε_h(w_max) + δ_spec(K_eff) + δ_ann·1[EV-annot]，其中 δ_spec 随 K_eff 单调不增、与名义 K 无关；当 ρ̄_B=1 时 K_eff=1，并发不贡献任何信息，P(fail) 退化为串行情形。
2. **并发只买延迟**：对任意 K，若分支完全相关，则 P_fail(K)=P_fail(1)；并发的收益仅体现在墙钟与探询排序，不改变后验信息量。这阻断了"自一致性 → 假置信"的升险通道。
3. **标注去偏**：若 IPW 倾向正确，元语料风险估计无偏；否则偏差被覆盖缺口 max_s |q_corpus(s)−p_deploy(s)| 显式界住，并在 J_s 中披露。作废传播完备时，被证伪祖先的后代不能进入任何已提交证据。
4. **独立性会计**：跨模态一致、多标注一致、并发一致共享 I_budget；任一来源的"票"需按 n_eff/K_eff 折减，超出预算即拒。因此击穿证据门要求所有结构性独立来源同时错，而非任意相关来源同错。
5. **终止性**：每检查点投机分支 ≤K，共识探针 ≤k_c，标注获取 ≤B_ann；PCE++ 在 K·k_p+k_c + B_ann 步内终止于 {承诺, 绕行, L2 协商, 安全停}。

**部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k;噪声,IPW) + δ_probe + ε_h + δ_spec(K_eff) + δ_ann·1[EV-annot])
             − P(写冲突未检出) − P(谱系作废未传播) − P(IPW 倾向系统性错误)
             − P(护盾回退失败) − P(τ_int ∧ 安全停失效)
```

关键：**并发给速度、去相关给信息**（K_eff 才是票数，K 只是线程数）；**标注给覆盖面、谱系给可信度**（IPW 还选择偏差的债、DAG 还作废的债）；**独立性是唯一不可摊销的资源**——跨模态、多标注、多分支三处一致共用同一本独立预算账，任何"多来源共识"都必须先申报有效独立数。

## 6. 本轮最大风险

**一句话**：本轮最大的风险是"伪独立"——把同一个先验的 K 次并发采样、同源同训的多个标注者、同一物理世界的一次观测，误记成多份独立证据；一旦独立性被这样透支，并发与主动标注会以更高速度、更强选择性把系统最不确定处的同一个错误固化成"共识"，且其错误恰好集中在覆盖最薄弱的层，四重护栏（K_eff/n_eff 折现、去相关证书、单写者、谱系作废）中任何一环被绕过，整个独立性会计就退化为自欺。
