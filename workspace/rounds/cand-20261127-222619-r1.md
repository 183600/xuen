### 第 1 轮灵感驱动研究记录（新循环，承接 CADVS-v3）

**灵感词**：模仿学习、续航能力

**继承关系**：当前状态中的 CADVS-v3（IP-485~488）已把「证据铸造」推进到五硬门 kc_evidence_forged_v3 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem，执行集 Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。本轮作为新循环的第 1 轮，不推翻 v3，而是用「模仿学习」补上策略侧的能力边界、用「续航能力」补上证据侧的资源边界，形成 CADVS-v4（IP-489~492），硬门扩展为七门，执行集升级为 Exec_CADVS-v4 ⊆ Exec_CADVS-v3，并进一步引入「能量弹性执行集族」{Exec_CADVS-v4(B)}。

**直觉与动机**：

1. **模仿学习：示范支撑就是能力的边界**。行为克隆（BC）/DAgger 得到的策略 π_I 廉价、快速、省算力，天然「续航友好」；但它的正确性只在示范分布 D_n 的支撑内被保证，支撑外是未经验证的外推。一条在示范里从未出现过的状态，模仿策略仍会给出一个看似合理的动作——这正是最危险的失效模式。因此需要一个「模仿能力证书」ICC，用示范密度 q_D(s) 与策略集成分歧 u(s) 共同界定 kc_imit：既在分布内、又低不确定性，才允许消费模仿动作。

2. **续航能力：证据本身也要耗电**。v2/v3 的覆盖、物理、人因、末端、记忆证据都不是免费的：体素刷新、SPRT 复核、教师查询、示范采集、末端力/触觉采样都要消耗电量。而机器人执行任务、返航、急停同样吃同一块电池。于是出现一个被 v1~v3 完全忽略的耦合：**维护证书可信度与执行任务在争夺同一份能量预算**。低电量时若继续大功率验证，会加速耗尽；若为省电而停止验证，证书会因证据陈旧而衰减。安全机制不能假设「证据无限供给」。

3. **二者合流：真正的约束不是「策略能否安全行动」，而是「我们是否负担得起让策略安全行动的证据」**。模仿策略把每步计算成本压到最低，但把风险集中到分布外；证据更新用能量把分布外风险压回去。二者通过电池耦合。据此引入：能量预留硬门 kc_energy（保证永远留得下安全急停/返航的能量）、能量感知的证据更新调度器 ERS（在 act / verify / learn 之间按「单位焦耳安全覆盖增益」分配）、以及证书新鲜度随燃料 F(t) 衰减的机制。结果是：电量越低，证书覆盖越薄，执行集越小——**fail-closed 从「状态相关」升级为「能量相关」**。

4. **关键洞见**：v3 回答「证据在不在、成不成立、谁背书、末点真不真、历史上可不可靠」；v4 追加「策略在此处是否被示范支撑」（kc_imit）与「我们是否留得起安全退路」（kc_energy），并把「证据」从静态资产变成需要持续供能的**可耗竭资产**。执行集不再是一个固定集合，而是一族随剩余电量单调收缩的集合 {Exec_CADVS-v4(B)}，B 越低集合越小。七硬门 fail-closed；软评分 ECS_v4 仅用于分级与仪表盘。

**形式化目标（增量）**：

1. 定义示范集 D_n = {(s_i, a_i)}_{i=1..n} ~ π_E、模仿策略 π_I（BC 或 DAgger），示范密度 q_D(s)（kNN/核密度）、集成分歧 u(s) = Var_{k}(π_k(s))；定义模仿能力证书 ICC 与硬门 kc_imit(s) = (q_D(s) ≥ ρ) ∧ (u(s) ≤ u_tol)。
2. 定义电池状态 B(t) ∈ [0, B_max]、功率 P(t) = P_act + u·P_verify + v·P_demo；定义安全预留 B_reserve(t) = P_stop·T_stop + B_margin 与硬门 kc_energy(t) = B(t) ≥ B_reserve(t)（且存在可行返航/急停轨迹）。
3. 定义证据燃料 F(t)（对近期验证/采集能量的折扣累积）与证书覆盖 ρ(F)（单调、凹）；证据陈旧以率 λ 衰减，故覆盖随「停止供能时长」指数下降。
4. 定义能量感知证据更新调度器 ERS：在预算 ∫P dt ≤ B_0 − B_reserve 下，最大化安全覆盖增益；覆盖函数对「被验证区域集合」单调子模，采用单位焦耳边际增益贪心，得 (1−1/e) 近似。
5. 定义 EFA-v4 七硬门与能量弹性执行集 Exec_CADVS-v4(B) ⊆ Exec_CADVS-v3，且 B_1 ≤ B_2 ⟹ Exec_CADVS-v4(B_1) ⊆ Exec_CADVS-v4(B_2)。

**本轮最大风险**：**能量与证据的死亡螺旋**——低电量时验证会加速耗电、停止验证又让证书陈旧失效，若调度失当，机器人可能在「为安全而验证」与「为续航而省电」之间反复横跳，最终陷入 fail-closed 瘫痪（原地拒绝一切动作）或为省电跳过验证而放大模仿策略的分布外风险，安全机制反而消耗了它所要保护的续航。

## 2. 关键算法骨架

### IP-489 ICC：模仿能力证书（规则/策略准入时查询，O(log n)）

```python
@dataclass
class ImitationCompetenceCertificate:
    """ICC：用示范支撑 + 集成分歧界定模仿策略可信域；kc_imit 硬门"""
    rho: float = 0.05           # 示范密度阈值（由留出集校准）
    u_tol: float = 0.1          # 集成分歧容忍
    k: int = 8                  # kNN 邻居数
    delta: float = 1e-3         # 覆盖估计置信度

    def support(self, s: np.ndarray, D_feats: np.ndarray) -> float:
        """q_D(s)：kNN 逆距离密度，越接近示范流形越大"""
        d = np.linalg.norm(D_feats - s, axis=1)
        kth = np.partition(d, self.k)[: self.k + 1]
        return 1.0 / (kth.mean() + 1e-9)

    def disagreement(self, s: np.ndarray, ensemble: list) -> float:
        """u(s)：K 个策略在 s 处输出动作的方差迹"""
        acts = np.stack([p(s) for p in ensemble])
        return float(np.trace(np.var(acts, axis=0)))

    def kc_imit(self, s: np.ndarray, D_feats: np.ndarray, ensemble: list) -> bool:
        """引理 41：通过 ⟹ s 在示范支撑内且策略低分歧，外推风险受控"""
        return (self.support(s, D_feats) >= self.rho
                and self.disagreement(s, ensemble) <= self.u_tol)

    def coverage_ci(self, q_hat: float, n: int) -> tuple[float, float]:
        """DKW/二项置信：用 n 条示范给出覆盖率的 [lo, hi]"""
        eps = np.sqrt(np.log(2.0 / self.delta) / (2.0 * n))
        return max(0.0, q_hat - eps), min(1.0, q_hat + eps)
```

### IP-490 EBG：续航预算治理器（每控制周期，O(1)）

```python
@dataclass
class EnduranceBudgetGovernor:
    """EBG：电池 + 安全预留；kc_energy 硬门，每控制周期 O(1)"""
    B_max: float = 1000.0       # Wh（归一化单位）
    P_stop: float = 50.0        # W，急停/制动功率
    T_stop: float = 2.0         # s，最坏急停时长
    B_margin_frac: float = 0.05 # 余量占满电比例

    def reserve(self) -> float:
        return self.P_stop * self.T_stop + self.B_margin_frac * self.B_max

    def kc_energy(self, B: float, has_return_path: bool = True) -> bool:
        """引理 42：通过 ⟹ 剩余电量足够执行一次最坏情形安全急停/返航"""
        return B >= self.reserve() and has_return_path

    def time_to_empty(self, B: float, P: float) -> float:
        """在预留之外还能支撑多久（用于软层与调度）"""
        if P <= 0:
            return float('inf')
        return max(0.0, (B - self.reserve()) / P)

    def eta_e(self, B: float) -> float:
        return float(np.clip((B - self.reserve()) / self.B_max, 0.0, 1.0))
```

### IP-491 ERS：能量感知证据更新调度器（异步，规则准入/慢时域）

```python
@dataclass
class EvidenceRenewalScheduler:
    """ERS：在预算内最大化安全覆盖；覆盖对区域集合单调子模 → 贪心 (1-1/e)"""
    lam: float = 0.01           # 证据陈旧衰减率 1/s
    P_verify: float = 5.0       # W，验证单位区域功率
    P_demo: float = 40.0        # W，采集一条示范功率
    delta: float = 1e-3

    def coverage(self, regions: set, F: dict) -> float:
        """ρ(F)：已被供能区域的覆盖并集（子模），陈旧燃料折减"""
        return float(sum(min(1.0, F.get(r, 0.0)) for r in regions))

    def marginal_gain_per_joule(self, region, F, dF: float) -> float:
        """单位焦耳带来的覆盖边际增益（贪心排序键）"""
        cur = min(1.0, F.get(region, 0.0))
        nxt = min(1.0, F.get(region, 0.0) + dF)
        return (nxt - cur) / (self.P_verify * dF + 1e-9)

    def schedule(self, B: float, regions: list, budget: float) -> dict:
        """按 marginal_gain_per_joule 从高到低分配；预算耗尽即停"""
        F = getattr(self, '_F', {})
        alloc, spent = {}, 0.0
        for r in sorted(regions, key=lambda r: -self.marginal_gain_per_joule(r, F, 1.0)):
            cost = self.P_verify
            if spent + cost > budget:
                break
            alloc[r] = 1.0
            spent += cost
        return alloc

    def decay(self, F: dict, dt: float) -> dict:
        """无供能时证据燃料指数衰减，覆盖随之下降"""
        return {r: f * np.exp(-self.lam * dt) for r, f in F.items()}
```

### IP-492 EFA-v4：七硬门 + 能量弹性执行集

```python
@dataclass
class EvidenceForgingAssemblerV4:
    """EFA-v4：七硬门 fail-closed；软评分仅分级，不参与安全决策"""
    scf: SpatialCoverageFieldKernel
    msrg_cache: dict
    hic: HumanIntentCertificateKernel
    eek: EndEffectorFidelityKernel
    ltem: LongTermEpisodicMemory
    icc: ImitationCompetenceCertificate
    ebg: EnduranceBudgetGovernor
    mu_S: float = 0.75
    w: tuple = (0.4, 0.4, 0.2)

    def hard_gate(self, x, t_now, rule_id, hic, eec: EEC, s: np.ndarray,
                  D_feats, ensemble, B: float, has_return_path: bool,
                  object_class, geo_sig, theta_domain_fp) -> tuple[bool, str]:
        if self.hic.veto_active(hic):             return False, 'HIC_STOP'
        if not self.ebg.kc_energy(B, has_return_path):
            return False, 'ENERGY_RESERVE'          # 先查资源：没有退路不冒险
        if not self.scf.kc_coverage(x, t_now):    return False, 'COVERAGE_BLIND'
        s2rc = self.msrg_cache.get(rule_id)
        if s2rc is None or s2rc.verdict != 'accept' or s2rc.mu_pass < self.mu_S:
            return False, 'PHYSICS_UNPROVEN'
        if not self.eek.kc_ee(eec):               return False, 'EE_UNPROVEN'
        pass_mem, eta_mem, novelty = self.ltem.query(
            object_class, geo_sig, theta_domain_fp, rule_id)
        if not pass_mem:                          return False, 'MEMORY_REJECT'
        if not self.icc.kc_imit(s, D_feats, ensemble):
            return False, 'IMIT_OOD'                # 示范支撑外：拒绝外推
        return True, 'FORGED' + ('|NOVELTY' if novelty else '')

    def ecs_v4(self, x, t_now, rule_id, B, eta_imit, A_att=0.0, eta_mem=0.5) -> float:
        base = (self.scf.gamma3d(x, t_now) ** self.w[0]
                * getattr(self.msrg_cache.get(rule_id), 'mu_pass', 0.0) ** self.w[1]
                * (1 + self.w[2] * A_att))
        return base * eta_mem * self.ebg.eta_e(B) * eta_imit
```

## 4. 正确性论证（增量更新）

### 引理 41（模仿支撑证书的泛化与外推界）

**陈述**：设 π_I 由 D_n 以 BC 训练、每步模仿损失 ε_BC（DAgger 则 ε_DAgger），示范密度 q_D 的估计误差以 DKW 界控制。则 (a) 在认证支撑 S_c = {s : q_D(s) ≥ ρ ∧ u(s) ≤ u_tol} 内，J(π_I) ≤ J(π_E) + T·ε_BC（DAgger 为 J(π_E) + ε_DAgger），且以概率 ≥ 1−δ 覆盖估计误差 ≤ √(log(2/δ)/(2n))；(b) 在 S_c 外 kc_imit 必拒，故执行集不含「示范未支撑的外推动作」。

**证明**：(a) 标准 BC 复合误差界（Ross & Bagnell）给出 J(π_I) ≤ J(π_E) + T·ε_BC；DAgger 通过交互式数据把 T 因子降为常数。密度估计的均匀收敛由 DKW 不等式 P(sup|q̂_D − q_D| > η) ≤ 2e^{−2nη²} 给出，取 η=√(log(2/δ)/(2n))。(b) 由 kc_imit 的合取定义，q_D(s)<ρ 或 u(s)>u_tol 时门必关。∎

**工程含义**：模仿策略的「便宜」不再等于「无条件可信」；证书把可信域钉在示范支撑与低分歧区，外推被硬性拦截。

### 引理 42（能量预留的可行急停界）

**陈述**：若 kc_energy 在时刻 t 成立，即 B(t) ≥ B_reserve = P_stop·T_stop + B_margin 且存在返航路径，则在任意后续功率 P(τ) ≤ P_stop 下，存在一条在电量耗尽前完成安全急停/返航的可行轨迹。进一步，若任务功率持续为 P_task，则预留之外的可执行时长为 (B(t) − B_reserve)/P_task。

**证明**：急停所需能量 ≤ P_stop·T_stop ≤ B(t) − B_margin；对功率积分 dB/dτ = −P(τ)，从 t 积分 T_stop 得消耗 ≤ P_stop·T_stop，剩余 ≥ B_margin > 0，故可行轨迹存在。可执行时长由同一积分直接得出。∎

**工程含义**：kc_energy 把「电量」变成一票否决的硬门，保证任何被批准的动作都不会让机器人失去安全退路——这是 v1~v3 完全缺失的资源安全属性。

### 引理 43（证据调度的子模贪心近似与覆盖凹性）

**陈述**：设覆盖函数 ρ(F) = Σ_{r∈R} min(1, F_r) 为被供能区域的覆盖并集，则 (a) ρ 对被选区域集合单调、子模；(b) 在总能量预算下，按单位焦耳边际增益贪心选择区域，得到 ≥ (1−1/e)·OPT 的覆盖；(c) 在陈旧衰减 F_r(t+dt)=F_r(t)e^{−λdt} 下，维持覆盖 ρ 所需稳态功率随 ρ 单调递增且凸，故「覆盖—续航」前沿是凹的。

**证明**：(a) min(1,·) 为单调凹函数，非负凹函数对集合的并集覆盖保持单调子模（标准覆盖函数结论）。(b) 子模最大化在基数/预算约束下贪心近似比为 1−1/e（Nemhauser–Wolsey）。(c) 稳态需持续注入 λF_r 抵消衰减，功率对 ρ 线性，故覆盖关于续航的前沿凹。∎

**工程含义**：安全覆盖不是「有/无」，而是可购买的连续量；ERS 给出在有限电量下「买多少安全」的近最优策略。

### 定理 v4（七硬门收缩、能量弹性与双重补全）

**陈述**：在以下假设下：(C1) 示范支撑估计与集成分歧忠实反映 π_I 的可信域；(C2) 电池模型与功率上界 P_stop 保守成立；(C3) 覆盖函数子模、陈旧衰减率 λ 已知；(C4) 继承 v3 的 (B1)~(B4)。则：
(i) Exec_CADVS-v4(B) ⊆ Exec_CADVS-v3（严格收缩，由 kc_imit 与 kc_energy 关闭 v3 未检查的策略外推与资源枯竭路径）；
(ii) 能量弹性：B_1 ≤ B_2 ⟹ Exec_CADVS-v4(B_1) ⊆ Exec_CADVS-v4(B_2)；
(iii) 示范支撑内的模仿代价由引理 41 界，支撑外零通过；
(iv) 任何被批准动作都不丧失安全急停/返航能力（引理 42）；
(v) ERS 以 (1−1/e) 近似最大化预算内覆盖（引理 43）；
(vi) 七硬门 fail-closed，仅 HIC veto 旁路至 S_stop。

**证明**：(i) v4 在 v3 每条路径上追加 kc_imit 与 kc_energy 两个合取项，故只缩不涨；严格性由 v3 允许、v4 拒绝的「示范外推」与「预留不足」路径非空保证。(ii) B_reserve 固定、kc_energy 对 B 单调，B 越低通过的状态越少。(iii)~(v) 分由引理 41、42、43。(vi) 由 hard_gate 合取结构。∎

**诚实声明**：(C2) 与 (C3) 是本轮最脆弱假设——电池模型会因老化、温度、瞬时大电流而漂移，P_stop 上界若不保守则 kc_energy 给出虚假退路；覆盖子模性与衰减率 λ 也是近似。缓解：在线电池内阻/容量辨识、P_stop 取 q99 上界并加安全系数、λ 用实机证据陈旧曲线标定、低电量时收缩到保守模式。

## 6. 已知风险与缓解（增量更新）

| 风险编号 | 描述 | 严重度 | 缓解措施 | 剩余风险 |
|---|---|---|---|---|
| R19–R45 | v1/v2/v3 全部既有风险 | — | 随 v1~v3 原样继承 | 见前表 |
| R46 | **示范偏差/因果混淆**（示范者次优或策略学到虚假相关，支撑内仍错） | 高 | 示范质量权重 w_i；多示范者一致性检验；支撑内留出集验证；DAgger 纠偏 | 支撑内系统性偏差难由密度门发现 |
| R47 | **电池模型失配**（老化/温度/大电流使 B、P_stop 估计漂移，kc_energy 给出虚假退路） | **极高** | 在线内阻/容量辨识；P_stop 取 q99 上界并加安全系数；低电量保守收缩 | 突发掉压仍可能击穿预留 |

| R49 | **调度器近视**（贪心忽略长期覆盖与任务结构，短期最优长期失效） | 中 | 滚动时域/MPC；子模贪心加 lookahead；任务阶段感知预算 | 非平稳任务下近似比退化 |

## 7. 本轮最大风险（最终确认）

**一句话**：**能量与证据的死亡螺旋**——低电量时验证会加速耗电、停止验证又让证书陈旧失效，若调度失当，机器人可能在「为安全而验证」与「为续航而省电」之间反复横跳，最终陷入 fail-closed 瘫痪（原地拒绝一切动作）或为省电跳过验证而放大模仿策略的分布外风险，安全机制反而消耗了它所要保护的续航。
