# 第 57 轮（承接第 56 轮「证据地图×主动探询×信任协商」IP-127~132；灵感循环第 3 轮；本轮灵感：「状态估计」×「步骤分」）

> 第 56 轮把安全赌注从"模型置信"换成"证据承诺"，用持久地图 𝓜 让证据跨到访积累，并用探-诺-演闭环把不确定性变成可交易对象。但它仍有两个隐含前提：**(P1) 承诺是检查点级的**——在检查点用信念一次性认证整段接触排程 σ，而真正决定这一步是否踩空的连续状态 x（位姿、速度、接触点、地形高度）会在步与步之间漂移；**(P2) 证据门是二值的**——接触要么挂证据类、要么拒绝，无法表达"部分支持"，也无法在保留 soundness 的前提下利用部分信息。本轮两个灵感正好补这两处：**状态估计**把"我现在究竟在哪、脚到底触到了什么"变成可计算、可审计、可观测的显式变量；**步骤分**把"全对才给分"改成"每一步独立挣分、可部分得分、可事后扣分"，但必须以无补偿聚合堵住"凑分"漏洞。核心命题由"证据说可信"升级为 **"每一步都重新估计、重新挣分、可被事后扣分地说可信"**。

核心矛盾：
- **H26**：承诺粒度与状态漂移不匹配——检查点认证的 σ 在下一步就可能因 x̂ 漂移而失效；护盾只能事后救，不能事前察觉"我的状态估计已经不可信"，状态估计误差也没有进入任何证据类或证书。
- **H27**：证据门是二值的，浪费了部分信息；但若允许部分证据累积成承诺，又会引入"补分漏洞"——高分维度补偿低分维度，最终把不可逆步骤"凑"过门槛。步骤分的要求恰是"**可部分得分，但不可补偿、不可跨步借分**"。

## 0. 直觉与动机

**灵感 1（状态估计 → 把 x̂ 的不确定性请进证书，而不是藏在护盾里）**
直觉：第 56 轮证据门查的是地图信念 `b_r`，却默认 `x` 已知。四足的实际状态估计会因打滑、IMU 偏置、接触模型误差而漂移；"地图说这块地能踩"与"我现在以为自己的脚在这"是两个独立的不确定性源，必须联合估计、联合认证。于是引入联合状态-语义后验 `p(x, θ_r | z_{1:k})`，用接触辅助的不变 EKF / 增量因子图估计；每步输出新息 `ν_k` 与 `NIS_k`，作为"状态估计健康分"。状态估计不再是黑盒前端，而是证书里的一个显式变量：**证书不仅要为"世界是什么"作证，还要为"我以为我在哪"作证。**

**灵感 2（步骤分 → 分步挣分、分步承诺、可回溯扣分）**
直觉：步骤分不是"降低标准"，而是"把标准拆到每一步并禁止跨步借分"。每一步 `s_k` 有四个维度分：状态估计健康 `s_est`、证据信用 `s_ev`、几何/摩擦裕度 `s_mg`、跨源一致性 `s_cons`；聚合采用"先过地板、再加权求和"的无补偿算子——任何一维低于地板，其余维度再高也不能把这一步判过。部分分只用于两件事：(a) 指示下一步该探哪个最弱维度；(b) 在可逆步骤上给出有界、可撤销的临时承诺。不可逆步骤仍要求硬机会约束 + 证据类齐全。事后若新息超界，回溯窗口内已发的分作废（扣分），回滚到最后一个一致检查点重估重诺。**这像阅卷：过程分可以给，但不能用"前面步骤写得多"去抵消失误的最终答案。**

**灵感 3（可观测性 → 探针不只买信息，还要买"能看见"的方向；步态是裕度×可观测性的双轴变速箱）**
直觉：第 56 轮的 VOI 只看语义熵降，但状态估计的某些方向在特定步态下根本不可观（腾空相速度不可观、静态 crawl 激励不足）。再多的探针也补不了不可观方向。因此探询必须带可观测性约束：优先选能提升 Fisher 信息 / 可观测 Gramian 的探针；若某方向结构性不可观，则改步态/改路线制造激励（persistent excitation）。步态于是从"裕度变速箱"升级为"**裕度 × 速度 × 可观测性**"的三轴变速箱：trot 激励好但裕度小，crawl 裕度大但激励弱，pace 折中。

**灵感 4（分步证书 → 证书的乘法结构，而不是一次性总结）**
直觉：任务证书 J 不再是"检查点通过"的布尔值，而是分步证书的序列组合 `J = ⊗_k J_k`，每步证书带有效期（horizon）、证据、新息、信用分、可撤销标记。组合规则要求"相邻步骤的状态估计在重叠区间内一致"；任何一步被回溯扣分，其后的步骤证书自动失效并需重认证。证书从"终点快照"变成"过程账本"。

**灵感 5（人机同构的步骤分 → 人的标注也按步、也扣分、也不能凑分）**
直觉：第 56 轮人类标注是区域级的、隔离生效的。分步视角下，操作者可以给出步级部分评价（这块落脚点看着稳、那块不确定），但同样走"地板 + 权重 + 隔离 + 事后佐证"的同一套评分逻辑；人的分不能跨步借，也不能补平状态估计的硬缺陷。人与探针、地图共用一本账，只是权重与隔离策略不同。

## 1. 形式化定义（增量：定义 133–138）

**定义 133（联合状态-语义后验 JSE）** 联合状态 `ξ_k = (x_k, θ_{r_k})`，后验 `p(ξ_k | z_{1:k}) = N(ξ̂_k, P_k)`（或粒子/因子图后验）；观测 `z_k` 含本体、接触、视觉、语义。新息 `ν_k = z_k − h(ξ̂_{k|k-1})`，新息协方差 `S_k = H_k P_{k|k-1} H_k^T + R_k`，归一化新息平方 `NIS_k = ν_k^T S_k^{-1} ν_k`。联合估计器输出 `(ξ̂_k, P_k, NIS_k, o_k)`，其中 `o_k = λ_min(O_k^T O_k)` 为局部可观测 Gramian 的最小特征值（可观测性度量）。

**定义 134（步骤分与无补偿聚合）** 第 k 步信用向量 `s_k = (s_est, s_ev, s_mg, s_cons) ∈ [0,1]^4`，分别由状态估计健康、证据信用（`1 − P_fail` 上界）、几何/摩擦裕度、跨源一致性给出。地板 `f = (f_est, f_ev, f_mg, f_cons)`，权重 `w`（`Σ w_i = 1`）。无补偿聚合：
`S_k = (Σ_i w_i s_{k,i}) · Π_i 1[s_{k,i} ≥ f_i]`。
承诺谓词 `commit_k ⇔ S_k ≥ θ_S ∧ P_fail(step_k) ≤ δ_f(g) ∧ ev_class(step_k) ≠ ∅ ∧ (reversible(step_k) ∨ s_est ≥ f_est^irr)`。部分分只用于探针定向与可逆临时承诺，不得跨步转移：`credit_transfer(k→k′) ≡ 0`；同一证据只能计分一次。

**定义 135（分步证书 SLC）** 第 k 步证书 `J_k = (ξ̂_k, P_k, NIS_k, o_k, s_k, ev_k, m_k, horizon_k, revocable_k, parent_hash)`；有效性
`valid_k ⇔ S_k ≥ θ_S ∧ 硬约束成立 ∧ NIS_k ≤ χ²_α ∧ 与 J_{k−1} 在重叠区间一致`。
任务证书 `J = ⊗_k J_k`：组合保持相邻状态一致，并传播撤销——任一 `J_i` 失效则所有 `k > i` 的依赖证书失效（除非重新认证）。

**定义 136（可观测性感知探询 OAP）** 探针 π 的信息增益 `IG(π) = H(ξ | z) − E[H(ξ | z, π)]`，用 Fisher 信息近似 `J_F(π) = J_0 + Σ H_π^T R_π^{-1} H_π`。可观测性约束 `λ_min(J_F(π)) ≥ o_min`。选择 `π* = argmax_π [IG(π) − cost(π)]`；若不存在能提升不可观方向的探针，则改步态/路线以增加激励：
`g* = argmax_g [λ_min(J_F(g)) − λ_risk·(1/δ_f(g)) − λ_time·time(g)]`，且 `select_gait` 必须非 halt。

**定义 137（新息漂移门 IDG）** 每步校验 `NIS_k ≤ χ²_α` 与 `NEES_k ∈ [l_α, u_α]`；连续 `m` 步超界或单步超 `χ²_{α′}` 触发漂移事件 `Drift(k*)`。响应按严重度分级：重加权/重估 → 重探 → 回滚到最近一致检查点 → 降档/安全停。漂移门是"状态估计的护盾"，与第 56 轮接触护盾串联而非替代。

**定义 138（回溯信用账本 RCL）** 信用账本 `L = [(k, s_k, J_k, t_k)]`；漂移事件 `Drift(k*)` 将窗口 `W(k*) = [k*−w, k*]` 内信用标记为 `revoked`，`J_{≤k*}` 失效，状态回滚到 `k*−w−1` 的一致后验。审计记录 `(revoke_reason, window, evidence)`；禁止信用通胀：同一证据只能计分一次，重算必须有新观测。

## 2. 关键算法伪代码（完整版见产物区）

### IP-133 JSE（联合状态-语义估计）

```python
def jse_step(xi_prev, P_prev, z, contact_model, horizon):
    xi_pred, P_pred = propagate(xi_prev, P_prev, contact_model)
    nu = z - h(xi_pred); H = jacobian(h, xi_pred)
    S = H @ P_pred @ H.T + R
    K = P_pred @ H.T @ inv(S)
    xi, P = xi_pred + K @ nu, (I - K @ H) @ P_pred
    nis = nu.T @ inv(S) @ nu
    o = lambda_min(observability_gramian(H, F, horizon))   # 局部可观测性
    return xi, P, nis, o
```

### IP-134 SSC（无补偿步骤分）

```python
def step_score(step, xi, P, nis, M, gait):
    s_est  = exp(-max(0.0, nis - chi2_thr) / scale)        # 状态估计健康
    s_ev   = 1.0 - upper_bound(P_fail(step, M, xi, P))      # 证据信用
    s_mg   = clip((margin(step, xi, P) - m_floor) / (m_target - m_floor), 0, 1)
    s_cons = agreement(step, xi, M)                        # 地图/观测/探针一致性
    s = [s_est, s_ev, s_mg, s_cons]
    if any(s[i] < floor[i] for i in range(4)):
        return 0.0, s                                      # 无补偿：一票否决该步
    return sum(w[i] * s[i] for i in range(4)), s
```

### IP-136/137（漂移门 + 分步证书）

```python
def step_certify(k, step, xi, P, M, gait, ledger):
    xi, P, nis, o = jse_step(xi, P, observe(step), contact_model, H)
    if drift_detected(nis, o, history):
        return rollback_and_replan(ledger, k)              # 回溯扣分，回滚重诺
    S, s = step_score(step, xi, P, nis, M, gait)
    if S < theta_S or not hard_feasible(step, xi, P, M, gait):
        return probe_or_downgrade(step, deficit_dim(s))    # 只探最弱维度
    Jk = make_step_certificate(xi, P, nis, o, s, step, M, horizon=1)
    ledger.append((k, s, Jk)); return Jk
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| JSE | O(n³) 稠密 / O(‖Δ‖) 增量因子图 | O(n²) | 新息诚实、NEES/NIS 保校准 |
| SSC | O(1) | O(1) | 地板不可补偿、证据不重复计分 |
| OAP | O(\|Π\|·(n³+cost)) | O(n²) | Fisher 信息真实、非破坏探针 |
| IDG | O(1)/步 | O(w) | 漂移检出、分级响应单调 |
| SLC | O(1)/步，组合 O(K) | O(K) | 相邻一致、撤销传播 |
| RCL | O(w) 撤销 / O(1) 摊销追加 | O(K) | 窗口完备、禁止信用通胀 |

**正确性定理（Step-Grounded Soundness with Retroactive Revocation, SGS-RR）**：在 A29–A36 基础上加 **(A37)** 联合估计器一致（NEES/NIS 在 χ² 界内），状态误差 `‖e‖_{P^{-1}}² ≤ χ²_{1−ε_est}` 以概率 `≥ 1−ε_est` 成立；**(A38)** 漂移门 sound：任何足以使已承诺步骤失效的漂移，在窗口内被检出概率 `≥ 1−ε_drift`；**(A39)** 无补偿聚合与不跨步转移（`S_k ≥ θ_S ⇒ ∀i: s_{k,i} ≥ f_i`，`credit_transfer ≡ 0`）；**(A40)** 撤销完备（依赖证书全失效，回滚后验一致，失败概率 `≤ ε_rev`）。则：

(i) **分步承诺健全性**：每个承诺步骤的失效概率 `≤ δ_f + ε_est + ε_drift + ε_cal + ε_probe + ε_h`；
(ii) **信用健全性**：步骤分不能绕过硬机会约束，也不存在"高分补低分"或"跨步借分"的升险路径；
(iii) **撤销健全性**：若 `Drift(k*)` 使某步证书失效，则所有依赖该步的后续证书失效，任务证书只在全部分步证书有效时有效；
(iv) **终止性**：每步在有限探针/步态/降档选项内终止于 {承诺, 临时承诺, 绕行, 协商, 安全停} 之一。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 状态估计器自校准漂移（NEES 看着正常但已偏） | 高 | 协方差保守膨胀 + 多估计器交叉校验 + 硬件在环注入 |
| 新息门误报导致步态抖动/频繁回滚 | 中 | 滞回 + 连续 m 步确认 + 分级响应 + 回滚代价预算 |
| 步骤分被"凑分"或信用通胀 | 高 | 无补偿地板 + 一证据一计分 + 对抗测试 + 审计账本 |
| 可观测性激励与安全裕度冲突 | 高 | 安全字典序优先：先过 K_B/δ_f 硬门，再在安全步态内选激励 |
| 不可逆步骤之后无法回滚 | 高 | 不可逆步骤要求全维满格 + 证据类齐全 + L2 确认；显式建模不可回滚假设 |
| 联合估计计算量挤占控制节拍 | 中 | 增量因子图/边缘化 + 预计算可观测性 + 降频重估 |

## 6. 本轮最大风险

**一句话**：分步信用把"部分证据"变成可承诺的资源，但状态估计与信用账本共享同一个可能失准的模型——若 NEES 自校准漂移而新息门又恰在盲区沉默，系统会用"看起来每一步都及格"的步骤分，把一路累积的估计偏差合法化为一次不可逆承诺；最大风险不是某一步算错，而是 **步骤分把系统性偏差切碎成每步都合规的小分**，因此必须以多估计器交叉校验、新息门滞回审计、无补偿地板与回溯扣分三重护栏，宁可回滚重估，绝不让"过程分"替"最终答案"背书。

| `o_k = λ_min(O_k^T O_k)` | 局部可观测 Gramian 最小特征值 |
| `s_k = (s_est,s_ev,s_mg,s_cons)` | 步骤分四维信用向量 |
| `f = (f_est,f_ev,f_mg,f_cons)` | 各维地板（低于即该步作废） |
| `S_k` | 无补偿聚合后的步骤总分 |
| `θ_S` | 步骤承诺门槛 |
| `risk_k` | 硬机会约束：`P_fail(step_k) ≤ δ_f(g)` |
| `J_k` | 第 k 步证书（状态、新息、信用、证据、有效期、可撤销） |
| `J = ⊗_k J_k` | 任务证书的分步组合 |
| `IG(π), J_F(π)` | 探针信息增益与 Fisher 信息矩阵 |
| `Drift(k*)` | 漂移事件及回溯窗口起点 |
| `W(k*) = [k*−w, k*]` | 回溯扣分窗口 |
| `credit_transfer ≡ 0` | 禁止跨步借分 |

## 2. 关键算法伪代码

### IP-133 JSE（联合状态-语义估计）

```python
def jse_step(xi_prev, P_prev, z, contact_model, horizon):
    # 传播：全身动力学 + 接触约束 + 语义参数随机游走
    xi_pred, P_pred = propagate(xi_prev, P_prev, contact_model)
    H = jacobian(observation_model, xi_pred)
    nu = z - observation_model(xi_pred)                    # 新息
    S = H @ P_pred @ H.T + R
    K = P_pred @ H.T @ inv(S)
    xi = xi_pred + K @ nu
    P = (I - K @ H) @ P_pred
    nis = nu.T @ inv(S) @ nu
    F = jacobian(propagate, xi_pred)
    o = lambda_min(observability_gramian(H, F, horizon))  # 可观测性
    return xi, P, nis, o

def nees_check(xi_true, xi_hat, P):
    e = xi_true - xi_hat
    return e.T @ inv(P) @ e                               # 与 chi2 区间比较
```

### IP-134 SSC（无补偿步骤分）

```python
def step_score(step, xi, P, nis, M, gait):
    s_est  = exp(-max(0.0, nis - chi2_thr) / scale)
    s_ev   = 1.0 - upper_bound(P_fail(step, M, xi, P))
    s_mg   = clip((margin(step, xi, P) - m_floor) / (m_target - m_floor), 0, 1)
    s_cons = agreement(step, xi, M)                       # 地图/观测/探针三方一致
    s = [s_est, s_ev, s_mg, s_cons]
    if any(s[i] < floor[i] for i in range(4)):
        return 0.0, s, deficit_dim(s)                     # 一票否决，不给补偿
    S = sum(weight[i] * s[i] for i in range(4))
    return S, s, None

def commit_ok(step, S, s, M, gait):
    if S < theta_S: return False
    if upper_bound(P_fail(step, M)) > delta_f_of_gait(gait): return False
    if evidence_class(step) is None: return False          # 继承第 56 轮证据门
    if not reversible(step) and s[0] < floor_est_irr: return False
    return True
```

### IP-135 OAP（可观测性感知探询）

```python
def observability_aware_probe(deficit, M, xi, P, F_abs, budget):
    cands = admissible_probes(M, F_abs)                   # 非破坏性过滤（A34）
    cands = [p for p in cands if info_gain(p, P, deficit) >= theta_ig]
    if cands:
        p = argmax(cands, key=lambda q: info_gain(q, P, deficit) - cost(q))
        return ('probe', p)
    # 无探针能改善不可观方向：改步态/路线制造激励
    for g in ['pace', 'crawl', 'trot']:
        if select_gait(schedule_risk(...)) == 'halt':
            continue                                      # 安全字典序优先
        exc = excitation_gain(g, P)                       # 对不可观方向的持续激励
        if exc >= theta_exc and budget.allows(g):
```

```python
def compose_certificates(certs):
    for k in range(1, len(certs)):
        if not overlap_consistent(certs[k-1], certs[k]):
            return Invalid('overlap_inconsistent', k)
        if certs[k-1].revoked:
            certs[k].revoked = True                       # 撤销向后传播
```

```python
def revoke_window(ledger, k_star, w):
    window = [e for e in ledger if k_star - w <= e.k <= k_star]
    for e in window:
        e.revoked = True
        e.revoke_reason = 'drift'
    rollback_to(last_consistent(ledger, k_star - w - 1))

def account_evidence(ledger, evidence_id, score):
    if evidence_id in ledger.seen:
        return 0.0                                        # 一证据一计分，反信用通胀
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| JSE | O(n³) 稠密 / O(\|Δz\|) 增量因子图 | O(n²) | 新息诚实、NEES/NIS 保校准（A37） |
| SSC | O(1) | O(1) | 无补偿地板、不跨步转移（A39） |
| OAP | O(\|Π\|·(n³+cost)) | O(n²) | Fisher 信息真实、非破坏探针（A34 继承） |
| IDG | O(1)/步 | O(w) | 漂移检出、响应单调（A38） |
| SLC | O(1)/步；组合 O(K) | O(K) | 相邻一致、撤销传播（A40） |
| RCL | O(w) 撤销；O(1) 摊销追加 | O(K) | 窗口完备、一证据一计分 |

**正确性定理（Step-Grounded Soundness with Retroactive Revocation, SGS-RR）**
假设 A22–A28（第 53/54 轮）、A29–A36（第 55/56 轮）成立；**(A37)** 联合估计器一致：`NEES_k ∈ [l_α,u_α]`，且状态误差 `‖e_k‖_{P_k^{-1}}² ≤ χ²_{1−ε_est}` 以概率 `≥ 1−ε_est`；**(A38)** 漂移门 sound：任何使已承诺步骤失效的漂移，在回溯窗口内被 `Drift` 检出的概率 `≥ 1−ε_drift`；**(A39)** 无补偿聚合与不跨步转移：`S_k ≥ θ_S ⇒ ∀i, s_{k,i} ≥ f_i`，且 `credit_transfer ≡ 0`、同一证据只计分一次；**(A40)** 撤销完备：任一依赖证书失效、回滚后验一致，失败概率 `≤ ε_rev`。则：

1. **分步承诺健全性**：每个承诺步骤满足
   `P(fail_k) ≤ δ_f(g) + ε_est + ε_drift + ε_cal + ε_probe + ε_h`；
2. **信用健全性**：步骤分不能替代硬机会约束，也不存在"高分补低分"或"跨步借分"的升险路径；部分分仅影响探针定向与可逆临时承诺；
3. **撤销健全性**：若 `Drift(k*)` 使某步证书失效，则所有 `k > k*−w−1` 的依赖证书失效，任务证书 `J=⊗J_k` 仅在全部步骤有效时有效；
4. **终止性**：每步在有限探针、有限步态档位、有限降档/回滚选项内终止于 {承诺, 可逆临时承诺, 绕行, 协商, 安全停}；
5. **部署界**（对步骤取联合界）：

```
P_safe ≥ 1 − Σ_k (δ_f + ε_est + ε_drift + ε_cal + ε_probe + ε_h)
             − P(回滚失败) − P(结构性不可观 ∧ 激励失败) − P(τ_int 超时 ∧ 安全停失效)
```

关键：**步骤分把"部分证据"纳入决策，但用无补偿地板把"凑分"堵死**；**状态估计误差首次成为证书的显式扣分项**；**回溯扣分让"事后发现漂移"不再等于"已经踩空"**，而是回滚到最后一个一致状态重估重诺。

## 6. 本轮最大风险

**一句话**：分步信用把"部分证据"变成可承诺的资源，但状态估计与信用账本共享同一个可能失准的模型——若 NEES 自校准漂移而新息门又恰在盲区沉默，系统会用"看起来每一步都及格"的步骤分，把一路累积的估计偏差合法化为一次不可逆承诺；最大风险不是某一步算错，而是 **步骤分把系统性偏差切碎成每步都合规的小分**，因此必须以多估计器交叉校验、新息门滞回审计、无补偿地板与回溯扣分三重护栏，宁可回滚重估，绝不让"过程分"替"最终答案"背书。
