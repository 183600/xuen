# 第 63 轮（承接第 62 轮「ROSE 鲁棒在线场景进化闭环」IP-183~192；灵感循环 II 第 2 轮；本轮灵感：「多轮对话」×「评测指标」）

> 第 62 轮用 ROSE 把 ESEC 从「静态语义-执行闭环」推进为「在线学习 + 鲁棒兜底 + 场景课程」的动态闭环：OLP 有 √T 遗憾界、WCV/RSC 有偏差免疫、SBR/SHC 有场景课程、Shield 有机制安全。但 ROSE 有两个一直被当成「接口细节」的盲区：
> 1. **多轮对话被压成单轮约束提交**：DMS 每轮产出一个约束 c，Shield 做一次投影；没有对话状态、没有跨轮证据累积、没有「下一个问题问什么最值」的模型。真实任务里意图是逐步澄清的（指代「那个」、否定「不是左边」、修正「再轻一点」、优先级「安全比速度重要」），单轮投影会把「还没说清」误当成「已经说清」，也会把跨轮的约束矛盾静默覆盖。
> 2. **评测是单轮、固定样本、聚合均值**：E201–E210 都是固定测试集上的点估计。但 ROSE 同时是（a）在线学习、（b）自适应采样、（c）多轮交互、（d）非平稳的——这四条一起使 i.i.d. 留出集评测失效：测试分布被系统自己改变，可选停止撞上多重比较，稀有安全事故被均值淹没，而对话用户还会适应机器人。
> 3. 两个盲区共享同一个根：**系统在「自己选数据、自己学、自己报告」**。多轮对话就是主动数据收集；评测若不对「数据由策略选择」保持有效，分数就只是自我安慰。本轮把「多轮对话」与「评测指标」当成同一个统计问题的两面。

## 0. 直觉与动机

**灵感 1（多轮对话 → CBS：把对话当成序贯实验设计）**
直觉：追问不是 UI 装饰，是**用一次交互换一条信息**。把 DMS 从「每轮吐约束」升级为**信念空间 POMDP**：维护意图约束的后验 b_t(c)，每个问题 q 的价值 = 期望信息增益（VOI）− 交互成本。只有当「执行所依据的可信约束集」落在安全域内才执行，否则问信息量最大的问题。对话收敛不再是「聊到用户满意」，而是**版本空间直径 ≤ ε、且真值以 1−β 概率仍在可信集内**的统计保证。

**灵感 2（多轮对话 → CCR：约束会累积也会打架）**
直觉：多轮里「轻一点」和「再用力点」、旧约束和新指令会冲突。不能静默取最新值，也不能整段推倒重来。用**最小冲突集（MUS）+ AGM 信念修正**：先找哪几条约束不能同时满足，再针对该冲突问一个能消解它的问题；**安全约束是硬约束、永不协商，只有用户偏好可修正**。Shield 因此从「单轮投影器」升级为「跨轮一致性守门员」：任何一轮都不能让可行域悄悄变空。

**灵感 3（评测指标 → AVE：自适应数据上的任意时有效推断）**
直觉：ROSE 的评测数据是**策略自己选出来的**，而且会一直流进来。固定样本置信区间在自适应采样与可选停止下失效（你可以一直测到显著为止）。换用 **e-process / 测试鞅 + 置信序列**：只要下注策略可预测（只用过去信息），则**任何**问询策略——包括对抗性、自适应、停停走走的策略——下，误报率都被 Ville 不等式控制。安全是稀有事件，更该用 e-value 而不是均值。这是本轮最硬的一条：**多轮对话导致的自适应采集不是评测的麻烦，而是选择 e-process 的充分理由**。

**灵感 4（评测指标 → DRO：从日志里评新策略）**
直觉：在线系统不能为了评测而停掉好策略。用**双重鲁棒离线策略评估（DR-OPE）**从历史日志估新策略价值。但正性假设（behavior policy 覆盖 target policy）一旦被违反，重要性权重会爆炸。因此同时报告有效样本量 ESS 与悲观下界；ESS 不足就明确「证据不足」，而不是给一个漂亮数字。评测的第一美德不是精确，是**不撒谎**。

**灵感 5（评测指标 → PSE：评测会改变被测系统）**
直觉：用户会适应机器人（被追问多了就学会给结构化答案），策略也会改变场景分布（表演性预测）。在固定用户模拟器上打分会产生 Goodhart。把评测定义为 **(机器人策略, 用户最优反应) 的不动点**，并显式报告「表演性间隙」：冻结用户评测与用户最优反应评测之差。差距大就说明分数不可迁移，不能拿去做发布口径。

**灵感 6（评测指标 → MCX：谁来评评测器）**
直觉：J_rose 是系统自己发的证书，自己证明自己不算证明。用**保形风险控制（CRC）**在外部校准集上给「被接受的证书」的实际违规率一个有限样本上界，报告风险-覆盖率曲线与 ECE。元评测把「证书通过率 99.9%」从宣传口径变成可审计指标。

**灵感 7（合流 → DIALECT：对话-评测闭环）**
CBS 回答「下一句问什么」，CCR 回答「约束打架怎么办」，AVE/DRO/PSE 回答「凭什么相信这个分数」，MCX 回答「凭什么相信这个证书」，DCL 回答「把评测预算花在哪」。合流后形成闭环：**对话产生自适应数据 → 评测必须 anytime-valid → 评测信号反过来调度追问与场景课程**。ROSE 是执行/学习层，DIALECT 是其上的交互-证据层；实时路径仍然零对话写、零评测写。

## 1. 形式化定义（增量：定义 185–196）

- **定义 185（DIALECT 对话-评测闭环）**：DIALECT = (ROSE, CBS, CCR, AVE, DRO, PSE, MCX, DCL, J_dialect)。定位：ROSE 之上的「交互 × 证据」层，不推翻任何既有接口；全部对话推理、评测统计、校准只发生在语义流与低频线程。
- **定义 186（对话信念状态 CBS）**：b_t(c) 为意图约束 c ∈ 𝒞 的后验；对话状态 D_t = (b_t, 硬约束 H_t, 软偏好 S_t, 指代集 R_t, 承诺集 K_t)。观测模型 P(a | c, q) 描述用户对问题 q 的回答 a；更新 b_{t+1}(c) ∝ b_t(c)·P(a_t | c, q_t)。
- **定义 187（对话动作与信息价值 VOI）**：动作空间 A_d = Q_ask ∪ {confirm, execute, abstain}；VOI(q) = E_{a∼P(·|b,q)}[H(b) − H(b'|a)] − λ_c·cost(q)；策略 π_d = argmax_{q∈Q_ask} VOI(q)，仅当「可执行且可信集安全」时 execute。
- **定义 188（版本空间与 ε-收敛）**：V_t = {c ∈ 𝒞 : c 与全部历史回答一致}；可信集 C_t^β = 质量 ≥ 1−β 的最小后验高密度集。对话 ε-收敛 ⇔ diam(V_t) ≤ ε 且 P(c* ∈ C_t^β) ≥ 1−β；问题 q 为 γ-信息量若 I(q;b) = H(b) − E[H(b')] ≥ γ。
- **定义 189（CCR 约束冲突修复）**：F_t = H_t ∩ S_t ∩ 𝒞_safe(φ̂_t, r_t)。若 F_t = ∅，在软约束上求最小不可满足子集 MUS ⊆ S_t（硬约束不可删）；若冲突只涉及软约束，按 entrenchment ≤_π 做 AGM 收缩+扩张，并针对 MUS 生成一个消解问题；若硬约束本身冲突或与安全域冲突，则 abstain/ask，绝不静默放宽 H_t。
- **定义 190（AVE 任意时有效评测）**：对每 episode 的有界损失 ℓ_t ∈ [0,1]，设原假设 H_0: E[ℓ_t | F_{t-1}] ≤ α。取可预测下注 λ_t ∈ [0,1]，e_t = 1 + λ_t(α − ℓ_t)，E_t = ∏_{s≤t} e_s；H_0 下 E_t 为非负上鞅。当 E_t ≥ 1/δ 拒绝 H_0（判定违规）；置信序列 CS_t = {α : E_t(α) < 1/δ}。
- **定义 191（DRO 双重鲁棒离线评测）**：日志由行为策略 μ 产生，目标策略 π；w_t = π(a_t|s_t)/μ(a_t|s_t)，V_DR = (1/n)Σ_i[V̂(s_0^i) + Σ_t γ^t w_{1:t}^i(r_t^i + γV̂(s_{t+1}^i) − Q̂(s_t^i,a_t^i))]；正性假设 μ(a|s) ≥ p_min > 0，同时报告 ESS = (Σw)²/Σw²。
- **定义 192（PSE 表演性/策略鲁棒评测）**：M(π) = sup_{σ∈𝒰} E_{D(π,σ)}[L]，σ 为用户最优反应，𝒰 为用户模型不确定集；表演性稳定点 π* ∈ argmin_π M(π)；表演性间隙 Δ_perf(π) = M(π) − M_frozen(π)。
- **定义 193（MCX 元证书校准）**：接受阈值 λ 作用于证书分数 s_J；在外部校准集上 R̂_n(λ) = (1/n)Σ L_i·1{s_{J,i} ≤ λ}，取 λ̂ = inf{λ : (n/(n+1))R̂_n(λ) + 1/(n+1) ≤ α}；报告风险-覆盖率曲线与 ECE = Σ_b (n_b/n)|acc_b − conf_b|。
- **定义 194（DCL 对话-评测课程）**：按簇分配三类预算：追问预算（按 C_t^β 熵与 MUS 计数）、场景生成预算（按 ROSE 的集群遗憾 R̂_c）、评测采样预算（按 e-process 检验功效与 ESS 缺口）；Hedge 权重 w_c ∝ exp(η·Ĝ_c) 统一驱动。
- **定义 195（J_dialect 交互-评测证书）**：J_dialect = (J_rose, diam(V_t), β, MUS ids, E_t, CS_t, ESS_t, Δ_perf, λ̂_MCX, entropy_gain, query_cost)。Valid ⇔ Valid(J_rose) ∧ (diam(V_t) ≤ ε ∨ abstained) ∧ (F_t ≠ ∅ ∨ abstained) ∧ (E_t < 1/δ) ∧ (ESS_t ≥ m_min) ∧ MCX_covered。
- **定义 196（DIALECT 闭环算子）**：语义流执行 [对话更新 CBS → VOI 选问/执行 → CCR 冲突修复 → Shield 投影 → ROSE 在线学习 → AVE/DRO/PSE 记账 → MCX 校准 → DCL 调度]；实时流执行 [锚点原子读 → OLP 前向 → WCV/AWC 编译 → 派发 → 证书回传]。**实时路径零对话写、零评测写、零等待。**

## 2. 关键算法骨架（完整伪代码见产物区）

```python
# CBS：对话 = 序贯实验设计（语义流，低频）
q* = argmax_q [ E_{a~P(.|b,q)} H(b) - H(b'|a) - lambda_c*cost(q) ]   # VOI
b = bayes_update(b, q*, a);  V = version_space(b);  execute iff C_beta ⊆ C_safe
# CCR：约束冲突 -> 最小冲突集 -> 针对性追问
if feasible(H, S, C_safe) is empty:
    mus = minimal_unsat_core(S); q* = resolve_question(mus) or abstain
# AVE：自适应数据上的任意时有效检验（每个 episode O(1)）
e_t = 1 + lambda_t*(alpha - loss_t);  E_t *= e_t
violation iff E_t >= 1/delta            # Ville 控制误报，与问询策略无关
# DRO/PSE/MCX：离线评新策略 / 用户最优反应 / 评测评测器
V_DR, ESS = doubly_robust(logs, pi, mu);  gap = M_best_response - M_frozen
lambda_hat = conformal_risk_control(cal_scores, alpha)
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 1（对话收敛）**：若每个问题相对当前信念为 γ-信息量，则 E[H(b_{t+1})|b_t] ≤ H(b_t) − γ；k = O(H(b_0)/γ) = O(log|𝒞|/γ) 步后 H(b_k) ≤ ε，配合可信集构造得 P(c* ∈ C_k^β) ≥ 1−β。收敛来自「问得值」，不来自「聊得久」。
- **引理 2（冲突修复可靠性）**：CCR 只在软约束上做最小收缩；输出要么 F_{t+1} ≠ ∅，要么 abstain。硬约束集合 H_t 单调不增（只会新增、不会被对话删除），因此安全域不会被对话悄悄放宽。
- **定理 1（任意时有效 + 自适应稳健）**：在 H_0 下对任意可预测下注与**任意（可含对抗、自适应、可选停止）问询策略**，P(∃t: E_t ≥ 1/δ) ≤ δ。固定样本 t 检验在多轮自适应采集下误报率随检查次数膨胀，e-process 不膨胀——这是把「多轮对话」与「评测指标」接上的核心定理。
- **定理 2（DR 一致性与诚实区间）**：正性 p_min>0、奖励有界时，|V_DR − V(π)| ≤ O(√(log(1/δ)/(n·p_min))) + 模型偏差；ESS < m_min 时不报价、只报「证据不足」。PDIS 逐决策加权避免整轨迹权重的指数爆炸。
- **定理 3（表演性间隙界）**：若用户最优反应引起的分布位移 W_1(D_frozen, D_BR) ≤ κ、损失 L-Lipschitz，则 |M_BR(π) − M_frozen(π)| ≤ L·κ；ε-稳定点处策略排序的翻转量被 L·κ 控制，差距大即判定评测不可迁移。
- **命题（元证书校准）**：CRC 选出的 λ̂ 使被接受证书的期望违规率 ≤ α（有界损失下的保形风险控制界）；E208 的「通过率」由此升级为「在覆盖率约束下的实际风险」。
- **集成定理（DIALECT-Complete）**：Valid(J_dialect) ⇒ ROSE 的执行/鲁棒保证 ∧ 对话 ε-收敛或明确 abstain ∧ 评测 anytime-valid ∧ 证书经外部校准——四条同时成立，缺一即降级为「执行安全但证据不足」。

## 5. 本轮最大风险

**一句话**：CBS 的收敛界、AVE 的 anytime 有效性、PSE 的表演性间隙，全都压在对「人类回答模型 P(a|c,q) 与用户不确定集 𝒰 正确」这一假设上；一旦用户策略性地给出无信息或误导性回答（或似然设定错误），系统会「自信地收敛到错误约束」，而同一模型错误又会让评测给出「已验证」的假象——对话与评测共享同一个不可验证的人类模型，是本轮全部保证的单点失效。

## 2. 形式化定义（完整版）

**定义 185（DIALECT 对话-评测闭环）** DIALECT 是 ROSE 的「交互 × 证据」升级层。ROSE 的 USR/MEL/DMS/SRT-Dual/SBR/OLP/WCV/RSC/ARA/Shield/OCB 全部保留；新增 CBS/CCR/AVE/DRO/PSE/MCX/DCL/CEP/GCR/J_dialect。不变式：**任何改变对话信念、约束集、评测统计、校准阈值的操作只发生在语义流与低频线程；实时流只做锚点原子读、OLP 前向、WCV/AWC 编译、派发、证书回传**。与定义 184 的时序隔离一致，并加强为「实时路径零对话写、零评测写、零等待」。

**定义 186（对话信念状态 CBS）** 对话状态 D_t = (b_t, H_t, S_t, R_t, K_t)：b_t 为意图约束后验；H_t 为不可协商的安全/伦理/物理硬约束；S_t 为可修正的用户偏好；R_t 为未解析指代集合（「那个」「左边那个」）；K_t 为已向用户承诺、可审计的约束。用户回答模型 P(a | c, q, σ) 含用户策略 σ；贝叶斯更新 b_{t+1}(c) ∝ b_t(c)·P(a_t | c, q_t, σ)。**信念只覆盖用户意图，物理参数 φ 仍由 MEL + RSC/CQB 的球处理，两者不混叠。**

**定义 187（对话动作与信息价值 VOI）** 动作 a_d ∈ A_d = Q_ask ∪ {confirm, execute, abstain}。问题 q 的期望信息增益
`I(q; b) = H(b) − E_{a∼P(·|b,q)}[H(b'|a)]`，
价值 `VOI(q) = I(q;b) − λ_c·cost(q)`。策略
`q* = argmax_{q∈Q_ask} VOI(q)`，
但执行受安全门控：仅当 `C_t^β ⊆ 𝒞_safe(φ̂_t, r_t)` 且 `F_t ≠ ∅` 时 execute；否则在 VOI 仍为正时继续问，VOI 低于阈值且无法保证安全时 abstain。`cost(q)` 计入用户耐心、交互时延与隐私泄漏风险。

**定义 188（版本空间与 ε-收敛）** 版本空间 V_t = {c ∈ 𝒞 : c 与历史全部 (q_i,a_i) 一致}；可信集 C_t^β 为后验质量 ≥ 1−β 的最小高密度集。对话 ε-收敛定义为 `diam(V_t) ≤ ε` 且 `P(c* ∈ C_t^β) ≥ 1−β`。问题 q 为 γ-信息量若 `I(q;b) ≥ γ`。**收敛是对「约束可辨识度」的陈述，不是对「用户满意」的陈述**——后者是体验指标，前者是安全指标。

**定义 189（CCR 约束冲突修复）** 跨轮可行域 F_t = H_t ∩ S_t ∩ 𝒞_safe(φ̂_t, r_t)。当 F_t = ∅ 时：
1. 若冲突可完全由软约束解释，求最小不可满足子集 `MUS ⊆ S_t`（MaxSAT / 最小击中集）；
2. 按 entrenchment 序 ≤_π（来源权威 > 时间新近 > 重复确认次数）做 AGM 收缩 `S_t ÷ ¬MUS` 再扩张，得到最小改动的新偏好集；
3. 针对 MUS 生成消解问题 `q = resolve(MUS)`，其答案若使 F_{t+1} ≠ ∅ 则继续，否则继续问；
4. 若 MUS 触及硬约束 H_t，或 H_t∩𝒞_safe = ∅，则**不得删除任何硬约束**，只能 abstain 或请求人类/上层重规划。
硬约束单调性：H_{t+1} ⊇ H_t（对话只能新增安全约束，不能删除）。

**定义 190（AVE 任意时有效评测）** 对每 episode 有界损失 ℓ_t ∈ [0,1]（可定义为「该 episode 是否违规/超限/失败」）。原假设 H_0: `E[ℓ_t | F_{t-1}] ≤ α`。取可预测下注 λ_t ∈ [0,1]（仅依赖 F_{t-1}），
`e_t = 1 + λ_t(α − ℓ_t)`，`E_t = ∏_{s=1}^t e_s`。
H_0 下 `E[e_t|F_{t-1}] = 1 + λ_t(α − E[ℓ_t|F_{t-1}]) ≤ 1`，故 E_t 为非负上鞅，`E[E_t] ≤ 1`。Ville 不等式给出 `P(∃t: E_t ≥ 1/δ) ≤ δ`。判定规则：`E_t ≥ 1/δ ⇒ 拒绝 H_0`（判定风险超标）。置信序列通过反演：`CS_t = {α : E_t(α) < 1/δ}`。**关键：λ_t 只依赖过去，允许 F_{t-1} 包含此前所有自适应问询决策，因此该保证对任意问询策略成立。**

**定义 191（DRO 双重鲁棒离线评测）** 日志 τ_i ~ μ，目标 π。逐决策重要性权重 w_t = π(a_t|s_t)/μ(a_t|s_t)（PDIS，避免整轨迹乘积爆炸）：
`V_DR = (1/n) Σ_i [ V̂(s_0^i) + Σ_t γ^t w_{1:t}^i ( r_t^i + γ V̂(s_{t+1}^i) − Q̂(s_t^i,a_t^i) ) ]`。
正性假设 `μ(a|s) ≥ p_min > 0`。诊断量：`ESS = (Σ_i w_i)² / Σ_i w_i²`；`ESS < m_min` 时拒绝报价，输出「证据不足，需探索」。区间用 bootstrap 或 e-value 反演，不用未经校正的正态近似。

**定义 192（PSE 表演性/策略鲁棒评测）** 用户最优反应 σ* 会响应机器人策略而改变回答分布与场景分布，故定义
`M(π) = sup_{σ∈𝒰} E_{D(π,σ)}[L(π,σ)]`，
其中 𝒰 为用户模型不确定集（含「配合」「敷衍」「误导」「策略性省略」四类）。表演性稳定点 `π* ∈ argmin_π M(π)`；`Δ_perf(π) = M_BR(π) − M_frozen(π)`。**发布口径只能是 M(π*)，不能是 M_frozen，后者系统性乐观。**

**定义 193（MCX 元证书校准）** 证书分数 s_J（越小越可信），校准集为外部审计 episode（与部署分布可交换或按时间加权）。对阈值 λ：
`R̂_n(λ) = (1/n) Σ_i L_i·1{s_{J,i} ≤ λ}`，
`λ̂ = inf{ λ : (n/(n+1))·R̂_n(λ) + 1/(n+1) ≤ α }`。
保形风险控制在有界损失下给出 `E[R(λ̂)] ≤ α`。同时报告风险-覆盖率曲线与 `ECE = Σ_b (n_b/n)|acc_b − conf_b|`。若校准集与部署分布不可交换，则用 ACI 风格的在线阈值调整并标注覆盖类型（边际/长期）。

**定义 194（DCL 对话-评测课程）** 场景簇 c 上分配三类预算：
- 追问预算 `B_q(c) ∝ w_c·(H(b_c)+n_MUS(c))`；
- 场景生成预算 `B_sim(c) ∝ w_c·R̂_c`（沿用 ROSE 集群遗憾）；
- 评测采样预算 `B_eval(c) ∝ w_c·(1/ESS_c)`，并优先投向「e-process 当前最接近判定边界」的簇（最大化检验功效）。
Hedge 权重 `w_c ∝ exp(η·Ĝ_c)` 统一驱动三者；评测不再是事后报告，而是**一等调度信号**。

**定义 195（J_dialect 交互-评测证书）**
`J_dialect = (J_rose, diam(V_t), β, MUS_ids, E_t, CS_t, ESS_t, Δ_perf, λ̂_MCX, entropy_gain, query_cost)`。
验证规则：
`Valid(J_dialect) ⇔ Valid(J_rose) ∧ (diam(V_t) ≤ ε ∨ abstained) ∧ (F_t ≠ ∅ ∨ abstained) ∧ (E_t < 1/δ) ∧ (ESS_t ≥ m_min ∨ eval_abstained) ∧ MCX_covered`。
审计链回答五个问题：用哪几条约束（MUS/V_t）、凭什么说够清楚（diam/β）、凭什么说评测有效（E_t/CS_t/ESS）、凭什么说分数不虚（Δ_perf）、凭什么信证书（λ̂/ECE）。

**定义 196（DIALECT 闭环算子）** 语义流（10–100Hz）：
[CBS 贝叶斯更新 → VOI 选问/执行 → CCR 冲突修复 → GCR 权限校验 → Shield 投影 → CEP 记录证据包 → ROSE 在线学习 → AVE/DRO/PSE 记账 → MCX 校准 → DCL 调度]。
实时流（1–10kHz）：
[锚点原子读 → OLP 前向 → WCV/AWC 编译 → ERTC 派发 → 证书回传 → J_dialect 构建]。
**实时路径零对话写、零评测写、零阻塞等待；对话与评测只读派发结果。**

### IP-193 CBS（对话信念规划）

```python
class ConversationalBeliefPlanner:
    """把多轮对话当序贯实验设计：每问一句 = 用交互成本换信息增益。"""
    def __init__(self, Q_ask, lam_c=0.1, beta=0.05, eps=0.05):
        self.Q_ask, self.lam_c, self.beta, self.eps = Q_ask, lam_c, beta, eps
        self.b = Prior(); self.H, self.S, self.R, self.K = set(), set(), set(), set()

    def entropy(self, b):
        p = np.clip(np.array(list(b.values())), 1e-12, 1)
        return -(p * np.log(p)).sum()

    def expected_post(self, b, q):
        out = 0.0
        for a, pa in self.answer_model(b, q).items():      # P(a|b,q)
            out += pa * self.entropy(self.bayes(b, q, a))
        return out

    def voi(self, b, q):
        return self.entropy(b) - self.expected_post(b, q) - self.lam_c*self.cost(q)

    def bayes(self, b, q, a):
        post = {c: b[c]*self.answer_model_given_c(c, q, a) for c in b}
        z = sum(post.values()) or 1.0
        return {c: v/z for c, v in post.items()}

    def step(self, b, C_safe, F_nonempty):
        if F_nonempty and self.credible_set(b, self.beta) <= C_safe:
            return ('execute', None)                        # 可信集已安全
        best_q, best_v = None, -np.inf
        for q in self.Q_ask:
            v = self.voi(b, q)
            if v > best_v: best_q, best_v = q, v
        if best_v <= 0:
            return ('abstain', None)                        # 问也不值 -> 明确放弃
        return ('ask', best_q)

    def credible_set(self, b, beta):
        items = sorted(b.items(), key=lambda kv: -kv[1])
        out, mass = set(), 0.0
        for c, p in items:
            out.add(c); mass += p
            if mass >= 1 - beta: break
        return out
```

### IP-194 / IP-201 CCR + GCR（约束冲突修复与权限治理）

```python
HARD_SOURCES = {'safety', 'physical_limit', 'ethics', 'contract'}

class ConstraintRepair:
    """硬约束永不删除；软约束做最小改动；无法安全修复就 abstain。"""
    def __init__(self, entrenchment): self.entrench = entrenchment  # c -> 序

    def feasible(self, H, S, C_safe):
        return intersect(H, S, C_safe)                     # 凸集交，非空则可行

    def step(self, H, S, C_safe):
        F = self.feasible(H, S, C_safe)
        if F: return ('ok', H, S, None)
        soft_conflict = self.minimal_unsat_core(S)          # MaxSAT / 最小击中集
        if soft_conflict and not self.touches_hard(soft_conflict):
            S2 = agm_revise(S, soft_conflict, self.entrench)  # 最小改动收缩+扩张
            q = self.resolve_question(soft_conflict)          # 针对 MUS 追问
            return ('ask', H, S2, q) if q else ('abstain', H, S, None)
        # 触及硬约束或与安全域直接冲突：绝不放宽，交由人类/上层
        return ('abstain', H, S, None)

    def touches_hard(self, mus):
        return any(getattr(c, 'source', None) in HARD_SOURCES for c in mus)

def agm_revise(S, mus, entrench):
    # 收缩：删除 entrenchment 最低的最小集合，使冲突消解；再扩张新约束
    drop = min_hitting_set(mus, key=lambda c: entrench[c])
    return (S - set(drop)) | set()
```

### IP-195 AVE（任意时有效评测）

```python
class AnytimeValidator:
    """H0: E[loss] <= alpha。E_t 为测试鞅；Ville 控制任意时误报。"""
    def __init__(self, alpha=0.05, delta=0.05, lam=0.5):
        self.alpha, self.delta = alpha, delta
        self.E, self.t, self.lam = 1.0, 0, lam
        self.alpha_grid = np.linspace(1e-4, 0.5, 200)
        self.E_grid = np.ones_like(self.alpha_grid)

    def update(self, loss):
        assert 0.0 <= loss <= 1.0
        self.E *= (1 + self.lam*(self.alpha - loss))        # e_t
        self.E_grid *= (1 + self.lam*(self.alpha_grid - loss))
        self.t += 1
        return self.E

    def violated(self):
        return self.E >= 1/self.delta                       # 拒绝 H0

    def confidence_sequence(self):
        ok = self.E_grid < 1/self.delta
        return (self.alpha_grid[ok].min(), self.alpha_grid[ok].max())
```

### IP-196 DRO（双重鲁棒离线评估）

```python
def doubly_robust_ope(logs, pi, Vhat, Qhat, gamma=0.99, m_min=50):
    vals, weights = [], []
    for tau in logs:                                        # tau: [(s,a,r,s')]
        w, v, rho = 1.0, Vhat(tau[0].s), 1.0
        for t, tr in enumerate(tau):                        # PDIS：逐决策权重
            rho *= pi(tr.a, tr.s) / max(mu(tr.a, tr.s), 1e-9)
            w *= rho
            v += gamma**t * rho * (tr.r + gamma*Vhat(tr.s2) - Qhat(tr.s, tr.a))
        vals.append(v); weights.append(w)
    ESS = (sum(weights)**2) / max(sum(x*x for x in weights), 1e-12)
    if ESS < m_min:
        return {'status': 'insufficient_evidence', 'ess': ESS}   # 拒答，不虚报
    return {'status': 'ok', 'value': np.mean(vals), 'ess': ESS,
            'ci': bootstrap_ci(vals), 'p_min_ok': check_positivity(logs, pi)}
```

```python
def performative_eval(pi, user_models, L, n_mc=2000):
    """M(pi)=sup_sigma E[L]；同时报告冻结用户与最优反应用户的差。"""
    frozen = np.mean([L(pi, rollout(pi, sigma_frozen)) for _ in range(n_mc)])
    worst = -np.inf
    for sigma in user_models:                               # 含配合/敷衍/误导/省略
        val = np.mean([L(pi, rollout(pi, sigma)) for _ in range(n_mc)])
        worst = max(worst, val)
    return {'M_best_response': worst, 'M_frozen': frozen,
            'delta_perf': worst - frozen,
            'transferable': (worst - frozen) <= DELTA_PERF_MAX}
```

### IP-198 MCX（元证书校准）

```python
def conformal_risk_control(scores, losses, alpha):
    """选阈值 lambda，使被接受证书的期望风险 <= alpha（有界损失）。"""
    order = np.argsort(scores); s, l = scores[order], losses[order]
    n = len(s)
    for k in range(n, -1, -1):                              # 从小到大收严
        lam = s[k] if k < n else -np.inf
        rhat = (l[:k].sum() + B_LOSS) / (n + 1)             # B_LOSS=1（保守）
        if rhat <= alpha:
            return lam, {'n': n, 'accepted': k, 'rhat': rhat}
    return -np.inf, {'n': n, 'accepted': 0, 'rhat': 1.0}
```

### IP-199 / IP-194 DCL（对话-评测课程）

```python
class DialogueEvalCurriculum:
    def __init__(self, C, eta=0.2):
        self.w = np.ones(C)/C; self.Ghat = np.zeros(C); self.ess = np.ones(C); self.eta = eta

    def step(self, cluster_id, regret, ess):
        self.Ghat[cluster_id] = 0.9*self.Ghat[cluster_id] + 0.1*regret
        self.ess[cluster_id] = ess
        self.w = softmax(self.eta*self.Ghat)
        return self.w

    def allocate(self, q_budget, sim_budget, eval_budget, ent, mus):
        q   = self.w*(ent + mus);        q   /= q.sum()
        sim = self.w*self.Ghat;          sim /= sim.sum()
        ev  = self.w/np.maximum(self.ess, 1); ev /= ev.sum()
        return (draw(q_budget, q), draw(sim_budget, sim), draw(eval_budget, ev))
```

```python
def DIALECT_round(M, obs, utterance, delta_f_req):
    V, T, P, L = obs
    # ---- 语义流：对话 + 评测 + 学习（全部写操作在此）----
    M.b = M.cbs.bayes(M.b, M.last_q, parse(utterance))

    x = 0.4*z_scene + 0.3*M.usr.intent_encoder(utterance) + 0.3*M.evidence_emb

    if status == 'abstain':
        return M, None, build_j_dialect(M, abstained=True)
    if status == 'ask':
        M.last_q = q; M.cbs.H, M.cbs.S = H, S
        return M, ('ask', q), build_j_dialect(M, asked=q)

    if act == 'abstain':
        return M, ('abstain', None), build_j_dialect(M, abstained=True)

    M.ara.commit(x, phi_hat, r=M.rsc.r, Rhat_c=M.hedge.Ghat)
    K_safe, EV_exec, cert_exec = realtime_step(M, delta_f_req)   # 实时流，只读

    loss = execution_loss(EV_exec, M.C_exec)
    M.ave.update(loss)                                   # anytime-valid 记账
    M.escrow.record(M.cep.packet(M.b, H, S, EV_exec))    # 证据包
    M.dro.log(EV_exec)                                   # 供离线评估
    if M.ave.violated():
        M.policy_gate.demote()                           # 评测触发降级/复评
    M.olp.online_step(x, execution_loss_grad(K_safe, EV_exec, phi_hat))
    M.rsc.update(EV_exec.tau_ext_obs, predict_ext_torque(phi_hat, K_safe),
                 sens_jacobian(phi_hat, K_safe))
    M.bank.mine(EV_exec, M.ara.read_latest()[0])
    M.hedge.step(M.ara.read_latest()[0].cluster_id, regret_of(EV_exec))
    M.dcl.step(M.ara.read_latest()[0].cluster_id, regret_of(EV_exec), M.dro.ess())
    return M, ('executed', K_safe), build_j_dialect(M)

def build_j_dialect(M, abstained=False, asked=None):
    return J_dialect(J_rose=M.cert_last, diam_v=diam(M.cbs.version_space(M.b)),
                     beta=M.cbs.beta, mus_ids=M.ccr.last_mus, E_t=M.ave.E,
                     CS=M.ave.confidence_sequence(), ESS=M.dro.last_ess,
                     delta_perf=M.pse.delta_perf, lam_mcx=M.mcx.lambda_hat,
                     entropy_gain=M.cbs.last_gain, query_cost=M.cbs.last_cost,
                     abstained=abstained)
```

## 4. 推导

**引理 1（对话收敛）** 设每次所选问题满足 I(q_t; b_t) = H(b_t) − E[H(b_{t+1})|b_t] ≥ γ。则
`E[H(b_{t+1}) | b_t] ≤ H(b_t) − γ`。
取全期望并求和：`E[H(b_k)] ≤ H(b_0) − kγ`。因 H ≥ 0，k ≤ H(b_0)/γ；H(b_0) ≤ log|𝒞|（有限假设类），故 k = O(log|𝒞|/γ) 步后 E[H] ≤ 0，即版本空间塌缩。可信集按后验质量 1−β 构造，故 P(c* ∈ C_k^β) ≥ 1−β。`diam(V_k) ≤ ε` 由假设类度量化（每步至少切掉 γ 的信息量）得到。∎

**引理 2（冲突修复可靠性）** CCR 只允许在 S_t 上做收缩（算法显式排除 H_t）。因此 H_{t+1} ⊇ H_t，安全域单调收紧。AGM 收缩+扩张给出最小改动（在 entrenchment 序下删除最小击中集）；若 MUS 触及硬约束则返回 abstain。故输出满足 `F_{t+1} ≠ ∅` 或 abstain，绝不存在「静默放宽安全约束后执行」。∎

**定理 1（任意时有效 + 自适应稳健）** 令 F_t 为到 t 为止的全部历史（包含问询策略、可选停止决策与用户回答）。取 λ_t 为 F_{t-1}-可测。H_0 下 `E[ℓ_t|F_{t-1}] ≤ α`，于是
`E[e_t|F_{t-1}] = 1 + λ_t(α − E[ℓ_t|F_{t-1}]) ≤ 1`。
e_t ≥ 1−λ_t ≥ 0，故 (E_t, F_t) 为非负上鞅，E[E_t] ≤ E[E_0] = 1。Ville 不等式：
`P(∃t≥0: E_t ≥ 1/δ) ≤ δ·E[E_t] ≤ δ`。
由于论证对任意 F_{t-1}-可测的 λ_t 与任意答案/停时机制成立，结论对自适应、对抗性、停停走走的问询策略都成立。对照：固定样本 t 检验若在 T 个数据依赖时刻反复查看，族错误率 ≤ 1−(1−α)^T，随 T 膨胀；e-process 不膨胀。∎

**定理 2（DR 一致性与诚实区间）** 在正性 `μ(a|s) ≥ p_min` 与奖励有界 |r| ≤ R_max 下，PDIS/DR 的重要性权重逐决策有界，方差 ≤ O(R_max² / (n·p_min))。当行为模型与 Q̂ 至少一个正确时 V_DR 无偏（双重鲁棒）；一般情形
`|V_DR − V(π)| ≤ O( sqrt(log(2/δ)/(n·p_min)) ) + B_model`，
B_model 为 Q̂/V̂ 的模型偏差。ESS 用于诊断：ESS < m_min 时重要性权重集中，估计不可信，算法返回 insufficient_evidence 而非点估计。∎

**定理 3（表演性间隙界）** 设用户最优反应导致的分布位移满足 `W_1(D_frozen, D_BR) ≤ κ`，且损失 L 对状态分布为 L-Lipschitz。则
`|M_BR(π) − M_frozen(π)| ≤ L·κ`。
在 ε-表演性稳定点 π* 处，若 π 与 π* 的策略排序在冻结评测下相差 ≥ 2Lκ，则排序在 BR 评测下可能翻转——这正是「冻结用户评测不可迁移」的形式化判据。∎

**命题（元证书校准）** 保形风险控制（CRC）取 λ̂ = inf{λ : (n/(n+1))R̂_n(λ) + 1/(n+1) ≤ α}。对可交换校准/测试样本与有界损失，`E[R(λ̂)] ≤ α`。证明是 CRC 标准结论：风险关于入选样本的期望由经验风险 + 1/(n+1) 的有限样本修正控制。若不可交换，则用 ACI 在线调整 λ 并只声称长期平均覆盖。∎

**定理 4（DIALECT-Complete）** 假设 A61–A76（ROSE）及：
- **(A77)** 对话回答模型 P(a|c,q,σ) 诚实或属于已知不确定集 𝒰；所选问题 γ-信息量（γ>0）；|𝒞| 有限或具有有限覆盖数。
- **(A78)** 安全硬约束集 H_t 不可由对话删除；GCR 权限矩阵拒绝任何降低 H_t 的修正。
- **(A79)** 评测损失有界 ℓ_t ∈ [0,1]；λ_t 可预测；H_0 的逐 episode 条件风险定义良好。
- **(A80)** DRO 正性 μ(a|s) ≥ p_min > 0；离线日志含行为策略概率。
- **(A81)** 用户模型不确定集 𝒰 覆盖真实最优反应；损失对分布位移 L-Lipschitz。
- **(A82)** 外部校准集与部署分布可交换或经时间加权；证书分数与损失可计算。
则 `Valid(J_dialect)` 蕴含：
1. **对话收敛或明确放弃**：diam(V_t) ≤ ε 且 P(c*∈C_t^β) ≥ 1−β，或系统 abstain（不假装理解）。
2. **跨轮安全不退化**：F_t ≠ ∅ 或 abstain；H_t 单调不降；Shield 的机制安全在每一轮保持。
3. **评测任意时有效**：自适应/对抗性问询与可选停止下，误报率 ≤ δ；不再依赖固定样本 i.i.d.。
4. **离线评估诚实**：正性成立时 DR 一致；ESS 不足时拒答。
5. **性能评估抗博弈**：发布口径为 M(π*)；Δ_perf 有界且被报告。
6. **证书自身可校准**：被接受证书的期望违规率 ≤ α（或声明为长期覆盖）。
7. **实时性不变**：实时流零对话写、零评测写、零等待，≤1ms 契约与 ROSE 完全一致。

## 5. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CBS 选问（语义流） | O(\|Q_ask\|·\|𝒞\|) | O(\|𝒞\|) | 引理 1：O(log\|𝒞\|/γ) 步 ε-收敛 |
| CBS 贝叶斯更新 | O(\|𝒞\|) | O(\|𝒞\|) | 后验归一、可信集质量 ≥1−β |
| CCR/MUS | 最坏 O(2^{\|S_t\|})，工程用 MaxSAT 近似 | O(\|S_t\|) | 引理 2：硬约束单调、非空或 abstain |
| AVE 更新 | O(1)（单 α）/ O(G)（网格 G=200） | O(G) | 定理 1：Ville 误报 ≤ δ |
| DRO | O(n·H) | O(n) | 定理 2：一致性 + ESS 拒答 |
| PSE | O(\|𝒰\|·n_mc·H) | O(H) | 定理 3：间隙 ≤ L·κ |
| MCX | O(n log n) | O(n) | 命题：期望风险 ≤ α |
| DCL | O(C) | O(C) | Hedge 伪遗憾 O(√(T log C)) |
| CEP 证据包 | O(1) | O(轮数) | 全轮可审计、来源可追溯 |
| DIALECT 实时路径 | ≤ 1ms 保持（ROSE 契约） | — | **零对话写、零评测写、零等待** |

**正确性注记（必须诚实声明的边界）**：
1. 定理 1 的 anytime 有效性是**对原假设成立的数据生成过程**而言；若策略本身改变了环境（表演性），则 H_0 的「固定风险」不再成立——此时只能声称「在该段历史的条件风险下有效」，并在 PSE 中另报间隙。二者不可混为一谈。
2. 引理 1 的收敛速率依赖 γ-信息量假设；若问题被用户策略性地答成无信息（γ→0），界退化为无穷——这正是本轮最大风险。
3. CRC 的 ≤α 是**期望**风险，不是每步条件风险；高风险尾部仍需 e-process 与安全停止兜底。

## 7. 已知风险

**一句话**：CBS 的收敛界、AVE 的 anytime 有效性、PSE 的表演性间隙，全都压在对「人类回答模型 P(a|c,q) 与用户不确定集 𝒰 正确」这一假设上；一旦用户策略性地给出无信息或误导性回答（或似然设定错误），系统会「自信地收敛到错误约束」，而同一模型错误又会让评测给出「已验证」的假象——对话与评测共享同一个不可验证的人类模型，是本轮全部保证的单点失效。

**次级风险与缓解**：
1. **问题空间爆炸**：Q_ask 连续/组合时 VOI 不可枚举 → 用子模近似 + 贪心（信息增益对条件熵近似子模），并限制每轮候选 ≤32；退出条件为 VOI<0 或预算耗尽。
2. **MUS 计算 NP-hard**：软约束规模大时 → 增量 MaxSAT + 冲突簇局部化（按来源/时间分块），只对最近窗口求 MUS；触发 abstain 的硬冲突直接升级人类。
3. **e-process 过度保守**：λ 固定会在真实违规时反应慢 → 用 hedged capital / 多 λ 并行取最大 e-value，保证功效同时不破坏有效性；阈值 δ 预注册。
4. **DR 正性崩溃**：长轨迹权重乘积爆炸 → PDIS 逐决策加权 + ESS 门控 + 悲观下界；必要时主动探索一小部分流量（探索税入预算）。
5. **表演性无限回归**：用户反应又依赖机器人对反应的预测 → 只报告一阶最佳反应与间隙上界，不做高阶不动点迭代；差距超阈值即冻结发布口径。
6. **评测本身被 Goodhart**：DCL 把评测采样集中到边界簇 → 用预注册的固定评测集 + 随机审计流量（≥5%）双轨，防止「只测能过的」。
7. **对话延迟与用户体验**：VOI 追问增加交互轮次 → cost(q) 含耐心衰减，硬性上限 ≤3 轮；超限则给出「最安全可行解 + 明确不确定性说明」。
