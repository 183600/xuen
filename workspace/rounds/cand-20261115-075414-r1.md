# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「跨任务泛化」×「轻量化结构」）

> R69 让闭环学会了「问」：不确定性二分，epistemic 交给看/问/触去消解。但整套 FLUID-RAS 有一个从未言明的前提——**每个任务都自带一整套专属重资产**：专属 trunk、专属流策略、专属标定、专属模态头、专属证书。换一个任务，保证从零开始；想在一台边缘机器人上同时跑五个任务，就要五套重模型和五套互不相认的证书。**R69 的保证是「任务下标」的，不是「可迁移」的**。
>
> 本轮两个灵感正好补上缺口：
> - **跨任务泛化**：真正该复用的不是「能力」，而是「验证」——策略可以千差万别（抓取/行走/装配/递物），但危险的形状高度同构：碰撞、失稳、过力、遮挡、超时、失接触。把「危险」从「任务」里抽出来，跨任务泛化就从「模型迁移」变成「坐标投影 + 契约」。
> - **轻量化结构**：小不只是参数少，而是**结构本身可验证**——单调 + Lipschitz 上界 + 低秩的小核，其区间证书在低维危险坐标上几乎免费；而单调性是**任务无关**的先验，天然可迁移。
>
> 核心命题：**把「裁决」从任务栈里剥离出来，做成一颗共享、冻结、结构可证的小核。大策略只提案（可重、可任务专属、可不可信），小核在共享危险坐标系上裁决（轻、可迁移、可审计）。跨任务泛化由安全层承担，而不是由能力层承担；保证转移的代价是一个可计算的「裕度价签」。** 命名 **NUCLEUS-RAS**（Nucleus-based Universal Certified Lightweight Envelope for Uncertainty-aware Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这些保证能不能只用一颗小核，就复用到所有任务上**」——安全不是一个任务一个模型学出来的，而是投影到共享危险坐标上、由一颗冻结的小核判定。

## 0. 直觉与动机

**灵感 1（跨任务泛化 → 可复用的不是能力，而是验证）**
直觉：我们一直默认「跨任务泛化」是大策略的属性，于是逼着一个大模型对所有任务都对，代价是它又大又难审计。但仔细看，任务之间真正共享的东西不是动作分布，而是**危险的形状**：任何具身任务都要远离碰撞、失稳、过力、遮挡、超时、失接触。危险是低维的，任务才是高维的。把危险从任务里抽出来，投影到一个共享的低维「危险坐标系」，任务之间就有了统一的比较与交接语言。于是跨任务泛化被拆成两个可分别求解的问题：**能力**（任务专属，允许重、允许不可信）与**裁决**（任务无关，必须小、必须可证）。**把泛化责任从能力层移到安全层，是本轮的第一个理论姿态。**

**灵感 2（轻量化结构 → 结构本身就是证书）**
直觉：轻量化有两种：一种是「把大模型压小」（蒸馏/剪枝/量化）， certify 时仍要面对一个黑箱；另一种是「一开始就长成可验证的形状」。本轮选后者：核做成**单调 + Lipschitz 上界 + 低秩**的结构化网络。单调性意味着「离危险更远绝不会更危险」——这是任何任务都成立的物理/安全先验，不需要从数据里学；Lipschitz 上界让区间证书可以被廉价地传播；低秩让每任务适配器的维度极小。于是「轻」与「可迁移」不是两个目标，而是同一个结构先验的两个面：**结构既买了推理/认证的便宜，也买了跨任务的可信。** 注意这与「用小模型拟合大模型」不同：小核不是近似大策略，它承载的是一个**单调风险上界**。

**灵感 3（propose-dispose → 大策略只提案，小盾牌才裁决）**
直觉：R69 让每个动作都过证书，但证书与策略绑在同一套重资产里。更好的分工是外科式的：**大策略负责「想」，小核负责「准」**。大策略可以重、可以任务专属、可以被投毒、可以幻觉——它永远只有提案权；小核必须小、共享、冻结、可证——它拥有否决权。这样跨任务泛化的负担从「大模型要对所有任务都对」降到「小核要对所有任务都保守」。后者容易得多，也更容易被审计和形式化。**安全架构的可扩展性，取决于被信任的那部分有多小，而不是被使用的模型有多强。**

**灵感 4（契约 → 保证转移不是免费的，价签是裕度）**
直觉：核只认识危险签名 σ，是适配器把任务观测投影到 σ。若适配器**高估**了裕度（把危险说成安全），核再准也没用。所以必须要求适配器**单侧可靠**：只能低估裕度，不能高估。低估的代价是保守（更多动作被判不安全），换来的是核的证书可以**原样转移**。于是跨任务泛化有一个明码标价：转移间隙 = 适配器单侧低估量 + 核 Lipschitz 放大 + 任务分布偏移。这个价签可计算、可审计、可预算——这比「相信大模型会泛化」要诚实得多。**安全侧的泛化从来不是免费的，它只是把代价从「不可知的失败」换成了「可度量的保守」。**

**灵感 5（共享核是单点故障 → 开放集 + 回退 + 无负迁移）**
直觉：一颗核服务所有任务，最怕两件事：其一，某任务存在 ℋ 里没有的危险（核会以完全自洽的证书盖章通过）；其二，为了让新任务过关而悄悄牺牲老任务（负迁移）。所以必须同时交付三件东西：**开放集危险探针**（残差/签名外域 → 契约失效 → 回退）、**无负迁移准入**（任何更新不得降低任一已注册任务的认证裕度）、**回退完备性**（每个状态要么核证书、要么本地证书，绝不留空档）。否则 NUCLEUS 不是轻量化，而是把一个任务的未知，变成一个机群的未知。

**灵感 6（对 R69 的严格包含 → R69 是「单任务 + 恒等适配」的边界）**
直觉：本轮不能推翻 R69。做法是把 R69 放回它真正的位置：**R69 是 T=1、适配器为恒等、契约恒真时的 NUCLEUS**。任何契约失效的任务/状态都路由回 R69 的本地全栈证书（重，但保证不变）。于是安全侧永不弱于 R69，效率侧在契约成立时获得「摊销认证 + 轻量裁决」的收益。这是前几轮反复坚持的姿态：**新层必须是旧层的严格泛化，而不是并列替代。**

## 1. 形式化定义（增量：定义 310–326）

**定义 310（NUCLEUS-RAS 总览）** NUCLEUS-RAS = (HZB, SGA, NUC, CTC, LSC, OSP, NBA, FTR, RAS-WM⋄)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；适配器/契约只离线写）；
(ii) **冻结核不变式**：部署期内核参数与其证书只读；任何在线更新只能发生在适配器/契约层，且必须通过 NBA；
(iii) **无无防护区**：任一状态要么持有「转移证书」（核 + 有效契约），要么持有「本地证书」（R69 全栈），二者不可同时缺失；无证书的动作一律不执行，宁可进入恢复/保守。

**定义 311（危险通道与安全签名 HZB）** 共享危险通道集 ℋ = {h_1,…,h_m}，m ≤ 16（碰撞、支撑、力、遮挡、时限、接触、…）。通道 h_i 的**裕度泛函** μ_i: 𝒪_τ × 𝒜_τ → ℝ，正值表示安全余量，负值表示越界。**安全签名** σ(o,a) = (μ_1,…,μ_m)。安全集 𝒮 = {σ : σ_i ≥ 0, ∀i}。关键是 μ 的定义在所有任务间**可比**（同一物理量纲/同一归一口径），σ 才是共享坐标，而不是又一个任务特征。

**定义 312（任务适配与危险接地 SGA）** 任务 τ 的适配器 A_τ = (E_τ, P_τ, b_τ)：观测/动作编码 E_τ: 𝒪_τ × 𝒜_τ → ℝ^{d}，低秩投影 P_τ ∈ ℝ^{m×d}（rank r ≤ 4），偏置 b_τ ∈ ℝ^m。签名估计 σ_τ(o,a) = P_τ E_τ(o,a) + b_τ。**残差** r_τ(o,a) 为 (o,a) 到适配器训练支撑集的距离 / 新颖度分（马氏距离、能量分或 kNN 到支撑集）。

**定义 313（单侧可靠性）** 适配器 A_τ 在置信度 1−δ_s 下**可靠**，当且仅当在支撑集上**逐坐标低估裕度**：
σ_{τ,i}(o,a) ≤ μ_i(o,a), ∀i。
不允许任何坐标高估。该性质由**单侧分位数校准 + 保形预测**实现（只取残差的上界，不取对称区间）。

**定义 314（冻结核与认证风险上界 NUC）** 核 N: D_N ⊂ ℝ^m → ℝ_{≥0}，对每个 σ_i **单调不增**，且 L_N-Lipschitz。对任务的认证风险上界
R̂(o,a) = N(σ_τ(o,a)) + L_N·ε_σ + r_reg，
其中 ε_σ 为单侧签名误差、r_reg 为残差回归界。动作可容许 ⇔ R̂(o,a) ≤ ε_safe。**核只输出上界，不输出点估计**——这是它与「学一个风险预测器」的本质区别。

**定义 315（结构化核）** N 为单调 Lipschitz 网络：非负权重（单调性由构造保证）、正交残差块 + 逐层谱范数约束（L_N = Π_j ℓ_j 可解析上界）、低秩隐藏层。量化版本按逐层舍入误差 ε_q 构造，其有效签名误差并入 ε_σ（定义 318、引理 21）。结构先验使核**任务无关**：单调性是物理先验，不是任务统计。

**定义 316（转移契约 CTC）** 任务 τ 的契约 C_τ = (δ_cov, ε_σ, r_reg, D_τ^{dom}, h_index)。有效条件：
(a) **覆盖**：P_{o~𝒟_τ}[σ_τ(o,·) ∈ D_N] ≥ 1−δ_cov；
(b) **单侧可靠**：定义 313 成立；
(c) **认证**：对校准集与对抗集，R̂ ≤ ε_safe 的比例达到审计阈值；
(d) **索引一致**：ℋ 到任务危险源的映射 h_index 无冲突、无未覆盖的已知危险。
CTC 是**跨任务的唯一接口**：核不知道任务，任务不知道核，二者只通过 σ 与 C_τ 相接。

**定义 317（转移假设 A99–A102）** A99：N 单调 + L_N-Lipschitz（定义 314–315）；A100：A_τ 单侧可靠（定义 313）；A101：任务分布偏移有界（W_1(𝒟_τ, 𝒟_src) ≤ W_max）；A102：契约覆盖成立（定义 316-a）。四条假设是定理 18 的全部前提，缺一即回退。

**定义 318（轻量认证 LSC）** 利用 N 的单调性，认证区间可取 [N(σ+εσ), N(σ)]，单调网络下 IBP **几乎精确**。进一步用**绑定通道分解**：把 m 个通道按物理耦合分成 G 组（每组 ≤3 维），风险 R̂ = max_g R̂_g；每组离线预计算**证书图集**（certificate atlas），在线只需 O(m) 定位 + O(1) 查表 + 加性 Lipschitz 膨胀。核的证书（L_N、图集、量化误差）**只算一次**，被所有任务共享——这是「摊销认证」的结构基础。

**定义 319（开放集危险探针 OSP）** 三路信号：(a) 签名域外（σ ∉ D_N）；(b) 适配器残差 r_τ > τ_r；(c) 签名空间的密度/重建异常。任一触发 ⇒ 契约失效 ⇒ 路由 FTR。OSP 只能**降低**盲区，不能消除盲区；其漏检率 δ_o 是引理 20 的显式残项。

**定义 320（无负迁移准入 NBA）** 维护任务注册表与每任务**裕度票** ticket(τ) = min_{o∈校准集∪对抗集} (ε_safe − R̂_τ(o))。任何对共享字典/核（仅离线）/适配器的更新 u 只有在
min_{τ∈registry} [ticket_u(τ) − ticket(τ)] ≥ 0
时才被准入；即**任一已注册任务的认证裕度不得下降**。新任务准入还需通过 CTC 与 OSP 的联合检验。这是一条刻意保守的规则：宁可拒绝一个「平均更好」的更新，也不接受一个「某些任务更危险」的更新。

**定义 321（回退路由 FTR）** 三态状态机：NUCLEUS（转移证书）→ R69-LOCAL（本地全栈证书）→ R68-CONSERVATIVE（纯保守）。转移条件单调、无环、可审计；进入前两态的判据分别为 CTC 有效 / 可恢复的本地契约。**任何状态下都不存在「无证书执行」**。

**定义 322（少样本接入 AAU）** 新任务只需学习 (E_τ, P_τ, b_τ) 与契约参数 (ε_σ, r_reg)，不触碰核。样本复杂度只随适配器维度 d·r 与 m 增长，不随核规模 B_N 增长。于是**接入成本 ≈ 适配器拟合 + 契约校准**，而非「重训整套安全栈」。

**定义 323（跨任务审计 VQAuditor-T）** 审计对象新增：契约有效性、单侧可靠违反、开放集触发、负迁移事件、回退频率、证书图集版本、量化位宽。结论回灌 AuditBuf，成为下一轮 NBA 与 OSP 阈值的先验。

**定义 324（跨任务干扰集 AIC-NUCLEUS）** ℰ_NUC = ℰ_FLUID × ℰ_cross，其中 ℰ_cross 含：**裕度膨胀攻击**（适配器被诱导高估裕度）、**共享字典投毒**（一个任务污染共享危险嵌入）、**开放集伪装**（未知危险落在 D_N 内且残差小）、**量化触发的证书缝隙**（int8 舍入吃掉安全裕度）。并入对抗训练与红队测试。

**定义 325（证书 J_NUCLEUS）** J_NUCLEUS = (J_FLUID（回退时）、contract_hash、nucleus_cert_hash、L_N、ε_σ、δ_cov、quant_bits、fallback_rate、negative_transfer_log、osp_stats、nucleus_ver)。Valid ⇔ 契约有效 ∧ 核证书未过期 ∧ NBA 无违规 ∧ 量化膨胀 ≤ 裕度。

**定义 326（轻量预算）** 部署预算 B = (B_N, B_A, T_query, T_cert, M)：核参数 B_N ≤ 5×10^4、单任务适配器 B_A ≤ 5×10^3、核裁决查询 T_query ≤ 0.2ms、认证摊销 T_cert ≤ O(B_A)、内存 M ≤ 1MB（int8）。预算是**硬约束**：超预算即退回 R69（重但可用），不允许「为了轻而悄悄放弃证书」。

```python
# IP-264 HZB：共享危险签名（任务无关的坐标）
def hazard_signature(o, a):
    return vector([margin[h](o, a) for h in HAZARDS])   # m <= 16, 可比裕度

# IP-265 SGA：任务适配器（唯一按任务训练的部分，低秩 + 单侧校准）
class SafetyGroundingAdapter:
    def __init__(self, d, m, rank=4):
        self.E = Encoder(d)                     # 任务专属，小
        self.P = LowRank(m, d, rank)            # rank <= 4
        self.b = zeros(m)
    def ground(self, o, a):
        sigma = self.P(self.E(o, a)) + self.b
        return sigma, self.residual(o, a)       # 残差 = 到支撑集的新颖度

# IP-266 NUC：结构化单调 Lipschitz 核（冻结、共享、可证）
class CertifiedNucleus:
    def forward(self, sigma):
        x = sigma
        for blk in self.blocks:                 # 非负权重 + 正交残差 + 谱范数<=1
            x = blk(x)
        return self.head(x)                     # 单调不增的风险上界
    def certified_risk(self, sigma, eps_sigma):
        return self.forward(sigma + eps_sigma) + L_N * eps_sigma   # 单侧：往危险侧膨胀

# IP-268 LSC：离线一次、全任务共享的证书图集
def certify_nucleus_once(N, D_N, groups):
    L_N   = prod(blk.lipschitz for blk in N.blocks)   # 解析上界
    atlas = {g: build_monotone_atlas(N, g, D_N) for g in groups}  # 绑定通道分组
    q_err = quant_error_bound(N, bits=8)
    return Certificate(L_N, atlas, q_err)              # 只算一次，冻结

def certified_risk_fast(N, cert, sigma, eps_sigma):
    g   = binding_group(sigma)                          # 主危险组
    return cert.atlas[g].lookup(sigma) + cert.L_N * (eps_sigma + cert.q_err)

# IP-267 CTC：契约检查（跨任务的唯一接口）
def check_contract(tau, calib_set):
    eps_sigma = one_sided_upper_quantile(residuals(tau), alpha=1-DELTA_S)  # 只取上界
    cov       = coverage(tau, D_N)
    ok        = (eps_sigma <= EPS_SIGMA_MAX) and (cov >= 1-DELTA_COV) \
                and audit_pass(tau, calib_set)
    return Contract(ok, eps_sigma, cov)

# IP-319 OSP：开放集危险探针
def open_set_alert(sigma, r_tau):
    return (not in_domain(sigma, D_N)) or (r_tau > TAU_R) \
           or (signature_density(sigma) < TAU_DENSITY)

# IP-320 NBA：无负迁移准入
def admit(update, registry):
    for tau in registry:
        if min_margin(tau, update) < min_margin(tau, current):  # 任一任务裕度下降
            return False
    return True

# IP-321 FTR + IP-274 主闭环：大策略只提案，小核才裁决
def NUCLEUS_step(M, o, tau):
    sigma, r = M.sga[tau].ground(o, M.last_action)
    if M.osp.alert(sigma, r):
        return M.ftr.to_local(o, tau, why='open_set')       # -> R69 本地证书
    if not M.ctc[tau].valid(sigma):
        return M.ftr.to_local(o, tau, why='contract')       # -> R69 本地证书
    a  = M.policy[tau].propose(o)                            # 大策略只提案
    sg, rg = M.sga[tau].ground(o, a)
    Rh = M.nuc.certified_risk(sg, M.ctc[tau].eps_sigma)
    if Rh > EPS_SAFE:                                        # 提案被核否决
        a  = M.shield.project(o, sg, M.nuc)                  # 签名空间内找可容许的最近动作
        sg, rg = M.sga[tau].ground(o, a)
        Rh = M.nuc.certified_risk(sg, M.ctc[tau].eps_sigma)
    if Rh > EPS_SAFE:
        return M.ftr.to_recover(o, tau, sg)                  # 核判不安全：恢复/保守，不硬执行
    M.vqa_t.log(tau, sg, Rh, M.ctc[tau].hash, M.nuc.cert_hash)
    return a

# IP-322 AAU：新任务接入只训练适配器 + 契约（不碰核）
def onboard(task, data):
    A = SafetyGroundingAdapter(d, m).fit(data)               # 少样本
    C = check_contract(task, calibration(data))
    return A, C if C.ok else fallback_to_r69(task)           # 契约不过 -> 全栈本地证书
```

## 3. 推导

**引理 19（单侧可靠性下的证书转移）** 设核 N 对每个 σ_i 单调不增，适配器单侧可靠：σ_i(o,a) ≤ μ_i(o,a)。若 N(μ) 是真实风险上界，则
N(σ) ≥ N(μ) ≥ R_true，
即低估裕度只会让上界更保守、绝不更乐观。计入签名估计误差 ε_σ 与 Lipschitz 常数 L_N 后，R̂ = N(σ) + L_N ε_σ 仍是上界；保守代价为 N(μ) − N(σ) ≤ L_N‖μ−σ‖∞。要点：**单侧可靠性把「适配器准不准」这个回归问题，降级成了「适配器会不会高估」这个更弱、更容易校准的问题。**

**引理 20（开放集盲区界）** 设单侧可靠违反率为 δ_s、OSP 漏检率为 δ_o，则「未知危险被盖章为安全」的概率
≤ δ_s + δ_o + P(μ ∈ D_N, h_new ∉ ℋ, r ≤ τ_r)。
最后一项是 ℋ 的张成误差，任何有限危险基都无法消除。系：共享核把 per-task 的未知**合成为** fleet 级未知；机群规模为 K 时，δ_o 必须做 Bonferroni/e-value 聚合，否则「单机 1% 漏检」在千机机群上就是「几乎必然有盲区」。

**引理 21（量化证书保持）** int8 逐层舍入等效于在签名上叠加加性误差 ε_q（按层放大后并入 ε_σ）。因 N 的 L_N-Lipschitz，认证上界膨胀 ≤ L_N ε_q。若该任务认证裕度 slack ≥ L_N ε_q，则量化后 J_NUCLEUS 仍 Valid；否则必须降位宽或对该任务回退。要点：**轻量化的数值代价必须被显式计入证书，而不是被「反正差不多」吸收掉。**

**定理 18（跨任务保证转移与价签）** 在 A99–A102（N 单调 + Lipschitz、适配器单侧可靠、任务分布偏移有界、契约覆盖）下，对任一满足契约的任务 τ 与 (o,a) ∈ supp(𝒟_τ)：
R_true(o,a) ≤ N(σ_τ(o,a)) + L_N ε_σ ≤ ε_safe。
进一步，新任务的期望风险满足
R_new ≤ R_src + L_N·E[μ − σ_τ] + C·W_1(𝒟_τ, 𝒟_src)。
故跨任务泛化不是免费的：**价签 = 单侧低估（保守） + 核 Lipschitz 放大（认证） + 分布偏移（数据）**。三项都可估、可审计、可预算；这正是它优于「相信大模型泛化」的地方。

**定理 19（摊销认证与轻量界）** 对 T 个任务，NUCLEUS 的总部署/认证成本为
C_N（一次） + Σ_τ (C_adapter + C_contract) + T·c_query，
其中 c_query = O(m·W_N) 可退化为 O(1) 查表（定义 318），且与核参数 B_N **无关**；逐任务边际认证成本 O(B_A + m)，不随 T 重验大核。相比「每任务独立 R69 全栈重验」的 T·C_full，存在 **T 倍量级的证书复用收益**，且收益随 T 线性增长、不牺牲每任务保证。这是「轻量化」真正的来源：**共享的不是模型权重，而是证书。**

**定理 20（无负迁移 + 回退完备 ⇒ 安全侧严格不弱于 R69）** 在 NBA 准入（定义 320）与 FTR 完备（定义 321，每个状态要么转移证书、要么本地 R69 证书）下，任一已注册任务的认证裕度不随时间下降；且当适配器为恒等、任务为源任务、核证书与 R69 证书一致时，NUCLEUS 逐指令等价于 R69。故 **R69 是 NUCLEUS 在 T=1、恒等适配、契约恒真时的退化情形**；任何契约失效状态都路由回 R69 本地栈，安全侧不做让步。注意该定理的「完备」依赖 OSP 的漏检率 δ_o——它正是引理 20 的残项，也是本轮最大风险的来源。

**系（跨任务泛化的正确指标）** 评价 NUCLEUS 不应只看「新任务成功率」，而应看三元组 (转移间隙, 契约覆盖率, 回退率)。一个「新任务成功率很高但转移间隙估计不出来」的系统，只是在用更大的黑箱换取更大的未知。

## 6. 本轮最大风险

**一句话**：NUCLEUS 的全部收益押在「共享危险基 ℋ 足以张成所有任务的真实危险」这一前提上——**若某任务的致命危险不在 ℋ 里，或适配器把它的裕度高估了一点，核会以完全自洽、看似无可挑剔的证书盖章通过；而共享核把过去「每个任务各自不知道」合并成「整个机群一起不知道」，一次盲区就是一次全局单点失效**——共享的证书越便宜，共享的盲区就越贵。

**次级风险与缓解**：
1. **单侧可靠性校准漂移**（分布漂移后不再低估）→ 保形预测滚动重校准 + CTC 定期再验证 + 漂移触发回退；
2. **OSP 漏检**（未知危险落在 D_N 内且残差小）→ 多路开放集信号 + 机群级 e-value 聚合 + 红队未知危险注入；
3. **无负迁移准入过保守**（永远无法更新）→ 分任务裕度票 + 可解释的拒绝日志 + 离线影子评估；
4. **量化/边缘数值吃掉裕度** → 引理 21 显式计入证书 + 位宽自适应 + 超界即回退；
5. **契约维护成本**（多任务的契约会腐烂）→ 证书图集版本化 + VQAuditor-T 定期审计 + 契约过期即降级。

## 3. 关键算法伪代码

```python
# IP-264 HZB：共享危险签名（任务无关坐标，m <= 16）
def hazard_signature(o, a):
    return vector([margin[h](o, a) for h in HAZARDS])      # 可比裕度，正值安全

# IP-265 SGA：任务适配器（唯一按任务训练，低秩 + 单侧校准）
class SafetyGroundingAdapter:
    def ground(self, o, a):
        sigma = self.P(self.E(o, a)) + self.b              # rank <= 4
        return sigma, self.residual(o, a)                  # 残差 = 支撑集新颖度

# IP-266 NUC：冻结、共享、单调 Lipschitz 核（只输出上界）
class CertifiedNucleus:
    def forward(self, sigma):                              # 非负权重 + 正交残差
        x = sigma
        for blk in self.blocks: x = blk(x)
        return self.head(x)                                # 单调不增
    def certified_risk(self, sigma, eps_sigma):
        return self.forward(sigma + eps_sigma) + L_N * eps_sigma   # 单侧膨胀

# IP-268 LSC：离线一次、全任务共享的证书图集（摊销认证）
def certify_nucleus_once(N, D_N, groups):
    L_N   = prod(blk.lipschitz for blk in N.blocks)
    atlas = {g: build_monotone_atlas(N, g, D_N) for g in groups}
    return Certificate(L_N, atlas, quant_error_bound(N, bits=8))

def certified_risk_fast(cert, sigma, eps_sigma):
    return cert.atlas[binding_group(sigma)].lookup(sigma) \
           + cert.L_N * (eps_sigma + cert.q_err)           # O(1) 查表 + 膨胀

# IP-267 CTC：契约（跨任务唯一接口）
def check_contract(tau, calib_set):
    eps_sigma = one_sided_upper_quantile(residuals(tau), alpha=1-DELTA_S)
    cov       = coverage(tau, D_N)
    ok        = eps_sigma <= EPS_SIGMA_MAX and cov >= 1-DELTA_COV \
                and audit_pass(tau, calib_set)
    return Contract(ok, eps_sigma, cov)

# IP-269 OSP：开放集危险探针
def open_set_alert(sigma, r_tau):
    return (not in_domain(sigma, D_N)) or (r_tau > TAU_R) \
           or (signature_density(sigma) < TAU_DENSITY)

# IP-270 NBA：无负迁移准入（任一已注册任务裕度不得下降）
def admit(update, registry):
    return all(min_margin(tau, update) >= min_margin(tau, current)
               for tau in registry)

# IP-274 主闭环：大策略只提案，小核才裁决
def NUCLEUS_step(M, o, tau):
    sigma, r = M.sga[tau].ground(o, M.last_action)
    if M.osp.alert(sigma, r):
        return M.ftr.to_local(o, tau, why='open_set')      # -> R69 本地证书
    if not M.ctc[tau].valid(sigma):
        return M.ftr.to_local(o, tau, why='contract')      # -> R69 本地证书
    a  = M.policy[tau].propose(o)                          # 大策略只提案
    sg, rg = M.sga[tau].ground(o, a)
    Rh = M.nuc.certified_risk(sg, M.ctc[tau].eps_sigma)
    if Rh > EPS_SAFE:                                      # 提案被核否决
        a  = M.shield.project(o, sg, M.nuc)                # 签名空间内最近可容许动作
        sg, rg = M.sga[tau].ground(o, a)
        Rh = M.nuc.certified_risk(sg, M.ctc[tau].eps_sigma)
    if Rh > EPS_SAFE:
        return M.ftr.to_recover(o, tau, sg)                # 恢复/保守，不硬执行
    M.vqa_t.log(tau, sg, Rh, M.ctc[tau].hash, M.nuc.cert_hash)
    return a

# IP-272 AAU：新任务只训练适配器 + 契约（不碰核）
def onboard(task, data):
    A = SafetyGroundingAdapter(d, m).fit(data)
    C = check_contract(task, calibration(data))
    return (A, C) if C.ok else fallback_to_r69(task)
```

## 4. 推导

**引理 19（单侧可靠性的证书转移）** N 逐坐标单调不增且适配器单侧可靠 `σ_i ≤ μ_i` ⇒ `N(σ) ≥ N(μ) ≥ R_true`；计入 ε_σ 后 `R̂ = N(σ)+L_Nε_σ` 仍为上界，保守代价 `N(μ)−N(σ) ≤ L_N‖μ−σ‖∞`。系：把「适配器准不准」降级为「适配器会不会高估」，后者更弱、更易校准。

**引理 20（开放集盲区界）** 单侧违反率 δ_s、OSP 漏检率 δ_o 时，错误盖章概率 `≤ δ_s + δ_o + P(μ∈D_N, h_new∉ℋ, r≤τ_r)`。系：共享核把 per-task 未知合成为 fleet 级未知；机群 K 台须做 Bonferroni/e-value 聚合，否则单机 1% 漏检在千机机群上近乎必然出现盲区。

**引理 21（量化证书保持）** int8 逐层舍入等效签名误差 ε_q；由 L_N-Lipschitz，认证上界膨胀 `≤ L_Nε_q`；若任务裕度 slack ≥ L_Nε_q，则量化后证书仍 Valid，否则降位宽/回退。

**定理 18（跨任务保证转移与价签）** 在 A99–A102 下，任一满足契约任务与 (o,a)：`R_true ≤ N(σ_τ)+L_Nε_σ ≤ ε_safe`；且 `R_new ≤ R_src + L_N·E[μ−σ_τ] + C·W_1(𝒟_τ,𝒟_src)`。跨任务泛化的价签 = 单侧低估 + 核 Lipschitz 放大 + 分布偏移，三项均可估、可审计、可预算。

**定理 19（摊销认证与轻量界）** T 个任务总成本 `C_N + Σ_τ(C_adapter+C_contract) + T·c_query`，`c_query=O(m·W_N)` 可退化为 O(1) 查表，**与 B_N 无关**；逐任务边际认证成本 `O(B_A+m)`，不随 T 重验大核。较「每任务独立 R69 全栈」的 `T·C_full`，存在 T 倍量级证书复用收益且不牺牲每任务保证。轻量化的真正来源是**共享证书**，不是共享权重。

**定理 20（无负迁移 + 回退完备 ⇒ 安全侧不弱于 R69）** NBA 使已注册任务裕度不降；FTR 使每状态要么转移证书、要么本地 R69 证书；当适配器恒等、任务为源任务、核证书与 R69 一致时逐指令等价于 R69。故 R69 是 NUCLEUS 在 T=1、恒等适配、契约恒真时的退化；任何契约失效状态都回到 R69 本地栈。该定理的「完备」依赖 OSP 漏检率 δ_o——即引理 20 的残项，也是本轮最大风险。

**系（跨任务泛化的正确指标）** 评价应看三元组 `(转移间隙, 契约覆盖率, 回退率)`，而非只看新任务成功率；「成功率高但转移间隙估不出来」只是用更大的黑箱换更大的未知。

## 5. 复杂度分析

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| HZB 危险签名（m≤16） | < 0.02ms | O(m) | 定义 311；任务无关坐标 |
| SGA 适配器（rank≤4） | < 0.05ms | < 20KB/任务 | 定义 312–313；单侧校准 |
| NUC 前向（≤5×10^4 int8） | < 0.08ms | < 200KB | 定义 314–315；单调 + Lipschitz |
| LSC 证书查表 / IBP | < 0.03ms | < 50KB/图集 | 定义 318；离线一次、全任务共享 |
| OSP 残差 / 新颖度 | < 0.02ms | O(m) | 定义 319；开放集门控 |
| **核裁决总延迟** | **< 0.2ms** | — | 定理 18；与任务、策略大小无关 |
| 回退 R69 路径 | 2.6–3.4ms | 继承 R69 | 定理 20；本地全栈证书 |
| 新任务接入（AAU） | 适配器拟合 + 契约校准 | O(B_A) | 定义 322；不触碰核 |

对比要点：R69 的保证成本是「每任务一次全栈认证 O(B_full)」；NUCLEUS 是「核一次 O(B_N) + 每任务 O(B_A + m)」。T 增大时，NUCLEUS 边际认证成本趋近常数，R69 线性增长——**收益是随任务数增长的摊销曲线，而非单点延迟**。

## 7. 本轮最大风险

**一句话**：NUCLEUS 的全部收益押在「共享危险基 ℋ 足以张成所有任务的真实危险」这一前提上——**若某任务的致命危险不在 ℋ 里，或适配器把它的裕度高估了一点，核会以完全自洽、看似无可挑剔的证书盖章通过；而共享核把过去「每个任务各自不知道」合并成「整个机群一起不知道」，一次盲区就是一次全局单点失效**——共享的证书越便宜，共享的盲区就越贵。

**次级风险与缓解**：单侧可靠性校准漂移（保形滚动重校准 + CTC 再验证 + 漂移回退）；OSP 漏检（多路开放集信号 + 机群级 e-value 聚合 + 红队未知危险注入）；无负迁移准入过保守（分任务裕度票 + 可解释拒绝日志 + 离线影子评估）；量化/边缘数值吃裕度（引理 21 显式计入 + 位宽自适应 + 超界回退）；契约腐烂（证书图集版本化 + VQAuditor-T 定期审计 + 过期降级）。
