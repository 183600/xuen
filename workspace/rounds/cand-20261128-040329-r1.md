### 第 5 轮灵感驱动研究记录

**灵感词**：泛化能力、课程学习

**继承关系**：第 4 轮 CADVS-v4（IP-489~492）在五锚点基础上追加价值锚 VACK 与平衡锚 BCK，形成七硬门 kc_evidence_forged_v4 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem ∧ kc_val ∧ kc_bal，软评分 ECS_v4 = ECS_v3·η_val·η_bal，执行集嵌套 Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ … ⊆ Exec_v29。本轮不推翻 v4，而是补上它未回答的两个问题：**（泛化）证据能否外推到部署分布？** 与 **（课程）如何用最少的证据、最稳的顺序完成外推？** 由此形成 CADVS-v5（IP-493~496），新增泛化保证锚 GACK 与课程锻造锚 CFC；执行集继续收缩为 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。关键结构决策：v5 新增的两道硬门只作用于**规则准入/慢时域**，不进入 1 kHz 控制环，从结构上回避 v4 的最大风险（实时性）。

**直觉与动机**：

1. **泛化能力：把「有限证据上的合法」升级为「部署分布上的风险上界」**。v4 的七锚点都是**经验证据**：3DCF 覆盖的是已观测空间、MSRG 的 S2RC 基于有限试验、LTEM 记录的是历史成功/失败。证书通过只证明「在证据分布 P_src 上合法」，并不保证在部署分布 P_deploy 上合法；而机器人恰恰在「新物体、新位姿、新摩擦、新载荷」上失效。引入泛化保证证书 GAC，把「经验风险 → 部署风险」的 gap 用三部分显式上界：(a) PAC-Bayes 复杂度项（规则后验 Q 相对联邦先验 P0 的 KL 与样本量 n）；(b) Wasserstein-DRO 分布漂移项（漂移半径 ρ 乘损失 Lipschitz 常数 L_ℓ）；(c) OOD 新颖度项（部署批次到证据支撑集的距离 ν_ood）。硬门 kc_gen：R_bound ≤ τ_risk ∧ ν_ood ≤ ν_max，否则 fail-closed。让「证书通过」多问一句：「这条规则在没见过的情形上，最坏能坏到哪？」

2. **课程学习：把「一次性全量铸造」升级为「按难度分阶段的证据采集」**。v1~v4 默认所有候选规则在同一分布上采集证据，样本效率低、且难任务早期失败会污染 LTEM。引入课程锻造控制器 CFC：为每个任务/规则定义难度 d(τ)（覆盖缺口、接触复杂度、集成不确定性、价值边际的加权），按 d 升序分阶段 K 采集证据；每阶段在「上一阶段掌握」后才晋级（mastery learning）。课程不是装饰，而是**泛化界的最优实验设计**：易任务的低方差证据先把 PAC-Bayes 项压小，再以收紧后的界作为进入难任务的判据。硬门 kc_curr：阶段不跳级 ∧ 覆盖达标 ∧ **部署代理集校准通过**。最后一项是关键防呆——课程分布必须被一个非课程采样的分层验证集校准，否则课程会把分布偏置误当成泛化。

3. **解决「课程扩张 vs 执行集收缩」的表面矛盾：能力-信任分离**。课程让**候选规则库 KC_t 单调增长**（能力变强）；硬门让**每条规则的部署执行集 Exec 单调收缩**（信任变严）。两者作用在不同对象上，因此不矛盾：课程扩张「可以尝试什么」，硬门收缩「可以信任什么」。形式化后得到「能力-信任分离定理」：|KC_t| 非降，而 Exec_CADVS-v5 对同一规则集 ⊆ Exec_CADVS-v4，且总可信比例 |Exec|/|KC| 可随课程推进而下降——这不是退化，而是「学得更多、信得更谨慎」。

4. **联邦课程：跨站难度序不同，需要课程先验聚合与一致性界**。不同站点的任务难度分布、接触条件、价值权重不同，直接 FedAvg 难度阈值会得到「无人满意」的课程。FFA 的 Δ_i 扩充课程统计量（各难度分位的成功率、样本量、漂移半径），Φ_global 下发全局课程先验与漂移先验；站点保留本地课程个性化。给出跨站课程一致性界：若站点难度分布间 W_1 ≤ D_div，则全局阶段阈值的迁移误差为 O(D_div)。

**关键洞见**：v4 回答「证据是否充分（sufficient）」；v5 回答「证据能否外推（generalizable）、以及如何最省证据地外推（curriculum）」。泛化证书是**尺度**，课程是**路径**；二者对偶——课程按泛化界的收紧速度给任务排序，泛化界反过来决定课程的晋级阈值。且 v5 的所有新计算都在准入/慢时域，控制环逻辑与 v4 完全一致，不新增实时性负担。

**形式化目标（增量）**：
1. 定义泛化保证证书 GAC = (R_emp, R_bound, KL_Q, n, ρ_hat, L_ℓ, ν_ood, δ, t)，及硬门 kc_gen = (R_bound ≤ τ_risk ∧ ν_ood ≤ ν_max)，软因子 η_gen = clamp(1 − R_bound/τ_risk, 0, 1)。
2. 定义难度度量 d(τ) = w_c·(1−Γ_3D) + w_k·κ_contact + w_u·σ_ens + w_v·(1−α_val)，归一化到 [0,1]；课程 C = (τ_(1),…,τ_(K)) 满足 d(τ_(1)) ≤ … ≤ d(τ_(K))。
3. 定义课程锻造证书 CCC = (stage k, D_k, R_bound_k, coverage_k, gap_val_k, t)，及硬门 kc_curr =（阶段 ≤ k 全部通过）∧（不跳级）∧（coverage_k ≥ γ_k）∧（|R̂_val − R̂_cur| ≤ ε_gap）。
4. 定义泛化上界定理：R_deploy(Q) ≤ R̂_S(Q) + √((KL(Q‖P0)+ln(2√n/δ))/(2n)) + L_ℓ·ρ_hat（以概率 ≥ 1−δ）。
5. 定义课程-泛化对偶定理：难度升序课程以 replay 与后验热启动把有效 KL 降低 Δ_transfer，达到同一 τ_risk 所需样本 n_curr ≤ n_random·(1 − Δ_transfer/KL)；若难度代理与真实损失方差的相关性 < 1−ε，则增益退化为 O(ε) 甚至负迁移。
6. 定义能力-信任分离定理：|KC_t| 非降；对同一规则集 Exec_CADVS-v5 ⊆ Exec_CADVS-v4，且新增硬门非恒真时严格收缩。
7. 定义 EFA-v5：九硬门 kc_evidence_forged_v5 = kc_evidence_forged_v4 ∧ kc_gen ∧ kc_curr（前七门在控制环/准入，后两门仅在准入），软评分 ECS_v5 = ECS_v4·η_gen·η_curr。
8. 明确实时性不变式：v5 不在控制环新增任何计算，kc_gen/kc_curr 的评估延迟只影响「规则准入时延」，不影响 1 kHz 控制周期。

**本轮最大风险**：**难度代理与漂移半径的双重失配会让泛化证书「在课程分布上很紧、在部署分布上失效」**——若难度 d(τ) 与真实损失方差弱相关，或 ρ_hat 被低估，则 PAC-Bayes-DRO 界是乐观的，脆性规则被假泛化准入（false generalization），而系统误以为自己已有可证明的泛化保证。

## 2. 关键算法骨架

### IP-493 GACK：泛化保证证书（准入/慢时域，异步 ~50–200 ms）

```python
@dataclass
class GeneralizationAssuranceKernel:
    """GACK：PAC-Bayes + Wasserstein-DRO + OOD → 部署风险上界；kc_gen 硬门"""
    tau_risk: float = 0.05           # 部署风险阈值
    nu_max: float = 0.35             # OOD 新颖度阈值
    delta: float = 0.05              # 置信水平
    lipschitz: float = 1.0           # L_ℓ（由损失定义/标定得到）
    prior: Any = None                # P0，来自 FFA Φ_global

    def certify(self, rule: Rule, evidence: EvidenceSet, deploy_proxy: ProxySet,
                t_now: float) -> GAC:
        # 1) 经验风险与 PAC-Bayes 复杂度项
        r_emp = evidence.mean_loss(rule)
        kl = self._kl_posterior_prior(rule, self.prior)          # KL(Q‖P0)
        n = evidence.size
        b_pb = r_emp + math.sqrt((kl + math.log(2.0 * math.sqrt(n) / self.delta))
                                 / (2.0 * n))
        # 2) 漂移半径：证据→部署代理的 Wasserstein-1 置信上估
        rho_hat = self._wasserstein_upper(evidence, deploy_proxy, self.delta)
        # 3) OOD 新颖度：部署代理批次到证据支撑集的距离
        nu_ood = self._ood_novelty(deploy_proxy, evidence)
        # 4) 部署风险上界（Kantorovich-Rubinstein 对偶吸收漂移）
        r_bound = b_pb + self.lipschitz * rho_hat
        return GAC(r_emp=r_emp, r_bound=r_bound, kl_q=kl, n=n, rho_hat=rho_hat,
                   lipschitz=self.lipschitz, nu_ood=nu_ood, delta=self.delta, t=t_now)

    def kc_gen(self, gac: GAC) -> bool:
        """引理 43：通过 ⟹ 部署风险以 1−δ 概率不超过 τ_risk"""
        return gac.r_bound <= self.tau_risk and gac.nu_ood <= self.nu_max

    def eta_gen(self, gac: GAC) -> float:
        return float(np.clip(1.0 - gac.r_bound / self.tau_risk, 0.0, 1.0))

    def _kl_posterior_prior(self, rule, prior) -> float: ...
    def _wasserstein_upper(self, ev, proxy, delta) -> float: ...
    def _ood_novelty(self, proxy, ev) -> float: ...
```

### IP-494 CFC：课程锻造控制器（准入/慢时域，秒~分钟级）

```python
@dataclass
class CurriculumForgingController:
    """CFC：难度升序分阶段采集证据；mastery 晋级 + 部署代理集校准；kc_curr 硬门"""
    w: tuple = (0.35, 0.25, 0.20, 0.20)   # w_c, w_k, w_u, w_v
    gamma_fn: Callable = lambda k: 1.0 - 2.0 ** (-k)
    eps_gap: float = 0.03
    n_stage: int = 200                    # 每阶段新增样本数
    replay: float = 0.3                   # 前序阶段回放比例（防遗忘）

    def difficulty(self, task: Task, scf, bcc_hist, ensemble, vac) -> float:
        cov = scf.gamma3d(task.x, task.t)
        k_contact = self._contact_complexity(bcc_hist)
        sigma = self._ensemble_uncertainty(ensemble, task)
        v_margin = 1.0 - vac.alpha_val
        d = (self.w[0]*(1-cov) + self.w[1]*k_contact
             + self.w[2]*sigma + self.w[3]*v_margin)
        return float(np.clip(d, 0.0, 1.0))

    def build_curriculum(self, candidates: list[Task], scf, bcc_hist, ensemble, vac) -> list[Task]:
        scored = [(self.difficulty(t, scf, bcc_hist, ensemble, vac), t) for t in candidates]
        scored.sort(key=lambda z: z[0])          # 难度升序
        return [t for _, t in scored]

    def run_stage(self, k: int, stage_tasks: list[Task], gack: GeneralizationAssuranceKernel,
                  ltem, deploy_proxy: ProxySet, t_now: float) -> tuple[CCC, bool]:
        # 1) 采集：本阶段 n_stage + 前序 replay（LTEM 热启动，降低有效 KL）
        D_k = self._acquire(stage_tasks, n_new=self.n_stage,
                            replay_ratio=self.replay, ltem=ltem)
        # 2) 用 D_k 更新后验，重算泛化界
        gac_k = gack.certify(rule=stage_tasks[0].rule, evidence=D_k,
                             deploy_proxy=deploy_proxy, t_now=t_now)
        # 3) mastery 判据：泛化界达标 + 覆盖达标 + 部署代理校准
        coverage = self._coverage(stage_tasks, deploy_proxy, d_max=max(t.d for t in stage_tasks))
        r_val = deploy_proxy.stratified_risk(stage_tasks[0].rule)   # 非课程采样
        r_cur = D_k.risk(stage_tasks[0].rule)
        gap = abs(r_val - r_cur)
        ccc = CCC(k=k, D_k=D_k, r_bound_k=gac_k.r_bound, coverage_k=coverage,
                  gap_val_k=gap, t=t_now)
        passed = (gac_k.r_bound <= gack.tau_risk
                  and coverage >= self.gamma_fn(k)
                  and gap <= self.eps_gap)
        return ccc, passed

    def kc_curr(self, k: int, history: list[CCC], ccc: CCC) -> bool:
        """引理 44：不跳级 + 前序全部通过 + 本阶段三项达标"""
        if [h.k for h in history] != list(range(1, k)):
            return False                                   # 不跳级
        if not all(h.passed for h in history):
            return False                                   # 前序未掌握
        return (ccc.r_bound_k <= self.tau_risk and ccc.coverage_k >= self.gamma_fn(k)
                and ccc.gap_val_k <= self.eps_gap)

    def eta_curr(self, ccc: CCC) -> float:
        return float(np.clip(ccc.coverage_k * math.exp(-ccc.gap_val_k / self.eps_gap), 0.0, 1.0))

    def _contact_complexity(self, bcc_hist) -> float: ...
    def _ensemble_uncertainty(self, ensemble, task) -> float: ...
    def _acquire(self, tasks, n_new, replay_ratio, ltem) -> EvidenceSet: ...
    def _coverage(self, tasks, proxy, d_max) -> float: ...
```

### IP-495 CERTCALC-v5：泛化与课程的核心定理（离线理论）

```python
# 定理 5：泛化上界（PAC-Bayes + Wasserstein-DRO）
def theorem_generalization_bound() -> str:
    """
    定理 5：设损失 ℓ_π(x) ∈ [0,1] 且关于 x 为 L_ℓ-Lipschitz，证据集 S ~ P_src^n 独立同分布，
    Q 为规则族上的后验，P0 为先验，W_1(P_deploy, P_src) ≤ ρ_hat 以概率 ≥ 1−δ/2 成立。
    则对任意 Q，以概率 ≥ 1−δ：
        R_deploy(Q) ≤ R̂_S(Q) + sqrt((KL(Q‖P0) + ln(2 sqrt(n)/δ)) / (2n)) + L_ℓ·ρ_hat.
    且当 ν_ood > ν_max（部署批次落在证据支撑集外）时该界不适用，kc_gen fail-closed。
    证明：PAC-Bayes 不等式给出前两项；Kantorovich-Rubinstein 对偶给出
```

### IP-496 EFA-v5：九硬门 + 软评分 + 证据铸造流水线 v5

```python
@dataclass
class EvidenceForgingAssemblerV5:
    """EFA-v5：控制环沿用 v4 七门；准入追加 kc_gen/kc_curr；ECS_v5 = ECS_v4·η_gen·η_curr"""
    v4: EvidenceForgingAssemblerV4
    gack: GeneralizationAssuranceKernel
    cfc: CurriculumForgingController
    tau_risk: float = 0.05

    def admission_gate(self, rule, x, t_now, rule_id, hic, eec, bcc,
                       object_class, geo_sig, theta_domain_fp, traj, context,
                       evidence, deploy_proxy, stage_k, stage_history) -> tuple[bool, str]:
        # 1) 先过 v4 七硬门（HIC veto 最高优先级）
        ok, why = self.v4.hard_gate(x, t_now, rule_id, hic, eec, bcc,
                                    object_class, geo_sig, theta_domain_fp, traj, context)
        if not ok:
            return False, why
        # 2) 泛化门（准入时，非控制环）
        gac = self.gack.certify(rule, evidence, deploy_proxy, t_now)
        if not self.gack.kc_gen(gac):
            return False, 'GENERALIZATION_UNPROVEN'
        # 3) 课程门（不跳级 + 掌握 + 部署代理校准）
        ccc, passed = self.cfc.run_stage(stage_k, [rule.task], self.gack,
                                         self.v4.ltem, deploy_proxy, t_now)
        if not self.cfc.kc_curr(stage_k, stage_history, ccc):
            return False, 'CURRICULUM_UNPROVEN'
        return True, 'FORGED_V5'

    def control_loop_gate(self, *args, **kwargs) -> tuple[bool, str]:
        """控制环：完全等价 v4.hard_gate，不新增任何计算"""
        return self.v4.hard_gate(*args, **kwargs)

    def ecs_v5(self, x, t_now, rule_id, A_att=0.0, eta_mem=0.5,
               eta_val=0.5, eta_bal=0.5, eta_gen=0.5, eta_curr=0.5) -> float:
        return (self.v4.ecs_v4(x, t_now, rule_id, A_att, eta_mem, eta_val, eta_bal)
                * eta_gen * eta_curr)
```

## 3. 复杂度与实时性（v5 的关键卖点：控制环零增量）

| 模块 | 时间复杂度 | 空间复杂度 | 实时性指标 | 所在时域 |
|---|---|---|---|---|
| GACK.certify | O(n·d + n log n)（KL + Wasserstein 经验估计） | O(n·d) | ~50–200 ms | 准入/慢时域 |
| GACK.kc_gen | **O(1)** | O(1) | < 0.01 ms | 准入 |
| CFC.build_curriculum | O(|cand| log |cand|) | O(|cand|) | 秒级 | 慢时域 |
| CFC.run_stage | O(n_stage·d) | O(n_stage·d) | 秒~分钟级 | 慢时域 |
| CFC.kc_curr | **O(K)**（K 阶段数，K ≤ 32） | O(K) | < 0.1 ms | 准入 |
| EFA-v5.admission_gate | O(1) + GACK/CFC | — | < 0.2 s | 准入 |
| EFA-v5.control_loop_gate | **O(1)**（等价 v4） | O(1) | **< 0.03 ms（不变）** | 控制环 |
| 端到端控制环延迟 | **与 v4 相同** | — | P99 仍为 ~0.8 ms | 控制环 |

**通信开销**：GAC 证书仅规则准入时产生（~0.5 KB/规则）；CCC 每阶段一条（~1 KB/阶段）；FFA Δ_i 扩充课程/漂移统计至 ~8–15 KB/站点；原始数据不离站。

**实时性结论**：v4 的最大风险是「新增控制环计算打破 1 ms 预算」。v5 通过**把新证据门全部放在准入/慢时域**，使控制环与 v4 逐指令等价，从结构上消除该风险。代价是「规则上线时延」增加（每阶段秒~分钟级），这是可接受的工程折衷。

## 4. 正确性论证

### 引理 43（泛化保证硬门的一致性界）

**陈述**：在定理 5 的条件下，若 kc_gen 通过（R_bound ≤ τ_risk 且 ν_ood ≤ ν_max），则对后验 Q，部署风险 R_deploy(Q) ≤ τ_risk 以概率 ≥ 1−δ 成立。

**证明**：由定理 5，R_deploy(Q) ≤ R_bound；kc_gen 要求 R_bound ≤ τ_risk，传递即得。ν_ood 条件保证漂移假设 W_1 ≤ ρ_hat 在部署批次上仍然适用（否则界不成立，fail-closed 拒绝）。∎

**工程含义**：把「在证据上没出错」升级为「在部署分布上最坏也不超过 τ_risk」，且界对样本量、模型复杂度、分布漂移、OOD 四个来源显式可分解，便于定位泛化失败原因。

### 引理 44（课程晋级的安全单调性）

**陈述**：设阶段 k 的晋级判据为 P_k = (R_bound_k ≤ τ_risk) ∧ (coverage_k ≥ γ_k) ∧ (gap_val_k ≤ ε_gap)，且 kc_curr 要求阶段 1..k 全部通过。则 (i) 晋级不会放宽任何风险阈值（τ_risk 全程固定）；(ii) 不跳级保证每个难度分位都有证据覆盖；(iii) 若部署代理集分层采样自 P_deploy，则 gap_val_k 是课程-部署分布偏置的一致估计，ε_gap 控制假泛化概率。

**证明**：(i) τ_risk 与 ε_gap 为常量，判据只增不减；(ii) 由 kc_curr 的前序全通过约束归纳；(iii) 分层采样使 R̂_val 无偏估计 P_deploy 风险，Hoeffding 给出 gap 的置信界。∎

**工程含义**：课程不是「降低标准」，而是「用固定标准、按难度分阶段达成」；代理校准把「课程分布偏置」显式暴露，而不是偷偷带进泛化界。

### 定理 v5（泛化保证 + 课程加速 + 能力-信任分离）

**陈述**：在 (B1)~(B6)（继承 v4）以及新假设 (B7) 损失 Lipschitz 有界、(B8) 漂移半径置信上估有效、(B9) 部署代理集分层采样自 P_deploy 下：
(i) Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29（严格收缩，新增 kc_gen/kc_curr 非恒真时严格）；
(ii) 部署风险 R_deploy ≤ τ_risk 以概率 ≥ 1−δ（引理 43）；
(iii) 课程达到 τ_risk 的样本复杂度不超过随机序的 n_random·(1−Δ_transfer/KL)，代理失配时按定理 6 折损；
(iv) 能力-信任分离（定理 7）：|KC_t| 非降，Exec 对固定规则集收缩；
(v) 联邦课程迁移超额风险 ≤ L_d·D_div + 定理 3 的 DP/毒化项（定理 8）；
(vi) 控制环与 v4 逐指令等价，无新增实时性风险。

**证明**：(i) v5 在 v4 准入路径上追加 kc_gen ∧ kc_curr 合取项；(ii) 引理 43；(iii) 定理 6；(iv) 定理 7；(v) 定理 8；(vi) 由 control_loop_gate 直接委托 v4.hard_gate 的实现。∎

**诚实声明**：(B8) 是本轮最脆弱假设——漂移半径 ρ_hat 的高估使界变松（可用性下降），低估使界失效（安全性下降），且真实 P_deploy 不可见，只能由代理集近似。(B9) 部署代理集若本身有偏（如只在实验室采），则 gap_val 校准失效。缓解：多代理集集成、conformal 校准、ρ_hat 保守放大、ν_ood fail-closed；但本质上泛化保证是「相对于所假设的漂移模型」的保证，不是绝对保证。

## 7. 本轮最大风险（最终确认）

**一句话**：**难度代理与漂移半径的双重失配会让泛化证书「在课程分布上很紧、在部署分布上失效」**——若难度 d(τ) 与真实损失方差弱相关，或 ρ_hat 被低估，则 PAC-Bayes-DRO 界是乐观的，脆性规则被假泛化准入（false generalization），而系统误以为自己已有可证明的泛化保证。
