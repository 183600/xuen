# 第 14 轮（新灵感循环第 1 轮；本轮灵感：「手眼标定」×「指标体系」）

> **基线**：第 13 轮 MetricVoiceGauge-NCD-HUTDH v15（技能扩散版；当前产物区 IP-378–401；定义 607–626；引理 125–130；实验 E661–E670）。
> **本轮纪律**：不推倒 v15。v6–v15 的九个不变式、v13 的 AIO/CPD/DDL/RTCR、v15 的 SCD/DSD/DCA/EDC 全部保留。五个新组件——HEC（手眼包络证书）、OMS（可观测性监督）、CIS（可证指标体系）、IAG（指标审计守卫）、CBD（标定预算调度）——一律以**中立元**接入，失效即严格退回 v15 的 nominal 标定/指标路径，再沿 v15→v14→v13→…→v6 退化链回收。本轮只做三件事：把“手眼变换”从一次性点估计改写为**带支撑域与记忆的认证集合**；把“指标体系”从仪表盘改写为**与证书对偶、不可补偿、抗 Goodhart 的判决系统**；把二者合成一条“标定—指标预算”。

## 0. 直觉与动机

**灵感 1（手眼标定 → 标定不是一个点，而是一个带支撑域的集合）**
直觉：v15 默认存在一个标定好的 `T̂_CE`，把相机点搬到末端或基座。但手眼标定 `AX=XB` 的解从来不是一个点：它由一组有限位姿的观测、有限精度的相机内参、有限同步的时间戳共同决定；当标定运动没有激发足够多旋转轴时，绕某个方向的平移/旋转几乎不可观测，解会沿一条很薄的流形滑动。更糟的是，安装会随振动、温升、线缆拉扯、换刀缓慢漂移，而任务分布又会走到标定支撑域之外。于是“标定一次、永远使用”在平均重投影误差上可能很好，却在支撑域边缘、在某个特定朝向、在漂移累积之后最危险。核心创新：**手眼包络证书（Hand-Eye Envelope Certificate, HEC）**。它不估计一个最优点，而是维护一个带记忆的认证集合 `C_t ⊆ SE(3)`，并给出它在任务空间中的投影半径 `ρ_he(x)` 与支撑域 `Ω_cal`。关键反直觉点：**安全关键路径上不要“标定得更准”，而要“把标定不确定性包成集合，并让任务/标定运动去缩小它”**；集合外的任何重投影、插值、学习补偿只能用于排序，不能用于放行。

形式化预告：设真实手眼变换为 `T ∈ SE(3)`，观测对 `(A_i,B_i)` 满足 `A_i T = T B_i + ε_i`，`‖ε_i‖ ≤ δ_i`。HEC 维护
`C_0 = { T' ∈ SE(3) : max_i d(A_i T', T' B_i) ≤ δ_i }`
的外逼近 `B(T̂, r_0)`，并把 `T'∈C_t` 经当前位姿的微分 `Dg` 投影为任务空间误差球
`ρ_he(x) = σ_max(Dg)·r(x) + ε_depth + ε_sync`；
`r(x)` 在 `x∉Ω_cal` 时按 Lipschitz 常数 `L_Ω` 膨胀。HEC 的唯一承诺是：真实 `T` 在所有时刻落在 `C_t` 内。

**灵感 2（指标体系 → 指标不是仪表盘，而是证书的可审计投影）**
直觉：v15 已经报告大量数字——p99 延迟、FAR/FRR、完成率、覆盖 `ρ_cov`、扩散温度 `τ`、共形余量 `U_d`。但这些是**仪表盘**：它们可以平均、可以加权、可以互相补偿。只要允许“用 2% 的完成率换 1% 的假接受”，就一定存在一个把安全违规藏在平均里的操作点。指标体系的真正问题不是“指标不够多”，而是缺少三层结构：**可观测性（这个数能不能被可靠测量）→ 可靠性（这个数绿了是否真的安全）→ 抗博弈性（能否在不改善真实安全的情况下把数做绿）**。核心创新：**可证指标体系（Certifiable Indicator System, CIS）**。每个安全指标 `I_j` 携带一个**可靠性关系** `I_j ≤ θ_j ⇒ φ_j`（绿 ⇒ 证书成立），而不是相关性；安全维度的聚合必须是**不可补偿**的 `min`/合取（最弱环节），性能维度才允许加权；指标层级严格单向约束（低层证书约束高层指标，反之不成立）。关键反直觉点：**“指标全绿”必须被定义成一个充分条件，而不是一个优化目标**；一旦把绿灯当成目标去优化，Goodhart 就会把指标与证书解耦。

形式化预告：指标系统 `I = (I^0,…,I^L)`，每层有阈值 `θ_j` 与证书谓词 `Φ_j`。**可靠性**：`Green_j = {s : I_j(s) ≤ θ_j} ⊆ Φ_j`。**保守间隙**：`Γ_j = sup_{s∈Green_j} (m_Φ(s) − m_I(s)) ≥ 0`。**抗博弈性**：对可达状态 `a,a'`，若 `I(a) ≤ I(a')` 则 `Φ(a') ⇒ Φ(a)`（指标序反射证书序）。安全聚合 `I_safe = min_j (θ_j − I_j)`，禁止 `Σ_j w_j I_j`。

**灵感 3（手眼 × 指标 → 标定—指标对偶与预算化自标定）**
直觉：标定状态 `C_t` 是隐藏的、连续的、缓慢漂移的；指标 `I_t` 是可观测的、离散的、可审计的。二者不是两套系统，而是同一个对象的**隐藏态—观测投影**。把标定证书投影成指标，系统才能被人类审计；把指标反馈给标定，系统才能知道“该往哪个方向激发运动来缩小包络”。但自标定有一个先有鸡还是先有蛋的难题：要缩小 `C_t` 需要做激发运动，而激发运动本身必须先用 `C_t` 证明安全。核心创新：**标定—指标对偶（Calibration–Indicator Dual, CID）+ 标定预算调度（Calibration Budget Director, CBD）**。对偶把 `C_t → I_t → 授权` 与 `C_t → 证书 → 授权` 画成一张交换图，二者之差 `Γ` 就是指标的保守间隙；CBD 把每一帧的预算分成“任务”和“可证激发”两部分，只在**净预算非负**（激发带来的包络收缩收益 ≥ 其安全预算消耗）时才注入标定运动。关键反直觉点：**标定不是免费的离线步骤，而是一种要用安全预算购买的、可证安全的信息获取动作**；买不起时，正确做法是缩小任务域或降速，而不是偷偷标定。

形式化预告：CID 的交换图要求 `I_t = Π(C_t)` 且 `Green(I_t) ⇒ Acc_t` 有效；CBD 选择激发 `u ∈ Acc_v16(C_t)` 使得 `Δr(u) ≥ c·cost(u)`，则 `C_{t+1} ⊆ C_t` 且 `r` 单调不增；若不存在这样的 `u`，`C_t` 保持不变（绝不用未认证数据扩张）。

**三者如何统一**
统一为 v15 语义/时限层之上的**标定可信层**：v15 回答“哪些动作在语义上被允许、在时限内能执行多少”（`Exec_v15`），v16 回答“这些动作在当前手眼标定不确定性下是否可证、以及系统能否用可审计指标证明这一点”（`Exec_v16`）。HEC 给出隐藏的标定集合，OMS 监督其可观测性，CIS 把集合投影成不可补偿的指标，IAG 审计指标是否仍与证书对偶，CBD 用可证激发买回包络。共享状态 `ζ_ci=(C_t, r_t, Ω_cal, I_t, Γ_t, B_he, B_cal, mode)`。硬包含关系为
```
Acc_v16(x) ⊆ Acc_v15(x),    Exec_v16 ⊆ Exec_v15 .
```

## 1. 研究问题（轮次升级版）

- **Q1（标定集合的可证语义）**：如何定义 `C_t` 才使“真实 `T` 永远在集合内”在有限观测、时间同步误差、深度误差下仍成立？`AX=XB` 的残差集如何外逼近成可在线更新的测地球而不丢解？支撑域外的膨胀常数 `L_Ω` 由什么量给出、在接触/遮挡/大深度处是否仍有效？
- **Q2（指标系统的可靠性）**：如何让“指标全绿”成为安全证书的充分条件而非相关指标？安全/性能维度的不可补偿聚合能否形式化为“绿灯集 ⊆ 证书集”？抗 Goodhart 的序反射条件在有限样本、分布漂移、指标被对抗优化时还能验证吗？保守间隙 `Γ` 如何量化并纳入预算？
- **Q3（对偶与预算化自标定）**：`C_t` 与 `I_t` 的投影何时交换？可证激发如何在“安全”与“信息增益”之间做预算最优？净预算非负的判据需要怎样的可观测性模型？当没有安全激发可用时，如何优雅地缩小任务域而不是让系统停滞？
- **Q4（与 v15 的兼容、活性与退化）**：HEC/OMS 是否可能被 v15 的 SCD/DSD 旁路？v15 的 `U_d`、`ρ_cov`、`τ` 与 v16 的 `B_he` 会不会误差叠加或相互抵消？IAG 能否区分“指标真的坏了”与“任务暂时走出支撑域”？塌缩到 `collapsed` 是否会长期清空可行集、导致频繁 `a_ask`？

## 2. 设计原则（在 P22–P24 基础上新增 P25–P27）

**P25 标定即集合律（Calibration as a Certified Set）**
安全关键路径上禁止用单一手眼变换 `T̂` 或平均重投影误差放行动作。每个被执行的动作必须相对一个认证集合 `C_t` 检查，且 `C_t` 只能由**已认证的观测/运动**收缩；任何来自未认证运动、跨支撑域插值、学习补偿的更新只能用于排序/预筛，不能用于扩张 `C_t` 或放行。若 `C_t` 无法认证，则该动作不得进入 `Acc_v16`。

**P26 指标即可证投影律（Indicators as Sound, Non-Compensatory Projections）**
每个安全指标必须携带“绿 ⇒ 证书成立”的可靠性关系；安全维度禁止加权和、禁止与性能维度交换，只能用 `min`/合取/字典序。指标层级必须单向：低层证书约束高层指标，高层指标不得放宽低层证书。任何把指标当成优化目标、或允许“用性能补安全”的聚合，都不构成可证指标系统。

**P27 自标定预算非负律（Certified Self-Calibration Pays Its Way）**
标定运动是一种信息获取动作，必须像任务动作一样通过 `Acc_v16` 认证。只有当激发 `u` 的包络收缩收益 `Δr(u)` 不低于其安全预算消耗 `c·cost(u)` 时，才允许注入；否则保持 `C_t` 不变。禁止用“先动一下看看”来获取标定数据，也禁止把标定运动排除在安全证书之外。

## 3. 与基线的接口（如何退化）

- HEC 失效 ⇒ 注入 v15 的 nominal 标定路径：`C_t ≡ {T̂_nominal}`、`ρ_he ≡ ε_nominal`，只保留名义重投影检查，**等价 v15 的标定使用方式**；
- OMS 失效 ⇒ 不再做可观测性膨胀，`r_t` 冻结在离线最坏情形 `r_max`，包络更保守但不再自适应，**等价“静态 HEC + v15”**；
- CIS 失效 ⇒ 指标退回 v15 的仪表盘（加权聚合），不提供“绿 ⇒ 安全”的可靠性关系，此时 IAG 强制把所有指标视为不可信，**等价 v15 的报告路径**；
- IAG 失效 ⇒ 审计守卫关闭，指标只能作事后日志，授权只走 HEC 证书路径，**等价“HEC + v15”**；
- CBD 失效 ⇒ 不注入任何标定运动，`C_t` 只随已认证任务观测收缩或冻结，**等价“无自标定 + HEC”**；
- 五者全失效 ⇒ MetricVoiceGauge-NCD-HUTDH v15（技能扩散版），再沿 v15→v14→v13→v12→…→v6 退化链回收；
- **安全继承**：HEC 只给出认证集合，OMS 只膨胀，CIS 只投影，IAG 只否决/塌缩，CBD 只在认证集内选激发。五端口均不能新增授权或放宽 v15 阈值；`Exec_v16 ⊆ Exec_v15` 由引理 136 保证。运行时仍与 v15 的时限/守卫结果取交。

## 4. 预期贡献

1. **手眼包络证书**：把“标定一次”改写为“维护一个带支撑域与可观测性记忆的认证集合”，给出 `AX=XB` 残差集的外逼近、支撑域外推的 Lipschitz 膨胀、以及 `ρ_he` 的任务空间界；解决“平均重投影很好、边界/漂移处最危险”的结构性矛盾；
2. **可证指标体系**：把“指标”从仪表盘改写为“证书的可审计投影”，给出可靠性关系、不可补偿聚合的不可行性定理、抗 Goodhart 的序反射条件与保守间隙 `Γ`；填补“安全关键系统的指标体系不可证”的空白；
3. **标定—指标对偶与预算化自标定**：把隐藏标定态与可观测指标画成交换图，把自标定改写为“用安全预算购买信息增益”的可证激发问题，给出净预算非负的单调收缩保证；
4. **语义层—标定层分离与可拔插退化**：v15 管“允许什么/时限内能做多少”，v16 管“在标定不确定性下是否可证、指标能否审计”；E671–E690 覆盖包络覆盖、支撑外推、不可补偿聚合、Goodhart 审计、漂移塌缩、端到端与消融。

## 5. 本轮最大风险

**一句话**：指标可靠性只在其标定支撑域 `Ω_cal` 内被验证，而 HEC 的噪声界 `δ_i`、膨胀常数 `L_Ω` 与 CIS 的支撑假设可能在同一场分布漂移中同时失效；此时包络自洽、指标全绿、对偶交换图也“成立”，系统却在支撑域外执行了一个**按证书、按指标、按对偶都自洽、却绝对错误的安全决定**。

## 1. 关键算法骨架

# IP-402 Hand-Eye Envelope Certificate：带支撑域的手眼认证集合
class HandEyeEnvelopeCertificate:
    def __init__(self, T_hat, r0, Omega_cal, L_Omega, eps_depth, eps_sync):
        self.T_hat = T_hat              # 名义手眼变换
        self.r = r0                     # 当前包络半径
        self.Omega = Omega_cal          # 认证支撑域
        self.L = L_Omega                # 支撑外膨胀 Lipschitz 常数
        self.eps_depth = eps_depth      # 深度/分割误差上界
        self.eps_sync = eps_sync        # 时间同步误差上界

    def update(self, pairs, motion_set, delta):
        # AX=XB 残差集 -> 测地球外逼近；只允许收缩
        resid = [d(A @ self.T_hat, self.T_hat @ B) for A, B in pairs]
        r_obs = max(resid) + delta
        self.r = min(self.r, r_obs)
        return self.r

    def support_distance(self, x, R):
        # 位姿到 Ω_cal 的测地距离
        return dist_XxSO3((x, R), self.Omega)

    def project(self, x, pose, depth):
        # 集合 -> 任务空间误差球
        r_x = self.r + self.L * self.support_distance(x, pose.R)
        J = jacobian_task_wrt_transform(pose, depth)
        return sigma_max(J) * r_x + self.eps_depth + self.eps_sync

    def certify(self, a, x, U_d, eps_model):
        rho = self.project(x, current_pose(x), depth(x))
        budget = rho + U_d + eps_model
        return m_task(a, x) >= budget, budget


# IP-403 Observability Margin Supervisor：可观测性监督与膨胀
class ObservabilityMarginSupervisor:
    def __init__(self, sigma_star, c_obs, drift_guard):
        self.sigma_star = sigma_star    # 可观测性阈值
        self.c_obs = c_obs              # 膨胀系数
        self.drift_guard = drift_guard

    def sigma_min(self, motion_set):
        O = stack_screw_axes(motion_set)
        return svdvals(O)[-1]

    def inflate(self, r, motion_set):
        s = self.sigma_min(motion_set)
        if s < self.sigma_star:
            return r * (1.0 + self.c_obs / max(s, 1e-9))
        return r

    def needs_excitation(self, motion_set):
        return self.drift_guard.fired() or self.sigma_min(motion_set) < self.sigma_star


# IP-404 Certifiable Indicator System：分层、不可补偿、可证投影
class CertifiableIndicatorSystem:
    SAFETY = ("calib_residual", "support_coverage", "budget_margin", "drift")
    PERF = ("completion", "latency", "frr")

    def __init__(self, theta, U_gap):
        self.theta = theta              # 每维阈值
        self.U_gap = U_gap              # 审计得到的一侧间隙上界

    def project(self, hec, r, budgets, task_stats):
        I = {
            "calib_residual": r,
            "support_coverage": rho_HE(task_stats.poses, hec.Omega),
            "budget_margin": task_stats.m_task - budgets.B_total,
            "drift": drift_score(),
            "completion": task_stats.completion,
            "latency": task_stats.p99_latency,
            "frr": task_stats.false_reject_rate,
        }
        return I

    def green(self, I):
        # 安全维度：最弱环节，不可补偿
        safety = min(self.theta[j] - I[j] for j in self.SAFETY)
        safe = safety >= 0.0
        # 性能维度：只在安全绿灯内允许加权排序
        perf = sum(self.theta[j] * I[j] for j in self.PERF)
        return safe, perf

    def gap(self, I, cert_margin):
        ind_margin = min(self.theta[j] - I[j] for j in self.SAFETY)
        return cert_margin - ind_margin


# IP-405 Indicator Audit Guard：指标—证书解耦审计
class IndicatorAuditGuard:
    def __init__(self, alpha_false_green, U_gap, support_fn):
        self.alpha = alpha_false_green
        self.U_gap = U_gap
        self.support_fn = support_fn
        self.false_green = 0
        self.total_green = 0

    def check(self, I, cert_margin, ind_margin, state):
        self.total_green += 1
        if not self.support_fn(state):
            return True, "outside_support"
        if ind_margin > cert_margin + self.U_gap:
            return True, "indicator_optimism"
        if self.total_green > 0 and self.false_green / self.total_green > self.alpha:
            return True, "goodhart"
        return False, "ok"


# IP-406 Calibration Budget Director：任务/可证激发预算
class CalibrationBudgetDirector:
    def __init__(self, c_gain, B_cal_max):
        self.c_gain = c_gain
        self.B_cal_max = B_cal_max

    def allocate(self, B_time, B_safe, need_excitation):
        B_cal = min(B_safe, self.B_cal_max) if need_excitation else 0.0
        return B_time - B_cal, B_cal

    def select_excitation(self, candidates, hec, acc_v16):
        feasible = [u for u in candidates if u in acc_v16]
        scored = [(info_gain(u, hec) / (cost(u) + 1e-9), u) for u in feasible]
        return max(scored)[1] if scored else None

    def accept(self, u, delta_r, cost_u):
        return delta_r >= self.c_gain * cost_u

def metricvoicegauge_round_16_handeye_indicator(M, s, obs, ...):

    results = middleware.run_cycle(runners={...}, ctx=ctx)

            execute(u)

    elif verdict == 'degrade':

        current_chunk = v15_conservative_chunk()
    elif verdict == 'recover':
        execute_recovery(nge.epistemic_recovery())

    # ---- 低频异步：重标定、指标校准、审计统计 ----

## 2. 形式化定义（定义 627–646）

**定义 627（手眼认证集合）** 设观测对 `(A_i,B_i)` 满足 `A_iT=TB_i+ε_i`、`‖ε_i‖≤δ_i`。手眼认证集合为
`C_obs = {T'∈SE(3) : max_i d(A_iT',T'B_i) ≤ δ_i}`；
HEC 用测地球 `C_t=B(T̂_t,r_t)` 外逼近 `C_obs∩C_{t-1}`，并保证 `T∈C_t`。

**定义 628（包络半径与支撑膨胀）** 对位姿 `x=(p,R)`，
`r(x)=r_t+L_Ω·dist((x,R),Ω_cal)`，
`ρ_he(x)=σ_max(Dg(x))·r(x)+ε_depth+ε_sync`，
其中 `Dg` 是手眼变换到任务点的微分，`L_Ω` 是支撑域外误差增长的 Lipschitz 常数。

**定义 629（标定预算消耗）** 动作 `a` 在 `x` 处的标定预算消耗 `B_he(a,x)=ρ_he(x)`；它必须与 v15 的 `U_d`、模型误差 `ε_model` 以加法合取，禁止相互抵消。

**定义 630（可观测余量）** 对运动集 `M={ξ_1,…,ξ_m}`（螺旋轴），`O_t=[ξ_1;…;ξ_m]`，可观测余量 `σ_min(O_t)`。若 `σ_min<σ_*`，包络按 `r_t←r_t(1+c_obs/σ_min)` 膨胀。

**定义 631（分层指标系统）** `I=(I^0,I^1,I^2,I^3)`，分别为原始测量层、证书层、任务层、审计层；每层含安全维 `S` 与性能维 `P`。

**定义 632（指标可靠性）** 对安全指标 `j`，`Green_j={s:I_j(s)≤θ_j}`；若 `Green_j⊆Φ_j`，称 `I_j` 对证书 `Φ_j` 可靠（绿 ⇒ 证书成立）。

**定义 633（保守间隙）** `Γ_j=sup_{s∈Green_j}(m_Φ(s)−m_I(s))`，`Γ=max_jΓ_j≥0`；它度量“指标比证书多保守/多乐观”。

**定义 634（抗博弈性/序反射）** 对可达状态 `a,a'`，若 `I(a)≤I(a') ⇒ Φ(a')⇒Φ(a)`，则指标不可在不改善证书的情况下被“刷绿”。

**定义 635（不可补偿安全聚合）** `I_safe(s)=min_{j∈S}(θ_j−I_j(s))`；安全当且仅当 `I_safe≥0`。禁止 `Σ_j w_j I_j` 作为安全判据；加权和只允许在安全绿灯内对性能维排序。

**定义 636（可证激发）** 激发 `u` 可证，若 `u∈Acc_v16(C_t)`；其收益 `Δr(u)=r_t−r_{t+1}(u)`，成本 `cost(u)` 为执行 `u` 消耗的安全预算。

**定义 637（净预算非负）** 激发可接受当且仅当 `Δr(u)≥c_gain·cost(u)`；否则不注入，`C_{t+1}=C_t`。

**定义 638（标定—指标对偶）** 交换图要求 `I_t=Π(C_t)`，`Green(I_t)⇒Φ(C_t)`，且 `Γ_t=m_Φ(C_t)−m_I(I_t)` 被 IAG 的一侧上界 `U_gap` 控制。

**定义 639（审计触发）** IAG 在以下任一条件触发：`state∉Ω_cal`；`m_I>m_Φ+U_gap`（指标过度乐观）；经验假绿率 `>α_false_green`。

**定义 640（v16 授权集）** `Acc_v16={a∈Acc_v15 : m_task(a,x)≥B_total(a,x)，IAG 未触发，且所需激发可证}`。

**定义 641（退化模式）** `normal`：HEC/CIS/IAG/CBD 全部有效；`reduced`：IAG 或 OMS 部分失效，授权收缩到 HEC-only；`collapsed`：任一关键证书失效，只允许 v15 的认证回退/`a_ask`。

**定义 642（支撑覆盖率）** `ρ_HE=|{x∈D_task : x∈Ω_cal}|/|D_task|`；它与 v15 的数据集覆盖 `ρ_cov` 不同，前者是标定支撑，后者是技能数据支撑，二者不得混用。

**定义 643（指标层级单向性）** 对相邻层 `ℓ,ℓ+1`，`I^{ℓ+1}` 绿灯必须蕴含 `I^ℓ` 绿灯；高层指标不得放宽低层证书。

**定义 644（指标归一化）** 每个指标归一化到 `[0,1]` 并带方向与阈值；禁止跨维度 z-score/加权补偿；安全维只做 `min`。

**定义 645（联合预算）** `B_total(a,x)=B_he(a,x)+U_d+ε_cal+ε_model`，所有项非负；任一项无法认证时置 `+∞`（fail-closed），不得置 0。

**定义 646（共享状态）** `ζ_ci=(C_t,r_t,Ω_cal,I_t,Γ_t,B_he,B_cal,mode,audit)`，每帧更新，作为 v16 与 v15 的唯一接口。

## 3. 推导

**引理 131（HEC 的可靠性）** 假设 A1：观测噪声有界 `‖ε_i‖≤δ_i`；A2：深度/同步误差有界；A3：支撑域外误差满足 Lipschitz 条件，常数 `L_Ω`；A4：无未建模的变换跳变。则对所有 `t`，真实 `T∈C_t`，且
```
sup_{T'∈C_t} ‖g(T',x)−g(T̂,x)‖ ≤ ρ_he(x) .
```
证明：A1 保证 `T` 属于 `AX=XB` 残差集，HEC 的测地球是其外逼近，故 `T∈C_t`。对 `x∈Ω_cal`，中值定理与 `σ_max(Dg)` 给出任务空间误差界；对 `x∉Ω_cal`，A3 给出 `r(x)≤r_t+L_Ω dist(x,Ω_cal)`，再由三角不等式合并深度/同步误差。∎ 推论：**HEC 的可靠性不依赖估计精度，只依赖“外逼近不丢解”；精度只影响保守性 `ρ_he`，不影响 soundness。**

**引理 132（支撑域膨胀与授权单调收缩）** 对 `x∉Ω_cal`，
`r(x)≤r_t+L_Ω dist(x,Ω_cal)`；因此 `B_he` 关于支撑距离单调不减，`Acc_v16` 关于支撑距离单调不增。证明：由定义 628 与 A3 直接得到；`m_task` 固定时，预算越大授权越少。∎ 推论：**任务域本身是一个可调的安全旋钮**——缩小工作空间或降速可以买回正预算，而不是靠“更准的标定”硬撑。

**引理 133（可证激发的单调收缩）** 若每个注入的激发 `u` 满足 `u∈Acc_v16(C_t)` 且 `Δr(u)≥c_gain·cost(u)`，则 `C_{t+1}⊆C_t` 且 `r_{t+1}≤r_t`；若不存在这样的 `u`，则 `C_{t+1}=C_t`。证明：对 `t` 归纳。`C_{t+1}` 只由 `C_t` 与认证观测的交集产生，故包含关系成立；净预算非负保证半径不增；无可用激发时不做更新。∎ 推论：**不存在“先做点危险动作来标定”的合法路径**；自标定只能花它自己赚回的预算。

**引理 134（不可补偿聚合的不可能性）** 设 `F(I_safe,I_perf)` 连续、对 `I_perf` 严格递增、对 `I_safe` 有有限敏感度（如加权和）。则对任意安全阈值 `θ_s`，存在状态 `s,s'`，使 `Φ_safe(s)` 不成立、`Φ_safe(s')` 成立，却 `F(s)≤F(s')`。故不存在由此类 `F` 定义的可靠绿灯集；安全必须用 `min`/合取/字典序，性能只能在安全绿灯内优化。证明：由连续性，取足够大的性能增益把安全赤字抵消；等价地，加权和的水平集必与安全/不安全边界相交。∎ 推论：**仪表盘式的加权总分对安全结构性不可靠**；它只能用于安全集内的排序。

**引理 135（指标—证书对偶的可靠性与间隙）** 若 CIS 对每个安全维可靠（`Green_j⊆Φ_j`），且 IAG 未触发，则 `I_t` 全绿 ⇒ `Acc_t` 有效；保守间隙满足 `0≤Γ_t≤U_gap`。证明：可靠性逐维复合得到 `Green(I_t)⊆Φ(C_t)`；IAG 未触发保证当前状态仍在指标有效支撑内；`Γ_t` 的定义与 IAG 的一侧上界给出上界。∎ 推论：**指标是证书的压缩**，代价是保守间隙 `Γ`，而不是 soundness；`Γ` 越大，指标越“白保守”，活动性越差。

**引理 136（联合预算可加与包含）** 在定义 645/640 下，
`Acc_v16⊆Acc_v15`，`Exec_v16⊆Exec_v15`；且标定、共形、模型三类误差只能相加，不能相消。证明：`Acc_v16` 是 `Acc_v15` 与额外非负预算约束的交集；`Exec_v16` 又对 `Acc_v16` 取子集；fail-closed 定义保证任一项缺失只会收紧。∎ 推论：**v16 永远不能放宽 v15**；它只能把“标定不可证”的区域从授权里剔除。

**引理 137（支撑覆盖—保守性权衡）** 设任务分布 `D_task`，则
```
|Acc_v16|/|Acc_v15| ≤ ρ_HE + P_{x∼D_task}(m_task(x) ≥ B_total(x) | x∉Ω_cal) .
```
证明：按 `x∈Ω_cal` 与 `x∉Ω_cal` 划分授权集；支撑内最多全部保留，支撑外只有预算仍为正的部分保留。∎ 推论：**扩大 `Ω_cal` 或缩小任务域都能提高授权保留率**；反之，走出支撑域必然以假拒绝/降速为代价。

| 指标对偶（E675） | `Green⇒` 证书，`Γ≤U_gap`，0 次假绿 | 增大校准集、收紧阈值、扩大 `U_gap` |
| Goodhart 审计（E676） | 检出 ≥95%，0 次未检出放行 | 增加审计维度、对抗训练、缩短审计周期 |
| 漂移塌缩（E677） | 漂移后 0 次越界，完成率 ≥v15−8% | 提前漂移检测、扩大回退集、缩短重标定 |
| 联合预算（E678） | 0 次重复计数/负补偿 | 统一加法预算、fail-closed、联合压力测试 |
| 平台迁移（E679） | 仅需重标定/支撑域，0 次上层重测 | 增加平台专项标定、减少上层假设 |

## 7. 已知风险与失效模式

1. **噪声界 `δ_i`/膨胀常数 `L_Ω` 低估**：若真实标定误差超出声明上界，`C_t` 不再覆盖 `T`，后续所有授权都建立在不健全的包络上。缓解：硬件在环扰动注入、EVT 尾部分位、在线残差监控、超界即膨胀/塌缩。

2. **支撑域外推在接触/遮挡/大深度处失效**：`L_Ω` 在这些区域可能急剧增大，线性膨胀不够。缓解：分区 Lipschitz 常数、深度相关的 `σ_max(Dg)`、支撑外直接降速/拒绝、主动标定扩展支撑。

3. **指标可靠性只在支撑内被验证**：`Green⊆Φ` 的校准集若集中在支撑内，分布漂移后指标仍绿而证书已失效。缓解：IAG 的支撑检查、OOD 检测、指标阈值随支撑覆盖率收缩、支撑外禁用指标放行。

4. **Goodhart/对抗优化**：任务策略可能学会“刷绿”某些指标而不改善证书。缓解：序反射审计、不可补偿聚合、随机化审计样本、指标轮换、把审计结果纳入证书。

5. **可证激发反而消耗安全预算**：在安全边界附近，激发运动的 `cost(u)` 可能高于其信息收益，导致净预算为负。缓解：净预算非负硬约束、候选集预筛、无激发时缩小任务域、把激发排入低风险时段。

6. **与 v15 的误差叠加/双重计数**：v15 的 `U_d`、`ρ_cov`、`τ` 与 v16 的 `B_he` 可能同向低估或重复扣除。缓解：统一加法预算（引理 136）、保守合取、禁止用 v16 抵消 v15 余量、联合压力测试 E678。

7. **时间同步/深度误差未建模**：`ε_sync`、`ε_depth` 在高速运动/透明/反光物体上可能远大于声明值。缓解：时间戳对齐、同步误差在线估计、深度失效检测、把这些误差显式纳入 `ρ_he`。

8. **多相机/多工具链的联合标定不一致**：多个 `T_CE` 之间的相对标定误差可能相互放大。缓解：联合 `AX=XB`、闭环一致性检查、单一主标定 + 从标定约束、漂移时整体塌缩。

9. **指标层级过深导致审计延迟/不可解释**：层数越多，单向约束链越长，故障定位越慢。缓解：限制层数 ≤4、每层只保留少数充分指标、审计异步化、关键路径只查 L1。

10. **自标定诱导任务分布偏移**：为了激发可观测性而选择的任务可能把系统带到训练分布外。缓解：激发候选必须同时满足任务安全与分布约束、限制激发频率、把分布偏移计入 IAG。

## 8. 本轮最大风险

**一句话**：HEC 的噪声界/膨胀常数与 CIS 的支撑假设可能在同一场分布漂移中同时失效；此时包络自洽、指标全绿、对偶交换图也“成立”，系统却在支撑域外执行了一个**按证书、按指标、按对偶都自洽、却绝对错误的安全决定**。
