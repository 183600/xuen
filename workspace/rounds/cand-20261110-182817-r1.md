# 第 44 轮（新循环第 4 轮） · Bimanual-Cert × RealTime-Cert：把「双臂协调」与「实时控制」纳入可验证证书闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形边际覆盖被欺骗 + 多用户契约空集」，但它仍压着两个未言明的单点假设：**(H1) 执行体被默认为单一运动链或可分动作空间**——几何证书、CBF、RL 都默认「逐臂安全 ⟹ 整体安全」，证书在 Q_L × Q_R 上做笛卡尔乘积；**(H2) 认证被默认为软实时/anytime**——证书晚一点算出来也能用，v20 的租约只约束「数据多新鲜」，不约束「计算是否在截止期前完成」。本轮灵感词「双臂协调」「实时控制」精确命中这两个假设：**双臂协调**迫使我们把证书从乘积空间搬到**闭链约束流形**上，用「协调契约（相对位姿 + 内力）」堵住逐臂证书的边际抵消；**实时控制**迫使我们把证书变成**硬实时任务**，用「数据新鲜 + 计算按时 + 预认证兜底」三合一实现时序 sound。二者耦合处——协调越难、联合证书 WCET 越大，而控制周期裕度越小——是本轮真正的新问题：「协调-实时悖论」。

## 0. 直觉与动机

**灵感 1（双臂协调 → 安全不是两只手的笛卡尔积，而是流形上的一份契约）**：想象两个人抬一张托盘。甲觉得自己离地 1.00 m 很稳，乙也觉得自己 1.02 m 很稳，但托盘因此倾斜 2 cm，杯子滑落——每只手臂都在「安全域」内，整体却不安全。这就是**边际抵消（margin cancellation）**：逐臂证书的乘积 (S_L × S_R) ∩ M 既不保证非空（协调不可行），也不保证不变（闭链反力把两臂耦合）。直觉上的修正不是把证书做得更保守，而是把「相对位姿 δ_rel」「物体位姿包络 P_o」「内力/负载分配 ρ」提升为一等证书变量，形成**协调契约 K**。收缩到契约上做验证是免费的；而把两臂当作独立个体再取交集是**不 sound** 的。

**灵感 2（实时控制 → 「晚到的正确」等于「错误」）**：1 kHz 力矩环每 1 ms 必须把命令写进执行器。若联合证书要 3 ms 才算出，这个证书再 sound 也没有意义——它错过了使用时刻。实时系统的正确性是**截止期前的正确性**，而不是最终正确性。v20 的租约 (m, τ, λ) 只回答「测量数据是否过期」，不回答「计算是否按时完成」。因此需要第二条时间轴：证书任务 (C, J, d, π) 的**时序 sound 性** = 释放后 WCET + 抖动不超过执行器释放时刻，同时数据新鲜度覆盖整个命令执行区间。

**灵感 3（耦合 → 协调-实时悖论）**：联合证书最贵的地方（快速运动、接近奇异、重载、双臂闭链）恰恰是控制周期裕度最小、最不能等的地方。于是出现悖论：**最需要精确联合证书的时刻，最没有时间算它。** 直接串行化会牺牲实时性，直接降级会牺牲安全性。本轮的核心构造是**证书升级阶梯 + 预认证应急组合 + 证书预算预留**：先用 O(1) 契约检查拿到底线，再在时间允许时逐级加深耦合深度 d，任何一级超时都落到离线预认证、且包络覆盖当前状态的兜底控制器上，绝不让「算不出来」变成「放出未认证命令」。

**耦合升级**：BCC（双臂协调证书引擎）在约束流形 M 上编译协调契约与联合不变集；RCS（实时证书调度器）把每条证书变成带 WCET/截止期的任务，用 RTA 与预算预留保证时序 sound；CRV（协调-实时验证器）用 HIL 按真实控制周期注入截止期 miss、抖动、抓取模式切换与「逐臂安全但联合不安全」的对抗样本。四层架构由 v8 的「仿真-检索-边缘飞轮 + 人格契约 + 并发证书」升级为 v9 的「仿真-检索-边缘飞轮 + 人格契约 + 并发证书 + 协调流形层 + 实时证书层」。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（双臂耦合构型流形与协调证书）**：双臂构型 q=(q_L,q_R)∈Q=Q_L×Q_R，共享物体位姿 o∈SE(3)。刚性闭链抓取的完整约束为 Φ(q,o)=0，定义**约束流形 M={(q,o):Φ(q,o)=0}**（含两臂协同运动，而非乘积空间）。安全集 S⊆M 编码无碰撞、关节/力矩限、物体朝向容差、滑移裕度。**协调证书** I_c⊆M 称为 sound，当且仅当 I_c 在闭链耦合动力学（含内力控制）下前向不变且 I_c⊆S。**命题（乘积反例）**：存在 S_L⊆Q_L、S_R⊆Q_R 均非空且各自不变，但 (S_L×S_R)∩M=∅ 或不是 M 上的不变集。故「逐臂证书 ⟹ 整体证书」不成立，除非追加定义 45 的契约条件。

**定义 45（协调契约与内力非抵消引理）**：协调契约 K=(P_o, δ_rel, W_int, ρ)：物体位姿包络 P_o、相对位姿容差 δ_rel、允许内力集 W_int、负载分配策略 ρ。对给定外部 wrench w_ext，**内力可行性**成立当且仅当 ∃w_int∈W_int 使 ρ 分配给两臂的力矩 (τ_L,τ_R) 同时满足各自力矩上限且 τ_L+τ_R=w_ext+w_int（内力不改变合外力，但会移动单臂工作点）。**联合边际** m_c=min(m_L, m_R, m_rel, m_int)，其中 m_rel 为相对位姿到 δ_rel 边界的裕度，m_int 为内力可行性到力矩边界的裕度。**非抵消引理**：若 (i) 两臂各自控制器保证相对位姿误差 ≤δ_rel；(ii) 物体位姿始终 ∈P_o；(iii) 沿计划的每个 w_ext 内力可行；则闭链执行始终留在 S 内，且 m_c≥θ ⟹ 联合安全。**推论（协调间隙）**：m_c 不能被 min(m_L,m_R) 上界，二者之差即「逐臂证书看不见的协调风险」；无契约时该间隙可任意大。

**定义 46（证书实时任务化与时序 sound 性）**：证书任务 T_c=(r, C, J, d, π)，r 释放时刻、C 最坏执行时间、J 抖动上界、d 必须完成时刻（=执行器释放时刻 a），π 优先级。**时序 sound**：存在数据测量时刻 τ 与命令执行区间 [a, a+T_ctl]，使 r+C+J≤a 且 m−λ(a+T_ctl−τ)≥θ，即「数据新鲜度」（v8 定义 41）与「计算及时性」必须同时成立。**定理（时序 sound 合并守卫）**：若所有安全关键证书任务满足 RTA 响应时间 ≤d，且每条命令要么由时序 sound 的证书背书、要么由定义 47 的预认证兜底背书，则任意执行器释放点都不会使用未认证或过期的边际。

**定义 47（预认证应急证书组合）**：兜底组合 F={(f_j, V_j, Cert_j^off)}，f_j 为离线预认证的保守控制器/安全停机，V_j⊆M 为其有效包络，Cert_j^off 为其离线不变性证书。**接管规则**：在截止期 miss 或证书不可用时，选 max_j perf(f_j) s.t. 当前状态 ∈V_j；若无覆盖，则执行最后一级安全停机 f_stop（其包络为全状态，证书最保守）。**覆盖条件**：∪_j V_j 必须覆盖协调证书 I_c 在下一控制周期内的可达集。**命题**：若覆盖条件成立且每个 Cert_j^off sound，则任何 miss 路径都不破坏 S（代价是性能单调下降，而非安全性）。

**定义 48（证书升级阶梯与协调-实时预算）**：耦合深度 d∈{0,1,2}：d=0 逐臂证书 + O(1) 契约一致性检查；d=1 追加相对位姿/内力可行性的成对验证；d=2 全联合流形证书（HJ/CBF-QP + 负载分配）。控制周期预算 B_cert(d)=T_ctl−C_exec−C_monitor−B_fallback，其中 B_fallback 为不可挪用的兜底 reserve（类比 v8 的 B_safe）。**在线选择**：d*(t)=max{d: WCET(d)≤B_cert(d)}；若集合为空，退 d=0 并预挂兜底。**协调-实时悖论（命题）**：在高动态/近奇异/重载工况，WCET(2) 单调上升而 T_ctl 与 B_cert 单调下降，故可行 d 集在这些工况最容易塌缩为空；因此 d=0 契约检查与预认证兜底不是可选项，而是安全底线。

**定义 49（双臂模式自动机与切换安全）**：模式 μ∈{IDLE, INDEPENDENT, COORDINATED, CLOSED_CHAIN, HANDOVER}。转移 μ→μ′ 允许当且仅当 (i) 目标模式入口证书在切换窗口内成立；(ii) 切换动作本身在某一证书任务截止期内原子完成（不被更高优先级任务撕裂）；(iii) 内力与相对位姿在切换期间连续（无阶跃）。**定理（切换安全）**：若每个模式的 I_c^μ sound 且所有允许转移满足 (i)–(iii)，则任意模式序列的分段执行保持在 S 内。这是 IP-51 CAR 在双臂闭链上的推广。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 BIMANUAL-COORDINATION-CERT-ENGINE（双臂协调证书引擎 BCC）
1. **流形证书编译**：从抓取几何与物体模型构造 Φ、M 与 S；在 M 上编译协调不变集 I_c（HJ 可达性或流形 CBF-QP），而非在 Q_L×Q_R 上取乘积。
2. **协调契约**：编译 K=(P_o, δ_rel, W_int, ρ) 为两臂共享守卫；ρ 由最小范数力矩 QP 在线求解。
3. **非抵消守卫**：联合边际 m_c=min(m_L,m_R,m_rel,m_int)，任何一项未定义即拒绝进入闭链模式。
4. **模式自动机**：独立/协同/闭链/交接的入口证书与原子切换。
5. **协调不可行协商**：当 (S_L×S_R)∩M=∅ 或内力不可行时，输出「换抓取/换相对位姿/换负载分配」的最小让步集，而非静默放开或停机。

### 2.2 IP-61 REAL-TIME-CERT-SCHEDULER（实时证书调度器 RCS）
1. **证书任务模型**：每条证书编译为 (C,J,d,π)，WCET 用最坏工况标定而非平均。
2. **时序 sound 守卫**：release+WCET+J≤a 且新鲜度覆盖 [a,a+T_ctl]，双时间轴缺一不可。
3. **预算预留与升级阶梯**：B_cert 预留 B_fallback；按定义 48 在线选 d*。
4. **预认证兜底组合**：离线生成安全停机/回撤/保持的包络与证书，miss 时按性能最优接管。
5. **与 IP-58 混合关键级融合**：HI 模式只保留 d=0 契约检查 + 兜底；安全监控器固定最高关键级与不可挪用预算。
6. **时间基准**：单调时钟 + 控制总线同步（如 EtherCAT/TSN 相位），把抖动计入 J 而非事后补救。

### 2.3 IP-62 COORDINATION-REALTIME-VALIDATOR（协调-实时验证器 CRV）
1. **HIL 实时验证**：按真实控制周期（1 kHz/250 Hz）而非仿真加速跑证书闭环。
2. **截止期与抖动注入**：WCET 角点、优先级反转、时钟漂移、总线抖动，检验时序 sound 与兜底接管。
3. **抓取模式切换 fuzz**：独立↔闭链↔交接，注入滑移/碰撞/单臂失效。
4. **边际抵消对抗搜索**：主动构造「逐臂安全但联合不安全」样本（力矩和不足、相对位姿漂移、内力饱和）。
5. **联合压力测试**：协调难度 × 实时负载二维网格，绘制安全-可用性-时延曲面。

## 5. 本轮最大风险

## 2. 关键算法（伪代码）

### IP-60 BCC：流形证书、协调契约与非抵消守卫
```
def compile_bimanual_certificate(grasp, object_model, S_spec):
    Phi, M = build_closed_chain_constraint(grasp, object_model)  # 定义 44
    S = compile_safe_set(M, S_spec)
    I_c = manifold_reachability(M, S)        # HJ 可达性 或 流形 CBF-QP
    return Certificate(I_c, M, S)

def coordination_contract(grasp, tau_max, w_ext, rho=None):
    P_o, d_rel = derive_pose_envelope(grasp)
    W_int = feasible_internal_wrench(grasp, tau_max)
    rho = rho or solve_load_sharing(w_ext, tau_max)   # min ||tau|| QP
    return Contract(P_o, d_rel, W_int, rho)

def internal_force_feasible(w_ext, K, tau_max):
    # ∃ w_int ∈ W_int: τ_L+τ_R = w_ext+w_int 且两臂均在限内
    return exists(K.W_int, lambda w: loads_ok(split(w_ext + w, K.rho), tau_max))

def joint_margin(cert, x, K):
    m_rel = margin_to_bound(x.pose_rel, K.d_rel)
    m_int = margin_to_infeasible(x.w_ext, K, x.tau_max)
    if m_rel is None or m_int is None:
        return None                          # 未定义即拒绝闭链
    return min(cert.m_L, cert.m_R, m_rel, m_int)   # 非抵消联合边际

def non_cancellation_admit(cert, x, K):
    m_c = joint_margin(cert, x, K)
    return m_c is not None and m_c >= cert.theta
```

### IP-61 RCS：证书任务调度、预算、升级阶梯与兜底
```
def response_time(t, higher):
    R = t.C
    while True:
        new = t.C + sum(ceil(R / h.T) * h.C for h in higher)
        if new == R: return R
        R = new

def schedule_cert_tasks(tasks):
    order = sorted(tasks, key=lambda t: -t.priority)
    # 固定优先级 RTA；安全监控最高关键级且不可裁
    return all(response_time(t, order[:i]) <= t.d for i, t in enumerate(order))

def certificate_budget(T_ctl, C_exec, C_monitor, B_fallback):
    return T_ctl - C_exec - C_monitor - B_fallback   # 定义 48，reserve 不可挪用

def choose_depth(state, K, B):
    feasible = [d for d in (0, 1, 2) if wcet(d, state, K) <= B]
    return max(feasible) if feasible else 0

def temporally_sound(lease, t_release, T_ctl, now):
    return (lease.release + lease.C + lease.J <= t_release and
            lease.m - lease.lam * (t_release + T_ctl - lease.tau) >= lease.theta)

def realtime_guard(state, K, certs, F, T_ctl):
    B = certificate_budget(T_ctl, C_exec, C_monitor, B_fallback)
    d = choose_depth(state, K, B)
    c = escalate(d, state, K, certs)   # d=0 契约 / d=1 成对 / d=2 全联合
    if c is None or not temporally_sound(c, t_release(), T_ctl, monotonic_now()):
        return select_fallback(F, state)     # 定义 47：性能最优且已覆盖
    return c

def select_fallback(F, state):
    cand = [(perf(f), f) for f, V, cert in F if state in V and cert.valid]
    if not cand:
        return F.stop                        # 全状态包络的安全停机
    return max(cand, key=lambda p: p[0])[1]
```

def coupled_guard(x, cert, lease, persona, K, t, T_ctl):
    m_c      = joint_margin(cert, x, K)
    m_lookup = cert_lookup_L0(x).m_lo
