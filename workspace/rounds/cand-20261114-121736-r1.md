# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互不确定性二分」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「桌面操作」×「技能学习」）

> R69 让系统学会「问」：把 epistemic 不确定性交给流匹配多模态策略 + 看/问/触的主动交互去消解。但它有两条隐含前提——**技能库是固定的**，且**每一轮歧义都能在当轮、毫秒级、靠一次交互解决**。桌面操作把这两条前提同时打破：
> - **桌面操作是长时程、接触密集、可组合、且大量不可逆的**：抓取→移动→对准→插入→倾倒→擦拭→复位，误差沿链复合；倾倒、掉落、切割、删除一旦发生就退不回来；
> - **真正的歧义往往不在「此刻看哪个模态」，而在「这个技能到底会不会、在哪些状态下会、做完之后世界变成什么样」**——这是**程序性/因果性**不确定性，看一眼、问一句都问不出来，只能**练**，或者请人**演示**。
>
> 于是本轮把 R69 的「交互消歧」升级为「**跨时间尺度的不确定性消解阶梯**」：感知歧义→看一眼（ms），语义歧义→问一句（s），程序歧义→练一次（min），示范歧义→请人演示（min–h）。四者共用同一套 VoI 语言排序，但成本、风险与**可观测性**截然不同。技能学习的产物也不再是一条轨迹，而是**带合同的技能**（precondition / policy / effect / competence region / risk / reversibility）——**不仅要学会「怎么做」，还要学会「在哪里能信、做坏了能不能退」**。
>
> 核心命题：**技能 = 可认证的宏动作合同；技能学习 = 对合同的长时程 epistemic 消解；技能复用 = 合同链式组合 + 漂移监控 + 可逆性提交门。** 命名 **CRAFT-RAS**（Certified Reusable Action Fragments for Tabletop/desktop operation with Reversibility-aware, growth-safe skill learning）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我学会的这件事，在这个新桌面上还作数吗**」——学习不是把策略悄悄改掉，而是把「可信的边界」和策略一起学出来。

## 0. 直觉与动机

**灵感 1（桌面操作 = 合同的舞台，而不是一条长轨迹）**
直觉：人做桌面任务时并不是把「抓杯子→移动→放下」当成一条 10 秒的连续轨迹在背，而是调用一堆**可复用的动作片段**：捏、夹、旋、撬、倒、擦。每个片段都有明确的前置条件（有没有空位、夹爪朝向、物体是否被固定）、明确的后果（物体位移、容器液面、盖子角度）和明确的失败方式（滑脱、碰倒、洒出、卡死）。真正让桌面操作难的，不是单个动作的动力学，而是**片段之间的契约是否接得上**，以及**接不上时能不能退**。所以本轮把「技能」定义为一份**合同**，而不只是一个策略网络——这直接决定了系统能否在组合与迁移时说出「这个我能保证、那个我不能」。

**灵感 2（技能学习 = 学习「边界」，而不只是学习「行为」）**
直觉：模仿学习教会的是「怎么做」，但从不告诉你「在哪能做、做了多大概率成、做坏了怎么收」。一个在演示分布内成功的抓取策略，换一个更滑的杯子就可能失败；而系统若不知道自己的**能力域（competence region）**，就会在域外自信地复用——这正是长时程系统最危险的失败模式。因此本轮的核心主张是：**技能学习的产物必须包含能力域与风险上界**，并且这个上界要**可校准、可证伪、可撤销**。我们借用选择性分类的 conformal 风险控制，把「这个技能在这个状态可不可信」变成一个带有限样本保证的**选择性风险**，而不是一句主观置信度。

**灵感 3（不确定性消解有一条阶梯，R69 只爬了前两级）**
直觉：面对不确定，人的手段是分层的——看不清就凑近看（感知），不明白就问（语义），不会做就试做一次（程序），连试都不知道怎么试就请人示范（示范）。这四级的**信息论性质不同**：看与问是**观测性**信息，练与示范是**干预性/示范性**信息。若不确定性是因果性的（「这个力会不会让它滑」），被动观测的 Fisher 信息可能为零，再多看、再会问也学不到；只有 `do(力=…)` 才能识别。于是「该看/该问/该练/该求示范」不是经验规则，而是**由潜变量的可观测性 κ 决定的排序问题**。R69 的「看/问」恰好是 κ≈0 的特例；桌面技能学习是 κ→1 的必然升级。

**灵感 4（学习与实时安全天然冲突 → 用「可恢复探索」和「双缓冲换装」拆开）**
直觉：R69 有一条硬不变式——实时回路不写学习参数。技能学习偏偏要改策略、加片段。硬把两者塞进同一个回路，安全证书必然当场失效。正确的做法是**双时间尺度**：快回路只做「认证执行 + 漂移监控」，慢回路在**沙箱/受护真机**里练习与固化；新技能只有在**可恢复探索集**内练习、通过生长安全准入、并在静默提交点双缓冲换装后，才允许进入快回路。这样「学习」永远不直接改正在跑的策略，安全侧只增不减。

**灵感 5（桌面操作不可逆 → 需要提交点与后悔账）**
直觉：桌面任务里最贵的不是慢，而是**做错且退不回**。倒出去的水、掉下桌的杯子、按错的删除键，代价是 ∞ 而不是一格时间。R68/R69 的「不确定就收紧」对可逆动作是优雅的（慢一点、再看一眼），对不可逆动作却不够——你不能「慢一点地倒」。所以本轮引入**可逆性等级**与**提交点**：在跨过不可逆边界之前，必须用一次显式审计（能问就问、能练就先在可恢复区练），并把「信心不足时的期望后悔」与「问/等的成本」直接比较。这把风险自适应从连续的 λ 缩放，扩展成**离散的提交决策**。

**灵感 6（迁移不是微调权重，而是重新验证合同）**
直觉：「桌面操作」天然是**多桌面**的：换一张桌子、换一批杯子、换一种抽屉，布局与摩擦都变。把技能迁移理解成「再微调一下网络」既慢又不可证；更合理的理解是**合同再验证**：对象中心特征大致不变，先做几次廉价、可恢复的校准探针，重新估计能力域的漂移；覆盖够就复用，不够就重练或请示范。这把 R69 的 OOD 风险从「一个全局检测分数」变成「每个技能各自的可证边界」。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（CRAFT-RAS 总览）** CRAFT-RAS = (SKC, SCA, LHV, CPR, RVA, REA, GSA, SPW, DRT, SKV, RAS-WM†)。三不变式：
(i) **快回路零学习写操作**（继承 R68 定义 276-i / R69 定义 293-i）：任何参数、技能库、校准状态的持久化写入都不得发生在实时控制路径上；
(ii) **合同门控**：技能 k 只可在 `s ∈ Ĉ_k`、且 `J_SKILL(k)` 有效、且 DRT 无漂移告警时执行；否则逐级退化为 R69 原语层；
(iii) **可逆优先 + 提交审计**：跨过 rev=2 提交点前，必须满足证据纪律与后悔门（定义 314/326）；可逆动作优先于不可逆动作，除非不可逆动作的期望收益严格占优且已通过提交门。

**定义 311（桌面对象中心状态）** 状态 `s = (O, g, c)`：`O = {o_i}` 为对象集合，每个 `o_i = (pose_i, shape_i, material_i, container_i, free_i)`；`g` 为夹爪/工具状态；`c` 为上下文（任务目标、可用空间、时间窗）。谓词语言 `𝓟` 由对象姿态、距离、支撑、包含、遮挡、液面等原子谓词及其布尔组合构成。技能合同与能力域都在 `𝓟` 上表达，从而具备**可解释、可检查、可迁移**。

**定义 312（技能合同）** 技能 `k = (φ_k, π_k, ψ_k, C_k, δ_k, ρ_k, rev_k, R_k, v_k)`：
- `φ_k ⊆ 𝒮`：前置谓词（initiation set）；
- `π_k`：闭环策略（复用 R69 的流匹配策略 FMP，冻结执行，可选残差微调）；
- `ψ_k`：后置效果分布（postcondition，可为带容差的谓词分布）；
- `C_k ⊆ 𝒮`：能力域（competence region）；
- `δ_k ∈ (0,1)`：能力域内失败概率上界；`ρ_k`：能力域内风险（伤害/损坏/越界）上界；
- `rev_k ∈ {0,1,2}`：可逆性等级，`R_k` 为对应恢复策略；
- `v_k`：合同版本哈希（绑定策略权重、校准状态、库版本）。
相对 options 框架：`φ_k` 是 initiation set、`ψ_k` 是 termination set、`π_k` 是 intra-option policy——但这里多出了 `C_k, δ_k, ρ_k, rev_k` 四项**可证边界**，它们才是安全复用所必需、而经典 options 不提供的。

**定义 313（能力域与选择性风险校准）** 设失败损失 `ℓ(s)=1`（技能在 s 执行失败）。选择性风险 `R_sel(Ĉ) = E[ℓ(s)·1{s∈Ĉ}] / P(s∈Ĉ)`。用 split-conformal 风险控制（校准集与测试状态可交换）选阈值 τ，使 `R̂_sel(Ĉ_τ) ≤ α`，则有限样本下 `P(R_sel(Ĉ_τ) ≤ α) ≥ 1−α_cal`。`δ_k := α`，`C_k := Ĉ_τ`。系：缩小 `C_k` 单调降低 `R_sel`、但降低覆盖率；**可交换性一旦破裂（换桌面），界失效，必须重校准**（这正是 DRT 的职责）。

**定义 314（可逆性等级、提交点与后悔门）** `rev=0` 完全可逆（恢复代价 `c_u≈0`，如空载移动）；`rev=1` 有代价可逆（需重抓/耗时 `c_u ≤ c_u,max`）；`rev=2` 不可逆（倒、切、丢、删，`c_u=∞`）。**提交点**为进入 `rev=2` 执行前的最后一个状态。定义提交后悔 `Regret_c = (1−p_s)·ℓ_irr`，其中 `p_s` 为校准后的成功下界、`ℓ_irr` 为不可逆损失。**提交门**：仅当 `Regret_c ≤ c_ask + c_wait`，或已完成一次消解且 `p_s ≥ τ_commit` 时提交；否则先问/先练/先退。

**定义 315（可恢复探索集）** 安全集 `S_safe`，恢复算子 `Rec_k`。`E_R = {s : ∃ 恢复策略 R 使风险 ≤ ε_rec 且在 T_rec 内回到 S_safe}`。**练习只允许发生在 `E_R` 内**；真机练习还要求实时监控 + 恢复动作常驻（guarded trial）。`E_R=∅` 时禁止练习，只能请示范或提问。

**定义 316（跨时间尺度 VoI 阶梯 LHV）** 消解选项 `O = {glance, ask, practice, demo}`。潜变量 θ 可为感知性、语义性、程序性、示范性。定义程序性 `κ(θ) = I_int(θ) / (I_int(θ) + I_obs(θ))`（`I_int` 为干预 Fisher 信息，`I_obs` 为被动观测 Fisher 信息）。选 `o* = argmax_{o∈O} [EIG(o;θ) − λ_c·c(o) − λ_r·risk(o)]`，s.t. 安全、可恢复性、预算。**层级排序性质**：最优层级 `r*(θ)` 关于 `κ(θ)` 单调不减（引理 21）。R69 的看/问是 `κ≈0` 的特例。

**定义 317（合同获取 SCA）** 输入演示集 `D_demo` 与练习集 `D_prac`：
- `φ_k, ψ_k`：由对象中心谓词归纳（演示前后状态差分 + 变点检测）；
- `π_k`：以 R69 FMP 拟合，演示不足时用练习补足；
- `Ĉ_k, δ_k`：按定义 313 做 conformal 选择性风险控制；
- `rev_k`：由效果谓词分析 + 恢复搜索自动分级；
- `ρ_k`：由练习中风险事件的分位数上界 + 保守修正给出。
输出合同 `k` 及合同置信证书；**未通过校准的合同不得入库**。

**定义 318（合同组合与证书链 CPR）** 链 `k_1 → … → k_L` 可采纳当且仅当：
(a) 效果-前置匹配：`P(φ_{i+1}(s') | s'∼ψ_i) ≥ 1−ε_m`；
(b) **时程感知收紧**：为维持整链失败率 ≤ δ_budget，要求每个 `δ_i ≤ δ_budget/L`（union bound），必要时收缩各自能力域；
(c) 可逆性预算：整链的不可逆暴露不超过单回合预算 `B_rev`；
(d) 证书链：`J_comp = J_SKILL(k_1) ∧ … ∧ J_SKILL(k_L) ∧ J_match`。
组合在形式上就是「效果满足前置」的偏序匹配，可用动态规划在合同图上求解。

**定义 319（生长安全准入 GSA）** 新技能 `k_new` 入部署库需同时满足：
(i) 合同通过定义 313 校准且覆盖非退化；
(ii) 在重叠域上与既有最优技能**风险占优**（或影子评估非劣，统计置信 `1−β`）；
(iii) 通过 `ℰ_skill` 对抗测试（演示投毒、练习作弊、合同漂移、组合错误）；
(iv) 影子部署 N 回合无非劣证据；
(v) 在静默提交点**双缓冲**换装（继承 R68 定理 15 换装不变式）。
任何一项不满足 → 保持 `probation`，只能在沙箱/影子使用。**准入必须单调：认证最坏风险不增。**

**定义 320（技能实践工作区 SPW）** 沙箱仿真 + 受护真机；只接受 `E_R` 内的探索请求；对桌面布局/摩擦/材质做域随机化；产出 `(s, k, outcome, risk_event)` 供 SCA 使用。SPW 与快回路物理隔离，**不向实时策略写任何参数**。

**定义 321（技能版本、证书绑定与撤销 SKV）** 每个部署技能绑定 `(contract_hash, policy_hash, calibration_hash, library_version, admission_epoch, status)`。`status ∈ {active, probation, revoked}`。撤销/漂移告警 → 立即回退到版本化前一库或原语层；回退过程受 R68 换装不变式约束，保证控制连续。证书 `J_SKILL = (J_FLUID, contract_hash, coverage, selective_risk, competence_hash, rev_class, drift_state, admission_epoch)`。

**定义 322（合同漂移监控 DRT）** 在线廉价检查三件事：
(a) **域内性**：`s` 是否在 `Ĉ_k`（几何/分类器，O(1)）；
(b) **效果残差**：`r_eff = d(s', ψ_k)`（执行后与后置分布的距离）；
(c) **行为似然**：复用 R69 定义 301 的 FMA 通道，`a_score = −log p_θ(ξ_obs|o)`。
漂移分 `D = max(1{s∉Ĉ_k}, r_eff/τ_eff, (a_score−a_ref)/τ_a)`；用 CUSUM/序贯检验累积。`D > τ_D` → 抢占：降级原语、触发再校准、必要时撤销技能。注意 `(b)/(c)` 正是 R69「标定不可吸收的第二意见」在技能层的复用。

**定义 323（参与式审计 VQAuditor-S）** 审计对象从 R69 的交互决策扩展到**学习决策**：演示来源与质量、练习是否诱导作弊、合同校准是否偷看测试集、准入是否越过影子评估、提交点是否越权、漂移告警是否被压制。结论回灌，作为 GSA 阈值与 SPW 采样先验。

**定义 324（技能干扰集 ℰ_SKILL 与 AIC-SKILL）** `ℰ_SKILL = ℰ_FLUID × ℰ_demo × ℰ_practice × ℰ_contract × ℰ_compose`：
- `ℰ_demo`：投毒/虚假/ spuriously correlated 演示；
- `ℰ_practice`：仿真利用（reward hacking）、自博弈退化、探索越界；
- `ℰ_contract`：合同漂移、校准偷看、能力域虚胖；
- `ℰ_compose`：效果-前置错配、证书链断裂、时程误差复合。
并入对抗训练与红队测试。

**定义 325（证书 J_COMP / J_SKILL 有效性）** `Valid(J_SKILL) ⇔ Valid(J_FLUID) ∧ coverage ≥ c_min ∧ R_sel ≤ α ∧ GSA 通过 ∧ 无 active drift alarm ∧ status=active`。`Valid(J_comp) ⇔ 全链 J_SKILL 有效 ∧ 匹配概率达标 ∧ 可逆预算未越界`。

**定义 326（两级退避：技能 → 原语）** 若 `s ∈ Ĉ_k` 且 `Valid(J_SKILL)` 且无漂移告警 → 用技能 k（获得**复用红利**）；否则**逐级退化**：先用同效果的低 `rev` 技能，再退到 R69 的 FLUID 原语层，最后退到 R68 纯保守。安全侧永不弱于 R69，效率侧只在可证域内获利。

**定义 327（跨桌面迁移与再校准）** 新桌面 `D'` 上，用少量可恢复**校准探针**（`rev=0/1`，`s∈E_R`）估计合同覆盖与效果残差的漂移；若覆盖率 `≥ c_min` 则复用，否则在 SPW 中重练或在 `κ` 高时请求示范。迁移被定义为**合同再验证**而非权重微调；任何无法重新验证的合同一律视为无效。

```python
    rev  = classify_reversibility(psi, recover_search=True)
    return SkillContract(phi, pi, psi, C, d, risk_upper(practice), rev,
                         find_recovery(psi), hash_of(...))

# IP-266 LHV：跨时间尺度 VoI 阶梯（看 < 问 < 练 < 求示范）
def choose_resolution(theta, o_t, budget):
    best = None
    for o in [glance, ask, practice, demo]:
        if not admissible(o, o_t, budget):      continue
        if not recoverable(o, o_t):             continue   # 定义 315
        eig = interventional_eig(o, theta) if o is practice else \
              observational_eig(o, theta)
        s   = eig - cost(o) - risk_penalty(o, o_t)
        if best is None or s > best.score: best = (o, s)
    return best if best and best.score > 0 else None

# IP-267/268 CPR+RVA：证书链组合 + 提交门
def compose_and_gate(contracts, goal, o_t, budget):
    plan = contract_graph_dp(contracts, goal)            # 效果→前置匹配
    if plan is None: return None
    L = len(plan)
    if any(c.delta > DELTA_BUDGET / L for c in plan):    # 时程感知收紧
        plan = tighten_domains(plan, DELTA_BUDGET)
    if not budget.allow_irreversible(plan): return None
    for i, c in enumerate(plan):
        if c.rev == 2:                                   # 提交点
            p_s = success_lower_bound(c, o_t)
            if (1 - p_s) * LOSS_IRR > ASK_COST + WAIT_COST:
                return ask_or_practice(c)                # 先消解再提交
    return plan

# IP-272 DRT：运行时合同漂移守卫（复用 R69 FMA 通道）
def drift_guard(skill, s, s_next, A_exec, policy):
    in_dom = skill.C.contains(s)
    r_eff  = effect_residual(s_next, skill.psi)
    a_sc   = -policy.log_likelihood(A_exec, s)           # R69 定义 301
    D = max(0.0 if in_dom else 1.0, r_eff / TAU_EFF,
            (a_sc - A_REF) / TAU_A)
    return cusum_update(D) > TAU_D                      # True → 抢占降级

# IP-275 CRAFT-RAS 主闭环（快回路只执行，学习全在 SPW 后台）
def CRAFT_round(M, obs, episode):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)  # 继承 R68
    # 1) 合同匹配：前置成立且证书有效
    cands = [k for k in M.skl.match(o)
             if M.drt.ok(k, o) and Valid(M.skv.cert(k))]
    if not cands:
        return M.FLUID_RAS_round(obs)                    # 退化 R69 原语层
    # 2) 若合同覆盖/效果仍有程序性歧义，走 LHV 阶梯
    theta = contract_uncertainty(cands, o)
    rung  = M.lhv.choose_resolution(theta, o, M.budget)
    if rung is practice:
        M.spw.request(cands, o); return M.FLUID_RAS_round(obs)  # 后台练，快回路不动
    if rung is ask or rung is demo:
        return M.mint.interact(rung, cands, o)           # 复用 R69 交互
    # 3) 证书链组合 + 提交门 + 可逆预算
    plan = M.cpr.compose_and_gate(cands, M.goal, o, M.rev_budget)
    if plan is None:
        return M.FLUID_RAS_round(obs)
    # 4) 执行并监控；任何漂移 → 逐级退避（定义 326）
    for k in plan:
        A = M.fmp.sample(o) if k.rev < 2 else M.rva.commit(k, o)
        obs_next = M.execute(A)
        if M.drt.drift_guard(k, o, obs_next, A, M.fmp):
            M.skv.revoke(k); return M.FLUID_RAS_round(obs_next)
        o = obs_next
    M.vqa_s.submit_async(plan, theta, rung)              # 参与式审计
    return plan
```

## 3. 推导

**引理 19（选择性合同的可证风险）** 在校准集与测试状态可交换、失败损失有界的条件下，按定义 313 选出的 `Ĉ_k` 满足 `P(R_sel(Ĉ_k) ≤ δ_k) ≥ 1−α_cal`，且 `R_sel` 关于能力域收缩单调不增。系 1：`C_k` 越小越安全、复用率越低——这是可显式定价的「安全-复用」权衡；系 2：换桌面使可交换性破裂，原界**不再成立**，必须由 DRT 触发再校准（定义 327），否则证书是「过期的真理」。

**引理 20（可恢复探索的累积安全）** 若全部练习发生在 `E_R` 内且每次恢复风险 `≤ ε_rec`，则 N 次练习的累积越界风险 `≤ N·ε_rec`（可用自适应停止进一步收紧）；`E_R=∅` 时练习不可行。系：**探索的安全预算可以直接写成恢复策略质量的函数**——恢复越强，越敢练；这也解释了为什么「会退」比「会做」更基础。

**引理 21（干预层级占优与阶梯单调性）** 设潜变量 θ 的程序性为 `κ(θ)=I_int/(I_int+I_obs)`。若 `I_obs(θ)=0`（纯混杂，被动观测无法识别因果效应），则任何看/问的 `EIG=0`，而 `do(a)` 的 `EIG>0`，练习/示范严格占优。更一般地，最优消解层级 `r*(θ)` 关于 `κ(θ)` 单调不减。系：R69 的看/问是 `κ≈0` 的边界；桌面「这个力会不会滑」这类问题必须升级到干预层。

**定理 18（CRAFT 严格包含 FLUID）** 固定技能库、禁用获取与练习、且所有可达状态落在已认证 `C_k` 内时，CRAFT 与 R69 逐指令相同；在 `C_k` 外 CRAFT 退回 R69 原语层，故对任意状态的期望风险 `≤ R69`。安全侧不做让步，效率侧仅在可证域内获得复用红利。

**定理 19（生长安全 / 证书不回归）** 若 GSA 只接纳在重叠域上风险占优（或影子评估统计非劣）的技能，换装在静默提交点双缓冲完成，撤销即时回退原语，则技能库**任意演化序列**的认证最坏风险单调不增，且控制轨迹连续（R68 定理 15 换装不变式保持）。系：**学习可以是单调改进的**，前提是把「准入」而不是「训练」当作安全边界。

**定理 20（长时程组合与不可逆后悔界）** 在合同组合可采纳（每步效果-前置匹配概率 `≥ 1−ε_m`）、漂移监控漏报 `≤ η` 下，长度 L 的技能链失败概率 `≤ Σ_i δ_i + L·ε_m + η·L`；若每技能风险 `≤ ρ_i`，累计期望风险 `≤ Σ_i ρ_i + (Lε_m+ηL)ℓ_max`。提交门保证跨 rev=2 边界的期望后悔 `(1−p_s)ℓ_irr ≤ c_ask+c_wait`。系：**长时程的敌人是指数复合的匹配误差与漂移漏报**，所以必须「时程感知收紧」+「漂移监控」，而不能只优化单技能成功率。

## 6. 本轮最大风险

**一句话**：CRAFT-RAS 的全部安全论证都押在「**能力域是校准的、且在新桌面上仍然可交换**」这一前提上——一旦能力域虚胖（练习覆盖不足、校准偷看、或桌面分布漂移使 conformal 的可交换性破裂），系统就会把一个**只在小样本上侥幸成功**的技能盖上「已认证」的章，并在长时程里反复复用、跨过不可逆提交点；**练错比不练更危险**，因为错误会被证书固化、被组合放大、被不可逆动作兑现。

## 3. 关键算法伪代码

```python
# IP-264/265 SKC+SCA：技能合同与获取（学「边界」而非只学「行为」）
class SkillContract:
    phi, pi, psi   = None, None, None      # 前置 / 流匹配策略 / 效果分布
    C, delta, rho  = None, None, None      # 能力域 / 失败上界 / 风险上界
    rev, recover   = 0, None               # 可逆性 / 恢复策略
    ver            = None

def acquire_contract(demos, practice):
    phi  = induce_precondition(demos)
    psi  = induce_effect(demos)
    pi   = fit_flow_policy(demos)                         # 复用 R69 FMP
    C, d = conformal_competence(practice, alpha=DELTA)    # 定义 313
    rev  = classify_reversibility(psi, recover_search=True)
    return SkillContract(phi, pi, psi, C, d, risk_upper(practice), rev,
                         find_recovery(psi), hash_of(...))

# IP-266 LHV：跨时间尺度 VoI（看 < 问 < 练 < 求示范）
def choose_resolution(theta, o_t, budget):
    best = None
    for o in [glance, ask, practice, demo]:
        if not admissible(o, o_t, budget): continue
        if not recoverable(o, o_t):        continue       # 定义 315
        eig = interventional_eig(o, theta) if o is practice else \
              observational_eig(o, theta)
        score = eig - cost(o) - risk_penalty(o, o_t)
        if best is None or score > best.score: best = (o, score)
    return best if best and best.score > 0 else None

# IP-267/268 CPR+RVA：证书链组合 + 不可逆提交门
def compose_and_gate(contracts, goal, o_t, budget):
    plan = contract_graph_dp(contracts, goal)             # ψ_i -> φ_{i+1}
    if plan is None: return None
    L = len(plan)
    if any(c.delta > DELTA_BUDGET / L for c in plan):     # 时程感知收紧
        plan = tighten_domains(plan, DELTA_BUDGET)
    if not budget.allow_irreversible(plan): return None
    for c in plan:
        if c.rev == 2:
            p_s = success_lower_bound(c, o_t)
            if (1 - p_s) * LOSS_IRR > ASK_COST + WAIT_COST:
                return ask_or_practice(c)                 # 先消解再提交
    return plan

# IP-272 DRT：合同漂移运行时守卫（复用 R69 FMA）
def drift_guard(skill, s, s_next, A_exec, policy):
    in_dom = skill.C.contains(s)
    r_eff  = effect_residual(s_next, skill.psi)
    a_sc   = -policy.log_likelihood(A_exec, s)            # R69 定义 301
    D = max(0.0 if in_dom else 1.0, r_eff / TAU_EFF, (a_sc - A_REF) / TAU_A)
    return cusum_update(D) > TAU_D                        # True → 抢占降级

# IP-276 CRAFT-RAS 主闭环（快回路只执行；学习全在 SPW 后台）
def CRAFT_round(M, obs, episode):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)   # 继承 R68
    cands = [k for k in M.skl.match(o)
             if M.drt.ok(k, o) and Valid(M.skv.cert(k))]         # 合同门控
    if not cands:
        return M.FLUID_RAS_round(obs)                            # 退化 R69
    theta = contract_uncertainty(cands, o)
    rung  = M.lhv.choose_resolution(theta, o, M.budget)          # 阶梯
    if rung is practice:
        M.spw.request(cands, o); return M.FLUID_RAS_round(obs)   # 后台练
    if rung in (ask, demo):
        return M.mint.interact(rung, cands, o)                   # 复用 R69
    plan = M.cpr.compose_and_gate(cands, M.goal, o, M.rev_budget)
    if plan is None:
        return M.FLUID_RAS_round(obs)
    for k in plan:
        A = M.fmp.sample(o) if k.rev < 2 else M.rva.commit(k, o)
        obs_next = M.execute(A)
        if M.drt.drift_guard(k, o, obs_next, A, M.fmp):
            M.skv.revoke(k); return M.FLUID_RAS_round(obs_next)  # 逐级退避
        o = obs_next
    M.vqa_s.submit_async(plan, theta, rung)
    return plan
```

## 4. 推导

**引理 19（选择性合同的可证风险）** 校准集与测试状态可交换、失败损失有界时，定义 313 的 `Ĉ_k` 满足 `P(R_sel(Ĉ_k)≤δ_k)≥1−α_cal`，且 `R_sel` 关于域收缩单调不增。系：`C_k` 大小是可显式定价的「安全-复用」权衡；换桌面破坏可交换性 ⇒ 界失效，必须再校准。

**引理 20（可恢复探索的累积安全）** 全部练习在 `E_R` 内且每次恢复风险 `≤ε_rec` ⇒ N 次练习累积越界风险 `≤N·ε_rec`（可自适应停止收紧）；`E_R=∅` ⇒ 练习不可行。系：恢复策略越强越敢练——「会退」比「会做」更基础。

**引理 21（干预层级占优与阶梯单调性）** 若 `I_obs(θ)=0`（纯混杂），看/问的 `EIG=0`，`do(a)` 的 `EIG>0`，练习/示范严格占优；一般地最优层级 `r*(θ)` 关于 `κ(θ)` 单调不减。系：R69 看/问是 `κ≈0` 边界；桌面因果性歧义必须升级到干预层。

**定理 18（CRAFT 严格包含 FLUID）** 固定技能库、禁用获取/练习、`s∈C_k` 时两者逐指令相同；`C_k` 外 CRAFT 退回 R69 原语，故任意状态期望风险 `≤R69`。

**定理 19（生长安全 / 证书不回归）** GSA 只接纳重叠域风险占优（或影子非劣）技能、静默点双缓冲换装、撤销即时回退 ⇒ 技能库任意演化序列的认证最坏风险单调不增，控制轨迹连续（R68 定理 15 保持）。

**定理 20（长时程组合与后悔界）** 匹配概率 `≥1−ε_m`、漂移漏报 `≤η` 时，长度 L 的链失败概率 `≤Σδ_i+Lε_m+ηL`；累计期望风险 `≤Σρ_i+(Lε_m+ηL)ℓ_max`；提交门保证 `(1−p_s)ℓ_irr≤c_ask+c_wait`。系：长时程的敌人是指数复合的匹配误差与漂移漏报，必须时程收紧 + 漂移监控。

## 7. 预期结果与判据（假设，待 E301–E315 验证）

1. 合同化后，域外复用率应从「无约束技能库」的 ~20–30% 降到 `<5%`，且下降主要来自 DRT 与 conformal 能力域；
2. LHV 阶梯相对「只看/只问」的单层 R69，在需要程序性信息的桌面任务上成功率提升最显著（+15%），而在纯感知任务上应自动退化到 R69（行为差≈0，E313）；
3. 提交门会把不可逆动作前的询问/练习比例推高，但总体完成时间因避免灾难回滚而下降；
4. GSA 的单调性检验（E306）是整轮最关键的安全判据：任何「学会后最坏风险上升」都直接否决该设计。

## 8. 本轮最大风险

**一句话**：CRAFT-RAS 的全部安全论证都押在「**能力域已校准、且在新桌面上仍可交换**」这一前提上——一旦能力域虚胖（练习覆盖不足、校准偷看、桌面分布漂移使 conformal 可交换性破裂），系统就会把只在小样本上侥幸成功的技能盖上「已认证」的章，并在长时程里反复复用、跨过不可逆提交点；**练错比不练更危险**，因为错误会被证书固化、被组合放大、被不可逆动作兑现。

**次级风险与缓解**：练习越界（定义 315 `E_R` + 引理 20）；演示投毒/仿真利用（GSA 对抗测试 + ℰ_SKILL + VQAuditor-S）；组合误差指数复合（时程收紧 + 定理 20）；技能膨胀/实时预算（后台学习 + 双缓冲 + P99）；迁移失配（校准探针 + 合同再验证，禁止未验证复用）。
