# 第 56 轮（承接第 55 轮 v31 GroundEdge-GenSim+++；灵感循环第 2 轮；本轮灵感：「力觉传感」×「阻抗控制」）

> 第 55 轮把语义标签升级为接触约束，用语义-接触生存核与语义护盾回答"接触在语义上是否可信"。本轮从外感知（exteroception）转向**本体接触感知（proprioceptive contact）**，核心矛盾：**H24**：语义与几何只能"预测"接触，而真实接触状态（是否接触、法向载荷、切向是否将滑）只有力/触觉能"证实"；预测与实测的残差，正是第 55 轮证书缺失的最后一环。**H25**：位置控制把接触误差转成力误差——表面定位偏 `Δ`，刚度 `K_d` 就把 `Δ` 放大为 `K_d·Δ` 的冲击力；因此"接触不确定性"必须由**阻抗（刚度/阻尼）**这一物理量连续承载，而不是靠离散的接触集膨胀。

## 0. 直觉与动机

**灵感 1（力觉传感 → 接触的"证实"而非"推断"）**
直觉：分割与几何说"这块表面应该能踩"，力/触觉说"此刻到底踩没踩、踩了多重、会不会滑"。前者是 prior，后者是 evidence。接触集应从"谓词"变成"带证据的随机变量"：`C_verified = {(p,c) | r_t<θ_r ∧ λ_meas∈FC(μ) ∧ f_min≤λ_n≤f_max ∧ s≥s_min}`。未验证的接触必须降级，而非默认成立。更进一步，力觉还能**提升**语义上不敢踩的接触（视觉模糊但力反馈证实为实心支撑），从而反向缓解第 55 轮"生存核过保守导致冻结"的风险。

**灵感 2（动量观测器 → 无加速度计的接触力估计）**
直觉：直接差分加速度噪声大。用广义动量观测器
`r(t)=K_O[p(t)-∫_0^t(τ+Cᵀq̇-g+r)dσ-p(0)]`，`p=M(q)q̇`
平滑估计外力，`||r||>θ_r` 判接触；`r` 与阻抗模型预测 `λ_pred` 之差 `r_t=||r-λ_pred||_{W_λ}` 就是接触模型失配的直接度量。这让"接触验证"成为可在线计算的量，而不是离线标注。

**灵感 3（阻抗控制 → 把接触不确定性编码为刚度）**
直觉：刚性位置控制在接触处等价于"用一个很大的弹簧顶住未知表面"，定位偏差 `Δ` 被放大成 `K_d·Δ` 的接触力。阻抗控制 `M_d ẍ̃ + D_d ẋ̃ + K_d x̃ = F_ext - F_ff` 让机器人表现为可设计的质量-弹簧-阻尼，**刚度就是接触不确定性的对偶变量**：越不确定越软。核心设计不等式 `K_d ≤ (F_max-F_ff)/Δ_max`——力预算与定位误差共同决定刚度上限。

**灵感 4（自适应阻抗 + 无源性能量罐 → 在线调增益而不失稳）**
直觉：力残差大说明接触模型（环境刚度/摩擦）错了，应在线改 `K_d,D_d` 与摩擦估计。但"边接触边调增益"极易破坏无源性，产生颤振/极限环。必须以**能量罐**约束自适应：只有罐中储存能量 `T>0` 才允许增大刚度/注入能量，否则只许耗散。这把自适应从"调到好为止"变成"调的时候保证不炸"。

**灵感 5（分层阻抗 → 支撑刚、操作柔的全身调度）**
直觉：全身不同接触需要不同阻抗——腿/支撑要高刚度抗扰，臂/手要低刚度顺应。阻抗不是标量而是**逐接触的刚度椭球** `Z_c=(M_d,D_d,K_d)_c`。云端给阻抗调度（任务相位上哪些接触该刚/该柔），边端按力反馈实时调；这把第 55 轮的云边语义接口升级为**云边阻抗-力接口**。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（接触力观测与验证残差）**
广义动量 `p=M(q)q̇`，广义动量观测器残差
`r(t)=K_O[p(t)-∫_0^t(τ+Cᵀq̇-g+r)dσ-p(0)]`。
接触验证量 `r_t=||r(t)-λ_pred(t)||_{W_λ}`。接触验证谓词
`ver(p,c)=1 ⇔ r_t<θ_r ∧ λ_meas∈FC(μ) ∧ f_min≤λ_n≤f_max ∧ s≥s_min`，
其中滑移裕度 `s=1-||λ_t||/(μλ_n)`。

**定义 128（接触阻抗模型与力放大律）**
逐接触阻抗 `Z_c=(M_d,D_d,K_d)`，任务空间误差 `x̃=x-x_d`：
`M_d ẍ̃ + D_d ẋ̃ + K_d x̃ = F_ext - F_ff`。
稳态下定位偏差 `Δ` 诱导的额外法向力满足
`||ΔF_n|| ≤ ||K_d||·||Δ|| + ||D_d||·||ẋ̃||`。
与环境刚度 `K_e` 串联时耦合刚度 `K_c=(K_d^{-1}+K_e^{-1})^{-1}`：`K_d≪K_e` 时力由阻抗主导（柔顺、抗定位误差）；`K_d≫K_e` 时力由环境主导（定位误差被放大）。

**定义 129（不确定性条件化阻抗调度）**
接触不确定性 `u(p)=w_s·H(Σ(p))+w_r·r_t+w_μ·σ_μ`（语义熵+力残差+摩擦估计方差）。调度
`K_d(p)=K_0·exp(-α u(p))`，`D_d(p)=2√(K_d M_d)·ζ(u)`，阻尼比 `ζ` 随 `u` 增大（更过阻尼）。
硬约束 `K_d(p)≤(F_max-F_ff-F_dyn)/Δ_max(p)`，`Δ_max` 由第 55 轮语义边界裕度 `m_s` 与几何不确定度给出。

**定义 130（阻抗塑形生存核）**
闭环阻抗动力学 `ẋ=f_Z(x,u_Z,λ)`。鲁棒可行集
`K_Z(Σ,δ)={x | ∀Δ,||Δ||≤δ, ∃u_Z,λ: f_Z=ẋ ∧ supp(λ)⊆C_verified ∧ x_{t+1}∈𝒳_safe}`。
软阻抗扩大鲁棒可行集但降低任务跟踪精度，定义折中曲线
`trade(δ)=vol(K_Z(Σ,δ))/vol(K_Z(Σ,0))` 与跟踪误差 `e_trk(δ)`。

**定义 131（力-阻抗稳定裕度）**
耦合系统（机器人阻抗 `Z_r` + 环境阻抗 `Z_e`）小增益 `γ=||G_r(jω)Z_e(jω)||_∞`，要求 `γ<1`。无源性裕度 `π_m` = 能量罐最小储备 / 单步最大能量注入。综合稳定裕度
`ρ_stab=1-max(γ, (s_min-s)/s_min, 1-π_m)`。

**定义 132（力-阻抗联合证书）**
`J_f=(C_verified, Z_sched, ρ_stab, s_margin, r_res, δ_f, π_m, evidence)`：
- `C_verified` 经力证实且带时戳的接触集；`Z_sched` 逐接触阻抗调度；
- `s_margin=min_t s(t)`；`r_res=max_t r_t`；`δ_f=||λ_meas-λ_pred||` 力扰动实测预算；
- `π_m` 无源性能量罐裕度；`evidence` 含力残差曲线、滑移事件、环境刚度辨识。
若 `C_verified≠∅`、`ρ_stab≥ρ_min`、`s_margin≥s_min`、`r_res<θ_r`、`δ_f<Θ_f`，则力-阻抗可部署。

## 2. 关键算法 伪代码

### IP-127 CFV（Contact Force Verification）

```python
def momentum_observer(q, dq, tau, M, C, g, KO, integ, p0):
    p = M(q) @ dq
    r = KO @ (p - integ - p0)          # external wrench estimate
    return r

def contact_verification(r, lam_pred, mu, s_min, theta_r, fmin, fmax):
    r_res = norm(r - lam_pred)
    lam_n, lam_t = r[2], norm(r[:2])
    s = 1.0 - lam_t / (mu * lam_n + 1e-9)
    ok = (r_res < theta_r) and (fmin <= lam_n <= fmax) and (s >= s_min)
    return ContactEvidence(ok, r_res, s, lam_n, lam_t)
```

### IP-128 ICS（Impedance Conditioning Schedule）

```python
def impedance_schedule(u, K0, alpha, M_d, Delta_max, F_budget, F_ff, F_dyn):
    K = K0 * exp(-alpha * clip(u, 0, 1))
    K = min(K, (F_budget - F_ff - F_dyn) / max(Delta_max, 1e-6))
    zeta = ZETA_LO + (ZETA_HI - ZETA_LO) * clip(u, 0, 1)
    D = 2.0 * sqrt(K * M_d) * zeta
    return Impedance(M_d, D, K)
```

### IP-129 PIK（Passivity-preserving Impedance Kernel，能量罐自适应）

```python
def passive_adapt(Z, dZ, tank, x_tilde, dx_tilde, dt):
    # energy needed to raise virtual stiffness/inertia
    dE = 0.5 * dZ.K * dot(x_tilde, x_tilde) \
       + 0.5 * dZ.M * dot(dx_tilde, dx_tilde)
    if dE > 0 and tank.T <= dE:
        return Z, tank, 'stiffen_refused'   # only dissipation allowed
    tank.T = tank.T - dE
    if tank.T < T_MIN:
        return Z, tank, 'tank_empty'       # freeze adaptation, keep old Z
    return Z + dZ, tank, 'ok'
```

### IP-130 FIS（Force-Impedance Shield）

```python
def force_impedance_shield(u_nom, x, Kernel, C_verified, Z_sched, W):
    u = qp_solve(
        H=W, g=-W @ u_nom,
        constraints=[
            viability_constraint(x, u, Kernel.K_in),
            contact_verified_constraint(u, C_verified),
            friction_cone_constraint(u, mu),
            force_budget_constraint(u, F_max),
            impedance_bound_constraint(Z_sched, Delta_max, F_budget),
            joint_limit_constraint(u),
        ])
    if u is None or projection_gap(u, u_nom) > Delta_u:
        return safe_compliant_brake(x, Z_sched), 'shield_infeasible'
    return u, 'ok'
```

### IP-131 FIC（Force-Impedance Certificate）

```python
def force_impedance_certificate(traj, evidence, rho_stab, pi_m, budgets):
    C_ver = {c for c in contacts_used(traj) if evidence[c].ok}
    if not C_ver:
        return ('reject', 'no_verified_contact')
    s_margin = min(evidence[c].s for c in C_ver)
    r_res = max(evidence[c].r_res for c in C_ver)
    if r_res > budgets.theta_r:
        return ('reject', 'force_residual', r_res)
    if s_margin < budgets.s_min:
        return ('reject', 'slip_margin', s_margin)
    if rho_stab < budgets.rho_min:
        return ('reject', 'instability', rho_stab)
    if pi_m < budgets.pi_min:
        return ('reject', 'passivity', pi_m)
    return ('ok', ForceImpedanceCert(C_ver, Z_sched, rho_stab,
                                     s_margin, r_res, pi_m, evidence))
```

### IP-132 CEP（Cloud-Edge Impedance Protocol）

```python
def cloud_edge_impedance(task_phase, cloud_sched, edge):
    Z_c = cloud_sched(task_phase)              # per-contact impedance profile
    lam, r, s = edge.force_observe()
    Z_e, tank = edge.estimate_environment(lam)
    Z_adapt, tank, status = passive_adapt(Z_c, edge.dZ(r, s), tank, ...)
    if status != 'ok' or s < edge.s_min or r > edge.theta_r:
        return ('reprofile', evidence=(r, s, lam, status))
    return ('ok', Z_adapt, force_impedance_certificate(...))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CFV | O(1) 每次（观测器递推） | O(n) | 观测器增益稳定、偏差有界 |
| ICS | O(|C|) | O(|C|) | 力预算不等式守恒、Δ_max 上界 |
| PIK | O(1) 每次 + O(QP) | O(n) | 能量罐非负、仅耗散注入 |
| FIS | O(QP) 每次 | O(|A_WB|) | QP 可行或柔顺制动回退 |
| FIC | O(|轨迹|·|C|) | O(|C|) | 接触非空、预算闭合 |
| CEP | O(|C|+τ) | O(|C|) | 回传有界、重调度收敛 |

**正确性定理（Force-Impedance Contact Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** 力/触觉经标定、偏差 `||b||≤ε_f`，动量观测器稳定；**(A34)** 阻抗内环无源且环境无源，经能量罐约束后 `γ<1`；**(A35)** 摩擦系数估计取下界 `μ̂≤μ`（保守）；**(A36)** 调度满足力放大不等式 `K_d≤(F_max-F_ff-F_dyn)/Δ_max`，且护盾不可行时回退 `u_stop∈𝒳_safe`。
则部署后单步安全概率：
```
P_safe ≥ 1 - P(||b||>ε_f) - P(μ̂>μ) - P(γ≥1) - P(schedule infeasible) - P(shield fallback fails)
```
关键：**力觉证实接触、阻抗界定定位误差的力放大、能量罐保无源、护盾兜底**——四层任一层失守，都不允许把"力看起来正常"当作"接触一定安全"。

## 6. 本轮最大风险

**一句话**：力觉证实与阻抗调度把"预测的接触"变成"可证实的接触"、把"离散裕度"变成"连续柔顺"，但其 soundness **三重依赖力传感器的无偏标定、摩擦系数的保守下界、以及阻抗自适应严格保无源**；一旦力偏差被当作真实载荷、或 μ 被高估使滑移裕度虚高、或能量罐约束失效让刚度在线注入能量，系统会在"自认为已证实"的接触上以过大刚度顶向错误表面，产生不可逆的滑移与冲击——因此必须以 **零漂在线辨识 + μ 保守下界 + 能量罐无源护栏** 三重保险，宁可柔顺制动，绝不把力觉的"读数正常"当作接触的"已经安全"。

# 第 56 轮产物 · 创新点清单 v32：GroundEdge-Compliance（CFV×ICS×PIK×FIS×FIC×CEP）

> 承接第 55 轮产物 v31（GroundEdge-GenSim+++）。本轮在"语义-接触接地 + 全身生存核 + 语义护盾"之上，增加 **接触力证实、阻抗条件化、无源自适应、力-阻抗护盾、力-阻抗证书、云边阻抗协议** 六大算子，把接触可信度从"外感知推断"推进到"本体力觉证实"，并把接触不确定性由阻抗连续承载：
> - **CFV（Contact Force Verification）**：动量观测器估计外力，残差/摩擦锥/滑移裕度三判据证实接触；
> - **ICS（Impedance Conditioning Schedule）**：不确定性 `u(p)` 条件化逐接触阻抗 `Z_c`，遵守力放大不等式；
> - **PIK（Passivity-preserving Impedance Kernel）**：能量罐约束下的在线阻抗自适应，保无源；
> - **FIS（Force-Impedance Shield）**：在原语义护盾 QP 中加入接触证实与力预算/阻抗上界约束；
> - **FIC（Force-Impedance Certificate）**：联合证书 `J_f`，把力残差、滑移裕度、稳定裕度、无源裕度写入部署条件；
> - **CEP（Cloud-Edge Impedance Protocol）**：云端阻抗调度 ↔ 边端力反馈自适应与证据回传。
>
> IP 编号：IP-127~IP-132（共 6 个新增）；升级 IP-121/123/126 以纳入力-阻抗维度。

## 2. 核心推导

**（D1）力放大律与安全不等式**
环境刚度 `K_e`、阻抗刚度 `K_d` 串联，耦合刚度 `K_c=(K_d^{-1}+K_e^{-1})^{-1}`。定位偏差 `Δ=x_d-x_env` 下稳态接触力
`λ_n ≈ K_c·Δ`。取 `K_d≪K_e` 得 `λ_n≈K_d·Δ`（阻抗主导，柔顺）；`K_d≫K_e` 得 `λ_n≈K_e·Δ`（环境主导，误差被放大）。为保证力预算 `F_max`：
`K_d ≤ (F_max - F_ff - F_dyn)/Δ_max`。
这就是 ICS 的硬约束来源，也是"语义边界裕度 `m_s`"进入控制增益的通道（`Δ_max∝1/m_s`）。

**（D2）无源自适应与能量罐**
虚拟阻抗储存能量 `E=½x̃ᵀK_dx̃+½ẋ̃ᵀM_dẋ̃`。在线增大 `K_d/M_d` 注入 `dE=½dK\|x̃\|²+½dM\|ẋ̃\|²`。设能量罐 `T`，仅当 `dE≤T` 时允许 `dE>0` 的调整，并令 `T←T-dE`；耗散项自动回充 `T`。可证：只要 `T≥0`，机器人端口对无源环境保持无源，耦合 `γ<1`，从而排除接触颤振/极限环。

**（D3）阻抗-不确定性折中**
刚度越低，对 `Δ` 的力敏感度越低（`∂λ_n/∂Δ=K_c↓`），但位置跟踪误差 `e_trk≈F_ext/K_d↑`。ICS 在 Pareto 前沿上取点，由任务相位（支撑 vs 操作）选择，而非固定刚度。

**（D4）力觉对语义接地的双向作用**
`C_verified = C^+(Σ) ∩ {ver=1}` 会**否决**语义高置信但力反馈异常的接触（防第 55 轮边界过度自信）；同时力反馈可**提升**语义低置信的接触（`C_verified ⊇ C^+` 的可能），从而放松第 55 轮"生存核过保守导致冻结"的风险。因此力觉既是安全下界，也是保守度的调节器。

def contact_verification(r, lam_pred, mu, s_min, theta_r, fmin, fmax):
    r_res = norm(r - lam_pred)
    lam_n, lam_t = r[2], norm(r[:2])
    s = 1.0 - lam_t / (mu * lam_n + 1e-9)
    ok = (r_res < theta_r) and (fmin <= lam_n <= fmax) and (s >= s_min)
    return ContactEvidence(ok, r_res, s, lam_n, lam_t)

### IP-128 ICS

```python
def impedance_schedule(u, K0, alpha, M_d, Delta_max, F_budget, F_ff, F_dyn):
    K = K0 * exp(-alpha * clip(u, 0, 1))
    K = min(K, (F_budget - F_ff - F_dyn) / max(Delta_max, 1e-6))
    zeta = ZETA_LO + (ZETA_HI - ZETA_LO) * clip(u, 0, 1)
    D = 2.0 * sqrt(K * M_d) * zeta
    return Impedance(M_d, D, K)
```

### IP-129 PIK

```python
def passive_adapt(Z, dZ, tank, x_tilde, dx_tilde):
    dE = 0.5 * dZ.K * dot(x_tilde, x_tilde) \
       + 0.5 * dZ.M * dot(dx_tilde, dx_tilde)
    if dE > 0 and tank.T <= dE:
        return Z, tank, 'stiffen_refused'
    tank.T -= dE
    if tank.T < T_MIN:
        return Z, tank, 'tank_empty'
    return Z + dZ, tank, 'ok'
```

def force_impedance_certificate(traj, evidence, rho_stab, pi_m, budgets):
    C_ver = {c for c in contacts_used(traj) if evidence[c].ok}
    if not C_ver:
        return ('reject', 'no_verified_contact')

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CFV | O(1) 递推 | O(n) | 观测器增益稳定、力偏差有界 |
| ICS | O(\|C\|) | O(\|C\|) | 力放大不等式守恒 |
| PIK | O(1)+QP | O(n) | 能量罐非负、仅耗散 |
| FIS | O(QP) | O(\|A_WB\|) | QP 可行或柔顺制动回退 |
| FIC | O(\|轨迹\|·\|C\|) | O(\|C\|) | 接触非空、预算闭合 |
| CEP | O(\|C\|+τ) | O(\|C\|) | 回传有界、重调度收敛 |

**正确性定理（Force-Impedance Contact Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** 力/触觉标定、`||b||≤ε_f`，动量观测器稳定；**(A34)** 阻抗内环与环境均无源，能量罐约束后 `γ<1`；**(A35)** `μ̂≤μ`（保守下界）；**(A36)** `K_d≤(F_max-F_ff-F_dyn)/Δ_max` 且护盾回退 `u_stop∈𝒳_safe`。
则
```
P_safe ≥ 1 - P(||b||>ε_f) - P(μ̂>μ) - P(γ≥1) - P(schedule infeasible) - P(fallback fails)
```
关键：**力觉证实接触、阻抗界定力放大、能量罐保无源、护盾兜底**，四层并联，任一失守都不把"力读数正常"当成"接触安全"。

## 6. 本轮最大风险

**一句话**：力觉证实与阻抗条件化将接触从"预测"推进到"证实"、从"离散裕度"推进到"连续柔顺"，但其 soundness **三重依赖力传感器无偏标定、摩擦系数保守下界、以及阻抗自适应严格保无源**；一旦力偏差被当作真实载荷、μ 被高估使滑移裕度虚高、或能量罐失效让在线刚度注入能量，系统会在"自认为已证实"的接触上以过大刚度顶向错误表面，造成不可逆滑移与冲击——故必须以 **零漂在线辨识 + μ 保守下界 + 能量罐无源护栏** 三重保险，宁可柔顺制动，绝不把力觉的"读数正常"当作接触的"已经安全"。
