# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「示教学习」×「场景理解」）

> 第 54 轮把技能组合推到动作空间剖面 α_S、组合图 G_S 与云边联合证书 J。本轮引入示教学习与场景理解，核心矛盾：H22：示教的可迁移内容不是关节轨迹而是"场景相对任务框架"，直接模仿轨迹在场景变化与本体差异下失效（correspondence problem）；H23：场景理解的粒度决定示教可泛化的边界——过粗导致动作歧义、过细导致对示教场景过拟合，存在一个最小充分场景抽象 c*。

## 0. 直觉与动机

**灵感 1（示教是场景条件下的动作剖面）**
直觉：一条示教不是一条轨迹，而是三元组 `D=(G_s,τ,ι)`——场景图 `G_s`、动作轨迹 `τ`、意图 `ι`。于是第 54 轮的剖面必须条件化：`α_S(a|c)`，其中 c 为场景抽象。示教回答"在什么场景下做什么动作"，场景理解回答"当前是哪个 c"。**技能不是单一剖面，而是场景条件剖面的一族**；这使"示教→技能"变成"示教→条件化剖面估计"。

**灵感 2（可模仿的是任务框架，不是关节角）**
直觉：对应问题（correspondence problem）的正解不是轨迹重定向，而是抽取 **场景相对任务框架** `F=(o, rel, aff, T_anchor→gripper)`：物体、关系、可供性、相对锚点的夹爪位姿。人示范的是"从杯子侧上方接近把手并握持"，机器人只需在自身动作空间求解满足 F 的动作。**场景理解因此是跨本体迁移的媒介，而不是背景**；轨迹只是 F 的一个实现样本。

**灵感 3（最小充分场景抽象）**
直觉：并非所有场景细节都影响动作选择。存在一个 **最小充分场景抽象 `c*`**：它是完整场景关于示范动作分布的 **最小充分统计量**——保留对动作有因果影响的因子、丢弃只与示教场景偶然相关的因子（如桌布颜色）。过细则记住示教场景（过拟合），过粗则动作歧义（欠拟合）。c* 给出泛化的边界，也是"该迁移什么"的判据。

**灵感 4（示教覆盖的有限样本保证）**
直觉：示教天然稀疏，`α_S(·|c)` 的估计必须带不确定性。用 conformal prediction 在校准示教上得到剖面区间 `Ĉ_α`，以 `1-δ` 概率覆盖真实可行动作集。这把"示教够不够"从口头假设变成 **可检验的统计证书**，并可直接进入迁移判据；下界不达标就拒绝迁移，而不是赌泛化。

**灵感 5（场景误判的反向解释闭环）**
直觉：与第 54 轮云边闭环衔接。云端用示教学习场景条件技能库，边端用真实场景理解做 `c` 分类、帧匹配与剖面校验；若 `c` 误判或帧锚点漂移，边端 Explain 回传"场景因子根因"，云端触发示教重索引与抽象重估。形成 **示教-场景-动作** 的三向闭环，而非单向模仿。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（示教三元组）**
`D=(G_s, τ, ι)`，`G_s=(O,R)` 为场景图（物体 O、关系 R，附几何位姿与可供性标签），`τ={a_t}_{t=1..L}` 为示教动作序列，`ι` 为意图（任务谓词/目标）。示教集 `𝔇={D_i}`。

**定义 122（场景相对任务框架）**
`F(τ)=⟨(o_t, rel_t, aff_t, T_t)⟩_{t=1..L}`，`o_t` 为操作对象，`rel_t` 为相对关系（above/inside/behind…），`aff_t∈𝒜ff` 为可供性，`T_t∈SE(3)` 为相对锚点物体的夹爪位姿。称 F 为示教的 **可模仿内容**；`τ` 中未进入 F 的关节冗余视为可丢弃。令 `sim_F` 为两框架序列的加权相似度。

**定义 123（场景条件动作剖面）**
`α_S : A × ℂ → [0,1]`，`α_S(a|c)` 为在场景抽象 c 下动作 a 被技能 S 覆盖的程度。覆盖 `cover(S,A_T|c)=1 ⟺ ∀a∈A_T, α_S(a|c)≥θ_cov`。第 54 轮 `α_S(a)` 是 `∑_c α_S(a|c)P(c)` 的边缘化特例。

**定义 124（最小充分场景抽象）**
设 `π_d(a|c_full)` 为由示教诱导的动作分布。`c*` 为 `c_full` 关于 `π_d` 的最小充分统计量：
```
c* = argmin_{c: P(a|c)=P(a|c_full) ∀a} |c|
```
因果表述：c* 保留所有对动作有因果影响的场景因子，剔除仅与示教场景相关的偶然相关因子。工程上以 **反事实场景增广** 估计充分性缺口 `ε_suf = E_{c~aug}[D_KL(π_d(·|c) ‖ π_d(·|c_full))]`。

**定义 125（示教-机器人对应关系）**
对应证书 `corr(D,ℛ)=(sim_F, feas, δ_T, anchor_map)`：`sim_F=sim(F_d,F_r)`；`feas=1` 当且仅当存在机器人动作序列 `τ_r⊂A_ℛ` 满足全部 F 约束；`δ_T` 为帧锚点位姿误差上界；`anchor_map` 把示教场景锚点映射到部署场景锚点。直接轨迹重定向是忽略 F、仅匹配 τ 的退化特例。

**定义 126（示教覆盖证书，conformal）**
在示教校准集上构造 `Ĉ_α(c)=[α̂(c)-q_{1-δ}, α̂(c)+q_{1-δ}]`，在可交换性下 `P(α_true(·|c)∈Ĉ_α(c))≥1-δ`。部署要求 `α̂_low(c)≥θ_cov` 对 `A_T` 中每个动作成立。

**定义 127（场景-示教联合迁移证书）**
`J_D=(c*, F, corr, Ĉ_α, ε_suf, evidence)`。部署判据：
```
ε_suf ≤ Θ_s ∧ corr.sim_F ≥ θ_F ∧ corr.feas=1 ∧ α̂_low(c*) ≥ θ_cov ∧ corr.δ_T ≤ Θ_T
```
它与第 54 轮 `J=(ρ,A_cert,γ_ce,δ_a)` 组合为双证书 `(J_D, J)`：前者管"该不该模仿/模仿什么"，后者管"组合后能不能部署"。

## 2. 关键算法 伪代码

### IP-121 SFT（Scene-relative Frame Transform）

```python
def extract_frames(G_s, tau, intent):
    frames = []
    for t, a in enumerate(tau):
        o = intent.target_at(t)                       # 由意图/接触检测定位操作对象
        rel = relation(G_s, o, hand_at(t))
        aff = affordance_of(G_s, o)                   # 可供性来自场景理解
        T = pose(G_s, o).inverse() @ hand_pose(t)     # 相对锚点位姿
        frames.append(Frame(o, rel, aff, T))
    return frames

def frame_similarity(F_d, F_r, w):
    n = max(len(F_d), len(F_r))
    return sum(w[k] * sim(fd[k], fr[k])
               for k in ('o', 'rel', 'aff', 'T')
               for fd, fr in zip(F_d, F_r)) / max(n, 1)
```

### IP-122 MSA（Minimal Sufficient Abstraction）

```python
def minimal_sufficient_abstraction(demos, scene_factors, eps_suf):
    # 互信息排序后贪心加入，达到充分性即停；再反向剔除冗余偶然因子
    mi = {f: mutual_info(f, action_label(demos)) for f in scene_factors}
    order = sorted(scene_factors, key=lambda f: -mi[f])
    c = set()
    for f in order:
        c.add(f)
        if sufficiency_gap(demos, c) <= eps_suf:
            break
    for f in list(c):
        if sufficiency_gap(demos, c - {f}) <= eps_suf:
            c.remove(f)
    return frozenset(c)

def sufficiency_gap(demos, c, n_aug=200):
    # 反事实增广：c 不变、扰动其余因子，测动作分布漂移
    base = policy(demos, c)
    return max(kl_div(base, policy_aug(demos, c, i)) for i in range(n_aug))
```

### IP-123 CPAP（Conformal Scene-Conditioned Profile）

```python
def conformal_profile(demos, c_star, A_T, delta=0.05):
    calib = [residual(d, c_star) for d in demos]
    q = quantile(calib, 1 - delta, method='higher')
    lo = {a: clamp(alpha_hat(a, c_star) - q, 0, 1) for a in A_T}
    hi = {a: clamp(alpha_hat(a, c_star) + q, 0, 1) for a in A_T}
    return lo, hi, q

def cover_lower_bound(lo, A_T, theta_cov=0.8):
    return all(lo.get(a, 0.0) >= theta_cov for a in A_T)
```

### IP-124 CAT（Cross-embodiment Action Transfer）

```python
def transfer_action(F, robot, A_R, anchor_map):
    constraints = [ground(f, robot, anchor_map) for f in F]
    if not constraints_feasible(constraints, A_R):
        return ('infeasible', infeasibility_witness(constraints, A_R))
    # 求解满足 F 的动作序列，而不是复制示教关节轨迹 tau
    a_seq = solve_ik_under_constraints(constraints, A_R)
    return ('ok', a_seq, residual_bounds(a_seq, constraints))
```

### IP-125 SCC（Scene-Conditioned Composition）

```python
def scene_conditioned_compose(T, c_now, G_S, profiles, theta_c):
    if c_now.confidence < theta_c:                 # 场景理解自身不可靠
        return ('defer', 'scene_uncertain')
    compat = lambda i, j: jaccard(profiles[i][c_now.id], profiles[j][c_now.id])
    path = a_star(G_S, goal=T, compat_fn=compat)
    return ('ok', path, [joint_certificate(seq) for seq in path.expand()])
```

### IP-126 DTC（Demonstration Transfer Certificate）

```python
def demonstration_transfer_certify(demos, T, robot, A_R, budgets):
    c_star = minimal_sufficient_abstraction(demos, scene_factors, budgets.eps_suf)
    lo, hi, q = conformal_profile(demos, c_star, T.actions, budgets.delta)
    if not cover_lower_bound(lo, T.actions):
        return ('reject', 'insufficient_demo_coverage', lo)
    F = extract_frames(demos.scene, demos.tau, demos.intent)
    corr = match_frames(F, robot.scene, A_R)
    if corr.sim_F < budgets.theta_F or corr.delta_T > budgets.Theta_T:
        return ('reject', 'correspondence_gap', corr)
    status, payload = transfer_action(F, robot, A_R, corr.anchor_map)
    if status == 'infeasible':
        return ('reject', 'action_infeasible', payload)
    suf_gap = sufficiency_gap(demos, c_star)
    if suf_gap > budgets.Theta_s:
        return ('reject', 'abstraction_insufficient', suf_gap)
    return ('ok', J_D(c_star, F, corr, (lo, hi, q), suf_gap))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SFT | O(L·(|O|+|R|)) | O(L) | 对象定位与锚点稳定 |
| MSA | O(|Φ|²·n_aug·|𝔇|) | O(|Φ|) | 充分性缺口估计无偏、无混杂 |
| CPAP | O(|𝔇|·|A_T|) | O(|A_T|) | 可交换性、校准集独立 |
| CAT | O(|F|·|A_ℛ| + IK) | O(|F|) | 约束可满足、帧锚点几何一致 |
| SCC | O(|V| log|V| + |E|·|A|) | O(|V|+|E|) | c 置信门控、剖面条件化一致 |
| DTC | O(|𝔇|·|A| + MSA) | O(|𝔇|+|A|) | 五条件合取、预算闭合 |

**正确性定理（Scene-Conditioned Demonstration Transfer Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 部署场景与校准示教在 c* 上可交换（exchangeability）；**(A30)** 最小充分抽象满足 `ε_suf ≤ Θ_s`；**(A31)** 帧锚点几何误差 `δ_T ≤ Θ_T` 且 `sim_F ≥ θ_F`。则迁移成功下界：
```
P_success ≥ (1-δ) · (1-ε_suf) · 1[feas=1] · (1 - P(δ_T>Θ_T)) - P(c_now 误判)
```
要点：**覆盖由 conformal 给出有限样本保证**、**抽象充分性由反事实增广估计**、**对应关系由帧约束可判定**，三者均为可检验量，而非叙述性假设。

## 4. 实验设计 E162–E166

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 帧抽取与跨本体对应 | `sim_F`、迁移成功率 vs 轨迹重定向 | 迁移成功率 ≥ 85%，较重定向高 ≥ 20% |
| E163 最小充分抽象 Pareto | 抽象维度 vs 动作预测准确率 | 准确率损失 ≤ 2% 时维度降 ≥ 50% |
| E164 conformal 覆盖有效性 | 经验覆盖率 vs 1-δ | 覆盖偏差 ≤ 3% |
| E165 场景漂移鲁棒性 | OOD 场景迁移成功率、defer 触发率 | 成功率下降 ≤ 10% 且正确 defer |
| E166 云边场景闭环 | 场景误判经 Explain 回传后的恢复率 | 恢复率 ≥ 80% |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 部署场景破坏可交换性，conformal 失效 | 高 | 在线漂移检测 + 加权 conformal + 触发重校准 |
| 最小充分抽象漏掉关键因果因子 | 高 | 反事实增广 + 因果发现 + 红队场景注入 |
| 场景图/可供性识别错误污染帧 | 高 | 多模态一致性校验 + 锚点几何回投影 |
| 示教本身次优或意图歧义 | 中 | 多示教聚合 + 意图显式化 + 反例示教 |
| 跨本体约束不可满足 | 中 | 早停 infeasibility witness + 人工接管 |
| 抽象过粗导致动作歧义 | 中 | 充分性预算 Θ_s 收紧 + 分层 c* |

## 6. 本轮最大风险

**一句话**：示教学习与场景理解的结合把技能从"动作剖面"升级为"场景条件剖面"，但其 soundness **同时依赖 conformal 的可交换性在部署分布漂移下仍成立、最小充分抽象 c* 可由有限示教辨识、以及场景图/可供性识别不出错**；一旦可交换性被 OOD 场景破坏、或 c* 遗漏关键因果因子，系统就会在错误场景上下文中"自信地误用"示教，造成场景-动作错配的负迁移，故必须以 **分布漂移检测 + 反事实场景增广覆盖 + 帧锚点几何校验** 三重护栏，并把场景理解置信度直接写入迁移证书——宁可拒绝迁移，也不在不可辨识的场景上模仿。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-DemoScene（SFT×MSA×CPAP×CAT×SCC×DTC）

```python
    a_seq = solve_ik_under_constraints(constraints, A_R)
    return ('ok', a_seq, residual_bounds(a_seq, constraints))
```

```python
def demonstration_transfer_certify(demos, T, robot, A_R, budgets):
    c_star = minimal_sufficient_abstraction(demos, scene_factors, budgets.eps_suf)
```

**正确性定理（Scene-Conditioned Demonstration Transfer Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 部署场景与校准示教在 `c*` 上可交换；**(A30)** `ε_suf ≤ Θ_s`；**(A31)** `δ_T ≤ Θ_T` 且 `sim_F ≥ θ_F`。则：
```
P_success ≥ (1-δ)·(1-ε_suf)·1[feas=1]·(1-P(δ_T>Θ_T)) - P(c_now 误判)
```
关键：**覆盖有 conformal 有限样本保证**、**抽象充分性可估计**、**对应关系可判定**，三者均进入证书而非藏在假设里。

## 5. 本轮最大风险

**一句话**：示教学习与场景理解的结合把技能从"动作剖面"升级为"场景条件剖面"，但其 soundness **同时依赖 conformal 的可交换性在部署分布漂移下仍成立、最小充分抽象 c* 可由有限示教辨识、以及场景图/可供性识别不出错**；一旦可交换性被 OOD 场景破坏、或 c* 遗漏关键因果因子，系统就会在错误场景上下文中"自信地误用"示教，造成场景-动作错配的负迁移，故必须以 **分布漂移检测 + 反事实场景增广覆盖 + 帧锚点几何校验** 三重护栏，并把场景理解置信度直接写入迁移证书——宁可拒绝迁移，也不在不可辨识的场景上模仿。
