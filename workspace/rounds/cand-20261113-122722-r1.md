# 第 66 轮（承接第 65 轮「VISTA 视觉知情安全时序归因」IP-214~223；灵感循环第 3 轮；本轮灵感：「数据集构建」×「多机协作」）

> 第 65 轮用三阶段残差签名把"几何 vs 力 vs 模型"从不可辨识升级为可分离，其自述的最大风险同样一针见血：**FIR 的归因能力依赖两个隐藏假设——故障属于有限假设集、且视觉与几何的失效相互独立；真实故障常是未知类型的组合，透明/镜面/对抗 patch 会让视觉与几何共享同一个分布外失效源，此时 FIR 会把未知复合故障强行归入最近假设、只膨胀错误的球，系统反而因"已经归因"而更自信地继续执行（A88）。** 本轮不再往假设集里塞第 7 个假设，而是换一个根本提问：第 65 轮问"这一帧谁坏了"，COHORT 问"**我们凭以判断谁坏了的这份证据，本身够不够格、独不独立、覆没覆盖住我们即将下的结论**"。本轮核心命题是：
>
> **把「故障可归因」升级为「归因可认证」：用主动协作的数据集构建把 p(ρ|H) 从静态先验变成带覆盖证书的可信对象，用多机异构证据把「独立性」从假设变成可测量的量，并把故障作用域（本机 / 共享 / 共因）显式纳入归因与安全承诺。**

## 0. 直觉与动机

**灵感 1（数据集构建 → 数据集不是归因的前提，而是归因的产物与证书对象）**
直觉：第 65 轮把 p(ρ|H) 当成离线拟合好的固定先验。但引理 7 的可辨识性其实是**数据集的性质**，不是传感器的性质：如果数据集中从未同时激励过"H_force"和"H_geo"，两者的签名列就共线，J_fi 奇异——无论部署时采多少帧都分不开。反过来，如果数据集只覆盖了已知故障的邻域，未知复合故障一定落在支撑集之外，FIR 却仍会按最近假设给出一个**高置信的错误答案**。所以正确的问题不是"后验多大"，而是"**这份数据集是否有资格支撑这个后验**"。数据集构建因此从工程前置步骤升级为**安全证书的组成部分**：可辨识裕度 κ_fi(D)、覆盖半径 ε(D)、复合故障覆盖 c_comp(D) 都必须是可计算、可审计、写进证书的量。

**灵感 2（数据集构建 → 闭环数据飞轮，但必须抗自证）**
直觉：真实部署会不断产生新的残差，这本身就是数据。于是数据集应当是**闭环生长**的：部署 → 检出 ambiguous / 越界 → 定向、安全地激励新故障（牺牲件或经现实差校验的仿真）→ 增广账本 → 重拟合 → 重认证。但这里有个陷阱：系统天然只会去采集"自己已经能解释"的数据，覆盖永远长不大，形成**自证预言**。因此采集目标必须由"新奇度 + 假设互信息 + 覆盖增益"驱动，而不是由当前后验驱动——**用不确定性去选数据，而不是用数据去确认不确定性**。

**灵感 3（多机协作 → 独立性是"测出来"的，不是"因为多"就成立）**
直觉：面对共因失效，最直觉的补救是"多上几个机器人，总有独立的"。但这恰恰是最危险的错觉：同构机器人共享同一世界模型、同一训练集、同一标定流程、同一 OOD 物体、同一光照与时间同步——它们是**一个传感器穿着很多具身体**。若把 R 个强相关证据当独立证据相乘，后验会以指数速度虚假集中。正确做法是估计**有效独立证据数** n_eff（由跨机残差相关矩阵的特征值参与比给出），并让贝叶斯更新用 n_eff 而不是 R。n_eff≈1 时，全队一致等于一票，不是 R 票。**多机协作的价值不在于票数，而在于异构性带来的可测量独立性。**

**灵感 4（多机协作 → 作用域：本机坏了、全队共享的坏了、还是被同一个东西一起骗了）**
直觉：第 65 轮的共因风险在多机下升级为一个新的、更本质的区分：故障是**本机局部**（某台 F/T 偏置）、**共享**（地图漂移、世界模型 bug、数据集被污染，全队一起错）、还是**共因**（同一个透明/对抗物体同时骗过视觉与力）。共享故障最危险，因为它让"多数投票"整体失效。而这里有一条漂亮的硬结论：**要区分"共享故障"与"所有机器人恰好同向的局部故障"，必须存在一个不共享该分量的锚点**（异构模型/独立标定/外部计量）。没有锚点，二者在观测上等价，任何确定性的作用域判断都会错。于是"多机"真正买到的东西是**锚点**，而不是数量。

**灵感 5（三灵感合流 → COHORT：Collaborative Heterogeneous Observation & Re-attribution with Traceable datasets）**
闭环：带溯源账本记录每条证据（FDL）→ 数据集可辨识性证书（DIC，给出 κ_fi(D)、ε(D)、c_comp）→ 证据独立性证书（EIC，给出 n_eff 与证据独立图）→ 演员-观察者证人多机协议（WITNESS）→ 覆盖感知归因与越界拒答（DFC）→ 作用域归因（FST）→ 主动协作数据集构建（ACD，覆盖增益的可分次贪心）→ 联邦标定（CFC）→ 作用域定向球（RSC-C）→ 共享故障下的认证前缀（CSC-C）→ 数据集/舰队对抗认证（AIC-C）→ 证书 J_cohort。第 65 轮把"接触"拆成接触前/中/后；COHORT 把"证据"拆成**证据本身是否可信、证据之间是否独立、证据覆盖是否足够**——让归因从"我算出了一个后验"变成"我能证明这个后验值得相信"。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（COHORT 闭环）**：COHORT = (VISTA, FDL, DIC, EIC, FST, WITNESS, ACD, DFC, CFC, RSC-C, CSC-C, AIC-C, J_cohort)。定位：VISTA 的"归因可认证"升级。不变式：**账本写入、数据集证书、独立性/作用域估计、主动采集、证书构建只在语义流；实时流只做残差采集、安全前缀执行、早停与派发，零学习写操作、零账本写入。**
- **定义 234（故障归因数据账本 FDL）**：每条证据 z_i=(ρ_i, prov_i, label_i, ver_i)，溯源 prov_i=(robot_id, sensor_calib_ver, model_hash, dataset_ver, env_id, inject_id, t)。账本为只追加哈希链 h_i=H(h_{i-1},z_i)，根哈希 R_D。**任何一次归因必须引用 D 的一个子集并写入 J_cohort**，使"结论"与"依据"不可分离。
- **定义 235（数据集支撑与覆盖半径）**：故障参数空间 Θ=Θ_local×Θ_shared×Θ_comp。覆盖半径 ε(D)=sup_{θ∈Θ} min_{z_i∈D} d(θ,θ_i)（d 为故障参数或诱导签名流形上的度量）。δ-覆盖 ⇔ ε(D)≤ε_max。复合覆盖 c_comp(D)=含 ≥n_min 样本的复合故障单元（(h_a,h_b) 同时激活）比例。
- **定义 236（数据集可辨识性证书 DIC）**：故障设计矩阵 Θ_D∈ℝ^{n×d_H}（第 i 行为样本 i 的故障幅度）。J_fi(D)=Θ_DᵀΣ_ρ⁻¹Θ_D，κ_fi(D)=λ_min(J_fi(D))/λ_max(J_fi(D))。DIC 有效 ⇔ rank(Θ_D)=d_H ∧ κ_fi(D)≥κ_min ∧ ε(D)≤ε_max ∧ c_comp(D)≥c_min。**关键：可辨识性是 D 的性质，不是传感器套件的性质；D 不共激励的故障对，部署时永远分不开。**
- **定义 237（证据相关与有效独立数）**：各机证据 ρ_r（或残差 e_r）。健康标定集上回归掉预测公共信号后，相关矩阵 C∈ℝ^{R×R}，C_{rr'}=corr(e_r,e_{r'})；特征值 λ_1..λ_R。有效独立数 n_eff=(Σλ_i)²/Σλ_i²（参与比），截断到 [1,R]。可按 (robot, modality) 扩展为证据图节点。
- **定义 238（独立性证书 EIC）**：EIC=(C, n_eff, 证据独立图 G_E, 锚点集 A)。聚合有效 ⇔ n_eff≥n_min。舰队贝叶斯更新用有效证据数而非机数：
  log P(H|ρ_{1:R}) ∝ log P(H) + (n_eff/R)·Σ_r log p(ρ_r|H)。
  n_eff=R 时退化为独立相乘；n_eff=1 时退化为单机证据——**同构克隆的一致不是证据**。
- **定义 239（故障作用域 FST）**：作用域 s∈{local, shared, common_cause}。观测模型 ρ_r=Sθ_r+S_sθ_shared+b+noise，θ_r 为本机故障、θ_shared 为共享模型/地图/数据集故障、common_cause 为同一 OOD 物体耦合视觉与力。作用域后验 P(s|ρ_{1:R})。**可辨识性条件**：存在锚点机 a∈A，其某证据通道不共享该分量。无锚点时 shared 与"全队同向 local"观测等价。
- **定义 240（演员-观察者证人多机协议 WITNESS）**：演员集 Act 执行动作，观察集 Obs 不动作。证据独立图 G_E 节点为 (robot, modality, view)。选 Obs*=argmax_{Obs⊆R\Act,|Obs|≤B} n_eff(G_E[Act∪Obs])·coverage(views)，s.t. 每个预测接触区域被 ≥1 个非演员以 ≥2 类模态覆盖。演员-观察者分离切断"动作-故障"耦合；视角多样破除遮挡；模态多样（力/触觉/本体/外部视觉）破除传感器共模。
- **定义 241（主动协作数据集构建 ACD）**：采集动作 u=(robot r, fault h, object o, env e, amplitude θ)。目标
  u*=argmax_u [ΔCov_D(u)+λ_I·I(ℋ;ρ_new|D)]/(risk(u)+cost(u))，
  s.t. risk(u)≤B_risk、object∈𝒪_sacrificial∪sim、通过现实差校验。多机并行时边际增益按 n_eff 折扣，避免相关探针重复计数。**覆盖增益可证明为次模，贪心有 (1−1/e) 保证。**
- **定义 242（越界检测与拒答 DFC）**：数据集级 conformal 新奇分数 s(ρ)=min_i d_M(ρ,ρ_i)（Mahalanobis/学习度量）或密度；阈值 q_nov(α) 由标定集给出。若 s(ρ)>q_nov → `dataset_out_of_support`，FIR **不得归因**，转 safe_idle +（安全时）ACD 采集，否则保守联合膨胀。这是对第 65 轮"未知故障被强行归入最近假设"的直接解药。
- **定义 243（舰队联邦标定 CFC）**：共享参数 ψ_0（故障签名 S、世界模型、度量）由各机联邦平均；本机参数 ψ_r（F/T 偏置、相机内参、接触模型）不出本机。**只有 ψ_0 进入共享账本**，本机故障无法污染共享签名；账本与证书均带版本。
- **定义 244（一致性与相关聚合）**：跨机聚合使用 EIC 加权后验（定义 238）。**显式拒绝把"多数票"当作独立性的替代**：相关克隆的多数票 = 一票。舰队置信度以 n_eff 报告，不以 R 报告。
- **定义 245（作用域定向球 RSC-C）**：在 r_geo/r_force/r_model 外新增 r_shared。路由：scope=local → 只膨胀该机对应球；scope=shared → 全队膨胀 r_shared+r_model，**不因"多数健康"而豁免**；scope=common_cause → r_shared↑ 且 w_vis↓；scope=ambiguous → 默认按 shared（保守）并标 `scope_ambiguous`。融合半径 r=√(r_geo²+r_force²+r_model²+r_shared²)。
- **定义 246（共享故障认证前缀 CSC-C）**：认证前缀须在**最坏作用域**下安全：若 scope∈{shared,ambiguous}，按"全队共享该故障"验证；演员前缀的安全不得依赖观察者正确。k*≤m；若唯一独立锚点掉线，强制 k*↓ 并重归因。
- **定义 247（数据集/舰队对抗认证 AIC-C）**：干扰集 ℰ_C=ℰ_V×ℰ_data×ℰ_fleet。ℰ_data 含账本投毒、标签噪声、数据集版本错配、相关采样；ℰ_fleet 含相关 OOD 漂移（全队见同一物体）、共享地图/模型漂移、时间同步故障、锚点掉线、克隆舰队。n_cert 128→160。**共因/投毒下不要求归因正确，只要求检出、拒绝证书并安全降级。**
- **定义 248（COHORT 证书 J_cohort）**：J_cohort=(J_vista, dataset_version_hash, provenance_root, ε(D), κ_fi(D), c_comp, n_eff, fault_scope, scope_conf, independence_graph_hash, out_of_support_flag, aic_c_ver)。Valid ⇔ Valid(J_vista) ∧ DIC 有效 ∧ EIC 有效(n_eff≥n_min) ∧ 全队同数据集版本 ∧ (作用域确定 ∨ scope_ambiguous→shared 保守) ∧ (¬out_of_support ∨ safe_idle)。

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（数据集条件可辨识性）**：J_fi(D)=Θ_DᵀΣ_ρ⁻¹Θ_D，θ 可辨识 ⇔ rank(Θ_D)=d_H。有限样本下后验错误率 ≤ exp(−n_eff·κ_fi(D)/2)。故**增加机器人数量若不同时增加 n_eff，不会降低归因错误率**——这直接给"堆机器人"去魅。
- **引理 10（作用域锚点必要性）**：若无任何证据通道独立于共享分量，则 shared 与"全队同向 local"观测分布相同，作用域后验不集中，任何确定性作用域判定的错误率 ≥ 先验质量。故作用域认证**必须**有锚点；无锚点只能默认 shared。
- **定理 9（COHORT 端到端归因-认证）**：在 A94–A99 下，若 DIC 有效、n_eff≥n_min、作用域确定或保守默认，则 Valid(J_cohort) ⇒ 故障被归因或被显式判越界/ambiguous、只膨胀正确作用域的球、覆盖保证成立、舰队级安全；且第 65 轮的隐藏假设 A88 被替换为**可测量、可审计的前提**。
- **定理 10（主动采集近最优）**：覆盖增益 ΔCov_D(u) 次模；n_eff 折扣后仍次模且相关探针边际递减；故贪心在风险预算下达到 (1−1/e) 近似最优。
- **命题（克隆舰队零信息）**：R 个完全同构同源机器人 n_eff=1，联合后验等于单机后验；只有异构性（不同传感器/标定/模型/视角）才能提升 n_eff。
- **实时性**：账本、DIC、EIC、FST、ACD、CFC 全在语义流；实时流只增作用域路由（<0.02ms）与越界早停（<0.05ms），目标 ≤2.6ms（A100）。

## 5. 本轮最大风险

**一句话**：COHORT 把"数据集覆盖"和"证据独立"做成了证书，但证书本身也是从同一份可能被污染、且与部署共享同一未建模共因的数据集里估出来的——**当投毒或共因恰好落在估计 n_eff/ε(D)/作用域的那部分数据上时，证书会自指地为"全队一起错"背书，多机协作与数据集构建并没有创造独立性，只是让我们能测量它，而测量本身可以被它要检测的那个共因骗过（A94/A98）。**

## 2. 形式化定义（完整版）

**定义 233（COHORT 闭环）** COHORT 是 VISTA 的"归因可认证"升级：在 VISTA 的"语义流 ∘ 实时流"骨架上挂载 FDL（可溯源账本）、DIC（数据集可辨识性证书）、EIC（证据独立性证书）、FST（作用域归因）、WITNESS（演员-观察者协议）、ACD（主动数据集构建）、DFC（越界拒答）、CFC（联邦标定），并原位升级 RSC-V→RSC-C、CSC→CSC-C、AIC-V→AIC-C、J_vista→J_cohort。不变式：**账本写入、数据集证书、独立性与作用域估计、主动采集、证书构建只发生在语义流与低频线程；实时路径只做残差采集、安全前缀执行、早停与派发，零学习写操作、零账本写入。**

**定义 234（故障归因数据账本 FDL）** 每条证据 z_i=(ρ_i, prov_i, label_i, ver_i)，其中 prov_i=(robot_id, sensor_calib_ver, model_hash, dataset_ver, env_id, inject_id, t)。账本 D={z_i} 为只追加哈希链 h_i=H(h_{i-1},z_i)，根哈希 R_D=h_n。任何一次归因必须引用 D 的一个子集 D_cite⊆D，并把 (provenance_root, D_cite 索引) 写入 J_cohort，使**结论与依据不可分离、可事后审计**。账本支持按 (robot, env, fault, version) 切片以计算覆盖与独立性。

**定义 235（数据集支撑与覆盖半径）** 故障参数空间 Θ=Θ_local×Θ_shared×Θ_comp。覆盖半径
ε(D)=sup_{θ∈Θ} min_{z_i∈D} d(θ,θ_i)，
d 可取故障参数空间上的欧氏/马氏距离，或诱导签名流形上的测地距离。称 D 为 δ-覆盖若 ε(D)≤ε_max。复合覆盖 c_comp(D) 为满足"故障对 (h_a,h_b) 同时激活且样本数 ≥n_min"的复合单元占全部需覆盖单元的比例。**ε 与 c_comp 是证书，不是经验指标：不达标的区域，系统不得声称可在其中归因。**

**定义 236（数据集可辨识性证书 DIC）** 设样本 i 的故障幅度向量为 θ_i，堆叠为设计矩阵 Θ_D∈ℝ^{n×d_H}。在线性化观测 ρ_i=Sθ_i+noise 下
J_fi(D)=Θ_DᵀΣ_ρ⁻¹Θ_D，κ_fi(D)=λ_min(J_fi(D))/λ_max(J_fi(D))。
DIC 有效 ⇔ rank(Θ_D)=d_H ∧ κ_fi(D)≥κ_min ∧ ε(D)≤ε_max ∧ c_comp(D)≥c_min。
直观：**若 D 中两类故障从未被共同激励，则它们在观测上共线，J_fi(D) 奇异，部署时无论采多少帧都分不开。** 可辨识性首先是数据集的性质，其次才是传感器的性质。DIC 的 deficient_cells（秩亏方向/未覆盖单元）直接交给 ACD 作为采集目标。

**定义 237（证据相关与有效独立数）** 设各机证据为 ρ_r（或残差 e_r），r=1..R。在健康标定集上回归掉由共享模型预测的公共信号后，计算相关矩阵 C∈ℝ^{R×R}，C_{rr'}=corr(e_r,e_{r'})，特征值 λ_1..λ_R。有效独立数
n_eff=(Σ_i λ_i)²/Σ_i λ_i²，
截断到 [1,R]。这是标准的参与比（participation ratio）：R 个完全独立通道 n_eff=R，R 个完全相关通道 n_eff=1。可把节点扩展为 (robot, modality) 以同时度量同机跨模态独立性与跨机独立性。

**定义 238（独立性证书 EIC）** EIC=(C, n_eff, G_E, A)。聚合有效 ⇔ n_eff≥n_min。舰队贝叶斯更新用**有效证据数**而非机数：
log P(H|ρ_{1:R}) ∝ log P(H) + (n_eff/R)·Σ_{r=1}^R log p(ρ_r|H)。
当 n_eff=R 退化为独立相乘；当 n_eff=1 退化为单机证据（各机等权平均）。**推论：同构克隆舰队的一致不构成证据；只有异构性（不同传感器、标定、模型、视角）才能提升 n_eff。**

**定义 239（故障作用域 FST）** 作用域 s∈{local, shared, common_cause}。观测模型
ρ_r = Sθ_r + S_sθ_shared + b + noise，
θ_r 为本机局部故障，θ_shared 为所有共享该地图/模型/数据集的机器人共有的故障，common_cause 为同一 OOD 物体同时耦合视觉与力的故障。作用域后验 P(s|ρ_{1:R})。**可辨识性条件**：存在锚点机 a∈A，其至少一个证据通道独立于被怀疑的共享分量（不同模型/数据集/标定，或外部计量）。**若无锚点，shared 与"全队恰好同向的 local"在观测上等价，作用域后验不集中。** 因此系统默认：scope 不确定时按 shared 处理（更保守，因为共享故障是全队级危险）。

**定义 240（演员-观察者证人多机协议 WITNESS）** 演员集 Act 执行动作，观察集 Obs 不动作。证据独立图 G_E 的节点为 (robot, modality, view)，边表示已知共因（共享模型、同一相机视角、同一标定）。选择
Obs* = argmax_{Obs⊆R\Act, |Obs|≤B} n_eff(G_E[Act∪Obs]) · coverage(views)，
s.t. 每个预测接触区域被 ≥1 个非演员以 ≥2 类模态覆盖。三条分离原则：(i) **演员-观察者分离**切断"动作-故障"耦合（非演员不受接触力尖峰污染）；(ii) **视角多样**破除遮挡与镜面共视；(iii) **模态多样**（力/触觉/本体感觉/外部视觉）破除传感器共模。

**定义 241（主动协作数据集构建 ACD）** 采集动作 u=(robot r, fault h, object o, environment e, amplitude θ)。目标
u* = argmax_u [ΔCov_D(u) + λ_I·I(ℋ;ρ_new|D)] / (risk(u)+cost(u))，
s.t. risk(u)≤B_risk、object∈𝒪_sacrificial∪sim、通过现实差校验。多机并行时，边际增益按 n_eff 折扣（相关探针的边际信息递减）。**覆盖增益 ΔCov_D 关于已覆盖单元集合是次模的**，故在预算约束下贪心达到 (1−1/e) 近似最优。采集目标由"不确定/未覆盖"驱动，而非由当前后验确认驱动——以抗自证。

**定义 242（越界检测与拒答 DFC）** 数据集级 conformal 新奇分数 s(ρ)=min_{z_i∈D} d_M(ρ,ρ_i)（马氏或学习度量），阈值 q_nov(α) 取标定集 ⌈(n+1)(1−α)⌉/n 分位。若 s(ρ)>q_nov(α) → 置 `dataset_out_of_support`，FIR **不得归因**，转 safe_idle +（安全时）ACD 采集，否则保守联合膨胀。**这是对第 65 轮"未知故障被强行归入最近假设"的直接解药：宁可承认不知道，也不给高置信的错误答案。**

**定义 243（舰队联邦标定 CFC）** 共享参数 ψ_0（故障签名 S、世界模型、度量）由各机联邦平均更新；本机参数 ψ_r（F/T 偏置、相机内参、接触模型）只在本机，不上传。**只有 ψ_0 进入共享账本**，因此本机局部故障无法污染共享签名，也不会被误当成全队故障。ψ_0 与 D 均带版本；联合证书要求全队使用同一版本（或显式声明跨版本校准）。

**定义 244（一致性与相关聚合）** 跨机聚合使用 EIC 加权后验（定义 238）。**显式拒绝把"多数票"当作独立性的替代**：相关克隆的多数票等于一票。舰队置信度以 n_eff 报告，不以 R 报告；若 n_eff<n_min，则报告"证据不足以联合归因"，退回单机最可信通道并降级。

**定义 245（作用域定向球 RSC-C）** 在 r_geo/r_force/r_model 外新增 r_shared。路由：
- scope=local：只膨胀被归因机对应的 r_geo/r_force/r_model，其他机不变；
- scope=shared：全队膨胀 r_shared+r_model，**不因"多数机健康"而豁免**（多数是相关的）；
- scope=common_cause：r_shared↑ 且 w_vis↓（视觉与几何共享同一失效源）；
- scope=ambiguous：默认按 shared（保守）并标 `scope_ambiguous`。
融合半径 r=√(r_geo²+r_force²+r_model²+r_shared²) 进入 WCV-C。相比第 65 轮，作用域使"只膨胀对的球"从假设级细化到**作用域级**。

**定义 246（共享故障认证前缀 CSC-C）** 认证前缀须在**最坏作用域**下安全：若 scope∈{shared, ambiguous}，按"全队共享该故障"验证 ∀s≤k、ρ_safe(s)≥0；演员前缀的安全不得依赖观察者正确（观察者可能被同一共因骗过）。k*≤m；若唯一独立锚点掉线，强制 k*↓ 并重归因。仍沿用第 65 轮的 conformal 选最小 k 与早停。

**定义 247（数据集/舰队对抗认证 AIC-C）** 干扰集
ℰ_C=ℰ_V×ℰ_data×ℰ_fleet，
ℰ_data 含账本投毒、标签噪声、数据集版本错配、相关采样；ℰ_fleet 含相关 OOD 漂移（全队见同一物体）、共享地图/模型漂移、时间同步故障、锚点掉线、克隆舰队。n_cert 128→160。ρ_dir 在 ℰ_C 上重算；**共因/投毒下不要求归因正确，只要求检出、拒绝证书并安全降级**。J_dir 增 dataset_ver、provenance_root、anchor_status。

**定义 248（COHORT 证书 J_cohort）** J_cohort=(J_vista, dataset_version_hash, provenance_root, ε(D), κ_fi(D), c_comp, n_eff, fault_scope, scope_conf, independence_graph_hash, out_of_support_flag, aic_c_ver)。验证规则：
Valid(J_cohort) ⇔ Valid(J_vista)
∧ DIC 有效（rank/κ_fi/ε/c_comp）
∧ EIC 有效（n_eff≥n_min）
∧ 全队同一数据集版本（或显式跨版本校准）
∧ (作用域确定 ∨ scope_ambiguous→按 shared 保守)
∧ (¬out_of_support ∨ safe_idle)
∧ aic_c_ver 为当前版本。
审计链新增：这份后验凭什么数据集（provenance_root/κ_fi/ε）、凭什么独立（n_eff/G_E）、凭什么作用域（anchor/scope_conf）。

## 3. 关键算法伪代码

### IP-225 DIC（数据集可辨识性证书）

```python
class DatasetIdentifiability:
    def __init__(self, kappa_min=1e-3, eps_max=0.1, c_min=0.8, n_min=5):
        self.kappa_min, self.eps_max, self.c_min, self.n_min = kappa_min, eps_max, c_min, n_min

    def certify(self, ledger):
        Theta = ledger.design_matrix()                 # n x d_H 故障幅度
        Sig = ledger.residual_cov()                    # Sigma_rho
        J = Theta.T @ np.linalg.inv(Sig) @ Theta
        rank_ok = np.linalg.matrix_rank(Theta) == Theta.shape[1]
        ev = np.linalg.eigvalsh(J)
        kappa = float(ev[0] / ev[-1]) if ev[-1] > 0 else 0.0
        eps = ledger.covering_radius()                 # sup_theta min_i d
        c_comp = ledger.composite_coverage(n_min=self.n_min)
        valid = rank_ok and kappa >= self.kappa_min \
            and eps <= self.eps_max and c_comp >= self.c_min
        return {'valid': valid, 'rank': int(np.linalg.matrix_rank(Theta)),
                'kappa_fi': kappa, 'epsilon': eps, 'c_comp': c_comp,
                'deficient_cells': ledger.null_directions()}
```

### IP-226 EIC（独立性证书）

```python
def effective_independence(ledger, healthy_slice):
    E = ledger.residuals(healthy_slice)                # T x R，已回归公共信号
    C = np.corrcoef(E, rowvar=False)                   # R x R
    lam = np.clip(np.linalg.eigvalsh(C), 1e-9, None)
    n_eff = float(lam.sum() ** 2 / (lam ** 2).sum())   # 参与比
    n_eff = min(max(n_eff, 1.0), C.shape[0])
    return {'C': C, 'n_eff': n_eff,
            'graph': build_evidence_graph(ledger),
            'anchors': find_anchors(ledger)}           # 不共享分量者

def fleet_bayes(rho_per_robot, lik, prior, n_eff):
    R = len(rho_per_robot)
    w = n_eff / R                                      # n_eff=1 → 等权平均
    logp = {h: np.log(prior[h]) +
            w * sum(np.log(lik[h](rho) + 1e-12) for rho in rho_per_robot)
            for h in prior}
    z = np.array(list(logp.values())); z -= z.max()
    return {h: float(np.exp(v) / np.exp(z).sum()) for h, v in logp.items()}
```

### IP-227 FST（作用域归因 + 锚点）

```python
def attribute_scope(rho_per_robot, anchors, model):
    # 若锚点通道与其余通道同向 → 共享；仅部分机偏离且锚点正常 → 局部
    scores = {}
    for s in ('local', 'shared', 'common_cause'):
        scores[s] = model.log_lik_scope(s, rho_per_robot, anchors)
    z = np.array(list(scores.values())); z -= z.max()
    post = {s: float(np.exp(v) / np.exp(z).sum()) for s, v in scores.items()}
    s_star = max(post, key=post.get)
    identifiable = len(anchors) > 0                    # 引理 10：无锚点不可辨识
    if not identifiable:
        return 'shared', 0.0, post                     # 默认保守
    return s_star, post[s_star], post
```

### IP-229 ACD（次模贪心采集）

```python
def greedy_acquisition(deficient_cells, robots, risk_budget, n_eff, B=20):
    covered, chosen, spent = set(), [], 0.0
    for _ in range(B):
        best, best_gain = None, 0.0
        for u in candidate_actions(deficient_cells, robots):
            if spent + risk(u) > risk_budget:
                continue
            gain = coverage_gain(covered, u) + LAMBDA_I * mutual_info(u)
            gain /= (risk(u) + cost(u))
            gain *= n_eff_discount(u, n_eff)           # 相关探针边际递减
            if gain > best_gain:
                best, best_gain = u, gain
        if best is None:
            break
        chosen.append(best); covered |= effect_cells(best); spent += risk(best)
    return chosen                                      # (1-1/e) 次模近似
```

### IP-233 COHORT 闭环算子（整合）

```python
def COHORT_round(M, obs, delta_f_req):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    # ———— 语义流 ————
    # 1) 数据集证书：先问证据够不够格
    dic = M.dic.certify(M.ledger)
    eic = M.eic.certify(M.ledger, M.healthy_slice)
    if not dic['valid'] or eic['n_eff'] < M.n_min:
        M.acd.request(dic['deficient_cells'], eic['n_eff'])
        return M, safe_idle(), build_j_cohort(M, dic, eic, out_of_support=True)

    # 2) VISTA 证据（视觉/力/阶段）
    y_vis = M.f_vis(img, depth, flow)
    A = M.ach.propose(M.x_prime, H=M.H)
    visual = M.vpg.verify_and_predict(y_vis, A, M.mws.last_contacts)
    rho = M.stage.split(M.residual_log, visual)

    # 3) 越界拒答：未知复合故障不硬归因
    if M.dfc.novelty(rho) > M.dfc.q_nov:
        return M, safe_idle(), build_j_cohort(M, dic, eic, out_of_support=True)

    # 4) 独立性 + 证人多机 + 作用域
    rho_all = M.fleet.collect(rho, robots=M.robots)
    post = fleet_bayes(rho_all, M.fir.lik, M.fir.prior, eic['n_eff'])
    obs_set = M.witness.select(M.act, eic['graph'], M.contact_regions)
    scope, conf, scope_post = attribute_scope(rho_all, eic['anchors'], M.fst)

    # 5) 作用域定向球 + 共享故障认证前缀
    M.balls = M.rsc_c.directed(scope, max(post, key=post.get), M.balls)
    k_star = M.csc_c.certified_prefix(A, post, scope, M.m, M.alpha_chunk)

    # 6) 实时执行（零账本写、零学习写）
    K_safe, EV_exec, cert_exec = realtime_step_cohort(M, delta_f_req, A, k_star)

    # 7) 语义流：写账本、联邦标定、对抗认证
    M.ledger.append(rho, prov=M.provenance(), label=scope)
    M.cfc.update(shared_params=M.cfc.psi0, local_params=M.cfc.psi_r)
    rho_dir = M.aic_c.certify(A, M.x_prime, M.balls, post, scope)
    return M, K_safe, build_j_cohort(M, dic, eic, post, scope, conf,
                                     k_star, cert_exec, rho_dir)
```

## 4. 推导

**引理 9（数据集条件可辨识性）** 在线性化 ρ=Sθ+noise 下，n 个样本的 Fisher 信息为 J_fi(D)=Θ_DᵀΣ_ρ⁻¹Θ_D。θ 可辨识 ⇔ J_fi(D)≻0 ⇔ rank(Θ_D)=d_H。若某两类故障在 D 中从未共激励，对应设计列线性相关，rank 亏缺，J_fi 奇异——**部署阶段再多的观测也无法补偿数据集的结构性缺陷**。在 rank 满且 κ_fi(D)>0 时，Laplace 近似下后验集中速率为 exp(−n_eff·κ_fi(D)/2)。因此**单纯增加同构机器人不改变 n_eff，不降低归因错误率**。∎

**引理 10（作用域锚点必要性）** 设所有 R 个证据通道都含有同一共享分量 S_sθ_shared。若不存在任何通道其观测不含该分量，则观测分布 p(ρ_{1:R}|shared,θ_shared) 与 p(ρ_{1:R}|local,{θ_r=θ_shared}) 完全相同（令每台本机故障等于共享故障即可复现）。故作用域后验在二者间不集中，任何确定性判定的最小错误率 ≥ min(P(shared),P(local))。**要辨识作用域，必须存在一个不共享该分量的锚点通道。** ∎

**定理 9（COHORT 端到端归因-认证）** 在 A94–A99 下：
1. **证据够格**：DIC 有效 ⇒ rank(Θ_D)=d_H 且 κ_fi(D)≥κ_min、ε(D)≤ε_max、c_comp≥c_min，归因所依赖的可辨识性与覆盖被显式保证（引理 9）。
2. **独立可测**：EIC 有效 ⇒ n_eff≥n_min，联合后验按有效证据数更新，不因同构克隆而虚假集中（定义 237/238）。
3. **作用域不混**：有锚点时作用域可辨识（引理 10）；无锚点或 scope_conf 低时默认 shared 保守处理，不因"多数健康"而豁免（定义 239/245）。
4. **越界拒答**：s(ρ)>q_nov ⇒ 不归因、safe_idle 或 ACD 采集，消除第 65 轮"未知复合故障强行最近邻"（定义 242）。
5. **共享安全**：CSC-C 在 shared/ambiguous 下按全队最坏验证，演员前缀不依赖观察者（定义 246）；RSC-C 只膨胀正确作用域的球。
6. **可审计**：Valid(J_cohort) 强制引用 provenance_root、DIC、EIC、scope，结论与依据绑定。
7. **优雅降级**：视觉失效→w_vis↓；本机 F/T 失效→local；共享模型/地图失效→shared；锚点掉线→scope 退化为 shared 且 k*↓；数据集越界→拒答。
8. **实时性**：实时路径 ≤2.6ms，零账本/学习写操作（A100）。∎

**定理 10（主动采集近最优）** 设覆盖增益 ΔCov_D(U)=|effect_cells(U)∖covered|，关于已覆盖集合 U 单调且边际递减，故次模。预算约束下最大化次模函数，贪心达到 (1−1/e)·OPT。加入 n_eff 折扣因子 δ(u)∈(0,1]，相关探针的 δ 更小，使边际增益仍次模且反映"重复采集同一故障单元信息递减"。故 ACD 在风险预算内以 (1−1/e) 近似最优地扩充覆盖。∎

**命题（克隆舰队零信息）** 若 R 个机器人同构、同源、同视角，则 C 全 1，λ=(R,0,…,0)，n_eff=(R²)/R²=1。由定义 238，联合后验 = 单机后验，舰队一致不提供额外证据。故"多机"的价值来自异构性而非数量；异构性通过锚点（引理 10）与 n_eff（定义 237）两条路径转化为可测量的归因能力。∎

**命题（多样性-可辨识性权衡）** 提高异构性会增大 n_eff 与锚点覆盖，从而提升作用域可辨识性；但异构性同时增大跨机迁移误差与共识成本，使共享标定 ψ_0 更难。存在一条由 (n_eff, 迁移误差) 刻画的 Pareto 前沿；COHORT 不追求最大 n_eff，而是在满足 n_eff≥n_min 与锚点覆盖的前提下最小化迁移/协调代价。∎

## 7. 已知风险

**一句话**：COHORT 把"数据集覆盖"和"证据独立"做成了证书，但证书本身也是从同一份可能被污染、且与部署共享同一未建模共因的数据集里估出来的——**当投毒或共因恰好落在估计 n_eff/ε(D)/作用域的那部分数据上时，证书会自指地为"全队一起错"背书，多机协作与数据集构建并没有创造独立性，只是让我们能测量它，而测量本身可以被它要检测的那个共因骗过（A94/A98）。**

**次级风险与缓解**：
1. **证书自指（核心风险）**：DIC/EIC 用同一账本估计又认证；缓解：**留出独立审计集**（不参与训练/拟合，物理隔离或时间后置），证书只在审计集上计算；审计集本身用密码学承诺 + 定期轮换；无法审计时显式降级为 `uncertified`。
2. **锚点脆弱**：唯一异构锚点掉线/被污染即作用域不可辨识；缓解：至少保留 2 个异构锚点、锚点状态写入 AIC-C、掉线即 k*↓ 并默认 shared。
3. **n_eff 估计偏差**：健康标定集不代表性（部署分布漂移）导致 n_eff 高估；缓解：在线漂移检测 + 分环境估计 n_eff + 取最坏环境值。
4. **投毒/标签噪声**：污染账本使覆盖与签名失真；缓解：溯源信誉、鲁棒统计（截尾/中位数）、跨机一致性校验、投毒检测入 AIC-C。
5. **采集的现实差与伦理/成本**：主动故障注入可能损坏牺牲件、仿真到现实有差；缓解：先仿真后真机、现实差校验门、风险预算硬约束、禁止在非牺牲件上注入。
6. **作用域默认 shared 的过度保守**：无锚点时全队膨胀，效率下降；缓解：把"补锚点"作为 ACD 的高优先级目标；作用域置信度提升后自动收敛。
7. **联邦标定的版本漂移**：ψ_0 版本不一致导致证书不可比；缓解：版本哈希强校验、跨版本显式校准、拒绝跨版本联合认证。
8. **计算与通信预算**：DIC/EIC/ACD 在语义流但随 n、R 增长；缓解：账本分片增量更新、EIC 降采样、只在证书失效时触发全量重算。
