# 第 1 轮（本轮灵感：「商业模式」×「谐波减速器」）

> **基线继承**：ToolGauge（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440）。
> 本轮纪律：**不动 50Hz 数值主路径**；在 ToolGauge 的「语义假设—契约工具—摊销校准」之上，
> 加一层「物理信任锚」和一层「经济结算」；两者都是可退化增强项，不是新依赖。
> 命名：**TrustGauge**（Reducer-Fingerprinted, Certificate-Settled Metrology）。

## 0. 直觉：两个词的交点不是比喻，而是「同一个减速比」

**灵感 1（谐波减速器 → 机器人自模型里最诚实的盲区，也是最便宜的标尺）**
直觉：电机侧编码器看不见柔轮的弹性变形，减速器的迟滞/丢步（lost motion）是一个隐藏状态——
这是「机器人对自己身体的盲区」的一个标准样本。但同一块缺陷还有另一面：传动误差 e(θ_m) 是确定性的、
与输入转角相位锁定的、且逐台唯一的。它既是盲区，也是一条**已知的多音激励**和一个**物理指纹**。
换错地方是噪声，换对地方是载波。

**灵感 2（商业模式 → 把「不确定性缩减」做成可审计、可定价、可追责的合约）**
直觉：商业模式不是一张幻灯片，而是一组关于价值创造与价值捕获的合约。ToolGauge 的 RepairCert
已经能证明「我修过」，但没有价格、没有责任、没有激励分析。商业模式的严谨版本是：
暴露 E_s = p_s·L_s（失败概率 × 损失）、修复收益 ΔE_s、成本 C_s、净价值 NVoI_s = ΔE_s − C_s；
再把它放进一个带相关风险的组合（共模偏差会让多个盲区同时失败），用证书、审计与结算把
「验证过的不确定性缩减」变成可交易的东西。

**灵感 3（两者相乘 → 物理信任锚 + 证书市场）**
直觉：没有物理锚的证书只是自说自话；没有经济层的修复只是成本中心。减速器指纹的逐台唯一性使它
天然成为一个 PUF（物理不可克隆函数）：证书可以绑定到这台机器、这个关节、这段物理响应上。
于是商业模式可以不是「卖模型」，而是「卖**设备绑定、可审计、按结果结算**的确定性」——
计量即服务（Metrology-as-a-Service）/ 结果型保修。物理层给信任，经济层给方向；两者在同一条闭环里。

**一个必须说清的边界**：这不是商业计划书，也不预测市场。本文只做三件可证伪的事：
（i）给减速器隐藏状态一个可辨识的模型；（ii）给「共模偏差」一个独立的物理参照；
（iii）给「修哪个盲区」一个带激励相容约束的决策规则。

## 1. 形式化定义（增量：定义 432–447）

### 定义 432（谐波减速器隐藏状态模型 HDM）

设电机侧（波发生器）角 θ_m、负载侧角 θ_l，减速比 R = Z_f/(Z_c−Z_f) = Z_f/2（Z_f 为柔轮齿数，Z_c−Z_f=2）。
令相对位移 ξ = θ_m/R − θ_l。传动误差取 K 阶谐波：

e_K(θ_m) = Σ_{k=1..K} (a_k·cos kθ_m + b_k·sin kθ_m).

迟滞/丢步用带死区的状态 z ∈ [−δ/2, δ/2] 描述（δ 为 lost motion）：

- ξ̇ > 0 ⇒ z ← min(δ/2, z+ξ̇)；ξ̇ < 0 ⇒ z ← max(−δ/2, z+ξ̇)；ξ̇ = 0 ⇒ z 不变；
- 力矩 τ = k_t·(ξ − e_K(θ_m) − z) + τ_f(ξ̇) + n_τ，k_t 为扭转刚度，τ_f 为摩擦。

于是可观测残差

ρ := θ_m/R − θ_l = e_K(θ_m) + z + τ/k_t + n_l.

**关键不是公式，而是可观测性**：一旦指纹 F = (e_K, δ, k_t) 已知，ẑ = ρ − e_K(θ_m) − τ/k_t
就直接给出隐藏状态。减速器用自己的缺陷测量自己的缺陷——这是「自参照」的全部内容。

### 定义 433（减速器指纹 RF）

F = (K, {a_k,b_k}, δ, k_t, unit_id, T_ref, tol)。辨识协议：

1. 单向整圈、近零载 ⇒ 拟合 e_K（差一个常数）；
2. 多次换向 ⇒ 由迟滞环宽度估计 δ；
3. 已知力矩斜坡 ⇒ 由 τ–ξ 斜率估计 k_t。

h(F) 作为设备身份。F 会随磨损与温升慢漂移，因此指纹有有效期；超出容差必须再指纹化（定义 447）。

### 定义 434（见证回执 WR）

w = (unit_id, t, θ_m, θ_l, τ, T, ẑ, ε_w, sig)，
其中 ε_w = |ρ − e_K(θ_m) − clip(ẑ,−δ/2,δ/2) − τ/k_t|。

valid(w) ⇔ ε_w ≤ ε_w^max ∧ Verify(sig)。见证回执**不依赖任何感知模型**，是物理层的独立通道；
它既可用于共模去混杂，也可用于证书的设备绑定。

### 定义 435（共模分解 CMD）

把 ToolGauge 的每条探测回执写成 r_i = u_{s(i)} + c_i + ε_i：c_i 为跨盲区共模，u 为局部目标。
见证特征 W_i 给出 c_i 的部分观测：c_i = P_cm(W_i) + c_i^⊥。

**排除性约束（exclusion restriction）**：W_i ⊥ u_{s(i)} | c_i——见证只通过共模影响回执。
在此假设下定义投影回执 r̃_i = r_i − P_cm(W_i)，共模可观测 ⇔ c^⊥ = 0。
记污染比 χ = Var(c)/Var(r)，投影后跨盲区残差相关为 ρ_res。

这条定义是诚实的关键：减速器见证只能去除**机械耦合**的共模；感知/光照/先验偏置若不在 span(W) 内，
投影后仍会留下相关，必须由 R-Quarantine 抓出来，而不是假装已经消除。

### 定义 436（自激频响探测 SE-FRM）

令 θ_m(t)=ωt（安全包络内匀速），则 d(t)=e_K(ωt) 是频率集 {kω} 上**已知**的多音激励。
负载侧响应 y(t) = (H_{u_s} * d)(t) + n(t)。相干估计

Ĥ_u(kω) = Σ_n y(t_n)·e^{−ikωt_n} / Σ_n d(t_n)·e^{−ikωt_n}，

再由 H_{u_s}(kω) 反演盲区参数 u_s。无需外部激振器：减速器自己就是激振源；相位由 θ_m 锁定，
所以解调是相干的。高次齿啮合谐波把载波推到 100 Hz 量级，而机械热漂移通常在 0.1 Hz 以下——
两者之间的频隙就是信噪比收益的来源。

### 定义 437（经济暴露与净价值 NVoI）

E_s = p_s·L_s，ΔE_s = (p_s − p_s′)·L_s，C_s = c_probe + c_down + c_risk，
NVoI_s = ΔE_s − C_s。

**商业死区** ΔE_min = C_audit/π1：低于它，审计成本超过可捕获价值，经济上不值得修。
这与减速器的 lost motion 同构：小输入不产生输出。π1∈(0,1] 是价值捕获比。

### 定义 438（价值组合调度 VPS）

max_{x∈{0,1}^{N_bl}} Σ_s x_s·NVoI_s − λ·CVaR_β( Σ_s x_s·L_s·Z_s )，
s.t. Σ_s x_s·C_s ≤ B。

Z_s 的失败相关由共模 c 诱导；CMD 给出相关矩阵估计，故调度器不仅看单点收益，还看「是否把鸡蛋放在同一个
共模篮子里」。N_bl ≤ 8 ⇒ 可精确枚举 2^8；更大规模用拉格朗日/贪心并给出界（引理 54）。

### 定义 439（信任证书 TC）

TC = (unit_id, s, H_s, Π_s, R_s, w, q_θ(u_s), guarantee=(1−α,ε), price, nonce, sig)，
price = π0 + π1·ΔE_s；nonce 为 PUF 挑战-响应，把证书绑定到设备。

### 定义 440（审计谓词 A）

A(TC)=1 ⇔ 签名有效 ∧ 回执可复验 ∧ 见证有效 ∧ 后验可重算 ∧ PUF 响应匹配 ∧ guarantee 自洽。
审计主体是确定性的；唯一需要设备的步骤是物理挑战-响应。审计通过才可结算。

### 定义 441（结算合约与激励相容）

P(TC) = price·1[A=1] − γ·1[实际失败超出 guarantee] − penalty·1[审计失败]。

- **IC-1（真实）**：独立审计概率 q、penalty > π1·max ΔE 时，只报告能通过审计的证书是占优策略；
- **IC-2（禁止探测即收费）**：仅当修复前 E_s ≥ E_min、NVoI_s > 0，且基线由独立通道测量，才可结算；
  过度探测的期望利润 ≤ 0；
- **IR**：买卖双方期望效用 ≥ 0。

### 定义 442（B-7C 闭环）

H（共形假设）→ C（TCV 编译）→ E（工具执行）→ C（摊销校准）→ V（独立回执交叉验证）→
U（热替换）→ **S（结算 + 台账 + 再指纹化触发）**。S 全异步，不进入 50Hz 路径。

### 定义 443（R-Quarantine 共模隔离）

在最近 K 次修复上计算 CMD 后的残差相关矩阵；若最大非对角 |ρ_res| > ρ_max 且对应共模不在 span(W)，
暂停 AP-Cal，回退 BP-Cal，并把相关证书标记为 unanchored（不可结算，直至再锚定）。
这是对 ToolGauge 最大风险「预训练先验跨盲区污染」的直接加固：先验偏差若不能用物理见证解释，就不许扩散。

### 定义 444（退化链延长）

F/w 不可用 ⇒ ToolGauge；经济层不可用 ⇒ ToolGauge 的增益注；审计失败 ⇒ 允许本地修复但不结算（stub+RED）；
SE-FRM 越出安全包络 ⇒ 退回被动探测。链：TrustGauge ⇐ ToolGauge ⇐ LeanGauge ⇐ MODGAUGE。

### 定义 445（证书组合）

串联：coverage 相乘（独立）或 1−Σα_i（并集界），方差相加；并联：取最大 coverage、取最小 ε，成本相加。
组合证书的误差传播必须可重放（E455）。

### 定义 446（采样与指纹有效期）

F 的有效期 τ_F 由温升/磨损模型给出；ε_w 连续超阈 ⇒ 触发再指纹化。再指纹化本身是一次受预算约束的探测，
其收益同样计入 NVoI（避免「为了校准而校准」）。

### 定义 447（继承与编号约定）

未重定义的第 1/2 轮记号（R、s、λ、γ、M_ver、N_bl、EC、MReg、H_s、Π_s、TCV 等）沿用定义 398–431。
令 F=∅、经济层=∅ ⇒ TrustGauge ≡ ToolGauge，因此本轮所有结论以 ToolGauge 为退化特例。

## 2. 关键推导（直觉版）

**引理 A（指纹可辨识）** 单向整圈提供 2K+1 阶持续激励，换向提供 δ 的信息，力矩斜坡提供 k_t 的信息；
在噪声 σ_n 下最小二乘误差 ~ σ_n·sqrt(cond(ΦᵀΦ)/N)。**边界**：温升会让 e_K 平移，所以 F 必须带温度项或有效期。

**引理 B（共模只被部分去除）** 在排除性约束与 c∈span(W) 下，r̃ 的跨盲区相关期望为 0；
若 c∉span(W)，残余相关 ≥ |corr(c^⊥)|，可检测但不可消除。**这是本方案最重要的诚实边界。**

**引理 C（SE-FRM 增益）** 对 1/f 噪声 S(f)=S_0/f，N 次相干平均在 kω 处的方差 ~ S_0/(kω·N·T)；
相对受漂移限制的直流估计，SNR 增益 ≈ 10·log10(kω/f_c) dB。取 k=Z_f≈100、ω=2π rad/s、f_c=0.1 Hz，
约为 30 dB。**边界**：高次谐波幅度小，最优 k 是幅度与噪声的折中。

**引理 D（收益与激励）** 无 CVaR 且失效独立时目标单调子模，贪心达 (1−1/e)；带相关 CVaR 时是 mean-risk 背包，
一般 NP-hard，但 N_bl≤8 可精确解。IC-1/IC-2 在独立审计与足够罚金下成立；**边界**：合谋与审计俘获未被消除，
需要职责分离。

**引理 E（时序与安全）** 新增计算全部异步；50Hz 路径只增加一次 O(1) 见证读取（<0.1 ms）；
SE-FRM 受幅值/力矩/温度硬包络约束，越界即退回被动探测。时序结论继承 ToolGauge 引理 50。

## 3. 参数尺度与可证伪预测

| 量 | 典型量级 | 待验证 |
|---|---|---|
| 减速比 R | 50–160 | 由型号给定 |
| 丢步 δ | 1–3 arcmin | 换向实验（E442） |
| 传动误差 e_K | 0.5–2 arcmin RMS | 整圈拟合（E441） |
| 齿啮合载波 | 100–160 Hz @1 rev/s | 频谱（E443） |
| 热漂移 | ~arcmin / 10–50°C | 温箱（E452） |
| 指纹熵 | 目标 ≥40 bit | PUF 实验（E444） |

可证伪预测：若 E443 的实测增益显著低于引理 C 的 30 dB（例如 <10 dB），则「减速器作为多音激励源」
这一核心假设不成立，本轮退回 ToolGauge；若 E445 中 c∉span(W) 的召回 <90%，则 CMD 的工程价值不足，
只保留 R-Quarantine 而删去投影。

## 4. 本轮最大风险

**一句话**：减速器指纹会随磨损/温升漂移，一旦漂移超过见证阈值，这个本应消除跨盲区共模的「共享参考」
就会变成新的共模源；而证书定价又让「忽略漂移、继续结算」比「停机重标定」更划算——
物理解析与经济激励在同一点失效（E445/E452 证伪，R-Quarantine + 定期再指纹化 + 独立审计兜底）。

# 第 1 轮产物 · 创新点清单 v3：**TrustGauge**（Reducer-Fingerprinted, Certificate-Settled Metrology）

> 背景：上一循环产物区 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440）
> 已解决「语义假设—契约工具—摊销校准—交叉验证—热替换」的闭环，但留下一个结构性缺口：
> 校准先验的跨盲区偏差仍只靠统计断路器（P-Quarantine）事后发现，且修复证书没有价格、责任与激励分析。
>
> 本轮以「谐波减速器 × 商业模式」为灵感，**在 ToolGauge 之上**加两层：
> 物理层用减速器的确定性传动误差与逐台指纹做**信任锚**（标尺 + PUF），
> 经济层把「验证过的不确定性缩减」做成**可审计、可定价、激励相容**的证书与结算。
> 集成链：**MODGAUGE ⊃ LeanGauge ⊃ ToolGauge ⊃ TrustGauge**；F=∅、经济层=∅ ⇒ 逐指令退回 ToolGauge。
> IP 编号：IP-321–326（共 6 个）；定义增量 432–447；引理增量 51–57；实验增量 E441–E455。

| `λ, CVaR_β, x` | 风险厌恶、组合风险、选择向量（定义 438） |
| `TC, guarantee=(1−α,ε), nonce` | 信任证书、覆盖保证、PUF 挑战（定义 439） |
| `A(TC), P(TC), γ, penalty` | 审计谓词、结算函数、责任系数、罚金（定义 440/441） |
| `IC-1 / IC-2 / IR` | 真实报告 / 禁止探测即收费 / 个体理性（定义 441） |
| `B-7C` | H→C→E→C→V→U→S（定义 442） |
| `ρ_max, unanchored` | R-Quarantine 阈值与不可结算标记（定义 443） |
| `τ_F` | 指纹有效期（定义 446） |

## 2. 形式化定义（要点）

**定义 432（HDM）** θ_l = θ_m/R − e_K(θ_m) − z − τ/k_t；z∈[−δ/2,δ/2] 为带死区的迟滞状态，
ξ̇ 的符号驱动 z 饱和移动；ρ=θ_m/R−θ_l=e_K+z+τ/k_t 可观测。**指纹已知 ⇒ 隐藏状态 ẑ 可反演。**
**定义 433（RF）** 单向整圈拟合 e_K，换向估 δ，力矩斜坡估 k_t；h(F) 为设备身份；F 有温度项与有效期 τ_F。
**定义 434（WR）** w 含 ẑ 与残差 ε_w；valid ⇔ ε_w≤ε_w^max ∧ Verify(sig)；不依赖感知模型。
**定义 435（CMD）** r_i=u_{s(i)}+c_i+ε_i；c_i=P_cm(W_i)+c_i^⊥；排除性约束 W⊥u|c；
r̃=r−P_cm(W)；共模可观测 ⇔ c^⊥=0；否则残差相关可检测但不可消除。
**定义 436（SE-FRM）** d(t)=e_K(ωt) 为已知多音激励；Ĥ_u(kω)=Σ y e^{−ikωt}/Σ d e^{−ikωt}；由 H_u 反演 u_s。
**定义 437（NVoI）** E_s=p_s L_s，ΔE_s=(p_s−p_s′)L_s，C_s=c_probe+c_down+c_risk，NVoI_s=ΔE_s−C_s；
ΔE_min=C_audit/π1 为商业死区。
**定义 438（VPS）** max Σx_s NVoI_s − λ·CVaR_β(Σx_s L_s Z_s)，s.t. Σx_s C_s≤B；相关由 c 诱导。
**定义 439（TC）** TC=(unit_id,s,H_s,Π_s,R_s,w,q_θ(u_s),(1−α,ε),price,nonce,sig)；price=π0+π1ΔE_s。
**定义 440（A）** 签名 ∧ 回执 ∧ 见证 ∧ 后验重算 ∧ PUF ∧ guarantee 自洽；通过才可结算。
**定义 441（结算/IC）** P=price·1[A]−γ·1[失败超保证]−penalty·1[审计失败]；IC-1 真实报告，
IC-2 仅当 E_s≥E_min、NVoI_s>0 且基线独立测量才结算；IR 双方期望效用≥0。
**定义 442（B-7C）** H→C→E→C→V→U→S；S 更新台账、触发保修/再指纹化，全异步。
**定义 443（R-Quarantine）** CMD 后残差相关矩阵最大非对角 >ρ_max 且不由 span(W) 解释 ⇒ 暂停 AP-Cal、
回退 BP-Cal、相关证书标记 unanchored。
**定义 444（退化）** 见上「退化链声明」；F=∅、经济层=∅ ⇒ TrustGauge ≡ ToolGauge。
**定义 445（组合）** 串联 coverage 相乘或 1−Σα_i、方差相加；并联取最大 coverage / 最小 ε；成本相加；须可重放。
**定义 446（指纹有效期）** τ_F 由温升/磨损模型给出；ε_w 连续超阈 ⇒ 再指纹化，其成本/收益计入 NVoI。
**定义 447（继承）** 未重定义记号沿用定义 398–431；本轮所有结论以 ToolGauge 为退化特例。

# IP-321 R-Box：指纹辨识 + 在线见证
class RBox:
    def __init__(self, F, eps_w):
        self.F, self.eps_w = F, eps_w

    def e(self, th_m):
        return sum(a * cos(k * th_m) + b * sin(k * th_m)
                   for k, (a, b) in self.F.harmonics.items())

    def witness(self, th_m, th_l, tau, T):
        rho = th_m / self.F.R - th_l
        z_hat = rho - self.e(th_m) - tau / self.F.k_t
        z_clip = clip(z_hat, -self.F.delta / 2, self.F.delta / 2)
        eps = abs(rho - self.e(th_m) - z_clip - tau / self.F.k_t)
        if eps > self.eps_w:
            return None                      # 指纹失配 ⇒ 见证不可用（退化）
        return Witness(self.F.unit_id, th_m, th_l, tau, T,
                       z_hat, eps, sign())

# IP-322 SE-FRM：把 e_K(ωt) 当已知多音载波
class SEFRM:
    def __init__(self, F, env, f_s, N_avg):
        self.F, self.env, self.f_s, self.N = F, env, f_s, N_avg

    def probe(self, s):
        if not self.env.safe(omega=self.F.omega_max, tau=self.F.tau_max):
            return None                      # 安全包络外 ⇒ 退回被动探测
        ys, ds, ts = [], [], []
        for n in range(self.N):
            th_m = self.env.spin(omega=self.F.omega, step=n)
            ys.append(self.env.measure(s, th_m))
            ds.append(self.F.e(th_m))
            ts.append(n / self.f_s)
        H = {}
        for k in self.F.probe_harmonics:
            num = mean([y * exp(-1j * k * self.F.omega * t)
                        for y, t in zip(ys, ts)])
            den = mean([d * exp(-1j * k * self.F.omega * t)
                        for d, t in zip(ds, ts)])
            H[k] = num / den
        return estimate_param(H, s)          # 盲区参数 u_s

# IP-323 CMD + R-Quarantine：投影掉可观测共模，抓出不可观测残差
class CMD:
    def __init__(self, P_cm, rho_max):
        self.P_cm, self.rho_max = P_cm, rho_max

    def project(self, receipts, witnesses):
        w = featurize_witness(witnesses)
        c_hat = self.P_cm(w)
        return [r - c for r, c in zip(receipts, c_hat)], c_hat

    def quarantine(self, r_tilde):
        R = corr_matrix(r_tilde)
        off = max_abs_offdiag(R)
        return off > self.rho_max, off

# IP-324 VPS：净价值 − CVaR 组合风险
class VoIScheduler:
    def select(self, blinds, ledger, budget, lam, beta):
        best, best_score = [], -float("inf")
        for x in powerset(blinds):                  # N_bl <= 8
            if sum(C[s] for s in x) > budget:
                continue
            ev = sum(E[s] * delta_p(s) for s in x) - sum(C[s] for s in x)
            risk = cvar(beta, ledger.loss_portfolio(x))
            score = ev - lam * risk
            if score > best_score:
                best, best_score = x, score
        return best

# IP-325 TCL：证书、审计、结算
class CertificateLedger:
    def issue(self, s, H, prog, receipts, w, post, guar):
        tc = TrustCert(unit=w.unit_id, s=s, H=H, prog=prog,
                       receipts=receipts, witness=w, post=post,
                       guarantee=guar, nonce=puf_challenge(w.unit_id),
                       price=PI0 + PI1 * delta_E(s))
        tc.sig = sign(tc)
        return tc

    def audit(self, tc):
        return (verify_sig(tc)
                and verify_receipts(tc.receipts)
                and verify_witness(tc.witness)
                and recompute_post(tc) == tc.post
                and puf_verify(tc.unit_id, tc.nonce)
                and guarantee_consistent(tc))

    def settle(self, tc):
        if not self.audit(tc):
            return 0, "audit_failed"
        return tc.price - liability(tc), "settled"

# IP-326 B-7C 闭环
def trustgauge_b7c(M, s):
    H = M.lbox.hypothesize(s, M.dbox.R[s])                     # H
    w = M.rbox.witness(M.env.th_m(), M.env.th_l(),
                       M.env.tau(), M.env.T())
    if w is None:
        return toolgauge_6c(M, s)                              # 退化：无见证
    prog = M.tbox.select(H, M.tools, M.tcv, M.budget_left(s))  # C
    receipts = M.tcv.execute(prog, M.env)                      # E
    receipts, c_hat = M.cmd.project(receipts, [w])             # CMD
    mu, Sig = M.apcal.calibrate(receipts, H, s)                # C
    if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):
        return stub_and_red(s, "cross_failed")                 # V
    new_ec = M.apcal.update_contract(M.dpe, mu, Sig, s)        # U
    if not contract_regression(new_ec):
        return stub_and_red(s, "regression_failed")
    M.mreg.hot_replace(M.dpe, new_ec)
    tc = M.ledger.issue(s, H, prog, receipts, w,
                        (mu, Sig), guar=(1 - ALPHA, EPS))
    q, off = M.cmd.quarantine(receipts)
    if q:
        M.rquar.trigger(off)                                   # R-Quarantine
    payout, why = M.ledger.settle(tc)                          # S
    M.voi.update(s, tc, payout)                                # 台账
    return payout, why

# IP-326 主闭环：50Hz 路径不动，物理/经济新逻辑全部异步
def TrustGauge_round(M, obs, audio, tac, depth, det):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s)
            submit_async(trustgauge_b7c, M, s)
    if M.rquar.triggered():
        M.apcal.pause()
        M.use_bpcal_fallback = True
    return ToolGauge_round(M, obs, audio, tac, depth, det)

## 4. 推导

**引理 51（指纹可辨识性）** 单向整圈回归量 [cos kθ, sin kθ] 持续激励 2K+1 阶；换向激励 δ；力矩斜坡激励 k_t。
噪声 σ_n 下 ||ê−e||_∞ ≤ √(2K)·σ_n·√(cond(ΦᵀΦ)/N)·(1+o(1))。**边界**：温升使 e_K 平移，F 带 T 项或走 τ_F 重标定。

**引理 52（共模可分离性）** 在排除性约束 W⊥u|c 与 c∈span(W) 下，E[corr(r̃)]=0；
若 c∉span(W)，则残余相关 ≥ |corr(c^⊥)|，可检测不可消除。**这是「物理锚」不是「万能锚」的正式边界。**

**引理 53（SE-FRM 增益）** 对 S(f)=S_0/f，N 次相干平均在 kω 处方差 ≈ S_0/(kω·N·T)；
相对受漂移限制的直流估计，SNR 增益 ≈ 10·log10(kω/f_c) dB。取 k=Z_f≈100、ω=2π rad/s、f_c=0.1 Hz 约 30 dB。
**边界**：高次谐波幅度下降，最优 k 由幅度-噪声折中决定。

**引理 54（组合调度界）** 无 CVaR 且失效独立 ⇒ 目标单调子模，贪心 (1−1/e)；
带相关 CVaR ⇒ mean-risk 背包，一般 NP-hard；N_bl≤8 时 2^N 精确，或拉格朗日松弛给上界。

**引理 55（激励相容）** 风险中性、独立审计概率 q、penalty>π1·max ΔE、基线独立测量下：
(a) 只报告可通过审计的证书是占优策略（IC-1）；(b) 过度探测的期望利润 ≤ 0（IC-2）；(c) IR 成立。
**边界**：合谋、审计俘获、基线被卖方控制时结论失效——须职责分离与随机复核。

**引理 56（时序与安全保持）** 新增计算全部异步；50Hz 路径只多一次 O(1) 见证读取（<0.1 ms）；
SE-FRM 受幅值/力矩/温度硬包络约束，越界即退回被动探测；预算/停机时间由 B-7C 硬顶。时序继承引理 50。

**引理 57（设备绑定）** 若指纹响应最小熵 H_ent、挑战空间 ≥2^{H_ent}，则无设备伪造随机挑战通过概率 ≤2^{−H_ent}；
nonce 新鲜性阻止重放。H_ent 由 E444 实测；**边界**：侧信道与物理克隆未被消除。

## 8. 本轮最大风险

**一句话**：减速器指纹会随磨损/温升漂移，一旦漂移超过见证阈值，这个本应消除跨盲区共模的「共享参考」
就会变成新的共模源；而证书定价又让「忽略漂移、继续结算」比「停机重标定」更划算——
物理解析与经济激励在同一点失效（E445/E452 证伪，R-Quarantine + 定期再指纹化 + 独立审计兜底）。
