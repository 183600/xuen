# 第 3 轮（灵感循环第 1 轮；本轮灵感：「创新点提炼」×「面部表情识别」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E439）。
> 其下继承 LeanGauge（IP-310–314）、MODGAUGE 五不变式与 4CV→6C 骨架。
> 本轮纪律：**只加一层「软证据蒸馏」，不改数值内核**——F-Box 只收紧探测包络，N-Box 只删除未被证成的创新主张；
> 两者都不进入数值真值通道。所有旧模块、五不变式与退化链保留。

## 0. 基线审计：先承认第 2 轮没做完的五件事

1. **E440 是空洞**：第 2 轮产物头部声称实验增量 E426–E440，正文表只定义到 E439。本轮从 **E441** 起，不替第 2 轮补写 E440。
2. **「独立回执」的独立性是假设，不是测量**：定义 421.V 依赖 `cross.modal` 与主通道相互独立，但二者常共享同一物理过程（同一材质、同一光照、同一温漂）。独立性没有被检验。
3. **语言修复证书只绑定回执，不审计「新在哪」**：定义 423/427 能阻止无回执的胡说，却不能阻止 VLA 用新词包装继承模块。第 2 轮最大风险中的「可信度外观」从未被测量。
4. **P-Quarantine 是事后断路器**：定义 428 要连续 3 次同向偏差才触发，缺少对「偏差前兆」的早期检测。
5. **人不在回路里**：第 2 轮把探测安全完全交给物理包络与工具前置；现场唯一能提前感知「这不对」的人，被排除在系统之外。

## 1. 双轴映射（升级而非重写）

| 灵感词 | 第 2 轮对象 | 升级为 | 一句话动机 |
|---|---|---|---|
| 面部表情识别 | IP-316 T₀ 工具库与定义 430 PROBING：安全只来自物理包络 | **F-Box + V-Box**：AU 级非语言证据 + 主体基线 + 保形集 + 微表情前兆；**只否决、不代言** | 人是探测现场唯一的非接触、零反作用安全通道；但脸是「有作者的软证据」，只能收紧、不能放松 |
| 创新点提炼 | IP-315–320 的 IP 清单与定义 427 语言证书：创新由作者自述 | **N-Box + D-Core**：AIU 分解 + 谱系扣除 + 反事实负载性 + 保形/FDR 选择 | 创新点不是文本里的新词，而是「去掉它数值契约会坏」的因果贡献；语言证书必须经蒸馏才可信 |
| 共同结构 | 二者都是弱、稀疏、多标签、基线相关、带未知「显示规则」的软证据 | **D-Core**：分解 → 基线/谱系扣除 → 时序/反事实验证 → 校准与弃权 | 同一个蒸馏算子，两个应用：把「脸」和「创新」都磨成可审计的切面 |

**核心命题**：ToolGauge 的「契约化工具 + 摊销校准 + 交叉验证热替换」之上，再加一层
「**软证据蒸馏**」——数值真值仍由计量层独占，软证据只做两件事：
**(a) 收紧探测安全包络；(b) 删除未被证成的创新主张**。
命名 **FacetGauge**：facet 既是「脸的一个切面」，也是「创新点的一个切面」；蒸馏就是找切面。

**三条设计律**：
- **表情不代言**：FER 只测量可观测的 AU/显示行为，不推断内部情绪、同意、疼痛、诚实或能力；高风险决策必须有独立证据或显式命令。
- **创新不自证**：作者/VLA 的「新」不是证据；novelty 必须由谱系扣除 + 反事实负载性 + 外部回执共同建立；未蒸馏的主张在序列化时剥离。
- **软证据安全单调**：F-Box 只能让探测包络变小，N-Box 只能让主张变少；任何软证据失效都退回 ToolGauge，而不是放宽约束。

**不变式保持声明**：
- MODGAUGE 五不变式（契约完整性、组合单调性、反作用通道完备、主张绑定、严格退化链）全部保留；
- 主张绑定不变式扩展为「**蒸馏主张绑定**」：语言主张不仅要引用有效回执，还要引用蒸馏后的 AIU，否则剥离；
- **严格退化链延长**：FacetGauge 失效（F-Box 不可用/未同意 / N-Box 无有效审计 / D-Core 失败）⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE。

## 2. 直觉与动机

### 灵感 1（面部表情识别 → 脸不是仪表，是「有显示规则的软证据」）

直觉：FER 的原始输出不是「快乐/恐惧」，而是面部动作单元（AU）的强度序列，例如 AU4（皱眉）、AU7（眼睑收紧）、
AU9（皱鼻）、AU10（上唇提升）、AU20（唇拉伸）、AU24（唇压紧）。从 AU 到表情、从表情到内部情感，
中间还隔着 **display rule（显示规则）**：礼貌、权力、文化、疼痛掩蔽、社交迎合都会让人「表演」。
同一个 AU12（嘴角上扬）可以是真实愉悦、职业微笑、尴尬、顺从或掩饰；同一个「平静脸」也可能是强忍不适。
因此 **脸不是温度计，脸是一个有策略的发送者**；把 FER 当情绪读数，会在最需要保守时系统性放松安全约束。

但脸仍然有用——不是用来「读心」，而是用来检测**可观测的非语言安全模式（NSP）**：
皱眉+眼睑收紧、皱鼻+上唇提升、唇压紧、上脸警觉样模式、以及 1/25–1/5 秒的微表情前兆。
这些模式不能告诉我们「他疼不疼」，但可以告诉我们「**此刻继续加大探测力度是否明智**」。
所以 F-Box 的输出不是情绪标签，而是：
- 一个**保形非语言集** `E_α(F)`（在主体基线归一化后，仍可能成立的可观测模式集合）；
- 一个**保守风险上界** `v(F) = max_{e∈E_α(F)} risk(e)`；
- 一个**微表情前兆** `micro(F)`，只用于提前收紧，不用于定罪。

安全姿态必须是 **veto-only**：脸只能让力/力矩/光照/温升/时长上限变小，永远不能变大。
即使 F-Box 完全误判——把礼貌微笑读成风险，或把强忍不适读成平静——系统最多变得「更保守」或「少预警」，
不会因为「脸说没事」而突破物理包络。这是与第 2 轮「零副作用」安全姿态的兼容方式：不增加作用力，只提前收手。

同时必须承认脸的三个工程事实：
1. **主体差异**：不同人、不同文化、不同性别表达的基线完全不同，必须做 per-operator 中性基线；
2. **微表情极难**：低强度、短时长、类别极不平衡，只能做前兆，不能做判决；
3. **隐私与同意**：人脸是生物特征。F-Box 必须端侧提 AU、原始帧不出设备、上传统计量加 DP、显式同意、可退出；
   若 DP 噪声改变了分布，保形校准必须在**同一 DP 机制**下做，否则覆盖率保证会在部署时悄悄失效。

### 灵感 2（创新点提炼 → 创新不是文本里的新词，是「去掉它会坏」的因果贡献）

直觉：一份「创新点清单」最容易犯的错，不是漏掉创新，而是**把继承、重命名、参数匹配和事后叙事当成创新**。
这和第 1 个灵感里的 display rule 完全同构：创新也有「显示规则」——
- 把上一轮的模块换个名字（lineage rename）；
- 把已有能力的参数调一调，声称「新机制」；
- 用一个只在自家测试集上成立的强基线做对比；
- 用 VLA 的语言证书把「继承」包装成「修复」，把「工程胶水」包装成「理论贡献」。

所以要「提炼」而不是「生成」：提炼 = **分解 + 扣除 + 证伪 + 校准**。
- **分解**：把每个 IP 拆成原子创新单元（AIU），一个 AIU 是最小的、不可再分的契约改动；
- **扣除**：用跨轮谱系账本做 `Nov(u) = 1 − max_v Sim(u,v)`；行为签名相同即 `Nov=0`，不管措辞多新；
- **证伪**：用反事实消融测负载性 `LB(u) = D(C) − D(C\u)`——去掉它，契约损伤是否真的变大；
- **校准**：多评审 + 保形选择 + BH/FDR，控制「把继承当创新」的假发现率；
- **弃权**：证据不足、评审分歧、压力套件没覆盖，就不写「创新」，只写「工程说明」。

这里最反直觉、也最重要的一点是 **micro-innovation（微创新）**：
文本 diff 很小、参数量很小、甚至只有一行公式修正，但反事实负载性极大（去掉它系统会系统性偏差）。
这恰好对应微表情：**低幅度、短时长、高信息量**，用「显著性」审稿会漏掉，用「反事实」才能抓到。
所以 N-Box 不按文本长度/引用数/语言华丽度打分，而按 `MI(u) = LB(u) / Footprint(u)` 排序。

### 灵感 3（合流 → 同一个蒸馏算子，两个应用）

把两个灵感放在一起，会发现它们不是两个模块，而是**同一个问题的两个实例**：

| 维度 | 面部表情 | 创新点 |
|---|---|---|
| 原始信号 | AU 强度序列 | 契约 diff / 回执 / 语言主张 |
| 原子单元 | AU / NSP | AIU |
| 混淆项 | display rule、主体、文化、遮挡 | 谱系、重命名、参数匹配、事后叙事 |
| 基线 | 主体中性脸 | 上一轮已有能力 |
| 验证 | 时序/微表情 + 保形集 | 反事实消融 + 多评审 + FDR |
| 安全姿态 | 只收紧包络 | 只删除主张 |
| 失败模式 | 把礼貌当同意、把疼痛当平静 | 把继承当创新、把胶水当理论 |

于是提出 **D-Core**：`D = Calibrate ∘ Verify ∘ Subtract ∘ Decompose`。
F-Box 是 `D` 在「脸」上的实例；N-Box 是 `D` 在「研究 artifact」上的实例。
这个统一不是修辞：它给出同一个可证伪要求——**任何软证据，必须能分解、能扣基线、能过反事实/时序验证、能在不确定时弃权**。
不能满足这四条的「表情识别」或「创新点提炼」，都只是给系统增加了一个自信的噪声源。

### 灵感 4（为什么现在做：第 2 轮的两个风险正好对应这两件事）

第 2 轮最大风险是「AP-Cal 的跨盲区强相关偏差 + VLA 语言证书放大可信度外观」。
- 对**物理风险**：F-Box 提供一个物理上独立、零反作用的提前收手通道；
- 对**认知风险**：N-Box 提供一个跨轮、反事实、可校准的创新审计通道。
两者都不碰数值真值，因此不会破坏第 2 轮的实时性与契约等价性；但它们把「系统有多自信」和「系统实际有多可信」拆开了。

## 3. 形式化定义（增量：定义 432–447）

**定义 432（非语言证据回执 NER）** 回执 `F = (A, Q, sig, ts, seq, consent_id)`：
- `A ∈ [0,1]^{T×K}` 是端侧提取的 AU 强度序列（K 个 AU），**原始像素不出设备**；
- `Q` 是质量向量（姿态、遮挡、光照、活体分数）；
- `valid(F) ⇔ Q ≥ q_min ∧ liveness ∧ consent ∧ Verify(sig) ∧ seq 单调`。
无效回执一律作废，且**永不进入任何风险/创新判定**。

**定义 433（显示规则混淆与非语言可识别性）** 观测模型
`A = g(ψ_int, r_disp, p, c, o) + ε`，
其中 `ψ_int` 为内部状态、`r_disp` 为显示规则、`p` 为主体、`c` 为文化/语境、`o` 为遮挡/姿态。
当 `r_disp` 未知时，`ψ_int` **一般不可识别**。因此 F-Box 只定义显示层泛函
`v(F) = φ(A_{t−w:t}, Q)`，
其中 `φ` 是预注册的、对 AU 强度单调的 **非语言安全模式（NSP）** 策略，输出的是「可观测不适/迟疑」的保守上界，
**不是** `P(emotion | A)`。本设计明确禁止把情绪分类概率作为决策变量（「表情不代言」律）。
可识别性条件：若 NSP 基与 `φ` 预注册，且 `φ` 对 AU 单调，则 `v` 作为**行为量**可识别；`ψ_int` 仍不可识别，故不进入任何证书。

**定义 434（主体基线与保形非语言集）** 对主体 `p` 取短时中性基线 `A_p^0`，归一化 `Ã = A − A_p^0`。
在显示层模式空间 `E_disp` 上取非一致性分数 `s(F,e) = 1 − q_θ(e | Ã)`，校准集上取 `1−α` 分位 `τ`，
定义 `E_α(F) = {e ∈ E_disp : s(F,e) ≤ τ}`，满足可交换性下 `P(e* ∈ E_α(F)) ≥ 1−α`。
按主体/文化/光照做 Mondrian 分组；若某组覆盖率 `< 1−α−η`，该组**弃权**。
风险上界取 `v(F) = max_{e∈E_α(F)} risk(e)`——只要集合里还有一种合理解读要求收手，就收手。

**定义 435（微表情前兆检测）** 微事件 `m` 是时长 `d ∈ [1/25, 1/5] s`、幅度 `‖A‖ ≤ a_micro` 的 AU 轨迹。
检测统计量 `S_t = max_m ⟨A_{t−w:t}, m⟩ / ‖m‖`，`S_t ≥ h` 触发。定义前置时间 `L = t_stop − t_detect`；
要求 `P(L ≥ L_min) ≥ 1−β`（在预注册事件集上）。微表情**只用于提前收紧**，不作为证据、不进入 N-Box、不写证书。

**定义 436（只否决的探测包络 Veto-Envelope）** 标称包络 `E⁰ = (f_max, τ_max, I_max, T_max, v_max, n_max)`。
对风险 `v(F)` 定义收缩
`E(F) = (1 − κ·v(F)) ⊙ E⁰`，`κ ∈ [0,1]`，
逐分量不超过 `E⁰`。单调性：`v₁ ≤ v₂ ⇒ E(v₁) ⊇ E(v₂)`。
若 `v(F) ≥ v_stop` 或 `micro.onset`，停止探测并要求操作者显式确认；
若 F-Box 无效/未同意，令 `E = E⁰`，但高风险探测必须显式确认。
**任何代码路径不得把任一分量乘以 >1 的因子**——这是「不会因为一张脸而突破物理包络」的机械保证。

**定义 437（同意/隐私门）** F-Box 仅在 `consent_id` 有效时启用；退出即关闭，系统按退化链运行。
原始帧不出设备；上传的仅是 AU 统计量 + 质量 + 保形摘要，且加 `(ε_dp, δ_dp)`-DP 噪声；
不做身份识别；保留期 ≤ `T_retain`；审计日志不可篡改。
**隐私-校准协同**：DP 噪声是一次分布平移，保形校准必须用同一 DP 机制，否则覆盖率失效。

**定义 438（原子创新单元 AIU）** `u = (ΔC, E_u, L_u, σ_u)`：
- `ΔC`：最小契约改动（一个定义/字段/不变式/算法步骤）；
- `E_u`：支持该改动的有效回执/实验证据；
- `L_u`：谱系描述（它精化/继承/替换了哪些前轮定义或主张）；
- `σ_u`：行为签名（在预注册压力套件 `𝒮` 上的契约测试结果向量）。
原子性：若 `u` 可拆成两个各自独立负载的子改动，则必须拆分；一个 IP 是 AIU 的**包**，不是原子。

**定义 439（谱系扣除）** 维护跨轮账本 `𝕃 = {u₁,…,u_m}`。定义
`Nov(u) = 1 − max_{v∈𝕃} Sim(u,v)`，
其中 `Sim(u,v)` 以**行为签名**为主：若 `σ_u = σ_v`（在 `𝒮` 上逐项相同），则 `Sim=1`、`Nov=0`，
无论文本措辞、变量名、引用如何变化；文本相似度只用于候选匹配，绝不用于判定 novelty。
`Nov(u) ≤ ν₀` 的单元称为 **lineage-equivalent**，可从创新集剔除（仍可作为工程说明保留）。

**定义 440（反事实负载性）** 设 `D(C)` 是预注册的契约损伤泛函（风险加权违规 + 覆盖率损失 + 校准误差 + 时延违规）。
对 AIU `u` 定义
`LB(u) = D(C) − D(C \ u)`，
其中 `C \ u` 表示把 `u` 替换为前轮版本/零字段/空实现后的契约。`u` 是**负载的**当且仅当
`LB(u) ≥ δ_LB` 且 bootstrap 置信下界 `≥ δ_LB`（置信度 `1−β`）。
`LB < 0` 意味着去掉它反而更好：该单元是**缺陷**，不是创新。
**注意**：`LB` 是相对于压力套件 `𝒮` 的；`𝒮` 不完备时，结论只能是「在 `𝒮` 上负载」，不能外推为「在真实世界负载」。

**定义 441（蒸馏创新证书 DIC）** 对候选主张 `c`（其 AIU 集为 `U(c)`），
`DIC(c) = (N_α(c), N_q(c), scores, receipts, ledger_refs, critics, hash)`：
- `N_α(c) ⊆ U(c)` 是保形 novelty 集：在可交换性下，真实负载且 novel 的单元以 `≥1−α` 概率被包含；
- `N_q(c) ⊆ N_α(c)` 是用 BH 在水平 `q` 下做 FDR 控制后的选择；
- `c` 是**已蒸馏**的当且仅当它只引用 `N_q(c)` 中的单元，且其中每个数值 token 都绑定有效回执（继承定义 423/427）。
未蒸馏主张在 EC 序列化时剥离；剥离是纯投影，不改变任何数值行为。
DIC 证明的是「**相对本账本、本压力套件，这条主张新在哪**」，不是「这条主张为真」。

**定义 442（微创新）** `MI(u) = LB(u) / Footprint(u)`，`Footprint` 为文本/代码/算力/测试成本。
`MI` 高而 `Footprint` 小的单元是**微创新**：一行修正可能改变整个契约的风险方向。
微创新必须在第二个独立压力套件上复现，否则只标记为「候选」，不进入 `N_q`。
这是微表情的认知对应物：低幅度、短时长、高信息量，靠显著性看不出，靠反事实才抓得到。

**定义 443（多评审校准）** 评审 `k=1..K`（符号检查器、反事实消融、人类专家、跨轮审计器）输出
`s_k(u) ∈ [0,1]` 与理由。每个评审在留出审计集上做温度缩放；聚合 `s(u) = Σ w_k s_k(u)`，
并计算分歧熵 `H(s₁..s_K)`。若 `H > θ_dis`，**加宽** `N_α` 或弃权，绝不收窄。
评审独立性按「同谱系/同作者/同模型」去相关，得到有效评审数 `K_eff`；`K_eff < 2` 时只允许「候选」，不允许「蒸馏」。

**定义 444（蒸馏核 D-Core）** `D = Calibrate ∘ Verify ∘ Subtract ∘ Decompose`：
- Decompose：脸 → AU/NSP 序列；artifact → AIU；
- Subtract：脸 → 主体中性基线；artifact → 跨轮谱系账本；
- Verify：脸 → 时序/微表情 + 保形集；artifact → 反事实 `LB` + 多评审 + FDR；
- Calibrate：脸 → 保形覆盖率 + 弃权；artifact → DIC + 弃权。
两个实例共享同一个失败判据：**不能分解、不能扣基线、不能过验证、不能弃权 ⇒ 不输出结论**。
`D` 的输出是软证书，**永不写入数值契约**。

**定义 445（主张膨胀断路器 I-Quarantine）** 监控
`infl = |claims(c)| / |N_q(c)|`、
`relabel = |{u : Nov(u)=0 ∧ 被当作新}| / |claims|`、
`drift = D_KL(𝕃_t ‖ 𝕃_{t−r})`。
若 `infl > θ_infl` 或 `relabel > θ_relabel` 连续 `r` 轮，触发**创新隔离**：
冻结所有 novelty 语言、要求外部审计、把 EC.claims 退化为仅含回执绑定事实、必要时退回 ToolGauge。
这是 P-Quarantine 的元层对应物：防止研究循环**自我欺骗式地越写越新**。

**定义 446（跨轮谱系账本）** `𝕃 = (u_i, σ_i, evidence_i, verdict_i, parent_i, hash_i)`，只追加、哈希链；
`verdict ∈ {genuine, equivalent, decoration, defect, unknown}`。
无法在账本中定位的「创新」一律不蒸馏；同一概念换名但行为签名相同者标为 `equivalent`。
账本是研究循环的**制度记忆**，也是防止跨轮重命名的唯一可靠依据。

**定义 447（继承与退化）** 未重定义者沿用定义 398–431；令 `F-Box=∅`、`N-Box=identity`、`D-Core=∅`
⇒ FacetGauge ≡ ToolGauge。
退化链：FacetGauge ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE。
具体地：F-Box 无效/未同意 ⇒ 无面部否决，物理包络 + 高风险显式确认；
N-Box 无效/为空 ⇒ 剥离所有 novelty 主张，只保留 ToolGauge 回执绑定事实；
D-Core 失败 ⇒ ToolGauge；再失败按第 2 轮链退化。

## 4. 关键算法骨架

```python
# IP-321 F-Box：端侧 AU + 主体基线 + 保形非语言集 + 微表情前兆
@dataclass
class FReceipt:
    au: np.ndarray          # A ∈ [0,1]^{T×K}，端侧提取
    q: np.ndarray           # 质量：姿态/遮挡/光照/活体
    E: set                  # 保形显示层模式集
    v: float                # 保守风险上界
    micro: dict             # {onset, latency}
    sig: str; ts: int; seq: int; consent_id: str

class FBox:
    def observe(self, frame, operator):
        if not consent(operator):                  return None
        au = on_device_au(frame)                   # 原始帧不出设备
        if not quality_ok(au.q):                   return None      # 弃权
        a  = normalize(au.A, baseline[operator])   # 主体中性基线
        E  = conformal_set(a, alpha=0.1)           # 显示层 NSP，不是情绪
        v  = max(risk(e) for e in E)               # 保守上界
        m  = spot_micro(a, h)                      # 1/25–1/5 s 前兆
        return FReceipt(a, au.q, E, v, m, sign(), now(), next_seq(), consent(operator))

# IP-322 V-Box：只否决的包络收缩（全部分量 ≤ 1）
def contract_envelope(E0, F):
    if F is None:                                  # 未同意/不可用
        return E0, "high_risk_requires_confirmation"
    if F.v >= V_STOP or F.micro.get("onset", False):
        return tighten(E0, KAPPA * F.v), "stop_or_confirm"
    return tighten(E0, KAPPA * F.v), "ok"          # tighten 内部 clamp 到 E0

# IP-323 N-Box：AIU 分解 + 谱系扣除 + 反事实负载性 + 保形/FDR
class NBox:
    def distill(self, prev_ec, new_ec, receipts):
        units = decompose(minimal_diff(prev_ec, new_ec))      # AIU
        for u in units:
            u.nov = 1.0 - max_sim(u, self.ledger)             # 行为签名优先
            u.lb  = ablation_damage(new_ec, u, self.stress)   # 去掉 u 再跑契约
            u.ev  = bind(u, receipts)                         # 无回执 ⇒ 不蒸馏
        scores = [self.critics.score(u) for u in units]
        N_alpha = conformal_select(units, scores, alpha=0.1)
        N_q     = bh_select(N_alpha, q=0.1)
        return DIC(N_q, units, receipts, self.ledger, self.critics)

# IP-324 D-Core：两个实例共享的四段算子
def D(evidence, prior, kind):
    units     = decompose(evidence, kind)          # AU/NSP 或 AIU
    residuals = subtract(units, prior)             # 主体基线 或 谱系账本
    verified  = verify(residuals, kind)            # 时序/保形 或 反事实/FDR
    return calibrate(verified, kind)               # 集合 + 弃权

# IP-326 主闭环：只收紧、只删主张，50Hz 路径不动
def FacetGauge_round(M, obs, audio, tac, depth, det, frame, operator):
    F = M.fbox.observe(frame, operator) if M.probing else None
    E, mode = M.vbox.contract_envelope(M.env.envelope, F)
    M.env.set_envelope(E)                          # 只会变小，不会变大
    if mode != "ok":
        M.env.require_confirmation(mode)
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s); submit_async(toolgauge_6c, M, s)   # 继承
    if M.pquar.triggered():
        M.apcal.pause(); M.use_bpcal_fallback = True             # 继承
    return MODGAUGE_round(M, obs, audio, tac, depth, det)

# 修复成功后：蒸馏证书 + 剥离未蒸馏主张
def after_repair(M, s):
    if not M.last_repair_ok: return
    dic = M.nbox.distill(M.prev_ec, M.ec, M.receipts)
    M.ec.claims = strip_undistilled(M.ec.claims, dic)
    M.ledger.append(dic)
    if M.iquar.update(dic): M.iquar.trigger()      # 定义 445
```

## 5. 推导（引理 51–56）

**引理 51（否决单调性与安全下界）** 对任意有效 `F`，`E(F) ⊆ E⁰` 逐分量成立；若 `F` 无效或未同意，
`E = E⁰` 且高风险探测要求显式确认。因此 F-Box 的任意误判都不会使任何探测包络分量增大；
「把不适读成平静」至多导致**漏预警**，不会导致**超包络**。
证明：`E(F) = (1−κv)⊙E⁰`，`κv ∈ [0,1]`；所有代码路径 `tighten` 均 clamp 到 `E⁰`；
无效分支只走 `E⁰` + 确认门，不走上界扩张。系：F-Box 不是安全证明，而是**安全方向上的单向阀**。

**引理 52（主体漂移下的保形覆盖）** 若校准与部署在主体/文化/光照分组内可交换，则每组
`P(e* ∈ E_α(F)) ≥ 1−α`；若组间 TV 漂移为 `η_p`，则覆盖 `≥ 1−α−2η_p`（加权保形可恢复至 `1−α−η_pL`）。
若某组覆盖低于 SLA，按定义 434 弃权；弃权不放松包络，只要求高风险显式确认。
证明：Mondrian 保形 + 标准 TV 传输不等式；DP 噪声下需用同一噪声机制重校准。

**引理 53（微表情前兆的检测延迟界）** 在基线 AU 噪声独立亚高斯（方差 `σ²`）、微事件幅度 `μ`、窗口 `w` 下，
匹配滤波阈值 `h` 的检测延迟满足
`E[τ] ≤ w + 2σ² log(1/β)/μ²`
以概率 `≥1−β`；前置时间 `L = t_stop − t_detect` 由事件到显式停止的间隔决定。
证明思路：窗口内 Hoeffding 界 + 变化点检测的标准延迟-虚警权衡；`w` 项来自窗口填充。
系：微表情只能给出「提前量」，其价值由 `P(L ≥ L_min)` 衡量，不由分类准确率衡量。

**引理 54（创新蒸馏的 FDR 与覆盖率）** 假设：
(A1) 在谱系分层内，零假设单元（行为等价于旧单元）与对照可交换；
(A2) 零假设下评审 p 值超均匀；
(A3) 压力套件 `𝒮` 对损伤泛函 `D` 是**契约完备**的（或结论显式条件于 `𝒮`）。
则 BH 在水平 `q` 下控制 `FDR ≤ q`；保形选择使真实负载且 novel 的单元以 `≥1−α` 概率落入 `N_α`。
若 `σ_u = σ_v`（行为等价），定义 439 直接令 `Nov=0`，该单元不可能进入 `N_q`——**重命名不能制造 novelty**。
证明：BH 的标准 FDR 定理；保形选择用非一致性分数 + 可交换性；谱系等价由行为签名定义，先于统计检验排除。
**推论 54.1**：若 `𝒮` 不完备，则 `LB` 只证明「在 `𝒮` 上负载」；这不是定理的漏洞，而是必须在 DIC 中显式写出的**适用范围**。

**引理 55（语言层不破坏热替换等价性）** N-Box 只删除/重写 `EC.claims`，不改变 `u_fields` 与 `χ_R`；
DIC 是元数据；未蒸馏主张的剥离是纯投影。故子图数值等价性与第 2 轮引理 49 相同；
若 N-Box 失败，剥离所有 novelty 主张后退回 ToolGauge 证书，数值行为不变。
证明：与引理 49 同构；`claims` 不在任何数值计算路径上。

**引理 56（时序与预算保持）** F-Box 仅在被显式标记为 PROBING 的异步窗口内运行，端侧 `O(T·K)`；
N-Box 仅在修复成功后异步运行，`O(|ΔC|·|𝒮| + |𝕃|·d)`；
50Hz 路径新增的只有 `O(1)` 的包络查表与 `O(1)` 的确认门标志，`< 0.1 ms`。
所有失败走退化链 ⇒ 第 2 轮引理 50 的硬实时与预算结论保持。
证明：新增计算均在异步事件域；同步路径只读缓存包络；退化链保证最坏情况回到已验证路径。

| `r_disp / ψ_int` | 显示规则 / 内部状态；`ψ_int` 不可识别，不进入任何决策 |
| `NSP / E_disp` | 非语言安全模式 / 显示层模式空间（定义 433） |
| `A_p^0 / E_α(F)` | 主体 `p` 的中性基线 / 保形非语言集（定义 434） |
| `v(F) / micro(F)` | 保守风险上界 / 微表情前兆（定义 434/435） |
| `E⁰ / E(F) / κ` | 标称包络 / 收缩后包络 / 收缩增益（定义 436） |
| `consent_id, ε_dp` | 同意标识与差分隐私预算（定义 437） |
| `u = (ΔC,E_u,L_u,σ_u)` | 原子创新单元 AIU（定义 438） |
| `Nov(u)` | 谱系扣除后的 novelty 残差（定义 439） |
| `LB(u) / δ_LB` | 反事实负载性 / 负载阈值（定义 440） |
| `N_α(c) / N_q(c)` | 保形 novelty 集 / FDR 选择集（定义 441） |
| `MI(u)` | 微创新分数 = `LB/Footprint`（定义 442） |
| `K_eff` | 去相关后的有效评审数（定义 443） |
| `D` | 四段蒸馏核（定义 444） |

| `𝕃` | 跨轮谱系账本（定义 446） |

## 2. 形式化定义（要点）

**定义 432（NER）** 回执含 AU 序列、质量、签名、时间戳、单调序号、同意标识；原始像素不出设备；无效回执永不进入风险/创新判定。
**定义 433（显示规则混淆）** `A = g(ψ_int, r_disp, p, c, o) + ε`；`r_disp` 未知时 `ψ_int` 不可识别。F-Box 只输出显示层 NSP 风险 `v(F)`，明确禁止 `P(emotion|A)` 进入决策。
**定义 434（主体基线 + 保形集）** `Ã = A − A_p^0`；`E_α(F) = {e : s(F,e) ≤ τ}`；`v(F)=max_{e∈E_α} risk(e)`；按主体/文化/光照做 Mondrian 分组，覆盖率跌破 SLA 即弃权。
**定义 435（微表情）** 时长 1/25–1/5 s、低幅度 AU 轨迹；匹配滤波检测；只用于提前收紧，不作证据。
**定义 436（Veto-Envelope）** `E(F)=(1−κv)⊙E⁰`；逐分量 ≤ `E⁰`；`v≥v_stop` 或微表情 onset ⇒ 停止/显式确认；任何路径不得把分量乘 >1。
**定义 437（同意/隐私）** 端侧、DP 统计量、不识别身份、可退出、保留期受限；保形校准与 DP 噪声同机制。
**定义 438（AIU）** 最小契约改动 + 证据 + 谱系 + 行为签名；可拆则必须拆；IP 是 AIU 的包，不是原子。
**定义 439（谱系扣除）** `Nov(u)=1−max_v Sim(u,v)`；行为签名相同即 `Nov=0`，文本相似度不用于判定 novelty。
**定义 440（反事实负载性）** `LB(u)=D(C)−D(C\u)`；`LB<0` ⇒ 缺陷；结论条件于压力套件 `𝒮`。
**定义 441（DIC）** `N_α` 保形 novelty 集 + `N_q` BH/FDR 选择；主张只能引用 `N_q` 且数值绑定回执；未蒸馏主张剥离为纯投影。
**定义 442（微创新）** `MI=LB/Footprint`；高 MI 低 footprint 的单元，必须在第二独立套件复现才可入 `N_q`。
**定义 443（多评审）** 温度缩放 + 分歧熵；分歧大则加宽/弃权；`K_eff<2` 只允许「候选」。
**定义 444（D-Core）** `D=Calibrate∘Verify∘Subtract∘Decompose`；两个实例共享同一失败判据；输出软证书，不写数值契约。
**定义 445（I-Quarantine）** `infl/relabel/drift` 连续越界 ⇒ 冻结 novelty 语言、外部审计、退化到 ToolGauge。
**定义 446（谱系账本）** 只追加、哈希链、`verdict` 五值；无法定位的「创新」不蒸馏；行为等价者标 `equivalent`。
**定义 447（继承/退化）** `F-Box=∅, N-Box=identity, D-Core=∅ ⇒ FacetGauge≡ToolGauge`；严格链 FacetGauge⇒ToolGauge⇒LeanGauge⇒MODGAUGE。

## 3. 关键算法骨架

```python
# IP-321 F-Box：端侧 AU + 主体基线 + 保形非语言集 + 微表情前兆
@dataclass
class FReceipt:
    au: np.ndarray; q: np.ndarray; E: set; v: float; micro: dict
    sig: str; ts: int; seq: int; consent_id: str

class FBox:
    def observe(self, frame, operator):
        if not consent(operator):                 return None
        au = on_device_au(frame)                  # 原始帧不出设备
        if not quality_ok(au.q):                  return None          # 弃权
        a  = normalize(au.A, baseline[operator])  # 主体中性基线
        E  = conformal_set(a, alpha=0.1)          # 显示层 NSP，不是情绪
        v  = max(risk(e) for e in E)              # 保守上界
        m  = spot_micro(a, h)                     # 1/25–1/5 s 前兆
        return FReceipt(a, au.q, E, v, m, sign(), now(), next_seq(), consent(operator))

# IP-322 V-Box：只否决的包络收缩
def contract_envelope(E0, F):
    if F is None:
        return E0, "high_risk_requires_confirmation"
    if F.v >= V_STOP or F.micro.get("onset", False):
        return tighten(E0, KAPPA * F.v), "stop_or_confirm"
    return tighten(E0, KAPPA * F.v), "ok"         # tighten 内部 clamp 到 E0

# IP-323 N-Box：AIU 分解 + 谱系扣除 + 反事实负载性 + 保形/FDR
class NBox:
    def distill(self, prev_ec, new_ec, receipts):
        units = decompose(minimal_diff(prev_ec, new_ec))      # AIU
        for u in units:
            u.nov = 1.0 - max_sim(u, self.ledger)             # 行为签名优先
            u.lb  = ablation_damage(new_ec, u, self.stress)   # 去掉 u 再跑契约
            u.ev  = bind(u, receipts)                         # 无回执 ⇒ 不蒸馏
        scores = [self.critics.score(u) for u in units]
        N_alpha = conformal_select(units, scores, alpha=0.1)
        N_q     = bh_select(N_alpha, q=0.1)
        return DIC(N_q, units, receipts, self.ledger, self.critics)

# IP-324 D-Core：两个实例共享的四段算子
def D(evidence, prior, kind):
    units     = decompose(evidence, kind)          # AU/NSP 或 AIU
    residuals = subtract(units, prior)             # 主体基线 或 谱系账本
    verified  = verify(residuals, kind)            # 时序/保形 或 反事实/FDR
    return calibrate(verified, kind)               # 集合 + 弃权

# IP-326 主闭环：只收紧、只删主张，50Hz 路径不动
def FacetGauge_round(M, obs, audio, tac, depth, det, frame, operator):
    F = M.fbox.observe(frame, operator) if M.probing else None
    E, mode = M.vbox.contract_envelope(M.env.envelope, F)
    M.env.set_envelope(E)                          # 只会变小
    if mode != "ok": M.env.require_confirmation(mode)
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s); submit_async(toolgauge_6c, M, s)   # 继承
    if M.pquar.triggered():
        M.apcal.pause(); M.use_bpcal_fallback = True             # 继承
    return MODGAUGE_round(M, obs, audio, tac, depth, det)

# 修复成功后：蒸馏证书 + 剥离未蒸馏主张
def after_repair(M, s):
    if not M.last_repair_ok: return
    dic = M.nbox.distill(M.prev_ec, M.ec, M.receipts)
    M.ec.claims = strip_undistilled(M.ec.claims, dic)
    M.ledger.append(dic)
    if M.iquar.update(dic): M.iquar.trigger()      # 定义 445
```

## 4. 推导（引理 51–56）

**引理 51（否决单调性）** `E(F) ⊆ E⁰` 逐分量成立；F-Box 无效/未同意 ⇒ `E=E⁰` + 高风险确认门。
任意面部误判都不会扩大探测包络；最多漏预警，不会超包络。证明：`κv∈[0,1]` + `tighten` 的 clamp + 无效分支只走 `E⁰`。
**引理 52（主体漂移下保形覆盖）** 组内可交换 ⇒ 每组覆盖 `≥1−α`；组间 TV 漂移 `η_p` ⇒ `≥1−α−2η_p`；低于 SLA 弃权（弃权不放松包络）。
**引理 53（微表情检测延迟）** 基线 AU 噪声独立亚高斯（方差 `σ²`）、事件幅度 `μ`、窗口 `w`、阈值 `h`：
`E[τ] ≤ w + 2σ² log(1/β)/μ²` 以概率 `≥1−β`。微表情的价值由 `P(L≥L_min)` 衡量，不由分类准确率衡量。
**引理 54（创新蒸馏 FDR/覆盖）** 在谱系分层内零假设可交换、零假设 p 值超均匀、`𝒮` 对 `D` 契约完备的条件下，
BH 控制 `FDR≤q`；保形选择使真实负载且 novel 的单元以 `≥1−α` 落入 `N_α`；行为等价单元由定义 439 直接排除，
**重命名不能制造 novelty**。推论：`𝒮` 不完备时结论只能是「在 `𝒮` 上负载」，必须在 DIC 中显式标注适用范围。
**引理 55（语言层不破坏热替换等价性）** N-Box 只改 `claims`，不改 `u_fields/χ_R`；DIC 是元数据；
未蒸馏主张剥离为纯投影；N-Box 失败则退回 ToolGauge 证书，数值行为不变（同第 2 轮引理 49）。
**引理 56（时序/预算保持）** F-Box 仅在 PROBING 异步窗口；N-Box 仅在修复成功后异步；
50Hz 路径只多 `O(1)` 包络查表与确认门标志（`<0.1 ms`）；退化链保证硬实时与预算不变式（继承第 2 轮引理 50）。

## 8. 本轮最大风险

**一句话**：N-Box 的「负载性」与 F-Box 的「群体校准」都依赖**预注册的有限套件/有限主体**；
一旦真实失效模式落在套件之外，系统会以「已蒸馏、已校准」的证书保留错误创新、放过真实不适——
这把有偏的尺子会把**测量偏差**包装成**可审计的安全感**，而这正是本轮最危险的地方。
