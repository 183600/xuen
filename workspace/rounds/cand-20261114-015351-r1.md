# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配×主动交互不确定性二分闭环」IP-253~263；本轮灵感：「夹爪控制」×「数据集构建」）

> R69 让闭环第一次学会「问」：把 epistemic 歧义交给看/问/触，用 VoI 判断值不值得问，用「k 个正交证据一致」防止单源定案。但它悄悄默认了两件从未被检验的事：**(A) 信息动作近似可逆、且不改变被问对象**；**(B) 流模型的模态分布来自一个可信、充分的数据源**。本轮两个灵感正好从物理层与数据层同时击穿这两个默认。
>
> - **夹爪控制**：接触是所有「问」里最值钱、也最危险的一种。它不可逆——夹爪一旦闭合、力一旦加上，就不能「取消触摸」；它内生——探询本身会移动你要估计的位姿、摩擦与接触面，所谓「观测」在接触里就是「干预」；它还带一个毫秒级的隐藏模态——**打滑**。R69 把信息当成免费快照、把 `cost(g)` 只记成物理/社交开销，在接触场景会系统性地**过度触摸**。
> - **数据集构建**：R69 最恐惧的「模态被幻觉 / 被坍缩」根本不是运行时校准问题，而是**数据覆盖与可识别性**问题。如果记录策略从不从左侧接触，那「左侧接触模态」在数据里就不存在，再好的 ECE 校准也救不回来；更糟的是，在线交互本身就是数据采集，而策略依赖的日志天然带**选择偏差与混杂**——数据集的构造方式决定了模型明天「看得见哪些模态」。
>
> 核心命题：**把「决策时的信息」与「数据集里的信息」合并成同一套接触信息经济学：每一次接触探询同时支付（i）任务 VoI、（ii）不可逆性/期权价值损失、（iii）接触风险，并赚取（iv）一份可沉淀的数据资产（元信息价值）；离线则用「干预式实验设计」构造一份让模态可识别、可校准、可追溯的数据集。物理先剪一刀（摩擦锥证书），数据再盖一票（可识别性门），两者任一不过就退回 R69 的纯保守。** 命名 **GRASP-RAS**（Gripper-contact, Reversibility-aware Active Sensing with Provenance-corrected data）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这一摸付得起吗——而且我今天摸到的东西，明天还学得会吗**」。信息不只是刹车踏板或一句提问，也可以是一只**不可撤销、会改变世界、并顺手写进训练集的夹爪**。

## 0. 直觉与动机

**灵感 1（夹爪 → 信息是破坏性的：触摸会改变被触摸者的未来）**
直觉：R69 的 VoI(g)=H(M|o)−E[H(M|o,y)] 默认「问完世界还是原来那个世界」。但接触不是读盘，是写盘：探针压下去，物体可能转、可能滑、可能被压出凹痕；夹爪闭合，就把「还可以从别的方向抓」这个期权作废了。于是信息动作的真实代价里有一项**期权价值损失**（option value loss）——你为了看清一个模态，永久关掉了另外一些模态。当物体易碎、姿态临界、或摩擦未知时，「再摸一下」甚至比「先不动、等一帧视觉」更危险。这不是给 `cost(g)` 加个常数能修的，它要求把「等待/不探询」（deferral）提升为一等动作，并显式给「保留选择权」定价。

**灵感 2（夹爪 → 接触模态是混合系统的隐藏状态，而物理是免费的先验）**
直觉：抓取不是一个连续动作块，而是一条**接触状态机**：接近 → 首次接触 → 力爬升 → 粘着 → 临界滑移 → 宏观滑移 → 释放。每一步的模态（是否接触、是否打滑、是否力闭合）都是隐藏的，而触觉常被夹爪自身遮挡。R69 的流策略可以天然扩展成「接触条件流」v_θ(x_s,s|o,c)，让模态显式化。更关键的是：**摩擦锥/力闭合/压碎极限**给了 R69 那个最怕的「幻觉模态」一个不依赖学习、不依赖校准的物理剪枝器——一个在力/位/摩擦锥里根本执行不了的模态不是假设，是幻觉。于是「模态可信吗」被拆成两问：物理上做得到吗（摩擦锥证书，硬约束）＋数据上见得多吗（可识别性门，统计约束）。

**灵感 3（数据集 → 模态分布其实是关于数据集的一句陈述）**
直觉：流模型说「绕左 0.6、绕右 0.4」，这句话的真实含义是「我的训练集里左模态占 0.6、右模态占 0.4」。R69 用 ECE 校准这个权重，但校准只能修正**已经出现过的模态**的置信度，无法凭空创造覆盖。若记录策略是确定性的（总从同一侧接近），模态后验就不可识别，ECE 再低也是在一个有偏支撑集上的自洽。所以 R69 最大风险的根因在数据侧：**覆盖（coverage）+ 正性/重叠（positivity）+ 出处（provenance）**。修法不是加一个运行时校对器，而是把「造数据集」当成一个**主动实验设计**问题：选哪些交互、哪些干预、哪些反事实标注，才能让接触模态可识别、可校准。

**灵感 4（数据集 → 交互即采集，所以 VoI 必须为「未来的模型」付一笔元价格）**
直觉：R69 里每一次「看/问/触」执行完就被审计、丢弃；但在 R70 里它同时是一条带出处标签的训练样本。于是存在**双时间尺度收益**：这一刻降低任务歧义（任务 VoI），同时降低明天模型的认知不确定性（元信息价值 MIV）。把二者放进同一个目标，就得到「边做边学、边学边选数据」的飞轮。但飞轮有暗面：如果只奖励「采集我已经会判别的模态」，模型会越来越自信于自己熟悉的那一小块世界（马太效应），罕见却致命的接触模态（如低摩擦斜面）会被几何式遗忘。**所以数据集构造必须带探索地板，和模型侧一样需要一个「可识别性门」。**

**灵感 5（两个时间尺度，一种货币 → 新层必须严格包含 R69）**
直觉：任务信息与数据信息本质是同一种东西（熵的下降），只是折现率不同。把它们写成统一的 RIV（reversibility-aware information value），并把 R69 的 VoI 当作「接触可逆、β=0、数据门通过」的退化边界：此时 RIV 逐项退化为 R69 的 VoI−c，行为逐指令一致，安全侧只增不减。这延续 R69 自己立下的规矩——**新层是旧层的严格泛化，不是并列替代**；否则每加一层就多一个必须独立信任的黑箱。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（GRASP-RAS 总览）** GRASP-RAS = (GCM, RIV, EIM, FCC, SIP, MIV, DCP, IDG, PAC, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i、R69 定义 293-i）——在线只记录、不训练；
(ii) **不可逆信息动作双重门**：任何不可逆接触探询 g 必须同时满足 RIV(g)>0 与 FCC 证书（定义 316、318）；
(iii) **数据出处纪律**：每条进入训练集的交互必须带行为策略倾向 π_b(g|o)、干预标记、来源与哈希；无出处数据不得用于模态/校准训练（定义 320）；
(iv) **可识别性纪律**：只有当 IDG 通过时，模态推理与 VoI 才被启用；否则退化为 R69 的纯保守（定义 322、327）。

**定义 311（接触增广动作空间）** 任务动作 a ∈ 𝒜_task；夹爪动作 a_grip = (w, f, K, v) ∈ 𝒜_grip（开度、夹持力、阻抗刚度、腕部增量）；信息动作 g = (g_gaze, g_probe, g_ask) ∈ 𝒜_info，其中 g_probe 现在是**一段受力的接触轨迹**而非一次快照。增广动作 ξ = (a, a_grip, g) ∈ 𝒜_+ = 𝒜_task × 𝒜_grip × 𝒜_info。策略 π_θ(ξ_{t:t+H} | o_t)。

**定义 312（夹爪接触状态机与接触条件流）** 接触模态 c_t ∈ 𝒞 = {free, C1 首次接触, C2 粘着, C3 临界滑移, C4 宏观滑移, C5 释放}。混合自动机由触觉法向/切向力、开度、滑移速度的守卫（guard）驱动。接触条件速度场 v_θ(x_s, s | o_t, c)，接触头 p_φ(c | o_t)。**完整模态** m = (c, 轨迹模态)，把 R69 定义 296 的几何聚类升级为「接触 × 轨迹」联合模态。

**定义 313（接触可观测性）** 接触模态 c 可观测，当且仅当存在有限探询策略使触觉/力/视觉签名把 c 与其他模态分离；因夹爪自遮挡，部分模态只能在**动态探询**（滑动、轻抖、力扫描）中显现。定义可观测矩阵 O_c 与最小分离探询代价，作为 MINT 候选信息动作的可行性下界。

**定义 314（内生观测模型 EIM）** 探询的观测不再是 p(y|g,o)，而是联合转移 (y, o′) ~ p(y, o′ | g, o)，其中 o′ = T(g, o, w) 由世界状态 w 与探询物理效应共同决定。R69 的静态 VoI 恰是 T = id（世界冻结）的退化情形。**探询改变被估计对象**是接触区别于注视/提问的本质。

**定义 315（不可逆度与期权价值损失）** 设 V(𝒮(o)) 为当前可达抓取/操作选择集的期权价值，探询后可达集缩为 𝒮(o′)。定义 Irr(g) = E[V(𝒮(o)) − V(𝒮(o′))] ≥ 0（含物体损伤/位姿锁死的等价损失）。闭合夹爪、施加不可回退力、把物体压向单一接触面都会抬高 Irr。

**定义 316（不可逆感知 VoI：RIV）** 候选信息动作 g 的净值为
RIV(g) = VoI_end(g) − c(g) − λ_irr·Irr(g) + β·MIV(g)，
其中 VoI_end(g) = H(M|o) − E_{o′~p(·|g,o)}[H(M|o′)]（内生增益），MIV 见定义 317。选择 g* = argmax_g RIV(g) s.t. FCC(g) ∧ 预算。**deferral 是一等动作**：若 RIV ≤ 0 或无证书动作，则不探询、走 R69 兜底；「等待/再看一帧」可作为候选 g 与探询公平竞争。

**定义 317（元信息价值 MIV）** MIV(g) = E[H(θ | D) − H(θ | D ∪ {(o,g,o′)})]，即新增该交互对模型参数/校准映射的认知熵的期望下降（θ 含接触条件流与模态头）。可用 Fisher 信息 D-最优性或集成 disagreement 近似；长时程、按折现 γ 记账。

**定义 318（摩擦锥接触证书 FCC）** 对夹爪动作的接触模型做小规模鲁棒 QP，计算力闭合裕度 m_fc（摩擦锥内）、压碎裕度 m_c = f_max/f（含不确定度）、滑移裕度 m_s = μN/|F_t| − 1。证书 Valid ⇔ 三者 ≥ 阈值且预测接触加速度有界。FCC 只剪枝、不生成，因此永不放大风险。

**定义 319（临界滑移的二分 SIP）** 把滑移相关不确定性拆为 U_ale（触觉噪声、物体微变形）与 U_epi_slip（「在滑」vs「在弹性形变」的身份歧义）。因验证动作不可逆，临界滑移带硬 deadline τ_slip：过了 τ_slip 再问就只剩「掉」。SIP 复用 FMA 的流似然第二意见，但条件在接触模态 c 上：Δa_c↑ 且切向力导数越界 ⇒ 临界滑移疑。

**定义 320（交互-数据同构与出处标签）** 每次执行交互产生记录 r = (o, a_grip, g, c, y, o′, π_b(g|o), intervention_flag, source, hash)。策略依赖的混杂来自 π_b：确定性的 π_b 会让某些模态永远不被记录（正性破坏）。出处是数据可被用于训练的先决条件。

**定义 321（数据集构造目标 DCP）** 给定原始池 D_raw，选出训练集 D_train 与分层校准集 D_cal：
max_D [Coverage(D) + λ_id·Identifiability(D)]
s.t. provenance(D) 完整、每模态校准样本 ≥ n_min、投毒鲁棒。
Coverage 取接触模态 × 物体 × 摩擦 × 接近方向的**设施选址（facility location）**子模目标；Identifiability 取模态-动作空间上的正性/重叠与有效样本量。

**定义 322（可识别性-数据门 IDG）** 数据级门控，检查：每模态覆盖 ≥ n_min、倾向性与重叠满足（positivity）、ESS ≥ τ_ess、每模态 ECE ≤ τ_ece。任一不过 ⇒ 模态权重不可识别，禁用 VoI/模态推理、放大兜底不确定度。IDG 是 R69 MCG 的**上游对偶**：MCG 管「运行时校准准不准」，IDG 管「用来校准的东西存不存在」。

**定义 323（出处感知纠偏 PAC）** 用倾向性逆概率加权（IPW，裁剪到 [p_min,1]）或分层重加权，把策略依赖日志校回目标分布；报告有效样本量 ESS = (Σw)²/Σw²。ESS < 阈值即视为不可识别，交由 IDG 拒绝。

**定义 324（数据集威胁模型 AIC-DATA）** 接触模态标签翻转、虚假相关（纹理↔摩擦）、幸存者偏差（只记录成功抓取）、反馈投毒（污染日志污染下一代模型）。ℰ_GRASP = ℰ_FLUID × ℰ_dataset，并入对抗训练与审计。

**定义 325（参与式数据审计 VQAuditor-D）** 在 R69 VQAuditor-I 之上审计数据集构造：出处完整性、覆盖声明是否属实、标签泄漏、幸存者偏差、投毒簇。审计结论回灌 IDG 与 DCP 的成本/约束。

**定义 326（证书 J_GRASP）** J_GRASP = (J_FLUID, coverage_vector, idg_verdict, ess, propensity_hash, contact_mode_ece, fcc_margin_p05, dataset_hash, grasp_ver)。Valid ⇔ Valid(J_FLUID) ∧ IDG 通过 ∧ 出处完整 ∧ FCC 未越界。

**定义 327（主闭环与两级退化）** 每轮：接触条件 FMP → FCC 认证 → RIV 选探询（含 deferral）→ 执行并带出处记录 → 周期性 DCP/IDG。任一门失败（FCC 不过 / RIV≤0 / IDG 不过 / 投毒 / 超时）⇒ 退回 R69 的 λ_floor 保守。当接触可逆（Irr=0）、放弃数据价值（β=0）、且 IDG 通过时，GRASP 逐指令退化为 FLUID-RAS。

# IP-264 GCM：接触条件流策略（复用 R69 MTM trunk 与 FMP 速度场）
class ContactConditionedFlow:
    def sample(self, o_t, c_hat, K, N_step=2):
        z  = self.trunk(o_t)
        xs = randn(K, D)
        for i in range(N_step):
            xs = xs + (1.0 / N_step) * self.v(xs, i / N_step, z, c_hat)  # 条件在接触模态
        return [self.decode(x) for x in xs]                              # ξ=(a,a_grip,g)

# IP-267 FCC：摩擦锥接触证书（物理先剪枝，不学习）
def certify_contact(g, o):
    m = contact_qp(g, o)                      # 力闭合 / 压碎 / 滑移裕度
    return Cert(safe=(m.fc >= M_FC and m.crush >= M_C and m.slip >= M_S), margins=m)

# IP-265/266/269 MIV 与不可逆感知 VoI（含 deferral）
def choose_contact_probe(modes, w, o, policy, budget):
    best = None
    for g in contact_probe_candidates(modes) + [DEFER]:          # 等待也是一等动作
        if not budget.allow(g):                       continue
        cert = certify_contact(g, o)
        if not cert.safe:                             continue
        voi   = endogenous_voi(w, g, o, policy)       # o' = T(g,o)，非冻结世界
        irr   = option_value_loss(g, o)               # 关掉的未来选择
        miv   = meta_info_value(g, o, policy.ensemble)  # 对明天模型的信息
        score = voi - cost(g) - LAM_IRR * irr + BETA * miv
        if best is None or score > best.score: best = (g, score, cert)
    return best if best and best.score > 0 else None   # 净值为负 → R69 兜底

# IP-270/272 DCP：干预式数据集构造（子模覆盖 + 倾向性纠偏 + 分层校准）
def construct_dataset(D_raw, budget):
    D = ipw_reweight(D_raw, propensities=D_raw.propensity, clip=P_MIN)  # PAC
    selected = []
    while budget.allow():
        r = argmax(D - selected, key=lambda x: coverage_gain(selected, x)
                                             + LAM_ID * ident_gain(x))
        if coverage_gain(selected, r) + LAM_ID * ident_gain(r) <= 0: break
        selected.append(r)
    D_cal = stratified_sample(selected, key='contact_mode', per_mode='proportional')
    return assemble(selected, D_cal)

# IP-271 IDG：数据级可识别性门
def identifiability_gate(D):
    if min(per_mode_counts(D).values()) < N_MIN: return False, 'coverage'
    if overlap(D) < TAU_OVERLAP:                 return False, 'positivity'
    if effective_sample_size(D) < TAU_ESS:       return False, 'confounding'
    if max(per_mode_ece(D)) > TAU_ECE:           return False, 'calibration'
    return True, 'ok'

# IP-276 主闭环（继承 R69，仅在接触/数据处置处插入 GRASP 层）
def GRASP_RAS_round(M, obs):

    c_hat = M.gcm.contact_head(o)
    if not M.idg.passed():                         # 数据不可识别 → 不做模态推理
        return r69_conservative(M, o)
    K = 4 if (c_hat.mode != 'free' or M.fmp.mode_head(z) >= TAU_MODE) else 1
    samples = M.gcm.sample(o, c_hat.mode, K)

    g = M.riv.choose(modes, o, M.budget) if U_epi > TAU_EPI else None
    if g is not None and g is not DEFER:
        rec = M.logger.begin(o, g, M.policy.behavior_propensity(o))  # 出处标签
        answer, o_next = M.gcm.execute(g)          # 探询改变状态（内生）
        U_epi = M.cia.update_belief(modes, answer)
        M.logger.commit(rec, o_next, answer)       # 带 provenance 的数据样本
    U_floor = U_ale + (U_epi if g is None or g is DEFER else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    if g is not None and not certify_contact(g, o).safe:      # 双保险
        lam, k = max(lam, 0.8), min(k, k_cal_shrink(...))
    M.dcp.maybe_schedule(); M.vqa_d.submit_async(g, U_epi, M.dataset_ref)
    return k, lam, select_mode(modes, U_epi, lam), (U_ale, U_epi)
```

## 3. 推导

**引理 19（不可逆折扣）** 对任意信息动作 g，Irr(g) ≥ 0，故 RIV(g) ≤ VoI_end(g) − c(g)（暂时忽略 MIV）。于是 RIV 选出的探询集合是静态 VoI 集合的子集；当 λ_irr·Irr(g) > VoI_end(g) − c(g) 时，最优策略严格偏好 deferral。要点：R69 在接触场景会**过度探询**，且过度量恰等于期权价值损失——不是调参问题，是目标函数漏项。

**引理 20（内生观测偏差）** 静态 VoI = H(M|o) − E_y[H(M|o,y)]；真实内生 VoI_end = H(M|o) − E_{o′}[H(M|o′)]。若 p(o′|g,o) 非退化且模态熵对状态 L-Lipschitz，E‖o′−o‖=δ，则 |VoI_static − VoI_end| ≤ L·δ。系：注视/提问（δ≈0）可用静态 VoI；**力探针（δ 大）必须用内生 VoI**，否则符号都可能反。

**引理 21（策略依赖数据的可识别性）** 设行为策略 π_b(g|o)。若存在正测度状态集使某接触模态 m 的判别性探询 π_b(·|o)=0，则 m 在 D_raw 中不可识别；任何给 m 赋正权重的模型都无法被数据检验。在正性/重叠成立且记录倾向性时，IPW 估计一致：E_{π_b}[π_t(g|o)/π_b(g|o)·f] = E_{π_t}[f]。系：IDG 必须**逐模态**检查正性，而不是只看总体 ECE。

**引理 22（覆盖 → 模态权重校准界）** 在 A95 可分性（Δ_min ≥ 3σ_in）下，若每个模态至少 n_min 个独立样本，则以置信 1−δ 有 |ŵ_k − w_k| ≤ √(log(2K/δ)/(2n_min))。若某模态样本为 0，则不存在有限界——这正是覆盖门的必要性；它是 R69 ECE 门在数据侧的镜像。

**引理 23（数据飞轮的坍缩与探索地板）** 若数据选择/记录策略按 MIV 贪心更新且无探索地板，经验模态分布按 π_{D,t+1} ∝ π_{D,t}(1+η·gain(m)) 演化，初始质量低且测得增益低的模态（常是罕见但安全关键的接触，如低摩擦斜面）几何式衰减到 0。给每个模态设干预采样地板 π_b ≥ ε，可使更新存在唯一内点不动点并阻止坍缩。系：**数据飞轮和模型一样需要门控**，否则「越采越自信」会退化为「越自信越偏」。

**定理 18（GRASP 严格包含 FLUID-RAS）** 在「接触可逆（Irr=0）∧ 放弃数据价值（β=0）∧ IDG 通过」边界上，RIV 逐项退化为 R69 的 VoI−c；FCC 安全集只叠加裕度约束（⊆ 原安全集）；GCM 在 c=free 时退化为 FMP；DCP/PAC 在数据门通过时不影响在线行为。故两者逐指令相同，GRASP 安全侧不做任何让步。

**定理 19（接触安全与无破坏性探询）** 若 FCC 以裕度 ≥ 阈值认证 g，且接触自动机守卫被强制执行，则期望夹持力 ≤ f_max、滑移概率 ≤ ε_slip，且不可逆动作不离开安全抓取集；若认证失败或 RIV ≤ 0，g 作废并执行 R69 的认证前缀。故信息动作不会单调增大物理风险。

**定理 20（子模数据集构造的近似最优性）** 覆盖目标是单调子模；在基数预算下贪心达到 ≥ (1−1/e)·OPT。把可识别性写成划分拟阵（partition matroid）约束后，约束贪心保持 (1−1/e) 近似。故 DCP 对其**声明目标**近最优——但这不保证泛化，泛化仍是本轮最大风险所在。

## 6. 本轮最大风险

**一句话**：GRASP-RAS 的全部收益押在「离线数据集的跨模态覆盖与出处标记是真的」这一前提上——**一旦记录策略只采集自己愿意采集的接触模态、或倾向性/出处被错标，IDG 就会在一份有偏数据上盖章通过，MIV 又反过来奖励「采集已经会的」，形成越采越自信、越自信越偏的自我确认闭环；而接触不可逆，使每一次被确认的错误都可能是最后一次探询。**

**次级风险与缓解**：
1. **接触证书本身近似失效**（摩擦系数未知、接触几何突变）→ FCC 用鲁棒 QP + 保守裕度，且仅作剪枝；失败即退回 R69 兜底（定理 19）。
2. **内生观测建模错误**（T 估计偏）→ 用真实接触动力学残差在线校验 EIM，偏差过大即禁用不可逆探询（引理 20）。
3. **数据飞轮坍缩**（罕见模态被遗忘）→ ε-探索地板 + 逐模态覆盖下限 + IDG（引理 23、E314）。
4. **投毒与幸存者偏差**→ 出处哈希 + 投毒簇检测 + 成功/失败对称记录（定义 324、E310）。
5. **离线 DCP 成本与在线实时预算冲突** → DCP 完全异步、IDG 周期性快检；在线环路只记录不训练（定义 310-i）。

**定义 324–326（威胁/审计/证书）** `ℰ_GRASP=ℰ_FLUID×ℰ_dataset`（标签翻转/虚假相关/幸存者偏差/反馈投毒）；VQAuditor-D 审出处、覆盖声明、泄漏与投毒；`J_GRASP` 并入 coverage、IDG、ESS、倾向性哈希、接触 ECE、FCC 分位。

# IP-264 GCM：接触条件流（复用 R69 trunk / 速度场，新增接触条件）
class ContactConditionedFlow:
    def sample(self, o_t, c_hat, K, N_step=2):
        z, xs = self.trunk(o_t), randn(K, D)
        for i in range(N_step):
            xs = xs + (1.0/N_step) * self.v(xs, i/N_step, z, c_hat)
        return [self.decode(x) for x in xs]                      # ξ=(a,a_grip,g)

    m = contact_qp(g, o)                                         # fc / crush / slip
    return Cert(safe=(m.fc >= M_FC and m.crush >= M_C and m.slip >= M_S), margins=m)

    best = None
    for g in contact_probe_candidates(modes) + [DEFER]:
        if not budget.allow(g) or not certify_contact(g, o).safe: continue
        voi = endogenous_voi(w, g, o, policy)                    # o'=T(g,o)
        score = (voi - cost(g) - LAM_IRR*option_value_loss(g, o)
                 + BETA*meta_info_value(g, o, policy.ensemble))
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None             # 负值 → R69

                                             + LAM_ID*ident_gain(x))

        selected.append(r)

    z, o = M.mtm.forward(...); c_hat = M.gcm.contact_head(o)
    if not M.idg.passed(): return r69_conservative(M, o)          # 数据不可识别
    K = 4 if (c_hat.mode != 'free' or M.fmp.mode_head(z) >= TAU_MODE) else 1
    U_ale, U_epi, modes = M.aud.decompose(M.gcm.sample(o, c_hat.mode, K), z)
    g = M.riv.choose(modes, o, M.budget) if U_epi > TAU_EPI else None
    if g is not None and g is not DEFER:
        rec = M.logger.begin(o, g, M.policy.behavior_propensity(o))
        answer, o_next = M.gcm.execute(g)                         # 改变状态
        U_epi = M.cia.update_belief(modes, answer)
        M.logger.commit(rec, o_next, answer)                      # 带出处数据
    U_floor = U_ale + (U_epi if g is None or g is DEFER else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    if g is not None and not certify_contact(g, o).safe:
        lam, k = max(lam, 0.8), min(k, k_cal_shrink(...))
    M.dcp.maybe_schedule(); M.vqa_d.submit_async(g, U_epi, M.dataset_ref)
    return k, lam, select_mode(modes, U_epi, lam), (U_ale, U_epi)
```

## 4. 推导

**引理 19（不可逆折扣）** `Irr≥0 ⇒ RIV ≤ VoI_end−c`，故 RIV 选出的探询集 ⊆ 静态 VoI 集；`λ_irr·Irr > VoI_end−c` 时严格偏好 deferral。R69 在接触场景的过度探询量恰等于期权损失——是目标漏项而非调参。

**引理 20（内生观测偏差）** 模态熵 L-Lipschitz、`E‖o′−o‖=δ` 时 `|VoI_static−VoI_end| ≤ Lδ`。注视/提问（δ≈0）可用静态 VoI；力探针（δ 大）必须用内生 VoI，否则符号都可能反。

**引理 21（策略依赖数据的可识别性）** 若某模态的判别性探询在正测度状态上 `π_b=0`，则该模态不可识别；正性/重叠 + 倾向性记录下 IPW 一致。故 IDG 必须逐模态检查正性。

**引理 22（覆盖 → 模态权重校准界）** A95 下每模态 `n_min` 样本，`|ŵ_k−w_k| ≤ √(log(2K/δ)/(2n_min))`；零样本模态无有限界——这是覆盖门的必要性，也是 R69 ECE 门的数据侧镜像。

**引理 23（数据飞轮的坍缩与探索地板）** 无探索地板时 `π_{D,t+1}∝π_{D,t}(1+η·gain)`，罕见但安全关键的模态几何式归零；`π_b≥ε` 使更新有唯一内点不动点。故数据飞轮与模型一样需要门控。

**定理 18（GRASP 严格包含 FLUID-RAS）** 「Irr=0 ∧ β=0 ∧ IDG 通过」时 RIV 退化为 R69 的 VoI−c，c=free 时 GCM 退化为 FMP，DCP/PAC 不影响在线行为 ⇒ 逐指令相同，安全侧只增不减。

**定理 19（接触安全与无破坏性探询）** FCC 认证且自动机守卫强制执行 ⇒ 期望力 ≤ f_max、滑移概率 ≤ ε_slip、不可逆动作不离开安全抓取集；认证失败或 RIV≤0 ⇒ 作废并执行 R69 认证前缀，物理风险单调不增。

**定理 20（子模数据集构造近似最优）** 覆盖目标单调子模，基数预算下贪心 ≥ (1−1/e)·OPT；可识别性写成划分拟阵后约束贪心保持该近似。仅对声明目标近最优，不保证泛化——泛化是本轮最大风险。

## 7. 本轮最大风险

**一句话**：GRASP-RAS 的全部收益押在「离线数据集的跨模态覆盖与出处标记是真的」这一前提上——**一旦记录策略只采集自己愿意采集的接触模态、或倾向性/出处被错标，IDG 就会在一份有偏数据上盖章通过，MIV 又反过来奖励「采集已经会的」，形成越采越自信、越自信越偏的自我确认闭环；而接触不可逆，使每一次被确认的错误都可能是最后一次探询。**

**次级风险与缓解**：接触证书近似失效（鲁棒 QP + 保守裕度，仅剪枝，失败退 R69，定理 19）；内生观测 T 估计偏（在线残差校验 EIM，偏差大即禁不可逆探询，引理 20）；数据飞轮坍缩（ε-探索地板 + 逐模态覆盖下限 + IDG，引理 23、E314）；投毒/幸存者偏差（出处哈希 + 投毒簇检测 + 成功/失败对称记录，定义 324、E310）；离线 DCP 与在线实时预算冲突（DCP 全异步、IDG 周期快检、在线只记录不训练）。
