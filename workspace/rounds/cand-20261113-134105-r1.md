# 第 66 轮（承接第 65 轮「VISTA 故障可归因闭环」IP-214~223；灵感循环第 3 轮；本轮灵感：「对话管理」×「自主导航」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述的最大风险一针见血：**VISTA 依赖"故障属于有限假设集"与"视觉/几何失效相互独立"两个隐藏假设；真实故障常是未知类型的组合，透明/镜面/对抗 patch 又会让视觉与几何共享同一个分布外失效源，于是 FIR 会把未知复合故障强行归入最近假设、只膨胀错误的球——系统因"已经归因"而更自信地继续执行。** 本轮不再加模态、也不再试图把分类器做得更聪明，而是换两个"过程性"的灵感：**对话管理**教我们如何在开放世界里说"我没听懂"、如何澄清、确认、修复、以及在不可解时把主动权交还；**自主导航**教我们如何在观测混叠中靠"移动与重访"消歧、如何用回环闭合纠正漂移、如何在"被绑架"之后全局重定位。二者合流，把 VISTA 的"一次性闭集归因"升级为**开放世界的诊断对话与诊断导航**。本轮核心命题是：
>
> **归因不是一个分类问题，而是一场机器人同"故障世界"之间的、受安全约束的对话：它必须能表达"未知"、必须能主动移动到可区分处、必须能回去核对、必须能在被证明错了之后重开对话。**

## 0. 直觉与动机

**灵感 1（对话管理 → 归因其实是"开放世界对话状态追踪 + 对话策略"）**
直觉：任务型对话系统的核心从来不是"猜用户意图"，而是维护一个**允许"未知/无匹配"的信念状态**，并在不确定时选择澄清、确认、修复或转人工。VISTA 的 FIR 恰恰相反：softmax 强制在 6 个假设里选一个赢家，未知复合故障只能被塞进最近邻。对话管理的第一课是：**没有 no-match 的分类器在安全系统里是不合法的**；第二课是：**"请你确认/我再说一遍"是合法的安全行为**——对应机器人重复一次已知诊断（confirm）；**"我没听懂，请换种说法"**对应换一个探针（re-ask）；**"转人工"**对应 safe_idle + 人类澄清（escalate/handoff）。归因因此从"一次判决"变成"多轮对话"，而对话状态就是故障信念、诊断上下文与历史三元组。

**灵感 2（自主导航 → 观测混叠只能靠"移动"消解）**
直觉：导航里最经典的难题是**感知混叠（perceptual aliasing）**：两个不同地点在单一视角下看起来一模一样，任何单帧分类器都无解；真正的解法是**移动**——换视角、走两步、回到有辨识力的地标。VISTA 的"不可辨识"（第 65 轮引理 7）正是诊断空间的感知混叠：某些故障在单阶段签名上完全同分布，单步互信息 AFA 对它们的信息增益近乎为零，因为**你站在原地看着同样的画面，再看一百次也不会多出信息**。要分离它们，必须让机器人**主动移动到一个新的诊断上下文**（零力窗、轻触、加载、二次接近、换基座视角），使"动作条件转移核"不同。于是 AFA 的"选一个探针"升级为**信念空间里的多步诊断导航**：不是最大化一步互信息，而是规划一条通往"可归因状态"的路径。

**灵感 3（自主导航 → 回环闭合 = 归因的自我证伪）**
直觉：VISTA 最危险的不是归因错，而是**归因错之后还越来越自信**。SLAM 早就遇到过同一问题：里程计会漂移，局部估计会越来越自信地错下去；解决办法不是让里程计更自信，而是**回环闭合**——走回一个认识的地方，用重访观测把累积漂移一次性纠正，纠正不了就触发重定位。对应到归因：**故意重访一个已知诊断上下文（重新回到零力窗，或从第二个视角重新轻触同一接触斑），把当前观测与当初存储的签名做一致性检验**。一致 → 归因被"接地"（positive grounding）；显著不一致 → 判为**归因漂移**，重开信念、执行修复，必要时全局重定位。回环闭合第一次给归因一个**可执行的自我证伪动作**，而不只是一个后验数字。

**灵感 4（自主导航 → 绑架归因与全局重定位）**
直觉：导航里的"绑架机器人问题"是：机器人被瞬移到别处，局部跟踪器仍会坚定地收敛到错误位置。诊断里同样存在**绑架归因**：传感器被更换、物体类别突变、光照长期改变、软件版本漂移之后，旧故障信念会**局部地、自信地**继续更新。VISTA 没有全局重定位机制。导航的做法是：检测到持续的大创新/持续回环失败 → **放弃局部先验，在整张地图上做全局多假设重定位**，并优先执行安全的恢复行为。对应到诊断：清空/展宽信念，在"已知故障图 + NOVEL"上做一次**低能量全局扫描**（null_test、环绕视觉、二次接近），绝不在未重定位时做不可逆动作。

**灵感 5（二灵感合流 → NAVDIA：Navigation of Attribution via Dialogue & Information Acquisition；VISTA 组件的原位升级）**
- **FIR → DST-N（开放世界诊断状态追踪）**：6 假设 softmax → 带显式 NOVEL 质量、conformal 无匹配检验与 type-I 控制的开放世界信念。
- **AFA → DPM（诊断对话策略）**：单步互信息 → 受风险约束的诊断 POMDP；行为集 {commit, probe, confirm, revisit, repair, escalate, human_query}。
- **阶段签名 → TOPO-D（拓扑诊断图）**：把"阶段"组织成可转移的诊断上下文图，支持多步规划与重访。
- **CGG/FIR 的"一次归因" → LC-A / REPAIR（回环闭合与对话修复）**：归因可被重开、可被纠正，而不是只能单向变自信。
- **RSC-V → RSC-O**：NOVEL 触发时膨胀的是"未知故障联合球"，不是随便一个已知球；同时禁止不可逆动作。
- **CSC → CSC-O**：认证前缀在开放世界支持集（含 NOVEL）上计算；无法认证则 `k*=0`（"不执行"也是一种对话行为）。
- **AIC-V → AIC-N**：干扰集增"诊断混叠"、"非平稳漂移"、"回环被世界变化欺骗"、"对话延迟/人类错误"。
- **J_vista → J_navdia**：证书增 open_world_mass、nomatch_flag、loop_closure_consistency、diagnostic_plan_id、escalation_state、attribution_revision。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（NAVDIA 闭环）**：NAVDIA = (VISTA, DST-N, TOPO-D, DPM, LC-A, REPAIR, KID-A, MIX, CSC-O, RSC-O/AIC-N, J_navdia)。定位：VISTA 的"开放世界 + 诊断导航"升级。不变式：**开放世界信念更新、诊断策略规划、回环闭合与修复、全局重定位、人类查询都发生在语义流/低频线程；实时流只做信念传播、无匹配打分、认证前缀早停与派发，零学习写操作。**
- **定义 234（诊断上下文与拓扑诊断图 TOPO-D）**：导航的"地点"在这里是诊断上下文 g ∈ G（自由空间接近、轻触、加载、二次视角观察、零力窗重标定……）。节点观测核 O_g(ρ|z)，边 a∈U 的转移核 T(g'|g,z,a)。TOPO-D 是一个 POMDP：状态 (z,g)，观测 ρ，动作 U。上下文由**可实时测得的状态量**（接触、力阈值、末端位姿、视点）定义，不由学习器任意划分；离线用故障注入 + 标定台构建，在线只做局部化。
- **定义 235（观测混叠与动作条件可辨识性）**：单步观测等价 z ~₁ z' ⇔ ∀a，KL(p(ρ|z,a)‖p(ρ|z',a)) ≤ ε_alias。混叠商 Z/~₁ 是"单步分辨率下的故障类别"。k 步可辨识 ⇔ ∃a_{1:k}，KL(p(ρ_{1:k}|z,a_{1:k})‖p(ρ_{1:k}|z',a_{1:k})) ≥ κ_sep。定义混叠指数 α_alias(z,z') = 1 − exp(− sup_{a_{1:k}, k≤K} KL)。**VISTA 的 J_fi≻0 只是 k=1 的局部线性化特例**；当混叠发生时，J_fi 在 Z/~₁ 上退化，必须 k≥2。
- **定义 236（开放世界诊断信念 DST-N）**：b ∈ Δ(Z ∪ {NOVEL})。已知故障的观测似然来自离线标定；NOVEL 由一个 conformal 无匹配检验给证据：对已知签名集合计算新颖分数 s_nov(ρ)（密度比/集成马氏距离），得 p 值 p_nov = (1 + #{i: s_i ≥ s_new})/(n+1)；若 p_nov ≤ α_nov，则拒绝"属于已知集"并给 NOVEL 质量。更新 b' ∝ b·L(ρ)，其中 L 显式含 NOVEL 项。**决策规则：若 b(NOVEL) > δ_nov，则禁止不可逆动作并进入 ESC / 澄清。**
- **定义 237（诊断对话行为与对话状态）**：对话状态 ξ_t = (b_t, g_t, h_t)，h_t 为已执行行为与观测历史。行为集 U = {commit（执行任务）, probe（物理探针）, confirm（重复已知诊断）, revisit（回访已知上下文）, repair（重开/膨胀信念）, escalate（安全降级/转人工）, human_query（结构化提问）}。每个行为带语义前置/后置：commit 要求 grounded(b)；revisit 要求存在可重访且**可区分**的节点；human_query 要求人类通道可用。
- **定义 238（诊断对话策略 DPM）**：一个受约束 POMDP：
  π* = argmin_π E[Σ_t γ^t (c_time + c_risk + c_wear + c_human)(u_t) − λ_I·I_t]，
  s.t. 每步预测力 ≤ f_safe、不可逆动作仅当 grounded(b) ∧ b(NOVEL)≤δ_nov。等价于在"可归因集" B* = {b : max_z b(z) ≥ 1−δ_fi ∨ b(NOVEL) ≥ 1−δ_nov} 上求随机最短路径。序列信息增益 I(a_{1:k}|ξ) = H(z|ξ) − E[H(z|ξ,a_{1:k})]。**VISTA 的 AFA 是 k=1、忽略 c_risk 序列效应、且无 NOVEL 项的特例。**
- **定义 239（归因回环闭合 LC-A）**：revisit 把系统驱动回已记录上下文 g_r，得复观测 ρ_lc。一致性残差 δ_lc = ‖ρ_lc − ρ̂_{g_r}‖²_{Σ_lc⁻¹}（ρ̂ 为归因时存储签名，Σ_lc 含重访噪声与上下文重建误差）。接受条件：δ_lc ≤ χ²_{3,1−α_lc} 且与当前归因假设的预测一致；否则判 attribution_inconsistent，触发 REPAIR。**回环是归因的证伪测试，不是几何的证伪测试。** 关键细节：回到一个**仍然混叠**的上下文没有信息，LC-A 必须规划"回访哪个上下文"。
- **定义 240（归因漂移与对话修复 REPAIR）**：漂移来源：非平稳故障（温漂、磨损、迟滞）、上下文重建误差、世界本身变化。修复算子 Repair(b, δ_lc) 遵循"先展宽、后重定位"：δ_lc 中等 → 对当前假设方差膨胀并降权（soft repair）；δ_lc 大或反复失败 → 丢弃局部先验，进入 KID-A 全局重定位（hard repair）。任何修复写入审计 attribution_revision。
- **定义 241（绑架归因与全局重定位 KID-A）**：触发条件：(i) 连续 R 次 revisit 失败；(ii) 创新序列 χ² 超界；(iii) NOVEL 质量持续 > δ_nov；(iv) 传感器/软件版本指纹改变。响应：b ← 宽先验（Z∪{NOVEL}），在安全行为集 {null_test, visual_orbit, re_approach} 上做全局诊断扫描，求最小期望代价到达 B*；期间 `k*=0`、禁止不可逆动作。这是 kidnapped-robot global localization 的诊断对偶。
- **定义 242（澄清与人类查询 MIX）**：human_query 是结构化对话框：给出候选故障集、观测摘要、置信度、建议处置与预计风险；人类返回 (选择, 置信, 修正)。响应模型 p(r|z) 含延迟 τ_h 与错误率 ε_h；超时缺省 → ESC（safe_idle）。**人类是可选的高成本通道，不是安全链的必选项**；无人类时退化为保守自主策略。
- **定义 243（开放世界认证前缀 CSC-O）**：支持集 supp_δ(b) 含 NOVEL。对已知 H 沿用 VISTA 的 ρ_safe；对 NOVEL 用在线保守包络，或直接 `k*=0`。
  k*(A_t) = max{ k : ∀H∈supp_δ, ∀s≤k, ρ_safe(s)≥0 ∧ P[越界]≤α_chunk }。
  若连 k=1 都不能认证 → `k*=0` 并 ESC。**"不执行"是合法的对话行为。**
- **定义 244（诊断导航的可达性）**：V(ξ) = min_u E[c(u) + γV(ξ')] 在信念可达图上求。若 V(ξ)=∞（不存在不越过不可逆视界即可到达 B* 的安全路径），判 diagnostic_dead_end → human_query 或 safe_idle。可达性充分条件：存在一条探针路径，使每个混叠对在某一步的观测核 KL ≥ κ_sep，且沿途力/形变不超限。
- **定义 245（归因证书 J_navdia）**：J_navdia = (J_vista, open_world_mass, nomatch_flag, loop_closure_consistency, diagnostic_plan_id, escalation_state, attribution_revision, dialog_log_hash)。Valid ⇔ Valid(J_vista) ∧ (grounded(b) ∨ 已 ESC/human_query) ∧ (b(NOVEL)≤δ_nov ∨ k*=0) ∧ (回环一致性已检验 ∨ 显式记录未检验原因) ∧ 修复/重定位已审计。
- **定义 246（诊断对话日志）**：不可变日志逐轮记录 (b, g, u, ρ, δ_lc, 决策, 人类输入)，哈希进 J_navdia。用于事后审计"当时为什么相信这个归因、为什么决定继续/停下"。这是对话系统 dialogue log / audit trail 的安全化。
- **定义 247（NAVDIA 闭环算子）**：语义流 [VISTA 前置 → DST-N 更新 → 无匹配检验 → DPM 多步规划 → (probe/confirm/revisit/repair/human_query) → CSC-O → Shield → 执行或暂停 → LC-A 回环检验 → REPAIR/KID-A → AIC-N]；实时流 [阶段签名/无匹配打分 → 信念传播 → CSC-O 早停 → 派发 → J_navdia 构建]。
- **定义 248（开放世界安全契约）**：(C1) 不可逆动作仅在 grounded(b) ∧ b(NOVEL)≤δ_nov ∧ k*≥1 时允许；(C2) 任何未匹配/未认证状态默认 `k*=0`（fail-closed）；(C3) 人类查询不是安全前提，只是降低保守性的可选动作；(C4) 回环失败不得被"更自信的局部更新"掩盖；(C5) 非平稳性显式进入转移核的时间参数，不得假设永久平稳。

## 2. 关键算法骨架

```python
# DST-N：开放世界信念 + conformal 无匹配
def dst_update(b, rho, known_lik, nov_model, alpha_nov):
    p_nov = conformal_pvalue(nov_model, rho)        # 对已知签名池
    lik = {z: known_lik[z](rho) for z in b if z != 'NOVEL'}
    lik['NOVEL'] = nov_model.density_ratio(rho)
    b = normalize({z: b[z] * lik[z] for z in lik})
    return b, (p_nov <= alpha_nov)                  # nomatch_flag

# DPM：诊断对话策略（多步、风险约束）
def choose_dialog_act(xi, topo, budget):
    if grounded(xi.b):                          # 可提交
        return 'commit'
    if xi.b['NOVEL'] > DELTA_NOV:               # 未知优先止损
        return 'human_query' if human_available() else 'escalate'
    if xi.revisit_budget > 0 and has_informative_revisit(xi, topo):
        return 'revisit'                        # 回环：回去核对
    plans = enumerate_probe_sequences(topo, xi, K=MAX_DEPTH)
    best = min(plans, key=lambda p: expected_cost(p) - LAMBDA_I * seq_info_gain(p),
               default=None)
    if best is None or not best.risk_ok:
        return 'repair' if drift(xi) else 'escalate'
    return best.act

# LC-A + REPAIR：归因的回环闭合
def loop_closure(xi, g_r, rho_lc, stored, post):
    delta = maha(rho_lc, stored.mu, stored.Sigma)
    if delta <= CHI2_LC and agrees(rho_lc, post):
        return 'accepted', xi.b                # positive grounding
    b = soft_repair(xi.b, delta)               # 先展宽、后重定位
    if delta > CHI2_HARD or repeated_failures(xi):
        return 'kidnapped', global_relocalize(b)
    return 'reopened', b

# CSC-O + commit guard：开放世界的"不执行也是行为"
def commit_guard(b, A, k_star):
    if b['NOVEL'] > DELTA_NOV: return 0
    if max(b[z] for z in KNOWN) < 1 - DELTA_FI: return 0
    return k_star
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（混叠分离与多步占优）**：对单步混叠对 (z,z')，VISTA/AFA 的一步期望信息增益 ≤ ε_alias；但若 TOPO-D 中存在一条 k≥2 的路径，使两假设在某上下文 g_k 的观测核分离（KL ≥ κ_sep），则按链式法则，该序列的期望对数似然比至少累积 κ_sep，最优 k 步策略的信息增益 ≥ κ_sep。故 DPM 在混叠对上严格优于 AFA，而 AFA 是 k=1 特例。**"再看一帧愈多"不成立，只有"走到别处看"才成立。**
- **引理 10（回环闭合对假置信的控制）**：设重访重建误差与观测噪声经 Σ_lc 归一。正确归因时 δ_lc ∼ χ²₃，故误报率 = α_lc；错误归因时 δ_lc ∼ 非中心 χ²₃(λ)，λ 由故障签名差与重访上下文的可区分度决定，漏检率 β_lc(λ)；R 次独立且**可区分**的重访后假置信 ≤ β_lc(λ)^R。若回访到仍混叠的上下文（λ≈0），回环无信息——这正是 LC-A 必须做主动选择的原因。非平稳时回环失败转为"检出"，代价是把世界变化误报为故障漂移（须由 AIC-N 区分）。
- **引理 11（开放世界无匹配的 type-I 控制）**：在可交换性下，conformal 无匹配对已知故障的误报率 ≤ α_nov；对未知故障，强制归因概率 ≤ β_novel（由 held-out 新颖集实测，非 1）。于是第 65 轮隐藏假设 A88（"故障集有限完备"）被替换为**可测的 β_novel + 显式 NOVEL 通道**；决策规则禁止最近邻回退。
- **定理 9（NAVDIA 端到端安全）**：在 A94–A98 下，Valid(J_navdia) ⇒ (归因确定 ∨ 显式 NOVEL/ambiguous 并 ESC) ∧ 未接地时无不可逆动作 ∧ 回环失败被检出或审计 ∧ VISTA 的力/滑移/几何安全链保持。**"未知"与"被绑架"不再是最近邻的垃圾箱，而是第一等状态。**
- **定理 10（诊断导航的近最优与重定位延迟）**：(i) 在自适应子模/条件独立假设下，贪心序列信息增益 ≥ (1−1/e) 最优；无此假设时给出 VISTA 单步策略在混叠对上的无界后悔下界。(ii) 若从 ξ 到 B* 存在代价有限的诊断路径，则 KID-A 在有限步内重定位，延迟 ≤ 路径长度 + 检测延迟；若不存在，则 diagnostic_dead_end 触发 human_query/safe_idle（不假装能解）。
- **命题（开放世界不牺牲名义性能）**：当 NOVEL 质量低且已知故障 grounded 时，CSC-O 退化为 CSC、DST-N 退化为 FIR；开放世界机制只在需要时付费。
- **实时性**：实时流新增 conformal 打分（<0.1ms）、信念传播（<0.05ms）、commit guard（<0.02ms）；DPM 规划、回环、修复、全局重定位全部在语义流（<50ms），人类查询异步。

## 2. 形式化定义（完整版）

**定义 233（NAVDIA 闭环）** NAVDIA 是 VISTA 的"开放世界 + 诊断导航"升级：在 VISTA 的"语义流 ∘ 实时流"骨架上挂载 DST-N（开放世界信念）、TOPO-D（拓扑诊断图）、DPM（诊断对话策略）、LC-A（回环闭合）、REPAIR（修复）、KID-A（绑架重定位）、MIX（人机澄清），并原位升级 CSC→CSC-O、RSC-V→RSC-O、AIC-V→AIC-N、J_vista→J_navdia。不变式：**开放世界信念更新、诊断规划、回环/修复/重定位、人类查询只在语义流/低频；实时流只做信念传播、无匹配打分、认证前缀早停与派发，零学习写操作。**

**定义 234（诊断上下文与拓扑诊断图 TOPO-D）** 诊断上下文 g∈G 是可用实时状态量识别的一类观测/物理配置（自由空间接近、轻触、加载、二次视角、零力窗重标定等）。每个节点的观测核 O_g(ρ|z)=p(ρ|z,g)；动作 a∈U 诱导转移核 T(g'|g,z,a)。于是诊断被写成 POMDP，状态 (z,g)，观测 ρ，动作 U。TOPO-D=(G,U,O,T,prior)。上下文由阈值/接触状态/末端位姿/视点定义，**不允许学习器任意聚类**，以保证可审计与可重访。

**定义 235（观测混叠与动作条件可辨识性）** 单步观测等价定义为 z ~₁ z' ⇔ ∀a∈U: KL(p(ρ|z,a)‖p(ρ|z',a)) ≤ ε_alias。混叠商 Z/~₁ 是"单步分辨率下的故障类别"。k 步可辨识 ⇔ 存在动作序列 a_{1:k} 使
KL(p(ρ_{1:k}|z,a_{1:k}) ‖ p(ρ_{1:k}|z',a_{1:k})) ≥ κ_sep。
由链式法则，在给定动作序列下
KL(p(ρ_{1:k}|z)‖p(ρ_{1:k}|z')) = Σ_t E_{q_t}[KL(O_{g_t}(·|z)‖O_{g_t}(·|z'))] + (路径分歧项)，
其中 q_t 为上下文分布。因此**即使每一步在混叠上下文上 KL≈0，只要路径把系统带到某个可区分上下文，序列 KL 即可为正**。VISTA 的 J_fi≻0 是 k=1、单上下文的局部线性化特例。

**定义 236（开放世界诊断信念 DST-N）** 维护 b∈Δ(Z∪{NOVEL})。已知似然来自离线故障注入标定。NOVEL 由 conformal 无匹配检验提供证据：对已知签名池计算新颖分数 s_nov(ρ)（密度比或集成马氏距离），p_nov=(1+#{i:s_i≥s_new})/(n+1)。若 p_nov≤α_nov，记 nomatch_flag=True 并给 NOVEL 质量。更新
b'(z) ∝ b(z)·L_z(ρ)（z∈Z），b'(NOVEL) ∝ b(NOVEL)·L_nov(ρ)，
L_nov 用密度比并对温度做标定。**决策规则：b(NOVEL)>δ_nov ⇒ 禁不可逆动作，进入 ESC 或 human_query。**

**定义 237（诊断对话行为与对话状态）** 对话状态 ξ=(b,g,h)。行为语义：
- `commit`：执行任务块（要求 grounded(b)：max_z b(z)≥1−δ_fi 且 b(NOVEL)≤δ_nov）；
- `probe`：施加物理/视觉探针以增加证据（受 f_safe、ε_strain 约束）；
- `confirm`：重复一个已知、低风险、可复现的诊断上下文，用于稳定性确认；
- `revisit`：回到已记录且**可区分**的上下文 g_r，执行回环检验；
- `repair`：重开信念、展宽方差或降权；
- `escalate`：safe_idle + 保守联合膨胀 + 保持，不执行不可逆动作；
- `human_query`：结构化提问（候选集、置信、建议、风险）。
每一行为有前置条件与安全后置条件，非法行为被 Shield 拒绝并记入日志。

**定义 238（诊断对话策略 DPM）** 给定 TOPO-D 与风险约束，求
π* = argmin_π E[Σ_{t=0}^{T} γ^t (c_time(u_t)+c_risk(u_t)+c_wear(u_t)+c_human(u_t)) − λ_I I_t]，
s.t. 预测法向力 f_n(u_t) ≤ f_safe(φ̂,f̂_vis)，预测形变 ≤ ε_strain，且不可逆 u_t 仅在 grounded(b)∧b(NOVEL)≤δ_nov 时允许。序列信息增益
I(a_{1:k}|ξ)=H(z|ξ) − E_{ρ_{1:k}}[H(z|ξ,a_{1:k},ρ_{1:k})]。
该目标是"到达可归因集 B* 的随机最短路径 + 信息奖励"。当 k=1、去掉 NOVEL、忽略序列风险时，退化为 VISTA 的 AFA。求解用点基 POMDP / QMDP 近似 + 深度受限的序列枚举（K≤3），实时只执行第一步。

**定义 239（归因回环闭合 LC-A）** revisit 将系统带到已记录上下文 g_r，得复观测 ρ_lc。一致性残差 δ_lc=‖ρ_lc−ρ̂_{g_r}‖²_{Σ_lc⁻¹}，其中 ρ̂_{g_r} 是归因时存储的签名，Σ_lc 含重访噪声与上下文重建误差。接受：δ_lc≤χ²_{3,1−α_lc} 且与当前归因假设的预测一致 → `loop_closure_consistency=accepted`，归因被 positive grounding。否则 → `inconsistent`，触发 REPAIR。
**关键点**：回访一个仍然混叠的上下文 λ≈0，回环没有信息；LC-A 的价值来自**主动选择回访哪个可区分上下文**，不是机械重放。

**定义 240（归因漂移与对话修复 REPAIR）** 漂移源：非平稳故障（温漂、磨损、迟滞）、上下文重建误差、世界变化。两级修复：
- **软修复**：δ_lc∈(χ²_{3,1−α_lc}, χ²_hard]，对当前最可能假设的方差按 δ_lc 膨胀、后验降权，重新进入 DPM；
- **硬修复**：δ_lc>χ²_hard 或连续 R 次失败，丢弃局部先验，进入 KID-A。
所有修复记录 attribution_revision=(old_h,new_h,δ_lc,reason)。

**定义 241（绑架归因与全局重定位 KID-A）** 触发集：连续 R 次 revisit 失败；创新序列 χ² 超界；b(NOVEL) 持续>δ_nov；传感器/软件指纹改变。响应：b←均匀（Z∪{NOVEL}，NOVEL 宽先验），在 `U_safe={null_test, visual_orbit, re_approach}` 上求解 `min E[cost]` 到 B*；期间 `k*=0`、禁不可逆。若 U_safe 上 V(ξ)=∞，直接 human_query/safe_idle。这是 kidnapped-robot global localization 的诊断对偶：**不信任局部跟踪、在整张图上多假设重定位。**

**定义 242（澄清与人类查询 MIX）** human_query 提交结构化上下文：候选故障集、观测摘要（阶段签名/新颖度/回环残差）、置信度、建议处置、预计力/时间风险。人类返回 (选择,置信,修正)，响应模型 p(r|z) 含延迟 τ_h 与错误 ε_h；超时缺省 ESC。**人类不是安全链的必选项**：无人时退化为保守自主策略，只是更慢更保守。

**定义 243（开放世界认证前缀 CSC-O）** supp_δ(b)={H:b(H)≥δ} 含 NOVEL。对已知 H 用 VISTA 的 ρ_safe/ρ_rob/ρ_slip/ρ_force；对 NOVEL 用在线保守包络或直接 k*=0。
k*(A_t)=max{k : ∀H∈supp_δ, ∀s≤k, ρ_safe(s)≥0 ∧ P[∃s≤k 越界]≤α_chunk}。
若 k=1 都不能认证 → k*=0 并 ESC。**沉默（不执行）是被显式允许且被审计的安全行为。**

**定义 244（诊断导航的可达性）** 在信念可达图上定义代价-去
V(ξ)=min_{u∈U_adm} E_{ρ'}[c(u)+γV(ξ')]，V(ξ)=0 if ξ.b∈B*。
U_adm 为满足力/形变/不可逆约束的行为。若 V(ξ)=∞，判 diagnostic_dead_end。可达性充分条件：存在探针路径，使每个混叠对在某步可区分上下文的观测 KL≥κ_sep，且沿途 f_n≤f_safe。该定义把"归因能不能做"从"分类器准不准"变成"安全图上有没有路"。

**定义 245（归因证书 J_navdia）** J_navdia=(J_vista, open_world_mass=b(NOVEL), nomatch_flag, loop_closure_consistency, diagnostic_plan_id, escalation_state, attribution_revision, dialog_log_hash)。验证：
Valid(J_navdia) ⇔ Valid(J_vista)
∧ (grounded(b) ∨ escalation_state∈{safe_idle,human_pending})
∧ (b(NOVEL)≤δ_nov ∨ k*=0)
∧ (loop_closure_consistency=accepted ∨ 显式记录未检验原因/dead_end)
∧ 修复/重定位已审计。
审计链新增：为什么相信/不相信这个归因（open_world_mass、回环）、为什么只执行 k* 步、为什么求助人类。

### IP-224 DST-N（开放世界信念）

```python
class OpenWorldBelief:
    def __init__(self, known_lik, nov_model, alpha_nov=0.05, delta_nov=0.2):
        self.known_lik = known_lik          # p(rho|z), 离线故障注入
        self.nov = nov_model                # 密度比 / 集成马氏
        self.alpha_nov, self.delta_nov = alpha_nov, delta_nov

    def update(self, b, rho):
        p = self.nov.conformal_pvalue(rho)  # 对已知签名池
        lik = {z: self.known_lik[z](rho) for z in KNOWN}
        lik['NOVEL'] = max(self.nov.density_ratio(rho), 1e-6)
        b = normalize({z: b[z] * lik[z] for z in lik})
        return b, (p <= self.alpha_nov)

    def grounded(self, b):
        return (max(b[z] for z in KNOWN) >= 1 - DELTA_FI
                and b['NOVEL'] <= self.delta_nov)
```

```python
class DiagnosticPolicy:
    def plan(self, xi, topo, max_depth=3):

        if xi.revisit_budget > 0:

            if g_r is not None:                  return Revisit(g_r)

            if q < best_q: best, best_q = seq, q
        if best is None:
            return Repair(xi) if xi.drift_detected else Escalate()
        return best.first_act                      # 实时只执行第一步
```

## 4. 推导

**假设 A94–A98（本轮成立边界）**
- **A94（上下文可分）**：诊断上下文可由实时可测量确定，上下文重建误差有界 ε_g。
- **A95（回合内平稳）**：一个诊断对话回合内故障签名与转移核平稳；非平稳只通过 KID-A/版本指纹跨回合处理。
- **A96（可交换性）**：已知故障标定集与在线已知样本可交换，保证 conformal 无匹配 type-I 控制。
- **A97（回环可区分）**：存在可重访且可区分的上下文，使目标混叠对在该上下文观测 KL≥κ_sep；不存在时 LC-A 只承诺记录 dead_end，不承诺检测。
- **A98（人类可选）**：人类查询可用时有界延迟/错误；不可用时安全链不依赖人类。

**引理 9（混叠分离与多步占优）** 设 (z,z') 单步混叠，即 ∀a，KL(p(ρ|z,a)‖p(ρ|z',a))≤ε_alias。VISTA/AFA 的一步期望信息增益 I₁≤ε_alias。若 TOPO-D 存在动作序列 a_{1:k} 和上下文 g_k，使 KL(O_{g_k}(·|z)‖O_{g_k}(·|z'))≥κ_sep，且路径在该步前保持两假设的上下文分布对齐（例如同一开环探针序列），则由链式法则该序列 KL≥κ_sep，故 DPM 的信息增益 ≥κ_sep。因此存在混叠对使 AFA 的后悔无界，而 k 步 DPM 有正增益。∎

**引理 10（回环闭合对假置信的控制）** 在 A94/A95 下，Σ_lc 归一后：正确归因时 δ_lc~χ²₃，误报率 α_lc；错误归因时 δ_lc~非中心 χ²₃(λ)，λ 随签名差与回访上下文可区分度单调增，单次漏检率 β_lc(λ)=P[χ²₃(λ)≤χ²_{3,1−α_lc}]。R 次独立且可区分的回访后，假置信（错误归因未被检出且持续被提交）≤ β_lc(λ)^R。若回访到仍混叠的上下文（λ≈0），β_lc≈1−α_lc，回环几乎无信息——这解释了为何 LC-A 必须**主动选择**回访点。非平稳时 δ_lc 的分布包含世界变化项，回环倾向"检出"，但会把世界变化误报为故障漂移；此二义性由 AIC-N 的共因/漂移模型显式建模。∎

**引理 11（开放世界无匹配的 type-I 控制与 β_novel）** 在 A96 下，对已知故障样本 p_nov 均匀分布于 [0,1]，故 P[p_nov≤α_nov | z∈Z]≤α_nov（误报率控制）。对未知故障 z∉Z，定义 β_novel=P[p_nov>α_nov | z∉Z]（把未知当已知的概率）。β_novel 无法在无分布假设下解析界定，但可由 held-out 新颖故障集实测并用 Clopper–Pearson 给置信区间。决策规则禁止"最近邻回退"，故强制归因概率 ≤β_novel 而非 1。这把第 65 轮 A88 的"故障集有限完备"从口头假设变成**可测对象 + 显式 NOVEL 通道**。∎

**定理 9（NAVDIA 端到端安全）** 在 A94–A98 下，若 Valid(J_navdia)，则：
1. **开放世界不撒谎**：b(NOVEL)>δ_nov 时 k*=0 且进入 ESC/human_query（定义 236/243）；决策规则禁止最近邻回退，故未知故障不会被当作已知故障静默执行。
2. **混叠可被移动消解**：若存在可区分路径，DPM 的信息增益 ≥κ_sep（引理 9），归因后验在可归因集 B* 上集中；若不存在，则 V(ξ)=∞，转 dead_end，不假装能解。
3. **错误可被回环纠正**：R 次可区分回访后假置信 ≤β_lc(λ)^R（引理 10）；修复/重定位写入审计，杜绝"越归因越自信"。
4. **尽快止损**：不可逆动作仅在 grounded 且 b(NOVEL)≤δ_nov 且 k*≥1 时允许（C1）；否则 fail-closed（C2）。
5. **VISTA 安全链保持**：力/滑移/几何约束仍由 J_vista 的 ρ_safe 与 CSC 逻辑保证；人类查询缺失不破坏安全（A98/C3）。
∎

**定理 10（诊断导航的近最优与重定位延迟）**
(i) 若序列信息增益在可采纳序列集上满足自适应子模性（或观测在给定上下文下条件独立），则深度受限贪心 ≥(1−1/e)·OPT；若无此结构，引理 9 已给出 AFA 在混叠对上的无界后悔，故 DPM 至少在该类上严格更优。
(ii) 若从 ξ 到 B* 存在代价有限的诊断路径，KID-A 的检测延迟 ≤R 次回访 + 创新检验窗口，重定位延迟 ≤ 该路径长度 + 检测延迟；若不存在，V(ξ)=∞ 触发 human_query/safe_idle。
∎

**命题（开放世界不牺牲名义性能）** 当 b(NOVEL)≤δ_nov 且存在 z 使 b(z)≥1−δ_fi 时，DST-N 的决策与 FIR 相同、CSC-O 的认证与 CSC 相同；NOVEL 分支与回环/重定位仅在需要时激活。故开放世界机制是"按需付费"的保守性扩展，而非全局降级。∎

## 8. 已知风险

**一句话**：NAVDIA 把第 65 轮的"错误归因"升级成了"**错误定位 + 错误修复**"——其正确性押在"诊断拓扑图回合内平稳、回访能复现当时签名"这个隐藏假设上；真实故障会随温漂/磨损/迟滞**路径依赖地漂移**，世界也会在两次回访之间改变，回环可能把"世界变了"误判成"故障漂移"（错误修复正确归因），也可能把"故障漂移"误判成"世界变了"（确认错误归因）；同时 NOVEL 校准失准会变成吞噬已知故障的万能垃圾桶，人类澄清又是慢、会错、未必在场的通道。**开放世界安全保证的强度，恰好等于"新颖/已知边界"与"诊断图平稳性"这两条最难验证假设的强度。**

**次级风险与缓解**
1. **世界变化 vs 故障漂移二义**：LC-A 的 δ_lc 同时含两者；缓解：AIC-N 显式建"世界变化"干扰类，回环只作必要非充分证据；引入与故障/世界都独立的第三通道（本体感觉/IMU/外部标定物）。
2. **NOVEL 变成垃圾桶**：α_nov/δ_nov 过松会把已知故障判未知、过度保守；过紧会漏新故障；缓解：β_novel 上界监控 + 在线重校准 + 把"已知故障被误判为 NOVEL"计入覆盖证书并触发告警。
3. **回访不可区分**：回到仍混叠的上下文没有信息，却消耗时间/磨损；缓解：LC-A 先算回访点的期望 KL 增益，低于阈值不访；显式 dead_end。
4. **非平稳转移核**：TOPO-D 在长任务中失效；缓解：转移核带时间/温度/磨损参数，KID-A 版本指纹检测；定期重标定。
5. **POMDP 规划组合爆炸**：序列长度 K 与 |U| 增长；缓解：深度受限 K≤3、rollout/QMDP 近似、只对混叠对展开。
6. **人类可用性与安全幻觉**：人类可能不在场/给错/延迟；缓解：安全链不依赖人类（C3），超时 fail-closed。
7. **实时预算**：无匹配打分与信念传播逼近 2.8ms；缓解：conformal 池预索引、ROI 降采样、把 DPM/回环/重定位全部留在语义流。
8. **审计膨胀**：逐轮日志体积大；缓解：只哈希关键证据 + 环形缓冲 + 事件触发落盘。
