# 第 44 轮（新循环第 4 轮） · Dense-Spatial × Streaming-Temporal：把「语义分割」与「语音交互」统一为可撤销承诺证书闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形只保边际覆盖、多用户契约求交为空」。但它仍压着两个未言明的单点假设：**(H1) 感知输出是离散、稳定、可快照的标签**——语义分割被当成一张已定的图，mIoU 被默许等价于安全；**(H2) 交互输入是一次性完整指令**——语音被当成 final transcript，partial/修订/口音/同音词不进证书。本轮灵感词「语义分割」「语音交互」精确命中这两个假设：前者是**空间稠密、误差相关、边界最危险**的修订流，后者是**时间流式、假设集、可回退**的修订流。二者在**指称接地**处相乘（“把左边那个红色杯子拿过来”），这是 v9 真正的新问题：**分割风险 × ASR 歧义不是两个可相乘的概率，而是必须联合校准的接地问题；“问一句”本身也是动作，也要证书。**

## 0. 直觉与动机

**灵感 1（语义分割 → 「mIoU 不是证书，区域风险上界才是」）**：直觉上，分割图看起来像“场景真相”，但它是稠密预测：错误在空间上高度相关，且集中在**物体边界**——而边界恰恰是机器人碰撞、抓取、避障最依赖的地方。一个 92% mIoU 的分割器可以在一小块关键区域上系统性漏掉障碍。因此把分割从“一张标签图”提升为**带分布无关风险上界的区域证书**：对每个安全关键区域声明“误标质量 ≤ ε_r（以高概率）”“边界位移 ≤ δ_b（以 1−α）”。证书的单位是**场景/区域**，不是像素——因为像素不满足可交换性，像素级 iid 假设是本轮必须显式拒绝的第一个谬误。

**灵感 2（语音交互 → 「partial 只能做准备，commit 必须持证且可撤回」）**：语音是流式修订过程：partial → final → 可能被用户自我纠正（“拿……不对，是右边那个”）。如果等 final 才动，交互不可用；如果用 partial 就动，同音词/否定/量词会把动作带到错误目标。折中是**承诺分级 + 可撤销承诺**：`prep`（可逆、无外部副作用的准备动作）可在任意假设集下执行；`commit`（移动/抓取/接触）只在意图集单点且接地持证时提交；提交后若修订使假设集扩张到已承诺动作不再合法，必须在 ρ_max 内安全撤回。一句话：**不可逆动作永不基于 partial 提交；一旦承诺，就必须能被修订证伪后撤回。**

**灵感 3（耦合 → 「指称接地是联合事件，澄清是带证书的动作」）**：真正的耦合不是“分割 + 语音”两个模块并列，而是“那个红色的、左边那杯”——语言里的指代词、属性、空间关系必须落到分割/几何的区域上。这里有两个致命陷阱：**(a) 乘积陷阱**：把 P(ASR 对) × P(分割对) 当作联合接地概率，而两模态误差往往正相关（遮挡同时破坏视觉与造成环境噪声），乘积会系统性 overclaim；**(b) 澄清陷阱**：搞不定就“问一句”看似安全，但澄清有延迟成本、可能死循环、可能挤占安全监控预算，甚至用户会不耐烦地随口一指。因此澄清必须是**带终止性、时延上界、期间安全与有效性保证的动作**，预算耗尽就最小风险默认（停/不抓），绝不猜测。

**耦合升级**：SEGCERT（IP-60）把分割编译为区域风险证书 + 边界膨胀 + 修订纪元；VOICECOMMIT（IP-61）把语音编译为假设集 + 意图集 + 承诺屏障 + 可撤销租约；GROUNDCLARIFY（IP-62）把两流在指称处**联合校准**，并把“澄清”纳入动作证书。v8 的「仿真-检索-边缘-人格-并发」飞轮由此升级为 v9 的「**稠密空间 × 流式时间**双修订流 + 可撤销承诺」闭环。核心原则一句话：**收缩/等待/提问永远偏向安全；任何“向前一步”的动作必须持有联合证书，且必须可被新证据撤回。**

## 1. 形式化定义（增量：定义 44–49）

**定义 44（稠密语义风险证书 DSC）**：设分割器 g_θ，校准分布 D_cal 采样于场景级（**不是像素级**）。对风险水平 ε 与置信 1−δ，用共形风险控制选阈值 λ̂，使以概率 ≥1−δ 有 E_I[L_seg(g_θ,λ̂;I)] ≤ ε，其中 L_seg 可取关键区域误标像素占比、边界位移超阈指示或 1−region IoU。场景证书 S(I) = {(r, label_vote_r, ε_r, B_r(δ_b), e_S)}，风险预算满足 ∑_r ε_r ≤ ε（仅当区域划分互斥时成立）。**证书单位是场景/区域，像素级可交换性不成立，严禁按像素做 iid 校准。**

**定义 45（边界感知的语义-几何接口）**：设语义边界 1−α 位移上界为 δ_b。自由空间与障碍分别做保守变换 F' = F ⊖ B_{δ_b}、O' = O ⊕ B_{δ_b}。**命题**：若真实语义边界落在 B_r(δ_b) 内且输入深度几何证书 sound，则 F' 无“假自由”、O' 无“漏障碍”，语义-几何链 sound。**开放词表闭包**：OOD/未知物体一律并入障碍（保守闭包），不得当作可通行。**修订规则**：每帧 e_S 前进；若相邻帧标签翻转或边界位移超过 Lipschitz 界，旧证书立即作废并重认证，**禁止用时间平滑“洗掉”真实的边界跳变**。

**定义 46（语音假设集与承诺屏障）**：ASR 产生按说话人/口音 Mondrian 分层的共形假设集 T̂_t^α，P(t*∈T̂_t^α) ≥ 1−α；意图集合 Î_t = {φ(t) : t∈T̂_t^α}。动作分三类：`prep`（可逆、无外部副作用）、`commit`（可撤回的移动/抓取）、`irreversible`（不可撤回接触/高速运动）。承诺屏障：
(C1) `prep` 在任意 Î_t 下可执行，只要对 Î_t 全部意图无害；
(C2) `commit` 仅当 Î_t 单点（或全部意图映射到同一动作）且联合接地证书（定义 47）通过；
(C3) 提交后若修订使 Î 扩张到已承诺动作不再合法，必须在 ρ_max 内执行已验证撤回，否则计违例；
(C4) `irreversible` 永不基于 partial transcript 提交。
**修订安全性**：对任意修订序列，已提交动作要么持续持证，要么在 ρ_max 内被安全撤回。

**定义 47（联合指称接地证书 JGC）**：给定语言 L（含指代、属性、空间关系）与场景 S（分割/检测/几何），候选指称集合 R̂ 由联合非一致性分数 s(L,S,r) 生成，该分数同时编码 ASR 假设与视觉区域证据；在校准集上取 1−α 分位。证书要求 P(referent ∈ R̂) ≥ 1−α，且**联合校准，禁止用 P(ASR)×P(seg) 近似**。**乘积陷阱命题**：当两模态误差正相关时，P_joint ≥ (1−α_1)(1−α_2) 不成立，边际相乘会 overclaim。**可执行条件**：R̂ 单点，或 R̂ 中所有候选对当前动作“安全等价”（同一安全处理）；否则必须走定义 48。

**定义 48（澄清动作证书 CC）**：澄清 c 是动作，成本为延迟 d_c、打扰度与失败率。策略 π_c 需同时满足：
(T) **终止性**：以概率 1 在 N_max 轮内终止（或预算耗尽转安全停机）；
(S) **期间安全**：澄清时保持不变式 I，且不挤占安全监控硬预算（承接 v8 混合关键级）；
(D) **时延**：d_c ≤ d_max(κ)；
(E) **有效性**：澄清后联合接地覆盖或单点率严格提升。
预算/轮数耗尽 → 最小风险默认（停/不抓），**“问”绝不能成为无限循环或拖延的借口**。

**定义 49（修订纪元绑定的可撤销租约 RRL）**：把定义 41 的租约扩展为 ℓ=(m,τ,λ,κ,e_S,e_V,e_G)，分别绑定分割、语音、接地修订纪元。**撤销优先于衰减**：若任一纪元前进，租约立即失效，即使 t−τ 仍在新鲜窗口内。**命题**：感知修订导致的语义失效无法被时间衰减模型捕获，必须显式撤销；与 IP-58 的 seqlock/epoch 合并后，快照读须同时匹配全部相关纪元，任一不匹配即降级或重取。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 SPATIAL-SEMANTIC-CERT ENGINE（分割风险证书引擎 SEGCERT）
1. **风险控制分割**：共形风险控制选阈值，关键区域风险 ≤ ε，输出区域证书与风险预算分摊。
2. **边界膨胀与语义-几何接口**：δ_b 腐蚀/膨胀自由空间与障碍；未知物体保守闭包。
3. **修订纪元与跳变检测**：帧间一致性检查，真实边界跳变触发重认证，禁止平滑掩盖。
4. **场景级漂移检测**：新场景/新物体/光照突变触发保守回退（宁可当障碍）。

### 2.2 IP-61 STREAMING-DIALOGUE-CERT ENGINE（语音承诺证书引擎 VOICECOMMIT）
1. **共形 ASR 假设集**：n-best + 置信度校准，按口音/噪声 Mondrian 分层。
2. **意图集与承诺分级**：prep / commit / irreversible；C1–C4 承诺屏障运行时执行。
3. **可撤销承诺**：修订触发撤回序列（已验证、有界时延 ρ_max）；撤回失败即熔断。
4. **barge-in 与轮次证书**：检测用户说话 → 有界时间进入柔顺/停止；澄清预算与终止性内建。

### 2.3 IP-62 JOINT-GROUNDING-CLARIFY VALIDATOR（联合接地与澄清验证器 GROUNDCLARIFY）
1. **联合接地校准**：联合非一致性分数（语音+视觉），场景级校准，显式拒绝边际相乘。
2. **澄清策略证书**：终止性/时延/期间安全/有效性四约束，预算耗尽转最小风险默认。
3. **多轮记忆一致性**：检测“那个”在轮次间的指代漂移，防上下文误导。
4. **对抗采样**：同音词、否定、量词、空间关系歧义、遮挡、快速换指、口音。

## 5. 本轮最大风险

**一句话**：把稠密分割风险与流式 ASR 假设集各自持证后**按边际相乘**当作联合接地保证，在相关误差、开放词表漂移与澄清循环下会同时触发「联合覆盖被静默 overclaim」与「澄清 livelock / 不安全延迟」——因此 E99（联合接地覆盖）与 E100（澄清终止与预算）必须设为红线实验，默认回退到「未知即障碍 + 不确认不承诺 + 只进安全停机」这条永不失 sound 的底线。

## 2. 关键算法（伪代码）

### IP-60 SEGCERT：风险控制分割、边界膨胀与修订
```
def seg_risk_cert(image, seg, eps, delta, e_S, alpha):
    lam = conformal_risk_threshold(calib_scores, eps, delta)   # 单调损失，场景级校准
    regions = segment(seg, image, lam)
    cert = []
    for r in regions:
        eps_r = allocate_risk(r, eps)          # sum eps_r <= eps（互斥划分）
        delta_b = boundary_quantile(calib_boundary, 1 - alpha)
        cert.append(RegionCert(r, label_vote=r.label,
                               risk=eps_r, boundary=delta_b, epoch=e_S))
    if ood_score(image) > tau_ood:             # 开放词表未知物体
        cert = conservative_closure(cert)      # 未知 => 障碍，绝不当作可通行
    return SceneCert(cert, epoch=e_S)

def semantic_geometry_chain(scene_cert, geom_cert):
    F, O = geom_cert.free_space, geom_cert.obstacles
    for r in scene_cert.regions:               # 边界保守变换
        F = erode(F, r.boundary)
        O = inflate(O, r.boundary)
    return GeometryCert(F, O,
                        epoch=(geom_cert.epoch, scene_cert.epoch))

def on_new_frame(prev_cert, new_cert, lipschitz_bound):
    if boundary_shift(prev_cert, new_cert) > lipschitz_bound \
       or label_flip_ratio(prev_cert, new_cert) > tau_flip:
        return invalidate(prev_cert)            # 真实跳变：重认证，禁止平滑掩盖
    return merge_with_epoch(prev_cert, new_cert)
```

### IP-61 VOICECOMMIT：假设集、承诺屏障与有界撤回
```
def asr_hypothesis_set(audio, alpha, speaker_id):
    scores = mondrian_scores[speaker_id]        # 按口音/噪声分层
    q = quantile(scores, 1 - alpha)
    return [h for h in nbest(audio) if nonconformity(h) <= q]

def intent_set(H, parser):
    return {parser(h) for h in H}

def commitment_gate(intents, grounding_cert, action):
    if action.kind == "irreversible":
        return len(intents) == 1 and grounding_cert.singleton_and_valid()
    if action.kind == "commit":
        return intents_stable(intents) and grounding_cert.all_safe_equivalent()
    return True                                  # prep：任意假设下无害才执行
                                                 # （无害性由 IP-53 监控器复核）

def on_revision(new_intents, committed, rho_max):
    if all_covered(committed, new_intents):
        return keep(committed)
    if is_reversible(committed) and can_retract_within(committed, rho_max):
        return safe_retract(committed)          # 已验证撤回序列
    return violation_and_fallback()             # 设计上不应发生 -> 熔断

def barge_in_certificate(audio_activity, motion_state, d_yield):
    if audio_activity.detected and not motion_state.compliant:
        return yield_compliant(deadline=d_yield) # 有界时间进入柔顺/停止
    return motion_state
```

### IP-62 GROUNDCLARIFY：联合接地、澄清证书与指代漂移
```
def joint_grounding_cert(lang, scene, alpha, e_S, e_V):
    candidates = []
    for h in asr_hypothesis_set(lang.audio, alpha, lang.speaker):
        for r in scene.regions:
            s = joint_nonconformity(h, r, scene)  # 同时编码语音与视觉误差
            candidates.append((s, h, r))
    q = quantile(calibration_joint_scores, 1 - alpha)   # 联合校准，非边际相乘
    Rhat = [(h, r) for s, h, r in candidates if s <= q]
    return GroundingCert(Rhat, epoch=(e_S, e_V))

def certified_clarify(grounding, budget, kappa):
    if grounding.singleton_and_valid():
        return grounding
    if budget.rounds >= N_max or budget.latency >= d_max(kappa):
        return safestop_or_minimal_risk_default()   # 预算耗尽：不猜
    q = select_max_information_gain_question(grounding)
    assert keeps_invariant(q) and not steals_safety_budget(q)
    return ask(q)                                    # 澄清是动作，受证书约束

def detect_referent_drift(history, current):
    # "那个"/"它"跨轮指代变化检测；漂移则重新接地，沿用旧绑定即违例
    if current.pronoun and resolve(history) != resolve(current):
        return require_regrounding(current)
    return current
```

### IP-51/52/56 升级：承诺状态机与纪元撤销
```
def car_transition_guard(e, x, cert, persona, lease, t):
    if cert.grounding is None or not grounding_valid(cert.grounding):
        return e in {GROUNDING_PENDING, CLARIFY_WAIT}      # 未接地不得推进 commit
    theta = cert.alpha_e[e] * cert.theta_sim[e]
    m_lookup = cert_lookup_L0(x).m_lo[e]
    m_lease  = lease.m - lease.lam * (t - lease.tau)
    m_bound  = -boundary_inflation(cert.scene, e)          # 边界膨胀只收紧
    m_cap    = persona_cap[e](persona)
    fresh    = lease_epochs_match(lease, cert)             # RRL：纪元匹配
    return fresh and min(m_lookup, m_lease, m_bound, m_cap) >= theta

def streaming_cert_step(x, audio, persona, budget_us, criticality):
    H = asr_hypothesis_set(audio, alpha, persona.speaker_id)
    G = joint_grounding_cert(audio.lang, scene(x), alpha,
                             e_S=scene_epoch(x), e_V=audio.epoch)
    if not intents_stable(intent_set(H, parser)):           # partial 阶段
        return prepare_only(x, G)                           # 只做可逆 prep
    if budget_us < 110 or criticality < K_GEOMETRY:         # HI 模式裁剪
        return prepare_only(x, G)
    return commit_or_clarify(x, G, persona)                 # 单点/安全等价才 commit
```

## 6. 本轮最大风险

**一句话**：把稠密分割风险与流式 ASR 假设集各自持证后**按边际相乘**当作联合接地保证，在相关误差、开放词表漂移与澄清循环下会同时触发「联合覆盖被静默 overclaim」与「澄清 livelock / 不安全延迟」——因此 E99（联合接地覆盖）与 E100（澄清终止与预算）必须设为红线实验，默认回退到「未知即障碍 + 不确认不承诺 + 只进安全停机」这条永不失 sound 的底线。
