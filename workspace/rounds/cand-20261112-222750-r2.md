# 第 62 轮（承接第 61 轮「具身语义进化闭环」ESEC IP-173~182；灵感循环第 8 轮；本轮灵感：「深度相机」×「排行榜」）

> 第 61 轮构建了「具身语义进化闭环」ESEC：USR 把场景/意图/阻抗/证据映射到共享语义空间 ℝ^d_us，MEL 提供多模态零样本物理属性推断，DMS 实现执行接地的多轮对话，SRT-Dual 用语义流-实时流解耦大模型时序，PCE+++++ 做六维预算兜底。但**四个更深的局限**仍未被触及：
> 1. **USR 只有「语义轴」，没有「几何轴」**：scene_emb 能表达「这是玻璃杯、要轻触」，却表达不出「接触面法向 n、最近障碍距离 d_sdf、局部曲率 κ」。而阻抗刚度矩阵 K = K_n·nnᵀ + K_t·(I−nnᵀ) 本质是**几何量**——第 61 轮的语义先验到了接触瞬间仍需靠通用规则「猜方向、猜硬度」，语义与几何之间存在结构性缺口。
> 2. **深度感知被当作「默认可信」**：透明、反光、无纹理、自遮挡、远距离都会让深度相机产生**系统性错误几何**（玻璃杯被「看穿」、镜面被「看歪」、机械臂自遮挡把目标挡掉）。第 61 轮没有任何深度置信度建模，错误 ESDF 会以「新鲜锚点」的身份直接进入 1–10kHz 实时环——这是比语义漂移更危险的**几何谎言**。
> 3. **策略选择是「单次推理拍板」，而非「证据排名」**：MEL/DMS 每个周期给出一组先验，但不同几何 regime（开阔/近接触/遮挡/透明/杂乱）的最优策略本就不同，却共用一套投影头与先验。第 61 轮缺少一种**跨任务、跨 regime、可置信地排序候选策略**的机制，无法回答「在这个几何条件下，哪套阻抗策略真的更好」。
> 4. **评测不可复现、易被 Goodhart 化**：没有统一排行榜、没有排名置信区间、没有污染检测。研究者只能看单次端到端成功率就宣布「更好」，而一旦把评测分数当作优化目标，策略会迅速过拟合评测集——**指标上升、真实能力下降**，且无人能察觉。

## 0. 直觉与动机

**灵感 1（深度相机 → 几何语义化，DGUSR）**
直觉：深度相机不是「另一张图」，而是一把把世界变成**可碰撞距离场**的尺子。对阻抗控制而言，深度真正有用的不是像素，而是三个几何量：**法向 n**（往哪个方向施加刚度）、**有符号距离 d_sdf**（离碰撞还有多远）、**曲率 κ**（表面多尖、多容易卡住）。关键洞见：在第 61 轮 USR 旁并联一个**几何编码器** E_geo，把 ROI 内的 TSDF/ESDF 压成 geo_emb ∈ ℝ^{d_geo}，并让「语义嵌入」与「几何嵌入」通过对比对齐共享同一度量——于是「玻璃杯」这个语义标签第一次带上了「法向朝上、曲率小、距离 8mm」的几何坐标。阻抗先验从「查语义表」升级为「读几何场」。

**灵感 2（深度相机的谎言 → 深度置信度场 DCM）**
直觉：深度相机在透明（玻璃、水面）、反光（金属、镜面）、无纹理（纯色墙）、自遮挡（机械臂连杆）四类场景下会稳定地给出**错误的、但有结构**的深度：玻璃被穿透、镜面被镜像、自遮挡处出现空洞与飞点。关键洞见：不能要求「深度总是对」，而要建立**空间深度置信度场** c_depth(x) ∈ [0,1]——它由点云密度、SDF 梯度一致性、多视角一致性、SDF 残差、材质先验联合估计，并**像光照图一样逐点存在**。实时流按 c_depth 加权信任几何，c_depth 低的地方几何先验权重自动归零。这把「传感器可靠性」从工程假设变成可计算、可预算、可审计的一等变量。

**灵感 3（排行榜 → 具身策略竞技场 EPA）**
直觉：排行榜的本质不是「排名」，而是**在有限、含噪、可作弊的对抗样本上，用统计手段把「谁更好」变成一个可置信的决策**。具身策略也一样：候选策略（不同投影头、不同先验、不同阻抗策略族）就像参赛选手，几何 regime 就是「赛道」。关键洞见：不要问「哪套策略全局最好」（这个问题没有意义），而要问「**在几何 regime r 下，哪套策略以多大概率击败对手，且这个判断有多可信**」。用 Bradley–Terry/Elo 维护分桶排行榜，用 bootstrap 置信区间与 Pareto 前沿（成功率/安全违规/时延/认知负荷）表达「多目标、非全序」的真实竞争关系。

**灵感 4（深度相机 × 排行榜 → 深度条件化排行榜选择 DCLS）**
直觉：regime 不该由人工划分，而应由**深度几何特征自己聚类**出来：把 (法向分布、距离直方图、曲率谱、c_depth 统计) 聚成 {开阔, 近接触, 遮挡, 透明/反光, 杂乱} 等桶。每个桶维护一张排行榜；运行时用深度几何把当前环境归桶，再用**上下文 bandit（UCB/Thompson）**在桶内选策略。关键洞见：几何既定义了「赛道」，又提供了「当前在哪条赛道」的判据；深度置信度则决定「这个判据有多可信、要不要探索」。选择器必须始终套一层**安全滤波器**：只能从 SafeSet 里选，探索绝不越过 ERTC 硬约束。

**灵感 5（排行榜的诅咒 → 反 Goodhart 评测协议 AGP）**
直觉：任何被当作目标的排行榜都会被优化到失真——评测集污染、任务泄漏、选择性汇报、多重比较造假。关键洞见：排行榜必须自带「免疫系统」：**轮换留出集 + 污染/新颖度检测 + BCa bootstrap 置信区间 + Benjamini–Hochberg 多重比较校正 + 晋升门禁（须在两个以上 regime 占优且安全不回退，且置信区间不重叠）**。晋升不是「分数高就上」，而是「有统计证据证明真的更好才上」。这把排行榜从「荣誉榜」变成「可证伪的科学仪器」。

**灵感 6（双锚点与深度失效回退 DUAF）**
直觉：第 61 轮的语义锚点是单锚点；本轮引入**几何锚点**后，系统有了两条独立的「世界描述」。二者一致时融合更准，冲突时按置信度裁决；当深度彻底失效时，必须**无缝回退到第 61 轮的纯语义安全集**，且带迟滞避免在「几何可用/不可用」之间抖动。关键洞见：回退不是降级到「更差」，而是降级到「**已知安全的基线**」——几何先验只在 c_depth 高时才被允许偏离基线，这保证了本轮**不引入任何新的不安全自由度的下界**。

**灵感 7（八维预算 + 闭环 DGLC）**
直觉：几何感知与竞技评测都要花钱：ESDF 更新、深度编码、跨视角对账消耗 B_depth；候选策略评测、排行榜更新、置信区间计算消耗 B_arena。把第 61 轮预算扩为 **B_cog8 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_depth, B_arena)**。关键洞见：**B_arena 耗尽时冻结排行榜（用当前冠军 + 保守探索），绝不因预算不足而放宽晋升门禁；B_depth 耗尽时冻结几何锚点并回退语义锚点，绝不重用过期 ESDF**。闭环 DGLC = 几何流 ∘ 语义流 ∘ 实时流 ∘ 竞技场更新，四个时间尺度（30Hz / 10–100Hz / 1–10kHz / 0.1–1Hz）互不阻塞。

## 1. 形式化定义（增量：定义 173–184）

**定义 173（深度几何-语义统一表征 DGUSR）** 在第 61 轮 USR 基础上并联几何轴，U⁺ = (E_sem, E_geo, Π_sem, Π_geo, Ω, d_us, d_geo)。其中：
- **语义编码器**：沿用 E_scene/E_intent/E_impedance/E_evidence，输出语义嵌入 ∈ ℝ^d_us（d_us = 256）
- **几何编码器**：E_geo: (P, TSDF, ESDF) → ℝ^d_geo（d_geo = 128），输入 ROI 内点云 P 与截断距离场
- **几何特征通道**：每个查询点输出 (n, κ, d_sdf, ∇d, plane_fit_residual)，经 PointNet++/稀疏体素编码为 geo_emb
- **对齐损失**：ℒ_geo = ‖E_geo(ESDF) − E_sem(scene_label)‖² + InfoNCE(E_geo, E_sem)，驱动「几何实例」与「语义实例」互相可检索
- **语义投影**：Π_sem: ℝ^d_us → K_sem（第 61 轮投影头）
- **几何投影**：Π_geo: ℝ^d_geo × ℝ⁵ → K_geo，输入 geo_emb 与局部几何 (n, κ, d_sdf)，输出几何先验阻抗
- **门控权重**：Ω: (c_depth, u_sem) → [0,1]，决定几何先验在融合中的权重（定义 181）
- **双向检索**：给定语义「玻璃杯」可检索其典型几何分布；给定几何 (κ≈0, 平面) 可检索可能的语义类别

**定义 174（深度置信度场 DCM）** DCM = (c_depth, F_fail, Cal)。其中：
- **逐点置信度**：c_depth: ℝ³ → [0,1]，
  ```
  c_depth(x) = σ( w₁·ρ_pts(x) + w₂·G_cons(x) + w₃·M_cons(x) − w₄·R_sdf(x) − w₅·A_rough(x) )
  ```
  其中 ρ_pts 为局部点密度、G_cons 为 SDF 梯度一致性（‖∇d‖≈1）、M_cons 为多视角深度一致性、R_sdf 为 SDF 残差、A_rough 为局部粗糙度/飞点率
- **失效模式分类器**：F_fail: ℝ³ → {transparent, specular, occluded, textureless, far, valid}，用于选择专用补偿（如透明用透射先验、反光用偏振/多视角）
- **聚合置信度**：C_depth(ROI) = Quantile_{0.1}(c_depth(x), x ∈ ROI)，用低分位而非均值，避免「大片可信、关键点不可信」被平均掉
- **校准**：Cal 保证 ECE ≤ 0.05（保形预测/温度缩放），使 c_depth 可被当作概率使用
- **不可信区**：I_bad = {x : c_depth(x) < τ_d}，τ_d 默认 0.5；实时流对 I_bad 不采信几何

**定义 175（几何锚点 GA）** 扩展第 61 轮语义锚点，新增与语义锚点**并列且配对**的几何锚点：
```
Anchor_t^geo = (ESDF_t|_ROI, normal_map_t, curvature_t,
                c_depth_field_t, roi_pose_t, F_fail_hist_t,
                pair_id, timestamp_t, version_t, checksum_t)
Anchor_t^sem = (scene_emb, intent_emb, phys_prior, role/...(第61轮), pair_id, timestamp, version, checksum)
```
- **配对**：pair_id 将同一时刻的几何锚点与语义锚点绑定；读取时若 pair_id 不匹配视为「半锚点」，只用较新且自洽的一侧
- **写入**：两锚点各自 CAS 写入共享内存，version 64 位单调递增；checksum 覆盖几何字段防撕裂
- **新鲜度**：几何锚点 τ_fresh^geo = 100ms（30Hz），语义锚点沿用 τ_fresh^sem = 200ms
- **ROI**：以末端执行器为中心、半径 r_roi（默认 0.3m）的截断区域，控制 ESDF 更新成本

**定义 176（深度几何先验 DGP）** 从几何锚点解析生成阻抗先验 K_geo = g_geo(d_sdf, n, κ, c_depth)：
```
# 1) 法向-切向分解（接触面法向硬、切向软）
K = K_n·n nᵀ + K_t·(I − n nᵀ)
K_n = base_k · (1 + α·κ⁻¹),   K_t = base_k · (1 − β·κ)
# 2) 安全距离斥力项（近接触时叠加）
if d_sdf < d_safe:
    K ← K + k_rep·(d_safe − d_sdf)²·n nᵀ          # 越近越硬，方向沿法向
    F_max ← F_max · clamp(d_sdf / d_safe, γ_min, 1)  # 越近越限力
# 3) 曲率保护（尖角/边缘容易卡住）
if κ > τ_κ:
    K_t ← K_t · (1 − δ_κ·min(1, κ/κ_max))
    d_safe ← d_safe + Δ_curv                         # 曲率大则提前减速
# 4) 深度不可信时收缩到保守包络
if C_depth < τ_d:
    K ← ConservativeEnvelope(K);  w_geo ← 0          # 几何先验退出
```
- **几何先验族**：K_geo 不是单点，而是带协方差 Σ_geo(c_depth, κ) 的分布，c_depth 越低 Σ_geo 越大
- **安全包络**：K_geo ∈ K_safe^envelope 恒成立（由安全滤波器强制投影）

**定义 177（具身策略竞技场 EPA）** EPA = (Π_cand, R, M, S, L, CI)。其中：
- **候选策略集**：Π_cand = {π₁,…,π_N}，每个 π 是「投影头 + 几何先验族 + 融合权重」的参数化配置
- **赛道（regime）**：R = {r¹,…,r^K}，由深度几何特征聚类得到（定义 178），每个任务轨迹按几何特征归桶
- **对局**：一次对局 m = (π_i, π_j, r, task, outcome)，同一 (task, regime) 下两两比较，outcome ∈ {i胜, j胜, 平, 双败(安全违规)}
- **Bradley–Terry 评分**：P(i 胜 j | r) = exp(s_i(r)) / (exp(s_i(r)) + exp(s_j(r)))；用最大似然/Bayesian 估计 s_i(r)
- **Elo 在线更新**：s_i(r) ← s_i(r) + η·(outcome − E[outcome])，η 随对局数衰减
- **Pareto 前沿**：在每 regime 内，以 (成功率↑, 安全违规↓, 时延↓, 认知负荷↓) 四目标维护非支配集，避免把「高风险高成功率」误判为冠军
- **置信区间**：CI_i(r) = BCa bootstrap 95% 区间；排名仅在区间不重叠时视为「显著」
- **安全对局不入榜**：任何触发 ERTC 违规的对局记为「双败」，不产生正向分数

**定义 178（深度条件化排行榜选择 DCLS）** 运行时按几何归桶并在桶内做上下文 bandit 选择：
```
# 1) 几何归桶
g_feat = (hist(n), hist(d_sdf), spec(κ), stats(c_depth), density(P))
r_t = nearest_regime(g_feat; R)          # 或 soft-assignment 到多个 regime
# 2) 桶内 UCB 选择（带安全滤波）
for π_i ∈ SafeSet(r_t, C_exec):
    ucb_i = ŝ_i(r_t) + β·sqrt( ln(N_r + 1) / (n_i(r_t) + 1) )
π* = argmax_i ucb_i
# 3) 低置信区域保守化
if C_depth < τ_d or n_{π*}(r_t) < n_min:
    π* ← π_safe_baseline          # 回退第 61 轮保守策略
# 4) 探索配额（仅在安全且预算允许时）
if B_arena.allows_explore() and π* ∈ SafeSet:
    π* ← ThompsonSample(Posterior(r_t)) ∪ {π_safe_baseline}
```
- **冷启动**：新 regime 用几何最近邻 regime 的排名做先验（迁移），并强制高探索率
- **安全硬约束**：SafeSet(r_t, C_exec) 已滤除任何会违反 ERTC/力上限/角色契约的策略；bandit 永远在安全集内选择
- **软归桶**：对 regime 边界用隶属度加权，避免硬切分在边界产生抖动

**定义 179（反 Goodhart 评测协议 AGP）** AGP = (Rot, Contam, CI, FDR, Gate, Audit)：
- **轮换留出集 Rot**：每 T 轮从隐藏任务池抽取一批任务，只评测不参与训练/调参；评测集与训练集按任务指纹隔离
- **污染检测 Contam**：对待评测任务计算其与训练分布的嵌入距离/新颖度；若新颖度 < ν_min 则标记「疑似泄漏」，结果降权或弃用
- **置信区间 CI**：所有排名差异必须报告 BCa bootstrap 95% CI；无 CI 的「提升」不计入晋升
- **多重比较校正 FDR**：对同批 N 个假设检验用 Benjamini–Hochberg 控制 FDR ≤ q（默认 0.1）
- **晋升门禁 Gate**：新策略 π_new 晋升为某 regime 冠军需同时满足
  ```
  (i)   在两个以上 regime 上 CI 下界 > 现任 CI 上界
  (ii)  安全违规率不显著上升（单侧检验）
  (iii) 至少在 1 个隐藏留出任务上通过
  (iv)  无污染告警
  ```
- **审计链 Audit**：所有对局、排名、晋升写入哈希链日志，任何一次晋升可被事后复算

**定义 180（深度不确定性感知回退 DUAF）** 定义几何锚点的「有效」与回退协议：
```
valid_geo(t) ⇔ (C_depth(t) ≥ τ_d) ∧ (R_sdf(t) ≤ ε_sdf) ∧ (pair_id 一致) ∧ (age ≤ τ_fresh^geo)
if not valid_geo(t):
    K_safe ← SemanticOnlyCompile(...)        # 完全回退第 61 轮语义安全集
    w_geo ← 0;  disable Π_geo
    if 连续 m 帧 valid_geo:                  # 迟滞恢复
        re-enable Π_geo;  w_geo ← warmup ramp
```
- **单调安全**：回退目标是「已知安全的语义基线」，因此 `K_safe(fallback) ∈ SafeSet` 恒成立；几何先验只有在 valid 时才允许**偏离**基线
- **迟滞与驻留**：m 默认 5 帧、驻留时间 τ_dwell 默认 200ms，防止在透明/非透明交界处抖动
- **降级不降安全**：B_depth 耗尽 ⇒ 冻结 ESDF 并回退语义锚点，禁止复用过期几何

**定义 181（几何-语义一致性对账 GSC）** 量化两条世界描述的一致程度并据此融合：
```
D_geo_sem = ‖E_geo(ESDF) − E_sem(scene)‖₂
          + |d_sdf − d_pred(scene)| / d_scale
          + (1 − cos(n, n_pred(scene)))
w_geo = c_depth / (c_depth + u_sem + ε)
K_fused = w_geo·K_geo + (1 − w_geo)·K_sem
```
- **一致**（D_geo_sem ≤ τ_gs）：按置信度加权融合，几何主导法向/距离、语义主导任务级刚度范围

### IP-188 EPA（具身策略竞技场 / 排行榜）

```python
class EmbodiedPolicyArena:
    def __init__(self, policies, n_bootstrap=2000, fdr_q=0.1):
        self.policies = policies
        self.scores = {r: {p.id: 0.0 for p in policies} for r in REGIMES}
        self.matches = {r: {p.id: 0 for p in policies} for r in REGIMES}
        self.n_bootstrap, self.fdr_q = n_bootstrap, fdr_q
        self.pareto = {r: [] for r in REGIMES}
        self.audit_chain = HashChain()

    def update(self, policy_id, outcome, regime):
        # outcome: 1.0 胜 / 0.0 负 / 0.5 平 / -1 安全违规(双败)
        if outcome == -1:
            self.audit_chain.append(("violation", regime, policy_id))
            return
        opp = self._sample_opponent(regime, exclude=policy_id)
        expected = 1.0 / (1.0 + 10 ** ((self.scores[regime][opp] -
                                        self.scores[regime][policy_id]) / 400))
        eta = ETA0 / (1.0 + self.matches[regime][policy_id] / 50.0)
        self.scores[regime][policy_id] += eta * (outcome - expected)
        self.matches[regime][policy_id] += 1
        self.audit_chain.append(("match", regime, policy_id, opp, outcome))

    def leaderboard(self, regime):
        return sorted(self.policies, key=lambda p: -self.scores[regime][p.id])

    def confidence_interval(self, regime, policy_id):
        boots = [bootstrap_bt(self.history(regime), policy_id)
                 for _ in range(self.n_bootstrap)]
        return bca_interval(boots, alpha=0.05)   # 95% CI

    def promotion_gate(self, regime, candidate):
        ci_c = self.confidence_interval(regime, candidate.id)
        ci_i = self.confidence_interval(regime, self.leaderboard(regime)[0].id)
        wins_elsewhere = sum(
            self.confidence_interval(r, candidate.id)[0] >
            self.confidence_interval(r, self.leaderboard(r)[0].id)[1]
            for r in REGIMES if r != regime)
        safe_ok = not self._safety_regressed(candidate.id)
        return (ci_c[0] > ci_i[1]) and wins_elsewhere >= 1 and safe_ok
```

### IP-189 DCLS（深度条件化排行榜选择）

```python
class DepthConditionedLeaderboardSelector:
    def __init__(self, arena, regimes, beta=1.0, n_min=5):
        self.arena, self.regimes = arena, regimes
        self.beta, self.n_min = beta, n_min

    def regime_of(self, g_feat):
        # 软归桶：返回隶属度分布
        return softmax([-regime_distance(g_feat, r.centroid) / T
                        for r in self.regimes])

    def select(self, g_feat, c_depth, safe_set, budget):
        memberships = self.regime_of(g_feat)
        if c_depth < TAU_D:
            return SAFE_BASELINE, memberships
        ranked = []
        for p in self.arena.policies:
            if p.id not in safe_set:
                continue
            s_hat = sum(memberships[r] * self.arena.scores[r][p.id]
                        for r in range(len(self.regimes)))
            n_eff = sum(memberships[r] * self.arena.matches[r][p.id]
                        for r in range(len(self.regimes)))
            ucb = s_hat + self.beta * math.sqrt(math.log(1 + budget.n_total) /
                                                (1 + n_eff))
            ranked.append((ucb, p))
        if not ranked:
            return SAFE_BASELINE, memberships
        best = max(ranked, key=lambda x: x[0])[1]
        if budget.arena.explore_quota <= 0 or best.id not in safe_set:
            return best, memberships
        return thompson_sample_or(best, self.arena, memberships)
```

### IP-190 DUAF + GSC（回退 + 几何-语义对账）

```python
class GeoSemanticReconciler:
    def __init__(self, tau_gs=0.3, m_recover=5, tau_dwell=0.2):
        self.tau_gs, self.m_recover, self.tau_dwell = tau_gs, m_recover, tau_dwell
        self.valid_streak, self.last_valid_ts = 0, 0.0

    def valid_geo(self, anchor_geo, now):
        return (anchor_geo is not None
                and anchor_geo.C_depth >= TAU_D
                and anchor_geo.R_sdf <= EPS_SDF
                and (now - anchor_geo.timestamp) <= TAU_FRESH_GEO)

    def fuse(self, K_sem, K_geo, c_depth, u_sem):
        w_geo = c_depth / (c_depth + u_sem + 1e-6)
        return w_geo * K_geo + (1.0 - w_geo) * K_sem, w_geo

    def reconcile(self, sem, geo, now):
        if not self.valid_geo(geo, now):
            self.valid_streak = 0
            return "fallback", 0.0
        D = (geo_emb_distance(sem, geo)
             + abs(geo.d_sdf - sem.d_pred) / D_SCALE
             + (1.0 - cos(geo.n, sem.n_pred)))
        if D <= self.tau_gs:
            self.valid_streak = 0
            return "fused", D
        if geo.C_depth >= TAU_D and sem.u_sem >= TAU_U:
            return "trust_geo_recheck_sem", D      # 质疑语义，触发 MEL 重推理
        if geo.C_depth < TAU_D:
            return "fallback", D                    # 质疑几何
        return "conservative", D                    # 两者都低：取最保守
```

class CognitiveGeoArenaBudget:

**正确性定理（DGLC-Complete）**：
假设第 61 轮 A61–A70，并新增 **(A71)** DCM：c_depth 经保形/温度校准，ECE ≤ 0.05，失效模式分类召回 ≥ 90%；ROI 内 ESDF 截断误差 ≤ ε_sdf。**(A72)** DGUSR：E_geo 在 ROI 上 Lipschitz，ℒ_geo 收敛到 ε_align-驻点；语义-几何检索一致性 ≥ 90%。**(A73)** EPA：对局在 regime 内可交换且采样非自适应偏差受控，Bradley–Terry 可识别；安全违规对局记双败。**(A74)** AGP：轮换留出集与训练集按任务指纹隔离，污染检测召回 ≥ 90%，BH 控制 FDR ≤ q。**(A75)** DCLS：SafeSet(r, C_exec) 恒为 ERTC 可行集的子集；探索仅在安全集内进行。**(A76)** DUAF：`valid_geo = false ⇒ K_safe` 取第 61 轮语义安全集，且迟滞参数 m、τ_dwell 足够大以排除抖动。**(A77)** 预算：B_depth/B_arena 耗尽只触发「冻结/回退」，不放松 SafeSet、契约、晋升门禁。

则：
1. **几何-语义一致性**：若 `valid_geo ∧ D_geo_sem ≤ τ_gs`，则 K_fused 同时满足法向/距离几何约束与任务级语义约束，接触阶段力超调概率 ≤ 1−α。
2. **深度失效单调安全**：若 `¬valid_geo`，则 `w_geo = 0` 且 `K_safe = SemanticOnlyCompile`，即本轮相对第 61 轮**不引入任何新的不安全自由度**；几何先验只能在高置信时让系统「更准」，不能让系统「更险」。
3. **排行榜可置信**：在 AGP 下，被晋升策略的真实能力提升 > 0 的概率 ≥ 1−q（FDR 控制），且不存在「仅靠评测集污染」的晋升路径。
4. **跨 regime 泛化**：对未见 regime，DCLS 的累积 regret ≤ C√(T log N) + O(K)，其中 K 为 regime 数、N 为候选策略数。
5. **实时性与预算安全**：四个时间尺度解耦，实时流不依赖 30Hz 几何流与大模型；任一预算耗尽只降精度/暂停晋升，不违反 ERTC 实时契约。

class DepthGroundedUSR:
    def __init__(self, d_us=256, d_geo=128, r_roi=0.3):
        self.d_us, self.d_geo, self.r_roi = d_us, d_geo, r_roi
        self.e_sem = SemanticEncoders(d_us)          # 第 61 轮四个语义编码器

        self.pi_geo = GeoImpedanceProjector(d_geo)
        self.align_opt = torch.optim.Adam(
            list(self.e_geo.parameters()) + list(self.pi_geo.parameters()), lr=1e-4)

    def encode_geometry(self, esdf, normals, curvature, roi_pose):
        pts = esdf.query_points_in_roi(roi_pose, self.r_roi)
        feats = torch.cat([pts.d_sdf, pts.grad, normals[pts.idx],
                           curvature[pts.idx], pts.density], dim=-1)
        return self.e_geo(feats, pts.xyz)            # [1, d_geo]

    def align_step(self, geo_emb, scene_label):
        anchor = self.e_geo.encode_label_prototype(scene_label)
        loss = F.mse_loss(geo_emb, anchor) + info_nce(geo_emb, anchor)
        self.align_opt.zero_grad(); loss.backward(); self.align_opt.step()
        return loss.item()

    def project(self, sem_emb, geo_emb, local_geo, c_depth):
        K_sem = self.pi_sem(sem_emb)
        K_geo = self.pi_geo(geo_emb, local_geo) if c_depth >= TAU_D else None
        return K_sem, K_geo

### IP-187 DGP（深度几何先验）

```python
class DepthGeometryPrior:
    def __init__(self, base_k=200.0, d_safe=0.02):
        self.base_k, self.d_safe = base_k, d_safe

    def build(self, n, kappa, d_sdf, c_depth):
        K_n = self.base_k * (1.0 + ALPHA / (kappa + EPS))
        K_t = self.base_k * (1.0 - BETA * kappa)
        K = K_n * outer(n, n) + K_t * (torch.eye(3) - outer(n, n))
        F_max = DEFAULT_F_MAX
        if d_sdf < self.d_safe:                          # 近接触斥力项
            K = K + K_REP * (self.d_safe - d_sdf) ** 2 * outer(n, n)
            F_max = F_max * clamp(d_sdf / self.d_safe, GAMMA_MIN, 1.0)
        if kappa > TAU_K:                                # 曲率保护
            K_t = K_t * (1.0 - DELTA_K * min(1.0, kappa / KAPPA_MAX))
            K = K_n * outer(n, n) + K_t * (torch.eye(3) - outer(n, n))
            d_safe_eff = self.d_safe + DELTA_CURV
        else:
            d_safe_eff = self.d_safe
        if c_depth < TAU_D:                              # 不可信区收缩
            K = conservative_envelope(K); F_max *= SAFE_MARGIN
        return dict(K=K, F_max=F_max, d_safe=d_safe_eff,
                    Sigma=geo_covariance(c_depth, kappa))

class EmbodiedPolicyArena:
    def __init__(self, policies, n_bootstrap=2000):
        self.policies = policies
        self.scores = {r: {p.id: 0.0 for p in policies} for r in REGIMES}
        self.matches = {r: {p.id: 0 for p in policies} for r in REGIMES}
        self.n_bootstrap = n_bootstrap
        self.audit_chain = HashChain()

    def update(self, policy_id, outcome, regime):
        # outcome: 1.0 win / 0.0 loss / 0.5 draw / -1 safety violation (double loss)
        if outcome == -1:
            self.audit_chain.append(("violation", regime, policy_id)); return
        opp = self._sample_opponent(regime, exclude=policy_id)
        exp = 1.0 / (1.0 + 10 ** ((self.scores[regime][opp] -
                                   self.scores[regime][policy_id]) / 400))
        eta = ETA0 / (1.0 + self.matches[regime][policy_id] / 50.0)
        self.scores[regime][policy_id] += eta * (outcome - exp)
        self.matches[regime][policy_id] += 1
        self.audit_chain.append(("match", regime, policy_id, opp, outcome))

    def confidence_interval(self, regime, policy_id):
        boots = [bootstrap_bt(self.history(regime), policy_id)
                 for _ in range(self.n_bootstrap)]
        return bca_interval(boots, alpha=0.05)

    def promotion_gate(self, regime, candidate):
        ci_c = self.confidence_interval(regime, candidate.id)
        ci_i = self.confidence_interval(regime, self.leaderboard(regime)[0].id)
        wins_elsewhere = sum(
            self.confidence_interval(r, candidate.id)[0] >
            self.confidence_interval(r, self.leaderboard(r)[0].id)[1]
            for r in REGIMES if r != regime)
        return (ci_c[0] > ci_i[1]) and wins_elsewhere >= 1 \
               and not self._safety_regressed(candidate.id)
```

### IP-189 DCLS（深度条件化排行榜选择）

```python
class DepthConditionedLeaderboardSelector:
    def __init__(self, arena, regimes, beta=1.0):
        self.arena, self.regimes, self.beta = arena, regimes, beta

    def regime_of(self, g_feat):
        return softmax([-regime_distance(g_feat, r.centroid) / T
                        for r in self.regimes])          # 软归桶

    def select(self, g_feat, c_depth, safe_set, budget):
        m = self.regime_of(g_feat)
        if c_depth < TAU_D:
            return SAFE_BASELINE, m
        ranked = []
        for p in self.arena.policies:
            if p.id not in safe_set:
                continue                                  # SafeSet 硬滤波
            s_hat = sum(m[r] * self.arena.scores[r][p.id] for r in len(self.regimes))
            n_eff = sum(m[r] * self.arena.matches[r][p.id] for r in len(self.regimes))
            ranked.append((s_hat + self.beta * math.sqrt(
                math.log(1 + budget.n_total) / (1 + n_eff)), p))
        if not ranked:
            return SAFE_BASELINE, m
        best = max(ranked, key=lambda x: x[0])[1]
        if not budget.arena_allows_explore():
            return best, m
        return thompson_sample_or(best, self.arena, m)
```

### IP-190 DUAF + GSC（回退 + 几何-语义对账）

```python
class GeoSemanticReconciler:
    def __init__(self, tau_gs=0.3, m_recover=5, tau_dwell=0.2):
        self.tau_gs, self.m_recover, self.tau_dwell = tau_gs, m_recover, tau_dwell
        self.valid_streak = 0

    def valid_geo(self, a_geo, now):
        return (a_geo is not None and a_geo.C_depth >= TAU_D
                and a_geo.R_sdf <= EPS_SDF
                and (now - a_geo.timestamp) <= TAU_FRESH_GEO)

    def reconcile(self, sem, geo, now):
        if not self.valid_geo(geo, now):
            self.valid_streak = 0
            return "fallback", 0.0                       # 单调回退语义安全集
        D = (geo_emb_distance(sem, geo)
             + abs(geo.d_sdf - sem.d_pred) / D_SCALE
             + (1.0 - cos(geo.n, sem.n_pred)))
        if D <= self.tau_gs:
            return "fused", D
        if geo.C_depth >= TAU_D and sem.u_sem >= TAU_U:
            return "trust_geo_recheck_sem", D
        if geo.C_depth < TAU_D:
            return "fallback", D
        return "conservative", D

    def fuse(self, K_sem, K_geo, c_depth, u_sem):
        w = c_depth / (c_depth + u_sem + 1e-6)
        return w * K_geo + (1.0 - w) * K_sem, w
```

## 5. 本轮最大风险

**一句话**：若深度相机在透明/反光/自遮挡下给出**系统性且自信的错误几何**，同时排行榜因评测污染/选择偏差被 Goodhart 化，把「榜上最好、物理最差」的策略推为冠军，再叠加 DCLS 在 regime 边界硬切换抖动，系统就会陷入「排行榜第一、现实翻车」的**几何-评测双重幻觉**；必须以「DCM 保形校准 + DUAF 单调回退语义安全集 + AGP 置信区间/隐藏留出/多重比较校正 + SafeSet 硬滤波 + B_depth/B_arena 只冻结不放宽」构建双重护栏，确保任何「更准/更好」都只能在「已验证安全」的集合内被采纳。
