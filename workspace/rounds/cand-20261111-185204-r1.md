# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「联邦学习」×「力觉传感」）

> 第 54 轮把技能组合提升为动作-鲁棒双证书，但仍有两个盲区：(1) 动作剖面 `α_S` 仅在单机运动学空间标定，跨站点/跨力觉硬件不可复用；(2) `δ_a` 只能由仿真间接估计，缺少「动作是否真正落到接触层」的直接物理证据。本轮把 **力觉传感** 作为「动作真实性的接地判据」，把 **联邦学习** 作为「跨站点证书聚合 + 隐私保护」的机制。核心矛盾：H22：动作剖面与鲁棒谱在单站点标定后迁移到异质力觉硬件会系统性失真；H23：联邦聚合的全局证书在 non-IID 接触分布下可能「被平均掉」关键站点的失效模式。

## 0. 直觉与动机

**灵感 1（力觉 = 动作真实性的接地信号）**
直觉：第 54 轮的 `δ_a` 只能靠仿真间接估；而力/触觉残差 `r_f = ||f_meas − f_pred||` 是动作是否真正对齐的**直接物理证据**。因此把动作剖面从 `α_S(a)` 升级为 **力条件剖面 `α_S(a|f)`**：一个动作 `a` 只有在力包络 `F_S(a)` 内才是有效占用。接触滑移、力跟踪超差、冲击过载都能在力空间被直接否决，而不必等到任务层失败。

**灵感 2（联邦 = 把单机证书升级为分布鲁棒证书）**
直觉：每个站点 `i` 有自己的力觉数据、本构参数与硬件标定，原始力轨迹既敏感又不可共享。联邦学习只聚合**证书统计量**（`ρ_i`、力嵌入分布、组合边支持度），不上传原始力数据。关键不是「平均」，而是**分布鲁棒聚合**：在以站点经验分布为中心、半径由跨站点力分布散度 `D_F` 决定的 Wasserstein 球内取最坏情形，得到 `ρ_fed`。这样全局证书不会因某站点接触分布被平均掉而失真。

**灵感 3（多站点支持度的组合图）**
直觉：一条技能组合边若只在 1 个站点成立，就不该进全局组合图。定义边支持度 `supp(i,j) = 站点中 compat_s ≥ θ_a 的比例`，只有 `supp ≥ κ` 且跨站点力包络交集非空时边才保留。这把第 54 轮 SCOM 从「单机可组合」升级为「联邦可部署」。

**灵感 4（接触指纹的联邦校准 → 不共享力数据也能对齐 γ_ce）**
直觉：不同机器人力觉硬件标定不同，导致第 54 轮 `γ_ce` 跨站点失真；但同一物体/抓取在不同站点会产生可对齐的**接触指纹**。用联邦对比学习把本地力觉编码到共享嵌入空间，学习站点校准 `g_i`，得到 `γ_ce^F = g_j^{-1}∘γ_ce∘g_i`。原始力轨迹不出站点，(ε,δ)-DP 保护上传的梯度/统计量。

**灵感 5（力-动作-鲁棒三联合证书 + 联邦负迁移绊线）**
直觉：部署前证书 `J^F = (ρ_fed, ρ_F, A_cert, F_cert, γ_ce^F, δ_a, δ_f, κ, ε)`，其中 `ρ_F` 为力觉鲁棒维度（接触稳定/力跟踪/冲击/滑移），`F_cert = (F_core, F_buffer, δ_f)` 为力包络证书。部署后用力残差序列做在线序贯两样本检验（NTT），一旦残差分布显著偏移即回滚——这是「联邦证书 + 边端实时力证据」的闭环。

**灵感 6（金字塔扩展）**
直觉：在第 54 轮动作-协同层 `𝔸` 之上叠加 **力觉-联邦层 `𝔽`**：`𝔽_0` 物理接触极限，`𝔽_1` 力条件剖面与力包络，`𝔽_2` 联邦分布鲁棒聚合，`𝔽_3` 跨站点组合与在线绊线。跨层证书需同时携带 `A_cert` 与 `F_cert`。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（力条件动作剖面与力包络）**
动作空间 `A = A_c × A_e`，接触力空间 `F ⊂ R^6`。技能 `S` 的力条件剖面 `α_S : A × F → [0,1]`，力包络 `F_S(a) = { f | α_S(a|f) ≥ θ_cov }`。任务给出目标动作序列 `A_T` 与目标力轨迹 `F_T`。力覆盖 `cover_F(S, A_T, F_T)=1` 当且仅当 `∀ a∈A_T, ∃ f∈F_T: α_S(a|f) ≥ θ_cov ∧ f ∈ F_S(a)`。

**定义 122（力觉鲁棒性维度）**
`ρ_F : D_F → [0,1]`，`D_F = {cs(接触稳定), ft(力跟踪), imp(冲击容忍), slip(滑移裕度)}`。`ρ_F` 与第 53 轮 `ρ` 并列，组合时逐维取 min 并施加接触耦合修正。

**定义 123（跨站点力分布散度）**
以力觉编码 `φ` 把原始接触序列映射到 `z = φ(f)`。站点 `i,j` 的接触分布散度 `D_F(i,j) = W_1(P_i(z), P_j(z))`（1-Wasserstein），站点集合散度球半径 `D_max = max_{i,j} D_F(i,j)`。

**定义 124（分布鲁棒联邦鲁棒性谱）**
各站点本地谱 `ρ_i(d)`，全局
```
ρ_fed(d) = inf_{Q: W_1(Q,P̂) ≤ D_max} E_Q[ρ(d)] − λ_DP·σ_DP(d)
```
其中 `P̂` 为站点经验分布的混合，`σ_DP` 为 (ε,δ)-DP 噪声引入的估计标准差。若 `ρ(d)` 关于 `z` 为 `L_ρ`-Lipschitz，则由 Kantorovich–Rubinstein 对偶给出可计算下界 `ρ_fed(d) ≥ E_{P̂}[ρ(d)] − L_ρ·D_max − 2√σ_DP(d)`。若某站点 `ρ_i(d)` 远低于其余站点，DRO 下界会显式保留该失效模式，而非被平均稀释。

**定义 125（联邦组合图）**
`G_S^fed = (V, E^fed)`，边 `(i,j) ∈ E^fed` 当且仅当
```
supp(i,j) = (1/n) Σ_s 1[compat_s(S_i,S_j) ≥ θ_a] ≥ κ
∧ ⋂_s F_{S_i⊗S_j}(a) ≠ ∅,  ∀ a ∈ A_core
∧ ρ_fed(d) ≥ ρ_min,  ∀ d ∈ D ∪ D_F
```
边证书 `C_comp^fed = (A_overlap, F_overlap, supp, ρ_fed, γ_ce^F)`。

**定义 126（联邦接触校准映射）**
站点校准 `g_i : F → F*`（共享规范力系）。联邦校准映射 `γ_ce^F = g_j^{-1}∘γ_ce∘g_i`，学习目标为接触指纹对比损失 `L_con` + 动作对齐损失 `L_align`，且满足 (ε,δ)-DP。力对齐误差 `δ_f = sup_{f∈F_core} ||γ_ce^F(f) − f||`。

**定义 127（力-动作-鲁棒联合证书）**
```
J^F = (ρ_fed, ρ_F, A_cert, F_cert, γ_ce^F, δ_a, δ_f, κ, ε, evidence)
```
`F_cert = (F_core, F_buffer, δ_f)`。可部署当且仅当 `dom_J(T)=in ∧ δ_a<Θ_a ∧ δ_f<Θ_f ∧ κ≥κ_min ∧ ε≤ε_max ∧ NTT 未触发`。

**定义 128（联邦负迁移绊线 NTT）**
部署后在线监控力残差序列 `r_f(t)`。设源站点残差分布 `R_0`，用序贯两样本检验（CUSUM / 保形 p 值）检验 `H0: r_f(t) ~ R_0`。若 `p_t < α_ntt` 连续 `k` 次或 CUSUM 越阈，则触发回滚并上报联邦聚合，更新 `D_max` 与 `ρ_fed`。

## 2. 关键算法 伪代码

### IP-121 FCP（Force-Conditioned Profiling）

```python
def force_profile(skill, A_c, A_e, F_grid, sampler, theta_cov=0.8):
    alpha, envelope = {}, {}
    for a in itertools.product(A_c, A_e):
        fs = [f for f in F_grid if sampler.feasible(skill, a, f)]
        alpha[a] = {f: sampler.conf(skill, a, f) for f in fs}
        envelope[a] = convex_hull(fs)          # F_S(a)
    return alpha, envelope

def cover_F(alpha, envelope, A_T, F_T, theta_cov=0.8):
    return all(any(alpha[a].get(f, 0.0) >= theta_cov and in_hull(f, envelope[a])
                   for f in F_T) for a in A_T)
```

### IP-122 FedRSA（Federated Robust Spectrum Aggregation）

```python
def fed_robust_spectrum(sites, dims, D_max, L_rho, eps, delta):
    rho_fed = {}
    for d in dims:
        emp = mean([s.rho[d] for s in sites])
        dro_lb = emp - L_rho[d] * D_max           # W1 球内最坏期望的下界
        sigma_dp = dp_noise_std(eps, delta, n=len(sites))
        rho_fed[d] = clamp(dro_lb - 2 * sigma_dp, 0.0, 1.0)
    return rho_fed
```

### IP-123 FedSCG（Federated Skill Composition Graph）

```python
def fed_composition_graph(skills, sites, theta_a, kappa, rho_min, D_max, L_rho):
    G = nx.DiGraph()
    for i, s1 in enumerate(skills):
        for j, s2 in enumerate(skills):
            if i == j:
                continue
            compats = [site.compat(s1, s2) for site in sites]
            supp = sum(c >= theta_a for c in compats) / len(sites)
            if supp < kappa:
                continue
            F_over = intersect_all([site.force_envelope(s1, s2) for site in sites])
            if is_empty(F_over):
                continue
            rho_fed = fed_robust_spectrum(sites, DIMS + D_F, D_max, L_rho, eps, delta)
            if min(rho_fed.values()) < rho_min:
                continue
            G.add_edge(i, j, supp=supp, F_overlap=F_over, rho=rho_fed,
                       cert=C_comp_fed(overlap(s1, s2), F_over, supp, rho_fed, gamma_ce_F[i][j]))
    return G
```

### IP-124 FCC（Federated Contact Calibration）

```python
def federated_contact_calibration(sites, rounds, eps, delta):
    g = {s.id: init_calib() for s in sites}
    encoder = init_encoder()
    for _ in range(rounds):
        updates = []
        for s in sites:
            s.dp_sgd(encoder, loss=L_con + L_align, eps=eps, delta=delta)  # 梯度裁剪 + 噪声
            z_local = s.encode_force_fingerprints(encoder)
            g[s.id] = s.fit_calibration(encoder, z_local, g[s.id])
            updates.append(g[s.id].delta)
        encoder = secure_aggregate(updates)        # 服务器只见掩码聚合量
    gamma_ce_F = {(i, j): compose_inverse(g[j], gamma_ce, g[i])
                  for i in sites for j in sites}
    return gamma_ce_F, encoder
```

### IP-125 FJTC（Force Joint Transfer Certificate）

```python
def force_joint_certificate(skill_seq, gamma_ce_F, budgets):
    A_core = reduce(intersect, [s.alpha for s in skill_seq])
    F_core = reduce(intersect, [s.envelope for s in skill_seq])
    delta_a = max_alignment_error(gamma_ce_F, A_core)
    delta_f = max_force_alignment_error(gamma_ce_F, F_core)
    rho_fed = fed_robust_spectrum(sites, DIMS + D_F, budgets.D_max, budgets.L_rho, budgets.eps, budgets.delta)
    rho_F = force_robustness(skill_seq)
    if delta_a > budgets.delta_a or delta_f > budgets.delta_f:
        return ('reject', 'alignment_budget', delta_a, delta_f)
    if min(rho_fed.values()) < budgets.rho_min or min(rho_F.values()) < budgets.rho_F_min:
        return ('reject', 'robustness', rho_fed, rho_F)
    if not ntt_armed(source_stats=rho_F):
        return ('reject', 'tripwire_unarmed')
    return ('ok', J_F(rho_fed, rho_F, A_cert(A_core), F_cert(F_core),
                      gamma_ce_F, delta_a, delta_f, supp, budgets.eps))
```

### IP-126 NTT（Negative Transfer Tripwire）

```python
def ntt_monitor(residual_stream, R0, alpha=0.01, k=3):
    cusum, hits = 0.0, 0
    for r_f in residual_stream:
        p = conformal_pvalue(r_f, R0)              # 或序贯似然比
        cusum = max(0.0, cusum + (alpha - p))
        hits = hits + 1 if p < alpha else 0
        if hits >= k or cusum > threshold(R0, alpha):
            return ('rollback', 'force_negative_transfer', r_f)
    return ('ok', None)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| FCP | O(|A|·|F|·|S|) | O(|A|·|F|) | 力包络凸化、采样覆盖 |
| FedRSA | O(n·(|D|+|D_F|)) | O(n·|D|) | W1 对偶下界、DP 噪声标定 |
| FedSCG | O(|S|²·n·|A|) | O(|S|²+n) | supp 阈值 sound、力交非空 |
| FCC | O(rounds·n·|F|) | O(|F*|) | 对比对齐、(ε,δ)-DP、安全聚合 |
| FJTC | O(|S|·(|A|+|F|)) | O(|A|+|F|) | δ_a/δ_f 预算闭合、DRO 下界 |
| NTT | O(T) 流式 | O(|R0|) | 保形校准、假阴性率可界 |

**正确性定理（Federated Force-Aware Composition Soundness）**
承接第 54 轮 (A26)–(A28)，新增：
**(A29)** 力条件剖面 `α_S(a|f)` 由力觉仿真/实机校准，力对齐误差 `δ_f` 有界；
**(A30)** 站点接触分布在 `W_1` 球半径 `D_max` 内，且 `ρ(d)` 关于力嵌入为 `L_ρ`-Lipschitz；
**(A31)** 联邦聚合采用 (ε,δ)-DP 裁剪 + 噪声，`n` 站点聚合噪声标准差 `σ_DP`；
**(A32)** NTT 序贯检验假阴性率 `≤ β_ntt`。
则：
```
P_success ≥ 1 − Σ_{d∈D∪D_F}(1−ρ_fed(d)) − β_E − P(δ_a>Θ_a)
            − P(δ_f>Θ_f) − β_ntt − 2√σ_DP·|D∪D_F|
```
关键：力觉下界**先扣 DRO 半径、再扣 DP 噪声、最后扣绊线假阴性**——即「隐私越强 / 站点越异质，证书越保守」是可量化的。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 力觉硬件异质致 D_max 过大、证书过保守 | 高 | 分层校准 + 站点聚类分域 DRO |
| DP 噪声淹没稀有失效模式 | 高 | 稀有事件重加权 + 本地 DP + 安全聚合 |
| 力包络交集为空致组合图过稀 | 中 | 概率力包络软化 + 缓冲带 |
| 接触指纹可被反演泄漏任务信息 | 高 | 力嵌入 DP + 梯度裁剪 + 指纹扰动 |
| NTT 阈值抖动造成误回滚 | 中 | 保形校准 + 滞回 + 冷启动锚点 |

## 6. 本轮最大风险

**一句话**：力觉-联邦方案把技能组合从「动作-鲁棒双证书」推进到「力-动作-鲁棒三联合证书」，但其 soundness **三重依赖力包络标定的真实性、D_max 是站点异质性的真实上界、以及 DP 噪声不抹掉少数站点的稀有失效模式**；一旦力包络欠标定、或联邦聚合把某站点的滑移失效平均掉，全局证书就会退化为「隐私安全的错觉」，导致在错误接触工况上系统性部署，故必须以 **分域 DRO + 稀有事件重加权 + NTT 在线绊线** 三重护栏，宁可保守拒绝，绝不把联邦平均值当作部署前提。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-FedTouch（FCP×FedRSA×FedSCG×FCC×FJTC×NTT）

> 承接第 54 轮产物 v31。本轮在「动作-鲁棒双证书」之上增加 **力觉接地** 与 **联邦聚合** 两大维度：
> - **FCP（Force-Conditioned Profiling）**：力条件动作剖面 `α_S(a|f)` + 力包络 `F_S(a)`，把动作真实性接地到接触层；
> - **FedRSA（Federated Robust Spectrum Aggregation）**：Wasserstein 球内分布鲁棒 + DP 噪声的联邦谱 `ρ_fed`；
> - **FedSCG（Federated Skill Composition Graph）**：带多站点支持度 `κ` 与跨站点力包络交的联邦组合图；
> - **FCC（Federated Contact Calibration）**：基于接触指纹的联邦校准映射 `γ_ce^F`，原始力数据不出站点；
> - **FJTC（Force Joint Transfer Certificate）**：力-动作-鲁棒联合证书 `J^F`；
> - **NTT（Negative Transfer Tripwire）**：部署后力残差序贯检验的负迁移绊线。

### IP-121 FCP

```python
def force_profile(skill, A_c, A_e, F_grid, sampler, theta_cov=0.8):
    alpha, envelope = {}, {}
    for a in itertools.product(A_c, A_e):
        fs = [f for f in F_grid if sampler.feasible(skill, a, f)]
        alpha[a] = {f: sampler.conf(skill, a, f) for f in fs}
        envelope[a] = convex_hull(fs)
    return alpha, envelope

def cover_F(alpha, envelope, A_T, F_T, theta_cov=0.8):
    return all(any(alpha[a].get(f, 0.0) >= theta_cov and in_hull(f, envelope[a])
                   for f in F_T) for a in A_T)
```

### IP-122 FedRSA

```python
def fed_robust_spectrum(sites, dims, D_max, L_rho, eps, delta):
    rho_fed = {}
    for d in dims:
        emp = mean([s.rho[d] for s in sites])
        dro_lb = emp - L_rho[d] * D_max        # W1 球内最坏期望下界
        sigma_dp = dp_noise_std(eps, delta, n=len(sites))
        rho_fed[d] = clamp(dro_lb - 2 * sigma_dp, 0.0, 1.0)
    return rho_fed
```

### IP-123 FedSCG

```python
def fed_composition_graph(skills, sites, theta_a, kappa, rho_min, D_max, L_rho):
    G = nx.DiGraph()
    for i, s1 in enumerate(skills):
        for j, s2 in enumerate(skills):
            if i == j:
                continue
            compats = [site.compat(s1, s2) for site in sites]
            supp = sum(c >= theta_a for c in compats) / len(sites)
            if supp < kappa:
                continue
            F_over = intersect_all([site.force_envelope(s1, s2) for site in sites])
            if is_empty(F_over):
                continue
            rho_fed = fed_robust_spectrum(sites, DIMS + D_F, D_max, L_rho, eps, delta)
            if min(rho_fed.values()) < rho_min:
                continue
            G.add_edge(i, j, supp=supp, F_overlap=F_over, rho=rho_fed,
                       cert=C_comp_fed(overlap(s1, s2), F_over, supp, rho_fed, gamma_ce_F[i][j]))
    return G
```

### IP-124 FCC

```python
def federated_contact_calibration(sites, rounds, eps, delta):
    g = {s.id: init_calib() for s in sites}
    encoder = init_encoder()
    for _ in range(rounds):
        updates = []
        for s in sites:
            s.dp_sgd(encoder, loss=L_con + L_align, eps=eps, delta=delta)
            z_local = s.encode_force_fingerprints(encoder)
            g[s.id] = s.fit_calibration(encoder, z_local, g[s.id])
            updates.append(g[s.id].delta)
        encoder = secure_aggregate(updates)
    gamma_ce_F = {(i, j): compose_inverse(g[j], gamma_ce, g[i])
                  for i in sites for j in sites}
    return gamma_ce_F, encoder
```

### IP-125 FJTC

```python
def force_joint_certificate(skill_seq, gamma_ce_F, budgets):
    A_core = reduce(intersect, [s.alpha for s in skill_seq])
    F_core = reduce(intersect, [s.envelope for s in skill_seq])
    delta_a = max_alignment_error(gamma_ce_F, A_core)
    delta_f = max_force_alignment_error(gamma_ce_F, F_core)
    rho_fed = fed_robust_spectrum(sites, DIMS + D_F, budgets.D_max, budgets.L_rho, budgets.eps, budgets.delta)
    rho_F = force_robustness(skill_seq)
    if delta_a > budgets.delta_a or delta_f > budgets.delta_f:
        return ('reject', 'alignment_budget', delta_a, delta_f)
    if min(rho_fed.values()) < budgets.rho_min or min(rho_F.values()) < budgets.rho_F_min:
        return ('reject', 'robustness', rho_fed, rho_F)
    if not ntt_armed(source_stats=rho_F):
        return ('reject', 'tripwire_unarmed')
    return ('ok', J_F(rho_fed, rho_F, A_cert(A_core), F_cert(F_core),
                      gamma_ce_F, delta_a, delta_f, supp, budgets.eps))
```

### IP-126 NTT

```python
def ntt_monitor(residual_stream, R0, alpha=0.01, k=3):
    cusum, hits = 0.0, 0
    for r_f in residual_stream:
        p = conformal_pvalue(r_f, R0)
        cusum = max(0.0, cusum + (alpha - p))
        hits = hits + 1 if p < alpha else 0
        if hits >= k or cusum > threshold(R0, alpha):
            return ('rollback', 'force_negative_transfer', r_f)
    return ('ok', None)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| FCP | O(\|A\|·\|F\|·\|S\|) | O(\|A\|·\|F\|) | 力包络凸化、采样覆盖 ≥ 95% |
| FedRSA | O(n·(\|D\|+\|D_F\|)) | O(n·\|D\|) | W1 对偶下界、DP 噪声标定 |
| FedSCG | O(\|S\|²·n·\|A\|) | O(\|S\|²+n) | supp 阈值 sound、力交非空 |
| FCC | O(rounds·n·\|F\|) | O(\|F*\|) | 对比对齐、(ε,δ)-DP、安全聚合 |
| FJTC | O(\|S\|·(\|A\|+\|F\|)) | O(\|A\|+\|F\|) | `δ_a/δ_f` 预算闭合、DRO 下界 |
| NTT | O(T) 流式 | O(\|R0\|) | 保形校准、假阴性率可界 |

**正确性定理（Federated Force-Aware Composition Soundness）**
假设第 54 轮 (A26)-(A28) 成立；新增 **(A29)** 力条件剖面由力觉仿真/实机校准且 `δ_f` 有界；**(A30)** 站点接触分布在 `W_1` 球半径 `D_max` 内且 `ρ` 关于力嵌入 `L_ρ`-Lipschitz；**(A31)** 联邦聚合为 (ε,δ)-DP 裁剪+噪声，聚合噪声标准差 `σ_DP`；**(A32)** NTT 假阴性率 `≤ β_ntt`。则：
```
P_success ≥ 1 − Σ_{d∈D∪D_F}(1−ρ_fed(d)) − β_E − P(δ_a>Θ_a)
            − P(δ_f>Θ_f) − β_ntt − 2√σ_DP·|D∪D_F|
```
关键：**力觉下界先扣 DRO 半径、再扣 DP 噪声、最后扣绊线假阴性**；隐私越强 / 站点越异质，证书越保守。

## 5. 本轮最大风险

**一句话**：力觉-联邦方案把技能组合从「动作-鲁棒双证书」推进到「力-动作-鲁棒三联合证书」，但其 soundness **三重依赖力包络标定的真实性、D_max 是站点异质性的真实上界、以及 DP 噪声不抹掉少数站点的稀有失效模式**；一旦力包络欠标定、或联邦聚合把某站点的滑移失效平均掉，全局证书就会退化为「隐私安全的错觉」，导致在错误接触工况上系统性部署，故必须以 **分域 DRO + 稀有事件重加权 + NTT 在线绊线** 三重护栏，宁可保守拒绝，绝不把联邦平均值当作部署前提。
