# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「状态机」×「柔顺控制」）

> 第 54 轮把技能组合从能力匹配推进到动作空间占用剖面、组合图与云边动作双证书，但仍把“动作”当作**静态可达集合**，隐含假设：动作是瞬时、无接触、位置主导的。本轮引入**接触相状态机**与**柔顺（阻抗/导纳）控制**。核心矛盾：H22：真实操作是“离散接触相切换 + 连续力调节”的混合过程，第 54 轮的静态 `α_S` 无法表达“何时切换、切换时力是否连续”；H23：位置型动作证书在接触瞬间会退化为刚性冲击，若柔顺参数 `(K,D)` 未被证书覆盖，组合在边端会出现能量注入与非无源切换，导致看似“动作可达”实则“接触失稳”。

## 0. 直觉与动机

**灵感 1（技能即混合状态机 → 从动作集合到接触相自动机）**
直觉：技能不是“能做到哪些动作”，而是“在哪些接触相里、用哪条连续律、满足什么守卫时切换”。因此技能 `S` 应建模为**混合状态机** `H_S`：离散模式 `Q_S`（approach / contact / regulate / retreat / recover），每模式带一条阻抗/导纳连续动力学 `f_S`，边上是**守卫** `Guard_S`（力、接触、位姿、时间谓词）。这样“技能可执行”变成“存在一条从 `q_0` 到 `Q_F` 且始终满足安全不变式 `Inv_S` 的混合轨迹”。

**灵感 2（柔顺动作 = 阻抗三元组 → 把动作空间扩展为 (x\*,K,D)）**
直觉：接触任务里真正可调的“动作”是**平衡点 + 刚度 + 阻尼**：`a=(x*,K,D)`，`K,D≻0`。硬 `K` 精确但易冲击，软 `K` 安全但易失位；柔顺控制就是在**柔顺包络** `C_S` 内选一条既不过硬、也不过软的参数轨。第 54 轮的 `α_S` 只覆盖了 `x*`，本轮把它细化为**柔顺剖面** `κ_S(a)`，并要求沿轨迹满足无源性（能量不净注入）。

**灵感 3（组合 = 守卫对齐的乘积自动机 + 无源切换）**
直觉：两技能能否组合，不只看动作交集，而要看**守卫是否可同步**（共享力/位姿变量上不产生死锁或冲突守卫）以及**切换是否无源**（能量罐 `E_q` 不被新模式的能量注入打穿）。组合规划因此从第 54 轮的图最短路，升级为**乘积自动机上的模式序列搜索**，每条边附“守卫证书 + 能量裕度”。

**灵感 4（云边协同 = 离散模式同步 + 连续柔顺跟随）**
直觉：云端适合规划**离散模式序列**与粗守卫时序 `P^Q_c`；边端适合高频执行**连续柔顺跟随**并以力估计监视守卫。两侧的对齐不再只是 `γ_ce` 的动作映射，而是**守卫时序同步裕度** `σ_sync`：云端以为“力到阈值才切”，边端却提前/滞后触发，就是模式错位。错位通过 `Explain_loop` 回传，云端重排模式序列或放宽/收紧守卫阈值。

**灵感 5（金字塔扩展 → 增加柔顺-状态层 𝕊）**
直觉：在第 54 轮的动作协同层 `𝔸` 之上叠加**柔顺-状态层 `𝕊`**：`𝕊_0` 物理接触/摩擦极限，`𝕊_1` 单技能混合自动机，`𝕊_2` 组合自动机的守卫与能量约束，`𝕊_3` 云边模式同步。联合证书升级为 `(ρ, A_cert, H_S, π_pass, σ_sync)`。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（技能混合状态机 HSM）**
技能 `S` 建模为 `H_S = (Q_S, A_S, f_S, Guard_S, Reset_S, Inv_S, q_0, Q_F)`：
- `Q_S`：离散接触模式集合，含 `approach, contact, regulate, retreat, recover`；
- `A_S = X × 𝒦 × 𝒟`：连续柔顺动作，`x*∈X` 平衡点，`K∈𝒦, D∈𝒟` 对称正定；
- `f_S: Q_S × A_S → 𝔛`：连续向量场（阻抗/导纳控制律）；
- `Guard_S ⊆ Q_S × Q_S × 2^{X×F}`：切换守卫（力/接触/位姿/时间谓词）；
- `Reset_S: Q_S×Q_S×X → X`：切换重置（位置/速度连续或按契约跳变）；
- `Inv_S: Q_S → 2^{X×F}`：安全不变式；
- `q_0∈Q_S`，`Q_F⊆Q_S`：初始与接受模式。
**混合轨迹** `τ=(q(t), x(t), a(t))` 合法当且仅当 `∀t: (x(t),F(t))∈Inv_S(q(t))`，且每次切换由 `Guard_S` 触发、切换非 Zeno（存在最小驻留时间 `dwell_min`）。

**定义 122（柔顺动作剖面与柔顺包络）**
柔顺剖面 `κ_S: A_S → [0,1]`，`κ_S(a)≥θ_cov` 表示技能在阻抗参数 `a` 下可执行。**柔顺包络**
```
C_S = { (x*,K,D) | λ_min(K)≥K_min, λ_max(K)≤K_max,
                  ζ(K,D)∈[ζ_min,ζ_max], ||x*||≤x_max }
```
其中 `ζ` 为阻尼比。**柔顺覆盖** `cover_c(S,A_T)=1` 当且仅当 `∀a∈A_T, κ_S(a)≥θ_cov`，且沿 `A_T` 的轨迹满足 `π_S≥0`（定义 124）。

**定义 123（守卫兼容性与状态机组合）**
两状态机在共享变量集 `V_sh` 上的守卫相容度
```
gcompat(H_i,H_j) = |Guard_i|_Vsh ∩ Guard_j| / |Guard_i ∪ Guard_j|
```
组合 `H_{i⊗j}` 为带共享变量同步的**乘积自动机**（共享守卫须同步，异步边不得写共享变量）。组合可判定条件：
```
gcompat(H_i,H_j) ≥ θ_g ∧ deadlock_free(H_{i⊗j})
∧ passivity_safe(∀ e∈E_{i⊗j}) ∧ ρ_{S_i⊗S_j}(d) ≥ ρ_min ∀d
```

**定义 124（无源能量罐与无源安全切换）**
每个模式 `q` 维护能量罐 `E_q(t)≥0`，控制律满足 `dE_q/dt ≤ F^T ẋ − E_diss`。切换 `q→q'` 注入能量
```
ΔE_{q→q'} = max(0, E_{q'}(t^+) − E_q(t^-))
```
无源裕度
```
π_S(q→q') = E_q(t^-) − E_min − ΔE_{q→q'} − E_diss^min·dwell_min
```
若 `∀` 可达切换 `π_S≥π_min≥0`，称 `H_S` 柔顺无源安全。该定义把“切换冲击”从定性经验变为可记账的**能量预算**。

**定义 125（云边状态机同步契约）**
`C^{ce}_H = (P^Q_c, P^A_e, ε_g, τ_sync, σ_ce)`：
- `P^Q_c=⟨q_1,…,q_k⟩`：云端离散模式序列与粗守卫时序；
- `P^A_e`：边端连续柔顺执行轨迹与力/位姿估计 `q̂_e(t), F̂_e(t)`；
- `ε_g = max_t ||g_c(t) − g_e(t)||`：守卫谓词对齐误差；
- `σ_ce(t) = t^c_{guard} − t^e_{guard}`：守卫触发时序裕度（取安全侧）；
- `τ_sync`：同步与回传允许延迟。
`Explain_loop` 在 `ε_g>ε_g^max` 或 `σ_ce<0` 时回传根因（模式错位/守卫阈值不当），触发 `replan(P^Q_c)`。

**定义 126（柔顺-状态联合证书）**
`J' = (ρ, A_cert, H_S, π_pass, σ_sync, evidence)`：
- `ρ`：第 53 轮鲁棒性谱；`A_cert`：第 54 轮动作占用证书；
- `H_S`：组合后的混合自动机；
- `π_pass = min_{q→q'} π_S(q→q')`：全路径最小无源裕度；
- `σ_sync = min_t σ_ce(t)`：最小同步裕度；
- `evidence`：接触相仿真反例、守卫触发日志、能量罐轨迹。
可部署当且仅当 `dom_{J'}(T)=in ∧ π_pass≥π_min ∧ σ_sync≥0 ∧ δ_a<Θ_a`。

## 2. 关键算法 伪代码

### IP-121 HSL（HSM Learning / 接触相分割与守卫归纳）

```python
def learn_hsm(demos, theta_f, dwell_min):
    phases = segment_by_contact(demos, dF_threshold=theta_f,
                                min_dwell=dwell_min)   # 力导数 + 速度突变分割
    Q = cluster_modes([p.fingerprint for p in phases])
    guards = induce_guards(phases.transitions,
                           features=['F', 'dx', 'contact', 't'])  # 决策树/谓词学习
    f = {q: fit_impedance_law(phases, q) for q in Q}
    Inv = {q: safe_envelope(phases, q) for q in Q}   # 力/位姿安全盒
    return HSM(Q, guards, f, Inv, q0=Q.start, QF=Q.accept)
```

### IP-122 CAP（Compliance Action Profile）

```python
def compliance_profile(skill, grid_x, grid_K, grid_D, sim, E_budget):
    kappa = {}
    for a in product(grid_x, grid_K, grid_D):
        if not in_envelope(a, C_S):      # 定义 122 柔顺包络
            kappa[a] = 0.0; continue
        ok, E_net, contact_ok = sim.episode(skill, a)
        kappa[a] = 1.0 if (ok and contact_ok and E_net <= E_budget) else 0.0
    return kappa
```

### IP-123 GAC（Guard-Aligned Composition）

```python
def compose_hsm(Hi, Hj, theta_g, rho_min):
    H = product_automaton(Hi, Hj, shared_vars=Hi.V & Hj.V,
                          sync='guard')            # 共享守卫同步
    for s in list(H.states):                       # 守卫不兼容即删态
        if guard_compat(Hi, Hj, s, theta_g) < theta_g:
            H.remove_state(s)
    if has_deadlock(H):
        return ('reject', 'deadlock', witness(H))
    for e in H.edges:
        if not passivity_safe(e):                  # 定义 124
            return ('reject', 'nonpassive_transition', e, pi_of(e))
    rho = compose_robustness_chain(Hi.rho, Hj.rho, K)
    if min(rho.values()) < rho_min:
        return ('reject', 'robustness_fail', rho)
    return ('ok', H, rho)
```

### IP-124 PST（Passivity-Safe Transition）

```python
def passive_transition(E_tank, q_from, q_to, a_to, dwell_min, E_min):
    dE = energy_injection(q_from, q_to, a_to)     # 切换冲量/势能跳变
    pi = E_tank - E_min - dE - E_diss_min * dwell_min
    if pi < pi_min:
        return ('reject', 'tank_depleted', pi)
    return ('ok', E_tank - dE - E_diss_min * dwell_min, pi)
```

### IP-125 CES（Cloud-Edge State Synchronization）

```python
def cloud_mode_plan(task, H, rho_min, pi_min):
    path = search(H, q0=task.q0, QF=task.QF,
                  cost=transition_cost,
                  constraint=lambda e: e.rho >= rho_min and e.pi >= pi_min)
    return [(q, coarse_guard(q)) for q in path]

def edge_sync(P_c_Q, estimator, guard_monitor, eps_g_max):
    for q, g_c in P_c_Q:
        q_hat, conf = estimator.mode()
        if q_hat != q and conf > conf_min:
            return ('reject', 'mode_mismatch', q_hat, q)
        while not guard_monitor.crossed(g_c):
            step_compliant(q)                     # 高频柔顺跟随
            if guard_monitor.time_since_expected() > tau_sync:
                return ('reject', 'guard_timeout', q)
        if abs(guard_monitor.last_error()) > eps_g_max:
            return ('reject', 'guard_offset', guard_monitor.last_error())
    return ('ok',)
```

### IP-126 JCS（Joint Compliance-State Certificate）

```python
def joint_compliance_cert(skill_seq, gamma_ce, delta_a_budget,
                          pi_min, sigma_min):
    A_core = reduce(intersection, [s.alpha for s in skill_seq])
    delta_a = max_alignment_error(gamma_ce, A_core)
    if delta_a > delta_a_budget:
        return ('reject', 'action_mismatch', delta_a)

    H, rho = compose_hsm_chain(skill_seq)          # IP-123
    pi_pass = min(e.pi for e in H.edges)           # IP-124
    if pi_pass < pi_min:
        return ('reject', 'passivity_fail', pi_pass)

    sigma = min_sync_margin(H, gamma_ce)           # IP-125
    if sigma < sigma_min:
        return ('reject', 'sync_fail', sigma)

    return ('ok', JointCert(rho, A_cert(A_core), H, pi_pass, sigma))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| HSL | O(N·T + |Q|·|Φ|) | O(|Q|·|Φ|) | 接触相分割完备、守卫可学习 |
| CAP | O(|X|·|K|·|D|·T_sim) | O(|A_S|) | 包络内采样 + 能量预算闭合 |
| GAC | O(|Q_i|·|Q_j|·|E|) | O(|Q_i|·|Q_j|) | 乘积同步 sound、死锁可达性 |
| PST | O(|E|) | O(|Q|) | 能量守恒记账、`π` 单调 |
| CES | O(|P|·T_sync + |E|) | O(|V|+|E|) | 守卫事件触发、时序可观测 |
| JCS | O(|Q|·|E| + |𝔇_ρ|) | O(|Q|+|𝔇_ρ|) | 联合证书 sound、预算闭合 |

**正确性定理（Compliance-State Composition Soundness）**
假设第 54 轮 (A26)–(A28) 成立；新增 **(A29)** 接触相分割与守卫谓词可由力/位姿观测校准，守卫误判率 `≤ β_g`；**(A30)** 每个模式的柔顺控制律无源，且切换能量注入可上界估计；**(A31)** 云边守卫时序可观测，`σ_ce` 估计误差 `≤ β_s`；**(A32)** 组合自动机非 Zeno（`dwell_min>0`）。则
```
P_success ≥ 1 − Σ_d(1−ρ_min(d)) − P(deadlock)
            − P(π_pass<π_min) − P(ε_g>ε_g^max) − β_E − β_g − β_s
```
关键：**守卫对齐先于动作对齐**，**无源裕度先于性能优化**，**模式同步先于连续跟随**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 乘积自动机状态爆炸 | 高 | 分层抽象 + 对称约简 + 守卫哈希索引 |

## 6. 本轮最大风险

**一句话**：把技能升级为“接触相状态机 + 柔顺阻抗动作”确实补上了第 54 轮缺失的切换语义与接触安全，但其 soundness **同时依赖守卫谓词的可学习性、切换能量记账的准确性、以及云边模式时序的可观测性**；一旦接触模型 sim-to-real 断层使守卫误触发，或能量注入被低估导致能量罐悄然打穿，组合状态机就会在真实边端出现**模式错位 + 非无源冲击**的连锁失稳，故必须以“保守守卫 + 能量罐在线审计 + 模式错位绊线”三重护栏，宁可牺牲柔顺性能，绝不把“仿真里能切换”当作“接触中可部署”。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-CompliantHSM（HSM×CAP×GAC×PST×CES×JCS）

> 承接第 54 轮产物 v31。本轮在“动作空间剖面 + 组合图 + 云边动作双证书”之上，增加 **接触相状态机化、柔顺动作剖面化、守卫对齐组合、无源安全切换、云边模式同步** 五个算子：
> - **HSM（Hybrid Skill Machine）**：技能 = 离散接触相 + 连续阻抗律 + 守卫；
> - **CAP（Compliance Action Profile）**：动作从 `x*` 扩展为 `(x*,K,D)`，给出柔顺剖面与包络；
> - **GAC（Guard-Aligned Composition）**：守卫兼容的乘积自动机组合 + 死锁/无源判定；
> - **PST（Passivity-Safe Transition）**：能量罐记账，切换必须 `π_pass ≥ π_min`；
> - **CES（Cloud-Edge State Synchronization）**：云端离散模式序列 ↔ 边端连续柔顺跟随，守卫时序对齐；
> - **JCS（Joint Compliance-State Certificate）**：`J'=(ρ,A_cert,H_S,π_pass,σ_sync)` 联合证书。
>
> IP 编号：IP-121~IP-126（共 6 个新增）；升级 IP-115/116/117/118，把“静态动作空间”替换为“状态机-阻抗动作空间”。

### IP-122 CAP

```python
def compliance_profile(skill, grid_x, grid_K, grid_D, sim, E_budget):
    kappa = {}
    for a in product(grid_x, grid_K, grid_D):
        if not in_envelope(a, C_S):
            kappa[a] = 0.0; continue
        ok, E_net, contact_ok = sim.episode(skill, a)
        kappa[a] = 1.0 if (ok and contact_ok and E_net <= E_budget) else 0.0
    return kappa

def cover_c(kappa, A_T, theta_cov=0.8):
    return all(kappa.get(a, 0.0) >= theta_cov for a in A_T)
```

### IP-123 GAC

```python
def compose_hsm(Hi, Hj, theta_g, rho_min):
    H = product_automaton(Hi, Hj, shared_vars=Hi.V & Hj.V, sync='guard')
    for s in list(H.states):
        if guard_compat(Hi, Hj, s, theta_g) < theta_g:
            H.remove_state(s)
    if has_deadlock(H):
        return ('reject', 'deadlock', witness(H))
    for e in H.edges:
        if not passivity_safe(e):
            return ('reject', 'nonpassive_transition', e, pi_of(e))
    rho = compose_robustness_chain(Hi.rho, Hj.rho, K)
    if min(rho.values()) < rho_min:
        return ('reject', 'robustness_fail', rho)
    return ('ok', H, rho)
```

def passive_transition(E_tank, q_from, q_to, a_to, dwell_min, E_min):
    dE = energy_injection(q_from, q_to, a_to)
    pi = E_tank - E_min - dE - E_diss_min * dwell_min

def edge_sync(P_c_Q, estimator, guard_monitor, eps_g_max):
    for q, g_c in P_c_Q:
        q_hat, conf = estimator.mode()
        if q_hat != q and conf > conf_min:
            return ('reject', 'mode_mismatch', q_hat, q)
        while not guard_monitor.crossed(g_c):

            if guard_monitor.time_since_expected() > tau_sync:
                return ('reject', 'guard_timeout', q)

### IP-126 JCS

```python
def joint_compliance_cert(skill_seq, gamma_ce, delta_a_budget,
                          pi_min, sigma_min):
    A_core = reduce(intersection, [s.alpha for s in skill_seq])
    delta_a = max_alignment_error(gamma_ce, A_core)
    if delta_a > delta_a_budget:
        return ('reject', 'action_mismatch', delta_a)

    H, rho = compose_hsm_chain(skill_seq)
    pi_pass = min(e.pi for e in H.edges)
    if pi_pass < pi_min:
        return ('reject', 'passivity_fail', pi_pass)

    sigma = min_sync_margin(H, gamma_ce)
    if sigma < sigma_min:
        return ('reject', 'sync_fail', sigma)

    return ('ok', JointCert(rho, A_cert(A_core), H, pi_pass, sigma))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| HSL | O(N·T + |Q|·|Φ|) | O(|Q|·|Φ|) | 分割完备、守卫可校准 |
| CAP | O(|X|·|K|·|D|·T_sim) | O(|A_S|) | 包络内采样、能量预算闭合 |
| GAC | O(|Q_i|·|Q_j|·|E|) | O(|Q_i|·|Q_j|) | 乘积同步 sound、死锁可判定 |
| PST | O(|E|) | O(|Q|) | 能量记账守恒、`π` 单调 |
| CES | O(|P|·T_sync + |E|) | O(|V|+|E|) | 事件触发、时序可观测 |
| JCS | O(|Q|·|E| + |𝔇_ρ|) | O(|Q|+|𝔇_ρ|) | 联合证书 sound、预算闭合 |

**正确性定理（Compliance-State Composition Soundness）**
假设第 54 轮 (A26)–(A28) 成立；新增 **(A29)** 接触相分割与守卫谓词可由力/位姿观测校准，误判率 `≤ β_g`；**(A30)** 各模式柔顺控制律无源且切换能量注入可上界估计；**(A31)** 云边守卫时序可观测，`σ_ce` 估计误差 `≤ β_s`；**(A32)** 组合自动机非 Zeno（`dwell_min>0`）。则
```
P_success ≥ 1 − Σ_d(1−ρ_min(d)) − P(deadlock)
            − P(π_pass<π_min) − P(ε_g>ε_g^max) − β_E − β_g − β_s
```
关键：**守卫对齐先于动作对齐**，**无源裕度先于性能优化**，**模式同步先于连续跟随**。

## 5. 本轮最大风险

**一句话**：把技能升级为“接触相状态机 + 柔顺阻抗动作”补上了切换语义与接触安全，但其 soundness **同时依赖守卫谓词可学习、切换能量记账准确、云边模式时序可观测**；一旦接触模型 sim-to-real 断层使守卫误触发、或能量注入被低估致能量罐悄然打穿，组合状态机就会在真实边端出现模式错位 + 非无源冲击的连锁失稳，故必须以“保守守卫 + 能量罐在线审计 + 模式错位绊线”三重护栏，宁可牺牲柔顺性能，绝不把“仿真里能切换”当作“接触中可部署”。
