# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「视觉-语言-动作模型」×「开源硬件」）

> 第 54 轮已把技能组合推进到动作空间剖面 `α_S`、组合图 `G_S` 与云边协同联合证书 `J`。本轮聚焦 **语义-物理解耦、跨具身证书传递、可复现负证据**。核心矛盾：H22：VLA 的语义泛化（语言→意图→token）与其动作头绑定特定具身，语义正确并不等于物理可执行；H23：开源硬件让复制与复现变廉价，但一次 fork 就可能静默改变动作包络与传感器动力学，使上一代证书在新硬件上「看似有效」。

## 0. 直觉与动机

**灵感 1（VLA 的两层结构 → 语义 token 与物理动作之间的接地算子）**
直觉：VLA 策略 `π_VLA(图像, 指令) → 动作 token 序列 τ`。token 是**语义层**的，物理动作 `a` 是**执行层**的，两者之间缺一个显式的接地映射 `g : T × ℰ → Δ(A)`。第 54 轮的 `α_S(a)` 只描述了物理动作占用，却默认「技能知道该做什么」；对 VLA 而言，**「说什么」和「做什么」被 token 空间隔开**。因此本轮的起点是：把技能从 `S` 升级为二元组 `(π_VLA, g; E)`，并在动作空间之前先检验 **语义↔物理的一致性**。

**灵感 2（开源硬件 = 可测量的具身 → 具身契约）**
直觉：闭源机器人只能黑箱标定；开源硬件（开放 BOM、RTL、固件、标定脚本）使「具身」第一次可以被**机器读取和署名**。于是定义 **具身契约 `E = (h, U, Φ_s, Φ_a, L_safe, τ_emb)`**：`h` 为硬件来源哈希，`U` 为运动学/动力学模型，`Φ_s` 传感器模态与噪声，`Φ_a` 执行器包络，`L_safe` 安全边界，`τ_emb` 控制延迟上界。VLA 的接地算子 `g` 必须**相对某个 `E` 签发**，脱离 `h` 的证书天然无效。

**灵感 3（硬件 fork 图 → 证书沿派生边传递而非重训）**
直觉：开源硬件的本质是**可派生**。硬件变体构成派生 DAG `F = (ℋ, Δ)`，节点是带哈希的硬件修订，边是 fork 改动 `ΔH`（换电机、改连杆、换相机、改固件调度）。若每次 fork 都重训 VLA，开源硬件的价值就归零。正解是让证书沿 `F` 传播：若改动 `ΔH` 在动作空间上满足 Lipschitz 预算且不触碰接地支撑集 `Σ`，则 `Λ(J, ΔH) = J'` 可继承；否则强制**回到标定**。这把「证书有效性」从状态空间、动作空间扩展到 **硬件空间**。

**灵感 4（负证据账本 → 开源让失败成为可复现、可签名的公共资产）**
直觉：开源硬件最强的不是「能复制成功」，而是「能**复现失败**」。把每一次失败写成最小复现条目 `(h, 场景, 失败类, 复现脚本, 签名)`，汇成 **负证据账本 NEL**。NEL 反过来做三件事：(i) 剪掉 `G_S` 中被硬件证据否决的边；(ii) 校准 `g` 与 `α_S` 的虚假覆盖；(iii) 在 fork 传播前提前否决「历史上在同族硬件必失败」的组合。这把第 53 轮的 `Explain` 从单机解释升级为**跨硬件可复现证据**。

**灵感 5（三空间证书金字塔）**
直觉：第 53 轮是状态空间鲁棒性 `ρ`，第 54 轮是动作空间覆盖 `α`，本轮补上硬件空间有效性 `β`。三者张成 **证书三维有效性域** `𝕁 = (ρ, α, β, GC, NEL)`：状态维度不越界、动作维度被覆盖、硬件维度在可传递半径内，且接地证书 `GC` 未过期、NEL 无阻断条目，才允许部署。语义层（VLA token）则通过接地证书间接进入这张网。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（具身契约）**
具身契约 `E = (h, U, Φ_s, Φ_a, L_safe, τ_emb)`：
- `h = H(BOM ‖ RTL ‖ firmware ‖ calibration)` 为开源硬件来源哈希；
- `U` 为开链运动学与刚体动力学模型；
- `Φ_s = {(modal, rate, noise, FOV), ...}` 传感器规格；
- `Φ_a = {q_min, q_max, v_max, τ_max, backlash}` 执行器包络；
- `L_safe` 安全包络（速度/力/工作空间）；
- `τ_emb` 端到端控制延迟上界。

**定义 122（VLA 接地映射）**
接地映射 `g : T × ℰ → Δ(A)`，把动作 token 序列 `τ ∈ T` 在具身 `E` 上映射为动作空间 `A` 上的分布。支撑集 `supp(g;E) = {a | g(τ,E)(a) > 0}`。要求 `g` 在 `Φ_a` 上**投影闭合**：`proj_{Φ_a}(supp(g;E)) = supp(g;E)`，即不得产生越过执行器包络的动作。

**定义 123（接地保真证书）**
接地保真证书 `GC = (g, E, Σ, ξ, δ_g)`：
- `Σ = {(图像, 指令, token, 实测动作)}` 为标定支撑集；
- `ξ = 1 - E_{σ~Σ}[dist(g(τ,E), a_real)] / diam(A)` 为经验接地保真度；
- `δ_g` 为置信上界（Hoeffding/Bootstrap）。
有效条件：`ξ - δ_g ≥ θ_g` 且 `hash(E)=h` 且 `Σ` 的模态覆盖 `Φ_s`。若语言指令存在歧义，额外要求 `margin(a*) ≥ θ_amb`，否则拒绝。

**定义 124（硬件派生图与证书迁移算子）**
硬件派生图 `F = (ℋ, Δ)`，节点 `H_i` 带 `h_i`，边 `H_i → H_j` 标注 fork 改动 `ΔH_{ij}`。证书迁移 `Λ(J_i, ΔH_{ij}) = (J_j, verdict)`，其中：
```
J_j = J_i 若 ΔH 对 A 的扰动满足 L_Δ·||ΔH|| ≤ min(δ_a, δ_g)
verdict ∈ {inherit, re-ground, reject}
```
`re-ground` 要求在新硬件上重跑 `Σ` 的主动标定；`reject` 表示改动触及 `supp(g)` 核心或 `L_safe`。

**定义 125（硬件空间鲁棒性谱）**
沿硬件扰动维度 `β = (noise, delay, backlash, link, compute)` 定义 `ρ_h(β)`：`ρ_h(β) = P(ξ ≥ θ_g ∧ δ_a ≤ Θ_a | 硬件扰动 = β)`。证书在硬件空间的**有效域** `D_h = {β | ρ_h(β) ≥ ρ_min}`，与第 53 轮状态空间 `D_ρ`、第 54 轮动作空间 `D_a` 构成三重有效域。

**定义 126（负证据账本）**
`NEL = {e_k}`，`e_k = (h_k, ctx_k, class_k, repro_k, sig_k, t_k)`：硬件哈希、任务上下文、失败类、最小复现脚本、签名、时间戳。查询 `Q_NEL(h, S, ctx)` 返回在语义等价硬件族内可复现的失败；阻断条件：存在 `e_k` 使 `compat_h(h, h_k) ≥ θ_h` 且 `class_k` 覆盖当前风险维度。`NEL` 是**可证伪**的：任何条目必须能被第三方在 `h_k` 上复现，否则降权。

**定义 127（三空间联合证书）**
`𝕁 = (ρ, α, β, GC, NEL_ref, γ_ce, evidence)`。部署判定：
```
deploy(𝕁, T, E) = 1 ⇔ dom_ρ(T) = in ∧ cover(α, A_T) = 1
                    ∧ β ∈ D_h ∧ valid(GC, h)
                    ∧ Q_NEL(h, S, ctx) = ∅ ∧ δ_a ≤ Θ_a
```
任一维失败即返回对应反例，禁止用其余维度的「看起来很好」去补偿。

## 2. 关键算法 伪代码

### IP-121 ECR（Embodiment Contract Resolver）

```python
def resolve_contract(repo):          # 开放 BOM/RTL/firmware/urdf
    h = sha256(canonical(repo.bom) + canonical(repo.rtl)
               + canonical(repo.firmware) + canonical(repo.calib))
    E = Embodiment(h=h,
                   U=parse_urdf(repo.urdf),
                   Phi_s=parse_sensors(repo.sensor_specs),
                   Phi_a=parse_actuators(repo.actuator_specs),
                   L_safe=parse_safety(repo.safety),
                   tau_emb=measure_control_latency(repo.firmware))
    issues = check_contract_complete(E)   # 字段缺失 → 不能签发证书
    return E, issues
```

### IP-122 VGX（VLA Grounding eXchange）

```python
def calibrate_grounding(vla, E, Sigma, theta_g):
    errs = []
    for (img, instr, tau, a_real) in Sigma:
        a_g = project_envelope(g(vla.tokenize(img, instr), E), E.Phi_a)
        errs.append(dist(a_g, a_real) / diam(E.A))
    xi = 1 - mean(errs)
    delta_g = bootstrap_upper(errs, alpha=0.05)
    if xi - delta_g < theta_g:
        return ('reject', 'grounding_unfounded', xi, delta_g)
    if ambiguity_margin(vla, Sigma) < theta_amb:
        return ('reject', 'instruction_ambiguous')
    return ('ok', GroundCert(g, E, Sigma, xi, delta_g))
```

### IP-123 FCP（Fork Certificate Propagation）

```python
def propagate(J, E_src, E_dst, delta_H, budgets):
    if hash(E_dst) == E_src.h:
        return ('inherit', J)
    L_delta = hardware_lipschitz(E_src, E_dst, delta_H)
    drift = L_delta * norm(delta_H)
    if touches_core(delta_H, J.GC.Sigma) or violates(delta_H, E_dst.L_safe):
        return ('reject', 'core_or_safety')
    if drift > budgets.delta_a or drift > budgets.delta_g:
        return ('re-ground', 'budget_exceeded', drift)
    J2 = rebind(J, E_dst)
    assert J2.GC.h == E_dst.h
    return ('inherit', J2)
```

### IP-124 NEL（Negative Evidence Ledger）

```python
def nel_insert(entry, replays=2):
    ok = all(reproduce(entry.repro, entry.h) for _ in range(replays))
    signed = sign(entry if ok else entry.demote())
    return append_ledger(signed)

def nel_block(h, skill, ctx, theta_h):
    hits = [e for e in ledger.query(skill, ctx)
            if hardware_similarity(h, e.h) >= theta_h and e.reproducible]
    return hits   # 非空则阻断组合，并把根因写回 Explain
```

### IP-125 RRC（Reproducibility Robustness Certificate）

```python
def issue_rrc(J, E, F, NEL, Sigma):
    rho = state_robustness(J)                    # 第53轮
    alpha = action_profile(J, E)                 # 第54轮
    beta = hardware_spectrum(J, E, F, probes)    # 本轮
    GC = calibrate_grounding(J.vla, E, Sigma, theta_g)
    blocks = nel_block(E.h, J.skill, J.ctx, theta_h)
    if blocks or GC[0] != 'ok' or not subset(beta_domain(beta), D_h):
        return ('reject', blocks or GC)
    return ('ok', TripleCert(rho, alpha, beta, GC, blocks, F.path(E.h)))
```

### IP-126 EVR（Embodiment Validity Router）

```python
def route(skill_lib, E, task):
    feasible = []
    for S in skill_lib:
        J = S.cert.instantiate(E)
        if deploy(TripleCert.of(J), task, E):
            feasible.append((S, cost_align(S, task)))
    return min(feasible, key=lambda x: x[1]) if feasible else 'no_safe_skill'
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| ECR | O(|repo|) | O(|E|) | 哈希规范化、字段完备 |
| VGX | O(|Σ|·|T|·|A|) | O(|Σ|) | 支撑集覆盖、投影闭合 |
| FCP | O(|F|·|Σ|) | O(|F|+|J|) | Lipschitz 预算、核心不触 |
| NEL | O(|NEL|·log|NEL|) | O(|NEL|) | 可复现性 ≥ 2、签名有效 |
| RRC | O(|Σ|·|A| + |β|·|F|) | O(|A|+|β|) | 三域交集非空 |
| EVR | O(|S|·|Σ|) | O(|S|) | 保守拒绝优先 |

**正确性定理（Embodiment-Conditioned VLA Deployment Soundness）**
在 (A27)(A28) 与第 54 轮假设之上，新增 **(A29)** `h` 由开放 BOM/RTL/firmware/calibration 的规范化哈希唯一确定且不可静默篡改；**(A30)** 接地标定集 `Σ` 对 `Φ_s` 的模态覆盖 ≥ 95%；**(A31)** NEL 条目经至少 2 次独立复现且签名可验证。
则对任意 `E` 与任务 `T`：
```
P_success ≥ 1 - (1-ξ+δ_g) - Σ_d(1-ρ_min(d)) - P(β ∉ D_h)
             - P(δ_a > Θ_a) - |blocks|·P_fp(NEL)
```
关键：**语义层由 `ξ` 保真、状态层由 `ρ` 保真、硬件层由 `β` 保真**；任一层的「乐观」都不能被另一层补偿。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 硬件来源哈希可被静默 fork 改写 | 高 | 签名 BOM + 构建可复现 + 哈希锁定 |
| VLA 语义先验导致过度自信接地 | 高 | 主动标定 + token 消融 + 保守 `ξ` 下界 |
| NEL 被投毒/过时 | 高 | 多重独立复现 + 签名 + 时间衰减 + 可证伪降权 |
| 硬件空间 `β` 维度灾难 | 中 | 敏感维度筛选 + 分层采样 |
| 语言指令歧义引发危险动作 | 高 | margin 阈值 + 拒绝而非猜测 |
| fork 图传递误差累积 | 中 | 路径级预算 + 强制重标定锚点 |

## 6. 本轮最大风险

**一句话**：把 VLA 的语义 token 经接地证书 `GC` 接到动作空间、再经硬件 fork 图 `F` 与负证据账本 `NEL` 扩展到开源硬件，能首次把「语义正确、动作可行、硬件可迁移、失败可复现」缝成一张三空间证书网，但其 soundness **同时押注硬件来源哈希不可静默篡改、接地标定集对真实模态的代表性、以及负证据账本的可信复现**；一旦某块开放硬件被悄悄 fork、或 `Σ` 漏掉关键模态、或 NEL 被批量投毒，整条「可复现」链就退化为可复现的错觉，故必须以 **签名硬件哈希 + 主动模态覆盖标定 + 多源可证伪负证据** 三重护栏，在任何证据缺口处一律保守拒绝，绝不把开源带来的「可复制」误当成「可信任」。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-VLA-OSHW（ECR×VGX×FCP×NEL×RRC×EVR）

> 承接第 54 轮产物 v31。本轮把第 53 轮状态空间鲁棒性 `ρ`、第 54 轮动作空间覆盖 `α`，扩展为 **硬件空间有效性 `β`**，并以「视觉-语言-动作模型（VLA）×开源硬件（OSHW）」为主轴，新增：
> - **ECR（Embodiment Contract Resolver）**：从开放 BOM/RTL/firmware/calibration 生成带哈希的具身契约 `E`；
> - **VGX（VLA Grounding eXchange）**：VLA token → 物理动作的接地算子 `g` 与接地保真证书 `GC`；
> - **FCP（Fork Certificate Propagation）**：证书沿开源硬件派生 DAG 的传递与重标定判定；
> - **NEL（Negative Evidence Ledger）**：可复现、可签名的负证据账本，反哺组合图与接地校准；
> - **RRC（Reproducibility Robustness Certificate）**：`ρ×α×β` 三空间联合证书 `𝕁`；
> - **EVR（Embodiment Validity Router）**：按三空间有效域选择保守可部署技能。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/116/118/120 以纳入具身契约与硬件空间维度。

```python
    for (img, instr, tau, a_real) in Sigma:
        tau_hat = vla.tokenize(img, instr)
        a_g = project_envelope(g(tau_hat, E), E.Phi_a)   # 投影闭合
        errs.append(dist(a_g, a_real) / diam(E.A))
    xi = 1 - mean(errs)
    delta_g = bootstrap_upper(errs, alpha=0.05)
    if not modality_covered(Sigma, E.Phi_s):
        return ('reject', 'modality_gap', coverage(Sigma, E.Phi_s))
    if xi - delta_g < theta_g:
        return ('reject', 'grounding_unfounded', xi, delta_g)
    if ambiguity_margin(vla, Sigma) < theta_amb:
        return ('reject', 'instruction_ambiguous')
    return ('ok', GroundCert(g, E, Sigma, xi, delta_g))
```

### IP-123 FCP

```python
def propagate(J, E_src, E_dst, delta_H, budgets):
    if hash(E_dst) == E_src.h:
        return ('inherit', J)
    L_delta = hardware_lipschitz(E_src, E_dst, delta_H)
    drift = L_delta * norm(delta_H)
    if touches_core(delta_H, J.GC.Sigma) or violates(delta_H, E_dst.L_safe):
        return ('reject', 'core_or_safety')
    if drift > budgets.delta_a or drift > budgets.delta_g:
        return ('re-ground', 'budget_exceeded', drift)
    J2 = rebind(J, E_dst)              # 证书必须重绑定到新哈希
    assert J2.GC.h == E_dst.h
    return ('inherit', J2)

def propagate_path(J, path, budgets):
    for (H_a, H_b, delta_H) in path.edges:
        verdict, J = propagate(J, H_a, H_b, delta_H, budgets)
        if verdict == 'reject':
            return ('reject', H_b.h)
        if verdict == 're-ground':
            return ('re-ground', H_b.h)   # 强制在新硬件上重跑 Σ
    return ('inherit', J)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| ECR | O(|repo|) | O(|E|) | 哈希规范化唯一、字段完备 |
| VGX | O(|Σ|·|T|·|A|) | O(|Σ|+|A|) | 支撑集覆盖 ≥ 95%、投影闭合 |
| FCP | O(|F|·|Σ|) | O(|F|+|J|) | Lipschitz 预算、核心不触 |
| NEL | O(|NEL|·log|NEL|) | O(|NEL|) | ≥ 2 次独立复现、签名可验 |
| RRC | O(|Σ|·|A| + |β|·|F|) | O(|A|+|β|) | 三域交集非空、联合 sound |
| EVR | O(|S|·|Σ|) | O(|S|) | 保守拒绝优先、无降级 |

**正确性定理（Embodiment-Conditioned VLA Deployment Soundness）**
假设第 53 轮 (A22)–(A25)、第 54 轮 (A26)–(A28) 成立；新增 **(A29)** `h` 由 BOM/RTL/firmware/calibration 规范化哈希唯一确定且验签通过；**(A30)** 标定集 `Σ` 对 `Φ_s` 模态覆盖 ≥ 95%；**(A31)** NEL 条目至少 2 次独立复现且签名可验证。
则对任意 `E` 与任务 `T`：
```
P_success ≥ 1 - (1-ξ+δ_g) - Σ_d(1-ρ_min(d)) - P(β ∉ D_h)
             - P(δ_a > Θ_a) - |blocks|·P_fp(NEL)
```
关键：**语义层由 `ξ` 保真、状态层由 `ρ` 保真、硬件层由 `β` 保真**；三层证据不可互相补偿，任一层缺口即整体拒绝。

## 5. 本轮最大风险

**一句话**：把 VLA 的语义 token 经接地证书 `GC` 接到动作空间、再经硬件 fork 图 `F` 与负证据账本 `NEL` 扩展到开源硬件，能首次把「语义正确、动作可行、硬件可迁移、失败可复现」缝成一张三空间证书网，但其 soundness **同时押注硬件来源哈希不可静默篡改、接地标定集对真实模态的代表性、以及负证据账本的可信复现**；一旦某块开放硬件被悄悄 fork、或 `Σ` 漏掉关键模态、或 NEL 被批量投毒，整条「可复现」链就退化为可复现的错觉，故必须以 **签名硬件哈希 + 主动模态覆盖标定 + 多源可证伪负证据** 三重护栏，在任何证据缺口处一律保守拒绝，绝不把开源带来的「可复制」误当成「可信任」。
