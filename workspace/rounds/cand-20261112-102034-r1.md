# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；灵感循环第 1 轮；本轮灵感：「伦理审查」×「用户测试」×「合法性接地」）

> 第 59 轮把「执行层物理」完整接入了安全论证链：BUQ 把电机转矩脉动/电流采样抖动变成结构化似然，ERTC 把嵌入式 WCET/抖动/总线竞争变成硬契约，EEIS 把 δ_f 编译成带证书的阻抗参数，CLEP 让执行实测成为第 5 个模态回传对账。但它有一个从未言明的前提：**「被授权的承诺」是给定的**——谁有权下这个承诺、同意是否真的被理解、用户是否能恰当地信任、人在关键时刻是否来得及接管。**伦理审查**与**用户测试**两个灵感精准击中这个**制度与人的抽象泄漏**：伦理审查不是「把风险压到 δ 以下」，而是**程序正当性**（protocol、informed consent、independent review、continuing review、adverse event reporting、vulnerable population protection）；用户测试不是「任务成功率」，而是**人能不能懂、能不能信得对、能不能接得住**。本轮核心命题：**把「可接受的承诺」从『概率上安全』扩展为『程序上正当 ∧ 交互上可用 ∧ 信任上校准 ∧ 干预上可行』，并让技术安全与合法性之间保持不可互相补偿的硬隔离——安全只能为合法性提供必要条件，绝不能替代合法性。**

核心矛盾：
- **H32（合法性不可概率化·非补偿性）**：第 59 轮的 δ_f=10⁻⁴、共形覆盖率、七类证据门全是**可补偿的标量风险**；伦理审查的核心恰恰是**不可补偿约束**：没有知情同意时，再高的收益也不能使一个不可逆、非治疗性的接触「可接受」；不能因为成功率 99.99% 就省略对弱势群体的保护；不能因为 δ_f 极小就绕过独立审查。把伦理压成一个加权效用，等价于**把权利问题错写成优化问题**。必须形式化为**合取式可接受集** Adm_E（协议覆盖 ∧ 风险类 ≤ 声明 ∧ 可逆性 ≤ 声明 ∧ 同意满足 ∧ 弱势保护 ∧ 审查有效），任何一项失败即否决，不存在「用安全分换伦理分」。
- **H33（同意是过程不是状态·理解与自愿不可观测）**：前几轮 consent_state 是一个静态门（有/无）。伦理审查要求同意是**知情（informed）→ 自愿（voluntary）→ 具体（scoped）→ 可撤回（revocable）→ 持续（ongoing/re-consent on material change）**的过程。抽象泄漏在于：`consent=true` 掩盖了**理解失败**（用户没看懂风险）与**隐性胁迫**（拒绝代价过高、时间压力、权威压力）。更尖锐的是**同意疲劳**：频繁弹窗会让用户形成「习惯性批准」，此时形式上有同意，实质上同意已被稀释为零。必须把同意建模为状态机 + 理解测验（teach-back）+ 自愿度 + 撤回时延 + 注意力预算。
- **H34（内部校准 ≠ 用户信任校准）**：第 59 轮保证 ECE ≤ ε_meta。但用户测试反复证明**过度信任（over-trust）**：用户看到「99.99% 安全」证书后恰好在 OOD 区域放松监督；也会因**误报/解释缺失**产生**不信任与弃用（disuse）**。内部校准好，不代表外部信任校准好。必须定义**信任传递函数 T**，约束展示策略：在系统条件可靠性低的区域**绝不显示高于真实置信的置信**（no overclaim），同时避免过度告警导致弃用（no under-trust）。解释必须是**可核验的（falsifiable）**，而不是装饰性的可信度话术。
- **H35（干预可行性·人类时序不被 ERTC 覆盖）**：伦理审查要求「有意义的人类控制（meaningful human control）」。但第 59 轮的 ERTC 只保证机器 WCET 与抖动，**不保证人的检测-理解-决策-动作时序**。若 τ_available < τ_detect+τ_orient+τ_decide+τ_act，那么「人类监督」只是**责任转移的修辞**，不是真实控制。必须定义**人机干预可行性 HFA**：只有 P(W_h ≤ τ_available) ≥ 1−δ_h 且工作负荷/态势感知达标时，才允许把决策外化给人；否则系统必须自稳或放弃，不能声称「有人在环」。

## 0. 直觉与动机

**灵感 1（伦理审查 → 非补偿性可接受性 EPA）**
直觉：IRB/伦理委员会不是在做「风险-收益的加权平均」，而是在做**逐项合格性检查 + 独立裁量**：研究目的是否正当、风险是否与收益成比例、受试者是否被公平选择、弱势群体是否有额外保护、同意是否充分、隐私是否受保护、是否有持续审查与不良事件预案。关键洞见：**这些条件之间是「与」关系，不是「或/加权」关系**。因此把每个高风险/不可逆承诺编译成一份**机器可检查的伦理审查协议 EPA**，并由一个**合法性门 EUJL** 做合取判定；δ_f 只是 EPA 中「风险类」的一栏证据，不能替代其它栏。这样，「技术安全」被降格为**必要不充分条件**，恢复了伦理审查的不可补偿结构。

**灵感 2（用户测试 → 信任校准 TCUT）**
直觉：用户不会读 ECE，也不会读共形区间；用户读的是界面上的一个数字、一句解释、一次告警。用户测试的核心发现是**信任与可靠性脱钩**：系统越自信，用户越少监督；系统越保守，用户越容易忽略告警。于是把「展示的置信 c_disp」当成一个**控制器输出**：它由内部校准置信 c_true 经过一个**展示策略 D** 得到，D 必须满足两个方向的不等式——在 OOD/低可靠区 c_disp ≤ c_true（不许过度宣称），在可靠区 c_disp 不应远低于 c_true（不许制造无谓弃用）。用用户测试拟合**信任传递函数** τ_u = T(c_disp, c_true, explanation, user_model)，并在线监测**过度信任率 OTR** 与**弃用率 DTR**。

**灵感 3（伦理审查 × 用户测试 → 动态知情同意 DIC 与同意疲劳）**
直觉：用户测试里的「出声思维（think-aloud）」和「复述式理解检验（teach-back）」正是伦理审查要求的「知情」的可操作化：不测「用户点了同意」，而测「用户能否用自己的话复述风险、收益、替代方案与撤回方式」。据此定义理解分 κ_comp，并要求 κ_comp ≥ κ_min 才签发同意令牌。再把同意建为状态机：未请求→已请求→已理解→已授予→生效→（撤回/过期/实质性变更需重新同意）。同时引入**同意疲劳模型**：提示率 λ_prompt 越高，理解分按 κ(λ_prompt)=κ_0·exp(−α·λ_prompt) 衰减；用**注意力预算 B_attn** 与提示率上限 λ_fatigue 防止「形式同意、实质空白」。

**灵感 4（伦理审查 → 持续审查与不良事件 CR-AER）**
直觉：IRB 不是一次性审批，而是**持续审查（continuing review）+ 方案修订（amendment）+ 不良事件报告（adverse event reporting）+ 暂停/终止**。把它映射到运行时：伦理事件（同意越界、范围越界、过度信任事件、接管失败、弱势伤害、价值冲突）分级 S_E；轻微→记录并聚合复核；重大→暂停该动作类并触发复审；严重→全局停止并上报审查权威。方案修订（例如放宽某动作类）不能由系统自证，必须在**影子模式**下重跑用户测试与红队测试，通过后才热更新——这是第 59 轮 CEB++++ 隔离区在治理层的对应物。

**灵感 5（用户测试 → 人机干预可行性 HFA）**
直觉：用户测试表明「接管」不是瞬时事件，而是一条链：注意到异常（τ_detect）→ 理解当前模式与后果（τ_orient）→ 决策（τ_decide）→ 动作（τ_act）。若临界时间 t_critical 太短、模式太复杂、工作负荷太高，接管成功率会断崖式下降。因此定义**交接窗 W_h** 与**可行域**：只有 P(W_h ≤ τ_available) ≥ 1−δ_h ∧ workload ≤ WL_max ∧ SA ≥ SA_min 时，系统才被允许依赖人类接管；否则必须**自稳/减速/停止**，并把「人类监督」从证书里删掉——**不允许用不存在的控制来为安全背书**。

**灵感 6（合流 → 合法性接地闭环 LGL 与五预算）**
直觉：把上述五件事合成一个**包裹在 CLEP 外面的合法性闭环 LGL**：①匹配/编译 EPA；②按需执行 DIC（含理解检验与撤回通道）；③若协议要求人类监督，先验证 HFA；④调用第 59 轮 CLEP 完成技术执行；⑤按 TCUT 展示校准置信与可核验解释；⑥CR-AER 监视伦理事件；⑦签发 J_legit。资源侧新增**第五预算 B_attn（人类注意力/复核容量）**：同意请求、告警、复核都消耗注意力；注意力耗尽时系统只能降低请求频率、转自动保守或停止，绝不允许「弹窗刷屏式合规」。安全通道从三条扩为四条：**信念更准、不确定性更大、动作更保守、合法性只能被消耗或被重新授权（永不自动增加）**。

## 1. 形式化定义（增量：定义 153–160）

**定义 153（伦理审查协议 EPA）** 协议 π=(π_id, purpose, scope, 𝔄_affected, r∈{R0..R4}, ρ∈{rev, costly_rev, irrev}, consent_mode, benefit_evidence, vulnerable_flags, monitoring_plan, ae_plan, authority, approval_sig, valid_until)。其中 scope 是动作类/区域/时长的**同意作用域格**。动作 a 的**伦理可接受性**为合取判定：
```
Adm_E(a, π, ctx) = ScopeCovers(π.scope, a)
                 ∧ r(a) ≤ π.r
                 ∧ ρ(a) ⪯ π.ρ
                 ∧ (π.consent_mode = none ∨ DIC_valid(ctx.consent, a, ctx))
                 ∧ VulnerableProtected(a, π, ctx)
                 ∧ Verify(π.approval_sig, π.authority)
                 ∧ now < π.valid_until
```
**非补偿性公理（NC）**：不存在权重 w 使 Adm_E = (Σ w_i·ℓ_i ≥ θ) 等价；任一硬项 ℓ_i=0 ⇒ Adm_E=0。特别地，δ_f 只进入风险类 r 的**证据栏**，不能抵消 consent/vulnerable/authority 任一项的失败。

**定义 154（动态知情同意 DIC 与同意疲劳）** 同意令牌 τ=(scope, grantor, witness, κ_comp, w_vol, t_grant, t_expire, revoke_channel, granted_context)。理解分 κ_comp = 1 − d(复述, 标准答案)，由 teach-back 用户测试测得；自愿度 w_vol = σ(拒绝代价的反向, 时间压力, 权威梯度)。有效性：
```
DIC_valid(τ,a,ctx) = ScopeCovers(τ.scope,a) ∧ now ≤ τ.t_expire
                   ∧ κ_comp ≥ κ_min ∧ w_vol ≥ w_min
                   ∧ Δmaterial(ctx, τ.granted_context) ≤ θ_rc
                   ∧ λ_prompt ≤ λ_fatigue
                   ∧ κ_0·exp(−α·λ_prompt) ≥ κ_min
```
实质变更 Δmaterial 超过 θ_rc ⇒ 同意自动失效并要求**重新同意**；撤回通道必须满足 τ_revoke ≤ τ_revoke_max（本地 ≤2 s、远程 ≤30 s 为典型工程界）。同意疲劳作为**同意无效的独立原因**，而不是用户过错。

**定义 155（信任传递与校准 TCUT）** 设 c_true(a) 为第 59 轮校准后的真实可靠性（1−δ_f^cal）。展示策略 D: (c_true, ood_flag, explanation, user_model) → c_disp。信任传递 τ_u = T(c_disp, c_true, explanation, user_model)，依赖行为 b∈{supervise, rely, disengage}。校准约束：
```
OTR = P(b = rely | c_true < c_reliable ∧ ood_flag) ≤ δ_OT
DTR = P(b = disengage | c_true ≥ c_reliable) ≤ δ_DT
NoOverclaim: ood_flag ⇒ c_disp ≤ c_true
Checkable: explanation 的每个关键断言可被用户/第三方在 ≤T_check 内独立核验
```
D 通过一个受约束优化求得：在 OTR/DTR 上界内最大化「帮助性」（信息量 − 认知负荷）。信任 ≠ 越高越好；目标是**校准**，不是讨好。

**定义 156（人机干预可行性 HFA / 可用性安全边界 USE）** 交接窗 W_h = τ_detect + τ_orient + τ_decide + τ_act；可用时间 τ_available(a) = t_critical(a) − t_request。τ_orient 依赖态势感知 SA 与模式清晰度；τ_decide 依赖工作负荷 WL 与信任校准。可行性：
```
HFA(a,user,ctx) = P(W_h ≤ τ_available(a)) ≥ 1 − δ_h
                  ∧ WL(ctx) ≤ WL_max
                  ∧ SA(ctx) ≥ SA_min
                  ∧ ModeConfusion(ctx) ≤ θ_mc
```
若 ¬HFA 且协议要求人类监督 ⇒ **不得声称人类在环**；必须转入自稳/降速/停止，并在 J_legit 中记录 `human_control_claimed=false`。

**定义 157（伦理-可用性联合合法性 EUJL）** 合法性向量 L(a) = (ℓ_prot, ℓ_consent, ℓ_trust, ℓ_hfa, ℓ_value, ℓ_review)，各分量∈{0,1}，其中 (ℓ_prot, ℓ_consent, ℓ_review) 为硬否决项，其余为条件项。L_ok(a) = ∧_i ℓ_i。合法性**不是概率、不可加总、不可用安全分补偿**；排序是偏序（L_ok ≻ ¬L_ok，而非 0.9 与 0.8 的比较）。技术安全 P_safe 是 L_ok 的必要非充分条件：L_ok ⇒ 已满足伦理程序，但不保证物理成功；反之 P_safe 再高也不能推出 L_ok。

**定义 158（伦理红队与用户测试充分性 ERT-UT）** 测试套件 𝒰 = {(s_j, p_k, π_l)}：场景 s_j、用户画像 p_k（含弱势画像：低视力、高认知负荷、非专家、恶意/对抗操作者、旁观者）、协议上下文 π_l。覆盖矩阵 C[r, p] 记录每个「风险类×画像」单元的样本数。测试充分性：
```
Adequate(𝒰) = ∧_{(r,p)∈Critical} N(r,p) ≥ N_min
             ∧ Coverage(风险类, 画像, 上下文) ≥ γ_cov
             ∧ RedTeamAdversarialCoverage ≥ γ_adv
```
对未覆盖单元，合法性判为 **unknown**（保守：按失败处理），而不是乐观插值。用户测试指标至少含：任务成功、理解分 κ、信任量表（Jian 等）、NASA-TLX 负荷、SAGAT 态势感知、SUS 可用性、误用/弃用事件。

**定义 159（持续审查与不良事件报告 CR-AER）** 伦理事件 e=(type, severity S_E, a, ctx, t)，type∈{consent_violation, scope_violation, overtrust_event, handover_failure, vulnerable_harm, value_conflict, explanation_misleading}。处置：
```
S_E=minor    ⇒ 记录 + 聚合复核（窗口 W_review）
S_E=major    ⇒ 暂停动作类 a + 触发复审（≤T_review）
S_E=critical ⇒ 全局停止 + 上报审查权威 + 冻结相关 EPA
```
方案修订（amend）必须经影子模式重测：`shadow_test(π')` 覆盖用户测试与红队；通过才热更新，失败回滚。复审期间该动作类的合法性 = 0（默认拒绝）。

**定义 160（合法性证书 J_legit 与 JCPS+++）** J_legit = (π_id, approval_chain, consent_tokens_log, κ_comp 轨迹, w_vol 轨迹, trust_calibration_report{OTR,DTR,c_disp 轨迹}, HFA_report{P(W_h≤τ_available), WL, SA}, user_test_coverage, redteam_log, ethics_incident_log, review_state, human_control_claimed)。JCPS+++ 在第 59 轮 JCPS++ 输出上追加 J_legit 与 B_attn_snapshot。

### IP-152 EPA（伦理协议编译与匹配）

```python
@dataclass
class EthicsProtocol:
    pid: str
    purpose: str
    scope: Scope                      # 动作类/区域/时长 的格
    affected: list
    risk_class: int                   # 0..4
    reversibility: str                # rev / costly_rev / irrev
    consent_mode: str                 # none / informed / dynamic / witnessed
    vulnerable_flags: set
    monitoring_plan: str
    ae_plan: str
    authority: str
    approval_sig: str
    valid_until: float

class EthicsProtocolCompiler:
    def __init__(self, registry):
        self.registry = registry      # 已批准协议库

    def match(self, action, ctx):
        cands = [p for p in self.registry
                 if scope_covers(p.scope, action)
                 and action.risk_class <= p.risk_class
                 and rev_le(action.reversibility, p.reversibility)]
        if not cands:
            return None               # 无覆盖协议 ⇒ 默认拒绝
        return max(cands, key=lambda p: (p.risk_class, p.reversibility))

    def admissible(self, action, protocol, ctx):
        if protocol is None: return False, "no_protocol"
        checks = {
          "scope": scope_covers(protocol.scope, action),
          "risk_class": action.risk_class <= protocol.risk_class,
          "reversibility": rev_le(action.reversibility, protocol.reversibility),
          "vulnerable": vulnerable_protected(action, protocol, ctx),
          "authority": verify_sig(protocol.approval_sig, protocol.authority),
          "not_expired": now() < protocol.valid_until,
        }
        if protocol.consent_mode != "none":
            checks["consent"] = dic_valid(ctx.consent, action, ctx)
        # 非补偿：全部为真才可接受；不做加权
        ok = all(checks.values())
        return ok, ("ok" if ok else [k for k,v in checks.items() if not v])
```

### IP-153 DIC（动态知情同意 + 同意疲劳）

```python
class DynamicConsentManager:
    def __init__(self, kappa_min=0.8, w_min=0.7, alpha=0.4, lambda_fatigue=6/3600):
        self.kappa_min, self.w_min = kappa_min, w_min
        self.alpha, self.lambda_fatigue = alpha, lambda_fatigue
        self.prompt_times = deque(maxlen=1000)

    def prompt_rate(self):
        return exponential_rate(self.prompt_times)

    def request(self, scope, user, ctx):
        # 防止同意疲劳：提示率超限直接降级为"稍后/自动保守"
        if self.prompt_rate() > self.lambda_fatigue:
            return ConsentResult(False, "consent_fatigue", kappa=0.0)
        render_consent(scope, ctx, modality=user.preferred)
        teachback = admin_teachback(scope)      # 用户复述风险/收益/替代/撤回
        kappa = comprehension_score(teachback, scope.ground_truth)
        w_vol = voluntariness_score(ctx)        # 拒绝代价、时间压力、权威梯度
        if kappa < self.kappa_min or w_vol < self.w_min:
            return ConsentResult(False, "not_informed_or_coerced", kappa, w_vol)
        token = ConsentToken(scope, user.id, witness=ctx.witness,
                             kappa=kappa, w_vol=w_vol, t_grant=now(),
                             t_expire=now()+scope.duration,
                             revoke_channel=user.revoke_channel,
                             granted_context=snapshot(ctx))
        self.prompt_times.append(now())
        return ConsentResult(True, "granted", kappa, w_vol, token)

    def check(self, token, action, ctx):
        if token is None: return False, "no_consent"
        if not scope_covers(token.scope, action): return False, "scope"
        if now() > token.t_expire: return False, "expired"
        if material_change(ctx, token.granted_context) > THETA_RC:
            return False, "material_change_need_reconsent"
```

```python
        return self.dispatch(events, action)

        elif sev == "minor":
            aggregate_review(events, window=W_REVIEW)
```

```python
def legitimacy_grounded_loop(M, cp, delta_f_req, budget):
    # ① EPA：匹配并判定不可补偿可接受性
    prot = M.eth.match(cp.action, M.ctx)

    if cp.action.needs_human:

    M, fused, D_plus, EV_exec, cert = closed_loop_exec_probe(M, cp, delta_f_req, budget)
    if EV_exec is None or EV_exec.degraded_flag:

    # ⑤ TCUT：展示校准置信与可核验解释
    disp = M.trust.display(cert.reliability, ood_flag=(D_plus > theta_D_plus),
                           explanation=M.explain(cp, cert), user=M.user)

    sev = M.cr.check(cp.action, M.ctx, EV_exec, trust_event_from(disp, M.user))

    legit = build_legit_certificate(M, cp, prot, cr, rep, disp, EV_exec)

class AttentionBudget:
    """第五预算：人类注意力/复核容量。"""
    def __init__(self, capacity):
        self.capacity, self.used = capacity, 0.0
    def attn_cost(self, display, consent):
        return (DISPLAY_COST if display.shown else 0.0) + \
               (CONSENT_COST if consent.requested else 0.0) + \
               (ALARM_COST if display.alarm else 0.0)
    def attn_spend(self, display, consent):
        self.used += self.attn_cost(display, consent)
    def viable(self):
        return self.used < self.capacity and self.used / self.capacity < 0.8
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|

**正确性定理（Legitimacy-Grounded Commitment Soundness, LGCS）**
假设 A22–A55（第 53–59 轮）成立；**(A56)** EPA 编译音完备：协议 scope/风险类/可逆性覆盖实际动作，审批签名不可伪造，过期即失效。**(A57)** DIC：理解分测量诚实（teach-back 与标准答案的一致性是真实理解的校准代理）；撤回通道存活且 τ_revoke ≤ τ_revoke_max；实质变更检测漏报率 ≤δ_rc。**(A58)** TCUT：信任传递模型 T 在用户画像上的拟合误差有界；展示策略满足 NoOverclaim；OTR/DTR 的在线估计与真实值偏差 ≤δ_T。**(A59)** HFA：交接时间分布由用户测试校准，且对同画像同模式可交换；P(W_h≤τ_available) 的估计误差 ≤δ_h^est。**(A60)** ERT-UT：关键「风险类×画像」单元覆盖充分；单元内可交换 ⇒ 共形误认证率 ≤δ_test。**(A61)** CR-AER：伦理事件检测漏报率 ≤δ_E；严重事件处置时延 ≤T_stop。**(A62)** 非补偿：EUJL 使用合取式硬否决，任何安全指标不参与补偿。则：

1. **非补偿可接受性**：若 Adm_E(a)=1 则协议、风险类、可逆性、同意、弱势保护、审查效力全部成立；不存在「δ_f 更小 ⇒ 可跳过同意/审查」的路径。技术安全只影响 r(a) 的证据，不改变合取结构。
2. **同意健全性**：若 DIC_valid(τ,a,ctx)=1，则 κ_comp ≥κ_min、w_vol ≥w_min、实质变更未发生、提示率未致疲劳、撤回通道存活；形式同意但理解/自愿不足的情形被判无效。
3. **信任校准保证**：在 A58 下，OTR ≤δ_OT、DTR ≤δ_DT；且 ood_flag ⇒ c_disp ≤ c_true，故系统不能在自身不可靠区域诱导用户过度依赖。
4. **人类控制诚实性**：若 ¬HFA(a,user,ctx)，系统不得声明 `human_control_claimed=true`，不得把决策外化给人；必须自稳或停止。故「人类监督」不是免责修辞，而是可验证的时序可行性。
5. **合法性单调性**：新增技术证据最多放宽 r(a) 的证据强度，**不能**放宽 consent/vulnerable/authority/review 任一项；合法性只能被事件消耗或被独立复审重新授予，永不因「技术更安全」而自动增加。
6. **测试充分性界**：在 A60 与可交换性下，对未认证单元判为 unknown 的比例 ≤1−γ_cov；对被认证单元的「实际不合伦理却通过」的概率 ≤δ_test+δ_cov。合法性证书的统计错误率因此可被显式预算。
7. **终止性**：LGL 在「技术接触次数 + 同意交互次数 + 复审等待」的有限预算内终止于 {合法承诺(带 J_legit), 请求同意, 自稳, 绕行, 暂停复审, 停止}。五预算 B_probe/B_ft/B_ux/B_exec/B_attn 单调消耗、互不挪用。
8. **部署界**：对检查点取联合界，
```
P_safe∧legit ≥ 1 − Σ_cp (第 59 轮全部项
              + δ_rc·1[实质变更] + δ_T·1[信任估计误差] + δ_h^est·1[交接估计误差]
              + δ_test·1[未覆盖单元] + δ_E·1[事件漏检])
            − P(审查权威失效) − P(同意令牌伪造) − P(撤回通道失效 ∧ 用户撤回)
```
**关键**：合法性不是「再乘一个概率因子」，而是**另一条不可补偿的坐标轴**；把伦理审查做成加权项是比任何建模误差都更根本的错误。

### IP-153 SSM（场景语义建模）

```python
class SceneSemanticModel:
    def __init__(self, N_scenes=10):
        self.N = N_scenes
        self.scenes = ['table_smooth', 'table_rugby', 'table_wood', 
                       'stairs_up', 'stairs_down', 'floor_carpet',
                       'floor_wet', 'charging_station', 'obstacle_soft', 'unknown']
        self.scene_impedance_prior = self._init_priors()
        self.scene_state_dim = self.N
        self.scene_prior = np.ones(self.N) / self.N
        self.scene_cov = np.eye(self.N) * 0.01
        self.recent_obs = deque(maxlen=20)
        
    def update(self, force_telemetry, position_telemetry):
        features = self._extract_features(force_telemetry, position_telemetry)
        H = self._observation_matrix(features)
        z = np.array([features.get(scene, 0.0) for scene in self.scenes])
        S = H @ self.scene_cov @ H.T + 0.01 * np.eye(self.N)
        K = self.scene_cov @ H.T @ np.linalg.inv(S)
        y = z - H @ self.scene_prior
        self.scene_prior = np.clip(self.scene_prior + K @ y, 1e-3, 1.0)
        self.scene_prior /= self.scene_prior.sum()
        self.scene_cov = (np.eye(self.N) - K @ H) @ self.scene_cov
        
    def get_scene_impedance_prior(self, top_k=3):
        top_indices = np.argsort(self.scene_prior)[-top_k:]
        return [{
            'scene': self.scenes[idx],
            'confidence': self.scene_prior[idx],
            'impedance_prior': self.scene_impedance_prior[self.scenes[idx]]
        } for idx in top_indices]
```

### IP-154 CIEC（认知意图约束）

```python
class CognitiveIntentController:
    def __init__(self, ertc, response_deadline=2.0):
        self.ertc = ertc
        self.response_deadline = response_deadline
        self.active_constraints = []
        self.lock_time = None
        self.locked = False
        
    def receive_intent(self, intent):
        c_intent = self._map_intent_to_constraint(intent)
        self._apply_constraints(c_intent)
        self.active_constraints.append(c_intent)
        self.lock_time = time.time()
        self.locked = True
        return c_intent
        
    def _map_intent_to_constraint(self, intent):
        mapping = {
            'slow_down': {'v_max': 0.1, 'K_d': 2.0, 'F_max': 1.5},
            'speed_up': {'v_max': 1.5, 'K_p': 1.2},
            'light_touch': {'K_p': 0.5, 'K_d': 1.5, 'F_max': 0.8},
            'stable': {'K_p': 1.0, 'K_d': 1.0},
            'danger': {'stop': True, 'K_p': 0.1, 'F_max': 0.5}
        }
        return mapping.get(intent, {})
```

### IP-155 EPIR（执行感知隔离区）

```python
class ExecutionPerceptionIsolationRegion:
    def __init__(self, window=100):
        self.shadow = {}
        self.buffer = []
        self.last_confirmed = 0
        self.last_received = 0
        self.window = window
        
    def append(self, ev_exec):
        seq = self.last_received + 1
        msg = EVExecMessage(
            timestamp=time.time(),
            seq_id=seq,
            content=ev_exec
        )
        msg.hash = hashlib.sha256(json.dumps(ev_exec).encode()).hexdigest()[:16]
        self.shadow[seq] = msg
        self.last_received = seq
        if len(self.shadow) > self.window:
            del self.shadow[min(self.shadow.keys())]
        return msg
        
    def recover_gap(self):
        if not self.buffer: return []
        to_recover = [self.shadow[s] for s in range(self.last_confirmed+1, self.last_received+1) 
                      if s in self.shadow]
        self.buffer = [m for m in self.buffer if m.seq_id > self.last_confirmed + len(to_recover)]
        self.last_confirmed += len(to_recover)
        return to_recover
```

### IP-157 PCE++++（认知预算）

```python
class CognitiveBudget:
    def __init__(self, scene_op=100, intent_op=50, ros_retry=3, exec_budget=None):
        self.B_scene_ops = scene_op
        self.B_intent_ops = intent_op
        self.B_ros_retry = ros_retry
        self.B_exec = exec_budget or ExecBudget()
        self.ops_scene = 0
        self.ops_intent = 0
        self.ros_fail = False
        
    def is_exhausted(self):
        if self.ops_scene >= self.B_scene_ops: return 'scene_default'
        if self.ops_intent >= self.B_intent_ops: return 'intent_default'
        if self.B_ros_retry <= 0: return 'local_loop'
        return None
```
