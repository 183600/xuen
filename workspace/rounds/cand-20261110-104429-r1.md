# 第 43 轮 · 从「运动证书」到「接触与共存证书」：力矩传感作物理层见证、社会影响作人类层约束（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR）。第 42 轮自陈最大风险是「仿真偏差累积 + 检索幻觉」——证书在仿真与检索的自信中静默失效。本轮灵感词「力矩传感」「社会影响」恰好补上两条此前完全缺席的证据链：**力矩传感**把证书从「位置/速度的运动学抽象」推进到「力/力矩的物理接触层」，给出高频、直接、可独立验证的安全见证，同时用真实接触数据反向缩小 Sim-to-Real 的 W₁（接触与摩擦正是仿真最难建模、也最容易造成迁移偏差的部分）；**社会影响**把「安全」从单一的物理不伤害，扩展为「在人类社会中可被接受地共存」——个人空间、接触舒适度、可预测性/可读性、跨人群公平性与可问责性。二者合成 **社会-物理联合证书（SPC）**，让飞轮第一次同时优化「不伤害身体」与「不伤害信任」。

## 0. 直觉与动机

**灵感 1（力矩传感 → 证书的「触觉神经末梢」与「偏差探针」）**：第 42 轮所有 margin 都是从运动学与模型间接推出来的：几何残差证书假设了动力学、CBF 假设了摩擦与接触、L0 查表也建立在离线模型之上。一旦真实接触（推门、递物、人机擦碰）发生，模型误差最大的地方恰恰是证书最该可信的地方。力矩传感（关节力矩传感器、SEA 弹性体形变、电机电流+动量观测器）的直觉是：它直接测量**广义外力矩 τ_ext**，因而是「物理层的真值见证」。它有三重作用：**(a) 更紧的证书**——用实测 τ_ext 替代模型保守界，直接放松 margin，缓解第 41/42 轮反复出现的「可用性崩塌」；**(b) 独立监控**——力矩残差 r_τ = τ_ext − τ̂_ext(model) 是模型误差的实时探针，可在不信任模型的前提下触发降级；**(c) 仿真校准**——接触/摩擦/惯量的真实力矩响应回灌 Isaac Sim，做接触域系统辨识，直接压低第 42 轮最致命的 W₁ 低估。

**灵感 2（社会影响 → 安全不再是单目标，而是「谁、在什么情境、被怎样影响」）**：第 42 轮的证书只回答「机器人自己会不会越界」，不回答「它如何影响人」。社会影响的直觉是：把**人**显式放进证书状态里。具体四类约束：**个人空间/近体学（proxemics）**——不同关系与场景有不同的可接受距离与接近速度；**接触舒适（comfort force/torque）**——按身体部位、年龄、辅助器具给出力矩/压强上限（而非笼统的「不碰撞」）；**可读性/可预测性（legibility）**——人的意图预测误差越小，惊扰与不信任越少；**公平性（equity）**——证书必须在儿童、老人、残障用户等子群上 worst-case 成立，而不是只在「平均成年人」上成立。再加一层**可问责性**：每张证书附带人类可读的「社会影响声明」（影响谁、牺牲什么、置信多少、如何申诉），使安全从技术指标变成可审计的社会契约。

**灵感 3（耦合：力矩是社会约束的物理载体）**：社会约束并非纯软性——「递物时不能捏痛老人」「拥挤处不能突然加速逼近」最终都落成**力矩/力/速度的物理界**。力矩传感因此是「社会影响」进入物理控制器的天然接口：把舒适力矩上限 τ_comfort(body_region, user_group) 直接写进 CBF 与守卫；把接触事件力矩波形作为社会舒适度的客观代理，替代昂贵且稀疏的主观问卷。反过来，社会情境（是否有人、距离多近、是否在注视）调节力矩证书的保守度：无人时可放松、有人时收紧，实现「情境感知的安全预算」。

**耦合升级（v8 一句话）**：运动证书 = 不越界；力矩证书 = 不施暴；社会证书 = 不惊扰、不歧视、可问责。三者取 min 得 SPC，飞轮目标从 (COT, 违例率, Nominal) 扩展为 (COT, 物理违例, 社会违例, 最差群体裕度, 信任)。

## 1. 形式化定义（增量：定义 38–45）

**定义 38（广义外力矩与力矩残差）**：对 n 自由度机械臂，τ_ext = τ_m − M(q)q̈ − C(q,q̇)q̇ − g(q) − τ_f，其中 τ_f 为摩擦。用动量观测器 r = K_o( p − ∫(τ_m − Cᵀq̇ − g + r)dt )，无外力时 r→0，有外力时 r→τ_ext（带一阶低通滞后 1/K_o）。**力矩残差探针** r_τ = τ_ext^meas − τ̂_ext^model；其幅值是可观测的模型失配度量。

**定义 39（力矩证书 T-Cert）**：T-Cert = (τ_lim(x, region), m_τ, k_contact, ρ_stab)，其中 m_τ = τ_lim − ‖W τ_ext‖_∞（W 为按关节重要性/人体易伤度加权的对角阵），k_contact 为接触模式（free / soft / hard / constrained），ρ_stab 为接触稳定性裕度（抓取矩阵最小奇异值 / 摩擦锥余量）。有效域 C_τ = {x : m_τ(x) ≥ θ_τ ∧ ρ_stab ≥ ρ_min}。

**定义 40（社会影响证书 SI-Cert）**：给定人类状态 h（位置、朝向、注视、年龄段/辅助器具分群 g、活动上下文 c），社会裕度
s(x,h) = min{ g_prox(x,h;c), g_comf(x,h;g), g_leg(x;h), g_eq(x;g) }，
其中 g_prox 为近体学距离/接近速度的归一化余量，g_comf 为接触力矩/压强相对 τ_comfort(body_region,g) 的余量，g_leg 为人类意图预测器对机器人下一段轨迹的负对数似然（越小越可读），g_eq 为相对「最差子群」的公平性余量。有效域 C_s = {(x,h) : s(x,h) ≥ θ_s}。

**定义 41（社会-物理联合证书 SPC）**：C_sp = C_motion ∩ C_τ ∩ C_s，联合裕度 m_sp = min(m_motion, m_τ, m_s)。**命题**：若三者在同一状态上均 ≥ 各自阈值，则同时满足运动安全、接触安全与社会可接受性；反之任一不足即触发**对应层**降级而非整体 SafeStop（分级失效，避免第 42 轮的可用性崩塌）。

**定义 42（人群分布鲁棒与公平约束）**：D_human = Σ_g π_g D_g 覆盖子群；**公平证书**要求 ∀g : P_{h∼D_g}(s < θ_s) ≤ ε_g，且 max_g ε_g ≤ ε_eq（worst-group 约束）。这把第 42 轮的域随机化从「环境参数」扩展到「人类参数」，并与 W₁ 迁移界同构。

**定义 43（社会影响向量与声明）**：I = (I_safety, I_comfort, I_trust, I_equity, I_privacy, I_autonomy) ∈ R⁶，每张证书附带 impact statement：影响对象、约束来源（法规/共同设计/伦理评审）、权衡点、不确定区间、申诉与回滚路径。I 与证书版本、评审记录一起进入 CKB 的不可篡改审计链。

**定义 44（情境安全预算）**：λ(x,h,c) ∈ [0,1] 为情境权重，θ_τ(x,h) = θ_τ⁰ · (1 + κ(1−λ))，θ_s 同理；λ=1（无人、空旷）放松，λ=0（近距离、易伤人群）收紧。λ 由社会情境估计器给出，且其估计不确定性必须计入 θ 的保守化。

**定义 45（力矩-社会飞轮）**：实机力矩残差序列与接触波形 + 人类反馈（距离、回避、问卷/生理代理）→ 更新 SCV 的接触模型参数与 W₁ 估计 → 更新 CKB 的「力矩指纹/社会指纹」→ 重算 T-Cert/SI-Cert → 热更新 ECR。新增收敛判据：连续 K 轮力矩残差 p99 与社会违例率同时下降才算飞轮有效。

## 2. 产出设计（新增 IP-57/58/59，升级 IP-49/50/51/52/53/54/55/56/47）

### 2.1 IP-57 TORQUE-CERT-MONITOR（TCM，力矩证书监控）
1. **多源力矩感知**：关节力矩传感器（首选）、SEA 形变、电机电流+动量观测器（虚拟冗余）；三取二表决，**传感器故障本身必须被证书覆盖**。
2. **力矩证书运行时**：m_τ 高频（≥1kHz）计算，接触模式自动机切换 k_contact；接触模式转移作为 CAR 的新转移边纳入守卫。
3. **残差探针与在线辨识**：r_τ 的 EWMA 与 p99 触发「模型失配」事件，回灌 SCV（接触摩擦、惯量、延迟）。
4. **安全力矩投影**：当 m_τ → 0 时，用阻抗/导纳控制把 τ_ext 钳制到 τ_lim 内（软约束优先于急停，急停本身降低可读性、引发惊扰）。

### 2.2 IP-58 SOCIO-CERT-ENGINE（SCE，社会证书引擎）
1. **人类状态与子群估计**：位置/朝向/注视/步态/辅助器具/年龄段的保守分群（不确定时归入更易伤子群）。
2. **社会裕度计算**：近体学场、舒适力矩表（身体部位×子群，参考但不限于 ISO/TS 15066）、可读性评分、worst-group 公平余量。
3. **社会 CBF**：g_prox、g_comf 作为额外控制障碍函数与力矩 CBF 联合求解；不可行时按「先减速—再远离—最后停」的社会化降级序列，而非突兀急停。
4. **影响声明生成与审计**：自动生成 impact statement，多人评审签署后写入 CKB 审计链；支持申诉与回滚。

### 2.3 IP-59 CONTACT-SOCIAL-CURRICULUM（CSC，接触-社会课程与共同设计）
1. **课程新增「接触相位」**：自由空间→近体接近→软接触→约束接触→人群共存，逐级提升；每级用 SPC 三项裕度做决策等价判据。
2. **社会场景域随机化**：人群密度、文化近体学参数、子群构成、突发行为（横穿、伸手、注视）作为 D_human 的随机化维度。
3. **参与式规格**：与目标用户/照护者/伦理委员会共同定义 θ_s、τ_comfort 与降级策略，记录「谁定义了安全」。
4. **反事实社会影响估计**：对同一任务比较「有/无社会约束」的行为差异，量化约束的可用性代价与社会收益。

```
L1: TRI-FUSE(INT8/定点) + IP-49 LIO → C_ms + B_t + L_m(经验/力矩校准)
```

回退：E87 力矩传感器不可靠 → 退回电流+观测器虚拟力矩并收紧阈值；E88 无可用性收益 → 仅保留力矩残差监控；E90 社会指标不可测 → 缩小到近体学+舒适力矩两个可操作项；E91 公平性不可达 → 限制部署人群并在 impact statement 显式声明；E92 辨识失效 → 回退 v19 的 W₁ 估计。

## 5. 本轮最大风险

**一句话**：力矩传感把「安全」的证据从模型移到传感器，但传感器本身可能漂移、失效甚至被物理攻击，而社会影响一旦被压缩成几个可优化指标就极易被 Goodhart 化——系统可能在「力矩残差很小、社会评分很高」的同时，因力矩感知盲区或对社会价值的粗暴简化而制造更隐蔽的伤害；因此必须把「力矩传感器自身的证书」与「社会指标的参与式定义 + 最差群体审计」作为红线，任何一项不可独立验证即不得宣称社会安全。

## 2. 关键算法（伪代码）

### IP-57 TCM：力矩证书监控
```
def momentum_observer(q, qd, tau_m, dt, Ko, M, C, g):
    p = M(q) @ qd
    # beta_int 状态量：d(beta_int)/dt = tau_m - C(q,qd).T @ qd - g(q) + r
    r = Ko * (p - beta_int)
    tau_ext_hat = r          # 一阶低通，带宽 ~ Ko
    return tau_ext_hat, update_beta(beta_int, tau_m, q, qd)

def torque_cert_monitor(q, qd, tau_ext, region, v19_cert):
    # 关节重要度/易伤度加权，取无穷范数
    m_tau = tau_lim[region] - max(abs(W[region] * tau_ext))
    k_contact = infer_contact_mode(tau_ext, qd, v19_cert)   # free/soft/hard/constrained
    rho = contact_stability_margin(k_contact)               # 抓取矩阵 σ_min / 摩擦锥余量
    return TCert(m_tau, k_contact, rho)

def residual_probe(tau_ext_meas, tau_ext_model, ewma, p99):
    r = tau_ext_meas - tau_ext_model
    ewma = alpha * r + (1 - alpha) * ewma
    if abs(ewma) > k_e * sigma_r or p99(r) > k_p * sigma_r:
        emit_model_mismatch(r)      # 回灌 IP-54 接触域辨识
    return ewma

def torque_safe_project(tau_ext, tau_lim, K_imp, J, u_nom):
    if max(abs(W * tau_ext)) <= tau_lim:
        return u_nom
    # 导纳/阻抗投影：先顺从回退，再钳制；避免不可读的硬急停
    return impedance_retreat(tau_ext, tau_lim, K_imp, J)
```

### IP-58 SCE：社会证书引擎
```
def social_margin(x, h, g, c, tau_hist, cert):
    g_prox = proxemic_margin(dist(x, h), closing_speed(x, h), c)
    g_comf = comfort_margin(tau_hist, body_region(x, h), g)   # 按部位×子群查 τ_comfort
    g_leg  = legibility_margin(predict_traj(x), human_intent_model(h))
    g_eq   = min_over_subgroups(threshold_margin(g))          # worst-group
    return min(g_prox, g_comf, g_leg, g_eq)

def social_cbf_qp(x, h, c, u_nom, cert):
    # 联合 QP：运动 CBF ∧ 力矩 CBF ∧ 近体学 CBF ∧ 舒适力矩 CBF
    return solve_qp(minimize=||u - u_nom||^2,
                    s.t.=[cbf_motion(x, u, cert),
                          cbf_torque(x, u, cert),
                          cbf_prox(x, h, u, c),
                          cbf_comfort(x, h, u, g)])

def graded_degrade(current_mode, failed_layer):
    # 分级失效：先柔性、再远离、最后停；而非一律 SafeStop
    return {'motion':  'SlowDown',
            'torque':  'CompliantStop',   # 阻抗钳制先于硬停
            'social':  'RetreatAndWait'}[failed_layer]

def impact_statement(cert, stakeholders):
    return {
        'affected':    stakeholders,           # 谁被影响
        'sources':     cert.constraint_sources, # 法规/共同设计/伦理评审
        'tradeoffs':   pareto_summary(cert),    # 牺牲了什么
        'uncertainty': cert.confidence,         # 置信与盲区
        'appeal':      cert.rollback_path,       # 申诉与回滚
    }
```

### IP-54 升级：接触域系统辨识（直接压低 W₁）
```
def identify_contact_model(tau_ext_log, q_traj, dt):
    # 回归：黏滞+库仑摩擦、惯量缩放、通信/执行延迟
    def residual(theta, i):
        tau_pred = friction_model(q_traj[i], theta) + inertia_scale(theta) * qdd(i)
        return tau_ext_log[i] - tau_pred
    theta_hat = least_squares(residual, x0=theta0)
    explained = explained_variance(residual(theta0), residual(theta_hat))
    W1_new = W1_before * max(0.0, 1.0 - explained)
    return theta_hat, W1_new
```

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 力矩传感器漂移/失效导致「虚假安全」 | 高 | 力矩传感器/SEA/电流观测器三取二；传感器自身故障检测纳入证书；失效回退虚拟力矩并收紧 τ_lim |
| 力矩带宽不足/混叠漏检快速碰撞 | 高 | ≥1kHz 采样 + SEA 高带宽通道；残差 p99 与冲击能量双判据；必要时硬件急停兜底 |

## 6. 本轮最大风险

**一句话**：力矩传感把「安全」的证据从模型移到传感器，但传感器本身可能漂移、失效甚至被物理攻击，而社会影响一旦被压缩成几个可优化指标就极易被 Goodhart 化——系统可能在「力矩残差很小、社会评分很高」的同时，因力矩感知盲区或对社会价值的粗暴简化而制造更隐蔽的伤害；因此必须把「力矩传感器自身的证书」与「社会指标的参与式定义 + 最差群体审计」作为红线，任何一项不可独立验证即不得宣称社会安全。
