# 第 10 轮（新灵感循环第 1 轮；本轮灵感：「检索增强生成」×「场景驱动创新」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**检索先证后行 + 场景精化单调 + 覆盖可审计**。v9 已把安全论证局部化到块证书，但每个新场景仍从零重算、旧经验无法复用；同时 v9 的 DA-ML 只把"陌生"压成一个标量风险，无法回答"缺的是哪一类场景"。RAG 提供跨场景复用能力，场景驱动创新提供缺失场景的生长机制。关键纪律：检索只提议**可迁移的证书**而非直接放行动作，任何检索失败注入空集中立元 ∅，严格等价退回 v9（引理 88/92）；场景只允许**精化**，创新只能增加覆盖、不能放宽约束（引理 89/91）。

## 0. 直觉与动机

**灵感 1（检索增强生成 → 认证先例检索）**
直觉：RAG 的通常形态是"检索文本→条件生成"，但控制系统不能信任"生成得像"。我们把检索对象换成**已经通过 v9 证书的认证先例** π=(x_π, ζ_π, Ĉ_π, V_π, L_π, h_π)，检索键是场景描述子 σ_t。检索不是把旧动作原样回放（那会"借来旧世界的安全"），而是提出一张**鲁棒迁移证书**：用局部 Lipschitz 界把先例证书按"状态距离 + 场景距离 + 先例年龄"折价，折价后仍满足当前阈值才允许执行。一句话：**复用旧证明，但必须为移动的距离付保证金**。付不起（界不成立/超时/版本漂移/撤销）就返回 ∅，等价 v9 在线重算。

**灵感 2（场景驱动创新 → 场景格与残差挖掘）**
直觉：场景驱动创新不是"给已知场景调参"，而是承认**场景本身是知识单元**：它同时定义检索键、证书有效域、阈值表和局部误差界。v9 把陌生度压成一个标量 Δ_dom，丢失了"缺哪类场景"的结构。我们建立版本化**场景格** L：每个节点是一个精化约束（域更小、阈值更严、β 更大）；当检索在该节点持续失败、且预测/守卫残差在节点外成簇时，触发**场景挖掘提议**：用残差簇提出一个子场景，经离线准入审查（覆盖不降、安全不回归、provenance 完整）后才进入在线格。创新只做覆盖的加法，不做约束的减法。

**综合（两灵感的交点：记忆–覆盖闭环）**
直觉：检索失败率是"覆盖缺口"的在线测量，场景挖掘把缺口变成新场景节点，覆盖台账再把新节点纳入可审计的性能声明。于是 RAG 不再是一次性外挂，而是一个**可证伪的记忆闭环**：它必须用"哪些场景检索不到 / 迁移证书不成立"来证明自己还缺什么，而不是用平均成功率掩盖长尾。场景是索引、是证书作用域、也是创新的计量单位。

## 1. 研究问题（轮次升级版）

- **Q1（检索的安全中性）**：在什么 Lipschitz / 新鲜度 / provenance 条件下，认证先例的迁移证书对真实指标仍是保守下界？当指标在接触、形变、打滑处不可微或导数爆炸时，如何在线检测并拒绝迁移？
- **Q2（场景创新的单调性）**：如何把"从残差中生长新场景"约束成格上的**精化**，使准入谓词同时保证覆盖非降、安全零回归，且不产生碎片化与别名重叠？
- **Q3（检索的实时性与可撤销性）**：如何把检索放进 20ms/50Hz 契约（超时→∅），并在记忆投毒、模型版本漂移、先例撤销时保证在线系统不信任任何过期或被污染的先例？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 检索先证后行律（Certificate-before-Action, CRM）**
检索结果不直接授权执行。先例 π 仅当鲁棒迁移证书 RTC_π(x_t,σ_t) 成立（折价后间隙下界 ≥ d_safe^s、力上界 ≤ τ_eff^s、中止点集迁移有效、provenance 与新鲜度匹配）才可替代在线生成；否则注入 v_R^⊥=∅，等价 v9 的 generate_chunk。检索只能**提议**证书，不能**替代**证书。

**P14 场景精化单调律（Refinement-Only Scene Evolution, SLI）**
场景格上的创新只允许 s_new ⪯ s_parent（域子集、阈值不更松、β 覆盖更严）。新场景只能把状态空间切得更细、把证书管得更紧；任何"放宽约束以提升覆盖率"的提议在准入谓词处直接拒绝。由此任意时刻的在线行为都被根场景 s_0（=v9 阈值）安全支配（引理 89）。

**P15 覆盖可审计律（Coverage-Conditioned Accountability, CGL）**
性能声明必须条件于覆盖率：系统同时报告 Cov(L,D) 与 P(θ|Cov)，未覆盖质量单列，禁止只用平均值。每个先例/场景携带可验证 provenance 哈希与版本；撤销沿依赖图传播并降级到父场景（更保守），而非静默删除。

## 3. 与基线的接口（如何退化）

- CRM 空记忆 / 检索超时 / 无有效 RTC / provenance 不匹配 / 先例过期 ⇒ v_R^⊥=∅，逐位等价 v9 在线生成（引理 88）；
- SLI 关闭 / 格不一致 / 提议未准入 ⇒ 冻结在根场景 s_0，所有阈值 = v9，不产生新节点（引理 89/91）；
- CGL 失效 ⇒ 退化为 v9 的平均指标日志（只影响可审计性，不影响控制）；
- RCR 失效 ⇒ 切回 v9 ContractMiddleware 的手写端口，无检索调用；
- v9 的 AC 失效 ⇒ K_eff←1，逐步执行；MW 失效 ⇒ v8 手写网关；ID 失效 ⇒ 全模块 active；
- v8 的 DA/SPR/Cal 失效 ⇒ 中立元注入（Δ_dom≡0 / risk_SLAM≡0 / weight≡1），等价 v7；全失效 ⇒ v7→v6。

## 4. 预期贡献

1. **认证先例检索**：把 RAG 从"检索文本条件生成"改造为"检索证明并折价迁移"，给出鲁棒迁移证书的保守性条件与严格退化路径；
2. **场景格创新闭环**：版本化、精化单调、准入审查的场景生长机制，把长尾残差沉淀为可复用节点，并给出覆盖非降 / 安全零回归的准入门槛；
3. **覆盖条件化评估**：用覆盖–性能 Pareto 取代平均成功率，令"没覆盖到的场景"成为显式、可审计的一等结论；
4. **记忆治理**：provenance 哈希、版本漂移、撤销级联、投毒检测，让检索层可被攻击也可被审计；E571–E590 覆盖迁移保守性、覆盖增长、碎片化、投毒与端到端。

## 5. 本轮最大风险

**一句话**：鲁棒迁移证书的可靠性完全依赖 Lipschitz 上界 L_g 的正确性，而 L_g 只能在平滑数据上标定；在抓取接触、形变、打滑等指标函数不可微、导数爆炸的时刻，真实 L_g 可能远超标定值，检索会以"已认证"的姿态在最熟悉的场景里借来一个不成立的安全证明。

**新增定义 540（场景描述子与场景节点 SceneDescriptor & SceneNode）** 在线从 v8/v9 已有观测量构造 σ_t=(φ_t,o_t,g_t,θ_t,ρ_t)，不引入新的高成本感知。场景节点 s=(Σ_s,T_s,β_s,M_s,v_s)：Σ_s⊆Σ 为描述子有效域；T_s=(d_safe^s,τ_eff^s,τ_grasp^s) 为节点阈值表；β_s 为节点前向模型误差余量；M_s 为已认证先例集合；v_s=(model_version, code_hash, lattice_version)。根场景 s_0 满足 Σ_{s_0}=Σ、T_{s_0}=v9 阈值、β_{s_0}=v9 β、M_{s_0}=全部先例。

**新增定义 541（场景格与精化序 SceneLattice & Refinement Order）** 场景格 L 上的偏序：s' ⪯ s 当且仅当
```
Σ_{s'} ⊆ Σ_s ∧ d_safe^{s'} ≥ d_safe^{s} ∧ τ_eff^{s'} ≤ τ_eff^{s} ∧ β_{s'} ≥ β_s
```
即子场景域更小、间隙要求更严、力上限更低、误差余量更大。在线查询用**最具体覆盖节点** ρ(σ)=argmax_{s: σ∈Σ_s} depth(s)（格一致性保证唯一）；节点间不得有未解决的别名重叠，重叠必须显式精化为更细节点。

**新增定义 542（认证先例 Certified Precedent）** π 的证书 Ĉ_π=(ĝ_min^π,ê_max^π,γ̂_grasp) 由 v9 定义 533 在认证时给出；V_π 是认证时通过滚动复核的状态管；L_π=(L_g^π,L_e^π,L_σ^π) 是在 V_π 邻域上标定的局部 Lipschitz 上界（含安全系数）；h_π=H(model_version, code_hash, cert_hash, data_digest) 为可验证 provenance；t_π 为认证时间。先例只有在通过准入审查并写入 M_s 后才可被检索。

**新增定义 543（鲁棒迁移证书 Robust Transfer Certificate, RTC）** 对当前 (x_t,σ_t) 与先例 π，令 d_x=‖x_t−x_π‖_W（按指标敏感度加权）、d_σ=‖σ_t−σ_π‖_Σ、age=t−t_π、β_s(age)=β_{s,0}+κ·age/T_fresh：
```
g^tr = ĝ_min^π − L_g^π·d_x − L_σ^π·d_σ − β_s(age)
e^tr = ê_max^π + L_e^π·d_x + L_σ^π·d_σ + β_s(age)
P^tr = { p ∈ P_π : ĉ_p^π − L_g^π·d_x − L_σ^π·d_σ ≥ d_brake(v_p) + d_safe^s }
```
RTC 有效 ⇔ d_x≤ρ_x ∧ d_σ≤ρ_σ ∧ age≤T_fresh ∧ h_π=H(current) ∧ g^tr≥d_safe^s ∧ e^tr≤τ_eff^s ∧ γ̂_grasp valid ∧ P^tr≠∅ ∧ K_eff≤|P^tr| 的前缀证书仍有效。任一不成立 ⇒ 该先例不可用（不是放宽，而是拒绝）。

**新增定义 544（检索安全序与可采纳集 Retrieval Safety Order）** 对节点 s，块 y 是 **s-可采纳**的当且仅当其证书满足 v9 定义 533（间隙/力/抓取）且其迁移中止点满足定义 534（停车不变式）。定义序 y ⪯_safe y' 当且仅当 margin_g(y)≤margin_g(y')、margin_e(y)≥margin_e(y')、P(y)⊇P(y')。检索只返回 s-可采纳的 y^ret；v9 生成器按构造返回 s-可采纳的 y^on。两者同属 A(s)，故检索路径不扩大可采纳集（引理 87/89）。

**新增定义 545（场景残差与新颖度 SceneResidual & Novelty）** r_t=(r_pred,r_guard,q_ret)：r_pred=‖F̂(x_t,a_t)−x_{t+1}‖（前向一致误差）、r_guard=(d_safe^s−clearance_t)/d_safe^s（守卫裕度归一化残差）、q_ret=1[RTC 无效]。节点 s 的窗口新颖度
```
ν_W(s) = mean_{i∈W} q_ret,i + λ·max(0, KS(r_pred|[W], calib_s) − α_KS)
```
其中 KS 为双样本统计量。触发挖掘 ⇔ ν_W(s)≥τ_nov 连续 H_nov 个窗口，或出现落在所有节点标定支撑之外的安全相关残差离群点。

**新增定义 546（场景挖掘提议 Scene Mining Proposal）** 对父节点 s_p 的未覆盖残差簇 D={(x_i,σ_i,y_i)}，提议子节点 s_new：Σ_new = D 在 σ 空间上的 (1−α) 保形包络（保守矩形/椭球）；T_new ⊒ T_{s_p}（**只可更严**）；β_new 取 D_val 上前向残差的上分位并加安全系数；M_new 由对 D 中状态重新执行 v9 证书器得到的可采纳块组成；h_new=H(h_parent, D_digest, model_version, reviewer_signature)。提议在准入前**完全惰性**，不参与在线检索。

**新增定义 547（场景准入谓词 Scenario Admission Predicate）** Adm(s_new; s_p, D_val, D_safe) 当且仅当：
```
(a) 精化：s_new ⪯ s_p（定义 541）
(b) 校准：D_val 上 RTC 有效率的 Clopper–Pearson 下界 ≥ 1−α（置信 1−δ）
(c) 安全：D_safe 上 s_new 阈值下安全违背数 = 0（或 ≤ 预注册 ε 且统计不显著更差）
(d) provenance：h_new 哈希链完整、model_version 匹配、reviewer 签名有效
(e) 格一致：Σ_new 与兄弟节点无未解决重叠；若重叠，必须进一步精化
```
任一失败 ⇒ 提议进入隔离区 Q，永不被在线查询；只有 (a)–(e) 全过才写入 L。

**新增定义 548（检索中立元与撤销级联 Retrieval Neutral Element & Revocation）** v_R^⊥=∅：空记忆、检索超时（D_R 越界）、无有效 RTC、age>T_fresh、h_π 不匹配、先例被撤销、格版本不一致，任一情形都返回 ∅。撤销沿 provenance 依赖图传播：revoke(π) 使 π 失效，并使所有 β 标定或证书复核曾使用 π 数据的场景节点失去法定人数（quorum）时**降级到父节点**（更保守），而非删除节点或保留其阈值。降级顺序 s→parent(s)→…→s_0，最终等价 v9。

**新增定义 549（覆盖函数与覆盖条件性能 Coverage & Coverage-Conditioned Performance）**
```
Cov(L,D) = (1/|D|)·Σ_{x∈D} 1[ Retrieve(x) ≠ ∅ ]
```
性能不报告单一均值，而报告曲线 { (c, P(θ | Cov≥c)) } 及未覆盖质量 U(L,D)={x: Retrieve(x)=∅} 的场景构成。预注册要求同时给出覆盖率下界与未覆盖长尾清单；任何"平均提升"若以覆盖塌缩为代价即判为不合格。

**新增定义 550（检索预算与新鲜度 Retrieval Budget & Freshness）** 检索端口契约：D_R≤0.5ms/周期、返回 k≤8 个候选、索引查询 O(log N)。先例年龄通过 β_s(age) 折价，age 越界直接失效；模型/代码版本漂移 Δ_F>ε_F 触发全库 revalidate（后台），在线期间只使用已 revalidate 的先例，否则 ∅。检索预算与 v9 契约共同满足 Σ_m Ŵ_m ≤ B_dec，50Hz 守恒不变。

# IP-357 CertifiedRetrievalMemory：场景索引的认证先例库 + 鲁棒迁移证书
@dataclass
class Precedent:
    x: np.ndarray; sigma: np.ndarray; chunk: "Chunk"
    g_min: float; e_max: float; abort: list
    L: tuple            # (L_g, L_e, L_sigma) 局部 Lipschitz 上界
    provenance: str; t: float

class CertifiedRetrievalMemory:
    def __init__(self, index, lattice, rho_x=0.25, rho_sigma=0.30,
                 T_fresh=1800.0, kappa=0.05, k=8):
        self.index, self.lattice = index, lattice
        self.rho_x, self.rho_sigma, self.T_fresh = rho_x, rho_sigma, T_fresh
        self.kappa, self.k = kappa, k

    def add(self, pi):
        s = self.lattice.most_specific(pi.sigma)
        if s is None or not provenance_ok(pi) or not s.contains(pi.sigma):
            return False
        self.index.insert(pi); s.M.add(pi.id); return True

    def rtc(self, pi, x, sigma):
        s = self.lattice.most_specific(sigma)
        d_x = weighted_dist(x, pi.x, W_METRIC)
        d_s = desc_dist(sigma, pi.sigma)
        age = now() - pi.t
        if s is None or d_x > self.rho_x or d_s > self.rho_sigma:
            return None                                  # 超出迁移半径
        if age > self.T_fresh or pi.provenance != current_provenance():
            return None                                  # 过期 / 版本漂移
        Lg, Le, Ls = pi.L
        beta = s.beta + self.kappa * age / self.T_fresh  # 定义 543 年龄折价
        g_tr = pi.g_min - Lg * d_x - Ls * d_s - beta
        e_tr = pi.e_max + Le * d_x + Ls * d_s + beta
        if g_tr < s.d_safe or e_tr > s.tau_eff:
            return None
        pts = [p for p in pi.abort
               if pi.clearance[p] - Lg * d_x - Ls * d_s
                  >= brake(pi.speed[p]) + s.d_safe]
        if not pts or not pi.grasp_valid:
            return None
        return RTC(g_tr, e_tr, pts, pi.provenance, age)

    def retrieve(self, x, sigma):
        try:
            with deadline_guard(0.5):                     # 定义 550
                s = self.lattice.most_specific(sigma)
                for pi in self.index.query(sigma, k=self.k):
                    if self.revoked(pi.id):
                        continue
                    r = self.rtc(pi, x, sigma)
                    if r is not None:
                        return r
        except DeadlineOverrun:
            pass
        return EMPTY                                      # v_R^⊥


# IP-358 SceneLatticeInnovator：残差驱动、精化-only 的场景生长
class SceneLatticeInnovator:
    def __init__(self, lattice, tau_nov=0.20, H_nov=3,
                 alpha=0.05, delta=0.05, n_min=30):
        self.lattice = lattice
        self.tau_nov, self.H_nov = tau_nov, H_nov
        self.alpha, self.delta, self.n_min = alpha, delta, n_min
        self.buf, self.miss = defaultdict(deque), Counter()
        self.quarantine = []

    def observe(self, sigma, rtc_ok, r_pred, r_guard):
        s = self.lattice.most_specific(sigma)
        self.buf[s.id].append((sigma, r_pred, r_guard, rtc_ok))

    def novelty(self, s):
        w = self.buf[s.id]
        if len(w) < self.n_min:
            return 0.0
        miss = 1.0 - mean(q[3] for q in w)                # 定义 545
        ks = ks_stat([q[1] for q in w], s.r_pred_calib)
        return miss + LAMBDA_KS * max(0.0, ks - self.alpha)

    def maybe_mine(self, sigma):
        s = self.lattice.most_specific(sigma)
        self.miss[s.id] = self.miss[s.id] + 1 if self.novelty(s) >= self.tau_nov else 0
        if self.miss[s.id] < self.H_nov:
            return None
        D = cluster_uncovered([q for q in self.buf[s.id] if not q[3]])
        if len(D) < self.n_min:
            return None
        return propose_child(s, D, self.alpha)            # 惰性提议，定义 546

    def admit(self, child, D_val, D_safe):
        if not refines(child, child.parent):              # (a)
            return self._reject(child, 'not-refinement')
        if clopper_pearson_lb(child.coverage(D_val), self.delta) < 1 - self.alpha:
            return self._reject(child, 'coverage')        # (b)
        if child.safety_violations(D_safe) > 0:           # (c)
            return self._reject(child, 'safety-regression')
        if not provenance_ok(child) or not child.reviewed:
            return self._reject(child, 'provenance')      # (d)
        if not self.lattice.consistent(child):            # (e)
            return self._reject(child, 'lattice-overlap')
        self.lattice.add(child)
        return child

    def _reject(self, child, why):
        child.status = 'quarantined:' + why
        self.quarantine.append(child)
        return None

## 4. 推导

**引理 87（鲁棒迁移证书的保守性 / Transfer Soundness）** 设 (A1) 先例在其认证状态 x_π 的证书是保守的（v9 引理 82）：真实间隙 g(x_π)≥ĝ_min^π、真实力 e(x_π)≤ê_max^π；(A2) 在迁移邻域内真实指标满足 Lipschitz 界 g(x_t)≥g(x_π)−L_g^π d_x−L_σ^π d_σ、e(x_t)≤e(x_π)+L_e^π d_x+L_σ^π d_σ；(A3) RTC 有效。则
```
g(x_t) ≥ ĝ_min^π − L_g d_x − L_σ d_σ = g^tr + β_s(age) ≥ g^tr ≥ d_safe^s
e(x_t) ≤ ê_max^π + L_e d_x + L_σ d_σ = e^tr − β_s(age) ≤ e^tr ≤ τ_eff^s
```
且对每个 p∈P^tr，迁移后的间隙下界 ≥ d_brake(v_p)+d_safe^s，故定义 534 的停车不变式成立。因此检索块是 s-可采纳的（定义 544），与 v9 在线证书同属 A(s)。∎
*关键限定*：结论完全条件于 (A2) 的 Lipschitz 上界；这不是纯代数恒等式，而是"标定假设"。

**引理 88（检索空洞与严格退化 / Null Retrieval Equivalence）** 检索返回 ∅ 的任一触发条件（空记忆、无有效 RTC、D_R 超时、age>T_fresh、provenance 不匹配、撤销、格版本不一致）都使主闭环对 current_chunk 的赋值与 v9 完全一致：同一 `generate_chunk(state, Δ_dom, τ_dom, trust_ok)`、同一 midchunk_guard、同一 v8 继承路径。SLI 在线只写残差缓冲，不修改任何阈值或动作；CGL 只写审计日志。故控制输出逐位等价 v9（日志中的 retrieval flag 不参与执行）；再由 v9 引理 83 逐级等价 v8。∎

**引理 89（场景精化的安全单调性 / Refinement Monotonicity）** 若 s'⪯s，则 Σ_{s'}⊆Σ_s 且 d_safe^{s'}≥d_safe^s、τ_eff^{s'}≤τ_eff^s、β_{s'}≥β_s。对任意块 y，若 y 是 s'-可采纳（g≥d_safe^{s'}、e≤τ_eff^{s'}、停车不变式成立），则必 g≥d_safe^s、e≤τ_eff^s，且停车不变式中的 d_safe 更小仍成立，故 y 也是 s-可采纳。即 A(s')⊆A(s)。场景创新只添加精化节点，永不放宽任何节点到父节点的约束，故全局可采纳集始终 ⊆ A(s_0)=v9 可采纳集。∎

**引理 90（新颖度触发的统计校准 / Conformal Novelty Calibration）** 设节点内残差样本与标定集可交换，采用分裂保形分数 s_i，则在线 p 值 p_t=(1+Σ_i 1[s_i≥s_t])/(n+1) 在无漂移时超均匀，触发 p_t≤α 的误报率 ≤α/查询；窗口聚合 W 次并以 H_nov 连续窗口确认，误触发上界由并集界 ≤H_nov·α。若真实未覆盖质量为 m，则期望检测延迟 ≤⌈τ_nov/m⌉ 个窗口。**该结论以可交换性为前提**；分布漂移破坏可交换性时，它退化为启发式，必须依赖引理 88 的 ∅ 回退与周期性重标定。∎

**引理 91（准入的覆盖单调性与统计边界）** 准入要求 (a) 精化、(b) D_val 上 RTC 有效率下界 ≥1−α、(c) D_safe 零违背、(d) provenance、(e) 格一致。添加子节点只可能把 Σ_child 上的检索结果从 ∅ 变为某个认证先例的 RTC（当且仅当 M_child 非空且 RTC 有效），不改动 Σ_child 之外的检索、也不改任何阈值（引理 89）。故在任意评估集上 Cov(L∪{s_new},D)≥Cov(L,D)，安全违背不增加；若父节点此前因过保守而频繁 ∅，覆盖严格增加。注意 (b) 是**置信下界**，因此覆盖非降在 D_eval 上是 w.h.p. 而非确定性；这由 (b) 的 α,δ 显式定价。∎

**引理 92（组合失效与退化链闭合 / Compositional Closure）** 将新组件映射到中立元：CRM→∅、RCR→v9 MW（检索端口禁用）、SLI→冻结根场景 s_0、CGL→v9 平均日志。任取失效子集 F，按中立元注入后，控制路径或等于 v9（引理 88），或等于 v9 某个既有退化级（v9 引理 83），故整体落在 {v9,v8,v7,v6} 格点内。并且：SLI 永不放宽阈值（引理 89），记忆投毒无法绕过 RTC 与 provenance（定义 543/547），撤销只降级到父节点（定义 548）。因此退化链在组合下闭合，检索层不产生新的不安全状态。∎

| 格 vs 扁平（E579） | 命中 ↑≥15% | 调整格深度与优先级 |
| 碎片化（E580） | 节点数 ≤预算且命中不降 | 合并兄弟节点、提高挖掘门槛 |
| 投毒（E581） | 检出 ≥95% | 加跨源一致性、人工复核入口 |
| 陈旧（E582） | 0 僵尸信任 | 缩短 T_fresh、增大 κ |
| 偏移（E583） | 回退平滑、无指令跳变 | 改 ρ 自适应、K_eff 插值 |
| 负迁移（E584） | 性能差 ≤容忍 | 降级节点、撤销相关先例 |
| Pareto（E585） | 覆盖–性能曲线可报告 | 重选评估集、补未覆盖清单 |
| 预算（E586） | 越限 ≤0.1%、0 丢拍 | 检索移后台预取、减小 k |
| 长跑（E587） | 覆盖趋势稳定、版本可审计 | 周期重标定、加衰减 |
| 多机（E588） | 覆盖 ↑≥10% | 场景库版本化、冲突消解 |
| 消融（E589） | 各组件非负且可分离 | 检查耦合、拆分检索/创新 |
| 竞赛（E590） | ≥ v9 + 15% 且覆盖指标不劣 | 综合调参、分析失分瓶颈 |

## 8. 本轮最大风险

**一句话**：鲁棒迁移证书的可靠性完全依赖 Lipschitz 上界 L_g 的正确性，而 L_g 只能在平滑数据上标定；在抓取接触、形变、打滑等指标函数不可微、导数爆炸的时刻，真实 L_g 可能远超标定值，检索会以"已认证"的姿态在最熟悉的场景里借来一个不成立的安全证明。
