# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「UniBot」×「视觉定位」）

> R66–R69 把闭环做得越来越聪明：会控制、会预测、会标定、会提问。但它们共享一个结构性盲点：**全部证据都来自同一条自指传感器流**——残差、流似然、模态、回答，都只在本机历史里自洽。自洽的系统可以**联合地错**：若整个地图坐标系/里程计基准被缓慢平移，R68 的残差为 0、R69 的流似然为 0、交互得到的回答也一致，因为大家活在同一条被平移的「纤维」上。这是**规范自由度（gauge freedom）**：局部证据对全局刚体变换不变，所以它从原理上看不见全局错。
>
> 本轮两个灵感正好补上两块缺失，也带来一个尖锐矛盾：
> - **视觉定位**给出对离线先验地图的绝对位姿——一个**外生锚点**，把全局 SE(3) 规范钉住；而且它在重复结构下天然给出**多峰位姿后验**，把「我在哪」变成 R69 意义上的 epistemic 歧义，主动重定位于是就是一个信息动作。
> - **UniBot（统一机器人基础模型）** 用一套共享表征同时承载「我在哪」和「我该做什么」，换来交叉读出互检与跨本体复用；但**统一会把误差相关性也统一掉**，直接威胁 R66–R69 全部安全论证所依赖的「正交证据源」前提。
>
> 核心命题：**为闭环引入外生视觉定位锚点来固定规范（gauge fixing），并把「锚点可信」与「多通道仍独立」拆成两个必须分别认证的属性；UniBot 式统一只允许发生在表征层，绝不允许发生在数据来源与失效模式层。** 命名 **ANCHOR-RAS**（Absolute-Navigation Consistency with Heterogeneous Orthogonal References）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我凭什么相信我所在的那个世界就是它**」——不确定性不仅要被问出来，还要被钉在一个外生的坐标上。

## 0. 直觉与动机

**灵感 1（视觉定位 → 外生锚点，固定规范）**
直觉：前面所有轮次的「自洽」都是相对自洽。一个人蒙着眼在走廊里走，他可以宣称「我走得很稳」（残差低）、「我的动作很自然」（似然高）、「我问到的答案一致」（证据一致）；但如果他一开始就站错了楼层，这些全都成立，结论却全错。视觉定位的价值不是「更准的里程计」，而是**一个不来自当前这条传感器流的绝对参考**。它钉住全局刚体变换这个不可观方向。关键限定：这种价值来自**过程独立性**（地图是离线、用别的数据、别的时间建的），而不只是几何外部性——若地图与当前里程计同源、同一次失效的产物，它只是把同一个错误抄了一遍。

**灵感 2（视觉定位天然多峰 → 别名 = epistemic，主动重定位 = 信息动作）**
直觉：视觉定位最危险的场景不是「定位失败」，而是「**自信地定位到错误的地方**」——重复房间、对称走廊、玻璃幕墙、季节变化。此时检索返回多个外观相似但地理位置很远的候选，位姿后验是**多峰**的。这与 R69 的流匹配多模态是同一类对象：几个候选 + 权重 + 可分性。于是「我在哪」本身就是一个可消解的 epistemic 歧义；消解它的动作（往左看、向前走两步换视野、切深度/语义模态）正是 R69 定义 294 的信息动作 g。**主动重定位不是新控制器，而是把已有 VoI 控制器接到一个更高价值、更高成本、作用范围更全局的信息动作上。**

**灵感 3（UniBot → 统一带来互检，也带来相关性）**
直觉：统一模型让定位头与策略头共享 latent z。好处很实在：若 z 同时解码出位姿 p̂ 与动作 a，则「在 p̂ 处执行 a」必须自洽——一个免费的交叉读出检验；而且一张地图上的统一表征更容易跨本体复用（另一台机器人也能在同一张图里重定位）。危险同样实在：**共享参数让不同通道的误差相关**。R69 敢用「k 个正交源一致」抗投毒，前提是各源欺骗相关 ρ<1；若 UniBot 把三个通道压成同一个 trunk 的三个头，它们的错误会一起犯，「多数一致」可能只是「同一个错误投了三次票」。统一是能力，不是安全；**安全需要失效模式的多样性，而不是表征的统一性。**

**灵感 4（锚点也是攻击面 → 不能给单一权威）**
直觉：一旦引入锚点，它就是唯一能**否决**整个自洽闭环的通道——这是它的力量，也是它的单点故障。过期地图、地图投毒、伪造的视觉基准/UWB/AprilTag、把定位重定向到错误楼层（GPS spoofing 的视觉版），都能让系统「自信地」做一次大幅纠正动作。因此锚点必须像 R69 的交互一样被认证：单次定位不得定案；地图要有来源证明与版本；别名要由主动重定位消解；锚点与局部证据冲突时，优先怀疑「世界变了/被改了」，而不是立刻推翻局部证据。

**灵感 5（严格包含 → 锚点关闭时逐指令退回 R69）**
直觉：并非所有场景都能/该做视觉定位（无图、暗光、算力紧张、地图过期）。ANCHOR 必须把 R69 作为「锚点关闭 / 不可信」的边界情形逐指令包含：门控不过就完全退回 FLUID-RAS，安全侧不减分；锚点可信且一致才获得「全局一致性红利」。**新层不能成为新的必须信任的黑箱，只能是一个可以被关掉、被审计、被降级的外挂。**

## 1. 形式化定义（增量：定义 310–326）

**定义 310（ANCHOR-RAS 总览）** ANCHOR-RAS = (GAL, MHP, GDL, AIR, UCC, IND, MCG-A, ALS, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **锚点预算硬约束**：全局重定位的调用频率与能耗有上限，只有经 ALS 调度且认证通过后，锚点才允许否决局部证据；
(iii) **锚点证据纪律**：单次定位/单一地图不得单独定案，需与局部证据在独立性证书下交叉验证；
(iv) **统一不豁免独立性**：UCC 共享 trunk 时必须报告有效独立性 ρ_eff，超过阈值即强制去相关，否则禁用锚点否决权。

**定义 311（先验地图与来源证明）** M = (M_dense, M_topo, prov(M), ver(M), t_build)。prov 记录数据来源/传感器/本体/时间。锚点价值的来源是 **proc(M) ⊥ 当前传感器流**（过程独立），而非单纯的几何外部性。

**定义 312（视觉定位观测与多峰位姿后验）** 图像 I_t；检索得候选 {(p_i, w_i, Σ_i)}_{i=1}^m，w_i 为检索+几何验证（PnP/RANSAC）后的权重，p_i ∈ SE(3)，Σ_i 为位姿协方差。全局位姿后验 P_t = Σ_i w_i 𝒩(p_i, Σ_i)。**不做单点坍缩。**

**定义 313（感知别名与位姿可分性）** 别名比 α = 1 − max_i w_i；位姿间距 Δ_pose = min_{i≠j} d_SE3(p_i, p_j)/√(tr Σ_max)；位姿熵 H_loc = −Σ_i w_i log w_i。可分性条件 **A96：Δ_pose ≥ 3σ_pose**。

**定义 314（外生性证书）** 证书 prov(M) 有效 ⇔ 地图数据与当前本体当前传感器流在采集时间/传感器/流程上不相交，且未被当前流在线监督。外生性不是「坐标不同」，而是「失效不共因」。

**定义 315（有效独立性证书 IND）** 三通道 e = (r_res, Δa, r_anchor)。在标定窗口估计三通道失效指示量的相关矩阵，定义 **ρ_eff = max_{i≠j} |Corr(err_i, err_j)|**；要求 ρ_eff ≤ ρ_max。ρ_eff 度量的是**失效模式**的独立，而非表征的独立——共享 trunk 不必然违反它，除非共享导致误差同源。

**定义 316（三轴证据与测地残差）** 测地残差 r_anchor = Mahalanobis(p̂_local, P_t)（用完整协方差，含模态间分离）。三轴证据 = 传感器自洽 r_res（R68）× 行为自洽 Δa（R69）× 地图锚定一致 r_anchor（R70）。

**定义 317（集体幻觉判据 GDL）** D = 1 ⇔ (r_res < τ_res) ∧ (Δa < τ_a) ∧ (r_anchor > τ_anchor)。语义：**局部两通道都判「我很好」，外生锚点却判「你不在你以为的地方」** ⇒ 疑似全局框架错、绑架（kidnapping）、地图漂移或地图被改。此时禁止直接用局部自洽去做大幅动作。

**定义 318（主动重定位 VoI）** 候选信息动作 g_loc ∈ 𝒜_info^loc（注视方向、小幅位移换视野、切换模态）：
VoI(g) = H_loc(P) − E_{y~p(·|g)}[H_loc(P|y)]，g* = argmax_g [VoI(g) − c_loc(g)]，s.t. risk(g) ≤ ε_int 且预算未超。若 max[VoI−c] ≤ 0：不重定位，保留多峰后验并走保守/回退。R69 的 MINT 在此被复用，只是作用对象从动作模态换成位姿假设。

**定义 319（统一交叉读出 UCC）** 共享 latent z → (p̂_loc, â, ξ)。一致性 c_ucc = −log p_θ(ξ | p̂_loc) 或位姿-动作相容性。若定位读出隐含的「我应在的位置」与策略读出隐含的位置冲突 ⇒ 统一层自相矛盾，标记为统一失败（不得据此做锚点否决）。

**定义 320（锚点信任门 MCG-A）** anchor_trusted ⇔ prov(M) 有效 ∧ 地图未过期（now − t_build ≤ TTL）∧ 别名 ECE ≤ τ_ece ∧ 近期主动重定位已消解别名 ∧ ρ_eff ≤ ρ_max。任一不满足 ⇒ 禁用锚点否决权，逐指令退回 R69。

**定义 321（锚点调度 ALS）** 触发条件（其一）：绑架疑似（r_anchor 突跳 / r_res 与 Δa 同时低但行为与地图预测漂移）、长时间无锚、进入地图重访区、UCC 报统一冲突。用便宜检索描述子做门控，仅在触发时做几何验证与多假设。**调度本身是 VoI**：是否值得花算力去固定规范。

**定义 322（三通道对偶）** (r_res, Δa, r_anchor) 的联合模式：
- 全低 ⇒ 一致，放行；
- r_res 高 ⇒ 传感器问题（R68）；
- Δa 高 ∧ r_res 低 ⇒ 行为/缓变故障（R69）；
- **r_anchor 高 ∧ 局部全低 ⇒ 全局框架错/绑架/地图漂移（R70 新增）**；
- 多通道同时高 ⇒ 疑似锚点被投毒，或统一导致的相关故障（应查 ρ_eff）。

**定义 323（三级退避）** (a) 锚点可信且一致 ⇒ R69 + global-consistency bonus（可谨慎释放部分过度保守，或仅作诊断）；(b) 锚点不可信/不可用 ⇒ **逐指令退回 R69**；(c) 锚点可信但强烈冲突且预算内无法消解 ⇒ **安全停机/重定位优先**：λ 拉满、禁止依赖局部自洽做大幅动作，纠正量受认证位姿不确定度约束。

**定义 324（锚点干扰集 ℰ_anchor）** 地图过期/季节变化/动态遮挡、感知别名、地图投毒、伪造视觉基准/UWB/标签、描述子漂移、跨本体重定位的域偏移、统一表征导致的相关失效。并入 AIC：ℰ_ANCHOR = ℰ_FLUID × ℰ_anchor。

**定义 325（参与式审计 VQAuditor-G）** 审计锚点决策：是否单源采纳、是否用陈旧地图、别名是否消解、是否越过局部证据直接大幅纠正、ρ_eff 是否达标、纠正动作是否超出认证不确定度。结论回灌 AuditBuf，成为 ALS 的调度先验。

**定义 326（证书 J_ANCHOR）** J_ANCHOR = (J_FLUID, map_prov_hash, map_ver, anchor_ece, aliasing_ratio, r_anchor, rho_eff, reloc_voi, gauge_state, anchor_ver)。Valid ⇔ Valid(J_FLUID) ∧ 锚点证据纪律满足 ∧ ρ_eff ≤ ρ_max ∧ 地图未过期。

# IP-264/265 GAL+MHP：多假设视觉定位，绝不单点坍缩
def localize(img, mp, topk=5):
    cand  = retrieval(img, mp.topo, topk)                  # 便宜描述子
    poses = geometric_verify(img, cand, mp.dense)          # PnP/RANSAC
    w     = softmax([p.inlier_score / T for p in poses])
    return PoseMixture(poses, w)                           # {p_i, w_i, Σ_i}

# IP-266 GDL：集体幻觉判据（局部自洽 ∧ 锚点冲突）
def delusion(r_res, delta_a, r_anchor, P):
    local_ok = (r_res < TAU_RES) and (delta_a < TAU_FMA)
    anc_off  = (r_anchor > TAU_ANCHOR)                     # Mahalanobis，含 Σ
    return local_ok and anc_off                            # 全局框架错/绑架/地图漂移

# IP-267 AIR：主动重定位（复用 R69 MINT 的 VoI）
def active_relocalize(P, budget, c_ras_wm):
    best = None
    for g in reloc_candidates(P):                          # 看向 / 小步 / 换模态
        if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
        score = (H_loc(P) - expected_H_loc(P, g)) - cost_loc(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None       # 无利可图 → 保留多峰

# IP-268/269 UCC + IND：统一交叉读出与有效独立性
def ucc_independent(z, xi, P, err_hist):
    p_hat = decode_loc(z)
    ok    = compat(p_hat, P) and policy_ll(xi, p_hat) > TAU_UCC
    rho   = max_abs_corr(err_hist)                         # 三通道失效指示相关
    return ok, rho

# IP-270 MCG-A：锚点信任门（不过 -> 逐指令退回 R69）
def anchor_trusted(mp, P, rho, now):
    return (prov_valid(mp) and now - mp.t_build < TTL
            and aliasing_ece(P) <= TAU_ECE
            and reloc_resolved(P) and rho <= RHO_MAX)

# IP-275 主闭环（继承 R69，只在证据层插入锚点）
def ANCHOR_RAS_round(M, obs):
    k, lam, mode, U = M.fluid.step(obs)                    # R69 原样先跑
    r_res, delta_a   = M.last_r_res, M.last_delta_a
    P = r_anchor = None
    # 1) 调度：只在值得/需要时做一次全局锚定
    if M.als.should_anchor(obs, r_res, delta_a, M.gauge):
        P = M.gal.localize(obs.img, M.map_)
        if M.mhp.ambiguous(P) and not M.budget.empty():
            g = M.air.active_relocalize(P, M.budget, M.c_ras_wm)
            if g is not None:
                P = M.mhp.update(P, M.cia.execute(g))      # 看/走/换模态
        r_anchor = M.gal.residual(P, M.gauge.pose)
        # 2) 三通道判据
        if M.gdl.delusion(r_res, delta_a, r_anchor, P):
            if M.anchor_trusted(M.map_, P, M.rho_eff, obs.t):
                return M.safe_relocalize_or_stop(P)        # 安全侧：重定位/停机
            else:
                M.vqa_g.flag('anchor_conflict_untrusted')  # 退回 R69
    # 3) 锚点可信且一致：固定规范，谨慎给红利
    if P is not None and M.anchor_trusted(M.map_, P, M.rho_eff, obs.t):
        lam = min(lam, M.global_bonus(lam, r_anchor, U))   # 可配置为恒等
        M.gauge.update(P)                                  # gauge fixing
    M.vqa_g.submit_async(P, r_anchor, M.rho_eff, M.gauge.state)
    return k, lam, mode, U

## 3. 推导

**引理 19（别名下的重定位信息增益）** 设真实位姿 p*、后验权重 w、位姿间距 Δ_pose、模态内标准差 σ_pose。在 A96（Δ_pose ≥ 3σ_pose）下，执行信息动作 g 使位姿后验熵降低 ΔH_loc，则相较直接按 w 采样，期望位姿误差下降 ≥ c·Δ_pose·(1 − e^{−ΔH_loc})。系：**别名越大、候选越分得开，重定位越值钱**；若候选在可分性上退化（Δ_pose 小，如完全相同的房间），重定位无益，应保留多峰并保守回退——这与 R69 引理 16 完全同构，只是从动作空间搬到 SE(3)。

**引理 20（局部闭环的规范不可观测性 / 集体幻觉原理）** 设局部证据向量 e_local = (r_res, Δa, H_mode, …) 只由相对测量与经标定吸收的常值偏置构成。令规范群 G_local = SE(3) 对地图坐标系与里程计基准做整体刚体平移/旋转（并同步相应外参），则 e_local(g·W) = e_local(W) 对所有 g ∈ G_local 成立。故任何仅以 e_local 为输入的检验都无法区分世界状态 W 与其规范轨道 g·W；全局位姿误差落在 G_local 轨道内时**原理上不可观**。外生地图把对称性从 G_local 收缩为地图自同构群 Aut(M)（自相似走廊、重复房间），即「感知别名」——所以别名不是巧合，而是锚点之后**残余的规范自由度**。系：R68/R69 的集体幻觉不是检测器的缺陷，而是仅有局部通道时的信息论必然。

**引理 21（锚点投毒上界与有效独立性）** 单源锚点若欺骗率为 δ_a，则错误锚点采纳率 ≥ δ_a。采用 k 个有效独立（ρ_eff<1）的锚点/证据源多数一致，错误采纳率 ≤ δ_a·ρ_eff^{k−1} + ε_σ。系：**统一表征会抬高 ρ_eff，从而直接削弱该上界**——IND 必须实测 ρ_eff 并设硬门；跨本体/同源数据构建的地图会破坏定义 314 的外生性，使 k 的有效值下降。

**引理 22（锚点修正的安全传播界）** 设当前位姿不确定度为 Σ_P，纠正动作幅度为 Δu，环境对位姿的敏感 Lipschitz 常数为 L_u。则纠正引入的附加风险 ≤ L_u·√(tr Σ_P)；若 ‖Δu‖ 被限制在 κ·√(tr Σ_P)（κ 为认证常数），则锚点修正的瞬时风险 ≤ κ·L_u·tr Σ_P。系：**大幅纠错必须被认证位姿不确定度封顶**，禁止「定位一跳就猛打方向」；这正是定义 323(c) 安全停机/限幅的依据。

**定理 18（ANCHOR 对 R69 的条件包含）** 在 A96–A100 下：当锚点不可用/不可信（MCG-A 不过）时，ANCHOR 与 R69 **逐指令相同**；当锚点可信且与局部一致时，其期望风险 ≤ R69（锚点只增加一个被证书约束的否决/诊断通道）。注意：**若锚点本身错误（违反 A99：P(错误锚定) ≤ ε_a）或 ρ_eff 越界，则不宣称支配**——此时按定义 323(b) 退回 R69，而非冒险。故 R69 是 ANCHOR 在「锚点关闭」边界上的严格退化；安全侧不做无条件让步。

**定理 19（统一-独立性权衡）** 设网络统一程度为 κ_u（共享参数比例/共享数据比例）。则平均精度随 κ_u 上升（方差与偏差下降），但通道误差相关 ρ_eff 随 κ_u 单调不降；在一阶模型下期望认证风险 ≈ R_acc(κ_u) − λ·ρ_eff(κ_u)。故存在最优 κ_u*：**特征可统一，证据不可统一**。系：把定位头与策略头做成同一 trunk 的兄弟头（共享特征）可以，但锚点的地图来源、失效模式与训练数据必须与局部通道**过程分离**，并实测 ρ_eff。

**定理 20（集体幻觉的可检出性与根本极限）** 在 A99、A100 下，幅度超出 τ_anchor 的全局框架错被 GDL 检出的概率 ≥ 1 − ε_a − ε_est；但误差若落在 Aut(M) 的轨道内（别名不可分辨），则任何有限信息动作都无法区分（引理 20 的残余对称性），检出概率不超过锚点的可分辨性上限。系：**可检出性 = 1 − 不可分辨轨道质量**；主动重定位只能通过走出基本域来打破对称，环境真自相似时存在根本极限，只能承认不确定并保守。

## 6. 本轮最大风险

**一句话**：ANCHOR-RAS 引入了一个能**否决**整个自洽闭环的外生权威——若这个锚点本身是陈旧/别名/被投毒，或因 UniBot 统一表征而「假独立」，系统就会把「全局自洽但略有偏差」升级为「**自信地、以认证口吻做一次大幅纠错**」；而由于锚点是唯一能固定规范的通道，一旦它错，R68/R69 的所有安全保证都会被一起翻译到错误的坐标系里——**锚点错了，比没有锚点更危险**。

1. **地图投毒/伪造基准**（单点劫持）→ 定义 314 来源证明 + 引理 21 多源独立上界 + ℰ_anchor 对抗训练；
2. **别名导致的自信错定位** → MHP 保留多峰 + 引理 19 主动重定位 + 不可分辨时承认极限并回退；

4. **锚点冲突时猛纠** → 引理 22 纠正幅度封顶 + 定义 323(c) 安全停机/重定位优先；
5. **锚定开销击穿实时** → ALS 门控 + 低频摊销 + 无锚路径与 R69 零差异（定理 18）。

## 4. 推导

**引理 19（别名下的重定位信息增益）** A96（`Δ_pose ≥ 3σ_pose`）下，信息动作使位姿熵降 ΔH_loc，则相较按后验直接采样，期望位姿误差降 ≥ `c·Δ_pose·(1−e^{−ΔH_loc})`。系：别名大且候选分得开，重定位才值钱；候选不可分（Δ_pose 小）时应保留多峰、保守回退。与 R69 引理 16 同构，只是搬到 SE(3)。

**引理 20（局部闭环的规范不可观测性 / 集体幻觉原理）** 局部证据 `e_local` 只由相对测量与标定吸收的常值偏置构成；对规范群 `G_local=SE(3)` 作用于地图系与里程计基准，`e_local(g·W)=e_local(W)`。故仅凭 `e_local` 无法区分世界与其规范轨道，全局位姿误差原理上不可观。外生地图把对称性收缩为地图自同构群 `Aut(M)`（重复走廊/房间 = 感知别名）——**别名是锚点之后的残余规范自由度**。系：R68/R69 的集体幻觉是信息论必然，而非检测器缺陷。

**引理 21（锚点投毒上界与有效独立性）** 单源欺骗率 δ_a ⇒ 错误采纳率 ≥ δ_a；k 个有效独立（ρ_eff<1）源多数一致 ⇒ ≤ `δ_a·ρ_eff^{k−1}+ε_σ`。系：统一抬高 ρ_eff 直接削弱上界；同源/同本体建图破坏外生性，使有效 k 下降。

**引理 22（锚点修正的安全传播界）** 位姿不确定度 Σ_P、纠正幅度 Δu、环境敏感 Lipschitz `L_u` ⇒ 附加风险 ≤ `L_u·√(tr Σ_P)`；若 `‖Δu‖ ≤ κ·√(tr Σ_P)` 则瞬时风险 ≤ `κ·L_u·tr Σ_P`。系：大幅纠错必须被认证位姿不确定度封顶。

**定理 18（ANCHOR 对 R69 的条件包含）** A96–A100 下：锚点不可用/不可信 ⇒ 与 R69 逐指令相同；锚点可信且一致 ⇒ 期望风险 ≤ R69（只增加被证书约束的否决/诊断通道）。若锚点错误（违反 A99）或 ρ_eff 越界，则**不宣称支配**，按定义 323(b) 退回 R69。R69 = 「锚点关闭」边界上的严格退化，安全侧不做无条件让步。

**定理 19（统一-独立性权衡）** 设统一程度 κ_u，平均精度随 κ_u 上升，但 ρ_eff 随 κ_u 单调不降；一阶模型下认证风险 ≈ `R_acc(κ_u) − λ·ρ_eff(κ_u)`，存在最优 κ_u*。**特征可统一，证据不可统一**：共享 trunk 可以，但地图来源、失效模式、训练数据必须与局部通道过程分离并实测 ρ_eff。

**定理 20（集体幻觉可检出性与根本极限）** A99/A100 下，超出 τ_anchor 的全局框架错检出概率 ≥ `1−ε_a−ε_est`；但误差落在 `Aut(M)` 轨道内（别名不可分辨）时任何有限信息动作都无法区分，检出率不超过锚点可分辨性上限。系：可检出性 = 1 − 不可分辨轨道质量；主动重定位只能靠走出基本域打破对称，真自相似环境存在根本极限。

## 7. 本轮最大风险

**一句话**：ANCHOR-RAS 引入了一个能**否决**整个自洽闭环的外生权威——若这个锚点本身是陈旧/别名/被投毒，或因 UniBot 统一表征而「假独立」，系统就会把「全局自洽但略有偏差」升级为「**自信地、以认证口吻做一次大幅纠错**」；而由于锚点是唯一能固定规范的通道，一旦它错，R68/R69 的所有安全保证都会被一起翻译到错误的坐标系里——**锚点错了，比没有锚点更危险**。

**次级风险与缓解**：地图投毒/伪造基准（来源证明 + 引理 21 多源上界 + ℰ_anchor）；别名自信错定位（MHP 多峰 + 引理 19 主动重定位 + 极限时回退）；UniBot 摧毁独立性（IND 硬门 + 定理 19 特征统一证据不统一）；冲突猛纠（引理 22 幅度封顶 + 定义 323(c) 停机优先）；锚定开销击穿实时（ALS 门控 + 低频摊销 + 定理 18 无锚零差异）。
