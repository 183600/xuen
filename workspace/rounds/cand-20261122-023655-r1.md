# 第 1 轮（本轮灵感：「真实世界泛化」×「自然语言指令」）

> **基线**：现有 MetricVoiceGauge-NCD-HUTDH-v20（IP-420–424：PCA/CTS/CFC/HPC/CFCtrl）。v17 的 CLP/S2C/HCG/PSV/APS/AMC、v19 的 DCM/OGCC/CCV/DRS/OGC、v20 的感知层全部保留，不推倒。
> **本轮纪律**：**指令是约束而非真值，泛化是腐蚀而非扩张，澄清由证书不可行触发**。本轮只做一件事：把自然语言指令与真实世界分布偏移，安全地编译进碰撞证书的可行域。

## 0. 直觉与动机

**灵感 1（自然语言指令 → 指令是"待证约束"，不是"已证目标"）**

直觉：传统流水线是 `自然语言 → 语义解析 → 符号目标 → 规划 → 执行`，它隐含假设"解析结果即真值"。但自然语言是对意图的有损压缩：指代（"那个杯子"）、量词（"都放好"）、隐含前提（"别碰倒旁边的东西"）都带歧义，且高度依赖场景上下文。解析器一次自信的错误，就会变成一个不被审计的不安全动作。更麻烦的是，v20 的证书体系只回答"这个 θ 是否零碰撞"，它根本不知道"这个 θ 是不是用户想要的 θ"。

核心创新：**自然语言指令编译器 (Natural-Language Instruction Compiler, NLIC)**。它不输出单一目标，而输出一个**类型化约束程序** `Π_inst = {(φ_k, c_k)}`：每个原子 `φ_k` 是定义在 `(物体, 参数 θ; 接地上下文 Γ)` 上的守卫谓词，`c_k` 是其接地置信度。语义采用**鲁棒解释 (Robust Interpretation)**：一个动作可被采纳，当且仅当它在**所有后验不低于 `τ_ground` 的接地**下都满足指令——即 `Sem_τ(ℓ) = ⋂_{g ∈ Gnd_τ(ℓ)} Sem(ℓ | g)`。

关键反直觉点：**歧义不该被"解析得更准"，而应被显式地转化为参数域的腐蚀**。歧义越大，可执行域越小；系统只在**鲁棒语义集变空或活性低于阈值**时才请求澄清——也就是说，**澄清由"证书不可行"触发，而不是由某个拍脑袋的置信度阈值触发**。这把"理解得对不对"这个不可证的问题，换成了"在哪些解释下都安全"这个可证的问题。

**灵感 2（真实世界泛化 → 泛化是"证书的失效域"，不是"覆盖更多"）**

直觉：在仿真/实验室里算出的证书，只在若干假设下成立：摩擦系数、质量、几何、标定。真实世界会漂移。域随机化 (domain randomization) 试图让策略对某个分布鲁棒，但它**不告诉你证书何时仍然有效**——它把"泛化"变成了一个平均意义上的赌注，而安全需要的是逐次可验证的边界。

核心创新：**真实-仿真包络证书 (Sim-to-Real Envelope Certificate, SEC)**。把真实观测相对模型预测的残差 `e = y - M(x)` 投影到**不安全方向**，得到方向性包络 `E^+`；用保形分位 (conformal quantile) `q_{1-δ}` 给出有限样本覆盖保证；证书的参数域被**腐蚀**为 `Θ_real = {θ ∈ Θ_sim : margin_col(θ) ≥ L · E^+}`（`L` 为碰撞谓词对残差的 Lipschitz 敏感度）。

关键反直觉点：**真实世界泛化不是让证书覆盖更多，而是让证书知道自己何时失效**。而且包络必须**非对称**：摩擦变大通常安全（抓得更紧），摩擦变小才危险；只腐蚀危险方向，可以在不牺牲安全的前提下换回大量活性。"泛化 = 有证书的撤退 (certified retreat)"，而非乐观外推。

**灵感 3（两者的统一 → 两类认知不确定性，一个闭包）**

直觉：自然语言带来**语义认知不确定性**（到底指谁、到底要什么），真实世界带来**物理认知不确定性**（模型到底还准不准）。v20 只处理了几何不确定性。两类不确定性若各自保守、却被分开验证，就会出现"语义上安全、物理上安全、但合在一起不安全"的缝隙——例如指令把参数逼到碰撞域的边界，而该处恰好是残差包络最厚的地方。

核心创新：**语义-物理闭包证书 (Semantic-Physical Closure Certificate, SPC)**。一个计划可执行，当且仅当三张证书在**同一个参数域**上同时成立：`C_sem`（鲁棒语义）、`C_phys`（包络腐蚀）、`C_geo`（v20 碰撞）。闭包要求三者有效域的交非空且互相覆盖。若闭包失败，**可审计拒绝证书 (Auditable Refusal Certificate, ARC)** 给出**最小不可行子集 (MUS)** 并区分"该问用户"还是"该拒绝/回退"；**开集漂移哨兵 (Open-Set Drift Sentinel, OSD)** 在运行时监控分布偏移，一旦超出标定包络就判定 SEC 失效并回退 v20。

**三者如何统一**

统一为 **v20 证书体系之上的语义-物理层**：v20 回答"给定几何，θ 是否零碰撞"；v21 回答"给定自然语言与真实观测，θ 是否既被指令蕴含、又在物理包络内、还零碰撞"。NLIC 是语义侧（指令→约束），UEG 是歧义侧（歧义→腐蚀/澄清），SEC 是物理侧（残差→腐蚀），OSD 是时效侧（漂移→失效），SPC 是闭包侧（三者同域求交），ARC 是失败侧（可审计拒绝）。共享状态 `ζ_sem = (Π_inst, Gnd_τ, Sem_τ, E^+, nov, W, mode_sem)`。统一接口：**只有 SPC 出具闭包 witness 的子域，才交给 v20 的 CCV 执行；任何一环失效都退回到 v20（更保守）**。

## 1. 研究问题（轮次升级版）

- **Q1（指令约束的保守语义）**：如何把自然语言稳定地编译为类型化约束程序 `Π_inst`，使低置信度原子不被丢弃而是转化为腐蚀压力？`Sem_τ(ℓ)` 在候选接地组合爆炸时如何可计算地近似？如何避免 `Gnd_τ = ∅` 时的"空集真值"导致系统误以为无约束？

- **Q2（歧义治理与澄清触发）**：如何定义"歧义→域腐蚀"的单调映射，使 `τ_ground` 下降时 `Sem_τ` 单调收缩？澄清问题应如何按"信息增益/活性代价"选择？在"证书不可行"与"活性过低"两种触发下，如何保证有限步终止且不遗漏真实指代？

- **Q3（真实包络的方向性与覆盖）**：如何从真实残差中估计方向性包络 `E^+`，并给出有限样本覆盖保证？Lipschitz 敏感度 `L` 未知或过松时，如何在"过度腐蚀（不活跃）"与"腐蚀不足（不安全）"之间取得可审计的折中？非平稳真实世界下保形假设失效如何处理？

- **Q4（闭包、拒绝与时序）**：如何定义并机械验证三证书的"同域闭包 witness"？MUS 如何支持"该澄清"与"该拒绝"的可审计区分？OSD 的漂移检测如何与 v20 的 APS 新鲜度阶梯、v20 的 CFCtrl 时序回退协同，保证控制环始终有可验证边界？

## 2. 设计原则（在 P31–P33 基础上新增 P34–P36）

**P34 指令约束保守律（Instruction Constraint Conservatism）**
设指令 `ℓ`、接地上下文 `Γ`。NLIC 产出 `Π_inst = {(φ_k, c_k)}_{k=1..K}`。定义**可信接地集** `Gnd_τ(ℓ) = { g : P(g | ℓ, Γ) ≥ τ_ground }`，其中 `g` 是对全部指代的整体赋值。定义**鲁棒语义域**
`Sem_τ(ℓ) = ⋂_{g ∈ Gnd_τ(ℓ)} { θ : Π_inst(θ; g) = ⊤ }`，并规定 `Gnd_τ = ∅ ⇒ Sem_τ = ∅`（**禁止空集真值**：无接地即不可执行，而非无约束）。
三条硬约束：(i) **不扩张**：`Sem_τ(ℓ) ⊆ Θ_n`，NLIC 只能在 v20 参数域内收缩；(ii) **单调腐蚀**：`τ_ground` 下降 ⇒ `Gnd_τ` 增大 ⇒ `Sem_τ` 单调收缩（歧义越大域越小）；(iii) **低置信不丢弃**：`c_k < τ_ground` 的原子仍保留为腐蚀压力，绝不因"没把握"而删除约束。

**P35 真实包络腐蚀律（Real Envelope Erosion）**
设模型 `M`、真实观测 `y`、残差 `e = y - M(x)`；按不安全方向取 `e^+ = proj_unsafe(e)`。在标定集上取保形上分位 `E^+ = q_{1-δ}(e^+)`。设碰撞谓词对残差的 Lipschitz 常数为 `L`。定义**真实有效域**
`Θ_real = { θ ∈ Θ_sim : margin_col(θ) ≥ L · E^+ }`，等价于 `Θ_real = Θ_sim ⊖ E^+_Θ`（`E^+_Θ = L·E^+` 为参数域腐蚀量）。
性质：(i) **只腐蚀不扩张**：`E^+ ≥ 0 ⇒ Θ_real ⊆ Θ_sim`，`E^+ = 0 ⇒ Θ_real = Θ_sim`；(ii) **方向性**：安全方向残差进入 `E^-`，不参与腐蚀，以换回活性；(iii) **覆盖保证**：在标定与部署可交换 (exchangeable) 时，`P(margin_real ≥ 0) ≥ 1 - δ`；可交换性被 OSD 破坏时 SEC 自动失效。

**P36 闭包与拒绝律（Closure & Refusal）**
定义可执行域 `Θ_exec = Θ_v20 ∩ Sem_τ(ℓ) ⊖ E^+_Θ`。计划可执行当且仅当存在**闭包 witness** `W`，使 `W ⊨ C_sem ∧ C_phys ∧ C_geo` 且三者**有效域都覆盖 `Θ_exec`**（不是各自独立成立）。若 `Θ_exec = ∅` 或闭包失败，ARC 计算**最小不可行子集** `MUS ⊆ Π_inst ∪ {物理约束} ∪ {几何约束}`：若 `MUS` 含歧义原子 ⇒ 发起澄清；若含物理约束 ⇒ 回退 v20 或拒绝；若含几何约束 ⇒ 拒绝。**任何情况下都不执行未闭包的计划**，`Exec_v21 = { π : ∃W, W ⊨ C_sem ∧ C_phys ∧ C_geo }`。

## 3. 与基线的接口（如何退化）

- NLIC 失效（解析器不可用）⇒ 只接受显式结构化指令 ⇒ `Sem_τ = Θ_n` 但需人工确认 ⇒ 等价 v20（更保守）；
- UEG 失效（歧义治理关闭）⇒ 歧义原子按"最保守解释"全禁 ⇒ `Sem_τ` 进一步收缩 ⇒ 等价 v20 的子集；
- SEC 失效（无真实标定数据）⇒ `E^+ = +∞`（全腐蚀）⇒ 回退 v20 仿真证书（已知风险由 v20 承担）；
- OSD 触发（分布漂移）⇒ SEC 立即失效 ⇒ 回退 v20；
- ARC 失效（无法求 MUS）⇒ 整体拒绝 ⇒ 最保守；
- **安全继承**：NLIC 只收缩、UEG 只腐蚀、SEC 只腐蚀、OSD 只触发回退、SPC 只求交、ARC 只拒绝，六者任意失效都只会让可执行集更小，`Exec_v21 ⊆ Exec_v20` 由引理 160 保证。

## 4. 预期贡献

1. **指令即待证约束**：首次把自然语言从"解析成目标"改写为"编译成可证约束程序"，用鲁棒语义交集把歧义转成域腐蚀，给出"澄清由证书不可行触发"的可证策略；
2. **泛化即证书失效域**：首次把真实世界泛化表述为方向性残差包络对证书参数域的腐蚀，用保形分位给出有限样本覆盖，明确"证书何时失效"；
3. **语义-物理闭包**：给出三证书同域闭包的 witness 定义与可机械验证结构，堵住"各自保守、合起来不安全"的缝隙；
4. **可审计拒绝**：用 MUS 区分"该问用户"与"该拒绝/回退"，让系统在无法安全执行时给出可复核的解释而非静默失败；
5. **开集时效治理**：OSD 把分布漂移、开集物体/指令、时序回退统一到"证书失效"这一事件上，`Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19`，实现"理解—泛化—安全"的闭环。

## 5. 本轮最大风险

**一句话**：整套方案依赖 NLIC 的候选接地集 `Gnd_τ(ℓ)` 与 SEC 的标定集"至少包含真值/可交换"；若解析器**置信度很高却系统性漏掉真实指代**（把"那个杯子"稳定地接到错物体），则鲁棒交集是在**错误的候选集**上做保守运算，得到"对所有已考虑解释都安全、却违背真实意图"的证书——**越保守，越自信地做错事**。

# IP-425 Natural-Language Instruction Compiler
class NaturalLanguageInstructionCompiler:
    def __init__(self, grounder, tau_ground=0.8):
        self.grounder = grounder          # 解析器 + 场景图接地器
        self.tau_ground = tau_ground

    def compile(self, ell, Gamma):
        """自然语言 -> 类型化约束程序；低置信原子保留，绝不丢弃"""
        atoms = self.grounder.parse_constraints(ell, Gamma)   # [(phi, c, refs)]
        return ConstraintProgram(atoms=atoms, ell=ell, Gamma=Gamma)

    def robust_semantics(self, prog, tau=None):
        """鲁棒语义：对所有可信接地求交；空接地 => ∅（禁止空集真值）"""
        tau = tau if tau is not None else self.tau_ground
        groundings = self.grounder.plausible_groundings(prog, tau)
        if not groundings:
            return Domain.empty()          # 无接地 => 拒绝/澄清，而非无约束
        region = prog.universe()
        for g in groundings:
            region = region.intersect(prog.satisfying_set(g))
        return region

    def grounding_confidence(self, prog, g):
        """整体接地置信度取原子最小置信（保守）"""
        return min(c for (_, c, _) in prog.atoms)

    def signature(self, prog):
        """供闭包 witness 引用的可审计摘要"""
        return merkle_hash([(phi.key(), round(c, 6)) for (phi, c, _) in prog.atoms])


# IP-426 Under-specification Envelope Governor
class UnderSpecificationEnvelopeGovernor:
    def __init__(self, nlic, feasibility_floor=1e-3):
        self.nlic = nlic
        self.feasibility_floor = feasibility_floor

    def govern(self, prog, theta_v20):
        sem = self.nlic.robust_semantics(prog)
        if sem.is_empty():
            # 触发条件是"证书不可行"，不是某个置信度阈值
            return ClarificationRequest(
                question=self.best_clarifying_question(prog, theta_v20),
                reason="EMPTY_ROBUST_SEMANTICS")

        eroded = theta_v20.intersect(sem)
        if eroded.volume() < self.feasibility_floor:
            return ClarificationRequest(
                question=self.best_clarifying_question(prog, eroded),
                reason="ACTIVITY_BELOW_FLOOR")
        return GovernedDomain(domain=eroded, tau=self.nlic.tau_ground)

    def best_clarifying_question(self, prog, domain):
        """选"信息增益 / 活性代价"最大的歧义原子"""
        best, best_score = None, -inf
        for atom in prog.ambiguous_atoms():
            gain = atom.entropy_reduction()          # 消歧后接地熵的下降
            cost = atom.erosion_cost(domain) + EPS   # 消歧后域的预期收缩
            score = gain / cost
            if score > best_score:
                best, best_score = atom, score
        return best

    def clarifies_progress(self, prog):
        """每个问题至少剔除一个候选，候选有限 => 有限步终止"""
        return all(atom.removes_at_least_one() for atom in prog.ambiguous_atoms())


# IP-427 Sim-to-Real Envelope Certificate
class SimToRealEnvelopeCertificate:
    def __init__(self, model, collision_fn, delta=0.05):
        self.model = model
        self.collision_fn = collision_fn
        self.delta = delta
        self.calib_plus = []       # 不安全方向残差
        self.calib_minus = []      # 安全方向残差（不参与腐蚀）

    def calibrate(self, real_trials):
        """real_trials: (x, y, unsafe_sign)；只对不安全方向做单侧分位"""
        for x, y, sign in real_trials:
            e = y - self.model(x)
            if sign > 0:
                self.calib_plus.append(e)
            else:
                self.calib_minus.append(e)
        self.calib_plus.sort()

    def envelope_plus(self):
        """split-conformal 单侧上分位"""
        n = len(self.calib_plus)
        if n == 0:
            return +inf                       # 无标定 => 全腐蚀 => 回退 v20
        k = math.ceil((n + 1) * (1.0 - self.delta))
        return self.calib_plus[min(k, n) - 1]

    def erode(self, theta_sim, lipschitz_L):
        E_plus = self.envelope_plus()
        erosion = lipschitz_L * E_plus
        theta_real = Domain.from_predicate(
            theta_sim,
            lambda theta: self.collision_fn.margin(theta) >= erosion)
        return RealDomain(
            domain=theta_real,
            margin_real=theta_sim.margin() - erosion,
            envelope=E_plus,
            coverage=1.0 - self.delta,
            valid=math.isfinite(E_plus))


# IP-428 Open-Set Drift Sentinel
class OpenSetDriftSentinel:
    def __init__(self, model, delta_osd=0.01):
        self.model = model
        self.delta_osd = delta_osd
        self.novelty_calib = []

    def novelty(self, x):
        return self.model.novelty_score(x)

    def calibrate(self, xs):
        self.novelty_calib = sorted(self.novelty(x) for x in xs)

    def check(self, x):
        n = self.novelty(x)
        n_cal = len(self.novelty_calib)
        if n_cal == 0:
            return DriftDetected(score=n, threshold=0.0, action="FALLBACK_V20")
        k = math.ceil((n_cal + 1) * (1.0 - self.delta_osd))
        threshold = self.novelty_calib[min(k, n_cal) - 1]
        if n > threshold:
            # 分布偏移 => SEC 失效 => 回退 v20
            return DriftDetected(score=n, threshold=threshold,
                                 action="FALLBACK_V20")
        return Fresh(score=n, threshold=threshold)


# IP-429 Semantic-Physical Closure Certificate
class SemanticPhysicalClosureCertificate:
    def __init__(self, nlic, ueg, sec, osd, ccv, lipschitz_L):
        self.nlic, self.ueg, self.sec = nlic, ueg, sec
        self.osd, self.ccv = osd, ccv
        self.lipschitz_L = lipschitz_L

    def close(self, ell, Gamma, node, theta_v20, x_obs):
        # 1) 物理时效：漂移即失效，直接回退
        drift = self.osd.check(x_obs)
        if isinstance(drift, DriftDetected):
            return self.refuse(ell, node, "PHYSICAL_ENVELOPE_INVALID", drift)

        # 2) 语义：编译 + 歧义治理
        prog = self.nlic.compile(ell, Gamma)
        governed = self.ueg.govern(prog, theta_v20)
        if isinstance(governed, ClarificationRequest):
            return governed

        # 3) 物理：方向性包络腐蚀
        real = self.sec.erode(governed.domain, self.lipschitz_L)
        if not real.valid:
            return self.refuse(ell, node, "NO_CALIBRATION", real)

        # 4) 几何：在"实际交集域"上做 v20 碰撞证书（非同域不闭包）
        theta_exec = theta_v20.intersect(real.domain)
        if theta_exec.is_empty():
            return self.refuse(ell, node, "EMPTY_CLOSURE", None)
        geo_ok, geo_proof = self.ccv.certify(node, theta_exec)
        if not geo_ok:
            return self.refuse(ell, node, "GEOMETRIC_UNCERTIFIED", geo_proof)

        # 5) 闭包 witness：三证书必须覆盖同一个 theta_exec
        witness = ClosureWitness(
            C_sem=prog.signature(),
            C_phys=real.envelope_proof(),
            C_geo=geo_proof,
            domain=theta_exec,
            valid_domains_cover=True)
        return Certified(theta_exec, witness)

    def refuse(self, ell, node, reason, detail):
        return AuditableRefusalCertificate.build(ell, node, reason, detail)


# IP-430 Auditable Refusal Certificate
class AuditableRefusalCertificate:
    @staticmethod
    def build(ell, node, reason, detail):
        constraints = collect_active_constraints(ell, node)
        mus = minimal_unsat_subset(constraints)
        if any(is_ambiguity_atom(a) for a in mus):
            action = "CLARIFY"
        elif any(is_physical_constraint(a) for a in mus):
            action = "FALLBACK_OR_REFUSE"
        else:
            action = "REFUSE"
        return RefusalCert(
            ell=ell, node=node, reason=reason,
            mus=mus, action=action,
            proof=merkle_sign(mus),
            detail=detail)

## 2. 推导

**引理 157（鲁棒语义的保守性与单调性）** 设 `Gnd_τ(ℓ)` 非空。对任意 `g ∈ Gnd_τ(ℓ)` 有 `Sem_τ(ℓ) = ⋂_{g'∈Gnd_τ} Sem(ℓ|g') ⊆ Sem(ℓ|g)`，故鲁棒语义不会采纳任何单一接地下的越界动作；又 `τ_1 ≤ τ_2 ⇒ Gnd_{τ_1} ⊇ Gnd_{τ_2} ⇒ Sem_{τ_1} ⊆ Sem_{τ_2}`，即歧义越大（阈值越低、候选越多）域单调收缩。当 `Gnd_τ = ∅` 时按 P34 约定 `Sem_τ = ∅`，从而排除"空集真值"导致的伪无约束。∎ 推论：**NLIC 只能收缩 v20 参数域，不能授权新动作**。

**引理 158（方向性包络腐蚀的可靠性）** 设标定残差与部署残差可交换，`E^+ = q_{1-δ}` 为单侧保形分位，则 `P(e^+ ≤ E^+) ≥ 1−δ`。若 `margin_col(θ) ≥ L·E^+`，由 Lipschitz 性 `|margin_col(θ) − margin_col(θ+e)| ≤ L·|e|` 得真实裕度 `margin_real(θ) ≥ margin_col(θ) − L·E^+ ≥ 0`，故 `Θ_real` 内每个 θ 在真实世界零碰撞的概率 ≥ 1−δ。又 `E^+ ≥ 0 ⇒ Θ_real ⊆ Θ_sim`，`E^+ = 0 ⇒ Θ_real = Θ_sim`，腐蚀算子幂等于边界。安全方向 `E^-` 不参与腐蚀，仅提高活性、不降低上述下界。∎

**引理 159（漂移回退的安全性）** 当 `nov(x) > q_{1-δ_osd}` 时 OSD 判定可交换性失效并置 `SEC.valid = False`；SPC 在闭包前先检查 OSD，失效即拒绝或回退 v20。故漂移期不产生基于过期包络的 `C_phys`，可执行集退化为 `Exec_v20`。由 v20 引理 156 知 `Exec_v20 ⊆ Exec_v19`，回退保持安全。∎

**引理 160（闭包可靠性与 v21 安全继承）** 若 SPC 出具 witness `W`，则 `C_sem`、`C_phys`、`C_geo` 的有效域都覆盖同一 `Θ_exec = Θ_v20 ∩ Sem_τ ⊖ E^+_Θ`。由引理 157 得 `Sem_τ ⊆ Θ_n`，由引理 158 得 `Θ_real ⊆ Θ_sim`，由 v20 得 `C_geo` 仅在 `Θ_v20` 内成立，三者取交只能收缩：`Θ_exec ⊆ Θ_v20`。因此 `Exec_v21 = {π : ∃W} ⊆ Exec_v20`。未闭包计划一律拒绝，故不存在"三证书各自成立但合起来越界"的执行。∎

**引理 161（澄清的有限终止与进展）** 歧义候选集有限；UEG 每题至少剔除一个候选（`clarifies_progress`），且 `τ_ground` 在澄清后单调上升使 `Gnd_τ` 单调收缩。故至多 `|Cand|` 轮后 `Gnd_τ` 为单点或为空：单点时 `Sem_τ` 为确定语义域，空集时 ARC 转为拒绝。信息增益非负、活性代价有下界 `EPS`，贪心不会死循环。∎

**引理 162（v21 整体安全继承）** 在同一几何快照、同一机器人集合、同一真实观测下，`Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`。证明：NLIC 收缩、UEG 腐蚀、SEC 腐蚀、OSD 仅触发回退、SPC 仅求交、ARC 仅拒绝，六者叠加只产生子集；任一环节失效均退化为更保守的 v20 路径。∎

## 6. 已知风险与失效模式

1. **接地器的自信误接（最大风险）**：若 `Gnd_τ(ℓ)` 置信度高却系统性漏掉真实指代，则鲁棒交集在错误候选集上运算，得到"对所有已考虑解释都安全、却违背真实意图"的证书。缓解：接地器校准/弃权、多模型集成、真值包含率在线抽检、低置信强制澄清。

2. **τ_ground 的两难**：过高会排除真值（不安全），过低会让候选爆炸（不可行/过度腐蚀）。缓解：用保形方法校准接地、按任务自适应 τ、以"真值包含率"而非"top-1 准确率"做验收。

3. **保形可交换性失效**：真实世界非平稳，标定集与部署分布不可交换时 `1−δ` 覆盖不再成立。缓解：加权保形、在线保形、OSD 触发即重标定，绝不沿用过期包络。

4. **Lipschitz 常数 L 不可靠**：`L` 估计过松导致过度腐蚀（不活跃），过紧导致腐蚀不足（不安全）。缓解：用区间 `[L_lo, L_hi]` 并取上界腐蚀、对 L 做敏感性分析、必要时用证书化估计。

5. **方向性符号错误**：把危险方向误判为安全方向，会直接删除必要的腐蚀。缓解：未知方向一律按不安全处理、多源残差交叉验证、方向性人工审计。

6. **OSD 漏检慢漂移**：渐进式漂移可能长期低于阈值，导致包络缓慢失效而不被察觉。缓解：窗口化/累积和 (CUSUM) 检验、周期性强制重标定、漂移趋势外推。

7. **闭包的耦合被误当作独立**：若在 `Sem_τ` 与 `Θ_real` 各自域上分别验证 `C_geo`，可能在交集边界处出现"各自安全、合起来越界"。缓解：SPC 强制在 `Θ_exec = Θ_v20 ∩ Sem_τ ⊖ E^+_Θ` 上重验，witness 记录实际交集域。

8. **候选接地组合爆炸**：`∏|Cand(r)|` 在长指令/多物体场景不可枚举。缓解：因子图/束搜索近似、惰性求交、按信息增益剪枝、缓存接地。

## 7. 本轮最大风险

**一句话**：整套方案的安全下界依赖"候选接地集含真值 + 标定集可交换"这两个不可由系统自证的前提；一旦解析器高置信地稳定漏掉真实指代，鲁棒交集就在错误的候选集上越算越保守，最终得到一个**形式完备、可审计、却在语义上执行了错误意图**的证书——即"在错误的集合上，保守地做错事"。
