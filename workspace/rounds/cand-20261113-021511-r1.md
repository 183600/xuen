# 第 64 轮（承接第 63 轮「LIRO 几何-技能-干扰闭环」IP-193~203；灵感循环 III 第 1 轮；本轮灵感：「语音识别」×「视觉伺服」）

> 第 63 轮构建了 LIRO：LSF 稠密几何先验、USL+CSP 技能组合、DIR+AIC 干扰不变表征与认证，把 ROSE 从「参数层在线鲁棒进化」推进到「几何-技能-干扰三层联合」。但第 63 轮暴露的不只是几何幻觉，而是**两个更深的时间尺度断层**：
> 1. **语言是静态快照，不是流**：DMS 只消费完整句子嵌入 L，无法在人类「还在说」时提前准备，无法把词/短语对齐到技能段，无法表达「我没听清 / 我可能理解错了」的置信度与修复动作。真实指令含停顿、自我更正（"拿红的——不对，蓝的"）、否定（"别碰"）、同音歧义（"杯子/被子"）、噪声与多人串音。
> 2. **执行在语义步之间开环**：ERTC 把技能展开成阻抗关键帧后，在两次语义更新之间不闭环；视觉伺服本可用图像雅可比以 30–60Hz 把图像特征误差映射为速度/阻抗修正，并对深度不确定、标定误差、时延、特征丢失给出收敛性与回退保证。
> 3. **缺少「语义时间 ↔ 物理时间」的显式桥**：ASR 的 CTC/RNN-T 对齐与视觉伺服的交互矩阵，本质都是「带时延的时序对齐 + 误差驱动闭环」。LIRO 需要一个对齐层，把 token 流、技能段、图像伺服轨迹三者单调、可审计地绑定起来。

## 0. 直觉与动机

**灵感 1（语音识别 → SST：Streaming Speech Transducer 流式语音意图转录）**
直觉：人类不是等你说完整句才理解；ASR 用 CTC/RNN-T 在声学帧上维护**部分假设格（lattice）**，边听边出词，并用语言模型先验与置信度决定「继续听 / 纠正 / 确认」。把 DMS 从「整句编码器」升级为**流式联合解码器**：声学帧 A_{1:T} 经冻结自监督编码器 E_ac（wav2vec2 式）→ 帧表征；联合词表 V_word × 技能表 V_skill 的 RNN-T 解码器输出部分意图假设 ℓ_t 及**词级时间戳**；对每个假设给出校准置信度 c_t（温度标定 + 熵）；安全关键词（"停 / 别动 / 不对"）走独立高召回低时延 KWS 通道，拥有**硬否决权**。DMS 不再等待句号，而是输出「带时间、带置信、可撤销」的意图流。

**灵感 2（视觉伺服 → VSC：Visual Servo Compiler 视觉伺服编译器）**
直觉：IBVS 用图像雅可比 L_s = ∂s/∂q 把图像特征误差 e = s − s* 映射为速度 q̇ = −λ L̂_s⁺ e，形成像素级闭环；PBVS 在 3D 位姿空间闭环；混合方案按深度可信度切换。把 ERTC 从「语义步之间开环展开」升级为**双层执行**：语义层给出技能期望特征 s*_σ（由 eff 后置条件编译），实时层用 VSC 以相机帧率闭环修正，并把图像误差方向映射为**各向异性阻抗**（沿误差方向增大刚度、正交方向降低刚度以柔顺），深度不确定时用 Broyden 在线更新 L̂_s，时延用常速预测器补偿，特征丢失/遮挡时回退 PBVS 或阻抗保持。收敛性不再靠「假设模型准」，而是给出**深度误差 × 时延 × 增益**的显式稳定域。

**灵感 3（合流 → VISTA：Visuo-Instructional Servo-Temporal Alignment 视听指令伺服时序对齐）**
直觉：语音给「做什么、什么时候」，视觉伺服给「往哪、多用力」；两者共享同一个数学骨架——**在时延与部分可观测下做单调时序对齐并闭环纠错**。VISTA 定义三层时间：
- **语义时间**（token 流，秒级、事件驱动）；
- **技能时间**（技能段 τ，百毫秒级、CSP 规划）；
- **物理时间**（伺服控制，毫秒级、连续）。

核心新对象是**对齐矩阵 A**：把 token 时间轴单调映射到技能段时间轴（CTC 边缘化 + 单调约束），再把技能段映射到伺服期望特征轨迹 s*(t)。任一层对齐失配都会在**伺服残差**上留下痕迹：若 token 对齐错，s* 指向错误特征，伺服会「高精度收敛到错误目标」——因此必须用**残差 ↔ 语音置信的交叉校验**触发修复（重听、澄清、回退）。这正是第 63 轮「几何幻觉」教训在时间维度的对应物：**错误的先验比没有先验更危险**。

**灵感 4（原位升级，不推翻 ROSE/LIRO）**
- **DMS → DMS-S**：流式部分假设 + 置信度 + 安全词否决 + 修复动作。
- **USL → USL-T**：每技能附**token 模板**（可发音/同义词/否定模式）与**时序签名**，供 CTC 对齐。
- **CSP → CSP-A**：规划约束加入「token-skill 单调对齐」与「不可逆技能延迟门控」。
- **ERTC → ERTC-VS**：技能展开为 s*_σ 特征轨迹，实时层 VSC 闭环。
- **AIC → AIC-SV**：认证并入语音置信与伺服收敛裕度（时延/深度/遮挡）。
- **OCB → OCB-Stream**：臂空间加入 {listen, wait, act, repair} × 伺服模式，奖励含「提前动作收益 − 误动作风险」。
- **J_liro → J_vista**：证书增加 speech_align_hash、servo_conv_cert、confidence_calib_ver。

## 1. 形式化定义（增量：定义 201–216）

- **定义 201（VISTA 闭环）**：VISTA = (LIRO, SST, USL-T, CSP-A, VSC, AIC-SV, OCB-Stream, J_vista)。三层时间隔离：语义时间（SST/CSP-A，事件驱动）、技能时间（USL-T，百毫秒）、物理时间（VSC/ERTC-VS，毫秒）；学习只发生在语义时间低频线程，实时路径零学习写操作。
- **定义 202（SST 流式语音意图转录）**：声学帧 A_{1:T} → E_ac（冻结，自监督）→ 帧表征 h_{1:T}；联合解码器输出部分假设格 ℒ_t = {(ℓ, π, c)}，ℓ 为词-技能混合序列，π 为单调对齐路径（CTC 边缘化），c 为校准置信度。KWS 通道 k_t ∈ {safe, veto} 拥有硬否决权。
- **定义 203（token-skill 单调对齐矩阵）**：A ∈ {0,1}^{T_tok×H}，A_{j,i}=1 表示 token j 对齐技能 σ_i；约束：每行至多一个 1（其余为空白）、每列连续、列序单调不减。对齐后技能边界 b_i = [t_i^start, t_i^end]。
- **定义 204（语义-物理时序 warp）**：W: 语义时间 → 物理时间，W(t) = Σ_i 1[t∈b_i]·(t − t_i^start)/(t_i^end − t_i^start)·D_i，D_i 为技能 σ_i 的伺服时长；W 单调、分段线性、可审计。
- **定义 205（USL-T 时序技能模板）**：σ^T = (σ, Tok_σ, sig_σ)，Tok_σ 为触发词/同义词/否定模式集合，sig_σ 为期望特征轨迹模板 s*_σ(t) 与时长先验。
- **定义 206（CSP-A 对齐感知规划）**：在 CSP 硬/软约束上增加：① 存在单调 A 使 token 序列与 τ 对齐且对齐代价 ≤ ε_align；② 不可逆技能（insert/release/hand-over）仅在意图置信 c ≥ τ_c 且无否定 token 时展开；③ 可逆技能（reach/approach）允许**预执行（anticipatory）**。
- **定义 207（VSC 视觉伺服编译器）**：s = f(q) ∈ ℝ^{2k}（或 2k+1 含深度），L_s = ∂s/∂q；q̇ = −λ_t L̂_s⁺ e，e = s − s*_σ；各向异性阻抗 K_t = K_⊥ + (K_∥ − K_⊥)·êêᵀ，K_∥ = K_0 + κ·sat(‖e‖/e_0)；力/速度经 ERTC 限幅。
- **定义 208（鲁棒收敛条件）**：设深度相对误差 ‖ΔL_s‖/‖L_s‖ ≤ ρ_d，时延 τ_d，特征界 ‖L_s‖ ≤ L_max。若 λ_t < 1/(L_max τ_d) 且 ρ_d < 1/2，则 ‖e_{t+1}‖ ≤ (1 − λ_t(1−ρ_d)/(1+ρ_d))‖e_t‖ + O(τ_d)，即**局部指数收敛到残差球**。
- **定义 209（特征丢失回退）**：可见特征数 k_vis < k_min 或跟踪残差 > e_loss 时，VSC 切换到 PBVS（位姿估计）或阻抗保持 K_t = K_hold；回退期间 ρ_servo 记为 invalid，禁止不可逆技能。
- **定义 210（置信门控执行/最优停止）**：每语义步选择 a ∈ {wait, act_reversible, act_irreversible, repair}；代价 J(a) = E[risk|a,c] + β·latency(a)；在单调似然比与校准置信下，最优策略为**双阈值策略**（c < τ_low → repair；τ_low ≤ c < τ_high → wait/仅可逆；c ≥ τ_high → act）。
- **定义 211（伺服残差交叉校验）**：r_t = ‖e_t‖ 的滑动统计；若 r_t 持续 > e_align 而语音置信高，则判定「语义-物理失配」概率高，触发 repair/澄清；若 r_t 低但意图后验熵高，则判定「高精度错误目标」风险。
- **定义 212（AIC-SV 时序认证）**：在 LIRO 干扰集 ℰ 上并集语音扰动（噪声/混响/串音）与伺服扰动（深度/时延/遮挡）：ρ_sv = min_{η∈ℰ_sv} min_t margin_VSC(t, η)；J_sv = (ρ_sv, speech_calib, servo_conv, align_hash)。
- **定义 213（OCB-Stream 流式预算老虎机）**：臂 = {listen, wait, act, repair} × {VSC-IBVS, VSC-PBVS, hold} × {ASR 全量/蒸馏}，K=24（聚合 12）；奖励 = task_progress − κ_compute·cost − κ_risk·𝟙[误动作] − κ_lat·latency。
- **定义 214（J_vista 扩展证书）**：J_vista = (J_liro, speech_align_hash, c_intent, calib_ver, servo_conv_cert, residual_stat, kws_veto)；Valid ⇔ Valid(J_liro) ∧ c_intent ≥ τ_high（不可逆时）∧ servo_conv_cert ∧ 无 veto ∧ 对齐单调一致。
- **定义 215（修复策略）**：Repair ∈ {repeat_back, clarify_slot, backtrack_skill, safe_hold}；由失配类型（低置信/槽位歧义/否定冲突/伺服残差）映射，并记录到 SSB 供后续语言先验更新。
- **定义 216（预执行安全门控）**：预执行仅允许在可逆技能子集 Σ_rev 上，且其期望特征 s* 与所有未消解假设的 s* 的**最小距离** ≥ d_safe；否则等待消歧。

## 2. 关键算法骨架（完整伪代码见产物区）

```python
# 语义时间：流式语音 → 部分意图格 → 单调对齐 → 对齐感知规划
lattice = sst.stream(audio_chunk)                    # 部分假设 (ℓ, π, c)
if sst.kws_veto: enter_safe_hold()                   # 安全词硬否决

tau, theta = csp_a.plan(goal=lattice.best, A=A, c=lattice.conf)
# 技能时间：把后置条件编译为期望图像特征轨迹
s_star_seq = [vsc.compile_reference(skill) for skill in tau]
# 物理时间：视觉伺服闭环 + 残差交叉校验
q_dot, K = vsc.servo_step(s, s_star_seq[0], depth_hat, dt)
if vsc.feature_lost: q_dot, K = vsc.fallback_pbvs_or_hold()
if residual_monitor.misaligned(): repair = repair_policy(lattice, residual)

J_vista = build_j_vista(J_liro, speech_align_hash, c_intent,
                        servo_conv_cert, residual_stat)
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 5（单调对齐的边界误差）**：若 token 错误率 ≤ ε_tok、每技能平均 token 数 ≥ n_min，且 A 单调，则技能边界时间误差 ≤ ε_tok·T_tok/H + O(1/n_min)；单调约束把「跨技能乱序对齐」概率压到 0，避免灾难性错段。
- **引理 6（VSC 鲁棒收敛）**：定义 208 条件下，误差递推 ‖e_{t+1}‖ ≤ α‖e_t‖ + cτ_d，α = 1 − λ(1−ρ_d)/(1+ρ_d) < 1；故存在残差球 B(0, cτ_d/(1−α))，且 α 随时延增大而趋近 1——**时延是收敛速度的硬约束，不是可忽略项**。
- **定理 4（置信门控安全性）**：若置信度经温度标定满足 ECE ≤ ε_cal，且风险对置信单调，则双阈值策略下「在错误意图上执行不可逆技能」的概率 ≤ α_speech + ε_cal + δ_thr。
- **定理 5（VISTA 端到端安全）**：若 Valid(J_vista)，则 P[任务安全] ≥ 1 − α_dir − α_speech − α_servo − δ_cert（各分量分别来自 LIRO 干扰认证、语音覆盖、伺服收敛残差、采样认证）。**安全是四张证书的交集，而不是任一模块的自证**。
- **命题（预执行时延收益）**：对可逆技能，预执行把期望等待时延降低 Δ_wait = E[剩余语音时长]，风险增量被 d_safe 门控限制在 α_pre；存在收益/风险帕累托前沿。
- **命题（残差可检测性）**：若不同目标的图像特征可分性 ≥ d_feat，则错误对齐导致的持续残差 r_t ≥ d_feat/2 可被检测；但若目标特征几乎重合（透明/同色/对称），检测退化为随机猜测——这是残差交叉校验的盲区。

## 5. 本轮最大风险

**一句话**：语音识别的「流畅但错误」与视觉伺服的「高精度收敛」会相乘成**自信地精确做错**——流式预执行在否定/更正从句到达前就动作，或同音/串音把 token 对齐到错误技能，而伺服残差在收敛到错误目标后反而很小，使残差交叉校验失效；VISTA 的核心单点假设是「token-skill 对齐在语义上忠实」，一旦它错，所有下游证书都只是在为错误意图背书。

## 2. 形式化定义（完整版）

**定义 201（VISTA 闭环）** VISTA 是 LIRO 的「语言流式化 × 执行视觉闭环化」升级，挂在第 63 轮「语义流 ∘ 实时流」骨架上。三层时间严格隔离：
- **语义时间**（秒级，事件驱动）：SST 流式解码 → 单调对齐 → CSP-A 规划 → CGE 门控；
- **技能时间**（百毫秒级）：USL-T 编译期望特征轨迹 s*_σ 与时长先验；
- **物理时间**（毫秒级，1–10kHz）：VSC 视觉伺服闭环 + ERTC 限幅 + SRM 残差统计。
不变式：**学习/规划/认证只发生在语义时间低频线程；物理时间只做前向控制与残差计算，零学习写操作**（继承 A75）。

**定义 202（SST 流式语音意图转录）** 输入流式声学块 A_{t:t+Δ}，输出部分意图格。形式化：
- 帧编码：h_{1:T} = E_ac(A_{1:T})，E_ac 冻结（自监督预训练，部署不更新）；
- 联合解码：以 RNN-T 风格在 V_word × V_skill 上做 beam search，保留 B=8 条假设，每条假设携带 log p(ℓ|A)、词级时间戳与 CTC 对齐后验；
- 置信校准：c = σ_temp(log p / T_cal + b_cal)，T_cal, b_cal 由验证集温度标定得到；
- 安全通道：KWS(A) → k_t，命中「停/别动/不对/松手」即 veto=True，绕过 beam 直接触发 safe_hold。
输出 ℒ_t = {(ℓ^(b), π^(b), c^(b))}_{b=1}^B，供对齐与门控。

**定义 203（token-skill 单调对齐矩阵）** 给定 token 序列 x_{1:T_tok} 与技能序列 τ=[σ_1,...,σ_H]，A ∈ {0,1}^{T_tok×H}，约束：
1. 每行 Σ_i A_{j,i} ≤ 1（token 可对齐到技能或为填充/虚词）；
2. 每列非零元连续（一个技能对应连续 token 段）；
3. 列序单调：若 j<j' 且 A_{j,i}=A_{j',i'}=1 则 i ≤ i'。
对齐代价 C(A) = Σ_j (1 − p_align(x_j, σ_{a(j)})) + λ_mon·𝟙[违反单调]，其中 p_align 由 token 模板与技能语义嵌入的点积给出。CSP-A 要求 min_A C(A) ≤ ε_align。

**定义 204（语义-物理时序 warp）** 由对齐边界 b_i 与技能时长先验 D_i 构造单调分段线性映射 W：
W(t) = Σ_i 1[t∈b_i]·(t − t_i^start)/(t_i^end − t_i^start)·D_i + W(t_i^start)。
W 把 token 时间映射到物理执行时间，保证「说到第 i 个技能时，伺服已推进到第 i 段」。W 单调、可审计，写入 J_vista 的 align_hash。

**定义 205（USL-T 时序技能模板）** 每技能 σ^T = (σ, Tok_σ, sig_σ)：
- Tok_σ：触发词、同义词、否定模式（如 grasp: {"拿","抓","pick","grab"}，negation: {"别","不要","don't"}）；
- sig_σ：期望图像特征轨迹模板 s*_σ(t)（关键帧 + 插值）、时长先验 D_σ、特征可见性要求 k_min；
- 复用第 63 轮 pre/eff/π_σ/cost/𝒫_feas，不改变技能语义，只增加「可被语言对齐的时序接口」。

**定义 206（CSP-A 对齐感知规划）** 在 CSP 基础上增加三类约束：
1. **对齐可行**：∃A 使 C(A) ≤ ε_align 且 A 与 τ 一致（定义 203）；
2. **不可逆门控**：对 σ ∈ Σ_irrev（insert/release/hand-over/throw），要求 c_intent ≥ τ_high 且否定模式未命中；否则该技能不可进入执行序列，只能规划为候选；
3. **可逆预执行**：对 σ ∈ Σ_rev（reach/approach/orient），允许在 c_intent ≥ τ_low 时预执行，但需满足定义 216 的 d_safe 门控。
目标：min_τ Σ cost(σ_i) + skill_switch_penalty + λ_gate·𝟙[门控未满足]。

**定义 207（VSC 视觉伺服编译器）** 技能 σ 的 eff 后置条件被编译为期望特征 s*_σ（如「夹爪对齐目标中心」→ 目标投影中心 + 夹爪指间中点特征重合）。控制律：
q̇ = −λ_t·L̂_s⁺·e，e = s − s*_σ，
其中 L̂_s 由解析模型或 Broyden 在线更新：L̂_{s,t+1} = L̂_{s,t} + η_b·(Δs − L̂_{s,t}Δq)Δqᵀ/(‖Δq‖²+ε)。
各向异性阻抗：K_t = K_⊥I + (K_∥−K_⊥)êêᵀ，K_∥ = K_0 + κ·sat(‖e‖/e_0, 0, 1)，K_⊥ = K_0·(1−β_f)。沿误差方向刚度大以快速纠偏，正交方向柔顺以容忍标定误差。输出 q̇, K_t 经 ERTC 的速度/力限幅后派发。

**定义 208（鲁棒收敛条件）** 设深度估计相对误差 ρ_d = ‖ΔL_s‖/‖L_s‖，控制时延 τ_d（相机曝光 + 传输 + 计算），‖L_s‖ ≤ L_max。采用常速预测补偿 ŝ_{t+τ_d} = s_t + τ_d·ṡ_t。若
λ_t < 1/(L_max·τ_d) 且 ρ_d < 1/2，
则误差递推
‖e_{t+1}‖ ≤ (1 − λ_t(1−ρ_d)/(1+ρ_d))‖e_t‖ + c·τ_d + O(ρ_d²)
成立，即误差局部指数收敛到半径 R = (cτ_d + O(ρ_d²))/(λ_t(1−ρ_d)/(1+ρ_d)) 的残差球。**时延越大，允许增益越小，收敛越慢——时延是硬约束**。

**定义 209（特征丢失回退）** 当可见特征数 k_vis < k_min 或跟踪残差 > e_loss 时：
- 若深度可信（点云/双目有效），切换 PBVS：由位姿误差 e_pose 生成 q̇ = −λ_p·e_pose；
- 若深度也不可信，切换阻抗保持 K_t = K_hold，q̇=0，等待特征恢复；
- 回退期间 servo_conv_cert=False，禁止所有不可逆技能，J_vista 标记 servo_degraded=True。

**定义 210（置信门控执行/最优停止）** 每语义步在 a ∈ {wait, act_reversible, act_irreversible, repair} 中选择。令意图后验为 p(ℓ|A_{1:t})，风险函数 R(a,ℓ) 对 ℓ 与真实意图的偏差单调，延迟代价 β·lat(a)。在单调似然比（MLR）与校准置信下，最优策略为双阈值：
- c < τ_low：repair（信息增益最高，避免在低置信上动作）；
- τ_low ≤ c < τ_high：wait 或仅 act_reversible（预执行可逆技能）；
- c ≥ τ_high 且无 veto：act_irreversible。
阈值由验证集上最小化期望风险标定，写入 calib_ver。

**定义 211（伺服残差交叉校验 SRM）** 维护残差滑窗统计 μ_r, σ_r 与意图熵 H_t。判定规则：
- **语义-物理失配**：μ_r > e_align 且 c_intent ≥ τ_high 且 H_t 低 → 高置信但伺服追不上，说明 s* 指向了不可达/错误特征 → repair（clarify_slot）；
- **高精度错误目标**：μ_r < e_track（伺服收敛良好）但 H_t 高 → 伺服收敛到某个目标，但意图本身未定 → 禁止不可逆，等待消歧；
- **正常**：μ_r < e_track 且 H_t 低 → 放行。
SRM 是把「语音对齐错误」投影到「物理残差空间」的可观测代理。

**定义 212（AIC-SV 时序认证）** 扩展第 63 轮干扰集：
ℰ_sv = ℰ_LIRO ∪ ℰ_speech ∪ ℰ_servo，
ℰ_speech = {噪声 SNR ≥ 5dB, 混响 RT60 ≤ 0.8s, 串音比例 ≤ 30%, 语速 0.5×–2×}，
ℰ_servo = {深度相对误差 ≤ ρ_d, 时延 ≤ τ_d, 遮挡比例 ≤ 40%, 特征丢失时长 ≤ 0.5s}。
ρ_sv(τ) = min_{η∈ℰ_sv} min_{t∈[0,H]} margin_VSC(π_σt, s*_σt, η)，采样 n_cert=64（四类各 16）。J_sv = (ρ_sv, ℰ_spec, speech_calib, servo_conv_cert, align_hash, cert_hash)。

**定义 213（OCB-Stream 流式预算老虎机）** 臂 = {listen, wait, act, repair} × {VSC-IBVS, VSC-PBVS, hold} × {ASR-full, ASR-distill}，原始 24 臂聚合为 K=12（模式合并）。每语义步 EXP3 采样，奖励：
r_t = progress_t − κ_compute·cost_t − κ_risk·𝟙[误动作] − κ_lat·latency_t，
归一化到 [0,1]。硬降级规则继承第 63 轮 PCE+++++：算力不足时不得选 ASR-full/IBVS。

**定义 214（J_vista 扩展证书）** J_vista = (J_liro, speech_align_hash, c_intent, calib_ver, servo_conv_cert, residual_stat, kws_veto)。
Valid(J_vista) ⇔
1. Valid(J_liro)；
2. 不可逆技能：c_intent ≥ τ_high 且 kws_veto=False；
3. servo_conv_cert=True（ρ_sv ≥ 0 且残差球在安全域内）；
4. speech_align_hash 对应的 A 单调一致，且与执行 τ 一致；
5. calib_ver 在有效期内（ECE 复核通过）。
审计链：speech_align_hash → token 时间戳与 A；servo_conv_cert → 深度/时延/增益记录；residual_stat → 实际残差滑窗。

**定义 215（修复策略 RPR）** Repair 由 SRM 与 SST 的联合状态映射：
| 失配类型 | 判据 | 修复动作 |
|---|---|---|
| 低置信 | c < τ_low | repeat_back("请再说一遍") |
| 槽位歧义 | 多假设共享技能但参数不同 | clarify_slot("是红色还是蓝色？") |
| 否定冲突 | 否定 token 与已执行/待执行技能冲突 | backtrack_skill（回退最近可逆技能） |
| 伺服失配 | μ_r > e_align 且高置信 | clarify_slot 或 safe_hold |
| 安全词 | kws_veto | safe_hold（立即） |
所有修复事件写入 SSB 的 dyn_annot，供后续语言先验与场景签名更新。

**定义 216（预执行安全门控）** 预执行仅允许 σ ∈ Σ_rev，且
min_{ℓ'∈ℒ_t, ℓ'未消解} ‖s*_σ(ℓ) − s*_σ(ℓ')‖ ≥ d_safe
即：当前假设与所有仍可能假设的期望特征至少相距 d_safe。若不足，则只执行「与所有假设共同的前缀动作」（如先抬升、先张开夹爪），不执行有方向性的接近。该门控把预执行风险限制在可逆、可撤销、方向不敏感的动作集内。

### IP-204 SST（流式语音意图转录）

```python
class StreamingSpeechTransducer:
    """冻结自监督声学编码 + RNN-T/CTC 联合解码 + 温度标定 + 安全词否决。"""
    def __init__(self, E_ac, joint_decoder, kws, calibrator, beam=8, T_cal=1.7):
        self.E_ac = E_ac                       # 冻结 wav2vec2 式编码器
        self.decoder = joint_decoder           # V_word × V_skill 联合 RNN-T
        self.kws = kws                         # 高召回安全词检测
        self.calibrator = calibrator           # 温度/向量标定
        self.beam, self.T_cal = beam, T_cal
        self.state = None

    def stream(self, audio_chunk):
        h = self.E_ac(audio_chunk)             # 帧表征
        hyps = self.decoder.beam_search(h, self.state, beam=self.beam)
        self.state = self.decoder.advance(self.state, h)
        lattice = []
        for hyp in hyps:
            c = self.calibrator.calibrate(hyp.logp, hyp.length, T=self.T_cal)
            lattice.append(Hypothesis(tokens=hyp.tokens, skills=hyp.skills,
                                      timestamps=hyp.timestamps,
                                      align_path=hyp.align_path, conf=c))
        veto = self.kws.detect(audio_chunk)    # "停/别动/不对/松手"
        return IntentLattice(hypotheses=lattice, veto=veto,
                             entropy=entropy([h.conf for h in lattice]))
```

```python
class AlignmentAwarePlanner(CSPPlanner):
    def plan(self, goal, x_prime, phi_hat, r, lattice, budget=100.0):
        # 1) 对每个候选技能序列做单调对齐代价评估
        feasible = self.usl.get_feasible(phi_hat, r, x_prime)
        # 2) 高层 A*，边权含对齐代价与门控惩罚
        def edge_cost(prev, nxt, seq):
            c = nxt.cost + (1.0 if prev and prev.name != nxt.name else 0.0)
            c += self._align_cost(lattice.tokens, seq + [nxt])
            if nxt.name in IRREVERSIBLE and lattice.conf < TAU_HIGH:
                c += GATE_PENALTY                # 不可逆技能高惩罚
            return c
        tau = self._a_star(feasible, goal, edge_cost, budget)
        # 3) 预执行门控：只允许可逆且与未消解假设特征可分
        tau_exec = []
        for skill in tau:
            if skill.name in IRREVERSIBLE:
                break                            # 遇到不可逆即停，等待置信
            if self._pre_exec_safe(skill, lattice, d_safe=0.2):
                tau_exec.append(skill)
            else:
                break
        return tau, tau_exec, self._bind_params(tau_exec, x_prime, phi_hat, r)

    def _align_cost(self, tokens, seq):
        A, C = monotone_align(tokens, [s.Tok for s in seq])
        return C
```

### IP-207 VSC（视觉伺服编译器）

```python
class VisualServoCompiler:
    """IBVS + Broyden 深度自适应 + 各向异性阻抗 + 时延预测补偿。"""
    def __init__(self, K0=200.0, kappa=1.5, beta_f=0.5, L_max=10.0,
                 tau_delay=0.06, eta_b=0.05):
        self.K0, self.kappa, self.beta_f = K0, kappa, beta_f
        self.L_max, self.tau_delay, self.eta_b = L_max, tau_delay, eta_b
        self.L_hat = None
        self.prev_s, self.prev_q = None, None

    def robust_gain(self, L_hat):
        # 稳定域：lambda < 1/(L_max * tau_delay)
        lam_max = 1.0 / (self.L_max * self.tau_delay)
        return min(0.8 * lam_max, 1.0)          # 保守留 20% 裕度

    def servo_step(self, s, s_star, depth_hat, q, dt):
        e = s - s_star
        L = self.interaction_matrix(s, depth_hat)      # 解析/数值
        if self.L_hat is None:
            self.L_hat = L.copy()
        else:
            # Broyden 在线更新（对深度/标定误差自适应）
            if self.prev_s is not None:
                ds = s - self.prev_s
                dq = q - self.prev_q
                denom = float(dq.T @ dq) + 1e-6
                self.L_hat += self.eta_b * ((ds - self.L_hat @ dq) @ dq.T) / denom
        lam = self.robust_gain(self.L_hat)
        q_dot = -lam * np.linalg.pinv(self.L_hat) @ e
        K = self.anisotropic_stiffness(e)
        self.prev_s, self.prev_q = s.copy(), q.copy()
        return q_dot, K

    def anisotropic_stiffness(self, e):
        norm = np.linalg.norm(e) + 1e-9
        e_hat = e / norm
        K_par = self.K0 + self.kappa * min(norm / E0, 1.0)
        K_perp = self.K0 * (1.0 - self.beta_f)
        return K_perp * np.eye(len(e)) + (K_par - K_perp) * np.outer(e_hat, e_hat)

    def feature_lost(self, k_vis, track_res):
        return k_vis < K_MIN or track_res > E_LOSS

    def fallback_pbvs_or_hold(self, pose_err=None, depth_ok=True):
        if depth_ok and pose_err is not None:
            return -LAMBDA_P * pose_err, K_HOLD        # PBVS
        return np.zeros_like(self.prev_q), K_HOLD      # 阻抗保持
```

### IP-208 SRM（伺服残差交叉校验）

```python
class ServoResidualMonitor:
    """把语音对齐错误投影到物理残差空间。"""
    def __init__(self, window=30, e_track=0.02, e_align=0.08):
        self.buf = deque(maxlen=window)
        self.e_track, self.e_align = e_track, e_align

    def update(self, residual, c_intent, intent_entropy):
        self.buf.append(residual)
        mu = float(np.mean(self.buf))
        sigma = float(np.std(self.buf))
        if mu > self.e_align and c_intent >= TAU_HIGH and intent_entropy < H_LOW:
```

### IP-212 OCB-Stream（流式预算老虎机）

```python
class StreamingBudgetBandit:
    ARMS = [(a, v, m) for a in ('listen', 'wait', 'act', 'repair')
                      for v in ('ibvs', 'pbvs', 'hold')
                      for m in ('full', 'distill')]   # 24 → 聚合 12

    def __init__(self, K=12, eta=0.3):
        self.w = np.ones(K) / K
        self.eta, self.K = eta, K

    def update(self, arm_idx, progress, compute_cost, latency, misaction):
        reward = progress - KAPPA_C * compute_cost - KAPPA_L * latency \
                 - KAPPA_R * float(misaction)
        reward = float(np.clip(reward, 0.0, 1.0))
        r_hat = reward / max(self.w[arm_idx], 1e-6) / self.K
        self.w[arm_idx] *= np.exp(self.eta * r_hat / self.K)
        self.w /= self.w.sum()
```

## 4. 推导

**引理 5（单调对齐的边界误差）** 设 token 序列长度为 T_tok、技能数 H，token 错误率为 ε_tok（替换/删除/插入混合），每技能平均 token 数 n = T_tok/H。单调约束（定义 203 条件 3）排除了跨技能的乱序对齐，因此每个技能边界只能因「局部 token 错误」偏移。单个边界的期望偏移 ≤ ε_tok·n（错误 token 造成的边界漂移上界），归一化到技能时长后为 ε_tok·T_tok/H。由马尔可夫不等式，P[|Δt_i| > δ] ≤ ε_tok·T_tok/(Hδ)。取 H 个边界做 union bound，最大边界误差以高概率 ≤ ε_tok·T_tok/H + O(√(log H))。**单调约束的作用不是降低 ε_tok，而是把「整段技能错位」这类灾难性错误的概率压为 0**。∎

**引理 6（VSC 鲁棒收敛）** 真实系统 s_{t+1} = s_t + L_s(q_t)Δq_t + w_t，其中 w_t 含深度误差与噪声。控制器使用 L̂_s = L_s + ΔL_s，‖ΔL_s‖/‖L_s‖ ≤ ρ_d。在无时延时，e_{t+1} = (I − λL_s L̂_s⁺)e_t + w_t，故 ‖e_{t+1}‖ ≤ |1 − λ(1−ρ_d)/(1+ρ_d)|·‖e_t‖ + ‖w_t‖。引入时延 τ_d 后，实际作用的是 e_{t−τ_d}，常速预测补偿把有效误差降为 e_t + O(τ_d)。由 λ < 1/(L_max τ_d) 保证 λL_sτ_d < 1，离散系统特征根在单位圆内。合并得定义 208 的递推，α = 1 − λ(1−ρ_d)/(1+ρ_d) ∈ (0,1)。残差球半径 R = (cτ_d + O(ρ_d²))/(1−α)。**当 τ_d → 1/(λL_max) 时 α → 1，收敛退化为临界稳定——这解释了为什么高时延下必须降增益，也解释了「看起来在动但追不上」的残差来源**。∎

**定理 4（置信门控安全性）** 设真实意图为 ℓ*，系统在时刻 t 的校准置信 c = c(ℓ_best)。温度标定保证 |P[ℓ_best=ℓ* | c] − c| ≤ ε_cal（ECE 界）。双阈值策略在 c < τ_low 时 repair（不执行不可逆），在 τ_low ≤ c < τ_high 时仅可逆动作，在 c ≥ τ_high 时执行不可逆。错误不可逆执行只可能发生在 c ≥ τ_high 且 ℓ_best ≠ ℓ*。由校准，
P[ℓ_best ≠ ℓ* | c ≥ τ_high] ≤ P[ℓ_best ≠ ℓ* | c] evaluated at c ≥ τ_high ≤ (1 − τ_high) + ε_cal。
对语音识别错误率 α_speech 做全概率展开，得总错误执行概率 ≤ α_speech + (1 − τ_high) + ε_cal + δ_thr，其中 δ_thr 为阈值估计的有限样本误差。**门控不能消除语音错误，只能把「错误 + 不可逆」的联合概率压到可接受水平**。∎

**定理 5（VISTA 端到端安全）** 设：
- (B1) LIRO 证书有效 ⇒ P[物理干扰下安全] ≥ 1 − α_dir（第 63 轮定理 3）；
- (B2) 语音覆盖 ⇒ P[意图在假设集内且门控正确] ≥ 1 − α_speech − ε_cal（定理 4）；
- (B3) 伺服收敛 ⇒ 在 ℰ_servo 下残差球 R 落在安全域内，P[伺服安全] ≥ 1 − α_servo（引理 6 + 定义 212 采样认证）；
- (B4) 对齐单调一致 ⇒ 技能段与 token 段不交叉（引理 5）。
由 union bound，P[任务安全] ≥ 1 − α_dir − α_speech − α_servo − ε_cal − δ_cert。Valid(J_vista) 要求四张证书同时成立，故其安全概率下界即上式。**关键含义：任一模块单独「自证安全」都不够，VISTA 的安全性来自四张证书的交集，短板决定整体**。∎

**命题（预执行时延收益）** 设人类说完整指令需 T_speech，可逆技能预执行可在前 Δ 秒开始，则期望等待时延降低 Δ_wait = E[min(Δ, T_speech)]。风险增量来自「预执行方向与最终意图不符」，但定义 216 要求 s* 与所有未消解假设的最小距离 ≥ d_safe，因此误预执行只发生在特征距离 < d_safe 的歧义场景，其概率被 d_safe 与特征可分性约束。存在帕累托前沿 Δ_wait(d_safe) 与 Risk(d_safe) 的权衡；d_safe 是唯一可调的安全旋钮。∎

**命题（残差可检测性）** 设错误目标与正确目标的图像特征距离为 d_feat。若伺服收敛到错误目标，残差 e 会稳定在 0 附近（相对于错误 s*），但相对于正确 s* 的偏差为 d_feat。SRM 观测的是「到当前 s*」的残差，因此**无法直接看到 d_feat**；它只能通过「高置信 + 低残差 + 后续语音与已执行动作冲突」间接发现。若 d_feat < e_track（目标特征几乎重合，如透明/同色/对称物体），则残差完全不可分，SRM 退化为随机猜测。**这是残差交叉校验的结构性盲区，必须靠多假设保持 + 主动探测（如轻微移动改变视角）弥补**。∎

## 7. 已知风险

**一句话**：语音识别的「流畅但错误」与视觉伺服的「高精度收敛」会相乘成**自信地精确做错**——流式预执行在否定/更正从句到达前就动作，或同音/串音把 token 对齐到错误技能，而伺服残差在收敛到错误目标后反而很小，使残差交叉校验失效；VISTA 的核心单点假设（A84）是「token-skill 对齐在语义上忠实」，一旦它错，所有下游证书都只是在为错误意图背书。

**次级风险与缓解**：
1. **同音/否定漏检**：ASR 对「别/不要/don't」的删除错误最危险 → 否定词独立 KWS 通道 + 否定后强制 re-confirm + 否定作用域解析（否定词绑定到最近技能而非整句）。
2. **流式预执行与更正冲突**：用户说"拿红的——不对，蓝的"，预执行已向红移动 → 只预执行可逆且方向不敏感动作（d_safe 门控），并保证回退时间 < 200ms；回退代价写入 OCB-Stream 奖励。
3. **SRM 结构性盲区**：透明/同色/对称目标残差不可分 → 主动探测（轻微视角变化、多假设保持、触觉确认）作为补充观测；无法消歧时强制 safe_hold。
4. **VSC 时延失稳**：真实系统时延抖动 → 在线估计 τ_d（互相关），λ_t 随时延自适应降增益；超稳定域则切 PBVS/hold 并标记 servo_degraded。
5. **对齐 DP 实时性**：长指令 H 大时 O(T_tok·H) 膨胀 → 分块增量对齐 + 前缀剪枝；超时则只对齐前 H_max 个技能（receding horizon）。
6. **多模态时序漂移**：音频、相机、本体时钟不同步 → 统一时间戳 + 硬件触发；warp W 显式记录时钟偏移，J_vista 审计可追溯。
7. **语言先验污染**：修复事件写入 SSB 后可能过拟合个别用户口音 → 说话人条件化先验 + 定期回滚 + 干净样本回放（继承 DIR 的经验回放）。
8. **证书组合的短板效应**：四证书交集使任一模块失败即整体失效 → 显式降级等级（full / reversible-only / safe_hold），降级状态本身写入 J_vista，避免「静默降级」。
