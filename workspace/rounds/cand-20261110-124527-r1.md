# 第 44 轮（本会话灵感循环第 1 轮 · 承接第 43 轮 v20） · Gazebo × 评测指标：把「独立仿真神谕」与「指标契约」一起做成可认证闭环（四层架构 v9）

> 承接第 43 轮 v20。v20 自陈最大风险是「共形只保边际覆盖」与「多用户契约空集」。但它在暗处还压着两个更根本的单点假设：**(H3) 认证只在单一仿真器（Isaac Sim / PhysX）内完成**——所谓「0 违例」很可能是 **simulator-specific 过拟合**，换一套物理后端就崩；**(H4) 评测指标是给定的、无偏的、不可博弈的常数门槛**——然而指标本身有方差、有分层偏差、可被 Goodhart 操纵。用「点估计 + 平均」去卡 (H3) 的仿真过拟合，等于用一把会弯的尺子去量一根会缩的棍。本轮灵感词精确命中这两个假设：**Gazebo** 提供与 PhysX 不同物理后端的**独立神谕**，迫使我们把「仿真到现实」从信仰变成可测的**差分间隙**；**评测指标** 迫使我们把指标从常数门槛提升为**带统计下界、防博弈、可预注册复现的契约**。两者耦合处（用可博弈的指标去跑独立神谕）才是本轮真正的新问题：**你可能用一套自欺的评测，去认证一个自欺的证书**。

## 0. 直觉与动机

**灵感 1（Gazebo → 独立神谕，而非第二个优化目标）**：直觉上，在一台仿真器里跑出「0 违例」就像在自家考场考满分——只能说明你会做这套卷子。Gazebo 的价值不是「再多跑一遍」，而是它的物理后端可以与 Isaac 的 PhysX **不同**（ODE / DART / Bullet），接触模型、积分器、传感器噪声模型都不同；于是同一控制器、同一场景、同一随机种子在两个仿真里跑，**一致是必要条件，不一致才是有效信号**。尤其关键：若控制器在 A 通过、在 B 违例，就抓到了 A 的过拟合；若轨迹本身先分叉（哪怕尚未违例），这是比离散违例更早的预警。**必须把 Gazebo 当对手而不是靶子**——一旦把 Gazebo 当优化目标，它就从神谕退化成第三个可被过拟合的仿真器。

**灵感 2（评测指标 → 指标即契约，点估计即谎言）**：直觉上，「违例 0 起、成功率 ≥95%」这类门槛看似客观，实则藏了三重作弊面：**(a) 统计**——只用点估计卡阈值，方差一大就能靠运气过；**(b) 分层**——平均值达标不代表每个用户/场景层达标（辛普森悖论），恰好绕过 v20 的「边际覆盖」软肋；**(c) 元层**——你可以在看到结果后悄悄换分层、换种子、放宽 α/δ 让自己通过（Goodhart 的元层变体）。因此把指标 M 升格为**契约**：带**下置信界 LCB**、**最差层门槛**、**孪生反指标**（靠作弊提升主指标必然拉坏它）、以及**实验前哈希预注册**的封存账本。一句话：**指标不是尺子，是要被认证的量具**。

**灵感 3（耦合 → 差分评测本身也必须被评测治理）**：跨仿真差分如果只报「gap ≤ δ」的点估计，同样可被操纵：挑有利场景、挑有利种子、事后调 δ。于是「独立神谕」必须由「指标契约」来跑：场景层预注册、gap 用 LCB、神谕独立性用账本评分、封存 holdout 只解封一次。反过来，指标契约也要在**两个独立物理后端**上验证其可复现性与稳健性——否则你只是把指标过拟合到了 Isaac。二者互为对方的验证器，构成**评测飞轮**。

**耦合升级**：GDO（差分神谕）把 Isaac↔Gazebo 变成可测间隙与独立性账本；MCG（指标治理）把 E87–E104 的每个门槛变成带 LCB/分层/孪生/预注册的契约；TCL（迁移证书）把「gap 小」翻译成「在有效包络内可迁移、包络外一律作废」。四层架构由 v8 的「仿真-检索-边缘 + 人格 + 并发」升级为 v9 的「**双神谕差分验证 + 指标契约治理 + 迁移包络**」闭环。

## 1. 形式化定义（增量：定义 44–50）

**定义 44（差分 soundness 与轨迹分叉）**：固定证书 c、控制器 π、场景集合 D（含随机种子）。在仿真 S 中记 Viol_S(s,c) ∈ [0,1] 为违例幅度、τ_S(s) 为轨迹。定义
- **差分间隙**：G_{A,B}(c) = sup_{s∈D} [Viol_B(s,c) − Viol_A(s,c)]_+；
- **轨迹分叉**：D_{A,B}(s) = d_H(τ_A(s), τ_B(s))（Hausdorff / Wasserstein 距离）。
称 c **（δ, δ_traj, α）差分稳健**，若 P_{s~D}[Viol_B − Viol_A > δ] ≤ α 且 P_{s~D}[D_{A,B}(s) > δ_traj] ≤ α。**命题**：若 c 在 A、B 中均无违例且轨迹分叉 ≤ δ_traj，则「A 的 0 违例」不再能单独作为部署证据，它只在**两神谕一致**时被采信。**方向性**：差分稳健是部署的**必要非充分**条件（两个仿真可能同错），这正是定义 45 存在的理由。

**定义 45（神谕独立性账本与共失败相关）**：账本 L = (引擎_A, 引擎_B, 接触模型, 积分器, 传感器噪声模型, 执行器模型, 时间步)。**独立性评分** ρ_L ∈ [0,1] 由各维度差异加权；同一引擎（如都用 PhysX）则 ρ_L = 0。用历史失败样本估计**共失败相关** ρ_fail = corr(1[Viol_A>0], 1[Viol_B>0])。**规则**：仅当 ρ_L ≥ ρ_min 且 ρ_fail ≤ ρ_max 时差分结果才可采信；否则标记「伪独立」，差分通过不构成迁移证据（只能算同仿真复测）。**落地建议**：Gazebo 端固定用 DART 或 Bullet 而非与 Isaac 同源的 PhysX，以拉高 ρ_L。

**定义 46（指标契约与可容许性）**：指标契约 M = (Ω, μ, P, Ê, L, G, θ, κ, V, h)：Ω 为事件代数、μ 为场景测度、P 为测量协议（采样器/种子/时程）、Ê 为估计量、L 为下置信界程序、G 为分层、θ 为各层门槛、κ 为防博弈类、V 为版本、h 为预注册哈希。M **可容许**当且仅当：
1. **可测性**：目标事件 ∈ Ω，Ê 无偏或有已知偏差界；
2. **统计有效性**：闸门只用 LCB（置信水平 1−β），不用点估计；
3. **防博弈性**：存在孪生指标 M⊥，使「只提升 M 而不提升真实目标」的改动必被 M⊥ 判负（定义 47）；
4. **可复现性**：给定 h，同一协议重跑结果逐位可复现（或差异落在预注册容差内）。

**定义 47（Goodhart 证书与孪生阻力）**：设 S 为被优化代理、T 为真实目标、Q 为可达改动集。**Goodhart 见证** w = (s,q) 满足 ΔS(q) ≥ ε 且 ΔT(q) ≤ 0。称指标对 (M, M⊥) **ε-抗博弈**，若 ∀q∈Q：ΔS(q) ≥ ε ⟹ (ΔT(q) > 0 ∨ ΔM⊥(q) < −γ)。即任何能骗过主指标的大改动，要么真实变好，要么被孪生指标当场揭穿。**推论**：只有主指标而没有孪生指标的闸门，在定义 47 意义下默认**不可容许**。

**定义 48（预注册与封存账本，元层防博弈）**：协议 π = (Ω, P, G, θ, α, β, δ) 在实验前计算 h = H(canonical(π)) 并提交（commit）。场景空间按 h 划分为**开发账本 O** 与**封存账本 H\***（H\* 提交时只公开承诺、内容不可见）。规则：
1. **冻结**：任何在看到 O 结果后对 π 的修改都使 h 失效，必须升版本重新提交；
2. **单次解封**：H\* 仅在所有指标契约冻结后解封一次，解封后的结果不得用于再调参（否则 H\* 降级为 O）；
3. **可审计**：报告必须同时给出 h 与解封次数。**意义**：定义 47 防「改动级作弊」，定义 48 防「选择级作弊」（挑分层/挑种子/挑 α 让自己刚好过线）。

**定义 49（分层条件评测与最差层下界）**：对分层 g∈G，令 LCB_g 为第 g 层指标的下置信界。**条件闸门**要求 min_{g∈G} LCB_g ≥ θ_g（或统一 θ），而非 pooled LCB ≥ θ。**命题（边际陷阱）**：pooled LCB ≥ θ 不蕴含任意 min_g LCB_g ≥ θ；存在分层（如 v20 的 persona 层）使总体达标而最差层严重不达标。**推论**：v20 的共形「边际覆盖」风险，在评测侧必须用定义 49 的分层闸门来对冲——这是把 v20 的自陈风险从「模型侧」搬到「评测侧」并给出可执行红线。

**定义 50（迁移证书与有效包络）**：迁移证书 T = (L, E, G_{A,B}, 假设清单)，E 为**有效包络**：E = {x : v ≤ v\*, ‖F‖ ≤ F\*, |Σ| ≤ Σ\*, ...}（速度、接触力、不确定度在标定范围内）。**命题**：T 仅对 x∈E 且假设清单与运行时一致的控制器类有效；x∉E 时 T 作废，控制器必须退回「串行安全监控 + 纯收缩人格契约」底线。**推论**：迁移不是全局布尔量，而是**带域**的局部承诺——直接压住「gap 小所以哪都能用」的过度外推。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 GAZEBO-DIFFERENTIAL-ORACLE（差分神谕 GDO）
1. **双后端重放**：同场景/同种子在 Isaac（PhysX）与 Gazebo（DART/Bullet）重放，ROS2 桥接统一观测与动作接口。
2. **差分指标**：差分间隙 G、轨迹分叉 D、非对称过拟合率；全部走 MCG 的 LCB（定义 46）。
3. **独立性账本**：自动记录引擎/接触/积分器/噪声差异，估计 ρ_L 与 ρ_fail；伪独立则拒绝出证书。
4. **场景对齐**：几何/材质/光照双向标定，产出「可比场景集」与「不可比清单」（不可比场景不参与 gap，但计入覆盖缺口）。

### 2.2 IP-61 METRIC-CONTRACT-GOVERNOR（指标治理 MCG）
1. **指标契约注册表**：每个 E 实验门槛编译为 M（定义 46），版本化、哈希化、可复现。
2. **LCB 闸门**：用 bootstrap / 秩统计 / Clopper-Pearson 给下界，禁止点估计过关。
3. **Goodhart 孪生**：每个主指标配一个反指标（如「违例率↓」配「任务完成率 / 最小让步次数↑」；「延迟↓」配「租约过期率↓」），跑对抗调参测试。
4. **预注册与封存**：实验前 commit h，划分 O/H\*，单次解封，报告强制附 h 与解封次数。

### 2.3 IP-62 TRANSFER-CERT-LEDGER（迁移证书 TCL）
1. **假设清单**：接触刚度、摩擦锥、传感器延迟、执行器饱和等的显式记录。
2. **有效包络标定**：扫速度/接触力/不确定度，拟合违例边界，给出 E 与安全裕度。
3. **包络守卫**：运行时 x∉E 立即作废迁移证书并降级（接 IP-58 关键级与 IP-51 守卫）。
4. **跨版本漂移检测**：仿真器/驱动/固件升级触发重标定，旧 T 自动失效。

## 5. 本轮最大风险

**一句话**：最大风险是「独立的假象」——Gazebo 与 Isaac 可能共享同一套刚体/接触近似，跨仿真一致并不等于真实世界 sound；更危险的是**指标契约本身可在元层被挑选**（分层、种子、α/β/δ、解封时机），于是我们用一套可 self-tune 的指标去认证一个可 simulator-tune 的证书，形成双重自欺。因此默认底线是：**指标契约必须实验前哈希预注册并冻结，跨仿真一致性只作必要条件而非 soundness 声明，任何迁移声明都限定在标定有效包络 E 内**。

## 2. 关键算法（伪代码）

### IP-60 GDO：双后端差分与独立性拒绝
```
def differential_validate(cert, suite, simA, simB,
                          delta, delta_traj, alpha, rho_max):
    ledger  = oracle_ledger(simA, simB)        # 引擎/接触/积分器/噪声差异
    rho_L   = ledger.independence_score()
    rho_fail= cofailure_corr(history)          # 历史共失败相关
    if rho_L < RHO_MIN or rho_fail > rho_max:
        return Reject("pseudo-independent oracle")   # 差分通过≠迁移证据
    rows = []
    for s in suite.scenarios:                  # 同一场景、同一随机种子
        tA = simA.rollout(s, cert.controller, seed=s.seed)
        tB = simB.rollout(s, cert.controller, seed=s.seed)
        rows.append((Viol(tA, cert), Viol(tB, cert), traj_dist(tA, tB)))
    asym     = mean(vA == 0 and vB > 0 for vA, vB, _ in rows)
    gap_lcb  = lcb([vB - vA for vA, vB, _ in rows], beta=alpha)
    div_p95  = quantile([d for _, _, d in rows], 0.95)
    if asym > alpha or gap_lcb > delta or div_p95 > delta_traj:
        return Reject("asymmetric overfit / gap / divergence")
    return Accept(gap_lcb, div_p95, rho_L, rho_fail)
```

### IP-61 MCG：契约可容许、预注册、分层闸门与 Goodhart 探针
```
def preregister(protocol):
    h      = sha256(canonical(protocol))       # Ω,P,G,θ,α,β,δ
    commit(h)                                  # 封存 H*：只公开承诺
    sealed = split_holdout(protocol.scenarios, h)
    return h, sealed

def admit_metric(M):
    return (M.is_measurable()
            and M.has_valid_lcb(beta=M.beta)                 # 只用 LCB
            and M.has_twin()
            and goodhart_probe(M, M.twin, Q, eps, gamma).passed
            and M.prereg_hash == M.current_hash())           # 事后改动即失效

def stratified_gate(results, M, strata):
    if not admit_metric(M):
        return Reject("inadmissible metric")
    lcbs = {g: lcb(results[M][g], beta=M.beta) for g in strata}
    return Accept(lcbs) if min(lcbs.values()) >= M.theta else Reject("worst stratum")

def goodhart_probe(M, twin, Q, eps, gamma):
    bad = [q for q in Q
           if delta(M, q) >= eps                          # 主指标被刷高
           and delta(twin, q) >= -gamma                   # 孪生没变坏
           and delta(target, q) <= 0]                     # 真实目标没变好
    return Probe(passed=not bad, witnesses=bad[:5])       # 有见证即抗博弈失败
```

### IP-62 TCL：迁移包络守卫
```
def transfer_gate(cert, x, T, runtime_assumptions):
    if not T.envelope.contains(x):
        return Void("outside validity envelope")          # 回退串行安全+纯收缩
    if not T.assumptions.consistent(runtime_assumptions):
        return Void("assumption ledger mismatch")
    return Valid(T)
```

def car_transition_guard_v9(e, x, cert_obj, persona, lease, metric_state, T, t):

## 6. 本轮最大风险

**一句话**：最大风险是「独立的假象」——Gazebo 与 Isaac 可能共享同一套刚体/接触近似，跨仿真一致并不等于真实世界 sound；更危险的是**指标契约本身可在元层被挑选**（分层、种子、α/β/δ、解封时机），于是我们用一套可 self-tune 的指标去认证一个可 simulator-tune 的证书，形成双重自欺。因此默认底线是：**指标契约必须实验前哈希预注册并冻结，跨仿真一致性只作必要条件而非 soundness 声明，任何迁移声明都限定在标定有效包络 E 内**。
