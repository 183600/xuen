# 第 55 轮（承接第 54 轮 v16+++ GroundEdge-GenSim+++；灵感循环新循环第 1 轮；本轮灵感：「快速原型」×「位姿估计」）

> 第 54 轮把技能组合推进到动作空间剖面 α_S、技能组合图 SCOM 与云边协同 CEC；但 α_S 默认对象位姿是干净且语义等价的输入，位姿估计误差被隐含地摊进采样噪声。本轮把位姿估计提升为一等公民，聚焦 **位姿误差的对称商空间几何、快速原型的证书样本效率、位姿-动作管的安全包络**。核心矛盾：H22：位姿误差不是各向同性标量，对称物体的位姿别名会让“视觉正确”的动作在任务语义下错误；H23：快速原型能用极少样本产出“看起来可部署”的证书，但若原型的对称群/位姿分布与目标不一致，证书不可迁移。

## 0. 直觉与动机

**灵感 1（位姿误差是带对称群的协方差场，而非标量 σ）**
直觉：估计器输出位姿 `T̂ ∈ SE(3)`，误差 `e = log(T^{-1}T̂) ∈ se(3)`，天然带一个 6×6 协方差 `Σ_pose`；而物体常有对称群 `G_sym`，观测无法区分 `T` 与 `T·g`。真正影响操作的不是全部误差，而是 **任务相关对称群 `G_task` 之外的误差**。若把对称方向上的误差也当风险，会过度保守；反过来，若把 `G_task` 误估得更大，会放行危险别名。因此位姿证书必须在商空间 `SE(3)/G_task` 上度量，而不是在原始 `SE(3)` 上量。

**灵感 2（快速原型 = 在位姿-动作平面上做主动边界探测）**
直觉：完整采样 `α_S(a|T)` 代价极高。快速原型用少量“短探针”（抓取、轻推、接近等原语）在 `(T,a)` 上取点，拟合带不确定度的成功面 `g_θ(T,a)`，并优先把探针花在 **安全边界 `α=τ`** 与 **对称轨道边界** 附近。这把第 54 轮 ACS 的离线剖面升级为“位姿条件代理 + 主动采样”：探针预算由信息增益和证书裕度共同驱动，而不是均匀网格。

**灵感 3（位姿-动作管：把位姿不确定性拉回动作空间）**
直觉：技能策略 `π_S` 把位姿映射为标称动作 `a_nom = π_S([T̂])`，灵敏度 `J = ∂π_S/∂ξ`。位姿协方差经 `J` 拉回为动作协方差 `Σ_a = P_𝒫 J Σ_pose Jᵀ P_𝒫ᵀ + Σ_act`。真实动作落在管 `Tube_ε(S,T) = {a : (a-a_nom)ᵀΣ_a^{-1}(a-a_nom) ≤ ε}`。可部署要求 **管被安全动作集包含且留有裕度**。若管越界，只有三条路：追加视角（NBV）压 `Σ_pose`；收缩为更保守技能；拒绝。位姿估计由此从“感知模块”变成“动作可行性的一等约束”。

**灵感 4（原型→部署的等变迁移证书）**
直觉：快速原型多在替代物或数字孪生上完成，只有存在等变映射 `ψ` 且 `ψ(A_safe^p(T)) = A_safe^t(ψ(T))` 时，原型证书才能迁移。用 **等变缺陷 `η_ψ`** 量化“原型能代表目标多少”：`η_ψ` 大时，原型的 95% 证书到目标可能只剩 70%。这把“快速”与“可信”显式解耦——迭代快不等于可部署，必须为迁移付一笔可计算的误差税。

**灵感 5（云边双速率闭环）**
直觉：云端持有原型库、对称先验与批量仿真探针，负责商空间证书与大范围边界搜索；边端负责真实位姿估计、NBV 与少量真实探针。云端证书下发 → 边端核对位姿-动作管包含 → 若在对称边界或安全边界失败，反向解释回传，触发云端 **重采样 + 对称群修正 + 重发证书**。这形成 **Pose → Probe → Certificate → Re-probe** 的闭环，与第 54 轮的云边契约 `C_ce` 自然衔接。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（任务相关位姿商空间）**
物体位姿 `T ∈ SE(3)`，对称群 `G_sym ≤ SE(3)`。**任务相关对称群**
`G_task = { g ∈ G_sym | π_task(T·g) = π_task(T), ∀T }`，
其中 `π_task` 为任务层观测（如抓取点、倾倒方向、插入轴）。位姿等价类 `[T] = T·G_task`，商空间 `𝒫 = SE(3)/G_task`。**商误差**
`d_𝒫(T,T̂) = min_{g∈G_task} ||log(T^{-1}T̂g)||_{Σ_pose}`。
一致性自检：若 `α_S(a|T·g) ≠ α_S(a|T)` 对某个 `g∈G_task` 成立，则说明 `G_task` 定义有误，触发对称红队。

**定义 122（位姿条件动作剖面与安全集）**
`α_S(a|T) = P(success | a,T)`，`A_safe^τ(T) = { a : α_S(a|T) ≥ τ }`。
第 54 轮的 `α_S(a)` 是本定义在 `T` 上取期望的边际：`α_S(a) = E_T[α_S(a|T)]`；边际会掩盖位姿别名处的空洞，因此本轮必须以条件剖面为准。

**定义 123（灵敏度与位姿-动作管）**
技能策略 `π_S : 𝒫 → A`，`a_nom = π_S([T̂])`，局部坐标 `ξ ∈ se(3)` 上
`J = ∂π_S/∂ξ`，`P_𝒫` 为商空间切向投影。动作协方差
`Σ_a = P_𝒫 J Σ_pose Jᵀ P_𝒫ᵀ + Σ_act`。
**位姿-动作管** `Tube_ε(S,T) = { a : (a-a_nom)ᵀ Σ_a^{-1} (a-a_nom) ≤ ε }`。

**定义 124（包含证书与安全裕度）**
包含证书 `C_inc = (Tube_ε, A_safe^τ, m_a)`，其中
`m_a = min_{a∈Tube_ε} dist(a, ∂A_safe^τ)`（有符号距离，边界内为正）。
可部署条件：`Tube_ε ⊆ A_safe^τ` 且 `m_a ≥ m_min`。
用有符号距离而非“点在边界上”的布尔判定，避免数值假阳性把临界动作放行。

**定义 125（快速原型探测算子与保形代理）**
探针 `p = (T_p, a_p, y_p)`，`y_p ∈ {0,1}`。代理 `g_θ : 𝒫×A → [0,1]`，认知不确定度 `σ_g`。
主动采集
`a*(T) = argmax_a [ U_boundary(a;T) + λ_sym · U_sym(a;T) ]`，
其中 `U_boundary` 为安全边界的 level-set 信息增益，`U_sym` 为跨对称轨道的覆盖增益。
用 split conformal 得下界 `α̂⁻(a,T)`，在可交换性下满足 `P(α_S(a|T) ≥ α̂⁻(a,T)) ≥ 1-α`。
**快速**定义为：达到证书所需探针数 `N_cert ≤ N_budget`，且 `N_cert ≪ |𝒫|·|A|`。

**定义 126（原型→部署等变迁移证书）**
等变映射 `ψ : 𝒫_p → 𝒫_t`。**等变缺陷**
`η_ψ = sup_{T∈D_p} d_H( ψ(A_safe^{τ,p}(T)), A_safe^{τ,t}(ψ(T)) ) / diam(A)`，
`d_H` 为 Hausdorff 距离。迁移证书 `C_trans = (ψ, η_ψ, δ_dist)`；当 `η_ψ ≤ η_max` 且位姿分布偏移 `D_𝒫(p,t) ≤ δ_dist` 时可用，否则拒绝迁移。

## 2. 关键算法 伪代码

### IP-121 QPC（Quotient Pose Certificate）

```python
def quotient_pose_cert(T_hat, Sigma, G_task, metric):
    # 在对称轨道 T_hat·G_task 上取最近代表元，得到商误差
    e_best, g_best = min(
        ((lie_log(inv(T_hat) @ (T_hat @ g)), g) for g in G_task),
        key=lambda eg: metric(eg[0], Sigma)
    )
    Sigma_q = project_cotangent(Sigma, G_task)   # 商空间切向投影
    return PoseCert(e_best, Sigma_q, g_best, d_quot=metric(e_best, Sigma))
```

### IP-122 PACS（Pose-Action Coverage Sampling）

```python
def active_probe_loop(skill, P_domain, budget, tau, surrogate, G_task):
    while budget > 0:
        T = select_pose(P_domain, surrogate, G_task)      # 别名/边界优先
        a = argmax_acquisition(T, surrogate, tau, G_task)  # 边界方差 + 对称覆盖
        y = skill.probe(T, a)                              # 仿真或真实短探针
        surrogate.update((T, a, y))
        budget -= 1
    alpha_hat = conformal_lower_bound(surrogate, alpha=0.05)
    return alpha_hat                                      # 位姿条件成功面下界
```

### IP-123 PAT（Pose-Action Tube）

```python
def pose_action_tube(pi_S, T_hat, Sigma_pose, Sigma_act, eps):
    a_nom = pi_S(T_hat)
    J = numerical_jacobian(pi_S, T_hat, local_frame=True)
    Sigma_a = project_quotient(J @ Sigma_pose @ J.T) + Sigma_act
    return Tube(a_nom, Sigma_a, eps)

def certify_inclusion(tube, A_safe, tau, m_min):
    # 采样 + 区间传播估计包含关系与最小有符号裕度
    m_a = min_signed_distance(tube.sample(), boundary(A_safe, tau))
    return ('ok' if m_a >= m_min else 'reject', m_a)
```

### IP-124 RPC（Rapid Prototype Certificate）

```python
def rapid_prototype_certificate(skill, P_domain, G_task, tau,
                                probe_budget, m_min):
    surrogate = init_surrogate(G_task)          # 对称等变先验
    alpha_hat = active_probe_loop(skill, P_domain, probe_budget,
                                  tau, surrogate, G_task)
    A_safe_hat = level_set(alpha_hat, tau)
    certs = []
    for T in P_domain.cert_points():
        tube = pose_action_tube(skill.pi, T, T.Sigma,
                                skill.Sigma_act, eps=chi2_quantile)
        ok, m_a = certify_inclusion(tube, A_safe_hat, tau, m_min)
        certs.append((T, ok, m_a, alpha_hat))
    return PrototypeCert(alpha_hat, A_safe_hat, certs,
                         evidence=surrogate.data)
```

### IP-125 ETC（Equivariant Transfer Certificate）

```python
def equivariant_transfer_cert(C_p, psi, target_domain,
                              eta_max, delta_dist):
    eta = hausdorff_defect(psi, C_p.A_safe, target_domain.A_safe)
    dist = pose_distribution_shift(C_p.P_domain, target_domain.P)
    if eta > eta_max or dist > delta_dist:
        return ('reject', 'equivariance_or_shift', eta, dist)
    A_safe_t = contract(psi(C_p.A_safe), eta)   # 迁移后保守收缩
    return ('ok', TransferCert(psi, eta, dist, A_safe_t))
```

### IP-126 PPC（Pose-Prototype-Certificate Loop）

```python
def ppc_loop(task, edge_pose, cloud_proto, target_domain,
             budget_cert, budget_probe):
    while budget_cert > 0:
        T_hat, Sigma = edge_pose.estimate()
        cert_q = quotient_pose_cert(T_hat, Sigma, task.G_task, metric)
        if cert_q.d_quot > delta_pose:
            edge_pose.next_best_view(cert_q)    # 先压低位姿不确定度
            continue
        C_p = cloud_proto.fetch(task, cert_q)   # 云端原型证书
        C_t = equivariant_transfer_cert(C_p, task.psi, target_domain,
                                        eta_max, delta_dist)
        if C_t[0] != 'ok':
            return C_t
        tube = pose_action_tube(task.pi, T_hat, Sigma,
                                task.Sigma_act, eps=chi2_quantile)
        ok, m_a = certify_inclusion(tube, C_t[1].A_safe_t,
                                    task.tau, task.m_min)
        if not ok:
            exp = explain_pose_failure(tube, m_a, cert_q)
            cloud_proto.reprobe(exp)            # 反向解释驱动重采样
            budget_probe -= 1
            continue
        return ('deploy', JointPoseCert(cert_q, C_t, tube, m_a))
    return ('reject', 'budget')
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| QPC | O(|G_task|·c_log) | O(6×6) | 商代表元穷举完备、协方差切向投影保正定 |
| PACS | O(N_probe·(log N + |A|)) | O(N_probe) | 采集函数覆盖边界、conformal 可交换 |
| PAT | O(|A|·6 + N_sample) | O(|A|) | 线性化误差有界、管采样覆盖尾部 |
| RPC | O(N_cert·(|A| + N_sample)) | O(N_cert) | 下界 sound、安全集 level-set 保守 |
| ETC | O(N_boundary·|G_sym|) | O(|A_safe|) | ψ 等变、Hausdorff 上界可估 |
| PPC | O(N_cert·(T_pose + N_probe)) | O(|𝒫|·|A|) 稀疏 | 闭环单调、重采样收敛 |

**正确性定理（Pose-Grounded Prototype Soundness）**
假设承接第 54 轮 (A22)–(A28)，并新增：
**(A29)** `G_task` 与真实任务不变群一致，且 `α_S` 在等价类上不变；
**(A30)** 探针在 `𝒫_p` 上可交换，conformal 下界有效（覆盖率 ≥ 1-α）；
**(A31)** `π_S` 的局部线性化误差 `ε_lin` 有界，`L_S` 为其 Lipschitz 常数；
**(A32)** 原型→目标映射 `ψ` 的等变缺陷 `η_ψ ≤ η_max`，位姿分布偏移 `≤ δ_dist`。
则对 `∀T ∈ D_t`：
```
P(fail at deployment) ≤ α + η_ψ + P(d_𝒫 > δ_pose) + ε_lin·L_S + β_E
```
四类误差被显式分离：**统计下界误差 α**（样本）、**迁移误差 η_ψ**（原型）、**位姿越界概率**（感知域）、**线性化误差**（动作映射）。相比第 54 轮只按 `Σ_d(1-ρ_min(d))` 粗算，本轮把“位姿带来的失效”从黑箱中拆了出来。

| 实验 | 指标 | 目标 |

| E162 商空间位姿证书 vs 标量误差 | 危险放行率 / 误拒率 | 危险放行 ≤ 2%，误拒下降 ≥ 20% |
| E163 位姿-动作管包含校准 | 预测覆盖率 vs 经验覆盖率 | 偏差 ≤ 3% |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| `G_task` 误判（把危险方向当对称） | 高 | 对称红队 + 多假设并行 + 任务不变性单元测试 |
| conformal 可交换性被 OOD 位姿破坏 | 高 | OOD 位姿检测 + 在线重校准 + 保守回退到第 54 轮 ACS |
| `J` 在大位姿误差下线性化失效 | 中 | 分段局部 tube + 二阶项 + 只在 `d_𝒫≤δ_pose` 内认证 |
| 快速原型探针分布偏置 | 中 | 分层采样 + hard-negative mining + 对称覆盖配额 |
| 云边位姿表征/坐标系不一致 | 高 | 共享位姿本体 + 标定证书 + 坐标变换可逆校验 |
| 原型替代物过拟合（快速但不迁移） | 高 | 先验估计 `η_ψ`，超阈值直接拒绝，绝不“先上线再观察” |

## 6. 本轮最大风险

**一句话**：把位姿误差放进对称商空间并用快速原型主动铺点，确实能把“位姿不确定性”变成可计算的位姿-动作管，但整个证书体系的 soundness **同时押注在 `G_task` 的正确性、conformal 的可交换性、以及原型→目标等变缺陷 `η_ψ` 的上界估计**上；一旦任务相关对称群被误判或目标位姿越出标定域，商空间证书会系统性地把危险别名动作认证为安全，且“快速”会让这种错误以更高频率被部署，故必须以 **对称红队 + OOD 位姿闸门 + `η_ψ` 硬阈值** 三重护栏，宁可慢一点认证，也不把“快速原型的可迁移假象”当成部署前提。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim⁺⁺⁺⁺ · PoseProto（QPC×PACS×PAT×RPC×ETC×PPC）

> 承接第 54 轮产物 v31（ACS×SCOM×CEC×AEC×JTC）。本轮把 **位姿估计** 与 **快速原型** 接入动作-鲁棒性证书体系，新增六个算子：
> - **QPC（Quotient Pose Certificate）**：在任务相关对称商空间 `SE(3)/G_task` 上度量位姿误差；

> - **RPC（Rapid Prototype Certificate）**：少样本、带保形下界的快速原型证书；
> - **ETC（Equivariant Transfer Certificate）**：用量化等变缺陷 `η_ψ` 判定原型→目标可迁移性；
> - **PPC（Pose-Prototype-Certificate Loop）**：云边双速率的 Pose→Probe→Certificate→Re-probe 闭环。

| `𝒫 = SE(3)/G_task` | 任务相关位姿商空间 |
| `d_𝒫(T,T̂)` | 商误差 `min_g ||log(T^{-1}T̂g)||_{Σ_pose}` |
| `α_S(a|T)` | 位姿条件动作剖面 |
| `A_safe^τ(T)` | 位姿条件安全动作集 |
| `J = ∂π_S/∂ξ` | 技能对位姿的灵敏度（局部 se(3) 坐标） |
| `Σ_a` | 拉回动作协方差 `P J Σ_pose JᵀPᵀ+Σ_act` |
| `Tube_ε(S,T)` | 位姿-动作管 |
| `m_a` | 管对安全集边界的最小有符号裕度 |
| `α̂⁻(a,T)` | conformal 成功概率下界 |
| `η_ψ` | 原型→目标等变缺陷（Hausdorff，归一化） |
| `C_trans=(ψ,η_ψ,δ_dist)` | 等变迁移证书 |
| `JointPoseCert` | `(PoseCert, C_trans, Tube, m_a, evidence)` |

## 2. 关键算法 伪代码

### IP-121 QPC

```python
def quotient_pose_cert(T_hat, Sigma, G_task, metric):
    e_best, g_best = min(
        ((lie_log(inv(T_hat) @ (T_hat @ g)), g) for g in G_task),
        key=lambda eg: metric(eg[0], Sigma)
    )
    Sigma_q = project_cotangent(Sigma, G_task)
    return PoseCert(e_best, Sigma_q, g_best, d_quot=metric(e_best, Sigma))
```

### IP-122 PACS

```python
def active_probe_loop(skill, P_domain, budget, tau, surrogate, G_task):
    while budget > 0:
        T = select_pose(P_domain, surrogate, G_task)
        a = argmax_acquisition(T, surrogate, tau, G_task)
        y = skill.probe(T, a)
        surrogate.update((T, a, y))
        budget -= 1
    return conformal_lower_bound(surrogate, alpha=0.05)

def acquisition(T, surrogate, tau, G_task):
    return boundary_variance(surrogate, T) + \
           lam_sym * symmetry_coverage_gain(surrogate, T, G_task)
```

### IP-123 PAT

```python
def pose_action_tube(pi_S, T_hat, Sigma_pose, Sigma_act, eps):
    a_nom = pi_S(T_hat)
    J = numerical_jacobian(pi_S, T_hat, local_frame=True)
    Sigma_a = project_quotient(J @ Sigma_pose @ J.T) + Sigma_act
    return Tube(a_nom, Sigma_a, eps)

def certify_inclusion(tube, A_safe, tau, m_min):
    m_a = min_signed_distance(tube.sample(), boundary(A_safe, tau))
    return ('ok' if m_a >= m_min else 'reject', m_a)
```

### IP-124 RPC

```python
def rapid_prototype_certificate(skill, P_domain, G_task, tau,
                                probe_budget, m_min):
    surrogate = init_surrogate(G_task)
    alpha_hat = active_probe_loop(skill, P_domain, probe_budget,
                                  tau, surrogate, G_task)
    A_safe_hat = level_set(alpha_hat, tau)
    certs = []
    for T in P_domain.cert_points():
        tube = pose_action_tube(skill.pi, T, T.Sigma,
                                skill.Sigma_act, eps=chi2_quantile)
        ok, m_a = certify_inclusion(tube, A_safe_hat, tau, m_min)
        certs.append((T, ok, m_a, alpha_hat))
    return PrototypeCert(alpha_hat, A_safe_hat, certs,
                         evidence=surrogate.data)
```

### IP-125 ETC

```python
def equivariant_transfer_cert(C_p, psi, target_domain,
                              eta_max, delta_dist):
    eta = hausdorff_defect(psi, C_p.A_safe, target_domain.A_safe)
    dist = pose_distribution_shift(C_p.P_domain, target_domain.P)
    if eta > eta_max or dist > delta_dist:
        return ('reject', 'equivariance_or_shift', eta, dist)
    A_safe_t = contract(psi(C_p.A_safe), eta)
    return ('ok', TransferCert(psi, eta, dist, A_safe_t))
```

### IP-126 PPC

```python
def ppc_loop(task, edge_pose, cloud_proto, target_domain,
             budget_cert, budget_probe):
    while budget_cert > 0:
        T_hat, Sigma = edge_pose.estimate()
        cert_q = quotient_pose_cert(T_hat, Sigma, task.G_task, metric)
        if cert_q.d_quot > delta_pose:
            edge_pose.next_best_view(cert_q)
            continue
        C_p = cloud_proto.fetch(task, cert_q)
        C_t = equivariant_transfer_cert(C_p, task.psi, target_domain,
                                        eta_max, delta_dist)
        if C_t[0] != 'ok':
            return C_t
        tube = pose_action_tube(task.pi, T_hat, Sigma,
                                task.Sigma_act, eps=chi2_quantile)
        ok, m_a = certify_inclusion(tube, C_t[1].A_safe_t,
                                    task.tau, task.m_min)
        if not ok:
            exp = explain_pose_failure(tube, m_a, cert_q)
            cloud_proto.reprobe(exp)
            budget_probe -= 1
            continue
        return ('deploy', JointPoseCert(cert_q, C_t, tube, m_a))
    return ('reject', 'budget')
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| QPC | O(|G_task|·c_log) | O(6×6) | 商代表元完备、`Σ_q` 正定 |
| PACS | O(N_probe·(log N+|A|)) | O(N_probe) | 主动覆盖边界、conformal 有效 |
| PAT | O(|A|·6+N_sample) | O(|A|) | 线性化误差 ≤ ε_lin、尾部采样覆盖 |
| RPC | O(N_cert·(|A|+N_sample)) | O(N_cert) | 下界 sound、安全集保守 |
| ETC | O(N_boundary·|G_sym|) | O(|A_safe|) | `η_ψ` 上界可估、双闸门 |
| PPC | O(N_cert·(T_pose+N_probe)) | O(|𝒫|·|A|) 稀疏 | 闭环单调、重采样收敛 |

**正确性定理（Pose-Grounded Prototype Soundness）**
假设第 54 轮 (A22)–(A28) 成立；新增 **(A29)** `G_task` 与真实任务不变群一致且 `α_S` 在等价类上不变；**(A30)** 探针可交换、conformal 覆盖率 ≥ 1-α；**(A31)** `π_S` 局部线性化误差 ≤ ε_lin、Lipschitz 常数 `L_S`；**(A32)** 等变缺陷 `η_ψ ≤ η_max` 且位姿分布偏移 `≤ δ_dist`。
则对部署域内 `∀T`：
```
P(fail) ≤ α + η_ψ + P(d_𝒫 > δ_pose) + ε_lin·L_S + β_E
```
**四项误差分离**：统计下界（样本）、等变迁移（原型）、位姿越界（感知域）、线性化（动作映射）。任一闸门触发即拒绝，不做“先部署再观察”。

## 5. 本轮最大风险

**一句话**：把位姿误差放进对称商空间并用快速原型主动铺点，确实能把“位姿不确定性”变成可计算的位姿-动作管，但整个证书体系的 soundness **同时押注在 `G_task` 的正确性、conformal 的可交换性、以及原型→目标等变缺陷 `η_ψ` 的上界估计**上；一旦任务相关对称群被误判或目标位姿越出标定域，商空间证书会系统性地把危险别名动作认证为安全，且“快速”会让这种错误以更高频率被部署，故必须以 **对称红队 + OOD 位姿闸门 + `η_ψ` 硬阈值** 三重护栏，宁可慢一点认证，也不把“快速原型的可迁移假象”当成部署前提。
