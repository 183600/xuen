# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 7 轮；本轮灵感：「谐波减速器」×「在线学习」）

> 第 60 轮把「执行层→证据层」升级为「场景→意图→约束→阻抗→执行→EV-exec→场景」的认知闭环（SSM×CIEC×EPIR×SERC×PCE++++）。但**四个更深层的局限**仍悬而未决：
> 1. **阻抗编译的「物理未落地」**：K_safe 始终是控制空间里的数字，隐含假设「关节能精确实现所命令的阻抗」。真实关节经谐波减速器（柔轮弹性、齿隙回差、周期性传动误差、分段非线性扭转刚度）后，物理阻抗 K_real 与命令阻抗 K_cmd 存在系统性偏差——整套 SGEC 在**执行器物理层是「盲」的**。
> 2. **场景先验的「硬件无关假设」**：SSM 的 π_scene(K|z) 默认同一场景在任何硬件上需要同一阻抗。但磨损、温升、装配差异会改变柔轮刚度与回差，同一场景在「新关节」安全、在「磨损关节」可能失稳；先验必须**以关节健康状态为条件**。
> 3. **证据链的「指令侧完备、物理侧失真」**：EPIR 记录的 EV-exec 多由命令/编码器构造，能证明「我下达了 K_safe」，却无法证明「我物理上施加了 K_safe」；传动误差让证据链**语义完备而物理失真**。
> 4. **模型的「一次性标定」**：Round 60 的阻抗先验与传动模型是离线标定的静态对象；而谐波减速器的传动误差、回差、刚度会随温度（分钟级）与疲劳磨损（小时—天级）**持续漂移**，缺失让模型保持有效的在线机制。

## 0. 直觉与动机

**灵感 1（谐波减速器 → 传动误差表征 HRER）**
直觉：谐波减速器不是「理想的 N:1 齿轮」，而是一只**会呼吸的非线性弹簧 + 周期性齿隙**：柔轮在波发生器每转一圈产生一次（及其倍频）的传动误差 e(θ_m)=Σ[a_k cos kθ_m + b_k sin kθ_m]，齿隙造成方向相关的丢失运动 β_lost·sgn(θ̇)，扭转刚度在低扭矩区「软」、高扭矩区「硬」（分段 K_1<K_2）。关键洞见：**把「关节」从黑箱换成可辨识的物理对象**——命令阻抗必须经过「传动算子」才落到物理世界，而该算子可被在线辨识、被反补偿。

**灵感 2（在线学习 → 安全认证在线学习 SCOL）**
直觉：生物运动控制靠「小脑前向模型」持续用误差校准，但没人会因为一次偶然的滑手就重写整套运动技能。把在线学习做成**「影子学习-证据晋升」双轨**：影子模型用递推最小二乘/卡尔曼吸收数据，但候选参数只有通过①步长裁剪 ②被动性投影 ③连续 N_cons 条 EV-exec 证据一致 三道门才「晋升」为活跃参数——**学到的物理永不直接覆盖已验证的物理**。

**灵感 3（在线学习 → 激励感知可辨识性 EAEX）**
直觉：在线学习理论的核心不是「更新公式」，而是「数据是否足够激励」。若机器人只在一个小角度范围重复运动，傅里叶基 φ_k(θ_m) 近似共线，Fisher 信息矩阵 FIM 病态——某些系数根本不可辨识，任何「学习」都只是在拟合噪声。关键洞见：**把可辨识性 κ_id=λ_min(FIM)/λ_min^* 当作一等公民**；不可辨识时主动在力/加加速度安全约束内注入有界微激励 u_d（选择学习价值 LV=I_gain/cost 最高的频率），否则冻结对应参数并放大其不确定度。

**灵感 4（谐波减速器 + 在线学习 → 多时间尺度校准 MTOC）**
直觉：谐波减速器的误差有三个截然不同的时间常数——**快尺度**（每周期的传动误差傅里叶系数，毫秒）、**中尺度**（温升引起的刚度/摩擦漂移，分钟）、**慢尺度**（柔轮疲劳磨损引起的回差增大、刚度下降，小时—天）。用一个 CUSUM 变点检测把「噪声」与「磨损事件」分开：慢尺度累计偏移超阈 h 即宣告磨损、放宽不确定度、触发重标定；慢尺度变化反过来放宽快尺度的搜索范围。

**灵感 5（三灵感合流 → 物理接地闭环 PREC）**
直觉：Round 60 的 K_safe 是「应该施加的阻抗」，PREC 补上「实际施加的阻抗」。闭环变为：**场景→意图→K_safe→反补偿 T⁻¹(K_safe;Θ̂)→K_cmd→真实关节（谐波传动）→物理 EV-exec（含传动残差）→在线学习 Θ̂→更新场景/阻抗先验**。关键洞见：**证据必须从「指令侧」下沉到「物理侧」**——只有把传动残差 r_e=θ_j−θ̂_j 纳入 EV-exec，证据链才真正闭到执行器。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（谐波传动误差表征 HRER）** 谐波关节模型 H=(N, e, g, β, Θ)。其中：
- **传动比** N（如 100）；波发生器角 θ_m，关节输出角 θ_j
- **周期传动误差**：e(θ_m;Θ_fast)=Σ_{k=1}^{K}[a_k cos(kθ_m)+b_k sin(kθ_m)]，K 阶（k=1 为每转一次主阶，另含齿啮合阶）
- **丢失运动/回差**：β_lost(t)·sgn(θ̇_m)，β_lost 随磨损单调增大
- **非线性扭转刚度**：τ=g(δ;Θ_med)，δ 为扭转形变；分段定义 τ=K_1δ (|δ|<δ_1)，τ=K_1δ_1+K_2(δ−δ_1) (|δ|≥δ_1)，K_1<K_2
- **输出方程**：θ_j = θ_m/N − e(θ_m;Θ_fast) − β_lost·sgn(θ̇_m) − g⁻¹(τ;Θ_med)
- **多时间尺度参数**：Θ=Θ_fast∪Θ_med∪Θ_slow（分别对应傅里叶系数、K_1/K_2/δ_1、β_lost/磨损状态）

**定义 162（阻抗传动算子 ILT）** 传动算子 T：(K_cmd, Θ) → K_real。
- **关节空间映射**：K_joint=J⁻ᵀ K_safe J⁻¹；物理实现 K_real=T(K_cmd;Θ)
- **反补偿**：命令阻抗 K_cmd=T⁻¹(K_safe;Θ̂_active)，使 T(K_cmd;Θ̂)≈K_safe
- **误差界**：若 T 对参数 L_T-Lipschitz，则 ‖K_real−K_safe‖ ≤ L_T·‖Θ̂−Θ‖
- **可实现性**：K_safe∈Im T(·;Θ̂) 且反解满足执行器限幅（τ_max, v_max, K_min/K_max）；否则投影 K_safe←Π_reach(K_safe) 并记录 reason=REALIZABILITY_CLAMP

**定义 163（安全认证在线学习 SCOL）** 学习算子 L 与三重护栏：
- **有界更新**：Θ̂_{t+1}=Π_P(Θ̂_t+clip(ΔΘ_t,−ρ,ρ))，其中 ΔΘ_t=R_t⁻¹φ_t r_t（RLS），Π_P 为**被动性投影**（保证 Re Z(jω)≥0，关节不向环境注入能量）
- **残差**：r_t=θ_j−θ̂_j(θ_m,τ)
- **晋升门**：影子参数 Θ_shadow 与活跃参数 Θ_active 分离；仅当连续 N_cons 条 EV-exec 与影子预测一致（‖r‖≤ε_r）且残差能量 V(Θ_shadow)≤V(Θ_active)，才令 Θ_active←Θ_shadow
- **回滚**：晋升后连续 M 次残差超阈，立即回滚至上一认证参数

**定义 164（激励感知可辨识性 EAEX）**
- **Fisher 信息矩阵**：F(Θ)=Σ_t φ_tφ_tᵀ/σ²，φ_t 为傅里叶特征
- **可辨识置信度**：κ_id=λ_min(F)/λ_min^*，κ_id<1 表示病态
- **学习价值**：LV(k)=I_gain(k)/cost(k)，I_gain∝(∂e/∂a_k)ᵀ F⁻¹ (∂e/∂a_k)
- **微激励**：u_d 满足 ‖u_d‖≤u_max、F≤F_safe、jerk≤jerk_max；仅在 LV 与预算允许时注入
- **冻结策略**：不可辨识系数冻结，其方差按 σ²_k←σ²_k·(1+γ) 膨胀，反补偿时该系数取保守下界

**定义 165（多时间尺度校准 MTOC）**
- **fast**：每控制周期更新 Θ_fast（由 SCOL 完成）
- **med**：温度 T 驱动的 Θ_med 插值/更新（K_1,K_2,δ_1 随温漂移）
- **slow**：CUSUM 统计量 S_t=max(0, S_{t−1}+(r_t^slow−μ_0−ν))；S_t>h ⇒ 磨损事件（β_lost↑、K↓），cov_slow←cov_slow·4，触发重标定
- **尺度耦合**：慢尺度不确定度↑ ⇒ 快尺度允许步长 ρ↑、晋升门 N_cons↓（但被动性投影强度不降）

**定义 166（物理接地闭环 PREC）** 算子 PREC(M, intent, δ_f_req)：
```
① SSM（R60）: z ← R_scene.update(obs)
② K_safe ← EEIS.compile_with_scene_prior(π_scene(K|z), δ_f_req)
③ CIEC（R60）: 若 intent 则 ERTC.lock(ϕ(intent))
④ ILT 反补偿: (K_cmd, K_safe) ← precompensate(K_safe, Θ̂_active, T)
⑤ Dispatch: send(K_cmd); telemetry ← execute()
⑥ SCOL: Θ̂ ← observe(θ_m, θ_j, τ, direction)
⑦ MTOC: fast_update / med_update / slow_update
⑧ EV-exec ← build_exec_evidence(telemetry, K_safe, K_cmd, Θ̂, r_e=θ_j−θ̂_j)
⑨ EPIR（R60）: S_shadow.append(EV-exec); S_sync.push()
⑩ XMC++（R60）: 用含传动残差的物理 EV-exec 融合
⑪ Return (K_safe, K_cmd, EV-exec, JIC.status, reason)
```

**定义 167（关节-阻抗-确定性三元组 JIC）** 扩展 R60 的 SIC：
- **JIC**=(Θ_certainty, κ_id, K_realizability)
- **Θ_certainty**=1/(1+tr(cov_fast))；κ_id 如定义 164；K_realizability=𝟙[K_safe∈Im T(·;Θ̂_active) ∧ 满足限幅]
- **JIC_valid** = Θ_certainty≥τ_Θ ∧ κ_id≥τ_id ∧ K_realizability
- **合取门**：只有 SIC∧JIC 同时通过才允许激进阻抗；否则回退保守 K_conservative，并在 EV-exec 中显式标注 rejected_reason

**定义 168（学习预算 B_learn 与 PCE+++++）** B_learn=(B_excite, B_update, B_promote)：B_excite 为微激励次数、B_update 为单周期最大更新算子数、B_promote 为晋升延迟上限。
```
voi_phys(π) = VOI_meta_pessimistic(π) − cost_cog − cost_exec − cost_learn
cost_learn = λ_ex·Excitation_cost + λ_upd·Update_cost + λ_pr·Promotion_cost
```
若 B_learn 耗尽：冻结 Θ̂_active（只读），并放大阻抗安全裕度 K_safe←(1+η)K_safe；若 κ_id<τ_id：冻结对应系数；若 Θ_certainty<τ_Θ：回退设计标称传动模型 Θ_general。

### IP-161 HRER（谐波传动误差表征）

```python
class HarmonicReducerModel:
    def __init__(self, N_ratio=100, K_harmonics=6):
        self.N = N_ratio
        self.K = K_harmonics
        self.a = np.zeros(self.K)          # cos 系数（快尺度）
        self.b = np.zeros(self.K)          # sin 系数（快尺度）
        self.beta_lost = 0.0               # 回差/丢失运动（慢尺度）
        self.K1, self.K2, self.delta1 = 1.0, 5.0, 0.02   # 分段刚度（中尺度）
        self.cov = {'fast': np.eye(2*self.K) * 1.0,
                    'med':  np.eye(3) * 1.0,
                    'slow': np.eye(1) * 1.0}
        self.wear_event = False

    def fourier_features(self, theta_m):
        return np.array([f(k*theta_m)
                         for k in range(1, self.K+1)
                         for f in (np.cos, np.sin)])

    def error(self, theta_m):
        phi = self.fourier_features(theta_m)
        return float(phi @ np.concatenate([self.a, self.b]))

    def torque_to_deflection(self, tau):
        if abs(tau) < self.K1 * self.delta1:
            return tau / self.K1
        return np.sign(tau) * (self.delta1 + (abs(tau) - self.K1*self.delta1) / self.K2)

    def predict(self, theta_m, tau, direction):
        return (theta_m / self.N
                - self.error(theta_m)
                - self.beta_lost * np.sign(direction)
                - self.torque_to_deflection(tau))
```

### IP-162 ILT（阻抗传动算子与反补偿）

```python
def precompensate(K_safe, theta_hat, T_op):
    # 反补偿：求解 K_cmd 使 T(K_cmd; theta_hat) ≈ K_safe
    K_cmd = T_op.inverse(K_safe, theta_hat)
    reason = 'OK'
    # 可实现性门：象空间 + 执行器限幅
    if not T_op.realizable(K_safe, theta_hat):
        K_safe = T_op.project_reachable(K_safe, theta_hat)
        K_cmd  = T_op.inverse(K_safe, theta_hat)
        reason = 'REALIZABILITY_CLAMP'
    # 误差界提示：||K_real - K_safe|| <= L_T * ||theta_hat - theta||
    return K_cmd, K_safe, reason
```

### IP-163 SCOL（安全认证在线学习）

```python
class SafeCertifiedOnlineLearner:
    def __init__(self, model, rho=1e-3, N_cons=5, M_rollback=3):
        self.shadow = copy.deepcopy(model)
        self.active = copy.deepcopy(model)
        self.rho, self.N_cons, self.M_rollback = rho, N_cons, M_rollback
        self.R = np.eye(2 * model.K) * 1e3      # RLS 协方差
        self.consistency = 0
        self.bad_count = 0

    def observe(self, theta_m, theta_j, tau, direction):
        r = theta_j - self.shadow.predict(theta_m, tau, direction)
        phi = self.shadow.fourier_features(theta_m)
        # 护栏①：有界步长
        dTheta = self._rls(phi, r)
        dTheta = np.clip(dTheta, -self.rho, self.rho)
        cand = self.shadow.theta_fast + dTheta
        # 护栏②：被动性投影（Re Z(jw) >= 0）
        cand = project_passive(cand)
        # 护栏③：残差能量单调（Lyapunov）
        if residual_energy(cand) <= residual_energy(self.shadow.theta_fast) + 1e-9:
            self.shadow.set_theta_fast(cand)
        # 晋升门：连续 N_cons 条证据一致
        self.consistency = self.consistency + 1 if abs(r) <= EPS_R else 0
        if self.consistency >= self.N_cons:
            self.active = copy.deepcopy(self.shadow)
            self.consistency, self.bad_count = 0, 0
        # 回滚
        self.bad_count = self.bad_count + 1 if abs(r) > EPS_BAD else 0
        if self.bad_count >= self.M_rollback:
            self.shadow = copy.deepcopy(self.active)
            self.bad_count = 0
        return self.active

    def _rls(self, phi, r):
        gain = self.R @ phi / (1.0 + phi @ self.R @ phi)
        self.R = self.R - np.outer(gain, phi) @ self.R
        return gain * r
```

### IP-164 EAEX（激励感知可辨识性）

```python
class ExcitationAwareExplorer:
    def __init__(self, model, u_max=0.01):
        self.model = model
        self.u_max = u_max
        self.FIM = np.zeros((2*model.K, 2*model.K))

    def update_fim(self, theta_window):
        Phi = np.stack([self.model.fourier_features(t) for t in theta_window])
        self.FIM += Phi.T @ Phi

    def identifiability(self):
        eig = np.linalg.eigvalsh(self.FIM + 1e-12*np.eye(self.FIM.shape[0]))
        return eig[0] / (eig[-1] + 1e-12)

    def suggest_dither(self, traj, budget):
        if budget.exhausted('excite'):
            return None
        for k in range(1, self.model.K + 1):
            if self.identifiability() < TAU_ID and self._unobservable(k):
                u = self.u_max * np.sin(k * traj.phase)
                if within_force_jerk(u, traj) and budget.allow('excite'):
                    return u
        return None
```

```python
class MultiTimescaleCalibrator:
    def __init__(self, model, h=5.0, nu=0.5, mu0=0.0):
        self.model = model
        self.S_cusum, self.h, self.nu, self.mu0 = 0.0, h, nu, mu0

    def med_update(self, temp):
        # 温度驱动刚度插值（中尺度）
        self.model.K1, self.model.K2 = self._thermal_curve(temp)

    def slow_update(self, r_slow):
        self.S_cusum = max(0.0, self.S_cusum + (r_slow - self.mu0 - self.nu))
        if self.S_cusum > self.h:
            self.model.wear_event = True
            self.model.cov['slow'] *= 4.0
            self.S_cusum = 0.0
            return 'WEAR_DETECTED'
        return 'NOMINAL'
```

### IP-168 PCE+++++（学习预算耦合）

```python
class LearningBudget:
    def __init__(self, excite_ops=20, update_ops=100, promote_latency=0.5):
        self.limits = {'excite': excite_ops, 'update': update_ops,
                       'promote': promote_latency}
        self.used = {'excite': 0, 'update': 0, 'promote': 0.0}

    def allow(self, kind):
        return self.used[kind] < self.limits[kind]

    def consume(self, kind, amount=1):
        self.used[kind] += amount

    def exhausted(self, kind=None):
        if kind is not None:
            return self.used[kind] >= self.limits[kind]
        return any(self.exhausted(k) for k in self.limits)


def physical_cost(action):
    return (0.15 if action.type == 'excite' else 0
            + 0.05 if action.type == 'update' else 0
```

### IP-161 HRER（谐波传动误差表征）

```python
class HarmonicReducerModel:
    def __init__(self, N_ratio=100, K_harmonics=6):
        self.N = N_ratio
        self.K = K_harmonics
        self.a = np.zeros(self.K); self.b = np.zeros(self.K)
        self.beta_lost = 0.0
        self.K1, self.K2, self.delta1 = 1.0, 5.0, 0.02
        self.cov = {'fast': np.eye(2*self.K), 'med': np.eye(3), 'slow': np.eye(1)}
        self.wear_event = False

    def fourier_features(self, theta_m):
        return np.array([f(k*theta_m) for k in range(1, self.K+1)
                         for f in (np.cos, np.sin)])

    def error(self, theta_m):
        return float(self.fourier_features(theta_m) @ np.concatenate([self.a, self.b]))

    def torque_to_deflection(self, tau):
        if abs(tau) < self.K1 * self.delta1:
            return tau / self.K1
        return np.sign(tau) * (self.delta1 + (abs(tau)-self.K1*self.delta1)/self.K2)

    def predict(self, theta_m, tau, direction):
        return (theta_m/self.N - self.error(theta_m)
                - self.beta_lost*np.sign(direction)
                - self.torque_to_deflection(tau))
```

### IP-163 SCOL（安全认证在线学习）

```python
class SafeCertifiedOnlineLearner:
    def __init__(self, model, rho=1e-3, N_cons=5, M_rollback=3):
        self.shadow = copy.deepcopy(model); self.active = copy.deepcopy(model)
        self.rho, self.N_cons, self.M_rollback = rho, N_cons, M_rollback
        self.R = np.eye(2*model.K) * 1e3
        self.consistency = 0; self.bad_count = 0

    def observe(self, theta_m, theta_j, tau, direction):
        r = theta_j - self.shadow.predict(theta_m, tau, direction)
        phi = self.shadow.fourier_features(theta_m)
        dTheta = np.clip(self._rls(phi, r), -self.rho, self.rho)   # 护栏①
        cand = project_passive(self.shadow.theta_fast + dTheta)    # 护栏②
        if residual_energy(cand) <= residual_energy(self.shadow.theta_fast) + 1e-9:
            self.shadow.set_theta_fast(cand)                       # 护栏③
        self.consistency = self.consistency + 1 if abs(r) <= EPS_R else 0
        if self.consistency >= self.N_cons:
            self.active = copy.deepcopy(self.shadow)
            self.consistency = 0; self.bad_count = 0
        self.bad_count = self.bad_count + 1 if abs(r) > EPS_BAD else 0
        if self.bad_count >= self.M_rollback:
            self.shadow = copy.deepcopy(self.active); self.bad_count = 0
        return self.active

    def _rls(self, phi, r):
        gain = self.R @ phi / (1.0 + phi @ self.R @ phi)
        self.R = self.R - np.outer(gain, phi) @ self.R
        return gain * r
```

```python
class ExcitationAwareExplorer:
    def __init__(self, model, u_max=0.01):
        self.model = model; self.u_max = u_max
        self.FIM = np.zeros((2*model.K, 2*model.K))

    def update_fim(self, theta_window):
        Phi = np.stack([self.model.fourier_features(t) for t in theta_window])
        self.FIM += Phi.T @ Phi

    def identifiability(self):
        eig = np.linalg.eigvalsh(self.FIM + 1e-12*np.eye(self.FIM.shape[0]))
        return eig[0] / (eig[-1] + 1e-12)

    def suggest_dither(self, traj, budget):
        if budget.exhausted('excite'):
            return None
        for k in range(1, self.model.K + 1):
            if self.identifiability() < TAU_ID and self._unobservable(k):
                u = self.u_max * np.sin(k * traj.phase)
                if within_force_jerk(u, traj) and budget.allow('excite'):
                    return u
        return None
```

```python
class LearningBudget:
    def __init__(self, excite_ops=20, update_ops=100, promote_latency=0.5):
        self.limits = {'excite': excite_ops, 'update': update_ops,
                       'promote': promote_latency}
        self.used = {'excite': 0, 'update': 0, 'promote': 0.0}

    def allow(self, kind):
        return self.used[kind] < self.limits[kind]

    def consume(self, kind, amount=1):
        self.used[kind] += amount

    def exhausted(self, kind=None):
        if kind is not None:
            return self.used[kind] >= self.limits[kind]
        return any(self.exhausted(k) for k in self.limits)
```
