# 第 3 轮（灵感循环续轮；本轮灵感：「技术路线图」×「分层规划」）

> **编号说明**：状态文件基线为第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440），
> 其下为第 1 轮 **LeanGauge**（IP-310–314；定义 398–415；引理 42–45；实验 E411–E425）与 **MODGAUGE**。
> 按「在前人基础上改进」的纪律，本轮顺延为第 3 轮。
> **本轮纪律**：不造更大的闭环，不替换任何数值模块，不重复第 2 轮的「工具/先验/语义」三轴；
> 只补 ToolGauge 的两个**正交**结构性缺口：
> （1）**时间/能力维缺口**：6C 是「单盲区、单次、视界=一次修复」的短视策略，缺少 campaign 视角——
> 盲区之间有前置依赖（没有可信标定就无法信任某类探测）、能力有成熟度（TRL 式 CML）、
> 预算按 epoch 下发、且「何时停止规划、开始测量」本身无人决策；
> （2）**抽象/复用维缺口**：T-Box 在扁平的 Π_s 上搜索，没有层级分解，也没有把已成功的修复沉淀为可复用宏选项；
> 长程规划若在工具级直接搜，会组合爆炸且原始动作的收益估计噪声极大。
> MODGAUGE 五不变式、ToolGauge 的 TCV / 双层下注 / AP-Cal / P-Quarantine 全部保留；
> 6C 保留为 **L2 执行原语**，外层新增 **RM-Box + HP-Box + R-H 协同**；
> 退化链延长为 `RoadmapGauge ⇐ ToolGauge ⇐ LeanGauge ⇐ MODGAUGE`。

## 双轴与耦合（补缺口，而非重写）

| 灵感词 | ToolGauge 的结构性缺口 | 升级为 | 一句话动机 |
|---|---|---|---|
| 技术路线图 | 6C 逐盲区短视；无时间轴、无成熟度门、无依赖/里程碑；预算是静态全局的 | **RM-Box：能力路线图**（now/near/far 三层视界 + 依赖 DAG + CML 成熟度门 + 里程碑 + 跨 epoch 预算与储备） | 修复不是「打地鼠」，而是一场 campaign：先建立可信能力，才谈得上修复；有些盲区必须等另一些能力成熟 |
| 分层规划 | T-Box 在扁平工具程序上搜索；无抽象、无复用；长程规划组合爆炸 | **HP-Box：HTN 式四层分解**（campaign → workstream → 6C repair → tool program）+ 层间接口契约 + 规划库（宏选项） | 长程任务在工具级规划是指数搜索且估计噪声大；层级把「怎么修」变成可复用、可估价的子问题 |
| 耦合（涌现） | 路线图决定「做什么/何时」，层级决定「怎么做」，各自最优却可能不可行 | **R-H 协同**：层级向上回报 cost/latency/evidence 分布；路线图向下设 deadline/预算/成熟度门；滚动重规划 + VoI 战略探测 | 承诺必须落在此刻可估价的抽象层上；规划粒度与承诺视界必须匹配 |
| 序相关（新） | ToolGauge 隐含按检测顺序修复，重排顺序的合法性从未定义 | **序相关边**：显式回执交换图，非交换对加先后约束 | 重排只有在「结果可交换」时才安全；把隐藏假设变成可检查的偏序 |

**核心命题**：`RoadmapGauge = ToolGauge + RM-Box + HP-Box + R-H 协同`。
- **RM-Box** 把「逐盲区短视修复」升级为「**需求拉动 × 技术推动**的时间分层路线图」：需求侧由任务关键度 `w_s` 给出，
  技术侧由能力成熟度 `CML` 给出，路线图 = 二者在时间轴上的匹配，带依赖、里程碑与硬预算储备。
- **HP-Box** 把「扁平工具程序」升级为「**四层分解 + 层间契约 + 规划库**」：已修复方案变成带前置/后置的宏选项，
  跨盲区复用；层级可靠性由可采纳抽象保证（引理 51），复用效率由契约匹配保证（定义 443）。
- **协同**给出第三层下注 **战略注 ν（VoI）**：在 `λ`（安不安全）与 `β`（单次值不值）之上，
  增加「值不值得先花预算把路线图本身搞清楚」的决策——这是 ToolGauge 完全没有的一个动作类别。

**三条可检验主张**：
1. 相同总预算下，路线图 + 分层相对 ToolGauge 短视策略的**认证覆盖**提升 ≥ 30%，且依赖违规 = 0（E441/E444）；
2. 分层规划在最优性损失 ≤ ε_abs 下，把长程规划搜索从指数降到多项式，且规划库复用带来 ≥ 2× 的修复摊销效率（E442/E447）；
3. 「只承诺 H0 + 储备 + 失效谓词」使超支率与「纸面能力」锁定率 ≤ 5%，滚动重规划抖动受噪声/滞回界控制（E445/E449/引理 54）。

**不变式保持声明**：
- MODGAUGE 五不变式全部保留；
- 主张绑定扩展：路线图里程碑的主张必须引用有效回执与门通过证据，否则序列化时剥离；路线图**假设**必须带失效谓词（定义 441）；
- **严格退化链延长**：RM/HP 失效（不可行/超时/证书失效）⇒ 退回 ToolGauge 短视 6C ⇒ 再失效 ⇒ LeanGauge ⇒ MODGAUGE。
  任何降级写 RED 日志与能力声明。路线图是增强项，不是依赖项。

## 0. 直觉与动机

**灵感 1（技术路线图 → 修复是一场 campaign，不是一次抢修）**
直觉：第 2 轮的 6C 像一个随叫随到的抢修队：发现一个盲区，就跑一遍 6C。但真实部署更像一家公司在做技术规划：
(a) 有**时间分层**——现在必须做什么（H0）、近期准备做什么（H1）、远期押注什么（H2）；
(b) 有**能力成熟度**——一项技术从「知道可能有用」到「可信任地使用」要过若干 TRL 式门，不能跳级；
(c) 有**依赖与里程碑**——没有可靠标定能力，就无法信任某类探测；某些修复必须先解锁前置能力；
(d) 有**预算与储备**——预算按阶段下发，远期只能给带区间的预测，不能提前承诺干净；
(e) 有**需求拉动 vs 技术推动**——不是所有盲区都值得修，路线图要把「任务真正在乎的盲区」与「技术已经成熟的能力」对齐。
把这些搬进计量系统，就得到 **RM-Box**：它优化的不是「下一个探哪」，而是
「**在未来几个时间桶里，把哪些盲区推进到哪一级成熟度、顺序如何、预留多少**」。

**灵感 2（分层规划 → 长程任务不能在工具级直接搜）**
直觉：T-Box 在长度 ≤ 6 的工具程序上还能搜，但把视界拉长到「几周、几十个盲区」，
在工具调用级直接规划会组合爆炸，且每个原始动作的收益估计都很噪。分层规划（HTN / options / 时间抽象）的启示是
**在正确的抽象层做正确的决定**：
- L0（campaign，周级）：选能力增量与里程碑；
- L1（workstream，小时级）：把相关盲区按同一根因 / 同一 SNC 指纹打包，分配预算与顺序；
- L2（repair，秒级）：就是现有 ToolGauge 6C，单盲区；
- L3（tool program，毫秒级）：就是现有 Π_s / TCV。
层间是**契约**而非普通函数调用：L1 向 L0 承诺 cost/latency/evidence 的分布，L2 向 L1 承诺「修复或 stub + 原因」，
L3 向 L2 承诺带签名回执。只要抽象**可采纳**（抽象代价是具体代价的下界）且分解保持契约，分层规划就既可靠又不丢最优性（引理 51）；
否则用显式抽象间隙 `ε_abs` 记账。

**灵感 3（耦合 → 承诺视界必须匹配估计精度）**
直觉：如果路线图承诺到很远、而估计只在近期可靠，就会「规划得很美、执行时处处翻车」；反过来只看一步，
就退化成 ToolGauge 短视。协同的关键是：**只承诺到估计可信的视界 `H_c`，视界外只做带区间的预测**；
并允许系统花一点预算做**战略探测**——不是修盲区，而是先测「这个能力到底能不能成熟」。
这把 ToolGauge 的双层下注（`λ` 安全、`β` 单次增益）扩展为三层下注：再加 **`ν` 战略注**（这次探测对整条路线图的期望价值是否为正）。

**关键转向（相对第 2 轮）**：ToolGauge 问「这个盲区该怎么修、这次探测值不值」；
RoadmapGauge 问「**在未来几个阶段里，我们应该成为什么样的系统、先建立哪些可信能力、什么时候停止规划去测量**」。
前者是战术，后者是战略；后者只能在前者保持可审计的前提下成立。

## 1. 形式化定义（增量：定义 432–447）

**定义 432（修复任务与类型化依赖 DAG，RTD）** 修复任务
`τ = (s, ℓ, d, b_τ, deadline_τ, ĝ_τ, E_τ)`，其中 `s` 为盲区（继承定义 398），`ℓ ∈ {0,1,2,3}` 为规划层，
`b_τ` 为预算，`ĝ_τ` 为预测认证增益，`E_τ` 为所需证据。
依赖边分四类：`E_ev`（证据依赖：需前序有效回执）、`E_cap`（能力依赖：需某能力达到 CML≥k）、
`E_phys`（物理依赖：热/力/时序冲突）、`E_cal`（标定依赖：前序标定改变后序探测语义）。
RTD 是一个带类型边的 DAG；`E_phys ∪ E_cal ∪ E_ev` 中**非交换**的对直接化为先后边（见定义 445）。
RTD 是路线图与分层规划的共同骨架。

**定义 433（能力与成熟度层级 CML）** 能力 `c = (tools ⊆ T₀, calibration_contract, certified_scope)`。
成熟度 `CML(c) ∈ {0,1,2,3,4}`：
0 = UNKNOWN；1 = HYPOTHESIZED（进入共形假设集 H_s，定义 422）；2 = PROBED（有效回执且 `n_eff ≥ n_min`，定义 426）；
3 = CROSS-VALIDATED（独立回执交叉验证 + 契约回归通过，定义 421.V）；4 = CERTIFIED（热替换 + RCert + 留出重验通过，定义 441）。
`CML` 除显式失效（定义 441）外**单调不减**；它是路线图中的「技术就绪度」。
修复一个盲区，本质上是把某个能力推高一级，而不是打一个补丁。

**定义 434（分层规划空间与接口契约 HPS）** 四层 `L0 ⊃ L1 ⊃ L2 ⊃ L3`，分解算子 `δ: τ ↦ {τ_i}`。
层间接口契约 `I_ℓ = (pre_ℓ, post_ℓ, envelope_ℓ, evidence_schema_ℓ, latency_quantiles_ℓ)`：
子任务的 `post` 必须蕴含父任务的 `pre`，子任务预算之和必须在父 `envelope` 内，
父承诺的时延分位数必须由子任务时延分布复合得到（分位数不可简单相加，用保守卷积上界）。
一个分层计划**良构**，当且仅当每条分解都满足上述契约；否则该分解不可执行（fail-closed）。

**定义 435（需求剖面与路线图目标）** 需求权重 `w_s = criticality(s) · coverage_need(s)`，
由任务层给出（继承 MODGAUGE 任务覆盖）。**认证覆盖**
`C_cert(A) = Σ_{s∈A} w_s · ū_s(A) · 1[gate_s passed]`，其中 `ū_s` 为**带证书**的归一化不确定度下降
（无证书的探测不计入，只计「测过」不计「可信」）。
第 k 个 epoch 的路线图目标：
`max_{A_1..A_H} Σ_{h} γ^{h} · C_cert(A_h)`，约束：依赖、每 epoch 预算（含储备）、deadline、风险门 `λ`。

**定义 436（里程碑与成熟度门）** 里程碑 `m = (c, target_cml, deadline, required_evidence)`。
门 `G_k` 是证据谓词，要求「不能跳级」（到达 k+1 必须先满足 k）且**可撤销**：
新证据可使 `CML(c)` 回退并触发重规划（定义 441）。门是路线图的承诺单位，也是审计单位。

**定义 437（滚动分层重规划 RHR）** 重规划节奏 `T₀ ≫ T₁ ≫ T₂`：L0 每 `T₀` 或失效时；L1 每 `T₁` 或 workstream 完成/失败时；
L2 事件驱动（现有 6C）；L3 每次调用。承诺视界 `H_c`；滞回 `h`。
一致性约束：新计划与已承诺前缀的差异，只有在「失效」或 `|ΔV| > h` 时才允许。
状态 = `(committed_prefix, forecasts, open_decisions)`；`H_c` 外只存区间，不承诺。

**定义 438（路线图信息价值 VoI 与战略注 ν）** 战略探测 `p`（测的是「能力可行性/代价」，不是某个盲区）：
`ν(p) = E_z[ V(R_{k+1} | z, p) − V(R_k) ] − cost(p) − risk_penalty(p)`。
仅当 `ν(p) ≥ γ_VoI` 且通过风险门 `λ` 才执行。
与操作增益 `β_t = Ĝ_t − c_t`（定义 419）的区别：`β` 优化单次探测的信息，`ν` 优化**整条路线图的决策质量**。
三层下注：`λ`（安全）→ `β`（单次值不值）→ `ν`（路线图值不值得先搞清楚）。

**定义 439（依赖闭包与解锁前沿）** `preds⁺(τ)` 为所有前驱闭包；任务**可执行**当且仅当所有 `E_cap` 前驱已成熟、
所有 `E_ev/E_cal` 前驱已满足、预算可行。可执行集合 `A` 的极小元构成**解锁前沿** `F = min(A)`。
调度只在 `F` 上选，**永不跳级**（by construction 保证依赖违规 = 0）。

**定义 440（分层预算与承诺诚实）** 总预算 `B = Σ_h B_h + R_reserve`。
仅承诺 H0：`Σ_{committed} b_τ + R_reserve ≤ B_0`；H1/H2 只给校准区间 `q_{1−δ}(cost)`。
超承诺护栏：`Σ_{committed} b_τ + q_{1−δ}(variance) ≤ B_0 + R`。
这把第 2 轮 TB-Contract（定义 424）从单次修复预算推广到多 epoch。

**定义 441（路线图证书与失效谓词 RCert）** `RCert = (milestones, evidence_refs, A_assume, I, forecast_intervals)`：
- `A_assume`：路线图成立所依赖的假设（如「部署-预训练 TV ≤ η」「材质族在指纹库内」「标定未漂移」）；
- `I(·)`：**失效谓词**，持续求值；一旦为真 ⇒ 立即重规划或降级，并把相关里程碑标记为「未认证」。
里程碑主张必须引用有效回执与门证据，否则剥离（主张绑定的路线图扩展）。
RCert 是 RepairCert（定义 427）在时间/能力维的推广：不只证明「这次修好了」，还证明「**凭什么相信它未来仍然成立**」。

**定义 442（依赖感知退化与级联）** 若能力 `c` 在 deadline 前未过门，所有以 `E_cap` 依赖 `c` 的任务进入重规划；
无替代路径则 `stub + RED`。级联范围恰为 `c` 的下游闭包，不在闭包内的能力不受影响。
这保持「局部失败、误差局部化」，并把第 2 轮 P-Quarantine 的全局刹车细化为**沿依赖的定向降级**。

**定义 443（规划库与宏选项复用）** 规划库 `Ω = {ω_j}`，`ω = (pre, post, subplan, applicability, cost_model)`，
其中 `pre/post` 是契约，`applicability` 由 SNC 指纹与 R 格子语义匹配（定义 425），`cost_model` 由历史回执校准。
复用需**重参数化并重验后置**；若复用后交叉验证失败，则对该上下文拉黑该选项（负迁移护栏）。
规划库把「每盲区从零规划」变为「跨盲区复用规划」，是 HP-Box 的样本效率来源。

**定义 444（路线图不变式）** (i) 依赖可靠性：不得在 `E_cap` 未成熟时执行；(ii) 预算可行性（含储备）；
(iii) 成熟度单调（除显式失效）；(iv) 承诺诚实（只承诺 `H_c` 内、只承诺 H0）；(v) 证据绑定（里程碑主张引回执）；
(vi) 严格退化（定义 447）。六条不变式在每次重规划后检查，违反即 fail-closed 并回退。

**定义 445（执行序鲁棒性与序相关边）** 两个任务 `τ_i, τ_j` **可交换**，当且仅当对所有上下文，
`receipts(τ_i then τ_j) =_cert receipts(τ_j then τ_i)`（μ 在 ε 内相等、门结果相同）。
可交换对不加边；非交换对加一条先后边（顺序由物理/S­NC 证据选定）。
调度在由这些边扩张出的**线性扩展**上进行：
- 全可交换 ⇒ 退化为集合选择（只选不排）；
- 全不可交换 ⇒ 退化为纯序列（即 ToolGauge 的检测顺序）。
这条定义把「重排是否安全」从隐藏假设变成可检查的偏序，是引理 55 的基础。

**定义 446（路线图后悔分解）** `Regret_k = V*(全信息 oracle) − V(实际计划)`，分解为
`Regret = Regret_est + Regret_sched + Regret_shift`：
估计后悔（AP-Cal/MP-Φ 误差，引理 47）、调度后悔（贪心 vs 最优，引理 52/53）、
漂移后悔（sim→real 的 η，引理 47/48）。三项分别由 E444/E445/E453 度量，用于审计「路线图输给了谁」。

**定义 447（退化等价）** 令 `H=0`（单 epoch）、`depth=0`（只保留 L2/L3）、`Ω=∅`、`ν=0`、且无任何序相关边，
则路线图调度退化为按检测顺序执行 6C，其回执与契约与 ToolGauge **逐指令等价**（相同 RNG 种子下数值一致）。
这保证路线图层是纯增强、可被安全关闭。

## 2. 关键算法骨架

```python
# IP-321 RM-Box：需求拉动 × 技术推动的能力路线图
@dataclass
class Task:
```

## 3. 推导

**引理 51（分层分解的可靠性与搜索界）** 设抽象**可采纳**（抽象代价 ≤ 具体代价）且分解保持契约（定义 434）。
则：(a) 分层规划是**可靠**的——任何产出的具体计划都可行；
(b) 若每个子问题精确求解，则对抽象任务**最优**；
(c) 若抽象有间隙 `ε_abs`（抽象代价相对具体代价的乘性误差），则 `cost(hier) ≤ (1+ε_abs)·cost(flat*)`；
(d) 搜索代价从扁平 `O(b^{d_flat})` 降为 `O(Σ_ℓ f_ℓ^{d_ℓ})`；当 `d_ℓ = d_flat/D`、`f = b^{1/D}` 时为
`O(D·b^{d_flat/D})`——指数只出现在**单层深度**，而非总深度。
证明思路：对层数归纳；可采纳性给出下界，契约保持使 `pre/post` 可复合，故组合计划可行且不劣于最优的 `(1+ε_abs)` 倍。
系：路线图只需在 L0/L1 上做组合优化，L2/L3 交给已验证的 6C/TCV，避免「长程工具级搜索」。

**引理 52（路线图可行性判定与 NP-难）** (a) 路线图**可执行**当且仅当 RTD 无环、每个里程碑的 `E_cap` 前驱先成熟、
每个 epoch 前缀满足 `Σb + R_reserve ≤ B_h`；判定代价 `O(V+E)`。
(b) 路线图价值最大化包含「带先序约束的背包 / RCPSP」为特例，故一般 **NP-难**；
因此小规模用 MILP 精确求解，大规模用解锁前沿贪心 + 局部搜索，并在 E444 报告与 MILP oracle 的最优性间隙。
系：任何只调度「可执行集合」的在线算法天然满足 (a)，依赖违规 = 0。

**引理 53（前沿贪心、调度界与储备）** (a) 若依赖图为 out-forest 且收益单调子模，前沿贪心的子模近似比至少为 `(1−1/e)` 乘以调度松弛因子；
一般 DAG 无常数比保证，只能靠 MILP 对照实测间隙（E444）。
(b) 对 `m` 个并行资源的 makespan，列表调度满足 `makespan ≤ (2 − 1/m)·OPT`（Graham 界）。
(c) 若每 epoch 储备 `R ≥ q_{1−δ}(cost 波动)`，则由 union bound，单 epoch 超支概率 ≤ δ；
这是定义 440「承诺诚实」的可证部分。
证明思路：(a) 子模贪心标准结论 + 先序把可选集限制为线性扩展，松弛因子由可行集最大链长给出；
(b) Graham 界；(c) 分位数定义直接得。

**引理 54（滚动重规划的稳定性）** 设路线图价值 `V` 关于估计 `θ` 为 `L`-Lipschitz，估计误差上界 `e`，滞回 `h > 0`。
则 (a) 视界 `T` 内重规划次数 `≤ L·TV(θ)/h + T/T₀`（`TV` 为估计的总变差）；
(b) 已承诺前缀的计划抖动 `≤ L·e/h`；
(c) 在平稳环境（`TV(θ)=0`）下不发生振荡重规划。
证明：每次重规划需 `|ΔV| > h`，故次数被总变差除以 `h` 界定；抖动由 Lipschitz 性直接得；平稳时 `ΔV=0 < h`，不触发。

**引理 55（路线图层不破坏热替换与退化等价）** (a) RM/HP 只对已审计操作做**排序与分解**，
任何重排都在定义 445 的线性扩展内进行，故回执/契约在证书等价意义下不变；不引入新的数值路径。
(b) 关闭路线图（`H=0, depth=0, Ω=∅, ν=0`，无边）⇒ 检测顺序 ToolGauge，
故第 2 轮引理 49/50 与 MODGAUGE 五不变式全部保持。
(c) 失败经定义 442 级联到严格退化链，不出现「半升级」状态。
系 55.1：sim→real 偏移 `η` 进入路线图后悔为 `≤ L·η`（每个里程碑），
由失效谓词与 P-Quarantine 限制累积；`η` 由 E453 实测。

**引理 56（VoI 战略注的后悔不增性）** 若战略探测 `p` 的观测 `z` 只影响后续路线图决策、
且 `ν(p) ≥ γ_VoI > 0`，则执行 `p` 后的期望路线图后悔不高于不执行时的后悔减 `γ_VoI`
（在不改变风险门可行域的前提下）。
证明：VoI 定义为期望价值增量减代价，非负即期望后悔下降；风险门保证可行域不扩大。
系：战略探测是「用少量预算买决策质量」，但不能突破 `λ` 安全门，与 ToolGauge 的物理安全语义一致。

## 2. 形式化定义（要点）

**定义 432（RTD）** 修复任务是带类型边的 DAG；`E_cap` 需前驱能力达 CML≥k，`E_ev` 需前驱回执，`E_phys` 捕捉热/力/时序冲突，`E_cal` 捕捉标定改变语义。
**定义 433（CML）** 五级成熟度，单调不减（除显式失效）；修复 = 把能力推高一级，而非打补丁。
**定义 434（HPS）** 四层分解；子 post 蕴含父 pre、子预算和 ≤ 父 envelope、时延分位数用保守卷积复合；不满足即 fail-closed。
**定义 435（路线图目标）** `max Σ_h γ^h C_cert(A_h)`，约束依赖、预算（含储备）、deadline、风险门 `λ`；`C_cert` 只计带证书的下降。
**定义 436（门）** 门是证据谓词，不能跳级且可撤销；是承诺与审计的单位。
**定义 437（RHR）** 分层节奏 + 承诺视界 `H_c` + 滞回 `h`；`H_c` 外只存区间。
**定义 438（VoI/ν）** `ν(p)=E[V(R_{k+1}|z,p)−V(R_k)]−cost−risk`；`ν≥γ_VoI` 且过 `λ` 才执行；与 `β` 正交。
**定义 439（解锁前沿）** 只调度可执行集合的极小元，by construction 依赖违规 = 0。
**定义 440（预算诚实）** 只承诺 H0；`Σcommitted + R_reserve ≤ B_0`；H1/H2 只给校准区间。
**定义 441（RCert）** 里程碑证据 + 假设集 + 失效谓词 + 预测区间；主张无回执即剥离；假设违反即降级/重规划。
**定义 442（级联退化）** 能力未过门 ⇒ 沿 `E_cap` 下游闭包重规划；无替代 ⇒ stub+RED；闭包外不受影响。
**定义 443（规划库）** 宏选项 + 契约匹配 + 重验后置 + 负迁移拉黑。
**定义 444（六不变式）** 依赖可靠 / 预算可行 / 成熟度单调 / 承诺诚实 / 证据绑定 / 严格退化。

**定义 447（退化等价）** `H=0,depth=0,Ω=∅,ν=0,无边` ⇒ 检测顺序 ToolGauge，逐指令等价。

```python
# IP-321 RM-Box
class RMBox:
    def plan(self, demand, caps, budget, horizon, library):
        cand = self.expand(demand, caps)
        dag  = self.add_typed_deps(self.add_order_edges(cand), caps)
        order = (self.solve_milp(dag, budget, horizon)
                 if self.small(dag) else
                 self.frontier_greedy(dag, budget, horizon))
        return Roadmap(order, self.gates(order), self.reserve(order), self.assumptions(order))
    def reserve(self, plan):
        return quantile_forecast(plan.cost_var, delta=0.05)   # 定义 440

# IP-322 HP-Box：HTN 四层 + 规划库
class HPBox:
    def decompose(self, task):
        if task.level == 3: return [ToolProgram(task)]        # Π_s / TCV
        if task.level == 2: return [SixC(task.s)]             # ToolGauge 6C
        for opt in self.library.match(task):
            if self.valid_contract(opt, task):
                return self.instantiate(opt, task)
        return self.bounded_search(task)
    def deposit(self, task, receipts):
        self.library.add(MacroOption.from_trace(task, receipts))

def roadmap_step(R, k):
    if R.invalidated(): return R.replan(level=0)              # 定义 441
    p = R.voi_probe_candidate()                               # 定义 438
    if p and p.voi >= GAMMA_VOI and R.risk_gate(p):
        p.execute(); return R
    t = R.scheduler.next_committed()                          # 只承诺 H_c 内
    run_hierarchical(t, R.hpbox)                              # L1→L2→L3

        R.milestone(t); R.hpbox.deposit(t)
    return R
```

## 4. 推导

**引理 51（分层可靠性与搜索界）** 可采纳抽象 + 契约保持 ⇒ 分层计划可靠；精确子解 ⇒ 抽象最优；间隙 `ε_abs` ⇒ `cost(hier) ≤ (1+ε_abs)cost(flat*)`；
搜索从 `O(b^{d_flat})` 降为 `O(Σ_ℓ f_ℓ^{d_ℓ})`，当 `d_ℓ=d_flat/D` 时为 `O(D·b^{d_flat/D})`——指数只在单层深度。
**引理 52（可行性与 NP-难）** 可行性判定 `O(V+E)`（无环 + 门前驱 + 前缀预算 + 储备）；价值最大化含先序约束背包/RCPSP 为特例 ⇒ NP-难；
小规模 MILP，大规模前沿贪心 + 实测间隙（E444）。
**引理 53（前沿贪心与调度界）** out-forest + 单调子模时前沿贪心有子模近似比 × 调度松弛因子；一般 DAG 无常数比；
`m` 资源列表调度 `makespan ≤ (2−1/m)OPT`（Graham）；储备 `R≥q_{1−δ}` ⇒ 单 epoch 超支 ≤ δ。
**引理 54（滚动重规划稳定性）** `V` 为 `L`-Lipschitz、误差 `e`、滞回 `h`：重规划次数 `≤ L·TV(θ)/h + T/T₀`；
承诺前缀抖动 `≤ L·e/h`；平稳环境不振荡。
**引理 55（不破坏热替换/退化等价）** RM/HP 只排序与分解已审计操作；重排在线性扩展内 ⇒ 回执/契约证书等价不变；
关闭路线图 ⇒ 检测顺序 ToolGauge，引理 49/50 与五不变式保持；失败经定义 442 严格退化。系 55.1：`η` 进入后悔 `≤ L·η`。
**引理 56（VoI 后悔不增）** `ν≥γ_VoI>0` 且不扩风险可行域 ⇒ 执行战略探测后的期望后悔下降至少 `γ_VoI`。

## 8. 本轮最大风险

**一句话**：RM-Box/HP-Box 用**被规划系统自己的估计**（AP-Cal 先验、`Ĝ`、门证据）来规划它自己，
分层抽象会把系统性高估逐层「洗白」——每层只看本地契约都报「可行」，
于是预算被锁定在一个永远到不了 CML-4 的「纸面能力」上，且因为只承诺 H0，失败暴露得晚、沉没成本大
（E444/E449/E451 为证伪，VoI 战略探测 + 独立门证据 + 失效谓词 + 硬储备为缓解）。
