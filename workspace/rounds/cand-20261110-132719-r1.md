# 第 44 轮（新循环第 4 轮） · Risk-Budgeted Competitive Autonomy：把「自主导航」与「竞赛策略」纳入可验证风险预算闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 把「个性化」与「并发」纳入证书闭环，但它仍压着两个更深的单点假设：**(H3) 导航 = 已知地图上的可达性问题**——所有证书查表都默认地图、定位、动力学前提是给定的、精确的；真实自主导航是**在线探索 + 定位退化 + 地图不确定**的在线问题，证书的「前提」本身带不确定性且会漂移，硬 sound 证书会因前提失真而静默失效。**(H4) 目标 = worst-case 不违例**——但竞赛是**计分对抗**，目标是在灾难风险有界的前提下**最大化期望得分**；永远回退「纯收缩 + 串行监控」的机器人虽然安全，却必然输掉比赛。本轮灵感词「自主导航」「竞赛策略」精确命中这两个假设：**自主导航**把证书前提显式化为**概率前提**，用 chance-constrained 证书 + 前提监控替代硬 sound 证书；**竞赛策略**把目标从「不违例」升级为「在灾难风险预算 Δ 下最大化期望得分」，用风险预算分配 + 约束 MDP + 对手博弈，让「有算计的冒险」成为**可验证的合法动作**。二者耦合处（探索 × 冒险 × 对手）是本轮真正的新问题：风险预算在分布漂移与级联失效下**不可加、不可单次验证**。

## 0. 直觉与动机

**灵感 1（自主导航 → 「证书的前提也是变量」，硬 sound 让位于 chance-constrained）**：直觉上，v20 的证书是一张「只要地图对、定位准、动力学对，就保证安全」的凭证；可自主导航的机器人恰恰是在**地图不全、定位会飘**的情况下行动。地图误差、定位协方差、地面摩擦变化都不是噪声，而是证书的**前提变量**。于是把证书从 C=(I, sound) 升级为 **C_δ=(I_δ, δ, prem)**：只要前提 prem 落在校准域内，机器人以 ≥1−δ 的概率留在 I_δ。硬 sound 只是 δ=0 的极限特例。代价是必须新增**前提监控器**——持续检验地图/定位是否偏离校准域，一旦偏离则证书失效、自动降级（回到硬约束或保守收缩）。一句话：**证书不再是「真」，而是「以概率 1−δ 真，且前提可监控」**。

**灵感 2（竞赛策略 → 「安全是约束不是目标」，风险预算是可花费的资源）**：直觉上，比赛里「全程龟速」不会撞，但会输。真正要优化的是**得分**（时间、任务完成度、风格分），安全是**约束**而非目标。于是引入**全局灾难风险预算 Δ**（如每次比赛 ≤10⁻³ 的灾难概率），策略层把 Δ 分配到各阶段：探索、转场、得分动作。一个「冒险超车」只要其**边际灾难概率**乘以**灾难损失**小于其**期望得分增益**，且剩余预算足够，就是**合法且最优**的。这把「安全 vs 得分」从哲学争论变成**约束优化**：max E[score] s.t. Σδ_p ≤ Δ。一句话：**收缩保底，冒险要预算，预算按边际收益分配**。

**灵感 3（耦合 → 「认证探索」与「对手博弈」）**：自主导航必须探索（否则拿不到分），但探索会消耗风险预算、削弱证书置信度。解药是**认证探索**：只在「存在一条认证撤退路径」的前沿内扩张（certified retreat invariant），把「迷路/被困」这类灾难挡在预算之外。竞赛还意味着**对手**：对手可预测（低熵）就**策略性利用**其预测轨迹抢分，不可预测就退回 robust reachability。于是对手也像 v20 的人格一样被建模成**策略契约 Π_o**，交互证书在「worst-case robust」与「nominal exploit + 风险预算」之间按对手熵自适应切换。

**耦合升级**：RBS（风险预算策略器）负责把 Δ 分配到阶段并选 safe/aggressive 模式；CNC（chance-constrained 导航证书）负责在概率前提下签发 C_δ 并监控前提；CEP（认证探索规划器）保证探索始终带认证撤退；OIG（对手博弈器）把对手策略契约纳入交互证书。四层架构由 v8 的「个性化 + 并发证书层」升级为 v9 的「个性化 + 并发 + **风险预算策略层** + **概率前提证书层**」。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（Chance-constrained 导航证书）**：导航证书 C_δ = (I_δ, δ, prem)，prem = (M̂, Σ_loc, f̂) 为地图、定位协方差、动力学模型及其校准域。**保证**：若 prem 在校准域内，则 P(∀t≤T: x_t ∈ I_δ | prem) ≥ 1−δ。**前提监控**：定义前提偏差 d_prem(t)=||(M̂−M_true, Σ_loc−Σ_true, f̂−f_true)||，当 d_prem > d_max(δ) 时证书失效。**命题（硬 sound 是特例）**：δ=0 且 d_max=0 时 C_δ 退化为 v20 的硬证书。**注**：chance constraint 用（按阶段分层的）共形/协方差传播校准，与定义 39 的共形意图共享秩统计工具。

**定义 45（灾难风险预算与策略分配）**：全局灾难风险预算 Δ ∈ (0,1)（每次比赛允许的灾难概率上界）。把比赛划分为阶段 p∈P，分配 δ_p，满足 **Σ_p δ_p ≤ Δ** 且 **δ_p ≥ δ_floor**（不可压缩的硬件/未知未知底噪）。风险分配解：max_{δ_p} E[score | δ_p] s.t. Σδ_p ≤ Δ, δ_p ≥ δ_floor。**可加性前提**：阶段失效事件近似独立（否则见定义 49 的相关性修正）。**推论**：若某阶段边际得分增益/边际风险比最高，则预算向它倾斜——这正是「有算计的冒险」的形式化。

**定义 46（竞赛目标 = 约束 MDP / CMDP）**：M=(S,A,P,r,s_0,γ)，目标 max_π E[Σγ^t r_t] s.t. (i) P(catastrophe) ≤ Δ；(ii) 每步硬 CBF/CAR 约束（v20 不变式 I 保持）。用拉格朗日/风险预算动态规划求解：L(π,λ)=E[Σγ^t r_t] − λ(P(catastrophe)−Δ)。**定理（安全-得分分解）**：若硬约束集非空，则 CMDP 的最优策略可分解为「硬约束守卫（v20）× 软目标策略（本层）」，即安全证书与策略优化正交、互不污染。**注**：这把 v20 的「证书」从目标降为约束，是范式的关键一步。

**定义 47（认证探索与撤退不变式）**：已知安全区 S_safe 与认证撤退关系 R_retreat ⊆ S×S（(s,s')∈R_retreat 表示从 s 存在认证路径回到 s'∈S_safe）。**认证前沿** F_c = {s ∉ S_safe : ∃s'∈S_safe, (s,s')∈R_retreat ∧ path(s→s') 证书有效}。探索策略只在 F_c 内扩张新前沿。**命题（防困）**：若策略只进入 F_c，则机器人任何时刻都存在认证撤退，故「被困/迷路」类灾难被结构性排除，不消耗 Δ。**代价**：F_c 比名义可达域小，探索更保守，需要用定义 45 的预算去「买」更激进的探索（缩短撤退路径要求换更大 δ）。

**定义 48（对手策略契约与博弈证书）**：对手 o 的策略契约 Π_o（与定义 38 的人格契约同构）：允许轨迹集、可预测性熵 H_o、交互风格。**博弈安全集** G(Π_o)=最大集合，使得 ∀π_o∈Π_o，∃a 使状态留在 G 内（robust reachability）。**自适应切换**：若 H_o ≤ H_low（对手可预测），允许用 nominal 预测轨迹做**策略性利用**（抢位、封堵），其额外风险由 δ_p 支付；若 H_o > H_high，退回 G(Π_o) 的 robust 证书。**命题**：利用模式只在「预测误差落在校准域」时 sound（与定义 44 前提监控同构），预测失效即回退 robust。

**定义 49（预算相关性修正与级联失效）**：阶段失效并非独立——一次定位丢失可能同时击穿转场与得分动作。定义相关性因子 ρ∈[0,1] 与级联图 G_casc。**保守预算**：Δ_eff = Δ/(1+(|P|−1)ρ)，或按最大割/连通分量做 union bound 修正：Σ_p δ_p + Σ_{(p,q)∈G_casc} δ_pq ≤ Δ。**命题（预算 sound 性）**：若用 G_casc 上的一致 union bound 分配，则总灾难概率 ≤ Δ，与独立性假设无关。**代价**：相关性越强，可用预算越少、策略越保守——这是「预算不是免费午餐」的数学表达。

## 2. 四大新增产出与既有 IP 升级

### 2.1 IP-60 RISK-BUDGET-STRATEGIST（风险预算策略器 RBS）
1. **预算分配**：按阶段边际得分/风险比分配 δ_p，含 δ_floor 与相关性修正 Δ_eff。
2. **模式选择**：safe / aggressive 双模式，按剩余预算 + 得分赤字 + 对手熵切换。
3. **CMDP 求解**：拉格朗日对偶 + 风险预算 DP，输出软目标策略（硬约束由 v20 守卫兜底）。
4. **预算审计**：实时记录已花/剩余预算与级联图，任何超支即强制 safe 模式。

### 2.2 IP-61 CHANCE-CONSTRAINED-NAV-CERT（概率导航证书 CNC）
1. **概率前提建模**：地图 M̂、定位 Σ_loc、动力学 f̂ 的校准域与偏差度量。
2. **C_δ 签发**：分层共形/协方差传播给 I_δ 与 δ，复用 v20 的 L0/L1 查表。
3. **前提监控器**：在线检测 d_prem > d_max，失效即证书作废并单调降级。
4. **硬/软双轨**：δ=0 的硬证书轨道永久保留，作为 chance 轨道失效的底线。

### 2.3 IP-62 CERTIFIED-EXPLORATION-PLANNER（认证探索规划器 CEP）
1. **撤退关系构建**：在线维护 R_retreat 与 S_safe，增量更新。
2. **认证前沿扩张**：只在 F_c 内探索，防止被困。
3. **探索-利用调度**：按「前沿信息增益 / 撤退代价」排序，与 RBS 的预算联动。
4. **撤退证书刷新**：探索越深，撤退路径越长，需定期重签租约（复用定义 41）。

### 2.4 IP-63 OPPONENT-INTENT-GAME（对手博弈器 OIG）
1. **对手策略契约**：在线估计 Π_o、轨迹集与熵 H_o。
2. **robust/exploit 切换**：按 H_o 在博弈安全集 G(Π_o) 与 nominal 利用间切换。
3. **多对手扩展**：多人博弈的联合安全集与优先级。
4. **反事实审计**：记录「若当时用 robust 会怎样」，量化利用模式的后悔值。

## 4. 实验设计（E95–E102 硬门槛，承接 E87–E94）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E95 chance 证书 soundness | 实机/仿真违例率 vs 标称 δ；前提监控漏报 | 实测 ≤ δ·1.2；0 起 |
| E96 前提监控 | 地图/定位退化检出率；失效降级时延 | ≥95%；< 100ms |
| E97 风险预算分配 | 得分 vs 固定保守基线；总灾难率 ≤ Δ；预算超支 | 提升 ≥10pp；成立；0 起 |
| E98 认证探索 | 被困/迷路事件；撤退路径存在率；探索覆盖率 | 0 起；100%；≥90% 名义 |
| E99 对手博弈 | robust 模式违例；利用模式后悔值；对手熵估计误差 | 0 起；< 5% 得分；< 20% |
| E100 相关性/级联 | 级联预算修正后灾难率；独立性假设违背率 | ≤ Δ；被正确检出 |
| E101 CMDP 分解 | 硬约束违例；软目标 vs 无约束最优的 gap | 0 起；< 10% |
| E102 长时程竞赛 | 完整比赛多次运行的灾难率；得分稳定性；预算耗尽率 | ≤ Δ；方差达标；< 10% |

回退：E95 chance 失真 → 关闭 chance 轨道，仅用 δ=0 硬证书；E96 前提监控漏报 → 缩短前提有效期、提高重检频率；E97 预算超支 → Δ 收紧 + 强制 safe；E98 探索被困 → 退回只在 S_safe 内活动；E99 利用后悔过大 → 只用 robust；E100 相关性失控 → 全用最坏 union bound（Δ_eff 极小）；任何红线失败 → 熔断回退 v20 的纯安全闭环（放弃竞赛得分优化）。

## 5. 本轮最大风险

**一句话**：风险预算 Δ 与 chance 约束 δ 都是**统计量**，需要多次独立同分布试验才能验证，而竞赛是**单次、分布漂移、对手自适应**的实现——预算的「可加性」在级联失效下失效、δ 的校准在训练/比赛分布漂移下失真，导致「账面安全（Σδ≤Δ）但实际灾难超预算」的**静默超支**；因此 E95（实测 δ）、E100（级联修正）、E102（单次比赛灾难率）必须设为红线，且默认回退到 δ=0 硬证书 + 只在 S_safe 内活动的**永不失 sound 的保守竞赛策略**。

## 2. 关键算法（伪代码）

### IP-60 RBS：预算分配、模式选择与 CMDP 分解
```
def allocate_risk_budget(phases, score_model, Delta, delta_floor, cascade):
    rho = estimate_correlation(cascade)            # 定义 49
    Delta_eff = Delta / (1 + len(phases) * rho)    # 保守相关性修正
    delta = {p: delta_floor for p in phases}
    budget = max(0.0, Delta_eff - sum(delta.values()))
    # 贪心/对偶：按边际得分增益 / 边际风险排序
    for p in sorted(phases, key=lambda q: marginal_gain_per_risk(q, score_model),
                    reverse=True):
        spend = min(budget, desired_delta(p))
        delta[p] += spend; budget -= spend
        if budget <= 1e-12: break
    return delta, Delta_eff

def select_mode(state, remaining, deficit, H_o):
    if remaining <= 0 or not premise_valid(state.prem):
        return SAFE                                  # 超支/前提失效 => 强制安全
    if deficit > 0 and H_o <= H_LOW and marginal_ok(state, remaining):
        return AGGRESSIVE                            # 有算计的冒险
    return SAFE

def cmdp_act(state, lam, hard_guard):
    if not hard_guard.holds(state):                  # v20 硬约束兜底
        return hard_guard.safe_action(state)
    # 软目标：max r − λ·risk；λ 由剩余预算动态更新
    return soft_policy(state, lam)

def audit_budget(spent, Delta, cascade):
    if spent + cascade_risk(cascade) > Delta:
        force_mode(SAFE); return False               # 任何超支即降级
    return True
```

### IP-61 CNC：概率证书签发与前提监控
```
def issue_chance_cert(x, prem, delta, horizon):
    if premise_deviation(prem) > d_max(delta):
        return None                                  # 前提失效 => 只走硬轨道
    I_delta = robust_invariant_prob(x, prem, delta, horizon)  # 共形/协方差传播
    return Cert(I_delta, delta, prem)

def premise_monitor(prem, calib, t):
    d = deviation(prem, calib)                        # 地图/定位/动力学联合偏差
    if d > d_max(prem.delta):
        degrade_monotone()                            # 证书作废，单调降级
        return False
    return True

def certify_branch_v9(branch, prem, delta):
    hard = certify_hard(branch)                       # v20 硬证书，永远保留
    chance = issue_chance_cert(branch.x, prem, delta, branch.horizon)
    if chance is None:
        return hard                                   # 硬轨道兜底
    return relax(hard, chance) if budget_available() else hard
```

### IP-62 CEP：认证探索与撤退不变式
```
def certified_frontier(frontier, retreat_rel, S_safe):
    return [s for s in frontier
            if has_certified_retreat(s, retreat_rel, S_safe)]

def certified_explore(frontier, retreat_rel, S_safe, budget):
    F_c = certified_frontier(frontier, retreat_rel, S_safe)
    ranked = sorted(F_c, key=lambda s: info_gain(s) / retreat_cost(s), reverse=True)
    for s in ranked:
        if retreat_cost(s) <= budget.remaining_retreat():
            return s                                  # 只进可认证撤退的前沿
    return None                                       # 无认证前沿 => 停/回撤

def refresh_retreat_lease(paths, t):
    for p in paths:
        if not lease_valid(p.lease, p.theta, t):      # 复用定义 41 租约
            p.lease = reissue_lease(p)                # 深探索需定期重签
```

### IP-63 OIG：对手契约与 robust/exploit 切换
```
def opponent_mode(Pi_o_est, H_o):
    if H_o > H_HIGH:
        return ROBUST                                 # 不可预测 => robust 可达
    if H_o <= H_LOW:
        return EXPLOIT                                # 可预测 => 策略性利用
    return ROBUST                                     # 中间地带保守

def game_certificate(state, Pi_o, mode, delta_p):
    if mode == ROBUST:
        return robust_reachability(state, Pi_o)       # ∀pi_o∈Π_o
    pred = nominal_trajectory(Pi_o)                   # 预测前提需校准
    if prediction_error(pred) > d_max(delta_p):
        return robust_reachability(state, Pi_o)       # 预测失真 => 回退
    return exploit_certificate(state, pred)           # 风险由 δ_p 支付

def counterfactual_regret(log):
    return sum(robust_score(e) - chosen_score(e) for e in log)
```

## 6. 本轮最大风险

**一句话**：风险预算 Δ 与 chance 约束 δ 都是**统计量**，需要多次独立同分布试验才能验证，而竞赛是**单次、分布漂移、对手自适应**的实现——预算的「可加性」在级联失效下失效、δ 的校准在训练/比赛分布漂移下失真，导致「账面安全（Σδ≤Δ）但实际灾难超预算」的**静默超支**；因此 E95（实测 δ）、E100（级联修正）、E102（单次比赛灾难率）必须设为红线，且默认回退到 δ=0 硬证书 + 只在 S_safe 内活动的**永不失 sound 的保守竞赛策略**。
