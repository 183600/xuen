# 第 68 轮（承接第 67 轮「SimRAS 仿真增强风险闭环」IP-233~242；灵感循环第 1 轮；本轮灵感：「力矩控制」×「多模态大模型」）

> 第 67 轮 SimRAS 把 RAS 从「在线反应式情绪闭环」升级为「离线仿真预训练 + 在线世界模型推理 + 视觉问答审计」的三层结构，核心资产是一个能滚动预测「情绪-故障」联合演化的世界模型，以及一个可解释的审计缓冲区。但 SimRAS 仍然停留在**动作块（action chunk）**的抽象层：它决定「下一步做什么」，却不决定「这一步用多大力、以多大刚度去接触」。而真实具身任务的风险，恰恰发生在**力矩环**——夹碎杯子、拉倒抽屉、人机交接时的挤压、插装时的卡死，都是毫秒级、牛顿级的物理事件。
>
> 本轮灵感的核心命题是：
>
> **把多模态大模型的语义/常识先验，通过「阻抗意图」这一物理接口，接地到 1kHz 的力矩控制；再用「扭矩证书 + 扭矩残差归因」保证模型不会说出做不到、或做出来危险的话。——TORQ：Torque-grounded Reasoning & Qualification。**
>
> TORQ 不追求「大模型直接输出力矩」（那是拿 10Hz 的语义模型去冒充 1kHz 的物理控制器），而是坚持**双时间尺度**：慢环路（≤10Hz）只产出可认证的阻抗意图，快环路（1kHz）在证书投影后的安全集内做力矩跟踪。**安全由投影与证书保证，性能由大模型提供**——这是 TORQ 与端到端 VLA 最根本的分野。

## 0. 直觉与动机

**灵感 1（力矩控制 → 具身智能的「最后一毫米」）**
直觉：动作块决定轨迹，力矩环决定「接触的质感」。同样是「把杯子放到桌上」，位置控制会在接触瞬间产生冲击；阻抗控制会让手腕在触桌时变软；而力矩控制甚至能感知「桌面是硬的还是铺了桌布」。第 67 轮的世界模型能预演轨迹，却没有任何一个头预测「接触瞬间的反作用力矩」。把这个缺口补上，闭环才真正落到物理。

**灵感 2（多模态大模型 → 物理常识的「语义先验」）**
直觉：力矩控制器是「盲」的——它只知道 `τ`、`q`、`q̇`，不知道手里是鸡蛋还是扳手。多模态大模型恰好补上这一层：看图 + 读指令，就能给出「易碎 → 低刚度、低力预算」「卡住 → 先小幅回撤再增力」「有人手靠近 → 降低刚度、限速」这样的**物理常识先验**。问题只在于：怎么把这种 token 化的常识变成牛顿。

**灵感 3（阻抗 = 语义-物理接口；本轮的核心洞察）**
直觉：不要让大模型直接输出力矩。力矩是 1kHz、强耦合、必须满足无源性的量；而阻抗 `ξ = (K, D, x_d, f_max, contact_mode, a_comply)` 是一个**低维、有界、可解释、可认证**的物理对象。大模型在阻抗空间里说话，力矩控制器在扭矩空间里执行：
- 大模型说「轻拿轻放」→ 调低 `K`、`D`、`f_max`；
- 大模型说「抽屉卡住了，加力但别猛拽」→ 沿拉出轴提高 `f_max`，压低法向刚度；
- 大模型说「人手在附近」→ 切到 `contact_mode=human_near`，刚度与速度上限同时收紧。

阻抗是语义与扭矩之间的「汇率」，把不可解释的扭矩决策转成可解释的刚度/力预算决策。

**灵感 4（torque token：让大模型「看见」力矩）**
直觉：原始 `τ_{t-T:t}` 是浮点时间序列，无法直接进入语言模型的离散 token 空间。但力矩的**物理语义**是低维的：接触/自由/滑移/冲击/卡死、力级（对数分档）、是否饱和、速度区间、刚度档位。把这些量量化成有限字母表 `Ω` 上的 token 串 `w_{1:L}`，就得到一种「力矩语言」。它有三个好处：
1. **可输入**：大模型能在物理 token 空间里做跨模态推理（图 + 指令 + 力矩词 + 触觉词）；
2. **可输出**：力矩事件能被「扭矩字幕器」翻译成人话，供审计与人类监督；
3. **可对齐**：token 序列与第 67 轮的 `expression_hash`/`scene_hash` 一样可做缓存键，复用历史审计结论。

**灵感 5（双时间尺度 + 证书：慢思考，快力矩）**
直觉：大模型慢（~10Hz、百毫秒级），力矩环快（1kHz、毫秒级）。硬把两者塞进一个环，要么牺牲实时性，要么牺牲安全性。TORQ 把「思考」与「执行」彻底分层：
- **慢环路**：多模态大模型产出阻抗意图 + 理由，频率 ≤10Hz；
- **证书层**：把意图投影到「认证扭矩意图多面体」`CTIP`（无源、摩擦锥、关节/力矩限、速率限、能量罐）；
- **快环路**：1kHz 力矩 MPC 跟踪投影后的意图，并做扭矩残差归因。
这样，**即使大模型胡说，投影后的力矩仍然落在安全集内**；大模型只决定「在安全集内往哪走」，不决定「能不能越界」。

**灵感 6（四灵感合流 → TORQ）**
TORQ 是第 67 轮 SimRAS 的「最低层接地」：
1. **TTV**（Torque Token Vocabulary）：把力矩/触觉序列变成物理词；
2. **TIR + IIH**（Torque Intent Reasoner + Impedance Intent Head）：多模态大模型输出有界阻抗意图；
3. **CTIP**（Certified Torque Intent Polytope）：认证意图多面体 + 投影；
4. **FTR**（Fast Torque Realizer）：1kHz 阻抗/力矩 MPC；
5. **TRA**（Torque Residual Attribution）：把 FIR/EFS 的故障归因下沉到扭矩残差（摩擦、背隙、负载、接触、传感器偏置）；
6. **CAWM**（Contact-Aware World Model）：给 SimRAS 的世界模型加「接触头 + 扭矩头」；
7. **TCQA**（Torque Captioner & QA）：力矩字幕 + 扭矩问答审计；
8. **CAA**（Control Authority Arbiter）：按置信度在「大模型意图」与「保守基线」之间做凸仲裁；
9. **J_TORQ**：把证书延伸到扭矩层。

## 1. 形式化定义（增量：定义 266–285）

- **定义 266（TORQ 总览）**：`TORQ = (TTV, TIR, IIH, CTIP, FTR, TRA, CAWM, TCQA, CAA, J_TORQ)`。定位：把 SimRAS 的「动作块闭环」下沉为「力矩意图闭环」。不变式：慢环路（≤10Hz）只读语义、只写阻抗意图；快环路（1kHz）只执行扭矩、只写残差日志；**任何扭矩指令必须先经 `CTIP` 投影**；实时流不做学习写操作。
- **定义 267（扭矩观测量与残差）**：关节力矩观测 `τ_meas(t) ∈ ℝ^n`，指令 `τ_cmd(t)`。名义动力学 `τ_nom = M(q)q̈ + C(q,q̇)q̇ + g(q)`。扭矩残差 `r_τ(t) = τ_meas(t) - τ_nom(t) - τ_ext(t)`，其中 `τ_ext` 为已知外力估计。`r_τ` 是摩擦、背隙、负载变化、接触、传感器偏置的最灵敏载体。
- **定义 268（Torque Token Vocabulary, TTV）**：映射 `W: (τ_{t-T:t}, q, q̇, 触觉) → w_{1:L}`，其中 `w_l ∈ Ω`，`Ω = Ω_c × Ω_f × Ω_s × Ω_v × Ω_k`：
  - `Ω_c = {free, contact, slip, impact, jam}`（接触模式）；
  - `Ω_f = {0,1,…,L_f}`（力级，对数分档）；
  - `Ω_s = {normal, saturated, oscillating}`（饱和/振荡标志）；
  - `Ω_v = {v0, v1, v2}`（速度区间）；
  - `Ω_k = {soft, medium, stiff}`（当前刚度档位）。
  `TTV = (Quantizer, Grammar, Detokenizer)`，其中 Grammar 用有限状态约束 token 转移（例如 `impact` 后不允许紧接 `free`）。
- **定义 269（阻抗意图 Impedance Intent）**：`ξ = (K, D, x_d, f_max, c_mode, a_comply)`，其中 `K, D ∈ SPD_n` 为任务空间刚度/阻尼，`x_d ∈ SE(3)` 为平衡位姿，`f_max ≥ 0` 为力预算，`c_mode ∈ Ω_c` 为接触模式，`a_comply` 为顺应轴（单位向量）。`ξ` 到一个力矩策略族的映射记为 `π_ξ`。
- **定义 270（Torque Intent Reasoner, TIR）**：多模态大模型 `π_θ(ξ, z_rat | o_vis, l, w_{1:L}, w^tac)`，输入图像 `o_vis`、语言指令 `l`、力矩 token、触觉 token，输出阻抗意图分布与「物理链式理由」`z_rat`（要求带单位与量纲检查）。
- **定义 271（认证扭矩意图多面体 CTIP）**：
  ```
  CTIP = { ξ : K ⪰ ε_K I, D ⪰ 2√K（临界阻尼下界）,
               f_contact ∈ F_c(μ)（摩擦锥）, ‖f‖ ≤ f_max,
               τ(ξ) ∈ [τ_min, τ_max], |dτ/dt| ≤ τ̇_max,
               E_tank(ξ) ≥ 0（无源能量罐）,
               K ⪯ K_max(Δt_delay)（时延稳定上界） }
  ```
  在任务坐标系取对角 `K, D`、对摩擦锥做多面体内近似后，`CTIP` 是可高效投影的凸集。
- **定义 272（证书投影）**：`ξ* = Π_CTIP(ξ_0) = argmin_{ξ ∈ CTIP} ‖ξ - ξ_0‖²_Ω`，其中 `Ω` 为按物理量纲归一化的度量。若无可行解，退化为保守基线 `ξ_safe`（固定低刚度 + 低力预算）。
- **定义 273（Fast Torque Realizer, FTR）**：1kHz 阻抗/力矩 MPC：
  ```
  τ_ref = J(q)^T [ K(x_d - x) + D(ẋ_d - ẋ) + f_ff ] + g(q) + τ_fric(q, q̇)
  τ_cmd = argmin_{τ_{0:H}} Σ_i ‖τ_i - τ_ref‖²_R + ‖Δτ_i‖²_S
          s.t. τ_i ∈ [τ_min, τ_max], |Δτ_i| ≤ τ̇_max Δt, 能量罐约束
  ```
  以 warm-start 的盒子约束 QP 求解；无 QP 时退化为解析阻抗 + 饱和。
- **定义 274（扭矩残差归因 TRA）**：故障-扭矩假设集 `H_τ = {h_fric, h_backlash, h_payload, h_contact, h_bias, h_model}`，后验
  ```
  P(H_τ | r_τ) ∝ p(r_τ | H_τ) P(H_τ)
  ```
  每个假设用参数化残差模型 `r_τ = Φ_h(q, q̇, τ) β_h + ε_h` 建模，`β_h` 在线递归最小二乘更新（仅慢环路写）。
- **定义 275（Contact-Aware World Model, CAWM）**：在 SimRAS 世界模型上增加两个头：
  - `contact_head(z_t) → ĉ_{t+1} ∈ Δ^{|Ω_c|}`（接触模式分布）；
  - `torque_head(z_t) → r̂_τ(t+1) ∈ ℝ^n`（扭矩残差预测）。
  损失 `L_CAWM = L_recon + λ_c L_contact + λ_τ L_torque + λ_cons L_cons`。
- **定义 276（接地置信度）**：`conf = σ( w_e·(-H(π_TIR)) + w_a·A(ξ_TIR, ξ_base) + w_w·(-‖r̂_τ - r_τ‖) + w_c·slack_CTIP + w_o·(-OOD(w)) )`，其中 `H` 为意图熵，`A` 为与保守基线的一致性，`slack_CTIP` 为证书松弛度，`OOD` 为 token 分布外分数；`w_*` 由离线标定，使 `conf` 校准（ECE < 0.05）。
- **定义 277（控制权限仲裁 CAA）**：`λ_auth = σ(α·conf + β·slack_CTIP - γ·R_est - δ·OOD) ∈ [0,1]`。执行意图 `ξ_exec = λ_auth·ξ* + (1-λ_auth)·ξ_safe`（`K, D, x_d` 凸组合，`f_max` 取 min，`c_mode` 取更保守者）。
- **定义 278（扭矩字幕 Torque Caption）**：`TCQA: (r_τ, w_{1:L}, ξ) → c_τ`，把一段扭矩事件翻译为带单位与因果假设的自然语言（例：「t=1.2s 接触后力升到 18N 并出现 2Hz 振荡，疑似刚度偏高/摩擦锥边缘，建议降 K 20%」）。
- **定义 279（J_TORQ 证书）**：
  ```
  J_TORQ = (J_SimRAS, impedance_hash, passivity_margin,
            wrench_cone_margin, τ_sat_flag, grounding_conf,
            λ_auth, torque_token_hash)
  ```
  `Valid ⇔ Valid(J_SimRAS) ∧ passivity_margin ≥ 0 ∧ wrench_cone_margin ≥ 0 ∧ (τ_sat_flag = False ∨ λ_auth ≤ 0.5)`。
- **定义 280（在线环路不变式）**：1kHz 环只含 `FTR + TRA + 投影 + 饱和检查`；≤10Hz 环含 `TIR + CAWM + TCQA + CAA`；证书每意图签发一次；实时环零学习写操作。
- **定义 281（多模态接地损失）**：`L_ground = L_intent + λ_1 L_torque_pred + λ_2 L_contact + λ_3 L_cert + λ_4 L_rat`，其中 `L_cert` 惩罚落在 `CTIP` 外的意图，`L_rat` 用「物理链式理由」的忠实性监督（理由中的量与实测力矩一致）。
- **定义 282（物理指令微调集）**：`D_phys = {(o_vis, l, w_{1:L}, ξ*, z_rat)}`，`ξ*` 由仿真中的安全最优控制 + 人类偏好共同标注；训练时把力矩 token 作为前缀与图像 token 对齐。
- **定义 283（安全屏蔽）**：若 `conf < τ_conf` 或 `Π_CTIP` 无可行解或 `J_TORQ` 无效，则 `λ_auth ← 0`，执行 `ξ_safe` 并记录 `fallback_event`。
- **定义 284（无源能量罐）**：`E_{t+1} = E_t + Δt(P_in - P_out)`，`P_in` 为控制器注入功率，`P_out` 为耗散；要求 `E_t ≥ 0` 且 `P_out ≥ 0`，作为 `CTIP` 的一条线性约束。
- **定义 285（评测三元组）**：`M_TORQ = (GroundScore, ContactSafety, TaskSuccess)`，其中 `GroundScore` 衡量意图与真实物理量（力/质量/摩擦）的一致性，`ContactSafety` 衡量超力、滑移、冲击、人机挤压事件率，`TaskSuccess` 衡量任务完成。

# IP-243 TTV：力矩 token 化
class TorqueTokenVocabulary:
    def __init__(self, L_f=7, T=16):
        self.L_f, self.T = L_f, T
        self.grammar = ContactGrammar()

    def encode(self, tau_win, q, qd, tactile):
        c = contact_mode(tau_win, tactile)          # 5 类
        f = log_quantize(norm(tau_win), self.L_f)   # 力级
        s = 'saturated' if saturated(tau_win) else ('oscillating' if osc(tau_win) else 'normal')
        v = vel_bin(qd)
        k = stiffness_bin(current_K)
        w = [('c', c), ('f', f), ('s', s), ('v', v), ('k', k)]
        return self.grammar.filter(w)

    def decode(self, tokens):
        return reconstruct_torque(tokens)           # 供审计/重建


# IP-244/245 TIR + IIH：多模态大模型输出阻抗意图
class TorqueIntentReasoner:
    def __init__(self, mllm, tokenizer):
        self.mllm, self.tok = mllm, tokenizer

    def infer(self, img, lang, tau_tokens, tactile_tokens):
        prefix = self.tok.render(tau_tokens, tactile_tokens)
        out = self.mllm.generate(img, lang, prefix,
                                 schema=IMPEDANCE_SCHEMA)   # 结构化约束解码
        xi = ImpedanceIntent(K=out['K'], D=out['D'], x_d=out['x_d'],
                             f_max=out['f_max'], c_mode=out['c_mode'],
                             a_comply=out['a_comply'])
        return xi, out['rationale']


# IP-246 CTIP：认证投影
class CertifiedTorquePolytope:
    def project(self, xi0, model, state):
        qp = build_ctip_qp(xi0, model, state)   # 无源/摩擦锥/限幅/速率/能量罐
        xi = solve_qp(qp)
        if xi is None:
            return SAFE_BASELINE, 0.0
        return xi, ctip_slack(xi, model, state)


# IP-247 FTR：1kHz 力矩跟踪
class FastTorqueRealizer:
    def step(self, xi, state):
        tau_ref = impedance_law(xi, state) + gravity(state) + friction(state)
        tau = solve_box_qp(tau_ref, state, horizon=5)   # warm-start
        return saturate(tau, state), tau_ref


# IP-274 TRA：扭矩残差归因
class TorqueResidualAttribution:
    def update(self, r_tau, q, qd, tau):
        for h in self.hypotheses:               # 摩擦/背隙/负载/接触/偏置/模型
            h.beta = rls_update(h.beta, r_tau, h.regressor(q, qd, tau))
        return bayes_posterior(self.hypotheses, r_tau)


# IP-276/277 CAA + 证书
def arbitrate(xi_tir, xi_base, conf, slack, risk_est, ood):
    lam = sigmoid(2.0*conf + 1.5*slack - 2.0*risk_est - 1.0*ood)
    xi = convex_blend(xi_tir, xi_base, lam)
    return xi, lam


# IP-252 TORQ 在线闭环
def TORQ_slow_round(M, obs):
    img, lang, tau_win, q, qd, tactile = obs
    tokens = M.ttv.encode(tau_win, q, qd, tactile)
    xi_tir, rationale = M.tir.infer(img, lang, tokens, tactile)

    # 证书投影（慢环签发）
    xi_star, slack = M.ctip.project(xi_tir, M.model, (q, qd))
    conf = M.calibrate_conf(xi_tir, xi_star, tokens, M.cawm)
    xi_exec, lam = arbitrate(xi_star, SAFE_BASELINE, conf, slack,
                             risk_est=M.risk, ood=tokens.ood)
    if conf < M.tau_conf or slack < 0:
        xi_exec, lam = SAFE_BASELINE, 0.0
    M.current_intent = xi_exec
    M.current_auth = lam
    M.emit_certificate(xi_exec, conf, lam, rationale)
    return xi_exec, lam, conf


def TORQ_fast_step(M, q, qd, tau_meas, dt):
    xi = M.current_intent
    tau_cmd, tau_ref = M.ftr.step(xi, (q, qd))
    r_tau = tau_meas - nominal_torque(q, qd) - tau_ref
    post = M.tra.update(r_tau, q, qd, tau_cmd)     # 仅写日志，不阻塞
    if saturated(tau_cmd) or post['contact'] > 0.9:
        M.flag_contact_event(r_tau)
    return tau_cmd, r_tau, post

## 3. 推导

**引理 13（扭矩 token 化的误差界）** 设力级量化步长为 `Δ_f`、接触模式判别错误率为 `ε_c`，则 `‖τ - Dec(Enc(τ))‖ ≤ √n·Δ_f/2 + L_τ·ε_c`。若下游阻抗意图对 token 的 Lipschitz 常数为 `L_ξ`，则意图误差 `‖ξ - ξ̂‖ ≤ L_ξ(√n·Δ_f/2 + L_τ·ε_c)`。取 `Δ_f` 使力级相对误差 < 3%、`ε_c < 2%`，意图误差 < 5%。

**引理 14（投影的非扩张性与可行性）** 若 `CTIP` 为闭凸集，则 `Π_CTIP` 非扩张：`‖Π(x) - Π(y)‖ ≤ ‖x - y‖`。因此大模型意图的抖动不会被投影放大；且只要 `ξ_safe ∈ CTIP`，投影永远可行，无需「兜底不可行」分支。

**定理 14（双时间尺度稳定性）** 设慢环意图每 `T_s` 更新一次，变化率 `‖ξ_k - ξ_{k-1}‖ ≤ ρ`；快环在固定 `ξ` 下是 ISS，增益为 `g`。若 `T_f/T_s = ε ≪ 1`，则闭环状态误差满足
```
limsup_t ‖e(t)‖ ≤ O(ρ/ε + e_track)
```
即**时间尺度分离把「慢思考」的漂移隔离在 `O(ρ/ε)`**。这解释了为什么 TORQ 必须把 MLLM 放在 10Hz 而非 1kHz。

**定理 15（扭矩证书的可靠性）** 若 `ξ* ∈ CTIP` 且快环跟踪误差 `‖τ - τ_ref‖ ≤ e_max`，则
1. 无源性裕度 `passivity_margin ≥ m_0 - L_p·e_max`；
2. 摩擦锥裕度 `wrench_cone_margin ≥ m_c - L_c·e_max`；
3. 只要 `e_max < min(m_0/L_p, m_c/L_c)`，执行力矩仍在安全集内，**与 MLLM 的准确率无关**。
这是 TORQ 的核心安全论证：**安全性由「投影 + 有界跟踪」保证，不依赖对模型的信任。**

**定理 16（权限仲裁的安全-性能权衡）** 由于 `ξ_base, ξ* ∈ CTIP` 且 `CTIP` 凸，`ξ_exec = λξ* + (1-λ)ξ_base ∈ CTIP`。设大模型意图在给定观测下出错概率为 `p_err`，保守基线成功率为 `s_base`，则
```
E[unsafe] = 0（证书保证）,
E[success] ≤ λ(1-p_err) + (1-λ)s_base
```
安全性与 `λ` 解耦，性能随 `λ` 提升；`CAA` 的作用是在 `conf` 高时增大 `λ`，在 `conf` 低时退回基线。这把「该信模型多少」变成一个可标定的标量，而不是二选一。

**引理 15（扭矩残差的可辨识性）** 若摩擦、背隙、负载、接触、偏置的回归子 `Φ_h` 两两不共线，且激励满足持续激励条件，则 `TRA` 的后验可辨识：`κ_τ = λ_min(Σ_h Φ_h^T Φ_h) > 0`，各假设后验收敛到真值邻域。

## 6. 本轮最大风险

**一句话**：TORQ 的扭矩证书只保证「在给定动力学模型内安全」，而多模态大模型最容易错的恰恰是模型未覆盖的物理量（质量、摩擦、形变、接触瞬态）——一旦模型与真实失配，`CTIP` 投影会把一个语义错误的意图「洗白」成证书合格的力矩，**安全证书反而成为错误意图的背书**；这是本轮所有论证依赖的核心假设：**阻抗意图空间足以表达任务所需的物理意图，且证书所用的动力学模型与真实接触动力学足够接近。**

**次级风险与缓解**：
1. **阻抗表达力不足**：冲击、拧紧、撬动等任务需要扭矩级而非阻抗级意图 → 引入「扭矩意图补丁」`τ_ff`（前馈力矩），但仍纳入 `CTIP` 校验；
2. **摩擦锥/接触刚度失配**：用 `TRA` 在线估计摩擦与接触参数并回写证书模型；对不确定参数取鲁棒裕度（`μ` 下界、`K_c` 区间）；
3. **MLLM 慢环误判任务语义**：用 `CAA` 降低权限，并以 `TCQA` 把理由暴露给人类；
4. **token 化丢失高频信息**：保留一路原始力矩残差直连快环，token 只服务慢环；
5. **算力与成本**：7B INT4 在边缘端仍偏重 → 蒸馏到 1–3B 的「力矩专用接地模型」，或云端慢环 + 端侧快环。

# IP-252 慢环
def TORQ_slow_round(M, obs):
    img, lang, tau_win, q, qd, tactile = obs
    tokens = M.ttv.encode(tau_win, q, qd, tactile)
    xi_tir, rationale = M.tir.infer(img, lang, tokens, tactile)
    xi_star, slack = M.ctip.project(xi_tir, M.model, (q, qd))
    conf = M.calibrate_conf(xi_tir, xi_star, tokens, M.cawm)
    xi_exec, lam = arbitrate(xi_star, SAFE_BASELINE, conf, slack,
                             M.risk, tokens.ood)
    if conf < M.tau_conf or slack < 0:
        xi_exec, lam = SAFE_BASELINE, 0.0
    M.emit_certificate(xi_exec, conf, lam, rationale)
    return xi_exec, lam, conf


# IP-252 快环
def TORQ_fast_step(M, q, qd, tau_meas, dt):
    tau_cmd, tau_ref = M.ftr.step(M.current_intent, (q, qd))
    r_tau = tau_meas - nominal_torque(q, qd) - tau_ref
    post = M.tra.update(r_tau, q, qd, tau_cmd)
    if saturated(tau_cmd) or post['contact'] > 0.9:
        M.flag_contact_event(r_tau)
    return tau_cmd, r_tau, post

## 4. 推导

**引理 13（token 化误差界）** 设力级量化步长 `Δ_f`、接触模式错误率 `ε_c`，则
```
‖τ - Dec(Enc(τ))‖ ≤ √n·Δ_f/2 + L_τ·ε_c
‖ξ - ξ̂‖ ≤ L_ξ(√n·Δ_f/2 + L_τ·ε_c)
```
取力级相对误差 < 3%、`ε_c < 2%`，则意图误差 < 5%。

**引理 14（投影非扩张）** `CTIP` 闭凸 ⇒ `‖Π(x)-Π(y)‖ ≤ ‖x-y‖`。大模型意图抖动不被放大；`ξ_safe ∈ CTIP` ⇒ 投影永远可行。

**引理 15（残差可辨识）** 若 `Φ_h` 两两不共线且持续激励，则 `κ_τ = λ_min(Σ_h Φ_h^T Φ_h) > 0`，TRA 后验收敛到真值邻域。

**定理 14（双时间尺度稳定性）** 慢环变化率 `‖ξ_k-ξ_{k-1}‖ ≤ ρ`，快环固定 `ξ` 下 ISS、增益 `g`，`ε = T_f/T_s ≪ 1`，则
```
limsup_t ‖e(t)‖ ≤ O(ρ/ε + e_track)
```
时间尺度分离把慢思考漂移隔离在 `O(ρ/ε)`，解释了 MLLM 必须放 10Hz 而非 1kHz。

**定理 15（证书可靠性）** 若 `ξ*∈CTIP` 且 `‖τ-τ_ref‖≤e_max`，则
```
passivity_margin ≥ m_0 - L_p·e_max
wrench_cone_margin ≥ m_c - L_c·e_max
```
只要 `e_max < min(m_0/L_p, m_c/L_c)`，执行力矩仍在安全集内，**与 MLLM 准确率无关**。安全性由「投影 + 有界跟踪」保证，不依赖对模型的信任。

**定理 16（权限仲裁的权衡）** 因 `ξ_base,ξ*∈CTIP` 且 `CTIP` 凸，`ξ_exec ∈ CTIP`。设意图出错概率 `p_err`、基线成功率 `s_base`，则
```
E[unsafe] = 0
E[success] ≤ λ(1-p_err) + (1-λ)s_base
```
安全性解耦，性能随 `λ` 提升；CAA 在 `conf` 高时增大 `λ`，低时退回基线。

**引理 16（扭矩字幕的忠实性）** 若 TCQA 的每个因果断言都必须由一个可检验的 token/残差模式支持（结构化解析 + 证据绑定），则字幕的「无依据断言率」≤ `1 - Acc_parse`，可被审计拦截。

## 8. 本轮最大风险

**一句话**：TORQ 的扭矩证书只保证「在给定动力学模型内安全」，而多模态大模型最容易错的恰恰是模型未覆盖的物理量（质量、摩擦、形变、接触瞬态）——一旦模型与真实失配，`CTIP` 投影会把一个语义错误的意图「洗白」成证书合格的力矩，**安全证书反而成为错误意图的背书**；这是本轮所有论证依赖的核心假设：**阻抗意图空间足以表达任务所需的物理意图，且证书所用的动力学模型与真实接触动力学足够接近。**

**次级风险与缓解**：
1. **阻抗表达力不足**（冲击/拧紧/撬动需要扭矩级意图）→ 增加前馈力矩补丁 `τ_ff`，仍经 `CTIP` 校验；
2. **摩擦锥/接触刚度失配** → `TRA` 在线估计并回写证书模型，对不确定量取鲁棒裕度；
3. **慢环语义误判** → `CAA` 降权 + `TCQA` 暴露理由给人类；
4. **token 化丢失高频** → 保留一路原始残差直连快环，token 只服务慢环；
5. **边缘算力受限** → 蒸馏 1–3B 力矩专用接地模型，或云端慢环 + 端侧快环。
