# 第 69 轮（承接第 68 轮「CALM-RAS 标定感知风险自适应闭环」IP-243~252；灵感循环第 1 轮；本轮灵感：「动作空间」×「抓取规划」）

> 第 68 轮把「测量可信度」做成了在线潜变量，却在其自陈风险里留下一个结构性缺口：**被动标定对慢故障天然秩亏**。若真实故障（渐进老化、慢泄漏、缓慢松动）恰好落在 COF 的标定带宽内，且其残差签名与温漂/蠕变不可分，那么 COF 越强，故障越会被「标好」；CFA 把 H_cal 后验推高，CAC 的金标集若没覆盖该模式，坏适配器照样放行。R68 的防线（速率限制 + canary）本质上是在**频率**和**样本**两个维度上防守，防不住「同频、同签名、不同因果」的混淆。
>
> 本轮两个灵感恰好给出破局的两块拼图，而且它们是对偶的：
>
> - **「动作空间」**：可辨识性不是场景的恩赐，而是**可以被动作设计出来的**。被动观测的 Fisher 信息在「漂移 vs 故障」方向上可能恒为零；但施加一个受控的外生输入，可以把两个假设的残差均值推开。安全不该只是把动作幅度调小（R68 的 λ 缩放 / k 收缩），而应把动作空间**结构化**，在其中保留一个随不确定度方向性收缩、但永不空心的「认证动作集」。
> - **「抓取规划」**：抓取是机器人少数能同时提供**几何真值、接触力真值、运动真值**的动作，也是极少数能自带「标准件」的实验。用已知质量/几何/摩擦的参考物做一次受控抓取，就等价于给传感器做一次可溯源计量；而抓取规划天然允许「为了获得信息而抓」（主动感知/regrasp）。
>
> 核心命题：
>
> **把抓取从「任务执行原语」升级为「计量实验原语」——GAM-RAS（Grasp-Action Metrology RAS）：用受限的主动抓取制造可辨识性，用认证动作集代替标量收缩，用「不可辨识即拒答」代替「标定吸收」。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**我能不能做一个动作，让测量变得可判定**」——当被动观测无法区分漂移与故障时，系统必须选择「做一个安全的实验」或「诚实地承认不知道」，而不是假装知道。

## 0. 直觉与动机

**灵感 1（动作空间 → 安全不是把动作调小，而是把动作空间结构化）**
直觉：R68 在高不确定时统一做 `k` 收缩与 `λ` 抬升，这是把动作空间沿一个标量方向整体压扁。但在抓取任务里，「保守」并不意味着「什么都不做」：轻触、低抬升、短程移送的抓取在标定很差时仍然可能是鲁棒安全的；而某些看起来幅度很小的动作（例如在狭窄间隙里微调位姿）反而更危险。**风险是动作空间里的一个子集，不是一个标量。** 正确做法是显式构造认证动作集 `A_cert(t)`：对当前可信世界集 `W_t` 中所有可能的标定误差/故障/物性做鲁棒可行性检查，只派发落在集合内的动作；不确定度升高时集合**方向性地**收缩，而不是均匀消失。

**灵感 2（抓取规划 → 抓取是能自带标准件的受控实验）**
直觉：力传感器零偏 `b_F` 与力传感器增益故障在「空载静止」段给出完全相同的残差——这是 R68 慢故障盲区的原型。但让机器人抓取两个已知质量的标准件（例如 0.5 kg 与 1.0 kg），在准静态下比较读数：**零偏是常数偏移，增益故障是随载荷缩放的误差，非线性故障是二阶项**。一次主动抓取就把一个秩亏的辨识问题变成了超定的回归问题。抓取规划因此不只是「怎么抓住」，而是「**抓什么、用多大力、抬多高，才能使这次交互对某个假设最有信息量**」。

**灵感 3（合流 → 主动计量闭环 GAM-RAS）**
把动作空间的结构、抓取规划的物理接触、R68 的标定后验三者合成：
1. **SAG Structured Action Grammar**：把抓取动作定义为 `(预抓取位姿, 抓取位姿, 接触模式, 力曲线, 抬升/移送速度, 中止策略, 参考物标记)` 的结构化元组，并赋予度量与「激进程度」偏序；为规划、认证、审计提供共同语言；
2. **MGP Metrological Grasp Planner**：在认证集内联合优化「任务收益 + 对 `(c,H)` 的信息增益 − 探针代价」，主动生成计量抓取；
3. **OID Observability-driven Diagnosis**：用 Chernoff 信息/ Fisher 信息判定「漂移 vs 故障」当前是否可辨识；只在歧义且值得时调度探针，且探针必须来自 `A_cert`；
4. **CAF Certified Action Filter**：对可信世界集做鲁棒力闭合、间隙、接触力、可恢复性检查，输出认证动作集；用投影取代 R68 的标量 `k` 收缩；
5. **GAC Grasp Action Certificate**：每个被派发的动作携带可验证证书（鲁棒裕度、最坏接触力、中止时间、可辨识性判决、哈希），无证书不派发；
6. **拒答协议**：探针预算耗尽仍不可辨识时，输出 `H_unknown` 并强制 `λ ≥ 0.8`，**绝不默认判为 `H_cal`**——把 R68 的「静默误吸收」变成「显式不知道」。

**灵感 4（对 R68 风险的对症下药）**
- R68「慢故障落在标定带宽内被吸收」→ 引理 16 证明：若被动 Fisher 信息为零，任何被动估计器的错误概率都 ≥ 1/2；只有满足激励条件的动作能把 Chernoff 信息从 0 抬到正数。**主动探针不是锦上添花，而是可辨识性的必要条件。**
- R68「CAC 放行未覆盖的慢故障适配器」→ 定理 16 证明：GAM-RAS 下要么探针分离故障（错误概率指数下降），要么拒答；「静默地把 H_trans 认证成 H_cal」的概率被 `δ_refuse` 封顶。
- R68「高不确定时统一收缩导致任务不可用」→ 引理 18/定理 17：在标量收缩是保守内近似的假设下，认证动作集保留所有真正鲁棒可行的动作，因而在同等安全约束下任务可用性不低于 R68。
- 与 R68 的正交性：速率限制防**快**故障被吸收，主动激励防**慢**故障被混淆；两者频域/信息域互补，不互相替代。

## 1. 形式化定义（增量：定义 293–309）

**定义 293（GAM-RAS 总览与四不变式）** GAM-RAS = (SAG, MGP, OID, CAF, GAC, RAS-C†)。不变式：
(i) **认证派发**：一切进入执行器的动作 `a` 必须属于当拍认证集 `A_cert(t)`，且携带有效 GAC；
(ii) **探针有界**：探针动作满足 `f(t) ≤ f_probe`、时长 `≤ T_probe`、必须存在认证的撤退动作 `π_abort`，且每回合探针预算 `B_t ≤ B_max`；
(iii) **不可辨识即拒答**：若在预算内无法满足激励条件，输出 `H_unknown`，`λ_risk ≥ 0.8`，不得以 `H_cal` 认证；
(iv) **实时流零学习写操作**：继承 R68，一切参数更新只在影子流经 CAC 认证后原子换装。

**定义 294（结构化动作空间 SAG）** 动作 `a = (g_pre, g, κ, f(·), v, π_abort, o_ref, probe_flag) ∈ 𝒜`：
- `g_pre, g ∈ SE(3)`：预抓取与抓取位姿；`κ`：接触模式（平行夹爪/吸盘/多指）；
- `f: [0,T] → [0, f_max]`：法向力曲线；`v`：抬升与移送速度剖面；
- `π_abort`：中止/撤退策略；`o_ref`：参考物标记（无则为 `⊥`）；`probe_flag` 表示该动作是否为计量探针。
赋予度量 `d_𝒜` 与偏序 `≼_agg`（激进程度），使「保守化」可被定义为沿偏序取下界，而非标量缩放。

**定义 295（抓取鲁棒性度量）** 对世界 `w = (ξ, m, μ, β)`（物体位姿、质量、摩擦系数、接触柔顺）：
`ε_fc(a,w) = max_{λ ∈ FC(w)} min_j ( μ n_j^T λ_j − ‖t_j‖ )`（力闭合裕度）；
`ε_clr(a,w) = min_{t∈[0,T]} dist(robot(t), scene ∖ object)`（无碰间隙）；
`f_worst(a,w) = max_t ‖f(t)‖`。
对可信世界集 `W_t` 取最坏值：`ε̄_fc(a,W_t)=min_{w∈W_t} ε_fc(a,w)`，其余同理。

**定义 296（可信世界集）** `W_t = { (c,H,ξ,m,μ,β) : (c−ĉ_t)^T Σ_t^{-1} (c−ĉ_t) ≤ χ²_{12,1−δ_c}, H ∈ supp(b_t), ξ ∈ Ξ_t, m ∈ [m_lo,m_hi], μ ∈ [μ_lo,μ_hi] }`，其中 `b_t` 是 R68 CFA 的联合后验（含 `H_cal` 与 `H_sensor^trans`）。`W_t` 是「系统当前愿意为之负责的全部世界」。

**定义 297（认证动作集）** 
`A_cert(t) = { a ∈ 𝒜_free : ε̄_fc(a,W_t) > 0 ∧ ε̄_clr(a,W_t) > d_safe + κ_U·U(t) ∧ f_worst(a,W_t) ≤ f_max ∧ ∃π_abort ∈ 𝒜_free 使 T_abort(a) ≤ T_max ∧ [probe_flag ⇒ 激励条件（定义 299）成立] }`。
`𝒜_free` 为运动学/碰撞可行集。关键：`A_cert` 对 `U` 的依赖是**逐动作**的，不是全局标量。

**定义 298（残差观测模型）** 对动作 `a` 与潜在参数 `θ=(c,H)`：
`y = h(a,θ) + ν, ν ~ 𝒩(0, R_ν)`，`y` 可含六维力/力矩、触觉阵列、视觉位姿、关节电流。残差 `r(a,y) = y − h(a,ĉ,H_0)`。`h` 由 MTM 的 `wm_head` 与接触模型给出（R68 的 MTM 直接复用）。

**定义 299（可辨识性与激励条件）** 对混淆对 `θ_0=(c_drift,H_0)` 与 `θ_1=(c_0,H_trans)`：
`D_passive = D_Chernoff( p(r|a_hold,θ_0) ‖ p(r|a_hold,θ_1) )`；若 `D_passive = 0` 则称该对**被动不可辨识**。
**激励条件**：`∃ a ∈ A_cert(t), n^T I(a) n ≥ κ_I`，其中 `I(a)=E[∇_θ log p(y|a,θ) ∇_θ log p(y|a,θ)^T]` 为 Fisher 信息，`n` 为 `θ_0−θ_1` 方向。等价地 `D_Chernoff(a) ≥ κ_D`。

**定义 300（计量抓取与参考件）** 计量抓取是一类 `probe_flag=1` 的动作，满足：
(i) 与已知 `o_ref` 交互，其 `m_ref, ξ_ref, μ_ref` 的溯源不确定度 ≤ `δ_ref`；
(ii) 至少施加 `L` 个可区分的准静态载荷水平（持续激励阶数 `L`）：`L≥2` 分离零偏 vs 增益，`L≥3` 分离二次非线性；
(iii) 每个载荷水平停留 `≥ T_dwell`，使动态过渡衰减到 `ε_dyn` 以下。
候选集 `𝒜_met = {a: probe_flag ∧ L(a) ≥ 2 ∧ 参考件可用}`。

**定义 301（计量抓取规划目标）** 
`a* = argmax_{a∈A_cert ∩ 𝒜_met} [ R_task(a) + β·IG_t(a) + γ·D_Chernoff(a) − c_probe(a) ]`，
`s.t. B_t > 0, P(probe unsafe | W_t) ≤ δ_probe`。`IG_t(a) = H(b_t) − E_{y|a}[H(b_{t+1})]`，用 D-optimal 设计近似：`IG ≈ ½ log det(I + I(a)Σ_t)`。

**定义 302（OID 探针调度）** 仅当三个条件同时成立才探针：
(i) 归因歧义：`max_H P(H|r) < 1−δ_amb`；
(ii) 误归因风险高：`E_{H~b_t}[ L_attr(H, Ĥ) ] > ε_attr`（`L_attr` 为把 `H_trans` 判成 `H_cal` 的代价，显式不对称）；
(iii) 信息价值为正：`β·IG_t(a*) > c_probe(a*)`。
否则走被动路径。探针采用「先诊断、后执行」：探针结果先更新 `(c,Σ,b)`，再重新规划任务动作。

**定义 303（抓取动作证书 GAC）** `π_GAC(a) = (ε̄_fc, ε̄_clr, f_worst, T_abort, D_C, ident_verdict, W_hash, model_ver, gac_hash)`。`valid(π_GAC) ⇔` 各裕度满足红线 ∧ `ident_verdict ∈ {SEPARATED, UNKNOWN}` ∧ 哈希链完整。**无有效 GAC 的动作不得进入执行器。**

**定义 304（不可辨识拒答协议）** 若探针预算耗尽仍 `D_Chernoff < κ_D`，则：
`H ← H_unknown`，`λ_floor ← 0.8`，`k ← k_safe`（仅保留撤退/保持），并把 `(W_t, 探针日志, 未辨识方向 n)` 写入 `ℰ_gam`。语义：**拒答优于误答**；`H_unknown` 是合法输出，不是失败。

**定义 305（COF 主动观测接口）** 在 R68 的 COF 上增加探针观测对 `(a_p, y_p)`：
`Σ_t^{-1} ← Σ_t^{-1} + I(a_p)`（仅沿被激励方向）；速率限制器保留（防快故障被吸收），但**慢故障不再靠带宽区分，而靠签名区分**。探针使 `I(a_p)` 在原本秩亏的 `n` 方向满秩。

**定义 306（动作投影与风险缩放的合成）** 令 `A_task(t) = ACH.propose(·)`。派发动作：
`a_dispatch = argmax_{a ∈ A_cert(t) ∩ B_{λ}(A_task(t))} R_task(a)`，
其中 `B_λ` 为风险预算约束。R68 的 `k` 收缩被**替换**为向 `A_cert` 的投影；`λ` 仅用于对已认证动作的残余风险缩放。若 `A_cert ∩ B_λ = ∅`，进入拒答/保持。

**定义 307（AIC-GAM 干扰集）** `ℰ_GAM = ℰ_CALM × ℰ_probe × ℰ_ident`；
`ℰ_probe = {探针滑落, 探针压损, 过度激励, 探针诱发失稳}`；
`ℰ_ident = {参考件模型误差, 秩亏未检出, 伪分离, 载荷水平不足}`。

**定义 308（J_GAM 证书）** `J_GAM = (J_CALM, W_hash, action_cert_hash, D_C, probe_log, ident_verdict, gam_ver)`。`Valid ⇔ Valid(J_CALM) ∧ 全部派发动作有有效 GAC ∧ (ident_verdict=SEPARATED ∨ λ≥0.8) ∧ 探针预算/红线未越界`。

**定义 309（管线）** 离线：在仿真中构建参考物库与接触模型，标定 `R_ν, δ_ref`，训练 MTM 与 MGP 的信息增益代理；在线：R68 被动闭环 → OID 判定歧义 → MGP 规划认证探针 → COF 主动更新 → 重新归因/规划 → 派发带证书动作；影子学习与 CAC 不变。

```python
# IP-253 SAG：结构化动作空间（取代裸关节空间/裸位姿列表）
class StructuredActionGrammar:
    FIELDS = ('g_pre','g','kappa','f_profile','v_profile','abort','o_ref','probe')
    def aggressive_order(self, a, b):        # 偏序：谁更"激进"
        return (a.f_max, a.v_lift, a.clearance_need) >= (b.f_max, b.v_lift, b.clearance_need)
    def conservative_lower(self, A):        # 保守化 = 取偏序下界，而非标量乘
        return [a for a in A if all(self.aggressive_order(a, b) for b in A)]


# IP-254/255 MGP + OID：计量抓取规划与探针调度
class MetrologicalGraspPlanner:
    def plan_probe(self, W_t, refs, budget):
        cand = [a for a in self.sag.sample(refs) if a.probe]
        best = None
        for a in cand:
            Ig = 0.5*logdet(np.eye(len(W_t.theta)) + self.fisher(a, W_t) @ W_t.Sigma)
            score = self.beta*Ig + self.gamma*self.chernoff(a, W_t) - self.cost(a)
            if self.voi_positive(score) and (best is None or score > best[0]):
                best = (score, a)
        return best[1] if best else None


class ObservabilityDrivenDiagnosis:
    def ambiguous(self, b):
        return max(b.values()) < 1 - self.delta_amb

    def should_probe(self, b, W_t, budget):
        return (budget > 0 and self.ambiguous(b)
                and self.expected_attr_loss(b) > self.eps_attr
                and self.chernoff_passive(W_t) < self.kappa_D)


# IP-256/257 CAF + GAC：鲁棒认证动作集 + 动作证书
class CertifiedActionFilter:
    def certify(self, a, W_t):
        eps_fc  = min(force_closure_margin(a, w) for w in W_t.sample())
        eps_clr = min(clearance(a, w)             for w in W_t.sample())
        f_worst = max(contact_force(a, w)         for w in W_t.sample())
        abort_ok = exists_certified_retreat(a, W_t)
        return (eps_fc > 0 and eps_clr > self.d_safe + self.kU*W_t.U
                and f_worst <= self.f_max and abort_ok)

    def filter(self, A_task, W_t):
        return [a for a in A_task if self.certify(a, W_t)
                and self.gac.emit(a, W_t).valid]


# IP-258/259 拒答与保持
def refuse_or_hold(M, W_t, why):
    M.log_gam(W_t, why)                     # 写入 ℰ_gam，含未辨识方向
    return M.certified_retreat(W_t), 0.8, 'H_unknown'


# IP-260..262 主闭环：被动 CALM → 主动探针 → 认证动作
def GAM_RAS_round(M, obs):
    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)      # 沿用 R68 MTM
    r    = residuals(z, o, M.wm_residual_cache)
    c, U, thr = M.cof.passive_step(o['cal'], r, sigma_stat(M)) # 被动标定
    b    = M.cfa(r, o['pi'], c, U)                             # 被动归因

    # ---- 主动计量：只在"歧义且值得"时做 ----
    W_t = credal_set(c, U, b)
    if M.oid.should_probe(b, W_t, M.budget):
        a_p = M.mgp.plan_probe(W_t, M.scene.refs, M.budget)
        if a_p is not None and M.caf.certify(a_p, W_t):
            cert = M.gac.emit(a_p, W_t)
            if cert.valid:
                y    = M.execute_bounded(a_p, cert)            # 有界、可中止
                c, U = M.cof.active_update(a_p, y)             # 沿激励方向降熵
                b    = M.cfa.conditional(r, y, a_p, c, U)      # 重新归因
                M.budget -= 1

    # ---- 认证动作投影：取代 R68 的 k 收缩 ----
    W_t = credal_set(c, U, b)
    A_task = M.ach.propose(M.x_prime, H=max(b, key=b.get))
    A_cert = M.caf.filter(A_task, W_t)
    if not A_cert:
        return refuse_or_hold(M, W_t, why='empty_certified_set')

    a      = M.mgp.project(A_cert, A_task, thr)
    cert   = M.gac.emit(a, W_t)
    lam    = max(M.efs.risk_scale(b), thr['lam_floor'])
    tau    = M.pi_sigma.dispatch(a) * lam
    M.vqa_c.submit_async(a, cert, {'cal_event': (c, U), 'ident': cert.ident_verdict})
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit)
    return a, cert, lam, (c, U, b)
```

## 3. 推导

**引理 16（被动不可辨识定理）** 若对混淆对 `θ_0=(c_drift,H_0)`、`θ_1=(c_0,H_trans)` 有 `h(a_hold,θ_0)=h(a_hold,θ_1)` 且噪声分布同族，则 `D_passive=0`，任何仅基于被动观测的检验器错误概率下界为 `1/2`，且不随样本数 `N` 改善。存在 `a_p` 使 `h(a_p,θ_0)≠h(a_p,θ_1)` 时，`D_Chernoff(a_p)>0`，`N` 次探针的错误概率 `≤ exp(−N·D_Chernoff(a_p))`。**系**：对落在标定带宽内的慢故障，增加被动数据无用，必须改变动作；这直接解释了 R68 盲区的不可修补性。

**引理 17（安全探针可行性）** 若 `a_p ∈ A_cert(t)`，则对任意 `w∈W_t` 存在控制屏障函数 `B(a,w) ≥ 0` 且沿闭环不减；在扰动有界 `‖d‖≤d_max` 与力上限 `f_probe` 下，探针期间违反安全约束的概率 `≤ δ_W`；且存在 `π_abort` 使系统在 `T_abort` 内回到认证保持态。故探针是**可恢复实验**，而非不可逆赌博（前提：`W_t` 覆盖真实世界，见风险）。

**引理 18（认证集对保守收缩的占优）** 在假设 A95（R68 的 `(λ,k)` 标量缩放是鲁棒安全约束的一个充分但非必要条件，即 `A_R68(U) ⊆ A_cert(U)`）下，对任意 `U`：`A_R68(U) ⊆ A_cert(U) ∩ B_λ`，因此 `max_{a∈A_cert∩B_λ} R_task(a) ≥ max_{a∈A_R68} R_task(a)`。**系**：认证动作集在不降低安全性的前提下，保留了被标量收缩误杀的安全动作（轻触、低抬升、短程移送）。

**定理 16（无静默慢故障认证）** 在 A92–A95 下，若真实状态为 `H_trans` 而被动观测使其与 `H_cal` 混淆，则 GAM-RAS 满足：
`P(以 H_cal 认证 | H_trans) ≤ δ_refuse + exp(−B_max·D_Chernoff(a*))`。
即要么探针把混淆分离（错误概率指数下降），要么协议输出 `H_unknown` 并强制保守；不存在「标定吸收故障且系统自信」的路径。对比 R68：该概率无上界（由标定带宽与金标覆盖率决定）。

**定理 17（端到端安全-可用性）** 在 A87–A95 下，GAM-RAS 的输出满足：
1. `P(unsafe) ≤ α_cal + α_grasp + δ_probe + δ_refuse`；
2. 任务可用性 `≥` R68 同安全约束下的可用性（引理 18）；
3. 探针开销有界：`B_max·(T_probe + T_settle) ≤ ρ·T_episode`，`ρ ≤ 0.2`；
4. 若 `ident_verdict=UNKNOWN`，则 `λ ≥ 0.8` 且仅派发认证撤退动作——**不确定永远导向收缩，绝不导向虚假自信**。

**定理 18（计量可分离性）** 若探针施加 `L≥2` 个不同载荷水平且各水平停留 `≥T_dwell`，则在零偏+增益故障模型下，`b_F` 与增益误差的 Fisher 信息矩阵满秩；`L≥3` 时对含二次项的故障模型满秩。证明：不同载荷下的残差均值构成 Vandermonde 型设计矩阵，`L` 个互异载荷保证列满秩。**系**：R68 中「同一残差、两种因果」的秩亏，在计量抓取下被结构性消除。

## 6. 本轮最大风险

**一句话**：GAM-RAS 把安全从「被动相信测量」转移到「主动做一个物理实验」，但**探针本身是一个真实、可能不可逆的接触干预**——若参考件/接触模型有误，系统会用一个错误的「标准」去校准自己；若探针在未建模的柔顺/摩擦/遮挡下落空或压损，诊断结论与物体安全会同时失效，而证书恰恰会给这次赌博盖上「已认证」的章。

## 2. 形式化定义（要点版）

**定义 293（总览与四不变式）** 认证派发（动作 ∈ `A_cert` 且有 GAC）；探针有界（`f≤f_probe`、`T≤T_probe`、必有认证撤退、`B≤B_max`）；不可辨识即拒答（`H_unknown` 且 `λ≥0.8`）；实时流零学习写操作（继承 R68）。

**定义 294（SAG）** 动作是结构化元组；偏序 `≼_agg` 使「保守化」成为沿动作空间取下界，而非标量乘。这是与 R68 最本质的语义差别：**风险是动作空间的一个子集，不是标量**。

**定义 295–297（鲁棒裕度与认证集）** 对 `w=(ξ,m,μ,β)` 定义 `ε_fc, ε_clr, f_worst`，取 `W_t` 上最坏值；`A_cert(t)` 要求最坏力闭合 >0、最坏间隙 > `d_safe+κ_U·U`、最坏接触力 ≤ `f_max`、存在认证撤退、探针还需满足激励条件。

**定义 298–299（观测与可辨识性）** `y = h(a,θ)+ν`；混淆对 `θ_0=(c_drift,H_0)`、`θ_1=(c_0,H_trans)`；`D_passive=0` 即被动不可辨识；激励条件 `n^T I(a) n ≥ κ_I`（等价 `D_Chernoff(a)≥κ_D`）。**引理 16 说明这是必要条件，不是可选项。**

**定义 300–301（计量抓取与规划）** 计量抓取与已知 `o_ref` 交互，`L≥2` 载荷水平分离零偏/增益，`L≥3` 分离二次非线性；规划目标 `max_{A_cert∩𝒜_met} R_task+β·IG+γ·D_C−c_probe`，`IG≈½logdet(I+I(a)Σ)`。

**定义 302–304（OID / GAC / 拒答）** 仅当「歧义 ∧ 误归因代价高 ∧ 信息价值正」时探针；`π_GAC` 含鲁棒裕度、最坏力、`T_abort`、`D_C`、`ident_verdict`、哈希；预算耗尽仍不可辨识 → `H_unknown` + `λ≥0.8` + 仅撤退，并写入 `ℰ_gam`。

**定义 305–306（CALM 接口与投影）** 探针以 `Σ^{-1} += I(a_p)` 注入 COF（仅沿激励方向降熵），速率限制保留防快故障；派发 `a=argmax_{A_cert∩B_λ} R_task`，R68 的 `k` 收缩被替换为认证集投影。**快故障由带宽防、慢故障由激励防，两者正交。**

**定义 307–309（干扰集 / 证书 / 管线）** `ℰ_GAM = ℰ_CALM×ℰ_probe×ℰ_ident`；`J_GAM Valid ⇔ Valid(J_CALM) ∧ 全动作有 GAC ∧ (SEPARATED ∨ λ≥0.8) ∧ 预算红线未越界`；离线参考物库+接触模型，在线两阶段（诊断→执行），影子学习与 CAC 不变。

```python
# IP-253 SAG：结构化动作空间 + 偏序保守化
class StructuredActionGrammar:
    def conservative_lower(self, A):
        # 保守化 = 在偏序 ≼_agg 下取极小元，而非把动作整体乘 0.5
        return [a for a in A if all(self.less_aggressive(a, b) for b in A)]


# IP-254/255 MGP + OID
class MetrologicalGraspPlanner:
    def plan_probe(self, W_t, refs, budget):
        best = None
        for a in self.sag.sample(refs):
            if not a.probe: continue
            Ig   = 0.5*np.linalg.slogdet(np.eye(W_t.dim) + self.fisher(a, W_t) @ W_t.Sigma)[1]
            score = self.beta*Ig + self.gamma*self.chernoff(a, W_t) - self.cost(a)
            if score > 0 and (best is None or score > best[0]): best = (score, a)
        return best[1] if best else None


# IP-256/257 CAF + GAC：鲁棒认证 + 动作证书
class CertifiedActionFilter:
    def certify(self, a, W_t):
        eps_fc  = min(force_closure_margin(a, w) for w in W_t.samples())
        eps_clr = min(clearance(a, w)             for w in W_t.samples())
        f_worst = max(contact_force(a, w)         for w in W_t.samples())
        return (eps_fc > 0 and eps_clr > self.d_safe + self.kU*W_t.U
                and f_worst <= self.f_max and self.has_certified_retreat(a, W_t)
                and (not a.probe or self.excitation_ok(a, W_t)))

    def filter(self, A_task, W_t):
        return [a for a in A_task if self.certify(a, W_t)
                and self.gac.emit(a, W_t).valid]


# IP-259 拒答/保持
def refuse_or_hold(M, W_t, why):
    M.log_gam(W_t, why, direction=M.oid.unidentified_direction())
    return M.certified_retreat(W_t), 0.8, 'H_unknown'


# IP-260..262 主闭环：被动 CALM → 主动探针 → 认证动作投影
def GAM_RAS_round(M, obs):
    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)       # R68 MTM 复用
    r    = residuals(z, o, M.wm_residual_cache)
    c, U, thr = M.cof.passive_step(o['cal'], r, sigma_stat(M))
    b    = M.cfa(r, o['pi'], c, U)

    W_t = credal_set(c, U, b)                                    # 可信世界集
    if M.oid.should_probe(b, W_t, M.budget):                     # 歧义且值得
        a_p = M.mgp.plan_probe(W_t, M.scene.refs, M.budget)
        if a_p and M.caf.certify(a_p, W_t):
            cert = M.gac.emit(a_p, W_t)
            if cert.valid:
                y    = M.execute_bounded(a_p, cert)              # 有界可中止
                c, U = M.cof.active_update(a_p, y)
                b    = M.cfa.conditional(r, y, a_p, c, U)
                M.budget -= 1

    W_t    = credal_set(c, U, b)
    A_task = M.ach.propose(M.x_prime, H=max(b, key=b.get))
    A_cert = M.caf.filter(A_task, W_t)
    if not A_cert:
        return refuse_or_hold(M, W_t, why='empty_certified_set')  # 不派发未认证动作

    a    = M.mgp.project(A_cert, A_task, thr)
    cert = M.gac.emit(a, W_t)
    lam  = max(M.efs.risk_scale(b), thr['lam_floor'])
    tau  = M.pi_sigma.dispatch(a) * lam
    M.vqa_c.submit_async(a, cert, {'cal_event': (c, U), 'ident': cert.ident_verdict})
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit)
    return a, cert, lam, (c, U, b)
```

## 4. 推导

**引理 16（被动不可辨识定理）** 若 `h(a_hold,θ_0)=h(a_hold,θ_1)` 且噪声同族，则 `D_passive=0`，被动检验错误概率下界 `1/2`，不随样本数改善；存在 `a_p` 使 `h(a_p,θ_0)≠h(a_p,θ_1)` 时 `D_Chernoff(a_p)>0`，`N` 次探针错误概率 `≤exp(−N·D_Chernoff)`。**这是对 R68 盲区不可修补性的正式解释，也是主动探针必要性的来源。**

**引理 17（安全探针可行性）** 若 `a_p∈A_cert`，则在有界扰动 `‖d‖≤d_max` 与力上限下，探针违反安全约束的概率 `≤δ_W`，且存在 `π_abort` 使系统在 `T_abort` 内回到认证保持态——探针是**可恢复实验**。

**引理 18（认证集占优）** 在 A95（R68 标量收缩是鲁棒安全约束的保守内近似，`A_R68(U)⊆A_cert(U)`）下，对任意 `U`，`max_{A_cert∩B_λ} R_task ≥ max_{A_R68} R_task`。**系**：认证集在不降安全性的前提下救回被标量收缩误杀的安全动作。

**定理 16（无静默慢故障认证）** `P(以 H_cal 认证 | H_trans) ≤ δ_refuse + exp(−B_max·D_Chernoff(a*))`。要么探针分离，要么拒答；不存在「标定吸收故障且系统自信」的路径。对比 R68：该概率无上界。

**定理 17（端到端安全-可用性）** `P(unsafe) ≤ α_cal+α_grasp+δ_probe+δ_refuse`；可用性 ≥ R68 同安全约束；探针开销 `B_max·(T_probe+T_settle) ≤ 0.2·T_episode`；`UNKNOWN ⇒ λ≥0.8 ∧ 仅撤退`——不确定永远导向收缩。

**定理 18（计量可分离性）** `L≥2` 个不同载荷水平使「零偏+增益」故障模型的 Fisher 信息满秩（Vandermonde 型设计矩阵列满秩）；`L≥3` 时对含二次项模型满秩。**系**：R68 中「同一残差、两种因果」的秩亏被结构性消除。

## 7. 本轮最大风险

**一句话**：GAM-RAS 把安全从「被动相信测量」转移到「主动做一个物理实验」，但**探针本身是真实、可能不可逆的接触干预**——若参考件/接触模型有误，系统会用一个错误的「标准」去校准自己；若探针在未建模的柔顺/摩擦/遮挡下落空或压损，诊断结论与物体安全会同时失效，而 GAC 证书恰恰会给这次赌博盖上「已认证」的章。

**次级风险与缓解**：参考件不可用/场景非结构化（退回仅被动 + 拒答，不强行探针）；探针开销（预算 `B_max`、`ρ≤0.2`、信息价值门控）；伪分离（E294 失配攻击 + 参考模型溯源不确定度纳入 `W_t`）；认证集为空（拒答/保持，绝不派发未认证动作）；Sim2Real 接触模型偏移（在线辨识 `β`、保守 `μ_lo/m_hi`、真机 canary）。
