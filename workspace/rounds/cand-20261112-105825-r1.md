# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 7 轮；本轮灵感：「上下文理解」×「记忆检索」）

> 第 60 轮实现了「场景语义 → 认知意图 → 阻抗编译 → 执行 → 证据」的闭环（SSM×CIEC×EPIR×SERC×PCE++++），但**三个更深层的局限**尚未解决：
> 1. **场景与意图的「无上下文多义性」**：SSM 把场景识别写成 p(z|观测 O)，CIEC 把意图映射写成固定的 ϕ(I)。可同一个力尖峰在「抓取」阶段与「擦拭」阶段含义不同，同一句「慢点」在搬运水杯与打磨零件时约束也不同——**没有上下文，场景和意图都是欠定的（under-determined）**。第 60 轮的误判风险，本质是「把多义观测当成了单义证据」。
> 2. **情景记忆缺失导致的「重复试错」**：每一轮场景适应都从零开始。历史 EV-exec 只被 EPIR 当作「证据完整性」材料，却没有被当作「决策经验」复用。工程上这很浪费：既有的成功/失败案例本可以给出更好的初始 K_safe。但**朴素复用会带来负迁移**——昨天的湿滑桌面参数可能不适用于今天的油污地面。
> 3. **被复用知识的「溯源真空」**：即使复用历史参数，也无法回答「这条 K_safe 来自哪次执行、当时上下文是什么、是否仍然有效」。第 60 轮的 J_exec 只覆盖「本次执行」，不覆盖「被复用的历史」，证据链在「记忆」处出现断点。

本轮把「场景感知闭环」推进为 **「上下文-记忆执行接地」**：上下文理解负责「怎么读」，记忆检索负责「怎么试」，来源与生命周期负责「能不能用」。核心口号：**上下文决定语义，记忆提供先验，溯源决定可用性。**

## 0. 直觉与动机

**灵感 1（上下文理解 → 上下文接地模型 CGM）**
直觉：人听到「把那个拿过来」时，并不只解析句子，而是用任务阶段、对话指代、对象身份、最近一次失败共同确定「那个」是哪一个。机器人同理：同一个观测 o =（力尖峰 3N，位置偏差 2mm）在上下文 C 下可能是「撞到桌沿」「抓取打滑」「装配卡滞」。关键洞见：**上下文不应只是拼进大模型 prompt 的一段文本，而应是一个可推理、可求熵、可被安全层检验的类型化状态变量**。把场景后验从 p(z|o) 升级为 p(z|o,C)，把意图映射从 ϕ(I) 升级为 ϕ(I|C)；上下文熵 H(C) 直接度量「现在是否已经足以做决定」。

**灵感 2（记忆检索 → 情景记忆检索 EMR）**
直觉：熟练工不是每一次都重新试错，而是会想起「上次这种桌面，K_p=0.8 会打滑」。把一次执行存成情景（episode）：(上下文 C_i, 场景 z_i, 意图 I_i, 阻抗 K_i, 执行证据 EV_i, 结果 Y_i, 来源 p_i, 时间 t_i)。检索不是关键词匹配，而是「上下文条件化相似度」：上下文越近、执行条件越像、来源越可靠、时间越新，权重越高。关键洞见：**记忆是「带来源的先验」，不是「事实」**；它能加速收敛，也能把系统带偏，所以必须与安全层解耦。

**灵感 3（负迁移护盾 NTS）**
直觉：最危险的记忆不是「检索不到」，而是「检索到一个看起来很像、其实因果无关」的记忆——系统因相似度高而过度自信。护盾的第一原则是：**记忆只能收窄安全集，不能扩张安全集**；第二原则是：相似度必须过门限、来源必须过校验、首次接触的 D⁺ 若超阈值立即回滚并把该案例记为 negative_case。即「先信任到可验证为止」。

**灵感 4（记忆生命周期 MLC）**
直觉：记忆会过期。工具换了、环境版本变了、操作者换了，旧记忆就可能从「经验」变成「毒素」。给每条记忆一个有效期半衰期与版本标签，用 Beta 成功/失败计数维护可信度，只有成功率下置信界（Wilson LCB）≥ τ_succ 才允许复用。关键洞见：**遗忘不是缺陷，而是安全机制**；「不记得」比「自信地记错」更安全。

**灵感 5（合流 → 上下文-记忆协同闭环 CMEG 与记忆预算 PCE+++++）**
直觉：CGM 给出上下文 → EMR 按上下文检索 → NTS 做复用门控 → CCR 融合先验 → EEIS 编译 → 执行 → EV-exec → 写回记忆并带来源。新的瓶颈随之出现：检索延迟、索引规模、上下文窗口、写回速率。若 B_mem 耗尽 ⇒ 只保留最近 N 条并退化为无记忆执行；若 H(C) 过高 ⇒ 拒绝检索，回退到第 60 轮的场景先验。合流后得到 **CMEG 闭环**：`上下文→检索→门控→融合→编译→执行→证据→记忆更新`。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（上下文接地模型 CGM）** 类型化上下文
C_t = (c_task, c_ref, c_agent, c_env, c_hist)，其中：
- c_task ∈ 任务阶段集 {approach, contact, grasp, transport, release, wipe, assemble}
- c_ref 为对话指代绑定（「它/这个/左边那个」→ 对象 ID 及绑定置信度 β）
- c_agent 为操作者身份与授权等级
- c_env 为环境/工具版本标签
- c_hist 为最近 n=16 条 EV-exec 的摘要（失败类型、D⁺、场景后验）

上下文滤波：p(C_t|O_{1:t}) ∝ p(o_t|C_t) Σ_{C_{t-1}} p(C_t|C_{t-1}) p(C_{t-1}|O_{1:t-1})。
上下文熵：H(C_t) = −Σ_C p(C_t) log p(C_t)，可判定条件为 H(C_t) ≤ τ_ctx。
上下文条件化消歧：p(z|O,C) ∝ p(O|z,C) p(z|C)；意图映射由固定表改为条件映射 ϕ(I|C)。
绑定规则：仅当 max_C p(C_t) ≥ τ_bind 且 H(C_t) ≤ τ_ctx 才允许单假设决策，否则保留多假设并推迟高代价执行。

**定义 162（情景记忆检索 EMR）** 情景记忆库 M = {m_i}，其中
m_i = (C_i, z_i, I_i, K_i, X_i, Y_i, p_i, t_i, α_i, β_i, h_i)：
- X_i 为执行条件（工具、负载、环境版本），Y_i 为结果（D⁺、ECE、成功/失败）
- p_i 为来源凭据（EV-exec 哈希链 + 执行证书），ρ(p_i) ∈ [0,1] 为来源可信度
- α_i, β_i 为复用成功/失败计数，h_i 为记忆半衰期

上下文条件化检索得分：
```
s(m_i|C_t) = exp(−d_C(C_t,C_i)/σ_c) · exp(−d_X(X_t,X_i)/σ_x) · ρ(p_i) · 2^{−(t−t_i)/h_i}
```
其中 d_C 为类型化距离（阶段、指代、操作者、环境分项加权）。检索集 R_t = TopK{s ≥ τ_ret}，检索置信 γ_ret = 1 − exp(−Σ_{m∈R_t} s(m|C_t))。

**定义 163（上下文条件化复用 CCR）** 记忆先验
```
π_mem(K|C_t) = Σ_{m_i∈R_t} w_i · N(K; K_i, Σ_i),  w_i = s_i / Σ_j s_j
```
与场景先验融合：π_fused = α·π_scene + (1−α)·π_mem，α = γ_scene/(γ_scene + λ_mem·γ_ret)。
**安全收窄原则**：
```
K_safe^mem = {K | P(K|z,C,M) ≥ τ_K} ∩ K_safe^scene ∩ K_safe_base
```
即记忆只能重定心或收窄，永不扩张安全集。

**定义 164（负迁移护盾 NTS）** 复用门控
```
g(m_i) = 1[ d_C ≤ ε_ctx ∧ d_X ≤ ε_X ∧ ρ(p_i) ≥ τ_prov
          ∧ LCB(success_i) ≥ τ_succ ∧ H(C_t) ≤ τ_ctx ]
```
负迁移风险上界：R_NT ≤ L_max·(1−κ(C_t,C_i))，κ 为上下文兼容度。
运行时护盾：首次接触后若 D⁺_first > τ_nt 或偏离符号/量级，立即 (i) 撤回本次记忆先验，(ii) 将 m_i 标记为 negative_case，(iii) 回退第 60 轮场景先验重编译。

**定义 165（记忆生命周期 MLC）** 每条记忆维护 Beta(α_i,β_i)、版本标签 v_i 与半衰期 h_i：
- **硬失效**：环境版本 Δv、工具变更、操作者变更 ⇒ 直接 retired
- **软降权**：时间衰减按半衰期 h_i 指数衰减
- **巩固**：成功复用 α_i←α_i+1；失败复用 β_i←β_i+1，失败即写入 negative_case 并短期禁止复用
- **保留策略**：在 B_mem 约束下按 `VOI(m_i)` 保留，淘汰低 s、低 LCB、旧版本记忆
- 复用可信度：LCB(success_i) 取 Wilson 下界，只有 LCB ≥ τ_succ 才可复用

**定义 166（上下文-执行溯源 CEP / J_exec⁺）**
```
J_exec⁺ = J_exec ∪ (context_hash, retrieved_ids, gate_decisions, memory_provenance_chain)
```
来源链要求每条被复用的 K 都能回放到具体 EV-exec 与其原始上下文；提供 audit(m) 函数：给定记忆 ID 返回 (原始上下文哈希, EV-exec 哈希, 门控记录, 是否仍然有效)。

**定义 167（记忆预算 PCE+++++ / B_mem）**
```
B_mem = (retrieval_latency, index_size, context_window, writeback_rate)
voi_mem(π) = VOI_meta_pessimistic(π) − cost_cog(π) − cost_exec(π) − cost_mem(π)
cost_mem = λ_ret·Retrieval_latency + λ_idx·Index_footprint + λ_ctx·Context_window + λ_wb·Writeback_cost
```
耗尽策略：B_mem 耗尽 ⇒ 仅保留 top-N_recent、关闭记忆检索（no-memory 模式）；H(C) 超阈 ⇒ 不检索；两者均安全回退到第 60 轮 SSM 先验。

**定义 168（上下文-记忆协同闭环 CMEG）** 算子 CMEG(M, O, I)：
```
① C_t ← CGM.filter(O) ; H_t ← entropy(C_t)
② if H_t ≤ τ_ctx and B_mem not exhausted:
      R_t ← EMR.retrieve(C_t, X_t) ; π_mem ← CCR.prior(R_t)
   else: R_t ← ∅ ; π_mem ← ⊥
③ K_safe ← EEIS.compile_with_priors(π_scene, π_mem, δ_f_req)
④ if NTS.gate(C_t, R_t): dispatch(K_safe, Cert)
   else: dispatch(round60_scene_prior, Cert)
⑤ Execute → EV-exec ; if D⁺_first > τ_nt: NTS.rollback(); recompile
⑥ MLC.update(R_t, outcome, provenance) ; MLC.forget(B_mem)
⑦ J_exec⁺ ← sign(context_hash, retrieved_ids, gate_decisions)
⑧ Return (C_t, K_safe, EV-exec, J_exec⁺, H_t, γ_ret)
```

## 2. 关键算法伪代码

### IP-161 CGM（上下文接地模型）

```python
class ContextGroundingModel:
    def __init__(self, phases, tau_ctx=0.35, tau_bind=0.7, n_hist=16):
        self.phases = phases
        self.tau_ctx = tau_ctx
        self.tau_bind = tau_bind
        self.belief = {c: 1.0 / len(phases) for c in phases}
        self.history = deque(maxlen=n_hist)

    def update(self, telemetry, dialogue_turn):
        prior = self._transition(self.belief, dialogue_turn)
        lik = {c: self._obs_likelihood(c, telemetry, dialogue_turn) for c in prior}
        post = {c: prior[c] * lik[c] for c in prior}
        Z = sum(post.values()) or 1.0
        self.belief = {c: v / Z for c, v in post.items()}
        self.history.append((telemetry.ts, dialogue_turn, self.argmax()))
        return self.belief

    def entropy(self):
        return -sum(p * log(p + 1e-12) for p in self.belief.values())

    def is_decidable(self):
        return self.entropy() <= self.tau_ctx and max(self.belief.values()) >= self.tau_bind

    def bind_referent(self, utterance, candidates):
        scores = {obj_id: self._binding_score(utterance, obj_id) for obj_id in candidates}
        best = max(scores, key=scores.get)
        return best, scores[best]

    def context_vector(self):
        # 供检索使用的类型化上下文表示，附带熵与绑定置信度
        return {
            'phase': self.argmax(), 'belief': dict(self.belief),
            'entropy': self.entropy(), 'recent': list(self.history)
        }
```

### IP-162 EMR（情景记忆检索）

```python
class EpisodicMemory:
    def __init__(self, sigma_c=0.5, sigma_x=0.5, tau_ret=0.2):
        self.cases = []
        self.sigma_c = sigma_c
        self.sigma_x = sigma_x
        self.tau_ret = tau_ret

    def retrieve(self, C, X, top_k=5):
        now = time.time()
        scored = []
        for m in self.cases:
            if m.retired or not m.provenance.valid():
                continue
            s = (exp(-self._d_ctx(C, m.C) / self.sigma_c)
                 * exp(-self._d_exec(X, m.X) / self.sigma_x)
                 * m.provenance.rho
                 * 2.0 ** (-(now - m.t) / max(m.half_life, 1e-6)))
            if s >= self.tau_ret:
                scored.append((s, m))
        scored.sort(key=lambda p: -p[0])
        return scored[:top_k]

    def write_back(self, case):
        assert verify_provenance_chain(case.provenance)
        self.cases.append(case)
        if len(self.cases) > self.index_capacity:
            self._evict_low_voi()
```

### IP-164 NTS（负迁移护盾）

```python
class NegativeTransferShield:
    def __init__(self, eps_ctx=0.25, eps_x=0.2, tau_prov=0.9,
                 tau_succ=0.6, tau_nt=1.0):
        self.eps_ctx, self.eps_x = eps_ctx, eps_x
        self.tau_prov, self.tau_succ, self.tau_nt = tau_prov, tau_succ, tau_nt

    def gate(self, C, X, R):
        if not R:
            return False
        if C['entropy'] > self.tau_ctx:
            return False
        top = R[0][1]
        return (self._d_ctx(C, top.C) <= self.eps_ctx
                and self._d_exec(X, top.X) <= self.eps_x
                and top.provenance.rho >= self.tau_prov
                and wilson_lcb(top.alpha, top.beta) >= self.tau_succ)

    def runtime_check(self, D_plus_first, predicted_D):
        if D_plus_first > self.tau_nt or sign_mismatch(D_plus_first, predicted_D):
            self.rollback()
            return 'NEGATIVE_TRANSFER'
        return 'OK'
```

### IP-165 MLC（记忆生命周期）

```python
class MemoryLifecycle:
    def update(self, R, outcome, env_version):
        for _, m in R:
            if outcome.success:
                m.alpha += 1
            else:
                m.beta += 1
                m.half_life = min(m.half_life, 1.0)
                m.negative = True
        for m in self.cases:
            if m.X.env_version != env_version:
                m.retired = True

    def usable(self, m):
        return (not m.retired and not m.negative
                and wilson_lcb(m.alpha, m.beta) >= self.tau_succ)
```

def context_memory_execution_grounding(M, obs, intent):

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CGM | O(\|C\|²)/周期 | O(\|C\| + n_hist) | 上下文后验收敛，H(C) ≤ τ 时消歧 |
| EMR | O(\|M\|) 线性检索（索引后 O(log\|M\|)） | O(\|M\|) | 检索精度@k ≥ 80%，来源校验 |
| CCR | O(k) | O(k) | K_safe^mem ⊆ K_safe_base |
| NTS | O(k) | O(1) | 负迁移一次接触内检出，回滚可用 |
| MLC | O(\|M\|) 摊销 | O(\|M\|) | 失效/过期记忆不复用 |
| CMEG | O(\|M\| + 编译) | 复用 | 端到端安全回退 |

**正确性定理（CEMG）**：
假设 A66–A70 成立：
- **(A66) 上下文可辨识**：在平稳上下文段，上下文滤波在 k 次观测后满足 H(C_t) ≤ δ_ctx，且后验校准。
- **(A67) 记忆覆盖与来源完整**：对操作分布内上下文，存在 d_C ≤ ε_ctx 的有效案例；来源经 EPIR 哈希链验证。
- **(A68) 安全收窄**：由定义 163，K_safe^mem ⊆ K_safe_base。
- **(A69) 负迁移可检出**：若复用先验因果错误，则 D⁺_first > τ_nt 的概率 ≥ 1−δ_nt。
- **(A70) 预算单调**：B_mem 单调消耗；耗尽后回退不破坏可用性。

则：
1. **上下文消歧可靠性**：若 is_decidable 成立，则场景/意图因多义性导致的误判率 ≤ δ_ctx；相对第 60 轮的 p(z|o)、ϕ(I)，歧义错误下降 ≥ 30%。
2. **记忆复用安全性**：被 dispatch 的 K_safe 始终 ∈ K_safe_base；记忆不能扩大不安全区域，故记忆复用不引入新的越界执行。
3. **负迁移有界性**：最坏额外损失 ≤ L_max·(1−κ)，且在一次接触内以 ≥ 1−δ_nt 概率检出；回滚后系统退回第 60 轮基线。
4. **溯源可审计性**：每个被采纳的 K 都有哈希链接回源 EV-exec；在 EPIR 前提下证据链完整性 ≥ 99.9%。
5. **预算安全性**：若 B_mem 耗尽或 H(C) > τ_ctx，则不检索并退化到 SSM，安全不变量保持。

### IP-161 CGM（上下文接地模型）

```python
class ContextGroundingModel:
    def __init__(self, phases, tau_ctx=0.35, tau_bind=0.7, n_hist=16):
        self.phases = phases
        self.tau_ctx = tau_ctx
        self.tau_bind = tau_bind
        self.belief = {c: 1.0 / len(phases) for c in phases}
        self.history = deque(maxlen=n_hist)

    def update(self, telemetry, dialogue_turn):
        prior = self._transition(self.belief, dialogue_turn)
        lik = {c: self._obs_likelihood(c, telemetry, dialogue_turn) for c in prior}
        post = {c: prior[c] * lik[c] for c in prior}
        Z = sum(post.values()) or 1.0
        self.belief = {c: v / Z for c, v in post.items()}
        self.history.append((telemetry.ts, dialogue_turn, self.argmax()))
        return self.belief

    def entropy(self):
        return -sum(p * log(p + 1e-12) for p in self.belief.values())

    def is_decidable(self):
        return self.entropy() <= self.tau_ctx and max(self.belief.values()) >= self.tau_bind

    def bind_referent(self, utterance, candidates):
        scores = {obj_id: self._binding_score(utterance, obj_id) for obj_id in candidates}
        best = max(scores, key=scores.get)
        return best, scores[best]

    def context_vector(self):
        return {'phase': self.argmax(), 'belief': dict(self.belief),
                'entropy': self.entropy(), 'recent': list(self.history)}
```

### IP-162 EMR（情景记忆检索）

```python
class EpisodicMemory:
    def __init__(self, sigma_c=0.5, sigma_x=0.5, tau_ret=0.2):
        self.cases = []
        self.sigma_c, self.sigma_x, self.tau_ret = sigma_c, sigma_x, tau_ret

    def retrieve(self, C, X, top_k=5):
        now = time.time()
        scored = []
        for m in self.cases:
            if m.retired or not m.provenance.valid():
                continue
            s = (exp(-self._d_ctx(C, m.C) / self.sigma_c)
                 * exp(-self._d_exec(X, m.X) / self.sigma_x)
                 * m.provenance.rho
                 * 2.0 ** (-(now - m.t) / max(m.half_life, 1e-6)))
            if s >= self.tau_ret:
                scored.append((s, m))
        scored.sort(key=lambda p: -p[0])
        return scored[:top_k]

    def write_back(self, case):
        assert verify_provenance_chain(case.provenance)
        self.cases.append(case)
        if len(self.cases) > self.index_capacity:
            self._evict_low_voi()
```

class ContextConditionedReuse:
    def prior(self, R):
        if not R:
            return None
        total = sum(s for s, _ in R)
        w = [(s / total, m) for s, m in R]
        return GaussianMixture([(wi, m.K, m.sigma) for wi, m in w])

    def fuse(self, pi_scene, pi_mem, gamma_scene, gamma_ret, lam=1.0):
        if pi_mem is None:
            return pi_scene
        alpha = gamma_scene / (gamma_scene + lam * gamma_ret + 1e-9)
        return mixture(alpha, pi_scene, 1 - alpha, pi_mem)

    def safe_narrow(self, pi_mem, K_scene, K_base, tau_K):
        return intersect(mass_region(pi_mem, tau_K), K_scene, K_base)

class NegativeTransferShield:
    def __init__(self, eps_ctx=0.25, eps_x=0.2, tau_prov=0.9,
                 tau_succ=0.6, tau_nt=1.0):
        self.eps_ctx, self.eps_x = eps_ctx, eps_x
        self.tau_prov, self.tau_succ, self.tau_nt = tau_prov, tau_succ, tau_nt

    def gate(self, C, X, R):
        if not R or C['entropy'] > self.tau_ctx:
            return False
        top = R[0][1]
        return (self._d_ctx(C, top.C) <= self.eps_ctx
                and self._d_exec(X, top.X) <= self.eps_x
                and top.provenance.rho >= self.tau_prov
                and wilson_lcb(top.alpha, top.beta) >= self.tau_succ)

    def runtime_check(self, D_plus_first, predicted_D):
        if D_plus_first > self.tau_nt or sign_mismatch(D_plus_first, predicted_D):
            self.rollback()
            return 'NEGATIVE_TRANSFER'
        return 'OK'

class MemoryLifecycle:
    def update(self, R, outcome, env_version):
        for _, m in R:
            if outcome.success:
                m.alpha += 1
            else:
                m.beta += 1
                m.half_life = min(m.half_life, 1.0)
                m.negative = True
        for m in self.cases:
            if m.X.env_version != env_version:
                m.retired = True

    def usable(self, m):
        return (not m.retired and not m.negative
                and wilson_lcb(m.alpha, m.beta) >= self.tau_succ)

**正确性定理（CEMG）**：
若 A66–A70 成立，则：
1. **上下文消歧可靠性**：is_decidable ⇒ 多义导致的场景/意图误判率 ≤ δ_ctx；相对第 60 轮无上下文版本，歧义错误下降 ≥ 30%。
2. **记忆复用安全性**：dispatch 的 K_safe ∈ K_safe_base；记忆不能扩张不安全区域。
3. **负迁移有界性**：额外损失 ≤ L_max·(1−κ)，一次接触内以 ≥ 1−δ_nt 概率检出；回滚后退回第 60 轮基线。
4. **溯源可审计性**：每个被采纳的 K 有哈希链接回源 EV-exec；证据链完整性 ≥ 99.9%。
5. **预算安全性**：B_mem 耗尽或 H(C) > τ_ctx ⇒ 不检索并退化到 SSM；安全不变量保持。
