# 第 12 轮（新灵感循环第 1 轮；本轮灵感：「语音交互」×「低成本方案」）

> **基线**：第 11 轮 MetricVoiceGauge-GSCF-SRA-JSSE（定义 549–561；引理 92–96；实验 E591–E610）。
> 本轮纪律：**廉价冗余 + 非对称权限 + 可溯解释**。两个灵感分别治理 v11 的两种债：**鲁棒债**（GSCF/SRA/JSSE 三重守护的失效模式在强遮挡 + 动态场景 + 标定漂移下可能同时触发，上轮已自认"无优雅退化路径，只能急停"）、**成本债**（50MB VQA + 深度/点云栈把系统钉死在昂贵硬件上，离家庭、教育、小型赛场的低成本部署很远）。v11 铁律不变：任一新模块失效 ⇒ 注入声明中立元，行为对 v11 **等价**（ASC/LCS）或**支配**（VAL），且**语音识别错误只影响效率、不影响安全**。

## 0. 直觉与动机

**灵感 1（语音交互 → 把"人"从被感知对象升级为权威源，但权限非对称）**
直觉：v11 里"人"只以被感知对象的身份出现（NRB 的人际距离、SRA 的 VQA 自问），却从未被当作**权威源**。而语音交互最便宜、最符合直觉的安全接口恰恰是：人喊"停"就停。但语音识别不可靠，把安全押在识别率上等于引入新的前提债。核心创新：**语音权限梯（VoiceAuthorityLadder, VAL）**——按**安全方向非对称**地把语音语义拆成两类。**否决（veto）**永远即时可信：误报只导致动作空间收缩（保守 = 安全），漏报至多退回 v11 基线，绝无扩权。**同意（consent）**只能在一个**预认证、有时限租约的扩张包络 E_c** 内扩权：识别器以为是"同意"最多把我们放进一个本就认证过的安全域，认错也只是换个安全动作。于是"识别对不对"只决定"跑得快不快、能不能抓"，不决定"安不安全"——这是把语音从"输入模态"提升为**安全的单调算子**，也是本轮最想保住的一句话。

**灵感 2（低成本方案 → 声学独立冗余，补的正是"看不见"的洞）**
直觉：v11 最贵的是"看得准"（深度/点云 + 50MB VQA），而 v11 最大的事故模式是"看不见"（遮挡、反光、黑暗、标定漂移）。声音恰好补这个洞且极便宜：MEMS 麦克风阵列 <5 美元、16kHz 单声道 256kbps、声学事件检测模型 <1MB、功耗 ~50mW。核心创新：**声学安全通道（AcousticSafetyChannel, ASC）**——麦克风阵列 + 轻量声学事件检测（人声喊叫/尖叫/玻璃破碎/撞击/哭喊）+ 波达方向 DOA，作为与视觉/几何/推理**物理正交**的领先指标并入证书余量 β_ASC 与 50Hz 第六检。声学事件可穿遮挡、不依赖光照与标定，正面拆解 v11"三重失效共触发"的最大风险：视觉三重守护一起坏掉时，声音这条独立通道仍在。配套**低成本语音栈（LowCostStack, LCS）**：关键词识别 KWS 替代全 ASR、蒸馏 D-SRA（≤6MB）替代 50MB VQA、模板化解释替代自由生成（无自由生成 ⇒ 解释幻觉为 0，且每句可溯源到台账），把决策侧内存从 ≤52MB 压到 ≤12MB 量级，并用**成本分档**（Tier-A/B/C）让"便宜"成为可证的取舍而不是偷工减料。

三者咬合：ASC 出**正交廉价证据**（证书物理侧更抗遮挡）、VAL 出**非对称人类权威**（证书规范侧可追责、可解释）、LCS 保证两者**装得下、说得清**——共同把 v11 三重守护证书 Ĉ⁺⁺ 升级为**低成本结构化信任证书 Ĉ⁺⁺⁺ = (ĝ_min, ê_max, γ̂_grasp, β_ASC, n_t, n_t^reason, γ_ac, Ψ_t, n_t^ground)**。

## 1. 研究问题（轮次升级版）

- **Q1（廉价正交安全）**：一个 <5 美元的麦克风阵列 + <1MB 声学事件检测器，能否为 v11 的可见/几何/推理三重守护提供**物理正交**的领先指标，使强遮挡 + 动态 + 标定漂移下的"三失效共触发"被独立声学通道打破（对声学可观测危险，联合未检出概率从并集界降到乘积界），同时正常环境误报 ≤1%？
- **Q2（非对称语音权限）**：如何形式化 veto/consent 的非对称权限，使**任意**语音解释（含误识别与对抗音频）下的执行动作都落在 `A_v11 ∪ 预认证扩张包络 E_c` 内（安全单调），且 veto 失明时收缩、consent 失明时禁扩张（支配 v11），从而"识别率只买效率、不买安全"？
- **Q3（可溯降本）**：KWS + D-SRA + 模板化解释能否在**解释接地率 = 1（幻觉 = 0）**、解释相关性不降的前提下，把决策侧内存 ↓≥75%、功耗不升、时延不升，并让 Tier-C 极简档（麦克风阵列 + IMU + 近距超声 + KWS）也携带**可证**的证书余量 β_C？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 声学独立冗余律（Acoustic Independence, ASC）**
声学通道必须在物理上独立于视觉/几何/推理链路（不共享深度、标定、嵌入）；它只许**增加**领先指标与**收缩**动作，不许单独扩权。声学失效（麦克风死、SNR 低、DOA 无效）⇒ 注入中立元 γ_ac≡1、κ≡0、β_ASC←β_GSCF、检 6 跳过 ⇒ 严格等价 v11。声学异常只有在方向/响度与机器人足迹相关（κ>0）时才计入本块余量，避免全局保守税。

**P17 语音权限非对称律（Voice Authority Asymmetry, VAL）**
语音语义按安全方向非对称：**veto（否决）即时可信、只收缩**；**consent（同意）只在一个预认证、有时限租约的扩张包络内扩权**，且不得覆盖任何物理不变式。识别不可用/未命中/对抗 ⇒ 回到 veto-only 的 L0 与 v11 动作集。由此"识别正确性"只影响效率，安全由预认证包络与 v11 基线独立保证（安全单调性）。

**P18 低成本可证律（Evidence-Backed Low Cost, LCS）**
任何降本（KWS 换 ASR、D-SRA 换 VQA、模板换自由生成、Tier 切换）必须携带**证据预算**：D-SRA 与全 SRA 的 n_reason 一致率 ≥99%（分歧即保守收缩）；解释接地率 φ_ground 构造上 =1（只填台账事实槽位）；每个成本档的证书余量 β_tier 由标定实验给出，切换仅在目标档前置条件成立且 β_tier 仍满足当前 d_safe 时允许。没有证据预算的便宜，不许上线。

## 3. 与基线的接口（如何退化）

- **ASC 失效**（麦克风死 / SNR < SNR_min / DOA 无效 / AED 超时 / 新鲜度 > T_ac）⇒ γ_ac≡1、κ≡0、β_ASC←β_GSCF、检 6 跳过：等价 v11 视觉三重守护行为；
- **VAL 失效**（KWS / 音频前端失效）⇒ veto 失明 ⇒ `K_eff←min(K_eff,2)` 且进入 Π_r（失去一层安全通道必须收缩）；consent 失明 ⇒ 禁扩张 ⇒ `A_voice ⊆ A_v11`（支配 v11）；
- **LCS 失效**（D-SRA / 模板 / TTS）⇒ 若有完整 SRA 则回退 v11 SRA + 自由解释；否则 n_reason 按 D-SRA 的保守结果保持或全 0（`K_eff←2`）、解释退化为结构化日志：等价或支配 v11；
- **其余**沿 v11 退化链：GSCF⇒v11 L1、SRA⇒v11 L2、JSSE⇒v11 L3、STF⇒v11 L4、NRB⇒v11 L5、AC⇒v11 L6、ID⇒v11 L7、MW⇒v11 L8、v8⇒v11 L9；
- **关键不对称**：任何语音识别错误（含对抗音频）只改变效率/可用性，不改变安全（引理 98）。

## 4. 预期贡献

1. **正交廉价冗余**：用 <5 美元麦克风阵列把 v11"三失效共触发即急停"的风险从物理通道上拆开——声学可观测危险获得独立检出，联合未检出从并集界降到乘积界（引理 97）；
2. **非对称人类权威**：veto-only + consent 租约式预认证扩张，给出"识别率只买效率、不买安全"的安全单调性定理（引理 98），把上轮的"人当被感知对象"升级为"人当可问责的权威源"；
3. **可证降本与可溯解释**：KWS + D-SRA + 模板化解释使决策侧内存 ↓≥75%、解释接地率 =1/幻觉 =0，并用 Tier-A/B/C 让低成本部署携带可证 β_tier（引理 99–100）；
4. **E611–E630** 覆盖声学标定、遮挡正交性、三失效共触发、音频对抗、veto/consent 单调性、D-SRA 一致率、解释接地、成本预算、成本档切换、长跑与竞赛。

## 5. 本轮最大风险

**一句话**：低成本声学通道的"便宜"是以**分布偏移与对抗音频**换来的（混响、口音、播放攻击、超声注入可让 AED 既漏报也假报），而语音权限把"人当安全备份"的假设在无人、误解、儿童或非母语场景下会**静默失效**——看似多了一层廉价冗余，实则可能在最需要它的时刻既没听见、也没听懂。

**新增定义 562（声学常态度）** 每 20ms 窗对波形 a(t) 做波束形成与 log-mel 特征，轻量 AED（log-mel + 微型 CNN/GRU，<1MB INT8）输出危险事件后验 p_ac(ℓ∣t)。γ_ac(t) = 1 − max_{ℓ∈L_danger} p_ac(ℓ∣t)。γ_ac,min 由 E611 标定，使正常家庭/赛场环境（含电视声、空调、多人交谈）下 γ_ac≥γ_ac,min 以概率 ≥1−ε_ac（ε_ac≤0.01）。**γ_ac,min 由噪声模型给出，不是调参。**

**新增定义 563（声学相关性权重）** κ(DOA, loud) = exp(−ang(DOA, θ_corridor)² / 2σ_θ²)·σ(loud; loud_0, s_l) ∈[0,1]。仅当声源方向指向机器人走廊近邻、且响度超过近场阈值时 κ>0。κ=0 ⇒ 声学事件与本块无关，不抬高 β_ASC（无全局保守税）。

**新增定义 564（声学余量与信任域）** β_ASC(ζ,t) = β_GSCF(ζ,t) + λ_ac·sup_{事件 e} κ_e·(1−γ_ac,e)。U_t^ac = mic_healthy ∧ SNR≥SNR_min ∧ DOA valid ∧ freshness(a)≤T_ac。¬U_t^ac ⇒ γ_ac≡1、κ≡0、β_ASC←β_GSCF（声明中立元）。

**新增定义 565（六检守卫）** 50Hz 守卫在原五检基础上新增检 6：若 U_t^ac 且 γ_ac<γ_ac,min ⇒ abort；若 ¬U_t^ac ⇒ 跳过（中性，等价 v11）。另设 **veto 快路径**：E_stop 命中 ⇒ 不等证书判定，立即 abort（≤2 帧，40ms）。总预算 ≤0.65ms（新增 0.05ms）。

**新增定义 566（低成本证书）** ĉ_t⁺⁺⁺ = (ĝ_min, ê_max, γ̂_grasp, β_ASC, n_t, n_t^reason, γ_ac, Ψ_t, n_t^ground)。有效 ⇔ v11 定义 552 有效 ∧ (¬U_t^ac ∨ γ_ac≥γ_ac,min) ∧ Ψ_t 合法（无未决 veto；若含 consent 扩张，则租约未过期且 E_c 已预认证）∧ n_t^ground 全接地。

**新增定义 567（语音权限梯状态机）**
- **L0（默认，veto-only）**：A_t^voice = A_t^v11，仅接收 veto；无同意扩张；
- **L1（consent-manipulation）**：若存在对能力 c=manipulate 的有效同意（绑定对象 o、conf≥τ_consent=0.85、租约未过期）⇒ A_t^voice ⊆ A_t^v11 ⊕ E_manip(o)；
- **L2（consent-speed）**：类似，A_t^voice ⊆ A_t^v11 ⊕ E_speed。
veto 事件 ⇒ 立即回 L0 且 A_t^voice ← Π_r(A_t^v11)（收缩），需**双因素 re-arm**（语音"恢复"+物理按钮）才解除。同意不可覆盖任何物理不变式；E_c 自身预认证（β_c 由 E617 标定）。

**新增定义 568（veto 事件与延迟）** E_stop = {p_ac(human_shout)≥0.8} ∪ {p_ac(scream)≥0.8} ∪ {KWS 命中 w∈V_stop}。veto 检测延迟 ≤2 帧（40ms）；假阳性只触发收缩（保守），假阴性至多回到 v11 基线（见引理 98）。

**新增定义 569（安全单调性）** 对任意语音解释 ω（含误识别与对抗音频），执行动作满足 A_t^voice(ω) ⊆ A_t^v11 ∪ (⋃_{c∈C_t^consent, lease 有效} E_c)，且各 E_c 预认证。无有效同意 ⇒ A_t^voice ⊆ A_t^v11；veto 触发 ⇒ A_t^voice ⊆ Π_r(A_t^v11)。即语音识别正确性只影响效率与可用性，不影响安全。

**新增定义 570（低成本语音栈 LCS）** 三件套：(i) KWS 替代全 ASR 做命令与停止词（|V_kws|≤32，<100KB，≤0.5ms/20ms）；(ii) D-SRA：从 v11 SRA 蒸馏（≤6MB INT8），在标定集上与全 SRA 的 n_reason 一致率 ≥99%，分歧 ⇒ 置 0 并 K_eff←2（P18 证据预算）；(iii) 模板化解释 R_tmpl（≤16）+ 小型 TTS（<2MB）。失效语义见 Level-3。

**新增定义 571（模板化解释）** r_k = Fill(tmpl_j, slots(F_Λ))，其中 F_Λ 为台账结构化事实；每个 slot 只允许取台账字段，每条断言携带 provenance id（台账记录号）。**不生成模板槽位之外的内容 ⇒ 无自由生成 ⇒ 解释幻觉率 = 0（对解释而言）**。示例模板：
| 模板 | 绑定事实 |
|---|---|
| "我在 {t} 停止，因为 {reason}（台账 #{id}）。" | 中止记录、触发检 |
| "检测到 {event} 在 {bearing}° 方向、约 {dist} 米处。" | AED 事件、DOA |
| "当前 {tier} 档；证书余量 {beta}；最近人工确认 {consent}。" | β_tier、Ψ_t |
| "我无法确认 {assumption}，因此收缩到保守模式。" | NRB/SRA 否决记录 |
| "已按同意在 {object} 上作业，租约剩 {lease}s。" | consent 记录 |

**新增定义 572（成本档与 β_tier）** Tier-A/B/C 见上表。每档给 β_tier 与覆盖保证（E622 标定）。档切换仅在目标档前置条件（传感器/模型齐备）成立且 β_tier 仍满足当前 d_safe 时允许；否则保持当前档或收缩。切换动作入台账。

**新增定义 573（声学-视觉联合信任域）** U_t^acv = (¬U_t^ac) ∨ (γ_ac≥γ_ac,min)。升级 v11 定义 553：
```
K_eff(t) = 1   若 ¬U_t^sem ∨ ¬U_t^geo ∨ ¬U_t^acv ∨ ĉ_t⁺⁺⁺ 不可得
         = 2   若 NRB 失效 ∨ SRA/LCS 失效 ∨ VAL veto（Π_r 级）
         = max(1, ⌊K_max·(1 − min(1, max(Δ_dom/τ_dom,
                        sup_走廊 T/τ_sem,
                        sup_走廊 (1−Γ)/τ_sem,
                        1[U_t^ac]·κ·(1−γ_ac)/τ_sem)))⌋)   否则
```
四重门控取 max：标量/语义/几何/声学任一越阈即收缩。

class AcousticSafetyChannel:
    def __init__(self, aed, gamma_ac_min, snr_min=12.0, tau_ac=0.5,
                 lam_ac=0.4, sigma_theta=0.35):
        self.aed = aed                       # log-mel + 微型 CNN/GRU, <1MB INT8
        self.gamma_ac_min = gamma_ac_min     # 标定下界（E611），非经验调参
        self.snr_min, self.tau_ac = snr_min, tau_ac
        self.lam_ac, self.sigma_theta = lam_ac, sigma_theta
        self.gamma_ac, self.doa, self.snr = 1.0, None, 0.0
        self.veto, self.t_last = False, -1e9

    def update(self, audio, t):              # 50Hz：波束形成 + AED
        feat = log_mel(audio, sr=16000, n_mels=40)
        probs, doa, snr = self.aed.infer(feat, self._beamform(audio))
        self.gamma_ac = 1.0 - max(probs[l] for l in L_DANGER)
        self.doa, self.snr, self.t_last = doa, snr, t
        self.veto = (probs['human_shout'] >= 0.8) or (probs['scream'] >= 0.8)
        return self.gamma_ac

    def healthy(self, t):
        return (self.snr >= self.snr_min and self.doa is not None
                and (t - self.t_last) <= self.tau_ac)

    def beta_on(self, ctx):                  # 定义 564
        if not self.healthy(ctx.t):
            return 0.0                       # 中性：等价 v11
        kappa = self._relevance(ctx.corridor_bearing, ctx.near_loudness)
        return self.lam_ac * kappa * (1.0 - self.gamma_ac)

    def _relevance(self, corridor_bearing, loud):
        dtheta = angle_diff(self.doa, corridor_bearing)
        return math.exp(-dtheta**2 / (2 * self.sigma_theta**2)) * loud_gate(loud)

    def guard_ok(self, ctx):                 # 定义 565 检 6
        if not self.healthy(ctx.t):
            return True                      # 中性：跳过，不惩罚
        return self.gamma_ac >= self.gamma_ac_min


class VoiceAuthorityLadder:
    def __init__(self, kws, stop_words, tau_consent=0.85, tau_lease=5.0,
                 capability_envelopes=None):
        self.kws, self.stop_words = kws, set(stop_words)   # KWS <100KB，|V_stop|≤8
        self.tau_consent, self.tau_lease = tau_consent, tau_lease
        self.envelopes = capability_envelopes or {}        # c -> E_c（预认证）
        self.veto_latched = False
        self.consents = {}                   # c -> (object, expiry, conf)

    def step(self, audio, t, scene):
        toks = self.kws.stream(audio)
        if any(w in self.stop_words for w in toks):        # veto 优先，只收缩
            self.veto_latched = True
            return ('veto', None)
        for c, tmpl in CONSENT_TEMPLATES.items():
            hit = match_consent(toks, tmpl, scene)         # 绑定能力 + 对象
            if hit and hit.conf >= self.tau_consent:
                self.consents[c] = (hit.object, t + self.tau_lease, hit.conf)
        return ('hold', None)

    def arm(self, dual_factor):              # 解除 veto 需双因素 re-arm
        if dual_factor.ok:
            self.veto_latched = False
            self.consents.clear()

    def filter_action_set(self, A_v11, t):   # 定义 567/569：只收缩或包络内扩张
        if self.veto_latched:
            return shrink_to_profile(A_v11, 'Pi_r')        # A ⊆ Π_r(A_v11)
        A = A_v11
        for c, (obj, exp, conf) in list(self.consents.items()):
            if t >= exp:
                del self.consents[c]
                continue
            A = A | expand_within(self.envelopes[c], obj)  # ⊕ E_c（预认证）
        return A


class LowCostStack:
    def __init__(self, dsra, kws, tts, templates, ledger):
        self.dsra, self.kws, self.tts = dsra, kws, tts  # 6MB / <100KB / 2MB
        self.templates, self.ledger = templates, ledger
        self.healthy = True

    def reason(self, chunk, ctx):            # 替代 v11 SRA 的 n_reason
        if not self.healthy:
            return None                      # 触发 Level-3
        verdicts = self.dsra.n_reason(chunk, ctx)
        if self._disagreement_risk(verdicts):  # P18：分歧 ⇒ 保守置 0
            verdicts = [0] * len(verdicts)
        return verdicts

    def explain(self, chunk, facts):         # 定义 571：模板化，φ_ground = 1
        out = []
        for j, tpl in enumerate(self.templates):
            slots = tpl.bind(facts)          # 只允许台账事实槽位
            if slots is None:
                continue
            rec_id = self.ledger.last_id(chunk.id, j)
            out.append(Fill(tpl, slots, provenance=rec_id))
        return out


class SixGuardCertifier(TriGuardChunkCertifier):
    def generate_chunk(self, state, ctx, stf, gscf, nrb, sra, A_voice, beta_ac):
        K = self.effective_K(ctx.delta_dom, ctx.tau_dom,
                             trust_ok=stf.trust_ok(ctx) and gscf.geo_ok(ctx),
                             ac_ok=ctx.ac_ok)                  # 定义 573
        if K == 1:
            return self._single_step_fallback(state)
        best = None
        for cand in self.policy.sample_sequences(state, K, n=64, restrict=A_voice):
            pred = self.Fq.rollout(state, cand)
            beta_asc = self.beta_base + self.lam * gscf.field_on_footprint(pred.corridor) + beta_ac
            g_min = pred.min_clearance - beta_asc
            e_max = pred.max_effort + beta_asc
            if g_min < self.d_safe or e_max > state.tau_eff:
                continue
            pts = self._abort_points(state, cand, pred)
            if not pts:
                continue
            chunk = Chunk(cand, LowCostCert(g_min, e_max, beta_asc, pts), pts)
            chunk, _ = nrb.review_chunk(chunk, stf, ctx)
            if chunk is None:
                continue
            n_reason = sra.reason(chunk, ctx)          # D-SRA；None ⇒ 回退全 SRA
            if n_reason is None:
                n_reason = self.full_sra.reason_on_chunk(chunk, stf, gscf, ctx)[0]
            chunk.cert.n_reason = n_reason
            if not all(n_reason):
                chunk.cert.valid = False
                continue
            chunk.cert.Q_abort = {p: self.jsse.map_abort(p) for p in pts}
            score = self.policy.score(chunk, pred)
            if best is None or score > best.score:
                best = chunk
        return best or self._single_step_fallback(state)

    def midchunk_guard_six(self, chunk, k_exec, live_obs, stf, gscf, nrb, jsse, asc, val):
        """50Hz 六检 ≤0.65ms；veto 快路径优先"""
        if val.veto_latched:
            return self._abort_to_jsse(chunk, k_exec, jsse)      # veto 优先
        if not chunk.cert_still_valid(live_obs):
            return self._abort_to_jsse(chunk, k_exec, jsse)
        stop_inv = (live_obs.nearest_clearance
                    - self.d_brake(live_obs.speed) - self.d_safe)
        if stop_inv < chunk.remaining_len(k_exec):
            return self._abort_to_jsse(chunk, k_exec, jsse)
        if stf.surprise_near(live_obs.pose) > stf.tau_sem:
            return self._abort_to_jsse(chunk, k_exec, jsse)
        if nrb.fast_norms(live_obs).violated:
            return self._abort_to_jsse(chunk, k_exec, jsse)
        if not gscf.geo_ok_near(live_obs.pose):
            return self._abort_to_jsse(chunk, k_exec, jsse)
        if not asc.guard_ok(live_obs.ctx):     # 检 6：声学
            return self._abort_to_jsse(chunk, k_exec, jsse)
        return ('continue', k_exec + 1)

## 4. 推导

**引理 97（声学正交冗余与联合降风险——v11 最大风险的正面拆解）**
设 (A5) 环境给定下，声学异常事件与「视觉/几何/推理失效」条件独立；(A6) 对声学可观测危险事件集 H_ac={喊叫、尖叫、玻璃破碎、撞击、哭喊}，ASC 检出率 ≥1−ε_ac,miss（E612），且正常环境误报率 ≤ε_ac（E611 标定 γ_ac,min）；(A7) 相关性权重 κ 只依赖 DOA 与响度，不依赖视觉。则对 e∈H_ac：
- 若 e 同时是 v11 三重守护的可捕获事件，v11 联合未检出 ≤ ε_geo+ε_sra+ε_jsse（并集界，引理 96）；
- 加入 ASC 后，独立通道未检出概率 ≤ ε_ac,miss，且因 (A5) 条件独立，联合未检出 ≤ (ε_geo+ε_sra+ε_jsse)·ε_ac,miss（乘积界）；
对 e∉H_ac（声学不可观测，如静默移动物体），κ=0，β_ASC 不增、检 6 不响，退化为 v11 保证（不劣化）。且 β_ASC 对 γ_ac 单调、κ=0 时不产生全局保守税。证明：独立性 + 并集/乘积界；κ 的定义 563 直接给出单调与无税。∎

**引理 98（语音权限的安全单调性——识别率只买效率）**
对任意语音解释 ω（含误识别、漏识别、对抗音频），VAL 执行动作集满足
`A_t^voice(ω) ⊆ A_t^v11 ∪ (⋃_{c∈C_t^consent, lease 有效} E_c)`，
且每个 E_c 预认证（β_c 标定，E617）。逐情形：
1. **veto 假阳性**（无人喊停却判停）：A_t^voice ⊆ Π_r(A_t^v11) ⇒ 收缩，保守，安全；
2. **veto 假阴性**（有人喊停却没识别）：不触发收缩，但 A_t^voice ⊆ A_t^v11，仍受 v11 保证；
3. **consent 假阳性**（未同意却判同意）：扩张仅在预认证 E_c 内，E_c 自带 β_c，安全；
4. **consent 假阴性**：不扩张，A_t^voice ⊆ A_t^v11。
四种情形的并集均 ⊆ A_t^v11 ∪ E_c。因此安全不变式不依赖识别正确性；识别错误只影响效率（假阳性致误停、假阴性致不能抓/不能加速）。∎

**引理 99（模板化解释的接地性与降本）**
(i) 由定义 571，每条解释句 r_k 由模板槽位 Fill 生成，槽位只取台账事实 F_Λ，并携带 provenance id ⇒ 接地率 φ_ground=1（构造保证），**无自由生成 ⇒ 解释类幻觉率 = 0**；(ii) 内存：LCS = D-SRA 6MB + TTS 2MB + KWS 0.1MB ≈ 8.1MB，替代 v11 SRA 的 50MB ⇒ ↓≥83.8%；加入 ASC 0.6MB 后，决策侧由 ≤52MB 降到 ≤12MB（↓≥75%）；Tier-C ≤2MB（↓≥96%）；(iii) 时延：D-SRA 4ms@5Hz（摊销 0.8ms）≤ v11 SRA 5ms@5Hz（摊销 1.0ms）；(iv) 功耗：移除 ~200mW SRA，新增 D-SRA 120 + TTS 20 + KWS 5 + ASC 50 ≈ 195mW，净不升。证明：定义 + E619–E621 实测。∎

**引理 100（v12 联合保守性与成本-安全权衡）**
在 v11 假设 + (A5)–(A7) + 引理 97–99 下，ĉ_t⁺⁺⁺ 有效 ⇒

## 8. 本轮最大风险

**一句话**：低成本声学通道的"便宜"是以**分布偏移与对抗音频**换来的（混响、口音、播放攻击、超声注入可让 AED 既漏报也假报），而语音权限把"人当安全备份"的假设在无人、误解、儿童或非母语场景下会**静默失效**——看似多了一层廉价冗余，实则可能在最需要它的时刻**既没听见、也没听懂**。
