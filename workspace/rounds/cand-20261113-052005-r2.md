# 第 65 轮（承接第 64 轮「GRIP 接触接地四层闭环」IP-204~213；灵感循环第 2 轮；本轮灵感：「云端协同」×「运动控制」）

> 第 64 轮用 F/T 与触觉把几何先验变成可证伪假设，其自述的最大风险一针见血：**当力/触觉存在未建模偏置、漂移、饱和，且接触模型本身错误（软接触、未建模动力学、接触点歧义）时，CGG 会把"传感器/模型错误"误判为"几何幻觉"——在正确几何上主动降级、在错误几何上放行，力觉从"接地真值"反变为新的单点故障与物理伤害源。**
>
> 根因是一个**可辨识性**缺陷：CGG 只使用**单机、单场景、单时刻**的残差，而 `e_t = b_i + m_c + h_s + η` 中的机器人偏置 `b_i`、物体类模型误差 `m_c`、场景几何幻觉 `h_s` 在单机观测下几乎同构，χ² 检验只能回答"残差大不大"，无法回答"是谁错了"。本轮从**云端协同**拿到"跨机器人 × 跨场景 × 跨时间"的第二维度，从**运动控制**拿到"时延/陈旧/丢包/坏节点下仍可证明安全"的执行层。核心命题是：
>
> **把"单机可证伪"升级为"跨机可辨识、云边可分工、时延可证明"——云端只负责让先验更可辨识，边缘只负责让运动永远安全；云可以建议，边缘必须认证。**

## 0. 直觉与动机

**灵感 1（云端协同 → 跨机残差微分诊断：FCC + CDD）**
直觉：一台机器人"感觉不对"时，它无法自证是"眼睛骗了它"还是"手坏了"。但整个机队可以：**偏置跟着机器人走**（同一台机器人在不同场景都偏），**几何幻觉跟着场景走**（不同机器人在同一场景都看到虚假接触面），**模型误差跟着物类走**（不同机器人、不同场景、同一物类都偏）。把机队残差排成一个 (机器人 × 场景 × 时间) 三向随机效应张量 `e_{i,s,t} = b_i + m_{c(s)} + h_s + ε`，其**协方差结构**就把三者分开了。云端聚合的是**充分统计量**（方差分量），不是原始力数据；边缘拿到的是"归因先验"，本地只测"残差幅度"。这直接把第 64 轮"传感器错 vs 几何错"的二义性变成**可判别假设**。

**灵感 2（云端协同 → 信任校准：TCP）**
直觉：云端不是真值，它是**更宽但更慢的观测**。WAN 有几十到几百毫秒时延、会丢包、会陈旧，机队里还可能有标定错误甚至被攻陷的节点。故云端先验必须自带**年龄、样本量、鲁棒置信度**：`w_c = g(τ)·h(N_eff)·κ_byz`，用 median-of-means / trimmed mean 做拜占庭鲁棒聚合（坏节点 < 1/2 时误差有界）。云端先验只是"又一个可证伪先验"，用的是同一套失效安全纪律。

**灵感 3（运动控制 → 时延感知参考调速 + CBF 安全滤波：DARG + DSC）**
直觉：云端计划坐网络过来时已经"过期"。若把云端轨迹当**指令**直接执行，一次 200ms 抖动就能撞上约束；正确做法是把它当**参考**：边缘缓存、外推，用**参考调速器**把参考缩放到鲁棒不变集 `O_∞` 内，再用**控制障碍函数 QP** 在 `φ ∈ B(φ̂,r)` 与 `δ ≤ δ_max` 的最坏情况下做安全过滤。**云端的建议永远不是边缘的命令**——这是把"云端成为新单点故障"从根上切断。

**灵感 4（运动控制 → 携带证书的云端计划与权威交接：CCP + MST）**
直觉：云端应像编译器交付目标文件一样交付**计划 + 证书**：假定的 φ 区域、有效期 `T_v`、接触力包络、参考轨迹 Lipschitz 界、约束集与哈希。边缘只需 O(1) 校验三件事——**没过期、φ 假设仍覆盖当前 WCV 球、力/滑移条件仍满足**——通过则当参考，不通过则本机回退。权威状态机 `{CLOUD_REF, EDGE_AUTO, SAFE_HOLD}` 负责无扰切换（bumpless transfer）：云断了就降级本机，本机恢复了再交回，**任何时刻安全都只由边缘证明**。

**灵感 5（两灵感合流 → STRATUS：Staleness-aware Trust-calibrated Robust Autonomous Two-tier Uncertainty Split）**
合流为「云边协同 · 时延鲁棒 · 证书化运动控制」：云层做 FCC 语料聚合 → CDD 微分诊断 → TCP 信任先验 → CCP 计划证书；边层做 CGG-C（归因感知的接触检验）→ WCV-C 编译 → DARG 参考调速 → DSC 安全滤波 → MST 权威交接 → J_ce 证书。**第 63 轮是"几何层"、第 64 轮是"接触层"，STRATUS 再加"云边层"，使"谁错了"第一次可辨识，使"云掉线/云作恶"第一次不破坏安全。**

## 1. 形式化定义（增量：定义 217–232）

- **定义 217（STRATUS 云边闭环）**：STRATUS = (GRIP, FCC, CDD, TCP, CCP, DARG, DSC, MST, J_ce)。三层：**云层**（低频、跨机、可延迟）、**边层**（实时、单机、证书化）、**通信面**（时延/抖动/丢包/陈旧）。不变式：**任何触及执行器与实时安全的计算必须在边层就地完成；云层只产出可校验的先验与参考；边缘永远保留一个已验证的安全回退。**
- **定义 218（云边能力分割 Split）**：`split: 𝒯 → {CLOUD, EDGE, EITHER}`，约束三条：(i) 实时安全闭包 `{残差、CBF、力限、派发}` 必须 EDGE；(ii) 全局聚合/大模型/长程规划必须 CLOUD；(iii) 任何 CLOUD 产物必须被 EDGE 的 O(1) 证书校验器接受后才能影响运动。记 `Split-Valid` 当且仅当三条同时成立。
- **定义 219（FCC 机队残差张量与方差分量模型）**：机器人 i∈[N]、场景 s∈[S]、时刻 t，物类 c(s)。残差随机效应模型 `e_{i,s,t} = b_i + m_{c(s)} + h_s + ε_{i,s,t}`，`b_i~N(0,σ_b²I₆)`（机器人标定偏置，跨场景持续）、`m_c~N(0,σ_m²I₆)`（物类接触模型误差）、`h_s~N(0,σ_h²I₆)`（场景几何幻觉）、`ε~N(0,Σ_w)` 独立。任意两观测协方差 `Cov = 1[i=i']σ_b² + 1[c(s)=c(s')]σ_m² + 1[s=s']σ_h² + 1[同观测]σ_w²`；方差分量 `Θ=(σ_b²,σ_m²,σ_h²,σ_w²)` 在 N,S,类别交叉设计下可由成对协方差的矩估计或 REML 辨识。
- **定义 220（CDD 残差微分诊断）**：边缘只可观本地残差幅度，云端提供**归因份额** `(π_b,π_m,π_h) = (σ_b²,σ_m²,σ_h²)/Σσ²`。对假设 `H_geo`（h_s 主导）、`H_sen`（b_i 主导）、`H_mod`（m_c 主导）计算后验 `P(H|e,Θ)= p(e|H,Θ)P(H) / Σ`；决策：`P(H_geo)>τ_geo` 才降级几何；`P(H_sen)>τ_sen` 只标记传感器并触发重标定/膨胀 Σ_w，**不降级几何**；`P(H_mod)>τ_mod` 触发 APP 重辨识或膨胀模型误差；若最大后验 < τ_amb（不可辨识）→ **同时对几何与传感器失效安全膨胀**（保守双降级）。
- **定义 221（TCP 信任校准云端先验）**：云端先验 `N(φ_c,Σ_c)` 附 `(年龄 τ, 有效样本 N_eff, 鲁棒置信 κ_byz)`。信任权重 `w_c = clip( (N_eff/(N_eff+κ₀))·exp(−τ/τ_c)·κ_byz, 0,1)`。融合 `Σ_post⁻¹ = Σ_local⁻¹ + w_c·Σ_c⁻¹`，球心 `φ̂ = Σ_post(Σ_local⁻¹φ_local + w_cΣ_c⁻¹φ_c)`。鲁棒聚合用 **median-of-means**：把 N 个节点的充分统计量分 k 组取组均值再取中位数，坏节点比例 `f_byz < 1/2` 时逐坐标误差 `≤ O(σ/√N + f_byz·B)`。`τ>τ_max` 或心跳丢失 → `w_c=0`，退化为 GRIP。
- **定义 222（CCP 携带证书的云端计划）**：`Π_k = (x_d(t),u_d(t),K_d(t),f_d(t))_{t∈[t_k,t_k+T_p]}`，证书 `Cert_k = (Φ_k, T_v, F_env, L_Π, S_k, sig_k)`：假定 φ 区域、有效期、接触力包络、轨迹 Lipschitz 界、约束集、签名。边缘接受谓词 `Accept(Π_k,t)` ⇔ `t−t_k ≤ T_v` ∧ `B(φ̂,r) ⊆ Φ_k`（或重叠度 ≥ θ_ov 且质量加权风险可接受）∧ `F_env ⊆ FCS 限值` ∧ `S_k ⊆ 已验证安全集` ∧ 签名有效。拒绝则本机回退，**不是"降级使用云端计划"**。
- **定义 223（通信扰动集与陈旧度）**：`ℰ_comm = {δ∈[0,δ_max]} × {jitter} × {dropout p_d≤p_max} × {τ_age≤T_v} × {byzantine fraction f_byz<1/2}`。通信裕度 `ρ_comm = min(δ_max−δ̂, p_max−p̂_d, T_v−τ_age, 1/2−f̂_byz)`。`ρ_comm<0` → 强制 `MST→SAFE_HOLD` 或 `EDGE_AUTO`。
- **定义 224（DARG 时延感知参考调速器）**：边缘维护计划缓存与鲁棒不变集 `O_∞(r,δ_max)`。对云端参考 `x_d(t)`（绝对时间索引，晚到只是让"当前参考"更旧而非错位），求最大 `α∈[0,1]` 使 `x` 在 `u = u_safe + α·(u_ref−u_safe)` 下停留于 `O_∞`，输出 `x_ref = x_safe + α(x_d−x_safe)`；缓存缺失时用 Lipschitz 外推 `x̂_d(t) = x_d(t_k)+L_Π(t−t_k)`，外推误差管 `ρ_tube = ½a_max(t−t_k)²` 并入约束裕度。
- **定义 225（DSC 时延鲁棒安全滤波）**：`u* = argmin_u ‖u−u_ref‖²`，s.t. `L_f h(x)+L_g h(x)u+α_cbf h(x) ≥ M_robust`，`M_robust = L_h(L_Π δ_max + ½a_max δ_max²) + L_hφ·r + δ_F`。等价地 `h` 取 GRIP 的接触/力/关节约束集合。回退 `u_safe ∈ K_safe`（GRIP 已验证）保证 QP 永远可行；`h(x)≥0` 的鲁棒不变性对 `∀φ∈B(φ̂,r), ∀δ≤δ_max` 成立。
- **定义 226（MST 运动权威交接）**：状态机 `{CLOUD_REF, EDGE_AUTO, SAFE_HOLD}`。`CLOUD_REF→EDGE_AUTO`：`Accept` 失败、心跳超时、`ρ_comm<0`、或云端与边缘安全集偏差 `d_H(S_cloud,S_edge)>θ_hand`；`EDGE_AUTO→CLOUD_REF`：连续 m 个计划被接受且 `ρ_comm≥0`；`→SAFE_HOLD`：DSC 不可行或 `ρ_force/ρ_slip<0`。切换用参考调速器做**无扰转移**（切换瞬间 `u` 连续，`Δu≤ε_bump`）。
- **定义 227（失效安全膨胀 Cloud-Unavailable）**：云不可用/不可辨识时令 `w_c=0`、`π` 取均匀先验、`r ← max(r, κ_unc·r)`（κ_unc=1.5）、同时置 `sensor_suspect=True` 与 `geo_degraded=True`。**方向固定保守**：云缺失只会让系统更保守，绝不会让系统更自信。
- **定义 228（CGG-C 云端辅助接触检验）**：在定义 203 上把"拒绝即降级几何"改为**归因条件降级**：`T̄>阈值 ∧ P(H_geo)>τ_geo → demote_geo()`；`T̄>阈值 ∧ P(H_sen)>τ_sen → recalibrate_sensor()`（膨胀 Σ_w、冻结几何、请求重标定，几何不降级）；`P(H_mod)>τ_mod → app.reidentify()`；不可辨识 → 双膨胀。这样第 64 轮的"误判"被显式拆成三条不同动作。
- **定义 229（FCC 更新与隐私）**：节点只上传**充分统计量**（残差均值/二阶矩、时间戳、场景/物类哈希、传感器型号码），不上传原始力/触觉张量；上传前加 `(ε_dp,δ_dp)`-差分隐私噪声或安全聚合。云端 `Θ` 用指数遗忘加权 `~Σ_t λ^{t}·stats` 在线更新，旧场景/旧物体自然淡出。
- **定义 230（运动控制证书条件）**：若 `Accept(Π_k,t)` 成立且 DSC 可行，则跟踪误差满足 `‖x(t)−x_d(t)‖ ≤ ρ_tube(r,δ_max) + κ_trk·e^{−λt}‖x(0)−x_d(0)‖`，且 `h(x(t))≥0 ∀t`（概率 ≥1−α）。证书记录 `(ρ_tube, λ, α, δ_max, r)`。
- **定义 231（J_ce 扩展证书）**：`J_ce = (J_grip, fault_label, diag_posterior_hash, ρ_comm, τ_age, cloud_plan_hash, split_ver, authority_state, dp_ε)`。`Valid(J_ce) ⇔ Valid(J_grip) ∧ Split-Valid ∧ (fault_label=unidentifiable ⇒ sensor_suspect ∧ geo_degraded) ∧ ρ_comm≥0 ∧ τ_age≤T_v ∧ cloud_plan_hash 与所执行参考一致（或 authority=EDGE_AUTO/SAFE_HOLD）∧ dp_ε≤ε_dp,max`。
- **定义 232（STRATUS 闭环算子）**：云层（10–100Hz 甚至更低）[FCC 聚合 → CDD 归因 → TCP 云端先验 → 长程 TSL/CSP 规划 → CCP 计划+证书]；边层实时 [锚点读 → CGG-C 残差 → WCV-C 编译 → DARG 调速（用缓存/外推）→ DSC 安全滤波 → FCS/SLD → MST 派发 → J_ce 构建]，边层语义线程再做 CGG-C 归因更新、APP/FPE、OLP-F、AIC-F。不变式：**边层安全路径不读云端返回值，只读本地已验证状态与缓存证书。**

```python
# 云层（低频）：FCC → CDD → TCP → CCP
Theta = fcc.update(robot_stats)                      # 方差分量（MoM/REML）
pi_b, pi_m, pi_h = cdd.attribution(Theta)            # 归因份额
phi_c, Sigma_c = tcp.cloud_prior(pi_h, fleet_stats, age)
plan, cert = cloud_planner.plan(phi_c, goal)         # 计划 + 证书
send_async(plan, cert, ts=now, dp_noise=eps_dp)

# 边层（实时）：CGG-C → WCV-C → DARG → DSC → MST
T = cgg.residual(W_meas, phi_hat, contacts)
label = cdd.diagnose_local(T, pi_b, pi_m, pi_h, tau)  # geo/sen/mod/unidentifiable
if label == 'geo':   demote_geo(r)
elif label == 'sen': recalibrate_sensor(); inflate(Sigma_w); r = max(r, kappa_unc*r)
elif label == 'mod': app.reidentify(); inflate_model()
else:                demote_geo(r); sensor_suspect = True   # 不可辨识 → 双保守

ok, reason = cert_verifier.accept(plan, cert, t, B(phi_hat, r), FCS, safe_set)
if not ok or heartbeat_lost or rho_comm < 0:
    authority = EDGE_AUTO; x_ref = local_safe_reference()
else:
    authority = CLOUD_REF; x_ref = darg.govern(plan.x_d(t), x, O_inf)

u_ref = tracking_controller(x, x_ref)
u_safe = wcv_c.safe_fallback(phi_hat, r)             # GRIP 已验证
u = dsc.qp(x, u_ref, u_safe, r, delta_max, h_set)
J_ce = build_jce(J_grip, label, rho_comm, tau, hash(plan), authority)
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 7（跨机可辨识性）**：在定义 219 的交叉随机效应模型下，`H_geo/H_sen/H_mod` 可辨识当且仅当 `N≥2, S≥2` 且存在同场景跨机与同机跨场景的观测对；归因后验的误判概率随 `N·S·SNR` 指数下降。**这是第 64 轮单机 CGG 做不到的。**
- **引理 8（陈旧先验的优雅退化）**：`w_c` 随 `τ` 指数衰减，`τ>τ_max` 时 `w_c=0`，STRATUS 严格退化为 GRIP；融合后误差界 `‖φ̂−φ*‖ ≤ ‖φ̂_local−φ*‖ + O(√(1/w_c))`，故云端只可能"帮不上忙"，不会把本机估计拉坏。
- **定理 7（云安全非干扰）**：对**任意**云端消息 `m`（含过期、错误、拜占庭），边缘 `DSC` 安全滤波与已验证回退 `u_safe` 保证 `h(x_t)≥0 ∀t`（概率 ≥1−α）。形式化：安全不变式与 `m` 的分布无关；云端只影响跟踪代价上界，不影响安全性。**这就从根上否证了"云端成为新单点故障"。**
- **定理 8（时延鲁棒可行性）**：若 `δ≤δ_max`、`Accept` 成立且 `O_∞` 非空，则 DARG+DSC 下约束满足且跟踪误差 ≤ `ρ_tube(r,δ_max)+κ_trk e^{−λt}‖e₀‖`；`ρ_tube` 随 `δ_max` 二次增长，给出"时延预算 ↔ 性能"的显式权衡。
- **定理 9（STRATUS 端到端证书）**：`Valid(J_ce)` ⇒ 局部 GRIP 四层安全（几何/接触/滑移/力限）∧ 归因正确（概率 ≥1−α_diag）∧ 时延鲁棒（定义 230）∧ 云安全非干扰（定理 7）——**证书链从"几何-技能-干扰-接触"扩为"几何-技能-干扰-接触-云边"五层**。
- **实时性**：证书校验 O(1) <0.3ms、DARG <0.4ms、DSC QP <0.8ms、CGG-C 残差 <0.05ms、MST <0.05ms；叠加 GRIP 实时路径，**边层 ≤2ms 契约不变**；云层无实时约束。

## 2. 形式化定义（完整版）

**定义 217（STRATUS 云边闭环）** STRATUS 是 GRIP 的"云边层"升级，分三层：**云层**（低频、跨机、可延迟、可离线）执行 FCC 聚合、CDD 归因、TCP 云端先验、长程 TSL/CSP 规划、CCP 证书生成；**边层**（实时、单机、证书化）执行 CGG-C 残差、WCV-C 编译、DARG 调速、DSC 安全滤波、FCS/SLD 检查、MST 派发与 J_ce 构建；**通信面**刻画时延、抖动、丢包、陈旧、坏节点。不变式：**边层实时安全路径不读取云端返回值，只读取本地已验证状态与本地缓存中通过 `Accept` 的证书；云层永远不直接驱动执行器。**

**定义 218（云边能力分割）** `split: 𝒯→{CLOUD,EDGE,EITHER}`。三条硬约束：
1. **安全闭包在边缘**：`{CGG 残差, SLD, FCS, WCV-C 编译, DARG, DSC, 派发}` 必须 `EDGE`；
2. **全局聚合在云端**：`{FCC 方差分量, 机队归因, 大模型先验, 长程规划}` 必须 `CLOUD`；
3. **云端产物必须被边缘证书校验**：任何 `CLOUD` 输出影响运动前必须通过 `Accept`（定义 222）且 `Split-Valid`。
`Split-Valid ⇔` 三条同时成立。该定义把"云端成为单点故障"从架构层禁止，而非靠运行时运气。

**定义 219（FCC 机队残差张量与方差分量模型）** 机器人 i∈[N]、场景 s∈[S]、时刻 t、物类 c(s)。残差三向随机效应模型
`e_{i,s,t} = b_i + m_{c(s)} + h_s + ε_{i,s,t}`，
其中 `b_i~N(0,σ_b²I₆)`、`m_c~N(0,σ_m²I₆)`、`h_s~N(0,σ_h²I₆)`、`ε~N(0,Σ_w)` 相互独立。任两观测的协方差
`Cov(e_{i,s,t}, e_{i',s',t'}) = 1[i=i']σ_b² + 1[c(s)=c(s')]σ_m² + 1[s=s']σ_h² + 1[同一观测]σ_w²`。
`Θ=(σ_b²,σ_m²,σ_h²,σ_w²)` 在 `N≥2, S≥2` 且存在"同机跨场景"与"同场景跨机"观测对的交叉设计下可辨识；云端用成对协方差矩估计或 REML 求解。注意：**这是跨机层才拥有的自由度**；单机只有 `σ_b²+σ_m²+σ_h²+σ_w²` 一个总量，故第 64 轮 CGG 在原理上不可区分三者。

**定义 220（CDD 残差微分诊断）** 边缘只能观测本地残差幅度，云端提供归因份额 `(π_b,π_m,π_h)`。对三个假设
- `H_geo`：`h_s` 主导（几何幻觉 / 分布外几何）；
- `H_sen`：`b_i` 主导（本机 F/T 偏置、漂移、标定误差）；
- `H_mod`：`m_c` 主导（软接触、未建模动力学、接触点歧义）
计算后验 `P(H|e,Θ) = p(e|H,Θ)P(H) / Σ_{H'} p(e|H',Θ)P(H')`。决策规则：
```
if P(H_geo) > τ_geo:          fault = 'geo'; demote_geo(r)
elif P(H_sen) > τ_sen:        fault = 'sen'; recalibrate_sensor(); inflate(Σ_w); r ← max(r, κ_unc·r)
elif P(H_mod) > τ_mod:        fault = 'mod'; app.reidentify(); inflate_model_error()
else:                         fault = 'unidentifiable'
                              demote_geo(r); sensor_suspect = True; r ← max(r, κ_unc·r)
```
`unidentifiable` 分支是**双保守**：既不冤枉几何、也不轻信传感器，方向固定为膨胀。默认 `τ_geo=τ_sen=τ_mod=0.7, τ_amb=0.4`。

**定义 221（TCP 信任校准云端先验）** 云端先验 `N(φ_c,Σ_c)` 附三元组 `(τ, N_eff, κ_byz)`（年龄、有效样本量、鲁棒置信）。信任权重
`w_c = clip( (N_eff/(N_eff+κ₀))·exp(−τ/τ_c)·κ_byz, 0, 1)`，
融合后验
`Σ_post⁻¹ = Σ_local⁻¹ + w_c·Σ_c⁻¹`，`φ̂ = Σ_post(Σ_local⁻¹φ_local + w_cΣ_c⁻¹φ_c)`。
鲁棒聚合采用 **median-of-means**：把 N 个节点的充分统计量随机分为 k≈√N 组，取组均值后逐坐标取中位数。当坏节点比例 `f_byz<1/2` 时，逐坐标估计误差 `≤ O(σ/√N + f_byz·B)`（B 为坏节点取值上界）；`f_byz≥1/2` 时中位数失效，触发 `unidentifiable` 与 `SAFE_HOLD`。`τ>τ_max` 或心跳丢失 → `w_c=0`，STRATUS 严格退化为 GRIP。

**定义 222（CCP 携带证书的云端计划）** 云端计划
`Π_k = (x_d(t), u_d(t), K_d(t), f_d(t))_{t∈[t_k, t_k+T_p]}`，
证书 `Cert_k = (Φ_k, T_v, F_env, L_Π, S_k, sig_k)`：假定 φ 区域、有效期、接触力/压强包络、轨迹 Lipschitz 界、声明约束集、签名。边缘接受谓词
```
Accept(Π_k, t) ⇔ (t − t_k ≤ T_v)
              ∧ (B(φ̂, r) ⊆ Φ_k  ∨  (overlap(B,Φ_k) ≥ θ_ov ∧ 质量加权风险 ≤ δ_risk))
              ∧ (F_env ⊆ FCS 限值 ∧ 滑移裕度 ≥ 0)
              ∧ (S_k ⊆ S_edge_verified)
              ∧ verify(sig_k)
```
**关键语义**：不接受就是"整个计划不用、回退本机"，而不是"挑着用云端计划的一部分"——后者会破坏证书的成分性。默认 `θ_ov=0.9, δ_risk=α_ce/2`。

**定义 223（通信扰动集与陈旧度）** `ℰ_comm = {δ∈[0,δ_max]}×{jitter}×{dropout p_d≤p_max}×{τ_age≤T_v}×{byzantine f_byz<1/2}`。通信裕度
`ρ_comm = min(δ_max−δ̂, p_max−p̂_d, T_v−τ_age, 1/2−f̂_byz)`。
`ρ_comm<0` → 强制 `MST→EDGE_AUTO`（若 DSC 可行）或 `SAFE_HOLD`。`ρ_comm` 与 `ρ_force/ρ_slip/ρ_rob/ρ_dir` 并列进入 J_ce。

**定义 224（DARG 时延感知参考调速器）** 边缘维护计划缓存与鲁棒不变集 `O_∞(r,δ_max)`（对 `∀φ∈B(φ̂,r)`、`∀δ≤δ_max` 前向不变）。给定云端绝对时间索引参考 `x_d(t)`（晚到只让"当前参考"更旧，不会错位），求
`α* = max{α∈[0,1] : x 在 u=u_safe+α(u_ref−u_safe) 下停留于 O_∞}`，
输出 `x_ref = x_safe + α*(x_d−x_safe)`。缓存缺失时用 Lipschitz 外推
`x̂_d(t) = x_d(t_k) + L_Π(t−t_k)`，
外推误差管 `ρ_tube(t) = L_Π(t−t_k) + ½a_max(t−t_k)²`，并入 DSC 约束裕度。`α` 单调、连续，保证无扰。

**定义 225（DSC 时延鲁棒安全滤波器）** 
```
u* = argmin_u ‖u − u_ref‖²
     s.t. L_f h(x) + L_g h(x)u + α_cbf h(x) ≥ M_robust
          M_robust = L_h·ρ_tube + L_hφ·r + δ_F
```
`h` 取 GRIP 的接触/力限/滑移/关节约束集合之交集。可行性：GRIP 已验证 `u_safe∈K_safe` 满足标称 CBF，且 `O_∞` 非空（假设 A88），故 QP 总有可行内点；若数值不可行 → `SAFE_HOLD` + compliant retreat。鲁棒不变性对 `∀φ∈B(φ̂,r), ∀δ≤δ_max` 成立。

**定义 226（MST 运动权威交接）** 状态机 `{CLOUD_REF, EDGE_AUTO, SAFE_HOLD}`：
- `CLOUD_REF→EDGE_AUTO`：`¬Accept` 或心跳超时或 `ρ_comm<0` 或 `d_H(S_cloud,S_edge)>θ_hand`；
- `EDGE_AUTO→CLOUD_REF`：连续 m 个计划 `Accept` 且 `ρ_comm≥0`；
- `至 SAFE_HOLD`：DSC 不可行或 `ρ_force<0` 或 `ρ_slip<0`。
切换通过 DARG 的 `α` 连续化，保证 `‖u(t⁺)−u(t⁻)‖≤ε_bump`（无扰转移）。**权威只影响参考来源，不影响安全滤波层级。**

**定义 227（失效安全膨胀 Cloud-Unavailable）** 云不可用或归因不可辨识时：`w_c=0`；`π` 取均匀先验；`r←max(r,κ_unc·r)`（κ_unc=1.5）；`sensor_suspect=True`；`geo_degraded=True`。**方向固定保守**：云缺失只会让系统更保守、更慢，绝不会更自信。该定义使 STRATUS 在断云时**可证明地回落到 GRIP 的失效安全语义**。

**定义 228（CGG-C 云端辅助接触检验）** 定义 203 的归因版：先算 `T̄`，再按定义 220 归因：
- `H_geo` → 执行原 `demote()`（几何球膨胀、λ_geo↓、force 主导）；
- `H_sen` → **不降级几何**；膨胀 `Σ_w`、冻结几何先验、置 `sensor_suspect`、请求重标定；若重标定不可用则 `r←max(r, κ_unc r)`；
- `H_mod` → 触发 APP 重辨识与模型误差膨胀，几何先验保留；
- `unidentifiable` → 双膨胀。
这直接消除了第 64 轮"在正确几何上主动降级（假阳）/在错误几何上放行（假阴）"的单一误判路径。

**定义 229（FCC 更新与隐私）** 节点只上传充分统计量：残差一阶/二阶矩、时间戳、场景/物类哈希、传感器型号码、健康标志；不上传原始力/触觉张量。上传前施加 `(ε_dp,δ_dp)`-差分隐私噪声或安全聚合。云端用指数遗忘 `Θ ← argmin Σ_t λ^{t0−t}‖stats_t − E[stats;Θ]‖²` 在线更新，旧场景/旧物类自然淡出。`dp_ε≤ε_dp,max` 写入 J_ce。

**定义 230（运动控制证书条件）** 若 `Accept(Π_k,t)` 且 DSC 可行，则
`‖x(t)−x_d(t)‖ ≤ ρ_tube(r,δ_max) + κ_trk·e^{−λt}‖x(0)−x_d(0)‖`，
且 `h(x(t))≥0 ∀t`（概率 ≥1−α）。证明在定理 8。证书记录 `(ρ_tube, λ, α, δ_max, r, u_safe_hash)`。

**定义 231（J_ce 扩展证书）**
`J_ce = (J_grip, fault_label, diag_posterior_hash, ρ_comm, τ_age, cloud_plan_hash, split_ver, authority_state, dp_ε)`。
`Valid(J_ce) ⇔`
`Valid(J_grip)`
`∧ Split-Valid`
`∧ (fault_label=unidentifiable ⇒ sensor_suspect ∧ geo_degraded)`
`∧ ρ_comm≥0`
`∧ τ_age≤T_v`
`∧ (authority_state∈{EDGE_AUTO,SAFE_HOLD} ∨ cloud_plan_hash 与所执行参考一致)`
`∧ dp_ε≤ε_dp,max`。
审计链：`fault_label` 追溯"谁错了"，`diag_posterior_hash` 追溯归因证据，`cloud_plan_hash` 追溯云端计划，`authority_state` 追溯运动权威，`ρ_comm/τ_age` 追溯通信质量。

**定义 232（STRATUS 闭环算子）** 云层（10–100Hz 或更低）：`[FCC 聚合 → CDD 归因 → TCP 云端先验 → 长程 TSL/CSP 规划 → CCP 计划+证书 → 异步下发]`；边层实时：`[锚点读 → CGG-C 残差 → WCV-C 编译 → DARG 调速（缓存/外推）→ DSC 安全滤波 → FCS/SLD → MST 派发 → J_ce]`；边层语义线程：`[CGG-C 归因更新 → APP/FPE → OLP-F → AIC-F → SSB]`。不变式同定义 217：**边层安全路径不依赖云端返回值。**

```python
class FleetContactCorpus:
    """云端：只收充分统计量，做三向随机效应方差分量估计。"""
    def update(self, node_stats, lam=0.995):
        # node_stats: [(robot_id, scene_id, class_id, mean_e, second_moment, ts, hw_id)]
        for st in node_stats:
            self.buffer.add(st, weight=lam ** age(st.ts))
        # 成对协方差矩估计（或 REML）
        C_same_robot  = self._mean_cov(same_robot=True,  same_scene=False)
        C_same_scene  = self._mean_cov(same_robot=False, same_scene=True)
        C_same_class  = self._mean_cov(same_robot=False, same_scene=False, same_class=True)
        C_noise       = self._mean_diag_var()
        sigma_b2 = max(0.0, C_same_robot - C_same_class)
        sigma_h2 = max(0.0, C_same_scene - C_same_class)
        sigma_m2 = max(0.0, C_same_class)
        # 拜占庭鲁棒：median-of-means
        return robust_mom([sigma_b2, sigma_m2, sigma_h2, C_noise])

class ContactDifferentialDiagnosis:
    HYP = ('geo', 'sen', 'mod')
    def attribution(self, Theta):
        s = Theta['b'] + Theta['m'] + Theta['h'] + 1e-9
        return Theta['b']/s, Theta['m']/s, Theta['h']/s

    def diagnose_local(self, T_bar, pi_b, pi_m, pi_h, tau, w_c):
        # 云端归因随陈旧度向均匀先验收缩（不可辨识 → 保守）
        pi = np.array([pi_b, pi_m, pi_h])
        pi = w_c * pi + (1 - w_c) * np.ones(3) / 3
        # 边缘只有总残差幅度；用归因份额分配似然
        loglik = np.log(pi + 1e-12) + self._magnitude_term(T_bar, pi)
        post = softmax(loglik)
        p_geo, p_sen, p_mod = post
        if p_geo > TAU_GEO: return 'geo'
        if p_sen > TAU_SEN: return 'sen'
        if p_mod > TAU_MOD: return 'mod'
        return 'unidentifiable'

class TrustCalibratedPrior:
    def fuse(self, phi_local, Sigma_local, phi_c, Sigma_c, tau, N_eff, kappa_byz):
        w_c = clip((N_eff/(N_eff+K0)) * exp(-tau/TAU_C) * kappa_byz, 0.0, 1.0)
        if w_c <= 0:
            return phi_local, Sigma_local, 0.0
        P_post = inv(inv(Sigma_local) + w_c * inv(Sigma_c))
        phi_post = P_post @ (inv(Sigma_local) @ phi_local + w_c * inv(Sigma_c) @ phi_c)
        return phi_post, P_post, w_c
```

```python
class DelayAwareReferenceGovernor:
    def govern(self, x, x_d_future, x_safe, O_inf, t, t_k):
        if x_d_future is None:
            x_d = self._lipschitz_extrapolate(t, t_k)
        else:
            x_d = x_d_future
        def in_invariant(alpha):
            u = x_safe.u + alpha * (self.u_ref_from(x_d) - x_safe.u)
            return O_inf.contains(self.predict(x, u))
        alpha = bisect_max(in_invariant, lo=0.0, hi=1.0, iters=12)
        return x_safe.x + alpha * (x_d - x_safe.x), alpha

class DelayRobustSafetyFilter:
    def qp(self, x, u_ref, u_safe, r, delta_max, h_set):
        Lh = lipschitz_h(h_set, x)
        M = Lh * (PLAN_LIP * delta_max + 0.5 * A_MAX * delta_max**2) + r + DELTA_F
        u = solve_qp(cost=lambda u: norm(u - u_ref)**2,
                     cbf=lambda u: Lf_h(h_set, x) + Lg_h(h_set, x) @ u
                                  + ALPHA_CBF * h_min(h_set, x) - M)
        if u is None:
            return u_safe, 'SAFE_HOLD'
        return u, 'ok'

class MotionAuthority:
    def step(self, accept, rho_comm, dsc_ok, rho_force, rho_slip, consecutive_ok):
        if not dsc_ok or rho_force < 0 or rho_slip < 0:
            return 'SAFE_HOLD'
        if (not accept) or rho_comm < 0:
            return 'EDGE_AUTO'
        if consecutive_ok >= M_HAND and rho_comm >= 0:
```

### IP-223 STRATUS 闭环算子

```python
def STRATUS_round(M, obs):
    V, T, P, L, P_cloud, W_meas, tactile, comm = obs
    # ———— 云层（异步，不阻塞边层）————
    # 云端已离线完成：FCC.update -> CDD.attribution -> TCP -> CCP
    plan, cert, cloud_age = M.cloud.poll_latest()

    # ———— 边层语义线程 ————
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))
    phi_geo, z_scene, pi_int, (U_ep, U_al) = M.mel.infer_by_mode(
        M.ocb_skill.choose().mel_mode, V, T, P, L, x_prime)

    # 1) CGG-C：残差 + 归因
    T_bar = M.cgg.residual_window(W_meas, M.q, phi_geo, M.mws.last_contacts, M.Sigma_w)
    pi_b, pi_m, pi_h = M.cdd.attribution(M.fcc.Theta)
    fault = M.cdd.diagnose_local(T_bar, pi_b, pi_m, pi_h, cloud_age, M.tcp.w_c)
    r = M.cgg_c.apply(fault, M.rsc.r, M.Sigma_w)     # 定义 228

    # 2) MWS / APP / FPE / TCP 融合
    contacts, ambiguous = M.mws.decompose(W_meas, M.surface, M.mu_hat, M.Sigma_w)
    if ambiguous or fault in ('mod', 'unidentifiable'):
        a_star, _ = M.app.choose_probe(phi_geo, M.J_geo, M.object_class, M.history)
        if a_star is not None:
            probe_log = M.execute_probe(a_star)
            phi_f, Sigma_f, mu_hat, mu_ci = M.fpe.identify(probe_log, M.Sigma_w)
        else:
            phi_f, Sigma_f = None, None
    else:
        phi_f, Sigma_f = M.last_phi_force, M.last_Sigma_force
    phi_hat, Sigma_hat, w_c = M.tcp.fuse(
        phi_geo, M.Sigma_geo, M.cloud.phi_c, M.cloud.Sigma_c,
        cloud_age, M.cloud.N_eff, M.cloud.kappa_byz)
    r = max(r, kappa_unc * M.rsc.r) if w_c == 0 else r

    # 3) WCV-C 编译
    K_safe, rho_rob = M.wcv_c.compile(x_prime, phi_hat, r, M.geo_set, M.mu_hat, M.f_lim)

    # 4) CCP 校验 + MST
    accepted, reason = M.verifier.accept(plan, cert, now(), phi_hat, r, M.fcs, M.safe_set)
    rho_comm = comm_margin(comm)
    authority = M.mst.step(accepted, rho_comm, True, M.rho_force, M.rho_slip, M.consec_ok)

    # 5) DARG + DSC（实时）
    if authority == 'CLOUD_REF':
        x_ref, alpha = M.darg.govern(M.x, plan.x_d(now()), M.local_safe, M.O_inf, now(), plan.t_k)
    else:
        x_ref = M.local_safe.x
    u_ref = M.tracker(x, x_ref)
    u, hold = M.dsc.qp(M.x, u_ref, M.u_safe, r, comm.delta_max, M.h_set)
    if hold == 'SAFE_HOLD':
        authority = 'SAFE_HOLD'; u = M.retreat.u

    # 6) 力觉安全 + 派发
    M.rho_force = M.fcs.check(contacts, [u.f_des], M.area_per_contact)
    if M.rho_force < 0:
        u = M.retreat.blend(u)
    EV = M.ertc.dispatch(u)

    # ———— 证书 ————
    return build_jce(M.j_grip_last, fault, M.cdd.posterior_hash, rho_comm,
                     cloud_age, hash(plan), SPLIT_VER, authority, M.dp_eps)
```

## 4. 推导

**引理 7（跨机可辨识性）** 在定义 219 的交叉随机效应模型下，考虑方差分量 `Θ`。成对协方差矩阵 `Cov(e_{i,s,t},e_{i',s',t'})` 在四类配对上的取值：
- 同机、异场景、异物类：`σ_b² + 1[同观测]σ_w²`
- 异机、同场景：`σ_h² + 1[同观测]σ_w²`
- 异机、异场景、同物类：`σ_m²`
- 异机、异场景、异物类：`0`

这是一个块状设计（block design）。当 `N≥2, S≥2` 且同时存在"同机跨场景对"与"同场景跨机对"时，三个方程线性独立，`(σ_b²,σ_m²,σ_h²)` 可辨识。反之，单机（N=1）时第二类配对不存在，`σ_b²` 与 `σ_h²` 不可分辨——这正是第 64 轮 CGG 的结构性盲点。归因后验的误判概率：由 Bernstein 不等式，`N_eff·S_eff` 个近独立配对下，份额估计误差 `O(1/√(N_eff S_eff))`，经后验阈值 `τ` 分离后误判率 `≤ exp(−c·N_eff·S_eff·SNR·(τ−1/2)²)`。故机队规模与场景多样性直接把"不可辨识"变成"可辨识"。∎

**引理 8（陈旧先验的优雅退化）** 融合式 `Σ_post⁻¹ = Σ_local⁻¹ + w_cΣ_c⁻¹`。当 `w_c→0`，`Σ_post→Σ_local`、`φ̂→φ_local`，STRATUS 的估计部分严格退化为 GRIP。误差分解：
`‖φ̂−φ*‖ ≤ ‖φ̂_local−φ*‖ + ‖φ̂−φ̂_local‖`。
第二项由加权平均界 `≤ (w_c·tr Σ_c/(tr Σ_local + w_c tr Σ_c))·‖φ_c−φ_local‖`。当云端先验偏差有界 `‖φ_c−φ*‖≤B_c` 且 `w_c` 衰减，附加误差 `≤ w_c B_c`，单调可忽略。`τ>τ_max` 时 `w_c=0`，附加误差恒 0。∎

**定理 7（云安全非干扰）** 设边缘动作 `u_t = DSC(x_t, u_ref,t, u_safe,t)`，其中 `u_ref` 可依赖任意云端消息 `m_t`（包括过期、错误、拜占庭），而 `DSC` 与 `u_safe` 只依赖本地状态与已验证证书。记安全集 `𝒮 = {x: h(x)≥0}`。由定义 225，DSC 的 CBF 约束对 `∀φ∈B(φ̂,r), ∀δ≤δ_max` 保证 `h(x_{t+1}) ≥ (1−α_cbf Δ)h(x_t) ≥ 0`，且当 QP 不可行时回退 `u_safe∈K_safe`（GRIP 已验证满足标称 CBF）。故闭环满足 `h(x_t)≥0 ∀t` 的概率下界 `1−α` **与 `m_t` 的分布无关**。云端消息只改变 `u_ref`，从而只改变跟踪代价 `J_trk(m)`；存在与 `m` 无关的常数 `C` 使 `J_trk ≤ C·(1+‖m−m_safe‖)`。因此"云端作恶/掉线"不会破坏安全，只可能降低性能。∎

**定理 8（时延鲁棒可行性）** 设真实计划满足 `‖x_d(t)−x_d(t')‖≤L_Π|t−t'|`、`‖ẍ_d‖≤a_max`。边缘在 `t` 使用 `t_k` 时刻计划，外推误差 `‖x̂_d(t)−x_d(t)‖ ≤ L_Π(t−t_k)+½a_max(t−t_k)² = ρ_tube(t)`。DSC 的 CBF 裕度 `M_robust ≥ L_hρ_tube + L_hφ r + δ_F` 覆盖该误差与 φ 球内最坏模型误差。于是对任意 `δ≤δ_max`，约束满足；跟踪误差由输入到状态稳定性（ISS）：
`‖x(t)−x_d(t)‖ ≤ ρ_tube(r,δ_max) + κ_trk e^{−λt}‖x(0)−x_d(0)‖`。
`ρ_tube` 对 `δ_max` 二次增长，故时延预算与跟踪性能间有显式二次权衡 `性能 ~ 1/(L_Πδ_max+½a_maxδ_max²)`。∎

**定理 9（STRATUS 端到端证书）** 假设 GRIP 的 A83–A87 及：
- **(A88)** 存在非空鲁棒不变集 `O_∞(r,δ_max)` 与已验证回退 `u_safe∈K_safe`，DSC 的 QP 在 `O_∞` 上可行；
- **(A89)** 机队场景/物类覆盖使 `Θ` 可辨识，或 `w_c` 的陈旧/拜占庭下降使系统进入 `unidentifiable` 双保守分支（即"不可辨识不导致不安全，只导致保守"）；
- **(A90)** 云端与边缘共享有界时钟偏斜 `|skew|≤δ_skew`，`Accept` 使用边缘时钟并留出 `δ_skew` 余量。
则 `Valid(J_ce)` ⇒
1. **局部安全**：`Valid(J_grip)`（几何接受或降级、φ 球含真值、滑移/力限安全），由定理 6；
2. **归因安全**：`fault_label` 正确或为 `unidentifiable`，后者强制双膨胀，故不会"自信地错"（引理 7、定义 228）；
3. **时延安全**：`ρ_tube` 覆盖且 `h(x)≥0`（定理 8）；
4. **云安全非干扰**：任意云端消息不破坏 1–3（定理 7）；
5. **优雅降级**：断云 `→EDGE_AUTO`，DSC 不可行 `→SAFE_HOLD`，不可辨识 `→` 双保守，均回落到 GRIP 或更保守语义。
故证书链从"几何-技能-干扰-接触"扩为"**几何-技能-干扰-接触-云边**"五层。∎

**命题（云端的可辨识信息增益）** 单机 CGG 对三假设的互信息 `I(H;e_local) ≤ H(H) − E[log(1+√(2πe σ_total²))]`，其归因误差不随观测时间下降（三假设同构）。跨机层引入 `N·S` 个近独立配对后，方差分量的 Fisher 信息 `J_Θ ∝ N_eff·S_eff/σ⁴`，归因后验熵
`H(H|e,Θ_cloud) ≈ H(H) − ½log det(I + J_Θ Σ_prior)`，
随 `N_eff·S_eff` 对数增长。故**云端的价值不是"更多同一份数据"，而是"不同相关结构的对照"**——单机永远无法自造出"同场景跨机"这一维度。∎

## 7. 已知风险

**一句话**：跨机可辨识性依赖"机队场景/物类覆盖足够且同分布"，一旦新场景/新物类在机队中**无先例**（`N_eff→0`、`π` 不可辨识），CDD 会退回"双降级"的保守模式，此时系统虽安全却可能**长期过度保守、任务不可用**；而若云端先验被系统性分布漂移污染，`w_c` 又会在陈旧度尚可时把错误归因当成"机队共识"注入——**云端从"可辨识性来源"反转为"共识性错误放大器"**，这是本轮所有跨机论证共同依赖的隐藏假设（A89）。

**次级风险与缓解**：
1. **机队分布漂移 / 新场景无先例**：`N_eff` 崩塌 → `unidentifiable` 双保守，任务变慢但安全；缓解：主动控制"探索场景"配额，把新场景样本优先上传（curiosity 采样），并对 `π` 做 Dirichlet 后验而非点估计。
2. **共识性错误放大**：多节点犯同一系统性错误（如同一批传感器同批标定错误）时中位数不鲁棒；缓解：按硬件批次/标定版本分层聚合，检测"批次内高度相关"并降权；`κ_byz` 纳入批次多样性。
3. **时延估计失准 / 时钟偏斜**：`ρ_tube` 依赖 δ_max 上界；若实际抖动超界则保守性失效；缓解：用 `δ_max = P99.9 时延 + δ_skew`，并在 J_ce 记录实测分位数；超界触发 `EDGE_AUTO`。
4. **云端规划与边缘动力学模型不一致**：云端用简化模型规划，边缘真实动力学更复杂；`Accept` 的 `S_k⊆S_edge` 与 DSC 兜底可防不安全，但会频繁拒绝；缓解：云端使用与边缘同一套 `φ` 参数化与约束语法，证书携带模型哈希。
5. **DSC 频繁不可行导致任务停滞**：`O_∞` 过保守或约束冲突；缓解：分层约束软化（力限硬、跟踪软）、`SAFE_HOLD` 中有界恢复策略、把不可行事件回灌云端重规划。
6. **隐私噪声降低可辨识性**：`ε_dp` 过大使 `Θ` 方差膨胀；缓解：安全聚合（不注入噪声，仅聚合）+ 仅对小样本场景加噪；`ε_dp` 与 `N_eff` 联合预算。
7. **实时预算超支**：DARG/DSC/CCP 串行约 3ms；缓解：分核并行、`n_worst` 降为 4、DSC 查表化、`realtime_mode` 显式记录并降级 WCV-C。
8. **对抗性云端**：定理 7 保证安全非干扰，但恶意云端可长期诱导低效计划（性能攻击）；缓解：`J_trk` 监控、`Accept` 率下降触发对云端节点的信誉降权与 `EDGE_AUTO` 常驻。
