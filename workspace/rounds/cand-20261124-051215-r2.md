# 研究循环 · 本轮灵感：「三维感知」×「阻抗控制」 → MetricVoiceGauge-NCD-HUTDH-v23

> **基线**：承接 v22（MetricVoiceGauge-NCD-HUTDH-v22：PGEV 三层能量可行性 Fil_strategic⊇Fil_tactical⊇Fil_operational + HDL/DCL 义务合规 + ACSC 机械臂配空间能量积分 + DCSC conformal 深度感知 + HPC-E 统一准入门 + CFC++ 层级模态共识；其上承 v21 的 SDC/CAC/DCL/GIC 语义-规范层、v20 的联邦感知证书 PCA/CTS/CFC/HPC、v19 的 DCM/OGCC/CCV/DRS/OGC、v17 的 CLP/S2C/HCG/PSV/APS/AMC）。
> 本轮纪律：**三维感知是带误差界与"未知"语义的连续距离场；阻抗控制是带力/位/能三界的交互契约**。不推倒 v22：PGEV/EVC/HDL/ACSC/DCSC/HPC-E/CFC++ 全部原样保留。本轮只做一件事：在 v22 的"离散包围体 + 二值安全"之上加一层"**几何-柔顺**"层，把"离障碍多远"升级为"认证距离场"，把"碰不碰"升级为"能多硬地碰、能把多少能量交给环境"，并顺手封堵 v22 的层级切换振荡与配空间过度保守导致的活性坍缩。

## 0. 直觉与动机

**灵感 1（三维感知 → 从"无名包围盒"到"带误差界的连续距离场 + 未知语义"）**
直觉：v22 的 PCA/Hull 与 v21 的 CertBox 本质上仍是**离散的、二值的、无梯度**的几何证据——它只能回答"这个体素被占/没被占"，不能回答"此刻离最近表面还有多少厘米、法向朝哪、这个距离有多可信"。三维感知（TSDF/ESDF、占据栅格、概率体素）恰好提供三样 v22 缺的东西。第一，**连续可微的净空** `d(x)`：距离场天然 1-Lipschitz（|d(x)−d(y)| ≤ ‖x−y‖），这使得"点估计误差"能升级为"整个邻域的均匀误差界"，正好是碰撞证书与阻抗增益调度共同需要的输入。第二，**接触几何**：ESDF 梯度给出表面法向 `n(x)` 与局部曲率 `κ(x)`，于是"从哪个方向来、用哪个方向柔顺"第一次有了物理含义——贴着墙滑行与迎面顶住是两种完全不同的风险。第三，也是最关键的，**未知（unknown）是一等公民**：TSDF 只在截断带内有效，远处自由空间其实是"未知"而非"自由"；占据栅格的未知体素既不能当障碍也不能当自由。v21 的 AbsCert 是**全局离散**的缺席证书，VCDF 是**局部连续**的距离证书，两者互补而非替代。反直觉点：**距离场越"平滑"越危险**——平滑插值会把孔洞、细杆、玻璃抹平，产生"看起来还有 20cm 净空、其实一根细线横在中间"的假自由；所以 VCDF 必须携带未知掩码与截断半径，且在未知处一律返回 0，宁可保守也不能让平滑掩盖稀疏。

**灵感 2（阻抗控制 → 安全的语义从"不碰"变成"有界地碰"，但柔顺本身会注入能量）**
直觉：v22 的证书回答"会不会碰"，可对物理人机交互（pHRI）而言，**接触不总是失败**：交接、扶持、贴墙作业都需要接触。阻抗控制 `τ = Jᵀ(K e + D ė) + τ_ff` 把机器人渲染成一个弹簧-阻尼器，于是"安全"的正确语义从"零接触"变成"**接触力有界、压入深度有界、交给环境的能量有界**"。但这里有两个反直觉陷阱。第一，**柔顺不等于安全**：刚度太低，压入深度 `δ = F/K` 会很大，靠近脆弱人体/易碎物时"软"反而造成大位移挤压；刚度太高，接触瞬间力会尖峰；而**时变刚度会泵入能量**——`½K̇e²` 这一项在增益随时间上升时是正功率，一个"自适应变刚"的阻抗控制器可以凭空调动能量，使无源性失效。第二，**力界不是控制器一条指令就能保证的**：`F = K_eff·p` 中真正的等效刚度是机器人与环境串联的 `K_eff = (1/K_p + 1/K_e)^{-1}`；当环境比模型软（`K_e→0`）时压入失控，当环境比模型硬且带尖角时力会集中，当人主动发力时外力叠加。因此 CIC 必须同时给出**力、位、能三条界**，并显式声明它成立所依赖的环境/人体模型假设。核心创新：**柔顺阻抗证书 (Compliance Impedance Certificate, CIC) + 无源能量槽 (Passivity Energy Tank, PET)**。关键洞察：**能量槽把"变刚度的野心"关进一个只能花已耗散能量的账户里**——想变刚，先证明你攒够了耗散能；这使时变阻抗重新变成无源系统，且与 v22 的 EVC 能量账户天然同构。

**两者如何统一：距离场决定"在哪柔顺"，能量槽决定"敢柔多硬"，交互预算决定"能花多少"**
三维感知给出认证距离场 `d̂(x)`（保守下界）与未知掩码 `U_t`；阻抗控制把净空映射成增益调度 `K(d̂), D(d̂)` 并受 CIC 三界约束；PET 把增益调度的非被动功率记账；v22 的 EVC 再划出一块**交互预算** `E_contact_budget ≤ E_res − E_fallback − E_reach_safe − E_arm − E_margin`，明确"交互不能挪用回退能量"。统一为 **v22 之上的"几何-柔顺"层**：
- **VCDF**（体素认证距离场）回答"局部净空多少、法向朝哪、有多可信、哪里是未知"；
- **CIC**（柔顺阻抗证书）回答"给定接触模型界，这组 `(K,D)` 调度是否保证 `F≤F_safe ∧ δ≤δ_safe ∧ E_inj≤E_safe`"；
- **PET**（无源能量槽）回答"变刚度所需的非被动功率是否已从耗散/认证盈余中预支，槽是否非负"；
- **UPS**（未知空间主动剥离调度器）回答"哪些未知可被主动观测变成认证自由，且剥离动作本身安全、不占回退走廊"。
统一准入门升级为 **HPC-EI = (HPC-E, VCDF, CIC, PET)**：几何∧规范∧负信息∧能量可持续∧差距内未证伪（v22 原样保留）∧ **距离场可靠 ∧ 交互三界成立 ∧ 能量槽非负**。共享状态 `ζ_pgev` 扩为 `ζ_geom = ζ_pgev ∪ (d̂_t, n̂_t, κ̂_t, U_t, K_t, D_t, Q_tank, E_contact_budget, peel_map)`。安全继承：VCDF 只把离散证书加密成更保守的连续下界、CIC 只收缩允许的 `(K,D)`、PET 只允许花已挣得的能量、UPS 只在认证视线内改写未知为自由，故 `Exec_v23 ⊆ Exec_v22` 由构造保持。

## 1. 研究问题（轮次升级版）

- **Q12（距离场的均匀可靠性界）**：如何由逐体素 conformal 误差 `ε_D(score)` 与 1-Lipschitz 性质导出对连续区域 `B` 的**均匀**下界 `P(∀x∈B, d_true(x) ≥ d̂(x)) ≥ 1−δ_D`？截断半径 `d_trunc` 外与未知体素如何处理（返回 0 是否足够保守）？ESDF 梯度法向 `n̂` 的角度误差 `ε_n` 与曲率误差如何界定，才能让"贴面柔顺"不沿错误方向滑动？细杆/孔洞/玻璃等稀疏结构造成的"平滑假自由"如何用多视角一致性显式排除？

- **Q13（阻抗三界的联合收紧）**：在环境刚度 `K_e∈[0,K_e^max]`、人体主动力 `‖F_h‖≤F_h^max`、法向误差 `ε_n`、控制延迟 `τ_d` 下，如何给出 `F≤F_safe`、压入 `δ≤δ_safe`、注入能量 `E_inj≤E_safe` 的联合充分条件？"太硬→力尖峰、太软→大压入"的双侧约束如何写成 `(K,D)` 的可行域，并与 `d̂` 的增益调度 `K(d̂)` 相容（近处自动变软、但不得进入"软到失控"区）？力饱和/导纳限制与无源性能否同时满足？

- **Q14（能量槽与交互预算的无双重记账）**：PET 的槽能量 `Q_tank` 与 v22 的 `E_res`、ACSC 的 `E_arm` 如何避免重复计算？"变刚度泵能" `½K̇e²`、人体外力做功、接触耗散如何在账户里逐项登记？交互预算 `E_contact_budget` 的划拨如何在低电/高温时自动收缩而不触发 v22 的分层振荡？槽空时"冻结刚度"与"高阻尼被动"两种退化如何选择且不产生极限环？

- **Q15（未知剥离的安全与活性）**：未知体素默认当障碍会使活性坍缩，主动剥离又如何保证"剥离动作本身安全"？认证视线（LOS）需要几路独立观测、多大深度一致性阈值、多低的假自由率？剥离必须不占用回退走廊 `Ecorr`，这条"不挖自己的退路"约束如何形式化并在线 O(1) 检查？剥离带来的 `d̂` 上升只允许发生在有认证的区域，如何与 v21 的 `Cov_t/κ_c` 及 v20 的 APS 新鲜度阶梯对齐？

## 2. 设计原则（在 v22 的 P37–P42 基础上新增 P43–P46）

**P43 认证距离场律（Certified Distance Field）**
对任意查询点 `x`，VCDF 返回保守下界 `d̂_t(x) ≤ d_true(x)`，且 `P(∀x∈B_t, d_true(x) ≥ d̂_t(x)) ≥ 1−δ_D`。实现上 `d̂_t(x) = max(0, d_raw(x) − ε_D(x) − ε_tsdf)`，`x∈U_t`（未知）或 `x` 在截断半径外但无独立自由证据时一律 `d̂_t(x)=0`；梯度法向满足 `∠(n̂,n) ≤ ε_n`。**失效向零**：任何标定漂移、体素融合失败、深度缺失都使 `d̂` **只减不增**，并在失配区退化为 0。自由空间的"升值"（`d̂` 上升）只能由 UPS 的认证剥离提供，绝不是平滑插值的副产品。

**P44 阻抗力-位-能三界律（Impedance Force-Displacement-Energy Bounds）**
允许的阻抗调度必须落在可行域 `𝒦 = {(K,D) : ∀K_e∈[0,K_e^max], ∀F_h≤F_h^max, ∀∠err≤ε_n, F_c ≤ F_safe ∧ δ_c ≤ δ_safe ∧ E_inj ≤ E_safe}` 内，其中 `F_c ≤ K_eff·p_max + F_h^max`、`δ_c = F_c/K_e + δ_dyn`、`E_inj ≤ ½K_eff p_max² + F_h^max δ_safe + E_dyn`。增益调度 `K_t = K(d̂_t, κ̂_t)` 必须**对 `d̂` 单调不减**（越近越软，等价地 `d̂` 减小则 `K` 不增），且存在下界 `K_min` 防止"软到失控"；对尖角/高曲率 `κ̂` 与未知邻域，取 `K_t→0`（退出柔顺，改走 v22 硬约束）。力指令逐周期饱和 `‖F_cmd‖≤F_safe`。任何一项界不可证（缺少 `K_e` 上界标定或 `F_h` 模型）⇒ 该接触任务判为不可执行，退回非接触模式。

**P45 无源能量槽律（Passivity Energy Tank）**
设槽能量 `Q_tank(t) ≥ 0`，其动力学 `Q̇_tank = P_diss + P_seed − P_act − P_leak`，其中耗散 `P_diss = D ė² ≥ 0`、认证盈余注入 `P_seed ≤ P_avail_max − P_loco`（且不侵蚀 v22 的回退储备）、非被动需求 `P_act = ½ K̇ e² + (非保守项)`。`Q_tank` 永不为负：若某调度会使 `Q̇_tank<0`，则冻结 `K̇=0` 或增大 `D`（转被动），绝不"透支未来能量"。`Q_tank` 带 TTL 与来源锚（耗散记账哈希、`E_contact_budget` 划拨凭证）；传感器/执行器/标定任一失效使 `Q_tank←0`，阻抗冻结为固定高阻尼被动模式。

**P46 未知空间主动剥离律（Unknown-Space Peeling）**
未知 `U_t` 默认当障碍（`d̂=0`）。UPS 仅在同时满足：① 从已认证自由位姿出发的视线 `LOS` 与目标体素不相交于占据/未知；② ≥`n_indep` 路独立视角深度一致（互差 ≤`ε_depth`）且 conformal 假自由率 ≤`α_free`；③ 剥离动作全程 `d̂(x(t)) ≥ d_brake(v)+r_robot` 且不进入回退走廊 `Ecorr`；④ 剥离后的自由区域仍需 v21 `Cov_t` 的召回下界 `κ_c` 背书——时才把未知改写为"认证自由"。剥离只允许**提升** `d̂` 于被认证体素，且一旦后续观测冲突立即回退为障碍并触发重签。

## 3. 与基线的接口（如何退化）

- VCDF 失效（体素融合/标定/深度流异常）⇒ 关闭连续增益调度，退回 v22 的 Hull/CertBox 二值证书 ⇒ 等价 v22（更保守）；若连 Hull 也不可信 ⇒ `d̂≡0`、全域视为接触 ⇒ 受控 SafeStop；
- CIC 不可证（缺 `K_e^max`/`F_h^max` 标定）⇒ 不执行接触任务，只做保持 `d_safe` 的非接触运动 ⇒ 子集；
- PET 失效/槽空 ⇒ 冻结 `K` 为固定被动高阻尼，禁止任何变刚度 ⇒ 只收缩 `(K,D)` 可行域；
- 交互预算不足（低电/高温/重载）⇒ `E_contact_budget=0`，退回纯导航/非接触操作 ⇒ 子集；不改变 v22 的回退储备；
- UPS 失效（视线不可证/多视角不足）⇒ 未知永久当障碍 ⇒ 比 v22 更保守但安全；
- 剥离冲突（新观测否定旧自由）⇒ `d̂` 立即回落、相关证书重签 ⇒ 只收紧；
- 全部失效 ⇒ 完全回退 v22 ⇒ `Exec_v23 ⊆ Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`。
- **安全继承**：VCDF 只提供保守下界、CIC 只交 `𝒦`、PET 只花已挣能量、UPS 只在认证视线内升值 `d̂`；任意失效都向更保守方向退化。VCDF/CIC 以 10Hz 事件注入、控制路径只做 O(1) 的距离查表与增益查表，与 v22 的层级降级、v21 的 APS 新鲜度阶梯同构。

## 4. 预期贡献

1. **认证距离场**：首次把三维感知的 TSDF/ESDF 变成带均匀误差界、法向误差与未知掩码的碰撞证据，给出"点误差 + 1-Lipschitz ⇒ 区域均匀下界"的构造，并把"平滑假自由"显式排除；
2. **阻抗三界证书**：把"柔顺"形式化为力/压入/注入能量三条同时成立的界，揭示"太硬力尖峰、太软大压入"的双侧可行域 `𝒦`，并给出与环境刚度上界、人体主动力、法向误差、时延的显式依赖；
3. **无源能量槽与交互预算**：用能量槽封堵时变阻抗的"凭空调能"，并把交互能量从 v22 的回退储备中独立划拨，做到全程无双重记账、低电自动收缩；
4. **未知空间主动剥离**：把"未知当障碍"的保守性与"主动感知提升活性"统一到一个带 LOS/多视角/假自由率/回退走廊约束的调度器，可审计地把未知升级为认证自由；
5. **几何-柔顺统一门**：`HPC-EI = (HPC-E, VCDF, CIC, PET)`，`Exec_v23 ⊆ Exec_v22 ⊆ …` 闭环；
6. **顺手封堵 v22 风险**：用连续柔顺替代"分层边界处二值切换"，在净空临界带用增益斜坡取代硬切换，抑制层级振荡；用 UPS 在安全前提下赎回被"未知当障碍"吞掉的活性。

## 5. 本轮最大风险

**一句话**：阻抗证书的力/位/能三界只在"环境是被动、刚度有上界、人体主动力有上界"的模型假设下成立；真人会主动施力，衣物、手指、线缆会形成**运动学勾挂**（约束而非力），此时"柔顺"会变成"用受控的力稳稳顶住、甚至困住一个人"，而 VCDF 的平滑假自由又会把机器人主动送进这次接触——即"**可审计的柔顺幻觉**"。

# IP-436 认证距离场：点误差 + 1-Lipschitz => 区域均匀下界
class CertifiedDistanceField:
    def __init__(self, esdf, calibrator, r_robot, d_trunc, eps_n, delta_D=1e-3):
        self.esdf = esdf              # TSDF/ESDF 融合后端
        self.calib = calibrator       # 逐 score-bin 的 conformal 误差分位
        self.r = r_robot
        self.d_trunc = d_trunc
        self.eps_n = eps_n
        self.delta_D = delta_D

    def query(self, x, U_t):
        # 未知或截断外：宁可保守，返回 0（等价"贴着障碍"）
        if x in U_t or self.esdf.outside_truncation(x):
            return DistanceReading(d=0.0, n=None, kappa=None, unknown=True)
        raw = self.esdf.value(x)
        eps = self.calib.quantile(self.esdf.score(x))   # P(err<=eps) >= 1-delta
        d = max(0.0, raw - eps - self.esdf.tsdf_residual)
        n = normalize(self.esdf.gradient(x)) if d > 0 else None
        return DistanceReading(d=d, n=n, kappa=self.esdf.curvature(x),
                               unknown=False)

    def certify_region(self, B, cover_pts):
        # 1-Lipschitz：若在 delta-cover 上点误差各 <= eps，则全 B 均匀 <= eps
        # P(forall x in B: d_true(x) >= d_hat(x)) >= 1 - |cover|*delta
        return all(self._point_certified(p) for p in cover_pts)

    def collision_free(self, x, v, U_t):
        # P43：d_hat >= r + 制动距离 => 认证无碰撞
        return self.query(x, U_t).d >= self.r + self.d_brake(v)

    def d_brake(self, v):
        # 最坏制动距离 + 感知-执行时延位移
        return v * self.tau_d + v * v / (2.0 * self.a_min)


# IP-437 柔顺阻抗证书：力 / 压入 / 注入能量三界
class ComplianceImpedanceCertificate:
    def __init__(self, Ke_max, Ke_min, Fh_max, F_safe, d_safe, E_safe,
                 p_max, K_min, K_max, D_min, D_max,
                 gain=1.0, m_eff=1.0, tau_d=0.01, kappa_sharp=5.0):
        self.Ke_max, self.Ke_min = Ke_max, Ke_min
        self.Fh_max, self.F_safe = Fh_max, F_safe
        self.d_safe, self.E_safe = d_safe, E_safe
        self.p_max = p_max
        self.K_min, self.K_max = K_min, K_max
        self.D_min, self.D_max = D_min, D_max
        self.gain, self.m_eff = gain, m_eff
        self.tau_d, self.kappa_sharp = tau_d, kappa_sharp

    def effective_stiffness(self, Kp, Ke):
        if Kp <= 0.0:
            return 0.0
        return Kp * Ke / (Kp + Ke)   # 机器人-环境串联

    def force_bound(self, Kp, Ke):
        # 机器人生成力 + 人体主动推力的保守上界
        return self.effective_stiffness(Kp, Ke) * self.p_max + self.Fh_max

    def penetration_bound(self, Kp, Ke):
        # Ke 有下界时压入有界；软环境改由位移守卫兜底
        if Ke < self.Ke_min:
            return float("inf")
        return (self.effective_stiffness(Kp, Ke) * self.p_max
                + self.Fh_max) / Ke

    def energy_bound(self, Kp, Ke, Dp, tau_d):
        # 弹性储能 + 人体做功 + 一阶暂态耗散上界
        return (0.5 * self.effective_stiffness(Kp, Ke) * self.p_max ** 2
                + self.Fh_max * self.d_safe
                + 0.5 * Dp * (self.p_max / max(tau_d, 1e-6)) ** 2)

    def feasible(self, Kp, Dp):
        for Ke in (self.Ke_min, self.Ke_max):     # 串联界在端点取极值
            if self.force_bound(Kp, Ke) > self.F_safe:
                return False
            if self.penetration_bound(Kp, Ke) > self.d_safe:
                return False
        if self.energy_bound(Kp, self.Ke_min, Dp, self.tau_d) > self.E_safe:
            return False
        return self.K_min <= Kp <= self.K_max and self.D_min <= Dp <= self.D_max

    def schedule(self, d_hat, kappa, U_t):
        # P44：K(d_hat) 对 d_hat 单调不减（越近越软）；尖角/未知 => 退出柔顺
        if U_t.near(d_hat) or (kappa is not None and kappa > self.kappa_sharp):
            return Impedance(K=0.0, D=self.D_max)      # 退化为 v22 硬约束
        K = clamp(self.K_min + self.gain * d_hat, self.K_min, self.K_max)
        K = min(K, self.max_feasible_K())              # 投影到 𝒦
        D = clamp(2.0 * math.sqrt(max(K, 1e-9) * self.m_eff),
                  self.D_min, self.D_max)
        return Impedance(K=K, D=D)

    def saturate(self, F_cmd):
        # 力指令逐周期饱和，防止接触瞬态尖峰
        return clamp_norm(F_cmd, self.F_safe)


# IP-438 无源能量槽：变刚度泵能必须从已耗散能量中预支
class PassivityEnergyTank:
    def __init__(self, Q0, P_leak, budget):
        self.Q = Q0
        self.P_leak = P_leak
        self.budget = budget        # E_contact_budget，独立于回退储备

    def step(self, dt, e, edot, K, D, Kdot):
        P_diss = D * edot ** 2
        P_act = max(0.0, 0.5 * Kdot * e ** 2)   # 变刚度泵入的正功率
        P_seed = min(self.budget.seed_power(), self.P_avail_max - self.P_loco)
        P_seed = max(0.0, P_seed)
        Q_next = self.Q + dt * (P_diss + P_seed - P_act - self.P_leak)
        if Q_next < 0.0:
            # P45：不透支。冻结变刚度或增大阻尼，且只花已有能量
            return TankVerdict(Q=0.0, freeze_K=True, force_passive=True)
        self.Q = Q_next
        self.budget.charge(dt * (P_act + self.P_leak))
        return TankVerdict(Q=self.Q, freeze_K=False, force_passive=False)

    def on_fault(self, fault):
        # 任何感知/执行/标定故障：槽清零、证书重签
        if fault in ("SENSOR", "ACTUATOR", "CALIB", "CLOCK"):
            self.Q = 0.0
            self.valid = False


# IP-439 未知空间主动剥离：不挖自己的退路
class UnknownSpacePeelingScheduler:
    def __init__(self, vcdf, cac, n_indep, eps_depth, alpha_free, marg=0.02):
        self.vcdf, self.cac = vcdf, cac
        self.n_indep, self.eps_depth = n_indep, eps_depth
        self.alpha_free, self.marg = alpha_free, marg

    def try_peel(self, voxel, pose, views, Ecorr, v):
        # ① LOS：从已认证自由位姿到体素不穿占据/未知
        if not self.vcdf.los_clear(pose, voxel):
            return PeelDecision(False, "LOS_BLOCKED")
        # ② 多视角一致 + conformal 假自由率
        D = [self.vcdf.depth_of(voxel, view) for view in views]
        if len(D) < self.n_indep or max(D) - min(D) > self.eps_depth:
            return PeelDecision(False, "MULTIVIEW_INCONSISTENT")
        if self.vcdf.false_free_rate(views) > self.alpha_free:
            return PeelDecision(False, "FALSE_FREE_RATE")
        # ③ 剥离动作全程净空足够，且不进入回退走廊
        if voxel in Ecorr or self._path_enters(Ecorr, pose, voxel):
            return PeelDecision(False, "RETREAT_CORRIDOR")
        if self.vcdf.query(voxel, set()).d < self.vcdf.r + self.vcdf.d_brake(v):
            return PeelDecision(False, "INSUFFICIENT_CLEARANCE")
        # ④ 仍需 v21 CAC 的召回下界背书
        if not self.cac.certifies_free(voxel):
            return PeelDecision(False, "CAC_NOT_CERTIFIED")
        self.vcdf.promote_unknown_to_free(voxel, views)   # 只升值该体素
        return PeelDecision(True, "PEELED")

    def rollback_on_conflict(self, voxel, obs):
        # P46：后续观测冲突立即回退为障碍并重签
        if obs.occupied(voxel):
            self.vcdf.demote_free_to_occupied(voxel)
            return True
        return False

## 2. 推导（引理 176–182）

**引理 176（距离场均匀下界）** 设距离场 1-Lipschitz：`|d_true(x)−d_true(y)| ≤ ‖x−y‖`。取区域 `B` 的 `ε`-覆盖 `{p_i}`（`B ⊆ ⋃ Ball(p_i,ε)`），且每点以概率 `≥1−δ` 有 `d̂(p_i) ≤ d_true(p_i)`、`|d_raw(p_i)−d_true(p_i)| ≤ ε`。则对所有 `x∈B`，取最近覆盖点 `p`：`d_true(x) ≥ d_true(p)−ε ≥ d̂(p)−ε ≥ d_raw(p)−ε_D−2ε`。故以 `d̂(x) := max(0, d_raw(x)−ε_D−2ε)` 在 `B` 上一致成立的概率 `≥1−|cover|·δ`。取 `δ_D=|cover|·δ` 即得 P43 的均匀界。∎

**引理 177（保守膨胀 ⇒ 无碰撞）** 若 `d̂_t(x) ≥ r_robot + d_brake(v)`，则由引理 176，`d_true(x) ≥ d̂_t(x)`，机器人球与障碍的最近距离至少 `d_brake(v)`；在时延 `τ_d` 与最大减速度 `a_min` 内可完全制动，故认证无碰撞。`d̂` 在未知/截断外为 0，使该不等式自动失败，退化为接触保守。∎

**引理 178（阻抗三界）** 机器人-环境法向串联刚度 `K_eff=K_pK_e/(K_p+K_e) ≤ min(K_p,K_e)`。命令虚拟压入 `p≤p_max`，人体主动推力至多 `F_h^max` 朝机器人，故接触力 `F_c ≤ K_eff p_max + F_h^max`。环境压入 `δ_c = F_c/K_e`，当 `K_e≥K_e^min` 时 `δ_c ≤ (K_eff p_max+F_h^max)/K_e^min`；`K_e<K_e^min` 时由位移守卫在 `δ>δ_safe` 前退出柔顺。注入能量由弹性储能 `½K_eff p_max²`、人体做功 `F_h^max δ_safe` 与一阶暂态上界 `½D(e/τ_d)²` 相加界定。故 `(K,D)∈𝒦` 时三界同时成立。∎

**引理 179（能量槽 ⇒ 无源）** 取 Lyapunov `V = ½K e² + ½mė² + Q_tank`。无接触时 `V̇ = −Dė² + Q̇_tank`，而 `Q̇_tank = P_diss+P_seed−P_act−P_leak`，代入得 `V̇ = −P_leak + P_seed − P_act`。对非被动项 `P_act=½K̇e²`，其恰好抵消 `½K̇e²` 的势能注入；`Q_tank≥0` 时系统对外端口不产生净能量。若某调度会令 `Q_tank<0`，控制器冻结 `K̇` 或增大 `D`，故 `Q_tank≥0` 是不变式，闭环对外无源。∎

**引理 180（交互预算与回退储备不重叠）** 定义 `E_contact_budget = E_res−E_fallback−E_reach_safe−E_arm−E_margin` 且仅当该值 `>0` 时为正。PET 的 `P_seed` 只能从 `E_contact_budget` 支取，`E_contact_budget` 的每次支取同时从 `E_res` 扣除，故任何时刻 `E_res ≥ E_fallback+E_reach_safe+E_arm+E_margin` 的回退不变量不被交互侵蚀；`E_res` 中不存在被两个账户同时计入的能量。低电/高温使 `E_contact_budget≤0` 时 `P_seed=0`，交互任务被门禁拒绝。∎

**引理 181（剥离的可靠性）** UPS 仅在 LOS 无占据/未知遮挡、`≥n_indep` 路深度互差 `≤ε_depth`、conformal 假自由率 `≤α_free`、不进入 `Ecorr` 且剥离路径净空足够、并被 v21 `CAC` 召回下界背书时，才把体素升级为认证自由。由 conformal 覆盖，单次升级的假自由概率 `≤α_free`；`Ecorr` 约束保证回退路径始终为已知自由，故剥离不削减安全回退能力。若后续观测冲突，`rollback_on_conflict` 立即降级为障碍并重签，`d̂` 只降不升，故剥离不破坏单调性。∎

**引理 182（v23 整体安全继承）** 同一几何快照、同一 v22 状态、同一能量账户下：VCDF 只给出保守下界 `d̂≤d_true` 且失效向 0（176/177）；CIC 只收缩允许的 `(K,D)` 到 `𝒦`（178）；PET 只允许花已耗散/已划拨能量且 `Q_tank≥0`（179/180）；UPS 只在认证条件下升值 `d̂` 且可回退（181）；HPC-EI 是 v22 HPC-E 与上述四者的合取。故 `Exec_v23 ⊆ Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`。∎

## 6. 已知风险与失效模式

1. **接触模型失准（最大风险）**：`K_e^max/K_e^min/F_h^max` 是经验界，真实人体可主动发力、衣物/手指/线缆形成运动学勾挂，使力/位/能三界在"模型内成立、模型外失效"。缓解：模型假设显式入证书、外加大力饱和与位移守卫、把未建模接触视为不可执行（E876–E883/E896–E899）。
2. **平滑假自由**：TSDF/ESDF 插值抹平细杆、孔洞、玻璃，使 `d̂` 虚高。缓解：未知/截断外归零、稀疏结构多视角一致性、UPS 剥离需 CAC 背书（E875/E890–E893）。
3. **距离场误差的均匀界过乐观**：`δ`-cover 的联合界在高维体素上可能过大，导致到处保守或局部越界。缓解：分层覆盖 + 保守 `ε_D` + E871/E872 覆盖判据。
4. **能量槽被"洗白"**：错误地把外部人体做功或传感器噪声当耗散充槽。缓解：只认 `Dė²` 与认证盈余，记账哈希审计（E885–E889）。
5. **交互预算与回退储备双重记账**：`E_arm`、`E_contact`、`E_res` 交叉扣减出错。缓解：引理 180 的分账不变式 + E887/E889。
6. **剥离诱发新风险**：为提升活性把机器人主动送向原未知区，若假自由则更危险。缓解：`Ecorr` 保护、假自由率上界、冲突即回退（E892/E893）。
7. **延迟与抖动**：10Hz 的 `d̂/𝒦/Q` 注入若陈旧，50Hz 控制环可能用过期增益。缓解：TTL + 新鲜度阶梯，过期即冻结为最保守被动（E904）。

## 7. 本轮最大风险

**一句话**：VCDF 的可靠性押在"距离场误差可均匀标定、且平滑不会抹掉稀疏结构"上，CIC 的可靠性押在"环境被动、刚度有界、人体主动力有界"上；这两条经验前提任一被真实世界击穿（玻璃/线缆/主动发力的人），系统就会在"已认证"的距离里，用"已认证"的柔顺力，稳稳地接触一个证书从未建模的对象——把"可审计的几何-柔顺安全"变成"可审计的柔顺幻觉"。
