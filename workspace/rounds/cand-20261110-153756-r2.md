# 第 44 轮（新一轮灵感循环首轮） · Scale-Cert × Claim-Cert：把「数据规模」写进证书的有效域，把「论文创新点」降格为可反驳的持证主张（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈的最大风险是「共形条件覆盖 + 多用户契约空集」，但这两个看似不同的故障有一个共同的、此前从未被写出的根因：**所有证书都默认自己是在「足够多、足够好」的数据上估计出来的**。由此留下两个未言明假设：**(H5) 证书与数据规模无关**——margin、条件覆盖、域差都被当作点估计直接写进有效域，样本量 N 从不出现，置信度 δ 从不出现；**(H6) 论文创新点与证据规模无关**——每轮新增一批 IP 就被叙事为「贡献」，但没有一个贡献被写成「在多大 N 上、相对哪个基线、被什么实验可以反驳」。本轮灵感词「数据规模」与「论文创新点」恰好从根上击中这两个假设：数据规模迫使我们把 N、δ、有效场景数 N_eff 提升为证书的一等字段；论文创新点迫使我们把「贡献」从叙事降格为 claim-cert，并接受「数据预算决定哪些创新点配被称为创新点」。一句话：**规模不是实验设置，而是证书有效域的一部分；创新点不是故事，而是一张会被预算与统计功效否决的证书。**

## 0. 直觉与动机

**灵感 1（数据规模 → 证书的「射程」由 N 决定，不由声明决定）**：直觉上，`m_lo = 0.83 ≥ θ` 是一条硬结论；但只要补一句「这是从 200 个样本估出来的」，它立刻变成一条有统计阴影的软结论：换一批样本，`m_lo` 可能掉到 θ 以下。v20 的所有证书都缺这一句。因此第一步是把证书从「点断言」升级为「带样本的断言」`c=(φ, D, m_N^-, N, δ, N_eff, prov)`：只有在 `m_N^- ≥ θ_safe` 且 `N_eff ≥ N_min(δ)` 时，证书才非真空。第二步是承认**规模有两种**：原始样本数 N 会被重复近邻样本稀释；真正决定证书射程的是**有效场景规模 N_eff**（覆盖了多少种与证书相关的行为模式，再扣除重复与污染）。这解释了为什么「再采一百万帧同一条走廊」不会让证书更强：它只增加 N，不增加 N_eff。

**灵感 2（论文创新点 → 创新点通胀的对偶是 claim-cert）**：到 v20 为止，项目已积累 59 个 IP、94 个实验编号。作为论文，这既是资产也是负债：审稿人只问一句——「如果只允许你保留一条可被反驳的主张，是哪一条？」过去的答案是叙事（「我们提出了四层可验证闭环」），无法反驳，因而也无法证明。本轮把每个创新点强制写成 `K=(claim, operationalization, falsification, baseline, N_min, Δ_min, β, artifact)`：claim 必须是可证伪的陈述；baseline 必须点名最近的 prior art；Δ_min 是最小可检测效应（MDE）；N_min 是达到 `1−β` 功效所需的最小数据规模。**规模不足的 claim 必须被自动降级为 hypothesis，并记入「规模债务」账本**——不是删掉，而是诚实地不进核心贡献。

**灵感 3（耦合 → 数据预算约束下的创新点组合，以及它和 v20 的接口）**：单条 claim 有 N_min，所有 claim 共享总预算 B_total，于是「本轮能声称哪些创新点」变成一个带红线的背包问题：`max Σ v_k x_k s.t. Σ b_k x_k ≤ B_total`，且安全红线 claim 必须入选。更关键的是这个耦合直接解掉了 v20 的两个遗留风险：**(a) 共形条件覆盖被边际覆盖欺骗**，本质是「每个人格（Mondrian 单元）的校准样本 n_u 太小」——所以给出**人格可扩张的规模门槛** `n_u ≥ N_min(α,δ)`，低于门槛时 `τ_u→0`、禁止扩张；**(b) 多用户契约空集**，本质是「可行域随场景规模暴露不足而被高估」——用 N_eff 给出可行性包络的置信下界，样本不足时只报保守包络。并发也受规模约束：并行投机带来的 margin 增益若小于估计的二倍半宽，就只是噪声，不能算「新鲜度杠杆」。

**耦合升级**：SCE（规模证书引擎）把 N、δ、N_eff 编译进每一条证书与阈值表；CCL（主张证书账本）把创新点变成可做功效分析、可被预算否决的 claim；SBV（规模基准验证器）在多尺度上重跑主张、审计污染与泄漏。四层架构由 v8 的「仿真-检索-边缘飞轮 + 人格 + 并发」升级为 v9 的「规模证书层 + 主张证书层」：**先量数据射程，再谈创新主张。**

## 1. 形式化定义（增量：定义 44–49）

**定义 44（带规模的证书，N-aware certificate）**：证书 `c = (φ, D(c), m_N^-(δ), N, δ, N_eff, prov)`：φ 为被证断言，D(c) 为有效域，`m_N^-(δ)` 为在 N 个样本上、置信水平 1−δ 下的 margin 单侧下界，N_eff 为有效场景规模，prov 为数据溯源。**非真空（non-vacuous）**：`m_N^- ≥ θ_safe` 且 `N_eff ≥ N_min(θ_safe, δ)`。**命题（规模单调性）**：在同一数据分布下 N_1 ≤ N_2 ⟹ `m_{N_1}^- ≤ m_{N_2}^-`（下界随样本单调不降）；故任何在 N_1 下 sound 的证书在 N_2 下仍 sound。这保证了「补数据不会破坏已有证书」，也让证书射程可比较。

**定义 45（证书-数据标度律，certificate scaling law）**：设无穷样本极限 margin 为 `m_∞`，经验 margin 的统计阴影满足
`m_N^- = m_∞ − C·N_eff^{−γ}`（拟合时对 (C, γ) 取置信上包络，γ>0）。
**有效规模** `N_eff = N_cov · (1 − ρ_contam)`，其中 `N_cov` 用覆盖估计（Good–Turing / Chao）从「证书相关行为模式」的发现曲线估计，`ρ_contam` 为污染/泄漏比例。**N_eff 校准定理（可检验假设）**：若标度律拟合在留出的更大 N 上外推误差 ≤ η，则该标度律可用于证书射程预测；否则只允许用最保守的 `N_min` 下界。**长尾推论**：重尾场景下 `γ < 1/2`（比 iid 均值更慢），「多采同分布数据」收益远低于「多采新行为模式」；因此数据采集应按 `∂m_N^-/∂N_eff` 而非原始 N 排序。

**定义 46（主张证书，claim-cert）**：`K = (claim, O, F, B, N_min, Δ_min, β, R)`：claim 为可证伪陈述；O 为操作化指标；F 为否证协议（预注册的检验与停止规则）；B 为最近 prior art 基线集合；Δ_min 为最小可检测效应；β 为 II 类错误上限；R 为可复现产物（种子、数据哈希、配置、代码版本）。**可采纳（admissible）**：在预算 N ≥ N_min 下，对 `Δ ≥ Δ_min` 的双侧检验功效 ≥ 1−β，且 F 能在 `Δ=0` 时以 ≤α 拒绝原假设。**新颖性** = 相对 B 的效应量经 F 检验显著；**必要性** = 消融实验把 claim 的机制单独移除后效应消失（否则 claim 归因错误）。

**定义 47（规模债务账本与创新点组合）**：总预算 `B_total`，每条 claim k 需 `b_k ≥ b(N_min^k)`、价值 `v_k`。**组合问题**：`max Σ v_k x_k` s.t. `Σ b_k x_k ≤ B_total`、`x_redline = 1`（安全红线 claim 必选）。**规模债务** `D_scale = Σ_{k: b_k > 可用预算} (b_k − 可用预算)`。**降级规则**：`x_k=0` 的 claim 从「核心贡献」自动降为「hypothesis / future work」，并保留否证协议，禁止在摘要中作为既成结论。**反 HARKing 命题**：若 F 在数据采集前预注册，且组合选择只看预算与功效、不看事后 p 值，则 claim 集对选择偏差免疫。

**定义 48（规模门控的共形人格可扩张性）**：对每个 Mondrian 人格单元 u，校准样本 `n_u`；条件覆盖的保守下界用 Beta/Clopper–Pearson 给出 `Cov_u^-`。**可扩张判据**：`n_u ≥ N_min(α, δ)` 且 `Cov_u^- ≥ 1−α`；否则 `τ_u := 0`，强制退回纯收缩 `C_u = C_global ∩ Π_u`（定义 38），**绝不使用边际覆盖冒充条件覆盖**。**命题**：该门控把 v20 的「覆盖被欺骗」转化为一个显式的样本量条件——扩张失效不再是静默的算法缺陷，而是可被 E97 直接测量的规模阈值。

**定义 49（噪声感知的新鲜度杠杆）**：设投机并行相对串行带来的 margin 增益为 `Δm`，其 `1−δ` 置信半宽为 `h_N(δ)`。**可证增益判据**：仅当 `Δm > 2h_N(δ)` 才把该增益计入证书；否则并行只算延迟收益，不算保守性收益。**推论**：v20 的「并行换新鲜度」在小样本下可能完全是噪声；证书系统必须拒绝把统计涨落当成真实保守性下降，否则并发会成为新的静默不 sound 来源。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-63 SCALE-CERT-ENGINE（规模证书引擎 SCE）
1. **带规模的证书编译**：所有 margined 结论从点值升级为 `m_N^-(δ)`；证书结构强制携带 (N, δ, N_eff, prov)，缺字段即判为「真空证书」并拒绝进入守卫。
2. **标度律拟合与射程预测**：在 N-sweep 上拟合 `m_∞, C, γ`，输出留出集外推误差；误差超阈值时降级为「只用 N_min 最保守下界」，不做外推。
3. **N_eff 估计**：行为模式发现曲线（Good–Turing/Chao）+ 尾指数 + 污染扣除；把「采了多少帧」翻译成「证书实际覆盖了多少种模式」。
4. **采集规划器**：以 `∂m_N^-/∂N_eff` 为边际收益做子模最大化，优先补「证书射程最薄且可采」的长尾单元，而非平均分布补帧。

### 2.2 IP-64 CLAIM-CERT-LEDGER（主张证书账本 CCL）
1. **claim 登记与 prior art 基线**：每条创新点绑定最近基线集合与可复现实验；禁止「无基线的贡献」。
2. **功效分析与 N_min 计算器**：输入 Δ_min、α、β、方差估计，输出所需 N_min 与当前预算缺口；缺口即规模债务。
3. **创新点组合优化**：在 B_total 与红线 claim 约束下解背包/子模组合，输出「本轮可声称贡献集」与「必须降级为 hypothesis 的集合」。
4. **论文门禁**：摘要/贡献列表只能引用 `x_k=1` 的 claim；规模债务账本随论文附录发布，作为方法学贡献的一部分。

### 2.3 IP-65 SCALE-BENCH-VALIDATOR（规模基准验证器 SBV）
1. **多尺度基准台**：对同一 claim 在 N ∈ {10³,10⁴,10⁵,10⁶,10⁷} 上重跑学习曲线，检验标度律外推与效应可复现性。
2. **污染/泄漏审计**：训练-测试近邻重叠、时间泄漏、persona 泄漏；输出 `ρ_contam` 与去污染后的 `N_eff`。
3. **跨尺度复现**：小 N 上的 claim 必须在较大 N 上不逆转（效应方向一致），否则标记为「尺度脆弱创新点」。
4. **对抗规模**：刻意构造类别极不平衡、长尾、分布漂移的规模梯度，检验证书射程预测的假阴性。

## 4. 实验设计（E95–E102 硬门槛，承接 E87–E94）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E95 标度律外推 | 留出 N 上 margin 预测误差；拟合 R²；γ 置信区间宽度 | 误差 < 10%；R² ≥ 0.95；区间窄于 ≤ 0.1 |
| E96 有效规模校准 | N_eff/N 随冗余度下降；Good–Turing 覆盖估计误差；长尾发现率 | 冗余 10x 时 N_eff 增幅 < 2x；误差 < 15%；≥ 基线 3x |
| E97 人格规模门控 | 低于 n_u 门槛时扩张违例；达标后条件覆盖；误扩张率 | 0 起；≥ 1−α(α=0.1)；0 |
| E98 claim 可采纳性 | 达功效 claim 比例；规模不足仍进贡献列表数；复现成功率 | ≥ 80%；0；≥ 90% |
| E99 污染审计 | 检出泄漏率；去污染后 margin 降幅；N_eff 校正误差 | ≥ 95%；如实报告；< 15% |
| E100 采集规划收益 | 每样本证书增益 vs 随机采样；射程提升 | ≥ 3x；≥ 10% |
| E101 规模感知并发 | 噪声下误计增益次数；大 N 下证书延迟；跨规模阈值误用 | 0；< 150μs；0 |
| E102 跨尺度复现 | 小 N claim 在大 N 逆转率；尺度脆弱 claim 检出率 | < 5%；≥ 95% |

回退：E95 外推失败 → 禁用标度律外推，只用 N_min 最保守下界；E96 N_eff 不可校准 → 退回原始 N 并整体放大阈值；E97 未达标 → 全部人格禁止扩张，仅保留纯收缩；E98 功效不足 → 只保留红线 claim，其余全部降为 hypothesis；E99 污染不可控 → 冻结数据集并重采；E100 无收益 → 退回均匀采样；E101 噪声误计 → 关闭投机并行；E102 尺度逆转 → 该 claim 从核心贡献中移除。

## 5. 本轮最大风险

**一句话**：规模标度律本身是用有限 N 拟合出来的，「用拟合出的 γ 去外推更大 N」存在把统计涨落误判为创新效应的风险；一旦 N_eff 估计偏乐观、污染扣除不足，claim 组合会在预算不足时仍放行，产生「有证但真空」的论文创新点。因此 E95/E96（标度律外推 + N_eff 校准）与 E98（claim 功效）必须设为红线，默认回退到「只用 N_min 最保守下界 + 最小可证主张集」。

## 2. 关键算法（伪代码）

### IP-63 SCE：带规模证书、标度律与有效规模
```
def certify_with_scale(phi, data, delta, theta_safe):
    N = len(data)
    m_lo = one_sided_lower_bound(phi, data, delta)      # DKW / bootstrap
    n_cov = coverage_estimate(discover_curve(data))     # Good-Turing / Chao
    rho   = contamination_fraction(data)                # train/test 近邻 + 时间泄漏
    n_eff = n_cov * (1 - rho)
    c = Cert(phi, D=data.domain, m_N=m_lo, N=N, delta=delta,
             n_eff=n_eff, prov=data.provenance)
    if m_lo < theta_safe or n_eff < n_min(theta_safe, delta):
        return VacuousCert(c)                           # 真空证书，禁止进守卫
    return c

def fit_scaling_law(curves, holdout):
    # curves: [(N_eff, m_lo)]；对 (m_inf, C, gamma) 取置信上包络
    m_inf, C, gamma = fit_envelope(curves, model='m_inf - C*N_eff^-gamma')
    err = max(abs(predict(m_inf, C, gamma, n) - m) for n, m in holdout)
    if err > ETA_MAX:
        return ScalingLaw.unusable(m_inf, C, gamma, err)  # 只允许 N_min 最保守下界
    return ScalingLaw(m_inf, C, gamma, err)

def n_eff_estimate(N, discover_curve, rho_contam):
    n_cov = good_turing_chao(discover_curve)              # 未见模式质量估计
    tail  = max(1.0, tail_index_penalty(discover_curve))  # 重尾惩罚
    return (n_cov / tail) * (1 - rho_contam)

def acquisition_plan(pool, cert_map, budget):
    # 子模最大化：每条新样本对目标单元证书射程的边际增益
    gains = {x: marginal_margin_gain(cert_map, x) for x in pool}
    return greedy_submodular(gains, budget)               # 优先射程最薄的可采长尾
```

### IP-64 CCL：claim-cert、功效与数据预算背包
```
def register_claim(claim, metric, baseline, delta_min, alpha, beta, var_hat):
    n_min = required_n(delta_min, alpha, beta, var_hat)   # 双侧检验功效公式
    return ClaimCert(claim, metric, falsification=pre_registered_test(alpha, beta),
                     baseline=baseline, n_min=n_min, delta_min=delta_min,
                     beta=beta, artifact=repro_bundle())

def is_admissible(K, available_n):
    # 预算不足以达到 1-beta 功效则不可采纳
    return available_n >= K.n_min and power(K, available_n) >= 1 - K.beta

def select_claim_portfolio(claims, B_total, redline):
    # 0/1 背包（或子模）：红线 claim 必选
    chosen = knapsack(claims, B_total, must_include=redline)
    debt = sum(max(0, b_k - remaining_budget) for k in claims if k not in chosen)
    return chosen, ScaleDebt(debt, demoted=[k for k in claims if k not in chosen])
```

### IP-65 SBV：多尺度基准与污染审计
```
def scale_sweep(run_claim, Ns):
    curves = []
    for N in Ns:
        res = run_claim(N)
        curves.append((N, res.metric, res.margin_lo, res.ci))
    return curves

def contamination_audit(train, test):
    near = nn_overlap_rate(train, test)      # 近邻重叠
    leak = temporal_or_persona_leak(train, test)
    return rho_contam = combine(near, leak)

def cross_scale_reproduce(claim, small_res, large_res):
    if sign(small_res.effect) != sign(large_res.effect):
        return "scale-fragile"                # 效应逆转，移出核心贡献
    return "replicated" if large_res.p > 0.05 else "replicated-significant"
```

### IP-57/58 升级：人格规模门控与噪声感知并发
```
def persona_expansion_allowed(n_u, alpha, delta, cov_lower):
    return n_u >= n_min_persona(alpha, delta) and cov_lower >= 1 - alpha

def certified_expand_v2(C_u, H_u_alpha, tau_u, shadow_cert, n_u, alpha, delta):
    if not persona_expansion_allowed(n_u, alpha, delta, cov_lower(H_u_alpha)):
        return C_u, 0.0                      # 低样本人格：强制纯收缩，根治边际覆盖欺骗
    return certified_expand(C_u, H_u_alpha, tau_u, shadow_cert)   # v20 原逻辑

def accept_parallel_gain(delta_m, half_width, delta):
    # 噪声感知：增益未超二倍置信半宽则只算延迟收益，不算保守性收益
    return delta_m > 2 * half_width
```

### IP-51/47 升级：规模守卫与组合一致性
```
def car_guard_with_scale(e, x, cert_obj, persona, lease, t):
    theta = cert_obj.alpha_e[e] * cert_obj.theta_sim[e]
    m_lookup = cert_obj.m_N[e]              # 已带 N/delta 的下界
    m_lease  = lease.m - lease.lam * (t - lease.tau)
    m_cap    = persona_cap[e](persona)
    if cert_obj.n_eff[e] < n_min(theta, cert_obj.delta):
        return False                        # 真空证书不得放行
    return min(m_lookup, m_lease, m_cap) >= theta and lease_valid(lease, theta, t)

def compose_with_scale(children):
    # 组合证书的有效规模取子证书最小 N_eff，防止以大 N 稀释小 N 的真空
    return ComposedCert(valid=all(c.non_vacuous for c in children),
                        n_eff=min(c.n_eff for c in children),
                        margin=min(c.m_N for c in children))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性保证 |
|---|---|---|---|
| SCE 证书编译 | O(N) 估计 + O(N log N) 近邻污染 | O(N) 数据/索引 | `m_N^-` 为 1−δ 下界 ⟹ 非真空判据 sound |
| SCE 标度律 | 拟合 O(K)；预测 O(1) | O(K) 曲线点 | 外推误差 ≤ η 才启用；否则退回最保守 N_min |
| SCE N_eff | O(N) 发现曲线 + O(1) 覆盖估计 | O(1) 统计量 | 覆盖估计 + 污染扣除 ⟹ N_eff ≤ N_cov ≤ N |
| SCE 采集规划 | 贪心近似 1−1/e | O(|pool|) | 边际增益排序 ⟹ 近似最优证书射程增长 |
| CCL 功效/N_min | O(1) 解析 / O(迭代) | O(1) | 功效 ≥ 1−β 才可采纳 ⟹ 规模不足 claim 被拒 |
| CCL 组合 | 背包 O(m·B) 伪多项式 | O(m·B) | 红线必选 + 预算约束 ⟹ 不超预算、不遗漏安全 claim |
| SBV 多尺度 | O(#N × T_run) | O(#N) 曲线 | 跨尺度方向一致 ⟹ 尺度脆弱 claim 可检出 |
| SBV 污染审计 | O(N log N) 近邻 | O(N) | 近邻/时间/persona 泄漏合并估计 ρ_contam |
| 人格规模门控 | O(1) | O(1)/persona | `n_u≥N_min ∧ Cov^-≥1−α` ⟹ 扩张不静默失 sound |
| 噪声感知并发 | O(1) | O(1) | `Δm>2h_N(δ)` 才计增益 ⟹ 不把涨落当保守性提升 |
| 组合代数 | O(#children) | O(1) | N_eff 取 min ⟹ 真空不可被大 N 子证书稀释 |

## 4. 实验设计（E95–E102，硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E95 标度律外推 | 留出 N 上 margin 预测误差；拟合 R²；γ 置信区间宽度 | <10%；≥0.95；≤0.1 |
| E96 有效规模校准 | 冗余 10x 时 N_eff 增幅；Good–Turing 误差；长尾发现率 | <2x；<15%；≥基线 3x |
| E97 人格规模门控 | 低 n_u 扩张违例；达标条件覆盖；误扩张率 | 0 起；≥1−α(α=0.1)；0 |
| E98 claim 可采纳性 | 达功效 claim 比例；规模不足仍进贡献列表；复现成功率 | ≥80%；0；≥90% |
| E99 污染审计 | 泄漏检出率；去污染后 margin 降幅；N_eff 校正误差 | ≥95%；如实报告；<15% |
| E100 采集规划收益 | 每样本证书增益 vs 随机；射程提升 | ≥3x；≥10% |
| E101 规模感知并发 | 噪声误计增益次数；大 N 证书延迟；跨规模阈值误用 | 0；<150μs；0 |
| E102 跨尺度复现 | 小 N claim 大 N 逆转率；尺度脆弱 claim 检出率 | <5%；≥95% |

回退：E95 外推失败 → 禁用外推、只用 N_min 最保守下界；E96 不可校准 → 退回原始 N 并整体放大阈值；E97 未达标 → 全人格禁止扩张、仅纯收缩；E98 功效不足 → 只保留红线 claim，其余降 hypothesis；E99 污染不可控 → 冻结数据集重采；E100 无收益 → 退回均匀采样；E101 噪声误计 → 关闭投机并行；E102 尺度逆转 → 该 claim 移出核心贡献；任何红线失败 → 熔断回退 v20。

## 5. 论文定位（本轮「论文创新点」的直接产物）

**一句话核心主张（core claim）**：*在有限、长尾、可污染的数据上，「证书是否 sound」不仅取决于算法，还取决于数据规模；把 (N, δ, N_eff, prov) 写入证书，并用 claim-cert + 数据预算约束创新点，可以在不牺牲 soundness 的前提下，使可验证的个性化与并发在数据规模上可预测地扩展。*

| 维度 | 最近 prior art（B） | 本轮差异（Δ） | 否证实验（F） |
|---|---|---|---|
| 统计证书 | PAC / 共形预测（假设 iid、独立报告覆盖） | N 与 δ 进入运行时证书；条件覆盖转为显式人格规模门控 | E95/E97：外推误差或低样本扩张失败即否证 |
| 数据规模 | 数据-centric AI / scaling law（多用于精度，不用于 soundness） | 标度律作用于 **margin 下界/证书射程**，并扣除污染与冗余 | E96/E99：N_eff 不可校准则核心 novelty 不成立 |
| 创新点评估 | 预注册 / 盲分析 / 基准污染研究 | claim-cert + 预算背包 + 规模债务账本，把「能声称什么」形式化 | E98/E102：达功效 claim 比例或复现率不达标即否证 |
| 个性化并发 | v20 PCE/CCR（边际覆盖 + 并发增益） | 用规模门槛与噪声感知把两者的静默失效变成可测条件 | E97/E101：低样本扩张或噪声误计即否证 |

**可复现产物 R**：数据哈希、N-sweep 配置、标度律拟合脚本、claim 预注册文件、污染审计日志、红线下界计算器；随论文附录发布，供第三方按 E95–E102 复核。

## 6. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 标度律用有限 N 拟合再外推更大 N，γ 估计偏差导致射程虚高 | 高 | E95 红线留出集外推；只取置信上包络；误差超限禁用外推，退回 N_min 最保守下界 |
| N_eff 估计偏乐观（覆盖估计高估、污染扣除不足） | 高 | E96/E99 红线；Good–Turing 与尾指数双重惩罚；污染审计独立于训练流程 |
| 人格单元样本不足却仍扩张，复现 v20 的边际覆盖欺骗 | 高 | E97 红线；`n_u ≥ N_min(α,δ)` 硬门控；不足即 `τ_u=0` 纯收缩 |
| claim 组合在预算不足时仍把未达功效的点写进核心贡献 | 高 | E98 红线；功效分析前置；规模债务账本公开；论文门禁只引用 `x_k=1` |
| 并行投机增益其实是统计噪声，被误当保守性下降 | 中-高 | E101 红线；`Δm>2h_N(δ)` 才计增益；否则只算延迟收益 |
| 组合证书用大 N 子证书稀释小 N 子证书的真空 | 中 | IP-47 N_eff 取 min；组合前逐个非真空检查 |
| 采集规划退化为「刷同分布数据」，N 涨而射程不涨 | 中 | 按 `∂m_N^-/∂N_eff` 子模排序；E100 收益门槛；长尾单元优先 |
| 多尺度基准本身成本过高，拖垮迭代 | 低-中 | 用学习曲线早期点 + 留出尺度；只对红线 claim 做全尺度扫 |

## 7. 本轮最大风险

**一句话**：规模标度律本身是被有限 N 拟合出来的，「用拟合出的 γ 外推更大 N」可能把统计涨落误判为创新效应；一旦 N_eff 偏乐观、污染扣除不足，claim 组合会在预算不足时仍放行，制造「有证但真空」的论文创新点——因此 E95/E96/E98 必须设为红线，默认回退到「只用 N_min 最保守下界 + 最小可证主张集」。
