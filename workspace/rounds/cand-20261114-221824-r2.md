# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环新循环第 2 轮；本轮灵感：「共享控制」×「场景理解」）

> R69 把不确定性拆成 aleatoric / epistemic，用流匹配多模态策略生成候选动作，再用「看 / 问 / 触」主动消解歧义。定位很漂亮：不确定性可以从刹车踏板变成一句提问。但它仍有三个未检验的假设：
>
> 1. **待消解的隐变量是「动作模态」M，而不是「世界是什么」。** R69 把场景压成一个扁平条件向量 z_t，然后问「该走哪个模态」。真实共享控制里，人与机器人的分歧常常根本不在动作，而在**对场景的信念**：那边是玻璃还是空气？这个把手能拉吗？地上那滩是水吗？孩子会不会突然冲出来？把场景信念折叠进动作模态，等于把「我们看到的不是同一个世界」误诊为「我们想去的不是同一个方向」。
> 2. **交互是单向的：机器人问、世界答。** R69 只优化**机器人自己的** epistemic 不确定性。可共享控制里，人也是控制回路里的决策者；人若无法预测机器人「看到了什么、凭什么这么做」，就会二选一地失败——要么过度信任、停止监控，要么过度怀疑、不停抢控。**机器人的可读性（legibility）和人看到的信息一样，是安全变量。**
> 3. **权威是一个二值/标量选择。** R69 的「选一个模态执行」暗含「整个执行器归机器人」。共享控制里权威是按**场景实体/区域**异质分配的：机器人在自己视野内的度量几何上强，在人视野外、透明/可变形物体、社会语义上弱；人与人相反。权威应当是一个**定义在场景图上的场**，而不是一个标量。
>
> 本轮两个灵感正好各补一刀：
> - **场景理解**提供共享控制的共同底稿：一个显式、带来源归属、带不确定性的**共享场景图**。它把「分歧」从动作层下沉到实体/关系/可供性层，于是可以问出比 R69 更精确的问题：我们到底在哪个物体、哪种关系上不一致？
> - **共享控制**提供双向通道与权威场：人不是神谕，而是同一执行器上的第二个控制源；机器人的场景理解要**展示给人看**，人才能恰当地让权或接管。信息动作因此从「机器人获取」升级为「双方对齐」。
>
> 核心命题：**把 R69 的「动作模态消歧」升级为「场景信念对齐 + 场景条件的权威分配」：先对控制分歧做三元归因（目标 / 场景 / 风险），只有场景分歧才走场景对齐；权威 α 成为定义在场景实体上的场，可正（引导）可负（危险否决）；可读性是与人共享的、可计价的交互动作（value-of-legibility）；而「一致」本身不等于安全——必须同时要求校准、证据独立与物理核验，否则共享理解会坍缩成共享幻觉。** 命名 **PRISM-RAS**（Perspective-Reconciled Interactive Scene-grounded Meta-control for Risk-adaptive Shared autonomy）——同一场景，多重视角，经棱镜分解后再合成一束可执行、可解释、可追责的光。

## 0. 直觉与动机

**灵感 1（共享控制 → 分歧是症状，病根在场景模型）**
直觉：两个人一起抬桌子，一个往左一个往右。R69 会把它读成「动作模态歧义」，然后问「你想走哪边」。但真实原因可能是：甲看见右边地上有电线（场景分歧），乙以为甲想绕开椅子（目标分歧），或者两人只是保守程度不同（风险分歧）。**同一个分歧信号，三种完全不同的病，三种完全不同的药。** 对目标分歧该谈判，对场景分歧该对齐/指认/核验，对风险分歧该调权威并解释。R69 把三种病都当第一种治，于是「问一句」经常问错问题——它问的是动作，而病根在观察。

**灵感 2（场景理解 → 把「世界是什么」变成可对齐的公共对象）**
直觉：场景理解不是把图像编码得更深，而是产出一个**可以被指着说**的结构：物体、属性、关系、可供性、自由空间、危险。只有结构化的东西才能对齐——「那个杯子」可以被指向、被命名、被核验；一个 512 维隐向量不能。共享控制需要的不是更准的单人场景模型，而是**两个不完整场景模型的公共工作区**：谁相信什么、信多少、来源是谁、在哪些实体上冲突。R69 的 z_t 是这个工作区被压扁后的残影。

**灵感 3（双向 → 可读性是一种安全资源，而不是 UI 装饰）**
直觉：共享控制里，人必须能预测机器人。机器人若不展示「它认为哪里有危险、它下一步想动哪个实体、它有多确定」，人只能靠猜；猜错就抢控或放任。于是**「让机器人被理解」和「让机器人理解」是同一个信息预算下的两个动作**。R69 的 VoI 只算「我做完这个动作会更懂多少」，PRISM 还要算「我做完这个展示，人会多懂我多少、抢控会少多少」。把注意力/视觉带宽做成可计价资源，才可能在真实驾驶舱/手术台/协作装配里不被解释淹没。

**灵感 4（权威场 → λ 与 α 都是它的退化）**
直觉：R69 的 λ 缩放「机器人动作敢做多大」，隐含机器人独占执行器。共享控制真正的旋钮是「这个自由度、这个实体、这个区域，现在谁说了算」。于是 α(e) 是比 λ 更高一层的对象：λ 是「机器人独占时」的标量化退化，R69 的 resolution bonus 是「对齐后把权威还给效率」的特例。更强的一点：α 可以**为负**——当机器人确信人漏看了一个危险（湿地板、透明玻璃、突然出现的儿童），机器人应在该实体上取得**否决/护栏权**，而不是礼貌地降低自己的速度。但否决必须是**可解释、限时、可申诉**的，否则共享控制变成不透明独裁。

**灵感 5（共享 ≠ 更安全 → 共识坍缩是新的头号故障）**
直觉：R68/R69 默认人是独立备份。共享控制把人变成同回路组件，去掉了独立性：机器人越自信，人越不看；人越依赖机器人的投影，越会复述机器人的判断。两条证据流因此**正相关**，甚至同源（人看的就是机器人渲染的画面）。这时「我们达成一致」可能只意味着**我们一起错了**。医学上的「共识幻觉」、航空里的「机组资源管理失效」都是这个结构。所以 PRISM 的目标不能是「最大化一致」，而必须是「**最大化经校准、可追溯、保留异议的一致**」；任何只奖励一致的指标都会被「共享幻觉」游戏化。

**灵感 6（威胁模型 → 会展示的系统会被利用来制造同意）**
直觉：一旦机器人能投影/高亮/解释，就出现了新的攻击面：篡改 AR 高亮让人只看危险 A 而忽略危险 B；给场景头打对抗补丁让机器人对某个实体过度自信；甚至「装弱」——人故意说没看见，诱导机器人做危险动作以测试/甩锅。**可读性通道既能建立信任，也能制造同意。** 因此必须有来源签名、证据独立性与「任何单一通道不得单独确立危险或一致」的纪律。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（PRISM-RAS 总览与六不变式）** PRISM-RAS = (SSG, SDA, SAP, SRC, SAV, LGL, HVG, MSA, EIG, SPL, RAS-WM⊞)。六条不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **场景权威良定义**：每个共享实体/区域 e 在任一时刻恰有一个权威主体，或处于认证混合律下（定义 313）；危险否决通道始终可达；
(iii) **双向可读性**：任何改变权威、或对计划关键的场景信念，必须在 δ_L 内可渲染/可解释给人（定义 316）；
(iv) **证据独立**：任何单一来源（单模态、单次人类断言、单个场景头）不得单独确立「危险」或「一致」，需 k 个有效独立源或高置信认证（定义 319）；
(v) **校准一致优先于一致**：一致必须伴随可靠图/共形校准与异议保留，禁止以降低多样性换取高分（定义 318）；
(vi) **保守退化**：场景分歧不可解、可读性失败、被投毒或 OOD 时，逐指令退化为 R69/R68 边界（定义 323）。

**定义 311（共享场景图 SSG）** 场景图 G_t = (O_t, R_t, A_t)：物体/区域节点、关系（支撑、包含、可达、归属、遮挡）、可供性。每个节点/边 i 带信念 b_i（类别、位姿、占据、可变形性、危险概率）、不确定性（协方差/credal 集）与**来源归属** s_i ∈ {R, H, shared, ext}。机器人在其证据下维护 p_R(G_t|o_t)；人的场景信念 p_H(G_t|·) 只能通过控制输入、注视、指认、语言被**间接**观测。SSG 是两者的并集，并显式标注**分歧实体集** D_t = {i : d(b_i^R, b_i^H) > τ_d}。关键：场景状态与目标状态、风险偏好分离建模——R69 的动作模态 M 是三者被压扁后的粗粒度投影。

**定义 312（场景分歧归因 SDA）** 给定控制分歧 Δu_t = u_H − u_R 与交互历史，对三类潜因做后验：
ζ ∈ {goal（目标不同）, scene（场景信念不同）, risk（风险偏好不同）}。
p(ζ|Δu, G_t, 𝔥_t) ∝ p(Δu|ζ) p(ζ|G_t, 𝔥_t)。其中 p(Δu|scene) 由「若按对方场景信念重放我自己的目标，命令是否一致」给出（反事实重放）；p(Δu|goal) 由目标推断残差给出；p(Δu|risk) 由同一最优动作在不同风险参数下的分歧给出。**SDA 是 PRISM 的诊断层**：只有 argmax 为 scene 且后验超阈值时才走场景对齐；R69 的「动作模态歧义」是 `scene` 与 `goal` 不可分时的退化标签。

**定义 313（场景权威场 SAP）** 对每个实体/区域 e，权威场 A_t(e) = (α_t(e), v_t(e), gate_t(e))：α ∈ [0,1] 为人的主导份额（α=1 人主导，α=0 机器人主导），v ∈ [0,1] 为机器人在 e 上的**危险否决强度**，gate 为是否把 e 纳入本次任务控制。执行
u_t = Σ_e mask_e · [α_e u_H + (1−α_e) u_R]，再投影到场景条件安全集 SafeSet(G_t)。
单调性要求：∂α_e/∂ρ_H(e) ≥ 0（人越可靠越让权），∂v_e/∂p(hazard_e) ≥ 0。R69 是 d_S=∅ 或 α≡0 的退化；R68 的 λ 是 α≡0 时的标量风险缩放。**α 是定义在场景图上的 λ。**

**定义 314（场景可靠性场 SRC）** 对每个实体 e 估计机器人可靠性 ρ_R(e) 与人的可靠性 ρ_H(e)：ρ 由场景头校准（ECE/覆盖）+ 共形预测 + **因果校正**给出；人的 ρ_H 必须扣除「机器人展示引导」带来的观察者效应（人若只是复述机器人高亮，不算独立可靠）。可靠性按任务相关维度分解：度量几何 / 语义类别 / 可供性 / 社会规范 / 遮挡外推。SAP 按维度取 argmax 可靠性，而不是全局平均。

**定义 315（场景感知价值 SAV，双向）** 增广信息动作集 𝒢 = 𝒢_sense ∪ 𝒢_query ∪ 𝒢_show ∪ 𝒢_point ∪ 𝒢_probe。定义
- 机器人信息增益 VoI_R(g) = H(G_t|𝔥) − E[H(G_t|𝔥, y_g)]（对齐场景信念）；
- 人类可读性增益 VoL_H(g) = H(p_H(robot belief/plan)) − E[H(p_H(·)|g)]（让人更懂机器人）；
- 务实的对齐收益 G_align(g) = 期望减少的 SDA 误诊损失。
SAV(g) = VoI_R + λ_L·VoL_H + λ_A·G_align − c(g) − risk(g)。
选 g* = argmax SAV，s.t. 安全、预算、证据独立。R69 的 MINT 是 𝒢=𝒢_sense∪𝒢_query 且 λ_L=λ_A=0 的特例。

**定义 316（可读性治理 LGL）** 渲染 ρ = Render(G_t, π, U) 需满足：(a) 保真（与机器人信念差 ≤ τ_f）；(b) **诚实不确定性**（不展示虚假精度，不把未校准的置信画成确定）；(c) 因果相关（高亮真正驱动本次权威/否决的实体）；(d) 无诱导框架。可读性亏损 L_def = KL(p_H^{after} ‖ p_H^{ideal})。**最小充分解释**：在使 L_def ≤ τ_L 的渲染中选信息量/视觉杂波最小者。若 L_def 超限，则禁止该权威变更，改用认证的极简模板或回退保守。

**定义 317（场景条件安全包络与危险否决 HVG）** SafeSet(G_t) 依赖场景实体：人周围保持区、易碎/透明物体、湿滑区域、可变形物、动态体。危险集 H_t 带概率。定义**危险分歧间隙** G_haz(e) = p(hazard_e | G_R) − p(hazard_e | G_H)。当 G_haz(e) > τ_haz 且机器人场景证据独立充分时，触发否决 v_e：对 e 施加护栏/限速/接管，**同时**必须触发一次针对 e 的可读性展示并记账。否决是限时的、可申诉的、有速率限制的（定义 326 定理 20），且绝不静默。

**定义 318（共享情境意识 MSA）** 定义单方情境意识 SA_R, SA_H 与**互情境意识** MSA：(a) 条件于正确性的一致度（不是原始一致度）；(b) 双方对彼此信念的校准（我知道你不知道什么）；(c) **异议保留**：少数但正确的场景信念不被多数/权威抹除。两种失败模式显式区分：**共识坍缩**（高一致但双方同错）与**慢性冲突**（双方各对一半但无法对齐）。MSA 的目标是最大化**校准的一致**，而非一致本身。

**定义 319（证据独立性与反共谋 EIG）** 来源间有效独立性由条件互信息/误差相关估计：I(s_i; s_j | G) 越低越独立；人若只在复述机器人高亮，则 s_H 与 s_R 不独立。危险/一致的确立需 ≥k 个有效独立源（机器人多模态、人的指认/语言、外部地图、物理探针），或单源高置信 + 认证。任何「共享展示」都不得充当下游证据的独立源（防止自我确认回路）。

**定义 320（场景投毒与视角欺骗 ℰ_PRISM）** ℰ_PRISM = ℰ_FLUID × ℰ_scene，其中 ℰ_scene = {AR/渲染欺骗、针对场景头的对抗补丁、伪造共识注入、权威耕作（装弱诱使机器人接管危险动作）、视角欺骗（人故意误报所见）、幽灵场景/重放、把展示当证据的自我确认}。并入 AIC：ℰ_PRISM = ℰ_CALM × ℰ_poison × ℰ_flow × ℰ_scene。

**定义 321（场景溯源账本 SPL）** 追加式防篡改日志：每拍记录机器人信念摘要、实际展示内容与时间、给人看的解释、人给的动作/指认、权威场 A_t(e)、否决及理由、证据独立性估计、证书哈希。用哈希链/签名支持事后责任归因与反榜单游戏；**「展示过什么」本身必须可审计**，否则无法区分「人没看见」与「机器人没让人看见」。

**定义 322（证书 J_PRISM）** J_PRISM = (J_FLUID, scene_ece, sda_confidence, authority_field_hash, veto_count_with_explanation, legibility_deficit_p95, hazard_gap_p95, msa_calibration, provenance_hash, prism_ver)。Valid ⇔ Valid(J_FLUID) ∧ 证据独立纪律 ∧ 所有否决均有解释 ∧ L_def ≤ τ_L ∧ 无未消解双离线。

**定义 323（退避阶梯）** (0) 无分歧 → 常规；(1) 场景分歧可解 → 交换/指认/核验后重算 SAP；(2) 不可解 → 按各实体可靠性把权威偏向更可靠一方，并对残余用 R69 的 λ_floor；(3) 危险分歧且可读性失败 → 机器人否决 + 认证护栏/停；(4) 攻击/OOD/双离线 → 退回 R68 纯保守。阶梯单调：越往下安全侧越强、效率侧越弱，且状态转移有迟滞与最短驻留时间。

**定义 324（决策相关分辨率 ARS）** 常规以粗粒度场景图运行；仅对「改变权威/否决决策的敏感实体」做细化，敏感度用决策互信息 I(e; A_t) 度量。这与 R69 自适应 K 同构：**把算力花在会改变决策的分辨率上**，并给出 P99 实时预算。

**定义 325（盲区接管与主动让权 PBH）** 由人视野/注视/工作负荷估计人的场景覆盖 𝒞_H；对任务相关但落在 𝒞_H 外的实体，机器人可**预先**取得权威或给出预警。主动接管必须提前宣布（可读性），否则会造成惊扰与抢控；宣布后若人在 δ_R 内无异议，视为默示同意并记账。**盲区接管是共享控制里最值钱也最危险的动作**：它既可能是救命的一把，也可能是对人自主性的剥夺。

**定义 326（PRISM 闭环）** 每拍：感知 → SSG + 可靠性场 → 对 Δu 做 SDA → 按可靠性算 SAP → 用 SAV 选「感知/问/展示/指认/探针」→ 最小充分可读渲染 → 场景条件安全融合 + 危险否决 → MSA/证据独立监控 → SPL 记账/证书 → 必要时按 ARS 细化场景。

```python
# IP-264 SSG：共享场景图（来源归属 + 分歧实体集）
class SharedSceneGraph:
    def update(self, o_t, u_H, gaze_H, point_H):
        G_R = self.scene_head(o_t)                    # 复用 R69 trunk 的场景头
        G_H = self.human_scene_estimate(u_H, gaze_H, point_H)
        G   = merge_with_provenance(G_R, G_H)         # 每个节点/边记录来源 s_i
        D   = {i for i in G.nodes if dist(G[i].b_R, G[i].b_H) > TAU_D}
        return G, D

# IP-265 SDA：目标/场景/风险三元归因（反事实重放）
def attribute_disagreement(u_H, u_R, G):
    p_scene = counterfactual_replay(u_H, my_goal=self.goal, scene=G_H)
    p_goal  = goal_inference_residual(u_H, u_R, G)
    p_risk  = risk_param_divergence(u_H, u_R, G)
    return normalize({ 'scene': p_scene, 'goal': p_goal, 'risk': p_risk })

# IP-266 SAP：逐实体权威场（可靠性 + 危险否决）
def scene_authority(G, rho_R, rho_H, D):
    for e in G.nodes:
        if e in D: alpha[e] = 0.5; continue          # 未对齐 → 认证混合/保守
        alpha[e] = trust_transfer(rho_H[e], rho_R[e]) # 可靠性高者主导
        veto[e]  = hazard_gap(G, e) * ident_valid(e)  # 危险分歧 → 否决
    return AuthorityField(alpha, veto)

# IP-267 SAV：双向价值（机器人 VoI + 人类可读性 VoL + 对齐收益）
def choose_scene_action(G, D, attribution, budget):
    best = None
    for g in candidates(G, D, attribution):           # sense/query/show/point/probe
        if not budget.allow(g) or not certified(g): continue
        s = (voi_robot(G, g) + LAMBDA_L * vol_human(G, g)
             + LAMBDA_A * align_gain(attribution, g)
             - cost(g) - risk(g))
        if best is None or s > best.score: best = (g, s)
    return best if best and best.score > 0 else None

# IP-269 LGL：最小充分可读解释（诚实不确定性）
def render_minimal(G, plan, U, authority):
    driver = causal_driver_entity(plan, authority)   # 真正驱动决策的实体
    rho = render(G, plan, U, highlight={driver})
    if legibility_deficit(rho) > TAU_L:
        rho = certified_minimal_template(G, driver, U)
    return rho                                       # 保真 + 诚实 + 无诱导

# IP-270 HVG：危险否决（可解释、限时、可申诉、不静默）
def hazard_veto(G, e, G_haz, indep_ok):
    if G_haz[e] > TAU_HAZ and indep_ok(e):
        v = veto_law(e, ttl=DELTA_V, max_rate=RATE_V)
        announce(reason=e, belief=G[e], uncertainty=U[e])   # 必须同时解释
        return v
    return None

# IP-271 MSA：校准一致 + 异议保留
def mutual_scene_awareness(G, p_H_about_R):
    agree    = conditional_agreement(G)              # 条件于正确性
    calib    = calibration(p_H_about_R)              # 人是否知道机器人知道什么
    dissent  = preserve_minority(G)                  # 少数正确信念不被抹掉
    if agree > TAU_AGREE and not calib:
        return 'consensus_collapse_suspect'          # 一致但不可信 → 危险
    return (agree, calib, dissent)

# IP-275 主闭环（继承 R69，在控制融合与交互目标处插入 PRISM 层）
def PRISM_RAS_round(M, obs, u_H):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(o)    # R68/R69
    G, D  = M.ssg.update(o, u_H, obs.gaze_H, obs.point_H)         # 共享场景图
    zeta  = M.sda.attribute(u_H, M.last_u_R, G)                   # 三元归因
    rho_R, rho_H = M.src.reliability(G, o, u_H)                   # 场景可靠性
    A     = M.sap.allocate(G, rho_R, rho_H, D)                    # 权威场
    g     = M.sav.choose(G, D, zeta, M.budget) if max(zeta.values()) > TAU_Z else None
    if g is not None:
        rho = M.lgl.render_minimal(G, M.plan, M.U, A)             # 先让人懂
        M.interact(g, rho); G, D = M.ssg.refine(G, g)             # 对齐/核验
        A = M.sap.allocate(G, *M.src.reliability(G, o, u_H), D)
    u = M.sap.fuse(u_H, M.fmp.decode(M.select_mode(zeta, G)), A, G)
    v = M.hvg.check(G, o)                                         # 危险否决
    if v is not None:
        u = M.hvg.apply(u, v); M.lgl.announce(v)
    if M.msa.suspect(G) or not M.eig.ok(G):
        u = M.saf.takeover(o.x)                                   # 保守退化
    M.spl.commit(hash_chain(G, A, u_H, u, v, rho_if_any)); M.vqa_p.submit_async(
        G, zeta, A, v, M.msa.metrics())
    return u, A, (G, D), zeta
```

## 3. 推导

**引理 19（场景分歧的可归因性与 R69 的偏差）** 设 Δu 由 (goal, scene, risk) 生成，且存在 overlap（同一目标在不同场景信念下可被观测）与排他性（场景重放不改变真实目标）。则 SDA 的三类后验可辨识；反之，若用 R69 的单一动作模态 M 解释，则在 scene 主导的分歧上，其归因误差下界 ≥ D_KL(p_scene ‖ p_M)·(1−ε_σ)。系：**问错问题的代价不是多问一次，而是在错误假设空间里更新，越问越偏。**

**引理 20（可读性的协调收益）** 设人预测机器人意图的误差为 e_H，抢控/放任概率随 e_H 单调增；最小充分解释把 e_H 降到 e_H'。则在解释保真度 ≥ 1−τ_f 时，协调风险下降 ≥ c·(e_H − e_H')，接管时延下降 ∝ 1/(1+VoL_H)。系：**可读性不是软指标，而是与 VoI 同量纲的安全预算**；但解释过载（视觉杂波）会使 e_H 回升，故存在最优解释量——这正是「最小充分」的来源。

**引理 21（危险否决的双边性）** 带解释、限时、可申诉的否决在机器人场景证据独立充分时，严格降低该实体上的期望伤害；但无解释的否决会把人的信任校准推向「不透明独裁」，使后续合理否决被忽略（狼来了），从而在其他实体上**增加**风险。故否决的正确性条件包含「可解释 + 证据独立 + 可申诉」，缺一不可。

**定理 18（PRISM 严格包含 R69）** 当 d_S=∅（无共享自由度）、D_t=∅（无场景分歧）、λ_L=0、无危险分歧时，PRISM 的 SDA 退化为 R69 的模态判定、SAP 退化为 α≡0、SAV 退化为 VoI，闭环逐指令等于 R69；此时 R68 又是「永不交互」边界。⇒ 安全侧不做让步，效率侧获场景对齐与可读性的额外收益。

**定理 19（共识不等于安全 / 共享幻觉不可能三角）** 存在场景使 p_R 与 p_H 高度一致却同时错误（同源传感器、同偏先验、或人复述机器人展示）。若授权目标只是最大化一致度，则存在对抗/分布偏移使期望伤害严格上升。安全的一致必须同时满足：(a) 有效证据独立，(b) 双方对彼此信念校准，(c) 至少一条非同源物理核验。三者构成「不可能三角」：在有限预算下最多同时强满足两个，PRISM 用退避阶梯显式选择牺牲哪个。

**定理 20（权威场连续与无突变）** 若 (i) 混合律在 α 上连续且满足无扰切换；(ii) veto 的生效/撤销有速率限制与最短驻留；(iii) 退避阶梯带迟滞；则任意阶梯切换下控制指令连续（Lipschitz 有界），且不产生执行器饱和/内力对抗。⇒ 共享不会因权威抖动而引入新的失稳。

## 6. 本轮最大风险

**一句话**：PRISM-RAS 的全部收益押在「共享场景图是校准的、且人机证据是独立的」这一前提上——一旦两端共用同源感知、同偏先验，或人只是复述机器人展示的内容，PRISM 精心对齐出的「共识」就会变成**共享幻觉**：权威被自信地分配到错误的场景上，可读性通道反过来成为制造同意的工具——**共识，可能比分歧更危险。**

## 2. 形式化定义（要点版）

**定义 310（总览与六不变式）** 零学习写操作继承；场景权威良定义（单主体或认证混合，否决可达）；双向可读性（权威变更 δ_L 内可解释）；证据独立（单源不得确立危险/一致，需 k 独立源）；校准一致优先于一致（防共识坍缩）；不可解/投毒/OOD 时逐指令退化 R69/R68。

**定义 311（SSG）** 场景图节点/边带信念、不确定性、来源归属；显式维护分歧实体集 D_t；场景状态与目标、风险偏好分离——R69 的动作模态 M 是三者压扁后的投影。

**定义 312（SDA）** `p(ζ|Δu) ∝ p(Δu|ζ)p(ζ|G,𝔥)`，ζ∈{goal,scene,risk}；用「按对方场景信念重放我方目标」估计 p(Δu|scene)。只有 scene 主导才走对齐；R69 的模态歧义是 scene∩goal 不可分的退化标签。

**定义 313（SAP）** 逐实体 `u = Σ_e mask_e[α_e u_H+(1−α_e)u_R] → SafeSet(G)`；单调性 `∂α/∂ρ_H≥0`，`∂v/∂p(hazard)≥0`。`R69 是 α≡0 的退化；R68 的 λ 是其标量情形`。α 是定义在场景图上的 λ。

**定义 314（SRC）** 逐实体/逐维度（度量几何/语义/可供性/社会规范/遮挡外推）可靠性；用 ECE + 共形 + 因果校正；人的可靠性须扣除「复述机器人展示」的观察者效应。

**定义 315（SAV）** `𝒢=𝒢_sense∪𝒢_query∪𝒢_show∪𝒢_point∪𝒢_probe`；`SAV=VoI_R+λ_L VoL_H+λ_A G_align−c−risk`；R69 MINT 是 λ_L=λ_A=0 且无 show/point 的特例。

**定义 316（LGL）** 渲染满足保真/诚实不确定性/因果相关/无诱导；最小充分解释 = 在 L_def≤τ_L 下视觉杂波最小者；L_def 越界禁止授权变更。

**定义 317（HVG）** SafeSet 随场景实体变化；危险分歧间隙 `G_haz(e)=p(h|G_R)−p(h|G_H)`；超阈值且证据独立充分 → 限时、可申诉、有速率限制、必须伴随解释的否决。

**定义 318（MSA）** 条件一致度 + 双方互校准 + 异议保留；区分**共识坍缩**（高一致双错）与**慢性冲突**；目标是校准一致而非一致。

**定义 319（EIG）** 用条件互信息/误差相关估有效独立性；共享展示不得作为下游独立证据，防「展示→复述→确认」自我回路。

**定义 320（ℰ_PRISM）** AR/渲染欺骗、场景头对抗补丁、伪造共识、权威耕作（装弱）、视角欺骗、幽灵场景、把展示当证据。

**定义 321（SPL）** 追加式防篡改日志：信念摘要、展示内容与时间、解释、人的动作/指认、权威场、否决理由、独立性、证书哈希。

**定义 322（J_PRISM）** 并入 scene_ece、sda_confidence、authority_field_hash、veto_with_explanation、L_def_p95、hazard_gap、msa_calibration、provenance_hash；Valid 要求所有否决有解释、无未消解双离线。

**定义 323（退避阶梯）** 无分歧→常规；可解场景分歧→对齐后重算；不可解→按可靠性偏置 + R69 λ_floor；危险分歧且可读性失败→否决+护栏/停；攻击/OOD/双离线→R68 纯保守。带迟滞与最短驻留。

**定义 324（ARS）** 粗粒度常驻，按决策互信息 `I(e;A_t)` 只细化会改变权威/否决决策的实体；与 R69 自适应 K 同构。

**定义 325（PBH）** 用视野/注视/负荷估计人的场景覆盖；对任务相关盲区可预先接管或预警；接管须提前宣布，δ_R 内无异议视为默示同意并记账。

**定义 326（闭环）** 感知→SSG/可靠性→SDA→SAP→SAV（感知/问/展示/指认/探针）→最小充分渲染→场景条件安全融合+否决→MSA/EIG→SPL/证书→按 ARS 细化。

## 3. 关键算法伪代码

```python
# IP-264 SSG：共享场景图（来源归属 + 分歧实体集）
class SharedSceneGraph:
    def update(self, o_t, u_H, gaze_H, point_H):
        G_R = self.scene_head(o_t)                      # 复用 R69 trunk
        G_H = self.human_scene_estimate(u_H, gaze_H, point_H)
        G   = merge_with_provenance(G_R, G_H)           # 每节点/边标来源 s_i
        D   = {i for i in G.nodes if dist(G[i].b_R, G[i].b_H) > TAU_D}
        return G, D

# IP-265 SDA：三元归因（反事实重放）
def attribute_disagreement(u_H, u_R, G):
    return normalize({
        'scene': counterfactual_replay(u_H, self.goal, G_H),
        'goal' : goal_inference_residual(u_H, u_R, G),
        'risk' : risk_param_divergence(u_H, u_R, G)})

# IP-266 SAP：逐实体权威场
def scene_authority(G, rho_R, rho_H, D):
    for e in G.nodes:
        alpha[e] = 0.5 if e in D else trust_transfer(rho_H[e], rho_R[e])
        veto[e]  = hazard_gap(G, e) * ident_valid(e)     # 危险分歧 → 否决
    return AuthorityField(alpha, veto)

# IP-268 SAV：双向价值（机器人 VoI + 人类 VoL + 对齐收益）
def choose_scene_action(G, D, zeta, budget):
    best = None
    for g in candidates(G, D, zeta):                     # sense/query/show/point/probe
        if not budget.allow(g) or not certified(g): continue
        s = (voi_robot(G, g) + LAMBDA_L * vol_human(G, g)
             + LAMBDA_A * align_gain(zeta, g) - cost(g) - risk(g))
        if best is None or s > best.score: best = (g, s)
    return best if best and best.score > 0 else None

# IP-269 LGL：最小充分解释（诚实不确定性）
def render_minimal(G, plan, U, A):
    driver = causal_driver_entity(plan, A)
    rho = render(G, plan, U, highlight={driver})
    if legibility_deficit(rho) > TAU_L:
        rho = certified_minimal_template(G, driver, U)
    return rho

# IP-270 HVG：危险否决（可解释、限时、可申诉、不静默）
def hazard_veto(G, e, G_haz, indep_ok):
    if G_haz[e] > TAU_HAZ and indep_ok(e):
        v = veto_law(e, ttl=DELTA_V, max_rate=RATE_V)
        announce(reason=e, belief=G[e], uncertainty=U[e])   # 必须同时解释
        return v
    return None

# IP-271 MSA：校准一致 + 异议保留
def mutual_scene_awareness(G, p_H_about_R):
    agree   = conditional_agreement(G)
    calib   = calibration(p_H_about_R)
    dissent = preserve_minority(G)
    if agree > TAU_AGREE and not calib:
        return 'consensus_collapse_suspect'
    return (agree, calib, dissent)

# IP-275 主闭环（继承 R69，在控制融合与交互目标处插入 PRISM 层）
def PRISM_RAS_round(M, obs, u_H):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(o)      # R68/R69
    G, D  = M.ssg.update(o, u_H, obs.gaze_H, obs.point_H)          # 共享场景图
    zeta  = M.sda.attribute(u_H, M.last_u_R, G)                    # 三元归因
    rho_R, rho_H = M.src.reliability(G, o, u_H)                    # 可靠性场
    A     = M.sap.allocate(G, rho_R, rho_H, D)                     # 权威场
    g     = M.sav.choose(G, D, zeta, M.budget) if max(zeta.values()) > TAU_Z else None
    if g is not None:
        rho = M.lgl.render_minimal(G, M.plan, M.U, A)              # 先让人懂
        M.interact(g, rho); G, D = M.ssg.refine(G, g)              # 对齐/核验
        A = M.sap.allocate(G, *M.src.reliability(G, o, u_H), D)
    u = M.sap.fuse(u_H, M.fmp.decode(M.select_mode(zeta, G)), A, G)
    v = M.hvg.check(G, o)                                          # 危险否决
    if v is not None:
        u = M.hvg.apply(u, v); M.lgl.announce(v)
    if M.msa.suspect(G) or not M.eig.ok(G):
        u = M.saf.takeover(o.x)                                    # 保守退化
    M.spl.commit(hash_chain(G, A, u_H, u, v)); M.vqa_p.submit_async(
        G, zeta, A, v, M.msa.metrics())
    return u, A, (G, D), zeta
```

## 4. 推导

**引理 19（场景分歧的可归因性）** 在 overlap 与排他性下，SDA 的三类后验可辨识；R69 的单模态解释在 scene 主导分歧上误差下界 ≥ `D_KL(p_scene‖p_M)(1−ε_σ)`。系：问错问题的代价是在错误假设空间里更新，越问越偏。

**引理 20（可读性的协调收益）** 最小充分解释把人的预测误差 `e_H→e_H'`，在同保真度下协调风险下降 ≥ `c(e_H−e_H')`，接管时延下降 ∝ `1/(1+VoL_H)`；解释过载会使 e_H 回升，故存在最优解释量——「最小充分」的来源。

**引理 21（危险否决的双边性）** 带解释/限时/可申诉且证据独立的否决严格降低该实体期望伤害；无解释否决会把信任校准推向「不透明独裁」，使后续合理否决被忽略，在其他实体上增加风险。

**定理 18（PRISM 严格包含 R69）** `d_S=∅ ∧ D=∅ ∧ λ_L=0 ∧ 无危险分歧` 时，SDA→R69 模态判定、SAP→α≡0、SAV→VoI，闭环逐指令等于 R69；R68 为「永不交互」边界。安全不让步，效率获场景对齐 + 可读性收益。

**定理 19（共识不等于安全 / 共享幻觉不可能三角）** 存在高一致却同时错误的场景（同源传感、同偏先验、人复述展示）。仅最大化一致度的授权存在分布偏移使其期望伤害上升。安全一致需同时满足：证据独立、互校准、非同源物理核验；有限预算下最多强满足两个，PRISM 用退避阶梯显式取舍。

**定理 20（权威场连续与无突变）** 混合律连续 + 无扰切换 + veto 速率限制/最短驻留 + 阶梯迟滞 ⇒ 阶梯切换下控制指令 Lipschitz 连续，无执行器饱和/内力对抗。

## 7. 本轮最大风险

**一句话**：PRISM-RAS 的全部收益押在「共享场景图是校准的、且人机证据是独立的」这一前提上——一旦两端共用同源感知、同偏先验，或人只是复述机器人展示的内容，PRISM 精心对齐出的「共识」就会变成**共享幻觉**：权威被自信地分配到错误的场景上，可读性通道反过来成为制造同意的工具——**共识，可能比分歧更危险。**

**次级风险与缓解**：场景图算力/延迟（定义 324 决策相关分辨率 + 复用 R69 trunk + 粗粒度常驻）；可读性过载（最小充分解释 + 视觉杂波预算）；危险否决被滥用成不透明独裁（限时/可申诉/速率限制/必须解释 + E305）；人机证据同源导致自我确认（定义 319 独立性 + 非同源物理核验）；透明/可变形/遮挡下场景不可靠（可靠性场逐维度 + 退避阶梯 + E311）；权威耕作/视角欺骗（SPL 溯源 + ℰ_scene 对抗训练 + E307–E308）。
