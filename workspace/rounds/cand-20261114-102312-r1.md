# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「云端协同」×「自适应控制」）

> R69 问出「我该向谁求证」，并给出了一个漂亮的答案：把不确定性拆成 aleatoric/epistemic，后者交给流匹配多模态策略 + 主动交互消解。但 R69 有一个没说出口的前提——**它所有的阈值、模态先验、VoI 成本、λ_floor 斜率，都是离线手调的常数**；而它自陈的最大风险恰恰是「流模型的模态分布不可信」。这两件事其实是同一个病：**单台边缘设备既没有足够多样本看清罕见模态，也没有足够算力在线重估这些参数。**
>
> 「云端协同」补第一块：把群体的模态统计、失败案例、校准证据汇聚起来，让罕见模态不再罕见。但云是慢的、陈旧的、异构的、可能被投毒的；「云端说的」不是真理，只是一条**带年龄、带出处、带相关性的证据**。
>
> 「自适应控制」补第二块，并给出理论骨架：R69 的手调常数应该在线自适应；而 R69 的 VoI 交互，本来就是自适应控制里最经典的**对偶控制（dual control）**——控制的同时必须探询。于是本轮把「问」与「学」放进同一个两时间尺度框架：**边端快环控制（FLUID-RAS，参数冻结为不可变快照），云端慢环辨识与自适应（只在新鲜、可迁移、过信赖域、过安全集、过影子评估时才提交）。**
>
> 核心命题：**把 R69 的固定超参数升级为「云端慢环自适应参数」，用年龄感知门控、信赖域投影、可迁移性检验、负迁移回滚、自适应安全罩五道闸，保证自适应只可能改进、不可能破坏已认证的安全。** 命名 **NIMBUS-RAS**（Networked Interactive Model-Based Uncertainty-aware Safe adaptive control）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我从群体学来的经验，还适用于此刻的我吗，学错了能不能退回去**」。

## 0. 直觉与动机

**灵感 1（云端协同 → 单机的「近视」是结构性的）**
直觉：R69 的模态校准门 MCG 要求 ECE < 0.05，但一台边缘机器人一天可能只遇到几次「罕见的岔口决策」，要校准 4 个模态的权重，样本量根本不够；越罕见的歧义越需要校准，却越校准不起——这是结构性矛盾，不是工程细节。云端协同的本质不是「把算力搬走」，而是**把分布搬进来**：同型号机器人在不同场景积累的模态计数、模态间可分性、失败案例，是任何单机都无法独立获得的先验。但请注意：能搬来的是**统计量**，不是「真理」；群体统计对「我」是否适用，取决于协变量偏移与机制偏移。「云端协同」在这里被定义为 **cloud-edge 的充分统计量协同**，而不是把原始数据或控制回路搬到云上。

**灵感 2（自适应控制 → R69 的手调常数应该会自己变）**
直觉：R69 里 TAU_MODE、TAU_EPI、TAU_FMA、λ_floor 斜率、交互预算 c_max……全是常数。可世界在漂移：传感器老化、场景迁移、任务分布变化，都会让最优阈值移动。自适应控制的本能回答是「在线估计、在线调参」。但自适应控制也最清楚代价：**调参通道本身就是不稳定源**。没有投影、没有安全罩、没有参考模型的自适应，会把系统调进振荡、饱和或局部错误吸引域。所以本轮不是「无脑自适应」，而是「**带五道闸的自适应**」。

**灵感 3（双时间尺度 → 快边慢云，实时性与全局学习的解耦）**
直觉：R69 的实时环路预算只有 2.6ms，绝不可能在里面跑云端往返。正确架构是**两时间尺度**：边端内环以毫秒级跑 FLUID-RAS，参数冻结为一个快照；云端外环以秒到分钟级跑辨识与自适应，异步提交新参数快照。这既保住了实时性，又让「学习」发生在不阻塞控制的地方。代价是：**提交到边端的参数是「过时的」**（age of information, AoI）。陈旧参数可能比不更新更危险，所以必须做年龄感知门控与漂移补偿。

**灵感 4（对偶控制 → R69 的「问」与自适应控制的「探」是同一件事）**
直觉：自适应控制有一个古老的两难——**dual control**：为了控制得好要估计参数，为了估计参数要施加激励（探测），但探测本身有控制代价。R69 的 VoI 交互（看/问/触）正是这个「探测」。区别是 R69 把探询当作本地、单步、信息论问题；自适应控制把它看成**持续激励（persistency of excitation, PE）**问题：如果云端已经提供了某个参数方向上的丰富信息，边端就不必再探；如果云端数据在该方向上没有激励，云端的信息量为零，边端仍须自己探。这给出一个可证伪的「探询套利」命题：**云端只能在它真正见过、且与本地相关的方向上替你省掉探询。**

**灵感 5（负迁移 → 从别人那里学错，比不学更危险）**
直觉：R69 的最大风险是「问错比不问更危险」；R70 把它升级成「**学错比不学更危险**」。云端聚合的群体经验可能在 fleet 平均上正确、在单个 edge 上错误（非 IID、场景异质、标注口径不同），也可能被投毒、被重放、被陈旧数据污染。更阴险的是：自适应是慢的、低频的，一旦被带进一个「局部稳定但全局错误」的参数区，很难归因、很难察觉，甚至会通过同一套证书流程被「盖章认证」。所以本轮必须交付负迁移检测、影子评估、版本回滚，以及「云端证据永远不能单独定案」的证据纪律。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（NIMBUS-RAS 总览）** NIMBUS-RAS = (FLUID-RAS†, CAL, AAR, TRP, CEP, DPB, NTE, SHE)。四不变式：
(i) **实时零学习写操作**（继承 R69 定义 293-i）：内环不写任何学习参数；
(ii) **参数快照不可变**：每次参数提交生成不可变版本 θ_a^{(v)}，内环只读快照；
(iii) **自适应单向安全**：任何自适应提交必须在「本地影子评估 + 信赖域 + 安全参数集」三重约束下不劣于当前版本，否则拒绝并回滚；
(iv) **云端证据非权威**：云端建议只是一条带出处/年龄/相关性的证据，永远不能单独满足 R69 的 k-正交证据纪律。

**定义 311（自适应参数向量与安全参数集）** θ_a = (π_mode_temp, TAU_MODE, TAU_EPI, TAU_FMA, c_VoI, λ_floor 参数, ECE 阈值, 交互预算参数)。安全参数集 Θ_safe ⊂ ℝ^{d_θ} 是凸紧集，由认证实验预先确定，且包含 R69 的标称参数 θ_0；任何提交必须满足 θ_a ∈ Θ_safe。

**定义 312（双时间尺度动力学）** 内环：t → t+Δ_t（Δ_t ≈ 2.6ms），用冻结 θ_a^{(v)} 执行 FLUID-RAS。外环：每 T_c（秒~分钟）在云端计算候选 θ_a^{cand}，经网络延迟 d_k 后在边端提交为版本 v+1。要求 A99：T_c ≫ Δ_t，且漂移时间常数 τ_drift ≫ T_c + d_k（时间尺度分离）。

**定义 313（年龄、陈旧度与通道模型）** 对第 k 次提交，AoI Δ_k = t_now − t_sent。通道模型：延迟有界 d_k ≤ d_max，丢包/重放/乱序可检测，TTL = τ_TTL(ḋ) 依赖慢漂移率 ḋ。Δ_k > TTL 的提交直接弃用。

**定义 314（年龄感知自适应律 AAR）** 候选提交 θ_a^{cand} 在 Δ_k 内按漂移率做**安全侧一阶补偿**：θ_a^{comp} = θ_a^{cand} ⊕ (−ḋ·Δ_k)（只沿使安全裕度增大的方向补偿），再进入后续闸门。若 Δ_k > TTL，不补偿、直接弃用。

**定义 315（信赖域投影 TRP）** 定义参数差异诱导的行为差异 D_TR(θ, θ') = sup_{o∈𝒪_rep} KL(p_θ(M|o) ‖ p_{θ'}(M|o)) + |λ_θ(o) − λ_{θ'}(o)|。提交需满足 D_TR(θ_old, θ_cand) ≤ δ_TR，否则沿 θ_old→θ_cand 径向回缩到边界。

**定义 316（云端证据溯源 CEP）** 每条云端证据 e_c 携带 provenance = (来源智能体集, 采集时间, 采集工况, 数据哈希, 是否独立)。可迁移性检验 T(e_c, o_t)：用协变量偏移（MMD/密度比）与机制稳定性检验判断 e_c 是否适用于当前工况。不通过则权重置 0。独立性权重 ω_ind ≤ 1，相关性高的源不重复计数。

**定义 317（相关感知有效样本量）** 若云端聚合 N 个样本来自 M 个簇、簇内相关 ρ̄，则 N_eff = N / (1 + (N/M − 1)·ρ̄)。所有云端校准置信区间宽度按 1/√N_eff 计算；N_eff 低于阈值则禁止校准类更新，只允许保守方向的自适应。

**定义 318（对偶控制探询预算 DPB）** 令 φ(o) 为参数辨识回归量，本地 Fisher 信息 F_l = E[φφᵀ]，云端对本地参数方向的信息 F_c（按 ω_ind·N_eff·T 折扣）。总信息 F_tot = F_l + F_c。仅当 λ_min(F_tot) < λ_PE（持续激励不足）时才探询，且只探 F_tot 最小特征值对应的方向。探询预算在「辨识」与「控制」间显式分配：b_id + b_ctl = b_total。

**定义 319（负迁移估计 NTE）** 候选参数先在本地验证缓冲/世界模型里做影子评估：r_new = shadow_risk(θ_cand)，r_old = shadow_risk(θ_old)。若 r_new > r_old + ε_NT + z_{1−α}·se，则判定负迁移，拒绝并回滚；回滚事件写入审计，并降低该 provenance 的未来信任权重。

**定义 320（自适应安全罩 SHE）** 认证缓存以参数版本号为键：cert(θ^{(v)})。参数版本变化即失效，必须用新参数重算（或验证旧证书在新参数下仍保守）。内环始终在 cert(θ^{(v)}) 给出的认证动作集内执行；无法及时重认证时，退回上一已认证版本，绝不带未认证参数上控制回路。

**定义 321（参考模型与自适应律）** 参考模型给出期望的安全裕度轨迹 y_ref(t) 与任务进度；跟踪误差 e = y_ref − y。慢环自适应律 θ̇_a = −Γ·Proj_{Θ_safe}(e·φᵀ)（带投影的标准化 MRAC/self-tuning 形式），并只在 AAR/TRP/CEP/NTE 全部通过后以离散快照形式提交。

**定义 322（联邦充分统计量）** 上传/聚合的不是原始数据，而是每类模态的计数、原型、协方差、校准分箱统计与失败案例摘要，满足差分隐私预算 (ε_dp, δ_dp)；带宽 O(K² + B)（B 为校准分箱数），与样本量无关。

**定义 323（跨智能体审计 VQAuditor-X）** 审计对象扩展到云端自适应：更新是否源于可迁移工况、是否单源主导、是否触发过回滚、N_eff 是否被高估、参数版本是否可复现。结论回灌全局 AuditBuf 与 provenance 信任分。

**定义 324（干扰集 AIC-NIMBUS）** ℰ_NIMBUS = ℰ_FLUID × ℰ_cloud，其中 ℰ_cloud = {陈旧/重放, 延迟尖峰, 非 IID 负迁移, 联邦投毒, 女巫智能体(sybil), 脑裂(split-brain), 参数版本混淆}。每类给出可检测信号与降级路径。

**定义 325（证书 J_NIMBUS）** J_NIMBUS = (J_FLUID, θ_a 版本与哈希, AoI_p95, D_TR, N_eff, τ_trust, rollback_count, provenance_hash, dp_ε, nimbus_ver)。Valid ⇔ Valid(J_FLUID) ∧ θ_a ∈ Θ_safe ∧ D_TR ≤ δ_TR ∧ AoI ≤ TTL ∧ NTE 无未处理回滚。

**定义 326（脑裂与一致性）** 云端分区时可能产生两个合法版本 v, v'。边端采用「版本单调 + 哈希链 + 最后已认证」规则：只接受版本号递增且父哈希匹配的提交；检测到分叉则冻结自适应、保留当前已认证快照，并上报审计。

**定义 327（可迁移性检验的统计形式）** 以密度比 w(o)=p_t(o)/p_s(o) 重加权源域风险：R_t(θ) = E_s[w(o)·ℓ(θ;o)]；当 w 的 ESS = (Σw)²/Σw² 低于阈值，或支持集不重叠时，判定不可迁移。

**定义 328（参数版本的可复现性）** 每个 θ_a^{(v)} 绑定 (训练数据哈希集, 聚合算法版本, 随机种子, DP 噪声, 父版本哈希)，任何下游行为可被独立复算审计。

# IP-265 CAL：云端慢环（异步，不进实时回路）
def cloud_adapt(fleet_stats, edge_stats, theta_old, meta):
    S = fed_aggregate(fleet_stats, weights=relevance_weights(meta))   # 只聚合充分统计量
    n_eff = effective_n(S.counts, intra_corr=S.rho)                   # 定义 317
    theta_cand = theta_old.copy()
    for name, upd in candidate_updates(S).items():
        if fisher_info(S, name) >= LAMBDA_PE:                         # 只调可识别方向
            theta_cand[name] = theta_old[name] + upd
    theta_cand = trust_region_project(theta_old, theta_cand, DELTA_TR)  # IP-267
    theta_cand = project_safe_set(theta_cand, THETA_SAFE)               # 定义 311
    return theta_cand, S.provenance, n_eff

# IP-266 AAR：年龄感知门控 + 安全侧漂移补偿
def age_aware_accept(theta_new, t_sent, t_now, ttl, drift_rate):
    aoi = t_now - t_sent
    if aoi > ttl: return None, aoi                     # 太旧：弃用，保留旧快照
    return compensate_safe_side(theta_new, aoi, drift_rate), aoi

# IP-267 TRP：信赖域径向回缩
def trust_region_project(theta_old, theta_new, delta):
    r = behavior_distance(theta_old, theta_new)        # sup_o KL + |Δλ|
    if r <= delta: return theta_new
    return theta_old + (delta / r) * (theta_new - theta_old)

# IP-268 CEP：可迁移性 + 独立性
def cloud_evidence_provenance(e_c, o_t):
    if mmd_density_ratio_ess(e_c, o_t) < ESS_MIN:      # 定义 327
        return Evidence(weight=0.0, independent=False)
    return Evidence(weight=trust_score(e_c.provenance), independent=e_c.independent)

# IP-269 DPB：对偶控制探询（信息够就不探）
def dual_control_probe(modes, w, F_local, F_cloud, budget):
    F_tot = F_local + F_cloud
    if lambda_min(F_tot) >= LAMBDA_PE: return None
    dirs = smallest_eig_dirs(F_tot, k=1)               # 只探最缺激励的方向
    return choose_interaction(modes, w, dirs, budget.split(id=budget.b_id))

# IP-270 NTE：影子评估 + 回滚
def negative_transfer_guard(theta_cand, theta_old, local_val):
    r_new, r_old = shadow_risk(theta_cand, local_val), shadow_risk(theta_old, local_val)
    if r_new > r_old + EPS_NT + z_alpha * se(local_val):
        return theta_old, True                          # 负迁移 → 回滚
    return theta_cand, False

# IP-271 SHE：版本键控的认证罩
def adaptive_shield(theta_version, o_t):
    cert = cert_cache.get(theta_version)
    if cert is None:
        cert = c_ras_wm.certify_all(theta_version.safe_subset, o_t)
        cert_cache.put(theta_version, cert)
    return cert.certified_action_set

# IP-277 双时间尺度主循环
def NIMBUS_inner_round(M, obs):
    k, lam, mode, U = FLUID_RAS_round(M.with_snapshot(theta_a.current), obs)  # 与 R69 完全一致
    cloud.report_local(build_stats(M, obs, U), async_=True)                  # 不阻塞
    return k, lam, mode, U

def NIMBUS_outer_tick(cloud, fleet, local_val):
    theta_cand, prov, n_eff = cloud_adapt(fleet.stats, cloud.edge_stats, theta_a.current, cloud.meta)
    theta_cand, aoi = age_aware_accept(theta_cand, prov.t_sent, now(), TTL, drift_rate)
    if theta_cand is None: return
    ev = cloud_evidence_provenance(prov, local_val.ref_obs)
    if ev.weight <= 0: return
    theta_cand, rolled = negative_transfer_guard(theta_cand, theta_a.current, local_val)
    if rolled: cloud.audit.record_rollback(prov); return
    if not parent_hash_ok(prov): return                  # 脑裂/版本混淆
    theta_a.commit(theta_cand, prov_hash=prov.hash, aoi=aoi, n_eff=n_eff)

## 3. 推导

**引理 19（相关感知有效样本量）** 设云端 N 个样本分成 M 个可交换簇、簇内相关系数 ρ̄，则总体均值估计的方差被放大因子 1 + (N/M − 1)ρ̄ 倍，故有效样本量 N_eff = N/(1+(N/M−1)ρ̄)。系：非 IID 下「1 万条日志」可能只值「几百条独立样本」；N_eff 小则校准置信区间宽，应少调校准参数、多留安全裕度。

**引理 20（对偶控制探询套利）** 设本地与云端对参数向量的 Fisher 信息为 F_l、F_c，云端按 ω_ind·N_eff 折扣。探询必要当且仅当 λ_min(F_l + ω_ind N_eff F_c) < λ_PE。于是「云端省探询」的充要条件是：云端在本地最缺激励的方向上有非零信息。若 F_c 在该方向为零（群体从未经历该工况），则套利为零——**云端不能替你探索它没见过的世界**。

**引理 21（负迁移的风险分解）** 设云端候选相对本地最优的分布偏移为 ε_H（异质性/协变量偏移），估计误差为 ε_est ~ O(1/√N_eff)，则本地风险增量 ≤ L·(ε_H + ε_est) − Δ_gain，L 为风险对参数的 Lipschitz 常数。影子评估以置信水平 1−α 拒绝坏更新，可把错误接受率压到 ≤ α，代价是少量好更新被误拒。

**引理 22（年龄-漂移误差传播）** 若慢漂移满足 ‖θ*̇‖ ≤ ḋ，提交年龄为 Δ，则相对当前最优参数的偏差 ≤ ḋ·Δ。故 TTL = τ_TTL(ḋ) 应满足 ḋ·TTL ≤ 安全裕度的固定比例；漂移越快，TTL 越短，甚至禁用慢环、退回固定 FLUID 参数。

**定理 18（延迟自适应下的安全不变性）** 在 A99–A102（时间尺度分离、有界延迟、本地验证代表性、Θ_safe 凸且含 θ_0）下，NIMBUS 内环始终在 cert(θ^{(v)}) 的认证动作集内执行，且任何提交都经 AAR/TRP/CEP/NTE/SHE 五闸；因此闭环安全集不变，约束违反率不高于 R69；跟踪误差有界：limsup‖e‖ ≤ O(T_c + d_max + ḋ·TTL + ε_est)。当 AoI > TTL 或任何一闸拒绝时，系统退化为参数冻结的 FLUID-RAS。

**定理 19（NIMBUS 严格包含 FLUID-RAS）** 当云端禁用、所有提交被任一闸拒绝、或 N_eff < N_min 时，NIMBUS 逐指令退化为 R69/FLUID-RAS。故安全侧不劣于 R69；自适应只提供可选的效率/校准增益，且增益可被影子评估证伪。

**定理 20（云端证据不破坏证据纪律）** 云端证据以独立性权重 ω_ind ≤ 1 计入 R69 的 k-正交证据；相关源不重复计数。故引理 18 的投毒上界仍成立，且单条云端证据永远不能单独定案；云端最多把「k 源一致」的速度加快，不能降低其独立性门槛。

## 6. 本轮最大风险

**一句话**：NIMBUS 把 R69 的单机「问错」升级为群体的「学错」——**云端可能用一群同样有偏的同伴，把边缘端缓慢、自信、且经过同一套证书流程「认证」地调进一个局部安全但全局错误的参数区**；自适应越平滑，这种负迁移越难被实时察觉。

**次级风险与缓解**：
1. **延迟/陈旧参数** → AAR + TTL + 安全侧漂移补偿 + 退回冻结快照；
2. **非 IID/负迁移** → N_eff + 可迁移性检验 + 影子评估 + 回滚 + provenance 降权；
3. **联邦投毒/女巫** → k-正交证据 + 独立性权重 + 稳健聚合（截尾/中位数）+ 审计；
4. **脑裂/版本混淆** → 版本单调 + 哈希链 + 分叉即冻结 + 可复现性；
5. **自适应参数使旧证书失效** → SHE 版本键控认证 + 提交前重认证 + 未认证不上线；
6. **隐私泄露** → 只传充分统计量 + DP(ε,δ) + 带宽受限。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** 内环零学习写操作；参数快照不可变；自适应单向安全（影子评估+信赖域+安全集不劣化才提交）；云端证据非权威（带出处/年龄/相关性，不能单独满足 k-正交纪律）。

**定义 311–312（参数与双时间尺度）** θ_a 含模态温度、各 TAU、c_VoI、λ_floor、ECE 阈值、交互预算；θ_a ∈ Θ_safe。内环 Δ_t≈2.6ms、外环 T_c 秒~分钟，A99：τ_drift ≫ T_c + d_k。

**定义 313–314（AoI 与 AAR）** AoI = t_now − t_sent；延迟有界、重放/乱序可检；Δ_k > TTL 弃用；否则沿安全侧做一阶漂移补偿再进闸。

**定义 315（TRP）** `D_TR(θ,θ') = sup_o KL(p_θ(M|o)‖p_{θ'}(M|o)) + |λ_θ−λ_{θ'}| ≤ δ_TR`，否则径向回缩。

**定义 316–317（CEP 与 N_eff）** provenance 五元组；可迁移性用密度比 ESS/MMD 检验，不通过权重置 0；`N_eff=N/(1+(N/M−1)ρ̄)`，N_eff 低则禁止校准类更新。

**定义 318（DPB）** `F_tot=F_l+ω_ind·N_eff·F_c`；仅当 `λ_min(F_tot)<λ_PE` 才探询，且只探最小特征方向；显式分配 b_id/b_ctl。

**定义 319（NTE）** 影子评估 `r_new > r_old + ε_NT + z·se` 即回滚，并降低该 provenance 的信任分。

**定义 320–321（SHE 与 ASL）** 认证缓存以版本号为键，参数变更即失效，未重认证则回退旧版本；自适应律 `θ̇_a = −Γ·Proj_{Θ_safe}(e·φᵀ)`，仅以快照提交。

**定义 322–323（FED-SS 与 VQAuditor-X）** 只传计数/原型/协方差/校准分箱/失败摘要，DP(ε,δ)，带宽 O(K²+B)；审计扩展至可迁移性、单源主导、N_eff 高估、版本可复现。

**定义 324–326（干扰集/证书/脑裂）** ℰ_NIMBUS=ℰ_FLUID×ℰ_cloud；J_NIMBUS 并入版本/AoI/D_TR/N_eff/回滚；版本单调+哈希链+父哈希匹配，分叉即冻结。

**定义 327–328（可迁移性与可复现性）** 密度比重加权 `R_t(θ)=E_s[w·ℓ]`，ESS 低或支持不重叠即不可迁移；每版参数绑定数据哈希/算法版本/种子/DP 噪声/父哈希。

# IP-265 CAL：云端慢环（异步，不进实时回路）
def cloud_adapt(fleet_stats, edge_stats, theta_old, meta):
    S = fed_aggregate(fleet_stats, weights=relevance_weights(meta))   # 只聚合充分统计量
    n_eff = effective_n(S.counts, intra_corr=S.rho)                   # 定义 317
    theta_cand = theta_old.copy()
    for name, upd in candidate_updates(S).items():
        if fisher_info(S, name) >= LAMBDA_PE:                         # 只调可识别方向
            theta_cand[name] = theta_old[name] + upd
    theta_cand = trust_region_project(theta_old, theta_cand, DELTA_TR)
    theta_cand = project_safe_set(theta_cand, THETA_SAFE)
    return theta_cand, S.provenance, n_eff

# IP-266 AAR：年龄感知门控 + 安全侧漂移补偿
def age_aware_accept(theta_new, t_sent, t_now, ttl, drift_rate):
    aoi = t_now - t_sent
    if aoi > ttl: return None, aoi                     # 太旧：弃用，保留旧快照
    return compensate_safe_side(theta_new, aoi, drift_rate), aoi

# IP-267 TRP：信赖域径向回缩
def trust_region_project(theta_old, theta_new, delta):
    r = behavior_distance(theta_old, theta_new)        # sup_o KL + |Δλ|
    if r <= delta: return theta_new
    return theta_old + (delta / r) * (theta_new - theta_old)

# IP-269 DPB：对偶控制探询（信息够就不探）
def dual_control_probe(modes, w, F_local, F_cloud, budget):
    F_tot = F_local + F_cloud
    if lambda_min(F_tot) >= LAMBDA_PE: return None     # 激励足够 → 不探
    dirs = smallest_eig_dirs(F_tot, k=1)               # 只探最缺激励的方向
    return choose_interaction(modes, w, dirs, budget.split(id=budget.b_id))

# IP-270 NTE：影子评估 + 回滚
def negative_transfer_guard(theta_cand, theta_old, local_val):
    r_new, r_old = shadow_risk(theta_cand, local_val), shadow_risk(theta_old, local_val)
    if r_new > r_old + EPS_NT + z_alpha * se(local_val):
        return theta_old, True                          # 负迁移 → 回滚
    return theta_cand, False

# IP-271 SHE：版本键控的认证罩
def adaptive_shield(theta_version, o_t):
    cert = cert_cache.get(theta_version)
    if cert is None:
        cert = c_ras_wm.certify_all(theta_version.safe_subset, o_t)
        cert_cache.put(theta_version, cert)
    return cert.certified_action_set

# IP-277 双时间尺度主循环
def NIMBUS_inner_round(M, obs):
    k, lam, mode, U = FLUID_RAS_round(M.with_snapshot(theta_a.current), obs)  # 与 R69 一致
    cloud.report_local(build_stats(M, obs, U), async_=True)                  # 不阻塞
    return k, lam, mode, U

def NIMBUS_outer_tick(cloud, fleet, local_val):
    theta_cand, prov, n_eff = cloud_adapt(fleet.stats, cloud.edge_stats, theta_a.current, cloud.meta)
    theta_cand, aoi = age_aware_accept(theta_cand, prov.t_sent, now(), TTL, drift_rate)
    if theta_cand is None: return
    ev = cloud_evidence_provenance(prov, local_val.ref_obs)
    if ev.weight <= 0: return
    theta_cand, rolled = negative_transfer_guard(theta_cand, theta_a.current, local_val)
    if rolled: cloud.audit.record_rollback(prov); return
    if not parent_hash_ok(prov): return                  # 脑裂/版本混淆
    theta_a.commit(theta_cand, prov_hash=prov.hash, aoi=aoi, n_eff=n_eff)

## 4. 推导

**引理 19（相关感知有效样本量）** N 个样本分 M 个可交换簇、簇内相关 ρ̄ 时，均值估计方差放大 1+(N/M−1)ρ̄ 倍，故 `N_eff=N/(1+(N/M−1)ρ̄)`。系：非 IID 下「1 万条日志」可能只值几百条独立样本；N_eff 小则少调校准、多留裕度。

**引理 20（对偶控制探询套利）** 探询必要当且仅当 `λ_min(F_l + ω_ind·N_eff·F_c) < λ_PE`。故「云端省探询」的充要条件是云端在本地最缺激励方向上有非零信息；若该方向 F_c 为零，套利为零——**云端不能替你探索它没见过的世界**。

**引理 21（负迁移风险分解）** 本地风险增量 ≤ `L·(ε_H + ε_est) − Δ_gain`，ε_est~O(1/√N_eff)；影子评估以 1−α 置信拒绝，把错误接受率压到 ≤ α，代价是少量好更新被误拒。

**引理 22（年龄-漂移误差传播）** 若 ‖θ*̇‖≤ḋ、提交年龄 Δ，则相对当前最优偏差 ≤ ḋ·Δ；故 `ḋ·TTL ≤ 安全裕度固定比例`，漂移快则 TTL 短，甚至禁用慢环。

**定理 18（延迟自适应下的安全不变性）** 在 A99–A102 下，内环始终在 cert(θ^{(v)}) 动作集内，提交经 AAR/TRP/CEP/NTE/SHE 五闸，故闭环安全集不变、违反率不高于 R69；`limsup‖e‖ ≤ O(T_c+d_max+ḋ·TTL+ε_est)`；AoI>TTL 或任一闸拒绝即退化为冻结 FLUID。

**定理 19（NIMBUS 严格包含 FLUID-RAS）** 云端禁用、提交被拒、或 N_eff<N_min 时逐指令退化为 R69/FLUID-RAS；安全侧不劣，自适应仅提供可被证伪的增益。

**定理 20（云端证据不破坏证据纪律）** 云端以 ω_ind≤1 计入 k-正交证据，相关源不重复计数；故引理 18 投毒上界仍成立，单条云端证据永不单独定案。

## 7. 本轮最大风险

**一句话**：NIMBUS 把 R69 的单机「问错」升级为群体的「学错」——**云端可能用一群同样有偏的同伴，把边缘端缓慢、自信、且经过同一套证书流程「认证」地调进一个局部安全但全局错误的参数区**；自适应越平滑，负迁移越难被实时察觉。

**次级风险与缓解**：延迟/陈旧（AAR+TTL+安全侧补偿+冻结快照）；非 IID/负迁移（N_eff+可迁移性+影子评估+回滚+provenance 降权）；联邦投毒/女巫（k-正交+独立性权重+稳健聚合+审计）；脑裂/版本混淆（版本单调+哈希链+分叉冻结+可复现）；证书失效（SHE 版本键控+提交前重认证+未认证不上线）；隐私（充分统计量+DP+常数带宽）。
