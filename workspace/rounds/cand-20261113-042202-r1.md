# 第 3 轮迭代（新灵感循环 v3 · 第 1 轮：「机械臂抓取」×「迭代验证」）—— 把抓取做成一份可证伪的承诺：事前签证书、事中分层审计、事后按失败模式重抓

> **本轮不换赛道，换"验证的位置"。** 承接 v2 的 UIP-01′/09′（检测"进度被撤回"→重做）与 UIP-11/12（Gazebo 判分 + 扰动工厂）。v2 的验证发生在"子目标进度"层，离失败已经太远；本轮下沉到所有操作的原子承诺——**抓取**。两个灵感词各回答一半：**机械臂抓取**回答"验什么"（一个可计算的抓取裕度证书），**迭代验证**回答"怎么验"（一串越来越贵、越来越有信息量的测试 + 最优停止）。
>
> **诚实声明**：本轮**未新增系统检索**；§0 的抓取器规格来自 2026-11-13 对 Unitree 公开产品文档的抽查，其余事实沿用 v2（2026-11-12）。带"推断/待核实"的内容是推导，不作为已核实结论。

## 0. 一条改变重心的硬事实：Dex1-1 是单自由度平行夹爪

| 事实 | 内容 | 来源 |
|---|---|---|

| 反馈/控制 | 电机状态反馈含角度/角速度/力矩/温度；控制指令含角度/角速度/力矩/刚度/阻尼；通信控制频率 1000Hz | 同上 |

| 赛制实际末端 | 数据集名为 `G1_Dex1_*`；接口动作中的夹爪维度与力矩反馈是否暴露 | **待核实**（保守假设：只有位置/夹爪开合，无原始力矩） |
| 若实际为多指手 | 若赛制用 Dex3-1（7 DOF、3 指），证书退化为"多接触力闭合"版本，方法框架不变 | 推断（support.unitree.com，2026-11-13） |

**直觉。** 多指手的抓取是"包络"，平行夹爪的抓取是"两点对跖"。这看起来更弱，但对研究反而是好事——成败几乎被三个可测量决定：**孔径余量、对跖对齐、摩擦/夹力余量**。它们可解释、可标定、可用几何谓词直接算，正好适合做成"证书"。

**严谨定义（平行夹爪的抓取裕度）。** 设物体沿闭合轴的宽度 `w`，夹爪孔径 `a`，指长 `L`，接触中心相对指根偏移 `e`，接触斑长度 `L_c`，质量 `m`，质心偏心 `d`，摩擦系数 `μ`，法向夹力 `F ∈ [F_min,F_max]`。定义四个归一化裕度：

```text
M_s = 2 μ F / (m g) − 1                      # 抗竖直滑移
M_r = μ F · L_c / (m g · d) − 1              # 抗绕接触线转动
M_a = min((a − w)/δ_a, (w − w_min)/δ_w)      # 孔径余量（太小夹不住、太大夹不紧）
M_φ = 1 − φ / φ_max                          # 对跖法向与夹爪闭合轴的夹角
M   = min(M_s, M_r, M_a, M_φ)
```

`M ≥ 0` 是"几何-力学可抓"的判据。以 Dex1-1 规格做量级校验（示例，非实测）：`μ=0.5、m=1kg` 时，`F=20N` 给出 `M_s≈1.04`，`F=5N` 给出 `M_s≈−0.49`——**同一个 1kg 物体，夹力 5N 必掉、20N 有 2 倍余量**；若质心偏心 `d=2cm`、接触斑 `L_c=2cm`，`F=20N` 时 `M_r≈0.02`，几乎贴着边界。这解释了为什么"能夹起来"和"能搬着走"是两件事。

## 1. 两个灵感词：先直觉，后定义

### 1.1 机械臂抓取：不是"手张开再合上"，是"用有限接触换取对物体的暂时支配权"

**直觉。** 抓取不是动作，是**承诺**：机器人断言"未来 H 步内，我能对物体施加足够的 wrench，且物体相对夹爪不漂移"。一旦承诺被打破——滑移、掉落、被人拿走、支撑面被移走——后面所有计分步都建在沙上。承诺有两个特点：它**可以被证据支持**（接触形成、微提不掉、相对位姿稳定），也**可以被证据撤销**（相对位姿漂移、伺服残差突变）。于是抓取天然适合做成一份**带证据的证书**，而不是一个布尔动作。

**严谨定义。** 抓取假设 `h = (T_o, T_g, a, w, μ, m, d, C)`（`C` 为接触集）。**证书**是一个映射

```text
c(h, o) = P( M(h) ≥ 0 | o )  ∈ [0,1]
```

其中 `o` 是截至当前的全部观测（多视角图像、夹爪关节反馈、指令历史）。证书不是"抓取成功"的标签，而是"在未来 H 步的扰动集 `W` 下仍保持支配"的概率。它必须带**输入不确定度**：`c = c̄ ± σ_c`；当 `σ_c` 大时触发主动探测，而不是硬判。

### 1.2 迭代验证：不是"多测几次"，是"用一串越来越贵、越来越有信息量的测试，把后验推过决策阈值"

**直觉。** 一次判断"这个抓取稳不稳"很难；但"先看对齐 → 再探接触 → 再轻提 → 再侧向错动"这条链，每一步都很便宜地排除一类失败。迭代验证 = 在**时间预算与步骤分预算**内做**最优停止**：不是测到"确定"为止，而是测到"再测的期望收益 < 再测的成本"为止。

**严谨定义。** 测试序列 `τ_1,…,τ_T`，成本 `c_i`（秒），观测 `y_i`，后验 `p_t = P(M≥0 | y_{1:t})`。两个停止边界：

```text
advance  if  p_t ≥ 1 − C_r / ΔV
regrasp  if  p_t ≤      C_r / ΔV
否则继续（或预算耗尽 → 选当前风险最小的动作）
```

其中 `ΔV` 是"抓取失败会损失的后续步骤分"，`C_r` 是重抓的等价成本。**测试选择**按单位成本信息增益最大：

```text
τ* = argmax_τ  I(M≥0 ; y_τ | h) / c_τ
```

**试探动作（probe）**：一种特殊的测试——不是被动等观测，而是主动做一个短动作，让观测对"稳/不稳"最可分辨。平行夹爪的自然试探库只有四个：沿重力**轻提**、沿闭合轴**轻推**、绕闭合轴**轻扭**、垂直闭合轴**轻剪**。试探是我们自己的动作，完全在 API 权限内；代价是几十到几百毫秒。

### 1.3 耦合命题（本轮核心判断）

> **抓取是"承诺"，迭代验证是"对承诺的持续审计"。** 二者合流后，v2 的 `regressed`（人为撤回）与滑移/掉落不再是两类事件，而是同一件事的两种表现：**证书被撤销**。这把"干扰恢复"与"抓取纠错"合并成一个机制，也把"抓取"从一个一次性动作变成一条可追责的证据链。

## 3. 瓶颈假设（v3）

- **H1（最高杠杆）**：在本赛制里，**晚失败的边际损失最大**（末步分值恒 ≥ 前序步），而晚失败最常见的根因是早期抓取处于"边缘稳定"。把验证前移到抓取，收益/成本比高于在任何后续步加验证。
- **H2**：Dex1-1 的 1-DOF + 0.1mm 重复定位 + 力矩反馈，使"接触形成"和"滑移"可以用**伺服残差（指令 vs 实际） + 物体相对夹爪的位姿漂移**廉价检测，不一定需要触觉阵列。
- **H3**：证书的误差主要来自**输入估计**（宽度/位姿/摩擦），不是来自模型。因此证书必须带输入不确定度，并在不确定时**主动探测**而非硬判。
- **H4（反直觉）**：夹力不是越大越好。夹力越大，软物体形变、被"挤出"、绕接触线翻转的风险越大；最优夹力是"刚好超过摩擦锥 + 安全系数"，而不是 120N 拉满。
- **H5**：重抓的时间成本是真实约束，验证预算应按 `(保护分值 × 抓取不确定度) / 重抓成本` 分配，而不是每个抓取都走完整五层测试。

## 1. 旗舰深潜：GMC + PVP + RUV

### 1.1 证书的三层结构

**第 1 层：解析先验（零模型，写在代码里）。** 用 §0 的 `M = min(M_s, M_r, M_a, M_φ)` 给出物理下界。它不需要训练，先验可解释，且在极端情况（比如 5kg 物体 + 5N 夹力）能直接一票否决。

**第 2 层：观测证据（把公式里的量测出来）。**
- `w`：由 head 立体对或腕部深度估物体沿闭合轴的宽度；透明/反光物体用轮廓 + 抓取历史兜底。
- `φ`、`e`：腕部相机看夹爪与物体接触面，估对跖法向与接触中心偏移。
- 接触形成：闭合时**伺服残差** `r_q = q_cmd − q_obs`；夹爪"以为还在合、实际停住"即接触。
- 滑移：物体相对夹爪的位姿漂移 `ΔT_rel = ||(T_g^{-1}T_o)_t − (T_g^{-1}T_o)_{t-1}||`；夹爪稳定而物体动 = 滑移。
- 夹力：若接口只给位置，用 `F ≈ K·r_q`（`K` 为夹爪刚度，可由离线标定得到）近似；若力矩可读，直接用。

**第 3 层：校准（把物理量变成概率）。** 用一个**极小**的逻辑回归 / 等渗回归把特征 `(M_s, M_r, M_a, M_φ, σ_w, σ_T, r_q)` 映射到 `c`。它可离线用 GSO（UIP-11）+ DRF（UIP-12）标定，参数只有十几个——既满足"单模型"合规，也能在真机上用几十条 rollout 重新校准。输出 `(c, σ_c)`，`σ_c` 由输入方差传播得到。

> **关键设计**：证书不是黑箱打分，而是"解析先验 + 少量可解释修正"。这样即使校准层失效，物理下界仍在；反过来，物理下界过于保守时，校准层负责放宽。

### 1.2 五层迭代验证协议（Tier 0–4）

| Tier | 测试 | 观测量 | 增量成本 | 主要排除的失败 | 触发条件 |
|---|---|---|---|---|---|
| T0 | 预抓取几何 | `w, a, φ, e` + `M_s/M_a/M_φ` 先验 | ~0（复用当前帧） | 太宽/太窄/明显偏心/角度错 | 每次抓取前 |
| T1 | 闭合接触 | 伺服残差 `r_q`、闭合时间、接触位置 | ~0.2–0.3s（Dex1 全行程 0.24s） | 空抓、太浅、只碰一指 | T0 通过后 |
| T2 | 微提（沿重力 1–3cm） | 物体相对夹爪漂移、`r_q` 变化 | ~0.3–0.5s | 低摩擦滑移、夹力不足 | T1 通过后 |
| T3 | 侧向/扭转试探 | 正交方向漂移、绕闭合轴转角 | ~0.3–0.6s | 转动失稳、质心偏心、软物体挤出 | `ΔV` 高或 T2 边缘时 |
| T4 | 运输监控 | 连续相对位姿、夹爪残差、支撑面变化 | ~0（随策略） | 人为撤回、支撑面被移、渐进滑移 | 整个搬运段 |

**迭代规则（最优停止）**：每个 Tier 给出一个似然比 `LR_i = P(y_i|不稳)/P(y_i|稳)`，累积 `Λ_t = Σ log LR_i`。等价地，把每层观测并入后验 `p_t`，用 1.3 的阈值停。**低风险抓取在 T2 后就放行，高风险抓取才升到 T3**；T4 不阻塞动作，只负责"撤销证书"。

### 1.3 决策阈值与"值在险"（推导）

设 `V` = 抓取稳定时后续步骤的期望得分，`V_f` = 抓取失败时的期望得分，`V_r` = 重抓后的期望得分，`C_r` = 重抓的等价成本（时间/风险折算成分数），`p = P(稳定 | 证据)`。

```text
EU(advance)  = p·V + (1−p)·V_f
EU(regrasp)  = V_r − C_r
advance  ⇔  p·V + (1−p)·V_f ≥ V_r − C_r
        ⇔  p ≥ (V_r − C_r − V_f) / (V − V_f)
```

若重抓基本能恢复到 `V_r ≈ V`，则阈值简化为

```text
p* = 1 − (C_r + (V − V_r)) / ΔV ,   ΔV = V − V_f
```

**读法**：`ΔV`（值在险）越大，阈值越低——越值得重抓；`C_r`（重抓成本）越大，阈值越高——越倾向将就。**这就是"按步骤分分配验证预算"的数学形式**，也是 UIP-27 的核心。

**由计分点直接读出 `ΔV`**（抓取发生在第 j 个计分步，保护其后所有步）：

| 计分结构 | 任务数 | 抓取在第 1 步：`ΔV` | 抓取在第 2 步：`ΔV` | 抓取在末步：`ΔV` |
|---|---|---|---|---|
| 2 步 50/50 | 11 | 50 | 0 | 0 |
| 3 步 30/30/40 | 14 | 70 | 40 | 0 |
| 4 步 25×4 | 5 | 75 | 50 | 0 |
| 5 步 20×5 | 2 | 80 | 60 | 0 |

> 结论：**抓取越靠前，验证越值钱**。这也解释了为什么"先抓对"比"后面补"重要——末步分值最大，而末步之前的所有抓取都在保护它。

**期望收益（示例参数，非真机）**：设坏抓取率 `p_bad`、真阳检测率 `d`、假阳率 `f`、重抓成功率 `r`，则

```text
ΔE ≈ ΔV · [ p_bad·d·r − (1−p_bad)·f·(1−r) ]
```

取 `p_bad=0.35, d=0.8, f=0.05, r=0.9`：`ΔV=50` 时 `ΔE≈12.4`，`ΔV=70` 时 `≈17.4`，`ΔV=80` 时 `≈19.9` 分。**假阳项很小，因为"误重抓一个好抓取"通常只是多花时间，不直接丢分**——这正是证书式验证相对"宁可错杀"的启发式更划算的原因。

### 1.4 失败模式 → 定向重抓映射（UIP-23）

| 失败模式 | 主要证据 | 定向修正（不是盲目重来） |
|---|---|---|
| 太宽/太窄 | T0 `M_a < 0`；闭合残差很小或很大 | 换抓取轴/换部位（把手、边缘）；换更大行程的接触位置 |
| 偏心/浅抓 | T1 接触点靠指尖；`e` 大 | 沿指长方向后退 1–2cm 再闭；降低接近高度 |
| 对跖角度错 | T0 `M_φ < 0`；腕部看到斜面 | 绕接近轴转腕 `±φ`；改用侧壁/棱边 |
| 夹力不足/滑移 | T2 漂移超阈；`M_s < 0` | 提高夹力（不超过 `M_r` 允许）；减小加速度 |
| 转动失稳 | T3 绕闭合轴转角超阈；`M_r < 0` | 二次抓取更深；改抓质心附近；降低搬运速度 |
| 人为撤回/支撑移动 | T4 相对位姿跳变；物体离开夹爪 | 重新定位物体 → 重新抓取或重新放置（合并 v2 的 DCR-R） |

**要点**：失败模式与修正动作是**多对一按证据路由**的，不需要重新跑完整抓取规划。这使重抓的平均成本远低于"从头再来"。

### 1.5 与 v2 "人为撤回"的统一

v2 已核实：`human_*` 大量是"把已完成进度撤回"（T08 抓书后挪架子、T11 抓电池后动绿盒、T12 中途把锁拿走、T25 放第一个后马上挪底座、T27 叠第二个后拿下第二个）。在证书框架下，这些事件统一为 **T4 撤销**：

```text
证书撤销 ⇔ 目标物体/支撑面相对夹爪（或世界）发生不可解释的位姿跳变
        ⇒ 冻结下游计分步
        ⇒ 重新估计物体位姿
        ⇒ 若仍可抓：重抓；若已被移走：先恢复物体，再抓
```

这样，"抓取滑移"和"人为撤回"共享同一套检测器与同一套恢复动作，v2 的 `regressed` 分支不再是特例。

## 2. UIP-27 · SGS（步骤分门控护盾）

- **机制**：在每个计分步边界做一次"是否放行"决策。放行条件是 `c ≥ p* = 1 − (C_r + (V−V_r))/ΔV`。`ΔV` 从 §1.3 的表直接读，`C_r` 用当前实测延迟与重抓耗时估计。
- **预算分配**：对每个抓取计算 `priority = ΔV · σ_c / C_r`，按优先级从高到低分配 Tier 深度。低优先级抓取只跑 T0–T2；高优先级（保护 70–80 分、且证书方差大）才跑 T3。
- **反过度验证**：设全局验证时间预算 `B_v`（例如 episode 时限的 15%），以及每任务最大重抓次数 `N_r`（例如 2）。超预算时退回"最保守但能做完"的动作，避免为了验证而超时。
- **与 UIP-02′ 的关系**：UIP-02′ 是"按计分点有序推进"的调度器；SGS 是它的**门控条件**——不是每一步都推进，而是"证书通过才推进"。

## 3. UIP-26 · AGS（可供性-几何抓取候选）

- **候选生成**：`language` + 首帧 → 部件先验（杯把、瓶颈、盒盖、拉链头、毛巾边）+ 立体测宽 → 生成 `K` 个候选 `(抓取轴, 接触位置, 接近方向, 目标夹力)`。
- **解析预排序**：用 §0 的 `M` 公式给每个候选算 `M`，先淘汰 `M<0`；剩下的按"证书上界 `c_up`"排序。
- **迭代验证**：只对 top-`k` 执行；每个执行后按 §1.2 验证；失败则用 §1.4 的映射生成下一个候选，而不是随机重采样。
- **未见物品**：语义先验给"该抓哪一部分"，几何给"这一部分多宽、是否对跖"；两者冲突时以几何为准（安全），语义只用于排序。
- **多抓取任务**（T16 叠毛巾、T27 叠碗、T22 拼字母）：每次新的抓取都重新签证书；上一次的成功不自动继承。

## 4. UIP-24 · CIPV（证书-策略协同迭代）

- **外循环（研究/离线）**：GSO + DRF 生成 `(抓取方式, 物体参数, 扰动) → 稳定/滑移/撤回` 标签；用它标定证书（§1.1 第 3 层），并筛选出"证书说稳但实际掉了"和"证书说险但实际稳"的困难样本。
- **内循环（执行/在线）**：不训练、不反传；只用观测更新后验与校准参数（最多做一次在线逻辑回归的几维更新），保证延迟与"单模型"合规。
- **策略学习**：把"证书通过且最终成功"的 rollout 作为正样本，"边缘稳定导致晚失败"的作为负样本，微调动作头，使策略主动选择**证书裕度大**的抓取，而不是"看起来最近"的抓取。证书头与动作头共享骨干（单模型），证书头只做辅助监督。
- **与"迭代验证"的双关**：外循环是研究的迭代验证（每个假设都要有 kill criterion，见 §8），内循环是执行的迭代验证（每次抓取都要有证书）。

## 5. UIP-25 · GVB（抓取验证基准与数据）

- **扰动网格**：`μ ∈ {0.2,0.3,0.5,0.7}` × `m ∈ {0.1,0.3,1,2,5}kg` × `w ∈ {20,50,80,88}mm` × 姿态偏角 `φ ∈ {0,5,10,20}°` × 质心偏心 `d ∈ {0,1,2,4}cm` × 遮挡/反光/标定噪声。
- **指标**：
  - 校准：ECE、Brier、可靠性曲线（证书说 0.8 稳，实际是否约 80% 稳）。
  - 检测：真阳率/假阳率、检测延迟（Tier 级）、撤销到恢复的时间。
  - 经济性：`Δ` 步骤分、`Δ` 成功率、验证时间占比、重抓次数。
  - 鲁棒：跨物体、跨视角、跨摩擦的迁移。
- **数据来源**：GSO（UIP-11）扫参数；DRF（UIP-12）脚本化"滑移 + 重抓 + 人为撤回"；真机只做**校准锚点**（每类抓取几十条），不追求大规模采集。
- **公开数据零覆盖的补救**：与 v2 的"人扰轴零覆盖"同理，公开 32000 episodes 几乎没有"滑移后重抓"的演示；GVB 是唯一能系统补齐这条轴的地方。

## 6. UIP-28 · AVC（Any-time 验证调度）

- **分层预算**：Tier 0–1 必做（便宜）；T2 默认做；T3 只在 `priority` 高时做；T4 常驻但不阻塞。
- **Any-time 输出**：任何时刻被评测端调用，都返回"当前证书 + 当前最优动作"；证书不足时返回**保守动作**（更慢的接近、更深的插入、更小的加速度），而不是等验证完成。
- **块长联动**：接触密集段用小 `k`（高频重观测，配合 T4）；自由搬运段用大 `k`（省往返）。`action_chunk_size` 在握手期固定为 `K_MAX`，每次返回 `≤K_MAX` 的块（保守假设；若接口要求严格等长则退回固定块长）。
- **可信度护栏**（吸收 v2 UIP-15）：重抓/试探不得造成动作统计异常；给验证动作设最大次数、最大时长、平滑滤波，避免"抽搐式"动作被可信度判定盯上。

class GraspCertificate:
    """UIP-21: analytic margin -> evidence update -> calibrated probability."""
    def __init__(self, calib, delta_a=0.01, phi_max=0.35, w_min=0.005):
        self.calib = calib            # tiny logistic regression, offline-calibrated
        self.delta_a, self.phi_max, self.w_min = delta_a, phi_max, w_min

    def margins(self, h):
        Ms = 2*h.mu*h.F/(h.m*g) - 1
        Mr = h.mu*h.F*h.Lc/(h.m*g*h.d + 1e-9) - 1
        Ma = min((h.a - h.w)/self.delta_a, (h.w - self.w_min)/0.01)
        Mphi = 1 - h.phi/self.phi_max
        return dict(Ms=Ms, Mr=Mr, Ma=Ma, Mphi=Mphi,
                    M=min(Ms, Mr, Ma, Mphi))

    def __call__(self, h, obs):
        z = self.margins(h)
        z.update(servo_residual=obs.r_q, slip=obs.drift,
                 sigma_w=obs.sigma_w, sigma_T=obs.sigma_T)
        c = self.calib.predict_proba(z)          # p in [0,1]
        sigma = self.calib.predict_std(z)        # input-uncertainty propagated
        return c, sigma, z


class IterativeVerifier:
    """UIP-22/23/28: tiered tests + optimal stopping + targeted regrasp."""
    def __init__(self, cert, tiers, C_r_of, budget_ms=1200, max_regrasp=2):
        self.cert, self.tiers = cert, tiers
        self.C_r_of, self.budget_ms, self.max_regrasp = C_r_of, budget_ms, max_regrasp

    def decide(self, h, obs, delta_V, budget_left):
        c, sigma, z = self.cert(h, obs)
        # UIP-27: task-specific threshold from value at risk
        p_star = 1 - (self.C_r_of(delta_V) + 0.0) / max(delta_V, 1e-9)
        p_star = min(max(p_star, 0.5), 0.99)
        trace = []
        for tier in self.tiers:                 # T0..T4, cheap -> expensive
            if c >= p_star and c - 2*sigma >= p_star - 0.1:
                return "advance", c, trace       # confident enough
            if budget_left <= 0:
                return "advance_safe", c, trace  # any-time fallback
            y = tier.run(h, obs)
            c, sigma, z = self.cert.update(h, obs, y)
            trace.append((tier.name, y, c))
            budget_left -= tier.cost_ms
            if c <= p_star and z["failure_mode"]:
                return ("regrasp", c, trace, z["failure_mode"])
        return "advance_safe", c, trace

    def regrasp(self, h, mode):
        # UIP-23: targeted correction, not random re-try
        return TARGETED_FIX[mode](h)


class CommitmentController:
    """Wraps the v2 policy; gates downstream scoring steps on the certificate."""
    def __init__(self, policy, verifier, score_vector, K_MAX=8, N_r=2):
        self.policy, self.verifier = policy, verifier
        self.s = score_vector
        self.K_MAX, self.N_r = K_MAX, N_r

    def reset(self):
        self.policy.reset(); self.g = 0; self.n_regrasp = 0
        self.cert = None; self.commit = None; self.buf = []

    def get_action(self, obs):
        # 1) always cheap-monitor the current commitment (T4)
        self.cert = self.verifier.cert.update_online(self.commit, obs)
        if self.cert.revoked:                       # slip / human undo / support moved
            return self.recover(obs)                # freeze downstream, re-estimate
        # 2) at a scoring-step boundary, decide whether to advance
        if self.at_boundary(obs):
            dV = sum(self.s[self.g+1:])             # value at risk
            verdict = self.verifier.decide(self.commit, obs, dV, self.budget_left())
            if verdict[0] == "regrasp" and self.n_regrasp < self.N_r:
                self.n_regrasp += 1
                return self.verifier.regrasp(self.commit, verdict[3])
            if verdict[0] == "advance_safe":
                self.policy.slow_down()             # conservative fallback
        # 3) otherwise: policy action chunk, optionally with a probe
        if not self.buf:
            self.buf = list(self.policy.get_action(obs, self.K_MAX))
        return self.buf.pop(0)

# UIP-22: probe selection by expected information gain per unit cost (schematic)
def choose_probe(h, posterior, probes):
    best, best_score = None, -1
    for p in probes:                              # lift / push / twist / shear
        y_pred = p.predict_observation(h, posterior)
        ig = mutual_information(posterior, y_pred)  # bits about M>=0
        score = ig / p.cost_ms
        if score > best_score:
            best, best_score = p, score
    return best

## 10. 合规与风险

- **单模型合规**：证书的校准层只有十几个参数、且与策略共享骨干；Tier 0 的解析公式是代码不是模型。**不要**引入外部 VLM 做"抓取好不好"的判断——那会把"单模型"变成灰色地带。
- **不能假设有触觉/力矩**：若接口只给夹爪开合位置，T1 用伺服残差、T2 用视觉漂移；证书的 `σ_c` 要相应变大，阈值更保守。若力矩可读，则 `F` 与滑移检测显著变强。
- **透明/反光/遮挡**：宽度与位姿估计在这些物体上最容易偏；证书必须显式携带 `σ_w, σ_T`，并在 `σ` 大时**降低置信度、增加试探**，而不是给一个高 `c`。
- **仿真过拟合**：GSO/GVB 只用于**标定与结构验证**，不能替代真机锚点；证书的可靠性曲线必须用真机几十条数据校准一次。
- **动作可信度**：试探/重抓会产生"非典型"动作；用最大次数、平滑、限速约束，避免被判为异常（v2 UIP-15 的护栏继续有效）。
- **时间预算**：验证与重抓都吃 episode 时限；若任务本身很短（2 步 50/50），只跑 T0–T2，别把时间花在 T3。

## 11. 本轮最大风险 & 押注

**一句话**：证书的输入（物体宽度、位姿、摩擦）本身不可观测；若几何估计有偏，证书会"自信地错"，而重抓的时间成本可能吃掉它保护下来的步骤分。

**→ 押注：UIP-21/22/23 的"抓取承诺闭环"**——它把 v2 里"事后察觉撤回"的被动恢复，前移成"花掉后续步骤分之前先证明这次抓取配得上"的主动门控；同时用同一套证书统一了滑移、掉落与人为撤回三类失败，且完全落在选手 API 权限与离线算力之内。先做 E201/E205 两个证伪实验：如果证书连夹力/宽度都测不准，就立即退回"固定保守抓取 + 只做 T4 撤销检测"的简化版。
