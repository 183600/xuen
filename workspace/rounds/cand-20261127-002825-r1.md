## 1. 直觉与动机

### 灵感 1（场景理解 → 从「像素分布覆盖」到「场景因子分解」）

**直觉**：第 1 轮把五轴泛化当作五个数据覆盖问题（I1 增广），这是在「统计上把训练分布撑大」。但换个角度看，五类评测扰动没有一类改变了任务本身——杯子还是杯子、插头还是插头，变的只是**场景中与任务无关的部分**，或**任务物体被外力改写**。一个只吃像素的端到端策略把「任务状态」和「场景长相」纠缠在一个表征里，所以背景换色也会改变动作。场景理解要做的，是把观测**分解**为任务相关状态（物体、位姿、可供性、关系）与 nuisance（背景、杂物、外观）；一旦策略只条件于前者，泛化就从「覆盖分布」变成「表示不变性」。更进一步：**相邻两帧的场景差分，是五轴统一的观测量**——人手移动物体、干扰物出现、物体被挪位，都是「场景里某处变了」。难点是区分「我自己造成的改变」与「世界被外力改写」；神经科学早就给了答案：大脑用**传出副本（efference copy / corollary discharge）**预测自身动作的感官后果，残差即外源事件。机器人同样可以做：用前向场景模型预测「我的动作应该造成什么场景差分」，观测差分减去预测差分，剩下的就是外源差分。

**严谨定义**：记观测 $o_t=(I_t^{1:4},q_t,g_t,l)$，其中 $l$ 是任务语言。场景图

$$
G_t=(V_t,E_t,A_t),\quad v=(c,T\!\in\!SE(3),z,K,\mathrm{id},u),
$$

$c$ 为类别、$T$ 为位姿、$z$ 为形状/外观嵌入、$K$ 为可供性锚点（抓取点/插孔/杯口/拉链头）、$u$ 为不确定度；$E_t$ 为关系（on/in/near/supports/occludes）；$A_t$ 为智能体节点（机器人连杆、人手）。语言 grounding 给出任务相关子图

$$
\gamma(l)\to(V^\star,R^\star,K^\star).
$$

**不变性目标**：若 $o,o'$ 诱导相同的任务相关图，则策略应同分布。定义 nuisance 不变性误差

$$
\varepsilon_{\mathrm{inv}}=\mathbb{E}_{o\sim_s o'}\Big[D\big(\pi(a\mid\phi(o)),\,\pi(a\mid\phi(o'))\big)\Big],
$$

则泛化误差可分解为

$$
\mathrm{Err}_{\mathrm{gen}}\ \le\ \underbrace{\mathrm{Err}_{\mathrm{est}}(\phi)}_{\text{场景估计}}+\underbrace{\mathrm{Err}_{\mathrm{inv}}}_{\text{不变性}}+\underbrace{\mathrm{Err}_{\mathrm{policy}}}_{\text{策略拟合}} .
$$

I1 用增广降低 $\mathrm{Err}_{\mathrm{est}}$ 在支撑上的经验值；I9 用因子化**结构性地**压低 $\mathrm{Err}_{\mathrm{inv}}$——两者互补，而非替代。

**传出副本与外源差分**：设前向场景模型 $f_\theta:(G_{t-1},a_{t-1},l)\mapsto\hat G_t$，定义

$$
\Delta G_t=G_t\ominus G_{t-1},\qquad
\Delta\hat G_t=\hat G_t\ominus G_{t-1},\qquad
R_t=\Delta G_t\setminus\Delta\hat G_t .
$$

$R_t$ 是**不能被自身动作解释**的场景变化。事件后验 $p(e\mid R_t,\text{hist})$，$e\in\{\text{NONE},\text{HUMAN},\text{DISTRACTOR},\text{STALL},\text{SLIP},\text{NOVEL}\}$。五轴到差分签名的映射：

| 评测轴 | 场景差分签名 | 策略应有的反应 |
|---|---|---|
| 位置泛化 | 任务节点位姿变、关系变 | 重 grounding、重规划（不是让位） |
| 干扰物 | 新增低相关节点 | 忽略（不得改变任务子图） |
| 背景 | 仅纹理/光照变，图不变 | 完全不变 |
| 未见物品 | 同类节点外观/形状变、可供性保持 | 类别级 affordance 迁移 |
| 人为干扰 | 外源差分改写任务节点/出现人手 | 让位→重估→续做（PR3） |

**最反直觉的一点**：真正要检测的不是「有没有手」，而是「有没有**无法用自身动作解释**的任务相关场景变化」。手在画面里但不碰任务物体，不应冻结；手没入画但物体被挪走，必须反应。这直接修掉第 1 轮 I4「手检测误报导致频繁冻结」的结构性缺陷。

### 灵感 2（开源生态 → 从「造基础模型」到「组件供应链 + 数据工厂」）

**直觉**：这场比赛的基座被开源「拉平」了——官方给了 UnifoLM 基线，社区还有 π0.5、GR00T N1.7、OpenVLA。大家起跑线相近，**胜负不在「谁再预训练一个更大的 VLA」，而在三件开源生态擅长的事**：(a) **组合**——把开放感知、仿真、服务组件按接口契约拼成可靠系统；(b) **生成**——用开放仿真器补齐真机数据没有的五轴组合；(c) **吞吐**——用可复现的评测/实验流水线，把「诊断→修复→提交」的循环转得比别人快。生态是「公地」：最优策略不是从零进化出新物种，而是做最强的**组装者/关键种**，同时把工具回馈社区换取反馈与可复现性。但开源不是免费：许可（部分权重非商用）、版本漂移、依赖冲突、精度/延迟参差，都是必须显式管理的**供应链风险**。

**严谨定义**：把外部资产视为组件

$$
c=(\mathrm{role},\ \mathrm{capability},\ \mathrm{IO},\ \mathrm{resource},\ \mathrm{license},\ \mathrm{provenance}),
$$

一条流水线是组件 DAG；**可组合**要求 IO 契约兼容且各段延迟预算之和不超过总预算。资格算子

$$
Q(c)=\mathrm{license}\wedge\mathrm{latency}_{p99}\wedge\mathrm{accuracy}\wedge\mathrm{repro}\wedge\mathrm{maint},
$$

只允许 $Q(c)=\text{accept}$ 的组件进入计分路径。生态杠杆

$$
L(c)=\frac{\Delta\mathrm{perf}}{\mathrm{integration\ cost}}\times\mathrm{reuse},
$$

在 $Q$ 约束下选 $L$ 最大者。数据侧同理：真机数据 $D_{\rm real}$ 覆盖标称场景，仿真数据 $D_{\rm sim}$ 覆盖参数化五轴；用域分类器 AUC 监控 sim-real gap，用密度比做重要性加权，少量真机做校准。教师→学生蒸馏仍是**一个模型**，符合 PR2，同时把大基座压到可部署延迟。

**最反直觉的一点**：开源生态里最贵的不是模型权重，而是**资格认证与集成成本**。一个「不够强但许可干净、p99 稳定、接口可组合」的组件，往往比「榜单更强但许可不明/延迟抖动」的组件更值得押——因为比赛按平均成功率与步骤分排名，一次服务抖动就抹掉一个创新点的全部收益。

### 两者统一：结构化泛化栈

场景理解回答「如何让策略对五轴结构性不变」，开源生态回答「用什么组件、什么数据、什么流水线把这件事做出来并稳定部署」。二者收敛为一个新框架：

$$
\underbrace{\text{官方真机 }D_{\rm real}}_{\text{基线}}
+\underbrace{\text{开源五轴数字孪生 }D_{\rm sim}}_{\text{I10}}
+\underbrace{\text{场景图 / 外源差分 }G_t,R_t}_{\text{I9}}
+\underbrace{\text{许可感知组件与蒸馏}}_{\text{I11}}
+\underbrace{\text{确定性低延迟服务}}_{\text{I6}} .
$$

**关键互补**：I9 的「结构化不变性」有一个致命循环依赖——场景估计器若也在标称数据上训练，会继承与策略相同的偏差。开源生态的**广预训练**（SAM2/GroundingDINO/DINOv2/π0.5/GR00T）正是打破循环的外部信息源；但仍需不确定度门控与 T0 回退（见 §6 风险）。

## 2. 研究问题（Q6–Q11，承 Q1–Q5）

- **Q6（最小充分场景图）**：$V^\star$ 需要多细？类别级 affordance + 6D 位姿 + 关系是否足以支撑 32 任务？能否只用共享骨干特征 + 轻量头，避免第二个大模型（PR2/D3）？
- **Q7（外源差分的可分离性）**：在五轴上，$R_t$ 能否把 HUMAN / STALL / SLIP 与 NOVEL（背景/外观/位置漂移）分开？分轴误报率上界如何标定？
- **Q8（不变性的可测性）**：同一任务状态换背景/干扰物，$\pi(a\mid\phi(o))$ 的动作散度能否显著低于原始像素策略？散度用什么度量（DTW / 动作分布 KL / 成功率）？
- **Q9（数字孪生的轴隔离）**：单轴生成能否保证「只动一根轴」？轴泄漏如何度量？sim-real gap 达到什么阈值时仿真数据开始负迁移？
- **Q10（固定 chunk 下的安全—吞吐权衡）**：$T_a$ 固定，接触族/人为干扰轴要求小 $T_a$，自由段要求大 $T_a$；全局单一 $T_a$ 的最优点如何由 32 任务权重与 180 s 预算推出？
- **Q11（组件资格与蒸馏）**：教师→学生在什么条件下保持 ≥95% 成功率且 p99 降 ≥2×？哪些组件因许可/延迟必须排除？

## 3. 设计原则（承 PR1–PR4，新增 PR5–PR7）

- **PR5 证据可分离律**：任何触发动作的信号，必须先证明它能与五轴 nuisance 分离（分轴误报率上界），否则只能作「建议」不能作「门控」；感知/观测器权重赛前冻结，评测时不做任何在线学习（诚信红线）。
- **PR6 传出副本归因律**：区分「自身动作造成」与「外源改写」必须用前向场景模型做残差归因；只检测「人」不够，要检测「无法解释的任务相关变化」；让位与恢复须满足 PR3 的「人已离开 + 场景重估 + 有时间」。
- **PR7 组件资格律**：进入计分路径的每个外部组件必须有已核实 license、哈希锁定的版本、p99 延迟测量与目标分布精度；非商用/许可不明权重不得进入提交物。

## 1. 创新点明细

### I9 场景图-外源差分感知底座（SOCS）★★★★★

- **动机**：五轴（位置/干扰物/背景/未见物品/人为干扰）都是**场景层**扰动（D4）；端到端像素策略把任务状态与 nuisance 纠缠，导致 $\mathrm{Err}_{\mathrm{inv}}$ 全局乘性；无触觉（D2）使接触/卡死/外力只能从代理信号推断。
- **与现有方案差异**：v1 把五轴拆成五个独立问题（I1 增广 + I4 手检测 + I3 伺服）；本点用**一个**「场景图 + 差分」表示统一：语言 grounding 得任务子图 $V^\star$，前向场景模型做传出副本，观测差分减预测差分得外源差分 $R_t$。同一信号驱动干预让位、卡死/滑移恢复、位置重定位、伺服触发。与 I1 是「结构 vs 统计」互补。
- **技术可行性**：高-中。开源件成熟（SAM2/GroundingDINO/立体深度/DINOv2/轻量跟踪）；头双目可做米制深度，腕相机做局部接触；`observation.language`（F9）提供任务 grounding。**三级集成，按风险递增**：
  - **T0（零重训，首选）**：场景图只用于事件检测、门控、伺服触发；VLA 仍吃原始像素。风险最低，可直接接入 I4/I5/I3。
  - **T1（轻适配）**：把场景图序列化进语言通道（对象/位姿/关系/人手），或渲染成 overlay 图作为额外视觉输入；用 LoRA 轻适配。需验证 VLM 是否真的利用该结构。
  - **T2（架构融合）**：object token 经 cross-attention adapter 进 action expert。收益可能最大，但改动大、风险高，暂缓。
- **所需资源**：1×A100 做离线感知管线与相机标定；1–2 人周/集成层；T0 的 perception p99 预算 ≤ 30 ms（可与 VLA 推理重叠）。
- **落地步骤**：①在 32 任务上分轴标定检测/分割/位姿/affordance 误差；②实现 $\Delta G/\Delta\hat G/R_t$ 与事件分类器（滞回 + 代价敏感阈值）；③T0 接入 I4/I5/I3；④离线不变性消融（同状态换背景/干扰物，测动作散度）；⑤T1 轻适配；⑥不确定度门控 + 回退原始像素策略。
- **风险**：估计器在未见物品/背景轴上退化（循环依赖，见 §6）；立体标定误差；分割边缘抖动导致差分误报。缓解：广预训练开源模型 + 类别级 affordance + 不确定度门控 + T0 回退 + 差分前先做跟踪平滑。

### I1 五轴泛化数据增广引擎（深化）★★★★

- **增量**：v1 的增广只看「视觉变、动作不变」，但没有度量**轴泄漏**——例如位置增广可能顺带改变了背景统计。本轮加两道门：①**单轴隔离**：每条增广样本只允许一个评测轴发生变化，其余轴用原场景；②**轴泄漏度量**：训练一个「轴分类器」从增广图像预测「被施加的轴」，若它能以高 AUC 预测**未被施加**的轴属性，说明泄漏，弃用该样本/调参。
- **与 I10 分工**：I1 负责「真机原始场景邻域内的统计增广」（保真度高、风险低）；I10 负责「原始场景之外的结构化合成」（覆盖广、需 gap 门禁）。
- **其余**（动机/资源/风险）沿用 v1 I1；风险仍是伪影破坏感知，缓解增加「轴泄漏门禁」。

### I2 弱任务诊断-加权课程共训（深化）★★★★

- **增量**：v1 按任务名/任务族聚类失败；本轮改为按 **I9 的失败机制**聚类——STALL（卡死）、SLIP（滑移/接触丢失）、NOVEL（外观/背景不识别）、EXTERNAL（被干预后未恢复）、REACH（够不到）。同一机制可跨任务迁移，加权更准，避免「按任务名过拟合」。
- **步骤增量**：①用 I9 事件日志给每个失败 episode 打机制标签；②机制 × 任务 的二维失败矩阵；③按机制稀有度与可修复性加权，而不是只按任务成功率；④强任务下限保护 + PCGrad 防梯度冲突（沿用 v1）。
- **风险**：机制分类器本身误标；缓解：人工抽检 + 高不确定度样本不参与加权。

### I3 接触族关键点视觉伺服回退（深化）★★★★

- **增量**：v1 用「阶段分类器或距离门控」触发伺服，容易模式抖动；本轮触发器改为 I9 的 CONTACT/SLIP 事件 + 任务子图的 affordance 锚点 $K^\star$（插孔/拉链头/杯口）。伺服只在 chunk 生成时接管**末端若干步**；由于 D1，chunk 内无法闭环，故接触阶段必须配小 $T_a$（见 I4/Q10）。
- **其余**沿用 v1 I3；单模型边界仍需组委会书面确认（PR2），确认前不上计分通道。

### I4 干预感知门控（修正）★★★★

- **修正点**：v1 的「刚被干预→短 chunk，稳定→长 chunk」被 D1 证伪（`action_chunk_size` 固定）。本轮改为：
  1. **检测**：不再用「手在画面」作门控，而用 I9 的**外源差分** $R_t$——只对「无法由自身动作解释的任务相关变化」反应（PR6）。手检测仅作特征先验。
  2. **反应**：固定小 $T_a$（建议离线在 2/4/8 中选，见 Q10）；在 chunk 的**尾部**填入减速/保持的安全动作（安全尾），降低「已下发但世界已变」的伤害。
  3. **恢复**：满足 PR3 的「人手离开 + 场景重估 + 有时间」才续做；恢复后进入短时保守模式。
- **可选增强**：若采用 $T_a=1$ + 异步 VLA（I6），则可获得 30 Hz 闭环反应，但延迟压力最大，需 p99 实测后再定。
- **风险**：外源差分误报导致冻结丢 180 s；缓解：滞回 + TTL + 每 episode 冻结时长上限 + 置信门控。

### I5 步骤分导向失败恢复（合并）★★★

- **变更**：卡滞检测（进度导数 < ε）并入 I9 的 STALL 事件（基于传出副本：指令有位移而场景无变化）；I5 保留**恢复原语库**（后撤-重接近-重抓、松开-重置-再抓）与「每 episode 恢复次数上限」。
- **价值**：超时=失败但步骤分仍计（F3），恢复是免费分；但恢复动作引入新分布，必须限制在训练支撑内。

### I6 确定性低延迟部署服务（深化）★★★★

- **增量**：①**异步推理**：若选 $T_a=1$，用后台线程跑 VLA（约 5–10 Hz），前台 30 Hz 返回「最新计划首步 + 快速伺服/保持」，解耦规划率与控制率；②**三速率预算**：感知 10–15 Hz、VLA 2–5 Hz（chunk 边界）、伺服 30–50 Hz（仅在 $T_a=1$ 时真正闭环）；③**降级模式**：perception p99 超预算时自动退回「原始像素 VLA + 固定 chunk」，保证不因感知拖垮整轮；④**状态隔离**：每端口独立队列 + episode 状态哈希，沿用 v1。
- **风险**：异步推理的时序竞态与陈旧计划；量化精度损失；缓解：版本化计划 + 时间戳丢弃过期计划 + 量化前后输出回归。

### 2.1 SOCS：场景图 + 传出副本 + 事件总线（I9）

```python
class SOCS:
    """Scene-graph Object-Centric Substrate. T0: perception only, VLA unchanged."""
    def __init__(self, detector, segmenter, depth, embedder, tracker, fwd_scene):
        self.det, self.seg, self.depth = detector, segmenter, depth
        self.embed, self.track, self.fwd = embedder, tracker, fwd_scene
        self.G_prev = SceneGraph.empty()
        self.hist = EventHistory()

    def update(self, obs, action_prev):
        # 1) language-grounded perception (budgeted, can run async)
        boxes = self.det(obs.images, prompt=obs.language)          # open-vocab
        masks = self.seg(obs.images, boxes)
        dmap  = self.depth(obs.images)                             # stereo metric
        nodes = backproject(masks, dmap, calib(obs))               # 3D object nodes
        nodes = [n.with_affordance(self.embed(n), obs.language) for n in nodes]
        nodes = self.track.associate(nodes, self.G_prev)           # stable ids
        G = SceneGraph(nodes, relations(nodes), agents=detect_agents(obs))
        V_star, R_star, K_star = ground(G, obs.language)           # task subgraph

        # 2) efference copy: predict what MY action should have changed
        G_hat = self.fwd(self.G_prev, action_prev, obs.language)
        d_obs = diff(self.G_prev, G)
        d_self = diff(self.G_prev, G_hat)
        R = residual(d_obs, d_self, task_nodes=V_star, tau_pose=TAU)

        # 3) event posterior + hysteresis (PR5/PR6)
        e = self.hist.classify(R, d_obs, V_star, R_star)
        self.G_prev = G
        return G, V_star, K_star, e
```

```python
def classify(R, d_obs, V_star, R_star, hist):
    if not touches(R, V_star):                      # nuisance only
        return NONE if not global_novel(d_obs) else NOVEL
    if has_agent(R, "human") or unexplained_pose_change(R, V_star):
        return HUMAN                                # external rewrite
    if is_stall(d_obs, hist):  return STALL         # command moved, scene didn't
    if is_slip(d_obs, hist):   return SLIP          # contact lost / object slipped
    if unreachable(d_obs):     return REACH
    return NONE
```

## 3. 形式化推导

**命题 1（不变性分解）**：设场景编码 $\phi$，任务状态等价关系 $\sim_s$，则

$$
\mathrm{Err}_{\mathrm{gen}}\le \mathrm{Err}_{\mathrm{est}}+\mathrm{Err}_{\mathrm{inv}}+\mathrm{Err}_{\mathrm{policy}},
\quad
\mathrm{Err}_{\mathrm{inv}}=\mathbb{E}_{o\sim_s o'}\big[D(\pi(\cdot|\phi(o)),\pi(\cdot|\phi(o')))\big].
$$

若 $\phi$ 对 nuisance 精确不变，则 $\mathrm{Err}_{\mathrm{inv}}=0$；I1 只能通过增大训练支撑间接压低它，I9 通过构造压低它。

**命题 2（外源差分的可识别性）**：若前向场景模型在自身动作上的预测误差为 $\epsilon_f$，任务节点位姿容差为 $\tau$，则外源事件可被识别当且仅当外源位移 $\delta_{\rm ext}>\tau+2\epsilon_f$（否则与自身预测误差不可分）。这给出**最小可检测干预幅度**，也说明 $\epsilon_f$ 必须在五轴上标定。

**命题 3（chunk 反应下界，D1）**：评测器执行完整 chunk 才再次观测，故任何依赖新观测的反应至少滞后 $(T_a-1)\Delta t$；且 $T_a$ 固定，不能按事件自适应。因此安全只能靠「赛前选小 $T_a$」或「chunk 内安全尾」实现，不能靠「中途抢占」。

**命题 4（资格门是硬约束）**：若某组件许可不满足提交要求，则其精度/延迟收益不可计入；故在 $Q$ 约束下最大化 $L(c)$，而非无约束最大化精度。

| E1 | 场景估计分轴标定：检测/分割/6D 位姿/affordance 误差 | 32 任务离线，每任务 200 eps，按五轴切片 | 任务物体 recall ≥95%（标称）/≥85%（未见+背景）；位姿误差 <1 cm/2°（标称）/<2 cm/4°（扰动） |
| E2 | 不变性消融：同任务状态换背景/干扰物，比较 SOCS 条件策略 vs 原始像素策略的动作散度 | 离线重放 | SOCS 的 nuisance 散度 / 真实状态散度 <0.2；否则 I9 只作软特征 |
| E3 | 外源差分事件检测：脚本化人手干预 + 自身动作 + 杂物注入 | 离线 + 单任务通道 | HUMAN/STALL/SLIP 的 AUC ≥0.9；误冻结率 <2%；检测延迟 <100 ms |
| E4 | 单轴生成与轴泄漏：每轴单独生成，测轴分类器 | 仿真 | 未施加轴的预测 AUC ≈0.5（无泄漏）；否则弃样 |
| E5 | sim-real gap 与迁移：6–8 任务，sim 预训练 + 少量真机微调 | 单任务通道 | gap AUC <0.7；真机相对纯真机基线 ≥+10 pp |
| E6 | 固定 $T_a$ 网格：$T_a\in\{1,2,4,8\}$，测成功率/步骤分/p99/干预恢复 | 单任务通道 + 本地压测 | 选使「成功率 + 步骤分」最大且 p99 达标的 $T_a$ |
| E7 | 组件资格与蒸馏：教师 vs 学生 | 离线 + 本地压测 | 成功率保持 ≥95%，p99 ↓≥2×；许可全部通过 |
| E8 | 提交前门禁（PR4）：run_client 全流程 + N 端口并发 + 动作健康度 | 本地 stub | 0 拒绝动作；p99 稳定；无异常动作统计 |

**核心指标**：32 任务平均成功率（主序）、平均步骤分（裁决）、分轴成功率、外源事件 AUC/误冻结率、动作散度比、sim-real gap AUC、p99 单步延迟、$T_a$ 选择后的干预恢复率。
