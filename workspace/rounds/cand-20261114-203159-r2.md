## 0. 直觉与动机

**灵感 1（阻抗控制 → 信任是一个连续的力学位姿）**
直觉：R69 的动作空间是 ξ=(a,g)，g 是一组离散信息动作。但人类的不确定不是「要不要伸手」，而是「伸手时有多硬」：扶老人时手很软，拧螺丝时手很硬，摸黑探路时手指略弯、力很小，让接触本身告诉自己前面是什么。阻抗控制把这件事写成
`F = M_d ẍ + D_d ẋ + K_d(x − x_d)`：控制的不是位置，而是「力与位移的关系」。于是「信任」有了一个连续旋钮 `K_d`——**高刚度 = 我信我的假设，去执行；低刚度 = 我不信，世界你来说。** 这把 R69 的离散 VoI 变成每毫秒可连续调节的物理量，也消除了「问 / 不问」之间的跳变。

**灵感 2（无源性 → 交互安全的模型无关证书）**
直觉：R69 用 C-RAS-WM 前缀认证来保证信息动作安全，但认证本身依赖世界模型预测正确——**用一个可能错的模型去保证另一个动作的安全**，这是自指。无源性的价值在于：只要机器人不向环境净注入能量（能量罐 `E_tank ≥ 0`），与环境 / 人接触的稳定性与能量安全就**与环境的真实动力学无关**。这给出一条与预测通道正交的安全通道：**预测通道管「会不会撞」，能量通道管「就算撞了，会不会把能量灌进人身上」。** R69 的交互安全从「模型说没事」升级为「物理保证不会失控」。

**灵感 3（具身智能 → 身体是第一个证据源，也是第一道滤波器）**
直觉：具身智能的核心不是「有个身体」，而是**智能部分地外包给形态与力学**：手被动顺应物体形状、腿被动缓冲落地、柔性腕把高频冲击滤掉。对本轮而言有两层含义：(a) **形态计算**——某些不确定性能被身体「免费」消解，软指在接触瞬间被动贴合，形状信息不需要策略去算；(b) **身体作为证据**——环境的阻抗（硬 / 软 / 固定 / 可动 / 活体）会直接写进力—位移曲线，这是视觉与语言都替代不了的物理通道。R69 的证据集 ℰ 全是「看 / 听 / 环一致」，缺的正是「摸起来是什么」。

**灵感 4（正面回应 R69 最大风险 → 用物理证伪幻影模态）**
直觉：R69 怕流模型幻觉出一个不存在的动作模态，然后去追问它。但每个模态其实都隐含一个**物理预言**：如果它是「抓住一个刚性杯子」，接触阻抗应该高；如果它是「推开一扇虚掩的门」，阻抗应该低且可动；如果它是「人」，阻抗应有主动性与时变。于是不必先相信流模型：**用一个低能量、可回撤的探测，让身体去测实际阻抗类，落在哪个模态的预言管内；落在所有预言管外的模态就被物理证伪。** 这是波普尔式的：证伪比证实便宜，且不要求你相信模型。R70 因此不再依赖「模态权重校准对了才敢问」，而是「问之前先用身体做一次可证伪的物理试验」。

**灵感 5（双刃剑升级 → 顺从是新的攻击面）**
直觉：让机器人变软，等于把控制权部分交给环境。对手可以「先软后硬」设陷阱、可以持续推挤抽干能量罐、可以用虚假顺从诱导机器人进入低刚度危险区，甚至可以伪造接触阻抗让幻影模态「通过」物理检验。**无源性只保证安全（能量不发散），不保证任务正确，也不保证不被骗。** 所以本轮必须同时交付：能量预算与有界回充、被动探测的幅值 / 功率 / 时长上限、物理干扰集 ℰ_phys，以及「物理证据也不得单独定案」的纪律——把 R69 的「k 个正交证据源」扩成「潜空间 + 身体」两类正交源。

# IP-264 VIC：方向分辨的变阻抗执行器（外环给阻抗，内环 1kHz）
class VariableImpedanceController:
    def __init__(self, k_safe, k0, D0, gamma, beta, dt=1e-3):
        self.k_safe, self.k0, self.D0 = k_safe, k0, D0

    def compose(self, P_amb, P_safe, U_ale, U_epi):
        k_amb = self.k0 / (1.0 + self.beta * U_epi)
        Kd = self.k_safe * P_safe + k_amb * P_amb + self.k_ale * np.eye(d)
        Dd = self.D0 + self.gamma * U_ale          # 噪声走阻尼，不走刚度
        return Kd, Dd

    def step(self, x, xd, Kd, Dd):
        return M @ ddx + Dd @ dx + Kd @ (x - xd)   # 内环 1kHz

# IP-265 EIM/DAP：从模态原型构造歧义子空间（方向，而非标量）
def ambiguity_projector(modes, r_max=3, energy=0.9):
    deltas = [modes[i].xi_bar - modes[j].xi_bar
              for i in range(len(modes)) for j in range(i+1, len(modes))]
    _, S, Vt = svd(np.stack(deltas))
    r = min(r_max, 1 + np.searchsorted(np.cumsum(S**2)/np.sum(S**2), energy))
    return Vt[:r].T @ Vt[:r]                        # P_amb

# IP-267 BPE：无源接触阻抗探测（能量受限、可回撤）
def contact_probe(vic, env, k_hat, pet):
    K_probe = np.clip(3.0 * k_hat, K_min, K_max)    # 引理 19：信息/能量最优
    ys = []
    for _ in range(T_probe):
        tau, Kd, Dd = vic.step(..., K_probe)
        f, v = env.sense()
        if not pet.allow(f, v):                     # 能量罐将透支 → 立即回撤
            vic.retreat(); break
        ys.append((f, v))
    return rls_impedance_fit(ys), pet.energy_used()

# IP-268 PFE：物理证伪（不是给模态重新加权，而是把它们杀掉）
def falsify(modes, Z_hat):
    kept = [m for m in modes
            if mahalanobis(Z_hat, signature(m)) <= TAU_FALSIFY]
    return kept                                    # 空集 => unresolved → 退 R69

    if U_epi > TAU_EPI and M.pet.can_probe() and not slow:

## 3. 推导

**引理 19（探测的信息—能量最优）** 一维串联接触：环境刚度 k_e、命令刚度 K_d、参考位移 Δ，稳态力 `F = K_d k_e Δ/(K_d + k_e)`。力测量方差 σ_F² 时，关于 k_e 的 Fisher 信息为
`I(K_d) = (∂F/∂k_e)²/σ_F² = K_d⁴ Δ²/[(K_d + k_e)⁴ σ_F²]`。
取弹簧能量代价 `W ≈ ½ K_d Δ²`，则信息 / 能量密度 `I/W ∝ K_d³/(K_d + k_e)⁴`，对 K_d 求导得唯一驻点 `K_d* = 3 k_e`。要点：**信息随刚度单调增加，但每焦耳信息在 K_d ≈ 3k_e 处最好**；因此合规不是「为了安全牺牲信息」，而是**在能量预算下信息效率最高的策略**。系：探测刚度应跟踪 `k̂_e`，与环境同量级；一味变硬既浪费能量又危险，一味变软则没有信号。

**引理 20（无源性 ⇒ 模型无关交互安全）** 设机器人端口无源、能量罐 E_tank ≥ 0、PC 有效。对任意无源环境（含人），耦合系统的存储能量有界：`E_sys(t) ≤ E_sys(0) + E_tank(0) + 有界回充`；净注入环境的能量 ≤ E_tank(0)。故交互不能在 WM 预测错误时向环境 / 人注入无界能量。系：R69 的模型依赖认证与 VIBE 的能量无关证书是**两条独立安全通道**，一条失效不蕴含另一条失效。

**引理 21（物理证伪的幻影拒绝）** 若幻影模态的预言签名与真实环境类的距离超过 τ_falsify 裕度 δ，则 N 次独立探测后误接受概率 ≤ `exp(−N δ²/(2σ²))`（Hoeffding）。真模态被误杀的概率由 τ_falsify 控制，可独立设定。要点：**证伪不需要校准模态权重**，只需要测量噪声有界；这把 R69 的「先校准、再交互」换成「先证伪、再交互」，降低了信任前提。

**引理 22（刚度调度的连续性）** `k_amb(U_epi) = k_0/(1 + β U_epi)` 对 U_epi 是 Lipschitz 的；配合零阶保持与速率限幅 `|dK_d/dt| ≤ K_rate` 及 PC，闭环力矩连续、无冲量注入。系：模式切换通过刚度平滑插值完成，继承 R68「无突变」结论。

**定理 18（VIBE 严格包含 R69）** 在 A99–A101 下，VIBE 在任意状态的期望风险 ≤ R69；当 `𝒰_amb = ∅`、或 `K_d = K_safe` 且 `E-VoI ≤ 0`、或 `E_tank = 0` 时，两者**逐指令相同**。R69 = 「刚体 + 无身体探测 + 次数预算」边界；安全侧不让步，信息侧获得「顺从」这一连续通道。

**定理 19（变阻抗交互安全与无突变）** 无源能量界（引理 20）+ C-RAS-WM 模型认证 + 连续刚度调度（引理 22）⇒ 所有 VIBE 交互的能量注入有界、接触力有界；探测失败 / 能量耗尽 / 证伪失败时单调退化为 R69 刚体保守；提交 / 换装不变式（R68 定理 15）保持 ⇒ 控制连续、无突变。

**定理 20（顺从攻击面的安全上界）** 在含能量虹吸与先软后硬陷阱的对抗环境下，无源性仍把总能量转移限制在 E_tank(0)（**安全性**），而信息正确性受具身证据纪律约束（R69 引理 18 的扩展）：单一物理通道不能给模态定案，故最坏情况是「**安全但判断错**」，不是「不安全」。这划清了 VIBE 的诚实边界：它买到的是安全，不是全知。

## 6. 本轮最大风险

**一句话**：VIBE-RAS 把信任交给刚度、把安全交给无源性，看似把「模型不可信」转嫁给了物理；但**无源性只保证能量不发散，不保证任务正确，也不保证在采样、时延、摩擦、齿隙下仍然成立**——一个被诱导进入低刚度状态的机器人可能「既安全又无用」，甚至在对手「先软后硬」的陷阱里被夺走控制权；而探测最优刚度依赖对 k_e 的估计，估计错了，物理证伪就会杀掉真模态、放过假模态，把 R69 的「问错」升级为「**摸错**」。

**次级风险与缓解**：
1. **离散化 / 时延破坏无源性** → 无源保持离散化 + 时延补偿 + 保守能量裕度（定义 325、E315）；
2. **能量虹吸 / 先软后硬陷阱** → 能量罐 + 功率上限 + PC 强阻尼 + ℰ_phys 对抗训练（定义 313、320）；
3. **物理证据伪造 / 单源采纳** → 身体 + 潜空间双证据纪律 + 引理 18/21（定义 310-iii、E308）；
4. **探测刚度误估导致误证伪** → 两步主动辨识 + 保守 τ_falsify + 证伪失败即 unresolved 退 R69（定义 316–317）；
5. **合规导致的性能/权威损失** → 方向分辨软化（安全方向不软）+ 严格包含 R69 的退化边界（定义 312、323、定理 18）。

## 4. 推导

**引理 19（探测的信息—能量最优）** 串联接触稳态力 `F=K_d k_e Δ/(K_d+k_e)`，关于 k_e 的 Fisher 信息 `I(K_d)=K_d⁴Δ²/[(K_d+k_e)⁴σ_F²]`；弹簧能量代价 `W≈½K_dΔ²` 下 `I/W∝K_d³/(K_d+k_e)⁴`，唯一驻点 `K_d*=3k_e`。⇒ 合规不是「为安全牺牲信息」，而是能量预算下信息效率最高；探测刚度应跟踪 k̂_e，与环境同量级。

**引理 20（无源性 ⇒ 模型无关交互安全）** E_tank≥0 且 PC 有效时，对任意无源环境，系统存储能量有界、净注入环境的能量 ≤ E_tank(0)；即使 WM 预测错误也不会向人注入无界能量。R69 的模型认证与本轮的能量证书是两条独立安全通道。

**引理 21（物理证伪的幻影拒绝）** 幻影签名距真实类超过 τ_falsify 裕度 δ 时，N 次独立探测的误接受概率 ≤ `exp(−Nδ²/(2σ²))`；真模态误杀率由 τ_falsify 独立控制。证伪不需要校准模态权重。

**引理 22（刚度调度连续性）** `k_amb(U_epi)` Lipschitz；配合零阶保持、速率限幅与 PC，力矩连续、无冲量注入；模式切换用刚度平滑插值。

**定理 18（VIBE 严格包含 R69）** A99–A101 下 VIBE 期望风险 ≤ R69；当 `𝒰_amb=∅`、或 `K_d=K_safe` 且 `E-VoI≤0`、或 `E_tank=0` 时逐指令相同。R69 = 「刚体 + 无身体探测 + 次数预算」边界。

**定理 19（变阻抗交互安全与无突变）** 无源能量界 + 模型认证 + 连续刚度调度 ⇒ 能量注入与接触力有界；探测失败 / 能量耗尽 / 证伪失败时单调退 R69 刚体保守；换装不变式保持 ⇒ 控制连续、无突变。

**定理 20（顺从攻击面的安全上界）** 对抗环境（能量虹吸、先软后硬）下无源性仍把总能量转移限制在 E_tank(0)（安全），信息正确性受双证据纪律约束；最坏情况是「安全但判断错」，不是「不安全」。

## 7. 本轮最大风险

**一句话**：VIBE-RAS 把信任交给刚度、把安全交给无源性，但**无源性只保证能量不发散，不保证任务正确，也不保证在采样、时延、摩擦、齿隙下仍成立**——被诱导进入低刚度的机器人可能「既安全又无用」，甚至被「先软后硬」夺走控制权；而探测最优刚度依赖 k_e 估计，估错就会杀掉真模态、放过假模态，把 R69 的「问错」升级为「**摸错**」。

**次级风险与缓解**：离散化/时延破坏无源性（无源保持离散化 + 时延补偿 + 保守裕度）；能量虹吸/先软后硬（能量罐 + 功率上限 + PC + ℰ_phys 对抗训练）；物理证据伪造/单源采纳（身体 + 潜空间双证据 + 引理 18/21）；探测刚度误估导致误证伪（两步辨识 + 保守 τ_falsify + unresolved 退 R69）；合规导致性能/权威损失（方向分辨软化 + 严格包含 R69 的退化边界）。
