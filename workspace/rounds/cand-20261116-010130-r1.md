# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「力矩控制」×「伦理与合规」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**把安全从"对未来的预测"下沉到"对当下的力/能量约束"，把合规从"事后叙事"升级为"可运行、可审计、可否决的约束层"**。两个灵感分别治理 v9 的两处软肋：**模型债**（块证书在域偏移时最不可靠，恰是最需要安全的时刻）、**合规债**（v9 的 14+ 个 IP 只有自家日志与论文叙事，行为承诺无第三方可验证证据，退化链本质是"信任我们"而非"证明我们"）。所有新模块沿用 v9 的中立元纪律，但把"中立元"重解释为权限格顶元，从而允许规范模块 fail-closed。

## 0. 直觉与动机

**灵感 1（力矩控制 → 模型无关的安全包络）**
直觉：v9 的块证书把安全押在前向模型 F̂ 的预测精度上，而 DA-ML 检测到域偏移之时正是 F̂ 误差最大之时（v9 风险原文）。力矩控制提供另一条路——**安全不必预测未来，只需约束当下的关节力矩、接触力与能量流**。核心创新：**力矩安全调速器（Torque Safety Governor, TSG）**：1kHz 力矩限幅 + 动量观测器接触力限幅（ISO/TS 15066 生物力学界）+ 能量槽无源性，三者都只依赖实测状态 q,q̇，不依赖 F̂。
更关键的细节：**力矩中性元不是 τ=0（去激励会因重力坠落），而是"重力补偿 + 关节阻尼"的柔顺保持 τ^⊥ = g(q) − Dq̇**。它让机器人成为可被动反驱的柔顺体——于是"人的否决权"从软件事件下沉为力学性质：**当同意/否决/合规软件全部失效时，人类仍可用手把机器人推开**。这是本轮最物理、也最不容易被代码 bug 剥夺的安全网。

**灵感 2（伦理与合规 → 可运行、可审计、可否决的约束层）**
直觉：合规不是一份文档，而是运行时不变量。把它拆成三件可工程化的事：
(a) **规范→原则→契约→证据的可追溯图（Obligation Graph & Traceability, OGT）**：让每条高优先级规范（如 ISO/TS 15066 §5.5.4 力/功率限制、EU AI Act Art.14 人类监督、GDPR Art.6/7 同意与 Art.17 删除）都有从法条到运行日志的完整证据路径，并显式度量"合规债"。
(b) **防篡改合规账本（Compliance Ledger, CL）**：哈希链 + 周期 Merkle 根外锚；退化、证书失效、同意/撤销、否决、接触、解释事件全部可第三方审计，且**PII 最小化**——链上只存承诺哈希，离线加密存原文，删除权用 crypto-shredding 与不可篡改性取得和解。
(c) **同意与否决管理器（Consent & Contest Manager, CCM）**：带作用域、时限、可撤销的同意令牌；语音/物理（力矩观测）/按钮/第三方四通道否决，任一通道在 L_veto 内强制降级并留痕；每次降级自动生成"解释三元组"（规范号、触发事件哈希、证据引用），对应解释权。

**灵感 3（两灵感的合流 → 单调退化格）**
直觉：v9 把退化链写成线性五级，且默认"中立元 = 恒等 = 安全"。但伦理约束里"关闭模块"绝不能等于"解除禁令"——物理模块可以 fail-neutral，规范模块必须 fail-closed。合流点极其干净：**v9 的中立元 v^⊥ 正是权限格的顶元 ⊤**（聚合恒等律 x⊓⊤=x 即是格恒等律）。于是 fail-closed 只是允许 v^⊥ 取 ⊤ 以下的元素，退化 = 与 v^⊥ 取交（meet），天然单调、可交换、与失效顺序无关。核心创新：**单调合规引擎（Monotone Compliance Engine, MCE）**。
深层张力也在此暴露：**禁止类约束向下封闭**（越降级越不违反），**积极义务向上封闭**（越降级越可能违反"必须行动"，如照护机器人不能对着摔倒的老人停机）。这一非对称无法用单一格运算表达，必须拆成"自动向下 fail-closed（禁令）+ 显式授权向上尽责（义务）"两条通道，并允许规范不可行时显式升级而非静默停机。

## 1. 研究问题（轮次升级版）

- **Q1（模型无关安全）**：力矩调速器能否在不依赖前向模型的前提下，给出与 v9 块证书同等级乃至更强的物理安全保证？当 v9 块证书因域偏移失效时，TSG 的接触力/无源性界是否仍成立？"柔顺保持"型中性元 τ^⊥=g−Dq̇ 是否足够既防坠落又可被动反驱？
- **Q2（合规可证与可撤销）**：如何把"规范→原则→契约→证据"做成可机检的追溯图，使每条高优先级规范都有运行时可验证的证据路径？哈希链账本在 8h 任务、~100 事件/s 下的开销与存储是否可接受？不可篡改性与 PII 删除权如何在密码学上兼容？
- **Q3（退化格与义务张力）**：以权限格交集统一 fail-neutral/fail-closed 退化，能否在保持 v9 逐位等价（全 top 时，引理 83）的同时，保证任意失效序列下硬禁令不被违反？当"向下安全"与"向上尽责"冲突（N_adm=∅）时，如何不静默停机而是显式升级？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 力矩包络律（Torque Envelope, TSG）**
安全的最低层不预测未来，只约束当下：|τ_i| ≤ τ_i^max、‖J^{-T}τ‖ ≤ F_limit（ISO/TS 15066 按身体部位与准静态/瞬态取值）、能量槽 T ≥ 0；任一将越界则按最小因子 s∈[0,1] 缩放 τ ← sτ，无法缩放时切到柔顺保持 τ^⊥=g(q)−Dq̇。前馈可用块力矩证书 Ĉ^τ 做 5Hz 候选筛选，但**运行时最终保证由 1kHz 调速器独立完成**；力矩中性元非 τ=0。

**P14 可追溯合规律（Traceable Compliance, OGT/CL/CCM）**
每个高优先级规范在 G_C 中必须有 N→P→K→E 的完整路径（覆盖率 cov，合规债 debt=1−cov）；运行时每次降级、证书失效、同意/撤销、否决、接触、解释都写入哈希链账本并周期锚定；同意令牌带作用域/时限/可撤销；四通道否决在 L_veto 内强制降级并生成解释三元组；账本只存承诺、离线存 PII，删除权用 crypto-shredding 实现。

**P15 单调退化律（Monotone Degradation, MCE）**
每模块失效值 v_m^⊥ ∈ 权限格 L，系统配置 M = ⊓_m v_m^⊥；物理模块 v^⊥ = ⊤（退回 v9 恒等，逐位等价），规范模块 v^⊥ ⊏ ⊤（fail-closed，且规范降级闩锁、需证据+授权解闩）；禁止类约束向下封闭故恒被保持；积极义务走独立"授权向上"升级通道，不得被向下退化静默吞掉，规范不可行（N_adm=∅）必须显式升级。

## 3. 与基线的接口（如何退化）

- **TSG 失效**（观测器/限幅计算异常）⇒ τ^⊥=g(q)−Dq̇ 柔顺保持；仍 fail-closed 于力/能量，物理可反驱，不退回 v9 的纯位置控制；
- **CL 失效** ⇒ 退回 v9 普通日志：可观测行为等价 v9，但审计能力降级为"信任模式"，必须显式告警并将 cov 视为 0；
- **OGT 失效** ⇒ 义务监控冻结在最近一次已验证规范集；未知规范默认按最保守解释（fail-closed）；
- **CCM 失效** ⇒ 否决通道退化为硬件急停（最保守），同意默认按最小作用域，deny-by-default；
- **MCE 失效** ⇒ 退回 v9 线性五级链：物理部分（v^⊥=⊤）逐位等价 v9（引理 88 特例），规范部分由硬件急停兜底；
- **全部失效** ⇒ 硬件急停 + 账本最后一次锚定根；完整退回 MetricVoiceGauge-OTL-GC-ER v7，再退回 v6 物理安全底线。

## 4. 预期贡献

1. **模型无关的力矩安全包络**：以当下可测的力矩/接触力/能量替代对未来指标的预测，直接消解 v9"最需要安全时证书最不可靠"的结构性风险；
2. **可运行、可审计、可否决的合规层**：追溯图 + 防篡改账本 + 四通道否决 + 解释权，把合规从叙事变成可第三方验证的证据；
3. **单调退化格**：把 v9 中立元重解释为权限格顶元，统一 fail-neutral 与 fail-closed，并显式刻画"禁止向下封闭 / 义务向上封闭"的非对称；
4. **物理层面的可反驱否决**：把"人的最终否决权"从软件事件下沉为力学性质（柔顺保持 + 无源性）；
5. **E571–E590** 覆盖力矩包络、无源性、物理否决、模型无关安全、退化格等价、fail-closed、规范不可行、尽责张力、账本篡改、追溯覆盖、PII 删除与端到端合规。

## 5. 本轮最大风险

**一句话**：把"安全"定义为单调向下退化，会系统性地偏向"不作为"——禁止类规范在停机时全部满足，积极照护义务却恰在停机时被违反；一旦"必须行动"只能靠一条绕开单调性的授权升级通道兜底，合规的正确性就从代数性质退化为对"谁有权授权、授权是否被滥用"的社会信任，而后者恰恰无法用本框架证明。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-TEC**（Metric Voice Gauge with Torque Envelope & Traceable Compliance）

> 背景：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮灵感：「力矩控制」×「伦理与合规」
> **继承纪律**：MetricVoiceGauge 九不变式（CVC-闭环、SpatialCert、RT-CVC、FaultCert、PrimitiveGraph、严格退化链、OTL、GCT、ER）与 v9 的 AC/MW/ID 三模块原样继承。新组件一律为**可选增强**：物理部分失效 ⇒ 注入中立元并严格等价退回 v9（引理 88）；规范部分失效 ⇒ **fail-closed 下降**（不得等价于"解除约束"）。二者由同一个权限格 meet 统一，避免"物理可 fail-neutral、规范必须 fail-closed"被硬编码成两套不可组合的退化逻辑。

**定义 540（力矩安全包络 Torque Safety Envelope, TSE）** 给定 τ∈R^n、雅可比 J、能量槽 T、步长 Δt，包络
```
E = { τ : |τ_i| ≤ τ_i^max ∀i,  ‖J^{-T}τ‖ ≤ F_limit,  T − (τᵀq̇)⁺·Δt ≥ 0 }
```
调速器输出 τ* = s·τ，s = min(1, min_i τ_i^max/|τ_i|, F_limit/‖J^{-T}τ‖, T/((τᵀq̇)⁺Δt))；更新能量槽 T ← T − (τ*ᵀq̇)Δt（吸收能量时回充至 T_max）。F_limit 按 ISO/TS 15066 身体部位表与准静态/瞬态类型取值。

**定义 541（力矩证书 Torque Certificate）** Ĉ^τ_t=(τ̂_peak,F̂_c_peak,T̂_min)，由标称块轨迹前向估计并留余量 β_τ；仅用于 5Hz 候选筛选（与 v9 块证书 Ĉ_t 联合作联合可行性），**运行时最终保证由 TSG 独立给出**。证书有效 ⇔ 三项均在 540 界内。

**定义 542（力矩中性元 Torque Neutral Element）** τ^⊥ = g(q) − Dq̇，D≻0。性质：(a) 静态保持位置（抵消重力）；(b) 对任意人类外力可被动加减速，机器人不主动净注入能量；(c) 不断电、不自由坠落。区别于 τ=0（去激励）。这是"物理否决权"的力学基础。

**定义 543（权限格 Permission Lattice）** A 为原子动作集，配置 X 的许可集 P_X⊆A；定义 X⊑Y ⇔ P_X⊆P_Y（X 不多于 Y 的许可）。⊤=A（全许可）、⊥=∅（停机）；⊓ 为集合交，给出最保守的公共许可。于是 (L,⊑,⊓) 为交半格，且 x⊓⊤=x（⊤ 是聚合恒等元——这正是 v9 中立元的格解释）。

**定义 544（单调退化 Monotone Degradation, MCE）** 每模块 m 失效值 v_m^⊥∈L；退化映射 d_m(X)=X⊓v_m^⊥；系统配置
```
M(t) = ⊓_m (⊤ ⊓ v_m^⊥) = ⊓_m v_m^⊥
```
物理模块 v^⊥=⊤ ⇒ d_m(X)=X（v9 恒等，引理 83）；规范模块 v^⊥⊏⊤ ⇒ 严格下降（fail-closed）。meet 可交换/可结合/幂等 ⇒ 失效顺序不影响最终配置。规范降级默认闩锁（定义 551）。

**定义 545（规范可行集与不可行升级）** 规范集 O 的可行集 N_adm={X∈L : X⊨O}。禁止类 o=¬φ **向下封闭**（X⊨¬φ ∧ Y⊑X ⇒ Y⊨¬φ）；义务类 o=□ψ **向上封闭**（Y⊒X 可能使 Y⊨□ψ；X⊨□ψ 不保证 Y⊑X 仍满足）。若 N_adm=∅ ⇒ 触发**规范不可行事件**，禁止静默停机，须在有限时延内请求授权（定义 551）或升级到人类监督者。

**定义 546（义务与情态）** o=(id,μ,φ,scope,priority,evidence)，μ∈{P(禁止),O(义务),F(许可)}。运行期 monitor 对 claim 流求值 φ：P 违反 ⇒ 立即 meet 降级；O 未满足 ⇒ 进入升级通道（不得用 meet 吞掉）。

**定义 547（可追溯图与覆盖率）** G_C=(N,Π,K,E) 四层：规范 Norm → 原则 Principle（P10–P15）→ 契约 Contract（κ_m）→ 证据 Evidence（测试 E5xx / 运行账本切片）。路径完整 ⇔ 四层逐层有边且证据时间戳有效。覆盖率 cov = 高优先级规范中路径完整者比例；合规债 debt=1−cov。运行期每个降级事件必须能回填一条 G_C 路径，否则记为"未映射降级"（审计缺陷，debt 增计）。

**定义 548（同意令牌与四通道否决）** σ=(scope,subject,[t0,t1],revocable,provenance)。动作 a 放行 ⇔ scope(a)⊆σ.scope ∧ t∈[t0,t1] ∧ ¬revoked。否决 c=(channel,subject,t,reason)，channel∈{voice, physical(由定义 541 观测残差 r 触发), button, third_party}。任一 c ⇒ 在 L_veto 内 meet 到排除被否决动作的配置，并写账本 + 生成 xp。物理否决的正确性由定义 542 的被动性保证（人可推离）。

**定义 549（合规账本与锚定）** 事件 e_t=(type, ts, subj_pseudo, commitment=H(payload), norm_id, prev=H_{t-1})，H_t=H(H_{t-1}‖canon(e_t))。每 K 个事件求 Merkle 根 R_k，由操作员签名并外锚（透明日志/可信时间戳）。**PII 最小化**：payload 离线加密存储，链上只留承诺；满足删除权 = 销毁离线数据及密钥（crypto-shredding），承诺仍在但不可关联，故"不可篡改"与"可删除"在密码学上相容。

**定义 550（解释三元组与解释权）** 每次降级/否决/证书失效生成 xp=(norm_id, trigger_event_hash, evidence_ref)，经自然语言模板渲染为"因为 [规范] 在 [触发] 时被 [证据] 判定为 [违反/不确定]，系统退到 [配置]"。解释的输入全部来自契约表与账本，不含自由生成内容。

**定义 551（退化闩锁与升级令牌）** 规范类降级默认**闩锁**：恢复需 (a) 证据复核 + (b) 授权令牌 auth=(subject,role,scope,t,sig)。物理类降级可自动恢复。升级令牌用于"向上尽责"通道：当义务未满足或 N_adm=∅ 需临时越权（如进入私人空间救人），auth 记录越权范围与时限并入账；无 auth 则不得向上，只可请求人类介入。

# ---------- IP-357 TorqueSafetyGovernor（1kHz，模型无关） ----------
class EnergyTank:
    def __init__(self, T0, T_max):
        self.T, self.T_max = T0, T_max
    def update(self, tau, qd, dt):
        P = float(tau @ qd)
        if P > 0:                      # 机器人对外做功 -> 扣储能
            self.T = max(0.0, self.T - P * dt)
        else:                          # 吸收能量 -> 回充（有上限）
            self.T = min(self.T_max, self.T - P * dt)
        return self.T

class MomentumObserver:                # 外部力矩残差 r ≈ τ_ext
    def __init__(self, K_O, M_fn, C_fn, g_fn):
        self.K_O, self.M, self.C, self.g = K_O, M_fn, C_fn, g_fn
        self.p_prev, self.r = None, 0.0
    def step(self, q, qd, tau, dt):
        p = self.M(q) @ qd
        if self.p_prev is None: self.p_prev = p
        integrand = tau + self.C(q, qd).T @ qd - self.g(q) + self.r
        self.r = self.K_O * (p - self.p_prev - integrand * dt)
        self.p_prev = p
        return self.r
    def contact_force(self, J, q):
        return np.linalg.pinv(J(q).T) @ self.r

class TorqueSafetyGovernor:
    def __init__(self, tau_max, F_limit, tank, D, dt=1e-3):
        self.tau_max, self.F_limit = tau_max, F_limit
        self.tank, self.D, self.dt = tank, D, dt
    def neutralize(self, q, qd, g):            # 定义 542
        return g(q) - self.D @ qd
    def govern(self, tau_des, q, qd, J, g):
        F = np.linalg.pinv(J(q).T) @ tau_des
        P = float(tau_des @ qd)
        s = 1.0
        s = min(s, float(np.min(self.tau_max /
                                np.maximum(np.abs(tau_des), 1e-9))))
        s = min(s, self.F_limit / max(float(np.linalg.norm(F)), 1e-9))
        if P > 0:
            s = min(s, self.tank.T / max(P * self.dt, 1e-12))
        tau = s * tau_des
        if (not np.isfinite(tau).all()) or s <= 0.0:
            tau = self.neutralize(q, qd, g)     # 定义 542 柔顺保持
        self.tank.update(tau, qd, self.dt)
        return tau, s

    def le(self, other):  return self.enabled <= other.enabled   # self ⊑ other
    def meet(self, other):
        return Mode(f"{self.name}⊓{other.name}", self.enabled & other.enabled)

class MonotoneComplianceEngine:
    def __init__(self, norms):

    def set_health(self, m, ok, fail_value):
        if ok and m in self.latched:            # 闩锁：不得自动恢复（定义 551）
            return
        self.ceil[m] = TOP if ok else fail_value

## 4. 推导

**引理 87（模型无关力矩安全）** 假设 (A1) q,q̇ 测量误差有界、(A2) J、M、g 与接触部位标定在信任集内。则 TSG 对任意前向模型误差（包括 F̂ 完全失效）仍保证：∀t，|τ_i(t)| ≤ τ_i^max、‖F_c(t)‖ ≤ F_limit、T(t) ≥ 0。证明：s 取各约束所需缩放因子的最小值，逐项由构造满足定义 540；s≤0 或非有限时切到 τ^⊥=g−Dq̇，其力矩幅值由 g 的标定上界与 D 决定，仍可另设保守界；全程不查询 F̂，故结论与前向模型误差无关。∎（注：F_c 的精度依赖 (A2) 的雅可比/接触部位标定，属可测性假设而非模型预测假设。）

**引理 88（单调退化与 v9 逐位等价）** 在权限格 (L,⊑,⊓) 上，d_m(X)=X⊓v_m^⊥ 且 v_m^⊥⊑⊤。(i) 若所有 v^⊥=⊤，则 M(t)=X（x⊓⊤=x），与 v9 引理 83 的"注入恒等元后逐位一致"相同；(ii) 任一失效使对应 v^⊥ 由 ⊤ 降为 ⊑⊤，M 单调不增（⊑），且因 meet 可交换/可结合/幂等，最终配置与失效发生顺序无关；(iii) 物理模块取 v^⊥=⊤，规范模块取 v^⊥⊏⊤，可在同一 M 中混合而无需两套退化逻辑。∎

**引理 89（fail-closed 与义务非对称）** (i) 硬禁令是向下封闭谓词：若 X⊨¬φ 且 Y⊑X，则 Y⊨¬φ。故任意 meet 序列（fail-closed 降级）不会违反任何硬禁令。(ii) 义务是向上封闭谓词：存在 X⊨□ψ、Y⊑X 而 Y⊭□ψ，故 meet 可能破坏义务。因此义务**不得**交给 meet 处理；MCE 在检测到义务未满足时走显式升级通道，无授权则抛规范不可行事件而非静默停机。(iii) 当所有规范为禁止类时，MCE 退化为纯 fail-closed meet，安全由 (i) 直接给出。∎

**引理 90（账本防篡改与删除权相容）** 在 H 抗碰撞假设下：(i) 修改/删除/重排任一事件将破坏其后所有 H_t 的链式校验，或被 Merkle 根不匹配检出；(ii) 对索引 t 的 Merkle 包含证明可被第三方在仅持根 R_k 时验证；(iii) crypto-shredding 销毁离线密钥后，payload 不可恢复，但 commitment 仍可验证"曾存在某事件"，故不可篡改性与 PII 删除权相容（承诺不可逆，且 subject 仅以伪名出现）。∎

**引理 91（追溯覆盖与否决时延）** (i) 若高优先级规范 cov=1 且 G_C 边语义正确，则任意运行期降级都能回填一条 N→P→K→E 路径，审计可判定其规范依据；未映射降级计为 debt，故"未证明合规"不会被静默当作"合规"。(ii) 否决时延 ≤ L_veto = t_detect + t_decide + t_torque，其中 t_detect ≤ 2ms（动量观测器）、t_decide ≤ 20ms（一个 50Hz 决策周期）、t_torque ≤ 1ms（1kHz 环），故 L_veto ≤ 23ms < 100ms 预算；物理通道再叠加上定义 542 的即时被动性。∎

**命题 92（物理否决的充分条件）** 若执行器透明（低摩擦、可反驱）且 TSG 保证非主动性（T≥0），则人类外力可在有限能量内改变机器人运动方向/使其停驻。证明由无源性：机器人不净注入能量，外力做功可单调耗散机器人动能；透明性保证力可传到关节。∎（透明性依赖硬件，列为假设而非结论。）

## 8. 本轮最大风险

**一句话**：把"安全"定义为单调向下退化，会系统性地偏向"不作为"——禁止类规范在停机时全部满足，积极照护义务却恰在停机时被违反；一旦"必须行动"只能靠一条绕开单调性的授权升级通道兜底，合规的正确性就从代数性质退化为对"谁有权授权、授权是否被滥用"的社会信任，而后者恰恰无法用本框架证明。
