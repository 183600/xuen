# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「群体智能」×「用户体验」）

> R69 把不确定性拆成 aleatoric / epistemic，用「流匹配多模态策略 + 主动多模态交互」去消解后者，并把「k 个正交证据源一致」写成证据纪律。但它隐瞒了一个结构性事实：**系统是单体的**。所谓「正交证据」只能来自同一次感知的不同分量——共享传感器、共享训练数据、共享世界模型，天然相关。于是 R69 最想防的「幻影模态」，恰恰是它最防不住的东西：一个模型幻觉出的模态，在系统内部找不到任何真正独立的第二意见。
>
> 本轮两个灵感正好补上「第二个声音」与「什么时候值得去听人」：
> - **群体智能**给出的不是「堆算力」，而是**独立性 + 多样性 + 法定人数**：N 个异构成员的共识，只要错误相互独立，幻影被多数否决的概率随人数指数下降；它同时把 R69 那句空洞的「k 源一致」兑现为可度量、可审计的**群体法定人数**；
> - **用户体验**给出的不是「界面好看」，而是**注意力的经济学**：人不是传感器，人是最贵、最该被节省的证据源。N 个成员各问一次是 N 倍打扰；正确做法是群体先在内部免费互证，**只在法定人数失败时才花一次人类注意力**，且这一次必须聚合、低认知负荷、可解释、可否决。
>
> 核心命题：**把单体的「问」升级为两级证据经济——(1) 群体共识在内部过滤幻影、兑现正交证据纪律；(2) 群体会诊失败时才触发一次「共享注意力预算」下的人类询问；(3) 呈现层必须做「适度依赖」校准，让人信任系统的方式与系统实际可靠度成比例。整体严格包含 R69：N=1 或独立性门不通过时逐指令退化为 FLUID-RAS。** 命名 **SWARM-RAS**（Swarm Wisdom, Appropriate Reliance & Minimal-interruption Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我该不该信这个『我们』——以及我该让人怎么信我**」。共识不是真理，共识是一个需要先被证明「成员彼此独立」才有意义的估计量；而体验不是一个附加分，它是防止「更自信的错误」被人类接受的那道闸。

## 0. 直觉与动机

**灵感 1（群体智能 → 共识的价值等于成员的独立性）**
直觉：一个人可能看错，但十个各自独立看的人同时看错同一处的概率很小——这就是孔多塞陪审团定理。它的前提被反复忽视：**独立性**。如果十个人用的是同一副眼镜、上的是同一门课、犯了同一个先验错误，那他们的「一致」不是证据，只是**同一份偏见的十次复读**。工程上的推论极其锋利：群体能否消解 R69 的幻影模态，不取决于成员数量 N，而取决于**有效独立人数 n_eff**。于是「群体智能」在本方案里不是一个规模指标，而是一个**需要被治理和验证的资源**：先度量独立性，再用共识；独立性不足时，共识必须被降权甚至禁用。

**灵感 2（用户体验 → 注意力是稀缺预算，信任是需要校准的量）**
直觉：R69 的 VoI 把「问」的成本写成物理/社交成本 c(g)，这太粗。真实的人因成本是：**打断**（interruption）、**任务切换**（context switch）、**建立上下文的解释负担**（explanation burden）、以及**被反复追问磨损的信任**（trust erosion）。这四者都不是线性可加的物理量，且会随时间疲劳累积（R69 的 E297 只是观察到了「交互疲劳」，没有建模）。更关键的是，即使系统答对了，若它**表达的信心**与**实际正确率**不符，用户也会以错误的方式依赖它：过度信任（automation bias，错也照做）或信任不足（disuse，对也怀疑）。因此 UX 在本方案里是两层硬约束：**(a) 人类注意力的共享预算**——N 个成员共用一个「每回合至多一次人问」的闸门；**(b) 适度依赖校准**——呈现的信心必须用可靠图校准到真实正确率，并配可解释、可否决的控制权。

**灵感 3（两个灵感的张力 → 群体越强，越要少打扰人；但越少打扰，越需要可信的呈现）**
直觉：群体共识与用户体验表面上冲突——多成员意味着更多潜在询问点。但正确的耦合是**反向**的：群体内部互证越充分，需要人类出面的场合越少，用户体验越好；而正因为人类出面变少，每一次出面都更关键，所以那一次询问必须**信息量最大、认知负荷最小、解释最清楚**。这把 R69 的「看—问—做」重构成「**群体先看—群体自问—人来裁一次—做并解释**」。UX 不是给系统加一个友好外壳，而是决定人类注意力该花在哪里的**分配器**。

**灵感 4（对 R69 最大风险的正面回应）**
直觉：R69 怕「模态权重不可信 → 追问幻影 / 误盖已验证」。单模型无法自证；但**一组独立模型的一致性**是一个单模型给不出的证据。一个幻影若只出现在某个成员的分布里，会在跨成员模态对齐后因支持度不足而被剔除；一个真模态应被多数独立成员共同支持。于是「**群体支持度 + 独立性加权法定人数**」成为 R69 那把悬空的「k 源一致」纪律的**可执行实现**：不是嘴上说正交，而是用 n_eff 去度量正交，用 quorum 去执行一致。

**灵感 5（新的危险 → 共识会放大同源错误，好体验会放大错误共识）**
直觉：群体智能是双刃剑。若成员因共享训练数据/共享传感器/共享底座模型而**集体同错**，共识不但不纠错，反而把 N 份同源偏差平均成一个**更平滑、更自信、更难被单个成员察觉**的幻觉——集体幻觉。更糟的是，若 UX 层把这种假共识以「高置信、低打扰、解释流畅」的形式优雅呈现，人类会系统性地过度信任它。**群体智能的收益与风险是同一枚硬币的两面，区别只在独立性是否真实。** 所以本轮必须同时交付：独立性度量与门控、集体幻觉压力测试、拜占庭群体界、以及适度依赖校准——否则 SWARM-RAS 只是给 R69 的错误装了一个「人多势众」的喇叭。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（SWARM-RAS 总览）** SWARM-RAS = (SMF, SCA, DIG, PRG, BFT, HAB, QAD, ARC, ELP, STIG, RAS-WM‡)。五条不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；STIG 账本只写证据，不写权重）；
(ii) **群体证据纪律**：任何群体共识须给出独立性加权支持度 S_j 与有效独立人数 n_eff，未过法定人数者视为幻影并剔除；
(iii) **人类注意力预算硬约束**：全体成员共用一个注意力预算，每人每回合至多一次人类询问，且该询问必须聚合、低认知负荷；
(iv) **适度依赖约束**：呈现信心须经可靠图校准，并提供可解释依据与否决通道；
(v) **严格包含**：N=1 或独立性门不通过或预算耗尽且无共识时，逐指令退化为 R69 的 FLUID-RAS。

**定义 311（异构群体成员 SMF）** 成员集合 ℳ = {M_1,…,M_N}，成员 i 拥有各自（可不同的）观测 o_t^{(i)}、流匹配策略 FMP_i 与感知编码器（复用 R68 MTM trunk 或独立实例）。异构性来自：训练数据子集、随机种子、架构宽度、传感器视角/模态。成员间仅通过动作空间与共享 STIG 账本耦合，不做梯度共享（保持错误可分离）。

**定义 312（成员模态后验）** 成员 i 输出 𝒫_i = {m_{i,k}, ŵ_{i,k}, ξ̄_{i,k}, Σ_{i,k}, a_score_i}（沿用 R69 定义 296–297、301），即模态、权重、原型、模态内协方差与动作轨迹负对数似然。𝒫_i 完全复用 R69 的 FMP/AUD/FMA，零重复训练。

**定义 313（跨成员模态对齐与共识 SCA）** 在共享动作空间内，用最优传输把各成员原型匹配到共识模态集合 {M_j}：
assign* = argmin_{π} Σ_i Σ_k ŵ_{i,k} · W_2²(ξ̄_{i,k}, M_{π(i,k)})，
M_j = Wasserstein 重心({ξ̄_{i,k} : π(i,k)=j})。共识权重 Ŵ_j ∝ Σ_{i,k:π(i,k)=j} α_i ŵ_{i,k}，其中 α_i 为成员 i 的独立性权重（定义 315）。对齐只在「模态可分」（A95）时有意义；不可分时退化为整体保守。

**定义 314（群体支持度与法定人数 PRG）** 模态 j 的独立性加权支持度 S_j = Σ_i α_i · 1[∃k: π(i,k)=j]。法定人数 Q = 2f+1（f 为可容忍的异构故障成员数，见定义 317），或按有效独立人数取 Q_eff = ⌈n_eff/2⌉ + 1。共识认证集合 𝒞 = {M_j : S_j ≥ Q_eff}。**支持度不足的模态定义为幻影**，从信念中剔除而非继承 R69 的「都算进 U_epi」。

**定义 315（有效独立性与多样性治理 DIG）** 在无标签探针集 𝒮_probe 上估计成员两两误差相关 ρ̄ 与表征相似度（CKA 代理），得有效独立人数
n_eff = N / (1 + (N−1)·ρ̄)（设计效应公式）。
独立性权重 α_i ∝ 1/(1 + Σ_{j≠i} ρ_{ij})。**独立性门**：n_eff ≥ n_min 且 ρ̄ ≤ ρ_max 才允许享「幻影抑制」信用；否则共识只作参考、不得减少保守（退化 R69）。多样性下限与相关性上限是本方案的第一安全联锁。

**定义 316（共识不确定性二分）** 群体层面的 U_ale^sw = Σ_j Ŵ_j · mean_i tr(Σ_{i,·})（模态内，不可约）；U_epi^sw = H(Ŵ) · g(Δ_min^sw) · κ(n_eff)，其中 κ(n_eff)∈[0,1] 是「共识可信折扣」：n_eff 越大，越敢把模态间不确定性当作**可被群体证据消解**的 epistemic；n_eff→1 时 κ→0，即退回 R69 单体口径（共识不提供额外可约性）。区分「群体真正解决了」与「群体只是意见一致」。

**定义 317（拜占庭群体门 BFT）** 至多 f 个成员可被污染/幻觉/对抗，满足 f < N/3。法定人数 Q = 2f+1；用动作空间离散度 + STIG 来源信誉做离群检测。若被污染成员相关性高（同一供应商/同一后门），独立性假设失效，DIG 必须把其相关性计入 ρ̄，否则 BFT 界不再成立（显式写进风险）。

**定义 318（共享人类注意力预算 HAB）** 全局注意力预算 B(t)（每人每回合 ≤1 次人问；长时程有平均中断率上界 b）。预算不按成员分配，而是**共享一个闸门**：任一成员都不能单独消耗人问，必须由共识层统一调度（定义 320）。预算不足 ⇒ 不询问，走 R69 保守退避。

**定义 319（人类注意力代价模型 c_ux）** c_ux(g) = w_int·interrupt(g) + w_sw·switch(g) + w_exp·explain_burden(g) + w_tr·trust_erosion(g)。其中 explain_burden 随问题所需上下文量增加，trust_erosion 随近期同类打断频率增加（与 STIG 衰减记忆耦合），interrupt/switch 由场景紧急度与用户当前任务负载调制。R69 的物理/社交成本 c(g) 成为 c_ux 的一个特例。

**定义 320（询问聚合与设计 QAD）** 仅当 𝒞=∅（群体无认证共识）且预算允许时，构造**单一**询问：
g* = argmax_{g∈𝒢} [ E[ΔH(Ŵ | answer(g))] / (c_ux(g) + λ_g) ]，s.t. budget.allow(g)，且 g 为「批量问题」（把若干待消歧维度合并为一次、可用自然语言或多选呈现）。目标不是最大化原始 VoI，而是最大化**每单位人类注意力**的共识熵下降。若 max 比值 ≤ 1：不问。

**定义 321（可解释与可控 ELP）** 每次呈现须包含：候选模态（人能理解的动作选项）、系统倾向及其**实际依据**（哪个正交证据/哪个成员反对）、以及「若不确认我会怎么做」。用户可**否决**并指定模态；否决进入 STIG，作为下一轮成本先验与 ARC 校准样本。解释必须**忠实**（faithfulness）：解释所引证据须与实际驱动法定人数判定的证据一致（用消融检验），禁止事后合理化。

**定义 322（适度依赖校准 ARC）** 设呈现信心 ĉ（由共识支持度与 U_epi^sw 校准得到），真实正确指示 Y。目标是可靠图对齐：|P(Y=1 | ĉ) − ĉ| ≤ ε_rel。定义两个体验指标：**过度依赖率** OR = P(采纳 | Y=0, ĉ 高)，**信任不足率** UR = P(拒绝 | Y=1, ĉ 高)。ARC 只校准**呈现**（等渗/温度缩放），不改策略；其样本同时来自人类否决与审计回灌。

**定义 323（STIG 共识证据账本）** 追加式、哈希链的共享记忆：记录 (状态签名, 提出的询问, 回答来源, 结果, 时间戳)，并按 exp(−Δt/τ) 衰减相关权重。用途：(a) 相似状态**避免重复询问**（负缓存）；(b) 摊销式定价（历史低产出的询问类型抬高 c_ux）；(c) **来源信誉**（哪个成员/哪位人类回答可靠，识别撒谎者）；(d) 可复现审计。账本只写证据不写权重，保持定义 310-i；隐私上只存聚合签名并随 τ 遗忘。

**定义 324（群体证书 J_SWARM）** J_SWARM = (J_FLUID, n_eff, ρ̄, quorum_ratio, phantom_rejected, attention_spent, interruption_rate, reliance_ece, over_reliance, explanation_faithfulness, stig_hash, swarm_ver)。Valid ⇔ Valid(J_FLUID) ∧ 独立性门通过（或已显式退化）∧ 注意力预算未越界 ∧ reliance_ece ≤ τ_rel。

**定义 325（群体投毒与共谋干扰集 ℰ_swarm）** 成员幻觉/后门共享、被同一数据源污染、STIG 投毒（伪造历史）、人类回答共谋、以「多数」为名的社会工程。并入 AIC：ℰ_SWARM = ℰ_FLUID × ℰ_member_fault × ℰ_ledger × ℰ_correlated。

**定义 326（单调退避与严格包含）** 定义退化触发：N=1、独立性门失败、𝒞=∅ 且预算耗尽、BFT 越界、STIG 完整性校验失败。任一触发 ⇒ 决策与 R69 逐指令相同（同一成员、同一 z、同一 λ_floor）。因此 R69 是 SWARM 在「N=1 且无独立外部证据」边界上的严格退化：安全侧不作任何让步。

**定义 327（注意力感知的时序调度）** 人问不是每回合都评估，而是在「群体熵尖峰 + STIG 显示该类问题历史高产 + 用户任务负载低」的窗口内触发。摊销 VoI：若某歧义会在未来以频率 ν 重现，当前询问的价值上界为 VoI_now + ν·VoI_future·e^{−Δt/τ}；据此决定「现在问、稍后重访时问、还是永不问」。

**定义 328（隐私与遗忘）** STIG 中的个体相关记录随 τ 衰减并可被删除；呈现层只暴露决策必要信息，不泄露成员内部表征。隐私预算与注意力预算并列，作为账本写入的硬约束。

# IP-264 SMF：异构群体成员（每个成员复用 R69 的 FMP/AUD/FMA 与 R68 trunk）
class SwarmModeField:
    def __init__(self, members):                 # N 个独立训练/异构成员
        self.members = members

    def posteriors(self, obs):                   # obs[i] 为成员 i 自己的观测（视角/模态可不同）
        return [m.fmp.sample_modes(obs[i]) for m in self.members]
        # 每个返回 {modes, weights, covs, a_score}，完全沿用 R69 定义 296–301

# IP-265 SCA + IP-266 DIG：共识对齐 + 独立性门
def consensus_and_gate(posts, members, probe_states):
    rho   = mean_pairwise_error_corr(members, probe_states)
    n_eff = len(members) / (1 + (len(members) - 1) * rho)
    alpha = independence_weights(members, rho)
    assign = ot_align([p['modes'] for p in posts])          # 跨成员原型匹配
    cons = []
    for g in group_by(assign):
        M = wasserstein_barycenter([...])                    # 共识原型
        S = sum(alpha[i] for i in supporters(g))             # 独立性加权支持
        cons.append(Mode(M, weight(g, alpha), S, a_score=agg(g)))
    return cons, n_eff, rho, alpha

# IP-267 PRG + IP-268 BFT：幻影抑制与法定人数
def certify(cons, n_eff, f):
    Q_eff = max(2 * f + 1, math.ceil(n_eff / 2) + 1)
    return [m for m in cons if m.S >= Q_eff]                 # 支持不足 = 幻影，剔除

# IP-269 HAB + IP-270 QAD：共享注意力预算 + 聚合单问
def escalate(certified, cons, budget, stig, user_load):
    if certified: return None                                # 群体已自洽 → 不打扰人
    cands = build_batched_queries(cons, stig)                # 把待消歧维度合并成一次
    best = None
    for g in cands:
        if not budget.allow(g): continue
        ratio = expected_entropy_drop(cons, g) / cognitive_cost(g, user_load, stig)
        if best is None or ratio > best.ratio: best = (g, ratio)
    return best[0] if best and best[1] > 1.0 else None       # 不划算 → R69 兜底

# IP-271 ARC + IP-272 ELP：适度依赖校准 + 可解释/可否决呈现
def present(certified, cons, u_epi, stig):
    conf = isotonic_reliance_calibrate(cons, stig.reliance_samples)  # ĉ → 真实正确率
    why  = faithful_explanation(cons, certified, method='ablation')  # 用实际驱动证据
    return LegibleDecision(conf, candidates=cons, rationale=why,
                           default_if_silent=select_mode(certified or cons, u_epi),
                           veto=True)

# IP-275 主闭环（继承 R69；仅在「交互取证」处插入群体 + 注意力层）
def SWARM_RAS_round(M, obs, user_state):

    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4

    g = M.hab.escalate(certified, cons, M.budget, M.stig, user_state.load)

## 3. 推导

**引理 19（独立群体的幻影抑制）** 设真模态总被存在，每个成员**独立地**幻觉出某幻影模态 m 的概率为 p<1/2，且成员错误相互独立。则幻影通过独立性加权法定人数 Q_eff 的概率
P_ph ≤ Σ_{j≥Q_eff} C(N,j) p^j (1−p)^{N−j}，
随 N 单调下降且在 p<1/2 时指数趋零（孔多塞型界）。系：R69 单体（N=1）的 P_ph = p，是无法自证的下界；SWARM 的收益正比于**真实**独立成员数，而非规模。

**引理 20（有效独立性与共识收益的坍缩）** 若成员误差两两相关 ρ̄（0≤ρ̄<1），则 n_eff = N/(1+(N−1)ρ̄)。当 ρ̄→1，n_eff→1，P_ph 回到 p，共识不带来任何抑制；当 ρ̄=0，n_eff=N，回到引理 19。故**收益是 n_eff 的函数，不是 N 的函数**。系：共享数据/底座导致的**集体幻觉**（ρ̄ 高且共同偏差）是共识的盲区；DIG 的相关性门是第一安全联锁，宁可退化也不让同源多数冒充独立证据。

**引理 21（注意力聚合的效率）** 设歧义状态比例为 η，群体以概率 1−δ 达成认证共识（δ 随 n_eff 下降），R69 对每个 VoI>c 的歧义状态都可能人问。SWARM 只在共识失败的 δ 比例上人问，且每次询问是「剩余最大分歧」的聚合问句。则期望人问次数由 η·P(VoI>c) 降为 η·δ，而每次人问的**条件期望信息增益**上升（只在群体也拿不准处花钱）。系：更好的群体不仅更准，还**更少打扰**——这正是用户体验与群体智能在本方案里的正向耦合。

**定理 18（SWARM 严格包含 R69 且安全单调）** 在 A95（模态可分）+ A99（成员错误可估、ρ̄ 可测）+ A100（注意力预算与退化触发可判定）下，SWARM 的决策在任意状态上的期望风险 ≤ R69；且当 N=1、独立性门失败、𝒞=∅ 且预算耗尽、BFT 越界或 STIG 完整性失败时，两者**逐指令相同**。证明要点：认证共识只**删除**支持不足的模态、不新增动作；风险缩放取 max(…) 且退化时 λ 单调不降；安全包络由 C-RAS-WM 独立认证、不经共识修改。故 R70 是 R69 在「无独立外部证据」边界的严格泛化。

**定理 19（适度依赖界）** 若呈现信心经可靠图校准（|P(Y=1|ĉ)−ĉ|≤ε_rel）且解释忠实（引用的证据与实际法定人数判定的消融贡献一致），则用户按阈值策略采纳时，过度依赖率 OR 与信任不足率 UR 的联合缺口 ≤ ε_rel + ε_faith + ε_prior（ε_prior 为用户先验偏差）。系：**更高的准确率不等于更好的体验**；未校准的信心会把「系统更准」转译成「用户更错地信任」。故 J_SWARM 必须同时报告 reliance_ece 与 explanation_faithfulness，而不能只报告任务成功率。

**定理 20（拜占庭群体安全）** 当故障成员 f < N/3 且故障成员与诚实成员错误相关有界（DIG 估计的 ρ̄ 已计入），法定人数 Q=2f+1 下认证模态的错误率 ≤ R69 单体的错误率；若 f ≥ N/3 或故障高度相关（ρ̄→1 的共谋），共识保证失效，必须由 DIG/BFT 显式触发退化（定义 326）。⇒ **安全不是「人多」给的，是「独立且多数诚实」给的**。

## 6. 本轮最大风险

**一句话**：SWARM-RAS 的全部收益押在「群体成员的错误相互独立」这一条上——**一旦成员共享训练数据、传感器或底座模型而集体同错，共识会把 N 份同源偏见平均成一个更平滑、更自信、更无法被任一成员察觉的集体幻觉；而 UX 层若再把这种假共识以「高置信、低打扰、解释流畅」的形式优雅呈现，人类会被系统性地培养出过度信任——于是系统不只是错，而是让最该纠错的人也不再怀疑它。**

**次级风险与缓解**：
1. **虚假独立性**（相关性估计被探针集偏差骗过）→ DIG 多代理探针（表征 CKA + 无标签分歧 + 数据溯源）+ 相关性门宁严勿松 + E303/E304 压力测试；
2. **共谋/共享后门**（f< N/3 的经典 BFT 界失效）→ 显式把相关故障计入 ρ̄、BFT 越界即退化、ℰ_correlated 对抗训练 + E306；
3. **注意力预算被「群体不肯认输」耗尽**（成员长期无共识 → 频繁人问）→ 预算硬闸 + 摊销 VoI + STIG 负缓存 + 退化 R69 保守；
4. **UX 沦为事后合理化**（解释与真实依据脱节）→ 忠实性用消融强制检验、ELP 引用实际驱动证据、E310；
5. **隐私与审计泄漏**（STIG 记账暴露个人数据）→ 聚合签名 + 衰减遗忘 + 删除可验证 + E314。

**定义 323–325（STIG + 证书 + 干扰集）** 哈希链证据账本，衰减复用；J_SWARM 并入 n_eff/ρ̄/注意力/依赖/忠实度；`ℰ_SWARM = ℰ_FLUID × ℰ_member_fault × ℰ_ledger × ℰ_correlated`。

**定义 326–328（退避 + 时序 + 隐私）** 退化触发：N=1 / 门失败 / 无共识且预算耗尽 / BFT 越界 / STIG 完整性失败 ⇒ 逐指令同 R69。摊销 VoI 决定「现在问 / 重访问 / 永不问」；STIG 个体记录随 τ 遗忘且可删除。

# IP-264 SMF：异构群体成员（复用 R69 FMP/AUD/FMA + R68 trunk）
class SwarmModeField:
    def posteriors(self, obs):                     # obs[i] 为成员 i 自己的观测
        return [m.fmp.sample_modes(obs[i]) for m in self.members]

# IP-265 SCA + IP-266 DIG：共识对齐 + 独立性门
def consensus_and_gate(posts, members, probe_states):
    rho   = mean_pairwise_error_corr(members, probe_states)
    n_eff = len(members) / (1 + (len(members)-1)*rho)
    alpha = independence_weights(members, rho)
    assign = ot_align([p['modes'] for p in posts])
    cons = []
    for g in group_by(assign):
        M = wasserstein_barycenter([...])
        S = sum(alpha[i] for i in supporters(g))
        cons.append(Mode(M, weight(g, alpha), S, a_score=agg(g)))
    return cons, n_eff, rho, alpha

# IP-267 PRG + IP-268 BFT：幻影抑制与法定人数
def certify(cons, n_eff, f):
    Q_eff = max(2*f + 1, math.ceil(n_eff/2) + 1)
    return [m for m in cons if m.S >= Q_eff]        # 支持不足 = 幻影

# IP-269 HAB + IP-270 QAD：共享注意力预算 + 聚合单问
def escalate(certified, cons, budget, stig, user_load):
    if certified: return None
    best = None
    for g in build_batched_queries(cons, stig):
        if not budget.allow(g): continue
        ratio = expected_entropy_drop(cons, g) / cognitive_cost(g, user_load, stig)
        if best is None or ratio > best.ratio: best = (g, ratio)
    return best[0] if best and best[1] > 1.0 else None   # 不划算 → R69 兜底

# IP-271 ARC + IP-272 ELP：适度依赖校准 + 可解释/可否决
def present(certified, cons, u_epi, stig):
    conf = isotonic_reliance_calibrate(cons, stig.reliance_samples)
    why  = faithful_explanation(cons, certified, method='ablation')
    return LegibleDecision(conf, cons, why,
                           default_if_silent=select_mode(certified or cons, u_epi),
                           veto=True)

# IP-275 主闭环（继承 R69，插入群体 + 注意力层）
def SWARM_RAS_round(M, obs, user_state):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    posts = M.smf.posteriors(obs) if K > 1 else [M.self_member.posterior(obs[0])]
    cons, n_eff, rho, alpha = consensus_and_gate(posts, M.smf.members, M.probe)
    indep = (n_eff >= N_MIN) and (rho <= RHO_MAX) and M.stig.integrity_ok()
    certified = certify(cons, n_eff, M.f) if indep else []
    U_ale, U_epi = collective_split(cons, certified, n_eff)
    g = M.hab.escalate(certified, cons, M.budget, M.stig, user_state.load)
    if g is not None:
        ans = M.qad.execute(g)
        U_epi = M.cia.update_belief(cons, ans)
        M.stig.record(o, g, ans, source=...)
    U_floor = U_ale + (U_epi if (not certified and g is None) else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if not indep: lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, U_cal))
    mode = select_mode(certified or cons, U_epi, lam)
    dec  = present(certified, cons, U_epi, M.stig)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa.submit_async(g, cons, dec, n_eff, rho, M.stig.last_hash)
    return k, lam, mode, (U_ale, U_epi), dec

## 4. 推导

**引理 19（独立群体的幻影抑制）** 每个成员独立幻觉出幻影模态的概率 p<1/2，则幻影通过法定人数 Q_eff 的概率 `P_ph ≤ Σ_{j≥Q_eff} C(N,j) p^j (1−p)^{N−j}`，随 N 指数趋零。单体（N=1）的 P_ph=p 是无法自证的下界。

**引理 20（有效独立性与共识收益的坍缩）** `n_eff=N/(1+(N−1)ρ̄)`；ρ̄→1 时 n_eff→1、收益归零；ρ̄=0 时回到引理 19。系：收益是 n_eff 的函数而非 N 的函数；共享数据导致的集体幻觉是共识盲区，DIG 相关性门是第一联锁。

**引理 21（注意力聚合的效率）** 群体以概率 1−δ 达成认证共识（δ 随 n_eff 下降），SWARM 仅在 δ 比例上人问，且问「剩余最大分歧」的聚合句：期望人问次数由 `η·P(VoI>c)` 降为 `η·δ`，条件信息增益上升。系：更好的群体更准且更少打扰。

**定理 18（严格包含 R69 且安全单调）** 认证共识只删除支持不足的模态、不新增动作；风险缩放取 max 且退化时 λ 单调不降；安全包络由 C-RAS-WM 独立认证。故期望风险 ≤ R69，且退化触发时逐指令相同。

**定理 19（适度依赖界）** 呈现信心校准且解释忠实时，`OR + UR` 的联合缺口 ≤ `ε_rel + ε_faith + ε_prior`。系：更高准确率 ≠ 更好体验；J_SWARM 必须报告 reliance_ece 与 explanation_faithfulness。

**定理 20（拜占庭群体安全）** f<N/3 且相关有界时，Q=2f+1 认证模态错误率 ≤ 单体；f≥N/3 或高相关共谋时共识保证失效，必须由 DIG/BFT 显式触发退化。⇒ 安全不是「人多」给的，是「独立且多数诚实」给的。

## 7. 本轮最大风险

**一句话**：SWARM-RAS 的全部收益押在「群体成员错误相互独立」这一条上——**一旦成员共享训练数据、传感器或底座模型而集体同错，共识会把 N 份同源偏见平均成一个更平滑、更自信、更无法被任一成员察觉的集体幻觉；而 UX 层若再把这种假共识以「高置信、低打扰、解释流畅」的形式优雅呈现，人类会被系统性地培养出过度信任——于是系统不只是错，而是让最该纠错的人也不再怀疑它。**

**次级风险与缓解**：虚假独立性（多代理探针 + 相关性门宁严勿松 + E303/E304）；共谋/共享后门（相关故障计入 ρ̄ + BFT 越界退化 + ℰ_correlated + E306）；注意力预算被「群体不肯认输」耗尽（硬闸 + 摊销 VoI + STIG 负缓存 + 退化 R69）；UX 沦为事后合理化（消融忠实性强制 + ELP 引用实际证据 + E310）；隐私/审计泄漏（聚合签名 + 衰减遗忘 + 删除可验证 + E314）。
