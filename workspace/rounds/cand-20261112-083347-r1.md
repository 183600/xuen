# 第 58 轮（承接第 57 轮「少样本×多模态×个性化」IP-133~138；灵感循环第 4 轮（竞赛篇第 1 轮）；本轮灵感：「竞赛策略」×「腕部相机」）

> 第 57 轮把证据变成"少样本可校准、跨模态可对账、个性化有界"的对象，但它仍默认了三个未经审视的前提：**(a) 世界是一个平均意义上的温和对手**——阈值与风险按名义测试分布调，安全验证看的是平均假承诺率，而真实失败恰恰来自被"选中"的尾部角落（恰好让视觉反光、恰好让探针落在盲带的材质组合）；平均安全不等于对抗安全。**(b) 证据都来自"远处"的传感套件**——最后一个厘米、真正要踩上去的接触斑块，从未被直接看见；腕部相机是唯一能在承诺前看清它的传感器，却也是最容易被自身污染的证人（手眼标定漂移、运动模糊、粉尘、足端自遮挡）。**(c) 探针与注意力由一个全局 VOI 统一分配**——区域之间、注视与接触之间没有显式竞争，既可能让高价值区域饥饿，也可能被"高分贝的假警报"操纵预算。本轮用两个灵感各补一条腿：**竞赛策略**把"自然"显式建模为有界对手，并把探询改造成逐次减半的证据锦标赛与红队地形联赛；**腕部相机**把最后一个厘米变成带"证据保管链"的近场证据；二者合流为**注视-探针联合竞价**。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"对手可界定、近场可自证、竞标不升险的证据说可信"**。

核心矛盾：
- **H29（平均安全 vs 对抗安全）**：不做最坏情况建模，平均风险达标也可能被一个针对性工况击穿；但把模糊集放到最大又会保守到冻结——安全的赌注从"先验质量"再后移一层，落到"对手模型的质量与半径"。
- **H30（近场信息 vs 自缠绕）**：腕部相机在最后一个厘米信息量最高，却与机器人自身强耦合——手眼标定、关节形变、运动模糊、粉尘与遮挡都能"伪造"一条看起来合格的近场证据；越靠近接触，越可能被自己的影子骗。
- **H31（竞标/锦标赛 vs 公平与终止）**：让多个证据请求竞价、让假设互相淘汰，能省预算也会引入新攻击面——假警报可以抬价挤占预算、弱势区域可以饥饿、真有危险的假设可能被过早淘汰；必须让"野牌"永不淘汰、预算必终止、分配可审计。

## 0. 直觉与动机

**灵感 1（竞赛策略 → 有界对手 + 红队地形联赛）**
直觉：竞赛里最危险的不是"平均水平的对手"，而是"专门研究你弱点、并按规则出招的对手"。地形也一样：它不必随机，它可以恰好是"透明冰面 + 视觉反光 + 探针高速通过"的组合。于是安全不该对名义分布求平均，而应在**声明的对手模糊集**内求最坏值；同时永远给"语料里没见过的世界"保留一份不可归零的概率质量（野牌假设），从根上堵住第 57 轮"元先验普遍错误"的盲区。再用**红队地形联赛**持续证伪自己的模糊集：生成器专门找失败样例，只有活过联赛的策略才允许宣称泛化。

**灵感 2（竞赛策略 → 逐次减半的证据锦标赛）**
直觉：探针预算像锦标赛赛程——先用便宜的非接触证据淘汰大多数"显然安全"的假设，只让少数彼此接近、真正决定风险的假设进入昂贵的接触轮；但淘汰规则必须是**保守的**：只有当某假设的风险上置信界都低于阈值时才淘汰它，且野牌假设永远参赛。这样省下的是"已经问清楚的区域"的预算，而不是"还没问清楚的风险"。Racing 的收敛性还能给出"错误淘汰概率 ≤ δ_race"的显式证书。

**灵感 3（腕部相机 → 带保管链的近场证据 EV-eye）**
直觉：腕部相机是"最后一个厘米的目击者"，但目击者要出庭，先得证明自己没被收买、没看错、没站错位置。于是给每条近场观察配三样东西：**手眼标定证书**（当前外参误差 ≤ε_cal）、**成像质量分**（模糊/曝光/遮挡/粉尘取最小）、**位姿溯源**（这一帧确实属于当前身体与相机版本）。三者缺一，证据只能降级为"提示"而不能入账。它的最高价值不是分类，而是**视觉伺服到最后安全接触点**——在没碰之前就把落点选对。

**灵感 4（合流 → 注视-探针联合竞价 GPA）**
直觉：腕部相机视场窄、驻留短，探针也稀缺，二者其实在竞争同一份"承诺前的时间预算"。把每个请求看成一次投标：出价 = 它对**最坏风险**的下降量（鲁棒 VOI），拍卖按预算与保留价分配，并对每个区域设最低份额——防止高分贝假警报把预算全抢走。用 proper scoring 让"诚实报价"成为最优策略；这样竞争带来效率，而不是带来新的可博弈面。

**灵感 5（合流 → 证据门六类、证书 J_q、PCE++）**
直觉：第 57 轮的五类证据在本轮获得"对抗与近场"维度：承诺条件不再是"某条证据够不够"，而是"**所有幸存假设（含野牌）的鲁棒风险上界是否都低于 δ_f**"；新增 **EV-eye**（仅 L0/L1、须保管链、永不单独授权不可逆接触）。击穿安全需要：对手模型半径错 ∧ 红队联赛漏检 ∧ 锦标赛错误淘汰 ∧ 手眼/成像证书伪造 ∧ 跨模态无对账 ∧ 无裕度 ∧ 人也错——纵深从五层到七层。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（对抗地形模糊集与鲁棒风险场 AAR）** 区域假设集 Θ_r（材质、刚度、承载、摩擦、隐藏空腔等）与经验分布 P̂_r；模糊集 ℬ_ε(P̂_r)={P: W_1(P,P̂_r)≤ε_adv}；另设野牌假设集合 Θ_unk，赋予不可归零质量 ε_unk。鲁棒风险
R_rob(a,r)=sup_{P∈ℬ_ε(P̂_r)} E_P[R(a,θ)] + ε_unk·R_max，
动作 a*=argmin_a [R_rob(a,r)+λ·cost(a)]。红队地形联赛：生成器 G 在声明的真实性约束 𝒞_real 内最大化失败率，联赛证书 RT=(ε_adv,ε_unk,失败样例集,覆盖率)，只有通过留出联赛的策略才可宣称泛化。R_max 为最坏后果上界；ε_adv、ε_unk 的取值本身必须被证书声明并可被联赛证伪。

**定义 140（逐次减半证据锦标赛 ERT）** 对 H_r 维护每假设的风险估计 R̂_h 与上置信界 Ū_h(t)=R̂_h+β_t(n_h)，β_t 为按 δ_race 校准的置信宽度。第 t 轮预算 n_t=B/(2^t|H_t|)，仅当 Ū_h(t)<θ_risk 且 h≠WILDCARD 时淘汰 h；WILDCARD 永远保留并代表 Θ_unk。健全性要求 P(错误淘汰真正危险假设)≤δ_race；记录 race_log=(每轮 H_t,分配,淘汰理由,UCB)。Racing 只减少"已被证据压低的假设"，不减少最坏情况。

**定义 141（腕部近场证据 WNE/EV-eye）** 眼在手上观察 z=(I,ξ_cam,v_cal,q_img,τ)，手眼标定证书要求 P(‖ξ̂_cam−ξ_cam‖≤ε_cal)≥1−δ_cal；成像质量 q_img=min(q_blur,q_exp,q_occ,q_dust)，可用性要求 q_img≥q_0；位姿溯源要求 z 的相机外参与身体/关节版本与当前一致（v_cal=v_now ∧ v_body=v_now）。似然 p(z|θ,ξ_cam) 以 ε_cal 膨胀其不确定性。EV-eye 仅可用于 L0/L1；可替代 L1 的一次佐证；**永不单独构成不可逆接触的必要证据**。若用于视觉伺服，落点须满足 𝒰_safe 且伺服全过程 q_img≥q_0，否则退回保守落点。

**定义 142（注视-探针联合竞价 GPA）** 请求 q=(region,type∈{gaze,probe},bid)；鲁棒出价 b_q=R_rob(π_now,r)−E_o[R_rob(π_after(q),r)]，仅在 b_q≥θ_voi 时参拍。分配 x_q∈{0,1} 求解 max Σ x_q b_q s.t. Σ_{gaze} c_q≤B_gaze、Σ_{probe} c_q≤B_probe、每区域每窗口份额 ≥m_min（防饥饿）、单请求时延 τ_q≤τ_int。采用保留价与诚实计分（proper scoring）使真实出价近似最优；被拒绝的请求进入下一窗口而非丢弃。全部分配写入 gaze_log/auction_log。

**定义 143（对抗证据门 AGE 与证书 J_q）** 证据类扩为六类：EV-probe\*（须元校准证书或共形带）、EV-visit、EV-margin、EV-xmodal（限 L1）、**EV-eye（限 L0/L1，须保管链）**、EV-human（auth≥A1 且佐证≥corrob\*(auth)）。鲁棒承诺条件：
∀h∈H_surv∪{WILDCARD}: Ū_h(a)≤δ_f ∧ 证据门过。
不可逆接触必要证据集仍为 {EV-probe\*∨EV-margin}∪佐证，EV-eye 与 EV-xmodal 均不得进入。证书 J_q=(J_p, ℬ_ε/ε_adv/ε_unk, race_log, gaze_log, auction_log, cal_cert, q_img_stats, redteam_report)，继承 J_p 全检。

**定义 144（探-诺-演++ 算子 PCE++）** 每检查点：①更新假设集、模糊集与 UCB；②若腕部相机可用且 q_img≥q_0，先做注视预扫并按 ERT 剪枝；③在预算（B_probe+B_gaze）内按 GPA 分配、按 ERT 执行，直到无"危险幸存者"或预算耗尽；④仅当所有幸存假设含野牌的鲁棒风险上界≤δ_f 且证据门过才承诺；否则选 argmax 绕行/降档，再不行进入 L2 协商（τ_int(auth)）或安全停；⑤全程写 J_q。终止预算上界为 B_probe+B_gaze+k_cons。

## 2. 关键算法伪代码（完整版见产物区）

```python
def robust_risk(M, r, a, amb):                      # IP-139: 含野牌质量
    r_hat = max(risk(a, h) for h in M.hyp[r])
    return r_hat + amb.eps_unk * RISK_MAX

def evidence_race(M, r, budget, amb):               # IP-140: 逐次减半
    H, log = set(M.hyp[r]) | {WILDCARD}, []
    while budget.left > 0 and dangerous_survivor(H, M, amb):
        for h in list(H - {WILDCARD}):
            if ucb_risk(h, M) < THETA_RISK: H.remove(h); log.append(('elim', h))
        q = argmax(admissible_queries(r, M), key=lambda q: bid(q, M, amb))
        if bid(q, M, amb) < THETA_VOI: break
        M = update(M, q, execute(q)); budget.spend(q)
    return M, H, log

def eye_admissible(z, M, body):                     # IP-141: 证据保管链
    return (z.q_img >= Q0 and handeye_cert_ok(M, z)
            and z.v_cal == M.cal_version and z.v_body == body.version)

def gaze_probe_auction(reqs, B_g, B_p, window):     # IP-142: 联合竞价
    reqs = [q for q in reqs if q.bid >= THETA_VOI]
    return solve_knapsack(reqs, B_g, B_p, min_share=M_MIN, window=window)

def probe_commit_evolve_pp(x0, M, task, budget, consent, personas, amb):
    route = plan_on_map(M, task, risk_model)
    for cp in route.checkpoints:
        if wrist_ready(M) : M = gaze_prescan(M, cp)
        M, H, rlog = evidence_race(M, cp.region, budget, amb)
        a = select_action(cp, M, H)
        if all(ucb_risk_h(h, a, M) <= DELTA_F for h in H | {WILDCARD}) \
           and age_gate(cp, M, personas):
            commit(a); log_Jq(cp, M, H, rlog); continue
        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, M)) != 'halt': route = alt; continue
        return negotiate_or_stop(cp, M, a, consent,
                                 tau_int=tau_int(personas.active.auth))
    return route, M
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| AAR | O(\|H\|·\|A\|) / 区域 | O(\|H\|·d_θ) | 模糊集覆盖、ε_unk 不归零 |
| ERT | O(B_probe·log\|H\|) 典型，O(\|H\|·B_probe) 最坏 | O(\|H\|) | UCB 保守、野牌不淘汰、δ_race |
| WNE | O(d_img)/帧 + O(d_cal) | O(frame buffer) | 标定证书、位姿溯源、q_img 诚实 |
| GPA | O((\|G\|+\|P\|)log(\|G\|+\|P\|)) | O(\|G\|+\|P\|) | 预算守恒、防饥饿、诚实计分 |
| AGE | O(\|σ\|) | O(\|σ\|) | 鲁棒条件、EV-eye 限 L1 |
| PCE++ | O(\|CP\|·(B_p+B_g)·(C_VOI+d_φ)+\|CP\|·A\*) | O(\|V\|+\|σ\|) | 预算终止、四态完备 |

**正确性定理（ARWS 概要）**：在 A33–A40 上加 **(A41)** 对抗覆盖：真实 θ∈ℬ_ε 概率 ≥1−δ_adv，野牌质量 ε_unk 不归零且 R_max 有效；**(A42)** 锦标赛健全：P(错误淘汰真危险假设)≤δ_race；**(A43)** 近场保管链诚实：手眼误差 ≤ε_cal、q_img 模型诚实、位姿溯源无错配；**(A44)** 竞价预算守恒、防饥饿、计分诚实且 τ_gaze≤τ_int。则：(i) 鲁棒承诺失效率 ≤ δ_f+δ_adv+δ_race+δ_cal+δ_eye+ε_meta(k)+δ_ood·α_conf；(ii) 交互单调性强化：AAR/ERT/WNE/GPA 只能经"在保留野牌的前提下缩小假设集"或"更保守的动作参数"影响系统，竞价不得引入升险动作；(iii) PCE++ 在 B_probe+B_gaze+k_cons 内终止于 {承诺,绕行,降档,L2,安全停}；(iv) 对检查点取联合界得部署安全下界。

## 6. 本轮最大风险

**一句话**：本轮把安全押在"对手模糊集的半径"与"腕部相机的证据保管链"上——若 ε_adv 定得过小、或手眼标定与成像质量证书在振动与温漂下失真，鲁棒决策就会退化为对虚构对手的优化，而近场视觉的"最后一眼"会被自身污染伪造；必须以野牌质量永不归零、EV-eye 永不单独授权不可逆接触、红队地形联赛持续证伪模糊集三重护栏，承认"我们没有见过的世界"永远有一票否决权。

# 第 58 轮产物 · 创新点清单 v34：Adversarial-Racing-WristEye（有界对手×证据锦标赛×腕部近场自证，AAR×ERT×WNE×GPA×AGE×PCE++）

### IP-139 AAR（有界对手与鲁棒风险）

```python
def ambiguity_update(M, r, obs, verdicts):
    M.hyp[r].update(explain(obs))                    # 数据驱动的假设扩展
    M.amb[r] = wasserstein_ball(M.emp[r], eps_adv)   # 声明半径，联赛校准
    if verdicts.falsifies_all(M.hyp[r]):             # 真实世界落在模型外
        M.amb[r].eps_unk = max(M.amb[r].eps_unk, EPS_UNK_FLOOR)
    return M                                          # 野牌质量永不归零

def robust_risk(M, r, a):
    r_hat = max(risk(a, h) for h in M.hyp[r] | {WILDCARD})
    return r_hat + M.amb[r].eps_unk * RISK_MAX

def redteam_league(policy, generator, C_real, n_rounds):
    fails = []
    for _ in range(n_rounds):
        t = generator.propose(maximize='failure', subject_to=C_real)
        if policy(t).failed: fails.append(t)
    return RT(eps_adv=calibrate_radius(fails), eps_unk=coverage_gap(fails),
              cases=fails, coverage=empirical_coverage(fails))
```

### IP-140 ERT（逐次减半证据锦标赛）

```python
def evidence_race(M, r, budget, amb):
    H = set(M.hyp[r]) | {WILDCARD}
    log = []
    t = 0
    while budget.left > 0 and dangerous_survivor(H, M):
        t += 1
        n_t = budget.total // (2**t * max(1, len(H)))
        for h in list(H - {WILDCARD}):
            if ucb_risk(h, M, n_t) < THETA_RISK:     # 只有上界都安全才淘汰
                H.remove(h); log.append(('elim', h, ucb_risk(h, M, n_t)))
        q = argmax(admissible_queries(r, M),
                   key=lambda q: bid(q, M, amb))
        if bid(q, M, amb) < THETA_VOI: break
        M = update(M, q, execute(q)); budget.spend(q)
        log.append(('probe', q, H.copy()))
    assert WILDCARD in H                              # 野牌永不淘汰
    return M, H, log
```

def eye_capture(M, cp):
    I = wrist_camera.capture(servo=cp.contact_point)  # 视觉伺服到最后落点
    z = Obs(I, xi=cam_extrinsics(), v_cal=M.cal_version,

def eye_admissible(z, M, body):
    return (z.q_img >= Q0
            and handeye_cert(M).error <= EPS_CAL
            and z.v_cal == M.cal_version
            and z.v_body == body.version
            and not self_occluded(z, body))

def eye_evidence(z, theta, M, level):
    if not eye_admissible(z, M, M.body): return None  # 只能作提示，不入账
    like = inflate(p(z | theta, z.xi), EPS_CAL)       # 标定误差进不确定性
    return 'EV-eye' if level in ('L0', 'L1') else None # 不可逆层硬禁令

def gaze_probe_auction(requests, B_gaze, B_probe, window, M):
    live = [q for q in requests if q.bid >= THETA_VOI]

def age_gate(c, M, persona, H_surv, amb, lv):
    if c.ev == 'EV-eye':
        ok = lv in ('L0', 'L1') and eye_admissible(c.z, M, M.body)
    elif c.ev == 'EV-xmodal':
        ok = lv == 'L1' and c.indep_declared and D(c.region) <= THETA_D
    elif c.ev == 'EV-probe*':
        ok = (c.inf.cls == 'ID' and c.inf.ece_k <= eps_meta(c.k)) or \
             (c.inf.cls == 'OOD' and c.region in ood_reg.certified)
    elif c.ev == 'EV-human':
        ok = persona[c.op].auth >= 'A1' and \
             c.corrob >= quarantine_exit(persona[c.op].auth)
    elif c.ev in ('EV-visit', 'EV-margin'):
        ok = round57_checks(c, M)
    else:
        return ('reject', 'no_evidence_class', c)
    if not ok: return ('reject', 'evidence_insufficient', c)
    if c.irreversible and c.ev in ('EV-eye', 'EV-xmodal'):
        return ('reject', 'nearfield_on_irreversible', c)
    return ('ok', c)

def robust_commit_ok(a, M, r, H_surv, amb):
    return all(ucb_risk_h(h, a, M) <= DELTA_F
               for h in H_surv | {WILDCARD})          # 含野牌

def probe_commit_evolve_pp(x0, M, task, budget, consent, personas, amb):

def xmodal_fuse_e(M, r, e):
    if e.modality == 'eye':
        if not eye_admissible(e.z, M, M.body): return M, None, None
        e.like = inflate(e.like, EPS_CAL)              # 标定误差进似然
    M.b[r][e.modality] = bayes_update(M.b[r][e.modality], e.like, w=rho(M)[e.modality])
    fused = Fuse(M.b[r], M.rho)
    D = disagreement(M.b[r])

    return M, fused, D

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| AAR | O(\|H\|·\|A\|)/区域；联赛离线 | O(\|H\|·d_θ) | 模糊集覆盖、ε_unk 不归零（A41） |
| ERT | O(B_probe·log\|H\|) 典型 | O(\|H\|) | UCB 保守、野牌不淘汰、δ_race（A42） |
| WNE | O(d_img)/帧 + O(d_cal) | O(frame buffer) | 保管链、ε_cal 膨胀、EV-eye 限 L1（A43） |
| GPA | O((\|G\|+\|P\|)log(\|G\|+\|P\|)) | O(\|G\|+\|P\|) | 预算守恒、防饥饿、诚实计分（A44） |
| AGE | O(\|σ\|) | O(\|σ\|) | 鲁棒条件、近场不得单独授权不可逆 |
| PCE++ | O(\|CP\|·(B_p+B_g)·(C_VOI+d_φ)+\|CP\|·A\*) | O(\|V\|+\|σ\|) | 预算终止、四态完备 |

**正确性定理（Adversarial Racing Wrist-eye Soundness, ARWS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；并设 **(A41)** 对抗覆盖：真实 θ∈ℬ_ε(P̂_r) 概率 ≥1−δ_adv，野牌质量 ε_unk>0 且 R_max 为有效上界；**(A42)** 锦标赛健全：P(错误淘汰真正危险假设)≤δ_race，且 WILDCARD 永不被淘汰；**(A43)** 近场保管链：手眼误差 ≤ε_cal、q_img 模型诚实、位姿与版本溯源无错配；**(A44)** 竞价预算守恒、每区域最低份额 m_min、诚实计分且 τ_gaze≤τ_int。则：

1. **鲁棒承诺健全性**：
   P(fail) ≤ δ_f + δ_adv + δ_race + δ_cal + δ_eye + ε_meta(k) + δ_ood·α_conf + δ_xm·1[L1]。
2. **交互单调性**：AAR/ERT/WNE/GPA 只能经 (a) 在保留野牌的前提下单调缩小假设集，或 (b) 更保守的动作参数（更宽区间、更低步态、更高佐证数、更短超时）影响系统；竞价受保留价与最低份额约束，不能把任何升险动作加入可行集。
3. **终止性**：每检查点探测 ≤B_probe、注视 ≤B_gaze、共识探针 ≤k_cons，PCE++ 终止于 {承诺, 绕行, 降档, L2 协商, 安全停}。
4. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + δ_adv + δ_race + δ_cal + δ_eye + ε_meta(k) + δ_probe
                   + δ_ood·α_conf + δ_xm·1[L1])
             − P(𝓜 陈旧未检出) − P(护盾回退失败) − P(τ_int ∧ τ_gaze 超时 ∧ 安全停失效)
```

关键：**野牌质量给盲区兜底**（不信任"语料之外无世界"）；**锦标赛省的是已问清楚的预算，不是没问清楚的风险**（只有 UCB 安全才淘汰）；**EV-eye 把最后一眼变成可入账证据，但用保管链和"仅 L1"把自欺隔离在非不可逆层**；**竞价让注意力竞争起来，却用保留价、最低份额与诚实计分保证竞争不升险**。

## 6. 本轮最大风险

**一句话**：本轮把安全押在"对手模糊集的半径"与"腕部相机的证据保管链"上——若 ε_adv 定得过小、或手眼标定与成像质量证书在振动与温漂下失真，鲁棒决策就会退化为对虚构对手的优化，而近场视觉的"最后一眼"会被自身污染伪造；必须以野牌质量永不归零、EV-eye 永不单独授权不可逆接触、红队地形联赛持续证伪模糊集三重护栏，承认"我们没有见过的世界"永远有一票否决权。
