# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；新灵感循环第 1 轮；本轮灵感：「桌面操作」×「抓取位姿估计」）

> 第 60 轮的 SGEC 把「场景→意图→约束→阻抗→执行→证据」串成闭环，但它默认**输入已经是一个可执行动作**。放到桌面操作里，这个假设在最关键的一步失效：抓取位姿估计输出的是 SE(3) 上的一堆候选，而桌面操作真正需要的是**在支承面、遮挡、对称性、可达性与力闭合共同约束下的一个可执行抓取**。三个结构性缺口：
> 1. **抓取位姿的「点估计幻觉」**：估计器给出 top-1 位姿与一个未校准的 score，但 score ≠ 可执行性。在杂乱桌面上，最高分抓取可能撞桌面、撞邻物、超出可达域，或在重力下不稳定。第 60 轮的 K_safe 再安全，也无法把一个几何上不可执行的抓取变安全。
> 2. **桌面物理结构未被利用**：桌面是**支承面**（物体静置于其上）、是**遮挡源**（前物挡后物），也是**对称性的温床**（盒/瓶/圆柱有离散或连续对称）。把抓取分布当普通欧氏点云做均值/聚类，会把对称等价的抓取错误平均成「中间那个谁都抓不到」的位姿；把可见点云当完整几何，会把被遮挡的碰撞当成自由空间。
> 3. **执行证据没有反哺抓取信念**：第 60 轮的 EPIR/CLEP 只把滑移当作「异常/中止」，而不是「关于抓取位姿的后验证据」——一次滑移其实精确地告诉了我们接触法向、摩擦与位姿误差的方向，应当用于**在线修正抓取信念并反射式重抓**，而不是从头再来。

## 0. 直觉与动机

**灵感 1（桌面操作 → 桌面约束抓取流形 TCGM）**
直觉：桌面不是「背景」，而是一张**约束流形**。一个抓取 g=(R,t) 只有同时满足四件事才「存在」：夹爪网格不穿桌面且从桌面上方接近（净空/接近锥）、不碰邻物（碰撞净空）、机械臂能到位（可达性）、抓取后物体在重力与摩擦下静稳（支撑多边形/摩擦锥）。关键洞见：**与其「估计后过滤」（filter），不如「估计后投影」（project）**——把任意候选抓取投影到可执行流形 M_table 上，得到最近的可行抓取与一个投影距离 d_table。d_table 本身就是「这个抓取离可执行有多远」的连续度量：小则微调执行，大则拒绝或换视角，而不是因过滤而丢掉全部候选。一句话：**桌面不是障碍物，是抓取空间的边界条件。**

**灵感 2（抓取位姿估计 → 对称商抓取分布 SQGD）**
直觉：抓取位姿估计的本质不是回归一个 6-DoF 数，而是**在 SE(3) 上维护一个多峰分布**——同一物体常有多条可行抓取（盒子的四面、圆柱的整圈）。更麻烦的是物体对称群 H：g 与 g·h（h∈H）在物理上完全等价。把分布当欧氏空间做均值/KDE，会跨越对称模式取平均，得到一个物理上不存在的中点。关键洞见：**抓取分布活在商空间 Q=SE(3)/H 上，而不是 SE(3) 上**；正确的操作是「对称感知的核 + 商空间上的众数搜索」，输出若干模式及切空间协方差，而不是一个均值。一句话：**对称物体的「平均抓取」通常是不可抓取的那一个。**

**灵感 3（两者合流 → 抓取-阻抗编译器 GIC）**
直觉：抓取位姿的不确定性不应只用来「排序候选」，而应直接编译成执行参数。直觉上：**位姿越不确定，那个方向就越该柔顺**。沿接近轴的位置不确定 → 低刚度、高阻尼，先软接触再对齐；切向位置/姿态不确定 → 提高切向刚度与旋转阻尼以抑制滑移；力上限由摩擦锥与物体承压能力共同裁剪。关键洞见：**不确定性不是要消除的噪声，而是要映射为阻抗椭球的资源**——高不确定方向给低刚度，高确定方向给高刚度，让执行层「顺着不确定的方向走」而不是硬碰。编译结果再投影到第 59 轮的 EEIS 可行集 K_safe，保证「抓取柔顺」不越「执行安全」。

**灵感 4（执行反馈 → 抓取执行证书 GEC + 反射式重抓 GRR）**
直觉：抓取应像第 59 轮的阻抗参数一样**持证上岗**。把净空、力闭合、静稳、滑移、可达、投影距离、遮挡与桌面置信度合成为抓取执行证书 J_grasp；只有全部边缘超过阈值才允许执行。执行中若 EV-exec 显示滑移/接触异常，不做「全局重规划」，而是用证书里的模式分布做**局部反射式重抓**：在距离当前抓取 Δ_max 内挑一个后验风险最低的等价模式，并用接触证据做贝叶斯更新。关键洞见：**滑移不是失败，是抓取位姿估计的一次在线观测。**

**灵感 5（预算 → PCE++++++ 抓取-视角双预算）**
直觉：抓取比场景识别更贵——它要采样、要投影优化、要估计对称群、要重抓，还可能需要**主动多看一个视角**来消解遮挡/对称歧义。PCE++++++ 新增 B_grasp=(B_sample,B_proj,B_sym,B_regrasp) 与 B_view。关键洞见：**当对称/遮挡歧义无法在预算内消解时，正确做法不是「赌一个」，而是保留假设的并集并执行其中风险上界最小的那个**；预算耗尽时回退到「保守证书 + 高柔顺 + 必要时请人看一眼」，而不是伪造确定性。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（桌面约束抓取流形 TCGM）** 设桌面平面 Π = {x | n_Π^T x + d_Π = 0}，n_Π 指向桌面上方；夹爪在抓取 g=(R,t) 下的占据网格为 G(g)；接近轴 a(g)=R e_z。定义四个约束残差：
- **桌面净空**：ρ_Π(g) = min_{p∈G(g)} (n_Π^T p + d_Π) − δ_table ≥ 0，且 n_Π·a(g) ≥ cos α_max（只能从上方/侧上方接近）；
- **邻物碰撞**：ρ_obs(g) = min_{p∈G(g), o∈O_occ} ‖p−o‖ − δ_obs ≥ 0；
- **可达性**：g ∈ W（关节限位、IK 有解、无自碰）；
- **静稳**：物体质心投影落在接触点/支撑多边形内且余量 ≥ δ_stab，同时切向力满足 |F_t| ≤ μ_s F_n（摩擦锥）。
记 M_table = {g ∈ SE(3) | 上述残差 ≥ 0}。M_table 是半代数集，边界不光滑，但局部可视为**带边界的约束流形**。定义投影
Proj_{M}(g) = argmin_{g'∈M_table} d_SE3(g,g')²，d_SE3(g,g')² = ‖t−t'‖² + λ_R‖log(R^T R')‖²。
**局部投影存在性/非唯一性**：当 M_table 非空且 g 处于其局部法锥内，SQP 投影存在；若 g 落在两片可行域之间（如两邻物缝隙），投影可能非唯一——此时**投影距离与投影方向的分歧度本身就是「抓取歧义」的证据**，必须进入证书，而不能悄悄取一个解。

**定义 162（对称商抓取分布 SQGD）** 设物体对称群 H = {h ∈ SE(3) | h·O = O}（盒：D₂；圆柱/瓶：连续 C_∞ × 反射；一般物体：{e}）。等价关系 g ~ g·h。商空间 Q = SE(3)/H。抓取分布 p 满足 H-不变性 p(g)=p(g·h)。定义**对称感知核**
k_H(g,g') = max_{h∈H} exp(−d_SE3(g, g'h)² / (2σ²))，
并在 Q 上做 mean-shift/Karcher 迭代求众数：
g_i^{(k+1)} = KarcherMean_{SE(3)}({g_j·h_{ij}*}；权重 w_{ij}=k_H(g_i^{(k)},g_j))，h_{ij}* = argmax_{h∈H} k(g_i,g_j h)。
输出**模式集合** Modes = {(ĝ_i, Σ_i, π_i)}_{i=1..m}，Σ_i 为 ĝ_i 处切空间 T Q 的协方差，π_i 为模式权重。**对称假设不确定时（如 H 估计置信度低），取 H 的超群 Ĥ ⊇ H 生成更粗的商空间**——宁可把两个模式合并成一个「对称族」，也不要把一个族错误拆成两个互相矛盾的点。若需分布无关覆盖，另用 conformal 校准模式集合 C_α，使 P(g* ∈ C_α) ≥ 1−α（交换性假设下）。

**定义 163（抓取-阻抗编译器 GIC）** 给定模式 (ĝ, Σ) 与任务 T，把切空间协方差分解为平移 Σ_t 与旋转 Σ_R，取 Σ_t 的特征分解 U diag(σ_j²) U^T。编译：
- **刚度**：K_p = U diag(k_j) U^T，k_j = k_min + (k_max−k_min)·exp(−β·σ_j²/σ_ref²)。沿高不确定方向 σ_j↑ ⇒ k_j→k_min（柔顺）；沿高确定方向 σ_j↓ ⇒ k_j→k_max（刚性）。
- **阻尼**：K_d = 2ζ√(K_p M)，逐轴取 ζ ≥ ζ_min，接近轴额外加阻尼 ζ_a > ζ。
- **力上限**：F_max = min(F_slip, F_obj, F_robot)，F_slip = μ_eff·F_n·(1−m_slip)，m_slip 为滑移余量。
- **安全投影**：K = Proj_{K_safe}(K_p, K_d)，K_safe 为第 59 轮 EEIS 可行集；若 K_safe = ∅ 或投影距离 > δ_K，触发 GRR/再观测，而非强行下发。
**单调性引理**：∂k_j/∂σ_j² < 0，即「越不确定越柔顺」在编译层是严格单调的；这使 GIC 可解释、可审计。

**定义 164（抓取执行证书 GEC）** J_grasp = (m_clear, m_fc, m_stab, m_slip, m_reach, m_occ, d_proj, c_plane)，各余量归一化到 [0,1]：
- m_clear 由 ρ_Π 与接近锥决定；m_fc 为力闭合度量；m_stab 为支撑多边形/摩擦锥余量；m_slip = 1−risk_slip；m_reach 由可达性/IK 余量决定；m_occ 为对隐藏体积的最小净空；d_proj = d_SE3(g, Proj_M(g))；c_plane 为桌面平面置信度。
**有效条件**：J_grasp 有效 iff min_i m_i ≥ τ_m ∧ d_proj ≤ δ_proj ∧ c_plane ≥ τ_plane。**失效概率上界**：在给定各边缘的指数型尾部假设下，P(fail) ≤ Σ_i exp(−c_i·m_i)（union bound），证书只输出可证明的上界，不输出「信心分」。**诚实性铁律**：d_proj 大、投影非唯一、c_plane 低、遮挡体积不确定时，证书必须判 INVALID，哪怕估计器 score 很高。

**定义 165（反射式重抓 GRR）** 抓取信念 b_t = {(ĝ_i, Σ_i, π_i)}。执行期由 EV-exec 得到接触残差 y_t 与滑移观测；对每个模式定义似然 L_i = ½(y_t−ŷ_i)^T Σ_obs^{-1}(y_t−ŷ_i)。异常分 s_t = max_i L_i。
- **贝叶斯更新**：π_i ← π_i·exp(−L_i)/Z；
- **重抓选择**：若 s_t > τ_slip，取 g' = argmin_i E[cost|mode i] s.t. d_SE3(g,g') ≤ Δ_max ∧ t ≤ τ_regrasp；
- **局部性**：只允许在 Δ_max 邻域内切换模式（反射式），若不存在合格模式则 safe-hold/放大柔顺，**不触发全局重规划**。
该定义把「滑移」从失败事件改写为**对模式权重的观测**：滑移方向与法向残差直接降低对应模式的 π_i。

**定义 166（TGEC 桌面抓取-执行闭环算子）** TGEC(M, T)：
```
① 感知: 点云/分割/物体位姿/桌面平面 Π
② 估计: p(g), 对称群假设 H（或多假设 {H_k}）
③ SQGD: Modes = quotient_mode_seek(p, H)
④ OGV: V_hidden = occlusion_completion(Π, 支撑图, P_vis); 剔除/降权与 V_hidden 冲突的模式
⑤ TCGM: 对每个模式 ĝ_i ← Proj_M(ĝ_i), 记录 d_proj,i
⑥ GIC: K_i = compile_impedance(ĝ_i, Σ_i) → Proj_{K_safe}
⑦ GEC: 计算 J_grasp,i；按风险上界与成本排序
⑧ 若存在有效证书: 执行 top-1；否则若 B_view 允许: 主动换视角 → 回 ①；否则执行「保守 + 高柔顺」或请人确认
⑨ Execute + CLEP; EPIR.append(EV-exec)
⑩ 若滑移/异常: GRR 贝叶斯更新 + 局部重抓 → 回 ⑧
⑪ Return: (g*, K*, J_grasp, Modes, EV-exec, S_local.status)
```

**定义 167（PCE++++++ 抓取-视角双预算）** B = (B_cog, B_grasp, B_view)，其中 B_cog 为第 60 轮四维认知预算，B_grasp=(B_sample, B_proj, B_sym, B_regrasp)，B_view=(n_views, view_latency)。抓取 VOI：
```
VOI_grasp(π) = E[Δrisk(π) − Δrisk(π after one more probe)] − λ_s·B_sample_cost
               − λ_p·Proj_cost − λ_v·View_cost − λ_r·Regrasp_cost
```
**降级规则**：B_sym 耗尽/对称置信度低 ⇒ 保留 H 并集（保守合并模式）；B_proj 耗尽 ⇒ 用最坏情况余量过滤（不投影）；B_view 耗尽且证书 INVALID ⇒ 执行保守高柔顺抓取或请求人类确认；B_regrasp 耗尽 ⇒ safe-hold，禁止继续试错；B_sample 耗尽 ⇒ 只用已缓存候选。

**定义 168（遮挡接地验证 OGV）** 桌面场景图 O = (objects, support_edges, occlusion_order)。由可见点云 P_vis、桌面平面与支撑关系构造**隐藏占据的保守上界** V_hidden：在桌面之上、位于物体轮廓完成的凸包/椭球并集内、且不落在可见自由空间中的体素集合（超近似，宁大勿小）。抓取 g 满足遮挡安全 iff G(g) ∩ V_hidden = ∅ 且接近走廊 A(g) ∩ V_hidden = ∅。遮挡余量 m_occ = min_{p∈G(g)∪A(g)} dist(p, V_hidden) − δ_occ。若 V_hidden 的不确定度（体素置信方差）过高，则 m_occ 以悲观分位数计，并优先消耗 B_view 获取补充视角。

### IP-161 TCGM（桌面约束抓取流形）

```python
class TableConstrainedGraspManifold:
    def __init__(self, table_plane, obstacles, gripper_mesh, robot, delta=(0.01, 0.02, 0.01)):
        self.Pi = table_plane                 # (n, d), n 指向桌面上方
        self.obs = obstacles                  # 邻物点云/网格
        self.gripper = gripper_mesh
        self.robot = robot
        self.d_table, self.d_obs, self.d_stab = delta

    def residuals(self, g):
        pts = transform(self.gripper.vertices, g)
        clearance = (pts @ self.Pi.n + self.Pi.d).min() - self.d_table
        approach = self.Pi.n @ g.R[:, 2] - math.cos(self.alpha_max)
        obs_gap = (self._min_dist(pts, self.obs) - self.d_obs) if len(self.obs) else 1.0
        reach = self.robot.reachability_margin(g)
        stab = self._static_stability_margin(g)
        return dict(clear=clearance, approach=approach, obs=obs_gap,
                    reach=reach, stab=stab)

    def project(self, g, iters=20):
        # SQP warm-start；把残差 < 0 的约束线性化后求最小 SE(3) 修正
        g_cur = g
        for _ in range(iters):
            r = self.residuals(g_cur)
            if min(r.values()) >= 0:
                break
            J = self._constraint_jacobian(g_cur)     # 数值/解析雅可比
            dxi = self._solve_qp(J, r)               # 半正定 QP，盒约束
            g_cur = g_cur * exp_se3(dxi)
        r = self.residuals(g_cur)
        feasible = min(r.values()) >= 0
        return g_cur, se3_distance(g, g_cur), feasible, r

    def _static_stability_margin(self, g):
        contacts = self._contact_points(g)
        hull = convex_hull(contacts)          # 桌面投影支撑多边形
        com = self._object_com(g)
        margin = signed_polygon_distance(com[:2], hull)
        friction = self.mu_s * self._normal_force(g) - self._tangential_force(g)
        return min(margin, friction)
```

### IP-162 SQGD（对称商抓取分布）

```python
class SymmetryQuotientGraspDistribution:
    def __init__(self, symmetry_hypotheses, sigma=0.03, m_max=6):
        self.Hs = symmetry_hypotheses     # [SE3Group]；未知时含恒等群
        self.sigma = sigma
        self.m_max = m_max

    def quotient_kernel(self, g, g2):
        return max(math.exp(-se3_distance(g, g2 * h) ** 2 / (2 * self.sigma ** 2))
                   for H in self.Hs for h in H)

    def mode_seek(self, samples, weights=None):
        samples = list(samples)
        centers = self._farthest_point_init(samples, self.m_max)
        for _ in range(30):
            new_centers = []
            for c in centers:
                ks, aligned = [], []
                for g in samples:
                    h_star, k_best = None, -1.0
                    for H in self.Hs:
                        for h in H:
                            k = math.exp(-se3_distance(c, g * h) ** 2 / (2 * self.sigma ** 2))
                            if k > k_best:
                                h_star, k_best = h, k
                    ks.append(k_best)
                    aligned.append(g * h_star)
                w = np.asarray(ks) * (weights if weights is not None else 1.0)
                new_centers.append(karcher_mean_se3(aligned, w))
            if max(se3_distance(a, b) for a, b in zip(centers, new_centers)) < 1e-4:
                break
            centers = new_centers
        return self._to_modes(centers, samples)   # [{g, Sigma, pi}], 合并同族

    def conformal_set(self, calib_scores, alpha=0.1):
        q = np.quantile(calib_scores, 1 - alpha)
        return lambda modes: [m for m in modes if m["nonconformity"] <= q]
```

### IP-163 GIC（抓取-阻抗编译）

```python
def compile_grasp_impedance(mode, eeis, k_range=(50, 2000), zeta=1.0, beta=1.0):
    U, s2, _ = np.linalg.svd(mode["Sigma_t"])
    k_min, k_max = k_range
    k = k_min + (k_max - k_min) * np.exp(-beta * s2 / np.median(s2 + 1e-9))
    Kp = U @ np.diag(k) @ U.T
    Kd = 2 * zeta * np.sqrt(Kp * mode["inertia"])
    # 接近轴额外阻尼：先软接触再对齐
    Kd = Kd + np.diag([0, 0, 0.5 * Kd[2, 2]])
    F_max = min(mode["mu_eff"] * mode["F_n"] * (1 - mode["m_slip"]),
                mode["F_obj"], mode["F_robot"])
    K = {"Kp": Kp, "Kd": Kd, "F_max": F_max}
    K_safe = eeis.project_into_feasible(K)    # 第 59 轮 EEIS
    if K_safe is None or eeis.project_distance(K) > eeis.delta_K:
        return None                            # 交 GRR / 再观测
    return K_safe
```

```python
def grasp_execution_certificate(mode, res, d_proj, v_hidden, c_plane, tau=0.2):
    m = {
        "clear": normalize(res["clear"], res["approach"]),
        "fc": force_closure_margin(mode),
        "stab": normalize(res["stab"]),
        "slip": 1 - slip_risk(mode),
        "reach": normalize(res["reach"]),
        "occ": occlusion_margin(mode["g"], v_hidden),
    }
    J = dict(margins=m, d_proj=d_proj, c_plane=c_plane)
    J["valid"] = (min(m.values()) >= tau and d_proj <= DELTA_PROJ
                  and c_plane >= TAU_PLANE)
    J["fail_ub"] = sum(math.exp(-c * x) for c, x in zip(C_VEC, m.values()))
    return J

class ReflexiveRegrasp:
    def update(self, modes, y, Sigma_obs):
        for mode in modes:
            L = 0.5 * (y - mode["y_hat"]).T @ np.linalg.inv(Sigma_obs) @ (y - mode["y_hat"])
            mode["pi"] *= math.exp(-L)
        Z = sum(m["pi"] for m in modes)
        for mode in modes:
            mode["pi"] /= Z

    def select(self, modes, g_cur, delta_max, tau_regrasp):
        cand = [m for m in modes
                if se3_distance(g_cur, m["g"]) <= delta_max and m["cert"]["valid"]]
        if not cand:
            return None                        # safe-hold，不全局重规划
        return min(cand, key=lambda m: m["pi"] * m["risk_ub"] + m["cost"])
```

## 2. 关键推导与引理

### 2.1 投影距离是可执行性的连续下界

设 d_SE3(g,g')² = ‖t−t'‖² + λ_R‖log(R^T R')‖² 为左不变度量。若 g' = Proj_M(g) 可行且 d_SE3(g,g') = d_proj，则对任意可行 g'' ∈ M_table，有
```
d_SE3(g,g'') ≥ d_proj                       （投影的最优性）
d_SE3(g,g'') ≤ d_SE3(g,g') + d_SE3(g',g'')  （三角不等式）
```
因此 **d_proj 是「到可行集的最近距离」**；它不是排序启发式，而是一个有几何意义的量。若 d_proj ≤ δ_proj，则 g 与某个可行抓取在 δ_proj 内；若投影非唯一（存在 g'_1,g'_2 同为最近点），则定义分歧度
```
amb(g) = max_{a,b∈Proj_M(g)} d_SE3(a,b)
```
并令 `amb(g) > δ_amb ⇒ 证书 INVALID`。这堵住了「悄悄取一个最近解」的漏洞。

### 2.2 GIC 的「越不确定越柔顺」是严格单调的

对第 j 个主轴：
```
k_j(σ_j²) = k_min + (k_max − k_min)·exp(−β σ_j²/σ_ref²)
∂k_j/∂σ_j² = −(β/σ_ref²)(k_max − k_min)·exp(−β σ_j²/σ_ref²) < 0
```
故不确定性增大 ⇒ 该方向刚度严格下降；又有 k_j ∈ (k_min,k_max)，编译有界，不会出现负刚度或无穷柔顺。对阻尼 K_d=2ζ√(K_p M)，ζ ≥ ζ_min 保证不欠阻尼；接近轴附加阻尼 ζ_a 使首次接触的冲击能量被耗散。该引理让「柔顺」不是玄学参数，而是可审计的不确定性函数。

### 2.3 对称核的 H-不变性

对任意 h₀∈H：
```
k_H(g h₀, g') = max_{h∈H} exp(−d(g h₀, g' h)²/2σ²)
              = max_{h∈H} exp(−d(g, g' h h₀^{−1})²/2σ²)
              = max_{h'∈H} exp(−d(g, g' h')²/2σ²) = k_H(g,g')   （H 对乘法封闭）
```
故商空间众数对对称作用等变，**不会把 g 与 g·h 当成两个需要平均的异类**。盒子的 D₂ 对称下，正确输出是 4 个模式（各面），而不是中心处一个「45° 平均抓取」——后者往往正好撞桌角或无法闭合。

### 2.4 证书失效概率上界

设各余量 m_i 的失败尾部满足 P(fail_i) ≤ exp(−c_i m_i)（亚指数/指数尾假设），则
```
P(any fail) ≤ Σ_i P(fail_i) ≤ Σ_i exp(−c_i m_i) = fail_ub
```
证书只发布 fail_ub 与是否有效，不发布「模型信心分」。若某个 m_i 因桌面倾斜/遮挡不确定只能用悲观分位数，则 fail_ub 相应放大；当 fail_ub > ε_fail 或任一 m_i < τ_m 时判 INVALID。这不是保守主义，而是**把不可证的确定性从接口里删掉**。

### 2.5 GRR 的贝叶斯更新

给定观测 y（接触残差/滑移方向），模式 i 的高斯似然 L_i=½(y−ŷ_i)^T Σ_obs^{-1}(y−ŷ_i)，则
```
π_i^+ = π_i·exp(−L_i) / Σ_j π_j·exp(−L_j)
```
即后验权重。若滑移方向与模式 i 的预测法向相反，L_i 大，π_i 快速下降；重抓只在 `d_SE3(g,g') ≤ Δ_max` 内选后验风险最小者，因此**不会因一次滑移而跳到桌子另一端的全局解**。这把「重抓」限制为低延迟的反射动作，而把全局重规划留给上层。

### 2.6 Conformal 模式集（可选保证）

若抓取成功预测器在 calibration 集上可交换，取非一致性分数 s_i，阈值 q = Quantile_{1−α}({s_i})，则模式集 C_α={i: s_i ≤ q} 满足 P(g*∈C_α) ≥ 1−α。用于把「估计器 score」升级为「有覆盖率保证的候选集」；当 C_α 为空时，系统必须选择换视角/保守抓取，而不是从空集里硬取 top-1。

### IP-161 TCGM（桌面约束抓取流形）

```python
class TableConstrainedGraspManifold:
    def __init__(self, plane, obstacles, gripper, robot,
                 d_table=0.01, d_obs=0.02, d_stab=0.01,
                 alpha_max=math.radians(75)):
        self.Pi, self.obs, self.gripper, self.robot = plane, obstacles, gripper, robot
        self.d_table, self.d_obs, self.d_stab, self.alpha_max = (
            d_table, d_obs, d_stab, alpha_max)

    def residuals(self, g):
        pts = transform(self.gripper.vertices, g)
        clear = (pts @ self.Pi.n + self.Pi.d).min() - self.d_table
        approach = self.Pi.n @ g.R[:, 2] - math.cos(self.alpha_max)
        obs = (min_dist(pts, self.obs) - self.d_obs) if len(self.obs) else 1.0
        reach = self.robot.reachability_margin(g)
        stab = self._stability(g)
        return {"clear": clear, "approach": approach,
                "obs": obs, "reach": reach, "stab": stab}

    def project(self, g, iters=20):
        cur = g
        for _ in range(iters):
            r = self.residuals(cur)
            if min(r.values()) >= 0:
                break
            J = self._jacobian(cur)
            dxi = solve_qp(J, r)                 # min ||dxi||^2 s.t. J dxi + r >= 0
            cur = cur * exp_se3(dxi)
        r = self.residuals(cur)
        proj_set = self._projection_candidates(g)   # 多初值 SQP 检测非唯一
        amb = max_pairwise_se3_distance(proj_set)
        return cur, se3_distance(g, cur), min(r.values()) >= 0, r, amb

    def _stability(self, g):
        contacts = self._contact_points(g)
        com = self._object_com(g)
        margin_in = signed_distance_to_hull(com[:2], contacts[:, :2])
        friction = self.mu_s * self._normal_force(g) - self._tangential_force(g)
        return min(margin_in, friction)
```

### IP-162 SQGD（对称商抓取分布）

```python
class SymmetryQuotientGraspDistribution:
    def __init__(self, hypotheses, sigma=0.03, m_max=6, delta_amb=0.02):
        self.Hs, self.sigma = hypotheses, sigma
        self.m_max, self.delta_amb = m_max, delta_amb

    def kernel(self, g, g2):
        return max(math.exp(-se3_distance(g, g2 * h) ** 2 / (2 * self.sigma ** 2))
                   for H in self.Hs for h in H)

    def mode_seek(self, samples, weights=None, iters=30):
        centers = farthest_point_init(samples, self.m_max)
        for _ in range(iters):
            new = []
            for c in centers:
                ks, aligned = [], []
                for g in samples:
                    h_star, k_best = None, -1.0
                    for H in self.Hs:
                        for h in H:
                            k = math.exp(-se3_distance(c, g * h) ** 2
                                         / (2 * self.sigma ** 2))
                            if k > k_best:
                                h_star, k_best = h, k
                    ks.append(k_best); aligned.append(g * h_star)
                w = np.asarray(ks) * (weights if weights is not None else 1.0)
                new.append(karcher_mean_se3(aligned, w))
            if max(se3_distance(a, b) for a, b in zip(centers, new)) < 1e-4:
                break
            centers = new
        return merge_symmetric_modes(centers, samples, self.Hs)

    def conservative_union(self, modes):
        # 对称假设不确定时：取超群 H_hat ⊇ H，合并可能同族的模式
        return merge_by_group_closure(modes, self.Hs)
```

### IP-163 GIC（抓取-阻抗编译）

```python
def compile_grasp_impedance(mode, eeis, k_range=(50, 2000),
                            zeta=1.0, beta=1.0):
    U, s2, _ = np.linalg.svd(mode["Sigma_t"])
    k_min, k_max = k_range
    denom = np.median(s2) + 1e-9
    k = k_min + (k_max - k_min) * np.exp(-beta * s2 / denom)
    Kp = U @ np.diag(k) @ U.T
    Kd = 2 * zeta * np.sqrt(Kp * np.asarray(mode["inertia"]))
    Kd[2, 2] *= 1.5                                  # 接近轴额外阻尼
    F_slip = mode["mu_eff"] * mode["F_n"] * (1 - mode["m_slip"])
    F_max = min(F_slip, mode["F_obj"], mode["F_robot"])
    K = {"Kp": Kp, "Kd": Kd, "F_max": F_max}
    K_safe = eeis.project_into_feasible(K)
    if K_safe is None or eeis.project_distance(K) > eeis.delta_K:
        return None, "EEIS_INFEASIBLE"
    return K_safe, "OK"
```

### IP-164/165 GEC + GRR（证书与反射式重抓）

```python
def build_certificate(mode, res, d_proj, amb, v_hidden, c_plane,
                      tau=0.2, delta_proj=0.015, delta_amb=0.02,
                      tau_plane=0.9):
    m = {
        "clear": norm_margin(res["clear"], res["approach"]),
        "fc": force_closure_margin(mode["g"]),
        "stab": norm_margin(res["stab"]),
        "slip": 1.0 - slip_risk(mode),
        "reach": norm_margin(res["reach"]),
        "occ": occlusion_margin(mode["g"], v_hidden),
    }
    J = {"margins": m, "d_proj": d_proj, "amb": amb, "c_plane": c_plane}
    J["valid"] = (min(m.values()) >= tau and d_proj <= delta_proj
                  and amb <= delta_amb and c_plane >= tau_plane)
    J["fail_ub"] = sum(math.exp(-c * x) for c, x in zip(C_VEC, m.values()))
    return J

class ReflexiveRegrasp:
    def observe(self, modes, y, Sigma_obs):
        for m in modes:
            d = y - m["y_hat"]
            m["L"] = 0.5 * d.T @ np.linalg.inv(Sigma_obs) @ d
            m["pi"] *= math.exp(-m["L"])
        Z = sum(m["pi"] for m in modes)
        for m in modes:
            m["pi"] /= Z

    def select(self, modes, g_cur, delta_max, tau_regrasp):
        cand = [m for m in modes
                if se3_distance(g_cur, m["g"]) <= delta_max
                and m["cert"]["valid"] and m["K"] is not None]
        if not cand:
            return None                               # safe-hold
        return min(cand, key=lambda m: m["cert"]["fail_ub"] + m["cost"])
```

### IP-166/167/168 TGEC 主循环 + 预算 + 遮挡

```python
def occlusion_completion(plane, support_graph, p_vis, voxel=0.005):
    # 可见点云 → 物体轮廓完成的保守凸包/椭球并集 → 桌面之上的隐藏体素
    visible = voxelize(p_vis, voxel)
    hidden = set()
    for obj in support_graph.nodes:
        hull = conservative_hull_completion(obj, p_vis, plane)
        for v in voxels_inside(hull):
            if v.z > plane.height and v not in visible:
                hidden.add(v)
    return HiddenVolume(hidden, confidence=support_graph.confidence)

def TGEC(M, task):
    scene = M.scene_model.update(M.telem_force, M.telem_pos)      # 第 60 轮
    cands = M.grasp_estimator(M.point_cloud, scene)
    Hs = M.symmetry_estimator(cands)                              # 多假设
    modes = M.sqgd.mode_seek(cands, Hs)
    V_hidden = occlusion_completion(M.table_plane, M.support_graph, M.point_cloud)
    modes = [m for m in modes if occlusion_margin(m["g"], V_hidden) > 0]
    for m in modes:
        m["g"], d_proj, feas, res, amb = M.tcgm.project(m["g"])
        m["K"], status = compile_grasp_impedance(m, M.eeis)
        m["cert"] = build_certificate(m, res, d_proj, amb, V_hidden,
                                      M.table_conf)
    valid = [m for m in modes if m["cert"]["valid"] and m["K"] is not None]
    if not valid:
        if M.budget.view_left() and voi_grasp(M) > 0:
            M = M.with_new_view()
            return TGEC(M, task)
        return M.safe_hold_or_ask_human(task)
    chosen = min(valid, key=lambda m: m["cert"]["fail_ub"])
    M.dispatch_impedance_params(chosen["K"], chosen["cert"])
    M, fused, D_plus, ev, cert = closed_loop_exec_probe(M, task, M.budget)
    M.epir.append(ev.__dict__)
    if ev.slip_detected:
        M.regrasp.observe(modes, ev.contact_residual, ev.Sigma_obs)
        nxt = M.regrasp.select(modes, chosen["g"], DELTA_MAX, TAU_REGRASP)
        if nxt is not None and M.budget.regrasp_left():
            return TGEC_with_grasp(M, task, nxt)
    return M, chosen, modes, ev, cert
```

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| TCGM | O(K·N_v·iters) | O(N_v+N_obs) | 可行则残差 ≥ 0；d_proj/amb 显式返回 |
| SQGD | O(m·n·|H|·iters) | O(n+m·d) | H-不变核；不跨对称族平均 |
| OGV | O(N_vox log N_vox) | O(N_vox) | V_hidden 超近似 ⇒ 隐藏碰撞不被误判 |
| GIC | O(d³) | O(d²) | ∂k/∂σ²<0；输出 ∈ K_safe 或 ⊥ |
| GEC/GRR | O(m) / O(m) | O(m·d²) | INVALID 拒执行；重抓 ≤ Δ_max |
| TGEC | 上述之和 | 复用 | 无证书必走换视角/保守/请人 |

**正确性定理（TGEC）**：若 A66–A70 成立（见想法区），则：
1. **几何可执行性**：证书有效 ⇒ 投影后抓取满足桌面净空、接近锥、邻物净空、可达与静稳约束。
2. **对称正确性**：SQGD 输出的模式在 H 作用下等价类稳定；当 H 被粗化为超群时，合并只会**减少**模式数而不会产生跨族平均点。
3. **执行安全**：GIC 的刚度沿不确定方向严格更低，且 (K_p,K_d,F_max) 落在 K_safe 或返回不可行。
4. **证据闭环**：GRR 的权重更新即贝叶斯后验，滑移方向与法向残差被保留为证据，重抓局部且有时限。
5. **失效可证**：任一假设被违反 ⇒ fail_ub 放大或证书 INVALID，系统回退而非静默执行。

## 5. 实验协议与预期结果（仿真推演，非实测）

**平台**：桌面杂乱场景 30 类物体（盒/瓶/圆柱/软包/堆叠）× 5 种桌面（光滑/木质/绒布/湿滑/倾斜 3°）；每场景 100 次随机初始位姿；基线为「top-1 抓取 + 固定阻抗 + 可见点云过滤」。

**消融预期**：去 TCGM ⇒ 碰撞率回升至 ~8%；去 SQGD ⇒ 对称物体成功率 −27%；去 GIC ⇒ 滑移率回升至 ~11%；去 OGV ⇒ 遮挡堆叠场景碰撞率 ×3；去 GRR ⇒ 单次失败恢复时间 ×2.5。**结论**：四个模块的作用域几乎不重叠——这正是把它们拆成独立 IP 而非一个大模型的理由。

**一个具体数值例子**：边长 0.08 m 的立方盒，D₂ 对称。抓取估计给出 4 个模式，位姿均值落在盒中心上方且与两邻面成 45°，若按欧氏 Karcher 均值会得到一个夹爪对角线张角不足、且与桌角净空 −6 mm 的位姿；SQGD 保留 4 个面模式，TCGM 将其中 2 个因邻物投影距离 34 mm 拒绝，剩余 2 个证书有效，GIC 沿接近轴把 k 从 800 降到 220 N/m、附加阻尼 1.5×，首触峰值力从 41 N 降到 26 N。

## 6. 本轮最大风险

**一句话**：若对称群被低估（圆柱当 C₁）、桌面平面倾斜误差未被悲观计入、或投影在两片可行域间非唯一却取了单个解，三个误差会被「d_proj 很小、c_plane 很高」互相掩盖，生成一个**看起来持证、实际几何错误**的抓取；必须以「对称假设取超群并集」「桌面/遮挡余量悲观分位数」「投影非唯一（amb>δ_amb）即 INVALID」「证书只输出可证 fail_ub」四重护栏，确保抓取信念的确定性永远不超过几何证据的确定性。
