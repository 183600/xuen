# 第 41 轮 · 双灵感收束 v8：单体多任务骨干 × 干扰证书 × 原型优先研究协议（四层架构 v6）

> 承接第 40 轮（v17：可认证流匹配执行 × 度量语义几何锚定 × 证书驱动课程引擎，四层架构 v5）。本轮灵感词「单模型多任务、快速原型」不是再叠一层模块，而是一次**结构性收束**：四十轮已累积 50 个 IP 与四层 v5，系统最大的隐患已从「证书不够严谨」转为「系统不可搭建、条款不可验证」。本轮把「一个共享骨干服务全部技能」与「一天内可证伪的最小原型」引入，让证书体系从越写越厚的文档，变成可被快速原型逐条履行的证明义务。

## 0. 直觉与动机

**灵感 1（单模型多任务 → 从技能银行到单体骨干）**：v5 的技能总线本质是「政策银行 + 专用模块联邦」：每个技能一套权重、每个层次一组专家，参数与工程复杂度随 IP 数线性膨胀——50 个 IP 意味着至少 50 条独立的训练、部署、认证流水线。单模型多任务给出相反的归纳偏置：一个共享主干 θ₀ 加每技能一个低秩适配器 φ_h，π_h(a|o) = f_{θ₀}(o; φ_h(z_h))。共享带来三重收益：a) 参数、延迟、运维成本从 O(K) 降到 O(1)+O(K·r)；b) 跨任务正迁移让新技能以极少数据冷启动；c) 任务算术 θ₀+Σα_hτ_h 让 IP-47 的组合从「类型检查」升级为「参数空间组合」。代价是把「技能隔离」换成了「全局干扰」——这正是证书体系必须正面回答的新问题。

**灵感 2（快速原型 → 把证书条款变成可证伪的最小实验）**：第 40 轮最大的自我批评是「装饰性证书」：L_v、κ、B_t 若无人快速实测，就只是符号。快速原型的洞见是：**每一条证书条款都是一项证明义务（proof obligation），最小原型是它的部分求值器**。于是研究流程被重写为 claim → 预注册阈值 → ≤1 天最小原型 → 实测 → 证书更新。用「原型阶梯」L0 解析/mock、L1 单任务仿真、L2 多任务仿真、L3 真机控制成本；用「研究债务账本」量化未履行条款，避免体系在纸面上自洽、在现实中空转。

**两灵感的耦合（本轮关键）**：单体多任务让干扰变成**全局且解析上不可控**，因此比以往任何时候都更需要快速原型提供经验反馈；反过来，快速原型因为只有一个骨干、一套基础设施，使「换共享拓扑做 A/B」的成本骤降，从而能在一天内搜索「哪几层该共享」。二者合起来给出本轮的可操作产物：**以干扰证书为目标函数的共享拓扑搜索**，加**从证书条款自动编译最小原型的原型编译器**。

**为什么是收束而非扩张**：过去每轮都在增加「可认证的对象」，本轮第一次减少「需要独立认证的对象」——把 K 条技能流水线压成 1 个骨干 + K 个适配器，把散落的实验压成一台原型编译器。收束本身就是最大的创新点：它让「可认证」从成本中心变成可交付物。

## 1. 形式化定义

**定义 27（单体多任务骨干 OB）**：技能集 H = {h₁,…,h_K}，共享主干 θ₀ 与任务条件适配器 {φ_h}。策略 π_h(a|o) = f_{θ₀}(o; φ_h(z_h))，z_h 为任务嵌入。共享率 ρ = |θ₀| / (|θ₀| + Σ_h |φ_h|)。任务向量 τ_h = φ_h（以 θ₀ 为零点）。组合 h_i ⊕ h_j：θ = θ₀ + α(τ_i + τ_j)。共享拓扑 S ⊆ {layer_1,…,layer_L} 表示被所有任务共享的层，其余层按任务私有。

**定义 28（干扰证书 CertX）**：对任务对 (i,j)，实测干扰 M_{ij} = m_i(θ_{i∪j}) − m_i(θ_i)，即共享/联合训练后任务 i 的证书边际变化；m_i 复用第 40 轮的六类边际，令 M_{ii} = m_i(θ_i) 为单任务自边际。θ 对 H 是 (β,{c_h}) 可认证的，当且仅当：
- 边际保持：∀h ∈ H，m_h(θ) ≥ c_h；
- 干扰有界（块对角占优）：max_i Σ_{j≠i} |M_{ij}| ≤ β·min_i M_{ii}，β < 1；
- 组合安全：任意子集 T ⊆ H 的组合边际 m_T ≥ min_{i∈T}(1−β)·M_{ii}。

**命题 1（干扰组合安全）**：若块对角占优成立，则对任意 T ⊆ H，m_T ≥ (1−β)·min_{i∈T} M_{ii}；故只要单任务自边际 M_{ii} ≥ c_i/(1−β)，联合训练与任意组合均保持认证。证明：联合训练下 m_i ≥ M_{ii} − Σ_{j≠i}|M_{ij}| ≥ (1−β)M_{ii}，对 i 取最小并利用组合的 min 传递即得。∎

**定义 29（原型优先协议 PP）**：证书包 C = {C₁,…,C_n}，每条条款 C_k 关联原型 P(C_k) = (ℓ_k, T_k, ψ_k, ε_k)，ℓ_k ∈ {L0,L1,L2,L3} 为原型阶梯层级，T_k 为预算（≤1 天），ψ_k 为检验，ε_k 为**预注册**阈值（先于实验固定）。若 ψ_k 在 ℓ_k 上以显著性通过，则称 C_k 被履行。研究债务 RD = Σ_k w_k·1[C_k 未被任何 ≥ℓ_k 原型履行]；原型覆盖度 PCov = |{k: C_k 已履行}|/n。协议目标：在总预算 B 下 max PCov，s.t. Σ_k T_k ≤ B，且预注册不可事后修改。

## 2. 三大产出设计

### 2.1 IP-51 ONE-BODY-MULTITASK（单体多任务骨干）
1. 共享主干 + 低秩适配器（LoRA / HyperNet-FiLM），把 v5 四层重组为四个任务族：感知融合、语义仲裁、任务-运动、蒸馏课程。
2. 任务算术组合：IP-47 的组合式任务在参数空间完成，系数 α 由 CertX 的干扰上界约束。
3. 共享拓扑搜索：以块对角占优度与共享率 ρ 为目标，逐层贪心 + 贝叶斯优化搜索 S。
4. 多教师蒸馏：把 v5 的 K 个专用技能蒸馏进单一骨干（教师 K → 学生 1），复用 IP-44。
5. 反遗忘：任务向量正交化 + 证书赤字加权回放（复用 IP-50）。

### 2.2 IP-52 INTERFERENCE-CERT（干扰证书）
1. 在线估计 M_{ij}：成对/子集联合微调的小步探针；用低秩聚类把 O(K²) 降为 O(K·r)。
2. 梯度冲突监控：cos(g_i,g_j) 与梯度手术（PCGrad）作为运行时干扰抑制。
3. 块对角占优证书：命题 1 给出组合安全的充分条件，接入 IP-46 的 CertBundle。
4. 干扰感知调度：IP-45 总线按 M 做适配器路由与并发隔离，高干扰技能不同时占用共享主干。

### 2.3 IP-53 PROTOTYPE-COMPILER（原型编译器）
1. 证书条款 → 原型 DAG：把 CertFlow/CertX 的每个字段编译成 L0–L3 的最小实验。
2. 预注册与自动证伪：阈值先写入、实验脚本自动生成、结果自动回填证书。
3. 研究债务账本：可视化未履行条款，驱动下一轮优先级排序。
4. 一天原型模板库：LIO 漂移、CBF 安全、流采样 N*、干扰矩阵等可复用 micro-bench。

## 5. 本轮最大风险

**一句话**：单体化把「局部可认证」变成「全局耦合」——一次分布漂移或一个任务的灾难性遗忘会经共享主干污染所有技能证书，而 O(K²) 干扰矩阵与快速原型又可能只覆盖廉价的 L0/L1，最终让「单模型」省下的工程债被「全局不可证」加倍偿还，故 E74 是本轮第一守门实验。

## 2. 关键算法

### IP-51 共享拓扑搜索（伪代码）
```
def search_sharing_topology(tasks, rho_min, budget):
    S = set()                                   # 初始全私有
    while sharing_ratio(S) < 1.0 - rho_min and budget > 0:
        cand = layers_not_shared(S)
        delta = {l: probe_interference(S | {l}, tasks) for l in cand}  # 低秩探针
        l_star = argmin_l block_diag_ratio(delta[l])                   # 干扰最小者
        if certify(CertX(S | {l_star})) is feasible:
            S = S | {l_star}
        budget -= probe_cost
    return S
```

### IP-52 干扰证书（伪代码）
```
def interference_cert(theta0, adapters, margins, beta):
    M = eye(K) * margins                         # M_ii = 单任务自边际
    for (i, j) in low_rank_pairs(adapters):      # O(K·r) 聚类，避开 O(K²)
        theta_ij = joint_finetune(theta0, [i, j], steps=probe_steps)
        M[i, j] = margin_i(theta_ij) - margins[i]
    block_diag = max_i sum_{j != i} abs(M[i, j]) <= beta * min_i M[i, i]
    cert = all(margin_h(theta) >= c_h for h in H) and block_diag
    return CertX(M, beta, block_diag, cert)
```

### IP-53 原型编译器（伪代码）
```
def compile_prototype(clause):
    psi = pick_test(clause.metric)               # 从一天模板库选检验
    eps = preregister_threshold(clause)          # 先于运行固定，禁止事后改
    script = codegen(psi, level=clause.level, budget=clause.budget)
    return Prototype(clause, psi, eps, script)

def run_prototypes(clauses, B):
    plan = knapsack(clauses, budget=B, value=coverage_gain)   # 覆盖度最大化
    for p in plan:
        r = execute(p)                           # L0 解析 / L1 单任务 / L2 多任务 / L3 真机
        p.clause.discharge(r, p.eps)             # pass/fail 回填证书
        ledger.update(p.clause, r)
    return ledger                                # 输出 RD, PCov
```
