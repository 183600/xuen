### 第 1 轮灵感驱动研究记录

**灵感词**：群体智能、阻抗控制

**直觉与动机**：

先给直觉。前几轮我们把控制问题建模为「证书驱动的优化」：KEMPC 用常识约束优化，CADVS 用分布式证书裁决，MRCC 让多机交换证书摘要。这条路线隐含一个「中心化裁决」的残余：证书必须被聚合、比较、排序，最后由某个节点拍板。群体智能给出的直觉恰好相反——**没有总控，只有局部规则与局部耦合，全局行为是涌现的**。阻抗控制的直觉则是：不要直接命令位姿或力，而命令「机器人与环境/同伴之间的动态柔顺关系」。把两者叠在一起，会得到一个很自然的问题：

> 能否让双足机器人（以及机群）不去「协商一个全局安全的动作」，而是**通过局部阻抗耦合自发形成安全队形/步态**，并且这种涌现行为本身可以被证书证明？

具体展开四点：

1. **从「位姿证书」到「能量证书」**。CADVS 的十二证多是状态/时序/几何谓词（FQC、DLC、SLO）。阻抗控制的核心不是位姿误差，而是**能量流动**：无源性（passivity）保证「机器人—环境—同伴」互联网络不会凭空产生能量。若每个智能体是一个带能量罐（energy tank）的无源阻抗端口，那么「证书」可以变成一条能量不等式 E_i(t) ≥ E_min，而不是一次性的状态检查。能量证书对交互式任务（推门、搀扶、双足落地冲击）比位姿证书更本质。

2. **群体智能的正确用法不是「多机投票」，而是「局部耦合的涌现」**。前几轮 MRCC 的均值一致性其实是「分布式投票」，它有一个致命弱点：**均值会掩盖最弱个体**。群体智能里真正稳健的机制是局部交互 + 最小共识（min-consensus）+ 信息素式记忆。把虚拟阻抗作为边、把能量裕度作为节点状态，整个机群就是一个「阻抗网络」，其稳定性可由网络无源性定理一次性证明，而不需要枚举全局状态。

3. **阻抗参数不该全局固定，也不该简单共识平均，而应「局部自适应 + 群体可行性投影」**。每个智能体根据自己的地形/负载/接触状态调 K_i、D_i；同时通过邻居共识把参数拉向一个共同可行域，但**投影到无源可行集**（K、D 正定且有界）。这等价于一个带凸约束的分布式优化，收敛性和无源性可以同时保证。

4. **知识共享用「信息素式安全场」而非广播**。群体智能的 stigmergy（痕迹通信）很适合安全知识：机器人在某处发生近失稳/打滑，就在该空间位置沉积「负证据」，场按扩散—衰减演化，后来者读到高浓度就提高局部刚度或绕行。关键是可以证明场强有界（沉积有界 + 衰减 > 0 ⇒ 稳态有界），从而不会出现「恐惧信息素」无限累积导致群体瘫痪。

5. **双尺度统一**：同一条理论可以同时用于「单机内部」和「机群」——左腿/右腿是耦合的两个阻抗端口，多台双足是更大的耦合网络。这让「群体智能」不只是多机器人，也可以是**肢体级群体**。

**关键洞见**：把「安全」从**状态谓词**重铸为**能量不等式**，把「群体」从**投票聚合**重铸为**无源阻抗网络**。前者让证书可组合（网络无源性由子模块无源性推出），后者让全局稳定性无需全局信息。二者合起来，就是把 CADVS 从「分布式证书裁决系统」升级为「可证明的涌现式柔顺控制系统」。

**形式化目标（增量）**：

1. 定义单智能体无源阻抗端口证书 PCert = (id, K, D, E_tank, m, t, Δt_val)，其中 m = E_tank − E_min 为无源裕度。
2. 定义虚拟阻抗耦合图 G_c = (V, E_c, K^c, D^c)，耦合储能 E^c_ij = ½‖x_i − x_j − d_ij‖²_{K^c_ij}。
3. 定义信息素安全场 φ(x,t) 的沉积—扩散—衰减 PDE，并给出场强上界 Φ_max = α·e_max/β。
4. 定义分布式投影共识阻抗自适应：K_i(k+1) = Proj_{P_i}(K_i(k) − η(∇f_i + γ Σ_j a_ij(K_i − K_j)))，P_i 为无源可行集（凸）。
5. 定义最小共识群体证书 SPCC：m_min = min_i m_i（而非均值），以及涌现行为证书 EBCert（序参量 R、队形误差 e_form、振荡指数 Ω）。
6. 定义 SICN 统一框架，使 Exec_SICN ⊆ Exec_CADVS，并证明：理想通信下网络无源、场强有界、共识收敛；同时明确「无源性 ≠ 状态安全」的边界。

**本轮最大风险**：**无源性证书与状态安全证书的语义错位**——能量有界只能保证网络不「自激发散」，却完全不能保证某个个体不跌倒、不超关节限位、不撞障；群体最小共识虽然避免均值掩盖最弱个体，但「最弱个体的能量裕度仍为正」与「最弱个体物理上仍安全」是两件事，于是可能出现「全网能量证书通过、队形也稳定，但边缘机器人已经越过安全边界」的群体版虚假安全感。

## 2. 关键算法骨架

### IP-478 Passivity Energy-Tank Impedance Port (PETIP)

```python
@dataclass
class PassivityEnergyTankImpedancePort:
    """PETIP：单智能体无源阻抗端口 + 能量罐证书"""
    agent_id: str = 'a0'
    freq_hz: int = 500
    k_min: float = 50.0
    k_max: float = 2000.0
    d_min: float = 5.0
    d_max: float = 200.0
    e_tank_max: float = 20.0      # J
    e_min: float = 0.5            # J，无源裕度零点
    e_ref: float = 0.8            # 归一化参考能量（仅高于此值才泄放）
    leak_gain: float = 0.05

    def __post_init__(self):
        self.K = np.eye(6) * 500.0
        self.D = np.eye(6) * 40.0
        self.E = 0.6 * self.e_tank_max

    def impedance_law(self, x, x_d, xdot, xdot_d):
        e = x - x_d
        ed = xdot - xdot_d
        return -(self.K @ e + self.D @ ed)

    def update_tank(self, u, xdot, dt, p_in):
        # Ė = P_in − uᵀẋ − leak；leak 仅在 E 高于参考值时耗散（不产生负泄漏）
        P_ctrl = float(u @ xdot)
        leak = self.leak_gain * max(0.0, self.E - self.e_ref * self.e_tank_max)
        self.E += dt * (p_in - P_ctrl - leak)
        self.E = float(np.clip(self.E, 0.0, self.e_tank_max))
        return self.E

    def gate(self, u):
        # 能量罐见底 → 线性降额，保证不向被控系统净注入能量
        if self.E <= self.e_min:
            return np.zeros_like(u)
        scale = min(1.0, (self.E - self.e_min) /
                    max(self.e_ref * self.e_tank_max - self.e_min, 1e-9))
        return scale * u

    def cert(self, t_now):
        m = self.E - self.e_min
        return PCert(agent_id=self.agent_id, K=self.K.copy(), D=self.D.copy(),
                     e_tank=self.E, margin=m, passive=(m >= 0.0),
                     t=t_now, validity_window=3.0 / self.freq_hz)
```

### IP-479 Stigmergic Safety Field (SSF)

```python
@dataclass
class StigmergicSafetyField:
    """SSF：沉积—扩散—衰减的安全信息素场（stigmergy）"""
    res: float = 0.10          # 网格分辨率 m
    alpha: float = 1.0         # 沉积增益
    beta: float = 0.05         # 衰减率 1/s
    diff: float = 0.01         # 扩散系数 m²/s
    e_max: float = 1.0         # 单次证据上界
    g_phi: float = 20.0        # 场强→刚度增益 (N/m per unit)
    phi_cap: float = None      # 缺省由 alpha*e_max/beta 推出

    def __post_init__(self):
        if self.phi_cap is None:
            self.phi_cap = self.alpha * self.e_max / self.beta
        self.phi = np.zeros((1, 1))

    def deposit(self, x, evidence, dt):
        i, j = self._cell(x)
        ev = float(np.clip(evidence, 0.0, self.e_max))
        self.phi[i, j] += dt * self.alpha * ev

    def step(self, dt):
        self.phi += dt * (self.diff * self._laplacian(self.phi)
                          - self.beta * self.phi)
        np.clip(self.phi, 0.0, self.phi_cap, out=self.phi)

    def stiffness_bias(self, x, K_base, k_min, k_max):
        i, j = self._cell(x)
        K = K_base + self.g_phi * self.phi[i, j] * np.eye(6)
        w, V = np.linalg.eigh(0.5 * (K + K.T))
        return V @ np.diag(np.clip(w, k_min, k_max)) @ V.T
```

### IP-480 Consensus Impedance Adaptation (CIA)

```python
@dataclass
class ConsensusImpedanceAdaptation:
    """CIA：带无源可行集投影的分布式阻抗自适应"""
    eta: float = 0.02
    gamma: float = 0.5
    rho: float = 1e-3          # 刚度正则，防参数漂移

    def local_grad(self, agent, x_d):
        e = agent.x - x_d
        ed = agent.xdot
        gK = 0.5 * np.outer(e, e) + self.rho * agent.port.K
        gD = 0.5 * np.outer(ed, ed) + self.rho * agent.port.D
        return gK, gD

    def step(self, agent, neighbors, x_d):
        gK, gD = self.local_grad(agent, x_d)
        cons_K = sum(a * (agent.port.K - nb.port.K) for nb, a in neighbors)
        cons_D = sum(a * (agent.port.D - nb.port.D) for nb, a in neighbors)
        K = agent.port.K - self.eta * (gK + self.gamma * cons_K)
        D = agent.port.D - self.eta * (gD + self.gamma * cons_D)
        agent.port.K = self.project(K, agent.port.k_min, agent.port.k_max)
        agent.port.D = self.project(D, agent.port.d_min, agent.port.d_max)

    @staticmethod
    def project(M, lo, hi):
        # 投影到 {εI ⪯ M ⪯ M_max I}：凸集上的非扩张投影
        M = 0.5 * (M + M.T)
        w, V = np.linalg.eigh(M)
        return V @ np.diag(np.clip(w, lo, hi)) @ V.T
```

### IP-481 Swarm Passivity Certificate Consensus (SPCC)

```python
@dataclass
class SwarmPassivityCertificateConsensus:
    """SPCC：最小共识（min-consensus）群体无源证书，显式暴露最弱个体"""
    diameter_bound: int = 8

    def __post_init__(self):
        self.m_min = float('inf')
        self.weakest = None
        self.rounds = 0

    def on_local(self, cert: PCert):
        if cert.margin < self.m_min:
            self.m_min, self.weakest = cert.margin, cert.agent_id

    def on_peer(self, pid: str, m_peer: float, hop: int):
        # 只接受更小的裕度：min-consensus，避免均值掩盖短板
        if hop > self.diameter_bound:
            return False
        if m_peer < self.m_min:
            self.m_min, self.weakest = m_peer, pid
            self.rounds = hop + 1
            return True
        return False

    def certify(self):
        return SwarmCert(valid=(self.m_min >= 0.0),
                         min_margin=self.m_min,
                         weakest=self.weakest,
                         rounds=self.rounds)
```

### IP-482 Emergent Behavior Certificate Monitor (EBCM)

```python
@dataclass
class EmergentBehaviorCertificateMonitor:
    """EBCM：监测期望涌现 vs 非期望同步/振荡"""
    r_min: float = 0.85        # 对齐度下界
    e_form_max: float = 0.10   # 队形误差上界 m
    omega_max: float = 0.30    # 振荡频带能量占比上界
    window: int = 200
    f_lo: float = 1.5
    f_hi: float = 6.0

    def __post_init__(self):
        self.buf = deque(maxlen=self.window)

    def observe(self, t, headings, positions):
        self.buf.append((t, np.asarray(headings), np.asarray(positions)))

    def order_params(self):
        if len(self.buf) < self.window // 2:
            return 0.0, float('inf'), 0.0
        _, headings, positions = self.buf[-1]
        R = float(abs(np.mean(np.exp(1j * headings))))
        e_form = float(np.std(np.linalg.norm(
            positions - positions.mean(axis=0), axis=1)))
        omega = self._band_power_ratio(self.f_lo, self.f_hi)
        return R, e_form, omega

    def certify(self):
        R, e_form, omega = self.order_params()
        desired = (R >= self.r_min) and (e_form <= self.e_form_max)
        bad_sync = omega > self.omega_max
        return EBCert(desired=desired, bad_sync=bad_sync,
                      R=R, e_form=e_form, omega=omega)
```

### SICN 统一执行流（单步）

```python
def sicn_step(swarm, sensors, t, dt):
    """SICN：局部无源阻抗 → 信息素场 → 共识自适应 → 群体证书裁决"""
    # 1) 每个智能体：阻抗 + 能量罐 + 无源证书
    for a in swarm.agents:
        u = a.port.impedance_law(a.x, a.x_d, a.xdot, a.xdot_d)
        u = a.port.gate(u)
        a.port.update_tank(u, a.xdot, dt, p_in=sensors[a.id].regen_power)
        swarm.spcc.on_local(a.port.cert(t))
        a.u = u

    # 2) 信息素安全场：沉积近失稳/打滑证据，扩散衰减，局部刚度偏置
    for a in swarm.agents:
        ev = sensors[a.id].near_miss_evidence
        if ev > 0:
            swarm.ssf.deposit(a.x[:2], ev, dt)
    swarm.ssf.step(dt)
    for a in swarm.agents:
        a.port.K = swarm.ssf.stiffness_bias(
            a.x[:2], a.port.K, a.port.k_min, a.port.k_max)

    # 3) 分布式投影共识自适应（每个迭代点保持无源可行）
    for a in swarm.agents:
        swarm.cia.step(a, a.neighbors, a.x_d)

    # 4) 群体证书：最小裕度 + 涌现行为
    swarm_cert = swarm.spcc.certify()
    swarm.ebcm.observe(t, swarm.headings(), swarm.positions())
    eb = swarm.ebcm.certify()

    # 5) 分级裁决（只增加约束，故严格包含于 CADVS）
    if not swarm_cert.valid:
        return SwarmAction.DECOUPLE_AND_HOLD, swarm_cert
    if eb.bad_sync:
        return SwarmAction.REDUCE_COUPLING, eb
    if not eb.desired:
        return SwarmAction.REPLAN_FORMATION, eb
    return SwarmAction.COMMIT, (swarm_cert, eb)
```

## 3. 复杂度分析（增量更新）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 | 实时性指标 |
|---|---|---|---|---|
| PETIP 阻抗律 + 能量罐 | O(n²)（n=6） | O(n²) | 500Hz–1kHz | < 0.02ms/体 |
| SSF 场演化（显式差分） | O(N_cells) | O(N_cells) | 100×100 网格 | < 0.5ms/步（可降采样） |
| SSF 局部读+刚度偏置 | O(n³)（6×6 特征分解） | O(n²) | 每体每步 | < 0.01ms/体 |
| CIA 投影共识 | O(n³) + O(\|N_i\| n²) | O(n²) | 20–50Hz | < 0.05ms/体 |
| SPCC 最小共识 | O(\|E_c\|) / 轮 | O(N) | ≤ 直径（≈8）轮 | < 0.1ms/轮 |
| EBCM 序参量 + 频带功率 | O(N log N)（FFT） | O(window·N) | window=200 | < 1ms/50ms |
| **群体单步（N=6）** | **期望 < 3ms** | **O(N·n² + N_cells)** | **P99 < 8ms** | **满足 100–200Hz 群体环** |

**通信开销**：PCert 约 300–800 bytes（含 6×6 增益矩阵，可量化/稀疏化）；N=6、50Hz 广播约 0.1–0.24 MB/s，远低于 CADVS 证书链路的 3–6 MB/s。SPCC 的最小共识只需在「发现更小裕度」时转发，事件驱动，平均通信量更低。

## 4. 正确性论证（增量更新）

### 引理 32（能量罐门控的单体无源性）

**陈述**：设被控对象能量为 H_i，控制功率 P_i = u_i^T ẋ_i，能量罐动力学为 Ė_i = P_in,i − P_i − λ·max(0, E_i − E_ref)，且门控后恒有 E_i ≥ 0。则增广系统（对象 + 能量罐）对端口 (u_ext,i, P_in,i) 是无源的，存储函数 S_i = H_i + E_i，供给率 u_ext,i^T ẋ_i + P_in,i。

**证明**：对象功率平衡 Ḣ_i = P_i + u_ext,i^T ẋ_i。于是
Ṡ_i = Ḣ_i + Ė_i = (P_i + u_ext,i^T ẋ_i) + (P_in,i − P_i − leak) = u_ext,i^T ẋ_i + P_in,i − leak ≤ u_ext,i^T ẋ_i + P_in,i，
因为 leak = λ·max(0, E_i − E_ref) ≥ 0。门控把 E_i 钳在 [0, E_max]，故 S_i 非负有界。∎

**工程含义**：PETIP 的 gate() 就是「E_i ≤ E_min 时置零、否则线性降额」的算法化，正是引理 32 的非负性条件；证书 m_i ≥ 0 是可直接在线检查的充分条件。

### 引理 33（虚拟阻抗耦合网络的无源性）

**陈述**：若 G_c 中每条边是虚拟弹簧—阻尼，F_ij = −K^c_ij(x_i − x_j − d_ij) − D^c_ij(ẋ_i − ẋ_j)，F_ji = −F_ij，且 K^c_ij, D^c_ij ⪰ 0，则互联网络存储 S = Σ_i (H_i + E_i) + Σ_{edges} E^c_ij 满足 Ṡ ≤ Σ_i (u_ext,i^T ẋ_i + P_in,i)，即网络无源。

**证明**：单边交换功率
P_ij = F_ij^T ẋ_i + F_ji^T ẋ_j = F_ij^T(ẋ_i − ẋ_j)
= −(x_i − x_j − d_ij)^T K^c_ij(ẋ_i − ẋ_j) − (ẋ_i − ẋ_j)^T D^c_ij(ẋ_i − ẋ_j)
= −dE^c_ij/dt − (ẋ_i − ẋ_j)^T D^c_ij(ẋ_i − ẋ_j) ≤ −dE^c_ij/dt。
对所有边求和，耦合项被耦合储能的变化吸收，阻尼项非正；再由引理 32 对每个节点相加即得。∎

**工程含义**：只要耦合边是无源元件，网络稳定性由「节点无源 + 边无源」组合得到，无需全局状态枚举。**但该结论依赖瞬时（或经波变量补偿的）通信**，见 R33。

### 引理 34（信息素安全场的场强有界性）

**陈述**：φ 满足 ∂φ/∂t = D_φ∇²φ − βφ + α Σ_k s_k δ(x − x_k)，0 ≤ s_k ≤ e_max，β > 0，Neumann 边界。则 t → ∞ 时 φ(x,t) ≤ Φ_max = α·e_max/β；进而刚度偏置满足 ΔK ≤ g_φ·Φ_max。

**证明**：常数上解 φ̄ ≡ α·e_max/β 代入方程：左端 0，右端 −β·(α e_max/β) + α Σ_k s_k δ = α(Σ_k s_k δ − e_max) ≤ 0（沉积点处取等）。由抛物型方程的比较原理（最大值原理），φ 不超过该上解；Φ_max 与初值无关。刚度偏置是 φ 的线性正函数，故 ΔK ≤ g_φ Φ_max。∎

**工程含义**：沉积有界 + 衰减严格正 ⇒ 场强有界，避免「恐惧信息素」无限累积导致群体僵死。只要 g_φ Φ_max ≤ K_max − K_base，SSF 的偏置不会把 K 推出无源可行集，从而不破坏引理 32。

### 引理 35（投影共识阻抗自适应的收敛性与可行性）

**陈述**：设通信图为无向连通图，权重双随机，各局部代价 f_i 凸且 L-光滑，步长 η ≤ 1/L，P_i = {K: εI ⪯ K ⪯ K_max I} 为凸集且 ∩_i P_i ≠ ∅。则 CIA 迭代收敛到共识，且每个迭代点满足无源可行性；其固定点满足 Σ_i ∇f_i = 0 的一阶最优性（在公共可行域上）。

**证明**：忽略投影时，标准分布式梯度下降的共识误差满足 e(k+1) ≤ (1 − c)e(k) + η‖∇f‖，连通图给出 c > 0，故共识误差有界并收敛；投影到凸集是非扩张算子（‖Proj(x) − Proj(y)‖ ≤ ‖x − y‖），不破坏收敛性，且逐点可行性由投影定义直接成立。固定点处共识项消失、梯度项求和为零，即一阶最优性。∎

**注意**：若异构可行域交集为空（∩_i P_i = ∅），则只能得到有界不一致而非精确共识——这是 R37。

### 定理（SICN 执行集收缩与网络能量有界）

**陈述**：在以下假设下：
(A1) 每个智能体的 PCert 有效（m_i ≥ 0，引理 32）；
(A2) 耦合边为无源虚拟弹簧—阻尼，且通信无时延或经波变量（wave variable）补偿（引理 33）；
(A3) 信息素场有界且 g_φ Φ_max ≤ K_max − K_base（引理 34）；
(A4) SPCC 最小裕度 m_min ≥ 0，且 EBCert.desired 成立；
则 (i) Exec_SICN ⊆ Exec_CADVS；(ii) 网络存储 S(t) 有界，且 S(T) − S(0) ≤ ∫_0^T Σ_i (u_ext,i^T ẋ_i + P_in,i) dt；(iii) 队形误差 e_form 保持在 EBCM 阈值内。**但 (ii)(iii) 不蕴含任何个体状态约束 x_i ∈ X_safe,i 成立。**

**证明**：
- (i) SICN 每一步在 CADVS 的十二证裁决之外只增加约束（PCert、SPCC、EBCert），可行动作集只会更小，故为子集。
- (ii) 由引理 32–33 对增广网络直接积分即得。
- (iii) 由 EBCert.desired 的定义（e_form ≤ e_form_max）直接得到。
- 最后一句：能量有界与队形有界都是标量/聚合量，状态约束是逐个体的集合成员关系，二者之间没有逻辑蕴含。∎

**诚实声明**：该定理是「稳定性/有界性」结论，不是「安全性」结论。SICN 必须与 CADVS 的十二证以及逐体状态约束（如控制屏障函数 CBF）联合使用，绝不能把「能量证书通过」误读为「个体安全」。

## 5. 实验设计（仿真 + 实机）

**仿真平台**：Isaac Gym / MuJoCo，N = 6 台双足（或 3 台双足 + 3 台四足），粗糙地形 + 随机外推 + 单体执行器退化注入。

**对照**：
- B1：固定阻抗（无自适应，无证书）；
- B2：均值一致性证书（朴素 MRCC 式聚合，故意用均值掩盖短板）；
- B3：SICN 去掉信息素场（消融 stigmergy）；
- B4：完整 SICN（min-consensus + SSF + CIA + EBCM）。

**指标**：群体跌倒率、个体最小安全裕度（到障碍/关节限位/支撑多边形边界）、能量罐违规率、队形 RMSE、任务完成率、**假证书率**（证书通过后 H 步内发生跌倒/越界）、通信量、最小共识轮数。

**预期（待复现，非实测）**：

| 指标 | B1 | B2 | B3 | B4 |
|---|---|---|---|---|
| 群体跌倒率 | 高 | 中 | 中低 | **最低** |
| 假证书率 | — | **最高**（均值掩盖） | 中 | **最低** |
| 队形 RMSE | 高 | 中 | 中 | **低** |
| 能量罐违规 | 高 | 中 | 低 | **最低** |
| 通信量 | 最低 | 中 | 中 | 中（事件驱动更低） |

**关键假设检验**：(H1) 在「一个体执行器退化」场景下，B2 的均值证书仍通过而该个体越界，B4 的 min-consensus 能提前暴露——这是本轮核心论点的直接检验；(H2) SSF 能降低重复踩坑导致的重复重规划次数；(H3) EBCM 能在高耦合增益下抑制非期望同步振荡。

**实机**：3 台双足/四足平台，Vicon 动捕 + 机载 IMU/关节编码器，柔性推挤与搀扶任务；重点验证能量罐在真实接触冲击下的非负性，以及 min-consensus 在通信抖动下的收敛轮数。

## 7. 本轮最大风险（最终确认）

**一句话**：**无源性是能量域的稳定性证书，而安全是状态域的集合成员关系，二者之间没有逻辑蕴含；群体最小共识虽能暴露「能量上最弱」的个体，却无法保证「物理上最危险」的个体——于是整个 SICN 可能陷入「全网能量证书通过、队形稳定，但某个边缘机器人早已越界」的群体版虚假安全感，这是比单机证书失效更隐蔽、也更难归因的根本风险。**
